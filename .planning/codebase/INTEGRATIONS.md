# External Integrations

**Analysis Date:** 2026-08-10

## APIs & External Services

**GitHub:**
- GitHub REST API - star count for homepage social proof
  - SDK/Client: native `fetch` in `src/lib/githubStars.ts`
  - Auth: public request to `https://api.github.com/repos/labring/FastGPT`
  - Endpoints used: repository metadata, `stargazers_count`

**CRM / Lead Routing:**
- CRM API - anonymous visitor attribution
  - SDK/Client: native `fetch` in `src/lib/leadAttribution.ts`
  - Auth: `NEXT_PUBLIC_CRM_API_URL` plus browser state
  - Endpoints used: `POST /visitors/track`

**Forms and Sales Links:**
- Feishu share forms - commercial and custom plan entry points
  - Location: `src/config/site.ts`
  - Usage: outbound inquiry links for sales and pricing flows
- FastGPT Cloud - trial CTA destination
  - Location: `src/config/site.ts` and `src/components/home/hooks/useStartUrl`
  - Default URL: `https://cloud.fastgpt.io`

**Static Assets and CDN:**
- `https://static.step1.dev/tixzae/assets` - QR and shared assets in `src/components/home/assets.ts`
- `https://oss.laf.run/...` - external image used in `src/config/site.ts` footer links

## Data Storage

**Browser Storage:**
- `localStorage.xs_attr` - first-touch and last-touch attribution state
- `localStorage.fastgpt_reported_attribution` - CRM reporting dedupe marker
- `localStorage.preferredLang` - preferred language selection
- `NEXT_LOCALE` cookie - locale preference for navigation

**File Storage:**
- `.cache/github-stars.json` - local cache for repository stars
- `out/` - static export consumed by verification scripts and deployment

**Databases:**
- The public site is content-driven and file-backed

## Authentication & Identity

**Auth Provider:**
- The public site is unauthenticated
- CTA links route users to external FastGPT Cloud and sales/contact destinations

## Monitoring & Observability

**Analytics:**
- Google Analytics - loaded from Google Tag Manager via `src/app/GoogleAnalytics.tsx`
- Baidu Tongji - loaded via `src/app/BaiDuAnalytics.tsx`
- Microsoft Clarity - loaded via `src/app/ClarityAnalytics.tsx`
- Rybbit - loaded via `src/app/RybbitAnalytics.tsx`
- Event attributes are generated by `src/lib/rybbitEvents.ts`

**Logs:**
- Hosting logs from Cloudflare Pages or Nginx in production
- Console output from verification scripts during build and audit runs

## CI/CD & Deployment

**Hosting:**
- Cloudflare Pages - static deployment target documented in `README.md`
- Nginx - static hosting and security header support in `nginx.conf`
- `serve@latest` - local static serving via `npm run start`

**Build Pipeline:**
- `next build` - exports the static site into `out/`
- `scripts/generate-robots.js` and `scripts/generate-llms.js` - build-time document generation
- `scripts/clean-faq-rsc.js` and `scripts/fix-html-lang.js` - post-build cleanup

## Environment Configuration

**Development:**
- Env vars live in local shell or `.env` files
- Public keys and URLs are read through `NEXT_PUBLIC_*` variables
- GitHub stars cache and attribution state stay local to the machine or browser

**Production:**
- Tracking, CRM, and site URLs resolve from environment variables
- Static export and redirect assets stay in sync with `public/_redirects` and `nginx.conf`

## Webhooks & Callbacks

**Outgoing:**
- CRM visitor tracking POST from `src/lib/leadAttribution.ts`
- Third-party analytics script loads from Google, Baidu, Clarity, and Rybbit

**Incoming:**
- Public static hosting requests only
