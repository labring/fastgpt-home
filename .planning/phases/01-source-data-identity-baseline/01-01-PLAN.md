## Trust Boundaries

| Boundary | Description |

| External workbook -> parser | Source files are outside the repository and are untrusted input to XML and ZIP parsing. |
| Parser -> audit scripts | JSON rows and manifests become inputs for validators and reports. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | `xlsx_reader.py` source manifest | high | mitigate | Hash the exact workbook bytes, retain sheet/header/row metadata, and compare the locked fingerprints in tests. |
| T-01-02 | Elevation of privilege | XML/ZIP parser | medium | mitigate | Read only the requested worksheet members through `zipfile`; reject malformed relationships and avoid external entity resolution. |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | Use Python standard library only; no new package install is planned. |
</threat_model>
