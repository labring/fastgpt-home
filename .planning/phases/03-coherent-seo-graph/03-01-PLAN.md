## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Encoded request/build route parameter → identity resolver | A URL segment selects an FAQ record and must resolve only through the validated registry/catalog. |
| Registry/catalog JSON/TS → metadata and link builders | Committed route data controls canonical URLs, alternates, links, static params, and sitemap entries. |
| Locale owner manifest → absolute URL output | Host and hreflang values must come from the manifest/owned helpers rather than user-controlled strings. |
| FaqItem authored fields → H1/JSON-LD HTML | Question/Answers become visible and structured data; serializers must preserve identity and escape content. |
| Build output → verifier | Static files and sitemap values are untrusted evidence until every record/path is checked. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-03-02 | Spoofing | `src/lib/seo.ts` canonical/alternate builder | high | mitigate | Use `getOwnedFaqUrl`, manifest owner domains, target-locale route keys, and published-counterpart checks; never trust request host/path. |
| T-03-03 | Tampering | `src/app/[lang]/faq/[id]/page.tsx` H1/FAQ JSON-LD | high | mitigate | Use one resolved `FaqItem` for H1, JSON-LD, breadcrumb, and related identity; parse all exported pages in HTML mode. |
| T-03-04 | Tampering | `src/app/sitemap.ts` URL set | high | mitigate | Enumerate final catalog IDs only, exact absolute URL de-duplicate, and reject legacy/prefixed aliases in the verifier. |
| T-03-05 | Injection | JSON-LD/metadata serialization | medium | mitigate | Reuse Next metadata and `JsonLdScript` escaping; verifier parses serialized tags rather than interpolating source strings. |
| T-03-06 | Integrity | `dynamicParams=false` static coverage | high | mitigate | Compare registry/catalog cardinality to io/cn export paths and fail on missing/unknown static routes. |
| T-03-07 | Environment | Case-insensitive export volume | medium | accept | Preserve healthy mixed-case policy, diagnose same-file collisions, and require case-sensitive CI/release evidence for full HTML verification. |
| T-03-08 | Supply chain | package scripts and verifier | high | mitigate | Use existing Node/Next dependencies only; no network fetch, spreadsheet runtime read, or new package. |
