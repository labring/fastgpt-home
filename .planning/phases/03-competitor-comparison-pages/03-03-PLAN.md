<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Source package/official URLs -> manifest | Local and remote evidence is normalized into publication metadata. |
| Manifest/signoff evidence -> build and sitemap | Publication state controls indexability and public distribution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03-01 | Tampering | Source fingerprints and manifest | high | mitigate | Pin hashes, validate exact source versions, and fail closed on drift before any status transition. |
| T-03-03-02 | Spoofing | Product/sales/legal signoff evidence | high | mitigate | Require role-specific approved status, signer, timestamp, and evidence reference for each page. |
| T-03-03-03 | Repudiation | Failure report and status transition | medium | mitigate | Write deterministic failure rows and preserve manifest status changes as reviewable artifacts. |
| T-03-03-04 | Information disclosure | Preview routes and unsigned content | high | mitigate | Preview metadata is noindex/nofollow and preview slugs are excluded from sitemap/navigation; only published entries are distributable. |
| T-03-03-05 | Tampering | Remote/internal link targets | medium | mitigate | Validate absolute or known-local URLs, fetch/check accessibility, and block temporary markers or unverified links. |
</threat_model>
