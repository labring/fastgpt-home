<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Manifest/content records -> Next.js route | Audited page data controls rendered text, links, assets, metadata, and publication state. |
| Rendered page -> search crawler/browser | Metadata and JSON-LD cross into external indexing and browser execution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04-01 | Tampering | Dynamic slug route | high | mitigate | Use exact static params, `dynamicParams=false`, typed slug lookup, and `notFound` for every unregistered locale/slug. |
| T-03-04-02 | Information disclosure | Preview metadata/sitemap | high | mitigate | Derive robots and sitemap from manifest status; previews get noindex/nofollow and no sitemap/nav entry. |
| T-03-04-03 | Code injection | Article/Breadcrumb JSON-LD | high | mitigate | Escape `<` before `dangerouslySetInnerHTML` and render only typed source data. |
| T-03-04-04 | Spoofing | Internal/external links | medium | mitigate | Render only manifest-verified targets and preserve external-link rel attributes; temporary markers are rejected by the manifest gate. |
| T-03-04-05 | Denial of service | Large comparison tables | low | accept | Static bounded four-page content has no user-controlled expansion; stable responsive CSS caps layout width and avoids client-side loops. |
</threat_model>
