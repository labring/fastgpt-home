# Plan 04-01: Import and validate the first 100 Meta records

## Objective

Read the V1.0 Meta workbook deterministically, map every source row through the Phase 1 identity evidence, and expose the 76 verified records through an English FAQ metadata overlay while keeping the 24 unresolved rows in a failure manifest.

## Tasks

1. Add a source reader/validator that checks workbook SHA, sheet, headers, row count, uniqueness, Title/Description field presence, and per-row source evidence.
2. Generate a checked-in `src/faq/legacyMeta.ts` module containing only the verified source rows keyed by existing FAQ repo key, plus a machine-readable source/mapping manifest with before/after hashes and unresolved rows.
3. Integrate the overlay at the FAQ data boundary so `getFaqData`, `getFaqItem`, static IDs, and detail-page metadata consume the source Title/Description without changing answers, questions, categories, keywords, keys, or URLs.
4. Add a regression verifier for exact 100-row source coverage, 76 applied rows, 24 explicit failures, source hash, metadata limits, and immutable-field hashes.

## Verification

- Run the Meta validator and inspect the generated manifest.
- Run `npx tsc --noEmit`, `npm run lint`, and the focused Phase 4 metadata test.
