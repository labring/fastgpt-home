<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Committed route registry → redirect projection | Registry fields decide which historical paths may receive a redirect and which paths remain denied. |
| Request pathname/query → edge redirect writer | Edge artifacts map untrusted paths to prevalidated absolute targets while preserving query strings. |
| Build environment → static artifacts | Site variant, owner URL, and filesystem semantics determine which routes and hosts are exported. |
| Static artifacts → aggregate verifier | Generated HTML, sitemap, Worker, and Nginx files are evidence until every expected record/path is checked. |
| Child process exit/output → release result | Subprocess failures must remain observable and cannot be swallowed by an aggregate coordinator. |
| Generated public/build files → repository worktree | Cleanup must avoid losing committed source snapshots or leaving stale variant residue. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering | Registry-backed alias projection | high | mitigate | Require canonical registry target, routeStatus repaired, collisionDisposition none, one-to-one source mapping, deterministic sorted output, and focused source checks. |
| T-04-02 | Spoofing | Collision ledger and denied aliases | high | mitigate | Merge record and ledger deny sets; assert all 572 denied repairs and 149 ledger source slugs are absent from Worker/Nginx maps. |
| T-04-03 | Open redirect/injection | Worker/Nginx target writers | high | mitigate | Permit only `https://fastgpt.io`/`https://fastgpt.cn` owner targets, encode path segments, preserve query values without interpolating them into target paths, and assert direct 301 semantics. |
| T-04-04 | Integrity | Variant build orchestration | high | mitigate | Set explicit variant/base URL environment, clear stale output, verify immediately, and require exact 1,400/1,490 route cardinality. |
| T-04-05 | Environment | Case-insensitive filesystem | high | mitigate | Probe case sensitivity before full builds; fail closed with a route-pair diagnostic and require Linux/Docker or case-sensitive APFS evidence. |
| T-04-06 | Error handling | Aggregate verifier subprocesses | high | mitigate | Capture exit status and stderr/stdout, annotate command/variant/record context, aggregate failures, and exit nonzero on any failed child. |
| T-04-07 | Artifact integrity | Cleanup and generated public files | medium | mitigate | Snapshot/restore tracked generated files, remove only disposable output on success, and expose retained paths under `--keep-artifacts`. |
| T-04-08 | Supply chain | Release command dependencies | medium | mitigate | Use current Node/npm scripts and built-ins only; no new package, runtime workbook read, network fetch, or deployment action. |
</threat_model>
