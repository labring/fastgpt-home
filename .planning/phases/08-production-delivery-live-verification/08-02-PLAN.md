## Trust Boundaries

| Boundary | Description |
|---|---|
| GitHub workflow inputs/secrets → provider APIs | CI can mutate production deployments and purge caches. |
| Archive/manifest → Docker/Pages provider | Published bytes and release identity become public state. |
| Kubernetes current image/Pages previous deployment → rollback record | External provider state supplies recovery targets. |

## STRIDE Threat Register — ASVS L1

| Threat ID | Category | Severity | Mitigation |
|---|---|---:|---|
| T-08-05 | Elevation of privilege | high | Least-privilege workflow permissions, secret guards, and no secret echo. |
| T-08-06 | Tampering | high | Digest-pinned image, content-addressed archive, manifest/tree checks, and immutable upload names. |
| T-08-07 | Repudiation | high | Persist provider IDs, previous revision, purge response, workflow run, and source commit. |
| T-08-08 | Denial of service | high | Require explicit rollback targets and rollout status before declaring success. |
| T-08-SC | Supply chain | high | Existing action majors, exact Wrangler 4.123.0 in package-lock, provider-audit `npm ci --ignore-scripts` with the local binary, and digest-pinned multi-arch Nginx runtime base. |
</threat_model>
