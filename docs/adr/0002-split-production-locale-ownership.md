# Split production locale ownership between fastgpt.cn and fastgpt.io

FastGPT assigns Simplified Chinese to fastgpt.cn and English, Traditional Chinese, Japanese, Arabic, Vietnamese, Thai, Indonesian, and Malay to fastgpt.io. Simplified Chinese is served at `fastgpt.cn/`, English is served at `fastgpt.io/`, and the remaining international locales use stable language prefixes. Each production root consistently serves its Primary Locale, with locale navigation triggered by an explicit user choice; IP, browser language, and stored preferences may provide suggestions. The China Site presents a single-locale interface, and the International Site language selector lists only locales owned by the International Site. Legacy `/zh` and `/en` URLs permanently redirect to their corresponding root URLs. A published locale URL requested from the other production site permanently redirects to its locale owner while preserving the page path and query parameters; requests outside the page's Published Locale Set return a localized `404` at the source. Preview hosts keep every locale on the preview hostname. This preserves the China Site's Mainland China signal and existing search equity while keeping Traditional Chinese available to global audiences; canonical URLs and hreflang entries follow the locale owner.
