# Publish locales per page

Each page defines its own Published Locale Set containing only locales with complete localized main content. Sitemaps, hreflang annotations, and page-level language navigation derive from that set, while the broader Supported Locale list describes the languages available across each production site. Every published version uses a self-referencing canonical URL on its locale owner and lists the complete reciprocal Published Locale Set in hreflang. Hreflang annotations use the HTML head as their single source, while each production sitemap lists only canonical Published URLs owned by that site. The English version acts as `x-default` when it belongs to the set, and preview hosts stay outside production hreflang clusters. Requests for a locale outside the page's Published Locale Set return a localized `404` with links to published variants; a `200` response represents complete localized content.
