# Issue tracker: GitHub

Issues and specs for this repo live in GitHub Issues at `labring/fastgpt-home`.
Use the `gh` CLI and pass `--repo labring/fastgpt-home`.

## Conventions

- Create issues with `gh issue create`.
- Read issues with `gh issue view <number> --comments`.
- List issues with `gh issue list`.
- Update labels with `gh issue edit <number> --add-label "<label>"`.
- Apply `ready-for-agent` to fully specified implementation issues.
- Pull requests are excluded from the triage request surface.
