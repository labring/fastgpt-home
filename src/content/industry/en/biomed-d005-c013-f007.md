# Workflow Orchestration for mRNA Vaccine Regulations

## Data Characteristics for this Category

mRNA vaccine regulations and Standard Operating Procedure (SOP) documents typically exist as PDFs, Word files, or internal knowledge base pages. Data sources include regulations published by drug regulatory agencies (e.g., China NMPA's "Good Manufacturing Practice for Pharmaceutical Products"), international vaccine association guidelines, and detailed SOPs developed by internal R&D, production, and quality control departments. These documents update infrequently, usually annually or every few years, following regulatory revisions or technological breakthroughs. Document structures are complex, containing extensive specialized terminology, charts, flowcharts, and cross-references. Fields and units are highly specialized, such as "preparation batch number," "mRNA purity (%)", "lipid nanoparticle (LNP) size (nm)", "storage temperature (℃)", and "vaccination dose (µg)", requiring strict adherence to numerical precision and unit consistency.

## Constraints Imposed by these Characteristics on Workflow Orchestration

The complex data characteristics of mRNA vaccine regulations introduce specific requirements for workflow orchestration. Document diversity and complex structures necessitate robust document parsing capabilities within the workflow to accurately extract key information and prevent data loss from parsing failures. The strictness of specialized terminology and measurement units requires precise semantic matching during information retrieval and Q&A to avoid misunderstandings from fuzzy matching, for example, distinguishing "batch" from "batch number." The infrequent update rate allows for a knowledge base synchronization strategy that combines periodic full updates with incremental updates, avoiding overly frequent full indexing. Documents containing charts and flowcharts require the workflow to handle non-textual information, such as extracting key information from visuals via image recognition or manual annotation, and integrating it into the Q&A context.

## Configuration Settings

| Configuration Item | Recommended Value | Rationale for this Value |
| :----- | :------- | :----------- |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | mRNA vaccine regulation documents can contain numerous charts and high-resolution images, leading to large file sizes. |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 seconds` | Parsing complex PDF documents is time-consuming; a longer timeout prevents parsing interruptions. |
| `Chunk size` | `800–1200 characters` | Paragraphs in regulatory documents often contain contextually dense professional descriptions; longer segments help maintain semantic integrity. |
| `Recall count` | `Top 10 entries` | Ensures sufficient relevant regulatory clauses are covered in highly specialized Q&A. |
| `Similarity threshold` | Calibrated by actual measurement | Adjusted using a test set based on actual Q&A scenarios to balance recall and precision. |
| `Rerank result count` | `Top 5 entries` | After reranking, focus on the few most relevant items to improve the accuracy of the final answer. |

## Three Common Pitfalls

*   A `workflow error {"message":"Dangerous behavior` during workflow debugging typically indicates misconfigured toolchains or model calls within the workflow, such as attempting to execute dangerous system commands or access restricted resources.
*   `base64` encoded data returned by the workflow cannot be directly displayed as an image because the frontend interface lacks the necessary decoding and rendering logic; the workflow is responsible only for data transmission, not direct rendering.
*   After file upload, the workflow fails to correctly parse or process the binary stream, resulting in empty file content or parsing errors. This occurs when the file upload interface does not correctly configure `Content-Type` or the workflow lacks file type identification and parsing tools.

## How to Confirm Correct Configuration

*   Upload an mRNA vaccine SOP document containing complex charts. Check if the knowledge base correctly extracts and indexes text content and observe if it provides basic descriptions or annotations for charts.
*   Ask questions using specific mRNA vaccine terminology (e.g., "LNP size," "mRNA purity"). Verify if the workflow accurately recalls regulatory clauses containing these terms, and check that the `similarity` values of the recalled results are within a reasonable range.
*   Simulate real-world operational scenarios by asking questions about specific regulatory processes (e.g., "mRNA vaccine production batch release process"). Check if the workflow's returned answers are logically clear, complete in steps, and consistent with the original document content.
