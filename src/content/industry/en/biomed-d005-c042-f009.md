# Citation and Traceability for Media and Consumables Regulations

## Data Characteristics

Regulatory documents for cell culture media and consumables in the biopharmaceutical sector typically exist as PDFs, Word documents, or internal knowledge base pages. Data sources primarily include technical manuals from suppliers, Standard Operating Procedures (SOPs) developed by internal R&D departments, standards published by quality control departments, and compliance requirements from regulatory bodies. Update frequencies vary; for instance, supplier technical manuals might update 1–2 times annually, while internal SOPs could update quarterly or semi-annually based on R&D progress or quality audit results. Document structures usually include clear chapter titles, clause numbers, tables (e.g., media formulation tables, consumable batch records), and detailed parameters with units (e.g., concentration `g/L`, pH value, sterilization time `min`, storage temperature `°C`). Fields such as "Batch Number," "Expiration Date," "Supplier," and "Specification Model" are common and critical.

## Constraints on Citation and Traceability from Data Characteristics

Regulatory documents for cell culture media and consumables have strict structures and contain numerous numerical parameters. This demands precise citation to specific chapters, paragraphs, or even table cells. Inconsistent update frequencies require clear differentiation of document versions during traceability to avoid citing outdated or superseded regulatory clauses. The specific fields and units within documents, such as batch numbers, concentrations, and temperatures, impose higher demands on the information extraction and matching accuracy of RAG systems. Cited sources must accurately display this critical information. Furthermore, when regulations involve multiple linked documents—for example, a certificate of conformity for a consumable batch referencing a specific testing standard SOP—the citation traceability mechanism needs to support cross-document linking and navigation to ensure users can trace the complete regulatory chain.

## Configuration Settings

| Configuration Item | Recommended Value | Rationale for Recommendation |
| :----------------- | :---------------- | :--------------------------- |
| `Chunk size` (Chunk Size) | `500–800 characters` | Media and consumable SOPs are dense. This length maintains contextual completeness while preventing overly long chunks that could affect recall precision. |
| `Chunk Overlap Length` (Chunk Overlap) | `50 characters` | Ensures context continuity and handles critical information spanning paragraphs, such as table headers and content. |
| `Recall count` (Recall Count) | `Top 5` | Regulatory questions require high accuracy. Increasing recall count improves coverage and prevents omission of critical clauses. |
| `Similarity threshold` (Similarity Threshold) | `0.75` | Regulatory clauses are precisely worded. A high threshold helps filter out semantically irrelevant passages, improving citation accuracy. |
| `Rerank result count` (Reranked Return Count) | `3 entries` | Further refines to the 3 most relevant citations, preventing user distraction by excessive information and focusing on core regulations. |
| `Knowledge Base Variables` | Calibrate based on actual measurements | Flexibly configure knowledge base variables according to query needs for specific fields (e.g., batch number, supplier) to enable parameterized retrieval. |

## Three Common Mistakes

*   Reply content includes citation links that are unclickable or point to incorrect locations. This usually results from incorrect knowledge base document path configuration or chaotic document version management.
*   The model's answer cites regulatory clauses not entirely relevant to the question. This might occur if the `Similarity threshold` (Similarity Threshold) is set too low, leading to the recall of overly generalized content.
*   When asked about regulations for a specific batch number or model of culture media, the model provides a general answer instead of precise citations. This typically means the knowledge base has not effectively extracted and indexed critical fields from the document.

## How to Confirm Proper Configuration

*   Test with questions containing specific batch numbers, expiration dates, and other fields. Check if the cited sources in the reply accurately point to specific clauses or table rows in the document.
*   Simulate questions about outdated regulatory clauses. Verify if the system can identify and avoid citing superseded versions, or provide clear version indications.
*   Randomly select 10–20 questions about media formulations or consumable usage specifications. Manually cross-reference the model's cited sources with the correct answers to determine the matching percentage.

The values provided are common starting points and should be measured against the reader's own samples.
