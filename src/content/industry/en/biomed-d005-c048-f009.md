# Reference and Traceability for Home Medical Regulations

## Data Characteristics in this Category

Regulations and Standard Operating Procedures (SOPs) in the home medical sector primarily originate from the National Medical Products Administration (NMPA), provincial and municipal drug regulatory departments, and industry associations. These sources publish standards, guidelines, and regulatory documents. Documents are typically in PDF, Word, or web page formats. Updates are not fixed but occur in concentrated bursts when major policy adjustments or technical specifications are released. Document structures commonly include chapters, clauses, and appendices. Content covers medical device registration, production, distribution, use, and adverse event monitoring. Fields and units frequently include product models, registration numbers, production batch numbers, expiration dates, calibration cycles, and measurement units (e.g., mmHg, mg/L). Strict requirements exist for numerical precision.

## Constraints from these Characteristics on "Reference and Traceability"

The authoritative and rigorous nature of home medical regulatory documents makes accurate and traceable references critical. Diverse data sources (different agencies, various formats) require robust multi-format parsing capabilities for the knowledge base. Unpredictable update frequencies necessitate regular or on-demand incremental updates for key regulations and robust version management. Document hierarchies and emphasis on specific fields and units demand context preservation during knowledge chunking to avoid information loss. Retrieval must precisely point to specific clauses in the original text. Strict numerical precision requirements mean that quoted values in answers must match the original text exactly, without approximation or rounding. These constraints collectively point to the need for fine-tuned configuration of reference granularity, retrieval strategies, and traceability links.

## Configuration Guidelines

| Configuration Item | Recommended Value | Rationale for Recommendation |
| :------------------ | :-------------------- | :------------------------------------------- |
| `Chunk size` (Chunk Size) | `300–500 characters` | Ensures each chunk contains a complete regulatory clause or SOP step, preserving contextual semantics. |
| `Recall count` (Retrieval Count) | `Top 5 entries` | Balances retrieval breadth and computational cost, covering potentially relevant regulations. |
| `Similarity threshold` (Similarity Threshold) | `0.75–0.85` | Avoids low-relevance references, ensuring precision of retrieved content and mitigating "hallucinations." |
| `Rerank result count` (Reranked Return Count) | `Top 3 entries` | Further optimizes results, prioritizing the most relevant regulatory clauses to improve answer quality. |
| `maxContext` | `8000–12000 tokens` | Ensures sufficient capacity for multiple original regulatory texts, providing adequate background information for comprehensive analysis. |
| `Reference Link Format` | `Document Name-Chapter Number-Page Number` | Provides a clear traceability path, allowing users to quickly locate the original source. |

## Three Common Pitfalls

*   Answers contain numerical values or regulations that conflict with the original text. This occurs when context is lost during knowledge base chunking or when retrieved items fail to cover all relevant constraints.
*   AI answers do not provide clear reference links, preventing users from tracing the source. This happens when the `Reference Link Format` is not specified in the knowledge base configuration or when necessary location information is missing from document metadata.
*   The knowledge base content is updated, but AI answers still reference outdated regulations. This occurs when the knowledge base does not perform incremental updates, or when indexing strategies are inadequate, leading to confusion between new and old versions.

## How to Confirm Proper Configuration

*   Select a typical regulatory Q&A scenario. Compare key clauses in the AI's answer with the original text. Check if wording, numerical values, and regulations are precise and accurate.
*   Verify the reference links provided in the AI's answer. Click each link to confirm it accurately navigates to the corresponding chapter or page in the original document.
*   For recently updated regulatory documents, ask relevant questions. Confirm that the AI's answer references the latest version of the content and can identify specific updated clauses.
