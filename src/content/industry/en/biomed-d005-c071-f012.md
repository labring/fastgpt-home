# Model Access and Configuration for Cleanroom Management

## Data Characteristics for This Category

Cleanroom management data primarily originates from internal quality management system documents. These include Standard Operating Procedures (SOPs), cleanroom management regulations, validation reports, environmental monitoring records, and deviation handling records. Documents are typically in PDF, Word, or scanned image formats. Content covers various aspects, such as personnel entry/exit, material management, equipment cleaning, environmental monitoring, and anomaly handling. Document update frequencies vary. SOPs are usually revised annually or when significant changes occur, while environmental monitoring records are generated daily or periodically.

Documents have a strict structure, containing numerous clauses, detailed rules, charts, and appendices. Fields include temperature and humidity, differential pressure, dust particle counts, and microbial limits. Units are explicit (e.g., `℃`, `Pa`, `particles/m³`, `CFU/plate`).

## Constraints Imposed by These Characteristics on "Model Access and Configuration"

The rigor and standardization of cleanroom management documents require models to accurately understand the logical relationships and detailed regulations between clauses during access. Diverse and heterogeneous document formats, especially scanned PDFs and Word documents, demand robust file parsing capabilities. Charts and appendices may contain critical thresholds or operating procedures; models must effectively extract this non-textual information. Inconsistent data update frequencies necessitate flexible indexing strategies to ensure the model answers based on the latest valid regulations. For numerous numerical fields with specialized units, the model must recognize and understand these units to avoid ambiguity or errors in question answering.

## Configuration Settings

| Configuration Item | Recommended Value | Rationale for Recommendation |
| :----------------- | :---------------- | :--------------------------- |
| `Chunk size` (Segment Length) | `800–1200 characters` | Cleanroom SOPs often contain detailed steps and regulations. This length helps maintain contextual completeness and prevents truncation of critical information. |
| `Recall count` (Recall Count) | `Top 5–7 entries` | Regulatory Q&A demands high accuracy and completeness. Recalling more relevant passages helps cover all pertinent clauses. |
| `Similarity threshold` (Similarity Threshold) | `0.75–0.85` | Ensures recalled passages are highly relevant to the query, filtering out semantically imprecise regulatory clauses. |
| `Rerank result count` (Rerank Return Count) | `3 entries` | Reranked models provide more precise answers. 3 entries are sufficient to cover main regulations and avoid information redundancy. |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 seconds` | Parsing can be time-consuming when processing scanned PDFs with many images or complex tables. |
| `embeddingModel` | `text-embedding-ada-002` | This model performs well in processing technical documents and specialized terminology, effectively capturing the semantic features of regulatory texts. |

## Three Common Mistakes

*   Model responses omit critical numerical values or units. For example, a response might mention dust particle counts but not specific limits or units. This typically occurs when file parsing fails to extract numerical fields and their corresponding units effectively from charts or specific formats.
*   Users experience long delays after asking a question, eventually leading to system errors like `HTTP 404 No Body` or `unmarshal_resp`. This might be due to file parsing timeouts, especially when processing large scanned PDFs or Word documents with complex embedded objects, if the `PARSE_FILE_TIMEOUT_SECONDS` parameter is set too low.
*   The model provides outdated answers to questions about changed regulations. This indicates that the knowledge base's indexing update mechanism failed to synchronize the latest version of regulatory documents promptly, or that sufficient model retraining or index rebuilding did not occur after an update.

## How to Confirm Proper Configuration

*   Select a recently updated cleanroom management SOP. Ask questions covering differences between new and old regulations. Check if the model accurately cites the latest clauses.
*   Ask questions about clauses involving numerical values and units (e.g., `differential pressure`, `temperature and humidity`, `microbial limits`). Verify that the model's answers include the correct values and units.
*   Upload a scanned cleanroom management document containing complex tables or flowcharts. Observe if the file upload and parsing process is smooth. Ask questions about key information within the charts to evaluate the model's extraction accuracy.

The values provided are common starting points and should be measured against the reader's own samples.
