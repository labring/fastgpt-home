# Citation and Traceability for Target Discovery Regulations

## Data Characteristics in this Domain

Data sources in target discovery primarily include research reports, journal articles, patent literature, clinical trial data, and bioinformatics databases (e.g., NCBI Gene, UniProt, DrugBank) published by research institutions. These documents are typically in PDF, XML, or HTML format. They are structurally complex, containing extensive specialized terminology, experimental data, charts, and references. Data update frequencies vary; fundamental bioinformatics databases may update weekly or monthly, while research papers and patents continuously increase as they are published. Documents often involve specific fields such as gene names, protein IDs, pathway names, disease codes, as well as activity data (e.g., IC50, EC50) and dosage units (nM, µM, mg/kg).

## Constraints Imposed by These Characteristics on Citation and Traceability

The complexity of target discovery data places high demands on citation and traceability. Documents contain charts and cross-references, so a single text segment may lose contextual information, affecting recall quality. The abundance of specialized terminology and abbreviations requires precise matching to ensure traceability accuracy. Varying update frequencies across different data sources challenge knowledge base content synchronization, requiring assurance that cited regulatory versions are current. Furthermore, the precision of numerical information, such as activity data and dosage units, demands that citations clearly indicate the exact location of the numerical source to avoid ambiguity or error. The low standardization of fields and units increases the difficulty of information extraction and comparison.

## Configuration Settings

| Configuration Item        | Recommended Value         | Rationale                                              |
| :------------------------ | :------------------------ | :----------------------------------------------------- |
| `Chunk size` (Segment Length) | `800–1200 characters`     | Balances complex sentences and context; avoids semantic loss in single sentences. |
| `Overlap Length` | `150 characters`          | Ensures semantic continuity between segments; covers cross-segment references. |
| `Recall count` (Recall Count)   | `Top 10 entries`          | Increases the probability of selecting highly relevant document segments. |
| `Similarity threshold` (Similarity Threshold) | `0.78–0.85`               | Balances recall accuracy and quantity; reduces interference from irrelevant information. |
| `embedding_model`         | `text-embedding-3-large`  | Enhances vector representation precision for specialized terms and concepts. |
| `reference_display_limit` | `5 entries`               | Balances citation completeness and interface conciseness; focuses on core sources. |

## Common Pitfalls

*   **Symptom**: After a user query, the answer only provides citation links without specific content.
    **Reason**: The `Similarity threshold` (Similarity Threshold) is set too high. The system determines that no sufficiently matching document segments are available for a direct answer, only providing relevant documents.
*   **Symptom**: The cited source document is an old version or contains outdated data.
    **Reason**: The knowledge base synchronization mechanism is not configured or executed promptly, failing to update target databases or newly published research papers in time.
*   **Symptom**: The system returns correct citation sources, but clicking them does not navigate to the precise location in the document.
    **Reason**: During document segmentation, page numbers or chapter anchor information for complex formats like PDFs were not stored or parsed, leading to imprecise traceability.

## Verification Steps

*   For typical target discovery queries, check if the answer contains precise information and verify the accuracy of all cited source documents, page numbers, or specific sections.
*   Randomly select recently updated documents from the knowledge base. Query the system to verify if it can cite the latest version of the data and confirm that the update frequency aligns with the actual data source.
*   Simulate user queries specifically including target activity data or dosage units. Check if the system's returned citations precisely point to the original location of the numerical values and verify their correctness.

The values provided are common starting points and should be measured against the reader's own samples.
