# Reference and Traceability for Structured Analysis of Media and Consumables R&D Documents

## Data Characteristics for This Category

R&D document data for media and consumables primarily originates from internal experimental records, supplier technical specifications, product manuals, industry standards, and regulatory documents. Data update frequency is relatively stable, with updates triggered by new product launches or batches, production process adjustments, or regulatory policy changes. Documents come in various forms, including PDF technical manuals, Word experimental reports, Excel batch analysis data, and some scanned images. The degree of structure varies; technical manuals typically have chapter headings, figures, tables, and parameter lists, while experimental records may contain free-text descriptions, images, and hand-drawn diagrams. Key fields include component name, concentration, batch number, production date, expiration date, storage conditions, quality control indicators (e.g., pH, osmolality, endotoxin content, growth performance test results), usage instructions, applicable cell lines, and safety data. Common units include g/L, mg/L, µg/mL, mM, %, pH units, mOsm/kg, EU/mL, CFU/mL.

## Constraints Imposed by These Characteristics on "Reference and Traceability"

The diversity of media and consumables documents requires support for parsing multiple file formats for reference and traceability. It must accurately extract key information from unstructured or semi-structured text. The strong time-sensitivity of fields like batch information and expiration dates demands version management capabilities in the knowledge base to ensure references are to the latest or specific batch data. The large number of parameters and unit variations necessitate robust entity recognition and unit normalization to prevent confusion. Additionally, since some documents may include scanned images or complex diagrams, OCR and image recognition capabilities are crucial for extracting data and annotations from figures and tables. Referencing regulatory documents requires precision down to specific clauses and the ability to link to original regulatory text to meet compliance requirements. Cross-references within documents require the system to identify and build internal linking relationships, enhancing the completeness of traceability.

## Configuration Settings

| Configuration Item         | Recommended Value  | Rationale                                                                |
| :------------------------- | :----------------- | :----------------------------------------------------------------------- |
| `Chunk size`                 | `500-800 characters`     | Media components and experimental procedure descriptions are often long, ensuring semantic completeness. |
| `Recall count`                 | `8-12 entries`          | Needs to cover multiple relevant parameters, batch information, and experimental results. |
| `Similarity threshold`               | `0.75-0.85`        | Ensures precision of recalled content, filtering irrelevant technical details. |
| `Rerank result count`             | `4-6 entries`           | Focuses on the most critical component, performance, or usage method information. |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 seconds`           | Handles parsing time for large technical manuals or documents with many figures. |
| `ENABLE_OCR`               | `True`             | Addresses recognition of parameters and figures in scanned images and pictures. |

## Three Common Mistakes

*   Batch number or expiration date fields are empty in reference results because OCR failed to recognize numbers in scanned images or date formats are inconsistent.
*   Inconsistent unit for media component concentration in AI dialogue is due to a lack of unit normalization or entity recognition errors.
*   The system cannot provide a link to the original document for a specific experimental result because file ID or path information was not preserved in metadata during document upload.

## How to Confirm Correct Configuration

*   Upload a batch of media technical manuals containing scanned images and tables. Check if AI reference results correctly identify and present all key parameters and units.
*   For queries involving batch information, verify if the AI-returned reference sources point to the latest or specified batch documents and confirm the accuracy of batch numbers and expiration dates.
*   Randomly select 10-15 reference results. Verify that each reference can be traced back to the specific paragraph or page in the original document and check if the links are valid.

Note: The values provided are common starting points. Measure against your own samples to determine optimal settings.
