# Citations and Source Traceability for International Student Admissions and Enrollment Records: Compare Documents and Locate Differences

## What this category's data looks like

International student admissions and enrollment management involves three types of materials: admission brochures, admission letters, and visa application forms. Field characteristics center on name spelling and order, passport number, date of birth, admitted major and program duration, reporting and registration dates, and signature and receipt. Admission brochures provide the major catalog and application conditions; admission letters carry the admission decision and reporting date; visa application forms record passport information and signature. Materials are updated by admission batch and semester; brochures change with policy adjustments, admission letters are generated by admission batch, and visa forms are submitted on a case-by-case basis. When these three types of materials enter this feature, they serve as candidate sources respectively: brochures are used to check major names and application conditions, admission letters are used to check admission decisions and dates, and visa forms are used to check identity fields and signatures.

## Configuration and implementation checks

The citation output of the knowledge base retrieval node outputs only an array of cited content, each item containing the original text snippet and source identifier, and the length can be 0. The discrepancy list must be continued by a subsequent AI node, code node, or manual work. The cited content is output as an array, and the length can be 0; even if no content is found, the output chain will still run through.

| Object | Check | Verification action |
| --- | --- | --- |
| Admission brochure | Major name, program duration, and application conditions must be consistent with the admission letter | In the citation array, refer back item by item to the original paragraphs of the brochure, and check the major name and program duration fields |
| Admission letter | Admission decision, reporting date, and signature receipt must be consistent with the visa application form | Open the citation marker to compare against the original admission letter, and check the date and signature fields |
| Visa application form | Name spelling, passport number, and date of birth must be consistent with the admission letter | Use `quoteList` to record discrepancy fields, and check the number of citation items and source identifiers in `responseData` (non-streaming module results returned with detailed output enabled) |
| Cited content array | The number of items is consistent with the matched materials; being empty is also normal | Run a test with a question that matches no materials, and confirm the array is empty while the chain continues |

## Three common errors

- Symptom: The same student's name spelling or date of birth does not match across two materials. Cause: The brochure and admission letter versions were not synchronized, or the admission information was not checked back when entering the visa form.
- Symptom: The admission letter lacks a signature or receipt field. Cause: The receipt template was not attached when the batch was generated, or pages were missing from the scanned copy, making the signature field impossible to check.
- Symptom: The cited snippet does not match the original text. Cause: First check whether this round matched anything and which material was matched, then look at trimming; do not directly attribute it to length trimming.

## How to verify the setup

Feature acceptance: Ask a question with original-text support, and check whether the citation array and citation markers can refer back to the original text; then ask a question that matches no materials, and confirm the array is empty while the chain runs through.

Business test: Use one real record to find fields inconsistent with the ledger

- In the node, check the selected knowledge base collections and their vector models, and confirm that the selected knowledge bases use the same vector model
- Open the search parameter panel and check the values item by item; check the tokens of the cited text with `quoteMaxToken`, and record the number of array items separately
