# Knowledge Base Retrieval for International Student Admissions and Enrollment Records: Compare Documents and Locate Differences

## What this category's data looks like

International student admissions and enrollment management involves three types of materials: international student admission brochures, admission letters, and visa application forms. Admission brochures are published by academic year and contain program names, application requirements, deadlines, and seals; admission letters are generated by admission batch and contain student names, admitted programs, registration dates, and issuer signatures; visa application forms are submitted by visa type and contain name spelling, passport number, entry date, and applicant signature. When these three types of materials enter the knowledge base retrieval and recall function, admission brochures serve as the rule basis, admission letters as individual records, and visa application forms as declaration evidence, each playing a reference role in field comparison and discrepancy localization. The materials update at different paces: brochures by academic year, letters by batch, and forms by individual case. Version synchronization and signature receipt completeness must be checked item by item.

## Configuration and implementation checks

This step is performed by the knowledge base retrieval service (retrieval node and search test), outputting candidate snippets and similarity scores (after mode, merge, rerank, filter, and limit truncation). The discrepancy list is completed by subsequent nodes or manually.

| Object | Check | Verification action |
| --- | --- | --- |
| International student admission brochure | Whether fields, dates, and signatures are consistent with the admission letter | In the search test, switch `searchMode` to semantic, full-text, or hybrid, compare candidate snippets and scores, and check the program name, deadline, and seal in the brochure |
| Admission letter | Whether the student name, admitted program, and registration date are consistent with the visa application form | Compare the ranking of the top candidate results before and after enabling `usingReRank`, and check the name spelling, program name, and issuer signature in the admission letter |
| Visa application form | Whether the name spelling, passport number, and entry date are consistent with the admission letter | Adjust `similarity` to filter low-scoring candidates, and check the name spelling, passport number, entry date, and applicant signature in the visa application form |
| Ledger record | Whether the name, quantity, and date of the same object are consistent across the two materials | Use one real record to retrieve, record the number of candidates and scores, and check whether the ledger fields correspond to the material snippets; the citation limit only checks the cited text tokens, and the array count is recorded separately |

## Three common errors

- Symptom: The name spelling or entry date of the same student does not match between the admission letter and the visa application form. Cause: The two materials are filled in by different steps, and the fields have not been cross-checked.
- Symptom: The program name or deadline version referenced in the admission brochure and the admission letter is not synchronized. Cause: Brochures are updated by academic year, while letters are generated by batch, and the versions are not aligned.
- Symptom: The visa application form lacks the applicant's signature, or the admission letter lacks the issuer's signature and receipt. Cause: The signature and receipt steps have not been included in the material verification checklist.

## How to verify the setup

Acceptance of this feature: Test once each with synonym-rewritten questions, compare candidate snippets and similarity scores; then toggle rerank on and off to observe changes in the ranking of the top results, and check the values of `searchMode`, `similarity`, and `usingReRank` along with the number of candidates.

Business test: Use one real record to find fields inconsistent with the ledger, hand them to the reviewer for confirmation, and write back the discrepancy list.

- In the knowledge base search test, retrieve the same record using field-based questions from the admission brochure, admission letter, and visa application form respectively, record the number of candidates and scores, and mark inconsistent names, quantities, and dates.
- After checking signature and receipt completeness, hand the discrepancy list to the reviewer for confirmation and write it back to the ledger; the citation limit only checks the cited text tokens, and the array count is recorded separately.
