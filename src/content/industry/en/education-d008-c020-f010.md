# Citations and Source Traceability for Grade Entry and Credit Recognition: Manage Authorized Access and External Services

## What this category's data looks like

This page centers on the grade entry and credit recognition scenario, bringing three types of materials—transcripts, deferred examination applications, and make-up examination arrangements—into the authorized access and external services chain. A transcript carries the course name, credits, grade, instructor signature, and course start date; a deferred examination application carries the application reason, original examination date, approver signature, and receipt; a make-up examination arrangement carries the make-up course, make-up time, examination room, and invigilator signature. After these three types of materials enter the knowledge base retrieval node, each participates in citation output as an independent source, the cited snippets point back to the corresponding original paragraphs, and the source identifier distinguishes the material type and version. The material update rhythm follows the academic affairs cycle: transcripts are synchronized after grades are released, deferred examination applications are archived after approval is completed, and make-up examination arrangements are published before the examination. In terms of field characteristics, the course name, credit count, and date of the same record in the transcript and the make-up examination arrangement must be consistent, and the version number and signature receipt determine whether the material can be exposed externally. The external entry points and authorization scope are generated by subsequent nodes or manually by comparing against the citation array; access is opened when the visitor's identity matches the visible scope, and unauthorized access is not visible.

## Configuration and implementation checks

This link is executed by the citation output of the knowledge base retrieval node, which outputs an array of cited content, each entry containing an original snippet and a source identifier, and the length may be 0. The externally exposable entry points and authorization scope are then completed by subsequent AI nodes, code nodes, or manually. The citation array only carries original snippets and source identifiers, and does not assume the responsibility of generating difference lists, ledgers, reports, or authorization scopes.

| Object | Check | Verification action |
| --- | --- | --- |
| Transcript | The course name, credit count, grade, instructor signature, and course start date must be item-by-item consistent with the same record in the make-up examination arrangement and the deferred examination application | Open the citation marker to compare against the source document, and verify the fields and dates; record the number of citations by the array length, and check the tokens of the cited text separately against `quoteMaxToken` |
| Deferred examination application | The application reason, original examination date, approver signature, and receipt are complete, and match the course name and date in the transcript | Expand the cited snippet in the conversation and point back to the original paragraph; use `quoteList` to view the node output and confirm that the source identifier points to that material version |
| Make-up examination arrangement | The make-up course, make-up time, examination room, and invigilator signature are consistent with the name, count, and date of the same record in the transcript and the deferred examination application, and the version has been synchronized | Run a trial with a question that has no matching material, and see that the citation array in `responseData` (non-streaming module results returned with detailed output enabled) is empty while the chain still runs through |
| External entry points and authorization scope | The visitor's identity matches the visible scope, and unauthorized access is not visible | Access once with a restricted identity, and see whether the visible scope matches the setting |

## Three common errors

- Symptom: The name, credit count, and date of the same course do not match between the transcript and the make-up examination arrangement. Cause: The two materials are entered separately, without field comparison and version synchronization.
- Symptom: The deferred examination application lacks the approver signature or receipt, yet the material still enters external services. Cause: The archiving step does not verify the completeness of the signature and receipt, and the version is not synchronized.
- Symptom: There is no citation marker in the answer, or the cited snippet does not match the original text. Cause: First check whether this round hit anything and which material was hit, then look at length truncation, and do not directly attribute it to truncation.

## How to verify the setup

Acceptance of this feature: ask a question with original-text support, and check whether the citation array and markers can point back to the original text; record the number of citations by the array length, and check the tokens of the cited text separately against `quoteMaxToken`, without doing an equality comparison; then ask a question with no matching material, and confirm that the array is empty while the chain runs through.

Business test: access once with a restricted identity, and see whether the visible scope matches the setting.

- In the node, check whether the selected knowledge base collections and their vector models are consistent, and open the search parameter panel to verify the values item by item.
- Run a trial with a question that has no matching material, and see that the citation array in `responseData` is empty while the output chain continues, and expand `quoteList` to compare against the source document.
