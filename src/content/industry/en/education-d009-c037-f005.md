# Multi-Turn Conversation and Prompts for Vocational Training Subsidy Applications: Handle Multilingual Materials and Terminology

## What this category's data looks like

Vocational training subsidy application materials include three types: training class filing records, attendance records, and completion assessment forms. Fields cover trainee name, ID number, course name, class start date, completion date, assessment result, and signature field. Materials come from training institution declarations, human resources and social security department reviews, and public announcement stages, updated by batch, with one version produced for each class start and completion. During multilingual materials and terminology handling, the class filing records serve as the terminology source for course and institution names, the attendance records provide the correspondence between personnel names and dates, and the completion assessment forms output the translated names of assessment conclusions and signature receipts. After the three materials enter the multi-turn dialogue and prompts feature, each serves as input for terminology extraction and consistency checking, and the terminology glossary and comparison draft are generated by the model during the dialogue.

## Configuration and implementation checks

This part is executed by the memory turns and prompt configuration in the application settings, outputting the reference range of historical messages and answer constraints. The unified terminology glossary and comparison draft are then completed by the model. Memory turns control how many previous dialogue turns can be referenced at most when answering; too small a value fails to use prior context, while too large a value brings in irrelevant content and increases consumption.

| Object | Check | Verification action |
| --- | --- | --- |
| Training class filing records | Course name, institution name, class start date, and signature field are written consistently across the three materials | Take the course name and date from the filing records, check item by item against the attendance records and completion assessment forms, and check whether signatures or receipts are complete |
| Attendance records | Trainee name, ID number, and attendance date match the filing roster | Compare with the filing roster by class start date and trainee number, check the quantity and dates, and confirm there are no missing signatures |
| Completion assessment forms | Assessment conclusion, completion date, and institution seal are in sync with the filing version | Check the assessment form version number against the filing version, and check whether the name, quantity, and date of the same record are consistent |
| Multi-turn dialogue and prompts | The second-round follow-up can correctly carry forward the reference from the first round | Run a trial with two consecutive rounds of questions, check the memory turns value in the application settings, and check the reference scope of `chatId`, `messages`, and `variables` in the session |

## Three common errors

- Symptom: The same trainee name is written differently in the attendance records and the completion assessment forms. Cause: The terminology glossary is not unified, the two materials are entered separately, and the translated name cannot refer back to the source text.
- Symptom: The dates in the class filing records and the completion assessment forms do not match. Cause: The versions are not in sync, the later material version was not updated along with the filing records, and signatures or receipts are missing.
- Symptom: When a reference is used in the second question, the answer does not address the question. Cause: The memory turns value is too small, the prior context range is insufficient, and `messages` does not cover the reference object from the first round.

## How to verify the setup

Feature acceptance: Ask two consecutive follow-up questions and see whether the second question carries forward the reference from the first question; check the memory turns value in the application settings, and check the reference scope of `chatId`, `messages`, and `variables`.

Business testing: Sample three terms and check whether their writing is consistent throughout the document, check whether the translated names can refer back to the source text, and confirm that the names, quantities, dates, and signatures or receipts of the training class filing records, attendance records, and completion assessment forms are complete.

- Check the current memory turns value in the application settings, run a trial with two consecutive rounds of questions, and compare the usage records of the two runs.
- Sample three terms and check item by item whether the names, quantities, dates, and signatures or receipts in the training class filing records, attendance records, and completion assessment forms are consistent.
