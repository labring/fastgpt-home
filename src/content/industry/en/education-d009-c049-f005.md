# Multi-Turn Conversation and Prompts for International Student Admissions and Enrollment Records: Handle Multilingual Materials and Terminology

## What this category's data looks like

This page addresses the scenario of international student admissions and enrollment management. The core materials include international student admission brochures, admission letters, visa application forms, along with a supporting unified terminology glossary and a comparison draft. Admission brochure fields include program name, duration of study, application deadline, and signature field; admission letter fields include name, admission number, registration date, and issuer signature; visa application form fields include passport name, date of birth, application number, applicant signature, and receipt. The material sources are the admissions office and academic affairs department, and the update cadence follows admission batches and enrollment changes. When entering the multi-turn dialogue and prompts feature, the admission brochure serves as the terminology source, the admission letter and visa application form serve as the comparison and anaphora roles, and the unified terminology glossary and comparison draft are generated by the model based on the historical message scope and answer constraints. Before external release, it is necessary to verify that the same term is written consistently throughout the entire document and that the translated name can refer back to the original text.

## Configuration and implementation checks

This step is executed by the memory turns and prompt configuration in the application settings, outputting the referenced historical message scope and answer constraints. The unified terminology glossary and comparison draft are then completed by the model, and the external entry point and authorization are handled by the publishing service and file permissions. The memory turns control how many previous dialogue turns can be referenced at most when answering. If the value is too small, the previous context cannot be used; if the value is too large, irrelevant content is brought in and consumption increases.

| Object | Check | Verification action |
| --- | --- | --- |
| International student admission brochure | Whether the fields, dates, and signatures are consistent with the admission letter | Check the memory turns value in the application settings, run a trial with two consecutive questions, and check whether the previous context references in `messages` are correctly carried forward |
| Admission letter | Whether the name, quantity, and date of the same record match across the admission brochure and the visa application form | Compare the admission number and registration date in the two materials, confirm that the versions are synchronized and the signature field is complete, and record the session corresponding to `chatId` |
| Visa application form | Whether the applicant signature and receipt are complete, and whether the application number can refer back to the admission letter | Extract three terms and check whether their writing is consistent throughout the entire document, and verify whether the field mapping in `variables` is consistent with the comparison draft |
| Unified terminology glossary and comparison draft | The same term is consistent throughout the entire document, and the translated name can refer back to the original text | Extract three terms and check whether their writing is consistent throughout the entire document, and confirm that there are no missing signatures or receipts before external release |

## Three common errors

- Phenomenon: The name, quantity, and date of the same record do not match between the admission brochure and the admission letter. Cause: The versions of the two materials are not synchronized, and the terminology glossary has not been updated uniformly.
- Phenomenon: The visa application form is missing a signature or receipt. Cause: The signature field and receipt field were not checked before release, and there was an omission in the material circulation process.
- Phenomenon: The second question answers off-topic when using anaphora. Cause: The memory turns value is too small to use the previous context, or the opening message is treated as previous context and brought in.

## How to verify the setup

Acceptance of this feature: Ask two consecutive follow-up questions, see whether the second question carries forward the anaphora from the first question, and check whether the historical message scope and answer constraints in `messages` match.

Business test: Extract three terms and check whether their writing is consistent throughout the entire document, confirm that the translated name can refer back to the original text, and that the fields, dates, and signatures of the admission brochure, admission letter, and visa application form match.

- Check the current memory turns value in the application settings and match it with the previous context scope required by the question.
- Compare the usage records of two runs to confirm that the run consumption changes accordingly after adjusting the number of turns.
