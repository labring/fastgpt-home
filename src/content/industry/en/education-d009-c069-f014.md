# Model Integration and Configuration for Journal Publication Licensing and Annual Verification: Handle Multilingual Materials and Terminology

## What this category's data looks like

This page addresses the scenario of journal publication licenses and annual verification. Materials include journal publication licenses, annual verification forms, rectification reports, and the multilingual materials and terminology comparison drafts formed around these materials. Licenses and verification forms are updated annually, and rectification reports are submitted along with rectification matters; field characteristics center on names, quantities, dates, signatures, and receipts. When materials enter the model access and configuration stage, licenses and verification forms serve as the source documents for terminology extraction and comparison, rectification reports serve as supplementary context, and the unified terminology glossary and comparison draft are generated by the model bound to the dialogue and retrieval use, for checking before external release.

## Configuration and implementation checks

This step is executed by the server-side model channel configuration, outputting model binding relationships and channel responses. The unified terminology glossary and comparison draft are then completed by subsequent AI nodes, code nodes, or manual work. Models are divided into five categories: language, indexing, reranking, speech synthesis, and speech recognition. Different stages bind different model types, and during configuration they are labeled according to the corresponding type for the stage.

| Object | Check | Verification action |
| --- | --- | --- |
| Journal publication license | Names, quantities, dates, and signatures must be consistent with the annual verification form | Compare the names, quantities, dates, and signature fields in the license and verification form, checking item by item |
| Annual verification form | The names, quantities, and dates of the same record in the two materials must match | Extract three terms, check whether the writing is consistent throughout the document, and refer back to the corresponding fields in the source text |
| Rectification report | The version must be synchronized with the license and verification form, and receipts and signatures must be complete | Check the rectification report version number, receipts, and signatures, and confirm synchronization with the license and verification form |
| Model configuration | The model type corresponds to the stage to be used, and the model identifier matches the name listed in the documentation | In the model configuration, check the type labels, compare against the model names returned by the channel, and check `maxContext`, `maxTokens`, `quoteMaxToken`, `toolChoice` |

## Three common errors

- Symptom: The names, quantities, and dates of the same record in the license and verification form do not match. Cause: The two materials were entered separately without cross-checking.
- Symptom: The rectification report version is not synchronized and still references old-version license fields. Cause: After the version update, the comparison draft and terminology glossary were not written back.
- Symptom: The verification form lacks signatures or receipts, yet the terminology comparison draft is still used. Cause: Material completeness checks were not included as a precondition for terminology processing.

## How to verify the setup

This feature acceptance: run one dialogue and one retrieval, check the model identifier in the response, and confirm that `maxContext`, `maxTokens`, `quoteMaxToken`, `toolChoice` take effect as configured.

Business test: extract three terms and check whether the writing is consistent throughout the document

- In the model configuration, check that the model type labels correspond to the stage to be used, and compare against the model names returned by the channel
- Extract three terms, check whether the writing is consistent throughout the document, and refer back to the source text in the license, verification form, and rectification report
