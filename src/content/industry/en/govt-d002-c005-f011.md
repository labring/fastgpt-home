# Property Rights, Asset and State-owned Capital Management: Service Inquiry and Reply - Forms and Interactions

## What data looks like for this category
Data sources for this category include state-owned assets supervision information systems, enterprise asset management systems, property rights exchange systems, appraisal firm reports, and financial statements. The update frequency is monthly. Daily documents cover property registration forms, asset appraisal reports, property rights transfer plans, on-site transaction announcements, and asset disposal approval forms. Fields include asset ownership information, appraisal parameters, transaction subject information, approval circulation nodes, and more. No additional statistical values or fabricated information is added.

## What constraints these characteristics impose on the forms and interactions link
Scattered data sources and monthly updates require form interactions to support variable references linked to multiple system data sources, eliminating manual entry errors. Complex daily document field structures demand forms configured in groups by business processes to lower entry barriers. Strict verification requirements for asset ownership and transaction information mean forms must add pre-verification steps to block submissions that violate business rules. Severe potential error consequences require the interaction link to include a submission preview function, ensuring information accuracy before circulation.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` component | Group by business processes, maximum 8 fields per group, maximum 8000 characters per field input | Daily document field structures are complex, grouping reduces entry complexity and matches the character length requirements of structured documents |
| `userSelect` component | Preset three types of options: state-owned assets supervision institutions, property rights exchange institutions, appraisal institutions, support custom supplementary entries | Typical business entities include these three types of institutions, preset options reduce manual entry errors |
| Data source synchronization cycle | 30 days | Data update frequency is monthly, matches the update rhythm of business data |
| Field verification rules | Enable required field verification and format matching verification | Asset information verification requirements are strict, pre-interception reduces error risks |
| Pre-submission preview | Enable full content preview | Ensure accurate transaction and ownership information, adapts to the strict requirements of state-owned asset disposal |
| Batch import verification | Enable field consistency verification, maximum single import file size is 1000 MB | Daily documents are mostly batch-submitted structured files, verification and size limits reduce manual verification workload |

## Three common misconfigurations
- Phenomenon: Core field null values appear after `formInput` component submission. Cause: Required field verification is not configured, users omit filling key information such as asset ownership number.
- Phenomenon: Options returned by the `userSelect` component do not cover typical business entities. Cause: Preset options do not include categories such as state-owned assets supervision institutions and property rights exchange institutions, leading users to enter incorrect formats manually.
- Phenomenon: The knowledge base search module fails to match corresponding entries when referencing asset data. Cause: Data source synchronization cycle is not configured, and system data older than 30 days is used.
