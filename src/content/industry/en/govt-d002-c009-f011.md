# Public Data Catalog and Open Government Service Consultation and Response: Forms and Interactions

## What Data in This Category Looks Like
This category of data covers documents including public data resource catalogs, data open lists, data item descriptions, desensitization rules, interface documentation, and update frequency descriptions. Data sources include local public data open platforms, integrated big data platforms, departmental business databases, and electronic certificate repositories. Data is updated monthly. Core fields include data item name, open scope, desensitization requirements, interface address, and update cycle. All content is in structured or semi-structured format, and authorization boundaries and usage conditions must be clearly marked. FastGPT v4.17.0 supports connecting to this type of data source.

## What Constraints Do These Characteristics Impose on Forms and Interactions
The monthly update frequency requires the form to support regular synchronization of data catalog changes, to avoid displaying outdated data items during interactions and prevent inconsistencies between the catalog and actual data. Data from multiple sources must be categorized by their affiliated department and open platform in the form to avoid confusion. Structured fields require form inputs to match fixed formats: for example, interface addresses must be validated for URL format, and desensitization rules must have preset options to avoid invalid inputs that could lead to data leakage risks. The authorization boundaries of data items must clearly prompt users of required usage compliance during interactions to avoid unauthorized calls.

## How to Configure Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `formInput` | Bind input boxes linked to public data catalog fields, limit input length to 200 characters | Most field lengths in data item description documents are under 150 characters, with a reasonable buffer added |
| `userSelect` | Preset two types of options: department and open platform, support multi-selection | Data sources include multiple departments and platforms, so data attribution must be clearly identified |
| Form validation toggle | Enable, validate URL format and legality of desensitization rule options | Interface documentation and desensitization rules follow fixed formats, so invalid inputs must be avoided |
| Data synchronization cycle | 30 days | Data in this category is updated monthly, so the synchronization cycle matches the update frequency |
| Interaction prompt text | Include data usage authorization requirements and update cycle descriptions | Users must be clearly informed of data open conditions and timeliness |
| Timeout setting | 60 seconds | Sufficient response time must be reserved for interface calls to avoid frequent timeouts |

## Three Common Misconfigurations
- The `formInput` component configured in the workflow does not appear in the conversation interface, and the interaction content is empty. The cause is that the conversation rendering toggle for the form is not enabled, or the bound field is not correctly linked to the public data catalog data source.
- Users do not receive connection notifications after submitting a business consultation form. The cause is that the callback trigger logic after form submission is not configured, or callback parameters do not correctly match enterprise WeChat message push rules.
- Desensitization rule options entered in the form do not display as preset, or the options do not match the actual data open list. The cause is that data catalog updates have not been synchronized regularly, or preset options do not cover the latest open rules.

## How to Confirm the Configuration Is Complete
- Open the test conversation interface, enter queries related to the public data catalog, and confirm that the form component loads normally and displays preset fields.
- Submit a test form, check whether the corresponding callback or synchronization logic is triggered, and verify that the data source synchronization cycle executes as set.
- Enter content that does not meet the format requirements, confirm that the form triggers validation prompts, and verify that the validation rules take effect.
- Adjust the synchronization cycle parameter, check whether the displayed content of the data catalog updates according to the new cycle, and verify that the configuration takes effect.
