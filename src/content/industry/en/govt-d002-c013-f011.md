# Forms and Interactions for Administrative Consultation and Response on Internal Control Evaluation, Audit and Rectification

## What data looks like for this category
Data sources for this category include enterprise internal control systems, ERP systems, financial shared service systems, audit management systems, and procurement contract project systems. Update frequency is annual. Daily generated documents include internal control self-evaluation reports, audit notices, audit working papers, issue lists, rectification ledgers, and rectification closing certificates. Document structure varies by audit project type. Core fields include issue number, rectification responsible person, completion deadline, and supporting material links. No unified fixed unit format exists. Multi-source heterogeneous data requires field mapping and integration adaptations.

## Constraints on forms and interactions from these characteristics
Multi-source heterogeneous data sources require forms to support bulk import and field mapping from multiple systems. This reduces repetitive manual entry work.
Annual update frequency eliminates the need for high-frequency real-time data synchronization. Forms must support retrospective query of historical audit data.
Differences in document structure require forms to have flexible field custom rules. These rules adapt to document formats of different audit projects.
Uniqueness of core fields requires mandatory field verification in the interaction link. This prevents missing information in key documents such as rectification ledgers.
Error consequences involve regulatory notifications and accountability. Forms must add data preview and secondary confirmation steps. These steps reduce the risk of human error.

## Configuration Settings

| Configuration Item | Suggested Setting | Rationale |
| --- | --- | --- |
| Form upload file size limit | 1000 MB | Adapt to the common size of single documents such as rectification ledgers and audit working papers |
| `formInput` validation rules | Include mandatory field validation and format validation | Match the fixed field requirements of issue lists and rectification ledgers |
| `userSelect` scope restriction | Group selectable by department role | Adapt to different permission requirements of internal control departments, audit departments, and subordinate enterprises |
| Maximum number of entries per submission | Top 200 entries | Match the single-processing scale of extracted business samples |
| Submission timeout threshold | 600 seconds | Adapt to the time required for pulling data from multiple systems |
| Form input character limit | 800–1200 characters | Adapt to the common length of audit issue descriptions |

## Three Common Misconfigurations
- Phenomenon: Text input in the `formInput` area lags when there are many workflow nodes. Cause: The number of simultaneously loaded node renderings in the form is not restricted. Overlapping associated requests from multiple system data sources lead to excessive page resource usage.
- Phenomenon: The `userSelect` reference variable list is empty when dynamically specifying a knowledge base. Cause: The associated variable for the corresponding knowledge base is not configured in global variables in advance. Or the variable is not bound to the current workflow node.
- Phenomenon: The code running option cannot be found in the tool call node. No connection configuration area exists. Cause: The code running tool permission is not enabled in system settings. Or the tool menu configuration of the current deployment version has not been synchronized and updated.

## How to Confirm Proper Configuration
- Upload a single audit working paper under 1000 MB. Confirm that the form upload verification passes and no error prompts appear.
- Enter the mandatory field content of the issue list in the `formInput` area. Confirm that the compliance prompt returns normally after triggering validation.
- Configure the department role grouping for `userSelect`. Try selecting users of the corresponding role. Confirm that the optional list loads correctly.
- Submit a form containing no more than 200 business samples. Confirm that the submission request completes within 600 seconds with no timeout errors.

The values provided are common starting points and should be measured against the reader's own samples.
