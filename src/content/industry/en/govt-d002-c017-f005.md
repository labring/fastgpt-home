# Service Consultation and Response for Medical Institution Supervision and Public Health Inspection: Tool Calling and Plugins

## What this category's data looks like
This category of data mainly comes from the health supervision information system, medical institution electronic registration system, complaint and reporting platform, and law enforcement inspection records, with a monthly update frequency. Daily processed documents include supervision inspection forms, medical institution practice licenses, rectification notices, supervision opinions, and penalty case files. Fields for a single document cover institution name, license scope, law enforcement personnel information, rectification requirements, penalty basis, and more. There is no unified fixed unit, and some fields require matching against institution registration information for verification.

## What constraints these characteristics impose on the tool calling and plugins workflow
Data sources are scattered and updated monthly. Tool calling must interface with multiple systems and adapt to parsing of different document formats. Daily documents fall into two categories: qualification-related and law enforcement-related. Tools must support structured field extraction and unstructured text parsing. Law enforcement inspection records and penalty case files are frequently used compliance data, so call accuracy must be ensured to avoid missing key qualification information. Monthly updated data must be regularly synchronized to the tool calling data source to prevent expired information from being used to generate responses. The service consultation and response scenario requires fast response times, so tool calling response durations must meet the waiting requirements of government service scenarios.

## How to set configurations
The following configurations are formulated for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | Adapts to dynamic tool calling needs in service consultation scenarios, automatically determines whether tool calling is required |
| `functionCall` | Enabled | Forces the model to follow tool calling specifications, preventing direct response generation without calling tools |
| Plugin timeout setting | `600 seconds` | Most data sources for this category are government systems, and interface responses may have delays. 600 seconds covers most synchronous calling scenarios |
| Knowledge base recall limit | Top 8 entries | Daily documents have many fields. Excessive recall will exceed context limits. The top 8 entries cover most qualification and law enforcement information |
| Document chunk length | `800–1200 characters` | Documents such as supervision inspection forms and penalty case files have complex structures. This chunk length retains complete field information and avoids field breakage caused by splitting |
| Question optimization | Enabled | User questions in service consultations may be vaguely phrased. Optimization enables more accurate matching of tool and knowledge base content |

## Three common mistakes
- Phenomenon: Tool selection fails during tool calling, and the model directly generates responses without using tool calling. Cause: The `functionCall` configuration is not enabled, so the model is not forced to follow tool calling specifications.
- Phenomenon: The <Reference> field returned by knowledge base chat is empty. Cause: The correct data source recall limit is not configured, or monthly data from the health supervision information system has not been synchronized and updated.
- Phenomenon: The Doc2x plugin processes uploaded corpus without valid output. Cause: The corpus is not specified as the document type for this category, or the document format and field structure are not adapted.

## How to confirm the configuration is complete
- Submit a consultation about medical institution practice qualifications, and check whether the model actively calls tools to retrieve information from the corresponding system.
- Check the tool calling log to confirm that the `toolChoice` parameter is `auto` and `functionCall` is enabled.
- Upload a supervision inspection form to the plugin, and verify that the plugin correctly extracts fields such as institution name and license scope.
- Wait 1 minute, then submit the same consultation again, and confirm that the monthly updated knowledge base data has been synchronized to the tool calling data source.
