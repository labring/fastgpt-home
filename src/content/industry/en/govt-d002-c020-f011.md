# Land Spatial Planning Compilation and Implementation Evaluation: Service Consultation and Reply - Forms and Interactions

## What This Category of Data Looks Like
Data for this category is primarily sourced from the national land spatial basic information platform, natural resource survey and monitoring data, population and economic statistics datasets, and publicly available remote sensing imagery. Routinely produced documents include national land spatial overall planning texts, detailed planning texts, special planning texts, planning implementation evaluation reports, and public opinion summary materials. The data update cycle is typically one year. Most document structures contain spatial coordinate fields, constraint indicator items, and regional scope descriptions. Field units mostly adopt industry-standard metrics such as hectares, square kilometers, and population counts.

## Constraints on Forms and Interactions
Multi-source heterogeneous spatial and statistical data requires forms to support mixed format input, and must be compatible with structured tables, spatial vector files, and unstructured text uploads. The annual update feature means forms do not need high-frequency refreshing, but must retain a historical version archive entry to allow planning staff to review input data from different cycles. Documents contain large amounts of spatial coordinates, constraint indicators, and regional scope descriptions. The interaction link must include built-in format verification logic to restrict input of non-compliant fields and prevent invalid data from entering subsequent processing workflows. Public opinion summary materials are mostly unstructured text, so forms must support batch upload and segment parsing, while adapting to text format differences from different sources. Regional-level planning data has a large volume, so the interaction link must limit the total file size for a single upload to avoid loading timeouts.

## Three Common Misconfigurations
- Phenomenon: Uploaded spatial vector files or public opinion text are not included in the large model's statistical summary scope. Cause: The associated trigger rules for `formInput` were not configured correctly, resulting in uploaded files not being bound to the current conversation context.
- Phenomenon: Uploaded JSON-format planning indicator files are truncated and cannot fully participate in analysis. Cause: The corresponding input character limit was not adjusted, and the default threshold is lower than the actual volume of a single JSON file for this category.
- Phenomenon: After adjusting the browser zoom level, input content and upload buttons in the form area disappear. Cause: Responsive layout adaptation for the form was not enabled, and interactive element anchoring configuration was not done for zoom scenarios.

## How to Verify Correct Configuration
- Upload a typical public opinion summary text, check if the conversation window displays the loaded file content.
- Upload a CSV file containing spatial coordinates, verify if the interface pops up a format compliance prompt.
- Adjust the browser zoom level, confirm that input boxes and upload buttons in the form area do not have content loss.
- Input a long piece of planning consultation text, check if the interface pops up an input over-limit prompt.
