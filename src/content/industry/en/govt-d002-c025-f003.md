# Work Consultation and Reply for Safety Production Hazard Inspection and Governance: Multi-turn Dialogue and Prompt Words

## What the data for this category looks like
Data for this category comes from safety production supervision systems, enterprise self-inspection systems for hazards, law enforcement inspection records, and accident statistics systems. The update frequency is daily.
Commonly used documents include hazard inspection checklists, hazard management ledgers, rectification notices, review records, and major hazard suspension and supervision orders.
Data fields include hazard ID, inspection time, responsible entity, rectification deadline, rectification status, and more. Units include days (for rectification deadlines) and items (for number of hazard entries), among others. Field structures vary across different document types. Some documents require associated data from cross-systems.

## Constraints Imposed on Multi-turn Dialogue and Prompt Words by These Characteristics
Data sources are scattered and involve multiple cross-system associations. This requires multi-turn dialogue to first clarify the specific system, affiliated unit, and time range of the user's query, to avoid returning irrelevant data.
The update frequency is daily. Prompt words must guide users to prioritize the latest inspection and rectification records to ensure the timeliness of query results.
There are multiple document types with large differences in field structures. Multi-turn interaction must gradually guide users to clarify the document type being queried, to avoid confusion between the query logic of inspection checklists and rectification ledgers.
Fields include clear time and responsible entity requirements. Prompt words must pre-set necessary parameter fields to reduce the number of information items users need to provide.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Maximum Context | Previous 8 turns of dialogue + current query | Based on the need to trace historical information such as inspection time and responsible entity for hazard inspection data, to avoid repeated questions |
| `variables` | Pre-set standard fields for hazard inspection checklists, rectification ledgers, and rectification notices | Based on fixed document fields for this category, pre-binding variables reduces the number of information acquisition steps in multi-turn interaction |
| `messages` | Gradually supplement hazard-related parameters based on user queries | Based on scattered data sources, multiple rounds are needed to obtain specific information such as system, unit, and time range |
| Single Match Record Limit | Top 3 entries | Based on the large number of hazard data entries, prioritize returning the latest or high-priority inspection and rectification records |
| Timeout Duration | 600 seconds | Based on cross-system queries involved in the hazard inspection process, which take a long time, to avoid early termination of dialogue |
| Query Optimization | Calibrated based on actual testing | Based on differences in question styles across different users, adaptation to professional terminology in the safety production field is required |

## Three Common Misconfigurations
- Dialogue returns 401 No auth credentials found. The cause is that access credentials for the safety production supervision system or enterprise self-inspection system are not bound in the configuration, leading to permission verification failure when calling external data during multi-turn dialogue.
- Multi-turn dialogue cannot obtain complete rectification deadline parameters for hazards. The cause is that the rectification deadline field is not pre-set in `variables`, causing the prompt words to fail to guide users to supplement the necessary query parameters.
- No text conversion result after voice input. The cause is that the voice-to-text trigger logic is not configured correctly, leading to the voice-to-text link not connecting properly during the multi-turn dialogue chain, and failing to convert voice content into processable text.
