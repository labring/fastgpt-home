# Construction Project Environmental Impact Assessment (EIA) Approval: Service Consultation and Reply - Deployment and Upgrade

## What Data for This Category Looks Like
Data for this category originates from the national unified construction project EIA declaration and approval system, ecological environment zoning control results, pollution discharge permit platform, and monitoring data. Update frequency is irregular. Daily processed documents include environmental impact assessment reports or report forms, approval applications, public participation explanations, technical evaluation opinions, and EIA approval documents. Document structures contain core fields such as basic project information, category level, pollution prevention measures, and public participation feedback. Field complexity and volume vary widely across different documents. Some report documents can reach hundreds of megabytes in size.

## What Constraints These Characteristics Impose on Deployment and Upgrade
Multi-source, irregularly updated data sources require flexible support for accessing data sources from different systems during deployment. Upgrade processes must ensure data synchronization is not interrupted. Differences in document structure and volume require configuring parsing and storage capabilities adapted to multiple document formats, to avoid upload failures for large files. The high-risk nature of core business links requires deployed services to have high availability. Upgrade processes must reserve rollback plans to prevent disruption to approval workflows. Concurrent requests fluctuate with project declaration peaks, so sufficient resources must be configured to support peak traffic.

## How to Configure Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Key | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30` | EIA approval business has peak declaration periods. This connection count supports concurrent document retrieval and storage requests, and avoids exceeding database connection limits. |
| `MONGODB_URI` | `mongodb://username:password@host:port/epi_approval?authSource=admin` | Used to store unstructured documents such as EIA reports and public participation explanations. Dedicated MongoDB instances ensure read/write performance and data security. |
| `REDIS_URL` | `redis://:your_redis_password@redis-host:6379/0` | Caches frequently queried project classification and ecological environment zoning control data, reducing repeated request pressure on backend databases. |
| `FE_DOMAIN` | `https://epi-approval.your-government-domain.gov.cn` | Binds the compliant domain name for official service consultation, ensuring user access paths meet government service requirements. |
| `STORAGE_S3_ENDPOINT` | `https://s3-cn-beijing.aliyuncs.com` | Used to store large-volume EIA reports and approval documents, adapting to government cloud compliant storage service standards. |

## Three Common Misconfigurations
- Symptom: Unable to access the FastGPT service normally via an intranet penetration address. The frontend returns a 403 or 404 status code. Cause: The penetrated public network domain name is not bound in the `FE_DOMAIN` configuration. The service intercepts access from non-configured domains when verifying request sources.
- Symptom: Database connection errors occur after upgrade. The log prompts "too many connections". Cause: The `DB_MAX_LINK` parameter is not adjusted, and the default low connection count configuration is retained. This cannot support concurrent requests for EIA approval business.
- Symptom: Retrieval results do not include the latest ecological environment zoning control data. Cause: No scheduled synchronization task is configured to pull irregularly updated data sources. Cached old data is not refreshed in a timely manner.

## How to Verify Configurations Are Correct
- Access the FastGPT backend system monitoring page, check the database connection count, and confirm that the current connection count does not reach the upper limit set by the `DB_MAX_LINK` configuration.
- Upload a standard EIA report form document, test the parsing and retrieval functions, and confirm that core fields such as project category and pollution prevention measures can be extracted normally.
- Access the configured `FE_DOMAIN` domain name, verify that the frontend page loads normally, and that there are no cross-domain or resource loading failure prompts.
- Trigger an upload operation for a large-volume EIA report document, confirm that the storage service configured via `STORAGE_S3_ENDPOINT` can receive and store files normally.
