# Government Procurement Project Inquiry and Reply: Workflow Orchestration

## What data for this category looks like
Data sources for government procurement project inquiry and reply include the China Government Procurement Network, local government procurement networks, fiscal integration systems, procurer budget systems, and supplier credit records. Data is updated daily. Daily processed documents include procurement requirements, procurement plans, bidding documents, tender documents, bid evaluation reports, winning bid announcements, procurement contracts, response to inquiries, and more. Each document type has fixed fields such as procurement project number, supplier unified social credit code, and winning bid amount. The data structure strictly follows government procurement public disclosure specifications, and only content compliant with regulatory requirements is disclosed. This configuration guide is based on FastGPT v4.17.0.

## What constraints do these characteristics impose on the "workflow orchestration" link
Multi-source data access requires splitting the workflow into separate data source nodes to avoid cross-system data confusion. The daily update frequency requires configuring scheduled synchronization nodes to ensure the latest publicly available data is retrieved for inquiries. Differences across document types require dedicated processing branches for each document type. For example, validation logic differs between winning bid announcements and response to inquiries. Strict regulatory requirements mean the workflow must add compliance validation steps to prevent disclosure of non-public information or triggering regulatory penalties. The high-stakes nature of process errors also requires configuring exception alerts and manual intervention nodes to enable timely intervention when a failure occurs.

## How to set the configuration
| Configuration Item | Recommended Setup | Basis for This Setup |

| Data source nodes | Create separate nodes for China Government Procurement Network and fiscal integration system | Matches the split processing needs of multi-source data to avoid cross-data contamination |

| Reply content length limit | Within 1000 characters | Adapts to government affair inquiry reply display specifications to avoid content exceeding display limits |

## Three common mistakes
- Phenomenon: After calling a government procurement HTTP interface during workflow orchestration, the conversation output does not display the winning bid announcement content returned by the interface. Cause: The output result of the HTTP node was not bound to the `variables` list of the conversation output node, so the output node cannot obtain the data returned by the interface.
- Phenomenon: Custom tool variables are not associated with procurement document fields, so corresponding procurement plans or winning bid announcement data cannot be retrieved during inquiries. Cause: Key fields such as procurement project number and supplier unified social credit code were not bound in the `variables` configuration, resulting in data matching failure.
- Phenomenon: A timeout error is triggered during workflow execution, and the preset alert node is not triggered. Cause: The `nodeId` of the exception handling node was not bound to the timeout trigger logic, so no corresponding intervention measures are available after a timeout.

## How to confirm the configuration is complete
- Manually trigger the workflow, enter a specified procurement project number, and check if corresponding public data such as procurement requirements and winning bid announcements are successfully retrieved.
- View the scheduled task log to confirm that the daily 00:00 automatic synchronization task for government procurement network data has a successful execution status.
- Simulate an interface timeout scenario, and check if the preset alert and manual intervention nodes are triggered and the process jumps normally.
- Verify that the output content only includes information publicly available on the China Government Procurement Network, and no undisclosed procurement plans or bid evaluation report content appears.
