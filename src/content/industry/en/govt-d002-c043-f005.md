# Special Equipment Safety Supervision Service Inquiry and Response: Tool Calling and Plugins

## What this category of data looks like
This category of data covers documents related to the full lifecycle of special equipment, including usage registration certificates, regular inspection reports, maintenance records, hidden danger rectification notices, accident reports, and operator certificates. Data sources are the special equipment safety supervision system, inspection and testing institution systems, user account books, and operator certificate databases. The update frequency is once per month. Each individual document includes fixed fields such as equipment number, registration date, inspection cycle, maintenance unit, operator qualification number, with no custom extended fields. The main data formats are structured tables and standard PDF documents.

## What constraints these characteristics impose on the tool calling and plugins link
The data sources for this category are scattered and have a fixed update frequency. The tool calling link must support interfacing with multiple systems, and must configure unified authentication rules to adapt to the permission requirements of different systems. Documents are mainly structured tables and standard PDFs, so tool calling must support text parsing and structured extraction, and must configure corresponding parsing parameters for different document types. Each individual document has fixed fields, so there is no need for dynamic extended fields. The result mapping of tool calling must strictly match preset fields to avoid errors caused by field mismatches. In addition, the data update frequency is once per month, so the caching strategy for tool calling can be set based on this to reduce resource consumption from repeated requests.

## How to set the configurations
The following configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Adapt to the automatic calling requirements of different document types, no need to manually specify a single tool |
| Plugin call timeout | 600 seconds | Matches the average response duration of multi-system integration for special equipment data |
| Structured document parsing mode | Match by document type | Adapt to the fixed field structures of different documents such as usage registration certificates and inspection reports |
| `functionCall` | Enabled, limited to 3 tools | Avoid tool calling overload, matches the information requirement scope of a single query for this category |
| Multi-data source authentication configuration | Configure keys grouped by system | Adapt to the authentication rules of different systems such as the special equipment safety supervision system and inspection institution systems |
| Data cache period | 30 days | Matches the once-per-month update frequency of this category of data, reducing repeated requests |

## Three common mistakes
- Phenomenon: Occasional errors when calling the large model, with empty returned fields or status code 500. Cause: Unified timeout thresholds are not configured for multi-data source integration, and some system response timeouts are not handled correctly.
- Phenomenon: The number of returned results is abnormal after converting text queries to SQL. Cause: Mapping rules for the fixed fields of this category are not configured, leading to field mismatches when generating SQL statements.
- Phenomenon: When parsing image attachments in hidden danger rectification notices, they cannot be automatically uploaded to the specified server and links cannot be replaced. Cause: The file upload trigger rules for the plugin are not configured, and the processing flow corresponding to the document type is not bound.

## How to confirm the configuration is complete
- Initiate a query that includes an equipment number, and check whether tool calling automatically triggers interface requests for the corresponding data source.
- Generate a text-to-SQL query, and check whether the generated SQL statement matches the fixed fields of this category.
- Upload the PDF document of a hidden danger rectification notice, and check whether the image attachments are automatically uploaded to the specified server and links are generated.
- Wait for 1 update cycle, and check whether the data returned by tool calling matches the updated content of the data source.
