# Legality Review of Regulatory Documents: Service Consultation and Reply - Forms and Interactions

## What Data for This Category Looks Like
This category of data comes mainly from the regulatory and rule database, higher-level law database, departmental policy document database, and administrative regulatory document filing system. Updates occur on an irregular basis. Daily processed documents include regulatory document drafts, drafting explanations, legality review opinions, solicitation opinion summaries, and filing reports. Data fields cover document numbers, issuing entities, article content, solicitation opinion scope, key review opinions, and more. There is no fixed unified unit. Corresponding normative basis must be associated with specific documents.

## What Constraints These Characteristics Impose on the Forms and Interactions Link
Dispersed data sources and irregular updates require forms to support multi-source file batch upload and real-time verification mechanisms. This avoids referencing expired regulations. Diverse document structures require custom field groups to be configured to meet field requirements for different review scenarios. Fields have no fixed unit. Users must be allowed to manually add unit descriptions or associate corresponding normative bases. The system must also link with filing system data. This ensures review results can be synchronized to the filing process and maintains the integrity of the review workflow.

## How to Configure the Settings
The following configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Supports multi-file batch upload, single file maximum 1000 MB, and custom field groups | Adapts to multiple types of review documents such as regulatory document drafts and drafting explanations, and meets flexible field configuration requirements |
| Single search limit | Top 10 entries | Matches the quantity range of higher-level laws and policy entries that need to be compared for a single legality review |
| `userSelect` | Links to multiple data sources such as the regulatory and rule database and higher-level law database | Covers all data sources of this category to ensure the completeness of review basis |
| Maximum context | 8000–12000 token | Accommodates the total content of complete review documents and associated regulations |
| Timeout threshold | 600 seconds | Adapts to the time required for multi-source data retrieval and article comparison |
| Query optimization | Preset article comparison rules based on review scenarios | Optimizes query logic for the core review links of legality reviews |

## Three Common Configuration Mistakes
- After selecting a large model and enabling thought process output, the results do not display the thought process. The cause is that the Retain Thought Process option in the large model configuration of `formInput` is not checked, or the permission parameters of the corresponding model are not associated.
- After configuring global variables, the node call prompts that the input is empty. The cause is that the global variable is not bound to the data source parameter of `userSelect`, causing the variable to not be correctly passed to subsequent review links.
- The copy button in the conversation interface is invalid. The generated markdown content has no line breaks, and a prompt pops up requiring manual text selection. The cause is that the markdown automatic line break configuration of the form is not enabled, and the adaptation logic for browser copy permission verification is not configured through `formInput`.

## How to Confirm the Configuration Is Complete
- Upload multiple types of review documents and check whether the form automatically recognizes and loads the corresponding custom field groups.
- Trigger retrieval and confirm that the returned results cover all configured data sources such as the regulatory and rule database and higher-level law database.
- Call the large model to generate review opinions and check whether the input parameters include the uploaded review documents and associated regulatory content.
- Test copying the generated review opinion text, confirm that the markdown format includes correct line breaks, and that the copy permission verification works properly.
