# Public Financial Expenditure Performance Evaluation Service Inquiry and Response: Deployment and Upgrade

## What the data for this category looks like
This category’s data covers the full lifecycle of fiscal project performance. Daily documents include performance target forms, self-assessment forms, performance evaluation reports, supporting material lists, and rectification reports. Data sources include the unified budget management system, project declaration materials, fund payment data, business system ledgers, and satisfaction surveys. The update frequency is annual. Data fields link project identifiers, performance indicators, fund usage records, and supporting material numbers, to match performance targets with actual expenditure outcomes.

## What constraints these characteristics impose during deployment and upgrade
Configure multi-source data connection and adaptation logic during deployment to avoid data silos, as data sources are scattered across multiple business systems.
Use a batch offline synchronization configuration mode, since the annual update frequency makes high-frequency incremental synchronization unnecessary.
Support multi-format parsing and field mapping during deployment to handle diverse document types, ensuring accurate association of performance indicators, fund records, and supporting materials.
Optimize retrieval matching association rules during upgrades to improve data verification efficiency, to meet verification requirements for core time-consuming links.

## How to set the configurations
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `DB_MAX_LINK` | `10–15 connections` | Adapts to annual batch synchronization database connection requirements, avoiding connection exhaustion |
| `MONGODB_URI` | dedicated database instance storing performance documents and evaluation data | Isolates business data from other system data, ensuring the security of performance data |
| `REDIS_URL` | local cache instance, with cache validity set to `86400 seconds` | Caches annually updated performance indicator and fund association data, reducing repeated queries |
| `STORAGE_S3_ENDPOINT` | enterprise internal object storage service address | Stores large-volume documents such as supporting materials, adapting to multi-format file upload and retrieval |
| `ROOT_KEY` | dedicated key generated in accordance with internal permission control rules | Restricts unauthorized personnel from modifying performance evaluation configurations |
| `FILE_TOKEN_KEY` | 16-digit random string, with token validity set to `3600 seconds` | Generates temporary access tokens for supporting materials, avoiding public exposure of storage paths |

## Three common configuration errors
- Request timeout errors occur during conversations. Cause: The `DB_MAX_LINK` configuration was not adjusted for annual batch data synchronization, leading to database connection exhaustion and failure to respond to inquiry requests in a timely manner.
- Supporting material search returns no results. Cause: `STORAGE_S3_ENDPOINT` was not configured correctly, failing to associate stored supporting file paths, resulting in missing corresponding materials.
- The system cannot call data interfaces from the unified budget management system. Cause: Permission verification was not configured via `ROOT_KEY`, leading to cross-system connection being blocked and failure to obtain fund payment and performance target association data.

## How to confirm the configuration is complete
- Run the annual batch synchronization script, verify that the database connection count does not exceed the configured limit.
- Upload a performance self-assessment form document, confirm that it can be associated with storage and indexed via the storage configuration.
- Initiate a performance inquiry test request, confirm that the response meets internal business requirements.
- Attempt to access the system configuration page using an unauthorized key, verify that permission control takes effect.
