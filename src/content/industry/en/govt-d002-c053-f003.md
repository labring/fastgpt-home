# Department Budget Preparation Service Consultation and Reply: Multi-turn Dialogue and Prompts

## What This Category of Data Entails
This category of data is mainly sourced from the unified budget management system, department staff establishment system, prior-year final accounts, project library, and the Ministry of Finance budget preparation notices. It updates annually. Daily processed documents include department budget drafts, project application documents, performance target forms, personnel expense calculation forms, and budget approvals. These documents contain exclusive business fields such as project codes, expenditure function classifications, staff establishment numbers, and performance indicators.

## Constraints Imposed on the "Multi-turn Dialogue and Prompts" Link
Department budget preparation data updates annually. Multi-turn dialogue must avoid introducing old data from non-current years. Multiple data sources require the dialogue to clearly distinguish document types from different systems. Prompt design must guide users to specify the document category for the current operation. Diverse document structures and exclusive business fields require multi-turn dialogue to gradually guide users to clarify specific budget projects, units, and cycles. Clear consequences of operational errors require dialogue context to accurately match the current budget operation link, avoiding confusion of information from different units or projects.

## Configuration Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Matches the field length of department budget documents, avoids cutting critical budget codes and expenditure amounts |
| Maximum Context | First 10 dialogue turns or 3500 characters | Balances context information completeness and interference control, aligns with the annual data update cycle |
| Single Search Limit | Top 7 recalled results | Matches the accuracy of budget-related documents, avoids redundant project information interfering with core calculation logic |
| `chatId` binding | Bound by budget unit scope | Distinguishes dialogue histories of different competent departments or subordinate units, avoids data confusion |
| `variables` binding | Bound to budget unit codes | Transmits context data for exclusive budget units, ensures recalled content complies with the rules of the corresponding unit |
| Context Cleanup Trigger | When the keyword "annual budget adjustment" is detected | Aligns with the characteristics of annually updated data, automatically clears old context from non-current years |
| Question Optimization | Enabled and limited to budget-specific terminology | Optimizes questions for exclusive expressions of department budget preparation, improves the accuracy of knowledge base recall |

## Three Common Misconfigurations
- Deviating results are returned when asking consecutive questions about department budget calculation across multiple turns. The cause is that reasonable context cleanup rules are not set, and redundant information from old dialogues interferes with recall matching of the current knowledge base.
- Unable to clear dialogue context according to specified conditions in the workflow. The cause is that the cleanup logic of the `messages` parameter is not configured correctly, or the trigger condition does not match the exclusive keywords of the budget scenario.
- Dialogue return results include document content of non-specified types, and knowledge base references cannot be disabled. The cause is that the prompt design does not clearly limit only calling budget-related documents, or the default switch for knowledge base recall is not turned off.

## How to Verify Correct Configuration
- Initiate 3 consecutive questions about different budget projects, check whether the context retains valid information and has no redundant interference.
- Add a context cleanup node with the trigger condition "annual budget adjustment" in the workflow, verify whether the dialogue history is cleared after triggering.
- Generate a dialogue sharing link, access it using an unauthorized test account, confirm that budget-related dialogue content cannot be viewed.
- Enter "disable knowledge base references" in the dialogue, check whether the return result is generated only based on the prompt design, without calling external knowledge base content.
