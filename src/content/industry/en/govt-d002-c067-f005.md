# Fertilizer and Pesticide Service Consultation and Response: Tool Calling and Plugins

## What the Data for This Category Looks Like
Fertilizer and pesticide service consultation data comes from multiple sources. These include official filing and quality inspection data from the Ministry of Agriculture and Rural Affairs Pesticide Inspection Institute and the National Fertilizer Quality Supervision and Inspection Center. It also includes annual updated filing information submitted by production enterprises. Data documents are stored in structured table format. Fields include product common name, registration certificate number, active ingredient content, applicable crop scope, pre-harvest interval, and residue limit standards. Units include grams per liter, kilograms per hectare, days, and others. Regular filing data updates once every quarter. Inspection data updates synchronously with batch production.

## What Constraints These Characteristics Impose on Tool Calling and Plugins
Fertilizer and pesticide data has many structured fields and diverse units. Tool calling must accurately match field names and units. This avoids incorrect consultation results caused by unit conversion errors. Official filing data updates quarterly. Plugins must be configured with a scheduled synchronization mechanism. This ensures the latest filing information is returned when called. Different products have detailed differences in applicable crops and pre-harvest intervals. Tool calling must support precise filtering of data by product registration certificate number or common name. This prevents cross-category confusion. Inspection data is generated per batch. Tool calling must support pulling the latest batch of quality inspection results on demand. Fixed caching cannot be relied on. The `toolChoice` configuration can limit the scope of tool calling. This meets the exclusive data needs of this category.

## Configuration Settings
This document is written based on FastGPT v4.17.0. The following are configuration recommendations for tool calling and plugins:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | Set to `auto` and bind exclusive tools | Ensure the correct category-specific tools are automatically selected to avoid incorrect calls |
| `functionCall` | Bind two exclusive tools: pesticide filing query and fertilizer quality inspection query | Limit the scope of tool calling to avoid calling unrelated functions |
| Tool calling trigger rule | Trigger when keywords such as fertilizer and pesticide, pesticide registration certificate, fertilizer standard are matched | Accurately locate category-specific consultation scenarios and filter invalid calls |
| Data synchronization cycle | Execute once every 90 days | Align with the quarterly update rhythm of official filing data |
| Cache validity period | 7 days | Balance data timeliness and call response speed |
| Response waiting time | 30 seconds | Avoid call failures caused by too long data pulling time |
| Unit conversion switch | Enable automatic conversion | Adapt to common user units such as mu and liter, and align with the standard units in the documents |
| Number of returned results | Top 3 matching results | Avoid excessive information interfering with user consultation experience |

## Three Common Misconfigurations
- Phenomenon: The original plugin data returned by tool calling is directly displayed to users without filtering. Reason: No output rules for tool calling results are configured, and all content returned by the plugin is returned by default.
- Phenomenon: The returned filing data is expired and does not match the latest official information from the current quarter. Reason: No scheduled synchronization mechanism is set, and old cached data older than 90 days is still used.
- Phenomenon: When a user asks about dosage per mu, the returned result is a value in kilograms per hectare without unit conversion. Reason: The unit conversion switch is not enabled, and the difference between the standard units in the documents and the units used in the user's daily questions is not handled.

## How to Confirm Proper Configuration
- Trigger a test question containing the fertilizer and pesticide keywords, check if the tool starts automatically and no unrelated plugins are triggered.
- View the plugin data synchronization log to confirm that the most recent synchronization time meets the configured cycle requirements.
- Simulate a user's question about dosage using common units, check if the returned result has completed unit conversion.
- View the output configuration of tool calling results, confirm that filtering rules have been set to only display the consultation content required by the user.

The values provided are common starting points and should be measured against the reader's own samples.
