# Hazardous Chemicals Storage and Transportation Inquiry and Response: Vector Models and Indexes
Reference only; verify against the target FastGPT release and deployment documentation.

## What This Category of Data Looks Like
Hazardous chemical storage and transportation inquiry and response data mainly comes from internal enterprise storage ledgers, safety compliance documents, administrative approval documents, real-time inventory and transportation logs. Data updates follow two schedules: storage ledgers and inventory logs are updated daily, while safety compliance documents are updated quarterly or annually when national or industry standards are revised. Document structure includes structured fields and unstructured text. Structured fields include hazardous chemical ID, storage location, temperature threshold, transportation route, approval document number, with units including cubic meters, degrees Celsius, kilograms, kilometers, and others. Unstructured text includes safety operation specifications, emergency response procedures, and similar content.

## What Constraints Do These Characteristics Place on Vector Models and Indexing
Data for hazardous chemical storage and transportation includes both structured fields and unstructured text. This requires vector modeling to retain field metadata to support precise queries in inquiries, such as searches by storage location or temperature threshold. Differences in data update schedules require indexes to support both incremental and full update modes, to adapt to daily updated real-time data and periodically updated compliance documents. Document length varies widely, from dozens of characters of compliance clauses to thousands of characters of storage and transportation process descriptions. This requires a flexible chunking strategy to avoid semantic breaks. Semantic weights differ across fields; for example, hazardous chemical ID has higher semantic uniqueness than storage location, so field priority must be distinguished during indexing.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Fits the length range of hazardous chemical storage and transportation documents, balances semantic completeness and vector retrieval density |
| Overlap Length | 100–150 characters | Prevents semantic breaks after chunking long documents, especially for continuous steps in storage and transportation processes |
| maxToken | 8192 | Matches the context limit of most mainstream embedding models, and supports the splicing requirement of chunked documents |
| Similarity Threshold | 0.72–0.85 | Ensures accuracy of inquiry responses, filters irrelevant results while covering valid compliance and process information |
| Single Search Limit | Top 6 results | Matches the conventional information needs of inquiry and response, avoids excessive results increasing context processing load |
| defaultToken | Calibrated via actual testing | Adapts to key permissions and billing rules of different embedding models, adjust based on actual call volume |

## Three Common Misconfigurations
- Phenomenon: A "This token is not authorized to use the model" prompt appears during calls. Cause: `defaultToken` is not correctly configured in FastGPT, or the bound key does not have permission to use the corresponding embedding model.
- Phenomenon: The bce-embedding model added via a third-party API transit channel shows no availability. Cause: FastGPT does not point the embedding model call path to the corresponding endpoint of the transit channel, or the channel's concurrent quota is exhausted.
- Phenomenon: Retrieval results contain chunked content with semantic breaks. Cause: Chunk length settings do not match the semantic units of hazardous chemical storage and transportation documents, such as overly short chunks splitting continuous emergency response procedures.

## How to Confirm Proper Configuration
- Upload a hazardous chemical storage and transportation approval document, and check the FastGPT chunk preview interface to confirm that chunk length and overlap length match the set values.
- Call the FastGPT embedding model test interface, input a section of hazardous chemical compliance text, and confirm that the returned vector dimension matches the standard dimension of the selected model.
- Input an inquiry about hazardous chemical storage temperature, and check the similarity scores of retrieval results to confirm they fall within the set threshold range.
- Check the FastGPT call logs to confirm that embedding model call requests use the configured `defaultToken` key, with no permission errors or timeout records.
