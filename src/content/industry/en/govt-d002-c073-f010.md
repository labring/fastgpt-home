# Work Consultation and Reply for State-owned Industrial Funds: Knowledge Base Retrieval and Recall

## Data Profile for This Category
State-owned industrial fund work consultation data is sourced primarily from official archived records, investment project ledgers, capital allocation vouchers, service guidelines, and regulatory policy documents. Two update cycles apply to the data:
- Project progress data is updated in real time alongside investment activities
- Policy documents are updated regularly per regulatory requirements

Document structures combine structured fields and unstructured text. Structured fields include fund ID, funder, investment sector, approval nodes, processing cycle, and similar items. Units include 100 million yuan, working days, and others. Individual document lengths vary widely, from several hundred characters of service guidelines to several thousand characters of project descriptions.

## Constraints on Retrieval and Recall
The data characteristics of this category impose multiple constraints on knowledge base retrieval and recall:
1.  The data includes both structured fields and unstructured text. Retrieval must balance field attribute matching and semantic content matching to avoid irrelevant fund project recalls.
2.  Differing update cycles require real-time project progress data to trigger knowledge base index refreshes, preventing outdated information from being returned.
3.  Wide variance in individual document lengths requires careful handling: short service guidelines must avoid over-splitting that loses context, while long project ledgers need reasonable chunking to preserve semantic integrity.
4.  Fields include clear units and identifiers. Field filtering can narrow the recall scope to improve retrieval accuracy.

## Three Common Configuration Errors
- Symptom: After calling the knowledge base API and receiving a reading link, clicking the link triggers an error with the prompt "Only support .txt, .m". Cause: State-owned industrial fund documents uploaded to the knowledge base have not been converted to allowed formats. Most documents in this category are project ledger PDFs and service guideline Word files that have not completed format conversion.
- Symptom: After importing work consultation documents, retrieval results fail to associate key fields such as fund ID and processing time limit. Cause: Documents have not been organized per structured field requirements, preventing retrieval from matching corresponding attributes.
- Symptom: The number of knowledge base retrieval results does not match the configured `limit` value. Cause: The `limit` parameter is not configured correctly, or additional unstated filtering rules are applied during retrieval, leading to premature result truncation.
