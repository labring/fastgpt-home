# Government-owned Industrial Fund Service Inquiry and Reply: Forms and Interactions
Reference only; verify against the target FastGPT release and deployment documentation.

## What this category of data looks like
The service inquiry data for government-owned industrial funds is primarily sourced from the state-owned assets special zone of the national public resource trading platform, the internal post-investment management system of fund managers, and local state-owned assets supervision platforms.
Data is divided into three categories: record-related information, post-investment operation information, and policy document information.
Record-related information includes fields such as full fund name, record number, manager entity information, total subscribed capital, total paid-in capital, with the unit being 100 million yuan.
Post-investment operation information includes lists of invested projects, exit progress, and similar details.
Policy document information consists of real-time updated notices related to state-owned assets supervision.
Record-related information is updated quarterly. Post-investment operation data is updated monthly. Policy documents are synchronized in real time.

## How These Characteristics Impact Forms and Interactions
Since data sources are scattered and update cycles vary, the forms and interactions link must separate static record query and dynamic post-investment inquiry entry points. This prevents confusion between data with different update frequencies.
Multiple field types require forms to support switching between fuzzy matching and exact query. This accommodates query needs for keywords like record numbers, manager names, and project names.
Fund levels are split into central and local. Interactive components must support grouping options by level. This helps users accurately narrow their inquiry scope.
In service inquiry scenarios, users may submit multi-condition combined queries. Forms must support multi-field filtering interaction logic. This improves query accuracy.

## How to Configure Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Support switching between fuzzy matching and exact query | Match multiple types of keywords such as record numbers and manager names |
| `userSelect` | Group and display options by central/local fund level | Distinguish inquiry scopes for different levels of industrial funds |
| Single search limit | Top 20 entries | Adapt to the project volume scale of government-owned industrial funds |
| Result sorting rule | Sort by update time in descending order | Prioritize displaying the latest record and post-investment data |
| Timeout threshold | Calibrate based on actual testing | Adapt to response latency from synchronized multi-data sources |
| Form validation rule | Enforce keyword length between 2 and 30 characters | Filter invalid query requests |

## Three Common Configuration Mistakes
- Issue: Chat window displays "No knowledge base selected". Cause: The record and post-investment datasets for government-owned industrial funds are not bound to the knowledge base configuration of the current Q&A session.
- Issue: Multi-condition filtering fails to trigger during interaction. Cause: The multi-condition parsing configuration for `formInput` is not enabled. Only single-keyword queries are supported.
- Issue: Returned result count does not match expectations. Cause: The single search return limit is not configured, leading to excessive redundant data being returned.

## How to Verify Successful Configuration
- Enter preset record-related keywords, verify that returned results cover content from corresponding data sources
- Select user grouping options, confirm that displayed options align with industrial fund tier classification rules
- Test input content of varying lengths, ensure the form validation rule operates per preset logic
- Initiate multiple queries, confirm that the response timeout threshold meets actual business scenario requirements
