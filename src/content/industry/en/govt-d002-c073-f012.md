# State-owned industrial fund service consultation and reply: Deployment and upgrade

## What the data for this category looks like
The service consultation and reply data for state-owned industrial funds is primarily sourced from internal service guideline documents, policy approval documents, project declaration process ledgers, and historical consultation reply records.
Data update rhythms fall into three categories:
1. Policy documents are updated quarterly alongside adjustments to superior policies.
2. Service process documents are updated monthly based on business adjustments.
3. Historical consultation ledgers are synchronized via real-time incremental updates.

Each single document includes fixed fields: policy document number, applicable subject scope, list of handling materials, handling time limit, consultation classification tags, and more. Field units mostly use standardized government affairs units such as "working days", "copies", and "items". There is no case where unstructured free text accounts for an overly high proportion.

## What constraints these characteristics impose on deployment and upgrade
Dispersed data from multiple sources requires configuring multiple storage source access adapters during deployment. This avoids data silos.
The fixed field structure requires strict field mapping during vector database import. Field types cannot be adjusted arbitrarily. Arbitrary adjustments will cause retrieval and matching failures.
Consultation ledger data with high real-time requirements needs sufficient database connection resources to support concurrent queries.
Data sources with different update rhythms require split incremental synchronization tasks. This prevents synchronization tasks from seizing system resources.
In addition, service data for state-owned industrial funds involves internal business sensitive information. Secure storage and access permissions must be configured during deployment. This complies with internal data management requirements.

## How to set configurations

| Config Item | Recommended Value | Rationale |
| --- | --- | --- |
| `MONGODB_URI` | `mongodb://admin:pass@host:27017/fastgpt_fund?maxPoolSize=20` | The consultation ledger data for state-owned industrial funds has a large volume. A sufficient connection pool is required to support concurrent queries. |
| `REDIS_URL` | `redis://:redis_pass@host:6379/1` | Cache reply templates for high-frequency consultations. This reduces repeated query pressure on the database. |
| `STORAGE_S3_ENDPOINT` | `http://internal-fund-storage:9000` | Store attachments such as service guidelines and policy documents. This adapts to the access path of internal object storage. |
| `DB_MAX_LINK` | `15–25` | Adapt to the concurrent consultation request volume of state-owned industrial funds. This avoids database connection exhaustion. |
| `FE_DOMAIN` | `https://fund-advice.internal.gov.cn` | Deploy under the internal domain of state-owned enterprises and public institutions. This ensures access security and compliance. |
| `FILE_TOKEN_KEY` | `32-bit randomly generated encrypted string` | Encrypt file access tokens. This prevents unauthorized file downloads and access. |

## Three common configuration errors
- Deleting a self-built service consultation application prompts a network error. The deletion operation cannot be completed. The root cause is that `FE_DOMAIN` is not correctly configured as an internally accessible domain name. Front-end requests cannot be correctly routed to the back-end service.
- Uploading a service guideline PDF cannot be retrieved. The system may also prompt a file reading failure. The root cause is that `STORAGE_S3_ENDPOINT` is not correctly configured to point to the internal storage path. The file was not successfully synchronized to the vector database storage source.
- High-frequency consultation queries time out or return empty results. The root cause is that the value of `DB_MAX_LINK` was not adjusted. Insufficient database connection pool causes concurrent query failures.

## How to confirm the configuration is complete
- Access the internal address corresponding to `FE_DOMAIN`. Confirm that the FastGPT v4.17.0 background management interface can be logged in normally.
- Upload a PDF file of the state-owned industrial fund service guideline. Check whether the file is successfully stored in the storage path specified by `STORAGE_S3_ENDPOINT`.
- Initiate a simulated query for a high-frequency consultation. Confirm that the returned results conform to the preset business logic. No timeout or error prompts should appear.
- Perform the operation to delete the self-built service consultation application. Confirm that no network error prompt appears. The operation should complete normally.
