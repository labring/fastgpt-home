# Service consultation and reply for state-owned capital investment companies: Document parsing and chunking

## What the data for this category looks like
Data sources include regulatory documents issued by state-owned assets supervision departments, internal group management systems, full-process investment project documents, service guidelines, and external reply ledgers.
Updates occur on demand, aligned with state-owned assets policy adjustments and group business expansion. No fixed update cycle exists.
Most documents use official document formatting, and include document numbers, issuing entities, main text chapters, and attachment lists.
Fields include project number, investment amount, supervision item number, and similar identifiers.
Units include ten thousand yuan, shareholding scale, project cycle (days), and similar metrics.

## Constraints on document parsing and chunking
Fixed formatting of state-owned assets supervision documents requires retaining metadata such as document numbers and issuing entities during parsing, to avoid splitting that breaks information relevance.
Long documents have clear chapter structures. Chunking must match chapter boundaries to prevent splitting of business logic.
Service guidelines and reply ledgers mostly contain structured Q&A content. Chunking must align with Q&A units to ensure reply accuracy.
Documents with multiple nested attachments require layered parsing support, to avoid missing attached information.
Documents updated on demand need to work with incremental parsing processes, to reduce repeated processing costs.

## Configuration settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `chunkSize` | 800–1200 characters | Documents for state-owned capital investment companies are mostly long-chapter official documents. This range balances information integrity and retrieval accuracy |
| `chunkSplitter` | Split by chapter and paragraph | Documents have clear chapters and paragraphs. Splitting this way preserves business logic coherence |
| `customPdfParse` | Enabled | State-owned assets documents are mostly standard PDF formats. Enabling custom parsing preserves metadata and nested attachment information |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Investment project documents may include multi-page drawings and attachments. This upper limit covers most business scenarios |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Large documents with nested attachments take longer to parse. This duration prevents timeout interruptions |
| `chunkSettingMode` | Custom mode | Chunking rules need adjustment for different document types such as policy documents and service guidelines, to adapt to business differences |

## Three common mistakes
- Phenomenon: After uploading a state-owned assets PDF file, parsing fails with a 504 status code. Cause: The `PARSE_FILE_TIMEOUT_SECONDS` parameter was not adjusted. Parsing large nested attachment documents takes longer than the default threshold, causing a timeout.
- Phenomenon: Chunking results split the chapter structure of state-owned assets documents, resulting in document numbers and main text being separated. Cause: `chunkSplitter` was not configured to split by chapter. Using the default character-based splitting causes logical breaks.
- Phenomenon: After uploading a file, the system prompts that the file size exceeds the limit and submission is not possible. Cause: The `UPLOAD_FILE_MAX_SIZE` parameter was not adjusted. The default upper limit cannot accommodate investment project documents with multiple attachments.

## How to confirm the configuration is properly set
- Upload a single state-owned assets policy PDF file. Check if parsed metadata includes document numbers and issuing entities, to confirm the custom parsing configuration is active.
- Adjust the `chunkSize` parameter. Check if the character count of chunking results falls within the preset range, to confirm `chunkSettingMode` is set to custom mode.
- Upload an investment project document with nested attachments. Verify that parsed results include attachment content, to confirm `chunkSplitter` adapts to the document structure.
- Submit a large document and review the task log. Confirm that parsing duration does not exceed the value set for `PARSE_FILE_TIMEOUT_SECONDS`.
