# State-owned Capital Investment Company Service Inquiry and Reply: Forms and Interactions

## What the Data for This Category Looks Like
State-owned capital investment company service inquiry and reply data mainly comes from the state-owned assets supervision and approval system, internal enterprise service ledgers, policy document repositories, and inquiry ticket records.
There are two update rhythms: approval tickets and inquiry tickets update in real time, while policy documents update regularly per regulatory requirements.
Document structures include fields such as ticket ID, unified social credit code of the applying entity, item type, submission time, processing status, reply content, and attachment links. Most field units use string and datetime formats, and attachment fields have size and format restrictions.

## What Constraints These Characteristics Impose on the "Forms and Interactions" Link
Because the data includes mandatory fields such as the unified social credit code required by state-owned assets supervision, forms must configure corresponding mandatory items and format verification rules. This ensures submitted data meets compliance requirements.
Real-time updated ticket data requires form status display to sync with system data. This prevents information lag.
A large number of standardized item types and ticket fields require forms to be configured with multi-dimensional filtering functions. This improves retrieval efficiency.
At the same time, state-owned assets supervision permission control requires dividing the visible and operational scope of forms based on department levels. This prevents unauthorized access.

## How to Set the Configuration

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `formInput` | Configure as a form structure that includes the unified social credit code, item type, and attachments | Matches the mandatory field requirements for service items of state-owned capital investment companies |
| `userSelect` | Divide optional user operation scope by department level | Adapts to the permission control specifications of state-owned assets supervision |
| Attachment upload limits | Single file no larger than 100 MB, total submissions no more than 500 MB | Matches the conventional storage and transmission requirements for state-owned asset approval attachments |
| Form field verification | Enable format verification for the unified social credit code field, limit the item type field to 200 characters or less | Ensures submitted data meets compliance format and length requirements |
| Real-time status synchronization | Enable a 5-second refresh interval for ticket status | Matches the real-time feedback requirements of service inquiries |
| Filter configuration | Preset two filtering dimensions: item type and processing status | Adapts to the rapid retrieval needs of a large number of tickets |

## Three Common Mistakes
- Phenomenon: The unified social credit code field fails verification after form submission, displaying a format error. Cause: The format verification rule for this field in `formInput` is not enabled, allowing data that does not meet the state-owned assets supervision identification format to be submitted.
- Phenomenon: Team members enter a username and see an invalid prompt. Cause: The legal user scope is not configured via `userSelect`, so external accounts or accounts from unauthorized departments cannot pass system verification.
- Phenomenon: Attachments cannot be displayed in the ticket after being uploaded. Cause: No whitelist format is configured for attachment uploads, blocking commonly used state-owned asset approval formats such as PDF and Word.

## How to Confirm the Configuration Is Complete
- Fill in a correctly formatted unified social credit code, submit the form, and check whether the verification passes and a ticket is successfully generated.
- Upload a PDF attachment with a single file size of 80 MB, and check whether the attachment is normally displayed on the ticket details page after submission.
- Switch to an unauthorized department account, and check whether access to ticket data outside this department is blocked.
- Use the item type to filter tickets, and confirm that the filter results match the preset configuration dimensions.
