# Basic Chemicals Service Consultation and Response: Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
The service consultation data for basic chemicals mainly comes from production process manuals, hazardous chemical safety operation procedures, raw material quality inspection reports, equipment maintenance records, and government regulatory documents.
Data updates follow two rhythms: general material standards are updated every six months. Documents are updated irregularly after process improvements or new safety supervision regulations are released.
Document structures primarily include long-text process descriptions and tabular material parameters. Fields include material name, CAS number, safety threshold, and others. Most parameter units use industrial standard units such as MPa, ℃, mg/m³.

## Constraints Imposed on Knowledge Base Retrieval and Recall
Long-text process descriptions require retaining contextual associations during chunking. This prevents splitting the integrity of key operation steps.
Tabular parameter data includes precise numerical values and units. Retrieval must match both semantics and structured fields to avoid incorrect recall caused by mismatched parameter units.
Differing update rhythms require the knowledge base to use a combination of incremental and full updates. This balances timeliness and synchronization efficiency.
Service consultations have high accuracy requirements for hazardous chemical safety data. A high recall rate must be maintained to avoid missing key disposal steps.

## Three Common Mistakes
- Phenomenon: A `timeout of 60000ms exceeded` error occurs when deleting folders with a large number of documents in the knowledge base. Cause: Basic chemical knowledge bases contain many long-text process documents. Failing to split batch deletion tasks causes a single request to time out.
- Phenomenon: Some images fail to display normally in knowledge base question answering. Cause: Some chemical document images use local relative paths that have not been uploaded to the knowledge base storage bucket, or use non-standard image formats that cannot be parsed.
- Phenomenon: Yuque public sharing links cannot be parsed normally by the knowledge base. Cause: The direct link format for Yuque public sharing is not used, or the link includes permission verification parameters, preventing the parsing request from retrieving document content.

## How to Confirm Proper Configuration
- Initiate a consultation with specific chemical material parameters, and verify that the matching score of retrieval results falls within the preset range.
- Review the number of results returned by the search, and confirm alignment with the configured single search upper limit.
- Upload chemical documents containing structured parameters and long text, and test that the hybrid retrieval mode recalls content matching both keywords and semantics.
- Trigger a batch deletion operation for large folders, and verify no timeout error occurs.
