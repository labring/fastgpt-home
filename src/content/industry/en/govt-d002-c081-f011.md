# Basic Chemicals Service Inquiry and Response: Forms and Interactions

## What this category of data looks like
Service inquiry data for basic chemicals primarily comes from enterprise internal ERP system material ledgers, safety and environmental management platform compliance records, process department production procedures and quality inspection reports, and compliance documents released by regulatory authorities. Data update rhythm follows real-time synchronization for daily operation records, with compliance documents updated quarterly or per regulatory requirements. Documents include structured fields and unstructured text. Structured fields include material name, CAS registry number, safety threshold, and equipment operating parameters, with corresponding units such as mg/m³, ppm, MPa, ℃ and others. Unstructured text covers process steps, accident cases, and operation guides.

## What constraints these characteristics impose on the forms and interactions link
Structured fields for basic chemicals have fixed units, so forms must support unit verification and format blocking to prevent invalid input. Material and compliance document categories are clearly defined, so forms need preset common options to reduce manual input errors. Parsing long documents and drawing attachments takes extended time, so interaction links must reserve sufficient feedback time to avoid repeated user submissions. Additionally, compliance data has version differences, so forms must support version selection to ensure the latest valid data is called.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Enable field linkage and format verification, limit CAS numbers to 10 or 11 digits | CAS numbers for basic chemical materials follow standard formats, verification quickly filters invalid inputs |
| `userSelect` | Preset 15 common material categories and 5 compliance document version options | Basic chemical service inquiries often involve fixed categories of materials and compliance documents; preset options improve submission efficiency |
| `formInput` | Add unit verification for safety limit fields, allow mg/m³, ppm, MPa | Basic chemical safety parameters have fixed unit formats, invalid inputs are blocked if units do not match |
| Upload file format restrictions | Only allow PDF, PNG, JPG uploads, maximum single file size 500 MB | Process drawings and compliance documents commonly used in basic chemicals use these formats, controlling transmission load |
| Interaction feedback duration | Set to 300–600 seconds | Parsing long process documents or batch material data requires sufficient processing time; adjust based on actual measurements |

This chapter’s configurations are based on FastGPT v4.17.0.

## Three common mistakes
- Phenomenon: After calling the HTTP interface to upload process drawings, the base64 encoded field returned by the interface is empty. Cause: Image-to-base64 encoding processing was not enabled in the `formInput` configuration, causing the interface to fail to parse the uploaded attachment files.
- Phenomenon: A 504 Gateway Timeout error is returned after form submission. Cause: The interaction feedback duration was not adjusted appropriately; the time required to parse basic chemical long documents exceeds the default threshold, causing the request to be interrupted.
- Phenomenon: A "field format mismatch" error occurs when connecting to a MySQL database. Cause: Type verification was not added for fields such as basic chemical CAS numbers and equipment parameters, causing the incoming string format to not match the database field definitions.

## How to confirm the configuration is complete
- Submit a test form containing a standard 10-digit CAS number and safety limits, check whether format verification is triggered and associated material information is correctly retrieved.
- Upload a basic chemical process drawing, call the preset HTTP interface, confirm that the returned base64 encoded content can be properly decoded into the original image.
- Select a preset compliance document version option to submit an inquiry, check whether the corresponding version of the knowledge base data is called to return accurate results.
- Simulate submitting an inquiry form containing more than 3 pages of process documents, confirm that the interaction feedback duration setting matches the actual processing rhythm, and no premature timeout occurs.
