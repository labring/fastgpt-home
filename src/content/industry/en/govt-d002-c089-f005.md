# Administrative Inquiries and Responses for Construction Machinery: Tool Calling and Plugins

## What this category of data looks like
Construction machinery administrative inquiry and response data covers matters such as registration, annual inspection, and maintenance qualification filing for special equipment including cranes and excavators. Data sources include special equipment regulations from the State Administration for Market Regulation, official maintenance and administrative manuals from original equipment manufacturers, and administrative guidelines from local government service platforms.
Update frequency: Special equipment regulations are revised quarterly. Original equipment manufacturer manuals are updated with new model releases. Local administrative guidelines are updated irregularly to align with local policy changes.
Each administrative inquiry data entry includes the following structure: item name, item code, handling entity, required materials, handling process, fee standard, and inquiry phone number. Fields include: 18-digit item code, handling time limit measured in working days, and material format requirements marked as PDF or physical paper.

## Constraints on Tool Calling and Plugin Workflows
Data sources for construction machinery administrative inquiries are scattered and use varying authentication methods. Tool calling must adapt to the different authentication logic of government platforms and original equipment manufacturers to avoid call failures.
The 18-digit item code has strict format requirements. Tool calling parameter validation must strictly match this format, otherwise the corresponding administrative item cannot be located.
Local administrative guidelines have regional differences. Tool calling must add regional filtering logic to prevent returning incorrect administrative rules across regions.
Material format fields use inconsistent terminology. Field mapping rules must be configured to ensure accurate format descriptions in returned results.
Handling time limits are measured in working days. Plugins must automatically convert this to natural language when generating responses to avoid confusion between working days and calendar days.

## Three Common Configuration Mistakes
- Phenomenon: Returns a 429 status code when calling `functionCall`, with a prompt indicating excessive request rate. Cause: No reasonable request interval is set. Construction machinery administrative inquiry data sources include multiple government service interfaces, and concurrent calls trigger rate limits.
- Phenomenon: The material format field in returned administrative guidelines from tool calling is empty. Cause: No multi-source data field mapping rules are configured. Material field names in original equipment manufacturer manuals and government platforms are inconsistent, with no alignment performed.
- Phenomenon: API key configuration is overwritten when two independent applications call the same tool. Cause: No independent tool instance is created for each application, and the same set of key configurations is reused.

## How to Verify Successful Configuration
- Input an 18-digit special equipment administrative item code, and verify if the tool automatically triggers the corresponding call and returns matching administrative processes.
- Switch query scenarios for different regions, and confirm that returned administrative guidelines only apply to the current regional rules, with no cross-region incorrect content.
- Send 3 or more consecutive tool calling requests, check if a rate limit error is triggered, and confirm that timeout and interval configurations are effective.
- Configure different API keys for two independent applications, send calls, and confirm that respective request logs and returned results are independent, with no configuration overwriting occurring.
