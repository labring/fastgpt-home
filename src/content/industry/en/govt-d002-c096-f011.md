# Non-ferrous Metal Smelting Service Inquiry and Reply: Forms and Interactions

## What This Category of Data Looks Like
The data sources for service inquiry in non-ferrous metal smelting include the internal enterprise DCS distributed control system, LIMS laboratory information management system, and equipment ledger system. Data update rhythm falls into two categories. Real-time production parameters are updated every 10 seconds. Batch quality inspection documents and operation logs are uploaded within 1 hour after each batch production is completed, and archived daily respectively. Most documents use structured fields, including furnace number, production time, furnace temperature, discharge amount, equipment operating duration, quality inspection number and other fields. They also come with unstructured detection photos and operation record text. All fields have clear industry standard units.

## Constraints Imposed on Forms and Interactions By These Characteristics
The mixed real-time and batch update rhythm requires forms to support two submission trigger modes. This adapts to different types of business data reporting. Fields with standard units require form controls to preset unit suffixes. This avoids unit errors during manual user input. The need to upload unstructured detection photos requires form configurations to support file upload controls with multi-format support and size limits. At the same time, traceability requirements for service inquiries from state-owned enterprises and public institutions require forms to automatically record metadata such as submitter and submission time. Core fields cannot be modified arbitrarily. Associated businesses across multiple devices and batches require forms to support multi-item batch addition and association.

## How to Configure Settings

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` control | Preset industry standard unit suffixes for each field, such as "Furnace Temperature (℃)", "Discharge Amount (tons)" | Matches the unit characteristics of smelting data fields, reduces input errors |
| `userSelect` control | Preset options for smelting furnaces 1-10 and common quality inspection types, support manual supplementation | Adapts to the device association attribute of production data, simplifies the entry process |
| File upload limit | Maximum 10 MB per file, supports jpg, png formats | Adapts to the common size and format requirements of detection photos |
| Submission trigger timing | Supports real-time submission and batch submission modes | Matches the update rhythm of real-time production data and batch quality inspection data |
| Context retention duration | 1800 seconds | Adapts to the session retention requirements of service inquiries |
| Error retry count | 3 times, 5-second interval | Adapts to form submission stability under network fluctuations |

## Three Common Configuration Mistakes
- The symptom is a "message receiving address verification failed" error after form deployment. The cause is failure to configure a publicly accessible callback address and adjust SSL certificate verification settings according to the network environment.
- The symptom is that values submitted via the `formInput` control cannot be correctly recognized by the system. The cause is failure to preset unit suffixes, which prevents the system from extracting valid business data.
- The symptom is that custom global variables cannot be configured with conditions in the evaluator. The cause is failure to set the variables associated with the form to a publicly callable type.

## How to Verify the Configuration Is Complete
- Open the form editing interface, check if each input control has the unit prompt corresponding to the business field.
- Submit a test form, check if the callback interface can normally receive submitted data, and adjust SSL certificate verification rules according to the actual network environment.
- Enter the evaluator configuration page, confirm that the associated form variables can be normally selected and used to configure conditions.
- Upload a test image file, check if the file upload control blocks files that do not meet the format or size requirements.
