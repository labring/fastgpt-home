# Port and Shipping Affairs Consultation and Response: Tool Calling and Plugins

## What the data for this category looks like
This document is written for FastGPT v4.17.0.
Data for port and shipping affairs consultation and response comes from three primary sources: direct maritime administration government public platforms, internal port group affair systems, and shipping company business manuals.
Static service guide data updates quarterly. It includes fields such as item number, application channel, material list, processing time limit, and consultation phone number. Processing time limit uses workdays as the unit. Material list uses "pieces" as the unit.
Real-time business data such as shipping schedules and berth occupancy is pushed by port scheduling systems. It updates once per minute. Fields include ship name, ETA time, and berth number. UTC standard time is used.
All data uses structured format. Some related data must be pulled via API interfaces.

## What constraints these characteristics impose on the tool calling and plugins link
Structured fields for static service guides require tool calling to strictly match preset parameter names. This avoids field misalignment caused by fuzzy matching.
The minute-level update frequency of real-time business data requires tool calling to set reasonable cache expiration times. This prevents returning outdated shipping schedule or berth information.
Fields that use workdays as the unit for processing time limits require tool calling to convert natural language "days" to workday counts during parsing. This avoids confusing natural days and workdays, which reduces the accuracy of service guidance.
The array format of material lists requires tool calling to correctly parse array content. It must clearly return multiple material requirements to inquiring users.
Additionally, there are many professional terms in port and shipping. Parameter mapping for tool calling must adapt to industry-specific vocabulary to avoid translation errors.

## How to set configurations
| Configuration Item | Recommended Value | Basis for This Setting |
| --- | --- | --- |
| `functionCall` | Force enabled | Port affair consultation has mostly structured parameters. Forcing enabled ensures parameters are parsed accurately and avoids fuzzy matching deviations |
| `toolChoice` | auto | Allows the system to automatically select between knowledge base or real-time data plugins based on consultation content. This balances query efficiency and information accuracy |
| Session context retention duration | 3600 seconds | Port affair consultations are typically completed within 1 hour. This duration ensures consistent consultation parameters for the same user's continuous inquiries |
| Multimodal file processing limit | 1000 MB | Material scans submitted for port affairs typically do not exceed this size. This prevents parameter error triggers |
| Tool call result display count | Top 2 | Affair consultations need to be concise. Limiting result counts reduces redundant information interference |

## Three Common Mistakes
- Phenomenon: Tool call returns `400 <400> InternalError.Algo.InvalidParameter: Multimodal file size` error. Cause: Multimodal file processing limit not configured. Large material scans for port affairs exceed the system's default threshold.
- Phenomenon: Tool call output in workflows cannot be hidden. Full plugin debug logs appear in responses. Cause: Tool call result display rules not set. The system defaults to returning all plugin execution information.
- Phenomenon: After inputting "share", the tool call parameter changes to "separate handover". Cause: Industry-specific word segmentation optimization not enabled. Port and shipping professional term word segmentation logic not adapted, leading to incorrect text translation.

## How to Confirm Configuration Is Correct
- Initiate a consultation including ship name and berth number. Check if the tool call correctly passes corresponding fields. Verify that the `functionCall` configuration is effective.
- Upload a material scan of common size for port affairs. Check if a parameter error is triggered. Verify that the multimodal file processing limit configuration is correct.
- Initiate two consecutive related consultations. Check if both tool calls use the same session parameters. Verify that the session context retention duration configuration is effective.
- Input a consultation including professional terms such as "separate stowage and document submission". Check if tool call parameters are correctly parsed. Verify the effect of the word segmentation optimization configuration.
