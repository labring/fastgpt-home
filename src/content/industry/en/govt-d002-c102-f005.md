# Service Inquiry and Response for Refinery and Chemical Production: Tool Calling and Plugins

## What the data for this category looks like
Refinery and chemical production service inquiry data mainly comes from DCS real-time control systems, equipment management EAM systems, process specification libraries, and laboratory analysis systems. Real-time operating condition data updates every second. Equipment ledgers and process specifications are synchronized and revised every 7 days for batch updates. Material batch data is bound with production dates and quality inspection numbers. The data includes process parameters (units: MPa, ℃, t/h), equipment ID codes, and patrol inspection record fields. Structured data is stored in relational tables, while unstructured process documents are saved as chapterized PDF files.

## What constraints these characteristics impose on tool calling and plugins
The data characteristics of refinery and chemical production impose multiple constraints on tool calling and plugins. The second-level update of real-time operating condition data requires that tool calling response delay does not exceed 5 seconds, otherwise it cannot support real-time service inquiries. Formatted exclusive fields such as equipment IDs and material batch numbers require that plug-in calls strictly match coding rules, otherwise accurate results cannot be returned. Chapterized unstructured process documents require plug-ins to specify document fragment indexes to locate target content. For scenarios of multi-source data mixed queries, plug-ins need to connect to DCS, EAM and other systems at the same time, and cross-source data permission verification logic must be configured.

## How to set up the configuration
The following configuration methods apply to FastGPT v4.17.0, and use the `functionCall` and `toolChoice` parameters supported by the platform.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Tool call timeout | 300 seconds | Matches the query delay requirements of real-time refinery and chemical production data, avoids inquiry interruptions caused by long waiting times |
| `functionCall` | Enabled, specify the function list as "Query real-time operating conditions, Query equipment ledger, Query process specifications" | Adapts to the three core service inquiry scenarios of refinery and chemical production, restricts the AI to only call preset tools |
| Database plugin character encoding | UTF-8 | Resolves Chinese data display abnormalities, matches the Chinese field format of refinery and chemical production data |
| Workflow branch execution logic | Only execute AI reply branch | Avoids information redundancy caused by simultaneous output of tool call results and AI replies |
| `toolChoice` | auto | Allows AI to independently select appropriate tools based on user questions, adapts to complex service inquiry scenarios |
| Qwen2.5 tool call switch | Enabled | Adapts to the function calling capabilities of the Qwen2.5 model, supports multi-tool linkage in refinery and chemical production scenarios |

## Three common misconfigurations
- Phenomenon: The AI return content from the first layer of tool calls in the workflow is printed and cannot be hidden via the interface. Cause: No output filtering rules for workflow branches are configured, causing tool return content from intermediate steps to be forcibly displayed.
- Phenomenon: The tool call module triggers both AI reply generation and next-level branch execution, resulting in information redundancy. Cause: The parallel execution logic of the workflow does not have branch isolation, and only a single path is not specified for execution.
- Phenomenon: The MySQL database plugin cannot display Chinese data, and no issue is resolved after all configuration adjustments. Cause: The character encoding of the database plugin is not configured as UTF-8, causing encoding conversion errors during data transmission.

## How to confirm the configuration is complete
- Initiate a test inquiry for real-time operating condition queries, check whether the tool call response time meets the preset timeout requirements.
- Trigger the tool call flow, confirm that only one of the AI final reply or tool call result is displayed, with no redundant output.
- Call the database plugin to query refinery and chemical material data containing Chinese, confirm that Chinese content is displayed normally.
- After enabling the Qwen2.5 tool call switch, initiate an inquiry that requires multi-tool linkage, confirm that the AI correctly selects and calls preset tools.

The values provided are common starting points and should be measured against the reader's own samples.
