# Work Consultation and Response for Refinery and Chemical Production: Forms and Interactions

## What Data for This Category Looks Like
Data related to work consultation and response for refinery and chemical production comes primarily from equipment distributed control systems (DCS), production daily reports, equipment operation and maintenance ledgers, safety inspection records, and internal work consultation application documents.
Data update rhythm falls into two categories: real-time process parameters sync every 10 seconds. Monthly summary reports update on the 1st of each month.
Document structure includes unique equipment ID, process operation parameters (with dedicated units such as ℃, MPa, m³/h), inspection time, abnormal alarm details, plus fields for work application documents including application ID, approval nodes, and completion time limit.

## Constraints Imposed by These Characteristics on the Forms and Interactions Link
High-frequency updates of real-time process parameters require form interactions to support dynamic loading of latest values. This prevents loading outdated process data.
Special unit fields need preset optional values. This stops format errors from manual input.
Multiple approval nodes for work application documents require forms to support step-by-step approval status display. Forms must also associate the permission scope of corresponding approvers.
Long-text abnormal alarm or process description content needs single input length limits. This avoids exceeding system processing limits.
Cross-department work forms must synchronize and associate data from multiple systems. Interaction links need to support automatic data backfilling. This reduces duplicate data entry.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Set maximum input length per single field to 8000 characters; bind preset unit options for numeric fields | Adapt to long text requirements for refinery and chemical production process descriptions and abnormal alarms, avoid format errors |
| `userSelect` | Display approval node options grouped by department; preset 10 common work types | Match permission division for cross-department work in refinery and chemical production, reduce user selection errors |
| Form dynamic loading | Set trigger interval to 10 seconds; sync latest data only when the form is opened | Adapt to update rhythm of real-time process parameters; FastGPT v4.17.0 supports this trigger logic |
| Form submission timeout | Set to 600 seconds | Adapt to long approval cycle of refinery and chemical work processes, avoid premature interruption of submission |
| File upload limit | Maximum 1000 MB per file; support PDF and CAD drawing formats | Adapt to upload requirements for refinery and chemical operation and maintenance drawings and test reports |

## Three Common Misconfigurations
- Issue: An "input content exceeds limit" error appears when submitting a work form. Submission cannot be completed. Cause: No reasonable length limit is configured for `formInput` for refinery long-text process descriptions. The default threshold is too low.
- Issue: After calling a work form node in a workflow, subsequent approval transfer nodes do not trigger execution. Cause: Callback parameters are not correctly configured after form submission. The workflow cannot receive the form completion signal.
- Issue: An error indicating unsupported file format or parsing failure occurs when uploading CAD drawings for equipment maintenance. Cause: Common refinery and chemical production file formats such as CAD and PDF are not added to the form upload allowed list. Files are intercepted.

## How to Verify Successful Configuration
- Open the form configuration page. Check the maximum input length setting for `formInput`. Confirm it matches the common length of refinery process descriptions.
- Select the department grouping option for `userSelect`. Check that common work types display correctly with no omissions or incorrect classifications.
- Upload CAD-format operation and maintenance drawings. Confirm the file uploads normally and enters the parsing queue. No format interception prompts appear.
- Trigger the workflow to call the form node. Submit test data. Check that subsequent nodes execute as expected. Confirm the callback configuration takes effect.
