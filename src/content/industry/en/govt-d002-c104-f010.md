# Coal Chemical Industry Service Inquiry and Reply: Knowledge Base Retrieval and Recall

## What This Category’s Data Looks Like
Coal chemical industry service inquiry and reply data mainly comes from internal enterprise process specifications, safety operation regulations, government approval service guides, and historical ticket reply archives. There are two types of data update cycles: fixed documents are updated quarterly or annually alongside policy and process iterations, while real-time ticket data is added synchronously with user inquiries. Most documents are chapter-structured PDFs or structured forms. Fields include process parameters (units: MPa, ℃, t/h), approval process nodes, inquiry classification tags, and reply time limit requirements.

## What Constraints These Characteristics Impose on the Knowledge Base Retrieval and Recall Link
The multi-source mixing, structured parameters, and compliance requirements of coal chemical industry service inquiry data create multiple constraints for retrieval and recall. Chapter-structured PDFs and structured forms require retaining contextual associations during retrieval, to avoid retrieving disconnected process fragments. Process parameter fields with units need precise matching of entities and units, to prevent incorrect replies caused by parameter confusion. The difference in update cadence between real-time tickets and fixed documents requires distinguishing trigger logic for incremental synchronization and full updates. It also requires verifying the version compliance of retrieved documents, to ensure the latest versions of approval and safety regulations are returned.

## How to Configure Settings
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | Coal chemical industry process parameters and compliance documents have high precision requirements. A setting that is too low will introduce irrelevant content, while a setting that is too high may miss valid compliance fragments |
| `limit` | Top 8 entries | Valid replies for service inquiries usually focus on a small number of relevant fragments. Too many entries will exceed the context window limit |
| `searchMode` | hybrid | Combines keyword matching and semantic retrieval, adapting to mixed queries of structured parameters and natural language inquiries |
| `usingReRank` | Enabled | Coal chemical industry documents have strong professionalism. Reranking can filter low-relevance non-professional fragments and improve reply accuracy |
| `datasetSearchUsingExtensionQuery` | Enabled | Service inquiries often involve abbreviations or industry terms. Extended queries can cover more professional documents |
| `collectionIds` | Specify by business group | Coal chemical industry needs to distinguish three types of knowledge bases: process, safety, and approval, to avoid retrieving irrelevant content across categories |

## Three Common Mistakes
- When calling the conversation interface, the associated knowledge base ID is not returned, and only general reply content is displayed. Cause: The retrieval knowledge base set is not limited via `collectionIds`, and the system does not mark the source identifier of retrieved content, making it impossible to trace the specific referenced knowledge base.
- After uploading a scanned PDF of a service guide, retrieval fails to match valid text fragments. Cause: OCR text extraction configuration is not enabled. Only the binary data of the scanned image is parsed, and no retrievable text blocks are generated.
- After a business system adds a knowledge base via the interface, the front-end retrieval returns no corresponding results. Cause: Retrieval is initiated before knowledge base vector generation and synchronization are completed, or the `collectionIds` of the newly added knowledge base are not specified in the retrieval request, so the retrieval scope does not cover the newly added content.

## How to Confirm the Configuration Is Properly Set
- Initiate a test query, verify that the returned results include preset coal chemical industry process parameters and compliance document fragments, and confirm that the retrieval scope matches the `collectionIds` configuration.
- View the retrieval log, confirm that the actual effective values of the `similarity` and `limit` parameters match the configured values, with no abnormal truncation or low-relevance content.
- Upload a test scanned PDF, verify that the system automatically completes OCR recognition and generates retrievable text blocks, and confirm that the reranking and extended query functions work properly.
- Call the conversation interface, check whether the returned results include the associated knowledge base identification field, and confirm that the source tracing function works normally.
