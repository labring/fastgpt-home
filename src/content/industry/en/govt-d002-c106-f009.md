# Coal-Electric Integration: Service Inquiry and Reply - Model Integration and Configuration

## What the Data for This Category Looks Like
Business data for coal-electric integration comes from internal business systems including mine production management systems, power dispatching platforms, coal purchase and sales ledgers, and environmental monitoring terminals. Update rhythms fall into three categories:
- Real-time operating metrics such as coal output and power generation load are updated every second
- Static ledgers such as mine qualifications and equipment archives are updated daily
- Purchase, sales and compliance documents are updated on demand

Most documents use structured fields, including mine ID, coal output (unit: ton), power generation load (unit: megawatt), daily coal consumption (unit: ton), environmental emission indicators (unit: mg/cubic meter), and more. A single monthly scheduling report can reach tens of thousands of characters in length.

## What Constraints Do These Characteristics Impose on Model Integration and Configuration
The characteristics of coal-electric integration data impose multiple constraints on model integration and configuration.
First, the data includes second-level updated real-time metrics and on-demand updated compliance documents. The configuration must support knowledge base slices with different update frequencies to avoid data lag affecting the accuracy of inquiry replies.
Second, the fields include professional business units. The model must accurately recognize units and business meanings, and the configuration must match the understanding needs of the business scenario.
Third, single monthly scheduling reports can reach tens of thousands of characters. This easily exceeds the model's default context limit, so relevant parameters need to be adjusted appropriately.
Fourth, the data involves production safety and compliance. The API endpoints and key configuration for model calls must comply with the data security access specifications of state-owned enterprises and public institutions.

## How to Set the Configuration
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `AIPROXY_API_ENDPOINT` | Fill in the official proxy endpoint of the corresponding model platform | Adapt to cross-platform model integration, comply with network security access requirements for state-owned enterprises and public institutions |
| `AIPROXY_API_TOKEN` | Fill in the valid access key of the corresponding platform | Ensure identity verification for model calls, comply with data security specifications |
| `maxContext` | 8000–12000 characters | Adapt to the average length of coal-electric integration business documents, avoid context overflow |
| `maxTokens` | 4000–6000 | Limit the number of tokens in a single reply, avoid generated content exceeding business requirements |
| `quoteMaxToken` | 2000–3000 characters | Limit the total length of referenced knowledge base content, ensure a reasonable ratio between context and reply |
| `toolChoice` | auto | Support AI to automatically identify required tools, adapt to inquiry needs of multiple business scenarios |
| `temperature` | 0.3–0.5 | Reduce the randomness of replies, ensure the accuracy and standardization of business replies |

## Three Common Misconfigurations
- Model calls return a 401 status code, or prompt "no access permission". `AIPROXY_API_TOKEN` is not configured correctly, or the key has expired and become invalid.
- Coal-electric integration business documents uploaded during conversations cannot be processed correctly, and a context overflow error occurs. The `maxContext` parameter is not adjusted based on the average length of business documents, and the parameter value is too small.
- AI cannot automatically identify required tools, and the reply content does not match business requirements. `toolChoice` is not set to auto, or a fixed tool call mode is configured.

## How to Confirm the Configuration Is Complete
- In the FastGPT v4.17.0 environment, test calling the configured model, enter inquiry questions related to coal-electric integration business, and check whether the returned results include correct business fields and units.
- Upload a typical coal-electric integration monthly scheduling report document, verify that document slicing and context loading work normally, with no overflow errors.
- Enable the automatic tool call function, enter inquiry questions that require tool calls, and check whether the AI can automatically match and call the corresponding tools.
- View the model call log to confirm that there are no format errors in the configuration of `AIPROXY_API_ENDPOINT` and `AIPROXY_API_TOKEN`.
