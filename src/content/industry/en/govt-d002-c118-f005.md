# Administrative Consultation and Response for Metal Material Processing: Tool Calling and Plugins

## What the data for this category looks like
The administrative consultation data for metal material processing originates primarily from internal industry process standard libraries, quality inspection report archives, and government service workflow guides. Data updates are adjusted when new national or industry specifications are released, and alongside quarterly routine inspection results. Most individual documents are structured entries, with fields including material grade, tensile strength, yield strength, heat treatment process parameters, administrative approval nodes, and required submission material lists. Units follow internationally adopted industrial standards, such as MPa, mm, hours, and similar units.

## What constraints these characteristics impose on the tool calling and plugins workflow
The large number of structured fields and strict industrial unit requirements mean that parameter matching for tool calls must precisely correspond to preset field names. Otherwise, the correct corresponding data cannot be returned. Data from multiple sources is stored separately in process standard libraries, quality inspection archives, and government service systems. Multiple independent tool calling entry configurations are required to connect to different data sources respectively. Administrative consultation often involves parameter queries targeting specific material grades. Tool calls must support precise filtering and recall of results by grade to avoid returning irrelevant content.

## Three common configuration errors
- Symptom: The tool call is not executed after triggering. The AI directly answers the question using natural language, and the interface log shows that the `toolChoice` parameter is not effective. Cause: The `toolChoice` parameter is not correctly set to `auto` or forced call mode, so the AI does not trigger the tool call logic.
- Symptom: The Doc2x plugin fails to recognize structured process parameter fields when processing uploaded metal material processing corpus. Cause: No industrial domain field mapping rules are specified in the plugin configuration, so the plugin cannot accurately extract core fields such as grade and mechanical properties.
- Symptom: Inconsistent units appear in tool call return results, and unit conversion errors occur for some parameters. Cause: No unit verification rules are configured for the plugin, and the industrial standard unit system for metal material processing is not strictly matched.

- Submit a consultation question containing a specific material grade, check whether the corresponding tool is triggered in the tool call log, and confirm that the `toolChoice` parameter is effective.
