# Real Estate Registration Ledger Summary and Report Generation: Document Parsing and Chunking

## What This Category's Data Looks Like
Data sources for this category include real estate registration information systems, cadastral survey databases, housing transaction online signing systems, tax systems, and electronic certificate repositories. The update frequency is daily. Commonly processed documents cover registration applications, ownership certificates, surveying and mapping results, tax payment vouchers, real property certificates, registration books, and more. Fields include location, building area, right type, ownership restriction status, and others. Units comply with general real estate registration specifications. Document formats vary across source systems, and some certificate documents have fixed layouts.

## What Constraints Do These Characteristics Impose on the Document Parsing and Chunking Link
Cross-system, multi-source data leads to significant differences in document formats. There are both structured electronic certificate documents and unstructured surveying and mapping descriptions and handwritten correction materials. This requires parsing tools to have format adaptive capabilities. The daily updated business rhythm requires the parsing process to have sufficient throughput to avoid slowing down the ledger summary cycle. Core fields of different documents have different priorities. For example, the right type field of real property certificates must be extracted first. Chunking rules must match the inherent structure of the document. Fields such as ownership status directly affect the accuracy of registration results. The parsing link must ensure that key information is not missing or incorrect.

## Configuration Settings
This setup is compatible with FastGPT v4.17.0. The following configuration items and recommendations are provided:
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Real estate registration documents include short-field certificate text and long-paragraph surveying and mapping descriptions. This range balances field integrity and chunking granularity |
| `chunkSplitter` | Split by title + paragraph | Most business documents have clear chapter titles and paragraph divisions. This splitting method preserves the logical structure of the document |
| `customPdfParse` | Enabled | Documents such as real property certificates and surveying and mapping results have fixed layouts. Custom parsing can accurately extract core fields and embedded information |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Single surveying and mapping result files may reach large sizes. This value covers the file size limits of most business scenarios |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Large PDF documents take longer to parse. This setting prevents parsing failures due to timeouts |
| `chunkSettingMode` | Manual mode | Adjustments to chunking rules are required for different document types such as certificates and surveying and mapping materials. Manual mode enables fine-grained configuration |

## Three Common Configuration Mistakes
- Scenario: When uploading a publicly shared Yuque web link related to real estate registration, the system prompts that the data source type is unsupported. Cause: No custom web parsing rules are configured, and the publicly shared Yuque link does not have open structured data reading permissions.
- Scenario: When parsing PDF-format real property certificates or surveying and mapping results, embedded images such as cadastral maps and surveying boundary maps are not extracted into the chunked text. Cause: The image extraction switch for custom PDF parsing is not enabled. The default parsing only extracts plain text content.
- Scenario: When batch uploading multiple large-volume surveying and mapping result PDFs, some files trigger timeout errors during parsing. Cause: The set value of `PARSE_FILE_TIMEOUT_SECONDS` is too small, and does not match the actual parsing time of large files.

## How to Verify Successful Configuration
- Upload a single real property certificate PDF, and check whether the chunked results include core business fields such as location, right type, and ownership restriction status.
- Upload a single large-volume surveying and mapping result PDF, and verify that the parsing time does not exceed the set value of `PARSE_FILE_TIMEOUT_SECONDS`.
- Upload a compliant publicly shared Yuque link, and confirm that the data source is parsed successfully and the content is complete without missing items.
- Check that the total size of uploaded files does not exceed the set value of `UPLOAD_FILE_MAX_SIZE` to avoid being intercepted by the system.

The values provided here are common starting points and should be measured against the reader's own samples.
