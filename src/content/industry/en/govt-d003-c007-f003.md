# Ledger Summary and Report Generation for Petition Matter Handling: Multi-turn Dialogue and Prompts

## What This Category of Data Looks Like
Data sources for this category include the national petition information system, local petition systems, the 12345 citizen hotline, grassroots governance platforms, and historical petition archives. The update frequency is daily.
Daily generated documents include petition registration forms, acceptance notices, transfer and assignment letters, handling opinions, review and recheck applications, and resolution plans.
Data fields cover request subjects, matter content, acceptance status, handling progress, responsible units, completion deadlines, and similar items. Common units are matter entries, time nodes, and personnel identification types.

## What Constraints Do These Characteristics Impose on the Multi-turn Dialogue and Prompts Link
Data sources are scattered and updated daily. Multi-turn dialogue must pull the latest data from different systems in sequence to avoid outdated information.
There are diverse document types. Prompts must adapt to field extraction rules for different documents such as petition registration forms and handling opinions.
Request screening and handling opinion formation are core time-consuming steps. Multi-turn dialogue must guide users to supplement key information to reduce manual intervention.
Data fields include request subjects, handling progress, and similar items. Prompts must clarify the priority of field extraction to ensure the completeness of the summarized ledger.

## How to Set Up Configurations
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Context window size | 8000–12000 token | Adapts to fields and content of multiple petition documents, avoids information truncation |
| `variables` variable configuration | Bind petition matter ID, responsible unit name | Pull corresponding ledger data from systems, reduces manual input |
| `messages` historical dialogue delivery | Retain 30 days of conversation records | Covers the full process of petition matter handling, connects multi-turn interactions |
| `chatId` session identifier configuration | Bind unique petition matter number | Accurately associate with the corresponding ledger, avoids mixing session data |
| Multi-turn dialogue trigger rule | Trigger based on matter keywords entered by users | Accurately locate the corresponding petition ledger, avoids loading irrelevant data |
| Timeout setting | 600 seconds | Adapts to the time spent pulling data across systems, avoids session interruption |

## Three Common Misconfigurations
- Symptom: The dialogue link cannot obtain the petition matter ID output by code running, and the corresponding field is empty. Cause: The `variables` variable is not correctly bound to the parameters passed by the system, and the variable source is not declared in the configuration.
- Symptom: Calling the dialogue interface returns the unAuthChat error, even though the apikey is configured correctly. Cause: The correct system-level permission parameters are not bound in the session configuration, resulting in identity verification failure.
- Symptom: The ledger summary result generated by multi-turn dialogue omits part of the petition document content. Cause: The context window is set too small, truncating key fields of long documents, causing the prompt to fail to extract information completely.

## How to Confirm Successful Configuration
- Manually enter a test petition matter ID, check whether the `variables` variable can correctly pull the corresponding ledger data.
- Initiate a test session containing historical dialogue, confirm that the `messages` parameter can fully deliver 30 days of interaction records.
- Trigger multi-turn dialogue, check whether petition data from the corresponding system is pulled according to preset rules, with no irrelevant content mixed in.
- Run a timeout test, confirm that the session completes data pulling and summary within 600 seconds, with no abnormal interruptions.
