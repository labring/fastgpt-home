# Ledger Summary and Report Generation for Highway Maintenance and Road Property and Road Right Management: Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
Daily documents for this category include maintenance plans, patrol logs, defect disposal forms, road construction permits, and road damage compensation forms. Data sources include highway maintenance management systems, bridge and tunnel monitoring systems, road patrol systems, and traffic flow monitoring data. The update frequency is daily.

Document structures include both structured forms and unstructured logs, with fields such as section identifier, defect type, disposal status, and permit number. There is no fixed unified format, so the setup must adapt to multi-source heterogeneous data indexing requirements.

## Constraints Imposed on Knowledge Base Retrieval and Recall
Business data from multiple connected systems requires the retrieval pipeline to support unified field mapping across data sources, to prevent missing fields or format confusion in retrieval results. The daily update frequency requires the retrieval engine to support high-frequency incremental synchronization, to ensure the timeliness of recalled data. Mixed document types require the retrieval mode to support combined matching of structured and unstructured content, to cover all types of business documents.

The strong correlation between road property and maintenance data means recalled results must include full-link information for sections, defects, and disposal work, to avoid information gaps during ledger summary and report generation caused by fragmented data.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Matches the mixed retrieval needs of highway maintenance documents, balances recall precision and recall volume, and avoids irrelevant content being included in ledger data |
| `limit` | Top 8–12 entries | Covers multi-type document data required for a single ledger summary, while controlling the total context length to avoid exceeding model input limits |
| `searchMode` | Hybrid retrieval | Adapts to free text in patrol logs and structured fields in disposal forms, improving recall accuracy across different document types |
| `usingReRank` | Enabled | Performs secondary ranking on initial recall results, prioritizing content with higher relevance to sections, defects, and road property |
| `datasetSearchUsingExtensionQuery` | Enabled | Expands query terms based on highway maintenance professional terminology, improving retrieval matching accuracy for exclusive terms such as defects and road construction |
| `collectionIds` | Configured according to actual business collections | Limits the retrieval scope to exclusive knowledge base collections for highway maintenance and road property and road right management, excluding other irrelevant business data |

## Common Mistakes
Three frequent errors:
- Retrieval response timeout, with logs showing excessive retrieval latency. This occurs when a reasonable `limit` value is not set for daily high-frequency updated data, leading to loading too many redundant documents during retrieval.
- Unconfigured gpt-4o-mini invocation errors triggered by workflow runs. This happens when automatic sub-model invocation associated configurations are not disabled, or when knowledge base retrieval results are not properly truncated, causing context overflow that triggers additional invocations.
- Automatically deleted directories or duplicate content in uploaded knowledge base documents. This occurs when document automatic cleaning configurations are not disabled, or when the upload option to retain original formatting is not selected.
