# Engineering Construction Project Approval Ledger Summary and Report Generation: Knowledge Base Retrieval and Recall

## What this category of data looks like
This category of data originates from engineering construction project approval management systems, construction drawing review systems, enterprise qualification databases, and credit platforms. It updates once daily. Daily documents include construction permit applications, construction drawing review qualification certificates, quality and safety supervision procedures, and completion acceptance record forms. Data fields include project unique identifiers, participating unit qualification information, approval node status, record material numbers, and other relevant fields. It adheres to government approval standard formats, with no custom unit fields.

## Constraints on knowledge base retrieval and recall
This category of data updates daily. Knowledge base synchronization frequency must match this daily update rhythm to avoid recalling expired approval materials. Multiple types of structured documents are mixed. Retrieval logic must differentiate between data types such as construction permit applications and completion acceptance records to prevent cross-type result confusion. Data comes from multiple systems. Labels must be used to define boundaries between each dataset to ensure precise retrieval scope. Participating unit qualification information and approval node status are core retrieval items. Matching subdivided fields improves recall accuracy.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | Engineering approval documents have standardized structures. This range filters irrelevant results while retaining valid approval materials, preventing invalid information from being included in ledger summaries. |
| `limit` | `Top 8–12 results` | Ledger summaries require full coverage of relevant approval nodes. This range balances recall completeness and processing time, avoiding excessive results that increase summary workload. |
| `searchMode` | Hybrid vector + keyword | Government documents have both structured fields and text descriptions. Hybrid mode enables accurate matching of fields such as approval numbers and qualification names, as well as semantic recall of approval process description content. |
| `usingReRank` | Enabled | After multi-source data mixed recall, reranking optimizes result ordering. It ensures core approval materials such as construction permit applications and completion acceptance record forms appear first, facilitating ledger summarization. |
| `datasetSearchUsingExtensionQuery` | Enabled | Approval-related questions use standardized phrasing. Optimization expands retrieval scope to cover synonymous terms such as "completion record" and "completion acceptance record", avoiding missing relevant documents. |
| `collectionIds` | Bind exclusive dataset ID for engineering construction approval categories | Precisely limits retrieval scope, prevents non-approval data from credit platforms from being included, and ensures recall results meet business requirements. |

## Three Common Configuration Mistakes
- Symptom: Retrieval results include non-engineering construction approval documents, with empty fields. Cause: Failed to limit retrieval dataset scope via `collectionIds`, and failed to configure filtering rules for target documents.
- Symptom: Incomplete recall results for queries about "participating unit qualifications". Cause: Failed to enable `datasetSearchUsingExtensionQuery` to optimize retrieval terms, and failed to cover synonymous expressions for qualification-related terms, leading to some relevant documents not being recalled.
- Symptom: No results returned when retrieving image-based approval materials in a local deployment version. Cause: Failed to enable the corresponding image understanding model, and failed to configure image retrieval support for the target dataset.

- Test queries using synonymous phrasing such as "completion record form", confirm that documents related to completion acceptance can be recalled, and verify that `datasetSearchUsingExtensionQuery` is active.
