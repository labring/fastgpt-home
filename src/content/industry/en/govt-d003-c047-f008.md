# Ledger Summary and Report Generation for Administrative Penalty Case Handling: Document Parsing and Chunking

## What this category of data consists of
Data for this category comes from administrative law enforcement case handling systems, law enforcement recorder footage, the national enterprise credit information publicity system, and departmental supervision databases of law enforcement agencies including market supervision, ecological environment, transportation, emergency management, and urban management. The update frequency is daily.

Commonly processed documents include on-site inspection records, interrogation records, evidence lists, prior administrative penalty notification letters, hearing notification letters, penalty decisions, and service receipts. These documents contain business fields such as law enforcement subject, illegal facts, penalty basis, penalty content, and service recipient. Some documents have attached image or picture-related materials.

## Constraints on Document Parsing and Chunking
Law enforcement documents have both structured headers and free-form text. Parsing workflows must preserve full evidence chain association. They must distinguish between fixed fields and free paragraphs to avoid splitting core business information.

Data from multiple sources has varying formats. Systems must support different types of uploaded files.

Daily updated business data requires parsing processes to have sufficient response speed, to avoid affecting the timeliness of ledger summary.

Errors in case handling have serious consequences. Parsing links must ensure accuracy, to reduce loss of key information caused by chunking errors.

## How to Set Configurations
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 characters | Adapts to the single-paragraph text length of law enforcement documents, avoiding splitting core business content such as illegal facts and penalty decisions |
| `chunkSplitter` | Paragraph + semantic chunking | Matches the paragraph structure of law enforcement documents, preserving the logical integrity of records and notification letters |
| `customPdfParse` | Enable structured parsing mode | Adapts to documents with fixed headers such as administrative penalty decisions, extracting key fields including law enforcement number and penalty content |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Addresses parsing time for multi-page case files, avoiding parsing failure due to timeout |
| `UPLOAD_FILE_MAX_SIZE` | 100 MB | Adapts to the size of multiple law enforcement case documents uploaded in a single batch |
| `chunkSettingMode` | Manual configuration | Adjusts chunking rules for the fixed structure of law enforcement documents, meeting business field requirements |

## Three Common Misconfigurations
- Copy function prompts an error and PDF download fails. Symptoms: The interface displays "Unable to use browser automatic copy, please manually copy the content below", and the PDF generation API call returns a timeout. Cause: The `PARSE_FILE_TIMEOUT_SECONDS` parameter is not adjusted. Large administrative penalty case documents cause parsing timeout, making it impossible to generate download files.
- Specific format image files fail to parse. Symptoms: When uploading image files exported from law enforcement recorders, the parsing status shows failed, and the log returns a service connection error. Cause: The parsing adapter for the corresponding law enforcement image format is not configured, and only the general document parsing mode is enabled.
- Knowledge base images cannot be retrieved. Symptoms: Upload on-site inspection records with attached image links, and no image-related content is returned during Q&A testing. Cause: Image parsing configuration is not enabled, and text descriptions or link information of images are not extracted during chunking.

## How to Confirm Proper Configuration
- Upload a single administrative penalty decision document, check the parsed chunk results, and confirm that core fields such as law enforcement number and illegal facts are not split.
- Upload multiple consecutively numbered law enforcement case files, check whether the association identifiers of the case files are retained after chunking.
- Trigger the copy or PDF download function, confirm that the prompt message no longer appears, and the downloaded file can be opened normally.
- Upload an on-site inspection record containing images, confirm that the parsed result includes the text description or link field of the image.

The values listed here are common starting points and should be evaluated against the user’s own samples.
