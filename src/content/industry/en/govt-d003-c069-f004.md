# Hazardous Chemicals Storage and Transportation: Ledger Summary and Report Generation - Workflow Orchestration
This page is written based on FastGPT v4.17.0.

## What the data for this category looks like
Ledger data for hazardous chemical storage and transportation comes from tank farm DCS systems, inbound and outbound loading and unloading records, daily inspection systems, and safety compliance filing platforms. Data updates in real time after each loading and unloading operation completes. Daily inspection ledgers are updated per shift. A single ledger document includes fields such as hazardous chemical name, specification model, storage tank number, inbound quantity, outbound quantity, remaining inventory, inspection date, responsible person, compliance check status, and more. Units include tons, cubic meters, kilograms, batch numbers, safety filing numbers and other exclusive identifiers.

## What constraints do these characteristics impose on workflow orchestration
Ledger data from multiple sources requires configuring parallel nodes in workflow orchestration to pull raw data from different systems. This avoids delays and incomplete data caused by single-node pulls. Real-time updated loading and unloading data requires binding real-time events to workflow trigger conditions. Pair this with a 2-hour scheduled supplementary pull task to cover scenarios where events are not triggered at night. This prevents statistics from lagging behind actual operations. Exclusive fields such as safety filing numbers and tank numbers require strict matching of the original naming of data sources during field mapping. This avoids missing or chaotic ledger data caused by field mismatches. The compliance check link must be embedded in the workflow. It automatically checks inventory thresholds and inspection results to meet regulatory requirements for hazardous chemical storage and transportation.

## How to Configure Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Trigger Mode | Bind loading/unloading completion events + 2-hour scheduled supplementary pull for inspection data | Matches the requirements for real-time updates and scheduled completion of hazardous chemical storage and transportation data, avoids missing inspection data not synchronized in time during night shifts |
| `variables` mapping rules | One-to-one correspondence according to data source field names, only retain required ledger fields | Avoids chaotic ledger data caused by field mismatches, meets standardized requirements for hazardous chemical ledgers |
| Single pull data volume | Top 100 records | Adapts to the volume of single-batch ledger data, avoids single request timeouts |
| Check node threshold | Trigger an alert when remaining inventory deviation exceeds 5 tons | Matches the safety threshold for hazardous chemical inventory control, prevents overstocking or stock shortages |
| Workflow timeout setting | 600 seconds | Addresses time requirements for pulling and checking data from multiple data sources, avoids task interruptions |

## Three Common Configuration Mistakes
- Phenomenon: The front-end interface freezes when dragging the `variables` configuration node, and returns to normal after deleting the variable configuration. Cause: No pagination loading for fields mapped by `variables`, rendering a large number of hazardous chemical exclusive fields at the same time causes excessive front-end resource usage.
- Phenomenon: Uploaded ledger files cannot be read by workflow nodes, with a prompt that the file path does not exist. Cause: Did not confirm the storage directory of the uploaded file, directly using the default path causes the node to fail to locate the file.
- Phenomenon: The safety filing number field is empty in the generated report. Cause: Failed to match the safety filing number field in the data source during `variables` mapping, causing mapping failure due to inconsistent case or spelling of field names.

## How to Confirm the Configuration Is Complete
- Trigger a test workflow, check if the pulled data includes all preset hazardous chemical ledger fields.
- Simulate a loading/unloading operation event, confirm that the workflow automatically triggers and completes data pulling and checking.
- Check the generated report format, confirm that field units are consistent with standard units for hazardous chemical storage and transportation ledgers.
- View workflow logs, confirm there are no error messages about timeouts or field mapping failures.
