# Ledger Summary and Report Generation for State-owned Industrial Funds: Workflow Orchestration

Reference only; verify against the target FastGPT release and deployment documentation.

## What the data for this category looks like
Ledger data for state-owned industrial funds mainly comes from the investment decision management system, account statements from custodian banks, and monthly operation and contribution submission documents from invested enterprises. Update cycles are divided into daily (custodian account statements), monthly (invested enterprise submissions), and quarterly (post-investment evaluation summaries). Each ledger document includes fields such as fund code, invested entity name, contribution/repayment amount, arrival date, project phase, and custodian bank name. Amount units are mostly ten thousand yuan or yuan, the date format is YYYY-MM-DD, and project phases use fixed enumeration values.

## What constraints these characteristics impose on workflow orchestration
Multi-source data has inconsistent units and field names, so the workflow must be configured with unified format validation and field mapping nodes to avoid data errors during aggregation. Data sources with different update frequencies require corresponding trigger rules: daily updated statements need scheduled triggers, and temporarily submitted ledgers need manual trigger support. There are many ledger fields, and the statistical dimensions are fixed as fund code and cycle, so the workflow must have built-in grouping and aggregation rules to ensure that summary data meets the disclosure requirements of state-owned assets supervision.

## Configuration Settings
| Configuration Item | Recommended Setting | Basis for This Setting |
| --- | --- | --- |
| Trigger Mode | Trigger according to the update cycle defined by `variables`, perform full synchronization at 2 AM daily, manually trigger temporary summary tasks | Based on the daily update and temporary submission requirements of ledger data |
| Data Cleaning Rules | Unify the amount unit to ten thousand yuan, complete missing custodian bank fields | Based on the format differences and field integrity requirements of multi-source data |
| Aggregation Configuration | Group by fund code, aggregate total contribution and repayment amounts by quarter | Based on the statistical and disclosure cycles of state-owned industrial funds |
| Timeout Threshold | 600 seconds | Based on the actual situation that the single processed ledger data volume is large |
| Problem Optimization Component | Place after the data cleaning node | Based on the logic that data format correction must be completed before prompt optimization |
| Report Template Call | Bind the preset state-owned industrial fund report template, replace core fields in `variables` | Based on the standardization requirements of report generation |

## Three Common Errors
- Phenomenon: Workflow nodes show failures, while the model backend has normal response logs. Cause: The delivery path configuration of `variables` in the workflow is incorrect, and the output of the data source is not correctly bound to the input parameters of downstream nodes.
- Phenomenon: Some fields in the generated report are empty, and aggregated data has missing entries. Cause: The field mapping rules of the data cleaning node are not configured, and mismatched field names of multi-source data lead to aggregation failure.
- Phenomenon: The problem optimization component does not take effect, and the generated report does not meet format requirements. Cause: The problem optimization component is placed after the report generation node, and format correction and rule alignment are not performed on the input ledger data first.

## How to Confirm Correct Configuration
- Manually trigger the workflow once, check the execution logs of each node, and confirm that the field values in `variables` have been correctly passed to downstream nodes.
- Check the output results of the data cleaning node, and confirm that the amount units of multi-source data have been unified to ten thousand yuan, and missing fields have been completed.
- View the aggregated ledger data, confirm that grouping and aggregation have been completed according to fund code and quarter, and the statistical results meet expectations.
- Generate a test report, confirm that the `variables` fields in the report template have been correctly replaced, and the content conforms to the preset format.
