# State-owned industrial fund ledger aggregation and report generation: Deployment and upgrade

## What the data for this category looks like
Ledger data for state-owned industrial funds mainly comes from the fund investment management system, investment decision approval system, post-investment monitoring platform, and state-owned assets supervision reporting interface. Data updates are divided into daily incremental updates and monthly full synchronization. A single ledger document includes fields such as fund entity name, investor entity, total subscribed capital, cumulative paid-in amount, list of invested enterprises, single investment amount, and exit node flag. Most field units are ten thousand yuan or hundred million yuan, and some flag fields are boolean values or strings.

## What constraints these characteristics impose during deployment and upgrade
Multi-source data access requires configuring multiple database connections during deployment to adapt to different system formats. Large-volume data from monthly full synchronization places requirements on the storage capacity of `MONGODB_URI` and the connection pool limit of `DB_MAX_LINK`. The nested structure of the invested enterprise list requires adapting layered fields during data parsing to avoid index interruptions. For intranet deployment scenarios, cross-domain access restrictions of the state-owned assets supervision interface require configuring intranet mapping and security whitelists. During upgrades, the original interface adaptation logic must be retained to avoid interrupting monthly reporting tasks.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `DB_MAX_LINK` | 100–150 connections | Adapts to concurrent connection requirements of multi-source databases during monthly full synchronization, preventing task interruption caused by exhausted connections |
| `MONGODB_URI` | mongodb://user:pass@host:port/fastgpt?authSource=admin&maxPoolSize=120 | Stores ledger nested fields and historical report data, with connection pool size matching the `DB_MAX_LINK` configuration |
| `PG_URL` | postgresql://user:pass@host:port/fastgpt?sslmode=disable | Stores structured ledger fields and user operation logs, adapting to precise queries for relational data |
| `REDIS_URL` | redis://:pass@host:port/0?maxmemory-policy=allkeys-lru | Caches temporary data for ledger incremental updates and session context, reducing repeated database query overhead |
| `STORAGE_S3_ENDPOINT` | Configured according to intranet storage nodes | Stores generated report files and large-volume ledger snapshots, adapting to secure access requirements for intranet deployments |
| `ROOT_KEY` | Randomly generated 32-character string | Configures the system administrator permission verification key, ensuring access security for ledger data |

## Three common mistakes
- Ledger indexing tasks remain in pending state after container startup. The cause is that `REDIS_URL` is not configured correctly, preventing temporary cache writes and blocking incremental update tasks.
- No ledger aggregation output content appears in the conversation results after calling the orchestration interface. The cause is that the structured query results associated with `PG_URL` are not correctly bound to the output node, resulting in unextracted data.
- Unable to connect to the state-owned assets supervision data source after upgrade. The cause is that the original intranet mapping configuration for `STORAGE_S3_ENDPOINT` was not retained, causing storage and interface access permissions to fail.

## How to confirm the configuration is correct
- Access the FastGPT v4.17.0 system settings page, and check that the parameter values of core configuration items such as `DB_MAX_LINK` and `MONGODB_URI` match the preset configurations.
- Execute a manual ledger incremental synchronization task, and check that there are no connection timeout or data parsing error prompts in the task logs.
- Initiate a ledger aggregation report generation request, and confirm that the generated report files can be downloaded normally through the specified storage path.
- Test the state-owned assets supervision interface call in the intranet environment, and confirm that there are no access permission error messages, and the interface returns data format matching the preset structure.

The values given are common starting points and should be measured against the reader's own samples.
