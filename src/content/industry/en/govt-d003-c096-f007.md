# Non-ferrous Metal Smelting Ledger Aggregation and Report Generation: Database and Operations

## What this type of data looks like
Data sources for non-ferrous metal smelting ledger data include process parameters collected on-site by PLC, raw material consumption records from the batching system, test reports from the quality control laboratory, and finished product inbound and outbound data from the warehouse system. Process parameters update in real time every second, raw material consumption and test data update per production shift, and inbound and outbound data updates daily. Each single ledger document includes fields such as batch identifier, associated raw material batch, parameter values of each process node, test results, finished product output, inbound time, and others. Process parameter fields are mostly numeric, and test results and output fields come with clear units of measurement.

## What constraints these characteristics impose on the database and operations segment
Real-time second-level updates of process parameters require the database to support high-concurrency writes. Connection pools must be properly configured to avoid connection exhaustion. Mixed storage of real-time parameters, shift-level data, and daily-level data will cause uneven read and write pressure on a single data collection. Storage collections must be split by update frequency to optimize read and write performance. Ledger fields differ across various smelting types, so dynamic field mapping must be supported to prevent valid data from being filtered by hard-coded validation rules. The demand for batch writes of high-frequency real-time data requires adjusting the database's batch commit threshold to reduce single I/O overhead. The storage requirement for long-term historical ledger data requires configuring automatic archiving rules to reduce storage pressure and query latency of the online database.

## How to set the configurations
| Configuration Item | Recommended Value | Rationale |
|---|---|---|
| `MONGODB_URI` | `mongodb://admin:securepass@db1:27017,db2:27017/metal_smelting?replicaSet=rs1&readPreference=secondaryPreferred` | Non-ferrous metal smelting ledgers include both real-time and batch data. Replica set configuration improves read and write availability, and the read preference setting reduces load on the primary node |
| `DB_MAX_LINK` | `20–30` | A single deployment node must handle real-time parameter writes, ledger queries, and report generation tasks at the same time. This range balances connection usage and concurrency capabilities |
| `REDIS_URL` | `redis://:cachepass@redis-host:6379/0?maxmemory-policy=allkeys-lru&maxmemory=8000 MB` | Used to cache frequently queried process parameters and ledger aggregation results. Specifying a memory policy and upper limit prevents cache overflow |
| `PG_URL` | `postgresql://report_user:reportpass@pg-host:5432/smelting_report?sslmode=require` | Stores structured ledger aggregation report metadata. SSL configuration ensures security during cross-network transmission |

## Three common errors
- Symptom: After entering the FastGPT container, running `npm list` cannot display the mongoose version. A dependency declaration exists in package.json, but the application runs normally. Cause: FastGPT uses pnpm or yarn workspace mode for dependency installation. The `npm list` command only scans top-level dependencies in the current directory by default, and does not traverse sub-packages.
- Symptom: After configuring `DB_MAX_LINK` to a value exceeding the node's carrying capacity, the database connection pool is exhausted, and connection timeout errors occur. Cause: The connection number upper limit is not adjusted based on the deployment node's CPU and memory resources, causing the database to fail to handle concurrent connection requests.
- Symptom: Some fields are empty after ledger data is written, and complete reports cannot be generated. Cause: Flexible mapping rules are not configured for dynamic fields of non-ferrous metal smelting, and hard-coded field validation filters valid fields that are not preset.
