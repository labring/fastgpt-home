The data sources for this category are scattered, covering multiple document types including government policies, business circulation workflows, and public feedback. ## Three Common Misconfigurations
- Phenomenon: The `quoteMaxToken` configuration value is set too small, resulting in truncated returned citation content that cannot fully display the original policy basis. Cause: The parameter was not adjusted based on the actual length of 12345 citizen hotline ticket policy documents, leading to loss of key handling clauses.
- Phenomenon: The interface displays citations but the answer does not match the exclusive 12345 citizen hotline knowledge base content. Cause: The exclusive policy knowledge base was not bound to the corresponding workflow, and only the general knowledge base was called, making it impossible to recall the exclusive policy basis for this category.
- Phenomenon: Only citations from text datasets are recalled, and other types of data such as dispatch records and visit records are not associated. Cause: The recall configuration for multiple types of data sources was not enabled, and only the index for text datasets was activated, resulting in incomplete traceability coverage.
