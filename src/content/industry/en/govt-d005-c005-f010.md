# Policy and Regulatory Basis Q&A for Property Rights, Asset and State-owned Capital Management: Knowledge Base Retrieval and Recall

## What this category of data looks like
Data sources for this category include state-owned asset supervision information systems, enterprise asset management systems, property rights exchange systems, valuation institution reports and financial statements.
Daily documents cover property rights registration forms, asset evaluation reports, property rights transfer plans, on-site transaction announcements, and asset disposal approval forms.
Document structure includes fields such as ownership number, asset category, evaluation benchmark date, and approval node.
There is no unified fixed unit. Some fields must match the standardized format of state-owned asset supervision.
The update frequency is monthly.

## What constraints do these characteristics impose on knowledge base retrieval and recall
The monthly update requirement means knowledge base synchronization tasks must align with this rhythm. Data lag will reduce the accuracy of policy basis references.
Documents from multiple systems have large format differences, including structured tables and unstructured text. Retrieval logic must adapt to mixed-format recall.
Fields such as ownership number and approval order number have strong uniqueness. Prioritize matching these core fields during retrieval to avoid irrelevant results.
Documents related to asset disposal involve state-owned asset security. Recall results must include complete approval nodes and ownership certification materials. No critical information may be omitted.

## Configuration Specifications
These configuration rules apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Meets the strong relevance requirement for state-owned asset documents, avoids low-relevance results, and ensures accuracy of policy basis references |
| `limit` | Top 8 entries | Controls the number of single-recall results. Adapts to the long content length of property rights documents, preventing context overload |
| `searchMode` | semantic | For mixed structured and unstructured state-owned asset documents, semantic retrieval outperforms single keyword retrieval, covering professional term matching |
| `usingReRank` | Enabled | Performs secondary sorting on recall results. Prioritizes core content blocks containing ownership numbers and approval information, improving visibility of key policy basis |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands professional synonymous expressions in the state-owned asset field, covering terms such as "property rights transfer" and "on-site transaction", improving recall coverage |
| `collectionIds` | Assigned per the dedicated state-owned property rights and asset knowledge base | Limits retrieval scope, avoids interference from irrelevant knowledge base content, and ensures recall results only come from dedicated documents of this category |

## Three Common Mistakes
- When calling the API to retrieve asset disposal announcement images in the knowledge base, returned image links cannot display normally in third-party systems. The cause is incorrect configuration of the API return path for knowledge base attachments. The link format does not meet third-party system requirements.
- A "Cannot convert undefined or null to object" error pops up during workflow runtime. The cause is failure to correctly specify the `collectionIds` parameter during retrieval, or passing an invalid knowledge base ID. The system cannot locate the retrieval scope.
- When `limit` is set to 1500 characters, document blocks exceeding this length are still recalled and referenced. The cause is failure to enable automatic content truncation configuration, or a too-low `similarity` threshold. Low-priority long blocks may be included in recall results.

## How to Verify Proper Configuration
- Log in to the FastGPT admin backend, navigate to the knowledge base configuration page. Confirm that `collectionIds` is bound to the dedicated property rights, asset and state-owned capital management knowledge base, and no irrelevant datasets are included.
- Initiate a test retrieval. Enter a specific property rights number or asset disposal keyword. Check that the `similarity` scores of returned results fall within the 0.75–0.85 range.
- Upload a property rights transfer plan document exceeding 1500 characters. Test recall results. Confirm that document block truncation rules match the configuration, or that no unlimited recall occurs.
- Run the workflow bound to this knowledge base. Check for parameter error-related alerts. Confirm that parameters such as `collectionIds` and `similarity` are passed correctly.
