# Policy and Regulatory Basis Q&A for Medical Institution Supervision and Public Health Inspections: Vector Models and Indexes

## What This Category's Data Looks Like
The data for this category comes primarily from health supervision information systems, medical institution electronic registration systems, complaint reporting platforms, and law enforcement inspection records. Daily documents include supervision checklists, medical institution practice licenses, rectification notices, supervision opinions, and penalty case files.
Data updates occur monthly. Document structures cover structured qualification fields and unstructured law enforcement text. Fields include institution name, license number, rectification content, penalty reasons, and more. Units adjust dynamically based on document type.

## Constraints Imposed by These Characteristics on Vector Models and Indexes
Monthly updated data sources require indexes to support periodic batch synchronization. This eliminates tedious manual updates and oversights.
Mixed storage of multiple document types requires vector chunking strategies to adapt to length differences between short entries and long documents. This prevents semantic loss from chunks that are too small or too large.
Mixed structured qualification fields and unstructured law enforcement text requires indexes to balance precise matching of qualification numbers and semantic matching of law enforcement content. This raises precision requirements for similarity threshold settings.
Law enforcement data errors directly impact regulatory compliance. This requires recall result accuracy to meet basic regulatory verification standards.

## Configuration Settings
| Configuration Item | Recommended Range | Rationale |
|---|---|---|
| Chunk Length | 800–1200 characters | Covers the length range of short supervision checklist entries and long penalty case files, preserves complete semantic units |
| Overlap Length | 100–150 characters | Prevents cross-chunk law enforcement logic from being split, maintains semantic coherence of rectification workflows |
| Similarity Threshold | 0.75–0.85 | Balances demand for precise qualification number matching and semantic matching of law enforcement content, adapts to the rigor of regulatory verification |
| Single Search Limit | Top 20 results | Meets law enforcement personnel's need to review multiple related documents during verification |
| `defaultToken` | 8192 | Adapts to the context length of most law enforcement documents, avoids truncation of critical penalty reasons or rectification requirements |
| `maxToken` | 16384 | Covers the full context of long documents, supports semantic retrieval of complex penalty case files |

## Three Common Mistakes
- Phenomenon: No index is generated after calling the knowledge base interface to create a training order, or batch updates cannot be triggered after manually adding data to a collection. Reason: The logic for adding data to a collection and triggering training orders is confused. Training orders are used for batch synchronization of monthly updated health supervision system data. Single manual additions only apply to temporary small-batch text.
- Phenomenon: Retrieval results only return text content, and cannot recall associated image documents. Reason: Multimodal vector index configuration is not enabled, image files are not synchronized to the specified storage path of the knowledge base, or the embedding model adaptation for image vectorization is not configured.
- Phenomenon: The interface cannot select target embedding models such as Zhipu Embedding-3. Reason: The metadata of the corresponding model is not imported in FastGPT configuration, or the interface address and token parameters are not correctly configured when mapping the model via oneAPI.

## How to Confirm Proper Configuration
- Verify the knowledge base's data source configuration, confirm that specified data sources such as health supervision information systems and medical institution electronic registration systems are linked.
- Initiate a query containing a medical institution practice license number, verify that recall results include related documents such as supervision checklists and rectification notices.
- View the model configuration interface, confirm that the target embedding model has been loaded and can be selected normally.
- Trigger a training order, check that FastGPT v4.17.0's index update log has no abnormal errors.
