# Policy and Regulatory Basis Q&A for Territorial Spatial Planning Formulation and Implementation Evaluation: Multi-turn Dialogue and Prompt Engineering

## What the data for this category looks like
This category’s data mainly originates from the territorial spatial basic information platform, natural resource survey and monitoring data, population and economic statistics, and remote sensing images. It is updated annually. Commonly processed documents include territorial spatial overall plans, detailed plans, special plans, planning implementation evaluation reports, and public opinion summaries. These documents usually contain fields such as spatial boundaries, constraint indicators, and implementation progress, with units mostly in formats related to hectares, population counts, and project codes.

## What constraints these characteristics impose on the multi-turn dialogue and prompt engineering link
Data for this category comes from scattered sources and has a large volume, mostly combining structured spatial data and unstructured documents. The annual update requirement means dialogue contexts must be linked to planning data from the same year. In multi-turn dialogue, the `messages` field must be used to manage historical contexts, ensuring that each round of questions is associated with previous planning data, while also distinguishing different types of planning documents to avoid mixing up indicators across documents. In addition, public opinion summaries and special plans have significant content differences, so the dialogue flow must guide users to clarify the document type corresponding to the current Q&A. The `variables` parameter should be used to pass planning type and annual restriction conditions, to prevent calling expired or irrelevant territorial spatial data.

## How to configure the settings
This configuration explanation is based on FastGPT v4.17.0. The specific configuration items are as follows:

## Three Common Misconfigurations
- Chat history disappears after refreshing the conversation page, and the interface displays a new conversation. Cause: The `chatId` persistent storage configuration is not enabled, and the session context is not bound to the user session.
- The AI prompt indicates that no files have been uploaded, but planning documents have been bound in the system prompt. Cause: The document binding path in the system prompt is configured incorrectly, or the document is not associated with the current knowledge base.
- Cross-year planning data mixing occurs during multi-turn dialogue. Cause: The time range of the data is not limited in the prompt, and expired territorial spatial basic information platform data is recalled.

## How to Confirm Proper Configuration
- Initiate a question containing spatial planning terminology, and check whether the returned results are associated with the corresponding type of planning documents.
- Refresh the conversation page, confirm that the session record corresponding to `chatId` has not been cleared, and the previous conversation content is still visible.
- Adjust the time range of the question, verify whether the AI can accurately recall planning implementation evaluation data from the corresponding year.
- Upload a new special planning document, confirm that the system can correctly identify its document type and include it in the Q&A scope.
