# Policy and Regulatory Basis Q&A for Territorial Spatial Planning Formulation and Implementation Evaluation: Citation Sources and Traceability

## What this category’s data looks like
Daily documents for this category include territorial spatial master plans, detailed plans, special plans, planning implementation evaluation reports, public opinion summaries, and more. Data sources cover multiple spatial and non-spatial categories, such as the territorial spatial basic information platform, natural resource survey and monitoring data, population and economic statistics data, and remote sensing images.

Data updates occur annually. Document structures span multiple dimensions, including regional overall planning, plot-level detailed rules, special facility layout, and more. Fields include planning scope boundaries, constraint indicators, implementation nodes, public feedback opinions, and more. A single core document can cover tens of thousands to hundreds of thousands of characters.

## What constraints do these characteristics impose on citation sources and traceability
Multi-source, heterogeneous data sources require the citation traceability process to distinguish format and permission rules for different data sources. The annual update frequency requires that the latest annual data source documents be prioritized for matching in every Q&A session.

Multi-dimensional document structures and variable field content require citation traceability to accurately match the document type and field range corresponding to the Q&A question, avoiding invalid cross-document citations.

Long-text core documents require the citation extraction process to support accurate positioning of long fragments, while retaining the correspondence between cited content and the original document to ensure traceability accuracy.

## Three common configuration mistakes
- When accessing the application via a guest sharing link, the citation "view original text" function fails to work after configuration. The cause is that the citation traceability permission for guest access scenarios is not enabled in the application permission settings, preventing external access from triggering citation display.
- No citation identifier or jump entry appears at the end of answer paragraphs. The cause is that the configuration for the `detail` parameter is not enabled, or the `quoteMaxToken` value is set too small, causing citation fragments to fail extraction.
- Citation content loading times out. The cause is that the `quoteMaxToken` value is not adjusted based on document length, causing citation extraction for long documents to exceed the system default threshold.

## How to confirm the configuration is correct
- Submit a test question requesting policy basis information, check whether the answer includes clear citation source annotations at the end.
- Click the citation annotation, confirm that you can jump to the original text position of the corresponding document, and that the displayed document information matches the data source.
- Generate a guest sharing link, access the application through this link, and confirm the citation function works normally.
- Test continuous follow-up question scenarios, confirm that subsequent question citation traceability can associate data source information from the conversation context.
