# Policy and Regulatory Basis Q&A for Land Use Rights, Mining Rights, and State-Owned Property Transactions: Document Parsing and Chunking

## What this category’s data looks like
Typical processing entities for this specific category include natural resource departments, state-owned asset supervision institutions, property right trading institutions, and public resource trading centers. Daily processed documents include transfer announcements, trading guidelines, bid application documents, margin vouchers, transaction confirmation letters, listing result announcements, and property right transfer prospectuses. Data sources include the national public resource trading platform, natural resource trading system, property right exchange system, and state-owned asset supervision system. The update frequency is daily. Documents contain structured tables, long text clauses, and ownership description fields. Some documents include embedded images or use encrypted formats.

## What constraints do these characteristics impose on document parsing and chunking
Document formats vary across multiple sources. Some PDFs and Excel files exported from systems use non-standard formats, requiring adaptation to different parsing logic. The daily update frequency demands stable and efficient parsing processes to avoid timeouts that disrupt business synchronization. Documents contain key fields such as ownership information and margin amounts. Chunking must retain full context without splitting critical transaction terms. Some embedded images in documents lack native text layers, requiring additional OCR processing to extract text. Otherwise, key accompanying descriptions will be lost.

## Configuration Settings
These configurations are optimized for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | This category’s documents include long clauses and structured ownership information. Chunk length preserves semantic integrity for standard policy text, avoiding splitting critical transaction terms |
| `chunkSplitter` | Split by title + paragraph | Documents often have structured titles such as transfer announcements and trading guidelines. Splitting by title preserves chapter logic, making it easier to locate corresponding clauses during policy retrieval |
| `customPdfParse` | Enable OCR image extraction mode | Some PDFs exported from systems have embedded images without native text layers. Enabling this configuration replaces the default parsing logic to extract auxiliary descriptive text from images |
| `PARSE_FILE_TIMEOUT_SECONDS` | 120–180 seconds | Large property right transfer prospectuses have many pages and take longer to parse. This time range covers the parsing needs of most documents |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | Supports batch uploading multiple transaction documents. The total size limit adapts to daily business batch processing requirements |
| `chunkSettingMode` | Manual configuration | Different document types such as transfer announcements and property right transfer prospectuses have varying chunking needs. Manual adjustment allows precise adaptation to business scenarios |

## Three Common Mistakes
- Embedded images are not displayed after uploading a PDF, and the corresponding text in the parsing result is empty. The cause is that the OCR extraction mode of `customPdfParse` is not enabled, and only the native text layer of the PDF is extracted.
- An unsupported format prompt appears when uploading an Excel document, and parsing cannot be completed. The cause is that encrypted Excel files or non-standard format documents exported from some property right exchanges cannot be recognized by the general parser.
- Search results only return text blocks without metadata such as target ownership and margin amounts. The cause is that no metadata extraction rules are configured, only plain text content is extracted, and structured fields in the document are not associated.

## How to Verify Proper Configuration
- Upload a transfer announcement PDF with embedded images. Check if the parsing result includes the text corresponding to the images, to confirm that the `customPdfParse` configuration is active.
- Upload a property right transfer prospectus with fewer than 10 pages. Verify that the parsing time is within the preset `PARSE_FILE_TIMEOUT_SECONDS` range, and no timeout errors occur.
- Upload an Excel-format margin voucher. Confirm that the system allows uploading and completes parsing without unsupported format prompts.
- Initiate a policy query test. Check if the returned search results include metadata fields such as target type and ownership restrictions, to confirm that the metadata extraction configuration is correct.

The values listed above are common starting points. Adjust them based on your own specific samples and use cases.
