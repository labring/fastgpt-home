# Policy and Regulatory Basis Q&A for Engineering Construction Project Bidding: Workflow Orchestration

## Data Overview for This Category
Data for this category comes from the national public resource trading platform, local public resource trading platforms, engineering approval systems, and bidding supervision systems. The update frequency is daily. Daily processed documents include bidding announcements, qualification pre-qualification documents, bidding documents, tender documents, bid evaluation reports, successful bid candidate announcements, and successful bid result announcements. Data fields cover section division information, qualification condition requirements, bid evaluation expert records, objection and complaint content, announcement correction content, and more. All fields are standardized business fields with no custom units.

## Constraints Imposed on Workflow Orchestration
Data sources are updated daily and originate from multiple dispersed locations. Workflow configurations must include scheduled synchronization tasks, and adapt to document format differences across platforms. Daily document types are diverse, and field standardization is high. Dedicated content splitting rules must be configured for different document types to avoid cross-document field confusion. Business errors carry significant impact consequences. Workflows must include compliance check nodes to verify whether fields such as qualifications and performance meet requirements. Processing of core fields including section division and bid evaluation records must strictly match business processes, ensuring that workflow node transitions conform to bidding business logic.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Scheduled Synchronization Frequency | A fixed time between 2:00 AM and 4:00 AM daily | Matches the daily data update rhythm, avoids peak business hours |
| Content Splitting Rules | Split by individual document type: split bidding announcements by section, split bid evaluation reports by bid evaluation stage | Adapts to the standardized structure of documents in this category, avoids cross-document content confusion |
| `variables` | Pre-set fixed business variables including section ID, announcement type, etc., with values determined through actual testing | Reduces repeated input, improves workflow reusability |
| Reply Component Configuration | Enable original link redirection, disable custom redirection prompts | Prevents links from displaying as unexpected question entry points |
| Workflow Node Timeout Setting | 600 seconds | Adapts to the time consumption requirements of multi-data-source synchronization, avoids abnormal node interruptions |
| `nodeId` | Assign a unique identifier to each business node, number in accordance with business process order | Facilitates node debugging and anomaly localization |
| Single Recall Limit | Top 10 entries | Adapts to the retrieval needs of documents in this category, avoids returning excessive irrelevant content |

## Three Common Misconfigurations
- Symptom: When there are many workflow nodes, text input in the configuration interface becomes laggy. Cause: The `variables` configuration is not optimized for lightweight use, and a large number of dynamic variables occupy page rendering resources, which does not comply with the FastGPT v4.17.0 workflow node rendering specifications.
- Symptom: Business links inserted in replies display the "Click to Ask Immediately" style. Cause: The reply component did not correctly enable the original link redirection configuration, and the link was mistakenly bound to conversation redirection logic.
- Symptom: No matching results appear after the workflow input instruction is executed. Cause: The `variables` were not set according to the field structure of category documents, leading to failure to match correct business data during retrieval.

## How to Verify Proper Configuration
- Manually trigger a workflow, check whether the number of synchronized documents matches the daily data source update volume.
- Test replies with inserted business links, confirm that links can directly jump to the corresponding public page, with no custom prompt content.
- Adjust the number of workflow nodes, verify that there is no page lag when entering configurations.
- Enter preset business instructions, check whether retrieval results match the policy and regulatory basis content of this category.
