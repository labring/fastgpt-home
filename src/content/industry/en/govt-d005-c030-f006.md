# Policy and Regulatory Basis Q&A for Construction Engineering Quality and Safety Supervision: Citation Sources and Traceability

## What this category's data looks like
Daily documents covered by this category include supervision plans, supervision inspection records, hidden danger rectification notices, quality problem handling forms, and completion acceptance supervision reports. Data sources are the engineering quality and safety supervision system, on-site construction site real-name management platform, supervision logs, and test reports. Data updates weekly. Document fields include supervision subject, inspection items, rectification requirements, acceptance conclusions, and more. Core fields use structured text and form records. No custom special units are included.

## What constraints these characteristics impose on the citation sources and traceability link
The weekly update frequency requires the knowledge base to run full synchronization regularly. This avoids using expired policies or supervision records as citations. Multi-source data integration requires unified associated fields. This ensures accurate matching of supervision system records and on-site supervision log correspondence during traceability. It prevents misalignment of traceability information. Documents cover content related to rectification closure. The traceability link must associate hidden danger rectification notices with rectification completion certificates. This avoids broken traceability results. Individual document lengths vary significantly. Long documents require reasonable limits on cited fragment length. This ensures the traceability content displayed in responses accurately matches the queried policy basis.

## How to configure the settings
This configuration is designed for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the average length of single documents in this category. Ensures coverage of complete policy clauses or on-site record fragments |
| Maximum number of citations | Top 3 | Core documents in this category are concentrated in number. Excessive citations lead to redundant responses. Focuses on key policies and supervision basis |
| Similarity threshold | 0.75–0.85 | Filters low-relevance non-supervision documents. Ensures traceability content is strongly correlated with queried policy basis |
| `responseData` | Enable source field display | Forces return of metadata for cited documents. Facilitates verification of citation authenticity and completeness |
| `detail` | Enable detailed traceability | Displays the position of cited fragments in the original document. Meets the traceability requirements for on-site records |
| Knowledge base synchronization frequency | Weekly | Matches the data update rhythm of this category. Ensures timeliness of cited data |

## Three common configuration mistakes
- Setting `quoteMaxToken` to 2000 token causes irrelevant long document fragments to appear in responses. This happens because the setting does not match the average length of single documents in this category. It exceeds the actual required traceability scope.
- Not setting a similarity threshold leads to large volumes of on-site daily records unrelated to policy basis in search results. This occurs because low-relevance data is not filtered. Traceability information becomes disorganized and cannot accurately match queried policy content.
- Hardcoding the knowledge base ID directly in the prompt triggers parameter verification errors during application deployment. This happens because application-level knowledge base association variables are not used. Hardcoded values cannot adapt to multi-environment deployment requirements.

## How to verify successful configuration
- Submit a query related to construction engineering quality and safety policies. Check if the document name and fragment position information of citation sources are displayed at the end of the response.
- Manually trigger the knowledge base synchronization. Confirm that the synchronization task executes successfully with no abnormal error logs.
- Adjust the maximum number of citations to Top 5. Verify that the number of returned citation results matches the set value.
- Enter a general query unrelated to this category. Confirm that the similarity threshold takes effect. No documents from this category are returned.
