# Policy and Regulatory Basis Q&A for Construction Project Environmental Impact Assessment Approval: Citation Sources and Traceability
This document is written based on FastGPT v4.17.0.

## What this category of data looks like
The data for this category mainly comes from the national unified construction project environmental impact assessment declaration and approval system, ecological environment zoning control results, pollution discharge permit platform, and environmental monitoring data. Commonly processed documents include environmental impact assessment reports or report forms, approval applications, public participation explanations, technical assessment opinions, and environmental impact assessment approvals. These documents center on construction projects, and include fields such as project category, environmental impact assessment level, pollution prevention measures, and public participation status. The update frequency is irregular, with no fixed cycle.

## Constraints on the Citation Sources and Traceability Link
Dispersed data sources across multiple platforms require the citation traceability process to cross-systemally associate documents from different data sources. Documents centered on projects include multiple types of specialized content, so it is necessary to accurately match fields such as project category and environmental impact assessment level to associate corresponding basis. The irregular update frequency requires retrieval processes to return the latest versions of policies and documents first. Errors in this link may prevent project construction from starting or result in revoked approvals, so traceability results must have clear verifiability to ensure every citation can be traced back to the original document.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the single-paragraph citation length of environmental impact assessment documents, avoiding truncation of core policy basis content |
| `responseData` | Enabled | Ensures that the answer carries identification information of the cited documents, supporting traceability viewing |
| `detail` | Enable detailed traceability mode | Displays the complete source path and update time of the cited documents, meeting compliance review requirements |
| Single retrieval limit | Top 8 entries | Covers relevant basis for the entire process of environmental impact assessment projects, avoiding omission of key approval documents |
| Retrieval timeout | 60 seconds | Adapts to the delay of cross-system retrieval, avoiding request interruption |
| Retrieval scope restriction | Full documents for single project | Limits the retrieval scope to data related to the currently processed construction project, avoiding interference across projects |

## Three Common Misconfigurations
- The citation function fails to display normally when accessing the application via a login-free shared link. This occurs because the traceability permission for public access is not enabled in the application configuration, or the shared link is not bound to the corresponding data retrieval permission.
- No citation identifier appears in knowledge base answer paragraphs. This happens because the `responseData` configuration item is not enabled, or no valid data source is matched during retrieval, preventing generation of a citation identifier.
- A timeout error occurs for retrieval requests. This is caused by an overly high single retrieval limit, or an overly short retrieval timeout configuration, exceeding system processing thresholds.

## How to Verify Successful Configuration
- Submit a question about the environmental impact assessment policy of a specific construction project, and check for a clickable source viewing entry at the end of the answer.
- Open the application configuration page, and confirm that configuration items such as `quoteMaxToken`, `responseData`, and `detail` are set to the specified values.
- Generate a login-free shared link, access the application through this link, submit a question, and confirm that the citation function displays normally and original documents can be viewed.
- Simulate a cross-system retrieval scenario, verify that no timeout error occurs for retrieval requests, and that returned results include relevant documents for the corresponding project.
