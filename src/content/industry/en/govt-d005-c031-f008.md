# Policy and Regulatory Basis Q&A for Construction Project Environmental Impact Assessment (EIA) Approval: Document Parsing and Chunking

## What this category of data looks like
Data for this category originates primarily from the national unified construction project EIA declaration and approval system, ecological environment zoning control results, pollution discharge permit platform, and monitoring data. Daily documents include environmental impact assessment reports (books or forms), approval applications, public participation statements, technical assessment opinions, and EIA approval documents. Document structures contain fixed fields such as project category, EIA level, pollution prevention measures, public participation content, and approval document number. Update frequency is irregular. Some large reports have considerable length, with significant variation in single-file size.

## Constraints Imposed on Document Parsing and Chunking
Multiple data sources result in inconsistent document formats. Formal approvals and reports use standard PDF format, while approval applications and statements are often created in Word format. This places compatibility requirements on parsing tools. Irregular updates mean chunking configurations must adapt to documents of varying versions and lengths, and cannot rely on fixed format templates. Documents include many EIA-specific terms and long paragraphs. Too-small chunks disrupt professional logic. Too-large chunks lead to excess irrelevant information during retrieval. It is also necessary to fully retain the context of core fields such as project category and pollution prevention measures, to avoid losing key approval basis during splitting.

## Configuration Settings
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 characters | Matches the typical paragraph length of EIA documents, avoiding splitting core approval clauses or project information |
| `chunkSplitter` | Custom delimiter + semantic segmentation | Adapts to the chapter separation habits of EIA documents, using hierarchical headings such as "1.", "(1)" and line breaks for chunking |
| `customPdfParse` | Enabled | Accurately extracts text and format information from EIA PDFs, preventing text loss caused by native PDF layout confusion |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Meets the upload requirements for single large EIA reports, adapting to common large-volume documents in the industry |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Reserves sufficient time for complete parsing of long documents, avoiding parsing interruptions due to excessive time consumption |
| `chunkSettingMode` | Manual mode | Allows adjustment of chunking parameters based on the professional structure of EIA documents, adapting to retrieval needs of specific business scenarios |

## Three Common Configuration Mistakes
- Parsing fails after uploading Excel-format EIA-related files. Reason: The default configuration does not support Excel document parsing, and only PDF and Word formats commonly used for EIA documents are supported.
- Chunk length still does not meet expectations after setting custom delimiters, with paragraph merging or over-splitting. Reason: `chunkSettingMode` was not switched to manual mode, or the `chunkSize` value does not match the actual paragraph length of the document.
- A parsing timeout error occurs when uploading a 3MB EIA PDF file. Reason: The `PARSE_FILE_TIMEOUT_SECONDS` setting is lower than the actual parsing time of this large document, causing the task to interrupt.

## How to Confirm Correct Configuration
- Upload a standard EIA PDF document, and check if the parsed text fully extracts chapter headings and core approval content.
- Manually set `chunkSize` to 1000 characters, upload a test EIA paragraph, and verify that the chunking result does not split key clauses or professional terms.
- Upload an EIA report larger than 500MB, and confirm that the upload and parsing process does not trigger size limit or timeout errors.
- Try uploading a Word-format EIA approval application, and check if it can be parsed normally to generate compliant chunking results.
