# Policy and Regulatory Basis Q&A for Construction Project Environmental Impact Assessment (EIA) Approval: Knowledge Base Retrieval and Recall

## What this category of data looks like
Data for this category comes from the national unified construction project EIA declaration and approval system, ecological environment zoning control results, pollution discharge permit platform, and monitoring data. Update frequency is irregular. Daily documents include environmental impact assessment reports or report forms, approval applications, public participation explanations, technical assessment opinions, EIA approval documents, and other key materials. Core information covers project categories, EIA levels, pollution prevention measures, approval requirements, and more. Documents do not have unified fixed field units, and use different formats based on document type. Long documents can reach hundreds of pages. Short documents are only a few hundred characters.

## What constraints these characteristics impose on knowledge base retrieval and recall
Data sources are scattered across multiple official platforms. Accurately limit the target dataset scope during retrieval to avoid retrieving irrelevant government data or cross-category content. Documents range from hundreds-page environmental impact assessment reports to brief EIA approval documents. Adjust text chunking and recall thresholds to match different document lengths. Overly long texts may exceed the model's context window. Overly short content may fail to cover core approval basis. Content includes dense professional terminology. Use a retrieval mode that matches domain-specific semantics. Regularly verify data synchronization status. This ensures the timeliness and accuracy of retrieved content. Outdated data can interfere with approval judgments.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | EIA-related content is highly professional. Low-match results must be filtered to avoid irrelevant policies interfering with approval judgments |
| `limit` | Top 8–12 results | Single EIA documents contain large volumes of content. Too many retrieved results will exceed the context window, while too few will fail to cover complete approval basis |
| `searchMode` | Professional semantic matching | Content includes exclusive terms such as EIA level and pollution prevention measures. Professional matching mode must be enabled to improve retrieval accuracy |
| `usingReRank` | Enabled | Long document chunks may have scattered semantics. Re-ranking optimizes result sorting to ensure core approval basis is retrieved first |
| `datasetSearchUsingExtensionQuery` | Calibrate based on actual testing | Adjust whether to enable extended queries based on the distribution of professional terms in the local dataset, to avoid retrieving non-target domain content |
| `collectionIds` | Bind the exclusive dataset ID for EIA approval | Data sources are scattered across multiple systems. Limiting the dataset ID allows accurate retrieval of EIA-related policies and documents, avoiding interference from cross-category data |

## Three Common Errors
- Symptom: Workflow calls to knowledge base search return configuration error prompts. Cause: The `collectionIds` parameter is not specified correctly, or the bound dataset ID does not belong to the EIA approval exclusive collection, causing the system to fail to match target data.
- Symptom: Knowledge base Q&A splitting step returns format errors. Cause: Fail to adapt to the long text structure of EIA documents, and set chunking parameters unreasonably. This causes semantic fragmentation in split text, making proper generation of Q&A pairs impossible.
- Symptom: A 503 error is prompted when uploading EIA-related files via the dialog box, while the upload to knowledge base process proceeds without issues. Cause: The file size uploaded via the dialog box exceeds the temporary storage threshold, or temporary service node resources are insufficient. The knowledge base upload uses an exclusive synchronization channel and is not affected.

## How to Confirm Proper Configuration
- Retrieval test: Input professional questions related to EIA level determination or pollution prevention measures, check whether retrieved results include chunked content from corresponding EIA documents, and confirm the `similarity` threshold meets business requirements.
- Dataset verification: View retrieval logs to confirm only content from the EIA-exclusive dataset bound via `collectionIds` is retrieved, with no cross-category data mixed in.
- Context verification: Check whether the total character count of retrieved results adapts to the current model's context window, avoiding content truncation due to exceeding limits.
- Re-ranking validation: Compare result sorting before and after enabling `usingReRank` to confirm the retrieval order of core approval basis meets expectations.

The values provided are common starting points and should be measured against the reader's own samples.
