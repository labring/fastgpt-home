# Policy and Regulatory Basis Q&A for Investment Project Approval and Post-Evaluation: Model Access and Configuration

## What data looks like for this category
Core data for this category comes from State-owned Assets Supervision and Administration Commission (SASAC) investment supervision systems, enterprise ERP and project management systems, industry market data, and audit and financial statements. Daily processed documents include annual investment plans, project proposals, feasibility study reports, due diligence reports, asset appraisal reports, and post-investment evaluation reports.
Data updates occur quarterly. Core document structures include modules for basic project information, technical analysis, financial forecasting, and compliance basis. Fields cover investment amount, progress milestones, and compliance clauses. Units adjust dynamically based on document type and business scenario.

## Constraints imposed on model access and configuration
Data sources cover multiple systems with fixed update cycles. Model access must adapt to internal network environments and permission controls to prevent data leaks.
Document types vary widely, with significant differences in length. Proper context length configuration is required to cover core compliance materials such as feasibility study reports and post-evaluation reports.
Policy-based Q&A has extremely high accuracy requirements. Generation randomness must be strictly controlled to ensure output aligns with SASAC regulatory requirements.
Some documents include image and text attachments, so multimodal parsing support is needed.
Quarterly updated data must be synchronized to the vector database regularly to avoid using outdated policy and project information.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | Adapts to the multi-document context length for investment project approval and post-evaluation, covering core compliance materials such as feasibility study reports and post-evaluation reports |
| `temperature` | 0.1–0.3 | Policy-based Q&A requires strict rigor, reducing generation randomness to avoid statements inconsistent with regulations |
| `vision` | Enabled | Supports parsing image and text attachments in project documents, matching common formats of approval and post-evaluation materials |
| `maxTokens` | 2000–3000 token | Controls single-round response length, ensuring completeness and readability of referenced policy basis, avoiding overly long output |
| `AIPROXY_API_ENDPOINT` | Fill in according to internal deployment environment | Adapts to the access path of internal networks for state-owned enterprises and public institutions, ensuring data transmission complies with security and compliance requirements |
| `AIPROXY_API_TOKEN` | Bind exclusive permission keys | Restricts model access permissions, complying with security control standards of SASAC regulatory requirements |

## Three common misconfigurations
- An error stating no available channels occurs after enabling the `vision` function. This is caused by failure to configure the API key for the multimodal model, or failure to enable internal network access permissions.
- No create model icon appears in the top-right corner of the interface. This is caused by the current account lacking group usage permissions for the corresponding model, or failure to upgrade to FastGPT v4.17.0.
- Search takes too long and hard disk IO usage is high. This is caused by failure to restrict the value range of `maxContext`, leading the system to load excessive historical project and policy document data.

## How to confirm configurations are correct
- Initiate a query that includes project document attachments, and verify that image content can be correctly parsed and associated with corresponding policy basis.
- Check API call logs to confirm that call records for `AIPROXY_API_TOKEN` match the bound permissions.
- Test multi-round compliance Q&A, and verify that referenced policy and project data in responses matches the latest information in the current system.
- Monitor system operating metrics, and confirm that response time and hard disk IO usage are within reasonable ranges.
