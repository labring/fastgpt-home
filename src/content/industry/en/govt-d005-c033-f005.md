# Policy and Regulatory Basis Q&A for Tendering and Procurement Compliance Management: Tool Calling and Plugins

This content applies to FastGPT v4.17.0.

## What this category of data looks like
The data sources for this category include enterprise procurement platforms, public resource trading platforms, supplier databases, contract management systems, and audit issue databases. The update frequency is daily.

Documents processed daily include procurement plans, requirement specifications, bidding documents, bid evaluation records, contracts, acceptance documents, and supplier complaint materials. Data fields include procurement method, budget amount, qualification requirements, scoring rules, performance clauses, and others. Field units follow the specifications of the respective documents, with no unified mandatory format.

## Constraints on Tool Calling and Plugins from These Data Characteristics
Data is scattered across multiple systems. Tool calling must support connecting to multiple types of data source plugins to enable cross-platform data retrieval.

Daily document types are diverse and have no unified format. Tool calling must adapt parsing logic for different document structures.

Data updates daily. Tool calling must support near-real-time retrieval of the latest policy and regulatory content.

Field specifications are inconsistent. Structured data returned by tools requires additional processing to meet field matching needs for compliance verification.

Compliance verification errors have serious consequences. The stability of tool calling results directly affects subsequent audit risks. A result verification link must be added.

## How to Configure Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Supports automatic judgment of whether to call tools, adapting to scenarios where cross-data-source content retrieval is required for policy Q&A |
| Database connection configuration | Enable multi-row query support | Adapts to the common MySQL storage environment for this category, supports simultaneous execution of insert and select statements |
| Result post-processing | Custom code extraction | For document data with inconsistent fields, supports extracting specific strings to match compliance verification rules |
| Online tool call limit | Top 3 entries | Public resource trading platforms have a large amount of policy content. Limiting the number of returned entries optimizes response speed |
| Timeout setting | 600 seconds | Cross-platform retrieval of procurement and policy data requires a long response time, preventing call interruptions due to timeout |

## Three Common Misconfigurations
- Unstable tool calling results, with returned content containing irrelevant fields or duplicate entries. Cause: No result post-processing link is configured. No string extraction and filtering are performed on raw data returned by tools, making the data unavailable directly for compliance verification.
- MySQL database plugin reports errors when executing multi-row statements. Cause: Multi-row query support for the database connection plugin is not enabled. Only single-statement execution logic is configured, which cannot support combined insert and select calls.
- No reference content obtained after online tool call. Cause: Reference capture configuration for online tools is not enabled. Only plain text results are retrieved, which cannot meet the source annotation requirements for policy basis Q&A.

## How to Confirm the Configuration Is Correct
- Submit a simulated policy Q&A request, check the tool calling log, confirm that the `toolChoice` parameter triggers the corresponding tool call.
- Configure a test MySQL multi-row query statement, execute it and check the returned results, confirm there are no errors and expected data is obtained.
- Submit an online tool call request, check if the returned results include reference source fields, confirm the configuration takes effect.
- Wait 1 update cycle, submit a policy Q&A request, confirm the tool has retrieved the latest policy content.
