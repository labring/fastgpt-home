# Policy and Regulatory Basis Q&A for Land Pre-examination and Planning Permit: Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
The service targets for this category are natural resource authority use control and planning permit offices, administrative examination and approval bureaus, and project entities. Data sources primarily include the national land spatial planning unified map, project examination and supervision platform, current land use database, and ecological protection redline data. Update frequency is irregular. Daily supporting documents cover land pre-examination and site selection opinions, construction land planning permits, construction engineering planning permits, redline diagrams, and planning conditions. Data fields include project site selection scope, land use scale, planning control requirements, redline coordinates, and more. Some documents include spatial coordinates and vector graphic information. No unified fixed unit system exists for this data.

## Constraints Imposed on Knowledge Base Retrieval and Recall
The data characteristics of this category create multiple constraints for the retrieval and recall process. Synchronization across multiple heterogeneous data sources must align with the irregular update rhythm to prevent data lag or redundancy. Documents contain non-pure text content such as spatial coordinates and vector redlines. This requires support for parsing and retrieving unstructured formats. Fields lack a unified unit system. This eliminates invalid recall based on unit matching. Consultation questions frequently link to cross-departmental preconditions from development and reform, housing and urban-rural development, ecology, and other sectors. This requires support for cross-document associated retrieval and context integration.

## Configuration Settings
The following configurations are based on the functional logic of FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | Policy texts related to land pre-examination have high professionalism. This setting filters low-similarity irrelevant retrieval results to ensure policy matching accuracy |
| `limit` | Top 8 entries | This category of retrieval needs to cover multiple approval documents and control data. 8 results balance retrieval completeness and context length |
| `searchMode` | Semantic + keyword hybrid retrieval | This setting matches both keywords and semantic associations, adapting to the mixed retrieval needs of professional terms and spatial descriptions in policy texts |
| `usingReRank` | Enabled | Semantic similarity of professional policy texts can be disturbed by redundant expressions. Reranking improves the sorting priority of highly relevant results |
| `datasetSearchUsingExtensionQuery` | Enabled | Project consultations often involve precondition associations. Extended queries expand the retrieval scope of relevant policy clauses |
| `collectionIds` | Bind the dedicated dataset ID for land pre-examination and planning permit | Isolate cross-category data to avoid interference from irrelevant policy documents on retrieval results |

## Three Common Configuration Errors
- Symptom: Spatial images in redline diagrams and planning condition documents within retrieval results fail to load normally. Cause: Non-text content index adaptation configuration is not enabled, so metadata for vector graphics and images is not parsed correctly.
- Symptom: The number of results returned in a single retrieval is far below the preset `limit` value. Cause: Permission configuration for cross-source datasets is not adjusted, and retrieval permissions for some data sources remain disabled.
- Symptom: Retrieval results include extensive real estate registration policy content unrelated to project site selection. Cause: The dedicated dataset is not bound via `collectionIds`, leading to mixing of documents from other categories within the same broad category.

## How to Verify Successful Configuration
- Upload a single land pre-examination and site selection opinion document, perform a retrieval test, and confirm the relevance of returned results matches business expectations.
- Review the dataset configuration items, and verify that `collectionIds` only includes data source collections exclusive to this category, with no cross-category documents included.
- After enabling `usingReRank`, compare the sorting order of retrieval results to confirm the reranking function operates correctly.
- Upload a redline diagram document containing spatial images, and confirm the images display properly in the retrieval result preview.
