# Policy and Regulatory Basis Q&A for Social Assistance and Minimum Living Security Review: Workflow Orchestration

## What the data for this category looks like
This category of data mainly comes from the low-income population dynamic monitoring platform, resident family economic status verification system, and cross-department shared data from public security, human resources and social security, medical insurance, housing and urban-rural development, and tax authorities. The update frequency is once per month. Daily processed documents include minimum living security application forms, family economic status verification reports, household survey forms, democratic appraisal records, public notice materials, and assistance approval forms. Document fields cover family income and property details, member relationships, and application qualification-related information. All fields adopt civil affairs assistance business standard fields, with no custom units.

## What constraints these characteristics impose on the "workflow orchestration" link
The monthly update frequency of cross-department shared data requires timed synchronization nodes in workflow configuration. This ensures the verification data called for policy Q&A uses the latest monthly version. The standardized field structure of multiple types of business documents requires workflows to bind corresponding document fields through the `variables` parameter. This avoids Q&A deviations caused by field mismatches. The access permissions for cross-department data require node access control configuration in workflows. This ensures only authorized links can call sensitive family economic data. In addition, the consequences of errors in minimum living security review require verification links in workflows. This performs associated matching between retrieved policy clauses and verification data, avoiding the risk of incorrect or missed security assistance.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Variable Selection Switch | Enable the `variables` parameter to configure the "Skip Knowledge Base Retrieval" option, default off | Adapt to user needs for skipping knowledge base retrieval on demand, and match the scenario of quick Q&A for known policy clauses in minimum living security review |
| File Stream Processing Node | Configure to receive binary stream format, set timeout to 600 seconds | Adapt to upload and parsing of document data such as household survey supporting materials and verification reports. 600 seconds covers transmission duration for most large-volume files |
| Environment Variable Call | Enable workflow environment variable call function, bind system parameters configured during deployment | Meet secure call requirements for sensitive configurations such as cross-department data interface keys and policy document paths |
| Single Retrieval Limit | Set to the top 5 policy documents | Avoid redundant Q&A caused by too many retrieval results, and match the business characteristic of limited number of policy clauses in minimum living security review |
| Node Timeout Setting | Set to 900 seconds | Cover the entire process duration of cross-department data synchronization and multi-document associated verification, avoiding workflow failure caused by node interruption |

## Three Common Mistakes
- Phenomenon: After configuring the `variables` parameter in the workflow, the variable selection option does not display on the frontend. Cause: The variable exposure switch for the workflow is not enabled, which prevents custom variable configurations from loading during runtime.
- Phenomenon: A request timeout error is returned when calling the file stream node for household survey supporting materials. Cause: No timeout time is set for the file stream node, so large-volume scanned paper materials cannot complete transmission and parsing.
- Phenomenon: Policy Q&A results include policy clauses outside the scope of minimum living security review. Cause: No single retrieval limit is configured, and the `variables` parameter is not used to bind family verification data to filter the retrieval scope, resulting in redundant results.

- Trigger workflow operation, check that retrieval results only include policy documents related to minimum living security review, and confirm that the retrieval scope filtering rules take effect.
