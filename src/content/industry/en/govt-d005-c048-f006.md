# Policy and Regulatory Basis Q&A for Administrative Licensing and Approval: Source Citation and Traceability

## What this category of data includes
This category covers daily approval documents from government service centers, administrative approval bureaus and other relevant entities. Included documents are service guides, application forms, acceptance notices, correction notification letters, administrative licensing decision letters, license certificates and more. Data sources include the national integrated government service platform item database, administrative licensing item list, departmental business approval systems, and electronic certificate database. The update frequency is daily. Documents typically contain standardized fields such as item code, legal establishment basis, handling conditions and other standard fields. No custom units are used, and all fields follow government service-related specifications.

## Constraints for Source Citation and Traceability
The daily data update requirement means the traceability link must real-time associate with the latest valid official data sources. This prevents referencing expired policies. Multiple types of approval documents use different citation identification rules. For example, electronic certificates must be linked to their electronic certificate database numbers. Service guides must be bound to specific entries in the national integrated government service platform item database. The rigor of legal basis requirements means traceability information must clearly point to specific items or official documents. Vague associations are not allowed. The need to retrieve data across multiple departmental sources means the traceability link must support verification logic for multiple sources. This ensures compliance of cited sources.

## Configuration Settings
This document is written based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Aligns with the paragraph structure of administrative licensing policy basis, to avoid splitting complete clauses of legal basis |
| Single Search Limit | Top 5 results | Legal basis for administrative licensing is usually concentrated in a small number of entries in official lists or item databases; too many results will interfere with traceability |
| Re-ranking | Enabled | Prioritizes matching core fields such as legal establishment basis and handling conditions, to improve citation accuracy |
| `quoteMaxToken` | 1200–1800 token | Retains sufficient cited content for precise traceability |
| `detail` | true | Returns detailed cited source metadata to meet compliance verification and audit requirements |
| `responseData` | Includes knowledge base ID, item code | Ensures the interface returns key identifiers that can be directly used for traceability |

## Three Common Configuration Errors
- Symptom: The conversation interface returns results that do not include the knowledge base ID or item code. Cause: The `responseData` parameter was not configured correctly, and the metadata return switch was not enabled.
- Symptom: The returned cited documents do not match the actual approval items. Cause: The chunk length was set unreasonably, causing split document fragments to be associated with incorrect item codes, or the search limit was set too high, introducing irrelevant documents.
- Symptom: Streamed response results cannot be parsed for traceability details. Cause: The `detail` parameter was not set to true, so the returned content does not include detailed metadata fields.

## How to Verify Correct Configuration
- Initiate a policy query targeting a specific administrative licensing item, and check whether the returned results include traceable official source identifiers.
- Call the interface and review the returned metadata fields to confirm that the required traceability information is included.
- Manually trigger a data source update simulation to verify that the system can correctly associate with the latest version of policy basis.
- Check the streamed response content to confirm that detailed citation details are included.
