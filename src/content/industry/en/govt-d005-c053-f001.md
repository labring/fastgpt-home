# Policy and Regulatory Basis Q&A for Departmental Budget Preparation: HTTP Interfaces and External Systems
## What This Category of Data Looks Like
Data sources for this category include the unified budget management system, departmental staffing system, prior-year final accounts, project repository, and budget preparation notices issued by the Ministry of Finance. Updates occur on an annual basis. Daily processed documents include departmental budget drafts, project application forms, performance target forms, personnel expense calculation forms, and budget approvals. Data fields cover project names, expenditure amounts, staffing headcounts, performance targets, and related items. Common units include ten thousand yuan, persons, and similar. The data structure undergoes minor adjustments each year to align with official annual budget preparation requirements.

## What Constraints These Characteristics Impose on HTTP Interfaces and External Systems
The annual update nature of this category’s data means HTTP interfaces do not require high-frequency polling, and can be configured as on-demand synchronous calls. The need to integrate multiple data sources requires interfaces to support different authentication methods to adapt to various business systems. The diversity of document fields requires the `variables` parameter to pass complete business field mapping rules to avoid data parsing discrepancies. The large volume of budget data processed per single request requires configuring reasonable timeout thresholds to prevent call interruptions caused by excessive data volume.

## How to Configure Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `Authorization` | Configure Bearer Token or dedicated secret key as required by the business system | Adapt to authentication rules of different external systems, and ensure secure transmission of departmental budget data |
| `variables` | Pass business field mappings related to budget preparation, such as project ID, expenditure category, staffing headcount | Unify parsing formats for data from different sources, and align with the document structure of departmental budget preparation |
| `responseData` | Only return a subset of fields that meet budget preparation review requirements | Reduce invalid data transmission and improve interface call efficiency |
| Timeout Threshold | 600–1200 seconds | Adapt to time consumption requirements for processing large volumes of budget data per single request, and avoid call interruptions |
| Retry Strategy | Retry 2 times after failure, with a 30-second interval | Address temporary external system fluctuations, and reduce the probability of call failures |

## Three Common Misconfigurations
- Scenario: Interface calls return a 504 timeout status code, or workflow execution fails to complete within 1200 seconds. Cause: The timeout threshold was not adjusted based on the single-request data volume for departmental budget preparation, and the default threshold is too low to cover data processing time.
- Scenario: Interface calls return a 401 unauthorized error. Cause: A universal authentication key was used to connect multiple external business systems, and dedicated authentication information was not configured for each individual system.
- Scenario: The file links received by the interface are relative paths, making it impossible for external systems to retrieve corresponding image or document resources. Cause: Relative paths were not converted to accessible absolute URLs, and correct file transfer parameters were not configured.
