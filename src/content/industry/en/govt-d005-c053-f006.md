# Policy and Regulatory Basis Q&A for Departmental Budget Preparation: Citation Sources and Traceability

## What Data This Category Includes
This category draws data from the unified budget management system, departmental staffing system, prior year final account data, project repository, and annual budget preparation notices issued by the Ministry of Finance. Daily output documents include departmental budget drafts, project application forms, performance target forms, personnel expense calculation forms, and budget approval documents. Data updates follow an annual cycle. Core fields include budget preparation basis, project expenditure details, staffing base, and similar items. Units use standard fiscal accounting formats such as ten thousand yuan and person.

## Constraints on the Citation Sources and Traceability Link
The annual update requirement means the knowledge base must complete full data synchronization each year. This prevents failed cross-cycle citations. Mixed multi-source data use requires the traceability link to associate metadata tags from different systems. It must clarify the source system and publishing entity for each policy basis. Complex document hierarchies with detailed fields require traceability to support direct jumps from Q&A results to corresponding budget draft clauses, project application book chapters, or original Ministry of Finance notices. Budget preparation has extremely high compliance requirements. Traceability results must directly match audit process verification rules. Content without an accurate source will result in budget application rejection.

## Configuration Settings
Configuration settings are based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | 1200–1800 token | Matches the length of single citation content for departmental budget preparation-related documents, ensuring complete extraction of original policy basis text |
| `responseData` | Enable source field return | Carries metadata of corresponding documents in the knowledge base, including source system, release time, and document type |
| `detail` | Enable detailed traceability mode | Supports returning specific page numbers or chapter positions of cited content in the original document |
| Single search limit | Top 6 recall results | Covers common policy basis types for departmental budget preparation, avoiding omission of key reference documents |
| Context window | 8000–10000 characters | Accommodates associated content from multiple budget preparation-related documents, ensuring complete policy chains can be called during Q&A |
| Reranking threshold | Calibrated based on actual testing | Adapts to semantic similarity judgment for fiscal policy documents, avoiding recall of irrelevant cross-year budget data |

## Three Common Configuration Mistakes
- Phenomenon: The returned citation field is empty after invocation, and source document information cannot be displayed. Cause: The `responseData` configuration item is not enabled, and the source metadata return function is not activated.
- Phenomenon: Recall results are irrelevant to the query content. For example, a query about annual budget preparation recalls redundant data from prior year final accounts. Cause: No reasonable reranking threshold is set, or the search scope is not limited to current year budget preparation policy documents.
- Phenomenon: Cited content is truncated, and complete original policy clause text cannot be displayed. Cause: The value of `quoteMaxToken` is too small, failing to match the single citation length requirement for departmental budget preparation documents.

## How to Verify Proper Configuration
- A test query containing "XX annual departmental budget preparation basis" is initiated. Returned results are checked for clear source document names and chapter information.
- Metadata fields of returned results are reviewed. Tags corresponding to the `responseData` configuration item, such as source system and release time, are confirmed to be included.
- Policy queries of different lengths are tested. Cited content is checked for completeness and absence of truncation.
- Cross-year query scenarios are simulated. Recall results are confirmed to only include valid current year budget preparation policy data.

The values listed above are common starting points and should be evaluated against the reader's own samples.
