# Policy and Regulatory Basis Q&A for Pharmaceutical Distribution: Citation Sources and Traceability

## What the Data for This Category Looks Like
Pharmaceutical distribution policy and regulatory basis data is sourced primarily from official announcements and normative documents.
These documents are issued by the National Medical Products Administration, the Ministry of Commerce, medical insurance bureaus of various provinces and cities, and industry competent authorities.
Data update frequency adjusts dynamically alongside policy releases.
The regular synchronization cycle is once per week.
Each document includes fixed fields: document number, issuing authority, release date, clause content, and applicable scenarios.
Clause content is split by chapter numbering.
Units use standardized Chinese expressions.
For example, document numbers follow the format Guo Yao Jian Fa [Year] Serial Number.
Dates use the YYYY-MM-DD standard format.

## Constraints Imposed on Citation Sources and Traceability
Official policy documents have clear document numbers, issuing authorities, and date identifiers.
The traceability link must fully extract these fields as verification basis.
Displaying only body content will prevent compliance verification.
Dynamically updated policies require the system to configure rules for filtering the latest versions by release date.
This prevents returning expired policy clauses.
The split document structure by chapter requires citations to precisely match specific clause numbers.
Broadly citing entire documents will lead to vague information scope.
Official data sources have fixed domain names.
Configuration must be set to only include documents from specified official domains.
This ensures source authority.

## Configuration Settings
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Value | Basis for This Selection |
| --- | --- | --- |
| Maximum Context | 8000–12000 token | Adapts to the average content length of single pharmaceutical policy documents |
| Maximum Knowledge Base Citations | Top 3–5 entries | Authoritative sources for pharmaceutical distribution policy documents are concentrated. Excessive citations increase reading burden |
| Maximum Response Tokens | 2000–3000 token | Reserves sufficient space to display policy clauses and complete traceability information |
| `quoteMaxToken` | 1500–2000 characters | Limits the content range of individual citations, to avoid truncating key policy clauses |
| `detail` | Enabled | Forces return of complete document metadata, including document numbers and release dates |
| `responseData` | Include Source URL | Ensures traceability links point to official data sources, and meets compliance requirements |

## Three Common Mistakes
- Phenomenon: API call results forcibly include citation content, and this cannot be disabled via configuration. Cause: The `responseData` parameter is not configured to return only pure Q&A body text, or the global mandatory citation display switch was accidentally enabled.
- Phenomenon: After configuring the maximum knowledge base citations parameter, the number of recalled policy documents does not meet expectations. Cause: The parameter value exceeds the valid number of documents in the current data source, or sorting and filtering by policy document release date was not performed.
- Phenomenon: Policy document numbers and release dates are not displayed in citation content, leading to incomplete traceability information. Cause: The `detail` configuration is not enabled, so document metadata fields are not returned.

## How to Confirm Configuration Is Complete
- A query targeting specific pharmaceutical distribution policies is submitted. The returned results are checked for complete source URLs and document metadata.
- The value of `quoteMaxToken` is adjusted. The content length of individual citations is verified to match the preset expectations.
- The API interface is called. The returned results are checked to confirm whether citation content can be toggled via configuration.
- The knowledge base data source configuration is viewed. It is confirmed that only policy documents from the specified official domains are included.

The values provided are common starting points and should be evaluated against local test samples.
