# Policy and Regulatory Basis Q&A for Hazardous Chemicals Storage and Transportation: HTTP Interfaces and External Systems

## What this category of data looks like
Data for the policy and regulatory basis of hazardous chemicals storage and transportation is mainly sourced from official release channels of the Ministry of Emergency Management, the Ministry of Transport, and relevant national and industry standards. Data is updated in line with policy revision cycles: national standards are updated every 1 to 2 years, and departmental normative documents are released and updated monthly. Each single data entry includes fields such as policy document number, issuing authority, effective date, applicable storage and transportation links, and core clause content. Clause content is split by clause number, and units include storage and transportation-related measurement standards such as meters, kilograms, and cubic meters.

## What constraints do these characteristics impose on the "HTTP Interfaces and External Systems" link
Policy data from official sources requires interface calls to carry valid authentication information to prevent unauthorized access. Policies with different update cycles require differentiated caching strategies. Set a 7-day cache period for national standard data, and a 1-day cache period for departmental normative documents, to reduce repeated requests. Fields split by clause require the `responseData` returned by the interface to be layered by clause number, to adapt to the clause-level call needs of external systems. Storage and transportation-related measurement units must retain original fields completely in the interface, and unit formats must not be converted without authorization.

## How to set configurations
The following configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setup | Rationale |
| --- | --- | --- |
| `Authorization` | Fixed prefix `Bearer ` plus the interface key assigned by the platform | Complies with official API authentication standards to ensure call legitimacy |
| `variables` | Pass `{"scene": "hazardous chemicals storage and transportation", "link_type": "storage/transportation"}` | Accurately filters policy data for the target scenario, improving recall accuracy |
| `responseData` | Return in the format `{"policy_number": "", "publish_unit": "", "effective_date": "", "clause_content": []}` | Matches the field structure of hazardous chemicals storage and transportation policy data, facilitating external system parsing |
| Interface timeout period | 30 seconds | Adapts to the query response duration of policy data, preventing request failure due to large data volume |
| Cache period | 7 days for national standard policy data, 1 day for departmental policy data | Matches the update frequency of the two data types, balancing data timeliness and interface load |

## Three common mistakes
- Issue: Unable to pass file type parameters when calling the interface, or returned parameter format is incorrect. Cause: Failed to correctly configure the transfer format of file parameters in `variables`, and failed to match the parameter structure required by the plugin.
- Issue: An error `IPROXY_API_ENDPOINT or AIPROXY_API_TOKEN is not set` is displayed after deployment. Cause: Failed to fill in the FastGPT proxy interface address and authentication token in the external system configuration, preventing the establishment of a normal call link.
- Issue: The number of policy data entries returned by the interface does not match expectations. Cause: No reasonable recall parameters were set, or the cache period was configured incorrectly, resulting in the return of old data.

## How to confirm the configuration is complete
- Call the interface and pass the correct `variables` parameter, check if the returned `responseData` includes policy fields for the hazardous chemicals storage and transportation scenario.
- View the interface call log to confirm that the `Authorization` parameter was carried correctly, with no authentication failure errors.
- Call the interface again after 1 day, check if the departmental policy data has been updated, to confirm that the cache configuration is effective.
- Pass different storage and transportation scenario parameters, confirm that the returned policy content matches the corresponding scenario.
