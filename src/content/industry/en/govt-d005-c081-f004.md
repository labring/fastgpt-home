# Policy and Regulatory Basis Q&A for Basic Chemical Industry: Workflow Orchestration

## What this category’s data looks like
Policy and regulatory basis data for the basic chemical industry mainly comes from documents related to work safety, environmental protection, and production capacity control released by the Ministry of Emergency Management, Ministry of Ecology and Environment, and Ministry of Industry and Information Technology, as well as standard documents released by industry associations.
There is no fixed cycle for data updates. Real-time synchronization is performed when new policies are issued. Industry standards are updated quarterly or annually.
Most individual documents contain fields such as document number, issuing unit, release date, applicable scope, core clauses, and penalties. Document length ranges from 5000 to 10000 characters. Units for production capacity and emission parameters involved in clauses are mostly tons/year, mg/m³, and similar units.

## Constraints on Workflow Orchestration
Basic chemical industry policy documents are lengthy and structurally complex. Workflows cannot load all content at once, and must retrieve relevant clauses in batches.
Policy updates have no fixed cycle. The supporting knowledge base synchronization mechanism must support flexible cycle adjustments to avoid missing the latest compliance requirements.
Policies include structured metadata such as document numbers and release dates, and often contain abbreviations and cross-departmental linked clauses. Workflows must support both structured field extraction and coreference resolution.
In addition, policies serve as compliance review basis. Workflow node order must follow the "retrieve - organize - verify - answer" logic to avoid missing key compliance information.

## Configuration Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Single Retrieval Limit | Top 8 entries | Basic chemical industry policy documents are lengthy per piece. Too many retrievals will exceed the context window. Too few will fail to cover compliance needs linked to multiple clauses. |
| Context Window Limit | 8000–12000 token | Policy clauses are dense and lengthy. Sufficient space must be reserved to carry retrieved policy content and user questions. |
| Question Optimization Switch | Enabled | Basic chemical industry policies often contain abbreviations and document number references. Enabling this option optimizes coreference resolution and improves retrieval accuracy. |
| Knowledge Base Sync Cycle | Every 7 days | New policy releases have no fixed cycle. Regular sync covers most update needs while avoiding excessive resource usage from overly frequent syncs. |
| Metadata Extraction Scope | Full text + metadata fields | Policies include structured fields such as document numbers and release dates. Both must be extracted to meet display requirements for compliance basis. |
| Node Timeout Setting | 600 seconds | Retrieval and organization of large policy documents take a long time. Setting a timeout prevents unlimited task runtime. |

## Three Common Mistakes in Configuration
- Phenomenon: The workflow returns only a single policy fragment after execution, failing to cover complete compliance basis. Cause: The single retrieval limit is set too low, not matching the compliance review scenario linked to multiple clauses in basic chemical industry policies.
- Phenomenon: A debug node enters a running state and cannot be terminated. The interface shows the node is unresponsive. Cause: No timeout parameter corresponding to `nodeId` is configured. No forced termination mechanism is set for long document processing tasks.
- Phenomenon: Responses contain ambiguous references such as "this document" or "the above provisions" with no clear corresponding policy clauses. Cause: The question optimization configuration is not enabled. Abbreviations and references in user questions are not processed, leading to inaccurate matching of retrieval results.

## How to Confirm Proper Configuration
- Upload a single basic chemical industry policy document, trigger workflow execution, and verify that the number of retrieved results matches the set single retrieval limit.
- Input a question containing a policy abbreviation, and verify that the returned results include complete metadata such as policy document numbers and release dates.
- Enter debug mode to run the workflow, wait 10 minutes, and check the node status to confirm no freezes or unresponsive situations.
- Input a question with ambiguous references, and verify that the returned results clearly link to specific policy clauses and document numbers.
