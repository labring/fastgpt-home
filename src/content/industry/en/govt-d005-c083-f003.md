# Policy and Regulatory Basis Q&A for Infrastructure Construction: Multi-turn Dialogue and Prompt Engineering

## What this category of data looks like
Data for infrastructure construction policy and regulatory basis comes from officially published public policy documents released by the national Ministry of Housing and Urban-Rural Development, Ministry of Transport, and provincial housing and urban-rural development authorities. The update cycle is 1 to 7 business days after a new policy is released.
Document structure includes policy title, issuing document number, issuing body, effective date, clause number, and specific content. Fields have no special units. Single document length varies significantly, ranging from thousands to tens of thousands of characters. This page is compatible with FastGPT v4.17.0.

## What constraints these characteristics impose on multi-turn dialogue and prompt engineering
Policy documents have varying lengths and contain multiple clauses. Passing full historical context during multi-turn dialogue may exceed the model’s context window limit. Historical dialogue must be selectively cropped to retain only content strongly related to the current question.
Policy fields include issuing document numbers and effective dates. Prompts must explicitly require the model to mark the corresponding policy document number and effective time when answering, to ensure compliance.
Infrastructure policies vary by region. The initial step of multi-turn dialogue must guide users to clarify the applicable administrative region, to avoid confusion between cross-region policies.
Policy update frequency is fixed. Prompts must restrict the model to only use the latest synced policy data, and not reference outdated, unupdated content.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| Maximum Context Length | 8000–12000 characters | Matches the typical length of single infrastructure policy documents, to avoid exceeding the model’s processing limit |
| Number of Historical Dialogues to Retain | First 3 entries | Based on the cropping logic for the `messages` array, balances context volume and window usage |
| Prompt Variable Binding | Bind the `variables` parameter | Ensures custom parameters such as user-specified region and project type are correctly passed to the prompt |
| Context Recall Limit | Top 5 matching entries | Matches the clause density of infrastructure policies, to avoid retrieving too many irrelevant policy snippets |
| Dialogue Timeout | 60 seconds | Matches the retrieval and generation rhythm of long policy texts, to prevent request interruption |

## Three Common Mistakes
- No running data appears in conversation logs. The cause is that the log storage switch associated with `chatId` is not enabled, so the interface call running process is not recorded.
- The text extraction module returns undefined after inputting any parameter into the prompt code block. The cause is that the `variables` parameter is not correctly bound in the prompt code block, so custom parameters are not properly passed.
- Associated logs disappear after a user deletes a conversation. The cause is that the binding logic between conversations and logs is set to clean up synchronously when the conversation is deleted, and log data is not stored independently.

## How to Verify Successful Configuration
- Initiate a conversation that includes an infrastructure policy query, and check whether the model’s answer marks the corresponding policy document number and effective time.
- Initiate a continuous multi-turn dialogue, and check the context usage status of the conversation window to confirm no out-of-limit prompts appear.
- Check the status of the log storage switch associated with `chatId`, to confirm whether running data is properly recorded.
- Test deleting a single conversation, to confirm whether associated logs are retained or cleaned up according to the preset logic.

The values provided here are common starting points, and should be evaluated against the user’s own samples.
