# Policy and Regulatory Basis Q&A for Coal Mining Production: Multi-turn Dialogue and Prompt Engineering

## What This Category of Data Looks Like
Data sources for this category include production safety regulations, industry standards, and local policy documents released by the National Energy Administration, the Ministry of Emergency Management, and local coal industry regulatory authorities. Data updates align with official policy release timelines, with no fixed cycle. Core policies are reviewed and updated quarterly. Most documents are chapter-based structured text, containing fields such as clause numbers, applicable job scenarios, quantitative implementation requirements, and violation penalties. Common units exclusive to coal mining production include tons, meters, cubic meters, and hours.

## What Constraints These Characteristics Impose on the Multi-turn Dialogue and Prompt Engineering Link
The structured, numbered clause feature requires multi-turn dialogue to track referenced clause numbers continuously, avoiding repeated retrieval requests. Prompts must explicitly link to the clause scope of the current context.
The non-fixed update cycle feature requires prompts to include policy version verification logic. This ensures responses reference the latest clauses published in the current system.
The exclusive measurement unit feature requires prompts to mandate clear marking of corresponding units in responses, eliminating measurement ambiguity.
The chapter-based document feature requires limiting the multi-turn dialogue context window to chapters related to the current job scenario. This reduces interference from irrelevant content.

## Three Common Misconfigurations
- Phenomenon: A 503 error appears when uploading policy documents via the dialogue interface, while uploading knowledge base files proceeds without issues. Cause: The temporary concurrent quota of the single-file upload interface does not adapt to the single-file size of coal mining policy documents. Large structured files exceed temporary interface limits.
- Phenomenon: When using a strict Q&A template, a "answer not found" prompt displays after retrieving image addresses from the knowledge base. Cause: The strict Q&A template only matches plain text retrieval results, and does not adapt to content parsing logic for image-based knowledge bases. Switch to a general Q&A template.
- Phenomenon: A prompt stating "No permission to operate this conversation record" appears. Cause: Session ownership permissions are not bound via `chatId`, and the association between the session and user is not verified during cross-session calls.

## How to Verify Successful Configuration
- Initiate an initial question that includes a working face number. Confirm the dialogue context is tracked correctly, and follow-up questions can link to policy clauses referenced in the initial question.
- Upload a single coal mining policy document. Verify the upload proceeds without errors, and retrieval results match clause content within the document.
- Switch between strict and general Q&A templates. Verify image-based knowledge base content returns normally when using the general template.
- Initiate two questions with a short interval between them. Verify subsequent questions can interrupt the previous generation process without waiting blockages.

The values provided here are common starting points, and should be evaluated against the user’s own samples.
