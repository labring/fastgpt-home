# Policy and Regulatory Basis Q&A for Coal Mine Production: Tool Calling and Plugins

## What the data for this category looks like
Data mainly comes from official policy documents, industry standards and specifications released by the National Energy Administration and the National Mine Safety Administration, as well as internal work safety management systems of coal mine enterprises. National-level policies are updated centrally every quarter or year. Internal enterprise systems are revised as needed. Documents use structured official format, with fields including document number, issuing authority, effective date, applicable mine type, clause content, and corresponding penalty standards. Penalty standards are measured in ten thousand yuan and construction period. Clauses are marked with chapter numbers.

## What constraints these characteristics impose on tool calling and plugins workflows
The multi-field structure of structured official documents requires accurate specification of extracted fields during tool calling, to avoid irrelevant results. Policy data from multiple departments requires plugins to connect to multiple official data sources and unify formats. Policy updates occur frequently, so plugins need a regular synchronization mechanism to maintain data timeliness. Different mine types use different applicable clauses. The mine type parameter must be passed during tool calling to filter content and reduce invalid recall.

## How to configure settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Adapts to complex multi-field extraction requirements, automatically selects the appropriate tool calling path |
| `functionCall` | Enable forced function calling | Ensures tool calling returns structured results, matching the field format of policy documents |
| Multi-data source synchronization cycle | `7 days` | Matches national policy update rhythms, balances data timeliness and system resource consumption |
| Field filtering rules | Filter by applicable mine type and effective date | Matches structured fields in policy documents, narrows recall scope and improves accuracy |
| Tool calling timeout | `30–60 seconds` | Adapts to standard response times for policy document queries, avoids unnecessary waiting |

## Three common errors
- A syntax error or execution interruption occurs when running multi-line SQL query statements. This happens because the multi-line statement execution parameter for tool calling is not configured. The default setting only supports single-statement execution.
- Original policy document reference content cannot be retrieved after calling the online tool. This happens because the online tool's data source whitelist is not configured, and official policy release platforms such as the National Mine Safety Administration are not included.
- A 500 status code is returned when importing structured policy documents. This happens because the multi-field structure of the documents is not adapted, and tool calling field parsing rules do not match chapter numbers, penalty standards, and other fields from official documents.
