# Policy and Regulatory Basis Q&A for Mineral Mining and Processing: Multi-turn Dialogue and Prompt Engineering

## What This Category of Data Looks Like
Data for policy and regulatory basis queries related to mineral mining and processing is sourced from official documents, industry standards, and local mine management regulations released by natural resource authorities and mine safety supervision agencies. Update frequency aligns with policy release timelines. Documents are stored in a structured format using file number, issuing entity, effective date, clause content, and applicable mining area type. Fields include file number, issuing entity, effective date, applicable scenario, penalty and compliance terms. Single document length ranges from hundreds to tens of thousands of characters. Some temporary notices only contain dozens of compliance points.

## What Constraints These Characteristics Impose on Multi-turn Dialogue and Prompt Engineering
The wide range of policy document lengths, with some compliance documents reaching tens of thousands of characters, requires that multi-turn dialogue context handling pass historical conversation content via the `messages` parameter to avoid truncating critical compliance clauses. Policy hierarchies include national, provincial, and municipal regulatory requirements. Multi-turn dialogue must bind the current session’s policy query context via `chatId` to prevent confusion across hierarchical rules. Documents contain structured fields, so prompts must explicitly request precise returns of corresponding fields to avoid vague responses. Mineral mining and processing policies have specialized terminology. Multi-turn dialogue must pass pre-set parameters such as mining area type via `variables` to retain terminology context and ensure consistency in follow-up questions. Data updates follow no fixed schedule, so prompts must guide users to confirm the effective date of queried content to avoid referencing expired policies.

## Three Common Misconfigurations
- Issue: Input guidance configuration does not take effect during debug preview, with no preset prompt text displayed in the interface. Cause: The input guidance configuration was not refreshed synchronously after importing the custom thesaurus, or the input guidance trigger logic was not bound to the corresponding session.
- Issue: The response length for some complex policy questions is only 200 tokens, which does not match the set upper limit of 3000 or higher. Cause: The `messages` parameter for multi-turn dialogue did not properly truncate expired context, causing context to occupy too much token quota and leaving insufficient quota for long responses.
- Issue: Policy clauses from the conversation process cannot be added to the knowledge base. Cause: The automatic archiving switch for conversation content was not enabled, or the archiving path was not bound to the dedicated knowledge base category for mineral mining and processing policies.

## How to Confirm Proper Configuration
- Enter the debug preview interface, check if the preset guidance text is displayed in the input box to confirm that the input guidance configuration takes effect.
- Submit a query involving multi-hierarchy policy checks, verify that returned content covers regulatory requirements across different hierarchies to confirm that the single search limit configuration is reasonable.
- Check if the session’s `variables` parameter includes pre-set information such as current mining area type to confirm that the context binding logic is correct.
- Submit a long-text policy query, verify that the response length matches the set token limit, and check that the `messages` parameter correctly passes historical conversation content to confirm that context handling is working properly.
- Check if the custom thesaurus has been imported with specialized terminology for mineral mining and processing to confirm that the terminology recognition logic is active.

The values listed here are common starting points and should be evaluated against local deployment samples.
