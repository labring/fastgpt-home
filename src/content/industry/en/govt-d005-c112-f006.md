# Policy and Regulatory Basis Q&A for Grain Reserve: Citation Sources and Traceability

## What the Data for This Category Looks Like
Grain reserve policy and regulatory basis data comes mainly from official normative documents, departmental rules, and local grain reserve management regulations issued by national and local grain and material reserve management authorities. Data update timing adjusts with new policy releases or revisions, with no fixed cycle. Documents are mostly official papers with formal document numbers. They include fields such as issuing authority, enactment date, policy clauses, and applicable regions. There is no unified short-text chunking format. Long documents use continuous clause paragraphs as their main content unit.

## Constraints Imposed on Citation Sources and Traceability
The formal nature of grain reserve policies requires traceability to be linked to specific document numbers and clauses. The citation link must accurately match the policy's metadata identifiers. Long documents use continuous clauses as units. Chunking cannot split clause integrity. Otherwise, citations will be taken out of context. The applicable region field is clearly defined. Retrieval results must support filtering by region. This prevents cross-regional policies from being incorrectly recalled. Data updates have no fixed cycle. The knowledge base must regularly synchronize the latest revised versions. This avoids returning invalid old policy content. Differences in policy hierarchy require retrieval results to be sorted by hierarchy. This ensures response compliance.

## Configuration Settings
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| Maximum citation token count | `800–1200 token` | Matches the context length of a single grain reserve policy clause, to avoid truncating key expressions |
| Citation details toggle | Enabled | Ensures returned traceability information includes policy document numbers and original clause text, meeting compliance traceability requirements |
| Return citation data | Enabled | Retains complete knowledge base document metadata for associating policy issuing units and dates |
| Maximum number of citations | Top 3 entries | Avoids excessive citations leading to redundant responses, aligning with the precision needs of policy Q&A |
| Similarity threshold | 0.75–0.85 | Filters low-relevance policy documents, only returning content with high matching degree to the query |
| Reranking rule | Sorted by issuing date in descending order | Prioritizes returning the latest revised policy documents, ensuring timeliness of cited content |

## Three Common Misconfigurations
- Citations returned in conversations are not linked to specific policy document numbers, only showing vague file names. This occurs because the `detail` configuration item is not enabled, and full metadata display for traceability details is not activated.
- Irrelevant industry policy citations appear even after a dedicated grain reserve policy knowledge base has been uploaded locally. This occurs because hybrid retrieval filtering rules are not enabled, and recall results are not filtered by data source type.
- The number of citations in responses far exceeds the preset limit. This occurs because `quoteMaxToken` is set too large, causing the system to merge multiple unrelated policy clauses into a single citation entry.

## How to Verify Correct Configuration
- Submit a query targeting a specific grain reserve policy, check if returned results include metadata such as policy document numbers and issuing units.
- After configuring a dedicated data source, submit a cross-domain test query to confirm only grain reserve-related policy citations are returned.
- After adjusting the maximum number of citations, verify that the number of citations displayed in responses matches the configured value.
- Test queries related to older policies, confirm that returned policy versions are the latest revised content.

The values provided are common starting points and should be measured against the reader's own samples.
