# Document and Material Drafting for "One Thing Done Efficiently" Joint Handling: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Data sources include the national government service platform "One Thing" special zone, local integrated government service platforms, electronic certificate database, and various department approval systems. Data is updated daily. Daily documents include joint handling item lists, one-time notice sheets, joint handling application forms, material circulation sheets, parallel approval opinions, and completion receipts. Fields cover item codes, joint handling department lists, required material details, pre/post handling relationships, handling node requirements, and more. Single document lengths vary widely, from several hundred characters for notice sheets to several thousand characters for approval opinions.

## Constraints imposed on knowledge base retrieval and recall
Daily updated data from multiple sources requires retrieval systems to support incremental synchronization and permission isolation. This prevents cross-department document confusion. Diverse document structures require adaptation to different chunking and recall rules. This ensures accurate matching of both structured item lists and unstructured approval opinions. Cross-department field associations require retrieval results to cover materials and process requirements from multiple departments. A single recall result cannot meet joint handling needs. Additionally, joint handling item logic relies on pre/post handling relationships. Recalled documents must accurately associate each department’s handling nodes. Otherwise, missing document materials or process errors may occur.

## Configuration Settings
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.72–0.80 | Matches the accuracy requirements for joint handling items, preventing low-relevance cross-department documents from appearing in retrieval results |
| `limit` | Top 8 entries | Covers multi-department materials and process documents required for joint handling, while controlling context length to avoid exceeding model limits |
| `searchMode` | hybrid | Combines keyword and semantic retrieval, adapting to structured item lists and unstructured notice sheets and approval opinions |
| `usingReRank` | Enabled | Re-ranks initial recall results, corrects semantic deviations in cross-department documents, and improves the ranking priority of key information |
| `datasetSearchUsingExtensionQuery` | Enabled | Expands question wording to match synonymous expressions for joint handling items, such as "parallel handling" and "joint handling", improving recall coverage |
| `collectionIds` | Dataset IDs bound by joint handling departments | Limits retrieval scope, only recalling documents from departments involved in the current joint handling item, avoiding interference from irrelevant data |

## Three Common Misconfigurations
- Phenomenon: Retrieval results return documents unrelated to the current joint handling item. Cause: No exclusive dataset bound via `collectionIds`, leading to recall of non-associated documents from other departments.
- Phenomenon: Retrieval latency for the same question varies significantly, ranging from 1 second to 20 seconds. Cause: No `limit` parameter set, resulting in excessive recalled documents, or `usingReRank` not enabled, causing additional re-ranking calculations.
- Phenomenon: Generated document materials miss cross-department material requirements or process nodes. Cause: `datasetSearchUsingExtensionQuery` not enabled, unable to recognize synonymous joint handling expressions in user questions, leading to incomplete recalled material lists.

## How to Verify Proper Configuration
- View retrieval logs to confirm all returned documents come from the bound joint handling department datasets, verifying that the `collectionIds` configuration takes effect.
- Run multiple retrieval tests for the same question, confirm latency fluctuations fall within a reasonable range, verifying the configuration effects of `limit` and `usingReRank`.
- Input joint handling questions using synonymous expressions, confirm recalled material lists cover all cross-department requirements, verifying that `datasetSearchUsingExtensionQuery` takes effect.
- Adjust the `similarity` threshold, test recall accuracy for different questions, confirm matching results meet the actual requirements of joint handling items.

The values provided are common starting points and should be measured against the reader's own samples.
