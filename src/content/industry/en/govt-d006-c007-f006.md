# Document and Material Drafting for Petition Matter Handling: Citation Sources and Traceability

## What This Category of Data Looks Like
This category involves entities including petition bureaus, departmental petition offices, subdistrict and township offices, and responsible unit offices. Daily generated documents cover statutory handling materials such as petition registration forms, acceptance notices, transfer and assignment letters, handling opinions, review and reexamination applications, and resolution plans. Data sources include the national petition information system, local petition systems, the 12345 citizen hotline platform, grassroots governance platforms, and historical petition archives. The system updates data daily. Each individual document includes structured fields such as petitioner information, matter description, handling process nodes, and legal basis. Matters handled across multiple departments require association with collaborative data from multiple systems.

## Constraints on Citation Sources and Traceability
Data sources cover multiple government systems. The citation link must accurately match field formats across different platforms to avoid cross-system data confusion. Real-time daily updates require citation sources to pull the latest handling status synchronously. This ensures document content aligns with current matter progress. Petition documents are statutory handling materials. Citation traceability must guarantee source uniqueness and traceability. Otherwise, repeated petitions or corrected handling opinions may result during review. Different document types have distinct format specifications. Adjustments to citation content display logic are required for each type, including acceptance notices and handling opinions.

## Configuration Settings
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Basis for This Approach |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Citation paragraphs for petition documents must be controlled in length to avoid interfering with the statutory expression logic of the main text |
| `responseData` | Return only structured data associated with petition systems | Filter non-business redundant data to ensure citation sources only include core handling information for petition matters |
| `detail` | Include detailed content of acceptance number and handling node fields | Meet the format requirements for petition documents to mark statutory handling basis and traceable numbers |
| Citation source display position | Separate paragraph at the end of the document | Complies with statutory format specifications for petition documents, enabling quick location of citation content during review |
| Citation source matching threshold | 0.75–0.85, calibrated via actual testing | Petition data fields are rigorous, requiring a high matching degree to avoid incorrect association with unrelated matters |
| Single recall citation source upper limit | Top 5 entries | Avoid excessive citation content distracting from core document information, aligning with reading habits in grassroots handling scenarios |

## Three Common Mistakes
1. The citation source in generated petition documents fails to associate with the acceptance number of the corresponding petition system. Cause: `responseData` is not configured to extract only structured business fields, resulting in non-petition business data being mixed in.
2. Generated citation content is overly long, causing document layout confusion. Cause: The value of `quoteMaxToken` is not adjusted, exceeding the reserved citation paragraph space of the document.
3. The default value of the form input node cannot reference petition matter variables. Cause: The variable reference path is not configured according to the field naming rules of petition matters, resulting in variable parsing failure.

## How to Confirm Configuration Is Complete
- Import a historical petition registration form, trigger the document generation process, and check whether the generated document includes the acceptance number of the corresponding system as the citation source.
- View the citation paragraph at the end of the generated document, confirming that the token count of the citation content falls within the range configured for `quoteMaxToken`.
- Fill in the title of a petition matter in the configuration of the form input node, test whether the default value can correctly call the variable content of the corresponding field.
- Simulate a cross-department collaborative handling scenario, check whether the citation source can trace back to the complete handling record of the original petition archive.

The values provided are common starting points and should be measured against the reader's own samples.
