# Document and Material Drafting for Highway Maintenance and Road Property Rights Management: Tool Calling and Plugins

## What the data for this category looks like
Data for this category mainly comes from highway maintenance management systems, bridge and tunnel monitoring systems, road administration patrol systems, and traffic flow monitoring data. The update frequency is daily. Daily generated documents include maintenance plans, patrol logs, defect disposal orders, road construction permits, and road property damage compensation forms. Document fields usually include facility numbers, road section ranges, monitoring data, disposal time limits, involved parties, and similar items. The field structures of different documents vary significantly. Patrol logs focus on real-time patrol records. Road construction permits focus on content related to approval processes. Units involved include specific measurement units such as road section length and area.

## What constraints these characteristics impose on the tool calling and plugins workflow
The diversity of data sources requires tool calling to adapt to authentication configurations for multiple data sources. Authentication formats differ across systems, so separate configurations are required. The daily update frequency means the tool calling trigger rhythm must match the data update cycle, to avoid calling outdated data. Differences in document structures require tool calling to adapt to field mapping rules for different documents, to prevent mismatched fields when generating documents. Data accuracy requirements mandate that tool calling verify the completeness of required fields, to stop generated documents from failing to meet business specifications. Additionally, errors in this category can lead to road safety issues, fund use disputes, and similar consequences. This means tool calling results must undergo compliance checks.

## How to set configurations
These configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Adapts to tool calling needs for multiple document types such as maintenance plans and patrol logs |
| `functionCall` | Grouped by document type | Matches differences in field structures across different documents |
| Authentication configuration | Configured separately by data source | Authentication formats differ across data sources such as highway maintenance management systems and road administration patrol systems |
| Timeout setting | 600 seconds | Provides sufficient response time to process full daily updated data |
| Single call limit | First 5 entries | Controls the volume of data returned by tool calls |
| Field extraction length | 800–1200 characters | Adapts to field extraction lengths for documents such as patrol logs |
| Result verification | Required fields must not be empty | Ensures generated documents include necessary business information |

## Three common errors
- Phenomenon: `toolChoice` is set to a fixed value, which cannot adapt to tool calling needs for multiple document types. Cause: No automatic tool selection rules are configured, so tool calling can only handle a single document type.
- Phenomenon: Tool calls return a 401 authentication failure error. Cause: Authentication information is not configured separately by data source, so access to road administration patrol systems or bridge and tunnel monitoring systems is denied.
- Phenomenon: Generated documents lack the road section number field. Cause: No field mapping rules are configured, so fields extracted by tool calls do not match the required fields of the document.

## How to confirm the configuration is correct
- Test tool calls, check that the return result of `functionCall` includes the fields of the target document, such as patrol time and road section number from patrol logs.
- Confirm that after authentication configuration passes, tool calls return normal data with no 401 or 403 errors.
- Test that generated documents include all required fields, such as facility numbers and road section ranges.
- Check that the tool call timeout setting meets business requirements, and no timeout errors occur.

The values provided here are common starting points, and should be evaluated against the user's own samples.
