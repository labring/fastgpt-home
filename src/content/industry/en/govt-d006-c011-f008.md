# Document and Material Drafting for Pension, Work Injury, and Unemployment Benefit Verification: Document Parsing and Chunking

## What this category of data looks like
Data for this category originates from social insurance management systems, personal benefit records, labor relations and work injury verification systems, and the electronic social security card platform. The update frequency is daily.
Documents processed daily include benefit application forms, payment period certificates, retirement approval forms, work injury verification materials, and unemployment benefit application materials. These documents often contain multi-column structured tables, with fields covering personal identity information, payment periods, benefit calculation items, and qualification determination conclusions. Some documents include attached electronic credential attachments.

## What constraints do these characteristics impose on the document parsing and chunking step
The multi-column structured document characteristics of this category can cause generic chunking logic to incorrectly split cross-column headers and data rows, breaking the integrity of field associations.
The high daily volume of updated documents requires the parsing process to have stable timeout fault tolerance, to avoid interruptions during batch processing.
There are significant structural differences between different document types. The layout structures of work injury verification materials and unemployment benefit application materials differ notably, requiring adaptive chunking strategies.
Additionally, associated fields included in documents (such as payment periods and benefit calculation items) require that context associations be retained during chunking, to avoid splitting business logic.

## How to Configure
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Preserve context for multi-column tables and long business fields, avoid splitting associated payment and benefit calculation content |
| `chunkSplitter` | Split by paragraph and table boundaries | Match the structure of mixed text and multi-column table documents, prevent table content from being forcibly split by character count |
| `customPdfParse` | Enable structured parsing mode | Retain row and column associations for multi-column tables in PDF documents, resolve misalignment issues with multi-column content parsing |
| `UPLOAD_FILE_MAX_SIZE` | 50 MB | Match the size of daily batch-uploaded social insurance documents, avoid parsing failures for large files |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Accommodate parsing time for long multi-page documents, meet stability requirements for daily batch processing |
| `chunkSettingMode` | Manual configuration | Adjust chunking parameters separately for the three categories of pension, work injury, and unemployment documents |

## Three Common Mistakes
- Phenomenon: Column misalignment or missing fields appear after uploading multi-column structured tables; table content from payment period certificates is only displayed as single-column text. Cause: The structured parsing mode of `customPdfParse` is not enabled, and the generic chunking logic incorrectly splits multi-column content into scattered text.
- Phenomenon: Embedded electronic credential images in PDF-format work injury verification materials cannot be parsed and extracted after upload, and no associated content appears in knowledge base retrieval. Cause: The image extraction switch for `customPdfParse` is not configured, and only the text portion of the document is parsed.
- Phenomenon: Parsing timeouts occur for batch-uploaded unemployment benefit application materials, and background task status shows failure. Cause: `PARSE_FILE_TIMEOUT_SECONDS` is set too short, failing to accommodate parsing time for multi-page long documents.

## How to Confirm Proper Configuration
- Upload a standard pension benefit application form, check if the parsed chunked content retains the row and column associations of the table, with no misalignment or missing fields.
- Upload a work injury verification PDF that includes embedded images, confirm that the parsed result includes associated content from the images.
- Upload a social insurance document larger than 20 MB, check if the parsing task completes within the preset time with no timeout errors.
