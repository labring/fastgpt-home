# Document and Material Drafting for Medical Institution Supervision and Public Health Inspection: Workflow Orchestration

## What This Category of Data Includes
Data for this category comes from health supervision information systems, medical institution electronic registration systems, complaint reporting platforms, and law enforcement inspection records. Updates occur on a monthly basis. Commonly processed documents include supervision inspection forms, medical institution practice licenses, rectification notices, supervision opinions, and penalty case files. Most document structures contain institution qualification fields, on-site inspection items, rectification requirements, and penalty basis. Fields cover structured and semi-structured content such as institution name, unified social credit identifier, inspection date, and rectification time limit.

## What Constraints These Characteristics Impose on Workflow Orchestration
Monthly updated data sources do not require frequent synchronization. Configure scheduled pull tasks for data updates. Multiple data sources require workflows to connect cross-system pull nodes. Address differences in field naming across systems. Documents include sensitive materials such as penalty case files. Add permission verification links to ensure data access compliance. Semi-structured on-site inspection records need information extraction steps. Use these steps to automatically populate inspection item content in documents. Associating institution qualification data with on-site inspection data is core to document generation. Set clear association rules to ensure accurate data matching.

## Configuration Settings
The following configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Variable Binding | Bind multi-source `variables` using the unified social credit identifier as the core key | Data for this category comes from multiple business systems. Binding `variables` via the core key ensures accurate associated data for document generation |
| Node Timeout | 600 seconds | Cross-system pulls of health supervision information and medical institution registration data have long response cycles. Allowing sufficient time prevents node failures |
| Concurrency Limit | 30-50 concurrency (calibrated via actual testing) | Matches the hardware carrying capacity of a single node, avoiding service interruptions caused by resource exhaustion |
| JSON Input Handling | Enable variable selection mode | Penalty case files and rectification notices for this category require embedded dynamic business fields. Supporting variable selection simplifies dynamic content configuration |
| Data Source Synchronization | Monthly update | Matches the monthly update frequency of data for this category, reducing invalid data pull requests |

## Three Common Misconfigurations
- Symptom: A workflow running on a single node triggers a service crash, with memory usage rising continuously to the threshold. Cause: No reasonable concurrency limit is set, exceeding the hardware resource carrying capacity of a single node. This corresponds to the common concurrency stress test anomaly issue in actual scenarios.
- Symptom: Documents generated via API-triggered workflows lack core business fields. Cause: Multi-source business data is not correctly bound via `variables`, leading to missing data associations and inability to populate required document fields.
- Symptom: Predefined business variables cannot be selected during JSON input configuration. Cause: The variable selection mode for JSON input is not enabled. The input box only supports static text input, making it impossible to embed dynamically generated business content.

## How to Verify Correct Configuration
- Manually trigger the workflow, check if the generated supervision inspection form includes required fields such as the unified social credit identifier and inspection date of the current inspection institution.
- Call the API to trigger the workflow, review the field completeness of the returned results, and confirm that multi-source data has been correctly associated.
- Adjust the concurrency limit to 30 concurrency, run a stress test script, and confirm that no service crash or timeout occurs on the single node.
- Enable the variable selection mode for JSON input, attempt to embed a predefined institution qualification variable, and confirm that the input box can normally recognize and load variable options.
