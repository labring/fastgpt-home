# Document and Material Drafting for Social Insurance Registration and Premium Verification: Source Citation and Traceability

## What Data for This Category Looks Like
The data for this category comes from social insurance handling systems, tax social insurance premium collection systems, market entity registration information, and shared public security and civil affairs data. The update frequency is daily. Daily generated handling documents include social insurance registration forms, payment base declaration forms, personnel adjustment forms, social insurance premium verification notices, and personal benefit records. Document structures include core fields such as personnel identity identifiers, labor relationship information, payment base, and verified amount. Data fields correspond one-to-one with form items in the handling process, with no extra redundant information.

## What Constraints These Characteristics Bring to the "Source Citation and Traceability" Link
Data originates from multiple sources and is updated daily. Traceability must clearly mark the data source system and generation time to avoid mixing data across cycles. Document fields strictly correspond to form items. Cited content must fully match original form fields, with no field misalignment. Errors directly affect payment compliance and personal rights and interests. The traceability link must have a complete auditable trail, and core verification steps cannot be omitted. At the same time, query responses for handling data have a fixed delay. The traceability process must adapt to system response rhythms to avoid timeout interruptions.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the content length of a single social insurance handling document, ensuring complete citation of core fields and source information |
| `responseData` | Return only data source identifiers and generation time | Complies with compliance requirements for social insurance handling data traceability, preventing irrelevant information from interfering with document drafting |
| `detail` | Enabled | Supports displaying original fields of cited data, making it easier to verify core content such as personnel identity identifiers and payment base |
| Single search limit | Top 3 results | Limits the number of recalled results, avoiding confusion across multiple system data, and focusing on core data from the current handling cycle |
| Maximum context | 600 seconds | Adapts to the response delay of social insurance system data queries, ensuring traceability processes do not time out |

Reference only; verify against the target FastGPT release and deployment documentation.

## Three Common Configuration Mistakes
- The cited payment base field is empty in generated documents. This occurs because the `detail` configuration is not enabled, and core field information from original data is not extracted.
- The generated document cites social insurance data from a non-current handling cycle. This occurs because the single search limit is not set, and historical redundant data is recalled, leading to confusion in traceability matching.
- A timeout error occurs when triggering a traceability query. This occurs because a reasonable maximum context duration is not set, exceeding the query response delay of social insurance handling systems.

## How to Verify Proper Configuration
- Generate a draft payment base declaration form, and check whether the citation module marks the data source system and generation time.
- Input a query containing historical personnel adjustment information, and confirm that the returned cited data only includes content from the current handling cycle.
- Test triggering a traceability query, and confirm that the response duration does not exceed the preset maximum context duration.
- Check whether the generated document includes core fields from original data, such as personnel identity identifiers and payment base.

The configuration values provided are common starting points, and should be evaluated against applicable samples.
