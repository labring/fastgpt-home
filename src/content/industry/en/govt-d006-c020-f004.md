# Document and Material Drafting for Territorial Spatial Planning Compilation and Implementation Evaluation: Workflow Orchestration

## What this category of data looks like
Data for this category primarily originates from the territorial spatial basic information platform, natural resource survey and monitoring data, population and economic statistics, and remote sensing images. The update frequency is annual. Documents produced daily include territorial spatial overall plans, detailed plans, special plans, planning implementation evaluation reports, public opinion summaries, and more. Document structures typically include modules such as spatial scope delineation, constraint indicator lists, layout plan explanations, multi-source data supporting materials, and feedback opinion collation. Fields cover spatial coordinates, population scale, facility layout, and other content. Some fields use units including square kilometers, hectares, and ten thousand people.

## What constraints do these characteristics impose on the workflow orchestration link?
Multi-source cross-platform data updates annually. This requires configuring timed synchronization nodes in workflows to ensure input data uses the latest version. Documents have complex multi-module structures. Different content nodes must be processed separately to avoid context overload. Links such as data summarization and layout coordination take significant time. Parallel processing nodes should be set up to optimize the workflow. Documents involve spatial constraint indicators. Field verification nodes must be configured to ensure data units and formats meet requirements. Errors in any link will cause delays in planning approval. Failure rollback and retry nodes should be configured to ensure process stability.

## Three common misconfigurations
- A timeout error is returned directly by the tool invocation link after the workflow initiates a data synchronization request. This occurs because the configured timeout duration does not meet the data processing requirements of this category, and the time required for spatial data loading exceeds the preset threshold.
- Global variables do not update as expected, and constraint indicators in planning documents do not display the latest annual data. This occurs because the variable update trigger logic is not configured after the timed synchronization node, or the variable reference does not bind the correct `variables` parameter.
- The main body of the document cannot correctly reference preset variables, and the content of the public opinion summary module is empty. This occurs because the variable reference path is not correctly configured in the main body editing link, or the initial variables are not preset with correct content matching the category document structure.

## How to verify a complete configuration
- Check whether the `variables` parameter binds the annually updated data fields required by documents in this category, and verify that the initial variable values match the template structure.
- Confirm that each workflow node has a unique `nodeId`, and that node status can be tracked precisely.
- Simulate the data synchronization link to validate whether the failure retry and timeout configuration matches the actual processing time required for this category’s data.
- Generate a test document, check whether variables are correctly referenced in each module of the main body, and confirm that fields such as public opinions and constraint indicators display normally.
