# Document and Material Drafting for Territorial Spatial Planning Compilation and Implementation Evaluation: Tool Calling and Plugins

## What the data for this category looks like
The data for this category mainly comes from the territorial spatial basic information platform, natural resource survey and monitoring data, population and economic statistical datasets, and public remote sensing images. Daily produced documents include territorial spatial overall planning, detailed planning, special planning texts, planning implementation evaluation reports, and public opinion summary forms. The data update cycle is annual. Document structures include fields such as spatial constraint indicators, regional layout plans, and cross-department coordination opinions. Some fields need to match spatial coordinates and statistical units.

## What constraints do these characteristics impose on the tool calling and plugins link
Since most data sources are static spatial and statistical datasets updated annually, tool calling must first bind existing data in the local knowledge base to avoid redundant real-time network requests. Documents contain multi-source coordination content and structured fields, so plugins must support reading long text passages and table data to avoid truncating key constraint indicators. Since planning documents require cross-department coordination, the context of tool calling must retain the opinion summary results from previous links to ensure complete parameter transfer. At the same time, since the data involves public management content, plugin calling must restrict access scope to ensure data security.

## How to set the configuration
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | Set to `auto` | Automatically match planning document parsing and data verification plugins to adapt to processing needs for multiple types of planning texts |
| `functionCall` | Enabled | Support plugin calling of structured data verification logic to ensure that planning indicators match document content |
| Plugin port restriction | Set to local loopback address | Prevent public network access to plugin interfaces and reduce the risk of territorial spatial data leakage |
| Single plugin call duration | 600 seconds | Adapt to time requirements for long text parsing and multi-source data verification |
| Context retention length | 8000–12000 token | Retain complete context of previous public opinions and spatial layout plans to ensure accurate parameter transfer |

## Three Common Misconfigurations
- Phenomenon: Only the local knowledge base is retrieved during tool calling, and network search cannot be triggered. Cause: The `toolChoice` configuration is not adjusted, the default binding of the local knowledge base is used, and cross-source data calling logic is not enabled.
- Phenomenon: Previous planning opinion conclusions cannot be passed during plugin calling. Cause: Insufficient context retention length is not set, resulting in truncation of previous content, which cannot be used as subsequent prompt input.
- Phenomenon: Security alerts are triggered after the plugin interface is exposed to the public network. Cause: The access network segment of the plugin port is not restricted, and the interface is exposed directly using a public network port, introducing data leakage risks.

## How to Confirm the Configuration Is Complete
- Enter the plugin management page of the FastGPT v4.17.0 application, check the configuration status of `toolChoice` and `functionCall`, and confirm that they are set as required.
- Upload a planning implementation evaluation report to trigger plugin calling, and check whether the returned results include data verification and structured parsing content.
- View the plugin access logs to confirm that only intranet or local addresses initiate calls, and there are no abnormal public network access records.
- Test plugin calling for long text documents to confirm that the context is fully retained, and no truncation of key spatial indicators or opinion content occurs.
