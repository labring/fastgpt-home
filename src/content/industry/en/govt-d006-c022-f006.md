# Document and Material Drafting for Land Use Rights, Mining Rights, and State-Owned Property Transactions: Source Citation and Traceability

## What this category of data looks like
This category of data primarily originates from the national public resource trading platform, natural resource trading systems, property right exchange systems, and state-owned asset supervision systems, with a daily update frequency. Daily produced documents include transfer announcements, trading notices, bid application forms, margin vouchers, transaction confirmation letters, listing result announcements, property right transfer specifications, and more. Core fields cover trading object ownership information, restriction conditions, margin amount, trading process nodes, transaction results, and other relevant details. The document structure primarily combines structured tables and paragraph descriptions.

## What constraints do these characteristics impose on the "source citation and traceability" link?
The multi-data-source nature requires the traceability link to support cross-system data associated display, to avoid confusion in cross-data-source citations. The daily update frequency requires the index synchronization mechanism to maintain near-real-time performance, ensuring that cited content aligns with the latest trading data. Documents include structured tables and paragraph descriptions, requiring precise matching of fields and context to avoid discrepancies between cited content and the actual situation of the trading object. The seriousness of ownership information and transaction results requires traceability to locate specific document entries, clearly mark the belonging data source and original voucher number, to ensure citations are traceable.

## How to set the configurations
The following configurations are adapted for FastGPT v4.17.0

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 characters | Must fully cover core content such as trading announcements and ownership descriptions, to avoid truncation of cited information |
| Single search limit | Top 5 results | Core trading information for this category is concentrated in the top 5 search results, to avoid interference from redundant data |
| `responseData` | Enable source field display | Ensure that returned cited content includes original document source identifiers and entry information |
| `detail` | Enable | Can return complete fields of cited documents, meeting the needs of detailed verification of ownership and trading conditions |
| Index synchronization cycle | Once daily | Matches the daily update frequency of business data, ensuring timeliness of cited content |

## Three common mistakes
- Phenomenon: The generated response does not include any citation sources. Cause: The core configuration for citation traceability is not enabled, or the knowledge base index is not associated with the trading system data source for this category.
- Phenomenon: The number of search results does not match the configured single search limit. Cause: Index refresh is not timely, causing old data to overwrite new trading documents, or the search matching threshold is set incorrectly.
- Phenomenon: Only the citation list is returned without response content. Cause: `quoteMaxToken` is set too small, truncating core response content and only retaining citation metadata.

## How to confirm the configuration is properly set
- Initiate a query targeting a specific trading object, check whether the response includes the source identifier and entry information of the corresponding document.
- View the knowledge base index refresh log, confirm that the synchronization frequency matches the configured index cycle.
- Test queries of different lengths, verify that the response content and citation sources are fully matched without truncation.
- Simulate an exception scenario, such as entering a non-existent object number, check whether a clear no-match result prompt is returned.

The values provided are common starting points and should be measured against the reader's own samples.
