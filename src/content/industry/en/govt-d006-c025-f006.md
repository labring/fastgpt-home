# Document and Material Drafting for Safety Production Hazard Inspection and Governance: Source Citation and Traceability

## What the data for this category looks like
The data sources for this category include safety production supervision systems, enterprise hazard self-inspection systems, law enforcement inspection records, and accident statistics systems. The update frequency is daily. Commonly generated documents include hazard inspection lists, hazard management ledgers, rectification notices, review records, and major hazard suspension and supervision orders. Document fields include hazard number, inspection subject, hazard description, rectification requirements, review conclusion, etc. Units follow the field definitions of the documents themselves: for example, rectification time limit is measured in days, and inspection records are measured in units of entries.

## What constraints these characteristics impose on the "source citation and traceability" link
Multi-source and heterogeneous data sources require configured cross-knowledge base associated retrieval to ensure that original records from different systems can be called simultaneously. The daily update rhythm requires setting high-frequency index refreshes to avoid referencing outdated hazard information. Fixed-format business documents require precise matching of specific fields such as hazard number and rectification time limit during traceability, to ensure that referenced content corresponds one-to-one with documents. The high-risk business attribute requires that traceability results can be directly traced back to original law enforcement or self-inspection records, to avoid compliance issues caused by vague citations.

## How to set the configurations
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Value Range | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Adapts to the text length of a single hazard inspection record, avoiding truncation of key judgment content |
| `responseData` | Enabled | Mandatorily returns identifiers and source paths of original traceability data to meet compliance requirements |
| `detail` | Full | Displays all fields of original records, facilitating verification of core information such as hazard number and rectification time limit |
| Single search limit | Top 5 entries | Matches the average number of hazard entries in a daily inspection list, ensuring coverage of all inspection content |
| Knowledge base refresh frequency | Daily | Matches the daily update rhythm of business data, ensuring the timeliness of referenced content |

## Three common mistakes
- After configuring the citation traceability function, a red error prompt is displayed on the interface. The cause is that the current workflow is not granted access permissions to safety production-related knowledge bases, resulting in failure to pull original traceability data.
- Only the first node in the workflow triggers knowledge base citation, and subsequent nodes return no results. The cause is that variables of the knowledge base retrieval node are not set to be globally reusable, or the variable reference rules are not correctly matched in subsequent nodes.
- Attempting to reference the knowledge base ID via a variable fails. The cause is that the variable scope does not cover the current workflow node, or the variable name conflicts with system configuration items.

## How to confirm the configuration is complete
- Draft a hazard rectification notice, verify whether the referenced hazard information is accompanied by source identifiers and numbers of original records.
- Trigger a multi-round hazard inspection workflow, confirm that each node can normally call the knowledge base and return complete traceability content.
- Adjust the value of `quoteMaxToken`, verify that long-text hazard records are fully referenced without truncation.
- View the knowledge base index management page, confirm that the daily automatic refresh task is executing normally with no failed logs.
