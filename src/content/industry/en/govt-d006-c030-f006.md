# Document and Material Drafting for Construction Engineering Quality and Safety Supervision: Citation Source and Traceability

## What This Category’s Data Looks Like
Business data for this category comes from the engineering quality and safety supervision system, construction site real-name management platform, supervision logs, and test reports. Daily drafted documents include supervision plans, supervision inspection records, hidden danger rectification notices, quality problem handling forms, and completion acceptance supervision reports.
Data is updated weekly. Most documents contain standard business fields: on-site inspection items, rectification closed-loop records, and acceptance verification parameters. There are no additional custom statistical units, and all content strictly follows the standardized formats of the existing housing and urban-rural development system.

## Constraints on Citation Source and Traceability
Dispersed multi-source business data requires the citation and traceability process to support association with multiple independent knowledge bases. This covers different data sources such as supervision systems, on-site platforms, and supervision logs.
The weekly update rhythm requires the knowledge base synchronization cycle to match business data circulation. This avoids citing outdated rectification or inspection records.
Fixed-format business documents require precise matching of corresponding fields during citation. This prevents irrelevant content from being mixed into drafting contexts.
Additionally, traceability for quality and safety-related documents must strictly correspond to original records. Any citation deviation could impact subsequent rectification closed-loop or completion acceptance processes.

## How to Set the Configuration
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum context token count | 8000–12000 token | Matches the typical content length of a single completion acceptance supervision report, to avoid truncating core traceability information |
| `quoteMaxToken` | 2000–3000 token | Limits the length of a single cited content segment, matching the typical length of on-site inspection records and supervision logs |
| Citation source return method | Return original text as-is | Ensures original document content can be directly verified during traceability, aligning with the voucher attribute of regulatory business |
| `responseData` switch | Enabled | Forces return of original knowledge base text fragments, meeting the requirement to directly output original content |
| Single recall result limit | Top 6 entries | Covers the typical source materials associated with a single supervision inspection record, avoiding redundant information interfering with document drafting |
| `detail` mode | Enabled | Retains the original format and business fields of cited content, avoiding format errors when generating documents |

Reference only; verify against the target FastGPT release and deployment documentation.

## Three Common Misconfigurations
- Phenomenon: Generated documents do not include original knowledge base text fragments, only AI-edited content. Cause: The `responseData` switch is not enabled, or the citation source return method is set to a non-original text mode.
- Phenomenon: The total length of cited content returned by a single retrieval exceeds the model’s capacity limit, causing system errors or timeouts. Cause: No upper limit is set for the `quoteMaxToken` parameter, or the set value exceeds the preset range.
- Phenomenon: Cited materials do not match the currently drafted document, and irrelevant historical rectification records are mixed into the context. Cause: The single recall result limit is set too high, or precise matching recall is not performed based on document fields.

## How to Verify Proper Configuration
- Draft a supervision inspection record, and check whether the generated result includes original text fragments from test reports and supervision logs.
- Check system operation logs to confirm that cited content returned by each retrieval does not exceed the length limit set by the `quoteMaxToken` parameter.
- Test knowledge bases associated with multiple data sources, and verify that generated hidden danger rectification notices can simultaneously reference records from the supervision system and real-name management platform.
- Adjust the single recall result limit, and check whether the number of returned cited entries matches the preset quantity requirement.

The values provided here are common starting points and should be measured against the reader's own samples.
