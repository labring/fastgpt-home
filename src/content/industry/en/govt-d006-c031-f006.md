# Document and Material Drafting for Construction Project EIA Approval: Source Citation and Traceability

## What Data for This Category Looks Like
Daily documents for this category include environmental impact assessment reports or report forms, approval applications, public participation statements, technical evaluation opinions, and EIA approval decisions. Data sources cover the national unified construction project EIA declaration and approval system, ecological environment zoning control results, pollution discharge permission platform, and monitoring data. There is no fixed update cycle; updates are synchronized with project declaration progress and policy adjustments. Document structures include professional fields such as basic project information, EIA level determination, pollution prevention measures, and public participation status. Minor differences in field formats exist across data from different sources.

## Constraints Imposed on Source Citation and Traceability
Since data comes from multiple cross-departmental systems, there are minor differences in field naming and format across sources. Unified mapping must be completed during the traceability link to avoid mismatches between cited content and real approval data. The lack of a fixed update cycle requires the traceability system to support incremental synchronization and version verification, ensuring cited monitoring data and ecological environment zoning control results are the latest valid versions. The complex document structure and professional fields require traceability-retrieved content to accurately correspond to core links such as EIA level and pollution prevention measures, avoiding redundancy or missing content that affects document compliance.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the length of core citation passages in EIA documents, avoiding content truncation or context overflow |
| `responseData` | Return system identifier, update time, and project number of matching sources | Meets the traceability requirements of EIA approval documents, clarifying the source and validity of cited data |
| `detail` | Enabled | Displays the full context of cited content, facilitating verification of pollution prevention measure compliance |
| Single search limit | Top 6 entries | Covers core matching results from major data sources, avoiding redundant information interfering with document drafting |
| Reranking rule | Descending by matching degree | Prioritizes approval data and control results most relevant to the current EIA project |
| Context window duration | 600 seconds | Adapts to delays in cross-system data retrieval, ensuring complete acquisition of cited source data |

## Three Common Configuration Errors
- Incorrect binding of knowledge base variables, resulting in generated documents being unable to link to real project data from the national unified construction project EIA declaration and approval system. This occurs because the corresponding category-specific knowledge base was not selected when referencing configuration variables, and only the general document library was called.
- Failure to set a reasonable value for `quoteMaxToken`, resulting in truncation of long citation passages and inability to fully display core content of public participation statements. This occurs because the default value is too small and does not adapt to the length characteristics of EIA documents.
- Failure to regularly clean expired embedding vector files, resulting in unexpected disk usage of the knowledge base. This occurs because no automatic cleanup policy was configured, and all historical data of original files, split chunks, and embedding vectors were retained.

## How to Verify Successful Configuration
- Generate an EIA approval application document, and check whether the source system, update time, and project number are marked below cited content.
- Enter the knowledge base management page of FastGPT v4.17.0, and confirm that designated data sources including the national unified construction project EIA declaration and approval system and ecological environment zoning control results have been added.
- Test calling tools to generate citation fragments, and verify that the value of `quoteMaxToken` limits the token count of cited content.
- Check disk usage statistics of the locally deployed FastGPT, and confirm that only three types of data are included: original files, split file chunks, and embedding vectors.
