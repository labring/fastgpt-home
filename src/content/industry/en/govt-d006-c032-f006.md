# Document and Material Drafting for Investment Project Approval and Post-Evaluation: Citation Sources and Traceability

## What this category of data looks like
This category of data covers the entire process of central enterprise strategic investment, project implementation and post-evaluation. Daily documents include annual investment plans, project proposals, feasibility study reports, due diligence reports, post-investment evaluation reports, and more. Data sources include the State-owned Assets Supervision and Administration Commission investment supervision system, enterprise ERP and project management systems, industry market data, audit and financial statements. Data is updated quarterly. Core fields include project investment scale, demonstration conclusions, post-evaluation rectification requirements, and other key information.

## What constraints these characteristics impose on the citation sources and traceability link
The formal document attributes and state-owned assets supervision requirements of this category require that the citation traceability link strictly matches official data sources, and must not be associated with irrelevant content. Data is updated quarterly, so the data source version of the knowledge base must be synchronized regularly to avoid citing expired supervision or financial data. Fields involve professional investment terminology and large-value asset information, so the corresponding data sources must be accurately retrieved to prevent retrieving non-investment documents. At the same time, traceability must fully record the source system and update time of the cited documents to meet the traceability requirements of state-owned assets audits.

| Single search limit | Top 5 entries | The number of core documents in this category is limited. Limiting the number of retrieved entries avoids redundant content and ensures traceability accuracy |

| `quoteMaxToken` | 2000–3000 token | Key information of cited sources must be fully retained to meet the traceability requirements of state-owned assets audits |
| Citation source display toggle | Enabled | Citation document sources must be included in formal outputs to comply with state-owned assets supervision compliance requirements |
| `detail` | High | Documents in this category require complete presentation of demonstration basis. A high detail level ensures that the LLM accurately associates citation positions with document chapters |
| `responseData` | Enable traceability mode | Adapts to the category's requirements for complete citation information, ensuring output content is traceable |

## Three common misconfigurations
- Symptom: Citation source information is not displayed on the formal chat page, but displays normally on the debug page. Cause: The citation source display toggle is not enabled, or the corresponding output item is not checked during configuration.
- Symptom: The number of retrieved cited documents is controlled by a score threshold, which does not meet the business requirements for entry limits. Cause: The citation count restriction rule is not configured correctly, and the score threshold is mistakenly used as the retrieval judgment standard.
- Symptom: The cited content in the generated post-evaluation report is misaligned with the original text, and cannot match the corresponding document chapter. Cause: The `detail` parameter is set too low, and complete document chapter information is not loaded, causing the LLM to fail to accurately associate citation positions.

## How to confirm the configuration is correct
- Trigger a project proposal drafting request, and check whether the output content includes citation source identifiers and corresponding document information.
- View the knowledge base data source configuration, confirm that only category-specific data sources such as the State-owned Assets Supervision and Administration Commission investment supervision system, enterprise ERP and project management systems are included.
- Adjust the value range of configuration items, verify that the number of retrieved cited documents meets business requirements and has no redundant content.
- Generate an investment post-evaluation report, check whether the cited content accurately matches the document chapters, with no misalignment or missing content.
