# Investment Project Approval and Post-Evaluation Document and Material Drafting: Knowledge Base Retrieval and Recall

This document is written based on FastGPT v4.17.0.

## What this category of data looks like
This category of data originates from state-owned assets supervision systems, enterprise ERP and project management systems, industry market data, audit and financial statements. It covers documents including annual investment plans, project proposals, feasibility study reports, due diligence reports, asset appraisal reports, and post-investment evaluation reports. Data is updated quarterly. Core documents include project approval procedures, investment decision meeting minutes, post-evaluation indicator systems, and related content. Most fields involve business-specific content such as project investment amount, implementation cycle, and performance evaluation standards.

## What constraints these characteristics impose on knowledge base retrieval and recall
Data is updated quarterly, so the knowledge base must support incremental synchronization of multi-system data sources per quarter to avoid retrieving expired investment plans or post-evaluation indicators. Document types cover multiple professional texts including project proposals, feasibility study reports, and investment decision meeting materials, so the system must adapt to content parsing and retrieval for different formats. Most fields involve business-specific content such as project investment amount, implementation cycle, and performance evaluation standards, so retrieval must accurately match business terminology to reduce generalized results. Additionally, approval and post-evaluation data have strong correlations, so cross-document associated recall must be supported to ensure retrieval results cover end-to-end business logic.

## How to Configure
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Matches the precision requirement for business professional terminology, prevents low-correlation results from being included in the retrieval set |
| `limit` | Top 10 entries | Investment decision materials and post-evaluation reports have large content volumes; controlling the number of single retrieval entries balances recall scope and response speed |
| `searchMode` | Full-text retrieval | Adapts to content coverage across multiple types of professional documents, supports cross-paragraph associated matching |
| `usingReRank` | Enabled | Re-ranks initial recall results by business relevance, improves the display priority of high-value documents |
| `datasetSearchUsingExtensionQuery` | Enabled | Expands business-related terms based on the original question, adapts to the professional expression habits of investment projects |
| `collectionIds` | Bind dedicated datasets for project approval and post-evaluation | Restricts retrieval scope, avoids interference from irrelevant state-owned assets supervision data on results |

## Three Common Misconfigurations
- Garbled characters appear in Chinese CSV files imported via templates, while English files show no issues. The root cause is failing to specify GBK or UTF-8 encoding in import settings, and the system default encoding does not match the encoding of Chinese files.
- The number of retrieval results does not match the configured `limit` parameter, with either too many or too few entries. The root cause is failing to correctly bind the dedicated dataset `collectionIds`; the retrieval scope covers non-business-related knowledge base content, leading to abnormal results.
- Disk usage of local deployment instances exceeds expected levels, and it is impossible to accurately calculate the proportion of each storage component. The root cause is failing to distinguish directories for original file storage, split text block storage, and embedding vector storage, and not troubleshooting disk usage by module.

## How to Verify Successful Configuration
- Upload one typical project proposal document, trigger retrieval verification, and check if returned results cover the document’s core content.
- Adjust the `similarity` parameter value, compare retrieval result relevance across different thresholds, and confirm alignment with business precision requirements.
- View the knowledge base dataset binding status, confirm that `collectionIds` only includes dedicated datasets related to investment project approval and post-evaluation.
- After enabling the `usingReRank` function, verify that re-ranked results prioritize displaying investment decision meeting materials or post-evaluation reports most relevant to the current query.
