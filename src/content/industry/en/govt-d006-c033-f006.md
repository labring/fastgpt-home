# Document and Material Drafting for Tendering and Procurement Compliance Management: Citation Source and Traceability

## What the data for this category looks like
This category covers all documents related to the full procurement process of state-owned enterprises, including procurement plans, requirement specifications, bidding documents, bid evaluation records, contracts, acceptance documents, and supplier complaint materials. Data sources include enterprise procurement platforms, public resource trading platforms, supplier databases, contract management systems, and audit problem databases. Updates occur daily. Documents are structured by procurement stage, with core fields such as procurement number, budget basis, scoring methods, supplier qualification requirements, performance acceptance clauses, and more. These data fields directly align with the core requirements of procurement compliance review.

## Constraints on citation source and traceability
These characteristics impose clear constraints on the citation source and traceability process. Mixed access to multi-source data requires distinguishing recall weights between internal procurement platforms and public resource trading platforms, to ensure the authority of compliance review. The daily update frequency requires that vector database synchronization cycles match business rhythms, to avoid citing outdated procurement plans or bid evaluation records. Document structures split by procurement stage require that recalled content is tightly bound to the current drafting document stage. For example, only compliance basis for the current procurement stage is recalled when drafting bidding documents. The alignment of core fields with compliance requirements requires precise matching of field information during traceability, to ensure cited content directly supports key compliance items such as procurement methods and scoring methods.

## How to configure the system
The following configurations are formulated for FastGPT v4.17.0.
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the length of single-paragraph compliance content for tendering and procurement documents, to avoid truncating key compliance basis |
| Single search limit | Top 8 entries | Covers multiple types of reference documents needed for procurement compliance review, while controlling total context length |
| `detail` | Enabled | Retains complete field information for citation sources, making it easy to verify procurement numbers, supplier qualifications and other details during audit traceability |
| `responseData` | Includes sourceId and file path | Associates field mapping with the backend database, enabling quick location of original documents |
| Similarity threshold | 0.65–0.75, calibrated via actual testing | Balances recall accuracy and recall scope, to avoid missing compliance-related reference content |

## Three common configuration errors
- Phenomenon: After setting the maximum number of citations to 20, recall results always stay at 5 entries and do not increase when the configuration is adjusted. Cause: The single search limit parameter is not configured correctly, or the vector database recall logic is restricted by a fixed threshold.
- Phenomenon: Output compliance documents retain Markdown source code formatting and are not rendered into readable formal documents. Cause: Content format optimization configuration is not enabled correctly, or prompt word configuration does not match document rendering requirements.
- Phenomenon: Corresponding document business fields cannot be matched using sourceId during traceability. Cause: Database fields were not mapped correctly when uploading documents, or the `responseData` configuration does not link to the correct field index.

## How to verify correct configuration
- Draft a document draft corresponding to a procurement stage, trigger the citation traceability function, and check if recalled content covers compliance reference documents required for the current stage.
- View the display fields for the citation source, and confirm that core compliance-related fields such as procurement number and scoring method are included.
- Adjust the similarity threshold and single search limit parameters, and verify that the number of recall results changes with the configuration.
- Check the mapping relationship between sourceId and originally uploaded documents, and confirm that the corresponding business document can be located using the ID.

The values provided are common starting points and should be evaluated against the reader's own samples.
