# Document and Material Drafting for Pollution Discharge Permit Management: Citation Source and Traceability

## What data for this category includes
The daily documents covered by this category include pollution discharge permit application forms, implementation reports, self-monitoring plans, ledger records, change applications, and permit copies. Data sources are the national pollution discharge permit management information platform, enterprise environmental protection ledgers, online monitoring systems, and environmental statistics systems. Data is updated quarterly. Document fields include permit limits, discharge outlet information, monitoring frequency, implementation status, and more. Units mostly involve pollutant concentrations (mg/L), emission amounts (tons/year), and similar units. Each document is associated with a fixed pollutant discharge unit code and permit number.

## What constraints these characteristics impose on the citation source and traceability link
The data sources for this category are scattered across multiple systems. For citation and traceability, the pollutant discharge unit code and permit number must first be matched to ensure associated data belongs to the same entity. Data is updated quarterly, so the latest version of the data must be verified when citing, to avoid calling expired ledgers or monitoring records. Documents contain professional environmental protection parameters and corresponding units. When citing, field and unit information must be fully retained, with no arbitrary adjustments allowed. A single document is associated with multiple batches of implementation reports, so fragments relevant to the current drafting content must be accurately located to avoid redundant citations. If traceability matching is incorrect, the drafted documents will have inconsistent parameters, leading to compliance risks such as over-permit discharge and unpermitted discharge.

## How to configure the setup
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the length of single-paragraph professional content in pollution discharge permit documents, to avoid truncating key information such as permit limits and discharge outlet parameters |
| Single search limit | Top 8 entries | Covers quarterly updated data from multiple sources, balancing traceability coverage and context load |
| Reranking | Enabled | Filters low-relevance cross-batch monitoring records, improving matching accuracy of cited fragments |
| `responseData` | Enable citation markers | Automatically associates document identifiers of corresponding sources at the end of answer paragraphs, adapting to business review processes |
| `detail` | Enable traceability details | Displays the type and update time of source documents, meeting compliance inspection requirements |

## Three common mistakes
- Phenomenon: After enabling the reranking function, the cited fragment is empty or relevant content cannot be retrieved. Cause: The minimum relevance threshold after reranking is not adjusted, causing fragments matching professional parameters of pollution discharge permits to be filtered out.
- Phenomenon: The citation traceability plugin fails to load normally in the import and export workflow. Cause: The data source associated in the workflow configuration is not synchronized to the new environment, or the association rule for pollutant discharge unit codes is not reconfigured.
- Phenomenon: The citation prompt "No permission to operate this conversation record" is displayed at the end of the answer paragraph. Cause: The citation marker configuration for `responseData` is not correctly enabled, or the system permission does not open the display permission for traceability information.

## How to confirm the configuration is correct
- Draft a trial version of a pollution discharge permit implementation report, trigger the citation traceability function, and check if the returned fragments include professional fields such as permit limits and discharge outlet information.
- Adjust the value of `quoteMaxToken`, verify that long document fragments are fully retained without truncation.
- After enabling the reranking function, compare the number of citation results before and after enabling to confirm that low-relevance content is filtered out.
- Check the citation markers at the end of the answer, confirm that the associated document type and update time match the actual data source.
