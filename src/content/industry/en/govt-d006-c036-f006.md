# Document and Material Drafting for Government Service Item Catalog and Service Guideline Maintenance: Citation Source and Traceability

## What This Category of Data Looks Like
Core data for government service item catalog and service guideline maintenance comes from the national basic directory of government service items, administrative licensing item list, power and responsibility list, and local government service item databases.
Daily maintained documents include the basic directory of government service items, implementation lists, service guidelines, standard material directories, flowcharts, and frequently asked questions.
Data updates occur monthly. Each individual document includes standardized fields: item name, implementing entity, acceptance conditions, application materials, and handling process. No custom non-standard units are used.

## What Constraints These Characteristics Impose on Citation Source and Traceability
Data sources originate from official entities. Traceability must match accurate official entries.
Data updates happen monthly. The knowledge base must sync regularly to keep content timely.
Multiple document types use standardized field structures. Citations must precisely match corresponding fields, to avoid generalized content.
Individual data requires complete fields. Traceability must retain full item information, not just the document name.
This link is part of background maintenance work. Traceability errors must be avoided, as they can cause inconsistent online and offline service handling standards.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Government-related documents have moderate single-citation content length. This range can fully retain key fields such as acceptance conditions and application materials, avoiding truncation of core information |
| `responseData` | Enabled | Specific knowledge base citation metadata must be returned to ensure external channels can display traceability information, matching the compliance traceability requirements of government service items |
| `detail` | Full | Full field content from service guidelines must be retrieved and returned, covering all key information such as document title, acceptance conditions, and application materials, to ensure verifiable traceability information |
| Single search limit | Top 6 entries | The number of government service item entries falls within a reasonable range. This value can cover most relevant entries while avoiding context redundancy that affects generation quality |
| Knowledge base synchronization cycle | Once per month | Matches the monthly update frequency of this category of data, ensuring consistency between the local knowledge base and official catalog content. FastGPT v4.17.0 supports this custom configuration |

## Three Common Mistakes
- Symptom: External publishing channels cannot display citation traceability information normally, while local testing returns normal content. Cause: The `responseData` parameter is not configured correctly, resulting in returned content without citation metadata.
- Symptom: Generated service guideline content does not match the cited entry, and the citation uses outdated item catalog content. Cause: No synchronization cycle matching the data update frequency is set, so the knowledge base has not synchronized the latest official item content.
- Symptom: Citation traceability only displays the document name, without including fields such as acceptance conditions and application materials for specific items. Cause: The `detail` configuration is not enabled, only basic metadata of the document is retrieved, without including the field content of specific items.

## How to Confirm Proper Configuration
- Access the FastGPT v4.17.0 knowledge base management page, review the synchronization log, and confirm the most recent synchronization time matches the official catalog’s monthly update rhythm.
- Use the name of an included government service item for testing, and verify that the generated content’s cited fields include complete implementation list information for the item.
- Navigate to the configured external publishing channel, and confirm the returned results display the corresponding knowledge base citation entry and specific fields.
- Adjust the `quoteMaxToken` parameter to a smaller range, test whether long-text service guidelines are properly truncated, and confirm the parameter takes effect.

Note: The configuration values listed above are common starting points. Adjust them based on specific samples and requirements.
