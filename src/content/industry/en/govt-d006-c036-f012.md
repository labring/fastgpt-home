# Document and Material Drafting for Government Service Item Catalog and Service Guide Maintenance: Deployment and Upgrade

## What the Data for This Category Looks Like
Daily documents for this category include basic government service item catalogs, implementation lists, service guides, standard material catalogs, flowcharts, and frequently asked questions. Data sources include official datasets such as the national basic government service item catalog, administrative licensing item list, power and responsibility list, and local government service item databases. The update frequency is monthly.

Document structures include fields such as item unique identifier, implementing entity category, application material details, acceptance conditions, and handling process nodes. Some documents use nested structures with multi-field associations.

## Constraints Imposed on Deployment and Upgrade
The monthly update frequency requires a stable incremental data synchronization mechanism after deployment, to prevent service interruptions from full re-imports.

Official data source compliance requirements mean configuration options must support integration with standardized government data interfaces. The multi-document association structure also requires a vector database to support multi-field associated retrieval.

The business requirement for field integrity verification means data validation rules must be configured during deployment, to block entries with missing key fields.

This category does not handle individual applicant’s specific service requests, so high-concurrency current-limiting rules for end-users are not required during deployment. Only stability for internal operation and maintenance scenarios needs to be ensured.

When deploying in a cloud environment, the configuration must adapt to the cloud service provider’s network access control policies, to secure access to databases and storage services.

## Three Common Misconfigurations
- After upgrading FastGPT, knowledge base retrieval errors display the message `text index required for $text query`. Cause: The MongoDB full-text index was not recreated after the upgrade. Text retrieval for government item data depends on this index.
- When deploying on Alibaba Cloud, connecting to the cloud RDS database fails, with a prompt of connection timeout or insufficient permissions. Cause: The IP address of the FastGPT deployment instance was not added to the RDS instance’s access whitelist, and correct database connection parameters were not configured.
- After deployment, only the basic item list loads, and associated attachments and process information for service guides cannot be accessed. Cause: Storage-related parameters such as `STORAGE_S3_ENDPOINT` were not configured, preventing normal reading of attachment resources.

## How to Verify Successful Configuration
- Run a database connection test command to confirm the MongoDB instance specified by `MONGODB_URI` can establish a valid connection.
- Upload a test service guide attachment, then access the file via the storage endpoint configured in `STORAGE_S3_ENDPOINT` to confirm the storage link works correctly.
- Trigger an incremental data synchronization task, and check the synchronization log for no errors related to missing fields or connection issues.
- Search for test government service item keywords, and confirm the retrieval results return expected item entries and associated documents.
