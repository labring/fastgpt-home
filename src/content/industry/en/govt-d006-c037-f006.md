# Document and Material Drafting for Government Information Application Disclosure: Citation Source and Traceability
## What data in this category looks like
Typical entities include government offices, government information disclosure offices, legal affairs divisions, and archives departments. Daily processed documents include government information disclosure application forms, supplementary notice letters, third-party opinion solicitation letters, response letters, service receipts, and administrative reconsideration response materials. Data sources cover government information disclosure platforms, official archive systems, document management systems, departmental business ledgers, and relevant specifications of the Government Information Disclosure Regulations. Data update frequency is irregular. Document structures include fixed fields such as applicant information, application matters, retrieval basis, public attribute judgment, and response content.

## What constraints these characteristics impose on the citation source and traceability link
Multiple data sources require the traceability link to support compatibility with formats and field specifications of different systems, to avoid matching deviations. Irregular update frequency requires traceability configurations to support on-demand incremental data synchronization, and cannot rely on fixed-cycle full updates. Fixed document fields require precise matching between application matters and corresponding basis during citation, and cannot broadly reference irrelevant content. Case-by-case handling requirements require traceability results to be bound to specific applicant application requests, to avoid citation confusion across cases.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the core content length of a single government document, ensuring complete citation information and compliance with typesetting requirements |
| `responseData` | Enabled | Requires returning original citation data for generating formal documents with clear traceability |
| `detail` | Medium | Balances recall accuracy and response speed, adapting to the rigor requirements of government documents |
| Single search limit | Top 6 results | Covers typical recall volume for multi-source data, avoiding redundant information interfering with response logic |
| Maximum context | 15000 characters | Accommodates context for multiple related documents, ensuring consistent and complete response basis |
| Knowledge base sync cycle | Calibrated based on actual testing | Adapts to the irregular data update feature, triggering incremental synchronization on demand |

## Three common errors
- Phenomenon: Relevant government documents are retrieved, but only a single citation identifier is displayed when generating a response, with no complete citation content shown. Cause: The `quoteMaxToken` value is set too small, which cannot accommodate the complete citation text, resulting in only the identifier remaining after truncation.
- Phenomenon: A parameter error prompt pops up during workflow operation, and citation data cannot be loaded normally. Cause: The `responseData` configuration item is not enabled, and the requirement to return original citation data fields is not set.
- Phenomenon: Search results include historical public information unrelated to the current application, causing the response content to deviate from the application matters. Cause: No reasonable single search limit is set, and old data not associated with the current application is recalled.

## How to confirm correct configuration
- Upload a standard government information disclosure response template to the knowledge base, and verify whether the recall accuracy of the `detail` configuration matches the basis content in the template.
- Trigger a simulated application process, and check whether the returned results include the original citation fragments and corresponding traceability information marked by `responseData`.
- View the knowledge base synchronization logs of FastGPT v4.17.0 to confirm that the incremental synchronization trigger logic complies with the irregular update configuration requirements.
- Test input an overlong application matter, and verify whether `quoteMaxToken` can correctly truncate and retain complete traceable citation content.
