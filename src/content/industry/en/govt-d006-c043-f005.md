# Document and Material Drafting for Special Equipment Safety Supervision: Tool Calling and Plugins

## What Data for This Category Looks Like
Data sources for this category include special equipment safety supervision systems, inspection and testing institution systems, user ledgers, and operator certificate databases. The update frequency is monthly. Daily processed documents include use registration certificates, periodic inspection reports, maintenance records, hidden danger rectification notices, accident reports, and operator certificates. Core fields include unique equipment number, inspection validity period, maintenance cycle, operator certificate number, hidden danger rectification status, equipment type, and others. All documents are bound to the unique identifier of the corresponding special equipment, and field formats must strictly match the verification rules of the supervision system.

## Constraints Imposed on Tool Calling and Plugins
The need to access multiple data sources requires plugins to support interfacing with multiple heterogeneous systems, with independent authentication and data pulling rules configured for each system. The monthly update frequency requires that tool call caching and filtering logic align with the monthly cycle to avoid pulling expired or unupdated data. The document structure tightly bound to unique equipment identifiers requires tool calls to accurately match field association relationships, such as automatically linking equipment numbers to the validity periods of corresponding inspection reports. The high-risk nature of supervision work requires stricter permission verification and failure handling for tool calls, to prevent sensitive data leaks or incorrect document generation.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `toolChoice` | `auto` | Adapt to multi-tool calling scenarios, automatically select tools for special equipment supervision document drafting and data pulling |
| `functionCall` | Enabled | Force structured function calls to ensure generated document fields comply with the format and verification rules of supervision documents |
| Tool call timeout period | 60-90 seconds | Allow time for data returns when connecting to multi-system data sources, avoid interrupting high-risk supervision document generation processes due to timeout |
| Tool authentication configuration | Configure the `Authorization` request header | Connect to authenticated SSE interfaces, comply with secure access requirements of special equipment supervision systems. This configuration supports custom request headers in FastGPT v4.17.0 |
| Mermaid plugin enable switch | Enabled | Generate flowcharts required for supervision work, such as hidden danger rectification flows and inspection cycle tracking charts, to meet document visualization needs |
| Tool call retry count | 2 times | Address temporary network fluctuations and ensure stability of high-risk supervision document generation |

## Three Common Configuration Mistakes
- Phenomenon: An error is reported when calling an SSE interface with header authentication, prompting unauthorized access, with a returned status code of 401. Cause: The `Authorization` request header is not added in the tool configuration, failing to meet the authentication requirements of the supervision system.
- Phenomenon: Flowcharts generated by Mermaid only return text code, with no image link available. Cause: The image generation plugin of the Mermaid MCP Server is not enabled, or the access path for image storage is not configured.
- Phenomenon: The number of maintenance records returned by tool calls does not match expectations, with no entries updated in the current month pulled. Cause: Tool call data source filtering conditions do not align with the monthly update frequency, and parameters for filtering by update time are not set.

## How to Verify Successful Configuration
- Initiate a test call, enter the unique equipment number of special equipment, and confirm that the tool pulls field data for the corresponding use registration certificate and inspection report.
- Configure an SSE interface tool with the `Authorization` header, initiate a test request, and confirm that the returned status code is 200 with no unauthorized error messages.
- Enable the Mermaid plugin, enter a description of a hidden danger rectification flow, and confirm that a code block capable of generating an image link is produced.
- Set the tool call retry count to 2 times, simulate a temporary network interruption, and confirm that the call is automatically retried and completed successfully.
