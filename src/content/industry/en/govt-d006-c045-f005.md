# Document and Material Drafting for Land Pre-examination and Planning Permission: Tool Calling and Plugins

## What Data Does This Category Include?
Data sources for this category include the national spatial planning unified map, project approval and supervision platform, land use status database, and ecological protection redline data. Update frequency is irregular.
Daily produced documents include land pre-examination and site selection opinions, construction land planning permits, construction engineering planning permits, redline maps, and planning conditions. Core fields cover project site selection scope, land scale, control indicators, prior approval conditions, and more. Field formats and required items for different documents follow fixed specifications that must strictly match official template requirements.

## What Constraints Do These Characteristics Impose on the Tool Calling and Plugins Link?
Multiple data sources with irregular update cycles require tools to pull latest control data and approval status in real time. This prevents compliance conflicts caused by using expired information.
Fixed document fields and formats require plugins to strictly match official template field structures. Generated documents will fail compliance review otherwise.
Cross-departmental data docking needs require plugins to support calling multi-source platform interfaces. Returned data volume must be controlled to avoid context overload that reduces generation efficiency.
Compliance of core fields directly affects project approval and construction start. Tool calling links must include built-in verification logic to proactively check for conflicts between land redlines and ecological protection redlines.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Adapts to multi-source data calling needs, automatically matching tools for national spatial planning, project approval, and similar use cases |
| Plugin Call Timeout | `120–180 seconds` | Matches average time taken for cross-departmental data pulling, avoiding early termination of valid calls |
| Maximum Single Tool Call | `Top 3 entries` | Controls returned planning control data volume, preventing context window overload |
| `functionCall` | Enabled | Enforces structured output of document fields, ensuring consistency with official permit document formats |
| Context Window | `8000–12000 token` | Carries complete information for multi-source data, templates, and generated content |
| Parameter Verification Switch | Enabled | Automatically checks compliance of core fields such as land scale and redline scope |

## Three Common Mistakes
-  Plugin calls return empty fields. The symptom is generated documents missing core fields including land scale and site selection scope. Logs show passed parameters did not match fixed fields of category documents. The cause is failure to pass parameters according to official document specifications for this category, only using general template fields to initiate calls.
-  Plugins fail to load redline maps in intranet environments. The symptom is connection timeout or permission errors when calling stored redline maps. This aligns with the default public network access requirement introduced in the plugin system update for FastGPT v4.17.0. The cause is failure to configure intranet penetration or adjust storage paths to adapt to intranet environments.
-  Document generation takes excessively long. The symptom is material generation via knowledge base taking more than 15 seconds, with the interface showing prolonged response waiting time. The cause is failure to limit the number of recalled planning data entries per call, leading to excessive redundant information in the context window.

## How to Confirm Proper Configuration
-  Initiate a simulated call for project land pre-examination. Check whether the plugin successfully pulls control data from the corresponding national spatial planning unified map, and confirm that returned fields match category document requirements.
-  View tool call logs. Confirm that output generated by `functionCall` uses a structured format matching field requirements of official permit documents.
-  Test storage access in intranet environments. Confirm that redline maps load normally without connection timeout or permission errors.
-  Simulate cross-departmental data pulling. Verify plugin call timeout configuration, confirm that timeout interruptions are not triggered, and that the generation process falls within the expected time range.
