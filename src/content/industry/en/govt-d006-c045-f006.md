# Document and Material Drafting for Land Pre-examination and Planning Permit: Source Citation and Traceability

## Data characteristics of this category
Core data for this category comes from the national land and space planning unified map, project approval and supervision platform, land use status database, and ecological protection red line data. Update frequency is irregular. Commonly produced and used documents include Land Pre-examination and Site Selection Opinion, Construction Land Planning Permit, Construction Engineering Planning Permit, red line drawings, and planning conditions. Document fields include project site selection scope, land use scale, planning control requirements, pre-approval conditions, and other items. Some drawing documents include spatial coordinates and boundary parameters.

## Constraints on source citation and traceability
Dispersed data sources and irregular update cycles require the traceability link to accurately associate each cited item with its specific data source batch. This avoids citing expired or incorrect planning data. Documents include two categories: text and spatial drawings. Citation must distinguish between traceability paths for text fields and spatial boundary parameters. This ensures complete source labeling for both content types. Administrative approval scenarios have high requirements for traceability accuracy. This prevents mismatches between cited sources and actual approval basis, while supporting quick location of the original data entry for a single citation.

## Configuration settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | Adapts to the length of cited content for land pre-examination and planning permit documents, avoiding truncation of key approval basis and spatial parameters |
| `responseData` | Enabled | Used to return the original data source identifier corresponding to the cited content, matching the traceability needs of administrative approval scenarios |
| `detail` | Full mode | Retains the complete context of cited content, facilitating verification of the match between project site selection and red lines |
| Citation display position | End of paragraph | Aligns with common labeling conventions for administrative approval documents in this category |
| Single recall data source limit | Top 5 entries | Avoids excessive redundant data interfering with approval judgment, focusing on core pre-approval basis |
| Timeout threshold | 60 seconds | Adapts to the loading pace of data sources for this category, avoiding process interruptions due to excessive waiting time |

## Three common configuration errors
- Symptom: No citation source identifier is displayed at the end of the answer paragraph. Cause: The `responseData` configuration item is not enabled, or the citation display position is not set to end of paragraph. This corresponds to the previously reported scenario where the new citation function does not display properly.
- Symptom: A timeout error is returned in the answer. Cause: The timeout threshold is set too short, failing to adapt to the loading pace of data sources such as the national land and space planning unified map for this category.
- Symptom: Cited content is truncated, with key land use scale or red line parameters lost. Cause: The `quoteMaxToken` setting value is too small, unable to accommodate the complete cited context.
