# Administrative Penalty Case File Handling: Document and Material Drafting — Citation Source and Traceability

## What this category of data looks like
Data for this category comes from administrative law enforcement case handling systems, law enforcement recorder footage, the National Enterprise Credit Information Publicity System, and departmental supervision databases. The update frequency is daily.
Core documents include on-site inspection records, interrogation records, evidence lists, prior penalty notification documents, penalty decisions, delivery receipts, and similar materials. The structure centers on core fields: illegal fact determination, discretion basis, and procedural workflow.
All documents are linked to a unique case handling number as their unique identifier, with no additional custom units.

## What Constraints Do These Characteristics Impose on the Citation Source and Traceability Link
Data sources for this category are scattered and linked to a unique case handling number. This requires the citation traceability process to accurately bind this number to avoid confusion across case files.
Daily updated real-time law enforcement data requires the traceability process to quickly pull the latest case handling system records and law enforcement footage materials.
The fixed structure and multi-field requirements of core documents require accurate location of source documents for corresponding fields. This ensures one-to-one correspondence between materials such as on-site inspection records and evidence lists and penalty decisions. Failure to do so will trigger the risk of case file review failure, and may even lead to revocation of the penalty.

## Configuration Settings

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| Maximum Context | 8000–12000 tokens, calibrated via actual testing | Adapts to the total length of multi-document links in administrative penalty case files, avoids truncation of core case handling information |
| `quoteMaxToken` | 1500–2000 characters | Limits the length of a single citation, adapts to the paragraph-style content structure of law enforcement documents |
| `responseData` | Enable source field binding | Forces return of the case handling number and source type of cited documents to meet traceability verification requirements |
| `detail` | Enable detailed traceability | Displays original document fragments and upload times of cited content, complies with the traceability requirements of law enforcement case files |
| Single Recall Limit | Top 6 entries | Covers the number of core evidence and documents for a single case file, avoids interference from redundant data |

This configuration scheme applies to FastGPT v4.17.0

## Three Common Mistakes
- Phenomenon: Knowledge base retrieval returns a number of results that does not match the configured single recall limit, or returns no results. Cause: The case handling number is not bound as a data filtering condition, resulting in recall of cross-case file data.
- Phenomenon: Citation formatting garbled characters appear in output content, with unclosed citation marks at the end of sentences. Cause: Format verification for `responseData` is not enabled, resulting in direct output of formatting symbols from original documents.
- Phenomenon: Knowledge base query takes too long, exceeding business response thresholds. Cause: The value of `quoteMaxToken` is not restricted, resulting in the cited token pushed in a single session exceeding the large model's processing limit.

## How to Confirm Proper Configuration
- Initiate a query simulating a case handling scenario, check whether returned results only link to documents with the current case handling number.
- View the citation source field, confirm that it includes the type and upload time of the original document.
- Test the length of a single citation, confirm that it does not exceed the preset `quoteMaxToken` limit.
- View system logs, confirm that no truncation errors caused by excessive context length occur.

The values provided are common starting points and should be measured against the reader's own samples.
