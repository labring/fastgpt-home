# Administrative Licensing and Approval: Document and Material Drafting — Source Citation and Traceability

## What the data for this category looks like
The daily documents for this category include service guidelines, application forms, commitment letters, acceptance notices, correction notification letters, administrative licensing decision letters, and license certificates. Data sources are the national integrated government service platform item database, administrative licensing item list, departmental business approval systems, and electronic certificate database. The update frequency is daily. Document fields include legally required content such as item codes, legal basis, handling conditions, and application material lists. Content must strictly match item boundaries and legal basis to ensure compliance with government approval requirements.

## Constraints on source citation and traceability
These data and document characteristics create clear constraints for the source citation and traceability process. Multi-source data updated daily requires the traceability process to pull the latest item lists and certificate data in real time. This avoids citing expired legal basis. The field requirements for legal documents are strict. Content must accurately match item codes and legal basis, and must not include content from non-legal sources. Cross-departmental system data calls must maintain stability. Otherwise, it will affect the generation and traceability verification of approval documents, and may lead to overdue completion or license revocation through reconsideration. Overall, configuration for the traceability process must balance compliance, real-time performance, and accuracy. This ensures every citation can be traced back to official data sources.

## Configuration guidelines
This configuration applies to FastGPT v4.17.0, and is formulated for the compliance requirements and data characteristics of administrative licensing and approval:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the length of legal basis and application materials in administrative licensing documents, ensuring cited content is complete and does not exceed context limits |
| `responseData` | Return only source data from the item database and electronic certificate database | Filters non-legal source content, complying with government approval compliance requirements |
| `detail` | Enabled | Retains field information of citation sources, such as item codes and release dates, to facilitate subsequent traceability verification |
| Maximum matching results | Top 8 entries | Covers common administrative licensing item types, avoiding omission of key basis |
| Context cache duration | 600 seconds | Matches the daily update frequency of data, ensuring the latest official data is called |

## Three common configuration mistakes
- Generated approval documents include unhideable citation links. The cause is incorrect configuration of the `responseData` return filtering rules, which retains unnecessary link fields.
- The temperature setting control disappears after configuring variable references. The cause is an abnormal linkage logic between variable references and model parameter configuration in some versions, which fails to properly load the parameter setting interface.
- Insufficient number of traceability results, failing to cover all relevant legal basis. The cause is failure to adjust the maximum matching results parameter, with the default value being too small leading to key basis being filtered out.

## How to confirm successful configuration
- Upload an administrative licensing service guideline, trigger the document drafting process, and check whether the generated content includes traceability fields such as item codes and release dates.
- View the system configuration log to confirm that the value of `quoteMaxToken` falls within the preset 800–1200 token range.
- Test cross-departmental data calls, verify that source data from the electronic certificate database returns normally, with no errors or missing content.
- Adjust the maximum matching results parameter, confirm that the number of generated traceability results changes with the configuration.

The values provided are common starting points and should be measured against the reader's own samples.
