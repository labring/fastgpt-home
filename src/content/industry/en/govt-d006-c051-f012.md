# Document and Material Drafting for Road Transport Business Licensing: Deployment and Upgrade

## What the data for this category looks like
The core data for this category comes from the road transport administration management system, the national road transport vehicle dynamic information public service platform, and the vehicle and practitioner database. The update frequency is daily. Documents processed daily include business license applications, vehicle technical files, driver qualification materials, safety production management systems, and road transport business licenses.
Business license applications include structured fields such as main entity qualification, site proof, vehicle list, and institutional texts. Vehicle technical files include fixed fields such as vehicle model and license plate number. Driver materials include information such as qualification certificate number and assessment records.

## What constraints these characteristics impose on deployment and upgrade
All data sources for this category are intranet-only systems with no public network access permissions. Therefore, during deployment, configure intranet-accessible database and cache addresses, and cannot rely on public network mirrors or API services.
Daily high-frequency data synchronization requirements demand a sufficient number of concurrent connections in the database connection pool to avoid connection exhaustion during synchronization. Documents include two types of content: structured fields and unstructured text, so different text processing strategies need to be adapted. Additionally, document storage needs increase as the number of enterprises grows, so a reasonable storage space limit must be reserved.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `PG_URL` | Intranet PostgreSQL instance address, formatted as `postgresql://user:pass@intranet_ip:5432/road_transport` | Business data is stored in the intranet road transport administration management system's PostgreSQL database, so an intranet-accessible connection address must be used |
| `REDIS_URL` | Intranet Redis instance address, formatted as `redis://:pass@intranet_ip:6379/0` | Caches daily synchronized vehicle and practitioner data, so must be deployed in an intranet environment to avoid public network access restrictions |
| `DB_MAX_LINK` | 20–30 | Multiple documents and database requests must be processed simultaneously during daily data synchronization, and this connection count meets concurrent requirements |
| Text chunk length | 800–1200 characters | Business documents include structured fields and unstructured safety system texts, this range balances field integrity and semantic coherence |
| File storage limit | 1000 MB | The total size of a single vehicle technical file and license application material usually does not exceed this threshold, meeting daily storage needs |

## Three common errors
- Running `docker-compose up -d` results in the `Error pulling image redis` error, with logs showing image pull timeout. The cause is using a public network Redis mirror, and the deployment server cannot access the public network image repository in the intranet environment.
- The system pops up a knowledge base quantity limit prompt, and new road transport business licensing related knowledge bases cannot be created. The cause is failing to adjust the default knowledge base quantity limit of the open source version, and failing to configure corresponding parameters to raise the limit.
- After upgrading the pgvector plugin, the `function vector_cosine_similarity does not exist` error occurs when querying vehicle file data. The cause is failing to reload the pgvector extension during the upgrade, or failing to synchronously update the database connection configuration.

## How to Confirm the Configuration is Correct
- Run the `docker ps` command, confirm that the PostgreSQL, Redis, and FastGPT v4.17.0 services are all running.
- Access the intranet-configured `FE_DOMAIN` address, log in to the system, and attempt to create a test road transport business licensing knowledge base. Confirm that it can be created normally without quantity limit prompts.
- Upload a sample vehicle technical file document, trigger the text chunking and indexing process, and confirm that the document can be retrieved normally.
- Check the database connection pool monitoring, confirm that the current database connection count does not exceed the `DB_MAX_LINK` configuration value.

The values listed above are common starting points and should be evaluated against the reader's own samples.
