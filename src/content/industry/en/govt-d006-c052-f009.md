# Document and Material Drafting for Department Final Accounts and Financial Reports: Model Access and Configuration

## What data for this category looks like
Data for this category comes from the unified budget management system, centralized treasury payment system, accounting system, and asset management system, and is updated annually. Daily produced documents and materials include department final account statements, balance sheets, income and expenditure final account statements, final account explanations, and government financial reports. The documents include fixed-format report fields, income and expenditure details, asset and liability data, and difference explanations. Most fields include budget codes, income and expenditure subjects, amount units, reporting unit identifiers, and must comply with official unified format requirements.

## What constraints these characteristics impose on the "model access and configuration" link
The annual update feature requires model access configuration to adapt to the processing rhythm of batch annual data, and avoid single-call timeouts. Data from multiple systems requires clear field mapping rules for the corresponding data sources in the configuration, to ensure the accuracy of field matching during account statement verification. The fixed-format document structure requires that context interception rules in the configuration adapt to report pagination and field order, and avoid missing key difference explanation content. This category focuses on actual income and expenditure and recorded asset and liability situations. Configuration should prioritize association with historical data and the rigor of difference explanations, differing from budget preparation categories that focus on future deduction logic. Mixed processing of multiple category documents requires configuration to distinguish the processing logic of different documents, preventing confusion between the fields of final account statements and their explanations.

## How to set the configuration
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | Adapts to the total length of annual final account documents, covering complete reports and explanation content exported from multiple systems |
| `maxTokens` | 4000 token | Limits the output length of documents generated in a single round, complying with official typesetting specifications for final account reports |
| `quoteMaxToken` | 1500 token | Restricts the length of associated data referenced from the knowledge base, ensuring that referenced content for account statement verification is accurate and does not exceed the context limit |
| `toolChoice` | auto | Allows the model to independently choose whether to call tools for data summarization and difference verification, adapting to complex final account scenarios |
| `temperature` | 0.2–0.4 | Reduces generation randomness, ensuring that field and value descriptions for final account data comply with official format requirements |
| `AIPROXY_API_ENDPOINT` | Fill in local or cloud interface address based on deployment environment | Adapts to access paths for multiple system data sources, ensuring the model can normally retrieve associated budget and income and expenditure data |

## Three common mistakes
- Phenomenon: The model output only contains Chinese, and does not follow the instructions from the English prompt. Cause: The target language association rule is not specified in the model access configuration, or the configuration prioritizes loading Chinese knowledge base content.
- Phenomenon: Connection timeout errors occur during workflow debugging. Cause: The `maxContext` configuration value is too large, exceeding the single-call limit of the model interface, or the address configured for `AIPROXY_API_ENDPOINT` cannot normally access the data source.
- Phenomenon: The generated final account explanation does not include budget execution difference verification content. Cause: The `quoteMaxToken` configuration value is too small, failing to fully reference associated treasury payment data, leading the model to omit key difference explanations.

## How to confirm the configuration is correct
- Call the test interface, input the summary of a single annual final account statement, and check whether the generated document includes correct income and expenditure subjects and amount units.
- View the model call log, confirm that the request address for `AIPROXY_API_ENDPOINT` matches the access path of the data source, with no connection exceptions.
- Adjust the `temperature` parameter to 0.3, call the same test prompt multiple times, and check whether the field consistency of the generated content meets expectations.
- Verify the `maxTokens` configuration, ensure that the generated final account explanation is not truncated, and complies with the length requirements of official documents.

The values provided are common starting points and should be measured against the reader's own samples.
