# Document and Material Drafting for Departmental Budget Preparation: Workflow Orchestration

## What data looks like for this category
This category of data primarily comes from the unified budget management system, departmental staffing establishment system, prior-year final accounts, project library, and the annual budget preparation notice issued by the Ministry of Finance. Data is updated once per year. Corresponding documents include departmental budget drafts, project application forms, performance target forms, personnel expense calculation forms, budget approval documents, and more. Common document fields include staffing headcount, project funding amount, performance quantifiable indicators, budget cycle, and others. Typical units are ten thousand yuan, persons, and number of projects.

## What constraints these characteristics impose on the workflow orchestration link
Annual data update cycles require workflows to sync with the latest Ministry of Finance preparation rules each year, to avoid using outdated standards.
Multiple data sources require workflow configurations to include cross-system call nodes. Call permissions and format conversion logic for each data source must be clearly defined.
Multiple document types and fixed fields require workflows to retain a unified context. This ensures consistent reuse of basic data for document drafting across different stages.
Concentrated time-consuming steps require workflows to split into independent nodes for calculation, review, and aggregation. This enables step-by-step optimization and exception handling.
This link occurs before annual funding allocation. It focuses on planning work for declaration and funding allocation, and must strictly align with annual budget cycle requirements.

## Three common errors
- Tool call node returns Invalid JSON error: The interface displays an error prompt "Invalid JSON: Bad control character". The cause is that raw data returned from fiscal system interface calls contains unescaped line breaks or special characters, with no data cleaning step added in the node configuration.
- Cannot copy or paste workflow components: Selected components cannot be dragged or copied to other workflows. The cause is that the global component reuse function is not enabled in the workflow editing interface, and components can only be reused within the current workflow.
- Ununified workflow context: Documents generated across different workflow nodes have inconsistent data. The cause is that `variables` is not configured to bind unified data source fields, and each node independently calls scattered data.

## How to confirm correct configuration
- Check data source binding for each workflow node to confirm `variables` maps to matching fields from the unified budget management system.
- Test tool call nodes to verify returned data has no unescaped special characters, and format meets document drafting requirements.
- Copy a single component to a new test workflow to confirm component configuration and dependent parameters are fully retained.
- Simulate the complete annual budget preparation process to confirm no gaps in data transfer between workflow nodes.
