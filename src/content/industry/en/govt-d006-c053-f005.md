# Document and Material Drafting for Department Budget Preparation: Tool Calling and Plugins

## What the data for this category looks like
Core data for this category comes from the unified budget management system, department staff establishment system, prior-year final accounts, project library, and the Ministry of Finance budget preparation notice. Update frequency is annual. Daily produced documents include department budget drafts, project application forms, performance target forms, staff expense calculation forms, budget approvals, and similar items. Document structures include fields such as staff establishment count, project funding amount, performance indicators, annual budget cycle, and similar items. Units are usually ten thousand yuan, person, item, and similar units. Data is usually stored across multiple systems, and a single document contains multiple types of related fields, which need to be integrated across data sources before document drafting can be completed.

## What constraints these characteristics impose on the "tool calling and plugins" link
Annual updated data sources require tool calling and plugins to adapt to fixed business cycles, avoiding frequent triggering of invalid calls. Cross-system data sources require plugins to support multi-data source docking, ensuring that corresponding fields can be obtained from the unified budget management system, staff establishment system, and similar systems. The multi-field structure of documents requires tool calling to accurately extract specific fields, avoiding redundant data interfering with document generation. The severity of error consequences requires tool calling to add parameter verification links, ensuring that the generated budget documents meet review requirements. Differences from final account scenarios require tool logic to focus on fund declaration and arrangement links.

## How to set the configurations
The following configurations are formulated based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `toolChoice` | Auto | Adapt to multi-step tool calling requirements in budget preparation scenarios, avoiding missing calculation, review, and other links when manually specifying functions |
| Single tool call timeout | 120–180 seconds | Corresponds to the time required for budget data calculation and cross-system query, calibrated based on actual testing |
| Knowledge base recall limit | Top 6 entries | Matches the field density of department budget documents, avoiding redundant data interfering with document generation |
| Custom plugin request timeout | 300 seconds | Covers the time required for cross-system batch data query, calibrated based on actual testing |
| Request retry count | 3 times | Adapts to unstable scenarios in cross-system calls, reducing the probability of call failure |
| `functionCall` | Enforce parameter completeness verification | Ensure that extracted fields such as staff establishment count and project funding meet format requirements |
| Document source tracking switch | Enabled | Retain reference information of budget documents associated with tool calls, meeting review requirements |

## Three common errors
- The associated budget document file name is not displayed in the result returned after calling a tool. The cause is that the document source tracking switch is not enabled, and the file index of the corresponding data source is not bound.
- Deployment of a custom plugin fails. The cause is that the interface permissions and parameter mapping rules of the plugin are not correctly configured, and the field format of budget data is not matched.
- A permission error is returned when calling the knowledge base interface with an application key. The cause is that the application is not bound to the corresponding budget data source access permission, and the unauthorized knowledge base is called directly.

## How to confirm the configuration is complete
- Initiate a tool call for department budget calculation, check whether the returned result includes the file name of the associated document.
- After deploying the custom plugin, use simulated budget data to initiate a call, verify that the fields returned by the interface match the format of budget documents.
- Check the application's permission configuration, confirm that access permissions for corresponding data sources such as the unified budget management system and project library have been bound.
- View the tool call log, confirm that the parameter verification link has been executed normally, and there are no missing field error reports.
