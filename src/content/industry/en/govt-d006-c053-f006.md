# Document and Material Drafting for Department Budget Preparation: Source Citation and Traceability

## What this category of data looks like
Core documents for this category include department budget drafts, project application forms, performance target forms, personnel expense calculation forms, and budget approvals. Main data sources are the budget management integrated system, department personnel establishment system, prior-year final account data, project library, and the Ministry of Finance's annual budget preparation notice. Data updates follow an annual cycle. Document fields include budget subject code, number of personnel establishment, project performance indicators, fund calculation amount, and others. Units include ten thousand yuan, person, number of projects, and others. The data structure is adjusted slightly each year in line with annual budget policies.

## Constraints on source citation and traceability
Annual fixed-cycle data requires that only valid current-year data sources are called during traceability, to avoid mixing cross-year invalid data. Multiple heterogeneous data sources must be matched to different document fields. For example, personnel expense calculation needs to link to personnel establishment system data. Project expenditures require retrieval of project library entry information. The standardization level of document structure affects chunking and recall accuracy. Precise fields such as budget subject code can improve traceability matching accuracy. Cross-departmental summarized budget data must ensure the traceability scope covers all subordinate units' reported data sources, to avoid missing citation bases. Additionally, compliance requirements for fiscal documents require that citation sources clearly mark the data source type and specific segments, and core verification information must not be omitted arbitrarily.

## Configuration guidelines
These configuration guidelines are formulated for FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | Adapts to the single-block content length of department budget documents, ensuring that citation fragments fully include budget subjects and calculation bases |
| `responseData` | Enabled | Used to return data source identifiers and document fragments for citation sources, matching the compliance requirements of budget preparation traceability |
| `detail` | Full | Retains the original field information of citation sources, making it easy to verify the correspondence between budget subject codes and fund amounts |
| Maximum context | Top 10 recall results | Covers multiple types of data sources related to annual budgets, avoiding missing project library or final account data |
| Timeout threshold | 300 seconds | Adapts to the response duration of internal fiscal system interfaces, preventing recall failures due to system delays |
| Chunk length | 500–800 characters | Adapts to the paragraph structure of budget documents, improving the accuracy of chunked recall |

## Three common errors
- Phenomenon: Cross-year final account data citations appear in generated budget preparation documents, and cannot be traced back to valid current-year data sources. Cause: The update cycle of the data source is not restricted to the current year, and historical redundant data is called.
- Phenomenon: The citation links attached to the reply content cannot jump to internal fiscal system documents, or unnecessary external links appear. Cause: Non-compliant link display formats are enabled, and the rules for data source identifiers of internal systems are not matched.
- Phenomenon: Citation fragments only show fund amounts without budget subject codes, making it impossible to verify the basis during review. Cause: The `detail` parameter is set to simplified mode, and core verification fields are lost.

## How to confirm the configuration is correct
- Initiate a query related to budget subject calculation, check whether the returned content includes identifier information of the corresponding data source.
- Check whether the citation fragments include core fields such as budget subject code and number of personnel establishment, confirm that the `detail` parameter is configured correctly.
- Test calls to different types of data sources, such as project library and final account data, check whether the recall results cover the corresponding document types.
- Check that the citation display format only marks the data source name and fragment position, with no redundant external links.

The values provided are common starting points and should be measured against the reader's own samples.
