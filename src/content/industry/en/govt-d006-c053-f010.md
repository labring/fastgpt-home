# Document and Material Drafting for Departmental Budget Preparation: Knowledge Base Retrieval and Recall

Reference only; verify against the target FastGPT release and deployment documentation.

## What the Data for This Category Looks Like
The data for this category mainly comes from the unified budget management system, departmental staffing system, prior-year final accounts, project library, and budget preparation notices issued by the Ministry of Finance. Daily produced documents include departmental budget drafts, project application forms, performance target forms, personnel expense calculation forms, budget approvals, and similar items. Most document structures contain clear fields such as project codes, performance indicators, and expense amounts. The update cycle is annual, and the data is strongly tied to annual fiscal fund allocations.

## What Constraints Do These Characteristics Impose on the Knowledge Base Retrieval and Recall Link
The annual update feature requires the knowledge base to complete full data synchronization on an annual cycle, to avoid interference from cross-year invalid data in retrieval results. Data from multiple systems has significant structural differences, so unified field mapping must be completed before retrieval to ensure accurate matching of budget-related documents from different sources. Documents contain strongly constrained fields such as project codes and performance indicators, so retrieval must support filtering recall results by specific fields to prevent irrelevant content from being included. At the same time, errors in this link will lead to failed budget review, so recall results must have high matching accuracy, and the proportion of irrelevant documents recalled must be strictly controlled.

## How to Configure the Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Meets the field precision requirements for matching departmental budget documents, filters low-relevance non-budget content |
| `limit` | Top 8 entries | Covers all types of reference documents required for departmental budget preparation, while controlling context length |
| `searchMode` | Semantic + keyword hybrid retrieval | Balances field matching and semantic association, adapts to the structured and semi-structured characteristics of budget documents |
| `usingReRank` | Enabled | Improves the sorting priority of high-matching results, avoids missing key budget notice content during initial recall |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands synonymous expressions related to budget preparation, covering the query habits of different job roles |
| `collectionIds` | Bind exclusive budget knowledge base collection IDs | Isolate documents from other categories, ensuring retrieval only targets departmental budget-related data |

## Three Common Mistakes
- Issue: An error indicating no knowledge base selected is returned when calling the chat interface, while the function operates normally during the debug preview phase. Cause: The knowledge base collection ID configured via `collectionIds` is not correctly passed in the interface parameters, or the knowledge base binding configuration differs between the production environment and debug environment.
- Issue: Importing knowledge base content in web link format fails, and authorized budget management system documents cannot be retrieved. Cause: No login credentials for web crawling are configured, so access restrictions cannot be bypassed to obtain target documents.
- Issue: A large number of non-budget irrelevant documents, such as administrative office notices, are included in retrieval results. Cause: The `similarity` threshold is not set, or the threshold is set too low, leading to recall of low-matching content.

## How to Verify the Configuration Is Correct
- Check the knowledge base binding configuration, confirm that the `collectionIds` parameter passes the correct budget-related knowledge base collection IDs, with no irrelevant collections included.
- Initiate a test query, enter "2024 Departmental Budget Preparation Notice", and verify that the returned results only include budget-related documents with no irrelevant content.
- After enabling `usingReRank`, compare the result sorting before and after enabling to confirm that high-matching budget documents are displayed first.
- After simulating annual data updates, trigger knowledge base synchronization, and verify that the retrieval results include the latest budget preparation requirements.
