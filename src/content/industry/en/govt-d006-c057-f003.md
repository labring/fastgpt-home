# Document and Material Drafting for Food Safety Supervision and Sampling: Multi-turn Dialogue and Prompt Engineering

## What Does the Data for This Category Look Like?
Data sources for this category include food safety sampling and monitoring systems, the State Administration for Market Regulation’s sampling results inquiry system, laboratory LIMS systems, and food producer and operator ledgers.
Data updates occur monthly.
Commonly processed documents include sampling plans, sampling slips, inspection reports, non-compliant food verification and disposal reports, and risk control notices.
Document fields include sampling number, inspection items, non-compliance determination basis, disposal measures, and additional relevant fields.
Some documents require association with linked information such as sampling locations and inspection batches.

## What Constraints Do These Characteristics Impose on Multi-turn Dialogue and Prompt Engineering?
Monthly updated data sources restrict dialogue contexts to valid data from the current month, preventing reference to expired sampling information.
Prompts must clearly distinguish processing logic for each document type based on its differentiated fields, such as sampling location for sampling slips or non-compliance determination basis for inspection reports, to avoid field confusion.
Multi-turn dialogue must actively confirm the current document type and associated batch to match context correctly, due to requirements for linked data.
Grassroots supervision office scenarios require lightweight dialogue processes, avoiding complex parameter configuration, while retaining traceable operation records.

## How to Configure the Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Context window size | 8000–12000 token | Adapts to full content loading of long documents such as inspection reports and disposal reports |
| Single recall result count | Top 3 | Matches the limited monthly updated data sources, avoiding interference from redundant information |
| `variables` configuration | Bind sampling number and inspection batch fields | Automatically populate fixed document fields to reduce manual input |
| `chatId` associated storage | Enable session history binding | Facilitates retrospective review of full-process dialogue records for a single batch of sampling |
| `messages` log storage | Enable full dialogue record | Retain the complete process of multi-turn interactions for troubleshooting |
| Question optimization switch | Enable | Helps organize colloquial sampling questions from supervision personnel into standardized query instructions |

## Three Common Configuration Mistakes
- Detailed internal application records fail to display in conversation view details. This occurs when full log storage for the `messages` parameter is not enabled, and only final reply content is saved.
- Data processing returns empty results after file uploads during local deployment. This happens when access permissions for category-specific data sources are not correctly bound, preventing reading of document formats exported from sampling systems.
- Conversation history cannot be queried in mongodb. This results from missing configuration of the association mapping between `chatId` and session records, so historical data is not stored by batch.

## How to Verify Proper Configuration
This verification process uses FastGPT v4.17.0.
- Initiate a multi-turn dialogue for a single sampling batch, and confirm that the context window loads documents including the sampling plan and sampling slip for the corresponding batch.
- Use the variable replacement function, enter a sampling number, and verify that the system automatically populates the fields configured in `variables`.
- View session records, and confirm that each conversation links to the full process of the current sampling batch via `chatId`.
- Trigger the question optimization function, enter a colloquial sampling question, and confirm that the input is converted to a standardized query instruction.

The configuration values provided here are common starting points, and should be evaluated against the reader's own samples.
