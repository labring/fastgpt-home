# Document and Material Drafting for Survey and Design: Citation Source and Traceability

## What the data for this category looks like
Survey and design data sources mainly include project survey reports, professional design drawings, national and industry standard atlases, and project review documents. The data update rhythm adjusts with project progress. Full professional files are updated on demand during the preliminary design stage. Only partially modified content is updated during the construction drawing stage. Document structures are categorized by disciplines such as architecture, structure, water supply and drainage. Each file contains fields including project number, drawing number, standard document number, chapter and page number. Units include square meters, cubic meters, millimeters, MPa and other commonly used engineering units.

## What constraints these characteristics impose on the citation source and traceability link
Professionally categorized data sources require binding the corresponding professional file library during traceability, to avoid recalling irrelevant cross-professional data. Fields with unique identification numbers require traceability information to accurately match drawing numbers and standard document numbers. Positioning cannot rely solely on file names. Versioned standards and drawings require traceability to associate the corresponding version of data sources, to avoid using expired version content. The large size of individual documents requires limiting the recall range during traceability, to avoid excessive redundant information interfering with generation results.

## Configuration settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | The length of single standard citations and drawing descriptions in survey and design documents usually falls within this range, to avoid truncating key traceability information |
| `responseData` | Only return source file ID, page number and professional classification | Survey and design documents require accurate positioning of specific content. Returning only necessary fields avoids redundant interference with document drafting |
| `detail` | Enabled | Matches specific fields of survey reports and design drawings, ensuring traceability information includes key content such as project number and drawing number |
| Maximum context | 15000 characters | Covers the core content of a complete single review document, ensuring traceability can associate complete project context |
| Single recall limit | Top 6 entries | Survey and design data sources are grouped by profession. Excessive recall will cause traceability confusion. Recalling by professional group better fits business logic |

## Three common configuration errors
- Unassociated traceability information appears in the generated document. The cause is that the return fields of `responseData` are not limited, resulting in recalling irrelevant cross-professional project file data.
- The generated document forcibly carries uncancelable citation markers. The cause is that the return rules of `responseData` are not configured correctly, and the mandatory traceability switch is accidentally enabled.
- The traceability information displays incorrect standard version numbers. The cause is that the version metadata of the data source is not associated, and the old version of standard content is directly called, without matching the standard version used by the current project.

## How to confirm the configuration is correctly set
- Upload a survey and design review document that includes drawing numbers and standard document numbers, trigger the document drafting task, and check whether the returned traceability information includes correct drawing numbers and standard page numbers.
- Adjust the value of `quoteMaxToken`, verify that the generated traceability text does not have truncation, and meets the citation length requirements of professional documents.
- Toggle the `detail` switch state, compare the detail level of the two generated traceability information sets, confirm that extra fields such as project number and drawing number are included after enabling.
- Check the FastGPT v4.17.0 system log, confirm that the traceability request only calls the specified survey and design professional data sources, and does not recall irrelevant files.

The configuration values listed above are common starting points. Adjust them based on your own specific samples and use cases.
