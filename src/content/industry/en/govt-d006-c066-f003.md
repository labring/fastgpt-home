# Document and Material Drafting for Advanced Chemical Materials: Multi-turn Dialogue and Prompt Engineering

## What the Data for This Category Looks Like
Data sources for advanced chemical materials primarily include the national new material industry filing database, production grade ledgers published by industry associations, and internal enterprise R&D compliance documents. The platform synchronizes filing information quarterly and updates performance parameters for production grades monthly. Document structures include fields with units such as material Chinese name, English alias, CAS number, density, melting point, tensile strength, heat distortion temperature, as well as attachment links for corresponding RoHS and REACH compliance reports.

## What Constraints These Characteristics Impose on Multi-turn Dialogue and Prompt Engineering
Since the data includes precise CAS numbers, performance parameters with units, and compliance documents, multi-turn dialogue must strictly follow field matching rules to avoid generating vague or incorrect parameter values. The fixed data update cycle requires regular knowledge base synchronization to ensure the latest compliance information is used. Long documents require sufficient space in the context window, while preventing invalid historical information from occupying resources. Material drafting for different grades must distinguish contexts using session identifiers to prevent parameter confusion across sessions. The configuration logic for this scenario is implemented based on FastGPT v4.17.0.

## How to Configure the Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum Context Length | 8000–12000 token | Compliance reports and performance parameter documents for advanced chemical materials are lengthy, so sufficient context must be retained to avoid loss of critical information |
| `chatId` Binding | Bind the globally unique ID of the current workflow | Prevent context confusion between multi-turn dialogues, and ensure context consistency for the same material drafting session |
| `variables` Injection | Inject the current material grade and CAS number | Accurately match corresponding data, and avoid generating incorrect parameter values or compliance content |
| Number of Historical Messages Retained | First 3 turns of dialogue + current request | Reduce invalid context occupancy and lower the delay of the first response |
| Knowledge Base Sync Cycle | Update once per quarter | Match the update rhythm of industry filing data, and ensure the latest compliance and performance data is used |

## Three Common Misconfigurations
- Phenomenon: When multiple AI dialogue modules are chained in a workflow, the final output includes all dialogue content from all modules, which does not meet the requirement of retaining only the last round of results. Cause: The `messages` parameter is not configured to retain only the last round of output for the current session, or no context truncation rule is set.
- Phenomenon: When calling the AI dialogue module for the first time, the first-word response delay exceeds 3 seconds, while subsequent response speeds are normal. Cause: No fixed `chatId` is bound, causing the full knowledge base data to be reloaded for each session, or no incremental synchronization knowledge base update strategy is configured.
- Phenomenon: No automatic question content appears after the dialogue box starts, and manual input triggering is required. Cause: No initial question instruction is injected via `variables` at the workflow start node, or no pre-trigger condition for dialogue triggering is bound.

## How to Confirm Proper Configuration
- Trigger a complete material drafting process, check that the final output only includes the results of the last round of AI dialogue, to verify that the context truncation configuration is effective.
- Record the response time of the first call, compare it with the speed of subsequent calls, to confirm that the delay meets the preset threshold standards of the business.
- Manually modify the material grade parameter injected via `variables`, check whether the generated document content matches the parameters and compliance requirements of the corresponding grade, to verify that the variable injection is effective.
- View the workflow running logs, confirm that `chatId` remains consistent throughout the session cycle, with no session context confusion.
