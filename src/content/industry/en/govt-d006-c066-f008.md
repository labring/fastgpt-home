# Document and Material Drafting for Advanced Chemical Materials: Document Parsing and Chunking

## What Data for This Category Looks Like
Document data for advanced chemical materials mainly comes from enterprise R&D project reports, raw material inspection and quality control reports, patent application documents, industry compliance documents, and production process manuals. The update rhythm fluctuates with project progress and regulatory requirements. R&D documents update with experiment milestones, while compliance documents update quarterly alongside regulatory policies.

Document structures typically include multi-column structured tables (such as raw material ratio lists, performance parameter comparisons), embedded molecular structure images, process flow diagrams, and long text passages (such as patent claims, experiment step descriptions). Fields and units are mostly professional chemical parameters: for example, purity measured in %, molecular weight in g/mol, particle size in nm, viscosity in mPa·s, plus specialized test terms like TG and DSC.

## What Constraints Do These Characteristics Impose on the Document Parsing and Chunking Link?
Multi-column structured tables can cause the default parsing logic to split content in a single-column layout, leading to data misalignment. Embedded molecular structures and process flow diagrams must be linked to corresponding text parameters, otherwise parsed results cannot fully reflect experiment and process information.

If chunk size is unreasonable for long patent passages or content dense with technical terms, terms may be split and parameter units broken. Large R&D reports have large file sizes and high parsing complexity, increasing the risk of timeout failures.

These characteristics require the document parsing link to adapt to multi-column layouts and support image association. The chunking link must balance the integrity of professional content and contextual relevance.

## How to Set the Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `customPdfParse` | Enabled | Advanced chemical material documents often contain molecular structure images and multi-column raw material ratio tables. Default parsing cannot fully extract structured information |
| `chunkSize` | 800–1200 characters | Covers complete passages of patent claims and performance test reports, avoids splitting technical terms and parameter units |
| `chunkSplitter` | Split by title + paragraph | Adapts to the hierarchical structure of R&D chapters and compliance clauses in documents, retains contextual relevance |
| `PARSE_FILE_TIMEOUT_SECONDS` | 120 seconds | Prevents parsing timeout when processing documents with multiple high-definition process flow diagrams |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | Supports uploading large R&D project reports and batch patent documents |

This configuration was validated on FastGPT v4.17.0.

## Three Common Mistakes
- Mixed column order after parsing multi-column tables: Parsed results show misalignment between raw material ratio columns and performance parameter columns. This occurs because `customPdfParse` is not enabled, and the default parsing logic does not recognize multi-column layouts.
- Separated images and text: When uploading documents with molecular structures or process diagrams, only plain text is extracted, and images are not linked to corresponding parameter descriptions. This occurs because image parsing association rules are not configured.
- Premature parsing task termination: The task status shows timeout, and returned results are incomplete. This occurs because the `PARSE_FILE_TIMEOUT_SECONDS` parameter is not adjusted, and the parsing duration of large documents exceeds the default limit.

## How to Confirm the Configuration Is Correct
- Upload a test PDF with two-column raw material ratios, verify that each column of data in the parsed results is fully corresponding with no mixed or misaligned content.
- Upload a document with molecular structure images, confirm that the parsed results include both the text annotations of the images and the image association information.
- Upload a R&D project report with more than 50 pages, confirm that the parsing task does not throw timeout errors and returns all content completely.
- View the chunking logs, confirm that each chunk contains complete technical terms and parameter units with no mid-passage splits.

The values provided are common starting points and should be measured against the reader's own samples.
