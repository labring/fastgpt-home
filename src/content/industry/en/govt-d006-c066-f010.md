# Document and Material Drafting for Advanced Chemical Materials: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Core data for advanced chemical materials derives from internal enterprise process specifications, new material performance test reports, industry general standard documents, and compliance filing materials. The data update schedule is adjusted based on new product development progress or compliance requirements, with no fixed cycle. Most documents are long-text PDFs or structured tables, containing fields such as material grades, performance parameters (such as tensile strength, heat distortion temperature), synthesis process steps, and safety data sheets. Units are mostly engineering units such as MPa, ℃, kg/m³.

## What constraints these characteristics impose on the knowledge base retrieval and recall link
The mixed document structure of long-text process documents and structured parameter tables for advanced chemical materials means the retrieval link must support both text semantic recall and structured field matching. Engineering parameter content requires unit consistency, so retrieval must filter results with mismatched units. Data sources with no fixed update cycle require verification of the latest version identifier before retrieval. Document drafting scenarios have high compliance requirements for recall content, so retrieval scope must be limited to valid content within a specified dataset to avoid irrelevant data interfering with drafting results.

## How to set the configurations
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Advanced chemical material parameter content requires high matching accuracy to avoid low-relevance results being included in compliance documents |
| `limit` | Top 8 entries | Cover sufficient reference materials while controlling context length to fit model input limits for document drafting |
| `searchMode` | hybrid | Adapt to the mixed document structure of text and structured table files, supporting both semantic and field matching |
| `usingReRank` | Enabled | Perform secondary sorting on recall results to filter invalid content with semantic matching but mismatched parameter units |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically supplement chemical professional terms to improve retrieval matching accuracy for engineering parameters |
| `collectionIds` | Bind exclusive dataset ID | Limit the retrieval scope to documents exclusive to advanced chemical materials, avoiding recall of irrelevant business content |

## Three Common Mistakes
- Issue: The error `fail to create post presigned url` appears when uploading PDF or CSV documents for advanced chemical materials. Cause: Object storage access keys and bucket permissions are not configured correctly, so pre-signed upload links cannot be generated.
- Issue: Retrieval fails to limit searches exclusively to the advanced chemical materials exclusive dataset, and documents from other categories are recalled. Cause: The `collectionIds` parameter is not configured correctly, or an incorrect dataset ID is bound.
- Issue: After deploying FastGPT locally, the enhanced PDF parsing function is enabled, but table content in advanced chemical material process manuals fails to parse correctly. Cause: The minerU service access address is not configured correctly, or the minerU association setting is not enabled in the backend.

## How to Confirm Configuration Completion
- Check dataset binding configurations to confirm that `collectionIds` points to the exclusive dataset for advanced chemical materials
- Initiate a retrieval test to verify whether recall results only include documents related to advanced chemical materials
- Validate parameter threshold configurations to confirm that the `similarity` value meets preset accuracy requirements
- Test the recall effect of structured tables and long texts to confirm that the configurations of `searchMode` and `usingReRank` are active

The values provided here are common starting points and should be evaluated against the samples used in the actual deployment.
