# Document and Material Drafting for Fertilizers and Pesticides: Multi-turn Dialogue and Prompt Engineering
This page content applies to FastGPT v4.17.0

## What this category of data looks like
Data related to fertilizers and pesticides is mainly sourced from public pesticide registration and filing documents released by the Institute of Pesticide Control of the Ministry of Agriculture and Rural Affairs, industry standard documents issued by the National Agricultural Means of Production Circulation Association, and production license materials submitted by enterprises. Data update rhythm is adjusted according to the validity period of registration certificates, and updates are synchronized when newly registered products go live. Most documents are in structured table format, including fields such as active ingredient content of pesticides, dosage form, pre-harvest interval, nutrient proportion of fertilizers, implementation standards, applicable crops, etc. Units include grams per liter, percentage, kilograms per mu, and others.

## What constraints these characteristics impose on the multi-turn dialogue and prompt engineering link
The characteristics of structured fields and fixed units require that prompts must clearly specify output formats and unit matching rules to avoid generating content that does not comply with industry specifications. The dynamic update of data according to the validity period of registration certificates requires that multi-turn dialogue contexts must be associated with the latest data versions to avoid calling expired filing information. The fact that a single document often contains multiple product parameters requires clear product identification in the dialogue flow to prevent confusion between parameters of different categories. At the same time, document drafting must comply with industry standards issued by the Ministry of Agriculture and Rural Affairs, and compliance verification logic must be embedded in the multi-turn dialogue link to ensure that generated materials meet registration and public disclosure requirements.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chatId` | Generate a unique value per product batch | Distinguish drafting dialogues for different fertilizer and pesticide products to avoid context confusion |
| `messages` | Retain the most recent 20 rounds of dialogue | Cover the multi-round revision process of a single document while controlling context volume |
| `variables` | Bind the latest filing data fields | Ensure generated content matches currently valid registration parameters |
| Maximum context length | 8000–12000 characters | Match the total field length of structured fertilizer and pesticide documents to avoid truncation of critical parameters |
| Single input character limit | 1800 characters | Prevent single input from exceeding model processing capabilities and reduce format errors |
| Dialogue history retention period | 7 days | Cover the complete cycle from drafting to finalization of a single document, retaining context for multi-round revisions |

## Three common mistakes
- Phenomenon: After a single input exceeds the model processing limit, an "input length exceeded" error is returned, and document generation cannot proceed normally. Cause: The single input character limit is not configured, or the limit value is set lower than the single-segment input length of fertilizer and pesticide structured documents, and over-limit requests are not intercepted in advance.
- Phenomenon: Uploaded JPG images of pesticide registration certificates or fertilizer production licenses cannot be correctly parsed into structured fields. Cause: The pre-processing node for image-to-text conversion is not configured, and image content is not converted into parameters usable for dialogue.
- Phenomenon: Dialogue drafting records for a specified product cannot be deleted, or old context is still displayed after deletion and re-invocation. Cause: A unique dialogue identifier is not generated for each fertilizer and pesticide product, resulting in deletion operations not accurately matching the target dialogue.

## How to confirm the configuration is correct
- Submit a test text containing structured parameters for fertilizers and pesticides, check whether the input is within the configured single input limit, and confirm that over-limit interception triggers normally.
- Generate a drafting document for pesticide registration certificate filing, check whether the units and fields of the generated content match the bound latest filing data.
- Generate a test dialogue with multiple rounds of revisions, check whether the dialogue history is normally retained for the configured retention period, and dialogues for different products do not interfere with each other.
- Attempt to delete dialogue records for a specified batch, check whether the context of the target dialogue is completely cleared.
