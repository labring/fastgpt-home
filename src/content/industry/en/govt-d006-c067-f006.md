# Document and Material Drafting for Fertilizers and Pesticides: Citation Sourcing and Traceability

## What Data in This Category Looks Like
The document data for the fertilizers and pesticides sector comes from four main sources:
- Ministry of Agriculture and Rural Affairs pesticide registration announcements
- Filing documents from the fertilizer registration management platform
- Industry national and industry standard documents
- Compliance materials submitted by manufacturing enterprises

Data updates follow a quarterly sync for registration information, and annual updates for standard specifications.
Single documents are mostly structured forms or technical manuals, containing fields such as registration certificate number, active ingredient content, applicable crop scope, application dosage, and pre-harvest interval. Common measurement units include g/L, kg/hectare, and application rate per mu.

## Constraints Imposed by These Characteristics on Citation Sourcing and Traceability
The large number of structured fields paired with inconsistent units requires the traceability process to match each field with its corresponding measurement standard. This avoids confusion over differences in measurement units for active ingredient concentrations and application dosages during citation.
Quarterly updated registration data requires automatic verification of the update time of cited documents during traceability. This ensures the latest valid version is used.
Multiple sources of compliance materials require associating the registration certificate number as a unique identifier during traceability. This avoids mixing up documents for similar products from different enterprises.
Long-form technical documents require precise positioning of the paragraph or page number of the cited fragment during traceability. This ensures traceability information can be quickly verified.

## Configuration Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Single Search Limit | Top 3–5 results | Professional documents in the fertilizers and pesticides sector have concentrated content; a small number of precise results can support document drafting, and avoid interference from redundant information |
| `quoteMaxToken` | 800–1200 token | Matches the typical length of cited fragments from single technical documents, to avoid token overflow that causes content truncation |
| Maximum Context Length | 2000–3000 token | Adapts to the integration needs of multiple sources of compliance materials, to ensure cited information is fully included in the context |
| `responseData` | Structured format with source identifiers | Adapts to traceability requirements for displaying registration certificate numbers and update times, to ensure cited information can be directly extracted and verified |
| `detail` | Enable full traceability information | Includes document source, update time, and field correspondence, to meet the traceability verification standards for compliant documents |
| Update Time Verification | Enable quarterly verification | Matches the quarterly update rhythm of fertilizer and pesticide registration data, to ensure the latest valid version is cited |

## Three Common Mistakes
- Issue: The response returns a context length error, or generated content is truncated. Cause: The `quoteMaxToken` parameter is not adjusted for the typical length of fertilizer and pesticide technical documents, and the set value exceeds the model's context carrying capacity.
- Issue: The cited traceability information only includes the document title, and does not display exclusive fields such as registration certificate number and active ingredients. Cause: The `detail` configuration item is not enabled, and the display logic for full traceability information is not activated.
- Issue: The generated document cites expired pesticide registration certificate data. Cause: The update time verification rule is not configured, and the latest registration documents are not filtered according to the quarterly update rhythm.

## How to Verify Proper Configuration
- Upload one typical fertilizer and pesticide registration document, trigger the document drafting process, and check whether the token length of the cited fragments in the generated content matches the preset range.
- View the traceability panel of the generated response, confirm whether exclusive fields such as registration certificate number and update time are included, to verify that the `detail` configuration is active.
- Simulate a scenario where expired data is cited, verify that the system automatically filters documents beyond the update cycle, to confirm that the update time verification rule is operating correctly.
- Adjust the single search limit parameter, check whether the number of cited results in the generated response matches the set value.
