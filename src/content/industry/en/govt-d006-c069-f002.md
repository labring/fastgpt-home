# Document and Material Drafting for Hazardous Chemical Storage and Transportation: Vector Models and Indexes

## What the data for this category looks like
Core data for hazardous chemical storage and transportation comes from enterprise storage and transportation ledgers, tank area inspection records, loading and unloading work orders, safety compliance manuals, and emergency response plan documents. Data updates are triggered by daily operations: new work records are generated per shift or daily, while compliance manuals and emergency plans are updated quarterly or annually. Document structures include fixed fields: general hazardous chemical name, CAS registration number, storage and transportation volume, tank number, operation time, corresponding compliance clause number. Units include tons, cubic meters, hours, and others. Short documents such as single loading and unloading orders are only a few dozen characters long, while long documents such as compliance manuals can reach tens of thousands of characters.

## What constraints these characteristics impose on the vector models and indexes link
Fixed fields and unique identifiers such as CAS numbers require vector chunking to avoid destroying field integrity, preventing retrieval bias caused by splitting key information. Frequently updated daily work records require indexes to support incremental synchronization mechanisms, avoiding performance loss from full reindexing. Compliance documents dense with technical terminology require vector models adapted to chemical industry text characteristics, to improve semantic matching accuracy. Ledger data volumes of 100,000 or more require index recall logic to balance coverage and response speed, avoiding excessively long single retrieval times.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Adapt to the length of single work records or compliance clauses in hazardous chemical storage and transportation documents, avoid splitting key fields such as CAS number and storage and transportation volume |
| Overlap Length | 50–100 characters | Retain cross-chunk work process context, avoid breaking the coherence of compliance logic due to sentence splitting |
| `maxToken` | 4096 token | Match the maximum input limit of general chemical professional embedding models, adapt to complete semantic input of long compliance documents |
| Similarity Threshold | 0.75–0.85 | Filter low-match non-storage and transportation documents, focus on retrieval results related to hazardous chemical operations |
| Single Recall Count | Top 10 entries | Balance recall coverage and query response speed under 100,000+ data volumes |
| `defaultToken` | Calibrated based on actual measurements | Adapt to the default input length of local embedding models, avoid truncation of professional field content |

## Three common mistakes
- Abnormal vector calculation scores, with a difference of less than 0.1 between similarity scores returned by retrieval. The cause is that chunk length is set too long, leading to excessively high overlap of vector features between different work records, making it impossible to distinguish valid matching content.
- Slow vectorization after uploading PDF files to the knowledge base, with progress stuck for more than 30 minutes. The cause is that incremental index configuration is not enabled, and full reindexing is performed on 100,000+ existing storage and transportation ledger data, occupying a large amount of computing resources.
- Thousands of entries are missing from the index list after importing 100,000 CSV data entries. The cause is that no field verification rules are configured, and invalid records containing unrecognized hazardous chemical names or empty CAS numbers are skipped.

## How to confirm the configuration is correct
After completing the configuration according to the FastGPT v4.17.0 interface guidelines, verify the effect through the following actions:
- Upload a single loading and unloading work order containing a CAS number and storage and transportation volume, check that the chunked text does not split key fields.
- Perform batch import of 100,000 CSV data entries, check the system logs to confirm there are no field filtering or truncation errors.
- Input a section of hazardous chemical compliance clause text, check that the returned similarity scores fall within the preset threshold range.
- Refresh the index list after waiting 10 minutes, confirm that newly added work records have completed index synchronization.
