# Document and Material Drafting for Hazardous Chemical Storage and Transportation: Tool Calling and Plugins
This document is written based on FastGPT v4.17.0.

## What the data for this category looks like
The business data for hazardous chemical storage and transportation mainly comes from internal enterprise storage and transportation operation systems, hazardous chemical ledger management modules, and compliance filing documents from local emergency management departments. Data synchronization mainly occurs after each shift ends. Some real-time operation records are updated within 10 minutes after completion. Each document related to a single work order includes fields such as generic hazardous chemical name, CAS registration number, storage tank number, daily inbound and outbound volume, storage temperature, operation approver, compliance verification number, and more. Field units include tons, cubic meters, degrees Celsius, hours, and others. Some fields are mandatory for local regulatory compliance.

## What constraints these characteristics impose on the tool calling and plugins workflow
The data fields for hazardous chemical storage and transportation include a large number of mandatory compliance items. Some fields require real-time verification with external regulatory systems. Therefore, tool calling must strictly match field formats and units to prevent generated documents from being non-compliant due to format errors. Data updates occur at a high frequency. Plugins must support real-time pulling of the latest operation records; otherwise, generated documents will contain outdated data. Compliance document templates vary significantly across different hazardous chemicals. Plugins must automatically match the corresponding template based on the incoming hazardous chemical CAS number. Tool calling parameters must carry clear field mapping rules to ensure generated documents meet local regulatory requirements.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | auto | Adapt to multi-scenario requirements for hazardous chemical storage and transportation document drafting, automatically select matching compliance templates and data sources |
| Plugin request timeout | 300 seconds | Hazardous chemical data pulling requires integration with multiple systems, which takes a long time; avoids request interruption due to timeout |
| Context window upper limit | 8000–12000 token | Needs to integrate multiple storage and transportation operation records and compliance documents; sufficient context ensures complete document content |
| Plugin parameter filtering rules | Filter by hazardous chemical name, storage tank number | Accurately pull the latest data for corresponding operations, avoids irrelevant information interfering with document generation |
| Streaming response switch | Enabled | Adapts to non-streaming call restrictions of some models, ensures normal processing of returned results by Agent nodes |
| Template matching threshold | Top 5 | Prioritizes matching the most appropriate hazardous chemical compliance template, ensures correct document format |

In some complex scenarios, `functionCall` can be manually specified to bind a specific compliance verification plugin.

## Three Common Configuration Mistakes
- Plugin calls return empty results, and logs indicate the model does not support non-streaming requests. This occurs when `toolChoice` is not correctly set to auto, and the streaming response switch is not enabled, causing the Agent node to fail to properly process the model's returned content.
- Generated storage and transportation documents omit CAS number or compliance verification number fields. This happens when mandatory fields from the hazardous chemical ledger are not bound in plugin configuration, and corresponding field mapping parameters are not included during tool calling.
- Interface calls fail after embedding in a third-party Vue3 project. This is caused by not adding the project's domain name to FastGPT's API whitelist, and not correctly carrying the API key for identity verification.

## How to Confirm Proper Configuration
- Manually trigger a document drafting request, and verify that the generated document includes mandatory fields such as hazardous chemical name, storage volume, and CAS number.
- Review FastGPT's plugin call logs, and confirm that each request pulls the latest hazardous chemical storage and transportation operation data, with data update times matching actual operation times.
- Test different hazardous chemical names, and confirm that the plugin automatically matches the corresponding compliance document template, with generated document formats meeting local regulatory requirements.
- Embed FastGPT's front-end components in a third-party project, and check that the page can normally initiate API requests, with returned document content consistent with results tested directly on the FastGPT official website.
