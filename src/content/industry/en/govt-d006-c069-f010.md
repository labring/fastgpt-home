# Document and Material Drafting for Hazardous Chemical Storage and Transportation: Knowledge Base Retrieval and Recall

## What data for this category looks like
Hazardous chemical storage and transportation data primarily comes from national and local hazardous chemical safety management regulations, internal enterprise storage and transportation ledgers, daily inspection and emergency response records. Compliance specification documents are updated quarterly in line with regulatory update cycles. Storage and transportation ledgers synchronize inbound, outbound and storage volume data daily. Inspection records are generated per shift. Most data uses structured fields, including hazardous chemical name, CAS number, storage conditions, compliance clause number, storage volume (unit: ton or cubic meter), alongside unstructured long documents such as inspection reports and outbound approval forms.

## What constraints do these characteristics impose on the knowledge base retrieval and recall workflow
Hazardous chemical storage and transportation data has many structured fields and high compliance requirements. Retrieval must prioritize precise field matching to avoid low-match irrelevant content interfering with document drafting. Data update frequencies vary widely: quarterly updates for compliance specifications versus daily updates for ledgers. This requires the retrieval workflow to support incremental recall to cover the latest content. A high proportion of long documents such as inspection reports and approval forms, if segmented using generic methods, may lead to truncation of key information, affecting the accuracy of document drafting. Additionally, documents related to hazardous chemicals must strictly correspond to the latest compliance clauses. The timeliness and accuracy of retrieval results directly relate to compliance risks.

## How to Set Configuration Parameters
| Configuration Item | Recommended Value | Rationale |
|---|---|---|
| `similarity` | 0.75–0.85 | Hazardous chemical data has high compliance requirements. Low-match outdated or irrelevant documents must be filtered out to avoid non-compliant content being included in drafted documents |
| `limit` | Top 8 entries | Hazardous chemical storage and transportation documents need to cover multiple dimensions including compliance clauses, storage parameters and emergency response content. Too many results will exceed the context length limit |
| `searchMode` | `vector+keyword` | Balances precise field matching for structured ledgers and semantic recall for unstructured inspection reports, adapting to mixed data structures |
| `usingReRank` | Enabled | Hazardous chemical data has strong relevance. Reranking can filter redundant recall results and raise the priority of compliance clauses and core storage parameters |
| `datasetSearchUsingExtensionQuery` | Enabled | User queries during document drafting often include implicit compliance requirements. Expanded queries can cover more relevant hidden compliance clauses |
| `collectionIds` | Fill in according to the classification of hazardous chemical compliance library and storage and transportation ledger library | Isolate different types of data sources to avoid interference from cross-category data, ensuring recalled content only targets the hazardous chemical storage and transportation scenario |

## Three Common Configuration Mistakes
- Symptom: Retrieval result count does not match expectations, with some key storage parameters or compliance clauses truncated. Cause: The segmentation rules for hazardous chemical long document fields were not adjusted, or the `limit` parameter was not set correctly, causing context to be occupied by redundant content.
- Symptom: The AI generates fictitious hazardous chemical compliance suggestions when no matching knowledge base content is found. Cause: The `similarity` threshold was set too low, recalling low-relevance non-hazardous chemical data, or no skip logic for no matching results was configured.
- Symptom: Retrieval results do not include the latest hazardous chemical compliance updates. Cause: No scheduled task for incremental recall was configured, or `collectionIds` were not associated with the latest version of the hazardous chemical compliance dataset.

## How to Verify Proper Configuration
- Input a specific hazardous chemical storage compliance question, and verify that the matching degree of returned retrieval results falls within the `similarity` threshold range.
- Check the total number of retrieval results to confirm it matches the `limit` setting, with no excessive redundant content.
- Input a hazardous chemical scenario question not covered by the knowledge base, and confirm that the retrieval results are empty to prevent the AI from generating fictitious content.
- Review the FastGPT v4.17.0 retrieval logs to confirm that `usingReRank` and `datasetSearchUsingExtensionQuery` are operating normally with no error messages.
