# Document and Material Drafting for Power Generation Groups: Source Citation and Traceability

This configuration scheme is compatible with FastGPT v4.17.0.

## What This Type of Data Looks Like

Data related to document and material drafting for power generation groups comes from internal power generation operation daily reports, unit maintenance procedures, safety operation specifications, and power industry policy documents issued by the National Energy Administration.

There are two update rhythms for this data:
- Operation and maintenance data is synchronized and updated daily
- Policy documents are updated irregularly according to their issuing cycle

Most documents are official papers with chapter numbers and file numbers. Common fields include applicable unit number, release date, and technical parameter indicators. Used units include power industry-specific measures such as megawatts and tons of standard coal per kilowatt-hour.

## Constraints for Source Citation and Traceability

The special fields and classification logic of power generation group documents require precise matching of specific paragraphs corresponding to the target unit and release time during traceability. Avoid broadly citing entire documents.

Frequently updated operation and maintenance data requires the traceability function to support real-time or daily synchronized knowledge base updates. This prevents citing outdated content.

The chapter structure of official documents requires the traceability function to locate specific paragraphs. This improves citation accuracy.

Documents with multiple field classifications require configuration support for filtering recalled entries by fields. This reduces interference from irrelevant content.

## Configuration Settings

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Adapts to the single-paragraph citation length of official power generation documents, avoiding context overflow |
| `responseData` | Structured format including file number and paragraph index | Matches the field characteristics of power generation documents accurately, facilitating traceability |
| `detail` | Enabled | Covers technical detail paragraphs in power generation operation and maintenance documents, meeting traceability accuracy requirements |
| Single recall limit | Top 3–5 entries | Prevents excessive irrelevant power generation procedure entries from interfering with citation accuracy |
| Knowledge base synchronization cycle | Once daily | Aligns with the daily update rhythm of power generation operation and maintenance data, ensuring cited data timeliness |
| Source file filtering criteria | Filter by unit number and release date | Matches the classification fields of power generation group documents, narrowing the recall scope |

## Three Common Configuration Mistakes

- Phenomenon: The optional list is empty after importing the knowledge base. Cause: The association permission between the knowledge base and the current application is not configured, or the knowledge base has not loaded because the synchronization cycle has not triggered.
- Phenomenon: A prompt of insufficient citation limit appears during invocation. Cause: `quoteMaxToken` is set too small, or the single recall limit is too high and exceeds the context window.
- Phenomenon: The cited source file cannot be downloaded. Cause: `responseData` is not configured to include the file access path, or the file storage path has insufficient permissions.

## How to Confirm Successful Configuration

- View the knowledge base list associated with the application. Confirm that the target power generation-related knowledge base has been added and its synchronization status is completed.
- Initiate a test query. Check whether the returned results include structured traceability information such as file number and paragraph index.
- Click the source file link in the returned results. Confirm that the specified paragraph of the corresponding document can be accessed normally.
- Adjust the `quoteMaxToken` parameter. Verify that the length of the cited content matches the expected setting.

The values provided here are common starting points and should be evaluated against the reader's own samples.
