# Document and Material Drafting for Power Generation Groups: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Data related to document and material drafting for power generation groups comes primarily from internal safety production regulations, unit operation manuals, annual work reports, compliance review documents, bidding technical documents, and similar sources. Data update rhythms fall into three categories: regularly updated annual compliance documents, quarterly updated operation monthly reports, and temporary safety notices and technical adjustment documents released at any time. Most documents include standard fields such as document number, issuing department, applicable unit scope, and effective date. Some documents contain unit parameter tables, with professional measurement identifiers including MW, hours, and tons of standard coal.

## What constraints these characteristics impose on knowledge base retrieval and recall
Data sources are scattered across independent document collections from multiple departments. Precise retrieval scope limitation is required to avoid irrelevant results. Documents with different update rhythms require the retrieval link to support adaptive configuration for incremental synchronization and periodic full refreshes. Long text structures and professional measurement fields require the retrieval model to accurately match semantic relevance and unit consistency. This prevents retrieval failure from terminology deviations. Frequent temporary notice updates require the retrieval link to quickly respond to index refreshes after document changes. Long paragraph document structures increase chunking and embedding complexity. Adaptive configuration for long-text retrieval parameters is needed.

## How to set configurations
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `collectionIds` | Bind the collection ID of the power generation group's exclusive document library | Data is distributed across independent collections from multiple departments. Precise scope limitation restricts retrieval to valid content and filters irrelevant documents |
| `similarity` | 0.72–0.80 | Documents for power generation groups involve safety production and compliance requirements. A higher similarity threshold prevents misuse of non-adapted documents |
| `limit` | Top 8 entries | Individual documents are typically 2000–5000 characters long. Excessive recall results exceed the context window and reduce subsequent generation efficiency |
| `searchMode` | `vector` | Most documents contain long-text semantic content. Vector retrieval is more suitable for semantic matching of professional terms and long paragraphs than keyword matching |
| `usingReRank` | Enabled | Initial ranking accuracy of long-text vector retrieval is insufficient. The re-ranking step increases the proportion of highly relevant results in top positions |
| `datasetSearchUsingExtensionQuery` | Enabled | Power generation groups have a large number of professional synonyms. Expanded queries cover terms such as "unit" and "generator set" to improve recall coverage |

## Three common mistakes
- Issue: The knowledge base only supports full document upload, and cannot update individual document content separately. Cause: No incremental sync trigger rule is configured, and the change push interface of the internal document system is not connected.
- Issue: The AI generated reply takes more than 60 seconds after retrieval, and the interface returns a timeout prompt. Cause: The number of recalled documents exceeds the preset limit, causing the context window to overload and extending model inference time.
- Issue: The semantic matching degree of retrieval results is extremely low, and the operation procedures for the target unit cannot be recalled. Cause: The locally deployed m3e-large model is not configured as the embedding tool for the knowledge base, and the default general embedding model is used, which cannot adapt to power generation professional terms.

## How to confirm the configuration is correct
- Enter the knowledge base management page, view the bound collection list, and confirm that `collectionIds` includes the exclusive collection ID of the power generation group's document library.
- Enter a professional search term such as "1000MW unit maintenance procedure", check the similarity score of returned results, and confirm that the score falls within the 0.72–0.80 range.
- Submit a single modified temporary notice document, check the index update log, and confirm that only this document is synchronized and updated, and no full index rebuild is triggered.
- Test retrieval and check the number of returned results, confirm that a single retrieval returns no more than 8 entries.

The values provided are common starting points and should be measured against the reader's own samples.
