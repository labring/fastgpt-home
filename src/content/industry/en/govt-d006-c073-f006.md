# Document and Material Drafting for State-owned Industrial Funds: Citation Source and Traceability
This documentation applies to FastGPT v4.17.0.

## What this category of data looks like
State-owned industrial fund document and material data primarily originates from official documents such as state-owned asset supervision department filing records, fund prospectuses, investment decision meeting minutes, capital contribution agreements, annual operation reports, and similar official materials. Update cycles align with project approval, annual audit, and major adjustment milestones, with quarterly or annual serving as primary update windows. Documents include structured fields and unstructured text. Structured fields include fund code, capital contributor name, subscribed scale (unit: 100 million yuan), term of existence (unit: year), and similar items. Unstructured content consists of official documents in standard PDF or Word format.

## What constraints these characteristics impose on the citation source and traceability process
The mixed structured and unstructured document structure requires that traceability operations must simultaneously mark the source documents for structured fields and specific paragraph locations for unstructured text. The lack of a fixed update cycle requires that the traceability system support on-demand incremental synchronization to avoid repeated traceability of old data. The requirement for specific units attached to fields requires that corresponding units be clearly marked in traceability results to ensure audit compliance. The high compliance requirements for official documents require that traceability links point to original archived files, and temporary storage paths must not be used.

## How to Configure Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Single-paragraph citations for state-owned industrial fund documents are lengthy, requiring coverage of complete fields and context |
| `responseData` | Enabled | Structured citation source fields must be returned for internal audit and external regulatory purposes |
| `detail` | Enabled | Specific paragraphs, page numbers, and document names of cited content must be displayed |
| Maximum number of citations | Top 3 entries | The number of citation entries in a single question-and-answer result should not be excessive to avoid information overload |
| Synchronization trigger cycle | 2:00 AM daily | Aligns with off-peak hours for state-owned asset data updates to reduce system load |
| File format filter | PDF and Word documents only | Matches the standard storage formats for official state-owned industrial fund documents |

## Three Common Configuration Errors
- The returned citation links fail to download normally, with a 404 status code. This occurs when the original file hosting path is not configured, resulting in citation links that do not point to valid storage locations.
- The exported traceability data only includes the overall knowledge base dimension, and cannot be split by business category or data type. This occurs when the citation archive setting grouped by category is not enabled, resulting in traceability data granularity that fails to match business requirements.
- The question-and-answer result returned by the API call does not include citation source fields. This occurs when the `responseData` parameter is not enabled, and the switch for returning structured traceability data is not configured.

## How to Confirm Proper Configuration
- Initiate a question-and-answer session based on state-owned industrial fund documents, and check whether the returned result includes citation entries marked with file names and paragraph locations.
- Call the corresponding API interface to check whether the `responseData` field in the returned result includes structured information about citation sources.
- Manually trigger a knowledge base synchronization, and check whether the updated fund documents can be correctly traced back to the original files.
- Download the exported traceability data, and confirm that the data can be split by business category and match the corresponding paragraphs of the original document.
