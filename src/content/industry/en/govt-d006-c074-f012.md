# Document and Material Drafting for State-owned Asset Management Companies: Deployment and Upgrade

## What the data for this category looks like
The data for document and material drafting at state-owned asset management companies primarily comes from state-owned asset supervision submission documents, asset disposal plans, equity transfer agreements, annual operation reports, and internal compliance self-inspection documents. Daily business documents are generated as needed. Monthly and quarterly supervision reports are updated on a fixed schedule, and annual reports are finalized at the end of the year. Documents are split into two categories: fixed-format reports and free-format plans. Fixed-format reports include fields such as state-owned asset supervision number, original and net asset value (unit: ten thousand yuan), equity ratio, and others. Free-format documents include custom content such as approval process nodes and risk assessment items, and other custom content.

## What constraints these characteristics impose during deployment and upgrade
Structured fields in fixed-format reports require adapting structured data parsing logic during deployment. Ensure database connection parameters such as `MONGODB_URI` and `PG_URL` accurately match the unique identifier fields of state-owned asset supervision documents. The document update rhythm, which combines on-demand generation and fixed-cycle updates, requires deployment to support both incremental and full data synchronization modes. This avoids repeated processing of already updated content. Document types with long texts and multiple attachments require configuring sufficient storage capacity and large-file processing capabilities. Secure configuration of `REDIS_URL` and `FILE_TOKEN_KEY` is also needed to guarantee access permissions for state-owned asset data.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale for This Setting |
| --- | --- | --- |
| `DB_MAX_LINK` | 10–20 connections | Adapt to database concurrent requests during batch parsing of state-owned asset documents, avoid connection exhaustion |
| `MONGODB_URI` | Exclusive database path containing the state-owned asset document library | Store metadata for structured reports and free-format documents, ensure data isolation |
| `REDIS_URL` | Configure as an internal network exclusive cache address, set cache expiration time to 300–600 seconds | Cache frequently accessed supervision document metadata, reduce database query pressure |
| `STORAGE_S3_ENDPOINT` | Connect to the storage service address specified by the state-owned asset system, reserve no less than 1000 MB of storage space | Store long documents and multiple attachment contents, comply with data storage compliance requirements |
| `FILE_TOKEN_KEY` | Use a randomly generated high-strength key | Encrypt document access tokens, prevent unauthorized access to sensitive state-owned asset data |
| `ROOT_KEY` | Configure as a key accessible only to internal operations | Restrict background configuration permissions, avoid unauthorized modification of document processing rules |

## Three common errors
- Issue: Port conflicts or dependent service connection failure errors occur when deploying with docker-compose. Cause: The correct internal network addresses for `PG_URL` and `REDIS_URL` were not configured in advance, causing the container to fail to complete dependency initialization during startup.
- Issue: When asking questions about state-owned asset-related documents consecutively, the system cannot associate previous content, and responses are off-topic. Cause: A reasonable concurrency value for `DB_MAX_LINK` was not configured, causing the context cache to be frequently cleared or overwritten.
- Issue: The setup entry for custom prompts and reference templates cannot be found in older versions of FastGPT. Cause: The advanced configuration switch was not enabled, or front-end static resources of the corresponding version were not loaded during deployment. This configuration requires attention when adapting to FastGPT v4.17.0 and earlier versions.

## How to confirm the configuration is complete
- Log in to the FastGPT background management panel, check the database connection status module, confirm that the connection status of `MONGODB_URI` and `PG_URL` shows normal.
- Upload a state-owned asset supervision report document, trigger the parsing process, check whether the system correctly extracts structured fields such as supervision number and asset values.
- Initiate consecutive questions, verify whether the system can associate previously mentioned document content to provide targeted responses.
- Check the file upload logs of the storage service, confirm that long documents and attachments have been successfully uploaded to the specified storage path.
