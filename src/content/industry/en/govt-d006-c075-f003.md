# Document and Material Drafting for State-owned Capital Investment Companies: Multi-turn Dialogue and Prompt Engineering

## What the data for this category looks like
Document data for state-owned capital investment companies comes from internal state-owned assets supervision documents, group management systems, investment project feasibility study reports, board resolutions, annual work reports, and similar materials.
State-owned assets supervision policies update quarterly or annually. Internal project files update in real time as projects launch and major matters advance.
Document structures include fixed format fields: document number, project subject, investment amount, regulatory basis, effective date, and more.
Most units use ten thousand yuan and hundred million yuan. Date format follows YYYY-MM-DD. Some documents include dedicated state-owned assets supervision terminology fields.

## Constraints Imposed on Multi-turn Dialogue and Prompt Engineering
Documents for state-owned capital investment companies include fixed regulatory fields and proprietary terminology. Multi-turn dialogue must accurately link context-specific details such as project numbers and amounts. This prevents generated content from straying from the business scenario.
Long document multi-turn interactions consume significant context resources. The conversation window scope must be reasonably limited.
State-owned assets supervision policies update frequently. Prompts must regularly sync the latest regulatory knowledge base content to ensure generated documents meet current requirements.
Different document types (such as requests, replies, investment plans) have large format differences. Prompts must match corresponding knowledge base classifications by scenario to improve content accuracy.

## Three Common Misconfigurations
- Issue: Image links in markdown-imported documents lack domain names, making generated documents unable to display images properly. Cause: The automatic domain addition rule was only configured in the Word-to-Markdown conversion process, and not synchronized to the configuration items for pure markdown imports.
- Issue: Outdated state-owned assets supervision clauses are repeatedly referenced in multi-turn dialogue, resulting in generated documents that do not meet the latest policy requirements. Cause: The bound knowledge base content was not updated regularly, and the prompt did not link to the latest regulatory policy documents.
- Issue: Parameter errors are returned when calling the session interface, making it impossible to initiate conversations normally. Cause: `chatId` was not correctly set as a unique identifier, leading to incorrect overwriting of session context.

## How to Verify Proper Configuration
- Initiate a test conversation, input a request corresponding to the document type, and check whether the generated document includes the preset exclusive business fields.
- View the session history, confirm that the project context bound to `chatId` is not confused with other sessions.
- Import a markdown document with images, check whether the image links in the generated document have the correct domain name.
- Switch the conversation language configuration, confirm that the initial prompt complies with the corresponding language specifications for state-owned assets documents.
