# Document and Material Drafting for State-owned Capital Investment Companies: Tool Calling and Plugins
Reference only; verify against the target FastGPT release and deployment documentation.

## What this category of data looks like
Documents and materials from state-owned capital investment companies mainly originate from internal investment project feasibility study reports, board and supervisory board resolution documents, state-owned assets supervision reports, annual work reports, and company articles of association. Updates follow business milestones: project documents are dynamically updated during initiation, approval, and implementation stages. Annual documents are updated once per calendar year. Most documents use unified templates from the state-owned assets system, with standardized fields including project number, investment subject, approval document number, confidentiality level, and investment amount. Common units include ten thousand yuan, hundred million yuan, person-times, and similar units.

## Constraints on tool calling and plugins from these data characteristics
Data sources are scattered, covering internal business systems and state-owned assets supervision platforms. Tool calling must support adaptive configuration for multi-source data pulling to avoid cross-platform data synchronization exceptions. Document fields are standardized but cover a broad range. `toolChoice` must accurately match specified fields to prevent irrelevant content from interfering with document generation. A large share of documents involve confidentiality requirements. Plugins must include permission verification logic, only allowing authorized roles to call confidential data. Update rhythms differ significantly across document types. Differentiated calling frequency thresholds must be configured for each data source to avoid excessive pulling or delayed data.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Automatically select the corresponding tool based on document type, no manual switching of calling logic required |
| `functionCall` | Triggered by specified fields | Accurately extract standardized fields from state-owned assets documents such as project number and investment amount, avoiding invalid content |
| Knowledge base content access permissions | Configured by role hierarchy; confidential documents only accessible to core management positions | Comply with state-owned assets supervision and confidentiality requirements for state-owned capital investment companies, preventing sensitive information leaks |
| Log collection and management | Retain complete logs of call duration, returned fields, and error codes; retention period of no less than 180 days | Meet traceability requirements for state-owned assets audits, enabling full reproduction of the tool calling process |
| Single tool call limit | Up to 8-12 matching data entries; each entry no larger than 500 KB | Balance data sufficiency and generation efficiency, avoiding redundant information interfering with document drafting |
| Tool call timeout threshold | 600 seconds | Adapt to the long field extraction and data pulling duration of state-owned assets documents, preventing mid-process interruptions |

## Three common configuration errors
- An `invalid api key` error occurs during tool calling. Cause: The application's appId was not correctly retrieved as the calling key, and other identifiers were incorrectly entered into the configuration item.
- Empty fields are returned after tool calling. Cause: No standardized fields matching state-owned capital investment company documents were detected, and the plugin was not adapted to the unified template structure of the state-owned assets system.
- Execution stops unexpectedly when multiple tools run in sequence. Cause: No timeout threshold was configured. Field extraction for long documents exceeded the default duration, causing the call to fail.

## How to verify correct configuration
- Initiate a tool call for a state-owned capital project document, and check that the returned fields include preset content such as project number and investment amount.
- Access the log collection module, and confirm that complete records of call duration, returned fields, and error codes have been created, with a retention period that meets requirements.
- Attempt to call confidential documents using a non-authorized role, and confirm that sensitive content cannot be accessed.
- Test the sequential execution flow for multiple tools, and confirm that there are no interruptions or timeout errors.
