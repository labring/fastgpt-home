# Document and Material Drafting for State-owned Capital Investment Companies: Citation Source and Traceability

## What the Data for This Category Looks Like
State-owned capital investment company document data mainly comes from normative documents issued by state-owned assets supervision departments, internal group management systems, investment project feasibility study reports, shareholder and board of director resolutions, and annual financial reports. Data is updated regularly on a quarterly basis. Temporary project files are updated synchronously with project initiation and approval nodes. Most documents use structured formats, containing document numbers, issuing units, effective dates, and clause entries, along with fields such as project number, supervision level, and affiliated sector. Common units include ten thousand yuan, hundred million yuan, and shareholding ratio.

## Constraints for Citation Source and Traceability
Structured document fields and specialized terminology require accurate matching of identification fields like document numbers and project numbers during citation traceability. This prevents generic retrieval from matching irrelevant documents. The quarterly update rhythm plus temporary node updates requires the knowledge base synchronization mechanism to cover both regular updates and temporary new data scenarios. This ensures the timeliness of traceability data. Multiple document source types require the retrieval scope to cover three categories: regulatory documents, internal management systems, and project documents. Specialized state-owned assets supervision terms in documents must be accurately recognized by the retrieval model to link fields correctly. This avoids misattribution in traceability results.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | 8000–12000 token | Single documents for state-owned capital investment companies are usually several thousand words long, requiring coverage of complete quoted clause fragments |
| `responseData` | Metadata format including document number and project number | Specialized fields must be extracted to complete traceability verification, ensuring citation sources can be traced |
| `detail` | Enabled | Precise matching of state-owned assets supervision specialized terms and structured fields in documents is required to improve retrieval accuracy |
| Single retrieval recall limit | Top 6–10 results | Data sources for this category are clearly categorized, excessive recall will increase subsequent filtering burden |
| Knowledge base update trigger rules | Every 7 days for regular synchronization + triggered by temporary project nodes | Covers both quarterly regular updates and temporary project file data scenarios |

## Three Common Configuration Mistakes
- Phenomenon: Retrieval results match irrelevant documents, and the target project’s feasibility study report cannot be located. Cause: The precise matching mode of the `detail` parameter is not enabled, and generic retrieval logic is used.
- Phenomenon: After uploading 100 5kb files to the knowledge base, only 50 show training completion. Cause: No file type filtering upload rules are configured. Some non-compliant state-owned assets supervision documents are not correctly identified.
- Phenomenon: After setting `quoteMaxToken` to 20000 token, the quoted fragment exceeds the context window and generation fails. Cause: The parameter is not adjusted based on single document length. Excessively expanding the token upper limit causes context overflow.

## How to Verify Proper Configuration
- Submit a retrieval request targeting a specific project document number. Check if returned results include exclusive metadata such as the corresponding document’s number and project number.
- View the knowledge base synchronization task list. Confirm that both regular periodic synchronization and temporary project trigger synchronization tasks run normally.
- Generate a draft document. Check if quoted fragments include traceable original document source information.
- Adjust retrieval-related parameters. Compare recall results across different configurations to confirm matching accuracy meets business requirements.
