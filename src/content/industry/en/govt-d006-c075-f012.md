# Document and Material Drafting for State-owned Capital Investment Companies: Deployment and Upgrade

## What the data for this category looks like
State-owned capital investment company documents and materials originate from normative documents issued by state-owned assets supervision authorities, internal group investment decision documents, project feasibility study reports, resolutions of the board of directors, board of supervisors and general meeting of shareholders, financial special explanations, and similar sources. Update rhythm adjusts based on business nodes and policy requirements, with no fixed cycle. Project documents are updated as projects progress, while policy documents are updated per regulatory requirements. Document structures include standard fields such as uniform document number, issuing entity, and effective date. Investment-related files additionally include specialized fields such as investment amount and project cycle. Individual document length ranges from hundreds of words in resolutions to tens of thousands of words in feasibility study reports.

## Constraints imposed by these characteristics on deployment and upgrade
State-owned capital investment company documents involve state-owned assets supervision information and internal sensitive data. Deployment must be limited to intranet environments, and all external access must be strictly isolated. Document length varies widely, and individual file sizes are large. Deployment requires resource configurations adapted to large-file storage and parsing. Data sources are scattered, and updates have no fixed cycle. Upgrade must ensure complete retention of historical document vector indexes and original data, to avoid data loss caused by configuration changes. Additionally, this category of documents has specific format and field requirements. Corresponding document parsing rules must be configured during deployment to ensure accuracy of subsequent retrieval and generation.

## How to set configuration values
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `MONGODB_URI` | `mongodb://intranet IP:27017/fastgpt?authSource=admin` | Adapts to intranet deployment requirements, prevents leakage of state-owned assets sensitive data |
| `REDIS_URL` | `rediss://intranet IP:6379/0` | Ensures encrypted transmission of cached data, complies with state-owned assets information security specifications |
| `STORAGE_S3_ENDPOINT` | `http://intranet storage node IP:9000` | Adapts to local storage of large-volume document files, reduces cross-network transmission latency |
| `DB_MAX_LINK` | `100–150` | Matches concurrent connection count for single-batch document parsing, avoids exceeding intranet database load |
| `FILE_TOKEN_KEY` | `Calibrated via actual testing, recommended 1000–2000 characters` | Adapts to average length of documents in this category, ensures integrity of long-document parsing |
| `FE_DOMAIN` | `https://intranet domain of state-owned capital investment company` | Limits frontend access scope, complies with internal system permission management requirements |

## Three common misconfigurations
- Phenomenon: Vector indexes of historical documents are lost after upgrade, old documents cannot be retrieved. Cause: Failed to back up the database data corresponding to `MONGODB_URI` in advance, directly executed the upgrade script to overwrite configurations.
- Phenomenon: MCP server service fails to start after deployment, logs report connection timeout errors. Cause: Did not configure an intranet-accessible `REDIS_URL`, causing the service to fail to connect to the cache component.
- Phenomenon: When deploying on a Huawei all-in-one machine, large-volume feasibility study report parsing fails, returns status code 500. Cause: Did not adjust the value range of `FILE_TOKEN_KEY`, exceeding the single-file processing limit of the default configuration.

## How to confirm successful configuration
- Log in to the FastGPT v4.17.0 backend system configuration page, verify the intranet address configurations of core parameters including `MONGODB_URI` and `REDIS_URL`, confirm they match the network topology of the deployment environment.
- Upload a typical state-owned capital investment company document file, trigger the parsing and vector generation process, check whether the parsing result includes core document fields such as document number and issuing date.
- Before executing the upgrade script, manually back up the database storage directory and vector index files, confirm the backup files are complete before performing the upgrade operation.
- In the intranet environment of the Huawei all-in-one machine, start the MCP server service, check that the logs have no connection timeout errors, confirm the service is running normally.
