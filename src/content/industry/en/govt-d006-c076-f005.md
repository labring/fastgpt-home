# Document and Material Drafting for State-owned Capital Operation Companies: Tool Calling and Plugins

## What the data for this category looks like
Document data for state-owned capital operation companies mainly comes from internal compliance documents, normative documents issued by state-owned assets supervision authorities, annual group operation reports, property transfer agreements, salary assessment plans, and similar materials. Update frequency adjusts according to business nodes. Regulatory policy documents update quarterly or annually. Internal project documents update with transaction and assessment cycles. Individual document lengths vary widely. They range from hundreds of words in notice-style files to tens of thousands of words in annual operation plans. Document fields include document number, main and copy recipient units, core business indicators (such as asset transfer amount, shareholding ratio), attachment list, issuing unit and date. Some confidential documents have classification markings.

## What constraints these characteristics impose on tool calling and plugin configuration
The characteristics of document data for state-owned capital operation companies impose multiple constraints on tool calling and plugin configuration.
The permission difference between confidential and public documents requires role-based access control to be configured during tool calling. Only authorized documents can be retrieved and cited.
The requirement for accuracy of core business indicators means the parameter verification link of tool calling must match the numerical format and unit specifications of state-owned assets supervision. This prevents errors in the description of asset amounts and shareholding ratios.
The frequent update feature of state-owned assets supervision policies requires plugins to be configured with tasks that regularly synchronize the latest regulatory documents. This ensures generated documents comply with current compliance requirements.
The document structure with multiple attachments requires plugins to support linked retrieval of attachment content. This avoids missing attachment-related descriptions in generated documents.

## Configuration Settings
All configurations are compatible with FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Access Control Permissions | Bind state-owned document categories by user role | Matches the permission difference requirement between confidential and public documents |
| Parameter Verification Rules | Match state-owned assets supervision numerical formats and units | Ensures accurate description of core business indicators |
| Plugin Synchronization Cycle | Once every 7 days | Adapts to the update rhythm of state-owned assets supervision documents |
| `toolChoice` | auto | Allows the model to independently select appropriate tool calling scenarios |
| Attachment Linked Retrieval | Enable attachment content indexing | Supports content citation for documents associated with multiple attachments |
| `functionCall` | Enable mandatory format verification | Ensures tool call output complies with compliance requirements |

## Three Common Misconfigurations
- Phenomenon: Documents generated in non-tool calling mode do not cite the latest state-owned assets supervision policy content. The web search function works normally in other scenarios. Cause: The trigger condition for document retrieval is not configured in non-tool calling mode. The model only relies on built-in knowledge base content.
- Phenomenon: After uploading a plugin, the corresponding entry cannot be found in the community plugin list. Cause: The plugin's category tags and adaptation scenario description are not filled in according to platform requirements. This results in index matching failure.
- Phenomenon: Predefined business variables cannot be selected in the JSON format tool input box. Cause: The variable mapping switch is not enabled, or the input box is not configured with format verification rules that allow variable injection.

## How to Confirm Configuration is Correct
- Run a tool calling test. Check whether the retrieval results include the corresponding category of state-owned documents. This verifies that the access control configuration takes effect.
- Generate a test document containing core business indicators. Check whether the indicator values and units comply with state-owned assets supervision specifications. This verifies that the parameter verification configuration takes effect.
- Manually trigger the plugin synchronization task. Check whether the synchronization log shows that the latest supervision documents have been indexed. This verifies that the synchronization cycle configuration takes effect.
- Try inserting predefined business variables into the JSON input box. Confirm that the variables can be correctly identified and replaced. This verifies that the variable mapping configuration takes effect.
