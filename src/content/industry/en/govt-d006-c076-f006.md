# Document and Material Drafting for State-owned Capital Operation Companies: Citation Source and Traceability

## What this category’s data looks like
State-owned capital operation company document and material data originates from publicly released state-owned assets supervision and administration department documents, internal group operation reports, investment and financing plans, compliance review opinions, property right transfer approvals, and similar materials. There are two data update cycles: regular operation reports are updated quarterly or annually. Major investment and financing and compliance-related matters are updated in real time. Document structures are fixed, with standard fields including document number, issuing unit, effective date, core clauses, and involved entities. Monetary content uses ten thousand yuan or hundred million yuan as the unified unit.

## What constraints these characteristics impose on citation source and traceability workflows
State-owned assets documents have classified or internally sensitive attributes. Traceability workflows must strictly match original document sources to prevent disclosure of non-public information. Fixed document number and effective date fields require extracting these identifiers as unique traceability references during citation. This ensures cited content can be traced back to the original document. Long paragraph structures and unified unit specifications require chunking and retrieval steps to retain complete core content and unit information. This avoids distortion of cited content. Documents with different update cycles require traceability systems to differentiate between regularly updated and real-time updated files. This prevents citing expired content.

## How to configure settings
| Configuration Item | Recommended Value Range | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1500–2000 token | State-owned capital operation company document paragraphs are relatively long, requiring sufficient retained cited original content to support drafting needs |
| `responseData` | Enable citation details | Must return complete traceability information to meet the requirements of state-owned assets compliance reviews |
| `detail` | Enable fragment traceability | Supports locating specific chapters of the original document, improving the accuracy of citations |
| Chunk overlap length | 100–200 characters | Matches the long paragraph structure of state-owned assets documents, avoiding core clause content being split during chunking |
| Single search limit | Top 6 results | Covers compliance documents from multiple sources while avoiding redundant information interfering with drafting |
| Maximum context | 8000–10000 characters | Adapts to context requirements for long document drafting, calibrated based on actual testing |

## Three common configuration errors
- No citation fields appear in API response data. This occurs when the `responseData` configuration item is not enabled, and the citation detail return logic is not activated.
- No citation fragments are displayed in interface replies. This occurs when the `detail` configuration item is not enabled, and the fragment traceability display function is not turned on.
- A red error code is returned in the console during API calls. This occurs when exclusive state-owned assets document fields (such as document number) are not correctly associated. This causes abnormal traceability matching logic and failure to locate valid sources.
