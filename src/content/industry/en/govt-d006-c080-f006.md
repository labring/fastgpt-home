# Document and Material Drafting for Urban Investment Platforms: Citation Source and Traceability

## What this category of data looks like
The data used for document and material drafting for urban investment platforms mainly comes from local state-owned assets supervision and administration commission filing documents, annual reports and project feasibility study reports publicly disclosed by urban investment entities, regional public utility operation ledgers, and urban investment bond prospectuses. Data update schedules are adjusted based on business milestones. Project-related files are updated alongside project approval, construction start, and completion milestones. Publicly disclosed materials are updated on a fixed quarterly or annual basis. Most documents follow official document formats, and include structured fields such as project number, entity name, region code, operation indicators, and debt scale. Units include ten thousand yuan, square kilometers, service person-times, and similar units.

## Constraints on Citation Source and Traceability
Most documents for urban investment platforms involve compliance reviews. Traceability information must clearly mark the file name, issuing entity, and issuing time. Vague citations are not permitted. The high volume of structured fields requires traceability to accurately match key identifiers such as project numbers and region codes. This prevents data confusion across different entities and regions. The update schedule adjusted to business milestones requires the traceability process to regularly sync the latest filing and disclosure documents. This prevents the use of expired or not yet effective content. The requirement for official document formats means traceability must match positioning details such as document chapters and document numbers. This ensures cited content is fully consistent with the original text.

## Configuration Settings
The following configurations are formulated based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 characters` | Compliance description paragraphs in urban investment platform documents are lengthy, so full cited content must be covered |
| `responseData` | Enabled | Original cited structured fields must be returned to generate accurate traceability information |
| `detail` | Full | Full context of cited content must be displayed to meet detail requirements for compliance reviews |
| Maximum number of citations | Top 3 entries | Citations for urban investment documents must focus on core compliance basis, avoiding redundant content that disrupts reviews |
| Knowledge base chunking granularity | 1500–2000 characters | Urban investment documents have complete structures. Overly fine chunking will disrupt the coherence of compliance description paragraphs |
| Knowledge base refresh cycle | 7 days | Publicly disclosed data for urban investment platforms is updated quarterly. Weekly refresh covers the latest filing and disclosure content |
| Traceability information display location | End of main text | Aligns with official document typesetting habits, allowing reviewers to quickly view citation sources |

## Three Common Configuration Errors
- Issue: The API call returns a 200 status code, but no content field is present. Cause: The `responseData` configuration is not enabled. This causes the API to only return aggregated results, without retaining original cited content.
- Issue: Garbled text or formatting errors appear in generated documents. Cause: The knowledge base chunking granularity is set too small. This disrupts the official typesetting structure of urban investment official documents, leading to formatting anomalies during parsing.
- Issue: Cited knowledge base content does not appear in the main text. Cause: The `detail` configuration is not enabled, or the maximum number of citations is set to 0. This causes the system to not extract and display the cited content.

## How to Verify Successful Configuration
- Send a test request, check if the returned result contains the `responseData` field, and the field includes information such as the original cited document name and issuing entity.
- Generate a document related to urban investment project approval, check if the cited content and corresponding traceability information are displayed in the main text.
- Adjust the value of `quoteMaxToken`, verify that the truncation or retention of cited content meets expectations.
- View the chunked document fragments in the knowledge base, confirm that the chunking granularity covers complete compliance description paragraphs.
