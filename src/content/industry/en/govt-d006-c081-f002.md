# Document and Material Drafting for Basic Chemical Industry: Vector Models and Indexes

## What the data for this category looks like
Documents and materials in the basic chemical industry primarily originate from internal enterprise process specifications, safety data sheets (MSDS), production operation records, compliance review documents, R&D experiment reports, and bidding documents. Data update cycles vary significantly: process specifications and compliance documents are updated quarterly or annually alongside regulations or process optimizations. Production records are updated daily. Bidding documents are generated irregularly based on project cycles.

Document structures include structured fields and unstructured text. Structured fields include material codes, CAS numbers, production batches, pressure limits, temperature thresholds, and similar items. Units involve professional chemical units such as tons, kilograms, cubic meters, MPa, ℃. The length of individual documents ranges from several hundred characters for production operation records to dozens of pages for safety data sheets.

## Constraints on Vector Models and Indexing
First, long documents account for a high proportion, with individual content possibly exceeding ten thousand characters. Performing full vectorization directly will exceed the model’s token limit, so reasonable chunk splitting is required.
Second, structured fields and professional terms are dense. Vector recall must balance semantic matching and metadata filtering. Otherwise, irrelevant material data may be retrieved.
Third, update frequencies vary greatly. Full indexing cannot adapt to frequently updated production records, so incremental index trigger rules need to be set.
Fourth, many industry-specific terms exist in the chemical field. The semantic matching accuracy of general vector models is insufficient. Select vector models adapted to the industrial field to avoid semantic deviation of terms.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Adapts to the paragraph length of basic chemical industry documents, avoids breaking the logical coherence of process descriptions during splitting |
| Overlap Length | 100–200 characters | Retains cross-chunk process step association information, prevents loss of contextual logic after splitting |
| Similarity Threshold | 0.72–0.85, calibrated via actual testing | Distinguishes semantic similarity of chemical professional terms, reduces the recall probability of irrelevant material data |
| Single Search Limit | Top 8 entries | Covers recall requirements for different types of documents, balances retrieval accuracy and response speed |
| `maxToken` | 4000 | Adapts to context splicing requirements for long documents, aligns with the content length range of basic chemical industry documents |
| `defaultToken` | 200 | Controls the output length of a single vector, optimizes storage efficiency of vector indexes |

## Three Common Misconfigurations
- Phenomenon: No available options appear in the index model selection interface, and configuration cannot be completed. Cause: The industrial-adapted vector model file for the chemical field has not been imported in FastGPT v4.17.0, or the model call path was not filled correctly during configuration.
- Phenomenon: Semantically similar but purpose-mismatched chemical material descriptions appear in recall results. Cause: Filter conditions were not set for structured fields such as CAS numbers and production batches in the documents, leading to retrieval of cross-category irrelevant data.
- Phenomenon: Vector index update tasks time out. Cause: The incremental index trigger timing was not set according to document update frequencies, and full indexing was mistakenly applied to daily updated production records, exceeding system processing thresholds.

## How to Verify Correct Configuration
- Enter the vector model configuration page of FastGPT v4.17.0, confirm that the industrial-adapted vector model has been added, and the target model can be selected normally from the drop-down list.
- Upload an internal enterprise safety data sheet document, perform a manual index test, and check whether the chunked content retains complete safety parameters and process descriptions.
- Initiate a query targeting specific material safety limits, verify whether the recall results include the CAS number field of the corresponding material, and the similarity meets the preset threshold.
- View the storage statistics of the vector index, confirm that the length of a single vector conforms to the configured value of `defaultToken`, and no abnormal overflow occurs.

The values provided are common starting points and should be measured against the reader's own samples.
