# Document and Material Drafting for Basic Chemical Industry: Tool Calling and Plugins

## What the data for this category looks like
Basic chemical industry document data mainly comes from internal enterprise process procedures, raw material quality inspection reports, safety technical specifications, and industry compliance documents. Data is updated by raw material batch and production cycle, while compliance documents are adjusted along with regulatory policies. Documents include structured parameter tables and unstructured explanatory text, with fields covering material codes, process temperature, pressure, batch numbers, and more. Units mostly use industry standard units such as ton, cubic meter, degree Celsius, and megapascal.

## What Constraints These Characteristics Impose on Tool Calling and Plugins
The mixed feature of structured parameter tables and unstructured compliance text in the basic chemical industry requires tool calling plugins to support both structured data reading and long text parsing. Data updated by batch and production cycle requires plugins to dynamically pull the latest batch information to avoid using expired data. Fixed-field compliance documents require tool calling parameters to match fixed fields such as material codes and process parameters. When long-text process instructions exceed context limits, tool calling must be used to split and process segments, while also supporting conversion verification of industry-specific units.

## How to Configure

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` or specify compliance check, data pull tool name | Basic chemical document drafting requires matching two types of tools: compliance check and data pull. Auto mode automatically adapts to scenarios, specifying the tool name limits the calling scope |
| `functionCall` | Enabled | Basic chemical documents require generating parameterized content. Enabling this allows inserting structured materials and process parameters via function calls |
| Database plugin data source configuration | Configured as enterprise internal raw material library and process library, specify character encoding as utf8mb4 | Basic chemical data contains Chinese material names and parameters; utf8mb4 avoids Chinese garbled characters |
| Tool call timeout setting | 300–600 seconds | Pulling large volumes of basic chemical data takes longer; the timeout setting must cover multi-batch data query processes |
| Number of returns per single tool call | Top 5–10 entries | Basic chemical documents do not require excessive redundant data; limiting the number of entries improves query efficiency |
| Maximum context length | 8000–12000 token | Long-text process specifications for basic chemical industry require full loading, adapting to long-context parsing needs |
| Basic chart plugin axis configuration | Configure X-axis as material code, Y-axis as process parameters, match units to industry standards | Basic chemical documents often require accompanying parameter charts; fixing axis fields and units ensures document compliance |

## Three Common Mistakes
- Phenomenon: Tool calls output both AI replies and execution branch logs, and do not execute a single path as expected. Cause: The `toolChoice` parameter is not configured correctly; the default auto mode triggers multi-branch execution simultaneously.
- Phenomenon: Chinese fields return empty or garbled characters after connecting the database plugin. Cause: The database character encoding is not configured as utf8mb4; basic chemical material names contain rare Chinese characters, which cannot be fully parsed by general encoding.
- Phenomenon: Chart units generated by the basic chart plugin do not match document requirements. Cause: Chart axis units are not configured according to industry standards; using default units directly leads to compliance issues.

## How to Verify Proper Configuration
- Call the tool call test interface, check whether the `toolChoice` parameter takes effect as configured, and the tool call range meets expectations.
- Execute a database plugin query, verify that Chinese material names and parameters can be displayed normally without garbled characters.
- Generate a draft basic chemical document, check whether the chart axis fields and units match industry standards.
- Test long-text process specification parsing, confirm that the context loads without truncation or errors.

The values provided are common starting points and should be measured against the reader's own samples.
