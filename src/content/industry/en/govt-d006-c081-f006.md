# Document and Material Drafting for Basic Chemical Industry: Citation Sources and Traceability

## What the data for this category looks like
Basic chemical industry document data mainly comes from internal enterprise process specifications, raw material quality inspection reports, product factory certificates, Material Safety Data Sheets (MSDS), and national/industry execution standard documents. Data updates are triggered on demand when raw material batches are replaced or production processes are adjusted, with no fixed cycle. Most documents are structured long texts, containing clear fields such as CAS registry numbers, purity, batch numbers, execution standard numbers, and operating parameters. Common units include mass fraction, volume ratio, MPa, and ℃.

## Constraints on citation and traceability
Basic chemical data has many structured, highly specialized fields. Citation and traceability require precise matching of unique identifiers such as CAS registry numbers and batch numbers. Without this, specific raw material or process documents cannot be located. Long text structures require retaining sufficient context during chunking, to avoid losing cross-chapter associated logic after splitting. The on-demand update feature requires the knowledge base to trigger an update mechanism synchronously, to prevent referencing expired raw material or process data. Safety technical instruction manuals from different manufacturers have minor format differences. Retrieval must support field extraction for multiple document structures.

## Configuration settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Single sections of basic chemical documents such as process specifications and MSDS are lengthy, requiring sufficient citation context to support drafting logic |
| `responseData` | Enabled | Key identifiers of document sources must be included in drafted documents to meet traceability requirements |
| `detail` | Enabled | Display specific fields in documents such as CAS numbers, batch numbers, and execution standard numbers to enhance traceability accuracy |
| Single search limit | Top 3–5 results | Basic chemical-related documents have strong relevance; too many search results will exceed the token consumption limit |
| Request timeout | 300 seconds | Retrieval of basic chemical documents requires matching a large number of professional fields, so sufficient time must be reserved for retrieval |
| Chunk overlap length | 100–150 characters | Chemical documents are mostly long texts; overlapping chunking preserves key cross-chapter associated information |

## Three common mistakes
- Issue: Citation sources are displayed on the debug page, but no citation content appears on the officially released chat page. Cause: The `responseData` configuration is not enabled, and citation display is only enabled in debug mode.
- Issue: The results of program execution in the workflow cannot be called as background knowledge by subsequent AI modules. Cause: The output of the execution node is not configured as a structured format readable by the knowledge base, and is not linked to the context input link.
- Issue: After setting the citation limit, the generated document still exceeds the token limit. Cause: The `quoteMaxToken` value is not adjusted based on the length of basic chemical documents, or the single search limit is set too high, leading to the introduction of too many redundant documents.

## How to confirm the configuration is correct
The following verification steps are based on FastGPT v4.17.0:
- Enter the debug page to initiate a chemical document drafting request, and check whether the returned results include specific document source fields such as CAS numbers and batch numbers.
- After publishing the chat page, initiate the same drafting request, and confirm that citation sources are normally displayed in the reply content.
- Submit a long text drafting request, and check that the token consumption of the generated content does not exceed the preset context limit.
- Trigger a knowledge base update, upload a new raw material quality inspection report, and verify that the new document can be normally retrieved and used as a citation source.

The values provided are common starting points and should be measured against the reader's own samples.
