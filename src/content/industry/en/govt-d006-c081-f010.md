# Document and Material Drafting for Basic Chemical Industry: Knowledge Base Retrieval and Recall

## What the data for this category looks like
The data used for document and material drafting in the basic chemical industry mainly comes from enterprise internal safety data sheets (MSDS), process operation specifications, product inspection reports, hazardous chemical compliance management documents, and industry standard documents. Data updates follow two rhythms: fixed quarterly updates and emergency updates. Most document structures include fixed fields such as product name, CAS registry number, specification parameters, safety limits, and approval document numbers. Common units include mass fraction, megapascals, degrees Celsius, milligrams per kilogram, and others. The length of individual documents varies widely, ranging from a few pages to dozens of pages of process package files.

## Constraints imposed on knowledge base retrieval and recall
The long text characteristics of basic chemical industry documents require the retrieval module to support semantic association matching for long paragraphs, to avoid context fragmentation caused by chunking. Professional fields such as CAS numbers and industry standard numbers require precise keyword matching, and cannot rely solely on semantic retrieval. Frequent emergency updates require the retrieval module to support incremental synchronization, to avoid performance loss from full synchronization. Diverse unit systems require unified unit parsing for retrieval results, to avoid retrieval deviations caused by unit mismatches. The large number of exclusive documents requires the retrieval scope to be strictly limited to the basic chemical industry exclusive collection, to avoid introducing irrelevant content.

| `datasetSearchUsingExtensionQuery` | Enabled | User questions during document drafting often omit professional prefixes. Extended queries can supplement standard numbers and term aliases, matching compliance-related documents |
| `collectionIds` | Enterprise basic chemical industry exclusive collection ID | Limit the retrieval scope to exclusive data such as MSDS and process specifications, to avoid retrieving irrelevant documents |

## Three common configuration errors
- Phenomenon: Retrieval results display document download links in debug mode, but the links disappear after the application is published. Cause: The knowledge base document external link permission is not enabled in the application configuration. Only debug mode enables temporary access permission by default.
- Phenomenon: After uploading a PDF chemical process package, the vectorization progress stalls for more than 300 seconds. Cause: The chunk batch processing parameter is not enabled. Chunking and vectorization of long PDF documents are not split into batches, leading to excessive resource usage.
- Phenomenon: In a simplified Chinese application, the knowledge base search citation upper limit is 13000, and context overflow occurs when called in a workflow. Cause: Configuration parameters for the application end and workflow end are not differentiated. The number of retrieved results is not adjusted to match the workflow’s context limit.

## How to confirm proper configuration
- Enter the knowledge base debug interface, input a basic chemical industry professional question, and verify that the matching score of retrieval results falls within the preset range.
- Initiate a simulated document drafting call, and check that the number of returned results matches the configured retrieval upper limit.
- Check retrieval results after the application is published, and confirm that only enterprise basic chemical industry exclusive documents are displayed, with no irrelevant industry or general content included.
- After enabling the reranking function, check that the ranking of retrieval results aligns with professional relevance, with no low-relevance content appearing first.
