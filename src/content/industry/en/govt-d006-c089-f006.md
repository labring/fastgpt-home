# Document and Material Drafting for Construction Machinery: Citation Sourcing and Traceability

## What the Data for This Category Looks Like
Data sources for construction machinery-related documents include equipment manufacturing industry standard documents, internal enterprise equipment archives, archived operation and maintenance logs, quality inspection and compliance documents, and others. Update frequency adjusts with new model mass production and annual compliance audit completion, with no fixed cycle. Most documents combine structured text and long paragraphs, containing fields such as equipment model, rated lifting capacity, working radius, maintenance cycle, and compliance certification number. Units include tons, meters, working hours, certification validity period, and similar units.

## Constraints Imposed by These Characteristics on Citation Sourcing and Traceability
The large number of structured fields with exclusive units means citation traceability requires precise binding of fields and units, to avoid matching parameters of unrelated equipment. The length of individual documents varies widely, from short text on equipment nameplates to long annual operation and maintenance manuals. When chunking documents, context association must be retained, otherwise traceability will lose the correspondence between equipment models and parameters. Data source updates have no fixed cycle, so knowledge base synchronization must adapt to non-timed update scenarios, to avoid citing expired data. Some documents involve compliance certification numbers, so traceability requires precise matching of the number field, otherwise the compliance validity of the citation cannot be confirmed.

## Configuration Settings
This configuration is formulated based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Similarity Threshold | 0.75–0.85 | Matches structured parameters of construction machinery with units, requires a higher threshold to avoid matching unrelated equipment |
| Single Search Limit | Top 6 results | Fields for individual equipment documents are concentrated, so excessive recall results are unnecessary |
| `quoteMaxToken` | 800–1200 characters | Covers core parameters and compliance numbers of a single piece of equipment, ensuring complete traceability information |
| Reranking | Enabled | Prioritizes recall of fragments containing equipment models and core parameters, improving traceability accuracy |
| `responseData` | Enabled | Forces return of complete citation source information to facilitate traceability verification |
| `detail` | Enabled | Returns detailed document fragment source paths and matched fields, improving traceability transparency |

## Three Common Misconfigurations
- Phenomenon: Returned results show that knowledge base content is cited, but the answer is completely unrelated to the equipment documents in the knowledge base, and the parameters of the target equipment are not mentioned. Cause: The similarity threshold is not set high enough, leading to recall of unrelated equipment document fragments.
- Phenomenon: Only text-format equipment manuals are cited, and structured parameter documents are not recalled. Cause: Matching configurations for structured fields are not enabled, and only text content is recalled by default.
- Phenomenon: The returned citation source is empty when calling the workflow via API, and the specified construction machinery knowledge base cannot be bound. Cause: The knowledge base ID is not configured as a global variable for the workflow, so the call does not point to the target knowledge base.

## How to Confirm Proper Configuration
- Upload the equipment manual document for a single piece of construction machinery, initiate a drafting query that includes the equipment model and rated lifting capacity, and verify that the cited fragments in the returned results include the corresponding model and parameters.
- Access the workflow configuration page, confirm that the target construction machinery knowledge base has been bound, initiate an API call, and check whether the returned `responseData` field contains correct citation source information.
- Adjust the similarity threshold to 0.8, initiate a test query, and confirm that the recalled results only include equipment document fragments strongly related to the query.
- Review the system log to confirm that the `detail` field returns complete document source paths and matched field information.

The values provided are common starting points and should be evaluated against appropriate sample data.
