# Document and Material Drafting for Building Construction General Contracting: Citation Source and Traceability

## What This Category of Data Entails
Business data for building construction general contracting originates from full project cycle documents: bidding files, construction logs, change visa forms, completion acceptance reports, standard construction specifications, and internal contract templates.
Data updates trigger at project progress milestones. Update frequency within a single project cycle shifts based on construction phases.
Most documents are structured text, with fields including project number, section name, construction location, material parameters, and acceptance standards. Units use engineering-specific measurement standards such as square meters, cubic meters, tons, and work hours.

## Constraints for Citation Source and Traceability
Business data for building construction general contracting is scattered across multiple project document types, and is bound to exclusive parameters by construction location and section. Citation traceability must precisely match project-related dimension information to avoid incorrect cross-section or cross-location associations.
Data updates frequently during construction progress. Knowledge base recall content must align with the current construction phase to prevent citations of expired visas or acceptance standards.
Documents include a large number of engineering-specific fields and measurement units. Field association relationships must be retained during recall to avoid loss of critical positioning information when text is split.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Range/Setting | Rationale |
| ---- | ---- | ---- |
| Similarity Threshold | 0.75–0.85 | Matches the precision of construction engineering terminology, and avoids recalling unrelated documents from other sections |
| Single Search Limit | Top 8 results | Covers multiple types of related documents for a single construction location, such as visas, acceptance records, and construction logs |
| `quoteMaxToken` | 1200–1500 token | Accommodates long text fragments from engineering documents, and preserves complete visa numbers or acceptance conclusions |
| Reranking | Enabled | Sorts content by relevance, and prioritizes recall of content directly related to the construction location of the current drafted document |
| `responseData` | Return only citation sources | Ensures output citations only link to exclusive documents for building construction projects, and excludes general knowledge |
| `detail` | Enabled | Displays fields from cited documents such as project number and section name, to facilitate quick verification and traceability |

## Three Common Errors
- Scenario: When citation is enabled in the configuration, the interface displays a list of cited documents, but the AI-generated document does not include professional content from the knowledge base. Cause: The `responseData` parameter is not configured correctly, or the similarity threshold is set too low, meaning recalled documents are not properly linked to the generation logic.
- Scenario: Uploaded drawing and table files in the knowledge base are not recalled, and only text datasets can generate citations. Cause: The parsing switch for the corresponding file format is not enabled, or structured indexes are not generated for non-text files, making it impossible to match field associations in engineering documents.
- Scenario: After dynamically passing knowledge base search variables, the AI does not recall documents for the corresponding project, and the generated document has no citation links. Cause: Dynamic variables are not correctly bound to knowledge base search parameters, or the project number passed by the variable does not match fields in knowledge base documents.

## How to Verify Successful Configuration
- Upload an engineering document that includes a specific project number, draft a document for the corresponding section, and check if the generated content includes the professional parameters from that document.
- View the citation traceability panel, and confirm that the displayed document fields include project number, construction location, and other exclusive information that matches the current project.
- Adjust the value range of the similarity threshold, observe changes in the number of recalled documents, and verify that the configuration takes effect.
- Disable the general knowledge recall switch, and confirm that the generated document only cites uploaded building construction project documents, with no unrelated content.

The values provided here are common starting points, and should be evaluated against the reader’s own samples.
