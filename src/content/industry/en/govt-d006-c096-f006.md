# Document and Material Drafting for Non-Ferrous Metal Smelting: Citation Source and Traceability

## What the data for this category looks like
Data sources for non-ferrous metal smelting primarily include production central control systems, online quality inspection reports, monthly production ledgers, and industry process standard documents. Real-time central control data updates alongside production processes. Offline ledgers and inspection reports are archived per production batch or daily. Industry standard documents receive static updates.

Document structure includes two categories: structured tables and unstructured reports. Structured fields cover metal grade, output, process temperature, pressure, and more, with units mostly percentage, ton, degrees Celsius, and megapascals. Unstructured documents include process descriptions and compliance files, with fixed document numbers, creation times, and responsible team identifiers.

## Constraints on Citation Source and Traceability
The high-frequency updates of real-time central control data require matching the latest production batch identifiers during traceability to avoid citing outdated data. Structured field units bind to their values. Retain original units during traceability, or deviations in process parameter meaning will occur. Multi-source data cross-validation requires clear marking of data source types in citation traceability to support subsequent compliance reviews. Long documents need sufficient context for full citation. Truncating key process parameter descriptions reduces document accuracy.

## How to Set Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the typical length of a single smelting quality inspection report or production ledger, avoiding truncation of critical traceability information |
| `responseData` | Enabled | Returns original cited data for compliance traceability, aligning with archiving requirements for non-ferrous metal smelting documents |
| `detail` | Enabled | Retains full context of cited content, making it easier to verify original process parameter wording and batch information |
| Single recall limit | Top 6 entries | Covers all required production data sets for a single smelting document, avoiding missing key traceability points |
| Knowledge base sync frequency | Real-time incremental sync (central control data), daily full sync (ledger reports) | Aligns with update rhythms of different data sources, ensuring timeliness of cited data |

This configuration is based on FastGPT v4.17.0.

## Three Common Mistakes
- Phenomenon: The response does not include knowledge base-associated smelting data, only displaying a correct citation list. Cause: The content integration configuration for `responseData` is not enabled, so only citation metadata is returned without inserting original content into the response body.
- Phenomenon: Unit information for metal grade is missing in citation traceability fields. Cause: Structured data field mapping rules are not configured, and original units are not retained, leading to incomplete process parameter meaning.
- Phenomenon: Key flash smelting temperature range is truncated in cited content. Cause: The value of `quoteMaxToken` is too small, causing complete process parameter descriptions to be truncated and reducing document accuracy.

## How to Verify Correct Configuration
- Upload a real non-ferrous metal smelting quality inspection report, initiate a query with specific metal grade requirements, and confirm the response body includes the original data and units from the report.
- Review the response’s citation traceability module, confirm each citation includes document creation time, data source type, and corresponding field identifier.
- Adjust `quoteMaxToken` to different values, confirm long document citations remain complete and untruncated.
- Call an external API to initiate a query, confirm returned results include the configured `responseData` field and complete citation context.

The values provided are common starting points and should be measured against the reader's own samples.
