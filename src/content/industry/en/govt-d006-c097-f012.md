# Document and Material Drafting for Nuclear Power Operations: Deployment and Upgrade

## What data falls under this category
The data used for document and material drafting in nuclear power operations primarily comes from on-site operation logs, safety review reports, equipment operation and maintenance procedures, and emergency response records. Data updates are triggered by production milestones. New documents are generated after individual jobs are completed and after monthly safety reviews. Most documents have a fixed structure, including approval signature sections, core parameter sections, and standardized operating steps. Fields cover reactor core temperature, operating duration, radiation dose, and other relevant metrics. Units mostly follow professional metrology standards such as megapascals, hours, and millisieverts.

## What constraints these characteristics impose during deployment and upgrade
The fixed structure and specialized field requirements for nuclear power operation documents require deployment to prioritize structured storage logic. Unstructured parsing must be avoided to prevent loss of core fields. Frequently updated production node data requires upgrade processes to ensure continuous data synchronization. Interruptions must be avoided to prevent disruption to on-site document generation. Consistent professional unit requirements require standardized unit mapping rules to be configured during deployment. Unit mixing in subsequently generated documents must be prevented. Large volumes of historical document libraries require sufficient storage space and data migration buffer time to be reserved during upgrades. Migration failures leading to data loss must be avoided.

## Three common mistakes
- Symptom: Custom plugin cannot be found in the background after installation. Cause: The plugin package was not placed in the FastGPT-specified plugin directory, or the service was not restarted to load the new plugin.
- Symptom: Pages embedded via iframe display a blank screen, but direct access to the address works normally. Cause: The `FE_DOMAIN` configuration does not include the embedded page's domain name, or the cross-domain access whitelist was not configured.
- Symptom: After upgrading to FastGPT v4.17.0, the audio transcription function throws an error for POST /v1/audio/transcriptions HTTP. Cause: The audio processing dependency package was not updated synchronously during the upgrade, or the transcription service address in the configuration file was not adapted to the new version's parameters.
