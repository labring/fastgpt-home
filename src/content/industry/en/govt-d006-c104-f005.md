# Document and Material Drafting for Coal Chemical Industry: Tool Calling and Plugins

## What the data for this category looks like
Coal chemical industry data sources mainly include plant DCS system logs, monthly production reports, environmental compliance filing documents, project feasibility study reports, and material ledgers. Update frequencies fall into three categories: process parameters updated in real time, production ledgers updated daily, and compliance filing documents updated quarterly. Document structures include structured process parameter tables (fields include reactor temperature, feed rate, units are ℃, m³/h), safety inspection checklists, contract texts, material application forms, and some documents include fixed-format approval process fields.

## What constraints these characteristics impose on tool calling and plugins
Coal chemical production data includes real-time process parameters, fixed-format compliance documents, and multi-type business ledgers, which impose multiple constraints on tool calling and plugins. The short update cycle of real-time process data requires tools to support high-frequency data pulling, to avoid parameter deviations in document generation caused by timeouts or delays. The widespread use of professional units such as MPa, t/h, and ℃ requires plugins to have built-in unit mapping rules for the coal chemical industry, to avoid parameter matching errors. Mixed input of multi-type documents requires tools to support unified parsing of structured ledgers, semi-structured compliance documents, and unstructured reports, adapting to different field extraction logics. Fixed-format compliance filing documents require plugins to preset extraction templates for corresponding fields, reducing manual configuration costs.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Tool Calling Mode | `functionCall` | Requires precise calling of coal chemical industry-specific plugins, to avoid parameter confusion caused by general calling |
| Timeout Period | 300-600 seconds | Pulling coal chemical data involves multi-source ledgers and real-time process data, so sufficient network and parsing time must be reserved |
| Plugin Data Source Scope | Only DCS logs, production reports, and compliance documents | Filter out irrelevant data sources to avoid non-coal chemical data interfering with document generation |
| Result Return Limit | Top 10 entries | Coal chemical documents usually only require the latest core production and compliance data; excessive results will increase context load |
| Unit Conversion Switch | Enabled | Coal chemical documents contain a large number of professional units; enabling this switch can automatically unify unit formats, improving field matching accuracy |
| Document Parsing Priority | Structured documents first | Most production ledgers and compliance documents in the coal chemical industry are in structured format; prioritizing parsing can improve extraction efficiency |

The above configurations are based on FastGPT v4.17.0.

## Three common mistakes
- Phenomenon: A 504 timeout error occurs when calling a coal chemical industry-specific plugin. Cause: The timeout period has not been adjusted for the data pulling requirements of multi-source coal chemical data, and the default timeout duration is insufficient to complete the parsing and integration of multiple ledgers.
- Phenomenon: Plugin calling cannot be triggered after the MCP function is connected in the workflow. Cause: The tool calling mode has not been correctly set to `functionCall`, or the plugin has not been bound to the corresponding workflow node.
- Phenomenon: An invalid workflow ID prompt appears during calling, and plugin calling cannot be completed. Cause: The workflow ID has not been correctly copied from the FastGPT workflow management interface, or extra characters such as spaces and punctuation have been mixed in during pasting.

## How to confirm the configuration is correct
- Manually trigger a tool call, check whether the returned parameters include coal chemical industry-specific fields such as reactor temperature and feed rate, and verify that the units meet expectations.
- View the workflow logs, confirm that the timeout period of the plugin call matches the configured setting, and there are no timeout errors.
- Check the plugin data source filtering rules, confirm that only coal chemical-related document types are allowed to be called.
- Verify that the workflow ID is pasted in the correct location with no extra characters, ensuring that the call points to the correct workflow node.
