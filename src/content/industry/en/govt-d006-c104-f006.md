# Document and Material Drafting for Coal Chemical Industry: Citation Source and Traceability

## What Data for This Category Looks Like
Data related to coal chemical industry document and material drafting primarily comes from internal documents including project feasibility study reports, process operation specifications, safety and environmental protection logs, material balance reports, and product quality inspection reports. Update frequency varies by document type:
- Process specifications update every 6 months alongside technical retrofits
- Safety logs update weekly
- Material balance reports update daily per production shift

Most documents use a chaptered structure with structured fields: material name, batch number, test values, and units (tons, cubic meters, ppm, etc.). Some long documents exceed tens of thousands of characters.

## Constraints on Citation and Traceability
The long text and structured field characteristics of coal chemical industry documents create three core constraints for citation and traceability:
1. Long documents need sufficient token space to hold full citation content. An overly small token limit truncates core professional data.
2. Structured fields such as batch numbers and test values require precise traceability. Effective traceability cannot rely solely on document titles.
3. Frequently updated log data needs matching refresh cycles. Delayed refreshes make cited content inconsistent with current production data.

Additionally, coal chemical documents contain many specialized terms. Retrieved content must align closely with the target professional scenario.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 8000–12000 token | Core single documents in the coal chemical industry have relatively long average lengths, requiring space to accommodate complete professional citation content and avoid data truncation |
| `responseData` | Enable metadata return mode | Coal chemical industry documents require traceability of structured fields such as specific material batches and test values, and metadata can directly associate with corresponding content |
| `detail` | Enabled | Detailed parameters of coal chemical professional documents need to be fully displayed; enabling this mode loads complete document metadata for traceability |
| Single retrieval limit | Top 8–12 entries | Professional information in the coal chemical industry is scattered across different chapters. Sufficient retrieval volume covers core production data and compliance requirements |
| Knowledge base refresh cycle | Follow technical retrofit nodes + full refresh weekly | Matches the update rhythm of coal chemical industry process retrofits and production logs, ensuring cited content aligns with current production status |

## Three Common Misconfigurations
1. After setting `quoteMaxToken` above 2000, the large language model does not cite any retrieved content. Root cause: The system prompt’s format constraints for long-token citations were not updated synchronously. The large language model cannot correctly parse or display citation sources.
2. After associating the knowledge base, correct retrieved entries do not appear in the answer’s citation list. Root cause: The `detail` parameter was not enabled. The document’s structured metadata was not loaded, so the large language model cannot match or associate specific traceability information.
3. After calling the FastGPT private knowledge base API, the returned response has no citation source field. Root cause: The `responseData` parameter was not configured to enable metadata return mode. Traceability information was not encapsulated in the interface response.

## How to Confirm Proper Configuration
- Upload a coal chemical industry process specification document, initiate a query for "material balance data for the synthesis section in this document", and check whether the answer includes specific metadata such as material name and batch number.
- Adjust `quoteMaxToken` to 10000 token, initiate a long-text query, and confirm the cited content in the answer has the expected length with no truncation.
- Call the FastGPT v4.17.0 API interface, and verify the returned `responseData` field includes document source, update time, and other metadata.
- Manually trigger a full knowledge base refresh, initiate a query for "recent safety log data from XX workshop", and confirm newly uploaded log content is correctly retrieved and cited.
