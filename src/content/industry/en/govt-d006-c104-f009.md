# Document and Material Drafting for Coal Chemical Industry: Model Access and Configuration

## What the data for this category looks like
Reference only; verify against the target FastGPT release and deployment documentation.

## What constraints these characteristics impose on the "model access and configuration" link
Coal chemical industry documents contain a large number of industrial professional terms and fixed-format parameter fields. This requires selecting models adapted to the industrial field when accessing models, to avoid misparsing of professional terms by general-purpose models. The phased update feature of documents requires the knowledge base synchronization cycle to match the project progress, to avoid using outdated data. The long document and multi-field structure requires reserving sufficient space for model context and reference fragment configuration, to ensure complete reading of process parameters and approval information. The rigor of safety-related documents requires limiting the model's random generation tendency, to avoid non-compliant content.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | Fill in the proxy address bound to the coal chemical project team | Ensure exclusive call chains to avoid cross-project permission conflicts |
| `AIPROXY_API_TOKEN` | Fill in the exclusive token assigned by the team | Restrict model call permissions to authorized personnel only |
| `temperature` | 0.2–0.4 | Coal chemical documents require strict matching of process parameters and specifications; lower temperature reduces random generation deviations |
| `maxContext` | 8000–12000 token | Adapt to the context reading requirements of long texts such as feasibility study reports and safety reports |
| `quoteMaxToken` | 2000–3000 characters | Ensure that complete fragments of retrieved equipment parameters, approval documents, etc. are passed to the model |
| `maxTokens` | 1500–2000 token | Meet the standard output length requirements for a single coal chemical industry document |

## Three common mistakes
- After adding `AIPROXY_API_TOKEN`, the call returns 404 page not found. The cause is incorrect proxy address configuration, which does not match the exclusive endpoint bound to the token.
- Relevant process parameter documents are indexed, but the model does not reference the content. The cause is that the `quoteMaxToken` value is too small, causing the retrieved document fragments to be truncated and unrecognizable by the model.
- Team members cannot view model usage records. The cause is that the team permission audit configuration is not enabled, or the corresponding viewing role is not assigned.

## How to confirm the configuration is complete
- Call the FastGPT test interface, pass in a prompt containing coal chemical process parameters, and check whether the returned result contains matching document fragments.
- View the proxy call logs, confirm that the requests for `AIPROXY_API_ENDPOINT` and `AIPROXY_API_TOKEN` return a 200 status code, with no 404 errors.
- Adjust the `temperature` parameter, compare document rigor under different values, and confirm that the output complies with the specification requirements of coal chemical documents.
- Check the coal chemical documents in the knowledge base index, confirm that the retrieval results are consistent with the referenced content in the model output.
