# Document and Material Drafting for Coal Transportation and Sales: Tool Calling and Plugins

## What This Category of Data Looks Like
Coal transportation and sales business data mainly comes from transportation and sales scheduling systems, contract management ledgers, railway shipping vouchers, and port loading and unloading records. Data is updated per shipment batch or daily. Core fields linked to a single document include contract number, coal variety, received base low calorific value, total moisture, shipped tonnage, port arrival time, consignee’s unified social credit code, and settlement unit price. Common units are industry standard ones such as tons, kcal/kg, and yuan/ton. The content of a single document typically ranges from 800 to 2000 characters. ## What Constraints These Characteristics Impose on Tool Calling and Plugins
Professional fields and unit requirements for coal transportation and sales mean tool calling must precisely match industry standard formats to avoid parameter parsing errors. Batch-updated data requires plugins to pull the latest shipment, contract, and settlement ledgers on a scheduled basis. Static cached data cannot be relied on for this use case. Document generation requirements that connect multiple data sources require tool calling to support pulling data across contract, shipping, and settlement systems. A single tool call must integrate multiple types of fields. Additionally, the character limit for single documents requires plugin context length to fit the 800 to 2000 character input and output range.

## How to Set the Configurations
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | Automatically matches the multi-tool calling scenarios required for coal transportation and sales documents, no manual tool specification needed |
| Plugin data source refresh interval | `Every 6 hours` | Matches the update rhythm of coal transportation and sales shipment data to ensure data timeliness |
| Tool calling timeout period | `120-180 seconds` | Reserve sufficient response time for pulling transportation and sales data across multiple systems to avoid mid-call interruptions |
| `functionCall` parameter configuration | Enforce field format validation | Professional coal transportation and sales fields must strictly match units and value ranges to prevent generation of incorrect documents |
| Document template field mapping | Calibrate based on actual testing | Transportation and sales template fields vary across enterprises, and must be aligned with the field naming rules of the target enterprise’s internal systems |

## Three Common Errors
- Phenomenon: Tool calling logs show missing or abnormally formatted request body fields. Cause: The `functionCall` parameter is not configured according to the professional field format for coal transportation and sales, causing the request body generated by the tool to fail to meet industry field requirements.
- Phenomenon: Plugins fail to connect to the specified coal transportation and sales knowledge base during calls, returning empty or irrelevant results. Cause: Correct knowledge base connection variables are not configured, and the transportation and sales contract number is not passed as a filter condition to the plugin.
- Phenomenon: Transportation and sales data returned by the plugin is outdated, with shipped tonnage shown in documents inconsistent with actual business data. Cause: The plugin data source refresh interval is set too long, failing to pull the latest shipment and settlement ledger data in a timely manner.

## How to Confirm the Configuration Is Complete
- Manually trigger a tool call, check if the returned transportation and sales data fields include required items such as contract number, received base low calorific value, and shipped tonnage, and whether field units comply with industry standards.
- View plugin operation logs to confirm that the data source refresh interval runs at the preset frequency, and the time difference between the latest data timestamp and the current time matches the business update rhythm.
- Test the validation logic of the `functionCall` parameter by entering a value that does not meet unit requirements, and confirm that the tool returns a format error prompt.
- Call the tool to generate a test document, check if the generated content is connected to the specified transportation and sales knowledge base content, with no redundant or missing fields.
