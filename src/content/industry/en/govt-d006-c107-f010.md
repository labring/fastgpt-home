# Document and Material Drafting for Coal Mining Production: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Coal mining production document data mainly comes from operating procedures, safety ledgers, hidden danger inspection records, equipment operation and maintenance logs, shift handover records, and other sources. Daily operation records are updated daily. Procedure documents are revised on a quarterly or annual basis.
Document structures fall into two categories: structured clauses and unstructured logs. Structured documents include fields such as chapters, clause numbers, and applicable scenarios. Unstructured logs include fields such as equipment numbers, hidden danger levels, inspection dates, and work teams. Units involve professional measurement identifiers including tons, meters, hours, and MPa.

## What constraints these characteristics impose on the knowledge base retrieval and recall link
Structured procedure documents require precise matching of clause numbers and applicable scenarios to avoid retrieving irrelevant cross-scenario content. Unstructured operation and maintenance logs and inspection records have strong semantic connections, so both keyword and semantic matching must be considered.
Daily updated operation records require regular knowledge base refreshes. Otherwise, retrieved content will lag behind on-site operations. Multi-field document structures require specifying retrieval dimensions to avoid interference from irrelevant fields on retrieval results. Differences in professional measurement units can cause matching deviations, so a unified unit recognition logic must be implemented during retrieval.
FastGPT v4.17.0 has optimized field filtering logic for this type of professional scenario. Configuration rules for this version must be adapted.

## How to Configure the Settings
| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `similarity` | 0.72–0.80 | Coal mining production documents have high compliance requirements. This range filters low-match irrelevant content while retaining sufficient valid retrieval results |
| `limit` | Top 8 entries | Coal mine document drafting often requires combining multiple clauses and multi-scenario records. A retrieval volume of 8 entries covers most drafting needs |
| `usingReRank` | Enabled | Coal mine operation and maintenance logs and hidden danger records have strong semantic connections. Reranking improves the sorting priority of highly relevant results |
| `datasetSearchUsingExtensionQuery` | Enabled | The coal mining industry has a large number of exclusive terms. Extended queries cover variants of professional expressions and improve retrieval coverage |
| `collectionIds` | Specify the exclusive collection ID for coal mining production documents | Avoid retrieving documents from other categories, narrowing the retrieval scope to the target dataset |

## Three Common Misconfigurations
- Phenomenon: GPU video memory remains high after knowledge base retrieval completes, and the reranking model does not automatically release resources. Cause: The relevant hook for automatically unloading the reranking model after retrieval is not configured in FastGPT v4.17.0.
- Phenomenon: An Invalid array length error occurs when configuring question answering splitting. Cause: The length of split text blocks exceeds the system preset array boundary, or unclosed format symbols are present.
- Phenomenon: A large number of non-coal mining production document contents appear in retrieval results. Cause: The exclusive coal mining production document dataset collection is not specified via `collectionIds`, causing the retrieval scope to cover documents from other categories.

## How to Confirm the Configuration Is Successful
- Upload a test coal mine hidden danger inspection record, perform retrieval, and check the source collection of returned results to confirm only the specified coal mining production document data is included.
- Check the GPU monitoring panel to confirm the reranking model’s video memory usage returns to the baseline level after retrieval completes.
- Enter coal mining exclusive terms, such as "fully mechanized mining face withdrawal procedure", and check if the matching degree of retrieval results conforms to the preset `similarity` range.
- Test the question answering splitting function, input a piece of coal mine operation log text that exceeds conventional length, and confirm no Invalid array length error occurs.
