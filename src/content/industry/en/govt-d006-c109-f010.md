# Document and Material Drafting for Power Grid Enterprises: Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
Power grid enterprise document and material drafting data primarily comes from internal safety regulations, operation guides, operation and maintenance manuals, bidding documents, and compliance documents. Data updates are triggered quarterly or annually alongside industry standard revisions, annual compliance reviews, and new business launches. Individual documents typically include structured fields such as chapter numbers, clause descriptions, applicable voltage levels, and operation workflow steps. Some on-site operation records are unstructured text, with units including kilovolt, hour, kilometer, and other power industry-specific measurement identifiers.

## What Constraints Do These Characteristics Impose on the Knowledge Base Retrieval and Recall Process
The structured fields and specialized measurement units of power grid enterprise documents require retrieval to match clause-specific details such as applicable voltage levels and operation areas, to avoid retrieving irrelevant content. A notable share of on-site operation records are unstructured, so both keyword retrieval and semantic matching must be supported. Data updated on a quarterly or annual basis does not require frequent knowledge base synchronization, so scheduled incremental update tasks can be configured. The presence of specialized units requires the retrieval logic to identify and associate power industry measurement terms, improving retrieval accuracy.

## Configuration Settings
This guide is compatible with FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | Power grid documents have high compliance requirements. This range filters low-similarity irrelevant content, balancing retrieval coverage and accuracy |
| `limit` | `Top 8 results` | Individual power grid documents are typically lengthy. 8 retrieval results can cover core clauses, avoiding context overflow |
| `searchMode` | `semantic+keyword` | Supports keyword matching for structured fields and semantic retrieval for unstructured content, adapting to the mixed structure of power grid documents |
| `usingReRank` | `Enabled` | Power grid document clauses have strong relevance. Re-ranking can further filter retrieval results that are semantically close but irrelevant |
| `datasetSearchUsingExtensionQuery` | `Enabled` | There are many specialized terms in the power grid industry. Extended queries can supplement synonym matching, improving retrieval performance for specialized terms |
| `collectionIds` | `Specify the collection IDs of power grid compliance documents and operation guides` | Limit the retrieval scope to avoid retrieving irrelevant non-document internal enterprise data |

## Three Common Configuration Errors
- Issue: A `Validation failed: name: Path `name` is required.` error is returned when generating a knowledge base using web static links. Cause: The required document name field was not configured for the power grid document collection, or the basic identification name was not filled in when uploading documents.
- Issue: An error occurs when viewing knowledge base citations in chat responses, with empty citations or abnormal status codes returned. Cause: The retrieval scope was not limited to power grid-exclusive document collections, or the `similarity` threshold was set too low, leading to invalid retrievals.
- Issue: Internal power grid document data stored on Feishu cannot be retrieved, or irrelevant citation content is forcibly displayed in responses. Cause: The Feishu knowledge base was not added to the retrieval scope of `collectionIds`, or the unnecessary cross-source retrieval switch was not disabled.

## How to Verify Correct Configuration
- Upload a power grid operation and maintenance guide document, and check that the knowledge base collection fields include required items such as document name and applicable voltage level.
- Initiate a retrieval test, input "10kV line operation and maintenance regulations", and verify that the `similarity` scores of retrieval results fall within the preset range.
- View the citation sources of retrieval results, and confirm that only content from power grid-exclusive document collections is displayed, with no irrelevant data included.
- Turn off the citation display switch, initiate a retrieval, and confirm that no knowledge base citation content is displayed in the response.

The values provided are common starting points and should be measured against the reader's own samples.
