# Document and Material Drafting for Metal Material Processing: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Data related to document and material drafting for metal material processing comes from internally archived process specifications, inspection records, technical disclosure documents, and publicly available metal processing industry standard documents. Update frequency aligns with enterprise production process adjustments. Industry standards are revised regularly. Documents fall into two categories: operation guides and technical manuals. Operation guides include equipment parameters and operation steps. Technical manuals include material grade classification and mechanical performance indicators. Fields include material grades, processing temperatures, mechanical performance parameters, and attached units of measurement.

## Constraints on Knowledge Base Retrieval and Recall
Metal material processing documents contain many process parameters with precise units of measurement and professional terminology. Ensure retrieved chunks retain the association between parameters and context during retrieval. Avoid separating parameters and their units. For long-text technical manuals, control chunk length reasonably. Prevent loss of complete process logic across chunks. Internally archived documents have custom fields such as exclusive material grades and batch numbers. Support filtering the recall scope by these fields during retrieval. Some documents include process drawings and tables. Link retrieval results to text descriptions of corresponding visual resources to ensure complete content. Enterprise internal documents update frequently with process adjustments. Support incremental knowledge base updates for rapid synchronization.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Matches professional terminology and parameter precision for metal material processing documents, avoiding irrelevant content in retrieval results |
| `limit` | Top 6–8 results | Covers process parameters and standards required for drafting a single document, preventing excessive results from interfering with context |
| `searchMode` | Exact match priority | Adapts to documents with precise parameters. Prioritize recalling content containing specified grades or parameters |
| `usingReRank` | Enabled | Re-ranks retrieval results by relevance. Optimizes sorting for professional terminology and parameter matches |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands professional term queries. Supplements industry synonyms and parameter expressions |
| `collectionIds` | Bind corresponding steel and non-ferrous knowledge base collections | Limits retrieval scope to metal material processing exclusive documents. Avoids mixing data from other categories |

## Three Common Mistakes
- Phenomenon: Retrieval results only return text fragments from Feishu knowledge base documents. No associated process drawing images are included. Cause: No knowledge base image extraction and recall rules are configured. Image OCR text is not included in the retrieval index.
- Phenomenon: Professional terminology matching in retrieval results is inaccurate. It is impossible to distinguish grade parameters of similar metal materials. Cause: The `datasetSearchUsingExtensionQuery` configuration is not enabled. Industry term library associated content is not linked. Only basic keyword matching is used.
- Phenomenon: After uploading metal material process specification documents, retrieval results do not return corresponding content. Responses deviate from the knowledge base scope. Cause: The `similarity` threshold is set too high. Eligible documents are not retrieved, or the knowledge base synchronization task has not completed index updates.

## How to Confirm Proper Configuration
- Upload a metal material operation guide document. Run a retrieval query containing process parameters. Verify that recall results include specified content from the document.
- View knowledge base synchronization logs. Confirm Confluence or Feishu documents have completed index updates. Check for no synchronization failure records.
- Adjust the `similarity` parameter value range. Verify that the number and relevance of recall results meet expectations.
- Enable the `usingReRank` configuration. Confirm that content related to professional parameters ranks first in re-ranked results.

The values provided are common starting points and should be measured against the reader's own samples.
