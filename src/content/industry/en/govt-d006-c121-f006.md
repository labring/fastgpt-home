# Document and Material Drafting for Expressway Operations: Citation Source and Traceability
Reference only; verify against the target FastGPT release and deployment documentation.

## What this category of data looks like
Expressway operation document data mainly comes from toll system logs, road patrol ledgers, maintenance work records, and emergency response archives. Data update frequencies cover real-time, daily, monthly, and other cycles. Each document typically includes fixed fields such as event number, occurrence time, road section pile number, responsible entity, and process node. Units include kilometers, yuan, hours, vehicle trips, and more. Some ledger documents include on-site photos or test data attachments.

## Constraints for citation source and traceability
The multi-source heterogeneous data characteristics of expressway operations require the citation traceability process to support multi-data source association matching, to avoid mixing documents from different business lines. Data sources with different update frequencies require distinct recall weight configurations. Real-time toll data must match the latest entries first, while monthly ledger documents must retain historical traceability capabilities. Documents contain precise fields such as pile numbers and vehicle trips, so retrieval must lock corresponding fields for matching to ensure traceability results fully align with the original text. Some documents with attachments must support traceability jumps linked to original attachments.

## Configuration settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1500–2000 token | Expressway operation documents usually contain long paragraphs of disposal processes and data records, so sufficient tokens must be reserved to store complete traceability content |
| Single search limit | Top 6 entries | Covers the number of data sources from multiple business lines including toll, road patrol, and maintenance, to avoid missing key traceability entries |
| `responseData` | Enable field traceability | Match precise fields such as pile numbers and vehicle trips in documents to ensure traceability results fully align with the original text |
| `detail` | Enable full traceability | Display event numbers and responsible entities in documents to meet compliance traceability requirements |
| Context window | 3000–4000 characters | Carry multi-source data association matching, to avoid truncating key traceability information |

## Three common mistakes
- Configuration errors are prompted during testing, but citation generation functions normally in formal operation. The reason is that the verification logic of some configuration items differs from actual operation logic, and the multi-field characteristics of expressway operation documents are not matched.
- Retrieval results only return a single document, and cannot associate traceability data from multiple business lines. The reason is that the single search limit is configured too low, which does not cover the recall needs of multiple data sources.
- The knowledge base selection is empty, and preset expressway operation document libraries cannot be imported directly. The reason is that corresponding documents are not classified under the Transportation - Expressway Operations tag in advance, so the system cannot automatically identify the target knowledge base.

## How to confirm proper configuration
- Initiate a test query containing road section pile numbers and vehicle trips, and verify whether the returned citation content includes complete traceability information for the corresponding fields.
- View the citation source list to confirm whether it covers document entries from multiple business lines including toll, road patrol, and maintenance.
- Test a query request involving attachment association, and confirm whether the traceability result includes a jump entry for the original document.
- After adjusting configuration items, check whether the number of recalled documents meets the preset search limit requirements through system logs.
