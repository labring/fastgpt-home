# "Efficiently Complete One Matter" Joint Handling: Application Material and Case File Review – Citation Sources and Traceability

## What Data for This Category Looks Like
Typical entities for this category include government service management departments, lead industry departments, data administration bureaus, and window comprehensive acceptance staff. Daily processed documents include joint handling item lists, one-time notice sheets, joint handling application forms, material transfer sheets, parallel approval opinions, and completion receipts. Data sources are the "One Matter" special zone of the National Government Service Platform, local integrated government service platforms, electronic certificate repositories, and departmental approval systems. The update frequency is once per day. Data fields include associated departments for matters, material submission status, approval progress, and other relevant items, and adaptation is required for non-uniform formats across multiple types of government documents.

## What Constraints These Characteristics Impose on the "Citation Sources and Traceability" Link
Cross-departmental data from multiple sources requires the traceability link to establish unified item ID association rules, to avoid mixing materials from different systems. Daily updated data sources require regular synchronization of the latest data, otherwise approval status lag issues will occur. Non-uniform formats across multiple types of government documents require the traceability function to adapt to field extraction logic for different documents, and cannot rely on a single chunking rule. At the same time, errors in this category directly affect service experience, so the accuracy of traceability must strictly match the pre- and post-relationships of joint handling items, to avoid repeated submissions or item stalls caused by incorrect material traceability.

## How to Configure Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Range | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Adapts to the length requirements of joint handling multi-document splicing, avoids truncating key approval opinions or material content |
| `responseData` | Return only joint handling item associated fields | Filters redundant data unrelated to joint handling, narrows the traceability scope, and improves query efficiency |
| `detail` | Enabled | Displays details such as the handler and transfer time of material transfer sheets, which meets the archiving requirements of case file review |
| Traceability data refresh frequency | 2:00 AM daily | Matches the daily update rhythm of business data, ensuring the timeliness of traceability data |
| Single recall citation count | Top 6 | Covers multi-department materials required for joint handling, avoids information overload that affects window staff judgment |

## Three Common Misconfigurations
- When viewing knowledge base citations in chat responses, an error occurs, the interface pops up a "Failed to load traceability data" dialog, and the log returns missing fields. The cause is that `responseData` is not configured to filter non-joint handling fields, resulting in incompatible field formats being returned when calling cross-departmental system interfaces.
- When answering questions, knowledge base search citation content appears, and irrelevant approval records are attached at the end of the answer. The cause is that the recall scope is not limited to the data source associated with the joint handling item list, resulting in the recall of materials from other individual approvals.
- After using a workflow tool to call, the input and response citations from the knowledge base search cannot be hidden. The cause is that the controlled display logic of `detail` is not enabled, and internal parameters of tool calls are mistakenly included in the traceability content.

## How to Confirm Proper Configuration
- Upload a joint handling application form and its corresponding material transfer sheet, trigger a question-and-answer session for this item, and check whether the traceability module only displays department approval data associated with this joint handling item.
- Check the value of the configuration item `quoteMaxToken`, manually splice 3 joint handling documents, and test whether key content is not truncated in the traceability content after the question-and-answer session.
- After triggering the question-and-answer session, check the traceability information to confirm whether details such as the handler and transfer time are included, corresponding to the enabled state of `detail`.
- Wait until 2:00 AM the next day to trigger data refresh, query the status of the joint handling item again, and confirm that the traceability data has been updated to the latest progress of the day.
