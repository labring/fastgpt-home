# "Complete One Task Efficiently" Joint Handling Declaration Materials and File Review: Document Parsing and Chunking

## What data for this use case looks like
Data sources include the national government service platform’s "One Task" special zone, local integrated government service platforms, electronic certificate repositories, and departmental approval systems. Updates occur daily. Commonly processed documents include joint handling task lists, one-time notification sheets, joint handling application forms, material circulation sheets, parallel approval opinions, and completion receipts. Most document structures include cross-departmental task association fields, approval process nodes, and material reuse requirements. No unified fixed format exists across documents. Some documents embed electronic certificate attachments and formula-based approval instructions.

## Constraints on document parsing and chunking
Since data sources cover multiple government platforms and formats are inconsistent, document parsing must support multiple formats including government PDF files, circulation sheet tables, and electronic certificate attachments. Daily updated batch materials require parsing tools with stable batch processing capabilities. Cross-departmental task association fields and process nodes require chunking to retain title hierarchy and paragraph association relationships. This avoids splitting cross-departmental pre- and post- logic. Some documents embed formula-based approval instructions. Parsing processes must ensure formula structures and corresponding approval requirements are not lost.

## How to configure settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `customPdfParse` | Enabled | Adapts to common tables, electronic certificate attachments, and embedded formulas in government documents, with higher accuracy than general parsing |
| `PARSE_FILE_TIMEOUT_SECONDS` | 120–180 seconds | Parsing joint handling materials and batch circulation sheets takes longer. This range covers most scenarios |
| `chunkSize` | 800–1200 characters | Balances complete cross-departmental task logic and retrieval accuracy after chunking, avoids overly long or short individual chunks |
| `chunkSplitter` | Split by title + paragraph | Matches the structured layout of joint handling documents such as task lists, approval opinions, and circulation sheets |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | Meets upload requirements for batch electronic certificates and circulation sheets, aligns with file storage specifications of government platforms |
| `chunkSettingMode` | Manual configuration | Adjusts chunking rules for the special structure of joint handling documents, no reliance on default general configurations |

## Three common misconfigurations
- Phenomenon: Calling `customPdfParse` fails to launch the file parsing tool, returning an error that the tool was not found or timed out. Cause: The port and environment variables for the Marker parsing service were not configured in FastGPT v4.17.0, causing the service to fail to start normally.
- Phenomenon: Approval formulas in joint handling application forms cannot be parsed normally, returning empty fields or garbled text. Cause: The local FastGPT version does not match the online version, and does not support complex formula formats common in government documents.
- Phenomenon: Cross-departmental association information is lost after chunking of batch material circulation sheets. Cause: `chunkSplitter` is configured to split by fixed characters, and the association relationship between titles and paragraphs is not retained.

## How to confirm configurations are properly set
- Upload a standard joint handling task list PDF, check if parsed chunks retain the hierarchical structure of task titles, preceding departments, material requirements, and other content.
- Call `customPdfParse` to parse an approval opinion document with embedded formulas, confirm that the returned parsing results include complete formula content and corresponding approval instructions.
- Check system operation logs, confirm that `PARSE_FILE_TIMEOUT_SECONDS` does not trigger timeout errors, and batch file parsing processes complete normally.
- Upload a batch material circulation sheet, check if chunks split associated circulation nodes and approval opinions by departmental tasks.

The values provided here are common starting points. They should be evaluated against the user’s own samples.
