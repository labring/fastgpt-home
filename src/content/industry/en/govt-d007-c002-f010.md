# "One Task Handled Efficiently" Joint Handling: Declaration Materials and Case Review — Knowledge Base Retrieval and Recall

## Characteristics of This Category of Data
This category of data originates from the national government service platform’s "One Task" special zone, local integrated government service platforms, electronic certificate repositories, and departmental approval systems. Updates occur daily. Common documents include joint handling item lists, one-time notice sheets, joint handling application forms, material circulation sheets, parallel approval opinions, and completion receipts. Document structures typically include cross-departmental associated item information, material requirements, handling process nodes, and departmental authority division fields. No unified fixed unit exists; specific field units adjust based on the joint handling item type.

## Constraints Imposed on Knowledge Base Retrieval and Recall
Daily updated data sources require the retrieval pipeline to support incremental synchronization. This avoids excessive resource consumption from full index reconstruction. Cross-departmental document structures vary widely. Content parsing for multiple formats and fields must be supported; single-field matching cannot be used. The association logic of joint handling items is hidden in documents. Recall results must cover item lists, material requirements, and process nodes simultaneously. This prevents fragmented retrieval results. Content in electronic certificate repositories has permission levels. Retrieval must match corresponding access permissions to stop unauthorized data access. Material circulation sheets and completion receipts have strong timeliness. Recall results must prioritize recently updated entries.

## Configuration Settings
The following configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Value Range | Rationale |
| --- | --- | --- |
| `similarity` | 0.65–0.85 | Material requirements and process descriptions for joint handling items have high similarity, so low-match irrelevant content must be filtered |
| `limit` | Top 8–12 entries | Joint review needs to reference multiple cross-departmental material requirements and process nodes; sufficient recall volume covers associated information |
| `searchMode` | vector + hybrid | Balances exact keyword matching for item names and material lists with semantic association for cross-departmental logic |
| `usingReRank` | Enabled | Joint handling items have complex association logic; re-ranking prioritizes entries strongly relevant to the review scenario |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands associated department authorities, preconditions, and other query terms based on user review questions, covering implicit joint handling logic |
| `collectionIds` | Configured by joint handling dataset groups | Must separately associate datasets of different types such as joint handling item lists, material forms, and approval opinions, to ensure accurate recall scope |

## Three Common Configuration Errors
- After importing joint handling datasets into the knowledge base, the system stays in the indexing state past the preset timeout threshold. The cause is unstructured documents from multiple department approval systems in joint handling data, with no pre-completed format standardization. This leads to excessively long index parsing time.
- Retrieval returns abnormally high similarity values, such as over 1000. The cause is missing similarity threshold filtering, or use of unadapted embedding model matching rules, causing deviation in semantic vector calculations.
- Relevant content from electronic certificate repositories cannot be retrieved. The cause is failure to specify `collectionIds` to associate the electronic certificate repository’s exclusive dataset, or missing permission mapping rules for the corresponding dataset.

## How to Verify Proper Configuration
- Submit a review question for a joint handling item. Check if returned results include cross-departmental material requirements and process nodes.
- Check if retrieval results sort entries most relevant to the current review scenario first.
- Verify dataset update status. Confirm daily incremental synchronization tasks run normally.
- Test accounts with different permissions. Confirm only joint handling documents within the corresponding permission range are retrievable.

The values provided are common starting points, and should be evaluated against the reader’s own samples.
