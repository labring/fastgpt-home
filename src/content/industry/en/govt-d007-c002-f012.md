# Declarations and File Review for "One Thing Handled Efficiently" Joint Handling: Deployment and Upgrade

## What data for this category looks like
Usually, data sources for this category include the national integrated government service platform "One Thing" special zone, local integrated government service platforms, electronic document repositories, and departmental approval systems. The update frequency is daily. Daily generated documents include joint handling item lists, one-time notification sheets, joint handling application forms, material transfer sheets, parallel approval opinions, completion receipts, and more. Data fields generally include cross-departmental item association relationships, application material reuse rules, parallel processing status tracking fields, approval opinions and receipt information for each link. There is no unified standardized field format, so adaptation to multi-source data structures is required.

## What constraints these characteristics impose on deployment and upgrade
Since data sources are scattered and updated daily, connection parameters for multi-source data synchronization must be configured during deployment to avoid connection timeouts or permission issues. Document formats are diverse and involve government-sensitive information, so a compliant local storage path must be specified, and uploading data to the public internet is prohibited. Cross-departmental material transfer and approval status tracking require cache support, so a stable cache service must be configured. At the same time, adaptation to the government private network environment is required, ensuring all services are deployed on the private network to guarantee data security. Deployment of FastGPT v4.17.0 must strictly follow the access control policies of the government network to avoid cross-network access issues.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `DB_MAX_LINK` | `100–200 connections` | Adapts to concurrent demands of multi-source data synchronization, avoids exhausting database connections |
| `STORAGE_S3_ENDPOINT` | `Government private network local storage endpoint` | Ensures government-sensitive files are not transferred to the public internet, complies with data security requirements |
| `REDIS_URL` | `Local Redis service address, port 6379` | Used to cache parallel processing status and material metadata, improves query efficiency |
| `FILE_TOKEN_KEY` | `Custom 32-bit random secret key` | Encrypts file access tokens, prevents unauthorized access to joint handling materials |
| `MONGODB_URI` | `MongoDB connection address within the government private network` | Stores structured data such as joint handling item lists and approval opinions, ensures data is transferred within the private network |
| `FE_DOMAIN` | `Official domain of the government service portal` | Connects to the government service entry point, ensures user access paths comply with regulations |

## Three common mistakes
- Symptom: Older browsers such as 360 Speed Browser fail to load front-end pages, and compatibility errors appear in the console. Cause: The FastGPT front-end compilation target is not adjusted to be compatible with ES2015 and higher low-version browser standards.
- Symptom: A `permission denied` error occurs during deployment, and the storage directory or database cannot be connected. Cause: The FastGPT process is not granted read and write permissions for the storage directory and database within the government private network.
- Symptom: ollama and FastGPT cannot communicate normally after deployment, returning a connection timeout error. Cause: The ollama service address within the government private network is not configured, and access permissions for the corresponding port are not opened.

## How to confirm the configuration is complete
- Check the database connection logs corresponding to `MONGODB_URI`. No authentication failure or timeout errors are present.
- Upload a joint handling application form. Confirm the file is stored in the specified directory within the government private network, and no public network transfer prompts appear.
- Access `FE_DOMAIN`, and test using older browsers such as 360 Speed Browser. The page loads normally.
- Trigger a daily data synchronization task. Check logs for no records of failed data updates.
