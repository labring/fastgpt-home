# Real Estate Registration Declaration Materials and File Review: Tool Calling and Plugins

## What the data for this category looks like
Data for this category primarily comes from the real estate registration information system, cadastral survey database, housing transaction online signing system, tax system, and electronic certificate repository, and is updated automatically daily. Documents processed daily include registration applications, ownership certificates, survey results, tax payment vouchers, real estate ownership certificates, and real estate registers. Data fields cover ownership subject information, right types, survey area, tax payment records, register numbers, and more. Most formats are structured forms or signed electronic documents.

## Constraints on tool calling and plugins from these data characteristics
Since data originates from multiple heterogeneous systems and updates daily, tool calling must support real-time pulling of the latest ownership, survey, and tax data across systems to avoid using expired information. Daily processed documents have diverse formats, so plugins must adapt to parsing different types of declaration materials including structured forms and signed electronic documents. Errors can lead to registration mistakes or property rights disputes, so tool calling results must undergo multi-layer verification to ensure accurate comparison of core fields such as ownership source and restriction status. Review processes mostly follow serial verification, so tool calling must trigger in sequence according to nodes to prevent data conflicts caused by concurrent operations.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `toolChoice` | Mandatorily set to `function` | Adapts to FastGPT v4.17.0 tool calling logic, ensures preset plugins are triggered strictly, and prevents free-form generation from deviating from review requirements |
| `functionCall` | Trigger single tool call per review node | Adapts to the serial verification process of real estate review, avoids cross-system data conflicts caused by concurrent calls of multiple tools |
| Single call result limit | Top 10 entries | Controls returned data volume, prevents exceeding context limits, and adapts to the structured characteristics of real estate data |
| Plugin timeout | 300 seconds | Adapts to the time required to pull cadastral and tax data across systems, prevents call failures caused by system response delays |
| Result verification switch | Enable field matching verification | Ensures returned ownership and survey data match core fields of declaration materials, and meets review requirements |

## Three Common Configuration Mistakes
- Returning empty results after calling cross-system data plugins. Cause: Cross-system data source permission verification is not configured, or the timeout setting is too short, resulting in failure to pull data from cadastral or tax systems.
- Generating empty charts after calling survey data visualization plugins. Cause: Structured data fields of survey results are not correctly bound, so the plugin cannot obtain valid drawing parameters.
- Returning a 400 status code when calling tools. Cause: Tool calling parameters do not match required fields for real estate review, such as failure to include an ownership number, leading to interface verification failure.

## How to Confirm Configuration is Valid
- Trigger a complete declaration material review process, check tool calling logs to confirm that `toolChoice` and `functionCall` parameters trigger as configured.
- Call the cross-system data plugin, verify that returned ownership data matches archived information in the electronic certificate repository, and adjust verification rules to meet requirements.
- Simulate submission of supplementary materials, check whether the plugin can correctly pull updated tax or survey data, and verify adaptability to real-time updates.
- Check tool calling error logs to confirm there are no parameter verification failures or timeout errors, ensuring configuration takes effect.
