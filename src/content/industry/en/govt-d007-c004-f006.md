# Declaration Materials and File Review for Proactive Public Disclosure and Policy Publication: Citation Sources and Traceability

## What this category of data looks like
This category of data draws from government portals, document management systems, government information disclosure directories, policy document repositories, and press conference materials. It updates daily. Daily documents include policy documents, policy interpretation drafts, public disclosure directories, information release approval forms, press releases, and website column update records. Data fields include document number, release date, public disclosure attribute, secrecy level, associated release column, and more. The structure primarily mixes structured official documents and unstructured web text.

## What constraints these characteristics impose on the citation sources and traceability workflow
The daily update cycle requires the citation traceability function to support incremental synchronization verification, preventing repeated citation of expired or unaudited content. The mixed structure of structured official documents and unstructured web text requires the traceability workflow to associate multi-dimensional identifiers such as document numbers and release URLs simultaneously. Supporting multiple document types to ensure consistent policy positions requires matching the publishing entity and release time during traceability, stopping misreading caused by citing expired policies. The public disclosure attribute and secrecy level fields require the system to automatically filter content that fails to meet proactive public disclosure requirements during traceability, ensuring cited content complies with regulations.

## How to configure the settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the single-piece content length of policy documents and interpretation drafts, ensuring cited content is complete and does not exceed context limits |
| `responseData` | Only return entries associated with public disclosure directories | Meets the traceability requirements of the proactive public disclosure category, only displaying publicly releasable compliant content |
| `detail` | Show full release path and document number | Meets traceability detail requirements during file review, facilitating verification of public disclosure attributes |
| Single search limit | Top 5 entries | Controls the number of returned results to avoid information overload in government public disclosure scenarios |
| Reordering | Sorted by release time in descending order | Prioritizes displaying the latest policy content, aligning with the timeliness requirements of government information updates |

## Three common configuration errors
- The symptom is that the citation result does not include the public disclosure directory link corresponding to the policy document. The cause is that the compliant content filtering switch in the `responseData` configuration is not enabled.
- The symptom is that the returned cited content is irrelevant to the query and does not match the public disclosure attribute. The cause is that the dual filtering logic based on public disclosure attribute and content relevance is not enabled, and only basic recall rules are relied on.
- The symptom is that the document number or secrecy level field is empty during traceability. The cause is that the `detail` parameter is not configured to return structured document fields, and only unstructured web text content is extracted.

## How to verify a correct configuration
- Upload a policy document and its corresponding public disclosure directory entry, initiate a test query, and check whether the returned result is associated with the public disclosure directory link and document number.
- Set `quoteMaxToken` to 800–1200 token, test citing a long-text policy document, and confirm that no content truncation or overflow error occurs.
- Initiate multiple policy-related queries with different release times, confirm that the returned results are sorted by release time in descending order, prioritizing the latest content.
- Check that the FastGPT version is v4.17.0 or higher, and confirm that the {{}} format variable reference function works properly.

The values provided are common starting points and should be measured against the reader's own samples.
