# Declaration Materials and File Review for Property Rights, Assets and State-owned Capital Management: Tool Calling and Plugins

## What data looks like for this category
The data for this category mainly comes from state-owned assets supervision information systems, enterprise asset management systems, property rights exchange systems, evaluation agency reports and financial statements, with a monthly update frequency. Daily processed documents include property rights registration forms, asset evaluation reports, property rights transfer plans, on-site transaction announcements, and asset disposal approval forms. Most document structures include fields such as asset ownership number, book original value, evaluation net value, transaction approval node, and others. The size of individual documents varies widely, and some batch-declared file materials form continuous file groups.

## Constraints imposed on tool calling and plugins
The data sources for this category are scattered and involve multiple internal systems. Tool calling must adapt to the interface formats and authentication rules of different systems. The monthly update frequency requires tool calling tasks to support scheduled triggering and batch scheduling. Mixed processing of multiple document types requires plugins to have parsing capabilities adapted to different document structures. The scale of single-batch batch file review imposes clear constraints on the concurrency limit and timeout threshold of tool calling. Task interruptions caused by overly long single call durations must be avoided.

## How to set configurations
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Timeout setting | 600–1200 seconds | Adapt to the single-batch data processing duration of batch file review, and avoid task failure caused by response delays of state-owned assets system interfaces |
| `toolChoice` | `auto` | Automatically select the tool calling mode to adapt to mixed processing scenarios of multiple types of documents and multiple system interfaces |
| Single call limit | First 8 files | Match the batch processing scale of monthly updates, and avoid exceeding system load due to overly large single call data volume |
| Document parsing plugin configuration | Switch parsing rules by document type | Adapt to field extraction requirements of different documents such as property rights registration forms and asset evaluation reports |
| Result verification switch | Enabled | Used to check the consistency of extracted fields such as asset numbers and ownership certificate numbers with data in the system |
| `functionCall` | Enable mandatory parameter verification | Ensure that fields such as asset ownership and transaction approval passed during tool calling comply with business specifications |

## Three common configuration errors
- Phenomenon: The tool calling task status shows timeout, and the background log returns that the execution duration exceeds 1200 seconds. Cause: The timeout setting was not adjusted according to the processing scale of batch files, and the short timeout configuration for general scenarios was used, resulting in interruption before the state-owned assets system interface completes data retrieval.
- Phenomenon: Extracted fields are empty after plugin calling, and cannot match business verification rules. Cause: Exclusive parsing rules were not configured for different document types such as property rights registration forms and asset evaluation reports, resulting in the plugin being unable to identify specific fields.
- Phenomenon: Authentication failure occurs when calling tools across multiple systems. Cause: Authentication parameters of different data sources were not distinguished, and interface keys of the enterprise asset management system and property rights exchange system were mixed.

## How to confirm the configuration is correct
- Manually trigger a single tool calling task, and verify that the returned fields include business-specific fields such as asset numbers and evaluation net values.
- View the tool calling log to confirm that the duration of each call falls within the preset timeout setting interval.
- Submit batch file data for monthly updates in bulk, and check whether task scheduling follows the preset single call limit.
- Verify that authentication parameters for calling multiple system interfaces match the configuration of the corresponding data sources.

The values provided are common starting points and should be measured against the reader's own samples.
