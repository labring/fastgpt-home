# Declaration Material and File Review for Property Rights, Asset and State-owned Capital Management: Knowledge Base Retrieval and Recall

This document is created for FastGPT v4.17.0. The following content is formulated for the business characteristics of this category.

## What This Category of Data Looks Like
This category of data covers core documents including property rights registration forms, asset evaluation reports, property rights transfer plans, on-site transaction announcements, and asset disposal approval forms. Data sources include state-owned asset supervision information systems, enterprise asset management systems, property rights exchange systems, evaluation agency reports, and financial statements. Data update frequency is monthly. Most documents contain structured fields such as ownership number, original asset value, evaluation value, and approval node, alongside long sections of qualitative descriptive content. Review workflows require associating cross-source data from multiple systems to complete verification.

## Constraints on Knowledge Base Retrieval and Recall
Monthly updated batch data requires retrieval and recall workflows to support regular incremental synchronization. Full re-scanning would consume excessive computing resources.
Cross-source data from multiple systems requires matching retrieval scopes across multiple collections. This ensures coverage of documents from sources such as state-owned asset supervision and property rights transactions. It prevents omission of key verification materials.
Documents combine structured fields and qualitative descriptive content. Retrieval must balance precise matching for specific details like ownership numbers, and semantic matching for content such as evaluation reports.
Review workflows associate multiple documents to verify consistency. Recall results must be sorted reasonably by relevance. This avoids missing associated materials needed for cross-checking.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.72–0.80 | Filters low-relevance asset ownership and evaluation report content. Balances recall precision and coverage, calibrated based on actual testing |
| `limit` | Top 12 results | Covers the number of associated documents needed for a single review material. Prevents context overflow that affects model generation |
| `searchMode` | hybrid | Combines keyword matching and semantic retrieval. Adapts to mixed document types with structured fields and qualitative descriptions |
| `usingReRank` | Enabled | Re-ranks recall results. Prioritizes display of property rights transfer plans and approval forms that match the core requirements of declaration materials |
| `datasetSearchUsingExtensionQuery` | Enabled | Expands retrieval terms based on user queries. Covers business synonyms such as "asset disposal" and "on-site transaction" |
| `collectionIds` | Configured per associated business collection | Limits retrieval scope to exclusive business collections such as state-owned asset supervision, property rights transactions, and evaluation reports. Prevents irrelevant data from interfering with state-owned asset review processes |

## Three Common Misconfigurations
- Phenomenon: The last two relevant documents are missing from recall results. Response content is truncated. Cause: The `limit` parameter is not set correctly. A value that is too low reduces the number of recalled entries. It cannot cover all required associated materials.
- Phenomenon: Retrieval results do not display source information for corresponding documents. Cause: Knowledge base citation display configuration is not enabled. Or the retrieval scope is not bound to the corresponding business collection. This prevents matching of source metadata.
- Phenomenon: Slow response or timeout occurs when calling the retrieval interface. Cause: The index structure is not optimized for monthly batch updated data. Or cross-collection retrieval does not limit the scope. This leads to an overly large retrieval range that exceeds system processing limits.

## How to Verify Correct Configuration
- Upload a test property rights registration form. Submit a query that includes "verify corresponding asset ownership". Check if the test document is included in the recall results.
- View the retrieval result display area. Confirm that each result includes document source and metadata information.
- Switch between different business collections. Verify that the retrieval scope only covers preset exclusive documents such as state-owned asset supervision and property rights transactions.
- Submit batch test queries. Check if recall results are sorted to prioritize matching core review requirements.
