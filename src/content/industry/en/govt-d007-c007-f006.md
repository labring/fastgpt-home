# Petition Case Handling: Declaration Materials and File Review – Citation Source and Traceability

## What this category of data looks like
Data for this category primarily originates from the national petition information system, local petition systems, the 12345 citizen hotline platform, grassroots governance platforms, and historical petition archives. The update frequency is daily.

Daily processed documents include standardized files such as petition registration forms, acceptance notices, transfer and assignment letters, handling opinions, review and re-examination applications, and resolution plans. Fields cover request content, handling progress, responsible units, file numbers, review materials, and more. The length of individual documents varies widely; some handling opinions can reach several thousand characters.

## What constraints do these characteristics place on the citation source and traceability process
Data sources are numerous and dispersed. Citations must accurately match file numbers and document fragments from corresponding systems to avoid cross-system confusion.

Incremental data updated daily must be synchronized to the knowledge base. Failure to do so will result in references to outdated handling opinions.

The fixed fields of standardized documents require citations to be bound to clear file identifiers. Traceability cannot rely solely on vague content.

The wide variation in individual document lengths requires balancing citation length and information integrity. This prevents missing handling basis due to truncated citations, which could lead to repeated petitions or review corrections.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1200–1800 token | Adapts to the chunk length of petition-related documents, balances contextual information and citation accuracy, and avoids truncating key handling basis, based on FastGPT v4.17.0 rules |
| `responseData` | Includes file number, document name, fragment offset | Matches the standard fields of petition files, ensuring traceability information can be directly linked to corresponding entries in the national petition information system |
| `detail` | Enabled | Displays complete cited fragment content to facilitate verification of consistency between handling opinions and original materials |
| Single recall limit | Top 3–5 entries | Controls the number of returned files, avoiding redundant information interfering with the review and judgment of petition matters |
| Similarity threshold | 0.75–0.85 | Accurately matches petition requests with historical files, filtering irrelevant petition records |

## Three common configuration mistakes
- A `quote type error` appears in the interface or logs. This occurs because the passed citation variable does not meet the field format requirements of petition files, and the identifier fields of documents such as petition registration forms and handling opinions are not correctly bound.
- After setting `quoteMaxToken` to 1500 tokens, retrieval results exceeding this length are still returned. This is because the knowledge base chunk length is set to 5000 tokens, which does not match the citation limit, causing individual chunks to directly exceed the restriction.
- No cited file address is displayed in the response. This is because the display configuration corresponding to `responseData` is not enabled, or the storage path of the source document is not bound to the file number of the petition system, making it impossible to generate a valid traceability address.

## How to confirm the configuration is correct
- Submit a test petition request, check whether the returned results include clear file numbers and document fragments, and confirm that the traceability information matches the actual entries in the petition system.
- Adjust the `quoteMaxToken` parameter to different values, verify whether the length of the returned citation fragments conforms to the set threshold range.
- Check whether the response includes directly linkable document source information, confirming that it is consistent with the file address rules of the petition system.
- Input a reference variable with an incorrect format for simulation, verify whether the `quote type error` is triggered, and confirm that the exception handling logic takes effect.

The values provided here are common starting points and should be evaluated against the reader's own samples.
