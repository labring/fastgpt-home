# Declaration Materials and Case Review for Highway Maintenance and Road Property Rights Management: Citation Sources and Traceability

## What this category of data looks like
Data for this category mainly comes from highway maintenance management systems, bridge and tunnel monitoring systems, road administration patrol systems, and traffic flow monitoring data. The update frequency is daily. Daily documents include maintenance plans, patrol logs, disease disposal forms, road construction permits, and road property damage compensation forms. Fields cover patrol time, road section number, disease type, disposal result, permit validity period, and other items. Units include kilometers, square meters, working days, and others.

## What constraints these characteristics impose on citation sources and traceability
Daily updated business data such as patrol logs and disease disposal forms require precise association of citation traceability with original records for specific road sections and times. This avoids invalid matching across business dimensions. Subdivided fields including road section number, disease type, and permit validity period must be bound to specific business attributes. General text matching cannot cover the matching needs of these subdivided fields. Road construction permits and road property damage compensation forms serve as core audit basis. They need complete traceability to timestamps and operation information from the original entry system, to ensure accuracy of compliance checks.

## How to set the configuration
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | Documents in this category are mostly structured business forms, with moderate valid information length per entry. This range covers complete traceability basis while preventing context overflow |
| Single search limit | Top 6 entries | Daily business form volume is concentrated. Excessive search results increase context redundancy. 6 entries cover core traceability materials |
| `responseData` | Return only matching source document metadata | The audit link requires association of metadata such as original document number and time. Traceability verification can be completed without returning full document content |
| Maximum context | 4000–6000 characters | Total length of materials such as maintenance plans and patrol logs involved in a single case is controllable. This range carries complete traceability information required for audit |
| `detail` | Enabled | Specific fields of traceability documents such as road section number and disposal result need to be displayed. This helps auditors quickly check business consistency |

## Three common mistakes
- The symptom is an empty optional knowledge base list during calls. The cause is failure to bind the data source directory for highway maintenance business. The system cannot automatically identify the corresponding knowledge base.
- The symptom is insufficient number of returned citation results. The cause is that `quoteMaxToken` is set too small, or the single search limit configuration is too low. This cannot cover all compliance materials involved in the case.
- The symptom is that traceable documents cannot be downloaded normally. The cause is failure to enable metadata access permission for traceable documents. The system cannot read the original storage path.

## How to confirm the configuration is complete
- Import the knowledge base corresponding to highway maintenance business, then check if the optional knowledge base list includes the target data source.
- Launch a case review test, and verify if the number of returned citation results matches the configured single search limit.
- Click the document link for citation traceability, confirm normal access and readable corresponding metadata.
- Export traceability data related to the audit, and check if the export granularity supports splitting by maintenance road section and business type.
