# Document Submission and File Review for Highway Maintenance and Road Property and Right Management: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Daily documents for this category typically include maintenance plans, patrol logs, defect handling forms, road construction permits, road damage compensation forms, and more. Data is generally sourced from highway maintenance management systems, bridge and tunnel monitoring systems, road patrol management systems, and traffic flow monitoring data. The update frequency is daily. Most documents use structured fields as their primary structure, including facility ID, patrol time, defect type, handling measures, permit number, and other fields. Some unstructured documents have on-site photos or monitoring data attached.

## What constraints these characteristics impose on the knowledge base retrieval and recall workflow
The high-frequency daily data requires the knowledge base to support incremental synchronization mechanisms, to avoid excessive resource consumption from full re-imports. Mixed multi-source heterogeneous data—structured fields and unstructured documents coexisting—requires retrieval logic that supports field matching across different formats. This ensures that defect descriptions in patrol logs can be associated with the scope of road construction permits for recall. A single file often involves multiple related documents, so enough relevant results must be retrieved to avoid missing key evidence. Additionally, there are many domain-specific terms, so retrieval must precisely match requirements for specific scenarios, preventing generalized results from interfering with review and judgment.

## Three Common Mistakes
- Symptom: When creating a knowledge base using the URL of an internal highway maintenance management system, the backend returns the `cannot fetch internal url` error. Cause: The internal network access whitelist is not configured, or the FastGPT deployment environment cannot access the interface of the internal system.
- Symptom: When clicking chunk preview for some PDF-format defect handling forms or road construction permit documents, a prompt appears indicating that file content cannot be read. Cause: The PDF contains encrypted content, non-standard font embedding, or the document parsing plugin does not adapt to the special typesetting of highway maintenance documents.
- Symptom: The number of collections that can be associated with the open-source knowledge base deployed locally is limited to 30, and cannot be expanded. Cause: The collection upper limit parameter in the deployment configuration is not modified, and the default open-source version has a basic quantity limit.

## How to confirm the configuration is complete
- Submit a query related to road construction permits, check whether the recall results include relevant patrol logs, defect handling forms and other associated documents.
- View the knowledge base synchronization logs, confirm that the daily incremental update tasks are running normally, with no failed records.
- Test professional term retrieval, enter "bridge and tunnel defect", confirm that the recall results include relevant data from bridge and tunnel monitoring systems.
- Check the configuration item parameters, confirm that `usingReRank` and `datasetSearchUsingExtensionQuery` are enabled.
