# Declaration Materials and Case File Review for Medical Institution Supervision and Public Health Inspection: Citation Source and Traceability

## What this category of data includes
Data sources for this category are health supervision information systems, medical institution electronic registration systems, complaint reporting platforms, and law enforcement inspection records. The update frequency is monthly. Daily processed documents include supervision inspection forms, medical institution practicing licenses, rectification notices, supervision opinions, and penalty case files. Core fields cover institution qualification numbers, law enforcement personnel information, compliance status of inspection items, rectification requirements, and penalty-related content. The character length of individual documents varies widely.

## What constraints these characteristics impose on citation source and traceability
Multi-source data access requires support for cross-system data associated traceability, to ensure cited case files align one-to-one with original law enforcement records and registration system information. Monthly update frequency requires configuring incremental synchronization mechanisms, to prevent citing expired institution qualification or rectification status. Field differences across multiple document types require traceability logic to adapt to unique fields of each document type. For example, match the qualification number of practicing licenses and inspection item entries on supervision inspection forms separately. The wide variation in individual document lengths requires flexible adjustment of context processing ranges during traceability, to adapt to case file content of different lengths and avoid truncating key compliance evidence.

## How to set the configuration
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `quoteMaxToken` | `800–1200 token` | Adapts to the wide length span of multiple document types including penalty case files and rectification notices, ensuring complete citation of core compliance content |
| Maximum Context | `Top 8–12 search results` | Matches the monthly updated data source scale, avoiding redundant information interfering with traceability accuracy |
| `detail` | Enabled | Required to return specific field information of citation sources, such as institution qualification numbers and law enforcement inspection times, to meet compliance requirements for case file review |
| `responseData` | Return original data link | Ensures traceability can directly jump to original data sources such as health supervision information systems, complying with compliance review traceability requirements |
| Single Search Limit | `Top 5–7 matching results` | Covers associated information across multiple document types processed daily, avoiding omission of key evidence |

## Three common misconfigurations
- The phenomenon is a data source access failure error returned when calling the traceability function. The cause is using workflow variables as file paths in the configuration, instead of directly uploading system-accessible data source links as required.
- The phenomenon is missing key qualification information in traceability results. The cause is not enabling the `detail` parameter, and not configuring complete field information for returning original data.
- The phenomenon is that search results include irrelevant historical case file data. The cause is not setting a reasonable single search limit, and not filtering content from non-current review cycles.

## How to confirm the configuration is correct
- Manually enter the qualification number of a medical institution practicing license, and verify whether the traceability result returns the corresponding system registration information.
- Trigger a traceability request for case file review, and check whether the returned citation sources include directly accessible original data links.
- Adjust the search parameters, and verify whether the number of returned results aligns with the requirement range of the current review scenario.
- View the configuration parameter effective logs, and confirm that parameters such as `quoteMaxToken` and `detail` have been loaded using the set values.

The values provided are common starting points and should be measured against the reader's own samples.
