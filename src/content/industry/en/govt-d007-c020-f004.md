# Declaration Material and File Review for Territorial Spatial Planning Compilation and Implementation Evaluation: Workflow Orchestration

## What This Category of Data Looks Like
Daily documents for this category include territorial spatial master plans, detailed plans, special plans, planning implementation evaluation reports, public opinion summaries, and more. Data sources cover territorial spatial basic information platforms, natural resource survey and monitoring data, population and economic statistics data, and remote sensing imagery. Most data contains fields such as regional spatial boundary coordinates, facility layout points, binding indicators, and approval node numbers. Document structures typically combine structured tables with spatial attachments. Updates follow an annual cycle, with large single data volumes involving multi-format business materials and files. Some documents include vector layer attachments, and field precision requirements are strict.

## Constraints Imposed on Workflow Orchestration by These Characteristics
The volume and format differences of multi-source data require workflows to include staged parsing and aggregation nodes to prevent single-context overload. Annually updated data sources need regular synchronization rules configured to ensure data called by workflows aligns with the latest planning requirements. Complex document structures require workflows to support multi-format parsing components to accommodate mixed input of spatial attachments and text materials. The rigor of file review also requires workflows to include circulation verification nodes to ensure declaration materials are complete and avoid issues such as approval delays. Additionally, this category handles planning content covering entire regions and multi-year constraints, so workflows must support long-cycle node circulation and multi-round data verification to match the business logic of planning compilation.

## Three Common Misconfigurations
- Workflow execution displays the "context length exceeded" prompt. Cause: No context length limit is set, or the single search limit is too high, resulting in loading too many territorial spatial planning documents and remote sensing imagery data.
- Shared links cannot be accessed normally. Cause: The corresponding authentication switch is not enabled in the workflow sharing configuration, or the configured permission rules do not match business department requirements.
- Approval delay markers appear after workflow circulation. Cause: No file material integrity verification node is configured, and public opinion summary documents are omitted.

## How to Confirm Correct Configuration
- Test workflow operation and check if the prompt signature time matches the system's current date.
- Trigger a RAG call and confirm that returned documents come from the bound territorial spatial planning exclusive knowledge base.
- Check the workflow sharing configuration page and confirm that the authentication switch is enabled and matches department permission rules.
- Attempt to export independent nodes bound to MCP tools and confirm that the exported file format meets business archiving requirements.
- View the data source synchronization configuration and confirm that the synchronization cycle matches the annual update rhythm of category data.
