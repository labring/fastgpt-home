# Declaration Material and File Review for Territorial Spatial Planning Compilation and Implementation Evaluation: Citation Source and Traceability

## What the Data for This Category Looks Like
Daily documents for this category include territorial spatial overall plans, detailed plans, special plans, planning implementation evaluation reports, public opinion summaries, and similar materials. Data sources cover territorial spatial basic information platforms, natural resource survey and monitoring data, population and economic statistical data, and remote sensing image materials. The data update frequency is once per year. Most document structures include fields such as spatial coordinates, planning indicators, and departmental opinions. Units involve standard spatial and statistical units such as hectares, ten thousand people, and square kilometers. Typical processing entities include natural resource department planning offices, planning institutes, and local governments. Daily work requires aggregating multi-source spatial data and cross-departmental opinions.

## What Constraints These Characteristics Impose on the "Citation Source and Traceability" Link
Territorial spatial planning data is mostly regional multi-source spatial and statistical data. Citation traceability must accurately match the original source of each planning basis to avoid confusion across data types. The annual update frequency requires regular synchronization of the latest data in the knowledge base. If synchronization does not occur, cited content will lag behind official planning adjustments. Document structures contain a large number of spatial coordinates and professional indicators. Citation traceability must retain field and unit information to ensure data accuracy can be verified during the review process. The aggregation characteristic of multi-source data also requires the traceability link to distinguish identifiers of different data sources. This supports cross-checking during file review. Planning file review requires retaining a complete citation chain. This ensures that each planning decision can be traced back to the original data. The accuracy of the traceability link directly affects the approval progress.

## Three Common Mistakes
- Phenomenon: After calling the API, the returned result has no content field, or the citation source module is empty. Cause: The `responseData` configuration item is not correctly enabled. Only the answer text is returned, without accompanying metadata.
- Phenomenon: Clicking the download link of the citation source fails to access the corresponding file. Cause: The access path of the local knowledge base is not correctly configured, or the nginx proxy does not cover the interface route for original file download.
- Phenomenon: The number of citation traceability results does not meet expectations, either too many or too few. Cause: The single search limit is set unreasonably, failing to match the recall requirements of multi-source data for territorial spatial planning.

## How to Confirm Proper Configuration
- Submit a test request, and check whether the returned result includes the citation metadata corresponding to the `responseData` field. This includes source name, path, and field information.
- Click the download link of the citation source to verify that the corresponding planning document or data file can be accessed normally, with no access errors.
- Adjust the `quoteMaxToken` parameter, observe the truncation of cited content in the response, and confirm that no critical planning indicators are truncated.
- Test queries involving multi-source data, and confirm that the returned citation sources cover different data types such as territorial spatial basic information platforms and remote sensing images.

The values provided are common starting points and should be measured against the reader's own samples.
