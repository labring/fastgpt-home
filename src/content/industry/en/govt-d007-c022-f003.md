# Declaration Material and Case File Review for Land Use Rights, Mining Rights, and State-Owned Property Transactions: Multi-Turn Dialogue and Prompt Words

## What This Category of Data Entails
Typical service entities include natural resource departments, state-owned asset supervision agencies, property right trading institutions, and public resource trading centers. Daily processed documents include transfer announcements, trading guidelines, bid application documents, margin vouchers, transaction confirmation letters, listing result announcements, and property right transfer specifications.
Data sources include the national public resource trading platform, natural resource trading systems, property right exchange systems, and state-owned asset supervision systems. Update frequency is daily.
Documents typically contain fields such as ownership number, trading target type, margin amount, and bid qualification conditions. Units include square meters, ten thousand yuan, and other standard units.

## Constraints on Multi-Turn Dialogue and Prompt Words
Data sources for this category are scattered and updated daily. Multi-turn dialogue must support real-time calls to multi-source knowledge bases, and must avoid using offline cached outdated materials.
Document structures vary, and some materials are lengthy. Dialogue must accurately match associated fields across documents, such as binding bid application documents and margin vouchers for verification.
Fields include key information such as ownership and restriction conditions. Prompt words must explicitly require returning complete fields, without omitting content that affects review.
Review errors have serious consequences. Multi-turn dialogue context memory must accurately associate historical review opinions, and avoid logical conflicts.

## Three Common Misconfigurations
- Phenomenon: A 422 status code is returned when triggering knowledge base retrieval in dialogue. Cause: The ownership number parameter for the current trading target is not configured in `variables`, resulting in missing retrieval conditions and inability to match corresponding documents.
- Phenomenon: Cross-system daily updated materials cannot be associated in multi-turn dialogue. Cause: Real-time data source trigger rules are not configured, only a single locally cached material is called, and the latest listing result announcement is not synchronized.
- Phenomenon: Ownership fields are truncated after long document chunking. Cause: Chunk length is set too small, failing to cover complete target restriction condition paragraphs, leading to missing key constraints during review.

## How to Verify Proper Configuration
- Upload a single property right transfer specification, verify that key fields such as ownership number and trading target type are not truncated after chunking.
- Initiate a multi-turn dialogue including bid application documents and margin vouchers, check that the retrieval results include both associated materials.
- Test context transmission via the `messages` parameter, confirm that historical review opinions can be correctly called by subsequent dialogue.
- Adjust the single search limit parameter, verify that the number of retrieved materials changes with the configuration.
