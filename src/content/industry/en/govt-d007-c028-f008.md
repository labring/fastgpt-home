# Declaration Materials and File Review for Market Entity Registration and Licensing: Document Parsing and Chunking

## What this category of data looks like
Data for this category originates from the enterprise registration fully electronic system, the national enterprise credit information publicity system, the electronic business license system, and the residence information database. The update frequency is daily. Commonly processed documents include establishment registration applications, articles of association, shareholder resolutions, residence certificates, business licenses, food business license applications, and similar materials. Most document structures contain hierarchical approval fields, subject qualification information, and business operation license-related statements. Some documents include embedded images or tabular structured data.

## What constraints do these characteristics impose on the document parsing and chunking step
Daily updated batch materials require the parsing process to support high concurrency. Handling mixed document types requires compatibility with formats including PDF, Excel, and embedded images. Hierarchical approval fields require that context associations are retained during chunking, to avoid splitting the complete logic of core approval materials such as shareholder resolutions and residence certificates. Embedded image and tabular data require the parsing step to extract both text and media information, ensuring that subsequent review steps can access complete material content.

## How to set configurations
The following configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Matches the length of single-segment core approval information in declaration materials, to avoid splitting key clauses such as shareholder resolutions and residence certificates |
| `chunkSplitter` | Split by paragraph + heading | Adapts to the hierarchical structure of articles of association and establishment applications, retains context associations of approval logic |
| `customPdfParse` | Enabled | Retains media information and layout details such as embedded business license scans and official approval stamps in PDFs |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Compatible with batch-submitted license application material packages, to avoid single-batch uploads being blocked |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Addresses parsing time for multi-page PDFs and Excel files with images, to avoid mid-process timeouts for long document parsing |
| `chunkSettingMode` | Manual configuration | Adjusts chunking rules for different document types, adapts to field independence of registration materials |

## Three common configuration errors
- After uploading an Excel file with embedded images, the parsing result only returns plain text, and image-related content is missing. The cause is that embedded media parsing configuration for tabular documents is not enabled, and only text content within cells is extracted.
- Uploading a single 30+ page PDF establishment registration application triggers a parsing timeout error. The cause is that `PARSE_FILE_TIMEOUT_SECONDS` is not adjusted to a value suitable for long documents, and the default timeout limit cannot cover the full parsing process.
- Converting a PDF to Markdown format results in lost approval stamp information in headers and footers. The cause is that the default PDF parsing mode does not cover header and footer areas, and only extracts main body text content.

## How to confirm configurations are correctly set
- An Excel residence certificate file with embedded shareholder identification images may be uploaded, and the parsing result checked to confirm whether it includes text descriptions of the images or corresponding associated fields.
- A multi-page PDF establishment registration application may be uploaded, and the parsing process verified to not trigger timeout errors, with parsing time meeting expected thresholds.
- The original document and parsed chunked content may be compared, to confirm that core approval fields such as name, residence, and shareholder information are not incorrectly split.
- A batch license application material package may be uploaded, and the upload process verified to not be blocked due to file size.

The values listed are common starting points, and should be evaluated against samples corresponding to the actual deployment context.
