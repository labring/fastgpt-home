# Declaration Materials and File Review for Construction Project Environmental Impact Assessment Approval: Citation Sources and Traceability

## What This Category’s Data Entails
This category’s data includes core documents such as environmental impact assessment reports or report forms, approval applications, public participation explanations, technical assessment opinions, and EIA approval decisions.
Data sources include the national unified construction project EIA declaration and approval system, ecological environment zoning control results, pollution discharge permission platform, and monitoring data.
There is no fixed update cycle for the data.
Documents contain fields including project category, EIA level, pollution prevention measures, public participation status, and approval opinions.
Each data source has different formats and field definitions. Some custom fields must retain their originally submitted content.

## What Constraints Do These Characteristics Impose on Citation Sources and Traceability
Data sources are scattered and have varying formats. Clear field mapping rules for each data source are required to avoid field mismatches during traceability.
Document volume varies significantly. The length span between small project report forms and large project reports is notable, so text splitting and citation must be adapted for different lengths.
Irregularly updated data requires the traceability chain to support real-time verification of the latest version. Fixed cache cycles cannot be relied on.
Materials submitted by different entities may include custom fields. The field integrity of the original source must be retained to ensure traceability back to the original submitted content.
If issues such as project suspension or approval revocation occur, original materials must be located quickly. The accuracy and completeness requirements for the traceability chain are very high.

## Configuration Settings

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 6000–10000 token | Adapts to the average length of EIA documents, fully retains cited approval basis text |
| `responseData` | Enable original source fields | Retains original field information from declaration materials and technical assessment opinions, facilitating traceability and verification |
| `detail` | Enable detailed traceability mode | Displays the source document name, affiliated data source, and upload time of cited content |
| Single recall limit | Top 8 entries | Covers multiple types of related materials required for EIA approval, avoiding omission of key reference content |
| Data source mapping rules | Calibrated based on actual testing | Adapts to field differences across different data sources such as the national unified EIA declaration system and pollution discharge permission platform |

## Three Common Configuration Mistakes
- Issue: The returned response does not display the cited original material content. Cause: The `responseData` configuration item is not enabled, or the field mapping rules for the data source are not correctly configured.
- Issue: After setting `quoteMaxToken` to 15000 token, the large language model does not receive the configured context content. Cause: The setting exceeds the platform's default context window limit, causing the context to fail to transfer normally.
- Issue: Garbled characters appear in cited content after uploading CSV-format monitoring data. Cause: The correct encoding format for the CSV file is not specified, and character set conversion was not completed during upload.

## How to Verify Successful Configuration
- Upload a standard EIA report form, submit a test question about the project approval basis, and check whether the document name and affiliated data source of the citation source are displayed at the end of the response.
- Adjust `quoteMaxToken` to different values, compare the length of the returned cited text, and confirm that the configuration parameter takes effect.
- Import test data from multiple types of data sources, submit a cross-data source question, and check whether relevant materials from different sources can be correctly recalled.
- View the platform's log panel to confirm that the API requests for citation traceability do not return error status codes.
