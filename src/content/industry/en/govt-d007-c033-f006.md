# Tendering and Procurement Compliance Management: Declaration Materials and File Review - Citation Sources and Traceability

## What This Category of Data Looks Like
This category of data draws from enterprise procurement platforms, public resource trading platforms, supplier databases, contract management systems, and audit issue databases. The system synchronizes the latest business data from each source daily. Daily processed documents cover procurement plans, demand specifications, bidding documents, bid evaluation records, contracts, acceptance documents, supplier complaint materials, and more. Each individual document includes fields such as procurement subject information, item details, evaluation criteria, performance records, and penalty records. Document formats vary across different sources. Archives must be sorted by business link to ensure review accuracy.

## Constraints on the "Citation Sources and Traceability" Link
The traceability link must synchronize the latest data in real time, because data sources update daily. This prevents the use of expired procurement plans or invalid supplier qualification information, and avoids deviations in audit basis. Documents from multiple sources must clearly mark their source platform or system, and distinguish between internal enterprise procurement data and public resource trading data. This meets the dual compliance requirements of state-owned asset supervision and internal audit. Documents from different business links, such as bidding documents and bid evaluation records, must be accurately matched. Incorrect association of cross-link documents may lead to bid rigging risks, audit rectification requirements, or contract invalidation determinations.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | The core review content of a single tendering and procurement related document is usually around one thousand characters, which matches the length requirement for traceability content |
| `responseData` | Return only knowledge base matching results | Ensure that outputs only use original text from the knowledge base for responses, without generating additional content |
| `detail` | Enabled | Display specific fields of traceability documents such as document name and source platform, to meet the traceability requirements of compliance review |
| Single search limit | Top 5 results | Tendering and procurement file review requires precise matching; too many results will interfere with traceability judgments |
| Context window | 2000–3000 characters | Covers the core review content of a single tendering file, to avoid truncation of critical information |

## Three Common Misconfigurations
- Phenomenon: Output content does not use original text from the knowledge base for responses, and includes additionally generated content. Cause: The `responseData` parameter is not configured correctly, and the large model's free generation logic is enabled.
- Phenomenon: Knowledge base citation variables cannot be selected in workflow nodes. Cause: The citation traceability switch is not enabled in the knowledge base configuration, or the workflow node is not bound to the corresponding knowledge base data source.
- Phenomenon: Cited traceability documents do not match the currently reviewed file, and cross-link documents appear. Cause: Chunking rules are not set based on document type, leading to mixed matching of procurement plans and bid evaluation records from different links.

## How to Confirm Correct Configuration
- Upload a single tendering and procurement file document to the FastGPT v4.17.0 knowledge base, initiate a corresponding review query, and check whether the output content completely matches the original text response in the knowledge base.
- View the traceability module of the output result, confirm that the displayed document name and source platform match the actually uploaded document.
- Add a variable output node in the workflow, and check whether the result fields matched by the knowledge base can be selected.
- Adjust the `quoteMaxToken` parameter value, and check whether the length of the output traceability content changes with the parameter.
