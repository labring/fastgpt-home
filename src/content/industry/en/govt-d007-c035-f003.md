# Pollution Discharge Permit Management: Declaration Materials and Case Review — Multi-turn Dialogue and Prompt Engineering

## What Data for This Category Looks Like
Data sources for this segment include the national pollution discharge permit management information platform, enterprise environmental protection ledgers, online monitoring systems, and environmental statistics systems. Commonly processed documents include pollution discharge permit application forms, implementation reports, self-monitoring plans, ledger records, change applications, and permit copies. Document structures include fields such as permit limits, discharge outlet parameters, monitoring frequencies, and ledger filling requirements. Units cover categories like concentration, emission volume, and frequency. Data is updated quarterly.

## What Constraints These Characteristics Impose on Multi-turn Dialogue and Prompt Engineering
Since data is updated quarterly, multi-turn dialogue must limit searches to documents from the most recent quarter to avoid using outdated data. Document types are diverse and include specialized fields and units. Prompts must guide dialogue to clarify the current review document type and corresponding fields. Review tasks involve cross-system data correlation. Multi-turn dialogue must gradually guide users to provide supporting materials from different sources to avoid overloading input at once. It must also ensure that the conversation context can carry the content of multiple review-related documents.

| Source Citation | Enabled | This ensures review conclusions returned in dialogue can be linked to original documents for easy verification |

## Three Common Errors
- The symptom is a "No available indexing model detected" prompt popping up after refreshing the dialogue page. The cause is that the pollution discharge permit-specific document library is not bound to the current dialogue agent, or the indexing model deployment status did not sync after refresh.
- The symptom is that review conclusions returned by dialogue do not include links or page numbers from original documents. The cause is that the prompt does not explicitly require returning location information of source documents, or the source citation configuration is not enabled.
- The symptom is that after loading a review conversation from months prior via `chatId`, further questioning is not possible. The cause is that the conversation context cache does not retain historical data beyond the quarterly update cycle, or session storage has been automatically cleared.
