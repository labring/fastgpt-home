# Declaration Materials and Case Review for Pollution Discharge Permit Management: Citation Sources and Traceability

## What Data for This Category Looks Like
Daily documents for this category include pollution discharge permit application forms, implementation reports, self-monitoring plans, ledger records, change applications, and permit copies. Data sources cover the National Pollution Discharge Permit Management Information Platform, enterprise environmental protection ledgers, online monitoring systems, and environmental statistics systems.
Data updates occur quarterly. Different documents have distinct field focuses:
- Implementation reports focus on quarterly emission summary data
- Ledger records focus on daily emission details
- Self-monitoring plans include monitoring points and permit limit requirements
- Case review requires verifying corresponding field information across multiple sources

## Constraints for Citation Sources and Traceability
Multi-source data requires clear linking of citation traceability to records from each original platform to prevent cross-system data confusion.
Quarterly data updates require the knowledge base to sync latest ledgers and monitoring data regularly. Cited data must include its update cycle to meet regulatory requirements.
Differing field requirements across document types mean retrieval must match review needs by document type. For example, prioritize recall of monitoring-related documents when reviewing a self-monitoring plan.
Strict compliance rules require accurate traceability information. Key permit limits or emission boundary data must not be omitted.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Single documents related to pollution discharge permits are mostly within the thousand-character range, and this token quota can fully cover core review content |
| `responseData` | Return top 6 citations | Declaration materials and case review require multi-dimensional verification; 6 citations can cover reference content for different review links such as ledgers, monitoring data, and permit limits |
| `detail` | Enable full traceability | Case review requires clear citation of document version, update time, and original source; full traceability meets compliance requirements of ecological and environmental supervision |
| Similarity threshold | `0.72–0.85` | Technical specifications and permit limit statements for pollution discharge permits are precise; this threshold range can filter irrelevant content while retaining valid reference data |
| Single search limit | Recall top 12 results | Multi-source data review needs sufficient recall volume to cover content from different data sources such as the National Pollution Discharge Permit Management Information Platform and enterprise ledgers |

## Three Common Mistakes
- Phenomenon: The interface displays "Knowledge base binding parameter format error", or output always references a fixed set of documents. Cause: The data source for the pollution discharge permit-specific knowledge base is not properly associated, or citation variables do not match platform-required naming rules.
- Phenomenon: Mixed search results include non-pollution discharge permit documents such as environmental impact assessment approval materials. Cause: No filtering rules based on document source tags are configured, leading to recall of cross-category irrelevant data.
- Phenomenon: Historical review records cannot be directly cited in conversations, or returned results do not link to historical case information. Cause: The historical conversation context binding function is not enabled, or historical conversations are not associated with the exclusive context identifier for the current pollution discharge permit case.
