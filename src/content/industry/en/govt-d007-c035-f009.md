# Pollution Discharge Permit Management: Declaration Materials and File Review — Model Access and Configuration

## What This Category of Data Looks Like
Data for this category primarily comes from the national pollution discharge permit management information platform, enterprise environmental protection ledgers, online monitoring systems, and environmental statistics systems. It is updated quarterly.

Commonly processed documents include pollution discharge permit application forms, implementation reports, self-monitoring plans, ledger records, change applications, and permit copies. Document fields include permit limits, discharge outlet information, monitoring data, change items, and other metrics. Units involve concentration, emission volume, time cycles, and other standards. The data must match the standardized format requirements of the ecological environment industry to ensure accurate field identification during review.

## Constraints Imposed on Model Access and Configuration
Dispersed data sources require cross-system integration. Model access must support parsing both structured and unstructured data from multiple sources.

Quarterly updated batch documents require support for large-batch processing. Single-batch input scale must be limited.

Industry-standardized document fields require the model to accurately identify professional fields such as permit limits and discharge outlets to avoid matching errors.

Significant differences exist in review logic across different document types. Flexible configuration of task adaptation parameters for the model is required to ensure review results meet the rigorous standards of ecological environment management.

## How to Configure Settings
These configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Range | Rationale |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | Adapts to the long-text structure of pollution discharge permit documents, covering the context requirements of multiple spliced review documents |
| `maxTokens` | 2000–3000 token | Meets the output verification length requirements for a single review document, avoiding truncation of key compliance determination content |
| `quoteMaxToken` | 1500 token | Limits the fragment length of source document citations, ensuring the accuracy and readability of review basis |
| `temperature` | 0.1–0.3 | Reduces randomness in review results, ensures consistency of compliance determinations, and meets the rigorous requirements of government review |
| `AIPROXY_API_ENDPOINT` | Fill in the dedicated address provided by the deployment service provider | Adapts to network environment requirements for direct connection or transit invocation of domestic models |
| `AIPROXY_API_TOKEN` | Fill in the valid token obtained | Ensures identity legitimacy for model calls, avoiding invalid token errors |

## Three Common Misconfigurations
- Issue: Invalid token error is returned when calling domestic models, while tests via oneapi complete successfully. Cause: `AIPROXY_API_ENDPOINT` or `AIPROXY_API_TOKEN` are not configured correctly. Direct connection does not adapt to the interface format requirements of domestic models.
- Issue: Video memory usage rises quickly to 6-7 GB and multiple GPUs are occupied after reranker model call. Cause: Reasonable values for `maxContext` or `maxTokens` are not set, causing the model to load excessive context data.
- Issue: Field matching errors appear in review results after configuration is complete. Cause: The model's context range is not adjusted for professional fields related to pollution discharge permits, causing the model to confuse non-standardized fields with compliance determination fields.

## How to Confirm Configurations Are Correct
- Launch a review test for a single pollution discharge permit application form. Verify whether the returned results include verification conclusions for core fields such as permit limits and discharge outlets.
- Use a general connectivity test tool to test the connectivity of the target model. Confirm that the token and interface address configurations are correct before connecting to the FastGPT platform.
- Adjust the `temperature` parameter, compare the differences between two review results, and confirm that the parameter takes effect.
- Submit batch quarterly updated documents, check whether the batch scale processed by the model matches the preset configuration, and confirm there are no obvious timeouts or content truncations.
