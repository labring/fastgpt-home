# Maintenance of Government Service Item Catalogs and Service Guidelines: Declaration Material and File Review – Citation Source and Traceability

## What this category of data looks like
The core data for this category includes documents such as basic government service item catalogs, implementation lists, service guidelines, and standard material directories. Data is primarily obtained from the national basic government service item catalog, administrative licensing item list, power and responsibility list, and local government service item databases. The typical update cycle is once per month. Each individual document contains standardized fields including item name, acceptance conditions, application material list, and handling process. Some documents also include local refined service requirements and frequently asked question explanations.

## What constraints these characteristics impose on the citation source and traceability link
The monthly updated data source requires that the citation traceability link support regular synchronous updates of the knowledge base, to avoid deviations in service handling standards caused by using expired data. Cross-level data from multiple sources requires that traceability information clearly mark whether the data is sourced from the national-level catalog or the local item database, ensuring that the original basis can be traced during review. The standardized field structure requires precise matching of core fields such as item name and application materials when citing, to avoid association errors caused by generalized matching. Additionally, comparison records generated during the maintenance process must be bound to traceability information, to facilitate subsequent verification of the compliance of maintenance actions.

## Three common mistakes
- Phenomenon: The returned result shows that a knowledge base document has been cited, but the content completely does not match the core fields of government service item catalogs and service guidelines. Cause: Precise matching rules were not set for the standardized fields of this category, resulting in matching to irrelevant non-government service data.
- Phenomenon: PDF and tabular government documents uploaded to the knowledge base are not cited, and only plain text datasets can be recalled. Cause: The corresponding parsing configuration for non-text formats was not enabled, or structured documents were not correctly imported into the government service item-specific knowledge base.
- Phenomenon: A workflow times out when calling the citation traceability function. Cause: The value of `quoteMaxToken` is too high, exceeding the resource limit for single processing by the platform, resulting in context loading timeout.

## How to confirm the configuration is complete
- Manually trigger a workflow, check the traceability information in the returned result, and confirm that it includes content such as data source and document type.
- Upload a test structured government document, trigger citation traceability, and confirm that the document is normally recalled and displayed.
- Adjust relevant configuration for matching rules, and verify whether the citation result changes with the configuration adjustments.
- Check the knowledge base synchronization logs, and confirm that the synchronization cycle matches the official data update frequency.
