# Government Information Application-Based Disclosure: Declaration Materials and File Review - Citation Source and Traceability

## What data falls under this category
Core data for this category comes from daily business documents of government offices and government information disclosure offices. These documents include government information disclosure application forms, supplementary notice letters, third-party opinion solicitation letters, reply letters, service receipts, and administrative reconsideration response materials.

Data sources cover government information disclosure platforms, official archive systems, document management systems, and departmental business ledgers. Update frequency is irregular, with no fixed cycle.

Document fields include applicant information, application matters, public attribute judgment basis, reply content, and service records. The structure of a single document varies based on the business link, requiring precise matching of associated information for the corresponding file. This explanation uses the configuration logic of FastGPT v4.17.0.

## Constraints imposed by these characteristics on the citation source and traceability link
Multi-source data access requires the traceability system to support metadata formats from different platforms. This avoids information loss caused by inconsistent formats.

Irregular update characteristics require traceability logic to support incremental synchronization and full verification. This ensures retrieval results always match the latest file status.

Differences in document structures require the traceability link to filter corresponding fields by business link. For example, when searching for application materials, prioritize matching the application matter field of the application form.

The severity of potential errors requires traceability results to be traceable. Each citation must be bound to a specific document source and generation basis. Precise traceability cannot be replaced by fuzzy matching.

## How to configure settings
| Configuration Item | Recommended Value | Rationale |
|---|---|---|
| `quoteMaxToken` | `1500–2000 token` | Matches the average length of single citations in government documents, to avoid truncating critical public attribute judgment basis |
| Maximum Context | `8000–12000 token` | Covers associated content from multi-source government documents, meets the reference need for full information such as application matters and reply content during file review |
| Single Search Limit | `Top 6 entries` | Matches the conventional number of associated entries for government files, to avoid introducing irrelevant third-party opinion materials that interfere with review |
| Maximum Knowledge Base Citations | `3–5 entries` | Balances information completeness and reply conciseness, aligns with information reference standards for government review |
| `responseData` | Enabled | Requires the system to return specific document source metadata, to support traceability verification |
| Response Timeout Threshold | `60–90 seconds` | Adapts to the average time required for government document retrieval, to avoid review interruptions caused by timeouts |

## Three common configuration mistakes
- Line breaks in responses appear as literal `\n` without proper line wrapping. The cause is incorrect configuration of text rendering line break parsing rules, or failure to use correct escape formatting in prompt words.
- The maximum knowledge base citations parameter does not take effect, and the number of returned citations exceeds the set value. The cause is failure to bind this parameter to the retrieval recall logic, or failure to save the configuration item successfully in the system.
- Retrieval results return timeout or abnormal status codes. The cause is that the response timeout threshold is set too small, which cannot cover the retrieval time of multi-source government documents, or failure to correctly configure access permissions for data sources.

## How to confirm correct configuration
- Upload a sample government information disclosure application form, trigger the retrieval process, and check whether the returned results include source information and metadata of the corresponding document.
- Enter a prompt containing `\n` in the test interface, verify that the reply content correctly renders line breaks and does not retain literal `\n`.
- Adjust the `quoteMaxToken` parameter value, observe whether the number of tokens in returned citations matches the set value range.
- Check whether the `responseData` and `detail` parameters in the configuration list are enabled, to ensure complete return of traceability information.
- Simulate a timeout scenario, verify that the system returns retrieval results within the set response timeout threshold.
