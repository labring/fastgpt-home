# Government Procurement Project Declaration Materials and File Review: Citation Sources and Traceability

## What the data for this category looks like
Documents covered under this category include procurement requirements, procurement plans, bidding documents, tender documents, bid evaluation reports, winning bid announcements, procurement contracts, responses to inquiries, and more. Data sources include the national government procurement website, local government procurement websites, the fiscal integration system, the procurer’s budget system, and supplier credit records. Data updates occur daily. Each document has a fixed field structure. For example, procurement requirements include project budget and procurement content, tender documents include qualification documents and quotation details, and supplier credit records include compliance status and business information. The number of documents processed daily fluctuates based on the scale of individual procurement projects. The core review link involves cross-checking multiple types of documents.

## What constraints these characteristics impose on the citation sources and traceability link
Data sources are scattered and updated daily. The traceability link must support incremental synchronization and deduplication across multiple data sources to avoid repeated references to expired or non-official content. Document types vary widely, with significant differences in their fields. Corresponding metadata extraction rules must be configured for each document type to ensure accurate association with official identifiers from the source during citation. The core review link takes a long time and involves multiple participating parties. Retrieved traceability content must precisely match review needs to avoid irrelevant information interfering with judgments. Additionally, government procurement processes have strict regulatory requirements. Cited sources must come from official public channels, and access to non-compliant data sources must be restricted.

## How to set the configurations
| Configuration Item | Recommended Value Range | Rationale |
|---|---|---|
| `quoteMaxToken` | 800–1200 token | Government procurement-related documents have moderate lengths of key content per piece. This range covers core review basis such as complete qualification clauses and scoring criteria, avoiding content truncation |
| Similarity threshold | 0.75–0.85 | Government procurement documents contain many professional terms. This threshold effectively filters irrelevant general content, ensuring retrieved content highly matches review needs |
| Single search limit | Top 6 results | The number of core documents related to government procurement projects typically ranges from 5 to 7. This value covers all necessary reference materials while avoiding context overload |
| `responseData` | Enable metadata return | Official identifiers such as document source channels and release times must be displayed during traceability to meet compliance requirements for the review link |
| `detail` | Enable full citation | The review link requires verification of original details of cited content. Full citation avoids review errors caused by out-of-context quoting |

## Three common errors
- Phenomenon: Cited output content is accidentally truncated, only showing parts of qualification clauses or scoring standard paragraphs. Cause: The value of `quoteMaxToken` is set too small, failing to cover complete key content of the corresponding government procurement document.
- Phenomenon: Mixed retrieval results include engineering construction bidding documents or other non-government procurement content. Cause: The retrieval knowledge base range is not limited to government procurement-specific data sources, leading to retrieval of documents from other categories.
- Phenomenon: Calling the interface after configuring citation variables returns an error message of "knowledge base does not exist" or "parameter format error". Cause: The unique identifier of the corresponding government procurement knowledge base is not correctly bound, or the variable format does not meet system requirements.
