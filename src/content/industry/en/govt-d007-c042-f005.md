# Declaration Materials and Case Review for Legal Compliance and Major Risk Management: Tool Calling and Plugins

Reference only; verify against the target FastGPT release and deployment documentation.

## What this category of data looks like
This category of data mainly comes from enterprise contract management systems, compliance risk databases, legal and regulatory repositories, case management systems, and reporting platforms. Documents processed daily include compliance risk lists, contract legal review opinions, major issue legal opinions, compliance review forms, and violation report investigation reports.
The data update frequency is monthly. Documents contain fields such as reviewer, risk level, compliance clauses, and handling opinions. The length of single documents varies widely.

## What constraints do these characteristics impose on the tool calling and plugins link
Multi-source heterogeneous data sources require plugins to adapt to API formats and permission rules of different systems, to avoid cross-system call failures.
The monthly data update frequency requires the retrieval scope of tool calling to be limited to compliance data updated in the most recent month, to avoid using expired information.
The diversity of document fields requires tool calling to support structured field extraction, ensuring accurate acquisition of key content such as risk levels in compliance review forms and compliance clauses in contract review opinions.
The wide variation in single document length requires tool calling to adapt to input texts of different lengths, avoiding interface errors caused by overly long texts.
The serious consequences of errors require tool calling to have failure retry and exception alert capabilities, ensuring the review process is not interrupted.

## How to set the configuration
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Automatic tool selection adapted to multiple scenarios, covering business such as contract review, risk screening, violation clue investigation, and more |
| `functionCall` | Enabled | Supports structured extraction of key fields from compliance review forms and legal opinions, improving review efficiency |
| Tool call timeout | 600 seconds | Matches the average time required to pull data across multiple systems, avoiding process interruption from cross-system calls |
| Single tool call return limit | Top 5 entries | Avoids returning excessive compliance risk data that exceeds the context window, affecting model judgment |
| Tool call result cache period | 30 days | Matches the monthly update frequency of compliance data, reducing repeated pull operations |
| Single file upload limit | 1000 MB | Adapts to the upload requirements of large compliance case files, avoiding errors caused by overly large files |

## Three common mistakes
- Interface returns 413 error: The interface returns a Payload Too Large status code. The cause is that the declaration materials or case text passed in a single tool call exceeds the maximum length allowed by the interface.
- Tool call process not hidden: The conversation interface fully displays tool call parameters, request logs, and return results. The cause is that the tool call process hiding configuration item is not enabled.
- Qwen3 model cannot restrict inference mode: The model automatically triggers general inference processes outside of tool calls. The cause is that the `toolChoice` parameter is not correctly configured to forced tool call mode, leading the model to independently select inference paths.

## How to confirm the configuration is complete
- Initiate a simulated contract review request, check whether tool calling automatically triggers appropriate compliance data retrieval and field extraction.
- Submit declaration materials that exceed conventional length, confirm that the interface returns the expected error status code.
- View the conversation interface, confirm whether the tool call process is hidden or displayed as configured.
- When testing Qwen3 model calls, confirm that only the configured tool call process is triggered, and no additional general inference content is generated.
