# Special Equipment Safety Supervision Declaration Materials and File Review: Citation Sources and Traceability

## What This Category of Data Looks Like
Core data covers documents related to the full lifecycle of special equipment, including use registration certificates, periodic inspection reports, maintenance records, hidden danger rectification notices, accident reports, operator certificates, and more. Data sources include special equipment safety supervision systems, inspection and testing institution systems, user unit ledgers, and operator certificate databases. The update frequency is once per month. Core fields include equipment number, inspection validity period, maintenance unit qualification, operator certificate number, hidden danger rectification status, and more. Key information for a single document is concentrated, and precise matching of supervision and review requirements is required.

## What Constraints These Characteristics Impose on the Citation Sources and Traceability Link
Since data is scattered across multiple independent supervision, inspection, and user unit systems, multi-source knowledge bases must be connected for unified recall. Cross-source data association rules need to be configured. The data update frequency is monthly, so the knowledge base synchronization cycle must match this rhythm to avoid referencing expired inspection or maintenance information. The precise matching requirement for core fields means citation traceability must bind key identifiers such as equipment number and validity period. Using only basic text similarity cannot meet precise traceability requirements. The supervision attributes of high-risk equipment require citation results to have high confidence. The number of recalled entries must be limited and sorted by business priority to reduce manual verification workload and error risks.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Documents related to special equipment have moderate length per copy. This range can cover core fields while avoiding context overflow |
| `responseData` | Return full metadata | Core supervision fields such as equipment number and inspection validity period need to be traced. Full metadata can directly associate with original records in the special equipment safety supervision system |
| `detail` | Enabled | Specific content of cited documents must be displayed to facilitate verification of details such as maintenance records and hidden danger rectification status |
| Single search upper limit | Top 6 entries | The number of document types involved in daily review is limited. Too many entries will increase manual verification burden |
| Knowledge base synchronization cycle | Once per month | Matches the monthly update frequency of business data to ensure the timeliness of referenced data |

## Three Common Misconfigurations
- Phenomenon: The number of returned citation entries exceeds the scope required for business review. Cause: `quoteMaxToken` or the single search upper limit is not configured, or the value is set too high. This recalls too many non-core document entries and increases manual verification costs.
- Phenomenon: The order of cited documents does not match business priority, for example, expired maintenance records are ranked before the latest inspection report. Cause: No reordering rules matching the special equipment supervision scenario are set. Only basic similarity sorting is relied on, and weights of business fields such as inspection validity period and rectification status are not added.
- Phenomenon: The cited source displayed in the conversation cannot be directly associated with the original records of the special equipment supervision system. Cause: The `responseData` configuration is not enabled. Only text summaries are returned, and key metadata such as equipment number and operator certificate number are missing, making traceability verification impossible.

## How to Verify Correct Configuration
- Submit a test query containing a specific special equipment number, check whether the returned cited documents include corresponding metadata such as use registration certificates and inspection reports.
- Adjust the value of `quoteMaxToken`, verify whether the total token count of returned citations matches the set range.
- Simulate a multi-knowledge base recall scenario, check whether documents from different sources are sorted by business priority, with the latest inspection reports and valid rectification records ranked first.
