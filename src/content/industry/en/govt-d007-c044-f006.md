# Declaration Materials and Case File Review for Environmental Law Enforcement and Monitoring Supervision: Source Citation and Traceability

## What this category of data looks like
This category of data covers the entire workflow of ecological environmental law enforcement and monitoring. Daily documents include on-site inspection records, sampling records, monitoring reports, order for correction decisions, and administrative penalty decisions. Data sources are online monitoring platforms, automatic pollution source monitoring data, ecological environmental law enforcement systems, and third-party test reports. The update frequency is daily. Document structures include fixed business fields: on-site inspection records include inspection points and working condition parameters; monitoring reports include pollutant concentrations and test standards; law enforcement documents include basis for identifying illegal facts and penalty-related information.

## What constraints do these characteristics impose on the source citation and traceability link
Format differences across multiple data sources require the traceability system to be compatible with field naming rules of different platforms, to avoid citation failure caused by field mismatches. Daily updated data sources need incremental synchronization logic configured, to ensure cited monitoring data and law enforcement records are the latest valid versions. The structured characteristics of fixed business fields require precise matching of key identifiers such as points and time during traceability. Without such matching, it is impossible to correspond to specific law enforcement or monitoring links. At the same time, the strong correlation requirement between law enforcement documents and monitoring reports means traceability results must be directly bound to corresponding test data and on-site records, to support compliance review of case files.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum Context | 20000 characters | Adapt to the splicing requirement of a single case file associated with multiple documents in this category, and align with the context limit range of FastGPT v4.17.0 |
| Single Search Limit | Top 6 entries | Evidence documents associated with a single case file in this category do not exceed 5. Top 6 entries can cover all associated content |
| `quoteMaxToken` | 800–1200 characters | Match the single-document length of daily law enforcement documents in this category, to ensure cited content is complete and not truncated |
| `responseData` | Group by data source | Differentiate online monitoring data, law enforcement system records, and third-party test reports, to quickly locate sources during review |
| `detail` | Display complete business fields | Show fields such as inspection points, sampling time, and pollutant concentrations, to support cross-verification of law enforcement evidence |

## Three common mistakes
- Phenomenon: Citation results only return text fragments, and do not display complete business fields of the source document. Cause: The `detail` configuration item is not enabled. Only text content is extracted without associating original fields.
- Phenomenon: When calling the traceability tool in a custom workflow, local uploaded case files cannot be cited, and only external links are supported. Cause: The index binding logic for local documents is not configured. The tool only recognizes source addresses in external link format.
- Phenomenon: Citation results exceed context length, causing truncation errors. Cause: The `quoteMaxToken` parameter is not adjusted. The length of a single cited document exceeds the processing range of the model.

## How to confirm the configuration is correct
- Upload one on-site inspection record and its corresponding monitoring report, trigger a traceability query, and check whether the returned result includes business fields such as inspection points and sampling time.
- Set `quoteMaxToken` to 800 characters, upload a law enforcement document with a length of approximately 900 characters, and confirm that the cited content is not truncated.
- Add a traceability node in the custom workflow, upload a local case file, and verify whether the tool can correctly bind this file as a citation source.
- Adjust the single search limit to top 3 entries, upload a case file associated with 4 documents, and confirm that the returned result includes all associated evidence files.
