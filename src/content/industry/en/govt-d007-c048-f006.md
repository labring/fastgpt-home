# Administrative Licensing Approval: Declaration Materials and File Review - Citation Source and Traceability

## What Data for This Category Looks Like
This category of data comes from the national integrated government service platform item database, administrative licensing item list, departmental business approval systems, and electronic certificate database.
Relevant platforms update this data daily.
Daily documents include service guides, application forms, commitment letters, acceptance notices, correction notices, administrative licensing decision letters, and license certificates.
Legally prescribed licensing items set the data boundary.
The data covers item setting basis, handling conditions, application material lists, approval processes, and license identification fields.
No additional statistical quantitative content is included.

## Constraints for Citation Source and Traceability
Data sources cover multiple departmental systems.
Ensure citation traceability matches the latest business data of the corresponding department. Avoid mixing cross-departmental data.
The daily update requirement means citation links must synchronize government data in real time. Avoid using expired lists to verify application materials.
Documents are bounded by legally prescribed items.
Strictly match application materials with the setting basis of the corresponding item. Do not reference unbound documents arbitrarily.
Electronic certificate documents must link to a unique identifier.
This allows direct retrieval of original vouchers during traceability. Do not rely on fuzzy matching logic.

## How to Set Configurations
The following configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum context length | 4000–6000 characters | Administrative license review requires loading multiple documents such as item lists, application materials, and approval opinions at once, covering complete business logic |
| Single recall limit | Top 3–5 entries | The legal basis and handling conditions for administrative licensing items usually concentrate in 3-5 core documents. Excessive recall will interfere with model judgment |
| `quoteMaxToken` | 800–1200 token | Matches the length of a single declaration material document, ensuring full citation of material content |
| Citation content return switch | Enabled | Synchronize and return original cited document information to meet file archiving compliance requirements |
| `responseData` | Enabled | Return metadata fields for cited documents to help reviewers verify sources |
| `detail` | Enabled | Display specific source paths and identifiers for cited documents, meeting government traceability compliance requirements |
| Knowledge base automatic synchronization | Triggered daily | Matches the daily update frequency of government data, ensuring cited item lists and electronic certificates use the latest versions |

## Three Common Mistakes
- Phenomenon: After adjusting citation limit parameters such as `quoteMaxToken`, model-generated content does not link to any knowledge base citations. Checking system logs shows normal recall results, but the final output citation mark field is empty. Cause: The citation content return switch is not enabled, or the maximum context length exceeds the current model’s supported range, leading to truncated citation information.
- Phenomenon: Citation works correctly during local testing, but cannot link to knowledge base content when called via external release channels. Cause: The external release channel lacks correct knowledge base association permission configuration, or local knowledge base update configuration parameters are not synchronized.
- Phenomenon: Generated content is unrelated to cited knowledge base content, and citation marks point to documents that do not contain the administrative licensing item content from the current question. Cause: The single recall limit is set too high, mixing documents unrelated to the target licensing item, or no exclusive administrative licensing business prompt word is bound, causing the model to not focus on the current business scope.

## How to Confirm Proper Configuration
- Submit a test question with the specific name of an administrative licensing item, and check if generated content includes citation source marks and document metadata.
- Open the system log page, and verify that recalled knowledge base documents belong to the currently configured administrative licensing item data source, and that source paths match preset system addresses.
- Adjust the `quoteMaxToken` parameter value, and verify that the citation fragment length of generated content matches the set token range.
- Trigger a manual knowledge base synchronization task, confirm the synchronization status shows success, and that the update time of subsequently cited item data aligns with the current day.

The values provided are common starting points and should be measured against the reader's own samples.
