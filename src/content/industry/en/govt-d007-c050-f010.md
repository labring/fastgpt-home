# Fiscal Expenditure Performance Evaluation: Declaration Materials and File Review - Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
Data for this category primarily comes from the unified budget management system, project declaration materials, fund payment records, business system ledgers, and satisfaction surveys. Daily documents include performance target forms, self-assessment forms, performance evaluation reports, supporting material lists, and rectification reports. Data updates follow an annual cycle. Most documents mix structured tables and unstructured text. Fields include project ID, performance indicators, fund amount, supporting material ID, and more. There are no fixed standard units; values vary based on actual project conditions.

## What Constraints These Characteristics Impose on Knowledge Base Retrieval and Recall
Annual updated bulk data requires retrieval and recall to support fast loading of full historical documents. This avoids excessively long indexing rebuild times. Mixed structured and unstructured documents require adapted chunking rules for tables and text. This ensures core fields like performance indicators and fund correspondences are accurately retrieved. Disparate multi-system data sources require a unified search entry for cross-source data. This prevents gaps in search scope. High compliance requirements for review work mean retrieved results must strictly match core performance evaluation logic. This reduces irrelevant document interference and improves review accuracy.

## How to Configure Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Matches the association strength between core indicators and supporting materials in fiscal performance evaluations. Prevents irrelevant retrievals if set too low, and misses valid materials if set too high |
| `limit` | Top 10 results | Covers core review points for all annual declaration files. The number of single search results aligns with the reading volume of manual reviews |
| `searchMode` | hybrid | Combines keyword and semantic retrieval. Adapts to document types mixing structured tables and unstructured text |
| `usingReRank` | Enabled | Optimized via FastGPT v4.17.0's re-ranking engine. Rearranges initial retrieval results to prioritize matches between performance targets and fund expenditure correspondences |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands relevant performance evaluation terminology based on user queries. Covers vocabulary used in professional review scenarios |
| `collectionIds` | Exclusive collection IDs corresponding to fiscal performance evaluation files | Limits search scope to the dedicated dataset. Prevents interference from documents of other categories |

## Three Common Misconfigurations
- Markdown formatting fails to render in context references. This occurs when original format markers are not preserved during document chunking, or when format retention parameters are not configured for retrieval and recall. This results in plain text output.
- Some queries fail to correctly reference knowledge base files. This occurs when `datasetSearchUsingExtensionQuery` is not enabled. Professional performance terminology is not expanded, so hidden associated fields in documents cannot be matched.
- A 60-second timeout occurs when switching knowledge base indexes or rebuilding indexes, or the system stays in the training state for an extended period. This happens when index rebuilding for annual bulk datasets does not use incremental optimization. Full scanning causes processing time to exceed system thresholds.

## How to Confirm Configurations Are Properly Set
- Upload a standard performance self-assessment form and corresponding supporting materials, initiate a search, and verify that retrieved results include the target documents and that sorting aligns with review logic.
- Trigger an index rebuild operation, check the system status update speed, and confirm no prolonged stagnation or timeout errors occur.
- Test queries containing professional performance terminology, and verify that retrieved results include the corresponding performance evaluation reports and target forms.
- Check the context reference area, and confirm that tables and format markers from original documents are correctly retained and displayed.
