# Department Final Accounts and Financial Report Submission Materials and File Review: Citation Sources and Traceability

## What This Category of Data Looks Like
The data sources for this category are the budget management integrated system, centralized treasury payment system, accounting system, and asset management system. The update frequency is annual. Daily documents include department final account statements, balance sheets, income and expenditure final account statements, final account explanations, and government financial reports. Each document has fixed accounting fields and corresponding units. Data is generated centrally on an annual cycle. Each single document covers core modules such as budget execution, assets and liabilities, and difference explanations.

## Constraints Imposed by These Characteristics on the "Citation Sources and Traceability" Link
The annual centralized update feature requires a single batch traceability to cover historical data from multiple systems, which places demands on the batch processing capability of retrieval. Mixed data from multiple systems requires traceability configurations to accurately match the field rules of each system, to avoid cross-system field confusion. Fixed-structure documents and clear business links require citation traceability to be directly linked to the corresponding document type and system source, to meet the precise requirements of audit verification. The time-consuming verification link requires traceability results to quickly locate specific data entries, to reduce manual investigation costs.

## How to Set the Configuration
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Matches the reasonable length of a single segment citation from department final account documents, to avoid marker truncation |
| `responseData` | Only return associated knowledge base entries | Ensures traceability only points to official fiscal data sources of this category |
| `detail` | Enabled | Generates detailed identifiers that include the citation source system and document type |
| Max Search Count per Request | Top 5 entries | Corresponds to the centralized source count of annual final account data, to avoid redundant recall |
| Max Context Size | `10000–15000 characters` | Adapts to the splicing length of multi-system data, ensuring traceability completeness |
| Timeout Threshold | `60 seconds` | Matches the reasonable response duration for annual batch data retrieval |

## Three Common Misconfigurations
- Garbled characters appear in the end quotation marks of conversation outputs, which eventually revert to standard quotation marks. The cause is that the `quoteMaxToken` value exceeds the actual length of a single document segment, causing formatting errors after citation markers are truncated.
- When querying non-existent fiscal questions in the knowledge base, citations of final account data from this category are still returned. The cause is that `responseData` is not configured to only return associated entries, and the system returns irrelevant data by default.
- The conversation request interface does not return the cite citation ID field. The cause is that the `detail` configuration is not enabled, so the interface does not generate unique identifiers for citation traceability.

## How to Confirm the Configuration Is Properly Set Up
- Initiate a query that includes specific final account statement fields, and check whether the citation markers in the returned results are standard quotation marks with no garbled characters.
- Enter a fiscal question not covered by the knowledge base, and confirm that no citations of final account data from this category appear in the returned results.
- Call the conversation interface, and check whether the returned data includes fields related to citation traceability.
- View the citation details, and confirm that the corresponding system source and document type are marked.
