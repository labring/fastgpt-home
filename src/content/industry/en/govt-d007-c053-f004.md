# Department Budget Preparation: Declaration Materials and File Review - Workflow Orchestration

## Data Profile for This Category
Core data comes from the unified budget management system, department staff establishment system, prior-year final accounts, project library, and the annual budget preparation notice issued by the Ministry of Finance. Daily processed documents include department budget drafts, project application forms, performance target forms, staff expense calculation forms, and budget approvals. The data update cycle is annual. Document fields include staff establishment count, project performance indicators, application amount, approved quota, etc. Most units are ten thousand yuan. Some fields must match the unified format requirements of the annual budget preparation.

## Constraints on Workflow Orchestration
The annual update frequency requires the workflow to complete a basic configuration reset once per year to adapt to the format requirements of the current year's budget preparation notice. The need to access multi-source data requires configuring cross-system data fetch nodes in the workflow to ensure unified data sources for documents such as budget drafts and application forms. The fixed format and unit requirements for document fields require embedding format verification links in the workflow to block non-compliant declaration materials. The need to summarize budget data from subordinate units requires configuring parallel processing nodes in the workflow to improve review efficiency.

## Configuration Guidelines
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `variables` | Preset global variables including department code, annual cycle, and amount unit, with values such as `2024-2025 fiscal year`, `ten thousand yuan` as fixed parameters and real-time fetched system data | Match annual update frequency, unify field and unit requirements for review links |
| `nodeId` | Assign unique identifiers to the three core nodes: cross-system data fetch, format verification, and review | Facilitate workflow debugging and abnormal node location, meet multi-source data access requirements |
| Format Verification Rules | Set field mandatory verification for staff expense calculation forms and project application forms; amount fields only accept numbers and `ten thousand yuan` units | Match fixed document format and unit requirements, block non-compliant declaration materials |
| Knowledge Base Association | Bind knowledge bases containing the Ministry of Finance budget preparation notice and prior-year final accounts, with a single recall limit of the top 5 results | Ensure quick access to official policies and historical data during reviews, adapt to multi-source data requirements |
| Timeout Settings | Set a timeout of `60 seconds` for cross-system data fetch nodes | Avoid workflow stagnation caused by system response delays, align with the typical response speed of the unified budget management system |

## Common Misconfigurations
- Issue: After modifying the value of `variables` in the workflow, downstream nodes read empty variables. Cause: The variable update operation was not configured as an inter-node transfer step. The variable was only modified in the current node and not synchronized to the global variable storage.
- Issue: When selecting a variable reference method for the AI chat component to specify a large model, the temperature setting entry cannot be found. Cause: The advanced settings area was not expanded in the large model node configuration panel of the workflow. The temperature parameter is hidden in the advanced options by default.
- Issue: When attempting to automatically obtain a knowledge base ID in the workflow, an empty value is returned. Cause: The knowledge base was not created and authorized on the FastGPT platform in advance, or the correct knowledge base association was not bound in the node configuration.

## How to Verify Successful Configuration
- Trigger the first run of the workflow on FastGPT v4.17.0, verify that the initial value of `variables` matches the preset parameters for the annual budget preparation.
- Enter the configuration panel of each core node, verify that `nodeId` is unique, with no duplicate or missing node identifiers.
- Submit a simulated department budget draft, verify that the format verification link correctly blocks declaration data that does not meet unit requirements.
- Trigger the knowledge base recall link, verify that the returned results include relevant content from the Ministry of Finance budget preparation notice, confirming that the association is working properly.
