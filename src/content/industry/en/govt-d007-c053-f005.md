# Department Budget Preparation: Declaration Materials and File Review - Tool Calling and Plugins

## What the data for this category looks like
This category of data typically originates from the unified budget management system, departmental staffing system, prior-year final account data, project repository, and the Ministry of Finance's annual budget preparation notice. The update cycle is annual. Commonly processed documents include departmental budget drafts, project application forms, performance target forms, personnel expense calculation forms, and budget approval documents. Fields include project code, number of staff, declared amount, performance indicators, and more. Units involved include ten thousand yuan, person, project serial number, and others.

## What constraints these characteristics impose on the tool calling and plugins workflow
Annual updated data sources require tool calling to limit datasets to the current budget year, to prevent cross-year data from interfering with review results. Multiple types of structured documents require plugins to support table field extraction and verification, ensuring numerical matching for personnel expenses and project expenditures. Data from multiple systems requires cross-source comparison; tool calling must configure multi-data-source linkage plugins to ensure budget declaration data aligns with staffing and project repository information. File review requires associating multiple documents; plugin calls must support field aggregation and verification for batch documents, improving review accuracy.

## Configuration settings
These configurations are based on FastGPT v4.17.0, adapted for the department budget preparation declaration materials and file review scenario:

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | Supports automatic selection of multiple plugins, aligns with multi-stage verification requirements for budget reviews |
| `functionCall` | `enabled` | Supports structured data extraction, adapts to field verification and aggregation for budget documents |
| Maximum number of single plugin calls | Top 3 entries | Avoids excessive data causing context overflow, aligns with the review scope of a single file |
| Plugin call timeout | 60 seconds | Multi-source queries for budget data typically complete within this time frame, avoiding long wait times |
| Knowledge base association scope | Only current budget year documents | Aligns with the annual data update characteristic, avoiding cross-year data interfering with review results |
| Plugin trigger condition | When missing budget declaration fields are detected | Automatically triggers the verification process, reducing manual intervention costs |

## Three common errors
- Plugin clicks have no response. The cause is that plugin permissions for corresponding data sources such as the unified budget management system and project repository are not bound, or the `toolChoice` configuration item is not set to a mode adapted to the current scenario.
- Continuous plugin calls at midnight lead to balance exhaustion. The cause is that time filtering rules for plugin calls are not configured, and precise matching of trigger conditions is not set, resulting in repeated empty or invalid requests.
- Multiple plugin selection prompts pop up in a single conversation. The cause is that the single call limit for `functionCall` is not enabled, or the maximum number of plugin calls within a conversation is not set, leading to repeated triggering of the plugin selection process.

## How to confirm the configuration is correctly set
- Upload an annual project application form to trigger plugin calls, check whether project code, declared amount and other fields can be automatically extracted, to verify that the `functionCall` configuration takes effect.
- View plugin call logs, confirm that calls are only triggered when missing budget declaration fields are detected, to verify that the trigger condition configuration is correct.
- Test uploading documents from non-current budget years, check that they are not included in the association scope, to verify that the knowledge base association scope configuration takes effect.
- Simulate a call request during nighttime hours, check that the request is blocked, to verify that the time limit configuration takes effect.
