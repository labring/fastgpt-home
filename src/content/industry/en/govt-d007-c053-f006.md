# Department Budget Preparation: Declaration Materials and File Review - Citation Sources and Traceability

## What data for this category looks like
Usually, core data for department budget preparation comes from the unified budget management system, department staff establishment system, prior-year final accounts, project library, and Ministry of Finance budget preparation notices. Update frequency is annual. Daily processed documents include department budget drafts, project application forms, performance target forms, personnel expense calculation forms, and budget approvals. Documents contain clear fields such as unit code, project name, calculated amount, and performance indicators. Core information for each document centers on annual fund declaration and allocation.

## Constraints on the citation sources and traceability link
Annual updated data sources require the traceability process to accurately match valid data for the current declaration cycle. It must avoid introducing historical redundant information. The multi-system source characteristic means the configuration must support cross-data source permission verification and field alignment. This ensures uniform document formats exported from different systems. Document fields are clear and directly tied to fund allocation. Traceability requires precise location of the source for corresponding fields. Otherwise, budget review may fail. The volume of summary documents requires the configuration to balance recall efficiency and information integrity. It must avoid missing key declaration basis.

## Configuration settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1500–2000 token | Matches the core content length of a single department budget document, ensures complete citation of key fields such as project name and calculated amount |
| `responseData` | Return only associated budget source documents | Filters non-relevant content, focuses on official data sources for budget preparation, improves traceability accuracy |
| `detail` | Enabled | Extracts and displays specific fields of source documents, such as project code, approved amount, and declaring unit information |
| Single recall limit | Top 6 entries | Covers the number of associated sources for subordinate unit budget summary, avoids excessive redundant data interfering with review |
| Maximum context length | 8000–10000 characters | Accommodates multiple associated documents involved in annual budget preparation, ensures complete invocation of declaration basis |
| Timeout threshold | 120 seconds | Adapts to delay conditions when retrieving budget data across systems, avoids request interruptions |

## Three common configuration errors
- Phenomenon: Returned source documents only show titles, with no specific field information. Cause: The `detail` configuration item is not enabled, and the field extraction logic for source documents is not activated, resulting in incomplete traceability information.
- Phenomenon: Recalled source documents include historical data from non-current years. Cause: The single recall limit is set too high, and data sources from historical cycles are not filtered, leading to invalid cross-year associations in declaration materials and file review.
- Phenomenon: Tool calls cannot reference locally configured data source variables, and only external links are supported. Cause: The `responseData` parameter is not correctly configured, which restricts the call permissions of local variables, only allowing loading of external link data sources, which does not meet the needs of internal system calls for departmental budgets.

## How to confirm configuration is successful
- Submit a test department budget declaration material, check whether the returned result includes specific field information of source documents, such as project code and approved amount.
- View the number of recalled source documents, confirm that it meets the preset single recall limit, with no additional redundant data.
- Test the invocation of locally configured budget system data source variables, confirm that associated document content can be obtained normally.
- Simulate a cross-system data retrieval scenario, confirm that the response time does not exceed the preset timeout threshold, with no request interruptions.
- In FastGPT v4.17.0, check whether the parameters on the configuration page have been correctly saved and take effect.
