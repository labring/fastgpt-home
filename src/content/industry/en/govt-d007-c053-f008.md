# Department Budget Preparation: Declaration Materials and File Review — Document Parsing and Chunking

## What This Category of Data Looks Like
The daily documents for this category include department budget drafts, project application forms, performance target forms, personnel expense calculation forms, budget approvals, and others. Data sources include the unified budget management system, department staff establishment system, prior-year final accounts, project repositories, and Ministry of Finance budget preparation notices. The update frequency is annual. Most documents combine structured tables and text, containing fields such as project codes, expense amounts, and staff establishment numbers. Units mostly use standard fiscal accounting units such as ten thousand yuan and person.

## Constraints on Document Parsing and Chunking
Batch documents updated annually have significant structural differences. Fixed-format budget approvals and flexibly filled project application forms both exist, requiring chunking to adapt to content of varying formats. Documents contain many structured fields, including closely linked expense amounts and project codes. Splitting associated data across tables must be avoided to prevent logical breaks during review. Most data sources are standardized files exported from internal systems, so parsing compatibility with different export formats must be supported. Single documents also cover a wide range of content, spanning multiple accounting dimensions from personnel expenses to project expenditures. Chunking must retain contextual associations to ensure complete review logic.

## Configuration Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 characters | Adapts to the length of structured paragraphs and table blocks in budget documents, avoiding splitting key expense calculation fields |
| `chunkSplitter` | Split by paragraph + title | Retains the association between project titles and corresponding application content in budget documents, aligning with contextual reading habits during review |
| `customPdfParse` | Enable structured parsing mode | Adapts to PDF tables exported from the unified budget management system, accurately extracting expense amounts and project codes from cell contents |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Addresses parsing time for single batch budget documents, preventing mid-interruption for large file parsing |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Meets upload requirements for annual batch budget documents, preventing large files from being blocked |
| `chunkSettingMode` | Manual configuration | Adjust chunking parameters for different types of budget documents such as personnel expense forms and project application forms, adapting to specialized review needs |

## Three Common Mistakes
- After uploading a single annual budget summary document, the interface displays parsing failure and the log returns a timeout error. The cause is failure to adjust the `PARSE_FILE_TIMEOUT_SECONDS` parameter, so document parsing time exceeds the default threshold.
- Parsed chunked content includes expense fields split across tables, making it impossible to associate corresponding project application descriptions during review. The cause is failure to set `chunkSplitter` to split by title + paragraph, resulting in adjacent table content being split into different chunks.
- In a local Docker deployment instance, uploading a document shows no parsing result and prompts a service connection failure. The cause is failure to correctly configure the local service address for `customPdfParse`, so FastGPT cannot connect to the parsing node.

## How to Verify Correct Configuration
- Upload a typical department budget draft document, view the parsed chunk preview, and confirm that each chunk contains a complete project title and corresponding application content.
- Check the parsing service runtime logs, confirm there are no timeout errors, and that the `PARSE_FILE_TIMEOUT_SECONDS` configuration value matches actual parsing time.
- Test chunking effects separately for different types of budget documents such as personnel expense calculation forms and project application forms, adjust `chunkSettingMode` parameters to fit specialized review needs.
- Verify that the uploaded file size does not exceed the `UPLOAD_FILE_MAX_SIZE` configuration value, to avoid the system blocking overly large files.
