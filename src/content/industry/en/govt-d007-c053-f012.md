# Department Budget Preparation: Declaration Materials and File Review - Deployment and Upgrade

## What the data for this category looks like
Data for this category primarily comes from the unified budget management system, departmental staffing system, prior-year final accounts, project repository, and budget preparation notices from the Ministry of Finance. Update frequency is annual. Daily processed documents include departmental budget drafts, project application forms, performance target forms, personnel expense calculation forms, and budget approvals. Fields include unit code, project category, applied amount, performance indicators, number of authorized staff, and more. The data structure is fixed and strongly tied to annual fund declarations. The number of fields and format for each document do not have significant differences.

## What constraints these characteristics impose on deployment and upgrade
Annual centralized updates, cross-system multi-source data integration, fixed-field structure documents, and batch review requirements impose multiple constraints on deployment and upgrade. Annual batch import and parsing of budget documents require storage and computing resources to adapt to peak traffic. Integration with multiple data sources such as the unified budget management system requires stable database and cache connections to ensure data synchronization. Fixed-field documents require knowledge base chunking logic to match business fields, to avoid misalignment during information splitting. For multi-node workflow review scenarios, optimize resource allocation to prevent node dragging and execution lag.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `DB_MAX_LINK` | `20–30 connections` | Adapts to peak database access demands during annual batch reviews, prevents connection exhaustion |
| `PG_URL` | `Read-only instance address from the same source as the unified budget management system` | Ensures stability and security of cross-system data integration, avoids write risks |
| `REDIS_URL` | `Local cache instance address, memory configured to 8000–12000 MB` | Caches frequently accessed budget field data to reduce database load |
| `STORAGE_S3_ENDPOINT` | `Alibaba Cloud OSS-compatible endpoint, storage capacity configured to 500–1000 GB` | Adapts to Alibaba Cloud deployment scenarios, stores batch-imported budget documents and files |
| `FILE_TOKEN_KEY` | `Unified key with internal office systems, expiration time set to 7200 seconds` | Ensures access security for batch-imported documents, prevents unauthorized downloads |

## Three Common Configuration Errors
- Workflow canvas drag response delay, node loading lag. Cause: The `DB_MAX_LINK` parameter was not adjusted to adapt to peak connections, leading to resource preemption due to exhausted database connections.
- Budget information returned by the knowledge base does not match actual declaration fields. Cause: Chunking logic matching business fields was not configured, resulting in loss of field information after document splitting.
- Docker deployment fails to start, cannot connect to the database. Cause: The `PG_URL` parameter was not configured correctly, using an incorrect database instance address.

## How to Verify Proper Configuration
- Use FastGPT v4.17.0 to run a test batch import of annual budget documents. Check import success rate and parsing completeness. Adjust storage and database configurations based on actual error messages.
- Simulate workflow operations with more than 10 concurrent users. Observe interface response speed. Optimize resource configurations for `DB_MAX_LINK` and `REDIS_URL` based on lag conditions.
- Verify cross-system data synchronization functionality. Confirm that fields pulled from the unified budget management system match local documents.
- Check internal office network domain access restrictions. Confirm only authorized users can access the review page.

The values provided are common starting points and should be measured against the reader's own samples.
