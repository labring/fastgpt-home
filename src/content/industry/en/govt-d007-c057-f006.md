# Food Safety Supervision Sampling Declaration Materials and File Review: Citation Sources and Traceability

This configuration is based on FastGPT v4.17.0 and is adapted to the business data characteristics of this category.

## What the data for this category looks like
This category’s data originates from food safety sampling monitoring systems, the State Administration for Market Regulation sampling results query system, laboratory LIMS systems, and food producer and operator ledgers. Daily documents include sampling plans, sampling slips, inspection reports, unqualified food verification and disposal reports, and risk control notices. Most fields use fixed formats, including sampling number, inspection items, non-conformity judgment basis, and disposal measures.

The data updates monthly. Individual document lengths vary widely, ranging from hundreds of characters for sampling slips to thousands of characters for inspection reports. The core evidence is inspection reports issued by laboratories. These reports must be linked to upstream and downstream process documents to form a complete file.

## What constraints do these characteristics impose on citation sources and traceability
Batch data updated monthly requires the traceability system to support quick recall of linked documents by batch, to avoid incomplete coverage during single indexing. Multi-source data requires unified field alignment, to prevent mismatches in key fields such as sampling numbers and inspection items when referencing across systems.

As core compliance evidence, inspection reports must be strictly linked to upstream and downstream documents such as sampling slips and disposal processes, to ensure the traceability chain is complete and auditable. Documents have fixed formats but complex fields, requiring precise keyword matching to avoid irrelevant documents being included in the citation pool. This prevents negative impacts on review efficiency and accuracy.

## How to set the configuration
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `1500–2000 token` | A single inspection report is approximately 800–1200 characters. When combined with linked documents such as sampling slips and disposal reports, the total token count must cover at least two core documents, to avoid truncation of key compliance content such as non-conformity judgment bases |
| Single search limit | Top 8 entries | The core evidence for this category is inspection reports, with no more than 7 linked documents. Retaining 2 redundant entries ensures complete coverage of the traceability chain |
| `responseData` | Return document title, sampling number, generation time | Regulatory file review requires quick location of document sources. The sampling number is a unique identifier field, facilitating subsequent manual verification |
| `detail` | Enabled | Core judgment fields of referenced documents must be displayed, such as non-conformity items and inspection bases, to meet the compliance requirements of file review |
| Search result reordering | Sorted by match score descending | Prioritize documents with the highest relevance to sampling plans and inspection reports, ensuring core evidence is cited first |

## Three common errors
- Phenomenon: The token count of the generated response far exceeds the set `quoteMaxToken` threshold, resulting in truncation of key content. Cause: The total token count of linked documents was not considered. The upper limit was set only for a single document, and no token space was reserved for cross-document citations.
- Phenomenon: The cited document is not the top-ranked result from the search. Cause: The search result reordering configuration was not enabled, or the reordering rules were not bound to core business fields such as sampling numbers, leading to match score calculations that do not fit the scenario requirements.
- Phenomenon: The citation prompt text uses the default Chinese, which cannot adapt to cross-language review scenarios. Cause: The knowledge base search prompt template was not adjusted. The default Chinese wording was used, and no corresponding language version was switched to.

## How to confirm the configuration is correctly set
- Import one complete sampling inspection file document, trigger the search and citation function, and check whether the returned referenced documents include the core inspection report and sampling slip.
- Adjust the `quoteMaxToken` parameter, observe the content length of the generated response, and confirm that no key fields are truncated.
- Check the sorting of the citation list, and confirm that the top-ranked document is the inspection report with the highest matching degree to the current review topic.
- Switch the prompt template, and confirm that the citation prompt text meets the language requirements of the current business scenario.
