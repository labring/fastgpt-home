# Declaration Materials and File Review for Food Safety Supervision Sampling: Deployment and Upgrade

## What the data for this category looks like
Core documents involved in this category include sampling plans, sampling forms, inspection reports, non-compliant food verification and disposal reports, and risk control notices. Data mainly comes from the food safety sampling and monitoring system, the State Administration for Market Regulation sampling results query system, inspection institution LIMS, and enterprise ledgers. The data update frequency is monthly. The core document structure uses sampling identifier, inspection items, non-compliance determination, and disposal process as key fields. There is no unified fixed unit; it varies by document type. For example, sampling forms include fields such as sampling date and inspection result values.

## What constraints these characteristics impose on deployment and upgrade
Monthly updated data requires configuring incremental synchronization trigger periods during deployment, to avoid excessive system resource usage from full data pulls. Differences in data formats across multiple sources require configuring unified access adaptation rules, to ensure documents from different systems can be parsed uniformly. Field differences in core documents require retaining key fields such as sampling identifier and non-compliance determination during document splitting, to prevent loss of core information required for review. The sensitivity of documents related to non-compliance disposal requires configuring permission isolation rules, to ensure only authorized roles can access sensitive materials.

## How to set the configurations
These configurations are based on the deployment specifications for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `REDIS_URL` | `redis://:custom password@server address:6379/0` | Used to cache metadata of sampling documents and temporary review results, reducing repeated query overhead |
| `STORAGE_S3_ENDPOINT` | `oss-cn-hangzhou.aliyuncs.com` | Adapted access address for domestic cloud storage, used to store large-volume documents such as sampling forms and inspection reports |
| `FILE_TOKEN_KEY` | `Randomly generated 32-bit string` | Used to encrypt document download links, preventing unauthorized access to sensitive review materials |
| `ROOT_KEY` | `Custom high-strength key` | Used to initialize platform administrator permissions, ensuring access security after deployment |
| `DB_MAX_LINK` | `20–30 connections` | Adapts to concurrent connection requirements for monthly batch data synchronization, preventing database connection exhaustion |

## Three common mistakes
- Symptom: An unknown error is returned when calling the inspection institution LIMS interface, with an invalid credential prompt. Cause: The platform's built-in credential storage rules were not used, and external platform-generated credentials were misused, leading to authentication failure.
- Symptom: After the Docker container starts, the listening port is fixed at 3000, and cannot be modified via custom configuration. Cause: Hardcoded port configuration inside the container was not overridden via environment variables, resulting in ineffective port settings.
- Symptom: Connection timeout occurs when importing monthly sampling data in batches. Cause: A reasonable upper limit for the database connection pool was not configured, leading to database connection exhaustion during concurrent synchronization and task interruption.

## How to confirm the configuration is complete
- Access the storage bucket corresponding to the configured `STORAGE_S3_ENDPOINT`, upload a sampling form document, and confirm that it can be read normally and an encrypted download link is generated.
- After starting the Docker container, use the `docker ps` command to check port mapping, and confirm that the custom port has been correctly bound.
- Trigger a monthly incremental data synchronization task, and check the platform logs to confirm there are no authentication errors or connection timeout prompts.
- Log in to the platform administrator account, use the permissions corresponding to `ROOT_KEY` to access all review documents, and confirm that the permission isolation rules are effective.

The values provided are common starting points and should be measured against the reader's own samples.
