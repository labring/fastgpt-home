# Fertilizer and Pesticide Declaration Material and File Review: Multi-turn Dialogue and Prompt Engineering

## What this category's data looks like
Fertilizer and pesticide declaration material and file review data mainly comes from publicly available filing documents from the Ministry of Agriculture and Rural Affairs Pesticide Inspection Institute, agricultural and rural bureaus of various provinces and cities, and internal declaration files submitted by enterprises. The data includes two categories: structured filing forms and unstructured scanned documents. Structured fields include registration certificate number, active ingredient name and content, production enterprise, applicable crops, recommended application rate, and other items. Units include g/L, %, kg/mu, and others. Update frequency is adjusted based on the approval progress of newly registered products. Newly approved products are updated every 1-3 months. Annual filing data is updated in a centralized manner each year.

## Constraints imposed on multi-turn dialogue and prompt engineering
The unit specificity of structured fields requires prompts to verify units when extracting declaration information. Non-compliant application rate suggestions will be generated otherwise. Mixed PDF announcements and scanned file archives require OCR recognition before entering the dialogue review link. This adds pre-steps for multi-turn dialogue. Regularly updated registration data requires the knowledge base update cycle to match the approval rhythm. Outdated approval information will be returned otherwise. The character count of a single declaration file can reach tens of thousands, which exceeds the default context limit. Context configuration must be adjusted to retain core review fields.

## How to configure settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Maximum Context Window | 8000–12000 characters | Matches the average character size of a single declaration file to avoid truncating core approval fields |
| Number of Associated Knowledge Bases | Top 2-4 | Fertilizer and pesticide registration knowledge bases have moderate individual size. Too many will slow down retrieval speed |
| `variables` Preset Fields | Registration certificate number, active ingredient proportion, recommended application rate | Binds core structured fields to improve information extraction accuracy |
| `messages` History Truncation | Last 8-12 dialogue turns | Filters redundant history and focuses on the review link for the current declaration file |
| `chatId` Session Binding | Enable and bind review batch ID | Enables persistent context for multi-turn dialogue and avoids session reset |
| Default Startup Prompt | Please verify the field compliance of this declaration material | Automatically loads preset review rules to simplify user operational workflow |

## Three Common Mistakes
- Phenomenon: The submitted declaration material JSON file is truncated during dialogue, or an "context limit exceeded" error is returned. Cause: The maximum context window configuration is not adjusted. The default limit cannot match the character size of fertilizer and pesticide declaration materials.
- Phenomenon: After associating more than 3 knowledge bases, the dialogue retrieval result is empty or returns an error. Cause: The number of associated knowledge bases is not limited. This exceeds the platform's default association limit and causes the retrieval logic to fail.
- Phenomenon: The review result is normal in preview mode, but a "field parsing failed" error occurs during formal dialogue. Cause: Knowledge base updates are not synchronized in the `chatId` bound session configuration. Preview uses local cached data, while formal sessions call the latest online data.

## How to Confirm Configuration is Correct
- Submit a standard fertilizer and pesticide declaration file. Check that the context fully retains all core fields without abnormal truncation.
- Associate the knowledge base for the corresponding category. Test whether retrieval can return the latest registration approval data without outdated information.
- Trigger the preset default startup prompt. Check whether the dialogue automatically loads the preset review logic and starts review without additional input.
- Submit a test file with a character count exceeding the preset context limit. Confirm that reasonable processing logic is triggered without forced errors.

The values listed above are common starting points and should be evaluated against the operator's own samples.
