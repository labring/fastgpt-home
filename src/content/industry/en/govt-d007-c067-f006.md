# Fertilizer and Pesticide Declaration Materials and Case Review: Source Citation and Traceability

## What data for this category consists of
Data for fertilizer and pesticide declaration materials and case review comes from three main sources: Ministry of Agriculture and Rural Affairs pesticide registration announcements, production enterprise filing documents, and local plant protection station inspection ledgers.
A single declaration material typically includes structured fields such as registration certificate number, active ingredient name, content ratio, application rate standard, and production batch number. Some materials also include PDF-format scanned paper documents and Excel-format production records.
Data update schedules follow these rules: pesticide registration certificates are updated annually during renewal, inspection ledgers are synchronized quarterly, and production filing documents are updated in real time with batch changes.
Field units include mass percentage, volume concentration, kilograms per mu application rate, and others. Cross-region naming differences exist for some fields. For example, some regions label "active ingredient content" as "active ingredient".

## What constraints these characteristics impose on source citation and traceability
First, structured fields require precise matching of key identifiers such as registration certificate numbers and active ingredients. Semantic text matching alone is not sufficient.
Second, multi-channel data with different update frequencies requires separate refresh cycle configurations. This prevents referencing expired inspection records.
Single declaration materials have long text lengths. A traced snippet that is too short will lose critical compliance evidence. A snippet that is too long will occupy excessive context space.
Cross-region field naming differences require the traceability system to support different naming conventions. This avoids missed recalls caused by keyword mismatches.
Additionally, case review compliance requires clear labeling of specific batches and release times for cited sources. This avoids audit risks from vague traceability.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Single fertilizer and pesticide declaration material text length ranges from 1000 to 1500 characters. Sufficient citation snippet length is needed for traceability |
| `responseData` | Return source document structured fields | Exclusive fields such as registration certificate number and active ingredient must be linked to meet compliance traceability requirements for case review |
| `detail` | Enabled | Specific page or paragraph location of cited content in the source document must be displayed to match the detail needs of review scenarios |
| Similarity threshold | 0.75–0.85 | Filter general agricultural documents unrelated to declaration materials. Only highly matching filing and inspection records are recalled |
| Single recall limit | Top 6 entries | Number of filing documents linked to fertilizer and pesticide declaration materials typically ranges from 3 to 5. Excessive recall increases context redundancy |

## Three Common Configuration Mistakes
- Phenomenon: Setting the similarity threshold to 1 still results in a large number of non-target cited documents. Reason: No secondary filtering is performed using fertilizer and pesticide exclusive fields such as registration certificate numbers. Only relying on global semantic similarity causes false recalls.
- Phenomenon: Cited source fields appear empty. Reason: The `responseData` configuration is not enabled. No structured source document information is specified to return, only text snippets are returned.
- Phenomenon: The response triggers a context over-limit error. Reason: The `quoteMaxToken` value exceeds the default context quota of FastGPT v4.17.0. The system cannot load the full cited content.

## How to Confirm Correct Configuration
- Upload a real fertilizer and pesticide registration declaration PDF, trigger a review-related question, and check if the response includes exclusive source document fields such as registration certificate number and active ingredient.
- Adjust the `quoteMaxToken` value, and observe if the length of cited snippets in the response changes with the configuration.
- Test setting different similarity thresholds, and observe if the number of recalled documents decreases as the threshold increases.
- Check system operation logs, confirm that each traceability request returns valid source document numbers or links, and that there are no empty fields or error messages.
