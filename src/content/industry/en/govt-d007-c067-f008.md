# Fertilizer and Pesticide Declaration Materials and Case Review: Document Parsing and Chunking
This page configuration is based on FastGPT v4.17.0

## What the Data for This Category Looks Like
The data for fertilizer and pesticide declaration materials and case review primarily comes from internal enterprise registration systems, the Ministry of Agriculture and Rural Affairs filing platform, and test reports issued by third-party quality inspection institutions. Update frequency aligns with independent registration declaration batches. Corresponding documents are updated once per completed declaration project. Most documents follow a fixed template structure, including standardized fields such as registration certificate number, active ingredient content, dosage form, and production qualification certificates. Some documents include long-form test data tables, scanned qualification documents, and multi-page approval circulation records. Field units are mostly mass concentration percentages, grams per liter, kilograms, and similar units. Cases often contain multiple nested sub-documents and attachments.

## Constraints on Document Parsing and Chunking
The fixed template structure of fertilizer and pesticide declaration materials requires preserving field associations during chunking. Do not split cross-page test data tables. Numeric fields with units must remain semantically complete after chunking. Prevent splitting the value and unit of active ingredient content into different chunks. Multi-page scanned documents and nested attachments increase total parsing time. Adjust timeout settings and file upload limits accordingly. Documents with mixed long text paragraphs and table structures require chunking rules that balance semantic coherence and content completeness. Also, support OCR extraction of text from scanned documents.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Adapts to the long paragraphs and table structures of fertilizer and pesticide declaration materials, preserving semantic integrity |
| `chunkSplitter` | Split by paragraph + table | Avoid splitting cross-page test data tables, ensure complete test information is contained within each chunk |
| `customPdfParse` | Enabled | Supports OCR text extraction from scanned documents, adapts to scanned qualification files in cases |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | Matches the actual file size of individual declaration cases containing multiple attachments |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Adapts to parsing time for large files and multi-attachment cases, prevents premature termination due to timeout |
| `chunkSettingMode` | Manual mode | Allows adjustment of chunking rules for the special structure of chemical documents |

## Three Common Misconfigurations
- After uploading a quality inspection report containing product images, the question-and-answer workflow cannot call text content from the images. The cause is failure to enable the OCR function of `customPdfParse`, so key information such as active ingredients embedded in the images is not extracted.
- Timeout errors occur when parsing declaration cases with more than 200 pages. The cause is failure to adjust the `PARSE_FILE_TIMEOUT_SECONDS` parameter. Using the default duration causes parsing to terminate before completion.
- Test data tables are split into multiple independent chunks. The cause is that `chunkSplitter` is not configured to preserve table structure, resulting in table headers and data rows being split into different chunks.

## How to Verify Proper Configuration
- Upload a standard declaration PDF containing a test data table. View the parsed chunk list to confirm that complete table data is not split across multiple chunks.
- Upload a multi-attachment declaration case within 500 MB. Confirm that the parsing status shows completion, with no timeout-related error prompts.
- Upload a document containing scanned qualification files. View the parsed text content to confirm that text information from the scanned documents has been fully extracted.
- When testing question-and-answer, enter questions related to active ingredients and dosage forms. Confirm that the returned results contain complete field information and corresponding units.

The values provided are common starting points and should be measured against the reader's own samples.
