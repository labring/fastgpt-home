# Declaration Materials and File Audit for Power Generation Equipment Manufacturing: HTTP Interfaces and External Systems

## What this category of data looks like
Declaration materials and file audit data for power generation equipment manufacturing mainly originate from equipment factory qualification documents, supervision and inspection records, project acceptance reports, and declaration forms required by industry authorities. Data updates follow production batch or annual archiving schedules. Declaration materials for a single unit are generated incrementally during the manufacturing process. Annual file data is updated according to the natural calendar year.

Document structures contain mixed-format content: qualification certificates in PDF format, component parameter ledgers in Excel format, assembly drawings in DWG format, and structured declaration forms. Fields include equipment serial number, manufacturing date, rated power (unit: MW), inspection item number, audit status, and others. Some fields have mandatory standardized units of measurement.

## What constraints these characteristics impose on HTTP interfaces and external systems
Mixed-format declaration materials require interfaces to support multipart form submissions, and compatibility with PDF, Excel, DWG and other file types. This prevents upload failures caused by unsupported formats.

The data update logic tied to production batches and annual cycles requires interfaces to support query parameters including equipment serial number, batch number, and audit year. This enables accurate matching of declaration file data.

Structured fields with units require interfaces to enforce uniform unit specifications when receiving and returning data. For example, rated power must use MW as the standard unit, to avoid format conflicts that disrupt subsequent audits.

The large volume of archived historical file data requires interfaces to support pagination queries. This controls the number of documents returned per request, preventing excessive interface load.

Large assembly drawings may consume significant transmission resources. Interfaces must support configuration options for resumable uploads or chunked uploads, to ensure transmission stability.

## Three common misconfigurations
- Symptom: The interface returns a 401 Unauthorized error, or authentication fails. Cause: The `Authorization` parameter is not configured correctly, or an invalid API key is used.
- Symptom: Uploaded power generation equipment drawing files are blocked by the interface and cannot be submitted. Cause: The file upload limit does not allow DWG format files, or the single file size exceeds the configured maximum.
- Symptom: The file data returned by the interface lacks the rated power field, or the unit display is abnormal. Cause: Correct equipment parameters are not passed in `variables`, or field unit specifications are not unified.

## How to confirm proper configuration
- Call the interface with preset equipment retrieval parameters, check if the returned document list matches the retrieval conditions, and adjust the `variables` parameter until results are accurate.
- Upload a test file that matches the configured format, confirm the interface returns a successful status with no format or size-related errors, and adjust the upload limit configuration until all target file types are supported.
- Review the `responseData` content returned by the interface, confirm only expected fields are included, and adjust the returned field configuration to meet business requirements.
- Initiate an upload request with a large file, confirm the interface does not time out or disconnect, and adjust the timeout setting to meet time consumption needs.
