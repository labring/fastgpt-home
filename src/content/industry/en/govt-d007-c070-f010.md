# Declaration Materials and File Review for Power Generation Equipment Manufacturing: Knowledge Base Retrieval and Recall

## What This Category of Data Looks Like
Declaration materials and file review data for power generation equipment manufacturing mainly comes from internal enterprise PDM systems, Feishu Docs, and local docx and xlsx files. Update rhythms follow project milestones: teams conduct concentrated updates before project declaration, and sync updates daily with quality inspection and operation records. Document structures include equipment model pages, technical parameter tables, approval workflow nodes, signature pages, and other elements. Fields cover rated power, service life, inspection report numbers, and similar items. Most units use specialized engineering units such as MW, hours, and pieces.

## Constraints for Knowledge Base Retrieval and Recall
The declaration materials and file review data for power generation equipment manufacturing includes large volumes of structured parameter tables, long-text design descriptions, and associated equipment drawings. Retrieval processes must adapt to structured content parsing and image-associated recall. Teams archive data by project, and documents from different projects have clear boundaries. Retrieval must limit scope to avoid cross-project interference. Specialized engineering units and fields require retrieval to match unit precision, preventing recall of documents with mismatched parameters.

## Three Common Configuration Errors
- Phenomenon: After importing docx or excel files, retrieval results cannot match equipment parameters in the table. Cause: Teams do not configure adapted retrieval parsing for structured tables, and only process content as plain text chunks.
- Phenomenon: Retrieval results include file records from other power generation equipment projects. Cause: Teams do not specify `collectionIds` to limit retrieval scope, and default to calling full knowledge base content.
- Phenomenon: After importing Feishu Docs, retrieval results only return text without associated drawing images. Cause: Teams do not enable image-associated recall configuration, and only extract text content from documents.

## How to Verify Correct Configuration
- Upload an excel test file containing rated power parameters, retrieve the parameter, and confirm recall results include the correct parameter values.
- Specify the archived collection ID of the current project, retrieve files and materials under the project, and confirm recall results only include documents from the corresponding project.
- After enabling `usingReRank`, compare retrieval result sorting, and confirm results with high parameter matching rank first.
- Upload a Feishu Doc containing equipment drawing images, retrieve the equipment model keyword, and confirm returned results include associated image links.

The values given are common starting points and should be measured against the reader's own samples.
