# State-owned Asset Management Company Declaration Materials and File Review: Knowledge Base Retrieval and Recall

## What this category of data looks like
Data for state-owned asset management company declaration materials and file review comes from multiple sources. These include declaration ledgers from state-owned asset supervision platforms, file documents from internal approval workflows, special reports issued by asset evaluation institutions, and scanned paper archives of property right registration. Data updates occur irregularly alongside annual state-owned asset audits and quarterly declaration batches, with no fixed cycle.
Most documents follow fixed template structures. They include fields such as the unified social credit code of the declaration entity, asset book value (unit: ten thousand yuan), approval node signature records, and state-owned asset supervision number. Some files are multi-page PDF or PPT formats, with embedded charts and table content.

## What constraints these characteristics bring to the knowledge base retrieval and recall link
Data sources are scattered across multiple internal systems. Retrieval must recall relevant content across multiple datasets.
Documents contain exclusive state-owned asset supervision terminology and structured fields. Retrieval must match both professional semantics and field information.
Long documents and multi-format files coexist. Parsing and chunking strategies must adapt to complex embedded content.
Update rhythm is irregular. The knowledge base must support incremental synchronization and batch updates.
Single review file has a large data volume. Recall results must control total context length to avoid exceeding model processing limits.

## Configuration Recommendations
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.85 | State-owned asset declaration materials contain exclusive professional terminology. This range filters low-match non-professional content and avoids irrelevant files interfering with the review process |
| `limit` | Top 8–12 results | Single declaration files involve multi-dimensional asset information. This range covers enough relevant documents while keeping total context length within model thresholds |
| `searchMode` | `vector` | Mixed content of structured fields (such as state-owned asset numbers and evaluation values) and unstructured text exists in declaration materials. Vector retrieval adapts to professional terminology matching |
| `usingReRank` | Enabled | Semantics may be scattered after long document chunking. Reranking improves the ranking priority of highly relevant fragments and optimizes the accuracy of review retrieval |
| `datasetSearchUsingExtensionQuery` | Enabled | Declaration materials often use abbreviations or industry jargon from state-owned asset supervision. Extended queries cover more synonymous terms and improve recall coverage |
| `collectionIds` | Specify dataset IDs corresponding to state-owned asset declaration files and evaluation reports | Non-business-related knowledge base content must be isolated to avoid recalling irrelevant documents and interfering with review judgments |

## Three Common Mistakes
- Phenomenon: When uploading PPT or PDF format state-owned asset declaration materials, knowledge base synchronization fails, and the interface displays "file parsing failed". Cause: The corresponding document format parsing plugin is not enabled, or the document is encrypted or contains a large number of high-definition images leading to parsing timeout.
- Phenomenon: When batch uploading declaration files, some files take more than 300 seconds to transcode, then a network failure prompt pops up. Cause: Single file size exceeds 100 MB, or the server's concurrent upload thread count is insufficient, leading to timeout interruption.
- Phenomenon: When deploying FastGPT v4.9.0 locally, there is no image understanding model option when creating a new knowledge base. Cause: This version does not integrate the image understanding model plugin by default, and the corresponding extension package must be manually installed to enable it.

## How to Confirm Proper Configuration
- Upload one state-owned asset declaration PDF file, check if the knowledge base parsing result includes core fields such as asset details and approval document number, confirm that format parsing is working normally.
- Initiate a query containing "state-owned asset number" and "evaluation value", check if the similarity scores of recall results fall within the preset 0.72–0.85 range, confirm that the similarity threshold is effective.
- After enabling `usingReRank`, compare the result ranking before and after reranking, confirm that highly relevant documents are moved to earlier positions, verify that the reranking function is working properly.
- After initiating a query, check if the returned results include the source identifier and fragment content of the recalled documents, confirm that knowledge base referenced content is output normally.
- Test batch uploading 5 or more declaration files, confirm that all files complete parsing and synchronization to the corresponding dataset, confirm that the batch upload function is working normally.

The configuration values listed above are common starting points, and should be evaluated against the reader's own samples.
