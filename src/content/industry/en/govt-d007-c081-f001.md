# Basic Chemicals Declaration Materials and File Review: HTTP Interfaces and External Systems

This page is written based on FastGPT v4.17.0.

## What the data for this category looks like
The declaration materials and file review data for basic chemicals mainly come from internal enterprise production ledgers, third-party laboratory testing systems, and submission ports of government regulatory departments. Data updates are adjusted according to project progress or quarterly archiving rhythms, with no fixed unified cycle. Documents mainly use a mixed structure, including structured raw material ingredient tables, compliance indicator tables, as well as unstructured PDF format test reports and Word format declaration instructions. Core fields include project number, raw material batch, test value, and compliance threshold. Corresponding units are mostly chemical industry-specific units such as mass percentage, molar concentration, megapascals, tons, and others.

## What constraints these characteristics impose on the "HTTP Interfaces and External Systems" link
Mixed structure documents require interfaces to support multi-format parsing and field verification, to avoid upload failures caused by format incompatibility. Specialized fields and units require interfaces to bind business-related `variables` parameters, to ensure that transmitted data such as test values and compliance thresholds conform to chemical industry format specifications. Batched update rhythms require interfaces to support dynamic parameter passing, which can flexibly adjust request content based on project number and raw material batch. The requirement to connect to external regulatory systems requires interfaces to configure the `Authorization` header for identity verification, while reserving sufficient timeout time to cover long document parsing processes.

## How to set configurations

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `Authorization` header configuration | Carry a Bearer-format system token | Meet the identity verification requirements of external regulatory systems |
| Request timeout | 600 seconds | Cover the complete process of uploading and parsing basic chemicals declaration materials |
| `variables` parameter binding | Bind project number and raw material batch fields | Match the batched declaration data update logic |
| `responseData` filtering rules | Only extract compliance test and file number fields | Focus on core business data required for review |
| Total file size for single upload | No more than 500 MB | Adapt to the average document size of basic chemicals declaration materials |
| Index chunking settings | Set chunk length based on actual measurement | Match the average character length of basic chemicals documents |

## Three common mistakes
- Symptom: CSV files uploaded via API cannot correctly map business fields, and audit results with empty fields are returned. Cause: The `variables` parameter is not configured according to the field order of the declaration materials, causing the system to fail to identify the corresponding relationship between raw material test values and compliance thresholds.
- Symptom: Timeout errors occur when calling the knowledge base interface to create a file collection, with a status code of 504. Cause: The request timeout is not set to adapt to the parsing duration of basic chemicals documents, exceeding the system default 120-second limit.
- Symptom: When querying audit results via the OpenAPI interface, the returned file data does not match the actually submitted content. Cause: No `responseData` filtering rules are configured, and redundant fields unrelated to review are returned, causing abnormal business logic statistics.

## How to confirm correct configuration
- Call the test interface to upload a CSV file of standard basic chemicals declaration materials, and check whether the returned `responseData` includes core fields such as project number and test value.
- View interface logs to confirm that the `Authorization` header is correctly carried, and no identity verification failure errors are present.
- Initiate a batch review request, and verify whether the number of returned results matches the number of submitted declaration material batches.
- Adjust the index configuration, upload a long document, and verify whether the parsing duration meets business expectations.
