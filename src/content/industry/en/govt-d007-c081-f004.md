# Basic Chemicals Declaration Materials and File Review: Workflow Orchestration

## What this category of data looks like
Data for basic chemicals declaration materials and file review mainly comes from internal enterprise environmental impact assessment reports, safety production license declaration documents, and quality inspection file archives. Updates are performed in batches according to project declaration cycles. Daily file archiving is updated monthly. Most documents are multi-page PDF files with fixed fields: project name, designed production capacity (unit: tons per year), environmental impact assessment approval document number, safety facility acceptance records, and test report number. Attachments often include test data tables with numerical units.

## What constraints these characteristics impose on workflow orchestration
Multi-page PDF structure requires configuring pagination parsing nodes in the workflow. This avoids field extraction errors caused by long text truncation. Fixed fields and unit requirements need preset verification rules. This ensures the format of production capacity, document numbers and other information in declaration materials is compliant. Batch update and archiving needs require setting batch processing nodes. This adapts to multiple file scenarios for single declarations. Unit differences in test data need unified conversion via global variables. This prevents review errors.

## How to set configurations
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Global variable settings | `{"project_cap_unit": "tons/year", "archive_cycle": "current month"}` | Matches the fixed units and archiving cycle of basic chemicals declaration materials |
| Node timeout period | 600 seconds | Adapts to the time required for multi-page PDF parsing and long text verification |
| Batch processing limit | First 20 items | Matches the typical number of files for a single basic chemicals declaration |
| `nodeId` binding | Bind by node function category | Ensures correct reference relationships between workflow nodes |
| Field verification rules | Preset required fields according to environmental impact assessment declaration templates | Covers mandatory review requirements for safety license and environmental impact assessment declarations in basic chemicals |
| `variables` call | Bind to all nodes that depend on fields | Enables unified unit conversion and cross-node reuse of archiving information |

## Three common misconfigurations
- Symptom: An error "Cannot read properties of undefined (reading 'incl')" appears when opening the workflow. Cause: The `variables` parameter is not configured correctly, causing the dependent fields referenced by the node to be uninitialized.
- Symptom: After updating global variables, subsequent workflow components cannot obtain the latest values. Cause: Variables are only modified in the global settings panel, and not bound to the input parameters of the corresponding nodes.
- Symptom: The number of results returned during batch file review does not match expectations. Cause: The batch processing limit setting does not match the typical number of files for a single basic chemicals declaration, and the parameter is not adjusted according to conventional project scale.

## How to confirm the configuration is correct
- Upload a standard basic chemicals environmental impact assessment declaration PDF, check if the field verification rule automatically identifies and marks missing required fields.
- Trigger a batch processing task, check if the `variables` parameter in the workflow log correctly loads the preset units and cycle values.
- Manually modify the global variables, then trigger subsequent review nodes, confirm that the component can obtain the updated variable values.
- Simulate a long text parsing task, check that the node timeout setting does not trigger a timeout error.

All recommended configuration values here are common starting points. Adjust them based on your own specific samples and requirements.
