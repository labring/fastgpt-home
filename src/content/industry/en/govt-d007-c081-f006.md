# Basic Chemicals Declaration Materials and File Review: Citation Sources and Traceability

This document provides configuration guidance and validation based on FastGPT v4.17.0.

## What this category of data looks like
Basic chemicals declaration materials and file data mainly come from internal enterprise project approval documents, safety production license application forms, third-party raw material test reports, compliance filing files, and similar sources. Data update rhythm adjusts with the approval, review, and archiving cycles of individual projects, with a single project material update cycle ranging from several weeks to several months. Most documents are structured forms paired with long-text process descriptions, including fields such as project number, production capacity parameters, raw material compliance certificates, and others. Some test documents use professional units such as ppm and MPa.

## What constraints do these characteristics impose on the citation sources and traceability link
The coexistence of structured fields and long-text process descriptions in basic chemicals declaration materials requires that traceability covers both field-level precise matching and full-text semantic association. Project materials are updated periodically, so traceability must ensure that the latest archived version is called. Some files contain internal compliance content, so the citation scope must be restricted to avoid sensitive information leakage. The text length of a single file is large, so the context carrying requirements of long-text traceability must be adapted to avoid citation truncation or context breaks.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Similarity Threshold | 0.6–0.7 | Basic chemicals declaration materials contain a large number of professional terms, requiring filtering of low-relevance search results |
| Single Search Limit | Top 8 entries | Single files have relatively rich content, avoiding excessive citations that cause context overload |
| `quoteMaxToken` | 8000–12000 token | Adapt to the traceability requirements of long-text process descriptions, ensuring complete citation of key content |
| Citation Data Return Format | Full document fragment + field annotation | Match the traceability display requirements of structured and long-text content |
| `detail` | Enabled | Display field information of the original document, facilitating reviewer verification of declaration content |
| `responseData` | Include source file path and update time | Ensure traceability information can be traced back to the latest archived materials |

## Three Common Misconfigurations
- Phenomenon: Field values of raw material test reports cannot be matched in search results, and the number of returned results is insufficient. Cause: The similarity threshold is set too low, filtering out relevant documents containing professional test terms.
- Phenomenon: The complete path and update time of the citation source are not displayed in the AI response. Cause: The source data return configuration corresponding to `responseData` is not enabled, and only text fragments are returned.
- Phenomenon: The response times out due to excessively long single citation text. Cause: The `quoteMaxToken` setting exceeds the system's carrying limit, failing to adapt to the length of basic chemicals long-text files.

## How to Verify the Configuration Is Correct
- Submit a test query containing professional terms, check the similarity ranking of returned results, and confirm that the threshold setting is effective.
- View the citation module in the AI response, confirm that it includes the complete path and update time of the source file.
- Check the length of the cited text fragment, confirm that it does not exceed the `quoteMaxToken` setting value.
- Upload an updated test document, initiate a query, and confirm that the returned traceability information is the latest version.

The values provided are common starting points and should be measured against the reader's own samples.
