# Basic Chemicals Declaration Materials and File Review: Document Parsing and Chunking

## What the data for this category looks like
Data for basic chemicals declaration materials and file review originates primarily from official documents used in enterprise project approval, safety reviews, pollutant discharge permit applications, and similar scenarios. It is generated in batches when projects launch, during compliance annual audits, or during special inspections.
Most documents use fixed template formats, including application forms, third-party test reports, process flow diagrams, material balance sheets, qualification certification documents, and more. Fields cover process parameters such as reaction temperature, pressure, and material ratio, plus compliance information like approval document numbers and qualification IDs. Units follow chemical industry standards, such as ℃, MPa, kg, m³, and others.

## Constraints imposed by these characteristics on document parsing and chunking
Basic chemicals declaration materials often include single PDF documents larger than 10MB, with numerous nested tables and long paragraph process descriptions. Standard parsing and chunking rules frequently cause timeouts, split tables incorrectly, or lose contextual information.
Fixed document structures require parsing rules adapted to exclusive templates. Without such adaptation, accurate extraction of qualification fields and process parameters fails.
Batch declaration materials with multiple attachments consume more parsing resources. Adjust upload and parsing limit configurations to avoid forced task termination.

## How to set configurations
This page’s configuration is based on FastGPT v4.17.0. Specific configuration items and their rationales are listed below:

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Basic chemicals declaration materials include long process descriptions and paragraphs with attached tables. This range preserves complete context for a single set of material balance or safety indicators |
| `chunkSplitter` | Split by paragraph + table boundaries | Tables and process descriptions are strongly linked in basic chemicals documents. Splitting by paragraph risks destroying table integrity |
| `customPdfParse` | Enabled | Basic chemicals declaration materials often include PDFs with vector process flow diagrams. Custom parsing preserves text information associated with graphics |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600–900 seconds | Parsing large chemical declaration PDFs over 10MB takes a long time. The default duration is insufficient and may trigger timeouts |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | A single basic chemical project declaration material may include multiple attachments, with a total size of hundreds of megabytes |
| `chunkSettingMode` | Manual configuration | Basic chemicals documents have fixed structures. Manual configuration allows adaptation to exclusive chunking and parsing rules |

## Three common mistakes
- When uploading a 10+ MB PDF declaration material, a timeout error occurs. The cause is failure to adjust the `PARSE_FILE_TIMEOUT_SECONDS` parameter. The default timeout duration does not cover the parsing time required for large documents.
- Some docx format file review documents cannot be parsed normally. The cause is failure to enable `customPdfParse` to adapt to complex nested tables. Nested process tables in basic chemicals documents cannot be recognized by the default parsing engine.
- Some tables in the knowledge base cannot be chunked correctly. The cause is that `chunkSize` is set too small, which splits complete material balance tables into scattered fragments and loses context association between parameters.

## How to confirm proper configuration
- Upload a single chemical declaration PDF over 10MB, check that the parsing task completes within the preset timeout without timeout errors.
- Upload a docx document containing nested process tables, check that the chunked content after parsing retains the complete table structure with no scattered cell fragments.
- Search for process parameters or qualification IDs in the knowledge base, check that returned results are complete paragraphs or tables with no truncated or missing content.
- Adjust the `chunkSize` parameter, compare chunking results across different values, confirm that complete context of process descriptions and associated tables is preserved.
