# Infrastructure Construction Declaration Materials and File Review: Knowledge Base Retrieval and Recall

## What This Category of Data Looks Like
Infrastructure construction declaration materials and file review data mainly come from project initiation approval documents, bidding documents, construction progress archives, completion acceptance reports, and budget and final account documents. Data updates are carried out in batches according to project phases. Initial declaration materials are uploaded during the project initiation phase, progress ledgers are updated synchronously during the construction phase, and complete files are archived after completion. Documents include structured fields and unstructured content. Structured fields include project number, construction unit, floor area (unit: square meters), contract duration (unit: days), and other items. Unstructured content includes Word declaration forms, PDF approval documents, CAD drawing scans, and other image format materials.

## Constraints Imposed on Knowledge Base Retrieval and Recall by These Characteristics
The characteristics of infrastructure construction declaration materials and file review data impose multiple constraints on the retrieval and recall link. First, mixed structured fields and unstructured content including images and long documents require retrieval to support both exact field matching and multi-format content parsing. Second, dense professional terminology and a large number of industry abbreviations require query expansion to cover related terms. Third, data between projects must be strictly isolated to avoid cross-project retrieval interfering with review results. In addition, batch-updated data requires support for incremental upload and batch isolation to prevent mixing of old and new data.

## Configuration Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | Infrastructure declaration materials contain a large number of professional terms. This range filters low-relevance results while retaining valid matches for targeted use cases. |
| `limit` | `Top 8 entries` | File review requires comparing multiple related materials. 8 results cover common comparison needs and avoid excessive results increasing review burden. |
| `searchMode` | `Hybrid Retrieval` | Supports both structured field matching and unstructured text retrieval, adapting to the mixed data structure of declaration materials. |
| `usingReRank` | `Enabled` | There are many professional terms in infrastructure construction. Reranking improves the accuracy of result relevance sorting and optimizes the recall order of professional content. |
| `datasetSearchUsingExtensionQuery` | `Enabled` | There are a large number of engineering abbreviations and professional terms in declaration materials. Query expansion supplements related vocabulary and improves recall coverage. |
| `collectionIds` | `Bind exclusive collection IDs by project batch` | Materials from different construction projects do not interfere with each other. Isolating by batch avoids cross-project retrieval interfering with review results.

## Three Common Configuration Mistakes
- Phenomenon: Uploaded CAD drawing scan files cannot be retrieved for relevant content. Cause: OCR parsing configuration for image format files is not enabled, only plain text declaration materials are indexed.
- Phenomenon: Retrieval results include file materials from other construction projects. Cause: Exclusive dataset is not bound via `collectionIds`, resulting in cross-project data being recalled simultaneously.
- Phenomenon: The number of relevant results returned by retrieval is far lower than expected. Cause: The `similarity` threshold is set too high, filtering valid materials matched by professional terms.

## How to Verify Correct Configuration
- Upload a test declaration material containing CAD scans, perform a retrieval including drawing keywords, confirm that the test material can be recalled.
- Enter a retrieval term with a specific project number, confirm that only declaration materials of the corresponding project are returned, with no cross-project results mixed in.
- Adjust the `similarity` threshold to the specified range, check whether the relevance of retrieval results meets review requirements.
- After enabling `usingReRank`, compare the result sorting before and after reranking, confirm that results related to professional terms rank higher.

The values provided are common starting points and should be measured against the reader's own samples.
