# Bulk Commodity Trade Declaration Materials and Case Review: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Bulk commodity trade declaration materials and case review data come primarily from trade contracts, customs declarations, quality inspection reports, warehouse receipts, and fund settlement vouchers. Data updates trigger per individual trade business node. Teams archive and update single declaration materials after review completion. Teams integrate and archive cases in monthly batches. Single documents are mostly multi-page PDFs or structured tables, containing fields including goods name, HS code, transaction quantity, settlement amount, and customs port. Quantity units are mostly tons or cubic meters. Amount units are RMB or USD. A single case can link to dozens of materials.

## What constraints these characteristics impose on knowledge base retrieval and recall
The data characteristics of this category create four core constraints for retrieval and recall. First, the data includes professional structured fields such as HS code and transaction quantity. Support field-level precise matching to avoid generic recall of irrelevant materials. Second, a single case links to dozens of related materials. Aggregate recall results by case dimension to avoid returning duplicate single materials. Third, data updates with each individual business node. Enable incremental synchronous updates for the knowledge base, so it covers the latest declaration materials without full refresh. Fourth, multiple quantity units exist such as tons and cubic meters. Associate unit fields for verification during retrieval to improve matching accuracy.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | `0.72–0.85` | Bulk commodity declaration materials contain professional terminology. A threshold that is too low introduces irrelevant materials, while a threshold that is too high fails to recall compliant materials with sufficient matching degree. This aligns with the parameter rules for FastGPT v4.17.0. |
| `limit` | Top 12–18 results | A single case links to many materials. Recall enough results to cover related items, while avoiding exceeding the model's context processing limit. |
| `searchMode` | `vector+keyword` | Balances semantic matching for professional terminology and precise matching for structured fields such as HS code, improving recall comprehensiveness. |
| `usingReRank` | Enabled | Declaration materials have high similarity. Re-ranking filters results that are semantically close but business irrelevant, improving retrieval accuracy. |
| `datasetSearchUsingExtensionQuery` | Enabled | Expand declaration keywords into extended queries including HS code and trading subjects, matching case materials more precisely. |
| `collectionIds` | Bind the collection ID of the corresponding bulk commodity trade case knowledge base | Limit the retrieval scope to the dedicated knowledge base, avoiding mixing in irrelevant data from other categories. |

## Three common mistakes
- Observed issue: Garbled Chinese characters appear in structured declaration material CSV files after import. Root cause: UTF-8 encoding format was not specified during import, or the encoding of the local source file does not match the import configuration.
- Observed issue: An unauthorized access error returns when calling the retrieval interface, while authentication parameter configuration is correct. Root cause: The retrieval node was not bound to the permission group of the corresponding business role, or the `collectionIds` configuration includes unauthorized knowledge base collections.
- Observed issue: Specified case materials can be recalled in online conversations, but no corresponding results return when calling the API. Root cause: The API call did not pass variable parameters associated with the current business, preventing `datasetSearchUsingExtensionQuery` from generating precise extended queries.

## How to confirm the configuration is correct
- Upload a single bulk commodity customs declaration CSV file, check that imported fields display fully and Chinese characters are not garbled.
- On the retrieval node configuration interface, confirm that `collectionIds` binds to the corresponding business knowledge base collection, with no extra collections included.
- Initiate a test retrieval, enter a keyword that includes an HS code, check that recall results aggregate by case dimension with no duplicate materials.
- Call the API interface, pass the same context variables as used in online conversations, and compare returned results with the matching degree of online conversation results.

The values provided are common starting points and should be measured against the reader's own samples.
