# Engineering Consulting Supervision Declaration Materials and File Review: Document Parsing and Chunking

## What the data for this category looks like
Engineering consulting supervision declaration materials and file review data originate from official documents submitted during project approval, construction preparation, on-site supervision, and completion acceptance stages. Updates follow project milestone phases. The total number of accumulated files for a single project cycle grows with project scale. Most documents use unified engineering supervision templates released by the Ministry of Housing and Urban-Rural Development. These templates have fixed sections including basic project information, supervision plans, progress reports, and acceptance files. Fields include project number, contract amount, supervision scope, and total construction period. Units use standard engineering measurements such as ten thousand yuan, days, and square meters. Some documents include PDF drawings exported from CAD and nested tables.

## Constraints Imposed on Document Parsing and Chunking
Engineering consulting supervision declaration materials and files use fixed template structures. Chapter numbers are tightly linked to professional content. Random character-based chunking breaks logical connections between professional paragraphs. Single files often include dozens of pages of long text and nested tables. Parsing takes longer, and chunk length must match professional content length. Document ends often include reference materials such as industry specifications and design files. Extraction of the corresponding references field must match engineering document reference formats to avoid missing key references. Single files for large-scale projects can reach hundreds of MB. This creates adaptation requirements for upload and parsing limit settings.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Most engineering declaration materials contain long paragraphs and professional tables. This range preserves core information of a single chapter without breaking logical connections |
| `chunkSplitter` | Split by chapter titles | Documents come with standard chapter numbers. Splitting by titles preserves content integrity and logical connections |
| `customPdfParse` | Enabled | Most declaration materials contain nested tables and professional symbols. Enabling custom parsing preserves format and field information |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Single files often exceed 50 MB. Sufficient timeout time is required to complete full parsing |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Single files for large-scale project files can reach hundreds of MB. The upload limit needs to be relaxed to meet business requirements |
| `chunkSettingMode` | Manual configuration | Adjustments to chunking rules for engineering documents are needed to avoid automatic chunking damaging professional content structure |

## Three Common Misconfigurations
- Issue: The references field is empty or not fully extracted after parsing. Cause: The reference extraction switch for custom PDF parsing is not enabled. Engineering document references use standard number formats. Default parsing rules cannot accurately identify these formats.
- Issue: The pdf-marker function works normally when deployed locally, but no parsing option appears for uploaded PDFs in the FastGPT knowledge base. Cause: The pdf-marker service address is not linked in FastGPT configuration, or container port mapping is configured incorrectly.
- Issue: Modifying the default maximum chunk length has no effect. Cause: The chunk parameter file in the source code is edited directly, instead of adjusting the `chunkSize` parameter via the visual configuration interface provided by FastGPT v4.17.0.

## How to Verify Correct Configuration
- Confirm that FastGPT v4.17.0 is the active version. Older versions may have incompatible parameter configurations.
- Upload a single engineering declaration PDF under 100 MB. Check that parsed text retains complete chapter numbers and professional parameter information.
- View system parsing logs. Confirm that the references field has extracted the list of industry specification references from the end of the document.
- Adjust `chunkSize` to 500 characters, upload a test document, and confirm that chunked paragraph lengths match the set range.
- Check that `UPLOAD_FILE_MAX_SIZE` in system settings exceeds the single-file size threshold for commonly used engineering project files.

The values provided here are common starting points and should be evaluated against the reader's own samples.
