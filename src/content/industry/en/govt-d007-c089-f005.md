# Construction Machinery Declaration Material and File Review: Tool Calling and Plugins

All configuration instructions on this page apply to FastGPT v4.17.0.

## What Data for This Category Looks Like

Data for construction machinery declaration materials and file review mainly comes from equipment factory certificates, monthly maintenance records, project acceptance documents, qualification filing documents, and similar sources. Static data such as factory parameters and filing numbers is updated when models are launched and put on the market. Dynamic data such as maintenance duration and operating conditions is updated monthly or quarterly. The document structure includes two parts: structured fields and attachments. Structured fields include equipment number, rated lifting capacity, rated power, working radius, and similar items, with units of piece, ton, kW, and meter respectively. Most attachments are PDF-format drawings, videos, or paper scans.

## Constraints Imposed on the Tool Calling and Plugins Link

Standardized structured fields require tool calling to accurately match preset fields, to avoid field misalignment caused by fuzzy parsing. There are various attachment types and significant differences in file sizes. Plugins must adapt to multiple formats such as PDF and CAD drawings, and also limit the single-file processing upper limit. The update cycles of static and dynamic data differ. Tool calling must distinguish caching strategies for data sources: static qualification data can be cached for a long time, while dynamic maintenance data requires a shortened caching cycle. Fields come with fixed units. Plugins must add an additional unit verification step to ensure consistency of review results.

## How to Configure the Settings

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `toolChoice` | `auto` | Adapt to field parsing for multiple types of construction machinery declaration materials, no need to manually specify tool types |
| `functionCall` | Enabled | Supports structured extraction of standardized fields such as equipment number and rated lifting capacity, improving review accuracy |
| Single tool call timeout | `120 seconds` | Construction machinery declaration materials include multiple drawing attachments, which take a long time to parse, to avoid mid-run interruptions |
| Tool call result caching duration | `7 days` | Factory qualification data has a long static update cycle, caching reduces repeated call overhead |
| Attachment parsing plugin trigger threshold | `Single file size ≤ 1000 MB` | Attachments such as construction machinery CAD drawings and maintenance videos have large sizes, limiting this avoids resource overload |
| Number of tool call results returned | `Top 5 entries` | File review only requires core parameters and latest attachment information, too many results increase processing burden |

## Three Common Misconfigurations

- Phenomenon: A specific error message is returned when calling the tool chain via API, but the interface test runs normally. Cause: The API request does not carry correct plugin authentication parameters, or the deployment environment has not opened the plugin access port.
- Phenomenon: Empty results are returned when parsing construction machinery CAD drawing attachments. Cause: No dedicated parsing plugin adapted to CAD format is configured, and only default text file parsing is used.
- Phenomenon: Inconsistent units appear in fields returned by tool calls, such as rated power appearing as both kW and horsepower. Cause: No unit verification plugin is enabled, and no standardized conversion is performed on the fields.

## How to Confirm the Configuration Is Complete

- Upload a PDF of a construction machinery factory certificate, trigger tool calling, and check whether the returned results include required fields such as equipment number and rated lifting capacity.
- Call the API to initiate a single file review request, compare the returned results of the interface test and API call to confirm that the two outputs are consistent.
- Upload a CAD drawing attachment with a size of 800 MB, trigger parsing, and confirm that the tool call is not blocked due to exceeding the volume limit.
- Simulate batch calls of 10 file review requests, check whether the tool call timeout time meets the preset value, and there is no abnormal interruption.
