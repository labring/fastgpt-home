# Engineering Machinery Declaration Materials and File Review: Citation Sources and Traceability

## What This Category of Data Looks Like
Data for engineering machinery declaration materials and file review mainly comes from enterprise equipment management systems, factory qualification certificate databases, and government special equipment supervision platforms. Update frequency adjusts based on business nodes. Factory qualification data is generated synchronously when equipment is commissioned. Daily maintenance records are updated monthly. Annual inspection reports are refreshed each calendar year.

Each document mostly uses the format of structured fields plus attachments. It includes fields such as equipment number, model, rated lifting weight (unit: ton), manufacturing date, maintenance unit, and annual inspection validity period. Some file materials contain multi-page scanned documents and seal information.

## What Constraints Do These Characteristics Impose on the Citation Sources and Traceability Link
The coexistence of structured fields and attachments in engineering machinery declaration materials requires distinguishing between metadata and scanned document text during traceability. This prevents mixing different source types in retrieval results.

Differences in update frequencies across data sets require associating data generation times with business nodes during traceability. This filters expired annual inspection or maintenance records.

The equipment number as the unique identification field requires binding traceability logic to this field and the corresponding declaration file. This ensures review materials for a single device are not confused with those of other devices.

The presence of multi-page sealed scanned documents requires retaining attachment storage paths and seal verification information. These serve as the core basis for traceability.

## Configuration Settings
| Configuration Item | Recommended Value Range | Rationale |
| ---- | ---- | ---- |
| Similarity Threshold | 0.75–0.85 | Engineering machinery declaration materials use mostly professional terms. This range filters lowly relevant non-equipment retrieval results to avoid mistakenly referencing unrelated files. |
| Single Search Limit | Top 8 Entries | Declaration materials for a single device typically do not exceed 7 copies. Retaining 2 extra entries ensures coverage of complete review basis. |
| Reranking | Enabled | When mixing structured fields and attachment text in retrieval, reranking prioritizes matching core review fields. This improves traceability accuracy. |
| Maximum Context | 1200–1500 Characters | The core text of a single declaration material is usually around 1000 characters. This range reserves extra space to avoid truncating critical seal or parameter information. |
| `quoteMaxToken` | 800 token | This parameter in FastGPT v4.17.0 controls the total token count of citation fragments. It adapts to the average length of engineering machinery declaration materials to avoid overflow. |

## Three Common Misconfigurations
- Phenomenon: Retrieval results are empty after enabling reranking, and the citation source field displays no content. Cause: The reranking relevance filtering threshold is set too high. This filters all matching structured fields and attachment text, resulting in no valid retrieval fragments.
- Phenomenon: A timeout prompt is returned when submitting a review request, and the interface shows a 504 status code. Cause: The `quoteMaxToken` parameter is not adjusted. The total length of citation fragments exceeds the system processing limit, causing the request to time out.
- Phenomenon: Referenced file materials do not match the device model being declared. Cause: The equipment number is not bound as a retrieval filtering condition. This leads to mistakenly referencing declaration materials from other devices.

## How to Verify Correct Configuration
- Submit a declaration review request for a single specific device. Check the citation source field in the returned results to confirm only materials related to this device are included.
- Enable the reranking function. Check whether retrieval results sort by priority matching core review fields such as device model and rated lifting weight.
- Check the actual call value of `quoteMaxToken` in the system log. Confirm it does not exceed the preset maximum context limit.
- Check the `responseData` field in the returned results. Confirm the storage path and seal information of the citation source are fully returned.
- Check whether the `detail` field includes binding information for the equipment number. This ensures the traceability logic is correctly associated.
