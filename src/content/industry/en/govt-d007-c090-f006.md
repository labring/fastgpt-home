# Declarations and File Review for Refined Petroleum Product Sales: Citation Source and Traceability

## What the data for this category looks like
Refined petroleum product sales declaration and case file data primarily comes from gas station POS transaction systems, oil product purchase ledgers, inventory check reports, and internal approval circulation documents.
Data update frequency aligns with business nodes. Individual sales transactions generate corresponding case entries in real time. Monthly summary declaration materials are updated at the end of each month.
Each case file document includes structured fields such as transaction serial number, oil product grade, sales volume (liters/ton), unit price, payment voucher number, and approval node records. Some approval materials include scanned signed vouchers.
Field units uniformly follow metrology specifications for the petroleum and petrochemical industry.

## Constraints imposed by these characteristics on citation source and traceability
Individual sales transactions generate dense case entries in real time. The citation traceability link must limit the recall time window and business scenarios, to prevent irrelevant data from interfering with context.
Some approval case files include scanned signed vouchers. Traceability must support associative traceability between OCR-recognized text and structured transaction fields, to ensure cited content matches original vouchers one-to-one.
Monthly summary declaration materials include multiple cross-cycle documents. Traceability must support parallel recall of multiple files and cross-document data association.
Unified metrology field units in the petroleum and petrochemical industry require the traceability link to automatically match units, to prevent citation deviations caused by unit conversion.

## Three common errors
- Phenomenon: A `quote type error` is thrown during invocation, and the interface prompts that the input variable format is abnormal. Cause: Reference variables are not configured per the structured field format of petroleum and petrochemical industry case files, and non-standard field names or unit parameters are used.
- Phenomenon: Batch traceability results do not include corresponding file names, only text content is displayed. Cause: The `responseData` configuration item is not enabled correctly, and the return file path field is not specified.
- Phenomenon: Citation content returned by the large model does not match the original case files, and incorrect cross-transaction associations occur. Cause: The recall time window and business scenarios are not limited, and irrelevant sales case entries are recalled.
