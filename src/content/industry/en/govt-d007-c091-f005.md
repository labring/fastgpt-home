# General Construction Engineering EPC Declaration Materials and File Review: Tool Calling and Plugins

## What the Data for This Category Looks Like
The data for general construction engineering EPC declaration materials and file review comes primarily from housing and urban-rural development department approval systems, internal enterprise construction ledgers, project approval documents, and phased supervision reports. Data updates align with project approval nodes, and triggers when new declaration materials are submitted or file content is revised. A single file includes fixed structured content: basic project information, construction qualification documents, capital certificates, construction plans, supervision logs, and more. Standardized fields include project number, construction location, investment amount (ten thousand yuan), construction area (square meters), construction period (calendar days). Some qualification documents include unique codes.

## Constraints on Tool Calling and Plugins from These Data Characteristics
The characteristics of this data create clear constraints for the tool calling and plugins workflow. Data sources are scattered, covering housing and urban-rural development approval systems, enterprise construction ledgers, supervision reports, and other channels. Plugins must support multi-source data integration. File fields are standardized but broad in scope, so tools must adapt to parameter verification for specific formats such as project numbers, qualification levels, and investment amounts. Single files can be large; some project declaration materials include dozens of documents, so tools need to support batch parsing and batch processing. Approval nodes are clearly defined, so tool calling must tie to project workflows to avoid invalid triggers.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Tool call timeout | 1200 seconds | A single document in construction project declaration materials can reach hundreds of pages, so full parsing requires a long duration |
| `toolChoice` | auto | Adapt to the changing audit node requirements in declaration materials, automatically select the corresponding tool |
| `functionCall` | Force parameter completion | Ensure that required fields such as project number and qualification level required for review are not missing |
| Batch call limit | First 8 documents | Too many audit materials in a single batch will cause context overflow, which matches the typical number of declaration materials for construction projects |
| Single tool return result limit | First 10 entries | Avoid overloading the context by returning too much file information |
| Parameter verification switch | Enabled | Match the fixed format requirements of construction project declaration material fields, reduce invalid calls |

## Three Common Configuration Errors
- After upgrading fastgpt-mcp-server, the service fails to start. Symptoms include a port occupation error during startup or immediate process exit. The root cause is that the new mcp-server version changed the configuration file path, and system environment variables were not updated synchronously.
- Calling MCP tools interrupts the context. Symptoms include lost conversation history or a cleared context window. The root cause is that context retention was not enabled during tool calling, or tool return results were not correctly spliced back into the context.
- Multi-parameter MCP calls cannot supplement missing parameters. Symptoms include a tool call error indicating missing required fields. The root cause is that no parameter collection node was configured in the workflow, so users were not guided to provide required parameters such as project number and qualification level.

## How to Confirm Successful Configuration
- Start the FastGPT v4.17.0 service and the associated MCP plugin service. Verify that system logs show no tool initialization failure errors.
- Upload a standard general construction engineering EPC declaration material, trigger the tool calling workflow, and confirm that required fields such as qualification and capital are correctly identified and corresponding tools are called.
- Configure a multi-parameter call node in the workflow, submit a test request, and confirm that the system prompts for missing required parameters.
- Adjust the tool call timeout to 1200 seconds, upload a large-volume declaration material, and confirm that the call process does not experience timeout interruptions.
