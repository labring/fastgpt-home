# Declaration Materials and Case File Review for New Energy Development: Deployment and Upgrade

## What the data for this category looks like
Data for new energy development declaration materials and case file review originates primarily from official approval documents. These include project establishment applications, land use space pre-examination opinions, environmental impact assessment reports, grid connection acceptance documents, and similar materials. Data updates align with project approval milestones, with 1 to 3 updates during a single approval cycle. Each document is typically a 10 to 50 page PDF or Word file. It contains fixed fields such as project name, construction location, installed capacity (unit: MW), total investment (ten thousand yuan), declaration entity, and approval progress. Some case files include on-site survey photos and satellite image attachments.

## Constraints Imposed on Deployment and Upgrade
Single new energy development declaration materials have large file sizes and multiple types of attachments. Reserve sufficient file storage and parsing resources during deployment. Data fields include numeric content with fixed units. When upgrading the database, confirm compatibility between field types and unit verification rules. Phased project approval updates require deployed synchronization tasks to support incremental pulling and version retention. This prevents full-volume repeated processing. Cross-departmental case file circulation requires cross-node permission and data synchronization rule configuration. Retain compatibility with original permission configurations during upgrades.

## Configuration Recommendations
These configurations apply to FastGPT v4.17.0.

| Config Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150 connections` | Adapts to database connection concurrency requirements during parsing of long single documents, and avoids connection exhaustion |
| `MONGODB_URI` | `mongodb://username:password@host:port/dbname?authSource=admin` | Stores case file metadata and approval records. Configure authentication information to ensure data security |
| `STORAGE_S3_ENDPOINT` | `https://s3-cn-beijing.volces.com` (or corresponding private storage node address) | Stores large attachments such as declaration material PDFs and images, and adapts to multi-type file storage requirements |
| `REDIS_URL` | `redis://:password@host:port/0` | Caches parsed document shards and approval statuses, and improves retrieval response speed |
| `FE_DOMAIN` | `https://fastgpt.your-domain.com` | Configures the frontend access domain, and adapts to docking requirements with internal approval systems |
| `ROOT_KEY` | `Custom complex string` | Configures the system's highest permission key, and ensures initial permission security after deployment |

## Three Common Misconfigurations
- Issue: Image pull timeout or `manifest unknown` error. Cause: Using an unofficial FastGPT image tag, or failing to configure a domestic mirror acceleration source to adapt to network environments.
- Issue: Missing fields or unit verification failure after importing declaration materials. Cause: Not configuring format verification rules for corresponding fields, resulting in numeric fields failing to complete format conversion per units such as MW and ten thousand yuan.
- Issue: `internal server error` prompt when importing approval plugins. Cause: Failing to synchronously update environment variable configurations relied on by plugins after upgrading, resulting in plugin incompatibility with the current system version.

## How to Verify Configurations
- Run the database connection test script to verify connectivity for the `MONGODB_URI` and `REDIS_URL` configurations, and confirm that the number of connections does not exceed the `DB_MAX_LINK` limit.
- Upload a sample document of new energy development declaration materials to trigger the parsing process, and confirm that attachments can be properly stored to the storage node corresponding to `STORAGE_S3_ENDPOINT`.
- Access the frontend address configured for `FE_DOMAIN`, and verify that the page loads normally without resource loading failure prompts.
- Configure an incremental synchronization task, upload an updated case file material, and confirm that the system can identify version differences and complete incremental processing.

The values provided are common starting points and should be measured against the reader's own samples.
