# Filing Material and Case Review for Oilfield Engineering Services: Knowledge Base Retrieval and Recall

Reference only; verify against the target FastGPT release and deployment documentation.

## What This Type of Data Looks Like
Filing materials and case review data for oilfield engineering services mainly come from project initiation applications, construction plans, acceptance case files, qualification certificates, engineering quotation sheets, and other documents. The data update rhythm is adjusted according to project progress: full batch upload of all materials when the project starts, and incremental updates during construction adjustments or quotation changes. Documents include structured fields and unstructured content. Structured fields include project number, well ID, operation type, budget amount, etc., with units such as meters, cubic meters, ten thousand yuan, and other professional engineering units. Unstructured content is mostly long-text documents in PDF or Word format, such as construction plans.

## Constraints Imposed on Knowledge Base Retrieval and Recall
Professional fields and units require retrieval results to accurately match engineering terminology, preventing generic documents from interfering with review judgments. The coexistence of long-text construction plans and short-document quotation sheets requires the recall mechanism to balance core paragraphs of long documents and full content of short documents. Batch-updated data per project requires the retrieval scope to be limited to the current project’s exclusive knowledge base set, avoiding cross-project data confusion. The core requirement of compliance review requires retrieval results to prioritize document content that meets safety and technical standards, filtering irrelevant historical records.

## How to Set Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.72–0.85 | Oilfield engineering filing materials contain a large number of professional terms. This range filters out irrelevant generic documents and retains accurately matched professional content |
| `limit` | Top 10 entries | Case review requires covering multi-dimensional supporting materials. 10 entries balance recall breadth and the reasonable length of single-round context |
| `searchMode` | vector_only | Filing materials are mostly structured and semi-structured content. Pure vector retrieval avoids terminology ambiguity caused by keyword matching |
| `usingReRank` | Enabled | Long-document construction plans require secondary sorting to ensure core compliance clauses and key technical parameters are recalled first |
| `datasetSearchUsingExtensionQuery` | Enabled | Can supplement professional term expansion, for example, expanding "cementing operation" to "oil well cementing construction" to match more professional documents |
| `collectionIds` | Fill in the knowledge base set ID associated with the project | Only retrieve filing and case data for the current project, preventing irrelevant cross-project data from interfering with reviews |

## Three Common Misconfigurations
- An API error is returned after calling the knowledge base document insertion API. Cause: The `collectionIds` parameter was not filled in according to the exclusive classification of oilfield engineering projects, causing the system to fail to locate the target knowledge base set.
- Searching a single engineering quotation sheet takes more than 30 seconds, and page loading is stuck. Cause: A reasonable value for the `limit` parameter was not set, and excessive cross-project case data was recalled, increasing the computational overhead of vector retrieval.
- Two associated knowledge bases are hit by the same query, but only one result is returned. Cause: The multi-knowledge base result merging logic was not enabled, or the retrieval scope was not correctly configured to cover both target sets.

## How to Confirm the Configuration Is Correct
- Call the document insertion API, upload an oilfield engineering construction plan document, and check whether the knowledge base backend displays that the document is associated with the specified project set.
- Enter the query "Compliance requirements for a certain well cementing operation" and check whether the retrieval time meets business expectations with no obvious lag.
- Associate two knowledge bases containing engineering quotations at the same time, enter the query "2024 fracturing service quotations", and confirm that the returned results include matching content from both knowledge bases.
- Adjust the `similarity` parameter to 0.8, and check whether the retrieval results filter out non-professional generic documents and only retain content related to oilfield engineering.
