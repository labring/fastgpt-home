# Coal Chemical Industry Declaration Materials and Case Review: Workflow Orchestration
This configuration guide is based on FastGPT v4.17.0.

## What this category’s data looks like
Coal chemical industry declaration materials and case review data mainly comes from internal project declaration systems, coal industry capacity approval platforms, and safety supervision reporting systems. Data update frequency adjusts with project progress. Single declaration material uploads can reach dozens of copies. Case review requires linking historical approval records. Document structure includes fields such as project name, approved capacity, environmental impact assessment filing number, coal extraction volume, declaration subject qualification number. Units include ten thousand tons, cubic meters, tons, and others. Some cases require electronic versions of paper scanned documents.

## Constraints on workflow orchestration
Large single-batch quantities of coal chemical declaration materials, plus the requirement for electronic scanned copies for some cases, mean workflows must support batch file processing and file stream parsing. Fields involve multiple professional units, so workflows need built-in field verification rules to avoid review errors from mismatched units. The need to link historical approval cases requires workflows to configure `variables` to call historical data interfaces. Cross-system data synchronization delays must also be addressed, so the number of parallel nodes per workflow is limited. Each review node must have a unique `nodeId` to avoid node conflicts that disrupt process execution.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Variable configuration | Define `variables` split by declaration links, including project ID, case number, capacity data fields | Coal chemical declaration materials have many fields; splitting variables simplifies verification logic |
| Number of files processed per single run | First 10 copies | Single-batch declaration materials usually do not exceed 10 copies, avoiding excessive node load |
| File stream processing node | Enable document/image parsing plugin | Some cases include scanned copies, requiring parsing of file stream content |
| Workflow timeout period | 600 seconds | Single-batch material review requires multiple rounds of verification, reserving sufficient processing time |
| Node trigger rule | Trigger in order of approval nodes | Coal chemical review follows a fixed process; skipping steps is not allowed |
| Knowledge base retrieval switch | Allow users to choose whether to enable it | Some declaration materials already have historical case data, so retrieval can be skipped as needed |

## Three Common Configuration Mistakes
- Phenomenon: Workflow node returns "Unable to parse file content" error. Cause: File stream processing node is not configured, and image format case scanned documents are directly passed to text review nodes, resulting in failure to read file stream data.
- Phenomenon: Workflow trigger order is chaotic, with some review nodes executing out of sequence. Cause: Node trigger rules are not configured according to the fixed coal chemical approval process, and parallel trigger logic is used.
- Phenomenon: Field verification fails, returning "Missing parameter" error. Cause: All required fields for coal chemical declaration are not defined in `variables`, resulting in empty parameters when nodes are called.

## How to Confirm the Configuration Is Correct
- Upload a single batch of 10 coal chemical declaration materials, and check if the workflow triggers in the preset approval node order.
- Adjust variable settings, and test whether the knowledge base retrieval link can be skipped as needed.
- Upload image format case scanned documents, and check if file stream content can be parsed normally.
- View workflow operation logs, confirm that the timeout period setting takes effect, and no node timeout errors occur.

The values provided are common starting points and should be measured against the reader's own samples.
