# Coal Chemical Industry Declaration Materials and File Review: Deployment and Upgrade

## What the data for this category looks like
Coal chemical industry declaration materials and file review data mainly comes from official submission documents and archived files from project approval, environmental impact assessment, safety acceptance, and other stages. The update rhythm progresses in stages along with project approval nodes.
A single file includes basic project information forms, process flow diagrams, material balance reports, environmental protection measure plans, approval opinion pages, and other content. Fields include fixed-format project numbers, production capacity units (ten thousand tons/year), coal type classifications, approval level identifiers. Some documents are a mix of dozens of pages of structured tables and unstructured drawings.

## What constraints these characteristics impose on the deployment and upgrade link
The mixed document structure and staged update characteristics of coal chemical industry declaration materials and files impose multiple constraints on the deployment and upgrade process.
When batch importing multiple long documents, ensure the stability of the database connection pool to avoid connection exhaustion in high-concurrency scenarios. Sensitive project data must be transmitted and stored over internal networks, so configurations must adapt to enterprise private deployment environments.
During cross-version upgrades, retain files under review, do not interrupt existing approval workflows, and synchronously update field mapping rules to adapt to newly added approval node fields.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `DB_MAX_LINK` | `20–30 connections` | Coal chemical industry declaration materials and file review involve batch import scenarios with a large number of files per batch. Sufficient database connection pool resources are required to support concurrent operations |
| `MONGODB_URI` | `Internal private network address + identity authentication parameters` | Coal chemical project data involves industry-sensitive information. Private network deployment and identity authentication must be enabled to ensure data transmission and storage security |
| `STORAGE_S3_ENDPOINT` | `Enterprise internal object storage service address` | Coal chemical industry files include dozens of MB-level process drawings and material reports. Internal object storage ensures reading speed and data controllability |
| `FILE_TOKEN_KEY` | `32-character random string` | Download links for coal chemical industry declaration materials must be encrypted and verified to prevent unauthorized access to sensitive file records |
| `FE_DOMAIN` | `Enterprise internal access domain name` | Only internal approval personnel are allowed to access the review system through the specified domain name to avoid external unauthorized access |
| `ROOT_KEY` | `Complex key generated according to enterprise security policies` | Restrict the scope of system administrator permissions to prevent accidental modification of coal chemical industry file review workflows and field configurations |

## Three common mistakes
- Scenario: After upgrading to FastGPT v4.17.0, the system version displayed on the frontend interface remains the old version. Cause: The frontend static resource rebuild and deployment steps were not executed. Only the backend service image was updated.
- Scenario: MongoDB database connection errors occur several days after deployment. Cause: No reasonable value was set for `DB_MAX_LINK`. The connection pool is exhausted during high-concurrency batch file imports, and no connection timeout reconnection mechanism was configured.
- Scenario: When upgrading across multiple versions by skipping intermediate versions without scripts, some coal chemical industry file approval field parsing fails. Cause: The skipped versions include incremental update scripts for file field mapping. Database structure synchronization for intermediate versions was not performed.

## How to confirm the configurations are set correctly
- Perform a test batch import of coal chemical industry declaration materials, check that there are no errors in the database connection logs, and confirm that the `MONGODB_URI` and `DB_MAX_LINK` configurations take effect.
- Upload coal chemical industry process drawings, check that the file upload and storage process has no abnormalities, and confirm that the `STORAGE_S3_ENDPOINT` configuration is correct.
- Access the configured `FE_DOMAIN`, check that the frontend interface loads normally and the version displays FastGPT v4.17.0, and confirm that the frontend deployment path is correct.
- Attempt to access uploaded file records using an unauthorized link, check that a permission denied error is returned, and confirm that the `FILE_TOKEN_KEY` configuration takes effect.
