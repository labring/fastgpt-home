# Coal-Electric Integration Declaration Materials and File Review: Document Parsing and Chunking

## What the Data for This Category Looks Like
Coal-electric integration project declaration materials and archive data come from full-process documents for project approval, environmental impact assessment approval, and completion acceptance for central and state-owned enterprise coal sector projects. Data updates are triggered by project approval nodes. Most data is generated in batches during the declaration phase. Daily archives are updated according to the approval circulation rhythm.
Documents include fixed-format approval forms, free-format feasibility study reports, scanned PDF and Word files. Structured fields include project number, coal type, installed capacity, and approval document number. Units include industry standard units such as ten thousand kilowatts, tons, yuan per ton, and others.

## What Constraints These Characteristics Impose on Document Parsing and Chunking
The mixed structure of fixed-format approval forms and free text requires the parsing process to retain the association between structured fields and context, preventing splitting that breaks approval logic.
Scanned PDFs make up a notable share of documents, so parsing capabilities for industry-standard documents must be supported.
Batch project documents have significant structural differences, so flexible chunking rules are needed to adapt to different document types.
Parsing long-text feasibility study reports may cause timeouts, so timeout parameters must be adjusted to support large file loading.
Industry-specific terms and units must be fully retained, and must not be incorrectly split during the chunking process.

## How to Configure
This document is written based on the function configuration of FastGPT v4.17.0. The following are configuration recommendations adapted to the coal-electric integration scenario.

| Configuration Item | Recommended Value | Basis for This Selection |
|---|---|---|
| `chunkSize` | `800–1200 characters` | Coal-electric integration declaration materials include long-text feasibility study reports and short-format approval forms. This range balances context integrity and chunking granularity |
| `chunkSplitter` | Split by paragraph and title hierarchy | Documents include title hierarchies and paragraph structures. Hierarchical splitting retains context association for approval logic |
| `customPdfParse` | Enabled | A large number of declaration documents are scanned standard-format PDFs. Enabling this adapts parsing for documents with fixed industry layouts |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120–180 seconds` | Parsing large-volume feasibility study reports takes a long time. This range avoids timeout interruptions |
| `chunkSettingMode` | Custom mode | Document structures vary greatly across different projects. Custom mode allows flexible adjustment of chunking rules to adapt to diverse documents |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | Some batch-declaration packaged documents have large volumes. This upper limit covers conventional project document requirements |

## Three Common Mistakes
- Phenomenon: Parsed documents do not correctly render Markdown formatting in context references, only original markup symbols are retained. Cause: `customPdfParse` is not enabled to adapt to industry-standard document typesetting, so the parsing process does not strip redundant format markers.
- Phenomenon: Document content cannot be extracted after passing in an external link, only empty results are returned. Cause: Parsing rules adapted to external document sources are not configured, or the document format pointed to by the link does not match the common standards for coal-electric integration declaration materials.
- Phenomenon: Chunking tasks trigger timeout interruptions, and full document parsing is not completed. Cause: The value of `PARSE_FILE_TIMEOUT_SECONDS` is too low, failing to cover the parsing time of large-volume feasibility study reports.

## How to Confirm the Configuration Is Correct
- Upload a typical coal-electric integration project feasibility study report document, check whether the parsing result fully extracts text content.
- Submit an external link pointing to a standard approval document, confirm that valid text is returned normally after parsing.
- Check the chunked context fragments, confirm that industry-specific terms and units are not forcibly split.
- Verify the parsing timeout parameters and file upload limits, confirm that the values cover the maximum document volume and parsing time requirements in the current business.
