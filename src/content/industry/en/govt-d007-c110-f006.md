# Mining and Mineral Processing Declaration Materials and Case Review: Citation Sources and Traceability

## What this category of data looks like
Data sources for mining and mineral processing declaration materials and case review data include geological exploration original records, mining right application approval archives, mineral processing production daily reports, safety supervision law enforcement cases, and other materials. Data update rhythms vary by type: mining permit materials are updated in stages along with the approval process, mineral processing production data is synchronized daily, and safety cases are updated according to law enforcement inspection frequency. Document structures include structured approval forms, unstructured exploration report PDFs, and transcribed text from on-site operation images. Fields include mining right number, ore output, and mineral processing throughput, with units of tons and cubic meters.

## What constraints these characteristics impose on the citation sources and traceability link
Unstructured content accounts for a high proportion of geological exploration reports, with numerous long text fragments. Complete original context must be retained during citation and traceability to avoid truncation of key argument content. The mining right number, as a unique identification field, must be bound to the corresponding approval case during the traceability link to ensure accurate matching of citation sources to specific permit documents. Daily synchronized mineral processing production data has high timeliness requirements, so the time window for cited data must be limited to prevent use of expired production records. Safety law enforcement cases have fixed formats, and specific fields must be matched to complete citation association. Otherwise, traceability information cannot correspond to specific law enforcement links.

## How to configure settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Value | Rationale |
|---|---|---|
| `quoteMaxToken` | 800–1200 token | Matches the fragment length of long-text declaration materials for mining and mineral processing, avoiding truncation of key arguments |
| `responseData` | Return only associated case fields | Ensures traceability information only includes valid fields such as mining right number and ore output, reducing redundancy |
| `detail` | Enable full traceability | Retains the context fragment of the original citation, adapting to the traceability requirements of unstructured exploration reports |
| Maximum number of citations | Top 3–5 | Matches the number of associated cases for a single declaration material, avoiding excessive citations that interfere with review logic |
| Time range limit | Last 180 days | Adapts to the timeliness requirements of daily updated mineral processing production data and staged approval cases |

## Three common misconfigurations
- Phenomenon: Review results include citation entries with no local knowledge base association, and the citation source field is empty or displays an invalid identifier. Cause: No valid filtering rules for `responseData` are configured, causing the system to return redundant citations not bound to local data sources.
- Phenomenon: Citation entries mixed with documents from different categories appear after hybrid retrieval, making filtering of declaration materials exclusive to mining and mineral processing impossible. Cause: The retrieval data source range is not limited, and the dedicated knowledge base cluster for mining and mineral processing is not bound.
- Phenomenon: A parameter error prompt is returned during deployment after citation variables are configured in the application, or cited content does not match preset mining and mineral processing cases. Cause: The knowledge base ID is not correctly bound to the dedicated data source for mining and mineral processing, and variables point to an incorrect knowledge base cluster.

## How to verify the configuration is correct
- A single mining and mineral processing declaration material PDF is uploaded, the review process is triggered, and whether the returned citation source is bound to the corresponding mining right number is checked.
- The value of `quoteMaxToken` is adjusted to verify whether the returned citation fragment length matches the expected adjustment result.
- The data source range is switched to confirm that only cases and declaration materials exclusive to mining and mineral processing can be retrieved.
- Citation fields are checked to confirm they only include preset valid fields, with no redundant unnecessary content.

All configuration values listed here are common starting points. Adjust based on specific samples and use cases.
