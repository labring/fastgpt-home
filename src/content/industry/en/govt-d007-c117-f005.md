# Declaration Materials and Case Review for Communication Towers and Infrastructure: Tool Calling and Plugins

## What this category of data looks like
Communication towers and infrastructure declaration materials and case data mainly come from paper scans of project establishment approval, base station site survey data, and operation and maintenance ledger systems. Data is synced in real time after a single declaration task is submitted. Daily case archiving is updated weekly.
Document structure includes fixed fields such as project number, base station longitude and latitude, construction plan, property certificate, and environmental impact assessment form. Longitude and latitude use decimal degree format. Construction area is measured in square meters, and tower height is measured in meters. Some supplementary materials include attachment links to on-site photos.

## What constraints do these characteristics impose on tool calling and plugin workflows
Declaration materials for communication towers include structured fields and semi-structured construction plan text. Tool calling must complete both text content extraction and numerical format verification.
Case review requires comparison with historical base station ledgers, so plugins need to call external operation and maintenance interfaces. This carries a certain risk of response timeout.
Document batches from different declaration rounds may have minor field differences. Tool calling parameters need flexible adaptation capabilities to avoid audit failures caused by hard-coded fixed fields.
Some declaration materials include attachment links, so tool calling must support pulling and parsing external link resources.

## How to configure settings

| Configuration Item | Recommended Value | Rationale |
|---|---|---|
| `toolChoice` | `auto` | Allows the model to autonomously select tools suitable for communication tower review, such as historical ledger comparison and format verification plugins |
| `functionCall` | `enabled` | Forces the model to output results in standard function call format, ensuring review logic can be parsed by tools |
| Maximum single tool call count | Top 3 entries | Core review fields for communication tower declaration materials do not exceed 3 categories; too many will introduce redundant context |
| Tool call timeout period | 120 seconds | The average response time of historical operation and maintenance ledger interfaces falls between 60 and 90 seconds, with reasonable buffer reserved |
| Knowledge base recall limit | Top 5 entries | Historical cases of base stations in the same region and of the same type have high similarity; 5 entries are sufficient to support review reference basis |

## Three Common Mistakes
- When a workflow calls a tool and returns "tool not found" with status code 500, the cause is that the interface configuration for the communication tower historical operation and maintenance ledger has not been added in plugin management, so the model cannot obtain necessary review reference data.
- Cross-origin blocking occurs when a third-party system calls the FastGPT API through a browser, the cause is that allowed third-party domain names have not been configured in FastGPT API settings, resulting in request interception.
- Knowledge base search returns empty results and review fields are empty, the cause is that base station longitude and latitude and tower height fields from communication tower declaration materials have not been mapped to index fields of the knowledge base, making it impossible to recall matching historical cases.

## How to Verify Successful Configuration
- Enter the plugin management page of FastGPT v4.17.0, confirm that the communication tower historical ledger interface has been added and run a connectivity test, returning normal historical data entries.
- Trigger a simulated review request in the workflow editor, view the tool call log, confirm that the model correctly selected the configured tool and returned results in the required format.
- Initiate a test request containing standard declaration fields, view the knowledge base recall results, confirm that matching historical case data from the same region is included.
- Check the cross-domain configuration page of the API gateway, confirm that third-party access domain names have been added to the allowed list, and there are no recent interception logs.
