# Declaration Materials and Case Review for Metal Material Processing: Citation Sources and Traceability

## What This Category of Data Looks Like
Metal material processing declaration materials and case data primarily originate from production batch quality inspection reports, process flow sheets, approval cases, and warehouse in-and-out vouchers. Data updates when production batches are completed or at monthly approval milestones. A single case document typically includes fields such as furnace number, chemical composition test values, mechanical performance parameters, approval process nodes, declaring entity and date. Units include professional industrial measurement standards such as MPa, %, and tons.

## What Constraints These Characteristics Impose on Citation Sources and Traceability
Metal material processing has numerous specialized fields and requires unified unit standards. Traceability must accurately match test parameters and approval nodes for specific batches to avoid generalized citations. Long document structures require retaining complete process association information during context processing, preventing loss of batch identifiers after splitting. In multi-round declaration scenarios, batch information from historical cases must be linked to ensure context coherence for subsequent queries. Internal permission controls for state-owned enterprises and public sector entities require strict differentiation of citation viewing permissions for different roles to prevent sensitive data leaks.

## How to Set Configurations
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Maximum Context Length | 8000-12000 characters | Adapts to the long document processing capability of FastGPT v4.17.0, retaining complete approval process context |
| `quoteMaxToken` | 600-1000 token | Limits the information length of a single citation to avoid redundant output |
| `responseData` | Enabled | Forces return of original document fields for citation sources to ensure complete traceability information |
| `detail` | Enabled | Displays the specific location of cited passages and document identifiers |
| Guest Sharing Citation Permissions | Configured via application permission groups | Aligns with internal permission control requirements for state-owned enterprises and public sector entities |
| Multi-turn Dialogue Context Binding | Enabled | Associates batch information from consecutive declarations to avoid off-topic responses |

## Three Common Mistakes
- Scenario: When accessing an application via a guest sharing link, the original text cannot be viewed after enabling the citation function. Cause: The application permission group is not configured to allow sharing users to access knowledge base original documents, or the sharing link is not bound to the correct permission scope.
- Scenario: During multi-round follow-up questions, subsequent questions cannot associate previously mentioned production batch information, resulting in off-topic responses. Cause: The multi-turn dialogue context binding configuration is not enabled, and batch identifier fields from consecutive interactions are not retained.
- Scenario: No citation marker is displayed at the end of the knowledge base answer passage. Cause: The `detail` parameter configuration is not enabled, or the parameter settings have not taken effect.

## How to Confirm Configuration Is Correct
- Initiate a single declaration material query, check if the specific document identifier and passage location of the citation source are displayed at the end of the answer.
- Initiate two consecutive related queries, confirm that the second answer associates the production batch information mentioned in the first query.
- Generate a guest sharing link, access using an unauthenticated account, check that the citation source function is subject to permission controls and meets configuration requirements.
- View the application configuration log to confirm that the `quoteMaxToken` parameter has taken effect and the citation length does not exceed the set range.

The values provided are common starting points and should be measured against the reader's own samples.
