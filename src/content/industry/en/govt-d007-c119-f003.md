# Declaration Materials and File Review for Iron and Steel Smelting: Multi-turn Dialogue and Prompt Engineering

## What this category of data looks like
The declaration materials and file review data for iron and steel smelting mainly come from enterprise internal MES systems, smelting process ledgers, environmental protection approval files, and compliance certification documents. There are two data update rhythms: process energy consumption data declared monthly is updated monthly, and annual files are archived upon approval completion. The document structure includes structured declaration forms (with fields such as furnace number, smelting batch, energy consumption per ton of steel, etc.) and unstructured attachments (such as process flowcharts, rectification receipts). Fields come with dedicated units; for example, the unit of energy consumption per ton of steel is kgce/t, and the unit of emission value is mg/m³.

## What constraints these characteristics impose on the multi-turn dialogue and prompt engineering link
The coexistence of structured fields and unstructured attachments requires prompts to clearly distinguish instructions for parameter extraction and file review, to prevent the model from confusing different types of data. Fixed dedicated units require prompts to mandate that corresponding units be included in output results, to avoid review deviations. The batch-by-batch and node-by-node file review process requires multi-turn dialogue to track changes in review status, and to splice dialogue context by link to avoid loss of key node information. Data with different update frequencies requires that the context of multi-turn dialogue be limited to a time range, to ensure that the review targets currently valid declaration materials and the latest files.

## How to set up the configuration
Based on FastGPT v4.17.0, here are specific configuration recommendations:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum Context | Previous 20 turns of dialogue + latest 8000 characters | Iron and steel smelting declaration materials include multiple sets of structured fields, and multi-turn dialogue needs to retain complete review node records |
| `messages` | Spliced by review link | Review nodes of file reviews are scattered across multiple turns of dialogue, and splicing by link ensures the model accurately associates context |
| `variables` | Preset furnace number, smelting batch fields | Structured fields of declaration materials are fixed, and preset variables reduce repeated input in prompts |
| Question Optimization | Calibrated based on actual testing | Needs to adapt to the mixed review scenario of structured parameters and unstructured files |
| Single Associated Document | Top 3 associated files | Compliance files for iron and steel smelting have high relevance, and too many documents will cause context overload |
| `chatId` | Bound to corresponding declaration project ID | Ensures that the context of multi-turn dialogue only associates with the current declaration project, avoiding confusion of cross-project information |

## Three common mistakes
- Phenomenon: After enabling multimodal image recognition and uploading a smelting process flowchart, the model fails to provide image content. Cause: The prompt does not explicitly specify support for multimodal input, or the call parameters of the corresponding multimodal model are not configured.
- Phenomenon: A list of referenced review files is automatically attached during the dialogue. Cause: The reference display switch of the dialogue node is not turned off, or the prompt does not explicitly require hiding reference content.
- Phenomenon: Early furnace number and batch information is lost after multi-turn dialogue exceeds the preset number of turns. Cause: The number of turns or character limit of the maximum context configuration is too low, and does not cover the complete declaration material review cycle.

## How to confirm the configuration is correct
- Initiate a test dialogue, input "Extract the energy consumption per ton of steel for this declaration", check if the reply includes the kgce/t unit and that the corresponding furnace number matches the preset variables.
- Upload a review receipt image of smelting files, confirm that the model can recognize the approval document number and rectification requirements in the image.
- Initiate a multi-turn dialogue, sequentially input questions for three different review links, check if the model can associate previous review node information.
- View the dialogue record, confirm that the list of referenced review files is not automatically attached.
