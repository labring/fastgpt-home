# Expressway Operations Declaration Materials and Case File Review: Source Citation and Traceability

## What This Category of Data Looks Like
This data covers expressway operations declaration materials and case file review. It comes from toll audit systems, road law enforcement archives, and toll detail ledgers of expressway operation units. Two update cycles apply: daily traffic-related declaration materials update in real time. Case files update in batches per archiving cycles. Document structures include structured forms such as declaration approval forms and site investigation records, plus unstructured attachments such as site photos and scanned vouchers. Fields include event numbers, involved vehicle license plates, law enforcement times, penalty basis document numbers, rectification time limits. Common units are copies, items, and times.

## What Constraints These Characteristics Impose on Source Citation and Traceability
Mixed structured and unstructured document structures require the citation and traceability process to support precise matching of structured fields and location of unstructured text fragments. Different update cycles for the two data types require refreshing retrieval indexes in batches by data type, to avoid recalling outdated content. Uniqueness requirements for professional fields require limiting matching scope during the recall phase, to reduce irrelevant toll or maintenance data mixing in results. The multi-attachment association attribute of declaration materials requires displaying the complete link between main materials and attachments during traceability, instead of returning only a single fragment.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1200–1800 token | The text length of a single expressway declaration case file material mostly falls between 800 and 1500 characters. Reserve sufficient token space to carry complete citation fragments and avoid truncating key content |
| `responseData` | Include citation source fields | Add traceability fields such as declaration material numbers and law enforcement times to returned results. This meets the traceability requirements of case file review |
| `detail` | Enabled | Display the original source fragment of cited content in results. This helps reviewers verify consistency between declaration materials and case files |
| Recall tag filtering | Bind the exclusive tag "Expressway Declaration Case Files" | Distinguish datasets from other systems on the same platform. Reduce recall results for irrelevant toll records or maintenance archives |

## Three Common Configuration Mistakes
- After adjusting the `quoteMaxToken` parameter to above 2000 tokens, generated results do not display any citation sources. System logs show normal recall results. The root cause is failure to enable the `detail` configuration item simultaneously. This excludes citation fragments from returned content.
- Local citation testing works normally, but external release channel calls fail to associate knowledge base content. The root cause is one of two issues: the external release channel lacks permission to carry knowledge base citations, or it is not bound to the corresponding expressway declaration case file dataset.
- Generated answers have no association with cited knowledge base content. Citation fields point to irrelevant toll records. The root cause is failure to limit the recall matching scope with the exclusive tag. This recalls non-declaration case file datasets and confuses search results.

## How to Verify Correct Configuration
- Access the background knowledge base management page of FastGPT v4.17.0. Verify that the exclusive tag for the bound expressway declaration case file dataset is correctly configured.
- Launch a test query. Check system logs for recalled data entries related to declaration case files. Confirm the retrieval scope meets expectations.
- Review returned fields of the generated result. Confirm the citation detail content corresponding to the `detail` configuration item is included.
- Adjust the `quoteMaxToken` parameter. Verify that the length of returned citation fragments matches the text characteristics of declaration materials.
