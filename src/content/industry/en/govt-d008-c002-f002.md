# Joint Handling for "One-stop Efficient Task Completion": Business Process Guidance - Vector Models and Indexes

## What the Data for This Category Looks Like
The data for this category typically comes from the national integrated government service platform's "One-stop Efficient Task Completion" special zone, local integrated government service platforms, electronic certificate repositories, and various departmental approval systems. Documents processed daily include joint handling item lists, one-time notice sheets, joint handling application forms, material circulation sheets, parallel approval opinions, and completion receipts.
The data update rhythm is daily. Most documents contain fields such as cross-departmental item association relationships, material requirements, and processing procedures. There are no unified fixed units, so structured and unstructured information must be extracted based on the actual content of each individual document.

## Constraints Imposed on Vector Models and Indexing
Multi-source scattered data sources require indexes to support cross-platform data synchronization access, eliminating duplicate cleaning processes. The daily update frequency requires configuring incremental indexing mechanisms to reduce resource consumption from full reindexing.
Diverse document types include structured forms and unstructured notice text, requiring vector models to adapt to mixed-format text splitting and embedding. Cross-departmental item association relationships need to retain associated fields in the index, ensuring that relevant joint handling link information is retrieved synchronously to avoid process breaks.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Adapt to the paragraph length of joint handling documents, avoid including cross-departmental association information in a single chunk which causes semantic breaks |
| Overlap Length | 100–150 characters | Retain cross-chunk process association information, ensure that complete preceding and following handling relationships can be obtained during retrieval |
| `maxToken` | 4096 token | Match the input limit of common vector models, avoid truncating complete process descriptions of joint handling items |
| Similarity Threshold | 0.72–0.78 | Filter low-relevance non-joint-handling government information, retain content strongly associated with target items |
| Single Search Limit | Top 8 entries | Balance the completeness of retrieved information and response speed, avoid excessive redundant content interfering with process guidance |
| `defaultToken` | 2048 token | Set the default context window length, adapt to the information length of common joint handling consultation scenarios |

## Three Common Errors
- Phenomenon: An access denied error is returned when calling the vector model, but the interface can be connected normally when tested with curl. Cause: The access address or port mapping parameters of the model service are not correctly filled in the FastGPT vector model configuration, causing the platform to fail to initiate requests normally.
- Phenomenon: Unable to directly perform add, delete, or modify operations on the vector database via MongoDB, prompting that the field format is incompatible. Cause: The official FastGPT vector database management interface is not used, and the internal vector index format requirements of MongoDB's vector storage collection are not followed when operating directly.
- Phenomenon: Cross-departmental association content is missing from retrieved joint handling process information, and the returned results do not match actual handling requirements. Cause: Item association fields are not retained in the index configuration, and vectors are generated only for individual documents, making it impossible to retrieve cross-departmental parallel approval association information.

## How to Confirm Proper Configuration
- Import a joint handling item list document, initiate a process guidance test, and check whether the retrieved content includes cross-departmental association information of the corresponding item.
- View the vector database update log, confirm that the daily incremental update task is executing normally, and no abnormal full reindexing is triggered.
- Test different types of joint handling consultation questions, check whether the returned similarity results fall within the preset threshold range.
- Check the vector model configuration parameters, confirm that the supported target model name and interface address have been correctly set.
