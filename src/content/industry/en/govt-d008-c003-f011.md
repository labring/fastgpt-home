# Real Estate Registration Business Process Guidance: Forms and Interactions

## What the data for this category looks like
This category covers real estate registration business in the government public service sector. Data originates primarily from the real estate registration information system, cadastral survey database, housing transaction online signing system, tax system, and electronic certificate library. The update frequency is daily.
Daily business documents include registration application forms, ownership certificates, survey results, tax payment vouchers, real estate ownership certificates, and real estate registers.
Data fields center on core elements such as real estate right ownership, location, area, and right restriction status. All content is structured or semi-structured material required for government service handling. No redundant non-business fields are included.

## Constraints imposed on forms and interactions by these characteristics
Multi-source data requirements mean form interactions must support cross-system data pulling and verification. This ensures real-time matching of ownership, survey, tax, and other information.
Daily updated data sources require that fields such as right restrictions and housing area in forms call the latest interfaces to obtain data. Cached old data must not be used.
Diverse business documents require forms to support classified upload of multiple files. This matches the submission requirements for different documents such as registration application forms and ownership certificates.
Business attributes with severe error consequences require adding pre-verification in the interaction link. Real-time prompts for required fields and format compliance reduce the risk of subsequent registration errors.
This category focuses on confirming real estate right ownership. Form interactions must focus on the right ownership verification link. Unrelated processes must not interfere with user handling. This differs from adjacent categories centered on construction activity permits.

## Configuration settings
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Form input box | Enable multi-file upload function, support up to 10 files per upload, single file size no more than 200 MB | Real estate registration business requires submission of multiple types of certification documents, which meets the submission requirements of business documents |
| `formInput` | Set required field verification rules, trigger when input loses focus | Real estate registration forms involve core required items such as ownership information. Losing focus verification can detect filling errors in advance |
| User selection module | Configure `userSelect` dynamic options, data source is linked to the cadastral survey database interface | Real estate right types and handling links need to be updated in real time with business rules. Dynamic options can match the latest business processes |
| Timeout setting | Set to 600 seconds, automatically terminate the request and prompt the user after timeout | Multi-source data verification needs to call multiple government system interfaces. Sufficient response time is reserved to avoid interruptions |
| File format verification | Support uploading pdf, jpg, png format files, filter illegal formats | Matches the general format requirements of daily business documents |
| Voice input function | Enable voice to text, response delay no more than 3 seconds | Meets quick input requirements in special scenarios |

## Three common errors
- Symptom: The chat function input box does not show the file upload button, making it impossible to submit business certification materials. Cause: The multi-file upload configuration of the form is not enabled, or the configuration is not linked to the corresponding permissions.
- Symptom: No response after inputting voice, and no corresponding text content is generated. Cause: The voice to text function is not enabled, or the response delay configuration exceeds the allowable range of the business.
- Symptom: The options in the user selection module do not update with business rules, showing outdated handling links. Cause: The dynamic data source of `userSelect` is not configured, and the real-time interface of the real estate registration system is not linked.

## How to confirm the configuration is complete
- Open the business handling form page, check if the multi-file upload entry is displayed. Try uploading no more than 10 files to verify if the single file size limit takes effect.
- Enter the user selection module, modify the linked data source interface, check if the options are updated to the latest real estate registration handling links in real time.
- Input voice content, wait for the text conversion result, verify if the response delay meets the configuration requirements.
- Fill in the required fields and then lose focus, check if the corresponding verification prompt pops up, verify that the verification rules of `formInput` take effect.
