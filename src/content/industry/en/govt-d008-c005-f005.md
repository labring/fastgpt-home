# Business Process Guidance for Property Rights, Asset and State-owned Capital Management: Tool Calling and Plugins

## What Data for This Category Looks Like
This category of data mainly comes from state-owned asset supervision information systems, enterprise asset management systems, property right exchange systems, evaluation agency reports and financial statements. The update frequency is monthly. Daily processed documents include property right registration forms, asset evaluation reports, property right transfer plans, on-site transaction announcements, and asset disposal approval forms. Fields cover asset numbers, ownership subjects, evaluation values, transaction base prices, approval statuses, and other relevant items. Units include ten thousand yuan, square meters, pieces, and others. The size of individual documents ranges from hundreds of characters to tens of megabytes.

## Constraints Imposed on Tool Calling and Plugins
The data characteristics of this category impose multiple constraints on tool calling and plugin configuration. Multi-source and heterogeneous data sources require tool calling to adapt to the interface formats of different systems. Unified parameter mapping rules must be configured. The size of documents spans from hundreds of characters to tens of megabytes. The context capacity limit for tool calling must be adjusted based on document type. The monthly update frequency does not require an extremely short calling interval. A data version verification link must be added to the process to avoid calling expired data. The presence of multiple field units requires automatic identification and conversion of unit formats during tool calling to prevent matching and verification errors.

## Configuration Settings
The following configuration items include two officially supported parameters, `toolChoice` and `functionCall`, and apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Adapts to multiple tool calling scenarios, no need to manually specify a single tool |
| Single tool call timeout | `600 seconds` | Longer response time is required to process large documents such as asset evaluation reports and property right transfer plans |
| Tool call context limit | `8000–12000 characters` | Adapts to the size range of most documents in this category |
| `functionCall` | `auto` | Automatically triggers tool calling logic that conforms to business processes |
| Data version verification interval | `30 days` | Matches the monthly update frequency of data in this category |
| Multi-source field mapping rules | Calibrated based on actual testing | Adapts to field differences across different state-owned asset supervision and asset management systems |

## Three Common Misconfigurations
- Symptom: External tool calls return empty results or fail to load content. Cause: The domestic network environment is not adapted, no domestically available alternative plugins are configured, and overseas search tools are used directly.
- Symptom: Fields returned by tool calls cannot complete ownership verification. Cause: Multi-source system field mapping rules are not configured, and original system fields are used directly for matching and verification.
- Symptom: Single tool calls terminate early and return timeout errors. Cause: The set timeout period is too short, and the processing time for large asset evaluation reports and property right transfer plans is not considered.

## How to Verify Correct Configuration
- Upload a typical document of this category, trigger the tool calling process, and check whether the tool automatically adjusts context parameters to match the document size.
- Simulate calling interface data from multiple source systems, and check whether the tool automatically converts field formats and units.
- Review the timeout settings for tool calls, adjust corresponding parameters based on document size, and ensure the process is not interrupted due to insufficient time.
- Trigger the data version verification link, and confirm that the system automatically identifies and filters expired monthly updated data.

The values provided are common starting points and should be measured against the reader's own samples.
