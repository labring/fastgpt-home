# Business Process Guidance for Property, Asset and State-owned Capital Management: Forms and Interactions

## What this category of data includes
Data for this category comes from state-owned assets supervision information systems, enterprise asset management systems, property right exchange systems, assessment agency reports and financial statements, with a monthly update frequency. Daily processed documents include property registration forms, asset evaluation reports, property right transfer plans, on-site transaction announcements and asset disposal approval slips. These documents contain fields such as asset ownership number, book original value, evaluation value and transaction approval status. Corresponding measurement standards must be matched for individual documents, and there are no unified global measurement rules.

## Constraints on forms and interactions
The characteristics of this category impose the following constraints on forms and interactions:
Monthly update frequency requires form interactions to support pulling the latest ledger data on a periodic basis, to avoid using expired information. Multiple data sources require forms to accommodate format differences from exports of different systems, and require configuration of unified data mapping rules. Fields across multiple document types need to match corresponding measurement standards, which requires the `formInput` component to support custom field validation rules to prevent entry of incorrect measurement values. Core time-consuming business links require forms to support field linkage, automatically bringing associated information to reduce manual verification workload and lower process error risks.

## How to configure
These configurations are based on FastGPT v4.17.0 and are tailored to the business characteristics of this category.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` component | Custom field validation rules, support multiple measurement unit mappings | Match the requirement that document fields in this category must correspond to matching measurement standards |
| `userSelect` component | Bind optional lists of asset ledgers from state-owned assets systems, no more than 20 items selected at one time | Avoid data loading timeouts during batch selection |
| Knowledge base association rules | Associate knowledge bases for property right exchanges and asset evaluation reports, limit retrieval scope to monthly updated data | Adapt to the monthly update frequency of category data |
| Text extraction trigger setting | Automatically trigger after `formInput` fields are completed | Reduce invalid extraction operations |
| Reranking model configuration | Enable to return the top 3 sorted results | Match the need for accurate verification in core business links |
| Timeout threshold | 600 seconds | Adapt to time requirements for pulling data from multiple sources |

## Three common misconfigurations
- Only a single highest-similarity result is returned after enabling the reranking model. Cause: The return count parameter of the reranking model is not configured, and the default setting only returns a single result, which does not meet the needs of multi-material verification in business processes.
- A specified reply is triggered directly after text content extraction fails, without waiting for user supplementary input. Cause: No waiting interaction logic is configured after extraction failure, leading to process interruption.
- Automatically associated ownership information cannot be displayed when entering an asset number in the form. Cause: No linkage mapping rule is configured between the `formInput` component and the state-owned assets system ledger, resulting in failure of automatic data synchronization.

## How to verify successful configuration
- Enter a test asset number, confirm whether corresponding ownership information, book original value and other field information are automatically displayed, to verify that the linkage rule takes effect.
- Trigger a text content extraction operation, enter content unrelated to the business, confirm whether the interaction waiting for user supplementary input is triggered.
- After enabling the reranking model, upload multiple test documents, confirm whether the number of returned results matches the configuration requirements.
- Import test monthly updated data, confirm whether the form can load the latest ledger information.
