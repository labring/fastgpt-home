# Business Process Guidance for Internal Control Evaluation, Audit and Rectification: Tool Calling and Plugins

## What this category of data includes
Data for this category comes from enterprise internal control systems, ERP, financial sharing systems, audit management systems, and procurement contract project systems. The update frequency is annual.
Commonly involved documents include internal control self-evaluation reports, audit notices, audit working papers, issue lists, rectification ledgers, and rectification closing certificates.
Data fields include issue identifiers, responsible departments, rectification measures, supporting material association information, and more. This covers two format types: structured ledgers and unstructured working papers.

## Constraints imposed on the "tool calling and plugins" workflow
Because data sources cover multiple internal business systems, tool calling must support cross-system API integration. This avoids reliance on a single data source format.
The annual update frequency means tool calling does not need high-frequency triggering. Batch execution can be configured according to the annual audit cycle.
Common documents include structured ledgers and unstructured working papers. Plugins must support parsing of multiple document types. This covers extraction of tables, text, and supporting material associations.
This category focuses on post-event sampling checks and closed-loop evidence chains. As such, tool calling must support association matching between vouchers and issues.
For time-consuming steps of extracting business samples, tool calling must support bulk voucher data pulling. It must automatically associate issue lists and rectification ledgers. This reduces the workload of manual operations.

## How to configure settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Adapts to tool calling needs for multiple types of audit documents, automatically matches corresponding plugins |
| Plugin data source whitelist | Only add specified system APIs such as internal control systems and audit management systems | Prevents access from unauthorized systems, ensures internal data security |
| `functionCall` trigger threshold | `800–1200 characters` | Matches the single-paragraph content length of audit working papers, ensures calling accuracy |
| Bulk call limit | `Top 20 entries` | Matches the reasonable scale of a single audit sample extraction, avoids system overload |
| PDF enhanced parsing switch | Enabled | Audit working papers often include embedded tables and scanned documents; enhanced parsing enables complete field extraction |
| Call timeout setting | `600 seconds` | Adapts to the time required for cross-system data pulling |

## Three common configuration errors
- Symptom: A server internal error prompt appears when installing a database connection plugin. Cause: The outbound access whitelist for the enterprise internal database is not configured. This prevents the plugin from accessing the target data source.
- Symptom: Fields returned after calling the audit data interface are empty. The dataId of the rectification ledger cannot be obtained. Cause: The correct data source table name or permission scope is not specified in the plugin configuration. This results in the interface not returning valid data.
- Symptom: The PDF enhanced parsing option does not appear in the plugin list. Cause: The special permission for the plugin marketplace is not enabled in the FastGPT backend, or the corresponding plugin package has not been deployed.

## How to confirm configuration is complete
- Navigate to the plugin management page. Confirm that added data sources match internal systems such as enterprise internal control and audit management systems.
- Initiate a single tool call test. Verify that structured fields of audit working papers and rectification ledger information can be pulled.
- After configuring the `functionCall` trigger rule, submit test text. Confirm that the automatic tool triggering timing meets expectations.
- Check the plugin marketplace list. Confirm that the PDF enhanced parsing plugin is in an enabled state.

The values provided are common starting points and should be measured against the reader's own samples.
