# Business Process Guidance for Internal Control Evaluation, Audit and Rectification: Forms and Interactions

## What the Data for This Category Looks Like
Data for this category mainly comes from enterprise internal control systems, ERP, financial sharing systems, audit management systems, and procurement contract project systems, with an annual update frequency. Daily associated documents include internal control self-evaluation reports, audit notices, audit working papers, issue lists, rectification ledgers, and rectification cancellation certificates. Core fields include issue number, rectification responsible person, rectification deadline, supporting material path, and others. The data structure mainly combines structured ledgers and unstructured documents, and needs to adapt to field entry requirements for multiple types of documents.

## Constraints Imposed on Forms and Interactions by These Characteristics
The annual update requirement means forms do not need high-frequency automatic synchronization mechanisms, and only need to support batch import of business data collected within the year. The existence of multi-system data sources requires forms to be configured with cross-system field mapping rules to ensure that entered data matches the field formats of each system. The variety of associated document types requires forms to support differentiated control configurations. For example, the rectification ledger page must be paired with a file upload control for associating rectification cancellation certificates. The rigor of audit processes requires forms to have built-in required field verification to avoid null values or format errors affecting subsequent audit processes. The link for extracting business samples and vouchers requires forms to support accurate entry of sample numbers to ensure data traceability.

## How to Configure the Settings
The following configurations are formulated based on the forms and interactions feature of FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `formInput` | Configure corresponding controls based on document field types: date picker for date fields, multi-line input for issue descriptions | Match the field format requirements of documents such as internal control self-evaluation reports and rectification ledgers |
| `userSelect` | Preset department and responsible person options from the enterprise organizational structure, support fuzzy search, take the top 200 commonly used options based on actual testing | Adapt to high-frequency scenarios of selecting responsible persons and departments in audit processes |
| Single submission volume of structured data | No more than 500 entries per submission | Match the batch import limit for business data collected within the year |
| Form verification timeout | 60 seconds | Avoid excessive waiting during cross-system data verification |
| File upload control | Support PDF and Excel formats, maximum 100 MB per file | Match the common formats and sizes of documents such as rectification cancellation certificates |

## Three Common Misconfigurations
- Issue: Field empty error occurs after form submission. Cause: No verification rules configured for required fields such as rectification responsible person and rectification deadline, leading to submission with null values.
- Issue: Data truncation occurs when batch importing rectification ledgers. Cause: The single submission data volume exceeds the configured limit, and the number of imported data entries is not verified in advance.
- Issue: Abnormal number of knowledge base retrieval results occurs after a user enters an overly long issue description. Cause: No character length limit set for `formInput`, and the overly long content exceeds the context processing threshold, affecting retrieval logic.

## How to Verify Successful Configuration
- Open the form configuration page and check whether the control type of each field matches the corresponding document field.
- Simulate submitting a test data entry that includes all required fields, confirm that the verification rules take effect and no errors occur.
- Upload a rectification cancellation certificate file that meets the format requirements, confirm that the upload control receives the file normally and the format verification passes.
- View the cross-system field mapping configuration, confirm that the entered data matches the field formats of each system.

The values provided here are common starting points and should be measured against the reader's own samples.
