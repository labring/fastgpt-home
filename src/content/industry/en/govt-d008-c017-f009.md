# Business Process Guidance for Medical Institution Supervision and Public Health Inspection: Model Access and Configuration
This document is written based on FastGPT v4.17.0.

## What This Category of Data Looks Like
This category of data comes from health supervision information systems, medical institution electronic registration systems, complaint reporting platforms, and law enforcement inspection records, with a monthly update frequency. Daily processed documents include supervision inspection forms, medical institution practice licenses, rectification notices, supervision opinions, and penalty case files. Data fields cover institutional main body information, scope of licensed qualifications, compliance status of inspection items, rectification requirements and implementation results, and other related content. There is no unified fixed unit of measurement, and some fields need to match the legal information registered by the institution at the time of registration.

## Constraints on Model Access and Configuration
Multi-source data access must be compatible with the output formats of different systems to avoid qualification verification deviations caused by field mapping errors. The monthly update frequency requires that configured document synchronization and vector recall cycles match business rhythms, to avoid using outdated law enforcement data. Diverse document types require the model to adapt to the text structures of structured qualification documents, semi-structured inspection records, and formatted law enforcement documents. At the same time, the accuracy of law enforcement-related data is directly linked to compliance results, so model calls must have traceable log records and failure retry mechanisms to ensure the reliability of process guidance.

## How to Set Configurations
| Configuration Item | Recommended Value Range | Rationale |
|---|---|---|
| `maxContext` | `8000–12000 token` | Must accommodate the full context of multiple law enforcement case files, rectification records, and institutional qualification documents, to avoid truncation of key compliance information |
| `temperature` | `0.1–0.3` | Business process guidance must strictly follow compliance requirements, to avoid generating ambiguous or non-standard guidance content |
| `quoteMaxToken` | `2000–3000 characters` | Must fully reference specific clauses in supervision inspection forms and rectification notices as a basis for guidance |
| `AIPROXY_API_ENDPOINT` | Model proxy access address deployed within the health commission system | Ensures law enforcement data remains within the internal domain, meeting internal security management requirements |
| `AIPROXY_API_TOKEN` | Fixed token value for internal authentication | Restricts unauthorized access, ensuring the security of law enforcement data and model services |
| `toolChoice` | `auto` | Automatically selects whether to call the document retrieval tool based on user input, adapting to different consultation scenarios |

## Three Common Mistakes
- Symptom: Returns a 401 unauthorized error when calling the model, but the target address can be accessed normally via a curl test. Cause: The `AIPROXY_API_TOKEN` parameter is not configured correctly, or the token permissions do not match the access rules of the internal model service.
- Symptom: Model response is empty or has occasional timeouts, stuck for approximately 10 seconds before returning an error. Cause: The `maxContext` parameter is set beyond the context limit supported by the model, or the proxy service's timeout threshold does not match the time required for multi-document retrieval.
- Symptom: Vector model access fails, with prompts for authentication errors or field mismatches. Cause: The vector model's access token is not aligned with the configuration in FastGPT, or the structured field format of health commission system documents is not adapted.

## How to Confirm Successful Configuration
- Run a curl command to test the connectivity and authentication validity of the model interface, verifying that the configurations of `AIPROXY_API_ENDPOINT` and `AIPROXY_API_TOKEN` are correct.
- Upload 1 to 2 typical health commission system documents to test the model's context loading capability, confirming that the values of `maxContext` and `quoteMaxToken` are suitable for the document length.
- Initiate a simulated business consultation, check whether the model can accurately recall relevant law enforcement document content, confirming that the value of `temperature` meets the requirements of compliant guidance.
- View the FastGPT call logs, confirm that the model call response duration and retry mechanism are triggered normally, verifying the rationality of the timeout and retry configurations.
