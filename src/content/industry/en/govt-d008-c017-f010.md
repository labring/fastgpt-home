# Business Process Guidance for Medical Institution Supervision and Public Health Inspection: Knowledge Base Retrieval and Recall

## What Data for This Category Looks Like
This category of data originates from the health supervision information system, medical institution electronic registration system, complaint and reporting platform, and law enforcement inspection records. Daily documents include supervision inspection forms, medical institution practice licenses, rectification notices, supervision opinions, and penalty case files. Most individual documents combine structured and semi-structured content, with fields including institution name, license scope, inspection date, rectification requirements, and penalty basis. Data is updated once per month, and must cover the latest status information for all registered medical institutions under the jurisdiction.

## What Constraints These Characteristics Impose on Knowledge Base Retrieval and Recall
Dispersed data sources create large differences in document formats. This requires support for mixed retrieval of structured fields and unstructured text.
The monthly update frequency means retrieval results must match the latest institution qualifications and rectification status. Data sources must be synchronized regularly to ensure information timeliness.
Single documents contain multiple core fields. Retrieval must accurately match specific fields such as institution qualifications and inspection content, to avoid irrelevant results interfering with law enforcement judgments.
Most law enforcement records and complaint data are unstructured text. Recall logic must be optimized to quickly extract key compliance-related information.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.72–0.78 | Matches core business fields such as institution qualifications and rectification requirements, avoids introducing irrelevant results if set too low, and avoids missing compliance-related content if set too high |
| `limit` | Top 8 entries | Covers multi-dimensional inspection records of medical institutions under a single jurisdiction, while controlling the total context length |
| `searchMode` | hybrid | Adapts to mixed retrieval needs for structured fields and unstructured text, balancing exact matching and semantic recall |
| `usingReRank` | Enabled | Rearranges recall results by business relevance, prioritizing qualification and rectification records related to current law enforcement inspections |
| `datasetSearchUsingExtensionQuery` | Enabled | Expands the scope of retrieval terms to cover synonymous expressions commonly used in law enforcement scenarios, improving retrieval coverage |
| `collectionIds` | Bound to health supervision document library and medical institution registration library | Limits the retrieval scope, only using business document data exclusive to this category |

## Three Common Misconfigurations
- An import format error prompt appears when uploading Markdown files of supervision inspection forms. Cause: The document contains unescaped table separators or special characters, and does not comply with FastGPT's Markdown import rules.
- Rectification notice content can be recalled normally during debug preview, but no search results appear after embedding in a custom page. Cause: The custom page does not correctly configure dataset access permissions or context parameters, leading to restricted retrieval scope.
- Supervision site photos uploaded to the cloud version of the knowledge base cannot be displayed normally. Cause: The image link has not been configured with cross-domain access permissions, or a compliant storage path format was not used during upload.

## How to Confirm Proper Configuration
- Manually enter the full name of a medical institution under the jurisdiction, and verify that the recall results include the institution's practice license information and recent supervision records.
- Adjust the value range of the `similarity` parameter, and confirm that the relevance of recall results meets the business needs of law enforcement scenarios.
- Test importing business documents in different formats, and confirm that no error prompts appear during the import and retrieval process.
- View the retrieval log to confirm that the number of recall results matches the setting of the `limit` parameter.

The values provided are common starting points and should be measured against the reader's own samples.
