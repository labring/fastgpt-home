# Business Process Guidance for Territorial Spatial Planning Compilation and Implementation Evaluation: Forms and Interactions

## What this category of data looks like
Data for this category typically comes from the territorial spatial basic information platform, natural resource survey and monitoring data, population and economic statistics, and remote sensing images. It is updated annually.
Commonly processed documents include territorial spatial overall plans, detailed plans, special plans, planning implementation evaluation reports, and public opinion summaries.
Data fields include spatial boundary coordinates, construction land area, and population scale. Common units are hectares, people, and square kilometers.
Document structures usually split into main text chapters and supporting attachment data files. This data serves regional spatial planning work for natural resource department planning divisions, planning institutes, local governments, and industry competent authorities.

## Constraints imposed by these characteristics on forms and interactions
Annual data updates require forms to support historical version switching and comparison, to avoid duplicate entry of old planning data.
Multiple data sources and diverse document structures require forms to support multi-format file upload and batch field import. This adapts to different types of input content such as planning reports, remote sensing images, and public opinion summaries.
Large regional spatial data volumes require forms to support chunked loading and pagination display, to avoid interface lag.
Unstructured public opinion summary content requires forms to provide flexible text entry and classification tag options, to adapt to opinion collation from different sources.

## Configuration Setup
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Predefine input boxes according to planning standard fields | Match common fields of territorial spatial planning, reduce manual configuration costs |
| `userSelect` | Preset approver scope by department role | Adapt to the hierarchical approval chain of natural resource departments, limit selectable submitters |
| Single search limit | Top 10 entries | Match the recall scope of multi-source spatial data, avoid timeouts caused by loading excessive data |
| Submission timeout | 600 seconds | Accommodate upload and parsing time for remote sensing images and large planning reports |
| File upload size limit | 1000 MB | Adapt to the conventional size of a single remote sensing image or planning report |

## Three Common Configuration Errors
1. No response after voice input: When the voice input button on the interface is clicked, the `formInput` text box fails to synchronize the recorded voice content. This occurs because the voice-to-text node is not configured to associate with the input source of `formInput`, and voice parsing permissions are not enabled.
2. Empty fields in HTTP request response: When form data is submitted through the FastAPI open script port, the returned response body contains no valid content. This occurs because role verification for `userSelect` is not correctly configured, and non-authorized roles cannot trigger the data writing logic.
3. MySQL connection failure after form submission: A database connection error prompt appears after the submit button is clicked. This occurs because the intranet access address and whitelist are not configured, so the form cannot connect to the internal database.

## How to Confirm Successful Configuration
- Test the field verification of `formInput`. When a construction land area value is entered, preset unit prompt options automatically pop up.
- Log in as a planning department role, use `userSelect` to select an approver, and confirm that the selectable range only includes internal approval positions of the department.
- Upload an 800 MB remote sensing image file, and confirm that the form normally receives the file and generates a preview thumbnail.
- Trigger the voice input function, read a section of planning-related text aloud, and confirm that the content is automatically synchronized to the `formInput` text box.
