# Business Process Guidance for Land Spatial Planning Compilation and Implementation Evaluation: Deployment and Upgrade

## What data for this category includes
Data for this category primarily originates from the National Land Spatial Basic Information Platform, natural resource survey and monitoring data, population and economic statistics, and remote sensing imagery. Updates occur annually. Commonly processed documents include overall land spatial plans, detailed plans, special plans, planning implementation evaluation reports, and public opinion summaries. Data fields include spatial coordinate ranges, constraint indicator values, planning implementation progress, and public feedback entries. Some documents have exclusive format and unit requirements, such as longitude and latitude coordinates and planning time limits.

## Constraints imposed during deployment and upgrade
Full annual spatial and operational data requires configuring incremental synchronization mechanisms during deployment. This prevents overloading storage resources with repeated full data loads. Multi-source heterogeneous data types include remote sensing imagery, statistical tables, structured spatial data, and unstructured text. Deployment must include multi-format parsing plugins to ensure all document types can be properly read and indexed. Long text in planning documents and spatial coordinate fields require dedicated splitting and indexing rules. This prevents context overflow that reduces process guidance accuracy. Unstructured text from internal departments and public feedback needs targeted semantic understanding configurations to ensure process guidance precision.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `DB_MAX_LINK` | 1000–2000 entries | Adapts to annual full spatial data association queries, avoids exceeding database connection limits in single requests |
| `MONGODB_URI` | Fill in the intranet access address for local deployment, fill in the dedicated connection string provided by the service provider for cloud versions | Stores unstructured data of planning documents and public opinions, requires guaranteed access permissions and stability |
| `PG_URL` | Fill in the spatial database connection address reachable by the deployment node | Used to store structured spatial data from the National Land Spatial Basic Information Platform, ensures query efficiency |
| `REDIS_URL` | Configure a high-availability cluster address | Caches frequently queried planning indicators and process node information to shorten response time for business process guidance |
| `STORAGE_S3_ENDPOINT` | Fill in the object storage endpoint adapted for remote sensing image storage | Used to store large files such as remote sensing images and planning drawings, ensures data reading speed |
| `ROOT_KEY` | Generate a dedicated key based on the deployment scenario | Used to manage system administrator permissions, ensures access security for core configurations |

## Three common configuration errors
- An error stating no initial password appears when logging into the cloud version, preventing account binding. This occurs when the WeChat scan-code login account initialization process is not enabled in the deployment configuration, and initial login credentials are not generated synchronously.
- Uploaded remote sensing imagery or planning drawing files cannot be parsed after local deployment. This happens when storage permissions for `STORAGE_S3_ENDPOINT` are not configured, or parsing plugins for spatial file formats are not installed.
- After upgrading to FastGPT v4.17.0, third-party channel model calls fail, such as invalid configurations for channels connected via oneapi. This is caused by changes to interface parameter formats after the version update, with no synchronous updates to parameter mapping rules in channel configurations.

## How to verify correct configuration
- Access the database monitoring panel in the system backend, review connection status, and confirm no alarms triggered by the `DB_MAX_LINK` upper limit are active.
- Upload a test overall land spatial planning document, confirm parsed text and spatial fields are fully extracted with no missing content or garbled text.
- Run a simulated planning process guidance query, verify response time matches expected business scenario requirements.
- Review system operation logs, confirm there are no records of data synchronization failures, storage access errors, or configuration loading exceptions.
