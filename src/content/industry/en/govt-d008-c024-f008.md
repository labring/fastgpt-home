# Business Process Guidance for Student Aid and Subsidy Review: Document Parsing and Chunking

## What this category of data looks like
This category of data comes from the national student funding management information system, school student status system, civil affairs low-income and extremely poor assistance data, and fiscal payment system. The update cycle is every semester. Daily processed documents include family economic hardship certification forms, aid application forms, scholarship and grant review forms, disbursement lists and public announcement materials. Most document structures contain fixed fields such as student ID number, family economic status description, review results, bank card information, etc. Some public announcement materials use tabular layout, and disbursement lists require matching student identities with fund disbursement records.

## What constraints do these characteristics impose on the "document parsing and chunking" link
The data characteristics of this category impose multiple constraints on document parsing and chunking. Documents from multiple systems have inconsistent formats, ranging from structured tabular disbursement lists to plain-text family economic status descriptions, requiring adaptation to differentiated parsing rules. The semester-level batch update requirement demands that the parsing process supports efficient batch processing to avoid delays affecting review progress. Documents contain sensitive personal information, so field integrity must be preserved during chunking to prevent sensitive information from being truncated or misaligned. Improper chunking logic for tabular documents will split identity and fund information linked within a single row, reducing matching accuracy for subsequent qualification verification. Long-text review materials must be split by natural paragraphs to avoid disrupting the semantic coherence of review opinions.

## How to set the configurations
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Adapts to the semantic length of single paragraphs in documents of this category, avoiding splitting linked information from review opinions or fund disbursements |
| `chunkSplitter` | Chunk by paragraph | Matches the natural semantic structure of family economic status descriptions and review materials, ensuring complete information after chunking |
| `customPdfParse` | Enable enhanced parsing | Adapts to multi-format aid application forms and public announcement materials, preserving the layout association between tables and text |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Addresses large-volume semester-wide summary disbursement lists during batch processing, avoiding parsing timeouts |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Supports batch upload of summary documents for a single semester, meeting batch processing requirements |
| `chunkSettingMode` | Manual configuration | Adjusts chunking parameters for different document types (tabular/text) to adapt to the diverse document formats of this category |

## Three common mistakes
- PDF parsing fails in the interface, with the error prompt "parsing timed out". The cause is failure to adjust the `PARSE_FILE_TIMEOUT_SECONDS` parameter. When processing large-volume semester-wide summary disbursement lists in batches, the default timeout duration is insufficient to complete parsing.
- Table rows are split after chunking, with some students' identity information and disbursement amounts belonging to different chunks. The cause is using the default character-based chunking, failing to configure chunking by paragraph, and not adapting to the structure of tabular documents.
- The PDF enhanced parsing function cannot be enabled, and the corresponding parsing module fails to load. The cause is incorrect configuration of the `customPdfParse` parameter, or failure to deploy the corresponding parsing dependencies, resulting in the enhanced parsing not being triggered.

## How to confirm the configuration is correct
- Upload a single PDF of the family economic hardship certification form, check the parsed chunking results, and confirm that paragraphs are not randomly truncated.
- Upload a batch disbursement list spreadsheet file, check whether each row's student information and disbursement amount are in the same chunk after chunking.
- Check the status of the `customPdfParse` parameter in system settings, confirm that enhanced parsing mode is enabled.
- Upload a single large-volume semester-wide summary document, wait for parsing to complete, and confirm that no timeout error is triggered.

The values provided are common starting points and should be measured against the reader's own samples.
