# Business Process Guidance for Engineering Construction Project Approval: Forms and Interactions

## What the data for this category looks like
This category’s data is sourced from the engineering construction project approval management system, construction drawing review system, enterprise qualification database, and credit platform, with a daily update frequency. Documents involved in daily handling include construction permit applications, construction drawing review qualification certificates, quality and safety supervision procedures, and completion record forms. Core fields include project number, construction area, participating unit qualification level, personnel practicing qualification certificate number, and more. Most document structures combine structured forms and supporting attachments.

## Constraints imposed on the "forms and interactions" link by these characteristics
Multi-system data sources require form interactions to support cross-source data pulling and integration, to prevent duplicate data entry by construction units. Daily updated data requires the interaction link to perform real-time verification of participating unit qualifications, project status, and other information, to avoid use of expired data. Structured documents and multiple fields require forms to be split into modules by approval node, support segmented saving and batch upload of attachments, and run format verification on fields such as qualification level and practicing qualification certificate number, to reduce entry error rates. Parallel approval node tracking requires the interaction link to provide synchronized display of node status, to help users track handling progress.

## How to Configure the Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Enable segmented submission mode, with a maximum of 1000 characters per segment | Adapt to the content length of single modules in documents such as construction permit applications, to avoid exceeding the input limit in a single submission |
| `userSelect` | Enable batch selection function, with a maximum of 8 participating units selectable at one time | Match the conventional configuration scenario of multiple participating units such as design, construction, and supervision in the approval process |
| Attachment upload limit | Maximum 100 MB per file, supports PDF and CAD formats | Match the conventional size and format requirements of daily approval documents |
| Real-time verification switch | Enable real-time field verification | Intercept format errors in fields such as qualification level and practicing certificate number in advance |
| Context window limit | Set to no more than 3500 tokens based on actual measurement | Adapt to the interaction context length requirements after integrating data from multiple systems, and match the interaction logic of FastGPT v4.17.0 |

## Three Common Configuration Mistakes
- Phenomenon: The system returns an input character limit exceeded error when submitting structured attachments for construction permit applications. Cause: The single-segment input upper limit configuration corresponding to `formInput` was not adjusted, and the default limit is lower than the actual content length of the approval document.
- Phenomenon: After scaling the published process guidance page to 50% or 200%, form module content is lost and cannot be displayed. Cause: Page responsive adaptation configuration was not enabled, and the form layout does not adapt to the scaled viewport size.
- Phenomenon: When selecting participating units, batch binding of qualification information for multiple units is not supported. Cause: The batch binding function of `userSelect` was not enabled, and only single-selection mode was configured.

## How to Verify the Configuration is Complete
- Upload an approval document attachment that follows daily formats, and confirm whether the system allows uploading and recognizes the corresponding format.
- Enter qualification level or practicing certificate number information that matches the field format, and confirm whether the system displays a real-time verification prompt or passes the verification.
- Attempt to batch select more than 3 participating units, and confirm whether the system supports batch binding and synchronously displays unit information.
- Adjust the page scaling ratio to 50% and 200%, and confirm whether the form module is fully displayed with no content loss.
