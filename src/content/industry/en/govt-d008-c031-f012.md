# Business Process Guidance for Construction Project Environmental Impact Assessment Approval: Deployment and Upgrade

## What the data for this category looks like
Data for this category comes from the national unified construction project environmental impact assessment declaration and approval system, ecological environment zoning control results, pollution discharge permit platform, and monitoring data. Daily processed documents include environmental impact assessment reports or report forms, approval applications, public participation explanations, technical assessment opinions, and environmental impact assessment approval documents. Document structures include fields such as project basic information, environmental impact assessment level determination, pollution prevention measures, and public participation content. Data update frequency is irregular, with updates synchronized alongside approval process progress or policy adjustments.

## What constraints these characteristics impose on the deployment and upgrade phase
This category’s data sources involve multiple government affairs systems. During deployment, adaptation to intranet multi-data-source docking configurations is required to avoid cross-network data leakage risks. Daily documents have diverse formats, including structured forms and unstructured text. Deployment requires configuring parsing rules compatible with multiple document formats. Data updates follow no fixed cycle, so the upgrade phase must support flexible incremental synchronization configuration. Environmental impact assessment data covers project construction pre-approval. Deployment stability directly impacts approval processes, so fault-tolerance mechanisms must be configured to ensure service availability. Configurations must also comply with intranet compliance requirements for government data storage.

## How to set configurations

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `DB_MAX_LINK` | `10–15 connections` | Environmental impact assessment approval processes require batch reading of declaration data. Concurrent connection counts are adapted to business peaks to avoid exhaustion. |
| `MONGODB_URI` | `Intranet-specific instance connection string` | Environmental impact assessment approval documents require intranet storage to ensure government data security and compliance. |
| `REDIS_URL` | `600-second cache expiration duration` | Cache approval process status to avoid repeated calls to external government system interfaces. |
| `STORAGE_S3_ENDPOINT` | `Intranet storage service address` | Environmental impact assessment documents must be stored in an intranet environment to meet government data confidentiality requirements. |
| `FILE_TOKEN_KEY` | `Set based on actual testing` | Generate document download authorization tokens to prevent unauthorized users from accessing approval documents. |

## Three common configuration mistakes
- Phenomenon: The `mysql connection refused` log appears during docker-compose deployment, and the mysql process shows normal startup. Cause: The `MONGODB_URI` configuration is incorrect, not pointing to the intranet-deployed mysql instance, or the container network policy restricts access to the database port.
- Phenomenon: Calls to the configured model interface respond slowly, but direct curl calls operate at normal speed. Cause: The `REDIS_URL` is not configured with a reasonable expiration duration, leading to repeated external data source calls for each request and increased response latency.
- Phenomenon: After uploading an environmental impact assessment document, parsing fails, and approval process guidance content cannot be generated. Cause: Parsing rules compatible with environmental impact assessment document formats are not configured, resulting in failed field extraction from unstructured text.

## How to confirm correct configuration
- Run the `docker ps` command to check that all FastGPT-related containers are in the Up state, with no abnormal restart records.
- Connect to the intranet database instance and run a query statement to verify that the connection count configured by `DB_MAX_LINK` has not been exhausted.
- Upload a standard environmental impact assessment report form to confirm successful document storage and generation of corresponding approval process guidance content.
- Simulate an approval query request to check that cache status matches the expiration duration requirements configured in `REDIS_URL`.
