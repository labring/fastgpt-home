# Business Process Guidance for Investment Project Approval and Post-Evaluation: Multi-turn Dialogue and Prompt Engineering

## What this category of data looks like
Data for this category originates from the State-owned Assets Supervision and Administration Commission investment supervision system, enterprise ERP and project management systems, industry market data, audit and financial statements. Daily processed documents include annual investment plans, project proposals, feasibility study reports, due diligence reports, asset appraisal reports, and post-investment evaluation reports. A single feasibility study or post-evaluation report often contains tens of thousands of words. Data updates follow a quarterly schedule. Core fields include project approval number, investment amount, feasibility study technical parameters, post-investment operation data, and more. Adaptations are made to support non-uniform format requirements across multiple types of business documents.

## What constraints do these characteristics impose on the multi-turn dialogue and prompt engineering link
Multiple long documents and quarterly updated data sources require multi-turn dialogue to support cross-document context association. Long text documents occupy large context window space, so single-turn dialogue context capacity must be reasonably limited. Field differences across different business documents require prompt engineering to adapt to multiple input formats, avoiding dialogue deviations caused by field mismatches. Quarterly updated static data requires multi-turn dialogue to support regular synchronization of the latest supervision system and ERP data, while handling the association logic between historical and new data. Investment decision materials and post-evaluation data for large projects increase the input load of dialogue interfaces, so context calling logic must be optimized.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chatId` | Fixed binding to project-specific ID | Ensures multi-turn dialogue context is associated with the corresponding investment project, avoiding cross-project context confusion |
| `messages` | Limit single-turn context to the first 20 turns of dialogue + current project core document fragments | Adapts to load limits for long document processing, avoiding context overflow |
| `variables` | Pre-set business variables such as project number, investment amount, update cycle | Adapts to field differences across multiple types of business documents, improving prompt matching accuracy |
| Single search limit | Top 10 results | Matches the limited data source scale updated quarterly, avoiding redundant recall |
| Maximum context length | 8000–12000 token | Adapts to the typical length of a single feasibility study report, balancing context completeness and interface response speed |
| Question optimization | Calibrated based on actual testing | Adapts to professional terminology scenarios for project approval and post-evaluation, optimizing semantic understanding of user questions |

## Three Common Misconfigurations
- Symptom: Multi-turn dialogue response timeout for a single 100,000-character Chinese document or 15,000-row Excel file. Cause: Context capacity is not limited, loading the full document occupies excessive interface resources.
- Symptom: Slow multi-turn dialogue output after searching the knowledge base. Cause: Context capacity is not limited, loading excessive redundant data causes high interface load.
- Symptom: Embedded images are not fully displayed after prompt engineering calls MCP. Cause: Format and size requirements for professional charts in project documents are not adapted, and image processing parameters are not configured.

## How to Verify Proper Configuration
- Initiate a multi-turn dialogue for the corresponding investment project, check that `chatId` matches the project-specific ID to ensure correct context association.
- Upload a single 100,000-character Chinese feasibility study report or 15,000-row Excel data set, verify that dialogue response time meets the preset threshold.
- Enter a question containing professional terminology, check that the prompt engineering correctly identifies project fields and generates matching content.
- Call the MCP tool to generate a post-evaluation report fragment, check that embedded charts are fully displayed.

The values provided are common starting points and should be measured against the reader's own samples.
