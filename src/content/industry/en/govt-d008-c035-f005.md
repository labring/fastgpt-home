# Business Process Guidance for Pollution Discharge Permit Management: Tool Calling and Plugins

## What this category of data looks like
Data sources for this category include the National Pollution Discharge Permit Management Information Platform, corporate environmental protection ledgers, online monitoring systems, and environmental statistics systems. Data is updated quarterly. Daily business documents include pollution discharge permit application forms, implementation reports, self-monitoring plans, ledger records, change applications, and permit copies. Data fields cover permitted emission limits, discharge outlet codes, self-monitoring requirements, and change item types. Units include pollutant emission amounts, monitoring data values, and other relevant metrics. Most document structures consist of structured forms paired with attachments.

## What constraints these characteristics impose on the "tool calling and plugins" workflow
Data sources for this category involve pulling data across multiple systems and platforms. Tool calling requires configuring multi-source data docking plugins. Data is updated quarterly, so the cache validity period for tool calling must align with this schedule to prevent use of outdated data. Daily documents include structured forms and attachments, so tools must support parsing both structured fields and unstructured attachment content. Specialized business fields such as permitted emission limits and discharge outlet codes require tool parameters to match pollution discharge permit business fields. Do not directly reuse parameter configurations from general business tools.

## How to configure the settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Adapts to multi-tool calling scenarios for pollution discharge permit business, automatically selects tools matching business workflows |
| `functionCall` | Enabled | Supports structured parameter passing, meets the structured field requirements of pollution discharge permit documents |
| Plugin timeout period | 300 seconds | Matches the average response duration of cross-system data pulls, prevents timeout failures during multi-source data calls |
| Plugin retry count | 2 times | Balances calling success rate and resource consumption, adapts to non-frequent calling scenarios for quarterly updated data |
| FastGPT version | FastGPT v4.17.0 | Adapts to plugin compatibility requirements for the configurations on this page, avoids version compatibility issues |

## Three common configuration errors
- When `toolChoice` is set to `none`, tool calling will not respond. This occurs because the mode for triggering tools is not specified, which cannot support the multi-step process guidance flow for pollution discharge permit business.
- An "upload file failed" message displays when calling the official Markdown to file plugin. This occurs because the plugin does not adapt to the attachment format requirements of pollution discharge permit documents, and no parsing plugin for the relevant file types is configured.
- No matching records are returned when calling MCP tools to query enterprise-related information. This occurs because the correct parameter format for the enterprise's unified social credit code is not provided, so enterprise data from the National Pollution Discharge Permit Management Information Platform cannot be matched.

## How to verify successful configuration
- Trigger the pollution discharge permit business process guidance flow, check whether the tool calling return results include the structured fields of the pollution discharge permit application form.
- Simulate a cross-system data pull, check whether plugin calling logs show normal response durations with no timeout errors.
- Verify tool parameter passing, confirm that the submitted enterprise information matches the registered information in the National Pollution Discharge Permit Management Information Platform.
- Test abnormal scenarios, such as submitting an invalid permit number, check whether expected error prompts are returned.
