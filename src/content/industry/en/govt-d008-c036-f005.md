# Business Process Guidance for Government Service Item Catalog and Service Guide Maintenance: Tool Calling and Plugins

## What data falls under this category
Data for this category primarily comes from the national basic catalog of government service items, administrative licensing item list, power and responsibility list, and local government service item databases. Daily maintenance documents include the basic catalog of government service items, implementation lists, service guides, standard material directories, flowcharts, and frequently asked questions. The data update frequency is usually once per month. Core fields include item name, acceptance conditions, application material list, handling process, and service caliber explanation. Catalogs at different levels must meet field alignment requirements.

## What constraints do these characteristics impose on the tool calling and plugins workflow
Monthly updated data sources require tool calling to support regular full synchronization of catalog data, avoiding discrepancies between new and old calibers. Multi-type document structures require plugins to adapt to different formats of catalogs, lists, and guide documents, to accurately extract core fields. The requirement for item field alignment verification requires tool calling capabilities to cover field comparison across cross-level catalogs, and also support integrity verification of key fields such as acceptance conditions and application materials, to prevent inconsistencies between online and offline service calibers.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Adapts to the automatic selection requirement for multi-type tool calls in government service catalogs, and aligns with the tool calling logic of FastGPT v4.17.0 |
| `functionCall` | Enabled | Used to trigger structured field extraction and verification, adapting to standardized field processing for service guides |
| Plugin loading path | `./plugins/gov-service/` | Corresponds to the deployment location of dedicated plugins for government service maintenance, facilitating unified management and updates |
| Tool call timeout duration | 600 seconds | Adapts to the time required for cross-level catalog data synchronization, preventing call interruptions due to large data volumes |
| Batch synchronization batch size | First 200 items | Matches the monthly update data volume, reducing resource usage per call |
| Single field extraction character limit | 800–1200 characters | Adapts to the average length of service guide documents, avoiding exceeding model context limits |

## Three Common Mistakes
- Phenomenon: The deployed government service maintenance plugin cannot be found in the FastGPT platform tool list. Cause: The plugin file was not placed in the plugin loading directory specified by the platform, or the directory path configuration does not match the preset path.
- Phenomenon: Empty verification results or missing core fields are returned after calling the field verification tool. Cause: The `functionCall` configuration was not enabled, preventing the tool from generating structured field extraction requests.
- Phenomenon: Frequent timeout errors occur in monthly synchronization tasks. Cause: The tool call timeout duration was not adjusted, and the default short timeout configuration cannot complete the pulling and comparison of full catalog data.

## How to Confirm Successful Configuration
- Log in to the plugin management interface of FastGPT v4.17.0, confirm that the dedicated government service plugin has loaded normally and appears in the list of available tools.
- Upload a standard service guide document, trigger tool call verification, and check whether core fields such as acceptance conditions and application materials can be extracted accurately.
- Configure a small-scale catalog synchronization task, run a test call, and confirm that the tool can normally pull and compare field content from higher-level catalogs.
- View the tool call logs, confirm that each call's timeout duration, batch size, and character limit match the preset configuration, with no abnormal errors.
