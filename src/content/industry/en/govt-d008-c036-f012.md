# Business Process Guidance for Government Service Item Catalog and Service Guide Maintenance: Deployment and Upgrade

## What this category of data looks like
This type of government service data originates from official sources including the national basic catalog of government service items, administrative licensing item list, power and responsibility list, and local government service item databases. The data includes documents such as basic government service item catalogs, implementation lists, service guides, standard material directories, flowcharts, and frequently asked questions. Fields covered include item codes, acceptance conditions, application material lists, and handling processes. Data updates occur once per month. All content must strictly match the standard format of the superior catalog, with no missing fields and unified caliber. This guide is compatible with FastGPT v4.17.0.

## Constraints for Deployment and Upgrade
This data comes from official authoritative sources and requires monthly updates. During deployment, permission channels that connect to official government data interfaces must be configured, and support for batch import of structured local documents must be included. Document fields must strictly match superior specifications. Field integrity check rules must be preset during deployment to block imported data that does not meet format requirements. The monthly update feature requires the upgrade phase to support quick configuration of scheduled synchronization tasks. Historical data rollback capabilities must also be retained to avoid inconsistent service calibers caused by update anomalies.

## Configuration Reference
| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `MONGODB_URI` | For local deployment, fill in the connection address of a self-built MongoDB instance. For commercial editions, fill in the address of an exclusive cluster | Stores metadata and historical versions of full government service item documents, and must support batch read/write requirements |
| `REDIS_URL` | Local Redis instance address on port 6379, or connection string for a managed Redis service | Caches frequently accessed item fields and synchronization task status, to reduce database load |
| `STORAGE_S3_ENDPOINT` | Local MinIO instance address, or endpoint from a cloud storage service provider | Stores large files such as service guide attachment materials and flowcharts, and must adapt to batch upload scenarios |
| `DB_MAX_LINK` | 100–150 | Controls the database connection pool size, to accommodate monthly batch synchronization tasks and daily queries |
| `FE_DOMAIN` | For local deployment, fill in the server public IP plus port, or a bound official domain name | Configures the jump path for service guide previews, to ensure normal access within government systems |
| `FILE_TOKEN_KEY` | 32-bit random string generated per business requirements | Encrypts download tokens for service guide attachments, to prevent unauthorized access |

## Three Common Misconfigurations
- Symptom: After uploading a service guide document, the file parsing node does not respond. Logs show a connection timeout. Cause: `STORAGE_S3_ENDPOINT` or `REDIS_URL` is not configured correctly, causing an interruption in the file storage or cache link.
- Symptom: After completing Windows Docker deployment, accessing the page shows a connection failure. Cause: The port specified in `FE_DOMAIN` is not opened, or the Docker container port mapping configuration is incorrect.
- Symptom: After batch importing the item catalog, some fields are empty. Cause: No field check rules are preset. Imported documents do not match the field specifications of the superior catalog, and are not blocked before being stored in the database, causing an exception.

## How to Verify Successful Configuration
- Run a manual data synchronization task, confirm that government service item documents can be imported successfully with no format check errors.
- Upload a test service guide attachment, confirm that the file can be stored normally and an accessible preview link is generated.
- Access the configured `FE_DOMAIN` address, confirm that the page loads normally with no connection failure prompts.
- Adjust the trigger interval of the scheduled synchronization task, verify that the task executes per the set rules.

The provided configuration values are common starting points, and should be evaluated against individual deployment samples.
