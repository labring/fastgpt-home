# Business Process Guidance for Special Equipment Safety Supervision: Knowledge Base Retrieval and Recall

## What this category's data looks like
This category of data comes from special equipment safety supervision systems, inspection and testing institution systems, user unit ledgers, and operator certificate databases. The update frequency is monthly. Daily documents include use registration certificates, regular inspection reports, maintenance records, hidden danger rectification notices, accident reports, and operator certificates. Fields cover equipment numbers, inspection cycles, maintenance units, operator qualification numbers, rectification completion status, and other relevant items. Most individual documents are structured forms or unstructured files with clear fields. The data is generated around core links of the full special equipment lifecycle: registration, inspection, maintenance, rectification, and similar processes.

## What constraints these characteristics impose on the knowledge base retrieval and recall link
Monthly updated data must be synchronized regularly to avoid retrieving expired inspection cycle or operator qualification information. The fields of different document types vary significantly. Matching rules must be configured for each document type to ensure retrieval results correspond to core business fields such as equipment numbers and inspection times. Core business links depend on precise matching. For example, inspection cycles must be verified to specific dates. Retrieval and recall results must cover multiple data sources including maintenance records and operator certificates. At the same time, the number of result entries must be controlled to support quick reference during business handling, preventing information overload that reduces process efficiency.

## How to configure the settings
The following configurations are formulated based on the parameter rules of FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Special equipment data requires precise matching of core fields such as equipment numbers and inspection cycles. This range filters low-correlation results while retaining valid matches |
| `limit` | Top 6 entries | Business handling requires quick access to core information. Limiting the number of entries avoids information overload, adapting to scenarios where supervisors conduct quick verification |
| `searchMode` | Vector retrieval | Hybrid retrieval takes longer. This category of data has a fixed update frequency. Using vector retrieval first ensures response speed, meeting the real-time needs of business handling |
| `usingReRank` | Enabled | Addressing the large field differences across multiple document types, re-ranking improves the sorting priority of highly relevant results, ensuring retrieval accuracy for core business fields |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands query terms to cover matching across multiple fields such as equipment numbers and operator certificate numbers, adapting to the multi-field retrieval needs of this category |

## Three common configuration mistakes
- Unexpected number of retrieval results, with only content outside the fixed entry count returned. Cause: The `limit` parameter is not configured correctly, or the similarity threshold is mistakenly used as an entry limit condition.
- Search tests return no results, and no parsing completion prompt appears after uploading special equipment-related PDF files. Cause: The dataset corresponding to special equipment documents is not correctly associated, or data has not been synchronized to the retrieval library due to unfinished parsing tasks.
- Retrieval response times out after more than 10 seconds. Cause: Hybrid retrieval mode is enabled. This category of data has multiple sources and a fixed update frequency. The additional calculation overhead of hybrid retrieval exceeds the response requirements of business handling.

## How to verify a complete configuration
- Run a search test, enter keywords such as equipment number or operator qualification number, and check whether the number of returned results matches the configured `limit` value.
- Check the retrieval response time, confirm that vector retrieval time meets the real-time requirements of business handling. Hybrid retrieval configuration does not need to be used as a default option.
- Upload a test special equipment maintenance record PDF, wait for parsing to complete, then verify that the document content can be normally retrieved through the search test.
- Adjust the `similarity` parameter range, check whether the relevance of returned results matches the matching requirements of core fields such as equipment numbers and inspection cycles.

The values provided here are common starting points and should be evaluated against the specific samples used in the target deployment.
