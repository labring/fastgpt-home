# Business Process Guidance for Environmental Law Enforcement and Monitoring Supervision: Forms and Interactions

## What this category of data looks like
Data for this category comes from online monitoring platforms, automatic pollution source monitoring data, ecological environment law enforcement systems, and third-party test reports, and is updated daily. Daily documents include on-site inspection records, sampling records, monitoring reports, rectification order decisions, and administrative penalty decisions. Fields must cover law enforcement subjects, monitoring points, pollutant values, rectification requirements, penalty basis, and other relevant items. Units include standard on-site law enforcement and monitoring units such as concentration, flow rate, and duration. The core use case is to prove actual illegal facts.

## Constraints Imposed on the Forms and Interactions Link
The daily update requirement for data means form interactions must support real-time pulling of the latest online monitoring and law enforcement system data, to prevent entry of expired information. The variety of law enforcement and monitoring documents requires forms to support dynamic switching of field groups, to match entry needs for different documents such as on-site inspection records and sampling records. The business requirement to strictly prove illegal facts means forms must include mandatory associated field verification, to ensure entered content aligns with monitoring data and law enforcement processes. The high-stakes nature of errors means forms must add cross-field logical verification, to prevent missing key evidence and avoid issues like unaddressed excessive emissions or insufficient penalty evidence.

## Configuration Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Bind to the automatic pollution source monitoring data interface, with a synchronization interval of 300 seconds | Data is updated daily. Real-time synchronization avoids entering expired monitoring values and adapts to the rapid entry requirements of on-site law enforcement |
| `userSelect` | Preset options for law enforcement subjects and monitoring points, support fuzzy search | Daily law enforcement requires rapid selection of fixed subjects and points, reducing manual entry errors and improving processing efficiency |
| Form trigger timing | Trigger according to law enforcement process nodes, hide pop-ups in nested workflows | Adapt to the linear processing logic of law enforcement processes, avoid pop-up interference with on-site operations |
| Field verification rules | Mandatorily associate excessive pollutant values with rectification measure fields | Strictly prove illegal facts, prevent missing key associated information, and comply with law enforcement business requirements |
| Interaction timeout setting | Set the timeout threshold to 600 seconds | On-site law enforcement may experience network fluctuations. A longer timeout avoids interrupting entry midway |

## Three Common Configuration Mistakes
- Phenomenon: When the `formInput` node nested in another workflow is triggered, the interaction pop-up still appears. Cause: The pop-up default display logic in nested scenarios is not turned off in the workflow configuration, and the hiding rule is only configured in a single workflow.
- Phenomenon: No excessive emission verification prompt is triggered when entering monitoring values. Cause: The field association verification logic is not configured, and pollutant values are not bound to preset compliance thresholds.
- Phenomenon: The form is not synchronized to the ecological environment law enforcement system after submission. Cause: The data synchronization interface permission of `formInput` is not correctly configured, resulting in interface call failure.

## How to Verify Successful Configuration
- Trigger the `formInput` node, check whether the latest pollution source monitoring data is automatically pulled, and verify that the data source matches the configured interface.
- Switch dynamic field groups, confirm that the entry fields corresponding to the document are correctly loaded, with no redundant or missing items.
- After submitting the form, check whether it is synchronized to the ecological environment law enforcement system, and confirm that the interface call status is normal.
- Simulate entering excessive pollutant values, check whether the associated field verification is triggered and a prompt to fill in rectification measures appears.
