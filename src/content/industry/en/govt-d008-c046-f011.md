# Business Process Guidance for Social Assistance and Minimum Livelihood Guarantee Review: Forms and Interactions

## What This Category of Data Includes
Data for this category originates from the low-income population dynamic monitoring platform, resident family economic status verification system, and cross-department shared data from public security, human resources and social security, medical insurance, housing construction, and tax authorities. Updates occur monthly. Daily business documents include minimum livelihood guarantee application forms, family economic status verification reports, household survey forms, democratic appraisal records, public notification materials, and assistance approval forms. Fields cover household income, total property, member relationships, and assistance eligibility determination. Some documents require association with cross-department shared structured data and paper supporting materials.

## Constraints on Forms and Interactions
Multiple cross-department and cross-system data sources require forms to support importing structured verification data. Monthly update frequency requires interaction flows to retain data timeliness verification logic. Diverse business document types and high field standardization require adaptation to different file upload formats and field mapping rules. Severe error consequences require forms to add input interception and verification links to prevent incorrect or missed guarantee approvals. Some business scenarios involve documents with high word counts and large data volumes, requiring support for large file processing and multi-round interactions to collect supplementary materials.

| Number of files uploaded per request | No more than 5 | Meets upload requirements for multiple supporting materials |
| Custom interface call timeout | 600 seconds | Adapts to time requirements for cross-department data verification, avoids interrupting verification processes midway |

## Three Common Configuration Mistakes
- After uploading a 100,000-character Word document or 15,000-row Excel file, the interface returns a "request timeout" prompt, and background logs show interface response timeout. The cause is failure to adjust file upload size limits and custom interface timeout configurations, causing large file processing to exceed preset thresholds.
- After configuring `formInput` keyword interception rules, the system returns a default prompt when a user enters specified keywords, and does not trigger a custom interface call. The cause is failure to complete association and parameter configuration for the custom interface, preventing linkage of business logic.
- Form fields do not match civil affairs business standard structures, and a "field mismatch" error appears when importing Excel files exported from the resident family economic status verification system. The cause is failure to configure form mapping rules by referencing field definitions in business documents.

## How to Confirm Successful Configuration
- Upload a test large file, check that upload progress and processing status are normal, adjust configurations until they align with business processing rhythms.
- Enter preset core keywords, check that a custom interface call is triggered, and verify that returned content matches business verification logic.
- Import an Excel document in the standard format for civil affairs business, check that field mapping is correct, and confirm that structured data can be read normally.
- Initiate multi-round conversations, check that context retains historical interaction content, meeting interaction requirements for supplementing materials.
