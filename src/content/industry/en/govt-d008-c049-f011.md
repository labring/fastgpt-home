# Business Process Guidance for Legality Review of Regulatory Documents: Forms and Interactions

## What Data This Category Handles
This category processes data from official compliance data sources including regulatory rule repositories, upper-level law databases, departmental policy document repositories, and administrative regulatory document filing systems. Update frequency is irregular.
Daily processed documents include regulatory document drafts, drafting explanatory notes, legality review opinions, solicited comment summaries, and filing reports. Data fields include document issuing authority, text content, solicited comment feedback, filing number, and more. No fixed unified unit exists; values change dynamically based on submitted review materials.
The review process requires comparison with upper-level legal basis and line-by-line review of text legality. Missing core information or associated errors will lead to compliance risks.

## Constraints Imposed on Forms and Interactions
Since most data sources are official compliance repositories with irregular updates, form interactions must support manually specifying associated compliance data sources to avoid lag from automatic pulling.
Since daily processed document types vary, forms must provide multiple file upload sections corresponding to different types of review documents such as drafts, drafting explanations, and solicited comment materials.
Since reviews require line-by-line comparison of text content, forms must support paragraph-split text input boxes to facilitate marking review points line by line.
Since review errors directly impact policy release and filing, forms must include mandatory validation items to ensure core associated information is not missing before submission.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `formInput` | Set as a combination of multi-file upload and structured text box, supports a total maximum single upload size of 1000 MB | Daily review requires submitting multiple policy-related materials, must support batch upload requirements |
| `userSelect` | Preset compliance data source options including regulatory rule repositories, upper-level law databases; allow manual addition of custom data sources | Data sources must accurately match compliance requirements for review to avoid associating invalid content |
| Knowledge Base Recall Limit | Set to recall 6–10 results upfront, calibrated via actual testing | Need to cover core upper-level legal basis while avoiding information overload that reduces review efficiency |
| Mandatory Field Validation | Check the three mandatory items: issuing authority, text content, and associated upper-level law | Missing core review information will block the review process and easily cause compliance risks |
| Timeout Threshold | Set to 900–1200 seconds | Time for multi-document comparison and compliance review fluctuates, must reserve sufficient processing time |

## Three Common Mistakes
- Phenomenon: Character transcription errors appear in compliance text entered into forms, such as "share" being changed to "hand over". Cause: Character validation configuration for form inputs is not enabled, so mistakenly submitted content caused by input method suggestions or input jitter is directly accepted.
- Phenomenon: Some documents are not recognized during multi-file upload and cannot be displayed in the form list. Cause: Upload whitelist for corresponding file formats is not configured, so review materials in non-specified formats cannot be received by the system.
- Phenomenon: Timeout error is triggered after submitting a review. Cause: Timeout threshold is not adjusted based on review time, and the set threshold is lower than the maximum actual processing time required.

## How to Confirm Proper Configuration
- Upload test regulatory document drafts and supporting drafting explanation materials, confirm that the form supports categorized multi-file upload and displays complete file names and size information.
- Intentionally skip mandatory fields such as issuing authority and associated upper-level law, attempt to submit the review, confirm that the system pops up prompt information for the corresponding missing items.
- Select the preset regulatory rule repository option, confirm that the system can normally load and display relevant compliance entries from this repository.
- Submit a single test document, confirm that the system processing time falls within the preset timeout threshold range.
