# Business Process Guidance for Fiscal Expenditure Performance Evaluation: Forms and Interaction

## What the data for this category looks like
Data sources for this category include the unified budget management system, project declaration materials, fund payment data, business system ledgers, and satisfaction surveys. The update frequency is annual. Commonly processed documents are performance target forms, self-assessment forms, performance evaluation reports, supporting material lists, and rectification reports. Core fields cover project ID, fund usage details, performance indicator completion status, and supporting material association items. There are no special custom unit requirements. Data volume changes with the number of annual approved projects. This page is based on FastGPT v4.17.0 configuration instructions.

## What constraints these characteristics impose on the forms and interaction workflow
Low-frequency data updated annually requires form interactions to support bulk import and validation, to avoid duplicate entry of annual project information. The need to associate multiple types of documents requires forms to support multi-field linkage, automatically associating corresponding fields between supporting material lists and performance evaluation reports. The corresponding verification of funds and performance indicators requires forms to have built-in field matching rules, automatically prompting deviations between fund expenditures and performance targets. Scenarios involving third-party participation require forms to support multi-role permission configuration, distinguishing operation permissions for filling, reviewing, and rechecking links to prevent unauthorized modification of core data.

## How to configure the settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Supports multi-field linkage validation, associates project ID with fund details | This category requires verification of the correspondence between fund expenditures and performance targets to avoid data mismatches |
| `userSelect` | Provides an option to skip knowledge base retrieval, disabled by default | Some scenarios require direct filling of performance data without retrieving external supporting materials |
| Bulk form import | Supports CSV format import, maximum 1000 entries per import | Annual project data volume changes with the number of approved projects; bulk import improves entry efficiency |
| Text input limit | 800–1200 characters per field | Adapts to the length of single paragraphs in documents such as performance evaluation reports and rectification reports |
| Form timeout setting | Sets a 600-second timeout threshold | Adapts to the longer process of annual project filling, preventing session disconnections mid-process |
| Role permission configuration | Configures operation permissions across three levels: filling, reviewing, rechecking | Supports process management for multi-stakeholder participation involving finance bureaus, budget units, and third-party institutions |

## Three common mistakes
- Symptom: After setting the user selection option, the logic to skip knowledge base retrieval cannot be triggered. Cause: The selected value of `userSelect` is not correctly bound to the retrieval switch, causing the option to not take effect.
- Symptom: After bulk importing project data, the step of incrementing the loop processing index returns null. Cause: The bulk data parsing rule for `formInput` is not configured, causing the index to not correspond to valid data items.
- Symptom: After configuring the knowledge base switching logic, the system returns a `common:core.chat` error. Cause: Form fields are not correctly associated with knowledge base name variables, causing the specified knowledge base to fail to match during retrieval.

## How to verify a successful configuration
- Import a small amount of test data, check whether it can be correctly parsed and trigger field linkage validation.
- Select the option to skip knowledge base retrieval, confirm that the retrieval link is not triggered.
- Switch accounts with different preset roles, verify whether operation permissions match the configured rules.
- Submit text content that exceeds the conventional length, check whether the input limit restriction is triggered.
