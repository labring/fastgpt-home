# Business Process Guidance for Department Budget Preparation: Vector Models and Indexes

## What Data Looks Like for This Category
Data for this category primarily comes from the budget management integrated system, department staff establishment system, prior year final account data, project library, and Ministry of Finance budget preparation notices.
Daily generated documents include department budget drafts, project application forms, performance target forms, personnel expense calculation forms, and budget approval documents.
The data updates on an annual cycle.
Documents typically include associated fields such as budget amount, staff establishment count, project code, and more. Common units are ten thousand yuan, person, percentage, and similar.
All content revolves around annual fund declaration and allocation.

## Constraints Imposed on Vector Models and Indexes
The annual update feature requires indexes to support periodic full reindexing, to avoid version deviations from incremental synchronization.
Differences in document formats across multiple sources require unified chunking and cleaning rules, to ensure consistent vector representations.
Documents include associated fields such as budget amount and performance indicators. Vector modeling must balance text semantics and associated matching of structured data.
Cross-department budget summary business needs require index recall to cover associated data across systems. Recalling only single document content is insufficient.
Data scale increases with management hierarchy. Index configuration must adapt to batch processing efficiency requirements.

## Configuration Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Value Range | Rationale |
|---|---|---|
| Chunk Length | 800–1200 characters | Department budget documents are mostly long text. This range preserves complete core semantic units such as budget projects and performance descriptions |
| Overlap Length | 100–150 characters | Prevents chunking from breaking cross-chunk budget association descriptions, ensuring contextual coherence |
| Similarity Threshold | 0.75–0.85 | Meets the semantic rigor requirements for budget data, filtering low-match irrelevant documents |
| Single Search Limit | Top 8 entries | Balances multi-dimensional project association review needs. A moderate number of recall results covers relevant materials such as budget drafts and application forms |
| `defaultToken` | 4096 | The total length of department budget documents typically falls within several thousand characters. This parameter can accommodate complete retrieval context |
| `maxToken` | Calibrated via actual testing | Budget data volume varies widely across different management levels. Adjust based on the total volume of actually deployed documents |

## Three Common Configuration Errors
1.  Symptom: Retrieval returns no valid results after custom index configuration, with an empty list returned in the interface.
    Cause: Core fields of department budget documents (such as project name and budget amount) are not included in the index's text extraction scope. Only extracting plain text descriptions leads to failed semantic matching.
2.  Symptom: Vector model calls return configuration errors, with a 400 status code.
    Cause: The exclusive authentication parameters for Tencent Hunyuan vector models are not filled in according to platform requirements. Required interface secret key fields are omitted.
3.  Symptom: Index construction times out, with a failed task status displayed.
    Cause: Chunk batch parameters are not adjusted for annual full-update budget data. The number of documents processed in a single batch exceeds the system's carrying capacity.

## How to Verify Proper Configuration
- Upload a single department budget draft document, run a retrieval test, and check whether the recall results include associated documents of the same type such as project application forms and performance target forms. Adjust the similarity threshold to meet business matching requirements.
- View the document statistics in the index management interface, confirm that the number of synchronized documents matches the actual number of uploaded department budget documents, to verify synchronization completeness of data sources.
- Call the vector model test interface, input a simulated budget preparation consultation question, and check whether the context window can fully accommodate the retrieved document content.
- Check the vector model call logs, confirm there are no records of authentication failures or parameter format errors, to verify the validity of model configuration.
