# Food Safety Supervision and Sampling Business Process Guidance: Forms and Interactions

## What this category of data looks like
The data sources for this category are the food safety sampling and monitoring system, the State Administration for Market Regulation sampling results query system, laboratory information management systems (LIMS) of inspection institutions, and account books of food producers and operators. Updates occur monthly. Core documents include sampling plans, sampling sheets, inspection reports, unqualified food verification and disposal reports, and risk control announcements. Fields cover sampling locations, inspection items, unqualified judgment basis, disposal measures, and more. All data must strictly match the standard format exported by the regulatory system, with no additional custom statistical figures.

## What constraints these characteristics impose on the "forms and interactions" link
Monthly updated data sources require forms to support bulk import of standardized templates, to avoid format errors from manual entry. Field differences across multiple professional documents require forms to display input items in blocks according to business links. For example, the sampling link focuses on location and sample information, while the disposal link focuses on unqualified judgment and rectification measures. Mandatory format requirements from the regulatory system require limiting the character range and optional values of input fields, to ensure submitted data can be directly synchronized to the official system. The high-risk nature of unqualified disposal also requires adding a secondary confirmation step in the interaction link, to prevent regulatory risks caused by missing key information.

## How to configure the settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` field length limit | 100–200 characters for sampling sheet fields, 500–800 characters for inspection report fields | Matches the field upper limit of documents exported by the regulatory system to avoid synchronization failures |
| `userSelect` optional value range | Three types of dropdown options: sampling locations, inspection items, disposal measures | Fixed optional values ensure input format complies with regulatory requirements and reduces manual entry errors |
| Form block display | Display in blocks according to three business links: sampling, inspection, disposal | Aligns with the business logic of core documents and reduces input complexity in scenarios with multiple fields |
| Pre-submission secondary confirmation | Trigger a confirmation popup when submitting the unqualified judgment field | Corresponds to the high-risk nature of unqualified disposal and prevents errors in key information |
| Single submission data volume | No more than 50 sampling records | Adapts to the batch processing requirements of monthly updates and avoids system timeouts |
| Request timeout threshold | 300 seconds | Matches the conventional response duration of regulatory system interfaces to prevent submission interruptions |

## Three common mistakes
- Symptom: When there are many nodes in the locally deployed workflow configuration interface, text in the input form becomes laggy. Cause: Input anti-shake configuration is not enabled for long form scenarios, causing full page rendering to trigger every time a character is entered.
- Symptom: Submitting the form fails to synchronize to the regulatory system, returning an error about field format mismatch. Cause: The character range of the `formInput` field is not limited, causing input content to exceed the receiving limit of the regulatory system.
- Symptom: The `userSelect` dropdown menu expands beyond the screen range, making all optional values impossible to view. Cause: No scroll height limit is set for the dropdown menu, causing layout overflow when there are too many options.

## How to confirm the configuration is complete
- Import the sampling sheet template exported by the regulatory system, and verify whether the form matches the field names and format of the template.
- Simulate submitting more than 10 sampling records, confirm that the interface is not laggy and that submission requests respond normally.
- Trigger the secondary confirmation popup for the unqualified judgment field, confirm that the popup prompt aligns with business logic.
- Lock the FastGPT v4.17.0 deployment image, confirm that no automatic version updates occur afterward.
