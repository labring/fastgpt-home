# Survey and Design Business Process Guidance: Multi-turn Dialogue and Prompt Words

## What the data for this category looks like
Survey and design business data comes primarily from pre-project site survey records, professional survey reports, construction drawing design documents, and project approval ledgers. Adjust data update frequency based on project phase progress. Update at key nodes such as preliminary design and construction drawing design as needed. Documents combine structured ledgers with unstructured drawings and reports. They include fields such as project number, professional classification, drawing version number, and approval status. Use units including square meters, cubic meters, meters, and working days.

## Constraints for Multi-turn Dialogue and Prompt Words
Survey and design data splits into structured ledgers and unstructured drawing reports, with updates tied to project phases. This requirement means multi-turn dialogue must bind to a unique project number. This prevents cross-project data confusion. Unstructured documents contain extensive content. Prompt words must clearly define professional classification and data phase. This stops the system from returning irrelevant content. Fields include subdivided items such as professional classification and version number. Multi-turn dialogue must guide users to gradually supplement necessary fields. This ensures accurate matching of business data. Data updates follow no fixed cycle. Prompt words must require calls to the latest phase document content for the current project.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum context window | First 10 rounds of dialogue + core data of bound project | Survey and design project cycles run long. Retain key dialogues and data from pre-site surveys and approvals to avoid context breaks |
| `messages` format | System prompt binds project number and professional classification | Associate each round of dialogue with a unique project and specialty. Prevent cross-project data confusion |
| `variables` configuration | Preset project approval phase and professional type variables | Quickly call survey and design documents for the corresponding phase. Cut down redundant content in prompt words |
| Streaming output return interval | Calibrated to 1–2 seconds based on actual testing | Match front-end display rhythm. Avoid loading lag from too much data returned in a single request |
| Conversation log binding | Enable `chatId` to store session records | Support retrospective review of dialogue content across the full project processing flow. Stop session data misuse |
| Custom icon configuration | Upload local icon files | Align with visual specifications for business scenarios. Meet project display requirements |

This configuration uses FastGPT v4.17.0.

## Three Common Misconfigurations
- Links in streaming output only replace the current page: Clicking drawing links from dialogue responses will not open a new tab. It only replaces the current page. The cause is missing configuration of the link target jump attribute. The system uses the default current-page jump behavior.
- Conversation log does not match actual response content: Dialogue details show content that does not match the front-end response. Multiple conversations leave the details showing the first response. The cause is incorrect binding of `chatId`. Multiple sessions reuse the same log storage.
- Unable to customize the login-free window icon: Calling the login-free dialogue window leaves the trigger button or window icons unchanged. The cause is missing specification of the custom icon path in configuration. The system uses built-in platform icons by default.

## How to Verify Successful Configuration
- Start a multi-turn dialogue that includes a project number and professional classification. Check that each response links to the approval status and professional data for the corresponding project. Confirm no context is lost.
- Enable streaming output. Click drawings or links in returned content. Verify they open in a new tab. Confirm the link configuration works.
- View the conversation log. Check that each session’s `chatId` matches the current session. Confirm no session data misuse occurs in log storage.
- Call the login-free dialogue window. Upload a custom icon file. Verify the trigger button or window icons update correctly.
