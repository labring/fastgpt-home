# Business Process Guidance for Advanced Chemical Materials: Workflow Orchestration

## What the data for this category looks like
Business data for advanced chemical materials primarily originates from internal enterprise production scheduling systems, electronic quality inspection reports, raw material supplier qualification documents, and national chemical industry standard documents. Data synchronization is triggered once after a production batch is completed, or a full synchronization runs once per week. Individual documents typically include raw material batch numbers, production parameters (reaction temperature, pressure, duration), quality inspection metrics (purity, impurity content), business process nodes (raw material warehouse inspection, production material picking, finished product inspection), and other content. Fields include clear units such as degrees Celsius, megapascals, hours, and percentages.

## What constraints these characteristics impose on workflow orchestration
First, data is organized by production batch. Workflows must pass the batch number as a retrieval condition via `variables`, otherwise accurate retrieval of production and quality inspection data for the target batch is not possible.
Second, data synchronization is triggered per batch or on a scheduled basis. Workflows must be configured with event-triggered knowledge base refresh nodes to avoid resource waste from full synchronization operations.
Third, fields include clear units. Prompts embedded in workflows must enforce that parameters carry units to prevent confusion during large model parsing.
Fourth, some production parameters involve enterprise confidential information. Workflows must include permission verification nodes to restrict access from unauthorized processes.

## How to set configurations
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `variables` | Bind to the raw material batch number field | Match batch-organized advanced chemical material data for accurate document retrieval |
| Knowledge base retrieval trigger | Filter by the batch number in `variables` | Follow the batch-associated data characteristic to avoid retrieving irrelevant production data |
| Timeout period | 300 seconds | Match the retrieval and parsing time required for professional chemical documents |
| Context truncation length | 800–1200 characters | Balance completeness of professional information and large model processing efficiency |
| Workflow permission node | Bind to internal enterprise role identifiers | Comply with access requirements for confidential production data to restrict unauthorized process access |

This page's configuration rules apply to FastGPT v4.17.0.

## Three common mistakes
- The symptom is that conditions cannot be configured for global variables of the custom type "knowledge base selection" in the judgment node. The cause is that the global variable is not bound to the workflow input node, so the judgment node cannot read the variable value.
- The symptom is that the workflow terminates immediately after reaching the large model reply node, with no subsequent steps progressing. The cause is that no non-empty verification node is configured for `variables`. When the global variable is empty, the workflow triggers a forced termination.
- The symptom is that no response is received after the workflow is published to a Feishu bot. The cause is that the event trigger rules for the Feishu bot are not matched to the workflow's trigger node, so user messages cannot be passed to the workflow.

## How to confirm the configuration is correct
- Trigger the workflow and pass a known production batch number, then check if the retrieval node recalls documents for the target batch.
- Select the bound `variables` variable in the judgment node, and confirm that conditional judgment rules can be configured.
- Simulate a user query via the Feishu bot, then check if the workflow executes according to the preset process and returns results.
- View the workflow logs, and confirm there are no timeout or empty parameter error messages.
