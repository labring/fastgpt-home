# Business Process Guidance for Fertilizer and Pesticide: Forms and Interactions

## What the data for this category looks like
The business data for the fertilizer and pesticide category mainly comes from the Ministry of Agriculture and Rural Affairs Pesticide Registration and Filing System, fertilizer production license publicity platform, and production and operation ledgers submitted independently by enterprises. Data update frequency varies by category segment: pesticide registration information is synchronized once per quarter, and fertilizer production filing data is updated monthly. A single business data document includes fields such as registration certificate number, active ingredient content, applicable crop range, standard application dosage, and pre-harvest interval. The unit for active ingredient content is grams per liter or percentage, the unit for application dosage is grams per mu or milliliters per mu, and the unit for package specification is kilograms per bag or liters per barrel.

## What constraints these characteristics impose on the "forms and interactions" link
Specialized fields and unit requirements for the fertilizer and pesticide category require developers to split forms into modules by business scenario. Each module carries basic filing information, usage parameters, and compliance check content separately. Too many fields on a single page causes operational confusion, so this split avoids that issue. Developers add built-in unit matching prompts to interactive components. These prompts automatically associate the standard unit for each field, reducing operator input errors. The quarterly or monthly data update rhythm requires systems to pull the latest filing data in real time during form interaction. Cached expired information is prohibited. Cross-field business associations, such as applicable crops corresponding to standard application dosage, require forms to support conditional linkage via `userSelect`. This feature automatically limits the optional range and default values of subsequent fields based on previous selections.

## How to set the configuration
The following configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Split by business module, with a 100–200 character input limit per block | Fertilizer and pesticide business has many specialized fields; splitting modules and controlling single input box length avoids information overload |
| `userSelect` | Conditional linkage trigger delay of 1000 milliseconds | Avoid redundant requests caused by quickly switching options, and adapt to the loading rhythm of specialized fields |
| Unit auto-match switch | Enabled, bind to the standard unit corresponding to the field | Cover specialized units such as grams per liter, grams per mu, reducing errors from manual unit input by operators |
| Form submission check timing | Real-time check after input item changes | Detect format errors in specialized fields in advance, improving submission success rate |
| Default value loading range | Top 5 commonly used filing data | Cover most conventional business handling scenarios, reducing the workload of manual input by operators |

## Three common mistakes
- Symptom: After filling all input items in the workflow, running it displays the error 'Cannot convert undefined or null to object'. Cause: Some associated fields in the form have no configured default values. When an operator does not fill them manually, the field value is passed as empty to the AI node, causing a type conversion failure.
- Symptom: Professional results output by the AI cannot trigger preset conditional selection branches. Cause: Conditional linkage rules are not configured via `userSelect`, and the terms output by the AI do not match the preset option range.
- Symptom: Previous AI output cannot be used as the input for subsequent nodes in dialogue interaction. Cause: Context association logic is not configured, and previous dialogue results are not bound to the parameters of subsequent interactions.

## How to confirm the configuration is correct
- Fill in a test data set that conforms to professional formats, check whether the form automatically matches the corresponding unit and prompts compliance.
- Switch between different applicable crop options, confirm whether the optional range of the subsequent application dosage field is updated synchronously.
- Submit the test form, check whether expected check prompts and AI responses are triggered.
- View workflow logs, confirm that all parameters passed by fields are valid non-empty values.
