# Business Process Guidance for Pharmaceutical Circulation: Tool Calling and Plugins

## What the data for this category looks like
Pharmaceutical circulation data mainly comes from enterprise warehouse management systems, cold chain delivery temperature and humidity monitoring terminals, and the National Medical Products Administration drug circulation supervision filing platform. Data is updated by delivery batch or daily batch. Documents use structured table format, including fields such as generic drug name, approval number, circulation batch number, inbound and outbound time, storage temperature and humidity, and delivery warehouse code. Temperature and humidity use degrees Celsius as the unit. Batch numbers are 12-character alphanumeric combinations. Delivery warehouse codes follow a fixed format: administrative division code plus 4-digit number.

## Constraints imposed on tool calling and plugins
The large number of structured fields with fixed formats requires strict matching of preset field names during tool calling. Parameter mismatches cause interface return errors. Temperature and humidity data has high real-time requirements. Plugin calls must adapt to short-cycle data pulling, so adjust the timeout threshold to a reasonable range. The batch field uses a fixed 12-character alphanumeric combination. Tool calling must include built-in format verification logic to filter invalid batch query requests. Regulatory filing data must be obtained through official compliant interfaces. Plugin configuration must bind specified domain name whitelists to prevent unauthorized calls.

## Configuration settings
| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `toolChoice` | Set to `auto` and specify the drug circulation tool list | Allows the model to independently select tools adapted to pharmaceutical circulation scenarios, reducing invalid calls |
| Plugin call timeout | 30–60 seconds | Adapts to the real-time pulling requirements of cold chain temperature and humidity data, avoiding expiration of short-cycle data |
| Field format verification switch | Enabled | Verifies fixed-format fields such as batch numbers and temperature and humidity data, filtering invalid requests |
| `functionCall` | Force enabled | Ensures the model strictly follows the preset tool parameter format for output, avoiding format errors |
| Interface whitelist configuration | Bind the domain names of the National Medical Products Administration drug circulation filing interface and enterprise warehouse management interface | Complies with compliance requirements for pharmaceutical data calls, preventing unauthorized access |
| Result cache duration | 15 minutes | Adapts to the update rhythm of inventory and sales data, avoiding repeated pulling of data from the same batch |

## Three common configuration mistakes
- A plugin call returns AxiosError 404. The cause is failure to configure the domain name whitelist for the corresponding pharmaceutical circulation interface in the FastGPT backend. Cross-domain requests are intercepted in this case.
- Using the BI chart plugin returns the fixed address api.example.com. The cause is failure to modify the built-in test interface address of the plugin. Replace this address with the enterprise's actual inventory, sales, or supervision interface address in the plugin configuration.
- Tool calls return missing result fields. The cause is failure to enable the field format verification switch. The model passes parameters that do not conform to pharmaceutical circulation data formats, resulting in empty fields returned by the interface.

## How to confirm successful configuration
- Initiate a query that includes a 12-character alphanumeric batch number. Check the tool call log for matched drug information corresponding to the batch.
- Simulate a cold chain temperature and humidity data query. Confirm the plugin call duration falls within the 30–60 second range, with no timeout errors.
- Modify the interface address of the BI chart plugin, then initiate a business data query. Confirm the returned chart data corresponds to actual pharmaceutical circulation business inventory, sales, or supervision information.
- Check interface call statistics in the FastGPT v4.17.0 backend. Confirm only whitelisted domain names have request records, with no unauthorized call records.
