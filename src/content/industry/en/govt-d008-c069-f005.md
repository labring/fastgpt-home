# Hazardous Chemical Storage and Transportation Business Process Guidance: Tool Calling and Plugins

## What the data for this category looks like
The business data for hazardous chemical storage and transportation comes from three main sources: internal enterprise storage and transportation management systems, local emergency management department filing databases, and on-site inspection terminals.
Daily inspection real-time temperature and humidity and inventory data updates every 15 minutes.
Basic filing data such as compliance certificates and storage qualifications synchronizes quarterly.
Each individual business document includes fields including storage and transportation node number, hazardous chemical UN number, storage temperature and humidity thresholds, approval process nodes, and handling time limit requirements.
Field units include cubic meters, tons, degrees Celsius, hours, and others.
Some process nodes require association with a unique compliance certificate file number.

## How these data characteristics impact tool calling and plugins
The characteristics of hazardous chemical storage and transportation business data create multiple constraints for tool calling and plugins.
High-frequency real-time inspection data requires tool calling to use short-cycle pull logic, to avoid using expired on-site data.
Uniqueness requirements for fields such as UN numbers and compliance certificate numbers require precise matching of field formats during tool calling, to prevent business data matching errors caused by parameter misalignment.
Business data spans multiple systems including storage and transportation management and emergency filing, which requires plugins to support multi-interface serial calls, and handle cross-system data format differences.
Some fields use different time units such as hours and days, so unified format conversion must be completed during the tool calling link to ensure the accuracy of process guidance.

## Configuration settings
This document is based on FastGPT v4.17.0. Specific parameters are listed below:

| Configuration Item | Recommended Value | Rationale |
|---|---|---|
| `toolChoice` | `auto` | Adapts to the need for automatic selection of multi-step tools in hazardous chemical storage and transportation processes, no need to manually specify a single tool |
| `functionCall` | `[{"name":"get_storage_flow","parameters":{"un_code":""}}]` | Specifies calling the tool to obtain storage and transportation process information, binds the hazardous chemical UN number parameter to match business data field requirements |
| Tool call timeout | `30 seconds` | Real-time data pull responses for hazardous chemical storage and transportation business typically complete within 20 seconds, 30 seconds covers conventional network fluctuation scenarios |
| Number of items returned per single tool call | `Top 3` | Compliance approval nodes associated with a single hazardous chemical storage and transportation business document do not exceed 3, too many entries will interfere with the clarity of process guidance |
| Context window length | `8000 token` | Total length of hazardous chemical storage and transportation process steps and associated data typically does not exceed 6000 tokens, reserves sufficient space to handle intermediate variables |

## Three common errors
- Calling the workflow API returns empty business data. Cause: The hazardous chemical UN number parameter was not correctly bound in `functionCall`, causing the tool to fail to match business data for the corresponding storage and transportation node.
- The AI response does not display the answer source. Cause: Automatic association of business document traceability fields after tool calling was not configured. Only the API was called to obtain corpus without binding source identifiers, making the traceability function unavailable.
- The default model configuration for tool calling is incorrect. Cause: The model adapted for hazardous chemical storage and transportation business was not specified in the new conversation settings, leading to insufficient reasoning capabilities for tool calling.

## How to verify a successful configuration
- Submit a test request containing a known hazardous chemical UN number, check if the tool call returns business data for the corresponding storage and transportation node.
- View the tool call log, confirm that the `toolChoice` parameter has taken effect, and the tool matching the business requirements has been automatically selected.
- Verify that the process guidance steps are displayed in the order of approval nodes in the business document, with no field unit conversion errors.
- Simulate a network delay scenario, confirm that the tool call returns results within 30 seconds or triggers a reasonable timeout prompt.
