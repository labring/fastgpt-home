# Hazardous Chemical Storage and Transportation Business Process Guidance: Forms and Interactions

This document is compatible with FastGPT v4.17.0.

## What Data for This Category Looks Like
Hazardous chemical storage and transportation data mainly comes from internal enterprise storage and transportation ledgers, and the hazardous chemical filing database of local emergency management departments. The data update rhythm is as follows: enterprise ledgers are updated daily, and filing data is synchronized weekly. The structure of a single document includes fields such as the unified social credit code of the storage and transportation entity, general name of hazardous chemicals, CAS registration number, storage warehouse area number, storage volume (unit: ton or cubic meter), compliant storage conditions, and approval document number. Fields must strictly match the compliant format published by the emergency supervision department.

## What Constraints Do These Characteristics Impose on the Forms and Interactions Link
Compliance field requirements for hazardous chemical storage and transportation data require forms to set format verification rules for fields including unified social credit code, CAS number, and storage volume to prevent submission of non-compliant data. Data sources include official filing databases, so forms must support quick association of existing compliant data via filing numbers to reduce manual input errors. High data update frequency requires the hazardous chemical option list in forms to support daily dynamic pulling of the latest filing data. Differences exist in storage volume units for different hazardous chemicals, so forms must support automatic unit matching or manual switching to adapt to multi-category data entry.

## How to Configure the Settings
| Configuration Item | Recommended Approach | Basis for This Approach |
| ---- | ---- | ---- |
| `formInput` | Configure independent input boxes for each compliant field, and add format verification rules | Hazardous chemical storage and transportation data fields have strict compliant formats, and pre-verification is required to avoid invalid submissions |
| `userSelect` | Configure the daily dynamically pulled hazardous chemical filing list as a dropdown option | Official filing data is updated in real time, and fixed options cannot match the latest compliant categories |
| `formInput` | Bind unit switching options to the storage volume field, supporting selection of tons, cubic meters, and liters | There are differences in storage measurement standards for different hazardous chemicals, adapting to multi-category data entry |
| Form submission verification timeout | 15-20 seconds | Need to wait for filing data association query to complete, the timeout period should not be too short |
| External variable binding | Enable the filing number variable import function | Support importing filing numbers from external systems to automatically associate existing compliant data |
| File upload configuration | Enable image/document upload function for compliance proof fields | Need to support submission of compliance materials such as storage certificates and approval documents |

## Three Common Misconfigurations
- Phenomenon: A "field format mismatch" error appears after form submission, and automatic correction is not possible. Cause: No corresponding format verification rules are configured for hazardous chemical-specific fields such as CAS number and unified social credit code, resulting in compliant data being blocked.
- Phenomenon: After selecting a specific hazardous chemical category, associated knowledge base search results are empty. Cause: The hazardous chemical category is not bound to the corresponding compliant knowledge base, and only the general knowledge base is used for search, which cannot match compliant documents for specific scenarios.
- Phenomenon: The form cannot upload files such as storage certificates, resulting in failure to submit compliance materials. Cause: No file upload parameters for `formInput` are configured, and only text input function is enabled.

## How to Verify Successful Configuration
- Manually enter a correctly formatted CAS number to check if format verification triggers, with a corresponding prompt displayed for incorrect formats.
- After entering a filing number, check if corresponding fields such as storage entity and hazardous chemical name are automatically filled completely.
- Switch the hazardous chemical category to confirm if storage volume unit options are updated synchronously to adapt to the measurement standards of the corresponding category.
- Manually upload a compliance proof image to check if it can be submitted and saved normally.
- Submit test data to check if verification is completed and correct results are returned within 15-20 seconds.
