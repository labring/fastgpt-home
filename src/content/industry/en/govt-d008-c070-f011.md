# Business Process Guidance for Power Generation Equipment Manufacturing: Forms and Interactions

## What this category of data looks like
Power generation equipment manufacturing data primarily comes from equipment operation and maintenance logs, factory quality inspection reports, production order systems, and spare parts inventory databases. Update frequency varies by type: production orders sync in real time, operation and maintenance logs update daily, and batch quality inspection reports are submitted with each production batch. A single document typically includes fields such as equipment model, unique serial number, work order number, quality inspection item parameters, and spare part code. Units include physical and industrial units such as units, pieces, operating hours, and megapascals.

## What constraints these characteristics impose on the "forms and interactions" link
Professional fields and industrial units for power generation equipment manufacturing require forms to be split into modules by business scenario. This avoids filling errors caused by too many fields on a single page. The uniqueness of equipment serial numbers requires forms to be configured with `userSelect`-style verification rules to prevent duplicate entries. Field differences are significant across different business links. For example, pre-launch forms focus on quality inspection parameters, while operation and maintenance forms focus on operating data. Corresponding field groups must be dynamically loaded based on the scenario. The presence of professional units requires forms to include built-in unit matching prompts to avoid users entering incorrect unit combinations.

## How to set up the configuration
This configuration is based on FastGPT v4.17.0.
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| Form segmentation | Split into 3-5 groups by business link, with no more than 8 fields per group | Power generation equipment manufacturing forms have many fields and are differentiated by scenario; splitting reduces filling complexity |
| `formInput` | Configure unit verification for numeric fields: set the operating hours field to 0-200000 hours, and the megapascal field to 0-30 megapascals | Matches the unit and value range requirements of industrial data, reduces entry errors |
| `userSelect` | Configure unique value verification for equipment serial number and work order number fields | Prevent duplicate entry of key business identification fields |
| Field required configuration | Set work order number and equipment model as required fields | Ensure the integrity of core business data |
| Unit prompts | Mark allowed unit types next to numeric fields | Aligns with professional unit standards for industrial data |
| Dynamic loading rules | Switch form field groups based on work order type | Adapts to field differences across business scenarios such as launch and operation and maintenance |

## Three common errors
- Phenomenon: After the voice input function embedded in the form is submitted, the transcribed content is not synchronized to the corresponding field, and the system returns a parameter error prompt. Cause: The call parameters of the speech recognition model are not bound in the form configuration, causing the transcription request to fail to initiate normally.
- Phenomenon: Work orders for the same equipment serial number can be submitted repeatedly, and the form does not block duplicate entries. Cause: The `userSelect` unique value verification rule is not enabled for the equipment serial number field.
- Phenomenon: After the form is submitted, the unit of the quality inspection parameter field is automatically modified, which does not match the user's input. Cause: No unit matching prompt is added in the `formInput` configuration, causing the system to fail to identify legal units.

## How to confirm the configuration is complete
- Enter the form editing page, check if 3-5 field groups are split by business link.
- For the equipment serial number field, test entering an existing number, confirm the system pops up a duplicate entry verification prompt.
- Submit a test work order, complete voice input transcription, check if the transcribed content is correctly synchronized to the corresponding field.
- Switch different work order types, confirm that the form field group automatically switches to display fields for the corresponding business scenario.
