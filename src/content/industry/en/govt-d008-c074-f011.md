# Business Process Guidance for State-owned Asset Management Companies: Forms and Interactions

## What This Category of Data Looks Like
Business data for state-owned asset management companies mainly comes from data synchronized via the state-owned asset supervision platform, internal asset ledger files, property right registration documents, and asset evaluation reports. Data update rhythms fall into three categories: daily asset changes are synchronized daily, monthly asset ledger updates, and full refreshes of annual property right inventory. A single business document uses an asset card as its core unit, containing fixed fields such as asset number, recording date, book value, usage department, and storage location. Book value is measured in ten thousand yuan, service life in years, and asset stock in pieces or units.

## What Constraints These Characteristics Impose on Forms and Interactions
Fixed fields and unit requirements mean forms must preset unit prompts for corresponding input items, to prevent redundant formatted content from being entered. Multi-source data synchronization requires forms to support association with real-time data from the state-owned asset supervision platform. Entering core identifiers such as asset numbers automatically completes existing fields. Business scenarios with different update rhythms require forms to support two trigger modes: real-time trigger for daily change processing, and batch import mode for annual inventory batch processing. Uniqueness requirements for asset fields mean forms must include built-in duplicate verification rules, to avoid repeated submission of processing applications for the same asset.

## Configuration Settings
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Fixed fields + unit prompts, single field input length limit set to 200 characters | Matches the content length limit of asset card fields, to avoid storage exceptions caused by overly long input |
| Duplicate verification switch | Enabled, verification interval set to 1000 milliseconds | Prevents repeated submission of the same asset number, adapts to real-time verification requirements for daily processing |
| `userSelect` | Preset options for state-owned internal departments and users, supports fuzzy search | Matches the organizational structure of state-owned asset management companies, reduces manual input errors |
| Batch import support | Enabled, single import limit set to 500 entries | Adapts to the business scale of annual inventory batch processing, avoids system overload |
| Trigger timing configuration | Set to real-time trigger for daily scenarios, post-submission trigger for batch scenarios | Matches the update rhythms of different businesses, avoids resource occupation caused by frequent synchronization |
| Error prompt configuration | Customized prompts based on field type, for example, asset number format error prompt is "Please enter a 12-digit standard asset number" | Aligns with the format requirements of business fields, reduces user learning costs |

## Three Common Misconfigurations
- Symptom: The `formInput` node dialog box nested in another workflow always displays and cannot be hidden. Cause: The pop-up trigger logic was not disabled in the nested workflow configuration, and the default pop-up settings of the independent workflow were retained.
- Symptom: No follow-up notification is generated after submitting the business form, and no pending task is created in the background. Cause: The event trigger node after form submission was not configured, and the state-owned internal pending task push system was not associated.
- Symptom: The unit prompt of the form input field is lost, and the entered numerical value is not recognized by the system. Cause: The unit rule of the corresponding field was not bound in the `formInput` configuration, and the general input box configuration was used directly.

## How to Verify Successful Configuration
- Manually enter a standard asset number, check whether the system automatically completes the existing data of the corresponding field.
- Submit a form application with a duplicate asset number, check whether the system pops up the corresponding format error prompt.
- Switch to the nested workflow scenario, trigger the `formInput` node, check whether the dialog box is hidden as configured.
- Submit a batch import test file, check whether the system normally processes data within the single import limit.

The values given are common starting points and should be measured against the reader's own samples.
