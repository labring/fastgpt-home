# Business Handling Process Guidance for State-owned Capital Investment Companies: HTTP Interfaces and External Systems

## What this type of data looks like
This guide is written based on FastGPT v4.17.0. Business handling process data for state-owned capital investment companies primarily comes from internal state-owned assets supervision platforms, project approval systems, and financial accounting modules. Data updates sync in real time with business handling progress. Full-process data for a single business from submission to completion generates structured documents. These documents include fields such as process node number, handling status, operator account, submission time, and approval deadline. Time fields use ISO 8601 format. Amount fields use Chinese yuan as the unit. Process node numbers are 6-digit numeric codes.

## What constraints these characteristics impose on the HTTP Interfaces and External Systems link
Multi-source data sources require interfaces to support cross-system data pulling, and to be compatible with request format differences across internal systems. Real-time updated business data requires interface timeout settings to align with the average approval duration of business handling processes, to prevent data synchronization interruptions from timeouts. Fixed structured field formats require request parameters to strictly match field names and encoding rules. Failure to do so causes data parsing failures. For permission-related operator information fields, interfaces must pass valid identity credentials via the `Authorization` parameter to block unauthorized access.

## How to set configurations
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `Authorization` | Bearer token format, bound to internal state-owned assets system accounts | Matches internal permission verification standards of state-owned capital investment companies, ensures legitimacy of interface calls |
| `variables` | Map process node number, handling status, submission time | Corresponds to the fixed field structure of business data, ensures consistent parsing by external systems |
| `responseData` | Extract core business handling fields, filter redundant metadata | Simplifies data processing logic for external systems, only transfers necessary business information |
| Request retry count | 2 times | Addresses temporary fluctuations in internal state-owned assets systems, ensures stability of data synchronization |
| Request timeout | 600 seconds | Matches the average approval duration of business handling processes, avoids synchronization interruptions |
| Document upload threshold | Within 1000 MB | Matches the typical size range of business documents for state-owned capital investment companies |

## Three common misconfigurations
- Phenomenon: The interface returns 400 Bad Request, with a prompt that the request body format is invalid. Cause: The request header’s Content-Type is not set to application/json, so the system cannot correctly parse the incoming business handling process data.
- Phenomenon: After calling the pushdata API to upload business documents, the interface displays the "Indexing" status for an extended period. Cause: When uploading in chunk mode, no reasonable chunk size is configured. Oversized chunks lead to excessively long indexing processing times.
- Phenomenon: The interface call returns empty business data fields. Cause: Internal system field names are not correctly mapped via `variables`, so the system cannot match corresponding content during data parsing.

## How to confirm the configuration is correct
- Call the test interface, check if the returned `responseData` includes the expected business handling process fields.
- View the interface logs, confirm that the `Authorization` parameter is correctly carried and follows the required format.
- Upload a small-sized test document, check if the indexing status completes within a reasonable time frame.
- Simulate business data submission, confirm that external systems can correctly receive and parse the content returned by the interface.
