# Business Process Guidance for State-owned Capital Investment Companies: Model Integration and Configuration

## What Data for This Category Looks Like
Data primarily comes from the state-owned assets supervision and reporting system, internal business approval ledger, investment project archive, and financial accounting module. Updates happen in real time alongside the progress of individual business processes. A full monthly update of all business ledgers is also performed. Each business document includes fields such as unique project identifier, approval step sequence, required application materials, statutory processing time limit, and responsible department. Fields use mostly text, enumeration values, and numeric units, with no complex nested hierarchical structures.

## Constraints These Characteristics Impose on Model Integration and Configuration
This guide is written for FastGPT v4.17.0.
Multi-source data access requires configuring independent context isolation for multi-model calls to avoid token mixing across different business data. Real-time synced business data requires the context window to fit the full information length of a single processing flow, preventing truncation of key approval step and responsible entity information. Standardized enumeration field structures require model output formats to strictly match preset fields, so the temperature parameter must be limited to reduce randomness. The non-complex hierarchical structure of business documents means visual understanding capability does not need to be enabled. Turn off redundant configuration items to reduce internal resource consumption.

## Configuration Settings
| Configuration Item | Recommended Range | Rationale |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | Matches the full context length of a single business document, avoiding truncation of approval step and responsible entity information |
| `maxTokens` | 2000–3000 token | Covers the full response content for business process guidance, ensuring all processing steps and material requirements are included |
| `temperature` | 0.2–0.4 | Meets output requirements for standardized business fields, reduces random deviation, and ensures accuracy of process guidance |
| `toolChoice` | auto | Allows models to call tools as needed to obtain real-time business data, adapting to multi-source access business processing scenarios |
| `vision` | false | Business documents primarily use text fields, so visual understanding capability is not needed, reducing computing resource usage |
| `AIPROXY_API_ENDPOINT` | Fill in the dedicated access address based on the deployment environment | Adapts to the internal network isolation deployment requirements of state-owned capital investment companies, ensuring data transmission security |
| `AIPROXY_API_TOKEN` | Encrypted token bound with exclusive permissions | Restricts interface call permissions to avoid unauthorized access to internal business data |

## Three Common Misconfigurations
- Phenomenon: Business data from different sessions is mixed in multi-model orchestrated business process guidance workflows. Cause: No independent context isolation configured for each session, and no correct session-level limit set for `maxContext`.
- Phenomenon: "undefined is not valid json" error is returned when accessing the guidance function via external channel links. Cause: Exclusive permissions for `AIPROXY_API_TOKEN` are not correctly bound, leading to unexpected interface return format.
- Phenomenon: Attached images in business documents cannot be recognized by the model and included in guidance content. Cause: The `vision` configuration item was accidentally turned off, or visual model access parameters matching business image formats were not configured.

## How to Verify Proper Configuration
- Initiate a test call for a single business processing flow, check if the reply content includes complete approval steps and material lists, and verify that the context configuration covers the actual information length of the test document.
- Call a multi-model orchestrated workflow, verify that contexts of different business sessions do not interfere with each other, and confirm that the session-level context isolation configuration is active.
- Access external channel links, check if the interface return format matches the standard structure of business data, and confirm that the interface token permission configuration is correct.
- Upload a business document containing images, verify that the model can correctly recognize image content and include it in process guidance, and confirm that the visual configuration item settings meet business requirements.
