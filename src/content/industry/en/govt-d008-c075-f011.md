# Business Process Guidance for State-owned Capital Investment Companies: Forms and Interactions

## What the data for this category looks like
Business process data for state-owned capital investment companies is primarily sourced from internal state-owned assets supervision systems, project declaration management systems, and financial accounting platforms. Data update cycles follow fixed schedules set by state-owned assets supervision authorities, including monthly, quarterly, and annual updates.
Document structure is organized around individual business projects. It includes modules such as basic project entity information, declaration material lists, and approval node fields.
Fields cover required state-owned assets-specific content: project investment amount (unit: ten thousand yuan), declaration date (format: YYYY-MM-DD), approval status (enumerated values: pending submission, under review, approved, rejected), capital source type, and more. Some fields must comply with standardized format requirements set by state-owned assets supervision authorities.

## Constraints imposed by these characteristics on forms and interactions
Business data for state-owned capital investment companies originates from multiple sources and has high field standardization. Form interactions must match fixed formats and enumeration rules set by state-owned assets supervision authorities. This prevents input errors that cause data to fail synchronization with internal systems.
The multi-module document structure results in a large number of form fields. Fields must be split reasonably to avoid interaction lag caused by loading excessive content in a single load.
Fixed update cycles require form validation rules to align with data update schedules. This ensures input content meets format requirements for subsequent synchronization.
Some fields must link to enumeration dictionaries from internal state-owned assets supervision systems. Form options must match internal system data to avoid data mismatches.

## How to configure settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Form input box configuration | Add fixed unit prompts for state-owned assets-specific fields, such as "project investment amount (ten thousand yuan)" | Match field unit requirements for state-owned capital investment company data |
| Dropdown selection component | Limit optional values for fields such as approval status and capital source type to enumeration dictionaries | Align with fixed enumeration fields required by state-owned assets supervision |
| `formInput` validation rules | Enforce matching of field formats, such as declaration date in YYYY-MM-DD format | Adapt to standardized data formats for cross-system synchronization |
| `userSelect` data source | Link to enumeration dictionaries from internal state-owned assets supervision systems | Ensure consistency between form data and internal systems |
| Form chunked loading | Split form fields by approval node | Avoid interaction lag caused by loading too many fields at once |
| Input timeout threshold | 300 seconds | Adapt to the longer process duration of state-owned assets business handling |

## Three common configuration mistakes
- Issue: Form loading fails when attempting to jump from other link nodes to a form node. Cause: Cross-link jump permissions for the form node are not configured, and the reuse switch for `formInput` is not enabled.
- Issue: An error appears in debug preview after enabling input guidance and configuring a custom thesaurus address. Cause: The custom thesaurus address is not bound to the exclusive thesaurus for the corresponding state-owned assets business, or the thesaurus format does not meet the requirements of FastGPT v4.17.0.
- Issue: A quote type error occurs when referencing knowledge base variables. Cause: The variable reference format does not match the field type. For example, a text reference method is used for an enumeration field.

## How to confirm the configuration is complete
- Verify that the unit prompts for form fields match the field units of internal data. For example, confirm that project investment amount is labeled with ten thousand yuan.
- Test that the optional values of dropdown selection components fully match the enumeration dictionaries from state-owned assets supervision systems.
- Trigger a cross-link jump to the form node, and confirm that the form loads normally and receives incoming parameters.
- Input test data that meets format requirements, and confirm that `formInput` validation rules can properly block input with incorrect formats.
