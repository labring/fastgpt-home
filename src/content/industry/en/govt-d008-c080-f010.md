# Business Process Guidance for Urban Investment Platforms: Knowledge Base Retrieval and Recall

## What the data for this category looks like
The business process data for urban investment platforms comes from internal business manuals, government service window guidelines, archived existing handling records, and public process descriptions from online service platforms.
Data updates trigger when policies adjust or processes optimize, with no fixed cycle. Updates usually run in batches quarterly or annually.
Most documents are structured by business category. They include fields such as business name, handling entity, required material list, handling time limit (unit: working days), consultation contact information, and affiliated region. Some documents have hierarchical process descriptions in markdown format.

## What constraints these characteristics impose on knowledge base retrieval and recall
Decentralized data sources create inconsistent document formats. Retain hierarchical associations during chunking to avoid losing subordinate business process logic.
No fixed update cycle requires the retrieval system to support incremental update triggers. This ensures the latest processes sync in a timely manner.
Metadata fields like region and handling entity must bind to text chunks. This allows associated metadata to return with retrieval results.
Business process descriptions are rigorous, with similar sub-items. Strictly control retrieval thresholds to avoid irrelevant cross-business content.
Single-batch recalled content must fit the context window. This prevents exceeding the model’s processing limit.

## How to set configurations
These configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
|---|---|---|
| `similarity` | 0.72–0.80 | Urban investment business processes use rigorous language. A threshold that is too low pulls in irrelevant cross-business content. A threshold that is too high misses supplementary explanations for similar processes. This value is calibrated via actual testing. |
| `limit` | Top 8 entries | Urban investment businesses have many sub-processes. Too many recalled entries exceed the context window. Too few miss associated material requirements. This value uses typical business association rules. |
| `searchMode` | `vector+keyword` | Urban investment businesses have both standardized process text and common colloquial consultation questions. Hybrid retrieval covers all query scenarios. |
| `usingReRank` | Enabled | Business processes have high semantic similarity. Reranking filters semantically similar but mismatched results. This improves retrieval accuracy. |
| `datasetSearchUsingExtensionQuery` | Enabled | Simplified user queries (such as "how to apply for a payment certificate") expand to full business process queries. This matches existing standardized documents. |
| `collectionIds` | Specify the exclusive urban investment platform dataset ID | This avoids recalling business data from other categories. It restricts retrieval scope to urban investment platform business handling documents. |

## Three common mistakes
- Retrieval results only return text chunks, without carrying business metadata such as affiliated region and handling window. Metadata binding configuration is not enabled, and associated metadata fields are not specified during retrieval.
- Uploaded QA pair format documents cannot be accurately matched, and only vague general process texts are returned. `searchMode` is not configured for hybrid retrieval; vector-only retrieval cannot match precise QA questions.
- Extra spaces appear between numbers and text in knowledge base retrieval results. These spaces are residual format conversion artifacts from imported original documents, and format anomalies are not cleaned during preprocessing.

## How to confirm the configuration is correct
- Submit a test query "XX project declaration process" and check if returned results include corresponding handling materials, window addresses and other metadata.
- Submit a simplified query "apply for a payment certificate" and confirm complete business process documents are recalled.
- Check retrieval logs to confirm only the exclusive urban investment platform dataset was called, with no content from other categories returned.
- Upload a test markdown business manual and verify imported chunks retain title hierarchy.

The values provided are common starting points and should be measured against the reader's own samples.
