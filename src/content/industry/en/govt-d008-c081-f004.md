# Business Process Guidance for Basic Chemical Industry: Workflow Orchestration

## What the Data for This Category Looks Like
Basic chemical industry business data mainly comes from the enterprise's internal MES Manufacturing Execution System, ERP material management system, safety and environmental protection department inspection logs, and equipment maintenance logs. Data update rhythm varies by type: production reports are updated per shift, material BOM lists are only updated when process changes occur, and inspection logs are archived daily. A single structured document usually includes fields such as material code, batch number, real-time production temperature, operating pressure, inspection time, and exception handling records. Most field units are standard industrial units such as tons, degrees Celsius, pascals, and hours. Some long-text process documents include step instructions and parameter ranges.

## What Constraints Do These Characteristics Impose on Workflow Orchestration
Basic chemical industry data sources are scattered. Workflow orchestration needs to configure cross-heterogeneous data source linkage logic to ensure information from different systems flows according to business sequence. Differences in data update frequencies require workflows to set different trigger timings. For example, scheduled trigger nodes adapt to periodically updated log data, while event trigger nodes adapt to real-time production exception data. Diverse field units in chemical data mean workflows must add field validation steps to ensure parameters match correct units before proceeding to subsequent processes. The high proportion of structured documents requires workflows to prioritize structured data extraction nodes to avoid ineffective text splitting operations.

## Three Common Mistakes
- Phenomenon: After importing a third-party JSON workflow, the local workflow cannot locate the text processing module. Cause: The text processing plugin adapted for basic chemical industry scenarios is not installed locally, or the module is not enabled in the workflow library.
- Phenomenon: The configured workflow cannot be exported as a JSON file. Cause: The workflow's export permission setting is not enabled, or the current version does not support the workflow export format for this category scenario.
- Phenomenon: After setting the search reference limit to 2000, the generated answer still exceeds 3000 tokens. Cause: Filter rules are not configured based on the single-item length of basic chemical industry documents, or the context splicing logic does not limit the total token count.
- Phenomenon: The workflow only executes when the user sends a manual message in the session, and cannot start automatically. Cause: The automatic trigger node at session initialization is not configured, or the trigger condition is not bound to the session start event.
