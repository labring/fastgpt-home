# Business Process Guidance for Infrastructure Construction: Forms and Interactions

## What the data for this category looks like
Business processing data for infrastructure construction projects is mainly sourced from project approval management systems, on-site supervision ledgers, bidding and tendering record documents, and construction progress weekly reports.
The data update rhythm is adjusted based on the project phase. Approval nodes are synchronized daily during the project initiation phase. Progress and material submission status are updated weekly during the construction phase.
A single business processing document includes fields such as project unique ID, bid section scope, approval process list, required submission material details, and processing time limit requirements. Most field units use engineering standard units such as ten thousand yuan, days, copies, and square meters.

## What constraints these characteristics impose on the "forms and interactions" link
Multiple data sources require forms to pull pre-filled data via interfaces connected to different systems. This reduces manual duplicate data entry.
Different phase update rhythms require forms to dynamically switch field groups based on project nodes. This adapts to processing needs for links such as project initiation, construction permit application, and construction.
Engineering-specific field units require the interaction interface to include built-in unit automatic matching and verification logic. This avoids unit errors from manual input.
The fixed approval node process requires forms to be displayed step-by-step by link. This prevents interaction lag caused by loading too many fields at once.

## How to configure the settings
This configuration applies to FastGPT v4.17.0. Specific settings are listed below:

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `formInput` | Enable multi-field linkage verification | Adapt to the dependency relationships between fields such as budget, material usage, and construction period in engineering forms |
| `formInput` | Enable speech-to-text linkage | Support voice input filling for infrastructure business forms |
| `userSelect` | Preset approval roles and processing node options | Align with the fixed processing workflows of infrastructure businesses, reducing manual input errors |
| Form timeout period | 600 seconds | Match the time consumption requirements for filling out large infrastructure project forms, preventing session expiration mid-process |
| Form field grouping | Split by approval link, no more than 8 fields per group | Reduce the filling complexity of infrastructure business processing forms, avoiding user visual fatigue |
| Material upload limit | Maximum 100 MB per file, only PDF, DWG, JPG formats allowed | Match the general specifications and format requirements of infrastructure approval materials |

## Three common configuration errors
- Symptom: A 400 error occurs when submitting an infrastructure project form, triggered only when entering fuzzy query-style content. Cause: No input filtering rules are configured for the `formInput` component, causing the system to attempt to retrieve non-form-related knowledge base content.
- Symptom: Text converted via speech-to-text cannot be automatically filled into corresponding form fields. Cause: The speech-to-text linkage configuration for the `formInput` component is not enabled, so the recognition result is only treated as ordinary text input and not mapped to form fields.
- Symptom: Approval node matching is incorrect after form submission. Cause: The preset options for the `userSelect` component are not configured according to the fixed workflow of infrastructure businesses, causing the system to jump to the wrong approval link.

## How to confirm the configuration is complete
- Open the form configuration page, verify that the linkage verification rules for the `formInput` component cover the dependency relationships of engineering fields.
- Test form loading for different approval links, confirm that field groups are displayed in the preset link order.
- Upload a standard infrastructure approval material, confirm that the format and size limits meet the configured requirements.
- Initiate a speech-to-text test, confirm that the converted text can be automatically mapped to corresponding form fields.
