# Business Handling Process Guidance for Construction Machinery: HTTP Interfaces and External Systems
This document is written based on FastGPT v4.17.0.

## What Data for This Category Looks Like
Data supporting construction machinery business handling process guidance originates from internal enterprise equipment management systems, equipment rental platforms, and offline business ledgers. It covers businesses including rental applications, maintenance approvals, and qualification verification for categories such as cranes and excavators. Data updates in real time to sync business node status. A single submitted business document includes fixed fields: equipment number, handling link, application time, handler information, and current progress status. Field units are uniformly equipment count, handling times, and natural days. The character length of a single data entry ranges from 300 to 800 characters, with no multi-layer nested complex structures.

## Constraints for HTTP Interfaces and External Systems
The fixed field structure of construction machinery business data requires that HTTP interface request parameters strictly match preset fields such as equipment number and handling node, with no arbitrary additions or removals. Real-time updated business status requires setting a reasonable timeout interval for the interface, to avoid business node synchronization delays caused by excessive waiting time. Unified field units require that interface return data include unit identifiers, to facilitate validation and display in subsequent process guidance modules. When paging to retrieve business lists, pagination parameters must fully align with the pagination logic of the external business system. Otherwise, the same data may be returned across different page numbers.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `Authorization` | Carry a Bearer token from internal enterprise systems | Used to verify interface call permissions and prevent unauthorized access |
| `variables` | Bind business fields such as equipment number and handling node | Matches the fixed field structure of construction machinery business data |
| `responseData` | Filter and extract by equipment number and progress status fields | Adapts to the core data requirements of business handling process guidance |
| Request timeout | 30-60 seconds | Adapts to the real-time synchronization rhythm of updated business data |
| Pagination parameter configuration | Bind pageNum and pageSize variables | Aligns with the pagination logic of the business system |
| Retry count | 2 times | Addresses interface call failures caused by temporary network fluctuations |

## Three Common Configuration Mistakes
- Calling the interface and receiving the same business data for different pageNum values. The cause is that the pageNum parameter is not correctly bound to the external system's paging query logic, so every request uses the default page number.
- Frequent unauthorized error messages appear during interface calls. The cause is that the `Authorization` parameter does not carry a valid token, or the token has expired and was not updated in a timely manner.
- The interface return data format does not match expectations. The cause is that non-core fields are not filtered per the `responseData` configuration, leading to redundant data being received by the process guidance module.

## How to Confirm Correct Configuration
- Call the configured HTTP interface, pass different pageNum parameters, and verify whether the returned business data corresponds to different handling nodes.
- Check whether the `Authorization` parameter carries a valid token, and confirm that permission verification has passed via the interface return status code.
- View the filtered return result from `responseData`, and confirm that only core business fields such as equipment number and handling progress are included.
- Simulate a business node update, call the interface, and confirm that the returned status data is synced in real time with the external system.
