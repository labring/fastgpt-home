# Business Process Guidance for Construction Machinery: Deployment and Upgrade

## What this category of data looks like
Data related to construction machinery business processing comes from equipment operation and maintenance logs, factory parameter manuals, business process approval documents, and spare parts requisition records.
Equipment operation data is synced in real time. Business documents are updated per process node.
Document structure includes structured parameter fields such as rated lifting capacity, working radius, with units of tons and meters, unstructured operation guides, and fault troubleshooting reports. Fields cover equipment unique identifiers, operation periods, fault codes, approval progress, and more. This guide is compatible with FastGPT v4.17.0 deployment and upgrade workflows.

## What constraints these characteristics impose on deployment and upgrades
The real-time update feature of equipment operation data requires configuring cache and database parameters adapted to high-frequency read/write operations to avoid data sync delays.
The large number of structured parameter fields with specific units requires enabling the structured data parsing module during deployment to ensure accurate field matching and unit recognition.
The association logic that binds business documents to unique equipment identifiers requires retaining the original database association configuration during upgrades to prevent equipment matching errors in process guidance.
The large volume of unstructured documents requires adjusting adaptation parameters for storage and vector retrieval during upgrades to ensure retrieval efficiency and accuracy.

## How to set configurations
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `REDIS_URL` | `redis://:custom password@localhost:6379/1` | Adapts to high-frequency cache requirements for real-time equipment data, ensuring rapid synchronization of operation status |
| `STORAGE_S3_ENDPOINT` | `http://local storage gateway address:9000` | Adapts to large file storage requirements for unstructured operation manuals and fault reports |
| `DB_MAX_LINK` | `20–30` | Matches the maximum concurrent database connections for multiple structured fields, preventing write timeouts |
| `MONGODB_URI` | `mongodb://admin:custom password@localhost:27017/fastgpt?authSource=admin` | Stores association data between equipment and business processes, supporting precise retrieval |
| `FE_DOMAIN` | `https://gcjx-business.xxx.com` | Binds the access domain name of the construction machinery business processing page to ensure normal process guidance links |
| `ROOT_KEY` | `32-character random string` | Configures the system's highest privilege key to ensure secure permission control after deployment |

## Three common mistakes
- Too few split results for business process questions and answers after upgrade. The cause is failing to retain the original storage adaptation configuration for long documents during upgrade, resulting in incomplete splitting of long construction machinery operation manuals and limited retrieval matching scope.
- Abnormal context format error returned when calling the large model after deployment. The cause is failing to adjust the parsing configuration for structured parameter fields of construction machinery, leading to incorrect recognition of units such as tons and meters, which disrupts the context structure.
- Processing failure returned when attempting to parse construction machinery operation manual PDFs. The cause is failing to configure access permissions for `STORAGE_S3_ENDPOINT`, resulting in failure to upload large file documents to the storage node and interruption of the parsing process.

## How to confirm the configuration is successful
- Access the configured `FE_DOMAIN` business page to confirm that the process guidance module loads normally and displays processing options for the corresponding equipment.
- Submit a simulated equipment spare parts requisition work order, check the database log to confirm that no connection limit exceeded prompt appears for the `DB_MAX_LINK` configuration.
- Upload a construction machinery fault troubleshooting manual PDF, check whether the storage node completes the file upload to confirm that the `STORAGE_S3_ENDPOINT` configuration takes effect.
- Conduct a business process question and answer test to confirm that the question and answer split results cover all complete business process steps, and verify that the document chunking configuration takes effect.
