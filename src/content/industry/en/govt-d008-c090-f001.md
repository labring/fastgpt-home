# Business Process Guidance for Refined Oil Sales: HTTP Interfaces and External Systems

## What the data for this category looks like
Gas station POS terminals, oil product inventory management systems, and daily inventory counting systems primarily provide business data for refined oil sales. Operational systems use two update rhythms for this data: they synchronize single transaction data in real time after completion, and generate and update batch inventory counting data after daily store closing. The structure of a single business data document includes oil product code, oil product name, current inventory, transaction amount, transaction time, and member identification fields. Inventory units are liters or tons, transaction amount units are yuan, and the time format uses the standard ISO 8601 format.

## What constraints these characteristics impose on HTTP interfaces and external systems
High-frequency real-time synchronization of transaction data requires HTTP interface response delays to align with gas station on-site business rhythms, preventing impacts to business handling efficiency. Structural differences across multiple data sources require interfaces to support different field mapping rules, adapting to return format differences between POS terminals and inventory management systems. Differences in inventory units (liters or tons) require clear unit conversion mapping rules in interface configuration, avoiding deviations in subsequent business statistics. Large-scale daily batch inventory counting data requires interfaces to support segmented pulling or pagination parameters, preventing timeouts or interception by external systems caused by excessive data volume in a single request.

## How to set the configuration
This document is formulated based on the interface and parameter rules of FastGPT v4.17.0. The specific configuration items are as follows:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `Authorization` | `Bearer {gas station internal API key}` | Refined oil sales external systems generally use Bearer token authentication to secure interface call permissions |
| `variables` | `{"batch_limit": "200 items", "unit_convert": "liters"}` | Adapt to the pulling scale of daily batch inventory counting data, unify inventory units to liters required for business handling |
| `responseData` | `["oil_name", "trade_amount", "trade_time", "member_id"]` | Only retain core fields required for business process guidance, reducing data transmission overhead |
| Request timeout | `60 seconds` | Match the maximum waiting time for on-site business handling at gas stations, avoiding user timeout |
| Data format validation | `Enable JSON format validation` | Adapt to standard data interaction formats of external systems, reducing format parsing errors |

## Three common configuration mistakes
- When calling the HTTP interface to obtain refueling voucher files, users receive empty fields or garbled characters in the response body. Cause: No binary stream receiving rule is configured in `responseData`, and FastGPT only processes JSON-formatted response data by default.
- Batch pulling of daily inventory counting data triggers a 504 timeout error. Cause: No reasonable batch pulling parameters are set via `variables`, and single request data volume exceeds external system limits.
- HTTP interface calls return 401 authentication failures. Cause: The `Authorization` parameter is not correctly spliced with the Bearer prefix, or an expired gas station system API key is used.

## How to confirm the configuration is complete
- Call the configured HTTP interface, check whether the request header carries the correct `Authorization` field, and whether the response body includes the fields specified in the configured `responseData`.
- Simulate batch pulling of inventory counting data, confirm that the interface returns data in segments according to the batch parameters set in `variables`.
- Simulate single transaction data synchronization, check whether the interface response time meets the waiting requirements for business handling.
- Verify the unit conversion result of inventory data, confirm that it is unified to the configured liters format.
