# Business Process Guidance for Refined Oil Sales: Deployment and Upgrade

## What the data for this category looks like
Business process guidance data for refined oil sales primarily comes from gas station management systems, retail ERP systems, and customer service ticket repositories. The data includes structured business process node tables. Fields in these tables include process name, node serial number, operation content, responsible position, and preconditions, with units "times" and "minutes". The data also includes unstructured common problem documents, which contain answers for high-frequency consultation scenarios such as fuel card top-up, invoice issuance, and abnormal deduction.
The data update cycle is not fixed. It syncs to storage when retail policies are adjusted, new services launch, or monthly tickets are archived. The length of individual documents varies widely.

## What constraints these characteristics impose on deployment and upgrade
Reference only; verify against the target FastGPT release and deployment documentation.
The need to mixed store structured business process node tables and unstructured FAQ data requires configuring storage paths for multiple data types during deployment, and encrypting documents that contain compliance clauses.
The need to access data from multiple system sources requires opening permission configurations for corresponding interfaces during deployment. During upgrade, existing sync links must be compatible to avoid interruptions.
The unfixed data update cycle and wide variation in document length require supporting incremental sync and dynamic document processing logic during deployment. During upgrade, verify that configurations adapt to long document scenarios.
Concurrent access volume of business process data grows with the number of stations. Adjust database connection parameters in advance to handle peak requests.

## How to set the configurations

## Three common mistakes
- Phenomenon: Disk space continues to be occupied at a high rate after Docker deployment, with the error prompt "no space left on device". Cause: No automatic cleanup policy configured for temporary files and offline processing logs, and no deletion of unnecessary build caches and expired documents.
- Phenomenon: Frontend pages fail to load normally, with the browser error "NET::ERR_CERT_INVALID". Cause: `FE_DOMAIN` is not configured as a valid HTTPS domain, and no SSL certificate is mounted to the specified path of the FastGPT container.
- Phenomenon: Search results for business processes have very low match rates or are empty after upgrade, with the error "embedding model not found". Cause: The configuration parameters for the Alibaba-emb3 model were not reloaded during upgrade, and the dependency package versions for the model were not synchronized for update.

## How to confirm the configuration is complete
- Run a database connection test to check if the `DB_MAX_LINK` configuration takes effect. The number of database connections under concurrent requests must not exceed the set upper limit.
- Upload a business process document containing compliance clauses to verify that `FILE_TOKEN_KEY` takes effect. Unauthorized access cannot retrieve the document content.
- Access the domain configured in `FE_DOMAIN` to confirm that the HTTPS handshake completes normally and the frontend page loads successfully.
- Trigger an incremental data sync task to verify that the `STORAGE_S3_ENDPOINT` configuration works correctly. Documents are successfully uploaded to the specified storage medium.
