# Business Process Guidance for Government and Enterprise Informatization Services: Model Access and Configuration

## What this category of data looks like

The business process guidance data for government and enterprise informatization services is mainly sourced from official documents such as government service handling guides, internal enterprise business approval manuals, and business handling specifications of communication operator business halls. The data update cycle is quarterly or semi-annually, synchronized with policy or process adjustments. Each single document has a fixed structure, including fields such as handling subject, required materials, handling steps, completion time limit, and consultation channel. The completion time limit is measured in working days, and each handling step description is clear with no ambiguous expressions.

## What constraints these characteristics impose on the "model access and configuration" link

First, the document fields include clear units such as working days, requiring the guidance content generated by the model to strictly match the units of the official fields. It is necessary to configure parameters to limit the randomness of the model output and avoid arbitrary modification of units. Second, the document structure is fixed and split by handling links. Knowledge base chunking must follow link boundaries, and recall configuration must match the document length of a single link to avoid logical confusion caused by cross-link recall. In addition, the data update cycle is fixed, so a regular refresh mechanism must be configured to ensure that the model uses the latest process data. Finally, government and enterprise data has compliance requirements. Model calls must be routed within the intranet environment, and proxy addresses and authentication parameters must comply with intranet access specifications.

## How to set the configuration

This document is written based on FastGPT v4.17.0. The following is the model access configuration plan for the government and enterprise informatization service scenario:

| Configuration Item | Recommended Range | Rationale |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | Government and enterprise business process documents are relatively long, requiring retention of complete multi-link context to avoid truncation of key handling steps |
| `maxTokens` | 1500–2000 token | A single process guidance reply must cover a complete handling link, while controlling the output length to facilitate user reading |
| `quoteMaxToken` | 600–800 token | Matches the average length of a single handling link in government and enterprise process documents, ensuring recalled content is complete and not redundant |
| `temperature` | 0.1–0.3 | Process guidance must strictly follow official documents, reducing generation randomness to avoid incorrect handling steps or units |
| `AIPROXY_API_ENDPOINT` | Proxy address deployed on the government and enterprise intranet | Complies with the compliance requirements for intranet transmission of government and enterprise sensitive data, avoiding transmission of sensitive business data over the public network |
| `AIPROXY_API_TOKEN` | Unified internal enterprise authentication token | When connecting to an intranet-deployed model, use the enterprise's own authentication system to ensure access security |

## Three common configuration mistakes

- Using a public network address when configuring `AIPROXY_API_ENDPOINT`, which causes the model to fail to call normally or sensitive data to be transmitted over the public network. This occurs because the compliance requirements for intranet transmission of government and enterprise data are not followed, and an intranet proxy address is not used.
- Failing to adjust the `temperature` parameter, with an excessively high value causing the model's generated process steps to deviate from official documents, resulting in incorrect completion time limits or handling links. This occurs because the generation randomness is not controlled to meet the rigor requirements of government and enterprise data.
- Failing to adapt the embedding model's output range during knowledge base search filtering, resulting in abnormal similarity results such as values over 10000. This occurs because the reference standard for the filtering threshold is not adjusted according to the model's requirements, and the default 0-1 interval configuration is used directly.

## How to confirm the configuration is complete

- Initiate a model test call to check whether the configurations of `AIPROXY_API_ENDPOINT` and `AIPROXY_API_TOKEN` take effect, with no access errors or authentication failure prompts.
- View the content recalled by the knowledge base to confirm that the recalled document fields match the official documents, and the recall length conforms to the `quoteMaxToken` setting.
- Generate process guidance content to check whether the output length conforms to the `maxTokens` limit, and that steps, time limits and other information match the official documents.
- Verify the access permissions of the release channel to confirm that intranet authorized users can normally access the guidance page with no permission interception issues.

The values provided are common starting points and should be measured against the reader's own samples.
