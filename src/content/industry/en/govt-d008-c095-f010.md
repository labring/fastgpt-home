# Business Process Guidance for New Energy Development: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Data sources include the New Energy Project Filing Specifications of the National Energy Administration, provincial development and reform commission grid connection process guidelines, project pre-approval form templates, and local government service center handling rules. Updates are synchronized dynamically with national and local energy policy adjustments and newly added project filing cases. Most documents use a chaptered clause structure, containing fields such as approval node serial numbers, material requirements, handling time limits, and responsible departments. Units include working days, megawatts, ten thousand yuan, and similar units.

## What constraints these characteristics impose on the knowledge base retrieval and recall link
The chaptered long clause structure requires avoiding context breaks during retrieval, to ensure complete association of approval nodes. Clear field and unit requirements demand precise keyword matching during retrieval, to avoid result deviations caused by unit confusion. Format differences across multiple source documents require unified preprocessing logic to ensure retrieval consistency. Dynamically updated data requires the knowledge base synchronization frequency to match the pace of policy adjustments, to prevent expired policy content from being recalled.

## Three Common Misconfigurations
- Phenomenon: After upgrading a private deployment version, clicking the knowledge base file details displays "Invalid dataset file key". Cause: The secret key configuration associated with the dataset was not updated synchronously during the upgrade, causing the original file index to fail to match the new system secret key.
- Phenomenon: Pulling the document library via the API returns a large number of non-new energy development government content. Cause: The `collectionIds` parameter was not specified correctly, causing the retrieval scope to cover all government documents, which interferes with business guidance results.
- Phenomenon: When a user asks "grid connection process", the recall results lack core material list items. Cause: `datasetSearchUsingExtensionQuery` was not enabled, and scenario-related keywords were not supplemented, causing some associated documents to not be accurately recalled.
