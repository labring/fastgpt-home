# Business Process Guidance for Non-Ferrous Metal Smelting: Deployment and Upgrade

## What the Category’s Data Looks Like
The business data for this category comes from the enterprise’s internal production scheduling system, business approval platform, and environmental protection filing system.
Update frequency fluctuates in real time with production processes.
Daily business submissions trigger immediate updates. Monthly summary archiving is performed.
Most documents are structured forms, with unstructured attachments such as quality inspection reports and production ledgers.
Fields include smelting batch identifiers, raw material input quantities, production durations, quality inspection results, and more.
Units include tons, kilowatt-hours, and cubic meters.

## Constraints Imposed on Deployment and Upgrade
This category’s business data primarily consists of structured forms, paired with large volumes of production and quality inspection attachments.
Submission frequency fluctuates in real time with production rhythms.
During deployment, prioritize storage and database connections that support structured data indexing.
During upgrades, back up vector indexes for process nodes in advance. This avoids interruptions to the business guidance service.
Real-time updated business data requires database connection synchronization frequencies to match business submission rhythms. This prevents index lag.
Storage requirements for multiple attachment types require configuring compliant storage endpoints and reasonable file upload limits.

## Configuration Settings

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `MONGODB_URI` | Connection address pointing to the internal structured business database; set maximum connection pool size to 200 | Meets storage needs for structured forms and approval data from non-ferrous metal smelting businesses, and avoids concurrent access timeouts |
| `REDIS_URL` | Configured as the local cache service address; set cache expiration time to 1800 seconds | Caches frequently accessed process node information to meet response speed requirements for real-time business guidance |
| `STORAGE_S3_ENDPOINT` | Endpoint address pointing to the enterprise’s internal object storage service; set maximum single file upload size to 1000 MB | Meets storage needs for large attachments such as quality inspection reports and production ledgers |
| `DB_MAX_LINK` | Set to 150–200 | Matches maximum concurrent connection limits for the enterprise’s internal database, preventing resource exhaustion |
| `FE_DOMAIN` | Enter the domain name of the enterprise’s internal business system | Ensures jump links in business process guidance point to internal compliant addresses |
| `ROOT_KEY` | Configured as the management key specified by the enterprise | Restricts modification permissions for the process guidance knowledge base by unauthorized users |

## Three Common Configuration Errors
- After deployment, a file parsing failure error is returned when processing smelting quality inspection PDF attachments. The cause is incorrect configuration of `STORAGE_S3_ENDPOINT`, leading to insufficient file read permissions to access attachment content.
- After upgrade, the number of split steps in the business process guidance decreases. The cause is failure to regenerate vector indexes for process nodes. The old index does not match the new knowledge base structure.
- A service error occurs after adding a structured business knowledge base. The cause is insufficient connection permissions configured for `MONGODB_URI`, preventing access to structured form data for smelting businesses.

## How to Verify Successful Configuration
- Submit a simulated smelting business approval form. Verify the process guidance page correctly displays operation steps for the corresponding nodes.
- Upload a smelting quality inspection PDF attachment. Confirm the service can read the file normally and generate knowledge base entries without parsing errors.
- Check database connection logs. Confirm the connection status for `MONGODB_URI` is normal, with no timeout or permission errors.
- Perform a version upgrade operation. Verify original business process guidance configuration is not lost, and the service operates normally for external access.
