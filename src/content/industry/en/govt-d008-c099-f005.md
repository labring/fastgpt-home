# Business Process Guidance for Oil and Gas Exploration and Development: Tool Calling and Plugins

## What the data for this category looks like
Data for oil and gas exploration and development mainly comes from drilling logs, well logging reports, reservoir simulation files, and on-site construction records. The data covers all operation phases of exploration, development, and operations. Structured data is stored classified by well ID, operation time, and equipment parameters. Unstructured data includes core scan images, well logging curve files, and construction videos.
Structured fields include well depth (unit: meters), permeability (unit: millidarcy), and formation pressure (unit: megapascals). Most unstructured file formats are PDF, TIFF, and CSV.
The data update cadence adjusts based on the operation phase: routine drilling data is updated daily, and reservoir simulation results are updated irregularly as parameters are iterated.

## What constraints these characteristics impose on tool calling and plugins
Structured professional fields and multi-format unstructured files for oil and gas exploration and development create multiple constraints for tool calling and plugin configuration. Professional data units and field names follow petroleum industry standards. Field mapping must be completed in advance when calling tools to avoid parameter mismatches that cause abnormal results.
Unstructured well logging images and long-cycle drilling reports have large file sizes. The load per single tool call must be limited to prevent context overflow. Real-time drilling data updates frequently. Plugin call triggers must match the on-site operation response window. Excessive delays will disrupt the continuity of business process guidance.

## Three common configuration errors
- Tool calling returns `You need to use the app key rather than the account key` error. Cause: Did not use application-level keys for tool calling, mistakenly filled account keys into configuration items.
- Structured field units returned after tool calling do not match. Cause: Did not configure industry standard field mapping rules, directly used general parameter parsing for professional data.
- Empty results returned after executing text-to-structured query via plugin. Cause: Did not configure query mapping rules for oil and gas industry professional fields, causing query statements to fail to match actual data structures.
