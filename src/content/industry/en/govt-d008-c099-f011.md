# Business Process Guidance for Oil and Gas Exploration and Development: Forms and Interactions

## What data looks like for this category
Data for oil and gas exploration and development mainly comes from drilling raw logs, seismic exploration reports, trial production capacity reports, business approval documents, and similar sources. Data update rhythm changes with project phases. Single well data is updated in real time after drilling operations are completed. Global reserve data is updated after overall block assessment is finished. Document structure includes structured fields and long text attachments. Structured fields include well ID, operating depth, formation pressure, daily oil production, and similar items. Units are mostly meters, megapascals, cubic meters, and tons. Long text attachments are mostly professional technical analysis reports, with lengths up to tens of thousands of characters.

## What constraints do these characteristics impose on forms and interactions
The data characteristics of oil and gas exploration and development impose multiple constraints on the forms and interactions link.
Many structured fields and complex unit systems require forms to support automatic unit matching and real-time verification to avoid input errors.
A high proportion of long professional reports requires forms to support large file uploads and progress display, adapting to attachment parsing of tens of thousands of characters.
Dynamically updated data tied to project phases requires dropdown options in forms to pull latest operating nodes, approval roles, and other data in real time, avoiding outdated options.
A high proportion of professional terms requires interaction prompts to use industry standard expressions, reducing user learning costs.

## How to set configurations
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Enable unit binding verification, support custom professional field verification | Oil and gas exploration and development fields have diverse units; binding enables automatic verification of input value and unit matching to avoid format errors |
| `userSelect` | Connect to real-time project database interface to pull latest well ID, operating node data | Exploration and development data updates dynamically with projects; real-time pulling avoids outdated options |
| Attachment upload limit | 1000 MB, support chunked upload | Professional reports can be tens of thousands of characters; large file upload limit must adapt to business needs |
| Real-time data refresh interval | 30–60 seconds, calibrated via actual testing | Project data updates rapidly; moderate refresh interval balances performance and data timeliness |
| Input format prompt | Display industry standard examples such as "100 cubic meters", "50 megapascals" | High proportion of professional terms; standard examples reduce user learning costs |

## Three common configuration errors
- Scenario: After entering a project-specific personnel account in the form, the system prompts that the username is invalid. Cause: The `formInput` configuration is not connected to the project's internal permission database, only calls the global default user pool interface, and cannot recognize project-specific accounts.
- Scenario: When importing a drilling report attachment with tens of thousands of characters, the page keeps refreshing and the specified parsing page cannot be selected. Cause: The attachment upload timeout setting is too short; the timeout interrupt is triggered during large file parsing, causing abnormal page status.
- Scenario: When speaking the formation pressure value via voice input, the system cannot recognize professional unit terms such as "megapascals", "cubic meters". Cause: No dedicated speech recognition vocabulary list for oil and gas exploration and development is configured; general speech models have insufficient recognition accuracy for industry terms.

## How to confirm the configuration is correct
- Submit a test well ID data, check whether the system automatically verifies unit matching, confirm that the `formInput` verification rule has taken effect.
- Upload a professional report larger than 500 MB, check whether the page displays upload progress and has no abnormal refresh, confirm that the attachment upload configuration meets business needs.
- Select an operating node option within the project, check whether the dropdown list contains the latest project node data, confirm that the `userSelect` data source configuration is enabled.
- Enter the professional term "daily oil production", check whether the interface displays the corresponding unit prompt example, confirm that the format prompt configuration has taken effect.
