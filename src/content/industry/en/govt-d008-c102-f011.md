# Workflow Guidance for Refinery and Chemical Production Operations: Forms and Interactions

## What this category of data looks like
Data sources include manufacturing execution system (MES), distributed control system (DCS), equipment maintenance work order system, and raw material and product quality inspection reports. Update frequency follows three patterns: process parameter data updates every 10 seconds, work order data updates in real time with processing nodes, and quality inspection reports update after batch completion. The structure of a single data document includes equipment number, process parameter value, timestamp, processing node, responsible person, and status fields. Fixed units are megapascals (MPa) for pressure, degrees Celsius (℃) for temperature, and cubic meters per hour (m³/h) for flow. String fields such as work order number and equipment ID are also included.

## Constraints Imposed on Forms and Interactions by These Characteristics
Real-time updates of process parameters require forms to dynamically load the latest values. This prevents business judgment errors caused by cached old data. Fixed unit fields require the interaction process to automatically match corresponding units. Manual input of non-standard units is prohibited, which reduces data format errors. The real-time update feature of work orders with processing nodes requires forms to bind real-time node status. Completed or unavailable operation items are disabled. Preset fields for equipment and work orders require forms to provide optional value lists. This reduces manual input format errors and ensures data meets system docking requirements.

## Three Common Mistakes
- An error message `failed to create post p` appears when uploading a text dataset. The cause is failure to upload files in accordance with format requirements of refinery operation documents, including unescaped special characters or single file size exceeding system limits.
- Complete final results cannot be obtained after enabling streaming return mode when calling an interface. The cause is failure to configure streaming result splicing logic for `formInput`, and failure to properly process chunked returned content.
- Refinery operation variable fields cannot be correctly referenced during knowledge base search. The cause is failure to bind knowledge base variables to corresponding form fields, leading to variable matching failure.

## How to Confirm Configuration is Complete
- A test text file for refinery operations is uploaded, and successful completion of the upload without error prompts is verified.
- The streaming interface configured with `formInput` is called, content is received and spliced in chunks, and acquisition of complete final results is verified.
- Preset equipment or work order options are selected in the form, and correct matching of knowledge base variables and return of corresponding content is verified.
- A 10–15 second wait period passes, and automatic update of process parameters in the form to the latest values is verified.
