# Coal Chemical Industry Business Process Guidance: Forms and Interactions

## What this category of data looks like
Coal chemical business processing data is sourced from internal project approval systems and safety and environmental protection supervision declaration platforms of state-owned and central enterprises. Data updates follow business processing node progress. Data only updates when a link changes during a single processing cycle. The core of the data is structured forms, including fields such as the unified social credit code of the applicant, project filing number, designed production capacity (unit: 10,000 tons/year), core process type, and declaration date. Some associated documents come with PDF attachments of process flow diagrams.

## What constraints do these characteristics impose on the forms and interactions link
Structured fields for coal chemical business processing have fixed units and exclusive classifications. Interaction links must enforce verification that field formats match units to avoid invalid inputs. Data updates with processing nodes, so forms must support dynamic loading of required fields for the current approval link to avoid redundant content. Submission of large attachments such as associated process flow diagrams requires stable upload interaction logic to prevent timeout interruptions. Process type options for different projects are fixed, so interactions must provide pre-selected menus to reduce manual input errors. Multi-link handover of business processes must clarify jump logic between the current step and subsequent steps in form interactions to avoid process confusion.

## How to set the configurations
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `formInput` | Split by business link, each link corresponds to a set of input fields | Coal chemical business processing has multiple approval links, splitting clarifies the interaction scope of the current step |
| User input validation | Validate that field formats match preset units, for example, production capacity only allows positive integers plus 10,000 tons/year | Coal chemical form fields have fixed unit requirements, validation reduces invalid data |
| `userSelect` | Pre-set process type options, including common types such as coal-to-olefins, coal-to-natural gas | Coal chemical process type classifications are fixed, pre-selection improves interaction efficiency |
| Single upload attachment limit | 2 attachments, each no larger than 500 MB | Attachments such as process flow diagrams have large volume, limiting quantity avoids upload timeouts |
| Upload timeout setting | 600 seconds | Large attachment uploads require sufficient time, calibrated based on actual testing |

## Three common mistakes
- Phenomenon: After referencing a custom plugin and connecting it to a code execution link, clicking the form input field triggers an error, and the interface displays "Invalid input parameter". Cause: The input fields required by the plugin are not bound in the `formInput` configuration, causing the code execution to fail to obtain the corresponding parameters.
- Phenomenon: In multi-round business processing conversations, the project number output by the AI in the previous round is not automatically filled into the corresponding field of the current form, requiring manual re-entry. Cause: The context inheritance configuration of `userSelect` is not enabled, and the output result of the previous conversation is not used as the default value of the current form.
- Phenomenon: When uploading a process flow diagram attachment, it fails directly after exceeding the configured attachment size limit, with no clear prompt. Cause: The error prompt logic for attachment uploads is not configured, and no specific problem is fed back to the user after large file upload timeouts.

## How to confirm the configuration is complete
- Enter the form configuration page, and check one by one that the input fields for each business link match the actual fields of the coal chemical business form.
- Trigger the approval node switch operation, confirm that only the required fields for the current link are loaded, and fields for non-current links are not displayed.
- Upload test attachments, confirm that the upload process complies with the configured quantity and size limits, with no abnormal errors.
- Simulate multi-round conversation interactions, confirm that data such as project numbers generated in previous conversations can be automatically filled into the corresponding form fields.
