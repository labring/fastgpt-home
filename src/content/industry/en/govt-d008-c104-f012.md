# Coal Chemical Industry Business Handling Process Guidance: Deployment and Upgrade

## What the data for this category looks like
Data for coal chemical business handling processes is primarily sourced from internal enterprise production scheduling systems, process approval platforms, and safety operation management systems. Updates occur each time a process starts, a node receives approval, or a process is completed, triggered by business node workflow. Each business document includes fields such as process node code, node name, handling time limit, required material list, responsible position, and safety check items. Material types include equipment maintenance tickets, hazardous chemicals requisition forms, work permit forms, and similar documents. Field units include hours, copies, items, and similar units.

## What constraints these characteristics impose during deployment and upgrade
Coal chemical business data contains sensitive safety check fields. During deployment, permission-isolated databases and storage nodes must be configured to prevent unauthorized access. Business process data volume fluctuates with production cycles. During upgrade, sufficient database connection pool resources must be reserved to support concurrent requests. Localized deployment scenarios are common, so adaptation to ARM architecture and Kirin operating system is required. Frequent process updates require that upgrades do not interrupt existing services, so rolling upgrade methods must be used.

## How to set configurations
The following configurations are formulated based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `MONGODB_URI` | Internal dedicated MongoDB cluster address, configured with read-write separation nodes | Coal chemical business process data volume is large, read-write separation reduces pressure on single nodes |
| `REDIS_URL` | Redis cluster address with persistent configuration, memory allocation no less than 16 GB | Requires caching process node permissions and temporary session data to ensure high-frequency access response |
| `STORAGE_S3_ENDPOINT` | Enterprise internal object storage endpoint, configured with storage nodes in the same region as the business system | Coal chemical business documents have large volume, storage in the same region reduces access latency |
| `DB_MAX_LINK` | `100–150 connections` | Coal chemical business handling processes involve multiple concurrent requests, requiring sufficient database connection pool support |
| `ROOT_KEY` | Random string of 16 characters or more | Ensures the security of background management permissions and prevents unauthorized access |

## Three Common Mistakes
- After upgrade, the process guidance function fails to load historical business data, with an error showing database connection timeout. Cause: Did not execute incremental scripts according to the version upgrade instructions, and directly overwrote the deployment, resulting in incompatible database structures.
- Dependency packages or tools fail to install in the container, with an insufficient permissions prompt. Cause: Did not enter the container using `docker exec --user root` to perform operations; the default container user does not have root permissions.
- The service fails to start after deployment in a localized environment (Kunpeng 920 + Kirin V10). Cause: Did not use the FastGPT image adapted for ARM architecture, and directly used the x86 image, resulting in operational exceptions.

## How to Confirm Configuration is Complete
- Run the `docker ps` command to confirm that all FastGPT-related containers are in running state.
- Access the configured `FE_DOMAIN` address to verify that the business handling process guidance page loads normally.
- Submit a test business process data to verify that the database can write data normally and the Redis cache can read data normally.
- Check the storage node corresponding to `STORAGE_S3_ENDPOINT` to verify that process attachments can be uploaded and downloaded normally.

The values provided are common starting points and should be measured against the reader's own samples.
