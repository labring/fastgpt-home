# Coal-electricity Integrated Business Process Guidance: Forms and Interactions

## What the Data for This Category Looks Like
Coal-electricity integrated business process data comes primarily from mine production management, coal procurement, power dispatch, and cross-sector collaborative approval systems. Data updates per business node. Single approval process data syncs daily. Ledger data updates per shift.
Documents center on structured forms, with fields including mine number, coal calorific value, unit load, and approval node status. Units include tons, kilowatt-hours, pieces, and other standard units. Some associated attachments use PDF or structured table formats.
This document is written based on FastGPT v4.17.0 configuration logic.

## What Constraints These Characteristics Impose on the "Forms and Interactions" Link
Structured forms have many fields and connect cross-sector business. Interaction configuration needs field linkage verification. This avoids invalid input or data conflicts.
Cross-system data update frequencies differ. Systems must support real-time data pulling and cache fallback mechanisms. This adapts to latency requirements for different scenarios.
Attachment types include PDF and structured tables. Multi-format upload verification rules must be adapted. This ensures files can be parsed correctly.
Approval nodes have hierarchical links. Interactions must clearly show the current processing link and upstream/downstream associations. This prevents incorrect process jumps.

## Three Common Mistakes
- Phenomenon: Form interaction cannot start directly via text. A voice button must be triggered. Cause: The form’s default text interaction activation configuration is not enabled, and the voice trigger entry is force-bound.
- Phenomenon: Some associated fields are empty after form submission. Cause: The linkage verification rule for `formInput` is not configured, causing cross-sector business fields to fail to automatically synchronize data.
- Phenomenon: Page load times out, returning status code 504. Cause: Form segment loading is not implemented, and loading all cross-system business data at once exceeds the interface response threshold.

## How to Confirm the Configuration Is Complete
- Fill the associated fields of the form sequentially, and check whether the corresponding linked fields automatically update their values.
- Upload business attachments of different formats, and confirm that the system only allows file types and sizes within the configured range.
- Disconnect the session and re-enter the form page, and check whether previously filled content is retained.
- Attempt to access the form with a non-authorized role, and confirm that sensitive fields across nodes cannot be modified.
