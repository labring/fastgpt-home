# Mining and Mineral Processing Business Handling Process Guidance: Workflow Orchestration
This document is written based on FastGPT v4.17.0.

## What the data for this category looks like
Business data for mining and mineral processing originates primarily from three sources: production scheduling systems, concentrator PLC collection equipment, and safety inspection ledgers. Data update rhythms fall into two categories: real-time sensor data updates every 60 seconds, and daily production reports are generated and archived after shifts end. Documents are structured by mining area, process, and shift, and include fields such as mining stripping volume, selected grade value, equipment operating duration, and tailings discharge volume. The units for these fields are tons, grams per ton, hours, and cubic meters respectively. They also include business handling-related fields such as process order numbers and handling node statuses.

## What constraints do these characteristics impose on the "workflow orchestration" link
Real-time sensor data’s high-frequency update rate requires workflows to use a matching trigger frequency, to avoid excessive resource consumption from over-pulling or delayed processing of abnormal data. Multi-process associated business logic requires workflows to bind fields for corresponding processes via `nodeId`, to ensure accurate cross-node data transfer. Differences in update rhythms across data sources require configuring separate trigger nodes for real-time data and scheduled reports, to avoid process execution chaos. Additionally, the diversity of field units requires adding format conversion nodes in workflows to unify data formats across different links.

## Configuration Settings
| Config Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Trigger Method | Trigger on `variables` update; real-time data sources trigger every 60 seconds | Matches the update frequency of real-time sensor data for mining and mineral processing to ensure data timeliness |
| Global Variable Mapping | Bind process-specific fields via `nodeId` | Accurately matches business fields for different process nodes to avoid cross-node data transfer errors |
| Node Timeout Setting | 300 seconds | Adapts to the typical time required for pulling mining equipment inspection data to prevent process blocking |
| Component Parameter Adjustment | Set the timing for data panel components to bind global variables to after node execution completes | Ensures that retrieved global variables have completed assignment |
| Log Output Configuration | Enable code running node printing | Facilitates troubleshooting of abnormal issues during process execution |
| Single Data Pull Volume | Top 20 entries | Matches the typical data volume of single-shift inspection ledgers to avoid data overload |
| File Generation Configuration | Disable reference display toggle | Prevents generated business reports from including irrelevant reference content |

## Three Common Mistakes
- A data panel shows unassigned global variables after clicking a button: The cause is that variable retrieval timing is set before node execution, at which point global variables in the workflow have not completed assignment.
- Workflow-generated business reports include irrelevant knowledge base reference content: The cause is that the reference display toggle was not disabled in the file generation configuration.
- No print information is output from code running nodes: The cause is that the process log printing configuration was not enabled, or the debug node was not associated with the current workflow's context.

## How to Confirm Proper Configuration
- Manually trigger the corresponding process node, view the real-time update log of `variables` to confirm that business data has been correctly transferred to global variables.
- Click the button bound to global variables, check that the field values displayed on the data panel match the actual business data.
- Run the code running node, view the print information in the process log to confirm that the output content is normal.
- Generate a business report, check that no irrelevant reference content is included to confirm that the configuration has taken effect.
