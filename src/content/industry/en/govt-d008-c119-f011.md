# Steel Smelting Business Process Guidance: Forms and Interactions

## What Data for This Category Looks Like
Business data for steel smelting mainly comes from production execution systems (MES), equipment PLC collection terminals, quality inspection reports, and equipment ledgers. Data update frequencies cover three categories: real-time (equipment operating parameters), daily (shift production reports), and monthly (monthly production capacity statistics). Single business documents mostly include structured fields such as furnace number, smelting temperature, component content, and finished product weight. Most fields are numeric or enumeration types. They are also accompanied by unstructured process description attachments, mainly in Excel and PDF formats.

## What Constraints These Characteristics Impose on the "Forms and Interactions" Link
The large number of structured fields with fixed units requires forms to be configured with unit validation rules to prevent mismatched input values and units. Enumeration fields such as furnace number and process type need selection components to limit input ranges and reduce manual entry errors. Real-time updated equipment parameters require forms to support real-time data pulling or scheduled synchronization to avoid using outdated data. Multi-format attachment upload requirements require the interaction link to adapt to parsing for different file formats. It also requires limiting single attachment and total upload volume to prevent parsing failures.

## How to Configure the Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` field validation rules | Bind corresponding unit validation to each numeric field, bind preset options to enumeration fields | Matches the characteristics of steel smelting data with many structured, unit-bearing and enumeration traits, reduces entry errors |
| `userSelect` component linkage logic | Automatically load preset fields for the corresponding process after selecting a furnace number | Matches the binding relationship between furnace number and process, simplifies the entry process for business handling |
| Total uploaded file size limit | 1000 MB | Adapts to the single-file volume requirements of process files which are mostly Excel or PDF, prevents upload failures |
| Form step-by-step loading rule | Split the form by ironmaking, steelmaking, and rolling stages | Matches the business process logic of multi-stage steel smelting, avoids operational confusion caused by too many fields on a single page |
| Input character limit | 800–1200 characters | Adapts to the conventional input length for business handling descriptions, prevents exceeding model processing thresholds |
| Real-time data synchronization switch | Enable real-time pulling of MES data | Matches the real-time update characteristics of equipment parameters, ensures the timeliness of form data |

## Three Common Misconfigurations
- Phenomenon: Uploaded steel smelting process Excel files are not used by the large model for statistical summary, and conversation return results do not include file content. Cause: The uploaded file is not bound to the input context of the `formInput` component, so the file is not included in the input pool for model calls.
- Phenomenon: Submitted JSON-format steel smelting data files exceed the limit, and a character limit error pops up on the interface. Cause: The input character limit configuration of the form is not adjusted, and the default threshold cannot cover the upload requirements of batch data.
- Phenomenon: After the released business handling form page is scaled, the form fields and button layout are disordered, and content cannot be displayed normally. Cause: Responsive layout parameters of the form are not configured, and element size adaptation under different screen zoom ratios is not implemented.

## How to Verify the Configuration Is Correct
- Enter a numeric field with a unit, check if a unit mismatch prompt pops up, verify that the `formInput` validation rules take effect.
- After selecting a furnace number, check if the preset fields for the corresponding process are automatically loaded, verify that the `userSelect` linkage logic works normally.
- Upload an Excel file within 1000 MB, check if the file is properly parsed and included in the conversation context.
- Adjust the page zoom ratio to 50% and 200%, check if the form layout remains complete with no content loss.

The values listed above are common starting points and should be measured against the reader's own samples.
