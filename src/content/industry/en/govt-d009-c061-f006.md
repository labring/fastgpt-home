# Party Building Learning Assistant for Meeting Spirit Summaries: Citation Sources and Traceability

## What This Category of Data Looks Like
The data source for meeting spirit summaries is official conference formal documents and supporting explanatory materials. Its update cycle aligns with the release process of the corresponding conference. Document structure includes modules such as conference theme, core arguments, domain-specific deployments, and participating entities. The core fields are conference name, holding time, original text link, and core summary content. Individual content lengths range from short press releases to full meeting transcripts, with no unified fixed word count range. Overall text uses formal wording as the primary style.

## Constraints Imposed on Citation Sources and Traceability
Official authoritative documents require traceability to be tied to a unique original source and publishing entity. This prevents questions about the authority of cited content. The conference-aligned update cycle requires traceability to support quick access to new conference documents without extra preprocessing. The wide range of document lengths requires traceability to adapt to citations of original text fragments of different sizes. This avoids truncation of key arguments. The field structure centered on conference identifiers requires traceability to associate identifiers such as conference name and holding time. This helps users accurately locate target conference content. These constraints together mean configuration must balance accuracy, timeliness, and adaptability.

## Configuration Settings
Configuration specifications are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `1200–2800 token` | Original text fragments of meeting spirit summaries have a wide range of lengths. This parameter controls the token limit for cited content, adapting to conference documents of different sizes |
| `responseData` | Includes original text link, conference name, holding time | Matches the field structure of meeting spirit summaries, ensuring clear conference identifiers and original sources are available during traceability |
| `detail` | Enabled | Core arguments of meeting spirit summaries must be fully presented. Enabling this returns more detailed original text citation fragments |
| Citation Limit | Top 3–5 entries | Single conference documents have substantial content. Limiting citation counts avoids token overflow, adapting to context length requirements for party building learning scenarios |

## Three Common Configuration Errors
- Phenomenon: After setting `quoteMaxToken` to 2000 tokens, the generated meeting spirit summary still triggers a token overlimit error. Reason: Original text fragments of meeting spirit summaries usually contain many technical terms and long sentences. Actual token usage is higher than general text, and the default calculation logic does not adapt to this category's text characteristics.
- Phenomenon: The published party building learning assistant page does not display the original conference text source link. Reason: The `responseData` parameter is not configured to an output format that includes the original text link. Traceability information is not included in the response content.
- Phenomenon: The generated summary cites document content from non-target conferences. Reason: Identifier fields such as conference name and holding time are not bound during the search phase. Recalled content does not match the target conference.

## How to Confirm Proper Configuration
- Launch a meeting spirit summary generation test, and check whether the response result includes traceability information such as original text link and conference name.
- Adjust the `quoteMaxToken` parameter, test response token usage across different values, and confirm alignment with the scenario's context length requirements.
- Generate summaries for conference documents of different sizes, and verify that recalled citation fragments match the target conference content.
- Check the published assistant page, and confirm that traceability information is normally displayed below the summary.
