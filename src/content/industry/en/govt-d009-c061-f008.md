# Party Building Learning Assistant for Meeting Spirit Summaries: Document Parsing and Chunking

## What this category of data looks like
Data sources are official meeting minutes, leadership speech manuscripts, and meeting resolution documents issued by Party organizations at all levels. Update frequency adjusts irregularly along with meeting schedules, with no fixed cycle. Document structures usually include hierarchical modules such as meeting theme, holding time, attendance scope, core speech content, and resolution matters. Most fields use formal written expressions. Statistical dimensions include character count, page count, and meeting duration.

## Constraints on Document Parsing and Chunking
Documents for meeting spirit summaries use mostly formal written language, with a high proportion of long paragraphs. Chunking must avoid splitting core semantics and resolution points. Documents have clear title hierarchies. Chunking must adapt to topic logic and must not split content across topics. Some documents include multi-page attachments and embedded images. Parsing must support extraction of large files and multimedia content. Updates have no fixed cycle. Parsing configurations must have flexibility to adapt to manuscripts of different lengths and structures.

## Configuration Settings
This page’s configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Documents for meeting spirit summaries use mostly formal written language. Long paragraphs need splitting while retaining semantic integrity. This range adapts to the length of most Party building meeting manuscripts |
| `chunkSplitter` | Split by title hierarchy | Meeting manuscripts have clear topic and point-based structures. Splitting by title preserves logical relevance and avoids splitting core content across topics |
| `customPdfParse` | Enable official PDF parsing plugin | Party building meeting documents use mostly formal typeset PDFs. The official plugin accurately extracts text, title hierarchies, and embedded image information |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Some meeting minutes include multi-page attachments and high-definition images. Large file upload support is needed to fully parse all content |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Long document parsing requires sufficient time to avoid mid-process timeout interruptions and ensure complete parsing workflow |
| `chunkSettingMode` | Manual configuration | Adjust chunking parameters based on the paragraph density of meeting manuscripts to adapt to meeting documents with different content structures |

## Three Common Misconfigurations
- Phenomenon: A GPU memory overflow error appears after starting the parsing service, and PDF documents cannot be processed normally. Cause: GPU resource allocation is not configured correctly, or parsing plugins and chunking parameters that exceed the graphics card's memory limit are enabled.
- Phenomenon: After importing a Word document, the domain name information of original images is lost, and images cannot load normally in conversations. Cause: The configuration to retain image external links during document parsing is not enabled, and only local image paths are retained.
- Phenomenon: Other devices on the local network cannot access the login page, returning an ERR_INCOMP error. Cause: The local network access permission for the service is not configured, or there is an abnormality in port mapping.

## How to Verify Correct Configuration
- Upload a standard Party building meeting minutes PDF, and check if the parsed text fully retains titles, topics, and core points.
- Check parsing task logs to confirm GPU resources are being called normally, with no GPU memory overflow or timeout errors.
- Import a Word document containing images, and check if the parsed Markdown content retains the original external link addresses of the images.
- Try to access the service address from other devices on the local network to confirm the page loads normally.

The values provided are common starting points and should be measured against the reader's own samples.
