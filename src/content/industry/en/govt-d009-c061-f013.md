# Party Building Learning Assistant for Meeting Spirit Summaries: Sharing and Embedding

## What this category of data looks like
The data for the party building learning assistant for meeting spirit summaries originates from officially released party building meeting transcripts, compiled meeting speech excerpts, and formally issued meeting minutes. Updates align with the scheduling of important party building meetings, with supplementary improvements made as needed on an ongoing basis. The document structure includes four fixed fields: meeting topic, holding time, core discussion points, and implementation requirements. Each individual piece of content is concentrated in the range of several hundred words, with no redundant formatted content.

## What constraints do these characteristics introduce for the sharing and embedding process
Since the data source is official party building materials, the content is rigorous and access scope must be controlled. The sharing and embedding process must strictly follow permission rules. The fixed document structure requires retaining the field hierarchy during embedding, and the content order cannot be arbitrarily altered. Following the update schedule tied to important meeting nodes, a regular synchronization mechanism must be configured to ensure embedded content uses the latest version. Additionally, the concentrated length of individual entries requires embedding container sizes to match standard party building platform content blocks, to avoid content truncation. Furthermore, the `shareId` associated with a sharing link must be bound to the corresponding workspace’s permissions to prevent unauthorized access.

## How to set the configurations
This configuration guide is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Sharing link permission | Only accessible to internal users | Meeting spirit summaries are internal party building learning materials, and access scope must be strictly controlled |
| `shareId` binding rule | Bind the team permissions of the current workspace | Ensure shared content is only visible to authorized personnel, in compliance with the confidentiality requirements for party building materials |
| Embedding container height | 300–500 pixels | Individual summary content is concentrated in several hundred words, adapted to the content blocks of standard party building platforms |
| Automatic synchronization frequency | Every 7 days | Meeting spirit summaries are updated alongside important meeting schedules; regular synchronization ensures content timeliness |
| Content display format | Retain the original document's title and point hierarchy | The structured fields of meeting summaries must be fully presented to facilitate learning and reference |
| Sharing link validity period | 180 days | Reduce invalid sharing links that have not been used for a long time, while meeting the reuse needs of quarterly learning materials |

## Three Common Misconfigurations
- Symptom: After restarting the Windows system, sharing links disappear from the FastGPT workspace deployed via Docker. Cause: The temporary directory mounted by the Docker container does not persistently store sharing configurations, resulting in lost configurations after restart.
- Symptom: Embedded meeting spirit summaries lack core fields, and only plain text content is displayed. Cause: The embedding configuration did not retain the original document's structured field format, only extracting unhierarchical text.
- Symptom: Sharing links fail to load properly on the target party building platform. Cause: The permissions bound to `shareId` did not authorize the target platform's access scope, resulting in blocked API requests.

## How to Confirm the Configuration Is Complete
- Open the generated sharing link, verify that unauthorized users are redirected to a permission prompt page, while authorized users can view the full content normally.
- Copy the embedding code to a test page, confirm that the displayed meeting spirit summary includes complete fields such as meeting topic, holding time, and core points, with no format confusion or content truncation.
- Wait for the preset automatic synchronization cycle, refresh the embedded page, and confirm that the content has been updated to the latest meeting spirit summary version.
- Call the API interface bound to `shareId`, verify that the returned content matches the original document's structured fields exactly.
