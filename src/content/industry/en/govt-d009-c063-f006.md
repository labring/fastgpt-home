# Party Building Learning Assistant for Party Building Material Retrieval: Citation Sources and Traceability

## What the data for this category looks like
The data sources for party building material retrieval mainly include official central and local party building platforms, internal party building archives of units, and publicly available authoritative party building document compilations. Updates are synchronized on demand or at fixed intervals. Each individual document follows a standardized structure with a formal title, segmented body content, publishing entity, publishing time, and other standard fields. Unified fields include document identifier, source attribution, and topic tags. The statistical unit is a single party building learning material, with content covering categories such as party theory learning, policy interpretation, and activity records.

## What constraints do these characteristics impose on the "citation sources and traceability" link
The official and authoritative nature of party building materials requires that traceability must fully display the publishing entity and publishing time, and key attribution information must not be omitted. Fixed update cycles require the knowledge base synchronization period to match the material update frequency, to prevent traceability content from being out of sync with newly released party building materials. Clear document structures and unified field specifications require that citations must be linked to the complete identifier of the original document, and preset topic tags and other exclusive information must also be returned. This ensures the accuracy and completeness of traceability; displaying only fragmented content cannot fully present the official attributes of the material.

## Configuration Settings
This guide applies to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | The segmented content of party building materials is usually long. This value range can fully retain the context of the cited passage and avoid truncation of key expressions |
| `responseData` | Enabled | Both model responses and cited document details must be returned to meet the need to verify material authority in party building learning |
| `detail` | Enabled | Party building materials include exclusive fields such as publishing entity and publishing time. Returning all fields enables complete display of traceability information |
| Single recall passage limit | Top 3 passages | Party building material retrieval should focus on core authoritative content, avoiding excessive passages that interfere with learning and reading |
| Knowledge base synchronization cycle | 7–14 days | Matches the fixed update rhythm of most party building materials, ensuring that traceable documents remain consistent with newly released content |
| Original document preview association | Bind slices to original documents | Supports viewing the complete details of the original file corresponding to the slice, making it easy to consult full content during learning |

## Three common configuration errors
- Only returning model response text without cited document details when calling the API. Cause: The `responseData` configuration switch is not enabled, and the parameter for returning citation details is not specified.
- No citation section displayed in the terminal reply interface, or the citation fields are empty. Cause: The `detail` parameter is not configured to enable full field return, or the knowledge base synchronization cycle does not match the update rhythm of party building materials, resulting in missing document information linked by citations.
- A red numeric error is returned in FastGPT citations after the model passes testing in oneAPI. Cause: The value range of `quoteMaxToken` is not correctly configured, or it does not match the token length of party building material slices, resulting in parameter verification failure.

## How to confirm configuration is complete and correct
- Call the corresponding API interface and check whether the returned results include citation details and full document information.
- Initiate a party building material retrieval query in the terminal interface, confirm that the citation section and information such as the publishing entity and publishing time of the corresponding document are displayed below the response.
- Click the citation link to confirm that you can jump to the complete preview page of the original file.
- Check the knowledge base synchronization log to confirm that the synchronization cycle matches the update rhythm of party building materials.

The values provided here are common starting points and should be evaluated against the user’s own samples.
