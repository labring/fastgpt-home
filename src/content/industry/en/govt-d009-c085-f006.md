# Party Building Learning Assistant for Quiz Generation: Citation Sources and Traceability

## What This Category of Data Looks Like
Data for party building learning assistants' quiz generation mainly comes from authoritative party building literature, officially released learning materials, and internal training documents. The data update rhythm aligns with official policy releases or training content iterations. There is no fixed cycle, and synchronization is performed as needed. Each entry is a complete quiz question, including the question stem, options, correct answer, explanatory text, and source identification field. Question types are categorized as single-choice, multiple-choice, and true-false. Each question corresponds to a unique source file path. Data is counted in entries, and explanatory content is measured in characters.

## What Constraints Do These Characteristics Impose on the Citation Sources and Traceability Link
The data characteristics of party building learning quiz generation impose three core constraints on the citation sources and traceability link. First, each question is bound to a unique source identifier. The traceability link must accurately match the corresponding paragraph of the specific document, and cannot return only generalized source categories. Second, explanatory texts for different question types may come from different sections of the same file. The original text position corresponding to the explanation must be clearly marked during traceability. Third, data is updated with party building policy iterations. The traceability link must associate source files of the corresponding version to avoid returning outdated content. Additionally, some internal training questions only allow internal access. The traceability link must verify that the call permission matches the access scope of the source file.

## How to Configure the Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Source texts for quiz generation are mostly single-paragraph explanations or file fragments. This range covers complete traceability content without occupying excessive context |
| `responseData` | Enabled | Source information must be attached to quiz results. Enabling this allows traceability-related fields to be included in full response outputs |
| `detail` | Enable full path | Specific source file paths and paragraph positions must be returned. Returning only file names does not meet precise traceability requirements |
| Version matching switch | Enabled | Party building learning data is updated with policy iterations. Enabling this allows association with source files of the corresponding version |
| Permission verification switch | Enable per scenario | Internal training questions require call permission verification to prevent unauthorized access to source files |

## Three Common Configuration Errors
- Phenomenon: The API call returns a normal status code, but the response result does not include citation source-related fields. Cause: The `responseData` configuration item is not enabled, so traceability data is not included in the return structure.
- Phenomenon: Quiz questions can be displayed on the page, but the corresponding source original text cannot be jumped to or downloaded. Cause: No access proxy rules for traceability links are configured, so internal file paths cannot be accessed externally.
- Phenomenon: The source text returned by traceability is truncated, and complete explanatory content cannot be displayed. Cause: The `quoteMaxToken` configuration value is less than the actual token count of the source text, resulting in automatic content truncation.

## How to Verify That the Configuration Is Correct
- A quiz generation call request is initiated, and the response result is reviewed for preset citation source fields.
- The current value of `quoteMaxToken` is viewed, and it is confirmed that the value covers the length range of common source texts.
- An internal permission scenario is simulated, and it is verified that source files without access permission are not returned.
- The traceability link is clicked, and it is confirmed that the link can jump to the corresponding original text page.

The values provided are common starting points and should be measured against the reader's own samples.
