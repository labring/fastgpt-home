# Party Building Learning Assistant for Learning Quiz Generation: Document Parsing and Chunking

## What the Data Looks Like
The data sources for party building learning quiz generation primarily include official party building learning materials, internal party building training documents, and custom quiz question bank spreadsheets. Update frequency aligns with party building learning plans, with learning materials and question bank content added irregularly. Document types include plain text learning manuals, multi-column Excel question banks, and formatted PDF party building files. Structured fields include knowledge topic, question stem, options, correct answer, and explanation content. Some documents include hierarchical titles and publication metadata.

## Constraints on Document Parsing and Chunking
The data for party building learning quiz generation includes two categories: structured spreadsheets and coherent text. Chunking multi-column Excel question banks must avoid mixing content across columns. Otherwise, question stems, options, and answers will be split into separate chunks, which harms the accuracy of subsequent quiz generation. Chunking long-text learning materials must preserve the integrity of knowledge topics. Do not split learning content from the same topic into multiple unrelated chunks, as this will break the logical flow of learning. For single-attachment upload scenarios, ensure only the currently uploaded file is parsed. Avoid accidentally including historical documents in the parsing scope, as this will interfere with accurate matching of quiz questions and generation results.

## Configuration Settings
The following configurations are based on the document parsing module of FastGPT v4.17.0, and are adapted to the scenario requirements of party building learning quiz generation.

| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 characters | Adapts to the typical length of party building learning materials and quiz questions, preserving the integrity of individual questions or single sections of learning content |
| `chunkSplitter` | Split by line (Excel), Split by title + paragraph (PDF) | For multi-column Excel question banks, splitting by line ensures each row of question content forms an independent chunk. For PDF party building manuals, splitting by title + paragraph preserves the logical connection of knowledge topics |
| `customPdfParse` | Enabled | Preserves the original formatting structure of PDF documents, preventing titles and paragraphs from being automatically rearranged by the system |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Provides sufficient parsing time for large Excel question banks or multi-page PDF documents, avoiding parsing failures due to timeout |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Meets the upload requirements for large-capacity party building question bank files, preventing files from being blocked due to exceeding size limits |
| `chunkSettingMode` | Manual configuration | Allows adjustment of chunking rules for different types of party building documents, enabling precise matching of parsing requirements for quiz generation |

## Three Common Misconfigurations
- After uploading a multi-column Excel question bank, the automatic chunking result is disorganized, with each row of questions split into separate chunks. This occurs because the default chunking rule uses paragraph or general line break splitting, and does not adjust the chunking logic for structured spreadsheets.
- When uploading a single party building document, previously uploaded document content is also parsed and loaded. This occurs because the single-file independent parsing mode is not enabled, and the system performs batch parsing of all previously uploaded documents by default.
- A timeout error occurs when parsing a large multi-page PDF party building manual, with the task status showing a timeout exception. This occurs because the `PARSE_FILE_TIMEOUT_SECONDS` parameter is not adjusted, and the default timeout duration is insufficient to complete full parsing of multi-page documents.

## How to Verify Proper Configuration
- Upload a test multi-column Excel question bank, view the parsed chunk list, and confirm that each row of question content forms an independent chunk.
- Upload a single PDF party building learning manual with titles, and check if the parsed result preserves the connection between original titles and their corresponding paragraphs.
- Review the parsing task logs, confirm that only the currently uploaded document is included in the parsing scope, and no historical document content is loaded.
- Wait for the parsing task to complete, then check if the task status shows success, with no error or exception prompts.
