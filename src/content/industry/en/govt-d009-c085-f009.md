# Party Building Learning Assistant for Learning Quiz Question Generation: Model Access and Configuration

## What the data for this category looks like
The core data sources for party building learning quiz question generation are official party building knowledge bases, public party building policy documents, and internal party building learning materials. The update rhythm adjusts dynamically with policy releases or quarterly updates. Each data entry includes three core fields: topic category, original text content, and release date. The unit of measurement is "article" or "entry". The original text content is standardized text with no redundant formatting. Its length ranges from short-to-medium policy explanations to complete party building activity records.

## What constraints these characteristics impose on the model access and configuration step
The fixed topic category field for party building learning quiz question generation requires the model to accurately match knowledge base content corresponding to its category. Teams must configure parameters that carry category information in the context during model access. The length of single original text content varies widely, so teams must limit the total text amount passed to the model in a single round to avoid exceeding the model's context window limit. Data updates adjust dynamically with policy releases, so teams must configure trigger logic for automatic knowledge base synchronization. This ensures the model uses the latest party building learning materials when called. Quiz question generation must strictly rely on the provided knowledge base content, so teams must restrict the model's permission to call external unrelated information.

## How to set the configuration
This configuration is formulated based on the parameter logic of FastGPT v4.17.0.

| Configuration Item | Recommended Value Range | Rationale |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | Adapts to the length range of party building original texts, avoiding truncation of core content used for question generation |
| `maxTokens` | 1500–2000 token | Controls the output length of a single quiz set, ensuring it aligns with the question generation scope of party building learning materials |
| `quoteMaxToken` | 3000 token | Limits the length of knowledge base original text referenced in a single round, ensuring the model only uses valid question generation materials |
| `temperature` | 0.2–0.4 | Reduces generation randomness, ensuring generated question content strictly matches the standardized wording of party building knowledge bases |
| `toolChoice` | "none" | Disables external tool calls, ensuring question generation only relies on the configured party building knowledge base content |
| `AIPROXY_API_ENDPOINT` | Fill in according to the deployed model service address | Connects to compliant large model services, ensuring data transmission meets security requirements |
| `AIPROXY_API_TOKEN` | Fill in according to the key provided by the service provider | Verifies access permissions for the model service, ensuring call legitimacy |

## Three common mistakes
- Phenomenon: Model calls return an "Invalid API endpoint" error. Cause: The `AIPROXY_API_ENDPOINT` parameter is not filled correctly, or the deployed model service does not adapt to FastGPT's call format.
- Phenomenon: Generated quiz questions include external content not from the party building knowledge base. Cause: `toolChoice` is not set to "none", so the model calls external tools to obtain irrelevant information.
- Phenomenon: Generated quiz questions reference too many irrelevant knowledge base entries. Cause: The model is not restricted to only selecting knowledge base entries with high matching scores, resulting in non-target topic party building materials being included.

## How to confirm the configuration is complete
- Enter the model management page, view the configured model parameters, and confirm that the values of `maxContext`, `maxTokens` and other parameters match the configuration requirements.
- Manually trigger a quiz question generation task, and check whether the generated questions only rely on the configured party building knowledge base content, with no external irrelevant information.
- Check the model call logs, confirm that the API request carries the correct `AIPROXY_API_TOKEN` and `AIPROXY_API_ENDPOINT` parameters, with no error returns.
- Test party building knowledge base content of different categories, confirm that the generated quiz questions match the corresponding category topics, with no cross-category incorrect content.

The values provided are common starting points and should be measured against the reader's own samples.
