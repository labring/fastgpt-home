# Party Building Learning Assistant for Quiz Generation: Knowledge Base Retrieval and Recall

## What Data for This Category Looks Like
Data sources include internal party regulatory documents, official party building learning materials, and audited public quiz question banks.
Update frequency aligns with latest party building learning requirements. There is no fixed cycle, but core content updates occur no more than once every six months.
Document structure is organized per single question or single quiz set. Each entry contains question stem, alternative answers, standard answer, knowledge point annotation, and applicable learning stage fields.
There are no complex nested structures. All fields use standardized party building-related tags.
The unit for counting single questions is "question".
Single question text length mostly ranges from 100 to 500 characters.

## Constraints on Knowledge Base Retrieval and Recall
Party building learning quiz data includes standardized party building knowledge point tags and applicable learning stage fields. Retrieval must perform precise filtering by tags and permissions to prevent recalling unsuitable content.
Data updates have no fixed cycle. The knowledge base must support incremental recall updates to avoid delays caused by full reindexing.
Single question structure is clear but has clear associated knowledge points. Retrieval and recall must match both question stem content and associated knowledge points, avoiding recalling only isolated text.
Party building content has hierarchical access permissions. The retrieval link must adapt to permission verification logic. Only documents matching internal management requirements of government and state-owned enterprises can be recalled.

## Configuration Settings
| Configuration Item | Recommended Range | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Party building content has high semantic relevance. A value too low will recall irrelevant party building text, while a value too high will miss associated questions related to knowledge points |
| `limit` | Top 8–12 results | A single quiz requires association with multiple knowledge points. Too many recalled results will cause context overflow, while too few will fail to cover all test points |
| `searchMode` | hybrid | Combines keyword and semantic retrieval, adapting to the characteristics of party building text that has both standardized keywords and semantic associations |
| `usingReRank` | Enabled | Reorders recalled results by relevance to avoid interference from content that prioritizes keyword matching but has no semantic relevance for quiz generation |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands synonyms related to party building, such as associated expressions for "three meetings and one lesson", to improve recall coverage |
| `collectionIds` | Specify exclusive collection ID for party building knowledge base | Avoid mixing non-party building content from other knowledge bases, ensuring precise retrieval scope |

## Three Common Misconfigurations
- Symptom: Retrieval results show references to documents not included in the local knowledge base. Cause: The `collectionIds` parameter was not configured to limit the retrieval scope, resulting in mixing non-party building content from other knowledge bases.
- Symptom: The number of retrieved results does not meet expectations, being either too many or too few. Cause: The `limit` parameter was not adjusted based on the test point coverage requirements of quiz generation, and a reasonable threshold was not set in combination with the semantic characteristics of party building text.
- Symptom: The exported knowledge base content does not include the latest modified CSV file data. Cause: Incremental update synchronization was not performed, and only the initial CSV file was uploaded without subsequent updates.

## How to Verify Proper Configuration
- Access the retrieval configuration panel in FastGPT v4.17.0. Confirm that `collectionIds` specifies the exclusive party building knowledge base collection, and no other unrelated collections are selected.
- Input a party building quiz question stem and initiate a retrieval. Check that all recalled results are party building-related content, with no cross-domain text.
- Adjust the `similarity` parameter. Verify that the relevance of recalled results changes as expected with the parameter adjustment.
- Enable `usingReRank`. Compare the result order before and after reranking to confirm the reranking function is active.

The values provided are common starting points and should be measured against the reader's own samples.
