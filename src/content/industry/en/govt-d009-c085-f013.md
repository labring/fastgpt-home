# Party Building Learning Assistant for Quiz Generation: Sharing and Embedding

Reference only; verify against the target FastGPT release and deployment documentation.

## What the data for this category looks like
The quiz generation category for Party building learning assistants uses data from official Party building learning materials, themed education documents, and standardized Party building question banks. Updates align with Party building themed activity schedules, and are synchronized after new policies or themes launch. Each data entry is a single quiz question as the smallest unit, with structured fields: stem text, option set, correct answer, explanatory note, and associated knowledge point tags. No complex multimedia embedding is supported, and only the question stem can carry minor formatting markup.

## Constraints for Sharing and Embedding Workflows
The small per-question size means the embedding container does not need to be large, and fits the sidebar or embedded card layout of business systems. The structured fields allow flexible configuration of the display scope of shared content: only the question stem or the full question (including answer explanations) can be exposed, which must match the permission control requirements of the business scenario. The non-real-time update rhythm requires embedding links to support regular refreshing to avoid outdated content. At the same time, the attributes of Party building learning content require that sharing and embedding links comply with internal permission specifications to prevent unauthorized content from spreading.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Share visibility scope | Select internal visible or public based on business scenario | Most Party building quiz questions are internal learning materials, so this must match permission control requirements |
| Embedding container size | 300–500 pixels width, height calibrated via actual testing | The per-question quiz content has a small size, which fits the sidebar or embedded card layout of business systems |
| Markdown export button display | Disabled | Internal learning scenarios do not require external exports, to prevent unauthorized spread of quiz questions |
| `shareId` binding configuration | Bind to business system user permission identifiers | Ensure only authorized users can access corresponding quiz questions, complying with confidentiality specifications for Party building learning |
| Content refresh cycle | 1–7 days, calibrated via actual testing | Adapts to the non-real-time update rhythm of Party building content, balancing content timeliness and server resource usage |

## Three Common Misconfigurations
- Phenomenon: The Markdown export button appears in the non-login embedding window. Cause: The export button option was not disabled in the configuration, and the default external export function remains enabled.
- Phenomenon: Embedded quiz question content fails to update with the source question bank. Cause: The content refresh cycle was not configured, and the default long interval was used or the automatic refresh logic was not activated.
- Phenomenon: Input keywords are incorrectly converted when the share operation is triggered. Cause: Basic character verification was not performed on the input parameters of the embedding component, leading to character conversion errors caused by encoding or input abnormalities.

## How to Verify Configuration Completion
- Access the embedded page, check whether the export button is displayed or hidden as configured.
- Simulate users with different permission levels to access the embedded content, confirm that only authorized users can view question content within the corresponding scope.
- Modify question content in the source question bank, wait for the configured refresh cycle, then check whether the embedded page content is updated synchronously.
- Trigger the share operation, confirm that input parameters are passed correctly without abnormal character conversion.
