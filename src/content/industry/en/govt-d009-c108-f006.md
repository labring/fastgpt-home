# Theoretical Learning Q&A Party Building Learning Assistant: Citation Sources and Traceability

## What the data for this category looks like
Reference only; verify against the target FastGPT release and deployment documentation.

## What constraints do these characteristics impose on citation sources and traceability
The authoritativeness of official party building content requires that traceability precisely matches the original release channel, and non-authoritative sources cannot be arbitrarily linked. The fixed release time field requires that traceability information carries accurate release nodes, avoiding vague labeling. The multi-field document structure requires that traceability links specific chapters or entries of the corresponding content; only linking the entire document cannot meet precise traceability requirements. The large character span requires that traceability limits the length of linked content, avoiding overly long traceability information that interferes with user reading. The seriousness of party building learning requires that traceability information has no errors or omissions, as this would affect the accuracy of learning.

## How to set configurations
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Party building theoretical learning materials have relatively long lengths, so the total token amount of traceability citations must be limited to adapt to model context limits |
| `detail` | Enabled | Specific chapters or entries of the source must be displayed to meet the requirements of precise traceability in party building learning |
| `responseData` | Enable source field output | Source information must be embedded in the response data to facilitate subsequent export or secondary processing |
| Single recall upper limit | Top 3 entries | Excessive traceability information is avoided interfering with core learning content, while major reference sources are covered |
| Source matching threshold | Calibrated based on actual testing | Party building content has strong professionalism, so semantic similarity must be strictly matched to avoid linking irrelevant content |

## Three common configuration errors
- Phenomenon: Generated Q&A documents still contain unclosed citation markers, or redundant source links appear in the reply body. Cause: The `detail` parameter or response data format is not configured correctly, causing the system to forcibly retain traceability information.
- Phenomenon: The release time field in traceability information is empty, or the marked issuing unit does not match the actual source. Cause: The extraction configuration for the corresponding field is not enabled, or the matched document does not carry standard release information fields.
- Phenomenon: The number of recalled traceability entries exceeds the set upper limit, or non-official party building content is linked. Cause: A reasonable single recall upper limit is not set, or the source matching threshold is set too low, resulting in insufficient semantic matching accuracy.

## How to confirm the configuration is valid
- Initiate a test question related to party building theory, and check whether the configured traceability information is displayed in the reply, including source title, issuing unit and other content.
- Export the generated Q&A document, and verify that the source fields are complete, with no missing or incorrect information.
- Adjust the values of `quoteMaxToken` or the single recall upper limit, observe whether the length and number of traceability information change synchronously to verify that the parameters take effect.
- Check the FastGPT system log, confirm that all sources matched for traceability are official authoritative party building content, with no unauthorized sources linked.

The values provided here are common starting points and should be measured against the reader's own samples.
