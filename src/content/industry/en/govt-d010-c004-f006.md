# Party Building Learning Q&A for Proactive Public Disclosure and Policy Publication: Citation Source and Traceability

## What this category of data looks like
This category of data originates from government portals, document management systems, government information disclosure directories, policy document repositories, and press conference materials. The update frequency is daily. Daily documents include policy documents, policy interpretation drafts, public directories, information release approval forms, press releases, and website column update records. Fields include document title, document number, issuing unit, release time, public attribute, and content body. No additional custom unit fields are included.

## What constraints do these characteristics impose on the citation source and traceability link
The daily update frequency requires the traceability system to synchronize newly released policy documents and public directories in real time. This prevents retrieval results from citing expired or undisclosed content. Documents include information release approval forms and column update records. Traceability processes must associate corresponding approval workflows to ensure cited content complies with public attribute requirements. Format differences exist across multiple data sources. Unified field mapping rules must be implemented to avoid traceability matching failures caused by inconsistent identifiers such as titles and document numbers. Policy interpretation drafts must be bound to original policy documents. This prevents traceability errors where interpretation content does not match the original text.

## How to Configure Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Adapts to the typical length of a single policy document body, fully retaining the core information of cited content |
| `responseData` | Enabled | Required to return fields such as the title, document number, and release time of the citation source, to meet the compliance requirements of government affairs traceability |
| `detail` | Recall top 3 entries | Party building learning Q&A needs to focus on core policy basis, avoiding excessive results that disrupt the retrieval experience |
| Public attribute filtering | Enable only public content | Complies with the specifications of government proactive public disclosure, preventing citation of undisclosed or classified documents |
| Source field mapping | Uniformly map document number and issuing unit | Resolves format differences across multiple data sources, ensuring the accuracy of traceability matching |

## Three Common Configuration Mistakes
- Phenomenon: The response returned by the conversation request API does not contain the cite reference ID field. Cause: The `responseData` configuration item is not enabled, causing the system to not generate the citation identification field.
- Phenomenon: When querying a question that does not exist in the knowledge base, file citations from non-target knowledge bases are still returned. Cause: The public attribute filtering rule is not configured, causing the system to match undisclosed or non-target classified content.
- Phenomenon: Policy interpretation drafts and original policy documents are not bound in the retrieval results, making it impossible to confirm the corresponding relationship during traceability. Cause: The source field mapping rule is not configured, and the document numbers of the interpretation drafts and original documents are not associated and bound.

## How to Confirm the Configuration Is Complete
- Initiate a question targeting a known public policy document. Check the response for cited content that conforms to the `quoteMaxToken` length limit.
- Review the API response data. Confirm that fields such as the title and document number of the citation source and their corresponding identifiers are present.
- Initiate a question targeting non-public content. Confirm that no citation results are returned in the response.
- Initiate a question targeting a policy interpretation draft. Confirm that the response simultaneously includes citation information for the original policy document.

The values provided here are common starting points and should be measured against the reader's own samples.
