# Party Building Learning Q&A for Property Rights, Assets and State-owned Capital Management: Document Parsing and Chunking

## What the Data for This Category Looks Like
Core documents for this category include property rights registration forms, asset appraisal reports, property rights transfer plans, on-site transaction announcements, and asset disposal approval forms. Data sources cover state-owned assets supervision information systems, enterprise asset management systems, property rights exchange systems, appraisal agency reports, and financial statements.
Document structures combine structured tables and long-text chapters, with fixed fields such as asset ownership numbers, appraisal parameters, and transaction approval processes. Update frequency is monthly. The number of documents imported in a single batch and the length of individual documents vary widely.

## What Constraints These Characteristics Impose on Document Parsing and Chunking
Monthly updated batch data requires parsing processes to support efficient batch handling, and prevents single-task timeouts. Structured table documents such as property rights registration forms must retain the link between table headers and corresponding row data, to avoid chunking that breaks business logic. Long-text documents such as asset appraisal reports and property rights transfer plans must avoid truncating core conclusions and transaction clauses, while adapting to format differences from different source system exports. Additionally, some intranet-deployed data sources such as enterprise asset management systems must comply with intranet access rules, which differ from public network parsing logic.

## Configuration Settings
The following configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Adapts to the length of both structured table paragraphs and long-text chapters of documents in this category, avoiding truncation of individual business units |
| `chunkSplitter` | Split by title + paragraph | Documents in this category mostly have clear chapter titles such as appraisal notes and transaction clauses, retaining the contextual link between titles and corresponding content |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Parsing a thousand-page asset appraisal report takes a long time, avoiding parsing interruptions caused by timeouts |
| `customPdfParse` | Enabled | PDF documents in this category mostly contain embedded tables and encrypted forms, and custom parsing retains the integrity of structured content |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Supports batch import of multiple system export files updated monthly, covering the maximum file capacity requirements of a single batch task |
| `chunkSettingMode` | Manual configuration | Documents in this category have significantly different structures, requiring separate adjustment of chunking rules for table-type and long-text documents |

## Three Common Configuration Errors
- Intranet Confluence pages cannot be parsed. The cause is that access permissions for intranet data sources are not configured. The default parsing engine only supports pulling content from public network addresses.
- Incomplete command prompts are returned after Excel document parsing. The cause is that chunking rules are not adjusted for structured tables. The default chunking logic does not retain the link between table headers and corresponding row data.
- The chunk granularity of a single Excel document is too large, leading to insufficient subsequent retrieval and matching accuracy. The cause is that the `chunkSize` parameter is not adjusted. The default chunking covers too many asset data rows, which damages the business integrity of individual records.

## How to Verify Successful Configuration
- Upload a single typical document, such as a single asset appraisal report, and review the parsed chunk list to confirm that core business units are not truncated.
- Batch import system export files updated monthly, check the completion rate and timeout rate of parsing tasks, and adjust `PARSE_FILE_TIMEOUT_SECONDS` to a value suitable for the actual scenario.
- For Excel-format property rights registration forms, verify that chunked data retains the link between table headers and corresponding asset records.
- Test parsing requests for intranet data sources, and confirm that configured access rules can normally pull page content.

The values listed here are common starting points, and should be evaluated against the reader's own samples.
