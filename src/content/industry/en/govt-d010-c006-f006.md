# Party Building Learning Q&A for Infectious Disease Information Reporting and Monitoring: Citation Sources and Traceability

## What Data for This Category Looks Like
Core data for this category comes from the Chinese Center for Disease Control and Prevention Information System, hospital HIS systems, infectious disease reporting systems, and laboratory testing systems. Daily documents include infectious disease report cards, epidemic analysis reports, case correction records, clustered epidemic reports, epidemiological investigation reports, and similar materials. Data is updated on a daily basis. Document structures include fields such as case unique identifier, reporting time limit, diagnosis result, correction information, and early warning signals. Fields must comply with regulatory requirements for statutory infectious disease reporting.

## Constraints Imposed on Citation Sources and Traceability by These Characteristics
Daily updated data requires the traceability process to match the latest correction records and reporting information in real time, to avoid citing outdated data. Multi-source documents require association with identification fields from different systems, to ensure that reporting channels can be distinguished during traceability. Diverse document types require matching a unified citation format, to ensure consistent source display across different reports. Regulatory requirements for statutory reporting mean that traceability must accurately associate case diagnoses and test results. Failure to do so may lead to delays in epidemic early warnings or risks of regulatory notifications.

## Configuration Settings
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the core content length of a single infectious disease report card or epidemic analysis report, ensuring complete citation without exceeding context limits |
| `responseData` | Enabled | Required to return source identifiers of original documents, including reporting system, case unique number, and update time, for precise traceability |
| `detail` | Enabled | Displays core fields of cited content, such as case diagnosis results, correction records, and reporting time limits, to facilitate compliance verification |
| Single recall limit | Top 6 entries | Covers the volume of core monitoring reports added daily, avoiding missing key epidemic signals |
| Context window | Calibrated via actual testing | Adapts to the splicing needs of multi-system associated data, ensuring complete associated display of reports from different sources |

## Three Common Configuration Mistakes
- Phenomenon: Returned citation content does not include a case unique number or reporting system identifier, making specific report records untraceable. Cause: The `responseData` configuration is not enabled, and source system and report identifier fields are not extracted.
- Phenomenon: Irrelevant epidemic analysis reports are returned even when the query does not involve infectious disease monitoring content. Cause: No matching filter based on case diagnosis fields is set, resulting in recall of unrelated documents.
- Phenomenon: Cited content omits case correction records or reporting time limit fields, making report accuracy unverifiable. Cause: The `detail` configuration is not enabled, and complete original document fields are not returned.

## How to Confirm Configuration Is Complete
- Submit a query that includes a specific infectious disease case number, and check if the returned results include the reporting system, number, and update time of the corresponding report.
- Submit a query that does not involve infectious disease monitoring content, and check if irrelevant report data is not returned.
- View the detail area of cited content, and confirm that core fields such as case diagnosis and correction records are included.
- Check the token count of cited content, and confirm it falls within the set range.

The values provided are common starting points and should be evaluated against the reader's own samples.
