# Party Building Learning Q&A for Internal Control Evaluation, Audit and Rectification: Forms and Interactions

## What this category’s data looks like
This category of data mainly comes from enterprise internal control systems, ERP, financial sharing systems, audit management systems, and procurement contract project systems. The update frequency is annual. Daily processed documents include internal control self-evaluation reports, audit notices, audit working papers, issue lists, rectification ledgers, and rectification closure certificates. Data fields cover audit issue descriptions, rectification measures, completion deadlines, supporting material association items, etc. There is no unified fixed unit, and it varies with document types. This page is written based on FastGPT v4.17.0.

## What constraints these characteristics impose on the "forms and interactions" workflow
Low-frequency data updated annually requires forms to support batch import of historical documents to avoid duplicate data entry. Multi-source data needs a data source filtering entry in the interactive interface to distinguish between internal control self-evaluation and audit rectification data. The multi-field association feature of rectification ledgers requires forms to support field linkage: selecting an issue list entry automatically loads the corresponding rectification measures. Differences in fields across different documents require the interactive interface to support switching configurations to adapt to different entry logic for audit notices and rectification closure certificates. The volume of data submitted in a single operation must be limited to a reasonable range to avoid system overload.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Enable multi-file batch upload, limit single file size to no more than 1000 MB | Adapt to the batch import needs of large-volume documents such as rectification ledgers and audit working papers |
| `userSelect` | Preset three option groups: audit issues, rectification measures, and supporting materials | Match the standard field classification of daily documents and reduce custom entry costs |
| Context Length | 800–1200 characters | Cover the core text length of audit working papers and rectification ledgers to avoid information truncation |
| Single Submission Limit | Top 10 entries | Match the low-frequency data scale of annual updates to avoid overload from single submissions |
| Timeout Threshold | 600 seconds | Adapt to the time required for cross-system data pulling and document parsing |
| Field Linkage Rule | Bind issue list and rectification ledger entries | Implement automatic loading of corresponding rectification requirements after selecting an issue, which aligns with business process logic |

## Three common misconfigurations
- After configuring a third-party model endpoint, the model list displayed in the interface does not match the model corresponding to the filled baseURL. The symptom is that the dropdown options do not show the custom model or show the default model. The cause is that the endpoint model automatic synchronization configuration is not enabled, or the model name parameter is not filled correctly.
- The guide prompt for party building learning Q&A does not take effect in form interactions. The symptom is that the AI response does not fit the standardized context of party building learning. The cause is that the guide prompt is not bound to the `formInput` configuration item, or the configuration path is incorrect.
- Format verification failure occurs when uploading documents such as audit working papers. The symptom is that the system prompts that the file format is not supported. The cause is that common document formats such as PDF and Word are not added to the allowed upload range, and the corresponding text parsing rules are not configured.

## How to confirm the configuration is complete
- Upload a test rectification ledger document, check whether the form automatically recognizes the document type and loads the corresponding field template.
- After configuring the third-party model endpoint, initiate a test conversation, check whether the AI response follows the preset party building learning Q&A guide prompt logic.
- Select a preset audit issue option, check whether the form automatically associates the corresponding rectification measure field to achieve the linkage effect.
- Submit batch-uploaded test documents, check whether the system completes parsing and generates corresponding interaction entries within 600 seconds, with no timeout errors.
