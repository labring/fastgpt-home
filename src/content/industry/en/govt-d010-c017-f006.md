# Party Building Learning Q&A for Medical Institution Supervision and Public Health Inspection: Citation Sources and Traceability

## What data does this category cover?
The data involved in this category includes supervision inspection forms, medical institution practice licenses, rectification notices, supervision opinions, penalty case files, and other related materials. Data mainly comes from health supervision information systems, medical institution electronic registration systems, complaint and reporting platforms, and law enforcement inspection records. The update frequency is once per month. Most documents combine structured fields and unstructured text, including core fields such as institution name, license scope, inspection time, rectification requirements, and more. There is no unified fixed format. Some documents require association with multiple types of system data to form a complete evidence chain.

## What constraints do these characteristics impose on the citation and traceability process?
The data characteristics of this category impose multiple constraints on the citation and traceability process. Data sources are scattered across multiple official systems. Each cited content must clearly mark its original system source to ensure traceability. Document structures are inconsistent and include both structured fields and unstructured text. Accurate fragment extraction for multi-format content must be supported, to avoid missing core associated information in cited content. The update frequency is once per month. A regular incremental synchronization mechanism must be configured to prevent citing expired license or rectification data. Core business fields are closely linked. When citing, associated identifiers such as institution name and inspection time must be retained, to ensure that traced content corresponds one-to-one with actual law enforcement and licensing actions.

## Configuration Settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | The core document fragment of this category is mostly 500–1000 token. Setting this range covers complete cited content without exceeding the context limit |
| `responseData` | Enabled | Original fields of cited documents such as institution name and inspection date must be displayed to support traceability verification |
| `detail` | Enabled | Contextual associated information of cited fragments must be displayed to facilitate verification of rectification requirements and penalty basis |
| Single search limit | Top 8 entries | The number of core documents in this category is moderate. Too many citations will cause token overflow, too few will fail to cover comprehensive compliance basis |
| Search similarity threshold | 0.75–0.85, calibrated via actual testing | Lowly relevant non-compliant documents must be filtered out, retaining content strongly related to supervision and licensing |

## Three Common Misconfigurations
- Symptom: Generated responses exceed token limits, and the interface displays a context overflow error. Cause: `quoteMaxToken` is set to 2000 token, which does not match the actual length of the core documents in this category, causing cumulative cited fragments to exceed the limit.
- Symptom: The cited documents in the response are not the top-ranked highly relevant results from the knowledge base search. Cause: A reasonable similarity threshold is not configured, causing weakly relevant but format-matched content to be returned first.
- Symptom: The original system source or core fields of the cited documents are not displayed in the response. Cause: The `responseData` configuration is not enabled, so original data sources and associated identifiers are not included.

## How to Verify Correct Configuration
- Initiate a party building learning Q&A regarding medical institution qualifications or rectification requirements. Check whether the returned results include core fields of cited documents such as institution name and inspection time.
- View the citation list at the bottom of the response to confirm that the number of citations matches the single search limit setting.
- Check the token length of cited fragments to confirm they do not exceed the `quoteMaxToken` configuration value.
- Simulate adjusting the similarity threshold to a lower value to verify that lowly relevant non-compliant documents are filtered out.

The values provided are common starting points and should be measured against the reader's own samples.
