# Party Building Learning Q&A for Territorial Spatial Planning Compilation and Implementation Evaluation: Forms and Interactions

This configuration is developed based on FastGPT v4.17.0.

## What data for this category looks like
Data for this category mainly comes from the territorial spatial basic information platform, natural resource survey and monitoring data, population and economic statistics, and remote sensing images. The update frequency is annual.
Daily documents include territorial spatial overall plans, detailed plans, special plans, planning implementation evaluation reports, and public opinion summaries.
Most documents include fields such as spatial coordinates, constraint indicators, and regional scale. Units include hectares, square kilometers, ten thousands of people, and others.
The length of individual documents varies widely. Some reports include associations between multi-dimensional spatial data and business content.

## What constraints these characteristics impose on the forms and interactions link
Since data is updated annually, forms must support annual filtering of associated data input items to meet the time dimension requirements of planning cycles.
Documents contain multiple types of fields and spatial attachments. The interaction link must support grouping display of different categories of input items to avoid interface information overload.
Public opinion summary documents require forms to support integration of content from multiple sources. Interactive entrances for batch import and classification organization must be set.
Input for spatial data-related fields must match specific format verification to prevent non-standard content from entering subsequent processes.

## How to set the configuration

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `formInput` | Supports multi-line text, attachment upload, and format verification | Matches the requirements for multiple types of fields and spatial attachments in documents of this category |
| `userSelect` | Presets 10 department classification options and an annual range selector | Adapts to planning scenarios involving multiple departments and annual updated data requirements |
| Section setting | Segments by row | Adapts to processing of public opinion summary files in multi-column Excel format |
| Timeout setting | 600 seconds | Adapts to time requirements for multi-source data loading and form submission |
| Form verification rules | Spatial coordinate format verification, required item linkage | Prevents non-standard spatial data and missing key information |

## Three common errors
- Symptom: A model error occurs when configuring the form to connect to a knowledge base. Cause: The specified embedding model is not selected, and an incompatible model type is used.
- Symptom: When importing a multi-column Excel public opinion summary file, automatic segment results are messy. Cause: The row-based segmentation unit is not manually set, and only the default automatic segmentation logic is used.
- Symptom: When using the form function released via API call, no user input guidance prompts are displayed. Cause: The trigger prompt logic for `formInput` is not configured in the workflow, and form content is only built in the editing interface.

## How to confirm the configuration is complete
- Manually trigger form submission, check if prompt messages for corresponding format verification pop up.
- Test the form function via API call, confirm that returned results contain all field content entered by the user.
- Upload a standard territorial spatial planning attachment, confirm that the system can correctly identify and associate corresponding fields.
- Switch the annual range selector, confirm that the associated document list synchronously updates data matching the selected year.

The values provided here are common starting points, and should be evaluated against the user's own samples.
