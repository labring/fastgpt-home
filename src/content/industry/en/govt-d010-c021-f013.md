# Centralized Treasury Payment and Reimbursement Audit Party Building Study Q&A: Sharing and Embedding

## What this category of data includes
Data for this category comes from the centralized treasury payment system, unified budget management system, electronic invoice platform, and contract management system. The update frequency is daily.
Commonly processed documents include payment applications, fund use plans, invoices, contracts, acceptance records, reimbursement approval forms, and payment vouchers.
Core fields cover budget indicators, economic classification, ticket numbers, contract clauses, acceptance records, and fund amounts.
All data is generated around the compliance audit process for single fund payments, and is part of daily execution data for fiscal management.

## Constraints on the sharing and embedding workflow from these characteristics
The daily update feature of this category of data requires that the shared and embedded knowledge base be configured with a regular update mechanism. This ensures that Q&A content matches the latest payment and reimbursement document information.
The structure where a single audit is associated with multiple types of documents requires embedded sessions to retain context association. This avoids broken Q&A that reduces audit efficiency.
Data involves fiscal compliance-related content. This requires that shared links strictly limit access permissions, and support custom language adaptation for different user groups.
In addition, the traceability requirement for sensitive business data requires that shared links support log recording and viewing functions to meet audit requirements.

## How to configure these settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Shared link language setting | Configure separately per session scenario, do not follow the console main interface | Adapt to language needs of internal and external user groups, resolve language mismatch issues |
| Shared prompt display | Can be toggled on or off individually | Meet interface simplicity needs for different usage scenarios, support hiding irrelevant prompt content |
| `shareId` binding rule | Limited to the knowledge base ID of the current category | Ensure shared sessions only call business data related to centralized treasury payment and reimbursement audit, prevent mixing content from other categories |
| Embedded session context length | 800–1200 characters | Match the information length of documents related to single payment audit, ensure complete context association for Q&A |
| Shared link access log permission | Bound to console administrator role | Ensure audit traceability for sensitive operations, comply with fiscal management compliance requirements |
| Session timeout setting | 600 seconds | Adapt to conventional operation duration for fiscal audits, prevent session failure mid-use |

## Three common configuration errors
- Shared link display language does not match the console main interface setting, failing to adapt to specified user groups. The cause is failure to separately configure the shared link language option, and the default follows the console's global language setting.
- Unable to view others' Q&A records corresponding to shared links, with the log entry showing no permission or empty. The cause is failure to grant the corresponding role permission to view shared logs, or failure to enable the log recording function for shared links.
- Embedded sessions return business data not from the current category, such as budget preparation related content. The cause is failure to limit the data source scope via `shareId` binding, resulting in mixing knowledge base content from other fiscal categories.

## How to confirm the configuration is correct
- Open the shared link, switch the language setting option, confirm the displayed interface language matches the configured target language.
- Use a non-administrator account to access the shared link, confirm the prompt text displays or hides as configured, matching expected results.
- Log in to the console's log management page, view the session records corresponding to the shared link, confirm that corresponding Q&A content can be retrieved.
- Ask non-current category business questions in the embedded session, confirm the returned result is empty or prompts that the question cannot be answered, ensuring the data source restriction takes effect.
- Confirm that the current FastGPT version is v4.17.0, ensuring compatibility with configuration functions.
