# Party Building Learning Q&A for Student Financial Aid and Subsidy Review: Source Citation and Traceability

## What the data for this category looks like
This category of data covers core documents including family economic hardship certification forms, financial aid application forms, scholarship and grant review forms, distribution lists, public notice materials, and more. Data sources include the national student financial aid management information system, school student status system, civil affairs low-income and special hardship data, and fiscal payment systems. Data is updated per semester. Each single document contains fields such as applicant identity, family economic status, student status, financial aid application level, distribution amount, and bank card information. No fictional statistical content is included.

## What constraints these characteristics impose on the "source citation and traceability" link
This category of data sources involves multiple cross-departmental systems. Citation and traceability must link corresponding entries from multiple sources including student status, civil affairs, and fiscal data to avoid bias from single data sources. Data is updated per semester, so all application and distribution documents for the current semester must be covered within the knowledge base sync cycle to ensure the content cited in Q&A is up to date. Each single document contains multiple associated fields, so citation and traceability must precisely match original records for corresponding fields to avoid information confusion across documents. Incorrect aid distribution leads to complaints and audit issues. The traceability link must fully retain the original data citation path to ensure every Q&A content can be traced back to official documents.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | This category's single core document is medium-length. Sufficient original cited content must be retained to avoid truncating key fields |
| `responseData` | Includes original document ID, field name, update time | Full metadata of citation sources must be recorded to meet audit and traceability requirements |
| `detail` | Enabled | Party building learning Q&A combines financial aid policies and actual application materials. Detailed citations improve response authority |
| Single recall limit | Top 5 entries | The number of application documents per semester for this category is moderate. Too many recalls increase context redundancy |
| Knowledge base sync cycle | 1 time per semester | This category's data is updated per semester. No frequent sync is needed to save system resources |

## Three Common Misconfigurations
- Phenomenon: An error occurs when viewing knowledge base citations in chat responses. Cause: Latest financial aid application and distribution documents are not synced per semester, causing the cited data source to be expired or not entered into the system.
- Phenomenon: No citation source content is displayed in Q&A responses. Cause: The `responseData` parameter is not configured correctly, or the option to hide citations is set, which does not meet traceability requirements.
- Phenomenon: Redundant knowledge base search input and output content are displayed in Q&A. Cause: Extra search step outputs in the workflow are not disabled, causing unnecessary citation information to be shown.

## How to Confirm Proper Configuration

- View the knowledge base sync log to confirm all core documents for the current semester have been updated with no missing entries.
