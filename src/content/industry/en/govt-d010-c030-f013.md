# Party Building Learning Q&A for Construction Engineering Quality and Safety Supervision: Sharing and Embedding

## What the data for this category looks like
Data for this category comes from project quality and safety supervision systems, construction site real-name platforms, supervision logs, and test reports. The update frequency is weekly.
Daily documents include supervision plans, supervision inspection records, hidden danger rectification notices, quality problem handling forms, and completion acceptance supervision reports. Each document has exclusive business-specific fields. There are no universal standard units. Field content is generated around the full process of construction site quality and safety supervision.

## Constraints imposed by these characteristics on the "Sharing and Embedding" link
Data has a weekly update frequency. The Q&A knowledge base after sharing and embedding must sync at this frequency to prevent outdated data from affecting supervision result judgments.
Document types cover the entire supervision process and contain sensitive business content. When sharing and embedding, limit the document scope to only push supervision-related documents required by the corresponding subject.
Data sources involve multiple business systems. Embedding configuration must support retrieval logic associated with multiple data sources to ensure Q&A content covers complete supervision links.
Party building learning Q&A must combine supervision business scenarios. When sharing and embedding, retain business context association to avoid invalid Q&A disconnected from the scenario.

## How to set the configuration
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `shareId` | Unique identifier string corresponding to the target application | Used to accurately associate the shared and embedded party building learning Q&A application, matching the exclusive knowledge base for construction engineering quality and safety supervision |
| Embedded iframe height | 600–800 pixels | Adapts to common office screen sizes used by supervision personnel, avoiding content overflow or excessive blank space on the page |
| Knowledge base sync cycle | 7 days | Matches the weekly update frequency of data in this category, ensuring Q&A content syncs with the latest supervision documents |
| Markdown export feature | Hidden | Prevents arbitrary export of sensitive supervision documents, complying with business data security requirements |
| Conversation persistence isolation | Store and isolate by user identity | Ensures different supervision subjects can only view their own conversation records, complying with data permission control requirements |
| Login-free window configuration | Disable Markdown export button | Adapts to permission control in login-free scenarios, matching operational simplification needs for the business scenario |

## Three Common Configuration Errors
- Phenomenon: The Markdown export button is displayed in the login-free window. Cause: The export function was not disabled in the login-free configuration, allowing unauthorized users to trigger export operations for sensitive supervision documents.
- Phenomenon: Different supervision subjects share the same conversation record. Cause: Persistence storage configuration isolated by user identity was not enabled, resulting in no permission control for conversation data.
- Phenomenon: The embedded Q&A application returns outdated supervision data. Cause: No knowledge base sync cycle matching the business was set, resulting in Q&A content not being synced with weekly updated documents.

## How to Confirm the Configuration is Successful
- Open the embedded iframe page, check if the Markdown export button is hidden, to confirm the configuration has taken effect.
- Use test accounts with different identities to initiate conversations, verify that each account can only view its own conversation records, to confirm the persistence isolation configuration has taken effect.
- Update a latest supervision inspection record, initiate relevant Q&A, verify that the returned content includes the latest document information, to confirm the sync cycle configuration has taken effect.
- Copy the application link corresponding to `shareId`, verify that the embedded page correctly associates the target party building learning Q&A application, to confirm the application match is correct.
