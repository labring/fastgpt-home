# Party Building Learning Q&A for Construction Project Environmental Impact Assessment Approval: Citation Sources and Traceability

## What This Category’s Data Looks Like
Data sources for this category include the national unified construction project environmental impact assessment (EIA) declaration and approval system, ecological environment zoning control results, pollution discharge permit platform, and monitoring data. Update frequency is irregular.
Daily documents include environmental impact assessment report books, environmental impact assessment report forms, approval applications, public participation explanations, technical assessment opinions, and EIA approval documents. Document structure follows the approval process, with chapters for project acceptance, technical assessment, and approval issuance. Fields include project name, approval document number, pollution prevention measures, and public participation opinions. There is no unified fixed unit format; formats are adjusted flexibly based on document type.

## What Constraints Do These Characteristics Impose on the "Citation Sources and Traceability" Link?
Scattered data sources and irregular update cycles require traceability functions to associate document identifiers across multiple systems. This ensures citations point to the latest version of approval documents.
Lengthy, complex document structures require citation functions to extract long text fragments. This prevents critical approval key points from being truncated.
Errors directly impact project construction approval and compliance confirmation. Citations must accurately match original documents. Arbitrary association of irrelevant content is not permitted.
This category differs from other approval scenarios. It focuses on pre-commissioning construction project compliance assessment. Citation scope must be strictly limited to EIA-related documents. Content from other fields such as pollution discharge permits must not be confused.

## Configuration Settings
All configurations below are based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Adapts to long text paragraphs of EIA reports, ensures cited content fully covers core points of project approval |
| `responseData` | Enabled | Returns the original ID and source path of cited documents, meets traceability verification needs for EIA approval |
| `detail` | Enabled | Generates specific location identifiers for cited fragments, facilitates verification of compliance details in EIA approvals |
| Maximum Number of Citations | Top 6 entries | Controls the number of citations per dialogue, avoids information overload that affects approval decision-making |
| Timeout Threshold | 600 seconds | Adapts to retrieval and citation generation processes for long documents, prevents request failures due to overly long content |

## Three Common Misconfigurations
- Citation markers in dialogue outputs become garbled. They first show as invalid symbols, then switch to standard quotation marks. The cause is incorrect configuration of the escape rules for `responseData`, leading to abnormal parsing of citation identifier formats.
- When a question falls outside the knowledge base coverage, the system still returns citations for construction project EIA-related documents. The cause is that the forced citation logic for unknown questions is not disabled. The system automatically associates irrelevant approval documents.
- Calling the dialogue interface fails to retrieve the unique identifier ID for citations. The cause is that the `detail` configuration item is not enabled, so the interface does not generate citation identifier fields.

## How to Verify Successful Configuration
- Submit a query that includes a specific EIA project name. Check if the output ends with clear source annotations, including document type and source system name.
- Trigger a test query for an unknown question. Confirm the system does not return any citations for EIA-related documents.
- Review the response fields returned by the interface. Confirm that citation identifier fields related to `responseData` and `detail` are present.
- Adjust the value of `quoteMaxToken`. Test if long paragraph citations display fully, with no truncation.

The values provided are common starting points and should be measured against the reader's own samples.
