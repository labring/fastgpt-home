# Party Building Learning Q&A for Construction Project Environmental Impact Assessment (EIA) Approval: Knowledge Base Retrieval and Recall

## What this category's data looks like
Core data for this category comes from the national unified construction project EIA declaration and approval system, ecological environment zoning control results, pollutant discharge permit platform, and monitoring data. The update frequency is irregular. Daily documents include environmental impact assessment reports or report forms, approval applications, public participation explanations, technical assessment opinions, and EIA approval documents. These documents cover project category, EIA level, pollution prevention measures, and public participation feedback. They include both long professional report texts and short approval conclusion texts. Most fields use professional terminology from the ecological environment sector, and there is no unified lightweight format.

## What constraints these characteristics impose on the knowledge base retrieval and recall link
Access to multi-source data limits the retrieval scope to a dedicated EIA document dataset, preventing recall of approval or monitoring data outside this category. The coexistence of long-text reports and short-text approval documents requires retrieval modes to balance semantic matching and precise keyword matching, avoiding missing key approval clauses. Irregular update frequency requires support for on-demand index updates, ensuring retrieval results sync with the latest approval data. Content dense with professional terminology requires a high similarity threshold to filter semantically similar but non-matching project documents, ensuring targeted retrieval results.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | EIA documents are dense with professional terminology. A higher similarity threshold filters documents from unrelated projects, preventing non-target project approval content from appearing in party building learning Q&A |
| `limit` | Top 5 entries | EIA approval requires checking multiple related documents. Too many results exceed the context capacity limit. Too few may miss key content such as technical assessment opinions |
| `searchMode` | hybrid | Balances keyword matching and semantic recall, adapting to both long professional texts in environmental impact assessment reports and short conclusion texts in EIA approvals |
| `usingReRank` | Enabled | The re-ranking function further filters results that are semantically similar but do not match the project category, improving the accuracy of retrieval results for party building learning Q&A |
| `datasetSearchUsingExtensionQuery` | Enabled | Extended queries cover EIA regulatory requirements related to party building, adapting to the scenario needs of party building learning Q&A and supplementing policy interpretation content |
| `collectionIds` | Fill in the dedicated EIA dataset ID | Limits the retrieval scope to only documents related to construction project EIA, preventing mixing of approval or monitoring data from other categories |

## Three common configuration errors
- Symptom: No knowledge base reference option appears in the variable selection panel in the code running node. Cause: The construction project EIA document dataset is not bound to the current application, so the system does not generate the corresponding knowledge base call variable.
- Symptom: Retrieval results include non-EIA documents or approval content from unrelated projects. Cause: The `collectionIds` parameter is not configured to specify the dedicated dataset, resulting in recall of documents from other categories or non-matching project data.
- Symptom: The first search result cannot be output. Cause: The `limit` parameter is not correctly set to `Top 1 entry`, or the result sorting function is not enabled, causing the returned result order to be inconsistent with expectations.

## How to confirm the configuration is complete
- In the application backend of FastGPT v4.17.0, navigate to the knowledge base configuration page, confirm that the dedicated construction project EIA dataset is bound, and the `collectionIds` parameter is correctly filled with the corresponding collection ID.

- Adjust the value of the `similarity` parameter, observe the change in the number of retrieval results, and confirm that the threshold setting takes effect.
- After enabling the `usingReRank` function, compare the result order before and after re-ranking, and confirm that the re-ranking function is operating normally.
