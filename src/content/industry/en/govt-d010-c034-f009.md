# Party Building Learning Q&A for Enrollment and Student Status Management: Model Access and Configuration

## What the data for this category looks like
This category involves entities including education bureau basic education departments, school academic affairs offices, enrollment examination institutions, and street community collaborative windows. Daily processed documents include enrollment application forms, student status information forms, transfer applications, enrollment plans, admission rosters, and student status change approval forms.
Data sources include the National Primary and Secondary School Student Status Management System, local enrollment platforms, household registration and property data, and school academic affairs systems. The update frequency is daily.
Data fields include student ID number, enrollment year, household registration address, student status change type, and more. It covers the full process of student identity verification and student status transfer.

## What constraints these characteristics impose on model access and configuration
The data characteristics of this category impose multiple constraints on model access and configuration.
The scenario of mixed multi-source data access requires configuration to support cross-system context integration, to avoid duplicate or missing student status records.
The daily update frequency requires knowledge base synchronization configuration to match the daily update rhythm, ensuring Q&A data aligns in real time with official systems.
Documents include structured forms and unstructured policy texts. Configuration must balance structured field recognition and the rigor of natural language Q&A.
Additionally, since errors affect student admission eligibility, model responses must have clear, traceable citation sources to avoid admission disputes.

## How to set the configuration
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | Covers the context of multiple core documents including enrollment application forms, student status change approval forms, and enrollment plans, ensuring complete business context can be referenced during Q&A |
| `maxTokens` | 4096 | Meets the length requirements for common responses such as enrollment policy explanations and student status change process descriptions, preventing key information from being truncated |
| `temperature` | 0.2–0.4 | Both party building learning Q&A and student status management require precise expression. This value range reduces response randomness and ensures content complies with official standards |
| `quoteMaxToken` | 2000 characters | Retains sufficiently long document fragments as citation basis, covering key verification fields such as student ID number and household registration address |
| `AIPROXY_API_ENDPOINT` | Fill in the actual address of the locally deployed model, such as `http://localhost:11434/v1` | Adapts to access requirements for locally deployed large models, and complies with the proxy configuration format of FastGPT v4.17.0 |
| `AIPROXY_API_TOKEN` | Fill in the actual key of the deployed model | Completes identity verification for model access, preventing connection errors |

## Three common mistakes
- Symptom: Connection error occurs during model testing, with status code 500 or "connection timed out" prompt displayed on the interface. Cause: The local address filled in for `AIPROXY_API_ENDPOINT` does not have the corresponding port open, or the permissions for `AIPROXY_API_TOKEN` are not configured correctly.
- Symptom: Duplicate or missing entries appear in the student status information returned by Q&A. Cause: The knowledge base is not updated daily, resulting in Q&A data being out of sync with real-time data from the National Primary and Secondary School Student Status Management System.
- Symptom: No cited document details are returned after calling the knowledge base Q&A API released by the platform. Cause: The citation retention configuration is not enabled, or `quoteMaxToken` is set too low, causing document fragments to be truncated prematurely.

## How to confirm the configuration is complete
- In the model testing interface of FastGPT v4.17.0, fill in `AIPROXY_API_ENDPOINT` and `AIPROXY_API_TOKEN`, then initiate a test to confirm no connection error prompts are returned.
