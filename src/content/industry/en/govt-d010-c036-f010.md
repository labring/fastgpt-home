# Party Building Learning Q&A for Government Service Item Catalog and Service Guide Maintenance: Knowledge Base Retrieval and Recall

## What this category's data looks like
The core data of this category includes basic government service item catalogs, implementation lists, service guides, standard material catalogs, flowcharts, and frequently asked questions. Data is primarily sourced from the national basic government service item catalog, administrative licensing item list, power and responsibility list, and local government service item databases. The typical update cycle is once per month. Most documents combine structured fields and unstructured text, including fixed fields such as item name, acceptance conditions, application material list, and service process. Some documents also include unified unit specifications and regional adaptation notes.

## Constraints Imposed on Knowledge Base Retrieval and Recall
Multiple data source tiers and the need for regional adaptation require retrieval and recall to support cross-tier data association matching. The monthly update feature requires the retrieval pipeline to quickly sync the latest catalog data to avoid using expired content. The mixed structure of structured fields and unstructured text requires the retrieval model to support both exact field matching and semantic understanding. Regional adaptation notes require recall results to be associated with corresponding regional service rules to prevent cross-region call errors. Additionally, the requirement for field integrity verification of service guides requires retrieval results to cover all required fields to avoid returning incomplete service guidance content.

## Configuration Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | 0.72–0.78 | Adapts to the mixed retrieval needs of structured fields and unstructured text, balancing precision and recall range |
| `limit` | Top 8 entries | Covers the context requirements of multiple fields in service guides, avoiding insufficient information in single results |
| `searchMode` | hybrid | Combines semantic retrieval and exact matching, adapting to retrieval of structured fields such as item name and acceptance conditions |
| `usingReRank` | Enabled | Re-ranks recall results by relevance, improving the display priority of key content in service guides |
| `datasetSearchUsingExtensionQuery` | Disabled | Prevents non-associated government items from being recalled due to extended queries, ensuring retrieval results accurately match catalog content |
| `collectionIds` | Specified according to the bound government service item knowledge base | Restricts retrieval scope to only the government service item catalog data currently being maintained |

## Three Common Misconfigurations
- Symptom: Semantic retrieval fails to recall the target service guide, but full-text retrieval matches normally. Cause: `searchMode` is not configured as hybrid mode; pure semantic retrieval alone cannot match structured fields such as item name and acceptance conditions.
- Symptom: Local service guide files uploaded to the knowledge base continuously show loading status in offline mode, and recover normally only when connected to the internet. Cause: Local caching policy is not configured; FastGPT requires internet access to pull dependent resources to complete file parsing and index construction.
- Symptom: Retrieval results include government items from non-current maintenance regions. Cause: `collectionIds` is not correctly specified, and the retrieval scope covers knowledge base data from other regions.

## How to Verify Proper Configuration
- Manually upload a single latest service guide file. After confirming index construction is complete, enter the core item name in the file, and check if the target file is included in the retrieval results.
- Adjust the `similarity` configuration range, verify that the relevance changes of retrieval results meet expectations, and ensure a balance between precision and recall range.
- Check the knowledge base update synchronization status, confirm that the monthly updated government catalog data has completed index refresh, and no expired content remains.
- Disable the `datasetSearchUsingExtensionQuery` configuration, verify that retrieval results only include government service item data of the current category, with no additional extended content.

The values listed here are common starting points and should be evaluated against the reader's own samples.
