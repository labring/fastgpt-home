# Government Information Application-Based Disclosure Party Building Learning Q&A: Citation Sources and Traceability

## What this category of data looks like
Data sources for this category include government information disclosure platforms, agency archive systems, document management systems, departmental business ledgers, and government disclosure-related regulations. Daily processed documents include government information disclosure application forms, supplementary notice letters, third-party opinion solicitation letters, reply letters, delivery receipts, and administrative reconsideration response materials. Data updates occur irregularly, synchronized with the progress of specific application handling. Document fields include applicant information, application content, reply document numbers, public attribute judgment basis, and more. The length of individual documents varies significantly.

## What constraints do these characteristics impose on the "citation sources and traceability" link?
Data sources are scattered, requiring integration with multiple systems to obtain complete documents. Metadata formats of documents from different sources must be unified to accurately associate citations. Diverse document types and lack of fixed length require the citation traceability link to adapt to different document structures and avoid missing key reply or application information. Irregular data updates require configuring a scheduled synchronization mechanism to ensure that cited documents are the latest handling versions. The business logic centered on individual case requests requires traceability to accurately match the corresponding documents of specific application matters.

## How to set the configurations
| Configuration Item | Recommended Value | Rationale for This Value |
| --- | --- | --- |
| Maximum citation token count | 1000–1500 tokens | Matches the typical length of individual application-based disclosure documents, avoiding truncation of key public attribute judgment content |
| Enable return of associated data | Yes | Binds metadata fields of government disclosure documents to ensure that specific reply document numbers or application document numbers can be associated during traceability |
| Enable detail recall | Yes | Recalls complete original text fragments of single documents to verify the matching between reply content and application matters |
| Number of single recall entries | Top 6 entries | Adapts to the number of documents associated with a single application in application-based disclosure business, avoiding recalling excessive irrelevant content |
| Data source synchronization frequency | According to business cycle | Matches the irregular update rhythm of data to ensure that cited documents are the latest versions |

## Three common misconfigurations
- Increasing the maximum citation token count to 2000 or 3000 results in no knowledge base citations displayed in the large model's response. System logs show that recalled document fragments were not included in the context. The cause is that the set parameter exceeds the maximum context window of the current model, causing the citation fragments to be filtered out.
- For a privately deployed FastGPT v4.17.0 knowledge base, responses generated under the release channel do not associate citation sources, while local testing works normally. The cause is that the data source permissions of the knowledge base were not correctly configured for the release channel, preventing external calls from reading document metadata.
- System logs show that the actual called model does not match the model configured in the application. The response content does not match the application-based disclosure documents in the knowledge base. The cause is that the model configured in the application layer and the model used in the knowledge base optimization step are not consistent.

## How to confirm the configuration is correct
- Check the FastGPT v4.17.0 system logs to confirm that recalled document fragments include target documents such as application-based disclosure reply letters and application forms.
- Test government disclosure-related questions related to party building, and check whether the response marks the corresponding document source fields, such as reply document numbers or application numbers.
- Adjust the maximum citation token count parameter to verify whether the length of the returned citation fragments matches the preset value range.
- Switch to the release channel for testing, and confirm that the generated response can normally display the associated knowledge base citation sources.

Note: The configuration values listed above are common starting points. Adjust them based on your own specific samples and use cases.
