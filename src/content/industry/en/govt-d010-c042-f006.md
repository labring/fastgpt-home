# Party Building Learning Q&A for Legal Compliance and Major Risk Management: Citation Sources and Traceability
Reference only; verify against the target FastGPT release and deployment documentation.

## What This Category of Data Looks Like
Daily documents for this category include compliance risk lists, contract legal review opinions, major issue legal opinions, compliance review forms, and violation report investigation reports. Data comes from enterprise contract management systems, compliance risk databases, laws and regulations databases, case management systems, and report platforms. The update frequency is once per month.
Most documents are structured or semi-structured text, with fields such as risk level, review opinions, and handling results. Some documents include multi-page attachments, requiring association of the full traceability chain between the main document and attachments.

## What Constraints Do These Characteristics Impose on the "Citation Sources and Traceability" Link
Data sources are mostly internal enterprise business systems with strict permission layers. When citing, traceable data must only be visible to authorized roles to prevent sensitive compliance information leaks.
The monthly update feature requires the traceability system to support regular incremental data synchronization, to avoid citing expired documents.
Documents contain structured fields such as risk level and review opinions. Traceability must accurately match corresponding fields instead of only full text, to ensure cited compliance bases are accurate.
Some documents include multi-page attachments. Traceability must fully associate the main document and attachments, to ensure complete context of cited content.
In the party building learning Q&A scenario, citations must cover both business compliance and party building specification bases, to ensure dual relevance of traceability information.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Fits the single-paragraph citation length for compliance documents, avoids exceeding model context thresholds |
| `responseData` | Enabled | Must fully return citation data to meet traceability requirements for compliance reviews |
| `detail` | Calibrated via actual testing | Adapts to multi-dimensional traceability needs in party building Q&A scenarios |
| Traceability detail display level | Full fields | Compliance documents must display key fields such as risk level and review opinions for verification |
| Citation recall limit | Top 3 entries | Avoids excessive citations distracting from key content, while covering major compliance bases |
| Incremental synchronization frequency | Monthly | Matches the monthly data update rhythm to ensure timeliness of traceable data |

## Three Common Mistakes
- An input error pops up after clicking the code run node in the workflow. Cause: Citation traceability permission parameters are not configured correctly, causing the plugin to fail to read authorized data from the compliance database.
- Citation result count is only 100 or 900, unable to select a value around 300. Cause: The optional range of the interface setting item does not cover the middle range. Adjust the recall limit via custom configuration of the corresponding parameter.
- Traceability results do not associate metadata fields of the corresponding document. Cause: The return citation data switch is not enabled, causing only text content to be returned without key information such as source system and update time.

## How to Confirm Configuration Is Complete
- Initiate a compliance-related question in the party building learning Q&A, check whether the returned results contain clear citation source identifiers.
- Verify the update time of the cited content to confirm it matches the monthly data update rhythm.
- View the citation details to confirm they include key field information of compliance documents.
- Test citation counts across different question scenarios to confirm they match the preset recall limit settings.
