# Party Building Learning Q&A for Legal Compliance and Major Risk Management: Sharing and Embedding

## What Data for This Category Looks Like
Data for this category comes from enterprise contract management systems, compliance risk databases, laws and regulations repositories, case management systems, and reporting platforms.
Daily documents include compliance risk lists, contract legal review opinions, major issue legal opinions, compliance review forms, and violation report investigation reports.
Compliance risk lists include risk categories, trigger conditions, and disposal suggestions. Contract legal review opinions include contract subjects, risk points, and modification suggestions. Violation report investigation reports include report content, investigation processes, and handling opinions.
Data update frequency is once per month. Document structures cover two categories: long-form legal documents and structured tables.

## Constraints Imposed by These Characteristics on the Sharing and Embedding Link
Category data originates from multiple internal systems and has high sensitivity. Strict cross-system data source permission verification must be configured during embedding to prevent unauthorized access.
Documents include long-form text and structured formats. The embedded knowledge base retrieval module must support multi-format parsing to ensure complete content retrieval.
The data update frequency is monthly. Shared knowledge base synchronization tasks must match this cycle to avoid frequent synchronization occupying internal system resources.
For embedding scenarios involving party building learning Q&A, internal office interaction specifications must be followed to prevent irrelevant functions from triggering browser security interception.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Knowledge base synchronization cycle | Once per month, 2–4 AM | Matches the monthly update frequency of category data, avoids peak business hours |
| Data source permission verification | Access restricted to internal IP ranges | Aligns with the high sensitivity of compliance data, prevents unauthorized external calls |
| Document chunking rule | Split by paragraph, 800–1200 characters per chunk | Meets parsing requirements for long-form legal documents and structured tables |
| API call timeout | 600 seconds | Satisfies retrieval and generation time requirements for long-form legal opinions |
| Embedded interface image interaction | Allow out-of-page pop-ups | Supports external zoom operations for images in responses |
| `shareId` | Bound to the exclusive compliance and party building knowledge base | Ensures API calls only use exclusive data for this category |

## Three Common Mistakes
- Phenomenon: After sharing as an API, some compliance-related questions fail to retrieve knowledge base content, while retrieval works normally on the debug page. Cause: The `shareId` is not bound to the exclusive compliance and party building knowledge base, causing the API call to use the default general knowledge base.
- Phenomenon: When the intelligent agent response on an embedded webpage includes images, the images can only be viewed within the iframe and cannot be zoomed externally. Cause: The image pop-up permission for the embedded interface is not configured, and the browser restricts external interaction with elements within the iframe by default.
- Phenomenon: After modifying the front-end embedded code, calling the API results in a connection blocked error. Cause: The allowed calling IP ranges are not configured, and the browser blocks API requests from unauthorized sources.

## How to Confirm Configurations Are Correct
- Call the API interface generated via sharing, enter compliance-related questions, and verify that returned results come from category-specific documents such as compliance risk lists and legal opinions.
- Access the internal page with the embedded intelligent agent, send a question that includes images, and confirm that images can be zoomed normally outside the page.
- Call the API interface from an unauthorized IP range, and confirm that a permission denied prompt is returned.
- View the FastGPT v4.17.0 knowledge base synchronization logs, and confirm that the monthly automatic synchronization task runs normally.
