# Party Building Learning Q&A for Land Use Preliminary Examination and Planning Permit: Sharing and Embedding

## What this category of data looks like
Data is sourced from the national land spatial planning unified map, project approval and supervision platform, land use status database, and ecological protection red line data. Update frequency is irregular. Daily documents include land use preliminary examination and site selection opinion, construction land planning permit, construction project planning permit, red line drawings, and planning conditions. Fields include project number, site selection coordinates, land use scale, control boundary, and more. Stored in two formats: text approval documents and spatial vector data, serving the land and planning approval process in the early stage of construction projects.

## Constraints imposed by these characteristics on the "sharing and embedding" link
The data includes two formats: text approval and spatial vector. Embedding must support associated sharing of both text Q&A and spatial data preview. Update frequency is irregular, so the embedded Q&A system must be configured with real-time data source pulling logic to avoid returning expired approval or planning data. There are many document fields linked to the full project process, so the retrieval scope must be limited to the exclusive data of this category when sharing, to prevent irrelevant content from interfering with Q&A accuracy. Confidential spatial data must strictly control sharing permissions, only allowing internal authorized users to access.

## Three common configuration mistakes
- Phenomenon: The embedded page displays blank and pops up a script error prompt in IE browser. Cause: FastGPT embedding code is not compatible with modern JavaScript syntax of IE browser, and IE browser has stopped official updates.
- Phenomenon: The shared Q&A returns document content unrelated to land use preliminary examination and planning permit. Cause: The retrieval data source scope configuration does not limit to the exclusive data source of this category, and other natural resource documents are mixed in.
- Phenomenon: The embedded Q&A cannot load the latest planning red line data. Cause: No real-time data source synchronization logic is configured, and cached old data is not updated in time.

## How to verify successful configuration
- Copy the generated embedding code, paste it into a test page, verify that the page loads normally and displays the party building Q&A entrance related to land use preliminary examination and planning permit.
- Enter a test question, such as "Does a certain project site selection meet the ecological protection red line requirements", verify that the returned result is associated with the data sources of the national land spatial planning unified map and project approval and supervision platform.
- Use an unauthorized account to access the embedded page, verify that the Q&A content cannot be viewed, confirm that the permission verification takes effect.
- Simulate network fluctuation disconnect and recovery, verify that the system can normally resume Q&A loading after triggering error retries.
