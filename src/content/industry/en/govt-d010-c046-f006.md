# Party Building Study Q&A for Social Assistance and Minimum Living Security Audit: Citation Source and Traceability
FastGPT v4.17.0

## What the data for this category looks like
Data for this category primarily comes from the resident family economic status verification system, low-income population dynamic monitoring platform, and cross-department shared data from public security, human resources and social security, medical insurance, housing and urban-rural development, tax, and other departments. The update frequency is once per month.
Documents processed daily include minimum living security application forms, family economic status verification reports, household survey forms, democratic appraisal records, public notice materials, and assistance approval forms.
Data fields focus on family income, property status, and member relationships. There are no unified standard units, so adaptation to the original formats of cross-department data sources is required.

## Constraints on Citation Source and Traceability
Cross-department data sources have inconsistent formats. The citation traceability link must support parsing and association of multi-source metadata to avoid source matching deviations.
Monthly update frequency requires regular triggering of knowledge base incremental synchronization. This prevents use of expired family economic status data, which would reduce audit accuracy.
Diverse document types require different citation priority configurations based on business scenarios. For example, public notice materials should be prioritized for traceability due to their official public disclosure attributes.
Traceability of sensitive fields such as family income and member relationships must retain the system identifier of the data source. This ensures the audit process is traceable and compliant with civil affairs work requirements.

## Configuration Settings

| Citation priority configuration | Sorted by public notice materials, verification reports, household survey forms | Different documents have different business credibility. Prioritize displaying official public disclosure materials. |

## Three Common Misconfigurations
- Phenomenon: When `quoteMaxToken` is set above 3000, the large language model cannot receive context content. Cause: This exceeds the default threshold of the FastGPT context window, resulting in truncated or skipped context delivery.
- Phenomenon: Garbled characters appear after uploading CSV documents related to minimum living security. Cause: The CSV encoding format is not specified. The original file encoding exported across departments does not match the platform's default encoding.
- Phenomenon: Associated data is not displayed after configuring citation sources. Cause: The `detail` parameter is not enabled, or the metadata return rules for the data source are not correctly configured.
