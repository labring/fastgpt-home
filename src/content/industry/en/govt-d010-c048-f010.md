# Administrative Licensing and Approval Party Building Learning Q&A: Knowledge Base Retrieval and Recall

## What This Category of Data Looks Like
This category of data comes from the national integrated government service platform item database, administrative licensing item list, departmental business approval systems, and electronic certificate database, and is updated daily. Daily documents include service guides, application forms, commitment letters, acceptance notices, correction notices, administrative licensing decision documents, license certificates, etc. Fields cover item codes, handling conditions, application material lists, approval processes, certificate validity periods, etc. There is no unified unit, and some fields must strictly match the boundaries of legal licensing items.

## What Constraints These Characteristics Impose on the Knowledge Base Retrieval and Recall Link
The requirement for daily data updates means the retrieval link must be configured with a daily incremental synchronization mechanism to ensure recalled content aligns with the latest item lists and approval processes. The existence of multiple document types requires chunking rules adapted to different document structures to avoid splitting structured fields and losing key information. The business requirement centered on legal licensing item boundaries means retrieval must match by item groups to avoid recalling irrelevant content across items. The associated need for the electronic certificate database means the retrieval link must enable field mapping between systems to ensure accurate verification of application materials and certificates.

## How to Configure the Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Matches the legal boundaries of administrative licensing items, must ensure strong association between retrieval results and item codes and handling conditions, to avoid mixing in low-relevance content |
| `limit` | Top 8 entries | Application materials for administrative licensing approval must be matched one by one. Recalling too many contents at one time will exceed the context window, while ensuring coverage of all necessary handling requirements |
| `searchMode` | `vector` | Administrative licensing items require precise matching of setting basis and handling conditions. Vector retrieval can achieve dual matching of semantics and keywords, adapting to the precise matching needs of administrative licensing items |
| `usingReRank` | Enabled | Recalled results of multiple document types require secondary sorting to ensure core documents such as the most relevant service guides and approval decision documents are ranked first |
| `datasetSearchUsingExtensionQuery` | Enabled | Can supplement keywords of legal licensing items by expanding user questions, improving matching accuracy for professional terms |
| `collectionIds` | Configured by administrative licensing item groups | Matches the business requirement of taking legal licensing items as boundaries, ensuring retrieval only targets the document collection corresponding to the relevant item |

## Three Common Configuration Errors
- A retrieval prompt appears: "No available channel for model gpt-4o-mini under current group default". The cause is that exclusive `collectionIds` are not configured for administrative licensing items, the default group is used, and the corresponding model channel is not bound.
- When referencing a knowledge base with configuration variables, parameters are not specified, resulting in retrieval failing to accurately match the document collection of the corresponding item. The cause is that the retrieval scope is not configured by referring to the field mapping rules of the item database.
- Electronic certificate image links in the knowledge base are displayed as "input an image" in responses. The cause is that the image rendering configuration for document extended retrieval is not enabled, or the image storage path of the certificate database is not correctly mapped.

## How to Verify the Configuration is Complete
- Perform a single retrieval test, enter keywords corresponding to the administrative licensing item, and check whether the recalled results only include documents corresponding to this item, with no cross-item content.
- View system logs to confirm that the daily incremental synchronization task is executing normally, with no error records for data update failures.
- Test the configuration of referencing the knowledge base with variables, enter the code of the corresponding item, and verify whether the retrieval result automatically matches the document collection of this item.
- Upload a test service guide document, and confirm after retrieval that the returned results include core content such as handling conditions and application material lists in the document.
