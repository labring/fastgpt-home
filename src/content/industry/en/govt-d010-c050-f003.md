# Party Building Learning Q&A for Fiscal Expenditure Performance Evaluation: Multi-turn Dialogue and Prompt Engineering
This document is written based on FastGPT v4.17.0.

## What this category of data looks like
This category of data originates from the unified budget management system, project declaration materials, fund payment data, business system ledgers, and satisfaction surveys. The update frequency is annual. Commonly processed documents include performance target forms, self-evaluation forms, performance evaluation reports, supporting material lists, and rectification reports. Core fields cover performance target items, fund disbursement records, supporting material association information, and rectification completion status. The data structure centers on a single fiscal expenditure project, linking business and financial information across all stages.

## What constraints these characteristics impose on the multi-turn dialogue and prompt engineering link
The annual updated data characteristics of this category require multi-turn dialogue to stably link fixed fields of historical projects, avoiding frequent full data pull triggers. The presence of multiple document types requires prompt engineering to clearly distinguish extraction rules for different documents such as performance target forms and self-evaluation forms, to accurately match corresponding fields. Decentralized data sources require multi-turn dialogue to gradually guide users to supplement key parameters including project number and affiliated budget unit, gradually narrowing the data query scope. Additionally, the potential consequences of errors in performance evaluation require that variables extracted during dialogue strictly correspond to business system ledgers and fund payment data, to avoid deviations in evaluation results caused by parameter errors.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `variables` | Preset fixed fields such as project number, performance year, and fund disbursement amount | This category requires accurate extraction of business fields to match data from the unified budget management system |
| `messages` | Retain the first 20 rounds of conversation content | Multi-turn dialogue for performance evaluation needs to trace previously confirmed project parameters to avoid repeated inquiries |
| `chatId` | Bind the unique project identifier | Associate multi-turn dialogue with the corresponding performance project to avoid data confusion across projects |
| Multi-turn dialogue timeout | `600 seconds` | Verification of supporting materials and data matching for performance evaluation require a relatively long processing cycle |
| Prompt context length | `1000–1200 token` | This category of documents contains many structured fields, requiring sufficient context to carry information |
| Voice input transcription toggle | Enabled for party building learning Q&A links, disabled for performance evaluation links | Performance evaluation requires accurate input of numeric fields, and voice transcription is prone to errors |

## Three Common Misconfigurations
- Symptom: Extracted project number is empty in dialogue, and the returned result has no corresponding performance data. Cause: The project number field is not preset in the `variables` configuration, and the prompt does not guide users to clearly provide this parameter.
- Symptom: No text conversion content after voice input dialogue. Cause: The voice transcription configuration is not enabled for the corresponding link, and the voice model call rules are not correctly configured.
- Symptom: Multi-turn dialogue repeatedly asks for the same performance year parameter. Cause: The historical conversation context is not retained via the `messages` configuration, and previously confirmed parameter information is not recognized.

## How to Confirm the Configuration is Complete
- Enter the preset project number to trigger a dialogue, and check whether the system automatically retrieves the content of the corresponding performance target form.
- Test voice input in the party building learning Q&A link to confirm that it can be normally transcribed into text; initiate a dialogue in the performance evaluation link to confirm that voice transcription is not triggered.
- View the `variables` configuration item to confirm that the core business fields of this category have been preset with no omissions.
- Initiate no more than 15 consecutive rounds of dialogue, and check whether the historical conversation content is correctly retained for parameter tracing.
