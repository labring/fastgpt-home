# Party Building Learning Q&A for Road Transport Business Licensing: Source Citation and Traceability

## What this category of data looks like
This category serves transportation bureau approval departments, road transport management agencies, and transport enterprises. Daily processed documents include road transport business license applications, vehicle technical files, driver qualification materials, safety production management systems, valid business license documents, and similar items. Data is sourced from the road transport administration system, the national public service platform for dynamic road transport vehicle information, and the vehicle and personnel database, with a daily update frequency. Single documents are mostly structured approval materials, containing fixed fields such as main qualification, vehicle information, personnel qualification, safety management systems, with no additional unstructured redundant content.

## What constraints do these characteristics impose on the source citation and traceability link
The data sources for this category are scattered and updated daily. The traceability link must accurately associate the original data system and update time to ensure the timeliness of cited content. Document structures are fixed with clear fields, so corresponding document types and core fields must be marked during traceability to avoid confusion between materials from different business links. A single retrieval must cover multiple types of documents, and must not exceed the system processing limit, otherwise incomplete traceability content or timeouts will occur. At the same time, errors directly affect license processing progress, so the traceability link must ensure cited content is not tampered with, meeting the strict requirements of approval verification.

## How to Set the Configuration
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 8000–12000 token | Matches the average length of single documents for road transport business licensing, ensuring complete citation of core approval material content |
| `responseData` | Original document snippet | Meets the requirement to directly output original knowledge base text, avoiding additional decorative content |
| `detail` | Enabled | Displays source identification, update time and field information of original documents, meeting strict traceability requirements |
| Multi-knowledge base association configuration | Bind specified data sources such as the road transport administration system and vehicle dynamic platform | Covers all full business data sources for this category, ensuring complete recall results |
| Global variable reference setting | Enable global variable permissions | Supports reusing global configurations such as datasetid in workflows, simplifying multi-node deployment processes |
| Single recall limit | Top 6 entries | Matches the average number of single-batch approval materials for this category, avoiding timeouts caused by excessive recalled content |

## Three Common Misconfigurations
- Knowledge base nodes within workflows fail to read the global datasetid variable, returning empty results. The cause is that global variable reference permissions are not enabled in the node configuration, or the variable scope does not cover the current workflow node.
- AI-generated traceability content includes explanatory text not sourced from the original document, and does not directly return original document snippets. The cause is that `responseData` is not set to original document snippet mode, and the content polishing function is enabled by default.
- A single retrieval results in system timeout or truncated content due to an excessively large `quoteMaxToken` setting. The cause is that the set token limit exceeds the system's single processing threshold, and no reasonable adjustment was made based on the document length of this category.

## How to Confirm the Configuration is Correct
- A test query related to road transport business licensing is submitted. The trailing content of AI replies is checked for clear source document identification, update time and field information.
- Workflow node global variable configuration items are reviewed. The datasetid variable is confirmed to be readable normally, with no null value errors.
- Multi-knowledge base association configuration is verified. Recall results are checked to confirm coverage of content from multiple data sources including the road transport administration system and vehicle dynamic platform.
- Returned results are checked to confirm inclusion of complete original document snippets, with no additional polished content.
