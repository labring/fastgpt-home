# Party Building Learning Q&A for Department Final Accounts and Financial Reports: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Data for department final accounts and financial reports comes from the budget management integrated system, centralized treasury payment system, accounting system, and asset management system. Daily documents include department final account statements, balance sheets, income and expenditure final account statements, final account explanations, and government financial reports. Data is updated centrally on an annual basis, and is only generated and released during the annual final account cycle. Documents include fields such as revenue and expenditure details, asset and liability balances, and budget execution difference explanations. Units include standard units commonly used in financial measurement such as yuan and ten thousand yuan. Single documents have a relatively large size.

## What constraints these characteristics impose on the knowledge base retrieval and recall link
The annual update rhythm means the knowledge base only needs full data synchronization once per year, with no need for frequent incremental updates. The mixed document structure of multiple types of structured reports and unstructured explanations requires retrieval to support both precise field matching and full-text semantic recall. Data sources from internal business systems need to adapt to internal permission control access rules. Large single document data size requires reasonable control of chunking granularity to avoid context overflow. The strictness of financial professional terms requires retrieved results to match precise business expressions, avoiding ambiguity that affects the accuracy of financial compliance Q&A for party building learning.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | Department final account data requires precise matching of financial terms and business scenarios. This range filters low-correlation results and adapts to the parameter rules of FastGPT v4.17.0 |
| `limit` | `Top 8 entries` | Single final account document has large data size. Too many retrieved entries will exceed the context window. 8 entries can cover core relevant content |
| `searchMode` | `Hybrid retrieval` | Contains structured report fields and unstructured explanatory text. Hybrid retrieval balances precise matching and semantic recall |
| `usingReRank` | `Enabled` | Financial data has strong professionalism. Reranking further filters irrelevant results and improves the accuracy of party building learning Q&A |
| `datasetSearchUsingExtensionQuery` | `Enabled` | Party building learning Q&A needs to link policies and business expressions. Extended queries can supplement relevant context |
| `collectionIds` | `Specified by annual final account datasets` | Data is updated annually. Dividing by datasets avoids cross-year data interference with retrieval results |

## Three common mistakes
- Symptom: An error is returned directly after creating a directory in the knowledge base, and directory creation cannot be completed. Cause: The structured storage rules for department final account data are not adapted. System verification checks are triggered due to mismatches between directory hierarchy and report field naming.
- Symptom: Retrieval response takes too long when using Milvus vector database with GPU. Cause: The `limit` parameter is not set reasonably. Too many retrieved documents cause excessive computing resource usage in vector retrieval and reranking links. Batch index optimization is not enabled.
- Symptom: Final account documents exported from the budget management integrated system cannot be imported. Cause: The data source connection permission for the corresponding system is not configured, and the document format is not converted to the standard format supported by the knowledge base.

## How to confirm the configuration is correct
- Submit a test query that includes financial professional terms and party building learning scenarios, and check whether the relevance of the retrieved results meets expectations.
- View the knowledge base's data source synchronization logs to confirm that annual final account data has completed full synchronization according to the set cycle.
- Enter the vector database management interface, and check whether the number of retrieved entries matches the setting of the `limit` parameter.
- Test the process of creating a new directory and importing report documents to confirm there are no verification errors.
