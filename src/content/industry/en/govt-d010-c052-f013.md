# Party Building Learning Q&A for Department Final Accounts and Financial Reports: Sharing and Embedding
Reference only; verify against the target FastGPT release and deployment documentation.

## What this category of data looks like
Data for department final accounts and financial reports comes from the budget management integrated system, centralized treasury payment system, accounting system, and asset management system. The update frequency is once per year. Daily documents include department final account statements, balance sheets, income and expenditure final account statements, final account explanations, and government financial reports. Data fields include unit code, subject code, revenue and expenditure execution amount, adjustment amount, and others. Amounts are denominated in yuan. The data structure is rigorous and involves internal financial sensitive information.

## What constraints do these characteristics impose on the "sharing and embedding" link
The annual update cycle means embedded content does not require frequent refreshes. After data updates, bound datasets must be re-synced. Structured report documents require embedded Q&A applications to accurately associate with datasets of the corresponding category, to avoid mixing in other fiscal data. The origin from internal systems requires strict access control in embedding configuration, to prevent unauthorized users from obtaining sensitive financial information. The party building learning Q&A scenario requires shared content to comply with confidentiality specifications, and must not disclose specific final account details.

## How to set the configuration
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Share link ID | Use the `shareId` bound to the current application | Ensure the embedded page is associated with a dedicated party building Q&A application, to avoid confusion with other applications |
| Guest window export function | Turn off Markdown export | Department final account data is internal sensitive financial information, to prevent data leakage after export |
| User conversation persistence | Enable user-specific storage | Ensure that Q&A history of financial personnel from different budget units is only visible to the respective user, to comply with data isolation requirements |
| Context window size | 2000-3000 token | Adapt to the length of department final account documents, accommodate context information for multi-turn Q&A |
| Single recall document limit | Top 10 entries | Balance answer accuracy and response speed, avoid excessive irrelevant data interfering with Q&A |
| Response timeout setting | 600 seconds | Adapt to the loading time of department final account documents, avoid request timeout due to large data volume |

## Three common errors
- Phenomenon: The embedded iframe page displays a Markdown export button, and the button cannot be hidden through interface settings. Cause: The export option in the guest window export configuration is not turned off, and the export function is retained by default.
- Phenomenon: Different users can view each other's conversation history after accessing the embedded page. Cause: The user-specific conversation storage configuration is not enabled, and conversation data is shared globally without isolation.
- Phenomenon: The embedded page prompts "Failed to load application" after loading. Cause: The `shareId` is not configured correctly, and it is impossible to associate with a valid party building Q&A application instance.

## How to confirm that the configuration is complete
- Access the embedded iframe page, check whether the Markdown export button is displayed on the interface, and confirm that it is not visible.
- Use two different identities to access the embedded page, initiate different Q&A sessions respectively, and confirm that each user's conversation history is only visible to themselves.
- Modify the configured `shareId` to an invalid string, refresh the page, and confirm that an application loading failure prompt appears, to verify the validity of the configuration association.
- Bind a test department final account document, initiate a Q&A session about statement verification, and confirm that the answer content only associates with the currently bound dataset, and does not mix with data from other categories.
