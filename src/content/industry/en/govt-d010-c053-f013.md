# Party Building Learning Q&A for Department Budget Preparation: Sharing and Embedding

## What data falls under this category
This category's data mainly comes from the unified budget management system, department staff establishment system, prior-year final accounts, project library, and the Ministry of Finance's budget preparation notices. The update frequency is annual. Daily processed documents include department budget drafts, project application forms, performance target forms, personnel expense calculation forms, budget approvals, and similar items. Data fields include project codes, expense amounts, staff establishment numbers, performance indicators, and similar items. Units include ten thousand yuan, number of people, project cycle, and similar items. All data is internal business content related to financial management.

## What constraints do these characteristics impose on the sharing and embedding process
Since this category's data is updated annually, the embedded knowledge base must regularly sync the latest budget preparation notices and current year's project library data. Otherwise, Q&A results will use outdated information. Daily documents are mostly structured budget-related files. When sharing and embedding, precise association with the budget knowledge base nodes of the corresponding department is required, to avoid mixing in non-budget party building learning content. Most data sources are internal financial systems. Embedding configuration must match internal permission rules, to ensure only authorized personnel can access party building Q&A content linked to budget data. Sensitive budget fields must also be prevented from being accessed by unauthorized users.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Sharing link permission | Visible to internal organizations | This category's data involves sensitive financial budget information, so unauthorized access must be restricted |
| Knowledge base binding scope | Bound to the party building knowledge base for budget preparation of the corresponding department | Ensure that Q&A only calls budget documents and party building learning content from this category |
| Global language setting | Match according to usage scenarios, such as Chinese/English | Adapt to the language habits of different users |

## Three common mistakes
- The display language of the embedded page does not match the preset configuration, because the global language parameter was not correctly set in the sharing configuration.
- Custom variables in the login-free sharing link do not display properly, because custom variables were not configured to allow passing in sharing scenarios.
- The Q&A returns budget data from the previous year, because the bound knowledge base data was not synced according to the annual update frequency.

## How to confirm that the configuration is complete
- Open the shared embedded page, check whether the display language matches the preset global language setting.
- Generate a login-free sharing link, pass in the preset custom variables, and verify that the variables display correctly.
- Initiate a party building Q&A that includes budget preparation related content, verify that the returned results use current year's budget document data.
- Attempt to access the sharing link using an unauthorized account, confirm that Q&A content cannot be obtained normally.
