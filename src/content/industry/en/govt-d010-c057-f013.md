# Food Safety Supervision Sampling Party Building Learning Q&A: Sharing and Embedding

## What this category of data looks like
Data sources for this category include the food safety sampling monitoring system, the State Administration for Market Regulation sampling results query system, the testing institution LIMS system, and the food producer and operator ledger. Daily documents cover sampling plans, sampling slips, inspection reports, unqualified food verification and disposal reports, and risk control notices. Data is updated monthly. Core fields include sampling number, inspection items, unqualified judgment results, verification and disposal progress, etc. All content is generated around the sample inspection and unqualified disposal workflow.

## What constraints these characteristics impose on the sharing and embedding link
The monthly updated data source requires that the embedded Q&A system regularly synchronizes full or incremental data to avoid referencing expired sampling plans or disposal results. The mixed structure of multiple document types requires configuring targeted document chunking rules when sharing and embedding, to ensure that professional fields in inspection reports and process information from sampling plans can be accurately retrieved. The professionalism of core fields means that the embedded Q&A interface must retain reference links to original documents, to facilitate regulatory staff to verify original vouchers, and also limit the single-round context length to avoid irrelevant historical sampling data interfering with current Q&A. The rigor of data association requires that the embedding function supports binding exclusive data pools by `shareId`, to prevent mixing of sampling data from different supervision institutes, ensuring business data isolation.

## How to set the configurations
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Document chunk length | 800–1200 characters | Adapts to the paragraph length of professional documents such as inspection reports and sampling slips, avoiding splitting key testing data |
| Context recall limit | Top 6 entries | Matches the monthly updated data volume, preventing excessive historical data from occupying loading resources of the embedding window |
| Reference link display | Enabled | Facilitates regulatory staff to verify core vouchers such as original sampling reports and disposal notices, meeting business rigor requirements |
| Exclusive data pool binding | Configured by `shareId` | Differentiates sampling data from different supervision institutes and testing institutions, avoiding cross-entity data mixing |
| Loading timeout threshold | 300 seconds | Adapts to the loading and retrieval time of large inspection reports, preventing embedding failure caused by network delays |

## Three common errors
- Phenomenon: Clicking on AI reply content after embedding fails to trigger local system navigation. Reason: The callback event binding of the embedding window is not configured, only FastGPT content display is implemented, and the navigation interface of the local application is not connected.
- Phenomenon: The login-free sharing link does not carry an exclusive identifier, resulting in failure to isolate sampling data from different supervision institutes. Reason: No custom identifier is added to the sharing link parameters, and the corresponding data pool configuration is not associated via `shareId`.
- Phenomenon: Embedded pages do not display reference links to original inspection reports or disposal notices after loading. Reason: The reference link rendering configuration is not enabled, or the metadata of core documents is not correctly associated with Q&A results.

## How to confirm the configuration is complete
- Copy the generated embedding code, deploy it to the test page of the local supervision system, and check whether the party building learning Q&A interface loads normally.
- Submit questions related to sampling plans and unqualified food disposal, confirm that the AI reply includes the corresponding original document reference links.
- Use embedding links with different `shareId` to submit Q&A, confirm that only exclusive sampling data of the corresponding supervision institute or testing institution can be accessed.
- Wait for the monthly data update, reload the embedded page, and confirm that the latest sampling reports and disposal notices have been synchronized to the Q&A database.
