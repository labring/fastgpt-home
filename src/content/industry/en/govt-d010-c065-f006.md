# Party Building Learning Q&A for Survey and Design: Citation Sources and Traceability

## What this type of data looks like
Reference only; verify against the target FastGPT release and deployment documentation.

## What constraints do these characteristics impose on the citation sources and traceability link
The project association attribute of survey and design party building data requires traceability information to include the corresponding project number. Otherwise, it cannot meet the needs of engineering personnel to bind party building learning to specific projects. Differences in document secrecy levels require filtering non-authorized accessible secret files during configuration to avoid unauthorized disclosure of internal information. The long-text official document structure requires retaining chapter and paragraph logic when chunking. This avoids truncating key context and leading to inaccurate traceability. The non-fixed update rhythm requires the knowledge base to support incremental synchronization mechanisms. This ensures newly released party building documents can be quickly included in the available citation scope.

## Configuration settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 characters | Survey and design party building documents mostly contain project association information. This range can cover the core content of a single chapter and the associated project ID, avoiding truncation of key traceability information |
| Maximum knowledge base citations | Top 3–5 entries | Party building reference content in this field is mostly monthly materials on the same topic. 3 to 5 entries can cover the common study scope, avoiding response redundancy |
| `responseData` | Enable traceability field display | It is necessary to return unique fields of survey and design party building documents such as associated project number and publishing unit, to meet the traceability needs of engineering scenarios |
| Maximum context | 4000–6000 tokens | Survey and design party building documents often contain cross-chapter project association descriptions. This range can fully load the context to ensure coherent Q&A logic |
| `detail` | Enable detailed traceability | It is necessary to display fields such as document publication date and desensitized secrecy level, which complies with compliance traceability requirements in engineering scenarios |

## Three common errors
- Phenomenon: The returned citation list contains secret document content, and a red error is displayed on the interface. Cause: No filtering rules for secret files are configured, and internal secret party building files are included in the available citation scope.
- Phenomenon: No variable reference is used when selecting the knowledge base, making it impossible to associate party building files of the current survey and design project. Cause: No variable rules for knowledge base filtering are configured, so associated party building content cannot be automatically filtered by project ID.
- Phenomenon: `quoteMaxToken` is set too small, causing the cited content to be truncated and project association information to be lost. Cause: The parameter threshold is not adjusted based on the long-text characteristics of survey and design party building documents.

## How to confirm the configuration is correct
- Initiate a party building Q&A that includes project association information, check whether the returned results contain traceability fields such as document publishing unit and associated project number.
- Adjust `quoteMaxToken` to a very small value, verify whether the cited content is truncated, and confirm that the parameter takes effect.
- Upload a secret test file, verify that unauthorized users cannot view the cited content of this file, and confirm that the permission filtering takes effect.
- Test batch updates of the party building knowledge base, verify that the traceability information of new files can be normally displayed after incremental updates.

The values given are common starting points and should be measured against the reader's own samples.
