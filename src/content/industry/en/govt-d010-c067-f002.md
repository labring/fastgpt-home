## What constraints these characteristics impose on vector models and indexing
Fertilizer and pesticide party building learning data contains industry-specific terminology, such as "slow-release fertilizer production process" and "pesticide field efficacy test specifications". This content differs from general party building materials, so a vector model adapted for professional domains must be selected. The length of individual documents varies widely, ranging from several hundred to several thousand characters. When splitting documents into chunks, balance must be maintained between content completeness and indexing efficiency. Some documents contain internal restricted content for enterprises, so permission filtering rules must be configured during the indexing stage. Data updates follow no fixed cycle, so support for switching between incremental indexing and full indexing is required to avoid reprocessing archived files.

## Three Common Configuration Mistakes
- The interface displays a vector model load failure, with a log returning an out-of-vRAM error. The GPU device used by the vector model is not specified. Two 3090 graphics cards are not properly allocated, causing the single-card vRAM to be insufficient for loading the model.
- A 404 error prompt pops up after configuring the indexing model. The `oneapi` access address is not correctly configured, or the `Baidu Embedding-v1` API key has not completed permission configuration, causing API requests to not be properly identified.
- An insufficient permissions prompt appears when attempting to add a vector model in a non-GPU environment. FastGPT’s vector model support configuration under CPU mode is not enabled, causing the system to only allow model loading in GPU environments by default.
