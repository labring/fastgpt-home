## Three Common Configuration Errors
- `Unexpected end of JSON input` error. This occurs when `AIPROXY_API_TOKEN` or the proxy address is not configured correctly, resulting in an incomplete JSON format response from model requests.
- Off-topic responses during long-text Q&A. This happens when `maxContext` is set too small, failing to recall sufficient relevant context and leaving the model without adequate reference material.
- Model outputs that do not match the preset format after uploading a QA-format knowledge base file. This is caused by failing to enable the precise matching configuration for `toolChoice`, leading the model to not strictly follow QA entries in the knowledge base for outputs.

## How to Verify Successful Configuration
- Initiate a long-text Q&A test related to party building learning, and confirm that the model’s returned content includes corresponding policy provisions or learning key points from the knowledge base.
- Check model call logs to verify that the actual usage values of `maxContext` and `maxTokens` match the preset configuration, with no abnormal truncation.
- Simulate an unauthorized API request, and confirm that the returned result is an identity verification failure, verifying the effectiveness of the `AIPROXY_API_TOKEN` configuration.
- Upload a test QA-format file, initiate a Q&A for the corresponding question, and confirm that the model output strictly matches the preset answer in the knowledge base.
