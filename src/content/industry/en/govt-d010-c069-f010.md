# Hazardous Chemicals Storage and Transportation Party Building Learning Q&A: Knowledge Base Retrieval and Recall

## What this category of data looks like
Party building learning data for hazardous chemicals storage and transportation comes from Party building work ledgers, team study records, safety and compliance supporting Party building documents of state-owned and public sector enterprises engaged in hazardous chemicals storage and transportation, and Party building guidance materials for storage and transportation links issued by superior Party committees. Updates occur once per month, synchronized with the enterprise's monthly Party building work. Document structure includes five fields: issuing unit, release date, applicable storage and transportation link (tank farm, pipeline, loading and unloading, etc.), document number, and core clauses. Single document word count ranges from 800 to 1500 characters. Some content combines hazardous chemicals professional terminology with Party building policies.

## What constraints these characteristics impose on knowledge base retrieval and recall
Documents are categorized by storage and transportation link. Retrieval must be limited to the knowledge base set for the corresponding link to avoid interference from cross-category materials. The monthly update feature requires the retrieval system to support regular knowledge base synchronization to ensure content timeliness. Documents containing professional terminology require a balance between semantic and keyword matching to prevent recall results from deviating from the storage and transportation scenario. Single documents have a relatively long length. The retrieval recall context length must be adapted to avoid exceeding the model context window. Redundant content must be filtered to ensure answer accuracy.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.72–0.78 | Matches the professional terminology precision of hazardous chemicals Party building content, filters non-storage and transportation link Party building materials |
| `limit` | Top 6 entries | Balances the recall comprehensiveness of hazardous chemicals storage and transportation Party building content with the single conversation context length limit |
| `searchMode` | Keyword + semantic hybrid | Adapts to the document structure that includes both Party building policy keywords and hazardous chemicals professional terminology |
| `usingReRank` | Enabled | Rearranges initial recall results by relevance, improves the display priority of core content |
| `datasetSearchUsingExtensionQuery` | Enabled | Supplements extended query terms related to hazardous chemicals storage and transportation, covers synonyms and professional terminology variants |
| `collectionIds` | Collection IDs grouped by storage and transportation link | Accurately limits the retrieval scope, prevents cross-category Party building materials from mixing into the result set |

## Three common errors
- Phenomenon: An error message stating "the number of associated knowledge bases exceeds the upper limit" appears after initiating a query. Cause: The knowledge base is not grouped and configured according to `collectionIds`, and all Party building knowledge bases are fully associated directly, exceeding the single conversation association upper limit.
- Phenomenon: Retrieval results include Party building content from non-hazardous chemicals storage and transportation links, which is irrelevant to the query topic. Cause: The retrieval scope is not limited by configuring `collectionIds`, or the `similarity` threshold is set too low, causing irrelevant content to be recalled.
- Phenomenon: The large model-generated answer does not cite the retrieved knowledge base document entries. Cause: `usingReRank` or `datasetSearchUsingExtensionQuery` is not enabled, leading to insufficient relevance of recall results that the model cannot identify as valid reference content.

## How to confirm the configuration is complete
- Log in to the FastGPT v4.17.0 backend, enter the knowledge base management module, confirm that independent knowledge base collections have been created according to the tank farm, pipeline, loading and unloading and other links of hazardous chemicals storage and transportation, and the corresponding `collectionIds` have been configured.
- Initiate a test query, input "Safety and compliance requirements for hazardous chemicals storage and transportation team Party building learning", check whether the applicable scenarios of the retrieval results are storage and transportation links, and the `similarity` score falls within the 0.72–0.78 range.
- View the citation module in the conversation interface, confirm that all retrieved document entries are correctly listed, with no empty fields or missing information such as issuing unit and applicable link.
- Adjust the `similarity` threshold to 0.70, verify whether irrelevant content is recalled, and confirm that the threshold setting meets the category requirements.

The values listed above are common starting points, and should be evaluated against the reader's own samples.
