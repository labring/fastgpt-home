## Three Common Configuration Mistakes
### Mistake 1
Phenomenon: The iframe area of the embedded page displays a blank screen. The browser console returns a 403 Forbidden status code.
Cause: The sharing link permission is configured as public, and no internal access permission is set for hazardous chemicals storage and transportation party building materials. Unauthorized users cannot load the content.

### Mistake 2
Phenomenon: The chat window occasionally fails to display after the iframe finishes loading. Refreshing the page restores normal functionality.
Cause: The embedded window height setting does not reserve space for the chat box to expand, or global page styles override the default display rules of the chat container.

### Mistake 3
Phenomenon: The interface language of the sharing link does not match the preset personalized settings.
Cause: No language is specified separately in the sharing configuration. The default language setting from the FastGPT console main interface is inherited, and no adjustment is made for external user groups.
