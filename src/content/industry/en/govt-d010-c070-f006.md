# Party Building Learning Q&A for Power Generation Equipment Manufacturing: Citation Sources and Traceability

## What Data for This Category Looks Like
Power generation equipment manufacturing party building learning data mainly comes from standardized documents issued by the enterprise party committee, learning ledgers from each workshop branch, and public materials from internal party building columns. The data update rhythm follows monthly updates of branch study plans and quarterly synchronization of the latest superior party building requirements. The structure of a single document is fixed: title, issuing unit, release date, and main content. Additional attached fields include document number, required study hours, and responsible branch. Study hours are measured in hours, and the storage size of a single file is counted in MB.

## What Constraints Do These Characteristics Impose on Citation Sources and Traceability
Decentralized sources of power generation equipment manufacturing party building data require citation traceability to accurately associate with the issuing entity, to avoid confusing study materials from different branches. The fixed document structure and fields require extracting metadata such as issuing unit, release date, and document number during citation, to ensure complete traceability information. The monthly and quarterly update rhythms mean the knowledge base sync cycle must match the update frequency, to prevent citing outdated content. Clear hour unit requirements require synchronizing the duration of corresponding study requirements during traceability, to avoid missing information.

## Three Common Misconfigurations
- Phenomenon: After calling the knowledge base module in a workflow, no source annotation information appears in the reply. Cause: The `responseData` configuration item is not enabled, so the system does not synchronize and return source file metadata.
- Phenomenon: Garbled square or angle bracket citation markers appear at the end of each paragraph in the AI output, which are later automatically converted to standard quotation marks. Cause: The return format of the `detail` parameter is not configured correctly, resulting in unescaped special symbols.
- Phenomenon: When asking a party building question that does not exist in the knowledge base, irrelevant document citations are still returned. Cause: A reasonable similarity threshold is not set, resulting in incorrectly recalled low-match content.

## How to Confirm the Configuration Is Correct
- Submit a specific party building-related question, check whether the reply includes metadata such as issuing unit and release date.
- Review the format of cited fragments, confirm that there are no garbled citation markers and the format meets expectations.
- Test asking a party building question not included in the knowledge base, confirm that no irrelevant cited content is returned.
- Adjust the value of `quoteMaxToken`, verify whether the completeness of cited fragments meets requirements.
