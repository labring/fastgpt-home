# Party Building Learning Q&A for Power Generation Equipment Manufacturing: Forms and Interactions

Reference only; verify against the target FastGPT release and deployment documentation.

## What the data for this use case looks like
Party building learning data in the power generation equipment manufacturing field mainly comes from official documents archived in the enterprise party committee office, party building activity records from frontline workshops, and learning guidelines issued by superior state-owned assets supervision authorities. Data is updated in three rhythms: synchronizing newly released party building learning materials from superior authorities monthly, updating internal workshop activity ledgers quarterly, and adding temporary learning tasks in line with project milestones. Document structure includes topic classification, publishing entity, effective date, main text, and supporting question stems. Fields cover applicable job scope and document number, with units of "articles" and "times" as statistical dimensions.

## What constraints these characteristics impose on forms and interactions
Because the party building learning data includes the applicable job scope field, the form must be configured with job filtering interaction to only display learning Q&A content visible to personnel in corresponding jobs. There are two update rhythms for data: monthly regular updates and temporary additions tied to project milestones. The interaction link must support real-time pulling of the latest question bank to avoid outdated content. The structure of supporting question stems and options in documents requires the form to distinguish between the question stem input area and the option configuration area, while also supporting batch import of structured Q&A data. The associated fields of job and document number require the form to automatically bind corresponding metadata when submitting learning records, ensuring that learning data can be traced.

## How to set the configuration
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Limit input length to 200–500 characters | Party building question stems need length control to avoid redundant user input |
| `userSelect` | Preset three options: frontline operation and maintenance, assembly workshop, quality inspection team | Aligns with core job classifications in power generation equipment manufacturing, and matches the applicable job field in the data |
| Single search limit | Top 10 entries | Party building Q&A data volume is moderate; too many results increase user filtering costs |
| Input timeout | 300 seconds | Sufficient time is needed to load job-associated question bank data and reserve adequate interface response duration |
| Batch import format | CSV format, including topic, question stem, option, and job fields | Matches the structured fields of existing party building learning data to simplify batch configuration workflows |

## Three common mistakes
- Phenomenon: Double quotes in imported structured Q&A data are automatically escaped with backslashes, showing raw text with \ during front-end rendering. Cause: The automatic escape logic was not disabled in the form configuration, causing the submitted JSON data to be escaped a second time.
- Phenomenon: Entering the same party building question during workflow debugging returns results that do not match those from front-end actual testing. Cause: The debugging environment is not bound to actual job filtering parameters, while the front-end automatically carries the filter condition of the user's assigned job when submitting, leading to different question bank recall scopes.
- Phenomenon: When configuring the knowledge base search interaction node, the drop-down box for variable reference has no selectable values. Cause: No output variable was configured in the preceding node, or the output variable is not associated with the party building Q&A knowledge base ID field, causing it to not be referenced by the current node.

## How to confirm the configuration is complete
- Open the front-end test page, select the corresponding job, enter a party building question, and check whether the returned Q&A results match the preset question bank content.
- After importing structured Q&A data, check whether the option text in the preview interface has unnecessary backslash escape characters to confirm that the escape configuration is correct.
- Configure the `userSelect` node in the workflow, trigger job filtering, and check whether the recalled Q&A results only include content for the corresponding job.
- When configuring variable references, check whether the output variable list of the preceding node includes the required knowledge base ID or job field to confirm that the association relationship is correct.
