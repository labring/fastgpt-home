# Party Building Learning Q&A for State-owned Asset Management Companies: Citation Sources and Traceability

## What the data for this category looks like
Party building learning Q&A data for state-owned asset management companies mainly comes from Party building work standards issued by state-owned asset supervision departments, study manuals issued by the company’s Party committee, guiding documents from superior Party organizations, and internal Party building activity records.
Data is updated on a regular monthly basis, with immediate supplements during important Party building conferences or policy adjustments.
Each single document includes five fixed fields: title, issuing entity, release date, core content, and scope of application.
There are no additional custom units. Content mainly consists of standardized text, with no complex charts or unstructured materials.

## Constraints on citation sources and traceability
Since all data sources are official formal documents, the traceability link must accurately match the issuing entity and release date to ensure the authority of cited content.
The fixed document structure requires that traceability information be extracted directly from the title, issuing entity, and release date fields, with no additional parsing of unstructured content.
The regular monthly and immediate supplementary update rhythm requires that knowledge base versions associated with traceability be updated with synchronization markers to avoid returning outdated Party building learning materials.
The seriousness of Party building content requires that traceability information fully display the source hierarchy, ensuring that citations in Q&A can be traced back to the original issuing unit.

## Configuration Settings
The following configurations are based on FastGPT v4.17.0, and are adapted to the traceability needs of Party building learning Q&A for state-owned asset management companies.

| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | Matches the core content length of Party building documents, fully displays the cited original text and avoids truncating key expressions |
| `responseData` | Enabled | Ensures that Q&A results include structured citation source information to meet traceability requirements |
| `detail` | Full mode | Extracts all document metadata, including issuing entity and release date fields, for complete traceability |
| Knowledge base synchronization frequency | Once per month | Matches the monthly update rhythm of Party building data, ensuring traceability information is synchronized with the latest documents |
| Number of citation sources displayed | Top 3 | Avoids information overload while covering core reference sources |

## Three Common Configuration Errors
- Phenomenon: No citation source field appears in Q&A results, or the field content is empty. Cause: The `responseData` configuration item is not enabled, or its value is set to disabled.
- Phenomenon: After deploying via nginx proxy, knowledge base original text links cannot be downloaded normally. Cause: The static resource path of the knowledge base original text is not included in the proxy rules, only Q&A interface traffic is proxied.
- Phenomenon: After calling the FastGPT interface via a POST request, the interface returns a normal status code but has no content field content. Cause: The full mode of the `detail` configuration item is not enabled, only simplified Q&A text is returned, and no citation source data is included.

## How to Confirm Proper Configuration
- Launch a test question related to Party building, and check whether source information entries are displayed below the Q&A result.
- Verify that configuration item values meet business requirements, such as whether the maximum citation token number covers the core document length.
- Call the interface to retrieve returned data, and confirm that the `responseData` field contains complete citation metadata.
- Launch a question after simulating a knowledge base update, and confirm that new citation sources can be correctly retrieved and displayed.
