# Party Building Learning Q&A for State-owned Capital Investment Companies: Sharing and Embedding

## What the data for this category looks like
The Party Building Learning Q&A data for state-owned capital investment companies mainly comes from official documents issued by the company’s party committee office, records of three meetings and one lesson meetings, party building activity archives, and the latest internal policy interpretation materials. The data update rhythm is to synchronize regular learning content once a month, with immediate updates when major policies are released or important party building activities take place. The document structure includes fields such as title, issuing unit, release date, main body, and applicable scope. The release date uses the YYYY-MM-DD format. The word count of the main body ranges from hundreds to thousands of characters, and some confidential documents are marked with internal use identifiers.

## What constraints these characteristics impose on the sharing and embedding link
Party building learning data contains internal confidential content, so the sharing and embedding link must strictly control access permissions to avoid unauthorized users obtaining sensitive information. The periodic update feature of the data requires the embedded knowledge base to match the update frequency to ensure the timeliness of shared content. The structured document fields support filtering shared content by issuing unit and release date, and can push learning Q&A to specific party branches in a targeted manner. At the same time, the authority of party building content requires that sharing links retain source identifiers to facilitate users to trace official documents.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Number of share links accessible without login | 100 | Covers the learning sharing needs of all party branches of the company, and matches the extended configuration rules of the team edition package |
| iframe interface language | Simplified Chinese | Adapts to the usage habits of internal employees, avoiding reading obstacles caused by English interfaces |
| Share link authentication switch | Enabled | Prevents unauthorized users from accessing internal party building learning content, and complies with confidential information management requirements |
| Share link validity period | 30 days | Matches the cycle of the monthly learning plan, ensuring that the content is valid during the learning cycle |
| Embedded pop-up trigger method | Click trigger | Avoids automatic pop-up interference with user browsing during page loading, and conforms to the usage logic of internal office scenarios |
| `shareId` parameter configuration | Consistent with the application's unique identifier | Ensures that the embedded iframe points to the correct party building learning Q&A application, avoiding incorrect link pointing |

## Three common mistakes
- An error "Exceeded the number of links" pops up when creating the 11th share link accessible without login. The cause is that the team edition package defaults to a limit of 10 share links accessible without login, and the quantity has not been adjusted in advance.
- The Q&A pop-up embedded via iframe displays an English interface. The cause is that the interface language was not configured as Simplified Chinese, and the system default or English display is used by default.
- The configuration entry for share link identity authentication cannot be found. The cause is that FastGPT v4.17.0 is used. The authentication configuration has been integrated into the application permission settings page, and this option is no longer available on the old version's sharing configuration page.

## How to confirm the configuration is complete
- Open the generated share link and check whether the interface language is Simplified Chinese.
- Try to create the 11th share link accessible without login, and confirm that no link limit error is displayed.
- Copy the embedded iframe code, check whether the `shareId` parameter in it is consistent with the unique identifier of the test application, and access the embedded page to confirm that the Q&A content loads normally.
- Test access to the share link by an unauthorized user, confirm that the Q&A content cannot be obtained, and verify that the authentication function is working.
