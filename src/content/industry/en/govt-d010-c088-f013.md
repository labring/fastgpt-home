## What constraints do these characteristics impose on the "sharing and embedding" link
The fixed fields, phased update rhythm, and long document features of engineering consulting supervision party building learning data impose three constraints on the sharing and embedding link. First, documents tied to supervision sections must use `shareId` to associate with the corresponding section's dataset, ensuring only matching section party building content is displayed after embedding. Second, the weekly update rhythm requires the embedded system to configure a reasonable cache expiration time to avoid displaying outdated content. Third, single documents of 1000 to 5000 characters require adjusting context truncation rules during embedding to prevent exceeding model token limits.

## Three common mistakes
- Phenomenon: After embedding into a supervision project webpage, the page displays mixed Chinese and English languages. Cause: The page language is not fixed in the embedding configuration, and the global language setting of the embedded page is inherited by default.
- Phenomenon: The no-login sharing page cannot retain continuous sessions, and the conversation resets each time a new question is sent. Cause: The session retention function of the no-login page is not enabled, or the session validity period is set too short.
- Phenomenon: Custom variables (such as supervision section number) on the no-login page cannot be displayed normally in Q&A. Cause: Custom variable transfer is not enabled in the dataset configuration associated with `shareId`, or the variable parameters are not correctly carried in the embedded link.

## How to confirm the configuration is complete
- Open the embedded page, enter a party building question related to the bound section, check whether the preset business field information is included in the answer.
- Send 2-3 party building-related questions consecutively, confirm that the session is not reset and the conversation context is coherent.
- Modify the content of the dataset bound to `shareId`, wait for the cache to expire, refresh the page, confirm that the updated content is displayed.
- Adjust the browser language environment of the embedded page, confirm that the page display language remains in the configured unified state.
