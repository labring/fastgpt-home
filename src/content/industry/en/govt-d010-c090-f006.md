# Party Building Learning Q&A for Refined Oil Sales: Source Citation and Traceability

## What the data for this category looks like
Party building learning data in the refined oil sales sector mainly comes from internal party building work platforms of petroleum and petrochemical sales enterprises, official documents released by the Party Committee Propaganda Department, and monthly learning ledgers and morning meeting records from grassroots gas stations.
Update frequencies vary across data types. Official Party committee documents update in real time upon release. Monthly learning plans update at the start of each month. Grassroots station learning records sync weekly.
Most documents use structured formats, with fields including title, issuing unit, document number, release date, main content, and applicable level such as district or station level. Units typically use "stations" to mark station coverage, and "characters" to count main text length.
This configuration is implemented using features from FastGPT v4.17.0.

## What constraints these characteristics impose on source citation and traceability
Since the data comes from internal non-public party building platforms of enterprises, the traceability link must configure internal authentication mechanisms to prevent unauthorized access and leakage of internal information.
Differing update rhythms across data types require the traceability system to support batch incremental sync. This ensures the latest learning materials and official documents can be retrieved in a timely manner.
The applicable level field included in documents requires traceability results to be linked to the learning scope of corresponding sales stations. This avoids cross-level reference of inapplicable party building content.
Additionally, the document number and issuing unit fields of official documents require traceability displays to include these key identifiers. This aligns with traceability standards for party building work in central and state-owned enterprises.

## How to set the configuration
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | The main text of party building learning documents in the refined oil sales sector is mostly 500–1500 characters long. This setting can fully extract traceability content and avoid truncation and loss of key information |
| `responseData` | Enabled | Full return of source information for party building learning content is required to comply with traceability standards for party building work in central and state-owned enterprises |
| `detail` | Display issuing unit + document number | Party building documents of refined oil sales enterprises usually carry official document numbers. Marking these can clearly trace back to specific issuing entities and official documents |
| Data source sync frequency | Real-time sync (official documents), daily incremental sync (grassroots ledgers) | Different types of party building data have different update rhythms. Matching sync frequencies ensures the timeliness of traceability content |
| Traceability result display limit | Top 3 entries | Party building learning Q&A for gas stations should focus on learning content. Excessive traceability information will disrupt the learning experience, and limiting the number of entries improves readability |

## Three common configuration mistakes
- Symptom: An error occurs when viewing knowledge base citations in chat responses. Cause: Access permissions for internal party building data sources are not configured, resulting in failure to read party building document resources of refined oil sales enterprises during traceability.
- Symptom: A large amount of redundant knowledge base citation content appears in responses. Cause: A reasonable value for `quoteMaxToken` is not set, leading to loading and display of too many non-core traceability entries.
- Symptom: After calling via workflow tools, input and response citations from knowledge base searches still appear in responses. Cause: Automatic display configuration for traceability data is not disabled, and the value of `responseData` is not set correctly.

## How to confirm the configuration is complete
- Initiate a question related to refined oil sales party building, and check if corresponding traceability identifiers such as issuing unit and document number are displayed at the end of the response.
- Adjust the value of `quoteMaxToken`, and verify whether the display completeness and length of traceability content meet the needs of the learning scenario under different values.
- Disable the traceability data display switch, and verify that no additional content related to knowledge base citations appears in responses.
- Simulate an update operation for internal party building data sources, and verify whether newly released party building documents can be normally displayed in traceability results.
