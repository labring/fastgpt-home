# Party Building Learning Q&A for Refined Oil Sales: Document Parsing and Chunking

## What this category of data looks like
The party building learning data for this category comes from the internal document systems of the refined oil sales sector under state-owned and public petroleum and petrochemical enterprises. These documents include quarterly study compilations issued by superior party committees, monthly branch study minutes, gas station position party building knowledge and competency manuals, and monthly party building assessment reports.
Data updates follow a set rhythm: branch study content updates weekly, knowledge and competency question banks update monthly, and assessment standards update quarterly.
Document types cover long PDF compilations, single-page knowledge point cards, and structured assessment tables. Common fields include document title, issuing unit, release date, study theme, knowledge point entries, assessment score, applicable position, and more. Associated units include study hours, scores, and position categories.

## What constraints do these characteristics impose on document parsing and chunking?
The multi-type document structure of party building learning data requires the parsing process to adapt to both long text compilations and short knowledge point cards. It must avoid splitting complete policy paragraphs or single knowledge and competency entries.
Frequently updated data sources need reasonable parsing timeout settings. This prevents task interruptions during batch synchronization.
Structured assessment tables and fielded content require the parsing process to retain original formatting and field associations. Losing these associations will remove key party building learning information such as assessment scores and applicable positions.
Documents from different sources — local files, public links — need adapted parsing rules. This ensures consistency across data sources.

## How to set the configurations
The following configurations follow the parameter rules of FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Adapts to the single-paragraph length of policy passages and position-specific knowledge and competency content in party building learning documents, avoiding splitting complete knowledge points |
| `chunkSplitter` | Split by paragraph + title | Matches the chapter structure of party building documents, retaining the association between study themes and corresponding content |
| `customPdfParse` | Enable structured parsing | Adapts to party building documents containing assessment tables and score fields, retaining original fields and formatting |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Addresses parsing time for quarterly study compilation PDFs with dozens of pages per file, avoiding timeouts during batch synchronization tasks |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Allows uploading batch collections of gas station party building learning materials, adapting to sector-level document synchronization needs |
| `chunkSettingMode` | Manual configuration | Adjusts parameters for different types of party building documents such as long text compilations and short knowledge point cards, adapting to scenario requirements |

## Three common mistakes
- Parsing a publicly shared Yuque link prompts an unrecognized data source error. The cause is failure to confirm the link is a password-free public share. Only Yuque links without access permission restrictions can be directly used as knowledge base data sources.
- After calling a tool to send an HTTP request, parameter parsing completes normally but the corresponding logic does not execute. The cause is incorrect configuration of tool permissions bound to the scenario, or failure to match the rule conditions that trigger the request.
- Imported PDF knowledge base files cannot be opened in the final results. The cause is failure to enable the embedded file preview configuration for `customPdfParse`, or the uploaded PDF file contains encrypted content that cannot be parsed.

## How to confirm the configuration is set correctly
- Upload a typical gas station party building knowledge and competency PDF, check that the parsed chunks retain complete knowledge point entries with no truncation or misalignment.
- Test importing a publicly accessible, password-free Yuque party building document link, confirm that parsing proceeds normally with no error prompts.
- Initiate a tool call for party building learning Q&A, check that parameter transmission and execution results match the preset scenario logic.
- View the parsing results of uploaded Excel assessment files, confirm that fields such as assessment scores and applicable positions are fully retained.
