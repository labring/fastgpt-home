# Party Building Learning Q&A for General Contracting of Housing Construction Projects: Citation Sources and Traceability

## What the data for this category looks like
The data for party building learning Q&A for general contracting of housing construction projects primarily comes from on-site party building ledgers, three meetings and one lesson meeting records, daily party member study files, and party building work standard documents issued by local housing and urban-rural development departments. Project teams adjust data update frequency based on project progress, and synchronize data monthly during a single project cycle. Each document typically includes fields such as project number, branch name, study date, study topic, study duration, list of attendees, original study minutes, and some documents include OCR text extracted from on-site check-in photos.

## What constraints do these characteristics impose on the citation sources and traceability link
The project number and branch name fields in each document require citation traceability to link to the party building dimension identifier of the corresponding project, to avoid cross-project citation confusion. The OCR text from on-site check-in photos requires the traceability link to also mark the original file type and storage path, to ensure traceability of the original voucher. The monthly data synchronization schedule requires the traceability function to synchronously update the knowledge base’s index association relationships, preventing citation of expired data. The list of attendees field included in the document requires the traceability return content to include this metadata, to facilitate on-site party building specialists to verify study participation status.

## Three common misconfigurations
- Phenomenon: The number of citations returned after calling is less than the preset value, or the system prompts token overflow. Cause: The `quoteMaxToken` value is not adjusted according to the length of housing construction party building documents, resulting in truncation of single citation content.
- Phenomenon: Citation sources are displayed as empty, or the original attachment cannot be loaded after clicking. Cause: The configuration item corresponding to `responseData` is not enabled, or the project + branch dimension identifier of housing construction party building documents is not correctly linked.
- Phenomenon: No citation traceability related fields are included in the results returned after API calling. Cause: The display switch corresponding to `detail` is not enabled in the API parameters, or the configured association dimension does not match the document fields.

## How to confirm the configuration is complete
- Initiate a query related to party building, and check whether the returned results include metadata fields such as project number and branch name.
- Click the citation source link in the returned results, and confirm that it can jump to the storage location of the corresponding document or display the original text content.
- Adjust the value of `quoteMaxToken`, and verify whether the length of the returned citation content matches the preset setting.
- Call the API interface, and check whether the returned results include citation source metadata and storage path fields.
