# Party Building Learning Q&A for General Contracting of Housing Construction Projects: Sharing and Embedding

## What this category of data looks like
The data for party building learning Q&A for general contracting of housing construction projects is mainly sourced from internal materials such as party building policy documents, branch study manuals, and party member education courseware released by the party committee of the central state-owned enterprise at the project location and the superior housing and urban-rural development department. The data update frequency is once per month, synchronized with the latest party building deployment. The document structure is mainly structured text, including fields such as topic classification, issuing unit, issuing date, and main body content. The length of a single document mostly ranges from 5000 to 20000 characters. Some policy attachments will include plain text content transcribed from PDF.

## What constraints do these characteristics impose on the "sharing and embedding" link
The monthly update frequency requires the embedded knowledge base synchronization cycle to match the update frequency, otherwise the Q&A content will not cover the latest party building requirements. The relatively long length of a single document will lead to high context window usage. When sharing and embedding, it is necessary to properly set the length threshold for context recall to avoid front-end loading timeouts or content truncation. Party building study materials are internal sensitive content, so sharing and embedding must be paired with permission verification. Direct public network access is not allowed, and login verification must be combined with the enterprise's own identity system. The documents include metadata fields, so the embedded Q&A interface must reserve space for displaying metadata to ensure that the authority and timeliness of Q&A content can be traced.

## Three Common Misconfigurations
- Symptom: After embedding in a Vue3 project, the page fails to load the Q&A component normally, and the console reports a cross-origin error. Cause: The project domain name was not added to the allowed cross-origin list in the FastGPT backend, causing the browser to block the cross-origin request.
- Symptom: When calling the share link to obtain historical conversations, the returned result is empty. Cause: The corresponding knowledge base was not bound via `shareId`, or the historical conversation storage duration was set too short, resulting in conversation data not being correctly retained.
- Symptom: The conversation icon on the embedded page displays the default style and cannot be replaced with the enterprise party building logo. Cause: The custom icon file was not uploaded in the embedding configuration, or the icon format does not meet platform requirements.
