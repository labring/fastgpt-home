## Constraints for Conversation Logs and Auditing
Structured storage of official party building policies and industry cases requires conversation logs to fully record user questions, AI-generated responses, cited document fragments, and corresponding document metadata.

## Three Common Misconfigurations
- Phenomenon: Conversation logs do not display cited new energy party building document fragments. Cause: Full log configuration `detail` is not enabled, and only basic session information is recorded.
- Phenomenon: Audit exported logs lack the `responseChatItemId` field, making it impossible to accurately locate the generation context of a single AI reply. Cause: The reply node ID association option is not configured, so logs are not bound with a unique reply identifier.
- Phenomenon: FastGPT running logs cannot be viewed after Docker deployment. Cause: The container's internal log directory is not mounted to the specified host path, so logs are only stored inside the container and cannot be accessed externally.
