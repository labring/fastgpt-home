# Party Building Learning Q&A for Non-Ferrous Metal Smelting: Document Parsing and Chunking

## What the data for this category looks like
Data related to party building learning in the non-ferrous metal smelting field mainly comes from internal party committee-issued study manuals, monthly meeting minutes, party member training slides, and quarterly assessment statistics tables.
Study materials are updated monthly. Assessment and attendance data are updated quarterly.
Document formats include Word study manuals with 100,000 Chinese characters per file, and Excel party member study statistics tables with over 15,000 rows.
Fields include study topic, attendees, study duration, assessment scores, and units such as hours, person-times, and scores.

## What constraints these characteristics impose on document parsing and chunking
The long documents and multi-row Excel tables associated with non-ferrous metal smelting party building data create multiple constraints for the document parsing and chunking process.
Single Word documents with 100,000 Chinese characters exceed standard parsing thresholds, causing timeout failures.
15,000+ row Excel tables, if split via default rules, lose semantic association between their rows and columns.
Fixed title hierarchies and quote formats used in party building documents require retaining context integrity during chunking, to avoid semantic breaks from improper splitting.
Additionally, some older scanned study materials require preservation of original layout information, creating additional parsing requirements.

## How to set the configurations
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Aligns with semantic units of party building documents, avoids splitting that breaks quotes or meeting content integrity |
| `chunkSplitter` | Split by paragraph + title hierarchy | Matches fixed title structures of party building documents, retains context associations |
| `customPdfParse` | Enabled | Processes scanned or complex-format party building study manuals, preserves original layout and title information |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Meets upload requirements for single Word documents with 100,000 Chinese characters |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Prevents timeout failures during long document parsing |
| `chunkSettingMode` | Manual mode | Enables custom chunking rules for special structures of party building documents, adapts to mixed-format study materials |

## Three common errors
- Phenomenon: After uploading a 100,000 Chinese character Word party building document, the parsing status shows timeout failure, and the chunking result is incomplete. Cause: `PARSE_FILE_TIMEOUT_SECONDS` is not adjusted to a reasonable duration, and long document parsing is terminated before completion.
- Phenomenon: After importing a 15,000+ row Excel party member study data sheet, each row appears as a separate chunk in the chunking result, and statistical information from the same batch cannot be associated. Cause: The `chunkSplitter` rule set to split by paragraph + title hierarchy is not selected, and default character-based splitting breaks the row-column association of the table.
- Phenomenon: After repeatedly clicking retry, the vectorization exception issue for some chunks only returns to normal. Cause: Adaptation parameters for `UPLOAD_FILE_MAX_SIZE` and `PARSE_FILE_TIMEOUT_SECONDS` are not configured, and occasional resource shortage issues during long document parsing can only be temporarily resolved via manual retries.

## How to confirm configurations are set correctly
- Upload a single Word party building document with 100,000 Chinese characters, check if the parsing completion time falls within the duration set by `PARSE_FILE_TIMEOUT_SECONDS`.
- Import a 15,000+ row Excel party building statistics table, check if the chunking result retains the semantic association of row and column data, and no single row or column appears as a separate chunk.
- Manually adjust the `chunkSize` parameter, verify if the chunked content completely retains complete paragraphs of party building quotes or meeting minutes.
- After enabling `customPdfParse`, upload a scanned party building study manual, check if the parsing result retains original title and layout information.
