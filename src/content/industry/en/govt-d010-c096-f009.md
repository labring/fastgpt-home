# Party Building Learning Q&A for Non-Ferrous Metal Smelting: Model Integration and Configuration

## What This Use Case’s Data Looks Like
Party building learning data for the non-ferrous metal smelting field mainly comes from party building ledgers from enterprise party committee offices, monthly party member learning courseware, and party building special materials combined with smelting safety production. Regular learning materials are updated monthly. Party committee meeting minutes and industry party building guidance documents are updated quarterly.

Documents are mostly multi-chapter formal texts, with fields including release date, affiliated party branch, learning topic, and supporting production requirements. They are measured in units of "pieces", "copies", and "times". Some documents include policy interpretations combined with smelting technical terms.

## Constraints Imposed by These Characteristics on Model Integration and Configuration
Data sources are scattered across multiple departments. Configure multi-data source synchronization rules to unify access to party building materials.
Documents are generally long and combine smelting technical terms with party building policies. Use a model with a sufficiently large context window to avoid truncating key information.
Update frequencies are not fixed. Support regular incremental synchronization to adapt to material updates across different cycles.
The state-owned enterprise and public institution attribute requires secure storage of API keys and access control to prevent leakage of sensitive party building data.
These characteristics directly determine the parameter adjustment direction and security configuration requirements during model integration.

## How to Configure Settings
| Configuration Item | Recommended Value Range | Rationale |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | Addresses the characteristics of long party building documents for smelting with multi-chapter content, avoiding truncation of key learning points |
| `temperature` | 0.1–0.3 | Maintains the rigor of party building Q&A, avoiding generated content that deviates from official documents |
| `quoteMaxToken` | 1500–2000 characters | Ensures that quoted fragments of party building documents are complete, covering specific party building requirements related to smelting production |
| `toolChoice` | auto | Allows the model to independently choose whether to call tools to supplement the latest party building policy content |
| `AIPROXY_API_TOKEN` | Bind enterprise-specific keys | Complies with data confidentiality requirements for state-owned enterprises and public institutions, preventing key leakage |
| `AIPROXY_API_ENDPOINT` | Fill in the exclusive access address of Alibaba Cloud Tongyi Qianwen | Adapts to the calling requirements of the qwen-max model |

## Three Common Configuration Mistakes
- Phenomenon: The party building Q&A results returned by the model do not reference the uploaded party building documents combined with smelting content. Cause: The `maxContext` parameter is set too small, causing long documents to be truncated, so key learning points combining smelting and party building cannot be obtained by the model.
- Phenomenon: When configuring the qwen-max model in non-tool call mode, network search is not triggered, while the search node runs normally. Cause: The `toolChoice` parameter is set to none, which forcibly turns off tool call permissions, preventing the model from calling the search node to obtain external party building policy content.
- Phenomenon: Vector training is triggered only when a single file is uploaded, and batch-uploaded party building documents do not update the vector database. Cause: No batch synchronization trigger mechanism is configured, only the rule that triggers training when a single file is uploaded is enabled.

## How to Confirm Configuration Is Complete
Upload a party building special document related to smelting safety production, launch a targeted Q&A, and check whether the returned result accurately references specific clauses in the document.
Launch a party building policy Q&A that requires network search, confirm that the model can normally trigger and return results from the search node.
Batch upload multiple party building learning documents, wait for the preset synchronization cycle, and check that there are no vector training error records in the system backend.
View the API configuration page of FastGPT v4.17.0, confirm that `AIPROXY_API_TOKEN` and `AIPROXY_API_ENDPOINT` are consistent with the official access configuration of Alibaba Cloud qwen-max.
