# Party Building Learning Q&A for Civil Aviation Airports: Knowledge Base Retrieval and Recall

## What the Data for This Use Case Looks Like
The data for civil aviation airport party building learning Q&A mainly comes from the airport's internal party building archive library, party building guidance documents issued by the Civil Aviation Administration, records of three meetings and one lesson from various party branches, and party member study reflection documents. The data update rhythm is monthly synchronization of new official notices, and quarterly updates of annual party building summary materials. Most documents are in PDF or Word format. Their structure includes topic titles, main body paragraphs, issuing units and dates. Fields include document number, topic category, and release channel. Statistical units are "articles" and "copies". The length of a single document mostly falls within the range of 500 to 5000 characters.

## Constraints on the Retrieval and Recall Link
The characteristics of the civil aviation airport party building learning Q&A data impose clear constraints on the retrieval and recall link. Documents include structured fields such as topic category and issuing unit, which requires the retrieval pipeline to support filtering recall results by category dimensions, narrowing the matching scope and preventing irrelevant content from being mixed in. Official documents account for a high proportion and have long paragraphs, which requires preserving complete policy expression logic during segmentation, avoiding splitting that breaks context association and affecting answer accuracy. There are many exclusive party building terms, which requires prioritizing matching domain-specific vocabulary during recall to reduce semantic ambiguity. Data is updated with new content monthly, which requires the retrieval system to support scheduled incremental updates to ensure the timeliness and accuracy of recalled content.

## How to Set Up Configurations
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Meets the precision requirement for matching civil aviation party building exclusive terms, avoiding recall of irrelevant general party building content |
| `limit` | Top 8 entries | Civil aviation party building documents have concentrated topics; too many results increase the burden of context stitching |
| `searchMode` | Hybrid Retrieval | Balances keyword matching and semantic matching to cover recall needs for terms and context association |
| `usingReRank` | Enabled | Performs secondary sorting of initial recall results by semantic relevance to correct deviations from single-mode retrieval |
| `datasetSearchUsingExtensionQuery` | Enabled | Optimizes retrieval queries for exclusive civil aviation party building terms to improve recall precision |
| `collectionIds` | Bind to exclusive airport party building collection ID | Restrict retrieval scope to only internal airport party building documents, preventing cross-category content from being included |

## Three Common Misconfigurations
- Phenomenon: Search test returns no results, and the interface shows no matching content. Cause: The `collectionIds` are not bound to the exclusive airport party building collection, so the retrieval scope covers irrelevant document libraries.
- Phenomenon: Hybrid retrieval takes more than 10 seconds, and the first call times out. Cause: The number of recalled entries specified by `limit` is not restricted, and the lightweight re-ranking mode of `usingReRank` is not enabled, leading to too many candidate results participating in calculations.
- Phenomenon: The answer does not call knowledge base content, and general expressions unrelated to party building topics appear. Cause: The `similarity` threshold is set too low, resulting in recall of non-party building general documents, or `datasetSearchUsingExtensionQuery` is not enabled, so the retrieval query fails to match domain terms.

## How to Confirm Configurations Are Properly Set
- Access the knowledge base retrieval test page, enter exclusive civil aviation party building terms, and check whether the recalled results only include airport party building related documents.
- Enable hybrid retrieval and re-ranking functions, and check whether the single retrieval time meets the preset threshold range for the business.
- Check whether the collection ID in the retrieval configuration matches the exclusive airport party building dataset to avoid cross-library retrieval.
- Adjust the `similarity` threshold, and verify whether the matching degree of retrieval results in different scenarios meets the preset standards.
