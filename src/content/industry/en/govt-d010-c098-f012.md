# Party Building Learning Q&A for Civil Aviation Airports: Deployment and Upgrade

## What the data for this category looks like
Party building learning Q&A data for civil aviation airports primarily comes from official party building documents issued by the airport party committee office, quarterly learning plans, theme education courseware, and unified deployment materials from superior party organizations.
Data updates align with arrangements from superior party building work, with no fixed cycle. Updates are triggered immediately when new policies or learning tasks are released.
Most individual documents follow a structured format, including file title, release date, applicable departments, and main content. Some documents include attached audio or PPT files. Fields include document number, topic classification, and audience level. Audio materials include duration units.

## Constraints imposed on deployment and upgrade
Party building data consists of official internal sensitive materials. When deploying FastGPT v4.17.0, a permission verification module must be configured to restrict knowledge base editing to internal operations and party affairs personnel only.
Data updates have no fixed cycle. A manually triggerable synchronization script must be set up, and interface configuration for automatically pulling data from superior platforms must be reserved.
For structured data with multi-department audiences, knowledge base permissions must be divided by department to prevent cross-department access to sensitive content.
Supporting audio materials must be compatible with speech recognition interfaces. During deployment, storage paths and transcription parameters must be configured in advance to adapt to the airport's internal network environment.

## How to configure parameters
| Config Item | Suggested Setting | Rationale |
|---|---|---|
| `PG_URL` | Connection address of the internal PostgreSQL instance at the airport, in the format `postgresql://username:password@host:5432/fastgpt` | Party building data must be stored in an internal database to ensure data security and compliance |
| `REDIS_URL` | Address of the internal Redis cache instance at the airport; set the maximum connection pool size to 20–30, and set the session expiration time to 900 seconds | Cache conversation logs and permission verification data to adapt to internal concurrent access volume at the airport |
| `STORAGE_S3_ENDPOINT` | Endpoint address of the internal object storage at the airport, such as `http://10.0.0.5:9000` | Store party building documents and audio materials to avoid security risks from external network access |
| `DB_MAX_LINK` | 20–30 | Match the internal concurrent access scale of the airport to avoid exhausting database connections |
| `FILE_TOKEN_KEY` | Randomly generated 32-character string key | Encrypt file download links to prevent unauthorized access to sensitive party building materials |
| `ROOT_KEY` | Only configured for designated party affairs operation personnel, not stored publicly | Control the highest platform permissions to prevent unauthorized operations and data leaks |

## Three common errors
-  Conversation logs appear empty or return a 404 status code. `REDIS_URL` is not configured, or connection parameters are incorrect, preventing session cache from storing and reading properly.
-  A connection timeout occurs after submitting a party building audio transcription request. The speech recognition interface is not set to an address accessible via the airport internal network, or network permissions for the corresponding port are not enabled.
-  Party building knowledge base files cannot be updated after deployment. `PG_URL` is not configured correctly, or database write permissions are insufficient, preventing knowledge base metadata from synchronizing.

## How to confirm successful configuration
-  Access the frontend address corresponding to `FE_DOMAIN`, log in, and view the knowledge base list to confirm all imported party building documents and audio materials display normally.
-  Run the database connection test script to verify the connection status of `PG_URL` and `REDIS_URL`, and confirm there are no timeout or permission error messages.
-  Submit a test party building-related question, obtain the answer, and check if the conversation log is generated normally and can be queried.
-  Attempt to upload a test party building document, confirm the file storage path matches the `STORAGE_S3_ENDPOINT` configuration, and confirm no upload failure prompts appear.
