# Port Shipping Party Building Study Q&A: Sharing and Embedding
Reference only; verify against the target FastGPT release and deployment documentation.

## What the data for this category looks like
Data for port shipping party building study Q&A comes from internal party building knowledge bases of port enterprise party and mass work departments. It includes study documents issued by superior party committees, daily branch study records, party member training slides, party building activity records, and similar content.
Update rhythm flexibly adjusts with superior party building work tasks. Temporary study tasks can be quickly added to the repository after issuance.
Each document is an independent single study material, with fields including topic, release time, applicable positions, main content, supporting thought questions, and more. Most fields are text-based. Some materials mark position adaptation scopes, and there are no complex numerical units.

## What constraints these characteristics impose on sharing and embedding
The internal knowledge base is only accessible to port internal employees. Sharing links must be configured with identity authentication to prevent external irrelevant personnel from accessing party building study content.
Documents include position adaptation fields. Embedded Q&A must support matching corresponding study materials based on a visitor’s position information, to avoid pushing non-adapted content.
Update rhythm flexibly adjusts with party building tasks. Embedded components must support regular synchronization of the latest knowledge base content, to ensure Q&A uses the most recent study materials.
Some documents include supporting thought questions. Embedding must include a configuration option to display or hide supporting content, to ensure complete coverage of the study process.
Most ports are deployed in intranet environments. Embedded components must adapt to intranet cross-domain rules, to avoid failed loading.

## How to set configurations
| Config Item | Recommended Value | Rationale |
| --- | --- | --- |
| Sharing link authentication method | Enable enterprise identity verification and bind internal accounts | Port party building content is only accessible to internal employees, prevent external access |
| Automatic synchronization frequency | Once every 12 hours | Adapt to the flexible update rhythm of party building tasks, balance timeliness and resource consumption |
| Mobile adaptation switch | Enable | Cover the mobile study scenario of port employees |
| Custom avatar configuration | Upload the avatar designated by the port party and mass work department | Unify brand visual image for party building study scenarios |
| `shareId` | Fill in the exclusive ID of the port party building knowledge base | Lock Q&A data for the corresponding knowledge base, avoid confusion with content from other scenarios |
| iframe embedding cross-domain configuration | Add intranet and cooperating unit domain names to the whitelist | Adapt to port intranet deployment and embedding requirements of external cooperating parties |

## Three Common Mistakes
- Phenomenon: The embedded chatbot automatically logs out after background login, with a 401 status code returned. Cause: No iframe embedded cross-domain identity transfer parameters are configured, causing session state to fail to synchronize.
- Phenomenon: No identity authentication option appears when configuring sharing links, unable to enable employee identity verification. Cause: The advanced configuration menu in the knowledge base sharing settings page is not expanded, as authentication options are collapsed by default.
- Phenomenon: AI and user avatars in the Q&A interface are not replaced with the specified styles, and default avatars are displayed. Cause: Required image files are not uploaded, or configuration items are not saved to take effect.

## How to Confirm Configuration Is Complete
- Open the sharing link, verify whether internal account password input is required, to confirm authentication configuration takes effect.
- Access the mobile page of the embedded component, verify that interaction logic and interface layout adapt to the current screen size.
- Check whether avatars in the Q&A interface match the preset port party building exclusive avatars, to confirm custom configuration takes effect.
- Wait for the automatic synchronization cycle to end, check whether the Q&A returns the latest party building study materials, to confirm synchronization configuration takes effect.
