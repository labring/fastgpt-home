# Coal-Electric Integration Party Building Learning Q&A: Source Citation and Traceability
This document is written based on FastGPT v4.17.0.

## What this category of data looks like
Party building learning data for coal-electric integration enterprises mainly comes from internal party building archives, central group learning materials, branch meeting minutes, and special theme education materials. The data update rhythm adjusts synchronously with enterprise party building work arrangements and the release of new policy documents. Most documents are paragraph-long texts, with a structure that includes document title, issuing unit, release date, and main body content. Fields cover document number, topic classification, affiliated branch, and more. Units of measurement are based on pieces and characters.

## What constraints do these characteristics impose on the "source citation and traceability" link
The long-text structure of party building documents may cause individual content blocks to exceed the preset citation length. This requires the traceability link to adapt to non-standard block lengths and avoid truncating key expressions. Multi-dimensional metadata fields require that citations carry information such as issuing unit and date simultaneously to ensure traceability accuracy. The irregular update rhythm requires the knowledge base synchronization mechanism to match the release cycle of party building documents, preventing outdated content from being cited. Additionally, the classification attributes of internal documents require the traceability link to filter results by dimensions such as branch and topic, narrowing the search scope.

## How to configure
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1200–1800 token | Matches the average length of individual blocks in coal-electric integration party building documents, avoiding individual blocks exceeding the citation upper limit |
| Metadata carrying | Enable document title, release date, affiliated branch fields | Meet the needs of accurate positioning during traceability, and align with the management logic of party building documents |
| `responseData` | Include original text fragments and metadata | Ensure that the returned citation content can be directly used for traceability display |
| `detail` | Enable complete fragment display | Retain the original text context to facilitate verification of the accuracy of cited content |
| Single search limit | Top 3 entries | Focus on core party building learning materials, avoiding redundant results from interfering |
| Synchronization cycle | Calibrate according to the release rhythm of party building documents | Match the data update frequency and ensure the timeliness of cited content |

## Three Common Misconfigurations
- Phenomenon: After setting `quoteMaxToken` to 1500 tokens, document blocks in the knowledge base that exceed this length are still cited. Reason: No forced splitting of ultra-long document blocks is performed, and only the original block length is used to verify the citation upper limit.
- Phenomenon: After the knowledge base retrieval is completed in the workflow, the AI conversation only returns citation identifiers without specific content. Reason: The `responseData` configuration is not enabled, and the original text fragment data is not carried.
- Phenomenon: After creating a plugin and referencing it in the workflow with code running, an error occurs in the input box. Reason: The input and output formats of the plugin are not correctly configured, and the citation data structure required for AI conversation is not matched.

## How to Confirm Configuration Is Complete
- Upload a party building document with complete metadata, trigger Q&A and check the returned citation content to confirm that it includes metadata fields such as document title, release date, and affiliated branch.
- Adjust `quoteMaxToken` to 1000 tokens, upload a party building document that exceeds this length, and verify whether ultra-long blocks are correctly split or filtered.
- Run a test workflow to confirm that after the knowledge base retrieval results are passed to the AI conversation, the returned citation format meets the preset requirements.
- Check the knowledge base synchronization log to confirm that the update frequency of party building documents matches the configured synchronization cycle.
