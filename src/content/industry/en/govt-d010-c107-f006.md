# Party Building Learning Q&A for Coal Mine Production: Source Citation and Traceability

## What this type of data looks like
Party building learning Q&A data in coal mine production scenarios mainly comes from internal party building documents issued by the enterprise’s party committee, party lesson courseware, branch study records, themed education materials, and similar resources. Data updates follow a monthly basic cycle, with new content added alongside new policy requirements and quarterly party building activity summaries. Individual documents are mostly structured text, containing fields such as title, publishing entity, theme classification, and main body content. The primary file formats are PDF and Word. The character count of individual documents varies widely, with some study manuals reaching tens of thousands of characters.

## What constraints do these characteristics impose on source citation and traceability
The publishing entities of internal party building materials are clearly defined, so traceability requires associating results with specific branches or party committee departments. Publishing unit information must therefore be retained in citation fields. The data update cycle is fixed, so corresponding mechanisms must be configured to avoid citing outdated old study materials. The character count of individual documents varies widely; long documents need to be split appropriately to ensure the accuracy of cited fragments, while avoiding loss of contextual connections after splitting. Some materials are for internal use only, so additional access permission verification is required during traceability to ensure cited content is only visible to authorized personnel.

## How to configure the settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Meets the full citation needs of policy original texts and key party lesson points in coal mine party building materials, avoiding truncation of critical expressions |
| `responseData` | Includes publishing unit, publishing date | Meets entity and timeliness verification requirements for state-owned enterprise party building archive traceability |
| `detail` | Enabled | Displays the contextual content of cited fragments to assist in confirming matching accuracy |
| Citation display limit | Top 3 entries | Focuses on core reference materials, avoiding excessive entries that distract from study focus |
| Permission verification switch | Enabled based on document publishing scope | Adapts to hierarchical access requirements for internal party building materials in coal mines, preventing leakage of confidential content |

## Three common configuration errors
- Phenomenon: A large number of irrelevant cited document lists are attached at the bottom of generated responses. Cause: The number of displayed citations is not limited, and all recalled party building materials are displayed as traceability entries.
- Phenomenon: In multi-turn dialogue scenarios, traceability results are not associated with the previous round of party building study content. Cause: The traceability association logic for multi-turn context is not configured, so traceability for each query is only based on the current question, and no citation association from historical conversations is retained.
- Phenomenon: The publishing entity or publishing time of party building materials is not displayed in traceability results. Cause: The metadata fields to be included are not specified in the `responseData` configuration, so corresponding traceability information cannot be extracted.

## How to confirm the configuration is correctly set up
- Initiate a query about party building policies or party lesson content, check the number of traceability entries at the bottom of the response, and confirm it matches the preset display limit.
- Select any traceability entry, check whether it includes metadata such as publishing unit and publishing date, and confirm that the `responseData` configuration is active.
- Test a query referencing long sections of party building materials, confirm that cited fragments are not truncated, and verify that the `quoteMaxToken` value is appropriate.
- Attempt to run a query for restricted-scope party building materials, confirm that unauthorized users cannot obtain corresponding traceability information, and verify that the permission verification configuration is active.
