# Party Building Learning Q&A for Coal Mine Production: Model Access and Configuration

## What Data for This Category Looks Like
Party building learning data for coal mine production mainly comes from internal enterprise party building archives, pre-shift meeting learning records, monthly safety and party building ledgers, and special study notices issued by superior party organizations. Data update rhythms cover daily and scheduled updates: pre-shift meeting records are updated daily, monthly ledgers are updated monthly, and special notices are released as needed. Document types include PDF learning courseware, TXT learning notes, and structured table-style check-in and assessment records. Fields include learning topic, learning time, number of participants, learning content summary, and assessment results. Units include "person", "hour", and "occurrence".

## What Constraints These Characteristics Impose on Model Access and Configuration
Mixed multi-format data requires model access configuration to adapt to parsing rules for PDF, TXT, and structured tables, to prevent field extraction errors. Exclusive party building terms such as "dual-base construction" and "pre-shift meeting clean government reminder" related to coal mine safety and party building require the model context to retain sufficient association scope, to ensure Q&A content conforms to official expressions. Frequently updated pre-shift meeting records require configuring an on-demand triggered index refresh mechanism to maintain data timeliness. Long-text quarterly party building summaries require adjusting parameter settings for context window and output length, to avoid content truncation.

## Three Common Misconfigurations
- Symptom: The model icon in the workflow fails to display normally, and a network error prompt appears when uploading party building-related documents. Cause: `AIPROXY_API_ENDPOINT` is not correctly configured to point to the local MinerU service, or the MinerU service port is not open to the FastGPT deployment environment.
- Symptom: Unable to create an index model channel for party building documents. Cause: `AIPROXY_API_TOKEN` is not configured in the FastGPT system settings, resulting in parsing service authentication failure and inability to complete index creation.
- Symptom: Generated party building Q&A content deviates from coal mine exclusive terms, or long document summarization is truncated. Cause: The value of `maxContext` is too low, failing to retain sufficient context association scope, or the `maxTokens` setting is insufficient, resulting in output truncation.
