# Party Building Learning Q&A for Mining and Mineral Processing: Document Parsing and Chunking

## What Data for This Category Looks Like
Party building learning data in the mining and mineral processing sector comes from internal learning materials archived by enterprise party committee offices, party building guidance documents issued by superior state-owned assets supervision departments, and regularly compiled party member study manuals. Updates follow a quarterly schedule, with new policy interpretations and study points updated alongside quarterly work arrangements. Most documents are in Word or PDF format, with some being scanned copies. The core structure includes three types of content: chapter titles, main body paragraphs, and study requirements. Fields include document number, issuing unit, and effective date. Statistical units are "piece" and "volume".

## What Constraints Do These Characteristics Impose on Document Parsing and Chunking
Party building learning materials in the mining and mineral processing sector come from dispersed sources. They include both standard format documents issued by superior departments and self-compiled study materials created by enterprises. Format differences can cause text extraction errors during parsing. Regularly updated batch documents require parsing processes to be reusable, to avoid repeated configuration adjustments. Documents contain party building professional terms related to mine safety. Context association must be retained during chunking to prevent term splitting that damages semantic integrity. Some documents are scanned copies, requiring additional OCR processing steps. This increases time requirements for the parsing link, so longer timeout thresholds need to be adapted.

## How to Configure the Settings
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Mining party building materials mostly contain long paragraphs and professional terms. This range avoids semantic fragmentation caused by overly short chunks, while ensuring retrieval accuracy |
| `chunkSplitter` | Split by paragraph + title | Party building materials have clear chapter titles and paragraph structures. This splitting method preserves semantic integrity |
| `customPdfParse` | Enabled | Some party building materials are scanned copies or PDFs with complex layouts. Enabling custom parsing can extract complete text and layout information |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Compiled party building study files from mining enterprises may include multiple integrated documents, so single file size is usually large |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Parsing large PDF or scanned copy documents takes a long time. This threshold prevents routine parsing tasks from being interrupted by timeout |
| `chunkSettingMode` | Manual configuration | Adjustment of chunking rules for professional terms and structures of mining party building materials is required to meet scenario-specific needs |

## Three Common Misconfigurations
- Phenomenon: The references field is empty after parsing. Cause: The associated information extraction configuration for custom parsing is not enabled, and no adaptation is made for the reference format of party building materials.
- Phenomenon: After locally deploying pdf-marker, there is no parsing option when uploading PDFs to the FastGPT knowledge base. Cause: The service port of pdf-marker is not connected to the FastGPT container network, or the custom parsing service address is not specified in the FastGPT configuration.
- Phenomenon: The number of chunking results does not meet expectations. Cause: The `chunkSize` parameter is not adjusted, and the default general chunk length is used, resulting in excessive splitting of long chapters in party building materials.

## How to Confirm the Configuration Is Correct
- Upload a standard mining party building PDF document, and check whether the parsed text contains complete chapter titles and paragraph content.
- Enter the FastGPT knowledge base configuration page, and check whether parameters such as `chunkSize` and `chunkSplitter` match the preset configuration.
- Upload a party building compiled file larger than 500 MB, and confirm that the parsing task does not trigger a timeout error.
- Test calling the parsing interface, and verify that the returned chunk data contains correct semantic units without obvious semantic fragmentation.
