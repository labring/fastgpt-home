# Party Building Learning Q&A for Shipbuilding: Source Citation and Traceability
This scenario's configuration instructions are based on FastGPT v4.17.0.

## What the data for this category looks like
Party building learning materials in the shipbuilding sector mainly come from official documents issued by higher-level party committees, internal party building activity records of shipyards, and special learning materials for industry party building co-construction. Materials are updated without a fixed cycle: regular content is updated monthly alongside party committee deployments, and temporary supplementary materials are added during major party building activities or production milestones. Document structure uniformly includes title, issuing unit, release date, and main body content. Some materials related to specific docks, ship types, or production nodes will additionally include a linked production number field. No additional statistical numerical fields are included.

## What constraints do these characteristics impose on the "source citation and traceability" link
Party building materials in the shipbuilding sector impose three constraints on the traceability link. First, some materials are linked to specific production nodes. Traceability must retain fields such as linked production numbers, otherwise the corresponding party building activity scenario cannot be accurately located. Second, materials are updated without a fixed cycle. Incremental synchronization triggered on demand must be supported to avoid missing temporarily added special learning content. Third, some materials involve internal production scenarios. Traceability links must distinguish between internal and public access permissions to ensure that visitors with different permissions can obtain corresponding compliant source information.

## How to set the configurations
| Configuration Item | Recommended Value Range | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | The core content of a single paragraph of shipbuilding party building documents mostly falls within the 500-1000 token range. This value range can fully reference a single valid segment of content |
| `responseData` | Full metadata | Must include fields such as issuing unit, release date, and linked production node to meet accurate traceability requirements |
| `detail` | Enabled | Must display context snippets of cited content to help verify matching accuracy |
| Source field filtering | Retain shipbuilding-related tags | Filter out non-shipbuilding party building materials to avoid returning irrelevant content |
| Synchronization trigger rules | Daily 00:00 scheduled trigger + manual trigger | Adapt to the feature that party building materials have no fixed update cycle, covering regular updates and temporary supplements |
| Traceability link generation rules | Generate corresponding links according to document permissions | Distinguish between internal and public access link formats to ensure traceability links can be accessed normally |

## Three common mistakes
- Phenomenon: The cited content returned after initiating a question does not carry information about linked production nodes. The cause is that the corresponding metadata field was not configured to be retained.
- Phenomenon: After entering a Chinese question, non-shipbuilding party building materials are returned. The cause is that the source field filtering function was not enabled, and irrelevant tags were not filtered out.
- Phenomenon: Internal document links in Notion format cannot be recognized when configuring source links. The cause is that Notion private links were not converted to a publicly accessible format supported by FastGPT.

## How to confirm the configuration is complete
- Initiate a question that includes "a certain dock's pioneer post establishment for party members". Check if the returned result includes metadata such as issuing unit, release date, and linked dock number.
- Upload a newly added shipbuilding party building learning document, initiate a question related to the corresponding topic, and confirm that the new content is correctly retrieved and includes complete traceability information.
- Adjust the value of `quoteMaxToken`, check if the length of the returned citation snippet matches the configured value range.
- Check the traceability link of each citation result, confirm that the source document can be accessed normally under the corresponding permissions.

The values provided here are common starting points and should be measured against the reader's own samples.
