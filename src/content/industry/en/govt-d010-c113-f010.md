# Party Building Learning Q&A for Shipbuilding: Knowledge Base Retrieval and Recall

## What this category of data looks like
Shipbuilding industry party building learning Q&A data mainly comes from party building documents issued by the enterprise party committee, learning ledgers of each branch workshop party branch, annual learning files of party members, and latest instructions and requirements from superior party committees. The data update rhythm is synchronizing branch learning updates monthly, and updating superior party building policy documents quarterly. Most documents are in doc or docx format, with clear section titles and body paragraphs as their structure. Fields include the branch the file belongs to, upload time, original content, and section hierarchy information, with no additional custom unit fields.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Shipbuilding party building content is mostly normative text, requiring filtering of low-relevance generalized expressions to retain accurately matched knowledge points |

## Three common mistakes
- Phenomenon: The doc/docx document content returned by RAG retrieval does not correctly carry the corresponding section title, or the section title does not match the body paragraph. Cause: The recall configuration associated with the document structure is not enabled, resulting in the parsed section hierarchy information not being included in the retrieval index.
- Phenomenon: The AI-generated party building learning Q&A content exceeds the scope of the knowledge base and includes expressions not included in the knowledge base. Cause: The dataset scope limitation is not enabled, or the external generation switch is not turned off, causing the model to call non-knowledge base data sources.
- Phenomenon: The doc/docx files uploaded to the knowledge base cannot be downloaded directly, and can only be obtained by clicking "View Original Content" to jump to a fixed address. Cause: No dedicated download entry is configured, and currently only the jump link to the original content is open, with the address format being the http://fastgpt/ewchat/api/com related path.

## How to confirm the configuration is correct
- Upload a doc format party building document with clear section titles, initiate a retrieval request for the corresponding section, and check whether the recall result carries the section title information.
- Limit the dataset scope of a specified branch, initiate a retrieval for a party building question across branches, and check whether the results only return document content within that branch's scope.
- Upload a test file, check whether there is a direct download entry on the interface, or whether the jump link to the original content conforms to the expected format.
- Initiate a party building question query that exceeds the knowledge base scope, and check whether the AI prompts that it cannot answer or only responds based on the knowledge base content.
