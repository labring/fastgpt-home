# Party Building Learning Q&A for Shipbuilding: Forms and Interactions

## What data for this category looks like
Party building learning data for the shipbuilding sector comes from three main sources: internal enterprise party building ledgers, monthly branch study records, and party building standard documents released by industry authorities. Update frequency follows two rhythms: branch study records are updated monthly, while industry standards are synced quarterly.

Each document is organized by branch. It includes fields such as study topic, participants, study duration, assessment points, and full relevant policy text. Standard units are hours, person-times, and pages. Most documents use structured Markdown format.

## Constraints imposed on forms and interactions
Structured fields like branch and study topic require forms to support dropdown selection with preset options. This prevents inconsistent formatting from free text entry.

Fields with units, such as study duration and number of participants, need interactions that restrict input to numbers plus matching units. This reduces manual verification work.

When linking to party building ledger data, forms must automatically pull archived branch lists and policy file names. This avoids duplicate data entry.

Additionally, data updates happen frequently. The interaction flow must support real-time sync of the latest party building learning data. This ensures form options match actual ledgers.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` component | Restrict input to numbers plus units | Corresponds to fields with units such as study duration and number of participants, aligns with the field specifications for shipbuilding party building data |
| `userSelect` component | Preset branch list, automatically pull party building ledgers | Matches the organizational structure of branches in shipbuilding enterprises, avoids manual entry errors |
| Context length | 800–1200 characters | Adapts to the average length of single party building study documents, ensures complete loading of study content during interactions |
| Single submission limit | First 5 entries | Controls the number of party building study records submitted per form, aligns with the standard monthly submission volume for branch studies |
| Submission verification rules | Verify field format and value range | Ensures fields such as study duration and number of participants comply with preset units and reasonable values |
| Data synchronization interval | 24 hours | Matches the update rhythm of branch study records, ensures form options always sync with the latest ledger data |

## Three common configuration errors
- When configuring the `userSelect` component, the branch dropdown list is empty. This occurs because the data source for internal enterprise party building ledgers is not linked, so preset options cannot load automatically.
- After form submission, a prompt indicating no knowledge base selected appears, but the function works normally in debug preview. This occurs because the production environment’s knowledge base binding configuration differs from the debug environment, and the production environment party building knowledge base was not synced.
- Returned party building learning Q&A results force display of cited content, and the setting cannot be disabled via configuration. This occurs after the FastGPT v4.17.0 version update, where the default citation switch status changed, and the corresponding configuration was not adjusted.

## How to confirm configurations are complete
- Navigate to the form configuration page. Confirm the `userSelect` component’s data source is bound to the enterprise party building ledger, and that branch names load normally in the dropdown list.
- Submit a test entry that follows the required format. Check that interaction return results only pull content from the configured party building knowledge base.
- Adjust the citation display configuration setting. Run a test interaction, then confirm results show or hide cited content as specified in the configuration.
- Wait for the full data synchronization interval to pass. Refresh the form page, then check if preset options are updated to match the latest party building learning records.
