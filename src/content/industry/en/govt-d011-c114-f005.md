# Document Assistance for Speech and Report Drafting: Tool Calling and Plugins

## What data for this category looks like
Data sources for speeches and report materials mainly include internal document archive systems of state-owned enterprises and government departments, past meeting speech drafts, and department report ledgers. Update cadence follows work cycles, including monthly, quarterly, and annual regular reports, as well as temporary special work reports. Document structure is fixed, including recipient unit, document number, main body (background explanation, work progress, existing issues, next steps), issuing unit and date, and other modules. Core fields include topic, drafter, approval status, and submission level. Content length ranges from 1000 to 5000 characters, with units mainly being characters, dates, and level numbers.

## What constraints do these characteristics impose on the tool calling and plugins workflow
The fixed document structure of this category requires tool calling to match specific text formats for field extraction. For example, extract unit information from document numbers and closing sections. Permission restrictions on internal data sources require plugins to have identity verification rules configured, to avoid unauthorized access to sensitive documents. The wide range of content lengths requires tool calling to support dynamic adjustment of the context window, to adapt to materials of different lengths. Differences in submission levels require plugins to adjust the level of detail of content based on the recipient, ensuring output complies with reporting specifications for the corresponding level.

## Configuration Settings
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | Set to `"auto"`, or specify as `"function"` | Adapts to scenarios where this category requires structured extraction and data query plugins |
| `functionCall` | Enable function calling, with no more than 5 parameters per single call | Matches the number of core fields of documents in this category, avoiding call failures caused by parameter overload |
| Plugin data source permissions | Configure internal system whitelists, only allowing access to authorized document archive libraries | Ensures compliance of internal document access, meeting industry data security requirements |
| Call timeout threshold | Set to `30–60 seconds` | Adapts to the average processing time of documents in this category, avoiding timeouts caused by overly long documents |
| Context window length | Set to `8000–12000 token` | Adapts to the 1000-5000 character length of documents in this category, avoiding truncation of core content |
| Content matching rules | Match and recall historical materials by document structure fields | Matches the fixed format characteristics of speeches and report materials, improving the relevance of recalled content |

## Three Common Configuration Errors
- Configuring the `toolChoice` and `functionCall` parameters results in empty fields returned by the content extraction node. Cause: The interface permissions of the custom model are not correctly configured, or the parameter values do not meet the calling requirements of the plugin.
- A 401 unauthorized error is returned when calling the plugin, but the same secret key works when called via Postman. Cause: Identity verification parameters are not correctly carried in the plugin configuration, or the permission scope of the secret key does not cover the plugin interface.
- Unable to obtain external data when calling internet-enabled plugins. Cause: No proxy or alternative plugin adapted to the domestic network environment is configured, preventing normal network requests from being initiated.

## How to Verify Correct Configuration
- Manually trigger a plugin call, check if the returned results include core fields of speeches or report materials, such as topic, submission level, and issuing unit.
- View the plugin call log to confirm that the `toolChoice` and `functionCall` parameters are correctly passed to the interface.
- Attempt to call an unauthorized internal document library, confirm that the system triggers permission interception, and verify the effectiveness of the data source configuration.
- Adjust the number of plugin call parameters, check whether the expected content extraction or data query action is triggered, and confirm that the parameter configuration takes effect.

The values provided are common starting points and should be measured against the reader's own samples.
