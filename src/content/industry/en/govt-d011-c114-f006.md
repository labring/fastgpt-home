# Document Assistant for Speech and Report Drafting: Citation Source and Traceability

## What the data for this category looks like
Data for this category comes primarily from internal document management systems of state-owned enterprises, previously archived meeting speeches, annual report materials, and public policy documents. Update cycles align with document circulation rhythms, and typically occur weekly or at special project milestones. Each individual document has a fixed structure: title, main recipient, main text paragraphs, signature block, and attachment list. Core fields include document number, issuing unit, completion date, and theme classification. Data is measured per individual manuscript. This page covers FastGPT v4.17.0.

## Constraints imposed on citation source and traceability by these characteristics
The fixed structure and clear fields of documents in this category require accurate matching of identifiers such as original title and document number during citation traceability, to avoid missing traceability information. Long main text paragraphs require retrieved segments to cover complete semantic units, to prevent breaking the original text’s logical flow. The project-aligned update feature requires knowledge base synchronization frequency to match document circulation rhythms, to ensure cited content stays timely. The rigor of official documents requires traceability information to include completion date and issuing unit, to meet compliance review needs.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1000–1500 token | Adapts to the average length of speech manuscripts, avoiding truncation of valid cited content |
| `responseData` | Includes title, document number, completion date | Matches the core review fields of documents in this category, meeting traceability compliance requirements |
| Single search limit | Top 3–5 entries | Speech manuscript citations require authoritative sources; too many entries will disperse core logic |
| `detail` | Enabled | Displays complete original text fragments and metadata, facilitating verification of citation accuracy |
| Knowledge base synchronization frequency | Weekly or at special project nodes | Matches the update rhythm of data in this category, ensuring the timeliness of cited content |

## Three common mistakes
- Symptom: After setting the `quoteMaxToken` parameter above 2000, the model response includes no cited content, and only retrieved entries appear in the retrieval details. Cause: The parameter value exceeds the current context window’s capacity limit, so the system cannot integrate cited fragments into the formal response.
- Symptom: The speech manuscript content associated with the knowledge base can be retrieved, but the corresponding cited fragment does not appear in the response main text. Cause: The `detail` configuration is not enabled, and the system only loads document metadata without obtaining the original text content for citation.
- Symptom: After local deployment, the associated knowledge base content cannot be cited normally, and the preset correct citation does not appear in the response. Cause: The `responseData` configuration does not include necessary metadata fields, and the system cannot identify valid citation sources.

## How to verify successful configuration
- Submit a simulated drafting request, review the citation list at the end of the response, and confirm the metadata in the list includes the document title, document number, and completion date.
- After adjusting the `quoteMaxToken` parameter, check that the length of cited fragments in the response matches the preset context capacity.
- Retrieve a test speech manuscript document, confirm the number of retrieval results aligns with the preset single search limit.
- Check the knowledge base synchronization log, confirm the synchronization frequency matches the update rhythm of documents in this category.

The values listed above are common starting points, and should be evaluated against specific operational samples.
