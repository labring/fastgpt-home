# "Efficiently Complete One Task" Joint Office Internal Office and Employee Services: Document Parsing and Chunking

## What this category of data looks like
This data typically serves government service management departments, data administration bureaus, and similar entities. Daily processed documents include joint office task lists, one-time notice sheets, joint office application forms, material circulation slips, parallel approval opinions, completion receipts, and similar items. Data sources include the "One Task" special zone of the national government service platform, local integrated government service platforms, electronic certificate repositories, and departmental approval systems. Updates occur daily. Joint office documents often include cross-departmental task association fields. Excel data often contains multiple departmental approval nodes. Word documents use fixed template formats with local variations.

## Constraints imposed on document parsing and chunking
Daily updated data sources require parsing workflows to support scheduled synchronous batch data processing. Large single documents (such as 100,000-character Chinese Word files, 15,000-row Excel files) require sufficient parsing duration and upload capacity. Cross-departmental association fields require chunking to preserve context associations. Breaking these associations will cause task relationship splitting errors, which will affect subsequent joint office workflow configuration. Locally differentiated document templates require parsing rules with custom adaptation capabilities, to prevent loss of key approval information due to format mismatches. Differences in data formats across multiple sources require the parsing process to support different encoding and typesetting specifications, to ensure accurate data extraction.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Adapts to the length of cross-departmental task association fields in joint office documents, avoids splitting that breaks context associations, and complies with the chunking rules of FastGPT v4.17.0 |
| `chunkSplitter` | Split by paragraph + title | Matches the fixed template structure of joint office documents, preserves the hierarchical relationship of task nodes, and ensures complete context for approval workflows |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Supports upload requirements for single 100,000-character Chinese Word files or 15,000-row Excel files, covering common large-document scenarios for this category |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Addresses parsing time required for large-volume joint office data, prevents task interruptions caused by insufficient default timeout duration |
| `chunkSettingMode` | Manual configuration | Flexibly adjusts chunking rules for different types of joint office documents (lists, application forms, circulation slips) to adapt to locally differentiated templates |
| `customPdfParse` | Enable custom parsing | Adapts to non-standard formats of government documents, preserves complete information of key fields such as parallel approval opinions and completion receipts |

## Three Common Mistakes
- Phenomenon: A timeout error is triggered when parsing a 100,000-character Chinese joint office task list, and a gateway timeout prompt is returned. Cause: The `PARSE_FILE_TIMEOUT_SECONDS` parameter is not adjusted, and the default timeout duration is insufficient to complete full parsing of large-volume documents.
- Phenomenon: Cross-departmental task association fields are lost after vector generation, and query results are empty. Cause: `chunkSplitter` is configured to split by fixed characters, which breaks the context association of cross-departmental tasks, causing association information to be split into different chunks.
- Phenomenon: After uploading a 15,000-row material circulation slip Excel file, the parsed result only contains partial data. Cause: The `UPLOAD_FILE_MAX_SIZE` parameter is not adjusted, and the file is truncated after exceeding the default limit, resulting in incomplete data.

## How to Confirm Configurations Are Correct
- Upload a single 100,000-character Chinese joint office task list document, and check whether the parsing task completes within the set duration.
- Extract parsed chunked content, and verify that cross-departmental task association fields are fully preserved in the same chunk.
- Upload a 15,000-row material circulation slip Excel file, and confirm that the number of parsed data rows matches the original file.
- Test knowledge base calls via multi-turn conversations, and check whether approval node information across different departments can be accurately associated.
