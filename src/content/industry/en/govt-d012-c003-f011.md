# Internal Office and Employee Services for Real Estate Registration: Forms and Interactions

## What this category of data looks like
Data sources for this category include real estate registration information systems, cadastral survey databases, housing transaction online signing systems, tax systems, and electronic certificate repositories. The update frequency is daily. Daily documents include registration applications, ownership certificates, surveying and mapping results, tax payment vouchers, real estate ownership certificates, and real estate registers. Data fields include parcel numbers, right holder information, real estate locations, right types, restriction statuses, and more. There are no universal standard units. Some fields require cross-system cross-source verification to ensure the accuracy of ownership information.

## Constraints imposed on forms and interactions
Cross-system cross-source data requires forms to support multi-field linked verification. This prevents duplicate or conflicting ownership information from being entered. Daily updated data must pull the latest status in real time during form interactions. This ensures the timeliness of verification steps. Diverse document types require forms to support multi-format attachment uploads and automatic field mapping. This reduces manual input workload and error rates. In cross-department collaborative window scenarios, forms must adapt to permission visibility ranges for different positions. Only fields and operations required for the corresponding role are displayed. This avoids information leaks or incorrect operations.

## How to configure settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Configuration | Rationale |
| --- | --- | --- |
| `formInput` | Enable automatic verification mode, verification interval 200–300 milliseconds | Real estate registration forms have many fields and require cross-source verification. Short interval verification can intercept input errors early |
| `userSelect` | Limit to displaying the top 10 candidate results per page | Candidate data related to real estate registration has clear entries. Displaying a small number avoids interface overload |
| Voice input permission configuration | Enable system-level permission verification, timeout threshold 15 seconds | Adapt to the complete process of voice interaction scenarios, avoid errors caused by expired permissions |
| Attachment upload configuration | Single file maximum 100 MB, support PDF, JPEG, DWG formats | Match the format and size requirements of daily documents in this category |
| Role permission configuration | Divide field visibility ranges by position | Adapt to multi-position collaboration business scenarios in real estate registration centers |

## Three common configuration errors
- The interface displays "Permission denied by system" for voice input errors. Cause: System-level voice input permission verification is not configured, or the permission configuration timeout threshold does not meet business scenario requirements. This results in permission being revoked by the system during interaction.
- Only 6 chat interaction pages can be opened simultaneously on a single device. Cause: Concurrency configuration is not adjusted for parallel processing of multiple real estate registration forms. The default concurrency limit is adapted for general office scenarios and cannot meet multi-window collaborative operation needs.
- Tool call return results contain redundant `Human <Instruction>` type content. Cause: Content filtering rules for `formInput` are not configured. This causes system prompt text to be mixed into tool call return results.

## How to confirm the configuration is correct
- Enter core fields such as parcel numbers and right holder information to trigger automatic verification. Check whether prompt information complies with business rules, and adjust the verification interval to match business rhythm.
- Initiate a voice input interaction to verify whether the permission verification logic works normally. Confirm that error text matches the configuration rules.
- Switch accounts with different position roles to check whether the form field visibility range matches role permissions.
- Upload commonly used documents in this category such as surveying and mapping result DWG files and tax payment voucher PDFs. Verify whether attachment upload format and size restrictions take effect.
