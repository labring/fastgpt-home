# Internal Office and Employee Services for Property Rights, Asset and State-owned Capital Management: Tool Calling and Plugins

## What data for this category includes
Data sources for this category include state-owned assets supervision information systems, enterprise asset management systems, property rights exchange systems, valuation institution reports, and financial statements. Updates occur monthly.
Daily processed documents include property registration forms, asset valuation reports, property rights transfer plans, on-site transaction announcements, and asset disposal approval slips.
Data fields cover asset ownership number, book original value, assessed value, transaction base price, disposal approval status, and more. These fields support core association verification between physical assets and book records.

## What constraints these characteristics impose on tool calling and plugins
Multi-source heterogeneous data sources mean tool calling must support interfacing with different systems, and adapt to mixed parsing needs for structured forms and unstructured reports.
Monthly update frequency reduces mandatory real-time data synchronization requirements. Scheduled pulling to update local caching is a viable approach.
Complex business document structures and multi-field association verification requirements require tool calling to pull data across systems. It must also complete cross-verification of ownership and book-physical consistency. This avoids information bias from single data sources.

## How to configure
The following configurations apply to FastGPT v4.17.0.

| Configuration Item | Suggested Value | Rationale |
| --- | --- | --- |
| `toolChoice` | auto | Adapt to the multi-tool automatic scheduling needs of property rights and asset tasks, no manual tool specification required |
| `functionCall` | Enable only when tool specification is explicitly required | Simplify tool scheduling workflows for routine property rights business, avoid redundant configuration |
| Workflow trigger rules | Trigger corresponding tools by document type | Differentiate processing logic for different documents such as property registration forms and asset valuation reports, match business scenarios |
| MCP call concurrency limit | 1-2 calls per second | Avoid empty return issues under high concurrency, adapt to the conventional call rhythm of state-owned assets business |
| Tool call timeout | 600 seconds | Cover the full processing duration of complex asset ownership verification and cross-system data pulling |
| Knowledge base recall count | Top 8 entries | Balance information completeness and processing efficiency, adapt to structured retrieval needs for property rights documents |

## Three common configuration errors
- Empty return when calling workflows concurrently. Phenomenon: MCP calls return none when making 2-3 calls per second. Cause: The MCP call concurrency limit is not restricted, and requests are discarded because system carrying capacity is exceeded.
- Failure to call the FastGPT chat interface normally. Phenomenon: Requests return connection failure or parameter errors. Cause: Interface authentication parameters and request header formats are not configured correctly, and the interface request body structure is not matched.
- Incorrect parameter passing for multiple images. Phenomenon: Only the first image is recognized during tool calling, and subsequent images are lost. Cause: Image parameters are not encapsulated in the array format required by the interface, and only the path or binary data of a single image is passed.

## How to confirm configuration is complete
- Initiate a tool call request for a single property rights transfer plan, check whether the returned result includes the structured parsing fields of the corresponding document.
- Simulate concurrent calls at 1-2 calls per second, check whether the returned results of MCP calls are all valid data with no null values.
- Set `toolChoice` to auto, submit a mixed request containing an asset valuation report and an asset disposal approval slip, and confirm that the corresponding parsing plugins are automatically called.
- View tool call logs, confirm that the timeout setting is in effect, and no prematurely terminated task records appear.

The values listed here are common starting points and should be evaluated against local sample datasets.
