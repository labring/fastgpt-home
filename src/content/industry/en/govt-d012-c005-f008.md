# Internal Office and Employee Services for Property Rights, Asset and State-owned Capital Management: Document Parsing and Chunking

## What the data for this category looks like
The core data for this category comes from state-owned assets supervision information systems, enterprise asset management systems, property rights exchange systems, external evaluation institution reports and financial statements, with a monthly update frequency. Commonly processed documents include property registration forms, asset evaluation reports, property rights transfer plans, on-site transaction announcements, asset disposal approval forms and others. Document structures include unified ownership identification fields, evaluation parameter nodes and transaction process records, covering core business information such as asset ownership, evaluation status and approval progress.

## What constraints these characteristics impose on the document parsing and chunking link
Monthly batch-updated document characteristics require parsing processes to have stability and repeatability, to avoid inconsistent chunking caused by parameter fluctuations. Mixed processing of multiple document types requires parsing logic to adapt to different structures, to prevent splitting key ownership and transaction node information. Unified access to multi-source data requires chunk formats to remain standardized, to reduce cross-system data alignment costs. The high-risk nature of core business links requires document parsing links to have failure alerts and retry mechanisms, to avoid subsequent process risks caused by parsing errors.

## How to Configure Settings
| Configuration Item | Recommended Setting | Rationale for This Setting |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Adapts to the typical paragraph length of property registration forms and asset evaluation reports, avoids splitting core ownership fields |
| `chunkSplitter` | Split by title + paragraph | Matches the chapter structure of documents, retains approval nodes and process information in property rights transfer plans |
| `customPdfParse` | Enabled | Adapts to asset evaluation reports with encryption, embedded fonts or non-standard layouts, resolves issues that regular parsing cannot read |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Accommodates batch on-site transaction announcements and annual asset summary reports, meets monthly batch upload requirements |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Prevents parsing timeouts for long documents such as annual evaluation summary reports, ensures normal completion of batch tasks |
| `chunkSettingMode` | Manual configuration | Adjusts chunking parameters for different document types, adapts to parsing needs of multi-source heterogeneous data |

## Three Common Misconfigurations
- After uploading a scanned asset evaluation report, the system log shows `ocr error` and text content cannot be extracted. Cause: The OCR adaptation mode of `customPdfParse` is not enabled, so non-editable PDF documents cannot be processed.
- After configuring a Feishu knowledge base, PPT and PDF files cannot be synchronized, and the synchronization task status shows timeout. Cause: `PARSE_FILE_TIMEOUT_SECONDS` is not adjusted, and long document parsing time exceeds the default threshold, causing task interruption.
- After connecting the Claude 3.7 model, normal chat processes run normally, but empty results are returned after file parsing is added. Cause: `chunkSettingMode` is not set to manual configuration, and the default chunking parameters split the structured transaction clauses of on-site transaction announcements, causing the model to fail to identify valid information.

## How to Confirm the Configuration Is Complete
- Upload a single property registration form PDF, check the chunk preview, confirm that core fields such as ownership number and asset location are not split into different chunks.
- Upload 3 to 5 monthly asset reports, check the upload queue status, confirm there are no timeout errors or parsing failure records.
- After enabling `customPdfParse`, re-upload an asset evaluation report with embedded tables, confirm that the parsing preview can normally display table content and evaluation parameters.
- Check the FastGPT v4.17.0 system configuration log, confirm that parameters such as `chunkSettingMode` and `PARSE_FILE_TIMEOUT_SECONDS` have taken effect as configured, and are not overwritten by default values.
