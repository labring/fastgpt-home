# Internal Office and Employee Services for Property Rights, Asset and State-owned Capital Management: Forms and Interactions

## What data for this category looks like
Data for this category mainly comes from state-owned assets supervision information systems, enterprise asset management systems, property rights exchange systems, assessment institution reports and financial statements. Daily processed documents include property rights registration forms, asset evaluation reports, property rights transfer plans, on-site transaction announcements and asset disposal approval slips. Data update frequency is monthly. Fields include ownership number, asset location, evaluation value, transaction base price, approval status and more. Corresponding units involve ten thousand yuan, square meters, pieces and others. Field formats vary across different documents.

## What constraints these characteristics impose on forms and interactions
Monthly updated data requires forms to support incremental sync of historical stock data, and avoid re-importing full documents. Multi-source documents with varying formats require forms to configure multi-data source mapping rules, and be compatible with file formats exported from different systems. Fields contain specific ownership and transaction information with fixed units, requiring forms to enable field format verification and unit restrictions. Errors in state-owned asset-related forms have serious consequences, requiring forms to configure permission controls, and only allow authorized employees to modify sensitive fields. The time-consuming process of verifying account and physical consistency requires forms to configure field linkage rules, and automatically associate ownership number and asset location information.

| Timeout setting | 120 seconds | The average time to retrieve stock asset data across systems is approximately 60-180 seconds, set a reasonable threshold based on actual measurements |
| Form input length limit | 2000 characters | Match the conventional content length of documents such as property rights transfer plans |
| Field linkage rules | Ownership number links asset location and evaluation value | Simplify the account and physical verification process, reduce manual entry errors |

## Three common configuration mistakes
- Phenomenon: When importing documents such as asset evaluation reports, the page keeps refreshing and target page numbers cannot be selected. Reason: OCR preprocessing is not enabled for PDF scanned documents, causing abnormal page parsing logic.
- Phenomenon: The optional scope of the `userSelect` component is empty, and internal employees cannot select the corresponding property rights management department. Reason: The state-owned assets internal organization architecture data source is not synced, so the component has no available options.
- Phenomenon: The knowledge base associated content returned after form submission is unrelated to the current asset. Reason: No dedicated knowledge base index for this category is configured, causing the recall scope to cover unrelated other business data.

## How to confirm the configuration is complete
- Import a standard property rights registration form document, check if page parsing is normal, and if selectable page numbers are complete.
- Submit a form test that includes all required fields, check if real-time verification intercepts submissions with null values or format errors.
- After configuring the internal organization architecture data source, check if the optional scope of the `userSelect` component includes relevant state-owned assets internal departments.
- Retrieve stock asset data, check if form field linkage automatically displays corresponding ownership number and asset location information.
