# Internal Office and Employee Services for Petition Matter Handling: Tool Calling and Plugins

## What this category of data looks like
Data sources include the national petition information system, local petition systems, the 12345 citizen hotline platform, grassroots governance platforms, and historical petition archives. Data is updated daily.
Daily processed documents include petition registration forms, acceptance notices, transfer and assignment letters, handling opinions, review and re-examination applications, and resolution plans.
Data fields cover information of the requesting party, matter details, acceptance numbers, responsible units, handling progress, and more. The format is primarily a mix of structured forms and official documents, with no additional custom statistical fields.

## Constraints imposed on tool calling and plugins by these characteristics
Multiple data sources and daily updates require tool calling to support integration with multiple system interfaces, to avoid data lag caused by expired cache.
Document types include structured forms and official documents. Tool calling must support content parsing and extraction for different formats.
Core handling links take up a large share of total processing time. Tool calling should be used to automatically complete actions such as identifying acceptable scope, coordinating responsible units, and generating handling opinions, to reduce manual repetitive operations.
Errors in data association directly affect petition order. Tool calling results must be verified to avoid incorrect process triggers that lead to repeated or improperly hierarchical petitions.

## How to configure
This configuration is based on FastGPT v4.17.0, with the following details:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` or specify a specific plugin ID | Adapt to the needs of multi-tool linkage in petition handling, automatically trigger corresponding tools or specify calls to specific business plugins |
| `functionCall` | Enabled | Force structured output of tool call parameters to meet the standardized process requirements of petition matter handling |
| Maximum single tool calls per round of dialogue | 2 per round of dialogue | Avoid process lag caused by too many tool calls, align with the single-processing logic of petition handling |
| Tool call timeout | 30–60 seconds | Adapt to the conventional response duration of multi-system interfaces, avoid interrupting handling processes due to waiting timeouts |
| Plugin call permission scope | Only open plugins related to petition business | Ensure data call security, avoid unauthorized access to non-business systems |

## Three common misconfigurations
- Symptom: When attempting to trigger two tool calls simultaneously, only one executes in the returned result. Cause: Multi-tool linkage parameters for `toolChoice` are not correctly configured. The default setting only allows a single tool call.
- Symptom: API calls fail in some regions, returning connection timeout or permission errors. Cause: Network proxies or whitelists for the relevant regions are not configured, and regional access restrictions for petition systems are not addressed.
- Symptom: Links in streaming output only overwrite the current page when clicked, and cannot open a new page. Cause: No new window opening identifier is added to the link parameters returned by tool calls, and front-end interaction specifications are not followed.

## How to confirm the configuration is complete
- Initiate a test dialogue with requirements for multiple tool calls. Verify that the expected number of tool calls are triggered.
- After configuring regional whitelists, initiate an API call in the corresponding region. Confirm that the returned result is normal with no errors.
- Generate a test link for streaming output. Click the link to confirm it opens in a new browser tab.
- Check that the returned results of tool calls match the field requirements of petition business documents, with no missing or incorrect information.
