# Internal Office and Employee Services for Student Aid and Subsidy Review: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Core data for this category comes from the national student aid management information system, school student status system, civil affairs low-income and extremely poor support data, and fiscal payment systems. The update cycle is one semester. Daily processed documents include family economic hardship certification forms, aid application forms, scholarship and grant review forms, disbursement lists, and public notice materials. Some documents are multi-page structured tables with fixed fields such as student ID number, household income, bank card number, review opinions, and disbursement amount. Data formats cover two categories: form text and tabular data.

## What constraints these characteristics impose on knowledge base retrieval and recall
Multi-source cross-system data sources require retrieval to support cross-data source field matching, to avoid qualification verification errors caused by relying on a single data source.
Semester-level update frequency requires the knowledge base to complete incremental updates on a periodic basis, preventing the recall of invalid aid data from previous semesters.
Documents contain a large number of structured fields and tabular content, so retrieval must balance semantic matching and precise keyword matching to ensure core qualification fields are recalled first.
The most time-consuming verification link requires retrieval results to prioritize content directly related to qualification determination, reducing the workload of manual screening.

## How to set the configuration
Reference only; verify against the target FastGPT release and deployment documentation.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Filter low-match, non-qualification-related documents, reducing audit risks of incorrect or missed disbursements |
| `limit` | Top 8 entries | Cover multiple associated materials required for class or college review, while controlling the context length of a single retrieval round |
| `usingReRank` | Enabled | For documents with many structured fields, reordering can improve the ranking priority of qualification-related content |
| `searchMode` | Semantic + keyword hybrid | Match both text semantics and structured fields such as student ID number and bank card number, improving accuracy |
| `collectionIds` | Specify based on current semester dataset | Limit retrieval scope, avoiding recall of invalid data from previous semesters |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expand business questions into structured queries, such as expanding "subsidy eligibility" to field searches for corresponding certification forms |

## Three Common Misconfigurations
- Phenomenon: The knowledge base content interface returns a format error, but docx files can be downloaded normally in the browser. Cause: Complex document parsing parameters are not configured correctly, resulting in embedded tables or multi-layout docx files failing to fully extract structured fields.
- Phenomenon: The number of retrieval results is far lower than expected. Cause: The `similarity` threshold is set too high, filtering some associated documents that meet qualification conditions, or `datasetSearchUsingExtensionQuery` is not enabled, leading to insufficient question expansion.
- Phenomenon: Retrieval results include historical aid data from non-current semesters. Cause: The knowledge base has not been updated on a semester cycle, or `collectionIds` is not used to limit the scope of the current semester dataset.

## How to Confirm Proper Configuration
- Upload a standard family economic hardship certification form, search for "family economic difficulty student eligibility", and check whether the recalled results include the core structured field content of this document.
- Adjust the `similarity` parameter, observe changes in the matching degree of retrieval results, and confirm that the threshold meets business screening requirements.
- Test cross-system joint retrieval, such as entering "current grade student ID number + low-income household", and confirm that the hybrid `searchMode` can match both types of fields.
- View the knowledge base update log, confirm that incremental updates have been completed on a semester cycle, and that `collectionIds` only includes datasets from the current semester.
