# Internal Office and Employee Services for Urban Sanitation and Urban Management Law Enforcement Cases: Deployment and Upgrade

## What This Category’s Data Looks Like
Typical data for this category comes from urban management law enforcement platforms, urban operation grid platforms, video surveillance systems, and public complaint work orders, with a daily update frequency. Daily documents include inspection records, case filing approval forms, on-site photos, rectification orders, penalty decisions, and case closure reports. Data fields cover case numbers, violation types, responsible parties, rectification status, and other relevant details. Some documents include multimedia attachments.

## What Constraints Do These Characteristics Impose During Deployment and Upgrade
Data sources cover internal business platforms and external public feedback, so deployment must adapt to the requirements of connecting to the organization’s own database. Documents include text and multimedia attachments, so resources supporting large file storage must be configured. Daily updated case data requires high-frequency caching to ensure retrieval efficiency. On-site evidence documents involve law enforcement compliance, so access permissions must be strictly controlled. During upgrades, permission verification logic and data synchronization task configurations must be updated synchronously.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `MONGODB_URI` | Intranet connection address of the urban management law enforcement’s own database | The core case data of this category is stored in the dedicated urban management law enforcement database, and a dedicated connection must be bound to avoid conflicts with other businesses |
| `STORAGE_S3_ENDPOINT` | Intranet object storage endpoint supporting large file storage | This category includes large-volume documents such as on-site photos, so storage requirements for unstructured multimedia data must be met |
| `REDIS_URL` | Address of a locally deployed Redis instance, with a cache period set to `24 hours` | Data for this category is updated daily, and high-frequency caching can reduce database retrieval pressure and improve access speed for internal employees |
| `FE_DOMAIN` | Dedicated intranet domain name of the internal office system | This scenario targets internal employees and law enforcement personnel, and an intranet domain name ensures the security of the access link |
| `DB_MAX_LINK` | `20–30` | The average daily case processing volume of this category is stable, so the number of connections must adapt to the basic requirements of concurrent retrieval and data synchronization, and is determined based on actual measurements |
| `FILE_TOKEN_KEY` | Randomly generated 32-bit encryption key | Sensitive documents such as on-site photos and penalty decisions require permission verification, and this key ensures the legitimacy of file access |

## Three Common Errors
Reference only; verify against the target FastGPT release and deployment documentation.
- After associating the urban management law enforcement knowledge base, corresponding documents cannot be retrieved, manifested as empty search results or irrelevant content returned. The cause is that `MONGODB_URI` was not correctly configured to point to the organization’s own law enforcement database, or the vector synchronization task was not triggered at the daily update frequency.
- Custom law enforcement workflow plugins do not display input and output parameters in the workflow, manifested as no configurable fields in the plugin configuration panel. The cause is that the plugin metadata was not loaded correctly after the upgrade, and the configuration files dependent on the plugin were not updated synchronously.

## How to Confirm the Configuration Is Complete
- Access the intranet address bound to `FE_DOMAIN`, verify that the front-end page loads normally with no console error messages.
- Manually trigger the vector synchronization task, check that documents such as inspection records and penalty decisions from the urban management law enforcement platform are successfully imported into the knowledge base with no import failure prompts.
- Enter category-specific keywords such as "on-site photos" and "rectification order", confirm that the search results include the corresponding documents and the citation logic works normally.
- Log in to the Redis monitoring panel, check that the instance corresponding to `REDIS_URL` is connected normally, and the cache task is automatically triggered every `24 hours`.
