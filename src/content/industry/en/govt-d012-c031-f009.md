# Internal Office and Employee Services for Construction Project Environmental Impact Assessment Approval: Model Access and Configuration

## What the data for this category looks like
The data for this category mainly comes from the national unified construction project environmental impact assessment declaration and approval system, ecological environment zoning control results, pollution discharge permit platform, and monitoring data. Commonly processed documents include environmental impact assessment reports or report forms, approval applications, public participation explanations, technical evaluation opinions, and environmental impact assessment approvals. Document structures include fields such as basic project information, pollution prevention measures, public participation status, and technical evaluation conclusions. Update frequency is irregular, triggered by project declaration and approval progress.

## What constraints these characteristics impose on the "model access and configuration" link
Multiple data sources and diverse formats require model access configurations to be compatible with document formats exported by different systems, and adapt to unified processing of multi-source data. Document lengths vary widely, from approval applications of a few hundred words to environmental impact assessment reports of tens of thousands of words. This requires context and output length configurations to cover different scenarios. Some documents include visual content such as drawings and monitoring point maps, which requires configuration items to support visual recognition capabilities. Data updates have no fixed cycle, which requires the configured retrieval and update logic to flexibly adapt to irregular data source changes. At the same time, the accuracy of approval-related content directly affects project construction and compliance, which requires model output to remain stable and avoid deviations.

## How to set the configurations
| Configuration Item | Recommended Value | Rationale for This Value |
| --- | --- | --- |
| `maxContext` | `8000–12000 token` | Adapts to the long text content of environmental impact assessment reports, ensuring the model can obtain sufficient context information |
| `maxTokens` | `2000–4000 token` | Limits single output length, avoiding overly long generated content that affects approval efficiency |
| `vision` | Enabled | Supports recognition of visual content such as drawings and monitoring point maps in environmental impact assessment documents, compensating for gaps in text information |
| `temperature` | `0.1–0.3` | Reduces output randomness, ensuring accuracy and consistency of content related to environmental impact assessment approval |
| `AIPROXY_API_ENDPOINT` | Fill in the internally deployed proxy address | Adapts to API channels accessed via the internal network, solving configuration issues where no available channels exist |
| `AIPROXY_API_TOKEN` | Fill in the assigned exclusive access token | Ensures API access security, preventing unauthorized access |

## Three Common Mistakes
- The model fails to recognize relevant content after uploading environmental impact assessment drawings. The cause is that the `vision` configuration item is not enabled, so the model cannot process visual document information.
- An error indicating no available channels is prompted when configuring a third-party model API. The cause is that `AIPROXY_API_ENDPOINT` or `AIPROXY_API_TOKEN` is not filled in correctly, or the current group does not have access permissions for the corresponding model.
- No model creation entry is displayed in the upper right corner of the interface. The cause is that the used FastGPT v4.17.0 version does not have the corresponding permission enabled, or the current account does not have model management permissions.

## How to confirm the configuration is complete
- Upload a text snippet of an environmental impact assessment report form, initiate a model call, and check whether the model can correctly extract the project category and environmental impact assessment level.
- After enabling the `vision` configuration, upload environmental impact assessment-related drawings, and check whether the model can recognize key information in the images and generate responses combined with text content.
- After filling in `AIPROXY_API_ENDPOINT` and `AIPROXY_API_TOKEN`, initiate a test call, and check whether normal response content is returned.
- Adjust the `temperature` parameter to the `0.1–0.3` range, call the same environmental impact assessment-related question multiple times, and check the consistency of the output results.

The values provided are common starting points and should be measured against the reader's own samples.
