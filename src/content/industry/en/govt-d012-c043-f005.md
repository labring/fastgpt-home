# Internal Office and Employee Services for Special Equipment Safety Supervision: Tool Calling and Plugins

## What this category of data looks like
Data sources for this category include special equipment safety supervision systems, inspection and testing institution systems, user account books, and operator certificate databases. The update frequency is monthly. Core daily documents include use registration certificates, periodic inspection reports, maintenance records, hidden danger rectification notices, accident reports, and operator certificates. Data fields cover equipment unique numbers, registration dates, inspection cycles, maintenance unit information, operator qualification numbers, hidden danger rectification status, and more. Most values use standardized formats such as standard equipment codes, date formats, and qualification certificate numbers.

## What constraints do these characteristics impose on the tool calling and plugins workflow
Data sources for this category are scattered across multiple independent systems. Tool calling must support multi-source interface integration and be compatible with standardized field formats returned by different systems. The monthly update frequency requires that tool calling synchronization and caching cycles match the monthly rhythm, to avoid frequent data pulling that exceeds system load. Multiple types of business documents require plugins to support parsing different document structures and accurately extract core supervision fields such as equipment numbers and inspection cycles. Additionally, the high-risk nature of supervision scenarios requires that tool calling be configured with strict parameter verification and result verification steps, to prevent erroneous data from entering office workflows.

## How to set configurations
The following configurations are based on the interface and parameter logic of FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Supports automatic selection of various supervision business tools, covering scenarios such as equipment verification and qualification inspection |
| `functionCall` | Enforce verification of core fields | Ensures that tool return results include required fields such as equipment numbers, inspection cycles, and operator qualification numbers |
| Plugin timeout duration | 30-60 seconds | Matches the typical interface response duration of multi-source special equipment systems, avoiding business process interruptions due to timeouts |
| Maximum number of plugins per call | First 3 | Focuses on core supervision business, avoiding excessive plugin calls that consume system resources |
| Number of returned results | Calibrated based on actual testing | Adapts to the number of business documents in different scenarios, ensuring coverage of core supervision requirements |

## Three common mistakes
- Phenomenon: Timeout errors are returned when calling external MCP plugins, or the workflow execution status shows a timeout. Cause: The timeout setting adapted to multi-source systems is not configured, or the timeout value is too short to match the response rhythm of special equipment systems.
- Phenomenon: A workflow ID does not exist error is returned when calling a workflow. Cause: The workflow ID of the corresponding business process was not obtained correctly, or the passed ID format does not meet system requirements.
- Phenomenon: Fields are empty or results do not match during API debugging. Cause: The mandatory verification configuration for `functionCall` is not enabled, or the field format of special equipment documents is not adapted, causing the tool to fail to correctly extract core data.

## How to confirm that configurations are correctly set
- Perform a single-step tool call test to verify whether the plugin can correctly connect to the special equipment safety supervision system and return corresponding document data.
- Trigger a workflow that includes multiple types of business documents, and check whether `toolChoice` automatically selects the tool matching the current business.
- View tool call logs to confirm that the returned results include core supervision fields such as equipment numbers and inspection cycles, and that no timeout errors occur.
- Adjust plugin call parameters to verify whether the maximum number of plugins per call configuration is effective, avoiding calls exceeding the preset quantity.
