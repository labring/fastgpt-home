# Internal Office and Employee Services for Environmental Law Enforcement and Monitoring Supervision: Multi-turn Dialogue and Prompt Engineering

## What the data for this category looks like
This category covers entities such as ecological environment law enforcement detachments, environmental monitoring stations, and third-party testing institutions. Daily processed documents include on-site inspection records, sampling records, monitoring reports, order for correction decisions, and administrative penalty decisions. Data sources include online monitoring platforms, automatic pollution source monitoring data, ecological environment law enforcement systems, and third-party test reports. Update frequency is daily. Document structures contain fields such as law enforcement time, location information, pollutant detection data, and law enforcement document numbers. Data formats from different sources have minor differences.

## What constraints these characteristics impose on multi-turn dialogue and prompt engineering
Multiple data sources and inconsistent formats require prompts to adapt to the field rules of different documents. This ensures the AI can accurately parse core information such as on-site working conditions and monitoring concentrations. Daily updated real-time data requires multi-turn dialogue to quickly call the latest monitoring and law enforcement records. This avoids reliance on outdated information. Multiple types of law enforcement documents require prompts to distinguish output formats for different scenarios. For example, order for correction decisions must clearly state rectification requirements. Administrative penalty decisions must match evidence chains. Errors in law enforcement and monitoring directly relate to public environmental safety. Prompts must add evidence verification logic to ensure output content is traceable.

## Three common configuration errors
- Format error prompts appear in the debug preview interface, and the custom thesaurus configuration does not take effect | The thesaurus file was not uploaded to the specified path, or the thesaurus content does not include high-frequency law enforcement and monitoring terms for this category
- The response length for a specific question is only 200 tokens, which does not match the preset maximum response of 3000 or more | The multi-turn dialogue context window is filled with non-core law enforcement data, and the system automatically triggers content truncation
- No corresponding monitoring report data is returned after calling the API interface associated with the knowledge base | The `variables` parameter was not correctly bound to inject retrieval conditions such as law enforcement location ID, resulting in overly large or invalid retrieval scope
