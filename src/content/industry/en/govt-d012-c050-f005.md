# Internal Office and Employee Services for Fiscal Expenditure Performance Evaluation: Tool Calling and Plugins

## What the data for this category looks like
This category covers daily office documents for entities including fiscal bureau performance departments and budget units. Documents include performance target forms, self-assessment forms, performance evaluation reports, supporting material lists, and rectification reports.
Data sources include the unified budget management system, project declaration materials, fund payment data, business system ledgers, and satisfaction survey results. The update frequency is once per year.
Each document includes structured performance indicators, fund allocation details, supporting material association information, and other content. Data must be pulled across multiple systems and integrated and processed across multiple document types.

## Constraints for the Tool Calling and Plugins Link
The annual update frequency of this category means tool calling does not need high-frequency triggering. Only batch processing within the annual performance evaluation cycle is required.
Multi-source data sources require plugins to support cross-system data pulling. Unified data source calling rules must be configured.
Daily documents include structured forms and long-text reports. Tool calling must adapt to text extraction needs for different formats.
The most time-consuming supporting material collection process requires tools to automatically complete field extraction and data verification. This reduces manual operation volume.
The correlation of performance data requires tool calling to complete correspondence verification between fund expenditures and performance targets. This ensures accurate data matching.

## Three Common Misconfigurations
- Text extraction tools return empty fields or format error prompts. The cause is failure to configure tool triggering rules for the fixed form formats of performance target forms and self-assessment forms, resulting in the tool being unable to match the corresponding document types.
- A connection timeout error occurs when deploying an MCP Server locally and failing to establish a connection. The cause is failure to adjust configuration parameters according to the FastGPT deployment network environment, and mistakenly writing the address as localhost:port.
- Access restrictions are triggered when multiple tool calls are initiated simultaneously. The cause is failure to adjust the concurrency threshold according to the annual update rhythm of fiscal data, with concurrent requests exceeding the system's adaptation range.

## How to Confirm Proper Configuration
- Input a sample text from a performance self-assessment form, trigger tool calling, and check if the text extraction tool is automatically called and structured performance indicator fields are returned.
- View the MCP Server connection logs, confirm that the proxy address configuration matches the FastGPT deployment network environment, and no connection timeout errors occur.
- Simulate batch document upload for annual performance evaluation, check if the tool call trigger conditions take effect according to preset rules, and no abnormal errors occur.
- Verify the cross-system data association function, confirm that fund payment data for the specified project can be pulled from the designated data source and associated with the performance report for matching.
