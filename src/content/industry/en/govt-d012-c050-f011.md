# Internal Office and Employee Services for Fiscal Expenditure Performance Evaluation: Forms and Interactions

## What the data for this category looks like
Data sources for this category include the unified budget management system, project declaration materials, fund payment data, business system ledgers, and satisfaction surveys. Data is updated annually.
Daily documents include performance target forms, self-assessment forms, performance evaluation reports, supporting material lists, and rectification reports.
Fields cover project identifiers, fund disbursement amounts, performance indicator items, supporting material paths, rectification completion status, and other relevant items. Units include ten thousand yuan, items, times, and similar units.

## What constraints these characteristics impose on the forms and interactions workflow
The annual update requirement means forms must support bulk import of standardized annual data, without frequent template structure adjustments.
The need to access data from multiple sources means forms must support associating fields from different business systems, to enable automatic data synchronization.
The time-consuming process of collecting supporting materials and verifying the correspondence between funds and performance targets means forms must support multiple attachment uploads and field linkage verification functions.
The serious potential consequences of errors mean forms must include permission control and operation logging mechanisms, to prevent unauthorized modifications.
Additional configuration needs must be adapted for scenarios such as form default values and image input.

## How to configure the settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Associate with the annual performance data template from the unified budget management system | Data sources are the unified budget management system, updated annually, requiring bulk import of standardized data |
| Attachment upload node | Maximum 1000 MB per file, up to 50 files per upload | Supporting materials are mostly scanned documents, contracts, and similar files with varying sizes, requiring adaptation for multi-attachment scenarios |
| `userSelect` | Restrict to the roles of performance office and budget unit handlers | Entities participating in evaluations include the finance bureau performance office, budget units, and similar groups, requiring permission scope control |
| Form default value configuration | Reference the current annual performance indicator library in global variables | Annual evaluations must use the current year's indicators uniformly, reducing manual input errors |
| Field verification rules | Linkage verification between fund expenditure fields and performance indicator completion fields | Need to verify the correspondence between fund expenditure and performance targets, to avoid data mismatches |
| Timeout setting | 600 seconds | Bulk import of annual data requires waiting for system synchronization, to prevent mid-import interruptions |

## Three Common Misconfigurations
- Symptom: When using the `formInput` node to import base64-format images, supporting materials cannot be parsed correctly. Cause: No image format verification rules configured, or the decoding switch for base64 data not enabled.
- Symptom: The default value of a form input node cannot reference a global variable, and the field is empty after submission. Cause: The global variable namespace not correctly bound, or the variable scope does not cover the current workflow.
- Symptom: When bulk importing performance self-assessment forms, the system prompts a timeout error. Cause: The timeout setting not adjusted to a duration suitable for bulk data, or large file import batches not split.

## How to confirm the configuration is complete
- Upload a standard performance supporting material, check if it can be stored normally and associated with the corresponding form field.
- After configuring `userSelect` role permissions, attempt to access the form with an unauthorized account, confirm that permission interception takes effect.
- Enter test fund data and performance indicators, check if linkage verification triggers reasonable prompts.
- Import a small batch of annual performance data, confirm that the form can load normally and display the imported content.
