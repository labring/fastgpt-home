# Internal Office and Employee Services for Food Safety Supervision Sampling: Knowledge Base Retrieval and Recall

## What the data for this category looks like
This category’s data supports daily operations for food sampling departments under market supervision bureaus, inspection institutions, grassroots supervision offices, and food producers and operators. It covers documents including sampling plans, sampling forms, inspection reports, non-compliant food verification and disposal reports, risk control notices, and more. Data sources include the food safety sampling monitoring system, the State Administration for Market Regulation sampling results query system, laboratory information management systems (LIMS) of inspection institutions, and enterprise ledgers. Updates occur monthly. The data includes structured sampling fields and unstructured inspection text. Core evidence comes from test reports issued by laboratories.

## What constraints these characteristics impose on the knowledge base retrieval and recall link
The monthly update frequency requires the knowledge base to support a combination of incremental synchronization and full updates. This avoids frequent full refreshes that consume system resources. Multiple document types require the retrieval system to support both structured field matching and unstructured text recall. This adaptation supports fixed fields in sampling forms and free text in inspection reports. Relying on laboratory test reports as core evidence requires retrieval results to prioritize association with non-compliant items and disposal processes. This reduces interference from irrelevant information. Grassroots office usage needs require retrieval results to be concise and focused. This reduces redundant content and improves query efficiency.

## How to Set the Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Sampling data contains a large number of professional terms, requiring filtering of low-matching irrelevant documents, and adapting to the parameter logic of FastGPT v4.17.0 |
| `limit` | Top 6–10 entries | Grassroots office staff need to quickly review core results, avoiding information overload |
| `searchMode` | vector+hybrid | Balancing retrieval needs for structured sampling fields and unstructured inspection reports |
| `usingReRank` | Enabled | Further filtering matching results to focus on content related to non-compliant disposal and sampling locations |
| `datasetSearchUsingExtensionQuery` | Enabled | Supplementing associated context information such as sampling plans and risk notices |
| `collectionIds` | Configured by business module | Dividing knowledge base collections by sampling plans, inspection reports, and disposal reports to accurately match query scenarios |

## Three Common Mistakes
- Phenomenon: Responses exceed the knowledge base scope, outputting unincluded sampling policy content. Cause: The rule restricting responses to only knowledge base content is not configured, leading the model to call external information.
- Phenomenon: Only partial document entries are displayed when exporting knowledge base file details. Cause: The export pagination parameter is not adjusted, with the default pagination size limiting the exported quantity.
- Phenomenon: A parameter error is returned when calling the create training order interface. Cause: Legitimate options for `trainingType` are not used, causing interface verification to fail.

## How to Confirm the Configuration is Correct
- Initiate a query with keywords such as "non-compliant food" and "sampling form". Check that returned results only include documents from the local knowledge base, with no external information.
- Run the knowledge base file details export operation. Confirm that the number of exported entries matches the actual number of uploaded documents.
- Call the create training order interface, passing a legitimate `trainingType` value. Verify that a 200 status code and success identifier are returned.
- Run a fuzzy query. Check that reranked results prioritize content related to core sampling processes.

The values provided are common starting points and should be measured against the reader's own samples.
