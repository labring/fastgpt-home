# Internal Office and Employee Services for Survey and Design: Forms and Interactions

## What the data for this category looks like
Survey and design data primarily comes from CAD construction drawings, BIM model files, geotechnical investigation reports, design change notices, and similar materials. Updates are triggered on demand as projects progress, such as synchronizing corresponding documents when a design change is released. Document structures typically include fields such as project unique identifier, professional classification (architecture, structure, water supply and drainage, etc.), parameter values and corresponding units (e.g., floor height 3000 millimeters, load 200 kilopascals), version number, and more. Data volume fluctuates with project complexity; a single design document may contain dozens to hundreds of professional parameter fields.

## What constraints do these characteristics impose on the forms and interactions link
Survey and design professional fields and unit requirements mean forms must support input validation with units, to prevent mismatched unit errors. Data from multiple professional classifications requires forms to display fields grouped by profession, to reduce filling complexity. Frequent update requirements mean forms must quickly synchronize to associated BIM models or design documents after submission, to avoid data inconsistency. Fixed professional terminology needs preset options to reduce manual input error rates and ensure uniform data format.

## How to set the configurations
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Enabled, display fields grouped by profession | Survey and design data is split by profession such as architecture and structure; grouping reduces filling complexity |
| `userSelect` | Enabled, preset professional terminology options | Survey and design has a large number of fixed professional terms; preset options reduce input errors |
| Form input length limit | 800–1200 characters | Professional parameter descriptions for survey and design are usually lengthy; reserve sufficient input space |
| Synchronization trigger timing | Within 10 seconds after submission | Survey and design data is updated frequently; rapid synchronization to associated BIM models or design documents is required |
| Timeout threshold | 600 seconds | Survey and design forms may be associated with large BIM models; sufficient synchronization time must be reserved |
| Unit validation rule | Match professional units (millimeters, kilopascals, etc.) | Prevent input errors caused by mismatched units |

## Three common configuration errors
- After enabling professional grouping with the `formInput` configuration, fields may overlap. This occurs because reasonable block spacing is not set, causing fields from different professions to overlap each other.
- After configuring a third-party model endpoint, the model displayed in the interface does not match the model corresponding to the entered baseURL. This occurs because the model identification field is not updated synchronously in the model configuration, causing the system to call cached old model information.
- After configuring unit validation rules, validation failure errors may occur. This occurs because professional units for survey and design are not matched, and only general mismatched unit rules are used.

## How to confirm configurations are correct
- Enter the form editing page and check whether fields are displayed grouped by profession.
- Submit a test data set containing professional parameters and check whether it is updated to the associated design document within the preset synchronization time.
- Select a preset professional terminology option, submit the data, and check whether the field value is correctly written to the system database.
- After configuring a third-party model endpoint, check whether the interface displays the model name matching the baseURL.
