# Internal Office and Employee Services for Advanced Chemical Materials: Forms and Interactions

## What the data for this category looks like
Business data for advanced chemical materials mainly comes from R&D laboratory synthesis ledgers, production central control DCS systems, supply chain purchase warehousing orders, and quality inspection reports. R&D data is updated by synthesis batch. Production data is synchronized in real time. Purchase and quality inspection data is updated by warehousing batch. A single document usually includes material codes, batch numbers, synthesis process parameters, quality inspection indicators, inventory surpluses, and supplier-related information. Most fields are structured numerical and enumeration types, with units including degrees Celsius, hours, kilograms, micrometers, and other standard units.

## What constraints these characteristics impose on forms and interactions
Synthesis parameters for R&D batches are mostly continuous numerical values. Forms must support range input and precision verification to avoid input beyond equipment operating ranges. Enumeration items for quality inspection data must use fixed optional values to prevent non-standard quality inspection results. Forms that use business data linked across multiple systems must include cross-data source variable references to ensure batch information is updated synchronously. Forms related to real-time production data must be set with short-interval automatic saving to avoid data loss. Uniqueness verification for material codes must connect to the enterprise master data system to prevent duplicate entries. Employee service forms such as consumable requisitions must link to existing inventory data to avoid over-limit requests.

## Three common configuration errors
- Symptom: After binding a global variable to `formInput`, the system prompts that the input is empty when debugging to the next node. Cause: The scope of the global variable was not set to the current workflow, or the variable binding did not trigger real-time updates.
- Symptom: When using the `userSelect` component to configure large model calls, the temperature parameter setting entry cannot be found. Cause: The "advanced parameters" expansion item was not enabled in the component configuration, and the temperature parameter is hidden by default.
- Symptom: Clicking the form copy button in Google Chrome prompts that copying failed, and the generated Markdown content has no line breaks. Cause: The "automatic line break marker" was not enabled in the form configuration, or the browser did not grant clipboard access permissions.

## How to confirm the configuration is complete
- Open the form preview page, enter any numerical value that complies with business rules, and the verification prompt should match the field type requirements.
- Select the dropdown option of the `userSelect` component, and confirm that the optional values are consistent with the material list in the enterprise master data system.
- After submitting the form, check the workflow log to confirm that the global variable has been correctly passed to the next node and there are no null value errors.
- Trigger the automatic save function, wait 30 seconds, then refresh the page to confirm that the form data has not been lost.
