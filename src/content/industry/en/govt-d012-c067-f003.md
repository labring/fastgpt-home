# Internal Office and Employee Services for Fertilizer and Pesticide Industries: Multi-turn Dialogue and Prompt Engineering

## What the Data for This Category Looks Like
The data for the fertilizer and pesticide category primarily comes from production batch ledgers, qualified quality inspection reports, formula technical documents, agricultural material distribution records, and field test archives. Data update frequency varies by business stage: production and quality inspection data is updated with each batch output, distribution records are synced daily, and formula documents are only updated when technical revisions are made. Document structure includes fields such as batch number, active ingredient content, standard application dosage, shelf life, and compliance standard number. Common units include kilograms, liters, milligrams/kilogram, and days, which are standard for agricultural and chemical industries.

## Constraints Imposed on Multi-turn Dialogue and Prompt Engineering
The fertilizer and pesticide category has a high volume of professional terms, clear field units, and significant cross-document variations. Multi-turn dialogue must fully retain key context information such as batch numbers and dosage units to prevent ambiguity. Update frequencies for different business data vary widely: distribution records are synced daily, while formula documents are only updated after technical revisions. Prompts must explicitly specify the call priority of corresponding data sources to ensure query result timeliness. Compliance standard documents and production ledgers use different field logic. Multi-turn dialogue must automatically switch to match the field rules of the relevant document when compliance verification is required, to ensure response accuracy.

## Three Common Configuration Errors
- Symptom: An error occurs when uploading attachments or datasets after upgrading the version, with a prompt of `fail to create post presigned url` or an interface upload failure. Cause: Cross-domain rules and permissions for S3 storage are not correctly configured, or storage configuration parameters were not synchronized and updated after the version upgrade.
- Symptom: Exclusive fertilizer and pesticide fields cannot be correctly associated in multi-turn dialogue, such as incorrect display of dosage units. Cause: The prompt does not clearly specify mapping rules between fields and units, leading to loss of context information.
- Symptom: Template imports can upload files normally, but uploads fail in the dialogue window. Cause: The file upload interface path for the dialogue window is not unified with the dataset upload interface, and the interface path change after the version upgrade was not synchronized and adjusted.

## How to Verify Configuration Correctness
- Initiate a multi-turn dialogue that includes batch numbers and dosage units, and confirm all key information is fully retained in the context.
- Trigger a file upload operation, and verify that a pre-signed URL can be generated normally and the upload completes successfully.
- Modify prompt variables, and confirm that the `variables` parameter correctly associates exclusive business fields and fills them into the response.
- Switch between different sessions, and confirm that the context bound to `chatId` does not become confused across sessions.
