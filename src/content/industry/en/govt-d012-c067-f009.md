# Internal Office and Employee Services for Fertilizer and Pesticide Industries: Model Integration and Configuration

## What the data for this category looks like
Data sources include internal enterprise production and sales ledgers, the Ministry of Agriculture and Rural Affairs agrochemical product registration database, and field trial records from regional agricultural technology promotion teams.
Product registration information syncs every quarter. Field farming data updates monthly per farming cycles. Daily sales and inventory data updates daily.
Most documents use structured formats, with fields including product name, registration certificate number, active ingredient content, applicable crops, recommended application dosage, pre-harvest interval, and more. Common units include grams per hectare, milliliters per mu, days, and others. A small number of long text documents include full product usage instructions and field guidance plans.

## Constraints Imposed on Model Integration and Configuration
This content uses the configuration logic of FastGPT v4.17.0. The following constraints arise from the above data characteristics:
Many structured fields with diverse units require configuring parameters that support multi-field structured parsing during model integration, to adapt to semantic recognition for professional units.
Differences in update frequencies across data types require separate configuration of vector database sync triggers. High-frequency inventory data uses real-time sync logic. Low-frequency registration information uses a scheduled sync strategy.
A high proportion of professional agrochemical terms requires selecting models with semantic understanding capabilities in the agricultural chemical field, to avoid field parsing deviations or unit recognition errors.
Wide variation in single document length requires properly configuring context-related parameters, to adapt to processing needs for both short-text field records and long-text product manuals.

## How to Set Configurations
| Configuration Item | Recommended Range | Rationale |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | Fertilizer and pesticide-related documents include long-text product manuals and multi-field structured data, requiring coverage of complete context |
| `temperature` | 0.2–0.4 | Stable professional term parsing results are needed, to avoid generating irrelevant non-business content |
| `quoteMaxToken` | 1500–2000 characters | Single referenced text lengths for field records and product ledgers mostly fall within this range, ensuring complete referenced content |
| `toolChoice` | auto | Automatically select whether to call tools for structured data queries based on tasks, adapting to multiple types of business scenarios |
| `AIPROXY_API_ENDPOINT` | Enterprise-built exclusive proxy address | Ensure transmission security of internal agrochemical sensitive data, avoiding business information leaks via external interfaces |
| `AIPROXY_API_TOKEN` | Exclusive token uniformly assigned by the enterprise | Implement fine-grained control over interface access permissions, preventing unauthorized model calls |

## Three Common Mistakes
- Phenomenon: A call returns the error "This token is not authorized to use the model: text-embedding-3-large". Cause: The corresponding token is not assigned permissions for the embedding model available for the fertilizer and pesticide scenario in channel configuration.
- Phenomenon: Pre-configured reranking models cannot be selected when creating an application. Cause: Reranking model parameters for the agrochemical scenario are not correctly adapted in the configuration file, or the configured model has not passed validity verification.
- Phenomenon: The prompt "No available channels for model gpt-4o under current group default" is displayed. Cause: The gpt-4o channel is not bound to the default group, or the token permissions configured for the channel do not cover the model call scope required for fertilizer and pesticide business.

## How to Verify Proper Configuration
- Launch query tests for agrochemical product registration information. Check whether returned results include correct business fields, and whether field units are recognized as required.
- View vector database sync logs. Confirm that data of different update frequencies has completed sync according to configuration rules, with no abnormal interruptions or omissions.
- Check interface call logs. Confirm that permission verification for `AIPROXY_API_TOKEN` has passed, with no unauthorized access error messages.
- Test reranking model calls. Confirm that returned agrochemical document sorting meets the relevance requirements of the business scenario. Sorting rules can be adjusted based on actual business needs.
