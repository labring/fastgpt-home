# Internal Office and Employee Services for Pharmaceutical Distribution: Forms and Interactions

## What the data for this category looks like
Internal office data for pharmaceutical distribution mainly comes from inventory management systems, temperature and humidity monitoring devices, employee attendance systems, and GSP compliance record ledgers. Data update rhythms vary: inventory documents are updated in real time as business flows proceed, temperature and humidity data is synchronized minute by minute, and attendance and compliance records are updated on a natural day basis. A single document usually includes fields such as generic drug name, approval number, inbound/outbound quantity, temperature and humidity thresholds, employee ID and job title. The unit of quantity is box, case, or piece. The units for temperature and humidity are ℃ and %RH. The time format is YYYY-MM-DD HH:mm:ss.

## What constraints these characteristics impose on the forms and interactions link
Since data sources are scattered and update rhythms differ, forms must support real-time synchronization of real-time fields such as temperature and humidity to avoid manual entry errors. Batch documents with multiple fields require forms to be split by business module to prevent operational errors caused by overly long pages. The mandatory nature of GSP compliance fields requires forms to be configured with strict validation rules; omitted fields cannot be submitted. The feature of binding employee positions and permissions requires the interaction link to filter editable fields based on the currently logged-in user's position, improving data accuracy.

## How to configure settings
This configuration applies to FastGPT v4.17.0

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Form block configuration | Split by business module, each block 100–150 characters | Adapt to the multi-field structure of pharmaceutical distribution documents and simplify single-page operation complexity |
| User permission selection | Associate with job permission groups, only display editable fields for the current job | Match the binding feature of employee positions and data permissions to avoid unauthorized operations |
| Form input validation | Add numeric range validation for temperature and humidity fields, range 0–40℃, 30%–90%RH; add format validation for drug number fields | Meet GSP compliance requirements and reduce data entry errors |
| Dynamic field update | 60-second interval, synchronize temperature and humidity monitoring data | Adapt to the minute-level update rhythm of temperature and humidity data and ensure form data timeliness |
| Submission timeout setting | 30 seconds | Adapt to the bandwidth requirements of batch document submission and avoid request interruptions caused by excessive data volume |
| Batch submission rate limiting | Limit the number of forms submitted simultaneously by a single user to no more than 6 | Match the upper limit of interactive pages that can be opened on a single device and prevent concurrent requests from exceeding service thresholds |

## Three common mistakes
- Submission fails after opening more than 6 interactive pages on a single device, with a connection error prompt. The cause is that batch submission rate limiting is not configured, and concurrent requests exceed service thresholds.
- The tool call return content includes an abnormal fragment starting with `Human <Instruction>`. The cause is that the context truncation rule for `userSelect` is not configured, and overly long instructions entered by employees interfere with the model's system prompt logic.
- Variable references in the knowledge base selection link are invalid, and retrieval results do not match the form input parameters. The cause is that form fields are not correctly bound to knowledge base retrieval parameters, resulting in variables not being passed in the interaction flow.

## How to confirm the configuration is complete
- Open 7 interactive pages and submit test data to confirm that there are no concurrent submission failures or connection error prompts.
- Enter an overly long custom instruction and check that the tool call return content does not include an abnormal fragment starting with `Human <Instruction>`.
- Enter 45℃ in the temperature and humidity field to confirm that the form pops up a numeric range validation prompt.
- Bind form field variables in the knowledge base selection link, enter a drug approval number, and confirm that the retrieval results match the input parameters.
