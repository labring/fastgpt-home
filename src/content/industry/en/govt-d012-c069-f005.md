# Internal Office and Employee Services for Hazardous Chemicals Storage and Transportation: Tool Calling and Plugins

## What the data for this category looks like
Hazardous chemicals storage and transportation data mainly comes from the enterprise's internal storage and transportation management system, safety supervision department supervision platforms, and on-site temperature and humidity and liquid level sensors. Data update rhythm is divided into two categories: real-time sensor-collected tank area temperature and humidity and liquid level data updates every 1-5 minutes. Static data such as inventory ledgers, transportation batches, and inspection reports updates daily. A single data document includes fields such as hazardous chemical number, common name, CAS number, storage tank number, temperature and humidity thresholds, net weight, and inspection report number. Units include tons, cubic meters, degrees Celsius, hours, etc. Some fields are required and have fixed formats.

## What constraints these characteristics impose on the "tool calling and plugins" link
The high-frequency updates of real-time sensor data require tool calling to have a short response window to avoid data failure caused by timeouts. The fixed format of static data requires tool calling parameters to strictly verify required fields to prevent invalid data from being passed in. Data from different sources needs to be unified in format through plugins, so plugins must support adaptive conversion of multi-source data. In addition, hazardous chemical data involves safety supervision requirements, so tool calling and plugins must have permission verification capabilities, and only allow authorized roles to access.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Adapts automatic tool selection for the multi-field hazardous chemical data, no manual function specification required, compatible with FastGPT v4.17.0 tool calling logic |
| Tool calling timeout | `30 seconds` | Hazardous chemical real-time sensor data requires fast response; excessive timeout will cause data to expire |
| Parameter validation switch | Enabled | Mandatorily verifies required fields such as CAS number and storage tank number for hazardous chemical data to prevent format errors |
| Plugin data pull interval | `5–15 minutes` | Balances the real-time performance of hazardous chemical inventory data and system resource usage |
| `functionCall` | `strict: true` | Mandatorily matches the required field format for hazardous chemical data to avoid invalid tool calls |
| Plugin cache limit | `100 MB` | Stores recent hazardous chemical data query results to reduce the frequency of repeated calls to storage and transportation system APIs |

## Three common mistakes
- Phenomenon: Tool calling returns an error of the type `400 <400> InternalError.Algo.InvalidParameter: The tool call i`. Cause: The parameter validation switch is not enabled, and a tool calling request missing required fields such as CAS number and storage tank number is passed in.
- Phenomenon: Timeout occurs when obtaining temperature and humidity data via the time application plugin. Cause: The tool calling timeout setting is too long, exceeding the business response window for hazardous chemical real-time data.
- Phenomenon: Unable to normally call MCP services to connect to the hazardous chemical storage and transportation system. Cause: The plugin's interface permission whitelist is not configured, and the API address of the storage and transportation system is not included in the allowed call range.

## How to confirm the configuration is correct
- Initiate a tool calling request that includes a valid hazardous chemical CAS number and storage tank number, and check whether the returned result contains correct data for the corresponding fields.
- Simulate passing in a tool calling request with missing required fields, and confirm that a clear error message indicating parameter validation failure is returned.
- Adjust the plugin data pull interval to `1 minute`, and verify that the system pulls hazardous chemical inventory data at the set frequency.
- View the plugin call logs to confirm that the `toolChoice` and `functionCall` configuration parameters have been correctly loaded.

The values provided are common starting points and should be evaluated against the reader's own samples.
