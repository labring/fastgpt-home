# Internal Office and Employee Services for Hazardous Chemicals Storage and Transportation: Model Access and Configuration

## What Data for This Category Looks Like
Business data for hazardous chemicals storage and transportation mainly comes from internal enterprise storage and transportation ledgers, tank farm real-time monitoring systems, monthly inspection records, employee operation logs, and emergency response archives. Data update frequencies fall into three categories: real-time (tank pressure, liquid level and other monitoring data), daily (storage and transportation ledger inbound and outbound records), and weekly (inspection summary reports). The document structure includes both structured tabular data (fields include material code, storage volume, batch, etc., with units of tons, cubic meters, hours) and unstructured text (such as inspection descriptions, emergency response process documents). A single emergency response report can be dozens of pages long.

## What Constraints Do These Characteristics Impose on the Model Access and Configuration Link
The mixed structured and unstructured data feature requires model access configuration to support both precise recognition of professional terms and structured field extraction and matching. The high-frequency update feature of real-time monitoring data requires the context window configuration to cover a sufficiently long history of data to avoid loss of key business information. The dense professional terminology feature of hazardous chemicals business requires model output to strictly comply with industry specifications to prevent deviations in professional expressions. The mixed input demand for multiple types of data requires configuration to adapt to parsing of data sources in different formats, avoiding data loss due to format incompatibility.

## How to Set the Configuration
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `maxContext` | `8000–12000 token` | Hazardous chemicals storage and transportation data includes multiple inspection logs and monthly ledgers, with a large total length. It needs to cover at least 3 consecutive days of business data |
| `maxTokens` | `2000–3000 token` | Employee inquiries mostly involve single operation guidance or single ledger verification, so overly long output content is unnecessary |
| `temperature` | `0.2–0.4` | Hazardous chemicals business requires strict accuracy to avoid hallucination deviations in professional terms or operation guidance |
| `toolChoice` | `auto` | Automatically select whether to call the internal ledger query tool to meet the rapid extraction demand of structured data |
| `AIPROXY_API_ENDPOINT` | `http://internal-ai-proxy:8080/v1` | Call the model through the enterprise internal proxy to avoid public network access restrictions and protect business data security |
| `AIPROXY_API_TOKEN` | `Exclusive token generated by the enterprise key management system` | Strictly control model call permissions to prevent business data leakage caused by unauthorized access |

## Three Common Configuration Errors
- Symptom: After upgrading FastGPT to version v4.17.0, the configured specified large model reverts to the default model after saving and restarting the chat. Cause: The model binding parameter was not locked in the application configuration, or the storage path of the configuration item changed after the version upgrade.
- Symptom: After using marker to process uploaded hazardous chemicals inspection PDF files, processing takes more than 10 minutes. Cause: Reasonable chunking parameters were not configured, or local vector acceleration was not enabled, resulting in low efficiency of large file splitting and encoding.
- Symptom: An error is prompted when adding a token via OneAPI: Error 1406 (22001): Data too long for column 'models'. Cause: The configured model identifier string length exceeds the database field limit, and a short name was not used instead of the full model path.

## How to Confirm the Configuration Is Complete
- View the model configuration page of the FastGPT application to confirm that the bound large model name matches the preset configuration.
- Upload a hazardous chemicals storage and transportation inspection log PDF to check whether the processing progress bar completes basic parsing within 5 minutes.
- Submit a test question containing professional terms, such as "How to handle toluene storage volume exceeding the limit in a certain tank farm", to confirm that the returned result contains accurate professional expressions.
- Check the system operation logs to confirm that the parameters of the model call request match the configuration items, and there are no abnormal error messages.
