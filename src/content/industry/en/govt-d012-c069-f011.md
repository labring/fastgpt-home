# Internal Office and Employee Services for Hazardous Chemical Storage and Transportation: Forms and Interactions

## What the data for this category looks like
Internal office data for hazardous chemical storage and transportation mainly comes from the tank farm real-time monitoring system, storage and transportation ledger management system, employee patrol mobile terminal, and internal approval workflow platform.
Real-time data such as tank temperature and pressure is updated every 5 minutes. Storage and transportation ledgers are updated daily. Patrol records are submitted by employees per shift. Approval data is updated immediately with workflow nodes.
Document structure uses structured forms, including fields such as tank number, hazardous chemical name, outbound quantity (tons), outbound time, patrol temperature (℃), patrol pressure (kPa), and approver. Some fields must match the official hazardous chemical list. Units are fixed and cannot be modified arbitrarily.

## What constraints these characteristics impose on the "forms and interactions" link
Structured data for hazardous chemical storage and transportation has compliance requirements. Forms must strictly match preset fields and units to prevent non-compliant inputs.
High-frequency updates of real-time monitoring data require forms to support quick filling and variable binding, reducing manual input errors.
Approval workflows have field linkage needs, requiring direct binding of form inputs to approval rules. For example, automatically trigger upper-level approval when outbound quantity exceeds a preset threshold.
Some storage and transportation data must be submitted in JSON format. Forms must support structured input and variable extraction to ensure data format meets docking requirements of downstream systems.

## How to configure
FastGPT v4.17.0, the following configuration items can directly adapt to the hazardous chemical storage and transportation scenario:

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `formInput` | Enable variable binding mode, support JSON format input | Most hazardous chemical storage and transportation data uses structured JSON format, need to bind system real-time variables and ledger data |
| `userSelect` | Preset official hazardous chemical list options, restrict manual input | Comply with hazardous chemical management compliance requirements, ensure material names match the official list |
| Form validation rules | Add positive floating-point number validation for quantity fields, unit fixed to tons | Match measurement specifications for storage and transportation data, avoid invalid inputs |
| HTTP response JSON extraction | Configure JSONPath extraction rules, bind downstream node variables | Can obtain real-time temperature and pressure data from tank farm monitoring systems |
| Tool call timeout setting | Set to 30 seconds | Adapt to request response duration of real-time monitoring data |

## Three common configuration errors
- Phenomenon: JSON input box cannot select system variables, fields are empty after submission. Cause: Variable binding mode for `formInput` is not enabled, only static JSON text input is supported.
- Phenomenon: JSONPath variables extracted by HTTP request node cannot be passed to downstream nodes. Cause: Variable mapping switch is not enabled in node configuration, or JSONPath path is written incorrectly.
- Phenomenon: Incorrect approval workflow is triggered after form submission. Cause: Linkage logic between preset options of `userSelect` and approval rules is not bound, resulting in failed field verification.

## How to confirm configuration is complete
- Open the form editing page, select the JSON input component, check if the variable selection pop-up appears, and can bind system ledger or real-time monitoring variables.
- Configure the HTTP request node, enter a test URL, fill in the JSONPath extraction rule, check if the preview area displays the extracted test data.
- Select the `userSelect` component, check if the preset options include standard material names from the official hazardous chemical list.
- Submit a test form, check if correct field validation prompts and approval workflow are triggered.
