# Internal Office and Employee Services for Power Generation Equipment Manufacturing: Document Parsing and Chunking

## What this category of data looks like
Internal office data for power generation equipment manufacturing includes equipment operation and maintenance manuals, maintenance work records, parts technical drawing descriptions, safety operation procedures, employee post training courseware, and similar materials. Update cycles adjust based on new model releases, monthly maintenance archiving, and quarterly safety procedure revisions, with no fixed schedule. Most documents are in PDF format, containing long-form technical paragraphs, structured maintenance record tables with fields such as equipment number, fault code, and processing duration, parts drawings with industrial symbols, and parameter tables. Field units mostly use industrial standard units including MW, MPa, millimeters, and kilowatt-hours.

## What constraints these characteristics impose on document parsing and chunking
Power generation equipment documents primarily contain long-form technical content. When splitting content, retain complete semantics of technical descriptions to avoid breaking professional logic. Documents include structured maintenance records and chart-integrated drawings. Use separate parsing rules for unstructured text and structured fields, otherwise key parameters will be lost. Single documents have large file sizes, which create higher requirements for upload size limits and parsing timeout periods. The recognition accuracy of industrial units and symbols directly impacts subsequent retrieval accuracy. Standard OCR modes cannot meet the parsing needs of drawings and tables.

## How to set the configuration
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `chunkSize` | 800–1200 characters | Adapts to long paragraph semantic units in power generation equipment operation and maintenance manuals, avoiding splitting critical technical descriptions |
| `chunkSplitter` | By paragraph + semantic boundary | Adapts to long text with engineering terms, preventing disruption to the complete logic of technical instructions |
| `customPdfParse` | Enable high-precision OCR mode | Adapts to PDF documents with parts drawings and industrial parameter tables, restoring structured fields |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Supports batch uploads of single large unit operation and maintenance manuals or multiple archived documents |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Meets the time requirements for long-text parsing, preventing mid-process interruption of large PDF document parsing |
| `chunkSettingMode` | Manual configuration | Adapts to the special structure of power generation equipment documents, enabling flexible adjustment of chunking rules |

## Three common errors
1. Phenomenon: After uploading a PDF containing industrial drawings, the parsing result lacks equipment parameter information, and the interface shows an OCR Error alert. Reason: The `customPdfParse` high-precision OCR mode is not enabled. Standard parsing modes cannot recognize industrial symbols and parameter tables within drawings.
2. Phenomenon: After uploading certain documents in simple mode, no matching search results appear, and only error prompts are displayed. Reason: `chunkSettingMode` is not configured for manual mode. Default chunking rules cannot adapt to the semantic boundaries of long-form technical manuals, leading to incorrect splitting of key content.
3. Phenomenon: After uploading an ultra-large unit operation and maintenance manual, the parsing task times out and fails. Reason: The value set for `PARSE_FILE_TIMEOUT_SECONDS` is too low to complete full parsing of a PDF document with over 1000 pages.

## How to confirm the configuration is applied correctly
- Upload a PDF document containing engineering drawings and parameter tables, and check if the parsed text includes fields such as equipment model and operating parameters to verify that the `customPdfParse` configuration is active.
- Upload a large operation and maintenance manual within the 1000 MB limit, and check if the parsing task completes within the time frame set by `PARSE_FILE_TIMEOUT_SECONDS` without timeout errors.
- Search for professional terms within the document, and check if returned results include complete technical description fragments to confirm that the `chunkSize` and `chunkSplitter` configurations perform as expected.
- Access the system settings page, and confirm that the configured value of `UPLOAD_FILE_MAX_SIZE` is not lower than the maximum size of commonly uploaded documents.

The values provided here are common starting points and should be measured against the reader's own samples.
