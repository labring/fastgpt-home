# Internal Office and Employee Services for State-owned Industrial Funds: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Data sources for internal office work of state-owned industrial funds include internal investment research documents, compliance approval archives, employee management rules, project ledgers, and regulatory policy documents.
Update cadence: Investment research documents are updated quarterly. Policy documents are updated in real time per regulatory requirements. Employee handbooks are updated irregularly when organizational structures adjust.
Document structure includes structured fields and unstructured content. Structured fields include project code, investment amount, compliance clause number, department affiliation, and others. Unstructured content includes long-form investment research minutes, PPT presentation materials, and PDF compliance documents. Field units include 100 million yuan, project cycle (months), approval document number, and similar items.

## What constraints do these characteristics impose on the knowledge base retrieval and recall process
The document characteristics of state-owned industrial funds create multiple constraints for retrieval and recall.
Long-form investment research minutes require proper splitting to retain semantic integrity. Avoid chunks that are too short and cause context breaks, or too long and exceed the context window.
Documents with precise fields need to balance semantic recall and exact field matching, preventing invalid results that only match semantics but do not meet field requirements.
Irregularly updated regulatory policies and project ledgers require incremental synchronization mechanisms to be configured, ensuring retrieved data matches the latest business status.
Multimodal investment roadshow PPTs need to support mixed text-image retrieval, avoiding loss of critical visual associated information by only extracting text.

## Three Common Misconfigurations
- Phenomenon: After importing PPT-format investment roadshow documents, retrieval results only include text content and no image-related information. Cause: The text-image association retrieval configuration for multimodal documents is not enabled. Only text content is extracted, and critical visual information in the images is not associated.
- Phenomenon: Retrieval results have scattered citation sources, and multiple associated documents for the same project cannot be displayed in a merged view. Cause: The search citation merging function is not enabled. Document results for the same business topic are not aggregated, leading to reduced efficiency of retrieval result display.
- Phenomenon: Real-time project data returned by HTTP interfaces cannot be used as a knowledge base retrieval source. Cause: External data source synchronization rules are not configured. Structured data returned by HTTP interfaces is not converted to a document format recognizable by the knowledge base, so it cannot be included in the retrieval scope.

## How to Verify the Configuration is Correct
- Upload a test multimodal document, initiate a targeted retrieval, and confirm that returned results include text and associated visual information.
- Submit a query that includes structured fields, and confirm that returned results match documents with the specified fields with no irrelevant content.
- Submit a query that uses internal industry abbreviations, and confirm that retrieval results cover expanded synonymous expression content.
- View the citation module of retrieval results, and confirm that documents for the same business topic are displayed in an aggregated manner.
