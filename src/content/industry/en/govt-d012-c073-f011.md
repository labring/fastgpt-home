# Internal Office and Employee Services for State-owned Industrial Funds: Forms and Interactions

## What the data for this category looks like
The internal office data for state-owned industrial funds mainly comes from investment decision management systems, investor ledger modules, financial accounting systems, and human resources approval modules. Data update cycles cover three categories: daily (investment decision progress, approval workflow status), monthly (financial revenue and expenditure, capital contribution arrival status), and quarterly (investor equity changes). Most documents are structured forms, including types such as project initiation applications, employee business trip approvals, and salary adjustment applications. Fields include project number, contribution amount, approval node, submission time, and more. Units include ten thousand yuan, person-times, natural days, and more. The proportion of unstructured text with excessive free-form content is low; most documents use structured fill-in content.

## What constraints these characteristics impose on the forms and interactions link
Structured field types require form controls to match the corresponding format. For example, amount fields must use numeric input boxes instead of free text boxes. Enumeration fields must use dropdown selection controls. Data with different update cycles must adapt to interaction refresh logic. For example, the user list for approval nodes must be refreshed regularly according to approval hierarchy to avoid outdated permission configurations. Units attached to fields require input validation rules to automatically bind unit prompts, preventing missing or incorrectly added units during input. Compliance requirements for state-owned businesses require adding audit trail steps in interactions, such as a secondary confirmation pop-up before submission, to ensure operations are traceable.

## How to configure the settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Basis for This Approach |
| ---- | ---- | ---- |
| Form input validation | Restrict numeric format for amount fields and attach ten thousand yuan unit prompts | Internal forms of industrial funds include amount fields such as contribution amount, to avoid unit input errors |
| User selection scope | Limit to users from the superior and same-level departments of the current approval node | Approval for state-owned industrial funds must follow hierarchical workflows, so the permission scope of selectable users must be restricted |
| Pre-submission confirmation | Enable secondary pop-up verification for `formInput` | State-owned businesses require retaining operation traces to avoid compliance risks from accidental submission |
| Timeout threshold | `300 seconds` | Cross-department approval interaction durations are usually long, so sufficient operation time must be reserved |
| Field linkage rules | Automatically load required contribution amount fields when "equity investment" is selected as the project type | Different project types of industrial funds correspond to different required form fields, requiring automatic adaptation |
| Reranking result recall | Configure to return `top 5` results | Match the multi-document association requirements of internal fund forms to avoid insufficient recall results |

## Three common mistakes
- Phenomenon: After the reranking model is called, only 1 result with the highest similarity is returned, and the specified number of results is not returned as configured. Cause: The multi-result recall switch for `formInput` is not enabled, causing reranking results to be forcibly truncated.
- Phenomenon: After submitting the form, the associated due diligence document field displays as empty and cannot be associated normally. Cause: The permission filtering rule for `userSelect` is not configured, causing users not in the approval node to be unable to access the corresponding document library.
- Phenomenon: After entering "500 ten thousand yuan" in the amount field, the system automatically clears the "ten thousand yuan" suffix, causing verification failure. Cause: The unit adaptation rule for form input validation is not enabled, and only pure numeric input is allowed.

## How to confirm the configuration is complete
- Open any internal form for an industrial fund, test whether the ten thousand yuan unit prompt is automatically displayed when entering the amount field, and whether a verification prompt pops up when entering non-numeric characters.
- Select the position corresponding to the approval node, confirm that the dropdown user list only displays accounts from the current department and superior levels, with no irrelevant users appearing.
- Trigger the secondary confirmation pop-up when submitting the form, confirm that the system generates an audit log record containing the operator and submission time after submission.
- Call the reranking model for testing, check whether the number of returned results matches the recall number configured for `formInput`, and verify that the multi-result recall function works normally.
