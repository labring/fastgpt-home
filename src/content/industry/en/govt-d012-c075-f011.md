# Internal Office and Employee Services for State-owned Capital Investment Companies: Forms and Interactions

## What data for this category looks like
Internal office data for state-owned capital investment companies comes primarily from state-owned assets supervision and reporting systems, internal group OA platforms, human resource management platforms, and financial management systems. Data update rhythms fall into three categories:
- State-owned assets monthly reports sync with the natural month
- Employee attendance data updates daily
- Project review forms are submitted on demand

Most documents are structured forms, with fields including state-owned assets filing codes, project investment amounts, employee IDs, and department levels. All fields must align with state-owned assets supervision formats. Common units include ten thousand yuan, person-times, and natural days.

## Constraints on forms and interactions
A high proportion of structured fields requires form components to support strict format validation. This blocks submission of data that does not meet state-owned assets supervision requirements.
Multi-data source synchronization needs require the interaction layer to support dynamic pulling of field options from different systems. This eliminates manual entry errors.
Sensitive fields such as state-owned assets filing codes require permission isolation. Only authorized positions can edit these fields.
Differing update rhythms across data types require forms to support configurable scheduled refresh or manual refresh triggers. This ensures data stays up to date.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Divided into three categories: text, number, and dropdown selection. Number fields restrict input range, with a maximum input length of 2000 characters | Most internal forms for state-owned capital investment companies use structured fields, and must match state-owned assets supervision format requirements |
| `userSelect` | Filter selectable users by department level, with a maximum of 100 selections per operation | Internal office work restricts operation scope via permissions to avoid cross-level unauthorized actions |
| Dynamic knowledge base binding | Bind corresponding knowledge bases according to business scenarios, support linkage switching with the `userSelect` component | Knowledge bases for state-owned capital investment companies are split into scenarios including projects, human resources, and finance, and need to be called as needed |
| Voice input configuration | Only enable for non-sensitive fields, set input timeout to 30 seconds | Voice input carries a high risk of recognition errors, sensitive fields require precise input, and a timeout prevents invalid waiting |
| Form verification rules | Trigger timing is before submission and during real-time input, error prompts match state-owned assets field specifications | Submitted data must comply with state-owned assets supervision format and content requirements |

## Three common misconfigurations
- Phenomenon: An unmarshal_resp error appears when converting text via voice input, and the interface displays an interface call failure. Cause: The voice input timeout parameter is not configured in FastGPT v4.17.0. This triggers parsing exceptions during long voice input.
- Phenomenon: For a workflow with dynamic knowledge base selection configured, the AI response does not reference matching documents. Cause: The selected value of the `userSelect` component is not correctly bound to the knowledge base variable. This means the specified knowledge base is not called during search.
- Phenomenon: An error occurs when executing a database connection using a SQL statement passed via a variable, but manual input of the same SQL works normally. Cause: No format validation is applied to the variable content. The passed SQL may contain special characters or fail to match database field specifications.

## How to confirm configuration is complete
- Submit a test form, and confirm that structured fields automatically validate formats and that error prompts align with state-owned assets field specifications.
- Select users from different departments, and confirm that the `userSelect` component correctly filters the selectable range, with no more than 100 selections per operation.
- Trigger voice input, enter a test text segment, and confirm that the conversion result is accurate with no parsing errors.
- Configure dynamic knowledge base binding, switch to different knowledge bases, and initiate a search. Confirm that returned results come from the selected knowledge base.
