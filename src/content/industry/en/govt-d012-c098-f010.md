# Internal Office and Employee Services for Civil Aviation Airports: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Knowledge sources for civil aviation airport internal office and employee services include operation control manuals, ground service specifications, security inspection operation procedures, maintenance and repair regulations, flight support emergency plans, and similar documents. Update schedules adjust flight support details every six months per flight season, update operation documents per equipment maintenance cycle, and update specifications quarterly per safety policy requirements. Documents are structured by departments such as operation control, ground service, and security inspection, and include fields like responsible positions, operation steps, and emergency response procedures. Units include sorties, minutes, passenger trips, parking stands, and other specialized units.

## What constraints these characteristics impose on the knowledge base retrieval and recall link
Since knowledge is stored by department, retrieval must bind the corresponding department's knowledge base set to narrow the search scope and improve efficiency. The presence of specialized terminology and fixed units requires the retrieval model to have specialized word vector matching capabilities to avoid semantic matching deviations. Different documents have different update cycles, so the knowledge base must support automatic synchronization rules configured by document type to ensure recalled content is the latest version. Long documents must be split by post operation logic units to avoid destroying process integrity and affecting recall accuracy.

This explanation is based on the configuration rules of FastGPT v4.17.0.

## How to set configurations
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | `0.72–0.88` | Civil aviation internal documents contain a large number of specialized terms and post-specific processes. A threshold that is too low introduces redundant content unrelated to the target post, while a threshold that is too high misses similar emergency response scenarios |
| `limit` | `Top 5–7 entries` | Airport internal office knowledge entries are mostly operation specifications for specialized posts. Returning too many entries at one time exceeds the context carrying limit, resulting in confused answer logic |
| `usingReRank` | Enabled | Airport documents contain a large number of process descriptions with similar wording. Reranking filters semantically duplicate recall results and improves answer accuracy |
| `datasetSearchUsingExtensionQuery` | Enabled | Employee questions often contain colloquial expressions. Query optimization converts colloquial requests into professional retrieval terms to match standard content in post manuals |
| `collectionIds` | Bind corresponding knowledge base IDs by department | Internal airport knowledge is stored classified by departments such as operation control, ground service, and security inspection. Binding the corresponding IDs narrows the search scope and improves recall efficiency |
| `searchMode` | `vector + keyword hybrid` | Civil aviation internal knowledge includes both structured processes and unstructured descriptions. Hybrid search balances semantic matching and precise keyword matching |

## Three common mistakes
- Phenomenon: No citation identifier appears at the end of a knowledge base answer paragraph. Cause: The citation generation configuration of FastGPT is not enabled, or the source document's metadata is not correctly bound to the recall results.
- Phenomenon: After a static page is updated, knowledge base content is not synchronized, and retrieval results still show old versions. Cause: The automatic synchronization trigger rule for the static page is not configured, or the update frequency setting does not match the flight season and equipment maintenance cycle.
- Phenomenon: Within the same conversation window, the second question receives an off-topic answer. Cause: The session context isolation configuration is not enabled, or the `limit` parameter value is too high, causing context overflow and overriding the retrieval logic of the new question.

## How to confirm the configuration is complete
- Submit a post question containing specialized terms, and check whether the source of the recall result is bound to the knowledge base document of the corresponding department.
- Submit a colloquial question, and check whether the answer is converted to professional expression and matches the standard process content.
- Trigger a static page update task, and check whether the synchronization log in the knowledge base backend shows a successful update.
- Submit two consecutive questions from different posts, and check whether the answers match the knowledge content of the corresponding posts respectively, with no context interference.
