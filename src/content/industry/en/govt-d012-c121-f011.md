# Internal Office and Employee Services for Expressway Operations: Forms and Interactions

## What Data for This Category Looks Like
Internal data for expressway operations comes from toll station toll collection systems, service area operation and maintenance systems, monitoring center dispatch platforms, and employee attendance systems.
Update cadence: Vehicle passing data updates in real time. Scheduling and supply material data updates daily. Inspection data updates per individual inspection cycle.
Document structure includes work order record sheets, scheduling sheets, equipment inspection sheets, and traffic volume statistics sheets.
Fields and units:
- Lane number (unit: count)
- Traffic volume (unit: vehicle trips)
- Inspection time (unit: YYYY-MM-DD HH:mm)
- Remaining supply material quantity (unit: pieces)
- Employee ID (no unit)

## Constraints Imposed by These Characteristics on Forms and Interactions
Real-time vehicle passing data requires form inputs to support fast synchronization, to prevent data inconsistency caused by delays.
Multi-field work order forms must be split by business scenario, such as separating toll work orders and operation and maintenance work orders, to reduce filling complexity.
Forms used for cross-department collaboration must have permission ranges configured, to only allow employees in corresponding positions to fill out or review.
Equipment inspection forms must set required fields, such as fault level and rectification time limit, to avoid missing key information that affects operational safety.
Employees may wear gloves or have oil stains on their hands, so forms must support non-contact interaction methods such as voice input.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `formInput` | Current employee ID, current lane number from global variables | Ensures expressway operation work orders are bound to handlers and corresponding work areas, to clarify responsibility |
| User selection scope | Operation/toll personnel under the current department | Internal office work only allows employees in the same position to collaborate on corresponding business, to prevent cross-department misoperations |
| Form submission validation | Required fields are lane number, fault type, rectification time limit | Prevents invalid work order submissions, and ensures standardization of operation and maintenance and toll collection processes |
| `userSelect` | Top 5 matched pending work orders | The number of pending work orders for expressway operations is moderate, limiting entry count improves query efficiency |
| Password-free login voice input settings | Input timeout period 5 seconds, maximum audio size 100 MB | Adapts to scenarios where employees have oil stains on their hands, to avoid interaction failures caused by timeout or oversized files |
| Workflow trigger delay | Trigger 10 seconds after form submission | Waits for cross-system data synchronization to complete, to prevent workflows from calling outdated unupdated data |

## Three Common Mistakes
- Symptom: The `formInput` node’s default value references a global variable and the field is empty. Cause: Global variables for expressway operation-specific fields such as current employee ID and lane number are not configured, or the variable scope does not cover the current workflow.
- Symptom: Voice input content does not appear after submission on a password-free login page, or the timer remains at 00:00 during long-press input. Cause: The voice input timeout threshold is not configured, or audio upload is not completed before submission due to network delay.
- Symptom: Batch work order execution tasks are interrupted early, showing a runtime limit exceeded error. Cause: The workflow runtime count configuration item is not adjusted, and the default value does not adapt to batch work order processing scenarios.

## How to Verify Correct Configuration
- Submit a test work order, and check if the `formInput` node automatically fills in the current employee ID and corresponding lane number.
- Test password-free login voice input, confirm that the input duration is normal and the content is successfully displayed in the form.
- Trigger the configured workflow, check that it starts according to the set delay time and the runtime count meets expectations.
- Submit the form without filling in required fields, confirm that the corresponding validation prompt pops up.
