# Code and Change Review Assistance for IT Asset Inventory: Citation Sources and Traceability

## What This Category of Data Looks Like
Data sources for this category include asset management systems, procurement systems, financial fixed assets modules, and terminal management platforms. Four types of documents are regularly produced: asset ledgers, inventory lists, loan and return forms, and scrap applications. Fields include asset number, specification model, user, storage location, usage status, purchase date, scrap status, and others.
Data is updated monthly, quarterly, or annually. Each update covers newly added, transferred, and scrapped asset entries in the current period. There is no requirement for real-time high-frequency updates.

## Constraints Imposed on Citation Sources and Traceability
The monthly, quarterly, or annual update rhythm means frequent full data source refreshes are not needed during traceability. Only incremental data needs to be synced per update cycle.
Different document types have varying field priorities. Asset numbers in asset ledgers serve as core traceable identifiers. Loan and return forms require linking the user field to complete ownership verification. Dedicated field matching rules must be configured for each document type.
Data sources are scattered across multiple systems. Traceability must support linking full-chain records of the same asset across systems to avoid ownership misalignment or information fragmentation.
Each update covers asset changes in the current period. Citation scope must be limited to entries from the current inventory cycle to avoid introducing expired data.

## Configuration Settings
These configurations are formulated for FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Maximum citation token count | 800–1200 token | Matches the combined field length of single entries in IT asset inventory documents, avoids truncating core traceability information |
| Return data source toggle | Enabled | Must display source paths of original documents such as asset ledgers and loan forms to reviewers, meets audit traceability requirements |
| Detail display toggle | Enabled and limited to top 3 entries | Asset inventory documents have many fields, limiting the number of displayed entries avoids interface clutter while covering core traceability information |
| Maximum context scope | Last 2 inventory cycles | Matches the monthly/quarterly update rhythm of data, avoids introducing expired asset change records |

## Three Common Configuration Mistakes
- Phenomenon: FastGPT-generated asset review responses are empty, only returning citation source lists such as asset ledgers and loan forms. Cause: No business response generation rule is configured, only traceability retrieval logic is triggered, with no content generated to match asset inventory business requirements.
- Phenomenon: After disabling the "Citation View" function for a login-free share link, the original document link can still be viewed during access. Cause: Citation traceability display was not synchronously disabled in the application's global configuration, only the temporary permission setting for a single share link was modified.
- Phenomenon: Asset numbers mentioned in previous rounds cannot be linked in multi-round review conversations. Cause: Maximum context scope was not configured to cover the current inventory cycle, the context window only retains single-round conversation content, with no association to historical asset entries.

## How to Confirm Configuration Is Complete
- Initiate a query targeting the current period's asset ledger, check if returned results include source document links for corresponding assets.
- Disable the application's citation display toggle, verify that shared links no longer display citation sources when accessed.
- Initiate a cross-document association query, check if information from both asset ledgers and loan and return forms can be linked simultaneously.
- Test multi-round conversations, verify that subsequent questions can associate asset entries mentioned in previous rounds.
