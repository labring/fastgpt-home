# Code and Change Review Assistance for Informatization Budget and Project Portfolio Management: Citation Sources and Traceability

## What this category of data looks like
This category of data is typically collected from financial systems, project management systems, contract ledgers, and business department requirement gathering. Update cycles are monthly, quarterly, or annual. Daily documents include annual budget sheets, project approval documents, project portfolio dashboards, and investment review reports. Data fields include budget amount, project priority, approval cycle, revenue indicators, and more. Common units are ten thousand yuan, quarters, and project numbers. The overall format combines structured tables and long text, with a core focus on project budget allocation and priority decision-making.

## What constraints do these characteristics impose on citation sources and traceability
Multi-source data collection requires citation traceability to integrate associated data from different systems, avoiding information bias from single sources. Fixed document structures require chunk matching to align with the format of budget sheets and approval documents, ensuring accurate field associations. The low update frequency but fixed core fields feature requires citation configurations to precisely target core business fields, reducing irrelevant information interference. The most time-consuming requirement closure and priority sorting process requires traceability results to quickly locate relevant budget and project data, avoiding redundant content that lengthens review cycles. Traceability errors may lead to budget mismatches, duplicate project construction, and other negative outcomes, so the traceability and accuracy of citation sources must be ensured.

## Three common misconfigurations
- When `quoteMaxToken` is set to 3000, the large language model does not receive context. The cause is that some FastGPT versions truncate context transmission for requests exceeding the threshold, preventing cited data from being passed in.
- Passing HTTP response data as a citation has no effect. The cause is failure to convert the data into the structured format supported by FastGPT knowledge bases, which requires standard fields such as source and content.
- Citations are displayed but the answer does not associate with knowledge base content. The cause is failure to enable the `detail` configuration or `responseData` does not match the category's core fields, preventing the large language model from identifying valid associated information.

## How to confirm configurations are correctly set
- Upload an annual budget sheet to the knowledge base, submit a code and change review assistance request, and check if the citation panel displays the source and core field information of the corresponding document.
- Adjust the `quoteMaxToken` parameter to different ranges, verify that the context length meets expectations, with no truncation errors or missing context.
- Call the FastGPT API to pass in structured category data, check if the returned results include the configured `responseData` fields and traceability path.
- Test using FastGPT v4.17.0 to ensure configuration items are compatible with current platform functions.
