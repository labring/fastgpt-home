# Code and Change Review Assistance for Content Audit Rule Operations: Citation Sources and Traceability

## What the data for this category looks like
The core data for this category comes from the content audit backend, user reporting channels, public regulatory policies, and internal audit sample libraries. Daily produced documents include audit rule entries, violation disposal guidelines, user appeal records, and quality inspection reports. Fields cover rule numbers, effective time periods, sample tags, disposal thresholds, and more. Data is updated daily or in real time alongside policy adjustments. The size of individual data entries ranges from tens to thousands of characters, with no fixed unified format.

## What constraints do these characteristics impose on the "citation sources and traceability" link?
Multi-source data requirements mean citation traceability must mark the original data acquisition channel to avoid confusion between internal audit rules and external policy texts. The high-frequency update feature requires the traceability link to support real-time pulling of the latest version of audit rules, ensuring cited content aligns with currently effective standards. Non-uniform document structures require traceability configuration to adapt to extraction logic for different fields, such as extracting rule numbers from audit rules and appeal numbers from appeal records. Difficult sample and review scenarios require traceability to quickly associate with original audit samples and quality inspection reports, supporting rapid verification of judgment basis.

## How to set the configuration
| Configuration Item | Recommended Setting | Rationale for This Setting |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Adapts to the length of single audit rule and sample content, avoiding truncation of critical rule entries |
| `responseData` | Return only three source types: audit backend, policy documents, appeal records | Limits traceability scope, filtering non-compliant external data |
| `detail` | full | Retains all fields of the original document, supporting detailed verification for rule explanations and appeal reviews |
| Maximum Context | 15000 token | Covers batch citation needs for multiple audit rules and samples, calibrated via actual testing |
| Single Recall Limit | Top 6 entries | Matches the number of single-round audit samples in daily reviews, avoiding information overload |

## Three Common Misconfigurations
- Phenomenon: When configuring `quoteMaxToken`, only 100 or 900 token presets are available, and custom values around 300 cannot be set. Cause: The platform's default presets do not cover the middle range, so manual input of custom parameters is required for flexible configuration.
- Phenomenon: When attempting to reference audit backend data returned via HTTP, the system returns a format error prompt. Cause: No data source filtering rules for `responseData` have been configured, causing non-compliant format content to be included in the traceability scope.
- Phenomenon: After setting the minimum relevance threshold to 1, a large number of irrelevant citation contents are still returned. Cause: The return field range for `detail` has not been limited, causing low-relevance redundant fields to be included in the traceability link.

## How to Confirm Successful Configuration
- View the citation traceability return results to confirm that only content from the three source types: audit backend, policy documents, and appeal records is included.
- Test citation of a single audit rule, checking that the token count of the returned content does not exceed the configured `quoteMaxToken` range.
- Simulate a difficult sample review scenario, verifying that the traceability results can associate with the complete fields of original audit samples and quality inspection reports.
- Adjust the custom value of `quoteMaxToken`, confirming that the FastGPT v4.17.0 platform can save configurations for non-default presets.

The values given are common starting points and should be measured against the reader's own samples.
