# Code and Change Review Assistance for Capacity Planning and Resource Scaling: Citation Sources and Traceability

## What the Data for This Category Looks Like
The data for this category primarily comes from cloud bills, monitoring systems, business forecast reports, and stress test reports. Most updates occur on a weekly or monthly basis. Daily produced documents include capacity planning reports, expansion application forms, resource utilization reports, and budget calculation sheets. Data fields include peak resource utilization, reserved resource cores, memory quotas, annual budget amounts, and more. Units are typically CPU cores, GB, and yuan. Data is updated gradually alongside business iterations and resource adjustments. The core content of a single document ranges from hundreds to thousands of characters, and data formats vary across different sources.

## Constraints Imposed by These Characteristics on Citation Sources and Traceability
Because the update frequency of this category’s data is low, citation traceability must ensure that associated data sources are the latest versions, to avoid citing expired capacity planning content. Data sources are scattered and have diverse formats, so clear differentiation must be made for different types of data sources to prevent confusion between stress test report data and cloud bill data. The core content of a single document is lengthy, so full display of core fields must be retained during citation, and critical peak forecast or resource bottleneck information must not be truncated. Additionally, this category’s data is directly linked to production resource configurations; citation errors will directly impact review results. Therefore, traceability information must include clear document sources, update times, and corresponding fields to assist reviewers in quickly verifying data validity.

## Configuration Settings
In FastGPT v4.17.0, the following configuration items can be used to complete citation source and traceability setup for this scenario:
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 characters` | The core paragraphs of capacity planning reports typically fall within this length range, preventing truncation of critical data such as peak utilization and resource quotas |
| External link import rules | Supports Notion and cloud document links | Data sources for this category are often stored on Notion or cloud document platforms, so compatibility with mainstream external link formats is required |
| `detail` | Enabled | Specific fields of cited data and source document sections must be displayed to help reviewers quickly locate citation basis |
| Match result limit | Top 3 entries | The update frequency of this category’s data is low; too many match results will increase the screening burden on reviewers |
| `responseData` | Return only entries with verification tags | Filters temporary data that has not completed updates, avoiding citation of expired or invalid capacity planning content |

## Three Common Misconfigurations
- Symptom: After importing a Notion link as a data source, capacity planning content cannot be retrieved normally. Cause: External link import rules are not configured, and support permissions for the corresponding link format are not enabled.
- Symptom: Cited capacity planning data is truncated during review, and complete peak forecast values cannot be viewed. Cause: The `quoteMaxToken` parameter is not set based on the content length of this category’s documents, and an excessively small value causes core information to be lost.
- Symptom: Query content unrelated to capacity planning data in the knowledge base is still marked as a valid citation. Cause: The verification tag for `responseData` is not enabled, allowing content that does not match core fields to be returned.

## How to Verify Proper Configuration
- Upload a capacity planning report stored on Notion, submit a review query containing "current server resource utilization", and check whether the citation results are linked to the corresponding fields in the report.
- Click the citation card to confirm that the displayed traceability information includes the document title, update time, and specific data fields, with no missing or incorrect content.
- Adjust the `quoteMaxToken` parameter to `1500 characters`, upload a lengthy expansion application form, and verify that long content is fully displayed without truncation.
- Configure retrieval to only allow cloud bill data sources, submit a query, and confirm that returned citation content only comes from cloud bill documents, with no other types of data mixed in.
