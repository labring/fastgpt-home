# Code and Change Review Assistance for Advertising Creative Audit: Citation Source and Traceability

## What the data for this category looks like
The core data for this category includes four types of documents: ad creative copy, landing page screenshots, audit opinions, and modification records. Data sources cover ad delivery platforms, landing page servers, product qualification filing systems, and general ad compliance clause libraries. The update frequency is daily or real-time synchronization. Each single data entry corresponds to the full audit workflow of a single delivery creative, and includes fields such as creative size, delivery channel, violation type tags, and rectification requirements. Fields adjust dynamically based on audit scenarios, with no unified fixed units.

## What constraints do these characteristics impose on the "citation source and traceability" link
Multi-source scattered data for ad creative audits requires the traceability system to support cross-platform associated queries. This ensures cited compliance clauses, product qualifications, and landing page information all come from the real source matching the current audit creative.
Real-time updated data rhythms require the traceability link to support incremental pulling. This avoids citing expired qualification or clause content.
Documents contain a mixed structure of text and visual materials. This requires the traceability system to match both copy content and the visual features of landing page screenshots.
A single creative corresponding to an independent audit workflow requires traceability to accurately locate the historical modification records and audit opinions of a single creative. This avoids confusing associated data across multiple creatives.
Violation point tagging relies on accurate clause sources. Traceability must directly link to specific compliance basis entries to ensure cited content has appropriate authority.

## How to configure the settings
| Config Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Adapts to the text length of ad creative copy and audit opinions, avoiding truncation of key traceability information |
| `responseData` | Includes source, content, timestamp fields | Matches the multi-source data structure of ad creative audits, retains source identifiers and update times |
| `detail` | Enabled | Displays associated text descriptions for landing page screenshots, supplements traceability details for visual materials |
| Single search limit | Top 3 entries | Matches the volume of associated data for single creative audits, avoids recalling irrelevant historical audit records |
| Maximum context | Calibrated via actual testing | Adapts to the loading volume of real-time updated product qualifications and advertising law clauses |
| Reranking | Sorted by similarity | Prioritizes recalling compliance clauses and historical modification records most relevant to the current audit creative |

## Three common errors
- Phenomenon: After configuring traceability-related parameters, clicking the test button triggers an error. Forcing to proceed allows normal operation, but citation content is missing during formal reviews. Reason: The document structure for ad creative audits is not correctly matched, leading to test validation failure while the formal workflow does not trigger full validation.
- Phenomenon: Only 1 relevant document is retrieved each time in the workspace knowledge base simple application, and multi-source ad platform data and product qualifications cannot be recalled. Reason: The single search limit is set too low, failing to cover the multi-source associated data volume required for ad creative audits.
- Phenomenon: The imported JSON-format knowledge base content is empty, and manual supplementation is required before use. Reason: The `responseData` field is not configured according to the document structure of ad creative audits, causing the system to fail to recognize the imported qualification and clause data.

## How to confirm the configuration is complete
- Import a single ad creative copy and landing page screenshot, trigger the code change review workflow, and check if the citation traceability module displays the corresponding ad platform source, product qualification link, and compliance clause entries.
