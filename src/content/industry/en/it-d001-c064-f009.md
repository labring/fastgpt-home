# Code and Change Review Assistance for Tender Document Preparation: Tool Calling and Plugins

## What the data for this category looks like
Data for this category comes from tender announcements, tender documents, enterprise qualification databases, and supplier quotations. The update frequency is once per tender project. Core documents include tender documents, qualification certificates, business deviation tables, and technical deviation tables. Data fields include tender clause numbers, response content, qualification certificate numbers, quotation details, and more. The overall structure strictly follows the chapter format of the corresponding tender document. The document structure and field requirements vary for each tender project.

## What constraints these characteristics impose on the tool calling and plugins workflow
Since data is updated per project and its structure changes with each tender project, tool calling must adapt to the latest tender document format each time, and fixed parsing rules cannot be reused. Documents must strictly match the response requirements of tender chapters. Plugins must accurately locate qualification and quotation data for corresponding clauses, to avoid cross-chapter confusion. The need to call multiple data sources requires the tool chain to sequentially connect to the qualification database, quotation system, and tender document parsing tool. The output of each link must comply with the format specifications of the tender document, otherwise the review results will fail to meet tender requirements.

## Configuration Settings
This configuration applies to FastGPT v4.17.0 and later versions.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Tool call trigger timing | Trigger by tender document chapter | Tender documents require chapter-by-chapter response. Triggering by chapter allows precise targeting of review requirements for corresponding clauses |
| Single tool call upper limit | First 10 entries | Qualification and quotation data per chapter typically do not exceed 10 entries, covering most review scenarios |
| Tool call timeout duration | 120 seconds | Querying qualification database and quotation data typically takes less than 1 minute. This duration covers conventional call scenarios |
| `functionCall` parameter | Enable mandatory validation | Tender document responses must strictly match tender clauses. Mandatory validation prevents generating non-compliant formatted content |
| Result return format | Split by tender document chapters | Tool return results can be directly embedded into corresponding chapters of the tender document, reducing manual adjustment workload |

## Three Common Mistakes
- Symptom: Frontend calls the FastGPT interface directly and returns an authentication failure. Troubleshooting steps: Check whether the AI Proxy administrator token that matches the AI Proxy server configuration and is non-empty is used for frontend authentication. External calls to the application API must not use the AI Proxy administrator token in place of the application API key.
- Symptom: The number of results returned by tool calls does not match expectations. Cause: The recall scope of tool calls is not limited, causing irrelevant data to be mixed in across chapters.
- Symptom: The workflow execution prompts that environment variables are missing. Troubleshooting steps: `AIPROXY_API_ENDPOINT` is the root address of the AI Proxy service. `AIPROXY_API_TOKEN` is the administrator token that matches the AI Proxy server configuration and is non-empty. These two variables are environment variables for the App/Admin server. Check whether the variables are not configured on the server, and only filled in the workflow global variables or application page. Failure to configure required variables will cause startup verification failure.

## How to Confirm Configuration is Complete
- Log in to the FastGPT Admin backend, check the server environment variable list, and confirm that `AIPROXY_API_ENDPOINT` (root address of the AI Proxy service) and non-empty `AIPROXY_API_TOKEN` (administrator token matching the AI Proxy server configuration and non-empty) are included.
- Trigger a tool call for tender document review, and check whether the tool return results correspond one-to-one with the current tender document chapters.
- Simulate a long-duration tool call, confirm that no global timeout error is triggered, and verify that the timeout duration configuration is effective.
- Check the configuration status of the `functionCall` parameter, and confirm that mandatory validation is enabled.

The values provided are common starting points and should be evaluated using the user’s own samples.
