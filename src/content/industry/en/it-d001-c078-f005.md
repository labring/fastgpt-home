# Code and Change Review Assistance for Cabinet Rack Installation and Cabling: Multi-turn Dialogue and Prompt Engineering

## What this category of data looks like
Data for this category originates from DCIM systems, enterprise asset systems, network topology diagrams, and customer construction work orders.
Daily processed documents include rack installation applications, cabinet cabling diagrams, port tag tables, and construction records.
Data updates occur once per work order or once per day.
Fields include cabinet rack unit number, cable length, port identifier, construction date, and others.
Corresponding units are U, meters, port sequence number, and year-month-day.

## Constraints on multi-turn dialogue and prompt engineering
This category’s data updates per work order or daily, and includes structured physical parameters and unstructured drawing content.
Multi-turn dialogue must bind to the context of a single construction work order to avoid mixing data across orders.
Documents such as cabinet cabling diagrams and port tag tables have large format differences. Prompts must explicitly define structured extraction rules to adapt to the field formats of different documents.
Physical parameter units such as U and meters have industry-specific meanings. Prompts must include unit verification logic to prevent mixed parameter usage.
Multi-turn confirmation during the rack installation acceptance phase must follow the construction process step-by-step to avoid missing critical steps.

## Configuration settings
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| ---- | ---- | ---- |
| `chatId` | Bind to the current work order's unique identifier | Ensures multi-turn dialogue context is fully tied to the specified work order and prevents session confusion |
| Maximum context length | 8000–12000 characters | Adapts to the text length of documents such as cabinet cabling diagrams and port tag tables, avoiding truncation of critical physical parameters |
| Number of single `messages` entries | Top 10 entries | Matches the construction process steps for a single work order, avoiding redundant historical data interfering with current review judgments |
| `variables` | Bind to the current work order ID and associated asset data | Ensures multi-turn dialogue only uses DCIM and asset system data linked to this work order, preventing cross-order data confusion |
| Knowledge base recall limit | Top 5 entries | Focuses on historical construction records related to the current rack and cable, reducing irrelevant information interference |
| File upload size limit | 1000 MB | Adapts to the common size of documents such as cabinet cabling diagrams and construction records, avoiding upload failures |

## Three common mistakes
- Long dialogue output latency. This occurs when the number of retained single `messages` entries is not limited, causing excessive historical context and irrelevant document data to load on each API call.
- Failure to correctly pass port tag table files during API calls. This happens when no file upload field mapping rules are configured in `variables`, so the system cannot recognize incoming document types and associated parameters.
- Incomplete image display when calling MCP with prompts. This occurs when prompts do not explicitly specify resolution and format requirements for cabinet cabling diagrams, causing MCP returned images to be truncated or compressed.

## How to verify correct configuration
- Initiate a simulated work order review dialogue, confirm the dialogue context only includes data linked to the current work order, with no cross-order information.
- Call the API with a test port tag table file, confirm the system can correctly identify and extract fields such as cabinet rack unit number and cable length.
- Trigger a prompt to call MCP, check that the returned cabinet cabling diagram fully displays all port and rack unit identifiers.
- Review system concurrency configuration parameters, confirm the concurrency setting matches the daily request peak for current cabinet room construction.
