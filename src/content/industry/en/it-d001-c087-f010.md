# Code and Change Review Assistance for Game Design and Numerical Balance: Citation Sources and Traceability

## What Data Looks Like for This Category
Daily documents for game design and numerical balance work include gameplay design docs, numerical tables, version requirement sheets, and balance test records. Data sources cover player behavior data, publicly available competitor materials, battle logs, and version feedback. Update frequency is typically weekly or per game version.

Document structures vary significantly. Numerical tables are structured tables with fields such as damage coefficients and growth curve parameters. Units include percentages, value multipliers, seconds, and similar metrics. Gameplay design docs are semi-structured text containing rule descriptions, process nodes, and related content.

## Constraints Imposed on Citation Sources and Traceability
This category has diverse data sources. Traceability priority must be differentiated between real-time data such as player behavior data and battle logs, and static data such as publicly available competitor materials, to avoid mixing information of different credibility levels.

The relatively high update frequency requires the traceability system to support rapid synchronization of the latest version feedback and battle log data.

Large differences in document structures mean structured numerical tables and semi-structured design docs need adapted citation matching logic. This ensures accurate association of fields and locations.

Errors here can lead to gameplay imbalance or version rework. Accuracy and traceability of citations are core requirements. Complete citation paths and source identifiers must be retained.

## Three Common Misconfigurations
- Setting `quoteMaxToken` too small results in truncated citation content. Reviewers cannot see complete numerical multipliers or rule descriptions. This occurs when the configuration does not adapt to the long-text characteristics of category documents, and the parameter is not adjusted based on the content length of numerical tables and design docs.
- After exporting a workflow and importing it to another environment, the citation plugin fails to load. The interface displays "No permission to operate this conversation record". This happens because the permission scope for citation traceability was not synchronized during export, and permissions were not correctly inherited after cross-environment import.
- An automatic citation identifier added at the end of knowledge base responses cannot be removed. The interface prompts that there is no permission to modify. This occurs because the citation display toggle was not disabled, and the current account does not have permission to modify citation configurations.

## How to Confirm Proper Configuration
- Upload a typical numerical table document, initiate a change review, and check that citation sources correctly match cell locations and corresponding fields in the document.
- Adjust the `quoteMaxToken` parameter, then review the displayed citation content to confirm it meets the preset length requirements with no critical content truncated.
- Export the current workflow configuration, import it to a test environment, and check that the citation plugin loads normally with no permission error messages.
- Disable the citation display toggle, then initiate a query for a gameplay design doc, and confirm that no citation identifiers or source information are displayed at the end of the response.
