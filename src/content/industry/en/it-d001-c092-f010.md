# Code and Change Review Assistance for On-Site Deployment Implementation: Citation Sources and Traceability

## What this category’s data looks like
This category of data primarily originates from customer data center environments, device inventories, software packages, and network topology documents. Daily outputs include deployment manuals, installation records, configuration lists, on-site check-in sheets, and similar documents. Data updates occur once per order or each implementation phase, with fields including deployment node identifiers, software version numbers, configuration parameter values, on-site check-in times, and more. Fields do not follow a unified mandatory format, and are adjusted based on differences in the customer’s on-site environment.

## What constraints do these characteristics impose on the citation sources and traceability link?
Data sources are scattered across multiple types of devices and non-standardized documents at the customer site. Citation traceability must cover heterogeneous local files and real-time environment data, and adapt to multi-source retrieval scopes. Update frequency varies by implementation phase, so the timeliness of citation sources must be recalibrated during each deployment phase. Daily documents are mostly unstructured content temporarily created on-site, requiring precise matching of low-structured text. On-site deployment has strict timeliness requirements. The citation traceability link cannot occupy excessive implementation cycle time, requiring a balance between retrieval accuracy and execution speed.

## How to configure settings
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1000–1400 token | Covers the average length of on-site deployment documents, fully retains key information from citation sources |
| Single search limit | Top 6 entries | Matches the number of documents for a single-phase deployment, prevents excessive retrieval results from interfering with reviews |
| `detail` | Enabled | Displays the full path and generation time of citation sources, to support on-site engineers in tracing and verifying details |
| `responseData` | Return only citation source metadata | Reduces redundancy in returned content, and improves efficiency of on-site reviews |
| Timeout threshold | 200–300 seconds | Adapts to the timeline of on-site deployment, prevents implementation delays caused by retrieval timeouts |
| Citation permission verification | Bound by environment | Adapts to permission isolation rules of customer data centers, avoids cross-environment citation errors |

This configuration was validated using FastGPT v4.17.0.

## Three common configuration errors
- Phenomenon: The number of citation results returned by the knowledge base search exceeds the preset 6-entry limit. Cause: The single search limit parameter was not configured correctly, and the value did not match the number of documents for a single-phase on-site deployment.
- Phenomenon: After exporting a workflow and importing it to another environment, cited deployment documents fail to load properly. Cause: The local path of the citation source was not exported alongside the workflow configuration, and the path in the new environment differs from the original environment.
- Phenomenon: The prompt "No permission to operate this conversation record" appears at the end of knowledge base responses. Cause: The permission isolation rules of the customer data center were not adapted, and environment binding verification for citation sources was not configured, leading to inability to access corresponding documents.

## How to confirm configuration is complete
- Import the deployment manual, configuration list, and on-site check-in sheet for a single phase to the knowledge base, initiate a code review request, and verify that returned citation sources include the names and generation times of the corresponding documents.
- Export the current environment’s workflow configuration, import it to a test environment, and verify that cited document sources and associated configurations load normally.
- Check citation annotations at the end of response content, confirm that the annotation format aligns with reading habits for on-site deployment documents, with no abnormal prompts.
- Adjust the value of `quoteMaxToken`, and verify that cited content is truncated and displayed fully as expected.

The values provided are common starting points and should be measured against the reader's own samples.
