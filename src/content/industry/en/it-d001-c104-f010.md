# Code and Change Review Assistance for Landing Page Conversion Optimization: Citation Sources and Traceability

## Data Characteristics of This Category
Core data sources for landing page conversion optimization include landing page access logs, heatmaps, form data, and ad source parameters. Regularly produced documents include landing page plans, tracking requirement documents, AB test reports, and form field lists.
Data update frequency follows a weekly cycle, or is adjusted for individual marketing campaigns.
Covered fields include page paths, dwell time, form submission rate, ad channel identifiers, and more. Field dimensions vary across different documents. Some documents require cross-verification across multiple data types.

## Constraints for Citation Sources and Traceability
Data sources for landing page conversion optimization are scattered and have diverse dimensions. The citation sources and traceability link must accurately match different types of data source documents to avoid retrieving irrelevant content.
Document update frequencies are inconsistent. Some documents are temporarily created for marketing campaigns. Retrieval context must align with the latest documents for the current campaign.
Document fields have unique variations. Some fields are exclusive identifiers. Targeted keyword matching is required during retrieval.
Errors in the traceability link will prevent accurate lead attribution, prevent precise calculation of ad costs, and affect subsequent optimization decisions.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| ---|---|--- |
| `quoteMaxToken` | `800–1200 token` | Matches the average length of documents such as landing page plans and AB test reports, avoids truncating critical information such as page paths or form field details |
| Similarity Threshold | `0.75–0.85` | Matches precise content such as landing page-specific page paths and ad channel identifiers, filters out irrelevant general business documents |
| Single Search Limit | `Top 6 results` | The number of associated documents for landing page optimization is typically limited. Excessive retrievals add context redundancy and reduce retrieval efficiency |
| Reranking | Enabled | Landing page data includes multi-dimensional metrics. Reranking optimizes snippet ordering and improves matching with retrieval requirements |
| `responseData` | `Return only citation snippets` | Focuses on specific document snippets for landing pages, avoids returning full redundant content, and facilitates quick traceability |
| `detail` | `Enabled` | Displays the complete source path and document metadata for citation snippets, meets the attribution needs of landing page optimization |

## Three Common Configuration Errors
- Enabling reranking results in empty citation snippets. The cause is that the reranking filter threshold is set too high, which filters out landing page-related snippets that meet basic similarity requirements.
- Setting `quoteMaxToken` to too small a value causes citation snippets to be truncated. The symptom is that returned citation sources only show partial content, and cannot fully display critical information from landing page plans.
- Exporting a workflow and importing it into a new environment causes the referenced knowledge base plugin to fail to load. The cause is that associated configurations for the bound knowledge base were not synced. Only the workflow file was exported, and no binding information for the data source was included.

## How to Verify Correct Configuration
- Upload a test landing page plan document, initiate a search with the keywords "landing page path" and "form field", and check whether returned citation snippets match corresponding content in the document.
- Adjust the similarity threshold, observe changes in the number of retrieved citation snippets, and confirm the threshold setting meets the matching accuracy requirements for the current business.
- Export the workflow file, import it into a new FastGPT v4.17.0 environment, and check whether the referenced knowledge base data source displays normally, with no missing prompts.
- View the `responseData` return results, confirm that only expected citation source snippets are included, with no additional unrelated content.
