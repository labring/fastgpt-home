# Code and Change Review Assistance for Configuration Management and CMDB Maintenance: Multi-turn Dialogues and Prompts

## What this category of data looks like
Data sources for this category include CMDB, cloud resource inventories, automated discovery tools, and procurement ledgers. Daily produced documents include configuration item lists, service component relationship topologies, change records, and asset inventory sheets. Fields covered include configuration item unique identifiers, dependency relationships, change times, asset statuses, and more. Common units are units, items, and times. Data update frequencies fall into two categories: daily updates and weekly updates. Update cadences vary across different data sources.

## Constraints on multi-turn dialogues and prompts
Data sources are scattered and update cadences differ. This requires multi-turn dialogues to filter expired configuration item information, preventing the model from referencing outdated data. Configuration items have complex dependency relationships. Prompts must clearly define context scope to avoid irrelevant asset information interfering with reviews. Daily documents have many fields. The total length of dialogue context must be controlled to avoid exceeding the model's processing limits. Differences in update frequencies require prompts to specify the latest data update cycle, ensuring the timeliness of review basis.

## How to configure settings
The following configuration instructions are written based on the functional logic of FastGPT v4.17.0.

| Configuration Item | Recommended Practice | Rationale |
| --- | --- | --- |
| Number of retained conversation turns | Last 8–12 conversation records | CMDB data updates daily or weekly; overly long context will introduce expired configuration item information, reducing review accuracy |
| Session ID generation rule | Generate a unique identifier for each single change review session | Distinguish context across different configuration item change reviews, avoiding data mixing between sessions |
| Global variable configuration | Bind configuration item ID, dependency relationship type, and update time range variables | Match configuration item lists and relationship topology fields from daily documents, enabling precise filtering of corresponding data |
| Single-session timeout period | 600 seconds | Covers typical time required for configuration item collection and relationship verification, preventing session interruptions from disrupting review workflows |
| Prompt template configuration | Explicitly specify configuration item fields and dependency relationship verification rules | Match the field structure of daily documents, ensuring model output meets review requirements |

## Three common misconfigurations
- Symptom: The number of retained conversation turns is set to 6, but the model cannot associate configuration item review information from the previous conversation. Cause: Context association rules are not configured correctly, resulting in incomplete transfer of session context.
- Symptom: Configuration item information extracted from CMDB data appears garbled. Cause: Data format is not specified in the prompt, or unstructured characters from automated discovery tools are not handled properly.
- Symptom: FastGPT chat windows embedded via iframe share context data across different sessions. Cause: A unique session identifier is not generated for each independent session, resulting in overwritten session context.

## How to verify correct configuration
- Initiate a configuration item query, verify that the returned results include the CMDB asset information bound to the current session.
- Initiate two consecutive change review-related questions, verify that the model can associate the configuration item dependency relationships from the previous conversation.
- View session logs, confirm that each independent session has a unique session identifier that is not reused.
- Test inputting a configuration item name containing special characters, verify that the returned results have no garbled text.
