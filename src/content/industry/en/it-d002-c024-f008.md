# Release Notes and Operation Report Summary for Information Feed Ad Creative Testing: Workflow Orchestration

## What the data for this category looks like
The data for this category primarily comes from advertising placement platforms, enterprise material libraries, user interaction data, and conversion data. Regularly produced documents include creative scripts, material test sheets, placement data reports, and iteration checklists. The data update frequency is daily or weekly. Data fields include material unique identifiers, creative combinations (images/videos + copy), placement targeting, impressions, click-through rates, conversion costs, test cycles, and more. Units include times, yuan, percentages, days, and others. Adjustments must be made to match the export formats of different advertising platforms.

## Constraints on Workflow Orchestration From These Data Characteristics
The data characteristics of this category impose multiple constraints on workflow orchestration. Non-standardized fields from multiple sources require the workflow to configure `variables` field mapping rules to adapt to different export formats of advertising platforms and material libraries. The daily or weekly update rhythm requires the workflow to support scheduled triggering. Node parameters must be used to mark test batches to avoid duplicate statistics of historical data. The multi-variable nature of creative combinations increases the complexity of loop orchestration. Reasonable trigger conditions for loop logic must be set, and iteration checklists and test data must be synchronized to ensure consistent dimensions in operation reports. The time-consuming links of material fatigue judgment and conclusion induction require embedding automated induction nodes in the workflow to reduce manual organization steps.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `variables` field configuration | Map fields from advertising platforms and material libraries to internal test sheets | Resolve data alignment issues caused by non-standardized multi-source data |
| Maximum loop count | 10-50 times, calibrated based on actual testing | Adapt to the scale of variable combinations for creative combinations, avoid invalid loops |
| Scheduled trigger cycle | Daily/weekly, set according to test rhythm | Match the daily or weekly update frequency of category data |
| `nodeId` binding | Bind the node ID of the corresponding test task | Achieve precise association between workflows and test tasks |
| Failure retry configuration | Retry 2-3 times, interval of 600 seconds | Address call failures caused by temporary fluctuations in advertising platform interfaces |
| Log recording toggle | Enable full-node logging | Facilitate quick troubleshooting of workflow errors or data anomalies |

## Three Common Misconfigurations
- Symptom: Workflow loops execute beyond the set number of times and terminate automatically, and no complete test report is generated. Cause: The maximum loop count parameter is not configured correctly, or the parameter value is smaller than the actual required number of creative combinations.
- Symptom: After calling an external advertising platform plugin, no corresponding placement data log is generated. Cause: The full-node logging toggle is not enabled, or `nodeId` binding for log traceability is not configured.
- Symptom: After the workflow runs, the text processing link produces no output. Cause: FastGPT v4.17.0 has replaced the legacy text processing node with a general field processing node. Failure to configure alternative logic will result in no output from the link.

## How to Verify Proper Configuration
- Manually trigger the workflow once, check whether the test task is triggered according to the set scheduled cycle.
- View the workflow log panel, confirm that all nodes have a successful running status, and that the test task identifier associated with `nodeId` is correct.
- Export the operation report, check whether the fields are mapped and aligned with the internal test sheet and the fields exported from the advertising platform.
- Adjust the maximum loop count to a smaller value, verify that the number of loop executions matches the set value.

The values provided are common starting points and should be measured against the reader's own samples.
