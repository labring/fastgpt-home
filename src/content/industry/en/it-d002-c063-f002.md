# Release Notes and Operation Report Summary for Campaign Setup: Context and Token

## What the Data for This Category Looks Like
Daily documents for this category typically include four core file types: campaign setup, targeting settings, budget scheduling, and conversion tracking configuration. Data usually comes from advertising platform APIs, user profile datasets, offline budget spreadsheets, and attribution tool interfaces. Update cycles follow daily or single campaign periods. Fields commonly include targeted audience tags, budget amounts, conversion event IDs, and more. There are no uniform mandatory units. Configurations must match the format requirements of the corresponding data source. Core operational steps focus on audience targeting configuration, budget allocation, and conversion event validation. Operational errors may lead to budget waste, missing conversion data, or failed campaign launch.

## What Constraints These Characteristics Impose on the Context and Token Link
The multi-source heterogeneous data sources for campaign setup require the context module to support inputs in different formats from advertising platforms, budget spreadsheets, attribution tools, and more. Token allocation must adapt to length differences across non-standardized fields. The update rhythm of daily documents is not fixed. The context cache refresh mechanism must support on-demand triggering, without using fixed cycles. Field validation for core operational steps relies on complete context. The token limit must cover the total content length of a single complete campaign setup document, to avoid truncation of critical configuration information. Operational errors will directly cause campaign failure. The accuracy of context recall must strictly match business fields such as targeting tags and conversion event IDs, to reduce invalid token consumption.

## How to Configure Settings
Under FastGPT v4.17.0, the configuration items are as follows:
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | Adapts to the total document length of a single complete campaign setup, covering core content such as targeting settings, budget scheduling, and conversion tracking configuration |
| `quoteMaxToken` | Single recalled content ≤1500 token, total recalled token ≤4000 token | Matches the volume of associated data required for campaign validation, avoiding excessive token usage that causes context overflow |
| Context refresh trigger rule | Triggered by document update timestamp | Adapts to the non-fixed update frequency of documents in this category, avoiding invalid cache consumption |
| Multi-source data priority | Advertising platform data takes precedence over budget spreadsheet data | Aligns with the business validation logic for campaign setup, prioritizing the accuracy of real-time campaign data |
| Temporary input token limit | No more than 20% of `maxContext` | Reserves sufficient space for temporarily added configuration adjustments, avoiding overwriting core context |

## Three Common Configuration Errors
- Phenomenon: Context recall results lack core tag fields for targeting settings, causing campaign setup validation to fail. Cause: The single content length limit for `quoteMaxToken` is not configured, leading to truncation of long fields.
- Phenomenon: The total token volume of merged multi-source data exceeds `maxContext`, and the system returns a context overflow error. Cause: No priority sorting rule for multi-source data is set, and non-core data is prioritized into the context.
- Phenomenon: After team switching, team data returned by the tokenLogin interface is not synchronized to the context cache, causing configuration permission validation to fail. Cause: The context refresh rule is not bound to team permission change events, and cache content is not updated in a timely manner.

## How to Verify Proper Configuration
- Upload a complete campaign setup document, and check whether the total token number displayed by the context module falls within the configured range of `maxContext`.
- Trigger a campaign setup validation process, and verify that the recalled associated data includes core fields from advertising platforms and attribution tools.
- Modify the update timestamp of a campaign setup document, and confirm that the context cache completes refresh within the specified time frame.
- Adjust the configuration value of `quoteMaxToken`, and test whether long field content is fully recalled without truncation.

The values provided here are common starting points, and should be evaluated against samples from the respective deployment.
