# Release Notes and Operations Report Summary for Cabinet Rack Installation and Cabling: Scheduled Tasks and Automation

## What the data for this category looks like
Typical users of this category are IDC operations engineers, network engineers, and equipment implementation staff. They regularly work with documents including rack installation applications, cabinet cabling diagrams, port label sheets, and construction records. Data mainly comes from DCIM systems, asset systems, network topology diagrams, and customer work orders. Update frequency is per order or daily. Data fields include rack position numbers, cable lengths, port identifiers, construction times, and others. Units include meters, individual units, days, and others. Field formats vary across different data sources.

## Constraints imposed by these characteristics in the Scheduled Tasks and Automation workflow
Data comes from multiple heterogeneous systems and updates per order or daily. Scheduled task trigger cycles must match the synchronization rhythm of data sources. Frequent polling must be avoided to prevent excessive resource usage. Document formats vary widely across types. Automated processing must adapt parsing logic for diagrams, tables, text, and other formats. This increases the complexity of task configuration. Errors in this category can lead to incorrect port connections, impaired heat dissipation, or delayed customer onboarding. Reasonable retry and alert mechanisms must be set after task execution failures. A time window for manual verification must be reserved. Task intervals should not be set too short.

## How to Configure Settings
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| Task Trigger Cycle | 600 seconds | Matches the per-order or daily data update frequency, avoids excessive system resource usage from frequent polling |
| Data Source Pull Scope | Newly added work orders and associated asset data for the current day | Focuses on pending rack installation and cabling tasks, reduces invalid data pulls |
| Exception Retry Count | 3 | Adapts to the latency characteristics of physical device operations, avoids excessive retries disrupting on-site construction |
| Alert Notification Threshold | 2 consecutive execution failures | Notifies operations engineers of exceptions in a timely manner, prevents delays to customer onboarding progress |
| Task Execution Timeout | 1800 seconds | Reserves sufficient time to complete cabling diagram parsing, port label verification, and data aggregation |
| Result Verification Rule | Match rack position number and port label consistency | Avoids core error risks such as incorrect port connections |

## Three Common Configuration Mistakes
- The symptom is no response after a scheduled task runs. The cause is that the locally deployed FastGPT v4.17.0 version has not been properly configured with environment variables, preventing the service from accessing data source interfaces.
- The symptom is timeout errors during task execution. The cause is that the set task execution timeout is too short to complete complex cabling diagram parsing and multi-field verification work.
- The symptom is that a single task can only process rack installation data for one cabinet, and cannot simultaneously trigger cabling verification tasks for multiple cabinets. The cause is that concurrent execution configuration is not enabled, resulting in serial task processing.

## How to Confirm Proper Configuration
- Manually trigger a scheduled task. Verify generation of a summary document including rack installation applications, cabinet cabling diagrams, and port label information.
- Review task execution logs. Confirm successful pulling of newly added work orders and associated asset data for the current day, with no data source connection errors.
- Simulate a data source disconnection exception scenario. Verify whether the preset alert notification is triggered.
- Randomly select a summary report. Confirm consistency between rack position numbers, port labels in the report, and original work order data.
