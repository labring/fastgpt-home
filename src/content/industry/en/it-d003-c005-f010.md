# Security and Compliance Material Review for Issue Triage and Response: Source Citation and Traceability

## Data Overview for This Category
The core data for this category consists of content daily created by open-source maintainers, community operators, and core contributors. Data sources include GitHub or Gitee Issues, version logs, user environment information, and code repositories. Daily documents cover Issue templates, label rules, reply records, and problem reproduction instructions. Fields include Issue numbers, associated code commits, reproduction steps, priority labels, and more. Data updates occur daily or weekly. The structure of individual entries varies widely: some entries only include a brief problem description, while others contain complete environment configurations and reproduction logs.

## Constraints Imposed on Source Citation and Traceability
Because data sources are scattered across GitHub/Gitee Issues and code repositories, individual content pieces have large length differences. Citation and traceability must accurately match each Issue’s unique identifiers and associated rules to prevent confusion between different entries. Data updates happen daily or weekly, so cited compliance materials must stay synchronized with the latest label rules and reply records. The core workflow of this category prioritizes problem descriptions and priorities. The citation link must first associate review rules matching the corresponding priority, while avoiding reduced classification efficiency from redundant recall. The irregularity of data structures also requires the traceability link to support flexible field matching, adapting to Issue documents in different formats.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum Context | Calibrated via actual testing, typically no more than 8000 token | Adapts to the length range of single GitHub Issue content, ensuring full content integrity for citation and traceability |
| Single Search Limit | Top 6 entries | Matches the recall needs for this category’s core fields, preventing redundant data from disrupting compliance review logic |
| Reranking | Enabled | Optimizes the ranking of recalled documents, ensuring high-priority Issue label rules and reply records are prioritized for citation |
| `quoteMaxToken` | 1200–1500 token | Aligns with the typical content length of GitHub Issues, avoiding traceability failures caused by overly long content |
| `responseData` | Retain original citation identifiers | Meets community operators’ archiving and auditing requirements, ensuring every citation can be traced back to the original Issue or document |
| `detail` | Enabled | Fully retrieves Issue reproduction instructions and associated code information, supporting detailed verification for security and compliance reviews |

## Three Common Misconfigurations
- Enabling the reranking function leads to empty citation results, making it impossible to retrieve Issue documents required for compliance review. Cause: The reranking similarity threshold is set too high, filtering out low-relevance but critical label rule documents that meet requirements.
- A timeout error appears when calling the traceability function, with no citation sources returned. Cause: The `quoteMaxToken` parameter is not configured properly, exceeding system limits when loading overly long Issue content.
- Custom citation templates and prompt words cannot be edited, making it impossible to adapt to the exclusive review logic for Issue triage. Cause: The installed FastGPT version is earlier than v4.17.0, so advanced configuration functions are not accessible.

## How to Verify Correct Configuration
- Submit a simulated compliance Issue, then check if the returned results include traceable citation identifiers such as corresponding Issue numbers and label rules.
- Call the traceability function three times consecutively, confirm the number of citation results stays within a reasonable range, with no frequent empty results.
- Review the configured value of `quoteMaxToken`, confirm it does not exceed the maximum context range allowed by the system.
- Access the AI configuration interface, confirm that custom citation templates and prompt words can be edited to fit this category’s exclusive review logic.

The values provided are common starting points and should be measured against the reader's own samples.
