# Security and Compliance Material Review for Personal Information Protection Compliance: Citation Sources and Traceability

## What the Data for This Category Looks Like
Data for this category primarily originates from business systems, App permission lists, privacy policies, and user request records. Update frequency follows a quarterly schedule or occurs whenever a product version is changed. Daily processed documents include personal information inventories, data processing rules, personal information protection impact assessment reports, user authorization texts, and similar materials. Most document structures include core fields such as information fields, processing purposes, legal bases, and storage periods. No uniform mandatory units apply. Some documents require association with natural person information identification fields. Data is scattered across multiple types of business and user-side documents. Precise matching of sources and versions is required to meet compliance review requirements.

## Constraints Imposed on Citation Sources and Traceability
Data sources are scattered and linked to business systems and user-side documents. Traceability requires precise matching of document source identifiers to avoid confusing compliance materials from different business scenarios. Update frequency fluctuates with product changes. Cited materials must be the latest versions; otherwise, review basis will become invalid. Multiple document types exist, each with different field weights. Retrieval logic must be adjusted specifically to focus on core compliance content. Fields involving natural person information require strict isolation of the traceability chain to prevent sensitive information leaks during citation.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | Matches the average length of single compliance documents in this category, avoids truncating core compliance basis |
| `responseData` | Return only compliance document fields | Filters non-essential content, focuses on core compliance materials such as personal information inventories and assessment reports |
| `detail` | Enable full traceability | Displays document source, update time, and associated fields to meet traceability requirements for compliance reviews |
| Single retrieval limit | Top 6 entries | Controls the volume of review materials, avoids redundant information interfering with confirmation of legal bases |
| Source data sync cycle | Triggered by product changes | Matches the update frequency of this category, ensures cited materials are the latest versions |

## Three Common Misconfigurations
- Non-compliance document citations displayed in the conversation interface without proper configuration. Failure to set the `responseData` parameter to return only compliance-related documents results in retrieval scope covering non-target data sources.
- Citation entries generated without importing the compliance knowledge base locally. Failure to disable automatic association of the global default knowledge base, or failure to isolate non-compliant business data in the source data sync link.
- Low-relevance citation content appearing in mixed retrieval scenarios. Failure to set differentiated retrieval matching rules for different compliance document types results in non-core field content being retrieved.

## How to Verify Proper Configuration
- In FastGPT v4.17.0, import a single compliance document, submit a corresponding review query, and check if returned citations only come from the target compliance data source.
- Disable all non-compliance knowledge bases, submit a test request, and confirm no citation entries from unconfigured data sources appear.
- Adjust the `quoteMaxToken` parameter, verify that the output citation content does not truncate core compliance fields.
- Run a mixed retrieval test, check if non-target types of compliance document citations can be filtered via configuration.

The values listed above are common starting points and should be evaluated against the reader's own samples.
