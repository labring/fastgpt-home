# Security and Compliance Material Review for IT Budget and Project Portfolio Management: Conversation Logs and Auditing

## What the data for this category looks like
The data for this category typically comes from financial systems, project management systems, contract ledgers, and business department requirements. Daily produced documents include annual budget sheets, project proposal documents, project portfolio dashboards, and investment review reports. Common fields include budget amounts, project cycles, priority identifiers, revenue calculation items, and more. Data update cycles are mostly monthly, quarterly, or annual, and are maintained and circulated by the CIO’s office, PMO, and financial BPs.

## What constraints do these characteristics impose on the conversation logs and auditing link
Dispersed data sources linked across multiple systems require conversation logs to fully record the cross-system data call chain to ensure audit traceability. Complex document structures with multi-dimensional fields require the auditing process to retain the correspondence between original documents and conversation interactions, avoiding field confusion. Long update cycles require logs to retain all interaction records within the corresponding cycle to facilitate review of budget and project adjustment processes. Interactions involving budget amounts and priority sorting require encrypted storage of sensitive fields to prevent compliance risks.

## How to configure
The following configurations are formulated based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Conversation log storage period | 12 months | Data update frequency is mostly monthly/quarterly/annual, needs to cover at least one full business cycle |
| Sensitive field encryption toggle | Enabled | Documents contain sensitive information such as budget amounts, must comply with security and compliance requirements |
| `chatId` association configuration | Bind project ID and budget number | Ensure each log is linked to corresponding IT project and budget data, facilitating chain traceability |
| `responseChatItemId` binding | Associate original document version number | Record the document version used during interaction, facilitating tracing of content change trajectories |
| `detail` log detail toggle | Enable full recording | Need to fully retain field calls and calculation logic during interaction to meet auditing requirements |
| Audit log export format | Standardized structured format | Facilitate subsequent compliance audits and cross-system data verification |

## Three common configuration errors
- Phenomenon: Uploaded budget sheets or proposal documents do not appear in conversation logs, and the large model cannot generate statistical results based on uploaded data. Cause: The `detail` log detail configuration is not enabled, or the association between uploaded documents and `chatId` is not bound.
- Phenomenon: Calling the multimodal interface to review project documents returns a 400 invalid image error, and no corresponding error details are available in the conversation logs. Cause: The configuration for binding image metadata with `responseChatItemId` is not enabled, causing logs to fail to record image format and verification issues.
- Phenomenon: System storage usage continues to rise, and expired conversation logs cannot be automatically cleaned up according to the set cycle. Cause: The automatic cleanup rule for the conversation log storage period is not configured, or the log automatic archiving toggle is accidentally disabled.

## How to confirm the configuration is properly set up
- Upload an annual budget sheet, initiate a statistical summary request, and check whether the conversation logs include the uploaded document’s identifier and interaction content.
- Initiate a multimodal document review request, and check whether the conversation logs record the binding information between `responseChatItemId` and the document version.
- Check the system storage usage, and confirm whether expired logs are automatically cleaned up according to the set cycle.
- Export an audit log, and confirm that the log format is standardized structured content, including the `detail` detail field and `chatId` association identifier.
