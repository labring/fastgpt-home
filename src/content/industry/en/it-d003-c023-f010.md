# Security and Compliance Material Review for IT Budget and Project Portfolio Management: Citation Sources and Traceability

## What This Category of Data Entails
Typical users of this category include CIO offices, PMOs, and financial BPs. They regularly process documents such as annual budget sheets, project proposal documents, project portfolio dashboards, and investment review reports. Data sources cover financial systems, project management systems, contract ledgers, and business department requirement submissions. Update frequencies are typically monthly, quarterly, or annually. Document structures include structured fields like budget amount and project number, plus unstructured review text. Data formats vary across sources. Some fields require cross-system association and verification.

## Constraints for Citation Sources and Traceability
Data sources for this category are scattered, and update cycles vary. Traceability workflows must accurately bind each cited snippet to its corresponding system and update time. This prevents cross-version data confusion. Documents include structured budget fields and long-text review content. Full original field information must be retained. Key content such as project numbers and budget amounts cannot be truncated. Data with different update frequencies must use corresponding version identifiers. This ensures cited content uses currently active budget or project information. Fields requiring cross-system association must match unique identifiers. This prevents budget mismatches or duplicate project citations.

## Configuration Guidelines
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | This category of documents includes structured budget fields and long-text review reports. Full key information of cited snippets must be retained. Core content such as project numbers and budget amounts cannot be truncated. |
| `responseData` | Only return associated source data | Must strictly align with fields from original budget sheets and proposal documents. Unauthorized tampered content must not be generated. Ensure traceability information matches original data completely. |
| `detail` | Enable full traceability | Must display system identifiers and update timestamps of data sources. Align with ledger specifications of financial and project management systems. Meet traceability requirements for compliance reviews. |
| Single recall limit | Top 5 entries | Project portfolio dashboards for this category usually display a limited number of core projects per page. Too many recalled redundant data will interfere with traceability and decision-making. |
| Data source binding rules | Associate by system classification | Must separately bind data from financial systems and project management systems to corresponding knowledge bases. Ensure cited source data comes from the correct business module. |

## Three Common Configuration Errors
- Symptom: After the citation switch is enabled, mandatory traceability content is returned without corresponding parameter configuration. Cause: In FastGPT v4.17.0, failure to correctly bind the association between data sources and project budget documents triggers full traceability by default. This causes unconfigured citations to be displayed.
- Symptom: Knowledge base variable reference format is configured incorrectly. It cannot match budget document fields. Cause: Category-specific data source identification parameters are not used. Only general dataset IDs are passed, without associating ledger mappings for financial and project management systems. This prevents recall of budget data for corresponding projects.
- Symptom: Recalled source data fields are empty. Traceability information cannot be displayed in responses. Cause: The `detail` parameter is not enabled. The system does not load full field content from source data. Only question-and-answer text is returned. Key identifiers from original documents are not included.

## How to Verify Correct Configuration
- Upload a single annual budget sheet to the corresponding knowledge base. Trigger a question-and-answer request that includes budget amount and project number. Check if returned content includes file identifiers and update timestamps of source data.
- Set `quoteMaxToken` to 800 tokens. Input an investment review question that includes long text. Verify that the character length of cited snippets does not exceed the set value. Confirm the parameter takes effect.
- Disable the citation switch. Trigger a question-and-answer request. Check that no traceability information is displayed in the response. Confirm the citation switch configuration is correct.
- Input an unassociated project number. Check that the system does not recall unrelated budget data. Confirm the data source binding rules configuration is correct.
