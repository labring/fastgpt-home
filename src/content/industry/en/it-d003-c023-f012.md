# Security and Compliance Material Review for IT Budget and Project Portfolio Management: Document Parsing and Chunking

## What the data for this category looks like
Core data for this category comes from financial systems, project management systems, contract ledgers, and business department requirements. Daily processed documents include annual budget sheets, project proposal documents, project portfolio dashboards, and investment review reports. Most documents contain structured fields such as budget line items, project numbers, priorities, and amounts. Some reports include unstructured explanatory content. Data updates follow a monthly, quarterly, or annual cycle. Document field formats from different sources have minor variations.

## How These Characteristics Impact the Document Parsing and Chunking Link
Differences in document formats across multiple sources require parsing logic to adapt to different table structures, to avoid losing structured fields. Documents mixing structured data and unstructured explanatory content need flexible adjustment of chunk boundaries, to ensure key information such as budget line items and project priorities is not split. Batch monthly, quarterly, or annual updated data requires matching stable parsing timeouts and file size limits, to avoid batch task interruptions. Minor differences in document fields require custom chunking rules, to prevent field confusion across documents, while meeting security and compliance review requirements for retaining key metadata.

## How to Configure Settings
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Adapts to the mixed length of structured fields and unstructured explanatory content in documents of this category, avoiding splitting of key budget information |
| `chunkSplitter` | Prioritize chunking by tables | Matches the characteristic that documents of this category mostly contain structured budget tables and project dashboards, preserving table integrity |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Meets the size requirements for batch-imported annual budget summary files and large cross-departmental project portfolio dashboards |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Meets the time requirements for batch parsing of multiple documents, avoiding parsing interruptions for large investment review reports |
| `customPdfParse` | Enabled | Adapts to formatted PDF documents exported from project management systems, preserving original layout and field structure |
| `chunkSettingMode` | Manual configuration | Adapts to format differences across documents from different sources, flexibly adjusting chunking rules to meet compliance review requirements |

## Three Common Misconfigurations
- Phenomenon: Parsing results are empty or fields are missing after uploading Feishu multi-dimensional documents or Excel files. Cause: The table parsing switch for the corresponding third-party knowledge base was not enabled, and the parsing rules for structured budget tables in documents of this category were not adapted.
- Phenomenon: A request error is triggered when uploading a large PDF-format annual budget file. Cause: The configurations of `UPLOAD_FILE_MAX_SIZE` or `PARSE_FILE_TIMEOUT_SECONDS` were not adjusted, and parsing tasks were interrupted due to exceeding the system's default limits.
- Phenomenon: Key fields required for compliance review such as project numbers and budget amounts are missing from parsed chunked content. Cause: `chunkSplitter` was not set to prioritize chunking by tables, leading to incorrect splitting of structured tables and key information being scattered across multiple chunks.

## How to Verify Proper Configuration
- A single small project proposal document can be uploaded to verify that the parsing result retains complete project numbers, priorities, and other fields required for compliance review.
- Batch monthly budget summary files can be uploaded to verify that parsing tasks are completed within the preset timeout period.
- After enabling `customPdfParse`, a formatted PDF document exported from a project management system can be uploaded to check that the parsed layout matches the original document.
- After adjusting `chunkSize`, checks can be performed to confirm that chunked content does not split continuous budget line item explanatory paragraphs.

The values provided here are common starting points, and should be evaluated against samples specific to the target deployment context.
