# Security and Compliance Material Review for IT Budget and Project Portfolio Management: Model Access and Configuration

## What the data for this category looks like
The core data for this category comes from financial systems, project management systems, contract ledgers, and business department requirements. Commonly processed documents include annual budget sheets, project proposal documents, project portfolio dashboards, and investment review reports. Data update cycles follow monthly, quarterly, or annual schedules. Document structures include fields such as budget amounts, project priorities, resource allocation, and revenue calculations. There is no unified fixed unit standard, so adaptation to value types and formats for different business scenarios is required.

## What constraints these characteristics impose on model access and configuration
Data sources are scattered and formats are heterogeneous. When accessing models, it is necessary to adapt to heterogeneous data formats output by multiple systems to avoid parsing failures. Document types are diverse and fields vary significantly. This requires configuring support for mixed parsing capabilities of unstructured text and structured tables. Data update frequency is low. High-frequency model calls are not needed, but the volume of documents processed in a single run may be large. It is necessary to limit the context and output token cap for each round of processing. At the same time, the data involves budget and project decisions. The compliance and accuracy of model output must be ensured, so relevant parameters must be strictly configured to control output randomness.

## How to configure the settings
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Range | Rationale |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | Adapts to the total length of multiple budget and project documents processed in a single run, avoiding context overflow |
| `maxTokens` | 2000–3000 token | Matches the conventional output summary length of investment review reports and project proposal documents, ensuring key information is complete |
| `quoteMaxToken` | 1500 token | Limits the token proportion of referenced source documents, reserving sufficient space for analysis of budget priority sorting |
| `temperature` | 0.2–0.4 | Reduces output randomness, ensuring stable and compliant results for budget calculations and priority judgments |
| `vision` | Disabled | Core data for this category is primarily structured text, so no image understanding capability is needed, reducing unnecessary resource consumption |
| `AIPROXY_API_TOKEN` | Administrator token configured for the AI Proxy server, must match the AI Proxy server configuration and not be empty | This variable is an environment variable for the App/Admin server, and is not part of the FastGPT interface model configuration |

## Three common configuration mistakes
- A call to a channel link returns "undefined" is not valid json. Troubleshooting: The App/Admin server environment variables `AIPROXY_API_ENDPOINT` or `AIPROXY_API_TOKEN` are not configured correctly, leading to abnormal request addresses or authentication issues.
- No image understanding model options are visible. Cause: Core data for this category is primarily structured text, and the `vision` configuration is not enabled. The platform hides non-essential visual model options by default.
- Single-round processing times out or fails. Troubleshooting: The number of documents per request is not adjusted based on the `maxContext` configuration, causing context usage to exceed the threshold and triggering link exceptions.

## How to Confirm the Configuration is Complete
- Import a mixed document of an annual budget sheet and a project proposal document, check whether the budget priority sorting result output by the model matches the fields in the source document.
- Initiate a single-round call, check whether the returned token consumption value falls within the configuration range of `maxTokens` and `maxContext`.
- Test the multi-document batch processing workflow, confirm that no format parsing errors occur, and ensure adaptation to heterogeneous data sources is working properly.
- Check whether the server has correctly configured `AIPROXY_API_ENDPOINT` and `AIPROXY_API_TOKEN`, and that the two values match.

The values provided are common starting points and should be measured against the reader's own samples.
