# Security and Compliance Material Review for Information Flow Ad Creative Testing: Citation Sources and Traceability

## What the data for this category looks like
Data for this category comes from advertising platform backends, internal material libraries, user interaction data, and delivery conversion reports. Daily produced documents include creative scripts, material test sheets, delivery data reports, and iteration checklists. Fields cover creative variable combinations, material types, delivery time periods, and conversion metrics. Data update frequency is adjusted daily or weekly, synchronized with single test cycles. Work focuses on the performance and compliance of different creative combinations.

## Constraints on Citation Sources and Traceability
This category’s data is scattered across multiple systems. Citation traceability requires connecting advertising platform, material library, and delivery report linkages. Every compliance review item must be traceable to original materials or delivery records. Daily documents focus on creative testing. Most fields tie to specific test batches and variable combinations. The traceability link must accurately match test entries with citation sources to avoid cross-batch confusion. Data updates daily or weekly. An automatic synchronization mechanism must be configured to keep reviewed cited content aligned with latest test data. Compliance review errors directly impact delivery effectiveness. The traceability link must retain complete source identifiers to quickly locate compliance issues.

## Three Common Configuration Mistakes
- Citation document identifiers disappear after official release. Symptom: Citation sources are visible in the debug page, but only review results are shown without source links on the official chat or published page. Cause: Persistent storage configuration for `responseData` is not enabled, so citation metadata is only temporarily cached during debug sessions.
- Knowledge base citation content cannot be extracted by the text content extraction component. Symptom: No citation extraction option appears in component parameters, so associated original document information cannot be synchronized. Cause: The extraction component is not bound to the knowledge base citation module, and context binding settings related to traceability are not enabled.
- Number of traceability results does not match expectations. Symptom: Displayed citation sources are fewer than the number of materials actually involved in the test. Cause: `quoteMaxToken` is set too low, truncating some cited content and causing source identifiers to be lost.

## How to Verify Correct Configuration
- Enable debug mode, input a single creative test script, check if the output includes complete citation source links and document identifiers.
- Trigger a complete creative compliance review workflow, confirm that the output includes source fields from the material library and advertising platform, and verify that the `detail` configuration is set to full mode.
- Adjust `quoteMaxToken` to different values, verify that the citation content truncation logic works as expected, ensuring no critical sources are truncated.
- Publish a test page, access it via an external link, confirm that citation identifiers are not hidden or lost.

The values provided are common starting points and should be measured against the reader's own samples.
