# Safety and Compliance Material Review for Information Feed Ad Creative Testing: Model Access and Configuration

## What the data for this category looks like
Data for this category primarily comes from advertising platform backends, internal material libraries, user interaction data, and conversion data. Daily produced documents include creative scripts, material test sheets, delivery data reports, and iteration checklists. Data updates follow a daily or weekly schedule, adjusted alongside delivery iterations. Data fields include creative material type, variable combinations, delivery time slots, conversion metrics, and linkages between creative test variable combinations and corresponding delivery effects.

## What constraints these characteristics impose on model access and configuration
Data for this category comes from scattered sources and updates frequently. Configure `maxContext` to limit total context length, and avoid mixing irrelevant delivery data. Daily documents have diverse structures. Configure `quoteMaxToken` to limit the token length of referenced content, adapting to the format and content scale of different documents. Data links creative variables and conversion effects. Adjust `temperature` to control output stability, avoiding result fluctuations caused by data updates. Errors directly affect delivery effects. Configure `toolChoice` to limit the scope of tool calls, ensuring the accuracy of compliance reviews. Enable the `vision` configuration to cover compliance reviews of image and video materials, adapting to multiple types of materials used in information feed ads.

## How to set configurations
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | Adapt to the total length of multi-source delivery data and creative documents, avoid truncating valid test data |
| `maxTokens` | 2000–3000 token | Control the output length of a single round of compliance review, avoid exceeding model load |
| `quoteMaxToken` | 1500–2000 token | Limit the content length of a single referenced material script or test sheet, ensure compliant references and avoid context overflow |
| `temperature` | 0.2–0.4 | Balance flexibility and stability of compliance reviews, adapt to high-confidence compliance judgments |
| `vision` | Enabled | Cover compliance reviews of image and video materials, adapt to multiple types of creative materials used in information feed ads |
| `AIPROXY_API_ENDPOINT` | Root address of the AI Proxy service, for example http://aiproxy:3000. Do not append /v1 or /chat/completions paths. Do not fill in single-model addresses such as VLLM/Ollama/Xinference | Environment variable for the App/Admin backend, points to the root address of the AI Proxy service, ensures the service can properly connect to the AI Proxy dependency |
| `AIPROXY_API_TOKEN` | Administrator Token configured for the AI Proxy backend, consistent with the backend configuration and not empty. Do not use application API Keys, model vendor keys, or tokens issued per application | Environment variable for the App/Admin backend, used for AI Proxy service identity verification, ensures the service can properly call the AI Proxy |

## Three Common Misconfigurations
- Incorrectly configuring `AIPROXY_API_ENDPOINT` triggers a 404 page not found error. Troubleshoot by checking if a single-model address such as VLLM/Ollama/Xinference was used, or if paths such as /v1 or /chat/completions were appended.
- Setting `temperature` above 0.5 causes the model to identify compliance rules poorly. High temperature leads to excessive output randomness, which prevents stable recognition of compliance details.
- Failing to configure `quoteMaxToken` to limit referenced material content causes token calculations to exceed model load, triggering request failure. Unrestricted token usage from referenced documents exceeds the model context limit.

## How to Confirm Proper Configuration
- Check the environment variable configuration of the App/Admin backend. Confirm that `AIPROXY_API_ENDPOINT` (AI Proxy service root address) and `AIPROXY_API_TOKEN` (AI Proxy administrator Token) are correctly configured and not empty, and that service startup checks pass without failures.
- Upload a creative script and material test sheet, verify that the model’s compliance review output covers compliance points for copy and materials.
- Adjust `temperature` to around 0.3, compare the stability of two review results, and confirm alignment with expectations.
- Upload an image material, confirm that the `vision` configuration is enabled, and verify that the model can identify the compliance status of the image.
