# Security and Compliance Material Review for Security Incident Response: Model Integration and Configuration

## What data for this category looks like
Core data for this category comes from SIEM, EDR, firewall logs, and host images. Update frequency is real-time or per-event. Daily output documents include incident response reports, forensics records, disposal plans, and notification materials. Each document includes fixed fields: event timestamp, affected asset identifier, attack path description, disposal operation record, and more. Fields adjust dynamically based on incident type, with no unified fixed units. This content is written for FastGPT v4.17.0.

## What constraints these characteristics impose on model integration and configuration
Data sources for this category are scattered, and updates occur in real time or per event. The model integration step must adapt to multi-source heterogeneous log formats to avoid parsing failures. Event-triggered update modes require support for short-cycle batch data processing. Long context waiting windows are not recommended. Daily documents include sensitive fields and event-specific dynamic fields. Content desensitization rules must be configured during model calls. Flexible context extraction logic must also be supported to adapt to field differences across incidents.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | Enter the root address of the AI Proxy service, for example http://aiproxy:3000. Do not append /v1 or /chat/completions paths | Required environment variable for the App/Admin server dependent on AI Proxy. Specifies the root access address for the AI Proxy service. Must not be a single model service address |
| `AIPROXY_API_TOKEN` | Enter a non-empty administrator token matching the AI Proxy server configuration | Required environment variable for the App/Admin server dependent on AI Proxy. Must match the administrator token configured for the AI Proxy server, and cannot be empty. Unrelated to model vendor permissions |
| `maxContext` | 8000–12000 token | Adapts to context length for multi-source logs of a single incident, prevents truncation of critical evidence information |
| `temperature` | 0.1–0.3 | Ensures the model’s output disposal plans and forensics logic are rigorous, reduces subjective bias |
| `toolChoice` | auto | Allows the model to independently choose whether to call tools for log parsing, adapts to extraction needs for dynamic fields |
| `maxTokens` | 2000–3000 token | Limits the output length of a single disposal suggestion, aligns with length specifications for notification materials |

## Three common misconfigurations
- Symptom: Calls return `403 This token is not authorized to use the model`. Troubleshooting steps: Verify authentication configurations such as the application API Key and model vendor key are correct. The AI Proxy administrator token is unrelated to model access permissions.
- Symptom: Model output disposal suggestions exceed notification material length limits. Cause: The `maxTokens` parameter is not configured, or its value is too large, failing to limit single-output length.
- Symptom: Multi-source heterogeneous logs cannot be parsed correctly. Cause: Log source formats are not adapted, and flexible context extraction configuration is not enabled, leading to failure to recognize dynamic fields.

## How to confirm configurations are correct
- Call the test interface, enter a single SIEM log and forensics record, check that a compliant disposal suggestion is returned with no permission errors.
- Review the model output content length, confirm it meets preset output limit requirements.
- Import multi-source heterogeneous log samples, check that the model can correctly extract attack path and affected asset information.
- Verify that `AIPROXY_API_TOKEN` matches the administrator token configured for the AI Proxy server, and is not empty.

The values provided here are common starting points, and should be evaluated against the user’s own samples.
