# Security and Compliance Material Review for Security Training and Phishing Drills: Source Citation and Traceability

## What data for this category looks like
Typical users of this category include security operations teams, internal enterprise training departments, or external security service providers. Daily processed documents fall into four categories: training courseware, phishing drill plans, phishing email templates, and drill result reports. Data sources cover four channels: employee contact lists, corporate email gateways, internal training platforms, and user click statistics systems. Update frequency is usually quarterly or annual. Document fields include sender, recipient, send time, click count, participant list, and more. Field differences vary significantly across document types: email templates include sending configuration fields, while drill reports include statistical analysis fields. ## What constraints these characteristics impose on source citation and traceability
Multi-data source access requires traceability workflows to associate multiple data types such as employee contact lists and email gateways. This ensures cited content sources are verifiable. Differences in fields across document types require traceability configurations to adapt to each document’s exclusive fields. This avoids missing key audit information. Quarterly or annual update frequency requires citations to validate data timeliness. This prevents use of expired drill plans or participant lists. Time-consuming drill crowd screening and template design may cause missing data. Traceability workflows must add data integrity check steps. This ensures cited content has no gaps.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches typical content length of phishing email templates and drill result reports, avoids truncating key traceability information |
| `responseData` | Structured format with source association fields | Adapts to traceability requirements for multiple data sources (employee contact lists, email gateways), facilitates cross-system association and verification |
| `detail` | Enabled | Used to display details such as click statistics and email sending records in drill result reports, meets compliance audit requirements |
| Single recall limit | Top 5 entries | Adapts to the volume of statistical data in drill result reports, avoids redundant information interfering with traceability |
| Data query timeout | 600 seconds | Adapts to query delays from multi-data source association, prevents timeout interrupting traceability workflows |
| Export file limit | 1000 MB | Adapts to batch export requirements for documents in this category, meets storage requirements for audit archiving |

## Three common configuration errors
- Empty citation source after importing a knowledge base: The citation source dropdown menu displays no content. The cause is incorrect configuration of data source association relationships. Channels such as employee contact lists and email gateways were not bound to imported documents.
- Insufficient limit error during citation: An error message returns indicating cited content exceeds limits. The cause is the `quoteMaxToken` configuration value being lower than the average length of the current document. This causes content truncation that prevents successful traceability.
- Citation results cannot be downloaded: The downloaded file lacks key traceability fields. The cause is the `detail` configuration item not being enabled. This means the returned data format does not include necessary association information.

## How to verify correct configuration
- After uploading a phishing email template, drill plan, or drill result report, check if the citation source dropdown menu automatically displays bound data source names.
- Initiate a citation query for a drill result report. Verify the returned results include traceability details such as click statistics and send time corresponding to the `detail` field.
- Test citation content that exceeds the `quoteMaxToken` configuration value. Confirm the system returns expected error prompts.
- Export citation data. Verify the export format matches the format specified by the `responseData` configuration, and includes all required association fields.
