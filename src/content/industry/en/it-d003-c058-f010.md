# Security and Compliance Material Review for Advertising Compliance Traceability: Citation Sources and Traceability
This page configuration is based on FastGPT v4.17.0.

## What this category of data looks like
Data for this category originates from advertising platform backends, customer qualification documents, contract systems, and publicly available regulatory rules. Daily documents include advertising review forms, qualification attachments, delivery records, and rectification notices. Updates are triggered per individual advertising campaign or natural monthly cycle. Each data entry includes fields such as campaign ID, qualification number, delivery period, and compliance review result. Formats must be matched using associated business documents, and no unified fixed unit exists.

## Constraints for citation sources and traceability
Data sources are scattered across multiple independent systems. Systems must support cross-source associated traceability configuration to ensure complete binding between advertising campaigns and their corresponding compliance evidence. Update frequencies vary per campaign or monthly cycle. Systems must adapt to non-fixed-cycle incremental synchronization rules to avoid missing latest delivery records or rectification notices. Document types are diverse and lack unified field standards. Systems must support custom field mapping to match formats of different business documents. Delivery records and rectification notices must be tied to a unique campaign ID. Systems must retain this association during traceability to prevent breaks in the evidence chain that disrupt compliance verification.

## Configuration settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Chunk length | 800–1200 characters | Matches typical length of single advertising compliance documents, avoids truncating key traceability fields such as qualification numbers and campaign IDs |
| Single search limit | Top 5 entries | Covers the number of compliance documents associated with a single advertising campaign, avoids introducing irrelevant data that disrupts traceability |
| Maximum context | 1200–1500 tokens | Fits context length requirements for compliance review queries, retains complete evidence chain information |
| Reranking | Enabled | Prioritizes returning traceability documents strongly bound to campaign IDs, improves traceability accuracy |
| Citation source display | Show source document ID and campaign binding fields | Meets regulatory traceability evidence chain retention requirements, facilitates subsequent verification |

## Three common misconfigurations
- Query results do not associate with compliance document content in the local knowledge base, and only return generic responses. This occurs because binding rules between data sources and advertising campaigns are not configured, so the system cannot match compliance data for the target campaign.
- Traceability results only display document titles, and do not include key fields such as qualification numbers and delivery periods. This occurs because full-field traceability configuration is not enabled, and only document summary information is returned.
- Retrieval requests return timeout errors with status code 504. This occurs because the single search limit is set too high and the chunk length is too large, causing system processing time to exceed preset thresholds.

## How to verify successful configuration
- Upload a single advertising review form to the corresponding data source, submit a query asking for the compliance qualifications of the associated advertising campaign, and check if the query response body includes key fields from the document.
- View the traceability results panel, and confirm that associated information such as source document ID and campaign binding fields is displayed.
- Simulate a batch retrieval request for a single advertising campaign, and check if result return time meets business expectations.
- Test a retrieval request outside of an active campaign cycle, and confirm that the system only returns compliance documents from the corresponding cycle.

The values given are common starting points and should be measured against the reader's own samples.
