# Security and Compliance Material Review for Ad Creative Audit: Citation Sourcing and Traceability

## What data for this category looks like
Core document carriers for this category include ad creatives, landing page screenshots, audit opinions, and modification records. Data sources cover ad placement platforms, landing page servers, product qualification filing databases, and advertising law compliance clause databases.
Update frequency is daily or real-time. Single creative associated fields include unique creative ID, placement channel, copy content, landing page URL, audit node, and violation judgment basis. All data is organized around the core needs of compliance review, with no redundant non-associated fields.

## What constraints do these characteristics impose on citation sourcing and traceability
Ad creative audit traceability requires matching multi-source heterogeneous data.
Ad platform creative data updates in real time. Support immediate pulling of latest placement content to avoid audit results lagging behind actual placement status.
Perform consistency checks for landing page URLs by tracing back to the original landing page server. Relying on cached static data will cause check results to be inaccurate.
Bind traceability of audit opinions and modification records to a unique creative ID. This ensures every compliance judgment links to the original creative and qualification documents, avoiding traceability confusion across creatives.
Synchronize static content from the advertising law clause database regularly. This ensures compliance of traceability bases.
Strictly limit the traceability scope to prevent irrelevant data from interfering with the audit process.

## Configuration settings
| Configuration Item | Recommended Value | Rationale |
| ---|---|--- |
| `quoteMaxToken` | `800–1200 token` | Total length of a single ad creative copy + landing page summary usually falls within this range, avoiding truncation of key information required for traceability |
| `responseData` | `Only return fields related to compliance judgments` | Ad creative audit only requires traceability of compliance-related creative, qualification, and clause data, reducing loading and display of invalid information |
| `detail` | `Enable traceability link jump` | Auditors can jump directly to the original creative or landing page for on-site verification, improving audit efficiency and accuracy |
| Traceability data source scope | `Ad platforms, landing pages, product qualification databases` | These three types are the core data sources for this category, covering all original materials required for compliance review |
| Data synchronization frequency | `Real-time synchronization + daily full incremental update` | In FastGPT v4.17.0, this configuration item can be set through the backend "Data Source Synchronization" page. Real-time updates adapt to audit of in-progress placements, and daily full incremental updates cover missed historical creatives and qualification documents |
| Traceability failure retry count | `2 times` | Avoids platform interface rate limiting caused by frequent retries, while ensuring basic traceability success rate |

## Three common mistakes
- Phenomenon: 404 Not Found error appears when viewing knowledge base citations in chat responses. Cause: The original URL of the landing page is not correctly bound in the traceability configuration, causing the reference link to point to an invalid cached address and failing to jump to the original landing page.
- Phenomenon: After calling the workflow tool, the input and response reference content of the knowledge base search are forcibly displayed in the response. Cause: Non-essential traceability field output is not turned off, causing redundant intermediate steps to be included in the final audit result display.
- Phenomenon: When the code running plugin references a third-party library, it cannot be linked to the compliance qualification basis of the ad creative. Cause: The product qualification database is not configured in the traceability scope, causing the third-party library call to not bind the corresponding compliance qualification documents and failing to complete compliance verification.

## How to confirm the configuration is correct
- Upload a test ad creative, trigger the compliance audit process, and check whether the returned result includes jumpable links to the original creative and landing page URL.
- Turn off non-essential traceability field output, initiate an audit request, and confirm that the final response only displays compliance judgment results, with no redundant search step reference content.
- Simulate a creative update scenario, modify the copy of an uploaded ad creative, and verify whether the real-time synchronized audit result matches the latest creative content and qualification documents.
- Check the system log to confirm that the number of traceability request retries does not exceed the configured 2 times, and there are no frequent interface rate limiting error records.

The values provided are common starting points and should be measured against the reader's own samples.
