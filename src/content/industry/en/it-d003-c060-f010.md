# Security and Compliance Material Review for Ad Account Opening Audit: Citation Sources and Traceability

## What this category of data looks like
Daily processed documents for this category include account opening application forms, scanned business licenses, industry access qualification documents, and account opening audit records. Data sources cover account application ledgers in ad platform backends, subject filing data from the national enterprise credit information publicity system, paper or electronic materials submitted by clients, and public industry access rules. Data updates are triggered by each individual account opening application. Some compliance inspection tasks update on a daily basis. Fields for individual materials include the main body’s unified social credit identifier, qualification validity period, and application submission time. There is no unified fixed unit; corresponding fields are only labeled based on material type.

## What constraints these characteristics impose on the citation sources and traceability link
The decentralized nature of multi-source data requires the traceability link to accurately associate exclusive materials for each application, avoid material confusion across applications, and ensure subject consistency during qualification verification. The update rhythm triggered by applications means traceability must support real-time pulling of newly submitted materials. Fixed caching cannot be relied on, as this may result in the use of expired qualification document data. Mixed processing of multiple document types requires traceability to distinguish source identifiers for different materials such as business licenses and industry qualifications, allowing auditors to quickly locate corresponding content. The most time-consuming qualification verification link relies on traceability to quickly locate matching materials, reducing manual verification communication costs and improving audit efficiency. If traceability errors occur, qualification verification may fail, leading to blocked account opening or compliance risks.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the average length of single account opening audit materials, avoiding truncation of key fields such as qualification numbers and application numbers |
| `responseData` | Return only associated material metadata | Streamlines output content, prevents irrelevant knowledge base content from being included in audit responses, and meets the precision requirements of compliance reviews |
| `detail` | Enabled | Displays metadata such as material source channels and submission time, fulfilling the traceability requirements of compliance audits |
| Single search limit | Top 3 entries | Matches the number of associated materials for a single account opening application, avoiding redundant information that interferes with auditor judgment |
| Cache validity period | Calibrated based on actual testing | Adapts to the update rhythm triggered by applications, preventing the use of expired client-submitted material data |

## Three common mistakes
- Phenomenon: Irrelevant knowledge base citation file lists appear in audit responses. Cause: The return range of `responseData` was not adjusted, and full associated knowledge base content was mistakenly included in audit results.
- Phenomenon: Material source channel identifiers are missing from traceability results. Cause: The `detail` parameter was not enabled, so metadata was not included in the returned content.
- Phenomenon: Key numbers in long qualification documents are truncated. Cause: The value of `quoteMaxToken` was too small, and did not match the actual length of account opening materials.

## How to confirm the configuration is correct
- Submit a simulated account opening application, and check whether the response displays metadata such as the source channel and submission time of the corresponding material.
- Verify that the content cited in the response only includes materials associated with this application, with no irrelevant entries.
- Confirm that key numbers in long qualification documents are not truncated, ensuring complete information.
- Check the cache validity period parameter in the configuration interface, and confirm that it matches the update rhythm requirements of the business.

The values given are common starting points and should be measured against the reader's own samples.
