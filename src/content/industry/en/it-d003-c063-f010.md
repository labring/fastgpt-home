# Security and Compliance Material Review for Campaign Setup: Citation Sources and Traceability

## What This Category of Data Looks Like
Common daily documents involved include campaign setup, targeting settings, budget scheduling, and conversion tracking configurations. Data sources typically originate from advertising platform backends, user profile tag libraries, enterprise budget spreadsheets, and attribution tools. Update frequency is daily or when a single campaign launches. Document fields include target audience package identifiers, budget amounts, conversion event codes, delivery time windows, and more. Units include yuan, user visits, hours, and others. Related fields exist across different documents; for example, the budget amount listed in budget scheduling must match the total budget of the associated campaign setup.

## Constraints for Citation Sources and Traceability
Data sources are scattered, requiring correlation across multiple sources such as advertising platforms and budget spreadsheets. During traceability, accurate matching of related fields across different documents is required. Update frequency is high, with daily or campaign-level updates. Cited document content must be the latest version, to avoid use of expired targeting settings or budget data. Document structures vary; field formats differ across document types, requiring targeted matching of fields corresponding to the cited document type. Campaign setup is a core configuration phase before ad launch. Traceability errors can prevent ad launch or cause budget waste, so citation source uniqueness and accuracy must be maintained.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the average length of campaign setup documents, avoiding truncation of key compliance fields such as targeting and budget settings |
| `responseData` | Return only core fields of associated documents | Reduces redundant content, focusing on data required for campaign setup including targeting settings and budget scheduling |
| `detail` | Enabled | Displays the specific storage path and update time of cited documents, meeting compliance audit requirements for traceability |
| Single search limit | Top 3 entries | Matches the number of documents associated with a single campaign setup, avoiding introduction of excessive unrelated user profile data |
| Maximum context timeout | 600 seconds | Adapts to pull delays across multi-source data, ensuring complete retrieval of all associated document content |
*This configuration applies to FastGPT v4.17.0*

## Three Common Misconfigurations
- Phenomenon: Irrelevant document empty fields appear in citation results, such as failure to properly display the audience package ID in targeting settings. Cause: `responseData` is not configured to return only associated fields, resulting in returned content from unassociated redundant documents.
- Phenomenon: An error prompt pops up during testing, which runs normally after forced ignoring, and only 1 citation entry is displayed in the returned results. Cause: Multi-source data association matching rules are not configured, only a single core document is retrieved, and data from budget spreadsheets or attribution tools is not associated.
- Phenomenon: Budget traceability data for campaign setup does not match actual budget scheduling. Cause: The `detail` module that displays update time is not enabled, resulting in citation of an outdated budget spreadsheet version without synchronized latest budget adjustments.

## How to Verify Correct Configuration
- Upload a complete set of campaign setup, targeting settings, and budget scheduling documents, run a citation traceability test, and verify that returned content includes all core configuration fields of associated documents.
- View the `detail` module in citation results, confirm that the specific storage path and latest update time of the documents are displayed.
- Adjust the value of `quoteMaxToken`, verify that key configuration content of the campaign setup is not truncated, such as fully displaying the identifier information of the target audience package.
- Simulate a multi-document association scenario, confirm that the number of returned citation entries matches the actual number of associated documents, with no missing or excessive irrelevant content.

The values provided are common starting points and should be measured against the reader's own samples.
