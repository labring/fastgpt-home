# Security and Compliance Material Review for Tender Document Preparation: Citation Sources and Traceability

## What the data for this category looks like
The core data for this category is generated around a single tender project. Daily documents include tender documents, qualification certificates, business deviation tables, and technical deviation tables. Data sources are tender announcements, tender documents, enterprise qualification databases, and supplier quotations. The update frequency is once per project, and each tender project corresponds to a separate set of data. The document structure strictly matches the format requirements of the corresponding single tender document, including fixed fields such as tender clause responses, qualification certificate attachments, and quotation details. There is no universal unified format, and adaptation to the personalized rules of different tenderers is required.

## What constraints these characteristics impose on the "citation sources and traceability" link
The independent update per project requirement means the latest tender announcement, qualification database, and quotation data must be retrieved anew before each tender submission, to avoid citing expired content. The lack of a universal document structure means citation traceability must strictly match the specific fields of the single corresponding tender document, and cannot rely on generic templates. The scenario of mixing multiple data sources requires the system to distinguish citation sources such as tender requirements, enterprise qualifications, and supplier quotations, to avoid confusion. The consequences of errors that lead to bid rejection mean the accuracy of citation traceability must meet standards, ensuring every citation corresponds to a specific segment of the original data source.

## How to set the configuration
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the typical content length of a single clause response in tender documents, to avoid truncating key compliance information |
| `responseData` | Return only associated file names and citation segments | Meets the requirement for clear traceable sources in tender document compliance reviews, to facilitate quick verification of cited content |
| `detail` | Full | Ensures citation content is complete and verifiable when checking qualification materials, to avoid qualification rejection risks caused by missing segments |
| Single search limit | Top 6 results | Covers the core requirement clauses of a single tender announcement, balancing retrieval accuracy and processing efficiency |
| Maximum context | 4000–6000 characters | Adapts to context association across multi-page tender documents, ensuring logical consistency in clause responses |

This configuration applies to FastGPT v4.17.0.

## Three common mistakes
- A `quote type error` is displayed in the interface. The cause is that the input citation variable does not match the system preset data source field format, and the fixed metadata of the tender announcement and qualification database is not correctly bound.
- Only a single variable can be selected as the citation source, and multiple data sources cannot be associated. The cause is that the citation pool for multi-variable merging is not configured, and the multi-source data association switch is not enabled.
- The API call does not return the cited file name. The cause is that the metadata return configuration for the `responseData` parameter is not enabled, or the document name return field is not specified in the configuration.

## How to confirm the configuration is correct
- Upload a test sample of a tender document and qualification database, initiate a clause response test, and check whether the generated content includes associated file names and specific citation segments.
- Attempt to select multiple data source variables as citation sources, confirm that multi-variable associated citation is supported after the configuration takes effect.
- Input a custom variable that does not meet the format requirements, check whether the `quote type error` is triggered, to verify that the verification rule is working properly.
- View the generated tender document response content, confirm that the citation segment matches the original data source as expected, with no missing or misaligned context.

The values provided are common starting points and should be measured against the reader's own samples.
