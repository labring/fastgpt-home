# Security and Compliance Material Review for Search Ad Keyword Management: Model Access and Configuration

## What Data for This Category Looks Like
Data for this category primarily originates from search ad backends, search term reports, bidding ranking data, and landing page data. Standard documents processed daily include keyword lists, negative keyword tables, bid records, and search term reports. Fields include keyword text, match type, bid amount, search volume, conversion data, and more. Units include characters, yuan, counts, and others. Data update frequency is typically daily or weekly. Synchronization rhythms vary across ad accounts; some large accounts incrementally sync partial data hourly.

## Constraints Imposed on Model Access and Configuration
Data characteristics for this category impose three clear constraints:
1. Multi-source structured data has inconsistent formats. Files exported from different ad platforms, such as keywords and negative keywords, have differences in field order and encoding. Model access must support batch data import across multiple formats.
2. Daily or weekly update cycles require scheduled synchronization tasks to balance data timeliness and model call resource consumption.
3. Data includes sensitive information such as brand terms and bidding strategies. The compliance review link must limit sensitive content leakage in model context, while adapting to batch data processing token limits to avoid exceeding model call quotas.

## How to Configure Settings
The following configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Value Range | Rationale |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | The context for search ad batch reviews typically includes multiple sets of keywords and associated report content. This range covers the context requirements of conventional batch tasks |
| `maxTokens` | 2000–3000 token | A single compliance review response must cover keyword compliance judgment and optimization suggestions. This range ensures complete, non-redundant output |
| `toolChoice` | auto | Automatically select whether to call the compliance check tool based on input data, adapting to the flexible needs of batch keyword reviews |
| `temperature` | 0.1–0.3 | Compliance reviews require consistent judgment. A lower temperature reduces subjective bias and ensures unified review standards |
| `AIPROXY_API_ENDPOINT` | Root address of the AI Proxy service, for example http://aiproxy:3000. Do not append subpaths such as /v1 or /chat/completions | This variable is a required environment variable for the App/Admin server, used to specify the access address of the AI Proxy service. It is not a single model service address or local ad data storage path |
| `quoteMaxToken` | 500 token per entry | Each keyword compliance review must reference corresponding search term report content. This length covers the reference requirements for single-entry data |

## Three Common Configuration Mistakes
- Phenomenon: Only the single most similar result is returned after a call, and all keywords to be reviewed are not covered. Troubleshooting items: Check whether the `maxTokens` configuration adapts to the context length requirements of the current batch data.
- Phenomenon: Multimodal search term report images cannot be correctly identified, and a visual model is incorrectly called for plain text keyword review tasks. Troubleshooting items: Check whether model call rules are configured separately by data type, and whether the model binding logic for multimodal and plain text tasks is differentiated.
- Phenomenon: The `toolChoice` function triggers abnormally, and the compliance check tool cannot be called automatically. Troubleshooting items: Check whether the `toolChoice` configuration is set to auto, and whether the bound model supports tool call functions.

## How to Verify Successful Configuration
- Upload a single set of keyword lists with fewer than 100 entries, and check whether the model generates complete compliance review results without truncation or missing content.
- Upload plain text keyword files and search term reports with images separately, confirm that the model only calls visual capabilities for tasks with images, as expected.
- View tool call logs, confirm that the number of compliance check tool calls triggered by `toolChoice` matches the number of keywords to be reviewed.
- Configure a scheduled synchronization task, check whether new ad data is automatically pulled and reviewed at the preset daily or weekly rhythm.

The values provided are common starting points and should be evaluated against samples relevant to the specific deployment context.
