# Security and Compliance Material Review for Text Annotation Projects: Citation Source and Traceability

## What Data Looks Like for This Category
The data for this category primarily comes from customer-provided corpora, annotation samples produced by the in-house annotation platform, supporting vocabulary lists, and quality inspection sampling results. Regularly produced core documents include annotation specification details, batch annotation sample packages, quality inspection qualification reports, and problem feedback ledgers. Data updates follow a cycle of daily batches or single annotation tasks. A single data entry typically contains fields for original text, annotation tags, quality inspection markers, and review opinions. It only focuses on content related to semantic boundaries, entity recognition, and intent classification, which differs from the visual feature processing logic of image annotation projects.

## What Constraints These Characteristics Impose on the Citation Source and Traceability Link
The multi-source nature of customer corpora and annotation samples requires precise matching of each text’s original source identifier during traceability, to avoid cross-batch data confusion. The daily or single-batch update rhythm requires the traceability link to support quick location of original documents by task batch. Annotation documents contain multi-level review fields. Traceability must synchronously associate quality inspection and review records to ensure the integrity of compliance review. Text data has no visual dimension information, so source matching can only be performed using metadata and text content features, with no additional visual features available for auxiliary verification.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Value Range | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the average length of single text annotation samples, to avoid truncating valid traceability information |
| `responseData` | Includes original text, tags, quality inspection markers | Covers core traceability fields for text annotation projects, meeting compliance review requirements |
| `detail` | Enabled | Displays complete source association paths, including task batches and update times |
| Single search limit | Top 5 entries | Adapts to the volume scale of single-batch annotation samples, avoiding interference from redundant information |
| Export granularity setting | By task batch | Matches the daily or single-batch update rhythm of this category’s data, facilitating batch traceability and compliance archiving |

## Three Common Misconfigurations
- Exported knowledge base original text links cannot be accessed normally via nginx proxy. The cause is failure to configure source data path mapping rules, resulting in traceability links pointing to internal, unexposed storage addresses.
- Empty fields are returned when obtaining citation sources via API. The cause is failure to enable the `responseData` configuration item, and failure to specify the scope of traceability fields to return.
- The number of traceability results does not match the actual annotation batch. The cause is an overly high single search limit, which pulls redundant cross-batch data and causes confusion in compliance review.

## How to Confirm Proper Configuration
- Initiate a query for a test annotation text, and check whether the returned results include associated information for original text, tags, and quality inspection markers.
- Call the API interface for obtaining citation sources, and verify that the returned fields include metadata such as task batches and update times.
- Export a traceability report for single-batch annotation data, confirm that the export granularity matches the task batch, and no cross-batch data is included.
- Access the exported original text link, confirm that the original annotation sample content loads normally.

The values provided are common starting points and should be measured against the reader's own samples.
