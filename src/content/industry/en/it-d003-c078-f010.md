# Security and Compliance Material Review for Cabinet Rack Installation and Cabling: Source Citation and Traceability

## What data looks like for this category
Typical users of this category are IDC operations engineers and network engineers. Daily processed documents include rack installation applications, cabinet cabling diagrams, port label sheets, and construction records. Data sources are DCIM systems, asset management systems, network topology diagrams, and customer work orders. Update frequency is per order or daily. Document fields include rack unit number, cable specification, port identifier, construction date, and more. Corresponding units are U (rack unit), meter, port number, and others. All content focuses solely on physical access information for physical equipment.

## What constraints these characteristics impose on source citation and traceability
Since data centers around physical access information for a single construction project and updates dynamically with work orders, citation and traceability must accurately match documents associated with the current work order. This avoids mixing in irrelevant data from historical cabinets. Most document types are structured tables and topology diagrams. Retrieval must distinguish port correspondence in cabling diagrams and acceptance status in construction records. This prevents referencing incorrect asset fields. Data sources are scattered across multiple systems. Traceability must link back to entries in the original system. Do not rely solely on chunked abstracts from the knowledge base.

## How to configure settings
The following is an explanation of configuration items for FastGPT v4.17.0:

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1200–1800 token | Matches the typical chunk length for single documents such as cabinet cabling diagrams and port label sheets. Prevents truncation of critical rack unit and port correspondence information |
| `responseData` | Return cited source file names and storage paths | Meets the needs of operations engineers to quickly locate original construction documents. Avoids interference from redundant content |
| `detail` | Enabled | Used to display field details of cited sources, such as port numbers and rack unit numbers in port label sheets. Ensures traceability information can be directly verified |
| Single recall limit | Top 3 entries | Matches the number of associated documents for a single work order. Avoids introducing irrelevant historical cabinet data |
| Citation display toggle | Automatically enabled with search results | Allows operations engineers to directly view cited original document information without additional manual configuration |

## Three common configuration errors
- `quote type error` occurs: The symptom is a format error prompt popping up during knowledge base citation. The cause is that the passed citation source parameter does not match the structured field format of cabinet rack installation documents, and specific fields of port label sheets or cabling diagrams are not correctly associated.
- Cited content exceeds configuration limits: The symptom is that the chunked content retrieved exceeds the value set for `quoteMaxToken`. The cause is that the knowledge base chunk size does not match the value of `quoteMaxToken`, leading to abnormal content truncation.
- Cited file addresses cannot be displayed: The symptom is that the path information of the original document does not appear in the reply. The cause is that the `responseData` configuration item is not enabled, or the configuration is set to only return text content without enabling source address return.

## How to confirm correct configuration
- Upload one cabinet cabling diagram and one port label sheet to the knowledge base. Initiate a query that includes a specific rack unit number. Check if the returned results include cited source file names and storage paths.
- Adjust `quoteMaxToken` to 1000 token. Retrieve a long construction record. Confirm that the returned cited content does not exceed this token threshold.
- Trigger a query related to rack installation applications. Check if the `quote type error` error appears. Confirm that the parameter format is configured correctly.
- View the status of the `detail` toggle in the configuration interface. Confirm that field details of cited sources are displayed in the reply.
