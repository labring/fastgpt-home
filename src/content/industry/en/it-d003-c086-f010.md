# Security and Compliance Material Review for Game License and Publication Declaration: Citation Sources and Traceability

## What the Data for This Category Looks Like
Core data for this category originates from daily work outputs of publishing entities, game distribution legal teams, and project leads. It includes four standard document types: declaration request files, game application forms, copyright certificates, and review reports. Data sources include the National Press and Publication Administration’s service platform, copyright registration systems, game package files, and operating institution filing materials. Update frequency adjusts irregularly based on the declaration progress of individual games. Document structures differ significantly: application forms and certificate files use structured fields, while review reports and request files are unstructured long texts with no unified fixed field unit standards.

## Constraints Imposed on Citation Sources and Traceability by These Characteristics
Dispersed multi-source data requires the traceability link to support recall and association of cross-platform, cross-type documents, to avoid missing key approval basis. Irregular update cycles require the system to support on-demand refreshing of data source indexes, ensuring cited content matches the latest submitted declaration materials. The coexistence of structured and unstructured documents requires retrieval configurations to balance field matching and semantic understanding, while supporting precise extraction of long text fragments. The rigor of approval workflows requires traceability results to be traced back to original files and specific fragments, with no allowance for vague or missing citation records.

## How to Set Configurations
| Configuration Item | Recommended Range | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Adapts to the core citation length of a single compliance material, avoiding truncation of key approval fields and certificate content |
| Similarity threshold | 0.75–0.85 | Balances recall accuracy and material coverage, meets the rigorous review requirements of game license declaration |
| Single search limit | Top 6 results | Matches the upper limit of associated document quantity for a single game’s declaration materials, avoiding interference from redundant information during review |
| Reranking | Enabled | Optimizes fragment sorting for long review report documents, prioritizing keywords related to compliance review |
| `responseData` | Return only source file path and fragment location | Meets archiving and verification requirements for approval material traceability, simplifies compliance audit workflows |
| `detail` | Enabled | Fully returns context content of cited fragments, facilitating verification of material consistency and completeness |

This configuration scheme applies to FastGPT v4.17.0

## Three Common Configuration Errors
- Empty citation fragments appear after enabling reranking. This occurs when the similarity threshold is set too high, causing reranking to filter out all eligible recall results.
- Setting `quoteMaxToken` to an excessively small value truncates key approval fields in declaration materials, preventing cross-document consistency verification.
- After exporting a workflow and importing it to a new environment, cited data source configurations fail. This is caused by failing to synchronize access permissions for the corresponding data sources, or the original data source path not taking effect in the new environment.

## How to Verify Correct Configuration
- Upload a single game application form document, trigger the citation traceability process, and check whether the returned source file path and fragment location accurately match the uploaded content.
- Adjust the similarity threshold range, compare the number of recall results under different thresholds, and confirm that the value range meets the accuracy requirements of business review.
- After enabling the reranking function, import a long review report document, and verify whether the returned citation fragments prioritize keywords related to compliance review.
- Export the workflow JSON file with the current configuration, import it to a test environment, and check whether all cited data sources and parameters are fully loaded and can be called normally.

All provided configuration values are common starting points, and should be evaluated against your own specific samples and operational requirements.
