# Security and Compliance Material Review for Speech Annotation and Transcription: Citation Source and Traceability

## What the Data for This Category Looks Like
The data for this category mainly comes from audio files, annotation platforms, proprietary vocabularies, and spot-check samples. Daily and batch task-related supporting documents include transcription specifications, audio delivery lists, quality inspection reports, and speaker annotation forms. Data is updated daily or per batch task. Data fields cover audio duration, structured transcribed text, speaker identifiers, annotator IDs, and quality inspection results. Units include seconds, characters, entries, and others. The core focus is on structured outputs from audio transcription and full-process annotation information.

## Constraints for Citation Source and Traceability
The non-text nature of audio data requires that citation traceability binds the correspondence between original audio clips and transcribed text, and clearly marks the source node of the annotation link. Data updated daily or per batch requires traceability information to match the task batch, to avoid cross-batch confusion. In multi-document association scenarios, citation weights for different document types must be distinguished during traceability. Citations for proprietary vocabularies must be bound with exclusive source identifiers. Annotation results such as noise segment judgment and speaker differentiation must retain correction traces in traceability, to ensure every step of the annotation process can be traced during compliance review.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Similarity Threshold | 0.75–0.85 | Matches semantic features of speech transcribed text, filters mismatched results from noise segments |
| Citation Limit | Top 10 entries | Adapts to the document volume of single-batch speech annotation tasks, avoids context overflow |
| Rerank Switch | Enabled | Optimizes the sorting logic of speech transcribed text, improves recall rate of relevant segments |
| `quoteMaxToken` | 1200–1500 characters | Matches average length of speech transcribed text, ensures complete citation of key segments |
| `detail` | Enabled | Displays complete annotation process and document association information, meets compliance review requirements |
| Maximum Context | Calibrated via actual testing | Adapts to multi-document association compliance review scenarios, avoids exceeding model processing limits |

## Three Common Configuration Mistakes
- Enabling the rerank switch results in empty retrieval results or missing citation segments. The cause is failure to adjust the similarity threshold synchronously; the rerank mechanism filters valid speech transcribed segments that were on the threshold edge.
- Custom citation templates and prompt words cannot be configured in the open-source version V4.8.22. The cause is that this function is only available in FastGPT v4.17.0 and above; older versions only support basic parameter adjustments.
- Setting the citation limit beyond a reasonable range causes context loading failure. The cause is failure to configure parameters based on the document volume of speech annotation tasks, exceeding the model's context processing limit.

## How to Verify Proper Configuration
- Single-batch speech annotation test data is uploaded, the compliance review process is triggered, and the citation traceability module is checked to confirm whether it displays the correspondence between original audio links, transcribed text segments, and annotation documents.
- The similarity threshold and rerank switch are adjusted, and the number of retrieval results is verified to meet expectations, with no obvious empty results or redundant segments.
- The `quoteMaxToken` and `detail` parameter configurations are checked to confirm that the length of cited segments matches the average character count of speech transcribed text, and that annotation node information is fully displayed.
- The `responseData` parameter is checked to confirm whether it is enabled, ensuring that the traceability interface returns complete source document information.
- Version information is reviewed to confirm that the currently running FastGPT version is v4.17.0 or above, ensuring that custom configuration functions are available.

The values provided are common starting points and should be evaluated against the reader's own samples.
