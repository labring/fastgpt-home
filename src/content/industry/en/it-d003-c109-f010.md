# Security and Compliance Material Review for Identity Account and Permission Management: Citation Sources and Traceability

## What data falls under this category
Data for this category comes from enterprise IAM platforms, HR systems, business system operation logs, and approval systems. Daily produced documents include account application forms, permission matrix tables, terminated account recovery forms, and monthly permission audit reports. Data updates occur via daily synchronization or real-time triggers when personnel are onboarded, offboarded, or have their roles changed. Single data fields include unique account identifier, bound business permission scope, approval process status, and effective and expiration times. The data structure is primarily structured tables, with some approval flow documents being semi-structured.

## What constraints do these characteristics impose on the citation sources and traceability process
Since most data sources are structured and semi-structured documents from internal enterprise systems, and updates are triggered by personnel changes, citation traceability must match real-time synchronized permission status. Uniqueness requirements for fields such as account ID and permission scope require precise matching of field values during traceability to avoid cross-account confusion. Semi-structured approval documents must support extraction of approval nodes and operation times to ensure the traceability chain can be linked to specific approval steps. Additionally, bulk data from audit reports must support filtering citations by time range to meet the cycle requirements of compliance reviews.

## How to configure settings
The following configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | Adapts to the field length of IAM-related documents, avoiding truncation of critical permission information and approval status |
| `responseData` | Includes account ID, permission scope, approval status | Matches the core fields of this category of data, ensuring traceability information covers content required for compliance reviews |
| `detail` | Enabled | Supports extraction of additional information from semi-structured approval documents, such as approver and effective time |
| Single recall limit | Top 3 entries | Adapts to the entry count for IAM data single scenarios, avoiding redundant information interfering with compliance reviews |
| Context citation range | Calibrated via actual testing | Adapts to full-process permission change scenarios for personnel onboarding, offboarding, and role changes in multi-turn conversations |

## Three common configuration errors
- The knowledge base citation option is not displayed in the variable selection panel of the code runtime node, only an empty citation field is shown. This occurs because the `responseData` configuration does not specify extraction of IAM-specific fields, so the system does not include IAM data in the available citation variable scope.
- The response is empty but includes a citation link. This occurs because `quoteMaxToken` is set below 600 tokens, truncating the approval status field of the permission application form, which prevents generation of valid response content.
- Multi-turn conversation context citation cannot be configured, only a single historical data entry is recalled. This occurs because the context citation range is not adjusted to cover multi-turn approval process nodes, and the update rhythm of this category of data triggered by personnel changes is not adapted.

## How to confirm configuration is complete
- Upload a test document of an account application form, trigger citation traceability, and check if the returned citation data includes account ID and approval status fields.
- Adjust `quoteMaxToken` to 1000 tokens, generate a response related to permission audit reports, and check if the response content matches the citation data.
- Enable the `detail` configuration, initiate a query involving the terminated account recovery process, and check if additional information such as approver and effective time is returned.
- Initiate a multi-turn permission application conversation, and check if the system automatically associates account information from historical conversations as a citation basis.

The values provided are common starting points and should be measured against the reader's own samples.
