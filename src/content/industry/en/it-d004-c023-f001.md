# Customer Technical Support and Pre-sales Q&A for IT Budget and Project Portfolio Management: HTTP Interfaces and External Systems

## What this category of data looks like
Daily documents for this category include annual budget sheets, project initiation documents, project portfolio dashboards, and investment review reports. Data sources include financial systems, project management systems, contract ledgers, and business department requirements. Data update frequencies are typically monthly, quarterly, or annually. Core fields include budget amount (unit: ten thousand yuan), project initiation number, priority level, and return on investment. This data is maintained jointly by the CIO office, PMO, and financial business partner teams. Field formats vary slightly across different systems.

## What constraints do these data characteristics impose on HTTP interfaces and external systems
The data characteristics of this category impose multiple constraints on HTTP interface configuration. The need to connect multiple data sources requires interfaces to be compatible with different authentication specifications, with flexible configuration of authentication parameters. The low-frequency update nature means interfaces do not require high-frequency calls, so reasonable caching and timeout strategies can be set. The nested document structure requires that business data returned by interfaces supports layered parsing to avoid missing fields. Temporary business adjustment requirements require interfaces to support dynamic parameter input to adapt to analysis scenarios of different dimensions. The complexity of cross-system data aggregation also requires interfaces to strictly verify the completeness of returned fields to prevent risks such as budget mismatches.

## How to set configurations
The following configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `Authorization` | Configure Bearer Token according to the connected system, with a validity period not exceeding 30 days | Adapt to the authentication specifications of multiple financial and project management systems, reduce the risk of key leakage |
| `variables` | Input parameters such as budget cycle and business department type, with a maximum of 15 parameters | Adapt to analysis scenarios of budget and project portfolio across different dimensions |
| `responseData` | Only return budget amount, project number, and priority level fields | Focus on core business data and reduce invalid transmission overhead |
| Timeout Threshold | 600 seconds | Adapt to the time consumption requirements of cross-system data aggregation, avoid interruptions from cross-system calls |
| Cache Duration | Set according to data update frequency: 720 hours for monthly updated data, 2160 hours for quarterly updated data | Match the update rhythm of this category of data, reduce repeated call costs |

## Three common mistakes
- An interface call returns a `401 Unauthorized` error. The cause is that the `Authorization` parameter is not configured correctly, or the key validity period exceeds the set range.
- The content returned by the interface cannot be correctly populated into AI responses. The cause is that the return value is not parsed according to the field hierarchy of `responseData`, resulting in missing business fields.
- Data interference occurs between different requests. The cause is that independent business parameters are not passed via `variables`, leading to reuse of temporary variables.

## How to confirm correct configuration
- Initiate a test call and check if the returned `responseData` only contains the preset core business fields.
- View the interface authentication log to confirm that the `Authorization` parameter verification passes, with no abnormal errors.
- Initiate two calls with different `variables` parameters and check if the returned results match the input parameter dimensions.
- Wait until the cache duration expires and call again, confirm that the interface has re-pulled the latest data source data.
