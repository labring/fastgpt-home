# Customer Technical Support and Pre-Sales Q&A for IT Budget and Project Portfolio Management: Sharing and Embedding

This document is based on the configuration logic of FastGPT v4.17.0, and provides explanations for the sharing and embedding links in the IT budget and project portfolio management scenario.

## What the data for this category looks like
The data for this category mainly comes from financial systems, project management systems, contract ledgers, and business department requirements. Daily produced documents include annual budget sheets, project approval documents, project portfolio dashboards, and investment review reports. Data update frequencies are mostly monthly, quarterly, or annually. Document structures include hierarchical project information and structured numerical fields such as budget amounts, project cycles, priority levels, etc. There is no unified standardized format, and some documents contain cross-system associated field information.

## What constraints these characteristics impose on the sharing and embedding link
Since the data sources involve multiple heterogeneous systems, configure precise permission mapping in the sharing and embedding link to ensure different visitors only access budget and project data within their corresponding job responsibilities. Since the data update cycle is long, set a fixed synchronization trigger timing for the knowledge base associated with sharing via external systems or the knowledge base itself, to avoid distortion of Q&A results caused by outdated data. Since documents contain structured numerical and hierarchical content, use the FastGPT Q&A tool called via embedding that supports structured field retrieval and associated queries, otherwise it cannot accurately respond to professional questions such as budget priority and project revenue review. In addition, since this scenario targets internal management teams, rely on FastGPT commercial edition identity verification integration or external business system configuration of basic access control capabilities for sharing links and embedded pages, to prevent leakage of sensitive budget information.

## Three common mistakes
- Sharing entries related to IT budget and project portfolio management fail to open. First verify the complete link generated by the system and its validity period, then check the browser request status; do not replace `shareId` yourself.
- The visible scope of IT budget and project portfolio management data does not match expectations. Verify the third-party identity verification results, workflow request parameters, and external system data permissions respectively; the sharing entry identifier itself does not provide business authorization.
- The same IT budget and project portfolio management Q&A cannot be seen on another device. For anonymous scenarios, first verify the device, browser, and local identity status; retention cannot be guaranteed across devices or after clearing cache, do not judge service abnormalities solely based on this phenomenon.

## How to confirm the configuration is complete
- Call the test interface for the sharing link or embedded page, enter a query containing budget fields, and verify that returned results include structured data from the corresponding system.
- Check the iframe configuration of the embedded code, confirm that image zoom and pan operations are allowed outside the iframe.
- View the knowledge base synchronization logs, confirm that the latest synchronization time and data scope match the update cycle of this category.
- Test access to the sharing link with external accounts of different permissions, confirm that only users within the authorized scope can obtain sensitive budget information.
