# Customer Technical Support and Pre-sales Q&A for Ad Creative Review: HTTP Interfaces and External Systems

## What Data for This Category Looks Like
Data for this category primarily originates from advertising placement platforms, landing page resources, product qualification documents, and advertising law compliance clauses. Daily processed documents include single ad creative copy, landing page screenshot files, review feedback opinions, and modification records.
Data updates occur daily or in real time. Single ad creatives include fields such as copy text, image or video links, and delivery targeting tags. Review opinion fields include violation types and rectification requirement descriptions.
Primary users of this data include ad reviewers, agency optimization specialists, and brand compliance staff, who conduct one-by-one compliance checks on each delivery item.

## Constraints for HTTP Interfaces and External Systems
Real-time or daily updated data requires interfaces to support high-frequency calls and incremental synchronization, to prevent review deviations caused by data lag. Single ad creatives contain multiple file and text types, so interfaces must support binary file uploads and structured text parameter passing.
Ad creative review requires one-by-one verification, so interfaces must limit the number of creatives per request to avoid resource overload. Review opinions and modification records must be linked to the corresponding creative ID, so interfaces must support querying historical review data by creative ID to ensure data link traceability.
Compliance checks rely on real-time updates of advertising law clauses, so interfaces must sync access to the latest compliance rule base to avoid outdated verification standards.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `Authorization` | Bearer {assigned API key} | Complies with FastGPT v4.17.0 interface authentication standards to ensure request legitimacy |
| `variables` | Key-value pairs containing creative ID and review status | Pass core identifiers and processing status of ad creatives to facilitate data association |
| `responseData` | Structured JSON containing violation type and rectification suggestion fields | Standardized return results to enable easy parsing and storage by external systems |
| Timeout period | 600 seconds | Adapts to the full verification duration of ad creative review to prevent mid-process interruptions |
| Maximum concurrent requests | 20 requests per minute | Matches the batch processing rhythm of ad review to avoid interface overload |
| Maximum creatives per request | 10 creatives per request | Adapts to the verification load of a single batch of creatives to avoid exhausting interface resources |

## Three Common Mistakes
- Symptom: The interface returns a 401 Unauthorized or 403 Permission Denied status code. Cause: The `Authorization` parameter is not set correctly, or an invalid API key without required permissions is used.
- Symptom: The review results returned by the interface do not match the actual content of the ad creative. Cause: The correct creative ID is not passed in the request's `variables` parameter, leading to misplaced associated data.
- Symptom: Timeout errors occur during batch import of ad creative data. Cause: The number of creatives per single request exceeds the preset interface limit, and request parameters are not adjusted to match the configuration.

## How to Confirm Configuration Is Complete
- Call the test interface, pass a valid API key and set the `Authorization` parameter, then check if the returned `responseData` includes the expected violation type and rectification suggestion fields.
- Review the external system's request logs to confirm that core identifiers and status information of ad creatives are being passed via the `variables` request parameter.
- Simulate batch requests, observe the interface return status, adjust request frequency and number of creatives per request until no abnormal errors occur, matching actual business rhythms.
- Link the database query chain to verify that review opinions and modification records can be correctly written to or read from the associated data of the corresponding creative.
