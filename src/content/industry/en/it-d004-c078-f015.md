# Customer Technical Support and Pre-sales Q&A for Cabinet Rack Installation and Cabling: Knowledge Base Retrieval and Recall

## What Data for This Category Looks Like
Typical users include IDC operation and maintenance engineers, network engineers, and equipment implementation personnel. Daily documents include rack installation applications, cabinet cabling diagrams, port label tables, and construction records. Data comes from DCIM systems, asset systems, network topology diagrams, and customer work orders. Update frequency is per order or daily.
Rack installation applications include fields for application number, equipment model, and cabinet position requirements. Cabinet cabling diagrams mark U positions and cable types. Port label tables record port numbers and corresponding device interfaces. Construction records retain acceptance times and wiring details.

## What Constraints Do These Characteristics Impose on Knowledge Base Retrieval and Recall
Multi-source heterogeneous data sources require the knowledge base to support connection of structured and unstructured documents from different systems. The per-order or daily update rhythm requires configuring incremental synchronization logic to avoid redundant overhead from full retrieval.
Document structures vary widely: there are tabular port label tables as well as text combined with images from cabling diagrams. Retrieval rules must adapt to different formats.
New or changed physical access attributes of equipment require the knowledge base to distinguish documents of existing equipment and new equipment, avoiding interference from inspection-related documents.
Time-consuming links such as cabinet position planning and cable verification require accurate recall of specific cabinet position and port information matching user queries, reducing manual verification costs.

## How to Configure Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Matches structured text such as cabinet cabling diagrams and port label tables, filters low-relevance redundant results |
| `limit` | Top 6 entries | The number of cabinet positions and ports involved in a single pre-sales or support query is limited, and too many results will interfere with decision-making |
| `searchMode` | Precise matching | Suitable for strongly structured documents such as rack installation applications and port label tables, improving retrieval accuracy |
| `usingReRank` | Enabled | Re-ranks initially recalled results by semantics, corrects deviations from keyword matching, and keeps retrieval time within 3 seconds |
| `datasetSearchUsingExtensionQuery` | Enabled | Generates extended queries based on user questions, covering different expressions of cabinet position and cable requirements |
| `collectionIds` | Grouped by cabinet area | Narrows the retrieval scope, reduces recall of irrelevant documents, and improves query speed |

## Three Common Misconfigurations
- Phenomenon: Retrieval returns cable selection suggestions outside the knowledge base, and no prompt indicating inability to answer is provided. Cause: The `similarity` threshold is not configured, low-relevance documents are recalled, and the refusal logic for content outside the knowledge base is not enabled.
- Phenomenon: The model output language does not match the preset English requirements, even if both the knowledge base and prompt are in English. Cause: `datasetSearchUsingExtensionQuery` is not enabled for English scenarios, and the language binding configuration does not match the English knowledge base.
- Phenomenon: Retrieval takes too long to support real-time pre-sales Q&A. Cause: The number of recalled entries from the `limit` parameter is not restricted, or the lightweight `usingReRank` mode is not enabled.

## How to Verify Proper Configuration
- Upload a cabinet cabling diagram and port label table, initiate a query including "Which switch corresponds to the network port in U12 cabinet position", and check whether the recalled results include the corresponding document fragments.
- Adjust the `similarity` parameter to 0.8, initiate a fuzzy query such as "Rack installation requirements for a certain computer room", and confirm that low-relevance results are filtered.
- View the knowledge base update log, and confirm that construction records and rack installation applications submitted per order are synchronized to the knowledge base via daily incremental updates.
- Test an English query such as "Which port corresponds to server in U8", and confirm that English documents are recalled and the model outputs English content.

The values provided here are common starting points and should be evaluated against the reader's own samples.
