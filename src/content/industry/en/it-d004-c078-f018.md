# Customer Technical Support and Pre-sales Q&A for Cabinet Rack Installation and Cabling: Re-ranking and Hybrid Retrieval

## What data for this category looks like
Data for this category typically comes from DCIM systems, asset management systems, network topology diagrams, and customer-submitted work orders.
Daily documents include rack installation application forms, cabinet cabling diagrams, port label tables, and construction records.
Fields include rack unit number, cable specification, port mapping relationship, construction time, and other relevant details.
Data updates occur once per order per day.
Each document covers the full process information for a single device rack installation or change.
There is no unified aggregated batch data for this category.

## What constraints these characteristics impose on re-ranking and hybrid retrieval
Data for this category is updated per order and linked to specific rack units and devices. Retrieval must accurately match the cabinet scope associated with a work order to avoid redundant results across orders.
Documents include strongly correlated fields such as physical location and cable parameters. Hybrid retrieval must match both text semantics and structured field attributes at the same time.
Single document lengths vary widely, from short application forms to complex cabling diagram analysis text. Retrieval and re-ranking logic must adapt to different document lengths.
Data sources are scattered. Structured and unstructured content from multiple systems must be integrated. This places requirements on the cross-source matching capability of retrieval tools.

## Configuration Recommendations
This document is written for FastGPT v4.17.0. The following are configuration recommendations for this scenario:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Similarity threshold | 0.72–0.80 | Accurately match structured fields such as cabinet numbers and port labels, filter low-relevance results |
| Single search limit | Top 10 results | Adapt to the limited volume of documents associated with a single work order, avoid redundant information interfering with pre-sales and technical support conversations |
| Retrieval mode | Hybrid retrieval | Cover both semantic text and structured rack unit data, match associated information from installation applications and cabling diagrams |
| Enable re-ranking | Yes | Perform secondary sorting on initial recall results, correct mismatching issues for documents across cabinets |
| Re-ranking model video memory limit | 1000 MB | Adapt to analysis of large documents such as cabinet cabling diagrams, prevent excessive video memory usage |
| Context length | 800–1200 characters | Match the typical length of single construction records or port label tables, optimize retrieval recall accuracy |

## Three Common Misconfigurations
- Phenomenon: Video memory remains occupied and cannot be released after the re-ranking model runs, eventually triggering an out-of-memory error. Cause: Automatic video memory recycling policy is not configured, and the maximum video memory usage threshold for the re-ranking model is not limited.
- Phenomenon: Retrieval results only return a single type of document, and cannot match both installation application and cabling diagram information at the same time. Cause: Retrieval mode is not set to hybrid retrieval, and only pure semantic retrieval is enabled.
- Phenomenon: An error is prompted when clicking test after configuring the re-ranking model. Forced operation leads to abnormal results. Cause: The document parsing rules corresponding to this category are not bound in the knowledge base configuration, causing formatted documents such as cabling diagrams to not be correctly identified.

## How to Confirm Configurations Are Correct
- Submit a keyword search that includes a cabinet number or port label, check if returned results include cabling diagrams and port label tables for the corresponding rack unit.
- View system retrieval logs, confirm that the re-ranking model is called normally, and that returned results are sorted according to semantic relevance logic.
- Adjust the similarity threshold range, observe changes in the number of retrieval results, and verify that the threshold configuration takes effect.
- Test retrieval for large-sized cabinet cabling diagram documents, confirm that no out-of-memory error is triggered, and verify that the video memory limit configuration takes effect.
