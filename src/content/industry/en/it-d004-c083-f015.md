# Customer Technical Support and Pre-sales Q&A for Game Content Compliance Self-inspection: Knowledge Base Retrieval and Recall

## What Data Looks Like for This Category
This category’s data originates from game text, art assets, plot scripts created during game development, and publicly released regulatory compliance requirements. Maintained documents include content self-inspection checklists, sensitive content modification records, user agreements, and compliance review minutes. Document structures include fields such as version identifiers, inspection items, audit statuses, and associated resource IDs. Updates to this data are triggered by game version iterations or event launches. Each update covers all compliance-related content for the current version or event.

## Constraints Imposed on Knowledge Base Retrieval and Recall
Game content compliance self-inspection data includes multiple content types such as text and art assets. This requires the retrieval and recall workflow to support associated matching across content types. Data is updated frequently alongside versions or events. This requires the knowledge base synchronization mechanism to support switching between incremental and full updates, and to prevent retrieval of expired content. Documents include both structured and unstructured content such as self-inspection checklists and review minutes. Multi-level directories and field differences require the retrieval pipeline to support filtering recall results by document type. Compliance scenarios demand extremely high content accuracy. Recall results must cover all associated compliance basis and historical modification records to support precise pre-sales Q&A and technical support.

## How to Set Configurations
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | Filter low-relevance retrieval results to avoid irrelevant compliance entries interfering with Q&A |
| `limit` | `Top 8–12 entries` | Cover core inspection items for a single version, while controlling total context length |
| `searchMode` | Hybrid vector retrieval + keyword search | Balance semantic matching and precise keyword hits, adapting to field retrieval for structured compliance documents |
| `usingReRank` | Enabled, re-rank top 5 results | Secondary sorting of recall results to improve display priority for highly compliance-relevant content |
| `datasetSearchUsingExtensionQuery` | Enabled, associate built-in compliance thesaurus | Automatically expand compliance-related synonyms and regulatory terms to cover users' vague query scenarios |
| `collectionIds` | Bind the compliance knowledge base collection for the current version, size no more than 1000 MB | Limit retrieval scope to avoid retrieving expired compliance data from non-current versions |

## Three Common Misconfigurations
- Issue: Calling the knowledge base content interface returns a format not supported error, but direct access to the link allows normal download of docx files. Cause: The knowledge base is not configured to support docx document parsing, or the uploaded docx file contains encrypted content.
- Issue: Not all content in Feishu document multi-level directories can be recalled, and doc attachments and images within the document have no retrieval results. Cause: The knowledge base Feishu document multi-level directory synchronization switch is not enabled, and parsing support for images and doc attachments is not configured.
- Issue: Users cannot toggle whether to skip knowledge base retrieval via the interactive logic. Cause: No conditional branch variable is configured in the workflow, and the retrieval switch is not bound to user input options.

## How to Confirm Configurations Are Set Correctly
- Log in to the FastGPT v4.17.0 knowledge base management backend, enter the retrieval configuration page for the target compliance knowledge base, and confirm that values for configuration items such as `similarity` and `limit` match the preset values.
- Upload a test game plot script and self-inspection checklist, initiate a retrieval request, and verify that the recall results include the corresponding inspection items and plot content.
- Trigger a knowledge base synchronization task for a version update, and verify that expired documents are automatically excluded from retrieval results.
- Configure a workflow with user selection variables, test whether the knowledge base retrieval step is correctly triggered or skipped when the retrieval switch is toggled.
