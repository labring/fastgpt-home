# Technical Documentation and API Q&A for Cloud Host Provisioning and Resource Activation: Source Citation and Traceability

## What data for this category includes
Data for this category originates from cloud management platforms, order systems, IAM permission systems, and billing systems. Daily generated documents include resource activation forms, instance configuration sheets, account permission forms, and delivery confirmation forms. Fields include instance ID, compute specification, deployment region, permission scope, order number, billing node, and similar items. Common units are CPU cores, memory in GB, region codes, and more. Data is synced in real time for each individual order. Each document only links to the full delivery workflow for one single cloud host. It only covers configuration and process data related to compute resource creation.

## Constraints for this category on source citation and traceability
Data for this category is distributed across multiple systems. Each document is tied to exactly one cloud host’s delivery workflow. Accurate association of unique identifiers such as instance ID and order number is required to prevent cross-order data mixing. The real-time update feature requires traceability processes to pull the most recent system data directly. Cached copies must not be relied upon. Most document fields are technical configuration items. Original units and formats must be retained to ensure traceability content matches actual delivery configurations. Process documents must be segmented to align with delivery stages, to avoid referencing configuration content from non-current stages.

## How to set configurations
The following configuration logic is based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Single delivery documents for this category are typically around 1000 tokens in length. Full coverage of instance configuration and delivery workflow information is required |
| `responseData` | `Return instance ID, order number, region code` | Traceability for this category requires binding unique identifiers to quickly link full delivery data for the corresponding cloud host |
| `detail` | `Enable original format retention` | Configuration fields for this category include units such as CPU cores and memory in GB. Original formats must be retained to avoid information distortion |
| `quoteMaxToken` | `Adjust in real time per single document` | For extra large delivery confirmation forms, longer token lengths must be supported to fully reference all content |
| `responseData` | `Filter non-associated fields` | Avoid returning redundant billing details. Only retain configuration and permission fields related to the current query |

## Three common configuration errors
- Phenomenon: The context citation area displays plain text instead of Markdown format. Cause: Original format retention for the `detail` configuration is not enabled, leading the system to automatically flatten document format markers.
- Phenomenon: Some queries fail to link to delivery documents in the knowledge base. Cause: Instance ID or order number is not bound as a unique retrieval identifier, leading the system to fail to accurately match delivery data for the corresponding single host.
- Phenomenon: Citation sources include configuration content from multiple cloud hosts. Cause: No single-document limit is set for `quoteMaxToken`, leading the system to pull content from multiple unrelated delivery documents.

## How to confirm configurations are properly set
- Initiate a query that includes an instance ID. Verify that returned citation sources only include delivery documents for the corresponding single host.
- Review the context citation area format. Confirm that Markdown markers from the original document are retained.
- Adjust the value of `quoteMaxToken`. Validate that the length of referenced content changes with the configuration.
- Trigger a query that includes permission configurations. Confirm that IAM-related field information is included in the citation sources.

The values provided are common starting points and should be evaluated against the reader's own samples.
