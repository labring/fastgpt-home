# Technical documentation and interface Q&A for product usage data analysis: citation sources and traceability

This document applies to FastGPT v4.17.0 and later versions.

## What this category of data looks like
Product usage analysis data typically comes from point burying systems, data warehouses, CRM systems, and ticket systems. Most updates occur on a daily or weekly basis. Daily produced documents include usage analysis reports, point burying schemes, indicator caliber tables, and dashboard requirement sheets. Data fields include function identifiers, operation time, operation type, associated customer ID, and indicator values. Units include basic statistical units such as times, minutes, and items. There are no unified complex format requirements.

## What constraints do these characteristics impose on citation sources and traceability
Product usage analysis data has scattered sources and diverse formats. When performing citation traceability, accurately match the fields and update cycles of the corresponding data source to avoid using delayed or mismatched content. Different documents have different indicator calibers. Link the corresponding caliber description documents during traceability to ensure consistency of analysis results. Data update frequency is fixed as daily or weekly. Mark the corresponding cycle during citation to facilitate subsequent abnormal data troubleshooting. There is a demand for combined citation of multiple fields. Traceability configuration must support simultaneous loading of multi-source variables to avoid missing key function operations or customer-related information.

## How to set the configuration
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Maximum citation token count | 800–1200 token | Adapts to the long-text traceability requirements of product usage analysis data, avoids truncating key indicator caliber descriptions |
| Return raw data toggle | Enabled | Used to link specific point burying records or data warehouse table names, meets the accuracy requirements for traceability |
| Traceability detail level | Full | Includes data source system, update cycle, and field information, matches the compliance display requirements of analysis reports |
| Multi-source citation limit | Top 5 entries | Balances traceability information density and reply readability, adapts to combined analysis scenarios with multiple data sources |
| Citation format configuration | Follow the format of "source system + update cycle + indicator caliber" | Unifies traceability display styles, facilitates cross-document indicator verification and abnormal troubleshooting |
| Traceability display toggle | Enabled | Ensures replies include necessary source information, meets the traceability requirements for customer success operations |

## Three Common Misconfigurations
- The interface dropdown menu only displays a single citation variable, and multi-source citation cannot be configured. The cause is that the multi-source citation limit configuration item has not been adjusted, and the default setting limits the number of data sources for a single citation.
- A `quote type error` error is returned when calling the interface. The cause is that the referenced variable format does not comply with the field rules of product usage analysis data, and the standard field naming of data sources such as point burying systems and data warehouses has not been matched.
- The full content of the citation source cannot be hidden in the reply. The cause is that the traceability detail level has not been adjusted to minimalist mode, or the traceability display toggle has not been turned off.

## How to Confirm the Configuration is Complete
- Send a test request, check whether the returned results include the configured traceability fields, such as source system, update cycle, and other information.
- View the optional variable list in the dropdown menu, confirm that all target fields of product usage analysis data are included.
- Simulate input of variables that do not comply with the format, verify whether the `quote type error` error is triggered, and confirm that the format verification rule is effective.
- Turn off the traceability display toggle and send a request, confirm that the detailed content of the citation source is no longer displayed in the reply.

The values provided here are common starting points and should be evaluated against the reader's own samples.
