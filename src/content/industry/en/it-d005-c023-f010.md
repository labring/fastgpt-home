# Technical Documentation and Interface Q&A for IT Budget and Project Portfolio Management: Source Citation and Traceability

## What this category of data looks like
Data for this category comes primarily from financial systems, project management systems, contract ledgers, and business department requirements. Daily generated documents include annual budget sheets, project initiation documents, project portfolio dashboards, and investment review reports. Data update frequencies are typically monthly, quarterly, or annual. Common document fields include project number, budget allocation amount, project approval milestones, portfolio priority, review cycle, and others. Corresponding units include RMB yuan, quarter, year, and additional relevant units.

## Constraints for Source Citation and Traceability
Data sources are scattered, and update cycles vary widely. Documents requiring traceability have distinct format differences. Citation and traceability must support structured and unstructured data exported from multiple systems. The accuracy of budget and project data directly affects decision-making. The traceability link must clearly label the original system, update time, and document version for each cited item. This prevents budget mismatches or distorted decision-making. Project portfolio dashboards and review reports have many associated data points. Cross-document associated traceability must be supported to avoid one-sided information from citing a single document. Data updated monthly or quarterly must show the latest version in traceability records. This prevents decision deviations caused by citing outdated information.

## Configuration Settings
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 9000–11000 token | Adapts to the field density of long documents in this category, retaining key information such as budget amounts and project numbers |
| `responseData` | Enable structured traceability mode | Extracts structured fields from original documents to facilitate quick verification of data sources and update times |
| `detail` | Enable full fragment traceability | Displays the original document location and version information for cited content, supporting retrieval of original contracts or budget spreadsheets |
| Single recall limit | Top 8 entries | Covers project and budget data imported from multiple systems, avoiding missed cross-departmental associated information |
| Version lock toggle | Enable based on update cycle | Matches the monthly/quarterly/annual update frequency of this category, ensuring cited budget and project data is the latest version |

## Three Common Configuration Errors
- Symptom: Only one citation result is returned when calling the knowledge base, and multi-document content cannot be retrieved. Cause: The single recall limit is configured too low, failing to cover budget and project data imported from multiple systems.
- Symptom: The knowledge base selection box is empty, and manual selection is required before use. Cause: No default knowledge base binding is configured, and documents from financial systems and project management systems are not batch-associated with the target application.
- Symptom: Cited content cannot download traceability files. Cause: The full path configuration for `responseData` is not enabled, so traceability links cannot point to the original document storage location.

## How to Verify Successful Configuration
- Submit a test query that includes budget fields or project numbers. Check if the number of cited results in the returned output matches the configured single recall limit.
- Review the traceability details of each citation. Confirm that the original system, update time, and document version are labeled correctly.
- Attempt to click the traceability link or download the traceability file. Confirm that the corresponding original document can be accessed normally.
- Test calling expired historical budget data. Confirm that the version lock toggle takes effect, and only the latest data from the current cycle is retrieved.

The values provided are common starting points and should be evaluated against the reader's own samples.
