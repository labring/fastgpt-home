# Technical Documentation and API Q&A for IT Budget and Project Portfolio Management: Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
The data for this category primarily comes from financial systems, project management systems, contract ledgers, and business department requirements. Daily output includes annual budget sheets, project initiation documents, project portfolio dashboards, and investment review reports. Most data updates occur monthly, quarterly, or annually. Document structures contain structured fields such as budget amount, project duration, priority level, and revenue metrics. Some documents include tabular budget details and project progress data.

## Constraints Imposed by These Characteristics on Knowledge Base Retrieval and Recall
Multi-source and heterogeneous data sources require retrieval systems to support unified indexing of cross-system documents, to avoid data silos. Low-frequency update characteristics mean high-frequency incremental synchronization is unnecessary. Batch update strategies can be used to reduce operation and maintenance costs. Structured fields and tabular content require retrieval models to support numerical matching and tabular content parsing, to accurately match business metrics such as budget amount and project duration. The core business scenarios for this category focus on requirement consolidation and priority sorting. Retrieval results must strictly align with business terminology, to avoid generic content interfering with decision-making.

The following configurations are based on FastGPT v4.17.0.

## How to Set the Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Matches structured business data such as budgets and project priorities, balances recall accuracy and coverage |
| `limit` | Top 8 entries | This category has a large number of knowledge base entries. Controlling return volume avoids context overflow, and fits project portfolio management decision scenarios |
| `usingReRank` | Enabled | Performs secondary sorting on initially recalled results, strengthens relevance of core business content such as budgets and project revenue |
| `datasetSearchUsingExtensionQuery` | Disabled | This category has low data update frequency, no need for additional query expansion, avoids introducing irrelevant business content |
| `collectionIds` | Configured by business department/project type grouping | Precise retrieval scope limitation, excludes non-target category document data, improves retrieval accuracy |

## Three Common Misconfigurations
- Symptom: Full data table content is returned during retrieval. Cause: The `limit` parameter is not configured, or the `similarity` threshold is set too low, leading to recall coverage of the entire knowledge base.
- Symptom: Retrieval results exceed the knowledge base scope, introducing non-budget or non-project related content. Cause: `datasetSearchUsingExtensionQuery` is enabled. The system automatically expands query terms, deviating from the business scope limited by the knowledge base.
- Symptom: Retrieval results cannot be filtered by specified data table columns. Cause: Target column corresponding documents are not split, or `collectionIds` is not configured to limit the corresponding dataset.

## How to Confirm Configurations Are Correct
- Submit queries that include exclusive business fields for this category, such as budget amount and project duration. Verify that the number of returned entries matches the configured retrieval limit.
- Compare result sorting before and after enabling the re-ranking function, confirm that the re-ranking logic adjusts the priority of core business content as intended.
- Check retrieval call logs, confirm that only specified grouped knowledge base collections are retrieved, and non-target data sources are not included.
- Enter generic queries outside the knowledge base coverage scope, confirm that the system does not return irrelevant content, and verify the constraint effect of the similarity threshold.
