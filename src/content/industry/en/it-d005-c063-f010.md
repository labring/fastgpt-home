# Technical Documentation and API Q&A for Campaign Setup: Citation Sources and Traceability
This document is compatible with FastGPT v4.17.0.

## What this category’s data looks like
Core data for campaign setup scenarios comes from ad platforms, user profiles, budget sheets, and attribution tools. Update frequency is typically daily or per single campaign cycle.
Four core types of regularly produced documents include campaign plans, targeting settings, budget scheduling, and conversion tracking configurations. Each document field uses clear business units: for example, budget is measured in yuan, targeting settings use audience tags as dimensions, and conversion events are identified by event IDs. The core content of a single campaign plan document is typically 500 to 1000 characters, with configuration parameters linked to multiple data sources.

## What constraints do these characteristics impose on citation and traceability
Data sources in this scenario are scattered. They are tied to core pre-launch campaign configurations.
Citation traceability must clearly distinguish content from different data sources. Do not confuse ad platform API data with static budget sheet data.
Document update frequencies are flexible. Citations must include the data update timestamp. This enables tracing the latest version during configuration validation.
Fields in single documents are highly specialized. Citations must precisely match specific configuration items. Do not display irrelevant content broadly.
Errors in campaign setup lead directly to budget waste or failed campaign launches. Traceability accuracy and completeness must meet business validation standards.

## How to configure settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | The typical length of a single campaign setup document block is 500-1000 characters. Match the general token conversion ratio to avoid exceeding context limits |
| `responseData` | Return only ad platform and budget sheet data sources | Campaign setup only relies on these two core business data types. Filter redundant content from unrelated data sources |
| `detail` | Enabled | Campaign configuration requires tracing specific fields. When enabled, document format markers are retained, making it easier to view complete configuration parameters |
| Maximum number of citations | Top 5 entries | The volume of configuration data associated with a single campaign plan is limited. Too many citations will interfere with the display of core information |
| Context timeout threshold | Calibrated based on actual testing | Interface response times vary across different ad platforms. Adjust to fit actual call conditions |
| Data source identifier binding | Enabled | Add a data source tag to each citation. Clearly distinguish content from sources such as ad platforms and attribution tools |

## Three common configuration mistakes
- Symptom: The context citation area fails to render Markdown formatted content, only displaying plain text. Cause: The `detail` configuration item is not enabled. Only raw text fragments are returned, and document format markers are not retained.
- Symptom: Some queries fail to trigger knowledge base citations, returning generic responses. Cause: The data source range for `responseData` is not limited. The system does not match campaign setup-related configuration documents.
- Symptom: Citation sources do not show specific types, making it impossible to quickly trace data sources. Cause: The data source identifier binding configuration is not enabled. All citations are displayed uniformly, unable to distinguish content from different sources such as ad platforms and budget sheets.

## How to verify your configuration is complete
- Submit a query about targeting settings. Check if the returned result includes clear data source identifiers.
- View the citation area. Confirm that Markdown formatted lists or bold markers are retained.
- Submit multiple queries for different scenarios. Verify that only citations from campaign setup-related configuration documents are returned.
- Test a query that exceeds the token limit set by `quoteMaxToken`. Observe if the system automatically truncates overly long citation content.

All recommended configuration values are common starting points. Adjust them based on your own sample data and testing results.
