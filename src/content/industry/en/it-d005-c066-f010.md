# Technical Documentation and API Q&A for Search Ad Keyword Management: Source Citation and Traceability

## What the Data for This Category Looks Like
The core data for search ad keyword management includes four types of documents: keyword lists, negative keyword lists, bid records, and search term reports. Data sources are search ad backends, search term reports, ranking data, and landing page data.

Data update frequencies are divided into daily and weekly updates. Bid records and search term reports are updated daily, while keyword lists and negative keyword lists are typically updated weekly.

Document fields include keyword text, match type, single bid, clicks, conversions, and more. Units include yuan per click, clicks, count, and others. Significant field differences exist across data from different sources: for example, search term reports contain actual user search terms, while negative keyword lists only include blocked keyword text.

## What Constraints Do These Characteristics Impose on Source Citation and Traceability
Data sources for search ad keyword management are scattered, with obvious field differences. Citation traceability must accurately match the document type and field of the corresponding data source, otherwise traceability confusion will occur.

Data with different update frequencies requires traceability labels to clearly state the update cycle, to prevent users from using expired data. Additionally, document fields contain multi-dimensional business information, so relevant fields must be fully displayed when citing to support keyword optimization decisions. Only displaying summaries cannot enable accurate verification.

The Q&A scenario for this category focuses on keyword-related operations, so cited content must be strongly relevant to the question. Irrelevant document content should not be included, as this will interfere with optimizer judgment.

## How to Configure Settings
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Suggested Value | Rationale |
| ---|---|--- |
| Maximum Citation Token Count (`quoteMaxToken`) | 800–1200 tokens | The text length of single records for search ad-related documents is concentrated between 100-300 characters. 800–1200 tokens can cover 3 to 4 complete records, avoiding truncation of key business fields |
| Cited Data Return Toggle (`responseData`) | Enabled | Traceability for search ad keyword management requires binding specific fields of original data, such as keywords, bids, and clicks. Only returning summaries cannot enable accurate verification |
| Cited Detail Display Mode (`detail`) | Full Fields | Documents such as keyword lists and negative keyword lists contain multi-dimensional business fields. Full display allows users to quickly verify data sources and content matching |
| Data Source Classification Binding Rule | Bind by Document Type | Data sources include different types such as search ad backends and search term reports. Classification binding avoids traceability confusion |
| Single Recall Citation Limit | Top 5 Entries | Search term report pages typically contain 5-10 entries. The top 5 entries can cover the optimization needs of core keywords |

## Three Common Configuration Mistakes
- Phenomenon: An automatically appended list of all cited files appears at the bottom of the response, which does not match the search ad keyword management Q&A scenario. Cause: Non-essential citation summary toggles were not disabled, and the default full citation display is enabled, resulting in irrelevant document content being listed alongside.
- Phenomenon: Cited content is truncated, making complete bid records or negative keyword list entries unviewable. Cause: The value of `quoteMaxToken` is too small, exceeding the token usage of single or multiple records, leading to truncation of key business fields.
- Phenomenon: Cited sources do not label the update time of the corresponding document, preventing users from judging data timeliness. Cause: Update time field display in cited details was not configured, or data source update time information was not synchronized.

## How to Verify Proper Configuration
- Input a question related to adjusting keyword bids, check if the cited content in the response includes exclusive fields such as bids and match types, and that no irrelevant document content is present.
- View the source identifier in the cited section, confirm that only specified data sources such as search ad backends and search term reports are included, and no other irrelevant knowledge base content is mixed in.
- Adjust the value of `quoteMaxToken`, verify whether the truncation of cited content meets expectations, and ensure that core business fields are not truncated.
- Check if the cited section labels the update time and type of the corresponding document, to ensure that traceability information is complete and traceable.
