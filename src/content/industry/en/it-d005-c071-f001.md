# Technical Documentation and Interface Q&A for Data Desensitization: HTTP Interfaces and External Systems

## What this category of data looks like
This category of data originates from enterprise databases, data dictionaries, self-developed desensitization tools, and access approval systems. Updates are performed per project batch or single data transfer. Daily generated documents include desensitization plans, field mapping tables, desensitization verification reports, and approval records. Core fields include sensitive field identifiers, desensitization rule types, verification result statuses, and approval node information. No unified fixed units are used; values are adjusted flexibly based on project configuration.

## Constraints on HTTP Interfaces and External Systems
Data sources for this category are scattered and updated per project. HTTP interfaces must support dynamic configuration of data source mapping rules to adapt to return formats of different systems. Daily generated documents include approval records, so interfaces must carry permission verification parameters to ensure access compliance. There is a requirement for pre-identification of sensitive fields, so interfaces must support field-level data filtering capabilities. Update frequencies are adjusted flexibly per project, so interfaces must support on-demand data synchronization triggering. Since errors involve compliance risks, interfaces must add a secondary verification step for desensitization results to prevent sensitive information leaks.

## Configuration Guidelines
| Configuration Item | Recommended Practice | Rationale |
| --- | --- | --- |
| `Authorization` | Carry access tokens in the format `Bearer <token>` | Used for permission verification when connecting to external desensitization tools, complies with general API security specifications |
| `variables` | Bind a mapping table of 10–50 fields | Adapts to desensitization field rules updated per project, supports dynamic adjustment of sensitive fields |
| `responseData` | Only return desensitized data fields | Prevents leakage of non-desensitized data, meets compliance requirements |
| Timeout threshold | 300 seconds | Adapts to time-consuming desensitization processing scenarios, avoids interface interruptions caused by large data volumes |
| Retry count | 2 times | Addresses temporary call failures of external desensitization tools, ensures stability of data transfer |
| Version adaptation | Bind to FastGPT v4.17.0 | Ensures compatibility between interface functions and platform versions, avoids configuration conflicts |

## Three Common Configuration Errors
- Phenomenon: A 401 Unauthorized status code is returned when calling the desensitization interface. Cause: The `Authorization` parameter is not configured correctly, and a valid access token is not carried in the request.
- Phenomenon: Global variable tokens cannot be passed to the desensitization interface in a workflow. Cause: The `variables` parameter is not bound in the interface configuration, and global variables are not mapped to interface request parameters.
- Phenomenon: The interface return result includes non-desensitized sensitive fields. Cause: The `responseData` filtering rule is not configured, and the requirement to only return desensitized data fields is not specified.

## How to Verify Successful Configuration
- Initiate a test data call that includes sensitive fields. Check whether the authentication status code returned by the interface matches expected values, to confirm that the authentication configuration has taken effect.
- Submit a preset test data set. Check whether the returned result only contains desensitized data fields, to confirm that the data filtering rules have taken effect.
- Submit preset global variables when calling the interface. Check whether the interface request parameters carry the corresponding variable values, to confirm that variable binding has taken effect.
- Review the platform version adaptation log. Confirm that there are no version conflicts between the interface configuration and FastGPT v4.17.0.
