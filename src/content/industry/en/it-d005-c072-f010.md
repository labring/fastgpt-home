# Technical Documentation and API Q&A for Data Collection Task Design: Citation Sources and Traceability

This document is compatible with FastGPT v4.17.0.

## What the data for this category looks like
Data for this category is generated around collection projects. Daily documents include collection plans, sample specifications, authorization statements, and task schedules. Data sources include customer requirements, public data sources, collection tool outputs, and internal sample libraries. Update cycles are typically adjusted per single project or weekly. The sample scope, field specifications, and compliance requirements for each project change based on requirements. Data fields include sample identifiers, collection sources, compliance status, task progress, and more. There are no unified fixed units, so fields must match the specific requirements of the project.

## Constraints for Citation Sources and Traceability
Data for this category is mostly project-level temporary content with frequent updates. Citation traceability must be bound to the collection plan and authorization documents of the specific project to prevent cross-project misuse. Data sources are scattered, so each sample’s collection source must be accurately marked to avoid confusion between public data and internal sample library content during traceability. Field specifications are adjusted per project, so traceability fields must support dynamic matching of the current project’s field definitions. Fixed templates cannot be used. Additionally, results from the collection compliance check process must be synchronized into traceability information to mitigate infringement risks.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | The single-document length of collection task content mostly falls within this range, which can cover core traceability content |
| `responseData` | Full traceability fields | All required information must be retained, including sample identifiers, collection sources, compliance status, and more |
| `detail` | Enable detailed traceability | Association information between collection plans and authorization statements must be displayed |
| Maximum number of citations per request | Top 5 | The sample batch for collection tasks usually does not exceed this number, which avoids information redundancy |
| Traceability matching accuracy | Calibrated via actual testing | Must match the custom field specifications of the project to adapt to traceability requirements for different projects |

## Three Common Configuration Mistakes
- The issue: Citation traceability fails to accurately match the collection documents of the specified project. Cause: The data source range parameter of the corresponding project is not bound, resulting in traceability results mixed with data from other projects.
- The issue: The number of citations cannot be limited to a fixed quantity, and can only be adjusted via fractions. Cause: The maximum number of citations per request setting is not configured, or the configuration does not take effect correctly.
- The issue: Authorization statement fields are missing from the traceability information referenced from the knowledge base. Cause: The full traceability field return mode is not enabled, and only core summary content is returned.

## How to Verify Successful Configuration
- Launch a test collection task, and check whether the returned traceability information includes corresponding document content such as collection plans and sample specifications.
- Adjust the maximum number of citations per request setting, and verify whether the number of returned traceability documents matches the adjusted requirement.
- Check the collection source markers in the traceability information to confirm whether they are consistent with the data source range of the current project.
- Review the parameter descriptions in the configuration interface to confirm that all setting items match the collection requirements of the project.

The values provided here are common starting points and should be measured against the reader's own samples.
