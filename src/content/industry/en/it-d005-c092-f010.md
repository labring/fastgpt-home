# Technical Documentation and API Q&A for On-Site Deployment: Citation Sources and Traceability

## What data for this category looks like
Data for this category primarily comes from first-hand resources including customer on-site computer room environments, equipment lists, software installation packages, and network topology diagrams. Four types of documents are regularly produced: deployment manuals, installation records, configuration lists, and on-site check-in sheets.

Data updates occur once per single-phase task or completed single order. Document fields include deployment node identifiers, software version numbers, configuration parameter values, on-site check-in times, and more. There is no unified fixed general field format. Configurations must match the actual on-site deployment requirements of customers.

## What constraints do these characteristics impose on the "citation sources and traceability" workflow
Data comes from real-time on-site customer resources and updates per phase. Citation traceability must match the currently deployed software version and on-site nodes to avoid calling expired historical configuration data.

Non-standard on-site document structures require traceability to support custom field matching logic, rather than relying on fixed-format general fields. The single-order independent update feature requires traceability context to be isolated per task, preventing cross-order configuration data confusion.

Most on-site deployment resources are offline or local files. Traceability must support direct association of local files and permission verification.

## How to set configurations
The following configurations are based on FastGPT v4.17.0 backend logic:

| Config Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | Matches the average single-paragraph length of on-site deployment documents, ensures cited content fully covers deployment steps and configuration parameters |
| `responseData` | Enable local file association mode | Adapts to offline document sources for on-site deployment, directly associates locally stored deployment manuals and configuration lists |
| `detail` | Enable detailed traceability mode | Displays specific fields of on-site documents such as equipment model and installation time, to meet troubleshooting needs of implementation engineers |
| Maximum context rounds | First 3 rounds of conversation context | Limits context scope within a single order, avoids cross-order data interference, aligns with the per-order execution characteristic of on-site deployment |
| Citation matching threshold | 0.75–0.85 | Adapts to non-standard formats of on-site documents, balances recall accuracy and coverage, calibrated based on actual testing |

## Three Common Misconfigurations
- Phenomenon: When accessing the application via a login-free share link, the citation source pop-up still appears even if the citation view function is disabled. Cause: The traceability permission switch in the share scenario was not disabled synchronously in the application configuration, resulting in incomplete configuration coverage of all access channels.
- Phenomenon: FastGPT replies only return a citation list, with no main text content. Cause: The value of `quoteMaxToken` is too small to accommodate the main text content, only citation metadata is loaded.
- Phenomenon: On-site deployment configuration information from the previous round cannot be associated in multi-turn conversations. Cause: The context scope isolated per task was not configured, resulting in cross-turn context being cleared or confused.

## How to Confirm Configurations Are Correct
- Upload an on-site deployment configuration list in the application backend of FastGPT v4.17.0, initiate relevant Q&A, and check whether the returned results include citation traceability links for configuration fields.
- Adjust the value of `quoteMaxToken`, test whether citation content of different lengths can be fully loaded, and confirm no truncation or loss occurs.
- Switch to login-free share mode, and verify whether the citation view function is enabled or disabled synchronously with the configuration.
- Initiate multi-turn deployment troubleshooting Q&A, and confirm whether the context retains the previous round's on-site node information.
