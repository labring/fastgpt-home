# Technical Documentation and API Q&A for Landing Page Conversion Optimization: Source Citation and Traceability

## What the data for this category looks like
The core data for landing page conversion optimization typically comes from landing page access logs, heatmaps, form data, and advertising utm parameters. Associated daily documents include landing page plans, tracking requirement documents, AB test reports, and form field lists. Data update frequency is usually weekly or within a single campaign cycle. Fields typically include page path, dwell time, form submission status, advertising utm parameters, and more. There are no uniform fixed unit requirements. Matching the field definitions of the corresponding documents is necessary.

## What constraints do these characteristics impose on the source citation and traceability link
The multi-source nature of data requires that citation traceability link advertising clicks and landing page behavior. Each citation block must correspond to specific advertising source parameters and page behavior data. Differences in update frequencies require contextual citations be limited to the current campaign or weekly cycle, to avoid mixing historical data that interferes with analysis. The structured nature of daily documents requires cited content match the fields of the documents. For example, fields in tracking requirement documents must correspond to fields in form data. The most time-consuming analysis process requires contextual citations accurately filter redundant information, reducing the loading and analysis costs of invalid content. Errors will prevent lead attribution and make advertising cost accounting impossible. The accuracy of citation traceability directly impacts business outcomes.

## How to configure settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1500–2000 token | Matches the total token volume of conversion data for a single campaign landing page, to avoid exceeding context window limits |
| `responseData` | Return only citation source ID and advertising utm parameters | Facilitates passing cited source parameters as variables into business request bodies, to complete the associated traceability of landing page data and advertising campaigns |
| `detail` | Enabled | Displays the document section or log snippet corresponding to the citation block, to assist in troubleshooting page path and form blocking issues |
| Maximum context entries | Top 8–12 entries | Matches the core data volume used in daily analysis, to avoid redundant information interfering with experimental result judgment |
| Citation matching threshold | 0.75–0.85 | Matches the field accuracy of landing page documents and log data, to reduce citations of irrelevant content |

## Three common configuration errors
1.  Phenomenon: The number of context entries displayed in the interface does not match the number sent to the calling API, and also does not match the actual number of citation blocks from the knowledge base. Cause: The truncation rule for `quoteMaxToken` was not configured according to the campaign cycle, resulting in historical landing page data from non-current campaigns being included.
2.  Phenomenon: Knowledge base blocks exceeding the set limit are still added to the context after configuring a citation upper limit. Cause: Only the total token limit was set, and single-block length verification was not enabled, leading to ultra-long landing page document blocks being directly cited.
3.  Phenomenon: Cited sources cannot be linked to corresponding advertising campaign information. Cause: Advertising source parameters were not configured for return in `responseData`, leading to missing traceability information.

## How to confirm correct configuration
- Review calling logs to confirm that the fields returned by `responseData` include landing page source ID and advertising utm parameters.
- Check the total token count of the context window to confirm it does not exceed the set `quoteMaxToken` value.
- Verify that the `detail` information of citation blocks corresponds to the current campaign’s landing page documents or log snippets.
- Trigger a landing page analysis request to confirm that the number of returned context entries matches the set maximum context entries.

The values provided are common starting points and should be measured against the reader's own samples.
