# Technical Documentation and Interface Q&A for Speech Annotation and Transcription: Citation Sources and Traceability

## What data for this category looks like
Data sources for this category include audio files, annotation results exported from annotation platforms, proprietary vocabularies, and random inspection quality control samples. Daily produced documents include transcription specifications, audio task lists, quality inspection reports, and speaker annotation forms. Data updates run daily or per batch task cycle.
The data structure centers around audio transcription results, including fields such as speaker identifiers, timestamps, transcribed text, and annotation tags. Association between original audio clips and annotation operation records is required, which differs from text annotation processes that directly handle text.

## What constraints do these characteristics impose on citation sources and traceability
This category’s data characteristics impose three constraints on traceability.
First, data sources include original audio, annotation platform records, vocabularies and other reference materials. Traceability must associate multiple types of sources, and cannot rely solely on transcribed text.
Second, the rhythm of daily or per-batch task updates requires traceability systems to support quick filtering of associated documents by task batch, to avoid mixing data across batches.
Third, structured fields such as speaker identifiers and timestamps require traceability results to retain corresponding metadata, and cannot return only unstructured text fragments.

## Configuration settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Matches the average length of a single speech transcription text, to avoid truncating key metadata such as speaker identifiers and timestamps |
| Maximum number of citation sources | Top 3–5 entries | Associated documents for a single batch of speech annotation tasks usually do not exceed 5, to avoid introducing irrelevant data across batches |
| `responseData` | Includes original audio path, annotation batch number | Adapts to the requirement of associating multiple types of sources for this category, supplementing non-text traceability information |
| `detail` | Enabled | Retains original fields of transcribed text, such as speaker tags and timestamps, to meet structured traceability requirements |
| Source filtering rules | Filter by task cycle | Adapts to the data characteristics of daily or per-batch updates, quickly locating associated documents for the current task |

## Three common misconfigurations
- Symptom: Markdown-formatted document content fails to render in the context citation area. Cause: The `detail` configuration is not enabled, only plain text transcription results are returned, and original document format fields are not retained.
- Symptom: Associated files in the knowledge base cannot be matched after a query. Cause: Source filtering rules are not configured by task batch, so the traceability scope covers expired or non-current task annotation documents.
- Symptom: A large number of noisy fragment annotation records are included in citation sources. Cause: The value of `quoteMaxToken` is not limited, resulting in recall of overly long non-critical annotation content that interferes with effective traceability.

## How to confirm correct configuration
- Initiate a test query for the current speech annotation task, check whether the citation sources include the original audio path and annotation batch number.
- Check whether the citation results retain structured fields such as speaker identifiers and timestamps, to confirm that the `detail` configuration is enabled.
- Trigger a cross-batch test query, confirm that the system only recalls associated documents within the current task cycle, and does not introduce expired data.
- Adjust the value of `quoteMaxToken`, verify that the length of the cited content matches the average length of current transcribed text.

The values provided here are common starting points, and should be evaluated against the reader's own samples.
