# Test Cases and Defect Analysis for Independent Innovation Replacement Adaptation: Model Access and Configuration

## What this category of data looks like
Data for test cases and defect analysis of independent innovation replacement adaptation comes from existing system inventories, domestic hardware and software catalogs, test environments, and publicly available vendor materials. Data is updated per project or quarterly. Daily produced documents include adaptation lists, compatibility test reports, migration plans, and issue ledgers. Data fields include system name, adaptation status, defect severity, test case number, and more. Units are primarily units, items, days, and similar. There is no unified fixed standard format, and adjustments must be made based on actual project requirements.

## What constraints these characteristics impose on the "model access and configuration" link
Data sources are scattered and formats are inconsistent. Model access must support mapping and standardization of heterogeneous fields. Configurations must therefore balance flexibility and compatibility. Data scale varies widely between project updates, so configuration parameters must support adjustment per project. Independent innovation replacement adaptation involves verification of hardware and software stack replacement. Model calls rely on a unified AI Proxy service. Strict compliance with environment variable configuration requirements starting from FastGPT v4.17.0 is required. Do not fill server-side required parameters in other interfaces. Do not confuse configuration items for AI Proxy and upstream models.

## How to set the configurations
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | Root address of the AI Proxy service, for example `http://aiproxy:3000` | Mandatory requirement starting from FastGPT v4.17.0. Do not append `/v1` or `/chat/completions` paths |
| `AIPROXY_API_TOKEN` | Administrator token consistent with the AI Proxy server configuration | Official mandatory requirement. Cannot be empty. Do not use application API keys or model vendor keys as replacements |
| `temperature` | `0.3–0.7` | Test case classification and defect analysis require consistent stable output, avoiding excessive randomness or inflexibility |
| `maxTokens` | `8000–16000 token` | Content lengths of documents such as adaptation lists and defect ledgers are typically large. This setting avoids truncation of critical analysis information |
| `toolChoice` | `auto` | Supports the model to independently select tools related to adaptation testing, completing test case generation or defect localization |

## Three common mistakes
- Symptom: When calling tools in advanced orchestration, the model cannot automatically select subsequent execution tools. Troubleshooting steps: Check if the `toolChoice` parameter is configured correctly, or check if FastGPT has correctly configured the `AIPROXY_API_ENDPOINT` and `AIPROXY_API_TOKEN` environment variables.
- Symptom: An error is reported when rearranging model calls, prompting authentication failure. Troubleshooting steps: Check if the AI Proxy administrator token and model vendor key are confused, and the latter was incorrectly filled into the `AIPROXY_API_TOKEN` environment variable of the FastGPT server.
- Symptom: FastGPT service startup verification fails, prompting missing required environment variables. Troubleshooting steps: Check if `AIPROXY_API_ENDPOINT` was not set correctly, if an extra path was appended to the address, or if the `AIPROXY_API_TOKEN` environment variable was not set.

## How to confirm the configuration is complete
- Check the FastGPT server startup logs to confirm there are no missing required item error reports related to AIPROXY.
- On the model channel configuration page, submit a call test for the upstream model to verify link connectivity.
- Submit a test case analysis request to confirm the model can output expected classification or analysis results.
- View the AI Proxy service monitoring logs to confirm there are legitimate requests from FastGPT, with no abnormal interceptions.
