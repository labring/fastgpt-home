# Test Case and Defect Analysis for Feed Ad Creative Testing: Citation Source and Traceability

## Data Characteristics for This Category
Core data for feed ad creative testing comes from ad delivery platforms, internal material storage repositories, user interaction logs, and conversion statistics systems. Daily work documents include creative scripts, material test sheets, delivery data reports, and iteration lists. Most document structures combine tables with text notes. Core fields include creative combination identifiers, test cycles, interaction metrics, and conversion metrics.
Data is updated daily or weekly. Material variables and test results for different test batches are archived to corresponding document entries separately.

## Constraints Imposed on Citation Source and Traceability
Data sources are scattered, so multi-source information from ad platforms, material libraries, and conversion systems must be linked. The traceability process must accurately match individual creative combinations, using matching methods targeted at material units.
Most daily documents are table-based, so traceability requires locating specific script lines or test sheet entries, corresponding to individual entries within the documents. Data updates daily or weekly, so citation sources must be refreshed regularly to maintain information timeliness.
Creative variables are combinations of images, videos, and copy. Traceability must bind to specific material units to avoid incorrect cross-batch associations. Errors will lead to reduced click-through rates and increased costs, so traceability accuracy directly affects the credibility of test conclusions.

## Configuration Settings
Configuration options under FastGPT v4.17.0 are referenced below:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Matches the total length of feed ad creative copy and material descriptions, avoids truncating critical traceability information |
| `responseData` | Includes material ID, delivery batch number, test entry number | Links to specific entries in creative test sheets and delivery reports, enabling precise traceability |
| `detail` | Enabled | Displays complete material source and test background information, meets optimizer traceability needs |
| Maximum Context Window | `Previous 3–5 conversation turns` | Discussions around feed ad creative testing usually focus on recent rounds of variable adjustments and result analysis, covers necessary context scope |
| Citation Source Refresh Frequency | `Once every 12–24 hours` | Matches the daily update rhythm of delivery data, ensures timeliness of cited information |
| Associated Document Scope | Creative scripts, material test sheets | Covers core document types used in daily work, prevents unrelated documents from being included in traceability scope |

## Three Common Configuration Errors
- When accessing the application via a guest login share link, the citation original text function shows as unavailable. This occurs because the citation source permission configuration for the share page is not enabled, or configuration items are not synchronized to the share link.
- No citation paragraph is displayed at the end of knowledge base responses. This occurs because the `detail` parameter is not enabled, or the configured `responseData` does not include necessary document identifier fields.
- Context cannot be linked during consecutive questioning, and subsequent questions receive off-topic answers. This occurs because the maximum context window is set too small, or the multi-turn conversation context binding logic is not enabled.

## How to Verify Correct Configuration
- Upload a creative test sheet and creative script, initiate a question related to test cases, check if associated document entries are displayed at the end of the response.
- Generate a guest login share link, access the link, click the citation icon, confirm that the corresponding position in the target document is accessible.
- Initiate 3 consecutive rounds of test optimization questions, confirm that responses link back to test discussion content from the first two rounds.
- Adjust the `quoteMaxToken` parameter, check if the length of cited source information in the response matches the configured token range.

The values provided are common starting points, and should be evaluated against local samples.
