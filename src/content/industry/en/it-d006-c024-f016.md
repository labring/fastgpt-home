# Test Case and Defect Analysis for Feed Ad Creative Testing: Forms and Interactions

## What This Category's Data Looks Like
Relevant data for feed ad creative testing mainly comes from advertising platforms, material libraries, user interaction data, and conversion data, with a daily or weekly update frequency. Daily associated documents include creative scripts, material test sheets, delivery data reports, and iteration checklists, which focus on creative variable combinations, test execution results, and delivery performance. Data fields cover creative types, material identifiers, interaction metrics, and conversion metrics. No additional statistical values are included, only basic information is recorded in accordance with standard test processes.

## What Constraints These Characteristics Impose on Forms and Interactions
Data sources for this category are scattered and have a clear update rhythm, requiring the form interaction link to support field mapping across multiple data sources. Synchronization logic is handled by external business systems or subsequent workflow nodes. The creative variable design phase is the most time-consuming; batch configuration and templated options need to be implemented by external business systems or subsequent workflow nodes to reduce operational costs. Since errors will directly lead to reduced click-through rates, increased costs, or material violations, pre-validation and error interception logic must be implemented by external business systems or subsequent workflow nodes. Additionally, feed ad creative testing mainly compares combinations of images, videos, and copy, differing from the keyword management process of search ads. Forms must design dedicated interaction logic for this type of combination testing.

## Three Common Mistakes
- Phenomenon: An "input content exceeds limit" error appears after submitting the test form, with no pre-interception prompt. Cause: The external business system or subsequent nodes did not configure the length validation rules for `formInput`, and did not intercept excessive content during the input phase.
- Phenomenon: Selected test materials cannot be correctly associated with the variable data of the corresponding test case. Cause: The external business system or subsequent nodes did not configure the mapping rules between materials and test case variables, and did not associate the corresponding fields in the material test sheet.
- Phenomenon: Importing materials in non-image, non-video, or non-text formats fails to trigger a violation prompt. Cause: The external business system or subsequent nodes did not configure the material format validation rules for the form, and did not filter invalid material types.

## How to Confirm Proper Configuration
- Enter creative copy that exceeds the length preset by the external business system or subsequent nodes, and verify whether the external validation logic pops up an interception prompt in real time.
- Select different material groups in the `userSelect` node, and verify whether the external business system or subsequent nodes can correctly reference the variable data of the corresponding materials.
- Import a local material test sheet, and verify whether the external business system or subsequent nodes can automatically match and fill in corresponding fields such as creative type and material ID.
- Submit a test form containing duplicate creative combinations, and verify whether the external business system or subsequent nodes will automatically filter duplicate entries.
