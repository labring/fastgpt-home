# Test Cases and Defect Analysis for Image Annotation Projects: Citation Sources and Traceability

## What This Category of Data Looks Like
Data for this category primarily comes from image samples, category dictionaries, spot check results, and rework lists generated by annotation platforms. Daily supporting documents include annotation specifications, bounding box examples, and quality inspection reports.
Data is updated daily or synchronized per annotation batch. Core fields include target bounding box coordinates, category labels, annotator identifiers, quality inspection results, and similar items. Common units are pixels, category numbers, and batch numbers.
Processing targets are position and category information for visual objects, which differs from the semantic content processing logic used for text annotations.

## What Constraints These Characteristics Impose on the Citation Sources and Traceability Link
Data sources for this category are scattered across image samples, annotation platforms, spot check results, and rework lists. The multi-system data setup requires the traceability link to bind a unified batch identifier to enable cross-platform data association.
Data is updated daily or per annotation batch. Corresponding batch timestamps must be matched to avoid mixing annotation data across different batches.
Core fields include visual information such as target bounding box coordinates and category labels. During traceability, pixel information and annotation version for individual images must be bound to each entry.
Daily supporting documents such as annotation specifications and bounding box examples must be linked to specific annotation steps as citation bases. This ensures traceability covers the full workflow.

## Configuration Setup

| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Citation content for image annotations includes visual metadata such as bounding box coordinates and category labels, requiring sufficient tokens to carry complete traceability information |
| `responseData` | Enabled | Original data fields such as annotation batches and image IDs must be returned to support multi-dimensional association for traceability |
| `detail` | Full | Details such as annotators, quality inspection results, and rework records must be displayed to meet traceability requirements for defect analysis |
| Single Recall Limit | `Top 5 entries` | Traceability data for an annotation batch typically includes no more than 5 associated records, avoiding redundant returned information |
| Citation Display Location | End of paragraph | Matches the common user habit of viewing annotation traceability, corresponding to the newly added citation display logic |
| Citation Timeout Threshold | `60 seconds` | Annotation data queries must match batch and image information, avoiding excessively long wait times that disrupt quality inspection workflows |

## Three Common Misconfigurations
- Scenario: When accessing the application via a login-free shared link, even if the citation view function is disabled, users still see a prompt that traceability content cannot be viewed. Cause: The associated configuration of the citation data source was not disabled synchronously, leaving background traceability logic active.
- Scenario: No citation marker is displayed at the end of a knowledge base answer paragraph. Cause: The full mode of the `detail` configuration item was not enabled, or the citation display location was not set to end of paragraph. This results in citation content not being mounted to the correct position.
- Scenario: The number of returned citation query results does not match expectations, or a timeout error occurs. Cause: `quoteMaxToken` and the timeout threshold were not set appropriately. Insufficient tokens prevent complete traceability data from being carried, or an overly short timeout threshold fails to complete multi-field association queries.

## How to Verify Proper Configuration
- Initiate a test query that includes annotation batches and image IDs. Check whether returned results include the traceability fields specified in the configuration.
- View the end of the answer paragraph to confirm that annotation-related citation links or information are mounted.
- Adjust the value range of `quoteMaxToken` to verify traceability content completeness across different values.
- Simulate a login-free access scenario to confirm that the citation view function switch operates according to the configured settings.

The values provided are common starting points and should be measured against the reader's own samples.
