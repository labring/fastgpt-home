# Test Cases and Defect Analysis for Security Product Rule Operations: Workflow Orchestration

## What the data for this category looks like
The data for this category mainly comes from WAF, IDS, firewalls, and threat intelligence platforms. Daily associated documents include rule change tickets, intercept logs, false positive analysis reports, and policy rollback records. Data update frequency is daily or triggered by protection events. Document fields include rule ID, effective time, intercept hit count, false positive judgment result, rollback operator, and others. There is no unified standardized field format, and fields vary across different protection products.

## What constraints these characteristics impose on the "workflow orchestration" link
Decentralized data sources and inconsistent formats require the workflow to support multi-source data pull and adaptation, and define multi-data source mapping rules via `variables` configuration. Fluctuating update frequencies require setting node timeout thresholds to adapt to real-time or batch pull scenarios. No unified document field format requires allowing custom field mapping nodes to avoid hard-coded field names. The false positive analysis and policy review links account for a high proportion of total time, so configure parallel processing nodes to split analysis tasks. Severe consequences occur if protection policy changes contain errors, so add pre-check nodes and rollback trigger branches to ensure automatic policy recovery during exceptions.

## How to set configurations
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Multi-data source mapping configuration | Configure corresponding field mapping rules by protection product type | Adapt to differences in data formats across products such as WAF and IDS |
| Node timeout threshold | 600-1800 seconds | Adapt to time requirements for real-time event pull and batch log processing |
| Custom field mapping | Enable field name editing permissions | Compatibility with non-standardized document fields across different protection products |
| Number of parallel task nodes | Parallel processing for the first 3-5 tasks | Reduce time spent on false positive analysis and policy review |
| Pre-check trigger | Automatically execute after rule change submission | Intercept non-compliant policy changes in advance |
| `variables` configuration | Define global protection rule ID and log time range variables | Unify parameter calls within the workflow and avoid hard coding |

## Three Common Mistakes
- No available plugin options when a workflow node calls external MCP functions. The cause is that MCP plugin permissions are not enabled in the global configuration, and the plugin is not bound to the corresponding workflow node.
- No return result after the code running node executes. The cause is that correct code running environment dependencies are not configured, or the node timeout threshold is set too short for the task to complete.
- No optional values when referencing knowledge base variables. The cause is that the value range of the global variable is not declared in the `variables` configuration, or the data source permissions of the corresponding knowledge base are not bound.

## How to Confirm the Configuration is Complete
- Manually trigger a rule change workflow, check if the log data pulled from multiple data sources matches the real-time logs on the protection platform.
- Submit a test rule change application, verify that the pre-check node can intercept non-compliant configurations.
- View the `variables` configuration list, confirm that global variables such as protection rule ID and log time range have been correctly declared and bound to the data source.
- Trigger a false positive analysis task, check that multiple analysis subtasks are started simultaneously by the parallel nodes, and the total time spent meets expectations.

The values provided are common starting points and should be measured against the reader's own samples.
