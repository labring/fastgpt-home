# Test Cases and Defect Analysis for Security Baseline Checks: Citation Sources and Traceability

## What Data for This Category Looks Like
Data for this category primarily comes from server configurations, middleware configurations, security device policies, and baseline tool outputs. Update frequency is monthly or quarterly. Daily deliverables include baseline checklists, configuration verification records, rectification recommendations, and exception approval forms. Data fields include configuration item number, compliance status, verification time, original configuration value, exception approval description, and more. Single data entries fall within the hundreds-of-characters range. The overall structure is fixed and tightly linked.

## Constraints Imposed on Citation Sources and Traceability Workflows
Scattered data sources mean traceability requires linking original verification records across multiple systems, with precise matching between configuration items and their corresponding documents. Low update frequency makes referenced historical data relatively stable, but regular refreshes are needed to align with the latest baseline versions. Fixed document structure requires traceability fields to exactly match configuration items in baseline checklists, to avoid mixing verification results across different items. The most time-consuming steps — configuration item verification and exception reason confirmation — require traceability links to quickly locate original verification records, cutting down manual verification costs. The risk of misconfigured settings remaining active long after an error means traceability data must be fully accurate and complete.

## Three Common Mistakes
- Citation documents appear in the debug page but not in the official chat page. This occurs because the traceability display switch is only enabled in the debug environment, and related settings are not synchronized in the application release configuration.
- Configuration item verification results cannot be extracted from knowledge base citations. This happens because the text extraction component is not linked to the specified configuration item field in the traceability knowledge base, and only generic text content is extracted.
- The number of citation sources does not match the expected value. This is caused by using citation limit parameters intended for generic knowledge bases, instead of configuration items optimized for security baseline check scenarios.
