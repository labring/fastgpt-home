# Test Cases and Defect Analysis for Ad Creative Review: Workflow Orchestration

## What Data for This Category Looks Like
This category of data primarily comes from advertising placement platforms, landing page hosting services, product qualification filing systems, and advertising law compliance clause libraries, with a daily or real-time update cadence. Daily processed documents include ad creative files, landing page screenshots, rectification opinions issued by reviewers, and creative modification history records. Data fields include creative unique identifiers, placement channel types, violation point classifications, rectification completion status, audit timestamps, and no additional custom statistical units.

## Constraints Imposed on Workflow Orchestration by These Characteristics
Data sources are scattered and have large differences in update cadences. This requires configuring multiple data source pull nodes when orchestrating workflows, to separately connect to the advertising platform creative library, landing page verification interfaces, and compliance clause libraries. Multiple types of document inputs need to adapt to different format parsing logic to avoid node compatibility issues. Real-time updated data requires workflows to support on-demand triggering of runs, to avoid invalid resource consumption from fixed-cycle execution. High-risk error outcomes require adding pre-checks, failure retries, and exception alert nodes during orchestration, to ensure that the execution results of each link are traceable and facilitate subsequent compliance audits.

## How to Set Configurations
| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| Data Source Trigger Timing | Triggered by creative update events; poll once every 600 seconds when no events are present | Matches the real-time or daily data update cadence of this category, reducing invalid data pull attempts |
| Single Pull Data Volume | 100–200 creative records | Balances node load and batch processing efficiency, and adapts to the standard single-batch processing scale of ad creative review |
| Node Timeout Threshold | 300–600 seconds | Covers time-consuming audit links such as landing page loading and compliance clause queries |
| Failure Retry Count | 2 retries | Addresses temporary network fluctuations or interface jitters, avoiding misjudgment as permanent audit failure |
| `variables` Scope | Workflow global | Ensures core audit parameters such as creative IDs and violation types are not lost when passed across nodes |
| Node Execution Order | Pull data first → validate format second → perform compliance check last | Aligns with the standard business logic of ad creative review, avoiding unnecessary computations |

## Three Common Mistakes
- Phenomenon: Workflow canvas lags when dragging nodes, with a several-second delay in status display. Cause: FastGPT v4.17.0 is not used; older versions such as 4.6.5 have unoptimized canvas rendering logic, leading to performance bottlenecks when there are a large number of nodes.
- Phenomenon: The workflow runs normally in the preview page, but returns no results in the chat page. Cause: The global transfer scope of `variables` is not configured, leading to context parameters not being correctly brought into the audit node in chat scenarios.
- Phenomenon: When configuring form-data parameters for an HTTP request node, landing page screenshot files cannot be uploaded correctly. Cause: The correct file source field is not specified in the file parameter item, or the file format verification rules for ad creative review are not matched.

## How to Verify Proper Configuration
- Trigger an audit workflow for a test creative, view the execution logs of each node, and confirm that the number of records pulled from the data source matches expectations.
- Simulate an abnormal scenario where the data source interface is temporarily disconnected, and verify whether the failure retry node triggers retries and alert actions as configured.
- Check the `variables` configuration panel, confirm that core audit parameters are set to be globally transferable, to avoid parameter loss across nodes.
- Compare the workflow node execution order with the standard ad creative review process, and confirm that the execution logic of each link matches business requirements.

The values provided are common starting points and should be measured against the reader's own samples.
