# Test Cases and Defect Analysis for Ad Creative Review: Citation Sources and Traceability

## What the Data for This Category Looks Like
The core data for this category comes from advertising placement platforms, landing page resources, product qualification documents, and advertising law compliance clauses. Daily processed documents include single ad creative copy, landing page screenshot files, rectification opinions issued by reviewers, and creative modification iteration records. Data updates occur daily or in real time. Each creative uses an independent review pipeline, with fields including creative ID, placement channel, violation type, rectification status, and more. All data focuses on compliance verification for a single placed creative, with no additional custom fields or units.

## What Constraints These Characteristics Impose on the Citation Sources and Traceability Link
Since data sources cover advertising placement platforms, landing page resources, product qualifications, and compliance clauses, citation traceability must support cross-data-source association matching. This ensures audit conclusions can be linked to original compliance basis. The real-time or daily update rhythm of data requires the traceability pipeline to adapt to both incremental synchronization and full verification modes. This meets the timeliness requirements of different review scenarios. The feature that each creative uses an independent review pipeline requires traceability results to be bound to specific creative IDs and version identifiers. This prevents confusion of review data across different creatives. Audit opinions and modification records must be associated with the original creative version. Thus, the traceability link must retain version traces of creative iterations. This supports accurate backtracking for defect analysis.

## Configuration Settings
These configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Covers the typical text length of ad creative copy, audit opinions, and compliance clauses, to avoid truncation of core traceability information |
| `responseData` | Enable source field return | Binds creative ID, placement channel, and version identifier to match the precise traceability requirements of individual review pipelines |
| `detail` | Enable full traceability mode | Displays original compliance clause text, landing page screenshot links, and product qualification document paths to support detailed defect verification |
| Single search limit | Top 5 results | Matches the number of data source types associated with a single creative, to avoid redundant results interfering with audit judgments |
| Maximum context validity period | 600 seconds | Adapts to the real-time update rhythm of advertising platform and landing page data synchronization, ensuring the timeliness of traceability results |

## Three Common Misconfigurations
- Phenomenon: Cited sources displayed in conversation outputs do not include the ID and version information of the corresponding ad creative. Cause: The source field binding logic of `responseData` is not enabled, and traceability results are not linked to individual review pipelines.
- Phenomenon: Traceability results return a large volume of historical data unrelated to the current review creative. Cause: The single search limit configuration value exceeds the number of associated data source types for a single creative, and no precise filtering is applied.
- Phenomenon: Cited advertising law compliance clause text is truncated, with key judgment basis missing. Cause: The `quoteMaxToken` configuration value is too small, and does not cover the total text length of compliance clauses and creative copy.

## How to Verify Correct Configuration
A single ad creative copy awaiting review is submitted to trigger traceability verification, and whether returned results are bound to the corresponding creative ID and version identifier is verified.
The displayed content of cited sources is reviewed, and compliance clauses, landing page links, and other information are confirmed to not be truncated, falling within the configuration range of `quoteMaxToken`.
The single search limit is adjusted to Top 3, verification is triggered, and whether the number of returned traceability results matches the set value is checked.
The configured maximum context validity period is waited, then traceability is triggered again, and whether real-time updated advertising platform data has been synchronized to the traceability results is confirmed.

The values provided here are common starting points, and should be evaluated against the reader's own samples.
