# Campaign Setup Test Cases and Defect Analysis: Workflow Orchestration

## What data looks like for this use case
The data for this use case mainly comes from advertising platform APIs, user profile tag libraries, budget scheduling tables, and attribution tools. Daily produced documents fall into four categories: campaign plans, targeting settings, budget schedules, and conversion tracking configurations. Core fields include targeted audience package ID, budget amount (unit: yuan), conversion event type, delivery time period, and more. Data update frequency is daily or per single campaign cycle. The volume of associated data for a single campaign plan changes based on campaign scale.

## What constraints these characteristics impose on workflow orchestration
Data sources are scattered and require integration with multiple tools. Workflows must include multi-data source verification links to ensure field formats from each source match.
Data updates occur at a daily or campaign cycle level. Workflow trigger timing must align with business update rhythms to avoid repeated processing of expired data.
Documents contain strongly associated fields such as targeted audiences, budgets, and conversion events. Workflows must verify field completeness and legality to prevent delivery failures caused by missing fields.
Delivery errors directly waste budget. Workflows must add pre-verification and failure retry links to reduce invalid operation risks.

The following configurations are based on FastGPT v4.17.0.

## How to set configurations
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `variables` | Bind targeted audience package ID and budget amount fields returned by advertising platforms | Match core business fields of campaign plan documents to avoid increased maintenance costs from hardcoding |
| Node timeout setting | 600 seconds | Match typical response time ranges of advertising platform APIs to prevent long-term blocking of workflow processes |
| Trigger timing | Trigger 24 hours before campaign launch | Align with daily or campaign-level business data update rhythms to ensure latest targeting and budget data is used |
| Failure retry count | 2 times | Address temporary interface fluctuations from advertising platforms to reduce workflow interruptions caused by single anomalies |
| Data source verification switch | Enabled | Verify format legality of budget amounts and conversion events to intercept invalid configurations early |
| `nodeId` | Assign unique identifiers to chart tool nodes | Ensure correct routing when multiple nodes are called in workflows and avoid data confusion |

## Three common configuration mistakes
- No output after workflow node runs, with prompt showing no running results | Cause: Failed to correctly bind data source fields corresponding to `variables`, or did not configure code running dependency environments during local deployment.
- Workflow triggers large model search even when the knowledge base is empty | Cause: Did not configure a data source verification link, and did not check whether the campaign plan document contains valid configuration content.
- Empty charts generated after chart tool calls | Cause: Did not correctly map conversion tracking event data to chart tool input fields, or did not verify whether data volume meets tool requirements.

## How to confirm configuration is complete
- Review the `variables` binding configuration of the workflow to confirm it matches core fields of the campaign plan document one-to-one.
- Review the `nodeId` configuration of chart tool nodes to confirm each node has a unique, non-duplicate identifier.
- Simulate workflow triggering, check running logs of each node to confirm data source verification links pass normally.
- Manually trigger a node error to confirm the failure retry mechanism executes per the configured number of times.
- Call the chart tool with test conversion data samples to confirm charts are generated normally.

The values provided here are common starting points, and should be evaluated against the reader's own samples.
