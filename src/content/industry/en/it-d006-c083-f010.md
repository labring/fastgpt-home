# Test Case and Defect Analysis for Game Content Compliance Self-Check: Citation Sources and Traceability

## What this category of data looks like
This category of data covers game plot text, character lines, art annotation copy, compliance self-check list items, and original text of regulatory compliance requirements. Daily documents include content self-check lists, sensitive content modification records, user agreements, and compliance review minutes. Data updates follow game version or operational activity cycles. Data fields include content snippets, review status, associated version numbers, and modification traceability records. Sources include in-game produced content and public regulatory requirements. This page is compatible with FastGPT v4.17.0.

## What constraints do these characteristics impose on citation sources and traceability
Data updates follow version or activity cycles, so traceability must tie to corresponding version identifiers to prevent cross-version citation failures. Data sources include in-game text, art assets, and public regulatory documents. Traceability paths for different sources must be distinguished to help auditors accurately locate original content. Daily documents include modification records and self-check lists, so traceability must link to modification traces to facilitate tracing adjustment processes for controversial content. Compliance scenarios have high requirements for traceability accuracy. Key information must not be truncated, and associated fields must not be omitted, to ensure audit process traceability.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum citation token count | 800–1200 token | Adapts to single-segment length of game plot text and compliance documents, avoids truncating key traceability information |
| Returned data source fields | Include original text snippets, version numbers, modification time | Matches traceability field requirements for game compliance data, covers version and modification records |
| Citation details toggle | Enabled | Returns complete citation source paths, facilitating auditors to trace back to original self-check lists or regulatory documents |
| Maximum number of citation sources | Top 5 entries | Controls traceability entries per round of responses, avoids information overload that reduces audit efficiency |
| Context cache duration | 24 hours | Matches game version update cycles, prevents cross-version citation failures, ensures consistent traceability information within the same version |
| Traceability matching threshold | Calibrated via actual testing | Adapts to different characteristics of game text and art assets, ensures recall accuracy |

## Three common configuration errors
- Phenomenon: API call returns status code 200 but no content value is returned. Cause: Correct data source fields are not configured, and original text snippets of game compliance documents are not associated.
- Phenomenon: Citation sources are displayed incorrectly, no version numbers or modification records are included, and adjustment processes cannot be traced. Cause: The citation details toggle is not enabled, or fields for returning version numbers and modification time are not configured.
- Phenomenon: Downloaded knowledge base original text links are inaccessible. Cause: Proxy paths for game version updates are not bound, causing traceability links to point to old version resources.

## How to confirm correct configuration
- Initiate a test request, check whether returned results include preset traceability fields such as original text snippets and version numbers.
- View the citation source list, confirm that the number of entries meets the configured upper limit, with no excessive redundant information.
- Click the traceability link, verify that original documents or resources can be accessed correctly, with no access errors.
- Simulate a version update scenario, submit new compliance data, check whether traceability information is tied to the corresponding version identifier.
