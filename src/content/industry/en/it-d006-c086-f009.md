# Test Cases and Defect Analysis for Game License and Publication Declaration: Tool Calling and Plugins

## What Data for This Category Looks Like
Game license and publication declaration data originates from official government service platforms, copyright registration systems, game package files, and operating institution filing materials. Daily processed documents include declaration request files, game content application forms, copyright ownership certificates, and content review reports. Document structure varies slightly based on the declaration entity and game type. Core fields include declaration entity information, game name and version number, copyright number, review opinions, and provincial preliminary review feedback. Data updates occur irregularly per game, with incremental supplementation as the declaration process advances.

## Constraints Imposed by These Characteristics on Tool Calling and Plugins Workflows
This document applies to FastGPT v4.17.0 and later versions. Documents in this category have inconsistent structures and come from scattered sources. Tool calling plugins must support multi-format document parsing and custom field extraction rules. Data updates follow no fixed schedule, so tools must support on-demand material verification and validation workflows. Core fields have strict consistency requirements. Tool calling must precisely match the fixed fields specified for declarations, to avoid approval failures caused by missing or incorrect fields. Data sources include official systems and local files, so plugins must support cross-source data comparison functions.

## How to Configure Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | Specified as `function` | Explicitly call the pre-configured declaration material processing tool, prevent the model from randomly calling unrelated functions |
| `functionCall` | Pass a parameter template containing core declaration fields | Adapt to the fixed field requirements of game license declarations, ensure extracted information complies with official formats |
| Single tool call timeout | 600 seconds | Reserve sufficient execution time for package comparison and multi-document integration during declaration material review |
| Context length limit | 8000–12000 characters | Accommodate complete core document content including declaration requests, review reports, and copyright certificates |
| Number of results returned per call | Top 3 entries | Limit redundant information returned by tools, focus on core declaration fields |
| Tool result validation rule | Validate consistency against declaration fields | Ensure extracted information matches the declaration fields required by official channels, reduce approval risks |

## Three Common Mistakes
- A 500 status code is returned after calling the tool. Troubleshooting steps: The App/Admin server failed to correctly configure the environment variable `AIPROXY_API_ENDPOINT` (AI Proxy service root address) and the non-empty `AIPROXY_API_TOKEN` (AI Proxy administrator Token). This may cause the proxy link to fail to connect or start verification failure.
- Field extraction returns empty when importing game packages or review reports. Troubleshooting steps: No parsing plugin configured to adapt to non-standard declaration document formats, which may prevent the tool from correctly identifying document content.
- Authentication failure errors are returned during tool calling. Troubleshooting steps: Confused the AI Proxy administrator Token (corresponding to environment variable `AIPROXY_API_TOKEN`) with the application API Key, and used incorrect authentication credentials to initiate the request.

## How to Verify Successful Configuration
- Check the environment variables on the App/Admin server, confirm that `AIPROXY_API_ENDPOINT` (AI Proxy service root address) and the non-empty `AIPROXY_API_TOKEN` (AI Proxy administrator Token) are correctly configured.
- Upload a standard game application form document, trigger a tool call, and verify whether the returned fields match the document content.
- Initiate a tool call request for complete declaration materials, check whether the returned results include expected field comparison and review opinion integration content.
- Check server runtime logs, confirm there are no records of AI Proxy connection failures or authentication errors.
