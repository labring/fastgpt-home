# Test Cases and Defect Analysis for Game License and Publication Declaration: Citation Sources and Traceability

## What the Data for This Category Looks Like
The data for this category primarily comes from official government service platforms, copyright registration systems, game package files, and filing materials submitted by operating institutions. Daily processed documents include four categories: declaration request files, game application forms, copyright certificates, and review reports. Each category of documents has fixed fill-in fields. For example, copyright certificates include registration numbers and right holder information, while review reports include content compliance verification items. Data updates occur irregularly, triggered by the declaration process for each individual game, with no fixed cycle.

## Constraints Imposed by These Characteristics on Citation Sources and Traceability
Cross-type documents from multiple sources require precise matching of corresponding fields during citation to avoid mixing information from different documents. Irregularly updated data must have their version validity verified during citation to ensure declaration materials use the latest filed version. Exclusive documents for a single game must be bound to the corresponding declaration process, and citation traceability must be associated with a unique declaration identifier to prevent mixing of materials across processes. Additionally, citations of compliance-related documents must clearly correspond to specific verification links, ensuring that traceability links back to specific review opinions to meet approval traceability requirements.

## How to Configure Settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the average length of single-segment content in declaration documents to avoid truncating key approval fields |
| `responseData` | Enabled | Retains document identifiers and metadata for citation sources, used for compliance traceability verification |
| `detail` | Full display | Ensures all fill-in information of documents can be viewed during traceability, meeting approval requirements |
| Single citation limit | Top 3 entries | Corresponds to the number of core materials for a single game declaration, avoiding redundant information interfering with review |
| Citation cache duration | 24 hours | Adapts to the conventional review cycle of declaration processes, avoiding referencing expired data |
| Version verification switch | Calibrated based on actual testing | Adapts to irregularly updated filed data, ensuring the latest valid version is referenced |

## Three Common Configuration Mistakes
- The symptom is redundant knowledge base citation links appearing in responses. The cause is that non-essential citation display configurations were not disabled, resulting in output of traceability information that exceeds approval requirements.
- The symptom is key approval fields being truncated in cited content. The cause is that the `quoteMaxToken` setting value is too low, resulting in truncation of core fill-in information from documents.
- The symptom is that the cited document version does not match the version required for the current declaration. The cause is that the version verification configuration was not enabled, so the system did not automatically match the latest filed data.

## How to Confirm Configurations Are Properly Set
- Test queries related to declaration materials can be initiated, and responses checked for traceable document identifiers and metadata.
- Configuration parameter values for citations can be reviewed, confirming that `quoteMaxToken`, single citation limit, and other parameters match the content length and quantity requirements of declaration documents.
- Updated filed data can be simulated for submission, and the system verified to automatically reference the latest document versions.
- Response output content can be checked, confirming that only citation information meeting approval requirements is displayed, with no redundant content.

The values provided are common starting points and should be evaluated against local samples.
