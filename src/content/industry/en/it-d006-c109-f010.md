# Test Cases and Defect Analysis for Identity Account and Permission Management: Citation Sources and Traceability

## What data for this category looks like
This category's data primarily comes from enterprise IAM systems, HR systems, business system logs, and approval systems. Updates occur daily, or in real time when personnel are onboarded, offboarded, transferred, or have role adjustments. Daily associated documents include account application forms, permission matrices, offboarded account recovery forms, and compliance audit reports. Data fields include account unique identifiers, permission binding rules, approval workflow nodes, effective and expiration times, and other relevant fields. Individual data entries have small volume but multiple associated dimensions. Cross-validation across multiple data sources is required to complete full traceability.

## Constraints on citation sources and traceability
The multi-source, heterogeneous data characteristics of this category require establishing cross-system account unique identifier mapping rules for the citation traceability link. This prevents account confusion across IAM, HR, and business systems.
The high-frequency update cadence requires the traceability link to support real-time pulling of the latest permission configurations and personnel change data. This prevents use of outdated permission rules.
The full-process association feature across multiple documents requires binding full node records including account applications, approvals, and offboarded account recoveries during traceability. This ensures citation sources can be traced back to original operations.
Hard compliance audit requirements require traceability data to retain complete operation logs and approval traces. This supports subsequent permission anomaly troubleshooting and compliance verification.

## How to configure settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | This category's data includes multiple associated contents such as permission matrices and approval records. Sufficient citation length is needed to fully display traceability information |
| `responseData` | Return original fields from associated systems | Core fields including account unique identifiers, permission binding rules, and effective/expiration times must be retained. This ensures accurate cross-system data matching during traceability |
| `detail` | Enable full-link traceability mode | This category requires binding full process nodes including account applications, approvals, and offboarded account recoveries. Enabling this mode obtains complete operation logs and approval traces |
| Single search limit | Top 5 entries | This category has limited associated permission data per entry. The top 5 entries cover common anomaly permission troubleshooting scenarios, avoiding interference from redundant data |
| Maximum context | `1500–2000 characters` | This needs to support associated display of multi-source data. It ensures complete viewing of traceability links during test cases and defect analysis |

## Three common configuration errors
- Phenomenon: An input error pops up when citing data related to identity account and permission management, and the workflow fails to run. Cause: Cross-system account unique identifier mapping rules are not configured. FastGPT cannot match associated data across IAM, HR, and business systems, triggering parameter verification failure.
- Phenomenon: Citation traceability results only display single-system data, and cannot show the complete approval process. Cause: The `detail` full-link traceability mode is not enabled. Only permission data from a single node is pulled, and full-process records are not associated.
- Phenomenon: The knowledge base citation limit cannot select custom intermediate values, only preset interval values can be used. Cause: The associated display requirements of multi-source data in this category are not adapted. The default configuration does not open custom intervals. The `quoteMaxToken` parameter must be manually adjusted to cover the required length.
