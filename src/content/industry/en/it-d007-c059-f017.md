# Online Troubleshooting and Post-Mortem for Ad Creative Review: Deployment and Upgrade

## What This Category’s Data Looks Like
Ad creative review data comes from ad delivery platforms, landing page links, product qualification documents, and advertising law compliance clauses. Data updates occur daily or in real time. Core documents include individual ad creatives, landing page screenshots, rectification opinions issued by reviewers, and creative modification history records. Data fields include creative copy content, landing page compliance check items, violation point annotation types, review status, and modification timestamps. Individual data volume fluctuates with creative complexity, with no unified fixed length limit.

## Constraints Imposed on Deployment and Upgrade by These Characteristics
The real-time or daily update data characteristics of ad creative review require the deployment phase to adapt to high-frequency, small-batch data writes and compliance check requests. Multi-source data access (ad platforms, landing pages, product qualifications, etc.) requires upgrades to support changes to different interface formats, and avoid interrupting daily review workflows. The lack of a fixed length for individual creatives places elastic requirements on vector storage and retrieval configurations, and prevents storage or transmission limits from being triggered by oversized individual data. The need to associatively store review opinions and modification records requires deployment to ensure the linkage stability of databases and caches, and prevent data inconsistency in review workflows.

## How to Set the Configurations
These configurations are written based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `REDIS_URL` | `redis://:your_password@your_host:6379/0` | Adapts to high-frequency cache check requirements, reduces direct database query pressure, and supports fast responses for real-time reviews |
| `MONGODB_URI` | `mongodb://your_user:your_pass@your_host:27017/fastgpt?authSource=admin` | Stores associative data such as review opinions and modification records, supports flexible document-based queries and associative retrieval |
| `DB_MAX_LINK` | `200` | Matches the single-batch data access limit for ad creative review, prevents service interruptions caused by exhausted database connection pools |
| `STORAGE_S3_ENDPOINT` | Configure a dedicated endpoint based on cloud service provider region | Stores large-volume resources such as landing page screenshots and creative source files, adapts to multi-region data synchronization and access requirements |
| `FE_DOMAIN` | Enter the external access domain name of the ad review platform | Ensures link consistency for review result callbacks and front-end display, avoids failures in external interface calls |
| `PG_URL` | `postgresql://your_user:your_pass@your_host:5432/fastgpt` | Stores structured review data, supports complex conditional queries and statistics |

## Three Common Mistakes
- Symptom: An `Invalid url` error is returned when submitting ad creative reviews in bulk. Cause: The `STORAGE_S3_ENDPOINT` parameter is not configured correctly, causing link verification for external resources such as landing page screenshots to fail.
- Symptom: The locally deployed Dockerized review service can be accessed normally, but external ad platforms cannot call the review interface. Cause: The `FE_DOMAIN` parameter is set to local localhost, and not replaced with the actual external domain name.
- Symptom: The custom compliance check model returns inconsistent results between the workspace and formal review environments. Cause: Cache configurations for `REDIS_URL` and `PG_URL` are not updated synchronously, causing retrieval data deviations between the two environments.

## How to Confirm Proper Configuration
- Run the service startup log viewing command, confirm that all configuration parameters have been loaded normally, with no prompts for missing parameters or format errors.
- Submit a single test ad creative, trigger the full review workflow, and verify that review results are properly written to the specified database and cache.
- Call external interfaces to initiate bulk creative review requests, confirm that the link can be connected normally, with no connection timeout or permission interception errors.
- Compare all configuration parameters between the workspace and formal environment, ensure that the values of all configuration items are completely consistent, and avoid result deviations caused by environment differences.

The values provided here are common starting points, and should be evaluated against the user’s own samples.
