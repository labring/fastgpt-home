# Pre-sales Technical Solution for Operation and Maintenance On-duty and Internal Work Order Q&A: Sharing and Embedding

## What the data for this category looks like
Data for this category comes primarily from customer interviews, bidding documents, vendor product materials, and historical project plans. Update frequency is per order or weekly. Commonly used documents include technical proposal books, customer requirement research forms, quotation lists, and demo scripts. There is no unified mandatory format for document structure. Most documents include fields such as requirement matching, technical route description, implementation boundary definition, and quotation details. Some documents like quotation lists contain multiple columns of detailed content. Historical project plans reuse past configuration items. Individual document word counts vary widely. Documents in this category prioritize clarifying technical routes and implementation boundaries, which differentiates them from bidding document preparation documents.

## Three Common Misconfigurations
- Sharing entries for pre-sales technical solutions fail to open. First verify the complete system-generated link and its validity period, then check browser request status. Do not manually replace `shareId`.
- The visible scope of pre-sales technical solution data does not match expectations. Verify the third-party identity verification result, workflow request parameters, and external system data permissions respectively. The sharing entry identifier itself does not provide business authorization.
- The same pre-sales technical solution Q&A cannot be accessed on another device. For anonymous scenarios, first check the device, browser, and local identity status. Retention cannot be guaranteed across devices or after clearing cache. Do not use this phenomenon alone to judge service abnormalities.
