# Operations on-duty and internal ticket Q&A for capacity planning and resource scaling: Deployment and upgrade

## What data this category uses
The data for this category comes from four primary sources: cloud billing statements, monitoring systems, business forecasts, and stress test reports. Update frequency is weekly or monthly. Daily produced documents include capacity planning reports, scaling applications, resource utilization reports, and budget calculation sheets. Document fields typically include resource type identifiers, utilization values, peak periods, budget amounts, and similar items. There is no fixed unified unit standard, and adaptation is required based on resource type. The data processing workflow must connect to multi-source heterogeneous information, with core links centered around peak prediction and resource bottleneck identification.

## What constraints do these characteristics impose on deployment and upgrades
Since data sources include multiple heterogeneous systems, access permissions and format verification rules for multiple data sources must be configured during deployment to avoid data synchronization exceptions. Since update frequency is weekly or monthly, incremental synchronization logic for historical data must be retained during upgrades to avoid excessive system resource usage from full re-import. Since core documents must adapt to the daily usage habits of operations teams, preset field mapping templates must be configured during deployment to ensure export formats meet team standards. Since errors may trigger peak failures or resource waste, a pre-verification link must be added during upgrades to verify whether configured resource thresholds are reasonable.

## How to configure settings
This configuration applies to FastGPT v4.17.0. The following are recommended values and their rationales for core configuration items:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `DB_MAX_LINK` | 100–150 connections | Matches the concurrent connection limit in cloud environments, avoiding database connection exhaustion |
| `REDIS_URL` | Authenticated private cluster address | Ensures cache security and access speed for capacity planning data |
| `STORAGE_S3_ENDPOINT` | Object storage endpoint specified by the cloud vendor | Adapts to storage requirements for operations reports, ensuring data persistence |
| Resource threshold configuration | Calibrated at 1.2 times the business peak | Aligns with the peak prediction logic in capacity planning reports, reserving buffer space |
| Data synchronization cycle | Synchronize once weekly | Complies with industry conventions for weekly/monthly data update frequencies, balancing timeliness and resource consumption |
| Document export template | Adapted to the operations team’s standard format | Matches the daily-used capacity planning report format, reducing secondary organization work |

## Three common configuration mistakes
- Symptom: Cannot write capacity planning data after startup, with logs indicating database connection timeout. Cause: The `DB_MAX_LINK` parameter is not correctly configured, and the concurrent connection count exceeds database limits.
- Symptom: Resource utilization report exports are empty or cannot be generated. Cause: `STORAGE_S3_ENDPOINT` is not configured, or the parameter is filled incorrectly, making it impossible to store exported report files.
- Symptom: Peak prediction results have excessive deviation, leading to unreasonable resource configuration. Cause: Resource threshold configuration is not calibrated using business forecast data, and default parameters are used directly.

## How to confirm successful configuration
- Run a database connection test to verify that connections configured via `DB_MAX_LINK` can be established normally, with no timeout errors.
- Manually trigger a resource utilization report export to confirm that the file can be stored normally at the specified object storage endpoint.
- Check the data synchronization logs to confirm that data is pulled and updated from cloud billing statements and monitoring systems according to the preset cycle.
- Compare the fields in the exported capacity planning report to confirm that they match the preset template fields, with no missing or misaligned entries.
