# Operational Duty and Internal Work Order Q&A for Computer Room Inspection and Environmental Monitoring: Knowledge Base Retrieval and Recall

## What data for this category looks like
Data for this category mainly comes from environmental monitoring systems, access control systems, UPS monitoring devices, and video inspection terminals. Data is updated daily or pushed in real time. Daily operation and maintenance documents include inspection sheets, temperature and humidity records, alarm records, and duty logs. Most fields include device numbers, temperature and humidity values (units are ℃ and %RH), alarm levels, inspection times, and access permission identifiers. Some documents use structured log formats, while others are semi-structured electronic inspection records converted from paper.

## What constraints these characteristics impose on knowledge base retrieval and recall
The real-time nature and field diversity of data in this category create clear constraints. Real-time updated environmental alarm data requires retrieval and recall data sources to support near-real-time synchronization, to avoid recalling outdated information. Structured and semi-structured documents from multiple sources contain many semantically similar entries. For example, different devices may have temperature and humidity over-limit alarm descriptions. Retrieval logic must be adjusted to distinguish recall priority between precise matches and similar scenarios. Exclusive fields for different devices, such as UPS output voltage and access control passage IDs, require filtering irrelevant content by specifying dataset ranges to reduce invalid recalls.

## How to configure settings
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.72–0.85 | Adapts to semantically similar alarm and inspection descriptions for this category, balancing precise recall and coverage |
| `limit` | Top 8–12 entries | Matches the typical number of entries on a single computer room inspection document, avoiding context overload |
| `searchMode` | vector_only | Prioritizes vector retrieval over keyword hybrid mode for structured operation and maintenance logs and inspection records |
| `usingReRank` | Enabled | Reranks similar temperature and humidity alarm and device status descriptions to improve accuracy |
| `datasetSearchUsingExtensionQuery` | Enabled | Optimizes vague queries in operation and maintenance scenarios—for example, automatically expanding "UPS abnormality" to match documents related to UPS monitoring |
| `collectionIds` | Fill in according to the target computer room dataset | Limits retrieval scope to only include environmental and inspection data from the current computer room, excluding other irrelevant knowledge base content |

## Three common configuration mistakes
-  Retrieval returns no results. The cause is failure to specify the `collectionIds` parameter, with retrieval scope covering irrelevant datasets and failure to match computer room-specific inspection and alarm documents.
-  Semantically similar entries cannot be accurately distinguished. For example, recall results for "temperature and humidity exceed standard" and "temperature exceed limit" are mixed. The cause is failure to enable `usingReRank`, or setting the `similarity` threshold too low, leading to recall of a large number of irrelevant similar entries.
-  Fields in semi-structured inspection sheets cannot be correctly extracted. The cause is failure to adjust retrieval logic for structured documents, or failure to enable `datasetSearchUsingExtensionQuery` to optimize field matching.

## How to verify correct configuration
-  Upload a single computer room temperature and humidity alarm record to a test dataset, submit a query containing the alarm description, and verify that the corresponding document is recalled.
-  Adjust the `similarity` threshold to 0.78, submit a query containing a similar alarm description, and check whether the reranked result ranking meets expectations.
-  Confirm that the `collectionIds` configuration only includes the current computer room’s environmental monitoring and inspection log datasets, avoiding cross-dataset recall of irrelevant content.
-  Submit a test query with a vague operation and maintenance question—for example, "UPS power abnormality"—and verify that it automatically matches documents related to UPS monitoring.

The values provided here are common starting points and should be evaluated against the reader’s own samples.
