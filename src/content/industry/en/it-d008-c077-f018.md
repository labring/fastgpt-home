# Operations Duty and Internal Ticket Q&A for Equipment Room Inspection and Environmental Monitoring: Reranking and Hybrid Retrieval

## What Data Looks Like for This Category
Data for equipment room inspection and environmental monitoring scenarios comes from environment and power monitoring systems, access control systems, UPS monitoring devices, and video inspection records. Daily generated documents include inspection record forms, temperature and humidity logs, alarm event records, and shift handover logs.

Data update rhythms fall into two categories: real-time and daily updates. Alarm events are synchronized in real time. Inspection logs and shift handover logs are updated daily.

Document fields include device point numbers, temperature and humidity values, alarm levels, trigger times, inspection results, and more. Corresponding units include degrees Celsius, percentage, device ID identifiers, and others.

## What Constraints These Characteristics Impose on Reranking and Hybrid Retrieval
Real-time alarm data has high timeliness requirements. Hybrid retrieval must prioritize recalling the most recently synchronized entries. Reranking models must adapt to relevance ranking for short time-series alarm text.

Multi-source heterogeneous data includes different types of fields: temperature and humidity values, alarm levels, text logs, and more. Hybrid retrieval must unify field mapping rules to avoid matching deviations between numeric and text data.

Daily updated inspection log data volume is relatively stable. It must filter expired entries according to inspection cycles. Reranking must adjust relevance scores combined with inspection time weights.

High-priority abnormal alarms in equipment room scenarios must be displayed first. Weight parameters for alarm types must be configured in hybrid retrieval.

## How to Configure Settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Similarity threshold | 0.65–0.75 | Adapts to hybrid matching of equipment room alarm and inspection data, filters low-relevance historical entries |
| Single search limit | Top 10 entries | Matches the information density viewed by operation and maintenance personnel in a single session, avoids excessive results interfering with judgment |
| Search mode | Hybrid retrieval | Integrates vector retrieval and keyword retrieval, adapts to multi-source heterogeneous equipment room data |
| Reranking toggle | Enabled | Corrects sorting deviations from initial retrieval, prioritizes displaying high-priority alarms and inspection results |
| Reranking recall count | Top 15 entries | Provides sufficient candidate results for the reranking model, ensures sorting accuracy |

## Three Common Configuration Mistakes
- The number of returned search results does not match the set single search limit. The cause is failure to synchronously adjust the reranking recall count configuration, leading to excessive candidate results being filtered during the reranking stage.
- The reranking model outputs no results or returns empty results. The cause is enabling the reranking toggle but not configuring the corresponding reranking model interface, or interface call timeout.
- Hybrid retrieval recalls a large number of low-relevance historical inspection logs. The cause is setting the similarity threshold too low, failing to filter expired or non-matching entries.

## How to Verify Configurations Are Correct
- Enter a known latest alarm event keyword, check if the search result displays this event first.
- Check if the number of search results matches the set single search limit, and if the post-reranking sorting aligns with business priorities.
- Verify that the search mode on the configuration page is set to hybrid retrieval, and the reranking toggle is enabled.
- Simulate entering a low-relevance query term, check if the similarity scores of the search results fall within the set threshold range.

The values provided are common starting points and should be evaluated against the reader's own samples.
