# Operations Duty and Internal Ticket Q&A for Game Content Compliance Self-Check: Reranking and Hybrid Retrieval

## What this category of data looks like
This category of data primarily comes from game text, plot scripts, art resource descriptions from game development and publishing stages, as well as publicly available regulatory requirements related to compliance. Daily maintained documents include content self-check lists, sensitive content modification records, user agreement templates, and compliance review minutes. Data updates are triggered during game version iterations or the launch of operational activities, with update cycles aligned to versions or activities. Most documents are a mix of structured and semi-structured data: content self-check lists include fields for violation types and rectification requirements; compliance review minutes include fields for review opinions and rectification time limits; art resource annotations include information such as style and compliance check status.

## What constraints do these characteristics impose on reranking and hybrid retrieval?
This category of data covers multimodal text and art metadata. Hybrid retrieval must support both text semantic matching and precise metadata matching. Following the update rhythm of versions or activities, retrieval results must match the current iteration’s compliance rules. The reranking stage must prioritize associating the latest sensitive content modification records. Documents include segmented fields such as violation types and rectification requirements, so hybrid retrieval must support targeted filtering by fields to avoid recalling old compliance entries across versions. In operations duty and ticket scenarios, retrieval results must quickly match the corresponding self-check list or review minutes. Reranking weights must tilt toward frequently associated compliance entries to improve the positioning efficiency of review personnel.

## How to Set Up Configurations
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Reranking Toggle | Enabled | Game compliance self-check requires prioritizing highly relevant sensitive content entries; reranking can filter low-semantic-association recall results |
| Single Recall Limit | Top 10 entries | Operations duty scenarios require quick browsing of core results; 10 entries cover the scope of common compliance issues for a single ticket |
| Similarity Threshold | 0.75–0.85 | Filter low-match-degree irrelevant content to avoid distracting review personnel with non-compliance-related entries |
| Search Mode | Hybrid Retrieval | Must match both text semantics and field attributes of compliance documents, covering retrieval needs for game text, plot scripts, and art metadata |
| Reranking Service Channel | Custom Channel | Adapt to dedicated reranking services for game compliance scenarios, meeting precise matching requirements for compliance documents |

## Three Common Misconfigurations
- Phenomenon: Connection timeout or 403 error returned when calling the reranking service. Cause: Incorrect configuration of the custom channel’s API key or address, and the request format for the reranking service under compliance scenarios is not adapted.
- Phenomenon: Hybrid retrieval returns a large amount of content unrelated to current compliance self-checks. Cause: Similarity threshold is not set, or the threshold is set too low, and retrieval scope is not limited to the compliance document library via retrieval rules.
- Phenomenon: Multiple variables after an HTTP request in a workflow cannot be associated with the retrieval results of a specified knowledge base. Cause: The retrieval context of the corresponding knowledge base is not bound in the reranking stage, or retrieval tasks are not split by knowledge base dimension.

## How to Confirm Configurations Are Set Correctly
- View the retrieval configuration panel in FastGPT v4.17.0, confirm that the reranking toggle is enabled.
- Initiate a test retrieval, input a compliance-related test question, check whether the number of returned results matches the single recall limit setting.
- View the matching scores of returned results, confirm that the scores fall within the set similarity threshold interval.
- Compare the results of semantic retrieval and hybrid retrieval, confirm that hybrid retrieval can cover matching content for both game text and art metadata.
