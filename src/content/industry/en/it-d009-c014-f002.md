# Requirements and Design Document Drafting for Cloud Resource Compliance Audit: Context and Token

## What This Category of Data Looks Like
Data for cloud resource compliance audit comes from cloud audit logs, IAM permission configurations, CMDB resource inventories, and security baseline scan results. Update frequency is monthly or quarterly. Regularly produced documents include compliance checklists, permission audit reports, resource inventories, and remediation tracking sheets. Most data uses structured fields, including resource ID, permission status, audit time, remediation status, and similar fields. Token size per document fluctuates with resource coverage. Compliance checklists and permission audit reports typically include multiple sections of structured text and table content.

## What Constraints Do These Characteristics Impose on Context and Token Processing
Integrate multi-source data for cloud resource compliance audit into context to ensure core information such as permission anomalies and resource configurations is not lost. Monthly or quarterly update frequency means context does not require frequent refreshes. However, compliance documents have large token sizes, so allocate token quotas reasonably to avoid truncating critical content. Core business workflows depend on context accuracy. Missing resource inventory entries or permission configuration details in context will lead to incorrect audit results. Data formats vary across different sources, so unify structured content during context integration to avoid format confusion that affects subsequent analysis.

## How to Configure Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `maxContext` | `Top 3–5 context records` | Context for cloud resource compliance audit mostly consists of historical operations and reports from a single audit cycle. Excessive context will occupy too much token quota |
| `quoteMaxToken` | `12000–15000 token` | Compliance documents include long texts such as resource inventories and permission reports. This range must cover at least one complete quarterly compliance checklist and core resource entries |
| Single search limit | `Top 10 recall results` | Recall data for cloud resource compliance audit is mostly structured logs. Excessive results will exceed the context token limit |
| Reranking rule | `Sort by relevance` | Prioritize matching core fields such as permission anomalies and remediation status to improve business relevance of the context |
| Maximum total context token | `16000 token` | Adapt to the average token size of cloud audit logs and compliance reports, avoid triggering automatic model truncation |

## Three Common Misconfigurations
- The interface displays 30 context entries, but 310 context entries are actually sent to the API. This occurs because the single search limit and context total token limit configurations are confused, and no token filtering is applied to recalled compliance report entries.
- The Markdown-formatted compliance checklist is not rendered in the context reference area. This occurs because imported compliance documents use native structured table formats, and no preprocessing is performed to convert them to standard Markdown structures.
- After setting `maxContext` to 0, the workflow still loads historical conversation context. This occurs because independent configurations for conversation context and knowledge base recall context are not distinguished, and the global context switch is mistakenly disabled.

- View the context preview panel in the FastGPT v4.17.0 workflow, confirm the displayed number of context entries matches the configured value of `maxContext`.
- Send a test request, compare the context token count returned by the API with the configured value of `quoteMaxToken`, confirm the threshold is not exceeded.
- Import a compliance checklist document, verify that the table format is correctly rendered in the context reference area.
- Check the number of recall results recorded in logs, confirm it does not exceed the configured single search limit.
