# Requirements and Design Document Drafting for Duty Scheduling and Handover: Document Parsing and Chunking

## What the Data for This Category Looks Like
This category’s data comes from operation and maintenance scheduling systems, fault ticket databases, monitoring alert platforms, and organizational contact directories.
Daily processed documents include standardized duty schedules, cross-shift handover records, escalation contact lists, and daily duty reports.
Documents include clear time fields, responsible party fields, pending item entries, and contact information. Update frequency is daily or weekly.
Most data is structured text. Some handover records include unstructured handwritten notes or screenshot attachments.

## Constraints Imposed on Document Parsing and Chunking
Diverse data sources and varying update frequencies require the parsing module to support batch processing of multi-format documents.
Time fields in duty schedules must accurately match shift time periods. When chunking, retain the association between time and responsible party to avoid semantic breaks.
Handover records include pending items and contact information. Chunk length must cover complete item entries to ensure full information is retrievable.
Some documents include attached screenshots. Mixed text-image parsing must be supported. Parsing timeout must be controlled to avoid blocking during batch processing.
Escalation contact lists have uniform field formats. Chunking rules can be optimized specifically to improve retrieval matching accuracy.

## Configuration Guidelines
The following configurations are based on FastGPT v4.17.0 document parsing module guidelines. They are tailored for the document parsing and chunking process in duty scheduling and handover scenarios.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Single items in duty schedules and handover records are mostly 500-1000 characters long. This range preserves core information such as complete shift time periods and pending items, avoiding semantic breaks from improper splitting |
| `chunkSplitter` | Split by paragraph + heading | Daily documents include structured content such as shift time headings and handover item paragraphs. Splitting by paragraph and heading preserves semantic integrity and improves retrieval matching accuracy |
| `PARSE_FILE_TIMEOUT_SECONDS` | 180 seconds | Batch parsing of multiple weekly duty schedules or handover records with multiple screenshots requires sufficient processing time to prevent parsing failures due to timeout |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | Supports handover record documents with multiple screenshots, meeting attachment upload requirements for operation and maintenance scenarios |
| `customPdfParse` | Enabled | Duty schedules and handover records are often stored in PDF format. Enabling this configuration accurately extracts associated information between text and embedded images |
| `chunkSettingMode` | Manual configuration | For special fields in scheduling documents such as shift time periods and responsible personnel, manual configuration optimizes chunking rules to improve targeted retrieval matching |

## Three Common Configuration Errors
1.  Phenomenon: Slow operation xxxxms is logged when parsing scheduling documents in a Docker deployment environment. Cause: The `PARSE_FILE_TIMEOUT_SECONDS` parameter is not adjusted. Batch parsing of multiple weekly duty schedules times out before completion.
2.  Phenomenon: Invalid image fields appear in returned results after uploading a handover record document with images. Cause: The `customPdfParse` configuration is not enabled. The default parsing logic cannot extract associated text information from embedded images.
3.  Phenomenon: Insufficient result entries are returned when batch parsing escalation contact lists. Cause: The `chunkSize` setting is too small. It splits complete contact entries into multiple chunks, preventing full list information from being matched during retrieval.

## How to Confirm Proper Configuration
1.  Upload a standard duty schedule PDF document. Review the parsed chunk results to confirm each chunk contains complete shift time period and responsible personnel information.
2.  Upload a handover record document with embedded images. Check that parsed results include associated text descriptions of the images, with no error prompts.
3.  Batch upload 5 weekly duty documents. Review logs for no timeout errors, and confirm the `PARSE_FILE_TIMEOUT_SECONDS` configuration is active.
4.  Access the system parameter configuration page. Confirm `chunkSettingMode` is set to manual configuration, and `chunkSize` falls within the preset range.

The values listed here are common starting points. They should be evaluated against the specific samples used in the target deployment.
