# Requirements and Design Document Drafting for Security Baseline Checking: Document Parsing and Chunking

## What the data for this category looks like
The typical users of this category are security operations staff, security consultants, and internal control auditors. The documents they process daily include baseline checklists, configuration verification records, rectification suggestions, and exception approval forms. Data sources are server configurations, middleware configurations, security device policies, and baseline tool output results. The update frequency is monthly or quarterly. Most documents use structured formats, with fixed fields such as configuration item number, check requirement, compliance status, and rectification measures. There is limited free-form text content. Some documents contain nested tables and batch configuration entries.

## What constraints these characteristics impose on the document parsing and chunking link
Since most documents focus on structured configuration entries, chunking must avoid splitting a single complete configuration item across multiple chunks. Otherwise, configuration association relationships will be lost during vectorization. Large baseline checklists may exceed conventional file upload thresholds, so upload limit parameters must be adjusted. The monthly or quarterly update frequency means documents do not change frequently, but a single update may include a large number of batch configuration entries. Chunking must retain contextual associations between entries. Baseline documents in Feishu online spreadsheet format must support online parsing logic, otherwise field extraction will be incomplete. The exported knowledge base template CSV must match the structured fields of the original document, and chunking must retain the correspondence between fields and content.

## How to set configurations
This document provides configuration instructions based on the parameter system of FastGPT v4.17.0.

| Configuration Item | Recommended Value Range | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Adapts to the average length of a single configuration item in baseline checklists, avoiding splitting complete configuration entries |
| `chunkSplitter` | Split by title + table | Matches the mostly structured checklist format of the documents, retaining the association between configuration items and their parent check items |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Supports uploading large-volume batch baseline checklists, covering the size of most enterprises' monthly verification documents |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Adapts to the parsing time required for large files and nested tables, avoiding timeout errors before parsing completes |
| `customPdfParse` | Enabled | For the PDF format commonly used for baseline checklists, enable custom parsing rules to retain table structures |
| `chunkSettingMode` | Manual mode | Allows adjusting chunking rules for structured documents, adapting to the special format of security baseline-related documents |

## Three common mistakes
- After uploading a baseline checklist larger than 10 MB, over 1000 chunks are generated, and some chunks experience vectorization errors. The cause is failure to adjust the `chunkSize` parameter for structured documents, resulting in a single configuration item being split across multiple chunks.
- After repeatedly clicking the upload retry button, the vectorization error issue is not resolved. The cause is failure to troubleshoot incorrect parameter configurations; retries alone cannot fix errors caused by improper chunking rules.
- After importing a baseline document in Feishu online spreadsheet format, some configuration item fields appear empty. The cause is failure to enable online document parsing adaptation, making it impossible to correctly identify the nested structure and field correspondence of the spreadsheet.

## How to confirm configurations are set correctly
- Upload a single baseline checklist larger than 10 MB, view the generated chunk list, confirm there are no abnormal error prompts, and that no single configuration item is split across multiple chunks.
- Import a baseline document in Feishu online spreadsheet format, verify that the extracted fields fully match the configuration items and check requirements in the original document.
- Export the dataset.csv file of the knowledge base, confirm that the exported format matches the structured fields of the baseline checklist, with no missing or misaligned content.
- Adjust the `chunkSize` parameter to different ranges, verify that all content of a single configuration item is fully retained in the chunked results, with no truncation.

The values provided are common starting points and should be measured against the reader's own samples.
