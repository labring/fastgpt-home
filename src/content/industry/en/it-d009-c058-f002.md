# Requirements and Design Document Drafting for Advertising Compliance Record-Keeping: Context and Token

## What the data for this category looks like
Data for this category comes from ad platform backends, customer qualification libraries, contract systems, and publicly available regulatory rules. Daily documents include four core types: ad review forms, qualification attachments, delivery records, and rectification notices. Data updates trigger upon completion of a single ad campaign or on a monthly cycle. A single delivery record includes fields such as delivery period, material version, and review number. Qualification attachments are mostly structured certificates or scanned file formats.

## What constraints these characteristics impose on the context and token workflow
Data sources for this category are scattered, requiring integration of structured and unstructured content from multiple systems. When splicing context, distinguish the priority between review-related text and delivery execution text. Data updates trigger per single campaign or monthly cycle. A single batch import includes a large number of documents, so strictly control the value of `maxContext` to avoid exceeding the model’s carrying limit. Delivery records and qualification attachments have significant field differences, so use `quoteMaxToken` to limit token consumption per single reference, preventing irrelevant data from occupying too much context space. Prioritize core evidence documents corresponding to archiving and sorting processes to ensure key information for compliance review is recalled first.

## How to set the configurations
| Configuration Item | Recommended Value Range | Rationale |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | Matches the average total token count of advertising compliance documents, avoids exceeding the model carrying limit of FastGPT v4.17.0 |
| `quoteMaxToken` | 1000–1500 token | Adapts to the single-document length of delivery records and qualification attachments, prevents single references from occupying excessive context space |
| Context matching priority | Prioritize review documents | Aligns with core business requirements for compliance record-keeping, prioritizes ad review forms and regulatory rule text |
| Single batch import limit | 50 items per batch | Adapts to the scale of monthly updated documents, reduces memory pressure during token splicing |
| Rerank model trigger threshold | Calibrated via actual testing | Adjusted based on text characteristics of compliance documents, improves accuracy of context recall |

## Three Common Misconfigurations
- Phenomenon: `rerank error fastgpt` error occurs after offline access to the rerank model. Cause: The trigger threshold of the rerank model is not adjusted based on the text characteristics of compliance documents, causing long texts to fail the rerank process normally.
- Phenomenon: LLM returns empty content with prompt `LLM model response empty`. Cause: The value of `maxContext` is too large, and the total context after splicing exceeds the model’s token limit, preventing the LLM from generating valid response content.
- Phenomenon: Token limit error is triggered during short Q&A after setting the reference limit. Cause: The token length of single references is not restricted using `quoteMaxToken`, and the total token consumption of multiple delivery records exceeds the single-round context quota.

## How to Verify Proper Configuration
- Import a single core compliance document, check the total token count after context splicing, confirm it matches the value range of `maxContext`.
- Trigger a single compliance document retrieval process, check the length of returned single references to confirm they meet the limit requirements of `quoteMaxToken`.
- Batch import monthly updated documents, confirm the system shows no splicing exceptions or memory overflow prompts.
- Initiate a continuous conversation, verify that historical compliance review records can be properly called and included in the context.

The values listed above are common starting points and should be measured against the reader's own samples.
