# Requirements and Design Document Drafting for Ad Account Opening Audit: Forms and Interactions

## What the data for this category looks like
Data for this category comes from several sources: advertising platform backends, the National Enterprise Credit Information Publicity System, customer-submitted opening applications, business licenses, industry qualification materials, and public industry access rules.
Data updates occur daily or whenever an opening application is submitted.
Core documents include opening application forms, main qualification files, industry access certificates, and audit records.
Fields cover main identity information, industry qualification numbers, advertising category scope, and more.
There are no unified fixed units. Format requirements match the field type.

## What constraints these characteristics impose on forms and interactions
Decentralized data sources require forms to support multi-format file uploads. They also require integration with external business systems for linked interface verification. This avoids duplicate errors from manual data entry.
For variable update frequency per application, replace fixed cached verification logic with real-time triggering. This meets the independent verification needs of each application.
Multiple types of qualification documents must display input items in stages according to the audit process. This prevents information overload that reduces filling efficiency.
Main qualification verification relies on external systems. Integrate external data sources to implement verification, and reserve related configuration interfaces. This ensures the accuracy of verification results.
Error consequences directly affect account opening compliance and customer experience. Interactions must add pre-verification and clear error prompt anchoring.

## Three Common Mistakes
- Configuring the `formInput` node and still having the input box cleared automatically after submission. Verification step: Check whether subsequent workflow nodes or external business systems have configured input content retention logic
- Selecting configured options one by one in the `userSelect` node. Verify whether the workflow enters the corresponding branch. The filtering of ad account opening audit records must additionally verify the input, permissions, and return values of the external interface
- Seeing a size limit exceeded prompt when uploading qualification files. Verification step: Check whether the file upload limit configuration meets requirements. Also check whether the uploaded file’s size and format match the configured specifications

## How to Confirm Proper Configuration
- Open the corresponding form editing page. Manually enter content and then blur the focus. Check whether external business systems or subsequent workflow nodes trigger real-time verification prompts
- Upload a test file that matches the configured format and size. Check whether the upload process completes normally
- Call the bound external data source interface. Confirm that returned structured data can be properly loaded and displayed by the `userSelect` node
- Submit the form and refresh the page. Check whether entered content is retained by subsequent workflow nodes or external business systems. Confirm that the input content retention logic is active
