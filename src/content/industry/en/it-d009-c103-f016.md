# Drafting Requirements and Design Documents for Art Asset Production Management: Forms and Interactions
This document is based on FastGPT v4.17.0 configuration guidelines.

## Data Structure for This Category
Core data for this category comes from art asset libraries, project management systems, engine resource directories, and outsourced delivery packages. Daily produced documents include art requirement sheets, asset specification sheets, outsourced feedback forms, and acceptance records.
Update frequency is mostly daily or weekly. Core fields include asset type (character/scene/effect), triangle count, texture resolution, delivery format, version number, and associated task ID. Some fields have specific units: triangle count uses triangles, resolution uses pixels.

## Constraints for Forms and Interactions
Data for this category is multi-source, with specific formats and units. It must connect to external business systems to pull existing fields across systems, avoiding duplicate data entry.
Specification fields vary significantly across different asset types. External business systems or subsequent nodes must preset field groups by asset type to reduce invalid configuration.
Data update frequency is tied to project iteration cycles. External business systems or subsequent nodes must automatically associate versions to avoid version misalignment.
Specification confirmation and outsourced rework communication are core time-consuming links. Real-time verification and field linkage from external business systems simplify operations, reduce error probability, and prevent issues such as resource mismatches and performance overrun.

## How to Confirm Correct Configuration
- Create a new art requirement sheet, select the corresponding asset type, check if the external system automatically pulls preset specification fields.
- Enter asset parameters that do not meet the required format, check if the external system displays verification prompts in real time.
- Submit a complete form, wait more than 300 seconds, confirm no timeout error is triggered.
- View the form submission record, check if the external system automatically binds the iteration version number of the current project.
