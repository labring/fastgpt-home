# Supplier and Process Quality Audit for SMT Mounting and Electronic Assembly: Knowledge Base Retrieval and Recall

## What data for this category looks like
Data sources for this category include customer-provided BOM, Gerber and coordinate files, MES systems, solder paste and component batch ledgers, placement machines, SPI/AOI testing equipment, reflow oven temperature records, and more. Document types cover changeover sheets, stencil parameter sheets, first article confirmation reports, maintenance records, traceability labels, and others. Fields include part number, reference designator, component batch, oven temperature parameters, coordinate position, and more. Units include millimeters, degrees Celsius, and others. The data update frequency is real-time per work order and each changeover.

## What constraints do these characteristics impose on the knowledge base retrieval and recall link
The high-frequency real-time update feature requires the retrieval system to support incremental indexing and fast refresh, to avoid data lag affecting audit accuracy. The coexistence of multiple types of structured and semi-structured documents requires optimizing retrieval matching logic for precise fields such as part number and reference designator. A single work order is associated with a large volume of documents; without restricting the retrieval scope, irrelevant data may be introduced, and a balance must be struck between the number of recalled documents and response speed. Additionally, the audit link has extremely high requirements for data accuracy: retrieval results must strictly match the exclusive parameters of the current work order to avoid risks such as wrong components and dry joints.

## How to set configurations
In FastGPT v4.17.0, the following configuration items can be adapted to the needs of this category:

| Configuration Item | Suggested Value | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Adapt to the precise matching requirements of part numbers and reference designators for the SMT category, filter irrelevant data with low matching degrees |
| `limit` | Top 10 entries | Control the number of documents recalled per single retrieval, avoid redundant content interfering with supplier and process quality audit judgments |
| `usingReRank` | Enabled | Optimize the sorting accuracy of retrieval results for unstructured text such as SPI/AOI reports and oven temperature records |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically supplement contextual information such as work order-associated BOM and coordinates, improve precise recall rates |
| `collectionIds` | Specify by the dataset ID associated with the current work order | Limit the retrieval scope, only recall documents exclusive to the current work order, avoid interference from cross-work order data |

## Three common misconfigurations
- Retrieval results do not match the exclusive parameters of the current work order: The phenomenon is that returned material data and oven temperature records do not match the BOM and changeover sheet of the current work order. The cause is failure to correctly use variable references to bind the dataset ID of the current work order, resulting in the retrieval scope covering irrelevant work order data.
- Retrieval speed is too slow: The phenomenon is that a single retrieval takes more than 3 seconds. The cause is failure to restrict `collectionIds` to the dataset associated with the current work order, retrieving full historical document data.
- Image link display abnormality: The phenomenon is that addresses of SPI/AOI reports and stencil images are truncated and cannot be loaded normally. The cause is that image paths fed into the knowledge base only use relative paths, and no publicly accessible absolute URL format is configured.

## How to confirm the configuration is properly set
- Initiate a retrieval test for the current work order, verify whether the returned results include specified documents such as the current work order's BOM and changeover sheet.
- View retrieval time logs, confirm response speed meets business requirements, adjust `limit` or `collectionIds` configuration to optimize performance based on actual conditions.
- Check image links in retrieval results, confirm all are complete absolute URL formats and can be accessed normally.
- Simulate variable reference scenarios, confirm that retrieval results automatically bring in exclusive parameters such as the current work order's part number and reference designator.

The values given are common starting points and should be measured against the reader's own samples.
