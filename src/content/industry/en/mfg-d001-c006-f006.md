# Supplier and Process Quality Audit for Photovoltaic Module Encapsulation: Citation Sources and Traceability

## What Data for This Category Looks Like
Data for this category originates from cell grading, adhesive film backsheet batches, MES systems, stringing and lamination equipment, and EL/IV testers. Corresponding records are generated for each module and each material batch on a regular update cycle. Daily documents include layout drawings, material batch records, lamination process records, EL images, IV test reports, insulation voltage withstand records, and packing lists. Fields include batch number, supplier code, lamination temperature, EL crack coordinates, peak power, and other metrics. Units include degrees Celsius, watts, millimeters, and other professional measurement units.

## Constraints Imposed by These Characteristics on the Citation Sources and Traceability Link
Each module has independent traceability data. Citation and traceability operations must target individual module batches and test records to prevent incorrect cross-module matching. Frequently updated business data requires the knowledge base to support incremental synchronization, ensuring retrieved content reflects the latest process and test results. Multiple document types require retrieval logic to classify and match by document type, prioritizing association with material batches and test reports. Professional fields such as EL crack coordinates and current gear require precise matching. Generalized retrieval will cause audit results to become invalid, and in severe cases may lead to customer claims.

## Configuration Settings
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Single Search Limit | 8–12 entries | Matches the multi-source document structure of photovoltaic module encapsulation, avoids retrieving excessive irrelevant data |
| Maximum Context | 10000–12000 characters | Accommodates multi-segment traceability content such as material batch records and EL image descriptions |
| Return Source Metadata | Enabled | Retains key audit information such as supplier code, batch number, and test parameters |
| Detail Retrieval Switch | Enabled | Enables precise matching of process and test data corresponding to individual modules |
| `quoteMaxToken` | 6000–8000 token | Controls total length of traceability information, prevents context overflow |

## Three Common Configuration Errors
- Setting the single search limit too low results in insufficient retrieved source documents, and the citation sources displayed on the interface are empty. This fails to meet the retrieval requirement for multiple batch documents in photovoltaic module encapsulation; retrieving only a small amount of data cannot cover the complete traceability chain required for audits.
- Disabling return source metadata means exported traceability data only contains text content, and cannot be associated with specific material batches or test reports. This ignores the business requirement of this category’s audit to accurately associate supplier and batch data.
- Failing to specify the document directory for the corresponding category when configuring knowledge base association rules results in empty knowledge base options during calls. This skips configuring the import path according to the document classification of photovoltaic module encapsulation, corresponding to the empty knowledge base issue mentioned in the community.

## How to Verify Successful Configuration
- Upload a photovoltaic module material batch record and EL image, call the audit function, and check if the returned citation sources include the metadata of the corresponding documents.
- Adjust the value of `quoteMaxToken`, verify that the returned traceability content is complete and not truncated.
- Select the specified knowledge base during test calls, confirm that the interface can directly select the target knowledge base without manual supplementation.
- Export the traceability data, check that it includes key fields such as batch number and test parameters.
