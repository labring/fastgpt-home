# Supplier and Process Quality Audit for Photovoltaic Module Encapsulation: Knowledge Base Retrieval and Recall

## What Data for This Category Looks Like
Data for the photovoltaic module encapsulation process comes from battery cell grading ledgers, glass adhesive film backplane batch records, workshop MES systems, string welding and lamination production equipment, and EL/IV testers.
The update rhythm is one set of test records per module, and batch traceability documents per batch of raw materials.
Daily documents include process layout drawings, material batch ledgers, lamination temperature, pressure and time records, EL crack images, IV power test reports, insulation voltage resistance records, and finished product packing lists.
Fields include battery cell current gear, lamination process parameters, crack coordinates, power value, insulation resistance value, and more. Corresponding units are amperes, degrees Celsius, pascals, watts, and megohms.

## Constraints Imposed on the Knowledge Base Retrieval and Recall Workflow by These Characteristics
High-frequency single-module or single-batch updates require the retrieval system to support incremental recall, avoiding delays from full index rebuilding.
Multiple types of documents coexist, so the retrieval logic must adapt to both image-text EL images and numerical test reports.
Professional fields such as battery cell current gear and lamination process parameters require precise retrieval matching, and irrelevant general documents must be filtered out.
Cross-process data association requires recalling related documents from different processes such as string welding, lamination, and testing. The retrieval scope must be isolatable by business module.

## How to Configure the Settings
| Config Item | Suggested Value | Basis for This Setting |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | Matches the precision requirements for professional fields such as battery cell current gear and lamination process parameters |
| `limit` | `Top 10 entries` | The volume of related documents for a single batch of materials or a single module is moderate, avoiding context overflow |
| `searchMode` | `mixedRecall` | Meets the retrieval needs for both image-text EL crack images and numerical IV test reports |
| `usingReRank` | `Enabled` | Filters non-crack-related results from EL image retrieval, improving the recall accuracy for professional judgment |
| `datasetSearchUsingExtensionQuery` | `Enabled` | Supplements associated batch information for battery cell grading, improving retrieval coverage for material traceability |
| `collectionIds` | `ID set bound to string welding/lamination/testing modules` | Isolates documents from different production processes, avoiding invalid cross-module recall |

## Three Common Mistakes
- The `Query read timeout` error occurs. The retrieval timeout configuration is not adjusted for large-volume EL images or IV reports, resulting in data loading timeout.
- No search results are returned after passing in a knowledge base ID. The `collectionIds` parameter is not configured correctly, or the retrieval scope does not cover the document library for the corresponding production process.
- The `apiCollection` interface returns `Invalid URL, code: 500`. The uploaded document path contains unescaped special characters, or the format requirements for photovoltaic module encapsulation documents are not met.

## How to Verify the Configuration Is Correctly Set
- Search for the keyword "battery cell current gear". Confirm that the returned results include material traceability documents for the corresponding batch.
- Trigger EL image retrieval. Confirm that re-ranked results prioritize professional documents related to crack judgment.
- Check the FastGPT v4.17.0 retrieval logs. Confirm that the `similarity` parameter value takes effect, and recall results meet the preset threshold.
- Verify that after externally passing in `collectionIds`, only document content from the corresponding business module is returned, with no invalid cross-module results.

The values provided are common starting points and should be measured against the reader's own samples.
