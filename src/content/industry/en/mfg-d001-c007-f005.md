# Supplier and Process Quality Audit for Stamping and Sheet Metal Forming: Tool Calling and Plugins

## What This Category of Data Looks Like
This category of data comes from steel coil labels and quality certificates, press and feeder operation data, mold management systems, MES systems, coordinate measuring machine or fixture inspection data. Daily documents include stamping work instructions, material utilization rate sheets, mold inspection checklists, first and last piece records, dimensional inspection reports, and mold change records. Data updates trigger per steel coil, material batch, or mold change event. Fields include steel coil grade and thickness, mold clearance value, mold change time, dimensional inspection tolerance values, and other relevant fields.

## What Constraints These Characteristics Impose on Tool Calling and Plugins
Because data updates are triggered per coil, batch, or mold change event, tool calling must support event-based triggering to match the data update rhythm and avoid invalid requests. Daily documents have significant format differences, so plugins must adapt parsing logic for multiple structured and semi-structured document types such as work instructions and inspection reports. Unlike machining which removes material piece by piece, this category relies on high-speed batch forming of sheet metal using molds. Mold changes and material batches have a major impact on stability, so tool calling must pay closer attention to real-time data synchronization at mold change nodes. Field precision requirements for mold and equipment data are high, so tool calling parameters must strictly match the field names of corresponding documents to prevent audit errors caused by parsing deviations. Batch data processing must also limit the dataset size per single call to avoid response timeouts.

## Configuration Settings
These configurations are based on FastGPT v4.17.0.
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Tool calling trigger rule | Trigger at mold change/batch inspection nodes | Matches the rhythm of data updates per coil, batch, or mold change |
| Single tool call dataset limit | 80–120 records | Prevents overload and timeouts from single requests |
| Single call result limit | Top 8–12 entries | Focuses on core audit data and avoids redundant information |
| Document parsing chunk length | 800–1200 characters | Adapts to the field length and structure of stamping documents |
| Workflow/API tool selection | Auto-adapt | Covers tool calling requirements across different audit scenarios |
| Workflow/API function-call configuration | Enable parameter validation | Ensures compliance with input and output format requirements for tool calling |
| Maximum call timeout | 600 seconds | Covers processing time for batch data and complex document parsing |

## Three Common Misconfigurations
- Custom plugins added to workflows do not display input or output parameters. This occurs because no field mapping rules for stamping documents are bound in the plugin configuration, causing the system to fail to recognize parameter structures.
- Timeout errors occur during tool calls. This occurs because the single call data volume exceeds the preset limit, or batch request accumulation occurs due to failure to trigger calls based on events.
- Fields are empty when parsing stamping inspection reports. This occurs because no parsing template for the corresponding document is matched, and structured tables are processed as plain text, preventing extraction of key dimensional fields.

## How to Verify Proper Configuration
- Manually trigger a tool call at a mold change node, and verify that the call follows preset rules and returns corresponding data.
- Upload a stamping work instruction to the workflow, and confirm that parsed fields match the preset document parsing template.
- Review tool call logs to confirm that `toolChoice` and `functionCall` configurations are active, with no parameter format errors.
- Simulate a batch data call, and check that response time does not exceed the preset 600-second threshold.

The values provided here are common starting points and should be measured against the reader's own samples.
