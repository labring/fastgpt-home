# Supplier and Process Quality Audit for Stamping and Sheet Forming: Citation Sourcing and Traceability

## What Data for This Category Looks Like
This category uses dies for high-speed, high-volume sheet forming. Data sources include steel coil labels and quality certificates, press and feeder operation data, die management systems, MES systems, coordinate measuring machine and fixture inspection data. Daily documents include stamping work instructions, material utilization rate sheets, die inspection logs, first/last piece records, dimensional inspection reports, and die change records. Data updates trigger per coil of material, per production batch, or per die change. Document fields include steel coil heat and lot numbers, die numbers, die change times, stamping dimensional tolerance values, calculated material utilization rates, and other items. Corresponding identifiers and numerical units are clearly tied to production nodes. Die changes and material batches have a significant impact on data stability.

## Constraints for Citation Sourcing and Traceability
This category has high data update frequency with clear trigger points. Citation and traceability processes must accurately bind unique identifiers such as steel coil batches and die change times. This prevents recalling invalid data across batches. Daily document types are diverse, with highly targeted fields. Recall rules must be configured per document category, such as stamping work instructions and dimensional inspection reports. This ensures cited content matches the current audit scenario. Multi-source data is stored dispersedly. The traceability link must associate related fields from different systems. For example, bind steel coil quality certificates to press operation data. Quality deviations directly affect mass production. The traceability link must retain complete citation trails to facilitate review of audit basis.

## Configuration Settings
This configuration is based on FastGPT v4.17.0 interface and parameter logic.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Core documents for this category, such as dimensional inspection reports and die change records, have lengths concentrated within this range, allowing complete retention of field information required for traceability |
| `responseData` | Only retain core answers and specified document citations | Workflow invocation scenarios require hiding redundant content from tool input and output, focusing on quality basis required for audits |
| `detail` | Enabled | Supplier and process quality audits require tracing specific parameters from die inspection logs and first/last piece records. Detailed mode fully presents key information from citation sources |
| Single recall limit | Top 6 entries | Valid documents associated with a single stamping production batch do not exceed 6. Excessive recall will introduce invalid data across batches |
| Document category-based recall | Classify by stamping work instructions and dimensional inspection reports | Daily audits only require documents for the target scenario. Category filtering prevents irrelevant data from being included in the citation trail |

## Three Common Misconfigurations
- Phenomenon: Tool invocation input and response citation fields appear in post-workflow invocation answers. Cause: Citation content display rules are not configured correctly, and redundant tool chain information is not filtered out.
- Phenomenon: "No matching documents found" error occurs during citation traceability. Cause: Recall filtering is not configured using unique identifiers such as steel coil batches and die change times. An overly broad recall range across batches results in no valid matching data.
- Phenomenon: Cited content is truncated, making complete traceability information unavailable. Cause: The `quoteMaxToken` configuration value is too small, truncating key fields in dimensional inspection reports and die change records.

## How to Verify Correct Configuration
- Submit a stamping batch quality audit query. Confirm the answer only displays core audit conclusions and specified types of document citations.
- Open the citation traceability module. Verify each citation is bound to category-specific identifier fields such as steel coil heat and lot numbers, and die numbers.
- Adjust the `quoteMaxToken` value. Confirm the truncation status of cited content matches expected behavior.
- Switch to workflow invocation mode. Confirm redundant tool call information does not appear in the answer.

The values provided here are common starting points, and should be evaluated against the reader's own samples.
