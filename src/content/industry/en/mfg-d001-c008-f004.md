# Supplier and Process Quality Audit for Cosmetics Manufacturing: Workflow Orchestration

## Data Profile for This Category
Data for this category comes from registered or filed formulas, raw material safety documents, weighing and emulsification equipment, ERP/MES systems, laboratory and packaging version management modules.
Daily documents include formula process sheets, weighing and feeding records, emulsification or filling records, cleaning and sanitization records, semi-finished and finished product inspection reports, and label review documents.
Data is updated per production batch or each line change. Document fields include exclusive content such as restricted substance levels in raw materials, process parameters, batch numbers, and packaging versions.

## Constraints on Workflow Orchestration
The per-batch or line-change update pattern of this category’s data requires workflows to bind batch-specific variables. Each production batch’s review process links to its corresponding data.
Documents have multiple types and unique fields. Targeted parsing rules must be configured for different document types to avoid incorrect field extraction.
Formulas and label content are subject to filing requirements. Compliance verification steps must be embedded in workflows to ensure data matches filed information.
This business has high-severity outcomes for errors. Fallback processes for failed retries and manual intervention must be configured to ensure review accuracy.

## Configuration Guidelines
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `variables` | Bind batch-specific variables such as `{batch_no}`, `{material_batch}`, `{pack_version}` | Data is updated per production batch, so it must be linked to production and review data for the corresponding batch |
| `nodeId` | Assign unique identifiers to formula verification, raw material review, and process parameter inspection nodes | Facilitates precise positioning of each link to troubleshoot process anomalies |
| Document parsing node | Set exclusive parsing rules for formula process sheets and inspection reports | Documents for this category include exclusive fields such as raw material restricted substances and emulsification temperature, requiring targeted extraction |
| Branch judgment node | Set branch conditions based on raw material filing compliance and process parameter thresholds | Requires verifying consistency between formulas and filed information, and whether process parameters meet requirements |
| Failure handling rules | Retry 3 times, timeout threshold calibrated via actual testing | Errors in production reviews have serious consequences, so process stability and timely intervention must be ensured |

## Three Common Misconfigurations
- Phenomenon: Workflow node configurations are lost after migration from an older version, and the interface displays a not ready status. Cause: Batch binding configuration for `variables` was not updated synchronously, and parameters from the older version are not compatible with current version rules.
- Phenomenon: Model output cannot be converted into official documents, and no corresponding files are generated after node execution. Cause: Document export format matching the category’s inspection report template was not configured, resulting in output content that cannot be saved as standard documents.
- Phenomenon: After uploading a complete formula process sheet, the model does not respond, and the workflow node status shows timeout. Cause: Reasonable parsing sharding rules were not set for large-volume documents, leading to loading and processing timeouts.

## How to Verify Correct Configuration
- Trigger a simulated batch task, and check whether batch variables bound by `variables` are correctly linked to input parameters of each node.
- Upload the standard formula process sheet for this category, and verify whether the document parsing node can accurately extract exclusive fields such as raw material restricted substances and emulsification temperature.
- Trigger an abnormal branch test, and confirm whether the failure handling rule triggers the retry or manual intervention process as preset.
- View workflow logs, and confirm that the execution order and configuration of each link node corresponding to `nodeId` are consistent.
