# Supplier and Process Quality Audit for Cosmetics Manufacturing: Model Integration and Configuration

## What the data for this category looks like
Typical data involved in supplier and process quality audits for cosmetics manufacturing includes formula process sheets, weighing and feeding records, emulsification or filling records, cleaning and clearing records, semi-finished and finished product inspection reports, and label review documents for skin care, hair care, makeup, and special cosmetics. Data sources cover registered or filed formulas, raw material safety materials, ERP/MES systems, laboratory test data, and packaging material version archives. Data is updated for each production batch or line change. Fields include restricted substance content, process temperature, packaging batch number, claimed content, and other items, with some fields using professional units such as degrees Celsius, grams, and milliliters.

## What constraints this category's characteristics impose on model integration and configuration
The batch-based, highly compliant data characteristics of this category impose multiple constraints on model integration and configuration. First, per-batch data volume is limited, but compliance requirements are strict. Context length must be limited to avoid interference from irrelevant data, while ensuring core compliance documents are not truncated. Second, data includes professional compliance fields and visual documents such as label scans and equipment operation screenshots. Parameters adapted for multimodal input must be configured. Third, data is scattered across multiple business systems. Proxy interfaces must be used for cross-source calls, and accurate identity verification must be ensured to avoid permission leaks or call failures.

## How to set the configurations
| Configuration Item | Recommended Values | Rationale |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | Matches the context length of full process and inspection documents for a single cosmetics production batch, avoiding truncation of critical compliance data |
| `temperature` | 0.1–0.3 | Reduces randomness in model output, ensuring consistent and rigorous results for formula and restricted substance audits to meet filing compliance requirements |
| `quoteMaxToken` | 2000–3000 token | Matches the reference document length for single-batch raw materials and packaging materials, ensuring completeness of audit basis |
| `vision` | Enabled | Supports reading visual content from emulsification equipment operation screenshots and label scans, adapting to image-based audit needs in production processes |
| `AIPROXY_API_ENDPOINT` | Corresponding deployed proxy platform address | Adapts to forwarding requirements for multi-source data access, ensuring stable cross-system calls across ERP and laboratory systems |
| `AIPROXY_API_TOKEN` | Valid key generated by the proxy platform | Completes identity verification for model calls, avoiding call failures caused by incorrect keys |

## Three Common Mistakes
- Phenomenon: Model call failure is prompted in the interface, with a 401 status code returned. Cause: The `AIPROXY_API_TOKEN` configuration is incorrect, and the valid key of the proxy platform is not filled in correctly, leading to identity verification failure.
- Phenomenon: The model displayed in the chat interface does not match the set Deepseek model, and results from other models are still returned. Cause: The application-level model configuration is not overwritten correctly, and the platform default model parameters are still used.
- Phenomenon: Random deviations appear in formula audit results, such as inconsistent judgments on restricted substance content. Cause: The `temperature` parameter is set too high, causing the model's output uncertainty to exceed the range required for compliance audits.

## How to confirm the configuration is successfully set
- Enter the application model configuration page of FastGPT v4.17.0, and verify that `AIPROXY_API_ENDPOINT` and `AIPROXY_API_TOKEN` match the public configuration of the proxy platform.
- Upload the complete process sheet and inspection report of a single production batch, initiate a formula compliance audit test, and check whether the returned results include complete reference document fragments.
- Adjust the `temperature` parameter to 0.2, initiate three identical restricted substance audit requests, and confirm that the returned results are completely consistent.
- Upload a label scan, verify that the `vision` function can correctly identify the batch number and claimed content on the label without recognition errors.

The values provided are common starting points and should be measured against the reader's own samples.
