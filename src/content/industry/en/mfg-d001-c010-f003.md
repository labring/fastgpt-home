# Supplier and Process Quality Audit for Medical Device Assembly and Clean Production: Multi-turn Dialogue and Prompt Engineering

## What the Data for This Category Looks Like
Data sources for this category include design history files, device and material batch data, MES systems, clean environment monitoring equipment, sterilization equipment, and inspection and calibration systems. Updates occur once per batch or per product. Clean zone environment monitoring updates on a fixed scheduled basis. Daily documents cover production process specifications, batch production records, clean zone operation records, sterilization batch records, inspection reports, software version records, adverse event and traceability materials. Fields include batch number, sterilization temperature (℃), sterilization duration (minutes), clean zone temperature and humidity, material unique identification number, software version number, and more.

## Constraints Imposed on Multi-turn Dialogue and Prompt Engineering Workflows
Data for this category is voluminous and updated by batch and cycle. Multi-turn dialogue must bind to a single batch session context to avoid mixing cross-batch data. Document fields are numerous and include high-risk parameters. Prompts must precisely limit extraction to specific fields to prevent interference from irrelevant data. Data sources involve production and environmental monitoring equipment. Dialogue must support real-time pulling of the latest batch records and environmental data to ensure timeliness of audit basis. Additionally, medical device traceability requirements require dialogue to retain complete audit context for subsequent verification.

## Configuration Settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Maximum Context Length | 8000–12000 characters | Matches the document length of a single batch production record to avoid truncation of critical sterilization and clean zone data |
| Session Binding Rule | Restrict single-batch sessions via `chatId` | Ensures dialogue only associates with files for the current audit batch, avoiding cross-batch data mixing |
| Variable Binding Rule | Bind `variables` to the current batch number and clean zone number | Automatically pulls batch production records and environmental monitoring data for the corresponding batch |
| Multimodal Recognition Toggle | Enabled, limited to JPG/PNG formats only | Adapts to audit requirements for clean zone monitoring images and sterilization record scans |
| Session Timeout Duration | 600 seconds | Matches the full duration of a single-batch audit process to avoid mid-process interruptions |
| Referenced File Display | Enabled on demand | Meets medical device traceability requirements, displays reference sources only when verification is needed |

## Three Common Configuration Errors
- Symptom: When calling a prompt during multi-turn dialogue, the historical context content of the current session cannot be retrieved. Cause: `chatId` binding for the current session is not configured correctly, causing the prompt to fail to associate with submitted audit records and `messages` historical dialogue content.
- Symptom: After enabling multimodal image recognition, when uploading clean zone monitoring images or sterilization record scans, the reply indicates that image content cannot be provided. Cause: The multimodal recognition toggle is not enabled, or the prompt does not explicitly allow processing image format inputs.
- Symptom: Referenced batch production record files are forcibly displayed at the bottom of dialogue replies, and cannot be hidden on demand. Cause: The referenced file display toggle is configured as globally enabled, and not adjusted to enabled on demand per audit node requirements.

## How to Verify Successful Configuration
- Submit batch production records and clean zone monitoring data for a single batch, check that the dialogue only returns content related to that batch, with no cross-batch data included.
- Upload compliant JPG or PNG format images, check that the dialogue can correctly identify and associate key information in the images, such as sterilization parameters and temperature and humidity records.
- Initiate multi-turn dialogue, confirm that subsequent questions do not require re-submitting batch information, and check that the dialogue can respond based on prior audit context.
- Adjust the configuration of the referenced file display toggle, check that referenced files are no longer forcibly displayed at the bottom of replies, or are displayed only on demand.

The values provided are common starting points and should be validated against local operational samples.
