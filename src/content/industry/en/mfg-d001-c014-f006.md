# Supplier and Process Quality Audit for Dyeing and Finishing: Citation Sources and Traceability

## What This Category's Data Looks Like
Data for this category comes from customer color swatches, formula libraries, dye chemical batch records, dye vat operation parameters, colorimeter data, setting machine logs, and environmental monitoring ledgers. Daily documents include dyeing formulas, chemical weighing records, dye vat curves, proofing confirmation sheets, color difference reports, setting process sheets, and sewage ledgers.
Data is updated per vat, per batch, or per shift. Fields include batch number, temperature curve, color difference ΔE value, chemical mixing ratio, and emission indicators. Units include degrees Celsius, kilograms, seconds, colorimetric units, and others.

## How These Category Characteristics Impact Citation and Traceability Requirements
This category’s batched, real-time data requires traceability to accurately bind vat numbers and batches to avoid cross-batch confusion. Non-structured documents such as dyeing formulas and dye vat curves used in wet chemical processing must retain batch-related fields after chunking. Otherwise, traceability cannot match the corresponding production link.
High-frequency per-vat data requires the traceability system to quickly locate the latest version, and also link environmental monitoring data to verify compliance. If vat numbers and timestamps are not bound, traceability results will not correspond to actual production processes, and cannot support the evidence requirements for quality audits.

| Maximum context recall count | Top 6 entries | Cover all associated data for a single vat's production process, meeting the full traceability requirements of quality audits |

## Three Common Configuration Errors
- The citation result does not display the batch field of the corresponding document. The symptom is that the citation field in the log is empty. The cause is that the batch field binding configuration is not enabled, resulting in failure to extract key identifiers such as vat numbers and batches during traceability.
- Unable to match the corresponding production document. The symptom is that the number of retrieval results is 0. The cause is that the chunk length is set too large, causing documents such as dye vat curves and color difference reports to lose batch association information after chunking, and cannot match user queries.
- The cited content is not displayed in the original format. The symptom is that Markdown-formatted process sheet content is converted to plain text. The cause is that the full document traceability configuration is not enabled, and only the chunked fragment content is returned.

## How to Verify the Configuration Is Correct
- Initiate a quality audit query associated with a specified vat number, and check whether core fields such as vat number and batch are included in the returned results.
- Upload a dye vat curve document, initiate a retrieval for the corresponding vat number, and confirm that the recall results include the full path and generation time of the document.
- Test multi-round queries associated with different batches, and confirm that each retrieval binds the production batch corresponding to the current query, and does not reuse associated data from historical batches.
- View the citation display area, and confirm that the format of the original document is fully retained, with no format loss.

The values provided are common starting points and should be measured against the reader's own samples.
