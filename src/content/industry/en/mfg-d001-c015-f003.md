# Supplier and Process Quality Audits for Active Pharmaceutical Ingredient and Pharmaceutical Intermediate Production: Multi-turn Dialogue and Prompt Engineering

## What the Data for This Category Looks Like
The data for this category comes from registered process documents, raw material batch ledgers, DCS control systems, weighing record systems, LIMS laboratory information management systems, chromatography data systems, and QMS quality management systems. Daily generated documents include batch production records, material balance reports, reaction and purification step records, cleaning validation records, impurity profile analysis reports, and deviation and change management documents. Data updates trigger once per production batch and per process step. Single-batch data includes process parameters, impurity test values, yield data, and compliance record fields.

## Constraints Imposed by These Characteristics on Multi-turn Dialogue and Prompt Engineering
Data for this category comes from dispersed sources covering professional production and quality links. Multi-turn dialogue must link exclusive fields from multiple systems such as DCS and LIMS. Prompts must clearly limit data retrieval to the current production batch or process step. Frequently updated batch data requires that dialogue context only retains valid information from the most recent single batch, to avoid audit errors caused by cross-batch data confusion. Complex professional document structures and exclusive terms such as impurity profiles and solvent residues require prompts to pre-set industry-standard explanations. A compliance check step must be added to the dialogue flow, to prevent unevaluated changes or deviations from entering the audit process.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum Context | 8000–12000 tokens, calibrated via actual testing | Fits the total length of single-batch production records and impurity profile reports, and avoids exceeding the context limit of FastGPT v4.17.0 |
| Query Optimization | Enable professional term calibration | Adapts to exclusive terms for pharmaceutical manufacturing such as impurity profiles and solvent residues, and improves dialogue understanding accuracy |
| Single Retrieval Limit | Top 6 results | Limits the number of retrieval results, and avoids overloading the audit logic with data from multiple systems |
| Variable Binding | Bind the current batch ID and raw material batch number in `chatId` and `variables` | Links batch information in the dialogue, and ensures retrieval only covers production data for the corresponding batch |
| Dialogue History Retention | Only retain the most recent 3 interactions in `messages` | Matches the short-process requirements of step-by-step audits, and reduces resource usage from redundant context |
| Pre-configured Prompt | Pre-set supplier audit opening script | Matches the standardized audit process for the business scenario |

## Three Common Misconfigurations
- The number of dialogue return results exceeds expectations, showing more than 6 retrieved data entries. This occurs because no specific value is set for the single retrieval limit, causing the system to call full historical production records.
- Dialogue cannot link impurity profile data for the current batch. This occurs because the batch ID parameter in `variables` is not bound, causing the retrieval scope to cover all production batches.
- The dialogue opening shortcut button does not trigger the pre-configured audit prompt. This occurs because the pre-set supplier audit opening prompt is not bound to the shortcut button in the configuration.

## How to Verify Successful Configuration
- Enter "Retrieve material balance data for the current batch", confirm that the system only returns production records for the current batch.
- Trigger the dialogue opening shortcut button, confirm that the pre-set supplier audit opening prompt pops up.
- Check the `messages` field in the dialogue, confirm that only the most recent 3 interactions are retained in the context.
- Enter a query containing "impurity profile" or "solvent residue", confirm that the system returns matching professional test data.
