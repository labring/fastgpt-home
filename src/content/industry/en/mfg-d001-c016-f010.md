# Supplier and Process Quality Audit for Transformer and High-Voltage Electrical Manufacturing: Knowledge Base Retrieval and Recall

## Data Overview for This Category
Data originates from design BOMs, silicon steel sheet and insulating material inventory records, vacuum drying equipment logs, oil test reports, and high-voltage test records from test stations.
Daily documents cover winding and core assembly records, vacuum drying logs, insulating oil test reports, partial discharge and withstand voltage test reports, and nameplate parameter tables.
Fields include insulation moisture content, partial discharge amplitude, withstand voltage value, tap position, and other metrics. Common units are ppm, pC, and kV.
Data is updated per individual product and per batch of raw materials.
Each individual product links to multiple test and assembly records.
Precise association of product serial numbers and raw material batch numbers is required to enable full-process traceability.

## Constraints for Knowledge Base Retrieval and Recall
This category’s data is updated per individual unit or batch. It requires precise association of product serial numbers and raw material batch numbers.
Retrieval must support filtering by these identifiers to prevent mixing cross-batch or cross-unit data.
Documents contain highly specialized insulation parameters and high-voltage test data. Semantic recall matching professional terminology is needed to align with this category’s specialized data characteristics.
Each individual product links to multiple test and assembly documents. The number and relevance of recall results must be controlled to avoid context overload that exceeds model processing limits.
Test data has strong timeliness. Retrieval must support sorting by update time. This ensures the latest test records are used during audits, supporting accurate quality audits.

## Configuration Settings
The following table outlines recommended configuration values and their rationale:

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | This category’s test data is highly specialized. Filtering low-correlation results prevents mismatches of insulation parameters and test data |
| `limit` | `Top 8–12 entries` | The number of documents linked to a single product is moderate. This setting controls context length to stay within the model processing limit of FastGPT v4.17.0 |
| `searchMode` | `vector` | This setting enables recall of semantically matched professional test reports and assembly records, adapting to the professional terminology retrieval needs of this category |
| `usingReRank` | `Enabled` | This category’s data is highly specialized. Reranking improves the ranking priority of highly relevant test data and assembly records |
| `datasetSearchUsingExtensionQuery` | `Enabled` | This setting expands the retrieval scope of professional terminology. For example, "partial discharge" can be expanded to "local discharge" to cover more relevant documents |
| `collectionIds` | `Bind corresponding transformer/high-voltage electrical test and assembly document collections` | This setting precisely restricts the retrieval scope to avoid mixing irrelevant data from other categories |

## Three Common Configuration Mistakes
- Phenomenon: Image links returned during knowledge base retrieval show expired status and cannot be accessed. Cause: A permanent storage policy for the document knowledge base is not configured correctly, and only temporary uploads have an expiration date set.
- Phenomenon: Retrieval results include documents outside this category, such as low-voltage electrical assembly records. Cause: The retrieval document collection is not restricted via `collectionIds`, leading to recall of cross-category data.
- Phenomenon: The number of returned retrieval results does not match the configured `limit` value, with either too many or too few results. Cause: The `similarity` threshold is not set correctly, resulting in low-correlation results being included or high-correlation results being filtered out.

## How to Verify Correct Configuration
- Enter the professional term "partial discharge". Retrieval results should include partial discharge test reports to confirm the `datasetSearchUsingExtensionQuery` extended retrieval function is active.
- Check the number of returned retrieval results to confirm it matches the configured `limit` value, verifying the `limit` parameter is applied properly.
- Review the sorting of retrieval results, with the latest test records displayed first, to confirm the `searchMode` and reranking configuration is reasonable.
- Check the relevance scores of retrieval results to confirm they meet the `similarity` threshold requirements, verifying the `similarity` configuration is active.

The values provided are common starting points and should be evaluated against relevant internal samples.
