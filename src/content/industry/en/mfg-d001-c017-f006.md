# Supplier and Process Quality Audit for Spraying and Coating: Citation Sources and Traceability

## What the data for this category looks like
Data for this category covers the entire production process of coating lines for automotive, home appliance, construction machinery, metal furniture and other applications. Daily documents include coating process cards, paint batch sheets, paint mixing records, film thickness and color difference reports, oven curves, defect repair orders, and VOCs ledgers. Data sources include TDS/SDS documents from paint suppliers, spray booth and oven operation data, colorimeters, film thickness gauges, environmental monitoring equipment, and MES production systems. Updates sync with each paint batch delivery, each shift production start, and continuous device data collection. Core fields include paint batch number, viscosity value, film thickness μm, color difference ΔE, oven temperature curve, VOCs concentration, and other key parameters.

## What constraints these characteristics impose on the "citation sources and traceability" link
This category’s data is multi-source and heterogeneous, including paper documents, structured data collected by equipment, and test reports. Accurate association of corresponding fields across different format data sources is required during citation traceability, to avoid confusion across data types. Frequently updated batch and shift production data requires prioritizing the latest batch paint parameters and shift production records during traceability, to prevent misuse of cross-batch data. The coating process includes multiple stages: pre-treatment, spraying, and curing. The time window of each stage must be matched to ensure the cited source strictly corresponds to the audit link. Traceability of defect repair orders requires association with corresponding batch coating parameters, matching the generation time of defects such as particles and sagging with equipment operation data, to improve traceability accuracy.

## Three common mistakes
- An error occurs when viewing knowledge base citations in chat responses, prompting "No valid data sources matched". The cause is failure to associate the paint batch number with the corresponding paint TDS/SDS and paint mixing records, resulting in inability to match core data for the corresponding batch during traceability.
- Variable reference fails when a knowledge base search card selects a knowledge base, returning empty fields. The cause is that the `responseData` configuration is not enabled, resulting in no associated structured data fields being returned, and the variable replacement logic cannot be completed.
- Irrelevant non-coating citation content appears in responses. The cause is that the single search limit is set too high, capturing other category data beyond the scope of coating audits, resulting in mixed traceability results.

## How to confirm the configuration is set correctly
- Initiate an audit query for a coating defect of a specific batch, check whether the cited sources include the paint batch sheet, film thickness and color difference report, and oven curve for that batch.
- Check whether the fields in the cited content include category-specific data, such as film thickness μm value, color difference ΔE value, or VOCs concentration records.
- Verify that the error prompt has disappeared, ensuring that the `quoteMaxToken` and `detail` configurations match the length requirements of the current data sources.
- Confirm that no non-coating citation content appears, and verify that the single search limit and reordering configurations are effective.

The values provided are common starting points and should be measured against the reader's own samples.
