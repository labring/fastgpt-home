# Supplier and Process Quality Audit for Spraying and Coating: Document Parsing and Chunking

## What the data for this category looks like
Core data for spraying and coating scenarios comes from daily production and supplier documents of automotive, home appliance, engineering machinery, and metal furniture coating lines. Daily documents include coating process cards, paint batch sheets, paint mixing records, film thickness and color difference reports, oven curves, defect repair orders, and VOCs ledgers. Data sources include TDS/SDS documents from paint suppliers, spray booth and oven operation data, colorimeters, film thickness gauges, environmental monitoring systems, and MES systems. Data is updated per paint batch and per production shift. Some instrument data such as oven curves is collected continuously. Document fields include professional parameters including film thickness (unit: μm), color difference ΔE, oven temperature (unit: ℃), paint viscosity (unit: Pa·s), and VOCs concentration (unit: mg/m³).

## Constraints on Document Parsing and Chunking
The variety of document types requires parsing tools to support multiple formats including plain text, structured tables, and curve charts. Frequently updated production data requires parsing processes to deliver sufficient efficiency to support batch document uploads. The strong correlation of data from the same production batch requires chunking rules to retain business associations between parameters, and avoid splitting that destroys complete information required for audits. Some documents output directly by instruments contain image-based text, so support for OCR recognition is required. Missing key parameters can lead to batch repairs or compliance risks, so chunking must ensure core audit fields are not omitted.

## Configuration Settings
These configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Coating documents include process paragraphs, table fragments, and instrument data. This range retains the association of core parameters for a single batch, and avoids chunks that are too small or too long |
| `chunkSplitter` | Split by headings and paragraphs | Matches the process step and report chapter structure of coating documents, and ensures chunking aligns with business logic |
| `customPdfParse` | Enabled | Adapts to documents containing tables and image-based text such as TDS/SDS and oven curves, and extracts complete field content |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Supports batch upload of multiple documents such as batch sheets and continuous oven curves in a single operation |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Adapts to parsing long documents such as long-duration oven curves and multi-page process cards, and prevents mid-parsing timeouts |
| `chunkSettingMode` | Manual configuration | Adjusts chunking rules for different document types such as table-based reports and plain text process cards, to fit scenario requirements |

## Three Common Mistakes
- Phenomenon: After uploading an Excel-format paint batch sheet, core fields such as paint model and batch number appear empty. Cause: `customPdfParse` is not enabled for table format adaptation, so structured data cannot be extracted correctly.
- Phenomenon: When uploading a single PDF file containing over 50 pages of oven curves, the parsing task times out and fails. Cause: `PARSE_FILE_TIMEOUT_SECONDS` is set to less than 300 seconds, which cannot cover the parsing time required for long documents.
- Phenomenon: Queries cannot associate film thickness data with the corresponding coating batch. Cause: `chunkSize` is set to over 2000 characters, which splits film thickness, color difference, and batch information for the same batch into different chunks, destroying data association.

## How to Confirm Proper Configuration
- Upload a standard coating process card PDF, and check if the parsed text fully retains process steps, parameter requirements, and chapter headings.
- Upload an Excel film thickness and color difference report, and check if film thickness values, color difference ΔE values, and corresponding workpiece numbers in the table are correctly extracted.
- Upload a single-page oven curve PDF, wait for parsing to complete, and confirm no timeout errors appear in the task.
- Adjust `chunkSize` to 800–1200 characters, test querying multiple parameters for the same batch of paint, and confirm the returned content contains complete associated information.

The values listed here are common starting points, and should be evaluated against samples relevant to the actual deployment context.
