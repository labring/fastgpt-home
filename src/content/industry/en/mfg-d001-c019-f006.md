# Supplier and Process Quality Audit for Plastic Injection Molding: Citation Sources and Traceability

## What Data Looks Like for This Category
This category’s data covers all nodes in the injection molding workflow. Sources include resin batches and property sheets, injection molding machine operating parameters, mold temperature controller data, workshop MES systems, and dimensional and appearance inspection results. Daily documents include injection molding process cards, raw material drying records, mold history logs, first-piece inspection forms, patrol inspection records, and material change and machine cleaning records. Data updates alongside production batches, mold or material change operations, and each shift’s production cycle. Fields include resin batch numbers, drying temperatures, injection pressures, cooling durations, mold numbers, and some parameters have clear units.

## Constraints Imposed by These Characteristics on the "Citation Sources and Traceability" Link
The high-frequency updates and multi-source dispersed nature of this category require citation traceability to bind to specific production batches and operation nodes, to avoid cross-batch data confusion. The existence of multiple types of production documents requires the system to support cross-document associated citations, such as binding raw material drying records to the corresponding batch’s injection molding process card. Data sources cover equipment parameters and quality inspection results. The traceability link must clearly mark the data’s affiliated system and collection time to ensure traceability. Since errors may lead to batch defects, mold damage, and customer safety issues, traceability must be precise to individual production records, not just vague document ranges.

## Configuration Settings
These configurations are adapted for FastGPT v4.17.0:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the average character count of documents related to a single batch of injection molding production, ensuring complete coverage of process and quality inspection data |
| `responseData` | Retain all fields from source documents | Facilitates direct extraction of key production information such as resin batch numbers and mold numbers during subsequent traceability |
| `detail` | Enabled | Supports returning the full path and collection time of cited documents, meeting the high-precision traceability requirements for production audits |
| Single search limit | Top 6 results | Covers multiple types of documents involved in a single batch of production, avoiding omission of key records |
| Context window | Calibrated based on actual testing | Adapts to the multi-source association needs of injection molding production data, avoiding context overflow |

## Three Common Configuration Mistakes
- Phenomenon: An error prompt appears after configuring the model for testing, but normal citation functionality works after ignoring the prompt. Cause: The return format of `responseData` was not configured correctly, leading to incompatibility with the initial verification logic, though normal parsing works during actual calls.
- Phenomenon: Only one cited document is returned for each retrieval, and multiple types of production documents cannot be called. Cause: The single search limit was set too low, failing to cover multiple types of documents such as injection molding process cards and drying records involved in a single batch of production.
- Phenomenon: The knowledge base selection is empty after importing documents, requiring manual selection of the target knowledge base. Cause: No default category binding was configured for production documents, leading the system to fail to automatically load the knowledge base corresponding to the production batch.

## How to Confirm Configuration Completion
Initiate a test query that includes a specific production batch, and verify whether the returned results mark the specific fields and collection time of the cited documents.
Adjust the value of `quoteMaxToken`, and verify if the cited document content in the response fully covers the key information of the target production record.
Import multiple types of injection molding production documents, launch a cross-document associated query, and confirm that the system can return information from multiple different types of cited documents.
Check if the `detail` configuration item is enabled, and confirm that the returned results include the full storage path and update time of the cited documents.

The values provided here are common starting points and should be evaluated against the samples used in the specific deployment.
