# Supplier and Process Quality Audit for Safety, Environmental Protection and Special Operations Management: Citation Source and Traceability

## What Data for This Category Looks Like
Data sources for this category include regulatory standards, online environmental monitoring equipment, gas detectors, personnel qualification files, equipment isolation lists, and regulatory platforms. Update frequencies fall into three categories: after each operation is completed, real-time or per monitoring cycle requirements, and periodic check updates. Daily documents cover risk identification lists, work permit tickets for hot work, confined space, hoisting and other operations, environmental monitoring records, hazardous waste disposal ledgers, emission monitoring reports, and accident and hidden danger rectification reports. Document fields include operation time, operation content, guardian qualification number, hazardous waste output, monitoring values, and more. Units include cubic meters, milligrams per cubic meter, person, day, and others.

## Constraints for the Citation Source and Traceability Link
Data sources for this category are scattered and diverse. Multiple data sources such as paper work permit tickets, real-time monitoring data, and regulatory platform files must be linked simultaneously. The citation and traceability link must match unique identifiers of each data source, such as work permit ticket numbers and equipment IDs, to avoid mixing documents from different scenarios. Data update frequencies vary widely. Real-time monitoring data must be retrieved immediately. Periodically updated ledgers require index refreshes on their set cycles. The traceability link must adapt to these differing update rhythms. Document structures and fields differ significantly. Work permit tickets have fixed approval fields, while hazardous waste ledgers use a ledger-style structure. Citations must accurately match corresponding fields to ensure key audit information is not missed. Errors in audit scenarios carry serious consequences. Citation results from the traceability link must accurately correspond to specific operation, monitoring, or rectification records.

## How to Configure Settings
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Adapts to the typical length of documents such as single work permit tickets and hazardous waste ledgers, avoiding truncation of core audit information |
| `responseData` | Return all associated data source metadata | Retains identifiers such as work permit ticket numbers and monitoring equipment IDs to facilitate subsequent traceability verification |
| `detail` | Enable full field display | Retains key audit fields such as operation time, qualification number, and monitoring values |
| Single batch of retrieved citation entries | Top 3–5 entries | Covers necessary reference data for core audit scenarios including risk identification, work permits, and hidden danger rectification |
| Data source time filtering rule | Prioritize retrieving data from the past 7 days | Matches the update frequencies of real-time monitoring and periodic inspections, ensuring the timeliness of cited data |

## Three Common Configuration Mistakes
- When setting the number of citation entries, only fixed levels are available, and custom intermediate values cannot be used. For example, only levels such as 100 and 900 are provided, and values around 300 cannot be configured. This occurs because the platform’s default citation entry count uses fixed levels, and custom interval settings are not enabled.
- After an audit request is submitted, the returned citation content only includes fragmentary information, and key fields such as guardian qualification numbers and hazardous waste output are not displayed. This occurs because the full-field citation detail level configuration is not enabled, and only document fragments are retrieved.
- Low-relevance historical documents are prioritized in citation results, and the latest real-time monitoring data is not retrieved first. This occurs because the time-sorted data source filtering rule is not configured, leading to a retrieval order that does not meet audit requirements.

## How to Verify Successful Configuration
- Submit an audit request containing keywords for hot work permit tickets, and check if the returned results include the full fields and unique number of the corresponding work permit ticket.
- View the citation source list in the response, and confirm the number of results matches the preset 3–5 entry level.
- Check the time sorting of cited content, and confirm that the latest environmental monitoring data or work permit tickets are displayed first.
