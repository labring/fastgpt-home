# Supplier and Process Quality Audit for Complete Home Appliance Manufacturing: Tool Calling and Plugins

## What data for this category includes
This category covers the full production process of air conditioners, refrigerators, washing machines and small home appliances. Daily documents include configured BOM, assembly work instructions, refrigerant charging records, electrical safety test reports, performance spot check reports and rework records.
Data sources include ERP/MES systems, component batch ledgers, tightening and charging equipment, safety compliance testers, performance laboratory data and after-sales fault records.
Data updates follow per-unit product, per-shift output or spot check plan schedules. Fields include component numbers, process parameters, test results, batch information and after-sales feedback content.

## Constraints on tool calling and plugins workflows
Since data updates per unit, per shift or per spot check plan, tool calling must support high-frequency triggering and batch data retrieval, and adapt to format conversion for multi-source heterogeneous data.
Mixed-line assembly of multiple product models requires tools to real-time verify matching between assembly processes and BOM to avoid misassembly.
Real-time collection of process parameters such as safety compliance and refrigeration requires tool calling to support low-latency communication with industrial equipment.
Correlation analysis between after-sales fault data and production data requires plugins to retrieve information from different data sources across systems, while meeting timeliness requirements for data updates to avoid quality risks caused by lagging judgments.

## Three Common Misconfigurations
- Symptom: Industrial equipment data interface returns 408 timeout error. Cause: The tool call timeout threshold is not set to match industrial device durations, and the default threshold is too short, causing call interruption before the device completes data return.
- Symptom: Batch-retrieved spot check report fields are empty. Cause: Batch calling mode for `functionCall` is not enabled, and the single call data volume is insufficient, resulting in failure to retrieve complete spot check batch data.
- Symptom: An error indicating incompatible protocol is prompted when calling plugins services generated by FastGPT. Cause: The SSE communication format generated by FastGPT is not adapted, and a compatible plugin access method is not configured, resulting in mismatched communication protocols.

## How to Verify Proper Configuration
- Submit an assembly process verification request for a single home appliance, check whether the tool automatically calls the matching tool for BOM and assembly work instructions, confirming that the call logic aligns with configuration requirements.
- Submit a batch spot check data retrieval request, check whether the number of returned data entries matches the configured single call limit, confirming that the batch calling function is active.
- Connect one safety compliance tester, submit a data retrieval request, check whether the returned test data format matches expectations, confirming that the multi-source data adaptation configuration is active.
- Submit a real-time assembly verification request, check whether the tool returns verification results in stream form, confirming that the stream response switch is configured correctly.
