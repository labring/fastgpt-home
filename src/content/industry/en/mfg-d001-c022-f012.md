# Supplier and Process Quality Audit for Household Appliance Final Assembly Manufacturing: Deployment and Upgrade

## What the Data for This Category Looks Like
Business documents involved in supplier and process quality audit for household appliance final assembly manufacturing include configured BOM, assembly work instructions, refrigerant charging records, electrical safety test reports, performance sampling inspection reports, and rework records. Data sources cover ERP/MES systems, component batch ledgers, tightening and charging equipment, safety compliance testers, performance lab equipment, and after-sales fault databases. Data updates are performed per single product, per shift production batch, or per sampling plan. Core fields include component model, process parameters, test results, rework reasons, and other key information.

## Constraints Imposed on Deployment and Upgrade by These Characteristics
The high-volume mixed-line assembly nature of this category requires deployed retrieval systems to accurately distinguish between multiple document models, to avoid retrieval bias related to incorrect assembly. Multi-source industrial equipment and real-time system data sources require configuring network policies adapted to intranet isolation, to reduce public network transmission delays and security risks. The high-frequency data update rhythm requires using rolling update modes during upgrades, to avoid interrupting real-time data access for production links. Sensitive safety compliance and after-sales data require configuring strict access permission verification rules, to ensure data compliance.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30 connections` | Adapt to concurrent write and retrieval demands for quality inspection data across multiple shifts, avoid exhausting database connections |
| `MONGODB_URI` | `replica set address including authentication information` | Ensure access security for sensitive data such as component batches and rework records, support automatic failover |
| `STORAGE_S3_ENDPOINT` | `enterprise intranet object storage domain name` | Reduce public network transmission delays, adapt to storage demands for large volumes of refrigerant charging records and safety compliance test videos |
| `REDIS_URL` | `local Redis instance, port 6379` | Cache assembly work instruction content for high-frequency queries, improve retrieval response speed |
| `FILE_TOKEN_KEY` | `32-bit custom encryption key` | Generate valid access tokens for documents embedded in production dashboards, avoid permission errors |
| `ROOT_KEY` | `key known only to internal operations staff` | Restrict access to backend management interfaces, prevent unauthorized configuration modifications |

## Three Common Errors
- Phenomenon: After upgrading to FastGPT v4.9.3, submitting a retrieval request with component batch keywords returns empty results. Cause: Failed to reindex newly added BOM and assembly work instruction fields, causing the vector database to not include the latest quality inspection documents.
- Phenomenon: When embedding FastGPT speech recognition function into a production dashboard webpage, a permission denied prompt appears. Cause: Failed to configure `FILE_TOKEN_KEY` to generate access permission verification rules, causing cross-domain requests to be blocked by the production environment gateway.
- Phenomenon: After executing docker build to start the FastGPT container, a database connection timeout prompt appears. Cause: `MONGODB_URI` is not configured with the correct intranet access address, and does not adapt to the network isolation policy of the production environment.

## How to Verify Correct Configuration
- Execute the `docker ps` command, confirm that all relevant containers for FastGPT v4.17.0 are running, with no abnormal exits.
- Submit a retrieval request containing keywords for a specific model of air conditioner assembly work instructions, verify that the returned results match the business documents for household appliance final assembly manufacturing.
- Upload a new refrigerant charging record, confirm that the file storage path complies with the configuration requirements of `STORAGE_S3_ENDPOINT`.
- Test the speech recognition function embedded in a test webpage, confirm that no permission error prompts appear.
