# Supplier and Process Quality Audit for Industrial Instrument Manufacturing and Calibration: Vector Models and Indexes

## What Data for This Category Looks Like
This category of data comes from flow, pressure, temperature, analytical instrument manufacturers and metrology laboratories. It covers assembly and commissioning sheets, calibration procedures, original calibration records, error curves, metrology certificates, and software version records. Data is sourced from design documents, standard instrument monitoring data, calibration software, laboratory information systems, and customer range requirements. The update frequency is per calibration per device. Fields include range units such as Pa, ℃, ppm, calibration dates, traceability numbers, error calculation values, and more. Some documents contain structured numerical values and chart text.

## What Constraints These Characteristics Impose on Vector Models and Indexing
This category of data has a high update frequency, and each single data entry is tied to the full calibration process of one device. When creating vector chunks, retain key metadata such as traceability numbers and measurement ranges to avoid information breaks. Error curves and metrology certificates include structured numerical values and chart text, so adapt vector mapping logic for long texts and structured fields. Calibration records for each device are updated independently, so the index must support incremental synchronization to avoid the time cost of full reconstruction. Data traceability requirements are strict, and retrieval results must link to field information from the original document. The index must therefore retain the association between document metadata and vectors.

## How to Configure the System
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Chunk Length | 800–1200 characters | Preserve semantic integrity for long texts such as calibration procedures and original records, and prevent truncation of key fields |
| Overlap Length | 50–100 characters | Retain semantic connections between adjacent chunks, and support coherence for continuous numerical text such as error curves |
| `maxToken` | 4096 token | Match the input limit of general embedding models, and accommodate the text length of multi-field documents like calibration certificates |
| Similarity Threshold | 0.75–0.85 | Filter low-match non-calibration documents, and ensure retrieval results relate to core instrument calibration workflows |
| Single Search Limit | Top 10 entries | Control the number of retrieval results, and prevent context overload that could impact audit judgments |
| `defaultToken` | Determined via actual measurement | Adapt to average token lengths of different calibration records, and optimize index construction efficiency |

## Three Common Misconfigurations
- No search results after upgrading the platform, and the interface shows abnormal knowledge base index status. The cause is failure to update index metadata association rules synchronously. FastGPT v4.17.0 adjusts field matching verification logic, and existing configurations do not adapt to the traceability number field format of calibration records.
- An error occurs when importing calibration records in CSV format, with a chunk failure prompt. The cause is unescaped special characters in the CSV file, such as the ± symbol in error curves, without prior text cleaning, triggering format verification failure during chunking.
- Retrieval results do not link to traceability information from the original calibration certificate. The cause is that the index configuration does not enable the metadata retention option, so only text vectors are stored without associating document fields, making key audit information like traceability numbers unavailable in retrieval results.

## How to Verify Proper Configuration
- Upload a single calibration procedure document, run a chunk test, and confirm the chunk results retain key fields such as traceability numbers and measurement ranges.
- Trigger incremental index synchronization, verify that updated calibration records can be retrieved normally, and confirm no excessively long full reconstruction time.
- Enter a search term such as "pressure calibration error calculation", and check that retrieval results link to metadata fields of the corresponding document.
- Adjust the similarity threshold, and confirm that the matching degree of retrieval results meets the accuracy requirements for audits.

The values provided here are common starting points and should be evaluated against the reader's own samples.
