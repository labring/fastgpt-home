# Supplier and Process Quality Audit for Non-Ferrous Metal Smelting and Electrolysis: Deployment and Upgrade

## What This Category’s Data Looks Like
Daily documents for this category include batching lists, smelting records, electrolyzer status records, laboratory reports, anode and cathode quality records, and environmental protection ledgers. Data sources cover concentrate and auxiliary material analysis, DCS systems, cell voltage and current monitoring, laboratory testing, and energy and environmental monitoring equipment. Update frequency aligns with business nodes: records are generated for each raw material batch, each smelting furnace, or each electrolyzer. Some cell status, voltage, and current data update in real time. Document fields include concentrate grade, auxiliary material ratio, cell voltage, current value, metal content, and others. Common units are kilograms per ton, volts, kiloamps, grams per ton, and similar units.

## Constraints Imposed by These Characteristics During Deployment and Upgrade
Multi-source heterogeneous data sources require configuring access links adapted to different data sources during deployment, while ensuring synchronization stability for real-time data. Frequently updated business data, such as electrolyzer real-time parameters, creates high concurrent access pressure. Adjust database connection parameters to avoid overload. Diverse document types and sensitive business data, such as environmental protection ledgers, require compliant storage and encryption configurations. During upgrades, ensure migration compatibility for historical documents to avoid interrupting audit processes due to field format changes. Inter-department collaboration needs call for a unified access entry, adapted to usage scenarios for roles including smelting, scheduling, and laboratory staff.

## How to Configure Settings
The following configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `DB_MAX_LINK` | 10–20 connections | Adapt to concurrent connection requirements for multiple data sources (DCS, laboratory, cell status monitoring) and avoid exhausting database connections |
| `STORAGE_S3_ENDPOINT` | Intranet address of the enterprise’s internal object storage service | Adapt to the need for batch storage of multiple types of documents including batching lists and cell status records, and ensure read speed under high concurrency |
| `REDIS_URL` | Intranet-deployed Redis service address, default port 6379 | Cache real-time cell voltage and current data to reduce database query pressure, adapting to real-time updated business scenarios |
| `PG_URL` | PostgreSQL database address associated with laboratory reports and metal balance ledgers | Store structured quality audit-related data and ensure stable data query performance |
| `FILE_TOKEN_KEY` | Key generated according to the enterprise’s internal document encryption rules | Encrypt and store sensitive business documents including batching lists and environmental protection ledgers, complying with data security requirements |
| `FE_DOMAIN` | Internal unified access secondary domain name of the enterprise | Configure the frontend access address, adapting to unified usage entries for departments including smelting, scheduling, and laboratory testing |

## Three Common Configuration Mistakes
- A POST /api/admin/initv4818 404 error is returned when running the upgrade trigger script. This occurs if `PG_URL` or `FE_DOMAIN` is not configured correctly, causing dependent services for the initialization interface to fail to start, or if the upgrade package deployment path is misconfigured.
- Initial login credentials cannot be retrieved after deployment. This occurs if `ROOT_KEY` is not generated correctly, preventing the initialization process from creating default administrator credentials, or if the credential storage path is misconfigured.
- A deployment exception occurs when connecting a speech recognition tool to process laboratory speech records. This occurs if related access parameters are not configured correctly, or if audio format and sampling rate requirements for the smelting scenario are not met.

## How to Verify Correct Configuration
- Run a database connection test command to confirm that the connection count set in `DB_MAX_LINK` can successfully establish multi-data-source connections, verifying database link functionality.
- Upload a simulated electrolyzer status record file. Check that it can be stored and read normally through the storage service configured via `STORAGE_S3_ENDPOINT`, confirming the storage link is working.
- Access the address set in `FE_DOMAIN`, and attempt to log in using the initialized administrator credentials. Verify that the frontend access entry and permission configuration are working correctly.
- Trigger a real-time cell voltage data synchronization task. Check that the cache service configured via `REDIS_URL` can properly cache data, confirming the real-time data link is functional.

The values provided are common starting points and should be measured against the reader's own samples.
