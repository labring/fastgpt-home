# Supplier and Process Quality Audit for Apparel Cutting and Sewing: Document Parsing and Chunking

## What the Data for This Category Looks Like
Typical entities in this category are apparel OEM/ODM businesses, brand supply chains, and cutting and sewing workshops. Daily generated documents include process sheets, layout plans, cutting orders, first sample seals, process quality forms, packaging and size matching sheets, and similar items. Data sources include orders and size charts, CAD patterns, material and accessory inspection records, hanging system data, needle detector results, and customer sample seals. Update frequency is adjusted per order, per style, or per batch. Document fields include cut piece dimensions, color batch numbers, process requirements, packaging ratios, and others. Units include centimeters, piece counts, yardages, and similar units. Most document structures have fixed headers and detailed content divided by style or batch.

## Constraints on Document Parsing and Chunking
The high-frequency, small-batch update characteristic of this category requires document parsing and chunking to adapt to the granularity of single-style, single-batch documents, to avoid mixing content across batches. The irreversible nature of cut pieces requires parsing to fully retain key fields such as pattern dimensions, color batch numbers, and packaging ratios, to prevent information loss that leads to subsequent audit deviations. Differences in document formats from multiple sources require parsing logic to support files with varying structures, such as layout plans exported from CAD and process tables exported from hanging systems. The labor-intensive process feature requires chunking to accurately split single-process content from process quality forms, to enable subsequent audit steps to call corresponding information.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Adapts to the length of single-process, single-cut-piece information for this category, avoids splitting key fields |
| `chunkSplitter` | Split by fixed header + paragraph breaks | Matches the structured paragraph structure of process sheets and process quality forms, preserves document logical integrity |
| `customPdfParse` | Enabled | Supports non-standard PDF layout plans exported from CAD, retains text information associated with vector graphics |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | Accommodates collections of layout plans and process sheets for a single style across multiple batches, prevents large file upload failures |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Adapts to the parsing duration of complex CAD pattern PDFs, prevents mid-parsing timeouts for large files |
| `chunkSettingMode` | Manual configuration | Adjusts chunking rules for structured documents in this category, adapts to splitting needs for different document types |

This document applies to FastGPT v4.17.0.

## Three Common Misconfigurations
- Issue: Uploading a process sheet PDF results in parsing failure, with the interface displaying "file parsing timed out". Cause: The `PARSE_FILE_TIMEOUT_SECONDS` parameter was not adjusted, and the parsing duration of large layout plans exported from CAD exceeds the default threshold.
- Issue: Some PDF files fail to identify cut piece dimension fields in layout plans. Cause: `customPdfParse` was not enabled, so non-standard layout PDFs exported from CAD are not supported.
- Issue: After configuring a custom file reading address, the workflow calls the document parsing tool and returns an invalid address error. Cause: The access permissions of the custom address were not verified, and the port of the locally deployed file service was not added to the allowed access list.

## How to Confirm Proper Configuration
- Upload a single-style cutting order PDF, and check if the parsed chunked content includes complete cut piece counts and size information, with no truncated fields.
- Upload a layout plan PDF exported from CAD, and confirm that text of dimension annotations associated with graphics can be extracted after `customPdfParse` is enabled.
- Upload a compressed package of multiple documents within 500 MB, and verify that the upload and parsing process has no timeout errors.
- Adjust `chunkSize` to 1000 characters, and check if single-process content from process quality forms is fully split into individual chunks.

The values provided are common starting points, and should be evaluated against the reader's own samples.
