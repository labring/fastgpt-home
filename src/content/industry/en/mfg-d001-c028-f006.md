# Supplier and Process Quality Audit for Incoming Material Inspection and Supplier Quality: Source Citation and Traceability

## What the data for this category looks like
The core data for this category comes from daily business documents and external supplier resources of manufacturing enterprise IQC, SQE, procurement quality, and supplier engineering departments. Daily documents include inspection specifications, sampling plans, incoming material reports, supplier audit reports, exception contact sheets, 8D reports, and concession acceptance approval forms. Fields cover batch numbers, version numbers, inspection items, non-conformity judgments, rectification records, and more. Data sources include purchase orders, drawing specifications, supplier quality certificates, inspection equipment records, historical quality data, and supplier portals. Update frequencies adjust with each incoming material batch, monthly or quarterly evaluations, and irregular audits. Most document formats are PDF, Excel, and structured forms.

## What constraints these characteristics impose on the "source citation and traceability" link
Data sources are scattered across internal business systems and external supplier portals. Cross-source matching rules must be configured to ensure cited documents come from the correct supplier. High-frequency updates require the traceability link to retrieve the latest batch documents in real time, avoiding expired versions. Documents include batch and version fields, so precise matching with the current incoming material’s corresponding information is needed to prevent citing mismatched inspection specifications. Audit errors can lead to batch production failures, so citation scope and quantity limits must be set to reduce irrelevant information interference.

## How to set configurations
| Configuration Item | Recommended Value | Rationale for This Setting |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | The valid content of a single incoming material inspection-related document mostly falls within this range, which can fully cover core inspection rules and judgment basis |
| `responseData` | Format containing original document links | Matches the business need to jump to the supplier portal to view original quality certificates and audit reports |
| `detail` | Display document batch and version fields | Facilitates quick verification of the match between documents and the current incoming material batch and specification version |
| Single search limit | Top 5 entries | Aligns with the sampling logic for supplier quality audits, limiting retrieved entries to reduce irrelevant document interference |
| Context window limit | Calibrated based on actual measurements | Adapts to system resources and LLM context requirements for batch retrieval of multi-source documents |

## Three common mistakes
- Retrieved document count does not meet sampling requirements, with result count differing from the set value. The cause is failure to configure the single search limit parameter, or the set value not matching the sample size rules of the sampling plan.
- The AI response does not display original document links, only local knowledge base summaries. The cause is failing to configure the `responseData` parameter to a format containing original links, only returning locally stored content.
- Expired version inspection specifications are cited, leading to incorrect audit judgments. The cause is failing to enable the version field matching logic of the `detail` parameter, and not filtering invalid documents.

## How to confirm the configuration is correct
This verification process is based on FastGPT v4.17.0.
- Upload an incoming material inspection report with clear batch numbers and version numbers, initiate a quality audit-related query, and check whether the batch and version fields of the document are displayed in the returned results.
- Initiate a test query, and check whether the AI response includes links to original documents on the supplier portal.
- Set the single search limit to Top 5 entries, initiate a query, and check that the number of cited documents returned does not exceed 5.
- Upload an inspection specification marked as an expired version, initiate a query, and check that this document is not retrieved or is clearly marked as an expired version.

The values provided are common starting points and should be measured against the reader's own samples.
