# Supplier and Process Quality Audit for Rubber Mixing and Product Vulcanization: Citation Sources and Traceability

## What This Category’s Data Looks Like
Data for this category comes primarily from formulation systems, raw material batch ledgers, internal mixers, Mooney viscometers, rheometers, vulcanizers, and laboratory testing equipment.
Daily documents include formulation sheets, weighing records, mixing curves, rubber compound quick test reports, vulcanization process cards, mold usage records, and finished product performance reports.
Each document is bound to a unique batch identifier.
Update frequency aligns with each raw material batch, each batch of rubber compound mixing, and each vulcanization operation.
Data fields include feeding ratio, mixing temperature, duration, vulcanization pressure, temperature curves, and more.
Units include degrees Celsius, minutes, megapascals, and other standard industrial units.

## Constraints on Citation and Traceability
The batch binding, high-frequency updates, and multi-source data characteristics of this category impose multiple constraints on citation traceability.
First, each batch of data must be accurately linked to a unique identifier to avoid cross-batch confusion, and ensure traceability results point to the correct mixing and vulcanization stages.
Second, multi-source heterogeneous documents such as curve, table, and text types must use a unified citation format to ensure different types of process records can be correctly traced.
Third, real-time data with high update frequency requires the traceability system to support fast loading of the latest batch documents, while retaining the tamper-proof nature of original records to match production quality control requirements.
Fourth, the high severity of errors requires traceability results to be fully traceable, ensuring original data sources can be quickly located during audits.

## How to Configure Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Maximum Context Token Count | 8000–12000 token | Adapts to batch citation needs for multiple documents such as mixing curves and process cards |
| Return Citation Data Toggle | Enabled | Ensures the system loads and displays original production documents stored in the local knowledge base |
| `detail` | Display full content of original documents | Meets full-field traceability requirements for process quality audits |
| Single Recall Result Count | Top 6 entries | Covers records from multiple stages including mixing, vulcanization, and testing under a single batch |
| `quoteMaxToken` | 1500 token | Limits the length of a single cited content to avoid context overflow |
| `responseData` | Return complete metadata and original content | Used for compliance scenarios requiring strict traceability |
| Reranking Configuration | Sort by match score in descending order | Prioritizes process records most relevant to the current audit query |

## Three Common Configuration Errors
- Issue: Responses do not include production document content from the local knowledge base, only display generic replies. The citation list shows correctly but the main text has no corresponding content. Cause: The return citation data toggle is not enabled, so the system does not load locally stored documents such as formulation sheets and mixing curves.
- Issue: Traceability results only display partial fields, making it impossible to view complete feeding ratios or vulcanization parameters. Cause: The `detail` configuration is set to display only basic fields, and full content display is not enabled.
- Issue: Recall results are sorted randomly, with irrelevant old batch records displayed first. Cause: The reranking configuration sorted by match score in descending order is not enabled, so recall results are not sorted by relevance.

## How to Verify Proper Configuration
- An audit request for a specific batch of rubber mixing is submitted, and the response is checked for associated original document citation identifiers or links.
- The detailed content of each citation is reviewed, and complete fields such as feeding ratios on formulation sheets and temperature curves on mixing curves are confirmed to be included.
- The number of single recall results is verified to match the set top 6 entries, and results are confirmed to be sorted from highest to lowest match score.
- A query of excessive length is tested, and the `quoteMaxToken` limit is confirmed to be active, with single cited content confirmed not to exceed the set 1500 token length.
- All the above verification actions are completed using the FastGPT v4.17.0 platform to confirm configuration takes effect.

The values provided are common starting points and should be measured against local operational samples.
