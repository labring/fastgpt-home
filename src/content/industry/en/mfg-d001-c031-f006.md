# Supplier and Process Quality Audit for Cement Clinker and Grinding: Citation Sources and Traceability

## What this category of data covers
This category of data covers the entire production process of cement clinker and grinding. Data sources include online composition analysis equipment, DCS control systems, laboratory testing systems, kiln and grinding operation equipment, raw fuel ledgers, and energy metering devices. Document types include raw material batching plans, kiln operation logs, laboratory reports, quality control notices, equipment inspection records, and energy reports.
Data update frequencies are divided into real-time (e.g., kiln temperature, composition data), shift-based (e.g., equipment inspection records), and daily (e.g., quality control notices). Fields include raw fuel composition parameters, equipment operation parameters, and quality inspection indicators. Units include kilograms, megajoules, micrometers, cubic meters per hour, and others.

## Constraints for Citation Sources and Traceability
Multi-source heterogeneous data with significantly different update cycles requires the traceability link to accurately distinguish collection times and update periods of different data sources. It also requires avoiding mixing real-time operation data with delayed daily reports.
Diverse professional document types and segmented fields require matching the business dimensions of corresponding documents during traceability. For example, associate thermal parameters from kiln operation logs with strength indicators from the same batch of laboratory reports.
The full-process data chain covers from raw fuel procurement to finished product inspection. Traceability must fully connect data sources across all stages, to avoid broken links that lead to missing audit basis.

## Configuration Settings
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 characters` | Covers core business parameters of a single raw material batching plan or laboratory report, avoids truncating critical content |
| `responseData` | `Return only verified data sources` | Filters temporary data that has not completed synchronization, ensures cited content is in valid state |
| `detail` | `Enabled` | Displays collection time of data sources and source equipment/ledger numbers, meets traceability requirements |
| Citation source matching threshold | `0.75–0.85` | Matches cement production terminology and parameters, avoids incorrectly associating non-corresponding business documents |
| Number of sources recalled per request | `Top 6` | Covers key nodes of the full process from raw fuel procurement to finished product inspection, avoids redundant information interfering with audits |
| Data source timestamp verification | `Calibrated based on actual measurements` | Adapts to different update cycles of real-time, shift-based, and daily data, ensures timeliness of cited data |

## Three Common Misconfigurations
- Issue: Cited sources displayed in the interface cannot be manually hidden or deselected. Cause: `responseData` return rules were not configured correctly, resulting in forced display of non-business data source content.
- Issue: Cited kiln operation logs cannot be associated with corresponding batch laboratory reports, preventing the formation of a complete quality audit traceability chain. Cause: Timestamp matching verification for the `detail` configuration was not enabled, and data sources were not bound by production batch.
- Issue: Cited raw material batching plans are truncated, making complete calcium-iron ratio and batching ratio parameters unavailable. Cause: `quoteMaxToken` value is too low, failing to cover the required character length for core business documents.

## How to Verify Proper Configuration
- Submit an audit request containing a specific production batch, check whether the returned cited content is labeled with data source collection time and source type.
- View the recalled data source list, confirm that only completed and synchronized valid documents are included, with no temporary unupdated records.
- Adjust the `quoteMaxToken` value, verify that core business documents such as raw material batching plans are not truncated.
- Simulate a query for non-target batch parameters, confirm that unrelated equipment operation data is not recalled.

The values provided are common starting points and should be measured against the reader's own samples.
