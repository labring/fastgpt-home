# Supplier and Process Quality Audit for Cement Clinker and Grinding: Knowledge Base Retrieval and Recall

## What the data for this category looks like
This category covers the full cement production workflow. Data sources include online composition analysis systems, DCS distributed control systems, laboratory reports, kiln and mill equipment sensors, raw and fuel ledgers, and energy metering devices.
Data updates follow three schedules:
- Real-time: such as kiln cylinder temperature, online composition data
- Shift-based: such as equipment inspection records
- Daily: such as quality control notices, energy reports
Daily documents consist mostly of structured industrial reports and unstructured operation records. They include fields like clinker free calcium content, mill hourly output, and kiln thermal system parameters, with standard industrial units attached.

## Constraints on Knowledge Base Retrieval and Recall
These characteristics impose specific constraints on the knowledge base retrieval and recall workflow:
Real-time data requires incremental indexing to avoid excessive server resource usage from full scans.
Shift-based and daily updated documents need scheduled full synchronization tasks. This ensures the latest records required for audits are included in the knowledge base.
Industrial documents have wide format variation, including standardized laboratory reports and free-form operation records. Implement multi-type text chunking and vectorization to handle these variations.
Fields include specific industrial units. Match unit-related keywords during retrieval to avoid confusing similar indicators with different parameters.
Content from core audit links, such as rotary kiln thermal systems and batching adjustments, needs prioritized recall. Adjust recall weights and search rules to prioritize this content.

## Configuration Settings
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | Matches the semantic precision of industrial terminology to avoid incorrectly recalling unrelated kiln and mill data |
| `limit` | Top 6 entries | Adapts to the total volume of shift-generated operation records, controlling context length to stay within model limits |
| `searchMode` | `mixedRecall` | Balances exact keyword matching for raw material batching plans and semantic matching for DCS data |
| `usingReRank` | Enabled | Corrects bias from single vector recall, prioritizing content related to rotary kiln thermal systems |
| `datasetSearchUsingExtensionQuery` | Enabled | Supplements context related to raw and fuel fluctuations, improving recall accuracy in batching adjustment scenarios |
| `collectionIds` | Exclusive dataset for cement clinker and grinding | Isolates knowledge base data from other categories to prevent recall of unrelated content |

## Three Common Misconfigurations
- An error occurs when uploading a 3MB PDF laboratory report, with a file parsing failure message displayed in the interface. The cause is failure to adjust chunking rules for multi-page table content in industrial PDFs, resulting in single chunk text length exceeding the system default limit.
- The knowledge base remains in the indexing state with no progress updates in a Docker deployment environment. The cause is failure to configure an incremental index trigger mechanism, performing full indexing on real-time generated laboratory reports and causing excessive server resource usage.
- No English equipment inspection documents in the knowledge base are recalled after entering a Chinese query. The cause is failure to enable cross-language retrieval configuration, only matching Chinese keywords and failing to recognize English text content.

## How to Confirm the Configuration Is Properly Applied
- Upload a raw material batching plan PDF, wait for indexing to complete, then check if the file appears in the knowledge base file list to confirm the indexing process is working normally.
- Enter the query "Adjust raw material batching to respond to raw and fuel fluctuations" and check if the recall results include relevant documents such as raw material batching plans and kiln operation records.
- View the similarity scores of retrieval results, confirm the scores fall within the preset `similarity` threshold range to verify that the configuration is active.
- Test entering the English keyword "clinker free calcium" and confirm if English laboratory report content in the knowledge base can be recalled.
- Test entering a query, confirm that the returned content strictly matches the original knowledge base text with no additional edits or formatting.
