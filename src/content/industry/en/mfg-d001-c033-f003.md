# Supplier and Process Quality Audit for High-Volume Automotive Component Manufacturing: Multi-Turn Dialogue and Prompt Engineering

## What this category of data looks like
Data for supplier and process quality audits in high-volume automotive component manufacturing comes from customer drawings, special characteristic lists, ERP/MES systems, measuring tools, equipment process parameters, and supplier quality certificates. Data is collected continuously per batch and shift. Daily documents include control plans, process flowcharts, work instructions, first-piece and patrol inspection records, SPC reports, PPAP materials, and 8D reports. Data fields include customer special characteristics, process parameters, batch numbers, quality inspection results, and more. Units include millimeters, newton-meters, batch numbers, and other professional industrial measurement standards.

## What constraints these characteristics impose on multi-turn dialogue and prompt engineering
The high-frequency batch-based data update requirement means multi-turn dialogue must strictly link to exclusive data for the current audit batch, to prevent cross-batch information from interfering with audit logic.
The presence of multiple types of professional documents means prompts must clearly specify document types and field formats, to avoid confusion between SPC reports and PPAP materials for different processes.
The strict quality constraints imposed by vehicle customers means dialogue must strictly follow transfer rules for customer special characteristics, and cannot arbitrarily modify parameter thresholds or skip compliance processes.
The scale of high-volume data means context management must prune redundant history, only retaining content relevant to the current audit link.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Context window size | 8000–12000 token | The total character count of documents such as control plans and SPC reports for a single batch is relatively high. Sufficient multi-turn dialogue context must be retained, and this range aligns with the processing limit of FastGPT v4.17.0 |
| `variables` binding scope | Only bind process parameters and quality inspection data for the current batch | Avoid cross-batch data interfering with audit logic, and ensure dialogue only links to the current audit object |
| Knowledge base permission control | Divide access scope by supplier and batch | Comply with confidentiality requirements in the automotive parts industry, and restrict unauthorized users from accessing sensitive quality assurance materials |
| `messages` history truncation threshold | Retain the last 3 turns of dialogue and current batch context | Only abnormal and rectification records for the current process need to be linked during multi-turn audits; redundant history will interfere with judgment |
| `chatId` binding rule | Only bind the batch identifier for the current session | Ensure multi-turn dialogue always links to the same audit batch, and avoid session confusion |
| Dialogue record retention period | 365 days | Batch audit records must be retained for vehicle manufacturer traceability and compliance checks |

## Three Common Misconfigurations
- Phenomenon: Dialogue returns quality inspection records that include multiple batches. Cause: Failed to bind the exclusive data scope of the current audit batch via `variables`, leading to retrieval of SPC reports and first-piece records from unrelated batches.
- Phenomenon: Set dialogue record retention periods do not take effect. Cause: Modified a non-platform-native configuration file by mistake, and did not adjust the retention period parameter via the official settings module.
- Phenomenon: Prompts fail to correctly recognize customer special characteristic fields. Cause: Did not clearly specify in the prompt that document sources are control plans and special characteristic lists, leading the model to confuse process parameters with customer requirements.

## How to Verify Proper Configuration
- Launch an audit dialogue for a specific batch, and confirm the returned quality inspection records only include first-piece and patrol inspection data for that batch.
- Switch to an account for an unauthorized supplier, and confirm that PPAP materials and quality assurance documents for that supplier cannot be accessed.
- View the platform's dialogue record management module, and confirm the retention period for the current dialogue matches the preset requirement.
- Test continuous multi-turn dialogue, and confirm each round of context only retains the last 3 turns of dialogue content and relevant documents for the current batch.
