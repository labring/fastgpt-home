# Supplier and Process Quality Audit for High-Volume Automotive Parts Manufacturing: Tool Calling and Plugins

## What the data for this category looks like
Data sources for this category include customer drawings, special characteristic lists, ERP/MES systems, measurement and inspection tool collection data, equipment process parameters, and supplier quality certificates. Daily generated documents include control plans, process flowcharts, work instructions, first article and patrol inspection records, SPC reports, PPAP materials, and 8D reports. Each document contains dedicated fields such as part number, process parameters, inspection values, and batch number. Data update frequency aligns with each batch of material going into production, shift-by-shift process patrols, and continuous collection of equipment parameters. The data volume per batch increases with process nodes.

## What constraints these characteristics impose on tool calling and plugins
Multi-source heterogeneous data sources require tool calling to support interfaces for different systems, and adapt to multiple document formats such as drawings, reports, and patrol inspection records. Frequently updated batch data requires tool calling to support near-real-time queries, to avoid audit deviations caused by data lag. Business rules constrained by vehicle customers require tool calling to strictly pass core fields such as batch numbers and special characteristics, ensuring audit results comply with customer quality system requirements. Cross-document association query needs for multiple document types require plugins to support cross-document field matching, enabling linked calling of control plans and SPC reports.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Workflow/API tool selection | Auto-select | Adapts to calling requirements for multiple types of audit documents; FastGPT v4.17.0 supports dynamic matching of corresponding tools with this parameter |
| Workflow/API function-call configuration | Enabled | Used to pass workflow global variable tokens to MCP tools, meeting cross-stage parameter transfer requirements |
| Context window size | 8000–12000 tokens | Adapts to multi-batch data association queries for high-volume manufacturing, calibrated via actual testing |
| Tool call timeout | 120 seconds | Matches the typical time required for measurement and inspection tool data collection and SPC report generation |
| Knowledge base recall limit | Top 8 entries | Covers retrieval requirements for multiple types of documents including control plans and PPAP materials |
| Single tool call data limit | 500 MB | Adapts to large document reading requirements for high-volume manufacturing |

## Three common errors
- No context association in results returned when calling the FastGPT application API. The cause is incorrect configuration of the context window parameter, and failure to retain historical data association for cross-batch audits.
- MCP tools cannot obtain workflow global variable tokens. The cause is that the `functionCall` parameter is not enabled, and global variable transfer configuration is not turned on.
- No relevant content returned for associated knowledge base queries. The cause is that the application and knowledge base belong to different teams, cross-team knowledge base access permissions are not configured, and special characteristic fields of parts documents are not matched.

## How to confirm the configuration is correct
- Initiate a query call for supplier quality certificates, check whether the returned results include associated control plan and SPC report data.
- Trigger an MCP tool call in the workflow, check whether the tool's input parameters carry the preset global variable token.
- Simulate a single-batch non-conformance scenario, call the tool to generate an 8D report, check whether it is associated with the first article patrol inspection records of the corresponding batch.
- View the API return logs, confirm that the context parameters have been correctly transferred and no fields are missing.

The values listed above are common starting points, and should be evaluated against the reader's own samples.
