# Supplier and Process Quality Audit for Heat Treatment: Citation Sources and Traceability

## Data Profile for This Category
Data for this category originates from material grades, customer technical specifications, temperature control instruments, furnace temperature uniformity testing equipment, hardness testers and metallographic equipment, and manufacturing execution systems (MES). Daily outputs include heat treatment process cards, charging charts, furnace temperature curves, hardness and metallographic reports, equipment inspection forms, and exception handling documents. Data is updated per furnace load and batch. Fields include furnace temperature range, holding duration, hardness value, metallographic structure rating, and similar metrics, with clear unit markers. For example, temperature uses degrees Celsius, duration uses minutes or hours. Single record size is moderate, but batch correlation is strong.

## Constraints on Citation and Traceability
The high timeliness, multiple document types, and precise field requirements of this category’s data create multiple constraints for the citation and traceability process. Unique data for each furnace load must be tied to a unique furnace batch number to prevent cross-batch data confusion. Multiple document types—including non-text datasets such as charging charts and furnace temperature curves—require the traceability system to identify and associate these datasets. Fields with clear units must match unit information during retrieval to avoid incorrect citation of irrelevant data. Additionally, process audits require tracing the associated workflows of exception handling documents. The traceability chain must cover the full cycle from process formulation to exception handling, ensuring completeness of audit basis.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum context token count | 8000–12000 token | Adapts to the total character count of full data for a single furnace load, avoiding truncation of critical process parameters and furnace temperature curves |
| `quoteMaxToken` | 1500–2000 token | Limits the return length of a single citation, adapting to the single-segment data length of hardness reports and metallographic analysis results |
| Citation detail display | Enabled | Ensures returned citations include complete fields and unit information, such as furnace temperature 1250℃, hardness HRC35 |
| `responseData` | Includes all types such as process cards, charging charts, and exception handling documents | Covers multiple data source types, avoiding recall of only text datasets |
| `detail` | Calibrated based on actual measurements | Controls the expansion level of cited content, matching the granularity of specific links that need verification during process audits |
| Single recall limit | Top 8 entries | Matches the conventional number of documents related to a single furnace load, avoiding redundant citations that interfere with audit judgments |

## Three Common Errors
- Phenomenon: Returned citations only include text documents, and do not associate non-text data such as charging charts and furnace temperature curves. Cause: `responseData` is not configured to cover all data source types, and only text dataset recall is enabled by default.
- Phenomenon: Cited content does not match actual data in the professional knowledge base, or does not hit expected furnace load data. Cause: A reasonable range for `quoteMaxToken` is not defined, leading to truncation of critical parameters or introduction of irrelevant batch data.
- Phenomenon: After calling the API and passing in the knowledge base, the corresponding heat treatment data cannot be associated. Cause: The knowledge base ID is not passed as a workflow input parameter, so the workflow cannot locate the specified data source.

## How to Verify Proper Configuration
- Upload a single furnace load’s heat treatment process card, furnace temperature curve, and hardness report, initiate an audit-related query, and check if the returned citation list includes all uploaded document types.
- View the expanded content of a single citation, confirm that it includes complete fields and unit information, such as holding duration and specific hardness value parameters.
- Call the API and pass in the specified knowledge base ID, check if the workflow correctly recalls heat treatment data for the corresponding batch, with no empty citations or incorrect associations.
- View system logs, confirm that the configured `quoteMaxToken` value does not cause excessive truncation of cited content, and complies with the parameter rules of FastGPT v4.17.0.

The values provided are common starting points and should be measured against the reader's own samples.
