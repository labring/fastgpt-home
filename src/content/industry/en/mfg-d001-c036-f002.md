# Supplier and Process Quality Audit for Welded Structural Component Manufacturing: Vector Models and Indexes

## What Data Looks Like for This Category
This category’s data originates from design drawings, material quality certificates, welding equipment parameters, filler metal inventory, non-destructive testing systems, and personnel qualification ledgers. Daily documents include welding procedure qualifications, welding procedure specifications, filler metal issue records, welder qualification records, weld inspection reports, and repair orders. Data updates follow a rhythm of per weld, per batch, or per shift. Single documents mostly contain clear structured fields such as process parameters, qualification numbers, and test results. Some drawing documents include structured dimensions and welding position information.

## Constraints Imposed on Vector Models and Indexes
This category’s data updates frequently. Indexes must support incremental synchronization to avoid excessive full reconstruction time. Multiple document types have distinct fields: numeric process parameters, qualification number fields, and text test report fields. Indexes must adapt to mixed-format data. Single weld-related data entries are small but update often. Control chunking granularity to match the information boundaries of a single weld. Some source data includes unstructured drawing fragments. Configure additional index rules adapted to images or structured drawings. Ensure vector retrieval accuracy for key fields such as qualification numbers and filler metal batch numbers to support rapid verification.

## Configuration Settings
This configuration is based on FastGPT v4.17.0. Specific parameters are as follows:

| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| Chunk Length | 800–1200 characters | Matches the typical paragraph length of a single welding procedure document, avoiding cutting that disrupts the integrity of process parameters |
| Overlap Length | 100–200 characters | Covers key conclusion descriptions across chunks in weld inspection reports, preventing loss of context during retrieval |
| `defaultToken` | 4096 | Adapts to the default token limit of most external APIs, meeting the requirement for complete content input of welding procedure qualification documents |
| `maxToken` | 8192 | Covers long documents containing descriptions of multiple weld drawings, avoiding content truncation |
| Similarity Threshold | 0.75–0.85 | Distinguishes qualified and unqualified results for filler metal qualification matching, reducing false positive rates |
| Single Search Limit | Top 10 entries | Matches the number of reference documents that need to be quickly retrieved during shift-level audits |

## Three Common Misconfigurations
- Phenomenon: When deploying a PG database via Docker, knowledge base index establishment always fails, with the host being an 8-core 16G virtual machine without a GPU. Cause: No chunking rules adapted to structured filler metal issue records were configured, and the default index shard size exceeded the memory allocation threshold of the virtual machine.
- Phenomenon: When connecting external vector and language APIs, arm-based soft routers experience lag or timeouts. Cause: Local model loading was not disabled, and only hardware resources of the external API were relied on, but no reasonable `defaultToken` upper limit was configured, resulting in excessive data volume per request.
- Phenomenon: After importing Excel and multi-dimensional documents from a Feishu folder, retrieval results are empty. Cause: The parsing switch for the corresponding file formats was not enabled, and the chunk length was not adjusted to adapt to the cell field structure of Excel tables.

## How to Confirm Configuration Is Complete
- Upload a single filler metal issue record document, trigger index establishment, check that the index status shows completed, and retrieve the filler metal batch number of the document to return matching results.
- After configuring the external API, initiate a small-scale retrieval request, confirm that the response duration meets expectations, and no connection timeout errors occur.
- Import multiple types of documents, including welding procedure specifications and weld inspection reports, retrieve welder qualification numbers, and confirm that the returned results include complete records of the corresponding qualifications.
- Check the memory usage of index shards, confirm that it does not exceed the reasonable proportion of allocatable memory of the host, and no memory overflow-related errors occur.

The values provided here are common starting points and should be measured against the reader's own samples.
