# Supplier and Process Quality Audit for Welded Structural Component Manufacturing: Citation Sources and Traceability

## Data Profile for This Category
Business data sources for welded structural component manufacturing include design drawings, material quality certificates, welding equipment parameters, filler metal inventory ledgers, non-destructive testing systems, and personnel qualification ledgers. Data is updated per weld seam, per batch of filler metal, or per shift. Daily generated documents include welding procedure qualifications, welding procedure specifications, filler metal usage records, welder qualification records, weld inspection reports, and repair orders. Covered fields include weld number, filler metal batch number, welder qualification number, non-destructive testing results, and other relevant fields.

## Constraints on Citation and Traceability
This category’s data characteristics impose multiple constraints on the citation and traceability process. First, data is updated per weld seam, per filler metal batch, or per shift. It is necessary to accurately match associated document content for the corresponding production batch, to avoid cross-batch citation of irrelevant content. Second, daily documents cover three categories: process, qualification, and inspection. It is necessary to filter and recall by document type, to ensure only content relevant to the current audit item is called, such as welding procedure qualifications and welder qualification records. In addition, quality audits rely on rigid fields such as welder qualifications and filler metal batch numbers. The traceability process must accurately extract corresponding fields from original documents, to provide clear basis for subsequent verification.

## Configuration Settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Single Search Limit | Top 6–10 results | Associated documents for a single batch of welded structural components typically do not exceed 8 categories. Recalling 6 to 10 results covers all core audit content |
| `quoteMaxToken` | 1000–1600 token | Total length of audit-related content for a single weld seam is typically under 800 tokens. A reasonable buffer is reserved to avoid truncation of critical information |
| `responseData` | Enabled | Original document fields such as weld number, filler metal batch number, and welder qualification number must be returned for precise traceability |
| `detail` | Full | Complete content fragments of original documents must be retained, to facilitate verification of non-destructive testing results and welding process parameters |
| Reranking | Enabled | Recall results are sorted by relevance, to ensure the most relevant welding procedure qualifications and weld inspection reports are displayed first |
| Maximum Context | Calibrated via actual testing | Combined with the single search limit and `quoteMaxToken` values, to adapt to the context limits of the model in use |

## Three Common Misconfigurations
- Scenario: After setting `quoteMaxToken` to 2000, the generated answer content exceeds 3000 tokens. Cause: Associated documents for welded structural components have long individual lengths, and the number of recalled documents is excessive. The accumulated total token count exceeds the model’s context limit, leading to truncated answers or token limit exceeded errors.
- Scenario: The prompt for referencing the knowledge base remains in Chinese, and no compliant English audit report can be generated. Cause: The Chinese instructions in the system prompt have not been replaced with English expressions adapted to the scenario, and the prompt format has not been adjusted for welding terminology.
- Scenario: The generated audit answer does not cite the top-ranked weld inspection report in the knowledge base. Cause: The reranking configuration is not enabled, the single search limit is set too low, causing core documents to be excluded from the recall range, or the similarity threshold is set too strict, filtering out highly relevant content.

## How to Verify Successful Configuration
- Review the citation source module of the generated answer, confirm that it includes corresponding fields such as weld number and filler metal batch number, and that the fields match the current audit production batch.
- Check the token consumption of the answer, confirm that it does not exceed the context limit of the current model, and that the `quoteMaxToken` value is adapted to the current content length.
- Verify the types of recalled documents, confirm that only target documents relevant to the current audit item are included, such as welding procedure qualifications and welder qualification records.
- Compare the sorting order of recalled results, confirm that the most relevant audit documents are displayed first, in line with business priority requirements.

The values provided are common starting points and should be measured against the reader's own samples.
