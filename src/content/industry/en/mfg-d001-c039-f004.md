# Supplier and Process Quality Audit for Electric Motor and Generator Manufacturing: Workflow Orchestration

## What the Data for This Category Looks Like
Business data sources for electric motor and generator manufacturing include electromagnetic design data, batch records for copper wire and insulating materials, output data from winding equipment, balancing machines, and electrical test benches, plus batch information from ERP/MES systems. Data update frequency is once per electric motor or production batch, with synchronized updates each time a type revision is made. Core daily documents include winding process cards, insulation treatment records, dynamic balancing reports, voltage withstand insulation test reports, and type and factory test reports. Fields covered include winding turns, insulation thickness, dynamic balancing value, withstand test voltage, temperature rise data, and more.

## What Constraints These Characteristics Impose on the "Workflow Orchestration" Link
Multi-source heterogeneous data sources require the workflow to be configured with multiple nodes connected to different devices and systems, to avoid reliance on a single data source. The batch-based update characteristic requires the workflow trigger logic to be bound to batch upload or device data synchronization events. The fields in core documents are highly specialized, so the workflow's `variables` must be accurately bound to the corresponding business fields; otherwise, verification and analysis cannot be completed. The special verification requirements for high-voltage and temperature rise tests require the workflow to add independent anomaly judgment nodes to adapt to the unique quality control links of this category.

## How to Set Up the Configuration
This guide applies to FastGPT v4.17.0. Below are workflow configuration recommendations for the electric motor and generator manufacturing scenario:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Trigger Mode | Triggered upon completion of batch upload or device data synchronization | Matches the business rhythm of updates per unit or per batch |
| `variables` Binding | Bind winding turns, insulation thickness, dynamic balancing value, withstand test value | Covers required fields from core business documents |
| Timeout Setting | 600 seconds | Adapts to the time required for multi-node data processing and test report parsing |
| Node Verification Rules | Perform non-null and format verification on test nodes marked with `nodeId` | Prevents abnormal data from entering subsequent analysis links |
| Retry Count | 2 times | Addresses occasional transmission jitter in device data |
| File Upload Limit | 1000 MB | Adapts to the text size of complete test reports for a single batch |

## Three Common Errors
- Symptom: Workflow node icons fail to display normally, and blank placeholders appear on the interface. Cause: The `variables` are not correctly bound to the core fields in winding process cards and test reports, resulting in missing parameters required for node rendering.
- Symptom: Offset 17 parsing errors pop up during workflow runtime. Cause: No format verification is performed on numeric `variables` such as winding turns and withstand test values, and non-numeric characters are mixed in, causing text parsing offset.
- Symptom: A network error is prompted when uploading a TXT document of insulation treatment records, or the workflow automatically interrupts after running for more than 2 minutes. Cause: The timeout setting and file upload limit are not adjusted, and the default parameters cannot adapt to the transmission and processing requirements of single-batch test reports.

## How to Confirm the Configuration Is Complete
- Import the winding process card and test report for a single electric motor, and check whether the fields bound to `variables` are automatically populated with corresponding content.
- Trigger a single workflow execution, and check the node logs to confirm that no offset-related parsing errors occur.
- Modify the timeout setting to above 600 seconds, execute a workflow that includes a complete test process, and confirm that the running duration meets the requirements.
- Upload a single TXT document of insulation treatment records, and confirm that the file can be uploaded normally and trigger the workflow.

The values given are common starting points and should be measured against the reader's own samples.
