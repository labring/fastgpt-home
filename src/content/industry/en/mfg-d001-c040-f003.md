# Supplier and Process Quality Audit for Battery PACK and Energy Storage System Integration: Multi-turn Dialogue and Prompt Engineering

## What the Data for This Category Looks Like
The core data sources for this category include cell capacity grading data, MES systems, welding equipment, torque tools, BMS software version records, and EOL test bench test data.
Daily audit documents include grouping rules, BOM lists, welding and torque records, BMS flashing records, insulation and voltage withstand reports, EOL test reports, and system configuration lists.
Data updates occur once per generated PACK or energy storage cabinet, with synchronized updates each time the BMS software version changes.
Document fields include cell capacity, internal resistance, welding torque value, insulation and voltage withstand value, BMS version number, and others. Some fields have clear units: torque is measured in newton meters, and voltage is measured in volts.

## How These Characteristics Impact Multi-turn Dialogue and Prompt Engineering
Data is bound to individual devices. Multi-turn dialogue must isolate context for different batches using unique identifiers to prevent data confusion.
Document types are diverse and filled with specialized terminology. Prompts must explicitly specify retrieval of specific documents such as grouping rules and test reports, while adapting to industry terms including BMS and EOL.
Data updates occur frequently. Dialogue nodes must support regular refreshing of associated data sources to ensure audits use the latest BMS versions and test records.
Key parameters such as insulation and voltage withstand values are directly linked to safety risks. Dialogue must extract and verify these fields to maintain accurate audit logic.

## Configuration Guidelines
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Maximum Context | 8000–10000 characters | Matches the total length of documents related to individual PACK audits |
| Number of Retained Historical Messages | First 15 | Covers the multi-turn interaction flow for a single audit |
| `variables` Binding Rule | Bind the BOM ID and cell batch number of the individual device | Ensures dialogue is linked to exclusive audit data for the corresponding batch |
| `chatId` Binding Strategy | Generate a unique ID per PACK/energy storage cabinet | Isolates audit context for different batches to avoid data cross-talk |
| `messages` Format | Concatenate in "User Question - System Response" order | Complies with FastGPT multi-turn dialogue context parsing standards |
| Question Optimization Switch | Enabled | Adapts to semantic correction of industry specialized terminology to improve audit accuracy |

## Three Common Misconfigurations
- Symptom: Attaching files in a local development environment generates summary analysis, but after deploying via image packaging, uploaded attachments cannot be recognized and no error is displayed. Cause: The attachment storage directory was not correctly mounted during image deployment, causing the retrieval node to fail to read uploaded document files.
- Symptom: The AI node following the pre-judgment module in a multi-turn dialogue chain cannot obtain the initial user question content. Cause: The field for the initial user question was not bound via `variables` in the orchestration workflow, resulting in lost context.
- Symptom: Uploaded cell test report images cannot be displayed in the dialogue interface. Cause: The image parsing configuration for the dialogue node was not enabled, or the access path for image storage was not specified.

## How to Verify Correct Configuration
- Upload the system configuration list and EOL test report for a single energy storage cabinet, trigger a multi-turn dialogue, and check if the dialogue context is bound to the exclusive identifier of this device.
- Simulate multi-round audit questions, check if previously mentioned torque values and insulation parameters are correctly referenced in subsequent dialogues to verify the context retention logic.
- Verify that in the image deployment environment, uploading attachments allows the dialogue to generate analysis content normally without abnormal errors.
- View the dialogue log to confirm that the BOM ID and cell batch number bound in `variables` match the information in the uploaded documents.

The values provided are common starting points and should be measured against the reader's own samples.
