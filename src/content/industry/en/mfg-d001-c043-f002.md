# Supplier and Process Quality Audit for Batch Synthesis in Specialty Chemicals: Vector Models and Indexing

## What the Data for This Category Looks Like
The primary entities in this category are enterprises engaged in coatings, resins, additives, agrochemical intermediates, and specialty chemicals. Daily documentation includes batch production instructions, feeding verification sheets, reaction process records, cleaning records, test reports, deviation and change orders. Data sources include formula and process libraries, raw material batch information, reactor DCS data, weighing system records, LIMS systems, and warehouse management systems. Data is updated per batch production or each critical step, with characteristics of switching between multiple products and batches. Formula and process data requires strict confidentiality, and cleaning confirmation records are one of the core audit bases.

## How Category Characteristics Impact Vector Models and Indexing
High-frequency updated data across multiple batches requires indexes to support incremental triggering, to avoid excessive resource consumption from full reindexing. The mix of multiple products and document types requires chunking rules tailored to the field structure of different documents. For example, structured fields on feeding verification sheets and time-series data from DCS systems require different chunking logic. The need to protect formula confidentiality requires permission isolation configured for vector storage, to prevent sensitive data leaks. The strong correlation between reaction process records and cleaning records requires vector indexes to retain context association information, to avoid splitting batch processes during retrieval.

## Three Common Configuration Errors
- Index construction gets stuck on the final batch of data and fails to complete full index generation. This occurs when incremental index triggering rules are not configured for batch-updated data sources, leading to full reindexing taking longer than expected.
- Mixed retrieval response time exceeds 10 seconds, and the number of single retrieval results is abnormal. This happens when unnecessary recall sources are not disabled, or the single search limit is not configured, causing the retrieval scope to cover too much irrelevant data.
- Some proprietary documents fail to be vectorized, such as encrypted PDFs exported from LIMS or structured Excel files with batch numbers. This is caused by not configuring category-specific document parsing rules, leading to parsing failures.
