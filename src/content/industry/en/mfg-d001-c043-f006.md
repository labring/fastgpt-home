# Supplier and Process Quality Audits for Batchwise Fine Chemical Synthesis: Citation Sources and Traceability

## What Data Looks Like for This Category
This category covers paint, resin, additive, agrochemical intermediate, and specialty chemical manufacturers. Daily documents include batch production instructions, batch feeding verification forms, reaction process records, cleaning records, inspection reports, deviation and change orders. Data sources include formula and process libraries, raw material batch records, reactor DCS data, weighing system data, LIMS systems, and warehouse management systems. Update frequency follows each batch production and every key process step. Document fields include unique batch identifiers, feeding quantities (kilograms/liters), reaction temperatures (degrees Celsius), timestamps, and more. Most data exists as structured tables or semi-structured log text.

## What Constraints Do These Characteristics Impose on Citation Sources and Traceability
This category produces multiple products with batch-to-batch switching, and each batch’s data is updated independently. Citation traceability must be bound to a unique batch identifier, and link batch data scattered across formula libraries, DCS, LIMS and other systems to ensure consistency of citation sources. Multi-step process records require traceability to accurately match corresponding document fragments by process nodes, avoiding invalid citations across batches or steps. The presence of deviation and change orders requires citation traceability to link version records before and after changes, ensuring cited content matches the currently valid version. The structured nature of documents requires citation traceability to identify fields and units, preventing citation errors due to mismatched formats.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | Matches the average length of single-batch process documents for this category, ensuring complete citation coverage of key steps including feeding, reaction, and cleaning |
| `responseData` | Only return entries linked to the associated batch and process step | Production data for this category is bound to batches and steps, requiring precise matching of documents for the target batch to avoid cross-batch invalid citations |
| `detail` | Display full document fields and source paths, with a character length not exceeding 500 | Documents for this category include fields such as batch number, feeding quantity, and reaction temperature, requiring clear identification of traced specific fields and source nodes |
| Context recall limit | Top 6 entries | The number of linked documents for key steps in this category is limited; excessive recall will lead to redundant context and reduced traceability accuracy |
| Citation validation switch | Enabled | This category requires strict alignment between cited content and sources, preventing unsubstantiated generated content to meet production compliance requirements |

## Three Common Misconfigurations
- Issue: The interface dropdown menu only supports selecting a single variable, making it impossible to reference documents from multiple feeding batches at the same time. Cause: The default configuration limits the number of variables referenced per round, and does not adapt to the needs of multi-batch, multi-step linked traceability for this category.
- Issue: A `quote type error` error is returned during invocation. Cause: The input reference variable format does not match the field structure of documents for this category, for example, missing required fields such as unique batch identifier or feeding quantity, which does not meet the system's preset reference format requirements.
- Issue: The source address and document type of the knowledge base citation are not displayed in the reply. Cause: The configuration switch for displaying citation sources is not enabled, or the configured `quoteMaxToken` parameter value is too small, resulting in truncation of source information.

## How to Verify Proper Configuration
This verification is based on the functional logic of FastGPT v4.17.0.
- Initiate a quality audit question that includes a specified batch number and process step, and verify that the reply links to documents including batch feeding verification forms and reaction process records for the corresponding batch.
- Check the length of cited content in the reply, confirm that it covers the core information of single-batch process documents and matches the `quoteMaxToken` configuration value.
- Review error logs to confirm that no `quote type error` errors appear, verifying that the reference variable format meets the field requirements of documents for this category.
- Check whether the reply displays traced information such as document batch number and timestamp, confirming the completeness of citation sources.
