# Supplier and Process Quality Audit for Spinning and Weaving: Source Citation and Traceability

## What Data for This Category Looks Like
Core data for this category comes from raw fiber inspection reports, ERP systems, spinning and loom operation logs, evenness testers, fabric inspection machines, and order specification documents. Daily retained documents include cotton blending lists, process setup sheets, equipment operation records, yarn inspection sheets, grey fabric inspection sheets, and defect ledgers. Data updates occur with each batch of incoming raw materials, each shift of equipment operation, and completion of each bolt of fabric. A single data entry corresponds to inspection results for a specific raw material batch, single equipment shift, or single bolt of fabric.

## Constraints Imposed on Source Citation and Traceability
Data for this category is scattered across offline inspection reports, online device logs, and ERP systems. Associative traceability across multi-format data sources must adapt to different storage formats. Data updates align with each raw material batch, equipment shift, and completed fabric bolt. Cited traceability information must match the current audit batch in real time. Daily document structures vary significantly: cotton blending lists focus on fiber indicators, process sheets focus on process parameters, and inspection sheets focus on defect records. Field associations must be precisely matched to audit scenarios. Single data entries have small volume but cover full-process batches. Traceability results must avoid redundancy while covering all link nodes from raw materials to finished products.

## Three Common Configuration Mistakes
- Phenomenon: Knowledge base-attached file links are automatically appended to conversations. Cause: Associated data return configuration was not turned off, or reference display toggle settings were not adjusted.
- Phenomenon: Non-current batch raw material inspection data is mixed into search results. Cause: Batch dimension retrieval filter conditions were not bound, resulting in traceability results covering all historical data.
- Phenomenon: Critical twist parameter values on process setup sheets are truncated in traceability results. Cause: Max citation token count was set too small, not adapted to the character length of a single document.

## How to Verify Proper Configuration
- Initiate a quality audit query for a single grey fabric bolt, verify whether the returned results include the corresponding batch cotton blending list, process setup sheet, and inspection records.
- Check the citation section at the end of the conversation, confirm that only data sources required for the current audit are displayed, with no redundant or irrelevant file links.
- Verify that when querying process parameters, complete details such as twist and weave parameters are returned, with no truncation.
- After adjusting retrieval keywords, confirm that the number of returned results matches the preset single retrieval limit.

The values listed are common starting points and should be measured against the reader's own samples.
