# Supplier and Process Quality Audit for Meat Products and Slaughter Processing: Workflow Orchestration

## What the data for this category looks like
Core data sources for this category include animal quarantine information, supplier batches, production traceability, temperature collection, metal detection, and laboratory testing. Daily retained audit-related documents include quarantine certificates, slaughter and cutting records, ingredient marinating records, thermal processing records, cold chain temperature records, and microbial test reports. Data update cadence follows one quarantine and batch binding per raw material batch, production records uploaded per shift, and cold chain temperature data updated via continuous collection. Data fields include batch number, quarantine number, temperature value (unit: ℃), test results, processing time, and others. Some fields must be bound and associated with supplier qualifications.

## What Constraints These Characteristics Impose on Workflow Orchestration
Business characteristics of this category impose multiple constraints on workflow orchestration. The batch-by-batch and shift-by-shift update cadence requires workflows to bind a unique batch number to trigger, preventing cross-batch data confusion. Real-time requirements for continuous temperature control require configuring real-time collection nodes, with alert branches triggered when timeouts occur. The strong binding between quarantine certificates and raw material batches requires adding association field validation in workflows, ensuring diseased raw materials cannot enter production. Strict controls for raw-cooked zoning and sterilization temperature require setting branch judgment nodes in workflows, implementing differentiated audits for different processing links. High-risk error consequences require configuring failure retries and manual intervention nodes in workflows, ensuring exceptions can be traced.

## Three Common Mistakes
- Node connections appear normal but the status remains stuck in running, with no next-step log output. Cause: No trigger validation for the batch number in `variables` is configured. The workflow cannot match the quarantine certificate data for the current batch, so trigger conditions are not met.
- Fields are empty after assigning values to global variable string arrays. Cause: Standard key-value pair array format is not used for assignment, leading to variable parsing failure.
- Variable results in AI conversation replies include historical content superposition. Cause: The automatic context splicing switch is not turned off, so results from previous conversations are carried over to the current variable.

## How to Verify the Configuration Is Correct
- Manually trigger a test batch workflow. Check that nodes execute in the preset order without stalling.
- Enter a globally variable array in the correct format. Confirm that the workflow can normally read fields such as batch number and quarantine number.
- Simulate an AI conversation reply. Check that the returned variable results only include current session content, with no historical data superposition.
- Configure an export node and trigger it. Confirm that an audit record file for the corresponding batch can be generated.
