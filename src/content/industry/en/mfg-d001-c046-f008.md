# Supplier and Process Quality Audit for Meat Products and Slaughter Processing: Document Parsing and Chunking

## What This Category's Data Looks Like
The main entities in this category are slaughterhouses, cooked meat and frozen prepared food enterprises. Daily documents include quarantine certificates, slaughter and cutting records, ingredient marinating records, thermal processing records, cold chain temperature records, and microbial test reports. Data sources include animal quarantine information, supplier batches, production traceability, temperature collection, metal detection, and laboratory test results. Updates occur once per raw material batch for quarantine certificates, processing records are generated per shift, and cold chain temperature data is updated via continuous collection. Most documents are fixed-format forms or time-series records, with fields including batch number, temperature value (℃), test values, and quarantine number. Some documents include quarantine identification images.

## What Constraints Do These Characteristics Place on the Document Parsing and Chunking Link
The batch association attribute of category data requires that chunks retain complete associated information within a single batch, to avoid breaking the binding relationship between quarantine certificates and their corresponding raw material batches. Time-series cold chain temperature records must not have their continuous temperature sequences truncated during chunking, as this would compromise production traceability integrity. Fixed-format form documents must retain complete fields, and must not split key information such as quarantine numbers and batch numbers. High-frequency bulk document import requirements mean parsing configurations must adapt to small-batch, multi-document upload scenarios, to prevent parsing failures caused by file size or timeout issues.

The following configurations are based on FastGPT v4.17.0, and are adapted to the document characteristics of the meat products and slaughter processing category.

## How to Configure the Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Adapts to the field density of forms and time-series records in this category, avoids splitting core batch-associated information |
| `chunkSplitter` | By paragraph + semantic boundary | Retains content coherence of processing records and temperature control records, avoids truncating time-series data or form fields |
| `customPdfParse` | Enabled | Retains embedded images and fixed table layouts in PDF documents, adapts to form documents with images such as quarantine certificates |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | Adapts to scenarios where multiple documents are packaged and uploaded per batch, avoids parsing failures for large files |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 seconds | Covers the parsing duration of long documents containing multi-page time-series temperature records, avoids timeout interruptions |
| `chunkSettingMode` | Manual configuration | Adjusts chunking parameters separately for different document types, adapts to the diverse document formats in this category |

## Three Common Mistakes
- Exporting a knowledge base from an old server to Excel then importing it to a new server results in scattered or duplicate batch information. This occurs because chunking boundaries are not configured for the category's batch association fields, leading to cross-batch associated data being split or merged.
- After a PDF file with embedded quarantine certificate images is uploaded, the parsed result does not extract the quarantine number from the images. This occurs because the `customPdfParse` configuration is not enabled, and the default parsing mode does not adapt to form documents with embedded images.
- The table dataset option is unavailable on the knowledge base creation page. This occurs because category-specific table parsing adaptation is not enabled, or an incorrect `chunkSettingMode` is configured which disables table recognition.

## How to Confirm Configurations Are Correct
- A single complete quarantine certificate PDF is uploaded. The parsed result is checked to confirm it retains the complete quarantine number and raw material batch number fields, and is not split across different chunks.
- A cold chain temperature record document with multiple consecutive pages is uploaded. The parsed result is checked to confirm it retains the complete temperature data sequence in chronological order, with no content truncation.
- A form document with embedded quarantine identification images is uploaded. The parsed result is checked to confirm it includes the text information associated with the images and the corresponding fields.
- A packaged multi-document file under 500 MB is uploaded. The parsing task is checked to confirm it completes within 300 seconds, with no timeout error prompts.

The values provided are common starting points and should be measured against the reader's own samples.
