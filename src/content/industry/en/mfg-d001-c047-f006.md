# Supplier and Process Quality Audit for Measuring Instruments and Laboratory Management: Citation Sources and Traceability

## What this category of data looks like
This category of data originates from daily work outputs of enterprise metrology rooms and CNAS system laboratories. It includes measuring tool ledgers, calibration plans, calibration certificates, interim check records, original test records, reference material ledgers, and deviation handling documents.
Data sources cover metrology management systems, external calibration institution certificates, LIMS systems, and environmental monitoring equipment.
Update rhythm follows calibration cycles, completion of single tests, or triggers from abnormal events.
Fields include unique instrument number, calibration date, measurement uncertainty, and traceability chain information. Units include calibration cycle (days/months), uncertainty percentage, and certificate number strings, among others.

## What constraints this category imposes on the citation sources and traceability link
The multi-source, decentralized nature of this data requires the traceability link to support cross-system data retrieval. This ensures complete citation of calibration certificates and ledger information.
The non-fixed update rhythm requires configuration to support on-demand incremental synchronization. This avoids invalid data occupying context.
Traceability chain and uncertainty information in fields are core basis for quality judgment. Full fields and original units must be retained during citation.
Incorrect citation will directly lead to failure of quality audit. Invalid citations must be strictly restricted to ensure each traceability entry corresponds to real metrology activity records.

## How to set the configuration
The following configurations are formulated based on the logic of FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 10000–15000 token | Supports complete citation of long texts such as calibration certificates and traceability chains, avoiding truncation of core fields such as measurement uncertainty |
| Maximum number of citations | Top 8 entries | Limits redundant citations, focusing on the latest and valid calibration and test records |
| `responseData` | Include metadata fields | Retains key traceability information such as instrument number, calibration date, and certificate number, supporting quality audits |
| `detail` | Full traceability chain | Displays the complete transfer path from standard instruments to tested products, meeting CNAS system audit requirements |
| Text extraction scope | Only metrology-related fields | Filters non-core equipment operation and maintenance information, focusing on metrology data required for audits |

## Three common mistakes
- Phenomenon: The text extraction component cannot extract metrology structured fields from knowledge base citation content, and no corresponding extraction options exist in optional parameters. Cause: The `responseData` metadata switch is not enabled, causing citation content to retain only text fragments and lose key traceability information such as instrument number and calibration date.
- Phenomenon: The official chat page does not display cited calibration certificates or test records, and content is only visible on the debug page. Cause: The citation document display switch is not configured, and the metadata display logic is not enabled synchronously during official deployment, causing citation sources to be hidden.
- Phenomenon: The number of citations exceeds expectations, with non-calibration-related redundant documents mixed in. Cause: The maximum number of citations is not set, and default retrieved documents include non-metrology content, interfering with the judgment logic of quality audits.

## How to confirm the configuration is correct
- Launch a test query for measuring instrument calibration or supplier audit, and check if the reply includes cited document numbers or links.
- Check if the `quoteMaxToken` configuration item covers the text length of the current longest calibration certificate, avoiding truncation prompts.
- Test the text extraction component to confirm that structured traceability fields such as instrument number and calibration date can be extracted.
- Switch to the official chat interface, and confirm that the display style of citation sources is consistent with that of the debug page.

The values given are common starting points and should be measured against the reader's own samples.
