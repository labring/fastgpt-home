# Supplier and Process Quality Audit for Metal Cutting Machining: Citation Sources and Traceability

## What the data for this category looks like
Typical entities are machining factories, precision parts factories, and machining workshops of equipment enterprises. Daily documents include process routes, operation cards, tool lists, CNC programs, first-piece inspection records, patrol inspection forms, and measuring tool calibration records.

Data sources cover product drawings and 3D models, CAPP/CAM systems, machine tool collection data, tool management systems, MES systems, and measuring and inspection tool data.

Update frequencies are triggered by work orders, individual products, sampling batches, or tool changes. Each document contains dedicated fields such as workpiece number, operation number, tool model, calibration date, and dimensional deviation values.

## What constraints do these characteristics impose on the citation sources and traceability link
Data sources are scattered and update frequencies are high. The consequences of errors include workpiece scrapping, tool collisions, or machine tool downtime. Citation traceability must be accurately bound to specific work orders, operations, or tool batches to avoid document confusion across work orders.

There are diverse document types and specialized fields. Traceability requires matching dedicated metadata such as process parameters and dimensional deviations. Generic fields cannot be used for traceability.

Documents such as CNC programs and operation cards have lengthy content. Full key parameters must be retained during citation. Using only excerpts will result in traceability failure.

## How to set the configuration
| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `quoteMaxToken` | 800–1200 token | CNC programs and operation cards for metal cutting machining have lengthy content. This range is needed to accommodate complete process parameters and traceability information |
| `responseData` | Full metadata including source fields | Dedicated traceability fields such as workpiece number, operation number, and tool model must be returned to meet audit requirements |
| `detail` | Enabled | Specific detailed data such as dimensional deviations and tool wear amounts in operation cards must be displayed |
| Citation content template | {{content}} (Source: {{sourceTitle}}, Work Order Number: {{workOrderNo}}, Tool Model: {{toolModel}}) | Matches dedicated traceability fields for machining work orders, clearly displays citation sources |
| Single search limit | Top 6 entries | Documents related to a single work order, including process, inspection, and tool documents, typically fall within the range of 5 to 7. This covers all associated documents |
| Knowledge base filtering rules | Bind workpiece number field | Accurately match documents associated with the current audit work order, avoiding interference from irrelevant data |

## Three common mistakes
- Symptom: No optional values appear when selecting variable references in knowledge base searches. Cause: Machining-specific variables such as work order number and tool model have not been configured in associated workflow nodes, or variables have not been bound to metadata fields of the corresponding knowledge base.
- Symptom: Online environment error Cannot redefine property: toString. Cause: The toString field is repeatedly defined in a custom citation template, or a metadata field conflicts with a system built-in field.
- Symptom: Citation content fails to match the corresponding operation card or CNC program. Cause: The single search limit is set too low, failing to cover all documents associated with the current work order, or the search benchmark is not bound to the benchmark feature field of the workpiece drawing.

## How to confirm the configuration is correct
- Submit a query that includes the workpiece number and work order number. Check whether the citation section of the returned results includes the preset dedicated traceability fields.
- In FastGPT v4.17.0, test the variable reference function. Confirm that configured variables such as work order number and tool model appear in the variable selection list of knowledge base searches.
- Trigger a query that uses a custom citation template. Verify that the returned citation content format complies with the preset template requirements.
- Adjust the single search limit parameter. Check that the number of search results matches the set value range.
