# Supplier and Process Quality Audit for Steel Rolling and Finishing: Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
Data for this category originates from slab or billet batches, heating furnaces, mill automatic control systems, online thickness and width measuring equipment, surface inspection devices, and MES systems at hot rolling, cold rolling, section steel, and steel pipe enterprises. The system updates data per coil or per piece, and syncs it in real time. Daily documents include rolling plans, heating schedules, rolling specifications, shape and thickness records, surface quality reports, and quality certificates. Fields include shape deviation, thickness deviation, and surface defect level. Units include millimeters, degrees Celsius, and other standard units. The system archives data linked by batch and coil number.

## What Constraints These Characteristics Impose on the "Knowledge Base Retrieval and Recall" Link
Real-time data updates per coil or per piece require the knowledge base to support incremental synchronization, to avoid full refresh that consumes excessive system resources. The document structure tied closely to batches and coil numbers requires retrieval tools to filter results by batch dimension, ensuring recalled data matches the target audit object. Detailed professional process and quality inspection field requirements demand strict control of retrieval relevance thresholds, to prevent low-relevance data from interfering with audit judgments. The combination of small single-coil data volume and large overall batch data volume requires limiting the number of single-round recall results, to avoid context overload that slows response speed.

## Three Common Misconfigurations
- Phenomenon: Authentication failure is returned when calling the knowledge base API, with an extra Bearer prefix in the request header. Cause: The automatic Bearer supplement function is not disabled in API configuration, causing the request format to not meet system requirements.
- Phenomenon: A large number of steelmaking documents unrelated to rolling processes are included in retrieval results, with insufficient relevance. Cause: `collectionIds` is not configured to limit the retrieval collection, resulting in cross-category data being recalled.
- Phenomenon: Knowledge base retrieval response times out, causing audit process lag. Cause: The `limit` parameter is not set reasonably, recalling too many redundant results leading to excessive context processing time.

## How to Confirm Configuration Is Complete
- View the knowledge base configuration page, confirm that `collectionIds` is bound to this category's exclusive document collection, and does not include datasets from unrelated categories.
- Initiate a retrieval test for a single batch of steel coils, verify that the relevance of returned results meets expectations, and the number of results matches the `limit` setting.
- Call the knowledge base API interface, check that the request header format meets requirements, with no automatically added extra authentication prefix.
- Simulate real-time update of single-coil data, verify that the incremental sync function works normally, and retrieval results can include the latest quality inspection records in a timely manner.
