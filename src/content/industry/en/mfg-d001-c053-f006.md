# Supplier and Process Quality Audit for Iron and Steel Smelting and Continuous Casting: Citation Sources and Traceability

## What this category of data looks like
This category of data covers full-process outputs from ironmaking, steelmaking, continuous casting, quality control, and scheduling departments of integrated iron and steel enterprises. It belongs to high-temperature continuous process industries, with high coupling strength between heats and casting sequences. It differs from non-ferrous smelting operations, which use different ore types and electrolysis routes. Daily documents include heat plans, batching lists, converter smelting records, composition reports, continuous casting process records, and slab judgment sheets. Fields include heat number, hot metal composition, endpoint temperature, casting speed, slab defect type, and others. Units include degrees Celsius, tons, millimeters, and additional standard industrial units. Data sources include hot metal and scrap steel data, L2 process control systems, laboratory test results, MES systems, energy medium systems, and equipment condition monitoring data. Update frequencies run per heat, in real time, or per shift.

## What constraints these characteristics impose on the citation sources and traceability link
The high-temperature continuous process and strong coupling between heats and casting sequences, plus the need to avoid unplanned shutdowns, require traceability data to fully cover full-process records for abnormal heats. This prevents data loss from process interruptions. Real-time updated L2 process data and shift-archived slab judgment sheets require separate handling for real-time retrieval and batch backtracking scenarios, to align with different update rhythms. Aligning fields across multiple data sources is challenging. Composition data from different systems may use inconsistent units, requiring unified mapping during the traceability link. The volume of document data linked to a single heat is concentrated. The context limit for a single retrieval must match the total length of documents for a single heat, to avoid exceeding processing thresholds.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | The total token count of documents associated with a single heat typically falls within this range. It matches the context processing limit of FastGPT v4.17.0 to avoid content overflow |
| `responseData` | Return original document metadata + snippets | Metadata such as heat number, test time, and data source system must be retained. This meets traceability association requirements for quality audits |
| `detail` | Enabled | Specific smelting record snippets and composition report content must be displayed. This supports detailed audits of suppliers and process quality |
| Single search limit | Top 6 entries | Controls redundancy in retrieval results. It prevents results from multiple data sources from exceeding the effective range of business processing |
| Context splicing order | Sorted in reverse chronological order of heat time | Latest process data and slab judgment results have higher reference value for quality audits. This aligns with business audit logic |

## Three Common Configuration Mistakes
- The issue is that the number of citations returned by retrieval exceeds the preset top 6 limit. The cause is incorrect configuration of `quoteMaxToken`, leading to the system not effectively truncating retrieval results.
- The issue is that the order of citation results does not match business expectations. They are not sorted by heat time or test priority. The cause is failure to set rearrangement by metadata fields, relying only on the default retrieval matching logic.
- The issue is that knowledge base citation content is always displayed in conversations. It cannot be turned off via conversation settings. The cause is failure to disable the citation display configuration in the workflow’s output node, leaving the forced rendering global setting enabled.

## How to Verify Correct Configuration
- Retrieve the batching list and converter smelting record for a single heat. Check that the returned citation snippets include the correct heat number and corresponding test data.
- Review the order of citation results. Confirm they are displayed in reverse chronological order of heat time, aligning with the priority logic of business audits.
- Trigger a quality audit-related query. Test whether the citation display toggle can be switched on and off via the output configuration.
- Verify that the cited metadata includes identifiers for data source systems. Confirm traceability to corresponding data sources such as L2 process control systems and laboratories.
