# Supplier and Process Quality Audit for Lithium-ion Cell Manufacturing: Citation Sources and Traceability

## What the Data for This Category Looks Like
Data for this category comes from raw material batch ledgers, production MES systems, slurry and coating testing equipment, workshop dew point monitoring systems, formation and grading cabinets, and laboratory OCV and safety testing equipment.
Update frequencies include real-time upload of per-production-batch and single-cell test data, and archival of laboratory reports per batch.
Daily professional documents include solid content records for batching, coating and calendering parameter sheets, winding tension logs, liquid injection volume ledgers, formation and grading curves, and internal resistance test values.
All content is exclusive to the lithium-ion cell manufacturing stage.

## Constraints for Citation Sources and Traceability
This category’s data has strong real-time performance, is split by production batches, and has concentrated professional fields. These traits create multiple constraints for citation and traceability.
Accurately match batch numbers and production stages to avoid mixing cross-batch data.
Configure targeted recall rules to filter redundant content unrelated to cell manufacturing.
Integrate index paths across multiple devices and systems to ensure coverage of full-stage data including slurry, coating, formation and grading.
Ensure traceability accuracy. Inaccurate traceability will invalidate audit basis and lead to battery consistency or safety risks.

## Configuration Setup
The following configurations are formulated for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `quoteMaxToken` | `8000–12000 token` | Professional documents for lithium-ion cell manufacturing contain large volumes of parameter and curve data. Sufficient context is required to support accurate matching of audit needs |
| `responseData` | Return full citation metadata | Specific document types and corresponding production stages must be displayed for cited documents to meet traceability requirements for supplier and process quality audits |
| `detail` | Enable detailed citations | Source equipment or laboratory for cited data must be clearly marked to enhance audit credibility |
| Single search limit | Top 6 entries | This category’s data is split by batch. Excessive recall will interfere with core audit basis and reduce judgment efficiency |
| Maximum context window | Calibrated via on-site testing | Data volume varies widely across production batches. Settings must adapt to server resources and business needs for on-site deployment |

## Three Common Mistakes
- Phenomenon: Cited coating and calendering parameter documents are not displayed on the official chat page, but display normally on the debug page. Cause: The complete metadata return configuration corresponding to `responseData` is not enabled. Extra citation information only loads in debug mode.
- Phenomenon: Recalled citation documents include irrelevant consumer electronics assembly records, and the number of results exceeds expectations. Cause: The single search limit is set too high, and data source indexes unrelated to lithium-ion cell manufacturing stages are not filtered.
- Phenomenon: Unable to extract formation and grading data for a specific batch from the knowledge base. Cause: The real-time data directory of the formation and grading cabinets is not included in the knowledge base index range, or the professional field extraction rule corresponding to `detail` is not configured.

## How to Verify Correct Configuration
- Enter keywords for the batching record of a specific battery batch, check if returned results include the raw material batch document and coating parameter record corresponding to that batch.
- View the citation area at the end of the reply, confirm that document types such as liquid injection record, OCV test report and corresponding data sources are marked.
- Adjust the `quoteMaxToken` parameter, verify whether the length of returned citation content adapts to the information density of professional documents.
- Simulate the supplier audit process, check whether associated data from the same production stage can be accurately recalled, with no irrelevant cross-stage documents included.

The values provided here are common starting points and should be measured against the reader's own samples.
