# Drafting Process Documents and Exception Reports for PCB Manufacturing: Source Citation and Traceability

## What the Data for This Category Looks Like
Daily documentation for PCB manufacturing includes engineering production instructions, Gerber analysis records, drilling and lamination parameters, chemical solution analysis reports, AOI inspection reports, electrical test reports, and sectioning test reports.
Data sources include customer-provided Gerber files, drill tapes, BOM files, CAM system outputs, equipment operating parameters, bath solution test results, data collected by AOI and electrical test equipment, and laboratory test records.
Data update frequency occurs per production batch, per shift, or via continuous collection.
Fields across different documents include layer number, rotation speed, feed rate, bath concentration, defect location, and more. Supported units include mm, rpm, m/min, ppm, and others.

## Constraints for Source Citation and Traceability
PCB manufacturing data sources are scattered and diverse in type. Precise matching of source identifiers across different documents is required to avoid mixing documents across production batches.
High-frequency updated equipment and test data require the traceability system to support real-time or near-real-time recall, to ensure cited content matches the current production batch.
Complex document structures and multi-field parameters require the traceability function to recognize correlations between specific fields, to accurately link exception reports to corresponding process parameters.
Severe consequences of operational errors require source citation and traceability to have high accuracy, to avoid mistakenly citing unrelated documents that cause production abnormalities.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale for This Setting |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Adapts to the length of single cited content for PCB exception reports and inspection records, avoids truncating critical parameters |
| `responseData` | Return only knowledge base documents | Ensures cited content only comes from the pre-configured PCB manufacturing knowledge base, excludes externally generated content |
| `detail` | Enabled | Extracts original fields from AOI and electrical test reports, retains precise production information such as drilling rotation speed and lamination pressure |
| Single recall limit | Top 5 entries | Covers multiple inspection records per production batch, meets the needs of exception association and traceability |
| Context length | 1000–1500 characters | Matches the length of single documents such as engineering production instructions and Gerber analysis records, avoids truncating pre-process descriptions |

## Three Common Misconfigurations
- Symptom: Returned citation sources do not match the actually uploaded documents, showing unrelated general documents. Cause: Recall filtering rules are not configured according to PCB manufacturing document types, leading the recall scope to cover non-production-related knowledge base content.
- Symptom: After citation traceability is enabled, unconfigured generated content is still returned, rather than only returning the original text from the knowledge base. Cause: The `responseData` parameter is not correctly enabled, or mixed recall mode is configured.
- Symptom: Cited content is incomplete, with key parameter fields missing. Cause: The `quoteMaxToken` setting is too small, truncating core production parameters such as drilling rotation speed and lamination pressure.

## How to Verify Proper Configuration
A single PCB drilling parameter document is uploaded, and a query containing keywords from this document is initiated, to verify that returned citation sources only include this document.
The `quoteMaxToken` value is adjusted, and citation completeness of long-parameter documents is tested, to confirm no truncation occurs.
A query containing exception keywords is initiated, to verify that returned cited content includes original exception records from AOI reports and electrical test reports.
The FastGPT v4.17.0 system log is checked, to confirm that all recalled documents come from the pre-configured PCB manufacturing knowledge base category.

The values provided are common starting points and should be measured against the reader's own samples.
