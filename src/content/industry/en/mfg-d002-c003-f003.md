# Drafting Process Documents and Exception Reports for Dairy Processing: Multi-turn Dialogue and Prompt Engineering

## What This Category's Data Looks Like
Data for this category comes from milk source testing, MES systems, homogenization and heat treatment equipment, online temperature and flow systems, CIP systems, and LIMS. Daily documents include raw milk acceptance records, standardized batching sheets, pasteurization or UHT sterilization records, CIP cleaning records, filling records, sample retention and microbial test reports. Data is updated in real time per milk tank and per production batch. Documents are associated by production batch, with fields including batch number, test values, and equipment operating parameters. Units include mg/kg, ten thousand/mL, ℃, seconds, L, and others.

## Constraints Imposed on Multi-turn Dialogue and Prompt Engineering
Data is updated in real time per milk tank and production batch, and linked across multiple systems. Multi-turn dialogue must fixedly tie to the context of the matching batch to avoid mixing cross-batch data.
Document fields and units have category-specific traits. Prompts must clearly restrict calls to the exclusive document fields of the current batch to prevent irrelevant data from being included.
Errors can lead to full-tank rejection or large-scale recalls. Dialogue must quickly verify data consistency to avoid generating incorrect process documents or exception reports.
Liquid raw materials are perishable, and processes run continuously. Dialogue response duration must be limited to ensure timely exception handling.

## How to Configure Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| ---- | ---- | ---- |
| `chatId` | Generate a unique ID per production batch | Distinguish dialogue contexts for different milk tanks and batches to avoid data cross-interference |
| `messages` | Retain the most recent 10 rounds of dialogue | Cover multi-step operation records for dairy processing batches to ensure complete context |
| `variables` | Bind batch number, test values, and equipment number | Link multi-system documents corresponding to the target batch to accurately call exclusive fields |
| Single dialogue return limit | Top 3 batch-associated records | Avoid information overload and focus on documents related to the current exception |
| Context character limit | 8000–12000 characters | Cover complete process and test document content for a single batch |
| Response duration limit | No more than 600 seconds | Ensure timely exception handling and adapt to the perishable nature of liquid raw materials |
| Prompt template | Calibrated based on actual testing | Match the enterprise's own process and exception report format |

## Three Common Mistakes
- A "missing parameter" error is returned when uploading files via the dialogue interface. The cause is failing to bind the production batch number corresponding to the file in `variables`.
- Equipment images in exception reports generated after the prompt calls MCP are not fully displayed. The cause is failing to limit multi-turn dialogue to only call exclusive equipment screenshots for the current batch.
- After upgrading to FastGPT v4.17.0, rule-like symbols appear at the end of dialogue return results. The cause is failing to turn off the rule trace display switch in dialogue settings.

## How to Confirm Proper Configuration
- Launch a multi-turn dialogue about an abnormal single-batch raw milk, check that `chatId` remains consistent and is linked to all historical documents of that batch.
- Upload a raw milk acceptance record, check that `variables` automatically extracts fields such as batch number and test values.
- Trigger exception report generation, check that the return result does not include extra rule-like symbols.
- Launch concurrent dialogues for multiple batches, check that no data cross-interference occurs across dialogue contexts.

The values provided are common starting points and should be measured against the reader's own samples.
