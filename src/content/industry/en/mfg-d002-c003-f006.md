# Drafting Process Documents and Exception Reports for Dairy Processing: Source Citation and Traceability

## Data Profile for This Category
This category covers the full processing workflow for liquid milk, yogurt, milk powder, and dairy ingredients. Daily documentation includes raw milk acceptance records, standardized ingredient lists, pasteurization/UHT heat treatment records, CIP cleaning records, filling records, and retained sample and microbial test reports.
Data sources include milk source testing equipment, production MES systems, online homogenization and heat treatment sensors, CIP systems, and LIMS laboratory management platforms. Updates occur in real time per individual milk tank and production batch.
Document fields include test values, equipment parameters, timestamps, and batch numbers. Common units include degrees Celsius, liters, colony-forming units per milliliter (cfu/mL), and similar units.

## Constraints Imposed on Source Citation and Traceability
Because data is updated in real time per tank and production batch, citation and traceability must be tied to unique batch numbers and timestamps. This prevents cross-batch data mixing.
Multi-source heterogeneous data comes from equipment, systems, and laboratories. Clear field mapping rules must be established for each source. This ensures accurate matching of original data nodes during citation.
Real-time updated temperature, flow, and heat treatment parameters must support second-level traceability. Static chunked caching cannot be relied on.
The perishable nature of dairy products requires traceability results to link to retained sample and microbial test reports. This verifies the compliance of exception judgments. Traceability cannot be separated from original test records.

## How to Set Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the average length of single-batch dairy processing documents, ensuring complete citation of core content from raw milk acceptance and heat treatment records |
| `responseData` | Enabled | Allows returning fields from original documents and traceability links, aligning with business requirements for verifying batch parameters in dairy processing |
| `detail` | Enabled | Expands specific fields of cited sources, such as antibiotic test values for raw milk, temperature and duration of CIP cleaning |
| Maximum Context | Previous 10 conversation turns | Covers the full process flow from raw milk acceptance to filling, ensuring coherent context for multi-turn process judgments |
| Single Search Limit | Top 6 results | Matches the number of associated documents for a single production batch, avoiding interference from redundant data when drafting exception reports |
| Reranking | Calibrated via actual testing | Adjusts sorting rules based on document structures of different production batches, prioritizing core data matching the current process link |

## Three Common Configuration Errors
- Issue: Only citation links are returned when generating process documents or exception reports. No body content is included.
  Cause: The `responseData` configuration is not enabled. Only traceability indexes are returned, without loading original document content.
- Issue: The citation viewing function fails to load when accessing the application via a login-free shared link.
  Cause: In FastGPT v4.17.0, traceability permissions for login-free sharing are not synchronized. The traceability display switch must be individually enabled in the application configuration.
- Issue: Previous batch raw material acceptance or ingredient data cannot be linked in multi-turn conversations.
  Cause: Maximum context is not configured to cover multi-turn process links. Only search results from the current single turn are used.

## How to Verify Correct Configuration
- Generate a process document for a single-batch raw milk acceptance. Check if the returned results include original document fields and traceability links.
- Simulate multi-turn process discussions. Confirm that subsequent generated exception reports can link to previous ingredient and heat treatment records.
- After generating an exception report, click the citation link. Verify that it redirects to the details page of the corresponding original document.
- Test the login-free shared link. Confirm that the citation viewing function loads original data normally.

The values provided here are common starting points and should be measured against the reader's own samples.
