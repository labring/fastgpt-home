# Process Document and Exception Report Drafting for Photovoltaic Cell Manufacturing: Source Citation and Traceability

## What this category of data looks like
Production data for photovoltaic cell manufacturing comes from silicon wafer incoming material ledgers, workshop MES systems, real-time operation logs of diffusion furnaces, coating equipment, and printing presses, EL defect detection images, IV performance test data, and laboratory physicochemical test results. Daily produced documents include process cards, diffusion sheet resistance parameter tables, printing and sintering temperature curves, EL defect annotation images, IV grading data, and batch yield reports. Data updates follow this cadence: synchronized per production batch, real-time updates for single-chip detection, and daily summary statistics. Fields include texturing tank temperature, diffusion sheet resistance, coating thickness, EL defect coordinates, open-circuit voltage, and other metrics, with matching professional units attached.

## Constraints imposed by these characteristics on source citation and traceability
Because data sources are scattered and tied to specific production batches and single-chip IDs, the traceability link requires precise matching of production identifiers. Generalized source descriptions cannot be used. Mixed citations of multiple document types (including text and images) require the traceability system to support associated display of cross-format data. Frequently updated real-time data requires limiting the context time range to avoid citing expired process parameters or abnormal records. Professional fields and fixed units require strict alignment of parameter names and units during traceability matching, to prevent process deviations caused by mismatches.

## Configuration Settings
Configuration references for FastGPT v4.17.0 are listed below:

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `quoteMaxToken` | 800–1200 token | Citations for photovoltaic process and exception reports are mostly parameter snippets and test data. This length covers typical citation needs without exceeding context limits |
| `responseData` | Return matching source batch numbers and chip IDs | The core of photovoltaic manufacturing traceability is binding specific production units, requiring precise association with production data for the corresponding batch |
| `detail` | Include device operation log snippets | Exception report drafting requires supplementing equipment operating conditions when abnormalities occur. This configuration provides necessary contextual details |
| Context time range | Last 72 hours | Changes in photovoltaic process parameters and anomaly associations usually occur within 3 days. An overly long range will introduce irrelevant expired data |
| Single recall source limit | Top 6 entries | The number of citation sources for a single report should not be excessive to avoid content redundancy that harms readability |

## Three Common Misconfigurations
- Irrelevant knowledge base citation entries remain in generated process documents. This happens when the `quoteMaxToken` parameter is not configured correctly, leading to retrieval of redundant source data beyond required needs.
- The traceability field of exception reports is empty, making it impossible to associate with the corresponding batch of EL detection images. This happens when `responseData` is not configured to return batch numbers and chip IDs, and only generalized document content is returned.
- The default value of the form input node cannot correctly reference process parameters, resulting in missing parameters in generated files. This happens when the form configuration does not bind the production batch variable prefix, so the corresponding data source is not matched.

## How to Verify Correct Configuration
- Generate a simulated exception report, and check if the citation source section includes the corresponding batch numbers and chip IDs.
- Check the length of citation content in the generated file to confirm it does not exceed the range set by `quoteMaxToken`.
- Test variable binding for the form input node to confirm that the default process parameter values for the corresponding production batch can be loaded correctly.
- Compare the time range of citation sources to confirm only production data from the last 72 hours is included.

The values provided are common starting points and should be measured against the reader's own samples.
