# Process Document and Exception Report Drafting for Photovoltaic Module Encapsulation: Source Citation and Traceability

## What Data for This Category Looks Like
Photovoltaic module encapsulation data comes from cell sorting systems, glass adhesive film backplane batch ledgers, factory MES systems, string welding and lamination production equipment, EL crack detection instruments, and IV power testers. Daily generated documents include layout diagrams, material batch records, lamination process parameter records, EL defect images, IV test reports, insulation withstand voltage test records, and finished product packing lists. Data updates follow a set cadence: one set of test records per module, and batch ledgers generated per batch of raw materials. Fields include material model, production batch, equipment operating parameters, test values, operator identification, and other relevant items.

## Constraints Imposed on Source Citation and Traceability
The multi-source data characteristics of photovoltaic module encapsulation create multiple constraints for the source citation and traceability process. Data is scattered across production equipment, testing instruments, and management systems. Precise matching of timestamps and associated fields for cell sorting, material batches, and production parameters is required. This prevents cross-batch data confusion during traceability, and avoids quality issues such as subsequent non-compliant power ratings or lamination delamination caused by misplaced data. Single-component test records are updated frequently, so citation time ranges must be limited. This prevents calling expired batch ledgers. Daily documents include both image-based EL defect images and numerical IV test reports. Support for associated citations across different data source formats is needed. This ensures that visual defect records and quantitative test data can be retrieved simultaneously when drafting exception reports.

## Configuration Settings
This page applies to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | Photovoltaic module encapsulation process documents and exception reports need to cite multiple sets of test data and batch records. This token range covers the citation needs of a single complete test report, and avoids truncating critical information. |
| `responseData` | Return associated document metadata | Citation of material batches and test report sources must be included in exception reports. Enabling this configuration synchronizes document metadata such as batch numbers and test times to the output content. |
| `detail` | Enabled | Process documents and exception reports need to fully associate detailed content such as EL images and IV test data. Enabling this retrieves more precise segmented data sources. |
| Single search limit | Top 6 entries | The data sources associated with a single exception report typically do not exceed 5 groups. The top 6 entries cover all association needs, and avoids interference from redundant information. |
| Response timeout | 300 seconds | Most photovoltaic module encapsulation data sources are deployed on factory internal networks. 300 seconds covers the retrieval and association time for multi-source data, and avoids mid-process timeouts. |
| Document chunk size | 1000–1500 characters | The text length of a single photovoltaic module test report typically falls within this range. Chunking ensures data integrity, and avoids truncating critical parameters. |

## Three Common Configuration Mistakes
- Citation sources are not displayed in formal exception report outputs, and are only visible in the debug interface. Cause: The `responseData` configuration is not enabled correctly, or the configuration item is not linked to the citation display module of the output template.
- The number of cited data sources exceeds expectations, and cannot be limited to a fixed number. Cause: The single search limit is not configured according to business needs, or the score threshold is mistakenly used as the entry limit condition.
- EL image data cannot be properly associated with process documents. Cause: The `detail` configuration is not enabled, or the associated fields of the data source are not matched correctly, resulting in failure to retrieve image-based test records.

## How to Confirm the Configuration Is Correct
- Enter the debug interface, enter the requirement for drafting a photovoltaic module exception report, and check whether the output content includes cited document metadata such as material batch numbers and test report numbers.
- Adjust the value of `quoteMaxToken`, observe changes in the citation length of the output content, and confirm that the configuration takes effect.
- Test calls for different types of data sources, such as EL images and IV test reports, and confirm that both formats of data can be cited normally.
- Switch to the officially released chat interface, and verify that the citation information matches the content from the debug interface.

The values provided here are common starting points. Adjust them based on your own specific samples and use cases.
