# Stamping and Sheet Metal Forming: Process Document and Exception Report Drafting: Citation Source and Traceability

## What Data for This Category Looks Like
This category of data originates from steel coil labels and quality certificates, press and feeder operation data, mold management systems, MES systems, and coordinate measuring machine and fixture inspection results. Daily documents include stamping operation instructions, material utilization rate sheets, mold inspection sheets, first and last piece records, dimensional inspection reports, and mold change records.

Data updates are triggered by coil material batches, mass production runs, and mold change operations. Each document includes fields such as material grade, mold number, production parameters, and inspection values, with units including millimeters, newtons, tons, and other industrial standard units.

## Constraints Imposed on Citation Source and Traceability
The data sources for this category are scattered, and update triggers occur frequently. The citation traceability link must support cross-system data association and matching to avoid limitations of single-source data.

Field priorities vary across different document types. For example, mold change records must be associated with mold numbers and production parameters, while dimensional inspection reports must bind to inspection values from first and last piece records. Different recall rules must be configured for each document type.

Additionally, data update frequency is high in mass production scenarios. Traceability results must match the latest coil material batches and mold change operation nodes to ensure cited content aligns with current production status.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Stamping and sheet metal forming process documents contain multiple sets of production parameters and inspection data. This token range covers the key content of a single core document and avoids truncation of valid information |
| `responseData` | Only recall documents from steel coil quality certificates, mold management systems, and MES systems | Core production data for this category comes from the above systems. Limiting sources reduces interference from irrelevant documents and improves traceability accuracy |
| `detail` | Display document source system, generation time, and associated batch number | Stamping production has strict timeliness. Labeling this information helps confirm cited content matches the current coil material batch or mold change operation |
| Single search limit | Top 6 entries | The number of valid documents associated with a single production batch for this category is limited. The top 6 entries cover major mold change, material, and inspection records, avoiding redundant results |
| Reranking Rule | Sort in descending order of document update time | Production data is updated frequently. The latest mold change and inspection records provide more reference value for current process and exception analysis |

## Three Common Misconfigurations
- Phenomenon: The generated process document or exception report includes the prompt "No permission to operate this conversation record" at the end. Cause: The recall source range for `responseData` is not limited. The system attempts to access unauthorized mold management system or MES data interfaces, triggering a permission verification failure.
- Phenomenon: Unparsed `\n` characters appear in the citation description of the exception report, and the expected line break effect is not achieved. Cause: Automatic formatting configuration for response content is not enabled. Line breaks in the original text are output as ordinary characters instead of formatting breaks.
- Phenomenon: Expired mold change records and material data unrelated to the current batch are included in citation results. Cause: Recall results are not sorted by document update time. The system returns earlier generated non-associated documents first.

## How to Verify Successful Configuration
- A steel coil quality certificate and a mold change record may be manually uploaded, a process document drafting request initiated, and cited content checked to confirm it only includes documents from the specified sources.
- After an exception report is generated, the additional information following the citation mark may be checked for the source system and generation time to confirm the `detail` configuration is active.
- Documents of varying lengths may be uploaded, the value range for `quoteMaxToken` adjusted, and cited content checked to confirm no excessive truncation or redundant loading occurs.
- Citation description input containing line breaks may be tested, output confirmed to correctly implement line break effects, and the formatting configuration verified as active.

The values provided are common starting points and should be evaluated against the reader's own samples.
