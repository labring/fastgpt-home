# Drafting Process Documents and Exception Reports for Active Pharmaceutical Ingredient and Pharmaceutical Intermediate Production: Model Access and Configuration

## What the data for this category looks like
Core data for active pharmaceutical ingredient and pharmaceutical intermediate production comes from registered process documents, raw material batch ledgers, DCS control systems, weighing systems, LIMS laboratory information management systems, chromatography data systems, and QMS quality management systems.
Data updates trigger per production batch and per process step.
Daily documents include batch production records, material balance ledgers, reaction and purification records, cleaning validation records, impurity profile reports, deviation and change documents.
Fields cover reaction temperature, yield ratio, impurity content, solvent residue content, and other metrics. Some fields use industry-specific measurement identifiers.

## Constraints imposed on model access and configuration
Multiple heterogeneous data sources require the access link to support API integration with multiple heterogeneous systems. This avoids creating data silos.
High-frequency batch-level updates require configurations to adapt to rapid data pulling and processing. Delays are prevented that would impact drafting efficiency for process documents and exception reports.
Complex document structures and specialized field units require models to accurately identify and map specific process fields. Field mapping rules must be configured in advance.
Compliance requirements for sensitive data control require limiting the model's context scope. This prevents leakage of unrelated data.

## How to configure the settings
| Configuration Item | Recommended Value Range | Rationale |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | Adapts to the total data volume of multi-step process documents for a single batch, to avoid truncating core process parameters |
| `maxTokens` | 3500–4500 token | Balances content completeness of exception reports and generation response speed |
| `temperature` | 0.2–0.4 | Ensures rigor of process descriptions and data references, reduces irrelevant divergent content |
| `toolChoice` | auto | Allows models to call data retrieval tools as needed to supplement missing batch-related data |
| `AIPROXY_API_ENDPOINT` | Enterprise privately deployed proxy address | Adapts to network isolation requirements of private deployments, to ensure data transmission security |
| `AIPROXY_API_TOKEN` | Exclusive key bound to the proxy service | Enables fine-grained access permission control, to avoid unauthorized data access |

## Three common configuration errors
- Scenario: After upgrading FastGPT v4.17.0, models connected to ONEAPI fail to connect. The interface returns a connection failure prompt. Cause: The ONEAPI proxy endpoint configuration has not been updated, or the permissions of the bound token have not been synchronized.
- Scenario: After adding a new model configuration, the FastGPT interface does not display the configuration item. Restarting the service does not resolve the issue. Cause: The configuration file was not placed correctly in the system-specified loading directory, or the deployment package did not complete a full update.
- Scenario: The generated exception report is missing batch yield data. Cause: The `maxContext` value is too small, truncating yield field information from batch production records.

## How to verify a successful configuration
- Verify that the `AIPROXY_API_ENDPOINT` and `AIPROXY_API_TOKEN` configurations match the privately deployed proxy service in the system settings interface.
- Upload a single-batch batch production record sample. Test whether the model can fully extract core process fields from the document.
- Generate a draft exception report. Confirm that the generated content includes relevant data from LIMS and DCS systems.
- Adjust the `maxContext` value range to ensure it covers all core process data for the current batch.

The values provided are common starting points and should be measured against the reader's own samples.
