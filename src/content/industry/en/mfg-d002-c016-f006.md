# Process Document and Abnormal Report Drafting for Transformer and High-Voltage Electrical Manufacturing: Source Citation and Traceability

This page is written based on the configuration instructions for FastGPT v4.17.0.

## What the data for this category looks like
The system sources core data for transformer and high-voltage electrical manufacturing from design BOM, silicon steel sheet and insulating material procurement data, vacuum drying equipment logs, oil test reports, partial discharge and withstand voltage test records from the test station, and nameplate parameter tables. Staff perform data updates once per device or per batch of materials. The system binds each single product to multiple documents including winding and core assembly records and vacuum drying records. Document fields include professional parameters such as insulation moisture content, partial discharge value, withstand voltage value, and tap position. The system requires full life cycle traceability for each single device.

## What constraints do these characteristics impose on the source citation and traceability link
Full life cycle traceability for single devices mandates that citations bind to documents of specific unit numbers or batches, and prohibits mixing data across batches. Multi-source and heterogeneous document formats require the traceability link to accurately match core fields such as insulation moisture content and partial discharge values, avoiding generalized retrieval. High-frequency single-device updates require the traceability system to associate the latest test reports and assembly records in real time, ensuring cited content matches current production status. Severe error consequences require the traceability link to lock the only correct source document, preventing subsequent process deviations caused by incorrect citations.

## How to set the configuration
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the standard text length of a single high-voltage test report, to avoid truncation of core data such as partial discharge and withstand voltage values |
| `responseData` | Enabled | The system must embed original traceable fields such as nameplate parameters and insulating oil indicators in process documents and abnormal reports |
| `detail` | Show only core fields | Focus on key production parameters for transformer manufacturing such as insulation moisture content and tap position |
| Single recall limit | Top 5 entries | Avoid introducing irrelevant documents from multiple batches, ensuring traceability accurately matches production data for the current unit number |
| Context loading timeliness | Calibrated via actual measurement | Adapt to the synchronization update rhythm of test station equipment data, preventing outdated citations caused by delays |

## Three common mistakes
- After sending a POST request, the interface returns success but has no content field: The cause is that the `responseData` configuration item is not enabled correctly, and source document data is not included in the return range.
- Garbled characters appear in cited content: The cause is that parsing character sets for documents such as insulating oil reports and test records are not unified, and the encoding format for professional terms is not adapted.
- The number of cited entries exceeds expectations and includes cross-batch documents: The cause is that the single recall limit is set too high, and the system does not restrict recall to only associated documents for the current unit number or batch.

## How to confirm configuration is complete
- Generate a draft transformer process document, check whether core specified fields such as insulating oil moisture content and partial discharge values are embedded in the main text.
- Click the traceability link of the cited source, confirm that it jumps to the corresponding original production documents such as test reports and assembly records.
- Send a test request, verify that the returned content field contains complete key production data from the source document.
- Check whether the displayed cited content only includes associated documents for the current batch, with no cross-batch redundant data.

The values provided here are common starting points and should be measured against the reader's own samples.
