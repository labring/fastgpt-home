# Drafting Process Documents and Exception Reports for Spraying and Coating: Document Parsing and Chunking

## Data Overview for This Category
This category's data primarily comes from coating supplier TDS/SDS documents, spray booth and oven operation data, results collected by colorimeters and film thickness gauges, environmental monitoring records, and MES systems. Typical daily documents include coating process cards, coating batch sheets, paint mixing records, film thickness and color difference reports, oven curves, defect repair orders, and VOCs logs. Data is updated with each batch of coating, per shift operations, or via continuous collection. Most documents contain process parameters, test values, batch information, and exception records. Many fields use specialized units such as μm, ℃, and mg/m³.

## Constraints on Document Parsing and Chunking
The multi-source heterogeneous document types, time-series collected data, and specialized field characteristics of this category impose multiple constraints on document parsing and chunking. Coating process cards are structured parameter documents. Oven curves are time-series numerical sequences. Defect repair orders are free-text records. Parsing rules must adapt to different formats. Abruptly truncating continuously collected oven operation data will lose the complete logic of temperature changes. Batch documents’ coating batch numbers and work team information must retain contextual associations, to ensure corresponding process parameters can be matched after chunking. Specialized test values must stay bound to their units. Parsing must avoid splitting units from their corresponding readings.

## Configuration Settings
These configurations are written for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Adapts to the parameter density and specialized paragraph length of coating-related documents, and avoids splitting process windows or time-series data |
| `chunkSplitter` | Semantic chunking | Adapts to the structure of multiple document types, and avoids abrupt truncation of oven curve temperature sequences or parameter groups in process cards |
| `customPdfParse` | Enable structured parsing | Extracts parameters and batch information from table cells in PDF documents such as coating process cards and batch sheets |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Accommodates the need to upload multiple documents packaged for a single coating batch, and avoids upload failures due to oversized files |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Covers the parsing time of long time-series documents such as oven curves, and avoids parsing interruptions due to timeouts |
| `chunkSettingMode` | Manual configuration | Adjust chunking parameters for different document types, and balances parsing performance for structured tables and free text |

## Three Common Configuration Mistakes
- Issue: After uploading a coating batch sheet in CSV or Excel format, content such as batch numbers and viscosity parameters in the table cannot be fully extracted, or fields appear empty. Cause: The `customPdfParse` configuration is not enabled. The default parsing mode only extracts plain text, and does not recognize the binding relationship between table parameters and batches.
- Issue: When uploading an oven curve PDF file, a parsing timeout error is triggered, or the parsing result lacks the temperature change data from the latter segment. Cause: The `PARSE_FILE_TIMEOUT_SECONDS` value is not adjusted to suit long time-series documents, or the `chunkSize` setting is too small, leading to excessive chunking that exceeds parsing thresholds.
- Issue: After uploading multiple VOCs logs in bulk, vectorization takes too long, or a prompt for excessive system resource usage appears. Cause: The `chunkSize` is not adjusted to a reasonable range, leading to excessive chunking that increases embedding task volume, or `UPLOAD_FILE_MAX_SIZE` is not restricted, leading to oversized files consuming excessive parsing resources.

## How to Verify Correct Configuration
- Upload a coating process card PDF, and check if the parsed result fully extracts bound information such as coating batch numbers, film thickness requirements, and operating temperatures from the table, with no scattered text extraction.
- Upload an oven curve PDF with more than 10 pages, wait for parsing to complete, and check that no time-series data is truncated, and parsing time does not exceed the preset timeout threshold.
- Upload a single batch document package not exceeding 1000 MB, confirm that the upload and parsing processes do not trigger errors, and that chunked results retain contextual associations between batches and corresponding process parameters.
- For paint mixing records in CSV format, check that parsed fields include complete viscosity values and corresponding coating models, with no incorrect field splitting.

The values provided are common starting points, and should be validated against relevant sample datasets.
