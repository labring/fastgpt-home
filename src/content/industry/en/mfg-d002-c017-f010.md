# Drafting Process Documents and Exception Reports for Coating and Painting: Knowledge Base Retrieval and Recall

## What This Category of Data Looks Like
This category of data covers coating line scenarios including automobiles, home appliances, construction machinery, metal furniture, and similar use cases. Daily documents include coating process cards, paint batch sheets, paint mixing records, film thickness and color difference reports, oven curves, defect repair sheets, and VOCs ledgers. Data sources include TDS/SDS documents from paint suppliers, real-time collected data from spray booths and ovens, colorimeters, film thickness gauges, environmental monitoring equipment, and MES systems. Update frequency adjusts dynamically with each batch of paint delivery, each shift’s production progress, and continuous equipment collected data. Document fields include process parameters, batch numbers, test values, timestamps, and similar fields. Some fields have attached units, such as film thickness μm, color difference ΔE, and oven temperature ℃.

## What Constraints Do These Characteristics Impose on the Knowledge Base Retrieval and Recall Link
Documents in coating scenarios have diverse types and high parameter precision requirements. Accurate matching of process windows and defect correspondence is required, so retrieval must distinguish the weight of different document types. Real-time collected equipment data has a high update frequency, so retrieval must support incremental recall to avoid using outdated production parameters. A large number of test values with units in documents require retrieval to match parameter units and value ranges, to avoid invalid recall caused by cross-unit confusion. Drafting exception reports requires associating multi-source data, so retrieval must support cross-document associated recall, while controlling the number of returned results to fit the context length limit of the drafting scenario.

## How to Configure Settings
This configuration is based on FastGPT v4.17.0. Specific configuration items and their rationales are listed below:

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | Matches the precision requirement for coating process parameters and defect reports, to avoid mixing in low-relevance results |
| `limit` | `Top 8–12 entries` | Fits the context length of process documents and exception reports, controls the number of documents returned per retrieval round |
| `searchMode` | `keyword + semantic` | Balances keyword parameters (such as film thickness μm) in coating documents and semantic association requirements for defect analysis |
| `usingReRank` | `Enabled` | Performs secondary sorting on initial returned results by relevance, to improve the recall priority of documents related to defect repairs |
| `datasetSearchUsingExtensionQuery` | `Enabled` | Automatically expands retrieval terms, to cover associated fields of multiple document types including paint batch sheets and oven curves |
| `collectionIds` | `Configured according to the coating scenario-specific dataset` | Limits the retrieval scope to only process, test, and ledger documents of this category, to avoid interference from irrelevant data |

## Three Common Mistakes
- A retrieval prompt displays "No available channel for model gpt-4o-mini under group default". The cause is that no dedicated retrieval group is configured for the coating scenario-specific dataset, or the group is not bound to the corresponding model channel.
- Image links in the knowledge base appear as "input an image" in AI replies. The cause is that the external link generation configuration for document images is not enabled, or metadata parameters associated with the images are not carried during retrieval.
- No corresponding oven curve data is matched in retrieval results. The cause is that `datasetSearchUsingExtensionQuery` is not enabled, so expanded retrieval terms for oven temperature and curing parameters cannot be associated.

## How to Confirm the Configuration Is Complete
- Upload one coating process card and one oven curve document, perform a retrieval test, and check whether the returned results include the corresponding documents and meet expected relevance standards.
- View the retrieval log, confirm whether `usingReRank` is effective, and whether the returned results are sorted from highest to lowest relevance.
- Test retrieval with a parameter that includes units, such as "film thickness 15μm", and check whether corresponding film thickness and color difference report documents are matched.
- Check the `collectionIds` configuration for the dedicated dataset, confirm that the retrieval scope only includes documents of this category, with no irrelevant datasets included.

The values provided here are common starting points, and should be evaluated against the reader's own samples.
