# Drafting Process Documents and Exception Reports for Furniture and Wood Product Manufacturing: Source Citation and Traceability

## What the data for this category looks like
This category covers panel furniture, solid wood furniture, custom home goods, and door manufacturing enterprises. Data sources include order design systems, sheet material and wood batch ledgers, CNC cutting and drilling equipment logs, ERP/MES systems, and moisture content test records.
Daily documents include order disassembly drawings, cutting lists, edge banding and drilling programs, coating process documents, hardware matching lists, trial assembly records, and packaging records.
Data updates trigger per order, batch, or daily. Individual documents include fields such as panel dimensions, material batches, process parameters, and hardware models. Some documents include units like millimeters, kilograms, and percentage.

## Constraints on source citation and traceability
Custom order-driven multi-panel production requires traceability to accurately link each panel under a single order, preventing cross-order mix-ups.
Data from multiple sources is spread across different systems, so citations must match sheet material parameters and process requirements for the correct batch.
High-frequency order and batch updates require traceability links to associate real-time production logs and test results, avoiding outdated data use.
Precise fields like panel dimensions and hole positions require cited source data to retain all original fields, without losing key parameters.

## How to set configurations
The following configurations are formulated for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | This category’s process documents and exception reports contain many panel parameters and batch details. Sufficient context is needed to enable complete traceability |
| `responseData` | Return complete source file metadata | Traceability information such as sheet material batches and equipment logs must be linked. Complete metadata ensures citations can be traced |
| `detail` | Enabled | Original process parameters and test results must be restored to meet detailed traceability requirements for exception reports |
| Single search limit | Top 6 entries | This category has a high number of panels per order. Enough associated documents are needed to ensure comprehensive traceability |
| Maximum context length | `4000–6000 characters` | Multiple document types including order disassembly drawings and cutting lists must be integrated. This avoids truncating critical traceability information |

## Three common configuration errors
- Phenomenon: Cited source file metadata fields are missing in generated exception reports. Examples include missing sheet material batch numbers and order numbers. Cause: `responseData` is not configured to return complete metadata. Only text content is extracted, and key identifiers are not retained.
- Phenomenon: Search returns too few associated documents to cover process data for all panels under a single order. Cause: The single search limit is set too low, not matching the multi-panel, multi-source document characteristics of this category.
- Phenomenon: Process document drafting requests time out, and complete cited content is not returned. Cause: `quoteMaxToken` is set beyond the system’s processing threshold, leading to excessive context loading time.

## How to verify configuration validity
- Generate a process document drafting request that includes panel parameter queries. Check if returned results include metadata fields such as sheet material batches and order numbers to confirm the configuration is active.
- Input a query covering multi-panel information. Confirm the number of returned search results matches the set single search limit to verify the configuration aligns with business needs.
- Check for context truncation prompts during generation. Confirm that `quoteMaxToken` and maximum context length settings fit document lengths.
- Simulate a traceability request for full data of a single order. Verify that metadata for all associated documents is correctly cited to ensure a complete traceability link.
