# Process Document and Abnormal Report Drafting for Process Change and Engineering Change: Model Access and Configuration

## What this category's data looks like
This category of data is generated by manufacturing enterprise change management teams. It covers documents including ECN/ECR, change assessment forms, drawings and BOM versions, process verification reports, switching plans, inventory disposal documents, and more. Data sources include PLM, ERP, MES systems, supplier materials, verification test records, and customer special requirements. Updates are triggered irregularly with each change. Documents contain design/material/process related fields, version numbers, verification status, approval nodes, and other content. There is no unified fixed unit, and adjustments are made based on the corresponding business links.

## Constraints on model access and configuration from this category's data characteristics
The data characteristics of this category impose multiple constraints on model access configuration. Data sources cover multiple business systems, and formats include structured fields and semi-structured documents. Configuration must support format adaptation and field mapping for multi-source data. Updates are triggered irregularly with changes, and single data volume fluctuates significantly. It is necessary to preset flexibly adjustable context parameter limits to avoid processing timeouts. Documents include key business fields such as version numbers and verification status. Model output must accurately associate with corresponding fields, so parameters need to be adjusted to control output accuracy. At the same time, the consequences of change errors are severe. Traceability binding functions must be configured to ensure that output content can be associated with original document sources.

## How to set the configuration
| Configuration Item | Recommended Setting | Basis for This Setting |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | The total document length involved in a single change for this category fluctuates greatly, covering content exported from multiple systems, requiring adaptation to different data volumes |
| `temperature` | `0.1–0.3` | Ensure that generated process documents and abnormal report content accurately match business fields, avoiding redundancy or deviation |
| `quoteMaxToken` | `2000–3000 token` | Retain sufficient original document reference details to meet traceability requirements for change verification |
| `AIPROXY_API_ENDPOINT` | `http://{Local IP}:{Port}/v1/chat/completions` | Adapt to local large model access requirements and resolve cross-network access restrictions |
| `AIPROXY_API_TOKEN` | Token value assigned by the proxy platform | Verify the legality of access identity |
| Workflow/API tool selection | `auto` | Automatically call document parsing tools to adapt to different formats of multi-source data |

## Three common mistakes
- Phenomenon: A connection error is returned during calling, with status code 500 or request timeout. Cause: The local address of `AIPROXY_API_ENDPOINT` is not filled in correctly, or the network access permission of the corresponding port is not enabled.
- Phenomenon: The generated process document does not associate original document references, and the reference fields are empty. Cause: The binding configuration of the `quoteMaxToken` parameter is not enabled, or the parameter value is too small to retain reference details.
- Phenomenon: The generated change report content has large deviations and includes irrelevant business fields. Cause: The `temperature` parameter value is too high, causing the model output to deviate from business field requirements.

## How to confirm the configuration is complete
- In FastGPT v4.17.0, after filling in `AIPROXY_API_ENDPOINT` and `AIPROXY_API_TOKEN`, run the connection test to confirm that a normal model response is returned.
- Upload an ECN document and a process verification report, trigger the drafting process, and check whether the generated content includes key fields such as document version numbers and verification status.
- View the reference module of the generated result to confirm that the original document fragment content has been associated and the reference details are complete.
- Adjust the `temperature` parameter to 0.2, generate the change report again, and compare the differences between the two outputs to confirm that the parameter configuration takes effect.

The values provided here are common starting points and should be measured against the reader's own samples.
