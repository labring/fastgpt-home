# Process Change and Engineering Change: Process Document and Abnormal Report Drafting - Knowledge Base Retrieval and Recall

## What Data for This Category Looks Like
Manufacturing enterprise R&D, process, quality, production, and procurement teams collaboratively generate data for this category. Daily documents include ECN/ECR forms, change assessment reports, drawings and BOM version files, process validation reports, production switching plans, inventory disposal documents, and customer approval documents. Data sources cover PLM, ERP, MES systems, supplier materials, validation test records, and customer-specific requirements. Updates occur irregularly with each change. Individual documents include change reason, impact scope, version information, and validation results. No unified fixed unit exists. Fields and units vary based on document type.

## What Constraints These Characteristics Impose on the Knowledge Base Retrieval and Recall Link
This category’s data comes from multiple systems and has no fixed update cycle. Knowledge base retrieval must support cross-source associated data recall. Documents have diverse types and include professional technical fields and associated information. The retrieval system must support fuzzy matching and multi-dimensional keyword recall. Document updates triggered by each change are irregular. Teams must implement an incremental synchronization mechanism to ensure data timeliness. Change scenarios require quick location of chain-effect related documents such as BOM and process validation reports. Recall results must cover cross-document associated information.

## Configuration Settings
This document is written based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | This category of documents contains professional technical fields and associated information. This range filters irrelevant results while retaining core associated content |
| `limit` | `Top 8–12 results` | Change scenarios require coverage of multi-dimensional associated documents. This quantity balances context length and information completeness |
| `searchMode` | `mixedRecall` | Balances keyword matching of change-related terms and vector recall of semantically associated cross-system documents |
| `usingReRank` | `Enabled` | The association relationships of documents in this category are complex. Reranking improves the ranking priority of highly associated results |
| `datasetSearchUsingExtensionQuery` | `Enabled` | Expands the retrieval scope to cover implicitly associated terms in change scenarios, such as material replacement information corresponding to process changes |
| `collectionIds` | `Bind the corresponding knowledge base collection related to change management` | Precise limitation of the retrieval scope to avoid irrelevant documents interfering with recall results |

## Three Common Mistakes
- Calling the FastGPT knowledge base interface returns an `Error: write EPROT` or `Query read timeout` error. Cause: Interface timeout parameters are not configured correctly, or HTTPS certificate verification is not handled during cross-system calls.
- Passing a knowledge base ID externally results in no returned search results. Cause: The target document collection is not bound to the specified `collectionIds` parameter, or the configured `similarity` threshold is too high and filters valid results.
- Recall results do not cover cross-system associated BOM or process validation documents. Cause: The `datasetSearchUsingExtensionQuery` configuration is not enabled, and only documents within a single knowledge base collection are retrieved.

## How to Confirm Proper Configuration
- Call the knowledge base retrieval interface, pass test keywords for change scenarios, and check whether returned document types include core category documents such as ECN/ECR and BOM version files.
- Check the number of interface returned results to confirm alignment with the configured `limit` parameter value range.
- Verify that returned result similarity scores fall within the preset `similarity` range.
- Confirm that enabling `usingReRank` places highly associated change-related documents at the top of results.

The values provided are common starting points and should be measured against the reader's own samples.
