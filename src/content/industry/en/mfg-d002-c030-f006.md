# Process Document and Exception Report Drafting for Rubber Compounding and Product Vulcanization: Source Citation and Traceability

## What this category of data includes
The primary entities for this category are tire, seal, hose, and rubber product manufacturers. They generate daily documents including formula sheets, weighing records, mixing curves, rubber quick test results, vulcanization process cards, mold records, and finished product performance reports.
Data sources cover formula systems, raw material batch ledgers, internal mixers, Mooney viscometers, rheometers, vulcanizers, and laboratory testing equipment.
Manufacturers create one associated document for each raw material batch, each batch of mixed rubber, and each vulcanized product per mold cycle. Document fields include dedicated units such as mass parts, degrees Celsius, and minutes. Every document binds to a unique batch number or mold cycle identifier.

## Constraints these characteristics place on source citation and traceability
High-frequency multi-source data updates demand that traceability links accurately bind unique identifiers. This prevents mixing of data from different batches and mold cycles.
Decentralized storage across multiple data sources requires traceability systems to correlate documents from different systems such as formula systems, device logs, and laboratory reports. Systems must uniformly match batch numbers or mold cycle identifiers.
Dedicated fields and units require teams to retain original unit information during citation. This avoids ambiguity around process parameters.
Severe potential consequences require traceability chains to reach back to original production data. Fuzzy document fragments cannot serve as a basis for traceability.

## How to Configure Settings
This configuration is adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum Context | 8000–12000 characters | Matches the total length of multiple documents related to a single batch of mixing or vulcanization. Prevents truncation of critical traceability information |
| Single Recap Limit | Top 8 entries | Corresponds to the number of associated documents generated per mold cycle or batch. Covers all associated data without exceeding context limits |
| `quoteMaxToken` | 1500 token | Ensures complete retention of original data fields for each traceability citation, such as mixing ratios and temperatures, without truncation |
| `responseData` | Only return documents bound to batch numbers | Filters irrelevant data. Focuses on raw material and device batches corresponding to the current process or exception report |
| `detail` | High recall granularity | Matches fine-grained fields of single device records and weighing records. Supports precise traceability to single mold cycle operations |

## Three Common Mistakes
- Symptom: After deploying FastGPT locally, checking the knowledge base disk usage shows a value that does not match the total size of the uploaded rubber category documents. Cause: `responseData` is not configured correctly to only associate target category documents. This leads to inclusion of unrelated non-rubber mixing data, which uses additional disk space.
- Symptom: When generating process documents with cited traceability, raw material batch numbers or internal mixer numbers are not displayed. Cause: The `detail` high recall granularity setting is not enabled. Unique identifier fields from formula systems or device logs are not captured.
- Symptom: Complete mixing curve data cannot be retrieved after generating an exception report. Cause: `quoteMaxToken` is set too small. Critical timestamp and temperature parameters from the curve are truncated, leading to incomplete traceability information.

## How to Verify Correct Configuration
- Import a valid mixing curve document and the corresponding batch formula sheet. Trigger process document generation. Check that the cited content includes raw material batch numbers and internal mixer numbers.
- Check the local knowledge base disk usage statistics. Confirm that only target category documents such as formula sheets, mixing curves, and vulcanization process cards are included.
- Generate a report describing an under-vulcanization exception. Check that the cited mixing curve data displays complete time and temperature fields.
- Adjust `quoteMaxToken` to a smaller value. Verify that field truncation prompts appear. Confirm that the current setting meets requirements.

The values provided are common starting points. They should be evaluated against the reader's own samples.
