# Heat Treatment: Process Document and Exception Report Drafting: HTTP Interfaces and External Systems

## What data for this category looks like
Data for this category comes from material grade archives, temperature control instruments, furnace temperature uniformity testing equipment, hardness testers, metallographic analyzers, and workshop MES systems. Data updates occur per furnace run or production batch. Core documents include heat treatment process cards, charging charts, furnace temperature curve reports, hardness and metallographic inspection reports, equipment inspection forms, and exception handling forms. Fields include furnace temperature range (unit: ℃), holding time (unit: minutes), material grade, hardness value (unit: HRC), defect type, corrective actions, and more. The data volume of a single document changes based on the number of inspection items.

## What constraints these characteristics impose on the HTTP Interfaces and External Systems link
Per-furnace personalized data requires interfaces to support single-furnace or small-batch calls. This avoids exceeding device response limits. Multi-source heterogeneous data formats require interfaces to be compatible with return structures from different devices. Field mapping must be used to complete standardization. High-frequency data updates require interfaces to have low-latency response capabilities. Interfaces must also support a failure retry mechanism to handle temporary device fluctuations. The combination of fixed document fields and dynamic inspection items requires interface extraction logic to flexibly adapt to new inspection items. This ensures field completeness for process documents and exception reports.

The following configurations apply to FastGPT v4.17.0.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Request timeout | 30–60 seconds | Adapt to the response duration of single-furnace device data collection |
| `Authorization` | Use system-generated Bearer tokens | Ensure compliance of external interface access permissions |
| `variables` | Bind entity variables such as furnace number and material grade | Match personalized process parameters for each furnace run |
| `responseData` | Extract fields including furnace temperature average, hardness value, and exception flag | Correspond to core data of process documents and exception reports |
| Retry trigger threshold | 2 consecutive failed requests | Prevent task interruptions caused by temporary device fluctuations |
| Single file upload limit | 1000 MB | Adapt to large-size documents such as charging charts and metallographic reports |

## Three common configuration errors
- Phenomenon: HTTP interface calls return empty fields or extraction errors. Cause: Target fields are not specified via the `responseData` configuration, or parameters bound via `variables` do not match the interface return format.
- Phenomenon: Uploading heat treatment process files or exception reports fails, but template import functions normally. Cause: The file upload interface path and access permissions are not configured correctly, or the file size exceeds system limits.
- Phenomenon: Interface requests frequently time out. Cause: The request timeout is set too short, and does not match the actual time required for heat treatment device data collection.

## How to confirm correct configuration
- Call the test interface, check if the returned `responseData` includes preset core fields such as furnace temperature and hardness.
- Upload a single heat treatment process card, confirm that the file can be parsed normally and synchronized to the external system.
- Simulate a single-furnace exception scenario, trigger the exception report drafting process, confirm that the exception flag returned by the interface is correctly extracted.
- Check the validity period of the `Authorization` token, confirm that the external interface access permission has not expired.

The values provided are common starting points and should be measured against the reader's own samples.
