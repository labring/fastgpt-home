# Heat Treatment Process Document and Abnormal Report Drafting: Citation Source and Traceability

## What Data for This Category Looks Like
Data for this category comes from material grade standards, customer technical requirements, temperature control instruments, furnace temperature uniformity test results, hardness tester and metallographic equipment test data, and MES systems. Daily generated documents include heat treatment process cards, charging charts, furnace temperature curves, hardness and metallographic reports, equipment inspection forms, and abnormal disposal forms. Data is updated per heat batch and per production lot. Each document includes fields such as heating, holding, and cooling parameters, charging position records, test values, and abnormal disposal procedures. Units include temperature (℃), time (hours), hardness (HV), and others. Only minor changes are made to workpiece geometry. The core focus is adjusting material microstructure and mechanical properties.

## Constraints on Citation Source and Traceability
This category has high data update frequency. New process and test data is generated for each heat batch. Citation and traceability workflows must link to real-time latest data such as furnace temperature curves and hardness test results to avoid using expired information. Daily document types are diverse, with significant differences between their fields. Precise matching of exclusive fields for different documents is required. For example, the heating and holding parameters of a process card and the measured temperature of a furnace temperature curve must be traced separately. Data sources cover multiple channels including equipment instruments, customer requirements, and MES systems. Clear distinction of credibility levels for each source is needed to ensure cited content aligns with original basis. Additionally, traceability for abnormal reports must link to the complete process of abnormal disposal forms, providing a complete evidence chain for subsequent failure analysis.

## Configuration Settings
This configuration is based on the logic of FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Core heat treatment documents are typically 500–1000 tokens in length. This setting fully covers core content such as process parameters and test data. |
| `responseData` | Return all original fields of associated documents | All original test data including furnace temperature and hardness must be retained to meet field verification needs during traceability. |
| `detail` | Enabled | Specific document type, generation time and source identifier of cited documents must be displayed to clarify traceability basis. |
| Maximum number of citations | `Top 3–5 entries` | The number of documents related to a single heat batch is limited. Excessive citations will disrupt core logic. Prioritize the most relevant core documents. |
| Citation source display | Display document type and generation time | Help quickly distinguish traceability bases such as process cards and furnace temperature curves. |

## Three Common Configuration Errors
- Setting `quoteMaxToken` to 3, but more than 3 cited documents are returned. Cause: Citation configuration parameters are not uniformly passed in the multi-branch workflow. Different knowledge base call branches use the default citation limit.
- Citation result sorting does not meet business expectations. Cause: No configuration for sorting by document type priority. Only default similarity sorting is used, which does not match the heat treatment scenario’s requirement to prioritize furnace temperature curves and process cards.
- Key test fields in citation sources are empty. Cause: The `detail` parameter is not enabled, so specific test values and generation information of original documents are not returned. Traceability verification cannot be completed.

## How to Verify Correct Configuration
- Initiate a simulated heat batch abnormal query, verify that the number of returned cited documents matches the configured `quoteMaxToken` value.
- Review the displayed citation source content, confirm that it includes document type, generation time and original test fields to meet business traceability requirements.
- Switch between different knowledge base branch calls, confirm that citation configuration parameters are uniform across all branches with no discrepancies.
- Test turning off the citation display switch, confirm that the citation source module is no longer displayed in the conversation interface.

The values provided are common starting points and should be measured against the reader's own samples.
