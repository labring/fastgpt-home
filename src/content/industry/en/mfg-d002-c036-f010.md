# Drafting Process Documents and Exception Reports for Welded Structural Component Manufacturing: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Welded structural component manufacturing core data covers end-to-end documents for enterprises producing steel structures, pressure vessels, construction machinery, and rail vehicle structural components. This includes welding procedure qualifications, welding process specifications, filler metal issue records, welder qualification records, weld inspection reports, and repair orders. Data sources include design drawings, material quality certificates, welding equipment parameters, filler metal warehouses, non-destructive testing systems, and personnel qualification ledgers. Data updates trigger with each weld, batch of materials, or shift production cycle. Individual documents contain clear fields such as process parameters, qualification numbers, and test results, with no redundant or ambiguous items.

## What constraints these characteristics impose on knowledge base retrieval and recall
Data for this category mostly comes from heterogeneous systems, and update frequencies trigger with production nodes. Retrieval links must support real-time incremental synchronization. Documents contain rigid constraint fields such as welder qualification numbers, procedure qualification numbers, and weld test parameters. Retrieval must accurately match fields, using field-specific matching logic. Individual data points have strong correlation. Retrieval results must cover process, qualification, and test dimensions of information. This avoids issues where single-dimensional recall leads to mismatched processes and qualifications. At the same time, data failure directly causes structural failure risks. Recall result confidence must match business rigid constraints.

## How to set configurations
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | Process parameters and qualification numbers for welded structural components require precise matching. This interval filters irrelevant results while retaining valid matching entries |
| `limit` | `Top 6 entries` | Process, qualification, and test data volumes for single production batches are concentrated. 6 results cover core associated information without exceeding the context window |
| `searchMode` | `Precise Matching` | Category documents contain rigid constraint fields. Precise matching avoids mismatched qualifications and process parameters |
| `usingReRank` | `Enabled` | Semantic similarity of multi-source heterogeneous data requires secondary calibration to improve result ranking accuracy |
| `datasetSearchUsingExtensionQuery` | `Enabled` | Can expand process queries into associated qualification and test queries, covering end-to-end process data |
| `collectionIds` | `Bind dedicated welded structural component dataset` | Isolate data from other categories to avoid irrelevant documents interfering with retrieval results |

## Three common mistakes
- Symptom: A `Validation failed: name: Path 'name' is required` error is returned when calling the knowledge base for generation. Cause: The dedicated welded structural component dataset has not been configured with required name metadata fields, or imported documents do not carry corresponding identification information.
- Symptom: An error appears when viewing knowledge base citations in chat responses. Cause: Document metadata from retrieval results was not fully retained, or original document association identifiers are lost after `usingReRank` is enabled.
- Symptom: Retrieval results do not cover filler metal warehouse data such as consumable issue records. Cause: The dataset collection corresponding to the filler metal warehouse was not added to the `collectionIds` configuration, leading to restricted retrieval scope.

## How to confirm configurations are set correctly
- Submit a query that includes a welder qualification number. Verify that retrieval results include the corresponding welder qualification record and welding procedure qualification document.
- Trigger an incremental synchronization. Confirm that new data from filler metal warehouses and non-destructive testing systems is covered by retrieval within the preset synchronization cycle.
- View retrieval logs. Confirm that actual values for configuration items such as `similarity` and `limit` match preset values.
- Test the operation to hide knowledge base citations as needed. Confirm that response citation display status can be adjusted according to requirements.

The values provided are common starting points and should be measured against the reader's own samples.
