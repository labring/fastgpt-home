# Process Document and Exception Report Drafting for Biologics and Aseptic Manufacturing: Source Citation and Traceability

## What This Category’s Data Looks Like
This category’s data covers the full production lifecycle of vaccines, antibodies, blood products, and sterile injectables. Daily documents include cell bank and master seed batch records, culture and purification records, aseptic filling records, environmental monitoring data, media fill simulation results, sterility test reports, and batch release documents.
Data sources include cell bank and seed batch ledgers, process analytical data, cleanroom monitoring results, MES systems, LIMS systems, and equipment integrity test records. Update cadences follow per-batch production, real-time monitoring, and fixed monitoring plans. Each document includes fields such as batch number, process parameter thresholds, test results, operator, and collection timestamp.

## Constraints Imposed on Source Citation and Traceability by These Characteristics
Dispersed multi-source data, batch-bound properties, and compliance requirements create multiple constraints for citation and traceability.
First, data is linked to production stages within a batch. Matching batch numbers can help associate source data and reduce cross-batch confusion.
Second, update cadences cover real-time, per-batch, and fixed-cycle updates. Retrieval priority can be adjusted by data type to help return content for the corresponding production stage.
Third, documents include process parameters and compliance records. Retaining original fields, units, and traceability details helps reviewers verify cited content.
For biologics and aseptic manufacturing, finished-product sampling should be considered alongside process records and risk assessment. Traceability can cover relevant production stages; missing data or an incorrect trace may make investigations more difficult and affect safety-risk assessment.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | This category’s process and test documents include long parameter records. Sufficient context must be retained to fully present cited content |
| `responseData` | `Return full field content of original sources` | Compliance traceability fields such as batch number, collection time, and operating subject must be fully retained to meet production compliance requirements |
| `detail` | `Enable traceability detail display` | The source system, test link, and collection time of original data must be fully labeled to support rapid location of abnormal root causes |
| Single Search Limit | `Top 5–7 results` | The volume of data associated with a single batch is limited. Too many retrieved results will dilute the relevance of core cited content |
| Context Cache Duration | `Match the corresponding production batch cycle` | Data is updated per batch. Cache duration must align with production rhythm to avoid citing expired data |

*Note: The above configurations are based on the interface logic of FastGPT v4.17.0.*

## Three Common Configuration Errors
- The {{id}} field of cited content displays as empty or points to a file collection ID from a non-current batch. Retrieval conditions are not bound to production batches. The unique ID of a single data entry is confused with the overall file collection ID of the knowledge base. The batch number is not configured as a retrieval filter parameter.
- After enabling variable reference mode, the model temperature setting button disappears and cannot be adjusted. The interface configuration for variable reference mode does not retain the model parameter entry. The global parameter setting panel is not loaded synchronously.
- The number of returned citation results does not match expectations, or duplicate data appears. The retrieval limit is not adjusted based on the volume of data associated with a single batch for this category. Retrieval rules do not exclude redundant cross-batch data.

## How to Confirm Proper Configuration
- Generate an exception report drafting request. Check whether the cited content includes all required fields for the current batch, such as batch number, collection time, and operating subject.
- View the citation traceability module. Confirm that each cited entry is labeled with the source system and test link of the original data, with no missing information.
- Test the model parameter settings in variable reference mode. Confirm that configuration items such as temperature can be adjusted normally and take effect.
- Retrieve associated data for a specified batch. Confirm that retrieved results only include valid data for the current batch, with no cross-batch redundant content.

The values provided are common starting points and should be measured against the reader's own samples.
