# Drafting Process Documents and Exception Reports for Electric Motor and Generator Manufacturing: Workflow Orchestration

## What Data Looks Like for This Category
Data for this category comes from electromagnetic design databases, copper wire and insulation material batch ledgers, winding equipment logs, balancing machine operation records, electrical test bench test data, and ERP/MES systems. Documents generated daily include winding process cards, insulation treatment records, dynamic balance reports, dielectric strength test reports, and type and factory inspection reports. Data is updated after each finished product or production batch, and related documents are updated synchronously when product type changes occur. Document fields include winding turns, insulation layer thickness, dynamic balance deviation value, dielectric strength test voltage, test environment temperature, and more. Some documents must be associated with corresponding batch raw materials and equipment parameters.

## What Constraints These Characteristics Impose on Workflow Orchestration
Data sources for this category are scattered but closely interconnected. Workflow orchestration must connect multiple heterogeneous data source nodes to ensure cross-system synchronization of core fields such as winding turns and insulation parameters. Data is updated after each finished product or production batch, and adjusted when product types change. The workflow must bind batch IDs and change identifiers in `variables` to trigger generation and updates of corresponding documents. Professional document fields include electromagnetic, mechanical, and electrical professional parameters. Field validation rules must be configured to prevent non-standard values from entering the process. Exception reports must be associated with multi-stage test data. The workflow must connect test, record, and process review nodes in sequence to ensure complete exception analysis. The most time-consuming winding turns verification step requires a dedicated verification step configured in the workflow to reduce manual verification costs.

## How to Set Configurations
| Configuration Item | Recommended Approach | Rationale |
|---|---|---|
| `variables` | Bind production batch number, material batch number, test date | Data is updated per unit or batch, so core identifiers for associated production and testing stages must be bound |
| Node Trigger Rule | Trigger after the electrical test bench data upload is complete | Exception reports are generated based on complete test data, all test data must be fully aggregated first |
| Field Validation | Validate the valid ranges of winding turns, insulation layer thickness, and dynamic balance deviation value | Professional document fields must comply with motor manufacturing process specifications to prevent non-standard parameters from entering the workflow |
| `nodeId` | Bind dynamic balance report and dielectric strength test report nodes | Exception analysis requires structured data from both types of reports, corresponding data must be accurately retrieved via node ID |
| Timeout Setting | 900–1500 seconds | FastGPT v4.17.0 supports custom timeout configurations. Multi-stage data aggregation and document generation require longer processing time; adjust values based on actual measurement calibration |

## Three Common Misconfigurations
- Symptom: When the workflow calls a chart tool to generate a winding parameter comparison chart, the output result is empty. Cause: The corresponding batch core parameters such as winding turns and test voltage are not bound in `variables`, so the tool cannot obtain valid data sources.
- Symptom: After the workflow configures field validation rules, a 400 error is triggered. Cause: The validation rule references a field that is not defined in the current workflow node, resulting in failed parameter validation.
- Symptom: Dynamic balance test data is missing from the generated exception report. Cause: The dynamic balance report node is not bound via `nodeId`, so corresponding structured test data cannot be retrieved.

## How to Verify Proper Configuration
- Manually trigger the workflow, check whether the production batch, test date and other parameters bound in `variables` are correctly synchronized to each stage node.
- Run the field validation rule, input parameter values that comply with motor manufacturing process specifications, and confirm that no validation error is triggered.
- Call the chart tool node, verify that the winding parameter comparison chart for the corresponding batch can be generated.
- Trigger the exception branch workflow, confirm that the exception report can automatically associate structured data from dynamic balance and dielectric strength tests.

The values provided are common starting points and should be measured against the reader's own samples.
