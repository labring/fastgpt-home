# Drafting Process Documents and Exception Reports for Electric Motor and Generator Manufacturing: Tool Calling and Plugins

## What data for this category looks like
This category of data comes from motor factory winding, insulation, final assembly, and testing departments. Daily documents include winding process cards, insulation treatment records, dynamic balance reports, voltage withstand insulation test records, and type and factory inspection reports. Data sources include electromagnetic design data, copper wire and insulation material batch information, winding equipment, balancing machines, electrical test benches, and ERP/MES systems. Updates trigger per product, per production batch, or each time a design change is made. Documents include fields such as winding turns, wiring methods, paint dipping parameters, test voltages, and temperature rise data. Some fields require matching with equipment operation logs and material batch information.

## What constraints these characteristics impose on tool calling and plugin workflows
The multi-source nature of category data requires tool calling to support format alignment between device logs, ERP data, and document text. This prevents cross-system field mismatches. High-frequency updates per unit or batch require plugin calling to support real-time pulling of the latest batch material and test data. Static caching cannot be relied on. The professional nature of document fields—such as voltage units for voltage withstand insulation tests, unbalance parameters for dynamic balance tests—requires tool calling to match specific field mappings. This avoids field adaptation deviations from general-purpose plugins. Updates triggered by design changes require plugins to support dynamic adjustment of calling logic. This adapts to new process parameters and test standards.

## Three common configuration mistakes
- An AxiosError 404 occurs when calling a plugin. The cause is failing to configure the plugin's target interface address to the actual domain name of the enterprise's internal equipment or MES system, and using an example domain name by mistake.
- A BI chart plugin returns empty fields. The cause is failing to configure field mapping rules that match motor test data. General-purpose plugins cannot recognize professional fields such as withstand voltage and dynamic balance values.
- Tool call times out. The cause is setting an overly short timeout period that does not adapt to data pulling delays from equipment such as electrical test benches. This causes the call to terminate before data pulling is complete.

## How to verify a complete configuration
Based on FastGPT v4.17.0, configuration can be verified through the following actions:
- Upload a winding process card and a dynamic balance report, initiate the question "Generate an exception report for this product", and check whether the device data returned by tool calling matches the fields in the uploaded document.
- View the plugin call log, confirm that the domain name of the interface request matches the actual address of the enterprise's internal equipment system, with no remaining example domain names.
- Simulate an anomaly scenario, initiate a call request, and confirm that the tool call duration does not exceed the configured timeout period, with no timeout error.
- Test multiple tool calls, confirm that the single call limit is not exceeded, with no call interception prompts.
