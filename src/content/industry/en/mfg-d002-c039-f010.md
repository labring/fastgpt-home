# Process Document and Abnormal Report Drafting for Electric Motor and Generator Manufacturing: Knowledge Base Retrieval and Recall

## What this category of data looks like
Data for this category comes from the winding, insulation, final assembly, and testing departments of electric motor factories. Daily documents include winding process cards, insulation treatment records, dynamic balance reports, voltage withstand insulation test records, and type and factory inspection reports. Data sources include electromagnetic design data, copper wire and insulation material batch records, winding equipment logs, balancing machine data, electrical test bench results, and ERP/MES systems. Updates are triggered per product, per batch, or for each type change. Documents contain clear process parameters, test values, and batch information, with most fields including units such as number of turns, insulation resistance value, and vibration amplitude.

## What Constraints These Characteristics Bring to Knowledge Base Retrieval and Recall
The multi-source nature of this category’s data requires retrieval to cover data sources in different formats, including equipment logs, ERP data, and test reports. It must accurately match fields with units such as batch numbers and process parameters. High-frequency updates per unit or batch mean recall results must be linked to the latest batch information in real time, to avoid using expired process parameters. The professional nature and strict field requirements of the documents mean retrieval should prioritize matching precise process cards and test report content. Retrieval results for abnormal reports must also directly link to production data for the corresponding batch, to avoid generic irrelevant content disrupting drafting work.

## How to Configure the Setup
This document is written based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `similarity` | 0.75–0.85 | Matches professional documents with clear parameters such as winding process cards and test reports, prevents low-relevance results from being included |
| `limit` | Top 6 entries | Covers multiple related documents for a single electric motor, such as process cards, test records, and abnormal reports, prevents excessive results from exceeding context limits |
| `searchMode` | `fullTextRecall` | The query examples emphasize identifiers or specialist terms; test this mode with representative data, not as a product default. |
| `usingReRank` | Enabled | Re-ranks recalled results by relevance to abnormal report drafting, raises the priority of professional content |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands associated query terms such as batch numbers and equipment models, covers multi-source production data |
| `collectionIds` | Bind corresponding knowledge bases by department | Limits retrieval scope to exclusive documents from the winding, insulation, and testing departments, prevents cross-category data from causing interference |

## Three Common Mistakes
- An empty result is returned when calling the file list interface. The cause is that the correct `collectionIds` parameter is not specified, and the retrieval target knowledge base scope is not limited, so the system fails to match documents from the corresponding department.
- An "incorrect file format" error is returned on the interface when uploading a docx document containing images. The cause is that the image extraction configuration during document parsing is not enabled, so the system cannot recognize docx format content with images.
- Request timeout occurs when downloading knowledge base files in batches. The cause is that a reasonable `limit` parameter is not set, recalling too many documents at once causes the request to exceed the response time limit.

## How to Confirm the Configuration Is Correct
- Submit a retrieval request containing professional keywords such as "winding turns" and "insulation resistance", verify that the returned results include category-specific documents such as winding process cards and dynamic balance reports.
- Upload a docx document containing images, confirm that no format error prompt appears on the interface, and the document can be parsed normally.
- Call the file list interface, pass the specified `collectionIds`, and verify that document entries from the corresponding department are returned.
- Submit a retrieval request for abnormal report drafting, verify that the re-ranked results first display professional parameter content matching the current abnormal type.
