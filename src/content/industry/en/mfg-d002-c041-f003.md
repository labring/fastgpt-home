# Process Document and Abnormal Report Drafting for Electroplating and Chemical Surface Treatment: Multi-turn Dialogue and Prompt Engineering

## Data Overview for This Category
Data for this category mainly comes from customer surface treatment specifications, tank solution test records, rectifier operation data, online water quality monitoring results, and hazardous waste management ledgers. Daily generated documents include tank solution analysis records, process parameter cards, fixture ledgers, film thickness and adhesion reports, hazardous waste disposal records, and wastewater monitoring reports. Data update frequencies cover per tank batch, per shift, and fixed monitoring cycles. Document fields include tank solution composition parameters, current and temperature values, fixture usage status, film thickness test results, discharge indicators, and some fields have dedicated units.

## Constraints Imposed on Multi-turn Dialogue and Prompt Engineering
Data for this category has high update frequency and covers multiple business scenarios. Multi-turn dialogue must support real-time calls to the latest tank solution test and online monitoring data to avoid generating documents using outdated parameters. Document fields include professional process parameters and compliance indicators. Prompts must clearly define the types and field ranges of recalled documents to prevent mixing in irrelevant data. Data from different sources has large format differences. The dialogue flow must adapt to different structures such as single-tank batch data from tank solution records and periodic summary data from hazardous waste ledgers, to ensure that the generated content fields match business requirements.

The following configurations are based on FastGPT v4.17.0.

## How to Configure
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chatId` | Automatically generated per conversation session | Binds exclusive data context for a single tank batch or single order, avoids cross-session data confusion |
| `messages` | Retain the most recent 20 rounds of conversation content | Adapts to multi-turn iteration needs for process adjustments, retains parameter modification history |
| `variables` | Bind exclusive variables such as tank solution test and online monitoring data | Automatically calls real-time data for the current batch, reduces manual input |
| Single recall limit | Top 8 entries | Matches the average number of documents per batch for this category, avoids interference from redundant data |
| Context window size | 8000–12000 token | Adapts to the total number of fields and parameters across multiple document types, ensures complete recall of key information |
| Prompt template | Restrict use of only specified documents such as tank solution analysis records and process parameter cards | Aligns with the business document types for this category, ensures generated content complies with requirements |

## Three Common Misconfigurations
- Symptom: Knowledge base association errors appear during dialogue, no issues in preview mode. Cause: Failed to restrict calls to only the category-exclusive tank solution and wastewater monitoring documents, mixing in irrelevant cross-category knowledge base data.
- Symptom: Generated process documents have missing fields or incorrect units. Cause: The prompt failed to explicitly specify matching dedicated parameter formats, and did not restrict document field ranges.
- Symptom: Generated content lags or is truncated after multiple turns of dialogue. Cause: Did not limit the number of conversation rounds retained in `messages`, leading to context window overload.

## How to Verify Proper Configuration
- Launch a test dialogue, enter the tank solution parameters for the current tank batch, and verify whether the generated process document automatically calls the corresponding data.
- View the conversation context panel, confirm that `chatId` is bound to the exclusive identifier for the current session, and there is no confusion with other sessions.
- Trigger abnormal report generation, check that the recalled documents only include specified types such as tank solution analysis and wastewater monitoring for this category.
- Adjust the number of conversation rounds to more than 20, confirm that no context window overflow prompt appears, and the generation process runs normally.

The values provided are common starting points and should be evaluated against the reader's own samples.
