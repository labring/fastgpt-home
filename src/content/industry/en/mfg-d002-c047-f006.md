# Process Document and Abnormal Report Drafting for Measuring Instruments and Laboratory Management: Source Citation and Traceability

## What This Category of Data Entails
This category of data originates from daily business documents of enterprise metrology rooms and CNAS system laboratories. It includes gauge ledgers, calibration plans, calibration certificates, periodic verification records, original test records, reference material ledgers, and deviation handling documents.
Data sources include internal enterprise metrology management systems, external calibration institution certificates, standard devices, LIMS systems, and environmental monitoring data. Updates trigger on calibration cycles, completion of single tests, or abnormal events.
Documents contain fields such as instrument number, measured value, uncertainty, and calibration date. Units cover all metrology scenarios based on the measured object.

## Constraints Imposed on Source Citation and Traceability
Traceability requirements for this data category require linking multi-source business data. The system must support precise cross-knowledge base matching.
Data updates follow no fixed cycle. An incremental indexing mechanism must be configured to maintain timeliness of traceability information.
Documents include high-precision measurement data and uncertainty fields. Accuracy demands for cited content are strict. Irrelevant search results must be filtered out.
Abnormal reports and process documents require a complete traceability chain. The number of cited entries and length of single citations must be limited. This prevents context overload that degrades generation quality.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Maximum Context | 8000–12000 token | Metrology documents include long texts such as calibration certificates and original records. Full loading of traceability chain associated data is required |
| Maximum Knowledge Base Citations | Top 6 entries | A single calibration certificate may be associated with multiple measuring instruments. Controlling the number of citations prevents context overload |
| Maximum Response Tokens | 2000–3000 token | Abnormal report drafting requires complete presentation of traceability information. Truncation of critical content must be avoided |
| `quoteMaxToken` | 1500 characters | Limits the display length of a single citation. Adapts to the field layout requirements of metrology documents |
| `responseData` | Enable traceability fields | Automatically associates core traceability fields such as instrument numbers and calibration dates from metrology management systems |

## Three Common Mistakes
- A red error prompt appears in the interface, and citation content fails to load normally. Cause: Multi-data source association is not configured, or the maximum knowledge base citations value exceeds the system allowable range.
- Generated abnormal reports lack calibration certificate traceability information. Cause: The maximum context value is too small, and complete traceability chain associated data is not loaded.
- Too many citation markers in response results interfere with reading. Cause: The `quoteMaxToken` parameter is not adjusted, or the maximum knowledge base citations value is too high.

## How to Verify Successful Configuration
- Import a calibration certificate as test data, submit an abnormal report drafting request, and check whether the returned result includes traceability fields such as instrument number and calibration date.
- View the FastGPT v4.17.0 knowledge base index log, and confirm that metrology documents have completed incremental updates according to calibration cycles.
- Adjust the `quoteMaxToken` parameter, then check whether the display length of a single citation meets expected layout requirements.
- Test the multi-knowledge base association scenario, and confirm that there is no conflict when calling data from both the metrology management system and LIMS system.

The values provided are common starting points and should be measured against the reader's own samples.
