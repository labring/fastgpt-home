# Process Document and Exception Report Drafting for Metal Cutting Machining: Source Citation and Traceability

## What the data for this category looks like
This category’s data covers the entire machining workflow. Sources include product drawings and 3D models, CAPP/CAM systems, machine tool collection terminals, tool management systems, MES systems, and inspection and measuring tool data. Daily documents include process routes, operation cards, tool lists, CNC programs, first-piece inspection records, patrol inspection forms, and measuring tool calibration records. Data updates are triggered by work orders, single-piece machining, spot checks, or tool changes. Fields have dedicated units: tool life is measured in minutes, process dimensional tolerances in millimeters, and CNC programs include line numbers and feed rate parameters.

## What these characteristics mean for source citation and traceability
Data sources are scattered across multiple independent systems. Multiple knowledge bases must be linked to cover complete process and exception data, preventing missed critical information during traceability. High-frequency updates require regular vector database refreshes to ensure cited content matches current production data. Diverse document types require adapted chunking strategies to ensure accurate retrieval for both long-text CNC programs and short-text patrol inspection records. Dedicated field units require matching parameter units during traceability to prevent process errors caused by mismatched dimensional units.

## How to set configurations
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Adapts to the long paragraph structure of metal cutting documents, retains complete operation card, tool parameter, and CNC program content |
| `responseData` | Enable citation traceability fields | Ensures returned process or exception reports are bound to corresponding knowledge base entries, meeting traceability requirements |
| `detail` | Enable detailed citations | Displays source paths and specific field information of cited documents, facilitating verification of process parameter compliance |
| Single search limit | Top 6 entries | Covers historical data from multiple work orders and multi-system data sources, avoiding missed critical exception report content |
| Maximum context | `1500–2000 characters` | Adapts to the long text length of CNC programs and process routes, retains complete descriptions of machining logic |

## Three common configuration mistakes
- Phenomenon: Citations fail to display properly after external publishing, and system logs show citation fields are empty. Cause: The `responseData` configuration item is not enabled, resulting in returned results not being bound to knowledge base traceability information.
- Phenomenon: Generated process or exception reports have no association with knowledge base citations, and the answer does not match private knowledge base metal cutting-specific data. Cause: The retrieval scope does not cover dedicated data sources such as tool management systems and MES, and only general process documents are retrieved.
- Phenomenon: The number of returned search results is not as expected, with only a small amount of data returned. Cause: The single search limit is set too low, failing to cover historical machining records from multiple work orders.
