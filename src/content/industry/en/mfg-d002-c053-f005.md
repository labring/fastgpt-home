# Process Document and Exception Report Drafting for Iron and Steel Smelting and Continuous Casting: Tool Calling and Plugins

FastGPT v4.17.0 configuration must be adapted to the production characteristics of this category. The following provides specific instructions.

## What Data for This Category Looks Like

Data sources for this category include hot metal and scrap steel inbound data, L2 process control system, laboratory test results, manufacturing execution system, energy medium monitoring system, and equipment status monitoring system.

Each heat generates a heat plan and batching list. Process data for converter smelting and continuous casting is synced in real time. Slab judgment sheets and exception records are summarized per shift.

Daily documents contain standardized fields including heat number, hot metal weight, blowing duration, casting speed, and slab thickness. Corresponding units are six-digit number, ton, minute, meter per minute, and millimeter, respectively.

## Constraints Imposed by These Characteristics on Tool Calling and Plugins

The real-time and tightly coupled nature of this category requires tool calling to support low-latency retrieval of real-time L2 process control data. Do not use historical data older than 10 minutes to support process document drafting.

Multiple document types and fixed field structures require plugins to pre-match field mapping rules for documents such as heat plans and composition reports. Plugins cannot directly adapt to generic documents without fixed structures.

The high-temperature continuous process characteristic requires tool calling to quickly generate disposal suggestions when exceptions are triggered. Avoid process interruptions.

High data update frequency and scattered data sources require plugins to integrate multiple system data interfaces. Avoid drafting failures caused by missing single data sources.

## How to Set Configurations

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Tool call trigger timing | Triggered after heat plan generation | Matches the standard production process organized by heat for this category |
| Single tool call timeout | 600 seconds | Adapts to time consumption requirements for retrieving data from multiple systems |
| `toolChoice` | Auto | Allows the model to independently select tools adapted to process and exception scenarios |
| Document field mapping plugin | Bind fixed fields of slab judgment sheets and smelting records | Matches the standardized structure of documents for this category |
| Maximum context length | 8000–12000 token | Accommodates complete content of multiple heat-related documents |
| `functionCall` | Enabled | Forces the model to call specified tools to complete data integration and document generation |

## Three Common Configuration Mistakes

- 500 error when importing process documents. Cause: Field mapping rules for documents of this category are not pre-configured, or document length processed by the embedding model exceeds the adaptive range.
- Error returned when calling third-party large models that only allow current usage. Cause: Permission configuration for third-party models is not completed in the platform, or interface parameters are filled incorrectly.
- Empty result after pulling data via internet-connected tools. Cause: Interface format for data sources of this category is not matched, or timeout setting is too short leading to incomplete data retrieval.

## How to Confirm Configuration is Complete

- Upload a real heat plan document. Check if fields are correctly mapped to preset plugin parameters after embedding.
- Trigger tool calling. Review returned tool calling logs to confirm `toolChoice` automatically selects tools adapted to the current scenario.
- When calling third-party large models, verify that interface response format meets preset plugin calling requirements.
- Simulate an exception trigger scenario. Check if generated exception reports include relevant fields from slab judgment sheets.
