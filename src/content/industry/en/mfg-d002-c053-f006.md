# Drafting Process Documents and Exception Reports for Iron and Steel Smelting and Continuous Casting: Citation Sources and Traceability

## What Data for This Category Looks Like
This category of data originates from ironmaking, steelmaking, continuous casting, quality control, and scheduling departments of integrated iron and steel enterprises. Daily documents include heat plans, batching lists, converter smelting records, continuous casting process records, and slab inspection sheets. Data sources cover hot metal and scrap charging data, L2 secondary process control systems, laboratory test results, MES manufacturing execution systems, energy medium consumption data, and equipment operation status collection systems. Update cadence: Smelting and process records are generated per heat, process data is synchronized in real time, and scheduling documents are summarized per shift. Document fields include heat number, cast sequence number, temperature parameters, operation duration, defect location, and others. Units use standard industry conventions such as degrees Celsius, meters, and minutes.

## Constraints Imposed on Citation Sources and Traceability by These Characteristics
Multi-source data and real-time updates require traceability systems to associate document fragments across multiple systems. Keyword matching limited to a single document cannot fulfill this requirement. The strong coupling between heats and cast sequences requires citations to filter non-current batch documents by hierarchy. This prevents mixing information from different production batches. Frequently updated documents require dynamic matching of the latest production data. Static cached context cannot meet real-time traceability needs for exception reports. Standardized document field formats require citation rules to align with field association logic. Text similarity matching alone cannot ensure traceability accuracy.

## How to Configure Settings
These configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum context token count | Set `quoteMaxToken` to 8000–10000 | Covers core fields of full-process documents for a single heat, avoids truncating critical traceability information |
| Single recall limit | Top 8 entries | Steel smelting documents have high relevance; additional recalls cover cross-system traceability chains |
| Response data return format | Enable raw document fragment return for `responseData` | Preserves field formatting and layout of original documents, making it easier to verify traceability sources |
| Detail level | Set `detail` to High | Process documents and exception reports require complete citation context to support multi-dimensional traceability of exception causes |
| Recall filtering rule | Match by heat number | Filters documents not from the current production batch, prevents mixing information across batches |

## Three Common Misconfigurations
- Phenomenon: Markdown-formatted document fragments cannot be rendered in context citations. Cause: Raw fragment return configuration for `responseData` was not enabled, only plain text summaries were returned.
- Phenomenon: Some queries fail to recall corresponding knowledge base files. Cause: Recall filtering rules based on heat number were not configured, resulting in non-current heat documents being included, or keyword matching failed to cover cross-system associated fields.
- Phenomenon: The number of citation results exceeds the expected limit. Cause: The single recall limit was set too high, and heat-based filtering rules were not enabled, resulting in recall of a large number of irrelevant historical documents.

## How to Verify Configurations Are Correct
- Submit an exception report drafting request for the current heat. Check if the returned citation list includes converter smelting records and continuous casting process records for the corresponding heat.
- Review the raw content of a single citation fragment. Confirm that the document’s field formatting and original layout are preserved, and that content was not simplified to plain text.
- Submit a query outside the current heat range. Check if recall results are automatically filtered to only return documents from the current production batch.
- View system operation logs. Confirm that the `quoteMaxToken` configuration value is active, and no context truncation error prompts appear.

The values provided are common starting points and should be measured against the reader's own samples.
