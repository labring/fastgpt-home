# Process Document and Exception Report Drafting for Sheet Metal Cutting and Bending: HTTP Interfaces and External Systems

## What Data for This Category Looks Like
Data for this category typically comes from CAD/CAM software, order BOMs, sheet metal inventory systems, laser cutters, bending machines, and MES systems. Daily output documents include 3D part unfolding drawings, CNC cutting programs, bending process cards, nesting diagrams, first-piece records, and process flow cards. Fields include exclusive parameters such as sheet material, bending times, and unfolded dimensions. Update cycles align with order deliveries, daily inventory checks, or each production changeover. The business runs in a multi-variety, small-batch mode. It relies primarily on drawing-driven workflows. Key links include 3D part unfolding and bending coefficient compensation.

## What Constraints These Characteristics Impose on HTTP Interfaces and External Systems
Since data sources include multiple types of industrial equipment and business systems, interfaces must support pulling and pushing data in multiple formats to adapt to output formats of different devices. The multi-variety, small-batch mode causes large fluctuations in data volume per interface call. Reasonable request timeouts and batch processing rules must be configured. Bending process cards and nesting diagrams include high-precision dimensional parameters. Interface transmission must ensure complete field integrity to avoid process errors caused by truncation. The high-frequency update requirement based on orders and changeovers requires interfaces to support real-time or near-real-time data synchronization. This avoids data lag in production links.

## How to Configure Settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
|---|---|---|
| `Authorization` | Application-specific key | This category requires isolation of process data for different production lines or orders to avoid cross-permission confusion |
| `variables` | Pass exclusive parameters such as sheet thickness, bending radius, and order number | Bending coefficient compensation and nesting calculations rely on these parameters, which must be passed dynamically during interface calls |
| `responseData` | Return unfolding drawing number, nesting utilization rate, and exception report ID | Directly obtain core business fields that can be synchronized to MES |
| Number of data items per single request | Top 10 entries | Adapts to the single-batch data scale of multi-variety, small-batch operations to avoid request overload |
| Request timeout period | 300-600 seconds | Matches actual time consumption of sheet metal unfolding and nesting calculations, calibrated based on actual measurements |
| Knowledge base binding rules | Bind by production line/order number | Accurately recall exclusive process documents for the corresponding production line |

## Three Common Misconfigurations
- Calling `api/v1/chat/completions` with a specified knowledge base tag returns no results. Cause: The application-specific key is not bound to the knowledge base collection that includes the tag.
- Returning a parameter error when creating a collection via `api/core/datas`. Cause: Exclusive sheet metal cutting and bending fields such as unfolded drawing dimensions and bending coefficients are not passed, so the system cannot identify the document type.
- Returning an empty `responseData` after an interface call. Cause: The `variables` parameter is not correctly configured to pass the order number, so matching production data cannot be found.

## How to Confirm Configurations Are Properly Set
- Call the application-specific key configured with `Authorization` to initiate a test request, and verify that bound sheet metal process documents can be recalled.
- Pass preset sheet metal-specific `variables` parameters, and check if `responseData` includes expected fields such as nesting utilization rate and bending process card number.
- Initiate batch requests simulating multi-variety, small-batch order data, and verify that interface response time meets the configured timeout threshold.
- Check external system synchronization logs to confirm that process document and exception report data has been correctly pushed to MES or sheet metal inventory systems.
