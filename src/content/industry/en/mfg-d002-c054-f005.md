# Process Document and Exception Report Drafting for Sheet Metal Cutting and Bending: Tool Calling and Plugins

## What data looks like for this use case
Sheet metal cutting and bending scenario data mainly comes from CAD/CAM software, order BOMs, sheet metal inventory systems, laser cutters, bending machines, and MES systems. Daily produced documents include unfolded drawings, CNC cutting programs, bending process cards, nesting diagrams, first-piece records, and process flow cards. Fields cover bending coefficients, sheet thickness, hole position coordinates, bending angles, leftover material dimensions, and more. Units are mostly millimeters, degrees, and square meters. Data is synchronized per order, daily, or each time production changes over.

## Constraints imposed by these characteristics on the tool calling and plugins link
Multi-source data access needs require plugins to support API integration with different systems, and adapt to document parsing rules for different formats. High-frequency data updates require tool calling to support dynamic binding of order or production changeover identifiers, ensuring the latest business data is used for each call. Multiple document types and clear physical field constraints require parameter validity checks before tool calling, to avoid invalid calculations. Errors have serious consequences, so the exception report drafting link must associate full link logs of tool calls to facilitate quick problem location.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Workflow/API tool selection | `auto` | Adapts to multi-tool calling scenarios for sheet metal cutting and bending, automatically selects tools such as unfolding calculation, nesting analysis, and abnormality verification |
| Workflow/API function-call configuration | `required` | Forces tool calling to generate core fields required for process documents, ensuring parameter completeness |
| Session persistence configuration | Enabled, bound to order ID | Ensures multiple tool calls for the same order are in the same session, retaining context parameters |
| Request timeout threshold | 300–600 seconds | Adapts to time-consuming operations such as CAD parsing and bending coefficient calculation, avoiding premature timeouts |
| Parameter validation rules | Match conventional ranges of sheet thickness 0.5–10 millimeters and bending angle 0–180 degrees | Filters abnormal inputs in advance based on physical constraints of sheet metal cutting and bending |

## Three common misconfigurations
- Symptom: HTTP request components do not receive fields such as sheet thickness and bending angle passed by the plugin, and the request returns a parameter missing error. Cause: Session persistence binding is not configured, and tool calls are not associated with current order context data, resulting in dynamic parameters not being included in the request.
- Symptom: Context is lost between two tool calls for the same order, leading to inconsistent bending coefficient calculation results. Cause: Session persistence configuration is not enabled, each tool call generates an independent session, and previous business parameters cannot be retained.
- Symptom: Calling the CAD parsing component returns a `Request failed with` error with no detailed information. Cause: Request retry rules are not configured, a single network fluctuation or system response delay causes a call failure, and no automatic recovery occurs.

## How to confirm configurations are properly set
- Initiate two tool calls for the same order, check if the second call can retrieve order BOM fields passed in the first call.
- Pass parameters outside conventional ranges (such as sheet thickness 15 millimeters), check if the tool triggers parameter validation interception.
- Simulate network fluctuations to interrupt one tool call, check if automatic retry is triggered and the process is completed.
- In the FastGPT v4.17.0 log panel, view tool call parameters, confirm that `toolChoice` and `functionCall` take effect as configured.
