# Drafting Process Documents and Exception Reports for Foundry (Sand Molding, Precision Casting, Die Casting): Vector Models and Indexes

## What Data for This Category Looks Like
Data for this category primarily originates from ERP material master data, melting furnace thermometers, spectrometers, MES furnace batch records, mold management systems, customer drawings, and technical specifications. Update frequency is per furnace batch, per batch, or daily.
Daily documents include foundry process cards, batching lists, furnace batch records, mold histories, first article inspection records, material test reports, and nonconforming product review forms. Fields cover alloy composition parameters, melting and pouring temperatures, furnace batch numbers, mold cycle numbers, defect types, material usage, and other relevant details. Some documents include comparison items between measured values and technical requirements.

## Constraints on Vector Models and Indexes
This category of data has high update frequency and scattered update volumes. Indexes must support incremental synchronization to avoid long blocking caused by full reindexing.
Document types include structured numerical records and semi-structured process text. Vector extraction logic must support mixed fields to ensure consistent encoding of professional parameters and text descriptions.
Individual document lengths vary significantly. Chunk boundaries must be adjusted separately for short batching lists and long furnace batch records.
Strong relational links exist between furnace batches, molds, and defects in the data. Indexes must retain vector mappings of associated fields to ensure accurate associated matching during retrieval.

## Configuration Recommendations
The following configurations are adapted for FastGPT v4.17.0.

| Chunk Length | 800–1200 characters | Adapts to the varying document lengths of this category, covering valid information boundaries for different document types such as batching lists and furnace batch records |
| Overlap Length | 100–150 characters | Prevents chunk truncation of professional terms and associated fields, ensuring contextual integrity for vector retrieval |
| Similarity Threshold | Calibrated based on actual measurements | Must match the error tolerance of process parameters in this category to distinguish vector features of qualified and abnormal parameters |
| Single Search Limit | Top 10 results | Covers the range of furnace batches and molds associated with a single batch in this category, avoiding redundant retrieval results |
| `maxToken` | 4096 | Adapts to the vector encoding length of industrial professional text, meeting the complete input requirements for long process cards |
| `defaultToken` | 256 | Adapts to vector encoding for short batching lists, balancing computing resources and information completeness |

## Three Common Misconfigurations
- Symptom: The knowledge base index process remains in a running state and cannot complete. Cause: Chunk parameters were not adjusted for the varying document lengths of this category, resulting in an excessive number of chunks and accumulated index tasks.
- Symptom: A 503 error related to text-embedding is displayed in the interface, and one API calls succeed. Cause: The default group `default` is not configured with sufficient vector model computing resources, failing to respond to batch retrieval requests for foundry process parameters in a timely manner.
- Symptom: Vector retrieval results fail to match target process parameters or exception reports. Cause: A localized vector model adapted to industrial professional terminology was not selected; general models have insufficient encoding accuracy for foundry professional fields.

## How to Verify Proper Configuration
- Review index logs to confirm that incremental synchronization tasks trigger at the update frequency of per furnace batch or per batch, with no repeated full index execution records.
- Submit retrieval requests that include alloy composition and melting temperature, and verify the matching degree between the associated fields (furnace batch numbers, mold cycle numbers) in returned results and retrieval conditions.
- Test vector encoding time for documents of different lengths, such as batching lists and long furnace batch records, to confirm that response times meet business scenario requirements.
- Check resource usage of the vector database to confirm that no sustained resource overload occurs due to index tasks.

The values provided are common starting points and should be measured against the reader's own samples.
