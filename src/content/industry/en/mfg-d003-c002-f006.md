# Q&A for Process Specifications and Technical Standards for SMT Mounting and Electronic Assembly: Quote Source and Traceability

## What the data for this category looks like
Business data for SMT mounting and electronic assembly comes from customer BOMs, Gerber files, coordinate files, MES systems, mounters, SPI/AOI testing equipment, reflow oven temperature records, and similar sources. Daily documents include BOMs and coordinate files, line change sheets, stencils and furnace temperature records, first article confirmation reports, SPI/AOI reports, maintenance records, and traceability labels. Data update frequencies are per work order, each line change, and real-time. Fields include part number, reference designator, component batch number, furnace temperature parameters, coordinate position, and others. Units include millimeters, degrees Celsius, and similar.

## What constraints do these characteristics impose on the quote source and traceability process
SMT work order data is updated in real time. Quote and traceability must match the latest work order and line change records to avoid using expired data. Document types are diverse and associated fields are complex, so it is necessary to accurately distinguish the quote scope of different documents to avoid confusion of key parameters such as part number and reference designator. Data update frequency is high, so the traceability process must quickly associate records generated in real time. The consequences of errors are severe, so traceability must accurately point to specific work order links, and false quotes must not be generated. At the same time, this category is significantly different from PCB manufacturing categories, so traceability must be limited to SMT-specific data such as mounting, solder joints, furnace temperature, and must not mix substrate manufacturing data from adjacent categories.

## Three Common Misconfigurations
- The symptom is that the output contains the phrase "Reference Mark: [1]". The cause is that the mark filtering rule for response data is not configured, resulting in unstripped original reference marks.
- The symptom is that the generated reply fabricates reference IDs. The cause is that no specific work order or line change record is bound as a traceability source, resulting in the large language model generating false references.
- The symptom is that PCB substrate manufacturing related data appears in the traceability results. The cause is that the traceability scope is not limited to exclusive documents for SMT mounting and electronic assembly, and data from adjacent categories is mixed in.

## How to Confirm the Configuration Is Correct
- Submit a process question related to part number and reference designator, check whether the reference marks in the reply correspond to SMT exclusive document identifiers such as work order ID and line change record.
- View the logs under FastGPT v4.17.0, confirm that the value of `quoteMaxToken` conforms to the configuration, and no key parameters are truncated.
- Verify the generated associated documents, check whether the output of reference marks is automatically disabled, and no redundant reference information appears.
- Submit a question related to furnace temperature parameters, check whether the traceability results only include SMT exclusive furnace temperature records and stencil data, and no content from adjacent categories is mixed in.

The values provided are common starting points and should be measured against the reader's own samples.
