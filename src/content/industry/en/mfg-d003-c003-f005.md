# Process Specification and Technical Standard Q&A for Dairy Processing: Tool Calling and Plugins

## What This Category's Data Looks Like
This category covers manufacturers of liquid milk, yogurt, milk powder and dairy ingredients. Daily operation documents include raw milk acceptance records, standardized batching sheets, pasteurization/UHT sterilization records, CIP cleaning records, filling records, sample retention reports and microbial inspection reports.
Data is sourced from raw milk testing systems, MES production management systems, homogenization and heat treatment equipment, online temperature and flow collection modules, CIP systems and LIMS laboratory management systems. Updates occur in real time for each milk tank and each production batch.
Document fields include raw milk antibiotic and physicochemical indicators, sterilization temperature and duration, cleaning cycle parameters, colony detection values and other metrics. Data dimensions are tightly bound to production batches.

## Constraints on Tool Calling and Plugins Workflow
Real-time production data requires tool calling to have low latency, to avoid blocking the question-and-answer flow of continuous production links. Batch-bound data structures require tool calling to carry clear batch identifiers, ensuring pulled documents accurately match the corresponding production links.
Multi-source heterogeneous data sources require plugins to support docking with different types of system interfaces, covering the full process from raw milk acceptance to filling completion.
Production link errors can trigger batch risks, so tool calling results must undergo compliance checks to prevent incorrect parameters from entering the question-and-answer flow.

## Three Common Misconfigurations
- Tool calls return a 400 status code with no response body. The cause is failure to carry production batch identifier parameters when requesting data interfaces, leading the interface to be unable to match documents for the corresponding milk tank or batch.
- Model function calling performance does not meet expectations. The cause is failure to enable the `toolChoice` forced trigger mode, leading the model to generate non-compliant calling instructions beyond the scope of process documents.
- Connection to MCP interfaces with header authentication fails. The cause is failure to configure authentication header parameters in plugin settings, leading to interface authentication failure and inability to pull data normally.

## How to Confirm Proper Configuration
- Initiate a process question-and-answer for a single batch of raw milk acceptance, check whether the tool correctly pulls the raw milk acceptance records and testing data for that batch.
- View tool calling logs, confirm that the `toolChoice` parameter has taken effect, and the model only calls preset process standard tools.
- After configuring an MCP interface with authentication headers, initiate a question-and-answer for the CIP cleaning process, check whether cleaning parameter data can be pulled normally.
- Simulate a temporary interface exception, check whether the tool triggers the retry strategy and returns data normally after recovery.
