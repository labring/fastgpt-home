# Process Specification and Technical Standard Q&A for Photovoltaic Module Encapsulation: Citation Sources and Traceability

## What the data for this category looks like
Core data for photovoltaic module encapsulation scenarios comes from production departments including string welding, lamination, framing, and testing. It covers multiple types of documents such as layout drawings, material batch records, lamination process logs, EL crack images, IV test reports, insulation voltage resistance records, and packing lists. Data sources include the battery grading system, glass adhesive film backplane batch ledger, production MES system, string welding and lamination equipment, and EL/IV testers. Update frequency follows two rules: exclusive records are generated for each module, and batch ledgers are synced for each material batch. Core fields include material batch number, battery current grade, lamination temperature and time, EL crack coordinates, and IV test power value.

## What constraints do these characteristics impose on the citation sources and traceability link?
This category has high data update frequency and exclusive single-record data. This requires citation traceability to precisely match exclusive information for a single module or single batch of materials, to avoid incorrect cross-batch and cross-component associations. The coexistence of multiple document types requires the traceability function to support metadata association across different formats, such as binding EL crack images to corresponding IV test reports. Core process parameters have high matching requirements, and errors directly affect module power and customer claims. Therefore, the accuracy of traceability results must be strictly guaranteed to avoid incorrectly citing non-associated data.

## How to Set Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 characters | Adapts to the length of single documents such as lamination process logs and EL test reports, to avoid truncating key parameters including lamination temperature and battery current grade |
| `responseData` | Enabled | Must fully return metadata such as material batch number and IV test power value, to support process verification and compliance traceability for production departments |
| `detail` | Full fields | Displays core fields including battery current grade, lamination time, and insulation voltage resistance value, to meet cross-departmental process traceability needs |
| Single recall limit | Top 5 entries | Matches the number of documents associated with a single module, such as process records, test reports, and packing lists, to avoid redundant citations interfering with responses |
| Context matching threshold | 0.75–0.85 | Precisely matches process parameters and test results, to reduce the probability of incorrectly associating material parameters from different batches |

## Three Common Mistakes
- The application returns an empty answer alongside a complete citation list. This occurs when `quoteMaxToken` is set too small. Truncated citation content prevents the large language model from generating an answer using valid parameters, so only the recalled citation metadata is returned.
- When accessing a share link without login, the citation view button appears but does not respond when clicked. In FastGPT v4.17.0, this happens because the guest login configuration does not sync the citation permission switch, leading to a mismatch between front-end display and back-end permissions.
- Subsequent questions in multi-turn conversations cannot associate the component batch information mentioned earlier. This occurs because context association configuration is not enabled. The batch number from previous conversations is not included in the recall scope, so subsequent queries only retrieve based on the current question alone, and cannot match exclusive component data.

## How to Confirm the Configuration is Correct
- Initiate a process parameter query, such as "What is the lamination temperature of a specific batch of modules?" Verify that the answer includes citation metadata such as material batch number and test time.
- Trigger a long-parameter query scenario, such as "What are the EL crack locations and corresponding IV test power of this module?" Confirm that the answer has no truncated content, and the citation list fully covers associated documents.
- Open the share link without login, click the citation source button, and confirm that access to the detail page of the corresponding document is available.
- Initiate a multi-turn conversation: first query basic information of a specific batch of modules, then initiate an associated query. Verify that subsequent answers can associate exclusive process data of the previously mentioned batch.
