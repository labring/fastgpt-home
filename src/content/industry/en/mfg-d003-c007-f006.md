# Process Specification and Technical Standard Q&A for Stamping and Sheet Forming: Citation Sources and Traceability

## What Data for This Category Looks Like
Data for this category comes from stamping workshops of enterprises producing automotive panels, appliance sheet metal parts, and hardware parts. Daily documents include stamping work instructions, material utilization rate tables, mold inspection logs, first and last piece records, dimensional inspection reports, and mold change records. Data sources cover steel coil labels and quality certificates, punch and feeder data, mold management systems, MES, coordinate measuring machine or inspection fixture data. Updates are performed per coil, per batch, and per mold change. Document fields include mold model, material grade, operating parameters, inspection dimensions, mold change time, and others, with professional units such as millimeters, newtons, and square meters.

## What Constraints Do These Characteristics Impose on the Citation Sources and Traceability Link
Data sources are scattered across multiple production systems, so the traceability link must correlate multi-source metadata to fully match production batches. Update frequency varies with coil, batch, and mold change, so traceability must synchronize the latest documents and system data in real time. There are many document fields with professional units, so traceability must accurately match fields and units to avoid ambiguity. Mold changes and material batches have significant impacts on production stability, so traceability must bind batches and mold change records to prevent cross-batch document confusion. Additionally, production abnormalities involve consequences such as batch dimensional deviations and mold damage, so traceability must quickly locate the abnormal source and corresponding batch.

## How to Set Up Configurations
This configuration example applies to FastGPT v4.17.0.
| Configuration Item | Recommended Setting Range | Rationale |
| --- | --- | --- |
| Similarity Threshold | 0.75–0.85 | Stamping process documents have dense technical terms, requiring a high threshold to filter unrelated content |
| `quoteMaxToken` | 1200–1800 token | Single blocks of stamping process documents contain long text such as mold parameters and material specifications, requiring coverage of complete valid information |
| `responseData` | Only return associated source metadata and original text snippets | Clear traceability of source systems, batches, and update times is required |
| `detail` | Enabled | Professional document fields and units must be displayed to facilitate accuracy verification |
| Number of single recall sources | Top 5 | Balances recall accuracy and content redundancy for multiple types of associated stamping process documents |

## Three Common Misconfigurations
- A large volume of unrelated citation content is returned after initiating a process Q&A. This occurs because the similarity threshold is set too low, failing to filter documents from non-current production batches.
- External content returned via HTTP cannot be used as a valid citation source. This occurs because `responseData` is not configured to support metadata return for external sources, and external links are not included in the traceable scope.
- Citation sources do not display document batch and update time information. This occurs because the `detail` configuration is not enabled, and document metadata fields are not loaded.

## How to Confirm Configuration Is Complete
- Import a stamping work instruction, initiate a query that includes mold parameters or material specifications, and check if the returned content includes the document’s batch number and update time.
- Initiate a query related to mold change records, and check if the returned citation sources prioritize documents from the current production batch.
- Test a citation request for an external link, and check if the returned content includes the source’s metadata and original text snippets.
- Adjust the `quoteMaxToken` parameter, and check if the length of the returned citation snippets matches the expected value.

The values provided are common starting points and should be measured against the reader's own samples.
