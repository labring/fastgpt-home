# Process Specification and Technical Standard Q&A for Stamping and Sheet Forming: Knowledge Base Retrieval and Recall

## What Data for This Category Looks Like
Stamping and sheet forming business data comes from steel coil labels and quality certificates, press and feeder operation data, mold management systems, MES systems, coordinate measuring machine or fixture inspection data. Daily maintained documents include stamping work instructions, material utilization rate tables, mold inspection logs, first/last piece records, dimensional inspection reports, and mold change records. This covers unstructured process descriptions and structured tabular data. Updates occur per coil of material, per production batch, and each mold change. Document fields include material grade, material thickness, drawbead parameters, blank holder force values, inspection tolerances, and corresponding units such as mm, kN, %.

## Constraints for Knowledge Base Retrieval and Recall
Data sources for this category are scattered and updates occur frequently. Knowledge base retrieval must support high-frequency incremental synchronization and multi-source data fusion. This prevents retrieval of expired or mismatched production data. Both structured and unstructured documents are present. Retrieval modes must balance text semantic matching and tabular structured parsing. This ensures matching of both process parameter values and written instructions. Stamping process parameters have high precision requirements. Retrieval results must accurately match business fields and units. This prevents production errors caused by incorrect parameter use. Mold and material coil data vary widely across production lines. Knowledge base collections must be divided by production line. This avoids mixing of process parameters across lines.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | High precision requirements for stamping process parameters require filtering low-match irrelevant standard content to avoid misuse of debug parameters |
| `limit` | Top 5–7 entries | The volume of process documents corresponding to a single mold change or material coil is moderate. Too many results exceed the context window. Too few results miss critical mold inspection or mold change records |
| `searchMode` | Hybrid retrieval | Balances structured tabular data (such as material utilization rate tables) and unstructured work instruction content, matching business documents of different formats |
| `usingReRank` | Enabled | Key stamping process parameters such as drawbead clearance and blank holder force require precise matching. Reranking improves the ranking priority of highly relevant results |
| `datasetSearchUsingExtensionQuery` | Enabled | Can automatically supplement process-related synonyms, such as matching "drawbead" with "stretching bead", covering colloquial expressions commonly used in workshop settings |
| `collectionIds` | Bind exclusive knowledge base collections by workshop | Distinguishes mold and material coil data across different production lines, avoiding mixing of process parameters across workshops |

## Three Common Misconfigurations
- The number of retrieval results does not match the set `limit`. The cause is incorrect configuration of `collectionIds`. Binding irrelevant knowledge base collections expands the retrieval scope, returning too many off-line process documents.
- Uploaded XLSX format material utilization rate tables cannot recognize preset Q&A pairs. The cause is failure to enable the structured data parsing function, or the Q&A pair columns in the table do not use standard "question" and "answer" field names. This is a common document recognition issue in the industry.
- A parameter error is returned when calling the retrieval interface. The cause is mixing the purpose of `collectionIds` and knowledge base IDs. Filling the file collection ID into the knowledge base ID parameter fails to locate the target knowledge base. This is a common parameter usage issue in the industry.

## How to Verify Correct Configuration
- Upload a test stamping mold inspection log. Initiate a retrieval query containing "mold clearance parameters". Verify that the number of returned results matches the set `limit`.
- Check the knowledge base update log in FastGPT v4.17.0. Confirm that documents for each material coil and each mold change trigger incremental synchronization, with no missing update records.
- Call the retrieval interface, passing a query containing specific material thickness and blank holder force values. Verify that the similarity scores of returned results fall within the set `similarity` range.
- Test multiple accounts accessing the same knowledge base. Confirm that all accounts can view and edit knowledge base content, with no permission errors.

The values provided are common starting points and should be measured against the reader's own samples.
