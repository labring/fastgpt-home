# Q&A for Process Specifications and Technical Standards for Pharmaceutical Preparations Manufacturing: Vector Models and Indexing

## What This Category of Data Looks Like
Data supporting pharmaceutical preparations manufacturing comes from approved formulation processes, material batch information, MES electronic batch records, equipment and environmental monitoring data, LIMS systems, and quality management systems. Daily documentation includes master production files, batch production records, batch packaging records, cleaning records, inspection records, deviation/CAPA/change documents, and batch release review forms.
Updates occur synchronously for each production batch and critical process step. Equipment and environmental data receive updates per fixed monitoring plans. Documents contain both structured parameter fields and unstructured operation descriptions. Core fields include material batch numbers, process parameter values, and test results.

## Constraints Imposed on Vector Models and Indexing
High-frequency updates per production batch and critical step require indexes to support incremental appending. Full reindexing would consume excessive storage and computing resources, so this must be avoided.
Documents include both structured parameters and unstructured operation descriptions. Chunking must balance per-chunk content completeness and retrieval granularity to prevent truncation of core process parameters or operation workflows.
Data ties to GMP compliance requirements. Retrieval results must provide sufficient context to support compliance judgments, while keeping retrieval latency low enough for real-time production site reviews.
High-frequency updated structured data needs precise field matching. Improper chunking can cause parameter retrieval mismatches, which must be avoided.

## How to Set Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Matches the single-section content length of pharmaceutical preparation batch records, avoids truncating core compliance information such as process parameters and material batch numbers |
| Chunk Overlap Length | 100–150 characters | Covers the transition content of process steps, prevents missing key operation descriptions across chunks during retrieval |
| Similarity Threshold | 0.75–0.85 | Distinguishes similar process parameters and compliance requirements, reduces false recall probability |
| `defaultToken` | 4096 | Matches the input length limit of mainstream API models, accommodates the context content of a single round of Q&A |
| `maxToken` | 8192 | Accommodates complete context of multiple batch records and process specifications, supports complex compliance judgments |
| Single Search Limit | Top 10 entries | Balances retrieval efficiency and recall coverage, avoids excessive documents slowing response speed |

## Three Common Mistakes
- Index creation gets stuck on the final group, with no progress updates or error messages shown in the interface. This occurs when incremental indexing logic is not configured, and full reindexing does not adapt to bulk batch record data. Index task backlogs will form and cannot proceed.
- Mixed retrieval response time exceeds 10 seconds, while pure vector retrieval takes around 8 seconds. This occurs when both full-text and vector retrieval are enabled, and the number of documents per single search is not limited. This exceeds the API call response threshold.
- Knowledge base creation fails, stuck at the "create index" step with no feedback. This occurs when chunk length is not adjusted to fit long batch record documents. Excessive memory usage during chunking blocks the process.

## How to Confirm Proper Configuration
- Review index chunking logs in FastGPT v4.17.0 to confirm that the number of chunks per batch of documents falls within the preset character length range.
- Initiate a Q&A related to process specifications to verify that pure vector retrieval response time meets expectations.
- Confirm that retrieval results include core fields such as material batch numbers and process parameters, with matching degrees within the preset similarity threshold range.
- Submit a new batch record for incremental update to confirm that the index completes the append operation normally without progress stagnation.

The values provided are common starting points and should be measured against the reader's own samples.
