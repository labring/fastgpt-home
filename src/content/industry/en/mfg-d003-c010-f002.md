# Q&A for Process Specifications and Technical Standards for Medical Device Assembly and Clean Production: Vector Models and Indexes

## What Data Looks Like for This Category
Daily documents for this category include production process specifications, batch production records, clean zone records, sterilization batch records, inspection reports, software version records, adverse event and traceability materials. Data sources include design history files, device and material lots, MES systems, clean environment monitoring equipment, sterilization equipment, inspection and calibration systems. Data is updated per batch or per device production, with regular synchronization of clean zone-related records per environmental monitoring plans. Most documents contain structured fields and semi-structured content such as unique device identifiers, sterilization parameters, clean zone temperature and humidity, and batch numbers.

## Constraints on Vector Models and Indexing Workflows
Data for this category is updated per production batch and linked to unique identifiers. Indexing must support incremental synchronization to avoid the time cost of full reindexing. Documents contain precise process steps and traceability information. Metadata must be retained during chunking to ensure retrieved results can be linked to specific batches and devices. Given the focus on sterility and patient safety, retrieval accuracy requirements are high. Irrelevant environmental monitoring or batch record content must be filtered out. Data volume grows continuously with production scale. Indexing must adapt to dynamically scalable storage and query requirements.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Documents for this category are mostly semi-structured process content. Chunks that are too long will break the association of consecutive operation steps, while chunks that are too short will lose context continuity information |
| Overlap Length | 100–200 characters | Process specifications include consecutive operation steps. Overlapping chunks preserve the logical connection between steps |
| Similarity Threshold | 0.75–0.85 | Irrelevant data that does not match process standards must be filtered out, only returning content highly relevant to the query |
| Single Search Limit | Top 10 results | This category requires precise retrieval results. Too many entries will increase context redundancy and reduce answer accuracy |
| `maxToken` | 8000 token | Adapts to the default limit of FastGPT v4.17.0, meeting the storage requirements of retrieved context for long process specifications |
| Reranking | Enabled | Corrects ranking bias from vector retrieval, ensuring higher-priority process and inspection standard content is returned first |

## Three Common Configuration Mistakes
- Phenomenon: Search results return irrelevant sterilization batch records or environmental monitoring data. Cause: The similarity threshold is set too low, failing to filter content that does not match process standards.
- Phenomenon: The index does not show as ready for an extended period, and question answering cannot be initiated. Cause: Incremental synchronization trigger rules are not configured. Full synchronization of all batch historical data takes too long, and synchronization tasks are not split.
- Phenomenon: Retrieved results do not include critical unique device identifiers or batch numbers. Cause: Metadata fields such as unique device identifiers and batch numbers are not retained during chunking, leading to missing critical traceability information in the context.

## How to Verify Proper Configuration
- Submit a query related to production process specifications. Verify that returned results only include matching process and inspection standard content, with no irrelevant environmental monitoring data.
- Check the index status dashboard. Confirm that the index completes updates within the configured synchronization cycle, with no error logs.
- Manually trigger an incremental synchronization. Verify that newly added batch production records can be retrieved normally.
- Review chunked text fragments. Confirm that each block includes necessary metadata fields such as unique device identifiers and batch numbers.
