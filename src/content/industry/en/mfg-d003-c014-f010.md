# Dyeing and Finishing Process Procedures and Technical Standards Q&A: Knowledge Base Retrieval and Recall

## What this category’s data looks like
Data for this category comes from customer color swatches, formula libraries, dye chemical batch records, dye vat operation data, colorimeter test results, setting machine parameters, and environmental monitoring ledgers. Daily generated documents include dyeing formulas, chemical weighing records, dye vat operation curves, sample confirmation sheets, color difference reports, setting process sheets, and sewage discharge ledgers.
Data updates occur per vat, per batch, and per shift. Each individual document includes fields such as dye brand, dosage (g/L), heating rate (℃/min), vat number, and operation duration. Some documents contain mixed numeric parameters and text descriptions.

## What constraints these characteristics impose on knowledge base retrieval and recall
Frequent real-time updates require the retrieval system to support incremental data synchronization, to avoid recalling expired dye chemical batch or vat number data.
Mixed numeric and text document structure requires retrieval to support both keyword matching and vector similarity matching, balancing the precision of process parameters and the completeness of process descriptions.
Strong business logic tied to single vat or single batch requires retrieval results to be filtered by vat number and batch number, to avoid invalid cross-batch data.
High-risk business outcomes require retrieval results to have high confidence, strictly limiting the retrieval scope to the dyeing and finishing exclusive knowledge base to prevent irrelevant documents from interfering with decision-making.

## Configuration Settings
This configuration is written for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `similarity` | 0.75–0.85 | Matches the precision requirement for dyeing process parameters, avoids mixing low-correlation non-dyeing and finishing data, and ensures effective matching of color difference reports and dyeing formulas |
| `limit` | Top 8 entries | The number of single vat process-related documents is moderate. Too many entries exceed the context window, while too few fail to cover multi-link parameters such as heating curves and chemical records |
| `searchMode` | vector+keyword | Balances numeric parameters of dyeing formulas and text descriptions of dye vat curves, matching multiple types of process document content |
| `usingReRank` | Enabled | Performs secondary ranking on initial recall results, corrects deviations from single vector matching, and optimizes retrieval results for process issues such as color difference handling and hand feel adjustment |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands query terms for process questions. For example, expanding "heating curve" to "setting machine heating parameters, dye vat heating rhythm" to cover more relevant documents |
| `collectionIds` | Corresponding collection ID of the factory's self-built dyeing and finishing process knowledge base | Limits the retrieval scope, avoids mixing documents from other categories such as weaving and garment manufacturing, and ensures the business relevance of retrieval results |

## Three Common Configuration Mistakes
- Phenomenon: Calling the retrieval interface returns empty results, or no corresponding documents after keyword matching. Cause: `collectionIds` is not specified as the collection ID of the current dyeing and finishing knowledge base, so the retrieval scope covers irrelevant document collections.
- Phenomenon: Knowledge base original document links fail to jump, and document attachments cannot be downloaded. Cause: Nginx proxy rules are not configured correctly, and the static resource access path of knowledge base files is not covered.
- Phenomenon: Unable to obtain the knowledge base file list via curl request, returns empty fields or 404 status code. Cause: The request parameters do not correctly carry the target knowledge base collection ID, or the authentication configuration for interface calls is missing.

## How to Confirm Proper Configuration
- Submit a process question containing specific dye vat temperature parameters, and check if the returned results include dye vat curves and dyeing formula documents for the corresponding vat number.
- Call the specified knowledge base file list interface, and confirm that the returned results include category-specific documents such as dyeing formulas, setting process sheets, and color difference reports.
- View the similarity scores of retrieval results, and confirm that the scores fall within the 0.75–0.85 range, with no obvious irrelevant non-dyeing and finishing documents.
- Click the original document link attached to the retrieval results, and confirm that you can normally access and download the complete content of the corresponding document.

Note: The configuration values listed here are common starting points. Adjust them based on your own specific samples and operational requirements.
