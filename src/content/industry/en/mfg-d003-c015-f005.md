# Active Pharmaceutical Ingredient and Pharmaceutical Intermediate Manufacturing Process Specifications and Technical Standards Q&A: Tool Calling and Plugins

## What the data for this category looks like
Typical data for this category comes from daily documents and system data from synthesis, fermentation, purification, quality assurance, and regulatory support departments. Included data are batch production records, material balance data, reaction and purification records, cleaning records, impurity profile reports, deviation and change documents.
Data sources include regulatory process documents, raw material batch records, DCS systems, weighing systems, LIMS, chromatography data systems, and QMS. Update frequency is per batch and per step.
Individual documents contain professional fields such as batch number, reaction temperature, residual impurity quantity, solvent residual ppm, with units including mg, ℃, ppm, and others.

## Constraints imposed on tool calling and plugins by these characteristics
Multi-source heterogeneous system data sources require that tool calling plugins be configured with multiple interface mapping rules to adapt to return formats of different systems.
Data updated per batch and per step requires that tool calling must specify batch number as a core query parameter to avoid retrieving expired or invalid data.
Standardization of professional fields requires that tool calling perform format validation on returned results, to ensure values such as impurity content and solvent residual match industry standard units.
Businesses with high-risk consequences require that tool calling add failure retry and exception interception mechanisms, to prevent invalid requests from triggering risks such as batch scrap.

## Three common configuration errors
- When calling the `apiCollection` interface to upload process documents, returns `Invalid URL, code: 500`: Interface addresses connected to LIMS and chromatography data systems are not properly configured, or the interface address contains invalid characters, preventing the request from being initiated normally.
- When uploading multimodal files such as impurity profile reports, returns `InternalError.Algo.InvalidParameter: Multimodal file size is...`: Upload threshold is not configured to match typical single-document size for this category, causing oversized files to be blocked.
- Input process query text (such as "Share yield data for batch XX") is incorrectly parsed into garbled text similar to misordered characters. This occurs because professional term word segmentation validation rules are not configured, and input preprocessing for tool calling does not filter non-standard input characters, leading to text parsing anomalies.

## How to verify successful configuration
- Submit a process query that includes a valid batch number, verify that tool calling returns batch production records or impurity profile data for the corresponding batch.
- Upload an impurity profile report that meets the 200 MB threshold, verify that the upload interface returns a successful status.
- After configuring `toolChoice` to `auto`, submit a query involving multi-system data, verify that the tool automatically selects the matching data source plugin.
- Disable automatic echo of tool calling results in the workflow, verify that tool calling output is not automatically displayed in the conversation interface.

The values provided are common starting points and should be measured against the reader's own samples.
