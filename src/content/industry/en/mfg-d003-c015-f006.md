# Q&A on Process Procedures and Technical Standards for Active Pharmaceutical Ingredient and Pharmaceutical Intermediate Production: Source Citation and Traceability

## What the data for this category looks like
Synthesis, fermentation, purification, quality assurance, and registration support departments generate daily documents that form the core data for active pharmaceutical ingredient and pharmaceutical intermediate production. These documents include batch production records, material balance records, reaction and purification records, cleaning validation records, impurity profile reports, and deviation and change documents.
Data sources cover registered process documents, raw material batch ledgers, DCS operational data, weighing system records, LIMS (Laboratory Information Management System) outputs, chromatography data system outputs, and QMS (Quality Management System) files. Update frequency is triggered per production batch and process step.
Document fields include batch numbers, reaction parameters, material usage quantities, impurity test values, change approval statuses, and other items. Units correspond to the document type: temperature uses degrees Celsius, and material quantity uses kilograms.

## Constraints for Source Citation and Traceability
Multiple heterogeneous data sources require associating unified identification fields across different systems during traceability, to prevent cross-data source matching errors.
The update frequency per production batch and process step requires traceability results to be bound to specific batch numbers and step nodes. Generalized citation of content applicable to all batches is not permitted.
Diverse document types include professional test data, requiring differentiation of credibility levels between process operation records and quality test reports during traceability.
Fields include professional parameters and their corresponding units, requiring complete retention of original fields and unit information during citation to avoid distortion of process parameter information.
The timeliness of change and deviation documents requires traceability to link to the latest approval status, ensuring cited content meets current compliance requirements.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Maximum Context | 15000–20000 characters | Adapts to the total length of multiple document types including batch production records and impurity profile reports |
| `quoteMaxToken` | 800–1200 token | Matches the typical length of a single core process document, avoids truncation of key parameters |
| `responseData` | Enabled | Requires returning traceability identifiers such as batch numbers and steps from original documents |
| `detail` | Full | Requires retaining original document fields and unit information to ensure accurate process parameters |
| Single Search Limit | Top 5 entries | Covers associated document types for a single process step, avoids redundant results |
| Maximum Knowledge Base Citations | 3–5 copies | Matches the number of associated records for a single process step, aligns with business data association logic |

## Three Common Misconfigurations
- Phenomenon: Unescaped `\n` appears in replies, and line breaks cannot be rendered correctly. Cause: The `detail` parameter is not correctly configured to full mode, causing line breaks in original documents to be output as escaped characters directly.
- Phenomenon: Traceability results only return a small number of documents, failing to cover associated data for the current process step. Cause: The single search limit is set too low, failing to match all associated reaction records, impurity profile reports, and other files.
- Phenomenon: Cited content is not bound to a specific batch number or step node. Cause: The `responseData` parameter is not enabled, so traceability identifier fields from original documents are not included in outputs.

## How to Verify Correct Configuration
- Submit a process question that includes a specific batch number, check whether the reply carries the traceability identifier for the corresponding batch in the FastGPT v4.17.0 environment.
- Test a question referencing a process document with line breaks, confirm that line breaks in the reply are rendered correctly, with no residual `\n` characters.
- Adjust the values of the single search limit and maximum knowledge base citations, verify that the number of returned associated documents matches expectations.
- Check the system configuration log to confirm that the values of `quoteMaxToken`, `responseData`, and `detail` parameters match the preset settings.

The values provided here are common starting points, and should be validated against the reader's own samples.
