# Spray Coating and Painting Process Specification and Technical Standard Q&A: Knowledge Base Retrieval and Recall

## What does this category's data look like
This category covers full-process documents and collected data for coating lines across automotive, home appliance, construction machinery, and related fields. Data sources include TDS/SDS documents from coating suppliers, real-time data from spray booths and ovens, test results from colorimeters and film thickness gauges, and records from MES systems. Daily documents include coating process cards, coating batch sheets, paint mixing records, film thickness and color difference reports, oven curves, defect repair sheets, and VOCs ledgers. Data updates occur per coating batch and per shift. Key process parameters are collected continuously. Fields include film thickness (μm), color difference ΔE*ab, oven temperature (℃), and coating batch number, among others.

## What constraints do these characteristics impose on the knowledge base retrieval and recall link
High-frequency updates to coating process data require the retrieval link to support incremental synchronization and real-time association. This prevents the use of expired coating batch or oven parameters. Differentiated structures across multiple document types require dividing retrieval collections by document type. This avoids interference from cross-category data. Continuously collected real-time parameters and offline ledgers need separate retrieval logic adaptations. For example, real-time oven data requires short-window retrieval, while VOCs ledgers require periodic backtracking retrieval. Process matching accuracy directly affects product appearance and compliance. Strictly control the relevance threshold of recall results to prevent low-relevance content from interfering with process judgment.

## How to configure settings
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | 0.85–0.90 | Coating process parameters have high precision requirements. Filter low-relevance results to avoid incorrect matches for color difference and film thickness parameters |
| `limit` | Top 8 entries | A single coating batch has approximately 5-7 process steps. Returning the top 8 entries covers the full process chain while controlling context length |
| `searchMode` | `mixedRecall` | Balances full-text keyword matching for process cards such as "film thickness control" and semantic recall for real-time parameters. This adapts to multiple data types |
| `usingReRank` | Enabled | Performs secondary sorting on initial recall results. Prioritizes core process parameters such as oven temperature and color difference thresholds to improve result accuracy |
| `datasetSearchUsingExtensionQuery` | Enabled | Expands process-related synonyms based on the original query. For example, expand "paint mixing" to "coating viscosity adjustment" to cover more process documents |

## Three common configuration errors
- Retrieval results return irrelevant content with semantic similarity below 0.9 and insufficient full-text search scores. This occurs when the `similarity` threshold and search score filtering rules are not configured. Low-relevance VOCs ledgers or process cards from non-current batches are recalled.
- After deploying from source code and connecting to a Docker database, knowledge base documents do not display synchronously. This happens when manual dataset synchronization commands are not executed, or the database connection configuration does not include the dataset index path. Documents fail to load correctly.
- Custom split document chunks are automatically deduplicated and merged. This occurs when the duplicate document deduplication switch for the knowledge base is not disabled. Chunks of identical content are deleted, disrupting the original retrieval order.

## How to verify correct configuration
- Import one current batch coating batch sheet and oven curve document. Initiate the query "current batch film thickness control parameters". Verify that returned results include the coating batch number and film thickness (μm) values.
- Adjust the `similarity` threshold to 0.85. Initiate the query "oven temperature control range". Confirm that returned results only include oven-related documents, with no unrelated paint mixing records.
- Enable external website data source synchronization. Wait 10 minutes, then initiate a coating process query for the corresponding website. Confirm that returned results include content from the external documents.
- Disable the duplicate deduplication switch, then import two nearly identical paint mixing records. Initiate the query "paint mixing viscosity parameters". Confirm that returned results include chunks from both documents, with no automatic merging.

The values listed here are common starting points. They should be measured against the reader's own samples.
