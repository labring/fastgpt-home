# Q&A for Process Specifications and Technical Standards of Plastic Injection Molding: Multi-turn Dialogue and Prompt Engineering

## What Data for This Category Looks Like
Data sources for this category include resin batch property sheets, injection molding machine operating parameters, mold temperature controller data, MES system records, first article inspection reports, and material change and machine cleaning records.
Data is updated per production batch, each mold change or material swap, and after each shift inspection.
Daily documents include injection molding process cards, raw material drying records, mold history logs, inspection sheets, and material change and machine cleaning records.
Fields cover process parameters and test results such as screw speed (rpm), holding pressure (MPa), drying temperature (℃), and raw material moisture content (%).

## Constraints Imposed by These Characteristics on Multi-turn Dialogue and Prompt Engineering
Data updates occur frequently and are triggered per batch. Multi-turn dialogue must link to the exclusive context of the current production batch to avoid calling outdated process parameters.
Document types are diverse, and fields use specialized units. Prompts must explicitly specify the document type range for retrieval, and require parameter unit matching.
Data from different production links is closely correlated. Multi-turn dialogue must follow the production process sequence: from raw material drying to filling and holding pressure, then to cooling, and gradually guide users to supplement scene information.
Unlike the cross-linking curing process of rubber vulcanization, there is no need to associate parameters from the curing stage.
Errors can have serious consequences. Dialogue must support verification prompts for abnormal parameters to avoid recommending content that does not comply with injection molding process specifications.

## How to Set the Configuration
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `chatId` | Bind to the current production batch ID | Ensure multi-turn dialogue links to exclusive data for the same production batch, avoiding cross-batch parameter confusion |
| `messages` | Retain the most recent 20 turns of dialogue content | Cover the full process adjustment cycle after a single mold change, avoiding loss of critical context |
| `variables` | Preset the raw material model and mold number for the current production batch | Automatically bring in exclusive parameters to reduce repeated input |
| Maximum context length | 8000–12000 token | Adapt to the total length of injection molding process documents, covering multiple process cards and inspection records |
| Single retrieval limit | Top 6 matching documents | Match historical data from the same batch and same mold, avoiding interference from redundant information |
| Question optimization | Enabled | Automatically complete missing information for process scenarios, such as supplementing the current plastic part type being produced |

## Three Common Errors
- Empty dialogue results or error messages. The cause is failure to bind the `chatId` of the current production batch, leading the retrieval scope to cover expired cross-batch data that cannot match the current process scenario.
- Retrieval results including unrelated non-injection molding process documents. The cause is failure to limit the retrieval document type range in the prompt, leading to matching business data from other categories.
- Loss of critical production parameters in dialogue context. The cause is failure to limit the retention turns of `messages`, leading to historical data from old batches overwriting valid information for current production.

## How to Confirm Proper Configuration
- Enter the raw material model of the current production batch when initiating a dialogue, confirm that the system automatically brings in the preset `variables` parameters.
- Initiate a query about a process abnormality, such as "Analyze the cause of shrinkage defects", confirm that the returned retrieval results include the current mold's history logs.
- Launch 3 consecutive questions about material change and machine cleaning, confirm that `messages` retains context information from previous dialogue turns.
- Check that the currently used FastGPT version is v4.17.0, confirm that the functions are compatible with the current configuration items.
