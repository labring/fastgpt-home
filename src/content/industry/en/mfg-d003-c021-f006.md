# Process Specification and Technical Standard Q&A for Furniture and Wood Products Manufacturing: Citation Source and Traceability

## What data for this category includes
This category of data covers the entire production process of panel furniture, solid wood furniture, custom home furnishings, and wooden doors. Daily documents include order disassembly drawings, cutting lists, edge banding and drilling programs, coating process specifications, hardware material lists, assembly testing and packaging records. Data sources include order design systems, sheet and wood batch ledgers, CNC cutting and drilling equipment logs, ERP/MES systems, and sheet moisture content test records. The system triggers data updates synchronously with order generation, daily production scheduling, and each batch of incoming materials.

## Constraints imposed by these characteristics on the citation source and traceability link
The custom order-driven production model causes large fluctuations in single-batch data volume, with a large number of board parts and complex associated fields. Citation and traceability must accurately match specific document entries under a single order. Data from multiple sources has large format differences, so the traceability function must link to original records of the corresponding system to avoid cross-document confusion. The high-frequency update feature requires the traceability function to support real-time or near-real-time document synchronization to avoid citing outdated process parameters or material information. Associated data from the on-site installation link must be accurately traced back to the original design of hole positions and hardware matching, otherwise installation errors and after-sales issues are likely to occur.

## How to configure
This configuration guide is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Process documents for furniture and wood products have long single-paragraph content, which needs to cover complete process steps, parameters, and associated material information |
| Maximum context window | `Top 10 historical conversations` | Custom furniture production Q&A often needs to link to previous order design and process adjustment records to avoid context breaks |
| `responseData` | Return original document path and entry ID | Accurate traceability to specific business documents such as sheet batch ledgers, cutting lists, and CNC programs |
| Single search limit | `Top 5 recall results` | A single order is associated with a large number of process documents, control the number of result entries to ensure the readability of traceability information |
| `detail` | Adjust based on actual testing | Document structures and field formats vary greatly between different enterprises, adjust the detail display threshold according to actual recall effects |
| Document synchronization trigger rules | Triggered by order, daily, or per batch of incoming materials | Match the data update frequency of this category to ensure that cited documents are the latest valid versions |

## Three common configuration mistakes
- Phenomenon: When accessing the application via a non-login share link, the citation source module shows blank content or prompts that there is no permission to view the original text. Cause: The traceability permission switch in share mode is not enabled in the application configuration, or the public access document permission range is not correctly configured.
- Phenomenon: No citation mark or source entry is displayed at the end of the knowledge base answer paragraph. Cause: The display configuration corresponding to `responseData` is not enabled, or the `detail` parameter value is too low to trigger the citation display logic.
- Phenomenon: Subsequent questions cannot link to process parameters of previous orders, and the answer is irrelevant to the question. Cause: The correct maximum context window is not configured, or the context association logic for historical conversations is not enabled.

## How to verify successful configuration
- Initiate a process Q&A related to a single order, check whether the corresponding document path or entry ID is displayed at the end of the answer.
- Enable the non-login share link, access the application and initiate Q&A, confirm that the citation source module loads normally and has no permission error prompts.
- Initiate 3 to 5 consecutive questions related to previous orders, check whether the answer can link to process parameters and document information from previous conversations.
- Adjust the `quoteMaxToken` parameter, verify whether the content integrity and citation range of the answer match the configured value.

The values provided here are common starting points and should be measured against the reader's own samples.
