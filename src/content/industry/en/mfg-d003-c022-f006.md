# Q&A for Process Specifications and Technical Standards for Household Appliance Complete Manufacturing: Citation Sources and Traceability

## What the data for this category looks like
Process specifications and technical standard data for household appliance complete manufacturing originates from ERP/MES systems, component batch ledgers, tightening and refrigerant charging equipment logs, safety compliance tester data, performance laboratory reports, and after-sales fault records. Daily documents include configured BOMs, assembly work instructions, refrigerant charging records, electrical safety test reports, random performance inspection reports, and rework records.
Data updates occur in real time for individual complete units, and on a scheduled basis for shifts and teams. Document fields include component batch numbers, tightening torque, charging volume, test voltage, fault codes, and more. Corresponding units include newton-meters, grams, volts, and others.

## What constraints do these characteristics impose on the citation sources and traceability workflow
The mixed-line assembly nature of this category requires citation traceability to accurately match models and processes, to avoid cross-referencing documents across multiple models. Frequently updated batch data requires traceability to link to the latest document versions, ensuring cited content aligns with current production batches. Differences across multiple document types require citation results to be sorted by risk level, with high-priority documents such as safety compliance and performance documents displayed first. The direct consumer-facing attribute requires traceability results to be traced back to specific production links, reducing the risk of batch rework and recalls. Additionally, individual complete units are associated with multiple process documents, so sufficient context must be carried to avoid truncating critical content.

## Configuration guidelines
The following configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Single Search Limit | Top 6 entries | Process documents for household appliance complete manufacturing typically map to multiple processes per model. The top 6 entries cover citation needs for core assembly, safety compliance, and performance links |
| Reordering | Enabled | Citation results for high-risk documents such as safety compliance tests and refrigerant charging records must be prioritized to support production safety |
| `quoteMaxToken` | 1200–1500 token | Core cited content for a single process document is mostly within 1000 words. This range reserves sufficient context to ensure complete traceable content |
| `responseData` | Enable source file path and update time | This links to the actual update batch of the document, matches the traceability requirement for component batch numbers, and ensures cited content aligns with current production batches |
| `detail` | Enable full citation snippet | This verifies that cited content aligns with process specifications, avoiding process deviations caused by out-of-context quoting |
| Maximum Context | 8000–10000 characters | Individual complete units are associated with multiple process documents. Sufficient context is needed to carry complete traceability association information |

## Three common configuration errors
- Symptom: Q&A results only cite 1 document, and multiple associated documents cannot be retrieved. Cause: Multi-document recall configuration is not enabled, or the single search limit is set too low.
- Symptom: No default selected item appears after importing JSON-format knowledge base documents, and target documents must be selected manually. Cause: Default knowledge base binding parameters are not configured, and automatic association rules for imported documents are not specified.
- Symptom: An error is prompted when clicking test after configuring the model. The system runs after forced ignoring, but citation fields are empty. Cause: The model interface timeout threshold is set incorrectly, or the return format of `responseData` does not adapt to the document source path field.

## How to confirm successful configuration
- Submit a query about the assembly work instruction for a specific washing machine model, and check if the citation list in the returned result includes the source path and update time of the corresponding document.
- Adjust the single search limit to 10 entries, and verify that the number of cited results matches the set value.
- Import multiple process documents for the same model, and confirm that the Q&A result can simultaneously associate cited content from multiple documents.
- Check the running logs to confirm that the truncation length of `quoteMaxToken` falls within the configured token range.
