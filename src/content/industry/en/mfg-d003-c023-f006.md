# Process Specification and Technical Standard Q&A for Industrial Instrument Manufacturing and Calibration: Citation Sources and Traceability

## What this category of data looks like
Data for this category comes from flow, pressure, temperature, and analytical instrument manufacturers as well as metrology laboratories. Daily documents include assembly and commissioning sheets, calibration procedures, original calibration records, error curves, metrology certificates, and software version logs. Data sources cover design documents, standard instrument and environmental monitoring data, calibration software, laboratory information systems, and customer range requirements. The update frequency is once per calibration for each device. Documents have clear fields and units, such as error values, metrology certificate numbers, calibration environmental parameters, and range limits. The length of individual document entries varies widely.

## What constraints these characteristics impose on the "citation sources and traceability" link
Since data is updated per calibration for each device, traceability must be precisely tied to a single calibration record for the corresponding device to avoid cross-device confusion. Data from multiple sources must have clearly differentiated credibility weights to ensure traceability of referenced standard instrument data, calibration software records, and other materials. The unique fields and units of documents require that key information such as metrology certificate numbers and error curve parameters be fully retained during citation, otherwise the traceability chain will be broken. Incorrect citations can lead to measurement deviations, invalid certificates, or failure of metrology audits. For this reason, the traceability link must strictly match the relevance between data and queries.

## Three common misconfigurations
- Phenomenon: The answer body returned by the knowledge base interface has no cited content. Cause: The `responseData` configuration item is not enabled, and cited content is not synchronized to the answer body.
- Phenomenon: Garbled text appears when downloading a CSV file of calibration records after upload. Cause: The parsing encoding adapted to the document character set is not specified, leading to failed transcoding of Chinese or special characters.
- Phenomenon: After setting `quoteMaxToken` to 3000, the large language model does not receive context content. Cause: The total system context token limit is exceeded, leading to failure to pass context normally to the large language model after truncation.

## How to confirm the configuration is correct
- Submit a query containing keywords such as calibration and metrology certificate, and check whether cited document fragments are included in the answer body.
- Check the `responseData` field returned by the interface to confirm whether the cited knowledge base document metadata and complete content are included.
- Adjust the `quoteMaxToken` value to verify whether context is normally passed to the large language model.
- Upload a test CSV file of calibration records and confirm that no garbled text appears after download.

The values provided are common starting points and should be measured against the reader's own samples.
