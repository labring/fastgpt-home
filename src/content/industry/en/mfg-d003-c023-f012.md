# Process Specification and Technical Standard Q&A for Industrial Instrument Manufacturing and Calibration: Deployment and Upgrade

## What the data for this category looks like
Daily documents for this category include assembly and commissioning sheets, calibration procedures, original calibration records, error curves, metrology certificates, and software version records. Data sources include design documents, standard instrument monitoring data, calibration software, laboratory information systems, and customer range requirements. Data is updated per device per calibration action. Each document includes fields such as exclusive range, error value, traceability number, ambient temperature and humidity. Units include metrology-specific units such as pascals, cubic meters per hour, degrees Celsius. The size of a single calibration record document varies based on the number of error curves.

## What constraints these characteristics impose on deployment and upgrade workflows
Since data is updated per device per calibration action, deployments must support fine-grained document management and permission isolation. Therefore, deployments must configure an independent database instance to avoid mixing with other business data.
Since the category includes large-volume unstructured documents such as error curves and metrology certificates, deployments must configure a storage service compatible with large files to ensure reliable storage and reading of documents.
Since calibration records require strict traceability, knowledge base retrieval must retain field-level metadata. During upgrades, the binding logic between metadata and vector database must remain unchanged.
Since calibration data for a single device must be updated frequently, adjust index refresh trigger rules to avoid wasting system resources from full reconstruction.

## How to set configurations
These configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `MONGODB_URI` | `mongodb://username:password@host:port/fastgpt_instrument` | Store structured and unstructured documents such as calibration procedures and metrology certificates; specify a dedicated database name to isolate business data |
| `STORAGE_S3_ENDPOINT` | `http://192.168.1.100:9000` or enterprise cloud storage endpoint | Store large-volume files such as error curves and original calibration records; match the access configuration of the enterprise's existing storage service |
| `FE_DOMAIN` | `https://calibration-docs.your-company.com` | Replace the default localhost address; configure as a compliant internal or public access domain name for the enterprise |
| `DB_MAX_LINK` | `20–30` | Adapt to calibration document retrieval requests initiated by multiple devices simultaneously; avoid exhausting database connections |
| `REDIS_URL` | `redis://:your-redis-password@host:6379/0` | Cache retrieval results and session data to reduce repeated database query pressure |
| `ROOT_KEY` | Generate a random string in accordance with enterprise security specifications | Configure the super administrator permission key; rotate it regularly to ensure system security |

## Three common configuration mistakes
- Symptom: Frontend access returns 403 Forbidden or fails to load static resources. Cause: The `FE_DOMAIN` parameter is not configured correctly, the default localhost address is still used, and it has not been replaced with the enterprise's compliant domain name.
- Symptom: Retrieval results are missing error curves or metrology certificates. Cause: `STORAGE_S3_ENDPOINT` is not configured, large-volume files are not properly mounted, causing the knowledge base to fail to read stored documents.
- Symptom: Database connection timeout. Cause: The value of `DB_MAX_LINK` is too low, which cannot support calibration document retrieval requests initiated by multiple devices simultaneously.

## How to confirm the configuration is correct
- Access the configured `FE_DOMAIN` address, confirm that the frontend page loads normally with no domain resolution or certificate errors.
- Upload a simulated calibration certificate file, confirm that the file can be stored successfully and retrieved in the knowledge base.
- Initiate a retrieval containing calibration procedure keywords, confirm that the returned results include the corresponding documents and that the metadata is complete.
- Check the database connection number monitoring, confirm that the connection number does not exceed the configured value of `DB_MAX_LINK`.

The values given are common starting points and should be measured against the reader's own samples.
