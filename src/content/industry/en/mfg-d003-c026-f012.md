# Non-ferrous Metal Smelting and Electrolysis Process Specification and Technical Standard Q&A: Deployment and Upgrade

## What this category's data looks like
The data for this category mainly comes from concentrate and auxiliary material analysis reports, production DCS systems, electrolyzer voltage and current collection terminals, laboratory test results, and energy and environmental monitoring equipment. Daily documents include batching lists, smelting records, electrolyzer condition records, test reports, anode and cathode quality records, and environmental protection ledgers. Data update rhythm follows the production process: corresponding records are generated for each batch of raw materials, each furnace, or each tank. Real-time parameters such as tank voltage and current are updated synchronously. Document fields include batch number, furnace number, tank number, various process parameter values, and timestamps.

## What constraints do these characteristics impose on deployment and upgrades?
The multi-source and scattered data sources, differentiated update rhythms, and exclusive process fields of this category impose multiple constraints on deployment and upgrade workflows. It is necessary to adapt to the dual requirements of offline document batch import and high-frequency synchronization of real-time production data, and configure corresponding data docking and synchronization rules. Exclusive identification fields such as batch numbers, furnace numbers, and tank numbers require that process-related information be retained during knowledge base chunking to ensure the accuracy of process context during retrieval. Verification rules for different data must match smelting and electrolysis process logic to avoid invalid data entering the knowledge base. At the same time, the retrieval link for core process parameters must not be disrupted during upgrades.

## Three common configuration mistakes
- Symptom: Request timeout occurs when initiating process parameter queries, and the interface displays Request Time. Cause: The database connection pool upper limit is not adjusted based on the concurrent query volume of this category, leading to connection exhaustion and inability to respond to new requests.
- Symptom: Batch numbers, furnace numbers and other identification information are missing from retrieval results after importing documents such as smelting records and electrolyzer condition records. Cause: Specified process-related fields are not retained during knowledge base chunking configuration, leading to loss of key context during retrieval.
- Symptom: Large model tools cannot be called to obtain real-time electrolyzer condition data. Cause: Intranet data docking access permissions are not configured correctly, leading to the system being unable to connect to production data collection terminals.

## How to verify correct configuration
- Log in to the system background, check the database connection pool monitoring panel, and confirm that the current active connection count does not reach the configured upper limit.
- Import a batch of smelting record and electrolyzer condition documents, perform a retrieval operation, and confirm that the returned results include preset reserved fields such as batch numbers and furnace numbers.
- Initiate more than 10 consecutive process parameter query requests, and confirm that there are no consecutive request timeout errors.
- Attempt to call a large model tool to query the smelting parameters of a specified furnace number, and confirm that valid content from the corresponding document can be returned.
