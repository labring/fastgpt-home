# Q&A on Process Procedures and Technical Standards for Garment Cutting and Sewing: Citation Sources and Traceability

## Page Overview
- Target industry: Garment cutting and sewing
- Business focus: Q&A on process procedures and technical standards
- Capability scope: Citation sources and traceability

## What this category's data looks like
Daily documents for this category include process sheets, patterns, layout plans, cutting orders, first article sealed samples, process quality tables, and packaging size-matching sheets. Data sources cover order and size charts, CAD patterns, fabric and accessory inspection records, hanging production system data, needle detector test results, and customer sealed samples. Each order, garment style, and production batch triggers updates to the category’s data. Document fields include process steps, tolerance requirements, fabric direction, size ratio, carton number, and more. Most units use industry-standard measurements such as centimeters, pieces, and meters.

## What constraints do these characteristics impose on citation sources and traceability links
This category’s data updates frequently with orders, styles, and production batches. Accurate binding of citation traceability to exclusive documents for each production batch prevents mixing data across batches. Daily documents contain production-related content such as process details and layout parameters. Traceability information must clearly point to specific process sheets, cutting orders, or first article sealed samples to ensure the process requirements in Q&A results match current production tasks. The irreversible nature of cut pieces and dense process steps also require traceability results to trace back to original inspection and pattern data, making it easier to identify the root cause of process deviations.

## How to set up the configuration
The following configurations are formulated for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the typical text length of a single process sheet or layout plan for this category, to avoid truncating core process requirements |
| `responseData` | Enable citation source display | Requires clear labeling of the source document for process requirements for production personnel, to facilitate on-site verification |
| `detail` | Full traceability path | Displays the complete link from original data to cited documents, covering order, batch, and document type information |
| Maximum number of citations | Top 3 | The number of documents associated with a single task for this category is limited. Too many citations will disrupt reading by production personnel |
| Traceability display toggle | Switch based on scenario | Turn off unnecessary traceability in workshop settings, retain full traceability information on office terminals |

## Three common configuration mistakes
- Phenomenon: Merged knowledge base search results are sorted unexpectedly, not prioritized by similarity. Cause: No exclusive recall rule configured for batch-bound documents for this category, so the default sorting logic does not match the association priority of process documents.
- Phenomenon: Citation entries that do not match the local knowledge base appear in conversations. Cause: The recall switch for cross-batch general documents was not disabled, causing the system to call historical data from non-current orders.
- Phenomenon: Knowledge base citation display in conversations cannot be turned off. Cause: The disable parameter for `responseData` was not configured in the corresponding workflow node, or traceability display was incorrectly set to globally forced on.

## How to confirm the configuration is properly set
- Submit a question about the process requirements for a single garment style, verify that the cited documents in the returned results belong to the exclusive process sheet or layout plan for the current order.
- View the citation traceability information, confirm that it includes fields such as order number, batch number, and document type, with a complete and traceable link.
- Switch between workshop and office terminal scenarios, verify that the citation display toggle works as expected to meet scenario requirements.
- Test inputting process text questions that exceed the `quoteMaxToken` range, confirm that core process parameters are not truncated in the results.

The values provided here are common starting points. Adjust them based on in-house samples.
