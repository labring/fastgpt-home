# Process Specification and Technical Standard Q&A for Mold Design and Manufacturing: Source Citation and Traceability

## What this category of data looks like
Daily documents for mold design and manufacturing include mold design task sheets, DFM reports, part drawings, machining process cards, trial mold reports, mold modification notices, and mold records. Data sources cover customer product models, mold flow or forming simulation results, CAD/CAM files, machining and measurement data, and trial mold samples. Data is updated per individual mold project. New version files are generated after each trial mold or mold modification. Document fields include number of cavities, material grade, machining tolerance, assembly accuracy requirements, and other details. Some documents include numerical results from simulation analysis.

## What constraints these characteristics impose on source citation and traceability
Because data is updated per individual project and new versions are created after each trial mold or modification, the traceability link must accurately associate the latest version documents of the current project. This avoids citing expired content.
Because document types are diverse and include details such as specific processes and tolerances, recalled citations must clearly correspond to the document type and specific chapter. Broad matching is not allowed.
Because assembly accuracy and demolding feasibility reviews are involved, citations must be bound to files for specific parts or processes. This ensures traceability results can be directly used for on-site verification.
Because data sources include simulation and measurement results, traceability must mark the tool or submitter that generated the data. This improves the credibility of results.

## How to configure the settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the valid single-paragraph content length of mold process documents. Prevents truncation of critical tolerance or process descriptions |
| `responseData` | Enabled | Ensures the output includes metadata from source files to meet traceability requirements |
| `detail` | Enabled | Displays specific chapters or part numbers of cited documents to facilitate on-site verification |
| Single recall limit | Top 3 entries | Focuses on core process documents for the current mold project. Avoids redundant citations that interfere with judgment |
| Version matching switch | Calibrated based on actual testing | Only recalls documents from the latest version of the current project. Adapts to the update rhythm after trial mold or modification |

## Three common errors
- When answering questions with no matching content in the knowledge base, citations from existing documents are still returned. This occurs because no empty response rule is configured when no valid recall results are found. The default redundant citation logic from the general knowledge base is used instead.
- Conversation API calls do not return the unique identifier ID of the citation. This occurs because the `responseData` configuration item is not enabled, or citation metadata collection is not enabled in the knowledge base settings.
- Returned citations point to outdated trial mold reports or process cards. This occurs because no rule is configured to filter recall results by document update time or project version. Outdated historical documents are recalled instead.

## How to confirm configurations are properly set
- Submit a question that falls outside the scope of the current mold project's knowledge base. Check if the response returns empty content or a clear prompt that no matching results exist.
- Review the response body from the conversation API. Confirm that citation metadata is included under the `responseData` field. This includes file names, chapter information, and unique identifiers.
- Submit a question related to machining of a specific part. Check if the returned citations include the process card or part drawing for that part.
- Submit a question linked to the latest mold modification notice. Check if the recalled documents are the latest version for the current project.
