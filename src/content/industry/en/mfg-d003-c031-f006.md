# Q&A on Process Specifications and Technical Standards for Cement Clinker and Grinding: Citation Sources and Traceability

## What this category of data looks like
This category of data covers mines, raw material, calcination, grinding, quality control, and energy departments of cement enterprises. Daily documents include raw material mixing plans, kiln operation records, laboratory reports, quality control notices, equipment inspection records, and energy reports. Data sources include online composition analysis systems, DCS control systems, laboratory test data, kiln and mill equipment operation data, raw and fuel ledgers, and energy metering reports. Update frequencies include real-time, shift-based, and daily. Document fields include material composition ratios, equipment operation parameters, test result values, and energy consumption indicators, with units such as percentage, ton, kilowatt-hour, MPa, and others.

## Constraints on Citation Sources and Traceability Posed by These Characteristics
Data sources are scattered, and their update frequencies vary widely. Real-time kiln and mill operation data requires matching timestamps during traceability to avoid cross-batch citation confusion. Document structures differ significantly across departments, so clear classification tags for the corresponding knowledge base are needed to accurately associate sources. Documents with test values such as laboratory reports and quality control notices must retain original fields and units to prevent information distortion during traceability. For batch data in raw and fuel ledgers and energy reports, the attribution batch of individual records must be distinguished during traceability to prevent incorrect associations. Additionally, since errors directly relate to clinker quality and production downtime, the citation source link must ensure uniqueness and traceability, avoiding vague associations.

## How to Configure Settings
This page’s configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | Matches the average length of single documents in this category, ensuring complete citation of key parameters and test results |
| `responseData` | Enabled and include citation source metadata | Meets the requirement for process specification Q&A to clearly mark source document type, test batch, and affiliated department |
| `detail` | Enabled | Allows returning original fields and units of cited documents, avoiding parameter ambiguity caused by truncated information |
| Single search limit | Top 6 results | Covers core citation needs for multiple types of documents including mixing, kiln operation, and laboratory test data in a single round of Q&A |
| Citation source display granularity | By document category | Matches the knowledge base structure divided by department and document type for this category, enabling production personnel to quickly locate source documents |

## Three Common Configuration Mistakes
- Phenomenon: Citation source fields are empty in Q&A response results. Cause: The `responseData` configuration item is not enabled, and the citation source return switch is not activated.
- Phenomenon: Insufficient citation entries are returned when calling the API, failing to cover required process parameters. Cause: The `quoteMaxToken` setting range is too narrow, unable to load source information for multiple associated documents, leading the system to truncate source data.
- Phenomenon: Cited documents cannot be downloaded to view their original content. Cause: No file storage path permissions are configured for citation sources, or no association is made with the original document upload records of the knowledge base.

## How to Verify Successful Configuration
- Initiate a test Q&A including raw material mixing parameters, check whether the returned results contain clear cited document names and source departments.
- Call the Q&A API, check whether the returned JSON structure includes the `responseData` field, and the field contains detailed metadata of the citation source.
- Adjust the value of `quoteMaxToken`, verify whether the display length of cited documents matches the set token range.
- Test the download link of cited documents, confirm that the originally uploaded laboratory reports or equipment inspection records can be accessed normally.
