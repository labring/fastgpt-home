# Process Specification and Technical Standard Q&A for Biologics and Aseptic Manufacturing: Tool Calling and Plugins

## What the data for this category looks like
This category covers vaccine, antibody, blood product, and aseptic injectable manufacturing enterprises. Daily documents include cell bank/stock seed batch records, culture and purification records, aseptic filling records, environmental monitoring data, media simulation filling reports, aseptic test results, and batch release documents.
Data sources include cell bank and seed batch systems, process analysis equipment, clean area monitoring systems, MES, LIMS, and equipment integrity testing tools.
Data update frequencies fall into three groups: batch-specific batch records, real-time process monitoring data, and environmental monitoring data tied to monitoring plans.
Document fields include batch number, culture temperature, filling duration, sedimentation bacteria concentration, and others. Some fields have clear units of measurement.

## Constraints imposed by these characteristics on tool calling and plugin workflows
The need to connect multiple data sources requires tool calling plugins to support simultaneous connections to systems including MES, LIMS, and clean area monitoring systems. Independent access permissions must be configured for each data source.
Different data update frequencies correspond to different trigger logic. Real-time process data must support event-triggered calls. Batch record data must support pulling by production batch.
The complex document structure requires tool calling to support `functionCall` triggered by document category, to prevent irrelevant information from interfering with Q&A results.
Additionally, errors in this category have severe consequences. Tool calling failure handling must include retry mechanisms and complete log retention, to ensure process traceability when exceptions occur.

## Three Common Configuration Mistakes
- Symptom: The tool call returns the `Invalid JSON: Bad control character` error. Cause: Text containing line breaks or special spaces in process specifications or batch records was not escaped, causing the JSON parameter format for tool calls to fail to meet requirements.
- Symptom: Tool call nodes cannot add connection lines, and no small circle control for connections appears in the interface. Cause: The multi-plugin linkage configuration item was not enabled in FastGPT v4.17.0, causing node interaction elements to be hidden.
- Symptom: MCP auxiliary task execution takes too long. Cause: The available plugin range was not limited via `toolChoice`, causing the model to automatically traverse all unassociated data source plugins and increasing thinking time.

## How to Verify a Successful Configuration
- Initiate a Q&A that includes keywords for specific process documents, and verify that the tool call invokes the preset corresponding data source plugin.
- Check that the interaction controls for tool call nodes load normally, and confirm that multi-plugin linkage configuration is enabled.
- Capture the request logs for tool calls, and verify that JSON parameters have no unescaped control characters.
- View the detailed logs of the MCP service, and verify that the range of called plugins matches the configured settings.
