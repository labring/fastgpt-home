# Process Specification and Technical Standard Q&A for Biologics and Aseptic Manufacturing: Source Citation and Traceability

## What data for this category looks like
Typical data sources include cell banks and seed lots, process analysis systems, clean zone monitoring data, MES, LIMS, and equipment integrity test records. Data update frequencies fall into three categories: per batch, real-time, and per monitoring plan. Daily documentation covers cell bank or seed lot records, culture and purification records, aseptic filling records, environmental monitoring reports, media fill simulation records, sterility test reports, and batch release materials. Data fields include batch number, culture temperature, clean zone sedimentation microbial count, equipment runtime, and others. Units include degrees Celsius, CFU/cubic meter, hours, and more.

## What constraints these characteristics impose on the source citation and traceability link
Data sources for this category are scattered across multiple production and monitoring systems. Citation and traceability must accurately match the system and batch associated with the data to avoid cross-batch confusion. Data update frequencies vary widely; real-time monitoring data and batch records must support immediate retrieval and traceability. Document structures are complex with highly specialized fields, so accurate extraction of corresponding field content is required during citation to ensure compliance. Incorrect citations may lead to aseptic assurance failure or entire batch rejection, so the traceability link must have strict accuracy verification mechanisms.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Biologics process documentation has long individual content blocks, requiring sufficient original text fragments for precise traceability |
| `responseData` | Enable original document fragment output | Direct return of knowledge base original text is required to meet compliance requirements and avoid information deviation caused by rewriting |
| `detail` | Enable full traceability information display | Fields such as batch number, detection time, and associated system of the data source must be displayed to comply with production traceability specifications |
| Single search limit | Top 6 search results | Balances traceability accuracy and context length, avoiding exceeding token limits that impact Q&A fluency |
| Maximum context | Calibrated based on actual testing | Document lengths vary significantly across batches, so parameters must be adjusted based on the actual deployed document library |

## Three common errors
- Symptom: Red error prompts appear in search results, and cited document fragments cannot be displayed normally. Cause: The `responseData` parameter is not configured correctly, preventing the system from returning original document content.
- Symptom: During workflow testing, only the first question triggers knowledge base citations, and no citation results appear for subsequent questions. Cause: The parameters of the knowledge base retrieval node are not correctly bound to global variables, or global variables are not passed in subsequent processes.
- Symptom: Non-original modifier text is added to knowledge base content output by the AI. Cause: The system's default content organization function is not disabled, causing the system to rewrite the original text.

## How to confirm configurations are set correctly
- Submit a process question that includes a specific batch number, and check if the returned results include the original fragment of the corresponding document.
- Trigger a multi-turn Q&A process, and confirm that each round of questions can correctly call the knowledge base and return citation content.
- View the citation traceability information, and confirm that it includes fields such as the data source system, detection time, and batch number.
- Confirm that the deployed FastGPT version is v4.17.0 to ensure all configuration item functions are available.

The values provided here are common starting points, and should be evaluated against the reader's own samples.
