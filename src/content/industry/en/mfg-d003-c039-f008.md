# Q&A for Process Specifications and Technical Standards for Electric Motor and Generator Manufacturing: Document Parsing and Chunking

## What this category of data looks like
Typical data for this category comes from winding, insulation, final assembly, and testing departments at electric motor factories and power equipment enterprises. Daily documents include winding process cards, insulation treatment records, dynamic balance reports, dielectric strength insulation test reports, and type and factory inspection test reports. Data sources cover electromagnetic design data, copper wire and insulating material batches, winding equipment, balancing machines, electrical test benches, and ERP/MES systems. Updates occur once per product unit or batch, and are synchronized with each design change. Documents include professional fields such as winding turns, wiring methods, impregnation and drying parameters, vibration values, temperature rise, and dielectric strength values, with corresponding units including turns, degrees Celsius, kilovolts, and others.

## Constraints imposed on document parsing and chunking by these characteristics
The binding of professional fields and their units requires that chunking does not separate parameters from their corresponding descriptions, otherwise the accuracy of subsequent process Q&A will be affected. The coexistence of multiple document types requires parsing tools to adapt to plain text process cards, structured test reports, and tabular data. High-frequency updated batch data requires the parsing link to support fast processing of single or batch files, avoiding long waiting times. Documents for core links such as winding turns verification and insulation system control must retain complete contextual associations, and must not be incorrectly split.

## How to set configurations
All following configurations are compatible with FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Adapts to the paragraph length of winding process cards and test reports, retains complete context for key parameters such as winding turns and dielectric strength values |
| `chunkSplitter` | Split by paragraph + heading | Matches the chapter structure of motor manufacturing documents, avoids splitting process steps or test data blocks |
| `customPdfParse` | Enable table recognition mode | Adapts to structured tabular data in dynamic balance reports and factory test reports, retains field correspondence |
| `PARSE_FILE_TIMEOUT_SECONDS` | 120 seconds | Addresses parsing time consumption for large reports containing large volumes of test data |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | Adapts to batch-uploaded batch test documents |
| `chunkSettingMode` | Manual configuration | Adjust chunking parameters for different document types (process card/test report) to adapt to professional field structures |

## Three common errors
- Phenomenon: Parsing times out after a large factory test report is uploaded, and the interface displays a task timeout error. Cause: The `PARSE_FILE_TIMEOUT_SECONDS` parameter was not adjusted, and the default timeout duration is insufficient to cover the parsing process for multi-page test data.
- Phenomenon: After an Excel-format copper wire batch list is uploaded, the extraction result only retains the header without specific content. Cause: Table analysis adaptation rules were not enabled, and the default chunking logic failed to recognize the cell association relationship in Excel, resulting in data loss.
- Phenomenon: Parsed chunks split a complete winding turns and wiring description paragraph. Cause: The `chunkSize` setting was too small, splitting coherent process steps into multiple independent blocks, losing the contextual binding between parameters and their descriptions.

## How to confirm configuration correctness
A standard winding process card PDF is uploaded, and parsed chunks are checked to confirm they retain the integrity of single process steps, with no split winding turns or wiring parameters.
A dynamic balance report Excel file is uploaded, and extraction of all test data fields is verified, with no null values or cell misalignment.
A single large factory test report under 500 MB is uploaded, and completion of the parsing task within 120 seconds is confirmed, with no timeout errors.
Insulation treatment records and type test reports are uploaded sequentially, and chunks are verified to be automatically separated by document headings and paragraphs, with no incorrect cross-chapter chunking.

The values provided above are common starting points and should be evaluated against samples appropriate to the specific use case.
