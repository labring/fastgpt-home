# Q&A for Process Specifications and Technical Standards for Electroplating and Chemical Surface Treatment: Knowledge Base Retrieval and Recall

## What this category of data looks like
The main entities for this category are electroplating workshops, electronic connector and hardware surface treatment workshops. Daily documents include bath solution analysis records, process parameter cards, fixture records, film thickness and adhesion reports, hazardous waste ledgers, and wastewater monitoring records. Data sources include customer surface treatment specifications, bath solution test results, rectifier operation data, online water quality monitoring records, and hazardous waste management ledgers. Update frequency is per bath cycle, per shift, or according to fixed monitoring cycles. Most documents are structured tables, with fields including tank number, tank temperature (℃), current density (A/dm²), metal ion concentration (g/L), processing time (min), and other parameter items with clear units.

## What constraints do these characteristics impose on the knowledge base retrieval and recall link?
The high proportion of structured tables with dedicated units requires the retrieval pipeline to support structured data matching and unit recognition, to prevent recall failures caused by unit mismatches. Frequently updated data requires the recall pipeline to support incremental synchronization, to ensure retrieval results reflect the latest process parameters and monitoring records. Diverse document types require adaptation to multi-format import and chunking rules, to ensure complete process information is not split apart. Severe potential consequences of errors require recall results to have high confidence, and low-correlation redundant data must be filtered to avoid incorrect process parameters being called.

## Configuration Settings
This configuration applies to FastGPT v4.17.0, and is customized for the process data characteristics of electroplating and chemical surface treatment:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | Electroplating process parameters are highly sensitive to threshold values. A setting that is too low will introduce irrelevant bath solution data, while a setting that is too high will miss matching valid parameters |
| `limit` | `Top 6 entries` | Single process queries usually involve multiple sets of related parameters such as tank temperature, current, and processing time. 6 results can cover complete combined process information |
| `searchMode` | `vector+keyword` | Balances keyword matching for structured fields and semantic vector recall, adapting to the structured characteristics of process parameter cards |
| `usingReRank` | `Enabled` | Electroplating process parameter combinations have strong correlation. Reranking can filter low-correlation bath solution records and improve recall accuracy |
| `datasetSearchUsingExtensionQuery` | `Enabled` | Expands scenario descriptions for user queries. For example, matching "rack plating current" to "current density during rack plating with fixtures", adapting to colloquial queries from workshop sites |
| `collectionIds` | `Bind exclusive knowledge base collections for corresponding electroplating workshops` | Isolates process data from different workshops to avoid parameter confusion and incorrect recall across workshops |

## Three Common Misconfigurations
- Phenomenon: Tabular data cannot be correctly recalled, returning empty results or irrelevant text. Cause: Multi-vector support for structured tables is not enabled, and an indexing mode adapted to tabular data is not configured.
- Phenomenon: API calls return empty fields or a 400 status code. Cause: The `collectionIds` parameter is not specified correctly, or a non-existent knowledge base collection ID is passed.
- Phenomenon: Complete process parameter cards are split into unrelated fragments after chunking. Cause: Reasonable maximum paragraph depth and chunk size are not set, leading to incorrect splitting across parameter groups.

## How to Verify Proper Configuration
- Upload a real bath solution analysis record table, initiate a query containing "bath solution pH value", and check whether the recall results include numerical values for the corresponding fields.
- Call the knowledge base retrieval API, pass the specified `collectionIds` parameter, and check whether the returned results only contain document data from the bound collection.
- After enabling `usingReRank`, compare the recall results before and after enabling to confirm that highly relevant process parameter records appear at the top of the list.
- Initiate a query using colloquial phrasing, such as "current density during rack plating", and check whether the corresponding process parameter card content is recalled.

The values provided here are common starting points, and should be validated against the reader's own samples.
