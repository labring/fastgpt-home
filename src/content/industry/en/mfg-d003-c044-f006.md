# Pulp and Paper Manufacturing Process Specifications and Technical Standards Q&A: Source Citation and Traceability

## What the data for this category looks like
Data sources for pulp and paper manufacturing processes and quality data include wood pulp and waste paper batch archives, DCS/QCS systems, on-paper machine measurement equipment, laboratory test reports, and energy and water treatment system records.
Data update frequencies cover real-time (online quality curves), per shift (beating and pulp blending records), and per roll (sheet break and product change records).
Daily documents include pulp blending sheets, beating logs, paper machine operation logs, online quality curves, laboratory test reports, and sheet break logs. Fields include pulp ratio, beating degree, sheet grammage, moisture content, and more, with corresponding units of %, °SR, g/㎡, %, etc.

## What constraints do these characteristics impose on the "source citation and traceability" link
The multi-dimensional, time-staged data characteristics of pulp and paper manufacturing require the traceability link to match the timeliness and scenario relevance of the data.
Real-time online quality curves must prioritize retrieving the most recently collected content.
Per-shift and per-roll documents must be linked to their corresponding production batches to avoid mixing data across batches.
Format differences across multiple document types (tabular quality curves, textual operation logs) require the traceability module to support content retrieval and display for different structures.
Process adjustments rely on precise parameter matching, so traceability must retain the original units of fields to prevent process judgment errors caused by inconsistent units.
High-speed continuous production characteristics require retrieved associated documents to cover the full process from stock preparation to finished products, avoiding one-sidedness from a single document.

## How to configure
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Value | Basis for This Setting |
| ---- | ---- | ---- |
| Single search limit | Top 3-5 entries | Core process documents for pulp and paper manufacturing are concentrated in three categories: pulp blending, beating, and quality testing. Excessive retrievals will exceed the context capacity limit |
| `quoteMaxToken` | 1200-1800 token | The text length of a single beating record or online quality curve usually falls within this range. Full citation is required to support parameter verification |
| Maximum context | 4000-6000 characters | Must accommodate the complete content of multiple associated documents including pulp blending sheets, beating records, and quality reports to cover the context needs of process Q&A |
| `responseData` | Enable document metadata return | Must label the production batch and collection time of traced documents to match the batch-based update rhythm of pulp and paper manufacturing data |
| `detail` | Enable full content traceability | Process Q&A requires verifying specific parameters such as beating degree °SR and grammage g/㎡. Only document titles are insufficient to support accurate judgment |
| Reordering | Reverse chronological order | Process adjustments for pulp and paper manufacturing rely on the latest operation records and sheet break logs, so the latest data has higher priority |

## Three common errors
-  Configuration errors are prompted during testing, but normal operation can be achieved by forcibly ignoring them. Cause: The corresponding pulp and paper manufacturing knowledge base group is not correctly bound, and the preset pulp blending sheet and operation record dataset is not loaded during testing.
-  Only 1 cited document is returned for Q&A, with the prompt "Knowledge base citation (1 entry)". Cause: The single search limit is configured too low, failing to cover the associated document set for pulp blending, beating, and quality testing.
-  The knowledge base option is empty during invocation, and the preset dataset cannot be selected directly. Cause: The automatic loading configuration of the knowledge base is not enabled, and the data source group must be specified manually.

## How to confirm the configuration is complete
-  Submit a process adjustment-related query, and verify that the cited documents in the returned results include the current production batch's pulp blending sheet and beating record.
-  View the citation traceability module, and confirm that each citation is labeled with the document source, collection time, and corresponding parameter units.
-  Simulate a sheet break scenario query, and verify that sheet break and product change records for the same batch are retrieved.
-  Adjust the query keywords, and confirm that multiple associated documents can be retrieved, with the number of citations matching the preset configuration.

The values provided are common starting points and should be measured against the reader's own samples.
