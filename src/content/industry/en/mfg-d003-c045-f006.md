# Spinning and Weaving Process Specifications and Technical Standards Q&A: Citation Sources and Traceability

## What the data for this category looks like
The main entities in this category are cotton spinning, chemical fiber spinning, woven fabric, and knitted fabric enterprises. Daily production documents include cotton blending or ingredient lists, process setup sheets, equipment operation records, yarn inspection reports, grey fabric inspection reports, defect records, and more. Data sources cover raw fiber inspection, ERP systems, real-time data from spinning and weaving machines, evenness testers, fabric inspection machine test results, and order specification requirements. Data updates trigger synchronously with each batch of raw materials entering the factory, each shift’s production progress, and each roll of fabric completed. Document fields include raw material indicators, process parameters, test results, and equipment operation data. There is no unified fixed format, and adjustments are made based on specific production links.

## What constraints these characteristics impose on the citation sources and traceability link
Because data sources are scattered and update frequency is high, citation traceability needs to connect real-time and historical data from multiple systems and devices at the same time. This places high requirements on retrieval accuracy. A single production batch is associated with a large number of documents, so retrieval scope must be limited to avoid interference from redundant information. Most document fields are professional process parameters, so field names and units must be matched accurately to complete effective traceability. In addition, defect records are strongly bound to production links. Traceability requires associating raw materials, setup processes, and equipment data for the corresponding batch. Complete verification cannot be completed using only a single document. Therefore, support for multi-document association and traceability functions is required.

## How to set the configuration
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Maximum Context | 8000–12000 token | Adapts to the long-text structure of spinning process documents, covering full-process parameters of batching, setup, and inspection |
| Maximum Knowledge Base Citations | Top 6 entries | Matches the total number of documents associated with a single production batch, including cotton blending sheets, inspection records, equipment data, and more |
| Maximum Response Tokens | 1500–2000 characters | Ensures process answers include complete traceability information and parameter details |
| `quoteMaxToken` | 1000 characters | Limits the display length of a single citation to avoid redundant, overly long traceability content in the interface |
| `responseData` | Enabled | Retains complete citation metadata for subsequent traceability verification and log troubleshooting |
| `detail` | Enabled | Displays the document source path and update time of citations, enhancing traceability credibility |

## Three common mistakes
- Symptom: Unconverted \n text appears in cited content, preventing normal line breaks. Cause: The format parsing function of the `detail` configuration is not enabled, so line break markers from original documents are not correctly converted.
- Symptom: The number of retrieved citations exceeds expectations, and irrelevant historical batch data is included. Cause: The value range for maximum knowledge base citations is not reasonably set, and filtering conditions for production batches are not bound.
- Symptom: Citation content in Q&A results cannot be hidden. Cause: `responseData` is mistakenly set to disabled, or the citation hiding option is not correctly checked in the Q&A plugin configuration.

## How to confirm the configuration is correct
This verification must be completed using FastGPT v4.17.0:
- Submit a process Q&A about the twist setting of a specific yarn, and check whether the returned results include traceability information for the corresponding process setup sheet and equipment operation records.
- View the line break effect of cited content, confirm that no \n text remains, and that the format matches the original typesetting of the document.
- Adjust the value of maximum knowledge base citations, verify that the number of retrieved citations changes with the configuration, and falls within the range of document quantities for a single production batch.
- Test enabling the citation hiding function, confirm that Q&A results no longer include any citation-related content or links.

The values provided here are common starting points and should be measured against the reader's own samples.
