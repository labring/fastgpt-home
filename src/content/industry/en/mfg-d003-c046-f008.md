# Process Specification and Technical Standard Q&A for Meat Products and Slaughter Processing: Document Parsing and Chunking

## What data for this category looks like
Typical entities for this category are slaughterhouses, cooked meat and frozen prepared food enterprises. Daily documents include quarantine certificates, slaughter and cutting records, ingredient marinating records, thermal processing records, cold chain temperature records, and microbial test reports.
Data sources cover animal quarantine information, supplier batches, production traceability, temperature collection, metal detection, and laboratory test results. Update frequency is per batch, per shift, and continuous temperature control collection.
Most documents are form-style with fixed fields or sequential records arranged by batch. Fields include batch number, quarantine number, temperature value, test results, and more. Common units are degrees Celsius, kilograms, batch numbers, and similar.

## What constraints these characteristics impose on document parsing and chunking
Documents for this category must strictly associate batches with quarantine information. Chunking must not break the batch-record correspondence. Otherwise, subsequent Q&A cannot accurately match compliance information.
Continuous temperature control records are high-frequency updated sequential data. Chunking must retain the binding between timestamps and corresponding batches to avoid disconnecting time and batches.
Key compliance parameters such as raw-cooked separation and sterilization temperature must be accurately extracted. Chunk boundaries must not cross these key fields.
Multiple imported quarantine certificates must accurately identify the independent fields of each document to avoid confusion across documents.
The accuracy of parsing and chunking directly affects the reliability of subsequent compliance Q&A. Errors may trigger product recall risks.

## How to set configurations
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | This category's documents include short fields such as batch numbers and temperature values. Excessively large chunks will separate batches from their corresponding records |
| `chunkSplitter` | By paragraph + fixed character boundary | Slaughter and thermal processing records are mostly fixed-format content arranged by batch. Splitting by paragraph preserves record integrity |
| `customPdfParse` | Enabled | Quarantine certificates and test reports are mostly PDF documents with fixed fields. Enabling this allows accurate extraction of key information within fields |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | Single-batch continuous temperature control records may include multiple CSV or PDF files. This value covers conventional bulk import needs |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 seconds | Parsing multiple imported quarantine certificates takes time. A too-low timeout setting will cause large file parsing failures |
| `chunkSettingMode` | Manual configuration | Adjustments to chunk boundaries are required for batch numbers and temperature fields. Manual configuration enables precise matching of business document structures |

## Three common mistakes
- Uploading Excel-format slaughter records results in empty parsed fields. The cause is that custom parsing rules for Excel-format batch records are not configured, leading to incorrect recognition of table fields.
- Parsing bulk temperature control records returns a timeout error. The cause is that `PARSE_FILE_TIMEOUT_SECONDS` is set too low, and does not adapt to the large file parsing duration of continuous temperature control records.
- Batch numbers and their corresponding temperature records are separated in chunking results. The cause is that `chunkSize` is set too large, crossing the paragraph boundary between batch headers and their corresponding records.

## How to confirm correct configuration
- Upload a single quarantine certificate PDF with a batch number. Check if the parsed text fully retains key field content such as quarantine number and batch number.
- Upload a single Excel-format temperature control record file. Confirm that the parsed chunks include complete timestamps and corresponding temperature values.
- Upload multiple documents for bulk import. Check that the parsing progress has no timeout errors, and chunks of each document are not confused with those of other documents.
- Adjust `chunkSize` to different values. Verify that chunks retain the binding relationship between batches and their corresponding records.

The values provided are common starting points and should be measured against the samples applicable to the actual use case.
