# Process Quality and Final Product Release: Work Instructions and Technical Standard Q&A — Citation Sources and Traceability

## What This Category’s Data Looks Like
The core data for this category comes from the IPQC, FQC, quality engineering, and laboratory teams of manufacturing enterprises. It covers documents including control plans, patrol inspection records, SPC reports, final product inspection reports, nonconforming product reviews, release orders, and quality monthly reports. Data sources include MES systems, testing equipment, laboratory systems, process parameter libraries, customer standards, and historical defect databases. Update frequency is per production batch, per shift patrol inspection, or continuous collection. Document fields include process parameters, inspection items, nonconformity judgments, release conclusions, and some fields have professional units such as mm, MPa, ppm.

## Constraints for Citation Sources and Traceability
Multi-source and frequently updated data requires the traceability link to accurately associate original data sources. This prevents accidental release of nonconforming products caused by expired data or mixed-up sources. Diverse document structures require adaptation to different chunking and metadata extraction rules, ensuring that cited content can be mapped to specific document sections or inspection items. In high-volume production scenarios with frequent queries, the traceability system must quickly match and return accurate associated information. It must also isolate inspection data from different batches to prevent incorrect cross-batch citations.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Similarity threshold | 0.75–0.85 | Matches term density in manufacturing specialized documents, filters low-correlation recall results |
| Single search limit | Top 6 results | Covers multiple associated documents involved in a single batch inspection, avoids missing key process references |
| `quoteMaxToken` | 1200–1500 token | Retains complete standard clauses or inspection item text, ensures completeness of traceability information |
| `responseData` | Enable metadata collection | Associates document names, section numbers, inspection item fields, and other information to meet traceability requirements for quality documents |
| `detail` | Enable | Displays contextual content of cited text, making it easier to verify whether process parameters meet standards |
| Maximum context length | 8000 characters | Accommodates associated content from multiple inspection reports and control plans, supports queries for complex process issues |

## Three Common Configuration Mistakes
- Symptom: Returns document fragments unrelated to the query. Cause: Did not adjust the similarity threshold for manufacturing specialized documents, resulting in low-matching generic text being incorrectly recalled.
- Symptom: Traceability information only includes document names without section or field identifiers. Cause: Did not enable the `responseData` metadata collection function, only returning plain text fragments.
- Symptom: Query results are truncated or time out. Cause: Did not properly set `quoteMaxToken` and maximum context length, exceeding system processing limits leading to content loss.

## How to Verify Correct Configuration
- Upload a control plan and final product inspection report, initiate a query that includes specific process parameters, and check whether the returned results are associated with the corresponding document sections and inspection items.
- View the citation section of the response, confirm that it includes metadata such as document names, section numbers, and inspection item numbers.
- Adjust the similarity threshold to 0.8, initiate a fuzzy query, and verify that only content matching process standards is recalled.
- Test batch queries for multiple inspection documents from different batches, confirm that the traceability information in returned results has no cross-batch confusion or omissions.

The values provided are common starting points and should be evaluated against applicable samples.
