# Process Specification and Technical Standard Q&A for Metal Cutting Machining: Citation Sources and Traceability

## What the Data for This Category Looks Like
Sources of metal cutting machining data include product drawings and 3D models, CAPP/CAM systems, machine tool collection data, tool management systems, MES, and measurement and inspection tool records. Daily documents include process routes, operation cards, CNC programs, first-piece inspection records, patrol inspection sheets, and measuring tool calibration records.
Update frequency is triggered by work orders, individual products, sampling inspection results, or tool changes. Each document includes fields such as operation number, clamping scheme, tool model, dimensional tolerance, and CNC program line number. Units are mostly millimeters, minutes, seconds, and other standard mechanical machining units.

## Constraints on Citation Sources and Traceability
Precise association of document identifiers across different systems is required during traceability for multi-source heterogeneous data sources. This prevents citation confusion between different data sources.
The high-frequency update feature requires real-time synchronization of the latest operation cards, tool parameters, or inspection records by the traceability function. This ensures cited content matches the current production status.
Matching key attributes such as operation number and tool model is required during traceability due to complex document structures and detailed fields. Relying solely on document titles cannot achieve precise traceability.
Traceability results must quickly locate original data for business scenarios where errors lead to serious consequences. This avoids workpiece scrap or machine tool failures caused by citation errors.

## Configuration Settings
This configuration is based on FastGPT v4.17.0. The specific parameter settings are as follows:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `2000–3000 token` | Matches the single-block content length of metal cutting process documents, to avoid truncation of key operation parameters and CNC program fragments |
| `responseData` | Includes citation source ID and document fragments | Meets the need to quickly locate original production documents during traceability, and adapts to traceability verification for interface calls |
| `detail` | Enabled | Displays specific fields of cited documents such as operation number and tool model, improving the readability and verifiability of traceability information |
| Single search limit | Top 6 entries | Covers the typical number of cited documents per work order, avoiding redundant results interfering with traceability judgment |
| Knowledge base citation merging | Enabled | Merges citations of multiple associated documents for the same operation, simplifying information display on the traceability interface |
| Timeout threshold | `60 seconds` | Adapts to the delay characteristics of machine tool data synchronization, avoiding citation failures caused by collection delays |

## Three Common Configuration Errors
- The citation field returned in conversations is empty. This occurs when the `responseData` configuration item is not enabled, and relevant fields for citation sources are not specified for return.
- Cited content truncates key operation parameters. This occurs when the value of `quoteMaxToken` is too small to cover the complete content of a single process document.
- The number of search results does not match the actual matched documents. This occurs when the single search limit is set unreasonably, failing to match the document quantity requirements for metal cutting machining.

## How to Confirm Proper Configuration
- Initiate a conversation that includes process parameter queries, and check whether the returned results include the document identifier and fragment of the citation source.
- View the configured value of `quoteMaxToken`, and verify that cited content of long documents is not truncated.
- Compare cited document fragments with original process files, and confirm that fields match accurately.
- Simulate a query scenario after a tool change, and confirm that the citation source can reflect the latest tool parameter data in a timely manner.

The values provided are common starting points and should be evaluated against the reader's own samples.
