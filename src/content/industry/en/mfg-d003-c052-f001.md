# Process Specification and Technical Standard Q&A for Steel Rolling and Finishing: HTTP Interfaces and External Systems

## What data for this category looks like
Data for this category originates from slab or billet batch information, furnace operating parameters, mill automatic control data, online thickness and width measurement results, surface inspection reports, and MES systems. Daily documents include rolling plans, heating schedules, rolling specifications, shape and thickness records, surface quality reports, and quality certificates. Data is updated per coil or billet, with some online parameters synchronized in real time. Document fields include batch number, heating temperature, rolling reduction rate, finished product thickness, surface defect level, and other relevant fields. Units include degrees Celsius, percentage, millimeters, and other standard units.

## Constraints for HTTP Interfaces and External Systems
Real-time data updated per coil or billet, plus multi-dimensional documents, impose requirements on HTTP interfaces. Interfaces must support batch number as a query parameter. The dataset returned in a single request must not be excessively large. Multi-source data docking demands interfaces compatible with format specifications from different external systems. Standardized request headers must transmit identity verification information. For real-time synchronization scenarios, interfaces need reasonable timeout thresholds. These thresholds prevent request blocking caused by mill line interruptions. Variations in fields between process specifications and standard documents require the `responseData` returned by the interface to flexibly map to local business fields.

## Configuration settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `Authorization` | Use Bearer Token format, carry access keys assigned by the business system | Complies with general identity verification specifications for external system APIs, and adapts to access requirements for steel rolling enterprise MES systems |
| `variables` | Pass billet batch numbers and product specification parameters | Accurately matches business requirements for coil or billet-based queries, narrows search scope to improve response speed |
| `responseData` | Map to fields such as rolling batch, heating temperature, finished product thickness | Compatible with data structures of local business systems, facilitating subsequent process calls |
| Single search limit | Top 10 entries | Covers the number of associated documents for a single coil batch, avoids returning redundant data |
| Request timeout | 600 seconds | Adapts to real-time synchronization delays for online inspection data, prevents request failures from mill line process interruptions |

## Three common misconfigurations
- Symptom: API calls return results unlinked to historical queries, and context is lost. Cause: Session context parameters are not passed in `variables`, so each request runs as an independent search.
- Symptom: Requests return a 401 Unauthorized error, and access to external Basic Auth interfaces fails. Cause: The Basic authentication format for the `Authorization` header is not configured correctly, and credentials are not Base64 encoded.
- Symptom: MCP tools cannot receive global variable tokens in workflows. Cause: Global variables are not bound to the tool's `variables` parameter, so parameters are not passed with the request.

## How to verify successful configuration
- Send a test request with a billet batch number as the `variables` parameter, and confirm the returned results include rolling specification documents for the matching batch.
- Review interface logs to verify the `Authorization` header is correctly included, with no identity verification-related errors.
- Trigger an MCP tool call, and confirm workflow global variables are properly passed to the tool's parameters.
- Simulate mill line real-time data updates, and confirm the interface returns the latest shape and thickness records within a reasonable timeframe.
