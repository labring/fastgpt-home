# Process Specification and Technical Standard Q&A for Steel Rolling and Finishing: Citation Sources and Traceability

## What this category’s data looks like
Daily documents for steel rolling and finishing include rolling plans, heating schedules, rolling specifications, plate shape and thickness records, surface quality reports, and quality certificates.
Data sources cover slab or billet batches, heating furnaces, mill automatic control systems, online thickness and width measurement systems, surface inspection systems, and MES systems.
Data is generated in real time per coil or individual steel piece.
Fields include batch number, heating temperature, rolling reduction, flatness deviation, thickness deviation value, and similar items.
Units use common industrial measurement standards such as degrees Celsius and millimeters.

## Constraints for Traceability Processes
Real-time data updated per coil or piece requires traceability to tie to the unique identifier of a specific coil or batch. This prevents cross-batch confusion.
Multiple types of on-site document sources require traceability to distinguish between automatically collected inspection data and manually compiled specification documents. Source attributes must be clearly defined.
Single documents containing precise process parameters require traceability to avoid truncating key information. Full document segments corresponding to the parameters must be retained.
Consequences of errors such as coil downgrading, strip breakage, equipment damage, or customer complaints require traceability to link to specific document entries and generation times. This supports rapid location of problem root causes.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `1500–2000 token` | Matches the length of a single rolling specification or inspection report. Prevents truncation of key process parameters such as heating temperature and rolling reduction |
| `responseData` | Enabled | Ensures the conversation interface returns knowledge base referenced document IDs and batch association fields. Enables precise traceability |
| `detail` | Enable full traceability information | Displays upload time, document type, and associated coil batch for referenced documents. Supports on-site personnel verification |
| Single search limit | Top 6 entries | Covers all relevant documents for a single steel coil, including rolling plans, heating schedules, and multiple inspection reports |
| Citation merging threshold | Calibrated via actual measurement | Avoids merging rolling data from different batches. Ensures traceability results fully match the queried coil batch |

## Three Common Misconfigurations
- Phenomenon: No knowledge base referenced ID field appears in results after calling the conversation interface. Cause: The `responseData` configuration item is not enabled. The interface does not generate traceability-related return data.
- Phenomenon: Key rolling temperature or thickness deviation parameters are truncated in referenced content. Cause: The `quoteMaxToken` value is too small. It cannot cover the complete process information of a single document segment.
- Phenomenon: Referenced entries include rolling data from other batches. Cause: The search scope is not filtered by coil batch dimension. This leads to incorrect traceability associated documents.

## How to Verify Successful Configuration
Call the FastGPT v4.17.0 conversation interface. Check if return results include referenced document IDs and batch association fields. Confirm the `responseData` configuration is active.
Enter a query specifying a target coil batch number. Verify all returned referenced documents are associated with that batch’s rolling specifications and inspection reports.
Check the length of returned referenced content. Confirm no key process parameters are truncated. Verify the `quoteMaxToken` value is reasonable.
Check the referenced list displayed on the interface. Confirm each entry is marked with document type and upload time. Verify the `detail` configuration is enabled.
