# Process Specification and Technical Standard Q&A for Iron and Steel Smelting and Continuous Casting: Tool Calling and Plugins

## Data characteristics for this category
Data sources include iron melt and scrap steel data, L2 process control systems, laboratory testing systems, MES manufacturing execution systems, energy medium systems, and equipment condition monitoring systems.
Updates occur per heat, in real time, and per shift. The coverage spans the full workflow from raw material input to finished product judgment.
Daily documents include heat plans, batching lists, converter smelting records, composition reports, continuous casting process records, and slab judgment sheets.
Fields covered include heat numbers, smelting temperatures, element composition values, casting rhythm parameters, and defect judgment results.
Units include degrees Celsius, tons, minutes, and other standard units.

## Constraints for tool calling and plugins
Multi-source heterogeneous data sources require plugins to adapt to different system interface protocols and data formats to prevent call failures.
Real-time and high-frequency update characteristics require tool calling to set short timeout periods to avoid blocking high-temperature continuous production processes.
The tightly coupled business logic of heats and casting sequences requires tool calling to precisely match the context of the current heat or casting sequence to avoid interference from cross-batch data.
Structured and semi-structured document structures require plugins to support extraction and parsing of different fields to ensure accurate parameter returns in Q&A responses.
The requirement that production processes cannot be stopped arbitrarily requires tool calling to have a lightweight failure retry mechanism to avoid long-term production interruptions.

| Workflow/API tool selection | `auto` | Automatically matches corresponding process documents or real-time data tools based on user questions, adapting to temporary adjustment needs during raw material fluctuations |

| Context window length | `8000–12000 characters` | Supports multiple sets of parameter documents for smelting and continuous casting processes, ensuring complete Q&A logic |
| Failure retry count | `2 times` | Addresses occasional system fluctuations, avoiding production delays caused by excessive retries |

## Three common configuration errors
- Symptom: Empty results returned after calling the image tool, with interface status code 401 displayed on the page. Cause: HTTP request header parameters adapted to iron and steel continuous casting process images (such as slab defect images, furnace temperature monitoring images) are not configured, resulting in database interface authentication failure.
- Symptom: Token limit exceeded error returned by tool calling. Cause: The number of document characters returned by a single tool call is not restricted, resulting in returned content exceeding the model's context limit.
- Symptom: Setting `toolChoice` to a fixed tool prevents adaptation to temporary process adjustments during raw material fluctuations. Cause: Automatic tool selection is not enabled, only preset fixed documents are called, and real-time L2 process data cannot be obtained.

## How to verify correct configuration
- Initiate a process Q&A that includes a specific heat number, and check whether the batching list and smelting record tools for the corresponding heat are automatically called.
- Simulate a raw material fluctuation scenario in a question, and verify whether `toolChoice` automatically selects the real-time data tool.
- Disconnect the simulated MES system interface, and check whether the failure retry mechanism is triggered and a clear call failure prompt is returned.
- Upload an image request related to slab judgment sheets, and verify that the HTTP request tool can correctly return and display the image.

The values provided are common starting points and should be measured against the reader's own samples.
