# Forging and Die Forging Process Specification and Technical Standard Q&A: Document Parsing and Chunking

This document is written based on FastGPT v4.17.0.

## What Data for This Category Looks Like
Core data for forging and die forging scenarios comes from raw material quality certificates, heating furnace system data, press collection data, MES systems, non-destructive testing instruments, and customer forging part drawings. Daily generated documents include forging process specifications, cutting cards, heating furnace records, forging process cards, mold life records, heat treatment work orders, and ultrasonic testing reports. Data updates per forging part, batch of workpieces, or furnace heat. Documents contain professional fields such as forging ratio, heating temperature, holding time, mold life count, and forging dimensional tolerances. Some documents include non-standard format forging part graphic annotations and furnace batch number associated information.

## What Constraints Do These Characteristics Impose on the Document Parsing and Chunking Link
Data for this category updates per batch or furnace heat, and contains a large number of professional technical fields. Document parsing must retain the association between fields and batches to avoid mixing content across batches. Daily documents include both structured forms and unstructured process descriptions, so content boundaries of different formats must be distinguished. Professional terms such as forging ratio and fiber direction must be fully retained within a single chunk, and cannot be forcibly split. Large batch documents containing multiple furnace heat records may require extended parsing time, so parsing interruptions due to timeouts must be avoided.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Matches the description length of a single working step in forging process specifications, avoids splitting continuous professional content such as deformation steps and heating zones |
| `chunkSplitter` | By paragraph + professional term boundary | Adapts to natural separation of professional paragraphs such as heating zones and deformation steps, retains the integrity of associated fields such as furnace batch numbers and hardness values |
| `customPdfParse` | Enabled | Adapts to non-standard format forging testing reports and heat treatment work orders, extracts embedded non-general fields such as furnace batch numbers and forging dimensions |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 seconds | Addresses large process documents containing multiple furnace heat records, prevents parsing from being forcibly terminated due to timeout |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Accommodates batch collection documents such as heating furnace records and ultrasonic testing reports |
| `chunkSettingMode` | Manual configuration | Adjusts chunking rules for forging professional documents, adapts to non-general process term structures and document formats |

## Three Common Misconfigurations
- Phenomenon: When calling the large model, the file parsing tool fails to start, and the interface displays parsing task timeout. Cause: The `PARSE_FILE_TIMEOUT_SECONDS` parameter is not adjusted to a value suitable for large process documents, resulting in termination of parsing before completion.
- Phenomenon: After uploading a PDF, only meaningless line break text is extracted, and professional fields such as furnace batch numbers and heating temperatures are all lost. Cause: The `customPdfParse` configuration is not enabled, making it impossible to adapt to non-standard format annotations and embedded fields attached to forging part drawings.
- Phenomenon: Adjacent heating temperature parameters and corresponding forging batch numbers are split into different chunks after chunking. Cause: The `chunkSplitter` configuration is set to fixed character splitting, and no splitting is performed according to professional paragraph boundaries.

## How to Confirm Proper Configuration
- Upload a forging process specification PDF containing furnace batch numbers, heating temperatures, and deformation step descriptions, and check whether complete professional fields and paragraph structures are retained after parsing.
- View the parsing task running logs, confirm that no timeout errors occur, and the parsing time is within the configured range of `PARSE_FILE_TIMEOUT_SECONDS`.
- Manually split a cutting card document, compare with the automatic chunking result, confirm that professional units such as deformation steps and heating zones are not split across chunks.
- Upload a batch testing report collection that does not exceed the configured value of `UPLOAD_FILE_MAX_SIZE`, confirm that the parsing task can start and complete normally.

The values given are common starting points and should be measured against the reader's own samples.
