# Forging and Die Forging Process Specification and Technical Standard Q&A: Knowledge Base Retrieval and Recall

## What this category of data looks like
This category of data supports the entire production process of forging plants, aerospace and automotive forging suppliers. Core documents include forging process specifications, cutting cards, heating furnace records, forging process cards, mold life records, heat treatment work orders, ultrasonic testing reports, and more. Data sources cover raw material quality certificates, heating furnace systems, press collection data, MES systems, non-destructive testing instruments, and customer forging drawings. Data updates follow the rhythm of each individual forging piece, each batch of materials, or each furnace production run. Core fields include forging model, material grade, heating temperature, deformation step, testing results, and more. Units involve physical quantities such as degrees Celsius, tons, millimeters, and others.

## What constraints these characteristics impose on knowledge base retrieval and recall
Data sources are scattered and bound to unique identifiers such as forging batch numbers and furnace numbers. Retrieval must accurately match these identifiers to retrieve valid results; otherwise, documents from unrelated production lines will be returned. The high-frequency update rhythm requires the knowledge base to support incremental synchronization, to avoid old batch data interfering with retrieval in current production scenarios. Documents contain both structured parameters and unstructured reports, so retrieval needs to distinguish matching weights for different types such as professional terminology and testing data. Core parameters such as forging ratio and fiber direction are key for process decision-making, so retrieved results must prioritize matches for these fields.

## How to set the configurations
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | Forging process parameters are professional terminology, so high matching accuracy must be maintained to avoid mixing in irrelevant results |
| `limit` | Top 8 entries | The number of process documents for a single batch of forgings is limited; too many results will exceed the context window |
| `searchMode` | Semantic + keyword hybrid retrieval | Both professional terminology keywords need to be matched, and semantic associations for structured fields such as batch and furnace numbers need to be linked |
| `usingReRank` | Enabled | Forging documents have a large number of similar parameter descriptions; re-ranking can filter redundant results and prioritize content strongly related to process specifications and testing standards |
| `datasetSearchUsingExtensionQuery` | Enabled | Implicit retrieval conditions such as forging batch numbers and material grades can be supplemented through extended queries to improve retrieval accuracy |
| `collectionIds` | Bind the exclusive knowledge base collection of the current production line | Avoid interference from unrelated data across production lines, matching the exclusive data scope of the production scenario |

## Three common misconfigurations
- Phenomenon: When selecting a knowledge base, no dynamic variables are associated, and retrieval results return forging documents from non-current production lines. Cause: Forging batch numbers and furnace numbers are not passed into the configuration as retrieval variables, resulting in a matching scope that exceeds the current production batch.
- Phenomenon: Knowledge base retrieval time exceeds the preset threshold, and a loading timeout prompt appears on the page. Cause: The re-ranking function is not enabled and the number of retrieved entries is set too high, or the retrieval scope covers the full non-exclusive dataset, increasing matching calculation volume.
- Phenomenon: The image address in the returned ultrasonic testing report is truncated, only showing part of the path. Cause: The absolute storage path of images was not retained during document import, or the knowledge base is not configured with complete resource mapping rules.

## How to confirm the configuration is correct
- Submit a test retrieval request carrying the forging batch number and furnace number of the current production line, and check whether the retrieved results only include process documents and testing reports for the corresponding batch.
- Adjust the `similarity` parameter range, and verify whether the professional terminology matching degree of the retrieval results meets the requirements of the current process scenario.
- After enabling the re-ranking function, compare the sorting of retrieval results before and after enabling to confirm that redundant similar documents have been filtered out.
- Import a single ultrasonic testing report document, and check whether the returned image address is complete and not truncated after retrieval.

The values provided are common starting points and should be measured against the reader's own samples.
