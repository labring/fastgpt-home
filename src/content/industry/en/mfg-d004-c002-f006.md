# Cross-review of technical documents for SMT mounting and electronic assembly: Citation sources and traceability

## What the data for this category looks like
Daily data for SMT mounting and electronic assembly covers work order-level full-process documents. These include BOM and coordinate files, line change tables, stencil and reflow oven temperature records, first article confirmation reports, SPI/AOI inspection reports, maintenance records and traceability labels.
Data sources include customer-delivered BOM, Gerber and coordinate files, MES system data, solder paste and component batch information. It also includes real-time collected data from mounters, SPI/AOI detectors and reflow ovens.
Data updates per work order and each line change. Some inspection data syncs in real time.
Document fields include part number, reference designator, component batch number, reflow oven temperature parameters, mounting coordinates and more. Most units use degrees Celsius and millimeters.

## What constraints do these characteristics impose on the citation sources and traceability link
High-frequency, real-time updated work order-level data requires the traceability system to accurately bind to the corresponding work order’s data source. This prevents citation confusion across work orders.
Multi-source, heterogeneous document types and professional fields require the recall process to match precise fields such as part number and reference designator. This meets professional retrieval needs.
Each work order has closely linked documents. Traceability must simultaneously associate component batches, mounting records and inspection reports. This ensures full process traceability when problems occur.
Real-time data synchronization requires the recall link to have low latency. This prevents citation errors caused by data lag.

## How to set the configuration
| Configuration Item | Recommended Value Range | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Adapts to the total length of core documents such as BOM and SPI reports for a single work order, avoiding truncation of key fields |
| `responseData` | Enabled | Used to return metadata required for traceability, such as citation source document ID, work order number, component batch number |
| `detail` | Enabled | Used to display specific field details of cited content, such as reflow oven temperature curve parameters, mounting coordinates |
| Similarity threshold | 0.72–0.85 | Matches the professional semantics of unique fields in SMT documents, avoiding recall of irrelevant work order data |
| Single recall limit | Top 5–7 entries | Covers the number of core citation documents required for a single work order, avoiding redundant content interfering with retrieval results |

## Three common misconfigurations
- Phenomenon: Directly filling in the knowledge base ID or citation variable produces consistent output results. Associating the variable with the knowledge base triggers a system error. Cause: The mapping rule between the variable and the corresponding work order data source is not configured in FastGPT v4.17.0, or the variable is not bound to the correct knowledge base storage path.
- Phenomenon: Adjusting the similarity threshold to the minimum and single recall limit to the maximum leaves the number of recalled content fixed with no change. Cause: The dynamic matching logic for the number of recalled entries is not correctly enabled, or the system does not recognize the adjusted threshold parameter configuration.
- Phenomenon: Output content appears as raw Markdown format text, without rendered typesetting effects. Cause: The rendering switch for the response format is not enabled, or the trigger rule for formatted output is not specified in the prompt.

## How to confirm the configuration is complete
- Upload the BOM and SPI inspection report for a test work order. A corresponding query is initiated. Check whether the returned results include the citation source document ID and work order number.
- Adjust the value of the `quoteMaxToken` parameter. Observe whether the length of the returned cited content changes with the parameter adjustment.
- Adjust the value of the similarity threshold. Observe whether the number of recalled citation entries changes with the threshold adjustment.
- Check the response format configuration. Confirm that the Markdown rendering mode is enabled. Verify that the output content has formatted typesetting effects.

The values provided are common starting points and should be measured against the reader's own samples.
