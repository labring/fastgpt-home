# Cross-Review of Technical Documentation for Dairy Processing: Deployment and Upgrade

## What the Data for This Category Looks Like
Typical entities are liquid milk, yogurt, milk powder, and dairy ingredient enterprises.
Daily documents include raw milk acceptance records, standardized ingredient lists, pasteurization or UHT heat treatment records, CIP cleaning records, filling records, reserved sample and microbial test reports.
Data sources include milk source testing equipment, MES systems, homogenization and heat treatment equipment, online temperature and flow collection systems, CIP systems, and LIMS laboratory management systems.
Data updates occur per milk tank, per batch, or in real time.
Fields include raw milk antibiotic and physicochemical indicators, heat treatment time and temperature parameters, aseptic filling verification data, and corresponding testing unit and equipment number for each entry.

## Constraints for Deployment and Upgrade
High-frequency real-time data updates require deployments to support high-concurrency data read and write operations. This prevents document synchronization interruptions caused by exhausted connections.
Multiple heterogeneous data sources require configuration of multiple storage connection types. This accommodates structured physicochemical indicator data and unstructured test reports.
Document fields include professional production parameters. Deployments must ensure accurate data mapping. This avoids missing fields or unit errors during cross-review.
Error consequences include rejection of an entire milk tank of raw milk or large-scale product recalls. Deployments must configure complete failure retry and alert mechanisms. This ensures the stability of the review process.

## Configuration Settings
This page applies to FastGPT v4.17.0 open source edition.

| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30 connections` | Adapts to real-time write concurrency per milk tank, avoids exhausting database connections |
| `MONGODB_URI` | `mongodb://<db-user>:<db-pass>@<host>:27017/fastgpt_dairy?authSource=admin` | Connects to LIMS systems and unstructured storage for reserved sample microbial test reports, supports high-frequency read/write |
| `PG_URL` | `postgresql://<pg-user>:<pg-pass>@<host>:5432/fastgpt_dairy?sslmode=disable` | Stores relational production data such as standardized ingredient lists and CIP records |
| `REDIS_URL` | `redis://:<redis-pass>@<host>:6379/0` | Caches real-time temperature and flow data, equipment status data, reduces pressure on core databases |
| `FE_DOMAIN` | Internal domain after enterprise Nginx proxy | Fixes proxy redirection issues for knowledge base original links, ensures normal internal access |
| `FILE_TOKEN_KEY` | 32-character random string | Encrypts knowledge base file download tokens, prevents unauthorized access to production documents |
| `ROOT_KEY` | Random string with complexity no lower than 12 characters | Verifies highest permissions for the admin backend, ensures security of deployment configurations |

## Three Common Configuration Errors
- Phenomenon: Docker deployment starts and displays a database authentication failure error. Logs show connection refused. Cause: Failed to correctly modify database password parameters in `MONGODB_URI` and `PG_URL`. Default initial passwords were retained.
- Phenomenon: After Nginx proxy configuration is complete, knowledge base original links fail to redirect properly. Access returns a 404 status code. Cause: Failed to set `FE_DOMAIN` to the internal domain after Nginx proxy. Links point to the container's default internal network address, which cannot be accessed externally.
- Phenomenon: After local deployment, the admin backend has no team invitation feature entry. The page prompts that the feature is not enabled. Cause: Failed to set `ROOT_KEY` and enable the team module via system settings. The open source edition does not activate this feature by default.

## How to Confirm Proper Configuration
- Log in to the FastGPT admin backend's data source management page. Test the connection status of `MONGODB_URI`, `PG_URL`, and `REDIS_URL` individually. Confirm all show normal connections.
- Upload a standardized ingredient list document to generate a knowledge base. Click the original link in the document details. Confirm redirection to the preset internal access address, with no 404 errors.
- Use `ROOT_KEY` to access the system settings page. Confirm the team function switch is enabled. The page displays team invitation related configuration items.
- Batch import 5 batches of CIP records. Observe that the database connection count in backend monitoring does not exceed the set `DB_MAX_LINK` value. No connection timeout logs are output.

The values given are common starting points and should be measured against the reader's own samples.
