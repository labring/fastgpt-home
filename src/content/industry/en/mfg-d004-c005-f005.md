# Cross-Review of Technical Documentation for Photovoltaic Cell Manufacturing: Tool Calling and Plugins

## What the Data for This Category Looks Like
Typical stakeholders are process, equipment, quality control, and production departments of polysilicon cell manufacturing enterprises. Daily documents include process cards, diffusion and coating parameters, printing and sintering records, EL inspection images, IV grading data, and yield reports. Data sources include silicon wafer incoming materials, MES systems, diffusion furnaces, coating equipment, printing presses, EL and IV testing equipment, and laboratory data. Update frequency follows per batch, per piece inspection, and daily cycles. Data fields include diffusion furnace temperature range, printing beat, EL inspection pixel coordinates, IV test voltage values, and similar items. No unified standard format is used.

## Constraints on Tool Calling and Plugins
The multi-source heterogeneous data characteristics of photovoltaic cell manufacturing create multiple constraints for tool calling and plugin configuration.
Unstandardized output formats from directly connected multi-device data sources require plugins to adapt to different device output formats, preventing parsing failures.
High-frequency per-piece inspection data requires tool calling to control single processing volume and frequency, avoiding timeouts or excessive resource consumption.
Scenarios with multiple document types require enabling multimodal plugins to support parsing of image and table data.
The strong association of piece-level data requires tool calling to accurately link process parameters and inspection results from the same batch, eliminating interference from cross-batch data.
Additionally, use the `functionCall` mode to enforce standardized plugin calling formats, ensuring returned results meet the field requirements of photovoltaic business workflows.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| Workflow/API function-call configuration | Mandatory mode | Ensure plugin calling format meets standardized requirements for photovoltaic document parsing, avoid format parsing failures |
| Workflow/API tool selection | Fixed binding to photovoltaic-specific plugin group | Limit calling scope, only use tool plugins adapted to photovoltaic data, reduce interference from unrelated tools |
| Single tool call timeout | 600 seconds | Adapt to time requirements for batch pulling of equipment inspection data, avoid call interruptions due to large data volume |
| Multimodal plugin support | Enabled | Adapt to parsing and visualization requirements for non-text documents such as EL inspection images and IV test curves |
| Maximum parsed length per document | 800–1200 characters | Adapt to parsed length requirements for text documents such as process cards and parameter tables, avoid content truncation |
| Context-associated document limit | First 8 entries | Focus on process and inspection data from the current production batch, reduce interference from irrelevant information |

## Three Common Misconfigurations
- Tool calling results are only displayed when re-entering the session, with no real-time return in the dialog box. Cause: Plugin calling result synchronization logic is not configured correctly, only cached data is loaded when the session is rebuilt.
- Basic chart plugin outputs `none`, and cannot generate visualization links for IV test curves. Cause: The parameter field names passed to the plugin do not match the actual fields of photovoltaic IV data, and core parameters such as voltage and current are not correctly mapped.
- File processing plugin cannot be found. Cause: The current FastGPT version does not include a universal file processing plugin built-in. Manually install the corresponding plugin package or upgrade to FastGPT v4.17.0 or higher.

## How to Verify Correct Configuration
- Submit a test request containing photovoltaic process parameter queries, verify that the request parameters for tool calling include corresponding business fields such as diffusion temperature and printing speed.
- After triggering plugin calling, check whether the session log contains complete tool return data, confirm that the results are not truncated or filtered.
- Switch photovoltaic document data from different batches, verify that plugin calling can correctly adapt to process cards and EL inspection images in different formats.
- Check the plugin installation status, confirm that all dependent tool plugins are enabled and their versions match the current FastGPT version.
