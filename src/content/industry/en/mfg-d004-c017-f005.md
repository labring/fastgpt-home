# Cross-Review of Technical Documentation for Spraying and Coating: Tool Calling and Plugins

## What data for this category looks like
Business data for this category covers coating line scenarios for automobiles, home appliances, construction machinery, and metal furniture. Daily documentation includes coating process cards, paint batch sheets, paint mixing records, film thickness and color difference reports, oven curves, defect repair sheets, and VOCs logs. Data sources include coating supplier TDS/SDS, data collected from spray booths and ovens, colorimeters, film thickness gauges, environmental monitoring equipment, and MES systems. Updates are generated per batch of paint and per shift for corresponding batch documents. Spray booth and oven data is collected continuously. Document fields include process temperature (unit: degrees Celsius), spray pressure (unit: megapascals), paint viscosity (unit: Ford cup seconds), film thickness (unit: micrometers), and additional relevant parameters.

## What constraints these characteristics impose on tool calling and plugins
Data for this category comes from multiple sources and has varied update rhythms. Multiple batch documents and real-time collected data must be included in the review scope at the same time. Tool calling must support parallel pulling of multiple data sources. Document fields include specific units and process parameters. Tool calling must include built-in field verification logic to prevent unit mismatches or parameter format errors. Frequently updated oven and spray booth data requires tool calling trigger frequency to match production tempo. The context length of a single call should not be excessive. Tool calling must support cross-document associated queries, binding process cards and oven curves for retrieval. Associated review requires matching documents from pre-treatment, spraying, and curing stages.

## How to configure settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Adapts to mixed scenarios in coating review that include both built-in parameter verification and external data source pulling, automatically selecting the calling method |
| Maximum single-recall documents | Top 10 entries | Single-batch coating-related documents do not exceed 12 copies. Excessive recall increases context processing load |
| Tool calling timeout | 600 seconds | Requires pulling MES, instrument data, and multiple batch documents. A longer timeout covers the time required for cross-source data acquisition |
| Context window length | 8000–12000 token | A single coating document is approximately 1000–2000 characters. Associated review requires including full content of 3–5 documents |
| Local model calling switch | Enabled | Adapts to usage requirements for locally deployed large models, supporting tool calling for private models |
| Plugin trigger rule | Triggered by document type | Paint mixing records require calling the viscosity verification plugin. Oven curves require calling the curing parameter verification plugin, matching review requirements for different document types |

## Three common configuration errors
- Symptom: Tool calling returns empty film thickness results. Cause: Plugin pulling permissions for film thickness gauge data are not configured, preventing access to real-time measurement data.
- Symptom: Timeout errors occur during concurrent calls. Cause: The coating scenario requires pulling multi-source data. The timeout period is not adjusted to match production tempo, and single call execution time exceeds system default limits.
- Symptom: Unit mismatch errors appear in VOCs log review results. Cause: Field verification logic is not configured in tool calling, and unified conversion processing is not performed for parameters with different units.

## How to confirm the configuration is complete
- View tool calling logs, confirm that each review can pull corresponding types of coating documents and real-time data, and verify that pulled field units match document requirements.
- Initiate a call by simulating a single-batch coating task, check if the `toolChoice` parameter automatically switches between built-in tools and external plugins based on the task.
- Adjust the number of recalled documents, observe changes in context load, and confirm that the recall upper limit setting matches the total number of documents in the current scenario.
- Test different types of coating document triggers, confirm that the logic of calling the viscosity verification plugin for paint mixing records and the curing parameter verification plugin for oven curves takes effect.

The values provided are common starting points and should be measured against the reader's own samples.
