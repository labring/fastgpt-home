# Cross-Review of Technical Documentation for Coating and Painting: Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
This category’s typical data originates from coating supplier TDS/SDS documents, spray booth and oven operation data, colorimeters, film thickness gauges, environmental monitoring equipment, and MES systems. Daily documents include coating process cards, paint batch sheets, paint mixing records, film thickness and color difference reports, oven curves, defect repair sheets, and VOCs logs. Data is updated per paint batch, per shift, and via continuous collection. Document fields include batch number, film thickness value, oven temperature curve nodes, VOC emission records, and some structured documents have clear unit identifiers.

## What Constraints These Characteristics Impose on Knowledge Base Retrieval and Recall
Multi-source, high-frequency updated data requires retrieval to balance real-time performance and accuracy, and avoid returning expired or mismatched coating parameters. Document types cover structured forms and unstructured curve text, so retrieval must support both field matching and semantic association retrieval. There is a strong logical correlation between the pre-treatment, spraying, and curing stages of the coating process; retrieval must associate documents from the corresponding time interval. Errors directly affect product appearance and compliance, so low-association results must be strictly filtered to prevent incorrect process parameters from being called.

## How to Set Configurations
| Configuration Item | Recommended Approach | Basis for This Approach |
|---|---|---|
| `similarity` | ≥0.82 | High precision is required for coating process matching, to filter low-association retrieval results |
| `limit` | Top 6-10 entries | There are many coating-related parameters, and too many results will exceed the context processing limit |
| `searchMode` | Hybrid retrieval | Meets matching requirements for both structured fields (such as paint batch number) and unstructured text (such as process cards) |
| `usingReRank` | Enabled | Perform secondary sorting on multi-source retrieval results to improve the accuracy of professional term matching |
| `datasetSearchUsingExtensionQuery` | Enabled | Cover synonymous expressions of coating professional terms, such as extended retrieval for "sag" and "orange peel" |
| `collectionIds` | Specify the IDs of coating-related knowledge base collections | Limit the retrieval scope to avoid mixing irrelevant documents from other categories |

## Three Common Misconfigurations
- Retrieval results include low-association content with semantic similarity less than 0.9 and full-text search score lower than 50000. The cause is that the `similarity` threshold and full-text search score filtering rules are not configured, resulting in low-quality results being returned.
- The interface continuously displays the retrieving status with no valid results returned. The cause is that the `limit` parameter is not restricted, the returned data volume is too large and exceeds the system processing limit, or the knowledge base collection configuration is incorrect leading to a retrieval loop.
- The retrieval optimization function only returns adaptation results for a fixed model. The cause is that model version restrictions are mistakenly bound to the retrieval configuration, and the independent rules of retrieval parameters and model configuration are not correctly distinguished.

## How to Confirm That Configurations Are Correct
- View the retrieval logs in FastGPT v4.17.0, confirm that the `similarity` values of the returned results all meet the preset threshold.
- Test retrieval of coating professional terms such as "oven curve" and "film thickness deviation", confirm that the returned results include documents and parameters of the corresponding category.
- Check retrieval time consumption, confirm that there is no continuous loading status, and verify that the timeout rule takes effect.
- Compare retrieval results with `usingReRank` enabled and disabled, confirm that the sorted results better align with the association logic of coating business.

All configuration values listed here are common starting points, and should be evaluated against the relevant samples.
