# Cross-Review of Technical Documentation for Continuous Basic Chemical Production: Multi-Turn Dialogue and Prompt Engineering

## What the data for this category looks like
Daily documentation for continuous basic chemical production includes operating procedures, process index cards, DCS trends, laboratory reports, interlock bypass records, special work permits, and shift logs.
Data sources include DCS/SIS systems, online analyzers, LIMS systems, equipment condition monitoring tools, energy metering devices, and raw material tank sensors.
Update frequencies cover real-time, per-shift, and daily.
Document fields include process temperature (℃), pressure (MPa), interlock action thresholds, shift number, laboratory result values, and more. Some documents include standardized unit identifiers.

## What constraints these characteristics impose on multi-turn dialogue and prompt engineering
Data sources for this category are scattered, and update rhythms vary significantly. For real-time data, limit the historical length of `messages` in multi-turn dialogue to avoid overload from historical messages.
Document fields use specialized units and fixed formats. Prompts must explicitly require matching the corresponding units and field structures to prevent output deviations.
Multiple document types must be called by update frequency category. Prompts must restrict sessions to only use current shift or real-time document data.
Review of documents related to strong interlocks requires retaining contextual association of historical dialogue. Use `chatId` to bind dialogue history.
This configuration applies to FastGPT v4.17.0.

## How to set configurations
| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| Chunk length | 800–1200 characters | Matches the content length of single-page process index cards and DCS trends, avoids splitting professional information across chunks |
| Single recall limit | Top 6 entries | Covers the typical quantity of shift logs, laboratory reports, and interlock records for one shift, avoids interference from redundant information |
| Maximum context window | 4000 token | Limits historical message length for multi-turn dialogue, adapts to single-interaction information volume of basic chemical production documents |
| `variables` | Preset to "Basic Chemical Continuous Production Technical Document Review" | Clarifies the prompt's application scenario, filters irrelevant knowledge base content |
| `chatId` | Bind unique session identifier | Retains historical interlock and process parameter context for multi-turn dialogue, prevents information loss after session interruption |
| Input guidance switch | Enabled | Assists in refining colloquial questions from on-site engineers, matches professional question types in basic chemical production scenarios |

## Three common misconfigurations
- Symptom: The conversation interface cannot repeat the content of an uploaded process index xlsx file, and returns a prompt indicating unreadable content. Cause: No dedicated parsing rule is configured for basic chemical xlsx documents (including process temperature, pressure, and interlock threshold fields). The default parsing logic cannot recognize the specialized field structure.
- Symptom: After enabling input guidance and configuring a word bank, the conversation interface does not display preset professional questions. Cause: The input guidance configuration is not bound to the current scenario's `variables` parameter, or the word bank does not cover typical question keywords for basic chemical production.
- Symptom: The model's output of interlock bypass records in multi-turn dialogue does not match current shift data. Cause: The prompt does not limit calls to only real-time or current shift document data associated with the current session, and incorrectly uses old data from prior sessions.

## How to confirm the configuration is correct
- Upload an xlsx process index document containing process temperature (℃) and pressure (MPa), initiate the question "Please repeat the core indicators of this document", and confirm the model returns the corresponding fields and units.
- After enabling input guidance, refresh the conversation interface, and confirm the displayed preset questions include basic chemical production scenario keywords such as "interlock bypass check" and "DCS trend verification".
- Initiate two consecutive questions: first ask about the content of the current shift log, then ask about the interlock status of that shift, and confirm the model can associate the two rounds of context to provide corresponding results.
- Check the knowledge base configuration, confirm the `variables` parameter is set to "Basic Chemical Continuous Production Technical Document Review Scenario", with no residual configuration from irrelevant scenarios.
