# Cross-Review of Technical Documentation for Plastic Injection Molding: Source Citation and Traceability

## Data Profile for This Category
Daily documentation for this category includes injection molding process cards, raw material drying records, mold histories, first-piece inspections, patrol inspection forms, and material change and machine cleaning records. Data sources include resin batches and property sheets, injection molding machine parameters, mold temperature machines, MES systems, and dimensional and appearance inspection results.
Data is updated after each production batch, each mold or material change, and each shift’s patrol inspection. Individual documents contain dedicated fields: process cards note packing-holding pressure cooling window parameters, drying records log raw material drying temperature and duration, and mold histories record mold run counts and maintenance times.

## Constraints Imposed by These Characteristics on Source Citation and Traceability
Because data is updated per production batch and mold/material change nodes, the traceability workflow must accurately bind production batches to corresponding documents to avoid mixing data across batches. The dedicated fields of multiple document types vary significantly, so matching rules must be configured to link process, drying, mold and other data from the same batch.
Errors can lead to dimensional and appearance defects, mold damage, or material mixing safety incidents. Therefore, traceability must ensure the accuracy and timeliness of cited data. Additionally, the sensitivity of material moisture content and mold temperature requires that citations of drying records and injection molding machine parameters must be precisely matched, otherwise production outcomes will be directly affected.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Matches the single-section content length of injection molding process cards and raw material drying records |
| Overlap Length | 100–150 characters | Prevents content fragmentation across mold change batches, ensuring contextual coherence for documents from the same batch |
| Single Search Limit | Top 5 results | Matches multiple document types from the same batch, such as process cards, patrol inspection forms, and mold histories |
| `quoteMaxToken` | 1200 token | Limits the content length of a single citation to prevent redundant output |
| `responseData` | Enabled | Retains original metadata of cited documents to facilitate association with production batches and timestamps |
| `detail` | Enabled | Displays specific fields of cited documents, such as resin grade, mold temperature parameters and other dedicated information |

## Three Common Configuration Errors
- Displaying redundant cited file lists at the bottom of the conversation interface. This occurs when the "automatically display citation sources" setting is not disabled, causing unnecessary documents to be listed.
- Missing critical raw material drying parameters in cited content. This happens when raw material drying records are not included in the associated knowledge base collection, or when the chunk length is set too small, resulting in truncation of drying record content.
- Search results only matching mold histories without associating injection molding machine parameters. This occurs when no time range filtering rule based on production batches is configured, leading to recall of data across batches.

## How to Verify Correct Configuration
- In the FastGPT v4.17.0 environment, upload injection molding process cards, raw material drying records, and mold histories from a single production batch, submit a process compliance query, and verify that the citation list only includes documents from that batch.
- Click the expand button for the citation list, and confirm that dedicated fields such as resin grade, mold temperature parameters, and production time are displayed.
- Adjust the value of `quoteMaxToken` and verify that the content length of a single citation changes accordingly.
- Submit a query related to material mixing risks, and confirm that the cited resin property sheet data matches the raw material grade of the current production batch.

The values provided are common starting points and should be measured against the reader's own samples.
