# Cross-Review of Technical Documentation for Furniture and Wood Product Manufacturing: Citation Sources and Traceability

This document outlines implementation details for citation sources and traceability within the cross-review of technical documentation for furniture and wood product manufacturing, based on the configuration logic of FastGPT v4.17.0.

## What the Data for This Category Looks Like
Typical entities in this category include panel furniture, solid wood furniture, custom home and door enterprises. Daily production-related documents include cutting drawings, cutting lists, edge banding and drilling programs, coating processes, hardware lists, assembly and packaging records. Data mainly comes from order design systems, sheet and wood batch records, CNC cutting and drilling equipment, ERP/MES systems, and moisture content testing equipment. Data update frequency is adjusted according to production rhythm, including custom panel parameters generated per order, process parameters updated daily, and batch information corresponding to each batch of materials. Document fields include panel dimensions, sheet batch numbers, moisture content values, hardware models, and similar items, with units mostly millimeters, percentages, quantities, and similar units.

## What Constraints Do These Characteristics Impose on the Citation Sources and Traceability Link
The custom order-driven production model means every panel corresponds to a unique order and batch information, so citation traceability needs to accurately bind order numbers and panel numbers to avoid confusion of documents across orders. Multiple types of frequently updated documents require the traceability link to support cross-document association, such as verifying size matching between cutting lists and edge banding programs. The large number of panels and reliance on on-site spatial dimensions require that complete contextual parameters be retained during citation, and key dimensions or batch information must not be truncated. Unlike standard BOM categories such as home appliances, documents in this category have no unified template, so traceability configuration needs to adapt to diverse document metadata formats.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 characters | Matches the average length of single furniture production documents, avoids truncating key information such as panel dimensions and sheet batches |
| `responseData` | Enabled | Requires returning original document metadata of citation sources, including category-specific fields such as sheet batch numbers and cutting program numbers |
| `detail` | Full | Displays complete context of citation fragments, facilitating verification of matching relationships between hole positions, hardware and on-site installation during cross-review |
| Single search limit | Top 8 entries | Covers multiple supporting production documents for custom orders, avoids missing key process parameters |
| Maximum context | 6000 characters | Carries associated information of multiple panel documents, supports cross-document cross-review comparison |

## Three Common Configuration Errors
- Configuration tests prompt errors, but the citation function malfunctions after forced operation. The cause is failure to correctly bind category-specific metadata fields, resulting in inability to match sheet batches or order numbers during citation.
- Knowledge base retrieval only returns a single document. The cause is that the single search limit is set too low, or the multi-document association recall logic is not enabled, failing to adapt to the production scenario of multiple supporting documents for custom orders.
- Citation source field is empty. The cause is that the `responseData` configuration item is not enabled, failing to require the system to return original document metadata information, making traceability verification impossible.

## How to Verify Successful Configuration
- Import typical documents for this category, including cutting drawings, cutting lists and coating process records, initiate a query containing panel dimensions and sheet batches, check whether the returned results include corresponding document citation markers.
- After adjusting the `quoteMaxToken` configuration, verify that citation fragments of long documents are complete, with no truncated key parameters.
- Initiate cross-document cross queries, such as verifying size matching between cutting lists and edge banding programs, check whether multiple associated documents can be recalled.
- View the citation metadata returned by the system, confirm that it includes category-specific field information such as sheet batch numbers and order numbers.
