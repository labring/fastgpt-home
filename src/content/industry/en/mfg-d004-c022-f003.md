# Cross-Review of Technical Documentation for Complete Home Appliance Manufacturing: Multi-Turn Dialogue and Prompt Engineering

## What data looks like for this category
This category covers air conditioner, refrigerator, washing machine, and small home appliance manufacturers. Daily documents include bill of materials (BOM), assembly work instructions, refrigerant charging records, electrical safety test reports, performance sampling test reports, and repair records. Data sources include ERP/MES systems, component batch ledgers, tightening and charging equipment, safety compliance testers, performance laboratory data, and after-sales fault records. Update cycles run at the individual product level, shift team level, or per sampling plan.

## Constraints for multi-turn dialogue and prompt engineering
The individual product-level update cycle requires multi-turn dialogue to accurately bind component and process data for the corresponding batch, to avoid mixing across different models. Multiple heterogeneous data sources (equipment records, laboratory reports, after-sales fault data) require prompts to clearly distinguish document types and field ownership, to prevent confusion between safety compliance and performance parameters. In mixed-line batch assembly scenarios, multi-turn dialogue must limit the context window to avoid redundant old data interfering with current model review, while aligning with each product’s exclusive update records to reduce misassembly or compliance risks.

## Configuration Settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `chatId` | Bind the unique batch number of a single product | Ensure each product’s review dialogue context is independent, avoiding cross-batch data confusion |
| `messages` | Retain the most recent 3 dialogue messages related to the current model, truncate earlier redundant content | Adapt to the document update rhythm at the individual product level, reducing interference from irrelevant historical data |
| `variables` | Bind the current model’s BOM version and safety compliance standard number | Enable prompts to accurately call exclusive document fields for the corresponding category |
| Maximum context window | 800–1200 characters | Adapt to the single-batch data length of home appliance complete machine documents, avoiding window overflow |
| Knowledge base recall limit | Top 6 entries | Match the multi-document review needs in mixed-line assembly, without overloading dialogue context |
| Historical session cleanup threshold | 600 seconds without new dialogue | Prevent redundant data accumulation in idle sessions, freeing dialogue resources |

## Three Common Configuration Mistakes
- The `401 No auth credentials found` error occurs. The cause is failure to bind access credentials for the enterprise ERP system to the `variables` configuration item, leading to permission verification failure during external document calls via dialogue.
- Historical documents recalled by the knowledge base do not match the current model. The cause is failure to bind the single product batch via `chatId`, resulting in recall of assembly work instructions or test reports across models.
- Incorrect fields are truncated after the dialogue context exceeds the preset length. The cause is failure to retain dialogue history related to the current model per the `messages` configuration item, accidentally truncating critical parameters from safety compliance tests.

## How to Verify Configurations Are Correct
- Manually input the batch number of a single product, verify that `chatId` is correctly bound to the corresponding batch’s BOM and test records.
- Initiate multi-turn dialogue, confirm that returned document fields only include configuration parameters for the current model, with no cross-model redundant data.
- Trigger knowledge base recall, confirm that the number of recalled documents aligns with the preset recall limit rules.
- Simulate idle session timeout, check that historical `messages` content is automatically cleaned up per the set threshold.
