# Cross-Review of Technical Documentation for Non-Ferrous Metal Smelting and Electrolysis: Citation Sources and Traceability

## What This Category of Data Entails
This category of data originates from concentrate and auxiliary material analysis reports, DCS systems, cell voltage and current monitoring tools, laboratory test results, and energy and environmental monitoring equipment. Daily documents include batching lists, smelting records, electrolytic cell condition logs, test reports, anode and cathode quality records, and environmental protection ledgers.
Data updates align with each raw material batch, each furnace run, or each electrolytic cell. Some cell condition and energy consumption data updates in real time. Document fields include material grade, impurity proportion, furnace temperature, cell current, recovery rate, and similar metrics. Common units are tons, degrees Celsius, milliamps, and percentage.

## Constraints for Citation Sources and Traceability
The real-time or short-cycle update nature of the data requires citation traceability to support quick recall of the latest cell condition and test data, preventing expired records from being cited.
The multi-source document structure and segmented fields require traceability to associate and match document fragments relevant to the current business scenario, and only return content tied to the active review target.
A single review must cover documents across the full batching, smelting, and electrolysis process, which creates capacity requirements for the `quoteMaxToken` setting.
Traceability for core fields such as impurity proportion and recovery rate must be accurately linked to original test or monitoring records, to maintain the credibility of cross-review.
Errors directly impact production indicators, so traceability must clearly show the source path of the original document to support anomaly troubleshooting.

## Configuration Settings
All configurations below are based on the functional logic of FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1500–2000 token | Must cover core document fragments for single-furnace smelting and multi-cell electrolysis, to avoid truncating key fields and source identifiers |
| `responseData` | Return only core business fields and source paths | Reduce redundant information, aligning with the rapid review needs of production scenarios |
| `detail` | Enabled | Supports displaying specific fields and update times of original documents, meeting the traceability requirements of cross-review |
| Single Recall Limit | Top 8 entries | Covers key documents across the full process, avoiding recalling too many irrelevant historical records |
| Context Window | 3000–4000 characters | Accommodates associated document content from multiple sources, ensuring the integrity of review logic |

## Three Common Misconfiguration Issues
- Phenomenon: Generated review results include unconfigured knowledge base search input and response content, with empty fields or irrelevant text displayed. Cause: Non-essential tool call output switches were not disabled in the workflow, leading to redundant cited content being included.
- Phenomenon: Knowledge base variable references in the workflow lack optional values, making it impossible to bind corresponding document fields. Cause: Business documents such as batching lists and electrolytic cell condition records were not imported into the target knowledge base in advance, or the correct knowledge base association path was not specified during variable configuration.
- Phenomenon: Traceability information in review results is incomplete, with source paths for core fields missing. Cause: The `quoteMaxToken` setting is too small, truncating source identifier fields from original documents and preventing full traceability information from being displayed.

## How to Validate Proper Configuration
- Import a single batch of batching lists and electrolytic cell condition records, submit a cross-review request, and confirm that returned results only include business-relevant document fragments.
- Review the traceability column of the result, verify that each cited entry is labeled with the original document type, generation time, and source system.
- Adjust the `quoteMaxToken` value, test content recall completeness across different ranges, and ensure core fields are not truncated.
- Disable non-essential tool output switches, confirm that generated results contain no redundant knowledge base search input or response content.

The values provided here are common starting points and should be evaluated against the reader's own samples.
