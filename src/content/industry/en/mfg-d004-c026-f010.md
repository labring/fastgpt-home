# Cross-Review of Technical Documentation for Non-Ferrous Metal Smelting and Electrolysis: Knowledge Base Retrieval and Recall

## What this category of data looks like
Data for this category originates from smelting, electrolysis, laboratory testing, and scheduling departments of copper, aluminum, lead-zinc and other smelting enterprises. Daily documents include batching lists, smelting records, electrolytic cell condition records, laboratory reports, anode and cathode quality records, and environmental protection ledgers. Data sources cover concentrate and auxiliary material analysis, DCS systems, cell voltage and current monitoring, laboratory testing, and energy and environmental protection monitoring modules. Updates run in real time upon completion of each raw material batch, furnace run, or cell operation. Individual documents contain fields with clear units, such as component proportions, operating condition parameters, and test values.

## What constraints these characteristics impose on the knowledge base retrieval and recall link
The multi-source heterogeneous data sources and real-time update rhythm of this category require the retrieval and recall link to support incremental synchronization and multi-format document parsing. Fields with clear units, such as cell voltage, current strength, and component proportions, need precise semantic matching during retrieval to avoid mismatching unlabeled numerical values. Business relevance varies widely across different document types. For example, electrolytic cell condition records have stronger relevance to real-time operating condition retrieval. Differentiated recall weights must be configured for different document sets. Individual documents also have high parameter density, so the context length of recall results must be controlled to avoid exceeding the model's processing limit.

## How to set the configurations
The following configurations are based on the knowledge base retrieval logic of FastGPT v4.17.0, adapted to the business characteristics of non-ferrous metal smelting and electrolysis.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.72–0.85 | Match process parameters and composition data with units, to avoid mixing low-relevance results |
| `limit` | Top 8–12 entries | Balance single-round retrieval context length and parameter coverage, adapted to smelting documents with high parameter density |
| `searchMode` | `mixedRecall` | Cover fixed fields in batching lists and real-time operating condition text in electrolytic cell condition records |
| `usingReRank` | Enabled | Perform secondary ranking on high parameter density recall results, to improve matching accuracy for complex operating condition queries |
| `datasetSearchUsingExtensionQuery` | Enabled | Expand process-related synonyms for queries, such as associating "cell voltage abnormality" with "electrolytic cell potential fluctuation" |
| `collectionIds` | Configured by document type grouping | Associate exclusive knowledge base sets for smelting records, electrolytic cell condition records, and other categories respectively, to accurately recall documents for corresponding scenarios |

## Three common misconfigurations
- A 503 error appears when uploading files via the chat dialog box, but no error occurs when uploading to the knowledge base. When uploading local smelting documents to the chat window, a 503 status code is returned, but no error is reported when uploading to the knowledge base backend. Cause: The temporary file parsing queue for chat scenarios does not have a timeout threshold configured for high parameter density documents, leading to parsing timeout for large-volume smelting records or laboratory reports.
- Semantic retrieval fails to return results for knowledge blocks containing specified keywords. A document labeled "anode copper purity" exists in the knowledge base, but no results are returned when using "anode copper purity" as the retrieval term. Cause: `datasetSearchUsingExtensionQuery` is not enabled, synonym expansion for professional terms is not performed, or the `similarity` threshold is set too high, filtering documents with low matching scores that still align with the query.
- Complex process queries do not return accurate associated results. When asking "How do impurities in the current batch of lead concentrate affect electrolytic cell current efficiency", the returned results are scattered and unrelated. Cause: The `limit` value is set too low, failing to recall enough relevant documents, or `usingReRank` is not enabled, so recall results cannot be sorted by business relevance.

## How to confirm configurations are set correctly
- Upload a single smelting document with high parameter density to the chat dialog box, check for 503 errors, and confirm the queue timeout threshold adapts to the document volume.
- Enter a retrieval term containing professional terms, verify that the corresponding document is recalled, and check the configuration status of the `similarity` threshold and `datasetSearchUsingExtensionQuery`.
- Initiate a complex process association query, check the number and sorting rationality of recall results, and confirm the configurations of `limit` and `usingReRank`.
- View the association configuration of knowledge base sets, confirm that different types of smelting documents are bound to corresponding retrieval scenarios via grouped `collectionIds` settings.

The values given are common starting points and should be measured against the reader's own samples.
