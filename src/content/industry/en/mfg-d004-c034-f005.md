# Cross-Review of Technical Documentation for Baked Goods and Convenience Foods: Tool Calling and Plugins

## What the Data for This Category Looks Like
Typical entities in this category are bakeries, pastry shops, instant noodle factories, and frozen pastry factories.
Daily documents include recipes and feeding lists, production records, baking or steaming curves, metal detection records, cleaning and disinfection records, and factory inspection reports.
Data sources include raw material qualification certificates, ERP/MES systems, weighing systems, oven or frying line equipment, laboratory test data, and food traceability ledgers.
Update frequency follows per batch, per shift, or daily schedules.
Document fields include core content such as allergen material lists, proofing/baking/frying window parameters, packaging dates, and shelf life.
Document structure and fields vary between different batches.

## Constraints Imposed on Tool Calling and Plugin Workflows
High document update frequency and batch-based generation mean tool calling must adapt to batch pulling and real-time verification rhythms.
Multi-source heterogeneous data sources require plugins to support cross-system format adaptation and authentication configuration, to prevent data pulling failures from system differences.
Batch-to-batch differences in document fields require tool calling parameters to precisely match the current batch’s document structure. Generic field mapping rules cannot be used.
Directly edible product attributes mean cross-review results must strictly correspond to key fields in documents such as allergens and foreign matter control.
Tool calling failure handling must include a rapid response mechanism, to prevent unqualified data from flowing to downstream links.
Frequent product line changes require tools to quickly switch review scenarios, adapting to document verification logic for different categories.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Workflow/API tool selection | `auto` | Adapt to multi-scenario document cross-review, automatically select corresponding tools to process different document types such as recipes and production records. This configuration is implemented based on the FastGPT v4.17.0 tool scheduling logic |
| Workflow/API function-call configuration | `enabled` | Enable function call mode to implement batch cross-review and field matching for multiple documents |
| Single call document count limit | `Top 20` | Adapt to the average number of production documents per batch, avoid overloading system resources |
| Authentication timeout period | `30 seconds` | Adapt to response rhythms of multi-source systems such as ERP/MES and oven equipment, prevent call failures from device delays |
| MCP format adaptation switch | Enabled | Compatible with cross-system data access requirements, meet cross-data source document pulling scenarios |
| Call failure retry count | `2 times` | Address temporary device fluctuations or network jitter, ensure continuity of the review process |

## Three Common Mistakes
- Phenomenon: Allergen material matching results returned by the tool are empty, and current batch allergen residue verification status is not displayed. Cause: Mapping rules for cleaning and disinfection records and allergen verification fields are not configured, leading to failure to pull allergen residue data for the corresponding batch.
- Phenomenon: 400 status code returned when calling an MCP format data source. Cause: MCP authentication parameters are not correctly configured, leading to identity verification failure and inability to complete data pulling.
- Phenomenon: Tool calling triggers a timeout. Cause: Single call document count exceeds the preset limit, exceeding system processing thresholds, leading to requests not completing responses within the authentication timeout period.

## How to Confirm Configurations Are Set Correctly
- Upload a single batch of bread recipe and corresponding cleaning and disinfection record documents, trigger tool calling, check if the returned results include matching information for allergen materials.
- Call the configured MCP format data source, verify that baking curve data can be pulled normally and cross-checked with production records.
- Simulate a single call with documents exceeding the preset count, check if the system triggers reasonable current limiting prompts or overload feedback.
- Trigger an authentication configuration test, verify that the connection status with ERP/MES systems is normal, confirm that the data pulling process has no abnormalities.
