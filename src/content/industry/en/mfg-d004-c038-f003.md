# Cross-Review of Technical Documents for Biologics and Aseptic Manufacturing: Multi-Turn Dialogue and Prompt Engineering

## What Data for This Category Looks Like
Typical entities in this category are vaccine, antibody, blood product, and sterile injectable manufacturers. Daily documents include cell bank or seed lot records, culture and purification records, aseptic filling records, environmental monitoring data, media fill simulation reports, sterility test results, and batch release materials. Data sources include cell bank and seed lot systems, process analysis platforms, clean zone monitoring systems, MES, LIMS, and equipment integrity testing tools. Data updates run per production batch. Critical process data syncs in real time. Environmental monitoring data updates per a predefined schedule. Document fields include professional parameters such as batch number, temperature (℃), time (hours), and settleable microbial count (cfu/plate).

## What Constraints These Characteristics Bring to the Multi-Turn Dialogue and Prompt Engineering Workflow
Multi-source, heterogeneous data sources require dialogue contexts to link documents from different systems. The `messages` parameter must retain cross-system associated information across dialogue turns. Data that updates per batch and in real time requires the `variables` parameter to dynamically bind exclusive parameters for the current batch, to prevent context confusion. Unstandardized document structures and high volumes of professional terms require prompts to clearly define field extraction rules in every dialogue turn, to ensure consistent review. Severe potential error consequences require multi-turn dialogue to gradually verify critical parameters, to stop error spread from a single step.

## How to Configure Settings
| Configuration Item | Recommended Approach | Rationale |
| ---- | ---- | ---- |
| `messages` | Retain the most recent 20 dialogue turns of context, with no more than 1500 characters per turn | Adapts to the single-document length of this category, to avoid context overflow |
| `variables` | Bind global parameters such as current batch number and clean zone number | Associates real-time or batch-updated business data, to ensure context consistency |
| `chatId` | Generate a unique identifier per production batch | Isolates review contexts for different batches, to avoid data cross-contamination |
| Maximum Context | 8000–12000 token | Covers the content scope of full core documents for a single batch |
| Prompt Optimization | Calibrate based on actual testing | Adapts to professional terms and document structures of this category |

## Three Common Misconfigurations
- Phenomenon: A `400 Bad Request` error is returned when calling the interface, with a prompt that the `appId` field is missing. Cause: Workflow call parameters are not configured correctly, and the transfer rules for workflow ID and application ID are confused.
- Phenomenon: Global variables are lost after multiple dialogue turns, and exclusive data for the current batch cannot be associated. Cause: Fixed business parameters are not passed between dialogues via the `variables` parameter, leading to context reset.
- Phenomenon: Uploaded aseptic filling records are not retrieved, and review results are empty. Cause: Field matching logic for files is not clearly specified in the prompt, or the binding setting between files and dialogue context is not enabled.

## How to Verify Successful Configuration
- A test dialogue is initiated, keywords for the current batch’s cell bank records are entered, and the returned context is checked for exclusive parameters corresponding to the batch.
- The FastGPT v4.17.0 call logs are reviewed, and correct passage of the `chatId`, `messages`, and `variables` parameters is confirmed.
- A media fill simulation report is uploaded, the review process is triggered, and correct extraction of professional fields such as settleable microbial count is verified.
- Three related questions are submitted in sequence, and the context is checked to confirm retention of batch information and associated data from prior dialogue turns.
