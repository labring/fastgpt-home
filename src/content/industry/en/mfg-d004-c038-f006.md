# Cross-Review of Technical Documentation for Biologics and Aseptic Manufacturing: Source Citation and Traceability

## What Data Looks Like for This Category
Typical data for this category comes from cell banks and seed lots, process analytics, cleanroom monitoring, MES, LIMS, and equipment integrity testing systems. Daily documentation includes cell bank or seed lot records, culture and purification records, aseptic filling records, environmental monitoring data, media fill simulation results, sterility test reports, and batch release materials. Data update frequencies cover per-batch, real-time, and per-monitoring-plan schedules. Fields include batch number, culture temperature, cleanroom sedimentary microbial count, equipment runtime, with corresponding units of degrees Celsius, CFU per cubic meter, hours, and others.

## Constraints Imposed on Source Citation and Traceability
Dispersed multi-source data requires citation traceability to link records across different systems, and prevent missing cross-system data. Diverse update frequencies need support for real-time validation and traceability queries for batch records, to ensure data from different time points is traceable. Complex document structures require citations to accurately locate specific segment content under a single batch. Additionally, compliance requirements for aseptic manufacturing and the active properties of biologics require citation traceability to accurately link to original data nodes, ensuring cross-review results are verifiable.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Single search limit | Top 8–12 entries | Covers dispersed multi-system document sources, avoids missing critical batch records |
| `quoteMaxToken` | 800–1200 token | Adapts to the long-text structure of batch records, retains complete citation context |
| Reordering configuration | Enabled | Raises recall priority for relevant documents, reduces interference from irrelevant citations |
| Maximum context length | 6000–8000 characters | Accommodates multi-segment linked data, supports logical linking for cross-review |
| `detail` | Enabled | Displays specific fields and source nodes of citations, meets compliance traceability requirements |
| `responseData` | Calibrated via actual testing | Adapts to field complexity of different batch documents, ensures accurate traceability |

This configuration applies to FastGPT v4.17.0.

## Three Common Configuration Mistakes
- Phenomenon: After enabling reordering, citation snippets for some batch documents are empty, and specific records cannot be recalled. Cause: The reordering filter threshold is set too high, filtering out low-relevance but valid original documents belonging to the batch.
- Phenomenon: After configuring the citation limit, multi-segment citations for some batch release materials are truncated. Cause: The citation limit is set too low, failing to cover the multi-subdocument linking requirements of batch records.
- Phenomenon: The phrase "No permission to operate this conversation record" appears at the end of response paragraphs, and citation display cannot be disabled. Cause: Citation traceability permission configuration is not enabled for the corresponding conversation role, preventing modification of citation display settings.

## How to Verify Successful Configuration
- Submit a cross-review request for one batch, check if returned results include citation snippets from multi-source documents such as cell banks, culture and purification records, and others.
- Review specific citation content, confirm that source nodes and update times of original data can be located.
- Test after enabling reordering, confirm that required citation snippets are still recalled, with no empty citations.
- Export the current configuration workflow, import it into a new environment, and verify that citation-related configurations load correctly.

The configuration values provided are common starting points and should be evaluated against the reader’s own samples.
