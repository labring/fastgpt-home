# Cross-Review of Technical Documents for Biologics and Aseptic Manufacturing: Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
The primary entities in this category are vaccine, antibody, blood product, and sterile injectable manufacturing enterprises. Daily documents include cell bank or seed lot records, culture and purification records, aseptic filling records, environmental monitoring data, media fill simulation reports, sterility test reports, and batch release documents. Data sources cover cell bank and seed lot systems, process analysis equipment, clean zone monitoring systems, MES, LIMS, and equipment integrity testing tools. Update frequencies include per-batch, real-time, and as specified in monitoring plans. Each document contains fields such as batch number, operation time, process parameter values, and test results. Units include colony-forming units, degrees Celsius, pascals, and other professional measurement identifiers. Some documents include both structured parameters and non-standardized operational description text.

## Constraints for Knowledge Base Retrieval and Recall
Dispersed multi-source data requires the retrieval system to support unified indexing across systems. Documents with different update frequencies need to support both incremental synchronization and full update logic. Complex document structures require both semantic matching to understand process descriptions and precise keyword matching to locate parameter records for specific batches. Aseptic manufacturing processes cannot rely solely on finished product sampling to ensure safety, so retrieved results must have clear source traceability. Results must prioritize content related to aseptic boundary control and critical parameter control to avoid irrelevant documents interfering with cross-review workflows. Batch-associated retrieval requirements also require the system to support quick association of all relevant documents by batch number, enabling efficient cross-review.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Matches the precision requirements for biologic process parameters, avoids retrieving irrelevant batch records |
| `limit` | Top 10 results | Controls the number of single-retrieval results, adapts to the reading load of multi-document cross-review |
| `searchMode` | `mixedRecall` | Balances semantic matching for process parameters and keyword retrieval for batch numbers, equipment numbers |
| `usingReRank` | Enabled | Re-ranks initial retrieval results by relevance, prioritizes high-value documents related to aseptic boundary control |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands search terms to cover synonyms for process parameters, such as matching "incubation temperature" for "culture temperature" |
| `collectionIds` | Corresponding knowledge base collection IDs for aseptic manufacturing, batch release | Limits retrieval scope, excludes documents from unrelated categories |

## Three Common Configuration Mistakes
- Issue: Clicking the reading link returned by the knowledge base retrieval API displays a prompt that only .txt format files are supported. Cause: PDF or Excel documents for process records were not correctly converted to searchable text format, or the configuration did not allow parsing of the corresponding file types.
- Issue: Retrieval results return only a small number of documents and fail to cover all process records for the current batch. Cause: The `limit` parameter is set too low, or `searchMode` is only configured for semantic retrieval without including keyword matching, failing to cover precise identifiers such as batch numbers.
- Issue: Retrieval results include documents unrelated to aseptic manufacturing, interfering with cross-review workflows. Cause: `collectionIds` was not configured to limit the retrieval collection, resulting in retrieval of knowledge base content from other categories.

## How to Confirm Proper Configuration
- Upload a batch’s cell bank records and aseptic filling records as test documents, configure the corresponding knowledge base collection, perform a batch number retrieval, and confirm that all relevant documents are included in the retrieval results.
- Adjust the `similarity` parameter to 0.8, retrieve "aseptic boundary control", and confirm that re-ranked results prioritize documents related to clean zone monitoring and personnel and material pathways.
- After enabling `usingReRank`, compare the order of initial retrieval results and re-ranked results to confirm that highly relevant documents appear first.
- Check that retrieval API results only include documents within the configured collection, excluding cross-category irrelevant content.

The values provided are common starting points and should be evaluated against the reader’s own samples.
