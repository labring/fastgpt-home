# Cross-Review of Technical Documentation for Electric Motor and Generator Manufacturing: Source Citation and Traceability

## What data for this category looks like
Data for this category comes from electromagnetic design systems, copper wire and insulation material batch ledgers, winding equipment operation logs, balancing machine collected data, electrical test bench reports, and ERP/MES systems. Winding process cards, insulation treatment records, dynamic balance reports, voltage withstand insulation test records, type and factory inspection reports are generated on an ongoing basis. These documents are updated once per product unit or material batch, and synchronized whenever a product type modification occurs. Documents include fields such as number of turns, insulation thickness, balance accuracy, test voltage, and batch number, with associated physical units including turns, millimeters, grams, kilovolts, and others.

## Constraints on source citation and traceability workflow
Data for this category is bound to individual product units or material batches, requiring precise matching between documents and production processes. Traceability must therefore associate batch numbers with metadata such as equipment logs. Diverse document types and specialized fields require support for cross-document field cross-checking, such as verifying consistency of winding turn counts between process cards and test report data. Frequently updated individual product data requires traceability responses to align with production timelines, with no delays permitted. Strict unit and precision requirements apply to data from high-voltage tests, dynamic balancing, and other procedures, requiring exact matching of original text fields to prevent traceability failures caused by unit conversion errors.

## How to configure
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Covers key content of a single core process or test document to ensure complete traceability information |
| `responseData` | Enabled | Forces return of source citation metadata and original text snippets to meet traceability needs for cross-review |
| `detail` | Full | Displays all associated fields including document name, batch number, generation time, and additional relevant details |
| Number of knowledge base entries recalled per single query | Top 5 | Matches multiple associated documents for a single product unit, avoiding interference from irrelevant data |
| Context association limit | Calibrated via actual testing | Adapts to context requirements for multi-document cross-review, preventing exceeding model processing limits |

## Three common configuration errors
- Red numeric error messages appear in the interface. Cause: The `responseData` configuration item is not enabled correctly, causing the system to fail to return valid traceability metadata and triggering format verification errors.
- The knowledge base source of output content cannot be confirmed. Cause: The `detail` parameter is not configured to full mode, so identifying information such as associated document names and batch numbers is not returned.
- Cited content cannot match the uploaded original documents. Cause: Associated knowledge base entries are not filtered by material batch, making it impossible to locate the original storage location of the corresponding document during traceability.

## How to confirm correct configuration
- In FastGPT v4.17.0, open a test conversation, upload the winding process card and voltage withstand test report for a single electric motor, and submit a query requesting verification of winding turn counts.
- Check if the output content includes metadata such as the document name and batch number of the cited source.
- Verify that the output content includes original text snippets within the `quoteMaxToken` limit.
- Confirm that no red numeric error messages appear, and that the number of recalled knowledge base entries matches the preset top 5 configuration.

The values provided here are common starting points, and should be evaluated against the reader's own samples.
