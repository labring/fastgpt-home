# Cross-Review of Technical Documentation for Electroplating and Chemical Surface Treatment: Citation Sources and Traceability

## What data for this category looks like
Daily documents for this category include bath solution analysis records, process parameter cards, fixture records, film thickness and adhesion reports, hazardous waste ledgers, and wastewater monitoring records. Data sources cover customer surface treatment specifications, bath solution test results, rectifier operation data, online water quality monitoring records, and hazardous waste management ledgers. Updates occur per bath cycle, per shift, or at fixed monitoring intervals. Each document includes fields such as bath solution component concentration, processing temperature, current parameters, film thickness values, fixture configuration, and discharge indicators. Corresponding units include g/L, ℃, A, μm, mg/L, and others.

## What constraints these characteristics impose on citation sources and traceability
The high update frequency and detailed field breakdown of documents in this category require citation traceability to accurately match real-time generated process data and historical records. Mistakes in this step directly impact coating quality, batch rework, and environmental compliance, so the traceability link must ensure cited documents fully correspond to current production scenarios. The mixed storage of multiple document types also requires the traceability system to distinguish between bath solution analysis records, process parameter cards, and other document types to avoid cross-confusion. Additionally, compliance requirements for hazardous waste and wastewater monitoring documents require the traceability link to retain complete call and citation chains for subsequent verification.

## Configuration settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the average length of a single process document in this category, to avoid truncating critical parameters and source information |
| Response data toggle | Enable `responseData` | Retains original parameters and returned content from knowledge base calls, to facilitate subsequent traceability and troubleshooting |
| `detail` | Enable | Outputs complete citation source details, including document ID, file name, and cited passage |
| Single recall limit | Top 6 entries | Covers multiple types of documents involved in a single bath cycle production, including bath solution analysis, process parameters, fixture records, and others |
| Context splicing length | Calibrated via actual testing | Adapts to the total length after splicing multiple documents, to avoid exceeding model context limits |
| Variable reference format | Bind category-specific dataset | Matches the field mapping rules of documents in this category, to ensure correct association with the corresponding knowledge base during calls |

## Three common configuration errors
- Symptom: After enabling the `detail` parameter, citation parsing fails during streaming returns, with empty field values. Cause: `responseData` for raw data return is not correctly configured, making it impossible to extract document IDs and source information associated with citations.
- Symptom: After upgrading to FastGPT v4.17.0, citation content is still returned even if the citation display toggle is turned off. Cause: The priority between global configuration and session configuration is not correctly distinguished, and forced traceability logic is enabled by default.
- Symptom: Using the `[{datasetId: xxx}]` format for knowledge base variable references has no effect. Cause: The dataset field mapping for this category of documents is not matched. A category-specific dataset binding configuration must be used.

## How to confirm correct configuration
- Manually initiate a query for bath solution process parameters, confirm that the attached citation file list in the returned results matches bath solution analysis records, process parameter cards, and other documents in the knowledge base.
- After enabling the `detail` and `responseData` parameters, check whether the returned raw data includes complete knowledge base call parameters and segmented content from streaming returns.
- Verify the citation display toggle configuration, confirm that no additional citation content is returned when the toggle is turned off.
- Test the category-specific variable reference format, confirm that documents from the corresponding dataset are correctly associated during calls.

The values provided are common starting points and should be measured against the reader's own samples.
