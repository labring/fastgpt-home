# Cross-Review of Technical Documentation for Meat Products and Slaughter Processing: Citation Sources and Traceability

## What the data for this category looks like
The core data for this category covers six source types: animal quarantine information, supplier batches, production traceability, temperature collection, metal detection, and laboratory testing. Daily generated documents include quarantine certificates, slaughter and cutting records, ingredient marinating records, thermal processing records, cold chain temperature records, and microbial test reports. Each document is bound to fields such as unique batch number, temperature value (℃), detection time, and quarantine number. Data updates occur once per production batch for batch-associated documents. Continuous temperature control data is updated per shift or in real time.

## What constraints these characteristics impose on the "citation sources and traceability" link
Biological risk control and full-process traceability requirements for this category require the citation sources and traceability link to accurately bind single-batch production data. Batch-based document updates require traceability to match unique batch numbers, to avoid mixing cross-batch data. The real-time nature of continuous temperature control requires retrieval to prioritize recent temperature records, ensuring temperature control compliance during production. The need to associate multiple document types means traceability must cover quarantine, production, and testing documents at the same time. It must also retain the original units and identifiers of fields to facilitate regulatory verification. Production requirements for separating raw and cooked areas mean citations must distinguish between raw meat and processed cooked product documents, preventing confusion of data related to cross-contamination.

## How to set configurations
| Configuration Item | Recommended Approach | Basis for This Approach |
| ---- | ---- | ---- |
| Maximum Context | 8000–12000 token | Matches the total length of all documents involved in a single production batch, to avoid truncation of critical information |
| `quoteMaxToken` | 1500 characters | Retains key content from a single core document such as quarantine certificates and microbial test reports |
| Number of Citation Data Entries Returned | Top 6 | Covers multiple types of documents involved in a single production batch, to avoid excessive redundant information |
| `responseData` | Carry original document ID and batch number | Meets the needs of precise association and batch verification during traceability |
| `detail` | Enable full field display | Retains business fields with units such as temperature value and detection time to facilitate regulatory verification |
| Citation Deduplication | Deduplicate by batch number | Avoids multiple citations of duplicate documents from the same batch, ensuring traceability accuracy |

## Three Common Misconfigurations
- Phenomenon: After batch uploading 100 batch-associated documents, nearly half have abnormal training status. Cause: No unique batch number is bound to each document as an identifier, leading to data conflicts during knowledge base indexing.
- Phenomenon: Repeated identical batch quarantine certificates appear in cited content. Cause: No deduplication rule configured by batch number, or duplicate content not filtered by batch dimension during chunking.
- Phenomenon: When using variable reference mode, the temperature parameter setup entry cannot be found. Cause: Advanced parameter configuration is not enabled in the conversation component, causing the temperature setting button to be hidden.

## How to Confirm Proper Configuration
- Upload a single quarantine certificate document with a batch number, trigger retrieval, and check if the citation result includes the batch number and quarantine number fields.
- Batch upload multiple types of documents from the same batch, and verify that there is no duplicate same-batch content in the citation results.
- Trigger conversational retrieval, check if the returned `responseData` carries the unique ID and batch information of the original document.
- Switch to variable reference mode, confirm that the temperature parameter setting button is normally displayed and can adjust values.
- In FastGPT v4.17.0, test the retrieval and traceability process for single-batch documents to ensure all configuration items take effect.

The values provided are common starting points and should be measured against the reader's own samples.
