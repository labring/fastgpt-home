# Cross-Review of Technical Documents for Measuring Instruments and Laboratory Management: Citation Sources and Traceability

## What this category of data looks like
This category of data originates from daily business documents of enterprise metrology rooms and laboratories within the CNAS accreditation system. Documents include gauge ledgers, calibration plans, calibration certificates, periodic inspection records, original test records, reference material ledgers, and deviation handling documents.
Data sources cover internal metrology management systems, external calibration institution certificates, standard instrument data, LIMS systems, and environmental monitoring records.
Update cycles are triggered by calibration cycles, completion of single tests, or abnormal events, with no fixed schedule.
Document fields include clear metrology-related units, such as uncertainty values (μm, mg, etc.), traceability levels, and calibration validity periods. The structure centers on individual instruments or tests, with multi-dimensional traceability information associated.

## What constraints these characteristics impose on the "citation sources and traceability" link
Data sources are scattered across multiple systems. This requires the citation traceability link to support cross-data source recall and association, rather than only retrieving documents from a single system.
Updates have no fixed cycle. This requires support for on-demand incremental updates to ensure the traceability chain always links to the latest calibration and inspection data.
Documents contain professional metrology fields and units. Citations must retain full field integrity, and critical information such as uncertainty and traceability level must not be truncated.
Individual business documents are linked to multiple related items. For example, a calibration certificate is linked to its corresponding gauge ledger and periodic inspection records. This requires automatic matching of association relationships during retrieval to avoid breaking the traceability chain.

## How to configure the system
| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | Covers the typical text length of a single calibration certificate or original test record, avoiding truncation of key content related to traceability |
| `responseData` | Return full original fields | Retains core metrology business fields such as instrument ID, calibration validity period, and uncertainty value to support traceability review |
| `detail` | Enable detailed traceability association | Automatically matches cross-document association relationships, such as binding between calibration certificates and their corresponding gauge ledgers or periodic inspection records |
| Single search limit | Top 6 entries | Matches the number of business documents linked to a single calibration certificate, avoiding redundant recall of non-associated content |
| Knowledge base capacity threshold | `1000–2000 MB` | Adapts to the scale of metrology document collections for a single laboratory, avoiding exceeding system storage limits |
| Retrieval timeout | `600 seconds` | Reasonable duration for waiting for cross-system retrieval, avoiding interruption of the traceability process due to timeout |

This configuration applies to FastGPT v4.17.0

## Three common misconfigurations
- Phenomenon: Only citation markers are returned for associated documents, with no corresponding business content. Cause: The `responseData` configuration is not enabled, so only document indexes are recalled and original text content is not pulled.
- Phenomenon: An error occurs when running the workflow after adding the citation plugin, with a prompt that the context is exceeded. Cause: The value of `quoteMaxToken` is too small, truncating key text paragraphs containing traceability chains in the calibration certificate.
- Phenomenon: Periodic inspection records are missing from traceability association results. Cause: Cross-data source retrieval is not configured, so only documents from a single metrology system are retrieved, and data from external calibration institution certificates is not associated.

## How to confirm the configuration is correct
- Upload a single calibration certificate and its corresponding gauge ledger, submit a technical document cross-review request, and check whether the returned results include complete business fields such as instrument ID, calibration validity period, and uncertainty value.
- Trigger an abnormal update scenario, such as modifying the calibration validity period of a gauge, and check whether the system automatically pulls the updated document and re-links it to the traceability chain.
- View the retrieval log to confirm that the number of recalled documents meets the preset single search limit, with no redundant or missing associated business records.
- Enter uncertainty description content containing long text, and check that the returned review results do not lose key traceability-related information.

The values provided are common starting points and should be measured against the reader's own samples.
