# Cross-Review of Technical Documentation for Equipment Inspection and Preventive Maintenance: Citation Sources and Traceability

## What the data for this category looks like
This category covers the full equipment management workflow of manufacturing enterprises. Daily documentation includes equipment ledgers, inspection checklists, maintenance plans, work orders, failure analysis, spare parts lists, and special equipment inspection records. Data sources include EAM/CMMS systems, equipment sensor collection data, operator inspection records, maintenance history archives, spare parts inventory data, and statutory inspection information. Data update frequencies cover shift-by-shift inspections, daily/weekly/monthly scheduled maintenance plan updates, and real-time records when failures occur. Document fields include equipment numbers, inspection points, parameter thresholds, maintenance record numbers, spare part models, and some documents must meet fixed format field requirements for statutory inspections.

## What constraints do these characteristics impose on the "citation sources and traceability" link?
The data for this category is multi-source and has large differences in update rhythms. The citation and traceability link must support associating information from different sources such as EAM/CMMS, sensor data, and inspection records at the same time, and adjust the index synchronization cycle according to the data update frequency. Daily documents include standardized fields such as equipment numbers and inspection points. During traceability, precise field matching must be performed to avoid cross-document matching deviations. Special equipment inspection records must strictly correspond to statutory formats, and traceability results must retain complete identifiers of original records to ensure traceability. Maintenance work orders have strong associations with inspection checklists and maintenance plans, and chain traceability across documents must be supported to locate complete associated information of failures.

## How to configure the settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `1200–1800 token` | Single equipment record for this category is mostly 400-1200 characters in length, so sufficient context must be retained to match associated documents |
| `responseData` | Return complete fields with original source identifiers | Core traceability fields such as equipment number, record time, and inspection point must be retained |
| `detail` | Enable detailed traceability mode | Support tracing associated information across inspection checklists, maintenance work orders, and spare parts lists |
| Single search limit | Top 5 entries | Cover 3-4 recent inspection and maintenance records to avoid interference from redundant information |
| Citation content template | Display document type, number, and generation time | Facilitate quick location of original records, aligning with traceability habits for equipment management documents |

The values provided are common starting points and should be measured against the reader's own samples.

## Three common mistakes
- Phenomenon: Unable to obtain optional values for the equipment number variable when configuring citation traceability. Cause: The equipment number field is not output in the preceding node, or the variable configuration is not bound to the field mapping of the corresponding document.
- Phenomenon: Knowledge base search results do not associate the original inspection checklist number. Cause: The `detail` mode is not enabled, or the `responseData` configuration does not retain original source identifier fields.
- Phenomenon: Citation content is confused with prompt templates, resulting in missing traceability information. Cause: The citation content template for knowledge base references is mistakenly set to conversation prompt format, and document type and number information is not retained.

## How to confirm the configuration is complete
- Input a specific equipment inspection point number, and check whether the returned results include associated records of the corresponding inspection checklist and maintenance work order.
- View the original source identifier of the traceability result, and confirm whether core information such as document type, number, and generation time is included.
- Test the variable reference function, and confirm that the selectable fields match the bound document fields.
- Adjust the `quoteMaxToken` parameter, and check whether the returned context length meets the document matching requirements.
