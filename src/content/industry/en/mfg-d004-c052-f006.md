# Cross-Review of Technical Documentation for Steel Rolling and Finishing: Citation Sources and Traceability

## What This Category of Data Looks Like
This category of data originates from the full production process of hot rolling, cold rolling, section steel, and steel pipe enterprises. It includes slab or billet batch information, furnace operating parameters, mill automatic control records, online thickness and width measurement data, surface inspection results, and MES system ledgers.
Daily generated documents cover rolling plans, heating schedules, rolling specifications, plate shape and thickness records, surface quality reports, and quality certificates. Fields include batch number, heating temperature, rolling reduction rate, thickness deviation value, surface defect level, and more. Units include degrees Celsius, millimeters, tons, and others. Data is updated in real time per coil or per individual steel product.

## Constraints for Citation Sources and Traceability Imposed by These Characteristics
The real-time, coil-level data update requirement means citation traceability must be precisely tied to the unique batch number of a steel coil or billet, to avoid cross-batch confusion.
Multiple types of business documents require search filtering by document category, to prevent mixing in unrelated production process data.
Professional field differences across documents require that citation matching must link to the exclusive fields of the corresponding document, to avoid generalized matching.
The strict requirements for coil-level traceability mean cited sources must be traceable to specific production equipment and time nodes, to enable rapid location of abnormal issues.

## How to Configure This Setup
This page’s configuration is based on the functional logic of FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the average length of a single rolling specification or plate shape record, to ensure complete citation of core business parameters |
| Single search limit | Top 6 results | Corresponds to the number of documents associated with a single coil’s production, to avoid redundant citation of unrelated data |
| `responseData` | Enable batch number association field | Forces return of the billet or steel coil batch number corresponding to cited documents, to meet the core requirements of coil-level traceability |
| `detail` | Enable full citation marking | Displays the full storage path and update time of cited documents, to comply with traceability requirements for industrial documentation |
| Query optimization | Calibrate based on actual measurements | Adapts to professional terminology in rolling scenarios, to improve the accuracy of citation matching |

## Three Common Misconfigurations
- Returned content is unrelated to knowledge base citations, and citation fields are empty. Cause: The batch number association configuration for `responseData` is not enabled, so the system cannot match production batches to corresponding business documents.
- Exceeded expected number of citations, with unrelated documents from steelmaking processes appearing. Cause: Search scope is not filtered by document types for rolling and finishing scenarios, leading to accidental association with production data from other categories in the same broad group.
- System returns request timeout. Cause: `quoteMaxToken` is set too high, exceeding the system’s processing threshold for content splicing, leading to excessively long citation splicing time.

## How to Verify Proper Configuration
- Initiate a query for a rolling plan tied to a specific steel coil batch, and check whether the citation list in the returned results includes business documents corresponding to the target batch number.
- Review the citation details in the system return, to confirm that the `detail` configuration displays the full update time and storage path of the document.
- Check system logs to confirm that the number of citations returned per search does not exceed the preset single search limit.
- Test queries containing professional terminology, to confirm that the token count of cited content falls within the preset range of `quoteMaxToken`.

The values provided here are common starting points, and should be measured against the reader's own samples.
