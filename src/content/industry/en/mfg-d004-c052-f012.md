# Cross-Review of Technical Documentation for Steel Rolling and Finishing: Deployment and Upgrade

## What the Data for This Category Looks Like
This category primarily covers manufacturers of hot-rolled, cold-rolled, section, and steel pipe products. Daily technical documentation includes rolling plans, heating schedules, rolling specifications, plate shape and thickness records, surface quality reports, and quality certificates.
Data sources include slab/billet batches, heating furnaces, mill automatic control systems, online thickness and width measuring equipment, surface inspection devices, and MES systems.
Data updates are performed per coil or per piece. Some parameters sync in real time, and full-coil full-link traceability is supported.

## Constraints for Deployment and Upgrade
Data sources are scattered, and real-time performance requirements are high. During deployment, multi-source heterogeneous data access must be adapted. During upgrades, data synchronization links must not be interrupted.
Coil-level traceability requires strict binding of documentation and data. Configuration must define clear data association rules to prevent batch information mismatches.
Frequently updated rolling parameters and quality records create indexing pressure. The deployment phase requires planning appropriate storage and retrieval resources.
During upgrades, ongoing batch associations must not be interrupted to avoid impacting production. Existing industrial storage system interface specifications must be compatible.
All deployment and upgrade operations must follow the official specifications for FastGPT v4.17.0.

## Configuration Settings
| Config Item | Recommended Value | Rationale |
|---|---|---|
| `DB_MAX_LINK` | `100–150 concurrent connections` | Adapts to high-frequency query demands of multi-source real-time data, avoids connection pool exhaustion |
| `REDIS_URL` | `Local dedicated cache instance, memory no less than 2000 MB` | Stores real-time synced rolling batch association data, ensures retrieval response speed |
| `STORAGE_S3_ENDPOINT` | `Endpoint address adapted to the enterprise’s existing industrial storage` | Connects to existing plate shape record and quality certificate storage systems, avoids repeated data migration |
| `MONGODB_URI` | `Dedicated database instance, connection count calibrated via actual testing` | Stores association relationships between coil-level technical documentation and quality data, supports fast retrieval |
| `FE_DOMAIN` | `Secondary domain name of the enterprise’s internal production management system` | Limits access scope, ensures security of internal deployments |

## Three Common Configuration Errors
- Phenomenon: Reranker call succeeds but returns false. Cause: No dedicated vector model for the steel rolling product category is bound, leading to failed association matching between technical documentation and real-time production data.
- Phenomenon: Custom retrieval count set to more than 6 fails to take effect. Cause: The `DB_MAX_LINK` configuration value is not adjusted, so the connection pool cannot support retrieval requests exceeding the limit.
- Phenomenon: The plugin edit interface continuously displays an unsaved prompt after an upgrade. Cause: Frontend cache was not cleared during the upgrade, so the old version’s status verification logic was not replaced.

## How to Confirm Proper Configuration
- Call FastGPT’s configuration verification interface to check that core parameters including `DB_MAX_LINK`, `REDIS_URL` and others match the preset values.
- Upload a hot-rolled plate shape and thickness record document, run a retrieval operation, and confirm that the corresponding rolling batch data can be associated.
- Adjust the custom retrieval count to 10, and verify that the number of retrieval results returned by the interface matches the set value.
- Access the frontend address corresponding to `FE_DOMAIN`, open the plugin edit interface, edit content and click save, and confirm that the prompt message disappears.

The values provided are common starting points and should be measured against the reader's own samples.
