# Cross-Review of Technical Documents for Sheet Metal Cutting and Bending: Quote Sources and Traceability

## What the Data for This Category Looks Like
Daily documents for this category include expansion drawings, CNC cutting programs, bending process cards, nesting diagrams, first-piece records, and process flow cards. Data originates from CAD/CAM software, order BOMs, sheet metal inventory systems, laser cutters, bending machines, and MES systems. Updates to this data are triggered by orders, daily production runs, or each changeover. Most document fields include sheet thickness, bending compensation coefficients, cutting dimensions, bending sequences, and other relevant details. Common engineering units such as millimeters and kilograms are used. The data volume of a single document varies based on process complexity.

## Constraints for Quote Sources and Traceability
Most documents use structured or semi-structured formats exported from CAD. Precise matching of drawing parameters and process data is required, so traceability workflows must limit the allowed format range of data sources. Update frequencies are high, with scattered trigger points, so real-time pulling of the latest order BOMs, inventory data, and process records is necessary to avoid using outdated information. Documents linked to multiple processes require traceability that can connect related data across documents, covering data sources for all involved processes. Consistent engineering units across fields require automatic unit conversion rules to be applied during traceability, preventing data misalignment.

## Configuration Guidelines
This configuration is based on FastGPT v4.17.0. Specific values can be adjusted for actual production scenarios.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 characters | Matches the length of core single-segment data in sheet metal process documents, avoiding truncation of key parameters such as bending coefficients and cutting dimensions |
| `responseData` | Include original quote snippets | Ensures direct access to original document text during cross-review to verify parameter accuracy |
| `detail` | Recall by process association | Covers associated documents such as expansion drawings, cutting programs, and bending process cards, meeting the needs of multi-link cross-checking |
| Single recall limit | Top 5 entries | Avoids excessive redundant data interfering with review, while covering data sources for major production processes |
| Quote source display format | Label document type and generation time | Aligns with auditing habits in sheet metal production, enabling quick location of latest process data |
| Timeout threshold | 60 seconds | Adapts to pull delays for CAD/CAM data, avoiding review failures caused by data pull timeouts |

## Three Common Configuration Errors
- Phenomenon: A POST request is initiated, the interface connects, but no content is returned. Cause: The `responseData` parameter is not configured correctly, and the return switch for original quote snippets is not enabled.
- Phenomenon: Garbled characters or misaligned formatted quote snippets appear in review results. Cause: Engineering units and field formats of sheet metal documents are not matched, and the automatic format verification switch is not enabled.
- Phenomenon: Recalled quote sources do not cover documents for associated processes. Cause: The recall level by process association is not set, and only documents of a single type are recalled.

## How to Confirm Successful Configuration
- Upload a typical bending process card and nesting diagram, initiate a cross-review request, and check if the returned results include quote snippets from the original documents.
- View the display format of quote sources, confirm that document types and generation times are labeled, in line with applicable production auditing habits.
- Simulate a production request after a changeover, check if the recalled data sources include the latest sheet metal inventory and process flow data.
- Adjust the single recall limit setting, verify that the number of returned quote sources matches the expected recall rules.

The values provided are common starting points and should be evaluated against samples from the actual production environment.
