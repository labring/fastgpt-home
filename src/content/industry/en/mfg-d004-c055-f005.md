# Cross-Review of Technical Documents for Foundry (Sand Casting, Precision Casting, Die Casting): Tool Calling and Plugins

## What data for this category looks like
Daily documents for this category include foundry process cards, batching lists, heat records, mold histories, first-piece inspection records, material test reports, and nonconforming product review forms. A single heat record includes dozens of parameters covering temperature and composition data for the full melting process. Data sources are ERP material master data, melting furnaces and thermometers, spectrometers, MES heat records, mold management systems, customer drawings, and technical requirements. Data is updated per heat, per batch, and daily. Document fields include professional parameters such as alloy composition percentage, pouring temperature, heat number, mold cycle, and return charge ratio. Common units are percentage, degrees Celsius, and kilograms.

## Constraints imposed on tool calling and plugin workflows by these characteristics
This category of data has a high update frequency and requires cross-document cross-checking across multiple systems. Tool calling must support real-time pulling of the latest data from different sources. Document fields have specialized attributes, so plugins must match dedicated parameter names and units to prevent check failures from field mismatches. Reviews for a single heat or batch require processing multiple associated documents. Tool calling must support batch queries and field association matching to ensure cross-review accuracy. System response speeds vary across foundry workshops, so tool calling parameters must support flexible adjustment for different scenarios.

## Three Common Configuration Mistakes
- Issue: Plugins fail to trigger in the chat interface after configuration. Cause: The plugin configuration file was not placed in the FastGPT-specified plugin directory, and enabling was not completed in system settings.
- Issue: Fields returned by tool calling are empty or formatted incorrectly. Cause: Dedicated foundry scenario parameter names were not matched. For example, "return charge ratio" was replaced with a generic term.
- Issue: Tool calling terminates due to timeout. Cause: A reasonable timeout duration was not set, and batch data query delays in foundry workshop systems were not accounted for.

## How to Verify a Successful Configuration
- View configured tools on the plugin management page of FastGPT v4.17.0, and confirm the status shows normal operation.
- Submit a test request with a specific heat number, and verify that the tool pulls corresponding batching list and heat record data.
- Check that tool calling return results include dedicated foundry fields such as alloy composition, pouring temperature, and mold cycle.
- Simulate a batch query of multiple associated documents, and confirm that tool calling successfully matches and returns associated data.
