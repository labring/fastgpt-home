# Bid Document and Quotation Preparation for PCB Manufacturing: Model Access and Configuration

## What Data for This Category Looks Like
Data for this category comes from client-provided Gerber files, drill files, BOM lists, plus internal factory CAM system data, production equipment parameters, bath solution test records, AOI inspection reports, electrical testing reports, and laboratory slice reports. Data is collected continuously alongside production batches and work shifts. Each production batch corresponds to complete documents including engineering production instructions, drilling lamination parameters, chemical solution analysis ledgers, and related records. Documents include fields such as layer number, aperture size, bath solution concentration, and detected defect type. Units use industrial standard measurements including millimeters, megapascals, and percentages.

## Constraints Imposed by These Characteristics on Model Access and Configuration
Multi-source heterogeneous data sources require access configuration to support parsing binary-format Gerber files and structured data from proprietary CAM fields. General text processing logic alone is insufficient. Frequently updated high-volume production data requires context window configuration to align with real-time synchronized business status. This prevents quotation deviations caused by expired context. Bid documents must bind to client-specific engineering parameters. This requires automatic calls to corresponding data source tools to extract fields, with tool call logic tightly tied to business processes. Quotation errors may lead to full batch scrap or high-value claims. As such, generation randomness must be limited to avoid parameter distortion.

## How to Configure Settings
The following configurations are written for FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | Adapts to the context length of multi-source production data, covering complete engineering and inspection data for a single production batch |
| `maxTokens` | 4000 token | Limits the output length of a single quotation and document generation, avoiding redundant content that causes chaos in bid file formatting |
| `quoteMaxToken` | 1500 token | Separately limits the generation length of quotation details, ensuring each quotation parameter is clear and compliant |
| `toolChoice` | auto | Automatically triggers tool calls to extract business fields such as client Gerber parameters and CAM drilling data |
| `temperature` | 0.2–0.4 | Reduces generation randomness, ensuring quotation parameters strictly match actual production data and avoiding incorrect values |
| `AIPROXY_API_ENDPOINT` | Fill in according to the factory's exclusive proxy address | Adapts to the internal network environment, ensuring security and stability of data transmission |
| `AIPROXY_API_TOKEN` | Configure according to the exclusive secret key | Ensures permission security for interface calls, preventing unauthorized access |

## Three Common Misconfigurations
- Interface logs show continuous calls during non-working hours, causing rapid account balance depletion. The root cause is missing access time window and IP whitelist configuration, allowing unauthorized third parties to use public API keys.
- Generated bid documents include drilling parameters that do not match the current production batch. The root cause is an overly small `maxContext` setting, which fails to load the latest CAM equipment parameters and leads to missing context.
- Generated quotation details use mixed units, such as millimeters and inches. The root cause is missing unit standardization conversion configuration in the tool call logic, with raw data extracted directly without unified processing.

## How to Verify Proper Configuration
- Submit test client Gerber files and BOM lists, confirm generated engineering parameters match original data.
- Simulate an interface call during non-working hours, check for access restriction triggers, confirm time window configuration is active.
- Generate a single batch of bid quotations and documents, confirm output length matches preset generation limits.
- Review interface call logs, confirm automatic tool call triggers and correct extraction of data fields including CAM and bath solution test records.

The values provided here are common starting points and should be evaluated against individual deployment samples.
