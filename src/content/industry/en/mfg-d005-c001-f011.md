# Bid Document and Quotation Preparation for PCB Manufacturing: Forms and Interactions

## What data for this category looks like
Data for this category comes from Gerber files, drill files, and BOM lists submitted by customers, as well as factory internal data including CAM system records, production equipment parameters, bath chemistry test logs, AOI inspection reports, electrical testing reports, and slice analysis reports. Daily documents include engineering production instructions, drilling and lamination parameter records, and chemical analysis ledgers.
Data is updated per production batch, with continuous collection per shift. Parameters across different production links are updated in real time as production progresses. The documents associated with a single quotation cover all data fields across the full process from customer requirements to finished product inspection.

## What constraints these characteristics impose on forms and interactions
Data for this category is scattered and highly specialized. Forms must support uploading multi-format professional files and automatically associate parsed results.
Data is updated per production batch and in real time, so forms must bind batch identifiers to enable full-chain traceability.
Fields include engineering parameters such as drilling aperture and lamination thickness, so standardized preset options are needed to reduce input errors.
Bid quotations must associate core data such as layer count and board type parsed from Gerber files, so forms must support automatically pulling corresponding fields for pre-filling to avoid duplicate entry and information inconsistency.

## How to configure the setup

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Enable multi-file upload, supporting Gerber, BOM, and drill file formats | Core business data for this category comes from professional engineering files submitted by customers, which must be uploaded directly for system parsing |
| `userSelect` | Preset 12 industry-standard PCB board types and 3-level drilling accuracy grades | Fields involve specialized engineering parameters; preset options reduce input errors |
| Batch binding field | Automatically associate production batch ID | Data is updated per production batch and per shift, so batch binding is required for full-chain traceability |
| Parameter validation rules | Limit drilling aperture range to 0.1–10 mm, lamination thickness range to 0.2–5 mm, chemical solution concentration range to 5–15 g/L, set timeout to 300 seconds | Professional parameters must conform to the actual processing range of production equipment; large files require reserved parsing time |
| Auto-fill fields | Pull layer count and board thickness parameters parsed by CAM | Avoid duplicate entry of known data already provided by customers |
| Result export configuration | Bind corresponding placeholders in bid document templates | Quickly generate standardized bid quotation documents from form data |

## Three Common Mistakes
- Symptom: After adding a custom plugin to a workflow, the plugin node displays no input or output parameters, and no error logs are generated. Cause: The `formInput` field is not configured in the form as the plugin's input source, so the plugin cannot bind to the interaction node to retrieve data.
- Symptom: The bid document generated after form submission lacks drilling parameter content. Cause: The drilling aperture field is not bound to the corresponding placeholder in the export template, so data is not filled correctly.
- Symptom: Data confusion occurs when cyclically calling AI sessions to process multiple batches of Gerber files. Cause: No production batch filtering conditions are bound to the cycle configuration, so data from different batches is processed together.

## How to Confirm Configuration is Complete
- Upload test Gerber and BOM files, confirm that the form automatically parses and fills corresponding fields.
- Select preset board types and accuracy grades, verify that the parameter validation rules block input values outside the allowed range.
- Bind a test bid document template, submit the form and confirm that template placeholders are correctly replaced with form data.
- View workflow logs, confirm that the custom plugin can normally read the content of the form's `formInput` field.

The values provided here are common starting points, and should be evaluated against the reader's own samples.
