# Tender Document and Quotation Preparation for Photovoltaic Cell Manufacturing: Vector Models and Indexing

## What Data for This Category Looks Like
Documents generated daily by process, equipment, and quality teams at crystalline silicon photovoltaic cell manufacturers. Data sources include silicon wafer incoming material records, MES systems, operating parameters for diffusion furnaces, coating equipment, and printing presses, EL and IV test results, and laboratory test data. Data is updated per batch of materials, per wafer test, and with daily generated reports. Document types include process cards, diffusion and coating parameter records, printing and sintering logs, EL detection images, IV grading data, and yield reports. Fields cover equipment operating parameters, test result values, and process step nodes. Data includes structured tables, semi-structured text, and image types, with no fixed unified format.

## Constraints Imposed by These Characteristics on Vector Models and Indexing
The business data of photovoltaic cell manufacturing has multiple format types and high-frequency update characteristics, requiring the indexing system to support both text and image vector generation and adapt to incremental indexing logic. The continuous production workflow requires retaining contextual associations between adjacent process steps during chunking, to avoid breaking the logical chain of process parameters. Wafer-level data has numerous fine-grained fields, so the vector model must support multi-field concatenated text input. This ensures accurate association of process parameters and cost accounting basis when preparing tender documents and quotations.

## How to Set Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Adapts to the single-process parameter length of photovoltaic cell process documents, avoids breaking process logic during chunking |
| Overlap Length | 100–200 characters | Retains contextual associations of adjacent processes, prevents loss of the sequential relationship of process parameters after chunking |
| `defaultToken` | 2048 | Matches the number of fields in structured photovoltaic cell data and the text length of single records |
| `maxToken` | 8192 | Adapts to the chunking needs of long texts such as IV grading data and yield reports, avoids exceeding the model's context window |
| Similarity Threshold | Calibrated via actual testing | Matches the matching accuracy requirements of photovoltaic cell process parameters, adapts to parameter comparison needs during bidding |
| Single Search Limit | Top 5 entries | Controls the context length during tender document generation, avoids redundant data interfering with quotation calculations |

## Three Common Misconfigurations
- Chunking error after version upgrade: Calling the file upload interface returns success, but the indexing task fails. Logs indicate a chunking parameter mismatch. This occurs because the default value range of `defaultToken` is adjusted in the new version, and the configuration does not adapt to the field length of the original photovoltaic cell data.
- Indexing task stuck for an extended period and cannot recover: The indexing status shows running beyond the preset duration, and some IV grading data fails to generate vectors. This occurs because a reasonable `maxToken` limit is not set, leading to blocking when long text chunking exceeds the model's context window, and breakpoint resume indexing configuration is not enabled.
- Abnormal reference results after switching vector models: The knowledge base reference returns empty results, and the frontend displays no matching content. This occurs because the vector model dimension configuration is not updated synchronously, so the original indexing vectors do not match the vector space of the new model.

## How to Verify Proper Configuration
- Upload a single standard process card document, access the chunking preview interface, and confirm that the text length after chunking falls within the configured chunk length range.
- Navigate to the vector model configuration page, confirm that the model adapted to multi-field text is selected, and verify that the `defaultToken` and `maxToken` configuration values match the recommendations in the table.
- Trigger an incremental indexing task, upload newly added EL detection image associated data, and check whether the corresponding content can be retrieved in the knowledge base after indexing completes.
- Call the task status query interface of FastGPT v4.17.0, pass the task ID returned after uploading the file, and confirm that the returned status is completed.
