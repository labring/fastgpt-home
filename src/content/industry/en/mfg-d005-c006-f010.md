# Tender Document and Quotation Preparation for Photovoltaic Module Encapsulation: Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
Data for the photovoltaic module encapsulation process comes from cell grading records, glass adhesive film backplane batch ledgers, production MES systems, string welding and lamination equipment logs, EL defect detection images, IV power test reports, insulation withstand voltage test records, and finished product packing lists.
Data update frequency: Each module corresponds to an independent record, and batch archives are generated synchronously for each batch of raw materials.
Document types cover structured ledgers, process parameter tables, image files, and layout description documents.
Fields include professional parameters such as current gear, lamination temperature, crack coordinates, power value, and withstand voltage rating.

## Constraints Imposed by These Characteristics on Knowledge Base Retrieval and Recall
The high-frequency, multi-type data characteristics of photovoltaic module encapsulation require the retrieval and recall link to support real-time incremental synchronization. This prevents process parameter errors in tender quotations caused by delayed data.
Multi-source heterogeneous documents need to adapt to different parsing rules. This ensures that non-plain text content such as EL images and IV test reports can be correctly indexed.
The precise matching requirement for professional fields requires the retrieval logic to balance semantic association and exact keyword matching. This avoids incorrect association of material records from different batches caused by fuzzy matching.
In addition, tender documents must cover full-process process parameters. The number of retrieved and recalled results must meet multi-dimensional coverage requirements, and documents from key links cannot be omitted.

## Configuration Settings
The following configurations are based on FastGPT v4.17.0:

| --- | --- | --- |
| `similarity` | 0.75–0.85 | Matches the precision requirement for professional process parameters of photovoltaic modules, filters out low-relevance non-batch documents |
| `limit` | Top 8 entries | Covers multiple tender-required links including string welding, lamination, testing, and packaging |
| `searchMode` | Semantic + keyword hybrid retrieval | Balances exact matching of professional terms such as cell current gear and semantic association of process flows |
| `usingReRank` | Enabled | Performs secondary ranking on initial recall results, prioritizes documents with higher relevance to tender parameters |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands retrieval terms, supplements derivative documents such as associated material batches and equipment logs |

## Three Common Mistakes
- Issue: Markdown document upload via API or page fails, with an incompatible format prompt. Cause: Parsing rules for non-plain text content such as embedded EL images and IV test reports in photovoltaic module encapsulation documents are not adapted, causing the upload process to interrupt.
- Issue: Importing a publicly shared Yuque link fails with a parsing error prompt. Cause: The link is not confirmed to be a publicly accessible page without permission restrictions, and the knowledge base's web extension parsing configuration is not enabled, making it impossible to crawl the process document content within Yuque.
- Issue: Deleting a folder containing a large number of documents in the knowledge base triggers a `timeout of 60000ms exceeded` error. Cause: Batch processing logic for bulk deletion is not configured, and the system's default timeout threshold does not adapt to bulk deletion operations for large folders.

## How to Confirm the Configuration Is Correct
- Enter a retrieval term that includes a specific cell current gear, check whether the `similarity` score of the returned results falls within the preset 0.75–0.85 range.
- Call the retrieval interface to verify that the number of returned results matches the `limit` configuration value, ensuring that multi-link documents required for tender are covered.
- Upload a Markdown document containing EL images and IV test reports, confirm that it can be normally retrieved and recalled after parsing, and that the corresponding test parameters are included in the results.
- Test deleting a folder containing 1000+ documents, confirm that the 60000ms timeout error is not triggered, and verify the stability of the batch operation.
