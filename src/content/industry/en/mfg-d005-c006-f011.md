# Tender Document and Quotation Preparation for Photovoltaic Module Encapsulation: Forms and Interactions

## What the data for this category looks like
Data sources for the photovoltaic module encapsulation link include battery cell grading records, glass adhesive film backplane batch ledgers, production MES systems, string welding and lamination equipment logs, and EL/IV tester output reports.
The data update rhythm follows: each module generates a corresponding test record, and each batch of raw materials updates batch information synchronously.
Daily generated documents include component layout diagrams, material batch traceability forms, lamination process parameter ledgers, EL crack detection images, IV power test reports, insulation voltage withstand test records, and finished product packing lists.
Data fields include battery cell current gear, lamination temperature duration, EL defect locations, power values, and more. Units include watts, degrees Celsius, seconds, and others.
This link electrically connects and encapsulates battery cells into outdoor weather-resistant products. It focuses on lamination processes and power grading, and differs from the semiconductor surface process links in battery cell manufacturing.

## What constraints do these characteristics impose on the forms and interactions link
High data update frequency and fine granularity per single module. Forms must support real-time association with the latest batch materials and equipment parameters to avoid calling outdated data.
Diverse document types including image EL diagrams and IV reports. Forms must support multi-format file upload and parsing triggers.
Tender quotations need to match detailed fields such as battery cell current gear. Forms must preset fixed fields and dynamically associated options to reduce manual entry errors.
Error consequences include non-compliant power ratings, lamination delamination, and other issues. Forms must add mandatory validation and abnormal field prompts to intercept non-compliant data in advance.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Triggered by component batch ID | Matches the rhythm of data updated per batch of materials, avoids invalid calls |
| `userSelect` | Preset option group for battery cell current gear | Corresponds to the most time-consuming matching link in the business, reduces manual input errors |
| Maximum single search limit | Top 8 entries | Covers multiple sets of test data associated with a single module, avoids missing key parameters |
| Maximum context length | 1200–1500 characters | Adapts to the text length after EL image parsing, ensures complete information |
| Timeout threshold | 600 seconds | Adapts to the time required for multi-format document parsing, avoids mid-process interruptions |
| File upload limit | 1000 MB | Supports batch upload of multiple types of documents including EL images and IV reports |

## Three Common Mistakes
- Phenomenon: Search results only return a single set of data, and cannot match multiple sets of battery cell grading records. Cause: The multi-option association rule of `userSelect` is not configured. Only a single vector model is bound, and parallel retrieval of multiple data sets is not implemented.
- Phenomenon: The conversation interface cannot display input and output token statistics data. Cause: The token statistics configuration switch is not enabled, and the corresponding data statistics node is not associated.
- Phenomenon: Parsed EL image data cannot be obtained after an HTTP interface call. Cause: No variable receiving rule is configured in the workflow, and the fields returned by the interface are not mapped to the input items corresponding to `formInput`.

## How to Confirm the Configuration Is Correct
- Manually enter the component batch ID, trigger the binding rule of `formInput`, and check whether the corresponding batch materials and test data are automatically associated.
- Click the selection box for battery cell current gear, and check whether preset grading options are loaded with no missing gear data.
- Upload EL images and IV test reports, and check whether the workflow normally parses and returns corresponding fields with no timeout or empty data error messages.
- Launch a complete quotation preparation process, and check whether the conversation interface displays input and output token statistics data as expected.

The values listed above are common starting points, and should be evaluated against the reader's own samples.
