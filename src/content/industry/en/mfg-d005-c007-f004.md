# Bid Documentation and Quotation Preparation for Stamping and Sheet Metal Forming: Workflow Orchestration

## What This Category’s Data Looks Like
This category’s data covers the entire production flow of stamping workshops for automotive body panels, home appliance sheet metal parts, and hardware components. Daily documents include stamping work instructions, material utilization rate sheets, mold inspection logs, first and last piece records, dimensional inspection reports, and mold change records. Data sources include steel coil labels and quality certificates, real-time data from stamping presses and feeders, mold management systems, MES systems, and coordinate measuring machine or fixture inspection data. Data updates are triggered per coil of material, per batch of materials, and each mold change. Fields include material grade, sheet thickness, mold number, production batch, inspection dimensional parameters, and additional relevant metrics.

## What Constraints Do These Characteristics Impose on Workflow Orchestration
The high update frequency, scattered data sources, and large number of fields for this category’s data create multiple constraints for workflow orchestration. The update rhythm triggered per coil, batch, or mold change requires workflows to use trigger nodes that run only when the corresponding event occurs, eliminating redundant calculations and outdated data. Integrating multi-source data requires sequentially connecting mold management systems, MES systems, and other data source nodes within the workflow to complete data cleaning and format standardization. Bid quotations rely on accurate material utilization rates and mold wear parameters, so workflows must perform pre-checks to verify the completeness of core fields, preventing quotation deviations caused by missing data.

## How to Set Configurations
| Configuration Item | Recommended Approach | Basis for This Approach |
| --- | --- | --- |
| Trigger Condition | Bind to coil warehousing and mold change completion events | Match the data update rhythm triggered per coil and mold change for this category |
| Variable Configuration (`variables`) | Introduce material thickness, mold number, production batch variables | Cover core production parameters required for bid quotation |
| Node ID (`nodeId`) Configuration | Set unique identifiers for each core node | Facilitate subsequent troubleshooting and process import/export |
| Data Source Docking Nodes | Configure 3 parallel docking nodes, with a timeout threshold set to 20 seconds each | Integrate multi-source production data and avoid overall process disruption caused by single data source failure |
| Text Classification Extraction Node | Extract no more than 1500 characters of document content each time, extract the top 10 core fields | Extract necessary parameters from documents such as stamping work instructions |
| Basic Chart Configuration | Follow the measured calibrated axis variable reference rules | Adapt to comparative display of sheet thickness, production volume and other metrics |

## Three Common Errors
- Text classification extraction nodes return empty results. This occurs when document fields are not mapped to the `variables` parameter, so the node cannot identify the target fields to extract.
- Workflow application imports fail, and old version configurations cannot be loaded in FastGPT v4.17.0. This happens when the complete node dependency package is not exported, and only the process file is exported, resulting in lost configurations.
- Basic chart axis variable references are incorrect. This occurs when the `variables` parameter in the workflow is not bound to the data source for the chart axis, causing the axis to display empty or incorrect values.

## How to Confirm the Configuration Is Complete and Correct
- Trigger a coil warehousing event to check if the workflow starts automatically.
- Review logs from data source docking nodes to confirm all interfaces return valid data.
- Run the text classification extraction node to verify that extracted fields match the preset `variables` parameters.
- After configuring the basic chart, preview the chart to confirm the x-axis and y-axis reference the correct workflow variables.
