# Bid Document and Quotation Preparation for Stamping and Sheet Metal Forming: Model Access and Configuration

## What the data for this category looks like
This category's data comes from various business documents and equipment collection information from stamping workshops. It includes stamping operation instructions, material utilization rate tables, mold inspection logs, first/last piece records, dimensional inspection reports, mold change records, and more. Data sources cover steel coil labels and quality certificates, operation data of stamping presses and feeders, mold management systems, MES systems, and coordinate measuring machine or fixture inspection results. Updates to this data trigger per coil of material, each production batch, and each mold change operation. A single update includes fields such as material parameters, equipment status, and inspection results for the corresponding batch.

## What Constraints These Characteristics Impose on Model Access and Configuration
This category has high-frequency data updates and covers multiple types of business documents. When accessing the model, adapt to high-frequency updated data sources to avoid retrieving expired mold change records or material parameters. There are significant field differences across different business documents. For example, the material utilization rate table includes material grade and thickness parameters, while the mold inspection log includes mold number and wear amount information. Ensure the model can recognize the exclusive fields of different documents. Bid document and quotation preparation requires accurate material utilization rate and mold debugging cost data, so limit the model context to business-related scope to avoid irrelevant information interfering with calculation results.

## How to Set the Configuration
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Range | Rationale |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | Matches the total length of multiple types of stamping workshop business documents, avoiding truncation of core material utilization rate and mold parameter data |
| `temperature` | 0.1–0.3 | Meets the rigor requirements for quotation and bid document preparation, reducing random output deviation |
| `quoteMaxToken` | 1500–2000 token | Limits the length of retrieved referenced content, ensuring only directly relevant material utilization rate tables and mold inspection records are included |
| `AIPROXY_API_ENDPOINT` | Calibrated based on actual testing | Adapts to domestically or overseas deployed nodes, avoiding cross-region access latency |
| `AIPROXY_API_TOKEN` | Exclusive key bound to the deployment node | Ensures access security for data interfaces and prevents unauthorized calls |

## Three Common Misconfigurations
- Semantic retrieval scores appear too high in the interface, with no matching business scenarios. This occurs because retrieval rules remain unadjusted for the exclusive document types of stamping workshops, leading to irrelevant mold inspection logs being prioritized for recall.
- A `tls: failed to verify certificate` error occurs during model calls. This happens because one fails to configure correct API node certificate verification rules, or uses an unauthorized transit interface.
- A single production data entry cannot generate multiple corresponding vectors. This occurs because multi-vector association configuration remains disabled, with only a single vector model bound, making adaptation to field differences across multiple business document types impossible.

## How to Verify Successful Configuration
- Upload the quality certificate and material utilization rate table for a single steel coil, and confirm retrieval results only return business documents for the corresponding batch.
- Submit a quotation preparation request, and check that the output includes material utilization rate and mold debugging parameters consistent with the uploaded documents.
- View the model call log, and confirm the `maxContext` parameter of the API request matches the configured value, with no truncation errors.
- Upload a new mold change record after simulating a mold change operation, and confirm retrieval results automatically update to the latest mold parameters.

The values provided are common starting points and should be measured against the reader's own samples.
