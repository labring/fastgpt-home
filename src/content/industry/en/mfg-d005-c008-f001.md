# Tender Document and Quotation Preparation for Cosmetics Manufacturing: HTTP Interfaces and External Systems

## What the data for this category looks like
This category’s data comes from registered and filed formulas, raw material safety documents, weighing and emulsifying equipment, ERP/MES systems, laboratory records, and packaging material version libraries for skincare, haircare, makeup, and special cosmetics manufacturers. Daily documents include formula process sheets, weighing and feeding records, emulsification and filling records, cleaning and sanitization records, semi-finished and finished product inspection reports, and label review forms. Fields include raw material ingredients, restricted substance content, production batch numbers, packaging material specifications, claimed content, and more. Updates are triggered per production batch or each line changeover.

## What constraints these characteristics impose on the "HTTP Interfaces and External Systems" link
Data sources for this category are scattered, involving multiple systems such as production equipment, ERP/MES, and laboratories. Multi-source data must be connected via HTTP interfaces. The high update frequency requires interfaces to pull the latest filed formulas, packaging material versions, and other information in a timely manner, to avoid using expired data in tender documents. Fields are subject to filing regulations and contain sensitive content such as restricted substances. Fields transmitted via interfaces must be accurate, otherwise compliance risks may arise. The consequences of errors are directly linked to product removal and recall, so interfaces must have failure retry and data verification capabilities to ensure data consistency.

## How to set the configuration
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Basis for This Approach |
| ------ | -------- | ------------ |
| `Authorization` | Carry `Bearer {token generated by oneapi}` | Used to connect external model channels and complete interface authentication |
| `variables` | Pass `{"recipe_version": "{{filed formula version}}", "pack_material": "{{packaging material version}}"}` | Pass business-specific variables for cosmetics manufacturing to ensure tender data matches the latest filings |
| `responseData` | Extract `quote_content, tender_document` | Match the core return fields required for tender document and quotation preparation |
| Interface timeout threshold | 30–60 seconds | Adapt to the average time required to pull data from multiple systems, avoid request interruption |
| Number of failure retries | 2 times | Respond to temporary network fluctuations or short-term unavailability of external systems |
| Field verification switch | Enabled | Verify that returned data contains required fields such as restricted substances and production batch numbers |

## Three common mistakes
- A "channel unavailable" error is returned during a call. Investigation shows the token configured for the oneapi channel was not correctly bound to the `Authorization` parameter in FastGPT.
- The interface returns empty fields. The cause is that correct business variables were not passed via `variables`, causing the external system to fail to match formula and quotation data for the corresponding production batch.
- A token invalid prompt is returned after a call. The cause is that a valid token generated by oneapi was not used, or the token did not carry the correct Bearer prefix.

## How to confirm the configuration is complete
- Execute an interface test request and check whether the returned results contain cosmetics manufacturing-specific fields such as formula ingredients and packaging material specifications.
- Trigger a complete tender document generation process and verify that the generated content matches the latest filed formulas in the ERP system.
- Simulate a oneapi channel authentication failure scenario and confirm that the system triggers corresponding error prompts and logs the event.
- Adjust the values of business variables in `variables` and verify that the returned quotation and document content will update along with the variable changes.

The values given are common starting points and should be measured against the reader's own samples.
