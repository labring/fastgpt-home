# Bid Document and Quotation Preparation for Cosmetics Manufacturing: Forms and Interactions

## What the data for this category looks like
Cosmetics manufacturing enterprises cover skincare, hair care, makeup, and special cosmetic categories. Daily generated documents include formula process sheets, weighing and feeding records, emulsification or filling records, cleaning and sanitization records, semi-finished and finished product inspection reports, and label review documents. Data sources include registered or filed formulas, raw material safety materials, production equipment data, ERP/MES systems, laboratory test results, and packaging material version records. Update frequency is per production batch or each line change. Core fields include formula number, raw material name, restricted substance content, emulsification temperature, filling specification, batch number, and packaging material version number, with corresponding units such as ℃, ml, g, batch number, and others.

## What constraints these characteristics impose on forms and interactions
The high-frequency update requirement for each line change means forms must support real-time pulling of the latest filed formulas and production data, to avoid using expired parameters. Multi-source cross-departmental data sources require forms to support cross-module linkage, such as automatically displaying restricted substance limits from raw material safety materials when a raw material batch is entered. Strict review requirements and severe error consequences require forms to have built-in field verification rules to block inputs that do not meet filing requirements. The bulk submission requirement in bidding scenarios requires forms to support bulk import and verification of multi-batch data, while ensuring each piece of data matches the current batch’s filing information.

## How to set the configurations
These configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Enable real-time field verification, set input length to 10–2000 characters | Match the common length requirements for fields such as formula numbers, raw material names, and batch numbers, to avoid rendering exceptions caused by overly long inputs |
| `userSelect` | Set to render options after data loading completes, set delay loading duration to 300–800 milliseconds | Adapt to high-frequency data updates after each line change, to avoid option errors caused by loading old data |
| Dynamic data source synchronization frequency | Synchronize once every 15–30 minutes | Balance data timeliness and server load, match the update rhythm of each production batch change |
| Pre-submission form verification | Force verification of required fields, including formula number, restricted substance content, and packaging material version number | Avoid bid document errors caused by missing key information, match the business requirements for severe error consequences |
| Multi-source data linkage trigger | Trigger linkage based on input field changes | Ensure real-time matching of cross-department source raw material and packaging material data with current form inputs |

## Three common mistakes
- Symptom: The raw material selection dropdown in the form keeps flashing and refreshing. Cause: The delay loading parameter for `userSelect` is not set, and the data source synchronization frequency is not limited, causing the page to repeatedly trigger data pulling.
- Symptom: Bid documents can be submitted without a fully filled formula number. Cause: Required field verification for `formInput` is not enabled, and pre-submission integrity checks are not configured.
- Symptom: Extracted restricted substance content exceeds filing limits but no prompt is triggered. Cause: No verification rule matching filing values is configured for the content field in `formInput`, causing abnormal data to not be blocked.

## How to confirm the configuration is correct
- Manually enter a restricted substance content that exceeds filing limits, check whether the corresponding verification prompt is triggered.
- Wait for the synchronization cycle to end, refresh the form, check whether the data source has been updated to the latest line change batch data.
- Try to submit the form without filling in required fields, check whether submission is blocked and an error prompt is displayed.
- Enter a packaging material version number, check whether the corresponding label claim content is automatically displayed.
