# Tender Document and Quotation Preparation for Chemical Pharmaceutical Dosage Production: Forms and Interactions

## What data for this category looks like
Data sources for chemical pharmaceutical dosage production include approved formulation processes, MES/electronic batch records, LIMS, and quality management systems. Daily documents cover master production files, batch production records, batch packaging records, inspection records, deviation/CAPA/change records, and similar items. Fields include material batch number, weighing value, process temperature, deviation number, and others. Units include mg, L, ℃, min, and others. Data is updated per batch production, each key process step, and per fixed monitoring plans.

## What constraints do these characteristics impose on forms and interactions
Data from multiple systems requires forms to support cross-source variable references. This avoids duplicate errors from manual entry.
Batch-based update requirements mean forms must bind batch-dimension dynamic fields. This ensures the latest data for the current batch is used for each tender submission.
Under GMP compliance rules, form interactions must retain audit trail nodes. Only quality-released data may be referenced.
Strict field unit rules require forms to include built-in unit validation. This prevents non-compliant formatted content from entering tender documents.

## How to set configurations
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| Form input field configuration | Bind `formInput` variable, enable unit validation rules | Pharmaceutical dosage form data requires matching fixed units such as mg, L, ℃ to avoid format errors |
| User selection component | Preset `userSelect` batch number option group | Data comes from approved batch lists in MES systems, reducing manual input errors |
| Variable reference validation | Enable strict format validation, only allow referencing GMP-released fields | Prevent referencing unapproved deviation or process data, comply with compliance requirements |
| Context length limit | 800–1200 characters | Adapt to the document length of single batch records, ensure model processing efficiency |
| Timeout setting | 600 seconds | Adapt to data pull latency across LIMS and quality management systems |
| Form submission trigger | Require two-level approval nodes | Match GMP processes for batch release approval, ensure data compliance |

## Three common mistakes
- A `quote type error` pop-up appears when submitting tender documents. The cause is failing to reference variables in the required `formInput` or `userSelect` format, and mixing unvalidated custom fields.
- Custom channel configuration fails when called, returning a `500` status code. The cause is failing to correctly fill in the authorization key and interface address in the channel configuration for FastGPT v4.17.0.
- BI charts render without data, with empty title or axis fields. The cause is failing to bind the corresponding `formInput` data source field, or the field format does not meet drawing requirements.

## How to confirm configurations are correct
- Submit a test form. Check if unit validation errors are triggered. Verify that fields bound to `formInput` return correct corresponding data.
- Select batch options from `userSelect`. Confirm that the dropdown options match the approved batch list in the MES system.
- Trigger a variable reference operation. Check if a `quote type error` pop-up appears. Verify that the strict format validation rule is active.
- Configure a custom channel. Initiate a test call. Confirm that the return result is normal, with no `500` status code errors.
