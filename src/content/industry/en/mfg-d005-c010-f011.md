# Bid Document and Quotation Preparation for Medical Device Assembly and Clean Production: Forms and Interactions

## What the data for this category looks like
Data for this category comes from design history files, device and material batch records, MES systems, clean environment monitoring equipment, sterilization equipment, and inspection and calibration systems.
Daily documents include production process specifications, batch production records, clean zone operation records, sterilization batch records, inspection reports, software version records, adverse event and traceability materials.
Data is updated once per product batch or device. Environmental-related parameters are updated regularly per the clean environment monitoring plan.
Data fields include device unique identifiers, material batch numbers, clean environment parameters, sterilization parameters, software version numbers, and traceability associated information.

## Constraints on forms and interactions from these characteristics
This category’s data has high dynamism and strict association requirements, creating multiple constraints for the forms and interactions link.
Parameters differ for each product batch, so the form must dynamically load real-time batch data and avoid fixed static options.
Fields such as device unique identifiers and material batch numbers must link to the traceability system. The form must verify logical consistency between fields. For example, sterilization parameters must match batch record data.
Professional parameters such as clean environment differential pressure and sterilization temperature must use limited valid value ranges to reduce manual input errors.
Multi-source data synchronization requires the form to support cross-system data pulling, ensuring filled content matches production system data.

The following configurations are formulated for FastGPT v4.17.0.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` maximum input length | 800–1200 characters | Adapts to core fill content for single-batch production records |
| `userSelect` optional data source binding | Associate real-time interfaces with MES and sterilization equipment systems | Ensures drop-down options sync with actual production batch data |
| Single-load optional entry count | Top 20 entries | Prevents page loading lag caused by too many drop-down options |
| Form field verification and submission rules | Enable field logical verification, trigger submission only after all mandatory fields are completed | Matches production system parameter requirements and avoids invalid submissions |
| Form timeout configuration | Save timeout of 600 seconds, prompt popup displayed for 5 seconds | Adapts to waiting duration for multi-system data pulling and ensures operators can read the prompt |

## Three common mistakes
- Phenomenon: When filled production record content exceeds the limit, AI processing reports an error or truncates the content, and the interface displays the "input character limit exceeded" prompt. Cause: The maximum input length configuration of `formInput` is not adjusted. The default character limit is used, and it does not match the single-batch document length for this category.
- Phenomenon: After page zoom, form fields are misaligned or content disappears, and the published page cannot display normally. Cause: Responsive layout adaptation is not configured. Fixed pixel form container sizes are used, and display requirements for different zoom ratios are not compatible.
- Phenomenon: When querying multiple data sources, multiple target knowledge bases cannot be selected, and full production-related data cannot be pulled. Cause: The interaction logic for multi-data source selection is not configured. Only single data source selection is supported, which cannot cover the fill requirements for multi-system data.

## How to confirm the configuration is set correctly
- Manually fill in the core parameters of a single batch, trigger form verification, and confirm that the logical consistency prompt matches the professional parameter range.
- Adjust the page zoom ratio to confirm that the form container and field content are not misaligned or lost.
- Pull real-time production batch data to confirm that the drop-down options match the latest batch numbers in the MES system.
- Test submitting fill content that exceeds the default character length to confirm that the length limit of `formInput` has taken effect as configured.

The values provided are common starting points and should be measured against the reader's own samples.
