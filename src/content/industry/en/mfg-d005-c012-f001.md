# Bid Document and Quotation Preparation for Semiconductor Wafer Fabrication: HTTP Interfaces and External Systems

## What the Data for This Category Looks Like
Data for this category covers wafer fab process integration, equipment, yield, and manufacturing departments. Core data sources include MES systems, equipment FDC modules, defect detection and metrology tools, wafer maps, process recipe libraries, and experimental data. Daily documents include process flow cards, batch run records, equipment recipes, SPC charts, exception handling sheets, defect atlases, and yield reports.
Data updates proceed in sync with each wafer batch production run, real-time parameter collection, and daily summary reports. Fields include process parameters, yield values, defect location coordinates, and more. Common units include nanoscale parameters, batch numbers, timestamps, and similar items.

## What Constraints These Characteristics Impose on HTTP Interfaces and External Systems
Data for this category is scattered across multiple industrial systems. HTTP interfaces must connect to multiple data sources such as MES and equipment FDC modules, and support parallel pulling of multi-source data.
Data update rhythms include real-time and batch modes. Interfaces must adapt to both short-cycle polling and event-triggered invocation logic.
Fields vary significantly across different documents. `responseData` must be parsed in a structured way, categorized by process parameters, yield data, defect information, and other groups.
Bid document and quotation preparation must bind to precise batch information. `variables` must pass core variables such as batch numbers and process node parameters.
Industrial scenario network fluctuations require interfaces to include fault-tolerant mechanisms, to avoid full process disruption from a single failed call.

## Three Common Mistakes
- Phenomenon: The interface call returns a `401 Unauthorized` status code, or an authentication failure prompt appears during debugging. Cause: The `Authorization` parameter is not configured correctly, or the used API key is not granted access permissions for the corresponding wafer fab system.
- Phenomenon: Process parameters are missing or units are incorrect in the generated bid documents. Cause: `responseData` is not parsed by field category, and format verification is not performed for special fields such as nanoscale parameters and batch numbers.
- Phenomenon: The data pulled by the interface does not match the current production batch, and the generated quotation has a large deviation from the actual process. Cause: The invocation timing of real-time data and batch data is not distinguished, and the batch number passed in `variables` is not updated synchronously.

## How to Confirm the Configuration is Correct
- Call the test interface, check whether the `Authorization` parameter is correctly carried with the request, and confirm the returned authentication status is passed.
- Manually pass the test batch number as the `variables` parameter, verify whether the `responseData` returned by the interface includes the process data corresponding to this batch.
- Simulate industrial network fluctuations to trigger interface retries, confirm that the retry logic works normally and no duplicate data is pulled.
- Compare the original interface returned data with the generated bid document fragments, confirm that parameter and unit matching meets business requirements.
