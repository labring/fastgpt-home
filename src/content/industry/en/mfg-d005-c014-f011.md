# Bid Document and Quotation Preparation for Dyeing and Finishing: Forms and Interactions

## What the data for this category looks like
Data sources include customer color samples, formula libraries, dye auxiliaries batches, dye vat control equipment, colorimeters, setting machines, and environmental monitoring data. Update frequency is per vat, per batch, per shift. Daily documents include dyeing formulas, chemical weighing records, dye vat curves, proofing confirmation sheets, color difference reports, setting process sheets, and sewage ledgers. Fields include dye auxiliaries concentration, vat number, heating rate, holding time, color difference ΔE value, wastewater discharge indicators, and more. Units include g/L, ℃, min, mg/L, and others.

## Constraints on Forms and Interactions
High-frequency updated business data requires forms to support real-time synchronization of the latest dye auxiliaries batches, vat numbers, and other information. This prevents errors in bid documents and quotations caused by using expired data.
Differences in fields across multiple document types require forms to support dynamic loading of dedicated fields. For example, concentration fields for dyeing formulas and discharge indicator fields for sewage ledgers must be configured separately.
Precise parameters for wet chemical processing require forms to restrict input ranges. This ensures parameters such as heating rate and holding time match the adjustable ranges of dye vat equipment.
Environmentally related fields must be linked to compliance thresholds. This prevents input of non-compliant values that cause subsequent issues.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Form input box type | Text box + drop-down selection combination | Matches input requirements for multiple types of fields such as dyeing formulas and dye vat parameters |
| `formInput` validation rules | 0.1–10 ℃/min, 1–60 min, required | Ensures heating rate, holding time and other parameters meet equipment operating requirements |
| `userSelect` option data source | Bind local formula library and dye auxiliaries batch table | Quickly call standard data to reduce manual input errors |
| Global variable binding rules | Associate real-time business data per vat/per batch | Adapts to synchronization requirements for high-frequency updated business data |
| Copy function trigger configuration | Bind selected content in the conversation window | Adapts to the requirement of batch copying parameter tables in bid documents |
| Variable reference configuration | Support direct calling of numerical fields exported by colorimeters | Reduces manual entry errors |

## Three Common Configuration Mistakes
- Symptom: Global variables prompt empty input when debugging between nodes. Cause: Real-time business data per vat/per batch is not bound, only static global variables are configured.
- Symptom: Temperature parameters cannot be set when the AI chat component calls the large model. Cause: No custom input item for temperature parameters is added in the `userSelect` configuration, only the default variable reference method is used.
- Symptom: The copy button triggers without line breaks, and prompts require manual text selection. Cause: No Markdown format line break rules for copied content are configured, resulting in no paragraph separation for spliced parameter tables.

## How to Verify Successful Configuration
- Test the `formInput` validation rules, enter values outside the preset range, confirm that the corresponding error prompt pops up on the interface.
- Call the `userSelect` drop-down options, confirm that the data source automatically loads the latest dye auxiliaries batches and formula library data.
- Trigger the copy function, confirm that the generated Markdown content includes correct line break format and selected content.
- In FastGPT v4.17.0, test the transfer of global variables between nodes, confirm that there are no empty input error prompts.

The values provided here are common starting points and should be evaluated against the reader's own samples.
