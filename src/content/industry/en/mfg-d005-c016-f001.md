# Bid Document and Quotation Preparation for Transformer and High-Voltage Electrical Equipment Manufacturing: HTTP Interfaces and External Systems

## What the Data for This Use Case Looks Like
Data required for bid document and quotation preparation for transformer and high-voltage electrical equipment manufacturing comes from multiple sources: design BOM, silicon steel sheet and insulating material procurement data, vacuum drying equipment logs, insulating oil test reports, partial discharge and withstand voltage test records from high-voltage test stations, and product nameplate parameter tables.
Data is updated per product unit or per batch of raw materials.
Daily documents include winding and core assembly records, vacuum drying records, insulating oil reports, partial discharge and withstand voltage test reports, and nameplate parameter tables. Nameplate parameters must include fixed fields such as rated voltage, rated capacity, and insulation class. Test reports must include detection data such as partial discharge values and withstand voltage values.

## Constraints Imposed on HTTP Interfaces and External Systems
The data required for bid document and quotation preparation is updated per product unit or per batch of raw materials. This requires HTTP interfaces to support precise data retrieval by product serial number or batch number, to avoid redundant overhead from full synchronization.
Documents include multiple types of structured detection data, such as insulating oil moisture content, partial discharge values, and withstand voltage values. The interface must support field mapping rules to automatically map external system detection data to bid document filling variables.
Product failures carry serious consequences, so the interface must have strict permission verification configured. This prevents unauthorized access to or tampering of bid data.
Bid document preparation cycles are usually long. The interface must support reasonable timeout settings and retry mechanisms to avoid preparation interruptions from temporary network fluctuations.

## Configuration Settings
These configurations apply to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `Authorization` | Bearer enterprise-specific authentication key | Isolate access permissions for different bid projects, prevent unauthorized interface calls |
| `variables` | Map nameplate parameters and test data to bid filling variables | Automatically populate structured data into corresponding positions of bid documents |
| `responseData` | Extract response text and populated document content | Facilitate integration with downstream quotation systems or document storage systems |
| Authentication timeout | 600 seconds | Adapt to the long cycle of bid document preparation, avoid authentication failure mid-process |
| Encoding format | UTF-8 | Correctly handle test report file names and document content containing Chinese characters |
| Retry count | 3 times | Address temporary network fluctuations, avoid preparation interruptions caused by single failed call |

## Three Common Misconfigurations
- An interface call returns a `401 Unauthorized` error. The cause is that the `Authorization` parameter does not correctly carry the enterprise-specific authentication key, or the key is not granted access permissions for the bid document interface.
- Garbled file names appear when uploading test reports with Chinese names. The cause is that the HTTP request does not have the `Content-Type: application/json; charset=utf-8` request header configured.
- Voice output is abnormal when connecting to a custom TTS. The cause is that the response text returned by `responseData` is not correctly mapped to the input parameters of the TTS interface, leading to parameter format mismatch.

## How to Verify Proper Configuration
- Invoke the authentication interface using the configured `Authorization` parameter, and verify return of a valid access token.
- Upload an insulating oil report with a Chinese file name, and confirm the file name displays normally without garbled characters in the uploaded file list.
- Trigger the bid document generation process, and confirm the generated document automatically populates nameplate parameters and test data.
- Invoke the TTS connection interface using the response text returned by `responseData`, and confirm the voice output content matches the text.

The values provided are common starting points and should be measured against the reader's own samples.
