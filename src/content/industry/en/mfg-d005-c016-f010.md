# Tender Document and Quotation Preparation for Transformer and High-Voltage Electrical Equipment Manufacturing: Knowledge Base Retrieval and Recall

## What data for this category looks like
Data sources for this category include design BOM, silicon steel sheet and insulating material inventory logs, vacuum drying equipment logs, oil test reports, and high-voltage test station records. Data updates are performed per single product or per batch of raw materials. Daily documents include winding and core assembly records, vacuum drying records, insulating oil test reports, partial discharge and withstand voltage test reports, and nameplate parameter tables. Fields include insulating oil moisture content, partial discharge magnitude, withstand voltage value, rated capacity, and rated voltage, with corresponding units of μL/L, pC, kV, kVA, and kV.

## What constraints these characteristics impose on knowledge base retrieval and recall
This category’s data is updated per single product or per raw material batch. Knowledge base retrieval must accurately match identifiers such as product model and batch number to avoid recalling documents from unrelated batches. Daily documents include structured test reports and unstructured assembly records, so the retrieval logic must support multi-format content recall. Fields have dedicated units; retrieval must retain unit association rules to prevent confusion between content with the same name but different parameters. In tender scenarios, documents related to high-voltage tests and insulation parameters must be recalled first. Therefore, recall weights should be tilted toward test reports and insulating oil test records, while redundant equipment operation log content should be filtered out.

## How to set up the configuration
This guidance is written for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | This category’s parameters require precise matching to avoid recalling low-relevance insulation or test data, ensuring the accuracy of tender content |
| `limit` | `Top 8 entries` | Tender documents need to cover multi-dimensional test, assembly, and material data; 8 entries balances recall volume and context length |
| `searchMode` | `Full-text retrieval` | Must match both structured fields and unstructured text content to meet recall needs for multiple document types |
| `usingReRank` | `Enabled` | Relevance judgment for high-voltage test data requires higher precision; re-ranking filters incorrectly recalled low-relevance records |
| `datasetSearchUsingExtensionQuery` | `Enabled` | Tender scenarios need to expand matching of associated content such as product model-related batches and test reports to improve recall completeness |
| `collectionIds` | `Bind three dedicated collections: insulation tests, assembly records, and nameplate parameters` | Must isolate knowledge base content from other categories to avoid recalling irrelevant data that disrupts tender preparation |

## Three common errors
- Symptom: After uploading test reports or insulating oil reports in PPT format, the knowledge base only displays text without images. Cause: The image recognition switch for PPT content extraction is not enabled, or the image conversion URL is not bound to the corresponding document collection.
- Symptom: When attempting to add an insulating material data collection, the interface pops up a configuration failure prompt. Cause: The collection ID parameter format does not meet system requirements, or the current knowledge base does not have access permissions for the corresponding collection.
- Symptom: After entering a long query containing rated voltage and partial discharge magnitude, the search results do not prioritize returning high-voltage test reports. Cause: The `usingReRank` function is not enabled, or the `similarity` threshold is set unreasonably, leading to incorrect recall of irrelevant content.

## How to confirm the configuration is correct
- Upload the nameplate parameter table and withstand voltage test report for a single transformer, perform a retrieval query containing the corresponding model, and check whether the returned results include the target documents.
- Adjust the `similarity` parameter range, verify whether the relevance of the search results meets business requirements, and modify the threshold as needed.
- Enable image recall testing, upload an insulating oil report containing images, and confirm that the search results can associate image URLs and display them normally.
- View the knowledge base collection binding list, confirm that only the three target collections of insulation tests, assembly records, and nameplate parameters are included, with no redundant external collections.

The values provided here are common starting points and should be measured against the reader's own samples.
