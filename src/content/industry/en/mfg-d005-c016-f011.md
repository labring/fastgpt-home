# Bid Document and Quotation Preparation for Transformer and High-Voltage Electrical Equipment Manufacturing: Forms and Interactions

## What data for this category looks like
Data for this category comes from design BOM, silicon steel sheet and insulating material inventory data, vacuum drying equipment, oil test records, and test station test results. Updates are triggered once per product or per batch of materials. Daily associated documents include winding and core assembly records, vacuum drying records, insulating oil reports, partial discharge and withstand voltage test reports, and nameplate parameter tables. Most fields include professional units, such as MΩ for insulation resistance, pC for partial discharge values, and kV for withstand voltage. A unique identifier for a single device must be bound to enable full-link traceability.

## What constraints do these characteristics impose on forms and interactions
The data characteristics of this category impose multiple constraints on the forms and interactions process. The update rhythm per product or batch requires forms to bind a unique device number or batch identifier to prevent mixing data from different products. Fields with professional units require forms to preset unit suffixes or enforce format validation to avoid input errors for parameters such as insulation resistance and partial discharge values. Dispersed data from multiple sources requires forms to support quick cross-data-source association to reduce duplicate entry. The high potential cost of errors also requires forms to add required field validation and real-time format reminders to lower subsequent rework risks.

## How to configure the settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Form input component | Bind fields with units such as insulation resistance and partial discharge values, limit value ranges to 0–1000 MΩ, 0–1000 pC, 0–500 kV | Match the format and value range of professional data for this category |
| User selection component | Associate the single device number/batch number option pool | Correspond to the update frequency per device or batch to enable accurate data association |
| Field validation rules | Enable mandatory unit validation and required field validation, set timeout threshold to 30 seconds | Avoid parameter format errors, prevent extended unresponsiveness |
| Data source association configuration | Associate design BOM and test report data sources | Match the data source channels for this category, reduce manual entry |
| Input termination trigger | Automatically close input prompts after all required fields are filled | Meet interaction requirements when no further input is needed |
| Knowledge base reference configuration | Limit calls to only the test standards and material parameter knowledge base | Avoid irrelevant content interfering with bid document and quotation preparation |

## Three common mistakes
- Phenomenon: No selectable values appear in the interface when selecting knowledge base reference variables. Cause: Data sources exclusive to the transformer category such as test reports and nameplate parameters are not associated, resulting in no available variable pool.
- Phenomenon: An invalid parameter input prompt appears when starting code-sandbox. Cause: Mandatory unit validation is not configured for professional fields such as insulation resistance and withstand voltage, resulting in parameter format mismatch with system requirements.
- Phenomenon: The database connection node cannot accept port number input. Cause: The form input component does not enable numeric type adaptation, only allowing text input which prevents port numbers (numeric format) from being entered normally.

## How to confirm the configuration is complete
- Open the form editing page of FastGPT v4.17.0, check that the `formInput` component is bound to professional fields with units such as insulation resistance and partial discharge values.
- Test the `userSelect` component, confirm that single device numbers or batch numbers can be selected as association identifiers.
- Fill in all required fields, verify that the input prompt automatically closes after subsequent input.
- Attempt to reference knowledge base variables, confirm that knowledge base content related to test standards and material parameters can be called.
