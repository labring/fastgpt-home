# Bid Document and Quotation Preparation for Plastic Injection Molding: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Typical entities in this category are enterprises producing automotive interior, home appliance, and medical plastic parts. Daily documents include injection molding process cards, raw material drying records, mold histories, first-piece inspection reports, patrol inspection forms, and material change and machine cleaning records.
Data sources include resin batch and property sheets, injection molding machine parameters, mold temperature machines, MES systems, and dimensional and appearance inspection results.
Data is updated every time a batch of raw materials arrives, each mold or material change is completed, and after each shift’s patrol inspection.
Document fields include melting temperature (℃), holding pressure (MPa), drying temperature (℃), and other parameters with clear units. Single document content length varies widely. It includes both tabular parameter lists and procedural operation records.

## What constraints these characteristics impose on knowledge base retrieval and recall
High-frequency, node-specific updates require the knowledge base to support incremental sync triggered by batches, mold changes, or material changes. This prevents retrieval of outdated process or raw material data.
Diverse document types and precise parameters with units require retrieval to support both semantic matching and keyword matching. This avoids errors where parameter units do not match.
High data correlation exists—for example, mold histories are strongly bound to injection molding process cards. Retrieval must associate related document entries. Returning only isolated single pieces of content does not meet requirements.
Bid documents must cover multiple dimensions including processes, raw materials, and molds. Retrieval results must be kept within a reasonable range. Exceeding context carrying limits reduces preparation accuracy.

## How to set up the configuration
This configuration is based on FastGPT v4.17.0. Specific parameter settings are as follows:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | Plastic injection molding has high requirements for parameter accuracy. Low-match irrelevant content must be filtered to avoid mixing unrelated process records into bid documents |
| `limit` | `Top 6–8 entries` | Bid documents must cover multiple dimensions including processes, raw materials, and molds. Too many results will exceed context length limits. Too few results will miss critical parameters |
| `searchMode` | `Hybrid vector and keyword search` | There are both precise parameter queries such as "PP material drying temperature" and semantic queries such as "meet the appearance requirements of automotive interior injection molding". Hybrid search balances accuracy and coverage |
| `usingReRank` | `Enabled` | Injection molding documents have strong correlation. Reranking surfaces high-match content such as process cards and mold histories ahead of other results, improving preparation efficiency |
| `datasetSearchUsingExtensionQuery` | `Enabled` | Bid queries usually imply specific scenario requirements. For example, "medical plastic part quotation" implies aseptic production requirements. Extended queries cover more relevant documents |
| `collectionIds` | `Bound to the dedicated knowledge base collection for injection molding` | Avoid retrieving documents from other categories such as rubber vulcanization process data. Ensure retrieved content is only related to plastic injection molding |

## Three common mistakes
- Phenomenon: When uploading a single injection molding process card to the knowledge base, it shows readiness in 8 segments, then later changes to 13 segments with duplicate indexed entries. Cause: No document deduplication rule is configured. The unique document identifier is not associated during chunking, leading to the same document being split and indexed multiple times.
- Phenomenon: Retrieval results include process content unrelated to plastic injection molding, such as rubber vulcanization cross-linking step descriptions. Cause: No dedicated collectionIds are bound. The retrieval scope covers knowledge base collections from other categories.
- Phenomenon: Retrieved raw material parameters do not match the resin model for the current bid batch. Cause: No document metadata-based filtering is enabled. The retrieval scope is not limited by fields such as resin batch and mold ID, leading to retrieval of parameter data from other batches.

## How to confirm the configuration is correct
- Upload an injection molding process card, check the number of chunks after indexing, confirm there are no duplicate entries. This verifies that the deduplication configuration is active.
- Launch a query including "PP material drying temperature", check if retrieval results prioritize drying records for the corresponding raw material. This verifies that the `usingReRank` and `similarity` configurations are active.
- Check the binding relationship of the knowledge base collection, confirm it only includes documents related to plastic injection molding. This verifies that the `collectionIds` configuration is active.
- Upload a latest material change and machine cleaning record, launch a query including "material change and machine cleaning requirements", confirm the result includes the newly uploaded document. This verifies that the incremental sync configuration is active.

The values provided here are common starting points, and should be evaluated against the reader’s own samples.
