# Tender Document and Quotation Preparation for Furniture and Wood Products Manufacturing: Forms and Interactions

## What the data for this category looks like
Core data for this category comes from order design systems, sheet material and wood batch ledgers, CNC cutting/drilling equipment logs, ERP/MES systems, and on-site moisture content test records. Data update rhythms adjust synchronously with order generation, daily batch inventory checks, and each batch of materials arriving on site. Daily associated production documents include personalized cutting drawings, cutting lists, edge banding and drilling programs, coating process cards, hardware material lists, trial assembly and packaging records. Core fields include panel length, width and height dimensions, base material type, color code, hardware model, and panel moisture content. Common units are millimeters, batch numbers, and percentages.

## What constraints these characteristics impose on forms and interactions
This category is driven primarily by custom orders. Each order has a large number of panels and relies on on-site spatial dimension adjustments. Forms must support multi-item bulk entry and dynamic addition of custom fields. Data sources are scattered and update frequently. Interaction links must support cross-system data pulling and real-time verification to avoid manual entry errors. Core fields such as panel dimensions and moisture content must match production equipment’s parameter ranges. Form interactions must restrict invalid input. Tender documents must also be associated with specific cutting documents and hardware lists. Interaction links must support quick mounting of corresponding files, and adapt to preview and reference of multi-format documents.

## How to set up configurations
The following configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `formInput` | Configure input verification rules for panel dimensions, moisture content, and hardware models, calibrated based on actual measurements | Must match production equipment parameter thresholds to avoid errors in subsequent production links caused by invalid input |
| `userSelect` | Bind data sources for sheet material batches and hardware material lists from ERP/MES systems | Ensure tender quotation references match actual production inventory and batch information, avoiding deviations between quotations and actual costs |
| Bulk import configuration | Support CSV format import for cutting lists and hardware list data | Each order has a large number of panels. Bulk import reduces manual entry workload and improves data accuracy |
| Document mounting limit | Top 20 items | The number of production documents associated with tender documents is limited. Excessive mounting will affect page loading speed and browsing experience |
| Real-time verification trigger | Trigger verification after input is completed | Immediately feedback input errors, avoid rework in subsequent links, and improve tender document preparation efficiency |

## Three common errors
- Phenomenon: When configuring the `userSelect` data source, cutting document entries in the knowledge base cannot be selected. Cause: The knowledge base is not bound to the current form interaction’s data source configuration item, or the knowledge base has not synchronized the latest production documents.
- Phenomenon: After form submission, a prompt indicates no knowledge base is selected, and associated production documents cannot be mounted. Cause: The production document knowledge base for the corresponding category is not pre-bound in the interaction link, or the knowledge base access permissions are not enabled.
- Phenomenon: When using `formInput` to configure field verification, an error is triggered even when valid custom panel dimensions are entered. Cause: The verification rule’s range setting does not cover the dimension range of custom panels, or the unit conversion logic does not adapt to conversions between millimeters and other commonly used units.

## How to confirm the configuration is complete
- Manually enter fields such as panel dimensions and moisture content, check whether input prompts matching production parameters are triggered, and adjust verification rules to fit the business scenario.
- Attempt to bind the ERP/MES data source, check whether optional sheet material batch and hardware list items can be pulled, and confirm the data source configuration takes effect.
- Upload a test cutting list CSV file, confirm the bulk import function can correctly parse and load data items.
- Mount no more than 20 production documents, check whether page loading and preview work normally, and adjust the mounting limit to meet business needs.

The values provided here are common starting points and should be measured against the reader's own samples.
