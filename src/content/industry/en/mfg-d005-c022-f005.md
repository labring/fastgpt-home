# Bid Document and Quotation Preparation for Complete Household Appliance Manufacturing: Tool Calling and Plugins

## Data for This Category
Core data for this category covers end-to-end production for air conditioners, refrigerators, washing machines and small household appliance complete units. Daily documents include bill of materials (BOM), assembly work instructions, refrigerant charging records, electrical safety test reports, performance spot check reports and repair records. Data sources include ERP/MES systems, component batch ledgers, tightening and charging equipment logs, safety compliance tester data, performance laboratory test results and after-sales fault archives. Data updates are performed per individual product, shift production batch and fixed spot check schedules.

## Constraints for Tool Calling and Plugin Workflows
Bid document and quotation preparation for complete household appliance manufacturing requires linking multi-dimensional production compliance data. Tool calling must directly connect to ERP BOM data, safety compliance test results and after-sales repair records. Real-time data updates for individual products require tool calling to support low-latency synchronization, to avoid quotation deviations caused by delayed data. Plugins must support filtering data sources by product model for parallel processing of multiple models in mixed-line production, to prevent parameter confusion across different categories. Compliance checks for bid documents require automatic matching of mandatory requirements after tool calling, with pre-configured data validation rules to ensure alignment with safety compliance and performance standards for household appliance products.

## Common Configuration Errors
- Calling proprietary system interfaces prompts `Error: write EPROT`. The cause is that correct HTTPS certificate trust rules are not configured in FastGPT, leading to interface handshake failure.
- Attempting to connect to the openrouter qwen next thinking model results in failed calls. The cause is that the model's interface address and key are not correctly filled in the plugin configuration, and `functionCall` is not enabled to adapt to the model's tool calling capabilities.
- Configuring an Oracle database connection plugin fails to read data. The cause is that whitelist permissions for database access are not configured, or field mapping does not match the BOM and spot check report fields for complete household appliances.

## How to Verify Successful Configuration
- Trigger a simulated bid project tool call, check that returned data sources only include data for the specified complete household appliance model.
- Review tool call logs, confirm that interface request and response formats follow preset rules, with no timeout or error messages.
- Generate a test bid document, verify that quoted data and safety compliance test results match original data exported from ERP.
- Test trigger conditions for different categories, confirm that plugins only start under matching bid project types, avoiding cross-category data interference.
