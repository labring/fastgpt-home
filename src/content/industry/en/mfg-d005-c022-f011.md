# Bid Document and Quotation Preparation for Complete Home Appliance Manufacturing: Forms and Interactions

## What the Data for This Category Looks Like
Business data for complete home appliance manufacturing covers categories such as air conditioners, refrigerators, washing machines, and small home appliances. Daily business documents include configuration BOMs, assembly work instructions, refrigerant charging records, electrical safety test reports, performance spot check reports, and rework records. Data sources include ERP/MES systems, parts batch ledgers, tightening and charging equipment, safety compliance testers, performance laboratory data, and after-sales fault records. Update cycles are executed per single product, per shift production batch, or per spot check plan.

## Constraints Imposed on Forms and Interactions
The mixed-line production of multiple product categories for complete home appliance manufacturing requires the form interaction link to support dynamic loading of exclusive parameter items for the corresponding product model, to avoid errors caused by mixed filling of multiple models. The high-frequency data update cycle per single product or per shift requires the interaction link to support real-time verification of the matching degree between input data and corresponding batch production records. Highly compliant safety and performance inspection document fields must be bound to output fields from safety compliance testers and performance laboratories, to reduce manual entry errors. The requirement for bid quotations to be associated with BOM and parts costs requires forms to link to material ledger data from the ERP system, to ensure the accuracy of quotation data.

## Configuration Guidelines
The configuration on this page applies to FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `formInput` | Enable batch number automatic verification, match the batch code format of ERP/MES systems | Corresponds to the high-frequency update requirements of parts batches and production records, ensures that entered data matches actual production batches |
| `userSelect` | Dynamically load optional parameter items by product model, pre-select the current bid model | Adapts to mixed-line production scenarios for multiple categories, avoids errors caused by mixed filling of multiple models |
| `userSelect` | Limit the number of selected parts categories to the top 10 per single selection | Prevents irrelevant materials from being included in bid documents, narrows the scope of quotation items |
| Form field linkage | Bind the test result fields of safety compliance test reports | Ensures that the quotation link is associated with compliance data, avoids risks of non-compliant safety standards |
| Global variable assignment | Dynamically link parts cost data from the selected knowledge base | Meets the real-time cost accounting requirements for bid quotations |
| `formInput` | Set the input character limit to 800–1200 characters | Adapts to the standard entry length of documents such as assembly work instructions and charging records, avoids content overflow |

## Three Common Misconfigurations
- Symptom: The `userSelect` dropdown list for selecting AI models or knowledge bases is empty, and no corresponding options can be chosen. Cause: Dynamic option loading rules for the corresponding category are not configured, and data sources from ERP or knowledge bases are not bound.
- Symptom: Document reference content is still returned when document reference configuration is not enabled. Cause: Form field linkage rules are mistakenly bound to unauthorized knowledge base data, or the global variable assignment logic does not verify the reference switch status.
- Symptom: The batch number entered in the bid quotation form cannot match production records. Cause: The verification rule for `formInput` does not adapt to the batch code format of ERP/MES systems, resulting in automatic verification failure.

## How to Verify Successful Configuration
- Manually enter the batch number of the corresponding model, check whether the verification prompt matching the ERP/MES batch records is triggered.
- Switch the bid model, check whether the `userSelect` component loads exclusive parameter options for the corresponding category.
- Turn off the document reference switch, submit a test form and confirm that unauthorized document content is not returned.
- Enter content that exceeds the conventional document length, check whether the preset input length limit is triggered.
