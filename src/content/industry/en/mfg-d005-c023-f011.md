# Bid Document and Quotation Preparation for Industrial Instrument Manufacturing and Calibration: Forms and Interactions

## What Data for This Category Looks Like
This category's data comes from flow, pressure, temperature, and analytical instrument manufacturers and metrology laboratories. Daily documents include assembly and commissioning sheets, calibration procedures, original calibration records, error curves, metrology certificates, and software version records. Data sources cover design documents, standard instruments and environmental monitoring data, calibration software, laboratory information systems, and customer range requirements. The update frequency is once per calibration per device. Data fields include fixed traceability numbers, range parameters, error values, environmental monitoring data, and more. Supporting units are mostly metrology-specific units such as m³/h, kPa, ℃.

## Constraints Imposed on Forms and Interactions
Data sources are scattered and mostly generated in real time during calibration, so forms must support quick binding to multiple data sources. Each calibration of a single device updates data, so forms must adapt to dynamically generated fields and unit validation rules. Document types are diverse and have strict field requirements, so forms must display content in blocks according to business links. Metrological review and certificate validity are directly linked to the accuracy of form data, so mandatory validation and review node interactions must be configured. Time-consuming links involving multi-point collection and error calculation require forms to preset standardized templates to reduce repeated data entry.

## Three Common Mistakes
- A node runtime prompt states that global variable input is empty. The symptom is that the debug panel shows an empty string for the variable value. The cause is that the variable is only declared in the global configuration, not bound to the data source of the `formInput` component, and not linked to actual business fields.
- The AI chat component has no temperature setting button when selecting variable references. The symptom is that the temperature adjustment entry is not displayed in the large model call parameter panel. The cause is that the advanced parameter configuration switch is not enabled, and custom parameter display is not activated.
- Clicking the copy button prompts that copying failed, and the generated Markdown content has no line breaks. The symptom is that a manual copy selection window pops up, and the output content does not retain paragraph line breaks. The cause is that the Markdown format retention configuration of the copy component is not enabled, and line break conversion is not activated.

## How to Confirm Configuration is Complete
- Check whether the `formInput` component is bound to fixed fields such as calibration certificate number and error value, and that the unit validation rules are in effect.
- Test whether the options of the `userSelect` component include optional content such as standard instrument model and metrology qualification, and that the default selected items meet business requirements.
- Submit calibration test data for a single device, check whether global variables can be correctly passed to subsequent nodes, and there are no empty input error messages.
- Click the copy button, verify that the generated Markdown content has line breaks, and that the copy function triggers normally.

The values given are common starting points and should be measured against the reader's own samples.
