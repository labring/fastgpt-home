# Bid Document and Quotation Preparation for Mold Design and Manufacturing: Tool Calling and Plugins

## What the Data for This Category Looks Like
Data for this category comes from customer product models, mold flow or forming simulation results, CAD/CAM files, machining and measurement data, and trial mold samples. Daily generated documents include mold design task sheets, DFM reports, part drawings, machining process cards, trial mold reports, mold modification notices, and mold history records. Data updates are triggered by project milestones, and are synchronized after each trial mold or mold modification. Data fields include the number of mold cavities, material grade, machining tolerance, trial mold times, man-hour quotas, and most use common industrial units such as millimeters, megapascals, and hours.

## What Constraints These Characteristics Impose on Tool Calling and Plugins
This category’s data types include structured documents, large-volume CAD files, and simulation analysis results, which place requirements on the file parsing capabilities of tool calling. Data update frequency adjusts dynamically with trial mold and mold modification actions, requiring plugins to pull the latest project data in real time to avoid using outdated process parameters or man-hour data. There are many specialized fields and industrial unit specifications, so tool calling must accurately match the specific fields required for bid documents. Complete quotation basis cannot be obtained through generalized extraction. Additionally, the delay risk associated with mold projects requires the tool calling process to have rapid feedback capabilities, ensuring the timeliness of quotation preparation.

## Configuration Settings
This configuration is formulated based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `toolChoice` | Specify custom tools | Bid documents need to call mold design and manufacturing-specific cost accounting and process parameter query tools to meet the professional data needs of this category |
| `functionCall` | Force tool call triggering | Core quotation fields such as the number of mold cavities and material usage must be extracted from CAD files and simulation reports to ensure data accurately matches bid requirements |
| Tool call timeout duration | 1200 seconds | Mold CAD files and simulation reports take a long time to load, so sufficient time must be reserved for data parsing and extraction |
| Tool return field filtering | Only retain mold materials, machining man-hours, and trial mold times | Bid documents only require fields related to core quotations to avoid redundant information interfering with AI-generated content |
| Context window size | 8000–12000 token | Document content such as part drawings and DFM reports must be fully loaded to ensure complete project context is available during tool calls |
| Tool call retry count | 3 times | Respond to temporary network fluctuations during mold data loading |
| File upload size limit | 1000 MB | Adapt to the upload requirements of large CAD assembly files |

## Three Common Mistakes in Configuration
- Phenomenon: The platform interface does not display tool call logs. Cause: The global tool call log switch is not enabled, or the configured custom tool does not enable the log reporting function.
- Phenomenon: The generated bid document lacks the mold machining tolerance field. Cause: The rule for extracting this field is not specified in `functionCall`, causing the tool to not return corresponding data.
- Phenomenon: The uploaded CAD file cannot be synchronized to the tool call parameters. Cause: The file-type tool input parameter mapping is not configured, causing the uploaded project files to not be correctly bound to the quotation calculation tool.

## How to Verify Correct Configuration
- Initiate a simulated bid quotation request, and check whether the tool call is triggered and returns mold-related cost and man-hour data.
- View the platform's tool call log panel to confirm that each call has complete request and return records.
- Upload a test CAD part drawing to verify whether the tool can correctly extract fields such as the number of mold cavities and machining tolerance.
- Check whether the AI-generated bid document marks the data source, such as "Data from this uploaded part drawing".

The configuration values provided here are common starting points, and should be evaluated against the reader's own samples.
