# Bid Document and Quotation Preparation for Mold Design and Manufacturing: Forms and Interactions

## What the data for this category looks like
Typical entities include injection molding, stamping, and die-casting mold enterprises, as well as mold centers of manufacturing enterprises. Daily documents include mold design task sheets, DFM reports, part drawings, machining process cards, mold trial reports, mold modification notices, and mold history records. Data is sourced from customer product models, mold flow or forming simulation results, CAD/CAM files, machining and measurement data, and mold trial samples. It is updated per individual project cycle, and synchronized after each mold trial or modification. Fields include the number of mold cavities, material grade, machining tolerance, number of mold trials, and more, with corresponding units such as millimeters, megapascals, hours, and others.

## What constraints do these characteristics impose on the forms and interactions link
Data sources are dispersed and updated frequently, requiring forms to support multi-source data import and version tracking, to avoid duplicate entry of latest information after mold trials or modifications. Document structures are complex and fields have high standardization, requiring format verification for specific fields to ensure data in bid documents matches actual process parameters. Bid scenarios need to be linked to quotation calculation logic, form fields need to be linked to corresponding cost items, and historical mold history data must be quickly called to reduce duplicate query workload.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Bind mold material grade, cavity count, and machining tolerance fields, set a tolerance verification rule of `0.01–0.1 millimeters` | The category's documents include standardized tolerance requirements from part drawings, ensuring input data complies with process specifications |
| `userSelect` | Preset mold trial defect types and mold modification reason options, link to corresponding quotation adjustment items | Bid quotations need to dynamically calculate mold modification costs based on mold defects, and preset options reduce input errors |
| Global variable type | Set to knowledge base selection type, bind to the mold history knowledge base | Data sources include historical mold records, enabling quick access to bid data from similar projects |
| Configurator condition settings | Link to the option values of `userSelect`, trigger corresponding quotation calculation logic | Bid documents need to automatically adjust quotation items based on mold type and defect status, improving preparation efficiency |
| Form submission timeout | Set to 600 seconds | Avoid form submission interruptions caused by long waiting times |
| Knowledge base recall limit | Set to top 3 entries | Bid documents need to accurately match historical successful cases, and excessive recall results will distract users |

## Three Common Configuration Mistakes
- Phenomenon: After setting a global variable to the knowledge base selection type, the condition options for that variable cannot be loaded in the configurator interface. Cause: The global variable is not bound to the `formInput` or `userSelect` fields, so the configurator cannot obtain the valid value range of the variable.
- Phenomenon: The prompt for the user select plugin is displayed repeatedly in each conversation. Cause: The single prompt trigger rule is not configured, and the full conversation prompt mode is enabled by default.
- Phenomenon: Knowledge base recall results include documents unrelated to mold design, which interfere with quotation calculation. Cause: No classification tags are defined for knowledge base recall, resulting in mixed irrelevant business data.

## How to Verify a Correct Configuration
- Submit a test form, check whether the format verification of the `formInput` field takes effect, and whether inputs that do not meet the tolerance range are blocked.
- Select the mold trial defect option in `userSelect`, confirm whether the configurator triggers the corresponding quotation adjustment logic.
- View the knowledge base recall results, confirm that only documents related to mold design and manufacturing are returned.
- Submit the form multiple times, check whether the prompt information is only displayed during the first submission.

The values listed here are common starting points, and should be evaluated against the reader's own samples.
