# Bid Document and Quotation Preparation for Baking and Convenience Food: Workflow Orchestration

## What Data Looks Like for This Category
Typical entities include bakeries, pastry factories, cracker, instant noodle, and frozen pastry manufacturing plants. Daily documents include formulas and material lists, production records, baking or steaming curves, metal detection records, cleaning and disinfection records, and factory inspection reports.
Data sources cover raw and auxiliary material qualification certificates, ERP/MES systems, weighing systems, ovens or frying lines, laboratory equipment, and food traceability ledgers. Update frequency is per batch, per shift, or daily.
Document fields include material dosage, baking duration, allergen labeling, packaging date, shelf life, and more. Units include kilograms, grams, minutes, dates, and more.

## Constraints Imposed on Workflow Orchestration by These Characteristics
This category has high data update frequency and large per-batch document content. This can easily cause workflow context to exceed processing limits, so input length must be controlled specifically.
At the same time, allergen and cleaning switching happens frequently. This requires linking allergen data and cleaning record verification links in the workflow to avoid mislabeling risks.
Multi-source data is scattered across different systems. Workflow nodes must integrate fields from each data source to ensure information consistency in bid documents and quotations.
In addition, frequent product line changes require the workflow to quickly adapt to changes in different formulas and production parameters.

## How to Configure the Workflow
This configuration is based on FastGPT v4.17.0. Specific settings are as follows:
| Configuration Item | Recommended Approach | Rationale |
|---|---|---|
| Variable auto-update trigger | Trigger on `variables` change | Adapt to per-batch and per-shift data update frequency, ensure real-time synchronization of bid quotation data |
| Single-process context length | 800–1200 characters | Match the document length of single-batch formulas and production records, avoid exceeding AI context limits |
| Node call count statistics | Count by `nodeId` | Track call status of core nodes such as allergen verification and formula review, facilitate process optimization |
| Image to base64 script timeout threshold | 60 seconds | Adapt to the conventional size of production record images, avoid process interruptions caused by long waiting times |
| Maximum retry count | 2 times | Balance process stability and resource consumption, handle temporary data reading failures |

## Three Common Configuration Errors
- Phenomenon: The `variables` field is not automatically updated, resulting in inconsistent bid data and actual production parameters. Cause: The variable update trigger is not set to trigger on data source changes, only manual trigger is configured.
- Phenomenon: Workflow execution times out, returning a context length exceeded prompt. Cause: The single-process context length is not limited, and multi-batch production records and baking curves are imported, exceeding the AI processing limit.
- Phenomenon: The base64-encoded image is not correctly passed to the AI node, causing the AI to fail to recognize the input content. Cause: No parameter mapping is configured after the script node, and the base64 result is not bound to the `variables` field of the AI input.

## How to Verify the Configuration Is Correct
- Manually trigger a data update, check if the `variables` field has synchronized the latest material list and allergen data.
- Import a single-batch production record image, run the workflow, confirm that the base64 encoding is correctly generated and passed to the AI node.
- View the node call statistics panel, confirm that the call counts of core nodes classified by `nodeId` are normally counted.
- Simulate the process check before submitting a bid quotation, confirm that the automatic review links for allergens and shelf life are triggered.

The values provided are common starting points and should be measured against the reader's own samples.
