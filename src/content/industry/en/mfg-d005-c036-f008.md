# Bid Document and Quotation Preparation for Welded Structural Component Manufacturing: Document Parsing and Chunking

## What This Category of Data Looks Like
Daily documents for welded structural component manufacturing include welding procedure qualification records, welding procedure specifications, filler metal issue records, welder qualification records, weld inspection reports, and repair orders.
Data sources cover design drawings, material quality certificates, welding equipment parameters, filler metal warehouses, non-destructive testing systems, and personnel qualification ledgers.
Documents update per weld seam, per batch, or per shift. Most documents have fixed fields: weld number, base material grade, filler metal model, inspection date, welder certification number, and others. Units include millimeters, kilograms, hours, and other process and quality-related measurement standards.

## Constraints on Document Parsing and Chunking
Documents from multiple sources have large format differences. They include text-based PDFs and scanned image-based reports. The parsing link must adapt to multiple input forms.
Frequently updated documents need chunking rules that match business data granularity. This avoids splitting critical business groups.
Binding relationships between fixed fields, such as welder certification number and qualification level, require chunking to preserve field integrity.
Bulk bidding materials include multiple related documents. Support for large-volume file uploads and batch parsing is required. Without this, efficiency for bid document and quotation preparation decreases.

## How to Set the Configuration
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `chunkSize` | 800–1200 characters | Matches the length of single-process descriptions in welding procedure documents, avoiding splitting binding groups of base materials, filler metals, and process parameters |
| `chunkSplitter` | Separate by paragraphs + headings | Preserves the heading hierarchy of welding procedure qualification records and inspection reports, ensuring that key business fields are not split across chunks |
| `customPdfParse` | Enabled | Adapts OCR parsing for scanned non-destructive testing reports and repair orders, extracting text content from images |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 seconds | Addresses batch parsing of multiple documents associated with large welding drawings, avoiding parsing failures caused by insufficient default timeout duration |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | Accommodates packaged documents for entire batches of filler metal issue records, meeting the upload requirements for bulk bidding materials |
| `chunkSettingMode` | Manual configuration | Customizes chunking rules for the fixed field structure of welding documents, without using the default general mode |

## Three Common Mistakes
- Parsing results are empty after uploading a scanned weld inspection report. The cause is that the `customPdfParse` configuration is not enabled, and OCR recognition of inspection data within the image is not triggered.
- The platform returns a timeout error after bulk uploading multiple welding procedure specifications. The cause is that `PARSE_FILE_TIMEOUT_SECONDS` is not adjusted to above 600 seconds; the default timeout duration is insufficient to process large associated documents.
- Welder qualification record certification numbers and qualification levels are split into different chunks after chunking. The cause is that `chunkSplitter` is configured to separate by characters, not by paragraphs + headings, leading to breaks in critical binding fields.

## How to Verify the Configuration
- Upload a scanned welding procedure qualification record PDF, and check whether the parsing result includes OCR-recognized weld parameter text content.
- Upload a single 100MB packaged document of filler metal issue records, and confirm that the parsing process does not trigger a timeout prompt.
- Manually split a welding procedure specification document, and compare whether the parsed chunking results retain complete groups of process parameters.
- Check whether `UPLOAD_FILE_MAX_SIZE` in the system settings matches the maximum volume requirement for business upload documents.

The values provided are common starting points and should be measured against the reader's own samples.
