# Bid Document and Quotation Preparation for Welded Structural Component Manufacturing: Deployment and Upgrade

## What Data for This Category Looks Like
Data related to bidding and quotation for welded structural component manufacturing comes from design drawings, material quality certificates, welding equipment parameters, filler metal inventories, non-destructive testing systems, and personnel qualification ledgers. Common daily documents include welding procedure qualifications, welding procedure specifications, filler metal consumption records, welder qualification records, weld inspection reports, and repair work orders.
Data is updated once per weld, per batch of workpieces, or per shift. Fields include weld number, base material grade, filler metal model, welder qualification level, non-destructive testing results, and corresponding identifiers such as base material grade, filler metal weight unit, and test judgment results. All data must comply with rigid qualification and process constraints.

## What Constraints These Characteristics Impose During Deployment and Upgrade
Data sources for this category are scattered, and update frequency is high. High-frequency updates of weld, filler metal, and qualification data require sufficient database connection resources during deployment, to avoid connection pool exhaustion.
Daily documents contain a large number of professional terms and rigid constraint fields. Deployment must support loading and matching of professional term libraries to ensure professional accuracy of bid documents.
For intranet deployment scenarios, most data sources are internal systems. Proxy parameters with permission verification must be configured. Multi-data source connection logic must also be adapted to ensure real-time performance and accuracy of data referenced in bid documents.
Deployment configuration for FastGPT v4.17.0 must be adjusted specifically to match the data characteristics of this category.

## How to Set Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `DB_MAX_LINK` | 10–20 connections | Adapt to concurrent connection demands of high-frequency updated weld and filler metal consumption data, avoid database connection pool exhaustion |
| `MONGODB_URI` | Intranet MongoDB instance address with read-write authentication parameters | Store unstructured document data such as welding procedure qualifications and non-destructive testing reports |
| `PG_URL` | Intranet PostgreSQL instance address with read-write authentication parameters | Store structured business data such as welder qualification ledgers and weld inspection reports |
| `REDIS_URL` | Local Redis service address, port 6379 | Cache frequently called welder qualification and filler metal inventory data to reduce access pressure on the primary database |
| `STORAGE_S3_ENDPOINT` | Intranet object storage endpoint address | Store large-volume documents such as welding procedure specifications and repair work orders, ensure document access stability |
| `FILE_TOKEN_KEY` | 32-bit randomly generated custom string | Encrypt document access tokens, prevent unauthorized personnel from accessing confidential process documents related to bids |

## Three Common Mistakes
- Symptom: `Cannot read properties of undefined (reading 'incl')` error occurs after starting the workflow. Cause: `PG_URL` is not correctly configured to point to welding process-related structured data, causing the system to fail to read core fields such as weld number and base material grade.
- Symptom: External professional term library cannot be accessed during intranet deployment, and proxy configuration does not take effect. Cause: Only proxy IP and port are configured, but username and password parameters are not added, so intranet to extranet permission verification cannot be completed.
- Symptom: Professional term matching rate is low, such as filler metal model and welder qualification level cannot be correctly identified. Cause: No professional term library tailored for welded structural components is configured, and a general term library cannot match industry-specific fields.

## How to Confirm Configuration Is Correct
- Check the database connection pool monitoring panel to confirm that active connections do not exceed the configured `DB_MAX_LINK` value.
- Upload a welding procedure qualification report to verify that the system can correctly parse fields such as filler metal model and base material grade.
- After configuring a proxy with a username and password, attempt to access the external professional term library to confirm that updated content can be normally pulled.
- Generate a test bid document to confirm that referenced welder qualification and filler metal inventory data match internal ledgers.
