# Tender Document and Quotation Preparation for Production Planning and Workshop Scheduling: Forms and Interactions

## Data profile for this category
This category’s data originates from ERP orders and inventory, BOM lists, process routes, equipment capacity ledgers, staff shift schedules, work-in-progress ledgers, and supplier delivery records. Daily processed documents include sales orders, master production plans, material requirement plans, weekly and daily scheduling sheets, production work orders, material shortage lists, and delivery change notices.
Data updates run on a daily or weekly schedule, or are triggered when orders are placed or abnormal events occur.
Core fields include order numbers, process man-hours, equipment load rates, and material inventory surpluses, with units such as hours, percentage, pieces, and other standard units.

## Constraints on forms and interactions
Dispersed data sources and inconsistent update triggers require forms to support batch import of multi-source data and real-time validation. Diverse document types need matching field mapping rules to avoid cross-document field conflicts.
Updates triggered by orders or abnormalities require forms to dynamically load the latest data, preventing expired information from being used to prepare tender documents.
Core fields have strict unit and precision requirements. Forms must include preset unit options to reduce manual input errors.
Tender quotations must link to equipment capacity and material inventory. Forms must display linked data interactively to ensure quotations align with actual production capacity.

## Configuration guidelines
The following configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Batch import limit | 50 documents per single import | Matches the batch work order data volume exported from ERP, to avoid import timeouts |
| `formInput` validation rules | Mandatory validation for required fields (order number, planned duration) | Ensures core production planning information for tender documents is complete |
| `userSelect` data source | Linked to ERP inventory and equipment capacity ledgers | Automatically pulls the latest production resource data to reduce manual entry |
| Form field unit presets | Match corresponding units by document type (hours, pieces, percentage) | Aligns with the field unit specifications for this category's data, reducing input errors |
| Timeout threshold | 600 seconds | Adapts to the time required for multi-source data pulling and verification, avoiding interruption of the preparation process |

## Three common configuration mistakes
- Empty values or formatting errors in form fields. This occurs when required field validation rules are not configured, leading to missing core production planning information in tender documents.
- Frequent refreshing and jumping of resource selection options in forms. This occurs when no fixed data source refresh trigger timing is set, creating conflicts between data pulling and form interactions.
- Workflows allowing subsequent operations before form submission is complete. This occurs when workflow nodes triggered by form submission are not configured, allowing incomplete scheduling data to be used for quotation preparation.

## How to verify correct configuration
- Upload test documents for this category, confirm the form automatically maps core fields and uses preset units.
- Trigger a data source refresh, confirm the equipment capacity and inventory data loaded by the form matches the ERP ledgers.
- Test form interaction when required fields are left blank, confirm validation rules activate correctly.
- Simulate an abnormal order trigger, confirm the form dynamically updates scheduling and material data.
