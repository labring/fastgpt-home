# Bid Document and Quotation Preparation for Electric Motor and Generator Manufacturing: Vector Models and Indexing

## What Data for This Category Looks Like
Core data for this category comes from electromagnetic design systems, copper wire and insulation material batch ledgers, winding equipment, balancing machines, electrical test benches, and ERP/MES systems. Daily generated documents include winding process cards, insulation treatment records, dynamic balance reports, voltage withstand insulation test records, and type and factory test reports.
Data is updated once per motor or per product batch, with synchronized updates each time product type changes.
Documents contain specialized industrial fields such as number of turns, insulation class, test voltage, and temperature rise values. They do not use the standardized format framework of general office documents.

## Constraints Imposed on Vector Models and Indexing
This category has high data update frequency, with close association between single batch data. Indexes must support incremental updates and batch associated retrieval.
The terminology system for specialized industrial fields differs significantly from general documents. Vector models must adapt to professional vocabulary for electromagnetism, insulation, and mechanical balancing.
Document formats vary across different files. Chunking strategies must balance the integrity of single-segment content and parameter association across documents.
Data association errors will directly lead to incorrect process parameter references in bid documents, causing subsequent production or operation accidents. Retrieval accuracy requirements are higher than general scenarios.

## How to Set Configurations
| Configuration Item | Recommended Range | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Adapts to the length of single-segment professional content in winding process cards and test reports |
| Overlap Length | 100–150 characters | Retains cross-chunk winding turn count and insulation parameter association information |
| Similarity Threshold | 0.75–0.85 | Filters low-match irrelevant test data to ensure retrieval accuracy |
| Single Search Limit | Top 8 results | Covers full-process test records and process documents for a single motor |
| `maxToken` | 4096 token | Adapts to long paragraph contexts of industrial documents, avoiding truncation of core parameters |
| `defaultToken` | Calibrated via actual measurements | Adapts to specialized term vector matching for different material batches |

## Three Common Mistakes
- Phenomenon: Irrelevant insulation treatment records appear in retrieval results, leading to incorrect insulation parameter references in bid documents. Cause: The similarity threshold is set too low, failing to filter low-match cross-batch data, causing confusion of professional parameters.
- Phenomenon: Index tasks remain in a waiting state for a long time. Background logs show chunking timeouts. Cause: The chunk length is set too large, exceeding the system's single-block processing capacity, with no adjustment made based on the single-segment content length of motor documents.
- Phenomenon: Vector retrieval returns empty result fields, making it impossible to extract winding turn count information. Cause: No index mapping was configured for the specialized fields of winding process cards, resulting in failure to correctly vectorize professional parameters.

## How to Confirm Proper Configuration
- Upload a single complete winding process card, check if the chunked text retains complete core fields such as turn count and insulation class.
- Initiate a retrieval request containing multiple fields from the same document chunk, confirm that the system returns the highest-match professional parameter results according to field priority.
- View index task logs, confirm that the processing duration for a single document meets expectations, with no persistent timeout errors.
- In the FastGPT v4.17.0 index management interface, confirm that the vector model has been correctly bound to Ali-emb3, and the index fields include specialized industrial parameters.
