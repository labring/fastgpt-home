# Bid Document and Quotation Preparation for Electric Motor and Generator Manufacturing: Forms and Interactions

## What Data for This Category Looks Like
Data for this category originates from electromagnetic design data, copper wire and insulation material batch records, winding equipment, balancing machines, electrical test benches, and ERP/MES systems. Updates occur per individual product, per product batch, or each time a type modification is made.
Daily documents include winding process cards, insulation treatment records, dynamic balancing reports, voltage withstand insulation test records, and type and factory inspection reports. Fields include winding turns, insulation thickness, dynamic balancing allowance, voltage withstand value, and more, with corresponding units of turns, millimeters, grams, kilovolts, and similar units.

## Constraints on Forms and Interactions
The data characteristics of this category create multiple constraints for the forms and interactions workflow.
First, data updates are tied to individual products or batches. Forms must support associating multiple sets of structured data by batch to eliminate manual duplicate entry.
Second, the workflow involves multiple types of professional test records. Form fields must match professional parameters for electromagnetism, insulation, and mechanical balancing. A block-based form structure is required.
Third, data sources span multiple devices and systems. The interaction workflow must support batch import of external test data. Field verification logic must be added to block abnormal input for parameters such as winding turns and voltage withstand values.

## How to Set Up the Configuration
This configuration is built for FastGPT v4.17.0, customized for the bidding scenario of electric motor and generator manufacturing:

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `formInput` | Bind fields in blocks according to business documents | Match structured fields of winding process cards and test reports to improve entry efficiency |
| `userSelect` | Preset batch number and equipment number options | Associate batch data from ERP/MES to reduce manual input errors |
| `formInput` | Enable field range verification | Match reasonable parameter ranges from electromagnetic design, such as 80–120 winding turns, 0.2–0.5 millimeters insulation thickness |
| Batch Import Configuration | Support uploading CSV format templates | Adapt to the update frequency per batch or per individual product to quickly import test data |
| Timeout Setting | 600 seconds | Adapt to the time consumption of pulling data from multiple devices to avoid mid-process interruptions |
| Data Association Rules | Automatically associate material data for the corresponding batch | Match records of copper wire and insulation material batches to simplify quotation preparation logic |

## Three Common Mistakes
- Phenomenon: Domestic large models such as Tongyi Qianwen cannot be selected, and no matching options appear in the interface drop-down list. Cause: The API access channel or key information for domestic large models has not been configured.
- Phenomenon: No associated test data loads after form submission, and fields remain empty. Cause: `formInput` and the ERP/MES data source interface have not been correctly bound.
- Phenomenon: A field mismatch prompt appears during batch import of test data. Cause: The uploaded file does not follow the preset template's field order and naming rules.

## How to Confirm the Configuration Is Complete
- A new bidding form is created, the winding turns field for the target motor batch is selected, and automatic loading of electromagnetic design data from ERP is confirmed.
- A test data CSV file conforming to the preset format is uploaded, and automatic matching of form fields and generation of corresponding input boxes are confirmed.
- The insulation thickness field is modified beyond the reasonable range, and appearance of a parameter verification prompt is confirmed.
- A preset equipment number option is selected, and automatic loading of copper wire material data for the corresponding batch is confirmed.

The values provided are common starting points and should be measured against the reader's own samples.
