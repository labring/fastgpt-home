# Bid Document and Quotation Preparation for Batch Fine Chemical Synthesis: Knowledge Base Retrieval and Recall

## What Data Looks Like for This Category
The primary entities in batch fine chemical synthesis scenarios are enterprises producing coatings, resins, additives, agrochemical intermediates, and specialty chemicals. Daily generated documents include batch production instructions, feeding verification slips, reaction process records, cleaning records, inspection reports, and deviation and change orders. Data is sourced from formula and process libraries, raw material batches, reactor DCS systems, weighing systems, LIMS, and warehouse management systems. Updates occur once per production batch or each key process step. Documents include structured feeding parameters, reaction conditions, and batch information, alongside unstructured process descriptions and deviation handling records, as well as sensitive content related to formula confidentiality.

## Constraints on Knowledge Base Retrieval and Recall
Multi-source heterogeneous data sources require retrieval to support documents in various formats, and accurately match structured fields such as batch numbers and formula IDs. Frequent batch-based updates require the knowledge base to support incremental synchronization, avoiding delays caused by full retraining. The multi-variety, batch-switching production mode requires retrieval results to be linked to cleaning and feeding records for the corresponding batch, to prevent cross-contamination risks. The need for formula confidentiality requires that the retrieval scope be strictly limited to authorized sets, to avoid sensitive data leaks.

## Configuration Guidelines
This configuration is based on FastGPT v4.17.0. Specific parameters and recommendations are as follows:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Fine chemical process parameters have high precision requirements; this threshold filters low-match irrelevant data while retaining retrieval results related to core processes |
| `limit` | Top 5–8 results | Bid documents require precise process and feeding data; excessive recall results increase context length and reduce generation efficiency |
| `searchMode` | `mixedRecall` | Can match both structured fields such as formula IDs and feeding quantities, as well as unstructured content such as process descriptions, adapting to multiple types of retrieval needs |
| `usingReRank` | Enabled | After multi-source data recall, re-ranking can place core process documents and compliance records at the top, improving the practicality of retrieval results |
| `datasetSearchUsingExtensionQuery` | Enabled | Expanding related process and feeding keywords based on bid questions can cover more associated production record documents |
| `collectionIds` | Bind collection IDs of formula libraries, feeding records, and cleaning records | Strictly limit retrieval scope to avoid interference from irrelevant data, while complying with compliance requirements for formula confidentiality |

## Three Common Misconfigurations
- An error indicating incorrect file format appears in the interface when uploading a docx document containing images. The cause is that document image parsing support is not enabled, or the embedded image format in the document does not meet system compatibility requirements.
- An error indicating download failure or an empty file list is returned in the interface when attempting to batch download knowledge base files. The cause is that batch download permissions are not configured, or the correct knowledge base collection scope is not selected.
- Image area content is not split for retrieval after enabling question-answering split mode. The cause is that the image parsing option during document upload is not checked, or the image question-answering split function is not enabled.

## How to Verify Proper Configuration
- Upload a batch of test documents containing feeding data and cleaning records, initiate a retrieval test, and check whether the recall results include feeding parameters and cleaning requirements for the target batch.
- Call the specified interface to upload html-format titles and content, and check whether they are successfully synchronized to the preset knowledge base collection.
- After enabling `usingReRank`, check whether the sorting of retrieval results places core process documents at the top.
- Upload a docx document with images, confirm that no format error is reported, and the text content in the images can be normally retrieved and matched.

The values provided here are common starting points and should be measured against the reader's own samples.
