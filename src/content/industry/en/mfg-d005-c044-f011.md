# Pulp and Paper Bidding Document and Quotation Preparation: Forms and Interactions

## What data this category includes
The data for this category mainly comes from wood pulp and waste paper batch ledgers, DCS/QCS control systems, on-paper machine measurement equipment, laboratory testing systems, and energy and water treatment systems. Data update cycles cover real-time, per-shift, and per-paper-roll production cycles. Daily documents include pulp preparation sheets, beating records, paper machine operation logs, online quality curves, laboratory test reports, sheet break and product change records. Fields cover pulp component parameters, paper machine operation parameters, and quality inspection indicators. Units include tons, cubic meters, seconds, grams per square meter, and others.

## Constraints imposed on forms and interactions
Multi-source heterogeneous data sources require forms to support fast cross-system data association and retrieval, to avoid manual entry of duplicate parameters. Parameters with different update frequencies — real-time operation data, per-shift summary data, per-finished-roll data — need to align with the dynamic loading timing of forms, to prevent expired data from being used for quotation preparation. The extensive set of documents and fields requires forms to display content in blocks based on business logic, such as a pulp preparation parameter section, paper machine operation parameter section, and quality inspection parameter section, to reduce entry complexity. The characteristics of continuous web production require forms to support batch import of parameters for the same batch of paper rolls, while verifying unit consistency to avoid quotation deviations caused by unit errors.

## Configuration Settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Configure grouping by business module, with a 10-30 second loading delay for each group | Match the update cycles of different data sources, avoid loading expired real-time or near-real-time data |
| `userSelect` | Preset option libraries for paper machine models and pulp types, support batch import | Reduce manual input errors, adapt to quick parameter reuse for multiple bidding batches |
| `formInput` | Set a separate 5-10 second loading delay for the quality inspection parameter group | Adapt to the real-time update frequency of online quality data |
| Form field validation rules | Enable unit validation and range validation, such as a grammage validation range of 20-200 grams per square meter | Align with the conventional parameter ranges of pulp and paper products, avoid invalid quotation data |
| Context window configuration | Retain 1000-1500 characters of historical input | Match the single document length of bidding documents, avoid context overflow |
| Single search limit | Top 5 entries | Limit the number of returned historical documents, avoid redundant information interfering with form filling |

## Three Common Configuration Mistakes
- Phenomenon: The reply content from the previous AI dialogue in the workflow is carried over to the current quotation preparation form, causing redundant information in the final output. Cause: No input mapping rules are configured, and non-target parameters from previous nodes are not filtered.
- Phenomenon: Unit mismatch errors occur after the form is submitted, or the generated quotation parameters do not match actual production data. Cause: Field validation rules are not enabled, and the units and ranges of input parameters are not verified.
- Phenomenon: Real-time production data loading is delayed, and the form displays expired paper machine operation parameters. Cause: No grouping loading delay is set for `formInput`, all input boxes load data simultaneously, triggering system current limiting.

## How to Verify a Correct Configuration
- Import a set of wood pulp and waste paper batch data, check whether the form automatically loads the corresponding parameters, with no redundant content requiring manual entry.
- Enter parameters that do not conform to conventional ranges (such as a grammage of 10 grams per square meter), check whether a validation prompt pops up.
- After configuring workflow input mapping, test passing test data from previous nodes, confirm that only target parameters are carried over to the current link.
- Adjust the loading delay parameter of `formInput`, check whether real-time data completes loading within the set time.

The values provided are common starting points and should be measured against the reader's own samples.
