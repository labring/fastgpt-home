# Bid Document and Quotation Preparation for Measuring Instruments and Laboratory Management: Multi-turn Dialogue and Prompt Words

## What the data for this category looks like
This category’s data covers daily business documents for enterprise metrology rooms and CNAS-accredited laboratories, including measuring tool ledgers, calibration plans, calibration certificates, interim check records, original test records, reference material ledgers, and deviation handling documents. The system sources data from metrology management systems, external calibration institution certificates, standard devices, LIMS systems, and environmental monitoring records. Updates trigger based on calibration cycles, completion of single tests, or abnormal events. Documents include fields such as instrument ID, calibration validity period, measurement uncertainty, traceability chain information, with units including specialized metrology units such as length, force, temperature, and others.

## What constraints these characteristics impose on the "multi-turn dialogue and prompt words" link
Data sources for this category are scattered, and updates follow no fixed schedule. Multi-turn dialogue must first clarify the call logic for corresponding data sources to avoid using expired calibration certificates or ledger data. Document fields include specialized metrology units and complex traceability information, so prompt words must pre-design metrology term recognition rules to ensure accurate parsing of measurement values, uncertainty, and other content during dialogue. The traceability chain maintenance link requires significant time investment, requiring multi-turn dialogue to guide users to supplement instrument calibration and traceability path information in sequence, preventing missing traceability issues in generated bid documents. At the same time, the consequences of errors are severe, so dialogue must verify data compliance before generating quotations to avoid invalid bids caused by parameter errors.

| Question optimization switch | Enabled | Optimize metrology term questions related to bid quotations, improve retrieval and generation accuracy |

## Three common configuration mistakes
- Calling the dialogue interface returns the `unAuthChat` status code. Cause: Failed to correctly bind the API key permission exclusive to the metrology category, or failed to associate the data source permissions of LIMS and metrology management systems during key configuration.
- The generated bid document contains line breaks causing JSON request failure. Cause: Failed to configure the escape rule for dialogue return content, and failed to preprocess line breaks in metrology parameters.
- Global variables fail to recognize parameters passed by the system side. Cause: Failed to bind category-exclusive parameters such as measuring instrument ID and calibration validity period to the `variables` configuration item, causing system parameters to fail to load correctly.

## How to confirm the configuration is complete
- Initiate a test dialogue containing a specific measuring instrument ID, check whether the returned result correctly calls the calibration information of the corresponding ledger.
- Submit test text containing line breaks, check whether the generated request body is in compliant JSON format.
- View the `variables` and `chatId` configuration items, confirm that exclusive business data parameters for the metrology category and laboratory identifiers have been bound.
- Initiate multiple consecutive dialogues, check whether the context retains the most recent metrology term dialogue content without key information truncation.

The values provided are common starting points and should be measured against the reader's own samples.
