# Tender Document and Quotation Preparation for Measuring Instruments and Laboratory Management: Model Integration and Configuration

## What Data for This Category Looks Like
Data for this category comes from daily operations of enterprise metrology rooms and CNAS system laboratories. It includes gauge ledgers, calibration plans, calibration certificates, periodic inspection records, raw test records, reference material ledgers, and deviation handling documents. Data sources include internal metrology management systems, external calibration institution certificates, LIMS systems, and environmental monitoring equipment. Data updates are triggered by calibration cycles, single test results, and abnormal events. Document fields include gauge number, calibration validity period, measured value, measurement uncertainty, traceability level, reference material batch number, and other fields. Some documents must meet legal metrology format requirements.

## Constraints for Model Integration and Configuration
Data sources for this category are scattered and have diverse formats. This requires model integration and configuration to support parsing and integration of multi-source documents. Data updates do not follow a fixed schedule, so dynamic loading of the latest calibration certificates and periodic inspection records must be supported. Document fields contain professional metrology terminology, so parameters for model calls must ensure content accuracy. Tender documents and quotation preparation must be based on credible metrology data. Configuration must prioritize data traceability and accuracy, and avoid generating content that does not meet CNAS system requirements.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `maxContext` | `8000–12000 token` | Must accommodate full context of multiple calibration certificates and traceability chain documents, to avoid truncating critical metrology data |
| `maxTokens` | `4000–6000 token` | Adapts to the single-page output length requirement for tender documents, covering complete metrology data descriptions and quotation logic |
| `quoteMaxToken` | `2000 token` | Prioritizes quoting authoritative metrology document segments such as calibration certificates and gauge ledgers, controlling the total length of quoted content |
| `temperature` | `0.1–0.3` | Ensures accuracy of metrology-related content, avoiding vague or uncertain statements |
| `AIPROXY_API_ENDPOINT` | Fill in the actual deployed proxy address | Adapts to network access restrictions of internal metrology systems, ensuring connectivity for model calls |
| `AIPROXY_API_TOKEN` | Fill in the assigned exclusive token | Ensures identity legitimacy for large model calls, preventing unauthorized access |

## Three Common Configuration Errors
-  The error `503 No available channels for model text-embedding-v3 under current group default` appears. This occurs when a dedicated embedding model channel for metrology-related embedding tasks is not configured, or channel quotas are exhausted.
-  A large model call returns a connection error, with a connection failure prompt in the interface. This occurs when `AIPROXY_API_ENDPOINT` or `AIPROXY_API_TOKEN` are not configured correctly, or network policies restrict access to the large model service.
-  Knowledge base search takes longer than 40 seconds, with delayed search result returns. This occurs when `maxContext` is not set reasonably, causing overly slow context loading, or redundant metrology historical documents are not filtered, leading to excessive recall volume.

## How to Verify Successful Configuration
-  Test the embedding model call by submitting a segment of a calibration certificate. Check the matching degree between the returned vector results and the document content, and adjust `maxContext` to a value appropriate for the document length.
-  Submit professional metrology-related questions, verify that generated tender document segments include accurate fields such as traceability chains and measurement uncertainty, and confirm that the `temperature` setting meets accuracy requirements.
-  View the large model call logs in FastGPT v4.17.0, confirm that `AIPROXY_API_ENDPOINT` and `AIPROXY_API_TOKEN` have no format errors, and there are no connection failure records.
-  Import multiple gauge ledger documents in batches, test search recall speed, and adjust `quoteMaxToken` to balance recall efficiency and content completeness.

The values provided are common starting points and should be measured against the reader's own samples.
