# Bid Document and Quotation Preparation for Measuring Instruments and Laboratory Management: Knowledge Base Retrieval and Recall

## What This Category of Data Entails
Data for this category comes from enterprise metrology rooms, metrology management systems in CNAS-compliant laboratories, external calibration institution certificates, LIMS systems, and environmental monitoring data. Daily documents include gauge ledgers, calibration plans, calibration certificates, interim verification records, original test records, reference material ledgers, and deviation handling documents. Fields include instrument number, specification model, calibration validity period, measured value, uncertainty, and others. Units include millimeters, pascals, calibration cycle days, and others. Update rhythms are triggered by calibration cycles, completion of single tests, or abnormal situations.

## Constraints Imposed by This Category’s Characteristics on Knowledge Base Retrieval and Recall
The multi-source heterogeneous nature of this category’s data requires retrieval to cover both structured ledger fields and unstructured certificate content. This avoids missing key traceability and measurement information caused by a single retrieval mode. The non-fixed update rhythm triggered by calibration cycles and abnormal situations requires support for incremental synchronization and on-demand knowledge base refresh. This prevents retrieval results from expiring or becoming invalid. The strong correlation between traceability chain and uncertainty fields requires recall results to be associated with full-link documents of relevant instruments. This avoids incomplete evidence caused by isolated retrieval. The rigor required in bidding scenarios requires filtering low-confidence recall results. This ensures that output measurement evidence complies with system specifications.

## How to Set the Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | Meets the rigor requirements for matching calibration certificates and traceability records of this category, filters low-confidence recall results |
| `limit` | `Top 8–12 entries` | Covers the retrieval needs for full-link documents of measuring instruments, avoids missing traceability chain information due to too few recall results |
| `searchMode` | `Hybrid retrieval` | Balances the retrieval needs for structured ledger fields and unstructured certificate content, adapts to multi-source heterogeneous data |
| `usingReRank` | `Enabled` | Improves the sorting accuracy of key fields such as uncertainty and traceability number, complies with the rigor requirements of bidding scenarios |
| `datasetSearchUsingExtensionQuery` | `Enabled` | Automatically expands the retrieval scope based on keywords from bid documents, covers relevant calibration plans and interim verification records |
| `collectionIds` | `Bind to the dedicated knowledge base collection for measuring instruments and laboratories` | Isolates non-category data, avoids mixing irrelevant documents in retrieval results |

## Three Common Misconfigurations
- Phenomenon: When invoking the tool, calibration certificate data recalled from the knowledge base cannot be associated, and the returned result is empty. Cause: The dedicated measuring instrument knowledge base collection was not bound to the corresponding tool invocation configuration, resulting in incorrect retrieval scope.
- Phenomenon: After uploading calibration certificate files in an offline environment, the upload status keeps spinning and cannot be completed. Cause: The offline mode of FastGPT v4.17.0 does not disable external dependency pulling, requiring access to specified resources to complete initialization.
- Phenomenon: When using the bge series embedding models for semantic retrieval, calibration certificate content cannot be recalled, while full-text retrieval can match normally. Cause: The `usingReRank` configuration is not enabled, or the `similarity` threshold is set too high, filtering out critical certificate documents with slightly lower semantic matching scores.

## How to Verify the Configuration Is Properly Set
- Enter the FastGPT knowledge base management page, check whether the `collectionIds` configuration is bound to the dedicated knowledge base collection for measuring instruments and laboratories.
- Submit a test query containing calibration number and uncertainty keywords, check whether the recall results include category-specific documents such as calibration certificates and traceability records.
- View the retrieval configuration panel, confirm that both `usingReRank` and `datasetSearchUsingExtensionQuery` are enabled.
- Simulate an offline environment to upload category documents, confirm that the upload process has no abnormal spinning status.
