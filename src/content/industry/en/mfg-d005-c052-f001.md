# Tender Document and Quotation Preparation for Steel Rolling and Finishing: HTTP Interfaces and External Systems

## What the data for this category looks like
Business data for steel rolling and finishing is generated per individual coil or single piece of steel. Daily documents include rolling plans, heating schedules, rolling specifications, shape and thickness records, surface quality reports, and quality certificates. Data sources include slab or billet batches, heating furnaces, mill automation controls, online thickness and width measurement tools, surface inspection equipment, and MES systems. Updates occur in real time per coil or piece. Core fields include coil number, thickness (mm), width (mm), rolling temperature (℃), surface defect level, batch number, and other relevant fields. Each document focuses on process parameters and quality information for a single batch of steel.

## What constraints these characteristics impose on the "HTTP Interfaces and External Systems" link
Because data updates in real time per coil, HTTP interfaces must support precise retrieval of single-coil data using coil number or batch number, and adapt to high-frequency synchronous requests. Daily documents have significant field differences, so interfaces must support specifying returned fields to avoid transmitting invalid data. Tender document and quotation preparation requires linking to the latest process and quality data, so interfaces must provide time range filtering capabilities. Single-coil steel rolling data volume is small but there are many batches, so interfaces must support batch retrieval and control the volume of data per single request to prevent timeouts or excessive load.

## How to set configurations
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `Authorization` | Bearer {custom authentication key} | Complies with the interface authentication specifications of external MES systems, prevents unauthorized access to production data |
| `variables` | Includes coil number, batch number, thickness tolerance range | Matches core business identifiers for steel rolling, enables precise retrieval of production documents for the target batch |
| `responseData` | Only returns rolling plan, shape and thickness record, and quality certificate fields | Reduces invalid data transmission, meets the document requirements for tender document and quotation preparation |
| Maximum data volume per single request | 100 coils | Adapts to the real-time update rhythm per coil, avoids interface timeouts or excessive load |
| Request timeout | 30 seconds | Balances timeliness of data acquisition and interface stability |
| Knowledge base chunk length | 800–1200 characters | Adapts to the paragraph length of rolling process documents, improves retrieval matching accuracy |

## Three common errors
- The `responseData` field returned by the interface is empty. The symptom is that no business document content is obtained after calling the interface. The cause is that no required return fields are specified, and full MES system data is retrieved directly, exceeding interface transmission limits.
- Batch requests return 504 timeout status code. The symptom is that the interface does not respond after pulling more than 100 coils of rolling data in a single request. The cause is that the request data volume exceeds the carrying capacity of the external system, and the configured maximum data volume per single request is not followed.
- Knowledge base indexing speed is slow. The symptom is that retrieval takes too long after uploading bulk rolling documents. The cause is that documents are not split per coil, and monthly rolling plans are merged into a single file, reducing chunking and retrieval efficiency.

## How to confirm the configuration is correct
- Call the configured HTTP interface, check if the returned `responseData` includes the core fields of rolling plan, shape and thickness record, and quality certificate.
- Initiate a single request for 100 coils of data, confirm that the interface returns a 200 status code and no timeout prompt.
- Upload a single-coil rolling specification document to FastGPT v4.17.0 knowledge base, check that the chunk length falls within the set range, and that retrieval accurately matches the coil number parameter.
- Initiate a request using an unconfigured authentication key, confirm that a 401 unauthorized status code is returned, verifying that the authentication configuration is valid.
