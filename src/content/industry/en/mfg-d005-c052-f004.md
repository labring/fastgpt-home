# Bid Document and Quotation Preparation for Steel Rolling and Finishing: Workflow Orchestration

## Data Profile for This Category
Data sources include slab or billet batches, heating furnaces, mill automation control systems, online thickness and width measuring equipment, surface inspection devices, and MES systems. Daily generated documents cover rolling plans, heating schedules, rolling specifications, shape and thickness records, surface quality reports, and quality certificates. Data updates are performed per coil or individual steel billet. Some parameters sync in real time. Fields include batch number, thickness tolerance, surface defect level, temperature curve, and others, adjusted dynamically with production batches.

## Constraints Imposed on Workflow Orchestration
This category’s data updates per coil or individual steel billet, with some parameters synced in real time. This requires workflow node trigger timing to match production batch node events, to avoid mixing data across batches. Multiple business documents must be spliced and integrated per bidding requirements. Workflows must support automatic extraction of corresponding document fragments based on field rules. Core parameters such as shape and thickness require real-time verification. Workflows must include built-in real-time data call nodes, and parameter verification logic must adapt to dynamically updated batch data. Documents such as quality certificates and rolling specifications must link to corresponding production batches. Bind `variables` in the workflow to store batch identifiers, ensuring accurate data traceability.

## Configuration Guidelines
This page provides configuration rules based on FastGPT v4.17.0.

| Config Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `variables` | Initialize with production batch identifiers, value range `0001–9999` | Matches the batch numbering rules for coils or steel billets in this category, ensuring accurate data traceability |
| Node Trigger Timing | Bind to production batch completion events, execute with a delay of `30–60 seconds` | Adapts to the real-time data synchronization rhythm of this category, avoiding retrieval of incomplete production data |
| Document Extraction Rules | Match corresponding fields in rolling plans and surface quality reports by field, extract `1000–1500 characters` per extraction | Meets the content length requirements of bidding documents, avoiding interference from redundant information |
| Global Variable Update Threshold | Calibrated based on actual measurements | This category has dynamic data update frequency, requiring adjustment of update thresholds according to actual production rhythm |
| `nodeId` | Assign a unique `nodeId` to each document splicing node | Distinguishes the splicing logic of different business documents, avoiding node execution conflicts |

## Three Common Misconfigurations
- Symptom: Workflow configuration cannot locate its storage location after saving. Cause: The workflow default storage directory is not configured in system settings, so the configuration file does not save to the expected path.
- Symptom: Files uploaded via simple tasks cannot pass their links as parameters to workflow tools. Cause: The path parameters of uploaded files are not correctly bound to the workflow’s input nodes, and the file link mapping rule is not enabled.
- Symptom: After modifying global variables, the next node’s debug prompt shows empty input. Cause: The updated `variables` parameter is not synchronized to the input configuration of subsequent nodes, so the variable is not passed correctly.

## How to Verify Correct Configuration
- Manually trigger the workflow once. Check if node logs correctly extract rolling plan and surface quality report fragments for the corresponding batch.
- Upload test steel coil batch data. Confirm that the batch identifier in the global variable `variables` is correctly passed to all subsequent nodes.
- Call the workflow tool. Verify that the uploaded file link is correctly passed to the corresponding node, with no parameter missing errors.
- Check the workflow’s trigger timing. Confirm it matches the production batch completion event, with no delayed or early execution.
