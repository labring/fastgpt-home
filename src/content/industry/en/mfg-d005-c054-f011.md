# Sheet Metal Blanking and Bending Bid Document and Quotation Preparation: Form and Interaction

## What data for this category looks like
Business data for sheet metal blanking and bending mainly comes from CAD/CAM software, order BOMs, sheet metal inventory systems, laser cutting and bending equipment, and MES systems. Daily output documents include unfolded drawings, CNC blanking programs, bending process cards, nesting diagrams, first-piece records, and process transfer cards. Data updates follow order generation, daily inventory checks, and production changeover adjustments. Core fields include bending compensation, sheet thickness, unfolded dimensions, and nesting utilization rate. Most units are millimeters, kilograms, and square meters.

## What constraints these characteristics impose on form and interaction workflows
This category primarily uses multi-variety, small-batch production. Forms must flexibly adapt to parameter requirements for different specifications of sheet metal workpieces. Data sources rely on drawing parameters exported from CAD/CAM, so forms must support importing standardized drawing data files. Data updates occur frequently, so forms must synchronize dynamic data such as sheet metal inventory and equipment capacity in real time or on a scheduled basis. Validation of core fields directly impacts subsequent production quality. Forms must set required field and value range validation for key fields such as bending compensation and unfolded dimensions to avoid issues like hole position misalignment and sheet material waste.

## How to set configurations
| Configuration Item | Recommended Approach | Rationale |
| ---- | ---- | ---- |
| Form field grouping | Group by drawing type, sheet material parameters, and process data | Adapt to different business scenarios of multi-variety, small-batch production |
| Default bending coefficient preset | Set to 1.6-2.0 millimeters for common carbon steel materials | Match general process parameters for sheet metal blanking and bending |
| `userSelect` trigger timing | Trigger after form submission pre-validation passes | Avoid invalid tool calls |
| Data synchronization interval | Synchronize sheet metal inventory data every 5 minutes | Match the update frequency of sheet metal inventory |
| `formInput` format restriction | Only allow uploading CSV format parameter files exported from CAD | Align with the document format of data sources |
| Form validation rules | Set unfolded dimensions and bending compensation as required fields with values greater than 0 | Avoid risks of hole position misalignment and sheet material waste |

## Three common misconfigurations
- The symptom is that the system fails to generate corresponding quotation data after submitting the bid quotation form. The cause is that the trigger condition for `userSelect` is not configured, so the agent cannot independently judge whether to call the parameter verification tool.
- The symptom is that imported sheet metal unfolded drawing parameters are missing or parsed incorrectly. The cause is that format validation is not set for `formInput`, so non-standard CAD exported files cannot be correctly identified.
- The symptom is that voice input bid requirements are not converted into editable text. The cause is that the voice transcription module and form input fields are not bound, so voice content cannot be synchronized to the interaction process.

## How to confirm configurations are correctly set
- Upload a standard CSV format parameter file exported from sheet metal CAD, check whether the form automatically fills the corresponding fields.
- Submit a form containing abnormal parameters such as negative bending compensation, check whether the verification prompt is triggered.
- Trigger the `userSelect` logic, check whether the agent independently calls the parameter verification tool.
- Wait 5 minutes, check whether the sheet metal inventory data is synchronized and updated in the form.
