# Tender Document and Quotation Preparation for Lithium-ion Cell Manufacturing: Forms and Interactions

This page is configured for FastGPT v4.17.0.

## What the data for this category looks like
The data for this category comes from raw material batch ledgers, production MES systems, slurry and coating testing equipment, workshop dew point monitoring devices, formation and grading cabinets, and laboratory testing equipment.
Daily documents include batching records, coating and rolling parameter ledgers, winding or lamination operation records, liquid injection volume logs, formation and grading testing data, and OCV and safety test reports.
Data is generated in real time for each cell production batch. Formation, grading, and testing data for individual cells is updated immediately upon completion of batch testing.
Fields include specific metrics such as slurry ratio, roll gap parameters, liquid injection volume, capacity, and internal resistance.

## How these characteristics impose constraints on forms and interactions
Multiple real-time data sources require forms to support automatic data import from multiple production devices and systems, reducing manual data entry.
Split fine-grained document structures require forms to be organized into sections matching batching, coating, winding or lamination, formation and grading, and testing. This aligns with daily document classification logic.
Specialized production fields require forms to pre-configure parameter items tailored to lithium-ion cell manufacturing, eliminating the need for generic field adaptation.
Frequently updated production data requires forms to support real-time synchronization of the latest testing results, avoiding expired data for document preparation.
Electrochemical production has special requirements that add parameter validity check rules to forms. This ensures entered data complies with production specifications.

## How to set up configurations
| Configuration Item | Recommended Approach | Rationale |

| `formInput` | Configure input items in sections for batching, coating, winding or lamination, formation and grading, and testing. Text input boxes support up to 8000 characters | Aligns with the classification logic of daily lithium-ion cell manufacturing documents, reduces input complexity, and fits standard tender document length requirements |
| `userSelect` | Pre-configure drop-down options for cell batches and raw material batches, display the first 8 latest records | Meets field mapping requirements for connecting multiple data sources, reduces manual input errors |
| Data automatic synchronization rules | Poll production systems every 600 seconds, trigger updates upon completion of production process nodes | Matches the real-time update rhythm of each production batch, ensuring data timeliness for document preparation |
| Parameter check configuration | Bind standard parameter ranges for production processes, pop up prompts for abnormal values | Meets compliance requirements for electrochemical production, proactively avoids invalid data |
| Form submission check | Check completeness and format of required fields, block incomplete submissions | Prevents document preparation errors caused by missing fields |

## Three common mistakes
- The form fails to load uploaded production testing report documents, with a prompt stating no matching knowledge base entries are found. This occurs because specialized documents such as batching records and formation and grading reports are not configured as associated knowledge bases for the corresponding form, or knowledge base indexes are not classified by production process.
- The cell batch drop-down list in the form is empty, and no production batches can be selected. This occurs because the data source for `userSelect` is not configured to point to the production system’s batch ledger, or the data synchronization polling interval is set too long, causing the latest batch data to not sync in a timely manner.
- The tender document generated after form submission is missing the specified coating and rolling parameter fields. This occurs because the parameter item is not included in the `formInput` configuration scope, or there is an error in the field mapping rules.

## How to confirm the configuration is correct
- Manually trigger a data synchronization, then check whether the form’s drop-down list displays the latest production batch records to confirm the synchronization rules are active.
- Upload a test batching record document, then check whether the form automatically loads the corresponding fields to confirm the `formInput` configuration is correct.
- Enter an abnormal parameter value, then check whether the form pops up a check prompt to confirm the parameter check rules are active.
- Submit the complete form, then check whether the generated tender document includes all configured production process fields to confirm field mapping is correct.
