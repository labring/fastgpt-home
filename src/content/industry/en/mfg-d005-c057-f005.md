# Bid Document and Quotation Preparation for Forging and Die Forging: Tool Calling and Plugins

## What data for this category looks like
Data related to forging and die forging comes from raw material quality certificates, heating furnace systems, press collection data, MES, non-destructive testing equipment, and customer forging drawings. Daily documents include forging process specifications, cutting cards, heating furnace records, forging process cards, mold life records, heat treatment entrustment slips, and ultrasonic testing reports. Data is updated per piece, per batch, or per furnace run. Document fields include furnace batch number, blank size, furnace temperature range, forging ratio, mold life, qualified inspection items, and others. Some documents must match the tolerance requirements and fiber direction specifications from forging drawings.

## What constraints these characteristics impose on the tool calling and plugins workflow
Dispersed data sources require tool calling to interface with multiple types of system APIs, and adapt to authentication and data formats for different data sources. The high-frequency update rhythm requires tool calling to support real-time or near-real-time pulling of data per furnace run or per batch, to avoid information deviation caused by static caching. Professional fields and business rules require tool calling parameters to be bound to forging-specific field mappings, to ensure the accuracy of quotation preparation. Complex process calculations such as deformation step planning and heating range preparation take a long time, so the timeout configuration for tool calling must be adjusted to match business rhythms.

## Three common mistakes
- A timeout error is returned after calling a custom MCP service, with the system prompting timeout-related information for MCP. The cause is that complex transaction processing for forging process step planning exceeds the default 90-second wait duration, and the timeout configuration was not adjusted.
- Quotation data fields returned by tool calls are missing the furnace batch number or forging ratio. The cause is that forging-specific field mappings were not configured, and generic field mappings were used, leading to failure to correctly extract professional data.
- Calling data source interfaces fails, returning connection errors or no data. The cause is that the data source access address and authentication rules were not correctly configured, making it impossible to connect to real-time data from heating furnace or MES systems.

## How to confirm the configuration is complete and correct
- Initiate a quotation preparation test for a single furnace run of forgings, check whether the tool call successfully pulls heating furnace records and raw material quality certificate data for that furnace run.
- Submit a test case containing complex deformation step planning, confirm that the tool call is not forcibly terminated, and the time consumption matches business expectations.
- View the structured data returned by the tool call, confirm that professional fields such as furnace batch number and forging ratio have been correctly mapped and included.
- Verify the complex transaction processing logic of the custom MCP service, confirm that the call result is fully returned without truncation.
