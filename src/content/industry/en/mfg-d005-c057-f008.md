# Bid Document and Quotation Preparation for Forging and Die Forging: Document Parsing and Chunking

## What Data for This Category Looks Like
Data for this category comes from raw material quality certificates, heating furnace system data, press collection data, MES, non-destructive testing equipment, and customer forging drawings. Daily documents include forging process specifications, cutting lists, heating furnace logs, forging process cards, mold life records, heat treatment work orders, and ultrasonic testing reports.
Data updates per piece, per batch, and per furnace run. Most documents contain fields such as forging ratio, fiber direction, heat batch number, heating temperature, and testing defect types, with units including professional industrial units such as millimeters, degrees Celsius, and tons.

## What Constraints These Characteristics Impose on the "Document Parsing and Chunking" Link
This category of data has a high update frequency. A single batch of forgings corresponds to multiple types of related documents, requiring accurate splitting of professional fields and batch-bound information.
Daily documents include both structured table-style testing reports and unstructured step-by-step process specifications, so parsing functions must adapt to multi-format text. Professional terms such as forging ratio and fiber direction must be fully retained to avoid chunking that breaks professional association logic.
Large-volume multi-furnace run log documents may exceed standard parsing thresholds, so timeout and chunking parameters need adjustment to adapt to batch data processing.

## How to Configure the Settings
This is optimized for FastGPT v4.17.0, with the following configurations tailored for the forging and die forging scenario:

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `chunkSize` | `800–1200 characters` | This category of documents contains professional terms and batch-related information; this range preserves complete process steps or test batch context |
| `chunkSplitter` | Split by paragraph + heading | Daily documents are mostly categorized by process steps and furnace runs; splitting by headings and paragraphs preserves the logical structure of the document |
| `customPdfParse` | Enable high-precision OCR mode | Some testing reports are scanned documents; high-precision mode accurately identifies tables and professional testing data |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300–600 seconds` | Single-furnace run batch log documents have large volume, requiring sufficient time to complete parsing |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | Scenarios where multiple furnace run documents are uploaded in combination require adaptation to large file uploads |
| `chunkSettingMode` | Manual configuration | Professional documents require adjustment of chunking parameters to adapt to the professional content structure of the forging industry |

## Three Common Mistakes
- Uploading a scanned ultrasonic testing report results in an OCR Error alert. The cause is that high-precision PDF parsing mode is not enabled, causing tables and professional terms in the scanned document to fail to be accurately identified.
- Uploading batch furnace run log documents results in no search results, only an error prompt. The cause is that the `PARSE_FILE_TIMEOUT_SECONDS` parameter is not adjusted; large-volume document parsing times out, causing data to fail to be successfully stored.
- Uploading a cutting list in simple mode, the large language model does not trigger document parsing. The cause is that manual chunking rules are not configured in `chunkSettingMode`, causing the system to fail to identify the structured fields of the cutting list and not trigger the parsing process.

## How to Confirm the Configuration Is Correct
- Upload a single scanned ultrasonic testing report, check if the parsed text contains fields such as testing defect types and heat batch numbers, to confirm that the high-precision OCR mode is active.
- Upload a single-furnace run batch heating furnace log document, check if the parsing progress completes within the preset timeout period, to confirm that the timeout parameter configuration is reasonable.
- Search for keywords related to forging ratio, check if the returned results contain complete process specification context, to confirm that the chunking parameters preserve professional association content.
- Test uploading a multi-document combined package within 500 MB, confirm that the upload and parsing processes have no abnormalities, to confirm that the file size limit configuration meets business needs.

The values provided are common starting points and should be measured against the reader's own samples.
