# Inspection and Process Record Audit for Stamping and Sheet Metal Forming: Vector Models and Indexes

## What the data for this category looks like
Data for this category primarily comes from stamping workshops of automotive panel, home appliance sheet metal, and hardware enterprises. It includes documents such as stamping work instructions, material utilization sheets, mold inspection checklists, first and last piece records, dimensional inspection reports, and mold change records.
Data sources cover steel coil labels and quality certificates, real-time data from punch presses and feeders, mold management systems, MES systems, and coordinate measuring machine or fixture inspection data. Updates are synced per coil of material, each production batch, or each mold change. Document fields include core production information such as material grade, mold number, inspection dimensions, and mold change time.

## Constraints on Vector Models and Indexing from These Characteristics
The high-frequency, small-batch data update rhythm of this category requires vector models and indexing systems to support fast incremental updates. This avoids performance losses caused by full reindexing.
Mixed input of multiple document types requires vector models to maintain consistent encoding for both unstructured text (such as work instructions) and structured fields (such as inspection dimensions and mold change time).
Strongly linked field attributes in production require indexes to bind metadata such as batch number and mold number. This ensures retrieval can accurately connect to corresponding production scenarios, reducing invalid matches across batches or molds.
Additionally, the decentralized nature of data sources requires indexes to support unified access and management of vectors from multiple sources.

## Configuration Setup
This configuration is adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Adapts to the text length of stamping work instructions and inspection reports, avoids breaking critical production information within a single chunk |
| Overlap Length | 50–100 characters | Retains metadata such as mold number and mold change time across chunks, prevents loss of critical production identifiers due to segmentation |
| Similarity Threshold | 0.75–0.85 | Meets the precision requirements for stamping inspection, avoids mismatching inspection data from different batches or molds |
| Single Search Limit | Top 10 results | Covers the volume of associated records for a single mold change or production batch, avoids performance waste from redundant retrieval |
| `defaultToken` | Calibrated based on actual testing | Adapts to the default input token limits of embedding models such as bce-embedding-v1, avoids exceeding limits for basic requests |
| `maxToken` | 8192 token | Matches the maximum input token count of mainstream open-source embedding models, supports complete encoding for multiple document types |

## Three Common Misconfigurations
-  Interface error prompts "This token does not have permission to use the model" or shows no available channels. The cause is failure to correctly configure the access method of the embedding model in FastGPT, failure to skip One API and directly bind the model-specific key, or failure to correctly enable channel permissions.
-  Cross-batch stamping inspection data appears in retrieval results. The cause is failure to bind metadata fields such as batch number and mold number in the index, resulting in vector matching not being linked to production scenario attributes, leading to invalid matches.
-  Token limit exceeded error occurs when generating vectors. The cause is failure to correctly set the `maxToken` parameter, with input text length exceeding the maximum token limit supported by the model.

## How to Confirm Proper Configuration
-  View the FastGPT embedding model configuration page, confirm that the access information of the corresponding model has been correctly entered, and no channel permission error prompts are displayed.
-  Upload a stamping mold change record document, trigger the vector generation process, and check that the generated vector data does not have truncated or missing key metadata such as mold number and mold change time.
-  Initiate an inspection record audit retrieval request, and verify that the number of returned results matches the set single search limit.
-  Test retrieval of inspection data from different batches, and confirm that returned results only include associated records for the corresponding batch.

All provided values are common starting points, and should be evaluated against the reader’s own samples.
