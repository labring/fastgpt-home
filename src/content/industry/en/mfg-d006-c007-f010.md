# Inspection and Process Record Audit for Stamping and Sheet Forming: Knowledge Base Retrieval and Recall

## What data for this category looks like
Data for stamping and sheet forming scenarios comes from steel coil labels and quality certificates, real-time data from punch presses and feeders, mold management systems, MES systems, coordinate measuring machine or fixture inspection data. Daily business documents include stamping work instructions, material utilization rate sheets, mold inspection checklists, first and last piece records, dimensional inspection reports, and mold change records.
Data updates trigger per coil of material, per batch of material, or each mold change. Document structures include fields such as material grade, mold number, mold change time, inspection dimensional parameters, and material utilization rate. Units include millimeters, tons, hours and other common business units.

## What constraints these characteristics impose on the knowledge base retrieval and recall link
Data sources are scattered and diverse, covering real-time equipment data, static documents and inspection records. Retrieval configurations must link multiple source business datasets to avoid missing key information such as mold management and material quality assurance.
The high-frequency update feature requires retrieval nodes to support incremental synchronization logic. This ensures the latest data from each mold change and batch of material can be quickly recalled.
Significant differences exist between document structures. Tabular material utilization rate sheets and text-based work instructions require retrieval strategies that balance precise field matching and semantic understanding.
Mold changes and material batches have a notable impact on process stability. Retrieval must link dimensional parameters such as batch and mold to improve the business relevance of retrieval results.

## How to set the configuration
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Aligns with the precision requirements for stamping parameters, filters low-match irrelevant inspection records and documents |
| `limit` | Top 8 entries | Covers the typical volume of inspection data for a single mold change or material batch, avoids context overload that impacts inference |
| `usingReRank` | Enabled | Optimizes ranking for long-text process documents and tabular data, improves recall rates for critical parameters such as drawbead parameters |
| `searchMode` | `mixedRecall` | Balances semantic matching for process descriptions and precise field matching for values such as mold number and material grade |
| `datasetSearchUsingExtensionQuery` | Enabled | Supplements extended queries linked to mold change records and material batches to match high-frequency business scenarios |
| `collectionIds` | Configured by workshop business grouping | Only includes associated datasets for the current stamping workshop, avoids interference from irrelevant data on retrieval results |

## Three common mistakes
- Phenomenon: Retrieval results do not include auxiliary business data such as mold inspection checklists. Cause: Auxiliary datasets are not included in the `collectionIds` configuration, and only core work document datasets are retrieved.
- Phenomenon: After importing an Excel-format material utilization rate sheet, retrieval results cannot match the specified material grade field. Cause: Column name indexing configuration for tabular datasets is not enabled. During vectorization, only cell content is associated, not header fields, leading to failed field matching.
- Phenomenon: Mold change batch variables output by HTTP requests in a workflow cannot be bound to retrieval conditions for a specified knowledge base. Cause: Variable mapping is not configured in the retrieval node, mold change batches are not passed as extended query parameters, and `datasetSearchUsingExtensionQuery` is not enabled.

## How to confirm the configuration is complete
- Upload a test first and last piece record Excel file with known mold number and mold change time, run retrieval, confirm returned results include matching content for the corresponding fields.
- Review the operation logs of the retrieval node, confirm extended query parameters carry preset mold change batch or material number variables, verify `datasetSearchUsingExtensionQuery` is active.
- Check the dataset configuration list, confirm all associated stamping workshop business datasets are added to the `collectionIds` configuration, with no critical data sources omitted.
- Adjust the `similarity` threshold, verify that low-match irrelevant document results are filtered, confirm retrieval precision meets business requirements.

The values provided are common starting points and should be measured against the reader's own samples.
