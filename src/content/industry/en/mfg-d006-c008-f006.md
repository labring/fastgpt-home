# Inspection and Process Record Audit for Cosmetics Manufacturing: Source Citation and Traceability

## What This Category's Data Looks Like
This category of data originates from daily production and compliance documents of skincare, haircare, makeup, and special cosmetic manufacturers. These documents include formulation process sheets, weighing and feeding records, emulsification and filling records, cleaning and sanitization records, semi-finished and finished product inspection reports, and label review forms.
Data sources cover registered and filed formulations, raw material safety materials, production equipment logs, ERP/MES systems, laboratory test results, and packaging material version records. Updates are made per production batch or each line change. Document fields include restricted substance content, feeding timestamps, homogenization parameters, batch numbers, and claimed content, among others.

## Constraints Imposed on Source Citation and Traceability
The update rhythm per production batch or line change requires traceability to be tied to the unique identifier of the corresponding production batch to avoid invalid cross-batch citation. Coexisting multi-source data requires establishing a unified traceability chain to link registered formulations, equipment logs, and laboratory test results, ensuring cited content matches original compliance records.
Documents contain compliance-sensitive fields such as restricted substance content and label claims. The traceability link must strictly match the content of the filed version to prevent mismatches between claims and filings. The fine-grained structure of multiple fields requires precise localization of document fragments from the corresponding production stage during recall, pulling only relevant content.

## Configuration Settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| Maximum Context | 800–1200 characters | Matches the core fragment length of a single cosmetics production document, avoiding truncation of registered formulations and inspection data |
| Single Recall Limit | Top 6 entries | Corresponds to the number of documents associated with a single production batch, reducing interference from irrelevant information |
| `detail` | Enable full field return | Covers all required fields for audit, including restricted substance content and feeding timestamps |
| `quoteMaxToken` | 1000 token | Standardizes the length of single-segment citations, adapting to document formats across different production stages |
| `responseData` | Bind production batch ID | Ensures traceability content is strictly tied to the corresponding production batch |
| Retrieval Source Filter | Retain only registered, production, and laboratory data | Focuses on core data sources for compliance audits of this category |

## Three Common Misconfigurations
- Phenomenon: Returned traceability content is unrelated to the current production batch, and fields are empty. Cause: The production batch ID was not bound as a retrieval condition, resulting in recall of documents from other batches.
- Phenomenon: The audit prompts a mismatch between formulation content and filings, with the error message "filed version mismatch". Cause: Full field return was not enabled, resulting in truncation of restricted substance statement fields in registered formulations.
- Phenomenon: The number of retrieval results exceeds the audit scope. Cause: The single recall limit was set too high, and parameters were not adjusted based on the number of documents associated with a single production batch.

## How to Verify Successful Configuration
- Retrieve the feeding record for a specified production batch, and verify that the returned content includes the batch’s timestamp and raw material information.
- Trigger a compliance audit request, and check that the returned traceability content is linked to the registered formulation and the current batch’s inspection report.
- Review the number of retrieval results, confirming that the count matches the scale of documents associated with a single production batch.
- Check error logs to confirm that no incomplete content prompts caused by truncated fields appear.

The values provided are common starting points and should be measured against the reader's own samples.
