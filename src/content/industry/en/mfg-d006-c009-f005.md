# Inspection and Process Record Audit for Pharmaceutical Dosage Form Manufacturing: Tool Calling and Plugins

## What Data Looks Like for This Category
Data for this category originates from approved formulation processes, MES electronic batch records, equipment environmental monitoring data, LIMS systems, and quality management systems.
Data updates trigger per production batch and each key process step, or follow fixed monitoring schedules.
Daily documents include master production files, batch production records, cleaning records, inspection records, deviation CAPA change records, and batch release audit forms.
Core fields include material batch numbers, process parameter values, test result values, and deviation descriptions. Involved units include milligrams, degrees Celsius, batch numbers, and similar units.

## What Constraints These Characteristics Impose on Tool Calling and Plugins
This content is based on FastGPT v4.17.0.
Data sources for this category are scattered and updated frequently. Tool calling plugins must support connection to multiple system data sources, and adapt to different formats of electronic batch records, LIMS test data, and related assets.
Each batch’s complete document includes dozens of core fields. Tool calling parameters must accurately match specific fields such as material batch numbers and process parameters, to avoid data misalignment from generic calls.
Under GMP compliance requirements, call logs and parameter traceability must be retained. Plugins must include a built-in log recording module to ensure operational traceability.
Frequently updated batch data requires limiting the volume of data per single call, to prevent context overflow that affects response efficiency.

## How to Set Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Workflow/API tool selection | Set to `auto` and bind the preset inspection and record audit plugin group | This category needs to call multiple compliance-related tools; automatic matching reduces manual configuration complexity |
| Workflow/API function-call configuration | Enable mandatory parameter verification mode | Fields in this category require precise matching to avoid passing invalid parameters during calls |
| Plugin call timeout | 600 seconds | Single batch data pulling and audit requires processing multiple documents; reserve sufficient response time |
| Bulk data pull limit | First 5 pending audit batches | Avoid loading too much data in a single call causing context overflow |
| Log retention configuration | Retain all call logs for a minimum of 365 days | Meet operational traceability requirements under GMP compliance |

## Three Common Mistakes
- Symptom: Cannot find the configuration entry for custom plugins on the plugin management page, unable to complete deployment. Cause: Did not complete the upload path configuration for the plugin package according to FastGPT official guidelines, mistakenly using a local path as the in-platform path.
- Symptom: The `q` parameter passed during tool calling is empty or does not match business requirements. Cause: Did not accurately map core content such as specific inspection batch numbers and material information in user questions to tool parameters, resulting in failed calls.
- Symptom: Results returned after plugin calling do not meet GMP compliance requirements, with missing core data fields. Cause: No parameter matching threshold configured, causing the tool call to automatically match irrelevant fields and fail to accurately pull core documents such as inspection records and deviation records.

## How to Confirm Configuration Is Correct
- Enter the plugin management page, confirm that all bound inspection and record audit plugins are in an enabled state, and the configuration path is correct.
- Initiate a simulated call, pass material information for a test batch, and check whether the automatically matched parameters during tool calling match the preset fields.
- View the call log module, confirm that parameters and returned results of each tool call are fully retained, and the retention duration meets compliance requirements.
- Adjust the `toolChoice` configuration to manual selection mode, verify that required inspection tools can be accurately selected from the bound plugin list.
