# Inspection and Process Record Audit for Finished Pharmaceutical Dosage Forms: Source Citation and Traceability

## What Data Looks Like for This Product Category
Finished pharmaceutical dosage form production data originates from approved formulation processes, material batches, MES/electronic batch records, equipment and environmental monitoring systems, LIMS, and quality management systems. Data updates follow each production batch cycle; key process steps and monitoring points are updated in real time as planned. Daily documents include master production documents, batch production records, batch packaging records, cleaning validation records, inspection records, deviation/CAPA/change documents, and batch release review forms. Core fields include batch number, process parameters, weighing values, test results, and deviation descriptions. Units include milligrams, degrees Celsius, batch numbers and other unique pharmaceutical production identifiers.

## Constraints Imposed on Source Citation and Traceability
Documents for a single production batch cover multiple business links, with scattered data sources that must be bound to a unique batch number. Traceability must accurately associate specific batches and steps to avoid cross-batch data confusion. Under GMP compliance requirements, cited content must retain the integrity and traceability of original documents, and must not alter or delete key information to ensure auditability. Data integrated across multiple systems needs to be unified into the traceability context to avoid disconnection across systems. Additionally, the high-risk nature of inspection and audit links requires that citation sources can be quickly located to original records, ensuring that complete operational links can be traced when issues arise.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1200–1500 token | Matches the average content length of batch records for single finished pharmaceutical dosage form production, ensuring coverage of complete process and test data |
| `responseData` | Return only original text fragments | Complies with pharmaceutical production compliance requirements, retains the originality of cited content, and avoids information deviation caused by AI processing |
| `detail` | Enabled | Retains citation metadata including batch number, document type, and generation time to meet the needs of accurate traceability positioning |
| Single search limit | Top 6 results | Covers multiple types of documents involved in single-batch production, avoiding omission of key process, test, or deviation records |
| Reranking | Enabled | Sorts cited content by relevance, prioritizing core audit fields such as process parameters and test results |
| Maximum context | 8000 characters | Adapts to traceability requirements for multi-document integration, ensuring all relevant records are included in the context scope |

## Three Common Misconfigurations
- Red error prompts appear in the interface when citing specific document fragments. This occurs when the `responseData` parameter is not configured correctly, causing the returned citation format to not comply with system validation rules.
- Subsequent workflow nodes cannot call knowledge base citation content. This happens when the `detail` parameter is not enabled, and citation metadata associations are not retained, preventing context from being passed between nodes.
- Search results do not directly return the original knowledge base text, and include AI-generated supplementary content. This occurs when `responseData` is not set to return only original text fragments, and the default content organization logic is enabled.

## How to Verify Proper Configuration
- Submit a single-batch inspection and audit request, and verify that the returned cited content includes complete original document fragments with no additional processed content.
- Test multi-round workflows to confirm that each node can correctly call knowledge base citation association data without content loss.
- Check citation metadata to confirm that it includes product category-specific fields such as batch number, document type, and generation time, enabling accurate positioning to original records.
- Simulate scenarios where no citations are matched, and verify that the system triggers corresponding prompts according to the configuration, ensuring the traceability logic operates normally.

The values provided are common starting points and should be measured against the reader's own samples.
