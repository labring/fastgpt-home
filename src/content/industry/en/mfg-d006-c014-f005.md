# Inspection and Process Record Audit for Dyeing and Finishing: Tool Calling and Plugins

## What data this category involves
Data for this category originates from dyeing and finishing factories and fabric enterprises, covering dyeing, setting, laboratory and quality departments. Included documents are dyeing recipes, chemical dosing records, dye vat curves, sample confirmation records, color difference reports, setting process sheets, wastewater ledgers, and more. Data sources include customer color samples, recipe libraries, dye chemical batches, dye vat control equipment, colorimeters, setting machines, and environmental monitoring devices.

Data update frequency follows per vat, per batch, per shift. Dye vat curves and color measurement data are synced in real time. Process sheets and ledgers are updated per shift.

Dyeing recipes include dye components and additive dosage, with units of kilograms and milliliters. Dye vat curves record heating rate and holding time, with units of degrees Celsius and minutes. Color difference reports include color difference values, with unit of NBS.

## Constraints on Tool Calling and Plugins
Data sources for this category cover industrial equipment, semi-electronic records, and paper ledgers. Tool calling must adapt to access format constraints of multi-source data.

High-frequency update rhythm (per vat, per batch, per shift) requires tool calling response times to match production tempo. Delays are avoided to prevent disruption of process handoffs.

Diverse document types include structured process sheets and unstructured equipment curves. Plugins must support format conversion and field extraction to ensure key parameters can be accurately called.

Unlike woven fabric structure data, core data for this category is color and process parameters. Plugins must prioritize color parameter validation and recipe matching.

Process errors can lead to full vat rework or scrap. Tool calling must include data validation logic to prevent incorrect parameters from triggering downstream processes. It must also ensure data storage compliance to avoid leaks of sensitive data such as wastewater ledgers.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Workflow/API tool selection | `auto` | Adapts to FastGPT v4.17.0 plugin automatic calling logic, automatically matches tools required for the current process, no manual switching needed |
| Plugin call timeout | `600 seconds` | Matches average duration of dye vat heating, holding and other processes, avoids interrupting production flow mid-process |
| Workflow/API function-call configuration | `Enable forced structured output` | Ensures dye vat parameters and color difference data returned by tools conform to preset field formats, facilitating subsequent process validation and calling |
| Plugin data storage path | `minio bucket /dyeing-finishing/process-records/` | Divides storage by category and workflow stage, enabling batch retrieval of process data like dye vat curves and color difference reports |
| Maximum plugin call retries | `2 times` | Balances call success rate and production tempo, avoids excessive retries delaying vat processing progress |

## Three Common Configuration Mistakes
- Calling a database connection plugin returns an internal server error, with a prompt that a database connection cannot be established. Cause: The plugin's database access whitelist is not configured, or the database port is not open to the FastGPT deployment server.
- After configuring minio storage, dye vat curve data cannot be saved normally, with a storage failure prompt. Cause: Minio access keys and bucket permissions are not correctly configured, and the storage path for dye vat data is not pointed to the dedicated bucket for this category.
- After calling a tool, the correct dataId cannot be obtained, preventing downstream processes from reading process sheet data for the corresponding batch. Cause: The unique identifier of the current vat is not specified as a retrieval condition in the tool call parameters, or batch numbers and data indexes are not correctly bound.

## How to Confirm Configuration Completion
- Manually trigger a plugin call, input the batch number of a specified vat, verify retrieval of curve data and color difference reports for the corresponding dye vat. Confirm returned results include preset fields such as heating rate and color difference values.
- Upload a simulated color difference report to the configured minio storage path, use FastGPT's file retrieval function to verify successful reading of the file. Confirm storage path configuration is correct.
- Trigger the database connection plugin, query feeding records for a specified dye chemical batch, verify return of structured data. Confirm database connection and permission configurations are correct.
- View FastGPT's plugin call logs, confirm each call's timeout time does not exceed 600 seconds, retry count does not exceed 2 times, and no abnormal error messages are present.
