# Inspection and Process Record Audit for Dyeing and Finishing: Citation Sources and Traceability

This document is written based on the configuration logic of FastGPT v4.17.0.

## What the Data for This Category Looks Like
Daily documents for this category include dyeing formulas, chemical weighing records, dye vat curves, sample confirmation reports, color difference reports, setting process sheets, and sewage ledgers. Data sources cover customer color samples, formula libraries, dye chemical batches, dye vat control equipment, colorimeters, setting machines, and environmental monitoring devices.

Data updates occur per vat, per batch, or per shift. Single-batch data includes fields such as vat number, dye ratio, dye vat temperature, holding time, discharge concentration, and some fields have clear units of measurement.

## What Constraints These Characteristics Impose on Citation Sources and Traceability
Frequent updates per vat, batch, and shift require traceability information to be accurately bound to specific vat numbers and batches, to avoid confusion of process records across batches. Documents for wet chemical processes mostly include structured numerical parameters and equipment operation curves, so traceable positioning of precise segments must be supported.

Data sources cover mixed formats of manual records and device-collected data, so association logic for different metadata types must be compatible. Consequences of errors include full-vat rework, scrap, and environmental compliance risks, so traceability information must be directly traceable to original records without secondary verification.

## How to Configure the System
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Matches the average length of single-segment documents such as dye vat curves and process sheets, to avoid truncating key process parameters |
| `responseData` | Enabled | When enabled, metadata of cited segments can be returned in responses, meeting traceability requirements |
| `detail` | Enabled | Associates cited segments with the full path and slice position of the original document, supporting original document preview |
| Maximum number of recalled entries | Top 6 entries | The number of process records and ledgers related to a single vat is limited; excessive recall will interfere with context accuracy |
| Context window | 2000–2500 token | Covers the total length of process parameters, batch information, and quality inspection records for a single batch |

## Three Common Misconfigurations
- Phenomenon: The terminal reply does not display the citation source module. Cause: The `responseData` configuration item is not enabled, or the citation display switch of the knowledge base is not activated.
- Phenomenon: Red numeric strings appear in citation error messages. Cause: The data source of the dyeing and finishing-specific knowledge base is not correctly bound, or core fields such as batch number and vat number are not mapped to the metadata of knowledge base slices.
- Phenomenon: The original document details before the slice cannot be previewed. Cause: The complete storage path and version information of the original document were not retained during knowledge base import, or the `detail` configuration item for associating the original document position was not enabled.

## How to Verify Successful Configuration
- Initiate a query containing a specific vat number or dye chemical batch number, and check whether a citation source module is displayed at the end of the reply.
- Click the jump link in the citation source module, and confirm that it jumps to the corresponding slice position of the original document imported into the knowledge base.
- View the metadata of the imported knowledge base slices, and confirm that core fields such as dye chemical batch, vat number, and production shift are included.
- Simulate an abnormal query scenario, and confirm that the citation error message is clear and readable, with no meaningless errors such as red numeric strings.

The values provided are common starting points and should be measured against the reader's own samples.
