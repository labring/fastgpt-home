# Inspection and Process Record Audit for Dyeing and Finishing: Knowledge Base Retrieval and Recall

## What data for this category consists of
Data for this category comes from dyeing and finishing factories, and the dyeing, setting, laboratory, and quality departments of fabric enterprises. It covers documents such as dyeing formulas, chemical weighing records, dye vat curves, sample confirmation records, color difference reports, setting process sheets, and sewage ledgers.
Data sources include customer color samples, formula libraries, dye chemical batches, dye vat control equipment, colorimeters, setting machines, and environmental monitoring systems. Update frequency is per vat, per batch, or per shift. Each single data entry includes fields like process parameters, test results, and batch information. This is structured and semi-structured data for wet chemical batch processing.

## Constraints imposed on knowledge base retrieval and recall
This category of data has high update frequency and is triggered per batch. This requires knowledge base retrieval to support incremental synchronization and batch-level data association.
Semi-structured data such as dye vat curves and color difference reports require targeted matching of process parameter and test result fields. This avoids low relevance issues caused by broad keyword searches.
The volume of single-batch data increases with the number of vats. The number of results retrieved in a single call must be limited. This prevents context overload.
Wet chemical processing has strong process relevance. Retrieval results must match formulas, equipment parameters, and test records simultaneously. This ensures business relevance of recalled content.

## Configuration settings
The following configurations are based on FastGPT v4.17.0, as detailed below:

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Matches strongly relevant business data such as dyeing formulas and color difference reports, filters low-relevance broad results |
| `limit` | Top 8–12 entries | Adapts to the data volume per vat, controls context length, avoids exceeding model input limits |
| `searchMode` | Semantic retrieval | Adapts to semantic matching of semi-structured non-pure text data such as dye vat curves and process sheets |
| `usingReRank` | Enabled | Improves sorting priority of precisely matched results such as color difference reports and formula parameters |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands synonym retrieval for process terms, covers professional expressions for dye chemical batches and setting processes |
| `collectionIds` | Dataset IDs divided by department | Isolates business data of different categories such as laboratories, dye vat control, and environmental monitoring, avoids cross-domain interference |

## Three common misconfigurations
- Retrieval results return empty or only irrelevant general text. The cause is failure to configure targeted field retrieval for semi-structured data such as dyeing formulas and dye vat curves. Only broad keyword matching is used.
- Old batch data is still recalled after an incremental update. The cause is failure to configure automatic synchronization rules for the knowledge base according to the update rhythm of per vat and per batch. This leads to delayed refresh of data versions.
- A context overrun error occurs after a call. The cause is failure to limit the value of `limit`. The number of results retrieved in a single call is too high. This exceeds the maximum length limit of model input.

## How to verify correct configuration
- Upload a single dye vat curve document, initiate a retrieval request containing corresponding vat information. Verify whether same-vat dyeing formulas and color difference reports can be matched.
- Trigger an incremental update operation. Check whether the knowledge base only synchronizes newly uploaded batch data and does not overwrite historical content.
- Initiate a retrieval request containing professional process terms. Verify whether matching results of corresponding fields are returned. Avoid recalling vague general text.
- Check whether the file types supported by the knowledge base cover common document formats of this category, such as dyeing formulas, dye vat curves, and color difference reports.
- View retrieval logs. Confirm that the number of recalled results conforms to the value range configured for `limit`.

The values given are common starting points and should be measured against the reader's own samples.
