# Coating and Painting Inspection and Process Record Review: Knowledge Base Retrieval and Recall

## What This Category's Data Looks Like
This category covers business related to coating lines for automobiles, home appliances, construction machinery, metal furniture, and similar applications. Data sources include coating supplier TDS/SDS documents, spray booth and oven operating data, results collected by colorimeters and film thickness gauges, environmental monitoring data, and MES system records. Daily documents include coating process cards, coating batch sheets, paint mixing records, film thickness and color difference reports, oven curves, defect repair sheets, and VOCs ledgers. Data update frequency follows per coating batch, per shift, and continuous collection modes. Some inspection documents include unit fields such as μm, ℃, mg/m³.

## What Constraints These Characteristics Impose on the Knowledge Base Retrieval and Recall Link
The multi-source, high-frequency update, and multi-document type characteristics of this category's data impose multiple constraints on the knowledge base retrieval and recall link. The update rhythm of continuously collected real-time working condition data and batch documents differs greatly. Retrieval must support filtering results by time range to avoid mixing expired batch data. Field units of multiple document types are bound to specific business scenarios. Retrieval must match corresponding unit parameters. For example, film thickness inspection results must be associated with process requirements using μm units. Retrieval priorities of defect repair sheets and process cards must be distinguished. Repair-related results must first match current batch process deviations. At the same time, compliance retrieval for VOCs ledgers requires precise matching of ledger fields to avoid interference from irrelevant data.

## Configuration Settings
This configuration applies to FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Matches the precision requirements for coating process parameters and inspection results. Prevents excessive irrelevant results if set too low, and misses valid matches if set too high |
| `limit` | Top 8–12 entries | Covers the number of main inspection and process documents for a single coating batch. Prevents too many results from exceeding the context window |
| `searchMode` | `vector+keyword` | Balances semantic matching of process parameters and precise keyword matching of batch numbers and inspection values, adapting to multiple document types |
| `usingReRank` | Enabled | Rearranges initial recall results by business relevance, prioritizing core inspection documents such as oven curves and film thickness reports |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands search terms. For example, expands "film thickness" to "film thickness μm" to match inspection fields with units |
| `collectionIds` | Configured by coating process grouping | Associates knowledge base collections for pre-treatment, spraying, and curing processes respectively. Narrows retrieval scope and improves matching precision |

## Three Common Mistakes
- Empty retrieval results or far fewer results than expected. Cause: Failed to configure `collectionIds` by coating process, so the retrieval scope covers irrelevant knowledge base collections, or the `similarity` threshold is set too high, filtering valid matching results.
- Retrieval results include old documents not linked to the current batch. Cause: Did not enable retrieval configuration for filtering by time range, or did not distinguish retrieval permissions between batch documents and real-time working condition documents.
- Knowledge base original document links cannot be downloaded normally. Cause: Did not correctly configure the nginx proxy path for knowledge base files, or did not bind storage permissions for the corresponding document collection in FastGPT.

## How to Confirm Configuration Is Complete
- Run a single retrieval test, enter process keywords or inspection parameters for the current batch, check if the returned document types cover core documents for the current process, and adjust corresponding parameters to meet business needs.
- Verify the extended search term function, enter "film thickness" to confirm if inspection reports with μm units are returned, and confirm that the `datasetSearchUsingExtensionQuery` configuration is active.
- Check the rearrangement order of retrieval results, confirm that core documents such as oven curves and film thickness and color difference reports appear at the top, and confirm that the `usingReRank` configuration is active.
- Test retrieval by batch number, confirm that only documents such as coating batch sheets and paint mixing records for the corresponding batch are returned, and confirm that the grouping configuration for `collectionIds` is effective.

The values provided are common starting points and should be measured against the reader's own samples.
