# Inspection and Process Record Audit for Continuous Basic Chemical Production: Source Citation and Traceability

## What data for this category looks like
Daily documents for the continuous basic chemical production category include standard operating procedures, process index cards, DCS trends, laboratory reports, interlock bypass records, special work permits, and shift logs.
Data sources include DCS/SIS, online analyzers, LIMS, equipment status monitoring, energy metering systems, and raw material storage tanks.
Data updates occur in real time, per shift, and daily.
All data fields include clear unit identifiers: process pressure uses MPa, temperature uses ℃, and material flow uses t/h.
Laboratory data includes sampling time and pass/fail thresholds.
Interlock records list trigger conditions and action times.

## What constraints do these characteristics impose on source citation and traceability
Real-time DCS trends and online analyzer data require exact timestamp matching during traceability. This ensures cited data corresponds to the current inspection node.
Shift-based and daily shift logs, plus laboratory reports, must be associated and cited by production batch. This prevents cross-batch data mixing.
Dispersed multi-source data requires integrating document formats and field rules across different systems. This unifies traceability matching logic.
Process parameter fields with units need unit consistency verification during matching. This prevents confusing same-name parameter data with different magnitudes.
Critical interlock records require binding equipment, time, and action information when cited. This meets compliance audit traceability requirements.

## Configuration Settings
| Config Item | Suggested Value | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Matches natural segment breaks for process procedures and DCS trend fragments, avoids truncating critical parameters and logical descriptions |
| Overlap Length | 100–200 characters | Covers cross-block interlock logic and process association information, prevents loss of critical context during traceability |
| Similarity Threshold | 0.75–0.85 | Verifies consistency of parameter units, prevents accidental matching of same-name parameter data with different magnitudes |
| `quoteMaxToken` | 3500–4500 token | Limits total length of a single round of citations, adapts to complete citation needs for long documents, avoids context overflow |
| `responseData` | Only return documents with verification marks | Filters expired archived data, ensures cited documents are valid for the current production cycle |
| `detail` | Display full citation fields | Shows details like sampling time and pass thresholds for laboratory data, meets full information requirements for audit traceability |

## Three Common Misconfigurations
- Phenomenon: Knowledge base return results are sorted unexpectedly, not presented by match degree to inspection questions.
  Cause: Similarity matching rules were not adjusted for the unit characteristics of basic chemical data, resulting in mixed priority levels for same-name parameter data with different units.
- Phenomenon: Unmatched local knowledge base citation entries are displayed in conversations.
  Cause: Redundant citation switches were not disabled, and expired data from offline archives was not filtered.
- Phenomenon: After calling multiple knowledge base branches, results from different categories do not use unified citation formats.
  Cause: A unified citation merging node was not configured in the workflow, leading to inconsistent traceability display formats across branches.

## How to Confirm Configuration Is Complete
- Upload a DCS trend document containing process pressure data marked with MPa units. Initiate a process verification request in the FastGPT v4.17.0 environment. Confirm that returned citations include correct unit identifiers and timestamps.
- Initiate an audit request containing interlock bypass records. Confirm that returned citations include trigger conditions, action time, and equipment number fields.
- Adjust the `quoteMaxToken` parameter value. Verify that the total length of returned citations falls within the set range.
- Disable the citation display switch. Initiate a test request. Confirm that knowledge base citation entries are no longer displayed in conversations.

The values listed above are common starting points. Adjust them based on your own specific samples and operational requirements.
