# Inspection and Process Record Audit for Plastic Injection Molding: HTTP Interfaces and External Systems
This document applies to FastGPT v4.17.0.

## What this category of data looks like
This category of data covers documents including injection molding process cards, raw material drying records, mold history, first-piece inspection reports, patrol inspection forms, and material change and machine cleaning logs. Data comes from resin batches and property sheets, injection molding machine parameters, mold temperature machines, MES systems, and dimensional and appearance inspection equipment. Data updates occur per production batch, each mold or material change, and at the end of each shift. Fields include batch number, mold number, raw material moisture content, process temperature and pressure parameters, inspection results, and more. Units include degrees Celsius, megapascals, seconds, and other standard industry units.

## What constraints these characteristics impose on HTTP interfaces and external systems
Data for this category is tightly linked to production batches and molds. Updates happen per batch, mold/material change, and shift end. As a result, HTTP interfaces must pull business data for a specific batch using unique identifiers to avoid mixing data across batches. Field formats vary across different data sources. Interfaces must accommodate return structures from heterogeneous systems, and support flexible field mapping rules. Injection molding process parameters are collected on a fixed cycle. Interface timeout settings must match this cycle to avoid interrupting data pulling workflows. Inspection and audit workflows rely on accurate business fields. Interfaces must support basic data validation to ensure fields conform to injection molding business definitions.

## How to set the configurations
| Configuration Item | Recommended Approach | Rationale |
| ---- | ---- | ---- |
| `Authorization` | `Bearer ${bound external system API key}` | Complies with HTTP interface standard authentication formats and meets the authentication requirements of systems such as injection molding machines and MES |
| `variables` | `{"batchId": "", "moldSerial": ""}` | Binds injection molding batches and mold numbers, matches the association rules of business data, and facilitates pulling inspection records by batch |
| `responseData` | `$.records[*]` | Accommodates the nested structure of inspection data returned by most injection molding equipment, extracts valid fields for audit workflows |
| Request timeout setting | `30–60 seconds` | Aligns with the collection cycle of injection molding process parameters, prevents data pulling from being interrupted by network delays |
| Field mapping rules | Set based on actual measurements | Field names returned by different injection molding equipment vary, so they must match the field definitions of local business documents |

## Three common errors
- Symptom: The external system returns a message indicating a receiving address verification failure. Cause: The interface was not deployed in a publicly accessible environment, or the SSL certificate verification option was not configured correctly.
- Symptom: The interface call returns an empty inspection record list. Cause: Correct batch number or mold number was not passed via `variables`, so corresponding business data cannot be matched.
- Symptom: The interface returns a 403 Forbidden status code. Cause: The `Authorization` parameter was not configured correctly, or an expired external system API key was used.

## How to confirm the configuration is complete
- Call the configured HTTP interface, and check if the returned `responseData` includes expected injection molding inspection record fields.
- Pass test batch numbers and mold numbers to verify the interface returns business data for the corresponding batch.
- Check if the `Authorization` parameter format follows the standard Bearer token specification, and confirm authentication passes.
- Simulate an external system triggering a callback to verify the interface can receive and process data normally.

The values provided here are common starting points and should be measured against the reader's own samples.
