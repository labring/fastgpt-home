# Inspection and Process Record Audit for Plastic Injection Molding: Source Citation and Traceability

## What this category's data looks like
The core entities of this category are manufacturers of injection molded parts, automotive interior components, home appliances, and medical plastic products. Daily documents include injection molding process cards, raw material drying records, mold history logs, first article inspection forms, patrol inspection forms, and material change and machine cleaning records.
Data sources cover resin batches and property sheets, injection molding machine parameters, mold temperature controller data, MES systems, and dimensional and appearance inspection results. Updates occur for every production batch, each mold or material change, and each shift patrol.
Document fields include pressure parameters measured in MPa, temperature parameters measured in ℃, time parameters measured in s, plus identification fields such as batch number, machine number, and defect type.

## What constraints these characteristics impose on the source citation and traceability workflow
This category has high data update frequency, and data is linked to key production stages such as production batches, mold changes, and material changes. Traceability results must accurately match the latest production records.
Multiple document types have significant field differences, so categorized recall and association by document type must be supported.
Data sources include direct device-collected data and system-entered data, so compatibility with metadata extraction from multiple data sources is required.
Traceability errors may lead to batch defects, mold damage, or even safety incidents. Full association of production and inspection records across all stages is therefore necessary to avoid missing key information.

## Configuration Settings
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 1500–2000 token | Matches the average length of single documents such as injection molding process cards and patrol inspection forms, ensuring complete citation of key parameters from a single source dataset |
| `responseData` | Enable source document metadata fields | Meets the requirement to associate business identification fields such as resin batch numbers, machine numbers, and inspection times during traceability |
| `detail` | Enable full document fragment citation | Prevents truncation of core content that affects inspection judgments, such as holding pressure time and mold temperature parameters |
| Maximum context length | 8000–10000 characters | Covers all associated records for a single mold change or shift, supporting cross-stage traceability across multiple documents |
| Single search limit | Top 6 results | Balances recall efficiency and traceability completeness, matching the typical number of records for shift patrols and material changes |

## Three Common Misconfigurations
- Symptom: Returns cited content even when the citation switch is disabled. Cause: There is a version compatibility issue with FastGPT v4.17.0, or the knowledge base citation configuration is overwritten by the global default settings.
- Symptom: Returned cited content is truncated, and complete process parameters cannot be displayed. Cause: The value of `quoteMaxToken` is too small, which does not match the document length of the injection molding process card, leading to loss of key information.
- Symptom: Unable to associate resin batch and property sheet information. Cause: No metadata mapping rule for source documents is configured in the knowledge base, so traceability identification fields such as batch numbers cannot be extracted.

## How to Verify Proper Configuration
- Import a single injection molding process card document, initiate a query that includes process parameters, and check whether the returned results include complete parameter fragments and document metadata.
- Initiate a query related to resin batches, and verify whether the returned results include traceability fields such as resin batch numbers and property sheet information.
- Adjust the value of `quoteMaxToken`, observe whether the length of the returned citation fragments meets expectations, and confirm that there is no truncation or overflow.
- Check the system logs for FastGPT v4.17.0, and confirm that the metadata of source documents has been correctly loaded and associated with the question-and-answer results.

The values provided are common starting points and should be measured against the reader's own samples.
