# Inspection and Process Record Audit for Safety, Environmental Protection and Special Work Management: Citation Source and Traceability

## What This Category of Data Consists Of
Data for this category comes from EHS departments and production inspection and maintenance teams of manufacturing enterprises across chemical, metallurgical, machinery, light industry and other sectors. It includes risk identification documents, work permits for hot work, confined space work, lifting operations and similar tasks, hazardous waste ledgers, emission monitoring records, personnel qualification documents, equipment isolation lists and more.
Data sources cover public regulations and standards, online environmental monitoring systems, gas detectors, personnel qualification databases, equipment management platforms and regulatory end interfaces.
Update frequencies include immediate updates upon completion of each job, real-time pushes for monitoring data, and regular verification of qualification and compliance documents.
Each individual document includes fields such as job number, monitoring value, qualification validity period, isolation status and others, using standard units related to compliance metering.

## Constraints for Citation Source and Traceability
Multi-source, heterogeneous data sources require traceability systems to support unified association across local documents, hardware interfaces and online platforms, to prevent source confusion.
High-frequency data updates require traceability results to match the latest job and monitoring data, and cannot rely on static caching.
The specialized, compliance-focused nature of document fields requires traceability to accurately map original fields, without omitting key compliance information such as job ticket numbers and monitoring thresholds.
Additionally, the high-risk nature of this category requires traceability results to be fully traceable, retaining complete original data source identifiers and verification information to enable verifiable audit processes.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | Typical text length of work tickets and monitoring records, ensuring coverage of core audit information |
| `responseData` | Retain original field mapping | Must fully display compliance fields such as job number and monitoring value to meet traceability audit requirements |
| `detail` | Enable precise recall | This category requires matching high-confidence compliance documents to avoid irrelevant content interfering with audits |
| Single recall count | Top 8–12 entries | Job audit needs to associate 3-5 core documents, avoiding excessive redundant information |
| Multi-source data recall switch | Enabled | Data sources include online platforms, hardware interfaces and local documents, which must be included in the traceability scope |
| Traceability information display level | Display source path and verification time | High-risk scenarios require complete display of compliance verification traces for data |

## Three Common Misconfigurations
- Issue: When calling a query, it is not possible to set a citation limit of around 300, only fixed options of 100 or 900 are available. Cause: Did not use the `quoteMaxToken` parameter for custom adjustment, and directly used the fixed gear configuration from the interface.
- Issue: The search results do not include real-time data from the online environmental monitoring platform. Cause: Did not enable the multi-source data recall switch, only recalled static documents stored locally.
- Issue: The detection time field of the gas detector is missing from the traceability results. Cause: Did not configure the original field retention rules for `responseData`, only returned summarized text content.

## How to Verify Successful Configuration
- Initiate a query that includes a specific job ticket number, check whether the returned results are associated with the corresponding risk identification documents and job permission records.
- View the traceability module, confirm whether the source path and verification time information of the original data are displayed.
- Adjust the `quoteMaxToken` parameter, verify whether the length of the returned reference text matches the expected compliance document range.
- Import real-time monitoring data in FastGPT v4.17.0, confirm whether the search results include the latest monitoring values and update times.
