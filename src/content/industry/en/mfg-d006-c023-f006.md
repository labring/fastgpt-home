# Inspection and Process Record Audit for Industrial Instrument Manufacturing and Calibration: Source Citation and Traceability

## What This Category of Data Looks Like
Core data for this category comes from daily business documents of flow, pressure, temperature, and analytical instrument manufacturers and metrology laboratories. These documents include assembly and commissioning sheets, calibration procedures, original calibration records, error curves, metrology certificates, and software version logs. Data sources include design documents, reference instruments, environmental monitoring data, calibration software, laboratory information systems, and customer range requirements. New records are generated each time an instrument is calibrated, so update frequency is per calibration per instrument. Document structures include fixed fields: tested part number, calibration date, reference instrument number, error value with corresponding physical unit such as Pa, ℃, MPa, metrology certificate number, and more. Single document lengths range from hundreds to thousands of characters.

## Constraints Imposed on Source Citation and Traceability
Data sources for this category are scattered, and update frequency is high. The citation and traceability link must support multi-source knowledge base association and incremental synchronization. Document fields are fixed and strongly tied to metrology compliance. Citations must accurately match key fields such as tested part number and metrology certificate number. Generalized citations are not allowed. Calibration records and metrology certificates for a single instrument are strongly bound. The traceability link must fully associate both document types. Failing to do so will result in failed metrology audits. Data updates frequently. The system must ensure retrieved documents are the latest version. Expired records must not be cited.

The following configuration applies to FastGPT v4.17.0.

## How to Set Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Number of associated knowledge bases | Up to 8 | Documents for this category such as calibration records and metrology certificates fall into different types. Too many associations will cause context redundancy |
| Maximum number of retrievals per request | Top 6 entries | Key calibration information is concentrated in a small number of documents. Too many retrievals will interfere with the large language model's judgment of the traceability chain |
| `quoteMaxToken` | 800–1200 token | Calibration records and metrology certificates have relatively long content. Sufficient original text fragments must be retained for traceability |
| Response data output switch | Enabled | Document names and field information for cited sources must be clearly displayed |
| `detail` | Enable detailed mode | Full traceability links must be displayed, including key information such as reference instrument number and calibration date |
| `responseData` | Include original citation fragments | Original text fragments must be retained for subsequent compliance verification and traceability checks |

## Three Common Configuration Errors
- Symptom: Output does not display document names or key fields for cited sources. Cause: Response data output switch is not enabled, and `responseData` parameter is not configured.
- Symptom: Original uploaded calibration record documents cannot be traced from output content. Cause: `detail` parameter is not enabled, detailed traceability mode is not turned on, and only generalized conclusions are returned.
- Symptom: Configuration cannot be saved after associating more than 8 knowledge bases. Cause: Association upper limit is not set reasonably based on the number of document types for the category, exceeding preset limits.

## How to Verify Correct Configuration Setup
- Initiate a query for calibration records of a single instrument. Check if the output includes specific names of cited documents.
- Review the designated area of the output content. Confirm that original cited fragment content is displayed.
- Attempt to associate 9 knowledge bases. Verify if the system prompts a configuration limit exceeded message, confirming the association upper limit is active.
- Initiate a query that includes error values. Check if the output matches specific values and units from the original document.

The values given are common starting points and should be measured against the reader's own samples.
