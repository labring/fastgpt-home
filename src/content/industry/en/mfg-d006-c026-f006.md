# Inspection and Process Record Audit for Non-Ferrous Metal Smelting and Electrolysis: Source Citation and Traceability

## What this category of data looks like
Data for this category mainly originates from concentrate and auxiliary material analysis reports, production DCS systems, electrolyzer voltage and current monitoring, laboratory test results, and energy and environmental monitoring equipment. Daily documentation includes batching lists, smelting records, electrolyzer condition records, test reports, anode and cathode quality records, and environmental protection ledgers. Data update frequencies cover each batch of raw material feeding, each furnace smelting cycle, and real-time operating conditions of each cell. Document fields include raw material feeding amount, cell voltage, current value, metal component content, environmental emission indicators, and similar metrics, with corresponding units of tons, volts, kiloamps, grams per liter, milligrams per cubic meter, and other standard units.

## What constraints do these characteristics impose on the "source citation and traceability" link
The multi-source, heterogeneous data characteristics of this category require that the citation and traceability process must associate records from different sources using production batches and electrolyzer numbers. The update rhythms of different data sources vary significantly, so timestamps must be accurately matched to avoid mixing data across time periods. The diversity of document fields and units requires automatic association of unit identifiers for corresponding fields during traceability to ensure consistency in data comparison. The full end-to-end production relevance requires traceability to cover the complete process from raw material feeding, smelting to electrolytic finished products, supporting the verification needs of metal balance and impurity control.

## Three common configuration errors
- Scenario: After the workflow is invoked, the answer still displays the input and response citation content from the knowledge base search. Cause: The configuration for disabling citation display was not turned off in the workflow node, resulting in redundant information from the search process being retained by default.
- Scenario: No optional values appear in the citation variable dropdown menu of the knowledge base search node, making it impossible to dynamically specify the target knowledge base. Cause: The identification variable for the corresponding knowledge base was not configured in advance in the global variables, or the variable type did not match the string format required by the node.
- Scenario: Traceability records from different production batches cannot be distinguished in MongoDB logs. Cause: Unique identification fields such as production batch and cell number were not added when writing logs, resulting in confusion between records from different batches.

## How to verify successful configuration
- Initiate a query simulating a production batch, check that the answer only displays the required citation source fields, with no redundant search process content.
- In the knowledge base search node of the workflow, select variable application, confirm that the citation variable dropdown menu displays the pre-configured global variable options.
- View the MongoDB logs, confirm that each traceability record includes unique identification fields such as production batch and cell number, and records from the corresponding batch can be filtered by the identifiers.
- Verify the fields and units of the cited content, confirm that they match the fields and units of actual production documents.
