# Inspection and Process Record Audit for Rubber Mixing and Product Vulcanization: Source Citation and Traceability

## What This Category’s Data Looks Like
Daily documents for this category include formula sheets, weighing records, mixing curves, rubber compound quick test reports, vulcanization process cards, mold usage records, finished product performance reports, and more. Data sources cover formula management systems, raw material batch ledgers, internal mixers, Mooney viscometers, vulcanizers, and laboratory testing equipment.
Data is updated once per truck of raw materials, each batch of rubber compound, and each mold run of products, generating a corresponding document each time. Single document fields include rubber type ratio, feeding sequence, temperature curve, vulcanization duration, pressure parameters, and more, with unique identifier fields such as batch number, mold run ID, operating personnel, and testing time. Units include commonly used industrial units such as degrees Celsius, minutes, and megapascals.

## What Constraints These Characteristics Impose on Source Citation and Traceability
This category has high data update frequency, with each batch or mold run corresponding to multiple types of documents. This requires the traceability system to retrieve newly generated documents in real time, to avoid citing expired or mismatched batch data.
There are large differences in fields across multiple document types, so different retrieval and matching rules must be configured per document category to ensure key information such as batch number and mold run ID is accurately identified.
Data sources cover industrial equipment and management systems, and formats vary across different data sources, so unified identifier fields are required for cross-source traceability.
At the same time, audit errors can lead to rubber compound scrap or product failure, so the accuracy and completeness of traceability results must meet high standards.

## Configuration Settings
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 8000–12000 token | Matches the average content length of a single mixing curve or vulcanization process card, to avoid truncating critical parameters |
| `responseData` | Enabled | Requires synchronous return of associated information required for traceability, such as raw material batches and internal mixer parameters |
| `detail` | Expand by document type | Differentiates display formats for different documents such as formula sheets and weighing records, to facilitate auditors' verification |
| Single recall limit | Top 6 entries | Adapts to the number of documents generated per mold run, to avoid excessive redundant data affecting response speed |
| Retrieval filter rules | Match by batch number / mold run ID | Ensures only documents corresponding to the current audit batch are retrieved, to avoid cross-batch confusion |

## Three Common Misconfigurations
- No citation content is returned after connecting the knowledge base in the workflow tool call module. The symptom is the tool returns empty results or the interface prompts "No matching documents found". The cause is that the retrieval keyword is not bound to the batch number or mold run ID of the current audit batch, making it impossible to locate documents for the corresponding batch.
- Retrieval response timeout occurs. The symptom is the conversation returns a 504 status code or the system prompts "Request timed out". The cause is that the `quoteMaxToken` setting is too high, and the single-transmission token volume exceeds the system processing limit.
- Audit results are associated with incorrect documents. The symptom is the returned reference documents belong to rubber compound from other batches. The cause is that the retrieval result filter rule by batch number is not configured, leading to recall of irrelevant historical data.

## How to Verify Proper Configuration
- Submit an audit request containing a known batch number, and check whether the returned reference documents include content such as weighing records and mixing curves for the corresponding batch.
- View the system retrieval log to confirm that the token volume transmitted per retrieval does not exceed the range set by the `quoteMaxToken` configuration.
- Test retrieval scenarios across multiple document types, confirm that different categories of documents can be retrieved and displayed separately according to the configured rules.
- Check the returned `responseData` field to confirm that all information required for traceability is included, such as raw material batches and testing parameters.

The values provided here are common starting points, and should be evaluated against the reader's own samples.
