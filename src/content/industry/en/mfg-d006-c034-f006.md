# Inspection and Process Record Audit for Baking and Convenience Food: Source Citation and Traceability

This document is written based on FastGPT v4.17.0.

## What data for this category looks like
Typical entities in this category are bread and pastry, biscuit, instant noodle, and frozen pastry factories. Daily generated documents include formulas and feeding lists, production records, baking or steaming curves, metal detection records, cleaning and disinfection records, and factory inspection reports. Data sources cover raw and auxiliary material qualification certificates, ERP/MES systems, weighing systems, ovens or frying lines, laboratory test data, and food traceability ledgers. Data updates are performed per batch, per shift, or daily. Core fields include material batch numbers, temperature and humidity parameters, test results, packaging dates, and allergen labeling information.

## What constraints do these characteristics impose on the source citation and traceability link
The multi-batch, high-frequency update feature of this category requires the traceability link to support quick location of associated documents by production batch. Strong compliance requirements for allergens and formulas mean source citations must accurately match qualification certificates and production records for corresponding materials, to avoid cross-batch confusion. In multi-document association scenarios, traceability results must be able to link multiple types of data such as feeding, testing, and production curves. The ready-to-eat attribute of products also strengthens the rigor of traceability for foreign matter, shelf life, and other fields. Invalid cross-category data citations must be restricted to ensure audit results comply with food production compliance requirements.

## Configuration settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | Adapt to the total length of production-related documents for a single batch, ensuring complete recall of information required for traceability |
| `responseData` | Includes file names, batch numbers, and test result fields | Align with the quick viewing needs of frontline factory audit personnel, focusing on core traceability content |
| `detail` | Enabled | Support expanding to view the full content of a single document, used for accurate review of allergens and formulas |
| Single search limit | Top 5 entries | Cover multiple types of documents related to a single batch including feeding, testing, cleaning, etc., avoiding interference from redundant information |
| Context recall window | 24 hours | Match the update rhythm of this category per shift or per day, ensuring recall of the latest data from the current day or batch |

## Three common mistakes
- Error prompt `quote type error` appears, and citation content cannot be returned normally. The cause is that the input variable format does not meet configuration requirements, and corresponding fields such as production batch and document type are not correctly bound. This prevents the system from identifying traceability association relationships.
- Search results only return a single document, and cannot associate multiple types of production data. The cause is that batch-based screening recall rules are not configured. This causes the recall range to cover all documents, making it impossible to accurately match information for the current audit batch.
- Cited content is truncated incompletely, and complete baking curve data cannot be viewed. The cause is that the `quoteMaxToken` setting value is too small, truncating associated information for single-batch production records and test reports.

## How to confirm the configuration is correct
- Upload documents for a single batch including formulas, metal detection records, and production records. Initiate an inspection and audit request, then check whether the returned citation list only includes associated documents for this batch.
- Click a citation entry, confirm that full document field content can be expanded for viewing, with no truncation or missing content.
- Enter allergen review-related questions, check whether returned citations include qualification certificates and feeding records for corresponding raw and auxiliary materials.
- Check the system log, confirm that no `quote type error` type errors appear, and that request responses meet business expectations.

The values provided are common starting points and should be measured against the reader's own samples.
