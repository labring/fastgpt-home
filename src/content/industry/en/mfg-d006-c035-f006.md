# Heat Treatment Inspection and Process Record Review: Citation Source and Traceability

## What the Data for This Category Looks Like
Business data for heat treatment scenarios comes from material grade archives, customer technical requirement documents, temperature control instruments, furnace temperature uniformity testing equipment, hardness testers, metallographic testing equipment, and workshop MES systems. Data updates occur per furnace charge and per batch. Business documents associated with a single furnace charge include heat treatment process cards, charging charts, furnace temperature curves, hardness and metallographic reports, equipment inspection sheets, and exception handling forms. Document fields cover heating temperature, holding duration, cooling rate, test values, timestamps, and more. Units include degrees Celsius, minutes, megapascals, and others. Some documents are chart formats with coordinate axes.

## What Constraints These Characteristics Impose on the Citation Source and Traceability Link
Single furnace charge business data is unique. The traceability link must accurately bind a unique furnace charge identifier to avoid cross-batch data confusion. The coexistence of multiple document types requires the traceability system to support simultaneous recall and display of structured text and chart data. Strict requirements for fields and units mean traceability results must match the units and numerical precision of corresponding fields to ensure review accuracy. Data sources come from multiple types of equipment and systems, so data connection stability must be guaranteed to avoid data loss during traceability.

## How to Set the Configuration
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| Maximum Context | 1.2 times the total character count of documents associated with a single furnace charge, calibrated via actual measurement | Documents associated with a single furnace charge include process cards, furnace temperature curves, reports, and more. Total character volume varies widely, so this approach ensures all associated data is covered |
| `quoteMaxToken` | 8000–12000 token | Total token count of documents associated with a single furnace charge typically falls within this range, preventing truncation of valid traceability information |
| `responseData` | Enable structured field mapping | Heat treatment data includes structured fields such as temperature and duration. Enabling this allows precise matching of traceability fields |
| `detail` | Enable full source display | Details such as timestamps for furnace temperature curves and test dates for hardness reports must be displayed to meet traceability review requirements |
| Single Search Limit | Top 6 associated documents | Documents associated with a single furnace charge typically do not exceed 6 categories, covering all business documents |
| Reranking | Sort by document-associated furnace charge ID | Ensure documents from the same furnace charge are recalled first, improving traceability accuracy |

## Three Common Mistakes
- Phenomenon: The generated traceability result does not include the timestamp field of the furnace temperature curve. Cause: The `detail` configuration item was not enabled, resulting in only document titles being returned without structured details.
- Phenomenon: After enabling the configuration variable reference function, the temperature parameter setting button disappears, and parameters cannot be adjusted. Cause: When enabling `responseData` mapping, the parameter entry for the temperature field was not correctly bound, resulting in the configuration entry being overwritten.
- Phenomenon: Recalled documents span multiple furnace charges, making it impossible to accurately locate traceability data for the current review batch. Cause: No sorting by furnace charge ID was set as the reranking basis, resulting in recalled results mixing documents from different batches.

## How to Confirm the Configuration is Correct
- Upload all associated documents for a single furnace charge, trigger a traceability query, and check if the returned results include all associated document types.
- View the details of the traceability result to confirm that structured fields such as temperature and timestamps are included, and that units match business requirements.
- Test queries for documents across furnace charges, confirm that only associated data for the specified furnace charge is recalled, with no mixed content.
- In FastGPT v4.17.0, adjust the value of `quoteMaxToken` and check whether key traceability information is truncated.

The values provided are common starting points and should be measured against the reader's own samples.
