# Inspection and Process Record Review for Electric Motor and Generator Manufacturing: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Data for this category comes from electromagnetic design databases, copper wire and insulation material batch ledgers, winding equipment operation logs, balancing machine test data, electrical test bench reports, and ERP/MES systems. Daily produced documents include winding process cards, insulation treatment records, dynamic balance reports, withstand voltage insulation test records, and type and factory inspection reports. Data is updated per individual motor unit and production batch, and synchronized after each product type change. Document fields include winding turns, insulation layer thickness, test voltage value, temperature rise value, and other related items, with corresponding units of turns, millimeters, kilovolts, and degrees Celsius.

## What constraints these characteristics impose on the knowledge base retrieval and recall link
Since data is updated per single unit or single production batch and refreshed synchronously with product type changes, knowledge base recall must prioritize matching the latest batch of materials, equipment, and test data to avoid using expired process or test parameters. Category documents cover multiple types of professional documents such as process cards and test reports, and include three categories of professional fields: electromagnetic, insulation, and mechanical balance. Retrieval must support precise field matching across different document types. Additionally, data sources cover equipment logs and management systems, and field formats vary across different sources. Unified field standardization processing must be completed before recall to ensure retrieval results can be directly used for the review link. The review link has extremely high requirements for result accuracy; incorrectly recalled low-relevance documents may lead to inspection errors, causing issues such as winding burnout and insulation breakdown.

## Three common mistakes
- Query read timeout error occurs. The cause is that retrieval timeout settings are not adjusted for long documents in electric motor manufacturing such as type test reports, leading to timeout when loading large-volume documents.
- No search results are returned after passing the knowledge base ID. The cause is that the bound `collectionIds` configuration is not associated with the corresponding winding and testing department knowledge bases, or `searchMode` is set to fuzzy matching causing professional fields to fail to hit.
- The `apiCollection` interface returns Invalid URL, code: 500. The cause is that the correct interface path is not used when uploading knowledge base files, or the uploaded document format cannot be parsed, leading to interface call failure.

## How to confirm the configuration is correct
- Retrieve content related to winding turns, and check whether the recalled results include the latest batch of copper wire insulation material parameters.
- Trigger knowledge base retrieval, and check whether the returned results are sorted to prioritize displaying test reports related to dynamic balance and withstand voltage tests.
- Call the external interface with the correct `collectionIds` to verify that document data from the corresponding department can be obtained.
- Simulate a timeout scenario to confirm that the retrieval request returns results within a reasonable duration without Query read timeout errors.
