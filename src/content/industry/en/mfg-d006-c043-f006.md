# Inspection and Process Record Review for Fine Chemical Batch Synthesis: Citation Sourcing and Traceability

## What the data for this category looks like
The business data for this category comes from the formula and process library, raw material batch ledger, reactor DCS system, weighing record system, LIMS laboratory management system, and warehouse management system. The system updates data per product batch. It generates independent documents for each critical reaction step, feeding operation, and site cleaning routine. Daily documents include batch production instructions, feeding verification slips, reaction process records, site cleaning records, inspection reports, and deviation and change orders. Fields include batch number, feeding amount (kg/L), reaction temperature (℃), reaction duration (hours), and other related items. Multiple document types for each batch are interlinked.

## What constraints do these characteristics impose on citation sourcing and traceability
Multiple documents linked to the same batch require that citation traceability accurately matches batch numbers to avoid referencing unrelated data across batches. The step-by-step update rhythm requires the system to pull the latest reaction and feeding records for the current batch in real time, ensuring review basis is up to date. The existence of multiple document types requires that the configuration supports filtering by document type, only calling documents related to inspection, feeding, and reaction processes. Additionally, the requirement for formula confidentiality requires that traceability limits access scope, only allowing calls to authorized document copies to prevent leakage of core process information.

## How to set up the configuration
Configuration instructions under FastGPT v4.17.0 are as follows:

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Maximum single search count | Top 10 entries | Matches the number of documents per batch and multi-step process for this category, covering records of all critical process steps |
| `quoteMaxToken` | 8000 token | Adapts to the stitching needs of multiple long documents, avoiding truncation of critical feeding and reaction data |
| `responseData` | Enabled | Requires the system to return specific document metadata for citation sources, facilitating subsequent traceability verification |
| `detail` | Enabled | Displays specific fragments of cited content, assisting reviewers in verifying data accuracy |
| Maximum context size | 12000 characters | Accommodates linked document content for the full process of a single batch, ensuring complete review logic |

## Three common misconfigurations
- Symptom: In the workspace knowledge base application, only 1 citation result is returned per retrieval, and the interface displays "Knowledge base citations (1 entry)". Cause: The maximum single search count configuration was not adjusted. The system’s default recalled document count is insufficient to cover linked documents for multi-step processes of this category’s single batch.
- Symptom: After importing a preset knowledge base, the specified collection is empty and requires manual re-selection. Cause: The default associated path for the knowledge base was not configured. The system cannot automatically load the knowledge base collection matching the current batch.
- Symptom: Clicking the download button for citation sources has no response, and cited content cannot be exported. Cause: The `responseData` configuration was not enabled. The system did not return downloadable metadata links, making it impossible to obtain complete information about citation sources.

## How to confirm the configuration is correct
- Initiate an inspection and review query for a specific product batch, check the citation source list in the returned results, and confirm that it includes three or more linked documents of feeding, reaction, and inspection types.
- Check whether the returned content contains complete cited fragments, with no truncation of critical data such as feeding amount, reaction temperature, and other core parameters.
- Verify that the metadata of citation sources includes batch number and document type fields, ensuring they match the batch information currently being reviewed.
- Attempt to download the metadata file for citation sources, confirming that links or detailed content for the corresponding documents can be obtained normally.
