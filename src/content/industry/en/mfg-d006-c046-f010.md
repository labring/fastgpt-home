# Inspection and Process Record Audit for Meat Products and Slaughter Processing: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Typical data sources for this category include animal quarantine information, supplier batches, production traceability, temperature collection, metal detection, and laboratory test results. Daily documents include quarantine certificates, slaughter and cutting records, ingredient marinating records, thermal processing records, cold chain temperature records, and microbial test reports. Data updates occur per batch and per shift. Continuous temperature control data updates every 15 minutes. Document fields include batch identifiers, temperature values, test indicators, quarantine numbers, and more. Temperature values use degrees Celsius as the unit, and microbial test indicators use colony-forming units as the unit.

## What constraints these characteristics impose on knowledge base retrieval and recall
Category data updates by batch and production time period. Retrieval must limit batch and time ranges to avoid retrieving irrelevant records across batches. Multiple types of specialized documents must be stored separately by document type. Retrieval must limit to dedicated document collections to prevent mixing in irrelevant administrative content. Specialized fields and units for continuous temperature control and microbial testing require retrieval to match specialized terminology, avoiding low-relevance content from being retrieved. Data ties to compliance risks. The accuracy of retrieval results directly affects audit efficiency and compliance, so irrelevant content must be strictly filtered.

## How to configure the system
The following configurations are based on the parameter logic of FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| ---- | ---- | ---- |
| `similarity` | `0.78–0.82` | Meat product inspection-related documents contain specialized terminology and strict compliance requirements, so low-match irrelevant content must be filtered |
| `limit` | `Top 5` | The total number of inspection and process records for a single batch production is limited. Limiting the number of retrieved entries reduces token usage and improves retrieval efficiency |
| `usingReRank` | Enabled | Category data has multiple field associations including batch, temperature, and test results. Re-ranking improves the ranking priority of highly relevant results |
| `datasetSearchUsingExtensionQuery` | Enabled | User queries may omit metadata such as batch numbers. Extended queries supplement associated fields to improve matching accuracy |
| `collectionIds` | Bind dedicated collections for quarantine records, production records, and cold chain records | Category data is stored separately by document type. Limiting collections excludes irrelevant corporate administrative documents |

## Three common configuration mistakes
- Phenomenon: Retrieval results include cold chain temperature records across batches, and irrelevant content cannot be filtered. Cause: The `collectionIds` dedicated document collection is not configured, or metadata filtering logic is not enabled.
- Phenomenon: An internet search triggers after knowledge base retrieval returns no results, and the returned content is casual chat irrelevant to inspection and audit. Cause: No trigger condition based on knowledge base matching results is set, or the trigger logic is not bound to category-specific business keywords.
- Phenomenon: The AI reply forcibly displays knowledge base citation markers and cannot be turned off. Cause: The citation display switch is not turned off in the retrieval configuration, or the logic to display citations only after successful matching is not configured.

## How to verify correct configuration
- Upload inspection records and quarantine certificates for a single batch, initiate an audit query for that batch, and confirm that retrieval results only include relevant documents for that batch.
- Adjust the `similarity` parameter value to verify that low-match irrelevant content is filtered.
- Initiate a query without clear batch information to confirm that `datasetSearchUsingExtensionQuery` automatically supplements batch-related retrieval conditions.
- Trigger a scenario where knowledge base retrieval returns no results, and confirm that subsequent internet searches or filtering logic activate according to the configuration.

The values provided are common starting points and should be measured against the reader's own samples.
