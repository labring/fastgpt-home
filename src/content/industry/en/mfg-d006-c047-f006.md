# Inspection and Process Record Audit for Measuring Instruments and Laboratory Management: Citation Sources and Traceability

## What data for this category looks like
This category of data comes from metrology management systems in enterprise metrology rooms and quality laboratories, external calibration institution certificates, standard instrument data, LIMS systems, and environmental monitoring records. Daily documents include gauge ledgers, calibration plans, calibration certificates, interim verification records, original test records, reference material ledgers, and deviation handling documents. Data is updated based on calibration cycles, single test results, or abnormal events. It includes unique instrument identifiers, calibration parameters, measurement results, and traceability chain association information. Fields and units align with general standard requirements for metrology and testing.

## What constraints do these characteristics impose on the citation sources and traceability link
Data sources are scattered, covering internal systems and external third-party documents. This requires the traceability link to support cross-data source association matching. The structure of different documents varies widely, so it is necessary to accurately identify exclusive fields for different file types such as calibration certificates and test records. Update rhythms change dynamically with calibration cycles and test events, so the system must adapt to non-fixed-frequency data source synchronization. The traceability chain must cover the complete link from instruments to test results to associated products. It is necessary to ensure that every cited metrology data point can be traced back to the original test document and calibration entity.

## How to set configurations
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | Matches the average length of a single calibration certificate or test record, to avoid truncating key traceability information such as measurement uncertainty |
| `responseData` | Enabled | Used to return metadata and source identifiers of cited documents, to meet traceability display requirements |
| `detail` | Full mode | Retains all field information of cited documents, to facilitate verification of core metrology and testing parameters |
| Single search citation limit | Top 3–5 entries | Matches the number of measuring instruments associated with a single round of inspection, to avoid redundant data exceeding the context token limit |
| Data source filtering rules | Filter by calibration validity period | Only include currently valid calibration certificates and test records, to ensure the validity of cited data |

## Three common misconfigurations
- Symptom: The published chat page does not display cited document sources, but the debug page displays normally. Cause: The `responseData` configuration item is not enabled, or the configured display logic only takes effect in the debug environment.
- Symptom: Knowledge base search results exceed the set citation limit, causing answer token overflow. Cause: The citation limit is set to an excessively high value that does not match the total length of metrology documents that a single round of conversation can carry.
- Symptom: The cited calibration certificate does not display the measurement uncertainty field. Cause: The `detail` full mode is not enabled, only summary information is extracted, and key parameters for metrology traceability are lost.

## How to verify correct configuration
- Submit a query related to measuring instrument calibration or testing, and check whether the reply includes source identifiers of cited documents.
- Check the token consumption of the reply, confirm that it does not exceed the preset context limit, and that the number of cited documents matches the configured limit.
- Export the cited original document fragments, and verify that core fields such as instrument number, calibration date, and measurement results are included.
- Test the same query on the published page, confirm that the citation sources are consistent with the content displayed in the debug environment.

The values provided are common starting points and should be evaluated against the reader's own samples.
