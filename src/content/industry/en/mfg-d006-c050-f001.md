# Inspection and Process Record Audit for General Mechanical Equipment Assembly: HTTP Interfaces and External Systems

## What Data for This Category Looks Like
Data for inspection and process record audit of general mechanical equipment assembly typically comes from PLM, ERP, parts inspection data collection systems, assembly torque tools, test benches, MES, and customer technical agreements.
Daily documents include assembly process cards, BOM lists, torque records, gap adjustment records, commissioning reports, factory inspection certificates, and packing lists.
Data is updated per device or order.
Fields cover device models, part numbers, torque values, gap parameters, test results, and other relevant metrics.
Common units include newton meters, millimeters, pascals, and other standard engineering units.

## Constraints Imposed by These Characteristics on HTTP Interfaces and External Systems
This category’s multi-order, single-device customization requirements mean HTTP interfaces must support precise data queries by device ID or order number.
Multi-source data access needs require interfaces to be compatible with field formats from different external systems.
Business identifiers must be passed via the `variables` parameter to match corresponding data.
Frequent updates to inspection records for single devices require interfaces to deliver fast response times.
The `Authorization` parameter must be used to secure data access.
Audit workflows rely on multi-dimensional data. The `responseData` returned by the interface must cover core fields such as assembly processes and inspection records.
Without these fields, the full audit workflow cannot be supported.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `Authorization` | `Bearer {custom secret key}, valid for 180 days` | Authenticate connections to external systems, prevent unauthorized access, and secure inspection and audit data |
| `variables` | `Includes device ID and order number, no more than 200 characters in length` | Adapt to business requirements for querying by single device or order, accurately match corresponding assembly records |
| `responseData` | `Returns assembly process card fields, torque records, gap adjustment values, test results, single record no more than 1500 characters` | Match the daily document structure of this category, meet the audit process's need for multi-dimensional data acquisition |
| Interface timeout setting | `600 seconds` | Adapt to the response time of multi-source data splicing, prevent call interruptions due to excessive data volume |

## Three Common Configuration Errors
- A 404 Not Found status code is returned during interface calls. Symptoms: Logs or interfaces show the path is inaccessible. Causes: The base path of the external system interface is not configured correctly, or the device ID or order number specified by the `variables` parameter is not included in the path.
- The interface returns empty results or no expected inspection data. Symptoms: No matching assembly records appear in audit tasks. Causes: The `variables` parameter does not pass the correct business identifier, or the parameter format does not meet interface requirements.
- The interface call succeeds, but the large language model cannot generate an audit conclusion. Symptoms: No valid output is produced after workflow execution. Causes: The fields returned by `responseData` do not include core audit data such as torque records and gap adjustment values, leading to insufficient context.

## How to Verify Successful Configuration
- Call the configured HTTP interface, and check if the returned `responseData` includes preset fields such as assembly process cards and torque records.
- Pass the correct device ID as the `variables` parameter, and confirm the interface returns assembly data for the corresponding order with no null values or missing items.
- Verify that the `Authorization` parameter format is correct, then call the interface to confirm a 200 OK status code is returned, with no identity verification related errors.
