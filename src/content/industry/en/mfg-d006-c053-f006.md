# Inspection and Process Record Audit for Iron and Steel Smelting and Continuous Casting: Source Citation and Traceability

## What Data for This Category Looks Like
Data for this category covers the full process of hot metal and scrap charging, converter smelting, and continuous casting. Data sources include the L2 process control system, laboratory test data, MES production management system, and energy medium and equipment status monitoring modules. Daily output documents include heat plans, batching lists, converter smelting records, composition reports, continuous casting process records, and slab judgment sheets. Fields include heat number, tapping temperature, carbon element detection value, casting speed, slab judgment result, and more. Units include degrees Celsius and meters per minute. Data updates occur per heat, in real time, and per shift.

## Constraints Imposed on Source Citation and Traceability by These Data Characteristics
This category’s data characteristics create multiple constraints for traceability workflows. Multi-source, heterogeneous data sources require unified heat number matching rules to prevent cross-system and cross-document traceability association errors. The high-frequency update rhythm requires traceability processes to support real-time data loading, and cannot rely on batch-synced offline datasets. Diverse document types require dedicated field extraction rules configured for each document type, to ensure accurate extraction of associated information from heat plans, smelting records, and continuous casting process records. The high-temperature continuous production characteristics require strict timeliness for traceability data. Expired process parameters cannot serve as valid traceability basis for current batches. The strong coupling relationship between heats and casting sequences requires traceability workflows to link records from both smelting and continuous casting stages, to avoid incomplete traceability caused by siloed processing.

## Configuration Recommendations
This configuration references the interface logic of FastGPT v4.17.0. Specific configuration items and recommendations are listed below:

| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | The character count of individual process records ranges from 300 to 600. This setting covers the full traceability content of a single complete document |
| `responseData` | Return only document IDs and links for associated heats | Focus on core traceability information to avoid interference from redundant data |
| `detail` | Enable full field display | Ensure no omission of key fields such as heat number and tapping temperature |
| Single recall limit | Top 8 entries | Covers the typical number of associated documents across smelting, laboratory, and continuous casting stages |
| Data timeliness filter | Retain real-time data from the last 2 hours | Aligns with the timeliness requirements of this category’s high-temperature continuous production, and filters expired invalid data |

## Three Common Configuration Mistakes
- Phenomenon: Irrelevant non-target heat documents appear in traceability results, and cannot be removed via configuration. Cause: No matching rule based on heat number is configured, leading to recall of documents from other batches.
- Phenomenon: Redundant citation annotations are embedded in generated traceability content, and cannot be cleared via configuration. Cause: Non-essential context citation switches are not disabled, leading to recall of content outside the associated scope.
- Phenomenon: Composition report fields in traceability results are empty, and carbon element detection values cannot be extracted. Cause: No dedicated field extraction rule is configured for laboratory documents, leading to failure to identify target fields.

## How to Verify Correct Configuration
- Input a single heat number, and verify that the recalled documents only include records from the smelting, continuous casting, and laboratory stages for that heat.
- Review the field completeness of traceability results, and confirm that core associated information such as heat number and tapping temperature is included.
- Test loading real-time process data, and confirm that traceability loading is completed within the set time range.
- Check generated traceability content, and confirm that only required associated documents are included, with no redundant non-relevant citations.

The values given are common starting points and should be measured against the reader's own samples.
