# Inspection and Process Record Audit for Sheet Metal Cutting and Bending: Workflow Orchestration

## What Data for This Category Looks Like
Daily documents for the sheet metal cutting and bending scenario include CAD unfolding drawings, CNC cutting programs, bending process cards, nesting drawings, first-piece inspection records, and process transfer cards. Data sources cover CAD/CAM software, order BOM systems, sheet metal inventory management modules, laser cutters, bending machine equipment logs, and workshop MES systems. Data update frequency aligns with order delivery, daily production scheduling, and each equipment changeover adjustment. Individual data entries include fields such as sheet thickness, bending compensation coefficient, cutting size, bending angle, and process transfer status. Units include millimeters, degrees, square meters, and other common machining units.

## What Constraints Do These Characteristics Impose on the "Workflow Orchestration" Link
The multi-variety, small-batch production nature of this category means each order has different document formats and parameter specifications. Workflow orchestration must support dynamic reading of business data from different sources, without using fixed templates. Data update frequency changes with orders and equipment changeovers, so workflow nodes must support on-demand triggering, rather than relying on fixed-cycle execution. The need for multi-data-source access requires workflow configurations to include cross-system connection verification logic, while adapting to network environment restrictions of workshop intranets. Additionally, core links such as bending sequence verification and compensation coefficient verification require dedicated verification nodes embedded in the workflow, to avoid subsequent assembly errors or sheet material waste. For example, when a new order is received, the workflow can automatically pull order BOM and CAD unfolding drawing data, verify the bending compensation coefficient, check the remaining material utilization rate of the nesting drawing, then sync the verification results to the MES system to complete the pre-audit before first-piece inspection.

## How to Configure
This document is written based on the workflow orchestration function of FastGPT v4.17.0. The following are configuration recommendations for this scenario.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Data source connection timeout | 300 seconds | Program transfer for sheet metal processing equipment and MES data pulling usually take 1 to 5 minutes. 300 seconds covers most normal transfer scenarios |
| `variables` definition | Include sheet thickness, bending compensation coefficient, order number | Processing parameters vary per order. Dynamically passing `variables` adapts to multi-variety, small-batch production needs |
| Question classification node background knowledge | Fill in common error types for sheet metal bending, such as hole position misalignment, bending angle deviation, remaining material waste, with a length of 500 to 800 characters | Helps quickly classify issues in inspection records, aligns with common error scenarios for this category |
| Database connection retry count | 3 times | Workshop intranet has fluctuation probability. Retries reduce connection failures caused by temporary network faults |
| `nodeId` configuration | Match the workshop database instance name | Avoid node identifier mismatch errors during database connections |
| Workflow export permission | Only accessible to administrators | Workflow configurations include sensitive information such as data source connection credentials. Permission control reduces data leakage risks |

## Three Common Mistakes
- Issue: Database connection error Failed to connect to jyfkk:1433. Cause: The workshop intranet firewall is not configured to allow port 1433, and the `nodeId` in the workflow does not match the database instance name.
- Issue: Workflow configuration fails to load normally after export. Cause: Associated data source credential configuration items were not selected during export, resulting in missing necessary connection parameters in the exported file.
- Issue: The question classification node cannot identify issues related to bending compensation coefficient deviation. Cause: Background knowledge only includes general inspection terminology, and does not include the category-specific bending compensation error judgment rules.

## How to Confirm Proper Configuration
- Trigger a test workflow, pass `variables` parameters for a simulated order, and verify that the corresponding order BOM and CAD unfolding drawing data are pulled correctly.
- Submit a first-piece inspection record that includes bending angle deviation, and verify that the question classification node correctly categorizes it as a bending process issue.
- Test the database connection, confirm that sheet metal inventory data can be pulled normally, with no connection timeouts or errors.
- Export the workflow configuration, verify that the exported file includes all node configurations and does not expose sensitive database connection credentials.

Note: The configuration values listed above are common starting points. Adjust them based on specific samples and operational conditions of the deployment environment.
