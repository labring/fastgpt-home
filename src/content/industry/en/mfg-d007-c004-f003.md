# Production Ledger Summary and Report Generation for Warehousing, Lot Tracking, and In-Plant Logistics: Multi-Turn Dialogue and Prompting

## What Data for This Category Looks Like
This category of data covers daily business documents from raw material warehouses, line-side warehouses, finished product warehouses, and material control departments. Documents include receiving slips, putaway slips, material picking and return slips, warehouse transfer slips, inventory counts, lot ledgers, first-in first-out records, and expiration date records. Data sources include ERP/WMS systems, barcode or RFID equipment, procurement and work order information, warehouse location data, AGV or conveyor systems, and weighing data. Update frequencies include real-time, daily synchronization, and monthly inventory updates. Fields include material codes, lot numbers, warehouse locations, expiration dates, inspection statuses, and others. Units include pieces, kilograms, cubic meters, and others.

## Constraints Imposed by These Characteristics on Multi-Turn Dialogue and Prompting
Dispersed data sources and varying update frequencies require multi-turn dialogue to adapt to data source calls at different frequencies. Prompts must clearly distinguish query scopes for real-time inventory, daily ledgers, and monthly inventory data. Strongly correlated fields related to lots and expiration dates require dialogue flows to jointly verify material identity, lot numbers, and inspection statuses, to avoid information silos across processes. Cross-process material flow management requirements require prompts to link process nodes and warehouse location information, to ensure summary reports cover complete material circulation links. Requirements for handling book-actual discrepancies and stagnant materials require dialogue to support multi-turn follow-up questions to clarify details such as discrepancy causes and stock age ranges of stagnant materials.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `messages` | 3-5 initial preset guiding questions, including "Summarize today's receiving data" and "Query expiration dates for specified lots" | Adapt to initial needs for multi-dimensional ledger queries in warehousing categories, clarify user query scopes |
| `variables` | Preset three general variables: material code, lot number, and warehouse location. Values are calibrated based on business scenarios | Simplify parameter transfer during multi-turn dialogue, adapt to field matching for different business documents |
| Maximum Context Length | 8000–12000 token | Cover accumulated ledger, lot circulation, and associated work order information from multi-turn dialogue, avoid context truncation |
| Single Search Limit | Top 8 results | Match the typical number of documents associated with a single lot of materials, ensure summary reports cover core business links |
| Question Optimization | Enabled | Automatically complete unspecified user query conditions, adapt to complex query logic for ledger summaries |
| `chatId` | Bind exclusive session ID for the corresponding warehouse or material control department | Isolate ledger data across departments, ensure sessions only call document indexes within corresponding permissions. This binding logic is supported in FastGPT v4.17.0 and later |

## Three Common Configuration Errors
- Issue: Dialogue returns 404 status code (no body). Cause: Exclusive index source for warehousing ledgers is not correctly bound, or index model does not match session permissions.
- Issue: Page refresh displays "No available index model detected" prompt. Cause: Index configuration bound to `chatId` is not persistently stored, or latest index settings are not loaded when the page loads.
- Issue: Preset guiding questions do not appear in the dialogue opening. Cause: Initial array of the `messages` parameter is not correctly populated with guiding content, or front-end rendering logic does not load the preset question list.

## How to Confirm Successful Configuration
- Initiate an initial dialogue, verify display of preset guiding questions, confirm `messages` parameter configuration is active.
- Submit a query instruction including a specific lot number and warehouse location, verify the dialogue can jointly call corresponding ledger data, confirm preset `variables` parameter is active.
- Review session logs, confirm index source bound to `chatId` matches documents for the current warehouse or department, verify permission configuration is correct.
- Trigger multi-turn follow-up questions, verify automatic completion of unspecified query conditions, confirm question optimization configuration is active.
