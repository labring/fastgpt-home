# Photovoltaic Module Encapsulation: Production Ledger Summary and Report Generation - Knowledge Base Retrieval and Recall

## What the data for this category looks like
Data sources for this category include the battery cell grading system, glass adhesive film backplane batch ledger, workshop MES system, string welding and lamination production equipment, and EL/IV testers. Data is updated synchronously for each produced module. Batch records are generated immediately when each batch of raw materials is placed in storage. Daily documents include layout drawings, material batch records, lamination process parameter records, EL defect images, IV power test reports, insulation voltage withstand records, and finished product packing lists. Data fields include battery cell current gear, lamination temperature and holding duration, EL crack coordinates, IV test power value, and more. Corresponding units are ampere, degrees Celsius, second, and watt.

## Constraints Imposed on Knowledge Base Retrieval and Recall by These Characteristics
The data characteristics of this category create multiple constraints for the retrieval and recall process.
High-frequency, real-time single-module data requires retrieval response speed to match workshop production tempo. This avoids slowing down ledger summary workflows.
Multiple types of heterogeneous documents coexist. These include text-image mixed EL defect images, numeric test reports, and plain text process records. This requires adapting recall matching rules for different modalities.
Associated retrieval between batch-level raw material data and single-module production data requires clear data association dimensions. This avoids misaligned recall results.
Strongly associated fields such as battery cell current gear and lamination process parameters require precise matching. Retrieval modes must support a combination of exact matching and semantic recall.

## How to Configure the Settings
The following configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | Matches strongly associated fields such as battery cell current gear and lamination parameters, to avoid recalling low-relevance process records |
| `limit` | Top 8 entries | Covers at least 3 types of documents for the lamination, string welding, and testing links corresponding to a single module, while controlling context length |
| `searchMode` | `mixedRecall` | Combines semantic recall and exact matching, adapts to retrieval needs for heterogeneous documents, and balances recall effects for EL images and text records |
| `usingReRank` | Enabled | Rearranges initial recall results, prioritizes relevance to core business fields such as EL crack judgment and IV power testing |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands association queries between batch material data and single-module data, resolves missing results in cross-dimensional data retrieval |
| `collectionIds` | Bind knowledge base collections for string welding, lamination, and testing links | Precise limitation of retrieval scope, to avoid mixing in document data from other categories |

## Three Common Misconfigurations
- Symptom: Authentication failed error returned when calling the API to synchronize knowledge base collections. Cause: API key permissions for bound knowledge bases are not configured, or the key has expired and become invalid.
- Symptom: Provider-related error pops up after clicking to add a new folder in the knowledge base. Cause: The knowledge base data source corresponding to production documents is not correctly associated, or the data source configuration format does not meet requirements.
- Symptom: Timeout occurs when retrieving combined data of EL images and IV test reports, with single retrieval taking more than 10 seconds. Cause: Reranking function is not enabled, or retrieval collection scope is not limited, leading to recall of too many irrelevant documents that occupy computing resources.

## How to Confirm Configurations Are Correct
- Upload a single batch of battery cell batch records and single-component EL images, perform retrieval, and verify that recall results include process parameter documents for the corresponding links.
- View the retrieval log, confirm that the number of returned recall results falls within the range specified by the `limit` configuration.
- Test API call to synchronize knowledge base collections, confirm that the return status code is 200 and no authentication errors are present.
- Simulate a high-frequency retrieval scenario, verify that single retrieval duration meets workshop production tempo requirements, with specific thresholds calibrated via actual testing.
