# Production Ledger Summary and Report Generation for Dyeing and Finishing: Knowledge Base Retrieval and Recall

## What data looks like for this category
Data sources include customer color swatches, formula libraries, dye chemical batch ledgers, dye vat operation control data, colorimeter reports, setting machine parameter records, and environmental monitoring ledgers. Daily documents include dyeing formulas, material weighing records, dye vat temperature curves, proofing confirmation sheets, color difference reports, setting process sheets, and sewage discharge ledgers. Fields include batch number, vat number, process parameters, detection values, and timestamps. Update frequency is per vat, per batch, per shift.

## What constraints these characteristics impose on knowledge base retrieval and recall
High-frequency vat-level and batch-level updates require the knowledge base to support incremental synchronization to avoid retrieval lag. Multiple types of process documents and detection data require retrieval to cover both structured parameters and unstructured text, while supporting filtering by meta fields such as vat number and batch number. The high precision requirements for color difference and formulas in wet chemical processing require recall results to strongly match current production scenarios, avoiding interference from irrelevant formulas. Compliance requirements for sewage ledgers require retrieval to associate environmental monitoring data fields to ensure compliance checks during report generation.

## How to configure settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Value Range | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Dyeing process parameters and detection data have high matching precision requirements, so low-similarity irrelevant content must be filtered out |
| `limit` | Top 8–12 entries | The number of process documents and detection data entries for a single vat production is limited; excessive recall will exceed the 4000-character context window limit of the model |
| `searchMode` | `vector` | Prioritize matching semantic and structured parameter features; hybrid retrieval mode can be switched as needed to cover all documents |
| `usingReRank` | Enabled | When multiple types of documents are mixed, reranking can correct sorting deviations from initial retrieval and match process priority |
| `datasetSearchUsingExtensionQuery` | Enabled | For structured data such as formulas and dye vat curves, extended queries can supplement contextual information associated with parameters |
| `collectionIds` | Bind the dataset for the current vat group/workshop | Narrow the retrieval scope to avoid interference from invalid data across workshops or batches |

## Three common misconfigurations
- Phenomenon: Retrieval results include cross-workshop irrelevant dye vat curves, and the vat number field does not match the current production batch. Cause: `collectionIds` is not configured to bind the dataset for the corresponding vat group, and metadata filtering rules are not enabled.
- Phenomenon: Retrieval recalls a large number of documents unrelated to the current dyeing formula, failing to match process parameter requirements. Cause: The `similarity` threshold is set too low, and the parameter is not adjusted for the high-precision matching requirements of the dyeing process.
- Phenomenon: When the application generates production ledger reports, it only returns existing knowledge base data and cannot supplement environmental monitoring information for the latest dye chemical batches. Cause: Model internet access permission is not enabled in the application configuration, and knowledge base retrieval is not set to non-enforced mode.

## How to confirm correct configuration
- Navigate to the knowledge base configuration page and confirm that `collectionIds` is bound to the dataset for the corresponding production workshop.
- Enter the current vat number as the retrieval keyword, and verify that the vat number field of the recalled documents matches the input content.
- Adjust the `similarity` parameter, compare recall results across different values, and confirm that the matching precision meets process requirements.
- Enable model internet access permission for the application, test retrieval of the latest dye chemical batch information, and confirm that external supplementary data can be obtained.

The values provided are common starting points and should be measured against the reader's own samples.
