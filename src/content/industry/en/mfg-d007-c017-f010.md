# Production Ledger Summary and Report Generation for Spraying and Coating: Knowledge Base Retrieval and Recall

## What Data for This Category Looks Like
Data sources for this category include paint supplier TDS/SDS documents, real-time collected data from spray booths and ovens, colorimeter/film thickness gauge test results, environmental monitoring data, and MES system records. Daily documents cover coating process cards, paint batch sheets, paint mixing records, film thickness and color difference reports, oven curves, defect repair orders, and VOCs ledgers. Data update frequencies include per paint batch, per shift, and continuous collection modes. Document fields include paint batch number, film thickness value (μm), oven temperature (℃), VOCs concentration (mg/m³), and others. Formats cover structured tables and unstructured text.

## What Constraints Do These Characteristics Impose on Knowledge Base Retrieval and Recall
Data characteristics of this category impose multiple constraints on the retrieval and recall link. Multi-source heterogeneous data formats, including structured test tables and unstructured process text, require retrieval systems to support mixed-format content recall. High-frequency update coverage per paint batch, per shift, and continuous collection requires configuring real-time synchronization and incremental recall mechanisms to avoid returning expired ledgers. Multi-field associated business requirements, such as matching paint batches with film thickness and oven curves, require retrieval systems to support multi-condition associated recall. Massive time-series data generated by continuous collection requires limiting the scale of single recall results to prevent context overload that affects generation efficiency. In addition, compliance association requirements for VOCs ledgers require precise matching of field content to avoid recalling irrelevant records.

## How to Configure the Settings
This configuration applies to FastGPT v4.17.0.
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Match the association accuracy of coating processes and test data, avoid recalling irrelevant process cards or test records |
| `limit` | Top 20 entries | Control the number of single recall results, adapt to the context length of multi-link association in spraying scenarios, prevent generation timeouts |
| `searchMode` | hybrid | Support mixed retrieval of structured tables and unstructured text, adapt to the multi-format data characteristics of this category |
| `usingReRank` | Enabled | Re-rank recall results, prioritize matching core business fields such as paint batch numbers and film thickness values, improve association accuracy |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expand retrieval keywords to cover professional terms such as process parameters and equipment numbers, adapt to business requirements of coating scenarios |
| `collectionIds` | Configure by business scenario | Independently associate separate datasets such as coating process libraries, test data ledgers, and VOCs compliance documents, avoid interference from cross-category data |

## Three Common Configuration Errors
- Phenomenon: When exporting production ledgers in full, the export stops after returning only 50,000 records, with no clear error prompt. Cause: The system default single export upper limit parameter was not adjusted, and the default threshold does not match the scale of massive time-series ledgers in this category.
- Phenomenon: After importing structured table data for film thickness and color difference, retrieval cannot associate corresponding coating process parameters. Cause: Multi-vector support was not enabled for table data, resulting in structured fields not being effectively embedded and recalled.
- Phenomenon: When accessing via nginx reverse proxy in an internal network, uploading oven curve files fails to trigger knowledge base synchronization. Cause: The reverse proxy's timeout parameters and request header configuration are improper, and cannot cover the time required for large file upload and synchronization.

## How to Verify Proper Configuration
- Manually enter a paint batch number as the retrieval keyword, check whether the recall results include associated paint mixing records and film thickness test reports.
- Enter the settings page of the corresponding knowledge base, confirm that multi-vector support function has been enabled for structured table data.
- Initiate a composite retrieval request including process parameters and test values, confirm that the recall results are sorted to prioritize matching core business fields.
- Test the full ledger export function, confirm that the returned record scale meets the preset configuration requirements.
