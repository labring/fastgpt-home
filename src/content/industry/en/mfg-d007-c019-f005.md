# Production Ledger Summary and Report Generation for Plastic Injection Molding: Tool Calling and Plugins

## What the Data for This Category Looks Like
Data for this category covers the full injection molding workflow. Sources include resin batch and property sheets, injection molding machine operating parameters, mold temperature controller data, manufacturing execution system (MES), and dimensional and appearance inspection records. Daily documents include injection molding process cards, raw material drying records, mold history logs, first-piece inspection forms, patrol inspection forms, and material change and machine cleaning records.

Data updates occur per production batch, each mold or material change, and once per shift. Fields include resin batch number, injection pressure, mold temperature, cooling duration, first-piece dimensional deviation, and more. Corresponding units include MPa, ℃, seconds, mm, and others.

## What Constraints These Characteristics Impose on Tool Calling and Plugins
Diverse, heterogeneous data sources require tool calling to adapt to different system API formats. It must regularly pull resin batch, injection molding machine parameter, and other data, while completing unified data format conversion.

The high-frequency update rhythm requires plugin trigger conditions to be bound to mold change, material change, and shift change events, to avoid redundant data pulls or missed data. Specific fields and unit requirements require preset field mapping rules during tool calling, to convert raw data into the standard format required for ledgers.

The serious consequences of errors require plugins to add a data validation step. This step conducts compliance checks on raw material batches and injection parameters, and blocks abnormal data from entering the ledger.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Workflow/API tool selection | `auto` | Adapts to multi-tool calling scenarios, automatically selects the corresponding plugin to process different types of injection molding data |
| Workflow/API function-call configuration | Enable parameter validation mode | Enforces verification of the match between incoming fields and injection molding ledger fields during tool calling |
| Plugin trigger timing | Bind mold change, material change, and shift end events | Matches the high-frequency update nodes of this category's data, to avoid invalid calls |
| Data validation thresholds | Dimensional deviation ±0.2mm, mold temperature ±5℃ | Based on the conventional tolerance range of injection molding processes, blocks abnormal data |
| API call timeout | 300 seconds | Adapts to the time consumption requirements of multi-source data pulls, avoids interruptions from single-call timeouts |
| Tool calling batch limit | Top 10 pending data entries | Controls the load of a single tool call, to prevent resource overload |

## Three Common Mistakes
- Phenomenon: After deployment, the plugin registration directory cannot be found, and a prompt for missing plugin entry appears when configuring tool calling. Cause: The `packages/plugins/register` folder was not manually created in the Docker mount directory, and the FastGPT plugin deployment specification was not followed.
- Phenomenon: In the tool calling configuration interface, the code running tool has no connected nodes, and workflows cannot be bound. Cause: The associated switch for the code running tool was not enabled in the system plugin configuration, or there was a plugin loading exception in the deployed version. This issue was fixed in FastGPT v4.17.0.
- Phenomenon: The ledger data returned by tool calling has missing fields or incorrect units. Cause: Field mapping rules were not configured, and custom fields from raw injection molding data were not converted to the standard ledger format.

## How to Confirm the Configuration Is Correct
- Manually trigger a plugin call for a mold change event, check if the system logs successfully pull the corresponding batch's injection molding machine parameters and raw material records.
- Check the validation rules in the tool calling configuration, input mold temperature data that exceeds the threshold, confirm that the plugin blocks abnormal data and returns a prompt.
- View the FastGPT plugin management page, confirm that the `toolChoice` and `functionCall` configurations have taken effect, with no error prompts.
- Export simulated injection molding ledger data, verify that the fields returned by tool calling match the preset ledger format.

The values provided here are common starting points, and should be evaluated against the reader's own samples.
