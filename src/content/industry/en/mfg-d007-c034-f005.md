# Production Ledger Summary and Report Generation for Baked and Convenience Foods: Tool Calling and Plugins

## What the data for this category looks like
Data for this category comes from various business documents and systems of bakeries, pastry shops, cookie, instant noodle, and frozen pastry factories. Daily documents include formulas and feeding lists, production records, baking or steaming curves, metal detection records, cleaning and disinfection records, and factory inspection reports. Data sources cover raw and auxiliary material qualification certificates, ERP/MES systems, weighing equipment, ovens/frying lines, laboratory testing systems, and food traceability ledgers. Data is updated by production batch, shift, or daily. Core fields include batch number, feeding quantity, processing temperature, allergen labeling, packaging date, and shelf life.

## What constraints these characteristics impose on tool calling and plugin workflows
The presence of multiple data sources requires tool calling to support connecting to different types of APIs such as ERP, production equipment, and laboratory systems. Pre-configured permissions and field mapping rules for each data source are required. The high-frequency update rhythm by batch and shift requires tool calling trigger timing to be bound to production batch nodes, to avoid repeatedly pulling expired data. The large number of formulas and frequent line changes in this category require tool calling to verify the association between formulas and allergen labeling, to prevent mismatches. The ready-to-eat product attribute requires reports generated by tool calling to include compliance fields such as foreign matter control and cleaning records, to ensure data integrity.

## Three Common Errors
- Symptom: After importing or exporting a workflow JSON, the interface prompts "Specified plugin not found". Cause: Local configuration information for plugins was not carried over when exporting the workflow, only the workflow logic structure was exported.
- Symptom: The allergen labeling field returned by tool calling is empty. Cause: The allergen ledger field to be pulled was not specified in the tool calling configuration, and only basic batch information is returned by default.
- Symptom: The number of tool call return results is insufficient, with only 2 documents returned. Cause: The configuration for the number of returned entries per tool call was not adjusted, and the default low entry threshold was used.

## How to Confirm the Configuration Is Set Up Correctly
- Manually trigger a tool call, check if the returned results include category-specific ledger fields such as formulas, baking curves, and metal detection records.
- Import or export the workflow JSON file, check that the plugin list is complete with no missing configuration parameters.
- Simulate input of single-batch production data, verify that tool calling triggers by batch and generates reports with corresponding content.
- View the tool calling logs to confirm that the parameter transfer format is correct, with no missing fields or format errors.
