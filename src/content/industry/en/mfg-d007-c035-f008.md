# Production Ledger Aggregation and Report Generation for Heat Treatment: Document Parsing and Chunking

## What the data for this category looks like
This category’s data originates from material grades, customer technical specifications, temperature control instruments, furnace temperature uniformity testing equipment, hardness testers, metallographic equipment, and MES systems. Data updates occur per furnace run and per batch. Daily generated documents include heat treatment process cards, charging charts, furnace temperature curves, hardness and metallographic reports, equipment inspection forms, and exception handling forms. Documents include fixed fields and specific units. For example, process cards note heating temperature and holding time. Furnace temperature curves contain time-temperature corresponding data. Hardness reports mark hardness value units.

## Constraints imposed on document parsing and chunking
High-frequency updates per furnace run and per batch create demand for bulk document parsing. Systems must support simultaneous processing of multiple documents in a single batch. Mixed multi-type document scenarios require parsing logic to adapt to different structures: fixed field formats for process cards, time-series data for furnace temperature curves, and unstructured descriptions for exception handling forms. The presence of specific units and fields requires retaining semantic complete units during chunking, avoiding splitting critical parameter combinations. Differences in the importance of different documents require adjusting chunking rules for individual document types, ensuring core data is not missed.

## Configuration settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `chunkSize` | 800–1200 characters | Adapts to the semantic length of a single process segment or single test item in heat treatment documents, avoiding splitting critical parameter groups |
| `chunkSplitter` | By paragraph + semantic boundary | Matches the segment logic of furnace temperature curves and process cards, retaining the association between test data and conclusions |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 seconds | Addresses parsing time consumption for combined uploads of multiple documents per furnace run, avoiding timeout interruptions |
| `customPdfParse` | Enable structured parsing mode | Adapts to the fixed field structures of heat treatment process cards and hardness reports, extracting accurate metadata |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | Supports bulk uploads of documents from multiple furnace runs, meeting workshop bulk archiving requirements |
| `chunkSettingMode` | Manual configuration | Adjusts chunking rules for different document types (such as furnace temperature curves vs. exception handling forms) to adapt to specialized scenarios |

## Three common misconfigurations
- Scenario: After uploading a heat treatment process card PDF, core process parameter fields are not extracted. Cause: Structured parsing mode for `customPdfParse` is not enabled; general PDF parsing cannot recognize industry-specific field formats.
- Scenario: Parsing task timeout errors occur when bulk uploading multiple furnace temperature curve documents. Cause: The value set for `PARSE_FILE_TIMEOUT_SECONDS` is too low, failing to adapt to parsing time consumption for multiple documents in a single batch.
- Scenario: After importing a Word-format equipment inspection form, the links for embedded images do not include the upload domain name. Cause: Parsing logic is not configured for the attachment association rules of heat treatment documents; general conversion does not retain domain information from the upload context.

## How to confirm proper configuration
- Upload a single heat treatment process card PDF, check that the parsed text fully retains core fields such as furnace number, heating temperature, and holding time.
- Upload bulk furnace temperature curve documents, confirm that no timeout errors occur during parsing tasks, and verify task completion status.
- Import a Word-format exception handling form, check that the links for embedded images fully include domain name information.
- Adjust the `chunkSize` parameter, then verify that chunked text units fully contain single-segment heat treatment process descriptions, with no split breaks for critical parameters.

The values provided are common starting points and should be measured against the reader's own samples.
