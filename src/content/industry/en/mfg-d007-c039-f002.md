# Production Ledger Summary and Report Generation for Electric Motor and Generator Manufacturing: Vector Models and Indexes

## What the data for this category looks like
The data for this category comes from electromagnetic design documents, copper wire and insulation material batch records, winding equipment logs, dynamic balancing machine data, electrical test bench reports, and ERP and MES systems. Daily documents include winding process cards, insulation treatment records, dynamic balancing reports, withstand voltage insulation test records, type and factory test reports. Data is updated per individual motor, each product batch, or each type change. Fields include number of turns, insulation thickness, test voltage, temperature rise values, and more, along with corresponding equipment numbers and production batch numbers.

## What constraints these characteristics impose on vector models and indexes
High-frequency updates at the individual unit or batch level require indexes to support incremental synchronization, avoiding full reconstruction that consumes excessive computing resources. Mixed storage of multiple types of documents requires indexes to distinguish field weights between process-related and test-related data. Numeric fields such as winding turns and insulation thickness need to adapt to the numeric encoding logic of vector models. Document structure adjustments caused by type changes require indexes to support dynamic field adaptation without rebuilding the full vector database. The need to associate different equipment logs with batches requires that vector retrieval must synchronize batch dimension filtering to narrow the retrieval scope.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Chunk Length | 800–1200 characters | Adapts to the single-page content length of winding process cards and withstand voltage test reports, avoiding single chunks containing irrelevant information across processes |
| Overlap Length | 100–150 characters | Retains context for key associated fields such as winding turns and production batch numbers, preventing retrieval loss of core parameters due to chunk breakage |
| Similarity Threshold | 0.72–0.80 | Filters low-match irrelevant test records, accurately recalling valid business data from the same batch and same process |
| Single Search Limit | Top 8 entries | Balances retrieval efficiency and recall completeness, covering test and process data for multiple products in the same batch |
| `defaultToken` | 2000 token | Adapts to the vector encoding length of a single test report, avoiding truncation of core parameters such as winding turns and test voltage |
| `maxToken` | 4000 token | Controls the total context length during summary report generation, complying with the input length limits of large models |

## Three Common Configuration Mistakes
- Symptom: After configuring the vector model, executing a storage task prompts "No available channel" or the vector synchronization status displays a failure. Cause: The embedding model permissions are not bound to the corresponding business group, and model access permissions are only configured in the default group.
- Symptom: The retrieval results include a large number of irrelevant general machinery documents, and fail to accurately recall winding and test data related to motor manufacturing. Cause: Vector indexes are not configured for motor manufacturing-specific fields such as winding turns and insulation thickness, and batch dimension filtering rules are not enabled.
- Symptom: Retrieval tasks take too long, and timeout prompts appear on the page. Cause: The chunk length is set to more than 1500 characters, or the single search limit is configured to more than 10 entries, resulting in excessive vector database scanning and reranking computation load.

## How to Confirm Successful Configuration
- Upload a complete winding process card and withstand voltage test report, execute the vector storage operation, and check that the task log shows successful storage with no content truncation prompts.
- Input the query "Do the winding turns of motors from the 2024 03rd batch meet process requirements?" and verify that the retrieval results include the process cards and test records for the corresponding batch, with no irrelevant documents mixed in.
- Adjust the similarity threshold to 0.75, confirm that the match quality of the retrieval results meets business expectations, with no excessive low-match invalid entries.
- Confirm that FastGPT v4.17.0 is currently in use, check the vector database monitoring panel, and verify that the execution frequency of incremental synchronization tasks matches the update rhythm of individual units or batches.
