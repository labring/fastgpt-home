# Production Ledger Summary and Report Generation for Measuring Instruments and Laboratory Management: Knowledge Base Retrieval and Recall

## What the data for this category looks like
The data for this category primarily comes from enterprise metrology rooms, metrology management systems in CNAS-accredited laboratories, external calibration institution certificates, LIMS systems, and environmental monitoring data. Daily documents include measuring tool ledgers, calibration plans, calibration certificates, interim verification records, original test records, reference material ledgers, and deviation handling documents. Data updates are triggered by calibration cycles, single test results, or abnormal events. Fields include instrument ID, calibration validity period, measurement uncertainty, traceability chain ID, and more. Units include standard metrology units such as millimeters, kilograms, and seconds.

## What constraints this category places on knowledge base retrieval and recall
Data for this category comes from multiple dispersed sources, so the retrieval link must support cross-dataset recall. Daily documents have significant structural differences, including structured ledger data and semi-structured certificate data. Matching rules for different fields must be supported. Data updates have no fixed cycle, so incremental synchronization triggered by calibration events or abnormalities must be supported. Professional fields such as traceability chain ID and measurement uncertainty have high retrieval precision requirements. Irrelevant non-metrology documents must be avoided, while complete recall of compliant documents must be ensured.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Ensures matching precision for metrology terminology and structured fields, and avoids recalling irrelevant non-metrology content |
| `limit` | Top 10 entries | Controls the number of recall results, adapts to the long-content context scenario of metrology documents, and avoids exceeding context window limits |
| `searchMode` | `fullTextRecall` | The query examples emphasize identifiers or specialist terms; test this mode with representative data, not as a product default. |
| `usingReRank` | Enabled | Re-sorts recall results by relevance, and improves the display priority of high-value calibration certificates and traceability records |
| `datasetSearchUsingExtensionQuery` | Disabled | Avoids introducing non-metrology redundant content via extended queries, and ensures retrieval focuses on exclusive data |
| `collectionIds` | Bound ID list of measuring instrument and laboratory management datasets | Limits the retrieval scope, and only covers target documents such as measuring instrument ledgers and calibration certificates |

## Three common configuration errors
- Symptom: The number of retrieval results is far lower than expected, and cannot cover all calibration certificates and ledger data. Cause: The `collectionIds` configuration is not set correctly to limit the retrieval scope, resulting in retrieval covering non-metrology business datasets.
- Symptom: After calling knowledge base search, the returned content does not match the asked metrology professional question, resulting in off-topic responses. Cause: The `similarity` threshold is set too low, which recalls a large number of low-relevance non-professional documents, or `usingReRank` is not enabled, resulting in disordered sorting.
- Symptom: Key metadata such as traceability chain ID and calibration validity period is missing from retrieval results. Cause: Retrieval rules for structured fields are not adapted, and only full-text retrieval is relied on, resulting in failure to accurately recall key metadata.

## How to confirm the configuration is properly set
- Manually enter a known measuring instrument ID, and check whether the retrieval results include the corresponding calibration certificate, traceability record, and ledger information.
- Trigger an incremental synchronization task, and confirm whether newly added calibration certificates or test records can be normally retrieved.
- Adjust the `similarity` threshold, and verify whether the relevance of retrieval results meets the requirements of metrology professional scenarios.
- Use the dataset management function of FastGPT v4.17.0 to confirm that the retrieval scope only includes exclusive datasets of measuring instruments and laboratory management.
