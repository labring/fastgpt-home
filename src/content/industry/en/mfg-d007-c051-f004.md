# Production Ledger Summary and Report Generation for Metal Cutting Machining: Workflow Orchestration

## What this category’s data looks like
Data sources for metal cutting machining production ledgers include product drawings and 3D models, CAPP/CAM systems, machine tool collection terminals, tool management systems, MES systems, and measurement and inspection tool data. Daily ledger documents cover process routes, operation cards, tool lists, CNC programs, first-piece inspection records, patrol inspection forms, and measuring tool calibration records.
Updates are triggered per work order, per workpiece, per sampling batch, or when tools are replaced. Fields include operation number, tool number, cutting speed, feed rate, inspection dimensions, and others, with corresponding units of revolutions per minute, millimeters per minute, millimeters, and similar units.

## What constraints these characteristics impose on workflow orchestration
The need to access multiple data sources requires workflows to bind multiple independent data pull nodes, each interfacing with systems such as machine tool collection, tool management, and MES. The high-frequency update feature requires trigger nodes to adapt to events like work order completion or tool replacement. Diverse document formats require workflows to support parsing different input types: structured process files, CNC program code, inspection record tables, and more. Strict field and unit requirements mean variable configuration must accurately match ledger field names and their corresponding units, to prevent summary errors caused by incompatible data formats.

## Configuration settings
These configurations are based on FastGPT v4.17.0:

| Configuration Item | Recommended Approach | Basis for This Approach |
| --- | --- | --- |
| `variables` | Configure fields including operation number, tool number, cutting speed (revolutions per minute), feed rate (millimeters per minute), inspection dimensions (millimeters), and other fields | Match standard document fields for metal cutting machining ledgers, adapt to format requirements of CAPP/CAM and measurement and inspection tool data |
| `nodeId` | Bind machine tool data collection nodes, tool management system nodes, and MES system nodes | Cover full data source pull requirements, enable unified summary of ledger data from multiple systems |
| Trigger timing | Trigger on work order completion events, with an interval no longer than 10 seconds | Match update frequency per work order, ensure real-time synchronization of ledger data |
| Global variable assignment | Use the API link of the release channel, pass in the `variables` parameter | Support dynamic injection of real-time collected cutting parameters into global variables |
| Failure retry | Retry 3 times, with 10-second intervals between each attempt | Address temporary fluctuations in machine tool collection or system interfaces, ensure data pull success rate |
| Output format | Export as an Excel file containing all ledger fields | Adapt to common report usage habits of machine tool processing plants, facilitate subsequent archiving and analysis |

## Three common errors
- Phenomenon: The last AI reply variable value in the workflow output overlaps the result of the previous variable, and field content is duplicated. Cause: Context isolation is not configured in the `variables` settings, causing residual variables from prior sessions to be carried into the current execution.
- Phenomenon: The workflow export entry cannot be found, and no corresponding button appears on the interface. Cause: The export button only displays when the workflow is in edit mode and not published; the entry is hidden after publication.
- Phenomenon: After using an API access link to assign values to global variables, the variables do not update or display as empty. Cause: The correct key-value pairs of the `variables` parameter are not included in the API request, or the `nodeId` of the target global variable is not specified.

## How to confirm proper configuration
- Trigger a test work order, and check whether the `variables` parameter in the workflow log includes all preset metal cutting machining ledger fields.
- Call the API to trigger the workflow, and verify that the returned result has no duplicated content from variable overlap, with all field values matching the test data source.
- Export the workflow configuration file, and confirm that all bound data source nodes and global variable settings are included.
- Submit an API assignment request, and check whether the values in the global variable panel are correctly updated to the test parameters.

The values provided here are common starting points and should be measured against the reader's own samples.
