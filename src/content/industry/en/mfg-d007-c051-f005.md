# Production Ledger Summary and Report Generation for Metal Cutting Machining: Tool Calling and Plugins

## What data for this category looks like
Data sources for this category include product drawings and 3D models, CAPP/CAM systems, machine tool collection terminals, tool management systems, MES systems, and measurement and inspection tool data. Daily documents cover process routes, operation cards, tool lists, CNC programs, first-piece inspection records, patrol inspection forms, and measuring tool calibration records. Data updates are triggered per work order, per workpiece, per sampling batch, or when tools are replaced. Fields include tool number, service life, machining dimensions, machine tool speed and feed parameters, inspection results, and other relevant items. Units include millimeters, revolutions per minute, meters per minute, and other machining-specific units.

## What constraints these characteristics impose on tool calling and plugins
Multi-source heterogeneous data sources require tool calling to adapt to the interface formats of different systems, to avoid calling failures caused by incompatible data formats. The high-frequency update feature requires tool calling to be bound to data trigger timing, matching update nodes such as work orders and tool replacements. The rich set of machining-specific fields requires tool calling parameters to clearly verify valid ranges for items such as tool service life and dimensional tolerances, to prevent invalid parameters from being passed. The ledger summary requirement associated with multiple documents requires tool calling to aggregate data by process and work order dimensions, to avoid information fragmentation.

## Configuration settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Adapts to parallel multi-tool calling, covering different data sources such as tool management, machine tool data, and inspection records |
| `functionCall` | `enabled` | Enables model function calling capabilities, supporting tool execution triggered by business nodes |
| Tool call timeout | `600 seconds` | Matches the conventional response cycle of machine tool data collection and tool system interfaces |
| Tool call retry count | `2–3 times` | Mitigates call failures caused by machine tool communication fluctuations and temporary interface exceptions |
| Tool call parameter verification | `Enabled` | Verifies valid ranges for fields such as tool service life and machining dimensions, avoiding invalid parameter input |
| Tool call trigger timing | After work order submission / After tool replacement | Matches the update frequency of data for this category, avoiding redundant calls |

## Three common configuration errors
- Phenomenon: A 400 <400> InternalError.Algo.InvalidParameter: Range of i error is returned when calling the MCP service. Cause: Tool calling parameters are not configured according to the valid ranges of fields such as tool service life and machining dimensions for metal cutting machining, resulting in values beyond the range being passed.
- Phenomenon: Tool calling returns empty ledger data or missing key fields. Cause: The tool entry for exclusive data sources of this category such as process routes and operation cards is not bound in the workflow, so corresponding machining data cannot be retrieved.
- Phenomenon: Tool calling cannot be triggered after configuring the Gemini model. Cause: The `functionCall` parameter is not enabled in the FastGPT v4.17.0 configuration to adapt the function calling format of this model, so the model cannot recognize tool calling instructions.

## How to confirm correct configuration
- Submit a test machining work order, check the tool calling logs in the FastGPT workflow, confirm that tool lists, machine tool collection parameters, and inspection record data have been successfully retrieved.
- Simulate a tool replacement event, verify whether tool calling is automatically executed according to the configured trigger timing, and generate corresponding ledger entries.
- Input machining dimension parameters beyond the valid range, check whether the tool calling returns a parameter verification failure prompt.
- Check the workflow monitoring panel of FastGPT v4.17.0, confirm that all tool calling execution statuses are normally completed.
