# Production Ledger Summary and Report Generation for Sheet Metal Cutting and Bending: HTTP Interfaces and External Systems

## What data looks like for this category
Business data for sheet metal cutting and bending scenarios typically comes from CAD/CAM software, order BOMs, sheet material inventory systems, laser cutters, bending machines, and factory MES systems. Daily produced documents include part unfolding drawings, CNC cutting programs, bending process cards, nesting diagrams, first-piece inspection records, and process flow cards. Data update rhythms adjust with work order creation, daily inventory checks, and equipment model changes. Core fields include sheet thickness, bending radius, unfolded dimensions, process flow order numbers, and inventory batch numbers. Units are mostly millimeters, kilograms, and pieces.

## Constraints for HTTP Interfaces and External Systems
As data sources are scattered and update frequencies are inconsistent, interfaces need to support batch data pulling and real-time synchronization requests from multiple systems. There are diverse document types including professional engineering drawings, so interfaces must support metadata transfer in different formats and file association logic. The multi-variety, small-batch business model leads to dynamic changes in work order parameters, so interfaces need to support flexible variable input to match ledger requirements for different sheet metal parts. At the same time, data association accuracy requirements are high, so interfaces must ensure accurate transfer of business fields to avoid misalignment or omissions in ledger summaries.

## How to Configure Settings
| Configuration Item | Recommended Approach | Basis for This Approach |
| --- | --- | --- |
| `Authorization` | Bearer {Enterprise-specific API key} | Complies with FastGPT v4.17.0 interface authentication specifications to ensure data access security |
| `variables` | Pass sheet thickness, bending radius, and order number by work order | Matches core business fields for sheet metal cutting and bending, enabling accurate association between ledgers and work orders |
| `responseData` | Return only order codes, sheet material utilization rate, and bending abnormality count | Reduces invalid data transmission and improves interface response speed |
| Timeout setting | 600 seconds | Adapts to complex nesting and bending calculation durations for sheet metal processing work orders, avoiding mid-process interruptions |
| Retry strategy | Retry 2 times after failure, 30-second interval | Addresses scenarios of network fluctuations or temporary device offline, ensuring data synchronization reliability |

## Three Common Mistakes
- The `source` field returned after calling the interface only contains the api keyword, and cannot be associated with local CAD drawings. This occurs because no business identifier for the drawing source is specified in `variables`, causing the interface to fail to match the associated data of the corresponding ledger.
- The interface call times out and returns a 504 status code. This occurs because no reasonable timeout duration is set, and the complex nesting calculation time for sheet metal processing exceeds the default interface time limit.
- The uploaded unfolding drawing file cannot be parsed correctly. This occurs because file metadata is not passed in accordance with the interface requirements, causing the system to fail to recognize the core drawing information for sheet metal cutting.

## How to Confirm Configuration Is Complete
- Call the test interface, pass simulated sheet metal work order parameters, and check if the returned `responseData` includes the preset core business fields.
- View the interface authentication log to confirm that the `Authorization` parameter is correctly carried and has not expired.
- Check if the passed `variables` parameter includes the core business fields of the current work order to ensure correct ledger association.
- Simulate a work order update after equipment model change, call the interface, and check if the ledger data is synchronized and updated.
- Upload a test sheet metal unfolding drawing to confirm that the interface can correctly receive and associate the corresponding business information.
