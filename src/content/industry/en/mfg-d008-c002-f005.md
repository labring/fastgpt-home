# Equipment Inspection and Maintenance Q&A for SMT Placement and Electronic Assembly: Tool Calling and Plugins

## What data for this category looks like
Data for this category comes from customer-provided BOMs, Gerber files, and component coordinates, plus production terminal data from MES systems, placement machines, SPI/AOI testing equipment, and reflow oven temperature records. Daily documents include changeover sheets, stencil parameter records, first article confirmation reports, maintenance ledgers, and traceability labels. Data updates take effect in real time with work orders and changeover operations. Within a single work order, component batches, furnace temperature parameters, and test results are dynamically changing structured fields, including core identification items such as part number, location number, and solder paste model.

## What constraints these characteristics impose on tool calling and plugin workflows
This category of data has strong real-time properties and multi-source correlation. The tool calling workflow must pull the latest MES work orders, equipment test data, and changeover configurations in real time. Multiple types of documents require cross-verification, and tools must support associative retrieval across BOMs, SPI reports, and maintenance records. The data volume of a single work order increases dynamically as production progresses. The context size returned by tools must be limited to avoid context overflow. The verification accuracy of core fields such as part number, location number, and component batch directly affects production quality. Tool calling must accurately match field formats and value ranges to avoid production accidents such as wrong component placement and dry joints.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| `toolChoice` | `auto` | Adapts to the multi-scenario needs of equipment inspection and maintenance Q&A. It can automatically select whether to call tools or generate answers directly based on user questions, without forced fixed tool calling. |
| `functionCall` | Enabled | This scenario requires accurate retrieval of structured data such as maintenance records and SPI/AOI reports. Enabling this setting forces tool calling to ensure answers are based on real production data. |
| Single search limit | Top 5–7 entries | A single work order is associated with a large number of documents. Limiting the number of returned entries avoids context overload while covering the information required for core verification. |
| Reranking | Enabled | Retrieval results matching core business fields such as part number and location number must be prioritized to improve the accuracy of maintenance question answers. |
| Maximum context | 8000–12000 characters | The total character count of documents associated with a single work order changes dynamically with production stages. This range covers the context needs of most work orders and avoids overflow.

## Three common configuration mistakes
- Calling the reranker tool returns `false` even though the tool call was successful. The cause is missing field mapping between the reranker tool and SMT category data. Retrieval results cannot match core business fields, causing the tool to return a verification failure.
- The "Unsaved" prompt remains displayed in the upper right corner of the plugin editing page, and does not disappear after clicking save. The cause is that in FastGPT v4.17.0, plugin configurations are associated with multi-source data indexes. Saving without completing verification of associated data causes the save status to fail to synchronize.
- The number of retrieval results returned by tool calling does not match the configured single search limit. The cause is incorrect setup of the retrieval range to documents associated with the current work order. The tool retrieves irrelevant data across work orders, resulting in more returned entries than expected.

## How to confirm configuration is complete
- Initiate an equipment inspection question that includes part number and location number. Check whether tool calling triggers retrieval results corresponding to BOMs and maintenance records.
- View the save status on the plugin configuration page. Confirm that the upper right prompt disappears and configuration items take effect after editing is completed.
- Adjust the value of the single search limit. Verify that the number of returned retrieval results matches the configured value.
- Initiate a maintenance question involving furnace temperature parameters. Check whether the tool calls relevant data from reflow oven temperature records.

The values provided here are common starting points and should be evaluated against the reader's own samples.
