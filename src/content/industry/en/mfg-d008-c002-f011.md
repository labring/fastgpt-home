# Equipment Inspection and Maintenance Q&A for SMT Mounting and Electronic Assembly: Forms and Interactions

## What the data for this category looks like
Data for SMT mounting and electronic assembly comes from BOMs, Gerber coordinate files provided by customers, MES systems, placement machines, SPI/AOI inspection equipment, and reflow oven temperature records. Data updates in real time per work order and each line change. Daily documents include BOMs and coordinate files, line change sheets, stencil and furnace temperature records, first article confirmation reports, SPI/AOI inspection reports, maintenance records, and traceability labels. Data fields cover part numbers, reference designators, component batches, furnace temperature parameters, inspection coordinates, and more. Corresponding units include millimeters, degrees Celsius, batch numbers, and others.

## What constraints these characteristics impose on the forms and interactions link
Real-time updates per work order and line change require forms to bind unique work order ID and line change number as association identifiers, to prevent incorrect data retrieval across work orders. Daily documents include structured BOMs, inspection reports, and more, so forms must support associating SMT category-specific knowledge base documents, and preset validation rules for corresponding fields. Severe consequences of errors require forms to set required field validation and input legality checks, to prevent risks such as wrong components and dry joints. Data sources include real-time device-collected parameters, so the interaction link must support real-time synchronization of device data to form fields, to reduce manual entry errors.

## Configuration Settings
These configurations are compatible with FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `formInput` | Bind work order ID, part number, and reference designator fields, set input validation rules | SMT work orders must be associated with corresponding part number and reference designator data to avoid mass production issues caused by wrong components |
| `userSelect` | Preset maintenance types (mounting defects, solder joint abnormalities, device errors), with no more than 8 dropdown options | Covers common classifications of SMT equipment inspection and maintenance, reducing redundant user input operations |
| Single search limit | Top 8 entries | Matches the number of common defect types for SMT inspection and maintenance, avoiding loading irrelevant historical data |
| Maximum context | 1200–1500 characters | Adapts to the typical document length of BOMs and maintenance records, ensuring retrieved content is complete without exceeding context limits |
| Retrieval timeout | 600 seconds | Adapts to the reasonable waiting time for real-time device data queries, preventing user frustration from long wait times affecting operational rhythm |
| Form submission trigger | Close input box after clicking confirm button | Aligns with the business scenario of single inspection submission, preventing duplicate work order submissions |

## Three Common Mistakes
- Phenomenon: No selectable values are displayed for referenced variables after selecting a knowledge base. Cause: Documents specific to the SMT category such as BOMs, line change sheets, and furnace temperature records have not been added to the associable knowledge base scope.
- Phenomenon: Knowledge base retrieval time increases significantly. Cause: The number of documents per search has not been limited, and a large number of historical maintenance records unrelated to the current work order are loaded.
- Phenomenon: Unable to terminate the user input process and close the input box. Cause: The post-submission hiding logic for `formInput` has not been configured, and the input termination rule for single submission has not been set.

## How to Verify Proper Configuration
- Manually enter a test work order ID and part number, verify that `formInput` triggers legality prompts for the corresponding fields.
- Click the `userSelect` dropdown menu, confirm that the preset maintenance type options load normally and do not exceed 8 items.
- Select the bound SMT knowledge base, check that referenced variables display corresponding document options such as BOMs and line change sheets.
- Initiate a simulated inspection query, confirm that retrieval time meets the preset time threshold.

Note: The configuration values listed are common starting points and should be evaluated against the reader's own samples.
