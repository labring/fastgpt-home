# Dairy Processing Equipment Inspection and Maintenance Q&A: Forms and Interactions

## What Data for This Category Looks Like
Data for this category originates from milk source testing, MES systems, homogenization and heat treatment equipment, online temperature and flow sensors, CIP cleaning systems, and LIMS platforms. Data syncs in real time for each milk tank and production batch. Associated documents include raw milk acceptance records, standardized batching sheets, pasteurization/UHT heat treatment records, CIP cleaning records, filling records, sample retention and microbial test reports. Fields cover raw milk antibiotic and physicochemical indicators, heat treatment temperature and duration, CIP cleaning parameters, filling sterility, and more. Units include ℃, seconds, CFU/mL, ppm, and additional standard units.

## Constraints for Forms and Interactions
Data updates frequently and ties to consecutive production batches. Forms must support real-time binding to global production batch variables to avoid delays and errors from manual input. Document fields differ significantly across production stages. Forms must support dynamic loading of field templates for the relevant stage, eliminating the need for repeated configuration. Data errors can cause full tank rejection or large-scale product recalls. Forms must include strict field validation rules. Forms must also support uploading binary test records and equipment photos to ensure data traceability. Continuous production workflows require forms to support batch data submission across multiple stages.

## Three Common Misconfigurations
- The `formInput` node fails to render base64-encoded equipment inspection photos. This occurs because binary stream input support is not enabled for the node.
- The default value of a form input node cannot read the global production batch variable. This occurs because the mapping relationship between the node variable and the global variable is not correctly configured.
- Uploaded CIP cleaning records cannot automatically match form fields. This occurs because field mapping rules between form fields and uploaded documents are not configured.

## How to Confirm Correct Configuration
- Upload a properly formatted raw milk acceptance record file, verify that form fields automatically match the document content.
- Paste a base64-encoded equipment inspection photo into the `formInput` node, confirm that the node can render the image normally.
- Switch the global production batch variable, verify that the form default value automatically updates to the inspection template for the corresponding batch.
- Submit test data, verify that the corresponding equipment maintenance Q&A logic is triggered, returning matching maintenance solutions.
