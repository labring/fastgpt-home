# Equipment Inspection and Maintenance Q&A for Photovoltaic Cell Manufacturing: Forms and Interactions

## What the data for this category looks like
Core users of this scenario are typically process, equipment, quality control, and production departments at crystalline silicon cell enterprises. Daily associated documents include process cards, diffusion and coating parameters, printing and sintering records, EL inspection images, IV grading data, and yield reports. Data sources cover incoming silicon wafers, MES systems, operating data from diffusion furnaces, coating equipment, and printing presses, EL and IV test results, and laboratory test data. Data update rhythm typically follows per production batch, per product inspection, and daily summary. Document structures center on equipment parameters, wafer-level test results, and batch-related records. There is no unified fixed format, and corresponding metadata must be matched according to the business scenario.

## What constraints these characteristics impose on forms and interactions
Data sources for this category are scattered and update frequency is high. Form interactions must accurately match metadata fields of different documents to avoid retrieving irrelevant content. Multiple types of documents require the interaction interface to support quick filtering by device type and inspection type, reducing manual input costs for users. Test data for each product is strongly linked to batches. Forms must support entering identifiers such as batch numbers and wafer numbers to quickly locate inspection and maintenance records for a single product. Error consequences directly relate to photoelectric conversion efficiency and product appearance. Interactions must ensure accuracy of parameter matching to avoid retrieval result deviations caused by input errors.

## Three common mistakes
- After selecting a knowledge base, referenced variables display as empty. The cause is that metadata fields for this category are not bound, and the system cannot identify associated parameters such as equipment and batches for photovoltaic cell manufacturing.
- Knowledge base retrieval latency increases significantly after upgrading the version. The cause is that the device type range for `userSelect` is not restricted. The system traverses all types of documents including incoming silicon wafers and EL inspection images, leading to increased retrieval load.
- A free input pop-up still appears after configuring a fixed input form. The cause is that the mandatory submission rule is not correctly enabled. The system retains the free input entry by default, and subsequent user input prompts cannot be disabled.

## How to confirm the configuration is complete
- Check if form fields cover core metadata such as batch numbers, equipment numbers, and wafer numbers. Field matching degree is calibrated according to actual business requirements.
- Test whether retrieval results only include inspection and maintenance records for the corresponding device after selecting a specific device type, with scope matching the business scenario.
- After submitting the preset form, confirm that the system no longer triggers free input prompts, and only retains the preset interaction process.
- Check if knowledge base referenced variables display exclusive parameters for photovoltaic cell manufacturing such as equipment numbers and batch numbers, matching the bound fields in the configuration.
