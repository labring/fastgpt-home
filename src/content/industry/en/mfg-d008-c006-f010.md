# Q&A for Equipment Inspection and Maintenance of Photovoltaic Module Packaging: Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
The data tied to equipment inspection and maintenance Q&A for photovoltaic module packaging comes from daily documents and business systems of the string welding, lamination, framing, and testing departments. Daily documents include layout drawings, material batch records, lamination process records, EL images, IV test reports, insulation voltage withstand records, and packing lists. Data sources cover wafer grading, glass adhesive film backsheet batches, MES systems, string welding and lamination equipment, and EL/IV testers. Data updates occur per module and per batch of materials. Fields include material batch numbers, equipment parameters, test values, process parameters, and more. Units use professional industrial standards such as power, temperature, and pressure.

## Constraints Imposed on Knowledge Base Retrieval and Recall
The data characteristics of this category create multiple constraints for retrieval and recall. First, data updates happen frequently, and single data entries have strong correlation. This requires the retrieval system to support real-time synchronization of batch data and equipment logs to avoid retrieving outdated or mismatched content. Second, document types span text, drawings, and test reports. This requires the retrieval system to support retrieval and display of multimodal content, ensuring visual documents such as EL images and IV test reports load correctly. Third, fields are highly specialized, and errors can lead to serious consequences. Retrieval matching must accurately align with key parameters like wafer current grades and lamination temperatures to prevent low-relevance entries from appearing, which would disrupt inspection and maintenance decisions.

## Configuration Settings
| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | High precision is required for matching key parameters of photovoltaic module packaging. This threshold filters low-relevant process records and test reports to ensure retrieval result relevance. |
| `limit` | Top 8 entries | A single module links to a limited number of process and test documents. Too many retrieved entries will exceed the conversation context window and hurt maintenance Q&A readability. |
| `searchMode` | vector+keyword | Balances text keyword matching for process documents and vector matching for EL images and IV test data, covering retrieval needs across all business document types. |
| `usingReRank` | Enabled | Scenarios like EL crack detection and power matching need high-confidence retrieval results. Reranking further filters low-relevant entries to improve decision accuracy. |
| `datasetSearchUsingExtensionQuery` | Enabled | Equipment inspection questions often require linking material batches and equipment operating parameters. Extended queries add contextual information to boost retrieval comprehensiveness. |
| `collectionIds` | Bound to the dedicated photovoltaic module packaging equipment inspection dataset | Isolates business documents from other categories to avoid retrieving irrelevant semiconductor manufacturing and wafer production content, ensuring a precise retrieval scope. |

## Three Common Mistakes
- Symptom: Layout drawings and EL images fail to load in retrieval results, with missing image placeholders shown on the page. Cause: No mapping rule has been configured between the knowledge base image storage path and business document paths, so image resources cannot be located during retrieval.
- Symptom: Excel-format material batch records and IV test reports fail to import, with an import failure prompt returned. Cause: Data has not been sorted to match the field order of category documents, and units such as power and temperature have not been standardized, leading to parsing errors.
- Symptom: After calling the conversation interface, returned results do not include associated knowledge base identification information. Cause: Retrieval traceability configuration has not been enabled, and the `datasetSearchUsingExtensionQuery` parameter for attaching traceability data has not been activated, so the interface does not return relevant identifiers.
