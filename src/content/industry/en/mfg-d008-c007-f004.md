# Stamping and Sheet Metal Forming Equipment Inspection and Maintenance Q&A: Workflow Orchestration

## What this category of data looks like
Data comes from steel coil labels and quality certificates, punch and feeder operation data, mold management systems, MES systems, and coordinate measuring machine or inspection tool inspection data. Daily related documents include stamping work instructions, material utilization rate sheets, mold inspection sheets, first and last piece records, dimension inspection reports, and mold change records.
Data updates are triggered per coil, per batch of materials, or each mold change. Fields include material grade, mold number, mold change time, dimensional tolerance values, material utilization rate, and more. Most units are millimeters (mm), square meters (㎡), and hours (h).

## What constraints these characteristics impose on the workflow orchestration link
High-frequency data updates with clear trigger nodes require workflows to bind `variables` trigger conditions to match variables such as coil batches and mold change events. Multi-source heterogeneous data requires configuring data source mapping for different nodes via `nodeId` in workflows to avoid data confusion. Many document fields have clear units, so field format rules must be configured in the workflow's variable verification link to ensure incoming data such as dimensions and utilization rates comply with standard units. High-frequency trigger scenarios like mold changes and first/last piece operations require workflows to support temporary storage and release of temporary variables to avoid global variable conflicts.

## How to set up the configuration
This document applies to FastGPT v4.17.0. The following are workflow orchestration configuration recommendations for this scenario:

| Configuration Item | Recommended Setting | Rationale |
|---|---|---|
| Global variable verification | Bind the coil number and mold change ID fields in `variables` | Match trigger scenarios per coil and each mold change, ensure accurate data association |
| Data source node differentiation | Divide punch data and mold management system data nodes by `nodeId` | Isolate multi-source heterogeneous data to prevent data crossover between different systems |
| Variable timeout period | 300–600 seconds | Adapt to the average processing duration of a single batch stamping process, avoid task interruption due to timeout |
| Context cache limit | First 8 session records | Focus on session information for the current batch and mold change stage, reduce unnecessary cache overhead |
| API variable input rules | Pass business identifiers via the `variables` parameter | Standardize input of business parameters such as coil numbers and mold changes to adapt to multi-data source docking requirements |

## Three common errors
- Phenomenon: After the workflow is saved successfully, refreshing the page shows that the configuration is lost. Cause: The configuration auto-sync switch is not enabled, and local cache is not synced to the server.
- Phenomenon: When switching between workflow nodes, a "required field not configured" error is triggered. Cause: The `variables` global variables from the previous node are not cleared, and the new node still validates the old required field rules.
- Phenomenon: After passing business parameters via API, the workflow cannot read the corresponding data. Cause: The incoming parameters are not bound to the `variables` parameter list, so the workflow cannot recognize the business identifier.

## How to confirm the configuration is correct
- Trigger a mold change event, check if the workflow starts automatically and reads the corresponding mold inspection sheet and mold change record data.
- Call the API to pass the coil number parameter, confirm that the `variables` parameter in the workflow correctly receives this value.
- Switch workflow nodes, check that the required variable verification error from the previous node is no longer triggered.
- Save the configuration and refresh the page, confirm that all setting items retain their original configurations.

The values provided are common starting points and should be measured against the reader's own samples.
