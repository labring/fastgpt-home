# Stamping and Sheet Metal Forming Equipment Inspection and Maintenance Q&A: Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
Data for this category comes from steel coil labels and quality certificates, press and feeder operation data, mold management systems, MES systems, coordinate measuring machine or fixture inspection reports. Daily documents include stamping work instructions, material utilization rate sheets, mold inspection sheets, first/last piece records, dimensional inspection reports, and mold change records.
Data updates trigger with each steel coil, each production batch, and each mold change. Most documents are tabular records, with fields including mold number, material grade, blank holder force value, mold change time, and similar parameters. Units are mostly millimeters, kilonewtons, hours, and similar units.

## Constraints on Knowledge Base Retrieval and Recall
The data for this category is scattered and updates frequently, triggering updates with each steel coil, production batch, or mold change. This requires the retrieval link to support incremental synchronization and event-triggered knowledge base refreshes.
Most documents are tabular records containing professional parameters such as mold number, material grade, and blank holder force value. This requires precise matching for structured data to avoid field ambiguity.
In high-frequency production scenarios, retrieval must support high-concurrency calls while retaining the association logic between units and numerical values to ensure the accuracy of maintenance and inspection Q&A.

## Configuration Settings
These configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | This category has high parameter precision requirements, requiring filtering of low-match non-professional content |
| `limit` | `Top 8–12 results` | Stamping scenarios require reference data covering mold, material, and operation dimensions to avoid insufficient single-piece information |
| `searchMode` | `vector+keyword` | Documents include structured tables and plain-text operation steps; hybrid retrieval balances semantic and keyword matching |
| `usingReRank` | Enabled | Multi-source recall results need to be reordered by relevance to improve the display priority of professional content |
| `datasetSearchUsingExtensionQuery` | Enabled | Maintenance Q&A often requires association of mold change records and inspection data; extended queries can cover related documents |
| `collectionIds` | Bind to the stamping workshop-specific knowledge base collection | Isolate data from other categories to avoid interference from irrelevant content in retrieval |

## Three Common Misconfigurations
- Retrieval shows matched documents, but the final answer only returns citation links without generating a specific solution. Cause: `datasetSearchUsingExtensionQuery` is not enabled, and related documents are not associated to supplement context, causing the model to be unable to generate a complete answer based on recalled content.
- After importing docx or excel format documents, retrieval accuracy is low. Cause: The retrieval configuration is not optimized for structured table content; using only plain text vector retrieval cannot match professional parameters in tables.
- The number of retrieval results does not match the set `limit`, with too many or too few results. Cause: The `similarity` threshold is not configured correctly; a threshold that is too high filters valid results, while a threshold that is too low mixes in irrelevant content.

## How to Confirm Correct Configuration
- Initiate a query containing professional parameters such as mold number and blank holder force, and check whether the recalled results cover stamping workshop-specific documents.
- Adjust the `similarity` value, observe changes in the relevance of recalled results, and confirm that the threshold adapts to the precision requirements of the current scenario.
- Test a query containing mold change and inspection related information, confirm that the `datasetSearchUsingExtensionQuery` function is enabled and recalls related documents.
- View the retrieval call log to confirm that the number of returned results falls within the range set by `limit`.

The values provided here are common starting points and should be measured against the reader's own samples.
