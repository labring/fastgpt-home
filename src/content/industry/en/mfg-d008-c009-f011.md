# Equipment Inspection and Maintenance Q&A for Pharmaceutical Dosage Production: Forms and Interactions

This configuration is compatible with FastGPT v4.17.0.

## What the data for this category looks like
Data related to equipment inspection and maintenance for pharmaceutical dosage production comes from approved formulation processes, MES electronic batch records, LIMS systems, and quality management systems. Daily documents include master production files, batch production records, batch packaging records, cleaning records, inspection records, deviation/CAPA/change documents, and batch release review forms.
Data is updated per production batch, each key process step, and as executed per equipment monitoring plans. Data fields must match standardized coding required by GMP. For example, equipment numbers use a 12-digit numeric format. Records must include required fields such as operator, time, and inspection results.

## What constraints these characteristics impose on forms and interactions
As data must strictly match the document structure and coding rules required by GMP, form interactions must preset standardized fields and options. Custom input will be restricted to avoid format errors. The uniqueness requirement for each batch of data means forms must link to batch variables. This ensures each inspection record can be traced back to the corresponding production batch.
Data updates are frequent and tied to production processes. Real-time validation must be configured in interaction steps to prevent non-compliant data from entering the quality management system. Errors may lead to batch recalls or regulatory penalties. Operation logging and approval nodes must be configured to ensure all interaction operations can be traced.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Enable required field validation, with fields matching GMP standard documents | Ensure form input content aligns with standardized fields of batch records and inspection forms, meeting data traceability requirements |
| `userSelect` | Preset 10–20 options for equipment numbers and inspection items | Comply with the equipment coding rules of the enterprise quality management system, limit input scope to avoid format errors |
| Context length limit | 800–1200 characters | Adapt to the average length of single-batch equipment inspection records, avoiding exceeding system processing limits |
| Timeout setting | 60 seconds | Adapt to the response timeliness of GMP approval processes, preventing process interruptions from affecting production progress |
| Validation rule configuration | Enable equipment number format validation | Ensure input equipment numbers comply with the 12-digit numeric GMP coding standard |

## Three common configuration mistakes
- Adding custom audio and video tags when configuring the `formInput` component results in no rendering effect. FastGPT form interaction nodes only support built-in standard input components. Rendering permissions for custom HTML tags are not open.
- After installing the specified version of FastGPT, the displayed version number does not match the expected version. Pre-built packages released on GitHub may have compilation identifier deviations. Obtain the corresponding version via source code compilation.
- After a workflow calls a sub-workflow, the steps following the `userSelect` node do not execute. The user selection node in the sub-workflow is not configured with variable return logic. The parent workflow cannot receive an execution completion signal.

## How to confirm the configuration is complete
- Import the fields from the enterprise’s existing equipment inspection form. Verify the field matching degree of the `formInput` component. Ensure all required fields have validation rules configured.
- Trigger the `userSelect` node. Confirm that the preset equipment number and inspection item options align with the coding rules in the quality management system.
- Call the workflow and pass batch variables. Verify that the knowledge base search node can correctly link to the equipment documents of the corresponding batch.
- Simulate a workflow call to a sub-workflow. Confirm that after the `userSelect` node completes selection, the subsequent maintenance Q&A node can execute normally and return results.
