# Equipment Inspection and Maintenance Q&A for Medical Device Assembly and Clean Production: Forms and Interactions

## What data for this category looks like
Daily documents for this category include production process specifications, batch production records, clean zone records, sterilization batch records, and inspection reports. Data sources include design history files, device and material batches, MES systems, clean environment monitoring equipment, sterilization equipment, and inspection and calibration systems.
Data is updated per production batch or per individual product unit, and also follows clean environment monitoring plan updates.
Fields include unique medical device identifiers, sterilization parameters, clean environment indicators, software version numbers, and adverse event records. Corresponding units include ℃, Pa, batch numbers, minutes, and others.

## Constraints imposed on forms and interactions
Data is updated per production batch or single device. Form interactions must bind the corresponding batch or device identifier to ensure data traceability.
Controlled documents have a large number of required fields. Mandatory validation must be added to interactions to prevent missing key information.
Parameters related to sterilization and clean environments involve compliance requirements. Confirmation steps must be added to interactions to block accidental modifications.
Bulk data submissions must match the category’s update frequency to avoid mixing data across batches.

## How to configure settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Bind fields such as sterilization parameters and unique identifiers, enable required validation | Category data requires controlled management, required fields ensure complete record-keeping |
| `userSelect` | Preset 3 fixed options categorized by batch production and environment monitoring, support up to 5 custom supplementary options, enable mutual exclusion validation | Adapt to the category's data structure organized by batch or monitoring plan, avoid concurrent selection conflicts |
| Form submission trigger condition | Trigger after validating the bound batch number | Ensure submitted data is associated with the corresponding production batch |
| Interaction confirmation popup | Automatically trigger when modifying sterilization parameters or clean environment indicators | Avoid compliance risks caused by accidental operations |
| Input length limit | 800–1200 characters per field | Adapt to the character range of single records in category documents |
| Timeout setting | 600 seconds | Adapt to the response duration of retrieving sterilization and environment monitoring data across systems |

## Three common configuration mistakes
- Symptom: Two tool call popups appear simultaneously. Cause: Mutual exclusion validation rules are not set for the `userSelect` configuration.
- Symptom: The backend returns an SSL connection failure error. Cause: Valid certificates for retrieving data across clean environment monitoring systems are not configured.
- Symptom: Some fields are empty after submitting bulk inspection forms. Cause: Corresponding production batch identifiers are not bound to bulk submissions for `formInput`.

## How to verify correct configuration
- Submit a form containing sterilization parameters, confirm that the interaction confirmation popup triggers.
- Select two mutually exclusive options from `userSelect`, confirm that only one can be selected at a time.
- Enter content exceeding 800–1200 characters, confirm that the input length limit prompt triggers.
- Wait 600 seconds without completing the submission, confirm that the timeout prompt triggers.

The values provided are common starting points and should be measured against the reader's own samples.
