# Equipment Inspection and Maintenance Q&A for Semiconductor Wafer Fabrication: Forms and Interactions

## What data for this category looks like
Data related to equipment inspection and maintenance Q&A for wafer fabrication typically comes from wafer fab MES systems, equipment FDC collection modules, defect detection and metrology equipment, wafer map databases, process recipe libraries, and experimental data. Daily involved documents include process flow cards, batch operation records, equipment operation recipes, SPC control charts, exception handling sheets, defect atlases, and yield reports.
Data updates follow per wafer batch, real-time collection, or daily synchronization, covering parameters and records for hundreds of process steps. Fields include nanoscale process parameters, batch numbers, equipment operating hours, and more. Units involve exclusive identifiers such as microns, hours, and batches.

## What constraints these characteristics impose on forms and interactions
Data for this category comes from multiple sources with varying update frequencies. This requires forms to support automatic association and real-time synchronization across multiple data sources, to avoid errors from manual entry.
A massive number of process steps and complex document structures require forms to display fields grouped by process module, to reduce cognitive load for entry and retrieval.
Nanoscale parameters and batch binding characteristics require forms to preset exclusive field validation rules, to ensure correct parameter precision and batch association.
Real-time collected equipment data requires fast response, which means interaction processes must be lightweight to eliminate unnecessary waiting steps.
An ultra-long process chain and limited rework windows require Q&A interactions to quickly locate exception types, to avoid process delays.

| Timeout setting | 600 seconds | Real-time collected equipment data requires timely synchronization. A reasonable timeout duration ensures process continuity |
| Data source association switch | Enabled | Must associate MES batch records and wafer map data to automatically populate known parameters and reduce manual input |
| Exception tag library | Import existing defect atlases and exception handling sheet templates | Exception types for this category must match process standards. Predefined tags unify entry formats |

## Three common mistakes
- After configuring a third-party model endpoint, the interface does not display the model corresponding to the entered baseURL. The cause is that the synchronization verification logic for model access was not configured in `formInput`, leading to incorrect loading of endpoint information into the selection list.
- An empty field error occurs when submitting an inspection form. The cause is that required validation was not set for exclusive wafer fabrication fields such as wafer batch numbers and equipment FDC parameter thresholds, leading to submission of missing required items.
- The exception handling result returned by maintenance Q&A does not match the current process step. The cause is that grouping filtering for `userSelect` was not configured by process module, leading to retrieval scope covering redundant data from unrelated process steps.
