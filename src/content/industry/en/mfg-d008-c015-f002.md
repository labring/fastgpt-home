# Equipment Inspection and Maintenance Q&A for Active Pharmaceutical Ingredient and Pharmaceutical Intermediate Production: Vector Models and Indexes

## What data for this category looks like
Data for this category comes from registered process documents, raw material batch records, DCS control systems, weighing systems, LIMS laboratory information management systems, chromatography data systems, and QMS quality management systems. Routine documents include batch production records, material balance sheets, reaction and purification step records, cleaning validation records, impurity profile reports, deviation and change documents. Data updates follow the rhythm of each production batch and each process step. Fields include professional content such as batch number, reaction parameters, yield, and impurity content. Document structures vary based on the process link.

## What constraints these characteristics impose on vector models and indexes
Multi-source heterogeneous data sources require indexes to support cross-system format adaptation, to avoid errors in parsing professional fields. High-frequency batch-based updates require indexes to be configured with incremental synchronization mechanisms, to reduce resource consumption from full scans. Long-text process records and terminology-dense impurity profile reports require chunking strategies that balance content completeness and retrieval accuracy, to prevent key maintenance logic from being truncated. Additionally, equipment inspection and maintenance Q&A needs to be linked to process compliance data, requiring retrieved results to have sufficient professional relevance, to avoid irrelevant content interfering with judgment.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| Chunk Length | 800–1200 characters | Documents for this category are mostly complete process fragments or impurity analysis content. This range can cover core information for single-step reactions and single-batch maintenance records |
| Overlap Length | 100–150 characters | Prevents associated logic across process steps from being truncated by chunking, and ensures context coherence in maintenance Q&A |
| Similarity Threshold | 0.75–0.85 | Filters retrieval results with insufficient professional term matching, and focuses on process documents directly related to equipment inspection and maintenance |
| Single Search Limit | Top 10 results | Controls the number of retrieval return results, to avoid result overload from multi-source data affecting response speed |
| `maxToken` | 8000 token | Equipment maintenance Q&A needs to link multi-step process records. This setting can hold enough context information to support logical deduction |
| `defaultToken` | Calibrated via actual testing | Adapts to length differences across batch documents, and avoids exceeding model context limits |

## Three common mistakes
- Symptom: Knowledge base retrieval response times out, with the interface showing request duration exceeding 60 seconds. Cause: Incremental indexing is not configured for the batch-based update rhythm of this category, and frequent full index scans cause excessive resource usage.
- Symptom: Index status remains "Indexing" and cannot become ready, with logs prompting embedding processing blocked. Cause: Reasonable batch processing parameters are not configured, and single-batch indexing tasks containing multi-source heterogeneous data exceed model processing capacity.
- Symptom: Multiple duplicate index entries are automatically generated in the dataset. Cause: The duplicate data automatic matching switch is not turned off. Fixed batch numbers, raw material names and other fields that regularly appear in documents of this category cause the system to misjudge them as new data.

## How to confirm configurations are set correctly
- Review system operation logs to confirm that index synchronization only triggers incremental updates after each batch of production is completed, with no high-frequency full scan records.
- Test retrieval of professional equipment maintenance-related terms, and verify that the relevance of returned results falls within the preset similarity threshold range.
- Check the number of index entries in the dataset, confirm that no automatically duplicated entries are generated, and that the number of index entries matches expectations after a single data import.
- Review system version information to confirm that the currently running FastGPT version is v4.17.0.

The values given are common starting points and should be measured against the reader's own samples.
