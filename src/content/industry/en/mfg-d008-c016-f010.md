# Equipment Inspection and Maintenance Q&A for Transformer and High-Voltage Electrical Manufacturing: Knowledge Base Retrieval and Recall

## What the Data for This Category Looks Like
Data for this category comes from design BOMs, silicon steel sheet and insulating material inventory logs, vacuum drying equipment logs, oil test reports, and high-voltage test station records. Documents are generated per production batch or single unit. They include winding and core assembly records, vacuum drying records, insulating oil test reports, partial discharge and withstand voltage test reports, and nameplate parameter tables.
Update frequency follows per single device or per batch of raw materials. Fields include insulating moisture content, partial discharge value, withstand voltage test voltage, and tap switch position. Corresponding units are ppm, pC, kV, and gear number.

## Constraints for Knowledge Base Retrieval and Recall
Full-process document association retrieval for a single device requires that recall results are tied to the production batch and test records of the corresponding device. This avoids mixing cross-batch data.
Retrieval of high-precision fields such as insulation parameters and partial discharge values requires that recall matching accuracy covers professional terminology and numerical details.
Frequently updated single-device or batch data requires the retrieval link to support real-time synchronization of updated document content.
Scenarios with multiple document types require retrieval modes to adapt to mixed retrieval of structured nameplate parameters and unstructured test reports.
The high cost of returning large components requires that retrieval results for abnormal working conditions have high confidence to reduce false recalls.

| `similarity` | `0.75–0.85` | Adapts to matching requirements for high-precision professional fields such as insulation parameters and partial discharge values, avoids recalling irrelevant content with low matching degrees |
| `limit` | `Top 8–12 entries` | Covers multiple types of documents for a single device, while controlling the total length of the context window to avoid exceeding the model's processing limit |
| `searchMode` | `mixedRecall` | Adapts to document types with both structured nameplate parameters and unstructured test reports, balances exact matching and semantic matching |

| `datasetSearchUsingExtensionQuery` | `Enabled` | Supplementary retrieval of professional terms such as device nameplate parameters and test numbers, covers omissions or abbreviations in user questions |
| `collectionIds` | `Knowledge base collection bound to production batch or single device` | Precise limitation of retrieval scope, avoids recalling irrelevant documents across batches or devices |

## Three Common Configuration Mistakes
- Phenomenon: All document content can be viewed on the knowledge base page, but the model prompts that the knowledge base is empty during conversation calls. Cause: The target knowledge base is not bound to the retrieval configuration of the corresponding application, or the `collectionIds` configuration does not include the collection ID of the target knowledge base.
- Phenomenon: The number of chunks after splitting a single document exceeds expectations, and complete content cannot be recalled during retrieval. Cause: Large files are not split according to single-device or single-batch documents, resulting in the system failing to correctly index the number of chunks of a single file.
- Phenomenon: Retrieval results contain a large number of irrelevant electrical documents from other categories, and cannot accurately match professional content of high-voltage electrical appliances. Cause: The retrieval knowledge base collection is not limited, or the retrieval configuration is not adapted to the professional terminology scope of this category.

## How to Verify Configuration Validity
- Manually enter the nameplate parameters of a single device, check whether the retrieval results include the test report and assembly records of the corresponding device.
- Trigger an abnormal working condition question, such as "How to handle partial discharge abnormalities in this transformer", check whether the retrieval results include the corresponding partial discharge test report and maintenance-related content.
- Check whether the values of the configuration items match the document type and update frequency of the current production batch, adjust the value range of the corresponding configuration.
- Upload a new test report, verify whether the updated document appears in the retrieval results, confirm that the real-time synchronization configuration has taken effect.

The values provided are common starting points and should be measured against the reader's own samples.
