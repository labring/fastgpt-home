# Spraying and Coating Equipment Inspection and Maintenance Q&A: Forms and Interactions

## What data for this category looks like
Data sources for spraying and coating scenarios include coating supplier TDS/SDS, spray booth and oven operation data, data collected by colorimeters and film thickness gauges, environmental monitoring data, and MES system records. Daily operation and business documents include coating process cards, coating batch sheets, paint mixing records, film thickness and color difference reports, oven curves, defect repair orders, and VOCs ledgers.
Data update frequency: batch sheets and paint mixing records are updated per coating batch; oven curves and VOCs ledgers are updated per shift; core equipment data such as spray booths and ovens is collected continuously. Business fields have clear units, such as film thickness (unit μm), color difference ΔE, oven temperature (unit ℃), and VOCs concentration (unit mg/m³).

## What constraints these characteristics impose on the forms and interactions link
Since data sources are scattered and update rhythms differ, forms need to support categorized entry of multiple field types, distinguishing between batch-level, shift-level, and real-time collected data. There are diverse daily document types, so an entry for preset document type selection must be provided in the interaction to avoid users entering irrelevant content. Business parameters have clear units, so forms must automatically bind unit identifiers to reduce manual input errors. Additionally, coating defects are closely linked to compliance risks, so interactions must enforce mandatory verification of core parameter required fields to avoid missing key inspection information and prevent subsequent mass repairs or compliance violations.

## How to set up the configuration
This configuration is based on FastGPT v4.17.0, and is suitable for building equipment inspection and maintenance Q&A forms for spraying and coating scenarios.
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` | Bind units by field type, e.g., bind μm to the film thickness field, and ℃ to the oven temperature field | Coating business parameters have clear units, which reduces manual input errors |
| `userSelect` | Preset options for spraying equipment, defect types, and document types, such as spray booth, runs, coating process card | Spraying and coating business scenarios are fixed, and preset options improve entry efficiency and accuracy |
| Single search limit | Top 8 entries | The number of coating-related documents is moderate, and the top 8 entries cover core matching results |
| Form mandatory verification | Enable verification for film thickness, oven temperature, and VOCs concentration fields | Missing core parameters will lead to invalid inspection or compliance risks |
| Voice input timeout threshold | 150 seconds | Voice input content for coating inspection is lengthy, a reasonable threshold avoids parsing interruptions |
| Dynamic knowledge base parameter passing | Bind variables for coating batch number and workshop ID | Coating data is updated by batch and workshop, dynamic parameter passing enables precise matching of corresponding documents |

## Three common errors
- No follow-up feedback or docking notification after form submission: This occurs because the submission callback logic for `formInput` is not configured, causing the form submission event to not trigger the preset follow-up process.
- Knowledge base search does not return referenced coating documents: This occurs because business variables such as coating batch number and workshop ID are not passed as filter conditions, causing the search scope to deviate from the corresponding data of the target batch or workshop.
- Error unmarshal_resp occurs during voice input text conversion: This occurs because a reasonable voice input timeout threshold is not set, triggering a parsing timeout error during long voice parsing.

## How to confirm the configuration is complete
- Submit a test form with complete core parameters, and check whether the preset submission callback process is triggered, such as generating a work order or pushing a notification.
- Pass a known coating batch number and workshop ID, verify whether the knowledge base returns associated documents such as process cards and paint mixing records for the corresponding batch.
- Record voice input content of approximately 120 seconds, check whether it can be normally converted into editable text without parsing errors.
- Select preset spraying equipment and defect type options, confirm that the `userSelect` component correctly passes the selected value to subsequent knowledge base search or Q&A processes.

The values provided are common starting points and should be measured against the reader's own samples.
