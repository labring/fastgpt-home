# Equipment Inspection and Maintenance Q&A for Continuous Basic Chemical Production: Multi-turn Dialogue and Prompt Terms

## What Data for This Category Looks Like
Data for this category comes from DCS/SIS systems, online analyzers, LIMS laboratory management systems, equipment condition monitoring modules, energy metering devices, and raw material storage tank ledgers. Update frequencies include real-time, shift handover, and daily summary. Daily documents include operating procedures, process index cards, DCS trend charts, laboratory reports, interlock bypass records, special work permits, and shift daily reports. Fields include temperature, pressure, flow as process control parameters, equipment vibration values, interlock trigger thresholds, and corresponding units such as ℃, MPa, m³/h, mm/s, etc.

## Constraints Imposed by These Characteristics on Multi-turn Dialogue and Prompt Terms
Real-time collected DCS and equipment condition data requires that multi-turn dialogue context retains process parameter change records from the past hour, to avoid calling expired status data. For ledger documents updated per shift and daily, prompt terms must specify prioritizing retrieval of the current shift’s records from the past 7 days and the latest interlock bypass records. Process parameters include multiple types of fields with units, so prompt terms must clearly require matching parameter values with corresponding units to avoid confusion across category parameters. The strong interlock feature of continuous production requires that multi-turn dialogue must associate isolation measures from special work permits and verify the compliance of alarm handling.

## Configuration Settings
The following configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Value | Rationale |
| --- | --- | --- |
| Maximum context length | 800–1200 characters | Matches the content length of single process records and equipment inspection items in basic chemical production, to avoid context overflow |
| Single search limit | Top 6 results | Covers the process indicators, equipment status, and shift records required for a single round of Q&A |
| Dialogue record retention period | 30–90 days | Supports retrospective review of the complete dialogue flow for shift-based maintenance coordination and interlock handling |
| Knowledge base permission control | Divided by production shift | Aligns with the permission grading requirements for special work permits and interlock bypass records |
| `variables` variable binding | Bind equipment numbers, process units | Accurately locate inspection and maintenance data for the corresponding production unit |
| `chatId` persistence | Enable persistent storage | Retains context association for multi-turn dialogue, facilitating maintenance process traceability |

## Three Common Mistakes
- Symptom: After setting the dialogue record retention period, querying historical records corresponding to `chatId` returns no results. Cause: The `chatId` persistent storage configuration was not enabled, resulting in session context not being correctly saved.
- Symptom: Non-current shift maintenance personnel can view sensitive interlock bypass records. Cause: Knowledge base permission control divided by production shift was not configured, resulting in failed permission grading.
- Symptom: When using the `FilesContent` tag to reference documents, search results do not match the parameter units of the current process. Cause: The prompt terms did not clearly require associating units with corresponding fields, resulting in failed parameter matching.

## How to Confirm Correct Configuration
- Initiate a multi-turn dialogue containing equipment numbers and process parameters, check whether the context retains the previous round’s equipment status data.
- Switch accounts for different production shifts, verify that personnel can only view work permits and inspection records for their assigned shift.
- Upload a single process index card, use the `FilesContent` tag to reference it, check whether search results match the corresponding parameter units.
- View system logs to confirm that session records for `chatId` persistent storage have been retained for the set duration.
