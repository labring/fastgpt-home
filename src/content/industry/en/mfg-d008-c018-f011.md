# Equipment Inspection and Maintenance Q&A for Basic Chemical Continuous Production: Forms and Interactions

## What This Category of Data Looks Like
Basic chemical continuous production mainly includes chlor-alkali, synthetic ammonia, methanol, and soda ash enterprises. Daily operation documents cover operating procedures, process index cards, DCS trends, laboratory reports, interlock bypass records, special work permits, and shift logs. Data sources include DCS/SIS systems, online analyzers, LIMS, equipment condition monitoring, energy metering, and raw material storage tanks. Update frequencies include real-time, per shift, and daily. Most data fields are bound to fixed units, such as pressure MPa, temperature ℃, and flow m³/h. Process index cards have clear thresholds. Interlock bypass records record operation time and operator information.

## Constraints Imposed on Forms and Interactions
Multi-source data with inconsistent update frequencies requires forms to support real-time data linkage and scheduled refresh configuration. This accommodates entry requirements for different types of documents. Diverse document types include records related to strong interlocks, so forms must configure validation rules for key parameters. This prevents safety risks caused by incorrect input. The equipment inspection and maintenance process involves multiple linked links, so interaction design must support context transfer between questions. This ensures the coherence of maintenance Q&A. Fault consequences are severe, so forms must add a secondary confirmation step. This reduces the probability of operational errors.

## How to Configure
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Approach | Rationale |
| ---- | ---- | ---- |
| `formInput` | Configure input boxes by field type, bind unit validation for numeric fields | Basic chemical production data includes a large number of process parameters with units, to avoid input errors |
| `userSelect` | Preset options for interlock status and work type, link to corresponding document libraries | Equipment inspection and maintenance often involve fixed work scenarios and interlock operations, reducing manual input errors |
| Question Optimization | Enable, select general Q&A model | Need to convert inspection questions into standardized queries to match process document content |
| Maximum Context | 800–1200 tokens, calibrated based on actual testing | Need to include key information from multiple types of documents such as DCS trends and process indicators, avoid context overflow |
| Single Search Limit | Top 6 results | Basic chemical document volume is moderate, excessive results will interfere with Q&A accuracy |

## Three Common Misconfigurations
- Phenomenon: The conclusion of the previous question is not carried over to the prompt for the next question. Cause: The context binding rule for `formInput` is not configured, leading to disconnection of the Q&A process.
- Phenomenon: The model selection interface element keeps flickering. Cause: The environment variable binding for the model is not configured, causing the frontend to repeatedly request the interface to refresh the status.
- Phenomenon: Returned results have incorrect format after inputting knowledge base content. Cause: The option association for `userSelect` is not configured according to the field structure of process documents, leading to mismatched recalled documents and questions.

## How to Confirm Successful Configuration
- Initiate two linked inspection questions, confirm that the prompt for the second question includes the conclusion of the first question.
- View the model configuration page, confirm that the correct environment variables are bound, and there is no continuously flickering status on the interface.
- Enter process parameters with units, confirm that the form triggers unit validation prompts.
- Retrieve interlock bypass record documents, confirm that the recalled results match the `userSelect` options for the current work type.
