# Equipment Inspection and Maintenance Q&A for Industrial Instrument Manufacturing and Calibration: Forms and Interactions

## What data for this category looks like
This category's data comes from design documents, standard instrument and environmental monitoring data, calibration software, laboratory information systems, and customer range requirements. Daily documents include assembly and commissioning sheets, calibration procedures, original calibration records, error curves, metrology certificates, and software version records. Data is updated after each calibration for every device. Data fields include device ID, calibration parameters, error values, traceability chain information, environmental conditions, and more. Units follow metrology verification regulation requirements. Calibration records are the core deliverable.

## What constraints these characteristics impose on forms and interactions
Data for this category is updated per device per calibration. This requires forms to bind to a unique device identifier to avoid mixing data across devices. The core deliverable is calibration records, so forms must enforce collection of required fields such as traceability chain and environmental conditions to prevent invalid certificates from missing information. The requirement to collect multiple points of error data means forms must support bulk entry of multiple fields, and must validate that numerical ranges meet metrology standards. Additionally, data sources involve integration with multiple systems, so the interaction process must support associating variables with external calibration software data to reduce manual entry errors, and adapt to the step-by-step operation needs of long-process calibrations.

## How to set configurations
| Configuration Item | Recommended Setting | Rationale |

| `formInput` | Configure input fields in 5 steps according to the calibration workflow, maximum input length per field is 800–1200 characters, add red prompt markers for required fields | Adapt to the step-by-step execution logic of calibration procedures, avoid too much content entered at one time, comply with FastGPT v4.17.0 form interaction specifications, and match the structured archiving requirements of metrology documents |

| Form save draft function | Enabled | Adapt to the step-by-step entry needs of long-process calibration data, avoid data loss caused by repeated operations |

## Three common mistakes
- Phenomenon: After enabling the rearrangement model, the returned equipment inspection Q&A results only contain a single piece of content with the highest similarity, and cannot associate multi-point calibration error data. Cause: The multi-field association recall logic is not configured, and only the single-result matching rule is called.
- Phenomenon: After calling the text content extraction node, no calibration error value is extracted, and the session has no subsequent interaction after triggering the specified reply. Cause: The session wait interaction node is not set, only a single specified reply is triggered, and context is not retained.
- Phenomenon: After entering the device ID, the associated calibration historical data is not automatically loaded. Cause: The device identifier variable is not bound to the `userSelect` configuration item, so the corresponding calibration record cannot be automatically matched.

## How to confirm the configuration is complete
- Manually enter calibration fields for a single device, check whether the required field prompts are displayed normally, and whether the input content conforms to the length limit.
- Select a preset standard instrument model option, confirm that the corresponding calibration procedure document can be correctly associated.
- Enable the form save draft function, exit the session midway and re-enter, check whether the entered data is retained.
- Simulate the waiting scenario for establishing a standard instrument connection, confirm that the session timeout time matches the actual operation time.

The values provided are common starting points and should be measured against the reader's own samples.
