# Incoming Material Inspection and Supplier Quality: Equipment Inspection and Maintenance Q&A, Multi-turn Dialogue and Prompt Engineering

## What the Data for This Category Looks Like
This category covers the full end-to-end process of incoming material inspection and supplier quality management for manufacturing enterprises. Data sources include purchase orders, drawing specifications, supplier quality certificates, inspection equipment records, historical quality data, and supplier portal information. Daily documents include inspection specifications, sampling plans, incoming material reports, supplier audit reports, exception contact sheets, 8D reports, and concession acceptance approval forms.
Data is updated in real time or periodically alongside each batch of incoming materials, monthly or quarterly supplier evaluations, and irregular audits. Documents contain clear fields including batch numbers, inspection items, non-conformity judgments, rectification requirements, and other clear fields. There is no unified fixed unit, and values are adjusted based on inspection project or supplier requirements.

## Constraints Imposed by These Characteristics on Multi-turn Dialogue and Prompt Engineering
Data for this category is updated per batch and periodically. Multi-turn dialogue must associate multiple documents from different times and sources, which creates high requirements for context synchronization. Field differences across different documents require prompts to clearly define field mapping rules, to avoid confusion over information such as batch numbers and inspection items.
In multi-turn dialogue, repeated verification of incoming material batches and supplier qualifications is necessary, which demands stable context memory capabilities. Additionally, scattered data sources lead to a large number of associated knowledge bases. Matching logic for dialogue context and knowledge base retrieval must be properly configured, to avoid retrieving irrelevant content that reduces judgment accuracy.

## Configuration Settings
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Number of associated knowledge bases | Top 10 | Matches the association needs for multiple types of documents in this category, with a reasonable upper limit calibrated through actual testing |
| Number of documents retrieved per single query | Top 8 | Covers the core document volume for inspection and audit scenarios in this category, avoiding excessive content that disrupts dialogue |
| Context window length | 8000–12000 characters | Adapts to the length of information that needs to be reviewed in multi-turn dialogue, such as incoming material batches and historical exceptions |
| `variables` | Bind batch number, supplier ID | Used to accurately filter inspection data for the corresponding batch and supplier-specific documents |
| `messages` | Retain the last 20 dialogue records | Covers the complete interaction context for multi-turn audit and rectification follow-up |
| `chatId` | Bind incoming material inspection order number | Ensures that dialogue context for the same batch of inspections is uniformly associated |

## Three Common Misconfigurations
- Phenomenon: Knowledge base association limit or character limit errors occur during formal dialogue, but not during preview. Cause: A reasonable number of associated knowledge bases and total character limit have not been configured based on the total volume of documents for this category, and non-inspection-related documents have been mistakenly added to the associated knowledge base.
- Phenomenon: The default question cannot be set to load automatically on the dialogue interface. Cause: The default question template for the `variables` parameter has not been bound in the session initialization configuration, or the session auto-initialization switch has not been enabled.
- Phenomenon: Markdown formatting is lost when copied dialogue content is pasted to an external platform. Cause: The format export configuration for dialogue content has not been enabled, or format markers were not included during copying.

## How to Confirm Proper Configuration
- A specific incoming material batch number is manually entered, and the dialogue’s ability to retrieve inspection specifications and historical exception records for the corresponding batch is verified.
- The session configuration page is reviewed to confirm that the number of associated knowledge bases and total character limit match the document scale of the current business.
- Multi-turn interaction is initiated, and whether the `messages` history record correctly retains the latest interaction content is checked.
- Session initialization is triggered, and whether the preset initial question content loads automatically on the dialogue interface is confirmed.

The values provided are common starting points and should be measured against the reader's own samples.
