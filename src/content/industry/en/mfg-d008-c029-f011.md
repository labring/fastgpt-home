# Equipment Inspection and Maintenance Q&A for Mold Design and Manufacturing: Forms and Interactions

## What Data for This Category Looks Like
The core data for this category comes from customer product models, mold flow or forming simulation files, CAD/CAM drawings, machining and measurement records, and prototype sample data. Daily documents include mold design task sheets, DFM reports, part drawings, processing technology cards, mold trial reports, mold modification notices, and mold records. Data updates are triggered by project milestones, and are synchronized after each mold trial or modification. Core fields include mold number, cavity count, material grade, defect type, equipment model, and others. There is no fixed unified format template, and it is dynamically adjusted according to project requirements. This page provides configuration instructions based on FastGPT v4.17.0.

## What Constraints These Characteristics Impose on the "Forms and Interactions" Link
Since data is dynamically updated per project and has no fixed format, forms must support associating multi-version project documents, and avoid using fixed field structures.
Since core data includes large files such as CAD and simulation files, forms must support uploading attachments in multiple formats, and limit single-file and total upload sizes.
Since the business processes of this category involve collaboration across multiple roles including design, manufacturing, and mold trial, forms must distinguish visible and editable fields for different roles, and only allow personnel with corresponding permissions to modify specific content.
Since errors directly affect mass production milestones, forms must add required field validation and abnormal input prompts to reduce invalid Q&A requests.

## How to Set Configurations
| Configuration Item | Recommended Setting | Rationale |
| ---- | ---- | ---- |
| `formInput` | `{moldNumber: "", defectType: "", equipmentModel: ""}` | Matches core business fields for mold categories, reduces duplicate user input effort |
| `userSelect` | `["injection molds", "stamping molds", "die-casting molds"]` | Covers common mold types in this category, narrows the business scope of Q&A, and improves response accuracy |
| Attachment upload limit | Maximum 5 files per upload, maximum 200 MB per single file | Matches the conventional storage size of CAD/mold flow simulation files, avoids occupying too much storage space |
| Context recall count | Top 3 entries | This category has a moderate number of documents associated with a single project; too many recalled entries will interfere with the model's judgment of core questions |
| Timeout threshold | 600 seconds | Complex mold data parsing and maintenance plan generation require long processing times, avoiding premature timeout errors |
| Custom prompt words | Calibrated based on actual testing | Needs to be adjusted in combination with internal enterprise mold maintenance documents and business processes, to adapt to the Q&A logic of specific scenarios |

## Three Common Mistakes
- Phenomenon: A 400 error is triggered when calling a specified model, and only occurs when specific short phrases are entered. Cause: The `formInput` field is not configured with input length limits, or illegal characters are not filtered, triggering FastGPT v4.17.0 model interface parameter verification failure.
- Phenomenon: The voice input function cannot be triggered normally, or the recognition result deviates significantly from user input. Cause: The voice recognition model is not correctly bound to FastGPT's `userSelect` input field, and the trigger permission for voice input is not configured.
- Phenomenon: Unable to distinguish whether user input contains images, and the basic Q&A model is called uniformly. Cause: No multi-modal input verification rules are added to `formInput`, and no pre-judgment logic for image recognition is configured.

## How to Confirm Proper Configuration
- Enter preset mold numbers and defect types, check whether the `formInput` field automatically fills in the associated document links of the corresponding project.
- Click the `userSelect` drop-down box, confirm that it includes the three preset options: injection molds, stamping molds, and die-casting molds.
- Upload a CAD format file with a size of 150 MB, check whether upload is allowed and no error prompts are displayed.
- Enter maintenance questions with and without images respectively, confirm that the target model is called directly when there are no images, and the multi-modal processing flow is triggered when there are images.

The values provided here are common starting points and should be measured against the reader's own samples.
