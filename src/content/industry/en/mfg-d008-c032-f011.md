# Equipment Inspection and Maintenance Q&A for Complete Vehicle Final Assembly: Forms and Interactions

## What the data for this category looks like
The core thread of data for this category is individual vehicle VINs. Data sources include ERP/MES systems, VIN and vehicle configuration systems, tightening tools, End-of-Line (EOL) inspection lines, and quality traceability systems. Daily documents cover production orders, VIN lists, assembly work instructions, tightening torque data, offline inspection reports, rework records, and consistency release documents. Data update frequencies follow two rhythms: real-time updates per vehicle, and batch updates per shift. Most fields are linked to vehicle-specific configurations and station operation records.

## What constraints these characteristics impose on forms and interactions
The mixed-model production model centered on VINs requires forms to support quick matching of exclusive work instructions and inspection items by VIN, to avoid mismatching and missed installations. Real-time tightening data and offline inspection data require forms to support real-time data entry and cross-system verification, to prevent operation timeouts or data loss. Cross-system data from multiple sources requires forms to support multi-field linkage, such as automatically displaying inspection items for the corresponding station and historical rework records after a VIN is matched. The high beat rate of final assembly lines requires form operation processes to be concise, to avoid lengthy steps that reduce station efficiency, while also strictly linking to vehicle-specific data to prevent confusion of inspection records across different vehicles.

## How to set configurations
| Configuration Item | Recommended Approach | Basis for This Approach |
| ---- | ---- | ---- |
| `formInput` | Bind the VIN field as a required item, enable real-time verification | Final assembly lines center on VINs, and vehicle-specific inspection items must be matched first to avoid mismatching and missed installations |
| `userSelect` | Preset 10-20 inspection items grouped by process, automatically expand by station | Inspection items at final assembly stations are mostly divided by process, reducing user search time |
| Voice input trigger | Set response delay to 500-800 milliseconds | Adapt to the fast operation rhythm of final assembly line stations, meeting the real-time requirements of voice inspection |
| Form submission verification | Enable required field verification, link with tightening data comparison | Tightening torque is a key quality item, and input values must be verified to match data stored in the system |
| Historical record call | Call the first 5 rework records for the same VIN | Final assembly rework records must be linked to the original vehicle data to quickly obtain historical maintenance information |
| Timeout threshold | 600 seconds | Reserve sufficient time to cross-systemally retrieve work instructions and historical data linked to the VIN |

## Three common mistakes
- Phenomenon: No SenseVoiceSmall model option appears in the interface during voice recording, making voice inspection impossible. Cause: The adaptation item for this voice model was not loaded in the FastGPT v4.17.0 system configuration, and the model binding switch for the voice input function was not enabled.
- Phenomenon: An empty result is returned after form submission, and no matching maintenance Q&A content is generated. Cause: The context association logic for `formInput` was not configured, and the work instruction data corresponding to the VIN was not bound.
- Phenomenon: Tool calls in advanced orchestration cannot automatically select maintenance tool configuration items for the corresponding station. Cause: The VIN field of the inspection form was not linked to the tool call node, and the grouping trigger rule for `userSelect` was not set.

## How to confirm the configuration is complete
- Enter a test VIN, check whether the form automatically displays inspection items for the corresponding station and linked work instruction links.
- Enable the voice recording function, check whether the preset speech recognition model can be selected, complete a single voice input, and submit the test.
- Submit a simulated inspection record, check whether the system returns matching maintenance Q&A content and historical rework records for the same VIN.
- Switch the simulated station, check whether the form automatically switches to the inspection items of the corresponding group, with no field verification errors or abnormal prompts.
