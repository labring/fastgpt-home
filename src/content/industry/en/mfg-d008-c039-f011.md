# Equipment Inspection and Maintenance Q&A for Electric Motor and Generator Manufacturing: Forms and Interactions

## What Data for This Category Looks Like
Typical entities for this category are winding, insulation, final assembly, and testing departments of electric motor factories and power equipment enterprises. Daily documents include winding process cards, insulation treatment records, dynamic balance reports, voltage withstand insulation test records, and type and factory inspection reports. Data sources cover electromagnetic design data, copper wire and insulation material batches, winding equipment, balancing machines, electrical test benches, and ERP/MES systems. Update frequency follows per unit or per batch, with synchronized updates each time a formal change occurs. The most time-consuming core steps are checking winding turns and wiring, controlling paint dipping and drying and insulation systems, analyzing abnormalities in vibration, temperature rise, efficiency, and voltage withstand. Data links multiple production and testing processes.

## Constraints Imposed on Forms and Interactions
Data for this category links multiple production and testing processes, and has a high update frequency. This requires forms to support associating corresponding data by batch or equipment number, to avoid mixing data across batches. Core parameters such as winding turns, insulation thickness, voltage withstand value, and others require strict verification to prevent accidents such as winding burnout or insulation breakdown caused by parameter errors. Most documents are stored in PDF or image format, so specific attachment upload rules need to be adapted. At the same time, because high-voltage and temperature rise test links exist, forms need to link verification logic for corresponding test data to ensure input content matches actual test results.

## How to Configure Settings
| Configuration Item | Recommended Setting | Rationale for This Setting |
| --- | --- | --- |
| `formInput` field validation rules | Bind fields such as winding turns, insulation thickness, voltage withstand value, set required status and value ranges, with single-value intervals calibrated based on actual measurements | Match core parameters in winding process cards and test reports to avoid missed or incorrect inputs |
| `userSelect` batch association options | Associate batch numbers and equipment number options from ERP/MES, with the current production batch selected by default | Adapt to the data update logic per unit or per batch, reduce manual input errors |
| Attachment upload format restrictions | Only support PDF and JPG formats, maximum 100 MB per file | Match common storage formats for documents such as winding process cards and test reports |
| Historical record call limit | Top 8 historical records | Prevent excessive historical records from causing verification failures, comply with context processing rules for FastGPT v4.17.0 |
| Voice input trigger verification | Bind detection supported by browser Web Speech API, enable Whisper model adaptation | Resolve compatibility issues with voice input prompts, match voice entry requirements for business scenarios |
| Global variable initial value | Preset default insulation material batch number for the current batch | Link requirements for associating material batches from business data sources, avoid variable update failure |

## Three Common Configuration Errors
- Symptom: After entering historical records in a `formInput` field in a workflow, verification fails, and the configuration cannot be saved. Cause: The number of historical record calls is not limited, resulting in input content exceeding system verification thresholds, which conflicts with workflow orchestration rules for FastGPT v4.8.14.
- Symptom: After configuring the Whisper model, the page still prompts that the browser does not support voice input. Cause: The automatic detection switch for browser Web Speech API is not enabled, or the pre-verification rules for voice input triggers are not bound.
- Symptom: After setting the global variable initial value, it does not take effect, and fields are empty when the form loads. Cause: The global variable is not bound to the default option of `userSelect`, or the variable update logic is not linked to the form initialization event.

## How to Confirm Successful Configuration
- Upload a winding process card PDF file, check whether the attachment upload module normally receives and displays file name, size and other information.
- Enter a value for winding turns, check whether verification prompts matching the preset range are triggered, and display a corresponding warning when the value exceeds the range.
- Select a batch number option, check whether the corresponding batch's insulation material data is automatically associated and filled into the corresponding form fields.
- Test the voice input function, read a section of test data content, check whether the Whisper model is normally called and the content is recognized as text.
