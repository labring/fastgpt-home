# Equipment Inspection and Maintenance Q&A for Petroleum Refining: Forms and Interactions

## What This Category of Data Looks Like
Typical users of petroleum refining equipment inspection and maintenance Q&A are production operation, process, scheduling, equipment, and laboratory departments of refinery enterprises. Daily documents include routine operation procedures, production plans, material balance reports, distillation outlet quality reports, interlock ledgers, shift handover records, and change management documents. Data sources include DCS/APC, LIMS, tank farm metrology systems, crude oil evaluation tools, equipment management systems, and energy systems. Update frequencies cover real-time, shift-based, and daily intervals. Data fields include unit number, inspection temperature, maintenance duration, material flow rate, and others. Corresponding units include ℃, hours, t/h, and other standard units. These fields must also associate coupled operation parameters for multiple continuous production units.

## Constraints Imposed on the Forms and Interactions Link
The coupling of multiple units via material and hydrogen energy networks requires forms to support linked input of cross-unit parameters, to avoid parameter conflicts. Large fluctuations in raw material properties require forms to dynamically adjust inspection items and verification rules, to adapt to detection needs for different crude oils. Data sources with varied update frequencies require forms to pull corresponding data by real-time, shift-based, and daily dimensions, to ensure input content timeliness. Fixed fields and unit requirements mandate built-in unit verification logic, to prevent input parameters from mismatching system collection formats.

## How to Configure the Settings
| Configuration Item | Recommended Approach | Rationale |
| --- | --- | --- |
| `formInput` | Bind input fields with fixed units, character limit 800–1200 characters | Match the format and length requirements of refinery equipment inspection parameters |
| `userSelect` | Preset options for unit number, inspection type, maintenance work order status | Match the fixed classifications in shift handover records and equipment management systems |
| Context call upper limit | First 8 historical records | Adapt to the shift-updated shift handover data volume and avoid context overload |
| Unit verification rules | Force matching preset units such as ℃, hours, t/h | Correspond to the parameter format requirements collected by DCS/APC |
| Historical record association | Filter by on-duty time range | Match the update frequencies of real-time and shift-based data sources |
| Voice input adaptation | Enable browser native speech recognition | Adapt to rapid input scenarios for on-site inspections |

## Three Common Misconfigurations
- Calling a code execution node in a workflow triggers a parameter verification failure error if the input includes historical record fields. This error occurs because historical records are not filtered by on-duty time range, and calling full data directly causes input parameter length to exceed limits.
- The interface prompts that the browser is not supported after the voice input function is enabled. This issue occurs because speech recognition adaptation is not enabled in the `formInput` component, or the browser version of the on-site industrial computer is incompatible with the native speech interface.
- Variables fail to take effect after plugin initial values are configured. This issue occurs because the global variable is not bound to the default selected item of the `userSelect` component, and the variable synchronization logic during form submission is not enabled.

## How to Verify Successful Configuration
- Input inspection parameters with preset units to confirm whether the form triggers unit verification prompts or automatically completes unit formats.
- Select a unit number to confirm whether associated documents for the corresponding unit are automatically loaded, such as routine operation procedures or interlock ledgers.
- Call the historical record interface to confirm that only records within the on-duty time range are returned.
- Enable the voice input function and test whether voice input content is normally recognized on the on-site industrial computer.
