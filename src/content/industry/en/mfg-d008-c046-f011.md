# Equipment Inspection and Maintenance Q&A for Meat Products and Slaughter Processing: Forms and Interactions

## What this category's data consists of
This category's data comes from animal quarantine information, supplier batches, production traceability systems, temperature collection devices, metal detection devices, and laboratory test results. Daily documents include quarantine certificates, slaughter and cutting records, ingredient marinating records, thermal processing records, cold chain temperature records, and microbial test records.
Data is updated per production batch, per shift inspection, and via continuous temperature control collection. Fields include batch number, quarantine number, temperature threshold, test results, and some records require binding biosecurity-related identifiers.

## What constraints these characteristics place on forms and interactions
Because data must be bound to batch and quarantine information, forms must support field linkage associated with batch numbers and quarantine numbers to avoid batch mix-ups.
The high-frequency collection of continuous temperature control requires forms to support real-time data entry and verification to prevent late submissions.
Strict compliance requirements for raw/cooked zone separation and sterilization temperature control require mandatory validation and abnormal warning triggers in the interaction process.
Records related to biological risks require strict permission differentiation. Form interactions must limit the editing scope of sensitive fields to ensure the accuracy of data traceability.
The Q&A interaction for equipment inspection and maintenance must quickly call historical maintenance records of the same batch to improve response efficiency.

## Configuration settings
This page's configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `formInput` field configuration | Batch number, quarantine number, inspection temperature, maintenance record number, with mandatory marking, single field length limited to 20 characters | Matches the batch traceability and quarantine binding requirements of this category, prevents storage exceptions caused by overly long fields |
| `userSelect` control configuration | Raw/cooked zone, fault type, processing status option groups, option values aligned with equipment manuals | Adapts to the standardized classification requirements of equipment inspection, ensures consistency of maintenance records |
| Continuous entry timeout threshold | 600 seconds | Matches the interval rhythm of shift inspections, avoids data loss caused by overly long inspection intervals |
| Context association count | First 3 historical inspection records | Quickly calls the maintenance history of the same batch of equipment, improves the efficiency of Q&A interactions |
| File upload rules | Only allow uploading .txt and .pdf format files, single file size limited to 10 MB | Matches the format specifications of daily documents of this category, prevents non-compliant files from occupying storage |

## Three common configuration mistakes
- Phenomenon: After submitting an inspection form, only a single set of maintenance suggestions is returned. Multi-dimensional maintenance solutions cannot be generated based on the same input. Cause: Multi-group prompt word binding for `formInput` is not configured, only a single set of Q&A logic is called.
- Phenomenon: Maintenance record processing results cannot be automatically brought into subsequent fault troubleshooting Q&A. Historical data is not loaded in the context. Cause: The output result of `userSelect` is not correctly associated with the input source of subsequent interactions, resulting in missing context.
- Phenomenon: Uploaded cold chain temperature record files cannot be parsed correctly. Returned fields are empty. Cause: File format validation for the form is not configured, allowing submission of non-specified format files.

## How to confirm proper configuration
- Enter a test batch number and quarantine number, check whether linkage verification prompts are triggered to confirm configuration takes effect.
- Select a fault type option, check whether drop-down options match preset classification items to confirm `userSelect` control configuration is correct.
- Wait 600 seconds without submitting the form, check whether a timeout reminder is triggered to confirm timeout threshold configuration is correct.
- Upload a test file in non-.txt format, check whether it is intercepted by the system to confirm file upload rules take effect.

The values provided here are common starting points and should be measured against the reader's own samples.
