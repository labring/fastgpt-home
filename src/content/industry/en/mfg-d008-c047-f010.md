# Equipment Inspection and Maintenance Q&A for Measuring Instruments and Laboratory Management: Knowledge Base Retrieval and Recall

## What this category of data looks like
This category of data includes gauge ledgers, calibration plans, calibration certificates, interim verification records, original test records, reference material ledgers, and deviation handling documents. Data sources include enterprise metrology management systems, LIMS systems, external calibration institution certificates, standard instruments, and environmental monitoring data. Updates trigger based on calibration cycles, completion of single tests, or abnormal events. Fields include instrument number, calibration validity period, measurement uncertainty, traceability number, environmental parameters, and similar items. Common units include millimeters, kilograms, degrees Celsius, calibration cycle days, and other related units.

## What constraints this category's characteristics impose on the knowledge base retrieval and recall link
Traceability requirements for this category of data mandate that retrieval results associate with core fields such as instrument number and calibration validity period, to prevent interference from irrelevant content. Differences in update rhythms across multiple data sources require the knowledge base to support incremental synchronization triggered by calibration cycles or abnormal events. The mixed document structure of structured ledgers and unstructured certificates requires support for both exact field matching and semantic content recall. Diverse unit systems allow unit keywords to be included during retrieval, to ensure matching accuracy of results.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Metrology data requires high matching accuracy to avoid interference from low-relevance non-metrology documents |
| `limit` | Top 8 entries | Balances retrieval efficiency and coverage, meets multi-document association needs for traceability chain queries |
| `searchMode` | hybrid | Combines exact field matching and semantic recall, adapts to the mixed document structure of structured ledgers and unstructured certificates |
| `usingReRank` | Enabled | Re-ranks initial recall results, prioritizes displaying high-weight content such as calibration certificates and traceability information |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands metrology-related keywords, such as expanding "calipers" to "vernier calipers, digital calipers" and similar terms, to improve recall accuracy |
| `collectionIds` | Bound by measuring instrument classification | Only retrieves knowledge base collections of the corresponding category, avoids interference from cross-category data |

## Three common mistakes
- Attempting to export the modified knowledge base returns an empty file. The cause is that persistent storage configuration for knowledge base incremental updates is not enabled, and only temporary retrieval results are cached.
- A parameter error occurs when configuring a single PDF for querying. The cause is that the `collectionIds` of the corresponding knowledge base are not correctly associated, or the unique identifier parameter for the single document is not specified.
- The number of retrieval results does not match the set `limit`. The cause is that retrieval from irrelevant knowledge base collections is not disabled, or the `similarity` threshold is set too high, filtering out valid results.

## How to confirm the configuration is complete
- Upload a standard instrument calibration certificate to the corresponding knowledge base, retrieve the keyword "traceability number", and confirm that the returned results include the correct content of the certificate.
- Trigger an incremental update, check the system logs, and confirm that only newly added interim verification records are synchronized, and the knowledge base is not fully rebuilt.
- Call the retrieval interface, pass the keyword "0-150mm vernier caliper", and confirm that the returned results only include documents for measuring instruments of the corresponding range.
- Check the `collectionIds` parameter in the retrieval configuration, confirm that it is bound to the knowledge base collection of the measuring instrument classification, to achieve retrieval filtering by category.

The values provided are common starting points and should be measured against the reader's own samples.
