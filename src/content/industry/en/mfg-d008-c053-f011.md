# Equipment Inspection and Maintenance Q&A for Iron and Steel Smelting and Continuous Casting: Forms and Interactions

## What the data for this category looks like
Iron and steel smelting and continuous casting business data originates from hot metal and scrap steel ledgers, L2 process control systems, laboratory test data, MES systems, energy medium systems, and equipment condition monitoring devices. Daily business documents include heat plans, batching lists, converter smelting records, composition reports, continuous casting process records, slab judgment sheets, and similar items. Data updates in real time when each heat completes, then is summarized and archived per shift. Fields cover core information such as heat number, smelting duration, equipment operating parameters, and composition test values.

## What constraints do these characteristics impose on forms and interactions
Business data is organized by heat and updates frequently. Forms must support quick retrieval of associated documents using heat number to avoid redundant manual input. Multiple structured document types require linked fields: selecting a specific document type automatically fills its associated fields. High-temperature continuous processes cannot be stopped arbitrarily, so interaction steps must be simplified to reduce inspection personnel’s operation time. Severe error consequences require required field validation in forms to prevent invalid queries caused by missing key retrieval conditions.

## Three Common Misconfigurations
- Issue: When configuring file upload, not enabling all formats by default results in failure to automatically recognize document formats such as batching lists and continuous casting process records when connecting to MCP. Cause: The file upload format was not configured to select all by default, only some formats were manually checked.
- Issue: After adding external model call configuration, an empty error is reported when entering the API key. Cause: The model's API address and key verification rules were not configured correctly, or the key did not carry the correct permission identifier.
- Issue: Unable to select variables referenced by the knowledge base in the code running node. Cause: The knowledge base retrieval results were not bound as global variables in the form interaction link in advance, or the variable scope configuration was incorrect.

## How to Verify Correct Configuration
- Enter any known heat number, verify that the form automatically populates associated document retrieval results for the corresponding heat.
- Upload a converter smelting record document, verify that the file upload component automatically recognizes the format and completes the upload.
- Call the model to query inspection questions about a continuous casting device, verify that the bound knowledge base can be called normally and returns results.
- Test submitting the form with an empty heat number field, verify that the required field validation prompt is triggered.

The values provided here are common starting points and should be measured against the reader's own samples.
