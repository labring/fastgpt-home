# Sheet Metal Cutting and Bending Equipment Inspection and Maintenance Q&A: Document Parsing and Chunking

## What Data for This Category Looks Like
Business entities in sheet metal cutting and bending scenarios typically include cabinet chassis, ventilation equipment, electrical cabinet and non-standard equipment manufacturers. Daily documents include unfolded drawings, CNC cutting programs, bending process cards, nesting diagrams, first-piece records, and process flow cards. Data sources include CAD/CAM tools, order BOMs, sheet metal inventory systems, laser cutters, bending machines, and MES systems. Update frequency adjusts based on orders, daily operations, or each changeover. Documents contain fields such as bending coefficient, sheet thickness, cutting size, and bending angle, with units mostly millimeters, kilograms, and similar measurements.

## What Constraints Do These Characteristics Impose on the Document Parsing and Chunking Link
The mixed-product, small-batch business model leads to diverse document types. These include CAD-exported PDF drawings, CNC program text, tabular nesting diagrams, and process flow cards. Parsing logic must support mixed formats. Frequently updated documents require fast parsing and chunking to avoid delaying equipment inspection and maintenance response times. The accuracy of key process parameters such as bending coefficient and cutting size directly affects production quality. Chunking must retain complete context to prevent truncation of critical information. Additionally, document structures vary significantly across different orders, so chunking rules need flexible adjustment to match the layout logic of various document types.

## How to Configure
The following configurations are based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `customPdfParse` | Enabled | Adapts to mixed document formats such as CAD-exported PDFs and process cards for sheet metal cutting and bending scenarios, supports custom parsing rules to extract key fields such as bending coefficient and cutting size |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 seconds | Single documents contain multiple types of content such as CNC programs and nesting diagrams, resulting in long parsing times. This avoids interrupting the parsing process due to timeout |
| `UPLOAD_FILE_MAX_SIZE` | 100–200 MB | Single cutting program or nesting diagram files have large sizes, so this adapts to the requirements of large file upload and parsing |
| `chunkSize` | 800–1200 characters | Retains complete context of key process parameters such as bending coefficient and sheet thickness, preventing important information from being truncated during chunking |
| `chunkSplitter` | Split by paragraph + title | Adapts to the title-content structure of process cards and process flow cards, ensuring chunking logic matches document layout |
| `chunkSettingMode` | Manual configuration | Adjusts chunking rules for different document types (such as unfolded drawing PDFs and CNC program text) to accommodate document differences in mixed-product, small-batch scenarios |

## Three Common Mistakes
- Symptom: PDF upload has no response for a long time, and the interface returns a 504 timeout status code. Cause: The `PARSE_FILE_TIMEOUT_SECONDS` parameter was not adjusted. The default timeout period is too short to complete parsing of large files containing nesting diagrams and CNC programs.
- Symptom: Only the first two columns of imported CSV table data are displayed. Cause: Custom parsing rules were not configured via `customPdfParse`. The default parsing logic only extracts the first two columns of fields, and does not adapt to multi-column sheet metal parameters and process information in nesting diagrams.
- Symptom: Key process parameters such as bending coefficient and cutting size are missing from chunked text fragments. Cause: The `chunkSize` setting is too small, truncating complete paragraphs containing key parameters and preventing subsequent Q&A from accessing complete information.

## How to Verify Successful Configuration
- Upload a PDF document containing a bending process card and a nesting diagram, and check if the parsed text includes key fields such as bending coefficient and sheet thickness.
- Upload a single cutting program file with a size not exceeding 200 MB, and confirm that no timeout error occurs during parsing.
- Review the chunked text fragments, and confirm that each chunk contains complete process parameters or process information, with no critical content truncated.
- Import CSV-format process flow card data, and confirm that all columns of data are correctly extracted.
