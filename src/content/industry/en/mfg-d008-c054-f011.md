# Sheet Metal Cutting and Bending Equipment Inspection and Maintenance Q&A: Forms and Interactions

## What data for this category looks like
Data for this category primarily comes from CAD/CAM software, order BOMs, sheet metal inventory systems, laser cutter and bending machine device logs, and workshop MES systems. Daily stored documents include 3D part unfolding drawings, CNC cutting programs, bending process cards, nesting diagrams, first-piece inspection records, and process flow cards. Data updates sync with order creation, daily inventory counts, and each equipment changeover adjustment. Core fields include sheet thickness, bending compensation coefficient, cutting size, and bending angle. Most units are millimeters and degrees.

## What constraints these characteristics impose on the "forms and interactions" link
This category has high-mix, low-volume production characteristics, and relies heavily on drawing-driven unfolding and bending compensation processes. Form interactions must support quick switching of process parameters for different orders. Data sources are scattered and update frequently, so forms must support real-time data pulling from external systems to avoid manual entry errors. Errors in core processes can lead to sheet material waste or assembly failure. Forms must add pre-check links to perform format and range checks on key fields such as bending compensation coefficient and cutting size. Additionally, the need to associate and upload nesting diagrams and process flow cards requires forms to support multiple file uploads and field linkage.

## Three common mistakes
- Custom input text exhibits character misalignment during tool calls. For example, inputting "share" results in "shae". The `formInput` configuration does not enable input validation or restrict valid character sets, leading to accidental submission via input method candidate words.
- Incorrect knowledge base recall limit configuration, with recall results being too many or too few. Failing to adjust the recall limit based on the precision requirements of process parameters for this category leads to Q&A results that deviate from actual needs.
- Global variables are not assigned triggers based on equipment changeover events. Failing to associate trigger conditions for equipment changeovers causes variables to use old process parameters, leading to inspection errors.

## How to confirm the configuration is complete
- Manually enter the bending compensation coefficient and cutting size fields, then submit to check if the form triggers the required field validation prompt.
- Select the pre-set equipment type options, confirm that the `userSelect` list includes laser cutter and bending machine, and supports custom addition of options.
- Simulate an equipment changeover event, check if global variables are synchronously updated to the current post-changeover process parameters.
- Submit no more than 5 process documents, confirm that the system can parse them normally and return corresponding Q&A results.
