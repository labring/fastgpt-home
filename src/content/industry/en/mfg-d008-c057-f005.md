# Forging and Open-Die Forging Equipment Inspection and Maintenance Q&A: Tool Calling and Plugins

## What this category's data looks like
Data sources for this category include raw material quality certificates, heating furnace systems, press collection data, MES systems, non-destructive testing instruments, and customer forging drawings. Data is updated after each forging part, each production batch, or each furnace run. Daily documents cover forging process specifications, cutting lists, heating furnace records, forging process cards, mold life records, heat treatment work orders, and ultrasonic testing reports. Fields include forging batch numbers, heating temperatures, pressure parameters, mold wear amounts, testing defect types, and more. Units involve degrees Celsius, megapascals, millimeters, and others.

## What constraints do these characteristics impose on the tool calling and plugins workflow
This category's data updates frequently and links to multiple production stages. Tool calling must support pulling the latest data when triggered by production batch or furnace run. Do not use expired mold life or heating parameter information. Daily document fields cover multiple dimensions including processes, testing, and equipment status. Plugins must be configured with multi-data source association logic to ensure that associated files such as cutting lists and ultrasonic testing reports can be pulled simultaneously during calls. Since the consequences of forging part errors are severe, the legitimacy of fields such as batch numbers and parameter ranges must be verified before tool calling, to prevent invalid data from entering the Q&A workflow. Additionally, this category focuses on forging ratio and fiber direction, so plugins must support reading corresponding testing fields for Q&A matching.

## How to set the configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `toolChoice` | `auto` | Adapts to the tool calling logic of FastGPT v4.17.0, automatically matching the tools required for equipment inspection and maintenance Q&A |
| `functionCall` | Enabled | Supports structured plugin calls to accurately return maintenance parameters and inspection steps related to forging equipment |
| Tool call timeout | 600 seconds | Matches the average time required to pull data for this category, preventing call interruptions due to large data volumes |
| Third-party library reference path | `./plugins/forging-tools` | Corresponds to the deployment directory of tools exclusive to this category, facilitating management of third-party libraries related to forging processes and testing |
| Number of results returned | Top 5 entries | Filters redundant information, focusing on the most relevant inspection and maintenance content such as mold wear and heating furnace abnormalities |
| Plugin trigger condition | Match by equipment number + batch number | Accurately associates production data and equipment status for the corresponding forging part, preventing cross-batch calls of incorrect data |

## Three common mistakes
- Empty image links are returned when calling the Mermaid tool to generate forging process flowcharts. This occurs because the `toolChoice` parameter is not configured correctly, or the correct interface address of the MCP service is not bound, so the drawing process cannot be triggered.
- An error occurs in the code running plugin indicating that the third-party dependency library cannot be found. This occurs because the third-party library reference path exclusive to this category is not configured, so the dedicated library files required for forging process calculation cannot be loaded.
- Tool call results include cross-batch equipment data. This occurs because the trigger condition is not matched by equipment number and forging batch number, leading to calls of data from incorrect production stages.

## How to confirm the configuration is complete
- Initiate an inspection query that includes equipment number and forging batch number, verify that the results returned by the tool call only associate production data for the corresponding batch.
- Run a code snippet that includes third-party library calls, confirm that the plugin can load and execute forging process calculation logic normally.
- Trigger the Mermaid drawing tool, confirm that a flowchart corresponding to the forging process can be generated and a valid image link returned.
- View the tool call logs, confirm that the timeout configuration matches the actual time required to pull data for this category, with no frequent timeout errors.

The values provided are common starting points and should be measured against the reader's own samples.
