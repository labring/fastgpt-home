# Quality Issue Traceability and Defect Analysis for SMT Mounting and Electronic Assembly: Workflow Orchestration

## What this category's data looks like
Production data for SMT mounting and electronic assembly comes from multiple sources. These include BOM and Gerber coordinate files provided by customers, work orders and line change records from MES systems, real-time operational data from placement machines, SPI/AOI inspection equipment and reflow ovens, plus documents such as stencil archives, first article confirmation reports and maintenance traceability labels.
Data syncs in real time for each work order and each line change. Core fields include part number, reference designator, component batch, reflow oven temperature curve parameters and inspection defect type.

## Constraints for Workflow Orchestration
Multi-source heterogeneous real-time data requires workflows to support dynamic variable loading per work order. This prevents cross-work order data confusion.
Frequent line changes trigger workflow variable resets. Ensure the `variables` configuration can quickly switch BOM and coordinate data associated with work orders.
Batch defect analysis after mass mounting requires batch execution nodes to process multiple sets of inspection data. Limit the number of single search results to avoid workflow timeouts.
Traceability links need to associate data from multiple nodes including SPI/AOI, reflow soldering and maintenance. Use `nodeId` to accurately bind data sources from each link.

## How to Set Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `variables` | Initialize per work order, include part number, reference designator, component batch, reflow oven temperature curve parameters | Match multi-field traceability requirements for SMT work orders. FastGPT v4.17.0 supports custom variable structures |
| `nodeId` | Bind SPI inspection node, AOI inspection node, reflow soldering node, maintenance record node | Accurately associate quality inspection and production data from each link |
| Batch execution | Process 10–50 work order data entries per single run | Adapt to batch defect analysis after SMT mass mounting |
| Knowledge base call scope | Bind the knowledge base of BOM and coordinate files associated with the current work order | Avoid cross-work order data interference |
| Parameter fallback | Retrieve from specified variables, use plugin default values if data is not retrieved | Address scenarios where data from some links is missing |
| Single search limit | Top 10 matching results | Control the output scale of analysis results |

## Three Common Configuration Errors
- Workflow calls a self-built knowledge base for search, and the interface displays "No matching content found". Cause: The workflow's `variables` are not bound to the associated fields of the self-built knowledge base, and only the global default knowledge base is called.
- Batch execution node fails to run, returning a "Missing parameter" error. Cause: No parameter fallback logic is configured, and the plugin default value is not used when the specified variable fails to retrieve data.
- Workflow node status remains "Running" for an extended period, eventually triggering a timeout. Cause: No reasonable single search limit is set, and an excessive volume of SPI/AOI historical report data is loaded at one time.

## How to Verify Correct Configuration
- Trigger a workflow run for a test work order, check whether `variables` correctly load the current work order's part number, reference designator and other fields.
- Call the knowledge base search function, confirm that only content related to the BOM and coordinate files associated with the current work order is returned.
- Run the batch execution node, verify that the number of processed work orders per single run matches the preset range.
- Manually delete the specified variable, confirm that the plugin automatically uses the preset default parameters.

The values given are common starting points and should be measured against the reader's own samples.
