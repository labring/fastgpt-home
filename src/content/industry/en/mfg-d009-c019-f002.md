# Quality Issue Traceability and Defect Analysis for Plastic Injection Molding: Vector Models and Indexes

## What This Category’s Data Looks Like
Business data sources for plastic injection molding include resin batch property sheets, injection molding machine operating parameters, mold temperature controller data, MES system records, and dimensional and appearance inspection results. Daily operational documents include injection molding process cards, raw material drying records, mold histories, first article inspection reports, patrol inspection forms, and material change and machine cleaning records.
Data is updated per production batch, each mold or material change, and once per shift. Document fields include resin batch number, moisture content, injection pressure (unit: MPa), mold temperature (unit: ℃), holding time, detected dimensional deviation, and more. Some paper patrol inspection forms require structured conversion first.

## What Constraints These Characteristics Impose on Vector Models and Indexes
Multi-source heterogeneous data sources require indexes to support mixed mapping of structured parameters and unstructured text, to avoid retrieval bias caused by field mismatches. The high-frequency update rhythm requires indexes to support incremental refresh, to avoid delays caused by full reconstruction.
Key parameters of injection molding processes (such as mold temperature, holding pressure window) have strong correlations. When chunking, the contextual integrity of parameters must be retained, and cross-page process content must not be arbitrarily truncated.
Unlike rubber vulcanization categories, injection molding data does not include cross-linking and curing related records. The index does not need to additionally associate curing stage features, which simplifies field mapping logic.
The following configurations are based on the vector model and index functions of FastGPT v4.17.0.

## How to Set the Configurations
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| Chunk Length | 800–1200 characters | Adapts to the single-page content length of injection molding process cards and mold histories, retains complete process parameter groups |
| Overlap Length | 100–150 characters | Prevents cross-chunk holding pressure and cooling window parameters from being truncated, ensures contextual coherence during retrieval |
| maxToken | 8192 | Adapts to long-text content of injection molding machine parameter logs, fully retains operating data for a single cycle |
| Similarity Threshold | 0.75–0.85 | Distinguishes similar features of common injection molding defects, such as flash and overflow, shrinkage and depression |
| Single Search Limit | Top 8 entries | Covers multi-dimensional inspection data and process records for a single batch of injection molding |
| defaultToken | 1024 | Ensures contextual integrity of a single retrieval result, fully displays process adjustment records corresponding to defects |

## Three Common Misconfigurations
- Insufficient number of retrieval results, only returning 2 or fewer entries. The cause is failure to adjust the index refresh frequency for the high-frequency updates of injection molding batches, resulting in new batch process records not being included in the index in a timely manner.
- Vector retrieval matches irrelevant rubber vulcanization process documents. The cause is failure to chunk using exclusive fields for the injection molding category (such as mold temperature, holding time), resulting in mixing features from other category documents.
- Interface prompts that the `defaultToken` parameter configuration is out of range. The cause is directly using the default value of a general large model, without adapting to the single-text length of injection molding data.

## How to Confirm Proper Configuration
- Upload one latest injection molding process card and mold history, check whether the chunked text retains complete holding pressure and cooling window parameters.
- Initiate a retrieval containing "shrinkage defect", confirm that the returned results include raw material drying records and mold temperature data for the corresponding batch.
- View the index refresh log, verify that the index update automatically triggered after material change per shift meets the preset frequency.
- Test the `maxToken` parameter, confirm that long-text injection molding machine parameter logs are not truncated.

The values provided are common starting points and should be measured against the reader's own samples.
