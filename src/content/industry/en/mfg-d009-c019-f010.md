# Quality Problem Traceability and Defect Analysis for Plastic Injection Molding: Knowledge Base Retrieval and Recall

## What this category of data looks like
Teams source data for plastic injection molding quality traceability and defect analysis from resin batch property sheets, injection molding machine operating parameters, mold temperature controller records, Manufacturing Execution System (MES) data, and dimensional and appearance inspection reports.
Teams maintain daily documents including injection molding process cards, raw material drying records, mold histories, first article inspection forms, production inspection logs, and material change and machine cleaning records.
Updates to this data occur per production batch, each mold change or material swap, and once per shift. Document fields include production batch, mold temperature, holding pressure, cooling time, raw material moisture content, and more, with corresponding units such as ℃, MPa, seconds, and %.

## What constraints these characteristics impose on the knowledge base retrieval and recall link
Teams trigger data updates for plastic injection molding per production batch, each mold change or material swap, and once per shift. This requires the knowledge base to support incremental updates and isolated collection management by production line, to avoid cross-batch data confusion.
Documents include structured parameter tables and unstructured records. This requires retrieval to support both semantic matching and precise keyword matching, covering query scenarios such as process parameters and problem descriptions.
Fields include parameter values with units. Retrieval must match standardized units to prevent failed recall due to unit inconsistencies.
Quality problems link to multi-dimensional data. An appropriate number of related documents must be retrieved without exceeding the context window limit.

## How to Configure the Setup
This configuration is based on FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | High precision is required for injection molding process parameters, so low-similarity irrelevant documents must be filtered out |
| `limit` | `Top 6–10 results` | Injection molding problems are linked to multiple factors, so enough related documents are needed without overflowing the context window |
| `searchMode` | `mixedRecall` | Balances precise matching for process parameters and semantic matching for problem descriptions |
| `usingReRank` | `Enabled` | Injection molding problems have many related factors, so re-ranking can further filter irrelevant results |
| `datasetSearchUsingExtensionQuery` | `Enabled` | Extends user queries, such as expanding "shrinkage" to corresponding process and mold parameters |
| `collectionIds` | `Bind to knowledge base collections for the corresponding production line` | Isolates process data from different production lines to avoid cross-line data confusion |

## Three Common Configuration Errors
- Phenomenon: Users who call the FastGPT chat API receive returned results that do not include the referenced knowledge base ID. Cause: The metadata return switch for retrieval results is not enabled, so the interface does not carry relevant source identification fields.
- Phenomenon: Importing Excel-format production inspection logs for injection molding fails, with an incompatible format error pop-up. Cause: Teams did not organize the Excel file according to the standard field structure, leading to merged cells or parameter values with non-standard units.
- Phenomenon: Image links in retrieval results fail to load normally, showing incorrect paths. Cause: Teams did not upload images to the unified storage directory configured for FastGPT, and used incorrect relative paths to reference images in documents.

## How to Verify the Configuration is Complete
- Upload a test injection molding process card, enter "Excessive mold temperature causes warping", and check if retrieval results include documents with corresponding mold temperature and cooling time values.
- Call the FastGPT chat API, and check if the context fields of returned results include the knowledge base collection ID and document source information.
- Upload a test image to the knowledge base, and confirm that the image loads normally in retrieval results with no path errors.
- Delete a test mold history document, and confirm that the document has been removed from the knowledge base list.
