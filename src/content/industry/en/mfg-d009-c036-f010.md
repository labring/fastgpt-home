# Quality Problem Traceability and Defect Analysis for Welded Structural Component Manufacturing: Knowledge Base Retrieval and Recall

## What the data for this category looks like
Data for this category primarily comes from design drawings, material quality certificates, welding equipment parameters, filler metal inventory, non-destructive testing systems, and personnel qualification ledgers. Daily produced documents include welding procedure qualifications, welding procedure specifications, filler metal issue records, welder qualification records, weld inspection reports, and repair work orders. Each document is linked to a corresponding weld or production batch.

Update frequency is per weld, per batch, or per shift. Fields include filler metal grade, welder certification number, non-destructive testing values, and repair times. There is no unified format template, and documents are generated dynamically based on production stages.

## What constraints these characteristics impose on knowledge base retrieval and recall
The high update frequency of this category’s data requires retrieval systems to support incremental synchronization, avoiding performance loss from full scans. Multiple dispersed data sources require retrieval scope to be limited by production batch or workshop, reducing interference from cross-batch unrelated documents.

Documents linked to a single weld mean retrieval should prioritize exact matches for weld numbers, batch numbers, and similar fields. This avoids fuzzy matches introducing irrelevant content. Rigid qualification and process fields require retrieval thresholds adapted to exact matching needs, preventing missed key compliance documents.

The strong association between repair work orders and non-destructive testing reports requires recall results to display linked documents for the same batch and weld, improving defect analysis efficiency.

## Configuration Settings
| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Matches rigid fields such as welding procedures and welder qualifications. A threshold that is too low will introduce irrelevant documents, while a threshold that is too high will miss valid compliance matches |
| `limit` | Top 10 entries | The number of documents linked to a single batch of welds is relatively high. Limiting the number of returned entries avoids context overflow and adapts to the information density required for on-site viewing by work teams |
| `searchMode` | `fullTextRecall` | The query examples emphasize identifiers or specialist terms; test this mode with representative data, not as a product default. |
| `usingReRank` | Enabled | Re-ranks recall results by weld relevance, placing documents directly related to the current defect issue at the top |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands query terms. For example, expands "welder qualification" to "welder qualification record" and "welder certification number" to match document fields |
| `collectionIds` | Bound to production workshop/batch, single collection no larger than 500 MB | Limits retrieval scope to document sets for the current production batch, reduces cross-batch interference and improves retrieval speed |

## Three Common Mistakes
- Imported welding process drawing images fail to display. The cause is either the knowledge base’s image external link whitelist configuration is not enabled, or image links come from internal unauthorized storage services.
- Knowledge base response times out after more than 15 seconds. The cause is either `collectionIds` is not specified, leading to full document retrieval, or `limit` is set too high, causing slow context loading.
- Retrieval results do not include welder qualification records. The cause is either `searchMode` is set to fuzzy matching, not prioritizing exact matches for welder certification number fields, or `datasetSearchUsingExtensionQuery` is not enabled to expand qualification-related query terms.

## How to Confirm Configuration Is Correct
- Upload a test weld inspection report, retrieve the corresponding weld number, and confirm returned results include linked welding procedure qualification records and filler metal issue records.
- View retrieval logs, confirm the number of returned results matches the `limit` setting, and re-ranked results are sorted by weld relevance.
- Test importing image documents from internal storage, confirm images display normally in the knowledge base preview of FastGPT v4.17.0.
- Simulate production scenario queries, such as "Repair basis for a batch of weld cracks", and confirm results include repair work orders and non-destructive testing reports.
