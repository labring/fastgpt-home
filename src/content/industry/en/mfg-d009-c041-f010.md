# Quality Problem Traceability and Defect Analysis for Electroplating and Chemical Surface Treatment: Knowledge Base Retrieval and Recall

## Data overview for this category
Data for this category comes from daily production and management records from electroplating plants and hardware surface treatment workshops. It includes tank solution analysis records, process parameter cards, fixture records, film thickness and adhesion reports, hazardous waste management ledgers, and wastewater monitoring records. Data sources include customer surface treatment specifications, tank solution test results, rectifier operation data, online water quality monitoring results, and hazardous waste registration information. Updates are performed per tank batch, per shift, or at fixed monitoring cycles. Individual documents mostly contain structured fields such as process parameters, test values, and operation times.

## Constraints for knowledge base retrieval and recall
The update rhythm of data for this category is not fixed, covering updates per tank batch, per shift, and at fixed monitoring cycles. This requires knowledge base retrieval and recall to support near-real-time synchronization of the latest documents. Multiple types of structured documents coexist, including different fields such as process parameters, test values, and operation records. This requires adaptation to precise matching requirements for structured content. Data sources include numeric information from production equipment and online monitoring, requiring support for precise retrieval of numeric fields. Hazardous waste and wastewater management documents must be recalled according to classification rules to avoid irrelevant content interfering with retrieval results. Individual documents have many associated parameters, requiring control of redundancy in recall results to ensure complete associated information without exceeding context thresholds.

## Configuration settings
These configurations are adapted for FastGPT v4.17.0.

| Configuration Item | Recommended Setting | Rationale |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | Meets the precise matching requirements for electroplating process parameters, preventing low-similarity irrelevant tank solution data from being included in results |
| `limit` | Top 6 entries | Balances completeness and readability of retrieval results, covering associated parameter records for a single production batch |
| `searchMode` | `mixedRecall` | Combines keyword and semantic retrieval, adapting to mixed retrieval scenarios for structured numeric values and unstructured process descriptions |
| `usingReRank` | Enabled | Rearranges recall results by relevance, optimizing the ranking priority of key metrics such as film thickness and adhesion |
| `datasetSearchUsingExtensionQuery` | Enabled | Automatically expands retrieval terms to cover synonyms and industry common expressions for process parameters, such as "tank solution concentration" and "tank solution component ratio" |
| `collectionIds` | Assigned by document classification | Limits the retrieval scope to dedicated datasets such as tank solution analysis, process parameters, and hazardous waste management, preventing interference from cross-category documents |

## Three common configuration errors
- Symptoms include some PDF files of tank solution analysis records failing to be recognized by the knowledge base, with no retrieval snippets generated. This occurs when table parsing configuration for tabular data in PDFs (such as tank solution component ratio tables) is not enabled, preventing structured content from being extracted.
- Symptoms include high latency for knowledge base queries, or retrieval accuracy not matching the matching accuracy during the document insertion phase. This occurs when the embedding model configuration is not unified between the retrieval and insertion phases, leading to mismatched vector spaces and failure to accurately recall target data.
- Symptoms include full-length results being returned directly after triggering knowledge base retrieval, without segmented streaming output, and occasional "no retrievable content" errors. This occurs when streaming return parameters for retrieval results are not configured, and dataset classification permissions and retrieval term extension configurations are not verified, leading to failure to recall valid data in some scenarios.

## How to verify correct configuration
- Upload a single tank solution analysis record PDF, enter keywords such as "tank solution temperature", and check if corresponding structured content in the document can be recalled.
- Adjust the `similarity` parameter range and verify that the relevance of retrieval results meets the matching requirements for process parameters.
- After enabling `usingReRank`, check if rearranged results place documents with key metrics such as film thickness and adhesion at the top.
- Switch specified dataset classifications and verify that the `collectionIds` configuration accurately limits the retrieval scope and prevents irrelevant documents from being recalled.

The configuration values listed above are common starting points. Adjust them based on your own specific samples and use cases.
