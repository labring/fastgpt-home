# Temu semi-managed sellers: product questions with vector indexes

## What the documents look like

For product questions in Temu semi-managed sellers, this page examines FastGPT vector indexes. An orientation instruction describes placement and cannot become a two-surface material specification. The examples are hypothetical.

## Constraints at the vector indexes step

A proposed Temu original says the matte face points outward for display and refers reverse-face material to a specification page. A separate positioning caption says the object can turn. A question about both faces being matte lacks reverse-face evidence. Turning describes a display action, not a material property. Entries may address orientation or composition questions, but each needs its own supporting original. Shared face and turning terms cannot turn a placement instruction into a two-sided matte specification that the supplied wording never states.

## Configuration and implementation checks

| Original-data/index check | Specific subject relationship | Acceptance action |
| --- | --- | --- |
| Orientation relationship | Matte face outward | Trace display action. |
| Reverse attribute | Separate specification reference | Retain required original. |
| Added entry meaning | Two-sided matte | Check support for both faces. |
| Target type | Caption says can turn only | Do not treat as composition. |
| Update adoption | Actual citation after specification addition | Check original data and entry targets. |

## Three common errors

First, a proposed two-sided matte entry may target only the outward-facing sentence; inspect the added two-sided attribute word by word. Second, a reverse-material question may target the positioning caption; read the target type and whether it concerns action or material. Third, after a specification page is added, the answer may still cite old placement text; inspect new original data, entry targets and actual returns rather than upload presence. These concern added meaning, target applicability and update adoption separately. Missing reverse-face evidence establishes neither identical nor different material.

## How to verify the setup

Acceptance should ask about display orientation, reverse-face evidence and the two-sided claim separately, retaining entry, original sentence and citation for each. Outward display and turning can be explained within their scope; reverse composition remains dependent on the specification. Check product applicability before comparing new material with the same questions, recording source additions separately from setting changes. Several entries for one original cannot establish coverage of the reverse face. A complete-looking search phrase cannot replace a material description absent from the original data it identifies.
