# General import declarations: product questions with retrieval

## What the documents look like

For product questions in General import declarations, this page examines FastGPT retrieval. Compare the material received with the sources used in the answer. The examples are hypothetical.

## Constraints at the retrieval step

A new import invoice test can say, “Test unit; retail packaging excluded.” Retrieval needs the unit subject and packaging exclusion together. Matching the packaging words alone does not establish inclusion. Inspect candidates for the literal phrase, then compare semantic, full-text and hybrid search with a complete packaging-scope question. “Test unit” is proposed source wording, without establishing actual use or an admission or exemption outcome.

## Configuration and implementation checks

| Documented item or implementation check | Material and condition | Evidence action |
| --- | --- | --- |
| Source scope (implementation check) | Separate invoice and transit-packaging sources | A transit box does not supply retail-packaging contents. |
| Search modes: semantic, full-text, hybrid | Original exclusion and complete packaging question | Compare the statements retrieved by the three modes. |
| Citation token limit | Retail-packaging exclusion | Inspect any exclusion lost in trimming. |
| Minimum relevance | Inspect filtering under semantic search or reranking | Investigate source scope and recall for empty results. |
| Question optimization | Device-interface follow-up | Do not invent an unsupplied interface type. |

## Three common errors

A proposed packing list records a protective transit box. If a query presents it as retail packaging, two source roles have been mixed. Retain the invoice sentence, packing entry and actual citation together. Also inspect whether citation trimming removed the exclusion: an isolated packaging noun can change the apparent answer. Several hits may repeat one transit record without providing sales-packaging evidence, so coverage needs examination beyond the number of snippets returned.

## How to verify the setup

A device-interface compatibility follow-up lacks support in the unit name and transit box. If optimization adds an interface type absent from the original, it changes the question’s evidence scope; retain both question versions for comparison. After obtaining the corresponding specification, repeat the question and trace new citations. Minimum relevance applies to semantic search or reranking. An empty result still needs a source-scope and recall check, rather than a conclusion that no specification exists or the product is incompatible.
