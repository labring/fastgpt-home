# Franchise store supervision: citation tracing for product questions

## What the documents look like

Franchise supervision in convenience retail differs from direct-operated fresh food ordering. The headquarters supervises how franchisees carry out headquarters standards, and the supervision record is the evidence of that relationship. Product information and selection questions draw on four kinds of material: supervisor app store-visit records, POS sales data, franchise system information, and store photographs. Headquarters, regional supervisors, and franchise owners all produce these materials, and updates arrive weekly or monthly.

Citation tracing matters here because the same product can carry different placement requirements across document versions. A store-visit form, a franchise contract, a rectification notice, and a display standard each carry their own effective version. When versions disagree, a supervisor needs the currently effective text before giving selection advice. A recommendation that cannot be traced to a specific document passage is exposed to franchise disputes, brand damage, and contract breach.

The knowledge base search node can associate one or more knowledge bases that share the same vector model. Its reference output is an array whose length may be zero, so the downstream chain still runs when nothing is retrieved. Retrieved references pass to the answering step, and every selection recommendation should trace to a specific passage of source text.

Hypothetical paper test case: an annex to a franchise contract, Display Standard, March 2025 version, clause 4.2, states that the first shelf of the chilled beverage area displays the private-label bottled water and the second shelf displays the partner-brand tea drink. The June 2025 version of clause 4.2 states that the first shelf displays the partner-brand tea drink and the second shelf displays the private-label bottled water. A July 2025 store-visit form records that the first shelf of the chilled beverage area at a given store holds the private-label bottled water. Draft sentence to be assessed: "This store's July 2025 display conforms to the current headquarters display standard."

Checking requires the visit-form date, the display standard version the visit form relied on, and the contract annex effective status. The March and June versions give mutually exclusive requirements for the same shelf position, so the visit form must be matched to a version. If the visit form does not state which display standard version it relied on, conformity cannot be determined and the claim is unsupported. Whether the franchise contract is effective, whether a rectification notice was delivered, and whether the display standard was updated are three separate facts; none can be inferred from another.

## Constraints at the citation tracing step

The search node accepts one or more knowledge bases that use the same vector model. A knowledge base built on a different vector model cannot be associated, so the identifier is checked first and non-matching bases are excluded rather than run for comparison. The reference output is an array and may be empty; an empty array does not mean the workflow has failed or stopped. The output chain continues, and the downstream answer step must be designed to mark that no reference source was returned.

Search parameters shape what reaches the answer step. Semantic search compares vector distance; full-text search suits exact queries such as item numbers, models, and proper nouns; hybrid search combines semantic and full-text recall and merges them through RRF. RRF is a fusion process inside hybrid search, not a separate switch. Rerank applies a second ordering to candidates and produces a 0-1 score. The minimum relevance value is a filter threshold and takes effect only under semantic search or when result reranking is used; it is not a final ordering rule, a category filter, an entity filter, or a permission filter. Retrieval does not grant authorization.

The reference ceiling limits how many tokens of content a single search may cite. The documented unit is tokens, not a top-k item count. Question optimization runs a model call before retrieval to resolve references and expand the question, which helps multi-turn follow-ups and adds latency.

Optional paths in the overall retrieval flow do not all execute on every request. Image retrieval requires an image input and a model capable of handling it, and reranking requires a configured ReRank model and the setting enabled. The reference ceiling is a token budget for citations; it is not the thinking budget used in AI configuration.

## Three common errors

1. Treating the June 2025 display standard as the only effective version and ignoring that the visit form may rely on the March version. Check: input the visit-form text and both display standard versions, compare whether the visit form states a version number, and observe whether a version conflict exists. The March and June texts give mutually exclusive shelf assignments for the same position, so the conflict is real, not assumed.

2. Treating a retrieved display standard clause as proof of store conformity and skipping the item-by-item comparison against the visit-form record. Check: input the retrieved reference array and the visit-form shelf and brand record, compare whether both point to the same shelf position and the same brand, and observe whether a position or brand mismatch appears.

3. Treating the franchise contract signature status as equivalent to contract effectiveness or to an updated display standard. Check: input the contract signature page and the effectiveness clause text, compare the signature date with the effectiveness conditions, and observe whether those conditions are satisfied. A pending request is not approval, and an unsigned termination is not a completed termination.

## How to verify the setup

1. Input the July 2025 store-visit form text and both display standard versions from the hypothetical sample. Compare whether the visit form states the version it relied on, and observe whether the draft sentence "conforms to the current headquarters display standard" is supported by evidence of the same version, same shelf position, and same brand. If the visit form states no version, the claim is unsupported. The two versions give mutually exclusive requirements for the same shelf layer, so a version match is required before any conformity judgment.

2. Input the retrieved reference array. Compare the array length with the number of selection recommendations in the answer, and observe whether each recommendation corresponds to at least one reference passage. For the paper input `[]`, the downstream answer design should mark that no reference source was returned and should not claim retrieval succeeded. This check does not assert that any particular query returns an empty array; it verifies how the downstream design handles the documented empty-output condition.

3. Input the shelf position and brand recorded in the visit form and compare them item by item with the cited display standard clause. Observe whether position and brand match exactly. If they differ, the result is non-conforming; if the visit form does not record the corresponding shelf position, the result remains to be verified. Evidence that is absent stays absent.

Authorization boundaries remain separate from retrieval throughout. Retrieval is not authorization, a form collects values, and business verification, approval, database writes, and external synchronization each require their stated downstream implementation. No scheduled trigger or hidden control is assumed. Where the documents provide no error code or actual observation, the page states what to compare and what remains unknown.
