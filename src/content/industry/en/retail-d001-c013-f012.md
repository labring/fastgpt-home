# Franchise store supervision: product questions with document chunking

## What the documents look like

For product questions in Franchise store supervision, this page examines FastGPT document chunking. Shelf-position examples and sale-specification lists need separate source identities. The examples are hypothetical.

## Constraints at the document chunking step

A proposed convenience-store display example places a small package on an upper shelf, under a heading that says positions only. A separate reference sends saleable specifications to the current product booklet, which is absent. A question about small and large packs needs this example role preserved: an illustrated placement does not establish current saleable sizes. Parsing should retain example identity and the referenced source. Chunking must not assign the position sentence to booklet contents or treat an unseen large pack as evidence that the format is not sold.

## Three common errors

One failure separates positions only and the answer presents the small pack as confirmed on sale. Another merges the booklet reference with the example so the product list appears already supplied. Compare heading, document identity and actual block boundaries to distinguish lost limitations from source substitution. Search wording for pack specifications still needs real specification text. Without the booklet, multiple example hits do not become a saleable-item list, and more matching passages cannot replace the missing source or establish the scope of the current period.

## How to verify the setup

Acceptance should query upper shelf, small package, saleable specification and the complete current-formats question. Returned blocks should distinguish example from reference. The answer may explain packaging used in the position example while leaving actual current formats dependent on the booklet. After obtaining it, inspect applicable period, actual processing and index state before testing whether new citations use that source. Successful upload does not establish matched periods or removal of the earlier example as a list substitute. Preserve original-to-parsed comparisons and check continued expansion of the example scope.
