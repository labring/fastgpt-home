# Franchise fee settlement: citation tracing for product questions

## What the documents look like

Franchise fee and deposit settlement handles money movement and breach deductions. It does not perform government filing. The records come from finance systems, franchise contracts, bank statements, and store violation records. Daily documents include franchise fee invoices, deposit ledgers, deduction notices, and contract payment schedules. Disputes concentrate on fund disagreements, franchise litigation, and deposit refund divergence, so product material question answering must return to specific document text. Amounts, payment terms, and deduction reasons in an answer need a checkable source.

The update frequency is monthly and per deduction. This page does not derive batch synchronization or real-time trigger mechanisms from that fact.

## Constraints at the citation tracing step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Its output is a citation array whose length may be zero. An empty array still passes through the output link. The citation limit is controlled by tokens. The minimum relevance value takes effect only in semantic retrieval or when result reranking is used. Neither one acts as a permission or entity filter. A retrieval result is not an authorization result. Hybrid retrieval merges through RRF. Reranking requires a model and must be enabled by configuration. Image retrieval requires image input and corresponding model capability. These paths are not guaranteed to execute on every request.

Hypothetical drill sample: the source text reads, "A deduction notice for a franchisee dated March 2025 states that the deduction reason is item 7 of the store violation record, and the amount matches the deduction column of the deposit ledger for that month; the contract payment schedule shows the payment term for this franchise fee as March 31, 2025." The draft sentence to be judged reads, "The March 2025 deduction for this franchisee has completed approval and has been deducted from the deposit." That sentence concerns approval status and fund execution. The material does not state an approval record or a bank statement, so the judgment is not supported. If the draft sentence instead reads, "The reason stated in the deduction notice matches the amount in the deduction column of the deposit ledger for that month," it shares the same subject, the same period, and the same field as the source text, so it can be supported.

## Three common errors

1. Treating a retrieval hit as an authorization basis. The error is using cited content to show that a deduction was approved. The check is to take the draft sentence and the deduction notice source text as input, compare whether an approval field exists, and record not supported when the source text lacks that field.

2. Treating an empty citation array as a workflow error. The error is concluding that an empty array means the node failed. The check is to input the paper value [], compare whether the downstream design still continues execution, and observe whether the output link passes through.

3. Forcing joint association across vector models. The error is selecting bases with different vector models together. The check is to verify each base's vector model identifier, exclude those that do not match, and record the actual observation without inferring a missed-recall result.

## How to verify the setup

- Verification one: input the deduction notice source text and the draft sentence from the hypothetical sample, compare whether approval and fund execution fields are stated, and judge not supported when the source text does not state them. The condition is met when the judgment conclusion matches the scope of the source text.

- Verification two: input the matching-amount statement from the hypothetical sample, compare the values of the same period and same field in the deduction notice and the deposit ledger, and treat it as supported when the two agree. The condition is met when the citation points to both source texts.

- Verification three: input the paper value [], compare whether the downstream node still executes, and treat the output link passing through as meeting the condition. Do not claim that a fabricated rule retrieval will necessarily return an empty array.
