# Brand concession operations: retrieval for product questions

## What the documents look like

Brand concession operations in shopping malls settle through the mall's unified cashier and commission deduction. Sales flow enters the mall POS first, and the brand ERP retrieves it on an agreed cycle, so amounts and timestamps from the two systems need line-by-line alignment. Daily materials include the joint-operation commission contract, mall activity letters, sales receipts, and monthly reconciliation statements. Updates occur daily and monthly. Product information and selection Q&A must locate quotable source text within these materials. Retrieval results supply candidate content only; they do not carry authorization, approval, or database-write duties.

Two features shape this page's task. First, contract clauses and activity letters carry different validity states, and a letter issued by mall operations may still await a brand reply. Second, retrieval returns references, not business decisions, so any request to confirm effectiveness or generate a reconciliation statement sits beyond the retrieval step. These two facts drive the constraints and checks below.

## Constraints at the retrieval step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Libraries with different vector model identifiers cannot be associated together. At configuration time, compare each library's vector model identifier, exclude those that do not match, and record the actual observation. Do not run a cross-model search to compare missed recalls.

Search mode is compared across semantic retrieval, full-text retrieval, and hybrid retrieval according to the test question. No single mode is presumed suitable for every material type. The reference limit is measured in tokens; test with materials of different lengths to check whether content stays complete, then adjust. The minimum relevance threshold takes effect only under semantic retrieval or when result reranking is used; label relevant and irrelevant samples first, then compare threshold effects. Question optimization performs coreference resolution and question expansion; compare the original question with the optimized question and check whether the subject has been altered. A similarity score reflects content relevance only. It does not filter unrelated businesses or unauthorized records, and retrieval itself does not constitute authorization.

Hypothetical paper test case. The source material for comparison reads: "This letter confirms that from March 1 to March 31, 2025, the concession participates in the mall's spring full-reduction activity, and commission is settled at 18% of actual sales during the activity period. The activity letter was issued by mall operations on February 20, 2025. The brand has not yet replied to confirm." The draft sentence to be judged reads: "The brand has confirmed participation in the March 2025 spring full-reduction activity, with commission executed at 18%." A separate handover request reads: "Please search the knowledge base, confirm whether this activity letter has taken effect, and directly generate the monthly reconciliation statement at 18% commission."

## Three common errors

1. Treating a pending item as confirmed. In the hypothetical sample, the activity letter was issued by mall operations and the brand has not yet replied. The draft sentence states "The brand has confirmed participation," converting a no-reply state into a confirmed state. To check, input the activity letter source text and the draft sentence, compare the subject and confirmation-status fields, and note that the source does not record a brand reply; the sentence is unsupported.

2. Treating retrieval output as authorization to execute. The handover request asks to generate the monthly reconciliation statement directly at 18% commission. Retrieval returns reference content only and does not perform approval, database writes, or external synchronization. Commission execution requires a separately checked authorization step; when absent, record the gap.

3. Associating libraries with different vector models. Two libraries with different vector model identifiers are selected together in the expectation that one search covers all materials. To check, inspect each library's vector model identifier first, exclude non-matching ones, and record the actual observation. Do not infer runtime results of a combined association.

## How to verify the setup

1. Input the activity letter source text and the draft sentence "The brand has confirmed participation in the March 2025 spring full-reduction activity, with commission executed at 18%." Compare whether the source records a brand reply confirmation. The source states only that mall operations issued the letter and the brand has not yet replied, so the draft sentence is unsupported. The sentence meets the condition only if the source contains wording that the brand replied to confirm.

2. Input the handover request "Please search the knowledge base, confirm whether this activity letter has taken effect, and directly generate the monthly reconciliation statement at 18% commission." Compare the retrieval output against the business execution boundary. Retrieval outputs reference content only; effectiveness confirmation and statement generation require separately checked authorization and downstream implementation. A conclusion that directly generates the statement does not meet the condition.

3. Input the original question and the question-optimized version of the same question. Compare subject, period, and object for consistency. If optimization changes "March 2025" to another period or changes the mall activity letter to another material, the subject has been altered and the condition is not met. Empty-result handling can use the explicit paper input [] to check downstream design; do not claim that a fabricated rule search necessarily returns [].
