# Channel diversion reviews: vector indexes for product questions

## What the documents look like

Channel diversion reviews concern regional and price order. The working material covers goods flow and selling prices, and it does not cover rebate amounts. Typical documents include diversion complaint forms, anti-counterfeit code records, distributor shipment records, e-commerce platform price screenshots, and investigation photographs. The update rhythm is weekly or irregular.

For product information and selection questions, these materials must be retrieved, compared, and cited. The vector model and index configuration therefore affects whether a complaint description can be matched to a specific code segment, batch, and regional authorization scope. Most material is textual. Investigation photographs are image inputs, and whether they can be retrieved depends on whether a corresponding index was built at the ingestion stage.

## Constraints at the vector indexes step

Knowledge bases associated for retrieval must use the same vector model. Before selection, check the actual model and its supported input types. One original data block can be associated with multiple indexes. Index content and original content are checked separately, and an index should use complete and focused information. Retrieval coverage and index length are weighed against the sample.

Image retrieval depends on whether an image description or image vector was generated at ingestion. Uploading an image at query time does not by itself guarantee a hit. Semantic recall and relevance scores do not perform permission or entity isolation, and retrieval results are not an authorization basis. Hybrid retrieval fuses multiple result paths through RRF. Reranking requires a model and must be enabled according to settings. These paths are not all executed on every request.

Hypothetical drill sample: a brand channel control staff member receives a paper document. The original text reads: "Complaint form number A-07 reports that authorized distributor D-12 in the East China region sold products of batch B-2026-02 on an e-commerce platform at 18% below the suggested retail price between 2 March 2026 and 8 March 2026. One anti-counterfeit code record screenshot and one store page screenshot are attached. Current status is pending verification." A draft sentence awaiting judgment reads: "This distributor has completed a diversion act and a penalty should be executed." This draft sentence conflicts with the "pending verification" status in the original text, and no penalty authorization is present. It cannot be output as a confirmed fact.

## Configuration and implementation checks

| Configuration item | Hypothetical trial starting point | Reason and comparison method |
| --- | --- | --- |
| Vector model | One same model associated across all candidate libraries | Check the actual model identifier first, exclude libraries with different models, and do not run cross-model comparison |
| Index content | Separate indexes for complaint form, code segment, and region | Compare against the original text item by item and observe whether recall covers the corresponding fields |
| Image index | Generate image description index at ingestion | Check the ingestion stage separately from query-time image upload to confirm whether an index was built |
| Search mode | Hybrid retrieval | Compare against semantic retrieval and full-text retrieval on the same set of paper questions |
| Reference cap | Hypothetical trial starting point set to 3000 tokens | Compare against default text index length and observe whether references are truncated |
| Minimum relevance | Hypothetical trial starting point set to 0.4 | Compare against rerank scores and observe whether low-scoring fragments are filtered |

These values are hypothetical trial starting points. The basis is the length of a single record in the sample material and the number of candidate fragments. They are adjusted after comparison with actual reference results for the same question set.

## Three common errors

1. Treating a retrieval hit as authorization confirmation. Input is the complaint form original text above together with the draft sentence. Compare the retrieval result against the status field in the original text and observe whether "pending verification" is misjudged as a completed penalty. Retrieval does not produce authorization, and penalty execution requires separate confirmation.
2. Associating libraries that use different vector models. Input is two knowledge bases with different model identifiers. Compare the model identifiers and observe whether both are selected together. The correct action is to check identifiers, exclude those that do not match, and record actual observations without inferring runtime results.
3. Treating a query-time image upload as an established image index. Input is an investigation photograph and the knowledge base ingestion record. Compare whether an image description or image vector was generated at ingestion and observe whether image-to-image search returns that photograph. When no index was built at ingestion, a query-time upload does not guarantee a hit.

## How to verify the setup

1. Input the complaint form original text above with the question "Which region and batch does A-07 involve?" Compare whether the returned reference contains the East China region and batch B-2026-02. Observe whether the reference content matches the original text and does not append a penalty conclusion. The expectation is that the reference covers the corresponding fields, without guaranteeing a first-position hit.
2. Input the draft sentence "This distributor has completed a diversion act and a penalty should be executed." Compare the output against the "pending verification" status in the original text and observe whether the evidence gap is preserved. The expectation is that a pending-verification statement is not presented as completed, and no authorization clause is fabricated.
3. Input an empty paper result []. Compare whether the downstream design carries the reference chain through and observe whether the chain works when output length can be zero. The expectation is that the chain works, without claiming that a fabricated rule retrieval necessarily returns an empty array.

After model or index adjustments, use the same set of paper questions to compare against the original reference text. Do not promise results based on vector scores alone. The same-vector-model requirement for retrieval libraries applies only to knowledge base association and does not extend to external systems.
