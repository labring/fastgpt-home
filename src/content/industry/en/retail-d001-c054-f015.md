# Channel diversion reviews: retrieval for product questions

## What the documents look like

Channel diversion review covers regional and price order, and it does not handle rebate amounts. The working materials come from anti-counterfeit code systems, e-commerce platform price pages, distributor shipment records and market inspections. The documents handled day to day include diversion complaint forms, anti-counterfeit code records, penalty notices and investigation photos. Category confidence is roughly as described, and material update frequency is weekly plus irregular.

These materials shape retrieval and recall directly. A complaint form describes a region and a subject. An anti-counterfeit code record points to the direction of goods movement. A penalty notice carries a stage status. Investigation photos are image input. Product information and selection question answering needs to organize the above materials by library, and retrieval results are returned only as reference content. Business authorization and penalty execution belong to downstream steps.

## Constraints at the retrieval step

A knowledge base consists of libraries, collections and data, and the smallest search unit is the library. One search node can associate one or more knowledge bases that use the same vector model. Libraries with different vector models cannot be associated together. Retrieval schemes include semantic search, full-text search, hybrid search, question optimization and result reranking. Hybrid search merges multiple result paths through RRF. Rerank scores can be used for filtering. The reference limit is measured in tokens. The minimum relevance value takes effect only under semantic search or when result reranking is used. Image retrieval requires corresponding image input and model capability. Reranking requires a model and must be enabled in settings. Retrieval is the recall process for reference content, and it does not carry permission or entity isolation.

Hypothetical paper exercise sample: on 10 March 2025 a brand channel control team received a diversion complaint form whose original text reads "Complaint subject: East China distributor A; product involved: anti-counterfeit code segment C of batch B; complaint reason: this batch appeared on an e-commerce platform listed below the suggested retail price." On the same day an anti-counterfeit code record reads "Anti-counterfeit code segment C was signed for by distributor A on 20 February 2025, signed quantity 200 units." A draft sentence awaiting judgment reads "Distributor A has completed penalty execution for this batch of diversion." Judgment of this draft sentence requires evidence of the same subject, the same period and the same field.

## Configuration and implementation checks

| Configuration item | Setting or check relevant to this page | Relation to the sample |
| --- | --- | --- |
| Associated knowledge bases | Select one or more libraries that use the same vector model | Check the vector model identifier for the complaint form library and the anti-counterfeit code record library separately |
| Search mode | Semantic search, full-text search or hybrid search | Code segment C is an exact code, so compare full-text or hybrid search |
| Reference limit | Measured in tokens, adjusted by actual material length | The sample text is short; this hypothetical trial starts at 512 tokens and compares completeness against a longer complaint form |
| Minimum relevance | Takes effect only under semantic search or result reranking | Label relevant and irrelevant samples first, then adjust the threshold |
| Question optimization | Coreference resolution and question expansion | Compare the original question with the optimized question, and check whether the subject was altered |
| Result reranking | Requires a ReRank model, enabled in settings | When candidates are numerous, compare order before and after reranking |

## Three common errors

1. Treating the association of multiple knowledge bases as permission to associate across vector models. The search node requires the same vector model. When libraries show different identifiers, check the identifier first, exclude the non-matching one, and record the actual observation. Do not then infer a runtime result.
2. Treating minimum relevance as permission or entity filtering. This parameter is a 0-1 filter threshold. It does not exclude unrelated businesses or unrelated records, and it does not perform authorization judgment.
3. Treating the draft sentence awaiting judgment as completed penalty execution. In the sample the draft says "has completed penalty execution," while the complaint form and the anti-counterfeit code record only state the complaint reason and the signing fact. No penalty notice, signature or execution status is recorded, so the claim is unsupported.

## How to verify the setup

1. Input the sample complaint form text and the anti-counterfeit code record text, and compare whether the draft sentence "Distributor A has completed penalty execution for this batch of diversion" has evidence of the same subject, the same period and the same field. The condition is met only when an original penalty notice stating the penalty execution status appears. The current sample supports a conclusion of pending verification only.
2. Input anti-counterfeit code segment C as the search term, and compare whether the reference content returned by full-text search and by semantic search contains that code segment. The exact-code recall condition is met only when the reference content contains the record corresponding to code segment C. If an empty array is returned, use the explicit paper input [] to check the downstream design. Do not claim that a fictional rule necessarily returns empty.
3. Input the same complaint form question, and compare whether the subject in the search term remains distributor A and batch B before and after question optimization is enabled. The question optimization condition is met only when the optimized question retains the original subject and object. When the subject is altered, record it as not met.

This page addresses only channel diversion review, product information and selection question answering, and knowledge base retrieval and recall. During operational handover, the authorization status of materials, operations and requests must be kept clear. Retrieval and forms are not authorization execution.
