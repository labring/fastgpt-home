# Livestream sample inspections: citation tracing for product questions

## What the documents look like

Sample inspection for livestream selection happens before a broadcast. The question is whether a product can be sold and whether it suits on-camera demonstration. The working documents are sample evaluation forms, quality inspection reports, supplier qualification files, and prohibited-item lists. These arrive from supplier materials, testing-agency reports, platform negative catalogs, and historical return rates.

Two timing facts shape this page. First, updates run weekly and per product, so the same item can carry different report and qualification versions at different moments. Second, the deciding question is narrow: does a particular document support a particular sentence. Citation tracing means matching each claim in a draft answer back to checkable source text, not judging whether the product is attractive or profitable.

## Constraints at the citation tracing step

The knowledge base search node can link one or more knowledge bases that share the same vector model, used for vector search. Its output is a citation array, and the length may be zero. A zero-length result still lets the downstream path run, so an empty array is a legitimate output rather than a workflow fault.

Retrieval performs recall and ranking. It does not perform authorization checks. The minimum relevance value is a filtering threshold, and it does not isolate businesses or unauthorized records. Hybrid search merges multiple recall paths through RRF. Rerank requires a model and must be enabled by configuration. Image retrieval requires image input and matching model capability. These paths are listed in the overall retrieval flow and do not all execute on every request.

Hypothetical paper exercise sample. Source text for comparison: "Sample evaluation form S-0417 records that a batch of insulated cups was submitted for testing on March 12; testing-agency report JC-2288 concludes that heavy-metal migration complies with the standard; supplier qualification file ZZ-0912 is valid until March 31 of the following year; the product does not appear in the current prohibited-item list QJ-0301." Draft sentence to be judged: "This insulated cup has completed quality inspection and obtained a passing conclusion, and can be listed and sold in this livestream."

Comparing sentence by sentence: report JC-2288 supports only the testing conclusion; qualification ZZ-0912 supports only the validity period; the prohibited-item list supports only a not-listed status. The phrase "can be listed and sold" describes an authorization and execution action. None of the materials state it, so that part remains unsupported.

## Configuration and implementation checks

| Configuration or check item | Hypothetical starting point for this exercise | Reason and comparison method |
| --- | --- | --- |
| Linked knowledge bases | Select the sample evaluation form base and the inspection report base that share one vector model | Official guidance requires the same vector model before bases can be linked together; verify the identifier first and exclude bases that differ |
| Search mode | Hybrid search | Number and model queries rely on full-text hits while natural-language queries rely on vectors; compare recall against semantic search alone |
| Citation limit | Hypothetical starting point of 3000 tokens | Documents control citation length in tokens; compare against 1500 and 6000 to see whether answers truncate or become too broad |
| Minimum relevance | Hypothetical starting point of 0.4 | This value takes effect only in semantic search or with reranking; compare candidate counts against 0.2 and 0.6 |
| Rerank | Enabled | Hybrid search widens the candidate range, and rerank scores can be used for filtering; compare ordering stability against leaving it off |
| Citation display | Compare each answer line against source text | Use a traceable sample to check source display; answer fluency does not substitute for source evidence |

## Three common errors

1. Treating an empty citation array as a retrieval failure. Observable error: a paper input of `[]` is judged as a broken workflow. Check: supply the empty array, compare how the downstream node is designed to receive it, and observe whether the path continues.

2. Treating a retrieval hit as authorization. Observable error: the presence of report JC-2288 is used to infer that the product may be listed. Check: compare the draft sentence against the source text and observe whether the source states listing permission; if it does not, record the claim as unsupported.

3. Linking knowledge bases that use different vector models. Observable error: bases with different vector models are selected together. Check: verify each base's vector model identifier, exclude those that do not match, and record what is actually observed rather than running a cross-model search to compare missed recall.

## How to verify the setup

- Verification one. Input the source sentence "testing-agency report JC-2288 concludes that heavy-metal migration complies with the standard." Compare the draft sentence "this insulated cup has completed quality inspection and obtained a passing conclusion." The condition is met when the answer restates only the testing conclusion and does not extend it into listing permission.

- Verification two. Input the paper citation array `[]`. Compare it against the downstream node's design. The condition is met when the path continues to execute without being reported as an error.

- Verification three. Input the prohibited-item query "is the insulated cup listed in QJ-0301." Compare the returned content against the list text. The condition is met when the answer presents only the not-listed status and keeps unstated parts as pending verification.

Authorization status must be checked separately. A pending review does not constitute approval, a quotation validity period does not indicate a supply period, and signing, reaching cooperation, and contract effectiveness are three distinct facts. Retrieval and form-collected values do not constitute authorized execution; database writes and external synchronization require a separately described downstream implementation.
