# Short-video affiliate sales: vector indexes for product questions

## What the documents look like

Short-video affiliate sales rely on long-term content exposure and product-link conversion rather than live explanation. The daily and weekly materials are short-video scripts, attached-product lists, commission plans and violation feedback. A product-information and selection Q&A task needs to place the product description in a script, the product name and category in an attached-product list, the rate and validity period in a commission plan, and the handling status in violation feedback into one search scope for operations staff.

These materials differ in subject, object and state. A script records spoken and visual content. A list records product identifiers and attachment status. A commission plan records a rate and an effective interval. Violation feedback records a video and a handling conclusion. Vector search runs against a whole library; collections only classify data and do not affect search results. Index content should be complete and focused, and retrieval coverage against index length needs to be weighed against actual samples.

## Constraints at the vector indexes step

Knowledge bases associated for retrieval must use the same vector model; check the actual model and input type first. One source data block can be linked to several indexes, and the index and the source text are checked separately. Image retrieval also depends on whether an image description or image vector index was generated at ingestion, and the query side alone does not settle this. After a model or index change, compare cited source text using the same set of questions rather than promising an outcome from a vector score alone.

Semantic retrieval depends on vector distance, full-text retrieval depends on keyword hits, and hybrid retrieval fuses the two paths through RRF. Minimum relevance is a filter threshold that takes effect only in semantic retrieval or when result reranking is used, and it does not carry permission or entity-isolation duties. The citation limit controls, in tokens, the maximum content cited per search. Retrieval and authorization are separate stages: retrieving a piece of material does not mean the corresponding commission plan has been approved, and it does not mean the attachment status has taken effect.

## Configuration and implementation checks

The items below concern the product-information and selection Q&A task on this page and cover the vector model identifier, index construction, search mode and filter parameters. The values are starting points for this hypothetical exercise only, used to explain the comparison method, and are not official defaults.

| Configuration item | Hypothetical starting point for this exercise | Reason and comparison method |
| --- | --- | --- |
| Vector model of associated knowledge bases | Same model identifier | Check model identifiers across libraries first, exclude inconsistent ones, and do not associate across models |
| Index content | Product name, category, commission rate and validity period indexed as separate entries | Compare with the source script text and confirm index fields match the source |
| Search mode | Hybrid retrieval | Compare with semantic retrieval alone and observe hits on identifier-type questions |
| Minimum relevance | 0.4 | Compare with 0.3 and 0.5 and observe whether irrelevant fragments decrease |
| Citation limit | 2000 tokens | Compare with 1500 and 3000 and observe whether cited content covers the fields needed for a judgment |
| Result reranking | Enabled | Compare with results when not enabled and observe changes in candidate ordering |

## Three common errors

1. Associating libraries that use different vector models. The input is two libraries with different model identifiers. Compare the model identifier field and observe whether the inconsistent library is excluded. Associating without checking identifiers means the retrieval path cannot run as the documentation describes.
2. Treating a vector score as authorization evidence. The input is one retrieved commission-plan result. Compare the retrieval score with the plan status field and observe whether the plan is pending review. A high score does not mean the plan has been approved.
3. Treating an image query as an established image index. The input is one product image. Compare whether the ingestion record contains an image description or image vector index, and observe whether the query side returns a result. Uploading an image at query time does not fill an index missing at ingestion.

## How to verify the setup

Hypothetical exercise sample. the source material reads a short-video script states "the featured product is a portable juicer cup, category kitchen small appliances, attached-product link product A." The attached-product list states "product A, kitchen small appliances, attachment status listed." The commission plan states "product A commission rate 15%, validity 1 March 2025 to 31 March 2025, status pending review." Proposed judgment sentence: "The product A commission plan has taken effect and settlement can proceed at 15%."

- Verification one: input the source material and the proposed judgment sentence, compare the commission plan status field with the phrase "has taken effect," and observe whether the status field is pending review. If it is pending review, the proposed judgment sentence is unsupported.
- Verification two: input the source material and the proposed judgment sentence, compare the validity interval with the settlement statement, and observe whether any record shows settlement has occurred. The material contains no settlement record, so this part remains to be verified.
- Verification three: input the query "which listed products are in the kitchen small appliances category," compare the returned citation with the source list, and observe whether the returned content includes product A and its attachment status. If an empty array is returned, handle it as an empty result and check the downstream design, without asserting that a rule-based retrieval must return empty.
