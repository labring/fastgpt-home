# Group-buy leader operations: model connections for product questions

## What the documents look like

Group-buy leader operations manages community pickup nodes and commission, and does not perform cold-chain quality inspection directly. The working material comes from the group-buy back office, leader community groups, order details, and after-sales records. The recurring documents are leader agreements, commission tables, pickup lists, and community announcements. These update daily and per group.

For product information and selection questions, each answer has to keep its source, date, and group session, then check the product, the supply scope, and the pickup arrangement separately. A commission table and a community announcement can describe the same product category while carrying different effective scopes, so the answer must state which document and which period it relies on.

## Constraints at the model connections step

Model access depends on AI Proxy. From V4.17.0, the App service and any Admin service that reuses the App/Service configuration must set `AIPROXY_API_ENDPOINT` and a non-empty `AIPROXY_API_TOKEN`. Missing either one causes startup validation to fail. `AIPROXY_API_ENDPOINT` takes the service root address and does not append `/v1`. Older OpenAI environment variables or a single-model custom request address cannot replace these two settings.

The system needs at least one language model and one index model before it works normally. The language model handles text dialogue; the index model indexes text blocks for retrieval. When selection questions involve image material, the model must have image input capability. Tool calling and extraction are checked against the chosen mode, and extraction also depends on the prompt mode listed in the documents. These capabilities are checked item by item against the inputs the application actually needs, and cannot be inferred from a model name.

Retrieval returns relevant text blocks and does not perform permission or entity isolation. Only libraries under the same vector model can be associated together. Libraries under different vector models are first checked by identifier, and those that do not match are excluded; a cross-model retrieval is not run to compare missed recall. A rerank model takes part only when it exists and is enabled by configuration. Image retrieval needs the corresponding image input and model capability. These are optional paths and do not mean every request executes all of them.

## Configuration and implementation checks

The following is a hypothetical paper exercise used to explain the checking method. It does not mean any real deployment or test has taken place.

Source material (hypothetical): A community group-buy platform's Leader Agreement, clause 3, states that "a leader may forward product material provided by the platform within an authorized group session." The March 2026 version of the Commission Table states that "leaf vegetables are commissioned at 5% of the pickup amount." The Community Announcement dated 18 March 2026 states that "this group supplies only Category A products this week; Category B products are suspended from ordering."

Draft sentence to be judged (hypothetical): "Leaders may forward all product material, and Category B products continue to accept orders."

The table below records paper configuration checks for this page.

| Configuration item | Assumed starting point for this exercise | Reason for the choice and comparison method |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | Assumed filled as `http://aiproxy:3000` | The document requires the root address without `/v1`; compare against a form that ends with `/v1` |
| `AIPROXY_API_TOKEN` | Assumed filled with a non-empty administrator token | The document requires a non-empty token consistent with the server; check the administrator token source and server consistency, and check application key use separately |
| Language model | Assumed one language model enabled | The document requires at least one; compare against a state with no language model enabled |
| Index model | Assumed one index model enabled | The document requires at least one; compare against a state with no index model enabled |
| Model capability | Assumed checked against the inputs the question needs | The document requires checking by input; compare against inferring capability from the model name alone |
| Knowledge base file parsing concurrency | Assumed `DATASET_PARSE_MAX_PROCESS=10` | The document lists 10 as the default value, used here as the starting point; compare against the actual queue backlog |

## Three common errors

1. Writing `AIPROXY_API_ENDPOINT` as a full request address that includes `/v1`. The input is the assumed address string; the comparison object is the document requirement that `/v1` is not appended; the observable result is whether that string ends with `/v1`.
2. Using an application API key as `AIPROXY_API_TOKEN`. The input is the assumed token value placed in the field; the comparison object is the document requirement of an administrator token consistent with the server; the observable result is whether that value matches the AI Proxy server configuration.
3. Inferring image input or tool calling capability from the model name. The input is the assumed model name together with the input types the question needs; the comparison object is the document requirement to check model capability against the application's needed inputs; the observable result is the value of the corresponding capability field in the model configuration.

## How to verify the setup

The checks below use the hypothetical sample above. They state what to compare and what is expected, and do not claim that any test has been run.

1. Input the hypothetical draft sentence "Leaders may forward all product material, and Category B products continue to accept orders." Compare it against the authorization scope in clause 3 of the Leader Agreement and the supply scope in the Community Announcement dated 18 March 2026. When the same field carries mutually exclusive values in the same period, that is a contradiction. If the draft sentence exceeds the agreement's authorization scope, or does not match the announcement's supply scope, it is unsupported.
2. Input the assumed `AIPROXY_API_ENDPOINT` string. Compare it against the document requirement that `/v1` is not appended. The observable result is whether that string ends with `/v1`; if it does, it does not match the document requirement.
3. Input the assumed `DATASET_PARSE_MAX_PROCESS=10`. Compare it against the default value 10 listed in the document. The observable result is whether this starting point matches the default; if it does not, record the difference and the reason for the choice, and do not treat it as the official default.

If retrieval returns an empty result, an explicit paper input of `[]` can be used to check how the downstream design handles an empty reference. This does not support inferring that some invented rule always returns empty. The model status probe's alert webhook and retry mechanism are capabilities described in the document; this page does not claim they have been configured or triggered.
