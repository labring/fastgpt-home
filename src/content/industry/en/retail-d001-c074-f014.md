# Cross-border resale returns: model connections for product questions

## What the documents look like

Cross-border return refurbishment and resale handles reverse logistics and item condition. The working materials come from overseas warehouse WMS records, TikTok return centers, Amazon return reports and item inspection photographs. Day-to-day documents include return inspection sheets, refurbishment records, scrap sheets and relisting lists. Product information and selection questions must connect return grades, refurbishment and packaging arrangements, and scrap-or-resale decisions to specific model information. Materials update daily or per batch; that cadence does not change how this page is configured.

## Constraints at the model connections step

Model connections depend on AI Proxy. Both App and Admin must set `AIPROXY_API_ENDPOINT` and a non-empty `AIPROXY_API_TOKEN`; if either is missing, startup validation fails. `AIPROXY_API_ENDPOINT` takes the service root address and does not append `/v1`. The system needs at least one language model and one index model. A model ID is the value of the `model` field in the request body and is globally unique; the model name is for display only. Model mapping maps the model FastGPT requests to the actual upstream model, for example `gpt-4o-test` mapped to `gpt-4o`. Channel priority ranges from 1 to 100, and a larger value is more likely to be selected first. Model probing covers only enabled system models; after a first failure the system retries at most 3 times, so a single round makes at most 4 attempts, and only when all 4 attempts fail is the model judged abnormal. Normal means response latency at or below 30s; high latency means above 30s. Knowledge-base retrieval and model connections are separate matters. A retrieval hit does not constitute authorization, and answers to selection questions require manual comparison against the source material.

Hypothetical drill sample: an overseas warehouse inspector submits a return inspection sheet whose text states "Subject: a Shenzhen cross-border seller; Object: model X-200 Bluetooth earphones; Status: outer packaging damaged, earphone body free of scratches; Date range: 1 March 2026 to 15 March 2026; Authorization boundary: limited to return inspection for this batch, excluding relisting approval." The refurbishment record for the same batch states "X-200 repackaged and received into stock as good condition." The draft sentence to be judged is "X-200 has completed relisting approval and can be sold directly." Judging that draft sentence requires comparing the authorization boundary in the inspection sheet with the actual status in the refurbishment record.

## Three common errors

1. Writing `AIPROXY_API_ENDPOINT` as a full request address that includes `/v1`. Check the input: the environment variable text. Compare: official text requires the root address without `/v1`. Observable result: if `/v1` is present, the value does not match the documented requirement and must be changed to the root address.
2. Treating a retrieval hit as relisting authorization. Check the input: the authorization boundary text in the hypothetical inspection sheet. Compare: the boundary states return inspection only, excluding relisting approval. Observable result: the draft sentence "has completed relisting approval" is unsupported, and the evidence gap must be recorded.
3. Reading the 4 attempts of model probing as 4 independent probes. Check the input: the probing description text. Compare: official text states at most 3 retries after the first failure, so at most 4 attempts in one round. Observable result: recording `attempts` as 4 rounds does not match the document.

## How to verify the setup

1. Input: the hypothetical inspection sheet text and the draft sentence. Compare: the claimed "has completed relisting approval" against the source authorization boundary "excluding relisting approval." Satisfied when: the draft sentence is judged unsupported and the authorization gap is recorded without inventing approval clauses.
2. Input: the hypothetical refurbishment record text "X-200 repackaged and received into stock as good condition." Compare: that record describes a refurbishment stock-in status, which is a different fact from a sales permission to "sell directly." Satisfied when: refurbishment completion and sales authorization are distinguished and the output states a pending-verification conclusion.
3. Input: the model mapping and model ID in the model channel configuration. Compare: whether the actual upstream `model` after mapping matches the model list inside the channel. Satisfied when: the mapping matches the documented example structure and model testing passes; if testing fails, record it as not passed and keep the original error without inferring a specific cause.
