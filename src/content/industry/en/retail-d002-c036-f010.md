# Multi-warehouse inventory: citation tracing for after-sales questions

## What the documents look like

Multi-warehouse allocation happens at the order-routing stage and decides which warehouse ships an order. It is a different step from courier handover. The main data comes from WMS, OMS, ERP inventory and platform inventory interfaces. Everyday materials include allocation rules, inventory synchronization tables, transfer orders and shortage alerts. Citation tracing answers a narrow question during after-sales support: when a reply cites an allocation rule, an inventory figure or a transfer status, which material, which version and which reconciliation produced that statement, and whether the material is in a state that can be cited. Source materials update daily or hourly. This page does not treat that update frequency as evidence of batch synchronization, real-time triggers or transaction-triggered mechanisms.

The knowledge base search node can associate one or more knowledge bases that share the same vector model. Its output is an array of citations, and the length may be zero. Even when nothing is retrieved, the output path still runs. Citation content is handed to the answering step, where each reply sentence is compared against the cited source text. The minimum relevance value is a filter threshold and applies only under semantic retrieval or result reranking. It does not perform permission or entity isolation. Retrieval by itself does not constitute authorization. A form collecting values is not the same as business verification, approval or a database write. Knowledge bases with different vector models cannot be associated together; check the identifier first and exclude those that do not match, rather than running a cross-model search to compare missed recalls. Hybrid retrieval merges multiple result paths through RRF, which is a fusion process and not a switch that can be turned on. Reranking requires a model and must be enabled under its settings. Image retrieval requires corresponding image input and model capability. Optional paths shown in the overall flow diagram do not mean every request executes all of them.

Hypothetical paper test case: A supply planning role keeps a document titled Allocation Rules (East China Region). Its body states: "From 1 March 2025, East China orders are shipped with priority from the Suzhou warehouse; when Suzhou sellable inventory falls below the safety stock, shipping moves to the Hangzhou warehouse." In the same batch of materials there is a Transfer Order (example number A-001) whose status field reads "pending review," with no approver signature recorded. A draft sentence is now to be judged: "East China orders are confirmed to ship from the Suzhou warehouse, and transfer order A-001 has been executed." The comparison target is whether the shipping-warehouse conclusion and the transfer order status in the draft sentence can be supported by the materials above.

## Constraints at the citation tracing step

The citation output must be passed to the answering step, and each answer sentence must be checked line by line against the cited source text. When a material carries a condition, a draft sentence that drops the condition is not supported by that material, even if the remaining words match. When a status field carries a value that is mutually exclusive with the value claimed in a draft sentence, the two conflict on the same field of the same object. When the material does not record a signature, that is an evidence gap and remains pending verification rather than becoming a denial. A pending review status does not demonstrate that operating permission is absent. Retrieval is not authorization, and a form value is not a business write. An empty citation array is a valid output and does not mean the workflow terminated with an error. The minimum relevance value is a filter threshold, not a final ordering rule, and it does not exclude unrelated businesses or unauthorized records. RRF is a fusion step applied to multiple retrieval paths, not a control that can be toggled. Image retrieval and reranking each require their own model capability and input conditions, and their presence in a flow diagram does not guarantee execution on every request.

Hypothetical test starting point: set the minimum relevance to 0.5. The reason is that the sample question contains an explicit subject and object, and the aim is to observe whether citations under that threshold still cover the source text of Allocation Rules (East China Region). The comparison object is the citation count and source coverage for the same query at a threshold of 0.3. This value is a hypothetical test starting point for this page and is not an official default.

## Three common errors

1. Treating "pending review" as already executed. In the sample, Transfer Order (example number A-001) has a status field of "pending review," while the draft sentence states "has been executed." These are mutually exclusive values on the same field of the same object, so the two conflict. A pending review does not demonstrate that operating permission is absent.
2. Treating a retrieval hit as authorization. Knowledge base search only returns citation content. It does not verify whether the shipping-warehouse priority was approved, and it does not write to any business database. The citation array length may be zero, and an empty array does not mean the workflow terminated with an error.
3. Forcing knowledge bases with different vector models into one association. Knowledge bases with different vector models cannot be associated together. Check the identifier first and exclude those that do not match, record only what is actually observed, and do not assert missed recalls or redundant returns.

## How to verify the setup

1. Input the source text of Allocation Rules (East China Region) from the hypothetical sample on this page together with the draft sentence, and compare the draft phrase "confirmed to ship from the Suzhou warehouse" against the source text "shipped with priority from the Suzhou warehouse; when Suzhou sellable inventory falls below the safety stock, shipping moves to the Hangzhou warehouse." The source text contains a priority condition, and the draft sentence omits it, so the statement is not supported. The condition is met only when the draft sentence retains the condition in full and matches the source text.
2. Input the status "pending review" of Transfer Order (example number A-001) together with the draft sentence "transfer order A-001 has been executed," and compare the same status field of the same document. The status field values are explicitly mutually exclusive, so the draft sentence conflicts with the source text. If the material records no approval signature, record that as an evidence gap and keep it pending verification.
3. Input a paper citation array of [] and check whether the downstream answering step continues to run and produces a no-citation notice. This input checks the downstream design and does not claim that a fictional rule search necessarily returns []. At the same time, check whether each reply sentence corresponds line by line to the cited source text, and do not substitute answer fluency for source evidence.
