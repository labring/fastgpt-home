# Tmall flagship operations: citation tracing for after-sales questions

## What the documents look like

Order fulfilment and after-sales question handling for a Tmall flagship store draws on four document groups: product listing pages, brand authorization letters, delivery commitment records, and after-sales work orders. Brand authorization and flagship store identity are preconditions for the storefront, and delivery commitment records connect directly to late-delivery compensation and store rating. The stated update frequency is daily and per order; this page does not extend that frequency into batch synchronization, real-time synchronization, or transaction-triggered mechanisms. In after-sales replies, customer service chat logs and after-sales work orders are commonly used to answer buyers, and a citation needs to lead back to the specific source text.

## Constraints at the citation tracing step

The knowledge base search node can select one or more knowledge bases that use the same vector model, and it outputs cited content as an array whose length can be zero. Even when no content is found, that output path still completes. An empty citation array is not a workflow error or termination. Retrieval results need to be passed to the answering step, and the answer must then be checked line by line against the cited source text. A similarity score is a filtering threshold; it does not perform permission or entity isolation, and retrieval itself does not constitute authorization.

Hypothetical paper exercise sample: a Tmall flagship store operator prepares a reply to a buyer asking about delivery time. The source texts available for checking are: first, the product listing page states "expected to ship before March 10"; second, the delivery commitment record states "this order is committed to ship before March 12, status confirmed"; third, the brand authorization letter states "authorization valid until December 31, 2025." The draft sentence to be assessed is: "This store commits to ship before March 10." That draft sentence conflicts with the March 12 date in the delivery commitment record and matches the March 10 date on the product listing page. The materials do not state whether this order has actually shipped, and they do not state whether compensation has been executed.

## Three common errors

1. Treating "expected to ship before March 10" on the product listing page as this order's delivery commitment, while ignoring the confirmed March 12 date in the delivery commitment record, so the draft sentence does not match the order's actual commitment.
2. Treating a retrieved brand authorization letter as proof that authorization remains valid. The letter states authorization valid until December 31, 2025, and whether it falls within the valid period needs to be checked against the current date; retrieving the material does not mean authorization status has been verified.
3. Treating an empty citation array as a workflow error. The node's citation array output can have a length of zero; an empty array does not mean retrieval failed, and it does not mean the downstream step must terminate.

## How to verify the setup

1. Enter the draft sentence from the hypothetical sample, "This store commits to ship before March 10," and compare it against the March 12 date in the delivery commitment record. If the draft sentence is changed to match the delivery commitment record, or is explicitly marked as governed by the order commitment, the checking condition is met.
2. Enter the brand authorization letter text "authorization valid until December 31, 2025" and compare the authorization period against the current date. If the current date falls within the period, the authorization period condition is met; if it falls outside, record it as pending verification and do not infer that authorization has lapsed or been renewed.
3. Enter a paper empty citation array [] and check whether the downstream answering step handles it as an empty array. If the downstream step does not error and does not fabricate cited content, the handoff checking condition is met; do not claim that a fictional-rule retrieval will necessarily return an empty array.

This page addresses only Tmall flagship store daily operations, order fulfilment and after-sales question handling, and citation source tracing. Retrieval or a form is not authorization execution, and the authorization state of materials, actions, or requests during an operations handover must not be treated as approved or completed.
