# Douyin storefront operations: citation tracing for after-sales questions

## What the documents look like

Douyin storefront operations center on product cards and the store experience score. The working materials for order fulfillment and after-sales answering include product qualification pages, experience score detail sheets, shipping violation appeals, and store announcements. The supplied brief gives a daily and per-order update frequency; this page does not derive batch synchronization, full synchronization, real-time behavior, or transaction-triggered mechanisms from that frequency.

For citation tracing, the practical difficulty is version alignment. A qualification page has an effective range, an announcement has a stated start date, and an appeal record carries a review state. When a colleague or a consumer asks where a sentence came from, the answer must point to the specific material and its current state. If the qualification page, the experience score detail, and the appeal material differ in version, a quoted sentence may fail to correspond to the currently effective text.

FastGPT's knowledge base search node outputs cited content as an array, and the array length may be zero. Even when nothing is retrieved, the output path still runs. The citation limit is measured in tokens. The minimum relevance value takes effect only under semantic retrieval or result reranking. Hybrid retrieval merges multiple result paths through RRF, and ReRank is a second-pass sorting step. Retrieval does not perform authorization checks, and a similarity setting does not exclude unrelated business lines or unauthorized records. Linked knowledge bases must share the same vector model; libraries with different vector models cannot be linked together. The correct step is to check the identifier and exclude non-matching libraries, not to run a cross-model search in order to compare missed recalls.

## Constraints at the citation tracing step

The search node's documented behavior sets the boundary. Cited content is an array, and a zero-length array is a valid output rather than a workflow failure. The citation limit is expressed in tokens, which matters because chunks in a mixed knowledge base vary widely in length; a top-k count would be unstable across a question-answer library and a document library. The minimum relevance value is a filter threshold, not a final ordering rule, and it applies only under semantic retrieval or reranking. After question optimization, hybrid retrieval, image retrieval, or reranking, the final result may come from merged paths and need not follow a single vector similarity order.

None of these settings grant business authorization. A retrieved passage is evidence that content matched a query; it is not evidence that a refund was approved, that a shipping appeal succeeded, or that a colleague holds the authority to answer a consumer. The page keeps those distinctions separate: node behavior, configurable fields, manual verification actions, and business actions that require a separate downstream implementation.

Hypothetical paper exercise: On 10 March 2025, a Douyin store merchant prepares after-sales answering materials for verification. The product qualification page text to be checked reads: "The quality inspection report for this batch of goods is valid until 30 June 2025 and applies to order fulfillment answering scenarios." A store announcement from the same day reads: "From 1 March 2025, out-of-stock orders are handled under platform rules; the specific compensation is subject to platform determination." A draft sentence awaiting judgment reads: "The quality inspection report for this product is valid long term, and the out-of-stock compensation amount is determined by this store." The handover request reads: "Please confirm whether the draft sentence above can be used directly in after-sales answering." No approval, refund, appeal outcome, or deployment is claimed here.

## Configuration and implementation checks

| Configuration or check item | Hypothetical starting value for this exercise | Reason and comparison object |
| --- | --- | --- |
| Linked knowledge bases | Select only the qualification and announcement libraries whose vector model identifiers match | Compare the vector model identifier of each candidate library against the already selected library; exclude non-matching ones |
| Search mode | Hybrid retrieval | Compared with semantic retrieval alone, identifiers and validity dates need keyword hits |
| Citation limit | 2000 tokens as the hypothetical starting value for this exercise | Compare against the measured combined length of the qualification page and the announcement to avoid truncation |
| Minimum relevance | 0.5 as the hypothetical starting value for this exercise | Compare against the number of recalled items when the value is not applied, and observe noise |
| Result reranking | Enabled | Compare against ordering without reranking; used when candidates are numerous |
| Citation handoff | Pass the citation array to the answering step for item-by-item checking | Compare against the answer text to confirm each sentence has a corresponding source passage |

## Three common errors

1. Treating a retrieval hit as an authorization pass. Input is the after-sales answering request; compare the retrieval result against the authorization state; the observable result is that a citation exists while an approval record is absent, so the evidence gap must be recorded.
2. Treating the minimum relevance value as an entity or permission filter. Input is a cross-library query; compare that value against the business ownership of returned records; the observable result is that a high-relevance record may still belong to another business scope.
3. Writing RRF as a switch that can be turned on. Input is the hybrid retrieval configuration; compare the documented description against the available fields; the observable result is that RRF is a fusion process with no corresponding toggle item.

## How to verify the setup

1. Input the qualification page text and the draft sentence from the hypothetical exercise; compare "valid until 30 June 2025" against "valid long term"; the observable result is that the two values are mutually exclusive on the same field, so the draft sentence is not supported.
2. Input the announcement text and the second half of the draft sentence from the hypothetical exercise; compare "subject to platform determination" against "determined by this store"; the observable result is that the responsible party differs, so that part remains to be verified.
3. Input an explicit paper-level empty array `[]`; compare it against the design of the downstream answering step; the observable result is that the downstream step still executes. This does not assert that a search for a fictitious rule will necessarily return an empty array.

The public technical facts checked for this page are: the knowledge base search scope requires checking the selected knowledge bases and material versions, and only libraries with the same vector model can be linked together; the search node outputs a citation array whose length may be zero, and an empty array does not mean the workflow has errored and stopped; the citation output should be checked as handed to the answering step, with each answer sentence compared against the cited source text; traceable samples should be used to check source display, and thought process or answer fluency should not substitute for source evidence; current and historical document versions should be used to test sources, and whether a citation is adopted still depends on review against the effective version.
