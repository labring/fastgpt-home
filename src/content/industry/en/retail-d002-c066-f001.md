# Short-video affiliate sales: after-sales questions with HTTP integrations

## What the documents look like

For after-sales questions in Short-video affiliate sales, this page examines FastGPT HTTP integrations. Shoppable-video service reads check linked merchandise against the actual order. Script descriptions cannot replace dispatch or refund outcomes. The examples are hypothetical.

## Constraints at the HTTP integrations step

A proposed customer asks about an undelivered bundle shown in a video, but prior-step organization retains only a single-unit product name without order correspondence. Inspect the actual external contract for required order identity and lookup scope instead of sending a similar name for different goods. Bundle script wording describes promotion, not what this order purchased. A response showing label creation does not establish carrier receipt.

## Three common errors

Bundle-single-unit mismatch needs the prior passage, actual transmitted value and order relationship. Label creation promoted to collection requires real handoff evidence. Script wording promoted to fulfilled commitment needs this order’s actual outcome. These inspect subject, logistics stage and fact status independently of a nonempty response.

## How to verify the setup

Retain product-description origins and the real request. Add this order’s relationship and compare returned coverage. Variables may use available prior-step output, but populated text is not correct identity; authentication and conditions follow the actual contract. Dispatch, refunds, product linking and customer notices need separate business receipts. Reading does not perform those actions or establish universal applicability of video copy to service cases.
