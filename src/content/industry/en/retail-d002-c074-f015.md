# Cross-border resale returns: retrieval for after-sales questions

## What the documents look like

Returns refurbishment and resale handles reverse logistics and item condition. This chain differs from first-leg replenishment, and the two should not be conflated when after-sales questions are answered. The everyday materials are return inspection sheets, refurbishment records, scrap or write-off forms, and relisting lists. These come from overseas warehouse WMS, TikTok return centers, Amazon return reports, and item inspection photos. After-sales answers depend on these materials to address return grade, refurbishment arrangement, and the decision to scrap or resell. The retrieval result feeds directly into a reply draft.

Materials are produced daily or per batch. A single return number can appear in both an inspection sheet and a refurbishment record, and the field definitions must be checked document by document. The retrieval step locates the passage that corresponds to the current question. It does not perform approval, refund, or inventory writes.

## Constraints at the retrieval step

The knowledge base search node can associate one or more libraries that use the same vector model. Libraries built on different vector models cannot be associated together. The vector model identifier is checked first, non-matching libraries are excluded, and the actual observation is recorded. A cross-model retrieval is not run to compare missed recalls.

Cited content is output as an array, and its length can be 0. When a search returns no hit, that output path still completes, so the downstream flow needs a design for accepting an empty result. The minimum relevance value takes effect only under semantic retrieval or when result reranking is used. It is a filtering threshold, not a sorting rule, and it does not constitute a permission or entity isolation boundary. A retrieved material passage does not mean that the material has been authorized for refund, scrap, or relisting.

Hypothetical paper exercise sample: the source material reads, "Return number RT-0417, item is a folding chair, inspection conclusion is outer packaging damaged and main body intact, refurbishment record registration date is March 12, status is pending packaging." The draft sentence to be judged reads, "RT-0417 has completed refurbishment and can be relisted." The check compares the inspection conclusion and the refurbishment record status against the completion and relisting wording in the draft sentence. The material does not state relisting authorization, so the sentence is not supported.

## Configuration and implementation checks

| Configuration item | Hypothetical starting point for this exercise | Verification method |
| --- | --- | --- |
| Associated knowledge libraries | Associate only the returns refurbishment material library that uses the same vector model | Check the vector model identifier of each library and exclude inconsistent ones |
| Search mode | Run semantic retrieval and full-text retrieval once each | Compare the recalled content of the two paths using the same test question |
| Citation limit | Set a starting point based on the passage length of this material | Compare whether content stays complete against inspection sheet passages of different lengths |
| Minimum relevance | Hypothetical starting point for this exercise, chosen to filter clearly unrelated passages | Compare hit changes against labeled relevant and irrelevant samples |
| Question optimization | Enable for multi-turn follow-up scenarios | Compare the original question with the optimized question and check whether the subject was altered incorrectly |

The starting values are set only for this paper exercise and are not official default values. Hybrid retrieval merges multiple result paths through RRF; this is a process description and is not a switch.

## Three common errors

1. Treating a retrieval hit as authorized execution. The input is the RT-0417 inspection and refurbishment material. The comparison checks whether the material states relisting permission. The observed result is that the material shows only a pending packaging status, and the relisting wording in the draft sentence lacks support.
2. Using a similarity setting in place of entity isolation. The input is a question containing multiple return numbers. The comparison checks whether returned content is limited to the current return number. The observed result is that the relevance value affects only sorting and filtering and does not exclude materials for other return numbers.
3. Treating pending review as approved. The input is an entry whose refurbishment record status is pending packaging. The comparison checks whether a review approval record exists. The observed result is that no review conclusion is stated, so completed refurbishment cannot be determined.

## How to verify the setup

1. Input the RT-0417 source material and the draft sentence above. Compare the inspection conclusion and refurbishment record status against the draft sentence. The observed result is that the draft sentence is not supported by the material, and the evidence gap must be recorded.
2. Input a question containing only a single return number. Compare whether the returned citations cover the material for that return number. The observed result is that the citation length can be 0; for an empty result, the downstream design is checked against the paper input [].
3. Input a multi-turn follow-up. Compare whether the subject in the original question and the optimized question remains consistent. The observed result is that the optimized subject is not altered incorrectly; if it is altered, that comparison result is recorded.

All three checks are paper exercises. No retrieval, refund, or relisting operation was actually executed.
