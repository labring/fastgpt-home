# MCN operations: citation tracing for copy drafting

## What the documents look like

An MCN organization manages long-term account compliance for multiple creators at the same time. Product and marketing copy drafting draws on creator signing contracts, training records, violation handling forms and account scheduling documents. Whether a promotional sentence in a draft is supported by material depends on whether the subject, object, status or validity scope named in that sentence can be matched to wording in an existing document. Material updates follow a daily and weekly rhythm, so a drafting check has to confirm that the version of the material behind a sentence is still within its valid range. At the retrieval step, cited content is output as an array whose length may be zero; an empty array means the output path still runs through, and downstream design has to accept an empty citation.

Because the organization serves many creators rather than a single brand session, the same knowledge base can hold contracts and training records for different people. Retrieval returns candidate passages; it does not confirm creator identity, contract validity or authorization scope. A similarity score reflects how closely content matches a question and carries no entity isolation or permission filtering function. Hybrid retrieval merges multiple result paths through RRF, and a rerank model performs a second ordering of candidate text. None of these steps replaces line-by-line comparison against source wording.

## Constraints at the citation tracing step

Knowledge base search first checks the selected knowledge bases and material versions; only knowledge bases that share the same vector model can be associated together. The citation output is an array and may be empty. The search node itself does not establish whether a creator signed a contract, whether training was completed, or how long a promotion may run.

Hypothetical paper exercise sample. Source text one: "Creator A signed the Livestream Promotion Cooperation Contract on March 1, 2026, contract number HZ-2026-031, cooperation term through August 31, 2026." Source text two: "Training records show Creator A completed product promotion compliance training on March 5, 2026." Source text three: "The account scheduling table states that Creator A conducts a beauty category livestream on April 10, 2026." Draft sentence to be assessed: "Creator A has passed compliance training and can promote beauty products long term." The phrase "has passed compliance training" can be compared against source text two. The phrase "long term promotion" has no corresponding validity-scope wording in the materials and remains an item awaiting verification.

A minimum relevance value is a filtering threshold and applies only under semantic retrieval or when result reranking is used. It is not a final ordering rule. Enabling question optimization, hybrid retrieval, image retrieval or reranking can produce a merged result set that is not strictly ordered by a single vector similarity. Citation upper limit is measured in tokens per search, not in a top-k item count. Thinking budget belongs to the thinking configuration of a model and does not serve as a citation token limit.

## Configuration and implementation checks

| Configuration item | Hypothetical starting point for this exercise | Reason and comparison method |
| --- | --- | --- |
| Associated knowledge bases | Select the knowledge bases holding creator signing contracts and training records | Check the vector model identifier of each base first, exclude those with a different vector model, and do not run cross-model retrieval |
| Search mode | Hybrid retrieval | Copy checking involves both exact queries such as identifiers and semantically similar content; compare against the result of semantic retrieval alone |
| Citation upper limit | Set by the implementer in the documented token unit | This value is a starting point for this exercise; compare cited content length at different values; top-k is not used |
| Minimum relevance | Set by the implementer as a 0-1 value | This value applies only under semantic retrieval or result reranking; compare recalled content before and after adjustment |
| Result reranking | Enabled according to whether a rerank model is available | When enabled, its score is used for filtering; compare against candidate ordering without it |
| Reply format | Select json_schema when a fixed structure is required | Ordinary verification keeps the default; compare against downstream reading requirements |

The optional paths shown in the overall retrieval diagram do not mean every request executes all of them. Image retrieval requires a corresponding image input and model capability. Reranking requires a model and must be enabled by configuration. When no image input or rerank model is present, those paths are not part of the request.

## Three common errors

1. Treating a retrieval score as an authorization judgment. Input: a creator contract passage with a relatively high similarity score. Comparison: whether that passage contains the contract number, validity period and other subject and scope information. Observable result: the score is high while the draft sentence still lacks a validity-scope basis.
2. Treating an empty citation array as a workflow halt. Input: an empty array output by the search node. Comparison: whether the downstream node is designed to accept an empty citation. Observable result: the empty array still runs through the output path.
3. Treating a thinking budget as the citation upper limit. Input: a budget value in the thinking configuration. Comparison: the token unit of the citation upper limit. Observable result: the two differ in unit and in the object they act on, so the budget value cannot be moved into the citation upper limit.

## How to verify the setup

1. Input source text one from the hypothetical sample together with the draft sentence. Compare the contract number and validity period in the draft sentence against the source wording. When the draft sentence contains a validity period not stated in the source, mark that part as awaiting verification.
2. Input source text two from the hypothetical sample together with the draft sentence. Compare "has passed compliance training" against the training record wording. When subject and status match, that part can be labelled with its source. When the draft sentence contains "long term promotion" and the material has no corresponding scope, that part remains unknown.
3. Input source text three from the hypothetical sample together with the account scheduling table. Compare the livestream date and session information. When the draft sentence refers to a time range outside the schedule, mark it as lacking source support.

The retrieval check observes the correspondence between the actually returned citation content and the source wording. Failure branches include returned content whose subject does not match the draft sentence, an empty citation array, and returned content that exceeds the material's valid range. Do not guarantee a first-hit result or full recall, and do not assert that an unrelated query must return empty. Knowledge bases with different vector models cannot be associated together; check identifiers first, exclude those that do not match, and record the observed result. An empty-result handoff can be checked on paper with an explicit input of an empty array against the downstream design, without claiming that a constructed rule-based query must return an empty array.
