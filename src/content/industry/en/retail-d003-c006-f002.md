# General export declarations: copy drafting with context limits

## What the documents look like

For copy drafting in General export declarations, this page examines FastGPT context limits. Shipment as separate parts and an assembly illustration describe different states. The examples are hypothetical.

## Constraints at the context limits step

A proposed export product packet says shipment uses separate-part packaging and the image is an assembly illustration. A service-scope remark does not list installation. A request to describe the unboxing experience needs actual shipment form, illustration identity and the service evidence gap together in input. An assembled picture cannot establish a complete machine on opening or an installation visit. The missing service entry identifies what this packet does not establish; it cannot determine that installation is excluded from every order. Copy needs to remain within the supplied material scope.

## Three common errors

One failure is a citation retaining the assembled illustration while trimming the separate-part condition, after which the draft says ready to use on opening. Another is installation service for an earlier product transferring into this draft. Inspect actual input shipment subjects, visual identity and historical product to distinguish form confusion from service inheritance. Reply length needs space for the shipment condition and unresolved scope; model context capability requires its own check. More output cannot supply installation arrangements, and complete source input must remain separate from evidence that a service was executed. A third error turns a later-obtained installation arrangement into completed installation. Check the state difference between an arrangement and an actual service record, including tense in the draft. A source defining service scope cannot establish that execution occurred.

## How to verify the setup

Acceptance should inspect shipment, illustration and service descriptions separately. Parts packaging stays attached to the current goods, and assembly remains illustrative. Compare the same unboxing request with empty history and earlier installation-service discussion to detect new complete-unit or home-service promises. If fixed output supports page editing, check shipment form, image note and unresolved service fields for completeness and parsing. Later installation material still needs order applicability checked. Its presence cannot by itself turn a service plan into a statement that installation has already been completed.
