# General import declarations: citation tracing for copy drafting

## What the documents look like

General trade import declaration work centres on five core documents: the import declaration form, the commercial invoice, the packing list, the bill of lading, and the contract. Supporting data arrives from the International Trade Single Window, customs tariff schedules, freight forwarder arrival notices, and foreign exchange payment slips. For product and marketing copy drafting, the fields that matter most are the transaction terms, freight and insurance amounts, country of origin, and specification descriptions recorded in those documents. Each sentence of promotional copy should be traceable to a corresponding document field.

The per-shipment update pattern has a direct consequence for citation tracing: the source version must be checked for each shipment. An invoice description from a previous shipment cannot be carried over to the current one without verification.

## Constraints at the citation tracing step

The knowledge base search node can associate one or more knowledge bases that share the same vector model. Its output is an array of citations, and the length may be zero. A zero-length array means the output path still runs; it does not mean the workflow has failed or terminated.

Retrieval returns candidate text only. It does not perform authorization checks or business verification. The citation limit is measured in tokens and controls how much content a single search may cite. The minimum relevance value is a 0-1 number that takes effect only in semantic search or when result reranking is used. Hybrid search merges multiple retrieval paths through RRF, which is a fusion process rather than a switch. Reranking requires a rerank model and must be enabled in the settings. Image retrieval requires image input and the corresponding model capability.

Knowledge bases built on different vector models cannot be associated together. The vector model identifier should be checked first, and any base that does not match should be excluded.

Retrieval output must be passed to the answering stage and compared against the source text item by item. For document timeliness, test the current version and the historical version separately.

## Configuration and implementation checks

The values below are hypothetical starting points for a paper exercise, not official defaults.

| Configuration item | Hypothetical starting point | Reason and comparison method |
| --- | --- | --- |
| Associated knowledge base | Single import declaration document base | Check the vector model identifier first; compare with other bases and exclude any that do not match |
| Search mode | Hybrid search | Declaration forms contain numbers and model codes; compare recall coverage against pure semantic search |
| Minimum relevance | 0.5 | Compare against 0.3 and 0.7; observe whether irrelevant fragments decrease while the target sentence is still recalled |
| Citation limit | 2000 tokens | Compare against 1000 and 4000; observe whether cited content covers the complete document fields |
| Question optimisation | Enabled | Compare against disabled; observe whether references are resolved in multi-turn follow-up questions |
| Result reranking | Enabled | Compare against disabled; observe whether ordering better matches the target sentence when candidates are numerous |

Hypothetical paper exercise sample. The source text reads: "The commercial invoice states transaction terms CIF, freight USD 1,200, insurance USD 300, country of origin Germany, specification model X-200." The draft sentence to be assessed reads: "This product is imported from Germany, model X-200." The input is the source text above together with the draft sentence. The comparison checks whether the country of origin and model in the draft sentence match the invoice fields for the same subject, the same period, and the same field. If they match and the invoice is the current version, the sentence is supported by the material. If the invoice does not state the country of origin, the sentence is recorded as unsupported.

## Three common errors

1. Treating retrieval output as an already-verified source. Retrieval returns candidate citations only. Until they are compared item by item against the source document, the copy sentence cannot be treated as established. Check: input the hypothetical source text above and the draft sentence, compare the country of origin and model fields, and observe whether a field-by-field match record appears.

2. Treating minimum relevance as an authorization or entity filter. This value filters low-relevance results only. It does not exclude unrelated businesses or unauthorized records. Check: input a query unrelated to import declaration, compare the returned citations against the query topic, and observe whether unrelated content may still be recalled.

3. Treating an empty citation array as a workflow error. The citation length may be zero. An empty array does not mean the process has stopped. Check: use a paper input of an empty array to verify the downstream handling design, and observe whether the downstream processes the empty-citation branch. Do not claim that a fictional rule search will necessarily return an empty array.

## How to verify the setup

1. Input the hypothetical source text "The commercial invoice states transaction terms CIF, freight USD 1,200, insurance USD 300, country of origin Germany, specification model X-200" together with the draft sentence "This product is imported from Germany, model X-200." Compare the country of origin and model in the draft sentence against the same invoice fields. If both match and the invoice is the current version, the sentence is supported. If the invoice does not state the country of origin, record the sentence as unsupported.

2. Input a query containing only the model code "X-200." Compare the recall results of hybrid search against pure semantic search. If hybrid search recalls a citation containing that code while pure semantic search does not, the full-text path is active. If neither recalls it, record the result as not retrieved and do not infer a failure cause.

3. Input an empty citation array to the downstream answering stage. Compare whether the downstream outputs through the empty-citation branch. If the downstream handles it and outputs a no-citation notice, the empty-result path runs through. If the downstream reports an error, record the observed behaviour without inventing an error code.

This page addresses one task only: citation tracing for product and marketing copy drafting in general trade import declaration. Whether a specific promotional sentence is supported by the materials cannot be converted into an enterprise identity certification tutorial.
