# Franchise store supervision: copy drafting with context limits

## What the documents look like

For copy drafting in Franchise store supervision, this page examines FastGPT context limits. Trace this store’s completed adjustment and pending review without borrowing regional completion. The examples are hypothetical.

## Constraints at the context limits step

A proposed franchise-store visit note says the end display’s position has been changed at this store, while its assortment awaits regional review. An earlier draft plans gradual adjustments across regional stores. This task concerns the named store’s record, so context must retain location, the completed positioning action and the pending review. Positioning completion is distinct from assortment acceptance, and the regional plan supplies no completion records for other stores. A photograph of an adjustment is not a review result.

## Configuration and implementation checks

## Three common errors

- If input loses this store’s limit and expands the action regionally, compare visit wording, submitted material and draft to locate the scope change.

- If a follow-up turns the historical regional plan into completion, compare history conditions with the current material fixed and inspect plan-versus-execution evidence.

- If positioning reaches input correctly but pending assortment is described as approved, inspect the condition and review source. Positioning completion does not replace assortment review.

## How to verify the setup

For acceptance, trace each statement to store identity, the positioning action and assortment review, while checking source versions. Once a regional review is available, add it separately and repeat the original question, inspecting actual use of that source. A later generation time does not establish refreshed content. Parse a structured summary before verifying its location and status fields; tidy fields establish no accepted correction. This example publishes no store update and performs no visit or procurement confirmation. Missing decisions still need corresponding records.
