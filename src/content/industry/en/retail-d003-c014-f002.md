# Convenience fresh-food orders: copy drafting with context limits

## What the documents look like

For copy drafting in Convenience fresh-food orders, this page examines FastGPT context limits. Separate the dates and supply states of this launch plan and historical availability copy. The examples are hypothetical.

## Constraints at the context limits step

A proposed fresh-food launch note plans pumpkin bread for tomorrow, with supply unconfirmed and a display image representing a trial sample. Tomorrow is relative to the plan’s source date; historical availability follows the period stated in that older material. Preserve the planned status, date and sample identity so old availability cannot overwrite this proposal. No formal ingredient statement, supply confirmation or test result is provided. Draft only from the supplied description rather than deriving composition or consumption effects from an image. Inspect actual image delivery separately; a text reference to a picture supplies no complete image content.

## Three common errors

- If a lost supply qualification becomes a promised arrival, compare the complete note, actual request and sentence to locate the omission.

- If a follow-up borrows historical availability, inspect the current plan date, the older source period and product referent. Retrieval date is not a supply date.

- If a trial-image description becomes specific ingredients, inspect actual ingredient material or image input. A product name and display note cannot supply composition.

## How to verify the setup

Trace the draft’s proposed date, trial-sample identity and unconfirmed supply to actual material. For structured output, validate parsing before checking support for supply status. Add a new supply notice and ingredient statement separately when obtained, repeating the original question without treating them as interchangeable. Record which source changes which sentence, beyond judging advertising fluency. Missing tests remain evidence gaps. This test confirms no sale decision, places no store order and publishes no food promotion.
