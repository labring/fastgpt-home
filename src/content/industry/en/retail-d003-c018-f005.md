# Regional dealer stock: multi-turn prompts for copy drafting

## What the documents look like

Stock replenishment in this category runs as a daily rolling order process, distinct from seasonal centralized ordering events. The working materials are replenishment applications, inventory turnover tables, outbound delivery notes, and payment collection plans, updated weekly or monthly. These four document types define the boundary of what a drafting task may cite. The drafting task converts quantities, statuses, and time ranges recorded in those materials into product and marketing copy for channel or terminal audiences. Any promotional conclusion the materials do not state stays marked as pending verification. Multi-turn dialogue allows materials to be submitted in batches and the reading confirmed round by round. The prompt constrains the model to draft only from submitted materials and to output a pending-verification marker when evidence is absent.

## Constraints at the multi-turn prompts step

In multi-turn dialogue, the scope of carried history directly affects whether a drafted sentence maps to the correct material. A new session carries no history. A continuing session retrieves the conversation from the database by chatId and uses the last entry of the messages array as the user question. The prompt must state the material scope, the drafting task, and how to handle missing evidence. Where question optimization is used for pronoun resolution, confirm whether continuous knowledge-base conversation is actually required; short questions do not automatically qualify. Model context length and reply cap determine whether a long material plus follow-up combination is truncated. Reply format is chosen according to downstream consumption; selecting json_schema requires filling in the corresponding format requirement and checking the returned structure.

Hypothetical paper exercise. The material text available for checking consists of three sentences. First, a dealer's March 2026 replenishment application states: "Product A requested quantity 200 units, application status pending review." Second, the same-period inventory turnover table states: "Product A ending inventory 40 units, turnover days 12." Third, the same-period payment collection plan states: "The dealer's March amount due is 500,000 yuan, collection status partially received." The draft sentence to be judged is: "Product A replenishment has been approved, inventory is sufficient, and terminal promotion can be supported immediately." The object of judgment is the replenishment application status field. The comparison values are "pending review" and "approved," which are mutually exclusive values of the same field, so the draft sentence contradicts the material. The inventory and collection portions do not state any promotion-support conclusion in the materials, so that part remains unsupported.

## Configuration and implementation checks

| Configuration or check item | Setting relevant to this page | Relation to the sample |
| --- | --- | --- |
| AI model | Select a model supporting the required context length and multimodal capability | The long material plus follow-up combination requires checking maximum context |
| Memory turns | Controls how many earlier chat turns are referenced | Determines whether prior turns are carried when materials are submitted across turns |
| Reply cap | Limits the length of a single answer | Prevents the draft sentence from being truncated early or becoming excessive |
| Temperature | Lower values produce more stable answers | Copy drafting needs stable restatement of material wording |
| Reply format | Plain text or json_schema | Choose json_schema and fill in the format requirement when downstream reads a fixed structure |
| Hide AI output | Generated content is not shown directly and can pass to later nodes | Internal results are rewritten into the final reply by the next node |

Hypothetical trial starting point: this sample sets temperature to a lower value because stable restatement of material wording is required, and the comparison object is output stability of the same prompt at a higher temperature. This value is only a starting point for this paper exercise and is not an official default. The numeric value of the reply cap is not given in the documents and remains unset.

## Three common errors

1. Writing "pending review" as "approved." The replenishment application status field values "pending review" and "approved" are mutually exclusive values of the same field, so rewriting directly contradicts the material. The check inputs the material text and the draft sentence, compares the status field value, and marks a contradiction when "approved" appears.
2. Treating inventory quantity and promotion support as the same thing. The material states only ending inventory of 40 units and turnover days of 12, and does not state that terminal promotion can be supported. The check compares whether the draft sentence contains a conclusion the material does not state, and marks it unsupported when such a conclusion appears.
3. Writing partially received collection as completed collection. The collection status field values "partially received" and "completed" are mutually exclusive values of the same field. The check compares that field and marks a contradiction when "completed" appears.

## How to verify the setup

1. Input the three material sentences above and the draft sentence, compare the replenishment application status field value, and confirm the output shows "pending review" differing from the draft sentence's "approved" with the system marking it as a contradiction.
2. Input the inventory turnover table text and the draft sentence, compare whether the draft sentence contains a promotion-support conclusion the material does not state, and confirm that conclusion appears and is marked unsupported.
3. Input the payment collection plan text and the draft sentence, compare the collection status field value, and confirm the output shows "partially received" differing from the draft sentence's "completed" with the system marking it as a contradiction. All three checks are paper expectations and have not been executed.
