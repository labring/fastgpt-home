# On-demand retail fulfillment: citation tracing for copy drafting

## What the documents look like

On-demand retail store fulfillment processes online orders by the minute, unlike periodic stocktaking. Records come from Douyin on-demand retail, Meituan or JD Daojia backends, store inventory, and rider tracking, with updates at minute-level and per order. This page addresses product and marketing copy drafting across instant orders, picking lists, out-of-stock reports, and delivery exception sheets, and asks whether a promotional sentence or a handover request can be supported by the materials available at that time. The update frequency itself does not change the tracing method, so synchronization mechanisms are not expanded here.

## Constraints at the citation tracing step

Knowledge base search can select one or more knowledge bases that share the same vector model; libraries using different vector models cannot be associated together, so identifiers must be checked first and non-matching libraries excluded. The search node outputs citations as an array, and the length may be zero; an empty array still passes through the output path. Hybrid retrieval merges multiple result paths through RRF, which is internal behavior of the retrieval chain and not an independent switch that can be turned on. Minimum relevance takes effect only under semantic retrieval or result reranking, and it is a filtering threshold that does not perform permission, entity, or business-ownership filtering. The citation limit is measured in tokens and does not use top k. Image retrieval requires image input and corresponding model capability, reranking requires a model and is enabled according to settings, and the optional paths listed in the flow diagram do not mean every request executes all of them.

Hypothetical drill sample: a picking list for a store at 11:20 on June 10, 2025 states "Product: a certain brand 500 ml purified water; Stock status: 3 units in store; Substitution rule: contact the customer to confirm when no same-specification substitute is available." An out-of-stock report at 11:22 the same day states "The product is sellable online, actually out of stock on the shelf, awaiting replenishment, no customer consent obtained for substitution." A draft sentence to be assessed is "This product is well stocked in store; order now for fast delivery." The assessment object is the same subject, same period, same field: the stock status on the list and the in-stock wording of the draft sentence point to the same product in the same time window, and their values differ in direction, constituting an inconsistency between the material and the draft sentence. The report's "no customer consent obtained for substitution" is a pending-verification state; it does not prove lack of operating authority, and it does not equal a completed substitution or refund.

## Three common errors

1. Treating minimum relevance as a permission or entity filter, assuming a higher value excludes unrelated stores or unauthorized records. Check method: input the sample list and report, compare returned entries before and after filtering, and observe whether what is filtered is low-relevance fragments or permission records.
2. Writing RRF as an independent switch that can be turned on, or treating thinking budget as the citation token limit. Check method: verify configuration item names against official field descriptions, and compare whether the filled field belongs to the retrieval fusion process or to thinking budget.
3. Reading the report's "awaiting replenishment, no customer consent obtained for substitution" as a completed substitution or obtained authorization. Check method: input the report text and the draft sentence, compare subject, period, and status fields, and observe whether mutually exclusive values exist in the same field.

## How to verify the setup

1. Input the hypothetical sample's list text and the draft sentence "This product is well stocked in store; order now for fast delivery," and compare the list's stock status field with the draft sentence's in-stock wording. If both point to the same product in the same period with values differing in direction, the draft sentence is judged unsupported and must be revised.
2. Input the out-of-stock report text and a handover request "Substitution confirmed with customer and delivery completed," and compare the report's status field with the facts stated in the request. If the report only states awaiting replenishment and no consent obtained, then the substitution and delivery completion stated in the request are both unsupported, and the evidence gap remains.
3. Use a paper input of an empty array to check the downstream handoff design, and observe whether the output path still passes through and whether the answering step receives empty citations. This check only verifies empty-citation handoff; it does not mean any retrieval rule necessarily returns an empty array, and it does not mean any business action has been executed.
