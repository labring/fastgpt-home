# Certificates of origin: copy drafting with context limits

## What the documents look like

For copy drafting in Certificates of origin, this page examines FastGPT context limits. Inspect product description, dispatch location and the missing origin statement without borrowing an older batch’s information. The examples are hypothetical.

## Constraints at the context limits step

A proposed product-origin introduction uses invoice wording for wooden components with an origin statement still to be supplied. A packing record gives only dispatch location, while historical copy concerns another batch’s source. Preserve component identity, the missing statement and location roles in the actual request before examining history. The invoice supports a product description without origin evidence; dispatch location does not supply manufacturing location. This ordinary-text test checks drafting support without providing origin rules, certificate outcomes or a real product-origin decision.

## Configuration and implementation checks

| Context check | Material in this test | Acceptance action |
| --- | --- | --- |
| Product subject | Wooden components | Add no absent finished-product properties. |
| Source gap | Origin statement is missing | Trace any definite origin claim. |
| Location role | Dispatch has its own meaning | Do not substitute manufacturing location. |
| Historical batch | An introduction for another batch | Inspect this batch’s referent. |
| Added material | Statement for the current components | Trace location and status after parsing. |

| `Reply length` | The reply limit differs from the context window. |

## Three common errors

- If the missing-statement condition disappears and the draft supplies a definite origin, compare invoice, actual input and the source sentence to locate the added claim.

- If an older batch’s source enters a follow-up about this batch, hold the current invoice constant across history conditions and inspect product, batch and cited version.

- If dispatch location becomes manufacturing location, trace field roles and originals. Joint occurrence in one passage does not make them interchangeable.

## How to verify the setup

Ask what the product is, whether origin material is provided and what the dispatch location supports, tracing sentences to actual received sources. When the current batch’s statement arrives, verify its component identity before retesting actual use; borrow no older batch’s statement. Inspect context capability and configuration, citation tokens and reply length separately. Longer output supplies no missing input. Parse a structured product card before verifying location and status fields. Drafting performs no certificate issuance, and absent source evidence remains identified.
