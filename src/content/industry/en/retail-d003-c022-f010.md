# Omnichannel stock transfers: citation tracing for copy drafting

## What the documents look like

Omnichannel stock transfers move goods between stores and warehouses. The work does not involve marketing outreach, so the document set centers on physical inventory movement rather than customer contact records. The main data sources are ERP inventory, store POS, e-commerce orders, and WMS. The documents handled day to day include transfer requests, inventory snapshots, store shortage lists, and transfer logistics notes.

For product and marketing copy drafting, any sentence that states an adjustable quantity, a store scope, or an arrival time needs to be traced back to these documents. Data updates occur daily and weekly. The citation tracing step uses that cadence to determine which point in time an inventory snapshot belongs to, and it prevents a snapshot from one moment being treated as a long-term state.

## Constraints at the citation tracing step

The knowledge base search node can select one or more knowledge bases that share the same vector model, for vector search. Its output is an array of citations whose length may be zero; even when no content is found, that output path still completes. The citation limit controls, in tokens, the maximum content cited per search. The minimum relevance value takes effect only under semantic search or result re-ranking, and it is a filter threshold rather than a final ordering rule. Hybrid search merges multiple result paths through RRF. Re-ranking requires a re-rank model and must be enabled through its setting. Image retrieval requires corresponding image input and model capability; the optional paths shown in the overall document flow diagram do not mean every path executes on every request. Retrieval does not constitute authorization, and a similarity score does not separate business entities or permission scopes.

Hypothetical drill sample: the source text reads, "Transfer request A-01 states: the requesting party is the East China store group, the transferring warehouse is the Suzhou warehouse, the receiving store is the Hangzhou Hubin store, the product is a certain down jacket, the requested quantity is 120 units, and the request date is 3 November 2025." "The inventory snapshot of the same day shows the adjustable stock of that product at the Suzhou warehouse is 90 units." "The store shortage list records that product as out of stock at that store." The draft sentence to be judged is, "The Suzhou warehouse can transfer 120 units of that down jacket to the Hangzhou Hubin store, expected to arrive this week." The quantity in this sentence exceeds the adjustable stock in the snapshot, and the arrival time has no corresponding field in the materials.

## Configuration and implementation checks

| Configuration or check item | Hypothetical starting point for this drill | Reason for the choice and comparison object |
| --- | --- | --- |
| Associated knowledge bases | Select the knowledge bases holding transfer requests and inventory snapshots | First check the vector model identifier of each base; only bases with the same model can be associated together |
| Search mode | Use semantic search together with full-text search | Compare against semantic search alone, and observe whether exact terms such as request numbers and store names are matched |
| Citation limit | Set a token amount covering one request and one snapshot for this hypothetical drill | Compare against a setting covering only the request, and observe whether the snapshot enters the citations |
| Minimum relevance | Set a medium value for this hypothetical drill | Compare against a lower value, and observe whether low-relevance fragments are carried into the drafting basis |
| Result re-ranking | Enable when a re-rank model is available | Compare against leaving it off, and observe citation order changes when candidates are numerous |
| Citation handoff | Pass the citation array to the answering step | Check the sentence-by-sentence correspondence between the answer and the cited source text |

## Three common errors

1. Treating the adjustable quantity in an inventory snapshot as a committable transfer quantity, ignoring the difference between the requested quantity and the snapshot quantity. For the check, input transfer request A-01 and the same-day snapshot, compare the requested quantity of 120 units against the snapshot adjustable stock of 90 units, and observe whether the draft sentence still states 120 units.
2. Adding an arrival time that the materials do not state into the draft sentence. For the check, input the two materials above, compare whether the draft sentence contains the field "expected to arrive this week," and observe whether any corresponding basis exists in the materials.
3. Treating a retrieval hit as authorization or completed approval. For the check, input transfer request A-01, compare whether it states approval or an authorization scope, and observe whether a pending-review status is written as an approved transfer.

## How to verify the setup

1. Input the source text of transfer request A-01 from the hypothetical sample together with the same-day inventory snapshot, compare the quantity in the draft sentence against the snapshot adjustable stock, and treat the sentence as passing source verification when the draft quantity does not exceed the snapshot adjustable stock and no unsupported arrival time appears.
2. Input a clearly paper-based empty citation array, check whether the downstream design continues to complete on an empty citation, and do not judge an empty result as a workflow error termination.
3. Input the record identifiers of the same down jacket in two knowledge bases with different vector models, check whether bases failing the common-association condition are excluded, and record the citation content actually observed without running a cross-model search to infer missed recall results.
