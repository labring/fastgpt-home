# Brand repair services: retrieval for copy drafting

## What the documents look like

Brand after-sales repair service work is organized around warranty responsibility and offline repair locations. The documents that matter for this page are warranty cards, repair work orders, inspection reports, and replacement approvals. These materials determine whether a product or marketing draft can carry wording such as "warranty," "replacement," or "free inspection." The after-sales system and store orders update per order and daily, so any retrieved content used for copy drafting has to belong to the same period as the current work order state.

The materials often disagree on state. An inspection report records a fault symptom. A replacement approval records an approval stage. A repair work order records handling progress. Copy drafting may cite only fields the material actually states. A warranty period, authorization scope, or effective condition that the material does not state stays unknown.

## Constraints at the retrieval step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Its cited-content output is an array whose length may be zero; when nothing is found, the output branch still runs. Search modes are semantic retrieval, full-text retrieval, and hybrid retrieval. Hybrid retrieval merges multiple result paths through RRF, then applies ReRank for a second ordering. The minimum relevance value is a filter threshold and takes effect only in semantic retrieval or when result reranking is used. The citation limit is measured in tokens.

Retrieval similarity does not carry permission or entity isolation duties. Whether recalled content may be used for a given draft still requires a manual check against the source material. Knowledge bases that use different vector models cannot be associated together; the model identifier should be checked first and non-matching bases excluded.

Hypothetical paper exercise sample: The source material reads "Work order A records a send-in date of March 2, the fault symptom is failure to power on, and the handling state is under inspection." "Warranty card B states a whole-machine warranty period of 12 months, counted from the purchase date." "Replacement approval C currently has the state pending review." The draft sentence to be judged is "This product carries a whole-machine warranty, and replacement can follow once inspection confirms the fault." The source material contains the subject, the object, the state, and the effective range, but it does not state replacement conditions or an approval outcome.

## Configuration and implementation checks

| Configuration item | Setting relevant to this page | How to check |
| --- | --- | --- |
| Associated knowledge bases | Select bases that contain warranty cards, repair work orders, inspection reports, and replacement approvals and that use the same vector model | Check the vector model identifier and exclude bases with a different model |
| Search mode | Compare semantic, full-text, and hybrid retrieval against test questions; do not assume one mode suits all material | Observe separately with identifier-type questions and natural-language questions |
| Citation limit | For this hypothetical trial, start at a token amount that covers the body of one work order plus one warranty card, because complete state fields must fit | Compare against a smaller value that covers only a single short sentence and observe content completeness |
| Minimum relevance | Label relevant and irrelevant samples first, then adjust the threshold | Compare recalled entries before and after filtering |
| Question optimization | Used for coreference resolution and question expansion | Compare the original question with the optimized question and check whether the subject was altered incorrectly |
| Cited-content output | Array format, length may be zero | Use a paper input of an empty array to check the downstream design |

## Three common errors

1. Treating a similarity score as a permission or entity filter. Input is a cross-store work order query; compare the recalled entries against the access scope and observe whether records outside the target scope appear. Similarity does not carry that duty.
2. Treating a pending replacement approval as a completed replacement. Input is approval state "pending review"; compare the draft sentence "replacement can follow" against the source and observe whether the source states replacement conditions and an approval outcome. What is not stated is not supported.
3. Associating knowledge bases that use different vector models. Input is two bases with different vector model identifiers; compare the identifiers and observe whether the non-matching base is excluded. Cross-model association cannot be performed, and its runtime result is not inferred.

## How to verify the setup

1. Input the hypothetical sample source material and the draft sentence "This product carries a whole-machine warranty, and replacement can follow once inspection confirms the fault." Compare the draft sentence against the fields of warranty card B and replacement approval C, and observe whether the warranty period and replacement conditions are stated in the source. If they are not stated, record the evidence gap.
2. Input a paper empty cited-content array. Compare the downstream copy step's design for handling an empty result and observe whether unsupported wording appears. The empty-result branch runs; do not claim that a fabricated-rule search necessarily returns empty.
3. Input an identifier-containing query and a natural-language query. Compare the recalled entries from semantic, full-text, and hybrid retrieval respectively, and observe whether the identifier-type question hits the corresponding work order field. Do not guarantee a first-position hit or full recall.
