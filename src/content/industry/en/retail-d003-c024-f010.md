# Brand concession operations: citation tracing for copy drafting

## What the documents look like

A brand concession inside a shopping mall accepts the mall's unified cashiering and commission settlement. Sales data first passes through the mall POS, then is reconciled against the brand ERP and the finance system. Monthly settlement differences affect activity resources and concession exit decisions. The daily documents include the joint-operation commission contract, mall activity letters, sales receipts, and monthly reconciliation statements. When product and marketing copy is drafted, a promotional sentence must be traceable to a specific clause, activity scope, or sales voucher in these materials. Material update frequency is daily and monthly; this page does not cover batch synchronization mechanisms.

## Constraints at the citation tracing step

The knowledge base search node can associate one or more knowledge bases that use the same vector model, and it outputs a citation content array whose length may be zero. An empty array does not mean the workflow has terminated with an error. Search results must be handed to the answering step, where the answer is checked line by line against the cited source text. The minimum relevance threshold takes effect only under semantic search or result reranking, and that threshold does not perform permission or entity isolation; retrieval itself does not constitute authorization. RRF is the fusion process for hybrid retrieval results, not a switch that can be turned on. Image retrieval requires image input and model capability, and reranking requires a model enabled according to settings. Optional paths shown in the document flow diagram do not mean every path executes on every request.

Hypothetical drill sample: a mall concession holds an activity letter whose source text reads, "The full-reduction activity covered by this letter applies only from March 1 to March 31, 2025, in the third-floor womenswear area, and does not apply to special-case goods." A joint-operation commission contract states, "Concession product advertising by Party B must be consistent with the seasonal materials approved by the brand owner." The draft sentence to be assessed is, "All goods at this concession participate in the March full reduction, and special-case goods also participate." The check compares whether the draft sentence's activity scope, time period, and product scope match the activity letter, and confirms whether brand-approved materials cover that wording.

## Three common errors

1. Treating the minimum relevance threshold as a permission filter. The input is a draft-sentence search; compare whether returned citations include materials from unauthorized concessions, and observe that unrelated content may still be recalled, so the source scope needs manual checking.
2. Writing RRF as a switch. The input is a hybrid retrieval configuration; compare whether an RRF enable item exists in the interface, and observe that the document describes it only as a fusion process with no independent switch.
3. Treating a pending activity letter as already effective. The input is an activity letter marked "pending brand approval"; compare whether the draft sentence cites its clauses, and observe that while approval is incomplete, the citation cannot serve as an effective basis.

## How to verify the setup

1. Input the hypothetical activity letter source text and the draft sentence; compare whether the draft sentence's time, area, and product scope match the source, and observe that the draft sentence says "all goods" and "special-case goods also participate" while the source limits the activity to the third-floor womenswear area and excludes special-case goods, which means the draft sentence is unsupported.
2. Input the hypothetical joint-operation commission contract source text and the draft sentence; compare whether the draft sentence is consistent with brand-approved materials, and observe that the contract only requires advertising to match approved materials without stating any approval result, so the item remains to be verified.
3. Input an empty citation array []; compare whether the downstream answering node still runs, and observe that the node output path does not terminate with an error, confirming the empty-result handoff design matches the documented behavior.
