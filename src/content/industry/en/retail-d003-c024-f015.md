# Brand concession operations: retrieval for copy drafting

## What the documents look like

A brand concession inside a shopping mall accepts the mall's unified cashiering and commission-based settlement. Its working documents are the joint-operation commission contract, mall activity letters, sales receipts, and monthly reconciliation statements. These sit alongside data from the mall POS, the brand ERP, mall membership campaigns, and the finance system. The brief records daily and monthly update frequencies. This page treats retrieval as reading whatever has actually been ingested, and does not infer any automatic synchronization from those frequencies.

For product and marketing copy drafting, the practical need is a citable basis inside these documents. An activity letter may state participation conditions. A commission contract may state which party bears a given cost. A monthly reconciliation statement may state a settled figure. The drafting task is to check a proposed sentence against such wording, not to generate claims the documents do not carry.

## Constraints at the retrieval step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. The smallest search unit is the library; a collection is only a classification layer and does not change search behavior. Semantic retrieval compares vector distance. Full-text retrieval relies on keyword hits. Hybrid retrieval combines both paths through RRF. Rerank performs a second ordering of candidate text. The minimum relevance value takes effect only under semantic retrieval or when result reranking is used. The citation cap is measured in tokens. Retrieval does not perform authorization and does not separate business entities.

A clearly labelled hypothetical drill sample follows. It is invented for this page and involves no real customer.

Source material, two sentences: "This concession participates in the mall spring membership campaign from 1 March 2024 to 31 March 2024. During the campaign, the membership discount is borne by the brand, and the mall deducts commission on actual sales."

Proposed draft sentence: "During the spring membership campaign, all discount costs for this concession are borne by the mall."

Comparing the two, the source names the brand as the party bearing the discount, and the proposed sentence names the mall. The subject differs on the same field, so the sentence is unsupported by the material. The campaign period matches in both, and the object is the same discount cost.

## Three common errors

1. Adopting the draft sentence "all discount costs are borne by the mall." The source material states the brand bears them, so the subject is reversed on the same field and the sentence is unsupported.

2. Treating minimum relevance as a permission or entity filter. It is a filtering threshold. It does not exclude unrelated businesses or unauthorized records, and retrieval by itself does not complete authorization.

3. Associating knowledge bases that use different vector models. The node requires the same vector model. When identifiers differ, exclude the library and record that fact, and do not run a cross-model comparison.

## How to verify the setup

1. Input the source material above and the proposed sentence, then compare the party bearing the discount. The material names the brand, the proposed sentence names the mall, and the result is judged unsupported.

2. Input a follow-up question that contains the campaign period, then compare the question before and after optimization. If subject and period match the original, the branch passes; if the subject is replaced, record that as a failed branch.

3. Input an activity letter that does not belong to this concession and observe whether it is cited. If it is cited, record the result and check the associated library scope. For the empty-result path, a paper input of [] can be used to check the downstream handling design, without asserting that retrieval must return an empty array.

For the empty-reference path, the documented behavior is that the reference output is an array whose length can be zero, so the output link still runs when nothing is found. The drill above checks the downstream design on paper and does not claim an observed run.

Question optimization adds a model call before retrieval. It is documented as improving multi-turn retrieval and as adding latency, and the decision to enable it can be based on actual results. Reranking produces a score between 0 and 1 and is documented as generally more precise than the vector score, which can be used for filtering. These are documented behaviors, not switches to be invented here.

Where the source material does not state a field, the value remains unknown. A pending review does not show that an operation permission is missing. Signing, reaching cooperation, and contract effectiveness are three separate facts. A quotation validity period does not state a supply period. Missing evidence stays missing, and no authorization or effectiveness clause is added to force a determinate answer.
