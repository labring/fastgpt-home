# Dealer ordering events: model connections for copy drafting

## What the documents look like

This page covers a brand dealer ordering event, the drafting of product and marketing copy, and the model connection and configuration step. The material set is the ordering handbook, the ordering contract, the sample list and the credit approval. These documents carry the product identity, policy wording and authorization scope that any drafted sentence may draw on, so the model connection step begins with reading them rather than with the model itself.

Two category facts shape this task. The ordering event serves offline dealer reservations and does not directly manage platform storefronts, so copy drafted here is judged against dealer-facing documents, not store listings. The data rhythm is seasonal and annual, so a drafted sentence refers to one event period and one set of terms. The drafting step therefore checks whether a proposed sentence stays inside the subject, object and validity range that the material states.

From V4.17.0, AI Proxy is a required dependency. Both the App and an Admin service that reuses App/Service configuration must set `AIPROXY_API_ENDPOINT` and a non-empty `AIPROXY_API_TOKEN`; missing either one causes startup validation to fail. Legacy OpenAI environment variables or a single-model custom request address cannot replace these two settings. The system needs at least one language model and one index model to work normally. A model ID is the value of the `model` field in the request body and is globally unique; a model name is for display and can be customized. A model channel is the protocol of a model provider, and one model can be configured across channels for load balancing.

## Constraints at the model connections step

Model connection does not itself authorize content. It supplies the capability to produce text, while the ordering handbook, contract, sample list and credit approval supply what the text may say. A drafted sentence about a product is supported only when the same subject, the same field and the same period appear in the material. A field the material does not state remains unsupported, even when it sounds plausible for a product of that kind.

Hypothetical paper exercise sample: a brand channel department prepares one product sentence for an ordering event. The material text supplied for checking is: "The sample list for this ordering event states Model A vacuum flask, capacity 500 ml, colors mist grey and navy, sample number SP-01." "The ordering handbook states that Model A vacuum flask has a minimum order quantity of 200 units this season, and the quotation validity period is 15 days from the day of the ordering event." The draft sentence to be judged is: "Model A vacuum flask offers 500 ml capacity in mist grey and navy, with a minimum order of 200 units this season." This sample is used for paper checking only and involves no real customer or real identifier.

The quotation validity period is not a supply period, and the minimum order quantity is not an authorization to order. The material states neither a supply commitment nor an approval outcome, so those remain gaps rather than conclusions.

## Three common errors

1. Entering `AIPROXY_API_ENDPOINT` as a full model request address with `/v1` appended. The document describes this variable as the AI Proxy service root address without `/v1`. Input: an address containing `/v1`. Comparison object: the documented example `http://aiproxy:3000`. Observable result: the startup validation or the call path does not match the documented form.

2. Using an application API key in place of `AIPROXY_API_TOKEN`. The document requires this token to be an administrator token, consistent with the server configuration and non-empty. Input: an application API key. Comparison object: the administrator token in the server configuration. Observable result: authentication does not pass.

3. Writing a promotional sentence that the material does not state. The sample material states capacity, colors, minimum order quantity and quotation validity period only. Input: a draft sentence going beyond the material. Comparison object: the sample list and ordering handbook text. Observable result: the sentence is recorded as unsupported.

## How to verify the setup

1. Input the material text and the draft sentence from the hypothetical sample, then compare whether capacity, colors and minimum order quantity share the same subject and the same field as the source. The source states 500 ml, mist grey and navy, and 200 units. When the draft sentence matches these, the condition is met. When the draft sentence contains a field the source does not state, record it as unsupported.

2. Input the hypothetical `AIPROXY_API_ENDPOINT` value and compare whether it is a service root address without `/v1`. When it matches the documented example, the condition is met. When it contains `/v1` or is a full request address, record a configuration error.

3. Input the hypothetical enabled states of the language model and the index model, then compare whether the system has at least one of each. When both are enabled, the condition is met. When either is missing, record that the documented usage precondition is not met. All of the above is paper checking; no deployment or test has been performed.
