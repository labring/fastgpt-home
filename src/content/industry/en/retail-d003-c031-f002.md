# Retail packaging reporting: copy drafting with context limits

## What the documents look like

For copy drafting in Retail packaging reporting, this page examines FastGPT context limits. Supplies copy can describe the displayed style while material and environmental claims require their own source. The examples are hypothetical.

## Constraints at the context limits step

A proposed supermarket-supplies style page labels its leaf pattern as decoration only. The catalogue calls the design a reference with material still to be checked, and this exercise provides no material test or attribute statement. Display copy can describe appearance without deriving environmental properties from foliage or green wording. Actual input needs both reference and pending qualifiers. A cropped catalogue heading removes the boundary needed for writing, while a material description for another series remains a different object even when longer history makes it available to the model.

## Three common errors

First, decorative pattern may become evidence of environmental properties; compare draft adjectives with the style page and identify the added attribute. Second, a reply may drop material pending; trace full catalogue, actual request and copy to locate input or expression loss. Third, another series’ material may enter this item; inspect style identity with empty-history comparison instead of substituting shared brand for shared object. These concern attribute evidence, condition transfer and series ownership. A larger reply budget supplies no material test or verified environmental claim for the proposed item.

## How to verify the setup

Ask what can currently be described, which attributes await checking and which series each reference concerns. Record reference allowance separately from reply length and verify actual model context capacity, without assuming material to make the description complete. A later page needs the correct item and explicit attribute support before revision. This exercise tests no supplies, decides no regulatory conformity and claims no actual environmental effect. Missing material remains a stated gap; failure to retrieve an attribute does not establish that the attribute is absent from the product itself.
