# Retail checkout and loyalty: copy drafting with context limits

## What the documents look like

For copy drafting in Retail checkout and loyalty, this page examines FastGPT context limits. Checkout promotional copy must distinguish layout vouchers and blank member cards from actual benefits. The examples are hypothetical.

## Constraints at the context limits step

A proposed checkout display includes a voucher marked layout only, not for redemption, and a blank member card. The campaign rule page has not been supplied. Counter copy can explain display purpose without inventing a usable offer or actual member details from the titles. A request containing only voucher and card names omits the restrictions, while a short reply might lose the illustration qualifier. Check the input objects before drafting what the current material can support, rather than treating a finished layout as evidence of a real promotional entitlement.

## Three common errors

First, layout artwork may become redeemable; compare original purpose and draft action while preserving the no-redemption meaning. Second, history may populate a blank card with an actual holder; inspect input origin and person ownership using generation without that history, inventing no personal details. Third, a missing rule page may lead to invented eligibility; inspect references for the exact clause source and leave rules unwritten when unsupported. These concern purpose, person and terms. More context cannot create the evidence required to announce a real promotion from these display-only objects.

## How to verify the setup

Ask what is displayed, whether the supplied artwork permits redemption and where rules originate, comparing request and output. Inspect reference, history and reply budgets separately from actual model context capacity. Later rules require campaign identity and version checking before revising the notice. This exercise issues no voucher, calls no membership system and processes no personal information or campaign activation. A completed layout does not establish that a real benefit is active. A rule page missing from the request also does not establish that the actual campaign has no rules elsewhere.
