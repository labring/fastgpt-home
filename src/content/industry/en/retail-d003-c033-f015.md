# Trade and FX administration: retrieval for copy drafting

## What the documents look like

Work in the foreign-exchange settlement and trade directory category centers on the authenticity of FX funds and the underlying trade background. Policy material from the State Administration of Foreign Exchange, bank online-banking records, enterprise finance ledgers, and customs export data form the main sources. The documents handled day to day are foreign-exchange receipt slips, trade contracts, invoices, and FX business registration materials. Updates arrive per transaction and monthly. Compared with letter-of-credit document examination, this category looks at funds and trade background rather than a full set of credit documents. That difference shapes retrieval: a receipt slip carries the receiving entity, amount, and date; a trade contract carries the signing parties and the subject matter; an invoice carries the goods description and amount. When drafting product and marketing copy, retrieval must pull the source passages that relate to a proposed sentence so a reviewer can check whether the promotional claim is supported by the materials.

## Constraints at the retrieval step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Bases built on different vector models cannot be associated together; check the model identifier and exclude any that do not match. Search modes are semantic retrieval, full-text retrieval, and hybrid retrieval. Hybrid retrieval merges multiple result paths through RRF, and Rerank performs a second ordering of candidate text. The citation limit is measured in tokens. The minimum relevance score takes effect only under semantic retrieval or when result reranking is used. Question optimization handles coreference resolution and question expansion. Image retrieval requires a corresponding image input and model capability, and reranking requires a rerank model enabled under the settings. Retrieval is a recall process; it does not perform permission or entity isolation.

Hypothetical exercise sample: the source material reads, "Party A, XX Import and Export Co., Ltd., and Party B, XX Trading Co., Ltd., signed a garment export contract in March 2025, contract number HX-2025-031, subject matter men's cotton shirts, quantity five thousand pieces. In April 2025 Party B received USD payment remitted by Party A through the bank; the bank receipt shows the payer as XX Import and Export Co., Ltd." The sentence to be assessed reads, "This product has obtained a long-term procurement commitment from XX Import and Export Co., Ltd." The procurement commitment mentioned in the draft sentence has no corresponding field in the source material, which records only the contract number, subject matter, quantity, and one receipt record.

## Configuration and implementation checks

| Configuration item | Setting for this page | How to check |
| --- | --- | --- |
| Associated knowledge bases | Select settlement and receipt material bases that use the same vector model | Compare vector model identifiers across bases and exclude any that differ |
| Search mode | Compare semantic, full-text, and hybrid retrieval on the test question | Observe the recalled content from each of the three paths for the same question |
| Citation limit | Set the hypothetical trial starting value at 2000 tokens, because the sample source is short and the contract and invoice fields need complete recall | Compare against 1000 tokens and 4000 tokens and observe whether recalled content stays complete |
| Minimum relevance score | Label relevant and irrelevant samples first, then adjust the threshold | Use the sample source as the relevant sample and observe how recall changes as the threshold moves |
| Question optimization | Compare the original question with the optimized question | Check whether the subject has been altered incorrectly |
| Result reranking | A rerank model is available and enabled under the settings | Observe the rerank score and the ordering of cited content |

## Three common errors

1. Treating "long-term procurement commitment" in the draft sentence as already recorded in the material. Input is the sample source and the draft sentence; compare whether a procurement commitment field appears in the source; the observed result is that the source contains only the contract number, subject matter, quantity, and one receipt record, and does not record a procurement commitment.
2. Equating the payer on the receipt slip with the contract's Party A. Input is the receipt payer and the contract Party A; compare whether the two names match; the observed result is that the receipt shows the payer as XX Import and Export Co., Ltd., which matches the contract Party A name, but the receipt does not record the contract number for that payment, so the correspondence between this receipt and HX-2025-031 cannot be confirmed.
3. Treating retrieved citation results as an authorization basis. Input is the cited content returned by retrieval; compare whether the cited content contains an authorization or approval field; the observed result is that the cited content contains only contract and receipt facts and records no authorization or approval information.

## How to verify the setup

1. Input the sample source and the draft sentence "This product has obtained a long-term procurement commitment from XX Import and Export Co., Ltd."; compare whether "procurement commitment" in the draft sentence has a corresponding field in the source; the observed result is that the source does not record that field, so the sentence is judged unsupported. If the source later records a procurement commitment clause, re-check.
2. Input the sample source and the receipt information; compare the receipt payer name with the contract Party A name; the observed result is that the two names match, but the receipt does not record the contract number, so the correspondence between this receipt and the contract remains to be verified. If the receipt later records contract number HX-2025-031, further checking becomes possible.
3. Input an empty citation array and the downstream design; compare whether the downstream can continue when the citation length is 0; the observed result is that the output path runs through and produces no cited content. If the downstream design depends on cited content, record that gap.
