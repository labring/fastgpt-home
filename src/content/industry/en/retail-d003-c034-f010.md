# Export tax rebate filings: citation tracing for copy drafting

## What the documents look like

Export tax rebate filing happens after goods leave the country, and the work is matching tax vouchers to that export. The main data sources are the electronic tax bureau, the export rebate filing system, customs electronic messages and the accounting ledger. The everyday documents are the export tax exemption and rebate filing form, the export customs declaration, purchase invoices and foreign exchange receipt vouchers. The update rhythm is monthly or per batch.

Copy drafting for goods and marketing sits upstream of that matching work. When a draft sentence names a product, a quantity, a batch or a voucher status, the sentence needs to be traceable back to the wording of a specific source document. Without that traceability, later filing and discrepancy handling lose their evidence base.

## Constraints at the citation tracing step

The knowledge base search node can associate one or more knowledge bases that use the same vector model, and it returns cited content as an array. That array length can be zero, which means the output path still runs even when nothing is retrieved. The citation cap controls how many tokens of content a single search may cite. The minimum relevance value takes effect only in semantic retrieval or when result reranking is used, and it is a filtering threshold, not a permission or entity isolation control. Hybrid retrieval merges multiple retrieval paths through RRF. Reranking requires a rerank model and must be enabled in the settings. Image retrieval requires corresponding image input and model capability.

These conditions mean a retrieval hit does not equal a business-reviewed source, and it does not equal authorization to use a drafted sentence.

Hypothetical drill sample: a foreign trade enterprise finance staff member drafts a product description for one export batch. The materials at hand are an export customs declaration (declaration date March 2025, product name "stainless steel insulated cup", quantity 2,000 units, domestic consignor Company A) and a purchase invoice (invoice date February 2025, product name "stainless steel insulated cup", quantity 2,000 units, seller Company B). The draft sentence to be judged is: "This batch of stainless steel insulated cups totals 2,000 units, and the corresponding purchase invoice has been obtained." The comparison covers two fields, product name and quantity. The authorization boundary is limited to the filing materials for this export batch and does not extend to other batches or other goods.

## Configuration and implementation checks

| Configuration item | Hypothetical starting point for this drill | Reason for the choice and comparison method |
| --- | --- | --- |
| Associated knowledge bases | Select only rebate material bases already confirmed to use the same vector model | Check the vector model identifier first, exclude those that differ, and do not run cross-model retrieval |
| Citation cap | Set a starting value measured in tokens | Compare against the total length of cited content returned, and observe whether truncation occurs |
| Minimum relevance | Set a starting value between 0 and 1 | Compare the number of citations before and after filtering, only under semantic retrieval or result reranking |
| Search mode | Start with hybrid retrieval | Compare cited content against semantic retrieval alone, and observe differences in hits on identifier-type fields |
| Result reranking | Enable per settings when a rerank model is available | Compare scores and citation order before and after reranking, and confirm the filtering basis |
| Cited content output | Accept the array output and allow a length of zero | Use a paper input of an empty array to check whether the downstream answering step still runs |

These values are hypothetical starting points for this drill, used for comparison against actual retrieval returns. They do not represent official defaults or fixed limits.

## Three common errors

1. Treating a retrieval hit as a reviewed material. The cited content array only shows that the search path returned content. Business review and authorization to use it require separate confirmation. Check method: input the declaration and invoice text above, compare the product name and quantity in the draft sentence against the same fields in both materials, and observe whether any statement lacks support.
2. Treating minimum relevance as a permission filter. That value filters low-relevance results only under semantic retrieval or result reranking. It does not exclude unrelated businesses or unauthorized records. Check method: input a retrieval question for the same batch, compare the number of returned citations before and after filtering, and observe whether filtered items were removed only for low scores.
3. Associating knowledge bases that use different vector models. The documentation states that only knowledge bases with the same vector model can be selected. Check method: verify the vector model identifier of each candidate knowledge base, exclude those that do not match, and record the actually observed associable scope.

## How to verify the setup

1. Use the hypothetical sample to check the draft sentence. Input the declaration and invoice text, compare the product name "stainless steel insulated cup" and the quantity "2,000 units" across both materials. When the same field matches in both materials, the sentence is supported. If only one material states the quantity, the quantity portion remains unsupported and the evidence gap must be recorded.
2. Use a paper input of an empty array to check downstream handling. Input an empty cited-content array, compare whether the answering step still executes and returns a notice, and observe whether the path runs through. Do not claim that a fictional rule retrieval necessarily returns an empty array.
3. Use dated materials to check source timeliness. Input the March 2025 declaration and the February 2025 invoice, compare whether the draft sentence notes the batch and date range, and observe whether the citation can be traced to a specific material version. Whether the citation is adopted still depends on review of the valid version, and a pending review does not indicate a lack of operating permission.
