# Fresh-food concession counters: copy drafting with multi-turn prompts

## What the documents look like

For copy drafting in Fresh-food concession counters, this page examines FastGPT multi-turn prompts. Add loss and receiving evidence across turns without treating earlier copy as batch proof. The examples are hypothetical.

## Constraints at the multi-turn prompts step

Suppose a concession agreement leaves losses for discussion, a sales note is compiled, and receiving registration lacks evidence for the current batch. An initial counter introduction followed by a sourcing question should inspect the history, inspection text and instructions actually carried into the request. Earlier generated wording that sourcing is traceable proves no current-batch inspection. Compiled sales establish no agreed loss allocation. These invented passages assess no actual food-safety result, sales volume or contract validity.

## Three common errors

- If a follow-up omits the inspection gap and repeats earlier complete-sourcing wording, inspect actual history and receipt of the current registration before supplying it again.

- If a question about loss responsibility turns separate discussion into accepted counter liability, inspect the original clause and any mutual supplementary confirmation.

- If earlier-batch inspection wording replaces missing current evidence, compare batch identity and receiving records. Conversational continuity supplies no missing document.

## How to verify the setup

Keep a draft fixed while adding current inspection evidence and loss positions across turns. Ask which sentences can remain and which need evidence. Compare new and history-bearing conversations, retaining actual requests and checking history selection against the deployment and model without invented limits. Instructions should attribute sources and retain missing evidence explicitly. A request for persuasive wording is insufficient. Responsible staff must check sourcing and contractual confirmations before publication.
