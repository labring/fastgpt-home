# Customer-service knowledge: workflow routing for copy drafting

## What the documents look like

Customer-service knowledge base maintenance is preparatory question-and-answer material work. It does not approve refunds. The material set for this category comes from the customer-service system, product detail pages, after-sales issue statistics, and quality-inspection spot checks. The day-to-day documents are FAQ entries, script templates, product parameter tables, and escalation tickets. Copy drafting for products and marketing produces candidate reply sentences. These candidates are checked by knowledge base operations staff and customer-service supervisors before they enter the knowledge base.

The output of this task is a candidate sentence, not a published answer. The workflow routing step decides what happens to that candidate: which information is collected, which branch is taken, and what is passed to later retrieval or judgment nodes.

## Constraints at the workflow routing step

The form input node is a user-interaction node. When it is triggered, the conversation enters an interaction state, and the workflow state is recorded. After the user fills in the required information and submits, the node collects the form information and passes it to later nodes. The user-selection node is also a user-interaction node. When it is triggered, the conversation enters an interaction state and the workflow state is recorded. When the user makes a choice, the node evaluates that choice and executes the corresponding branch. Both nodes can be added repeatedly and trigger execution.

A hypothetical paper exercise sample is given here for checking purposes only. The source material reads: "This insulated cup has a capacity of 500 milliliters, the material is 304 stainless steel, and the applicable temperature range is minus 20 degrees Celsius to 100 degrees Celsius." The candidate sentence reads: "This insulated cup has a capacity of 500 milliliters, the material is 304 stainless steel, and the heat-retention duration can reach 24 hours." The source material does not state a heat-retention duration. That field in the candidate sentence is unsupported and pending verification. It is not a contradiction, because the source does not give a mutually exclusive value for the same field.

Workflow routing must pass the collected copy request to retrieval or judgment nodes, and compare output against input item by item. The same-vector-model requirement for retrieval libraries is limited to within a retrieval library. It does not extend to business-registration websites or other external systems. RRF is a hybrid-result fusion process and is not written as a switch. Thinking budget is a thinking budget and is unrelated to the citation token limit. Order writes, document backfill, and external status synchronization require a separate business interface or a later process. This page does not assume scheduled triggers or hidden controls.

## Three common errors

1. Treating a promotional statement in the candidate sentence as supported by the material. The source material states only capacity, material, and applicable temperature range. The candidate sentence contains "heat-retention duration can reach 24 hours." That field is not stated in the source. It should be recorded as unsupported and pending verification, not written as a negation or a conflict.

2. Treating retrieval relevance as a permission or entity filter. A relevance score does not perform the function of excluding unauthorized records. Retrieval is not authorization. Access scope must be checked separately.

3. Extending the interaction node's state-recording behavior into a global state-recording switch, or writing the "yes" branch of the user-selection node as automatic approval. After branch execution, manual verification is still required. A pending review does not demonstrate a lack of operating permission.

## How to verify the setup

1. Input the source material and candidate sentence given above. Compare each field of the candidate sentence against the corresponding field in the source: capacity and material match; heat-retention duration is not stated in the source. The expected observation is that this field is marked unsupported and pending verification, and is not judged as a contradiction.

2. Input a paper empty result [] and check whether downstream nodes handle it through the empty-result branch. The expected observation is that the downstream design accommodates an empty result. Do not claim that a fictional rule retrieval necessarily returns [].

3. Input the vector model identifiers of two libraries within the same retrieval library and compare whether the identifiers are consistent. The expected observation is that consistent identifiers allow joint association, and inconsistent identifiers exclude the non-conforming library and record the actual observation. Do not run a cross-model retrieval comparison of missed recalls.
