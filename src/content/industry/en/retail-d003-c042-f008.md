# Product listing reviews: workflow routing for copy drafting

## What the documents look like

Platform product title and detail compliance handles advertising truthfulness and qualification display. It does not handle parcel delivery, which is the key difference from platform shipping operations. The main data sources are the platform rules center, advertising law compliance checklists, the brand asset library, and inspection agency reports. Everyday documents include the product title table, detail page assets, the prohibited advertising terms list, and quality inspection reports. Typical roles are e-commerce product operations, legal compliance, and artwork review. Errors can lead to product delisting, complaints, and administrative penalty risk. The most time-consuming steps are checking absolute terms, comparing physical parameters, and replacing non-compliant assets. Update frequency is weekly and at each new listing; this page does not derive batch synchronization or real-time triggers from that frequency.

For copy drafting, the workflow needs interactive nodes to collect materials and pass them to later nodes. A form input node enters the interaction state when triggered, collects required information, and passes the submitted information to subsequent nodes after submission. A user selection node executes the corresponding "yes" branch after the user makes a choice, and branch connections need to be verified one by one. Interaction state recording is behavior of the interactive nodes; no separate global state-recording switch is set here. Collected information must be explicitly passed to later retrieval, judgment, or interface nodes, and outputs are compared item by item with inputs. Order writing, document backfill, and external status synchronization require separate business interfaces or downstream flows; this page does not construct such functions. The same-vector-model requirement for retrieval libraries does not extend to business registration sites or other external systems also needing the same model. Semantic recall and relevance scores do not handle permission or entity isolation, and retrieval does not constitute authorization.

## Constraints at the workflow routing step

Hypothetical drill sample: the source material text reads, "This product was inspected by a certain quality inspection agency according to standard GB/T 0000-0000, report number HYP-2026-001, inspection date March 10, 2026, and the inspection conclusion is that the tested items meet the standard requirements; the report is valid only for the submitted sample." The draft sentence reads, "This product has been inspected by a national authoritative agency, all indicators fully meet the standard, and it is suitable for all populations." The judgment targets are whether the three expressions "national authoritative agency," "all indicators fully meet the standard," and "suitable for all populations" in the draft sentence are supported by the material above. The material only states a certain quality inspection agency, that the tested items meet the standard, and that the report is valid for the submitted sample. It does not state that the agency is a national authoritative agency, does not cover all indicators, and does not address applicable populations. The material identity is an inspection report excerpt; the object is the draft sentence and the source material text; the stage is copy drafting review; the date and quantity scope is the single report dated March 10, 2026, covering only the submitted sample; the authorization boundary is that this page only compares draft wording against the supplied material text and does not perform certification, approval, publication, or external synchronization.

## Configuration and implementation checks

| Configuration item | Setting or check on this page | Relation to the sample |
| --- | --- | --- |
| Form input node | Set required fields to collect the draft sentence and source material text | Collects the sample draft sentence and source material text |
| User selection node | Set the "yes" branch for material support and another branch for unsupported | Selects item by item for the three expressions in the sample |
| Output handoff | Pass collected information to a later judgment node and compare item by item | Compares the draft sentence with the source material text |
| Interaction state check | Verify that triggering enters the interaction state and records state | Confirms the sample continues after submission |
| External action separation | Order writing, document backfill, and external synchronization connect to separate business interfaces | This page performs none of these actions |

## Three common errors

1. Treating "national authoritative agency" in the draft sentence as already stated in the material. The source material only says "a certain quality inspection agency" and does not state a national authoritative agency. The check input is the draft sentence and the source material text; compare the agency name field; when the material does not state it, record the expression as unsupported.
2. Treating "all indicators fully meet the standard" as already covered by the material. The source material only says "the tested items meet the standard requirements" and does not cover all indicators. Compare the indicator scope field; when the material does not state all indicators, record the expression as unsupported.
3. Treating "suitable for all populations" as already addressed by the material. The source material does not address applicable populations. Compare the applicable population field; when the material does not state it, record the expression as unsupported.

## How to verify the setup

1. Input the hypothetical drill sample's draft sentence and source material text, and compare "national authoritative agency" with the agency name in the material. When the material does not state a national authoritative agency, the user selection node should enter the unsupported branch and record that expression as unsupported. The expectation is unsupported; this is not claimed to have been tested.
2. Input the same draft sentence and source material text, and compare "all indicators fully meet the standard" with the inspection scope in the material. When the material only states that the tested items meet the standard requirements, the node should enter the unsupported branch. The expectation is unsupported; this is not claimed to have been tested.
3. Input the same draft sentence and source material text, and compare "suitable for all populations" with the applicable population field in the material. When the material does not state an applicable population, the node should enter the unsupported branch. The expectation is unsupported; this is not claimed to have been tested. For empty-result handoff, a clearly labelled paper input of [] can be used to check the downstream design; it cannot be claimed that a fictional rule retrieval will necessarily return [].
