# Product listing reviews: model connections for copy drafting

## What the documents look like

Title and detail compliance work handles advertising truthfulness and qualification display. It does not handle parcel delivery. The working documents are the product title table, detail page assets, the advertising prohibited-word list, and quality inspection reports. Sources include the platform rules center, advertising law compliance lists, the brand asset library, and inspection agency reports. These materials change weekly and at each new listing, and they determine which statements a draft can draw support from.

Two features of this material shape the drafting task. First, every proposed sentence needs a traceable counterpart in a supplied document, because a reviewer compares the draft against the source line by line. Second, the material carries a subject, an object, and a validity scope that must survive into the draft. A quality report names a sample, a tested item, and a conclusion. A brand asset page names an applicable skin-type range. A draft that widens either one loses the support the material provides.

## Constraints at the model connections step

AI Proxy is a required dependency. Both the App service and an Admin service that reuses App/Service configuration must set `AIPROXY_API_ENDPOINT` and a non-empty `AIPROXY_API_TOKEN`. Missing either one causes startup validation to fail. `AIPROXY_API_ENDPOINT` holds the AI Proxy service root address and does not carry `/v1`. Model capability is checked against the inputs the application actually needs, with multimodal input and tool calling verified separately. Application parameters are set in the application or node configuration; a same-named field on a compatible chat interface is not assumed to override orchestration. Retrieval returns candidate content and does not perform permission or entity isolation.

Hypothetical paper exercise sample. On 12 October 2026 a product operator submits a draft sentence: "This product is certified by a national authority and suits all skin types." The two source passages supplied for comparison are: quality inspection report number A-2026-1012, which states "Sample name: moisturizing cream; tested item: microbiological indicators; conclusion: meets GB 7916"; and the brand asset library entry for this product, which states "Applicable skin types: dry, neutral." The phrase "certified by a national authority" has no corresponding subject in either passage. The phrase "suits all skin types" does not match the applicable skin-type range in the asset library. This sample illustrates how a draft sentence is compared against source material during copy drafting.

## Three common errors

1. Entering a full model request address in `AIPROXY_API_ENDPOINT`. The input is an address carrying `/v1` or `/chat/completions`; the comparison object is the documented root-address form; the observable result is a startup validation failure or a call error.
2. Treating "certified by a national authority" in the draft sentence as already supported by the material. The input is that draft sentence together with the inspection report text; the comparison object is the tested item and conclusion recorded in the report; the observable result is that no certifying subject appears in the material, so the statement remains unsupported.
3. Treating a retrieval relevance score as a permission filter. The input is one query; the comparison object is whether returned items belong to a document the requester may access; the observable result is that relevance does not exclude unrelated business records, so identifiers must be checked manually.

## How to verify the setup

1. Input the hypothetical draft sentence "This product is certified by a national authority and suits all skin types" together with the inspection report text "tested item: microbiological indicators; conclusion: meets GB 7916." Compare whether a certifying subject named in the draft appears in the material. The observable result is that the material records no national-authority certification, so that statement remains unverified.
2. Input the same draft sentence together with the brand asset library text "applicable skin types: dry, neutral." Compare "suits all skin types" against the applicable skin-type range in the asset library. The observable result is that the two ranges do not match, so the draft sentence needs revision or additional material.
3. Input one query against the product title table. Compare whether returned items belong to that product's document. The observable result is that returned content may include other product records, so items must be excluded by document identifier and the actual observation recorded. An empty result can be carried into a downstream design check using the explicit paper input `[]`; no claim is made that a fictional rules query returns `[]`.
