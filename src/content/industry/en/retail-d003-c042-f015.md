# Product listing reviews: retrieval for copy drafting

## What the documents look like

Platform product title and detail compliance concerns the truthfulness of promotional wording and the display of qualification material. It does not cover parcel delivery. The working materials are platform rule-center entries, advertising prohibited-term lists, brand asset libraries, third-party inspection reports, product title tables, and detail-page assets. These materials update weekly and at each new product launch, so a single drafting request may draw on statements of different origin and different scope of validity.

Material form drives retrieval difficulty. Prohibited-term lists are mostly short entries, so exact keyword matching works well. Inspection reports carry report numbers, model designations, test items, and validity dates, so number and model queries depend on keyword hits. Detail-page assets and title tables are natural-language sentences, so semantic retrieval more readily recalls similar phrasing. When these materials sit in one library, a single search needs to cover both exact terms and semantically similar content.

## Constraints at the retrieval step

The knowledge base search node can associate one or more libraries that use the same vector model. Libraries with different vector models cannot be associated together. Check the vector model identifier first, exclude those that do not match, and record the actual observation. Do not run a cross-model search to compare missed recalls.

Search mode follows the test question. Semantic retrieval depends on vector distance, full-text retrieval depends on keyword hits, and hybrid retrieval uses both paths and merges them through RRF. RRF is the fusion process for hybrid results, not a switch that can be turned on. Minimum relevance is a filter threshold that takes effect only under semantic retrieval or when result reranking is used. It carries no permission or entity-isolation function, and retrieval itself does not constitute authorization.

Cited content is output as an array whose length can be 0; when nothing is found, that output path still completes. The citation limit is measured in tokens and does not use top k. Question optimization adds one model call before retrieval for coreference resolution and question expansion, which increases overall latency.

Optional paths in the materials do not mean every request executes all of them. Image retrieval requires the corresponding image input and model capability, and reranking requires an available model enabled per settings.

### Hypothetical paper exercise sample

The following is a paper sample for illustrating a checking method. It points to no real entity.

Material text one (entry from an advertising prohibited-term list): This list applies to all product title and detail-page text on the platform; the entry "ultimate" is listed as a prohibited absolute expression.

Material text two (excerpt from an inspection report): The tested object is a batch of stainless steel vacuum flasks; the test item is heat-retention performance; the report number and test date appear on the report's first page; the report is valid until the date stated there.

Draft sentence: This product uses ultimate craftsmanship, and its heat-retention performance is confirmed as qualified by an inspection report.

Handover request: Please search this batch of materials and confirm whether the draft sentence can be used directly.

Determination points: Material text one covers title and detail text and lists "ultimate" as a prohibited expression; the draft sentence contains that word, so this is an explicit mutually exclusive value in the same field. Material text two states only the tested object, the test item, and the validity period; it states no "ultimate craftsmanship" or similar process wording, so that part of the draft sentence is unsupported. Whether the inspection report supports a "qualified" conclusion depends on whether the report text states a conclusion field; the sample does not provide that field, so it remains to be verified.

## Three common errors

1. Treating minimum relevance as a permission or entity filter. Minimum relevance is a filter threshold and does not exclude unrelated businesses or unauthorized records. Retrieval does not constitute authorization, and business verification and writes require downstream implementation. Check action: read the description of this value and confirm that it takes effect only under semantic retrieval or result reranking.

2. Describing RRF as a switch that can be turned on. RRF is the fusion process for hybrid retrieval results. Check action: inspect the configuration items for a switch named RRF; if none exists, record it as a fusion process.

3. Associating libraries with different vector models and then inferring missed recalls or redundancy. The documents state only that libraries with the same vector model can be associated. Check action: read each library's vector model identifier, exclude non-matching ones, record the actual observation, and draw no inference about runtime results.

## How to verify the setup

1. Input material text one above and the draft sentence, and compare whether the draft sentence contains a prohibited expression listed in the list. When the list entry appears in the retrieval citation and the draft sentence contains that word, the expected prohibited-term hit is satisfied. If it does not appear, record it as not hit and draw no inference about the cause.

2. Input material text two above and the draft sentence, and compare whether the report excerpt states process wording and a conclusion field. When the cited content contains only the tested object, test item, and validity period, the expectation that the process wording is unsupported and the conclusion field remains to be verified is satisfied.

3. Input the paper empty result [] and check how the downstream design handles a citation length of 0. When the output path still completes and the downstream treats it as an empty citation, the expectation is satisfied. Do not claim that a fictional rule search necessarily returns [].
