# Marketplace advertising: retrieval for copy drafting

## What the documents look like

Paid placement in this category adjusts bids against live traffic and conversion signals, so whether a draft claim is actually supported by the underlying material affects how budgets and bids get judged. The working documents are placement plans, keyword reports, audience package descriptions and conversion attribution tables. Their field structure and wording boundaries define what a copy draft may cite.

Two facts shape this page. First, the material set is operational rather than promotional: a placement plan states a period, a region and a budget line; a keyword report states a term and a metric; an audience package description states a definition and its conditions. Second, the update rhythm runs daily or hourly. Retrieval itself does not depend on that rhythm, so update frequency is not treated here as a retrieval condition.

The search node can associate one or more knowledge bases that use the same vector model. Bases built on different vector models cannot be associated together. This is a check on the vector model identifier, not a statement about what a cross-model search would return.

## Constraints at the retrieval step

Search mode is compared per test question across semantic retrieval, full-text retrieval and hybrid retrieval. No single mode is assumed to suit every document. Hybrid retrieval combines vector and full-text results through RRF, which is a fusion step in the pipeline, not a switch with its own field.

The minimum relevance value is a 0-1 threshold that applies only under semantic retrieval or when result re-ranking is used. It filters low-relevance results. It does not act as a permission filter, an entity filter or a business-record separator, and raising it does not change which bases are reachable. The citation limit is measured in tokens, not in a count of items; it is tested against material of differing length to see whether content stays complete. Question optimization performs coreference resolution and question expansion before retrieval. Its effect is checked by comparing the original question with the optimized question and confirming the subject was not altered. Re-ranking requires a re-rank model and must be enabled according to its settings. Image retrieval requires actual image input and matching model capability. The optional paths drawn in the overall retrieval diagram are not all executed on every request.

Hypothetical paper exercise. Source material reads: "The A-series laundry detergent launched by this brand in East China in the third quarter of 2024 has a pack size of 2 kilograms and an execution standard of Q/XX 001-2024." The draft sentence under review reads: "The A-series laundry detergent has an execution standard of Q/XX 001-2024 and applies to all regions nationwide." The object of comparison is the execution standard field together with the applicable-region field. The period is the third quarter of 2024, the region is East China. The draft extends the applicable scope to the whole country. The material does not state nationwide applicability, so that extension is unsupported. The execution standard value itself matches; the region does not.

## Configuration and implementation checks

| Configuration item | Hypothetical starting point for this exercise | Comparison method and basis |
| --- | --- | --- |
| Associated knowledge bases | Associate only the single base holding the A-series detergent material | Verify the vector model identifier; exclude bases on a different model |
| Search mode | Run semantic retrieval and full-text retrieval once each | Compare hit content against the test question |
| Citation limit | Set to a token amount that fully covers the source material | Compare completeness against material of differing length |
| Minimum relevance | Label relevant and irrelevant samples first, then choose a value | Applies only under semantic retrieval or re-ranking |
| Question optimization | Enabled for follow-up questions, disabled for complete questions | Compare original and optimized question subjects |
| Result re-ranking | Enabled when candidates are numerous | Requires a re-rank model and must be enabled by setting |

These are starting points for a paper exercise, chosen so the comparison has a defined reference. They are not documented defaults and no value here is presented as official.

## Three common errors

1. Rewriting "East China" in the material as "all regions nationwide." Input: the source material text. Comparison: the applicable-region field. Observable result: the draft sentence's region scope exceeds the scope stated in the material.
2. Treating minimum relevance as a permission filter, on the assumption that raising it excludes unrelated business records. Input: the relevance value. Comparison: the reachable retrieval scope. Observable result: the relevance setting does not change which bases can be accessed.
3. Writing RRF into configuration as a switch that can be turned on. Input: the hybrid retrieval setting. Comparison: the documented fusion step. Observable result: RRF is a result-merging stage and has no separate switch field.

## How to verify the setup

1. Input the source material text and the draft sentence. Compare the execution standard field and the applicable-region field. The condition is met when the draft's region does not exceed the region stated in the material. In this exercise the draft fails that condition on region.
2. Input the identifiers of two bases built on different vector models. Compare the vector model field. When the identifiers differ, exclude the association and record the actual observation. Do not run a cross-model retrieval to compare missed recalls.
3. Input an explicit paper-level empty result, written as []. Compare the downstream node's handling design. The condition is met when the downstream path completes on an empty citation chain. Do not claim that a rule-based retrieval necessarily returns [].

Across all three checks, the retrieval step returns candidate content; it does not grant access, approve anything or write to any downstream system. Where a field is not present in the material, the status remains unknown rather than negative.
