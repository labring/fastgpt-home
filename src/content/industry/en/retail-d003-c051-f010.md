# Douyin storefront operations: citation tracing for copy drafting

## What the documents look like

Shelf operations copy for a Douyin storefront draws on four recurring document types: product qualification pages, experience score details, shipping violation appeals, and store announcements. These materials update daily and per order, so any statement about shipping time or compensation conditions in draft copy must match the current version of the source material. A qualification page records the subject, the object, and the valid scope. Experience score details record status per order. Appeal materials record a processing stage.

The practical consequence for copy drafting is that a promotional sentence is only traceable when it can be matched back to specific wording in a specific current document. Because versions move with daily and per-order updates, the comparison is made against the version in hand at drafting time. A sentence that reads plausibly can still fail the comparison when the source states a different value for the same field.

## Constraints at the citation tracing step

Retrieval begins by confirming which knowledge bases are selected and which material versions they hold. Only knowledge bases that share the same vector model can be associated together. The search node outputs a citation array, and that array may have a length of zero. An empty array means the output path still completes; it does not mean the workflow terminated with an error.

The citation ceiling is controlled in tokens, not by a top-k item count. The minimum relevance value takes effect only under semantic retrieval or when result reordering is used. Neither setting performs permission filtering or entity isolation, and a relevance score is not a category or authorization filter. Whether a retrieved result is actually adopted into copy still depends on a valid-version review. Retrieval by itself is not authorization.

Hypothetical paper exercise sample. The source material reads: "This store's shipping time is within 48 hours after payment; during major promotions the announcement governs." The experience score details show the order status as shipped. The shipping violation appeal is currently at the pending-review stage. The draft sentence to be assessed is: "This store promises all orders ship within 24 hours." Comparing the draft sentence against the source material, the shipping-time field shares the same subject and object but carries a different value, so the draft sentence is not supported by the material. The draft sentence also says "all orders," a scope the source material does not state, so that portion is likewise unsupported. The appeal material showing pending review does not indicate a lack of operating permission, and it does not indicate the appeal has passed.

## Three common errors

1. Treating the draft sentence "This store promises all orders ship within 24 hours" as supported. The source material states 48 hours and defers to the announcement during major promotions. The field is the same but the value differs, so the sentence is unsupported. The check takes the draft sentence and the source material as input, compares the shipping-time field, and records that differing values mean the sentence is not supported.

2. Writing the appeal material's "pending review" as "appeal rejected" or "lacks operating permission." Pending review states only a processing stage. The check takes the appeal source text and the draft sentence as input, compares the status field, and records that a conclusion absent from the material means the sentence is not supported.

3. Forcing knowledge bases with different vector models into a shared association. The check takes each base's model identifier as input, compares whether the identifiers match, and excludes any base whose identifier differs while recording the actual observation. It does not run a cross-model retrieval to compare missed recalls.

## How to verify the setup

1. Take the source material "This store's shipping time is within 48 hours after payment; during major promotions the announcement governs" and the draft sentence "This store promises all orders ship within 24 hours." Compare the shipping-time field. The condition is met when the values differ, at which point the draft sentence is judged unsupported and the evidence gap is retained.

2. Take the paper citation array []. Compare it against the downstream answering step's design. The condition is met when the downstream step continues through the empty array without an error, which confirms the empty-result handoff has been checked.

3. Take each knowledge base's model identifier. Compare whether the identifiers match. The condition is met when mismatched bases are excluded and the actual observation is recorded, which satisfies the precondition for shared association.

Across all three checks, the comparison must hold the same subject, the same period, and the same field. Only clearly mutually exclusive values in the same field count as a contradiction. Wording that is absent, or that shows only a related stage, is unsupported or awaiting verification rather than negated or conflicting. Pending review does not demonstrate a lack of operating permission. The optional paths in the overall retrieval flow are not all executed on every request: image retrieval requires a corresponding image input and model capability, and reordering requires an available model enabled by configuration.
