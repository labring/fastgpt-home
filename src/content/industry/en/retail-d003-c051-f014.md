# Douyin storefront operations: model connections for copy drafting

## What the documents look like

Douyin storefront operations revolve around product cards and the store experience score. The working documents are product qualification pages, experience score breakdowns, shipping violation appeals and store announcements. These materials come from the Douyin store workbench, the Douyin e-commerce learning center, Selected Alliance data and logistics interfaces, and they update daily and per order. Copy drafting for products and marketing relies mainly on two of these document types: the product qualification page and the store announcement. The model connection and configuration step exists to attach model capability to the sentence-by-sentence checking of draft copy against those source materials, so that each proposed sentence can be compared with the original wording and judged as supported or unsupported.

## Constraints at the model connections step

According to the FastGPT v4.17.2 documents, AI Proxy has been a required dependency since V4.17.0. Both the App and any Admin service that reuses App/Service configuration must set `AIPROXY_API_ENDPOINT` and a non-empty `AIPROXY_API_TOKEN`; a missing value in either causes startup validation to fail. Legacy OpenAI environment variables and a single-model custom request address cannot replace these two settings. `AIPROXY_API_ENDPOINT` takes the AI Proxy service root address and must not have `/v1` appended. The system needs at least one language model and one indexing model to work normally. Model capability is checked against the input the application requires, with multimodal input and tool calling verified separately, and application parameters are set in the application or node configuration.

Hypothetical paper exercise sample: two source sentences, taken from a fictional product qualification page and store announcement. "The store sells the item 'Four Seasons Cotton-Linen Scarf'; the material is stated as cotton-linen blend, the execution standard is FZ/T 73001, and the qualification page is valid until 31 December 2026." "Store announcement: this store ships within 48 hours after payment." One draft sentence to be judged: "The store's scarf is pure cotton and ships the same day." The comparison scope is limited to these two materials. In the draft sentence, "pure cotton" and the qualification page's "cotton-linen blend" are different values in the same material field, which forms a contradiction; "ships the same day" and the announcement's "within 48 hours after payment" likewise form a contradiction. Both are judged unsupported.

## Configuration and implementation checks

The table below lists only officially documented settings or implementation checks relevant to this page's primary task. Values marked "assumed starting point" are comparison starting points chosen for this paper exercise, not official default values.

| Configuration item | Assumed starting point | Check method and reason |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | `http://aiproxy:3000` | Enter the root address without `/v1`; compare with the documented example form and confirm no extra path |
| `AIPROXY_API_TOKEN` | Non-empty string | Must match the server configuration and must not be empty; compare against an empty value, where empty fails startup validation |
| Language model | At least one enabled | Compare against the requirement that the system needs at least one language model; if none is enabled, the system is unusable |
| Indexing model | At least one enabled | Compare against the requirement that the system needs at least one indexing model; if none is enabled, the system is unusable |
| Model mapping | `gpt-4o-test` mapped to `gpt-4o` | Follow the documented mapping example and check the requested model name against the upstream model name |
| Channel priority | Assumed starting point 50 | Range 1 to 100; a larger value is more easily selected first; compare with neighbouring channel values to order them |

## Three common errors

1. Filling `AIPROXY_API_ENDPOINT` with a complete request address that includes `/v1` or `/chat/completions`. The documents state this variable is the service root address and must not have `/v1` appended. Check the actual string entered for this variable, compare it with the root-address form, and treat any occurrence of `/v1` as non-conforming.
2. Using an application API key as `AIPROXY_API_TOKEN`. The documents require this token to be the AI Proxy administrator token, matching the server configuration and not empty. Check the entered value against the server configuration value; a mismatch or an empty value is non-conforming.
3. Treating a configured language model as sufficient for drafting copy. The documents state the system needs at least one language model and one indexing model. Check the enabled model list for the presence of both types; a missing type is non-conforming.

## How to verify the setup

1. Input the hypothetical sample's qualification page wording "the material is stated as cotton-linen blend" together with the draft sentence "the store's scarf is pure cotton." Compare the values in the same material field; mutually exclusive values mean the draft sentence is judged unsupported. If the draft sentence is rewritten to match the original wording, the condition is met.
2. Input the hypothetical sample's announcement wording "ships within 48 hours after payment" together with the draft sentence "ships the same day." Compare the values in the same shipping-time field; mutually exclusive values mean the draft sentence is judged unsupported. If the draft sentence is rewritten as "ships within 48 hours after payment," the condition is met.
3. Input the actual configured value of `AIPROXY_API_ENDPOINT`. Compare it with the requirement of a root address without `/v1`; an occurrence of `/v1` does not meet the condition, and the absence of an appended path meets it. All three items are completed as paper checks, not executed in a real system, and results depend on actual observation.
