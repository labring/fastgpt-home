# Channel diversion reviews: model connections for copy drafting

## What the documents look like

Channel diversion review concerns regional and price order. It handles the direction of goods flow and abnormal selling prices. It does not handle rebate amount accounting. The main materials come from anti-counterfeit code systems, e-commerce platform prices, distributor shipment records and market inspections. Everyday documents include diversion complaint forms, anti-counterfeit code records, penalty notices and investigation photographs. The update rhythm is weekly and irregular.

Copy drafting works on the complaint description, the batch and region information in anti-counterfeit code records, the handling position stated in penalty notices, and the on-site state shown in investigation photographs. These materials determine whether a drafted sentence can be supported. An anti-counterfeit code record typically contains a code segment, query time and query location. A complaint form contains the complained party, the region involved and the complaint reason. A penalty notice contains the established facts and the handling conclusion. Drafting compares each item against these materials. Parts the materials do not state remain pending verification.

## Constraints at the model connections step

Model connection requires the AI Proxy dependency to be deployed first. App and Admin both must set `AIPROXY_API_ENDPOINT` and a non-empty `AIPROXY_API_TOKEN`. Missing either item causes startup validation to fail. Legacy OpenAI environment variables or a single-model custom request address cannot replace these two. The system needs at least one language model and one index model to work normally. Only one speech recognition model takes effect, so configuring one is sufficient.

Model capability is checked item by item against the input the application needs. Multimodal support, tool calling and thinking configuration are verified separately. Application parameters are set in the application or node configuration. It cannot be assumed that same-named fields of a compatible chat interface will override the orchestration.

The following is a hypothetical exercise sample, used only to explain the comparison method. It points to no real subject.

Hypothetical source text (complaint form extract, identifiers and subject fictitious): Complaint form CX-2026-0417 states that the complained party is a distributor in the East China region, the code segment range involved is A0001 to A0500, and the complaint reason is that goods in the above code segment were sold in an e-commerce shop in the South China region below the suggested retail price. Two shop page screenshots are attached, with a screenshot time of 15 April 2026. This complaint form does not state the complained party's authorized sales region scope, and no penalty decision is attached.

Drafted sentence to be judged: "Upon investigation, this distributor sold outside its authorized region, disrupted the price system, and has been penalized under company rules."

Comparison conclusion: The complaint form states the code segment and the low-price selling reason. It does not state the authorized region scope, and it does not state that a penalty has been made. The two statements "sold outside its authorized region" and "has been penalized" are not supported by the material and should remain pending verification.

## Configuration and implementation checks

| Configuration item | Hypothetical trial starting point for this page | Reason for the choice and comparison method |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | Enter the AI Proxy service root address | The official text requires the root address without `/v1`; compare character by character against the actual deployment address |
| AIPROXY_API_TOKEN | Enter a non-empty token consistent with the server side | The official text requires it to be non-empty; compare against the AI Proxy administrator token |
| Language model | Enable one language model that has passed channel testing | The official text requires at least one; use the channel test result as the basis |
| Index model | Enable one index model besides the language model that has passed channel testing | The official text requires at least one; use the channel test result as the basis |
| Model capability check | Tick each item against the input copy drafting needs | Verify multimodal support and tool calling separately; do not merge the judgement |
| Application parameters | Set in the application or node configuration | Do not assume same-named fields of a chat interface override the orchestration |

## Three common errors

1. Writing `AIPROXY_API_ENDPOINT` as a full request address that contains `/v1`. The official text requires the service root address without `/v1`. Check method: read the variable value, compare it against the actual deployment root address; the presence of a `/v1` or `/chat/completions` suffix means the configuration is wrong.
2. Using an application API key as `AIPROXY_API_TOKEN`. The official text requires an administrator token consistent with the server side. Check method: read the variable value, compare it against the administrator token configured on the AI Proxy server side; a mismatch or an empty value does not satisfy the requirement.
3. Writing "the code segment was sold at a low price in South China" directly as "sold outside its authorized region". The material does not state the authorized region scope, so this judgement lacks a basis. Check method: look for an authorized region field in the complaint form; when it is not found, keep the wording pending verification and do not write it into the drafted sentence.

## How to verify the setup

1. Input the hypothetical source text and the drafted sentence, and compare whether "sold outside its authorized region" in the drafted sentence has a corresponding supporting field in the complaint form. The complaint form states the code segment and the low-price selling reason, and does not state the authorized region scope. This statement is not supported and should remain pending verification.
2. Input "has been penalized under company rules" from the same drafted sentence, and compare whether the complaint form has a penalty decision attached. The material has no penalty decision attached, so this statement is not supported. A penalty notice is a separate document; a complaint form cannot replace it.
3. Input "code segment range A0001 to A0500" from the source text and the quotation in the drafted sentence, and compare whether the code segment range is consistent. If the drafted sentence writes the code segment as another range, the quotation is inaccurate and must be corrected against the source text.

These checks all address the copy drafting task. They do not involve enterprise identity certification or report analysis. Model probing and channel testing belong to a separate check at the connection configuration step and are carried out separately from the copy judgement.
