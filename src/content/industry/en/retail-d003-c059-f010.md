# Store cold-chain receiving: citation tracing for copy drafting

## What the documents look like

Cold-chain receiving at a store is organized around the arriving batch and its temperature history. The temperature record from the refrigerated vehicle, the WMS, the store receiving system and quality-inspection photographs together form the material that can be checked against a batch. Each arrival produces a cold-chain temperature record, an arrival acceptance form, a rejection form and a supplier delivery note. These four document types are the main basis for citation when product and marketing copy is drafted.

The acceptance step concerns transport temperature and the arriving batch. Origin price inquiry is outside this step. Records update per batch, and some records update daily, so material belonging to different batches from the same supplier has to be checked separately. When copy cites this material, the temperature record corresponds to transport condition, the acceptance form corresponds to the arrival result, the rejection form corresponds to the handling of non-conforming goods, and the delivery note corresponds to the supplying entity and quantity. The subject, object, state and valid scope of the four document types must agree before any single promotional sentence can be supported.

A second characteristic matters for citation tracing. The knowledge-base search node can associate one or more knowledge bases that use the same vector model, and it outputs cited content as an array whose length may be zero. When the cited content is empty, the output path still runs; an empty array does not mean the workflow has errored and stopped. The retrieval output has to be passed to the answering step, where the answer is checked line by line against the cited original text.

The following is a hypothetical paper exercise, used only for checking on this page, and does not refer to any real entity.

Material text one: "On 12 March 2025, refrigerated vehicle paper-plate 0001 arrived at the store. The transport temperature record shows 2 to 6 degrees Celsius throughout. The store receiving system registered batch L20250312-01."

Material text two: "The arrival acceptance form for the same batch states: leafy vegetables passed sampling inspection, 120 boxes received into storage; of these, 30 boxes were registered as rejected because the leaves were wilted, rejection form number R20250312-01."

Material text three: "The supplier delivery note states the supplier is the paper-plate fresh delivery unit, delivery date 12 March 2025, corresponding to purchase order PO-20250310-07."

Draft sentence to be assessed: "This batch of leafy vegetables arrived under cold chain at 2 to 6 degrees Celsius throughout, and all 120 boxes passed inspection and entered storage."

The draft sentence differs from the material at field level. The material states 120 boxes entered storage and 30 boxes were rejected; the draft sentence says all 120 boxes passed and entered storage. For the same batch and the same field, the passed quantity and the rejected quantity are mutually exclusive values, and the draft sentence is not supported by the material. The material does not state whether this batch obtained a regulatory release or a supplier compensation conclusion, so any such wording remains to be verified.

## Constraints at the citation tracing step

The knowledge-base search node associates knowledge bases that share the same vector model for vector search. Knowledge bases built on different vector models cannot be associated together; the identifier is checked first and non-matching bases are excluded. Retrieval is not authorization, and a relevance score is not a category, entity or permission filter. A similarity setting does not exclude unrelated businesses or unauthorized records.

Search mode matters for this task. Batch numbers and rejection form numbers are precise fields, so full-text search or hybrid search is appropriate. Hybrid search combines vector recall and full-text recall through RRF, and RRF is a fusion process, not a switch. The citation limit controls the maximum tokens of content cited per search; the unit is tokens, not an estimated number of items. The minimum relevance value is a filter threshold that applies only in semantic search or when result re-ranking is used; it is not a final ordering rule. Result re-ranking requires a re-rank model and must be enabled by configuration; an optional path shown in a document flow diagram does not mean every request executes it.

The citation output is an array and its length may be zero. A paper input of [] can be used to check how the downstream design handles an empty array. This does not imply that a fabricated rule will necessarily return an empty array.

| Configuration or check item | Use on this page | Basis and boundary |

| Associated knowledge bases | Hold the knowledge bases containing cold-chain temperature records, acceptance forms, rejection forms and delivery notes | Must share the same vector model to be associated; check the identifier and exclude non-matching bases first |
| Search mode | Use full-text or hybrid search for precise fields such as batch number and rejection form number | Hybrid search fuses multiple recall paths through RRF; RRF is a fusion process, not a switch |

## Three common errors

1. Mixing the quantity in the draft sentence with the material fields. The input is material text two above and the draft sentence to be assessed. Compare the received-into-storage quantity field and the rejected quantity field. If the draft sentence says all boxes passed and entered storage while the material registers a partial rejection, the sentence is not supported. The error is that "all" covers a rejection fact that has already been registered.
2. Using retrieval similarity in place of source checking. The input is a citation array returned by one semantic search. Compare the subject, batch and date in the cited original text against the draft sentence. If the cited content does not match the batch number in the draft sentence, it cannot serve as the source for that sentence. The error is treating a relevance score as proof of source validity.
3. Writing a pending state as a completed conclusion. The input is the regulatory release or compensation field not yet stated in the material. Compare what the material actually records against the wording of the draft sentence. If the material holds only an arrival acceptance record and no release conclusion, the wording remains to be verified. The error is treating stage evidence as a final fact.

## How to verify the setup

1. Input material texts one, two and three together with the draft sentence to be assessed. Compare the batch number, temperature range, received-into-storage quantity and rejected quantity fields in the draft sentence against the material records. When all four fields agree, the sentence is supported by the material. If any field disagrees or the material does not state it, record the sentence as unsupported or to be verified, and keep the evidence gap open.
2. Input a citation array returned by one search. Compare the original text of each citation against the fields the draft sentence relies on. When the cited original text contains the subject, object, state or valid scope the draft sentence needs, it can serve as a source candidate. When the citation array is empty, use the paper input [] to check how the downstream design handles it, and do not infer that a fabricated rule will necessarily return an empty array.
3. Input the validity-period or authorization wording in the draft sentence. Compare whether the material states the corresponding period and authorization boundary. When the material states a quotation validity period, that period does not indicate a supply term. When the material does not state signing, effective-date or authorization clauses, the related conclusion remains to be verified, and no clause is invented to obtain a definite answer.
