# Fresh-food weighing and sorting: context limits for copy drafting

## What the documents look like

Fresh-food weighing and sorting sits in the warehouse fulfillment stage, where the central facts are weight and specification rather than order aggregation. The documents involved are the sorting task sheet, the weighing label, the short-weight compensation form, and the quality inspection record. The sorting task sheet states the order and the required specification for each item. The electronic scale produces actual weighed values. The weighing label carries specification and weight information. The short-weight compensation form records how a weight difference was handled. The quality inspection record preserves the inspection conclusion.

These materials are generated per order and summarized by day. Copy drafting for products and marketing needs to cite specific values and states from these materials, such as the specification range of a batch, the weighing results, and the inspection conclusion. Whether a promotional sentence can stand depends on whether the corresponding material states the subject, object, state, and valid scope that support that sentence. A sentence that goes beyond what the material records is not supported, even when it sounds plausible.

## Constraints at the context limits step

When drafting copy, the length of content the model can reference is bounded by the model's maximum context. The reply length is controlled separately by the reply limit, and the two must not be conflated. The knowledge base reference limit is measured in tokens; a long single passage may be truncated, so the reference content needs to be checked against a specific question sample for completeness. The memory round count determines how many earlier conversation rounds the model can reference. The same question produces different model input under empty history and under history with prior rounds, and the results may differ.

If a fixed reply format is used, the fields need to be verified as complete and parseable, not merely checked for text length. Semantic retrieval and the minimum relevance score affect only the similarity ranking and filtering of recalled content; they do not perform permission isolation or business entity filtering. The association between a knowledge base and a vector model is limited to the same model identifier and cannot be shared across different vector models. RRF is the fusion process for mixed retrieval results, not an independent switch that can be turned on. The thinking budget is a token budget for the model's reasoning stage and is a different configuration item from the knowledge base reference token limit.

## Configuration and implementation checks

The following items address the copy drafting task on this page, illustrated with a hypothetical exercise sample.

| Configuration item | Hypothetical starting point for this exercise | Reason and comparison method |
| --- | --- | --- |
| Maximum context | Check against the selected model's actual capability | Estimate the combined length of source material and draft sentence, compare with the context value shown for the model, and confirm no truncation |
| Reply limit | Enable and set to a length that accommodates basis and handling action | Compare the total length of the draft sentence, material citation, and handling note, and confirm the reply is not cut short |
| Knowledge base reference limit | Set in tokens to cover the length of a single passage | Check against the token volume of the sample material, and confirm the reference content is not trimmed |
| Memory rounds | Start with a small number of rounds | Compare the same question under empty history and under history, and exclude irrelevant content carried in by history |
| Minimum relevance | Keep default or adjust against the sample | Takes effect only under semantic retrieval or result reranking; observe whether recalled content includes the sample material |
| Reply format | Plain text, or json_schema when required | If downstream reads fixed fields, select json_schema and verify fields are complete and parse successfully |

## Three common errors

1. Treating the reply limit as the model's full context window. The reply limit controls only the length of a single answer, while the total content the model can reference is determined by the maximum context. The check compares the combined length of source material and draft sentence against the context value shown for the model. If the combined length exceeds it, the input is truncated and the material must be reduced or the model changed.

2. Treating the minimum relevance score as a permission or entity filter. The minimum relevance score is a similarity threshold that takes effect only under semantic retrieval or result reranking, and it does not exclude unrelated businesses or unauthorized records. The check observes whether recalled results include content outside the sample material. If they do, the setting has not performed business filtering, and permission control needs to be designed separately.

3. Treating RRF as an independent switch that can be turned on. RRF is the fusion process for multiple result paths in mixed retrieval, not a configuration item. The check confirms whether the search mode is mixed retrieval and observes whether multiple recall paths are merged. If only a single retrieval path is used, no RRF fusion occurs.

## How to verify the setup

Hypothetical exercise sample: the source material consists of three sentences. "The sorting task sheet for this batch of spinach states a specification of 200 grams to 250 grams, and the actual weighing records are 218 grams, 230 grams, and 245 grams. The quality inspection record states that this batch of leafy greens has no yellow leaves and no rotten roots, and is judged qualified. The short-weight compensation form states that order A generated a compensation record because the actual weight fell below the lower specification limit." The draft sentence to be assessed is: "Each portion of this batch of spinach is a full 200 grams or more, fresh quality with no yellow leaves."

1. Input the source material and the draft sentence, and compare "each portion is a full 200 grams or more" in the draft against the actual values in the weighing records. The weighing records contain 218 grams, 230 grams, and 245 grams, all above 200 grams, but the material does not state that every portion reaches that lower limit; it states only three weighing values. If the draft sentence claims all portions are full weight, it exceeds the scope supported by the material. If the material supports only partial weighing values, the draft sentence should be revised to match the records.

2. Input the source material and the draft sentence, and compare "fresh quality with no yellow leaves" against the quality inspection record. The inspection record states no yellow leaves, no rotten roots, and a qualified judgment, so that part of the wording matches the material. If the draft sentence adds "fresh," a state not recorded in the material, that content is unsupported and must be removed or the corresponding inspection field supplied.

3. Input the same question under empty history and under history, and compare the model input content. If the input under history contains irrelevant content from earlier conversation rounds, adjust the memory rounds or question optimization settings, and confirm whether the input difference affects the accuracy with which the draft sentence cites the source material.

For a paper check of empty output handling, a clearly labelled hypothetical input of an empty reference list can be used to examine the downstream design, without asserting that any retrieval rule returns an empty list. Cross-model association is not permitted; verify model identifiers first and exclude those that do not match, rather than running a cross-model retrieval to compare missed recalls. Optional paths in the overall retrieval flow are not executed on every request: image retrieval requires a corresponding image input and model capability, and reranking requires a model and must be enabled according to settings.
