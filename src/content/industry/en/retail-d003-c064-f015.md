# Livestream sample inspections: retrieval for copy drafting

## What the documents look like

Livestream product selection and sample quality inspection happen before a broadcast begins. The work answers two questions: whether a product can be sold, and whether it suits live demonstration. This page addresses one task inside that stage, drafting product and marketing copy, where retrieval and recall exist to show whether a proposed sentence can be supported by the underlying materials.

The everyday documents are sample evaluation forms, quality inspection reports, supplier qualifications, and prohibited or restricted lists. Sources include supplier materials, testing body reports, platform negative catalogs, and historical return rates. These materials determine what copy may state and what it may not. An inspection report supplies test items and conclusions. A supplier qualification supplies the entity and its validity period. A prohibited list supplies the platform's restriction scope. A sample evaluation form supplies trial observations. When copy is drafted, retrieval must return these fields by entity, object, status, and validity scope so each sentence can be checked one by one.

Two industry facts shape this task. First, the stage is pre-broadcast, so a drafted claim that outruns its supporting material carries consequences at the point of sale. Second, the material set is heterogeneous: a test conclusion, a business license, and a platform restriction list each answer a different kind of question, and a single sentence can touch all three.

## Constraints at the retrieval step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Knowledge bases built on different vector models cannot be associated together. Check the model identifier first and exclude those that do not match. Do not run cross-model retrieval in order to compare missed recalls.

Search modes are semantic retrieval, full-text retrieval, and hybrid retrieval. Hybrid retrieval merges multiple result paths through RRF. RRF is a fusion process, and it is not written as an on/off switch. The minimum relevance value takes effect only under semantic retrieval or when result reranking is used. It is a filtering threshold, not a final ordering rule. The citation limit is measured in tokens. Question optimization performs reference resolution and question expansion, and it adds one model call before formal retrieval. The output citation content is returned as an array and its length may be zero, meaning the output path still runs even when nothing is found. Image retrieval requires corresponding image input and model capability. Reranking requires a model and must be enabled according to settings. The optional paths shown in the overall flow diagram do not mean every request executes all of them. Retrieval and recall do not perform permission or entity isolation.

Hypothetical drill sample. The material text reads: "The quality inspection report submitted by Supplier A in March 2025 shows that sample batch A-031 received a passing conclusion on the rubbing color fastness item, report number QC-2025-0317, valid until March 2026." "The business license submitted by Supplier A states a business scope of daily goods sales, valid until December 2027." "The April 2025 version of the platform prohibited list places disposable medical masks in a restricted category, requiring medical device business filing." The sentence to be judged: "This mask has passed quality inspection, the color fastness is qualified, and it can be purchased with confidence." This sentence involves entity, object, and status, and each must be compared item by item.

## Configuration and implementation checks

The table below lists only settings or implementation check items relevant to this page's primary task. Values are starting points for this hypothetical trial and must be compared against another set of values before being fixed.

| Associated knowledge bases | Select the bases containing inspection reports, qualifications, and the prohibited list | Check each base's vector model identifier first and exclude those with a different model |

## Three common errors

1. Treating minimum relevance as a permission or entity filter. Input: the draft sentence "This mask has passed quality inspection," with only minimum relevance configured. Compare: whether that threshold takes effect under semantic retrieval or reranking, and whether it excludes unrelated entities. Observable result: if raising the threshold still returns inspection conclusions from other suppliers, the setting does not carry entity isolation.
2. Associating knowledge bases built on different vector models. Input: selecting two bases whose vector model identifiers differ. Compare: whether the vector model identifiers of the bases match. Observable result: when identifiers do not match, joint retrieval should not be executed; record the actual observation and do not infer missed recall or redundancy.
3. Treating an unstated status as a denial. Input: the draft sentence claiming "can be purchased with confidence," while the material states only color fastness qualification. Compare: whether the material states "can be purchased with confidence" or an equivalent expression. Observable result: that field is unstated, which counts as unsupported and pending verification, not as a contradiction or denial.

## How to verify the setup

1. Input the inspection report text from the hypothetical sample and the draft sentence "This mask has passed quality inspection, the color fastness is qualified, and it can be purchased with confidence." Compare: whether the entity, object, and status in the draft sentence match the same entity, the same period, and the same field in the report text. Observable result: the color fastness qualification is supported; "can be purchased with confidence" is unstated, counts as unsupported, and remains pending verification.
2. Input the prohibited list text from the hypothetical sample and the same draft sentence. Compare: the list places disposable medical masks in a restricted category and requires filing, while the draft sentence does not state filing status. Observable result: the filing portion is an evidence gap; a pending review does not demonstrate a lack of operating permission.
3. Input an explicit paper empty result and check downstream handling. Compare: whether the output path still runs when the citation content array length is zero. Observable result: downstream handles it as an empty citation; do not claim that a particular rule's retrieval necessarily returns an empty array.
