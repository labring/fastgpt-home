# Cross-border settlements: workflow routing for copy drafting

## What the documents look like

Cross-border platform settlement and currency exchange concerns the collection of funds from orders that have already been completed. It does not handle fraud chargebacks. The documents that circulate in this work are platform settlement statements, exchange rate tables, service fee invoices, and receiving reconciliation sheets. They come from platform settlement centers, bank transaction records, payment institution back offices, and ERP order data. The people who work with them are cross-border seller finance staff, tax accountants, and platform operations staff. These documents update weekly or monthly. Errors in this work produce incorrect profit calculations, tax filing deviations, or cash shortfalls.

The copy drafting task requires converting facts from settlement statements, exchange rate tables, service fee invoices, and reconciliation sheets into sentences that can be presented externally. Amounts, fee rates, settlement cycles, and collection status in drafted copy must stay within the wording of the corresponding document. Fields that a document does not state remain unknown.

## Constraints at the workflow routing step

In FastGPT v4.17.2, the Form Input node is a user interaction node. When it triggers, the conversation enters an interaction state, the workflow state is recorded, and execution continues after the user completes the interaction. After the user fills in required information and submits, the node collects the form information and passes it to subsequent nodes. The User Selection node also enters an interaction state; after the user makes a choice, the node evaluates that choice and executes the "yes" branch. The interaction state and state recording are behaviors of these interaction nodes themselves; the documents do not describe a global state-recording switch. Order writes, document backfills, and external status synchronization require a separate business interface or a later process; the orchestration itself does not perform these actions.

Hypothetical paper exercise sample: the source material reads, "The March 2025 platform settlement statement records that Store A had a settlement amount of USD 12,000 for the month, a service fee of USD 240, and a settlement cycle of the 15th of the following month. The exchange rate table for the same period records that the USD to RMB central parity rate on March 31, 2025 was 7.10." The sentence to be assessed is, "Store A completed currency settlement in March 2025 at a rate of 7.10, with a service fee of zero." The comparison target is the same store, the same period, and the same field. The settlement statement records a service fee of USD 240; the drafted sentence states a service fee of zero; the same field carries mutually exclusive values, which constitutes a contradiction. The settlement statement records a settlement cycle of the 15th of the following month; the drafted sentence states that currency settlement was completed; the material does not record a completion status, so that part is unsupported. The exchange rate table gives a central parity rate; the drafted sentence presents it as the rate used for settlement; the material does not record the source of the settlement rate, so that part remains to be verified.

## Configuration and implementation checks

| Configuration item | Value or check item on this page | Basis and explanation |
| --- | --- | --- |
| Form Input node | Collect store identifier, settlement period, and the sentence to be assessed | The node collects required information and passes it to later nodes |
| User Selection node | Set a "yes" branch for "whether the sentence matches the material" | After the user makes a choice, the "yes" branch executes |
| Interaction state check | Triggering enters the interaction state and records the workflow state | A behavior of the interaction node itself; no separate global switch |
| Output handoff check | Pass collected information to a later retrieval or evaluation node | Compare output against input item by item |
| External action division | Order writes and document backfills connect to a separate business interface | Orchestration does not perform writes or synchronization |
| Hypothetical trial starting point | Compare the drafted sentence against material fields item by item | Chosen because assessment requires the same subject, period, and field |

## Three common errors

1. Writing the central parity rate from the exchange rate table as the rate used for settlement. In the hypothetical sample, the exchange rate table states only that the central parity rate on March 31, 2025 was 7.10; it does not state the source of the settlement rate. The drafted sentence says settlement was completed at 7.10, which treats an unstated field as stated. Check: input the exchange rate table text and the drafted sentence; compare whether the drafted sentence asserts a rate use the material does not state; if so, mark it as unsupported.

2. Treating the settlement cycle as a settlement completion status. In the hypothetical sample, the settlement statement records a settlement cycle of the 15th of the following month, and the drafted sentence says settlement was completed; the material does not record a completion status. Check: input the settlement statement text and the drafted sentence; compare whether the drafted sentence treats a cycle field as a status field; if so, mark it as pending verification.

3. Writing the USD 240 service fee as zero. In the hypothetical sample, the settlement statement records a service fee of USD 240, and the drafted sentence states a service fee of zero; the same field carries mutually exclusive values. Check: input the service fee field from the settlement statement and the service fee wording in the drafted sentence; compare whether the two values are mutually exclusive; if so, mark it as a contradiction.

## How to verify the setup

1. Input the settlement statement text, the exchange rate table text, and the drafted sentence from the hypothetical sample. Compare the service fee wording in the drafted sentence against the service fee field in the settlement statement. If the two values are mutually exclusive, judge it a contradiction. If the drafted sentence contains no service fee wording, record it as not addressed.

2. Input the settlement statement text and the drafted sentence from the hypothetical sample. Compare the settlement status wording in the drafted sentence against whether the settlement statement records a completion status. If the material does not record a completion status while the drafted sentence asserts completion, judge it unsupported. If the drafted sentence only restates the settlement cycle, record it as consistent.

3. Input the exchange rate table text and the drafted sentence from the hypothetical sample. Compare the rate use in the drafted sentence against what the exchange rate table states. If the exchange rate table states only a central parity rate while the drafted sentence calls it the settlement rate, judge it pending verification. If the drafted sentence only restates the central parity value, record it as consistent. All three checks use paper samples as input and do not claim actual execution.
