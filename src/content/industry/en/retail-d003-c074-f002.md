# Cross-border resale returns: context limits for copy drafting

## What the documents look like

Return refurbishment and resale handles reverse logistics and item condition. The records differ from first-leg replenishment records. The main data sources are the overseas warehouse WMS, the TikTok return center, Amazon return reports and item inspection photographs. The routine documents are the return inspection sheet, the refurbishment record, the scrap sheet and the resale listing list. Copy drafting has to judge whether one promotional sentence is supported by the inspection sheet and the refurbishment record, for example appearance grade, whether accessories are complete and whether packaging was replaced. Data updates daily or per batch. This page concerns only which materials enter the context at drafting time.

## Constraints at the context limits step

The maximum context of a model sets how much content a single request can reference. The reply cap controls answer length. These two settings are not the same thing. The knowledge base reference limit is controlled by tokens, not by item count, so a long single inspection description can be trimmed. A larger memory turn count brings in more history, and consumption and response speed change with it. The same question has different input under empty history and under history, and retrieval results can differ as well. When json_schema is selected, downstream steps read fixed fields, and checking text length alone does not confirm that the structure is usable. Semantic retrieval and the minimum relevance score affect relevance ordering only. They do not carry out permission or entity isolation. Retrieval itself is not authorization. Hybrid retrieval merges multiple result paths through RRF. ReRank requires a model and must be enabled according to the setting.

Hypothetical paper exercise sample: the source material reads "Return inspection sheet: the subject is one batch of folding tables, condition is minor surface scratches, hardware complete, original packaging damaged; the refurbishment record states the outer carton was replaced and re-inspection passed; date scope 1 March 2024 to 31 March 2024; authorization scope is internal verification within the inspection and refurbishment step." The draft sentence is "This batch of folding tables is listed for sale in new condition after refurbishment." The judgment requires the same subject, the same period and the same field. The material supports minor surface scratches and outer carton replacement only. It does not state "new condition" or "listed for sale." That sentence is not supported, and the evidence gap is retained.

## Configuration and implementation checks

| Maximum context | Shown according to the actual capability of the selected model | Compare with the combined length of the inspection sheet and refurbishment record, and confirm nothing is truncated |
| Reply cap | Hypothetical starting point for this exercise set to cover the basis and the handling action | Compare with the length of the draft sentence and observe whether it is cut off early |
| Reference limit | Controlled by tokens; hypothetical starting point for this exercise covers the two documents | Compare with the length of the single inspection description and confirm the content is complete |
| Memory turns | Hypothetical starting point for this exercise keeps a small number of turns | Compare the input for the same question under empty history and under history |
| Reply format | json_schema when fixed fields are needed | Check that fields are complete and parsing succeeds, not only the length |
| Minimum relevance | Takes effect only under semantic retrieval or ReRank | Observe whether the sample material remains after filtering |

## Three common errors

1. Treating the reply cap as the full context window. The input is the maximum context and the reply cap. Compare the meaning of the two settings and observe whether the reply cap is mistaken for the length of referenceable content.
2. Treating the minimum relevance score as a permission or entity filter. The input is a similarity threshold and one inspection record that does not belong to this batch. Compare the filter condition and observe whether that record is carried in because its relevance is high.
3. Treating a scrap sheet pending review as completed scrapping. The input is the status field of the scrap sheet and the draft sentence. Compare the status value and observe whether an unfinished action is written as a completed fact.

## How to verify the setup

1. Input the source material above and the draft sentence. Compare "minor surface scratches, hardware complete, outer carton replaced" with "new condition, listed for sale." The condition is met when the draft sentence is marked as not supported and the gap is recorded.
2. Input two requests, one with empty history and one with history. Compare the retrieval input for the same question. The condition is met when the difference is recorded and no claim is made that a particular result must appear.
3. Input a paper empty result [] and the downstream handling design. Compare whether the downstream step treats it as an empty reference. The condition is met when the downstream step does not generate unsupported copy. Whether retrieval returns [] is unknown and is not guaranteed.
