# Creator sales campaigns: citation tracing for copy drafting

## What the documents look like

Creator sales campaigns depend on external creator performance and commission settlement, so copy drafting starts from source material that can be checked line by line. The working documents are creator cooperation agreements, commission setting sheets, sample shipment sheets, and livestream performance reports. These materials update per session or per week.

A price, gift, specification, commission rate, or after-sales promise that appears in draft copy requires a matching field in the source material. When that field is absent, the sentence is unsupported. Version timing also matters: the same product can use different agreement or setting sheet versions across sessions, so drafting must confirm which version is being cited.

## Constraints at the citation tracing step

The knowledge base search node can associate one or more knowledge bases that share the same vector model. Its output is a citation array whose length may be zero; even when nothing is retrieved, the output path still completes. The minimum relevance value is a filter threshold that takes effect only under semantic retrieval or when result reranking is used. It does not perform permission or entity isolation, and retrieval itself is not authorization. Hybrid retrieval merges multiple result paths through RRF. Reranking requires a rerank model and must be enabled by configuration. Image retrieval requires corresponding image input and model capability. Knowledge bases with different vector models cannot be associated together; the handling step is to check the identifiers first, exclude the non-matching ones, and record what was observed without running a cross-model retrieval for comparison.

Hypothetical paper exercise: the source material reads "The product for this session is Model A thermos, agreement number H-001, cooperation date March 8, 2025; the commission setting sheet states a commission rate of 15% for this session; the sample shipment sheet states a shipment quantity of 2 units." The draft sentence to be judged is "The commission rate for Model A thermos in this session is 15%, and the gift is 1 unit of the same thermos." On checking, the commission rate matches the same field in the commission setting sheet. The gift item has no corresponding field in the source material, so it is unsupported; the evidence gap must be recorded, and the sentence cannot be judged as a negation or a conflict.

## Three common errors

1. Treating the minimum relevance value as a permission or entity filter. The input is one retrieval request; the comparison object is the filter scope described in the documentation; the observable result is that this setting affects relevance filtering only and does not exclude unauthorized records.

2. Treating a pending review or a quotation validity period as an already effective fact. The input is the draft sentence to be judged and the source material; the comparison is the value of the same field; the observable result is that a field not stated in the material is recorded as unsupported and is not written as a negation or a conflict.

3. Treating an optional retrieval path as executed on every request. The input is one text query containing no image; the comparison object is the path conditions listed in the documentation; the observable result is that image retrieval and reranking are enabled under their respective conditions and produce no corresponding result when not enabled.

## How to verify the setup

1. Input the source material and draft sentence from the hypothetical exercise above, and compare the commission rate field. The observable result is that the sentence is supported when both values are 15%; if the source material does not state a gift, that part remains pending verification.

2. Input one text query and observe the citation array, comparing the number of returned entries against the citation limit. The observable result is that the array length falls between zero and the limit, and the downstream path still completes when the array is empty.

3. Input an explicit paper empty result [] and compare it against the downstream handling design. The observable result is that downstream processes it as an empty citation; this check does not claim that a fabricated rule retrieval necessarily returns an empty array.
