# Creator commission settlement: context limits for copy drafting

## What the documents look like

Commission settlement happens after a sale closes, so copy drafting for this category works across four material types: commission setting records, settlement statements, refund commission deduction details, and invoices. These materials update weekly or monthly. A draft may quote a rate, a deduction condition, or a settlement cycle that comes from the previous period, so any figure or condition written into the copy needs to line up with the period and scope stated in the source material.

Creator contracts and Selected Alliance backend records together form the basis of the promotion relationship. Statements about commission rates, valid promotion determination, and after-sales commission deduction need to be checked against those materials for subject, object, and effective scope. Where a timing gap exists between the finance system's posting basis and the settlement statement, the copy should not present one period's figure as a long-term commitment.

## Constraints at the context limits step

Copy drafting depends on the model reading the materials above. The maximum content a single request can reference is set by the chosen model's maximum context. The reply limit only constrains output length and does not serve as a full context window. The knowledge base citation limit is controlled by tokens, so a long single passage may be truncated; question samples are needed to check whether the cited content is complete.

History input affects how the same question behaves with empty history compared to history present. When a fixed reply format carries structured fields, field completeness and successful parsing need verification; checking text length alone is not enough. Semantic retrieval and minimum relevance act on recall and filtering only, and do not carry permission or entity isolation. The association requirement between a retrieval library and a vector model stays inside the knowledge base and does not extend to external systems.

Hypothetical drill sample: Material text one reads "March 2025 commission setting record: a certain product carries a commission rate of 12%, with a settlement cycle of 15 days after confirmed receipt." Material text two reads "April 2025 refund commission deduction details: two March orders for this product were refunded, and the corresponding commission has been deducted back." The draft sentence to be judged reads "This product's commission rate is 12% long term, and refunds do not deduct commission." Judgment points: the material states only the March rate and does not state long-term validity; the refund deduction details show the commission was deducted back, so the draft sentence takes the opposite value on the same field compared with the material, and is unsupported.

## Configuration and implementation checks

| Configuration or check item | Hypothetical starting point for this page | Reason and comparison object |
| --- | --- | --- |
| AI model | Select a model whose context length covers the four material types | Compare against total material length to confirm a single request can hold it |
| Reply limit | Assume set to a medium length | Compare against draft sentence length to confirm no early truncation |
| Knowledge base citation limit | Assume set by token to cover a single passage | Compare against the longest single passage to check for truncation |
| Memory turns | Assume a small number of turns retained | Compare input difference against the same question under empty history |
| Reply format | Use json_schema when fixed fields are required | Check field completeness and successful parsing |
| Minimum relevance | Assume kept at default | Compare against recall results to confirm target material remains after filtering |

## Three common errors

1. Treating the reply limit as the full context window. Input is the four material types plus the draft sentence; the comparison object is the model's maximum context; the observable result is truncated material or a missing basis for the draft sentence.
2. Treating minimum relevance as a permission or entity filter. Input is the same question with materials for different subjects; the comparison object is the subject identifier in recall results; the observable result is that material for an unrelated subject is still recalled.
3. Writing a single-period figure from the material as a long-term commitment. Input is the March commission setting record and the draft sentence; the comparison object is the period and effective scope field; the observable result is that the draft sentence goes beyond the scope stated in the material.

## How to verify the setup

1. Input the two material sentences and the draft sentence from the hypothetical sample above, compare the rate and deduction wording in the draft sentence against the same-field values in the material, and observe that the draft sentence takes the opposite value from the refund deduction details, which is judged unsupported.
2. Input the same question twice, once with empty history and once with a small number of memory turns, compare the input content difference between the two requests, and observe that history has not introduced rate or period information outside the material.
3. Input an explicit paper-based empty result [], check whether the downstream handling design treats it as an empty citation, and observe that the downstream does not treat the empty citation as a confirmed conclusion.
