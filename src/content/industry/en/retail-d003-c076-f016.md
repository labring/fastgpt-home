# Creator commission settlement: interactive forms for copy drafting

## What the documents look like

Commission settlement in this category happens after a sale closes. The object being checked is the valid promotion order, and refunds or after-sales events change the final commission payable. Routine materials include commission setting records, settlement statements, refund commission deduction details, and invoices, with weekly and monthly update cycles. This page addresses product and marketing copy drafting. The material scope is the product facts and commission wording that the copy cites; the settlement amount itself is not determined here.

A commission setting record can state a rate and an applicable period for a named product. A settlement statement can state which orders count as valid promotion. A refund deduction detail can show how a refund changes the amount owed. These are separate documents, and a value that appears in one is not automatically confirmed for the period or product named in a draft sentence.

## Constraints at the interactive forms step

The form input node is a user interaction node. When it triggers, the conversation enters an interaction state, the workflow state is recorded, and execution continues after the user completes the interaction. After the user fills required information and submits, the node collects the submitted form information and passes it to later nodes. The node itself does not carry business database functions.

The user selection node also enters an interaction state and records workflow state while waiting. When the user makes a choice, the node judges that choice and executes the corresponding branch. It is not a personnel directory or a business data selector.

Field validation, business approval, write-back, and batch operations require an external system or later nodes. A selection that keeps the workflow moving is not an approval. A pending review is not evidence that an authorization is missing.

Hypothetical drill sample: the material text reads, "The product in this creator collaboration is Product A, a vacuum cup; the commission rate follows the settlement statement wording; refunded orders are not counted as valid promotion." A separate commission setting record states, "Product A vacuum cup, commission rate fifteen percent, applicable period is this collaboration." The draft sentence to be judged reads, "This product has a commission rate of fifteen percent, and refunded orders are also counted as valid promotion."

Compare the same subject, same period, and same field. Both the material text and the setting record point to refunded orders not being counted as valid promotion. The draft sentence's statement about refunded orders conflicts with the material on that field. The commission rate field has an explicit value in the setting record, but whether the applicable period covers the collaboration named in the draft still needs checking.

## Configuration and implementation checks

| Configuration or check item | Use on this page | Condition or source |
| --- | --- | --- |
| Form input node | Collect the draft sentence and cited material identifiers | Official document states submitted information is passed to later nodes |
| Required information check | Check whether subject, product, period, and field are complete | Test missing items and completed items separately |
| User selection node | Choose to adopt or return the draft sentence | Branch executes according to the choice |
| Interaction state | Wait for form completion or a selection | Workflow state is recorded after triggering |
| Downstream handling split | Validation, approval, and write-back | Implemented by an external system or later nodes |

Hypothetical trial starting point: set four required items, because the sample contains four comparison dimensions: subject, product, period, and field. The comparison method is to check each item against the material text. If any item is missing, record the gap; do not treat the copy as established on that basis.

## Three common errors

1. Treating the commission rate in the draft sentence as a verified fact. The draft sentence states fifteen percent. The setting record does state that value, but whether the applicable period covers the collaboration named in the draft is not stated. That field remains to be verified.

2. Treating the refunded-order wording as compatible with two positions. The material text and the setting record both point to refunded orders not being counted as valid promotion on the same field. The draft sentence states they are also counted, which is a mutually exclusive value on the same field.

3. Treating the branch result of the user selection node as a completed approval. A selection to adopt only means the workflow continues. Business approval requires an external system. A pending review does not demonstrate that permission is absent.

## How to verify the setup

1. Input the hypothetical sample's material text and draft sentence, and compare the refunded-order field. The material text and setting record both point to not counted; the draft sentence states counted. A mutually exclusive value on the same field meets the identification condition.

2. Input the commission rate from the setting record and the value cited in the draft sentence, and compare the applicable period field. The setting record does not state that this rate covers the collaboration named in the draft. A field gap is recorded as to be verified.

3. Input an explicit paper empty result `[]` and check the downstream design. Observe how later nodes handle the absence of cited material. Do not claim that a fictional rule retrieval necessarily returns empty.
