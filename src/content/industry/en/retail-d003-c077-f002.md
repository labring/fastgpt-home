# Import and export permits: context limits for copy drafting

## What the documents look like

Permit handling takes place before declaration and determines whether a shipment may lawfully cross a border, so drafting product and marketing copy for this category cannot be treated as a pure wording exercise. The working documents include automatic import licences, dual-use item licences, contracts and product descriptions. The use, model and controlled-scope statements inside product descriptions and contracts directly define what the copy may and may not say. These materials are prepared per shipment and updated irregularly, so the permit status of the same commodity can differ between one shipment and the next.

The drafting task in this page is limited to product and marketing copy. Whether a specific promotional sentence is supported by the underlying materials is a wording-evidence question, and it stays separate from identity certification, report analysis or any other task.

## Constraints at the context limits step

The context window is checked against the actual model capability, and the reply limit is the maximum length of a single answer; these are two different measures. The knowledge-reference limit is counted in tokens, so when a single passage is long the referenced content can be trimmed and the use statement or controlled-scope sentence on which a judgement depends may not enter the context. Memory turns bring earlier conversation into the request, so the same question submitted with empty history and with history produces different inputs and can produce different conclusions. When a fixed reply format is used, whether the fields are complete and can be parsed by a downstream node needs separate checking; acceptable text length does not mean acceptable structure.

Hypothetical paper exercise sample: the source material reads "The goods in this shipment are an industrial pump of a certain model, intended for general industrial circulating-water transport", "The contract stipulates a delivery period of sixty days after signing", and "The automatic import licence application is in pending review status". The draft sentence to be judged is "This product has obtained an automatic import licence and export can be arranged immediately". In this sample the subject, object and status are all paper assumptions and point to no real enterprise or licence number.

## Three common errors

1. Treating the reply limit as the full context window. Input: the maximum context shown in the model popup and the reply limit already set. Compare the meaning of the two values and observe whether they are merged into one limit.
2. Writing a pending-review status as an obtained licence. Input: the sample statement "The automatic import licence application is in pending review status". Compare the draft sentence "has obtained an automatic import licence" and observe whether the two point to the same fact.
3. Setting the reference limit too small so the use statement is trimmed. Input: the sample source text and the token limit that was set. Compare the text that enters the context and observe whether the use sentence appears in full.

## How to verify the setup

1. Input the sample source text and the draft sentence. Compare the licence-status wording in the draft against the status field in the source. The sentence is supported only when both share the same subject, the same period, the same field and a matching value; where the source says pending review, the draft wording "has obtained" is not supported.
2. Input the same question once with empty history and once with a small number of history turns. Compare the content that actually enters the context in the two requests. If the history version introduces older shipment information unrelated to the current commodity, the memory-turn setting needs to be lowered.
3. Input an explicit paper empty result `[]` together with the downstream handling design. Compare the downstream output when it receives empty references. If the downstream still generates affirmative copy, the empty-result branch needs additional handling; this must not be taken to imply that a fictional rule necessarily returns an empty result.

The public technical facts checked for this feature, used to locate relevant content in the documents and not required to be copied as a fixed five-row table, are: model context is checked against actual model capability and the reply limit is not the full context window; reply length is adjusted to the task and keeps enough room for the basis and the handling action; the knowledge-reference limit is controlled in tokens and checked against single-passage length and the question sample to see whether content is trimmed; history input is checked by comparing the same question with empty history and with history to exclude context differences; and structured downstream handling is verified by field completeness and successful parsing, not by text length alone.

This page addresses only import and export permit handling, product and marketing copy drafting, and context and token limits. Semantic retrieval and relevance scores do not perform permission or entity isolation, and a same-vector-model requirement for a retrieval library does not extend to business-registration websites or other external systems. RRF is a fusion process for mixed results and is not written as a switch. The thinking budget is a reasoning budget and must not be reused as the reference token limit. Retrieval checks describe observations and failure branches and do not guarantee a first-hit result, full recall or an empty result for unrelated queries. Libraries built on different vector models cannot be associated together; check the identifiers first, exclude those that do not match, and record the actual observation without inventing run-time outcomes. A judgement requires the same subject, the same period and the same field; only clearly mutually exclusive values in the same field count as a contradiction, while an unstated value or evidence from a related stage alone remains unsupported or pending verification. Pending review does not demonstrate a lack of operating authority; signing, reaching cooperation and contract effectiveness are three distinct facts; a quotation validity period does not indicate a supply period. Authorization or effectiveness clauses must not be invented to obtain a definite answer, and evidence gaps stay recorded as gaps.
