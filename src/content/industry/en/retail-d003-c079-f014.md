# Central chain procurement: model connections for copy drafting

## What the documents look like

Central procurement and central distribution rely on documents from headquarters purchasing, distribution, and store replenishment. Centralized procurement contracts record supplier, item, price, and delivery terms. Replenishment plans and distribution orders record batch, quantity, and arrival arrangements. Store requisition orders record store demand. These documents are assembled from ERP purchasing, WMS, store POS, and supplier delivery data, with daily or weekly updates.

Drafting copy for goods and marketing requires extracting externally expressible item facts from these documents, such as specification, origin, and supply status. When copy includes content that no document supports, the wording seen by stores and consumers diverges from headquarters procurement records, and later reconciliation becomes more costly. This page addresses only model connection and configuration for the copy drafting step. It does not address price and display auditing, and it does not address enterprise identity certification.

## Constraints at the model connections step

Copy drafting calls a language model, and model connection is handled by AI Proxy. FastGPT v4.17.2 requires App and Admin to configure `AIPROXY_API_ENDPOINT` and a non-empty `AIPROXY_API_TOKEN`; if either is missing, startup validation fails. `AIPROXY_API_ENDPOINT` takes the service root address and does not append `/v1`. Legacy OpenAI environment variables or a single-model custom request address cannot substitute for these two items.

Model capabilities are checked against the inputs the application requires. Multimodal input, tool calling, and reasoning configuration need separate verification. Application parameters are set in the application or node configuration; identically named fields in a compatible chat interface do not necessarily override orchestration.

Hypothetical paper exercise sample: a central procurement and distribution enterprise supply chain center retains an excerpt of a centralized procurement contract, whose original text reads: "Supplier A supplies headquarters with 500 g pack Northeast rice; the contract is valid from January 1, 2026 to December 31, 2026; the first distribution order shows 200 cases arrived on February 10, 2026." The draft sentence under review is: "This item originates from Northeast China and is supplied stably year-round." The phrase "supplied stably year-round" does not appear in the contract excerpt and is an unsupported statement.

## Three common errors

1. Writing `AIPROXY_API_ENDPOINT` as a full request address that includes `/v1`. Check: input the variable value, compare with the root address format given in the document; an occurrence of `/v1` does not meet the condition.
2. Using an application API key as `AIPROXY_API_TOKEN`. Check: input both values, compare with the AI Proxy server configuration; a mismatch does not meet the condition.
3. Treating "first arrival" in the contract excerpt as the basis for "supplied stably year-round." Check: input the contract excerpt original text and the draft sentence, compare subject, period, and field; when the period stated in the draft sentence exceeds the coverage of the contract validity period, the statement is unsupported.
