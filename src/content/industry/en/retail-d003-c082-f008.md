# Returned-goods inspections: copy drafting with workflow routing

## What the documents look like

For copy drafting in Returned-goods inspections, this page examines FastGPT workflow routing. Returned-item descriptions preserve inspection coverage and grading evidence. An inbound record cannot establish condition or saleability promises. The examples are hypothetical.

## Constraints at the workflow routing step

A proposed inbound return record says the item was received. Inspection photographs show only the shell, grading awaits review and shelving remains an arrangement. Collect passages with the item relationship. A person may obtain function checks or grading evidence. Receipt establishes intake, shell images do not establish working functions, and a shelving arrangement does not establish public saleability. Supply no grading standard or claim of full restoration from complete-looking assets.

## Configuration and implementation checks

| Return-item copy | Proposed subject | Evidence needed |
| --- | --- | --- |
| Inbound record | Received only | Not a quality conclusion |
| Image coverage | Shell only | Separate function evidence |
| Grading state | Review pending | Not a fixed condition grade |
| Shelving arrangement | Task is not permission | Actual decision |
| Item correspondence | Same model is not same item | Exclude other-object assets |

## Three common errors

Appearance promoted to function needs actual functional inspection. Pending review promoted to a grade needs this item’s explicit conclusion. A shelving arrangement promoted to saleability needs the actual business decision. These inspect evidence type, conclusion stage and permission rather than fill gaps through workflow completion.

## How to verify the setup

Inspect whether function and grading paths receive the same returned item. Added function records change only covered content, leaving unresolved grading explicit. Exclude photographs from another object instead of linking them by model name. Stock classification, listing and service commitments need separate authority and receipts. A finished description establishes neither restored condition nor a completed sale.
