# Store counts and loss control: copy drafting with workflow routing

## What the documents look like

For copy drafting in Store counts and loss control, this page examines FastGPT workflow routing. Inventory-loss wording separates identified discrepancies, cause investigation and actual handling. A count difference or recording excerpt cannot directly establish responsibility. The examples are hypothetical.

## Constraints at the workflow routing step

Proposed count wording says book-to-stock differences remain unresolved. Analysis lists possible causes, and a recording-review excerpt describes one action segment. Collect coverage and let a person obtain count evidence or inspect cause records. Supply no quantities, loss amounts, identities or accusations. A discrepancy needs investigation, and a possible cause remains a hypothesis. An ended count without loss approval does not establish adjusted inventory.

## Configuration and implementation checks

| Inventory-loss wording | Proposed source status | Boundary retained |
| --- | --- | --- |
| Book-to-stock difference | Unresolved | Not an established cause |
| Analysis passage | Possible cause | Not investigation finding |
| Recording excerpt | Partial action description | Not responsibility |
| Inventory handling | Actual record absent | Not adjusted stock |
| Input transfer | Qualified wording preserved | Evidence changes corresponding claims only |

## Three common errors

Hypothesis promoted to cause needs actual investigation evidence. A segment promoted to responsibility requires complete context and the actual finding. Counting promoted to handling needs the corresponding inventory-processing record. These inspect inference, evidence coverage and execution without changing them through finished copy.

## How to verify the setup

Compare actual recipients on count and cause paths, preserving unresolved wording. Added discrepancy origins change only supported explanations while missing handling outcomes remain open. Inventory changes, spoilage and formal investigation need separate authority and records. The copy distinguishes known from unknown without deriving responsibility from visible footage or claiming loss-prevention performance from workflow output.
