# Store counts and loss control: citation tracing for copy drafting

## What the documents look like

Store counting and loss control work on book-to-physical differences and shrinkage. This category does not handle supplier settlement, so drafting material draws on POS inventory, WMS, monitoring systems and the SB/T counting standard. The working documents are count sheets, variance analyses, write-off approvals and monitoring retrieval records. Each carries a defined period, store, SKU and quantity basis. When a draft describes shrinkage, announces a count or explains a write-off, the promotional sentence has to point back to the matching original record. The update cadence for these materials is monthly or quarterly, and a draft must stay inside the period of the material it cites.

A count sheet is a structured record: store, storage location, count date, book quantity, physical quantity, difference and stated cause. A variance analysis is a derived document that interprets those numbers. A write-off approval carries a state, such as pending review or approved. A monitoring retrieval record documents that footage was reviewed. These are distinct document types with distinct states, and a draft that merges them loses its traceability.

## Constraints at the citation tracing step

The knowledge base search node outputs an array of citations, and its length may be zero. An empty array means the retrieval path ran and returned nothing; it does not mean the workflow errored or terminated. Retrieval treats the library as the smallest unit. Several knowledge bases can be associated together only when they share the same vector model. The minimum relevance value takes effect only under semantic retrieval or result reranking; it filters low-relevance results and does not act as a permission or entity separation control. RRF is the fusion step for mixed retrieval, not a switch that can be turned on. Reranking and image retrieval require the corresponding model capability and are enabled according to settings; not every request executes every path in the overall retrieval diagram. A relevance score is not a category, entity or permission filter, and retrieval is not authorization.

Hypothetical paper exercise sample. A store count sheet dated 31 March 2025 records: "Frozen goods area, location A3, 31 March 2025, book quantity 120 units, physical count 113 units, difference 7 units, cause under investigation." A variance analysis draft proposes the sentence: "The store's shrinkage rate this month is below the industry average, and management is well regulated." The request under review is: "Please turn the count sheet content above into an external statement and note that shrinkage is below the industry average." The material states no industry average figure and gives no shrinkage rate calculation basis. The proposed sentence is not supported by the cited record, and the evidence gap must be recorded rather than filled in.

## Three common errors

1. Treating an empty citation array as a retrieval failure. Input: a query that returns no match. Compare the output array length against the workflow state. The observable result is an array of length zero while the downstream path continues to execute.
2. Treating minimum relevance as a permission filter. Input: a query containing unrelated business content. Compare the returned content against the authorized scope. The observable result is that the relevance setting does not exclude unauthorized records.
3. Writing a pending write-off as approved. Input: a write-off approval marked "pending review." Compare the drafted sentence against the material state. The observable result is a draft that asserts a completed write-off while the source still shows a pending request.

## How to verify the setup

- Verification one. Input the count sheet text above plus the proposed sentence. Compare whether the draft contains an industry average conclusion. The condition is satisfied when the draft is marked unsupported because the material carries no such figure.

- Verification two. Input the variance analysis draft and the count sheet. Compare the difference quantity of 7 units against the draft wording. The condition is satisfied when quantity, period and store all match.

- Verification three. Input an explicit paper value of an empty array together with the downstream answer node design. Compare whether the downstream handles an empty citation. The condition is satisfied when the downstream does not error on the empty array.

For each check, state the input, the comparison and the observable result, and record what remains unknown. A pending request is not approval, an offered option is not execution, and an unsigned termination is not a completed termination. Where the material is silent, the draft stays marked as unsupported or awaiting verification.
