# MCN operations: document comparison with context limits

## What the documents look like

For document comparison in MCN operations, this page examines FastGPT context limits. An activity-recap excerpt and reuse of complete footage have different permission subjects. The examples are hypothetical.

## Constraints at the context limits step

A proposed MCN contract clause allows edited excerpts only for the current activity recap and requires separate confirmation for reuse of complete footage. A communication note says to follow the previous standard version, but no such attachment is supplied. A question about long-term reuse of a complete video needs the excerpt, full footage, current recap and separate-confirmation subjects preserved together. Keeping only use permitted would remove the distinction. Historical shorthand cannot define the missing version or expand an excerpt permission to the complete recording. The comparison must first identify the unresolved version and material subjects.

## Configuration and implementation checks

## Three common errors

One failure condition is a retrieved passage losing the second clause, after which recap use becomes unrestricted reuse of complete footage. Another is a prior project practice in conversation history displacing the current clause. Retain the actual input with its material subjects, current wording and historical reference to distinguish a trimmed condition from a substituted object. Actual model context capacity needs checking on its own terms; reply length does not define it. More available input space also cannot supply a standard-version attachment whose text is missing from the available sources.

## How to verify the setup

Acceptance should repeat the same reuse question with empty history and with the proposed earlier-project reference. Inspect whether the actual current input still contains the purpose limitation and separate-confirmation condition. The output can distinguish material subject, stated use and confirmation still needed; verify that excerpt and complete footage have not collapsed into one entry. Where a fixed downstream format is used, check complete entries and successful parsing. The reply must retain the missing-attachment action rather than shortening away its qualification or describing proposed reuse as permission already obtained.
