# MCN operations: document comparison with citation tracing

## What the documents look like

For document comparison in MCN operations, this page examines FastGPT citation tracing. Script comments, material-use scope and creator availability need separate source traces. The examples are hypothetical.

## Constraints at the citation tracing step

A proposed MCN packet contains a collaboration note referring finished-video use to a material-permission page, a script comment removing a night scene and a creator reply offering Wednesday for discussion. A question about using the edited video on store screens needs the actual use source. The comment concerns content and the reply concerns availability for conversation. Neither supplies the missing permission scope. Identify the current finished material and screen context rather than completing an unseen permission page or announcing a confirmed shoot from exchanged script comments.

## Configuration and implementation checks

| Transaction-source check | Material and action scope | Acceptance action |
| --- | --- | --- |
| Finished material | Current edited video | Check material identity. |
| Content comment | Remove night scene | Do not turn into use permission. |
| Availability | Wednesday discussion | Seek separate shoot confirmation. |
| Use page | Currently missing | Inspect scope and answer input. |
| Earlier-page subject | May concern another creator | Compare creator and version. |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Associated knowledge bases` | Knowledge bases associated with one search node must use the same embedding model. |
| `Citation output` | The output is an array; an empty array can continue. |
| `Citation input handoff` | Inspect citations actually received by the answer step. |
| `Citation display check` | Trace displayed sources to their originals. |
| `Document-validity check` | Inspect source identity and applicable version separately. |

## Three common errors

First, a script deletion may be cited as screen-use permission; inspect the actual use page and its material identity. Content feedback establishes no usage scope. Second, Wednesday availability may become a confirmed shoot; inspect the activity named in the reply and seek current scheduling confirmation. Third, another creator’s earlier use page may attach to this finished video; check creator, material and version. These require scope evidence, event confirmation and source-subject correspondence. A shared agency name cannot join them into an established permission chain.

## How to verify the setup

Ask separately what changed in the script, which activity the creator offered and what supports screen use, retaining the exact cited wording. If only the script reaches the answer, investigate whether the use page entered the knowledge scope and actual input. Its absence from results does not establish that use is prohibited. After receiving it, verify the current material and proposed use. Reading the page establishes no completed signing, approval or publication; each actual arrangement still needs its own applicable record and evidence.
