# Shopify fulfillment: document comparison with tool calls

## What the documents look like

For document comparison in Shopify fulfillment, this page examines FastGPT tool calls. Compare the material received with the sources used in the answer. The examples are hypothetical.

## Constraints at the tool calls step

A Shopify transaction comparison can ask what an order and shipping-rate template each cover. Proposed inputs supply the destination region, template applicability and source version, without evidence that this template was applied to this order. Describe a proposed reading tool around textual differences rather than treating the template’s existence as completed fulfillment. Check system-module parameters separately from configurable plugin parameters; similar names do not establish identical meanings.

## Configuration and implementation checks

| Check | Proposed material or condition | Evidence to inspect |
| --- | --- | --- |
| Applicability | Order region and template passage | Application to this order is not presumed |
| Parameter classes | System and plugin configuration inspected separately | Each transmitted meaning has a basis |
| Missing source | Template passage omitted from request | No completed comparison asserted before supplementation |
| Label boundary | Label used to locate the order only | It does not replace commitment evidence |
| Further action | Separate refund or fulfillment procedure | Difference output is not an execution receipt |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Tool description` | Describe purpose, inputs and non-applicable situations. |
| `Tool parameters` | Inspect module and plugin parameters separately. |
| `Required parameters` | The model may not invoke a tool without suitable required inputs. |
| `Tool connections` | Available tools must connect to the calling module. |
| `Tool-call termination` | Termination ends the call without a later AI summary. |

## Three common errors

If the request contains only the destination but omits the template passage, the comparison lacks necessary evidence. Inspect what actually reached the tool rather than its configuration alone. Another failure treats a shipping label as final proof of a shipping commitment. Compare the read passages, returned citations and question, removing conclusions without scope evidence. A label can locate a record without establishing contractual performance. If both texts are supplied but the template version does not cover this order, inspect its applicable period and order correspondence. Nonempty sources are not necessarily suitable; an earlier template cannot directly support the present shipping judgment.

## How to verify the setup

Retest first without the template passage, then with the corresponding version, inspecting actual requests, calls and sources of each difference. Missing suitable required inputs may prevent a call; collect the source through interaction and verify the result without promising automatic completion. Termination prevents a subsequent AI summary of this call. Refunds, rate changes or fulfillment updates additionally require business permission and actual receipts.
