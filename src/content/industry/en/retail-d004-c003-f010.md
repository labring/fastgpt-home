# Shopify fulfillment: document comparison with citation tracing

## What the documents look like

For document comparison in Shopify fulfillment, this page examines FastGPT citation tracing. Packaging revisions, buyer preferences and handling requests retain their own actions. The examples are hypothetical.

## Constraints at the citation tracing step

A proposed Shopify packet has a product page specifying a paper box, a buyer note asking to avoid an extra gift box where possible and a service reply saying the preference was recorded. An earlier note says gift-box details are subject to discussion. A question about this order’s final packaging needs an actual order-change record. The page describes the original configuration and the note expresses a request; recording the preference does not establish execution. The earlier note also needs a version and transaction match before use.

## Configuration and implementation checks

| Transaction-source check | Material and action scope | Acceptance action |
| --- | --- | --- |
| Original configuration | Product page specifies paper box | Check order-matched page. |
| Preference qualifier | Avoid extra box where possible | Retain condition strength. |
| Service action | Preference recorded | Do not call it an executed change. |
| Earlier note | Gift-box details for discussion | Inspect applicable version. |
| Execution source | Current order handling absent | Seek this order’s record. |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Associated knowledge bases` | Knowledge bases associated with one search node must use the same embedding model. |
| `Citation output` | The output is an array; an empty array can continue. |
| `Citation input handoff` | Inspect citations actually received by the answer step. |
| `Citation display check` | Trace displayed sources to their originals. |
| `Document-validity check` | Inspect source identity and applicable version separately. |

## Three common errors

First, preference recorded may become order modified; inspect the current order’s processing record rather than treating a service phrase as a completed write. Second, the old gift-box note may override the current product page; check versions, subject and applicable order timing. Third, removing where possible may turn a preference into an absolute condition; return to the original sentence and inspect any subsequent confirmation. These checks concern execution, source applicability and condition strength. A confirmation-style document title cannot replace reading what its body actually acknowledges.

## How to verify the setup

Acceptance should separate original packaging, requested preference, service action and current order state while inspecting actual citation content. Product-page-only references support the paper-box configuration, not completed handling of the buyer note or an inferred rejection. If an order record is added, confirm its transaction and handling round before using it. Empty references leave search scope and transfer to investigate. This text comparison performs no packaging modification and supplies no evidence that a warehouse actually used a particular packing arrangement for the order.
