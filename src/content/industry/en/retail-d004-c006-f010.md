# General export declarations: document comparison with citation tracing

## What the documents look like

For document comparison in General export declarations, this page examines FastGPT citation tracing. Trace subject correspondence among export-contract names, invoice abbreviations and packing descriptions. The examples are hypothetical.

## Constraints at the citation tracing step

A proposed export packet contains a contract for a desktop metal stand excluding a clamp light, an invoice using an abbreviated stand name and a packing note saying the base is packed separately. An earlier promotional page describes a stand-and-light combination. A question about including the light in this transaction’s description needs source-subject correspondence. The promotional combination cannot replace the contract exclusion. The abbreviation needs mapping evidence, while separate packing concerns arrangement rather than an added or removed component. No declaration eligibility or completed processing follows from these names.

## Configuration and implementation checks

| Transaction-source check | Material and action scope | Acceptance action |
| --- | --- | --- |
| Contract composition | Clamp light excluded | Retain exclusion sentence. |
| Invoice abbreviation | Correspondence unverified | Seek transaction mapping. |
| Base placement | Separate packing is not exclusion | Inspect list and action. |
| Earlier promotion | Stand-and-light combination | Check version and subject. |
| Actual references | Current contract and invoice | Inspect delivery of qualifiers. |

| Documented item / implementation check | Condition |

| `Citation output` | The output is an array; an empty array can continue. |

## Three common errors

First, the promotional combination may expand this contract; inspect page version, combination identity and the explicit exclusion instead of relying on similar stands. Second, the abbreviated invoice name may become the full contract subject without evidence; inspect this transaction’s item correspondence and retain both originals. Third, separate packing may become exclusion of the base from the sale; read the packing action and item list. These are version applicability, name mapping and packaging meaning. Each requires its own source relationship rather than a shared product word.

## How to verify the setup

Ask what the contract excludes, whether the invoice abbreviation is mapped and why the base is separately described, checking actual cited qualifiers. Promotional-page-only references cannot establish a completed contract-invoice comparison; inspect whether current transaction sources entered scope and reached the answer. Added mapping still needs the current item checked instead of inferring identity from a similar model. Reading performs no declaration and replaces no independent review of applicable requirements. An empty array supplies no usable reference for this answer and requires further investigation rather than a business-status conclusion.
