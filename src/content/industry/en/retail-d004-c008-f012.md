# Amazon FBA preparation: document comparison with document chunking

## What the documents look like

For document comparison in Amazon FBA preparation, this page examines FastGPT document chunking. Outer-carton relabelling and excluded product labels require their row-level scope retained. The examples are hypothetical.

## Constraints at the document chunking step

A proposed FBA service attachment lists outer-carton relabelling within current work and product labels outside scope on the next row. A note says added handling requires separate confirmation. A question about product relabelling first needs row subjects and scope checked. Related label vocabulary cannot merge carton and product services. If parsing emits columns separately, the negative value may attach to the wrong row. Compare each original row with parsed output before chunking, instead of relying on the service attachment title or the shared relabelling theme.

## Three common errors

One common error joins product labels to current work and the answer declares inclusion. Another loses the added-confirmation note across chunk boundaries, making any additional task appear immediately executable. Compare original table, parsed text and block scope to distinguish wrong-row pairing from separated conditions. Original data may have several search entries, but a product-label entry still needs the actual block containing its exclusion. Index wording cannot create an added service, and agreed scope cannot become an executed relabelling result without an actual work record.

## How to verify the setup

Acceptance should query carton markings, product labels and whether product relabelling can be added directly. Returned blocks need their proper rows and separate-confirmation condition. A task-list output should distinguish current work from additions awaiting confirmation rather than marking everything executable. After revisions, inspect actual processing, indexes and returned versions before repeating the questions. Uploading a new attachment does not establish that the exclusion row was updated in retrieval. Preserve original and cited passages, with old blocks available to locate continued use of the earlier scope.
