# Franchisee onboarding: document comparison with citation tracing

## What the documents look like

For document comparison in Franchisee onboarding, this page examines FastGPT citation tracing. Trace attendance, assessment comments and opening-assistance confirmation by event and responsibility. The examples are hypothetical.

## Constraints at the citation tracing step

A proposed franchise-opening packet has a coaching note leaving display training for later arrangement, an attendance sheet for a product introduction and a message offering further discussion of opening displays. An earlier store’s assessment concerns equipment operation. A question about completed display training and opening confirmation needs event roles separated. Attendance describes participation in one activity, not passing another course. The earlier assessment differs in both store and content. It cannot complete missing current-store training or opening evidence simply because it belongs to the same franchise background.

## Configuration and implementation checks

| Transaction-source check | Material and action scope | Acceptance action |
| --- | --- | --- |
| Activity identity | Product-introduction attendance | Do not substitute for display assessment. |
| Course result | Attendance is not passing | Inspect actual assessment content. |
| Assistance action | Further discussion offered | Seek current-store arrangement. |
| Earlier-store record | Equipment assessment | Check store and subject. |
| Opening confirmation | Complete evidence absent | Retain unresolved items. |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Associated knowledge bases` | Knowledge bases associated with one search node must use the same embedding model. |
| `Citation output` | The output is an array; an empty array can continue. |
| `Citation input handoff` | Inspect citations actually received by the answer step. |
| `Citation display check` | Trace displayed sources to their originals. |
| `Document-validity check` | Inspect source identity and applicable version separately. |

## Three common errors

First, introduction attendance may become a passed display assessment; inspect activity identity, curriculum and actual assessment outcome, since participation and passing need different evidence. Second, an offer to discuss may become a committed on-site service; read the message action and seek this store’s assistance arrangement. Third, an earlier equipment assessment may become current-store opening confirmation; compare store, assessment subject and version. These concern event result, service action and source attribution. A common franchise brand cannot join unrelated records into a completed opening-readiness chain.

## How to verify the setup

Acceptance should ask which introduction was attended, how display training is arranged and which opening matters are confirmed, inspecting actual citation content. Attendance alone leaves course and assessment evidence pending; it proves neither failure nor cancellation. Added arrangements need this store and course checked, while assessment results support only what was evaluated. Empty references require knowledge-scope and transfer investigation. This comparison performs no training or opening approval. One record also establishes no complete opening readiness, which would need the actual applicable evidence rather than an inferred general status.
