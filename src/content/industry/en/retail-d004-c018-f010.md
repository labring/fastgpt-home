# Regional dealer stock: document comparison with citation tracing

## What the documents look like

For document comparison in Regional dealer stock, this page examines FastGPT citation tracing. Compare regional enquiries, transfer suggestions and confirmed orders by product version and action. The examples are hypothetical.

## Constraints at the citation tracing step

A proposed distributor packet has a regional agreement supplying against confirmed orders, a store enquiry seeking the matte version and a warehouse suggestion to examine a glossy substitute sample. An earlier glossy order is retained separately. A question about a confirmed switch this round needs request, suggestion and transaction identity separated. The agreement requires a confirmed order, the enquiry requests matte and the suggestion only offers a sample to examine. Earlier trade does not renew automatically. A glossy inventory introduction or shared region establishes no acceptance of the proposed substitute.

## Configuration and implementation checks

| Transaction-source check | Material and action scope | Acceptance action |
| --- | --- | --- |
| Current request | Matte version | Retain request identity. |
| Substitution action | Examine sample first | Do not make it a changed order. |
| Earlier order | Prior glossy transaction | Inspect order identity. |
| Agreement reference | Confirmed order | Read actual specification. |
| Arrival state | Current execution absent | Do not infer store receipt. |

### Documented conditions

| Documented item / implementation check | Condition |

| `Associated knowledge bases` | Knowledge bases associated with one search node must use the same embedding model. |
| `Citation output` | The output is an array; an empty array can continue. |
| `Citation input handoff` | Inspect citations actually received by the answer step. |
| `Citation display check` | Trace displayed sources to their originals. |
| `Document-validity check` | Inspect source identity and applicable version separately. |

## Three common errors

First, viewing a substitute sample may become a changed order; inspect the suggested action and seek this round’s confirmed order. Second, the earlier glossy order may become current evidence; compare order identity, finish and transaction round instead of carrying it forward through the same store. Third, the regional agreement alone may confirm the matte request; inspect the actual order it references and its specification. These concern acceptance action, transaction identity and reference depth. Several relevant sources cannot collectively replace the missing current confirmation or establish real stock availability.

## How to verify the setup

Acceptance should ask what this round requests, what alternative is proposed and whether a current order is confirmed, inspecting actual references. Warehouse-advice-only input can describe the glossy sample proposal without announcing a changed order or refusal of matte supply. An added order needs finish, store and current-round identity checked, without inferring current inventory from an earlier purchase. Empty references require scope and transfer checks. The comparison creates no order or transfer and establishes no actual delivery to the store, which needs its own applicable operational evidence.
