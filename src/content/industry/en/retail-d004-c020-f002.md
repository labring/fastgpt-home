# Certificates of origin: document comparison with context limits

## What the documents look like

For document comparison in Certificates of origin, this page examines FastGPT context limits. Retain process statements, unverified origins and version notes in origin-document inputs. The examples are hypothetical.

## Constraints at the context limits step

A proposed origin-document packet states assembly at Mountain Bay Works with material information still to verify, marks source details pending in an application draft and labels an older page reference only. The current question asks which production facts are supported. Actual input needs assembly scope and missing material evidence instead of compressing them into complete production at that works. Historical material information for another item supplies no current stand evidence. No origin rule is introduced. Entering a context window does not elevate an unverified source statement into obtained proof or a completed production verification.

## Configuration and implementation checks

| Context-material check | Input and expression conditions | Acceptance action |
| --- | --- | --- |
| Process scope | Assembly statement | Do not expand to full production chain. |
| Later qualifier | Materials pending | Inspect actual retention. |
| Version status | Older page reference only | Do not replace current source. |
| Product reference | Other item in history | Compare empty-history input. |
| Output evidence level | Statement differs from proof | Retain attribution and pending state. |

## Three common errors

First, dropping materials to verify may make the chain appear complete; compare the original with actual request for process and missing conditions. Second, an old reference or another product’s historical material may override current text; inspect version, item and dialogue reference, including empty-history input. Third, output may announce a confirmed origin while losing attribution; inspect evidence level and reply length, preserving assembly as a statement and unresolved support. These concern scope delivery, source migration and conclusion strength. Larger budgets replace no original production evidence absent from the packet.

## How to verify the setup

Ask which process is claimed, what is missing and which page is reference only, tracing actual input and answer. When references are token-limited, inspect whether the later material qualifier remains rather than checking filenames alone. Confirm actual model capability, with reply allowance providing expression space only. Added sources still need product, party and version correspondence instead of borrowing another item from the same works. This exercise determines no origin eligibility, issues no certificate and submits no application. It establishes no actual verified production origin beyond the source statements supplied.
