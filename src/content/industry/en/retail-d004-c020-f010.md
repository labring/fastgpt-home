# Certificates of origin: document comparison with citation tracing

## What the documents look like

For document comparison in Certificates of origin, this page examines FastGPT citation tracing. Trace production statements, dispatch locations and certificate drafts by evidence type. The examples are hypothetical.

## Constraints at the citation tracing step

A proposed origin-document packet has a contributor stating that assembly occurred at Qinghe Works, a transport page naming South Harbour as dispatch point and a certificate draft marking production information for verification. An item sheet names a metal stand without production-stage evidence. A question about confirmed production origin and an issued certificate must separate contributor statement, logistics location and draft stage. Dispatch identifies an event location, not the entire production process. Restating the contributor establishes no obtained proof, and the answer must not invent origin rules or a certification conclusion.

## Configuration and implementation checks

| Transaction-source check | Material and action scope | Acceptance action |
| --- | --- | --- |
| Production statement | Assembly at Qinghe Works | Check speaker and support. |
| Dispatch location | South Harbour | Do not make it production proof. |
| Product correspondence | Current metal stand | Check added-evidence subject. |
| Draft stage | Production pending verification | Retain unresolved state. |
| Issuance outcome | Actual record absent | Do not infer from draft. |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Associated knowledge bases` | Knowledge bases associated with one search node must use the same embedding model. |
| `Citation output` | The output is an array; an empty array can continue. |
| `Citation input handoff` | Inspect citations actually received by the answer step. |
| `Citation display check` | Trace displayed sources to their originals. |
| `Document-validity check` | Inspect source identity and applicable version separately. |

## Three common errors

First, dispatch from South Harbour may become production there; compare the transport event with the production statement and seek production evidence instead of treating similar place names as proof. Second, an assembly statement may become verified production origin; identify its speaker and actual supporting material while preserving unverified stages. Fluent restatement adds no evidence. Third, a certificate draft may become an issued document; inspect stage and actual issuance record, since pending verification establishes no confirmation. These require location meaning, evidence type and document-state checks rather than one combined geographic conclusion.

## How to verify the setup

Acceptance should ask what transport action occurred, which production activity the contributor claims and what stage the draft records, tracing wording and source identity. Transport-only input leaves production support and certificate state unresolved; it does not prove a false statement or rejected application. Added production or issuance records need product, party and version correspondence, avoiding another batch’s evidence. This proposed-text exercise determines no origin eligibility and submits no application. Readable files or a complete draft also establish no obtained certificate without the actual applicable issuance record.
