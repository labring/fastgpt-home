# Product listing reviews: document comparison with context limits

## What the documents look like

For document comparison in Product listing reviews, this page examines FastGPT context limits. Inspect reference material versus final specifications, including clause delivery and historical title references. The examples are hypothetical.

## Constraints at the context limits step

A hypothetical product-copy clause gives a contributor’s material a reference purpose and requires public specifications to be checked against this variant’s final instructions. The attachment contains visual suggestions only; final instructions are absent. A historical title for a previous variant used quiet, without supporting performance material for the current product. Inspect whether contribution purpose, variant restriction and the instructions prerequisite reach the actual context. Visual ideas can support creative selection without supplying specifications. A contract mentioning specifications does not provide performance values or transfer an older variant’s adjective. Quiet is only historical draft wording in this exercise.

## Three common errors

- If the final-instructions prerequisite is clipped from a citation, compare the full clause, cited fragment and actual request to locate the missing specification basis.

- If a follow-up about this variant imports quiet from the previous title, hold current attachments fixed across empty and populated histories and inspect variant/version references.

- If a structured comparison labels visual suggestions as performance evidence, inspect document type and stated purpose. Successful parsing still requires support for every conclusion.

## How to verify the setup

Ask what the contributor supplied, which document governs specifications and whether the current variant’s instructions are available. Trace actual input. When instructions arrive, check variant and version before identifying newly supported items. Inspect model context capability, citation-token limits and reply length separately. One successful short request does not measure the full window. Preserve the distinction between creative reference and specification evidence without treating contract comparison as an actual performance check.
