# Marketplace advertising: document comparison with context limits

## What the documents look like

For document comparison in Marketplace advertising, this page examines FastGPT context limits. Trace creative confirmation, an unsettled budget and an execution notice without importing a past campaign’s result. The examples are hypothetical.

## Constraints at the context limits step

A hypothetical ad commission confirms the direction of this creative version while leaving execution scope for a notice and the budget for separate discussion. An attachment lists visual suggestions without an execution notice. History includes confirmed delivery for a previous campaign. Inspect the limited subject of confirmation: creative direction only. The pending notice and budget wording in the same clause must survive actual input delivery. Creative suggestions, budget agreement and execution outcomes need different sources. No real advertising amount or outcome data is supplied, and creative approval does not establish a running campaign.

## Configuration and implementation checks

| Ad-commission context | Hypothetical clause | Inspection action |
| --- | --- | --- |
| Confirmed subject | This creative direction | Add no complete execution arrangement. |
| Missing notice | Scope awaiting notice | Retain the latter part of the clause. |
| Budget state | Separate discussion required | Find no budget basis in visual suggestions. |
| Historical campaign | Earlier delivery discussion | Inspect current references and stage. |
| Comparison fields | Creative, budget and execution | Trace source identity after parsing. |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Model context` | Use the actual model’s accepted context scope. |
| `Reply length` | The reply limit differs from the context window. |
| `Knowledge-reference limit` | Knowledge citation limits are token-based. |
| `History-input check` | Compare empty-history and populated-history inputs. |
| `Structured-output handoff` | Validate parsing, then inspect support for field values. |

## Three common errors

- If the pending execution notice disappears from a citation, compare the full commission, citation and request to see whether creative confirmation became settled execution scope.

- If a follow-up imports delivery from the previous campaign, hold the current commission fixed across history conditions and inspect campaign identity and execution stage.

- If a parseable comparison uses visual suggestions as the budget basis, inspect source purpose and actual budget wording. A populated field is not itself supporting evidence.

## How to verify the setup

Ask which creative version was confirmed, whether execution scope and budget were supplied and whether a notice covers this campaign. Trace actual input sentence by sentence. When a notice or budget material arrives, check campaign and scope separately before repeating the questions, retaining remaining gaps. Inspect context capability against actual model configuration, separately from citation limits and reply length. Longer output does not establish complete delivery of the commission. A tidy comparison still needs source identity for creative, budget and execution fields.
