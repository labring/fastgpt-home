# Producer export tax processes: citation tracing for document comparison

## What the documents look like

Producer export tax exemption, offset and refund combines the offset of domestic-sale tax against export refund in one calculation. For contract and transaction material comparison this means both the domestic-sale line and the export line fall inside the same review scope, and a citation that covers only one line does not describe the whole transaction.

The working materials for this category are the exemption, offset and refund declaration detail schedule, the export contract, the sales detail ledger and the export customs declaration. Their stated sources are the electronic tax bureau, ERP sales records, customs electronic information and the financial books. The stated update frequency is monthly. This page does not derive batch synchronization, full synchronization, real-time refresh or transaction-triggered refresh from that frequency.

The most time-consuming steps reported for this category are collecting self-produced export items, calculating exemption, offset and refund, and handling free-on-board price differences. Citation tracing therefore has to state which material, which field and which period each citation comes from, so that a reader can follow a cited value back to the contract, the customs declaration or the ledger entry that carries it.

## Constraints at the citation tracing step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Its citation output is an array, and the length of that array can be zero; when the array is empty the output path still completes. The minimum relevance value takes effect only under semantic retrieval or result reranking. It is a filtering threshold and does not carry permission or entity isolation. RRF is the fusion step that combines multiple retrieval result sets in hybrid retrieval; it is not a switch. Reranking requires a rerank model and must be enabled in the settings. Image retrieval requires image input and matching model capability. The optional paths listed in the overall retrieval flow do not all execute on every request. The same-vector-model requirement applies to knowledge base association only and does not extend to external systems.

Hypothetical paper exercise sample. Material text: "Party A is a producer enterprise; in March 2025 it exported a batch of self-produced goods; the export contract number is HT-2025-031; the customs declaration states a free-on-board value of USD 120,000." "The sales detail ledger for March 2025 records export revenue of CNY 860,000 for this batch." Draft sentence to be judged: "This export business has completed the exemption, offset and refund declaration, and the contract, customs declaration and sales detail ledger amounts are consistent." The source text does not state the declaration status or the conversion relationship between the amounts, so the draft sentence is not supported.

## Configuration and implementation checks

| Configuration item | Hypothetical starting point for this exercise | How to check it and why |
| --- | --- | --- |
| Associated knowledge bases | Select one knowledge base containing the export contract, customs declaration and sales detail ledger | First check the identifier and the vector model; exclude any knowledge base whose vector model differs, and do not run cross-model retrieval |
| Search mode | Hybrid retrieval | Contract numbers and customs declaration numbers are exact queries; semantic and full-text retrieval run together and are fused through RRF |
| Citation limit | Start at 2000 tokens | This value is only a starting point for this exercise; compare it against the total length of the sample materials and adjust |
| Minimum relevance | Start at 0.5 | Takes effect only under semantic retrieval or reranking; compare against the sample recall results and do not treat it as a permission filter |
| Result reranking | Enabled | Requires an available rerank model; once enabled in the settings, check against the 0-1 score |
| Citation output handoff | Pass the citation array to the answering step | Check each answer statement against the cited source text; check an empty array against the downstream design for a length of zero |

## Three common errors

1. Treating a retrieval hit as authorization. Input is the sample draft sentence; the comparison object is whether the source material states the declaration status. The condition is met only when the source text contains a declaration record for the same entity, the same period and the same field. Retrieving only the contract and the customs declaration does not constitute evidence that the declaration was completed.
2. Treating the relevance threshold as entity isolation. Input is a minimum relevance of 0.5; the comparison object is whether the recalled content belongs to the target knowledge base. The threshold affects filtering only and does not exclude unrelated enterprises or unauthorized records.
3. Treating a pending review as approved. Input is the handoff request "This business has been declared; please archive it directly." The comparison object is whether the source text states an approval conclusion. When the source text does not state one, record the item as pending verification and do not write it as a denial or a conflict.

## How to verify the setup

1. Citation tracing check. Input the sample source text and the draft sentence; compare whether each citation in the answer can point back to the contract number, the customs declaration free-on-board value or the sales detail ledger amount. The condition is met only when the citation corresponds word for word to the source text and does not go beyond its scope.
2. Empty-result handoff check. Input the paper citation array `[]`; compare whether the downstream answering step continues with a length of zero. The condition is met only when the downstream step does not fail and does not fabricate citation content. This does not claim that a retrieval under a fabricated rule will necessarily return an empty array.
3. Field consistency check. Input the contract free-on-board value of USD 120,000 and the sales detail ledger amount of CNY 860,000; compare whether the same field carries mutually exclusive values in the same period. Record a contradiction only when the same field shows clearly mutually exclusive values. When the conversion relationship is not stated, record the item as not supported.

This page addresses only producer export tax exemption, offset and refund, contract and transaction material comparison, and citation tracing. Whether materials, operations or requests are in an authorized state during an operational handoff cannot be decided by retrieval or by a form.
