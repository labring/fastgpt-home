# Producer export tax processes: access controls for document comparison

## What the documents look like

Producer export tax processes combine domestic sales tax offsets with export refunds in a single calculation. This differs from foreign-trade enterprise export refunds, where the two lines are handled separately. For a producer, contract and transaction material comparison therefore has to reconcile an internal sales trail and an export trail at the same time. The working documents are the exemption, offset and refund declaration detail schedule, the export contract, the sales detail ledger, and the export customs declaration. Data arrives from the electronic tax bureau, ERP sales records, customs electronic information, and the financial books. The update rhythm is monthly, so any access configuration has to cover all materials gathered for the current month.

Comparison requires matching the contract counterparty, the operating unit on the customs declaration, the customer in the sales detail ledger, and the enterprise on the declaration detail schedule as one and the same subject, for the same period, on the same field. A mismatch on any one of these can produce a wrong tax amount or a reduced refund.

A hypothetical exercise sample illustrates the shape of the material. The export contract reads: "Party A: a producer export enterprise; Party B: an overseas buyer; goods: self-produced electromechanical products; trade term: FOB; contract date: 10 March 2025; amount: USD 120,000." The export customs declaration for the same month records an operating unit identical to Party A on the contract. A draft sentence awaiting review reads: "The export business under this contract has been gathered into the declaration detail schedule by the documentation post and can be handed over for refund calculation." The draft does not state the documentation post's operating time or authorization scope.

## Constraints at the access controls step

FastGPT's permission system separates member permissions from department and group permissions. Member permissions carry the highest priority; department and group permissions are combined as a union. Resource types include team, app, dataset, and collection. When knowledge base file-level permission is enabled, each file or folder is checked against a permission snapshot, and knowledge base permission always remains the threshold. Retrieval recall filters by files the current member can read, and this filtering applies only when authentication is performed by current member identity. Team administrators do not bypass file-level permission.

Document classification, labels, and retrieval relevance do not equal access authorization, and retrieval settings cannot substitute for permission configuration. A relevance score is not a category, entity, or permission filter. Retrieval is not authorization.

For the exercise sample, the relevant constraints are these. The knowledge base file-level permission switch governs whether collection-level snapshots exist at all. Collaborator configuration uses full-overwrite semantics, so the submitted list is the final result, and a list missing the current creator is rejected. Retrieval authentication by current member identity is the only mode that triggers file-level filtering. Member permission overrides an all-member group permission for the same person. Team administrator status does not bypass file-level permission, unlike team owner and system root.

## Three common errors

1. Treating retrieval relevance as a permission filter. A similarity setting does not perform entity or permission isolation. Retrieval recall filters by readable files only when authentication is by current member identity. If a relevance threshold replaces collaborator configuration, files beyond the member's authorization may still be recalled.

2. Treating a pending draft sentence as a completed operation. The draft sentence above does not state the documentation post's operating time or authorization scope. A pending review status does not show that operating permission is absent, and it does not show that gathering is complete. The documentation post's actual submission record and authorization scope have to be checked.

3. Treating a team administrator as able to bypass file-level permission. Documented team administrators do not bypass file-level permission; the knowledge base and files still authenticate by their own collaborator configuration. Testing file visibility with a team administrator account can produce results that differ from the expectation.

## How to verify the setup

1. Input the hypothetical contract text and the draft sentence above. Compare the contract Party A, the customs declaration operating unit, the sales detail ledger customer, and the declaration detail schedule enterprise for the same subject, the same period, and the same field. The observable condition is that all four share one subject and the draft sentence states the documentation post's operating time and authorization scope; only then is the handover condition met. If the draft sentence remains in pending review status, record it as unsupported.

2. Use two accounts, one with file read permission and one without, to search the same knowledge base for the contract material. Compare what each account can actually see. The observable condition is that the account without permission does not recall the file and the account with permission can view it. If both accounts can see it, check the file-level permission switch and the collaborator configuration.

3. Input an explicit paper input of `[]` to check the empty-result handling design. Compare how the downstream process handles an empty result. The observable condition is that the downstream process does not perform gathering or refund calculation on an empty result. If the downstream process still proceeds, record it as pending verification and check the authentication entry point.

Across all three checks, a pending request is not approval, an offered option is not execution, and an unsigned termination is not a completed termination. Missing evidence remains missing.
