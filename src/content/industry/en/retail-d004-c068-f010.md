# Group-buy presale orders: citation tracing for document comparison

## What the documents look like

Group-buy presale order collection takes orders first and organizes procurement and fulfillment afterward. Contract and transaction material comparison therefore has to place the presale product table, the order-collection result, the procurement plan and the cut-off notice inside one body of evidence. These materials update daily or per session, and for a single session the product name, cut-off time and quantity basis may appear in separate documents.

Citation tracing answers a narrow question: which original text supports a proposed sentence or a handover request, what state that material is in, and whether the material can carry the wording being proposed. The comparison does not settle identity certification, does not approve procurement, and does not execute refunds. It establishes what the source text says and what remains unstated.

## Constraints at the citation tracing step

Retrieval returns cited content as an array, and the length may be zero. An empty array does not mean the workflow has errored and terminated; the downstream path still runs. The citation cap is expressed in tokens, not in a top-k item count. The minimum relevance value is a filter threshold that applies only in semantic retrieval or when result reranking is used, and it is not a permission filter or an entity isolation control. Knowledge bases selected together must share the same vector model; cross-model association is not available, so the check is to confirm the knowledge base identifier and the vector model identifier, exclude non-matching bases, and record the observation. RRF is the fusion step for mixed retrieval results and is not described as a switch. Thinking budget is a model reasoning parameter and has no relationship to the citation token cap. Once retrieval output reaches the answer step, each answer sentence is compared against the cited original text.

Assumed paper exercise sample. Material A is the original text of a presale product table for one session: "Product: green grapes; Specification: 500 g per portion; Cut-off time for this session: 10 March 18:00; Presale quantity cap: 200 portions." Material B is the original text of a cut-off notice: "This session closes at 10 March 18:00; no new orders are accepted after the cut-off." The proposed sentence under review is: "The supply quantity of green grapes for this session is 200 portions, and the supply period runs to 10 March 18:00." The subject and object of the proposed sentence match Material A, but "supply quantity" and "presale quantity cap" are different fields, and "supply period" and "cut-off time" are different fields. Neither material states a supply quantity or a supply period, so the sentence is not supported.

## Configuration and implementation checks

| Configuration or check item | Purpose on this page | Assumed starting value for this exercise and reason |
| --- | --- | --- |
| Associated knowledge bases | Limit the retrieval scope | Include the knowledge base holding Material A and Material B; confirm the vector model identifiers match |
| Search mode | Determine the recall path | Mixed retrieval for this exercise, because identifier and time fields benefit from full-text hits |
| Citation cap | Control total cited tokens | Start at 2000 tokens so two short materials fit; compare against actual returned length |
| Minimum relevance | Filter low-relevance results | Start at 0.3; compare against returned relevance scores before deciding |
| Cited content output | Carry retrieval results forward | Output is an array and may have length zero; the downstream design accounts for an empty array |
| Material version check | Confirm the effective version | Compare the current cut-off notice against a historical version; which version is adopted requires effective-version review |

## Three common errors

1. Treating "presale quantity cap" as "supply quantity." The input is the Material A original text and the proposed sentence. The comparison is between field names and the object each value describes. Material A states only a presale quantity cap and does not state a supply quantity, so the sentence is marked unsupported.
2. Treating "cut-off time" as "supply period." The input is the Material B original text and the proposed sentence. The comparison is between field meanings. Cut-off time is the point at which orders stop; neither material states a supply period, so the sentence is marked pending verification.
3. Treating a retrieval hit as authorization or business execution. The input is the cited array returned by retrieval. The comparison is between the cited content and the authorization state of the handover request. Retrieval supplies source text only; procurement ordering and refunds must be carried out by the responsible business step, and a retrieval result does not constitute authorization.

## How to verify the setup

1. Input the Material A and Material B original texts together with the proposed sentence "The supply quantity of green grapes for this session is 200 portions, and the supply period runs to 10 March 18:00." Compare the fields in the proposed sentence against the fields stated in the originals. The item passes if the system marks supply quantity and supply period as unsupported or pending verification. It does not pass if the sentence is judged consistent with the originals.
2. Input a paper query with no matching content. Compare whether the retrieval output is an array of length zero and whether the downstream path continues on an empty array. The item does not pass if the downstream path treats the empty array as an error and terminates.
3. Input two knowledge bases whose vector model identifiers differ. Compare whether the association is rejected or flagged as not jointly associable, and record the actual observation. The item does not pass if the system permits the association and continues retrieval; record that observation without inferring a specific missed-recall outcome.

The current effective version of a cut-off notice is a separate fact from whether a proposed sentence is supported by the text. A pending review does not show that operating authority is absent, and a retrieval result is not an approval.
