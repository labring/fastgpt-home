# Cross-border product labels: context limits for document comparison

## What the documents look like

Cross-border product compliance and labelling comparison work centres on product test reports, English labels, MSDS documents and platform prohibited-item lists. These materials are prepared before listing and import, and their purpose is to carry product safety and label evidence. When they are wrong or incomplete, the consequences include platform delisting, customs seizure and consumer claims. Updates are irregular and each new product listing starts a fresh round of material preparation.

In the contract and transaction material comparison task, the objects being checked are field values belonging to the same product, the same destination country and the same period. The context and token stage determines how much source material text a single comparison request can load, how many earlier conversation turns are retained, and how many tokens of knowledge-base fragments the reference limit allows in. When source material is very long, the portion beyond the limit does not enter the model's view, and any comparison conclusion can only cover what was actually loaded.

## Constraints at the context limits step

The model context is checked against the actual model capability, and the reply limit is an output-side restriction; the two are not the same value. The knowledge-base reference limit is controlled by token, so when a single material passage is long, the referenced content may be truncated and the actually loaded content needs to be checked against a question sample. When the history turn count is too small, referents in multi-turn follow-up questions cannot be completed; when the turn count is too large, early irrelevant material occupies context.

Hypothetical paper exercise sample, not a real record:

Source material one: "Supplier A issued product test report number TR-0310 on 10 March 2025, covering the phthalate item for model X-100; the report conclusion states that this item meets the destination country limit; the report does not state a validity period."

Source material two: "An English label draft provided by the same Supplier A on 12 March 2025, marked with model X-100 and batch B-2025-03; the warning statement field is empty."

Draft sentence to be judged: "Supplier A's model X-100 has completed destination-country compliance testing, and the label warning statement has been filled in according to destination-country requirements."

Comparison scope: same Supplier A, same model X-100, March 2025. The phrase "has completed destination-country compliance testing" covers only the single phthalate item, and the report states no validity period. The phrase "the label warning statement has been filled in according to destination-country requirements" is inconsistent with the empty warning statement field in the label draft. This draft sentence is not supported, and the label part shows mutually exclusive values in the same field.

## Configuration and implementation checks

The following are implementation items for this paper check. The values are hypothetical trial starting points, not official defaults.

| Configuration item | Starting point for this exercise | Reason and comparison object |
| --- | --- | --- |
| AI model | Select a model that supports a long context | Compare with the length of the source materials to confirm that the full test report and label draft can be loaded in a single request |
| Memory turns | Hypothetically set to 2 turns | Compare with a single-turn comparison need; multi-turn follow-up requires retaining the previous turn's material object |
| Reply limit | Hypothetically set to a medium length | Compare with the length of the draft sentence, keeping enough room to state the basis and the handling action |
| Reference limit | Hypothetically set to a token amount covering both materials | Compare with the length of a single material passage and check whether the referenced content is truncated |
| Reply format | Keep default | No change is needed when downstream flow does not read a fixed structure |
| Minimum relevance | Hypothetically set to medium | Takes effect only in semantic retrieval or result reranking; compare with the recalled content |

Retrieval is recall, not authorisation. Forms collect values; business verification, approval and external synchronisation require separate downstream implementation. RRF is a fusion process for mixed results, not a switch. Thinking budget is a reasoning budget and is unrelated to the reference token limit.

## Three common errors

1. Treating the reply limit as the complete context window. When source material text exceeds the model context, the excess does not enter the comparison scope, and the conclusion covers only the loaded portion. Check: input the full source material text, compare the model context with the source length, and observe whether truncation prompts or missing content appear.
2. Treating the knowledge-base reference limit as able to hold all materials. When a single material passage is long, the referenced content is truncated and the comparison omits the cut portion. Check: input both materials, compare the reference limit with the material token amount, and observe whether the returned reference contains the label draft's warning statement field.
3. Treating a retrieval hit as completed authorisation or approval. Retrieval only returns relevant fragments and does not verify supplier authorisation status. Check: input the draft sentence, compare the retrieval result with the authorisation record, and observe whether an authorisation field exists; when it is missing, record the gap and mark it as pending verification.

## How to verify the setup

1. Input source material one and source material two, compare the draft sentence "has completed destination-country compliance testing" with the report's covered items, and observe whether the report states a validity period and all items. When the report covers only phthalates and states no validity period, this statement is not supported.
2. Input the label draft text, compare the draft sentence "the label warning statement has been filled in according to destination-country requirements" with the label draft's warning statement field, and observe whether the field is empty. When the field is empty, mutually exclusive values in the same field hold, and the draft sentence contradicts the source.
3. Input an explicit paper empty result `[]`, check the downstream handling design, and observe whether downstream treats it as an empty result. Do not claim that a fictional rule retrieval necessarily returns `[]`; libraries across different vector models cannot be associated together, so check the identifier first, exclude non-matching ones, and record the actual observation.
