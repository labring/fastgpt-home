# Cross-border resale returns: document comparison with tool calls

## What the documents look like

For document comparison in Cross-border resale returns, this page examines FastGPT tool calls. Returned-goods comparison distinguishes appearance work, component replacement and resale evidence. The examples are hypothetical.

## Constraints at the tool calls step

A proposed clause covers appearance work only, leaves component replacement to a separate agreement and lacks resale documentation. Describe the tool as comparing clauses with evidence, specifying required product identity, version and attachment scope. Check system-module parameters separately from plugin configuration, connect available tools and observe actual invocation. No inspection or completed sale is supplied in the material; tool output cannot create either fact.

## Configuration and implementation checks

## Three common errors

Appearance work enlarged into functional repair needs clause scope checked. An absent appendix reported as agreed replacement needs agreement text checked. Handling terms reported as completed resale need event evidence checked. These examine scope, an evidence gap and the difference between terms and events.

## How to verify the setup

Retain source excerpts, tool parameters and responses, checking whether each citation belongs to this item and version. Preserve missing-input status when required parameters are unavailable. Assess terminal output if calling stops. Inspection, transaction confirmation and sales operations require their business processes. This comparison identifies support and gaps without deciding product safety or granting sales authority.
