# Chain-store site selection: retrieval for document comparison

## What the documents look like

Site selection and store opening take place before a store begins trading, so the working materials centre on leasing and engineering delivery. A site evaluation sheet records trade-area footfall and store-type calculations. A letter of intent for lease carries the preliminary arrangement between the landlord and the chain headquarters. A decoration budget and an opening schedule constrain the delivery milestones. These materials are updated per store and at irregular intervals, and the same store leaves several versions behind at different stages. Contract and transaction material comparison requires placing a draft sentence or a handover request back inside the valid range of the corresponding material. The retrieval step recalls candidate source text; it does not perform authorization judgement.

## Constraints at the retrieval step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Knowledge bases built on different vector models cannot be associated together. The vector model identifier must be checked first, and any base that does not match is excluded. Search mode is compared across semantic retrieval, full-text retrieval and hybrid retrieval for the test question; no single mode is assumed to suit every material. The reference limit is measured in tokens. The minimum relevance value takes effect only under semantic retrieval or when result re-ranking is used. Problem optimization performs coreference resolution and question expansion, so the original question and the optimized question are compared to check whether the subject has been altered incorrectly. Reference content is output as an array and its length can be 0, meaning the downstream chain still runs when nothing is retrieved. Retrieval does not constitute authorization, and a pending review does not demonstrate the absence of operating permission.

Hypothetical paper exercise sample: a chain headquarters development officer intends to submit a lease letter-of-intent handover request. The source material reads: "Party A is a commercial management company; Party B is a chain headquarters. The letter of intent states that the leased subject is a three-storey street-facing unit, and the intent validity period runs to the end of the third quarter of the current year. The decoration budget table lists the upper limit of hard-decoration cost for this unit, and the opening schedule lists opening sixty days after delivery." The draft sentence to be judged reads: "Both parties have reached agreement on the lease terms, and the contract takes effect from the date of signing."

## Configuration and implementation checks

| Configuration item | Value or check item on this page | Basis and comparison method |
| --- | --- | --- |
| Associated knowledge bases | Associate only site-selection and store-opening material bases that use the same vector model | Check the vector model identifier and exclude bases on different models |
| Search mode | The hypothetical trial starting point for this exercise is hybrid retrieval | Compare recalled source text separately against semantic retrieval and full-text retrieval |
| Reference limit | The hypothetical trial starting point is a token amount covering the full text of the letter of intent and the budget table | Compare against a shorter value to see whether content is truncated |
| Minimum relevance | The hypothetical trial starting point is a middle value after labelling relevant samples | Compare against higher and lower values to observe the number of unrelated fragments |
| Problem optimization | Enabled for handover requests that contain coreference | Compare the original question and the optimized question for consistency of the subject |
| Result re-ranking | Enabled when candidates are numerous and a re-ranking model is available | Compare candidate order before and after re-ranking; this is not a mandatory switch |

## Three common errors

1. Treating a retrieval recall as an authorization confirmation. The draft sentence states that the contract takes effect from the date of signing, while the material only records an intent validity period. Recalling the letter of intent does not mean signing has been completed, and it does not mean the contract has taken effect.
2. Associating knowledge bases that use different vector models. The vector model identifier should be checked first and non-matching bases excluded; cross-model retrieval is not executed in order to compare missed recalls.
3. Treating a handover request under review as already approved. The request is in a pending review state, which does not demonstrate the absence of operating permission and does not constitute execution.

## How to verify the setup

1. Input the hypothetical sample source text and the draft sentence. Compare whether the "reached agreement" and "effective on signing" asserted in the draft sentence share the same subject, the same period and the same field as the "intent validity period" in the source text. The source text does not record signing or effectiveness, so the judgement is unsupported.
2. Input a handover request containing coreference. Compare whether the optimized question is consistent with the source-text subjects "a commercial management company" and "a chain headquarters". If the subject has been altered incorrectly, the condition is not met.
3. Input an explicit paper empty result []. Check whether the downstream design carries the empty-reference chain. Do not claim that a fictional rule retrieval necessarily returns [].
