# Shopify fulfillment: procurement with vector indexes

## What the documents look like

For procurement in Shopify fulfillment, this page examines FastGPT vector indexes. Trace replenishment set names, separate spares and earlier-product indexes independently. The examples are hypothetical.

## Constraints at the vector indexes step

A proposed Shopify replenishment source supplies a pump separately without a bottle, while an older set combines bottle and pump. A draft index says whole-bottle replenishment. The current question asks about buying the pump alone. The draft adds a bottle to a part-only source, and the older set concerns a different subject. Inspect the actual data block linked by each proposed index before testing pump-only and whole-bottle questions. Several indexes may describe one block, but another set cannot enlarge that block’s stated supply scope through borrowed content.

## Configuration and implementation checks

| Original-data/index check | Specific subject relationship | Acceptance action |
| --- | --- | --- |
| Part scope | Pump only, bottle excluded | Inspect source qualifier. |
| Index addition | Whole-bottle replenishment | Inspect added bottle meaning. |
| Earlier-set target | Historical source | Check linked block and version. |
| Reference adoption | Exclusion wording | Inspect actual delivery. |
| Same-question retest | Separate part and complete set | Compare returned originals. |

| `Original data and indexes` | One original data block can have multiple indexes. |

## Three common errors

First, a whole-bottle index may link to a pump-only original; compare index, block identity and bottle exclusion for added meaning. Second, an older set index may still point to historical text while being treated as current replenishment; inspect version and subject rather than merging through pump terminology. Third, a relevant index hit may yield an answer omitting the bottle exclusion; expand actual cited text and inspect its delivery. These require index meaning, version target and reference adoption checks. High scores or several hits establish no correct supply scope by themselves.

## How to verify the setup

Ask about the separate pump, earlier set composition and current source statement, retaining index text, linked block and actual returns. If an edited index still returns the old set, repair correspondence before repeating the same questions rather than declaring correction complete. Failure to return text establishes no refusal to sell. These are text fixtures without assumed image processing. Model or index changes should be compared through actual references, promising no retrieval effect or real inventory. Actual supply still needs applicable confirmation beyond the proposed source and index relationship tests.
