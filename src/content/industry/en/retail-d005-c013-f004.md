# Franchise store supervision: procurement with vector indexes

## What the documents look like

For procurement in Franchise store supervision, this page examines FastGPT vector indexes. Distinguish shelving corrections, store identity and sample fit when inspecting index wording. The examples are hypothetical.

## Constraints at the vector indexes step

A proposed franchise-store correction notice says: “Use narrower shelving in the main cabinet; review it at the next visit.” A supplier note describes a display sample whose store fit remains unconfirmed. These texts support different claims: a requested correction and the identity of a sample. Indexes for shelving requirements and sample fit must point to their respective originals. A supervisor’s request does not identify an appointed supplier, and a narrow shelf in a sample description does not establish compatibility with this store’s cabinet.

## Configuration and implementation checks

| Implementation check | Material in this test | Evidence action |
| --- | --- | --- |
| Requested correction | Narrow shelving and a later review | Do not turn it into purchase approval. |
| Sample identity | Store fit remains unconfirmed | Preserve the supplier qualification. |
| Store mapping | An entry may point to another store | Check source identity with the return. |
| Added evidence | Separate cabinet specs and purchase confirmation | Identify the question each supports. |
| Photograph check | Inspect content actually read | File presence does not verify dimensions. |

## Three common errors

- If an index states head-office purchase approval, inspect the correction notice for that approval. A request for narrower shelving does not establish a buying decision.

- If retrieval returns another store’s correction record, check store identity with the index target rather than the shelf name alone.

- If the unconfirmed-fit qualification disappears, compare the sample wording, index and answer to locate whether it was lost in indexing or after retrieval.

## How to verify the setup

When cabinet specifications or procurement confirmation become available, identify them as new sources rather than rewriting the old notice to imply it already contained them. Repeat separate questions about the correction, purchase approval and cabinet fit, recording the material cited for each. Verify the vector-model condition before jointly linking head-office and store collections. If additional indexes address one data item, inspect that every target still belongs to this store. For store photographs, inspect the actual image or text-processing output; a stored file alone does not show that shelf dimensions were read. Installation and inspection results require their own records.
