# Certificates of origin: procurement with vector indexes

## What the documents look like

For procurement in Certificates of origin, this page examines FastGPT vector indexes. Distinguish the fabric provider, dispatch location and origin statement when tracing index targets. The examples are hypothetical.

## Constraints at the vector indexes step

A proposed production attachment says Supplier A provides fabric and that its origin statement is attached separately. A packing record describes consolidation for dispatch at Warehouse B. Entries must distinguish provider, material and dispatch location rather than turning A’s address or B’s location into fabric origin. This ordinary-text test supplies no origin rule. Ask who provides the fabric, whether the separate statement is available and where dispatch occurs, inspecting the original addressed by each index and the question it can actually support.

## Configuration and implementation checks

| Implementation check | Material in this test | Evidence action |
| --- | --- | --- |
| Party roles | Fabric provider versus dispatch warehouse | Addresses do not become origin evidence. |
| Statement pointer | Fabric origin statement is separate | Retain the missing-attachment gap. |
| Material object | Fabric differs from a finished jacket | A product description is not its source statement. |
| Index mapping | Supply, material and transport have originals | Inspect each target identity. |
| Added evidence | Obtain the corresponding fabric statement | Retest citations without recasting old records. |

## Three common errors

- If dispatch at Warehouse B becomes fabric manufacture there, compare source, index and answer to locate the changed location role.

- If A’s finished-jacket description answers the fabric-source question, inspect its subject. Related names do not turn product copy into an obtained fabric-origin statement.

- If only packing material returns after the fabric statement is added, inspect the new data’s retrieval scope and index target. Missing retrieval differs from a location-role error after retrieval.

## How to verify the setup

After adding the fabric statement, check supplier and material identity, then inspect candidates and citations for the original question. The old packing record remains dispatch evidence rather than becoming a production record.

If the attachment is not retrieved, inspect scope and target. If it is retrieved but locations are mixed, compare original and answer. Verify matching models within one search node. This checks source location without determining origin.
