# Certificates of origin: procurement with citation tracing

## What the documents look like

For procurement in Certificates of origin, this page examines FastGPT citation tracing. Agency document preparation, production addresses and the current manufacturer need separate sources. The examples are hypothetical.

## Constraints at the citation tracing step

A proposed procurement packet associated with origin documentation contains an agency service list offering document preparation, a factory introduction listing a production address and an application awaiting confirmation of the current manufacturer. A question about buying that factory goods directly from the agency needs distinct source roles. The service list contains no product sale, the address does not link this batch to manufacture and the application remains open. Handling factory material cannot establish agency supply, and address wording cannot establish the origin of these goods.

## Configuration and implementation checks

| Procurement source check | Proposed material and scope | Evidence action |
| --- | --- | --- |
| Agency role | Document preparation | Check for actual product-sales scope. |
| Address content | Production address only | Do not establish current-batch manufacture. |
| Application state | Manufacturer unconfirmed | Seek current confirmation. |
| Goods linkage | Current batch and factory material | Inspect corresponding original wording. |
| Evidence boundary | Role location is not certificate outcome | Retain source scope. |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Associated knowledge bases` | Knowledge bases associated with one search node must use the same embedding model. |
| `Citation output` | The output is an array; an empty array can continue. |
| `Citation input handoff` | Inspect citations actually received by the answer step. |
| `Citation display check` | Trace displayed sources to their originals. |
| `Document-validity check` | Inspect source identity and applicable version separately. |

## Three common errors

First, document preparation may become product supply; inspect the agency actual service or sales scope. Second, a factory address may become manufacturing proof for this batch; inspect goods-linked source material. Third, pending manufacturer confirmation may become a settled identity; inspect current confirmation and applicability. These require role, goods relationship and process state respectively. Links or company names cannot assemble an unstated supply chain. These excerpts also do not determine certificate issuance or compliance outcomes, since their actual coverage concerns source roles and an unresolved purchase relationship.

## How to verify the setup

Acceptance should ask what the agency supplies as a service, what the address states and whether the manufacturer is confirmed. Inspect each actual citation, retaining document preparation and pending confirmation without inventing supply. If references contain only the factory introduction, inspect whether agency and application text reached the answer; empty references cannot establish absence of any relationship. Later confirmation must match goods and parties for this batch. One transaction cannot cover every product at the address, and locating a document cannot replace the goods correspondence required in its text.
