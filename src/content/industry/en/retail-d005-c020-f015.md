# Certificates of origin: retrieval for procurement

## What the documents look like

A certificate of origin serves import-country tariff treatment and customs clearance, and it does not necessarily sit under a letter of credit. That difference shapes what retrieval has to find for inventory procurement and supplier records: production records, purchase evidence and supplier declarations carry more weight than banking documents. The main data sources named in the brief are China International Trade Single Window, CCPIT systems, enterprise production records and customer customs-clearance requirements. Everyday documents are the certificate application, commercial invoice, packing list and production cost material.

For the procurement and supplier side, the fields that matter are material name, purchase batch, supplier name, originating content and price terms. The brief gives a per-order or batch update frequency. When records from different suppliers or different batches are retrieved together, the quoted content can splice across batches, and the origin-rule judgment loses an object it can be checked against. Retrieval at this step therefore has to keep batch and supplier identity visible in what it returns.

## Constraints at the retrieval step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Knowledge bases built on different vector models cannot be associated together. The operating step is to check the vector model identifier of each candidate library, exclude those that do not match, and record what was actually observed. Cross-model retrieval is not performed to compare missed recall.

Semantic retrieval, full-text retrieval and hybrid retrieval have different fit. Numbers, model designations and proper nouns suit full-text or hybrid retrieval; natural-language questions suit semantic or hybrid retrieval. The citation limit is measured in tokens. The minimum relevance value takes effect only under semantic retrieval or when result reranking is used. RRF is a fusion process for mixed results, not a switch that is turned on. Question optimization performs coreference resolution and question expansion and adds one model call. Quoted content is output as an array whose length can be 0, and the output path still runs in that case.

Hypothetical exercise sample: Supplier A issued a declaration on 5 March 2026 with the text "This batch of aluminium profiles was cast and extruded by this company on 18 February 2026 in Foshan, Guangdong Province; the aluminium ingots were purchased from Supplier B." The draft sentence to be assessed is "The origin of this batch of aluminium profiles is Foshan, Guangdong Province, and a certificate of origin can be applied for directly on the strength of Supplier A's declaration." The request is pending verification. Supplier A's declaration by itself does not constitute an application authorization.

## Three common errors

1. Treating the production address in Supplier A's declaration as a conclusion about origin qualification, without checking the origin rule and the purchase batch evidence. Check: input the declaration text and the draft sentence, compare whether the declaration states a conclusion under the origin rule, and observe whether the draft sentence goes beyond what the declaration supports.
2. Associating knowledge bases that use different vector models and then inferring missed recall or redundancy from that. Check: input the vector model identifier of each library, compare whether the identifiers match, and observe whether any non-matching library was excluded.
3. Treating a pending application request as an authorized action already carried out. Check: input the request status field and the authorization records, compare whether an approval record exists, and observe whether the request is still pending verification.

## How to verify the setup

1. Input the Supplier A declaration text and the draft sentence from the hypothetical sample. Compare the subject, production address and date stated in the declaration with the conclusion in the draft sentence. The condition is met when the draft sentence is observed to be supported by the declaration; an origin-rule conclusion that the declaration does not state is recorded as pending verification.
2. Input the vector model identifiers of the purchase batch library and the supplier declaration library from the hypothetical sample. Compare whether the two identifiers match, and observe whether any non-matching library was excluded. Cross-model retrieval is not performed.
3. Input a paper empty result array [] and compare how the downstream design handles empty quoted content, observing whether the output path runs. Do not claim that a fictional rule search necessarily returns [].

The knowledge base search node can associate one or more knowledge bases that use the same vector model; this is a documented association condition, not a statement that other systems must share a model. Semantic recall and relevance scores do not perform permission or entity isolation, and retrieval is not authorization. Whether a certificate application, an approval, a database write or an external synchronization actually occurs depends on downstream implementation that this page does not assume.
