# Brand member operations: procurement with vector indexes

## What the documents look like

For procurement in Brand member operations, this page examines FastGPT vector indexes. Inspect the different scopes of campaign procurement plans, sample-colour limits and historic gift rules. The examples are hypothetical.

## Constraints at the vector indexes step

A proposed membership campaign plans to offer a fabric bag to eligible participants, with its style awaiting procurement confirmation. A supplier sample note says the display colour is no delivery-colour commitment. No real member data, final style or supply colour is provided. Entries should distinguish the planned material, sample description and missing confirmation. A question about what this campaign has procured must preserve plan versus confirmation; a searchable display colour cannot become the supplied specification.

## Configuration and implementation checks

| Implementation check | Material in this test | Evidence action |
| --- | --- | --- |
| Plan identity | Proposed material; style unconfirmed | Do not imply completed buying. |
| Sample limit | Display colour is no delivery commitment | Preserve its source qualification. |
| Activity scope | General benefits differ from this campaign | Check period and target identity. |
| Added confirmation | Retain campaign procurement evidence | Retest style and colour separately. |
| Personal scope | No real member data is supplied | Infer no individual eligibility or receipt. |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Embedding model` | Knowledge bases associated with one search node must use the same embedding model. |
| `Original data and indexes` | One original data block can have multiple indexes. |
| `Index content` | Index wording should be complete and focused. |
| `Image indexes` | Where image retrieval is used, inspect descriptions or image vectors. |
| `Version and result check` | After a change, reuse questions to compare originals. |

## Three common errors

- If an index states that blue bags were procured, inspect the plan for both completed buying and blue, preserving the added wording beside the answer.

- If a historical benefit rule is used for this campaign, check activity, period and data identity rather than treating optional gifts as confirmed purchases.

- If the sample note is retrieved but its display-colour limit is absent from the final citation, compare both passages to prevent that colour becoming a delivery commitment.

## How to verify the setup

After obtaining campaign-specific procurement confirmation, add it as a source and trace citations for style and delivery-colour questions, retaining the sample note’s historical qualification. Check vector-model conditions before linking campaign and specification collections, inspecting whether each index still targets the current activity. Index counts and relevance do not establish procurement execution. If a display image actually participates, inspect its real text-extraction or image-processing output, supplying unread colour conditions separately. This acceptance test checks source scope. It buys no gifts, assigns no member benefits and establishes no campaign sending or publication.
