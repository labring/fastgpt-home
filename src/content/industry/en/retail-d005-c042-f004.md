# Product listing reviews: vector indexes for procurement

## What the documents look like

Platform product title and detail compliance handles advertising truthfulness and qualification display, and it does not handle parcel delivery. At the inventory procurement and supplier materials step, the documents include purchase contracts, supply confirmation letters, quality inspection reports, brand authorization letters, and advertising prohibited-word lists. These materials enter the knowledge base, and retrieval results are used to check parameters, qualifications, and authorization statements in titles and details.

Material updates occur weekly and with each new product launch. Retrieval configuration does not change because of update frequency. Vector model quality, data quality, and retriever precision jointly affect recall. This page addresses the vector model and index step only.

Three features of this material set shape the work. First, the same parameter or qualification may appear in a contract, a confirmation letter, and a detail page, so a retrieved passage and the drafted sentence must be compared field by field rather than treated as interchangeable. Second, supplier documents carry distinct states: a confirmation letter records what a supplier states it can supply, a signed contract records an agreement, and an authorization letter records permission to display a brand. Retrieval returns text, and none of these states is established by the fact that a passage was returned. Third, inspection reports and authorization letters have validity ranges, and a date attached to one field does not transfer to another field.

## Constraints at the vector indexes step

Knowledge bases associated for retrieval must use the same vector model. The actual model and its input types are checked before association. A single source data block can be linked to multiple indexes, and the index content and the source text are checked separately. Index content is built from complete and focused information, and retrieval coverage and index length are weighed against the sample at hand. Image retrieval also depends on whether image descriptions or image vectors were generated at ingestion time, and uploading an image at query time does not substitute for an index created at ingestion. After a model or index change, the same group of questions is used to compare cited source text, and vector scores alone do not support a promise about outcomes.

Hypothetical exercise sample, clearly labelled as invented for this page: the source text to be checked reads, "Supplier A issued a supply confirmation letter on 1 March 2025, confirming that Model A filter elements can be supplied in a quantity of 500 units, with the quotation valid until 30 April 2025." The draft sentence to be judged reads, "Model A filter elements are confirmed for supply of 500 units, with a supply term until 30 April 2025." The source text contains a subject, an object, a quantity, and a quotation validity date. It does not state a supply term. The draft sentence replaces the quotation validity date with a supply term, which is an unsupported statement.

## Configuration and implementation checks

| Configuration item | Setting or check on this page | Explanation |
| --- | --- | --- |
| Associated knowledge bases | Select only knowledge bases sharing the same vector model | Cross-model association is not available; check identifiers first and exclude those that do not match |
| Index field | Check the correspondence between indexes and source data blocks | One data block can map to multiple vectors; index and source text are checked separately |
| Index content | Hypothetical starting point for this exercise: a complete sentence with subject and date | Compared against an index containing only a product name, to examine recall coverage |
| Image index | Check whether an image description or image vector was generated at ingestion | An image uploaded at query time does not replace an ingestion-time index |
| Search mode | Use full-text or hybrid retrieval for identifier and model-number questions | Semantic retrieval relies on vector similarity, and precision is affected by the model |
| Result review | Compare cited source text using the same group of questions | ReRank scores apply according to settings and do not by themselves support a promise about outcomes |

RRF is a fusion step for combined retrieval results, and it is not written here as a switch to be turned on. Optional paths in the overall retrieval flow do not all execute on every request: image retrieval requires an image input and the corresponding model capability, and reranking requires a model and applies according to settings.

## Three common errors

1. Treating a quotation validity date as a supply term. The source text states only that the quotation is valid until 30 April 2025, while the draft sentence writes a supply term ending on that date. Comparing the same field confirms that the draft statement is unsupported.
2. Associating knowledge bases across vector models. After checking each library identifier, libraries whose models do not match are excluded. Cross-model retrieval is not run to compare missed recalls.
3. Treating a retrieval hit as authorization confirmation. Retrieval returning Supplier A's supply confirmation letter does not mean the supplier has been approved or that a contract has taken effect. Authorization status is checked separately.

## How to verify the setup

1. Enter the hypothetical source text and the draft sentence, and compare the quotation validity date field with the supply term field. The source text does not state a supply term, so the appearance of that statement in the draft sentence is judged unsupported, and the evidence gap is retained.
2. Enter the same group of product parameter questions and compare the vector model identifiers of each knowledge base. Association is possible only when the identifiers match; when they do not match, exclude that library and record the actual observation.
3. Enter one identifier-type query and observe whether the cited content contains the corresponding source data block. If the citation is empty, use the paper input `[]` to check the downstream design. No claim is made that a fabricated rule query necessarily returns an empty result.

A pending review does not demonstrate a lack of operating permission. Signing, reaching cooperation, and contract effectiveness are three distinct facts. A quotation validity date does not indicate a supply term. The material needed for a check must be inside the target retrieval scope to which access is held or inside a clearly identified manual input; when it is missing, record the gap.
