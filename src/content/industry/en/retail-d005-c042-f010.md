# Product listing reviews: citation tracing for procurement

## What the documents look like

Platform product title and detail compliance handles advertising truthfulness and qualification display. It does not handle parcel delivery. In the inventory procurement and supplier materials setting, the materials that require checking include the product title table, detail page assets, the advertising prohibited-terms list, and quality inspection reports. These materials draw on the platform rules center, advertising law compliance checklists, brand asset libraries, and inspection agency reports. The update frequency is weekly and at each new product launch. The citation tracing step addresses one question: whether a given title or detail description, at drafting time, can be traced to a currently valid supplier document or the original text of a quality inspection report. Checking extreme terms and comparing physical parameters belong to the daily work of this category; this page handles only the citation source and tracing step.

The knowledge base search node can associate one or more knowledge bases that share the same vector model. Cited content is output as an array, and the length may be zero; even when no content is found, the output path still runs. The minimum relevance score is a filter threshold and takes effect only in semantic retrieval or when result reranking is used; it does not perform permission or entity isolation. Retrieval itself does not constitute authorization. RRF is a mixed-result fusion process, not a standalone switch. Reranking requires model support and must be enabled by configuration, and image retrieval requires image input and model capability; these paths do not all execute on every request. Knowledge bases with different vector models cannot be associated together, so the vector model identifier must be checked first and non-matching bases excluded. The documented unit for the citation limit is tokens.

## Constraints at the citation tracing step

Hypothetical exercise sample: Supplier A provides to an e-commerce store operator B, on 1 March 2026, a quality inspection report numbered QC-2026-0317. The tested object is "stainless steel vacuum flask 500 ml", and the inspection conclusion is "conforms to GB 4806.9-2016". While drafting a product title, B writes the sentence: "This product has passed national authoritative quality inspection and is absolutely safe and non-toxic." Pending determination request: can this title sentence cite QC-2026-0317 as its source? In this sample, the report text does not contain the phrase "absolutely safe and non-toxic", and does not contain the words "national authoritative". The report validity period is not stated in the original text and is unsupported information.

The materials to be checked in this scenario are the product title table, detail page assets, the advertising prohibited-terms list, and quality inspection reports. The citation tracing step must establish whether a specific drafted sentence can be traced to the original text of a currently valid supplier document or inspection report. A retrieval result is not an authorization basis. The minimum relevance score filters low-relevance content and does not separate suppliers or records by entity. The citation limit is expressed in tokens, and its documented purpose is to bound how much content is cited per search.

## Configuration and implementation checks

| Configuration item | Hypothetical exercise starting value | How to check |
| --- | --- | --- |
| Associated knowledge bases | Select the supplier materials base and the inspection report base that share the same vector model identifier | Compare the vector model identifiers of the two bases; exclude any base whose identifier differs |
| Search mode | Use hybrid retrieval | Observe the citation array after semantic recall and full-text recall are fused through RRF |
| Citation limit | Set to 2000 tokens | Compare against the length of the report original text in this sample and confirm the original text fits within the cited range |
| Minimum relevance | Set to 0.5 | Compare against the 0-1 range of rerank scores and observe whether candidates below the value are filtered |
| Cited content output | Accept the citation array, length zero permitted | When the array is empty, check whether the downstream design can still receive it |
| Reply format | Keep default | Adjust only when a downstream process needs to read a fixed structure |

The citation limit of 2000 tokens is chosen because the inspection report original text in this sample is about 800 characters, and the original text should fit completely within the cited range; this value is a hypothetical exercise starting point, not an official default. The minimum relevance of 0.5 is chosen because the semantic distance between the drafted sentence and the report original text in this sample must be judged through the rerank score against the filter threshold; this value is a hypothetical exercise starting point.

## Three common errors

1. Treating a retrieval result as an authorization basis. The input is a retrieval result from the supplier materials base; the comparison object is the authorization status field; the observable result is that retrieval returned cited content while the authorization field is not stated. Retrieval does not produce an authorization effect.

2. Treating the minimum relevance score as a permission or entity filter. The input is the minimum relevance setting; the comparison object is the supplier entity in the returned results; the observable result is that a low relevance threshold did not exclude records of other suppliers. This parameter filters only low-relevance content.

3. Treating an unstated validity period as confirmed. The input is the inspection report original text; the comparison object is the validity period wording cited in the drafted sentence; the observable result is that the report original text contains no validity period field. Unstated information remains unsupported and is not a negation.

## How to verify the setup

1. Input the drafted sentence from the hypothetical sample, "This product has passed national authoritative quality inspection and is absolutely safe and non-toxic", and the original text of inspection report QC-2026-0317. Compare whether "national authoritative" and "absolutely safe and non-toxic" appear in the report original text. The observable result is that neither phrase appears in the report original text, and the citation is not supported by the original text.

2. Input the pending determination request from the hypothetical sample, "can this title sentence cite QC-2026-0317 as its source". Compare the tested object "stainless steel vacuum flask 500 ml" in the report original text with the product referred to by the title sentence. The observable result is that the tested object matches, but the report states no validity period, so the citation scope is limited to what the report original text states.

3. Input an explicit paper-form empty array [] as the retrieval output. Compare the downstream answer step's design for receiving an empty array. The observable result is whether the downstream design can still continue execution; this observation checks empty-result handling and does not assert that a hypothetical rule retrieval necessarily returns an empty array.
