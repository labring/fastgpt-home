# Multi-store management: citation tracing for procurement

## What the documents look like

Multi-store matrix operations for inventory procurement and supplier records revolve around four document types: store authorization lists, price control tables, cross-territory complaint forms, and monthly sales reports. Brand e-commerce leads, channel operations staff, and distributor e-commerce teams share these materials. The brief records update frequencies of daily and monthly. Cross-store authorization and price order are the defining concerns of this category; single-store traffic efficiency sits lower in priority. In inventory procurement and supplier records, citation tracing must answer which document, which version, and which authorization scope a purchase quantity or supplier quotation came from.

The four document types differ in what they can support. A store authorization list names authorized stores and an authorization period. A price control table names a store, a model, and price points. A complaint form names a complained-against store, a complaint matter, and a handling status. A monthly sales report aggregates figures over a period. A procurement draft that draws on these materials must match the same subject, the same period, and the same field before any claim of consistency or conflict can be made.

## Constraints at the citation tracing step

The knowledge base search node can associate one or more knowledge bases that share the same vector model. Knowledge bases with different vector models cannot be associated together. The citation output is an array whose length may be zero; an empty array still completes the output path. The minimum relevance value is a filtering threshold that takes effect only in semantic search or when result reranking is used, and it does not perform permission or entity isolation. Retrieval does not constitute authorization. A form collecting values does not mean business verification, approval, a database write, or external synchronization has occurred. After the store authorization list, price control table, cross-territory complaint form, and monthly sales report enter the knowledge base, the answering step must check each citation against its source text.

Hypothetical exercise sample: the source material is three sentences. Sentence one: "The store authorization list (March 2025 version) states: Store A, Store B, and Store C are authorized distributor stores in the East China region, with authorization valid until December 31, 2025." Sentence two: "The price control table (March 2025 version) states: Store A, for a certain model, has a suggested retail price of 199 yuan and a minimum transaction price of 179 yuan." Sentence three: "The cross-territory complaint form (number XH-2025-0312) states: the complained-against party is Store D, the complaint matter is low-price selling, and the handling status is pending verification." Draft sentence to be judged: "Store D is an authorized distributor store and can be supplied at the minimum transaction price of 179 yuan." Check points: the authorization list does not name Store D, so the draft sentence placing Store D within the authorized scope is unsupported; 179 yuan is Store A's minimum transaction price and does not constitute a supply authorization for Store D.

## Configuration and implementation checks

| Configuration item | Hypothetical starting point for this exercise | Reason for the choice and comparison method |
| --- | --- | --- |
| Associated knowledge bases | Inventory procurement knowledge base, supplier records knowledge base | Both must share the same vector model; verify the identifier first and exclude any that do not match |
| Search mode | Hybrid search | Number and model queries depend on full-text recall; compare hit results against pure semantic search |
| Minimum relevance | Hypothetical starting point 0.4 | Compare recalled item counts against 0.3 and 0.5, and observe whether unrelated fragments appear |
| Citation limit | Hypothetical starting point 3000 tokens | Compare answer coverage and truncation against 2000 and 4000 |
| Result reranking | Enabled for this exercise | A rerank model must already be available; compare candidate ordering against the disabled state |
| Reply format | Default | Keep default when downstream steps do not read a fixed structure |

These values are starting points for this paper exercise, not official defaults. The same-vector-model requirement for associated knowledge bases does not extend to business registration sites or other external systems.

## Three common errors

1. Treating a retrieval hit as authorization confirmation. The input is the cross-territory complaint form text, and the comparison object is the store authorization list. If the complaint form states only "pending verification" while the draft sentence still writes "authorization confirmed," the claim is unsupported.
2. Applying Store A's price to Store D. The input is the price control table text, and the comparison object is the supply price in the draft sentence. If the price control table does not name Store D or a corresponding price, that supply price lacks a source.
3. Treating an empty citation array as a workflow error. The input is the explicit paper input [], and the comparison object is the downstream handling design. If the downstream does not define an empty-array branch, that is a configuration omission; an empty retrieval result does not by itself mean the node terminated abnormally.

## How to verify the setup

1. Input the three hypothetical source sentences and the draft sentence, then compare the authorized subject in the draft sentence against the subjects named in the authorization list. If Store D does not appear in the list, the draft sentence's claim that Store D "is an authorized distributor store" is unsupported, and the evidence gap is recorded.
2. Input the price control table text and the 179 yuan figure in the draft sentence, then compare the store to which the price applies. If that price corresponds only to Store A, the supply price for Store D lacks a source. This is recorded as unsupported, not as a contradiction.
3. Input the paper empty array [] and compare whether the downstream node defines an empty-citation branch. If the downstream continues executing on the empty array, the handling design holds. If undefined behavior appears, record it as pending verification and do not infer a specific error cause.

All three checks use the hypothetical sample as input and were not actually executed. Retrieval does not guarantee a first-item hit or full recall, and whether an unrelated query returns empty must likewise be based on actual observation.
