# Multi-store management: retrieval for procurement

## What the documents look like

Materials in this category centre on store authorization lists, price control tables, cross-territory complaint forms and monthly sales reports. Sources include each platform's merchant back office, ERP channel pricing, brand anti-counterfeit systems and distributor reports. Updates arrive daily or monthly. The same supplier and the same product can carry different authorization status and different price wording across stores, so a single query often has to bind subject, store, period and field together, for example the authorized scope of one store in one month or the valid interval of one supplier quotation.

These documents do not verify authorization on their own. A retrieval hit means text was recalled. It does not mean authorization holds, an approval passed, a database write completed or any external system was synchronized. Forms collect values; business verification and downstream writes need their own stated implementation. A pending request is not an approval, an offered option is not execution, and an unsigned termination is not a completed termination.

## Constraints at the retrieval step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Bases built on different vector models cannot be associated together; check the identifier and exclude those that do not match rather than running a cross-model search to compare recall loss.

Search modes are semantic retrieval, full-text retrieval and hybrid retrieval. Hybrid retrieval merges multiple result paths through RRF, and RRF is a fusion step, not a switch that can be turned on. The citation limit is measured in tokens, not in a guessed item count. The minimum relevance value applies only under semantic retrieval or when result reranking is used, and it is a filter threshold rather than a final ranking rule. A relevance score is not a category, entity or permission filter, and it does not exclude unrelated businesses or unauthorized records. Retrieval is not authorization.

Question optimization performs coreference resolution and question expansion and adds an extra model call before retrieval. Citation content is output as an array whose length can be 0, and the downstream path still runs when nothing is retrieved. Image retrieval requires image input together with the corresponding model capability, and reranking requires an available model enabled by configuration. These optional paths are not executed on every request.

Hypothetical paper exercise sample. Source text for review: "Authorization list – Store A: supplier A, authorization period January 2024 to June 2024, authorized scope: small household appliances. Price control table – Store A: supplier A, small household appliances, minimum retail price 99, valid period March 2024." Draft sentence to be assessed: "Store A supplier A holds supply authorization for small household appliances in March 2024, and the quotation valid period covers the supply term." This draft mixes the authorization period, the price valid period and a supply term. The authorization period and the price valid period are different fields, and a quotation valid period does not indicate a supply term. The draft is assessed as pending verification.

The numeric starting points above are chosen only so the paper exercise has a comparable value; they are not official defaults. Each is compared against actual material of differing length or against labelled samples, and the observed outcome decides whether the setting is kept.

## Three common errors

1. Treating a retrieval hit as established authorization. Input: the draft sentence "Store A supplier A holds supply authorization for small household appliances in March 2024." Compare the authorization period field, January 2024 to June 2024. Observe whether the draft concludes that authorization is in force from the retrieval hit alone. The correct result is that authorization status still requires manual verification.
2. Mixing different fields. Input: the draft phrase "the quotation valid period covers the supply term." Compare the price control table valid period of March 2024 against the authorization period. Observe whether the quotation valid period is treated as a supply term. The correct result is that no supply term is stated in these fields.
3. Associating bases built on different vector models. Input: the vector model identifiers of the authorization list base and the price control table base. Compare whether the two identifiers match. Observe whether association still proceeds when they differ. The correct result is to exclude the mismatched base and record the exclusion.

## How to verify the setup

1. Input the hypothetical sample source text and the draft sentence above. Compare the three fields: authorization period, price valid period and supply term. Observe whether the draft sentence is assessed as pending verification. The condition is met when the assessment matches the field differences.
2. Input the vector model identifiers of the authorization list base and the price control table base. Compare whether the identifiers are the same. Observe whether the association step excludes the base when identifiers differ. The condition is met when the exclusion is recorded.
3. Input an empty citation array [] on paper. Compare whether the downstream design handles it as an empty result. Observe whether the path still runs. The condition is met when the downstream design explicitly accepts an empty result. This does not claim that any retrieval would return [].

All three checks are paper reviews. No retrieval was executed, and no business action, approval, refund or synchronization is claimed to have occurred. Where a field is not provided in the source material, it remains unknown rather than being treated as absent, conflicting or denied.
