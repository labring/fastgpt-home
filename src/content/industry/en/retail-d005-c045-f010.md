# Seller ratings management: citation tracing for procurement

## What the documents look like

Seller ratings work follows post-fulfilment consumer feedback and does not set promotional prices the way campaign registration does. The operating materials for this category include negative-review handling records, experience-score details, service diagnostic reports and rectification ledgers. Platform sources named in the brief are Douyin Shop experience scores, Tmall service indicators, JD after-sales reviews and the customer service system. The brief gives daily or weekly update frequency, and this page draws no batch-sync, full-sync, real-time or transaction-triggered mechanism from that.

The task on this page is inventory procurement and supplier records, examined through citation sources and tracing. Procurement and supplier materials carry their own text, version and authorization state, and the tracing step aligns those against retrieval output item by item. A supplier quotation, a signed supply contract and an authorization to act are separate facts, and the documents may record only some of them.

## Constraints at the citation tracing step

The knowledge base search node can select one or more knowledge bases that share the same vector model, and it outputs cited content as an array whose length can be zero. When the array is empty the output path still completes. That documented behavior means an empty citation array is not by itself a workflow failure.

Retrieval output passes to the answering stage, where each answer item is checked against the cited source text. A traceable sample is used to check what the source actually displays; a thinking process or a fluent answer does not substitute for source evidence. Freshness is checked by testing sources against a current version and a historical version, and whether a citation is adopted still depends on review of the effective version. Retrieval and similarity scores carry no authorization or entity-isolation duty. The minimum relevance value is a filter threshold, and it is not a permission filter.

Hypothetical paper exercise sample. The source material text reads: "Supplier A submitted an inventory procurement quotation on 1 March 2026; the quotation is valid until 31 March 2026; Supplier A has not yet signed a supply contract." The draft sentence to be judged reads: "Supplier A has signed a supply contract, and the supply term covers the second quarter of 2026." The comparison must hold the same subject, the same period and the same field. A quotation validity date does not state a supply term. An unsigned contract does not state that an operating permission is absent. A pending review does not demonstrate an authorization state.

These values are hypothetical starting points for this exercise and are not official defaults. RRF is a fusion step for mixed results, not a toggle. A thinking budget is a reasoning budget and is not used as a citation token limit.

## Three common errors

1. Treating a quotation validity date as a supply term. Input: the sample source text above and the draft sentence. Compare "valid until 31 March 2026" with "covers the second quarter." The two refer to different objects, and the draft sentence is not supported.
2. Treating an unsigned contract as an absent operating permission. Input: "has not yet signed a supply contract." Compare against the authorization field. That field is not stated in the source, so the matter is pending verification rather than negated.
3. Treating an empty citation array as a workflow error. Input: a paper output of []. Compare against the downstream handoff design. With an empty array the output path still completes, so this does not constitute an error.

## How to verify the setup

1. Input the sample source text and the draft sentence. Compare "has signed" in the draft against "has not yet signed" in the source. The same field carries mutually exclusive values, so the draft sentence fails.
2. Input the sample source text and the draft sentence. Compare "the supply term covers the second quarter" against "the quotation is valid until 31 March 2026." The source does not state a supply term, so the claim is unsupported and the evidence gap is recorded.
3. Input a paper citation output of []. Compare whether the answering node still executes. The path completes and the answer cites no unsupported content, so the handoff behaves as designed. Whether retrieval matches anything, and whether it returns empty, is not guaranteed.

The checks above are written as expected observations and do not claim that any test was run. A retrieval check records what is observed and includes the failing branch; it does not guarantee a first-hit match, full recall or an empty result for an unrelated query. Cross-model knowledge bases cannot be associated together; identifiers are checked first and non-matching bases are excluded, without running a cross-model retrieval to compare missed recall. Optional paths in the overall retrieval flow are not executed on every request: image retrieval requires image input and matching model capability, and reranking requires a reranking model and the setting to be enabled. Where the source does not state a system error code or an automatic business action, that remains unknown.
