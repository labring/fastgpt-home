# Marketplace category access: citation tracing for procurement

## What the documents look like

Category access review happens before listing or store onboarding. The objects under review are the operating entity's qualifications and the brand authorization chain. In inventory procurement and supplier material work, the documents that need citation include the business license, trademark registration certificate, brand authorization chain, and industry license. Suppliers provide these materials, and qualification status and authorization scope change with each onboarding batch. A citation must therefore be traceable to a specific document and version.

Common sources include platform merchant recruitment pages, the National Enterprise Credit Information Publicity System, trademark office data, and license systems. Citation tracing answers which document, which version, which entity, and which period a qualification conclusion comes from. A retrieved fragment is candidate content only. It does not constitute an authorization or an approval outcome.

This category differs from store review maintenance because category access occurs before listing or onboarding, and the core concern is entity qualification and the authorization chain. Errors lead to onboarding rejection, inability to publish in a category, or deposit occupation. The update frequency is irregular and tied to each onboarding instance. The three most time-consuming steps are collecting the authorization chain, matching the operating category, and supplementing licenses.

## Constraints at the citation tracing step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Its output is an array of cited content, and the length can be zero. When the citation array is empty, that output path still completes, so downstream design must handle the empty result. After retrieval output is passed to the answering step, qualification conclusions in the answer should be checked item by item against the cited source text.

Minimum relevance is a filter threshold and takes effect only in semantic retrieval or when result reranking is used. It does not perform permission or entity isolation. Hybrid retrieval merges multiple result paths through RRF, which is a retrieval process and does not correspond to a switch that can be turned on. Rerank requires a rerank model and must be enabled according to settings. Image retrieval requires image input and the corresponding model capability. These optional paths do not mean every request executes all of them.

### Hypothetical paper exercise sample

The following is paper exercise material and does not correspond to any real entity.

Source text one (supplier qualification statement, hypothetical date 2025-03-10): "This company holds a certain type of food business license, hypothetical license number SP-2025-0310-001, valid until 2026-03-09, with operating items covering prepackaged food sales."

Source text two (brand authorization chain statement, hypothetical date 2025-03-12): "The brand owner authorizes a certain trading company as a non-exclusive distributor, authorization period 2025-04-01 to 2025-12-31, authorization region East China, authorization category prepackaged food."

Proposed handover request for judgment: "Please confirm that this supplier can be used for East China prepackaged food category onboarding, and that both qualification and authorization are already in place."

Judgment points: the entity, license number, validity period, and operating items in source text one must match the entity and category proposed for onboarding. The authorization start date in source text two is 2025-04-01, a different period from the date of source text one, so whether the authorization has taken effect must be checked against the actual date. Neither source states a platform review conclusion, so the phrase "both already in place" in the proposed sentence lacks review evidence.

## Configuration and implementation checks

| Configuration item | Relevant description on this page | Check method |
| --- | --- | --- |
| Associated knowledge bases | Select one or more knowledge bases that use the same vector model | Check the vector model identifier of each selected base; bases with inconsistent identifiers are not associated together |
| Citation content output | Array format, length can be zero | Use a paper input of an empty array to check downstream handling design |
| Search mode | Semantic retrieval, full-text retrieval, and hybrid retrieval are selectable | When querying by qualification number or proper noun, check whether full-text or hybrid retrieval is used |
| Minimum relevance | Value from 0 to 1, effective only in semantic retrieval or result reranking | Compare against cited source text to confirm the needed source remains after filtering |
| Citation limit | Maximum tokens of content cited per search | Set a hypothetical starting point for this exercise and record the reason, then compare with the actual token length of retrieved content |
| Result reranking | Requires a rerank model and must be enabled according to settings | Check whether it is enabled and whether scores relate to source text relevance |

For the citation limit, the hypothetical starting point for this exercise is set to the token amount needed to cover the full text of both source materials. The reason for this choice is that the sample materials are short and the license number and validity period fields need to be preserved completely. The comparison object is the actual token length of the content returned by retrieval. This value is a starting point for this exercise and is not an official default.

## Three common errors

1. Treating retrieval results as an authorization conclusion. Error behavior: the citation array returns a qualification fragment, and the handover request is marked as ready for onboarding. Check: input hypothetical source text one, compare the license number, validity period, and operating items in the returned citation against the source text, and observe whether the answer contains a review conclusion not stated in the source.

2. Associating knowledge bases across different vector models. Error behavior: bases with different vector model identifiers are selected together in the association scope. Check: input the model identifier list of the selected bases, compare whether the identifiers are consistent, and observe whether any inconsistent identifier remains associated.

3. Using a relevance score in place of entity and period checks. Error behavior: a high minimum relevance score is taken to mean the material applies. Check: input hypothetical source text two, compare the authorization start date 2025-04-01 with the proposed onboarding date, and observe whether an authorization for a period not yet in effect is recorded as already in place.

## How to verify the setup

- Verification one: input the full text of hypothetical source text one and the proposed handover request for judgment, compare the entity, license number, validity period, and operating items in the cited content against the source text for word-for-word consistency, and observe whether the answer restates the source scope without adding a review conclusion. The condition is met when the citation can be traced to that material and no conclusion outside the source appears.

- Verification two: input the full text of hypothetical source text two, compare the authorization period 2025-04-01 to 2025-12-31 with the proposed onboarding date, and observe whether the system marks an authorization whose period does not cover the date as already in effect. The condition is met when a period mismatch is recorded as pending verification rather than judged as already in place.

- Verification three: input a paper empty array as the citation output, compare whether the downstream node design handles a length of zero, and observe whether the path continues and the empty result is recorded. The condition is met when downstream does not terminate with an error because of the empty array, and the empty result is not interpreted as a definite conclusion that qualification is missing.

All three verifications are paper checks and were not actually executed. Fields not stated in the materials remain unknown. A pending review status does not constitute approval. Signing, reaching cooperation, and contract effectiveness in an authorization chain are different facts. A quotation validity period does not indicate a supply period.
