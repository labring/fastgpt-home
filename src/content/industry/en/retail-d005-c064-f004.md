# Livestream sample inspections: vector indexes for procurement

## What the documents look like

Sample inspection for livestream selection happens before a broadcast. The decision at that stage is whether a product can be sold at all and whether it suits on-camera demonstration. The procurement and supplier materials step works from four document families: sample evaluation forms, quality inspection reports, supplier qualification certificates, and prohibited-item lists. Each family carries a different subject, object, state, and validity range. A qualification certificate addresses the legal standing of a business entity. An inspection report addresses a specific sample batch. A prohibited-item list constrains categories under platform rules. A sample evaluation form records a trial conclusion. Vector models and indexes are used here so these materials can be recalled correctly during retrieval. A retrieval hit is not an authorization decision.

## Constraints at the vector indexes step

Knowledge bases joined into one retrieval must share the same vector model. The actual model and its supported input types are checked first. One source data block can be linked to multiple indexes, and each index is checked against the source text separately. Index content is built from complete and focused information; retrieval coverage and index length are weighed against the sample at hand. Image retrieval also depends on whether an image description or image vector was generated at ingestion time, and the query side alone does not settle that question. After a model or index change, the same group of questions is used to compare cited source text. A vector score on its own does not support a claim about results.

Hypothetical exercise sample

Source text one to be checked: "The food business license of Supplier A records the entity as 'A Trading Co., Ltd.', the permitted scope includes prepackaged food sales, and the validity period runs to 31 March 2026."

Source text two to be checked: "Sample evaluation form number SP-0417 records: A Trading Co., Ltd. submitted 'instant oatmeal' as a sample; the trial conclusion is that the taste is acceptable, and a current-batch quality inspection report is recommended before broadcast."

Draft sentence to be assessed: "A Trading Co., Ltd. holds complete qualifications, and this sample can enter the broadcast schedule directly."

Handover request: "Please retrieve the qualification and inspection materials for A Trading Co., Ltd. and confirm whether it can go on air."

## Configuration and implementation checks

| Configuration item | Hypothetical starting point for this exercise | Reason and comparison method |
| --- | --- | --- |
| Joined knowledge bases | Only knowledge bases using the same vector model are joined | Check the vector model identifier of each base first, exclude those whose identifiers differ, and do not run retrieval across models |
| Search mode | Hybrid retrieval | Supplier names and sample numbers are exact queries, while semantic recall covers descriptive content; compare the cited source text for the same question under both modes |
| Citation cap | Set to a number of tokens as the hypothetical starting point for this exercise | Compare against the completeness of the actual cited content under the same question group; a fixed top k is not used |
| Minimum relevance | Set to a middle value as the hypothetical starting point for this exercise | Compare cited source text before and after raising or lowering the value; this value takes effect only under semantic retrieval or result reranking |
| Index content | Each source data block has its index and source text checked separately | Check whether the index covers subject, object, state, and validity period, and compare each item against the source text |
| Image index | Only when an image description or image vector was generated at ingestion | Check the ingestion record; uploading an image on the query side does not substitute for an ingestion index |

## Three common errors

1. Treating a retrieval result as an authorization conclusion. The input is a retrieval request; the comparison object is the permitted scope and validity period in the source text; the observable result is whether retrieval returns the corresponding source text. Qualification validity and sample approval remain subject to manual verification. A retrieved qualification certificate and sample evaluation form do not mean the qualification is valid or that the sample has been approved for broadcast.

2. Joining knowledge bases that use different vector models. The input is a set of knowledge base identifiers; the comparison is whether the vector model identifiers match; the observable result is that bases with non-matching identifiers are excluded and cross-model retrieval is not performed.

3. Treating the phrase "complete qualifications" in the draft sentence as a verified fact. The input is the draft sentence and the source text; the comparison checks whether subject, permitted scope, and validity period correspond item by item; the observable result is that parts not stated in the source text are marked as unsupported, without being rewritten as a denial or a conflict.

## How to verify the setup

1. Input source text one and the handover request, then compare whether the cited source text returned by retrieval contains the entity name, the permitted scope, and the validity period to 31 March 2026. The condition is met when the cited source text matches the source text and missing fields are recorded as unknown.

2. Input the draft sentence to be assessed, then compare "complete qualifications" against the permitted scope in source text one for the same subject, the same period, and the same field. The condition is met when the source text does not state the judgment "complete" and that wording is marked as unsupported.

3. Input source text two to be checked, then compare the trial conclusion in the sample evaluation form against the draft sentence's "can enter the broadcast schedule directly." The condition is met when the source text records only the recommendation to add a current-batch quality inspection report, the broadcast scheduling conclusion is unsupported, and the item stays in a pending-verification state.
