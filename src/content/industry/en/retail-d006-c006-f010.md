# General export declarations: staff training with citation tracing

## What the documents look like

For staff training in General export declarations, this page examines FastGPT citation tracing. Check placeholder text, item explanations and source documents by their classroom roles. The examples are hypothetical.

## Constraints at the citation tracing step

A proposed export-document class contains a blank form prompting an item name, an example labelled desktop stand, example text and an instruction to verify actual names against original documents. The learner writes stand accessories set. The example illustrates placement, the instruction requires originals and the submission adds accessories and set composition. No current item document is supplied. Preserve placeholder and example labels instead of treating a practice entry as real exported goods or a sample name as the prescribed description for every similar stand in the exercise.

## Configuration and implementation checks

| Training-source check | Teaching identity and evidence scope | Acceptance action |
| --- | --- | --- |
| Placeholder identity | Entry prompt | Do not make it a completed record. |
| Example name | Desktop stand | Inspect example label. |
| Added composition | Accessories and set | Seek product support. |
| Source gap | Current original document | Keep pending. |
| Format and fact | Correct placement supplies no facts | Trace every statement. |

## Three common errors

First, the example name may become current-document wording; inspect the example label and actual source instead of supplying product facts from teaching material. Second, accessories set may become equivalent to desktop stand; check composition evidence for each addition, since similar names establish no identical subject. Third, a blank-form prompt may become a completed current record; inspect the submitted entry and corresponding original. A prompt records no completed entry. These concern source identity, added meaning and form contents, keeping correct formatting separate from factual support for the item description.

## How to verify the setup

Ask what the example demonstrates, what the learner added and which source is still missing, tracing actual references. Teaching material alone leaves the original item document unresolved; provide no declaration conclusion or statement of passed review. A further proposed product page may support another exercise if clearly labelled hypothetical, without presenting it as customer evidence. Empty references require scope and transfer investigation. This page submits no form and determines no customs classification, eligibility or release state. Actual documents and outcomes need their own independent applicable verification beyond the classroom packet.
