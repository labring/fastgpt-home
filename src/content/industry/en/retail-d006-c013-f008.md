# Franchise store supervision: staff training with workflow routing

## What the documents look like

For staff training in Franchise store supervision, this page examines FastGPT workflow routing. Compare the material received with the sources used in the answer. The examples are hypothetical.

## Constraints at the workflow routing step

Franchise-supervision training can collect the learner’s question, display-standard passage and store-visit wording. Proposed text supplies the standard and finding without follow-up verification, teaching the difference between required practice and completed practice. The receiving step needs source identity and applicable store. A training explanation is not a site inspection, and a standard establishes neither learner competence nor accepted rectification. Treat a display photograph as an observation of the pictured arrangement only; it does not establish that the learner can reproduce it, which requires actual assessment evidence.

## Configuration and implementation checks

| Training check | Proposed input | Observable evidence |
| --- | --- | --- |
| Standard and site | Requirement separate from visit finding | Explanation is not site verification |

| Follow-up destination | Only an earlier visit heading received | Inspect selection and received values |
| Added source | This store’s follow-up passage | Answer actually cites the addition |
| Formal recognition | Separate assessment or rectification closure | Workflow is not a passing result |

## Three common errors

Test choices to read the standard or obtain this store’s follow-up, inspecting each connected yes branch. If the latter still receives only an earlier visit heading, inspect selection and received values, retaining the verification gap. A photograph from another store also needs caption and subject checks before removal. Continued execution does not establish a verified on-site condition. If viewing a display image becomes the learner’s ability to reproduce it, inspect the observed arrangement and that learner’s actual practical assessment separately. A picture supplies no competence evidence, and completed reading is not passed operation.

## How to verify the setup

Trace question, submitted passage, branch input and training answer. Repeat after this store’s follow-up arrives and inspect actual use of the addition. Interaction state follows the triggered node while awaiting the person, without an invented global completion switch. Assessment recognition, rectification closure and supervision writes need downstream or external arrangements; reaching the end establishes neither a qualified learner nor corrected store.
