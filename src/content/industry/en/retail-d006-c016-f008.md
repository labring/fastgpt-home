# Franchisee onboarding: staff training with workflow routing

## What the documents look like

For staff training in Franchisee onboarding, this page examines FastGPT workflow routing. Compare the material received with the sources used in the answer. The examples are hypothetical.

## Constraints at the workflow routing step

A franchise-opening training workflow can collect the question, applicable SOP and this store’s checklist items. Proposed input contains attendance and checklist wording without assessment content or site verification. Preserve those gaps downstream instead of turning attendance into mastery or a checklist’s existence into readiness. Pass the handbook version with its source rather than deriving all applicable requirements from a store name.

## Configuration and implementation checks

| Training check | Proposed input | Observable evidence |
| --- | --- | --- |
| Attendance boundary | Attendance and checklist supplied | No competence or opening approval claim |
| Handbook version | Earlier SOP treated as applicable | Trace origin and applicability |
| Assessment destination | Source request passes attendance heading | Inspect actual connection and values |
| Supplement retest | This store’s assessment or site passage | Explanation actually uses new evidence |
| Formal approval | Recognition and opening assessed separately | Workflow is not a passing credential |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Form input node` | Submitted form values pass to subsequent steps. |
| `User-selection node` | Execution follows the connected selected branch. |
| `Interaction-state check` | Inspect waiting and post-submission states. |
| `Output handoff check` | Compare values passed between steps. |
| `External-operation responsibility` | External business operations require an implementation. |

## Three common errors

Test choices to obtain assessment material or read the SOP, inspecting each connected yes branch. If requesting assessment passes only an attendance heading, inspect received values and connections; attendance is not competence evidence. An earlier handbook treated as current also needs identity and passage checks followed by an applicability source. Choosing to continue learning does not establish headquarters approval of this opening. If an opening checklist names checks to perform but the answer calls them complete, inspect the passage status and this store’s actual verification records. The checklist’s existence supplies no completion outcome or passed opening from an ended interaction.

## How to verify the setup

Trace question, entered values, source version, branch result and answer. Repeat after this store’s assessment or site material arrives and inspect actual use of the addition. Interaction-state recording is node behavior, not a global completion switch. Assessment recognition, opening approval and profile writes require independent downstream or external authority and receipts. Reaching the end establishes neither a passed learner nor satisfied opening conditions.
