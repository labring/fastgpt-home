# On-demand retail fulfillment: staff training with interactive forms

## What the documents look like

For staff training in On-demand retail fulfillment, this page examines FastGPT interactive forms. Instant-retail training preserves roles across order acceptance, picking and courier handoff. The examples are hypothetical.

## Constraints at the interactive forms step

Suppose a practice ticket shows store acceptance, lists picking as an open task and includes a courier name from an older order. Collect practice order and store identity, then choose picking review or handoff evidence. Test missing order identity and completed input, inspecting which ticket reaches downstream nodes. The node records interaction and transfers entered information without a built-in order database or authority granted through a name field.

## Configuration and implementation checks

| Instant-retail training | Paper state | Check |
| --- | --- | --- |
| Store acceptance | Not picked | Picking record |
| Courier name | Older order | Order correspondence |
| Class submission | Interaction complete | Not delivered |
| Required order | Missing/completed tests | Actual input |
| Business execution | Separate order/delivery systems | Authority and evidence |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Form input` | Collect input and pass values after submission. |
| `Required-information check` | Design required business inputs and missing-input handling. |
| `User selection` | The selected option maps to a connected branch. |
| `Interaction state` | Inspect waiting and completed interaction separately. |
| `Downstream responsibility` | Verify validation, approval and write results separately. |

## Three common errors

Acceptance reported as completed picking needs picking evidence checked. An older courier applied here needs order correspondence checked. Classroom submission reported as delivered needs receiving evidence checked. These concern stage, identity and a physical event; no delivery-time measure or real fulfillment outcome is supplied.

## How to verify the setup

Have the trainee trace missing picking and handoff evidence from the acceptance wording, inspecting each selected branch connection. Added courier correspondence corrects identity alone while delivery still needs independent support. Order operations, stock deduction and delivery writes require business interfaces and real authority. The training chain practices comparison without triggering these actions or claiming they occurred. Separate store-worker and courier roles, locating the picking task independently from receiving evidence for the training review.
