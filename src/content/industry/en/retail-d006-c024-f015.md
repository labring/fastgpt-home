# Brand concession operations: retrieval for staff training

## What the documents look like

A brand concession inside a shopping mall accepts the mall's unified cashiering and commission-based settlement. Records therefore come from several systems at once: the mall POS, the brand ERP, the finance system, and mall membership campaigns. Daily and monthly materials coexist, and the four document families that matter for this page are the joint-operation commission contract, the mall campaign letter, the sales receipt, and the monthly settlement statement.

Store service and internal training use retrieval to answer a narrow question: after a search, do these four materials actually support a judgment about a shift, an authorization, or a status. The materials describe subjects, objects, validity scopes, and states. A campaign letter can state a plan while an approval is still pending. A settlement statement can show a period while the commission rate comes from the contract. Retrieval returns text; it does not decide whether a person may act.

Update frequency does not change retrieval parameters. It changes when a human re-checks a figure against the source document.

## Constraints at the retrieval step

The knowledge base search node can link one or more knowledge bases that use the same vector model. Its reference output is an array, and that array can have a length of zero, so the downstream path still runs when nothing is found.

The minimum relevance value is a filter threshold that takes effect only in semantic retrieval or when result reranking is used. It is not a permission filter and not an entity isolation mechanism. A relevance score is not a category, entity, or permission filter, and raising it does not exclude other concessions' records or unauthorized materials. Retrieval is not authorization.

Hybrid retrieval merges multiple result paths through RRF. RRF is a fusion step inside hybrid retrieval, not a switch that can be turned on by itself. Reranking requires a model and runs according to its settings. Image retrieval requires image input and matching model capability, and is a processing path added to the existing search chain rather than a separate capability. The overall flow lists optional paths; not every request executes all of them.

Forms collect values. Business verification, approval, database writes, and external synchronization each need their own downstream implementation. A pending request is not an approval, and an offered option is not an execution.

Hypothetical drill sample, labelled as invented for this page: a brand concession store manager submits a shift-handover request on 12 March 2026, intending to place the sentence "the campaign authorization is already in effect and gift commitments may be made externally" into training material, based on a mall campaign letter dated 11 March 2026 stating that the full-reduction campaign ends 15 March 2026. Two sentences from the letter are available for comparison. The first reads: "This letter is a notification of the campaign plan; authorization is subject to the brand side's written approval." The second reads: "Gift distribution requires confirmation by both mall operations and the brand side." The authorization state of this request is pending review. The letter is a plan notification. No approval is recorded.

## Configuration and implementation checks

| Configuration or check item | Hypothetical starting point for this trial | Reason and comparison object |
| --- | --- | --- |
| Linked knowledge base | Link only the one library containing the campaign letter and training material, with a matching vector model identifier | Compare against a library whose vector model identifier differs; exclude the mismatched one |
| Search mode | Run semantic retrieval first, then hybrid retrieval on the same question | Compare the retrieved content the two modes return for an authorization-type question |
| Reference limit | Set to 2000 tokens for this trial | Compare with 800 tokens and observe whether the letter's clauses are truncated |
| Minimum relevance | Set to 0.3 for this trial | Compare with 0.5 and observe whether plan-notification passages are still retrieved |
| Question optimization | Enabled for this trial | Compare with the disabled state and check whether "this campaign" is rewritten to the letter's subject |
| Result reranking | Not enabled for this trial | Compare with the enabled state and judge whether candidates suffice for clause checking |

## Three common errors

1. Treating minimum relevance as a permission or entity filter, on the assumption that raising it removes records of unauthorized concessions. The check is to compare the reference content returned for the same question at two threshold values and observe whether other concessions' materials still appear.
2. Treating the campaign letter's plan as an authorization already in effect. The check is to compare the draft sentence "authorization is already in effect" with the source wording "authorization is subject to the brand side's written approval" and observe whether an approval field exists.
3. Describing RRF as a switch that can be turned on. The check is to compare the reference arrays from hybrid retrieval and from semantic retrieval alone, and observe whether the fused result draws on more than one retrieval path.

## How to verify the setup

1. Input the drill sample's source sentences and the draft sentence. Compare "authorization is already in effect" in the draft against "authorization is subject to the brand side's written approval" in the letter. The condition is met when the reference content contains that source sentence and the draft sentence is marked as unsupported.
2. Input the question "who confirms gift distribution" and compare the retrieved passage with the source sentence "requires confirmation by both mall operations and the brand side." The condition is met when the reference content contains that sentence and no single-party confirmation conclusion is produced.
3. Input an explicit paper-level empty result, written as [], together with one downstream design note, and compare whether the downstream continues on the empty array. The condition is met when the downstream path runs and no claim is made that a fabricated rule necessarily returns an empty array.

Across all three checks, the judgment must concern the same subject, the same period, and the same field. Only explicitly mutually exclusive values in one field count as a contradiction. A field that is not recorded, or evidence that covers only a related stage, counts as unsupported or pending verification. Pending review does not demonstrate the absence of an operating permission. Signing, reaching cooperation, and contract effectiveness are three separate facts. Materials needed for a check must sit inside an accessible target retrieval scope or an explicit manual input; when they are missing, record the gap.
