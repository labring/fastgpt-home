# Supermarket supplier accounts: citation tracing for staff training

## What the documents look like

Supermarket supplier entry settlement is built mainly on purchase-and-sale or consignment payables. A store may have no resident operating staff, which distinguishes this work from a large-format joint-counter arrangement. Settlement evidence sits across ERP purchasing, the supplier portal, POS sales and the finance system. Everyday documents include the purchase contract, the delivery acceptance note, the rebate agreement and the reconciliation statement.

Store service and internal training must explain contract terms, accepted quantities and rebate deduction points so that any statement can be traced back to specific document wording. Materials update weekly or monthly; this page does not describe any real-time synchronization mechanism.

## Constraints at the citation tracing step

The knowledge base search node can select one or more knowledge bases that share the same vector model as the retrieval scope. Its output is a citation array, and the length may be zero; an empty array still lets the output path run through. Whether retrieval results are passed to the answering step, and whether an answer corresponds item by item to cited source wording, must be checked separately. The minimum relevance value is a filtering threshold and does not perform permission or entity isolation; retrieval itself is not authorization. Knowledge bases with different vector models cannot be associated together, so the vector model identifier should be checked first, non-matching bases excluded, and the actual observation recorded, without running cross-model retrieval to compare missed recalls. Image retrieval requires image input and the corresponding model capability, and reranking requires a model and must be enabled by configuration. Optional paths shown in the overall document flow diagram do not mean every request executes all of them.

Hypothetical paper exercise sample: a supplier signs a purchase contract with a supermarket, and the contract number and signing date are stated in the text. A delivery acceptance note records the accepted quantity for the current period. A rebate agreement sets the deduction percentage. A reconciliation statement states the amount payable for the current period. The draft sentence to be judged is: "The supplier's rebate for this period has been deducted under the agreement, and the reconciled amount is correct." This sentence involves the correspondence between subject, period and field, and can only be judged after comparing each item against the materials above.

## Configuration and implementation checks

| Configuration or check item | Purpose on this page | Correspondence with the sample |
| --- | --- | --- |
| Associated knowledge bases | Define the retrieval scope and check selected bases against the material version | The bases holding the contract, acceptance note, rebate agreement and reconciliation statement |
| Same vector model requirement | Decide whether multiple bases can be associated together | Check the identifier first and exclude bases whose model differs |
| Citation content output | Carry the citation array, whose length may be zero | When the array is empty, the downstream design still has to handle it |
| Citation input handoff | Check that the answer corresponds item by item to cited source wording | The draft sentence has to point to specific source wording |
| Citation display check | Use a traceable sample to check the display of source wording | A fluent answer does not replace source evidence |
| Material timeliness check | Test sources with the current version and a historical version | Whether a citation is adopted still depends on review against the effective version |

This page does not specify a citation token limit, a minimum relevance value or a thinking budget. The thinking budget belongs to model thinking configuration and is not the same field as the citation token limit. If a later trial needs a starting value, it should be clearly labelled as a hypothetical starting point for that trial, with the reason for choosing it and the value it is compared against.

## Three common errors

1. Treating a retrieval hit as business authorization. A retrieval returning a citation array only means content was recalled; it does not mean the payable has been checked, the rebate deducted or the reconciliation confirmed. For the check, input the sample materials and the draft sentence, compare whether the draft sentence corresponds item by item to the source wording, and observe whether any conclusion appears that the source wording does not state.
2. Forcing knowledge bases with different vector models into one association. The documentation states that joint association requires the same vector model. For the check, input the vector model identifiers of the candidate bases, compare whether the identifiers are consistent, and observe whether non-matching bases were excluded and the actual observation recorded.
3. Treating an empty citation array as a workflow error. The documentation states that the output length may be 0 and that the path still runs through. For the check, input a paper empty array, compare whether the downstream design handles it as an empty result, and observe whether an undefined error assertion appears.

## How to verify the setup

1. Input the contract, acceptance note, rebate agreement and reconciliation statement wording from the hypothetical sample, together with the draft sentence "The supplier's rebate for this period has been deducted under the agreement, and the reconciled amount is correct." Compare whether the subject, period and field of the draft sentence match the source wording, and observe whether any authorization or effectiveness conclusion appears that the source wording does not state. The condition is met when the draft sentence can point item by item to the source wording, and any part not supported is marked as pending verification.
2. Input the vector model identifiers of the candidate knowledge bases. Compare whether the identifiers are consistent, and observe whether non-matching bases were excluded. The condition is met when jointly associated bases have the same vector model identifier and no cross-model retrieval was run to compare missed recalls.
3. Input a paper empty array as the citation output. Compare whether the downstream design handles it as an empty result, and observe whether an undefined error or automatic business action appears. The condition is met when the downstream runs through with the empty array and no assertion is made that retrieval will always return an empty array.
