# Export tax rebate filings: citation tracing for staff training

## What the documents look like

Export tax rebate filing happens after goods leave the country, when tax vouchers are matched against export records. The main data sources are the electronic tax bureau, the export rebate filing system, customs electronic messages and the accounting ledger. The documents handled day to day are the export tax exemption and rebate filing form, the export customs declaration, purchase invoices and foreign exchange receipt vouchers. In store service and internal training, citation tracing answers a narrow question: when the same filing material is explained, copied or handed over at a store, can each statement be pointed back to the exact source document, the exact version and the exact field it came from. The update frequency is monthly and per batch, so document version is the first checkpoint in any comparison.

## Constraints at the citation tracing step

The knowledge base search node can associate one or more knowledge bases that share the same vector model, and it outputs cited content as an array whose length may be zero. A zero-length array still lets the downstream chain run. The citation cap is controlled in tokens. The minimum relevance value takes effect only in semantic retrieval or when result reranking is used, and it is a filter threshold. Hybrid retrieval merges multiple result paths through RRF. Reranking requires a rerank model and must be enabled through settings. Image retrieval requires corresponding image input and model capability. Retrieval itself is not authorization, and a citation array does not mean the business step has been reviewed.

Hypothetical drill sample: a paper training set for one export enterprise. The source text reads: "Export customs declaration number A-2024-0315, export date 18 March 2024, corresponding purchase invoice number INV-0312, amount consistent with the customs declaration; foreign exchange receipt voucher SW-0402 shows arrival on 2 April 2024." The draft sentence to be judged reads: "The customs declaration, purchase invoice and foreign exchange receipt voucher required for this batch's rebate filing are all matched and ready for submission." The judgment points are whether the three materials agree on subject, period and field, whether the receipt date falling after the export date sits inside the valid range of the material, and whether the draft sentence goes beyond what the source text supports.

## Configuration and implementation checks

| Configuration item | Hypothetical starting point for this drill | How to check |
| --- | --- | --- |
| Associated knowledge bases | Select only bases sharing the vector model of the sample materials | Compare base identifiers and vector model identifiers; exclude those that differ |
| Search mode | Semantic retrieval plus full-text retrieval | Use full-text for numbered fields, semantic for natural-language description |
| Citation cap | Start from the full token count of the three sample materials | Compare against the actual token count of the sample; raise it if insufficient |
| Minimum relevance | Not enabled for this drill | It filters only in semantic retrieval or reranking |
| Result reranking | Not enabled for this drill | Requires a rerank model and must be enabled through settings |
| Citation output handoff | Pass the citation array to the answering step | Check each answer statement against the cited source text |

The associated knowledge bases must share the same vector model before they can be linked together. When identifiers differ, exclude the mismatched base and record the actual observation rather than running a cross-model retrieval to compare recall. The optional paths in the overall retrieval flow are not all executed on every request: image retrieval needs corresponding image input and model capability, and reranking needs a model enabled through settings. RRF is a merging process for hybrid results, not a switch to turn on.

## Three common errors

1. Treating a retrieval hit as completed authorization. A citation array of length zero still lets the chain run, and a hit does not mean the filing has been reviewed or submitted. Authorization status must be checked separately.
2. Treating the minimum relevance value as a permission or entity filter. That value only filters low-relevance results; it does not exclude unrelated enterprises or unauthorized records.
3. Linking knowledge bases that use different vector models. The documentation requires the same vector model before joint association. Check identifiers first and exclude those that do not match.

## How to verify the setup

1. Input the three source sentences and the draft sentence from the drill sample. Compare whether the draft sentence introduces conclusions such as "all matched" or "ready for submission" that the source text does not state. The condition is met only when the source text explicitly supports the statement. If the source text is silent, record the gap as unsupported or pending verification.
2. Input the full text of the three sample materials. Compare whether the citation cap in tokens covers all three. The condition is met when the cited content presents the key fields of all three materials completely.
3. Input a paper material that does not state the receipt date. Compare whether the answer marks the missing field as pending verification. A definite conclusion in place of the missing field does not meet the condition. A pending review does not prove that operating permission is absent, and a zero-length citation array can be checked against the downstream design using an explicit paper input of an empty array; this does not claim that a fabricated rule always returns an empty array.

This page addresses only export tax rebate filing, store service and internal training, and citation tracing. Which materials, operations or requests sit in what authorization state during a handover cannot be inferred from retrieval or from a form. Retrieval is not authorization, and a form collects values; business verification, approval, database writes and external synchronization each require their own stated downstream implementation.
