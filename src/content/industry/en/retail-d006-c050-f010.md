# Complaints and official replies: citation tracing for staff training

## What the documents look like

Complaints and official replies are directed at a platform or a regulatory authority, so the written record must carry formal evidence and rectification language. In store service and internal training, customer service supervisors, legal compliance staff, and store owners work from complaint tickets, regulatory inquiry letters, order evidence, and rectification reports. The material arrives from the 12315 platform, the platform complaint center, customer service chat, and the order system. Updates are irregular and occur per case, so a citation tracing step cannot rely on a fixed refresh rhythm.

Two features of this category shape the task. First, the reply audience is a regulator or platform rather than a repair or reshipment customer, so every quoted statement must trace back to a specific ticket, a specific piece of order evidence, and a specific document version. Second, the same complaint may reference a regulation that has been revised, which means tracing must compare the version cited in a draft against the version currently in effect inside the knowledge base. Citation tracing here means checking, line by line, that each quoted item in a reply returns to source text held in the knowledge base, and that the source version is the one still valid.

## Constraints at the citation tracing step

The knowledge base search node first checks the selected knowledge bases and their document versions. Only knowledge bases that share the same vector model can be associated together. The search node outputs a citation array, and that array may have a length of zero; an empty array does not mean the workflow has errored or stopped. The retrieval output then passes to the answering stage, where each reply sentence must be compared against the cited source text. Citation display is checked against a traceable sample, and the model thinking process or the fluency of a reply does not substitute for source evidence. Document timeliness is checked by testing sources against the current version and a historical version, and whether a citation is adopted still depends on review against the effective version.

Hypothetical drill sample: a store received a regulatory inquiry letter on 12 March 2025 stating, "Please provide the refund handling record for order A-20250301 and the customer service communication record." The knowledge base holds a version of the Refund Handling Standard dated 28 February 2025, containing the sentence "A refund request must be submitted within fifteen days after order payment." A draft reply reads, "According to the Refund Handling Standard, the refund request for this order complies with the requirement to submit within fifteen days." To be determined: whether the standard version cited by this draft sentence is the currently effective version, and whether that standard text actually states the fifteen-day limit.

## Three common errors

1. Treating retrieval output as already-authorized evidence. Retrieval is recall, not authorization. In the sample, the inquiry letter demands the refund record, and a retrieved standard sentence only describes the standard content; it does not show that this order was actually refunded. The order system record and ticket status must be checked, and any gap recorded.
2. Forcing knowledge bases with different vector models into one association. Official text states only same-vector-model knowledge bases can be associated. For cross-model bases, verify the identifier and exclude non-matching ones; do not run a cross-model search to compare missed recalls.
3. Treating the thinking process or reply fluency as source evidence. Citation display is checked against a traceable sample of the original text. If the standard version cited by the sample draft sentence is the 28 February 2025 version, it must be compared with the currently effective version to confirm whether that version is still valid.

## How to verify the setup

1. Input the sample draft sentence "According to the Refund Handling Standard, the refund request for this order complies with the requirement to submit within fifteen days," and compare the standard version cited by that sentence against the currently effective version identifier in the knowledge base. If the two version identifiers match and the original text does state the fifteen-day limit, the traceable-citation condition is met; if the version identifiers differ, record a version gap.
2. Input a paper citation array of [], and compare whether the downstream answering stage still runs. Official text states the citation length may be 0 and the output path still runs. If the downstream design continues with an empty array, the empty-result handling condition is met; do not claim that a search for a fictional rule necessarily returns [].
3. Input the requirement in the inquiry letter, "the refund handling record for order A-20250301," and compare the retrieval output against the order system record for the same subject, the same period, and the same field. If retrieval hits only the standard text and not the actual handling record for that order, record it as unsupported; if both are hit and the fields agree, the evidence-chain check condition is met.
