# Pinduoduo seller campaigns: workflow routing for staff training

## What the documents look like

Pinduoduo low-price campaign store operations revolve around low-price resource slots, campaign inventory, and refund-rate fluctuation. The daily document set consists of campaign registration forms, product cost calculation sheets, after-sales refund slips, and platform internal messages. Campaigns advance by session, and materials update daily and per campaign. In store service and internal training, campaign operators, supply-chain buyers, and store service staff handle these materials together. Workflow routing must treat form collection, user selection, and downstream business actions as separate matters.

## Constraints at the workflow routing step

The Form Input node is a user-interaction node. When triggered, the conversation enters an interaction state, the workflow state is recorded, and execution continues after the user completes the interaction. After the user submits the required information, the node collects the form information and passes it to subsequent nodes. The User Selection node is also a user-interaction node. When the user makes a choice, the node evaluates that choice and executes the corresponding "yes" branch. Both nodes can be added repeatedly and trigger execution. Interaction waiting, state recording, and dialog hiding are existing node behaviors; there is no corresponding control switch for them.

Retrieval or form collection does not constitute authorization. Order writes, document backfill, and external status synchronization require a separately connected business interface or a later process.

Hypothetical drill sample: a Pinduoduo campaign store operator submits a handover material in a store service and internal training setting. The source text reads: "I am in the campaign operator role, responsible for the store-side handover of the registration form and product cost calculation sheet for a certain low-price campaign; the after-sales refund slip is still under review, the platform internal message has not been answered, and the campaign inventory estimate is not complete." The proposed judgment sentence reads: "This operator has completed the store-side handover for this campaign and may execute campaign inventory deduction." The source text states only the role and the objects of responsibility; the refund slip is under review, the internal message is unanswered, and the inventory estimate is incomplete. The proposed judgment sentence exceeds the source text.

## Three common errors

1. Treating handover information collected by the Form Input node as authorization for inventory deduction. Input: the hypothetical sample source text and the proposed judgment sentence. Compare whether the source text states inventory deduction authorization. The source text does not state it, so the judgment sentence does not hold.
2. Treating execution of the User Selection node's "yes" branch as completed handover. Input: the selection result and the handover material source text. Compare whether the source text states a completed handover status. The source text says only "still under review," "unanswered," and "not complete," so the judgment sentence does not hold.
3. Treating retrieval or form collection as completed business verification or external synchronization. Input: node outputs and the external action division description. Compare whether a business interface or later process exists. Without such a connection, the external action has not executed.

## How to verify the setup

1. Input the hypothetical sample source text and the proposed judgment sentence. Compare whether the source text states inventory deduction authorization and completed handover status. The source text does not state them, so the proposed judgment sentence should be judged unsupported.
2. Input the User Selection result and the branch connections. Compare whether the corresponding "yes" branch executes after the choice. If it executes, the branch connection is correct; if it does not, record the item as pending verification.
3. Input the node outputs and the subsequent node inputs. Compare whether the collected information is clearly passed to later retrieval, judgment, or interface nodes. If it is passed, the information handoff is in place; if it is not, record the gap.
