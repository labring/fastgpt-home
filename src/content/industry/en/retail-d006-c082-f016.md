# Returned-goods inspections: staff training with interactive forms

## What the documents look like

For staff training in Returned-goods inspections, this page examines FastGPT interactive forms. Returns-receiving training separates receipt, inspection advice and stock disposition. The examples are hypothetical.

## Constraints at the interactive forms step

Suppose an exercise sheet records parcel receipt, inspection advice lists tests still to perform and goods identity awaits order correspondence. Collect warehouse, matter and original wording, then choose identity completion or inspection review. Test missing required information and completed input, inspecting the version actually received downstream. After interaction the node passes information without a built-in inspection database or stock-disposition authority.

## Configuration and implementation checks

| Returns-receiving training | Hypothetical material | Learning check |
| --- | --- | --- |
| Parcel receipt | Receiving event | Not conformity |
| Pending tests | Inspection required | Not all passed |
| Goods identity | Order mapping unresolved | Physical correspondence |
| Required input | Missing/completed tests | Actual handoff |
| Stock disposition | Authorized process | Independent inspection evidence |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Form input` | Collect input and pass values after submission. |
| `Required-information check` | Design required business inputs and missing-input handling. |
| `User selection` | The selected option maps to a connected branch. |
| `Interaction state` | Inspect waiting and completed interaction separately. |
| `Downstream responsibility` | Verify validation, approval and write results separately. |

## Three common errors

Parcel receipt reported as conforming goods needs inspection evidence checked. Tests still required reported as all passed need finding status checked. Unidentified goods applied to this order need physical-item correspondence checked. These concern an event, finding stage and subject; classroom records replace no real inspection.

## How to verify the setup

Ask the trainee to distinguish receiving evidence from conformity evidence, inspecting output handoff on both routes. Added order mapping corrects identity alone while inspection still needs real material. Retain pending-test wording beside its source. Acceptance, returns decisions and stock writes require authorized procedures and receipts. The training form records comparison practice without adjusting goods state or confirming sale availability. Place returned-item identity beside warehouse receipt, retaining pending-test status so the trainee explains why order mapping alone cannot establish that inspection passed.
