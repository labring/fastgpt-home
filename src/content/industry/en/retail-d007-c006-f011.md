# General export declarations: operating reviews with database operations

## What the documents look like

For operating reviews in General export declarations, this page examines FastGPT database operations. Review original documents, indexes and answers for the same shipment, validating recovered content beyond a running service. The examples are hypothetical.

## Constraints at the database operations step

An operations exercise selects a declaration, invoice and packing attachment, retaining shipment, version and a traceable passage for backup and recovery checks. Identify responsibilities of original-data storage and the vector backend in the actual deployment, then test recovered contents separately. A working database connection with a missing packing attachment requires preserving the original and failed read to investigate coverage. A running process does not establish shipment completeness, and an index entry is not a copy of the original.

## Three common errors

- If an index finds the shipment title but the packing attachment is unreadable, compare original, version and read result. Connectivity establishes no complete restored shipment source.

- If originals exist but citations target an earlier shipment, retain question, citation and recovered wording to inspect versions and indexes. A score cannot verify identity.

- If unbacked ERP or forwarder sources become restored material, inspect coverage and actual external retrieval. One database cannot recover excluded evidence or establish declaration accuracy.

## How to verify the setup

Before and after a change, use the same shipment and question to retain original reads, index correspondence and application answers. Observe errors and elapsed time under the actual workload, locating failed connection or query stages without copying another project’s concurrency threshold. Separate backup creation from recovery read tests, keeping missing attachments and external sources unresolved. Operations acceptance covers only verified scope; it replaces neither declaration accuracy, contractual approval nor business confirmation of tax-document matching.
