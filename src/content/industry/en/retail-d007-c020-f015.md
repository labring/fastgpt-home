# Certificates of origin: retrieval for operating reviews

## What the documents look like

Certificates of origin serve import-country tariff treatment and customs clearance. Their documentary logic is not necessarily bound by a letter of credit, and the applicable rules come from the import country and the customer's clearance requirements. The working materials for this category include certificate of origin applications, commercial invoices, packing lists, and production cost records. These materials originate from the Single Window for International Trade, chamber of commerce systems, enterprise production records, and customer clearance requirements.

Operating reviews and exception reviews ask whether the declared status of a given certificate, within a given period, is supported by the accompanying materials. The retrieval step only locates candidate passages for human comparison. A search hit is candidate reference content. It does not constitute authorization, approval, or a declaration status.

Materials update per shipment or in batches. The retrieval configuration does not change with update frequency, so this page does not treat update cadence as a configuration driver.

## Constraints at the retrieval step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Knowledge bases built on different vector models cannot be associated together. Implementation checks verify the vector model identifier, exclude inconsistent libraries, and record the actual observation. Cross-model retrieval is not executed.

The output references are an array, and the length can be 0. When no content is retrieved, the output branch still proceeds. An empty-reference result is a valid link in the chain, not a failure of the node.

The minimum relevance score is a filter threshold. It takes effect only in semantic retrieval or when result reranking is used. It does not perform permission isolation or entity isolation. RRF is the fusion process for combining multiple retrieval channels; it is not an on/off switch. Image retrieval requires an image input and the corresponding model capability. Reranking requires a rerank model and must be enabled according to the configuration.

Hypothetical exercise sample. On 10 March 2026, an export documentation clerk organizes review materials for one shipment. The source text reads: "Certificate of origin application number HYP-2026-0310, declaration date 6 March 2026, goods are stainless steel fasteners, declared country of origin China, accompanied by commercial invoice number INV-2026-0306 and packing list number PL-2026-0306, production cost records archived 5 March 2026." The draft sentence under review is: "This certificate of origin application has been approved by the issuing authority and can be used for customer customs clearance." The subject, object, date range, and status fields needed for the judgment come from the source text above. The source text does not state an approval status.

## Three common errors

1. Treating a retrieval hit as approval evidence. The draft sentence states that the application has been approved. The source text states only the declaration date and the archive date; it does not state an approval status. The input is the source text above and the draft sentence. The compared field is declaration status. If the source text has no approval field, the sentence is unsupported and the evidence gap is recorded.

2. Treating the reference limit as a permission boundary. The input is the same test question with different reference limits. The comparison is whether the returned content contains the complete passage of the same material. If a material is truncated under one limit, this is a content completeness issue and is unrelated to access permission.

3. Forcing knowledge bases with different vector models into one association. The input is two knowledge bases with different vector model identifiers. The comparison is whether the identifiers match. If they do not match, the library is excluded, retrieval is not executed, and no inference is drawn about missed recall or redundant results.

## How to verify the setup

1. Run retrieval for the draft sentence "This certificate of origin application has been approved by the issuing authority and can be used for customer customs clearance." The input is the hypothetical sample source text. Compare whether the returned content contains an approval field. The expected observation is that the sentence is unsupported and a pending-verification record is retained.

2. For the same test question, use semantic retrieval, full-text retrieval, and hybrid retrieval separately. The input is "HYP-2026-0310 declared country of origin." Compare whether the candidate content covers the application, invoice, and packing list. The expected observation is that differences between modes can be observed; a first-hit result is not guaranteed.

3. For the empty-result branch, use an explicit paper input of an empty reference array. Compare whether the downstream node still proceeds and records the empty result. The expected observation is that the chain continues to execute. No claim is made that a given rule's retrieval necessarily returns an empty array.
