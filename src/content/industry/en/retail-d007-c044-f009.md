# Marketplace advertising: operating reviews with tool calls

## What the documents look like

For operating reviews in Marketplace advertising, this page examines FastGPT tool calls. Advertising-review tools verify metric definitions and observation windows before interpreting campaign records. The examples are hypothetical.

## Constraints at the tool calls step

Suppose an advertising summary contains clicks only, a plan awaits execution and a historical screenshot uses a different observation window. Describe the tool as reading and comparing these records, requiring campaign identity and period. Connect it to the calling module and inspect actual parameters. Check system parameters separately from plugin configuration; missing required identity may prevent invocation. No measured result is supplied, and clicks establish no advertising-generated orders.

## Configuration and implementation checks

| Advertising-review tool | Proposed material | Inspection |
| --- | --- | --- |
| Click record | One metric | No additional-order inference |
| Plan state | Execution pending | Operation receipt |
| Observation window | History differs | Check boundaries/identity |
| Required parameters | Campaign and period | Actual invocation |
| Business decisions | Separate changes/attribution | Authority and evidence |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Tool description` | Describe purpose, inputs and non-applicable situations. |
| `Tool parameters` | Inspect module and plugin parameters separately. |
| `Required parameters` | The model may not invoke a tool without suitable required inputs. |
| `Tool connections` | Available tools must connect to the calling module. |
| `Tool-call termination` | Termination ends the call without a later AI summary. |

## Three common errors

Clicks reported as additional orders need metric definitions and order evidence checked. A pending plan described as applied optimization needs operation receipts checked. Historical data mixed into this period needs window boundaries and campaign identity checked. These examine meaning, execution stage and temporal comparability, without establishing causation from a successful tool response.

## How to verify the setup

Retain input, tool request and raw response, checking whether conclusions exceed returned metrics. Assess actual terminal output if termination is configured, without expecting a later model summary. Campaign changes, budget operations and attribution each require business authority and evidence. The tool organizes differences in existing records for review. Keep click definitions apart from order-attribution evidence and identify windows that cannot be directly combined.
