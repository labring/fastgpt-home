# Marketplace category access: citation tracing for operating reviews

## What the documents look like

Marketplace category qualification access happens before listing or merchant onboarding. The core materials are the business license, trademark registration certificate, brand authorization chain, and industry license. Operating reporting and exception review must answer which material, which version, and which authorization boundary supports a given qualification conclusion. Qualification materials update irregularly, and each onboarding attempt can bring a new version, so the same entity's material status at different points in time needs separate records.

The difference from store review maintenance is timing. Review maintenance happens after a transaction; qualification access happens before a business action. This determines that citation tracing concerns onboarding materials and their review status. The citation output is an array, and its length can be zero. Even when no content is found, the output path still runs through.

## Constraints at the citation tracing step

Knowledge base search can select one or more knowledge bases that use the same vector model for vector search. Knowledge bases with different vector models cannot be associated together. When identifiers do not match, exclude the non-matching ones and record this; do not run cross-model retrieval to compare missed recalls. Retrieval returns material fragments and does not constitute an authorization judgment. Whether a material is adopted still requires review against the valid version.

The minimum relevance score is a 0-1 filter threshold that takes effect only in semantic retrieval or when result reranking is used. It does not perform permission or entity isolation. Hybrid retrieval merges multiple result paths through RRF, and the rerank model produces a 0-1 score. These mechanisms affect ordering and do not change whether a material has been authorized.

Hypothetical drill sample: the original text of one material reads "Business license issued by the Market Supervision Administration of a certain city, entity is A Supply Chain Management Co., Ltd., unified social credit code field stated as 91330000XXXXXXXXXX, registration status is active, issue date is March 12, 2024." The original text of another material reads "Brand owner B Company issues an authorization letter authorizing A Supply Chain Management Co., Ltd. to sell designated category goods in the East China region from April 1, 2024 to March 31, 2025; no signing date appears at the signature block of the authorization letter." A draft sentence to be assessed reads "A Supply Chain Management Co., Ltd. has obtained a long-term valid authorization from B Company and can cover sales in all regions." The period and region in this draft exceed the scope stated in the authorization letter, and the signing date is missing, so it is unsupported and the evidence gap must be recorded.

## Three common errors

1. Treating a retrieved material as already authorized. The input is the citation array returned by search; the comparison object is the period and region stated in the authorization letter; if the draft sentence exceeds that scope, the observed result is insufficient citation support and a pending verification item must be recorded.
2. Forcing association of knowledge bases with different vector models. The input is the vector model identifier of multiple knowledge bases; the comparison object is whether the identifiers match; the observed result is that non-matching ones should be excluded and retrieval comparison should not continue.
3. Judging an empty citation array as a workflow failure. The input is a citation array of length zero; the comparison object is the downstream handoff design; the observed result is that the output path still runs through, material absence is recorded as a gap, and no system error is inferred.

## How to verify the setup

1. Input the business license original text from the hypothetical sample and the draft sentence "A Supply Chain Management Co., Ltd. has obtained a long-term valid authorization from B Company and can cover sales in all regions." Compare the entity, period, and region in the draft sentence against the fields stated in the authorization letter. The observed result is that the period and region do not match and the signing date is missing, so it is judged unsupported and the evidence gap is retained.
2. Input two knowledge bases whose vector model identifiers differ. Compare whether the identifiers match. The observed result is that the non-matching one is excluded, the retrieval scope is limited to same-model knowledge bases, and the exclusion action is recorded.
3. Input an explicit paper empty array []. Compare whether the downstream handoff design still executes downward. The observed result is that the output path runs through, material absence is recorded as a gap, and no claim is made that a fictional rule search necessarily returns an empty array.
