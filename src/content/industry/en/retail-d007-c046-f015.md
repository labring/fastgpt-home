# Marketplace category access: retrieval for operating reviews

## What the documents look like

Category access happens before listing or onboarding, and the core materials are entity qualifications and the authorization chain. For this task the documents are the business license, the trademark registration certificate, the brand authorization chain, and the industry license. These materials come from platform recruitment pages, the national enterprise credit information publicity system, trademark office data, and license systems. Updates are irregular, and collection restarts with each onboarding.

Operating reports and exception reviews need to answer what state a given retrieval or form request currently sits in, whether materials are complete, and whether the authorization chain is continuous. The retrieval step only locates materials already stored in the knowledge base. It does not verify whether a business license is authentic, and it does not decide whether an authorization is in effect.

Irregular updates mean the library can hold both older and newer scanned versions at the same time, so retrieval results need manual comparison of version and date. The knowledge base search node can associate one or more knowledge bases that use the same vector model. Knowledge bases built on different vector models cannot be associated together; the identifier is checked first and non-matching bases are excluded. Search modes are semantic search, full-text search, and hybrid search. Hybrid search merges multiple result paths through RRF, and RRF is a fusion process rather than a switch that can be turned on. Minimum relevance takes effect only under semantic search or when result reranking is used; it is a filter threshold, not a permission or entity isolation mechanism. The reference cap is measured in tokens, and the output reference content is returned as an array whose length can be 0.

## Constraints at the retrieval step

A hypothetical drill sample is used here. An onboarding specialist searches the knowledge base for a brand authorization chain. The stored material reads in three sentences: "Authorizing party: Huachen Daily Chemicals Co., Ltd. Authorized party: Ruitong Trading Co., Ltd. Authorized brand: Jieyun. Authorization period: January 1, 2025 to December 31, 2025." A separate business license reads: "Name: Ruitong Trading Co., Ltd. Unified social credit code: hypothetical number 91330100MA2XXXXX0A. Business scope: sales of daily chemical products." The draft sentence to be judged is: "Ruitong Trading Co., Ltd. has obtained a long-term authorization from Huachen Daily Chemicals Co., Ltd. for the Jieyun brand." The authorization period in the draft does not match the source text "January 1, 2025 to December 31, 2025," and "long-term authorization" is not supported by the source text.

Several constraints follow from this. Retrieval returns stored sentences; it does not confirm that an authorization is continuous or that it covers the current onboarding period. The minimum relevance value filters low-relevance results and does not exclude unrelated businesses or unauthorized records, because a similarity score does not carry entity isolation duties. A pending request is not an approval, and finding related materials does not mean an onboarding application has passed or that a deposit has been handled. When the input contains an image, image description retrieval or image vector retrieval runs only if the corresponding model capability is configured. Reranking runs only when a rerank model is available and enabled by settings. The optional paths shown in the overall retrieval diagram are not all executed on every request.

## Three common errors

1. Treating retrieval recall as authorization confirmation. Finding the three authorization sentences only shows the material was located in the library. Whether the authorization is continuous and covers the current onboarding period still requires manual comparison of period and parties.
2. Treating minimum relevance as a permission filter. The value only filters low-relevance results. It does not exclude unrelated enterprises or unauthorized records, and the similarity score does not perform entity isolation.
3. Treating a pending review request as approved. The draft sentence is in a to-be-judged state. Retrieving related materials does not mean the onboarding application has passed, and it does not mean the deposit has been processed.

## How to verify the setup

1. Input the three authorization sentences and the draft sentence. Compare "long-term authorization" in the draft against "January 1, 2025 to December 31, 2025" in the source text, and observe whether the period mismatch is identified and judged as unsupported.
2. Input the business license text and the draft sentence. Compare the entity names "Ruitong Trading Co., Ltd." and "Huachen Daily Chemicals Co., Ltd.," and observe whether the draft conflates the authorizing party with the authorized party. If so, record a same-entity comparison failure.
3. Input a question unrelated to qualifications. Observe whether the returned reference array is 0 or contains only low-relevance fragments. Do not assume an unrelated query must be empty. If the returned content is unrelated to qualifications, record it as a retrieval scope needing convergence, and do not conclude from this that permissions are isolated.

The same-entity, same-period, same-field rule applies to all three checks. A contradiction requires explicitly mutually exclusive values in the same field. A field that is not stated, or evidence that covers only a related stage, is recorded as unsupported or pending verification, not as a denial or a conflict. A pending review does not demonstrate a lack of operating permission. Signing, reaching cooperation, and contract effectiveness are three distinct facts. A quotation validity period does not indicate a supply period. No authorization or effectiveness clause is added to force a definite answer, and evidence gaps remain open.
