# Producer export tax processes: citation tracing for operating reviews

## What the documents look like

Producer export tax exemption, offset and refund combines domestic-sale tax offsets with export refunds in one calculation. Operating reports and exception reviews therefore draw on four document families at the same time: the exemption, offset and refund declaration detail schedule, the export contract, the sales subsidiary ledger, and the export customs declaration. These families do not share one field basis. The customs declaration records a free-on-board value, the sales subsidiary ledger records a booked amount, and the declaration detail schedule aggregates self-produced exports under the exemption, offset and refund basis. Collecting self-produced exports, computing the exemption, offset and refund, and handling free-on-board differences are the time-consuming steps. Citation tracing addresses a narrower question: during a review, can each reported figure be traced back to the original material line by line. The supplied brief gives a monthly update frequency. This page does not derive batch synchronization or real-time triggers from that frequency.

## Constraints at the citation tracing step

The knowledge base search node can associate one or more knowledge bases that use the same vector model, and it outputs cited content as an array whose length may be zero. When the array is empty, the output path still runs through. Whether retrieval results reach the answering step, and whether an answer matches cited source text item by item, must be checked separately. The minimum relevance score is a filter threshold; it does not perform permission or entity isolation. The same-vector-model requirement applies only to knowledge bases that are jointly associated, and it does not extend to business registration sites or other external systems. Reranking is an optional path that requires a rerank model and must be enabled under its settings. RRF is the fusion process for mixed retrieval results, not a switch.

Hypothetical paper exercise sample: the source material reads, "The March 2025 exemption, offset and refund declaration detail schedule of a certain producer enterprise states export sales of RMB 1,000,000; the export contract for the same month stipulates a free-on-board price of USD 150,000; the sales subsidiary ledger records RMB 1,020,000; the export customs declaration reports a free-on-board price of USD 150,000." The draft sentence to be assessed is, "The enterprise's declared export sales for March match the customs declaration amount, and the difference has been verified." The source material provides only four amounts and one contract. It states no exchange-rate conversion basis and no verification conclusion for the difference. The draft sentence is unsupported.

## Configuration and implementation checks

| Configuration or check item | Value or action on this page | Basis and boundary |
| --- | --- | --- |
| Associated knowledge bases | Hypothetical starting point for this exercise is 1, containing only the four material families above | Joint association of multiple bases requires the same vector model; verify the identifier first |
| Citation limit | Hypothetical starting point for this exercise is 800 tokens, compared with 1,200 in the previous review record | The limit controls cited content volume, not permissions |
| Minimum relevance score | Hypothetical starting point for this exercise is 0.3, compared with the default disabled state | Takes effect only in semantic retrieval or with reranking |
| Search mode | Mixed retrieval first; exact-number fields use full-text retrieval separately | RRF is a fusion process, not written as a switch |
| Cited content output | Accept the array and compare each item with the source material text | Length may be zero; an empty array is not an error |
| Material version check | Test sources with one current version and one historical version | Whether a citation is adopted still depends on valid-version review |

## Three common errors

1. Treating a retrieval score as a permission filter. Input is a cross-entity review query; the comparison is between the returned citation items and the authorization scope of the querying entity; the observable result is that score level has no correspondence with entity ownership, and the score does not exclude unrelated entity records.
2. Writing a pending-review state as verified. Input is the draft sentence above; the comparison is between the draft conclusion and the four source materials; the observable result is that the source text states no verification conclusion, so the draft sentence exceeds the evidence.
3. Treating an optional retrieval path as executed every time. Input is a plain text query; the comparison is between the actual execution path and the optional paths listed in the documentation; the observable result is that image retrieval and reranking were not enabled and cannot be described as executed.

## How to verify the setup

1. Input the four source materials and the draft sentence from the hypothetical sample above; compare the draft conclusion against the amounts, period and entity stated in the source text; the condition is met when the draft conclusion is judged not to pass because the source text does not support it.
2. Input an explicit paper empty-result array; compare whether the downstream design continues to run through with length zero; the condition is met when the downstream reports no error and does not treat the empty array as authorization granted.
3. Input two knowledge bases whose vector model identifiers differ; compare whether the identifiers match; when they do not match, exclude joint association and record only the actual observation, without inferring missed recall or redundant results.
