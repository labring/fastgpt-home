# Cross-border settlements: operating reviews with workflow routing

## What the documents look like

For operating reviews in Cross-border settlements, this page examines FastGPT workflow routing. A settlement operations report separates platform records, receipt confirmation and accounting handling. Updated statements do not establish received funds. The examples are hypothetical.

## Constraints at the workflow routing step

A proposed report contains a platform-settlement description and an unconfirmed collection draft but calls statement generation completed collection. Fee material belongs to a different period. Collect periods, source status and pending-confirmation passages. A person can inspect transaction correspondence or obtain receipt evidence. No exchange rates, amounts, fee figures or calculations are supplied. Explain the stage each source supports without merging platform processing and actual business receipt.

## Configuration and implementation checks

| Settlement-report handoff | Proposed source status | Evidence distinction |
| --- | --- | --- |
| Platform description | Statement generated | Not actual receipt |
| Collection draft | Unconfirmed | Actual receipt evidence |
| Fee material | Different period | Not current scope |
| Transaction relationship | Correspondence needed | No inferred fund-state change |
| Formal accounting | Writes and reconciliation separately checked | Finished report is not completed handling |

### Documented conditions

| Documented item / implementation check | Condition |

| `Form input node` | Submitted form values pass to subsequent steps. |
| `User-selection node` | Execution follows the connected selected branch. |
| `Interaction-state check` | Inspect waiting and post-submission states. |
| `Output handoff check` | Compare values passed between steps. |
| `External-operation responsibility` | External business operations require an implementation. |

## Three common errors

Statement promoted to receipt needs the corresponding real collection record. Mixed periods require the original fee period beside received text. Draft promoted to mutual confirmation needs explicit acknowledgment for this reconciliation. These inspect fund stage, coverage and confirmation status rather than infer from report titles.

## How to verify the setup

Inspect inputs on correspondence and receipt branches. Added transaction mapping changes only that relationship while receipt remains unproven. An updated statement must not silently become received funds. Payment, accounting writes and formal reconciliation need separate authority and receipts. Workflow completion establishes neither fully handled settlement nor suitable exchange or funding operations.
