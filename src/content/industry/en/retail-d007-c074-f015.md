# Cross-border resale returns: retrieval for operating reviews

## What the documents look like

Cross-border return refurbishment and resale handles reverse logistics and item condition. It sits in a different stage from overseas-warehouse inbound replenishment. The working materials are return inspection forms, refurbishment records, scrap declarations and resale listing sheets. They arrive from overseas-warehouse WMS, TikTok return centres, Amazon return reports and item inspection photographs. Operating reviews and exception reviews check return grades, refurbishment and packaging arrangements, and scrap-or-resell decisions on a daily or per-batch basis. Refund cost, repeat complaints and inventory book-to-physical mismatch are the consequences that matter. Retrieval turns these scattered materials into citable source text so a reviewer can compare each line item against the original wording.

## Constraints at the retrieval step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Knowledge bases built on different vector models cannot be associated together. Search mode is compared across semantic search, full-text search and hybrid search for the test question; no single mode is assumed to suit all materials. Numbers, model designations and proper nouns suit full-text or hybrid search, while natural-language questions suit semantic or hybrid search. The citation limit is measured in tokens. The minimum relevance score takes effect only under semantic search or when result reranking is used. Question optimisation performs coreference removal and question expansion. Hybrid search merges multiple result paths through RRF. Reranking requires an available model and must be enabled by configuration. Image retrieval requires the corresponding image input and model capability. Retrieval and relevance scores do not carry permission or entity isolation.

Hypothetical drill sample: a cross-border seller's after-sales supervisor organises a batch of return inspection materials on 10 March 2025 for review comparison. The source text reads: "Inspection form HT-0310-07, subject is a Shenzhen seller, object is Bluetooth earphones, return grade assessed as B, may be resold after refurbishment, assessment date 10 March 2025." "Refurbishment record FX-0310-02, same subject, same object, packaging replacement completed, status awaiting inspection re-check, record date 10 March 2025." The draft sentence to be assessed is: "This batch of Bluetooth earphones has completed refurbishment and can be directly resold." The difference from the source text is that the refurbishment record status is awaiting inspection re-check, and the resale decision lacks evidence of completion.

## Three common errors

1. Treating a retrieval hit as authorised execution. Inspection form HT-0310-07 assessing grade B as eligible for resale after refurbishment does not mean refurbishment is complete or that listing has been approved. Retrieving that source text shows only that the material exists; the business action requires separate system implementation.
2. Writing awaiting inspection re-check as completed refurbishment. Refurbishment record FX-0310-02 has status awaiting inspection re-check, while the draft sentence states refurbishment is complete and direct resale is possible. That wording is unsupported.
3. Forcing association across different vector models. Check each library's vector model identifier, exclude those that do not match and record the actual observation. Do not run cross-model retrieval to compare missed recalls.

## How to verify the setup

1. Input the source text of inspection form HT-0310-07 and the draft sentence "This batch of Bluetooth earphones has completed refurbishment and can be directly resold", compare against the status field of refurbishment record FX-0310-02, and observe that when the status is awaiting inspection re-check, the draft sentence is unsupported.
2. Input the source text of refurbishment record FX-0310-02, compare its subject, object and date against inspection form HT-0310-07 for same subject, same period and same field, and observe that when subject and object match but status differs, the result is recorded as pending verification.
3. Input the vector model identifiers of each library, compare whether they match, and observe that when they do not match, exclude that library and record it without running cross-model retrieval.
