# Import and export permits: operating reviews with workflow routing

## What the documents look like

For operating reviews in Import and export permits, this page examines FastGPT workflow routing. Separate withdrawal requests, replacement applications and appendix indexes from authority decisions. The examples are hypothetical.

## Constraints at the workflow routing step

An invented progress packet contains a company request to withdraw an earlier application, a replacement draft awaiting internal confirmation, an old receipt retained in the directory and a license-appendix name without contents. Collect application relationships and source purposes, then choose old/new mapping or appendix collection. A company request is no authority rejection. An older receipt cannot support a new draft without correspondence, and an appendix name establishes no goods coverage. This exercise determines no procedure or statutory outcome.

## Configuration and implementation checks

| Permit-progress review | Invented purpose | Inspection |
| --- | --- | --- |
| Withdrawal note | Company request | Not authority rejection |
| Replacement draft | Internal confirmation pending | No inherited state |
| Old receipt | Earlier matter intake | Check old/new mapping |
| Appendix index | Name only | No contents-reviewed claim |
| Formal action | Separate withdrawal/resubmission | Not executed by nodes |

## Three common errors

- If the company withdrawal request becomes authority rejection, compare author, request verb and formal handling records. Applicant positions cannot become institutional decisions.

- If an older receipt proves intake of the replacement, inspect draft identities, the receipt subject and actual received input. File organization transfers no handling state.

- If an appendix index becomes reviewed product scope, inspect actual contents and subjects. Unobtained attachments remain absent evidence rather than findings from names.

## How to verify the setup

Retain application identity chains and visible appendix scope on both routes. Compare submitted wording, downstream input and report entries. New receipts update their corresponding matter only; added contents still need subject checks without implying permission. A name or report title alone leaves work pending. Formal withdrawal, resubmission, licensing decisions and external reporting require responsible business processes and authority. Choices and interaction records execute none of those operations and provide no admission opinion.
