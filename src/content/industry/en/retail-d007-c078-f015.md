# Chain-store site selection: retrieval for operating reviews

## What the documents look like

Chain headquarters site selection and store opening work happens before a store begins trading. The core of the work is lease and engineering delivery, and the documents handled day to day are site evaluation forms, lease letters of intent, renovation budgets and opening schedules. Operating reports and exception reviews need to place a given store's budget, schedule and actual status inside one retrieval scope so that a specific field can be checked at a specific point in time. These materials are updated per store, and the update timing is irregular rather than fixed.

The retrieval question this page addresses is narrow: what does the record say for a named store, a named field and a named date. The quoted content comes from the knowledge base. Retrieval by itself does not authorize a lease, a payment or a start of works, and no retrieval result should be treated as if it did.

## Constraints at the retrieval step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Knowledge bases built on different vector models cannot be associated together. The identifier should be checked first and non-matching libraries excluded, with the actual observation recorded. A cross-model retrieval should not be run in order to compare missed recalls.

Semantic retrieval, full-text retrieval and hybrid retrieval should be compared against the test question, and no single mode should be assumed to suit all materials. Hybrid retrieval merges multiple result routes through RRF. RRF is a fusion process, and it should not be written as a toggle that is switched on. The minimum relevance value takes effect only in semantic retrieval or when result reranking is used. It is a filtering threshold, not a permission or entity isolation mechanism, and it cannot be used to exclude unrelated businesses or unauthorized records. The quote limit is measured in tokens. Question optimization performs coreference resolution and question expansion, and it adds one model call. Image retrieval requires the corresponding image input and model capability, and reranking requires a model and must be enabled in the settings. Quoted content is output as an array whose length can be zero, so the downstream link still runs when nothing is found.

Hypothetical paper exercise sample: one paper document states, "Renovation budget for a store (hypothetical reference ZX-001): the object is a store, the stage is pre-opening, the date is the hypothetical date 1 March 2025, the budget amount is a hypothetical 800,000, and the authorization scope is verification by the regional development manager, excluding payment approval." A second paper document states, "Opening schedule for a store (hypothetical reference PQ-001): the object is a store, the stage is under renovation, the date is the hypothetical date 1 March 2025, and planned completion is the hypothetical date 30 April." A draft sentence to be assessed reads, "The store renovation budget has received payment approval, and the opening schedule has confirmed completion." Neither payment approval nor completion confirmation appears in the materials, so the sentence is unsupported.

## Three common errors

1. Treating a retrieval hit as authorization evidence for payment approval or completion confirmation. ZX-001 states only verification by the regional development manager and excludes payment approval, so retrieving that material does not create an approval fact. Check: input the ZX-001 text and the draft sentence, compare whether the phrase "payment approval" appears in the draft sentence, and observe that the material does not state it, so the claim is unsupported.

2. Treating minimum relevance as an entity or permission filter. The value takes effect only in semantic retrieval or result reranking, and it is a filtering threshold. Check: input the PQ-001 text and the minimum relevance setting, compare whether that setting is used to exclude unauthorized records, and observe that the setting does not perform permission isolation, so it cannot be used to exclude them.

3. Writing RRF as a toggle, or treating optional routes as running on every request. Image retrieval requires image input and model capability, and reranking requires a model and must be enabled in the settings. Check: input the retrieval request for this round, compare whether image input and a reranking model are present, and observe that the image route does not run when image input is absent, so the route cannot be asserted to have run.

## How to verify the setup

1. Input the ZX-001 and PQ-001 texts together with the draft sentence, compare whether "payment approval" and "completion confirmation" appear in the materials, and observe that neither phrase is stated. The condition is met when the claim is judged unsupported and the evidence gap is recorded.

2. Input two libraries carrying the same vector model identifier, compare whether the identifiers match, and observe that only a match permits joint association. When they do not match, exclude the library, record the actual observation, and do not run cross-model retrieval.

3. Input an explicit paper empty reference `[]`, compare whether the downstream link continues to run, and observe that the link runs. Do not claim that a fabricated rule search necessarily returns `[]`.

This page covers only chain headquarters site selection and store opening, operating reports and exception reviews, and knowledge base retrieval and recall. During operational handover, the authorization state of materials, actions and requests must not be inferred from retrieval or from a form. Retrieval and similarity scoring do not perform permission or entity isolation, and the same-vector-model requirement for associated libraries does not extend to business registration sites or other external systems. No system error or automatic business action should be asserted unless the source text states it. A pending review does not show that an operating permission is missing, and signing, reaching cooperation and contract effectiveness are three distinct facts.
