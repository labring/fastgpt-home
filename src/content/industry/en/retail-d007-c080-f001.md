# Store price and display checks: operating reviews with HTTP integrations

## What the documents look like

For operating reviews in Store price and display checks, this page examines FastGPT HTTP integrations. Separate item/bundle labels, photographed coverage and facing changes from price correction. The examples are hypothetical.

## Constraints at the HTTP integrations step

This page invents audit text: a shelf label describes individual items, a promotion card covers bundles only, a photo description covers the left shelf section, and a store reply records changed facing without mentioning price changes. Management reporting should inspect packaging, photographed area and action in actual HTTP returns. Bundle conditions cannot apply automatically to individual items, and one section cannot characterize the whole store. No actual price, quantity, image analysis or violation finding is supplied.

## Configuration and implementation checks

| Label/display HTTP evidence | Invented coverage | Inspection |
| --- | --- | --- |
| Item label | Separate from bundles | No condition transfer |
| Promotion | Bundles only | No invented conversion/discount |
| Photo note | Left shelf section | No whole-store expansion |
| Store reply | Facing changed only | Not repriced |
| Report finding | Packaging, area and action | Separate source evidence |

## Three common errors

- If a bundle promotion applies to an individual-item label, compare packaging/counting subject, promotion wording and cited row. Invent no conversion or discount condition.

- If a left-section photo note becomes a completed whole-shelf inspection, compare stated coverage and actual attachments. Partial visibility proves nothing about unseen areas.

- If changed facing becomes corrected pricing, inspect the reply verb, label-change records and reinspection sources. Repositioning and repricing need separate evidence.

## How to verify the setup

Pass store, packaging and audit matter under the real read contract. Inspect Params, Headers and applicable Body with credentials redacted. Retain request scope, response text and adopted report statements; a photo index establishes no viewed image. Right-section evidence expands only covered space, and price-change records establish no store-wide match alone. Actual price changes, audit findings and external explanations need responsible authority and receipts. Querying modifies neither POS records nor display data.
