# Returned-goods inspections: retrieval for operating reviews

## What the documents look like

Returned-goods inspection handles reverse parcels and assigned item grades. It does not handle outbound picking for new orders. The working records come from a WMS returns module, platform after-sales cases, carrier return parcels and an inspection bench. The documents reviewed on this page are the return warehouse receipt, inspection photographs, the grade determination table and the resale listing sheet. These records update per item and per day.

For operating reports and exception reviews, one returned item's receipt, photographs and grade determination must be aligned to the same subject, the same period and the same field. Retrieval at this step only returns relevant document fragments as referenced content. It does not determine whether that returned item has been authorized for resale or for scrap.

## Constraints at the retrieval step

The knowledge base search node can associate one or more knowledge bases that use the same vector model. Referenced content is returned as an array, and its length can be zero. When nothing is found, the output link still completes.

Semantic retrieval relies on vector distance. Full-text retrieval relies on keyword hits. Hybrid retrieval merges the two result sets through RRF. The minimum relevance value takes effect only under semantic retrieval or when result reranking is used. Identifiers and model numbers in the grade determination table suit full-text or hybrid retrieval. Natural-language descriptions of inspection exceptions suit semantic retrieval.

The same-vector-model requirement applies only to which knowledge bases may be associated together. It does not extend to business-registration sites or other external systems. Retrieval and similarity scores do not constitute permission or entity isolation, and cannot be used to exclude unrelated business or unauthorized records.

Hypothetical paper exercise sample: the material text to be checked reads, "Return warehouse receipt RH-2024-0417-08, subject is after-sales warehouse Zone A, returned item is model X200 power tool, receipt date 17 April 2024, quantity 1 piece." The grade determination table text reads, "RH-2024-0417-08 inspection conclusion: housing scratched, grade B, resale listing recommended." The draft sentence awaiting determination reads, "RH-2024-0417-08 has completed resale listing at grade B, and the refund dispute has been closed." Neither the completed resale listing nor the closed refund dispute is stated in the given materials.

## Three common errors

1. Treating a retrieval hit as authorized execution. Input the draft sentence and the retrieved grade determination fragment, then compare whether either states that the resale listing is complete or that the refund dispute is closed. When neither is stated, record the result as unsupported; do not write it as executed.
2. Treating minimum relevance as an entity or permission filter. Input a query about a different model, then compare whether the returned referenced content may still contain fragments of an unrelated model. A similarity threshold does not perform the function of excluding unauthorized records.
3. Forcing association of knowledge bases with different vector models. Input two bases whose vector model identifiers differ, then compare whether the node permits associating them together. When identifiers do not match, exclude the non-conforming base and record it; do not run cross-model retrieval to compare missed recalls.

## How to verify the setup

1. Input the draft sentence "RH-2024-0417-08 has completed resale listing at grade B, and the refund dispute has been closed," together with the return warehouse receipt and grade determination table text above. Compare whether the completed resale listing and the closed refund dispute in the draft sentence have corresponding statements. The satisfying observation is: the check conclusion clearly states that both facts are not stated in the given materials, the evidence gap is retained, and the item is not determined as completed.
2. Input the identifier "RH-2024-0417-08" under full-text retrieval and under semantic retrieval respectively. Compare whether the referenced content returned by each path contains the fragment corresponding to that identifier. The satisfying observation is: full-text retrieval hits the identifier, the semantic retrieval return is recorded item by item, and a miss is not written as necessarily empty.
3. Input a query unrelated to inspection. Compare the length and content of the returned referenced content. The satisfying observation is: if the returned array is [], check the downstream link design against an empty reference; if it is non-empty, record the actual content item by item, without inferring that an unrelated query must be empty, and without claiming that an invented rule necessarily returns [].

This page addresses only returned-goods inspection / operating reports and exception reviews / knowledge base retrieval and recall. Which materials, operations and requests are in what authorization state during an operations handover cannot be treated as authorized execution by retrieval or by a form.
