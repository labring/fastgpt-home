# B2B marketplaces: multilingual work with vector indexes

## What the documents look like

For multilingual work in B2B marketplaces, this page examines FastGPT vector indexes. Compare the material received with the sources used in the answer. The examples are hypothetical.

## Constraints at the vector indexes step

A new bilingual B2B quotation test can state that only uninstalled components are supplied and installation requires a separate agreement. Check a Chinese installation question and its English counterpart against the proposed search entries, tracing both to the same limiting wording. Adding language-specific indexes to one original does not establish business approval of a translation; this test compares the correspondence of the ordinary text actually supplied in both languages.

## Configuration and implementation checks

| Item or implementation check | Original or index content | Traceable evidence |
| --- | --- | --- |
| Embedding model | Associated multilingual sources | Check actual consistency beyond model names. |
| Original mapping | Only uninstalled components supplied | Trace both language entries to the restriction. |
| Index content | Installation-inclusion questions in both languages | Do not add assembly or installation service. |
| Repeated question | Same installation scope in Chinese and English | Compare the original passages cited. |
| Scanned material | Missing version later supplied as a scan | Inspect the actual text or image ingestion path; check descriptions or vectors where image retrieval is used. |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Embedding model` | Knowledge bases associated with one search node must use the same embedding model. |
| `Original data and indexes` | One original data block can have multiple indexes. |
| `Index content` | Index wording should be complete and focused. |
| `Image indexes` | Where image retrieval is used, inspect descriptions or image vectors. |
| `Version and result check` | After a change, reuse questions to compare originals. |

## Three common errors

- If an English index adds assembled or with installation, compare it with uninstalled components and separately agreed installation. Added index wording cannot amend quotation scope.

- If both language indexes hit but citations lose the exclusion, compare each actual citation and target data. Two hits do not establish matched scope.

- If test translation and a proposed index become confirmed formal English terms, inspect source identity and confirmation evidence. Adding a language index is not business approval.

## How to verify the setup

Where the task requires a business-confirmed counterpart but only proposed test text is supplied, an index cannot stand in for that confirmed version. After obtaining it, trace the language original, index and citation; knowledge bases associated within one search node need matching embedding models. For a scanned supplementary document, establish the text or image ingestion path actually used and compare its stored representation with the source. Where image retrieval relies on a description or image vector, verify that artifact. Repeat both-language questions about installation scope, checking retention of uninstalled components and a separate installation agreement. Matching both queries alone does not establish the same scope.
