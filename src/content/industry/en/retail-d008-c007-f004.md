# General import declarations: multilingual work with vector indexes

## What the documents look like

For multilingual work in General import declarations, this page examines FastGPT vector indexes. Imported packing materials need carton, inner-box and unit identity preserved rather than replaced by index wording. The examples are hypothetical.

## Constraints at the vector indexes step

Proposed import packing material defines an outer carton as transport packaging and an inner box as display packaging. English headings distinguish outer carton and display inner box, but the quantity section is not supplied. A question about received units needs more than packaging hierarchy. Indexes can describe each layer to clarify what box refers to, yet two indexes for one hierarchy note are not two receiving records. Translation must not silently treat box as a product unit or generate an actual item count from the presence of packaging layers.

## Configuration and implementation checks

| Material check | Conditions in this test | Implementation evidence |
| --- | --- | --- |
| Counting object | Carton, inner box, unit | Trace unit source. |
| Quantity material | Not supplied | Invent no total. |
| Batch identity | Current batch | Check receipt mapping. |
| Multiple indexes | Same hierarchy note | Do not count separate receipts. |
| Actual receipt | No site verification | Absence is not zero. |

| `Embedding model` | Knowledge bases associated with one search node must use the same embedding model. |
| `Original data and indexes` | One original data block can have multiple indexes. |

## Three common errors

First, box may become a product unit; inspect English headings and Chinese layer identities, tracing the answer’s counting unit. Second, absent quantity material may produce a total; compare original contents and answer and request separate quantity evidence instead of filling it. Third, hierarchy wording may map to another batch’s receipt; inspect batch identity and original path rather than join counts through similar package names. These concern unit, numerical evidence and batch ownership. Index phrasing itself does not verify physical receipt, even if the retrieval result appears highly relevant to packaging.

## How to verify the setup

Test outer-carton purpose, inner-box purpose and the source of any unit count, retaining each index-to-original relationship. Bilingual descriptions need the same layer before checking whether returned text supports the question; semantic relevance does not guarantee agreement on the counting unit. Bases associated with one retrieval node need the same embedding model, without extending that condition to all workflow stages. This exercise accepts no goods and decides no real trade quantity. A missing quantity field does not mean zero received, and failure to retrieve a receipt does not establish that receipt never occurred.
