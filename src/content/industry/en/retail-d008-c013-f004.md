# Franchise store supervision: multilingual work with vector indexes

## What the documents look like

For multilingual work in Franchise store supervision, this page examines FastGPT vector indexes. Franchise reference-store images are not approval of a current layout; indexes need their example identity. The examples are hypothetical.

## Constraints at the vector indexes step

Proposed franchise captions describe a reference store’s display example, with the current store’s layout under review. A question asking whether this store may reproduce the layout needs current decision evidence beyond the example image. Indexes for reference layout and pending current review can map to the note without naming it an approved standard-store plan. Establish whether actual ingestion used text or images first. A page containing a picture does not establish that image descriptions or image vectors were used to process or retrieve that page.

## Configuration and implementation checks

| Current stage | Under review | Preserve pending status. |

| Later comments | Current store and version | Do not borrow old approval. |

## Three common errors

First, an index may change example into approved layout; compare example identity and pending stage for an added conclusion. Second, reference and current stores may merge; inspect store identity and caption origin instead of borrowing current authority from shared branding. Third, an image description may omit the written pending condition; inspect the actual ingestion path and returned original. Only an actual image-retrieval path calls for checking its description’s treatment of the restriction. These concern document nature, store identity and carrier processing, without making visual resemblance permission for current implementation.

## How to verify the setup

Ask which store owns the picture, what the example shows and whether the current store has a decision, tracing actual indexes and originals. Several indexes for one caption do not constitute multiple approvals. Check the same embedding model for bases linked within one retrieval node when relevant. This exercise reviews no actual franchise eligibility or fit-out plan and performs no display work. Failure to retrieve current comments leaves evidence unverified, rather than establishing non-approval. Later comments need the current store and layout version before defining the supported answer scope.
