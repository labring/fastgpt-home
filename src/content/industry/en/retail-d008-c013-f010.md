# Franchise store supervision: citation tracing for multilingual work

## What the documents look like

Franchise supervision in convenience retail differs from direct-operated fresh food ordering because headquarters supervises how franchisees execute standards. The working materials are store visit forms, franchise contracts, rectification notices and display standards. These documents often exist in more than one language version, and a supervisor may need to trace an answer back to a specific clause in a specific version. The typical actors are headquarters, regional supervisors and franchise store owners. Errors can produce franchise disputes, brand damage and contract breach. Source data arrives from the supervision app, POS sales, the franchise system and store photographs, with weekly and monthly update rhythms. For citation tracing, the practical consequence is that any answer must point back to a versioned passage rather than to a general recollection of the standard.

## Constraints at the citation tracing step

The knowledge base search node can associate one or more knowledge bases that share the same vector model, and it outputs cited content as an array whose length may be zero. Even when nothing is retrieved, that output path still completes. Semantic retrieval supports cross-language understanding, so a Chinese question can match an English knowledge point, which matches the multilingual retrieval need here. The citation limit is controlled in tokens. The minimum relevance value takes effect only in semantic retrieval or when result reranking is used, and it acts as a filter threshold; it does not perform permission or entity isolation. Hybrid retrieval merges multiple result paths through RRF, and ReRank reorders candidate text and returns a score between 0 and 1. Retrieval itself is not authorization. Whether a citation is adopted still depends on human review against the effective version.

Hypothetical paper exercise sample: the Chinese text of clause 7.2 of a franchise contract reads "Party B shall submit a written rectification report within ten days of receiving the rectification notice" (English rendering). The corresponding English clause reads "Party B shall submit a written rectification report within ten days of receiving the rectification notice." A draft sentence under review reads "The franchisee shall submit a rectification report within seven days of receiving the rectification notice." The judging task is to check whether the draft sentence and the cited clause share the same subject, the same period and the same field.

## Configuration and implementation checks

| Associated knowledge bases | Select only the Chinese and English franchise contract bases that share one vector model | Compared with the identifier of a base using another vector model, which is excluded so no cross-model retrieval runs |
| Search mode | Hybrid retrieval | Compared with semantic retrieval alone, because numbers and proper nouns need full-text recall as a supplement |
| Citation limit | Hypothetical starting point of 800 tokens | Compared with the full length of the sample clauses, so both the Chinese and English clauses can enter the citation intact |
| Minimum relevance | Hypothetical starting point of 0.3 | Compared with the rerank score of the sample question, and used only as a filter threshold |
| Question optimization | Enabled | The sample is a short multilingual question, compared with the retrieval term completeness when it is disabled |
| Result reranking | ReRank enabled | Compared with the candidate order without reranking, to judge whether the clause enters the citation |

These values are starting points for this hypothetical exercise and are not official default values.

## Three common errors

1. Treating minimum relevance as a permission or entity filter and assuming that raising it excludes records belonging to unrelated franchisees. The value is only a similarity filter threshold and does not provide isolation; that requires a separate system implementation.
2. Associating knowledge bases that use different vector models. The documentation requires the same vector model before bases can be associated together, so the model identifier should be checked first and non-matching bases excluded, without running cross-model retrieval to compare results.
3. Reading a cited content array of length zero as a workflow error that terminates the run. The documentation states that the output path still completes with an empty array, so the downstream design should be observed against the actual output.

## How to verify the setup

1. Input the draft sentence from the hypothetical sample together with the Chinese and English clause texts. Compare the "seven days" in the draft sentence with the "ten days" in the source clause, and observe whether the citation points back to the text of clause 7.2. When the draft sentence and the source clause share the same subject, the same period and the same field but hold mutually exclusive values, the result is a contradiction; if the citation does not point back to the source, record it as unsupported.
2. Input a paper citation array of `[]`. Compare whether the downstream node continues to execute on the empty citation, and observe whether the output path completes. The condition is met when the downstream does not terminate with an error because of the empty array.
3. Input the identifiers of two knowledge bases that use different vector models. Compare whether the model fields match, and observe whether they are allowed to be associated together. When the model identifiers differ, they should be excluded and recorded as pending verification, without inferring missed recall or redundancy from that fact.

This page addresses only franchise store supervision, cross-border materials and multilingual retrieval, and citation tracing. Operational handover must distinguish which materials, actions and requests sit at which authorization state; retrieval or a form does not itself constitute authorization to execute.
