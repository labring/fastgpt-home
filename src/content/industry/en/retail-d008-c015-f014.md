# Letter-of-credit documents: model connections for multilingual work

## What the documents look like

Letter-of-credit examination and presentation turns on documentary consistency. The service condition is the bank's payment undertaking, which differs from the tax-matching task of export rebate filing. Working materials include issuing-bank notices, UCP600 clauses, freight forwarder bills of lading, and bank presentation records, refreshed per transaction. Cross-border material and multilingual retrieval must bring letters of credit, commercial invoices, bills of lading, insurance policies, and drafts into a searchable scope so document examiners can check clauses against document wording. Languages, layouts, and field positions vary widely, and retrieval results must be traced back to the source text for item-by-item comparison.

## Constraints at the model connections step

Model access depends on AI Proxy. Deploy dependent services for the version in use, and verify model channels separately from application configuration. Both the App and any Admin service that reuses App/Service configuration must set AIPROXY_API_ENDPOINT and a non-empty AIPROXY_API_TOKEN; missing either causes startup validation to fail. AIPROXY_API_ENDPOINT holds the service root address without a /v1 suffix. AIPROXY_API_TOKEN holds a non-empty administrator token consistent with the server side and cannot be replaced by an application API key. The system requires at least one language model and one index model. Retrieval libraries that share the same vector model can be associated; libraries with different identifiers must first have identifiers checked and non-matching ones excluded, without running cross-model retrieval to compare missed recall. Semantic recall and relevance scores do not carry permission or entity isolation.

Hypothetical drill sample: a document examiner receives a letter-of-credit advice whose source text reads "Issuing bank: Example Bank; Applicant: Example Importer; Beneficiary: Example Exporter; Amount: USD 100,000; Latest shipment date: 2026-09-30; Presentation period: within 21 days after shipment." A drafted sentence reads "This letter of credit allows partial shipment." The source text contains no partial-shipment clause, so the drafted sentence remains to be verified.

## Three common errors

1. Entering AIPROXY_API_ENDPOINT as a full request address carrying /v1. Check whether the input is the service root address, compare against the documented example format, and treat the presence of /v1 as non-conforming.
2. Using an application API key as AIPROXY_API_TOKEN. Check whether the value is empty and whether it matches the server-side administrator token; a mismatch is non-conforming.
3. Treating the partial-shipment clause absent from the hypothetical sample as confirmed fact. Check whether the drafted sentence has a corresponding source field; when the source text lacks that field, the sentence remains to be verified.

## How to verify the setup

1. Input the hypothetical sample source text and the drafted sentence, then compare whether the drafted phrase "allows partial shipment" can find a corresponding field in the source text. The source text does not state that clause, so the expected result is pending verification rather than a contradiction finding.
2. Input a candidate value for AIPROXY_API_ENDPOINT and compare whether it carries /v1. When /v1 is appended, the value does not meet the documented format requirement and must be changed back to the root address.
3. Input a candidate value for AIPROXY_API_TOKEN and compare whether it is non-empty and consistent with the AI Proxy server side. When it is empty or inconsistent with the server side, startup validation fails and the value must be corrected before restart.

Retrieval observation: input a letter-of-credit keyword query and record the returned entries and their source positions; for an empty result, use the paper input `[]` to check the downstream design without asserting that a fictional rule must return empty. Image retrieval requires an image input and a model with that capability, and reranking requires a model enabled according to settings; when these conditions are unmet, that path does not execute.
