# Certificates of origin: workflow routing for multilingual work

## What the documents look like

Applications for certificates of origin revolve around four document families: the certificate of origin application, the commercial invoice, the packing list, and production cost records. Data sources include China International Trade Single Window, CCPIT systems, enterprise production records, and customer customs clearance requirements. A certificate of origin serves import-country tariff treatment and customs clearance, and is not necessarily bound by a letter of credit. The same shipment may therefore carry Chinese-language application information alongside foreign-language clearance requirements, and multilingual retrieval has to hold both. Handling frequency is per shipment or in batches, and document clerks, declarants, and exporters need to hand work off within one workflow.

For the workflow routing step, this matters in two ways. First, the interaction nodes sit in front of retrieval, so the values a person supplies determine what the downstream retrieval step receives. Second, retrieval output is an input to later judgement or interface nodes, and does not itself carry authorization.

## Constraints at the workflow routing step

The form input node is a user interaction node. When it triggers, the conversation enters an interaction state, the workflow state is recorded, and execution continues after the user completes the interaction. Required fields are collected on submission and passed to subsequent nodes. The user selection node behaves in the same interaction pattern: when the user makes a choice, the node evaluates that choice and executes the "yes" branch.

These two nodes form the front interaction stage for cross-border materials and multilingual retrieval. Retrieval does not perform authorization judgement. Its results can only serve as input to later judgement or interface nodes. Order writing, document backfill, and external status synchronization require a separate business interface or a later process.

Hypothetical paper exercise sample, used only for this page. Paper source text: "Applicant: Company A; Goods: valves; Invoice number: INV-001; Destination country: Germany; Customer clearance requirement: an English certificate of origin must be attached." A draft sentence under review reads: "This shipment has obtained all certificates required by the German customer for customs clearance." Comparing the draft sentence with the source text, the source text states only the customer's clearance requirement. It does not state that any certificate has been obtained or dispatched. The draft sentence is therefore unsupported.

## Three common errors

1. Treating a retrieval result as an authorization conclusion. Input the sample source text and the draft sentence, compare whether the draft sentence states that a certificate has been obtained, and observe that the source text does not state this. The draft sentence is unsupported.
2. Treating empty-result handling as a guaranteed return of []. Input the paper value [], compare whether the downstream design handles an empty result, and observe that no claim can be made that retrieval under an invented rule will always return []. Record the gap.
3. Treating the "yes" branch of the user selection node as already executed. Input the sample selection request, compare whether the branch connections have been verified one by one, and observe that a pending review does not demonstrate the absence of operating authority.

## How to verify the setup

1. Input the sample source text and the draft sentence. Compare whether the draft sentence matches the source text on the same subject, the same period, and the same field. The source text does not state that a certificate has been obtained, so the draft sentence is unsupported. This is the expected observation; it is not a claim that a test was run.
2. Input the paper value []. Compare whether the downstream design handles an empty result. The expected observation is that no claim can be made that retrieval under an invented rule always returns []; record the gap rather than filling it.
3. Input the sample selection request. Compare whether the "yes" branch executes. A pending review does not demonstrate the absence of operating authority. Signing, reaching cooperation, and contract effectiveness are three distinct facts, and the sample provides none of them.

Across all three checks, the material being compared must share subject, period, and field. Only mutually exclusive values in the same field constitute a contradiction. A field that is not stated, or evidence that covers only a related stage, is unsupported or pending verification.
