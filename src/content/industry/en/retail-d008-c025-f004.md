# Brand outlet operations: vector indexes for multilingual work

## What the documents look like

Outlet discount operations aim to clear past-season inventory rather than maintain a full-price new-arrival image. The working documents are discount approvals, slow-moving inventory lists, price tags and gross-margin worksheets. In cross-border and multilingual retrieval these materials frequently carry price tags in several languages, cross-border channel discount terms and margin calculations in different currencies, so retrieval has to match meaning across languages.

A semantic search relies on vector distance and can match a Chinese question to an English knowledge point. A knowledge base selected for association must use the same vector model as the others, so the actual model and its input types are checked first. One original data block can be linked to several indexes, and the index content is checked against the source text separately. Image retrieval depends on whether an image description or image vector was generated at ingestion time. An RRF merge combines results from several recall paths and is one stage of the retrieval chain. The minimum relevance value applies only during semantic search or after result reranking, and it is a filter threshold. The reference cap is measured in tokens.

A hypothetical paper case, labelled as such, provides the material for this page: on 10 March 2025 a channel clearance group at an outlet store submits a discount approval form. The source text reads: "This form covers 2024 autumn and winter slow-moving styles, discount range fifty to seventy percent, applicable stores are three East China outlet stores, approval status is pending review by the channel lead." A draft sentence reads: "This discount approval has been granted and the price tag change can be executed." The source shows only a pending status, so the draft sentence treats a pending item as granted, which the source does not support.

## Constraints at the vector indexes step

The knowledge base selected for association must use the same vector model. The model identifier and its input types are checked, and a different model is excluded from joint association. One original data block can carry several indexes, and each index is compared with the source text rather than assumed to cover it. Image retrieval depends on an index created at ingestion; uploading an image at query time does not create that index. RRF is a merge stage for mixed retrieval results, not a switch that is turned on. The minimum relevance value is a filter threshold that applies only in semantic search or after reranking, and it does not isolate businesses, categories or permissions. Retrieval is not authorization. The reference cap is counted in tokens, which differs from a top-k item count. A relevance score is not a category, entity or permission filter, and a similarity setting does not exclude unrelated businesses or unauthorized records. Where a field is not provided in a document, that field remains unknown.

## Three common errors

1. Treating a pending review as granted. The discount approval source text states that the status is pending review by the channel lead, while the draft sentence states that approval has been granted. The two values occupy the same status field and are mutually exclusive, so the draft sentence is not supported by the source.
2. Associating knowledge bases that use different vector models. When two knowledge bases carry different vector model identifiers, the identifiers do not match, so the non-matching one is excluded. No cross-model retrieval is run to compare missed recalls.
3. Treating a query-time image upload as an existing image index. Whether an image can be retrieved depends on whether the corresponding index was generated at ingestion time. A query-time upload does not constitute an ingestion index, and the missing record is recorded as a gap.

## How to verify the setup

1. Input the discount approval source text and the draft sentence above, and compare the approval status field. The source value is pending review and the draft value is granted. Because the two values are mutually exclusive in the same field, the draft sentence is not supported. This is a paper comparison, not a completed test.
2. Check the vector model identifiers of the two knowledge bases. Joint association is possible only when the identifiers match. When they differ, exclude the non-matching base and record the actual observation. Do not infer a runtime result from the exclusion.
3. Check the image ingestion record for an image vector index. When the record exists, the image can take part in image vector retrieval. When it is missing, record the gap and do not claim that a query-time upload replaces it.

The empty-reference output remains an array whose length can be zero, so a downstream design can be checked against an explicit paper input of an empty array.
