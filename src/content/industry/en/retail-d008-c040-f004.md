# Customer-service knowledge: multilingual work with vector indexes

## What the documents look like

For multilingual work in Customer-service knowledge, this page examines FastGPT vector indexes. Trace a return-policy exception through Chinese and English indexes without turning suggested replies into completed refunds. The examples are hypothetical.

## Constraints at the vector indexes step

A hypothetical support exercise pairs Chinese and English wording that requires the condition of an opened item to be checked before a separate reply decides whether it can be accepted. An older response example covers unopened goods only. A proposed English search entry for an opened return must preserve both the item condition and the pending reply. The word opened describes the subject; it supplies no acceptance decision. Identify which original the entry targets and whether the returned passage retains the prerequisite. Several language entries may point to one original, but their presence establishes neither an accurate exception translation nor permission to borrow the unopened example’s conclusion.

## Configuration and implementation checks

| Support-language check | Original in this exercise | Evidence to retain |
| --- | --- | --- |
| Exception | Opened items require a condition check | Retain the prerequisite in both languages. |
| Pending action | Acceptance needs a separate reply | Identify the respondent and any decision for this item. |
| Older example | Unopened goods only | Record its condition separately from this question. |
| Index target | English entry and actual original | Trace opened to a passage covering that condition. |
| Case outcome | Policy versus refund receipt | Separate explanation of a rule from proof of execution. |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Embedding model` | Knowledge bases associated with one search node must use the same embedding model. |
| `Original data and indexes` | One original data block can have multiple indexes. |
| `Index content` | Index wording should be complete and focused. |
| `Image indexes` | Where image retrieval is used, inspect descriptions or image vectors. |
| `Version and result check` | After a change, reuse questions to compare originals. |

## Three common errors

- If an English entry turns a pending reply into accepted, compare both originals with the entry to locate where return acceptance was added.

- If an opened-item question retrieves only the unopened example, inspect the targeted original and applicable condition. Shared return vocabulary does not transfer the conclusion.

- If the returned passage requires a check but the answer announces a refund, compare candidates, the actual citation and response to find where the prerequisite disappeared.

## How to verify the setup

Ask in both languages what condition applies, whose reply remains pending and what is established now, following actual citations to the originals. After a reply for this item is supplied, check its product and request identity before identifying the newly supported conclusion. Check matching embedding models at the search node when it associates the relevant knowledge bases. Model consistency does not establish language equivalence. This paper exercise accepts no goods, approves no return and executes no refund. A retrieved policy is not a processing receipt for the actual case.
