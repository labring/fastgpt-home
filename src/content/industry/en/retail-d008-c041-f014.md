# Marketplace promotions: multilingual work with model connections

## What the documents look like

For multilingual work in Marketplace promotions, this page examines FastGPT model connections. Use campaign names and product wording to inspect bilingual delivery, distinguishing lexical variation from changed conditions. The examples are hypothetical.

## Constraints at the model connections step

Parallel campaign names in a registration form provide two points for a bilingual connection test. Inspect delivery of both texts and preservation of the same campaign subject. An English response does not establish reading of Chinese material. Matching a campaign name also does not show that a product’s function description was translated. If one language was lost before input, this run cannot validate the complete counterpart. Inspect actual input and source version before repeating the question.

## Configuration and implementation checks

| Connection or implementation check | Multilingual campaign material | Verification trace |
| --- | --- | --- |
| Campaign counterpart | Deliver Chinese and English subjects separately | Completeness of the actual request |
| Wording variation | Keep context for New Arrival and Latest Product | No direct eligibility or approval inference |
| Source completeness | A single input cannot establish comparison of both | Retain request and precise output |
| Function gap | A translated name is not a detailed counterpart | Locate missing original, translation or delivery |
| Retest boundary | Inspect added text under the same question and settings | No extension to price or approval conclusions |

## Three common errors

- If one language never arrives but bilingual reading is claimed, locate activity names and identities in input. Retain omissions; an English reply does not establish Chinese delivery.

- If New Arrival and Latest Product become eligibility or platform approval, inspect their contexts, activity and scope. Wording differences do not decide business acceptance.

- If a translated product name becomes reviewed functional detail, inspect actual counterparts. Distinguish absent original, absent translation and omitted delivery before obtaining material and retesting.

## How to verify the setup

An English product name does not establish a counterpart for detailed functions. Identify whether the original description, parallel version or actual delivered passage is absent, then obtain the corresponding material. Hold question and application settings constant when checking added text, retaining the subject and its restrictions. This text test does not presume processed scan images, provide an activity price or establish platform approval. Its connection result is limited to the input actually exercised rather than every source the task might eventually need.
