# Product listing reviews: citation tracing for multilingual work

## What the documents look like

This category handles advertising truthfulness and qualification display for platform product listings. It does not handle parcel delivery. The working materials are product title tables, detail-page assets, prohibited-word lists for advertising, and third-party quality inspection reports. Sources include the platform rule center and the brand asset library. Updates follow a weekly cycle and each new listing.

For cross-border materials and multilingual retrieval, these documents need a checkable original source. Title tables, assets, and reports frequently carry version differences, and citation tracing requires each citation to be tied to a specific file and its effective scope.

A hypothetical paper sample for this page: a product title table record states "subject: a cross-border e-commerce store; object: portable juicer title and detail page; status: draft awaiting compliance review; effective scope: March 2025 version." A proposed sentence reads "This product has obtained international certification and leads global sales." A handover request reads "Please retrieve the citation source for this title from the brand asset library and confirm whether it can be published directly."

## Constraints at the citation tracing step

The knowledge base search node can associate one or more knowledge bases that share the same vector model. Its output is an array of citations, and the length may be zero. When the array is empty, the output path still runs through.

Semantic retrieval supports cross-language understanding, so a Chinese question can match an English knowledge point. This gives a path for checking multilingual titles and assets. Full-text retrieval suits exact queries such as numbers, model designations, and proper nouns. Hybrid retrieval merges multiple result paths through RRF. Result reranking uses a ReRank score. The minimum relevance value takes effect only under semantic retrieval or result reranking. The citation limit is measured in tokens.

The retrieval step returns citations. It does not perform authorization decisions or business approval. A retrieval hit is not a publication authorization. The proposed sentence about international certification and global sales leadership must be compared against the quality inspection report and the asset original text. Publication still requires compliance review.

The minimum relevance value is a filter threshold, not an entity filter or a permission filter. It cannot be used to exclude unrelated businesses or unauthorized records. Knowledge bases with different vector models cannot be associated together; the model identifier is checked first, and non-matching bases are excluded. No cross-model retrieval is performed to compare missed recalls.

## Three common errors

1. Treating a retrieval hit as publication authorization. The proposed sentence "has obtained international certification and leads global sales" needs comparison against the quality inspection report and the asset original text. Retrieval returns citations only; publication still requires compliance review, and the retrieval result does not constitute authorization.

2. Treating minimum relevance as an entity or permission filter. This value takes effect only under semantic retrieval or result reranking. It cannot be used to exclude unrelated businesses or unauthorized records.

3. Forcing association of knowledge bases with different vector models. Only bases with the same vector model can be associated together. When identifiers differ, exclude them first and record the observation. Do not invent missed-recall outcomes from a forced association.

## How to verify the setup

1. Input the hypothetical title table original text and the proposed sentence. Compare the subject, object, status, and effective scope of "international certification" in the proposed sentence against the quality inspection report original text. A contradiction is judged only when the same field has clearly mutually exclusive values. When a field is not stated, record it as pending verification.

2. Input the handover request. Compare "publish directly" in the request against the citation array returned by retrieval. If the citation array is empty, record it as no source retrieved. The downstream design needs to accept an empty array; do not judge it as a system error.

3. Input a Chinese question about the same title and the English asset. Observe whether semantic retrieval returns the corresponding citation, and compare each citation original text against the displayed content. Do not substitute answer fluency for source evidence. Do not guarantee a first-hit match or full recall.
