# Marketplace advertising: multilingual work with workflow routing

## What the documents look like

For multilingual work in Marketplace advertising, this page examines FastGPT workflow routing. Advertising plans, keyword reports and attribution wording travel separately. Translation must preserve the difference between an assigned relationship and evidence establishing an operating cause. The examples are hypothetical.

## Constraints at the workflow routing step

An advertising-material workflow can collect plans, keyword reports and attribution wording with existing translations, without budgets, outcome figures or real audience data. Proposed input lacks current execution and complete transaction evidence. Preserve those gaps. Attribution describes a recorded relationship rather than automatically proving cause. Choices arrange definitions, original reading or execution sources without establishing effects through selection.

## Configuration and implementation checks

| Multilingual workflow check | Proposed material | Actual handoff evidence |
| --- | --- | --- |
| Execution stage | Plan separate from actual record | Not translated as executed |
| Attribution meaning | Assigned relationship separate from cause | Inspect definition and evidence |
| Activity period | Report subject and present question | Other-period source not mixed |
| Evidence handoff | Definition, execution or transaction source | Connected branch actually receives it |
| Formal business | Separate advertising, writing and release | Organization is not effectiveness proof |

### Documented conditions

| Documented item / implementation check | Condition |
| --- | --- |
| `Form input node` | Submitted form values pass to subsequent steps. |
| `User-selection node` | Execution follows the connected selected branch. |
| `Interaction-state check` | Inspect waiting and post-submission states. |
| `Output handoff check` | Compare values passed between steps. |
| `External-operation responsibility` | External business operations require an implementation. |

## Three common errors

Planned advertising translated as executed needs this run’s actual record. Assigned attribution described as causation needs the definition and supporting relationship. Another activity’s report needs subject and period checks. These concern execution, explanatory scope and source correspondence rather than certainty in wording.

## How to verify the setup

Retain originals, translations, activity period, definitions and received text. Repeat with corresponding execution or transaction sources and keep conclusions within evidence. Test each connected yes branch; recorded interaction is not passed effectiveness verification. Advertising changes, writes, access and report release need actual procedures and receipts. Organization establishes neither effective campaigns, generated growth nor audited attribution.
