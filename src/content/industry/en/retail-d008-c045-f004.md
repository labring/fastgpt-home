# Seller ratings management: multilingual work with vector indexes

## What the documents look like

For multilingual work in Seller ratings management, this page examines FastGPT vector indexes. Trace review subjects, suggested replies and appeal progress to the appropriate originals. The examples are hypothetical.

## Constraints at the vector indexes step

A hypothetical store note says a review describes a dent in the packaging while the product’s condition remains to be checked. A reply draft suggests requesting photographs, and an appeal note records preparation of material. The English counterpart must preserve the packaging/product distinction and the absent photographs. An index headed damaged item would expand the affected subject when the original describes only packaging. Follow that entry to the original and retain the unresolved product condition. A suggested request for images does not establish their receipt. The review, proposed reply and appeal preparation remain separate records even when they concern the same order.

## Configuration and implementation checks

| Review-language check | Hypothetical record | Inspection |
| --- | --- | --- |
| Affected subject | Dented packaging; product unchecked | Preserve the distinction in both languages. |
| Photograph stage | The draft suggests requesting images | Check the attachment inventory for actual receipt. |
| Appeal stage | Material under preparation | A platform outcome needs its own receipt. |
| One order, distinct records | Review, reply draft and appeal note | Inspect record type before combining conclusions. |
| Added evidence | Photographs and platform receipt | Trace which state each new source supports. |

| `Original data and indexes` | One original data block can have multiple indexes. |

## Three common errors

- If packaging damage becomes product damage in an English entry, compare the review with the indexed subject to locate the expansion.

- If a proposal to request photographs becomes images received, compare the draft, attachment inventory and actual citation to locate the invented event.

- If preparing an appeal becomes completed platform handling, inspect the actual receipt for this appeal. Preparation material supplies no decision.

## How to verify the setup

Ask in both languages which object the review describes, whether photographs are available and which appeal stage has evidence. When images or receipts arrive, check order identity, record type and creation time separately. A platform receipt does not itself establish a product inspection outcome. Retain each entry’s original and language version so an expanded English meaning can be traced through the index and citation. Inspect matching embedding models where one search node associates the relevant bases. Review facts and platform status still require their respective evidence. This exercise submits no appeal and decides nothing about deleting a review.
