# Wholesale stall trading: multilingual work with vector indexes

## What the documents look like

For multilingual work in Wholesale stall trading, this page examines FastGPT vector indexes. Preserve the unit subject, purchase intent and delivery evidence in bilingual stall-trading entries. The examples are hypothetical.

## Constraints at the vector indexes step

A hypothetical stall-trading enquiry asks about a whole carton while leaving its assortment to be checked. The English counterpart uses carton enquiry and keeps the assortment pending. A sample note records inspection of one style only. It establishes neither a uniform carton nor a completed purchase. An entry changing carton enquiry to case order introduces an order stage; treating case as a product model would also change the unit’s role. Preserve the enquiry’s scope and unresolved composition in the original. An index can locate relevant wording without deciding carton contents or actual dispatch.

## Configuration and implementation checks

| Stall-language check | Original in this task | Specific action |
| --- | --- | --- |
| Unit subject | Whole-carton enquiry | Distinguish the carton from a model name. |
| Assortment | Still to be checked | Do not infer a uniform style. |
| Transaction stage | An enquiry only | Find this purchase’s confirmation separately. |
| Sample note | One style inspected | Do not extend to the carton or order outcome. |
| Additional documents | Packing list and order | Check batch/subject before answering composition and state. |

### Documented conditions

| Documented item / implementation check | Condition |

| `Embedding model` | Knowledge bases associated with one search node must use the same embedding model. |
| `Original data and indexes` | One original data block can have multiple indexes. |
| `Index content` | Index wording should be complete and focused. |

## Three common errors

- If a whole carton becomes a carton of one style, compare the enquiry with the pending-assortment sentence to trace the added uniformity.

- If viewing a sample becomes a confirmed purchase, inspect the sample note and separate order-confirmation evidence. The actions need their own records.

- If case becomes a model name and targets another product, inspect its unit role in the sentence and the targeted original. One shared word does not identify a physical item.

## How to verify the setup

Ask in both languages whether the transaction remains an enquiry, whether assortment is stated and what the sample note establishes. Follow the actual targets. When a packing list or order record arrives, check batch and subject identity, inspecting composition and transaction status separately. Neither source supplies every fact. Multiple indexes for one original should retain carton as the counting subject. After checking embedding consistency within the associating search node, continue inspecting the citations. This exercise writes no order and confirms no stock, purchase or delivery outcome.
