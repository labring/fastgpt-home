# Complaints and official replies: document chunking for multilingual work

## What the documents look like

Complaints and official replies are directed at a platform or a regulator, so the material carries formal evidence and remediation language. The working set includes complaint tickets, regulator inquiry letters, order evidence, and remediation reports. These materials update per case rather than on a fixed cycle, and they arrive from separate places: the 12315 platform, the platform complaint center, customer service chat, and the order system. In cross-border handling, one case frequently holds a Chinese-language ticket alongside a foreign-language inquiry letter, and the transaction date, product name, and amount must be aligned item by item across those documents. Parsing and chunking decisions made at intake determine whether later retrieval can link a specific question in an inquiry letter to the matching order evidence and remediation paragraph.

Two features of this material shape the work. First, multilingual content depends on cross-language semantic understanding during vector retrieval, so a chunk boundary that separates a condition from the statement it governs will break the link between the inquiry question and its answer conditions. Second, the same source record can map to more than one index, and a long text can be given several indexes to improve recall precision. Source records and retrieval indexes are separate objects: an upload completing and a training or index state becoming usable are different facts.

## Constraints at the document chunking step

Semantic retrieval suits natural-language questions; full-text retrieval suits identifiers, model numbers, and proper nouns; hybrid retrieval merges multiple result paths through RRF; result reordering requires a ReRank model and is enabled according to settings. Image retrieval requires the corresponding image input and model capability. Retrieval does not perform authorization judgment. The minimum relevance value is a filter threshold and does not isolate entities or permissions.

Hypothetical paper exercise sample: the source text reads, "Complaint ticket T-2041 records that the consumer placed an order on 12 March 2025, order number A-88231, product a portable juicer, and claims the delivered goods were missing the cup lid. Regulator inquiry letter R-117 requires the store to submit a remediation report within ten working days of receiving the letter, and to explain the delivery and inspection records for that order." The draft sentence to be assessed is, "The store has submitted the remediation report, and the regulatory matter is closed." The subject needed for the determination is the store; the object is the remediation report and the status of the regulatory matter; the period is the ten working days required by the letter; the effective scope is the actual submission and acceptance records.

## Configuration and implementation checks

| Configuration item | Applicable setting or check on this page | Relation to the sample |
| --- | --- | --- |
| Search mode | Semantic, full-text, or hybrid retrieval, chosen by material language and question type | Foreign-language inquiry questions use semantic retrieval; order number A-88231 uses full-text retrieval |
| Reference limit | Maximum tokens referenced per search, set against actual material length | The ticket and letter are long, so the limit must cover both the question sentence and the condition sentence |
| Minimum relevance | A 0-1 value, effective only under semantic retrieval or result reordering | Filters low-relevance fragments; does not perform permission isolation |
| Question optimization | Coreference removal and question expansion in multi-turn dialogue, adding one model call | Completes the subject when a follow-up asks about the remediation deadline |
| Result reordering | Requires a ReRank model, enabled according to settings, score used for filtering | Reorders remediation paragraphs when candidates are numerous |
| Index state check | Distinguish source records from indexes; confirm actual training and index state | A completed upload does not mean retrieval has updated |

Hypothetical trial starting point for this page: set the reference limit to a token quantity that covers the full ticket and letter, because in this case the question sentence and the condition sentence are distributed across two documents. The comparison object is whether the actual recalled content after chunking contains the complete condition.

## Three common errors

1. Treating a successful upload as an updated retrieval state. Input: a notice that the remediation report upload completed. Comparison: the actual training and index state. Observable result: whether retrieval can recall the content of that report.
2. Treating a retrieval result as a basis for authorization or case closure. Input: the draft sentence "the regulatory matter is closed." Comparison: the actual submission and acceptance records. Observable result: whether acceptance evidence exists for the same subject and the same period.
3. Treating minimum relevance as a permission or entity filter. Input: a cross-store query. Comparison: whether returned content belongs to the target store. Observable result: a similarity setting does not isolate unrelated records.

## How to verify the setup

1. Input order number A-88231 and the product name from the source text, use full-text retrieval, compare whether the returned fragment contains the delivery and inspection records for that order, and observe whether the result hits the corresponding source record.
2. Input the draft sentence "the store has submitted the remediation report, and the regulatory matter is closed," compare whether the source text states a submission time and an acceptance status, and observe whether the result falls into supported, unsupported, or pending verification.
3. Input an empty-result scenario, using the paper input [] to check how the downstream design handles no recall, compare the retrieval return against the downstream handling logic, and observe whether the result explicitly records the gap.
