# Channel diversion reviews: multilingual work with workflow routing

## What the documents look like

For multilingual work in Channel diversion reviews, this page examines FastGPT workflow routing. Multilingual distribution leads retain dispatch, destination and unresolved state against the same batch originals. The examples are hypothetical.

## Constraints at the workflow routing step

A proposed Chinese record identifies this batch’s dispatch warehouse while leaving destination unverified. The English exercise counterpart preserves that gap. History concerns another batch’s sales territory. Routes may organize both originals or request destination material, retaining batch and location roles. Dispatch origin is not sales territory, and a missing destination establishes no absence of cross-area movement. Changing language supplies no investigation result and transfers no older-batch scope.

## Configuration and implementation checks

| Language route | Task subject | Check |

| Destination | Current batch unresolved | Retain gap |
| Older record | Another batch/area | Do not transfer |
| Bilingual handoff | Same state | Inspect received input |

## Three common errors

Dispatch location promoted to sales territory needs location roles checked. Another batch’s destination applied here needs subject and period inspected. Pending Chinese wording becoming an established English finding needs both originals and actual delivered input compared. These concern role, batch and state.

## How to verify the setup

Ask which location has evidence and which batch remains unresolved, comparing bilingual route inputs and citations. Verify batch identity before adding destination material; an investigation finding still requires its own evidence. Real system reads or writes need separate authority and receipts. Language branches perform no investigation or penalty. Keep dispatch location, destination and evidence status separately visible in bilingual comparison. If destination evidence is missing, both language versions should point to that same open question, without introducing a confirmed sales territory.
