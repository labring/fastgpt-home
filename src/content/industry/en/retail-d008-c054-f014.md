# Channel diversion reviews: model connections for multilingual work

## What the documents look like

Channel diversion review concerns regional and price order. It does not handle rebate amounts, which belong to a separate category. The working materials are diversion complaint forms, anti-counterfeit code records, penalty notices and investigation photographs. In cross-border and multilingual retrieval, one batch of materials can hold complaint descriptions in different languages, price screenshots from different regions and code lists in different formats, so the language and field structure of each item need to be confirmed before retrieval. Data arrives weekly or irregularly, and retrieval configuration does not depend on a scheduled trigger. Tracking the goods source code and comparing low-price shops are the two most time-consuming steps that fall inside this page's retrieval scope; carrying out a penalty is a downstream business action.

## Constraints at the model connections step

Model connection depends on AI Proxy. From V4.17.0, the App and any Admin service that reuses App/Service configuration must set `AIPROXY_API_ENDPOINT` and a non-empty `AIPROXY_API_TOKEN`; a missing item causes startup validation to fail. `AIPROXY_API_ENDPOINT` takes the AI Proxy service root address and does not append `/v1`. The system needs at least one language model and one index model to work normally. The index model builds indexes over text chunks; the language model handles dialogue and multimodal image recognition. A model ID is the value of the `model` field in the request body and is globally unique. Model mapping can map the model FastGPT requests to the actual upstream model. Channel priority runs from 1 to 100, and a larger value is more likely to be selected first. The same-vector-model retrieval association requirement applies to knowledge base and vector store configuration and does not extend to business registry sites or other external systems. Semantic recall and relevance do not carry permission or entity isolation duties, and a retrieval result does not constitute authorization.

Hypothetical paper test case: a cross-border diversion complaint form reads: "Complainant: a regional distributor; subject of complaint: an e-commerce shop; codes involved: A-2024-001 to A-2024-050; discovery date: March 2024; complaint content: the shop sells products corresponding to the above codes at a low price outside the authorized region." One draft sentence to be judged reads: "The shop has already committed cross-region diversion, and a penalty should be executed immediately." Checking that draft against the form, the form states only the complaint content and the code range, and states no investigation conclusion and no penalty decision, so "has already committed" and "should be executed immediately" are not supported by the material.

## Configuration and implementation checks

| Configuration item | Hypothetical starting point for this trial | Reason for the choice and comparison method |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | Assume the AI Proxy service root address is entered, without `/v1` | The official requirement is the root address; compare with an address containing `/v1` and confirm whether startup validation passes |
| `AIPROXY_API_TOKEN` | Assume a non-empty administrator token consistent with the server is entered | The official requirement is non-empty and consistent; compare with an application API key and confirm it cannot substitute |
| Index model | Assume one index model is enabled | The official requirement is at least one index model; compare with the not-enabled state and confirm knowledge base availability |
| Language model | Assume one language model is enabled | The official requirement is at least one language model; compare with the not-enabled state and confirm dialogue availability |
| Model mapping | Assume a FastGPT model ID is mapped to the actual upstream model | The official text describes the mapping relation; compare with an unmapped request and confirm the upstream `model` value |
| Channel priority | Assume a value of 50 | The official range is 1 to 100; compare with a value of 1 and confirm the difference in first selection |

## Three common errors

1. Entering `AIPROXY_API_ENDPOINT` as a full request address that contains `/v1`. Input: an address containing `/v1`. Compare: the official root-address format. Observable result: whether startup validation fails.
2. Treating semantic recall relevance as a permission or entity isolation measure. Input: a cross-region retrieval request. Compare: the returned records against the authorized scope. Observable result: whether unauthorized records appear, confirming that relevance does not carry isolation duties.
3. Treating "has already committed" and "should be executed immediately" in the draft sentence as confirmed facts. Input: the sample complaint form text and the draft sentence. Compare: whether the material states an investigation conclusion and a penalty decision. Observable result: whether the draft sentence exceeds what the material supports.

## How to verify the setup

1. Input the sample complaint form text and the draft sentence. Compare "has already committed cross-region diversion" in the draft with the complaint content field in the original. When the original states no investigation conclusion, that part of the draft is unsupported and the evidence gap must be recorded.
2. Input the sample complaint form text and the draft sentence. Compare "should be executed immediately" in the draft with whether the original states a penalty decision. When the original states no penalty decision, that part is unsupported and its pending-verification state must be kept.
3. Input the code range A-2024-001 to A-2024-050 from the sample complaint form. Compare whether the retrieval return covers that range. If the return is empty, use the paper input `[]` to check the downstream design, without claiming that a fictional rule necessarily returns `[]` on retrieval.
