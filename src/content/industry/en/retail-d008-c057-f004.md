# Near-expiry markdowns: multilingual work with vector indexes

## What the documents look like

For multilingual work in Near-expiry markdowns, this page examines FastGPT vector indexes. Distinguish batch-label records from proposed handling without inferring saleability or completed action. The examples are hypothetical.

## Constraints at the vector indexes step

A hypothetical fresh-goods note records the batch label while leaving the handling plan for review. The English counterpart retains recorded batch label and pending plan review. An older display sheet covers a previous batch without confirming handling of this one. An entry changing label recorded into discount applied would promote recordkeeping to an executed action. Inferring that the goods remain saleable would also exceed the material. Dates, batch identity, appearance records and handling decisions serve different purposes. Where no physical check is supplied, identify which recorded fields the evidence actually supports. This example gives no assessment of food condition or fitness for consumption.

## Configuration and implementation checks

| Batch-handling translation check | Hypothetical material | Inspection action |
| --- | --- | --- |
| Registration | Batch label recorded | Add no completed handling. |
| Plan stage | Arrangement under review | Inspect this batch’s actual decision. |
| Batch identity | Previous display sheet | Do not use it as current-state evidence. |
| Label scope | Paper information only | Add no saleability or physical finding. |
| Added records | Inspection and execution have their own subjects | Check batch, record type and event time. |

## Three common errors

- If batch registration becomes completed handling in an entry, compare the recorded statement, plan and execution record for this batch to locate the added action.

- If a previous display sheet determines this batch’s state, inspect batch and product identities. A matching product name does not transfer the conclusion.

- If label wording alone becomes saleability, inspect applicable checking evidence and a decision. An index hit supplies no physical-condition finding.

## How to verify the setup

Ask in both languages what was recorded, whether the plan was reviewed and which batch has evidence of action. Trace each actual citation. When inspection or handling records arrive, check batch identity and record type before updating their respective conclusions. Registration time does not itself establish inspection time. Preserve batch and stage limits in multiple entries for one original. Check embedding consistency at the search node associating the bases. The exercise tracks documents without executing a markdown, disposal or listing and does not replace actual goods checks or business decisions.
