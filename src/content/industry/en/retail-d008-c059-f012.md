# Store cold-chain receiving: document chunking for multilingual work

## What the documents look like

Cold-chain receiving at a store turns on transport temperature and the arriving batch. It does not cover origin pricing. The data comes from reefer vehicle temperature control, the WMS, the store receiving system and quality-inspection photographs. The daily documents are cold-chain temperature records, arrival acceptance forms, rejection forms and supplier delivery notes. Each arriving batch produces a temperature record and an acceptance result, and rejection reasons are registered item by item. These materials commonly mix Chinese and English product names, batch numbers and temperature ranges, so parsing and chunking quality decides whether later multilingual retrieval can locate the correct batch.

Three facts shape this page. First, the temperature record carries a measurement time, a measurement point and a limit; these belong together, because a retrieved fragment that holds a number without its limit cannot support a judgment. Second, the same source data can map to more than one vector index, so index count and content length are traded against each other. Third, retrieval is not authorization: a delivery note appearing in search results does not mean the batch has been released.

## Constraints at the document chunking step

Segmentation has to keep a condition in the same chunk as the content it constrains. If measurement time, measurement point and limit are split apart in a temperature record, the retrieved fragment lacks the basis for a decision. A single set of source data may correspond to several vector indexes, and the number of indexes has to be weighed against content length. Retrieval does not grant permission. The fact that an acceptance form is retrieved does not mean that batch has been released.

Hypothetical drill sample. A supplier delivery note contains three sentences of source text: "Deliverer: Beiling Cold Chain Distribution; Receiving store: Qinghe Store No. 3; Arriving batch: LL-240517-A; Product: chilled beef; Arrival temperature record: 2.8°C; Acceptance status is pending quality inspection." One draft sentence is submitted for judgment: "This batch has passed acceptance and may be placed on sale." The subject needed for the judgment is the deliverer, the store and the batch; the object is chilled beef; the status is pending quality inspection; the valid scope is limited to the batch stated on that delivery note. The draft sentence presents a pending quality-inspection status as passed acceptance, which does not match the source status, so the sentence is unsupported.

## Configuration and implementation checks

| Configuration item | Hypothetical trial starting point for this page | Reason for the choice and comparison method |
| --- | --- | --- |
| Search mode | Hybrid search | Product names and batch numbers need exact hits while temperature descriptions need semantic matching; compare recall coverage against semantic search alone |
| Minimum relevance | 0.45 | Takes effect only in semantic search or with result reranking; compare false recalls and missed recalls against 0.3 and 0.6 |
| Citation limit | 1200 tokens | Controls cited volume by tokens; compare fragment completeness against 800 and 2000 |
| Question optimization | Enabled | Completes references in consecutive batch follow-up questions; compare retrieval hits against disabled |
| Result reranking | Enabled | Reorders candidates a second time; compare ordering stability against no reranking |
| Index verification | Checked batch by batch | Confirms training and index state; compare against relying on upload success alone |

RRF is a fusion step for mixed results, not a switch to be turned on. Image retrieval requires an image input and matching model capability, and reranking requires a model that is enabled in the settings. Optional paths in the overall flow are not executed on every request.

## Three common errors

1. Reading a pending quality-inspection status directly as passed acceptance. Input: the delivery note source text and the draft sentence. Comparison: the acceptance status field. If the draft sentence and the source text differ, the sentence is unsupported.
2. Treating a retrieval hit as release authorization. Input: the search result and the authorization record. Comparison: whether an independent approval exists. When the approval record is absent, the release state remains unverified.
3. Associating libraries that use different vector models. Input: each library identifier and its vector model identifier. Comparison: whether the models match. When they do not match, exclude that library and record the observation; do not run a cross-model retrieval comparison.

## How to verify the setup

1. Input the hypothetical delivery note source text and the draft sentence. Compare the acceptance status field. When the draft sentence and the source status differ, output unsupported; the sentence may be cited only when they agree. Expected result stated, not tested.
2. Input batch number LL-240517-A and a temperature description, using full-text search and semantic search separately. Observe whether the same temperature record chunk is recalled. When it is not recalled, record the gap and check the index state.
3. Input a paper empty result `[]` together with a downstream handover request. Compare whether the downstream process treats it as an empty result. If the downstream process releases the batch directly, record the design gap. Do not claim that a rule-based retrieval must return an empty result.

Material changes require rechecking the actual training and index state; upload success is not the same as retrieval having been updated. Where a field is not stated in the source, or only related-stage evidence exists, the status is unsupported or unverified rather than contradicted. A pending review does not show that operating permission is absent. Signing, reaching cooperation and contract effectiveness are three separate facts. Authorization or effectiveness clauses are not supplied to force a definite answer; the evidence gap stays open.
