# Fresh-food weighing and sorting: model connections for multilingual work

## What the documents look like

Fresh-food weighing and sorting sits inside warehouse fulfilment. The work turns on weight and specification rather than on advance order aggregation. The materials that circulate are sorting task sheets, weighing labels, short-weight compensation forms and quality inspection records. In cross-border material and multilingual retrieval work, these materials are read by a model, compared across languages, and returned as a draft that a person can check. Updates arrive per order and daily. One task corresponds to one sorting task sheet, while weighing labels and quality inspection records are produced alongside that order.

Multilingual retrieval requires that the same batch of materials keeps consistent identifiers across languages. Model connection and configuration therefore has to settle identifier and capability matching before materials enter the retrieval scope. The materials listed in the brief are the only ones this page treats as inputs.

## Constraints at the model connections step

Model connection depends on the AI Proxy service. In the shared App and Admin configuration, `AIPROXY_API_ENDPOINT` holds the service root address and does not carry a `/v1` suffix. `AIPROXY_API_TOKEN` holds a non-empty administrator token that matches the server side; an application API key does not substitute for it. A missing value in either field causes startup validation to fail.

Model capability is checked against the input the application actually needs. Multimodal input, tool calling and thinking configuration are each verified separately. Parameters are set in the application or node configuration, and a same-named field on a compatible chat interface is not assumed to override orchestration.

Retrieval association requires the same vector model. Datasets that use different vector models cannot be associated together. The check is to confirm the identifier and exclude the ones that do not match, then record what was observed. A relevance score does not act as a category, entity or permission filter, and retrieval does not confer authorization.

## Three common errors

1. Entering a full request address in `AIPROXY_API_ENDPOINT` with `/v1` appended. The input is the configured value; the comparison is the documented example format; the observable result is whether a path is appended to the address.

2. Using an application API key as `AIPROXY_API_TOKEN`. The input is the token value; the comparison is the server-side administrator token; the observable result is whether startup validation passes.

3. Associating datasets that use different vector models. The input is the dataset identifier; the comparison is the vector model identifier; the observable result is whether the identifiers match. When they do not match, exclude that dataset and record what was observed.

## How to verify the setup

Hypothetical paper exercise sample. The source material reads: "Sorting task sheet A-001, object batch B-2024, status pending sorting, effective range 2024-06-01 to 2024-06-30; weighing label T-001 corresponds to batch B-2024, status printed." The proposed draft sentence reads: "A-001 has completed sorting and generated a compensation form." The pending request reads: "Please confirm whether the compensation form for A-001 has been generated."

- Check one: the input is the source material above together with the proposed draft sentence. The comparison is the status field "pending sorting" for A-001 in the source. The observable result is that the draft sentence claims completed sorting, which does not match the source status field, so the sentence is unsupported.

- Check two: the input is the pending request above. The comparison is whether a compensation form record appears in the source. The observable result is that the source does not state a compensation form, so the evidence gap remains missing and generation cannot be determined.

- Check three: the input is the source material above. The comparison is the correspondence between batch B-2024 and weighing label T-001. The observable result is that both carry the same batch identifier and T-001 shows status printed. When the identifiers differ, exclude the association and record what was observed.

These checks test the named primary task of drafting and comparing proposed copy against supplied source wording. They do not test identity certification, report analysis or any other task. A pending request is not approval, and an offered option is not execution.
