# Livestream sample inspections: model connections for multilingual work

## What the documents look like

Sample inspection for livestream selling happens before a broadcast. The work decides whether a product can be sold and whether it suits on-camera display. The working materials are supplier files, testing-agency reports, platform negative lists, and historical return rates. Day to day, the team handles sample evaluation forms, quality inspection reports, supplier qualifications, and prohibited-item lists. In cross-border work the same material may arrive in more than one language, so retrieval has to cover multilingual text. This page addresses model connection and configuration only, and does not construct business features that lack a documented basis.

## Constraints at the model connections step

The system needs at least one language model and one index model to operate normally. From V4.17.0, AI Proxy is a required dependency. The App and any Admin service that reuses App/Service configuration must both set `AIPROXY_API_ENDPOINT` and a non-empty `AIPROXY_API_TOKEN`; missing either one causes startup validation to fail. `AIPROXY_API_ENDPOINT` takes the service root address and does not append `/v1`. The model ID is the value of the `model` field in the request body and is globally unique; the model name is for display and can be customized. One model can be configured across different channels to achieve load balancing. Retrieval relevance does not carry permission or entity-isolation duties, and the same-vector-model requirement for a retrieval library is limited to vector retrieval association; it does not extend to external systems.

Hypothetical paper exercise: a quality inspector submits a draft sample evaluation form. Two source sentences read, "The third-party testing report provided by the supplier states that this batch of samples meets the category requirements outside the platform prohibited-item list; the report was issued on March 10, 2026, and is valid until September 10, 2026," and "The supplier qualification certificate is in a pending-review state and platform admission confirmation has not been completed." The proposed sentence to be judged is, "The supplier qualification has passed platform review and the broadcast can be scheduled." The source only states that the qualification is pending review; the proposed sentence exceeds what the source supports.

## Three common errors

1. Treating the proposed sentence "The supplier qualification has passed platform review" as a verified fact. The source says the qualification is "in a pending-review state and platform admission confirmation has not been completed." Same subject, same field, mutually exclusive values, so the two conflict. Pending review does not demonstrate a lack of operating permission, and it does not equal review approval.
2. Treating the testing report validity period as a supply term. The source states only that the report is valid until September 10, 2026. It states no supply term, so that field is unsupported.
3. Treating a retrieval hit as authorized execution. Retrieval relevance does not constitute permission or entity isolation. Form values do not produce business verification, approval, or database writes.

## How to verify the setup

1. Input the two source sentences and the proposed sentence from the sample, then compare whether "pending-review state" and "has passed platform review" share the same subject and the same field. The condition is met only when the two values agree; here the values are mutually exclusive and the result should be recorded as a conflict.
2. Input the testing report validity field from the sample source and compare whether the source states a supply term. The source states none, so the result should be recorded as unsupported, not written as a negation or a conflict.
3. Input one authorization-boundary request and compare whether retrieval or the form produces an approval or a write. Retrieval and forms do not constitute authorized execution; when the downstream implementation is absent, record the evidence gap.
