# Livestream violation appeals: retrieval for multilingual work

## What the documents look like

Livestream violation appeals address penalties that have already been issued, so the work centers on reconstructing an evidence chain rather than preventing a future event. The typical materials are violation notices from the platform violation center, livestream recordings, customer service records, product qualification files, and draft appeal statements. In a cross-border setting, one violation event can produce a Chinese notice, a foreign-language qualification certificate, and a multilingual recording of the same session. Retrieval therefore has to reach the same business object across languages.

Material arrives irregularly, once per violation. Each appeal forms its own batch, so the retrieval scope is set by the notice and the session covered by that particular appeal. The three slowest steps are locating the violation segment, supplementing evidence, and drafting the appeal reasoning. Retrieval quality affects all three, because a missed qualification file or a missed recording segment forces manual rework before any statement can be drafted.

## Constraints at the retrieval step

The knowledge base search node can be linked to one or more knowledge bases that use the same vector model. Knowledge bases built on different vector models cannot be linked together. The vector model identifier of each candidate knowledge base is checked first, and any library that does not match is excluded before retrieval runs. Cross-model retrieval is not performed to compare what was missed.

Semantic retrieval works through vector distance and supports cross-language understanding, which allows a Chinese question to match a foreign-language knowledge point. Full-text retrieval depends on keyword hits and suits exact queries such as numbers, model designations, proper nouns, and error codes. Hybrid retrieval uses both semantic and full-text recall and merges the two result sets through RRF. Rerank requires a rerank model and runs when it is enabled in the settings; it produces a score between 0 and 1 that represents relevance between the retrieved content and the question.

The citation limit is measured in tokens per search. The minimum relevance value applies only under semantic retrieval or when result reranking is used. Image retrieval requires an image input and the corresponding model capability. When a search returns nothing, the output path still completes, and the cited content array can have a length of 0. Retrieval and similarity scores do not perform permission or entity isolation; a hit still needs human verification of authorization and business status.

A hypothetical drill sample is used below for illustration. A store receives a platform violation notice whose text reads: "During minutes 37 to 41 of this livestream, the displayed product qualification document was already expired. The penalty is a product broadcast ban and a deposit deduction." The same batch contains a foreign-language qualification document stating a validity period from January 1, 2024 to December 31, 2024, and a draft Chinese appeal sentence: "The qualification was still within its validity period on the day of the livestream, and the broadcast ban should be revoked." The item to be judged is whether the retrieved validity period and the session date stated in the notice support that draft sentence. The materials do not state the specific livestream date. That date is unsupported information, and the gap must be recorded.

## Configuration and implementation checks

| Configuration item | Hypothetical starting point for this drill | Reason for the choice and comparison method |
| --- | --- | --- |
| Linked knowledge bases | Link only the one knowledge base holding this appeal batch | Check the vector model identifier of each library first, exclude non-matching libraries, and do not run cross-model retrieval |
| Search mode | Run semantic retrieval first | Compare the returned content of semantic, full-text, and hybrid retrieval on the same question; no single mode is assumed to suit all materials |
| Citation limit | Set a token value that covers one full qualification document | This is a hypothetical starting point for this drill; compare short and long documents to see whether content is complete, then adjust |
| Minimum relevance | Label relevant and irrelevant samples first, then set a threshold | This value applies only under semantic retrieval or result reranking; compare returned items before and after filtering |
| Question optimization | Enable for short multilingual questions | Compare the original question with the optimized question and check whether the subject or session was altered |
| Result reranking | Enable when a rerank model is available and configured | Compare ordering before and after reranking; the rerank score runs from 0 to 1 and can be used for filtering |

## Three common errors

1. Treating a retrieval hit as an authorization basis. Retrieval returns cited content only and does not judge operating permission. Appeal submission and penalty revocation are business actions that require separate downstream system implementation. A pending review status does not demonstrate that operating permission is absent.
2. Linking knowledge bases that use different vector models. The node requires linked knowledge bases to share the same vector model. A library with a different model identifier is excluded and recorded, and the comparison of missed recall does not continue.
3. Treating an unstated date as a confirmed fact. The livestream date is missing from the sample, and the draft sentence claims the qualification was valid on that day. That claim is unsupported. It cannot be judged as contradictory or negated; the evidence gap is recorded instead.

## How to verify the setup

1. Input the sample notice text and the foreign-language qualification text, then retrieve the qualification validity field. Compare whether the returned content includes January 1, 2024 to December 31, 2024. A returned field that is not truncated counts as a complete citation.
2. Input the draft sentence "The qualification was still within its validity period on the day of the livestream" and compare whether the retrieval result includes the livestream date. When the result does not include that date, the expected outcome is unsupported, and the gap is recorded. The draft sentence is not judged as established.
3. Use a paper input of an empty array to check the downstream design, and observe whether the output path still completes when the cited content length is 0. This check addresses downstream handling and does not claim that a given rule always returns an empty result.
