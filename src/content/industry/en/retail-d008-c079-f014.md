# Central chain procurement: model connections for multilingual work

## What the documents look like

Central procurement and distribution records follow headquarters purchasing and outbound delivery. The working set is purchase contracts, replenishment plans, delivery notes and store requisitions, fed by ERP purchasing, WMS, store POS and supplier delivery data. Store price and display audits sit outside this scope.

Cross-border material and multilingual retrieval changes the shape of that set. A single purchase contract may carry clauses in more than one language, and replenishment plans and delivery notes may name the same field differently across regional systems. Retrieval therefore has to be checked per document language and per field meaning rather than once for the whole corpus. The brief gives a daily or weekly update rhythm; this page does not derive batch synchronization, full synchronization, real-time or transaction-triggered behavior from that rhythm.

## Constraints at the model connections step

Model connections run through AI Proxy. In the shared App/Admin configuration, `AIPROXY_API_ENDPOINT` holds the AI Proxy service root address without a `/v1` suffix, and `AIPROXY_API_TOKEN` holds the non-empty administrator token that matches the server configuration. An application API key does not substitute for that token. A missing value in either variable fails startup validation. The system needs at least one language model and one index model before it is usable.

The model ID is the value of the `model` field in the request body and is globally unique. The model name is a display label and can be customized. Model channels are separated by protocol type, and model mapping translates the model FastGPT requests into the model the upstream provider actually serves. Model status probing covers enabled system models only: a first failure is retried up to three times, so one round can make four attempts, and only four failed attempts produce an abnormal verdict. A successful attempt with response latency above 30s is recorded as high latency rather than normal.

Assumed paper exercise sample: a chain supply center processes one cross-border purchase contract in September 2026. The contract text contains two sentences: "This agreement takes effect on the date of signature by the authorized representatives of both parties and remains valid until 31 August 2027." and "The supplier shall complete shipment within 5 working days after receiving the delivery note." A replenishment plan states "expected arrival at warehouse before 20 September", and a store requisition is marked "pending review". The proposed sentence to be judged is: "This purchase contract has taken effect, and the supplier must ship before 20 September." The task is to check the field correspondence between that sentence and the contract text, the replenishment plan and the requisition.

## Configuration and implementation checks

| Configuration item | Assumed starting value for this exercise | Reason and comparison object |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | AI Proxy root address, no `/v1` | Compare against the documented requirement and confirm no path suffix is attached |
| `AIPROXY_API_TOKEN` | Non-empty administrator token | Compare against the server-side configuration and confirm the values match and the value is not an application key |
| Language model | At least one enabled | Compare against the requirement of at least one language model |
| Index model | At least one enabled | Compare against the requirement of at least one index model |
| Model mapping | Retrieval model ID mapped to the upstream model | Compare against the actual model ID inside the channel |
| Probe interval | 30 minutes as the assumed starting value | The documented range is an integer from 5 to 60 minutes; compare 30 against that range |

## Three common errors

1. Setting `AIPROXY_API_ENDPOINT` to a full request address that includes `/v1` or `/chat/completions`. Check: read the variable value, compare it against the documented instruction not to append `/v1`, and observe whether a path suffix is present.
2. Using an application API key in place of `AIPROXY_API_TOKEN`. Check: read the variable value, compare it against the server-side administrator token, and observe whether the value is empty or of the wrong kind.
3. Treating "expected arrival at warehouse before 20 September" in the replenishment plan as a firm shipment deadline for the supplier. Check: read the proposed sentence together with the contract text, compare whether "shipment within 5 working days" and "ship before 20 September" share the same party and the same field, and observe whether two distinct facts have been merged.

## How to verify the setup

1. Input the two contract sentences and the proposed sentence from the assumed sample. Compare whether "takes effect on the date of signature" and "has taken effect" share the same party, the same period and the same field; compare whether "shipment within 5 working days" and "ship before 20 September" sit in the same field. Observation: the proposed sentence joins the contract's effectiveness condition to a warehouse arrival date taken from the replenishment plan, and the contract text states no 20 September shipment deadline, so the sentence is unsupported. Expected result, not a completed test.
2. Input the store requisition marked "pending review". Compare whether "pending review" and "approved" occupy the same status field. Observation: pending review does not indicate approval, and it does not demonstrate that an operating permission is missing; the status remains to be confirmed.
3. Input an empty retrieval result, written as `[]`. Compare whether the downstream design treats an empty result as no match, and observe whether any undefined automatic business action is triggered. Retrieval carries no authorization function; an empty result does not mean access is denied, only that this retrieval returned no entries.

Authorization boundaries stay explicit throughout. A pending request is not an approval, an offered option is not an execution, and an unsigned termination is not a completed termination. Whether a contract has been signed, whether cooperation has been reached and whether a contract has taken effect are three separate facts. A quotation validity period does not state a supply deadline. Where a material does not record a field, that field stays unknown, and the gap is recorded rather than filled with an invented clause.
