# TikTok Shop US operations: operations handover with workflow routing

## What the documents look like

For operations handover in TikTok Shop US operations, this page examines FastGPT workflow routing. Return grading and settlement handover separates returned-item receipt, inspection findings and financial handling. One item’s record does not close every order. The examples are hypothetical.

## Constraints at the workflow routing step

Proposed handover says a return arrived, grading evidence remains missing, refund wording contains only an application and a settlement statement lacks this order’s relationship. Collect return identity and passages. A person can obtain grading evidence or inspect settlement mapping. Receipt establishes intake, not quality or refund outcomes. A statement title cannot supply fund movements. No amounts, rates or platform criteria are supplied, and choices do not determine item grades.

## Configuration and implementation checks

| Return-settlement handover | Proposed state | Evidence needed |
| --- | --- | --- |
| Returned item arrived | Intake only | Not completed grading |
| Grading evidence | Missing | Actual item inspection |
| Refund wording | Application, not execution | Real outcome |
| Settlement statement | Order relationship absent | Transaction mapping |
| Path subject | Order and return checked together | Not every after-sales case |

## Three common errors

Receipt promoted to grading needs this item’s actual inspection. Refund application promoted to execution needs the current handling result. Aggregate statements applied to this order need transaction correspondence. These inspect quality stage, fund action and ownership despite complete-looking source names.

## How to verify the setup

Inspect whether grading and settlement paths receive the corresponding order and returned item. Added inspection changes supported quality claims alone while refund handling remains pending. Appearance-only checks do not establish functionality. Refunds, stock classification and settlement writes need separate authority and receipts. Workflow records establish neither platform acceptance of a grade nor closure of every after-sales case.
