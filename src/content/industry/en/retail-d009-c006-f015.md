# General export declarations: retrieval for operations handover

## What the documents look like

General trade export declaration work produces, for each shipment, an export declaration form, a commercial invoice, a packing list and a contract. Practitioners include trading companies, customs brokers and documentation staff. The operational handover question is narrower than the customs question: which materials, actions and requests sit at which authorization state when a case moves between people.

Compared with general trade import declaration, the export side also affects export tax refund voucher matching. A declaration error can lead to document return and inspection, declaration discrepancies, and blocked refund processing. The materials also circulate in different versions during handover, so retrieval has to return the subject, the object and the valid scope together for a human to check the authorization state.

Sources named in the brief are the China International Trade Single Window, the customs code library, carrier bills of lading and enterprise ERP. Update frequency is per shipment.

## Constraints at the retrieval step

Retrieval returns reference content only. It does not constitute authorization, approval or a database write. The knowledge base search node can associate one or more knowledge bases that use the same vector model. Knowledge bases with different vector models cannot be associated together; when identifiers do not match, exclude the non-matching base, record the actual observation, and do not run a cross-model retrieval to compare missed recalls. Reference content is output as an array, and its length can be 0, meaning the downstream branch still runs when nothing is found. The minimum relevance value takes effect only under semantic retrieval or when result re-ranking is used; it is a filter threshold and does not perform permission or entity isolation. Hybrid retrieval merges multiple result paths through RRF, and RRF is a merging process rather than a switch that can be turned on. Image retrieval requires an actual image input plus the corresponding model capability, and re-ranking requires a model and must be enabled according to settings. The paths drawn in the overall document flow diagram do not mean every request executes all of them.

Hypothetical paper exercise sample: a documentation clerk at a trading company records a draft export declaration in a handover ledger. The material text reads: "Draft declaration number HYP-2024-EX-017, declaration date 12 June 2024, operating entity Company A, transaction terms FOB, freight field left blank, one commercial invoice and one packing list attached, contract not yet signed, refund voucher not matched." The draft sentence to be judged is: "This declaration has completed declaration and meets the conditions for refund voucher matching." The retrieval request is to look up the current state and attached material list for this document by number HYP-2024-EX-017. This sample is for paper review only and does not represent any real business action.

## Configuration and implementation checks

| Configuration item | Starting value for this hypothetical trial | Reason for the choice and comparison method |
| --- | --- | --- |
| Associated knowledge bases | Associate only the single-vector-model base holding export declaration templates and document checklists | Check whether the vector model identifiers of each base match; exclude those whose identifiers differ |
| Search mode | Run full-text retrieval by number first, then semantic retrieval by natural language description | Compare whether the reference content returned under each mode covers the subject and state fields |
| Reference upper limit | Start at a token amount covering one declaration plus two attached materials | Test with materials of different lengths to see whether content is complete, then adjust the value |
| Minimum relevance | Start at 0.5 | Label relevant and irrelevant samples first, observe whether the state field survives filtering, then adjust |
| Question optimization | Enable for follow-up questions containing references; disable for questions that already carry a complete number | Compare the original question with the optimized question and check whether the subject was altered |
| Result re-ranking | Enable according to settings when candidates are numerous | Observe whether the re-ranking score and the reference content share the same subject and the same period |

## Three common errors

1. Treating a retrieval hit as completed authorization. The input is the retrieval request for number HYP-2024-EX-017, and the comparison object is the reference content against the authorization field in the handover ledger. If the reference content contains only the document checklist and does not state an approval status, the result is unsupported and the declaration cannot be judged complete.
2. Comparing the draft sentence "has completed declaration" against the material text. The source text states only a declaration date and a draft number, and does not state a declaration receipt or release status. The same field lacks mutually exclusive values, so the statement is unsupported and the evidence gap must be recorded.
3. Forcing knowledge bases with different vector models into one association. The input is two bases whose vector model identifiers differ, and the comparison object is those identifiers. A mismatch means exclusion; do not go on to infer missed recalls or redundant returns as runtime outcomes.

## How to verify the setup

1. Input the retrieval request and the material text from the hypothetical sample, and compare whether the returned reference content contains the number, declaration date, operating entity and attached material list. If the reference content lacks the state field, record the gap and do not supply authorization clauses.
2. Input the draft sentence "This declaration has completed declaration and meets the conditions for refund voucher matching," and compare its same-field values against the material text. The source text does not state a declaration receipt or a refund voucher matching result, so the sentence is unsupported and remains pending verification.
3. Input a paper-level empty result and check whether the downstream design continues along the branch where reference content length is 0. Do not claim that a fictional rule retrieval necessarily returns an empty array; record only the output actually observed.
