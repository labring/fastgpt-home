# General import declarations: operations handover with workflow routing

## What the documents look like

For operations handover in General import declarations, this page examines FastGPT workflow routing. Import handover separates transport documents, arrival and this event’s handling result. Shipping paperwork is not release or warehouse-receipt evidence. The examples are hypothetical.

## Constraints at the workflow routing step

Proposed handover contains bill-of-lading and packing excerpts, a declaration draft and missing receiving evidence. Collect goods relationships and source status. A person can obtain correspondence or inspect handling progress. A transport document states its contents without establishing current arrival, release or warehouse receipt. Similar contract and invoice names cannot fill a batch relationship. Supply no amounts, import procedures or admission judgments.

## Configuration and implementation checks

| Import handover check | Proposed source status | Distinction |
| --- | --- | --- |
| Transport excerpt | Shipping document | Not a handling result |
| Declaration draft | Unresolved | Not actual submission |
| Goods relationship | Similar names insufficient | Actual correspondence |
| Receiving state | Record absent | Not completed intake |
| Subsequent handling | Release and receipt separately checked | Gaps do not decide permission |

## Three common errors

Transport paperwork promoted to release needs this event’s actual result. Similar names substituted for correspondence need genuine goods explanations. An unresolved declaration draft promoted to execution needs the actual submission record. These inspect result type, goods relationships and action stage independently of ended handover.

## How to verify the setup

Inspect actual passages received by both paths. Added goods mapping changes correspondence alone while receiving and handling retain their own gaps. An arrival description must not become completed warehouse intake. Formal declaration, release verification and warehouse receipt need separate authority and receipts. Interaction records establish neither handled goods nor permission or refusal inferred from absent sources.
