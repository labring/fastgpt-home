# Warehouse picking and packing: retrieval for operations handover

## What the documents look like

Warehouse picking, checking and packing handles order outbound. It does not handle supplier arrivals. The working materials are wave picking lists, checking records, shipping labels and packaging consumable sheets. These come from a WMS, an order system, an electronic label platform and weighing equipment. Updates occur per order and per hour, so handover status can change between one retrieval and the next. A retrieved record reflects one point in time only.

For operations handover, the question is which materials, operations and requests are authorised, which are still pending, and which have been completed. The retrieved text is the basis for that judgement. A retrieval hit does not itself grant or confirm an authorisation. The knowledge base search node can be linked to one or more knowledge bases that use the same vector model. Bases using different vector models cannot be linked together. Search modes are semantic retrieval, full-text retrieval and hybrid retrieval. Hybrid retrieval merges multiple result paths through RRF, which is a fusion process. The minimum relevance value takes effect only under semantic retrieval or when result re-ranking is used. The reference limit is measured in tokens. Reference content is output as an array and its length can be zero, so the downstream path still runs when nothing is retrieved. A similarity score does not perform permission or entity isolation.

## Constraints at the retrieval step

Handover materials change per order and per hour. A wave picking list, a checking record, a shipping label and a packaging consumable sheet can each carry a different status at the same moment. Retrieval returns text; it does not return an authorisation state. Where a material does not state an authorisation field, the only supportable conclusion is that the point remains to be verified.

Hypothetical drill sample. The original handover material text reads: "Checker A submitted the checking record for wave W-0310 on 10 March; status is pending review by the checking supervisor. Packaging consumable sheet P-0310 has been signed and confirmed by the packaging supervisor. Shipping label F-0310 has been printed and has not been scanned for handover." The draft sentence to be judged reads: "W-0310 has completed checking and handover, and A has obtained outbound operation permission." The subject, the status and the scope in that draft do not match the original text. The draft is unsupported.

Three constraints follow. First, the pending review status is not a completed check and is not a handover. Second, the signed packaging consumable sheet covers one material only; it does not extend to the wave or to the checker. Third, the printed label that has not been scanned for handover is a separate fact from an authorisation to release goods. A pending request is not an approval. An offered option is not an execution. An unsigned termination is not a completed termination.

## Three common errors

1. Treating a retrieval hit as a completed authorisation. Input: the original sample material text. Compare "pending review by the checking supervisor" with "has completed checking". If the draft sentence still claims handover, the claim is unsupported and the evidence gap must be recorded.

2. Linking knowledge bases that use different vector models. Input: the vector model identifiers of the two bases. Compare whether they are identical. If they differ, exclude the link, record the actual observation, and do not run a cross-model retrieval to compare missed recalls.

3. Writing a pending review status as an absence of operation permission. Input: "pending review by the checking supervisor". Compare whether the material states a permission field. If no permission field is stated, record only that the point remains to be verified. A pending review does not demonstrate that operation permission is missing.

## How to verify the setup

1. Input the original sample material text and the draft sentence. Compare "pending review by the checking supervisor" with "has completed checking and handover". If the draft sentence still claims handover, judge it unsupported and retain the evidence gap. Do not add authorisation or effective clauses to obtain a definite answer.

2. Input the vector model identifiers of the two knowledge bases. Compare whether they are the same. If they differ, exclude the link and record the actual observation. Do not assert a runtime result such as missed recall or redundant returns.

3. Input a paper empty result []. Compare whether the downstream path still runs. If it runs, this is consistent with the documented statement that reference content length can be zero. Do not claim that a retrieval under invented rules will necessarily return [].

The optional paths in the overall retrieval flow are not executed on every request. Image retrieval requires an image input and the corresponding model capability. Re-ranking requires a model and the setting to be enabled. Retrieval is not authorisation. Forms collect values; business verification, approval, database writes and external synchronisation need their stated downstream implementation.
