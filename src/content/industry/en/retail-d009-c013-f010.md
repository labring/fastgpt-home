# Franchise store supervision: citation tracing for operations handover

## What the documents look like

Franchise supervision in convenience retail depends on four document families: store visit forms, franchise contracts, rectification notices, and display standards. These materials sit across a supervisor app, POS sales records, the franchise system, and store photographs, with weekly or monthly update cycles. The three most time-consuming steps are checking displays, reconciling headquarters orders, and tracking rectification. For operations handover, the material itself, the material status, and the authorization boundary must be recorded separately. A store visit form that exists does not mean rectification was performed. A rectification notice that was issued does not mean the franchisee signed for it. A contract visible in the system does not mean the current operator may cite its clauses. Citation tracing addresses whether each statement in an answer or handover record can point back to a specific material, a specific version, and a specific authorization scope.

## Constraints at the citation tracing step

The knowledge base search node selects one or more knowledge bases that share the same vector model, and outputs a citation array whose length may be zero. An empty array means the search path completed without a match; it does not mean the workflow has errored or terminated. The citation limit controls the maximum tokens of content cited per search, measured in tokens. The minimum relevance value is a filter threshold between 0 and 1, and it takes effect only under semantic retrieval or result reranking. Hybrid retrieval merges multiple result paths through RRF. Reranking requires a ReRank model and must be enabled by configuration. Image retrieval requires image input and the corresponding model capability; it does not run on every request. Retrieval by itself is not authorization, and a similarity score does not distinguish franchise store ownership or operator permission. Knowledge bases built on different vector models cannot be linked together; the vector model identifier should be checked first, mismatched bases excluded, and the actual observation recorded without inferring the runtime result of a linked search.

## Three common errors

1. Treating a retrieval hit as authorization. In the hypothetical drill sample, a supervisor retrieves a franchise contract clause that belongs to a different franchise store. Retrieval returns the content, but the operator has no right to cite that store's contract. The error is using a similarity score in place of a permission check. Check method: input the sample contract clause and the operator's authorized region, compare the franchise store identifier in the cited content against the operator's authorization scope, and observe whether a cross-store citation appears.

2. Writing a pending status as already effective. In the hypothetical drill sample, a rectification notice carries the status awaiting franchisee confirmation, while the draft sentence states that rectification is complete. The error is equating pending review with completed execution. Check method: input the rectification notice source text and the draft sentence, compare the status field in the notice against the completion wording in the draft sentence, and observe whether the two conflict.

3. Treating an empty citation array as a retrieval failure. In the hypothetical drill sample, the paper input is [], and the downstream node receives an empty array. The error is concluding that the search necessarily returns empty or necessarily errors. Check method: input the empty array, compare the downstream node's handoff design, observe whether the path continues to execute, and record the actual observation without presupposing the result.

## How to verify the setup

1. Input two sentences from the store visit form source text in the hypothetical drill sample and the draft sentence "The store display has been rectified according to standard." Compare the completion wording in the draft sentence against the status field in the store visit form source text. If the source text states "awaiting re-inspection," the completion wording in the draft sentence does not match the source status, and the item is judged unsupported.

2. Input the franchise contract clause from the hypothetical drill sample and the handover request "Cite store A's contract clause into store B's supervision record." Compare the franchise store identifier in the contract clause against the target store identifier in the request. If the two differ, the request is judged outside the authorization boundary, and the evidence gap is recorded.

3. Input the paper empty array [] and the downstream handoff design. Compare whether the downstream node continues to execute and whether it produces output. If the path continues without error, record that the empty citation was handled normally. If the downstream design depends on a non-empty array, record it as pending verification, without inferring that failure must occur.
