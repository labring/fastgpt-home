# Brand repair services: retrieval for operations handover

## What the documents look like

Brand after-sales repair work centres on warranty liability and physical service outlets, which differs from platform after-sales that mainly processes refunds. Records come from the after-sales system, store orders, service-outlet feedback and the national three-guarantee catalogue. Everyday documents include warranty cards, repair work orders, inspection reports and replacement approvals. These materials carry a subject, an object, a status and a validity scope. The retrieval step returns quoted content for a question; authorization and handover status have to be checked separately. Records update per order and daily, and this page does not infer batch synchronization or transaction-triggered mechanisms from that cadence.

For operations handover, the practical difficulty is that a work order can look complete while its approval state is still open. A warranty card states coverage, a work order states what was received and inspected, an inspection report states a conclusion, and a replacement approval states a decision. Retrieval can surface any of these, but it does not decide whether a replacement may proceed.

## Constraints at the retrieval step

The knowledge-base search node can associate one or more knowledge bases that use the same vector model. Its quoted-content output is an array, and its length can be 0, so the downstream path still runs when nothing is found. Semantic retrieval, full-text retrieval and hybrid retrieval rest on vector distance, keyword hits and RRF fusion respectively. Minimum relevance takes effect only under semantic retrieval or when result re-ranking is used; it is a filter threshold and does not provide permission or entity isolation. A retrieval score does not determine operating permission, and it does not determine whether a handover is complete. The citation limit is measured in tokens, which differs from top k.

Hypothetical paper exercise, not submitted or tested: a brand after-sales centre holds a paper record whose text reads “Work order W-2024-0317, received 17 March 2024, device model A-100, fault described as unable to charge, inspection conclusion battery fault, warranty status within warranty period, handling opinion free battery replacement, outlet signatory Li, signed 18 March 2024.” A draft sentence awaiting judgement reads “This work order has completed replacement approval and replacement may proceed.” The record states only a free-battery-replacement handling opinion and an outlet signature. It does not state a replacement-approval conclusion, so the draft sentence is unsupported. This sample is a paper exercise and has not been filed, approved or tested.

## Three common errors

1. Treating a retrieval score as an authorization decision. Input: the sample work order and the draft sentence. Compare the retrieval output with the work-order text. If the draft sentence is treated as already approved, that is an overreach; retrieval does not judge approval status.
2. Extending the same-vector-model requirement to external systems. Input: the list of knowledge-base identifiers. Compare the vector-model identifier of each library. Forcing libraries with different models into one association is a configuration error; check identifiers and exclude those that do not match.
3. Treating a handling opinion as a replacement approval. Input: the work-order text “handling opinion free battery replacement.” Compare it with the draft sentence “has completed replacement approval.” Treating the two as the same fact is a field conflation; the approval conclusion is not stated and remains unsupported.

## How to verify the setup

1. Input the sample work-order text and the question “What is the warranty status of work order W-2024-0317?” Compare the quoted content with the source phrase “within warranty period.” The condition is met when the quotation contains that field and the subject and period match. If there is no hit, record the actual observation; a first-position hit is not guaranteed.
2. Input the draft sentence “This work order has completed replacement approval and replacement may proceed.” Compare it with whether the work-order text states a replacement approval. If the source has no such field, the sentence is unsupported; it is not to be reclassified as a denial or a conflict.
3. Input the paper empty result []. Compare whether the downstream node continues with a quoted-content length of 0. The condition is met when the path runs and no approval or database-write action is triggered; retrieval does not perform authorization, approval or external synchronization.

Across all three checks, the same subject, the same period and the same field must be compared. Only mutually exclusive values in one field count as a contradiction. A field that is not stated, or evidence that shows only a related stage, is unsupported or pending verification. A pending review does not demonstrate a lack of operating permission.
