# Wholesale stall trading: citation tracing for operations handover

## What the documents look like

Wholesale market stall trading is fragmented. Prices are negotiated in person, and goods often move by consignment. The paperwork reflects that rhythm. Purchase notes, handwritten sales slips, stall lease contracts and payment receipts are frequently split between paper and chat records. These materials commonly record only quantity, amount and the handler. Signing, deal conclusion and contract effect do not necessarily occur at the same moment on the page. A quotation validity period is not a supply deadline.

Citation tracing for this category means following a given answer or handover request back to the specific wording of a source document, and stating which state that document is actually in. The data updates daily and per order. That frequency affects when a cross-check is performed; it does not change the feature on this page.

## Constraints at the citation tracing step

The knowledge base search node can be linked to one or more knowledge bases that share the same vector model. Its output is an array of citations, and the array length may be zero. When the array is empty, that output path still completes. The citation array is a retrieval result. It does not constitute authorization. A similarity score is a ranking basis; it does not perform permission or entity isolation. Retrieval scope is first checked against the selected knowledge bases and the document version.

Hybrid retrieval merges multiple result paths through RRF. Reranking requires a model and must be enabled in settings. Image retrieval requires corresponding image input and model capability. These optional paths do not mean every request executes all of them. A thinking budget is a model reasoning-strength setting and is unrelated to the token-based citation limit.

A hypothetical drill sample follows. A wholesale market stall has Material One, a handwritten sales slip reading: "12 March 2024, Stall A sold 200 jin of potatoes to Buyer Jia, unit price 2 yuan, handler Yi, payment not received." Material Two is a stall lease contract reading: "Stall A, lease term 1 January 2024 to 31 December 2024, lessee Bing." The draft sentence to be assessed is: "Buyer Jia obtained ownership of this batch of potatoes on 12 March 2024, and payment was settled." A separate handover request on the same day reads: "Hand over the citation sources for all of Stall A's 12 March sales slips to the next shift." The materials contain no ownership-transfer clause and no record of payment settlement.

## Configuration and implementation checks

| Configuration or check item | Value or action on this page | Basis and comparison method |
| --- | --- | --- |
| Linked knowledge bases | Select only knowledge bases sharing the same vector model | Official text states that only identical vector models may be linked together; verify the identifier first and exclude non-matching ones |
| Citation limit | Hypothetical trial starting point 2000 tokens, not an official default | Sample materials are mostly short sentences; compare citation count against a 4000-token setting |
| Minimum relevance | Hypothetical trial starting point 0.3, not an official default | Compare with 0.5 and observe whether the same question returns a different number of citations |
| Search mode | Semantic retrieval or hybrid retrieval | For exact fields such as numbers and amounts, compare separately using full-text retrieval |
| Citation content output | Check array length; zero is permitted | An empty array does not mean the workflow errored and stopped |
| Citation input handoff | Check whether retrieval output is passed to the answering step | Compare each answer item against the cited source wording |

## Three common errors

1. Treating a retrieval hit as authorization. The input is "hand over the citation sources for all of Stall A's 12 March sales slips to the next shift." The comparison object is the wording of Material One. That material records only that payment was not received. A retrieval array being returned does not mean the handover has been approved. The observable result is that citations exist while the authorization state remains unsupported.

2. Treating an unstated field as a contradiction. The input is the draft sentence "payment was settled." The comparison object is Material One's "payment not received." A contradiction requires mutually exclusive values for the same field. Material Two does not touch on payment at all, so it is an unsupported item, not a denial or a conflict.

3. Moving a thinking budget into the citation limit. The input is a model reasoning-strength setting. The comparison object is the token field of the citation limit. The two differ in unit and in function. The observable result is that adjusting reasoning strength does not change the citation count limit.

## How to verify the setup

1. Enter the hypothetical Material One and the draft sentence. Compare the draft sentence "payment was settled" against the source wording "payment not received." A contradiction finding is satisfied only when the same subject, the same date and the same field carry mutually exclusive values. Material Two does not record payment, so it is logged as an evidence gap.

2. Enter an explicit paper-based empty result array []. Compare whether the downstream answering step still executes. If the output path completes, the handoff design check is satisfied. Do not claim that a fictional rule will necessarily return an empty array.

3. Enter Material One and the handover request. Compare whether the citation sources can be traced back to the source wording, and whether the handover has an authorization basis. The check on this page is satisfied only when citations are traceable and the authorization state is marked as pending verification. Do not claim the handover was executed.
