## Three common errors

- If recovered answers omit the supplier’s nonconfirmation and claim an agreed settlement, compare the reconciliation sentence, actually restored text and adopted citation.

- If an earlier arrival’s photo note supports the current exception, compare batch, photographed subject and receiving record. Matching attachment names supply no mutual proof.

- If model calls work while photo files are absent, inspect service connectivity, file storage and retrieval separately. Readable descriptions establish no recovered image set.

## How to verify the setup

Record baseline and target-deployment conditions, create a backup and verify actual restoration coverage for exception reports, notes and attachments. Inspect installed dependencies and retrieval backends without guessed settings or performance limits. Repeat questions about exception state, counterparty position and missing evidence before and after the change, with member-access tests separately. Report observed checks without promising loss-free recovery or completed claims. Liability confirmation and financial action remain business processes.
