## Three common errors

- If restored headquarters requirements become a locally passed audit, inspect document purpose and field evidence. Recovered standards establish no performed work.

- If an earlier photo note supports the current correction, compare store, round and photographed subject. A filename supplies no current identity.

- If the application responds while originals are missing, inspect file storage, text retrieval and model paths separately. Readable text proves no recovered image.

## How to verify the setup
