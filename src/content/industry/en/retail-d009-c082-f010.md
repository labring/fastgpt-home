# Returned-goods inspections: citation tracing for operations handover

## What the documents look like

Returned-goods inspection handles incoming return parcels and item grading. It is separate from the outbound pick-and-pack flow for new orders. The working data comes from the WMS returns module, platform after-sales records, carrier return items, and the inspection bench. Day-to-day documents include the return inbound receipt, inspection photos, the grade determination sheet, and the re-listing sheet. Updates occur per item and per day, so handover status can change with each individual inspection conclusion. Citation tracing at handover must be able to point to a specific item and a specific version of the source material.

The consequences of error concentrate on resale of defective goods, refund disputes, and inventory contamination. The citation tracing step has to answer whether a conclusion, a photo, or a determination sheet can be located at handover, whether its version can be checked, and whether the authorization boundary is clear. Retrieval and forms do not by themselves constitute authorization to execute.

## Constraints at the citation tracing step

The knowledge base search node outputs a citation array, and its length can be zero. Even when no content is found, the output path still runs through. When linking knowledge bases, only one or more knowledge bases sharing the same vector model can be selected. Semantic retrieval and the minimum relevance value deal with similarity and a filter threshold. They do not carry permission or entity-isolation duties. Hybrid retrieval merges multiple result paths through RRF, and ReRank performs a second ordering of candidate text. These are retrieval processes. They do not change whether a given record is visible to a given role, or whether a handover has been approved.

Hypothetical drill sample: an after-sales warehouse inspector processes return inbound receipt R-20260310-017 on 10 March 2026. The item is a coat. The inspection photo is annotated "left cuff stain." The grade determination sheet gives a preliminary grade of B, resalable. The re-listing sheet has not been generated. A draft handover sentence reads: "R-20260310-017 has been graded B and can be listed directly." The source material for comparison reads: "Grade determination sheet: preliminary grade B, pending inventory administrator review." and "Re-listing sheet: not generated." Here "has been graded" and "pending review" are mutually exclusive states of the same field. The draft sentence writes a pending review as a completed determination, and describes a re-listing sheet that has not been generated as directly listable. This is an unsupported statement.

## Three common errors

1. Treating a retrieval hit as authorization. The input is the citation array returned by retrieval. The comparison object is the status field of the grade determination sheet for that item. The observable result is whether the citation content matches the source text of the determination sheet. If the citation shows only "grade B" without "pending review," then the "has been graded" wording in the handover request is unsupported.

2. Treating an empty citation array as process termination. The input is a paper input of []. The comparison object is the design of the downstream answering step. The observable result is whether the downstream path still runs through and records the gap. Official text states the length can be zero and the output path still runs through.

3. Forcing joint linking of knowledge bases with different vector models. The input is the vector model identifiers of the two knowledge bases to be linked. The comparison object is the official "same vector model" condition. The observable result is that identifiers that do not match are excluded and recorded. A cross-model retrieval is not executed to compare missed recalls.

## How to verify the setup

1. Use the hypothetical sample to check the draft sentence. The input is "R-20260310-017 has been graded B and can be listed directly" together with the source material "preliminary grade B, pending inventory administrator review" and "re-listing sheet: not generated." Compare the state values of the same field. The observable result is that "has been graded" and "pending review" are mutually exclusive, the draft sentence is unsupported, and it should be recorded as pending verification.

2. Use a paper input of [] to check empty-citation handoff. The input is an explicit empty array. The comparison object is whether the downstream answering step still executes and leaves a gap record. The observable result is that the path runs through and does not produce fabricated sources.

3. Check the linked knowledge base identifiers. The input is the list of vector model identifiers for the knowledge bases to be linked. The comparison object is the official same-vector-model condition. The observable result is that matching identifiers are retained and mismatches are excluded and recorded. No runtime result is inferred from this.

A pending review does not demonstrate a lack of operating permission. Signing, reaching an agreement, and contract effectiveness are three distinct facts. This page does not claim that any test, deployment, approval, or refund has occurred.
