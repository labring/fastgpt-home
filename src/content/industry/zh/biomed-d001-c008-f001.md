# I 期临床临床试验预筛的HTTP 接口与外部系统

## 这个品类的数据长什么样

I 期临床试验预筛的数据主要来源于临床试验管理系统 (CTMS)、电子数据采集系统 (EDC)、医疗机构的电子病历系统 (EMR) 以及部分生物样本库系统。这些数据通常包含受试者人口学信息、既往病史、体格检查结果、实验室检查数据、影像学报告以及知情同意书状态。数据更新频率在试验进行期间较高，尤其是实验室检查结果，可能以天为单位更新。数据文档结构复杂，常采用 CDISC (Clinical Data Interchange Standards Consortium) 标准的 SDTM (Study Data Tabulation Model) 或 ADaM (Analysis Data Model) 格式，包含大量结构化和半结构化数据。字段名称通常遵循医学专业术语，例如 `SubjectID`、`VisitDate`、`LabTestCode`、`ResultValue`、`Unit`，单位则严格按照国际单位制或临床常用单位，如 `mmol/L`、`ng/mL`、`mmHg`。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

I 期临床试验预筛数据的高度结构化和严格的更新频率，要求 HTTP 接口具备高效的数据拉取和解析能力。由于数据源分散且格式多样，接口设计需要考虑多种认证机制，如 OAuth2.0 或 API Key。特别是来自 EDC 和 EMR 的数据，其接口可能存在严格的访问控制和速率限制，需要合理设计请求间隔。CDISC 标准的复杂性，意味着在数据解析阶段需要强大的模式匹配和字段映射能力，以确保数据的准确性和完整性。单位的标准化处理是关键，接口返回的数据若单位不统一，则需要在集成层进行转换。数据量虽然相对较小，但其敏感性要求传输过程必须采用 HTTPS 并进行数据加密，以符合 HIPAA 等法规要求。

## 配置怎么定

| 配置项             | 建议取法                                 | 这样取的依据                                       |
| :----------------- | :--------------------------------------- | :------------------------------------------------- |
| `API_KEY`          | 按数据源系统提供的密钥                   | 确保对外部系统的认证授权，避免未经授权的访问       |
| `requestTimeout`   | `60 秒`                                  | 适应复杂查询和潜在的网络延迟，保障数据完整性       |
| `maxConnections`   | `50`                                     | 平衡外部系统负载与数据拉取效率，防止过载           |
| `dataParseMode`    | `JSONPath` 或 `XPath`                    | CDISC 标准数据常为 JSON 或 XML 格式，支持精准字段提取 |
| `unitConversionMap`| `{"mg/dL": "mmol/L", ...}`               | 统一不同数据源的医学单位，确保数据一致性           |
| `retryAttempts`    | `3`                                      | 处理临时性网络波动或外部系统繁忙，提高接口稳定性   |

## 容易做错的三处

*   接口返回 `HTTP 500` 错误，内容为空，通常是外部系统内部逻辑错误或数据查询参数不正确导致。
*   获取到的实验室检查结果字段 `ResultValue` 为空，或单位 `Unit` 字段缺失，原因多是外部系统接口文档未完全遵循，或解析 `JSONPath` / `XPath` 表达式有误。
*   OneAPI 中配置的大模型服务自动关闭，这可能是由于外部 API 密钥过期、配额用尽或 OneAPI 侧对特定模型接口的健康检查失败。

## 怎么确认配好了

*   通过 FastGPT 的接口调试工具，使用预设的 I 期临床受试者 ID 调用接口，检查返回数据中的 `SubjectID`、`VisitDate`、`LabTestCode` 等核心字段是否准确无误。
*   检查关键实验室检查结果如血常规、肝肾功能指标的 `ResultValue` 和 `Unit` 字段，核对其数值和单位是否与原始数据源一致，尤其关注单位是否已按 `unitConversionMap` 正确转换。
*   模拟并发请求，观察接口响应时间和成功率，确保在 I 期临床试验数据更新高峰期，接口仍能稳定提供数据。
