# 影像设备临床试验预筛的文档解析与分块

## 这个品类的数据长什么样

影像设备临床试验数据主要来源于设备厂商提供的技术手册、性能报告、操作规程、维护日志，以及临床中心生成的病例报告、影像学检查结果、伦理审批文件。这些文档多以 PDF、Word、DICOM 报告等格式存在。更新频率方面，设备技术参数和操作规程通常随设备型号迭代或软件升级而更新，而临床数据则随试验进展持续产生。文档结构上，技术手册常包含大量图表、规范化参数列表；病例报告则结合自由文本描述与结构化诊断字段。字段与单位具有高度专业性，例如 CT 设备的 X 射线剂量以毫西弗（mSv）计，磁共振设备的磁场强度以特斯拉（T）计，超声设备的频率以兆赫兹（MHz）计。

## 这些特征在「文档解析与分块」这一环带来什么约束

影像设备文档的专业性和多样性，对文档解析与分块提出了特定要求。首先，技术手册中的图表和参数列表需要精确识别和提取，这要求解析器具备优秀的图文混排处理能力，并能区分表格数据与普通文本。其次，DICOM 报告等特殊格式的解析，需要专门的解码器，以确保元数据和图像描述的完整性。再次，大量的专业术语和计量单位，要求分块策略能够识别并保持这些关键信息的上下文完整性，避免因断句导致语义丢失。例如，一个关于“1.5T 磁共振成像系统”的描述，若“1.5T”与“磁共振成像系统”被拆分到不同块，将影响后续的检索准确性。此外，更新频率的不一致性，意味着需要支持增量解析和版本管理，确保知识库的时效性。

## 配置怎么定

| 配置项             | 建议取法                                          | 这样取的依据                                                                                                                              |
| :----------------- | :------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------- |
| `分段长度`         | `800–1200 字符`                                   | 保持影像设备技术参数、操作步骤等关键信息的上下文完整性，同时避免单个块过大导致检索效率下降。                                            |
| `分段重叠长度`     | `100–200 字符`                                    | 确保跨分块的关键术语、缩写、计量单位或短语能被完整捕获，尤其在专业文档中，衔接处语义完整性至关重要。                                  |
| `OCR_ENABLED`      | `True`                                            | 影像设备文档中常包含扫描件、图片中的表格或设备铭牌信息，开启 OCR 确保所有文本内容均可被解析。                                           |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒`                                          | 鉴于影像设备技术手册或临床病例报告可能包含大量页面和复杂图表，预留充足的解析时间以避免因超时而解析不完整。                              |
| `MAX_FILE_SIZE`    | `200 MB`                                          | 影像设备技术手册或包含嵌入图像的报告文件可能体积较大，适当放宽文件大小限制，支持上传和解析大型文档。                                    |
| `分段策略`         | `按标题层级分段` 结合 `按固定长度分段`          | 优先依据技术手册和临床报告的章节结构进行分段，当结构不明确时，退回固定长度分段，确保内容颗粒度适中。                                    |

## 容易做错的三处

*   解析结果中缺少表格数据或图片中的文字，原因是 OCR 功能未启用或配置不当，导致解析器忽略了非文本内容。
*   临床试验方案的关键参数在检索时语义不完整或关联性差，原因在于分块长度过短，将描述同一设备参数的句子拆分到不同块中。
*   上传大型影像设备技术手册时出现解析超时错误，原因是没有为 `PARSE_FILE_TIMEOUT_SECONDS` 配置足够长的等待时间。

## 怎么确认配好了

*   随机抽取多份不同类型的影像设备文档（如技术手册、病例报告），检查解析后各分块是否包含完整的专业术语和计量单位。
*   针对包含图表和扫描件的文档，验证解析结果中是否准确提取了图片中的文字信息和表格数据，确认 OCR 效果。
*   上传一份超过 100 页的影像设备技术手册，观察解析过程是否顺利完成，并且最终生成的文本块数量与文档内容量级匹配，以评估 `PARSE_FILE_TIMEOUT_SECONDS` 的设置。
*   通过关键词检索，验证包含跨分块关键信息的查询，如“1.5T 磁共振成像系统”，能否召回相关且语义完整的文本块。
