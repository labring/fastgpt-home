# 清洁验证临床试验预筛的HTTP 接口与外部系统

## 这个品类的数据长什么样

清洁验证数据主要来源于制药生产过程中的设备清洗记录、残留物检测报告和微生物检测报告。这些数据通常以结构化或半结构化的文档形式存在，如 PDF 格式的分析报告、Excel 表格记录的清洗参数或 LIMS（实验室信息管理系统）导出的 CSV 文件。更新频率取决于生产批次和清洁周期，通常为每日或每周进行。核心字段包括设备编号、批次号、清洁剂名称、清洁参数（温度、时间、浓度）、残留物限度、实际检测值、微生物限度、检测结果以及清洁验证报告编号。单位涉及微克/表面积单位、CFU/表面积单位等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

清洁验证数据的多源性与半结构化特点，要求 HTTP 接口具备强大的文件解析能力。PDF 和 Excel 文件需要预处理，提取关键字段，这可能导致数据提取的复杂性增加。更新频率较高，需要接口支持批量数据上传和增量更新，以避免重复上传和数据冗余。字段与单位的特异性，例如残留物浓度单位 `µg/cm²` 或 `ppm`，以及微生物的 `CFU/cm²`，要求接口在数据传输时能明确标识单位或进行标准化转换，确保数据一致性。此外，由于清洁验证数据对合规性要求高，接口需支持数据溯源和完整性校验，确保数据在传输过程中不被篡改。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `maxChunkSize` | `800-1200 字符` | 清洁验证报告多为长文本，此范围有助于保留上下文完整性，提高召回准确率。 |
| `overlapRate` | `0.15` | 保证分段之间有足够的重叠，避免关键信息被切割，尤其在图表或表格附近。 |
| `recallThreshold` | `0.75` | 确保召回结果与清洁验证的严格标准相符，过滤掉不相关的辅助信息。 |
| `batchUploadLimit` | `100 MB` | 兼顾网络传输效率和服务器处理能力，适应每日或每周的批量数据更新。 |
| `parseTimeout` | `600 秒` | 处理大型 PDF 或包含复杂表格的 Excel 文件时，提供充足的解析时间，避免超时。 |

## 容易做错的三处

*   接口返回 `HTTP 500` 错误，内容为 "Invalid Unit Format"，原因是上传数据中残留物检测值的单位与系统预设单位不匹配。
*   知识库搜索结果缺失关键信息，例如某个批次的清洁剂浓度，是由于文件解析器未能正确从非标准格式的 Excel 模板中识别出对应的字段。
*   批量上传大量清洁验证报告后，部分数据未被索引，原因是接口 `batchUploadLimit` 配置过低，导致部分文件上传失败，但系统未给出明确的失败提示。

## 怎么确认配好了

*   上传一份包含复杂表格和多单位表示的清洁验证 PDF 报告，检查知识库中是否正确提取了所有关键字段及其单位。
*   模拟一次批量数据上传，检查所有预期文件是否被成功索引，并通过搜索功能验证数据完整性。
*   通过接口调用，查询特定设备或批次的清洁验证记录，并比对返回数据与原始报告，确认字段值与格式一致。
