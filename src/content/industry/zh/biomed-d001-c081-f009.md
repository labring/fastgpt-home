# 神经退行性临床试验预筛的引用来源与溯源

## 这个品类的数据长什么样

神经退行性疾病临床试验的数据来源主要包括 ClinicalTrials.gov、欧洲临床试验数据库（EU CTR）、WHO 国际临床试验注册平台（ICTRP）等官方注册机构，以及专业的生物医药数据库如 PubMed、Embase 和 Scopus。这些数据更新频率不一，官方注册平台通常在试验状态变更时即时更新，而文献数据库则有每日或每周的更新周期。文档结构以结构化数据和非结构化文本并存，例如 ClinicalTrials.gov 的 `Study Design` 字段包含自由文本描述，而 `Eligibility Criteria` 则包含详细的纳入/排除标准。字段涵盖试验基本信息（如 `NCT Number`、`Study Title`）、疾病领域（如 `Alzheimer's Disease`、`Parkinson's Disease`）、受试者特征（如 `Age Range`、`Gender`、`Biomarkers`）、药物信息（如 `Intervention Type`、`Drug Name`）、研究阶段（如 `Phase 1`、`Phase 2`）及结果指标（如 `Primary Outcome`、`Secondary Outcome`）。单位方面，常涉及剂量（mg）、时间（周、月）、生物标志物浓度（pg/mL）等。

## 这些特征在「引用来源与溯源」这一环带来什么约束

神经退行性疾病临床试验数据的高度异构性及其更新频率的差异，对引用来源的有效性和溯源的准确性构成了特定约束。由于 `Eligibility Criteria` 等关键信息常以非结构化文本形式存在，传统基于关键词的匹配难以精准捕获语义关联，这要求更高阶的文本理解能力，例如利用嵌入模型识别同义表达或隐含条件。不同数据库的更新周期差异，意味着在进行引用时需特别关注数据的新鲜度，避免引用过时或已撤回的试验信息。此外，涉及生物标志物等专业字段时，单位的统一性与标准化至关重要，不一致的单位可能导致错误的解读，进而影响预筛结果的准确性。多源异构数据要求系统在引用时能够清晰标识来源，支持用户快速跳转至原始数据库，核验信息的可靠性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `maxContext` | `800–1200 字符` | 适应神经退行性疾病临床试验报告中冗长且信息密集的描述，确保上下文完整性。 |
| `召回条数` | `前 5 条` | 平衡召回精度与计算开销，覆盖核心相关度高的试验信息。 |
| `相似度阈值` | `0.75–0.85` | 针对医学文本的专业性和严谨性，确保召回结果与查询意图高度相关。 |
| `分段长度` | `400 字符` | 兼顾段落语义完整性与模型处理效率，尤其对 `Eligibility Criteria` 等长文本。 |
| `重排返回条数` | `3 条` | 聚焦最相关的试验，减少冗余信息干扰，提升预筛决策效率。 |
| `REFERENCE_DISPLAY_LIMIT` | `3` | 避免在对话中显示过多的引用链接，保持界面简洁，聚焦核心溯源信息。 |

## 容易做错的三处

- 对话回答中提示“没有权限操作此对话记录”，通常是由于引用来源的内部链接或 `NCT Number` 字段在导出工作流时丢失了权限配置，导致系统无法验证用户访问原始数据的权限。
- 导出工作流并导入新环境后，工作流中引用的自定义插件找不到，这可能是因为新环境缺少插件的 `plugin_id` 或 `plugin_name` 注册信息，未能正确加载对应的解析器或数据源连接器。
- 对话回答段落末尾的引用显示不完整或格式错误，例如 `\n` 未能正确换行，这通常是 `REFERENCE_FORMAT_TEMPLATE` 配置中转义字符处理不当，或前端渲染组件未能正确解析 Markdown 格式。

## 怎么确认配好了

- 随机抽取 5-10 个预筛结果，核对其引用的 `NCT Number` 是否能成功跳转至 ClinicalTrials.gov 上的对应试验页面，并验证页面内容与引用摘要是否一致。
- 使用包含特定生物标志物或基因变异的查询，检查召回结果中是否包含相关试验，并核对 `Biomarkers` 字段的单位与查询意图是否匹配。
- 模拟一次完整的预筛流程，检查对话回答末尾的引用链接是否正确显示，点击后能否直接访问到原始数据源的精确位置，例如 ClinicalTrials.gov 的特定 `Eligibility Criteria` 部分，且无权限错误。
- 检查系统日志，确认在数据摄取和更新过程中，是否存在因 `PARSE_FILE_TIMEOUT_SECONDS` 或 `UPLOAD_FILE_MAX_SIZE` 限制导致的神经退行性疾病相关大型研究报告处理失败记录。
