# 高值耗材临床试验预筛的HTTP 接口与外部系统

## 这个品类的数据长什么样

高值耗材在临床试验预筛阶段的数据，主要来源于医疗器械注册数据库、医院信息系统（HIS）、实验室信息管理系统（LIMS）以及电子病历系统（EHR）。这些数据通常包含器械型号、批次、生产商、适应症、禁忌症、使用科室、患者基本信息、诊断结果、相关检验指标和影像学数据。数据更新频率不一，注册信息可能季度更新，而患者临床数据则实时产生。文档结构方面，注册信息常以结构化文档或表格形式呈现，临床数据则混合了结构化字段和非结构化文本（如医生手写记录）。字段与单位上，高值耗材特有的标识符如序列号、唯一器械标识（UDI）是关键。检验指标的单位复杂，例如血液生化指标可能涉及 mmol/L、g/L，影像报告则包含尺寸（mm）、密度（HU）等，需要精确解析。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

高值耗材数据的多源性决定了HTTP接口需要支持多种认证机制和数据格式，例如对接注册数据库可能需要API密钥或OAuth 2.0，而从HIS或EHR拉取数据则可能涉及更复杂的单点登录或私有协议封装。其数据更新频率的不一致性，要求接口设计支持定时拉取（如注册信息）和事件驱动推送（如新患者入组或关键检验结果）。混合的文档结构意味着接口不仅要能处理JSON或XML等结构化数据，还需要有能力解析非结构化文本，例如通过预处理服务提取关键信息。高值耗材特有的标识符（如UDI）和复杂的单位体系，对HTTP请求参数的校验和响应数据的标准化提出了高要求。错误的标识符或单位解析可能导致预筛结果偏差，甚至影响患者安全。因此，在外部系统集成时，需要重点关注数据清洗、标准化和单位转换逻辑。

## 配置怎么定

| 配置项                       | 建议取法                               | 这样取的依据                                   |
| :--------------------------- | :------------------------------------- | :--------------------------------------------- |
| `API_ENDPOINT_URL`           | 真实接口地址，如 `https://api.example.com/v1/devices` | 外部系统提供的标准访问路径                     |
| `REQUEST_TIMEOUT_SECONDS`    | `60 秒`                                | 避免因外部系统响应慢导致预筛流程长时间阻塞     |
| `AUTH_HEADER_NAME`           | `Authorization`                        | 常见的API认证头，承载令牌或密钥                |
| `AUTH_TOKEN_TYPE`            | `Bearer`                               | OAuth 2.0等认证体系中常用的令牌类型            |
| `DATA_PARSE_STRATEGY`        | `JSON_PATH` 或 `REGEX_EXTRACT`         | 应对结构化（JSON）与非结构化（文本）混合数据   |
| `RETRY_ATTEMPTS`             | `3 次`                                 | 应对网络波动或外部系统临时性故障               |

## 容易做错的三处

*   HTTP 请求返回 401 或 403 错误，原因在于 `AUTH_TOKEN` 配置不正确或已过期。
*   接口调用成功但返回数据中关键字段为空，原因可能是 `DATA_PARSE_STRATEGY` 未能正确匹配复杂的临床数据结构。
*   数据拉取超时，原因在于 `REQUEST_TIMEOUT_SECONDS` 设置过短，外部系统处理高并发或复杂查询时响应延迟。

## 怎么确认配好了

*   通过 Postman 或 curl 工具模拟 API 请求，核对返回状态码是否为 200，并检查响应数据结构与预期是否一致。
*   在 FastGPT 知识库中导入少量测试数据，执行一次知识库更新操作，观察日志输出中是否有外部接口调用成功的记录。
*   针对高值耗材特有的序列号或 UDI，构造查询请求，确认返回结果中包含这些关键标识符，且数值与来源系统一致。
