# CDMO产品的表单与交互

## 这个品类的数据长什么样

CDMO（合同研发生产组织）产品的数据主要围绕化学分子结构、合成路线、工艺参数、质量控制指标及法规符合性文件展开。数据来源包括研发实验记录、批生产记录、分析检测报告、物料安全数据表（MSDS）和注册申报文件。更新节奏通常与项目进展和批次生产周期同步，例如，一个新工艺开发可能每周更新，而常规生产批次数据则按批次生成。文档结构多为结构化或半结构化，如实验方案、分析报告的 PDF 或 Word 文档，以及存储在 LIMS 或 MES 系统中的结构化数据。字段与单位具有高度专业性，例如反应温度（℃）、压力（MPa）、产率（%）、纯度（%）、杂质含量（ppm）等，且常涉及 IUPAC 命名法或 SMILES 字符串等化学专业表示。

## 这些特征在「表单与交互」这一环带来什么约束

CDMO产品数据的专业性和多样性对表单与交互设计提出特定要求。首先，复杂的化学结构和工艺参数需要支持富文本输入、结构式绘制工具或特定格式上传，常规文本框难以满足。其次，数据更新的周期性意味着知识库内容需要定期同步或支持增量更新，以确保咨询结果的时效性。文档类型多样，要求平台具备强大的文档解析能力，能够从 PDF、Word、Excel 等多种格式中准确提取关键信息。专业字段和单位的识别与解析是核心，这意味着在表单设计时需要考虑对特定命名实体（如化学品名称、CAS 号）的识别，并在交互中提供准确的单位转换或解释，避免因专业术语理解偏差导致回答错误。此外，法规文件的引用和查询也需要支持精确匹配和上下文理解。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `500–800 字符` | 确保单个知识块包含足够上下文，同时避免过长导致信息冗余或语义漂移，尤其针对工艺描述和实验步骤。 |
| `召回条数` | `前 5–8 条` | CDMO咨询通常需要综合多个维度的信息（如合成步骤、质量标准），适当增加召回条数有助于覆盖更全面的信息。 |
| `相似度阈值` | `0.75–0.85` | 高专业度文本要求较高的匹配精度，避免将不相关的化学或工艺信息召回，导致误判。 |
| `重排返回条数` | `前 3 条` | 经过重排后，最相关的3条通常能有效支撑回答，兼顾准确性和响应速度。 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | CDMO相关的分析报告、批生产记录等文件可能包含大量图表和数据，文件体积较大，需要支持大文件上传。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 复杂PDF或扫描件的解析耗时较长，适当延长超时时间可提高解析成功率。 |

## 容易做错的三处

*   用户上传 PDF 后，系统提示“文档解析失败，请检查文件格式或内容”。原因可能是 PDF 包含大量图片或扫描件，OCR 识别率低或解析超时，导致无法提取有效文本。
*   咨询特定化学品纯度范围时，回答中出现不相关数值或单位错误。原因在于知识库中未对专业字段（如“纯度”、“杂质含量”）进行有效标注或实体识别，导致模型无法区分数值的上下文。
*   在团队协作中，新成员无法访问已配置的知识库或模型。原因是没有正确配置团队成员的权限，或邀请时使用的用户名与注册系统不匹配，导致权限验证失败。

## 怎么确认配好了

*   上传多种格式的 CDMO 相关文档（如工艺规程 PDF、分析报告 Excel），检查文档是否能被成功解析并生成知识块。
*   针对核心产品或工艺参数，进行多轮提问，验证模型能否准确回答，并引用正确的知识来源。
*   模拟不同权限的用户登录，测试其在表单填写、文件上传和知识库访问等环节的操作权限是否符合预期。
*   使用包含专业术语和单位的查询语句，评估模型对这些信息的理解和回复的准确性，确保单位转换或解释无误。
