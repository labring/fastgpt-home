# GMP 合规产品的表单与交互

## 这个品类的数据长什么样

GMP 合规产品的相关数据主要来源于官方发布的法规文件、指导原则、行业标准、审计报告以及企业内部的质量管理体系文件。这些数据更新频率相对较低，通常随政策修订或行业实践发展而变化，可能以季度或年度为周期。文档结构通常高度规范化，例如法规文件多为章节体例，包含严格定义的术语、条款和附录；审计报告则有固定的报告模板和数据项。字段与单位具有高度专业性，如批次号 `batch_number`、生产日期 `production_date`、有效期 `expiration_date`、检测结果 `assay_result`（常伴随 `mg/mL`、`IU` 等单位）、偏差编号 `deviation_id`、CAPA 措施 `CAPA_action` 等。数据中还可能包含大量的文本描述，用于记录生产过程、质量控制细节和偏差处理过程。

## 这些特征在「表单与交互」这一环带来什么约束

GMP 合规数据的高度规范性要求表单设计必须精准匹配其字段结构，避免自由文本输入导致的数据不一致。例如，批次号、生产日期等核心标识符需设置为固定格式或下拉选择，以确保数据完整性和查询准确性。更新频率低意味着历史数据的查询和追溯能力至关重要，表单应支持按时间范围、批次号等进行复杂查询，并能快速加载大量历史记录。文档结构的高度专业性决定了交互设计需要提供丰富的上下文信息和术语解释，例如在填写偏差报告时，应能快速关联到相关的法规条款或标准操作规程（SOP）。文本描述多则要求输入框支持多行文本，并可能需要集成文本分析功能，辅助用户提取关键信息或识别潜在风险点。字段与单位的专业性要求表单在数值输入时提供单位选择或自动校验功能，防止单位混淆造成的错误。

## 配置怎么定

| 配置项                   | 建议取法       | 这样取的依据                                                                                             |
| :----------------------- | :------------- | :------------------------------------------------------------------------------------------------------- |
| `maxContext`             | `2000 字符`    | 应对法规条款和详细的质量记录，确保足够上下文理解。                                                       |
| `分段长度`               | `500 字符`     | 考虑到法规条款的逻辑完整性和审计报告的段落结构，避免语义割裂。                                           |
| `相似度阈值`             | `0.8`          | 确保检索结果与严格的合规要求高度相关，减少无关信息的干扰。                                               |
| `召回条数`               | `前 10 条`     | 提供足够多的相关法规或记录供工程师参考，同时避免过载。                                                   |
| `重排返回条数`           | `前 3 条`      | 聚焦最核心、最直接相关的合规条款或操作指导，提高决策效率。                                               |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒`       | 应对可能包含大量图表和复杂排版的法规文件或审计报告，确保解析完成。                                       |

## 容易做错的三处

*   现象：用户在输入批次号时，系统无法识别或提示格式错误。原因：表单的输入校验规则过于严格，未能兼容不同生产线或历史批次号的多种格式，或者未提供足够的格式示例。
*   现象：在线咨询时，AI 回答与 API 调用对同一问题的回复质量差异显著。原因：API 调用时缺乏在线聊天环境自动提供的隐式上下文（如历史对话、用户画像），导致模型无法获得完整信息。
*   现象：系统查询某项合规要求时，返回的结果条目过多，且包含大量不相关内容。原因：知识库构建时，文档分段策略未能有效识别和保留法规条文的最小独立语义单元，导致召回的文本片段缺乏精确性。

## 怎么确认配好了

*   选取典型 GMP 法规文件和企业内部 SOP 文档，测试表单数据录入与查询功能，核对录入数据的准确性和查询结果的完整性。
*   针对不同复杂度的合规咨询问题，在模拟聊天环境中进行多轮对话测试，评估 AI 对法规条款、生产流程和偏差处理的理解与回复准确性，确保回复内容符合合规要求。
*   使用 API 接口调用知识库，针对关键字段和专业术语进行检索，检查返回结果的相似度分数、相关性排序，并与预期结果进行对比，以确定 `相似度阈值` 和 `召回条数` 是否合理。
*   检查文档上传与解析日志，确保大型或复杂结构的合规文档（如年度质量回顾报告）能够被成功解析，且关键信息字段未出现缺失或乱码，确认 `PARSE_FILE_TIMEOUT_SECONDS` 设置合理。
