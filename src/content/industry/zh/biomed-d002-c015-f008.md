# 临床决策支持产品的工具调用与插件

## 这个品类的数据长什么样

临床决策支持（CDS）产品的数据主要来源于权威医学文献、临床指南、药品说明书、疾病数据库、基因组学数据以及电子健康档案（EHR）。这些数据更新频率不一，例如药品说明书和临床指南可能季度或半年更新，而医学研究论文则持续发布。数据文档结构通常高度标准化，例如药品数据遵循 RxNorm 或 SNOMED CT 编码，疾病数据采用 ICD-10 或 ICD-11 分类。字段包括药物剂量、给药途径、禁忌症、不良反应、疾病诊断标准、治疗方案、基因变异位点等。单位严格遵循国际标准，如毫克（mg）、毫升（mL）、国际单位（IU）、mmol/L 等，并对数值范围有明确定义。

## 这些特征在「工具调用与插件」这一环带来什么约束

CDS 产品数据的高度标准化和严谨性，对工具调用与插件的准确性提出了高要求。首先，数据更新频率的不一致性要求工具调用插件具备灵活的数据同步机制，确保获取到最新版的临床信息，例如药品召回信息或最新指南修订。其次，严格的字段与单位规范意味着插件在解析和传递参数时必须进行精确匹配和单位转换，任何偏差都可能导致错误的决策建议。例如，若剂量单位不匹配，可能导致过量或不足。此外，复杂的文档结构，如嵌套的疾病诊断路径或多分支的治疗方案，要求工具调用插件能够处理复杂的 JSON 或 XML 数据结构，并能正确提取关键信息。对错误处理的鲁棒性也至关重要，因为错误的输入或外部接口故障可能直接影响患者安全。

## 配置怎么定

| 配置项                   | 建议取法                                        | 这样取的依据                                                 |
| :----------------------- | :---------------------------------------------- | :----------------------------------------------------------- |
| `maxContext`             | `4096`                                          | 保证能够容纳完整的临床情境描述和相关查询，避免截断关键信息。 |
| `API_TIMEOUT_SECONDS`    | `60 秒`                                         | 应对外部医学知识库或计算工具可能存在的查询延迟。             |
| `callback_url`           | 部署环境的实际回调地址                          | 确保外部工具执行结果能够准确回传，例如药品相互作用分析结果。 |
| `error_handling_strategy`| `retry_then_fallback`                           | 优先重试外部服务调用，若失败则回退到预设的默认安全决策或提示。 |
| `data_schema_validation` | `strict`                                        | 确保传入和传出数据严格符合预定义的医学数据模式，避免格式错误。 |
| `log_level`              | `INFO`                                          | 记录关键的工具调用输入、输出及异常，便于追溯和问题排查。   |

## 容易做错的三处

*   调用外部医学知识库时返回 `HTTP 401 Unauthorized` 错误：原因通常是 API 密钥 `api_key` 配置不正确或已过期。
*   工具调用后，返回结果中的剂量或单位字段为空：原因可能是外部接口返回的数据结构与期望不符，或插件未正确解析 `dosage_unit` 字段。
*   工作流调用另一个工作流时，被调用工作流无法完整执行：原因往往是父工作流在调用子工作流时，未传递所有必需的 `input_parameters`，导致子工作流因缺少关键信息而中断。

## 怎么确认配好了

*   通过模拟临床案例，验证工具调用能够成功触发外部决策支持系统，并返回预期的决策建议或数据。
*   检查日志输出，确认 `log_level` 为 `INFO` 时，所有工具调用的输入 `input_payload`、输出 `output_response` 和任何潜在的错误 `error_message` 都被正确记录。
*   针对特定疾病和药物组合，手动比对工具调用返回的剂量、禁忌症等关键字段，与权威医学指南或药品说明书中的信息一致。
