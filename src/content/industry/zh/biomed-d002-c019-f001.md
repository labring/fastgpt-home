# 代谢与内分泌产品的HTTP 接口与外部系统

## 这个品类的数据长什么样
代谢与内分泌领域的产品和试剂数据，其主要来源包括官方产品说明书、技术文档、实验报告、临床研究文献以及供应商提供的规格表。这些数据的更新频率通常与产品生命周期和研发进展同步，新品发布、配方改进或批次变更时会进行更新，一般为季度或年度更新。文档结构上，数据常以结构化或半结构化形式存在，例如试剂盒成分列表、检测指标范围、操作步骤、存储条件等。字段方面，常见的有 `产品名称`、`CAS号`、`批次号`、`储存温度`、`有效期`、`检测原理`、`灵敏度`、`特异性`、`线性范围`等。单位上，温度常使用 `℃`，浓度使用 `mg/mL` 或 `µM`，体积使用 `mL` 或 `µL`。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
代谢与内分泌产品数据的低更新频率，意味着外部系统通过HTTP接口同步数据时，无需设置过高的拉取频率，避免不必要的资源消耗，可以设定为每日或每周同步。文档中的结构化与半结构化数据，要求接口设计能够灵活处理JSON或XML等格式，并且需要进行有效的数据解析和字段映射。例如，`CAS号`等唯一标识符是进行产品检索和关联的核心。对于带有单位的字段，如 `储存温度` 或 `线性范围`，在接口传输和系统内部处理时，需要确保单位的一致性或进行明确的单位转换。此外，由于数据量相对较大且包含实验图谱或详细操作步骤的PDF文档链接，HTTP接口需要支持大文件下载或提供稳定的文件存储服务地址，避免因单次请求数据过大而导致的超时或传输失败。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `maxContext` | `2000 字符` | 代谢与内分泌产品描述通常较长，需要更多上下文理解。 |
| `召回条数` | `10 条` | 保证在检索时能覆盖到多种相关产品或试剂，提高准确性。 |
| `相似度阈值` | `0.75` | 确保召回的产品与用户咨询内容高度相关，过滤不准确信息。 |
| `分段长度` | `500 字符` | 兼顾语义完整性与分段效率，适应产品说明书的章节结构。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 处理包含大量图表和详细内容的PDF文档，避免解析超时。 |
| `外部API认证方式` | `Bearer Token` | 行业标准，确保数据传输的安全性与接口访问权限控制。 |

## 容易做错的三处
*   API 调用返回 `{"code":514,"statusText":"unAuthApiKey","message":"common:code_error.e`，原因是没有正确配置或传递 `Authorization` 头部的 API Key。
*   在 FastGPT 后台对话日志中，`使用者` 字段为空或不准确，原因是没有在 API 请求中正确传递 `chatId` 参数，导致系统无法关联用户身份。
*   API 调用大模型时出现连接超时或响应延迟过高，现象是请求长时间无返回，原因是大模型配置未设置为 `stream` 模式，导致模型一次性返回所有内容，增加了传输负担。

## 怎么确认配好了
*   通过 API 接口发送一个包含产品名称和关键参数的查询请求，检查返回结果是否准确包含相关产品的详细信息，并核对 `批次号` 和 `储存温度` 等关键字段的值。
*   在 FastGPT 后台的“对话日志”中，查看通过 API 调用的对话记录，确认 `使用者` 字段是否正确显示，并且对话内容与 API 请求的 `query` 参数一致。
*   使用支持流式传输的客户端工具调用 API，并观察模型响应是否以分块形式逐步返回，以此验证 `stream` 模式是否成功启用。
*   上传一份包含复杂图表和表格的代谢与内分泌产品说明书 PDF 文件，观察文件处理进度，并尝试查询其中特定字段，核对解析结果是否完整准确，确保文件解析耗时在 `PARSE_FILE_TIMEOUT_SECONDS` 配置范围内。
