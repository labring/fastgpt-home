# 减毒灭活疫苗产品的知识库检索与召回

## 这个品类的数据长什么样

减毒灭活疫苗产品的数据主要来源于药品监管机构的审批文件、临床试验报告、药品说明书、学术期刊论文以及企业内部的研发文档。这些数据更新节奏相对稳定，通常在产品上市前和上市后进行阶段性更新，例如批次更新、不良反应补充、适应症扩展等。文档结构上，说明书通常包含成分、适应症、用法用量、不良反应、禁忌、注意事项、贮藏等标准化字段。临床试验报告则包含试验设计、受试者信息、统计分析结果等。字段与单位方面，剂量常以 μg 或 IU 表示，贮藏条件涉及温度（℃）和湿度（%），有效期以月或年为单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束

减毒灭活疫苗数据来源的权威性及其标准化结构，要求知识库检索必须高度准确，避免误导性信息。临床试验报告和说明书中的专业术语、剂量单位、特定病症描述，对分词和实体识别提出了较高要求，以确保关键医学概念的完整性。数据更新的周期性，意味着知识库需要有高效的增量更新机制，以纳入最新的批次信息或不良反应报告。此外，不同文档类型（说明书、报告）的结构差异，需要灵活的文档解析策略，以抽取核心信息，防止因文档格式不一致导致的检索遗漏。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `500–800 字符` | 疫苗说明书和报告中常有较长的段落描述，此长度有助于保持上下文完整性。 |
| `分段重叠长度` | `50 字符` | 确保段落衔接处的语义连续性，避免关键信息被截断。 |
| `召回条数` | `10–15 条` | 疫苗咨询场景对信息的全面性要求较高，适当增加召回数量以覆盖更多相关片段。 |
| `相似度阈值` | `按实测标定` | 根据实际测试结果，平衡召回率与准确率，避免无关片段的引入。 |
| `重排返回条数` | `3–5 条` | 经过重排后，精选出最相关的核心信息，提高回答的精准性。 |
| `解析策略` | `按标题分段` | 疫苗文档通常有明确的章节标题，按标题分段可有效组织语义块。 |

## 容易做错的三处

*   检索结果为空，或者返回的片段与查询意图不符。原因在于分段策略不当，导致关键信息被切割或上下文缺失。
*   知识库更新后，部分查询仍旧返回旧版本信息。原因在于增量更新机制配置不完善，未能及时同步最新数据。
*   系统在处理包含剂量、单位或专业术语的查询时，召回效果不佳。原因在于分词器未针对生物医药领域的专业词汇进行优化，导致语义理解偏差。

## 怎么确认配好了

*   选取一批包含剂量、适应症、禁忌等关键信息的查询，执行检索，核对召回片段是否精准且完整覆盖相关信息。
*   模拟产品批次更新或不良反应报告发布，更新知识库后，测试相关查询，确认系统返回的是最新数据。
*   针对不同文档类型（如说明书、临床报告），分别进行查询测试，验证知识库对不同结构数据的解析和召回能力。
