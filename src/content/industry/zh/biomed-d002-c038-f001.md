# 合理用药产品的HTTP 接口与外部系统

## 这个品类的数据长什么样

合理用药产品的数据源通常包含药品说明书、临床指南、药物相互作用数据库、不良反应报告以及患者用药记录等。这些数据更新频率不一，药品说明书和临床指南可能季度或年度更新，而药物相互作用数据库和不良反应报告则可能实时或每日更新。文档结构复杂，药品说明书通常为非结构化文本，而药物相互作用数据库则为结构化数据，包含 `drug_id`、`interaction_level`、`mechanism` 等字段。患者用药记录则涉及 `patient_id`、`medication_name`、`dosage`、`start_date`、`end_date` 等敏感信息。单位方面，剂量常用毫克（mg）、克（g），频次常用每天（QD）、每小时（Qh），时长常用天（day）、周（week）。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

合理用药数据的高度敏感性要求 HTTP 接口必须采用严格的身份验证和授权机制，例如 OAuth 2.0 或 API Key 配合 IP 白名单。数据更新频率的差异意味着接口需要支持增量更新或周期性全量同步，以保证信息的时效性。非结构化文本数据（如药品说明书）的接入需要强大的文本解析能力和语义理解，确保关键信息能够被准确提取和结构化。结构化数据（如药物相互作用数据库）则要求接口能够处理复杂的 JSON 或 XML 格式，并确保字段映射的准确性，特别是对于 `interaction_level` 等枚举类型字段的映射。此外，药品剂量和频次等单位的标准化处理，对于避免误解和计算错误至关重要。

## 配置怎么定

| 配置项                 | 建议取法                               | 这样取的依据                                                                 |
| :--------------------- | :------------------------------------- | :--------------------------------------------------------------------------- |
| `API_KEY`              | 随机生成 32 位字符串                   | 提升接口安全性，避免未经授权的访问                                           |
| `REQUEST_TIMEOUT_SECONDS` | `60 秒`                                | 应对外部系统响应慢或数据量大时的潜在超时问题                                 |
| `MAX_RETRIES`          | `3`                                    | 应对网络波动或外部系统临时性故障，减少因瞬时问题导致的失败                   |
| `DATA_SCHEMA_VERSION`  | `v2.1`                                 | 确保与外部系统数据结构定义一致，避免解析错误                                 |
| `BATCH_SIZE`           | `500 条记录`                           | 平衡接口请求频率与数据吞吐量，避免单次请求过大或过小                         |
| `ERROR_NOTIFICATION_EMAIL` | `devops@example.com`               | 及时通知开发运维团队接口异常，便于快速响应和处理                             |

## 容易做错的三处

*   调用 FastGPT 对话接口时，未能返回引用的知识库 ID，原因在于外部系统返回的数据结构中未包含或未正确映射知识库标识符字段。
*   服务器在无网络状态下启动 OneAPI 容器服务报错，显示 `failed to get` 等信息，原因在于 OneAPI 在启动时尝试连接外部资源（如模型服务或配置中心），而当前环境不具备网络访问能力。
*   请求外部合理用药接口后，返回的药品剂量单位不一致或为空，原因在于外部系统数据源本身存在单位混用或缺失，且接口未进行标准化转换或校验。

## 怎么确认配好了

*   通过 Postman 或 curl 工具模拟 HTTP 请求，检查 `200 OK` 状态码和返回数据结构的完整性。
*   在 FastGPT 内部日志中查找 `HTTP_REQUEST_SUCCESS` 或 `EXTERNAL_API_CALL` 等关键词，确认接口调用成功记录。
*   核对返回数据中 `medication_name`、`dosage`、`unit` 等关键字段是否与预期值一致，并检查单位是否标准化。
