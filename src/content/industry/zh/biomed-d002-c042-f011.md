# 培养基与耗材产品的文档解析与分块

## 这个品类的数据长什么样

培养基与耗材产品的文档主要包含产品说明书、技术规格书、安全数据表（SDS）和批次分析报告。这些文档通常由供应商提供，更新频率相对较低，主要在产品配方、规格或法规要求变更时更新。文档结构上，产品说明书常包含产品名称、型号、组分、储存条件、使用方法、质量控制指标等分节。技术规格书则更侧重于详细的理化指标和性能参数。SDS会详细列出成分的危害信息。字段方面，常见的有化学成分百分比、pH 值、渗透压、粘度、颗粒度、效期、批号等，单位涉及 g/L、mg/L、pH 单位、mOsm/kg、cP、μm 等多种类型。

## 这些特征在「文档解析与分块」这一环带来什么约束

培养基与耗材文档的特定结构和字段对文档解析与分块提出了具体要求。首先，产品说明书和技术规格书中的表格数据（如组分列表、质量控制标准）是核心信息，需要确保解析时表格结构不被破坏，字段与值能正确关联。其次，SDS中的危害信息和急救措施等关键安全数据，通常以特定章节或格式呈现，需要确保这些关键信息在分块时保持完整性，避免被截断。再次，由于存在多种单位，解析器需能准确识别并保留单位信息，防止单位与数值分离导致语义错误。最后，产品更新频率低，意味着初期构建知识库时需投入精力保证文档解析的准确性，后续维护的压力相对较小，但新增产品或版本更新时，需重新进行精确解析和分块。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `500–800 字符` | 培养基与耗材文档的段落通常包含较多专业术语和参数，适当增加分段长度有助于保留上下文的完整性，避免关键信息被切割。 |
| `分段重叠长度` | `50–100 字符` | 确保相邻分段之间有足够的重叠，以应对跨段落的关键信息，例如成分列表的延续或操作步骤的连贯性。 |
| `解析策略` | `表格优先` | 产品说明书和技术规格书中包含大量表格数据，该策略能确保表格内容被正确识别和提取，保留其结构化信息。 |
| `最大段落深度` | `3` | 多数培养基与耗材文档的层级结构不会过深，此深度足以覆盖大部分章节和子章节。 |
| `文件类型` | `PDF, DOCX, XLSX` | 供应商通常以这些格式提供文档，确保解析器能覆盖主流文件类型。 |

## 容易做错的三处

*   知识库上传表格数据后，部分行数据丢失，因为解析器未正确识别表格边界或跨页表格的连续性，导致数据不完整。
*   上传包含图片的PDF文档后，图片中的文字内容未被提取，因为默认解析模型不具备图像OCR能力。
*   查询产品参数时，结果中数值与单位脱节或单位错误，因为解析器在分块时将数值和单位分离，或者未能准确识别单位符号。

## 怎么确认配好了

*   上传典型产品说明书和技术规格书，检查解析后的分段内容，确保表格结构、关键参数和单位信息完整无误。
*   上传包含复杂图表或扫描件的PDF文档，核对解析结果中是否包含图片周边或内部的文本信息，判断OCR能力是否符合预期。
*   对知识库进行查询测试，针对产品组分、储存条件、安全数据等关键信息进行提问，评估召回结果的准确性和完整性。
*   检查解析日志，确认是否存在文件解析失败或超时的记录，并根据错误信息调整相关配置参数。
