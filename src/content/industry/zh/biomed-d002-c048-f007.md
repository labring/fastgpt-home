# 家用医疗产品的工作流编排

## 这个品类的数据长什么样
家用医疗产品的数据来源多样，包括产品说明书、用户手册、临床报告摘要、合规文件以及市场宣传资料。数据更新频率相对较低，主要集中在新产品发布、法规更新或产品召回时。文档结构通常高度标准化，包含产品名称、型号、功能参数、使用禁忌、维护保养指南、售后服务信息等。字段方面，常见的有 `产品型号`、`序列号`、`生产日期`、`有效期`、`适用人群`、`主要功能`、`技术参数`。单位则严格遵循国际标准，如血压计的 `mmHg`、血糖仪的 `mmol/L` 或 `mg/dL`、血氧仪的 `%SpO2`，确保数据解读的准确性与一致性。

## 这些特征在「工作流编排」这一环带来什么约束
家用医疗产品数据标准化程度高，使得在工作流中进行结构化信息提取和比对成为可能，减少了对非结构化文本处理的依赖。数据更新频率低，意味着知识库的同步策略可以设置为较低频率，例如每月或每季度一次，降低了系统资源消耗。严格的单位规范要求工作流在处理数值型参数时，必须包含单位转换或校验环节，以防因单位不一致导致咨询结果错误。例如，用户咨询血糖值时，系统需要识别用户提供的单位并与知识库中的标准单位进行匹配或转换。此外，合规文件和临床报告摘要的存在，要求工作流具备从复杂文档中精准抽取关键安全信息和适用范围的能力，确保咨询回复的严谨性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `800–1200 字符` | 家用医疗产品说明书通常包含较长的功能描述和注意事项，此长度能较好地保留上下文语义完整性。 |
| `召回条数` | `前 5 条` | 考虑到产品特性和用户咨询的聚焦性，适量召回可确保相关性，避免引入过多噪声信息。 |
| `相似度阈值` | `0.78–0.85` | 医疗产品咨询对准确性要求高，此阈值能有效过滤掉低相关文档，提升精确匹配概率。 |
| `重排返回条数` | `3 条` | 在召回基础上进行重排，挑选最相关的三条信息提供给用户，有助于快速定位核心问题。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 处理大型产品说明书或临床报告时，需要较长的解析时间，避免因超时导致文件处理失败。 |
| `全局变量` | 按实测标定 | 需根据具体工作流逻辑，定义产品型号、法规版本等，便于知识库查询与动态内容生成。 |

## 容易做错的三处
*   工作流执行时，返回结果中关键字段（如 `产品型号`、`适用人群`）为空。原因在于知识库变量引用路径错误，或者在数据抽取环节未正确配置字段映射。
*   在调用外部API获取产品实时库存或价格时，出现 `axioserror` 错误。原因常是API密钥过期、网络连接问题或请求参数格式不符合API规范。
*   用户咨询特定产品功能时，得到的回复与产品说明书存在偏差。原因是知识库更新不及时，或分段策略导致关键信息被截断，未能被召回。

## 怎么确认配好了
*   对典型家用医疗产品咨询场景进行端到端测试，检查回复中是否准确包含了产品名称、型号、功能参数及使用注意事项。
*   验证工作流在处理包含不同单位数值（如 `mg/dL` 和 `mmol/L`）的查询时，能否正确识别并进行内部转换或提示。
*   模拟产品数据更新后，执行知识库同步流程，并验证新数据能否在咨询中被正确引用。
*   检查工作流日志，确认在处理复杂文档时，没有出现 `PARSE_FILE_TIMEOUT_SECONDS` 超时错误，且文档解析成功。
