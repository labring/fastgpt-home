# 家用医疗产品的表单与交互

## 这个品类的数据长什么样

家用医疗产品的数据多来源于产品说明书、用户手册、官方网站的产品详情页、以及医疗器械注册证信息。这些数据更新频率相对较低，通常随产品型号迭代或法规调整而更新。文档结构以半结构化为主，包含大量产品参数、使用方法、禁忌症、注意事项、维修保养等文本描述，以及图片、图表。字段方面，常见的有产品名称、型号、生产厂家、注册证号、适用范围、技术指标（如测量精度、电池续航）、材料成分等。单位多样，涉及长度（毫米、厘米）、重量（克、千克）、时间（小时、天）、数值（毫伏、帕斯卡）以及特定医疗单位（如 mmHg、mmol/L）。

## 这些特征在「表单与交互」这一环带来什么约束

家用医疗产品的低更新频率意味着知识库构建后，日常维护的压力较小，但首次数据录入和清洗工作量较大。半结构化文档要求表单设计能灵活适配不同产品的特有字段，并支持富文本输入，以承载详细的说明信息。多样的单位和技术指标字段需要表单具备单位校验和范围限制功能，防止用户输入无效数据。例如，血压计的测量范围、血糖仪的校准液浓度等，都需严格的数值约束。此外，因产品涉及用户健康，交互设计需强调清晰性、准确性和易用性，避免歧义，特别是在涉及禁忌症和注意事项的咨询环节。

## 配置怎么定

| 配置项                   | 建议取法                                 | 这样取的依据                                                                                                                                                                                                                                                        |
| :----------------------- | :--------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `maxContext`             | `2000 字符`                              | 家用医疗产品说明通常较长，需要足够的上下文长度以提供完整的产品信息和使用指导。                                                                                                                                                                            |
| `minSimilarity`          | `0.8`                                    | 确保检索到的知识点与用户查询高度相关，减少不准确信息的召回，尤其是在涉及产品型号、技术参数等精确匹配的场景。                                                                                                                                                   |
| `segmentLength`          | `500 字符`                               | 适中的分段长度能有效捕获产品说明书中的关键信息块，避免过长分段稀释主题，或过短分段丢失上下文。                                                                                                                                                            |
| `recallTopN`             | `前 5 条`                                | 在保证召回质量的前提下，提供足够多的相关知识点供模型选择，但避免过多冗余信息增加处理负担。                                                                                                                                                                |
| `variableNames`          | `产品名称`、`型号`、`注册证号`           | 确保表单能直接引用和匹配用户常问的核心产品信息，提高咨询效率。                                                                                                                                                                                             |
| `inputValidationRules`   | `数值范围校验`、`单位匹配`、`枚举值限制` | 针对血压、血糖等数值型参数，设置合理的输入范围，并校验单位是否符合标准（如 `mmHg`），对特定参数（如电池类型）可采用枚举值限制，确保数据准确性。                                                                                                          |

## 容易做错的三处

*   在知识库搜索中，选择知识库后，引用变量时显示没有可选值，原因是没有在知识库中配置或提取对应的实体变量。
*   用户在表单中输入数值型参数后，系统提示“无效参数输入”，原因在于表单未对输入值进行单位校验或范围限制，导致超出预设的有效区间。
*   飞书等外部系统集成时，表单输入功能无法正常传入数据，原因可能是 API 接口参数名不匹配，或数据格式不符合目标系统的要求。

## 怎么确认配好了

*   提交包含不同产品型号、技术参数的模拟咨询，检查返回结果是否准确提及对应的产品信息和规格。
*   测试输入超出合理范围的数值或不符合预设格式的文本，确认表单是否能正确触发校验提示，阻止无效提交。
*   通过外部平台（如飞书）调用表单功能，检查数据是否能完整、无误地传递到 FastGPT，并触发相应的知识库查询。
*   针对特定产品，模拟用户提问关于禁忌症或注意事项的问题，验证 FastGPT 是否能准确召回并呈现相关警示信息。
