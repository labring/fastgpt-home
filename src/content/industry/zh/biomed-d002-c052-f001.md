# 干细胞治疗产品的HTTP 接口与外部系统

## 这个品类的数据长什么样
干细胞治疗产品的数据主要来源于临床试验注册库、学术期刊、药品监管机构数据库以及特定生物技术公司的内部研发平台。这些数据更新频率不一，临床试验数据通常在试验进展或结果发布时更新，可能为季度或年度。监管批文信息更新较为及时，通常在审批完成后数日内上线。数据文档结构复杂，常包含产品基本信息（如通用名、商品名、适应症、作用机制）、研发阶段、临床试验设计（入组标准、主要/次要终点、剂量方案）、安全性数据（不良事件分类及发生率）、有效性数据（疗效指标的具体数值与统计学意义）、生产工艺、质量控制标准以及市场准入状态。字段方面，可能涉及细胞株来源、培养基组分、细胞计数（单位：个/mL）、细胞活力百分比、特定标记物表达水平（单位：%或MFI值）等生物学特有指标。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
干细胞治疗产品数据的高复杂性和多样性，要求 HTTP 接口在数据模型设计上具备高度的灵活性和可扩展性，以适应不同来源和类型的结构化与非结构化信息。更新频率的差异意味着需要设计分层的缓存策略和增量更新机制，避免频繁的全量数据拉取，同时保证关键监管信息的实时性。例如，临床试验结果通常以 PDF 报告形式发布，需要集成文档解析能力。生物学特有字段（如细胞计数单位、活力百分比）要求接口在数据传输和存储时保持单位一致性，并支持特定的数据类型校验。此外，安全性与有效性数据的敏感性，对接口的鉴权机制和传输加密提出了更高要求，确保数据合规性与隐私保护。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `maxContext` | `8192 token` | 处理包含大量临床试验细节和生物学参数的复杂查询 |
| `FETCH_TIMEOUT_SECONDS` | `60 秒` | 应对外部系统响应慢或数据量大时的传输延迟 |
| `PARSE_PDF_MAX_PAGES` | `50 页` | 覆盖常见临床试验报告的页数范围，平衡解析效率 |
| `similarityThreshold` | `0.78` | 确保在专业术语高度相似时，能精确匹配核心概念 |
| `embeddingModel` | `text-embedding-ada-002` | 兼顾生物医药领域专业词汇的语义理解与成本效益 |
| `chunkSize` | `800 字符` | 适应干细胞治疗数据中长文本描述（如作用机制、试验方案）的有效切分 |

## 容易做错的三处
*   调用接口后，对话历史中出现重复的回复内容，原因是外部系统在网络波动下重试请求，导致同一消息被处理多次。
*   接口返回的药物剂量字段为空，实际外部系统有数据，原因是在数据映射时，未正确处理外部系统返回的特定单位或别名。
*   在拉取临床试验数据时，接口偶尔会返回 504 Gateway Timeout 错误，原因是外部数据源的 API 存在速率限制，导致请求被阻塞。

## 怎么确认配好了
*   对干细胞治疗产品名称进行查询，核对返回的适应症、作用机制、研发阶段等核心信息是否与权威数据库一致。
*   模拟高并发请求，观察接口响应时间，并检查是否存在异常的超时或连接错误。
*   针对包含图片或表格的 PDF 格式临床报告，验证其内容是否能被正确解析，并提取关键数据字段。
