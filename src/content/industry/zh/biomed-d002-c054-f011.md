# 康复设备产品的文档解析与分块

## 这个品类的数据长什么样

康复设备的数据主要来源于产品说明书、技术手册、临床应用指南、维护保养手册、合规性认证文件等。这些文档通常由制造商发布，更新频率相对较低，主要集中在新产品发布、型号升级或法规变更时。文档结构复杂，可能包含大量图表、插图、技术参数表。字段方面，常涉及尺寸、重量、功率、电压、电流等物理量，以及材质、功能模式、适用人群、禁忌症等描述性信息。单位多采用国际标准单位制，但也可能出现特定行业或地区习惯的单位，如磅、英寸等。

## 这些特征在「文档解析与分块」这一环带来什么约束

康复设备文档的复杂结构，特别是图表和参数表的混杂，要求解析器能够有效区分文本与非文本内容。更新频率低意味着一旦解析完成，知识库的稳定性较高，但初次解析的准确性至关重要。技术参数表中的数值和单位必须被正确识别和关联，以避免问答时出现单位混淆或数值误读。多语言版本文档的存在，可能需要考虑多语言处理能力。此外，文档中包含的临床应用场景和禁忌症等关键信息，其完整性和准确性直接影响咨询结果的可靠性，因此分块时需确保这些逻辑关联性强的片段不被割裂。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `800–1200 字符` | 康复设备说明书逻辑段落较长，包含多项技术参数或操作步骤，此长度有助于保持上下文完整性。 |
| `重叠长度` | `100–200 字符` | 确保相邻分段之间有足够重叠，以捕捉跨分段的关键信息和上下文关联。 |
| `自动分段策略` | `按标题和段落` | 康复设备文档通常有清晰的标题层级和自然段落，此策略能有效保持语义完整性。 |
| `最大文件大小` | `100 MB` | 康复设备技术手册可能包含高分辨率图片和详细图表，文件体积较大。 |
| `解析超时时间` | `300 秒` | 复杂PDF文档的解析可能耗时较长，增加超时时间可避免解析中断。 |
| `图像OCR` | `启用` | 康复设备文档中大量技术参数可能以图片形式呈现，启用OCR确保信息提取全面。 |

## 容易做错的三处

*   解析结果中技术参数数值与单位分离，导致查询时数值无法匹配或单位错误。原因在于解析器未能将数值和其紧邻的单位识别为一体。
*   上传的Excel格式文档，分块后每行数据被错误地拆分成多个片段，导致查询结果不完整。原因在于默认分段策略未针对表格数据结构优化，未能识别表格行作为独立语义单元。
*   大型PDF文档上传后长时间无响应或解析失败，提示`PARSE_FILE_TIMEOUT`。原因在于默认解析超时时间过短，未能处理复杂文档的解析耗时。

## 怎么确认配好了

*   上传典型产品说明书，通过知识库预览功能检查分段是否逻辑连贯，关键技术参数是否完整保留在单个分段内。
*   针对包含表格数据的维护手册，上传后验证表格行是否被视为独立分段，且每行数据字段完整。
*   上传超大容量的临床应用指南，观察解析过程是否顺利完成，无超时报错，并检查解析日志确认状态码为成功。
