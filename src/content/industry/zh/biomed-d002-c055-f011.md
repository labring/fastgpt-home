# 影像设备产品的文档解析与分块

## 这个品类的数据长什么样
影像设备产品的数据来源多样，主要包括产品手册、技术规格书、操作指南、维护手册以及临床应用案例等。这些文档通常由制造商发布，更新节奏相对稳定，主要集中在新产品发布、固件升级或法规变更时。文档结构上，多数采用章节式编排，包含大量图片、图表、结构示意图，以及详细的参数列表。例如，MRI 设备手册会详细列出磁场强度（单位：特斯拉）、梯度场强（单位：毫特斯拉/米）、扫描序列名称、图像分辨率（单位：像素），并配有波形图和扫描协议示例。CT 设备文档则会涉及探测器类型、X射线管电压（单位：千伏）、电流（单位：毫安秒）、扫描速度（单位：秒）等。这些文档普遍具有严谨的专业术语和精确的数值描述。

## 这些特征在「文档解析与分块」这一环带来什么约束
影像设备文档的章节式结构和大量的图表使得直接按自然段落分块可能导致语义断裂。关键的技术参数和专业术语分散在文本、表格和图注中，需要确保分块能够捕获这些核心信息。文档中包含的图像和复杂布局，对文本提取的准确性提出了更高要求。例如，表格中的参数如果未能正确解析，将直接影响后续的问答准确性。此外，由于影像设备产品的专业性，很多参数具有特定的单位和数值范围，分块时需尽量保持这些数值与单位的关联性，避免被拆分到不同的块中，影响上下文理解。文档更新不频繁，但每次更新可能涉及核心性能指标或安全规范，要求系统能够识别并优先处理这些关键修订部分。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `分段长度` | `500–800 字符` | 兼顾语义完整性和召回效率，避免过长分块稀释关键信息，过短分块丢失上下文。 |
| `最大段落深度` | `3` | 影像设备文档通常有清晰的章节、小节结构，此深度足以覆盖大部分层级，保持结构化信息。 |
| `索引大小` | `128` | 确保索引的粒度适中，能够有效区分不同设备型号、功能或参数的细节。 |
| `模型识别段落` | `开启` | 利用模型识别文档的逻辑段落边界，提升解析准确性，尤其适用于技术手册。 |
| `API_TIMEOUT_SECONDS` | `600 秒` | 影像设备手册可能包含大量页面，文件解析耗时较长，增加超时时间防止中断。 |
| `解析类型` | `PDF` | 影像设备文档多以 PDF 格式分发，选择针对 PDF 优化的解析器，提升图文混合解析效果。 |

## 容易做错的三处
- 文档解析后出现大量乱码或缺失关键参数：原因在于文档中包含复杂的图表或非标准字体，默认解析器未能正确识别。
- 对话中无法准确回答关于某特定型号设备的参数问题，仅返回通用描述：原因在于文档分块过大，特定型号的详细参数被泛化信息稀释，导致召回不精确。
- 上传大型 PDF 手册后，系统长时间无响应或报错 `504 Gateway Timeout`：原因在于文件体积过大或解析复杂，超出了默认的 API 请求超时时间 `API_TIMEOUT_SECONDS`。

## 怎么确认配好了
- 随机抽取 5 份不同型号的影像设备文档进行解析，检查解析后的文本内容是否完整、无乱码，并重点核对关键技术参数（如磁场强度、电压、像素）是否正确提取。
- 针对解析后的文档，提出关于设备特定功能或参数的精确问题，例如“某款 CT 设备的 X 射线管电压是多少？”，检查系统能否给出准确且包含单位的回答，并评估召回的知识块是否包含所需信息。
- 尝试上传一份包含表格和图片较多的复杂文档，观察解析过程是否顺畅完成，没有出现超时或解析失败的提示，并检查解析结果中表格内容的完整性。
- 比对解析后的文档分块结果，检查同一逻辑段落（如某一功能模块的描述）是否被完整分在一个或少数几个块中，避免语义被过度拆分。
