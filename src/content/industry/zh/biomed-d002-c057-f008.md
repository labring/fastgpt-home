# 心血管介入产品的工具调用与插件

## 这个品类的数据长什么样

心血管介入产品的数据主要来源于医疗器械制造商的产品说明书、临床研究报告、注册审批文件以及行业协会发布的标准与指南。这些文档通常以 PDF 格式为主，包含大量的图片、图表和结构化信息。数据的更新频率相对稳定，新产品上市或现有产品迭代时会发布更新，但通常不会过于频繁。文档结构往往高度标准化，遵循医疗器械产品技术要求和行业规范。字段方面，常见的包括产品型号、规格、材质、涂层、尺寸（如支架直径 `mm`、长度 `mm`、导丝直径 `inch`）、适应症、禁忌症、使用方法、不良事件发生率等，单位严谨且统一。

## 这些特征在「工具调用与插件」这一环带来什么约束

心血管介入产品的数据特征对工具调用与插件的配置提出了特定要求。首先，大量的 PDF 文档和图片意味着需要强大的文档解析能力，以及对多模态内容的识别与处理。结构化的产品参数决定了工具调用需要精确匹配字段，例如在查询特定支架的直径范围时，必须能识别并提取 `mm` 单位下的数值。数据更新频率相对较低，因此对缓存策略和数据同步的实时性要求适中。文档的标准化结构有利于通过正则表达式或特定标记来提取信息，但也要求工具能处理复杂表格和嵌套结构。此外，由于产品信息通常涉及专业术语和临床细节，需要插件具备一定的医学术语理解能力，以避免误解或遗漏关键信息。

## 配置怎么定

| 配置项                       | 建议取法       | 这样取的依据                                       |
| :--------------------------- | :------------- | :------------------------------------------------- |
| `UPLOAD_FILE_MAX_SIZE`       | `500 MB`       | 处理包含大量图片和图表的 PDF 文档                  |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒`       | 确保大型、复杂 PDF 文件的完整解析                  |
| `分段长度`                   | `800–1200 字符` | 平衡上下文完整性与检索效率，避免切断关键描述       |
| `召回条数`                   | `前 8 条`      | 覆盖多种产品规格或相关临床信息，提高召回准确率     |
| `相似度阈值`                 | `0.75`         | 确保检索结果高度相关，避免无关产品信息干扰         |
| `http_timeout`               | `30000 毫秒`   | 应对可能存在的外部 API 响应慢或数据量大的情况      |

## 容易做错的三处

*   调用外部 API 时返回 `Invalid URL` 或 `code: 500`，通常是由于传递给 API 的参数格式不正确，或 URL 拼接有误。
*   工具调用节点输出了冗余或不必要的 AI 回复，原因是未正确配置工具的 `is_agent_response` 参数或后处理逻辑。
*   多模态文件上传后，部分图片或图表内容未能被有效识别和提取，这可能是由于 `Multimodal file size is` 提示的限制，或图像解析服务配置不足。

## 怎么确认配好了

*   上传一个包含表格和图片的典型产品说明书 PDF，检查解析后的文本内容是否完整且结构正确，特别是产品规格和使用方法等关键字段。
*   针对特定产品型号发起咨询，观察工具调用是否能准确地提取出对应的参数（如支架直径 `mm`、长度 `mm`），并校验返回结果与原始文档的一致性。
*   触发一个需要调用外部 API 的查询（例如查询某个产品的最新注册状态），检查工具调用日志，确认 API 请求参数、响应状态码 `200` 以及返回数据是否符合预期。
