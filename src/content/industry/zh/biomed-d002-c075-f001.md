# 生物等效性产品的HTTP 接口与外部系统

## 这个品类的数据长什么样
生物等效性（BE）研究数据主要来源于临床试验报告、药代动力学（PK）分析结果以及生物样本检测数据。这些数据通常以结构化或半结构化文档形式存在，例如 PDF 格式的临床研究报告、Excel 或 CSV 格式的 PK 参数表、以及 LIMS 系统导出的生物分析原始数据。数据更新频率取决于研究进展，在临床试验阶段可能每周或每月更新，而在申报阶段则趋于稳定。字段包括受试者信息、给药方案、血药浓度-时间曲线数据、药代动力学参数（如 Cmax、AUC0-t、Tmax、t1/2）、统计分析结果（如几何均数比值及其 90% 置信区间）。单位通常涉及剂量（mg）、时间（h）、浓度（ng/mL）、面积（ng·h/mL）等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
生物等效性数据的复杂性和多样性，要求 HTTP 接口具备强大的文件解析能力。大量的结构化和半结构化数据，例如 PK 参数表格，需要准确提取关键数值和文本信息，并映射到知识库的特定字段。临床研究报告中的非结构化文本，例如研究方案描述或不良事件报告，则需要通过自然语言处理技术进行语义理解和信息抽取。数据更新的周期性特点，例如试验数据阶段性更新，决定了接口需要支持增量更新或周期性全量同步机制。同时，血药浓度等时间序列数据可能需要特定处理，以支持图表生成或趋势分析。严格的数据准确性要求，使得在数据传输和解析过程中必须有完善的校验机制，确保单位和数值的正确性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 考虑临床研究报告、原始数据文件等可能较大 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 大型 PDF 文件或复杂表格解析需要较长时间 |
| `分段长度` | `500 字符` | 兼顾文本语义完整性与召回效率，避免过度截断 |
| `相似度阈值` | `0.75` | 生物等效性数据对准确性要求高，减少不相关召回 |
| `重排返回条数` | `5 条` | 确保核心相关信息在小范围内呈现，便于用户快速获取 |
| `HTTP_REQUEST_TIMEOUT` | `60 秒` | 外部系统数据传输可能因数据量大而耗时 |

## 容易做错的三处
*   从外部系统拉取数据时，接口返回 `HTTP 504 Gateway Timeout` 错误，这是因为数据量过大或外部系统响应慢，导致 FastGPT 侧的请求超时。
*   上传的 Excel 文件中，部分药代动力学参数字段为空，原因是没有正确配置列名映射规则，导致解析器无法识别特定单位或缩写。
*   在对话中询问特定生物等效性报告的统计结果，AI 回答不准确或缺失关键数值，这是由于 PDF 文档解析时未能有效识别表格中的数值并将其结构化存储。

## 怎么确认配好了
*   上传一份包含复杂表格和多页文本的生物等效性报告 PDF 文件，检查知识库中是否正确提取并存储了所有关键的药代动力学参数和研究结论。
*   通过 HTTP 接口从外部 LIMS 系统同步一批血药浓度原始数据，核对同步后的数据字段名、数值和单位是否与源系统一致。
*   进行模拟对话测试，针对知识库中不同类型的生物等效性数据（如 BE 试验方案、PK 参数表、统计分析结果）提出问题，评估 AI 回答的准确性和完整性，并检查引用文档是否指向正确的数据源。
