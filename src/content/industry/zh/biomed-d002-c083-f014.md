# 稳定性研究产品的表单与交互

## 这个品类的数据长什么样
生物医药领域的稳定性研究数据主要来源于长期的实验监测报告。这些数据通常以结构化表格、图谱或文本描述的形式存在，记录了药品、试剂或生物制品在不同温度、湿度、光照等条件下，随时间推移的物理、化学和生物学性质变化。数据更新频率通常较低，可能按月、季度或年度进行。文档格式多样，包括 PDF 报告、Excel 表格或LIMS（实验室信息管理系统）导出的 CSV 文件。关键字段包括批次号、样品编号、检测日期、储存条件、检测项目（如含量、纯度、溶出度、pH值）、检测结果及单位（如 %、mg/ml、IU/mg），以及判定标准和结论。

## 这些特征在「表单与交互」这一环带来什么约束
稳定性研究数据的低更新频率意味着知识库构建时，初期数据摄入量大，但后续增量更新较少，主要关注历史数据的准确性和完整性。多样的文档格式要求 FastGPT 在数据摄入阶段具备强大的文档解析能力，特别是对 PDF 和 Excel 中表格数据的结构化提取。字段与单位的规范性，例如含量“%”与“mg/ml”的区分，以及 pH 值范围的界定，直接影响表单设计时对用户输入的校验规则和单位选择控件。此外，批次号和样品编号等唯一标识符是构建有效检索和关联查询的基础，需要在表单设计时作为核心查询项突出。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 稳定性研究报告通常包含大量图表和原始数据，单个文件大小可能较大。 |
| `分段长度` | `800 字符` | 确保每个分段包含足够的上下文信息，便于理解实验条件与结果的关联。 |
| `召回条数` | `前 5 条` | 稳定性研究报告中，相关信息往往集中且关联性强，过多召回可能引入噪声。 |
| `相似度阈值` | `0.75` | 保证召回结果与用户查询高度相关，减少不准确的实验数据或结论。 |
| `maxContext` | `3000 Tokens` | 应对用户可能提出的复杂查询，例如跨多个批次的综合稳定性趋势分析。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 处理大型 PDF 或 Excel 文件时，解析时间可能较长，避免解析超时。 |

## 容易做错的三处
*   用户输入批次号后，系统返回“未找到相关信息”，原因通常是数据摄入时批次号字段未被正确识别或索引，导致检索不匹配。
*   用户查询某个检测项目的历史数据，结果却缺失部分时间点的数据，这可能由于原始报告中的时间戳格式不统一，或解析时未将所有时间序列数据完全提取。
*   用户在表单中输入“含量”，系统却提示“单位不匹配”，现象是由于表单配置未提供“%”和“mg/ml”等多种常用单位选项，或输入校验规则过于严格。

## 怎么确认配好了
*   上传典型稳定性研究报告（PDF、Excel、CSV），检查知识库中是否正确提取了批次号、样品编号、检测项目、结果和单位等关键字段。
*   通过 API 调用获取应用的初始化信息，核对开场白和预设表单字段是否与稳定性研究的常见咨询场景相符。
*   模拟用户提问，例如查询某个批次在特定储存条件下的溶出度变化趋势，确认系统能够准确召回相关数据并给出合理响应，并验证表单输入功能能够正确传入后端服务。
