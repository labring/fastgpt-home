# 自身免疫产品的知识库检索与召回

## 这个品类的数据长什么样

自身免疫疾病领域的产品与试剂，其数据来源广泛，涵盖了体外诊断（IVD）试剂说明书、产品技术手册、临床研究报告、专利文献、法规文件以及学术论文等。数据更新频率因类型而异，IVD 试剂说明书和产品手册通常随产品版本迭代或批次更新，而临床研究和学术论文则持续发布。文档结构多为规范化的 PDF 或 Word 格式，包含大量的专业术语、缩写、图表与数据。字段与单位具有高度特异性，例如抗体滴度（IU/mL, U/mL）、灵敏度（%）、特异性（%）、检测限（LOD）、定量限（LOQ）等，这些参数在不同产品和检测方法之间可能存在差异。

## 这些特征在「知识库检索与召回」这一环带来什么约束

自身免疫领域数据的高度专业性和规范化结构，对知识库的召回精度提出了挑战。大量专业术语和缩写要求模型具备强大的语义理解能力，能够识别同义词、近义词以及上下位概念，避免因字面匹配不足导致漏召。产品说明书中的图表和表格内容，如果无法被有效解析和向量化，将导致重要信息丢失。数据更新的周期性，特别是新批次产品说明书的发布，要求知识库具备高效的增量更新机制，确保召回信息的时效性。此外，字段与单位的特异性，如数值范围和特定单位的组合，要求检索结果能够精确匹配，避免因单位混淆或数值误读造成的错误信息。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `800–1200 字符` | 确保单个分段包含完整的概念或论述，避免因切分过细导致语义破碎。 |
| `分段重叠` | `100–200 字符` | 保证上下文的连续性，提高跨段落信息召回的完整性。 |
| `召回条数` | `前 8–12 条` | 在保证覆盖度的前提下，兼顾后续重排模块的处理效率。 |
| `相似度阈值` | 按实测标定 | 根据实际语料库和查询类型，通过测试召回率和精确率确定。 |
| `重排返回条数` | `前 3–5 条` | 筛选出最相关的少数结果，减轻用户阅读负担，提高信息获取效率。 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 适应包含大量图表或高分辨率图片的 PDF 文档上传需求。 |

## 容易做错的三处

*   上传 PDF 文件后预览显示「无法读取该文件内容」：现象通常是 PDF 内部编码或格式异常，导致解析库无法正确识别文本层。
*   上传 PPT 或 PDF 后无法同步到知识库：原因是系统配置未开启对这些文件类型的解析支持，或解析服务超时。
*   新建知识库时缺少图片理解模型的选项：现象是界面上未出现相关配置项，这通常是由于部署版本不支持该功能，或相关依赖未正确安装。

## 怎么确认配好了

*   上传数份典型的自身免疫产品说明书 PDF，检查文件分段是否合理，语义完整性是否保持。
*   针对说明书中包含的特定抗体名称、检测指标及数值范围进行查询，验证召回结果是否包含正确的信息来源。
*   模拟用户咨询场景，使用口语化或非标准术语提问，核对召回结果的相关性与准确性，并根据评估结果调整 `相似度阈值`。
*   检查知识库中 IVD 试剂说明书的最新版本是否已成功同步，确保新产品信息的及时性。
