# 药物经济学产品的HTTP 接口与外部系统

## 这个品类的数据长什么样

药物经济学数据通常来源于多方，包括临床试验报告、真实世界证据（RWE）研究、医疗费用数据库、药品定价政策文件以及卫生技术评估（HTA）机构发布的报告。这些数据更新频率不一，临床试验数据可能数年更新一次，而药品价格或医保支付政策则可能每年或每季度调整。文档结构多样，常见有PDF格式的报告、Excel表格形式的成本效益模型输入数据、以及结构化数据库中的药品使用和费用明细。字段方面，特有指标包括质量调整生命年（QALY）、增量成本效益比（ICER）、药物日均费用（DDD）等，单位涉及货币（如美元、欧元）、生命年、以及各种临床指标单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

药物经济学数据来源的复杂性和多样性，要求HTTP接口能够处理多种数据格式和认证机制。例如，访问HTA机构的API可能需要特定的API密钥或OAuth认证。数据更新频率的不一致性，意味着外部系统集成时需要设计灵活的缓存策略和数据同步机制，避免频繁拉取静态数据，同时确保关键动态数据（如最新药价）的及时性。文档结构的多样性，尤其是大量非结构化PDF报告的存在，使得HTTP接口返回的数据解析成为挑战，可能需要结合OCR或文档解析服务。特有字段和单位的存在，要求接口在数据传输时能清晰定义数据类型和单位，避免下游系统解析错误，例如货币单位的明确标识（`currency_code`）和QALY值的浮点数精度。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `requestTimeout` | `60 秒` | 药物经济学数据查询可能涉及复杂计算或多源数据聚合，适当延长超时时间以应对潜在延迟。 |
| `maxRetries` | `3 次` | 外部数据源偶发性网络抖动或服务不稳定，重试机制可提高成功率。 |
| `contentType` | `application/json` 或 `application/xml` | 确保与外部API约定的数据交换格式一致，通常为JSON或XML。 |
| `headers` | 包含 `Authorization` 字段 | 许多药物经济学数据API需要API Key或Bearer Token进行身份验证。 |
| `cacheTTL` | `24 小时` | 针对更新频率较低的静态数据，如历史ICER值，设置缓存可减少API调用负担。 |
| `responseSchema` | 按外部API文档定义 | 明确响应数据结构，便于后续的数据提取和验证，例如包含 `ic_value` 和 `currency_unit` 字段。 |

## 容易做错的三处

*   调用外部API时返回 `HTTP 401 Unauthorized` 或 `403 Forbidden`，原因是没有正确配置或传递 `Authorization` 请求头中的API密钥或令牌。
*   HTTP请求成功但返回结果中关键字段（如 `QALY_value` 或 `cost_per_patient`）为空，原因可能是请求参数错误，或者外部API在特定条件下不返回该字段。
*   处理返回的PPTX文件时无法直接存储并提供给用户，原因在于HTTP客户端默认将响应体作为文本处理，需要配置为二进制流并正确写入文件系统。

## 怎么确认配好了

*   通过API调试工具（如Postman）模拟请求，验证HTTP状态码为 `200 OK`，并检查响应体是否包含预期的药物经济学关键字段（如 `ICER`、`QALY`）。
*   在FastGPT中实际调用该HTTP接口，观察日志输出，确认没有出现连接超时或解析失败的错误信息。
*   针对特定查询，比对外部系统直接返回的数据与FastGPT通过HTTP接口获取并处理后的数据，验证数值精度和单位是否一致，尤其关注货币和时间单位。
