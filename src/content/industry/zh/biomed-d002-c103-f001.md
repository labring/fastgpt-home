# 零售连锁产品的HTTP 接口与外部系统

## 这个品类的数据长什么样
生物医药零售连锁的产品与试剂数据通常来源于企业内部的商品管理系统（PIM）、库存管理系统（IMS）或供应商提供的电子目录。数据更新频率较高，新品上架、库存变动、促销活动等均可触发更新，可能达到小时级甚至分钟级。文档结构多为结构化数据，如JSON或XML格式，包含产品名称、SKU、批号、有效期、存储条件、适应症、用法用量、禁忌、不良反应、价格、库存量、门店分布等字段。单位涉及剂量（mg、ml）、包装规格（盒、瓶）、温度（℃）等，且有严格的数值范围限制。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
高频的数据更新要求HTTP接口具备高效的同步或异步更新机制，以确保用户获取的信息实时准确。结构化数据特性使得接口设计时需重点关注字段映射的准确性与完整性，尤其对于批号、有效期等溯源关键信息，需要确保其在不同系统间的一致性传递。数据量大且字段复杂，对接口的响应速度和并发处理能力提出更高要求。同时，生物医药产品的特殊性决定了对数据准确性和安全性的极致追求，接口需支持严格的身份认证和数据加密，并能有效处理因数据格式不符或业务逻辑校验失败导致的错误，确保咨询服务的可靠性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `requestTimeout` | `60 秒` | 应对复杂查询或外部系统响应慢的情况，避免超时中断。 |
| `maxConnections` | `按实测标定` | 根据外部系统承载能力和并发需求动态调整，保障系统稳定性。 |
| `retryAttempts` | `3 次` | 面对瞬时网络波动或外部服务短暂不可用，增加请求成功率。 |
| `header.Authorization` | `Bearer <token>` | 确保接口调用具备合法的认证凭证，符合安全规范。 |
| `body.product_id` | `字符串类型` | 匹配零售系统产品唯一标识的字段类型，保证数据传递准确。 |
| `response.status_code` | `200` | 确认外部系统成功处理请求，否则视为调用失败。 |

## 容易做错的三处
*   调用外部 rerank 服务时，选择自定义渠道后请求失败，常见原因是 `Authorization` 请求头或 `Content-Type` 头未正确设置。
*   FastGPT 调用 OneAPI 代理 OpenAI 服务时，如果 OneAPI 启动报错，通常日志会显示网络不通，这可能是因为 OneAPI 容器内部无法访问 OpenAI API 地址，需要检查容器的网络配置或代理设置。
*   上传图片模型无法解析，现象是模型无法从图片中提取信息，原因在于当前模型或接口不支持直接解析图片作为输入，需要先将图片转换为文本描述或使用支持多模态输入的模型。

## 怎么确认配好了
*   对核心产品信息查询接口进行端到端测试，验证返回的产品名称、价格、库存等字段与源系统数据是否完全一致。
*   模拟高并发场景，观察HTTP接口的响应时间（`responseTime`）和错误率，确保在压力下系统仍能稳定提供服务，并根据实际负载调整 `maxConnections`。
*   检查外部系统日志，确认每次FastGPT发出的请求都被正确接收和处理，并核对返回的关键业务字段（如 `product_sku`、`inventory_level`）是否符合预期，以及 `response.status_code` 是否为成功状态码。
