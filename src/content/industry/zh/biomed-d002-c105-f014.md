# 骨科植入产品的表单与交互

## 这个品类的数据长什么样
骨科植入产品的数据主要来源于医疗器械注册证、产品说明书、技术标准、临床试验报告以及供应链批次信息。数据更新频率相对较低，主要集中在产品型号迭代、注册证变更或法规更新时。文档结构通常以 PDF 格式为主，包含大量图表、技术参数表和操作步骤。字段方面，特有字段包括材料成分（如 `Ti-6Al-4V` 钛合金）、表面处理工艺（如 `HA涂层`）、植入部位（如 `股骨`、`脊柱`）、尺寸规格（如 `直径 6.0mm`、`长度 120mm`）、无菌状态（如 `EO灭菌`）、使用寿命和批次号。单位多涉及毫米（`mm`）、牛顿（`N`）、兆帕（`MPa`）等工程和生物力学单位。

## 这些特征在「表单与交互」这一环带来什么约束
骨科植入产品的数据特征对表单与交互设计提出了特定要求。首先，PDF 文档的普遍性意味着需要强大的文档解析能力，以准确提取图表和表格中的结构化数据。产品更新频率低，但每次更新可能涉及关键技术参数，这要求知识库具备版本管理功能，确保检索到的是最新有效信息。交互设计上，查询往往涉及多维度约束，例如用户可能同时关注特定材料、特定尺寸和特定适应症的产品。这要求表单支持复杂的组合查询，例如通过下拉菜单选择植入部位，通过输入框限定尺寸范围。同时，批次号等信息在售后追溯中至关重要，需要在交互中提供便捷的查询入口。对于类似 `HA涂层` 这样的专业术语，需要有同义词或解释提示功能，提升非专业用户或初级工程师的查询体验。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `500 字符` | 骨科植入产品说明书常有较长的技术描述段落，适中长度可保证上下文完整性 |
| `召回条数` | `前 8 条` | 确保覆盖产品不同维度的关键信息，避免遗漏相关规格或临床数据 |
| `相似度阈值` | `0.75` | 考虑到专业术语和型号的精确性，高阈值可减少不相关结果 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 处理包含大量图表和表格的 PDF 文档可能耗时较长，防止解析超时 |
| `maxContext` | `4000 token` | 确保在生成回复时能包含足够的产品参数、材料和使用说明 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 产品说明书和注册证文件可能较大，需要支持大文件上传 |

## 容易做错的三处
1. 查询结果中产品型号或规格不匹配：原因在于知识库分段策略不当，导致关键参数被截断或上下文丢失，影响匹配精度。
2. 用户输入专业术语时无法获得有效回复：原因在于缺少同义词管理或术语解释功能，导致系统无法理解或关联用户的查询意图。
3. 表单提交后长时间无响应或报错：原因在于后端文档解析服务处理复杂 PDF 文件时超时，或文件大小超出限制。

## 怎么确认配好了
1. 使用包含不同材料、尺寸和表面处理工艺的骨科植入产品名称进行查询，核对返回结果是否准确包含了所有相关参数。
2. 尝试输入产品说明书中出现的专业术语或缩写，验证系统能否给出正确的解释或关联到相关产品。
3. 上传一份包含大量图表和表格的 PDF 格式产品注册证文件，观察文件解析进度和最终能否成功提取出关键信息。
4. 模拟用户通过表单组合查询多个条件（例如 `钛合金 股骨 6.0mm`），检查返回的产品列表是否符合预期。
