# 骨科植入产品的部署与升级

## 这个品类的数据长什么样

骨科植入产品的数据来源多样，主要包括产品说明书、注册证、临床试验报告、操作手册、学术论文以及企业内部的销售与培训资料。这些文档的更新频率较高，尤其是新产品上市、注册证变更或技术迭代时。文档结构上，通常包含大量专业术语、图片（如植入物设计图、X光片）、表格（如尺寸规格、力学性能数据）和图表。字段方面，常见的有 `产品型号`、`材料成分`、`尺寸规格`、`适用症`、`禁忌症`、`灭菌方式`、`使用寿命`、`注册证号`等。单位涉及毫米、克、牛顿、兆帕、摄氏度、年等多种物理量单位，且对精度要求严格。

## 这些特征在「部署与升级」这一环带来什么约束

骨科植入产品数据的高更新频率要求知识库系统具备高效的增量更新机制，以确保信息的时效性。文档中包含的复杂图片和表格，对文件解析和内容抽取能力提出挑战，需要支持多模态数据处理。专业术语和严格的单位精度，要求模型在理解和生成时保持高度准确性，避免误读或误传。此外，注册证号等关键结构化信息需要准确识别和索引，以便于精确检索。部署时，需要考虑对这些复杂数据类型的处理能力，以及升级过程中新旧数据模型的兼容性，确保知识库的连续性和稳定性。

## 配置怎么定

| 配置项                 | 建议取法                               | 这样取的依据                                                                 |
| :--------------------- | :------------------------------------- | :--------------------------------------------------------------------------- |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB`                               | 应对产品说明书和临床报告中包含的大量高分辨率图片和图表文件体积。           |
| `maxContext`           | `8000`                                 | 确保模型能处理包含详细技术规格和临床数据的长篇文档上下文。                   |
| `分段长度`             | `800–1200 字符`                        | 兼顾语义完整性和搜索效率，避免专业术语被截断，同时保证召回效率。             |
| `召回条数`             | `前 10 条`                             | 骨科植入问询对信息全面性要求高，增加召回条数可提高相关性信息覆盖率。         |
| `相似度阈值`           | 按实测标定                               | 需根据实际数据和模型表现，通过测试调整，确保召回结果既相关又精确。           |
| `重排返回条数`         | `前 5 条`                              | 经过重排的模型能更精准地识别核心相关信息，聚焦于最直接的答案。               |
| `IMAGE_INDEX_ENABLED`  | `true`                                 | 启用图像索引功能，对产品设计图、X光片等关键视觉信息进行有效检索和理解。      |

## 容易做错的三处

*   新上传的带有图片的产品说明书在问答时无法提供图片相关内容：原因在于没有开启 `IMAGE_INDEX_ENABLED` 参数，或模型未配置图像处理能力。
*   知识库更新后，模型对旧数据的回答出现专业术语理解偏差：原因在于新模型版本对特定领域术语的微调不足，或旧数据索引未完全重建。
*   文档上传或知识库更新过程中出现 `HTTP 504 Gateway Timeout` 错误：原因在于 `PARSE_FILE_TIMEOUT_SECONDS` 参数设置过低，未能处理大型或复杂文档的解析。

## 怎么确认配好了

*   上传一份包含产品设计图和规格表格的说明书，提问图片或表格中的具体数据，检查回复是否准确。
*   对骨科植入产品中的特定专业术语进行提问，例如“髓内钉的锁定方式”，检查模型是否能正确理解并给出相关解释。
*   通过系统日志查看文件解析任务的完成时间，确保大型文档的解析未出现 `PARSE_FILE_TIMEOUT_SECONDS` 超时错误。
*   在知识库中检索一个已更新过的产品型号，检查返回信息是否为最新版本，并验证其数据准确性。
