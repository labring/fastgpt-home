# 高值耗材产品的HTTP 接口与外部系统

## 这个品类的数据长什么样
高值耗材的数据主要来源于生产厂商的官方数据库、国家药监局的医疗器械注册信息以及各级医院的采购与库存管理系统。这些数据更新频率相对较低，通常按季度或年度发布，但涉及价格、批次和有效期等关键信息时，更新会更为频繁。文档结构通常包含产品名称、型号规格、注册证号、生产企业、适用范围、主要参数、单位、包装、批号、灭菌方式、储存条件以及唯一的UDI（唯一器械标识）编码。字段单位严格，例如尺寸以毫米或厘米表示，容量以毫升或升表示，且常伴随特定的医学缩写。UDI编码作为核心标识符，其格式和解析规则需要精确遵循国际标准。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
高值耗材数据更新频率较低，意味着接口调用不必过于频繁，但每次调用需确保数据完整性和一致性。UDI编码的唯一性和复杂性要求接口参数设计时，必须能准确接收和解析包含多段信息的编码字符串。数据来源的多样性使得接口设计需要考虑数据清洗和标准化，以统一不同来源的字段命名和单位表示。例如，不同系统可能对“有效期”有不同的字段名或日期格式。此外，涉及批号和效期的查询，对实时性有一定要求，需要确保接口能快速响应。由于这类数据通常用于决策支持和合规性审查，对数据传输的安全性、准确性和可追溯性有较高要求，需要通过安全的HTTP协议和严格的认证机制保障。

## 配置怎么定

| 配置项                 | 建议取法                                | 这样取的依据                                                                                             |
| :--------------------- | :-------------------------------------- | :------------------------------------------------------------------------------------------------------- |
| `API_ENDPOINT`         | 厂商或监管机构的官方 API 地址           | 确保数据来源的权威性和最新性，例如 `https://data.nmpa.gov.cn/api/medical_device`                          |
| `AUTH_HEADER`          | `Authorization: Bearer <API_KEY>`       | 采用标准的 OAuth2 或 API Key 认证，保障数据接口安全                                                    |
| `REQUEST_TIMEOUT_SECONDS` | `60 秒`                                 | 考虑到数据量可能较大，预留充足的响应时间，避免因网络延迟导致超时                                         |
| `MAX_RETRIES`          | `3 次`                                  | 应对网络波动或临时服务不可用，增加请求的健壮性                                                           |
| `UDI_PARAM_NAME`       | `udi_code` 或 `device_identifier`       | 明确指定接收 UDI 编码的参数名，方便接口调用方理解和传递                                                  |
| `DATA_SCHEMA_VALIDATION` | 开启（例如，使用 JSON Schema 进行验证） | 确保接收到的数据结构和字段类型符合预期，避免因数据格式不一致导致处理错误，例如 `{"udi_code": {"type": "string", "pattern": "^\\(01\\)\\d{14}"}}` |

## 容易做错的三处
*   调用外部接口时返回 `401 Unauthorized` 错误，原因在于 `Authorization` 头中的 API Key 配置错误或已过期。
*   接口返回的数据中，部分关键字段（如批号、有效期）为空，原因是外部系统接口返回的数据结构与预期不符，或数据清洗规则未能正确处理。
*   上传文件到知识库后，文件内容无法被正确解析或检索，原因是文件格式不支持，或在上传时未正确设置 `Content-Type` 导致解析失败。

## 怎么确认配好了
*   对核心高值耗材产品，通过接口调用并与官方数据库比对，核对返回的产品名称、型号和UDI编码是否完全一致。
*   模拟外部系统向 FastGPT 发送包含批号和有效期信息的查询请求，检查 FastGPT 返回的答案是否能准确引用这些信息，并验证其准确性。
*   使用 FastGPT 的文件上传功能，上传一份包含高值耗材详细参数的说明书，然后尝试提问其中特定参数，确认知识库能够正确检索并回答。
