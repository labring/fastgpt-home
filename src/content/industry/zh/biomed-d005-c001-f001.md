# CAR-T 细胞治疗制度的HTTP 接口与外部系统

## 这个品类的数据长什么样

CAR-T 细胞治疗的制度与标准操作流程（SOP）文档通常以 PDF、Word 或内部知识库页面的形式存在。这些文档涵盖了从患者筛选、细胞采集、制备、质控、回输到后期随访的全流程规范，以及相关的伦理、法规要求。数据来源主要包括国家药监局发布的指导原则、行业协会制定的操作规范、医院或研究机构内部制定的详细SOP、以及制药企业提供的产品说明书。文档更新频率相对较低，通常随法规修订或技术进步而更新，可能每半年到数年一次。文档结构严谨，包含大量术语、流程图、表格和引用文献。字段包括但不限于：细胞类型、治疗方案、剂量、质控指标、不良事件等级及处理措施、随访周期等，单位多为国际标准单位或临床常用单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

CAR-T 细胞治疗制度文档的更新频率低，意味着外部系统通过 HTTP 接口获取数据时，无需频繁轮询，可以采用周期性较低的同步策略，例如每周或每月一次全量或增量同步。文档内容高度专业化，涉及大量生僻医学术语和复杂流程，这对文本解析和语义理解模块提出了更高要求，需要确保 HTTP 接口能稳定传输大文件，并且后端能有效处理多格式文档。文档中包含的表格、流程图等非文本信息，要求 HTTP 接口能够支持二进制文件传输，并在外部系统侧具备相应的解析能力。此外，文档的严谨性要求在数据传输和解析过程中保持内容的完整性和准确性，任何字段的缺失或单位的误读都可能导致严重的后果。

## 配置怎么定

| 配置项                       | 建议取法       | 这样取的依据                                                                                             |
| :--------------------------- | :------------- | :------------------------------------------------------------------------------------------------------- |
| `HTTP_REQUEST_TIMEOUT_SECONDS` | `600 秒`       | CAR-T 文档体积可能较大，上传或下载耗时较长，避免请求超时。                                               |
| `MAX_FILE_SIZE_MB`           | `100 MB`       | 考虑到单个 PDF 或 Word 文档可能包含大量图片和表格，预留足够的文件大小限制。                              |
| `SPLIT_CHUNK_SIZE_TOKENS`    | `800–1200 字符` | 确保单个知识块包含足够上下文，同时避免过长导致模型处理效率下降。                                         |
| `EMBEDDING_BATCH_SIZE`       | `32`           | 平衡嵌入模型处理效率与内存消耗，适合处理专业文档中的中等长度文本。                                       |
| `PARSE_FILE_TYPE_LIST`       | `pdf, docx`    | CAR-T 制度文档主要以 PDF 和 Word 格式发布，确保系统能正确识别和解析。                                    |
| `SYNC_CRON_EXPRESSION`       | `0 0 * * 0`    | 每周日凌晨执行一次同步任务，适应 CAR-T 制度文档更新频率低的特点，减少不必要的资源消耗。                  |

## 容易做错的三处

*   HTTP 请求失败或返回状态码 500：通常是由于文件过大或网络不稳定，导致上传或下载超时，外部系统未能正确处理大文件传输。
*   知识库问答结果中缺乏关键的剂量或质控标准信息：这可能是文档解析过程中，表格或流程图中的关键数据未能被有效提取，或字段识别出现偏差。
*   系统提示“无法找到相关内容”或返回通用性回答：可能是在文档切片时，专业术语被错误分割，或相似度匹配阈值设置过高，导致无法召回相关知识块。

## 怎么确认配好了

*   手动上传一个典型的 CAR-T 治疗 SOP 文档（例如 50MB 的 PDF 文件），检查是否能成功上传并被系统解析。
*   通过 HTTP 接口触发一次数据同步，并检查日志，确认所有预期文档均已成功拉取并处理，没有出现文件下载失败或解析错误。
*   对知识库进行提问，例如“CAR-T 细胞回输前的质控指标是什么？”，验证系统能否准确返回文档中具体的数值和单位，并检查返回内容的完整性。
