# CRO制度的模型接入与配置

## 这个品类的数据长什么样
CRO（合同研究组织）在生物医药研发流程中扮演关键角色，其制度与标准操作规程（SOP）文档是核心资产。这些文档通常以 PDF、Word 或内部知识库格式存在，内容涵盖临床试验方案、数据管理规范、质量控制流程、伦理审查指南等。数据更新频率较高，尤其在法规变动、新项目启动或内部流程优化时。文档结构往往严谨，包含大量专业术语、缩写、图表和交叉引用。字段方面，常见版本号、生效日期、修订历史、责任部门、审批人等元数据，内容主体则涉及操作步骤、判定标准、风险评估、应急预案等，单位多为时间（天、小时）、剂量（mg、mL）、浓度（mM）等生物医药领域特定量纲。

## 这些特征在「模型接入与配置」这一环带来什么约束
CRO制度文档的专业性与严谨结构，要求模型在理解语义时能准确识别专业术语和上下文关联，避免泛化理解。高更新频率意味着知识库需要高效的同步与索引机制，确保模型始终基于最新版本提供问答服务。文档中包含的图表和交叉引用，对文件解析能力提出了更高要求，传统文本提取可能丢失关键信息。元数据（如版本号、生效日期）的存在，需要模型具备根据这些属性进行筛选和排序的能力，确保答案的时效性和准确性。此外，精确的单位识别与量纲理解，对于回答涉及具体操作参数的问题至关重要，避免因单位混淆导致误判。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `800–1200 字符` | CRO SOP文档段落结构紧凑，长分段有助保留上下文，避免专业术语被截断。 |
| `召回条数` | `前 5-8 条` | 制度问答对准确性要求高，增加召回条数可提高相关性高的片段被选中的概率。 |
| `相似度阈值` | `0.75–0.85` | 领域专业性强，提高阈值能有效过滤掉泛化或不相关的召回结果，提升精确度。 |
| `重排返回条数` | `3 条` | 经过重排模型处理，精选少量最相关的片段，减少模型处理负担，提高响应速度。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 大尺寸、复杂排版的PDF文件解析耗时较长，预留充足时间避免解析失败。 |
| `maxContext` | `32000 token` | 确保大模型能处理较长的上下文，覆盖多个相关制度条目。 |

## 容易做错的三处
*   批量处理节点执行中断，原因是文件解析超时或内存溢出，未能将所有制度文档成功导入知识库。
*   模型回答中出现过期或错误版本的制度信息，原因是知识库未及时更新或版本元数据未被有效利用。
*   对含有专业缩写或特定量纲的问题回答不准确，原因是模型训练数据中缺乏足够的CRO领域特定语料。

## 怎么确认配好了
*   上传典型CRO制度PDF文档，验证文件解析是否完整，包括图表说明文字和复杂表格内容。
*   向模型提问涉及最近修订的SOP内容，检查回答是否基于最新版本，并能引用正确的版本号。
*   测试模型对专业术语、缩写以及带有具体计量单位的问题的理解和回答准确性，例如询问“某药物剂量单位”或“试验周期天数”。
