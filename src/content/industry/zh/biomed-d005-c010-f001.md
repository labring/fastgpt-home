# IVD 诊断试剂制度的HTTP 接口与外部系统

## 这个品类的数据长什么样

IVD 诊断试剂的制度与 SOP 文档通常以 PDF、Word 或内部系统页面形式存在。这些文档内容高度结构化，包含法规要求、生产流程、质量控制、风险管理等多个方面。更新频率相对较低，主要发生在法规变更、产品升级或内部流程优化时，通常为季度或年度更新。文档中大量使用专业术语、缩写和标准代码，例如《体外诊断试剂注册管理办法》中的分类编码、ISO 13485 标准条款号。字段方面，常见有批次号、有效期、储存条件、检测原理、预期用途、适用仪器等，单位涉及温度（℃）、时间（小时、天）、浓度（mg/dL、IU/mL）等，精确度要求高。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

IVD 诊断试剂制度文档的低更新频率意味着外部系统同步时无需频繁轮询，可以采用定时触发或事件驱动的方式，降低系统负载。文档的专业性和结构化特点，要求 HTTP 接口在解析时能准确识别并提取关键信息，例如通过正则表达式或特定标记来识别标准条款号和产品批次信息。字段和单位的精确性要求，使得在与外部系统进行数据交换时，需要严格的数据类型校验和单位转换机制，避免因格式不匹配导致的解析失败或数据错误。例如，对储存温度字段，接口需要确保接收到的数据在预设的数值范围内，并正确处理单位。文档中可能包含大量表格和图示，对接口的数据抽取能力提出了更高要求，需要支持复杂结构化数据的解析。

## 配置怎么定

| 配置项                       | 建议取法                               | 这样取的依据                                                                                             |
| :--------------------------- | :------------------------------------- | :------------------------------------------------------------------------------------------------------- |
| `FETCH_INTERVAL_HOURS`       | `24 小时`                              | IVD 制度文档更新频率较低，降低拉取频率可减少不必要的系统开销。                                           |
| `PARSE_FILE_TYPE_WHITELIST`  | `pdf,doc,docx`                         | IVD 制度文档常见格式，确保只处理支持的文档类型。                                                         |
| `MAX_DOCUMENT_SIZE_MB`       | `20 MB`                                | IVD 制度文档可能包含大量图表和文本，此大小足以覆盖多数情况。                                             |
| `CHUNK_SIZE_TOKENS`          | `512–768 token`                        | 保证切片包含足够上下文，同时避免单个切片过大影响模型处理效率。                                           |
| `METADATA_EXTRACT_REGEX`     | `批次号:([A-Z0-9]{6,})`                | 针对 IVD 文档中常见的批次号格式，用于从文本中提取关键元数据。                                            |
| `ERROR_RETRY_COUNT`          | `3 次`                                 | 针对网络瞬时波动或外部系统临时故障，提供一定的重试机制。                                                 |

## 容易做错的三处

*   HTTP 状态码返回 404 或 500 错误，原因在于外部系统接口地址配置不正确或鉴权信息过期。
*   从外部系统拉取到的文档内容为空，现象是解析器无法处理或报错，原因是没有正确处理外部接口返回的空响应体或异常数据格式。
*   解析后的问答结果中， IVD 产品批次号或有效期字段缺失，原因是对文档中的特定字段提取规则不准确，未能正确匹配并抽取。

## 怎么确认配好了

*   通过调用 FastGPT 的日志接口，检查 HTTP 请求与外部系统交互的返回状态码是否为 200。
*   手动上传一份包含批次号和有效期信息的 IVD 制度文档，验证解析器是否能正确识别并抽取这些关键字段。
*   在 FastGPT 知识库中查询 IVD 制度相关问题，检查问答结果中是否包含从外部系统同步的最新制度内容，并核对内容的准确性。
