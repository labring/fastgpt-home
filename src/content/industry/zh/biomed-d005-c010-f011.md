# IVD 诊断试剂制度的文档解析与分块

## 这个品类的数据长什么样

IVD 诊断试剂的制度与 SOP 文档主要来源于法规标准、企业内部质量管理体系文件、产品说明书和操作规程。这些文档的更新节奏通常与法规修订周期、产品生命周期或内部审核计划相关，通常是季度或年度更新，部分紧急变更可能更快。文档结构高度规范化，常见格式包括 PDF、Word 或扫描件，内部通常包含大量表格、图示和流程图。文本内容专业性强，涉及医学术语、化学成分、计量单位（如 `mg/dL`、`IU/L`）和批次信息，对准确性要求极高。文档中常有版本号、生效日期和修订历史等元数据。

## 这些特征在「文档解析与分块」这一环带来什么约束

IVD 诊断试剂文档的规范化结构要求解析器能准确识别章节标题、段落和表格内容，避免内容混淆。专业术语和计量单位的存在，意味着需要保留上下文的完整性，防止分块过碎导致语义丢失。文档中的表格和流程图需要增强的 PDF 解析能力来提取结构化信息，否则关键的步骤、参数或判定标准可能无法被有效索引。更新频率和版本号的特点，要求文档解析流程能支持增量更新，并能关联不同版本之间的内容变动，确保问答结果基于最新且正确的制度。高准确性要求下，任何解析错误都可能导致不合规的问答。

## 配置怎么定

| 配置项                 | 建议取法       | 这样取的依据                                                 |
| :--------------------- | :------------- | :----------------------------------------------------------- |
| `分段长度`             | `800–1200 字符` | 确保 IVD 制度和 SOP 中的专业术语和上下文完整性，减少语义丢失风险。 |
| `重叠长度`             | `100–200 字符`  | 提高段落间关联度，捕获跨段落的信息，特别是涉及流程或多步骤说明时。 |
| `启用增强 PDF 解析`    | 勾选           | 有效识别并提取 IVD 文档中常见的表格、流程图等复杂布局内容。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒`       | 应对大型 SOP 或指导原则文件，避免因文件过大或结构复杂导致解析超时。 |
| `maxContext`           | `4000 字符`    | 适应 IVD 诊断试剂问答中可能需要较长背景信息的情况，提供更全面的回答。 |

## 容易做错的三处

*   现象：解析后的知识库中，表格内容显示为乱码或缺失。原因：未启用或配置增强 PDF 解析功能，导致无法正确识别和提取 PDF 中的表格结构数据。
*   现象：用户提问某个操作步骤时，回答内容不完整或跳跃。原因：`分段长度`设置过小，将一个完整操作步骤拆分到多个不连续的知识块中，丢失了上下文。
*   现象：上传文档后，长时间无响应或报错 `504 Gateway Timeout`。原因：`PARSE_FILE_TIMEOUT_SECONDS` 参数设置过短，大型或复杂结构的 IVD 文件在默认时间内无法完成解析。

## 怎么确认配好了

*   上传一份包含复杂表格和流程图的 IVD 诊断试剂说明书或 SOP 文件，检查解析后的知识块是否能正确显示表格数据和流程描述。
*   针对特定制度文件中的某个关键操作步骤进行提问，验证回答是否能完整、准确地呈现该步骤的所有细节，包括涉及的参数和单位。
*   尝试上传一份更新后的制度文件，观察系统是否能够识别版本差异，并能基于最新版本提供问答服务。
*   检查解析日志，确认没有出现因文件结构复杂或大小超出限制导致的解析错误或超时警告。
