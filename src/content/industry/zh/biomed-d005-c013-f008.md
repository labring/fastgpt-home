# mRNA 疫苗制度的工具调用与插件

## 这个品类的数据长什么样

mRNA 疫苗相关的制度与标准操作程序（SOP）文档通常以 PDF、Word 或结构化 XML 格式存在，来源于药品监管机构、生产企业内部质量管理体系以及行业协会发布的技术指南。这些文档更新频率较低，通常在数月到数年不等，除非有重大技术突破或监管政策调整。文档结构严谨，包含大量章节、附录和交叉引用，涉及生产工艺、质量控制、临床试验、存储运输等多个环节。核心字段包括批次号、有效期、存储条件（例如 `2°C` 至 `8°C`）、纯度指标（例如 `>95%`）、生产设备型号、操作步骤编号（例如 `SOP-QC-001`）和风险评估等级。部分文档还包含图表、流程图和化学结构式。

## 这些特征在「工具调用与插件」这一环带来什么约束

mRNA 疫苗制度文档的低更新频率意味着知识库构建时不必追求实时性，但对文档版本的管理要求更高，需要确保工具调用基于最新批准的制度版本。文档的严谨结构和交叉引用特性要求 RAG 检索模型具备理解复杂上下文和多跳推理的能力，以准确回答涉及多个章节或附录的问题。图表和化学结构式的存在，对文档解析能力提出了挑战，可能需要专门的图像识别或 OCR 工具辅助提取信息。存储条件等带有具体数值和单位的字段，在工具调用时需要进行严格的单位校验和范围判断。批次号、SOP 编号等标识符，在作为工具参数传递时，必须确保格式的准确性，以避免查询失败或误操作。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :------------------------- | :---------------------------------- | :--------------------------------------------------------------- |
| `maxContext` | `2000–3000` tokens | 适应制度文档的复杂上下文和长篇幅，确保语义完整性。 |
| `分段长度` | `500–800` 字符 | 平衡上下文完整性和检索效率，避免单个分段过长或过短。 |
| `召回条数` | `8–12` 条 | 提高检索的覆盖率，增加命中相关制度条款的可能性。 |
| `相似度阈值` | `0.75–0.85` | 确保召回的文档片段与查询高度相关，减少无关信息干扰。 |
| `重排返回条数` | `3–5` 条 | 精选最相关的少数文档片段，供工具调用进行精确参数提取。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600` 秒 | 应对大型 PDF 或 Word 文档的解析需求，避免因超时导致解析失败。 |

## 容易做错的三处

*   调用工具时，API 返回 `403 Forbidden` 状态码，原因是调用的密钥权限不足，未能正确配置访问目标知识库或外部服务。
*   工具执行后，返回结果中的关键字段（例如 `存储温度`）为空，原因是没有对文档中的表格或图表内容进行有效提取和结构化。
*   在需要用户确认的场景下，工具直接执行了操作而没有等待用户输入，原因是工具配置中缺少 `用户确认` 或 `交互式验证` 步骤的定义。

## 怎么确认配好了

*   针对核心制度文档，构造包含关键字段（如批次号、SOP 编号、温度范围）的测试问题，验证工具能否准确识别并提取参数。
*   模拟实际业务场景，执行包含复杂逻辑判断和多步骤工具调用的测试用例，检查工具链的执行路径和最终输出。
*   检查日志输出，确认工具调用过程中没有出现 `Timeout`、`Permission Denied` 或 `Invalid Parameter` 等错误信息，并记录每次调用的响应时间，设定合理阈值。
