# 代谢与内分泌制度的工具调用与插件

## 这个品类的数据长什么样

代谢与内分泌领域的制度与SOP（标准操作流程）文档通常来源于医疗机构、制药企业、临床研究组织或监管部门。这些文档的更新频率相对稳定，一般遵循年度或双年度审核周期，但遇到重大临床指南更新或药物上市时，可能触发非周期性修订。文档结构多为PDF或Word格式，包含目录、章节标题、正文、图表、附件等。关键信息字段包括疾病诊断标准、治疗方案、药物剂量、不良反应处理流程、检验指标正常范围、患者教育内容等。单位方面，常见有`mg/dL`（血糖）、`IU/L`（胰岛素）、`pmol/L`（甲状腺激素）、`mmol/L`（电解质）以及各种药物制剂的`mg`、`µg`等。文档中还会出现大量的医学术语缩写和专有名词。

## 这些特征在「工具调用与插件」这一环带来什么约束

代谢与内分泌领域的制度文档在工具调用与插件层面，主要面临多源数据整合、专业术语解析和实时性需求等约束。由于文档可能分散于多个系统，例如内部知识库、法规数据库，需要工具具备跨平台数据获取能力。大量的医学术语和缩写，要求工具调用过程中能准确理解上下文，避免因歧义导致错误指令。例如，`DM`可能指糖尿病，也可能指其他疾病。同时，临床决策的实时性要求，促使插件在获取最新指南或药物信息时，能够快速响应并返回结构化数据，供模型进一步分析。文档中包含的剂量单位换算、指标正常范围查询等，也需要工具调用插件进行精确计算和比对。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `maxContext` | `8192 token` | 确保能够承载大部分SOP文档的关键章节内容，减少上下文丢失。 |
| `chunkSize` | `800–1200 字符` | 适应医学文档中较长的句子结构和段落，保证语义完整性。 |
| `overlapSize` | `100 字符` | 确保分段之间的上下文衔接，处理跨段落的关键信息。 |
| `similarityThreshold` | `0.75` | 平衡召回精度与召回率，过滤掉不相关的制度条款。 |
| `toolCallTimeout` | `60 秒` | 应对外部API响应可能存在的延迟，尤其是查询大型数据库时。 |
| `enableCodeInterpreter` | `true` | 用于处理药物剂量计算、检验指标单位转换等复杂逻辑。 |

## 容易做错的三处

*   现象：模型尝试调用外部工具时，返回`HTTP 404 Not Found`或`HTTP 500 Internal Server Error`错误。原因：外部API地址配置不正确，或后端服务未正确部署、未授权访问。
*   现象：工具调用返回的结果中，关键字段如`drugDosage`或`normalRange`为空或格式不正确。原因：外部工具的响应结构与预设的Schema不匹配，或模型未能正确解析返回的JSON数据。
*   现象：在查询特定药物的禁忌症时，工具调用未能返回最新数据，而是提供了过期的信息。原因：外部数据源的更新机制未与工具调用插件同步，或缓存策略过于激进，未及时刷新数据。

## 怎么确认配好了

*   针对核心制度问答，设计覆盖常用药物剂量、诊断标准、治疗流程等典型场景的测试用例，验证工具调用结果的准确性。
*   模拟高并发查询，观察工具调用插件的响应时间与稳定性，确保在业务高峰期也能正常工作，响应时间应满足预设的`toolCallTimeout`。
*   核对工具调用返回的结构化数据，确保所有关键字段的命名、数据类型和单位与预期一致，尤其是数值型字段的精确性。
*   定期检查外部API的日志，确认每次工具调用请求与响应的完整性，并追踪潜在的错误信息，以便及时排查。
