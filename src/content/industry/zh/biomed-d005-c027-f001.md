# 减毒灭活疫苗制度的HTTP 接口与外部系统

## 这个品类的数据长什么样

减毒灭活疫苗相关的制度与SOP文档，其数据源主要来源于国家药监局、世界卫生组织（WHO）的官方发布、疫苗生产企业的内部管理系统以及临床研究机构的报告。这些文档的更新频率通常较低，主要集中在法规政策调整、疫苗批次更新或生产工艺改进时。文档的结构以PDF、Word或XML格式为主，内容包含详细的疫苗生产规范、质量控制标准、储存运输要求、临床试验数据和不良反应监测指南。核心字段包括疫苗名称、批次号、生产日期、有效期、储存条件、适用人群、禁忌症、不良反应发生率等，单位则涵盖温度（摄氏度）、时间（年/月/日）、剂量（IU/μg）、百分比（%）等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

减毒灭活疫苗制度文档的低更新频率意味着外部系统在同步数据时无需频繁轮询，可以采用周期性较长的定时任务。文档格式的多样性（PDF、Word、XML）要求HTTP接口具备强大的文件解析能力，需要支持多种MIME类型，并能准确提取非结构化文本中的关键信息，例如通过OCR技术处理扫描版PDF。字段的复杂性和单位的特异性，对数据抽取后的清洗和标准化提出了更高要求，例如确保所有温度单位统一为摄氏度，剂量单位统一，避免因单位不一致导致问答结果偏差。此外，文档中涉及的敏感信息（如生产商内部数据）要求接口在数据传输和存储过程中必须遵循严格的安全协议，例如使用HTTPS加密传输，并对关键字段进行脱敏处理。

## 配置怎么定

| 配置项                       | 建议取法                                   | 这样取的依据                                       |
| :--------------------------- | :----------------------------------------- | :------------------------------------------------- |
| `HTTP_REQUEST_TIMEOUT_SECONDS` | `120 秒`                                   | 大型PDF或Word文档解析需要较长时间，避免超时。      |
| `MAX_FILE_SIZE_MB`           | `50 MB`                                    | 减毒灭活疫苗SOP文档通常较大，确保能上传完整文件。  |
| `SUPPORTED_MIME_TYPES`       | `application/pdf, application/msword, application/vnd.openxmlformats-officedocument.wordprocessingml.document, application/xml` | 覆盖常见的制度文档格式，确保兼容性。               |
| `DATA_SYNC_INTERVAL_HOURS`   | `24–72 小时`                               | 疫苗制度更新频率较低，减少不必要的资源消耗。       |
| `API_KEY_AUTHENTICATION`     | `Bearer Token`                             | 提供安全的API访问控制，确保数据来源的合法性。      |
| `FIELD_MAPPING_RULES`        | `按实测标定`                               | 针对不同文档源的字段名差异进行标准化映射。         |

## 容易做错的三处

*   现象：外部系统调用FastGPT接口上传文档后，返回400错误，提示“Unsupported Media Type”。
    原因：`Content-Type`请求头未正确设置，或者上传的文件类型不在FastGPT配置的`SUPPORTED_MIME_TYPES`列表中。
*   现象：通过API获取的对话记录列表，发现`offset`参数设置后，返回结果并未从预期位置开始。
    原因：`offset`参数的计算逻辑或默认值与实际业务需求不符，或外部系统未正确处理分页逻辑。
*   现象：API调用获取的制度问答结果中，关键数值（如储存温度）出现单位混淆或数值错误。
    原因：文档解析后，`FIELD_MAPPING_RULES`配置不足以统一不同来源数据的字段单位，导致信息在入库前未标准化。

## 怎么确认配好了

*   通过API上传不同格式（PDF、Word、XML）的减毒灭活疫苗制度文档，检查FastGPT是否均能成功识别并入库，且返回状态码为200。
*   调用“获取对话记录列表”接口，使用不同的`offset`和`limit`参数组合，验证返回结果的起始位置和数量是否符合预期。
*   针对上传的文档内容，提问涉及关键数值和单位的问题（例如“某疫苗的储存温度是多少？”），核对FastGPT返回的答案与原文是否一致且单位正确。
