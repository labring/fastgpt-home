# 减毒灭活疫苗制度的模型接入与配置

## 这个品类的数据长什么样
减毒灭活疫苗相关的制度与SOP文档，其数据来源主要为药监局发布的法规文件、药企内部的质量管理体系文件、生产工艺规程、以及批生产记录等。这些文档通常以PDF、Word或扫描件形式存在。更新节奏相对稳定，国家层面的法规文件通常几年修订一次，企业内部SOP则根据生产工艺改进或监管要求变化进行年度或半年度审查更新。文档结构上，法规文件常包含章节编号、条款、附录等，SOP则有明确的标题、目的、范围、职责、操作步骤、记录要求等标准化模块。字段与单位方面，涉及疫苗活性单位（如TCID50、PFU）、生产批号、有效期、储存温度（摄氏度）、接种剂量（毫升）等特定术语和计量单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
文档来源分散且格式多样，要求模型接入支持多格式文件上传和内容提取，特别是针对扫描件的光学字符识别（OCR）能力。更新频率适中，意味着模型训练或知识库更新可以采取周期性策略，无需实时同步。文档的结构化特点，如法规的条款编号和SOP的操作步骤，为RAG（检索增强生成）模型的召回提供了结构化锚点，利于精准匹配。减毒灭活疫苗特有的专业术语和计量单位，要求模型具备强大的语义理解能力，能够识别并区分这些专业词汇，避免在问答中产生歧义或误解，特别是对于数值型单位的精确转换和计算。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `800–1200 字符` | 疫苗制度文本专业性强，上下文关联度高，需要较长分段以保留语义完整性。 |
| `分段重叠长度` | `100–150 字符` | 确保分段边界的上下文衔接，提升检索召回率。 |
| `召回条数` | `5–8 条` | 制度问答对准确性要求高，增加召回量可覆盖更多相关信息。 |
| `相似度阈值` | 按实测标定 | 需根据具体嵌入模型和数据集进行调整，平衡召回率与准确率。 |
| `重排返回条数` | `3–5 条` | 聚焦最相关的制度条款，减少模型处理无关信息的负担。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 大型PDF或Word文档解析耗时较长，预留充足时间避免超时。 |

## 容易做错的三处
*   现象：模型对疫苗剂量单位的换算或解读出现错误，例如将“毫升”与“微升”混淆。原因：缺乏对行业特定计量单位的专业词汇表或单位转换规则的预设，模型单纯依赖通用语言理解。
*   现象：用户提问某个SOP章节内容，模型返回了不相关的法规条文。原因：文档分段时未充分利用SOP的结构化信息（如章节标题、步骤编号），导致语义边界模糊。
*   现象：上传的扫描版批生产记录无法被正确解析，导致知识库内容缺失。原因：OCR引擎对低质量扫描件或手写批注的识别能力不足，或文件预处理环节未进行图像增强。

## 怎么确认配好了
*   上传典型减毒灭活疫苗相关法规和SOP文档，检查知识库中是否正确提取了关键信息，特别是批号、有效期、活性单位等专业字段。
*   针对不同复杂度的制度问题（如涉及多条款交叉引用、单位换算）进行测试，核对模型回答的准确性和完整性，并检查引用源文档是否正确。
*   模拟SOP变更场景，上传新版SOP文档，确认模型能够正确识别更新内容，并在问答中优先使用最新信息。
