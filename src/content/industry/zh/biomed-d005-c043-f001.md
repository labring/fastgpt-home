# 基因治疗 AAV制度的HTTP 接口与外部系统

## 这个品类的数据长什么样

基因治疗领域中，腺相关病毒（AAV）载体生产与质控相关的制度与标准操作规程（SOP）文档通常以 PDF、Word、或内嵌式网页形式存在。这些文档的更新频率受法规变动、技术迭代及内部流程优化的影响，通常为季度或年度更新。文档结构复杂，包含大量规范性文本、图表、流程图、以及引用外部标准链接。字段方面，特异性表述如“滴度（vg/mL）”、“空壳率”、“衣壳蛋白纯度”、“宿主细胞残留 DNA 含量”等是常见指标，单位精确到小数点后多位。文档还常包含批次记录、偏差处理流程、变更控制等敏感信息。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

AAV 制度与 SOP 文档的复杂结构和专业术语，要求 HTTP 接口在数据提取时具备高精度语义理解能力，避免因格式差异或术语歧义导致信息丢失。季度或年度的更新频率意味着外部系统需要定期触发数据同步，并进行版本比对，以确保知识库的时效性。文档中包含的图表和流程图，对接口的数据解析能力提出了更高要求，纯文本提取可能不足以捕捉全部语义。此外，涉及批次记录等敏感信息，HTTP 请求需要严格的认证授权机制，确保数据传输的安全性与合规性。专业性字段和单位的存在，要求外部系统在处理这些数据时，能够准确识别并保存其数值和单位，以便后续的量化分析。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `maxContext` | `3000 Tokens` | 适应 AAV 制度文档的复杂长句与专业内容，保证上下文完整性 |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 兼顾大型 PDF/Word 文档的上传需求，平衡传输效率 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 处理结构复杂、页数较多的 SOP 文档，避免解析超时 |
| `分段长度` | `800–1200 字符` | 确保每个文本分段包含足够专业上下文，提高检索召回率 |
| `召回条数` | `前 5 条` | 鉴于 AAV 制度问答的精确性要求，集中高质量相关段落 |
| `相似度阈值` | `0.75` | 高于常规阈值，筛选出与 AAV 规范高度相关的精确匹配内容 |

## 容易做错的三处

*   现象：系统返回的 AAV 批次放行标准中，关键指标数值缺失或单位错误。
    原因：HTTP 接口在文档解析时未正确识别专业数值字段及其关联单位，导致提取结果不完整。
*   现象：用户查询 AAV 生产变更控制流程时，获得的回答是旧版本制度内容。
    原因：外部系统未能及时同步最新版本的制度文档，知识库中存在过时信息。
*   现象：FastGPT 对 AAV 质控 S OP 中的流程图描述不准确或无法理解。
    原因：文档解析环节未能有效处理内嵌图像和流程图信息，仅提取了纯文本导致语义缺失。

## 怎么确认配好了

*   选取多个具有代表性的 AAV 制度文档，通过 HTTP 接口上传并检查其解析后的文本内容是否完整，尤其是专业术语、数值和单位。
*   模拟制度更新场景，上传新版本文档，观察外部系统是否能正确识别版本差异并更新知识库。
*   针对包含图表和流程图的 SOP 文档，提问相关流程，核对 FastGPT 生成的回答是否准确描述了图示内容。
*   通过 API 接口查询制度中特定批次记录信息，验证数据返回的准确性和安全性，确保敏感信息未被泄露。
