# 学术推广制度的文档解析与分块

## 这个品类的数据长什么样
学术推广制度文档通常来源于制药企业内部合规部门或法务部门，以及行业协会发布的指导性文件。这些文档的更新频率相对较低，通常一年一次或在政策法规发生重大调整时进行修订。文档结构以章节体为主，层级分明，包含大量法规条文引用、内部审批流程、行为规范细则和违规处理办法。内容侧重于界定学术推广活动的合法边界、合规流程和风险控制，其中涉及的字段包括但不限于：审批编号、活动类型、参与人员资质、费用标准、报销凭证要求等。单位多为货币单位（元）、时间单位（天、小时）以及百分比。

## 这些特征在「文档解析与分块」这一环带来什么约束
制度文档的章节体结构要求文档解析工具能够准确识别并保留层级信息，以确保检索时能关联到完整的上下文。法规条文的引用和细则描述，使得段落之间逻辑关联性强，对分块的粒度提出较高要求，需要避免过度拆分导致语义丢失。审批流程和费用标准的条目化特点，使得关键信息通常以列表或表格形式呈现，这要求解析器能有效提取结构化数据。较低的更新频率意味着初次解析的准确性至关重要，后续维护主要集中在增量更新和版本管理。字段和单位的标准化，有助于在分块后进行更精准的实体识别和信息抽取。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `500–800 字符` | 确保法规条文和流程描述的上下文完整性 |
| `分段重叠长度` | `50–100 字符` | 保持相邻分段间的语义衔接，减少信息丢失 |
| `文件类型白名单` | `['.pdf', '.docx']` | 学术推广制度主要以 PDF 和 Word 格式发布 |
| `解析超时时间` | `600 秒` | 应对大型制度文件解析可能耗时较长的情况 |
| `表格识别` | `启用` | 制度文档中常包含费用标准、流程步骤的表格数据 |
| `章节标题保留` | `启用` | 保留文档的层级结构，有助于RAG检索时提供上下文 |

## 容易做错的三处
*   解析结果中关键流程步骤或费用标准信息缺失，原因在于未开启表格识别或解析器未能正确处理文档中的复杂表格结构。
*   RAG检索结果返回的段落语义不完整，报“信息片段不完整”的错误，原因在于`分段长度`设置过短，导致含有强逻辑关联的法规条文被过度拆分。
*   上传大型制度文件后，文档解析节点长时间无响应或报告 `504 Gateway Timeout` 错误，原因在于`解析超时时间`设置过短，未能覆盖大型文件解析所需的时间。

## 怎么确认配好了
*   上传一份包含复杂表格和多级章节的学术推广制度文档，检查解析后知识库中是否完整保留了表格内容和章节标题信息。
*   对知识库进行基于制度内容的提问，检查返回的答案是否能准确引用到完整的法规条文或流程步骤，并验证其上下文是否连贯。
*   随机抽取解析后的文档分段，验证其`分段长度`和`分段重叠长度`是否符合预期设置，并评估分段的语义完整性。
*   测试不同大小的制度文档上传，观察解析过程是否正常完成，没有出现超时或解析失败的错误日志。
