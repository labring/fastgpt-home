# 小分子化药制度的知识库检索与召回

## 这个品类的数据长什么样

小分子化药的制度与 SOP 数据主要来源于药企内部的质量管理体系文件、生产工艺规程、检验操作规范以及注册申报资料。这些文档的更新节奏通常与药品生命周期管理、法规政策变化及生产工艺优化密切相关，可能每年进行例行修订，或在发生重大变更时即时更新。文档结构上，通常采用结构化的 PDF 或 Word 格式，包含标题、章节、附录、图表和表格。内容涉及详细的化学结构、反应条件、质量标准、分析方法等，字段常包含批号、CAS 号、含量、杂质百分比等，单位涉及 ppm、mg/mL、℃、kPa 等精确数值。

## 这些特征在「知识库检索与召回」这一环带来什么约束

小分子化药制度文档的结构化特点决定了在知识库切分时，应优先考虑保持章节的完整性，避免关键信息被切割。文档中包含的精确数值和专业术语，要求分词器能正确识别并建立索引，确保检索时能精准匹配。由于更新频率相对固定，知识库的同步策略可以采用周期性全量更新与增量更新相结合的方式，避免频繁的小范围修改导致索引重建开销过大。制度文件间的交叉引用和上下游关联性，意味着在召回时需要考虑多文档关联检索的能力，以提供更全面的上下文信息。此外，文件大小可能因为包含大量图表和附件而超出常规限制，需要调整文件上传配置。

## 配置怎么定

| 配置项                   | 建议取法       | 这样取的依据                                     |
| :----------------------- | :------------- | :----------------------------------------------- |
| `UPLOAD_FILE_MAX_SIZE`   | `1000 MB`      | 应对包含大量图表和附件的制度文件，避免上传失败 |
| `分段长度`               | `800–1200 字符` | 保持制度章节内容的完整性，减少语义割裂          |
| `召回条数`               | `前 8 条`      | 确保覆盖多角度的制度细节和关联信息              |
| `相似度阈值`             | `0.75`         | 提高检索结果的精准度，减少不相关内容的干扰      |
| `重排返回条数`           | `前 5 条`      | 精炼最终呈现给用户的结果，提升查阅效率          |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒`       | 允许处理大型或复杂结构文档的解析时间             |

## 容易做错的三处

*   上传制度文件时收到“文件大小超出限制”的错误提示，原因在于 `UPLOAD_FILE_MAX_SIZE` 参数设置过小，未能适配包含大量图表或附件的文档。
*   特定查询无法召回相关制度内容，即使关键词明确存在，原因可能是分段策略导致关键信息被切割，或者分词器未能正确识别专业术语。
*   升级 FastGPT 版本后，部分制度问答效果下降，表现为召回结果不一致，原因可能在于新版本默认配置与旧版本存在差异，需要重新校准 `相似度阈值` 或 `召回条数`。

## 怎么确认配好了

*   上传一份典型的小分子化药 SOP 文件（例如，一份包含图表和附件的 PDF 文件），检查是否能成功解析并入库，观察文件处理状态。
*   针对文件中包含的特定 CAS 号、批号或精确数值，进行检索测试，验证是否能准确召回包含这些信息的段落。
*   选取几个跨章节或涉及多份制度文件的复杂问题进行测试，评估召回结果是否全面且上下文连贯，并根据实际需求调整 `相似度阈值`。
