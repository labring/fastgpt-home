# 工艺验证制度的引用来源与溯源

## 这个品类的数据长什么样

生物医药领域的工艺验证制度数据，主要以内部文档形式存在，包括验证方案、验证报告、偏差处理、变更控制等。这些文档通常是 PDF、Word、Excel 文件，存储在企业内部的文件服务器或内容管理系统中。数据更新频率相对较低，通常随工艺变更或定期审查而更新，周期可能长达数月甚至一年。文档结构高度标准化，包含引言、目的、范围、职责、验证内容、验收标准、结果与结论等固定章节。字段方面，涉及批次号、设备编码、物料批号、操作人员、验证日期、关键工艺参数（如温度、压力、时间）、检测指标（如含量、纯度、收率）及其单位（如 `℃`、`MPa`、`min`、`%`、`ppm`）。

## 这些特征在「引用来源与溯源」这一环带来什么约束

工艺验证数据的低更新频率意味着知识库内容更新无需过于频繁，但历史版本管理至关重要，以确保引用的准确性。文档结构标准化为自动解析和信息提取提供了便利，但也要求解析器能处理复杂的表格和嵌套结构。多样化的文件格式增加了预处理的复杂性，需要支持多种文件类型的文本抽取。特定字段和单位的存在，要求 RAG 系统在召回和生成时能正确识别和保留这些信息，避免因单位混淆导致误解。此外，对溯源性的高要求，使得回答中必须清晰标明引用来源的具体文档、页码甚至段落，以满足合规性审查的需求。

## 配置怎么定

| 配置项             | 建议取法                                        | 这样取的依据                                                                                             |
| :----------------- | :---------------------------------------------- | :------------------------------------------------------------------------------------------------------- |
| `分段长度`         | `800–1200 字符`                                 | 工艺验证文档段落较长，包含多项参数和操作步骤，过短的分段易丢失上下文；过长则增加无关信息。           |
| `召回条数`         | `前 5 条`                                       | 考虑到工艺验证的严谨性，需要确保覆盖核心信息，5 条能较好平衡覆盖度与召回效率。                         |
| `相似度阈值`       | `0.75`                                          | 较高的阈值有助于减少不相关文档的召回，降低误导风险。                                                     |
| `重排返回条数`     | `3 条`                                          | 经过重排可以进一步优化答案质量，3 条足以涵盖最相关的核心信息。                                           |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒`                                        | 工艺验证报告可能包含大量数据和图表，文件解析耗时较长，增加超时时间避免解析中断。                         |
| `引用显示格式`     | `文档名-页码-段落范围`                          | 提供精确的引用路径，便于用户快速定位原文，满足审计和合规性要求。                                         |

## 容易做错的三处

*   回答中提示可以换行，但实际输出 `\n` 字符，并未实现换行功能。原因在于生成模型在特定配置下未正确解析换行符，或者前端展示未对 `\n` 进行渲染。
*   知识库回答时，段落末尾的引用显示“没有权限操作此对话记录”。原因在于引用链接指向的资源权限配置不当，或者用户当前会话未绑定相应的访问凭证。
*   导入工作流后，其中引用的插件无法找到。原因在于目标环境的插件库未安装或未注册该工作流所需的特定插件，导致路径解析失败。

## 怎么确认配好了

*   上传一份包含多页和复杂表格的工艺验证报告 PDF 文件，检查解析后的文本内容是否完整，关键参数（如 `批次号`、`检测指标`）及其单位是否正确提取。
*   针对一份包含特定工艺参数和验收标准的文档，提出相关问题，核对返回的答案是否准确引用了原文的 `文档名`、`页码` 和 `段落范围`。
*   模拟一次包含敏感信息的查询，确认系统是否能正确识别并根据配置的权限策略，限制或调整引用来源的显示。
