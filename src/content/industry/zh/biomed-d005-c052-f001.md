# 干细胞治疗制度的HTTP 接口与外部系统

## 这个品类的数据长什么样
干细胞治疗领域的制度与SOP文档，其数据来源主要为国家药监局、卫健委发布的法规文件、医院内部的质量管理体系文件、以及行业协会发布的指导原则。这些文档通常以 PDF、DOCX 格式存在，内容结构严谨，包含大量专业术语、流程图和表格。更新频率相对较低，通常为季度或年度修订，但一旦修订，影响范围广。字段方面，常涉及批次号、细胞株编号、患者ID、操作人员资质、环境监测数据等，单位则严格遵循生物学和医学规范，例如细胞数量以 `cells/mL` 表示，温度以 `℃` 为单位，时间以 `min` 或 `h` 为单位。文档长度普遍较长，单份文件可能超过 `50 页`。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
干细胞治疗制度文档的数据特征，对 HTTP 接口与外部系统对接提出了具体要求。首先，文档的专业性和严谨性要求模型能准确理解上下文，避免因歧义导致错误解读。长文档结构复杂，需要高效的分块与索引机制，以支持精准召回。较低的更新频率意味着数据同步不必过于频繁，但每次更新都需进行全面且细致的增量或全量替换。字段的专业性与单位的标准化，要求接口在数据解析时能正确识别并处理这些信息，例如将 `5 x 10^6 cells/mL` 视为一个整体的数值表达。此外，由于文档通常包含图表，系统需要具备处理非文本信息的能力，或者在上传前进行预处理。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `UPLOAD_FILE_MAX_SIZE` | `100 MB` | 制度文档通常较大，确保能上传完整文件 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 大文件解析耗时较长，避免解析超时中断 |
| `分段长度` | `800 字符` | 兼顾上下文完整性与检索效率，提高召回准确率 |
| `相似度阈值` | `0.75` | 领域专业性强，提高阈值以确保召回内容高度相关 |
| `重排返回条数` | `前 5 条` | 关键制度问答，确保最相关的几条信息优先展示 |
| `maxContext` | `4096 tokens` | 保证模型能处理较长的上下文，理解复杂制度条款 |

## 容易做错的三处
1. 现象：HTTP 接口返回 `404 Body Not Found`。原因：`Content-Type` 请求头未正确设置为 `application/json` 或其他预期类型，导致服务器无法解析请求体。
2. 现象：DeepSeek 等模型的思考过程未在回调接口中显示。原因：API 请求中未明确设置 `stream` 参数为 `true` 或 `detail` 参数以获取详细处理步骤。
3. 现象：上传文档后，部分专业词汇或数值单位在检索时匹配度低。原因：未对文档进行充分的预处理，例如标准化单位表示、扩充专业词汇同义词库或进行 OCR 识别，导致向量化效果不佳。

## 怎么确认配好了
1. 上传一份包含复杂流程图和专业术语的干细胞治疗SOP文档，检查是否成功解析并生成了可检索的文本内容，核对关键字段是否正确提取。
2. 通过 API 接口模拟提问，问题应涵盖制度中的关键条款和操作细节，验证返回结果的准确性和完整性，并检查返回的思考链条是否合理。
3. 针对一份已知有修订的制度文档，测试增量更新功能，确认系统能正确识别并应用新的内容，旧版本内容不再被召回。
