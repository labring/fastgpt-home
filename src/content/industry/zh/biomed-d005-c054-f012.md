# 康复设备制度的模型接入与配置

## 这个品类的数据长什么样

康复设备相关的制度与SOP文档，主要来源于医疗器械生产企业的质量管理体系文件、国家及地方药品监督管理局发布的法规文件、以及医疗机构内部的设备操作规程。这些文档的更新频率相对稳定，通常在法规修订或产品迭代时进行季度或年度更新。文档结构以层级分明的章节为主，包含大量技术细节、操作步骤、安全规范和维护要求。内容中常涉及特定康复设备的型号、序列号、技术参数（如功率、频率、治疗模式）、校准周期和故障代码等字段，单位多为国际标准单位（如瓦特、赫兹、毫米、摄氏度），也包含特定的医疗计量单位（如焦耳/平方厘米、毫安）。

## 这些特征在「模型接入与配置」这一环带来什么约束

康复设备制度文档的技术细节和严格规范性，要求模型在知识召回时必须保证高精度和低幻觉，避免误导性信息。频繁涉及的设备型号和技术参数，使得模型需要能够准确识别并理解这些实体，区分不同型号设备的差异。文档的层级结构和长文本特性，对文本切分策略提出了挑战，需要保持语义完整性。此外，法规文件的定期更新，要求知识库能够便捷地进行增量更新和版本管理，确保模型始终基于最新有效制度提供问答服务。对特定字段和单位的准确识别，直接影响问答结果的可用性，要求模型具备较强的数值和单位理解能力。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `500–800 字符` | 兼顾语义完整性与召回效率，避免过长段落稀释关键信息 |
| `分段重叠` | `50 字符` | 确保上下文衔接，减少因切分导致的重要信息丢失 |
| `召回条数` | `前 5–8 条` | 覆盖多角度相关信息，但避免引入过多无关内容增加模型负担 |
| `相似度阈值` | `0.75–0.85` | 过滤低相关性结果，提高召回精度，减少模型幻觉 |
| `重排返回条数` | `前 3 条` | 经过重排后，聚焦最相关的几条信息，提升最终答案质量 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 应对大型SOP文档解析时间，防止因超时导致处理失败 |

## 容易做错的三处

*   模型在回答涉及设备型号或技术参数的问题时，经常出现张冠李戴或数值错误，原因在于文档切分时未能有效保持设备与参数的对应关系，或嵌入模型对专业术语的理解不足。
*   用户提问后得到“404”或“无法找到相关信息”的错误响应，原因可能是OneAPI配置中的模型名称或API地址与实际部署不符，或使用的嵌入模型不支持特定语言编码。
*   模型在处理涉及校准周期、维护频率等时间相关制度问答时，给出的结果与最新版本规定不符，原因在于知识库未及时更新，或文档版本管理机制失效。

## 怎么确认配好了

*   选择几份具有代表性的康复设备制度SOP文档，上传至知识库，检查是否能正常完成解析，并查看日志中是否存在`PARSE_FILE_TIMEOUT_SECONDS`相关的错误。
*   针对上传的文档，设计包含设备型号、技术参数、操作步骤和安全规范的测试问题，验证模型能否准确召回相关段落，并核对召回段落的完整性和准确性。
*   准备一批包含制度更新前后的对比问题，测试模型是否能基于最新版本的制度给出回答，并人工比对答案的准确性与时效性，以此确定知识更新机制的有效性。
