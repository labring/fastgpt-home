# 招标挂网制度的HTTP 接口与外部系统

## 这个品类的数据长什么样

生物医药领域的招标挂网制度数据，主要来源于各级药械集中采购平台、医保局官网以及省级公共资源交易中心。这些数据更新频率较高，通常每周或每月发布新的招标公告、中标结果或挂网目录调整信息。文档结构以 PDF 公告、Excel 列表或结构化 XML 文件的形式存在。PDF 公告中包含批文号、通用名、剂型、规格、生产企业、最高限价、采购周期等关键信息，常以非结构化文本或图片表格形式呈现。Excel 列表则可能直接提供结构化的数据，但仍需处理合并单元格或不规范的表头。字段名称在不同平台可能存在差异，例如“采购价格”可能对应“中标价”或“医保支付标准”，单位方面则涉及“元/盒”、“元/支”、“元/片”等多种药品计量单位，需要统一处理。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

招标挂网数据的高更新频率要求外部系统具备定时抓取和增量同步能力，以确保知识库的时效性。多样的文档结构，特别是大量的非结构化 PDF 公告，对 HTTP 接口的数据解析能力提出了挑战。这意味着在调用外部系统接口获取数据后，需要进行复杂的文档预处理，例如 OCR 识别、表格提取和文本解析。不同平台字段名称的不一致以及计量单位的多样性，要求在数据导入或接口调用时进行严格的字段映射和单位标准化，避免语义混淆。例如，对于价格字段，需要明确其货币单位和药品数量单位，防止因单位不匹配导致的数据错误。此外，部分平台可能设有反爬机制或访问频率限制，影响 HTTP 接口的稳定性与效率。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `HTTP_REQUEST_TIMEOUT_SECONDS` | `60 秒` | 处理大型 PDF 文件或复杂网页解析任务可能耗时较长，避免请求超时。 |
| `MAX_FILE_SIZE_MB` | `20 MB` | 多数招标公告 PDF 文件大小在此范围内，确保能够上传和处理。 |
| `CHUNK_SIZE_TOKENS` | `800–1200 字符` | 适应制度条文的长度，平衡语义完整性与召回效率。 |
| `SIMILARITY_THRESHOLD` | `0.75` | 招标挂网制度问答对准确性要求高，提高召回结果的相关度。 |
| `RETRY_COUNT` | `3 次` | 应对外部接口偶发的网络波动或服务暂时性不可用。 |
| `SCHEDULE_INTERVAL_CRON` | `0 0 * * 1` | 通常每周发布新的招标公告，确保数据及时更新。 |

## 容易做错的三处

*   HTTP 请求返回 403 Forbidden 状态码，因为外部数据源可能设置了 User-Agent 限制或 IP 访问频率限制。
*   解析后的价格字段为空或数值明显错误，原因是 PDF 中价格数据以图片形式存在，OCR 识别失败，或者单位转换逻辑有误。
*   查询结果中未包含最新的政策变动，原因在于数据抓取频率不足，或者外部系统增量更新机制未正确触发。

## 怎么确认配好了

*   定期检查知识库中招标挂网相关制度的更新时间戳，确保与外部数据源的发布时间一致。
*   随机抽取 5-10 条复杂查询，比对 FastGPT 返回的回答与原始制度文件中的关键信息，验证字段解析和内容准确性。
*   通过 FastGPT 的日志系统监控 HTTP 接口的调用成功率和响应时间，确保接口稳定且无明显延迟。
