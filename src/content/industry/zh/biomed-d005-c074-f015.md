# 生物制药设备制度的部署与升级

## 这个品类的数据长什么样

生物制药设备相关制度与标准操作规程（SOP）的数据源自设备供应商提供的技术文档、制药企业内部质量管理体系文件以及监管机构发布的合规指南。这些文档通常以 PDF、DOCX、XML 等格式存在，内容涵盖设备操作手册、维护保养规范、校准验证记录、故障排除指南以及风险评估报告。数据更新频率相对稳定，主要集中在设备采购、升级或监管政策调整时。文档结构往往高度标准化，包含明确的章节标题、图表、参数列表和流程图。字段与单位具有严格的专业性，例如压力单位为 `bar` 或 `psi`，温度单位为 `°C`，流量单位为 `L/min`，且常伴随特定的设备型号和批次信息。

## 这些特征在「部署与升级」这一环带来什么约束

生物制药设备制度文档的专业性与标准化结构，要求知识库在数据解析时具备对特定段落、表格和图示文字的准确提取能力，以保证语义完整性。文档中包含大量专业术语和缩略语，需要配置专门的词汇表或领域模型，确保向量化和召回的精准度。由于更新频率相对较低但内容变更影响重大，知识库的增量更新机制需支持对特定文档版本的管理和回溯，避免旧版本信息污染。同时，文档体积可能较大，对文件上传大小和解析超时时间有较高要求。字段与单位的严格性，意味着检索结果需要能清晰呈现原文中的数值信息，避免歧义。对合规性的高要求，使得部署后的知识库必须经过严格的验证，确保问答结果的准确性和一致性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 大型设备手册和验证报告文件体积较大，需确保能顺利上传。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 复杂 PDF 文档解析耗时较长，避免因超时导致解析失败。 |
| `分段长度` | `800–1200 字符` | 保留制度条文的上下文完整性，兼顾向量化效率。 |
| `相似度阈值` | `0.75` | 确保召回的制度条文与查询意图高度相关，避免无关信息干扰。 |
| `重排返回条数` | `前 5 条` | 聚焦于最相关的少数几条制度，便于工程师快速定位。 |
| `maxContext` | `按实测标定` | 根据实际设备制度文档的平均长度和复杂程度进行调整。 |

## 容易做错的三处

*   上传大型 PDF 文档时提示 `文件过大` 或 `解析超时`：这通常是由于 `UPLOAD_FILE_MAX_SIZE` 或 `PARSE_FILE_TIMEOUT_SECONDS` 参数设置过小，未能满足生物制药设备文档的实际需求。
*   检索结果中出现大量无关或低相关度的内容：这可能源于 `相似度阈值` 设置过低，导致召回范围过广，未能有效过滤掉非核心制度条文。
*   知识库导入备份文件时出现 `MongoServerError: The dollar ($) p` 错误：这通常是由于 FastGPT 版本与 MongoDB 数据库版本不兼容，导致数据结构或查询语法无法正确解析。

## 怎么确认配好了

*   上传一份包含复杂表格和图示的设备操作规程 PDF 文件，验证文件是否能成功上传并被正确解析，且内容分段合理。
*   针对特定设备型号和故障代码进行提问，检查召回结果是否准确指向相应的故障排除章节或维护规范，并能呈现原文中的关键参数。
*   对比不同版本的制度文档，执行增量更新操作，确认知识库能正确识别并更新变动部分，同时旧版本信息未被错误覆盖。
