# 真实世界研究制度的知识库检索与召回

## 这个品类的数据长什么样

生物医药领域的真实世界研究（RWE/RWD）制度文档通常源自国家药监局、行业协会、伦理委员会发布的指导原则、技术规范、操作规程以及企业内部的标准化操作程序（SOP）。这些文档更新频率相对稳定，一般为季度或年度修订，重大政策调整时会进行即时更新。文档格式以 PDF 居多，部分以 Word 或富文本格式发布。内容结构严谨，包含大量专业术语、法规条文、流程图和表格数据。字段涉及研究设计、数据采集、统计分析、伦理审查等，单位多为时间（年、月）、数量（例）、比例（%）或特定分类标准。

## 这些特征在「知识库检索与召回」这一环带来什么约束

真实世界研究制度文档的专业性与结构严谨性，要求知识库在分块时需高度关注语义完整性，避免法规条文被截断。更新频率适中，意味着知识库需要具备定期增量更新和版本管理能力。PDF 文档占比高，对文档解析的稳定性提出了更高要求，尤其在处理复杂表格和图文混排时。文档中专业术语和缩写密集，影响传统关键词匹配的召回精度，需要向量检索能准确捕捉其上下文语义。此外，不同制度之间可能存在交叉引用或修订关系，知识库召回时需能识别这些关联，提供更全面的信息。

## 配置怎么定

| 配置项             | 建议取法       | 这样取的依据                                                                                             |
| :----------------- | :------------- | :------------------------------------------------------------------------------------------------------- |
| `分段长度`         | `500–800 字符` | 确保法规条文或操作步骤的语义完整性，避免过短分段丢失上下文，过长分段引入噪音。                           |
| `分段重叠长度`     | `50–100 字符`  | 维持分块间的上下文连续性，提升跨分块查询的召回效果，尤其适用于流程描述或多段论述。                       |
| `召回条数`         | `6–10 条`      | 在保证信息覆盖度的前提下，避免返回过多冗余结果，兼顾召回效率与后续大模型处理能力。                       |
| `相似度阈值`       | 按实测标定     | 需根据具体嵌入模型和数据集进行调优，确保召回结果的相关性，避免低质量召回。                             |
| `重排返回条数`     | `3–5 条`       | 进一步精炼召回结果，聚焦最相关内容，提升最终问答的准确性。                                               |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒`       | 应对大型 PDF 文档解析耗时，尤其包含复杂表格或图片内容时，避免解析超时。                                  |

## 容易做错的三处

*   上传 PDF 文档后提示“无法读取该文件内容”：原因常是文档加密、扫描件未 OCR 或解析器版本不兼容。
*   知识库未能同步飞书中的 PPT 和 PDF 文档：通常是由于飞书接口权限配置不完整，或 FastGPT `knowledge_base` 模块未正确集成相应的文档解析插件。
*   上传单个文档时出现长时间转圈后网络失败：多是由于 `UPLOAD_FILE_MAX_SIZE` 配置过小，或 `PARSE_FILE_TIMEOUT_SECONDS` 值不足以处理大型文件。

## 怎么确认配好了

*   上传典型制度文档（如 100 页以上的 PDF），检查分块预览是否正常，且每个分块内容语义连贯。
*   针对文档中的专业术语、法规条款进行提问，验证召回结果是否包含原文的精准段落。
*   模拟制度修订场景，更新部分文档后，核实知识库的增量更新机制是否按预期工作，旧版本内容是否被正确替换或标记。
*   通过 FastGPT 的 `knowledge_base` 模块，查看文档解析日志，确认无 `400` 或 `500` 状态码，且解析时间在可接受范围内。
