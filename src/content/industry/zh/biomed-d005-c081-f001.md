# 神经退行性制度的HTTP 接口与外部系统

## 这个品类的数据长什么样
神经退行性疾病领域的制度与SOP文档，通常来源于权威医疗机构、药企研发部门及临床试验数据。数据更新频率相对较低，主要集中在新药研发、临床指南修订或法规政策调整时。文档结构复杂，常包含大量医学术语、实验数据、操作流程图、风险评估矩阵和合规性要求。字段方面，可能涉及病理学指标如 `Aβ` 斑块负荷、`Tau` 蛋白磷酸化水平，或药理学参数如 `IC50` 值、`PK/PD` 数据。单位则严格遵循国际标准，例如 `nM`（纳摩尔）、`mg/kg`（毫克每千克）或 `pg/mL`（皮克每毫升）。这些文档往往以 PDF、Word 或结构化数据库的形式存在。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
神经退行性领域的制度文档复杂性高，且包含大量专业术语和图表，使得传统的文本解析方法效率不高。这要求HTTP接口在数据传输时，能够支持大文件上传，并考虑文件解析服务的稳定性与并发能力。文档更新不频繁的特点，意味着对缓存机制的依赖性可以降低，但对数据一致性的要求更高。结构化数据与非结构化文本混杂，需要外部系统具备强大的混合数据处理能力，例如结合OCR技术识别图表内容，或利用特定模型提取关键医学实体。字段和单位的严格性，则要求接口在数据校验时能精确识别并处理异常数据，避免因单位不匹配导致的错误理解。同时，考虑到数据敏感性，传输过程中的加密和访问控制是不可或缺的。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 制度文档常包含大量图表与附件，文件体积较大，需要支持大文件上传。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 大型PDF或Word文档解析耗时较长，避免因超时导致解析失败。 |
| `maxContext` | `800–1200 字符` | 医学SOP细节丰富，需要较长的上下文窗口以确保信息完整性。 |
| `embeddingModel` | `text-embedding-ada-002` 或领域特定模型 | 确保对复杂医学术语和概念的理解精度。 |
| `相似度阈值` | `0.78–0.85` | 保证召回内容的专业性和相关性，避免泛化信息干扰。 |
| `HTTP_REQUEST_TIMEOUT_SECONDS` | `30 秒` | 外部系统处理请求可能涉及复杂计算，预留足够响应时间。 |

## 容易做错的三处
*   HTTP请求返回 `504 Gateway Timeout` 错误：原因在于外部文件解析或大模型推理耗时过长，超出了默认的网关超时设置。
*   问答结果中关键医学参数如 `剂量` 或 `频率` 缺失或不准确：原因在于文档解析时未正确识别或提取这些带有特定单位的字段。
*   外部系统调用时，API返回 `403 Forbidden` 状态码：原因在于未正确配置API密钥或缺少必要的认证信息。

## 怎么确认配好了
*   上传并解析一份包含图表和复杂医学术语的神经退行性疾病SOP文档，检查解析后的文本内容是否完整且无乱码。
*   针对文档中的特定医学概念进行提问，验证问答结果中是否包含相关专业术语和具体数值，并与原文核对。
*   模拟高并发场景下对HTTP接口的调用，观察系统响应时间与错误率，确保在压力下仍能稳定服务。
*   检查FastGPT的运行日志，确认外部HTTP接口调用没有出现 `Connection refused` 或 `SSL handshake failed` 等连接错误。
