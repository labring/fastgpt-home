# 罕见病制度的多轮对话与提示词

## 这个品类的数据长什么样
罕见病制度数据来源多样，主要包括国家卫健委、药监局发布的政策文件、临床诊疗指南、药品说明书、医保目录以及各类专家共识。这些文档多以 PDF、Word 或官方网页形式呈现，更新频率相对较低，通常按季度或年度发布。文档结构复杂，包含大量专业术语、法律法规条文、医学描述和治疗方案。字段方面，涉及药品名称、适应症、用法用量、医保支付范围、诊断标准、遗传学特征等。单位常包含毫克（mg）、微克（µg）、毫升（mL）、国际单位（IU）以及百分比（%）等医学和药学计量单位。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
数据来源的复杂性和更新频率限制了知识库构建的自动化程度，需要人工介入进行初步筛选和标注。文档结构复杂，导致分段时需要更精细的策略，以避免语义中断或信息丢失。大量专业术语和医学描述对模型理解能力提出较高要求，可能导致在多轮对话中出现专业术语理解偏差或混淆。医保支付范围、诊断标准等字段的精确性要求高，任何误解都可能影响信息准确性。医学和药学单位的混用，要求提示词设计时需明确单位转换或识别策略，防止因单位理解错误导致回答失真。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `最大上下文窗口` | `32000 token` | 罕见病制度文档篇幅长、信息密度高，需要更大的上下文窗口承载更多背景信息。 |
| `分段长度` | `500-800 字符` | 兼顾语义完整性和召回效率，避免过长段落引入噪声，过短段落切断关键信息。 |
| `召回条数` | `前 8 条` | 确保覆盖到多个相关制度文件或指南的不同章节，提升答案的全面性。 |
| `相似度阈值` | `0.78-0.85` | 罕见病领域的专业术语相似度较高，需要更高的阈值以减少不相关内容的召回。 |
| `重排返回条数` | `前 3 条` | 在召回结果中进一步精选最相关的条目，减少模型处理负担，提升回答精准度。 |
| `最大输出长度` | `1500 字符` | 制度问答通常需要详细解释，保证模型有足够的输出空间。 |

## 容易做错的三处
*   模型输出的 Markdown 表格格式错乱，内容被截断。原因在于模型输出的字符数超过了 `最大输出长度` 限制，或者 Markdown 渲染器无法正确处理复杂表格结构。
*   多轮对话中，模型无法准确区分不同罕见病的相似症状或治疗方案。原因在于提示词未能有效引导模型关注疾病的特异性诊断标准或鉴别要点。
*   用户提问涉及医保支付范围时，模型未能返回具体支付比例或报销条件。原因在于知识库中相关制度文件未能被精确召回，或者提示词未明确要求模型提取这类数值信息。

## 怎么确认配好了
*   针对典型罕见病制度查询，进行多轮对话测试，检查模型能否保持对话上下文一致性。
*   随机抽取包含医学术语、计量单位和法律条文的复杂问题，验证模型回答的准确性和专业性。
*   模拟用户提问关于医保报销、药品用法用量等关键信息，核对模型输出与原始文档的一致性。
*   通过持续监测用户反馈，定期调整 `相似度阈值` 和 `重排返回条数`，优化召回和排序效果。
