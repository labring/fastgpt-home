# 质量文档管理制度的部署与升级

## 这个品类的数据长什么样

生物医药行业的质量文档管理制度数据，主要来源于企业内部的质量管理体系（QMS）、实验室信息管理系统（LIMS）以及生产执行系统（MES）。这些文档包括标准操作规程（SOP）、批生产记录（BPR）、检验方法（QM）、偏差处理报告、变更控制文件等。文档更新频率通常较低，但每次更新都需严格的版本控制和审批流程。文档结构通常高度标准化，包含标题、版本号、生效日期、修订历史、正文、附件等固定字段。字段内容以文本描述为主，辅以表格、图示，单位则严格遵循行业标准，如 mL、mg/L、℃、kPa 等。

## 这些特征在「部署与升级」这一环带来什么约束

质量文档数据的高度结构化和严格版本控制，要求部署时必须确保文档解析的准确性和版本溯源能力。更新频率低但每次更新影响范围广的特点，使得升级过程需要具备灰度发布和回滚机制。文档中包含大量专业术语和行业标准单位，对模型理解能力提出更高要求，需要针对性地进行词汇表导入和单位识别配置。此外，文档通常以 PDF 或 Word 格式存储，解析器需能准确提取文本内容，并保留表格、列表等格式信息。部署时应预留足够的存储空间，以应对未来文档数量的增长，同时保证检索性能。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 生物医药文档内容复杂，解析时间可能较长，避免超时中断。 |
| `maxContext` | `3000 字符` | 单个质量文档篇幅较长，需要更大的上下文窗口以捕获完整信息。 |
| `分段长度` | `800–1200 字符` | 确保分段能包含相对完整的SOP步骤或制度条款，方便模型理解。 |
| `召回条数` | `前 5 条` | 质量文档问答通常对准确性要求高，增加召回条数可提高相关性。 |
| `相似度阈值` | 按实测标定 | 需平衡召回率与精确率，确保召回的文档段落高度相关。 |
| `UPLOAD_FILE_MAX_SIZE` | `100 MB` | 考虑单个质量文档可能包含大量图片或图表，文件体积较大。 |

## 容易做错的三处

*   模型回答出现专业术语混淆或单位错误，原因在于未导入行业词汇表或未配置单位识别规则。
*   文档更新后，问答结果仍引用旧版本内容，原因在于知识库同步机制未正确配置或未触发增量更新。
*   上传大型PDF文件时，系统报错或无响应，现象通常为 `HTTP 504 Gateway Timeout`，原因在于文件解析超时或文件大小超出 `UPLOAD_FILE_MAX_SIZE` 限制。

## 怎么确认配好了

*   上传一个包含最新修订内容的SOP文档，并验证问答结果是否能准确引用新版本规定。
*   针对文档中包含的专业术语和标准单位提问，确认模型回答中术语和单位使用正确。
*   模拟同时上传多个大型质量文档，检查系统是否能稳定解析并建立索引，无超时或报错。
*   通过API接口查询知识库，核对文档分段是否保留了原始文档的结构和关键信息。
