# 院感管理制度的部署与升级

## 这个品类的数据长什么样
院感管理制度的数据主要来源于医疗机构内部发布的各类规章制度、操作规范、技术指南和应急预案。这些文档以 PDF、Word、或内部知识库页面等形式存在，内容涵盖手卫生规范、消毒隔离技术、职业暴露处理流程、多重耐药菌感染防控策略等。更新频率通常与国家政策调整、行业标准变化以及医院内部管理要求同步，可能每年进行一次全面修订，或根据突发事件进行临时补充。文档结构多为章节式，包含目录、正文、附录等，其中涉及大量专业术语、医学缩写和剂量单位（如 `g/L`、`ppm`）。

## 这些特征在「部署与升级」这一环带来什么约束
院感管理制度文档的结构化程度不高，PDF 和 Word 文档中的表格、图片和特殊格式可能导致文本提取困难，影响 FastGPT 对知识点的准确识别。频繁的政策更新和制度修订要求 FastGPT 知识库具备高效的内容更新和版本管理能力，确保查询结果的时效性。文档中特有的医学术语和缩写，如 `VAP`（呼吸机相关性肺炎）、`SSI`（手术部位感染），需要 FastGPT 在向量化处理时保持语义的准确性，避免因词汇理解偏差导致召回错误。此外，制度间的交叉引用和复杂逻辑关系，对 FastGPT 的上下文理解和推理能力提出更高要求。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 院感制度文档通常较大，包含图片和复杂格式，确保能上传完整文件。 |
| `分段长度` | `800 字符` | 兼顾上下文完整性与单段信息密度，避免过长导致信息冗余或过短丢失关键上下文。 |
| `召回条数` | `前 5 条` | 保证召回足够相关制度片段，应对制度间交叉引用的情况。 |
| `相似度阈值` | `0.75` | 医疗领域对准确性要求高，适当提高阈值减少不相关结果。 |
| `重排返回条数` | `前 3 条` | 经过重排后，取最相关的少数几条，提高最终答案的精确性。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 大文件解析可能耗时较长，预留足够时间避免解析中断。 |

## 容易做错的三处
- 上传大型 PDF 文档时提示“API请求失败: 404 - 未找到资源”。这通常是由于 `UPLOAD_FILE_MAX_SIZE` 配置过小，导致服务器拒绝接收文件。
- 知识库更新后，查询结果仍是旧版内容。这表明知识库索引未及时重建或缓存未清除，导致查询命中旧数据。
- 部署过程中 Docker build 报错 `ERROR: failed to solve: archive/tar: unknown file mod`。这通常是 Dockerfile 或构建上下文中的文件权限问题，导致构建过程无法访问必要文件。

## 怎么确认配好了
- 上传一份包含表格和图片的标准院感管理制度 PDF 文件，确认文件能被成功解析并切分成多个知识块。
- 针对近期更新的某项制度，提出相关问题，核对 FastGPT 返回的答案是否引用了最新版本的内容。
- 使用包含医学术语和缩写的查询语句，验证 FastGPT 能准确理解并召回对应的制度条款，检查召回结果的 `相似度` 值是否符合预期。
