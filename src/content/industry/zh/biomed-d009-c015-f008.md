# 临床决策支持注册申报资料准备的工具调用与插件

## 这个品类的数据长什么样

临床决策支持（CDS）系统在注册申报资料准备过程中，涉及的数据主要来源于权威医学文献、临床指南、药品说明书、疾病数据库、以及真实世界数据（RWD）中的匿名化患者病例。这些数据更新频率不一，文献和指南通常按季度或年度更新，药品说明书随审批动态实时更新，疾病数据库则可能持续维护。文档结构复杂，包含非结构化的文本描述、半结构化的临床试验报告、以及结构化的实验室检测结果与诊断编码。字段和单位具有严格的医学规范，例如剂量单位（mg/kg）、时间单位（h、day）、效应指标（如 `ORR`、`PFS`），且常伴有特定的医学术语和缩写。

## 这些特征在「工具调用与插件」这一环带来什么约束

CDS 数据来源多样性要求工具调用插件具备多源数据集成能力，能处理不同格式的数据，例如通过爬虫或API接口获取实时更新的指南。更新频率的差异性，使得插件需要支持定时任务触发数据同步，避免使用过时信息。文档结构的复杂性，特别是大量非结构化文本，对信息抽取和实体识别插件提出了更高要求，需要能准确识别医学实体和关系。严格的医学规范和术语，意味着插件在参数映射时，必须进行严格的单位转换和术语标准化，以确保数据一致性。例如，药品剂量单位转换不当可能导致严重的决策偏差。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `tool_timeout_seconds` | `300 秒` | 复杂医学知识检索和数据处理可能耗时较长，避免因超时中断。 |
| `max_input_tokens` | `4096 tokens` | 确保能完整传入临床案例描述、相关病史等信息，支持复杂查询。 |
| `max_output_tokens` | `2048 tokens` | 允许插件返回详细的决策依据、推荐方案、以及引用文献摘要。 |
| `retrieval_top_k` | `5` | 召回最相关的少数几篇权威文献或指南，提高准确性。 |
| `similarity_threshold` | `0.85` | 针对医学术语的精确匹配要求，确保召回内容的语义高度相关。 |
| `enable_unit_conversion` | `True` | 自动处理不同来源数据中的医学单位差异，如 `mg` 到 `g` 的转换。 |

## 容易做错的三处

*   工具调用返回 `HTTP 504 Gateway Timeout`：原因在于执行复杂的医学文献检索或数据分析任务耗时过长，超出了插件的默认超时设置。
*   插件执行后结果字段为空或数据不一致：往往是由于传入的医学术语或单位未标准化，导致插件无法正确解析或匹配数据。
*   AI 生成的 SQL 查询语法错误，或查询结果与预期不符：通常是因为未将用户查询中的特定医学实体（如疾病名称、药物剂量）准确映射到数据库字段，或未考虑数据库中数据存储的特定格式。

## 怎么确认配好了

*   针对典型临床案例，测试工具调用是否能在 `tool_timeout_seconds` 内稳定返回结果。
*   验证插件返回的决策建议或数据分析结果，其字段值是否与原始医学数据保持单位和术语的一致性。
*   通过模拟多种查询场景，检查插件生成的 SQL 或 API 调用参数是否准确无误地映射了医学实体和数值，并能正确执行。
