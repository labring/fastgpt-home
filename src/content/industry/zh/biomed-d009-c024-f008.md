# 健康管理注册申报资料准备的工具调用与插件

## 这个品类的数据长什么样

健康管理注册申报资料，其数据主要来源于体检报告、健康评估问卷、穿戴设备监测数据、临床诊断记录及干预方案报告。这些数据更新频率不一，体检报告通常每年一次，穿戴设备数据可能每分钟更新，而干预方案则根据患者依从性动态调整。文档结构复杂，既有标准化程度高的实验室检测报告（包含 `项目名称`、`结果值`、`参考范围`、`单位`），也有大量非结构化的医生诊断意见、健康指导建议。字段涵盖数值型（如血压 `mmHg`、血糖 `mmol/L`）、文本型（如 `诊断描述`、`用药建议`）、枚举型（如 `风险等级`）。单位标准化是关键，例如体重可能出现 `kg`、`g`，身高 `cm`、`m`。

## 这些特征在「工具调用与插件」这一环带来什么约束

健康管理数据的多源性与异构性，要求工具调用时能适配多种数据接口，例如对医疗机构HIS系统、体检中心LIMS系统的数据连接。更新频率的差异性，意味着需要设计灵活的数据同步机制，高频数据实时处理，低频数据周期性同步。文档的半结构化与非结构化特性，对插件的信息抽取能力提出高要求，需要能够从自由文本中准确识别关键实体和关系，例如从医生建议中抽取 `药物名称`、`剂量`、`频次`。字段单位的不一致性，使得在数据传递给下游分析工具或规则引擎前，必须进行严格的单位归一化处理，例如将所有体重数据统一为 `kg`。同时，数据权限管理和隐私保护在工具调用中至关重要，确保敏感健康信息在流转过程中的安全性与合规性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `max_input_tokens` | `4096 tokens` | 适应健康报告文本长度，防止截断关键信息。 |
| `tool_timeout_seconds` | `60 秒` | 处理外部接口调用可能出现的延迟，避免过早超时。 |
| `data_schema_validation` | `严格模式` | 确保传入数据的格式和类型符合预期，例如血压值必须为数值型。 |
| `unit_conversion_rules` | `预设单位转换表` | 统一不同来源数据的单位，例如将 `g` 转换为 `kg`。 |
| `api_auth_type` | `OAuth2.0` | 符合医疗数据接口常见的安全认证标准，保证数据传输安全。 |
| `concurrent_calls_limit` | `10 并发` | 平衡系统资源占用与响应速度，避免对外部系统造成过大压力。 |

## 容易做错的三处

*   调用外部API时返回 `403 Forbidden` 或 `401 Unauthorized` 错误，原因通常是 API 密钥或认证令牌未正确配置，或已过期。
*   工具调用后返回的数据字段为空，例如 `诊断结果` 未能正确提取，往往是由于解析插件的正则表达式或抽取模型未适配最新的文档模板结构。
*   集成外部 MCP 客户端时，数值类型参数传递失败，表现为 `invalid_argument` 错误，常见于 MCP 客户端对数值类型有特定格式要求，而 FastGPT 默认传递的字符串类型不符合。

## 怎么确认配好了

*   通过 FastGPT 的调试界面，针对特定健康报告，运行工具调用流程，核对输出的结构化数据与原始报告内容是否一致。
*   使用不同来源和格式的健康数据，反复测试工具调用的稳定性，确保所有预期的字段都能被正确提取和转换。
*   模拟高并发场景，观察工具调用与插件的响应时间，并检查外部服务日志，确认没有因调用频率过高而产生限流或错误。
