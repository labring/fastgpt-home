# 冷链物流注册申报资料准备的向量模型与索引

## 这个品类的数据长什么样
生物医药冷链物流的注册申报资料主要包括设备验证报告、温度监控数据、风险评估文件、操作规程（SOP）、偏差处理记录、以及供应商资质证明等。数据来源多样，涵盖传感器实时数据流、PDF 格式的验证报告、Word 文档的操作手册和 Excel 表格的温度记录。更新频率相对较高，尤其是温度监控数据为连续性数据，其他文档如 SOP 或风险评估报告则可能随法规更新或内部流程调整而定期修订。文档结构上，报告类文件通常包含封面、目录、正文、附录等标准格式，而数据记录则多为结构化或半结构化的表格。字段与单位具有强烈的专业性，例如温度数据会精确到摄氏度或华氏度的小数点后一位，时间戳精确到秒，涉及的设备型号、批次号、有效期等字段也必须准确无误。

## 这些特征在「向量模型与索引」这一环带来什么约束
冷链物流申报资料的数据特性对向量模型与索引提出了特定要求。首先，大量结构化和半结构化数据，特别是连续的温度监控数据，需要模型能有效提取其中的时间序列特征和数值趋势，单纯的文本嵌入可能不足以捕捉其深层含义。其次，文档更新频率高，尤其是 SOP 和风险评估，要求索引机制支持高效的增量更新和版本管理，避免重复全量索引的资源浪费。再者，专业性强的字段和单位，如 `温度范围 (-20°C)` 或 `相对湿度 (60% RH)`，要求向量模型对这些特定实体有良好的识别和语义理解能力，确保在召回时能准确匹配相关规定或标准。最后，报告类文档的复杂结构，需要索引能区分不同章节或段落的重要性，并能处理图片、图表等非文本信息，以提高召回精度。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `500–800 字符` | 兼顾文档上下文完整性与单段信息密度，降低噪音对召回的影响。 |
| `重叠长度` | `100–150 字符` | 确保相邻段落间的语义连续性，避免关键信息被切割。 |
| `召回条数` | `前 8–12 条` | 在保证覆盖率的前提下，控制后续重排或 LLM 处理的负担。 |
| `相似度阈值` | 按实测标定 | 需根据具体召回效果和误报率，在 `0.75–0.85` 范围内调整。 |
| `解析图片内容` | `开启` | 冷链验证报告中常包含图表、设备照片等关键非文本信息。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 应对大型 PDF 验证报告或包含大量嵌入对象的文档解析耗时。 |

## 容易做错的三处
*   知识库未能索引到验证报告中的温度曲线图或设备布局图，原因在于 `解析图片内容` 功能未开启或图片解析模型未正确配置，导致非文本信息被忽略。
*   在检索特定批次货物的温度超标记录时，召回结果中出现了大量无关的 SOP 文档，现象是 `相似度阈值` 设置过低，使得语义不相关的段落也被纳入召回。
*   新发布的风险评估报告内容无法被及时检索到，原因在于知识库索引机制未配置增量更新或自动同步功能，导致旧版本信息滞后。

## 怎么确认配好了
*   上传一份包含复杂图表和特定专业术语的冷链验证报告，检索其中图表描述的关键信息，确认召回结果包含图片相关内容。
*   针对一份包含敏感温度范围（如 `-20°C` 至 `-15°C`）的 SOP 文档，使用不同表述方式（例如 `零下二十度到零下十五度`）进行检索，检查召回结果的准确性和鲁棒性。
*   定期更新一份冷链操作规程，并在更新后立即进行检索，核对召回内容是否为最新版本，并验证旧版本内容不再被优先召回。
