# 医院运营注册申报资料准备的HTTP 接口与外部系统

## 这个品类的数据长什么样

医院运营的注册申报资料准备，其数据来源多样且复杂。数据主要来自医院内部信息系统（HIS、LIS、PACS）、财务系统、人力资源系统，以及外部监管机构发布的标准文件。更新频率相对较低，通常与政策法规发布周期、年度审计或重大运营调整相关，多数数据为月度或季度更新，部分关键指标如床位使用率、门诊量等可能为日报。文档结构以结构化表格数据为主，如各类报表、清单，同时包含大量非结构化文本，如规章制度、操作手册、批文扫描件。字段与单位具有强行业属性，例如“床位数”（单位：张）、“门急诊人次”（单位：人次）、“医疗废物产生量”（单位：千克）、“执业医师数量”（单位：名），以及各类财务科目代码、统计分类编码等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

医院运营数据来源的分散性，要求 FastGPT 在 HTTP 接口集成时，能够灵活配置多个外部数据源的连接参数。数据的低更新频率意味着接口调用不必过于频繁，主要以按需触发或定时批量同步为主，避免资源浪费。文档结构的多样性，尤其是非结构化文本的存在，对接口返回的数据格式提出了挑战，需要能够处理 JSON、XML、PDF 或图片等多种内容类型，并可能需要后处理以提取关键信息。强行业属性的字段与单位，要求接口在数据解析时具备高度的准确性，避免因单位转换或字段误解导致的数据错误，例如“床位数”与“实际开放床位”是两个不同的概念。此外，部分敏感数据传输需要考虑加密和认证机制，例如采用 `HTTPS` 协议和 `OAuth2.0` 认证。

## 配置怎么定

| 配置项                   | 建议取法                                        | 这样取的依据                                                 |
| :----------------------- | :---------------------------------------------- | :----------------------------------------------------------- |
| `requestMethod`          | `POST` 或 `GET`                                 | 依据目标外部系统 API 文档指定，`POST` 适用于提交数据，`GET` 适用于获取数据。 |
| `requestURL`             | `https://api.example.com/hospital/data`         | 外部系统提供的具体 API 端点，确保协议为 `HTTPS` 进行安全传输。 |
| `headers.Authorization`  | `Bearer YourAccessToken`                        | 外部系统要求的认证令牌，通常为 `OAuth2.0` 或 API Key。       |
| `timeout`                | `60000` 毫秒                                    | 考虑到数据量可能较大，适当延长超时时间，避免因网络延迟或处理时间过长导致连接断开。 |
| `requestBody`            | JSON 格式，包含 `hospitalId`、`reportDate` 等 | 根据外部系统 API 文档构建请求体，精确指定需要获取的数据范围。 |
| `responseParserScript`   | 自定义脚本，提取关键字段并处理单位              | 解析返回的 JSON/XML 数据，将“床位数”等字段转换为 FastGPT 可用的格式，处理单位转换。 |

## 容易做错的三处

*   调用接口后收到 `HTTP 401 Unauthorized` 错误，原因是没有正确设置 `headers.Authorization` 参数，或者提供的 Token 已过期或无效。
*   接口返回数据中缺少预期字段或字段值为空，原因可能是 `requestBody` 中的查询参数不完整，或者 `responseParserScript` 未正确解析返回的复杂 JSON 结构。
*   长时间等待后接口调用超时，原因可能是 `timeout` 设置过短，或者外部系统 API 响应缓慢，未能在指定时间内返回结果。

## 怎么确认配好了

*   通过 FastGPT 的调试界面，手动触发一次 HTTP 接口调用，检查返回的 `HTTP Status Code` 是否为 `200 OK`。
*   检查接口返回结果中的关键字段，例如“门诊人次”、“床位数”等，确认数据结构和数值与外部系统原始数据一致。
*   比对 FastGPT 知识库中导入的数据与外部系统数据源，通过抽样核对特定日期或科室的数据，验证数据完整性和准确性。
