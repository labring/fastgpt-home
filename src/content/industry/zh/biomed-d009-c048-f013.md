# 家用医疗注册申报资料准备的知识库检索与召回

## 这个品类的数据长什么样

家用医疗器械的注册申报资料，其数据来源主要包括法规文件、技术标准、临床试验报告、产品说明书、风险管理报告、检测报告以及生产工艺文件。这些文档的更新频率受政策法规调整和产品迭代影响，通常为季度或年度更新，但核心技术标准和法规修订可能导致突发性更新。文档结构上，法规文件多为层次分明的条文，技术报告则包含大量图表、专业术语和计量单位。字段涉及产品型号、性能指标、适用范围、禁忌症、使用方法、维护保养、安全警示等，其中性能指标常带有明确的数值范围和单位，如 `V` (伏特)、`mA` (毫安)、`℃` (摄氏度)、`mmHg` (毫米汞柱)。数据通常以 PDF、Word、或扫描件形式存在。

## 这些特征在「知识库检索与召回」这一环带来什么约束

家用医疗注册申报资料的特点，对知识库检索与召回带来了特定的挑战。法规条文的严谨性和嵌套结构，要求知识库能准确识别文本层级关系，避免断章取义。技术报告中包含的图表和专业术语，意味着纯文本检索可能不足，需要更强的语义理解能力来关联图表内容与文字描述。频繁的更新要求知识库具备高效的增量索引和版本管理能力，确保检索结果的时效性。此外，性能指标的数值范围和单位，例如 `100-240V` 或 `0.5-2.0A`，在检索时需要支持数值区间查询和单位转换的语义匹配，以避免因单位不一致或数值范围匹配不精确而导致的召回遗漏。扫描件的存在则强调了对OCR识别质量和后续文本处理能力的依赖。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `500–800 字符` | 确保法规条文和技术细节的完整性，避免关键信息被截断 |
| `分段重叠长度` | `100–150 字符` | 维持上下文连贯性，尤其在跨段落引用时提供足够背景信息 |
| `召回条数` | `8–12 条` | 考虑到申报资料的复杂性，提供更多相关片段以供模型综合判断 |
| `相似度阈值` | 按实测标定 `0.75–0.85` | 平衡召回率与准确率，确保相关性高的文档被纳入 |
| `重排返回条数` | `5 条` | 聚焦于最相关的核心信息，减少模型处理无关内容的负担 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 处理大型PDF和Word文档，特别是包含复杂图表和表格的报告 |

## 容易做错的三处

*   检索结果中出现大量无关或低相关度的法规条文，原因在于分段策略过于粗糙，未能有效区分法规层级。
*   模型无法准确回答涉及设备性能参数的问题，例如特定电压或电流范围，原因在于知识库未能对数值型数据进行有效抽取和索引，导致检索时无法匹配数值区间。
*   处理扫描件来源的报告时，检索结果中出现乱码或关键信息缺失，原因在于OCR识别质量不佳或后续文本清洗不足。

## 怎么确认配好了

*   选取多个典型查询问题，例如“XX型号家用呼吸机的禁忌症是什么？”或“XX法规中关于电源适配器的安全要求”，检查召回结果是否包含所有相关且准确的法规条文或技术描述。
*   针对包含性能参数的查询，例如“血糖仪的测量精度范围”，核对召回结果中是否能正确匹配到数值区间和单位。
*   定期上传新发布的法规或产品更新文档，检查知识库索引更新速度和新文档的检索召回效果。
*   检查知识库管理界面中，针对复杂文档（如大型PDF报告）的解析状态，确认没有出现解析失败或超时。
