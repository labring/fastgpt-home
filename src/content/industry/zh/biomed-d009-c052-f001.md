# 干细胞治疗注册申报资料准备的HTTP 接口与外部系统

## 这个品类的数据长什么样

干细胞治疗注册申报资料的核心数据来源于临床试验报告、生产工艺文件、质量控制记录以及药理毒理研究报告。这些数据通常以结构化（如临床试验数据库导出）、半结构化（如PDF格式的实验报告、CTD模块文档）和非结构化（如原始图谱、显微图像）的形式存在。数据更新频率在临床试验阶段较高，可能每周或每月更新，进入注册申报环节后则相对稳定，主要集中在补充资料阶段。文档结构通常遵循ICH M4Q（CTD）模块要求，包含行政信息、质量、非临床和临床部分。字段与单位具有高度专业性，例如“细胞活力”单位为%，“细胞纯度”单位为%，“细胞增殖能力”单位为倍数，“特定表面标志物表达”单位为%或MFI值，以及各种药代动力学参数（如Cmax、AUC）及其对应单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

干细胞治疗资料的专业性与复杂结构对HTTP接口提出了更高要求。由于涉及大量PDF格式的临床报告和生产工艺文件，外部系统需具备强大的文档解析能力，能够准确提取关键字段。数据更新频率决定了HTTP接口设计时需考虑增量同步机制，避免重复传输大量不变数据。例如，临床试验数据需要定期从外部数据库通过API拉取，而申报文档的变更则可能触发特定模块的更新。字段与单位的专业性要求外部系统在数据交互时能严格校验数据类型与范围，防止因单位不匹配或数据格式错误导致解析失败。此外，某些原始图谱或图像数据文件较大，需要支持大文件传输或分块上传，并对传输时效性有一定要求。

## 配置怎么定

| 配置项                       | 建议取法                                 | 这样取的依据                                                 |
| :--------------------------- | :--------------------------------------- | :----------------------------------------------------------- |
| `max_request_timeout_seconds` | `300 秒`                                 | 处理复杂的PDF解析和大文件传输，需要较长的响应时间            |
| `max_payload_size_mb`        | `200 MB`                                 | 适应包含高分辨率图像或大量实验数据的申报文档                 |
| `retry_attempts`             | `3 次`                                   | 应对网络波动或外部系统瞬时故障，确保数据传输可靠性           |
| `chunk_size_characters`      | `1500–2500 字符`                         | 优化长文本（如临床研究总结）的切分与处理效率                 |
| `data_schema_version`        | `v2.1`                                   | 确保与外部注册申报平台的特定数据接口版本兼容                 |
| `auth_token_refresh_interval`| `按实测标定`                             | 依据外部系统API令牌有效期和刷新机制，防止鉴权失败            |

## 容易做错的三处

*   现象：API请求返回HTTP状态码401或403。原因：认证令牌过期或权限不足，未能正确携带或刷新 `Authorization` 头信息。
*   现象：响应体显示“No data provided”或特定字段为空。原因：外部系统数据结构与预期不符，或请求参数 `document_type`、`module_id` 等未正确指定，导致未能检索到对应数据。
*   现象：HTTP请求长时间无响应直至超时。原因：传输的数据量过大，或外部系统处理复杂查询耗时过长，`max_request_timeout_seconds` 设置不足。

## 怎么确认配好了

*   通过模拟请求，验证是否能成功获取到不同CTD模块（如“质量模块3”、“临床模块5”）的关键摘要信息，核对返回数据结构与预期数据模型一致。
*   上传包含复杂图表和表格的PDF文档，检查解析结果中关键字段（如“细胞活性%”、“基因表达量MFI”）是否被准确提取并格式化。
*   对大文件（例如超过100MB的原始实验数据）进行上传测试，确认传输过程无中断，并能在规定时间内完成。
*   定期检查API调用日志，关注是否有鉴权失败（401/403）、请求超时（504）或数据解析错误（400/500）等异常记录，并根据错误码调整 `auth_token_refresh_interval` 或 `max_request_timeout_seconds` 等参数。
