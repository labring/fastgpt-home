# 康复设备注册申报资料准备的文档解析与分块

## 这个品类的数据长什么样

康复设备注册申报资料的数据来源广泛，主要包括产品技术要求、检验报告、临床评价报告、风险管理报告、说明书、标签、体系文件以及各类法规标准。这些文档通常以 PDF 格式存在，部分可能为扫描件。更新节奏受法规修订、产品迭代及临床试验进展影响，通常为季度或年度更新，但涉及重大变更时可能随时更新。文档结构复杂，包含大量表格、图片、附录，且不同类型文档间存在交叉引用。字段方面，涉及生物力学参数、电生理参数、材料学指标、安全性能参数等，单位多样，如牛顿·米（N·m）、毫伏（mV）、兆帕（MPa）、赫兹（Hz），并常伴有测量方法和判定标准。

## 这些特征在「文档解析与分块」这一环带来什么约束

康复设备申报资料的复杂性对文档解析与分块提出了特殊要求。首先，大量扫描件和复杂排版（如多栏、图文混排）需要增强的 OCR 能力和版面分析算法，以确保文本提取的完整性和准确性。其次，频繁的交叉引用要求分块时能有效识别并保留上下文关联，避免关键信息碎片化。表格数据在申报资料中至关重要，传统文本分块方法容易破坏表格结构，导致数据语义丢失，因此需要专门的表格解析和多向量支持。此外，各类参数和单位的精确识别，以及它们与对应判定标准的关联，是确保知识库高质量召回的关键，需要精细化的实体识别和关系抽取能力。更新频率的不确定性则要求知识库具备高效的增量更新和版本管理机制。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `800-1200 字符` | 康复设备文档上下文关联性强，长分段有益于保留完整语义，避免关键信息被截断。 |
| `分段重叠长度` | `100-200 字符` | 确保相邻分段之间有足够的重叠，以应对跨分段的引用或关键术语。 |
| `启用增强PDF解析` | `勾选` | 处理包含大量扫描件、复杂排版和表格的 PDF 文档，提升文本和表格识别准确率。 |
| `最大文件大小` | `500 MB` | 康复设备申报资料可能包含大量图片和附件，文件体积通常较大，需支持大文件上传。 |
| `表格多向量支持` | `启用` | 精确解析表格结构，将表格内容转化为多向量表示，提升表格数据召回准确性。 |
| `解析超时时间` | `600 秒` | 复杂 PDF 文档解析耗时较长，增加超时时间可避免解析中断，确保大型文件处理完成。 |

## 容易做错的三处

*   PDF 文件解析失败或内容缺失：现象表现为日志中出现 `PDF_PARSE_ERROR` 或知识库中导入的文档内容不完整。原因常常是未启用增强 PDF 解析功能，或 `解析超时时间` 设置过短，导致复杂或扫描性质的 PDF 文件无法被有效处理。
*   表格数据召回不准确或丢失：现象是查询表格相关内容时，结果无法提供正确的行或列信息，或表格内容被错误地解析为普通文本。根本原因在于 `表格多向量支持` 未被启用，导致系统无法识别表格的结构化语义。
*   文档内容上下文关联性差：表现为检索结果中的分段过于零散，无法提供完整的段落或逻辑链条，导致用户需要多次查询才能获取完整信息。主要原因是 `分段长度` 设置过短，或 `分段重叠长度` 不足，未能有效捕捉康复设备申报资料中复杂的逻辑关系和交叉引用。

## 怎么确认配好了

*   上传典型包含扫描件、复杂表格和图文混排的申报资料 PDF，检查知识库中导入的文档内容是否完整，尤其是表格结构和图片说明是否被正确提取。
*   针对文档中的关键参数（如“最大输出力矩”、“有效作用面积”）和其对应的检测方法进行检索，验证召回结果是否能准确呈现完整的上下文信息。
*   选取申报资料中具有复杂交叉引用的段落，通过提问验证模型能否理解并关联不同分段中的信息，确保知识库能够支持多跳问答。
