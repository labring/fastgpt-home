# 康复设备注册申报资料准备的知识库检索与召回

## 这个品类的数据长什么样

康复设备注册申报资料的数据来源广泛，涵盖国家药品监督管理局（NMPA）发布的法规文件、指导原则、技术审评报告，以及国际医疗器械监管机构（如 FDA、CE）的相关标准。此外，还包括设备制造商内部的产品技术要求、风险分析报告、临床评价资料、质量管理体系文件等。数据更新频率不一，法规文件通常每年修订或发布新版，技术标准可能数年更新一次，而企业内部资料则随产品研发和迭代实时更新。文档结构以 PDF、Word、Excel 居多，部分为扫描件或图片格式。字段与单位具有高度标准化特征，例如设备型号、序列号、生产许可证号、注册证号、性能参数（如功率 `W`、频率 `Hz`、尺寸 `mm`）、安全指标等，这些字段在不同文档中可能以不同表述出现，但核心含义一致。

## 这些特征在「知识库检索与召回」这一环带来什么约束

康复设备注册申报资料的数据特点对知识库检索与召回提出了具体要求。首先，法规和指导原则的权威性与严谨性，要求检索结果必须精准无误，不能出现模糊或臆测内容，这决定了召回策略需优先保证相关性。其次，企业内部文档的实时更新特性，意味着知识库需要支持高效的增量更新机制，以确保检索到的信息始终是最新版本。文档格式的多样性，尤其是扫描件和图片，要求知识库具备强大的 OCR 文本识别能力，将非结构化数据转化为可检索内容。字段与单位的高度标准化，虽然有助于结构化信息抽取，但也对分词和实体识别的准确性提出挑战，例如识别“`频率`”对应的“`Hz`”单位。此外，不同文档中同一概念的多样化表述，需要知识库能够处理同义词和概念关联，避免因表述差异而遗漏重要信息。

## 配置怎么定

| 配置项             | 建议取法                               | 这样取的依据                                                                                                                                              |
| :----------------- | :------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `分段长度`         | `500–800 字符`                         | 确保法规条款、技术说明等内容的语义完整性，避免关键信息被截断。                                                                                            |
| `分段重叠长度`     | `100–150 字符`                         | 保持上下文连贯性，尤其对于交叉引用较多的技术文档和标准，有助于模型理解。                                                                                  |
| `召回条数`         | `前 8–12 条`                           | 平衡检索效率与覆盖度，法规和技术文档的复杂性可能需要更多上下文支持。                                                                                      |
| `相似度阈值`       | `按实测标定`                           | 康复设备申报资料对准确性要求高，需通过测试集确定能有效过滤无关信息且不遗漏关键信息的阈值，通常在 `0.75` 以上。                                            |
| `重排返回条数`     | `前 5 条`                              | 在初次召回的基础上，利用更复杂的模型对前 N 条结果进行二次排序，进一步提升结果相关性与精确度，减少无关干扰。                                              |
| `知识库搜索触发条件` | `用户输入包含“注册”“申报”“标准”等关键词` | 避免不必要的知识库查询，仅在用户明确需要法规或技术支持时激活，提高响应速度；结合判断器可实现根据不同查询类型路由到特定知识库。                      |

## 容易做错的三处

*   现象：用户提问关于特定设备型号的性能参数，但检索结果中缺少相关数据，或返回了不相关的法规条文。
    原因：知识库在数据导入时，未对设备型号、性能参数等关键结构化信息进行有效提取和索引，导致检索时无法精准匹配。
*   现象：知识库搜索耗时过长，有时甚至超过 `60 秒`，特别是在对话轮次增多后更为明显。
    原因：知识库的分段策略不合理，导致单个文档被切分成过多小段或过长分段，增加了向量检索的计算量，或未充分利用缓存机制。
*   现象：当用户输入“`CE 认证`”时，知识库未能召回关于欧盟医疗器械法规 `MDR` 的文件。
    原因：知识库未建立充分的同义词或概念映射关系，导致对行业特定术语和其等效表达的理解不足。

## 怎么确认配好了

*   选择一批典型的康复设备注册申报问题，包括法规查询、技术参数询问、风险评估等，进行检索测试，检查召回结果的相关性、准确性和完整性，并记录每次查询的响应时间，确保在可接受的 `5 秒` 内。
*   定期模拟新法规发布或产品技术资料更新，执行知识库的增量更新操作，验证更新流程是否顺畅，更新后的数据能否被正确索引并检索到。
*   对包含扫描件和图片格式的文档进行测试，确认 OCR 识别后的文本内容与原文一致，且关键信息（如注册证号、型号等）可被正确检索。
*   检查知识库的日志输出，确认在用户查询时，`相似度阈值` 和 `召回条数` 等参数是否按照预期生效，以及是否存在 `HTTP 500` 或 `TIMEOUT` 错误码。
