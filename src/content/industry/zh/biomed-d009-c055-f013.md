# 影像设备注册申报资料准备的知识库检索与召回

## 这个品类的数据长什么样

影像设备（如CT、MRI、超声诊断仪）的注册申报资料，其核心数据来源包括但不限于国家药监局（NMPA）发布的法规文件、技术审评指导原则、标准目录、以及企业内部的产品技术要求、检测报告、临床评价报告、说明书草稿等。这些文档通常以PDF、Word、Excel等格式存在。法规文件更新频率相对稳定，通常以年为周期，但技术指导原则和标准会根据技术发展和监管需求进行不定期修订。企业内部资料则随产品研发迭代而更新。文档结构严谨，包含大量专业术语、图表、测试数据、设备参数（如分辨率、扫描时间、剂量等）以及特定的术语（如“空间分辨率”、“信噪比”、“伪影”）。计量单位多样，涉及物理量、医学影像学指标等，如毫米（mm）、西弗（Sv）、高斯（G）、帧/秒（fps）。

## 这些特征在「知识库检索与召回」这一环带来什么约束

影像设备注册申报资料的专业性与严谨结构，对知识库的检索与召回提出了具体要求。首先，法规和技术指导原则的更新不频繁但影响深远，要求知识库能够快速识别并更新相关条款，确保召回内容的时效性。其次，文档中包含大量图表和专业术语，尤其在性能指标和临床应用描述部分，传统文本分块方法可能导致关键信息割裂，影响召回的完整性。例如，描述“空间分辨率”的段落可能包含文本说明、图示和测试数据，单一文本切分无法有效关联。此外，各类设备参数的计量单位多样，在检索时需要精确匹配，避免因单位差异导致的误判。精确召回需要兼顾文本语义理解与结构化数据提取能力，以应对不同类型文档中嵌套的复杂信息。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `500–800 字符` | 兼顾影像设备资料中的长句和图表描述，避免关键信息被切断。 |
| `重叠长度` | `100–150 字符` | 确保上下文连续性，尤其在专业术语和参数描述跨段时。 |
| `相似度阈值` | `0.75–0.85` | 提高召回结果的精确性，过滤掉不相关的法规或技术条款。 |
| `召回条数` | `8–12 条` | 在保证覆盖面的前提下，避免引入过多噪声信息干扰判断。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 应对大型PDF文件，特别是包含大量嵌入图片和表格的文档。 |
| `maxContext` | `3000 Tokens` | 确保在生成回复时能够包含足够的技术细节和法规引用。 |

## 容易做错的三处

*   知识库问答中无法识别图片内容，导致对设备性能的图像化描述无法给出有效回答。原因在于文档解析时未启用或正确配置图片OCR（光学字符识别）功能，导致图片内容未被提取为可检索的文本。
*   检索结果中出现大量与具体设备型号不符的通用性法规条文，未能精确匹配目标设备的申报要求。原因在于知识库在构建时缺乏对文档元数据的有效管理，未能将法规条文与特定产品系列或设备类型进行有效关联。
*   在查询特定技术参数时，召回结果缺乏相关图表数据，导致信息不完整。原因在于文档切分策略过于依赖纯文本，未能将图表及其对应的文字说明视为一个整体进行处理和索引。

## 怎么确认配好了

*   上传包含复杂图表和专业术语的影像设备技术文档，检查文档解析日志，确认图片OCR是否成功提取了图表中的文本信息。
*   针对特定影像设备型号，提出关于其核心性能参数（如“CT设备的低对比度分辨率”）的问题，验证召回结果是否包含该型号对应的技术要求、测试报告或相关法规条款，并确认参数数值与单位的准确性。
*   进行模拟法规更新测试，替换知识库中某项旧版法规文件，然后查询相关问题，核对召回结果是否优先呈现新版法规内容，确保时效性。
*   查询涉及多章节、多页面的技术指导原则，确认召回的文本片段能够提供完整的上下文，避免断章取义。
