# 心血管介入注册申报资料准备的HTTP 接口与外部系统

## 这个品类的数据长什么样

心血管介入医疗器械的注册申报资料，其数据来源广泛且更新频率不一。临床试验数据、生物相容性报告、性能验证报告通常由第三方实验室或研究机构提供，数据格式多样，包含 PDF、Word 文档、Excel 表格、DICOM 图像等。产品技术要求、说明书、标签等由企业内部撰写，多为标准化的 Word 或 PDF 格式。法规文件如指导原则、标准文本则来源于国家药监局官网，更新频率随政策调整。数据内容涉及大量专业术语、计量单位（如毫米、毫克、牛顿、帕斯卡、毫升/分钟），以及复杂的图表和图像信息。部分数据，特别是临床随访数据，可能以半结构化或非结构化文本形式存在。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

数据来源的多样性要求 HTTP 接口具备强大的文件类型解析能力和灵活的数据抽取机制。非结构化文本的存在，尤其是临床随访记录中的不良事件描述，对文本处理和实体识别能力提出较高要求，需要接口能够处理长文本并进行语义理解。计量单位的规范性与一致性是关键，HTTP 接口在数据传输和处理过程中必须严格校验，避免单位混淆导致的申报错误。部分敏感数据，如患者隐私信息，在通过 HTTP 接口传输时，需要严格的数据脱敏和加密措施。此外，法规文件的动态更新意味着外部系统需要定期通过 HTTP 接口拉取最新政策，以确保申报资料的合规性，这就要求接口具备版本控制和增量更新能力。

## 配置怎么定

| 配置项                   | 建议取法                               | 这样取的依据                                                                         |
| :----------------------- | :------------------------------------- | :----------------------------------------------------------------------------------- |
| `maxContext`             | `8192`                                 | 处理心血管介入器械申报资料中的长文本描述，如临床报告摘要，需要较大上下文窗口。     |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300` 秒                               | 考虑到大型 PDF 或图像文件的解析耗时，延长文件解析超时时间。                          |
| `分段长度`               | `1000–1200 字符`                       | 确保临床试验报告、技术要求等文档分段内容的完整性，减少语义断裂。                   |
| `相似度阈值`             | `0.78`                                 | 提高对关键技术参数、法规条款等高精度匹配的需求，避免遗漏。                         |
| `HTTP_REQUEST_TIMEOUT_SECONDS` | `60` 秒                                | 外部系统拉取大型法规文件或临床数据包时，提供足够的网络传输时间。                   |
| `MAX_FILE_SIZE_MB`       | `500 MB`                               | 允许上传大型的生物相容性报告、影像学数据等文件。                                   |

## 容易做错的三处

*   调用外部 API 时，返回 `HTTP 504 Gateway Timeout` 错误，原因可能是外部系统处理复杂查询或返回大量数据时响应时间过长，超过了网关或应用配置的超时限制。
*   从外部知识库拉取的法规文本中，特定字段（如“适用范围”、“注册类别”）内容为空，原因在于外部系统接口在数据映射或抽取时，未能正确识别或解析这些半结构化文档中的对应字段。
*   通过 API 输出的注册申报资料草稿中，产品型号或技术参数的单位错误或缺失，原因是文本生成模型在整合多源数据时，未能严格遵守单位规范，或外部数据源本身存在单位不一致的问题。

## 怎么确认配好了

*   通过 HTTP 接口上传一个包含多页表格和图片的 PDF 版临床试验报告，检查知识库中该文档的分段是否完整，并能正确识别表格内容。
*   使用外部系统接口拉取最新的国家药监局心血管介入器械相关指导原则，核对本地知识库中的法规文本版本是否与官网一致。
*   通过 API 生成一份产品技术要求草稿，重点检查其中涉及的几何尺寸、材料强度等关键参数的数值与单位是否准确无误，并与原始设计文档进行比对，确认其符合预期设定的误差范围。
