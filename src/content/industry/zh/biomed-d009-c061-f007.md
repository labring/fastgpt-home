# 手术机器人注册申报资料准备的工作流编排

## 这个品类的数据长什么样

手术机器人的注册申报资料数据源多样，主要包括产品技术要求、检验报告、临床试验报告、风险分析报告、说明书以及软件验证报告等。这些文档通常以 PDF、Word、Excel 等多种格式存在，内容涵盖机械设计参数、电子电气性能指标、软件架构说明、临床有效性与安全性数据、以及生物相容性测试结果。数据更新节奏与研发迭代周期紧密相关，通常在产品设计变更、软件版本升级或临床试验阶段性总结后进行。文档结构复杂，常包含图表、图片与大量专业术语。字段涉及机械臂自由度、定位精度、图像处理算法、并发症发生率等，单位则涵盖毫米、弧度、毫秒、百分比等，且常伴随特定的医学或工程规范缩写。

## 这些特征在「工作流编排」这一环带来什么约束

手术机器人资料的复杂文档格式与多源性，要求工作流具备强大的文档解析能力，特别是对非结构化数据中的关键信息提取。数据更新频率与迭代周期决定了工作流需支持版本管理和增量更新，以确保申报资料始终基于最新数据。专业术语和规范缩写，对大模型的理解能力提出高要求，需要通过领域知识增强或专业词典进行辅助。字段与单位的多样性，以及数据间的逻辑关联，使得工作流中的数据验证和一致性检查环节至关重要，避免因数据错漏或单位不统一导致申报失败。此外，临床试验报告中的敏感数据处理，要求工作流在数据流转过程中严格遵守数据安全和隐私保护协议。

## 配置怎么定

| 配置项                 | 建议取法                               | 这样取的依据                                                                                                |
| :--------------------- | :------------------------------------- | :---------------------------------------------------------------------------------------------------------- |
| `文件分段长度`         | `800–1200 字符`                        | 兼顾上下文完整性与模型处理效率，避免长文本导致的语义漂移。                                                  |
| `相似度阈值`           | `0.78`                                 | 确保检索相关性，过滤掉不相关的技术文档片段，减少误报。                                                      |
| `召回条数`             | `8 条`                                 | 覆盖足够多的潜在相关信息，同时限制输入令牌数，避免模型过载。                                                |
| `最大上下文`           | `16000 令牌`                           | 适应手术机器人资料中常出现的长段描述和复杂图表说明，保证完整理解。                                          |
| `数据源更新频率`       | `每周`                                 | 匹配研发周期的中等频率更新，及时纳入最新的设计变更和测试报告。                                              |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒`                               | 处理大型 PDF 或包含复杂图表的 Word 文档时，提供充足的解析时间，避免超时报错。                               |

## 容易做错的三处

*   数据库连接出现 `Failed to connect to jyfkk:1433` 错误，原因可能是工作流配置的数据库地址或端口有误，或者数据库防火墙未开放访问权限。
*   工作流执行超时，结果条数不符合预期，原因可能是 `PARSE_FILE_TIMEOUT_SECONDS` 设置过短，未能完整处理大型临床报告或图像密集型文档。
*   大模型预测结果中出现大量无关信息，原因可能是 `相似度阈值` 设置过低，导致召回了过多与申报资料不直接相关的文档片段。

## 怎么确认配好了

*   模拟提交一个典型的手术机器人注册申报资料，检查工作流是否能完整解析所有文档，并提取出产品名称、型号、主要技术参数等关键字段。
*   随机抽取临床试验报告中的若干问题，通过工作流进行问答测试，核对模型返回的答案是否准确、是否有足够的引用支持，并评估答案中是否包含敏感信息。
*   上传一份包含最新设计变更的文档，观察工作流是否能识别并更新相关数据，然后验证基于更新数据生成的报告内容是否反映了这些变更。
