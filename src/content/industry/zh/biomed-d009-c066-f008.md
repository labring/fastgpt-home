# 招标挂网注册申报资料准备的工具调用与插件

## 这个品类的数据长什么样

生物医药领域的招标挂网数据主要来源于各省市的医药集中采购平台、医保局官网以及部分第三方数据服务商。这些数据更新频率较高，通常按月或季度发布，涉及产品目录、价格、中标企业、挂网状态等关键信息。文档多以结构化或半结构化形式存在，例如 Excel 表格、PDF 公告或网页数据。字段方面，常见的包括“通用名”、“商品名”、“生产企业”、“剂型”、“规格”、“包装”、“挂网价格”、“挂网批次”、“医保支付标准”、“采购区域”等，其中“挂网价格”可能涉及多种定价策略和单位，如“元/盒”、“元/支（含税）”、“元/最小制剂单位”。数据的特点在于其时效性和区域性，不同省份的挂网规则和价格体系可能存在差异。

## 这些特征在「工具调用与插件」这一环带来什么约束

招标挂网数据的时效性要求工具调用能快速响应数据源变化，例如通过 API 定期抓取最新公告。数据的区域性意味着在设计工具时需要考虑多区域数据源的适配，避免硬编码特定省份的解析逻辑。文档结构的多样性（Excel、PDF、网页）对解析工具的鲁棒性提出要求，单一解析器可能无法覆盖所有情况。例如，PDF 公告中的表格可能需要 OCR 识别后进行结构化抽取。字段单位的复杂性，如“元/盒”与“元/最小制剂单位”的换算，需要在工具调用后的数据处理环节进行标准化，否则可能导致数据比对错误。此外，由于招标挂网涉及大量历史数据，知识库的增量更新和版本管理也成为重要的考量。

## 配置怎么定

| 配置项                   | 建议取法                               | 这样取的依据                                                               |
| :----------------------- | :------------------------------------- | :------------------------------------------------------------------------- |
| `maxContext`             | `1500 tokens`                          | 确保模型能处理典型挂网公告的完整上下文，避免信息截断。                   |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒`                               | 应对大型 PDF 公告或复杂网页解析可能耗时较长的情况。                      |
| `召回条数`               | `前 10 条`                             | 招标挂网涉及产品众多，增加召回条数提升相关信息的覆盖度。                 |
| `相似度阈值`             | `0.75`                                 | 精准匹配产品信息，降低因名称相似导致的误召回。                           |
| `重排返回条数`           | `前 5 条`                              | 在召回信息中进一步筛选出最相关的少数几条，提高模型处理效率。             |
| `tool_call_max_retries`  | `3 次`                                 | 应对外部 API 调用可能因网络波动或服务暂时性不可用而失败的情况。          |

## 容易做错的三处

*   调用外部 API 获取数据时返回 `HTTP 502 Bad Gateway` 错误，原因可能是 API 服务端负载过高或临时维护，未设置重试机制。
*   解析 PDF 公告后，特定字段如“挂网价格”为空，原因在于 PDF 格式多样，现有解析器对某些特殊排版或扫描件识别能力不足。
*   知识库查询结果中，不同批次同一产品的价格单位不一致，原因是数据源未做标准化处理，直接导入导致单位混淆。

## 怎么确认配好了

*   选取多个不同省份、不同发布形式（Excel、PDF、网页）的招标挂网公告，通过工具调用流程进行解析，检查关键字段如“挂网价格”、“生产企业”是否准确抽取。
*   使用历史数据与最新数据进行比对，确认知识库的增量更新机制是否正常工作，新挂网产品信息能够被准确索引。
*   模拟用户查询“XX 药品在 XX 省的最新挂网价格”，验证模型是否能通过工具调用获取并正确解读最新数据，并给出有单位的数值。
