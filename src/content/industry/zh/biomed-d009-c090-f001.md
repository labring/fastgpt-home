# 药物经济学注册申报资料准备的HTTP 接口与外部系统

## 这个品类的数据长什么样
药物经济学数据主要来源于临床试验报告、真实世界研究数据、卫生技术评估报告、成本效益分析模型以及文献数据库。这些数据通常以结构化表格（如 Excel、CSV）、非结构化文本（如 PDF 报告、Word 文档）和半结构化数据（如 XML 格式的经济学模型输入参数）形式存在。数据更新频率相对较低，主要集中在药品上市前后的研究发布周期，通常为每半年至一年。文档中包含大量专业术语、单位（如美元/QALY、%）、统计学指标（如置信区间、P值）和复杂的模型参数。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
药物经济学数据来源多样，导致外部系统集成时需要支持多种数据格式的解析。由于数据更新频率不高，对实时性的要求相对宽松，但对数据完整性和准确性有极高要求，因此在接口设计时需侧重数据校验与错误回溯机制。文档中复杂的专业术语和统计学单位，要求接口在数据提取和转换为向量时，能够有效识别并保持其语义准确性，避免因单位或指标混淆导致的误解。此外，文档通常体积较大，可能包含图表和复杂表格，对接口的文件处理能力和超时设置构成挑战，需要更长的处理时间和更大的文件上传限制。

## 配置怎么定

| 配置项                       | 建议取法                                        | 这样取的依据                                                 |
| :--------------------------- | :---------------------------------------------- | :----------------------------------------------------------- |
| `UPLOAD_FILE_MAX_SIZE`       | `500 MB`                                        | 药物经济学报告常包含大量图表和详细数据，文件较大。           |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒`                                        | 处理复杂 PDF 和 Word 文档中的图表、表格及文本提取耗时较长。  |
| `分段长度`                   | `800–1200 字符`                                 | 确保单个分段能包含足够的上下文，同时避免过长导致语义漂移。   |
| `召回条数`                   | `前 10 条`                                      | 药物经济学概念关联性强，增加召回条数可提高相关信息覆盖率。   |
| `相似度阈值`                 | `0.75`                                          | 保证召回内容的专业性和精确性，过滤掉不相关或泛化信息。       |
| `HTTP_REQUEST_TIMEOUT_SECONDS` | `120 秒`                                        | 外部数据源响应可能较慢，预留充足时间避免连接中断。           |

## 容易做错的三处
1. 外部系统调用返回 404 错误，原因是 API 路径或认证信息未正确配置。
2. API 调用后返回数据字段为空或格式错误，原因在于接口对数据结构校验不严格，未能有效处理外部数据源的非标准输出。
3. 文档上传后处理超时，原因是 `PARSE_FILE_TIMEOUT_SECONDS` 设置过短，无法应对大型或复杂文档的解析。

## 怎么确认配好了
1. 上传一个典型的药物经济学 PDF 报告，检查其是否能被成功解析并切分成合理的分段。
2. 通过 API 调用外部数据源，核对返回的关键字段值和单位是否与预期一致。
3. 模拟并发请求，验证系统在处理多个外部接口调用时是否能稳定运行，并检查响应时间。
