# 远程医疗注册申报资料准备的引用来源与溯源

## 这个品类的数据长什么样

远程医疗的注册申报资料主要包括医疗器械注册证、服务资质许可、临床试验报告、用户操作手册、安全评估报告、软件验证文件以及相关法规符合性声明等。数据来源广泛，涉及国家药品监督管理局（NMPA）、各省市卫健委、行业协会以及第三方检测机构。资料更新频率不一，法规文件通常每年修订或发布新版，临床数据和安全报告则可能根据产品迭代或不良事件反馈进行补充。文档结构多为 PDF 格式的正式报告、Word 格式的详细说明、Excel 格式的统计数据，以及少量图片和视频文件。核心字段包括 `产品名称`、`注册证号`、`适用范围`、`性能指标`、`软件版本`、`测试报告编号`、`临床试验批件号`、`不良事件编号` 等，单位涉及 `mm`、`Hz`、`dB`、`毫秒`、`次/分钟` 等。

## 这些特征在「引用来源与溯源」这一环带来什么约束

远程医疗申报资料的法规强约束性要求引用来源的精准性与溯源的完整性。文档多为长篇幅的正式报告，分段过短可能导致语义丢失，过长则影响检索精度。法规更新的滞后性要求知识库能够处理版本管理，确保引用的是最新有效文本，同时保留历史版本以供对比。多机构数据来源要求对不同来源的文档进行有效区分和权限控制，防止交叉引用或引用不具备法律效力的非官方文件。技术规范中包含大量专业术语和计量单位，需要模型具备准确识别和关联的能力，避免因单位混淆导致引用错误。此外，临床试验报告和安全评估报告中的图表数据，需要结合文本描述进行综合理解，对引用内容的完备性提出挑战。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `500–800 字符` | 平衡长文档语义完整性与检索粒度，减少截断风险 |
| `分段重叠长度` | `50–100 字符` | 确保上下文连续性，避免关键信息被切分到不同段落 |
| `召回条数` | `前 8–12 条` | 覆盖多源信息，提高相关性召回率，减少遗漏 |
| `相似度阈值` | `0.78–0.85` | 排除低相关度内容，提升引用精确度，减少误引 |
| `重排返回条数` | `前 3–5 条` | 聚焦最相关内容，优化最终呈现，提高可读性 |
| `启用文档版本管理` | `是` | 确保引用法规和技术标准为最新生效版本，支持历史追溯 |

## 容易做错的三处

*   现象：模型输出的引用来源为空或提示“未找到相关引用”。原因：知识库分段长度设置不当，导致关键信息被截断或语义不完整，检索时无法匹配。
*   现象：引用内容与问题关联度低，甚至出现其他产品或服务的信息。原因：`相似度阈值`设置过低，未能有效过滤掉不相关的召回结果。
*   现象：系统提示 `KnowledgeBaseError: Invalid document ID`。原因：引用变量或知识库ID在文档更新或删除后未同步更新，导致指向了不存在的资源。

## 怎么确认配好了

*   针对典型申报问题，验证模型输出的引用来源是否指向正确的法规条文、技术报告章节或临床数据表格。
*   模拟法规更新场景，上传新版文档后，核对模型引用是否自动切换到最新版本，并能查询到旧版文档的引用记录。
*   随机抽取多份申报资料中的专业术语和计量单位，测试模型能否准确识别并引用到包含这些术语的原始文本。
*   检查引用来源的文件名和页码是否与原始文档内容精确对应，确保溯源链路完整可验证。
