# 院感管理注册申报资料准备的多轮对话与提示词

## 这个品类的数据长什么样

院感管理注册申报资料主要来源于国家药品监督管理局（NMPA）发布的法规文件、指导原则、技术审评要点，以及各类医疗机构的院内感染管理制度、操作规范、统计报告。数据更新频率较高，法规性文件通常按年度或根据疫情变化进行修订，院内报告则按季度或月度更新。文档以 PDF、Word、Excel 等格式为主，包含大量非结构化文本和结构化数据。结构化数据涉及感染率、病原菌分布、抗菌药物使用情况、手卫生依从性等字段，单位多为百分比、例数、频次。非结构化文本则涵盖法规条款解读、临床案例描述、管理措施细则等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束

院感管理资料的法规性强、更新频繁，要求多轮对话系统能够快速适应最新政策变化，避免引用过时信息。非结构化文本中包含的专业术语和概念繁多，对提示词的语义理解和上下文关联能力提出挑战。多轮对话需要准确识别用户意图，例如区分“手卫生依从性”与“手卫生培训”等相似概念。结构化数据与非结构化文本的混合，要求系统在检索时能够整合不同类型的信息源。文档格式多样性，特别是 PDF 中可能存在的表格和图片，需要高效的解析能力，以确保信息完整性。法规文件的层级关系和引用关系，对对话系统在溯源和解释方面有严格要求。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `maxContext` | `6` | 院感法规与指南通常具有较强的逻辑关联性，6轮对话可覆盖常见的问题链条。 |
| `分段长度` | `800–1200 字符` | 适应法规文件和指导原则中段落长度，保证语义完整性。 |
| `召回条数` | `10 条` | 考虑到法规条文可能分散在不同文件中，增加召回量可提高覆盖率。 |
| `相似度阈值` | `0.75` | 院感术语精准度要求高，提高阈值可减少不相关内容的干扰。 |
| `重排返回条数` | `3 条` | 在召回结果中精选最相关的3条，提高最终回答的质量和聚焦性。 |
| `TEMPERATURE` | `0.3` | 注册申报资料的严谨性要求，降低模型自由度，避免生成不准确内容。 |

## 容易做错的三处

*   对话开场白中预设多个问题后，用户提问无法准确匹配意图。原因在于提示词设计过于宽泛，未能有效引导模型聚焦到细分领域关键词。
*   对话接口返回 `404 status code`（无响应体）。原因通常是模型配置错误，例如 `API_KEY` 失效或 `MODEL_ID` 拼写有误，导致模型服务无法被正确调用。
*   刷新页面后提示“检测到没有可用的索引模型”。原因多为知识库索引构建失败或未完成，导致系统无法从知识库中检索信息。

## 怎么确认配好了

*   针对核心法规条款，模拟多轮提问，检查回答是否准确引用原文，并能指出原文 `文档ID` 及 `页码`。
*   输入包含院感专业术语的复杂问题，验证系统能否正确理解术语含义并给出相关解释，可参考行业专家意见来确定理解的准确性。
*   测试系统对最新发布的法规文件的响应能力，检查更新后的知识库是否能及时提供相关信息，可与官方发布时间进行比对。
*   使用包含结构化数据的提问，如“某季度手卫生依从性报告”，确认系统能否正确提取并解释数据，比对原始报告数据来确定提取的准确性。
