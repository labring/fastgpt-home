# 线索同步私域咨询转化的部署与升级

## 这个品类的数据长什么样

生物医药领域的线索数据通常来源于多种渠道，例如线上广告投放、学术会议注册、线下沙龙活动、以及医生或患者的自主咨询。这些数据以结构化或半结构化的形式存在，常见的文档结构包括：姓名、联系方式、意向产品、咨询时间、初步描述、来源渠道等字段。数据更新频率因来源而异，广告投放数据可能实时同步，会议或活动数据则可能在活动结束后批量导入。字段单位相对统一，主要涉及文本、数字和时间戳，但偶尔会出现特定医学术语或产品批号的缩写，需要额外处理。

## 这些特征在「部署与升级」这一环带来什么约束

线索数据来源的多样性要求部署时具备灵活的数据接入能力，例如支持多种API接口、文件导入格式。频繁的数据更新节奏对系统的实时处理能力和并发性能提出要求，需要关注消息队列和异步处理机制的配置。数据中的半结构化内容和专业术语，如产品批号或疾病代码，在升级过程中可能需要定制化的预处理模块，以确保知识库的准确性和检索效率。此外，私域咨询对数据安全和隐私合规性要求较高，部署方案必须严格遵循相关法规，例如数据脱敏和访问权限控制。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `DATA_SOURCE_INTERVAL_SECONDS` | `600 秒` | 平衡数据实时性与系统负载，多数线索数据在此间隔内更新足矣。 |
| `MAX_DOCUMENT_SIZE_MB` | `10 MB` | 覆盖多数线索导入文件大小，避免因文件过大导致上传失败。 |
| `CHUNK_SIZE_TOKENS` | `512` | 平衡上下文长度与检索精度，确保线索关键信息被完整捕获。 |
| `RECALL_TOP_K` | `5` | 在保证相关性的前提下，减少不必要的检索计算量。 |
| `SIMILARITY_THRESHOLD` | `0.75` | 过滤低相关度结果，提升咨询转化准确性，可根据实际效果微调。 |
| `VECTOR_DB_CONNECTION_TIMEOUT_SECONDS` | `30 秒` | 应对网络波动或数据库瞬时负载，防止连接超时导致数据同步中断。 |

## 容易做错的三处

*   数据同步任务长时间无响应或报错 `Connection refused`，原因可能是数据源API密钥过期或网络防火墙未开放对应端口。
*   导入的线索数据在知识库中检索不到，或检索结果不准确，现象是咨询回复中缺少关键信息，原因是数据预处理阶段未能正确解析特定字段或专业术语。
*   系统在特定时间段内出现性能瓶颈，表现为线索同步延迟，原因可能是并发处理能力配置不足，未能有效应对高峰期的线索涌入。

## 怎么确认配好了

*   通过系统日志检查数据同步任务是否按预期频率成功执行，并确认无 `ERROR` 级别日志。
*   随机抽取多条已同步的线索数据，在知识库中进行模拟咨询，验证相关信息能否被准确检索和引用。
*   监控系统资源使用情况，特别是在数据同步高峰期，确保CPU、内存和网络I/O均在健康范围内。
