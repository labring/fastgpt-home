# 单克隆抗体药物警戒的HTTP 接口与外部系统

## 这个品类的数据长什么样

单克隆抗体药物的不良反应数据通常来源于临床试验报告、真实世界研究、上市后监测系统（如 FDA Adverse Event Reporting System, FAERS）及文献综述。这些数据更新频率不一，临床试验数据相对稳定，上市后监测数据则持续流入。文档结构多样，包括结构化报告（如 CIOMS I 表格、MedWatch 表格）、半结构化文本（如医学记录、病例报告）和非结构化描述（如医生笔记）。字段方面，除了常规的患者信息、药品信息、事件描述、预后等，还特别关注抗体类型（如 IgG1、IgG4）、靶点（如 PD-1、TNF-α）、给药途径、伴随用药、以及免疫原性相关指标（如抗药抗体检测结果）。单位上，剂量常以 `mg/kg` 或 `mg` 计，时间单位包括 `天`、`周`、`月`。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

单克隆抗体药物不良反应数据的多样性和复杂性，对 FastGPT 在 HTTP 接口与外部系统集成时提出了具体要求。半结构化和非结构化文本的存在，意味着系统需要具备强大的文本解析能力，以准确提取关键字段信息。抗体类型和靶点等特有字段的识别，要求 HTTP 请求参数能够灵活映射到外部系统的特定查询字段。数据更新的持续性，特别是上市后监测数据，决定了接口调用策略需要支持周期性或事件驱动的同步机制。同时，由于数据源可能分布在多个不同平台，接口需要处理不同的认证方式（如 `API Key`、`OAuth 2.0`）和数据格式（如 `JSON`、`XML`）。剂量和时间单位的标准化处理，也是确保数据一致性和准确性的关键。

## 配置怎么定

| 配置项                   | 建议取法                                           | 这样取的依据                                                 |
| :----------------------- | :------------------------------------------------- | :----------------------------------------------------------- |
| `HTTP Method`            | `POST` 或 `GET`                                    | 依据外部系统 API 文档要求，`POST` 用于提交数据，`GET` 用于查询。 |
| `Content-Type`           | `application/json`                                 | 外部系统普遍采用 `JSON` 格式进行数据交换，便于解析。       |
| `Timeout`                | `600 秒`                                           | 处理复杂查询或大量数据时，外部系统响应时间可能较长。         |
| `Headers.Authorization`  | `Bearer <YOUR_API_KEY>`                            | 多数外部系统采用 `Bearer Token` 或 `API Key` 进行认证。      |
| `Request Body`           | 按外部系统 API 文档构建 `JSON` 对象              | 确保请求体中的字段名和数据类型与外部系统定义一致，例如包含 `antibody_type`、`target_molecule` 等字段。 |
| `Response Field Mapping` | 映射外部系统返回的 `adverse_event_description` 到 `event_text` | 将外部系统返回的关键信息映射到 FastGPT 内部字段，便于后续处理。 |

## 容易做错的三处

*   HTTP 请求返回 `400 Bad Request` 错误，原因在于请求体中的 `antibody_type` 字段值不符合外部系统预期的枚举列表。
*   工作流中 HTTP API 节点返回的文本被截断，导致后续分段发送不完整，原因在于 `max_response_length` 参数设置过小，未能完整接收外部系统返回的长篇不良反应描述。
*   外部系统接口调用频繁导致 `429 Too Many Requests` 状态码，原因在于未配置适当的 `速率限制` 或 `重试间隔`，超出外部系统允许的调用频率。

## 怎么确认配好了

*   在 FastGPT 的 HTTP API 配置界面，使用实际的单克隆抗体不良反应查询参数进行测试，检查返回结果的 `status code` 是否为 `200 OK`。
*   核对 HTTP API 返回的 `JSON` 数据中，关键字段如 `event_text`、`antibody_type`、`target_molecule` 是否包含预期内容，并检查其数据格式是否正确。
*   在 FastGPT 工作流中，将 HTTP API 节点的输出连接到文本解析或知识库存储节点，检查解析后的数据是否能准确提取出不良反应的详细信息和相关生物学特征。
