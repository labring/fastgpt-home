# 合理用药药物警戒的多轮对话与提示词

## 这个品类的数据长什么样

合理用药在药物警戒领域的数据主要来源于药品说明书、临床试验报告、真实世界研究、不良反应报告系统、药典以及专业医学文献。这些数据更新频率不一，药品说明书和药典通常随药品上市后监管要求定期修订，不良反应报告系统则实时接收并处理数据。文档结构上，数据通常以非结构化文本（如不良反应报告的叙述性文字）和半结构化表格（如药品用法用量、禁忌症、注意事项）形式存在。字段方面，常见包括药品通用名、商品名、适应症、用法用量、不良反应名称、发生率、严重程度、处理措施、患者基本信息等。单位涉及剂量（毫克、毫升）、频率（每日次）、疗程（天、周）等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束

合理用药数据的多样性与更新频率对多轮对话的准确性和时效性构成挑战。非结构化文本的理解需要强大的语义分析能力，以准确提取不良反应事件的关键信息。半结构化数据的解析则需确保字段与单位的正确映射，避免误解剂量或用法。高频更新的药品说明书和不良反应报告要求知识库能快速同步，以提供最新的用药建议，避免基于过时信息给出错误指导。多轮对话中，用户可能以口语化或非标准术语描述症状或药品，这要求提示词设计需覆盖多种表达方式，并能引导用户提供必要信息。此外，医学术语的专业性与严谨性，使得对话系统在生成回复时必须保证专业性和准确性，避免模糊或误导性表述。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `maxContext` | `6` 轮 | 兼顾上下文连贯性与系统资源消耗，避免过长的对话历史导致模型理解偏差。 |
| `分段长度` | `500` 字符 | 药品说明书和不良反应报告内容通常较长，此长度能有效捕获完整语义信息。 |
| `召回条数` | `10` 条 | 确保从知识库中检索到足够多的相关信息，覆盖不同维度的用药建议或不良反应细节。 |
| `相似度阈值` | 按实测标定 | 需根据实际数据特点和召回效果，通过测试集调整，平衡查全率与查准率。 |
| `重排返回条数` | `3` 条 | 优先展示最相关且简洁的用药指导或不良反应信息，提高用户获取有效信息的效率。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300` 秒 | 处理药品说明书等大型文档时，预留充足时间进行内容解析和结构化处理。 |

## 容易做错的三处

*   对话中出现图片链接无法加载，提示“无法访问该资源”。原因是图片URL未进行白名单配置或网络代理设置不当，导致FastGPT服务无法直接访问外部图片资源。
*   上传大型CSV或XLSX格式的不良反应数据表后，AI对话功能无法正常引用数据。原因是文件解析超时或文件内容结构复杂，导致数据未能成功向量化或索引。
*   在多轮对话中，模型无法准确识别用户提到的药品通用名，而是混淆为商品名或同类药物。原因是知识库中缺乏药品通用名与商品名的映射关系，或提示词中未强调通用名的识别优先级。

## 怎么确认配好了

*   进行多轮对话测试，输入特定药品名称和症状，核对系统返回的用药建议与药品说明书中的信息一致性，特别是用法用量、禁忌症部分。
*   上传包含多种格式的药物警戒文档（如PDF版药品说明书、CSV版不良反应报告），检查文件是否能被正常解析，并在对话中能被有效引用，验证 `PARSE_FILE_TIMEOUT_SECONDS` 设置是否合理。
*   模拟用户描述不良反应事件，观察系统是否能准确提取不良反应名称、严重程度等关键字段，并结合知识库给出相应的处理建议，评估 `相似度阈值` 和 `召回条数` 的效果。
