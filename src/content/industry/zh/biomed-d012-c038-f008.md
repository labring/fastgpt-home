# 合理用药药物警戒的工具调用与插件

## 这个品类的数据长什么样

合理用药数据主要来源于国家药品监督管理局（NMPA）、各级医疗机构上报的不良反应事件（ADR）数据库、临床试验报告、药品说明书以及药理学研究文献。数据更新频率较高，NMPA 季度或年度发布药品不良反应监测报告，医疗机构的 ADM 系统则实时或每日更新。文档结构以结构化数据为主，如药品批次号、药品通用名、剂型、剂量、给药途径、患者基本信息、不良反应描述、发生时间、严重程度等。非结构化数据包括病例报告详情、医生诊疗记录。字段名称标准化程度高，例如 `药品通用名称`、`不良反应代码`（如 MedDRA 编码），单位统一，如 `mg`、`ml`、`次/日`。

## 这些特征在「工具调用与插件」这一环带来什么约束

合理用药数据的实时性和复杂性，对工具调用与插件的响应速度和数据处理能力提出了较高要求。由于涉及大量结构化与半结构化数据，插件需要具备高效的数据解析和整合能力，以处理药品说明书、临床指南等多种格式的文档。药品不良反应事件的关联性分析和潜在风险评估，需要插件能够调用外部药理学知识库或统计分析工具。数据量大、更新频繁的特点，决定了工具调用需要支持异步处理和长时任务，避免因数据查询或复杂计算导致的超时。此外，对敏感患者信息的处理要求插件在数据传输和存储过程中符合严格的隐私保护与合规性标准。

## 配置怎么定

| 配置项                       | 建议取法                                 | 这样取的依据                                                                         |
| :--------------------------- | :--------------------------------------- | :----------------------------------------------------------------------------------- |
| `maxResponseTokens`          | `2048`                                   | 确保能容纳详细的药品信息、不良反应描述及用药建议，避免截断关键内容。                 |
| `timeoutSeconds`             | `180` 秒                                 | 考虑到外部知识库调用和复杂药理学分析可能耗时较长，增加容错时间。                     |
| `apiEndpoint`                | `https://api.nmpa.gov.cn/drug_info`      | 直接调用权威数据源，保证数据准确性与时效性。                                         |
| `functionCallMaxArgs`        | `10`                                     | 药物警戒任务常涉及多药品、多症状、多患者特征的组合查询。                             |
| `concurrentCallsLimit`       | 按实测标定                               | 避免因高并发导致外部 API 速率限制或服务过载。                                        |
| `retryAttempts`              | `3` 次                                   | 外部 API 调用可能因网络波动或服务暂时性不可用而失败，增加重试机制提高稳定性。       |

## 容易做错的三处

*   调用外部药品知识库时，API 返回 `HTTP 504 Gateway Timeout`。原因可能是外部知识库响应时间过长，或插件默认超时时间设置过短，导致请求在未获得完整响应前被中断。
*   在处理药品不良反应事件报告时，工具调用返回结果中关键字段（如 `不良反应严重程度`）为空。原因可能是数据源字段命名不一致，或插件在解析非结构化报告时未正确提取对应信息。
*   插件在进行药物相互作用分析时，结果与临床实际不符。原因可能是调用的药理学知识库版本过旧，未包含最新研究成果，或查询参数未能准确映射到知识库的查询接口。

## 怎么确认配好了

*   构造包含多种药品、患者特征和症状的复杂查询，检查插件返回的用药建议是否全面、准确，且无关键信息遗漏。
*   模拟外部知识库接口的慢响应或临时故障，验证工具调用是否能按预期触发重试机制，并在超时后返回明确的错误提示。
*   比对插件对药品不良反应事件报告的分析结果与人工审核结论，尤其关注关键字段的提取准确性与风险评估的一致性。
