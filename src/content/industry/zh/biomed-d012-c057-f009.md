# 心血管介入药物警戒的引用来源与溯源

## 这个品类的数据长什么样
心血管介入领域的药物警戒数据主要来源于医疗器械不良事件报告（MDR）、临床试验报告、真实世界研究（RWE）数据以及学术期刊和会议文献。MDR 数据通常由监管机构（如 FDA 的 MAUDE 数据库）收集，更新频率不一，可能为月度或季度批次更新。临床试验报告和 RWE 数据则根据研究周期和发布策略定期发布。文档结构上，MDR 报告常包含器械信息、事件描述、患者信息和结果等结构化字段，但也存在大量自由文本描述。学术文献则以 PDF 格式为主，包含摘要、引言、方法、结果和讨论等标准章节。字段方面，特有单位如毫米（mm）、千克（kg）、毫升（mL）等常用于描述器械规格和患者生理参数，同时涉及 ICD-10 编码等标准化医学术语。

## 这些特征在「引用来源与溯源」这一环带来什么约束
心血管介入数据的多样性对引用来源与溯源带来了特定约束。MDR 报告中的自由文本描述和半结构化数据，要求 RAG 系统在切分和嵌入时能有效处理非标准化的事件描述，确保相关性召回。其不规律的更新频率意味着知识库需要支持增量更新和版本管理，以反映最新的不良事件信息。PDF 格式的学术文献，特别是图表和复杂排版，对文档解析能力提出了更高要求，可能导致文本提取不完整或格式丢失，影响引用准确性。此外，由于涉及精确的器械参数和生理指标，系统必须能够识别并正确处理带有单位的数值型信息，避免在引用时出现歧义或错误。对 ICD-10 等医学编码的正确识别和关联，是确保溯源到原始医学术语的关键。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `500–800 字符` | 兼顾 MDR 事件描述的完整性和学术文献段落的语义连贯性，避免关键信息被截断。 |
| `召回条数` | `前 8 条` | 考虑到心血管介入不良事件报告的复杂性，适当增加召回条数以覆盖更多潜在相关信息。 |
| `相似度阈值` | `0.75` | 确保召回的引用内容与查询高度相关，减少误报，尤其在处理具体器械型号和症状时。 |
| `重排返回条数` | `前 3 条` | 在保证相关性的前提下，精简最终呈现的引用，提升用户阅读效率。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `180 秒` | 应对大型 PDF 文档解析，特别是包含多页图表和复杂布局的临床试验报告。 |
| `MAX_PREVIEW_SIZE` | `5 MB` | 允许用户预览较大的原始报告文件，便于核对引用来源的上下文。 |

## 容易做错的三处
*   问答结果中引用来源的 URL 无法访问或指向错误。这通常是由于知识库原文链接在部署后未能正确配置代理或 CDN 路径，导致前端无法正确解析后端提供的文件下载地址。
*   引用内容缺失关键数值或单位，导致信息不完整。原因在于文档解析阶段未能有效识别和提取自由文本中的数值-单位组合，或者在分段时将数值与单位分离。
*   RAG 问答结果中未返回任何引用来源，即使知识库中存在相关内容。这可能源于模型`maxContext`参数设置过小，导致检索到的引用内容无法全部送入大模型上下文，或者相似度阈值过高，导致相关文档被过滤。

## 怎么确认配好了
*   针对典型的心血管介入不良事件查询，检查问答结果是否返回了至少 3 条有效的引用来源，并点击验证所有引用链接是否可达。
*   随机抽取 5 份包含数值和单位的原始文档（如 MDR 报告），通过提问验证系统能否准确引用并呈现这些数值和单位，与原文对比确认无误。
*   上传一份包含复杂表格和图表的 PDF 文献，观察其解析耗时是否在 `PARSE_FILE_TIMEOUT_SECONDS` 配置范围内，并检查解析后的文本内容是否完整保留了关键信息。
*   在知识库管理界面，随机选择几个心血管介入相关的文档，验证其`分段长度`是否符合预期，以及分段内容是否保持了语义完整性。
