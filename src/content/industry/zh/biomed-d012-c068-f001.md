# 智能导诊药物警戒的HTTP 接口与外部系统

## 这个品类的数据长什么样

智能导诊在药物警戒领域的数据主要来源于药品说明书、医学文献、不良事件报告系统（如 FAERS、EudraVigilance）以及临床指南。这些数据更新频率不一，药品说明书通常随审批更新，不良事件报告系统数据则持续流入。文档结构以半结构化和非结构化为主，例如药品说明书包含适应症、禁忌症、用法用量、不良反应等章节，医学文献则包含摘要、方法、结果、讨论等。字段方面，常见的有药品通用名、商品名、活性成分、不良反应名称（MedDRA 编码）、发生率、严重程度、报告时间、患者特征等。单位则涉及剂量（mg、g）、频率（次/日、周）、时间（天、月、年）等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

药物警戒智能导诊的数据特征对 HTTP 接口与外部系统集成提出了特定要求。半结构化和非结构化数据源意味着需要强大的文本解析能力，以及对不同数据格式的适配。例如，从外部不良事件报告系统获取数据时，可能需要处理 JSON、XML 或 CSV 等多种格式的接口响应。数据更新的实时性要求，尤其是对于新发布的不良事件报告，决定了接口调用频率和数据同步策略。例如，对于高频更新的数据源，可能需要配置定时任务，以小时级或分钟级频率调用接口。此外，涉及医学术语和编码（如 MedDRA）的字段，要求接口能够准确传输这些标准化编码，并在必要时进行映射或转换，以确保内部系统对这些信息的正确理解和处理。

## 配置怎么定

| 配置项                   | 建议取法                               | 这样取的依据                                                 |
| :----------------------- | :------------------------------------- | :----------------------------------------------------------- |
| `HTTP_REQUEST_TIMEOUT`   | `60 秒`                                | 外部系统响应可能因数据量大或网络延迟而较慢，预留足够时间防止请求中断。 |
| `MAX_BODY_SIZE_MB`       | `50 MB`                                | 不良事件报告或药品说明书可能包含大量文本，需要支持较大请求体。 |
| `API_KEY_HEADER_NAME`    | `X-API-KEY`                            | 外部系统通常通过自定义 HTTP 头传递 API 密钥进行认证。      |
| `RETRY_TIMES`            | `3`                                    | 外部接口可能因瞬时网络波动或服务负载而失败，适当重试可提高稳定性。 |
| `DATA_PARSE_STRATEGY`    | `JSONPath 表达式`                      | 针对不同外部系统返回的 JSON 结构，通过表达式灵活提取所需字段。 |
| `MEDDRA_MAPPING_ENDPOINT` | 按实测标定                             | 需要与内部 MedDRA 编码服务对接，确保术语标准化。            |

## 容易做错的三处

*   外部接口返回 `HTTP 401 Unauthorized` 错误，原因通常是 `API_KEY_HEADER_NAME` 未正确配置或 `API_KEY` 值不匹配。
*   调用外部系统后返回数据字段为空，这是由于 `DATA_PARSE_STRATEGY` 中定义的 JSONPath 表达式与实际返回的 JSON 结构不符。
*   请求外部系统时出现 `Connection timed out` 错误，这表示 `HTTP_REQUEST_TIMEOUT` 设置过短，无法等待外部服务完成响应。

## 怎么确认配好了

*   通过模拟请求工具（如 `curl`）调用配置的 HTTP 接口，检查是否能正常获取到外部系统返回的原始数据。
*   在 FastGPT 内部配置一个测试 Agent，调用该 HTTP 接口，并验证返回的数据结构和关键字段（如药品名、不良反应描述）是否符合预期。
*   检查系统日志，确认 HTTP 请求的发送、接收以及数据解析过程中没有出现异常报错或警告信息。
*   针对特定不良反应编码（如 MedDRA `10000001`），执行一次端到端的查询，确认智能导诊结果中相关信息准确。
