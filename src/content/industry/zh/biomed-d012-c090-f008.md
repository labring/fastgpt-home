# 药物经济学药物警戒的工具调用与插件

## 这个品类的数据长什么样

药物经济学数据主要关注药品的成本效益、成本效用和成本效果分析。数据来源包括临床试验结果、真实世界证据（RWE）、医保报销数据库、医疗服务定价目录、患者调查问卷等。这些数据通常以结构化表格（如 Excel、CSV、数据库记录）和非结构化文本（如临床报告、文献综述）的形式存在。更新频率不一，临床试验数据随研究进展发布，而医保目录和定价信息则可能按年度或半年度调整。文档结构多样，例如成本数据可能包含药品采购价、管理费、不良事件处理费等字段，效用数据则可能涉及质量调整生命年（QALY）或残疾调整生命年（DALY）等指标，字段名称和单位需要严格区分。

## 这些特征在「工具调用与插件」这一环带来什么约束

药物经济学数据的多样性和复杂性，对工具调用与插件提出了特定要求。首先，数据来源广泛且格式不一，需要工具具备强大的数据解析和预处理能力，以统一数据结构。例如，从不同医保数据库获取的报销数据，其药品编码、费用单位可能存在差异，需要插件进行标准化转换。其次，涉及 QALY、DALY 等专业指标的计算，要求工具能调用特定的统计分析库或外部计算服务。再者，数据的更新频率差异，意味着工具调用需要支持定时任务或增量更新机制，以确保分析结果的实效性。最后，药物警戒中对不良反应事件的识别和关联，可能需要调用自然语言处理（NLP）工具从非结构化文本中提取关键信息，并与结构化经济学数据进行整合分析。

## 配置怎么定

| 配置项                       | 建议取法                               | 这样取的依据                                                                                             |
| :--------------------------- | :------------------------------------- | :------------------------------------------------------------------------------------------------------- |
| `maxContext`                 | `4096`                                 | 适应药物经济学报告中包含的复杂背景信息和详细计算过程，确保模型理解完整上下文。                           |
| `tool_timeout_seconds`       | `120 秒`                               | 考虑到外部统计计算或数据库查询可能耗时，避免因超时中断关键分析步骤。                                     |
| `plugin_max_retries`         | `3 次`                                 | 应对外部服务偶尔的网络波动或临时故障，提高工具调用的鲁棒性。                                             |
| `function_call_strict_mode`  | `true`                                 | 确保模型严格按照定义的工具函数签名进行调用，避免生成不符合预期格式的参数，尤其在财务或统计计算中。     |
| `prompt_template`            | 包含 `{{query}}` 和 `{{tools_schema}}` | 明确指示模型在理解用户查询后，参照提供的工具函数定义，选择合适的工具进行药物经济学分析或数据提取。     |
| `data_extraction_model_version` | `Qwen2-7B-Instruct-v0.1`               | 选择在结构化信息提取方面表现良好的模型版本，适用于从临床报告中提取不良反应事件或成本数据。             |

## 容易做错的三处

*   工具调用返回 `HTTP 400` 或 `500` 错误码，原因在于传递给外部 API 的参数格式不正确或缺少必要字段，例如药品编码未按API要求进行统一转换。
*   模型未能自主选择合适的药物经济学分析工具，原因可能是工具函数描述不够清晰，或者 `prompt_template` 未能有效引导模型理解何时调用特定分析功能。
*   从非结构化文本中提取的不良反应事件信息不完整或出现偏差，原因可能是 `data_extraction_model_version` 在处理特定医学术语或缩写时效果不佳，需要针对性微调或使用更专业的模型。

## 怎么确认配好了

*   提交包含典型药物经济学分析需求的查询，观察模型是否正确识别并调用相关的外部计算工具，例如成本效益分析模块。
*   测试不同格式的药物警戒数据输入，验证工具链能否准确解析并提取出不良反应事件、药品名称、剂量等关键信息，并将其传递给后续处理环节。
*   检查工具调用日志，确认 `tool_timeout_seconds` 设置是否足够，没有出现因外部服务响应慢导致的调用失败记录。
*   模拟外部工具服务短暂不可用场景，验证 `plugin_max_retries` 配置是否能使系统进行合理的重试，并在最终失败时给出明确的错误提示。
