# 药物经济学药物警戒的引用来源与溯源

## 这个品类的数据长什么样
药物经济学在药物警戒领域的数据主要围绕药物上市后的真实世界证据。这些数据来源于多中心临床研究、医保支付数据库、电子病历系统（EHR）、患者报告结局（PRO）数据以及各类注册登记系统。数据更新频率通常为季度或年度，取决于数据源的更新周期和数据清洗的复杂性。文档结构多样，包括研究报告（PDF、Word）、数据库导出文件（CSV、JSON）、学术论文（PDF）和结构化数据表（如药品价格、治疗方案成本、不良事件发生率等）。字段方面，除了药品通用名、适应症、不良反应事件等常规信息外，还包含药物成本（`drug_cost_unit`）、治疗总费用（`total_therapy_cost`）、生命质量调整寿命年（QALYs）、增量成本效益比（ICER）等药物经济学特有指标。单位通常涉及货币（例如 `USD`、`CNY`）、时间和无量纲比率。

## 这些特征在「引用来源与溯源」这一环带来什么约束
药物经济学数据的多样性及其跨模态特性，对引用来源的统一管理提出了挑战。PDF 格式的研究报告和学术论文需要进行高效的文本提取和结构化处理，以确保关键经济学指标能够被准确识别和索引。数据库导出文件中的结构化数据，要求在摄入时能够保留字段间的关联性，例如药品成本与特定治疗方案的对应关系。较低的数据更新频率意味着知识库在更新时，应优先考虑能够反映最新政策或临床指南变化的数据源。对于包含大量图表和表格的文档，需要支持图像识别或表格解析，以便从非文本信息中提取药物经济学参数。同时，引用溯源需要能精确指向原始文档中的具体段落或数据表，尤其是在涉及经济学模型参数和计算结果时，以支撑结论的可靠性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `分段长度` | `500–800 字符` | 适应药物经济学报告中包含较长论述段落的特点，确保上下文完整性。 |
| `分段重叠度` | `100–150 字符` | 保证跨段落的经济学指标或论证链条能够被有效关联，避免信息割裂。 |
| `召回条数` | `8–12 条` | 考虑到药物经济学分析的复杂性，需要更多相关证据支持结论的生成。 |
| `相似度阈值` | `0.75–0.82` | 兼顾准确召回与避免噪声，尤其是对于包含大量数字和术语的经济学文献。 |
| `重排返回条数` | `5 条` | 在初次召回基础上，进一步精炼与药物经济学问题最相关的证据链。 |
| `PARSE_TABLE_ENABLED` | `true` | 确保能够从研究报告中解析并利用包含成本、效益数据的表格。 |

## 容易做错的三处
1. 问答结果中未提及本地知识库内容，但引用列表却包含相关文档。原因可能是 `相似度阈值` 设置过高，导致模型在生成回答时未能有效利用召回到的低相似度但相关的知识片段。
2. 引用来源指向的原始文档为空或无法打开。这通常是由于知识库摄入时文件路径存储错误或原始文件已被移动/删除。
3. 针对药物经济学指标的提问，回答中仅给出通用医学信息，缺乏具体的成本效益数据或模型参数。原因在于知识库在处理非结构化文档时，未能有效识别和提取表格或图表中的关键经济学数据，导致索引缺失。

## 怎么确认配好了
1. 针对包含特定药物经济学指标（如 `ICER` 值、`QALY` 增益）的问题，检查回答是否准确引用了来自知识库文档的对应数值，并能追溯到原始文档中的具体位置。
2. 上传一份包含复杂表格的药物经济学研究报告，提问表格中的关键数据，验证系统是否能正确解析并引用表格内容。
3. 模拟一个关于药物成本效益的场景，提问系统如何评估某种新药的经济性，并核对回答中引用的证据是否全面覆盖了成本、效果和比较分析等维度，且来源可查。
