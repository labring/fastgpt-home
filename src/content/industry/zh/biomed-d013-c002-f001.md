# CDMO质量文档的HTTP 接口与外部系统

## 这个品类的数据长什么样

CDMO（合同研发生产组织）的质量文档涉及药品从研发到生产的全生命周期，数据来源广泛，包括原始实验记录、批生产记录、检验报告、偏差处理、变更控制、供应商资质文件等。这些文档通常以 PDF、Word、Excel 等格式存储，部分数据可能存在于LIMS（实验室信息管理系统）、MES（制造执行系统）等专业系统中。文档更新频率高，尤其在研发和临床阶段，方案、报告、批次记录会持续产生和修订。文档结构复杂，包含大量规范性字段（如批号、产品名称、规格、生产日期、有效期、检验结果、判定标准）和非结构化描述（如偏差描述、调查结论）。单位涉及质量（mg, g, kg）、体积（mL, L）、浓度（% w/v, ppm）、时间（min, h, day）等，且对精度要求极高。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

CDMO质量文档的高更新频率和复杂结构对HTTP接口设计提出挑战。接口需要支持频繁的文档上传、更新和版本管理，并能处理多种文件格式。来自LIMS或MES等外部系统的结构化数据，要求接口能精确映射字段，并支持批量导入。文档中包含的专业术语和严格的合规性要求，意味着在数据抽取和知识图谱构建时，需要有针对性的处理策略，避免语义偏差。对时间精度和数值单位的严格性，要求接口在数据传输和解析环节能保持一致性，防止因格式转换导致的错误。此外，由于数据敏感性，接口的安全认证和访问控制是核心约束。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 考虑单个批生产记录或复杂报告可能包含大量图表和附件，确保大型文件上传顺畅。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 应对包含复杂表格或扫描图像的PDF文档，解析耗时较长的情况。 |
| `maxContext` | `8000 字符` | 确保一次召回能覆盖质量偏差调查、变更控制等长篇幅文档的关键上下文。 |
| `相似度阈值` | `0.75–0.85` | 兼顾准确召回与避免无关文档干扰，防止因专业术语相似导致的误召回。 |
| `HTTP_REQUEST_TIMEOUT` | `120 秒` | 外部LIMS或MES系统接口响应可能存在延迟，预留足够时间完成数据同步。 |
| `EXTERNAL_API_RETRY_COUNT` | `3 次` | 应对外部系统偶尔的网络波动或瞬时服务不可用，提高数据同步的健壮性。 |

## 容易做错的三处

*   调用外部系统API时返回`HTTP 401 Unauthorized`或`HTTP 403 Forbidden`：通常是由于`API_KEY`或`ACCESS_TOKEN`配置错误、过期，或者接口权限不足。
*   文档上传后，检索结果中重要字段为空或数值单位不匹配：文件解析器未正确识别文档中的特定字段名或单位格式，需要调整解析规则或自定义提取器。
*   从外部系统同步数据后，首次查询响应时间过长，或混合检索性能低下：向量索引重建或更新策略不合理，未能及时反映最新数据，或者混合检索的查询优化不足。

## 怎么确认配好了

*   通过FastGPT管理界面上传一份典型的批生产记录PDF，查看其解析结果是否完整，关键字段如批号、生产日期、检验结果等是否被正确提取。
*   配置与LIMS系统的HTTP接口，手动触发一次数据同步，核对FastGPT中导入的检验报告数据与LIMS系统中的原始数据是否一致，特别是数值和单位。
*   使用包含特定质量偏差描述的查询语句进行检索，验证系统能否准确召回相关偏差报告，并评估召回结果的完整性和相关性。
*   模拟外部系统接口的短暂故障（例如，通过临时关闭外部服务或配置代理延迟），观察FastGPT的HTTP接口重试机制是否按预期工作，并最终成功同步数据。
