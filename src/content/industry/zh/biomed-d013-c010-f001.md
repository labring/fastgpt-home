# IVD 诊断试剂质量文档的HTTP 接口与外部系统

## 这个品类的数据长什么样

IVD 诊断试剂的质量文档主要包括注册证、说明书、批检报告、稳定性研究报告、原材料检验报告等。这些文档通常以 PDF、Word、Excel 等格式存储，部分扫描件为图片格式。数据来源多样，包括研发部门、生产部门、质量控制部门以及法规注册部门。更新节奏受产品生命周期和法规要求影响，例如批检报告随生产批次实时生成，说明书和注册证则可能在法规更新或产品变更时进行修订。文档结构严谨，包含大量结构化数据（如批号、有效期、检测结果、判定标准）和非结构化描述（如方法学原理、注意事项）。字段与单位具有高度专业性，常涉及生物学指标、化学浓度、光学密度等，单位如 `IU/mL`、`ng/dL`、`OD值` 等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

IVD 诊断试剂质量文档的数据多样性要求 HTTP 接口支持多格式文件上传和下载，特别是对图片格式文档的 OCR 识别能力。实时性要求使得接口设计需考虑高并发下批检报告的快速录入和解析。文档的严谨结构和专业字段，意味着在数据提取时需要精确匹配特定模式和单位，例如从文本中识别 `批号` 字段和对应的 `YYYYMMDD` 格式值。非结构化描述的分析则依赖于更复杂的自然语言处理能力。此外，法规合规性要求所有数据操作均需记录日志，确保可追溯性。对于外部系统，例如 LIMS（实验室信息管理系统）或 ERP（企业资源计划系统）的对接，需要定义清晰的数据交换协议和身份验证机制，以保证数据完整性和安全性。

## 配置怎么定

| 配置项                       | 建议取法                                 | 这样取的依据                                                 |
| :--------------------------- | :--------------------------------------- | :----------------------------------------------------------- |
| `UPLOAD_FILE_MAX_SIZE`       | `100 MB`                                 | 应对包含大量图片或扫描件的 PDF 文档，确保能完整上传。      |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒`                                 | 处理复杂结构或大文件时的解析时间，避免因超时导致解析失败。 |
| `maxContext`                 | `3000 Tokens`                            | 确保能一次性处理较长的段落，捕获完整的专业术语和上下文。   |
| `similarity_threshold`       | `0.75`                                   | 提高召回结果的精确性，减少无关信息的干扰，特别是法规条款。 |
| `extract_fields`             | `批号`, `生产日期`, `有效期`, `检测项目`, `检测结果` | 针对批检报告等核心文档，确保关键结构化数据的提取完整。     |
| `auth_method`                | `OAuth2`                                 | 与 LIMS/ERP 等外部系统集成时，保障接口调用的安全性和权限控制。 |

## 容易做错的三处

*   现象：上传的批检报告图片无法被正确解析出关键字段，或者提取出的数值带有错误单位。原因：OCR 引擎对特定字体、表格结构或专业单位符号的识别能力不足，或未配置针对 IVD 行业术语的词典。
*   现象：HTTP 请求发送后长时间无响应，最终返回 `504 Gateway Timeout` 错误。原因：外部系统接口处理复杂查询或大文件解析时，后端处理时间超过了网关或代理服务器的默认超时设置。
*   现象： FastGPT 平台在调用外部 LIMS 系统接口时，提示 `401 Unauthorized` 错误。原因：HTTP 接口的认证令牌过期，或 `Authorization` 请求头中携带的凭证格式不符合 LIMS 系统的要求。

## 怎么确认配好了

*   选择一份包含复杂表格和专业术语的 IVD 诊断试剂说明书 PDF 文件，上传至 FastGPT，检查关键字段（如产品名称、适用范围、检测原理）是否被准确提取，并核对文本内容是否完整无误。
*   模拟一次批检报告的上传与解析流程，核对解析出的 `批号`、`生产日期`、`检测结果` 等字段，确认其数据类型和单位是否与原始文档一致，特别是针对 `OD值` 或 `IU/mL` 这类特殊单位。
*   配置 FastGPT 与一个模拟的 LIMS 系统进行 HTTP 接口对接，尝试进行数据查询或上传操作，观察接口返回的状态码和数据结构，确保数据能正确传输并被外部系统接收处理，同时检查日志记录是否完整。
