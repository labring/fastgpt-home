# mRNA 疫苗质量文档的部署与升级

## 这个品类的数据长什么样

mRNA 疫苗的质量文档核心数据来自研发、生产、质检和临床试验阶段，数据更新频率与疫苗生命周期各阶段紧密相关。研发阶段文档更新频繁，生产质检阶段则有固定的批次报告和周期性审计文件。文档结构通常包含详细的实验记录、批生产记录、检验报告、稳定性研究数据和偏差处理报告。字段方面，涉及诸如核酸序列信息、脂质纳米粒（LNP）组分比例、纯度、效价、内毒素含量等特异性指标，单位常包含 `μg/mL`、`%`、`IU`（国际单位）等。文档格式多为 PDF、Word、Excel，部分关键数据可能以 LIMS（实验室信息管理系统）导出的结构化数据存在。

## 这些特征在「部署与升级」这一环带来什么约束

mRNA 疫苗质量文档的特殊性对部署与升级环节提出了具体要求。首先，文档中包含的核酸序列、LNP 配方等敏感信息，要求部署环境具备严格的数据隔离和访问控制，尤其是在多租户或混合云场景下。其次，大量的 PDF 和扫描件需要高效的 OCR 处理能力，以确保文本内容可被模型准确解析。字段名和单位的高度专业化，要求模型在向量化和召回时能准确理解其语义。此外，不同批次文档的更新，可能涉及同一指标在不同时间点的变化，这需要系统具备版本管理能力，并能处理增量更新对知识库一致性的影响。对效价等关键指标的查询，要求系统能精确匹配和提取数值。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 确保能够上传包含大量图片和图表的批生产记录 PDF 文件。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 处理大型 PDF 文件，特别是扫描件 OCR 耗时较长的情况。 |
| `maxContext` | `8192 token` | 考虑到 mRNA 疫苗实验记录和报告中常有较长的描述和数据表格。 |
| `分段长度` | `800 字符` | 保证单个文档段落能包含足够上下文，应对专业术语和关联数据。 |
| `召回条数` | `前 8 条` | 提高复杂查询下，如跨批次数据对比，相关信息的召回率。 |
| `相似度阈值` | `0.75` | 平衡召回精度与召回率，减少不相关结果对专业查询的干扰。 |

## 容易做错的三处

*   新部署系统无法正确解析旧批次扫描件中的关键字段，原因是 OCR 引擎未针对低质量扫描件进行优化，导致文字识别率低。
*   升级后模型回答中出现关键指标数值错误，原因为新版本模型对特定单位的识别或转换逻辑出现偏差，未能正确处理 `IU` 或 `ng/mL` 等单位。
*   知识库初始化后，查询敏感信息如核酸序列时返回空值，原因是部署时未正确配置数据权限，导致部分敏感数据未被索引或授权访问。

## 怎么确认配好了

*   上传一份包含复杂表格和专业术语的 mRNA 疫苗批生产记录 PDF，并验证其内容是否被系统完整且准确地分段和索引。
*   针对多个批次的质量检验报告，查询同一关键指标（例如效价或纯度）在不同批次中的数值，核对系统返回结果与原始文档是否一致。
*   模拟用户提问，查询特定 mRNA 疫苗的核酸序列或 LNP 组分比例，确认系统能否召回并正确呈现相关敏感信息，并检查访问权限是否生效。
