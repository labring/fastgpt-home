# 分子诊断质量文档的HTTP 接口与外部系统

## 这个品类的数据长什么样

分子诊断领域的质量文档主要包括试剂盒批次放行记录、仪器校准报告、操作规程（SOP）、风险评估报告、偏差处理记录等。这些文档通常以PDF、Word或结构化文本形式存在，部分数据可能存储在LIMS（实验室信息管理系统）或ELN（电子实验记录本）中。数据来源多样，包括实验室内部生成、供应商提供以及监管机构发布。更新频率差异显著，SOP可能每年修订，而批次放行记录则随批次实时生成。文档结构化程度不一，SOP通常具备固定章节，而偏差记录则包含大量自由文本描述。字段方面，常见的有批号、有效期、仪器序列号、检测项目、质控结果、关键参数如`Ct值`、`熔解曲线温度`等，单位包括`ng/μL`、`拷贝数/mL`、`℃`、`kPa`等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

分子诊断质量文档的多样化来源和格式要求HTTP接口具备强大的文件解析能力。例如，从LIMS或ELN系统拉取结构化数据时，需要精确匹配其API接口规范，确保`批号`、`有效期`等关键字段的准确映射。非结构化文档（如PDF版SOP）的引入，则要求接口在上传后能触发高效的光学字符识别（OCR）和内容解析流程，以提取文本内容和识别文档结构。由于部分文档（如批次放行记录）的实时性要求，HTTP接口需要支持高频数据同步，并具备增量更新机制，避免全量同步带来的性能负担。同时，字段和单位的标准化是关键，接口在数据传输时需确保单位一致性，避免因`μL`与`mL`混淆导致的数据错误。对于外部系统的数据，接口还需处理不同系统间的数据模型差异，进行必要的转换与校验。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `API_KEY` | 外部系统提供 | 用于身份验证，确保数据传输的安全性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 应对大型PDF或Word文档的OCR及解析时间，避免超时 |
| `UPLOAD_FILE_MAX_SIZE` | `100 MB` | 兼顾文档大小与网络传输效率，满足大型SOP或报告上传需求 |
| `maxContext` | `8000 tokens` | 适应分子诊断SOP等长文本的上下文窗口需求，确保语义完整性 |
| `分段长度` | `500 字符` | 优化长文档的召回效率与相关性，平衡理解与检索粒度 |
| `相似度阈值` | `0.75` | 确保召回的质量文档与查询高度相关，减少无关信息干扰 |

## 容易做错的三处

*   现象：外部系统数据同步后，部分关键字段如`批号`或`检测结果`为空。原因：HTTP接口的数据映射配置不正确，未能将外部系统字段与FastGPT内部字段正确关联，或外部系统API返回的数据结构发生变化但接口未及时更新。
*   现象：上传大量PDF格式的SOP后，系统长时间无响应或报错`504 Gateway Timeout`。原因：`PARSE_FILE_TIMEOUT_SECONDS`配置过短，对于复杂的文档解析（OCR、结构化提取）未能提供足够的处理时间。
*   现象：配置了新的模型API，但FastGPT界面显示“无效的令牌”。原因：`API_KEY`配置错误或未正确保存，未能通过目标AI模型的身份验证，导致请求被拒绝。

## 怎么确认配好了

*   通过FastGPT的后台日志，检查HTTP接口与外部系统交互时是否有`200 OK`或其他成功的状态码。
*   上传一个典型的分子诊断SOP或批次放行记录，检查FastGPT知识库中该文档的内容是否被完整且正确地解析，关键字段如`批号`、`有效期`等是否被识别。
*   使用一个与质量文档内容相关的查询，验证FastGPT是否能准确召回相关文档片段，并根据实际需求调整`相似度阈值`。
