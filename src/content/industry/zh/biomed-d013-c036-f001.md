# 单克隆抗体质量文档的HTTP 接口与外部系统

## 这个品类的数据长什么样

单克隆抗体（mAb）的质量文档数据来源于研发、中试、生产及质控等多个环节。这些文档通常包括批生产记录、检验报告、稳定性研究报告、偏差处理报告、变更控制文件、以及供应商资质文件等。数据更新频率在研发阶段可能较快，生产阶段则通常随批次生产周期更新，例如每批次生产结束后生成一批新的检验报告。文档结构复杂，常包含图谱、表格、纯文本描述、以及嵌入的结构化数据。字段方面，除了常规的批号、生产日期、有效期等，还会有特定的分析项目（如纯度、聚集体含量、内毒素水平）、检测方法（如高效液相色谱 HPLC、质谱 MS）、单位（如 %、AU·min、EU/mg），以及各类检测结果的数值。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

单克隆抗体质量文档的数据复杂性，对HTTP接口与外部系统的数据传输和处理能力提出了具体要求。文档中包含的大量图谱和表格数据，意味着接口在传输时可能需要支持大文件传输或提供文件分片上传功能，以避免因文件过大导致的连接超时或性能瓶颈。文档更新节奏与批次生产周期相关，因此外部系统调用接口获取数据时，需要考虑轮询频率与数据一致性，避免频繁调用造成资源浪费，也要确保能及时获取最新批次数据。字段的专业性和多样性，要求接口能够灵活处理不同数据类型，例如将图谱解析为可分析的元数据，将表格数据结构化，并正确识别和转换单位。失败处理机制需要能够区分是网络问题、认证失败，还是文档解析错误，并提供详细的错误码和信息，以便工程师进行故障排除。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `maxContext` | 8000–16000 字符 | 单克隆抗体文档专业性强，上下文长度要足以覆盖关键信息，保证模型理解批次间关联。 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 质控文档常包含高分辨率图谱和详细表格，单个文件大小可能较大。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 复杂文档（如批生产记录）解析耗时较长，需要足够的处理时间避免超时。 |
| `maxRetryAttempts` | 3 次 | 外部系统调用可能因网络瞬时波动导致失败，适当重试有助于提高成功率。 |
| `similarityThreshold` | 0.75 | 质量文档术语严格，高阈值有助于精确匹配，避免召回无关内容。 |
| `responseTimeout` | 120 秒 | 接口处理请求、解析文档并生成回复可能需要较长时间，防止客户端超时。 |

## 容易做错的三处

*   调用接口后返回状态码 200 但响应体为空，原因在于文档中存在大量非文本内容（如扫描件图片），模型未能有效提取可供回答的信息。
*   外部系统多次调用接口获取最新批次数据，但返回的仍是旧数据，原因在于接口缓存机制未充分考虑数据更新频率，未及时清除或刷新旧数据。
*   在工作流中配置的 API Key 无法通过认证，现象是返回 401 Unauthorized 错误，原因在于 API Key 的权限范围不足，无法访问请求的特定资源或功能。

## 怎么确认配好了

*   通过 HTTP 客户端工具模拟外部系统调用，上传一份包含图谱和表格的典型单克隆抗体批生产记录，核对返回结果是否包含所有关键文本信息和结构化数据，并检查解析时间是否在预期范围内。
*   在生产环境进行一次完整的批次数据更新后，立即调用接口查询该批次数据，确认返回的是最新版本，比对关键字段（如批号、检测日期）以验证数据一致性。
*   使用不同权限级别的 API Key 调用接口，验证低权限 Key 是否能正确触发权限不足的错误响应，高权限 Key 是否能正常访问所有预期功能，确保安全策略生效。
