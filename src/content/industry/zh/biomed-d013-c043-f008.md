# 基因治疗 AAV质量文档的工具调用与插件

## 这个品类的数据长什么样

基因治疗 AAV（腺相关病毒）的质量文档主要涵盖载体生产批次报告、质粒构建记录、病毒滴度测定、纯度分析、基因组完整性验证、宿主细胞残留检测、生物安全性评估及稳定性研究报告等。这些文档通常以 PDF、Word 或结构化数据库记录的形式存在。数据更新频率与批次生产周期相关，通常在每个生产批次完成后生成或更新。文档结构高度标准化，遵循 GMP（良好生产规范）和 GLP（良好实验室规范）要求，包含固定的章节、表格和图谱。字段如 `批次号`、`滴度 (vg/mL)`、`纯度 (%)`、`基因组拷贝数 (GC/mL)`、`内毒素 (EU/mL)` 等具有明确的命名规则和计量单位。

## 这些特征在「工具调用与插件」这一环带来什么约束

基因治疗 AAV 质量文档的高度结构化和标准化，决定了工具调用需要精确地从特定位置提取特定格式的数据。批次报告的更新周期性意味着工具需要支持定时或事件驱动的数据同步机制，以确保检索结果的时效性。文档中包含大量图谱和表格数据，要求工具调用具备解析复杂布局的能力，例如从图像中识别文本（OCR）或从表格中提取行列表数据。计量单位的严格性要求工具在数据处理和传递给外部系统时，必须保持单位的一致性，避免因单位转换错误导致的数据偏差。生物安全性等关键指标的阈值判断，则依赖于工具能够准确识别字段并进行数值比较，触发预设的业务逻辑或告警。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `model` | `gpt-4o` 或 `claude-3-opus` | 处理复杂文档结构和专业术语的准确性要求高 |
| `maxContext` | `128k` tokens | 单份质量报告篇幅可能较长，需完整理解上下文 |
| `tool_call_timeout` | `600 秒` | 外部数据库查询或复杂数据处理可能耗时，避免过早超时 |
| `召回条数` | `前 5 条` | 保证检索结果的精炼度，聚焦最相关信息 |
| `相似度阈值` | `0.78` | 平衡召回率与准确率，降低无关文档的干扰 |
| `数据库连接池大小` | `10-20` | 应对并发查询需求，保证工具调用的响应速度 |

## 容易做错的三处

- `tool_calls` 数据库连接报错：现象是日志中出现 `400 Messages with role` 错误，原因通常是数据库连接字符串中的敏感信息未正确编码或环境变量未正确加载。
- 本地部署工具调用后无输出：现象是工具调用成功但未返回预期数据，原因常是 FastGPT 容器与数据库容器之间的网络隔离，导致 FastGPT 无法访问数据库服务端口。
- 变量传入 SQL 语句报错：现象是 SQL 查询执行失败，错误提示语法错误，原因多为变量在 SQL 模板中未正确进行转义处理，或变量类型与数据库字段类型不匹配。

## 怎么确认配好了

- 选取一份典型 AAV 质量文档，通过工具调用查询其中一个批次的滴度值，核对返回结果与文档原文是否一致。
- 模拟一次外部系统的数据请求，调用 FastGPT 的工具接口，检查返回的结构化数据字段名和单位是否符合预期。
- 故意输入一个不存在的批次号，观察工具调用是否能正确返回“未找到”或触发预设的错误处理逻辑。
