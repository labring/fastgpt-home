# 干细胞治疗质量文档的工具调用与插件

## 这个品类的数据长什么样

干细胞治疗领域的质量文档，其数据来源呈现多样性与高时效性。主要包括临床试验方案、研究者手册、生产工艺规程（SOP）、质量标准、批生产记录、检验报告以及监管机构发布的指导原则。这些文档的更新频率受研发进展、法规修订、生产工艺优化等因素影响，通常为季度或半年度更新，但临床试验方案或生产批记录可能随项目推进实时生成。文档结构上，PDF 和 Word 格式是主流，内部包含大量表格、图示及专业术语。字段与单位具有高度专业性，例如“细胞活力”常以百分比表示，“细胞数量”以 `cells/mL` 或 `total cells` 计，“传代次数”以 `passage number` 标记，对数值精度和单位一致性要求极高。

## 这些特征在「工具调用与插件」这一环带来什么约束

干细胞治疗质量文档的数据特征对 AI Agent 的工具调用与插件功能提出了特定约束。文档的专业性、多格式和高更新频率要求工具链具备强大的文档解析能力，特别是对复杂表格和图示内容的结构化提取。例如，从批生产记录中准确抽取 `起始细胞数量` 和 `最终细胞得率`，需要专门的 OCR 和表格识别工具。实时或高频的更新节奏意味着知识库需要支持增量更新和版本管理，防止调用过时信息。专业术语和计量单位的严格性，要求工具在信息抽取后能进行单位转换或校验，避免因单位不一致导致的误判。此外，对特定字段（如 `批次号`、`有效期`）的识别与关联，是实现精准问答和自动化流程的关键。

## 配置怎么定

| 配置项             | 建议取法       | 这样取的依据                                                 |
| :----------------- | :------------- | :----------------------------------------------------------- |
| `maxContext`       | `32000 tokens` | 干细胞文档通常较长，包含大量背景信息和实验数据，需要较大上下文窗口来维持语义连贯性。 |
| `分段长度`         | `800–1200 字符` | 兼顾语义完整性与单段处理效率，避免关键信息被截断或过长导致召回噪音。 |
| `相似度阈值`       | `0.78–0.85`    | 确保召回结果与专业查询高度相关，过滤非核心信息。             |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒`       | 大型 PDF 文档解析耗时较长，增加超时时间以防解析中断。         |
| `召回条数`         | `前 8 条`      | 考虑到干细胞文档的复杂性，适当增加召回条数以覆盖更多潜在相关段落。 |
| `tool_retrieval_threshold` | `0.8`          | 确保工具调用触发条件严格，避免误调，特别是涉及数据校验或外部接口时。 |

## 容易做错的三处

*   调用外部工具时，返回的 `响应状态码` 为 `400` 或 `500`。原因在于工具接口的输入参数格式不符合预期，例如 `批次号` 字段未按要求传递，或传递了非预期的特殊字符。
*   AI 生成的回复中，关键数值（如 `细胞活力`）缺失或单位错误。原因常是文档解析阶段未能准确识别表格中的数值和对应单位，导致上游信息输入不完整。
*   模型无法识别应调用哪个工具来处理问题，出现“未找到合适工具”的提示。原因在于工具的 `描述` 或 `输入参数说明` 不够清晰，无法与用户查询进行有效语义匹配。

## 怎么确认配好了

*   选择一个包含复杂表格和专业术语的典型干细胞治疗 SOP 文档，测试其上传解析后，能否准确抽取 `修订日期`、`版本号` 和表格内的 `关键工艺参数`。
*   构建一个需要查询特定 `批次号` 生产记录的问题，验证 AI Agent 能否正确识别 `批次号` 并调用对应的内部查询工具，返回该批次的 `检验报告编号`。
*   模拟一个需要进行数据校验的场景，例如查询 `细胞数量` 是否符合特定范围，检查 AI Agent 是否能触发外部的 `数据校验服务` 插件，并给出校验结果。
*   针对一个涉及最新法规更新的问题，核对 AI Agent 是否能优先从最新版文档中提取信息，其 `更新时间` 字段与文档实际更新时间是否一致。
