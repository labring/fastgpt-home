# 康复设备质量文档的多轮对话与提示词

## 这个品类的数据长什么样

康复设备的质量文档主要来源于设备的设计开发、生产制造、检验测试及上市后监管等环节。这些文档通常以 PDF、Word、Excel 等格式存储，涵盖技术要求、风险分析、验证报告、说明书、用户手册、法规符合性声明等。文档更新频率相对较低，主要集中在产品生命周期的关键节点，例如设计变更、生产工艺调整或法规更新。文档结构通常高度标准化，遵循医疗器械行业规范，例如 ISO 13485 或 GMP。字段与单位具有强烈的专业性，例如“安全裕度”（百分比）、“负载能力”（牛顿/N）、“防护等级”（IPXX）、“平均无故障时间”（小时/h）等，且常包含技术图纸和复杂的表格数据。

## 这些特征在「多轮对话与提示词」这一环带来什么约束

康复设备质量文档的标准化结构和专业性对多轮对话的准确性和提示词的构建提出了具体要求。文档中大量专业术语和计量单位，需要模型具备精准的语义理解能力，避免在对话中产生歧义。较低的文档更新频率意味着知识库的稳定性较高，但当发生法规更新或产品召回时，快速更新知识库并确保对话系统能够立即反映最新信息至关重要。文档中嵌入的技术图纸和复杂表格数据，对知识库的预处理和RAG（检索增强生成）机制提出了挑战，需要确保这些非文本信息也能被有效索引和检索，从而支持更深入的问答。此外，合规性要求使得对话系统在回答敏感问题时必须能够引用到具体的文档章节或页码。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `maxContext` | `6` | 康复设备相关问题往往需要较长的上下文才能准确理解，兼顾性能与效果。 |
| `分段长度` | `500–800 字符` | 质量文档段落通常较长且专业性强，保证单个分段能包含足够信息。 |
| `召回条数` | `前 8 条` | 确保召回足够多的相关文档片段，覆盖复杂或多角度的问题。 |
| `相似度阈值` | `0.75` | 保证召回内容的精确性，避免无关或低相关性文档混入。 |
| `重排返回条数` | `前 3 条` | 提升最终返回结果的质量，将最相关的文档片段优先呈现。 |
| `ENABLE_INPUT_GUIDE` | `true` | 引导工程师提问，尤其是在面对复杂设备参数和法规条文时。 |

## 容易做错的三处

*   现象：对话中模型无法复述知识库中 `xlsx` 文件内容，声称无法读取。原因：知识库在处理 `xlsx` 等结构化文件时，可能未正确配置数据抽取或索引策略，导致数据未能有效转换为可检索的文本片段。
*   现象：用户开启了输入引导和词库，但在对话界面看不到预期的问题提示。原因：可能未在应用的“提示词与模型”配置中，将“引导问题”选项正确关联到已配置的词库或预设问题集。
*   现象：API 调用返回的 AI 对话回复内容中，变量值 `B` 叠加了上一个变量值 `A` 的结果。原因：在工作流设计中，如果 `AI对话` 节点配置的“上下文”或“消息历史”参数未正确清空或隔离，可能导致不同变量间的响应内容发生混叠。

## 怎么确认配好了

*   针对核心康复设备型号或法规条款，进行多轮模拟对话，检查模型能否准确理解并给出合规回答，并能引用到正确的文档出处。
*   上传包含复杂图表和专业术语的新版质量文档，测试知识库更新后，对话系统能否立即识别并回答相关问题，检查 `index` 状态。
*   使用不同工程师角色（例如，设计、生产、质检）模拟提问，确认对话系统对不同视角问题的适应性和准确性，确保 `AI对话` 节点中的 `system_prompt` 能有效引导模型。
