# 患者援助质量文档的部署与升级

## 这个品类的数据长什么样

患者援助项目的质量文档主要包括项目方案、合规审批记录、患者知情同意书模板、药品发放与回收记录、不良事件报告流程、以及定期审计报告。数据来源多样，涵盖药企内部合规部门、第三方项目管理机构、医疗机构以及患者反馈渠道。更新节奏受政策法规变化、药品批次更迭、项目周期调整和审计要求驱动，通常为季度或半年更新，部分关键合规文件可能按月甚至按周修订。文档结构以非结构化文本为主，包含大量法律条款、医学术语和项目流程描述。关键字段包括项目名称、药品批号、患者ID（脱敏）、医生签名、审批日期、事件描述、处理结果等。计量单位涉及药品剂量（毫克、单位）、时间周期（天、月）、数量（份、例）等。

## 这些特征在「部署与升级」这一环带来什么约束

患者援助文档的更新频率和合规性要求，决定了FastGPT在部署时需特别关注数据同步机制的效率与准确性。大量非结构化文本以及其中嵌套的敏感信息，要求部署方案必须具备强大的文本解析能力和灵活的脱敏配置，以确保问答系统的合规性。文档中复杂的法律条款和医学术语，对模型理解能力提出较高要求，需配置合适的嵌入模型和召回策略。此外，项目审计报告等文档的周期性更新，意味着升级过程不能中断服务，要求部署支持热更新或蓝绿部署策略，确保服务的连续性。多源数据汇集也对数据清洗和整合提出挑战，需要确保文档索引的完整性和一致性。

## 配置怎么定

| 配置项                   | 建议取法                                                               | 这样取的依据                                                 |
| :----------------------- | :--------------------------------------------------------------------- | :----------------------------------------------------------- |
| `UPLOAD_FILE_MAX_SIZE`   | 100 MB                                                                 | 患者援助项目方案或审计报告可能包含大量图表和附件，文件较大。 |
| `分段长度`               | 800–1200 字符                                                          | 确保法律条款和医学描述的完整性，避免关键信息被切断。         |
| `相似度阈值`             | 0.75                                                                   | 提高对合规性细节和专业术语的召回精度。                     |
| `maxContext`             | 4096 tokens                                                            | 处理复杂法律条文和多轮问答场景，保持上下文连贯。             |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒                                                                 | 应对大型PDF文档和扫描件的解析时间，避免超时。                |
| `召回条数`               | 前 5 条                                                                | 确保相关性高的关键文档片段被优先检索，减少无关信息干扰。     |

## 容易做错的三处

*   局域网内其他设备无法访问FastGPT服务，但部署服务器本地可以。这通常是防火墙未开放对应端口，或Docker容器端口映射配置不正确导致。
*   上传大型PDF文档后，知识库构建长时间无进展或报错。现象可能是`PARSE_FILE_TIMEOUT_SECONDS`设置过短，未能充分解析文档内容。
*   问答结果中出现患者敏感信息。这往往是文档预处理阶段脱敏配置不当，或未启用FastGPT内置的敏感信息过滤功能。

## 怎么确认配好了

*   通过局域网内其他设备访问FastGPT管理界面和对外服务接口，验证网络连通性。
*   上传并解析一个包含复杂图表和大量文本的患者援助项目审计报告，观察知识库构建状态是否正常完成，无超时报错。
*   使用包含患者ID或药品批号的测试问题进行提问，检查回答中是否已对敏感信息进行脱敏处理，并能准确引用相关文档内容。
