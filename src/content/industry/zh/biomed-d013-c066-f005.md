# 招标挂网质量文档的多轮对话与提示词

## 这个品类的数据长什么样

招标挂网的质量文档主要来源于药监局、医保局、各省市公共资源交易中心等官方网站。数据更新频率较高，尤其在政策调整和新产品上市时，部分省份的挂网信息可达每周更新。文档形式多样，包括 PDF 格式的招标文件、产品注册证、质量标准、检验报告，以及 Excel 或 Word 格式的挂网产品目录和报价清单。文档结构相对固定，例如注册证通常包含注册证号、企业名称、产品名称、规格型号、有效期等字段；报价清单则有产品编码、通用名、剂型、规格、挂网价、生产企业等。单位方面，常见有毫克（mg）、毫升（ml）、片、支、盒等，且不同地区对同一产品的单位表述可能存在差异。

## 这些特征在「多轮对话与提示词」这一环带来什么约束

招标挂网质量文档的特点对多轮对话与提示词设计提出了具体要求。文档更新频率高，意味着知识库需要频繁更新，提示词应能引导模型关注最新数据，避免引用过期信息。文档格式多样且包含大量结构化与非结构化数据，要求模型具备强大的文档解析能力，提示词设计需兼顾提取关键结构化信息（如产品注册证号、挂网价格）和理解非结构化描述（如质量标准中的技术要求）。字段和单位的地域性差异，使得多轮对话在涉及跨区域对比时，需要提示词明确地域范围或进行单位转换，防止因单位不一致导致的误解。此外，文档内容的专业性强，提示词需要精确定义术语，确保模型理解医药领域的特定含义。

## 配置怎么定

| 配置项             | 建议取法       | 这样取的依据                                   |
| :----------------- | :------------- | :--------------------------------------------- |
| `maxContext`       | `8000 tokens`  | 应对复杂招标文件和多轮问答的上下文长度需求   |
| `分段长度`         | `600 字符`     | 平衡长文档的语义完整性与召回效率             |
| `召回条数`         | `前 8 条`      | 覆盖多个相关文档片段，提高信息广度           |
| `相似度阈值`       | `0.78`         | 筛选出与招标挂网主题高度相关的文档段落       |
| `重排返回条数`     | `前 5 条`      | 精炼最终返回结果，突出最相关信息             |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB`     | 适应大型 PDF 招标文件和产品目录文件大小      |

## 容易做错的三处

*   模型在多轮对话中引用了过时的挂网信息，原因是知识库未及时同步最新发布的招标公告。
*   用户提问“某产品在广东的价格”，模型返回了全国平均价，现象是提示词未明确限定查询地域。
*   上传大型 PDF 格式的质量标准文件后，系统长时间无响应或报错，原因是 `UPLOAD_FILE_MAX_SIZE` 参数设置过小，导致文件上传失败。

## 怎么确认配好了

*   模拟用户提问最新发布的招标公告内容，核对模型回答是否引用了最新的挂网价格和政策条款。
*   针对特定产品，在多轮对话中逐步缩小查询范围至特定省份和剂型，验证模型能否精确提取地域性信息。
*   上传一份尺寸接近 `UPLOAD_FILE_MAX_SIZE` 限制的 PDF 文档，确认文档能够正常解析并建立索引。
*   设计包含专业术语和计量单位的复杂问题，检查模型在多轮交互中对这些术语的理解和单位转换的准确性。
