# 招标挂网质量文档的工具调用与插件

## 这个品类的数据长什么样

生物医药行业的招标挂网质量文档，数据来源主要是各省级及国家药品集中采购平台、医保局官网或行业协会发布的公开文件。这些文档更新频率通常不固定，可能随政策调整、批次采购或年度更新而变化，但一般不会过于频繁。文档类型以 PDF、Word、Excel 居多，其中 PDF 占比最高。内容结构相对固定，通常包含产品基本信息（如通用名、商品名、剂型、规格、生产企业）、质量标准（如注册证号、批准文号）、申报信息（如价格、采购量、供应区域）以及资质证明等。字段名称标准化程度较高，但不同省份平台可能存在细微差异，例如“注册证号”可能写作“药品注册批件号”，单位则严格遵循药学或计量标准，如“mg”、“ml”、“片”、“支”等。

## 这些特征在「工具调用与插件」这一环带来什么约束

招标挂网文档以 PDF 为主，且结构化信息与非结构化描述并存，这要求工具调用与插件在数据解析时具备强大的多格式处理能力。更新频率的不固定性意味着需要建立灵活的触发机制，以应对不定期发布的新文件，并确保信息时效性。字段名称的细微差异，对插件在提取信息时提出了更高的鲁棒性要求，需要通过配置同义词或模糊匹配来确保准确性。同时，文档中包含的注册证号、批准文号等关键信息，常需要与内部数据库进行比对或校验，这驱使工具调用直接集成外部数据查询接口。价格、采购量等数值型数据，则可能需要进行单位转换或数值计算，要求插件具备基础的运算能力。

## 配置怎么定

| 配置项                   | 建议取法                                 | 这样取的依据                                                                                                                                                                                                                                                             |
| :----------------------- | :--------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `MAX_FILE_SIZE`          | `200 MB`                                 | 招标挂网文档通常包含较多图片和附件，文件体积可能较大，此设置确保能够处理绝大多数文件。                                                                                                                                                                                 |
| `PARSE_TIMEOUT_SECONDS`  | `300 秒`                                 | PDF 文档解析，特别是包含复杂表格和图片的文件，耗时较长，预留充足的解析时间以避免因超时导致处理失败。                                                                                                                                                               |
| `CHUNK_SIZE`             | `1000–1500 字符`                         | 招标挂网文档中既有结构化数据也有描述性文本，此分段长度有助于在保持上下文完整性的同时，提高召回的准确性，避免单个分段过大或过小。                                                                                                                                       |
| `SIMILARITY_THRESHOLD`   | `0.75`                                   | 确保在检索相关信息时，能够有效过滤掉不相关的文本段落，提升召回质量。                                                                                                                                                                                               |
| `EXTERNAL_API_ENDPOINT`  | `https://api.example.com/drug_registry`  | 用于调用外部药品注册数据库，核对或补充文档中的药品信息，确保数据一致性与准确性，例如核验注册证号的有效性。                                                                                                                                                       |
| `HTTP_REQUEST_RETRIES`   | `3`                                      | 外部API调用可能因网络波动或服务暂时性不可用而失败，设置重试机制可以提高工具调用的成功率。                                                                                                                                                               |

## 容易做错的三处

*   插件日志显示“请求失败，状态码 401”，原因通常是 `Authorization` 头信息未正确传递或 API 密钥过期。
*   解析结果中某个关键字段（如“批准文号”）为空，这通常是由于文档中该字段的表述与插件预设的提取规则不符，或是 OCR 识别错误导致。
*   工具调用后，期望的结果并未出现在后续流程中，这可能是因为插件的返回值路径配置有误，或者 `output` 字段的 JSON 结构与下游组件的预期不匹配。

## 怎么确认配好了

*   上传典型招标挂网 PDF 文档，检查知识库分段结果，确认关键信息（如产品名、规格、生产企业、注册证号）是否被准确抽取并分段。
*   执行模拟工具调用，验证 `EXTERNAL_API_ENDPOINT` 返回的数据结构是否符合预期，并确认关键字段（例如 `drug_status`）能够被正确解析。
*   针对包含多张表格的 Excel 文档，检查插件能否正确识别并提取所有表格数据，并确认数值型字段（如价格、采购量）的单位和数值准确性。
