# 生物制药设备质量文档的工具调用与插件

## 这个品类的数据长什么样
生物制药设备的质量文档主要包括验证方案、验证报告、校准证书、维护记录、操作规程（SOP）等。这些文档多以 PDF 格式存储，部分扫描件可能不含文本层。数据来源通常是设备供应商、内部工程部门或第三方校准机构。更新节奏方面，校准证书通常按年度或半年度更新，维护记录随维护活动实时生成，验证报告在设备安装、改造或重大变更后更新。文档结构相对固定，例如校准证书包含校准日期、校准员、设备编号、测量参数、允许偏差和实测值等字段，并常附有计量标准溯源信息。字段单位严格遵循国际单位制（SI），如温度单位为摄氏度（°C）、压力单位为巴（bar）或帕斯卡（Pa）、流量单位为升/分钟（L/min）。

## 这些特征在「工具调用与插件」这一环带来什么约束
生物制药设备质量文档的特性对工具调用与插件提出了特定要求。首先，大量 PDF 格式，特别是扫描件，要求插件具备高效的 OCR 识别能力，并能处理多页文档的结构化信息提取。其次，文档更新节奏决定了工具调用需要支持定时或事件触发机制，以确保信息的时效性。例如，当新的校准报告上传时，系统应能自动触发解析并更新相关设备状态。文档中严格的字段与单位要求，使得插件在提取数据时必须进行严格的校验与标准化处理，避免因单位不匹配或数值格式错误导致的数据污染。此外，设备编号、批次号等关键标识符的准确提取，是连接不同文档、构建设备生命周期视图的基础，工具调用流程需要能精确识别这些模式。

## 配置怎么定

| 配置项             | 建议取法       | 这样取的依据                               |
| :----------------- | :------------- | :----------------------------------------- |
| `maxContext`       | 4000-8000 Token | 应对长篇幅验证报告，确保上下文完整性       |
| `UPLOAD_FILE_MAX_SIZE` | 50 MB          | 适配大型 PDF 文档，特别是包含高分辨率图片的扫描件 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒         | 给予 OCR 复杂扫描件及解析结构化数据充足时间 |
| `分段长度`         | 800 字符       | 平衡文本语义完整性与召回效率               |
| `相似度阈值`       | 0.75-0.85      | 提高对专业术语、设备型号等特定信息的召回精度 |
| `工具调用超时时间` | 120 秒         | 考虑外部接口响应慢或处理复杂文件流的场景   |

## 容易做错的三处
* HTTP 请求返回文件流时，工作流中直接返回响应为空。原因是工作流未配置正确的媒体类型处理，导致无法识别二进制数据流。
* 调用外部模型时出现响应为空，日志显示“messag”等不完整错误信息。原因多为外部 API 接口返回的错误消息格式不标准或未被工作流正确解析。
* 工作流在应用配置测试正常，但通过 API 调用时报错。原因通常是 API 调用时缺少必要的环境变量或认证信息，与应用配置时的环境不一致。

## 怎么确认配好了
* 上传一份包含扫描页面的设备校准报告 PDF 文件，检查工作流是否能正确识别并提取校准日期、设备编号和测量值。
* 模拟外部系统上传新的设备维护记录，确认工具调用是否能被触发，并成功解析维护内容与时间戳。
* 针对一份包含多种计量单位的验证方案，验证插件是否能准确识别并标准化所有数值和单位，例如将“bar”转换为“Pa”。
