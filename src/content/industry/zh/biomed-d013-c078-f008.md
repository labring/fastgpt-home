# 监护设备质量文档的工具调用与插件

## 这个品类的数据长什么样

监护设备的质量文档主要包括设计开发文档（如设计输入/输出、风险管理报告）、生产过程记录（批生产记录、检验记录）、上市后监督文档（不良事件报告、用户反馈）以及合规性文件（注册证、型式检验报告）。数据来源广泛，涉及研发、生产、质控、市场等多个部门。更新频率因文档类型而异，设计文档相对稳定，生产记录实时生成，上市后监督数据则持续动态更新。文档结构以结构化文本（如表格、清单）和半结构化文本（如报告、批记录）为主，PDF 格式常见。字段与单位具有高度专业性，例如“血氧饱和度”单位为 `%`，“心率”单位为 `bpm`，“血压”单位为 `mmHg`，且常伴随特定的测量方法和精度要求。

## 这些特征在「工具调用与插件」这一环带来什么约束

监护设备质量文档的多源性与动态更新特性，要求工具调用具备灵活的数据摄取能力，以适应不同系统的数据接口。文档中大量专业术语和计量单位，对模型理解和抽取精度提出了更高要求，需要通过定制化工具或插件进行精确解析，避免单位混淆或数值误读。半结构化文档的存在，使得通用解析工具效果有限，需要开发针对性的文档解析插件，识别并提取关键信息。此外，合规性文件通常涉及特定格式和审批流程，工具调用需能触发外部系统进行状态查询或流程流转，例如查询注册证的有效期或触发风险评估流程。对实时性要求较高的生产记录和上市后监督数据，需要通过API插件实现近实时的数据同步和状态更新，以支持快速响应和决策。

## 配置怎么定

| 配置项                 | 建议取法       | 这样取的依据                                   |
| :--------------------- | :------------- | :--------------------------------------------- |
| `MAX_FILE_SIZE`        | `50 MB`        | 兼顾大型PDF文档和系统性能，避免过大文件导致处理超时 |
| `PARSE_TIMEOUT_SECONDS` | `300 秒`       | 多数质量文档可在该时间内完成解析，确保及时性   |
| `CHUNK_SIZE`           | `800–1200 字符` | 平衡上下文长度与召回精度，适应专业术语密集文档 |
| `OVERLAP_SIZE`         | `100–150 字符`  | 保证切片间上下文连贯性，提高跨段信息抽取准确率 |
| `SIMILARITY_THRESHOLD` | `0.75`         | 确保召回文档与查询高度相关，过滤不必要的噪音   |
| `MAX_RETRIEVED_CHUNKS` | `前 5 条`      | 聚焦最相关的关键信息，减少模型处理负担         |

## 容易做错的三处

*   工具调用返回 514 错误码，现象是无法触发外部服务或获取数据，原因可能是 API 密钥过期或权限配置不正确，导致认证失败。
*   文档解析后，部分专业字段（如“压力值”）为空或单位错误，原因在于通用解析器未能准确识别监护设备特有的字段名称和计量单位，需要定制化正则表达式或语义规则。
*   知识库查询结果与预期不符，未能召回相关生产批次记录，原因可能是文档切片策略过于粗糙，导致关键批次信息被分割到不同片段，或相似度阈值设置过高。

## 怎么确认配好了

*   通过测试工具调用，检查外部系统是否收到请求，并返回正确的状态码和预期数据结构。
*   上传典型监护设备质量文档，检查解析结果中的关键专业字段（例如 `序列号`、`校准日期`、`测量范围`）是否被准确抽取，且单位无误。
*   针对特定质量问题进行知识库提问，核对召回的文档片段是否包含提问的核心信息，并通过调整相似度阈值来验证其召回效果。
