# 院感管理质量文档的多轮对话与提示词

## 这个品类的数据长什么样
院感管理的数据主要来源于医院内部的感染监测系统、病例报告、实验室检测结果、设备消毒记录、医护人员培训档案以及相关规章制度文档。这些数据更新频率较高，感染病例报告可能每日更新，消毒记录实时录入，规章制度则根据国家政策和医院实际情况定期修订。文档结构通常包含标准化模板，如感染上报表、消毒操作规程、感控培训手册、应急预案等。字段涵盖患者基本信息、感染部位、病原学结果、抗生素使用情况、消毒剂类型与浓度、执行人员、操作时间等，单位涉及时间（小时、天）、浓度（%）、数量（例、人次）等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
院感管理数据的实时性与时效性要求多轮对话系统能够快速检索并引用最新数据，避免提供过时的信息。文档的标准化模板和结构化字段，使得提示词设计需要精准匹配特定字段，以提高召回准确性。例如，查询特定病原体的感染案例或某种消毒剂的使用规范时，系统需要理解并解析这些专业术语。此外，法规和规章制度文档的严谨性，要求对话系统在引用时保持原文的完整性与准确性，减少信息偏差。多轮对话中可能涉及跨文档的知识整合，例如，将感染病例数据与相关消毒规程关联分析，这对上下文管理和信息融合能力提出了较高要求。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| :----- | :------- | :----------- |
| `maxContext` | `8` | 确保在多轮对话中能够覆盖较长的对话历史，便于理解上下文。 |
| `分段长度` | `800–1200 字符` | 适应院感规章制度和操作流程文档的段落长度，保证语义完整性。 |
| `召回条数` | `前 5–8 条` | 兼顾检索效率与相关性，避免引入过多无关信息。 |
| `相似度阈值` | 按实测标定 | 针对院感专业术语的语义相似性进行优化，确保召回内容的精准度。 |
| `重排返回条数` | `3` | 提高最终呈现给用户的关键信息质量，过滤低相关性结果。 |
| `temperature` | `0.1–0.3` | 降低模型生成内容的随机性，确保回答的准确性和严谨性。 |

## 容易做错的三处
*   对话接口返回的院感规章制度版本不是最新版本，原因是对文档更新机制的配置不当，导致索引未及时刷新。
*   在查询特定消毒剂浓度时，系统未能准确提取数值信息或单位不匹配，原因在于提示词未能有效引导模型识别和解析结构化字段。
*   多轮对话中，用户后续提问与前一轮上下文关联性不足时，系统表现出“失忆”，原因是没有配置足够的 `maxContext` 或上下文管理策略不当。

## 怎么确认配好了
*   针对最新的院感管理规章制度，进行多轮对话测试，验证系统是否能准确引用最新版本内容。
*   设计包含专业字段（如病原体名称、消毒剂浓度）的查询，检查系统能否精确提取并回复相关信息。
*   模拟用户进行多轮追问，核对系统在不同轮次间是否能保持上下文一致性，并基于历史对话生成连贯回复。
