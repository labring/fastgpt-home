# 幼儿园卫生保健与膳食管理的业务依据查询：重排与混合检索

## 这个品类的数据长什么样

本页面向幼儿园卫生保健与膳食管理场景，材料包括带食材名称与规格的采购单据、留样记录与批次、食谱、消毒记录、缺勤病因归类表及本园保健制度。这些材料按周与月更新，版本以园内保健室现行归档为准。进入混合检索时，食谱与制度文本走全文路，单据与批次字段走向量路，两路合并后由重排模型统一排序，供后续引用裁剪定位到可回指原文的条目。

## 配置怎么定

这一环由检索服务中的重排模型执行，输出排序后的候选与重排得分。可回指原文的依据条目由引用裁剪与回答生成接着完成。混合检索同时走向量与全文两路并合并结果，合并后范围大、不能直接做相似度过滤，通常再用重排模型排序并按重排得分过滤。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 混合检索 | 向量与全文两路都已启用，候选应同时来自两路 | 在搜索参数里核对两路开关，并看候选是否同时来自两路；比对 `searchMode` 与 `usingReRank` |
| 重排模型 | 已绑定并用于排序与过滤，重排前后顺序与得分可对比 | 对比重排前后的排序与得分，用重排得分做过滤，记录候选条数与得分 |
| 留样记录与批次 | 留样时间与批次能对上采购单据的食材名称与规格 | 把留样批次与单据逐条对齐，核对留样时间落在消毒时段之外 |
| 消毒记录与缺勤病因归类 | 消毒时段不缺段，缺勤病因归类与食谱、采购品类一致 | 按日期补齐消毒时段，核对缺勤病因归类与食谱、采购品类是否对得上 |

## 容易做错的三处

- 现象：单据与留样批次对不上。原因：留样时间与批次字段未与采购单据的食材名称、规格同步更新，合并后候选混排。
- 现象：食谱与采购品类不一致。原因：食谱文本走全文路、采购字段走向量路，两路合并后未按重排得分过滤。
- 现象：消毒记录缺时段。原因：消毒时段字段不完整，重排得分接近，前几条候选排到无关材料。

## 怎么确认配好了

本功能验收：开重排前后对比前三条的顺序与得分，记录候选条数与得分，核对 `usingReRank` 与 `similarity` 是否参与过滤。

业务测试：问一个跨材料的依据问题，看回答是否给出可回指的出处，并核对出处能对上本园材料与现行版本。

- 在搜索参数里核对两路开关，确认候选同时来自两路，并记录候选条数与重排得分。
- 对比重排前后前三条的顺序与得分，核对 `limit` 与 `searchMode` 取值，确认过滤按重排得分执行。
