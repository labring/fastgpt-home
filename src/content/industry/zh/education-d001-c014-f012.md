# 学校德育与班主任工作的业务依据查询：文档解析与分块

## 这个品类的数据长什么样

本页聚焦学校德育与班主任工作的业务依据查询，材料来自本机构主题班会方案、学生综合素质记录、家访记录三类。主题班会方案提供活动目标与流程字段，综合素质记录承载学生表现与评价字段，家访记录保留沟通时间、对象与回执字段。三者按学期与月度更新，日期、签字、数量、名称须逐项对齐。材料进入文档解析与分块后，各自成为独立数据行，绑定唯一数据标识，供检索层按索引状态决定是否召回。主题班会方案侧重流程节点，综合素质记录侧重字段完整性，家访记录侧重签字与回执，三者共同支撑可回指原文的依据条目。

## 配置怎么定

解析与训练任务（服务端任务）只输出数据行与索引状态（已解析、索引中、已完成），可回指原文的依据条目要由检索与后续处理接着做。解析分块在解析完成后立即落库为可见数据行并绑定唯一数据标识，索引按三态流转，待索引数据不参与召回。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 主题班会方案 | 字段含活动目标、流程、日期与签字，须与综合素质记录中的名称、数量、日期对齐 | 打开数据行核对状态与界面显示一致，确认 `chunkSize` 与 `chunkSplitter` 切分后条目能回指原文 |
| 学生综合素质记录 | 字段含评价项、日期与签字，须与家访记录中的学生名称、日期对得上 | 分别核对文件记录与数据行，确认 `trainingType` 与索引三态 parsed / indexing / indexed 流转正确 |
| 家访记录 | 字段含沟通时间、对象、回执与签字，须与主题班会方案中的日期、数量一致 | 查看重建任务覆盖的数据行，确认只覆盖已完成索引的数据，待索引数据不参与重建 |
| 数据行与索引状态 | 处于 parsed / indexing / indexed 三态之一且与界面显示一致 | 打开数据行核对状态，确认待索引数据不参与召回，换模型只对已完成索引的数据重建 |

## 容易做错的三处

- 现象：同一记录在两份材料里的名称、数量、日期对不上。原因：材料各自独立解析落库，字段未做跨材料对齐，回指原文时出现分歧。
- 现象：版本未同步，旧版方案仍被召回。原因：重建只针对已完成索引的数据，待索引数据不参与重建链，旧版未及时更新索引状态。
- 现象：缺签字或回执，依据条目无法闭环。原因：解析分块只输出数据行与索引状态，签字与回执字段缺失时检索层仍可能命中。

## 怎么确认配好了

本功能验收：上传一份主题班会方案，看数据行状态从 parsed 到 indexing 再到 indexed 的流转，并核对重建任务只覆盖已完成索引的数据，确认 `chunkSize`、`chunkSplitter`、`trainingType` 在数据行中的记录。

业务测试：问一个跨材料的依据问题，例如某次家访记录与综合素质记录中的日期是否一致，看回答是否给出可回指的出处。

- 打开数据行核对状态与界面显示一致，确认文件记录与数据行各自的身份分得开。
- 查看重建任务覆盖的数据行，确认只覆盖已完成索引的数据，待索引数据不参与重建。
