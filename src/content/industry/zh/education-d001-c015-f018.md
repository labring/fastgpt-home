# 中小学心理健康筛查与转介的业务依据查询：重排与混合检索

## 这个品类的数据长什么样

中小学心理健康筛查与转介涉及心理筛查方案、访谈记录、转介单三类材料。筛查方案记录量表名称、筛查日期、筛查对象范围与负责人签字；访谈记录记录访谈时间、访谈对象、问题描述与访谈人签字；转介单记录转介对象、转介原因、接收方与回执签字。三类材料按学期或学年更新，版本以日期与签字为准。进入该功能时，筛查方案作为筛查依据的源头，访谈记录作为个体情况的补充，转介单作为转介动作的凭证，各自承担依据条目、过程记录与结果回执的角色。材料字段不一致时，以现行版本与签字齐全者为准，便于回指原文。

## 配置怎么定

这一环由检索服务中的重排模型执行，输出排序后的候选与重排得分。「可回指原文的依据条目」由引用裁剪与回答生成接着完成。混合检索同时走向量与全文两路并合并结果，合并后范围大、不能直接做相似度过滤，通常再用重排模型排序并按重排得分过滤。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 混合检索 | 向量与全文两路都已启用，两路结果已经合并 | 在搜索参数里核对两路开关，查看候选是否同时来自两路，并记录候选条数与得分 |
| 重排模型 | 已绑定并用于排序与过滤，重排前后排序与得分可对比 | 对比重排前后的排序与得分，核对 `usingReRank` 与 `searchMode` 的取值，记录候选条数与得分 |
| 心理筛查方案 | 筛查方案中的量表名称、筛查日期与负责人签字能对上现行版本 | 核对方案字段、日期与签字，确认与访谈记录、转介单中的名称、数量、日期一致 |
| 转介单 | 转介单中的转介对象、转介原因与回执签字能对上原文 | 核对转介单字段、日期与签字，确认回执齐全，并与筛查方案、访谈记录交叉比对 |

## 容易做错的三处

- 现象：同一记录在筛查方案与访谈记录里的名称、数量、日期对不上。原因：两份材料各自更新，未做交叉核对，导致依据条目无法回指同一原文。
- 现象：转介单缺签字或回执，版本未同步。原因：转介流程未闭环，旧版本仍被检索到，现行版本与历史版本混用。
- 现象：候选很多但前几条不相关，结果明显偏向关键词命中。原因：合并后范围大，未用重排得分过滤，相似度过滤看起来失效。

## 怎么确认配好了

本功能验收：开重排前后对比前三条的顺序与得分，核对 `usingReRank`、`searchMode`、`similarity` 与 `limit` 的取值，记录候选条数与得分变化，确认重排后前三条更相关。

业务测试：问一个跨材料的依据问题，看回答是否给出可回指的出处，并核对引用条数与引用文本 tokens，数组条数单独记录。

- 在搜索参数里核对两路开关，确认向量与全文两路都已启用，并查看候选是否同时来自两路。
- 对比重排前后的排序与得分，按重排得分过滤，核对 `usingReRank` 与 `similarity` 的取值，记录候选条数与得分。
