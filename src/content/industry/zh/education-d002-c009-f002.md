# 义务教育控辍保学的材料核对与差异定位：上下文与 token

## 这个品类的数据长什么样

本页聚焦义务教育控辍保学场景，材料来自辍学风险台账、劝返记录与家访记录三类。台账按月更新，含学生姓名、风险等级、责任人与日期；劝返记录随每次劝返填写，含对象名称、劝返次数、结果与签字；家访记录按次登记，含受访学生、家访日期、问题描述与回执。三类材料进入该功能时，台账作为基准对象，劝返与家访记录作为比对对象，各自承担字段来源与差异定位的角色。字段特征集中在名称、数量、日期与签字四类，名称需与学籍一致，数量指劝返次数或家访次数，日期须与台账节点对应，签字与回执用于确认流程闭环。材料版本未同步时，同一记录在两份材料里的名称、数量、日期容易对不上，需逐字段核对并形成差异清单。

## 配置怎么定

这一环由应用设置（回复上限等）执行，输出单次回答长度与可容纳的上下文范围。「差异清单」由模型接着完成。回复上限用滑块控制单次回答的长度，设置过低回答会被截断，设置过高会增加消耗。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 辍学风险台账 | 名称、数量、日期与签字是否与劝返记录一致 | 逐条比对姓名、风险等级、劝返次数与日期，记录差异字段并核对签字栏；关注 `maxResponse` 对长清单输出的截断影响 |
| 劝返记录 | 同一对象在两份材料里的名称、数量、日期是否对得上 | 以台账为基准，核对劝返次数、劝返结果与回执日期，标记版本未同步或缺失签字的条目 |
| 家访记录 | 家访日期、问题描述与回执是否与台账节点对应 | 检查家访次数与台账节点日期，核对回执签字；长清单输出时留意 `maxContext` 与 `quoteMaxToken` 的预算分配 |
| 差异清单 | 字段级差异是否可定位到具体材料与行 | 汇总名称、数量、日期、签字四类差异，交复核人确认并回写 |

## 容易做错的三处

- 现象：同一记录在台账与劝返记录里的劝返次数对不上。原因：版本未同步，一方更新后另一方未回写，导致数量字段出现差异。
- 现象：家访记录日期与台账节点日期不一致。原因：登记时未按台账节点填写，或补录时日期填错，造成同一对象日期对不上。
- 现象：劝返记录缺签字或回执。原因：流程未闭环，签字与回执未随记录同步，核对时无法确认该条记录已处理。

## 怎么确认配好了

本功能验收：提一个需要长回答的问题，例如列出全部差异字段，看回答结尾是否完整，确认回复上限未截断。

业务测试：用一条真实记录找出与台账不一致的字段，记录名称、数量、日期或签字的具体差异。

- 在应用设置里核对回复上限开关与滑块位置，确认与页面要求的回答长度匹配。
- 对比两次运行的用量，观察上限调整后单次用量变化，并检查较长回答结尾是否完整。
