# 幼儿园家园共育沟通的资料版本与变更维护：HTTP 接口

## 这个品类的数据长什么样

幼儿园家园共育沟通的资料版本与变更维护，材料来源包括教师观察记录、家长诉求登记、通知送达回执、承诺事项与回应时间表。这些材料进入 HTTP 接口与外部系统时，各自角色不同：观察记录作为幼儿表现描述依据，诉求登记用于家长诉求分类，回执用于通知送达核验，承诺表用于承诺事项与回应时间追踪。更新节奏按日或按周，字段特征含版本号、生效日期、变更说明与引用编号。版本台账与变更记录需保证现行版本唯一、旧版可追、引用同步，最终去向为更新知识库或对外文档。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。版本台账与变更记录由后续节点解析响应，或外部系统按约定处理接着完成。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 观察记录材料 | 幼儿表现描述与观察记录是否一致 | 核对请求体字段与样例返回，确认描述来源可追 |
| 家长诉求登记材料 | 家长诉求分类是否与反馈归类一致 | 检查请求头与变量来源，比对分类字段 |
| 通知送达回执材料 | 通知送达状态是否与承诺事项及回应时间对应 | 在请求预览里看渲染后的完整地址与返回字段 |
| 版本台账与变更记录 | 现行版本唯一、旧版可追、引用同步 | 用一条样例请求比对返回，核 `responseData` 与版本号 |

## 容易做错的三处

- 现象：承诺未回应。原因：承诺事项与回应时间表未随版本更新，旧版引用未同步。
- 现象：表述与观察记录不符。原因：幼儿表现描述字段在请求体中被覆盖，变量来源未核对。
- 现象：反馈未归类。原因：家长诉求分类字段缺失，外部系统收到空字段。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果。

业务测试：改一处内容，看版本号与引用是否同步更新。

- 在变量面板核对每个占位的来源，确认 `variables` 与 `Authorization` 取值正确。
- 检查请求体字段与外部接口约定一致，记录数组条数并单独核引用文本的 tokens。
