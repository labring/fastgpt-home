# 现代学徒制与订单班管理的资料版本与变更维护：HTTP 接口

## 这个品类的数据长什么样

现代学徒制与订单班管理涉及三类材料：校企合作协议、订单班培养方案、师傅带徒记录。校企合作协议含合作期限、岗位、人数、签字盖章；订单班培养方案含课程、轮岗、考核、日期；师傅带徒记录含带徒师傅、徒弟、工时、签字回执。材料来源为学校、企业、师傅三方，更新节奏随学期、批次、人员变动。进入本功能时，协议与方案作为版本台账的基准，带徒记录作为变更来源，通过 HTTP 接口与外部系统交换字段，保持现行版本唯一、旧版可追、引用同步。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。「版本台账与变更记录」由后续节点解析响应，或外部系统按约定处理接着完成。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 校企合作协议 | 核对合作期限、岗位、人数、日期与签字盖章是否与订单班培养方案一致 | 在请求预览里看渲染后的完整地址，核对请求体字段与外部接口约定 |
| 订单班培养方案 | 核对课程、轮岗、考核、日期与师傅带徒记录是否对得上 | 核对请求头名称与取值来源，确认鉴权信息按外部系统要求传入 |
| 师傅带徒记录 | 核对带徒师傅、徒弟、工时、签字回执是否齐全且版本未同步 | 在变量面板核对每个占位的来源，用一条样例请求比对返回 |

## 容易做错的三处

- 现象：同一记录在校企合作协议与订单班培养方案里的名称、数量、日期对不上。原因：材料分别由学校与企业维护，未通过 HTTP 接口与外部系统做字段核对。
- 现象：师傅带徒记录已更新，但版本台账仍指向旧版，引用未同步。原因：变更未触发 HTTP 节点请求，后续节点未解析响应更新知识库或对外文档。
- 现象：协议或带徒记录缺签字或回执，外部系统收到空字段。原因：请求体字段与外部接口约定不一致，占位变量未解析成实际值。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果；检查 `Authorization`、`variables`、`responseData` 是否按预期出现。

业务测试：改一处内容，看版本号与引用是否同步更新

- 在请求预览里看渲染后的完整地址，核对请求头名称与取值来源
- 在变量面板核对每个占位的来源，用一条样例请求比对返回
