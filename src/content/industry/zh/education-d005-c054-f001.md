# 自学考试考籍与毕业审核的资料版本与变更维护：HTTP 接口

## 这个品类的数据长什么样

本页聚焦自学考试考籍与毕业审核中的三类材料：考籍档案、课程合格证、毕业申请表。考籍档案来自省级考籍系统，含姓名、身份证号、准考证号、专业代码与在籍状态；课程合格证来自统考成绩库，含课程代码、课程名称、合格日期与成绩；毕业申请表由考生填写并经主考院校初审，含专业名称、拟毕业时间、课程门数与签字栏。三类材料按考期与批次更新，字段中日期与签字是审核关键。进入该功能时，考籍档案作为身份与在籍依据，课程合格证作为课程完成凭据，毕业申请表作为毕业结论的申请载体，三者通过 HTTP 接口与外部系统交换，形成版本台账与变更记录。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。「版本台账与变更记录」由后续节点解析响应，或外部系统按约定处理接着完成。请求地址、路径参数、请求头与请求体中的占位变量来自全局变量、系统变量或前方节点输出，变量面板可核对每个占位的来源。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 考籍档案 | 姓名、身份证号、准考证号、专业代码与在籍状态须与课程合格证、毕业申请表逐项一致 | 在变量面板核对占位来源，用一条样例请求比对返回字段与档案字段 |
| 课程合格证 | 课程代码、课程名称、合格日期与成绩须与考籍档案中的专业计划匹配 | 核对请求头名称与取值来源，检查 `Authorization` 是否按外部系统要求传入 |
| 毕业申请表 | 专业名称、拟毕业时间、课程门数与签字栏须与课程合格证汇总结果一致 | 预览渲染后的请求体，核 `variables` 与 `responseData` 字段是否与申请表约定一致 |
| HTTP 请求 | 请求地址与路径参数中的占位变量能解析成实际值 | 在请求预览里看渲染后的完整地址，确认无空字段与超时 |

## 容易做错的三处

- 现象：同一考生姓名在考籍档案与毕业申请表里写法不同。原因：两处材料分别录入，未做字段级比对与版本同步。
- 现象：课程合格证日期与毕业申请表汇总日期对不上。原因：旧版合格证未随考期更新，引用仍指向旧记录。
- 现象：毕业申请表缺主考院校签字或回执。原因：审核环节未回写签字状态，外部系统未按约定处理返回字段。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果；检查 `Authorization`、`variables`、`responseData` 三处取值与来源。

业务测试：改一处内容，看版本号与引用是否同步更新

- 在变量面板核对每个占位的来源，确认来自全局变量、系统变量或前方节点输出
- 用一条样例请求比对返回字段，确认请求头名称与取值来源符合外部系统要求
