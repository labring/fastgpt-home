# 教师资格考试与认定的资料版本与变更维护：HTTP 接口

## 这个品类的数据长什么样

教师资格考试与认定的材料分三类：笔试面试报名表、普通话证书、体检表。报名表字段含姓名、证件号、报考科目与考区，日期为报名与审核日期，签字栏需考生与审核人签署；普通话证书含等级、证书编号、测试日期与发证单位，无签字栏但需核对证书编号与等级对应；体检表含体检项目、结论、体检日期与医师签字，签字与回执缺一不可。三类材料进入 HTTP 接口与外部系统时，报名表作为主记录驱动版本台账，普通话证书与体检表作为附件字段参与版本比对。更新节奏随认定批次与政策调整变化，旧版需保留可追溯，引用同步到知识库或对外文档。字段特征为日期多、签字栏多、同一记录在不同材料中的名称与数量需对齐。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。「版本台账与变更记录」由后续节点解析响应，或外部系统按约定处理接着完成。请求地址、路径参数、请求头与请求体均可通过 `variables` 引用全局变量、系统变量或前方节点输出，鉴权信息按外部系统要求放入 `Authorization`。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 笔试面试报名表 | 字段、日期与签字齐全，且与普通话证书、体检表中的姓名、证件号、日期一致 | 在请求预览里看渲染后的完整地址，核对报名表字段与外部接口约定一致，检查 `Authorization` 与 `variables` 来源 |
| 普通话证书 | 证书编号、等级、测试日期与报名表、体检表记录不冲突 | 用一条样例请求比对返回，核 `responseData` 中证书编号与等级字段，确认旧版可追且引用同步 |
| 体检表 | 体检结论、体检日期与医师签字、回执完整，且与报名表日期对齐 | 核对请求头名称与取值来源，检查签字与回执字段是否随版本号更新，避免同一记录日期对不上 |
| 版本台账与变更记录 | 现行版本唯一，旧版可追，引用同步更新 | 改一处内容后，在变量面板核对每个占位来源，确认版本号与引用同步更新 |

## 容易做错的三处

- 现象：同一记录在报名表与体检表里的姓名、日期对不上。原因：两份材料分别维护，HTTP 节点请求体字段未按版本台账对齐，引用未同步。
- 现象：普通话证书等级与报名表记录不一致，旧版仍被引用。原因：版本未同步，变更记录未回写，后续节点解析响应时取到旧字段。
- 现象：体检表缺医师签字或回执，外部系统收到空字段。原因：请求体未包含签字与回执字段，或变量占位解析为空，鉴权信息缺失导致返回 401。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，检查 `responseData` 中报名表、普通话证书、体检表字段是否齐全，再对一条样例比对结果，确认 `Authorization` 与 `variables` 解析正确。

业务测试：改一处内容，看版本号与引用是否同步更新

- 在请求预览里看渲染后的完整地址，核对路径参数、请求头与请求体中的变量占位是否解析成实际值
- 用一条样例请求比对返回，检查 `responseData` 中报名表、普通话证书、体检表的字段、日期与签字是否与外部系统约定一致
