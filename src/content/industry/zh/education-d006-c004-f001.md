# 幼儿园家园共育沟通的进度记录与统计核对：HTTP 接口

## 这个品类的数据长什么样

本页面向幼儿园家园共育沟通场景，材料来自班级日常记录、家长反馈与通知送达回执，更新节奏按周汇总、按月核对。进度表与统计口径说明是核心产物，进入 HTTP 接口与外部系统这一功能时，班级记录作为请求体字段来源，家长诉求分类与通知送达状态作为路径参数或请求头标识，承诺事项与回应时间、幼儿表现描述则作为统计口径的判定依据。字段特征包括：承诺事项与回应时间成对出现，幼儿表现描述需与观察记录一致，家长诉求分类需归入固定类别，通知送达需有明确状态。这些材料在功能中各自承担不同角色：记录提供原始数据，分类提供统计维度，送达状态提供核对基准，最终由 HTTP 节点向外部系统发送请求，响应体与返回字段供后续节点解析，形成可核对的进度表与统计口径说明。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。「进度表与统计口径说明」由后续节点解析响应，或外部系统按约定处理接着完成。请求地址、路径参数、请求头与请求体均可通过 `variables` 引用全局变量、系统变量或前方节点输出，鉴权信息按外部系统要求放入 `Authorization` 请求头。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 承诺事项与回应时间 | 承诺是否在约定时间内得到回应，回应时间是否可追溯 | 核对请求体中承诺事项字段与回应时间字段是否成对出现，检查返回字段是否包含对应时间戳 |
| 幼儿表现描述 | 表述是否与观察记录一致，有无主观夸大或遗漏 | 用一条样例请求比对返回，核对描述字段与原始观察记录是否吻合 |
| 家长诉求分类 | 反馈是否归入约定类别，有无未归类或错归类 | 检查请求体中分类字段取值是否在约定范围内，核对返回字段的分类统计 |
| 通知送达 | 送达状态是否明确，有无未送达或状态缺失 | 核对请求头与请求体中送达标识，检查响应体返回的送达状态字段 |

## 容易做错的三处

- 现象：承诺事项在记录中列出但未见回应时间。原因：请求体字段缺失或外部系统未回填回应时间，导致统计口径无法闭合。
- 现象：幼儿表现描述与观察记录存在出入。原因：记录时未对照原始观察材料，请求体字段取值与事实不符。
- 现象：家长诉求未归类或归入错误类别。原因：分类字段取值超出约定范围，外部系统收到空字段或无效值。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果；同时核对 `variables` 来源、`Authorization` 请求头与 `responseData` 返回字段是否与外部接口约定一致。

业务测试：用一周记录核对合计，看口径与例外是否写清，确认记录数与统计数对得上，口径写到表头。

- 在变量面板核对每个占位的来源，确认请求地址与路径参数能解析成实际值。
- 用一条样例请求比对返回，核对请求体字段与外部接口约定是否一致，检查返回字段是否完整。
