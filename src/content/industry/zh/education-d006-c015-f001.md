# 中小学心理健康筛查与转介的进度记录与统计核对：HTTP 接口

## 这个品类的数据长什么样

本页面向中小学心理健康筛查与转介场景，材料来自心理筛查方案、访谈记录、转介单三类。筛查方案提供名单与量表批次，访谈记录承载过程与签字，转介单记录去向与回执。三类材料进入 HTTP 接口时，分别作为请求体字段、路径参数与请求头鉴权信息的来源。更新节奏按周或按月汇总，字段特征集中在姓名、数量、日期与签字。进度表与统计口径说明需在表头写明统计范围、例外规则与数据来源，确保记录数与统计数对得上。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。「进度表与统计口径说明」由后续节点解析响应，或外部系统按约定处理接着完成。HTTP 节点不代替外部系统写库或审批。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 心理筛查方案 | 方案中的名单、量表批次、日期与签字须与访谈记录、转介单逐项对应 | 在请求预览里核对渲染后的完整地址，确认路径参数与请求体字段来自方案，并检查 `variables` 面板中每个占位的来源 |
| 访谈记录 | 同一记录在方案与转介单中的姓名、数量、日期应一致，签字与回执不可缺失 | 用一条样例请求比对返回，核对请求体字段与外部接口约定一致，并在变量面板核对 `responseData` 返回字段 |
| 转介单 | 转介单的回执状态、日期与签字须与筛查方案、访谈记录同步，版本未同步时以最新签字件为准 | 核对请求头名称与取值来源，确认 `Authorization` 按外部系统要求传入，再比对返回字段中的回执标记 |
| 进度表与统计口径说明 | 表头须写明统计范围、例外规则与数据来源，记录数与统计数对得上 | 用一周记录核对合计，检查口径与例外是否写清，并核对返回字段中的计数与日期 |

## 容易做错的三处

- 现象：同一记录在筛查方案与访谈记录里的姓名、数量、日期对不上。原因：两份材料各自更新，未做逐项核对与版本同步。
- 现象：转介单缺签字或回执，统计时被计入完成。原因：口径未写明例外规则，签字与回执字段未纳入核对。
- 现象：请求返回 401 或外部系统收到空字段。原因：鉴权信息未按外部系统要求传入，或变量占位未解析成实际值。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果；确认 `Authorization`、`variables`、`responseData` 三处占位均能追到具体出处。

业务测试：用一周记录核对合计，看口径与例外是否写清，确认记录数与统计数对得上。

- 在变量面板核对每个占位的来源，确认请求地址、请求头与请求体中的变量均解析成实际值。
- 用一条样例请求比对返回，检查请求体字段与外部接口约定一致，并核对返回字段中的计数与日期。
