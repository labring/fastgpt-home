# 职业院校人才培养方案制定的进度记录与统计核对：HTTP 接口

## 这个品类的数据长什么样

职业院校人才培养方案制定涉及三类材料：人才培养方案、课程标准、岗位能力分析表。人才培养方案含专业名称、学制、培养目标、课程结构、实施安排与审批签字；课程标准含课程名称、学时学分、目标、内容与考核方式；岗位能力分析表含岗位名称、能力项、对应课程与签字回执。材料来自教务、二级院系与专业建设委员会，更新节奏为学期初集中修订、学期中微调、学期末汇总。进入该功能时，人才培养方案作为主记录，课程标准与岗位能力分析表作为关联材料，各自提供字段、日期与签字信息，供进度记录与统计核对使用。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。进度表与统计口径说明由后续节点解析响应，或外部系统按约定处理接着完成。HTTP 节点不代替外部系统写库或审批。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 人才培养方案 | 字段、日期与签字齐全，名称与数量同课程标准一致 | 在请求预览里看渲染后的完整地址，核对 `variables` 来源 |
| 课程标准 | 学时学分与课程名称同人才培养方案对得上，版本同步 | 用一条样例请求比对返回，核对 `responseData` 字段 |
| 岗位能力分析表 | 岗位名称、能力项与对应课程同课程标准一致，签字或回执完整 | 核对请求头名称与取值来源，确认 `Authorization` 传入 |
| HTTP 请求 | 路径参数、请求体与请求头三处占位变量能解析成实际值 | 在变量面板核对每个占位的来源，比对返回字段 |

## 容易做错的三处

- 现象：同一记录在人才培养方案与课程标准里的名称、数量、日期对不上。原因：两份材料分别录入，未做字段级比对与统一口径。
- 现象：课程标准版本未同步，旧版学时学分仍被统计。原因：修订后未更新关联材料，进度记录仍指向旧版本。
- 现象：岗位能力分析表缺签字或回执，统计时被计入完成。原因：进度记录只记条目数，未核对签字字段与回执状态。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果；核对 `variables`、`responseData` 与 `Authorization` 三处占位来源。

业务测试：用一周记录核对合计，看口径与例外是否写清；记录数与统计数对得上，口径写到表头。

- 在变量面板核对每个占位的来源，确认请求地址、请求头与请求体中的变量能解析成实际值。
- 用一条样例请求比对返回，核对字段与外部接口的约定一致，并检查返回字段是否包含所需统计口径。
