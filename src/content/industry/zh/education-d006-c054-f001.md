# 自学考试考籍与毕业审核的进度记录与统计核对：HTTP 接口

## 这个品类的数据长什么样

本页聚焦自学考试考籍与毕业审核中的进度记录与统计核对，涉及考籍档案、课程合格证、毕业申请表三类材料。考籍档案由省级考办按考期归档，记录考生基本信息、准考证号、专业与主考院校；课程合格证按课程逐次生成，载明课程代码、名称、成绩与取得日期；毕业申请表在全部课程合格后提交，含姓名、身份证号、专业、课程门数、签字与回执。材料进入该功能时，考籍档案提供基础身份与专业口径，课程合格证提供逐门合格记录与日期，毕业申请表提供汇总门数与签字状态。更新节奏随考期与毕业申请批次推进，字段特征集中在姓名、课程名称、数量、日期与签字回执。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。「进度表与统计口径说明」由后续节点解析响应，或外部系统按约定处理接着完成。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 考籍档案 | 姓名、准考证号、专业与主考院校在档案与合格证、申请表之间名称一致、日期可追溯 | 核对字段与日期，比对两份材料中的姓名与专业写法 |
| 课程合格证 | 课程代码、名称、成绩与取得日期逐条对应，数量与申请表汇总门数一致 | 按课程逐条比对名称与日期，统计合格门数 |
| 毕业申请表 | 课程门数、姓名、身份证号与签字回执齐全，日期与合格证取得日期不冲突 | 检查签字与回执，核对汇总门数与合格证数量 |
| HTTP 节点输出 | 响应体、状态码与返回字段按约定返回，`responseData` 中的记录数与统计数对得上 | 在请求预览里查看渲染后的地址与请求体，用一条样例请求比对返回字段 |

## 容易做错的三处

- 现象：同一考生在两份材料里的姓名或课程名称写法不同。原因：录入批次不同，未按统一口径核对。
- 现象：课程合格证数量与毕业申请表汇总门数对不上。原因：部分合格证未同步或漏计，统计口径未写到表头。
- 现象：毕业申请表缺签字或回执，日期与合格证取得日期冲突。原因：材料流转中版本未同步，审核环节未回填。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果；在变量面板核对 `variables` 与 `Authorization` 来源，确认 `responseData` 记录数与统计数一致。

业务测试：用一周记录核对合计，看口径与例外是否写清。

- 在请求预览里查看渲染后的完整地址，核对路径参数与请求体字段是否与外部接口约定一致。
- 在变量面板核对每个占位的来源，确认 `variables`、`Authorization` 与 `responseData` 可追溯到全局变量、系统变量或前方节点输出。
