# 教师资格考试与认定的进度记录与统计核对：HTTP 接口

## 这个品类的数据长什么样

教师资格考试与认定涉及笔试面试报名表、普通话证书、体检表三类材料。报名表记录考试科目、场次与缴费状态；普通话证书标注等级与发证日期；体检表含体检结论、医师签字与医院回执。材料来自报名系统导出、证书扫描件与体检机构回执，按周或按月汇总更新。字段特征集中在姓名、证件号、科目名称、数量、日期与签字栏。进入进度记录与统计核对功能时，报名表承担记录数与科目口径的基准，普通话证书与体检表作为资格条件附件参与核对，三者共同支撑进度表与统计口径说明的产出，并进入周报或月报。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。「进度表与统计口径说明」由后续节点解析响应，或外部系统按约定处理接着完成。请求地址、路径参数、请求体与请求头均可通过 `variables` 引用全局变量、系统变量或前方节点输出。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 笔试面试报名表 | 字段含姓名、证件号、科目、场次与缴费状态，日期与签字齐全 | 核对报名表记录数与统计合计是否一致，科目名称与日期是否逐条对应 |
| 普通话证书 | 字段含等级、发证日期与证书编号，签字或电子回执完整 | 核对证书编号与报名表姓名、日期是否对得上，版本是否同步 |
| 体检表 | 字段含体检结论、医师签字与医院回执日期 | 核对体检表数量与统计口径说明表头，缺签字或回执单独标注 |
| HTTP 节点请求 | 请求地址、请求头与请求体字段同外部接口约定一致 | 在请求预览里看渲染后的完整地址，核 `Authorization` 与 `responseData` 返回字段 |

## 容易做错的三处

- 现象：同一考生在报名表与体检表里的姓名或日期对不上。原因：两份材料分别录入，版本未同步，缺少统一核对环节。
- 现象：普通话证书数量与统计合计不一致。原因：证书扫描件未及时归档，统计时漏计或重复计入。
- 现象：体检表缺医师签字或医院回执。原因：材料流转环节未设签字确认，回执未随表返回。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果。

业务测试：用一周记录核对合计，看口径与例外是否写清。

- 在变量面板核对每个占位的来源，确认请求头名称与取值来源，并检查请求体字段与外部接口约定一致。
- 用一条样例请求比对返回，确认 `variables`、`Authorization` 与 `responseData` 均能追到具体出处。
