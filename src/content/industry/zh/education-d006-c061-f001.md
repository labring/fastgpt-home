# 科研成果登记与知识产权管理的进度记录与统计核对：HTTP 接

## 这个品类的数据长什么样

科研成果登记与知识产权管理涉及三类材料：成果登记表、专利交底书、软件著作权材料。成果登记表字段含成果名称、完成人、日期与签字；专利交底书含技术名称、发明人、申请日与回执；软件著作权材料含软件名称、版本号、著作权人与签章。材料来自研发、法务与科研管理部门，按周或按月汇总更新。进入本功能时，成果登记表承担记录主键与统计基数，专利交底书提供申请进度与外部回执，软件著作权材料补充权利归属与版本信息。三类材料在名称、数量、日期与签字上需交叉对齐，HTTP 节点负责把汇总请求发往外部系统，返回字段供后续节点核对。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。进度表与统计口径说明由后续节点解析响应，或外部系统按约定处理接着完成。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 成果登记表 | 字段、日期与签字是否齐全，记录数能否与统计数对上 | 核对成果名称、完成人、日期与签字栏，比对周报合计 |
| 专利交底书 | 技术名称、申请日与回执是否与登记表一致 | 用一条样例请求比对返回字段，检查日期与回执编号 |
| 软件著作权材料 | 软件名称、版本号与签章是否同步更新 | 核对版本号与签章，确认与登记表名称一致 |
| HTTP 请求 | 请求地址、请求头与请求体中的占位变量能否解析成实际值 | 在请求预览里看渲染后的完整地址，核对 `Authorization`、`variables` 与 `responseData` 来源 |

## 容易做错的三处

- 现象：同一成果在登记表与交底书里的名称、数量或日期对不上。原因：两份材料由不同节点分别填报，未按同一记录主键对齐。
- 现象：软件著作权材料的版本号与登记表不一致，回执缺失。原因：版本未同步，签字或回执未随材料更新。
- 现象：请求返回 401 或外部系统收到空字段。原因：请求头鉴权信息未按外部系统要求传入，或占位变量未解析成实际值。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果，确认 `responseData` 与约定字段一致。

业务测试：用一周记录核对合计，看口径与例外是否写清，确认记录数与统计数对得上。

- 在变量面板核对每个占位的来源，确认 `Authorization`、`variables` 与 `responseData` 都能追到全局变量、系统变量或前方节点输出。
- 核对请求头名称与取值来源，用一条样例请求比对返回，检查外部系统是否收到空字段。
