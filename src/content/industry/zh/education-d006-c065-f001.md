# 实验室危化品采购与台账的进度记录与统计核对：HTTP 接口

## 这个品类的数据长什么样

实验室危化品采购与台账涉及采购申请、领用登记、库存台账三类材料。采购申请记录品名、规格、数量、申请日期与审批签字；领用登记记录领用人、领用数量、领用日期与保管签字；库存台账记录结存数量、日期与盘点签字。材料按周或按月汇总，字段以名称、数量、日期、签字为主。进入该功能时，采购申请与领用登记作为请求体字段来源，库存台账作为核对基准，三者通过 HTTP 接口与外部系统交换数据，进度表与统计口径说明由后续节点解析响应或外部系统按约定处理完成。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。进度表与统计口径说明由后续节点解析响应，或外部系统按约定处理接着完成。HTTP 模块向目标地址发请求，路径参数、请求体与请求头三处都能用变量占位，变量来自全局变量、系统变量或前方节点输出。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 采购申请 | 名称、数量、日期与签字是否与领用登记一致 | 核对请求体字段与外部接口约定，用一条样例请求比对返回 |
| 领用登记 | 领用数量与日期是否与库存台账对得上 | 在变量面板核对每个占位的来源，确认 `variables` 能解析成实际值 |
| 库存台账 | 结存数量与盘点日期是否与两份材料版本同步 | 在请求预览里看渲染后的完整地址，检查 `Authorization` 与返回字段 |
| HTTP 返回体 | 状态码与返回字段是否覆盖进度记录所需字段 | 用 `responseData` 字段与样例比对，确认统计口径写到表头 |

## 容易做错的三处

- 现象：同一记录在采购申请与领用登记里的名称、数量对不上。原因：请求体字段未按外部接口约定映射，变量来源未逐一核对。
- 现象：库存台账与领用登记日期不一致，版本未同步。原因：前方节点输出未更新，请求头鉴权信息与外部系统要求不符。
- 现象：缺签字或回执，统计数对不上。原因：外部系统收到空字段，返回体未按约定回写，后续节点未解析响应。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果，确认 `Authorization`、`variables`、`responseData` 三处占位均可追溯。

业务测试：用一周记录核对合计，看口径与例外是否写清，确认记录数与统计数对得上、口径写到表头。

- 在请求预览里核对渲染后的完整地址与请求头名称，确认路径参数与请求体字段与外部接口约定一致。
- 在变量面板核对每个占位的来源，用一条样例请求比对返回字段，确认统计口径与例外情况写入表头。
