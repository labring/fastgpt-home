# 幼儿园家园共育沟通的授权访问与对外服务：HTTP 接口

## 这个品类的数据长什么样

幼儿园家园共育沟通的材料包括通知、幼儿表现观察记录、家长诉求与承诺回应。这些材料进入 HTTP 接口与外部系统时，通知进入请求体等待送达确认，观察记录与家长诉求作为变量来源参与字段填充，承诺回应则需外部系统按约定处理。材料由班级教师与家长在沟通中产生，更新节奏随每日活动与家长反馈变化。字段特征上，通知含标题、正文与接收范围，观察记录含时间、场景与行为描述，家长诉求含分类与期望回应时间。这些材料共同构成可对外的入口与授权范围，访问者身份与可见范围需匹配，越权不可见。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。可对外的入口与授权范围由后续节点解析响应，或外部系统按约定处理接着完成。HTTP 模块向目标地址发请求，路径参数、请求体与请求头三处都能用变量占位，变量来自全局变量、系统变量或前方节点输出。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 请求地址与路径参数 | 占位变量能解析成实际值，且与家长或上级可见范围匹配 | 在请求预览里看渲染后的完整地址，核对 `variables` 来源 |
| 请求头 | 鉴权信息按外部系统要求传入，越权身份不可见 | 核对 `Authorization` 名称与取值来源，确认与访问者身份一致 |
| 请求体 | 字段与外部接口的约定一致，承诺事项与回应时间、幼儿表现描述、家长诉求分类、通知送达均落在对应字段 | 用一条样例请求比对返回，检查 `responseData` 中字段是否齐全 |
| 变量来源 | 每个占位都能追到具体出处，观察记录与家长诉求不混淆 | 在变量面板核对每个占位的来源，确认无空字段 |

## 容易做错的三处

- 现象：承诺未回应。原因：请求体未包含回应时间字段，外部系统无法按约定触发回执。
- 现象：表述与观察记录不符。原因：变量来源指向错误节点，通知正文与观察记录字段被混用。
- 现象：反馈未归类。原因：家长诉求分类字段在请求体中缺失，后续节点无法解析响应并归入对应类别。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果，确认 `responseData` 与 `Authorization` 取值正确。

业务测试：用受限身份访问一次，看可见范围是否符合设定。

- 在请求预览里核对渲染后的完整地址与路径参数，确认每个占位变量可追到全局变量、系统变量或前方节点输出。
- 用一条样例请求比对返回，检查请求头名称与取值来源，确认鉴权信息与外部接口约定一致。
