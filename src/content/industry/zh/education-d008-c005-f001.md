# 幼儿园安全防护与应急演练的授权访问与对外服务：HTTP 接口

## 这个品类的数据长什么样

幼儿园安全防护与应急演练涉及隐患项与整改期限、演练人数与签到、门禁与校车检查项、责任人签字等材料，通常由园所安全负责人按周或按月汇总，经上级审核后形成对外服务内容。这些材料进入 HTTP 接口与外部系统功能时，隐患项与整改期限作为请求体字段，演练人数与签到作为路径参数或请求体，门禁与校车检查项作为请求头鉴权后的可见范围依据，责任人签字作为返回字段的确认标识。材料来源为园所日常巡检记录、演练方案与签到表、门禁与校车检查台账，更新节奏随安全例会与演练周期变动。字段特征包括隐患编号、整改截止日期、演练参与人数、签到状态、检查项结果、签字状态等，需通过授权访问控制对外服务范围，确保家长或上级仅见匹配身份的内容。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。可对外的入口与授权范围由后续节点解析响应，或外部系统按约定处理接着完成。HTTP 模块向目标地址发请求，路径参数、请求体与请求头三处都能用变量占位，变量来自全局变量、系统变量或前方节点输出。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 请求地址与路径参数 | 占位变量能解析成实际值，且路径参数中的演练人数与签到标识与外部接口约定一致 | 在请求预览里看渲染后的完整地址，核对路径参数是否对应园所与演练场次 |
| 请求头 | 鉴权信息按外部系统要求传入，且可见范围与访问者身份匹配 | 核对请求头名称与取值来源，确认`Authorization`携带的令牌对应家长或上级角色 |
| 请求体 | 字段与外部接口的约定一致，隐患项与整改期限、责任人签字等字段完整 | 用一条样例请求比对返回，检查隐患未闭环或检查项漏项是否被拒绝 |
| 变量来源 | 每个占位都能追到具体出处，`variables`与`responseData`可追溯 | 在变量面板核对每个占位的来源，确认来自全局变量、系统变量或前方节点输出 |

## 容易做错的三处

- 现象：隐患项与整改期限在返回中缺失或未闭环。原因：请求体字段未按约定传入，或后续节点未解析`responseData`中的整改状态。
- 现象：演练记录与方案不符，签到人数与路径参数不一致。原因：路径参数占位变量解析成旧值，或请求头鉴权范围未限制到对应演练场次。
- 现象：门禁与校车检查项漏项，责任人签字未回传。原因：请求体字段与外部接口约定不一致，或`variables`引用错误导致空字段提交。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果，确认`Authorization`、`variables`、`responseData`均按预期解析。

业务测试：用受限身份访问一次，看可见范围是否符合设定，越权内容不可见。

- 在请求预览中检查渲染后的完整地址与路径参数，确认占位变量解析成实际值。
- 核对请求头名称与取值来源，确认鉴权信息按外部系统要求传入。
