# 职业学校学生实习管理的授权访问与对外服务：HTTP 接口

## 这个品类的数据长什么样

职业学校学生实习管理材料含实习协议、实习计划、实习日志，来源为教务、实习指导教师与企业带教三方，更新节奏随实习批次与月度节点推进。实习协议载明岗位、期限、责任与签字，实习计划载明轮岗安排、日期与带教人，实习日志按日或周记录岗位、任务、时长与回执。材料进入 HTTP 接口与外部系统时，协议作为授权依据决定可见范围，计划作为排期依据决定时间字段，日志作为过程依据决定明细字段。三类材料在名称、数量、日期与签字上须逐项对齐，同一记录在两份材料里的字段对不上即视为不一致，版本未同步或缺签字、回执时不得作为对外服务依据。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。可对外的入口与授权范围由后续节点解析响应，或外部系统按约定处理接着完成。HTTP 节点不代替外部系统写库或审批，只把请求送达并取回结果。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 实习协议 | 协议中的学生姓名、岗位名称、起止日期与签字须与实习计划一致，缺签字或回执视为不可对外 | 在请求预览里看渲染后的完整地址，核对路径参数与请求体字段是否取自协议，并用一条样例比对返回 |
| 实习计划 | 计划中的轮岗部门、带教人、日期与数量须与实习日志逐项对齐，版本未同步时不得作为授权依据 | 核对请求头名称与取值来源，确认 `Authorization` 按外部系统要求传入，再在变量面板核对每个占位的来源 |
| 实习日志 | 日志中的日期、任务名称、时长与回执须与协议、计划对得上，同一记录在两份材料里对不上即判为不一致 | 用一条样例请求比对返回，检查 `responseData` 中字段与日志约定是否一致，并记录 `variables` 的出处 |
| 授权范围 | 访问者身份与可见范围匹配，越权不可见，家长或上级仅见约定字段 | 用受限身份访问一次，看可见范围是否符合设定，并核对状态码与返回字段 |

## 容易做错的三处

- 现象：请求返回 401。原因：鉴权信息未按外部系统要求传入请求头，或协议签字缺失导致授权依据不完整。
- 现象：外部系统收到空字段。原因：变量占位未解析成实际值，或实习计划与日志版本未同步、日期对不上。
- 现象：请求超时。原因：目标地址不可达或路径参数取值有误，且同一记录在两份材料里的名称、数量不一致。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果；确认 `Authorization`、`variables`、`responseData` 三处引用可追溯。

业务测试：用受限身份访问一次，看可见范围是否符合设定，越权内容不可见，家长或上级仅见约定字段。

- 在请求预览里核对渲染后的完整地址与路径参数，确认占位变量能解析成实际值。
- 在变量面板核对每个占位的来源，检查请求头名称与取值来源，并用一条样例请求比对返回字段。
