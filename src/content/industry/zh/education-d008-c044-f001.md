# 培训机构教务排课与消课的授权访问与对外服务：HTTP 接口

## 这个品类的数据长什么样

培训机构教务排课与消课材料进入 HTTP 接口与外部系统时，主要涉及课表、消课记录、调课申请三类。课表含课程名称、上课日期、时段、教室与教师签字；消课记录含学员名称、消课数量、消课日期与家长回执；调课申请含原课次、目标课次、申请日期与审批签字。材料来源为教务系统导出与纸质签字件，更新节奏按周或按次同步。进入该功能后，课表作为对外入口的可见范围依据，消课记录作为对外服务的数据字段，调课申请作为授权变更的触发材料，三者共同决定访问者身份与可见范围是否匹配。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。「可对外的入口与授权范围」由后续节点解析响应，或外部系统按约定处理接着完成。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 课表 | 字段、日期与签字是否与教务系统导出件一致 | 在请求预览里看渲染后的完整地址，核对课表字段与签字日期 |
| 消课记录 | 名称、数量、日期是否与家长回执对得上 | 核对请求体字段与外部接口约定，用一条样例请求比对返回 |
| 调课申请 | 版本是否同步、是否缺签字或回执 | 在变量面板核对每个占位的来源，确认申请日期与审批签字 |
| 请求头 | 鉴权信息按外部系统要求传入 | 核对 `Authorization` 名称与取值来源，确认 `variables` 与 `responseData` 引用 |

## 容易做错的三处

- 现象：同一消课记录在教务系统与家长回执里的名称、数量、日期对不上。原因：两份材料未按同一版本同步，字段取值来源不同。
- 现象：调课申请缺签字或回执，对外入口仍可见。原因：授权范围未按材料完整性校验，版本未同步。
- 现象：请求返回 401 或外部系统收到空字段。原因：`Authorization` 取值来源错误，或 `variables` 未解析成实际值。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果；确认 `Authorization`、`variables`、`responseData` 三处引用可追溯。

业务测试：用受限身份访问一次，看可见范围是否符合设定

- 在变量面板核对每个占位的来源，确认课表、消课记录、调课申请字段与日期一致
- 用一条样例请求比对返回，核对外部接口约定的字段与签字回执
