# 中外合作办学机构设立与年报的授权访问与对外服务：HTTP 接

## 这个品类的数据长什么样

中外合作办学机构设立与年报材料，主要包含设立申请书、合作协议、章程，以及年报填报与回执。设立申请书给出机构名称、办学层次、专业与招生规模；合作协议约定各方权责、投入方式与期限；章程写明治理结构、决策程序与签署页。材料通常按学年或审批批次更新，字段集中在名称、数量、日期、签字与盖章。进入授权访问与对外服务功能时，设立申请书与合作协议提供身份与范围依据，章程与回执提供签署与版本凭证，年报数据则作为对外服务中按身份可见的内容来源。

## 配置怎么定

这一环由工作流里的 HTTP 节点执行，输出响应体、状态码与返回字段。可对外的入口与授权范围由后续节点解析响应，或外部系统按约定处理接着完成。HTTP 节点只负责发请求与回传结果，不代替外部系统写库或审批。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 设立申请书 | 名称、数量、日期与签字是否与合作协议一致 | 取两份材料逐字段比对，缺签字或回执的记为待补 |
| 合作协议 | 同一记录的名称、数量、日期是否与章程对得上 | 核对签署页与版本号，确认无未同步的旧版本 |
| 章程 | 治理结构与决策程序字段是否与年报口径一致 | 检查签署与盖章页，核对回执是否齐全 |
| HTTP 请求 | 请求地址、请求头与请求体能否按约定解析 | 在请求预览里看渲染后的完整地址，核对 `Authorization`、`variables` 与 `responseData` 的来源 |

## 容易做错的三处

- 现象：同一机构名称在设立申请书与合作协议里写法不同。原因：两份材料各自维护，版本未同步，缺少统一字段口径。
- 现象：招生数量与日期在年报与章程附件中对不上。原因：更新节奏不一致，旧版本未作废，回执未归档。
- 现象：请求返回 401 或外部系统收到空字段。原因：鉴权信息与请求体字段未按外部接口约定传入，变量来源未核对。

## 怎么确认配好了

本功能验收：预览渲染后的请求，核状态码与返回字段，再对一条样例比对结果。

业务测试：用受限身份访问一次，看可见范围是否符合设定。

- 在变量面板核对每个占位的来源，确认 `Authorization` 与 `variables` 能解析成实际值。
- 用一条样例请求比对返回，检查 `responseData` 字段与外部接口约定是否一致。
