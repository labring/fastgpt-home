# 中小学心理健康筛查与转介的多语资料与术语处理：检索召回

## 这个品类的数据长什么样

本页面向中小学心理健康筛查与转介场景，材料包括心理筛查方案、访谈记录、转介单三类。心理筛查方案规定量表选择、筛查维度、预警分级与转介标准，进入知识库后作为术语锚点，用于统一量表名称、维度名称与分级表述。访谈记录承载学生主诉、教师观察与家长反馈，进入知识库后作为术语的上下文来源，用于确认同一概念在不同记录中的实际写法。转介单记录转介事由、接收机构、回执与签字，进入知识库后作为术语的落地凭证，用于核对名称、数量、日期与签字是否与方案、访谈记录一致。三类材料更新节奏不同：方案按学期或政策调整更新，访谈记录随个案产生，转介单随转介流程更新。字段特征上，方案侧重分级与标准条目，访谈记录侧重时间、对象与描述，转介单侧重编号、日期、签字与回执。多语资料与术语处理时，需保证同一术语在全篇写法一致，译名能回指原文。

## 配置怎么定

这一环由知识库检索服务（检索节点与搜索测试）执行，输出候选片段与相似度得分（经模式、合并、重排、过滤与上限裁剪）。「统一术语表与对照稿」由后续节点或人工接着完成。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 心理筛查方案 | 量表名称、维度名称、分级表述与转介标准在全篇写法一致，译名能回指原文 | 在知识库搜索测试中切换 `searchMode`，用同义问句各测一次，记录候选条数与得分；核对方案中同一术语在不同段落是否同写 |
| 访谈记录 | 同一记录在方案与转介单中的名称、数量、日期对不上时，先核命中与关联 | 用 `similarity` 过滤后查看候选片段是否保留原文关键描述；核对访谈记录中的日期、对象与方案、转介单是否一致 |
| 转介单 | 转介事由、接收机构、回执与签字字段完整，版本与方案同步 | 开启 `usingReRank` 前后对比前几条排序；核对转介单编号、日期、签字与回执是否与方案、访谈记录对应 |
| 知识库检索服务 | 候选片段与相似度得分经模式、合并、重排、过滤与上限裁剪后返回 | 查看返回候选是否同时包含语义与全文结果；`limit` 控制引用文本 token 预算，引用文本的 tokens 单独记录，不与数组条数做相等比较 |

## 容易做错的三处

- 现象：同一记录在方案与转介单里的名称、数量、日期对不上。原因：多语资料与术语处理未统一，同一概念在不同材料中写法不同，检索命中后未核对关联。
- 现象：版本未同步，方案更新后访谈记录与转介单仍沿用旧术语。原因：材料更新节奏不同，知识库未按版本重新导入或重新索引，检索仍召回旧片段。
- 现象：转介单缺签字或回执，术语表与对照稿无法回指原文。原因：转介流程字段未补齐，检索返回的候选片段缺少关键凭证，后续节点或人工无法据此生成完整成品。

## 怎么确认配好了

本功能验收：用同义改写的问句各测一次，对比候选与得分，再开关重排看前几条排序。切换 `searchMode` 观察语义、全文与混合的候选差异；开启 `usingReRank` 前后对比前几条顺序；用 `similarity` 过滤后记录候选条数与得分，`limit` 控制引用文本 token 预算，引用文本的 tokens 单独记录。

业务测试：抽三条术语查全篇写法是否一致，确认译名能回指原文，并核对心理筛查方案、访谈记录、转介单的字段、日期与签字是否对应。

- 在知识库搜索测试中切换 `searchMode`，用同义问句各测一次，记录候选条数与得分，对比语义、全文与混合的召回差异。
- 开启 `usingReRank` 前后对比前几条排序，用 `similarity` 过滤后查看候选片段是否保留原文关键描述，`limit` 控制引用文本 token 预算并单独记录引用文本的 tokens。
