# 科研项目年度进展与验收的多语资料与术语处理：文档解析与分块

## 这个品类的数据长什么样

科研项目年度进展与验收材料，涵盖年度进展报告、中期检查材料、验收报告三类。年度进展报告按周期提交，记录阶段任务、指标与人员；中期检查材料侧重节点对照与调整说明；验收报告汇总全周期成果、经费与签字回执。来源为项目组多语种原始记录与翻译稿，更新随检查节点滚动。字段特征：同一记录的名称、数量、日期、签字在多份材料间需一致，译名需回指原文。材料进入文档解析与分块时，年度进展报告与中期检查材料作为待索引数据行参与初次训练，验收报告在索引完成后供检索与后续处理生成统一术语表与对照稿。

## 配置怎么定

解析与训练任务（服务端任务）只输出数据行与索引状态（已解析、索引中、已完成），统一术语表与对照稿要由检索与后续处理接着做。解析分块在解析完成后立即落库为可见数据行并绑定唯一数据标识，索引按三态流转；待索引数据不参与召回，换模型只对已完成索引的数据重建。

| 对象 | 判断 | 核验动作 |
| --- | --- | --- |
| 年度进展报告 | 同一记录的名称、数量、日期在中期检查材料与验收报告中需一致，签字与回执不可缺失 | 核对数据行状态是否为 parsed / indexing / indexed，并查看 `chunkSize` 与 `chunkSplitter` 对应分块是否覆盖该记录 |
| 中期检查材料 | 版本需与年度进展报告同步，同一术语译名全篇一致且能回指原文 | 分别核对文件记录与数据行标识，确认 `trainingType` 对应训练模式，抽三条术语查全篇写法是否一致 |
| 验收报告 | 字段、日期与签字齐全，同一记录在两份材料里的名称、数量、日期对得上 | 看重建任务覆盖的数据行是否只含已完成索引的数据，核对签字与回执字段 |
| 统一术语表与对照稿 | 术语全篇一致、译名能回指原文，引用条数与引用文本 tokens 分别记录 | 抽三条术语查全篇写法是否一致，核对引用条数为数组长度，引用内容预算看 `quoteMaxToken` 对应 tokens |

## 容易做错的三处

- 现象：同一记录在年度进展报告与验收报告里的名称、数量、日期对不上。原因：多语资料未统一术语，分块后各材料独立落库，缺少跨材料对照。
- 现象：中期检查材料版本未同步，签字或回执缺失。原因：材料更新后未重新解析落库，旧数据行仍处于已完成索引状态，检索层召回旧版本。
- 现象：刚上传的材料搜不到，训练失败后留下空数据行。原因：数据行处于待索引状态不参与召回，训练中断残留孤儿数据，需重试或删除后重新解析。

## 怎么确认配好了

本功能验收：上传一份材料，看数据行状态流转与重建任务的覆盖范围，确认解析完成后立即落库为可见数据行，索引按 parsed / indexing / indexed 三态流转，换模型只对已完成索引的数据重建。

业务测试：抽三条术语查全篇写法是否一致，核对译名能否回指原文，并确认引用条数为数组长度、引用内容预算按 `quoteMaxToken` 对应 tokens 单独记录。

- 打开数据行核对状态，确认与界面显示一致，并分别核对文件记录与数据行标识。
- 查看重建任务覆盖的数据行，确认只含已完成索引的数据，待索引数据不参与重建链。
