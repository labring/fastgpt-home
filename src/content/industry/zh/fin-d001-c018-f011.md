# 养殖业农业保险材料的解析与分块：格式、表格与字段抽取

## 这个品类每天在处理什么材料
这个品类日常处理的材料包括养殖户资料、承保清单、耳标、个体识别或批次资料、存栏记录、检疫材料、死亡证明、扑杀证明、无害化处理证明、查勘定损和赔款资料。数据主要来自养殖场或农户、畜牧兽医及检疫资料、个体识别和存栏系统、无害化处理记录、农险系统。各类材料的更新频率存在差异：存栏记录随生产过程变动，个体识别或批次资料在新增、出栏或死亡时触发更新，检疫材料随检疫事件生成，死亡及无害化处理证明则在出险事件发生后产生。部分材料为结构化表格，部分为纸质扫描件或图片，形态差异显著。

## 这些材料在「文档解析与分块」这一环带来什么约束
不同类型的材料给文档解析与分块环节带来多重约束。多格式材料需要支持结构化表格、非结构化文本、图片等多模态解析，避免遗漏关键信息。高频更新的出险类材料需要适配实时处理需求，保障解析时效性。核心业务关联的材料，如承保清单与个体识别资料，需要在分块时保留跨文档的字段关联，避免割裂业务逻辑。部分材料的字段密度较高，需要合理控制分块粒度，防止关键关联信息被拆分。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 常见取法，需按材料字段密度、关联信息长度实际标定 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 覆盖多格式解析、批量材料处理的常见耗时，需按单批次材料量调整 |
| `字段抽取精度阈值` | 0.75–0.85 | 平衡抽取准确性与召回率的常见区间，需按核心字段重要性调整 |
| `多模态解析开关` | 开启 | 适配耳标图片、纸质扫描件的解析需求，需按材料占比配置 |
| `关联块保留开关` | 开启 | 保留跨文档的字段关联信息，避免割裂业务关联逻辑 |
| `召回条数` | 前3–5条 | 匹配核心核验环节的关联材料数量，需按实际关联复杂度调整 |

## 最耗时的环节会卡在哪
最耗时的三个环节中，文档解析与分块可分别覆盖部分工作。在承保清单与存栏、个体识别或批次资料的交叉核验环节，可自动抽取两类材料的个体标识、存栏数量等字段，替代手动提取基础信息的步骤，但无法自动校验耳标与个体识别信息的匹配性，失败形态为抽取的字段与原件对不上，需人工回退重做。在查明死亡、疫病或扑杀原因及保险责任环节，可抽取死亡证明、检疫材料中的核心原因信息，替代手动整理的步骤，但无法结合保险条款完成责任判定，失败形态为抽取字段为空，无法支撑后续判定。在核对死亡个体、检疫或无害化处理与赔款对象的环节，可提取死亡个体的标识、无害化处理的批次信息，替代手动核对的基础步骤，但无法确认赔款对象与个体的绑定关系，失败形态为召回不到对应关联材料，需人工重新核验。

## 做错了会怎样
解析与分块环节出错会引发多重后果。业务层面可能出现虚构存栏、重复承保或死亡原因误判造成的损失；合同层面可能因保险个体和责任认定错误引发争议；监管层面可能因虚假承保理赔被处理；农户层面可能因漏赔或身份匹配错误引发投诉。容易引发这些后果的配置失误包括：分段长度过短切断了承保清单与个体识别的关联字段，召回条数过低漏掉关键的检疫或无害化材料，未开启关联块保留导致跨文档信息割裂，未开启多模态解析导致耳标等图片材料无法抽取，字段抽取阈值过低导致核心字段为空。

## 与相邻品类的区别
与种植业农业保险相比，本品类的核心主键为“动物/批次—存栏—检疫—死亡—无害化”，业务逻辑围绕个体或批次的全链路信息展开。种植业的核心关联逻辑则侧重地块、种植周期、遥感监测等维度，无法直接套用本品类的解析与分块配置。若将同一套配置迁移至种植业，会无法匹配核心业务关联规则，导致字段抽取和关联校验失效，无法支撑后续业务环节。

## 还需要按机构实际情况确认的
- 耳标并非所有养殖险种唯一识别方式，不同地区、险种的个体识别方式可能存在差异，需结合机构承保的具体险种核实。
- 无害化处理作为理赔条件的具体适用范围需按地方政策和保险条款核实，不同地区的政策要求、不同保险条款的适用规则存在差异，需结合机构实际承保条款调整。
