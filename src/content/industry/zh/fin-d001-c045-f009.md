# 种植业农业保险答复的溯源：引用范围、角标与原文定位

## 这个品类每天在处理什么材料
日常处理的材料包含投保及承保清单、农户和经营主体资料、地块和种植面积资料、作物信息、保单、灾害证明、查勘影像、定损表、公示和赔款资料。数据来源涵盖农户/合作社、农业农村部门、地块/GIS/遥感、气象、农险系统。各类材料形态存在差异，投保清单、农户资料多为结构化文本，地块和种植面积资料、GIS数据为空间格式，查勘影像、灾害证明为多媒体格式，不同材料的解析和关联逻辑存在区别。数据更新频率各有不同，承保地块和作物信息随农事及投保事件更新，气象数据持续监测更新，灾害相关遥感影像在灾害事件触发时更新，面积和产量数据按生产季节及查勘更新。

## 这些材料在「引用来源与溯源」这一环带来什么约束
不同材料的格式差异要求解析模块适配多种类型，跨来源的数据需要建立统一关联索引，确保不同来源的信息能准确绑定。更新频率的差异要求区分实时数据和静态数据的缓存策略，避免使用过期的气象或地块数据。不同材料的关联逻辑存在区别，需明确地块、作物、投保清单之间的主键关联规则，避免错误绑定非对应主体的资料。同时，多媒体类材料的解析需要额外的适配步骤，确保影像、空间数据能被正确提取并关联到对应业务环节。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | 前10-15条 | 覆盖主要关联材料，常见取法，需按实际材料标定 |
| `相似度阈值` | 0.75-0.85 | 平衡精准度和召回率，常见取法，需按实际材料标定 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300-600秒 | 处理大体积查勘影像、GIS文件的耗时需求，常见取法，需按实际材料标定 |
| `分段长度` | 800-1200字符 | 保留文档完整语义单元，常见取法，需按实际材料标定 |
| `重排返回条数` | 前5-8条 | 聚焦核心关联材料，常见取法，需按实际材料标定 |

## 最耗时的环节会卡在哪
投保清单与地块、作物和面积逐项核验环节，需逐一匹配多份材料的关联字段，溯源功能可辅助召回对应地块、作物资料，但无法自动完成跨主体的身份校验。做不好时会出现召回不到对应地块资料、抽取的种植面积字段为空，导致核验流程停滞。灾害后结合现场、遥感和气象资料界定受灾范围环节，需整合多源时空数据，溯源功能可快速关联遥感影像与气象监测记录，但无法自动校准空间坐标偏差。做不好时会出现结果与原件对不上、解析过程超时中断，导致受灾范围界定失误。把损失测定结果与农户清单、保险责任逐笔匹配环节，需核对损失数据与保单责任条款，溯源功能可召回对应定损表与保单内容，但无法自动判定责任适配性。做不好时会出现需要人工回退重做、抽取的保险责任字段为空，导致匹配流程延误。

## 做错了会怎样
溯源环节出错会引发多类后果：业务层面，虚构地块、面积或损失会造成赔款或补贴风险；合同层面，作物、面积和责任期间的错误会产生理赔争议；监管层面，虚假承保理赔行为可被监管处理；农户层面，漏损或支付对象错误会引发集中投诉。易引发这些后果的配置失误包括：召回条数过低导致漏掉关键的灾害证明或地块资料，未开启溯源功能导致答复无法回查原件核对，分段长度设置过短切断了完整的保险责任条款，相似度阈值设置过高导致无法召回必要的关联材料。

## 与相邻品类的区别
与养殖业农业保险相比，种植业农业保险的核查主键为地块—作物—面积—灾害—产量/损失，更依赖遥感、气象和空间数据的关联匹配，不使用个体动物身份标识。因此针对种植业的溯源配置需侧重空间数据解析与多源时空数据关联，若直接沿用养殖业的配置，会因缺乏空间数据适配模块导致关联失效。

## 还需要按机构实际情况确认的
- 不同作物的损失测定方法由险种和地区标准决定，不同机构的经营险种、覆盖地区存在差异，需确认对应作物的损失判定规则与关联文档。
- 遥感是否作为必备数据并非所有业务统一要求，不同机构的业务流程、监管要求存在差异，需确认是否需要强制关联遥感资料作为溯源依据。
