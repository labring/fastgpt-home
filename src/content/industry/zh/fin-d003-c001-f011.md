# ETF 投资与运营材料的解析与分块：格式、表格与字段抽取

## 这个品类每天在处理什么材料
这个品类日常处理的材料包括指数成分文件、申购赎回清单PCF、现金替代及补退资料、一级市场申赎文件、调仓指令、跟踪误差、基金公告。数据来源覆盖指数公司、交易所行情及ETF业务数据、中国结算、公司行动、托管估值系统。不同材料的更新频率存在差异，行情/二级交易数据在交易时段实时更新，PCF按ETF业务日生成，一级申赎文件随业务日事件触发，指数调整由指数机构事件触发，估值数据则按基金估值日生成。各类材料形态差异明显，包含结构化表格、公告类文本、实时数据流与指令类文件。

## 这些材料在「文档解析与分块」这一环带来什么约束
各类材料在文档解析与分块环节带来多重约束。结构化材料如PCF、一级市场申赎文件需精准抽取固定字段，对分块的边界控制要求较高；实时行情类材料需适配低延迟解析，避免超时影响业务流程；多源关联材料如调仓指令与公司行动公告，需保留上下文关联以确保信息完整；不同材料的格式规范差异大，需适配多样的解析规则；高频更新的材料需避免重复解析，提升处理效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 常见取法，需按实际材料的段落长度、字段密度标定，适配结构化表格与公告类文档的分块需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 常见取法，需按单份最大文档的实际解析时长调整，覆盖多数批量处理场景 |
| `召回条数` | 前 3–5 条 | 常见取法，需按实际业务关联文档的数量标定，覆盖核心关联信息 |
| `字段抽取匹配阈值` | 0.85–0.95 | 常见取法，平衡抽取准确率与召回率，需按不同文档的字段规范调整 |
| `maxContext` | 2000–3000 字符 | 常见取法，保留关键上下文关联，避免切断跨文档的业务逻辑，需按材料的上下文依赖程度标定 |

## 最耗时的环节会卡在哪
最耗时的三个环节中，文档解析与分块可分别提供部分支持。编制和核对PCF、现金替代及一级市场申赎参数时，该功能可自动抽取结构化表格中的申赎比例、成分股数量等字段，但无法自动校验参数合规性，若召回不到对应文档、抽取字段为空，会导致核对中断。执行指数成分调整并处理停牌/公司行动时，可快速定位调仓指令与公告中的调整条款，但无法判断替代方案合理性，若结果与原件对不上，需人工回退重做。持续核查一级申赎、二级价格、持仓及跟踪误差时，可批量整理多源数据的分块内容，但无法自动识别异常波动关联逻辑，若超时中断会导致核查流程停滞。

## 做错了会怎样
解析与分块环节出错会引发多重后果。业务层面，PCF或现金替代字段抽取错误会影响一级申赎和套利流程；合同层面，错误的申赎参数处理会产生业务争议；监管层面，ETF运作不规范可被交易所或监管机构处理；持有人层面，净值、成交或申赎异常会造成财产损失。易引发此类后果的配置失误包括分段切断关键条款、召回条数过低漏掉核心材料、未开启字段溯源导致无法回查原件、字段匹配阈值设置不当导致抽取错误。

## 与相邻品类的区别
相较场外指数基金，ETF投资与运营增加了PCF、交易所上市交易、一级市场申赎、现金替代及做市相关的业务链条。该品类需处理的文档中包含PCF、一级市场申赎文件等场外指数基金无需处理的材料，这些材料的格式规范与字段要求存在差异，因此文档解析与分块的配置需针对性调整，无法直接沿用场外指数基金的配置方案。

## 还需要按机构实际情况确认的
- 各ETF的实物/现金申赎模式、现金替代类型和做市安排以基金及交易所文件为准，不同机构的ETF产品模式存在差异，需针对性调整字段抽取规则。
- 耗时排序未有统一公开统计，不同机构的业务流程差异会导致耗时环节的优先级不同，需结合实际业务场景标定。
