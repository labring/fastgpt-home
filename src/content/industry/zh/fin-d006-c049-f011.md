# 证券经纪业务材料的解析与分块：格式、表格与字段抽取

## 这个品类每天在处理什么材料
这个品类日常处理的材料包括开户及身份资料、风险揭示、委托成交、权限变更、客户回访、异常交易核查、投诉及营销合规材料。数据来源覆盖交易所行情成交、中国结算账户信息、券商柜台、CRM、适当性及反洗钱系统。其中委托成交与行情数据在交易时段实时更新，账户信息与异常监控数据随事件触发更新，客户回访频率则按机构内部制度执行。各类材料形态差异显著，既有结构化的交易明细表格，也有长文本合规文档与表单类客户资料。

## 这些材料在「文档解析与分块」这一环带来什么约束
各类材料在文档解析与分块环节存在多重约束。结构化的交易明细、账户信息类文档需要精准抽取表格字段，避免遗漏关键交易参数与身份信息；实时更新的委托成交与行情数据要求解析流程具备低延迟特性，确保数据时效性；合规类文档需严格保留原文语义，分块时不能切断关键条款；多源数据的统一映射需要适配不同系统的字段格式，避免出现信息混乱。同时，事件触发类的异常交易核查材料需及时完成解析，保障监控响应效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 常见取法，需按实际材料的段落长度、语义完整性标定，避免切断关键条款或字段 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 常见取法，需根据单份文档最大体积调整，适配多类型合规材料的处理需求 |
| `召回条数` | 前8–12条 | 常见取法，需按实际文档数量和字段密度标定，覆盖核心业务材料的关键信息 |
| `字段抽取置信度阈值` | 0.75–0.85 | 常见取法，需按机构的合规要求调整，平衡抽取准确率与召回率 |
| `maxContext` | 4000–6000 字符 | 常见取法，需按实际分块后的总长度调整，匹配经纪业务核心材料的语义关联范围 |

## 最耗时的环节会卡在哪
最耗时的三个环节分别为审查账户和身份资料及权限、监控异常委托与账户使用及交易行为、处理交易差错与费用及账户权限和客户争议。审查环节可自动抽取身份、权限相关字段，替代手动核对，若抽取字段为空或结果与原件对不上，需人工回退重做。监控环节可实时解析委托、异常交易文档提取行为字段，若召回不到对应条款或超时中断，会导致监控滞后。处理争议环节可分块整理投诉、成交明细材料，若分段切断条款，无法完整追溯争议依据，需人工重新梳理。

## 做错了会怎样
解析分块出错会引发业务层面的交易差错或系统处理损失，产生委托与费用相关的合同争议，因实名制、适当性或交易管理不规范面临监管处理，还会造成客户错误交易、权限限制并产生赔偿或投诉。常见的配置失误包括分段切断关键条款导致语义不完整、召回条数过低遗漏核心材料、未开启字段溯源功能无法回查原件、超时中断未及时处理实时文档，这些失误均会放大上述风险。

## 与相邻品类的区别
证券经纪业务的核心是账户服务与执行客户委托，文档解析与分块聚焦于账户、交易、合规等执行类材料的字段抽取与语义整理。投顾业务聚焦于研究判断与投资建议，需处理的材料多为研究报告、客户持仓分析类文档，两类业务的材料特征与处理需求存在显著差异，因此同一套解析配置无法适配相邻品类的业务场景。

## 还需要按机构实际情况确认的
- 开户复核的内部触发阈值：不同机构的合规要求、客户群体特征存在差异，阈值设定需匹配自身业务流程，无公开统一标准。
- 客户回访的触发频率与标准：各机构的客户服务制度、监管区域要求不同，需结合自身情况确认具体规则。
- 异常交易调查的内部触发规则：异常交易的判定维度、阈值因机构的风控体系、交易品种范围而异，无法形成公开统一的标准。
