# 基金及金融产品代销材料的检索与召回：分段、阈值与重排取法

## 这个品类每天在处理什么材料
日常处理的材料包括风险测评、产品风险评级、产品准入尽调、适当性匹配记录、销售宣传材料、过程留痕、申购赎回及投诉资料。数据来源覆盖产品管理人文件、监管/协会公开信息、机构产品库、CRM、交易和销售系统。各类材料形态存在差异，风险测评记录多为结构化表单，产品合同与销售宣传材料多为长文档，过程留痕多为系统日志类文本，申购赎回及投诉资料多为交易记录与工单文档。数据更新频率存在区别，产品信息随管理人披露触发更新，客户交易数据实时或事件触发更新，风险测评按规则与客户变化复评，产品准入复审周期因机构而异。

## 这些材料在「知识库检索与召回」这一环带来什么约束
材料类型覆盖结构化与非结构化，需适配多格式检索逻辑，避免单一检索方式遗漏信息。多源数据来源要求配置跨系统同步机制，保证知识库数据的完整性。不同更新频率需要混合更新策略，兼顾实时交易数据与定期更新的产品信息。部分材料涉及合规留痕，需保证召回的精准性与可溯源性，防止遗漏关键合规内容。各类材料的合规优先级存在差异，需配置权重调整机制，优先召回风险匹配、产品准入类核心材料。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | `800–1200 字符` | 常见取法，需按实际材料的条款长度、合规文档的完整性要求标定 |
| `相似度阈值` | `0.75–0.85` | 平衡精准召回与覆盖范围，需结合合规文档的重要性调整 |
| `召回条数` | `前 10–15 条` | 覆盖核心合规材料且避免冗余，需按机构的审核流程长度调整 |
| `重排返回条数` | `前 3–5 条` | 聚焦风险匹配、产品准入类核心文档，需按审核优先级调整 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `60–120 秒` | 适配长文档解析的常见耗时，需按最大文档的解析难度标定 |
| `maxContext` | `4000–6000 字符` | 控制上下文窗口避免溢出，需结合模型支持的上下文长度调整 |

## 最耗时的环节会卡在哪
第一个耗时环节为阅读产品合同、说明书和风险资料完成产品准入，可通过检索召回对应合规条款与尽调材料，但无法替代人工审核实质合规性。若召回不到对应条款会导致审核延误，抽取字段为空则无法完成准入校验。第二个环节为核对客户情况、风险承受能力和产品风险匹配，可召回客户风险测评记录与产品风险评级文档，但无法替代人工匹配判断。若召回条数过低漏掉关键记录，或结果与原件对不上会导致匹配错误。第三个环节为审查宣传销售材料、关键销售环节留痕和异常交易，可检索宣传材料与留痕记录，但无法替代异常交易的合规判断。若超时中断会导致流程停滞，需要人工回退重做。

## 做错了会怎样
出错后果包括业务层面的错售或产品准入错误、合同层面的销售文件与产品合同不一致引发纠纷、监管层面的适当性、宣传或收费违规被处理、客户层面的损失、投诉、赔偿或诉讼。易引发这些后果的配置失误包括：分段长度设置过短切断合规条款，导致审核无法获取完整信息；召回条数设置过低漏掉关键的适当性匹配记录；未开启文档溯源，导致无法核对原始材料引发纠纷；相似度阈值设置过高，导致无法召回必要的合规文档；超时设置过短，导致长文档解析失败中断流程。

## 与相邻品类的区别
与产品管理人等相邻品类不同，销售机构一般不负责底层投资决策，核心责任链为产品是否准入、客户是否匹配、怎么卖、是否留痕。代销场景的检索召回重点围绕合规匹配与留痕记录，需优先召回风险测评、适当性匹配、销售留痕类文档。而相邻品类的检索召回重点为投资研究、产品发行相关文档，因此同一套配置无法适配两类场景的需求。

## 还需要按机构实际情况确认的
- 不同类型金融产品适用的适当性制度并非完全相同，因产品类型、监管要求存在差异，机构需适配不同的检索匹配规则。
- 统一产品准入模板和复审周期属于机构内部制度，不同机构的业务流程、合规要求存在区别，需调整知识库的召回匹配逻辑。
