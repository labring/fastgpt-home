# 固定资产贷款答复的溯源：引用范围、角标与原文定位

## 这个品类每天在处理什么材料
日常处理的材料包括可研或投资方案、依法需要的审批核准备案及许可材料、资本金证明、工程及采购合同、授信调查报告、提款材料、工程进度及贷后检查资料。主要数据来源涵盖企业及项目资料、发改和行业主管部门公开信息、银行信贷系统、工程进度资料、不动产及担保登记、工商征信。不同材料的更新频率存在差异：信贷系统数据为事件触发更新，项目审批许可材料随事项变更更新，工程进度材料按项目节点更新，外部登记数据在查询时获取，机构复核频率无统一公开要求。各类材料形态涵盖结构化审批文件、非结构化工程文档与系统内结构化数据，差异明显。

## 这些材料在「引用来源与溯源」这一环带来什么约束
多类型混合的材料结构要求溯源功能同时支持结构化字段抽取与非结构化文本的精准定位；分散的跨系统、跨机构数据来源要求溯源能力关联多源原始材料，统一标识来源路径；差异化的更新频率要求溯源功能匹配最新版本的材料内容；单笔项目涉及材料数量较多，要求溯源功能具备高效的召回与定位能力，避免遗漏核心依据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | 前5-10条 | 常见取法，需按项目涉及的材料数量、项目复杂度实际标定 |
| `相似度阈值` | 0.75-0.85 | 常见取法，需按文档专业术语密度调整匹配精度 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300-600秒 | 常见取法，需按大型审批文档的解析时长实际标定 |
| `分段长度` | 800-1200字符 | 常见取法，需按单份文档的段落结构调整，避免切断核心条款 |
| `重排返回条数` | 前3-5条 | 常见取法，需按核心材料的优先级调整展示顺序 |

## 最耗时的环节会卡在哪
核实项目总投资、资本金及依法需取得的审批许可条件环节，溯源功能可快速定位可研、审批文件中的对应条款，替代手动翻找的重复工作，但无法自动判断合规性，若召回不到对应条款，会导致人工回退重做。复核投资回报和借款人整体偿债来源环节，溯源可关联授信报告、工商征信的原始数据，替代跨文档查找的工作，但无法整合多源数据的逻辑判断，若抽取字段为空，无法匹配偿债依据。按工程/采购进度核验提款及支付对象环节，溯源可关联工程进度、提款材料的对应节点，替代进度核对工作，但无法确认支付对象的合规性，若结果与原件对不上，需要人工复核修正。

## 做错了会怎样
出错会导致业务层面建设条件、资本金或投资收益判断错误形成损失，合同层面提款条件未满足仍放款产生争议，监管层面违反固定资产贷款规则被采取监管措施，客户层面错放或停放影响项目资金安排。常见的配置失误包括召回条数过低漏掉关键材料，分段长度过短切断核心条款，未开启溯源功能导致答复无法回查原件，相似度阈值过高导致无法召回相关依据。

## 与相邻品类的区别
与项目融资相比，固定资产贷款范围更广，不要求每笔贷款都主要依赖该项目自身未来收入偿债。与流贷相比，固定资产贷款围绕长期资产投资、项目总投资和建设进度展开。两类相邻品类的核心材料与关注节点存在差异，因此同一套溯源配置无法直接适配，例如项目融资需更聚焦项目自身现金流相关材料，流贷则无需跟踪工程进度相关资料。

## 还需要按机构实际情况确认的
- 各行业具体审批许可和资本金要求需按项目类型核实，不存在统一“四证齐全”口径，不同行业的监管要求与机构准入标准存在差异，需结合项目所属行业确认。
- 前三耗时环节的排序未找到统一公开依据，不同机构的人员配置、系统工具存在差异，耗时排序会因实际情况不同而变化。
- 外部登记的机构复核频率无统一公开要求，不同机构的风控流程与复核周期存在差异，需结合自身机构的管理规则确认。
