# 银团贷款材料的解析与分块：格式、表格与字段抽取

## 这个品类每天在处理什么材料
日常需处理的材料包括银团邀请函、信息备忘录、参加行授信批复、银团贷款合同、担保文件、提款通知、代理行报告、贷款人会议资料。数据来源覆盖借款人项目及财务资料、各参加行授信系统、代理行台账、工商征信。不同材料的更新频率存在差异：组团和授信资料随交易节点更新，提款、付息、还款操作由合同事件触发更新，重大事项随事件触发更新，代理行报告则按合同约定频率更新。各类材料形态差异显著，既有结构化的合同文本与表格类批复，也有自由格式的会议纪要与短通知类文件。

## 这些材料在「文档解析与分块」这一环带来什么约束
各类材料的结构差异对解析分块形成多重约束。银团贷款合同、担保文件等长文本材料存在固定条款结构，需精准识别语义边界避免切断关键条款；贷款人会议资料、代理行报告等自由文本材料需适配松散的段落布局；授信批复、份额核算表等表格类材料需准确抽取单元格内容，避免破坏表格结构。部分材料包含嵌套附件，需支持分层解析以完整提取内容。跨来源的材料格式不统一，需兼容不同的排版样式与文件类型。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 常见取法，需按银团合同、会议纪要等不同文档的平均段落长度标定，避免切断长条款或拆分过细 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 常见取法，需适配大额银团合同、多附件担保文件的解析时长，避免超时中断 |
| `表格抽取精度阈值` | 0.85–0.95 | 常见取法，需平衡抽取准确率与处理速度，适配授信批复、份额核算表等表格类材料 |
| `召回条数` | 前 6–10 条 | 常见取法，需覆盖银团组团、份额核算等核心信息的检索需求，避免遗漏关键条款 |
| `嵌套附件解析开关` | 开启 | 常见取法，需支持担保文件、联合授信资料等包含嵌套附件的材料解析，完整提取内容 |

## 最耗时的环节会卡在哪
统一整理可供多家银行独立授信的信息包环节，解析分块可自动抽取各文档中的授信条件、份额要求，替代手动复制粘贴，但无法完成跨银行的条款对齐，若召回不到对应授信条款、抽取字段为空，会导致信息包缺失。协调各行先决条件、合同条款及担保结构环节，解析分块可提取各文档中的先决条件、担保条款，替代手动整理条款清单，但无法完成跨机构的条款沟通，若分段切断条款导致上下文缺失、结果与原件对不上，需人工回退重做。核算提款、本息和各参加行份额并处理通知环节，解析分块可抽取合同中的份额比例、计息规则，替代手动提取数据，但无法完成实时账务核对，若表格抽取错误导致份额数据偏差、超时中断，会导致核算流程延迟。

## 做错了会怎样
解析分块环节出错会引发多维度影响：业务层面代理计算或资金分配错误造成账务差异；合同层面贷款人条件不一致可能阻断提款；监管层面牵头、代理或风险分担不规范可能被纠正；客户层面提款或通知错误影响资金安排。易引发该类后果的配置失误包括：分段长度设置不当切断长条款，召回条数过低遗漏关键材料，表格抽取阈值设置不合理导致字段抽取不全，解析超时中断导致流程延迟。

## 与相邻品类的区别
银团贷款与单一银行贷款的核心差异在于多家机构基于共同贷款合同分工协作，特有文件包括信息备忘录、组团相关材料、代理行报告及贷款人会议资料。单一银行贷款的材料仅围绕单一授信主体，无上述特有文件与协作相关动作。因此解析分块的配置需适配特有文件的结构与语义，直接套用单一银行贷款的配置会遗漏特有信息或误判文档边界。

## 还需要按机构实际情况确认的
- 银团代理报告和贷款人会议频率主要由合同约定，不同机构的合同约定差异较大，需根据自身合作的合同条款确认解析频率与触发条件。
- 三项耗时环节的排序未见统一公开依据，不同机构的业务流程差异会导致各环节耗时权重不同，需结合自身实际业务场景调整解析分块的资源分配优先级。
