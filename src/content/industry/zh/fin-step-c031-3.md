# 并购贷款的重建并购后合并现金流、债务负担及整合假设：哪一部分能交给系统

## 这一步现在是怎么做的
这一步需先归集交易双方财务资料、工商司法信息等多源数据，结合并购方案、股权结构图明确整合前提，逐一拆解标的与买方的财务科目，搭建合并现金流测算框架，核对债务负担的期限、担保结构，结合估值材料调整整合后的偿债安排。人工主要耗时在跨文档信息校验，需反复匹配交易协议、财务及法律尽调报告中的条款与数据，同时结合投后整合资料调整假设条件，易因多源数据不一致出现反复返工的情况。

## 哪一部分能交给系统
可由系统承接的环节包括三类。第一类是多源文档数据抽取，从并购方案、交易协议、财务及法律尽调报告中自动提取并购比例、债务明细、担保条款等字段，对应文档抽取能力。第二类是跨源数据比对，自动匹配交易双方财务资料、征信数据中的债务信息，校验数据一致性，对应检索比对能力。第三类是结构化内容生成，基于预设模板生成合并现金流测算初稿、债务负担清单，结合行业可比数据调整假设参数，对应生成能力。还可自动按通用规则初步核对贷款比例、期限是否符合要求，对应规则匹配能力。

## 哪一部分交不了
部分环节无法由系统完全承接。一是整合假设的合理性判断，需结合交易真实背景、行业惯例判断并购后业务协同、成本节约等假设是否符合实际，系统无法基于非结构化的交易背景信息完成判断。二是特殊交易条款的适配，需结合股权结构、担保安排的具体细节调整模型参数，系统无法识别非标准化的交易瑕疵。三是风险判断环节，需结合内部授信信息、监管要求评估偿债能力的潜在风险，系统无法替代人工完成专业风险研判。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `数据源白名单` | 仅允许接入并购方案、股权结构图、交易协议等指定文档类型 | 常见取法，需按机构实际可接入的文档范围标定 |
| `抽取字段映射规则` | 预设覆盖并购比例、债务余额、担保结构等核心字段的映射关系 | 常见取法，需按具体交易的字段需求调整 |
| `合规校验规则集` | 加载2026年现行并购贷款监管规则条目 | 常见取法，需按机构所在地监管要求更新 |
| `生成内容置信度阈值` | 设置为0.75-0.85 | 常见取法，需按机构风险容忍度标定 |
| `任务超时阈值` | 设置为15-20分钟 | 常见取法，需按文档总量调整 |

## 做不好会以什么形式暴露
- 核心字段抽取为空，通常因`抽取字段映射规则`未覆盖对应交易场景的必填字段，导致系统无法识别目标信息。
- 生成结果与原件对不上，通常因`数据源白名单`未纳入全部必要文档类型，导致系统缺少关键数据支撑。
- 任务超时中断，通常因`任务超时阈值`设置过短，或`数据源接入范围`包含过多非必要文档导致处理负载过高。

## 还需要按机构实际情况确认的
- 不同并购类型的贷款比例、期限和担保结构需按2026年现行规则及具体交易复核。
- 本环节的前三耗时排序属于作业判断，需结合机构实际作业流程确认。
