# 产品咨询客户服务的HTTP 接口与外部系统

## 这个品类的数据长什么样
产品咨询的数据来源为企业内部产品管理系统及监管备案存档文档，更新节奏为产品条款、销售规则调整或新备案完成时触发，无固定周期。单条咨询数据的文档结构包含产品唯一标识、产品全称、产品分类、风险等级标识、投资期限标注、销售门槛说明、收益说明字段。字段与单位规则为：产品唯一标识为字符串类型，风险等级标识为R1至R5的枚举值，投资期限标注以“自然日”“自然年”为单位，销售门槛说明以“元”为单位，收益说明为文本描述形式。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
由于数据依赖内部私有系统与备案文档，HTTP接口需支持对接企业内部部署的产品管理API，并通过企业级鉴权机制保障数据访问合规。数据更新无固定周期，接口缓存策略需适配动态更新场景，不宜设置过长的缓存有效期，避免返回过期产品信息。字段包含枚举类风险等级、带单位的期限与销售门槛，接口返回字段需严格对齐调用方的解析规则，否则会导致前端展示或业务逻辑异常。此外，产品咨询数据涉及金融合规信息，接口需支持返回数据的版本标识，便于调用方核对备案有效性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `external_product_api_url` | 企业内部产品管理系统的标准化API端点 | 用于拉取统一的产品咨询数据源，确保数据一致性 |
| `api_auth_type` | `api_key` | 适配多数企业内部API的鉴权标准，保障数据访问安全 |
| `product_data_cache_ttl` | `300 秒` | 平衡数据时效性与接口调用频率，适配产品非固定更新的节奏 |
| `required_product_fields` | `product_id, product_name, risk_level, term, sales_threshold` | 覆盖产品咨询的核心展示字段，避免调用方解析缺失 |
| `request_timeout` | `10 秒` | 适配金融类接口的常规响应节奏，避免超时导致咨询中断 |
| `ssl_verify_mode` | `strict`，若使用自签证书可调整为`insecure` | 保障接口通信加密安全，适配不同部署环境的证书要求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部产品接口返回`SSL_ERROR_SSL`报错或连接超时。原因：未配置`ssl_verify_mode`适配内部自签证书，或未跳过证书校验环节。
- 现象：工作流中调用产品接口后返回字段缺失，导致咨询页面展示空白。原因：未在`required_product_fields`中配置所有调用方所需的字段，接口返回数据未覆盖解析依赖项。
- 现象：产品咨询结果延迟触发超时提示。原因：`request_timeout`配置过短，或内部产品接口响应缓慢未做适配调整。

## 怎么确认配好了
- 调用FastGPT内置接口调试工具，传入测试产品ID，检查返回字段是否与配置的`required_product_fields`完全匹配。
- 模拟企业内部产品数据更新场景，触发数据刷新，检查接口返回的最新产品信息是否同步至咨询结果。
- 查看接口调用日志，确认鉴权参数已正确携带，无`401 Unauthorized`报错。
- 调整`ssl_verify_mode`为`insecure`后，调用接口验证自签证书场景下的连接是否正常。
