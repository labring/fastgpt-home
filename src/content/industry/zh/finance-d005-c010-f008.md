# 产品咨询客户服务的工具调用与插件

## 这个品类的数据长什么样
产品咨询的数据主要来自金融机构官方产品手册、实时费率公示系统、核保规则文档及历史客服交互库。数据更新节奏因类型不同存在差异，产品条款更新多按季度，费率数据每日同步，核保规则调整无固定周期。单条咨询数据包含产品编号、产品名称、保障责任范围、对应费率、投保年龄区间、核保准入条件等字段，单位多为万元保额、百分比费率、周岁年龄等标准化金融计量单位，部分历史问答会附带用户提问的场景标签。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于产品咨询数据包含实时费率、动态调整的核保规则，工具调用需支持高频实时接口拉取，避免使用超过24小时的缓存数据。多字段的标准化校验要求工具在调用前需匹配产品编号、投保年龄、保额单位等参数，防止参数错位导致的咨询偏差。不同数据源的接口响应时长差异较大，需为不同类型的数据源配置独立的超时阈值，同时需支持对历史问答库的向量召回与实时接口结果的融合处理，确保返回内容同时覆盖标准化条款与最新动态信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `pluginInvokeCacheTTL` | `1800 秒` | 适配产品费率每日更新的节奏，同时避免频繁调用实时接口导致的资源占用 |
| `apiCollectionTimeout` | `10–15 秒` | 覆盖多数金融机构接口的响应时长，防止因接口延迟导致的咨询中断 |
| `vectorRecallTopK` | `前 8 条` | 平衡历史问答库的召回覆盖范围与结果处理效率，适配产品咨询多场景的需求 |
| `similarityThreshold` | `0.75–0.85` | 过滤低匹配度的历史问答，避免返回不相关的产品咨询内容 |
| `paramCheckStrictMode` | `开启` | 严格校验产品编号、保额单位等字段，防止因参数错误导致的咨询结果偏差 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 适配完整产品手册的上传需求，避免因文件过大导致的上传失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用节点仅返回接口原始数据，未生成AI整理后的产品咨询回复。原因：未开启插件调用后的结果整合开关，导致AI未对工具返回的原始数据进行结构化整理。
- 现象：调用apiCollection接口时返回`Invalid URL, code: 500`错误。原因：配置的HTTP工具集地址未添加合法的协议前缀，或接口地址存在拼写错误，导致无法正常发起请求。
- 现象：上传产品手册文件时触发`Multimodal file size is`相关报错。原因：上传文件大小超过`UPLOAD_FILE_MAX_SIZE`配置的阈值，或文件格式未被系统支持的多模态解析范围。

## 怎么确认配好了
- 发起一条包含具体产品编号的模拟咨询，查看工具调用日志中是否正确携带了匹配的产品参数。
- 调用配置好的HTTP工具集接口，检查返回的响应数据格式是否与预设的字段结构一致。
- 上传一份标准产品手册文件，确认上传进度条完成且无报错提示。
- 调整相似度阈值配置，验证召回的历史问答结果的匹配度是否符合预期。
