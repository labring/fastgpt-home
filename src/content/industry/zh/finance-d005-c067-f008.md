# 投诉工单客户服务的工具调用与插件

## 这个品类的数据长什么样
投诉工单数据来源于金融、保险、理财机构的客服工单系统与客户服务CRM模块，更新节奏为工单提交后实时录入，处理状态变更的同步频率为1-5分钟。文档包含固定字段：`ticket_id`（唯一字符串标识）、`customer_account`（关联客户账户编号）、`complaint_type`（枚举类型，如扣费异常、服务咨询）、`description`（用户投诉详情长文本）、`submit_time`（ISO 8601格式时间戳）、`status`（待处理/处理中/已办结枚举值）、`associated_amount`（涉事金额，单位元）。

## 这些特征在「工具调用与插件」这一环带来什么约束
工单数据的实时更新要求工具调用需绑定事件触发机制，避免定时拉取导致的处理延迟。固定字段的枚举属性要求插件调用时需校验`status`、`complaint_type`等字段的取值范围，防止非法参数传入。关联客户账户与涉事金额的敏感属性，要求工具调用环节需开启数据脱敏配置，避免敏感信息泄露。长文本的投诉描述存在上下文长度限制，需配置前置摘要提取步骤，压缩传入工具的文本长度，适配模型上下文窗口。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `trigger_mode` | `event_based` | 匹配工单实时提交、状态变更的更新节奏，避免定时拉取带来的处理延迟 |
| `tool_call_timeout` | `300 秒` | 适配工单处理涉及的跨系统查询、数据库交互流程，预留充足的响应时间 |
| `sensitive_field_list` | `customer_account, associated_amount` | 覆盖工单内的敏感字段，保障客户信息与涉事金额的合规脱敏 |
| `preprocess_max_length` | `800-1200 字符` | 压缩投诉描述的长文本，适配模型上下文窗口限制，避免文本截断或超出长度报错 |
| `enum_param_check` | `enabled` | 校验`complaint_type`、`status`等枚举字段的取值合法性，过滤非法调用请求 |
| `external_db_allowed` | `oracle, mysql` | 适配金融机构常见的工单系统数据库类型，支持跨源数据拉取 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用第三方接口时返回`Error: write EPROT`错误。原因：未配置正确的HTTPS证书校验规则，或接口域名未加入FastGPT的允许访问白名单，导致加密通信失败。
- 现象：尝试连接Oracle数据库时无法拉取工单数据。原因：未将`oracle`加入`external_db_allowed`配置项的允许列表，或数据库连接字符串格式不符合要求。
- 现象：工具调用节点执行完成后，对话链路无AI回复输出。原因：未配置工具调用结果的返回格式，或未正确开启自然语言回复生成开关，导致未拼接AI回复内容。

## 怎么确认配好了
- 手动触发一条测试工单的状态变更，观察FastGPT是否自动发起工具调用，确认事件触发配置生效。
- 调用工具测试接口，传入包含客户账户与涉事金额的测试数据，检查返回结果中对应字段是否已脱敏，确认敏感配置生效。
- 传入不符合枚举规则的参数发起调用，观察是否返回参数校验失败的提示，确认枚举校验配置生效。
- 传入超出配置长度的投诉描述文本，检查工具接收的文本是否已按要求截断，确认预处理配置生效。
