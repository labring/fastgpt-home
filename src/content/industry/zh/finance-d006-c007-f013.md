# 乳制品投研知识库建设的知识库检索与召回

## 这个品类的数据长什么样
乳制品投研数据来源涵盖行业协会月度监测报告、乳企公开财报、原料供应商报价文档、第三方检测机构质检报告及供应链物流记录。更新节奏差异明显，原料奶价格按日更新，乳企财报按季度发布，行业白皮书按季度或年度更新。文档类型包含扫描版PDF研报、结构化报价表格、纯文本舆情数据及带图表的分析文档，字段包含乳脂率、蛋白质含量、原料收购价、保质期等，对应单位分别为g/100g、元/公斤、天等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
扫描版PDF占比高，要求检索系统支持精准OCR识别以提取有效文本；结构化表格与非结构化研报并存，要求检索同时支持字段精准匹配与语义关联召回；多更新频率数据共存，要求召回结果可按更新时间筛选以保证数据时效性；字段单位多样，要求检索时自动匹配单位关联，避免单位不匹配导致的结果偏差；长文档占比高，要求分段检索时合理拆分段落，避免割裂语义关联。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | 900 秒 | 乳制品研报PDF常包含多页扫描内容，OCR解析耗时较长，需延长超时时间避免解析中断 |
| `UPLOAD_FILE_MAX_SIZE` | 2000 MB | 单份乳制品行业白皮书PDF体积可达GB级，需放宽上传上限以支持大文件上传 |
| `分段长度` | 800–1200 字符 | 乳制品研报常包含长段落的原料分析，分段过短会割裂语义关联，过长则影响召回精度 |
| `相似度阈值` | 0.72–0.85 | 乳制品投研关键词（如乳脂率、乳铁蛋白）语义相似度区分度高，阈值不宜过低避免无关结果，不宜过高遗漏相关内容 |
| `召回条数` | 前 8 条 | 投研场景需覆盖多维度数据，召回过少无法支撑分析需求，过多则增加上下文处理负担 |
| `OCR_ENABLE` | 开启 | 扫描版原料检测报告、行业白皮书占比高，需开启OCR识别以提取图片中的文本内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传扫描版PDF后，检索结果无有效文本内容。原因：未开启OCR识别配置，仅识别了PDF的图片图层，未提取文本信息。
- 现象：通过接口新增知识库后，业务系统调用检索接口返回空结果。原因：未配置知识库与业务系统的检索权限映射，或接口请求未携带正确的知识库唯一标识参数。
- 现象：添加知识库时返回`413 Request Entity Too Large`错误。原因：上传的文件体积超过`UPLOAD_FILE_MAX_SIZE`配置的上限，不符合系统限制。

## 怎么确认配好了
- 上传一份扫描版乳制品检测报告PDF，查看解析后的文本内容是否完整，确认OCR配置已生效。
- 调用检索接口，传入乳制品投研关键词，核对返回结果的条数与配置的召回条数是否一致。
- 检查知识库的权限配置，确认业务系统的调用账号拥有该知识库的检索权限。
- 上传一份体积较大的乳制品行业白皮书PDF，确认上传未触发`413`错误，验证`UPLOAD_FILE_MAX_SIZE`配置符合预期。
