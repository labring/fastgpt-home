# 储能投研知识库建设的数据库与运维

## 这个品类的数据长什么样
面向金融领域的储能投研数据主要来自电芯供应商的循环寿命测试报告、电网侧储能电站的SCADA实时采集数据、行业协会发布的并网标准文档。实时运行数据更新频率为秒级，电站运维日志按日归档，行业研报按周或月更新。单条数据包含设备唯一标识、充放电功率、剩余电量、环境温度、安装位置等字段，单位多采用伏特（V）、安培（A）、千瓦时（kW·h）、摄氏度（℃），部分文档包含多组时序参数的嵌套结构。

## 这些特征在「数据库与运维」这一环带来什么约束
储能投研数据的秒级实时采集需求，要求数据库集群支持高并发写入与低延迟查询；嵌套时序参数结构需要支持JSONB或类似的半结构化字段存储，适配多维度参数组合查询；多源数据更新频率差异大，需采用分层存储架构，将高频实时数据存入内存数据库，低频归档数据存入对象存储；不同厂商设备的字段命名与单位存在差异，需在数据入库前配置标准化映射规则，避免查询时出现字段缺失或单位混乱。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 储能行业的循环寿命测试报告、年度运维日志通常包含大量时序数据，解析耗时较长，600秒可覆盖长文档完整解析 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 单份储能电站的季度运维归档文件可能超过1.5GB，需支持大文件批量上传 |
| `RECALL_TOP_K` | `前20 条` | 储能投研需同时匹配充放电功率、剩余电量、环境温度等多维度参数，20条召回结果可覆盖常用查询组合 |
| `SIMILARITY_THRESHOLD` | `0.75` | 储能参数的技术语义相似度需达到0.75以上，才能保证投研数据的相关性，避免混入无关设备的参数信息 |
| `DB_WRITE_BATCH_SIZE` | `500 条/批` | 秒级采集的储能实时运行数据批量写入可降低数据库集群负载，500条适配多数云原生数据库的写入阈值 |
| `SQL_SERVER_ENABLED` | `true` | 部分储能行业用户已部署SQL Server存储设备台账历史数据，需支持跨数据库调用 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用数据库插件时返回`404 Not Found`错误，提示无法找到指定表。原因：未配置储能设备台账与SQL Server表的映射规则，或表名与配置的映射名称不一致。
- 现象：使用API批量访问知识库时出现`503 Service Unavailable`错误，查询响应延迟超过30秒。原因：未针对储能秒级采集的高并发写入场景调整数据库连接池参数，连接数不足导致服务过载。
- 现象：检索储能充放电功率数据时返回单位混乱的结果。原因：未在数据入库前配置单位标准化转换规则，不同数据源的功率单位混用了千瓦（kW）与兆瓦（MW），导致查询结果无法统一。

## 怎么确认配好了
- 上传一份储能电站的季度运维日志，验证解析任务在配置的超时时间内完成，无解析失败的告警提示。
- 发起多并发的实时数据查询请求，观察数据库集群的负载状态，调整连接池参数至匹配当前业务并发量的取值。
- 检索不同来源的储能参数数据，检查返回结果的字段命名与单位是否符合预设的标准化规则。
- 测试跨数据库调用功能，确认可从指定数据库中读取储能设备台账数据并完成关联匹配。
