# 出版投研知识库建设的数据库与运维

## 这个品类的数据长什么样
出版行业投研数据主要来自公开出版的行业白皮书、学术期刊、出版社内部运营报表、图书零售监测数据及版权登记公示信息。更新节奏随数据类型差异明显：行业报告按季度或半年度更新，学术期刊按月或双月刊发布，图书零售数据按月同步，版权信息随登记动作实时更新。文档结构包含长幅研究报告、结构化业务报表及短资讯三类，核心字段包含ISBN编码、出版日期、印量、定价、目标读者标签与版权到期日，单位涵盖册、元、日期格式等。

## 这些特征在「数据库与运维」这一环带来什么约束
该品类的数据特征对数据库与运维环节带来多重约束。混合类型的数据需要同时适配关系型数据库存储结构化字段与向量数据库处理非结构化文本，提升存储架构的复杂度。差异化的更新节奏要求配置分批次同步策略，避免全量更新占用过多资源。长幅研究报告的向量入库需适配分段规则，防止单条数据超出模型上下文限制。核心唯一标识如ISBN编码需设置主键约束，防止重复入库。时效性较强的版权数据需配置定期校验机制，确保数据合规性。批量导入的零售报表需适配批量写入参数，提升同步效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_CHUNK_SIZE` | 800–1200 字符 | 适配出版行业长报告的分段需求，平衡上下文召回精度与存储效率 |
| `VECTOR_INSERT_BATCH` | 50–100 条/次 | 适配批量导入零售报表与期刊合集的场景，避免单次写入超时 |
| `DB_CONNECTION_TIMEOUT` | 30–60 秒 | 应对长报告解析后的批量入库请求，防止连接中断 |
| `SYNC_JOB_CRON` | 按数据类型分配置：零售数据`0 0 2 * * *`、版权数据`0 */6 * * *`、行业报告`0 0 0 * * 0` | 匹配不同数据的更新节奏，降低资源占用 |
| `MAX_SQL_PARAM_LENGTH` | 4096 字符 | 适配ISBN、定价等结构化字段的批量传入，防止参数溢出报错 |
| `FILE_PARSE_TIMEOUT` | 600 秒 | 处理长篇幅行业研究报告的解析与入库流程，避免超时终止 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用数据库工具时，手动输入SQL可正常执行，传入变量后返回`400`状态码或空输出。原因：未配置`MAX_SQL_PARAM_LENGTH`适配变量长度，或变量中包含未转义的特殊字符导致SQL语法错误。
- 现象：工作流调用数据库工具时触发`tool_calls`报错，日志显示连接超时。原因：未调整`DB_CONNECTION_TIMEOUT`参数，长报告解析后的批量入库请求超出默认超时限制。
- 现象：批量导入图书零售数据后出现重复条目。原因：未为ISBN编码字段设置主键约束，导致重复数据写入数据库。

## 怎么确认配好了
- 执行单条带变量的SQL测试，确认返回结果与手动输入一致，根据测试结果调整`MAX_SQL_PARAM_LENGTH`与转义规则。
- 上传长篇行业研究报告，等待解析入库完成，检查向量库中分段数据的数量与长度，匹配`PARSE_CHUNK_SIZE`的配置。
- 配置分类型的定时同步任务，触发一次同步后查看数据库更新日志，确认不同数据类型按预期节奏更新。
- 模拟批量导入结构化报表，检查写入成功率与耗时，调整`VECTOR_INSERT_BATCH`参数适配当前硬件资源。
