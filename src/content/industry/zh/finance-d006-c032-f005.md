# 化学原料投研知识库建设的多轮对话与提示词

## 这个品类的数据长什么样
化学原料投研数据主要来源于行业协会公开报告、生产企业合规文档、海关进出口统计、现货报价平台及MSDS安全技术说明书。数据更新节奏存在差异：现货报价每日更新，行业年度报告按季度或年度发布，MSDS文档在组分或合规要求变更时同步更新。文档结构以结构化参数表为主，包含CAS登记号、分子式、分子量、熔点、沸点、密度、纯度、包装规格等字段，单位涵盖g/mol、℃、MPa、kg/桶等专业化工单位，部分长文档包含供应链上下游的批量交易数据。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
化学原料数据的多维度参数与专业单位要求多轮对话需精准匹配字段标识，避免参数混淆。长文档如完整年度供应链报告会占用较多上下文窗口，需限制单轮召回的文档长度，防止模型推理超时。不同数据源的更新频率差异要求对话系统支持增量召回，优先获取最新现货报价与合规数据。此外，CAS号作为唯一标识，需在多轮对话中保留前置的原料标识，避免用户重复输入，同时防止模型匹配到错误的化学原料参数。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 2500–3500 字符 | 化学原料单份文档的参数段落通常包含3-5个核心指标，该区间可覆盖3-4轮投研对话的上下文需求，避免模型推理过载 |
| `召回条数` | 前8–12条 | 化学原料数据包含理化参数、供应链、合规三类核心维度，召回过多会增加token消耗，过少则无法覆盖完整投研需求 |
| `相似度阈值` | 0.75–0.85 | 化学原料CAS号具有唯一性，阈值过低会匹配到无关原料，过高则无法召回相近品类的替代分析数据 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 120 秒 | 单份完整行业报告或大型MSDS文档通常超过10页，较长解析时长可避免大文档解析失败 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 部分大型行业数据库文档体积较大，该上限可支持完整导入化学原料相关的批量数据文件 |
| `CONCURRENCY_LIMIT` | 20–30 并发 | 化学原料投研的并发请求通常来自机构内部的投研团队，该区间可满足日常批量对话需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：多轮对话后模型响应延迟超过15秒，日志显示`context window overflow`。原因：未限制`maxContext`参数，导致每次召回的文档和上下文总token超过模型上限。
- 现象：调用对话API上传文件后返回`413 Request Entity Too Large`。原因：未调整`UPLOAD_FILE_MAX_SIZE`参数，超过默认文件上传限制，无法导入大型行业报告。
- 现象：通过提示词调用MCP生成的理化参数图表无法完整展示，页面显示图片截断。原因：提示词未明确指定图表输出尺寸，且未配置`MCP_IMAGE_MAX_SIZE`参数，导致生成图片超出默认展示阈值。

## 怎么确认配好了
- 上传一份典型的化学原料MSDS文档，发起多轮提问，核对模型提取的参数与文档内容一致。
- 调用对话API上传指定格式的文件，检查知识库是否成功召回对应内容。
- 发起连续3轮针对同一化学原料的投研提问，检查上下文是否被正确保留，模型可关联前置的CAS号参数。
- 调用MCP生成化学原料的理化参数图表，检查图片是否完整显示，无截断情况。
