# 化学原料投研知识库建设的引用来源与溯源

## 这个品类的数据长什么样
化学原料相关数据来源包括行业协会公开公报、生产企业年度报告、海关进出口统计文档、化学品安全技术说明书（MSDS）、现货交易日报。更新节奏存在差异：行业协会数据按季度更新，现货价格按日更新，企业年报按年度更新，MSDS随国家标准修订更新。文档结构混合结构化参数表格与长文本分析段落，字段包含唯一标识CAS号、纯度百分比、产能、单价等，单位多为吨/年、元/吨、%。

## 这些特征在「引用来源与溯源」这一环带来什么约束
结构化参数占比高，要求溯源时需精准匹配字段与单位，避免跨品类混淆。CAS号作为唯一标识可用于快速定位对应段落，但需在溯源结果中同步展示该标识以确认参数归属。多更新频率的数据源，要求溯源结果附带文档更新时间，避免引用过期数据。长文本与结构化混合的文档结构，要求分段时保留字段关联关系，否则溯源无法对应具体参数来源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | 前8–12条 | 化学原料投研文档多包含精准参数，过多召回会引入无关品类的内容，过少则无法覆盖核心投研数据 |
| `相似度阈值` | 0.75–0.85 | 化学原料的参数表述严谨，阈值过低会引入非对应品类的文档，过高则可能遗漏有效溯源内容 |
| `分段长度` | 600–1000 字符 | 化学原料文档既有结构化表格段落，也有长文本分析，该长度可保留字段关联关系同时避免上下文断裂 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 120 秒 | 大型化工行业报告文档解析耗时较长，该时长可覆盖完整解析流程 |
| `引用展示格式` | 显示文档名+段落起始行号+CAS号 | 化学原料的核心标识为CAS号，结合行号可快速定位溯源的具体参数内容 |
| `重排返回条数` | 前5条 | 投研场景下仅需核心溯源依据，过多条目会干扰阅读与信息核对 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：返回的引用列表仅显示文档名，未标注具体段落或CAS号标识。原因：未配置`引用展示格式`为包含CAS号或行号的格式，导致无法精准定位化学原料的对应参数来源。
- 现象：调用工作流时传入的知识库变量未生效，知识库搜索节点仍使用默认配置的知识库。原因：未正确配置工作流中知识库搜索节点的「知识库来源」为变量引用，未校验变量传递的格式是否符合接口要求。
- 现象：chat接口返回的引用列表顺序与召回顺序不一致，且部分引用未包含有效化学原料参数信息。原因：开启了重排功能但未限制`重排返回条数`，同时未过滤掉未匹配到核心字段的召回条目。

## 怎么确认配好了
- 上传一份包含CAS号、产能参数的化学原料文档，发起投研查询，核对返回结果中是否附带文档名、段落位置及CAS号标识。
- 通过API调用工作流，传入指定知识库ID作为变量，验证知识库搜索节点是否调用对应知识库，未采用默认配置。
- 调整`相似度阈值`为0.7和0.85，对比返回的引用列表差异，确认阈值配置生效。
- 查看文档解析日志，确认分段后的内容保留了结构化字段的关联关系，未出现字段断裂的情况。
