# 化纤投研知识库建设的数据库与运维

## 这个品类的数据长什么样
化纤投研的数据主要来自上游石油石化产业链的原料报价（如PTA、乙二醇）、下游织造与终端服饰的供需数据、行业协会发布的月度开工率与库存报告、海关总署的进出口明细数据。数据更新节奏差异明显：原料现货价为实时更新，开工率、库存数据为周度更新，行业研报与进出口数据为月度或季度更新。文档结构包含三类：结构化的表格数据（含明确字段与单位）、半结构化的行业分析片段、非结构化的长篇研报。字段包含现货价、开工率、库存天数、进出口量等，部分数据需跨数据源关联匹配。

## 这些特征在「数据库与运维」这一环带来什么约束
化纤投研的数据特征对数据库与运维环节提出多重约束：首先，实时更新的原料价格数据要求低延迟的写入与查询链路，需避免数据库连接阻塞；其次，多更新节奏的数据源需分层调度的更新任务，避免高峰时段的资源抢占；第三，大量带单位的结构化数据需统一的元数据管理，确保检索时的字段匹配精度；第四，跨周期的历史数据查询需支持复杂SQL关联，对数据库的查询性能与超时配置提出更高要求；最后，多类型文档的混合存储需兼顾结构化查询与向量检索的双重能力，需合理配置数据库与向量库的资源分配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `VECTOR_STORE_BATCH_SIZE` | `20-30 条/批` | 化纤行业的单条结构化数据片段、研报分句长度适中，批量过大易触发数据库写入超时，批量过小会增加数据库连接开销 |
| `SQL_QUERY_TIMEOUT` | `600 秒` | 投研场景下需跨周期关联历史产能、价格、库存数据，需足够超时时间避免查询中断 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 化纤行业的大型年度供需报告、海关进出口明细文件体积较大，需支持大文件上传 |
| `MONGO_CONNECTION_POOL_SIZE` | `50-80` | 多并发投研查询场景下，需足够连接池支持同时读写业务数据与向量检索数据 |
| `DB_BACKUP_CRON` | `0 2 * * *` | 避开每日9-17点的投研业务高峰时段，降低备份对正常服务的影响 |
| `PARSE_TABLE_FIELD_PRESERVE` | `开启` | 化纤数据中包含大量带单位的结构化表格（如元/吨、开工率百分比），保留字段元信息可提升检索匹配精度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用投研知识库的查询接口时，系统返回`504 Gateway Timeout`错误。原因：未针对化纤行业的长周期历史数据查询调整`SQL_QUERY_TIMEOUT`参数，导致跨表关联查询超时被网关拦截。
- 现象：删除数据库挂载目录后重新部署服务，仍无法正常启动。原因：未清理容器内的持久化数据卷残留，或未正确配置数据路径参数，导致数据库仍读取旧的异常配置文件。
- 现象：数据源插件返回的数据库连接结构无法生成预期的SQL执行结果。原因：未将数据源的结构化数据映射为投研所需的字段关联规则，或未开启数据库的SQL查询权限，导致插件无法执行正常查询逻辑。

## 怎么确认配好了
- 上传一份化纤行业的结构化价格表格文件，核对解析后的数据是否保留了相关字段与单位信息，确认字段解析配置生效。
- 发起一次跨多个周期的历史数据查询，核对查询执行时长是否符合预设的超时要求，确认查询超时配置合理。
- 查看数据库备份日志，确认每日备份任务在非业务高峰时段执行，无业务时段的备份告警，确认备份调度配置正确。
- 发起多并发的投研查询请求，观察数据库连接数变化，确认连接数未超过配置上限，无连接溢出相关告警。
