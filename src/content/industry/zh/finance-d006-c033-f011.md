# 化纤投研知识库建设的文档解析与分块

## 这个品类的数据长什么样
化纤品类的数据源主要覆盖石油石化产业链上游原料行情、中游生产工艺参数、下游应用需求报告及海关进出口明细。数据更新节奏差异明显，原料期货行情每日更新，行业供需报告多为月度发布，企业生产年报按年度更新。文档结构以结构化表格为主，包含聚合度、纤度、断裂强度等工艺参数，同时穿插价格走势折线、供需平衡表，字段单位多采用旦尼尔（D）、厘牛每特克斯（cN/dtex）、吨等行业专用单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
多数据源的更新节奏差异要求解析任务适配不同频率的文档批量处理，避免短周期行情类文档的解析超时。结构化表格占比高且包含专用单位，常规通用解析容易出现表格单元格错位、单位识别错误的问题，需要针对性调整解析的表格拆分逻辑。行业专用参数的字段名与通用术语存在差异，分块时需保留参数的完整标识，避免拆分后丢失关键上下文。长文档的分块需要兼顾工艺参数表与文字描述的关联性，防止跨块割裂关键工艺逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 化纤行业文档常包含多页大型供需平衡表，需足够时间完成完整解析 |
| `chunk_size` | `800–1200 字符` | 兼顾工艺参数表的完整性与文字描述的上下文连贯性，避免跨块拆分关键参数 |
| `chunk_overlap` | `100–150 字符` | 保留工艺参数与前后文字描述的关联，防止召回时丢失上下文 |
| `PDF_PARSE_TABLE_MODE` | `fixed` | 化纤文档的表格多为固定格式，fixed模式可减少单元格错位问题 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 部分年度行业报告的PDF文件体积较大，需适配批量上传需求 |
| `CUSTOM_PARSE_SERVICE_URL` | 按自建服务实际地址填写 | 适配化纤文档的专用解析需求，替代通用解析提升表格识别准确率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传PDF文件后解析出的表格出现行列错位，字段对应关系混乱。原因：未将`PDF_PARSE_TABLE_MODE`设置为`fixed`，采用默认的流式解析模式无法适配化纤文档的固定格式表格。
- 现象：调用智能体API上传文件后返回`504 Gateway Timeout`状态码，解析任务失败。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时长不足，无法完成大型化纤行业报告的解析。
- 现象：自定义PDF解析服务未被触发，仍使用平台默认解析逻辑。原因：未在知识库设置中启用自定义解析功能，或`CUSTOM_PARSE_SERVICE_URL`配置的接口地址无法正常访问。

## 怎么确认配好了
- 上传一份包含大型供需平衡表的化纤行业PDF文档，查看解析后的表格是否保持行列对齐，无错位情况。
- 在知识库设置中查看`PARSE_FILE_TIMEOUT_SECONDS`参数值，确认其适配当前文档的解析时长需求。
- 调用智能体API上传测试文件，查看返回的解析结果是否包含完整的工艺参数字段与对应单位。
- 确认当前使用的FastGPT版本为4.8.20-fix2及以上，以支持`PDF_PARSE_TABLE_MODE`参数的完整配置。
- 检查自定义解析服务的接口日志，确认平台已向配置的`CUSTOM_PARSE_SERVICE_URL`发送解析请求。
