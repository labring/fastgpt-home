# 医美投研知识库建设的引用来源与溯源

## 这个品类的数据长什么样
医美投研数据主要来自国家药监局医美产品备案数据库、医美机构公开执业备案信息、行业协会发布的诊疗规范、脱敏的临床诊疗记录与学术期刊研究文献。数据更新节奏存在差异：药监备案数据随产品注册审批进度更新，机构运营数据随季度经营调整更新，临床研究文献随期刊发表实时收录。文档结构包含产品备案表（含产品名称、注册证号、生产厂家、适用范围）、诊疗项目清单（含项目编码、收费标准、耗材型号）、临床研究报告（含治疗方案、随访记录），字段包含注册证编号、执业范围、耗材用量单位、收费单价单位等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
医美投研数据的多来源与差异化更新节奏，要求溯源环节需明确标注数据的采集时间与官方备案编号，避免混用过期信息。不同文档类型的合规属性差异，要求溯源需区分执业备案、产品备案与临床数据的展示边界，不得超机构执业范围引用诊疗信息。字段包含明确的单位标识，要求溯源环节需保留原始字段的单位信息，不得擅自修改或省略。脱敏的临床数据需标注脱敏处理标识，确保引用内容符合医疗数据合规要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `topK` | `前8-12条` | 医美投研数据包含多维度备案、临床、机构信息，需覆盖足够候选来源确保引用准确性 |
| `scoreThreshold` | `0.75-0.85` | 医美数据专业性强，需过滤低相关结果，同时保留细分领域的小众临床研究数据 |
| `citationFormat` | `{来源名称}（{注册证号/备案编号}，{采集时间}）` | 医美数据需关联官方备案编号与采集时间，满足合规溯源要求 |
| `knowledgeBaseRefreshInterval` | `7天（药监备案数据）/1天（临床研究数据）` | 不同医美数据更新节奏差异大，分批次配置刷新周期确保数据时效性 |
| `sensitiveFieldMask` | `脱敏患者信息、机构详细地址` | 医美临床数据涉及隐私，需过滤敏感字段后再引用 |
| `citationDisplayMode` | `仅展示来源摘要与编号` | 避免暴露原始文档的冗余内容，符合投研场景的简洁溯源需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流中调用知识库搜索节点时，引用变量下拉框无可选内容。原因：未在全局变量配置中创建知识库ID类型的变量，或变量未绑定对应知识库的权限范围。
- 现象：生成的回答中显示知识库搜索的input和response原始内容。原因：未配置`citationDisplayMode`的仅展示摘要规则，或工作流中未屏蔽工具调用的原始日志输出。
- 现象：引用的医美产品数据显示过期备案编号。原因：未按数据类型分批次配置`knowledgeBaseRefreshInterval`，导致旧备案数据未及时更新。

## 怎么确认配好了
- 进入知识库管理页面，查看`knowledgeBaseRefreshInterval`的配置是否按数据类型分批次设置。
- 发起一次医美投研查询，检查生成回答的引用部分是否包含来源名称、备案编号与采集时间。
- 测试动态指定知识库的功能，确认工作流中引用变量下拉框可显示已配置的全局变量。
- 查看工具调用日志，确认未输出知识库搜索的input和response原始内容。
