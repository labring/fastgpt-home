# 半导体投研知识库建设的对话日志与审计

## 这个品类的数据长什么样
半导体投研的数据主要来自三类渠道：公开行业研报、晶圆代工厂及器件厂商的公开财报与产品参数手册、EDA设计工具的运行日志与供应链报价单。数据更新节奏差异较大，行业研报按周或月度更新，财报按季度发布，产品参数手册通常每季度修订一次。文档结构包含结构化的参数表格、非结构化的技术分析文本，以及时序类的产能、报价数据，部分字段带有明确单位，例如制程节点以纳米为单位，营收以亿美元为单位。

## 这些特征在「对话日志与审计」这一环带来什么约束
半导体投研数据的多源异构特征，要求对话日志需完整记录参数匹配、数据源版本、工具调用的时序关联。结构化参数字段多且带固定单位，审计环节需校验日志中返回的字段与知识库中存储的单位是否一致，避免出现单位不匹配的问答结果。不同数据源的更新频率差异，要求审计日志需标记每条问答引用的数据源更新时间，确保回溯时可验证信息的时效性。EDA工具日志与供应链报价的时序数据，要求对话日志需记录工具调用的触发时机与返回的时间戳区间，便于排查跨工具调用的链路问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `log_retention_days` | `90 天` | 半导体投研数据需按季度财报周期留存审计记录，90天可覆盖完整季度回溯需求 |
| `tool_call_log_detail` | `完整参数与单位` | 半导体数据字段带固定单位，需完整记录工具返回的参数单位，避免问答单位错误 |
| `max_context_window` | `8000–12000 字符` | 半导体研报与技术文档篇幅较长，需适配长文本上下文的日志记录 |
| `audit_trigger_threshold` | `相似度阈值 0.75` | 按知识库召回的相似度阈值触发审计，确保高相关性问答的日志可追溯 |
| `parse_file_timeout_seconds` | `600 秒` | 半导体参数手册与财报文档通常篇幅较大，需延长解析超时时间以完成完整日志记录 |
| `log_export_format` | `CSV 带字段元数据` | 结构化参数字段需附带元数据，CSV格式便于后续审计与合规校验 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用模块持续输出冗余运行记录，占用日志存储空间。原因：未配置`tool_call_log_detail`参数为精简模式，默认记录了完整的工具调用链路与中间参数。
- 现象：调用MCP工具时返回400错误，提示连接失败。原因：未设置`tool_call_timeout_seconds`参数适配半导体EDA工具的长调用周期，导致连接超时未完成握手。
- 现象：上传结构化的供应链网段记录表时，仅识别两列数据。原因：未配置对应参数调整Excel解析列数上限，默认仅解析前两列，无法适配多字段的半导体供应链表格。

## 怎么确认配好了
- 触发一次半导体参数查询，检查对话日志中是否包含完整的参数单位与数据源更新时间戳。
- 调用MCP工具获取晶圆产能数据，验证日志中记录了工具调用的完整链路与返回结果。
- 上传多列的半导体供应链表格，检查解析后的数据字段是否与原表格一致。
- 查看审计面板，确认所有高相关性的问答都被标记并记录了完整的上下文信息。
