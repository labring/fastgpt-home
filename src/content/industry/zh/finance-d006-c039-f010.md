# 厨卫电器投研知识库建设的数据库与运维

## 这个品类的数据长什么样
数据主要来自品牌官方技术手册、电商平台商品详情页、第三方检测机构报告、供应链报价文件。更新节奏随新品迭代、合规标准调整波动，无固定周期。文档形态包含结构化参数表、图文混合的产品说明、长格式行业分析文档。字段涵盖额定功率、安装尺寸、噪音分贝、能效等级等，单位多为瓦特、毫米、分贝(A)、年。

## 这些特征在「数据库与运维」这一环带来什么约束
结构化参数多但更新无固定周期，需支持动态字段扩展与增量同步；长文档与结构化数据混合存储，需兼容不同格式的解析与索引；多来源数据存在单位不统一（如功率标注有W和kW），需内置单位转换规则；新品发布时的批量数据导入，需支持高并发的批量写入与校验。投研场景需要回溯历史参数版本，需保留数据变更日志，进一步增加了存储与运维的复杂度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 适配厨卫电器长格式行业文档、多页参数手册的解析耗时需求，避免中途中断 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 支持批量导入多份产品说明书、年度供应链报告等大体积文件 |
| `召回条数` | `前8-12条` | 厨卫电器投研以单条参数匹配为主，过多召回会增加无效信息过滤成本 |
| `相似度阈值` | `0.75-0.85` | 参数类信息的语义匹配精度要求较高，避免低相关的参数条目被召回 |
| `MYSQL_CHARSET` | `utf8mb4` | 解决中文参数描述、产品名称的乱码问题，兼容全量字符集存储 |
| `DB_SYNC_BATCH_SIZE` | `50 条/次` | 平衡批量同步供应链数据的写入效率与数据库负载，避免单次请求过载 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：MySQL连接后中文参数显示为乱码，日志中出现`Incorrect string value`报错。原因：未将数据库连接字符集配置为`utf8mb4`，仅使用基础字符集无法兼容全量中文内容存储。
- 现象：10MB以上的Word格式产品文档解析耗时过长，任务状态显示`超时`。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`配置，默认超时时长不足以覆盖长文档的解析与索引构建流程。
- 现象：同时发起多个知识库同步任务时，部分任务返回`503 Service Unavailable`状态码。原因：未根据数据库连接池配置限制并发请求数量，单节点数据库连接被耗尽。

## 怎么确认配好了
- 执行单份10MB以上的Word文档上传解析，确认任务未超时，解析结果包含完整的参数内容。
- 导入包含中文参数描述的测试数据集，检查数据库存储的中文内容无乱码，可正常检索。
- 调整并发请求数量，发起批量同步任务，确认数据库连接未被耗尽，任务均正常完成。
- 发起参数检索请求，确认返回的条目数量与配置的`召回条数`匹配，无明显冗余或缺失。
