# 城商行投研知识库建设的数据库与运维

## 这个品类的数据长什么样
城商行投研数据来源包含内部信贷台账、区域经济统计报表、监管报送文件、本地产业研报及央行货币政策工具数据。更新节奏差异明显：内部信贷数据T+1更新，区域经济数据按月度或季度更新，监管文件按报送周期更新，行业研报实时发布。文档结构覆盖三类：结构化的信贷台账（含客户ID、授信额度、不良率等字段）、半结构化的研报（含发布机构、发布时间、核心观点）、非结构化的监管公文。字段单位包含万元、%、人次等，部分字段需适配区域专属统计口径。

## 这些特征在「数据库与运维」这一环带来什么约束
多来源的数据类型要求平台支持多数据库协议接入，需兼容MongoDB、MSSQL、Oracle等多种存储格式。不同更新频率的数据源会导致调度压力不均，需配置分层同步策略避免资源抢占。区域专属的统计字段要求数据库支持自定义字段映射，避免数据格式不兼容。金融数据的合规要求需确保数据库运维全程可审计，且本地数据不得跨区域传输，需支持本地化部署。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `FILE_PARSE_MAX_SIZE` | `1000 MB` | 城商行投研数据包含大额监管文件和行业研报，需适配单文件最大尺寸 |
| `DB_CONNECTION_TIMEOUT` | `30秒` | 适配城商行本地网络的常规连接耗时，避免不必要的超时中断 |
| `MAX_CONNECTION_POOL_SIZE` | `20-50` | 匹配城商行投研场景的并发查询规模，避免资源耗尽 |
| `DATA_SYNC_SCHEDULE` | 按数据源类型配置 | 内部信贷数据用`0 0 1 * * ?`，区域经济数据用`0 0 0 1 * * ?`，适配不同更新频率 |
| `ORACLE_CONNECT_ENABLE` | `开启` | 城商行常用Oracle存储核心信贷与监管数据，需加载对应驱动 |
| `AUDIT_LOG_RETENTION_DAYS` | `90天` | 满足金融数据合规审计的留存要求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：MongoDB连接状态查询失败，日志返回`Connection refused`报错。原因：未将平台部署节点的IP加入城商行内部MongoDB的访问白名单，导致外部访问被拦截。
- 现象：编排流程中连接MSSQL数据库时返回`Failed to connect to jyfkk:1433 - 38BBDDC3AF7F0000`错误，且本地MongoDB可视化工具可正常连接。原因：数据库连接字符串未正确指定MSSQL的实例名，或平台未配置MSSQL的端口转发规则。
- 现象：数据库连接配置界面仅显示三种数据库类型选项，无法选择Oracle。原因：未开启`ORACLE_CONNECT_ENABLE`配置项，平台未加载对应的数据库驱动组件。

## 怎么确认配好了
- 执行数据库连接测试操作，根据数据源类型调整连接参数直至测试通过。
- 触发一次全量数据同步任务，核对同步的文档数量与预期的数据源数据量一致。
- 查看审计日志模块，确认所有数据库操作均被正常记录，留存时长符合合规要求。
- 调用投研数据查询接口，核对返回的字段与预设的投研数据字段结构一致。
