# 塑料橡胶投研知识库建设的引用来源与溯源

## 这个品类的数据长什么样
塑料橡胶行业投研数据主要来自大宗商品交易所（如上海期货交易所、大连商品交易所）的现货/期货报价、中国塑料加工工业协会的行业调研数据、海关总署的进出口统计、第三方大宗商品报价平台的实时数据，以及专业机构发布的深度行业研报。数据更新节奏覆盖日更（现货即时报价）、周更（行业周报与库存数据）、月更（进出口与仓单统计）与季度更（深度分析报告）。文档类型包含结构化表格（含牌号、交割品级、升贴水、仓单数量等字段，单位多为元/吨、万吨、百分比）、半结构化的行业分析文稿与非结构化的市场动态内容。

## 这些特征在「引用来源与溯源」这一环带来什么约束
上述数据特征对引用来源与溯源环节带来多重约束。结构化数据占比高，溯源需精准匹配具体字段与发布周期，避免混淆不同交割牌号的报价数据；多源且更新频率差异显著，需在溯源信息中明确标注数据源类型与发布时间，防止使用过期数据支撑投研结论；单份文档长度跨度大，从数百字的即时报价单到数十页的深度研报，溯源需同时适配短切片与长切片的位置标记；字段包含专业术语与行业专属定义，溯源需保留原始字段名称，确保投研人员可快速验证数据准确性与合规性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 1000–1500 字符 | 适配塑料橡胶行业兼具短报价单与长周期研报的文档结构，保留表格与段落的信息完整性 |
| `召回条数` | 前 8–12 条 | 覆盖交易所、协会、海关等多类数据源，避免超出上下文额度影响回复连贯性 |
| `引用上限` | 1200–1800 token | 单份塑料橡胶研报有效信息密度较高，预留足够空间展示完整溯源内容 |
| `相似度阈值` | 0.72–0.85 | 过滤低相关性的历史归档数据，精准匹配当前投研问题中的牌号、交割期等关键词 |
| `引用来源展示开关` | 开启 | 满足投研场景的合规性与可验证需求，明确标注数据来源 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 适配大型行业研报的解析时长，避免超时截断关键内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置`引用上限`为1500后，返回结果仍超出该条数。原因：FastGPT 4.6.7版本中，未同步调整`maxContext`参数，或切块长度设置过大导致单块内容占用过多上下文额度。
- 现象：引用内容未包含文件地址或发布机构信息。原因：未开启`引用来源格式`的完整路径展示，或解析时未提取文档元数据字段。
- 现象：解析大型塑料橡胶研报时触发`504 Gateway Timeout`错误。原因：`PARSE_FILE_TIMEOUT_SECONDS`设置值过低，未预留足够解析时长。

## 怎么确认配好了
- 上传一份塑料橡胶现货报价单，发起针对性查询，查看返回结果的引用条数是否符合`引用上限`的设置值。
- 查看回复中的引用来源模块，确认包含文件路径、发布机构、发布日期等元数据信息。
- 调整`相似度阈值`至0.6，发起相同查询，观察召回结果的相关性变化，验证参数生效。
- 上传一份超过100页的塑料橡胶行业研报，检查解析后切片的溯源信息是否包含章节编号与页码。
