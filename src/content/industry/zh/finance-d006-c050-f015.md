# 塑料橡胶投研知识库建设的部署与升级

## 这个品类的数据长什么样
塑料橡胶投研数据主要来自国内大宗商品期货交易所、行业协会、海关进出口数据库、现货市场报价平台与专业研报机构。数据更新节奏存在差异：现货报价与期货行情为交易日实时更新，行业动态与企业经营数据为周度或月度更新，深度研报为季度或不定期发布。文档包含结构化的报价单、库存数据，字段包含密度、熔融指数、拉伸强度等化工专用参数，单位涉及g/cm³、g/10min、MPa等专业计量标准，同时包含非结构化的行业分析文本。

## 这些特征在「部署与升级」这一环带来什么约束
不同更新节奏的数据要求部署时支持定时全量与增量同步的灵活切换，避免全量同步占用过多系统资源。专业化工字段与单位要求部署时配置自定义实体识别词典，确保解析后的数据字段完整、单位统一。文档结构差异大的特点要求升级时适配多解析模板，分别处理短平快的现货数据与长篇幅的研报内容。数据量随市场波动变化的特性要求部署时预留足够的存储与向量库扩容空间，避免突发数据量导致系统卡顿。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `1500 MB` | 单份行业研报或海关数据文件通常不超过1500MB，该取值可覆盖绝大多数文件上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 长篇幅深度研报的解析耗时可达500秒左右，预留足够时间避免解析中断 |
| `maxContext` | `8000–12000 字符` | 塑料橡胶专业术语密集，足够的上下文长度可保留字段间的关联关系 |
| `召回条数` | `前8–12条` | 投研分析需要多维度数据支撑，该取值可平衡召回精度与系统资源消耗 |
| `相似度阈值` | `0.72–0.85` | 专业化工术语的语义区分度较高，该阈值可过滤无关召回结果 |
| `VECTOR_DB_REFRESH_INTERVAL` | `3600 秒` | 现货报价与行情数据日更，每小时刷新一次向量库可满足实时性需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：docker部署后上传大文件返回`413 Request Entity Too Large`错误。原因：未调整`UPLOAD_FILE_MAX_SIZE`参数，默认配置无法容纳单份大型行业研报文件。
- 现象：多用户并发访问时触发`CUDA out of memory`报错。原因：未根据模型参数量和并发数合理分配显存，32B模型单卡运行需预留至少24GB显存，每新增10个并发会话需额外预留2–3GB显存。
- 现象：外部模型调用失败，提示认证错误或无法连接本地部署的外部模型。原因：未通过环境变量`INITIAL_ROOT`设置正确的管理员密码，或未在模型配置中填写对应接口的地址与端口。

## 怎么确认配好了
- 上传一份包含专业化工参数的塑料橡胶现货报价文件，检查解析后的字段是否完整且单位正确，确认实体识别与解析配置生效。
- 发起指定数量的并发测试请求，查看系统显存与CPU占用情况，确认资源分配满足预设的并发需求。
- 手动触发一次增量同步任务，查看向量库更新日志，确认同步周期配置符合数据更新节奏要求。
- 调用外部模型接口发起测试请求，检查返回结果是否符合预期，确认认证参数与接口配置正确。
