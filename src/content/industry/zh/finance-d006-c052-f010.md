# 多元控股投研知识库建设的数据库与运维

## 这个品类的数据长什么样
投研数据涵盖结构化财务报表、行业深度研报、股权关联图谱三类，来源包含集团内部各子公司的业务系统、外部监管披露文件、第三方行业数据库与公开股权登记信息。结构化数据按季度同步更新，非结构化研报与实时资讯按日更新，股权关联数据随交易动态调整。文档包含统一的主体标识字段、内容字段与元数据字段，结构化字段附带明确数值单位，非结构化文档附带分类与来源标签。

## 这些特征在「数据库与运维」这一环带来什么约束
结构化数据的多维度关联需建立复合索引，降低跨表查询延迟；长篇幅非结构化研报需适配向量数据库的分段存储规则，避免单条向量数据过大；多源数据同步需配置定时校验任务，确保内部业务数据与外部公开数据的一致性；字段单位的统一存储规则需提前定义，减少后续数据清洗工作量；股权关联的多对多关系需优化向量索引结构，保障关联检索效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_MAX_CONNECTIONS` | `200–300` | 适配多源关联查询的并发连接需求，保障投研数据检索与同步任务稳定运行 |
| `MILVUS_COLLECTION_PARTITION_NUM` | `4–6` | 匹配多元控股多类投研数据的存储规模，降低单分区查询压力 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 覆盖长篇幅行业研报的解析时长，避免因文档过长导致解析失败 |
| `VECTOR_SEGMENT_LENGTH` | `800–1200 字符` | 适配投研文档的专业术语密度，保障语义召回的完整性与精度 |
| `DATA_SYNC_CRON_EXPR` | `0 0 2 * * *` | 选择每日凌晨非业务高峰时段执行增量同步，降低系统资源占用 |
| `MONGO_VERSION` | `4.4.29` | 兼容不支持AVX指令集的部署环境，解决版本兼容性报错问题 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：部署后出现`mongo version incompatible`报错，提示版本不兼容。原因：未根据服务器AVX指令集支持情况选择对应MongoDB镜像版本，或未匹配FastGPT支持的版本范围。
- 现象：投研数据同步任务频繁超时，数据库查询响应延迟过高。原因：未调整`MONGODB_MAX_CONNECTIONS`参数，并发连接数不足以支撑多源数据同步与检索的并发需求。
- 现象：数据库服务出现非预期资源占用峰值，核心检索任务卡顿。原因：误将sandbox容器纳入生产环境的数据库运维链路，未明确其仅为本地开发测试组件。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`MONGODB_MAX_CONNECTIONS`配置是否匹配当前并发任务规模，根据测试结果调整取值。
- 导入单篇长篇幅行业研报，查看解析日志，确认`PARSE_FILE_TIMEOUT_SECONDS`配置覆盖文档解析的实际时长。
- 执行多组向量召回测试，对比不同分段长度下的召回结果，调整`VECTOR_SEGMENT_LENGTH`至符合业务需求的取值。
- 查看定时同步任务的执行日志，确认`DATA_SYNC_CRON_EXPR`配置的执行时段未与核心业务时段重叠。
