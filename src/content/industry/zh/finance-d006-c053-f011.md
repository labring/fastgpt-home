# 多元金融投研知识库建设的文档解析与分块

## 这个品类的数据长什么样
多元金融投研的数据来源涵盖券商第三方研报、信托/资管企业财报、行业监管文件、市场交易统计文档等。更新节奏差异显著：监管文件随政策发布不定期更新，企业财报按季度/年度固定周期更新，行业研报则随市场事件实时更新。文档结构跨度大，短则数页的监管通知，长则数百页的财报附注；部分文档包含结构化表格，如资产负债表、行业规模统计，字段与单位绑定紧密，例如信托规模以亿元为单位、产品净值以元/份为单位，同时存在大量专业术语与嵌套章节结构。

## 这些特征在「文档解析与分块」这一环带来什么约束
多元金融文档的多源混合格式要求解析引擎同时支持文本提取、结构化表格识别与非结构化内容还原，避免遗漏专业字段与单位信息。文档长度跨度大的特征，要求分块逻辑可灵活调整粒度，避免拆分包含完整业务逻辑的段落。字段与单位的强绑定特性，要求分块时保留上下文关联，防止拆分跨字段的行或语句。嵌套章节与跨页表格的存在，则要求解析后还原原始文档层级，避免分块后上下文断裂，影响后续投研信息的检索与使用。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunk_size` | 800–1200 字符 | 适配多元金融文档的专业段落长度，避免拆分包含字段与单位的完整业务语句 |
| `chunk_overlap` | 100–150 字符 | 保留跨分段的上下文关联，避免专业术语或表格跨段信息丢失 |
| `parse_table_mode` | 结构化提取+保留排版 | 适配多元金融文档中大量的结构化表格，完整提取字段与单位信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 适配百页级财报附注的解析耗时，避免长文档解析超时 |
| `enable_table_merge` | 开启 | 解决跨页表格的错位问题，还原完整的表格结构 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配大型行业研报合集的上传需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传PDF或Word文档后，解析内容为空或返回「解析失败」报错。原因：未适配多元金融文档的大体积或复杂格式，例如未调整`UPLOAD_FILE_MAX_SIZE`参数，或未开启对应格式的解析插件。
- 现象：解析后的表格出现列错位、行断裂，或字段与单位分离。原因：未开启`enable_table_merge`配置，或`chunk_size`设置过小，拆分了跨页表格的完整行。
- 现象：开源版本API对接后，对话时上传文件解析失败，返回状态码413。原因：未在API网关配置中调整文件上传大小限制，超出FastGPT默认的`UPLOAD_FILE_MAX_SIZE`参数阈值。

## 怎么确认配好了
- 上传单份百页级财报文档，检查解析后的文本是否完整覆盖所有章节，无明显内容截断。
- 上传包含跨页表格的行业研报，核对解析后的表格是否完整拼接，无列错位或行缺失。
- 调用API上传小型监管文件，检查返回的解析结果是否包含完整的条款内容，无字段拆分错误。
- 查看平台解析日志，确认无超时报错，匹配配置的`PARSE_FILE_TIMEOUT_SECONDS`参数设置。
