# 家居用品投研知识库建设的数据库与运维

## 这个品类的数据长什么样
家居用品投研数据主要来源于行业协会公开统计资料、品牌方官方产品手册、跨境电商平台sku快照、海关进出口报关数据。更新节奏存在差异，行业合规类数据每季度更新，产品sku与售价数据每周同步，新品上市后24小时内补录。文档多为结构化表格与长文本结合，单篇包含产品编码、材质成分、出厂指导价、供应链产能、合规认证编号等字段，单位涵盖元/件、万套/年等。

## 这些特征在「数据库与运维」这一环带来什么约束
多来源与差异化更新节奏要求拆分存储不同类型数据，避免全量同步导致的运维负载过高。高频更新的sku数据需采用增量同步机制，减少全量拉取的资源消耗。结构化字段的强校验需求，要求数据库层面配置字段格式规则，避免无效数据写入。长文本行业报告与结构化sku数据的混合存储，需要针对性建立索引，覆盖高频查询的产品编码与合规认证字段，提升查询效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `增量同步间隔` | `12 小时` | 适配家居用品sku每周更新的节奏，避免同步频率过高占用资源，同时保证数据时效性 |
| `召回条数` | `前 12 条` | 家居用品投研需覆盖多维度sku与行业报告，召回过多会增加重排压力，12条可平衡召回范围与性能 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 长文本行业报告解析耗时较长，600秒可避免超时中断 |
| `相似度阈值` | `0.72–0.78` | 家居用品竞品对标查询需精准匹配，阈值过低会引入无关数据，过高则遗漏有效对标信息，按实测标定 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 部分海关进出口数据文档体积较大，该取值可支持完整上传 |
| `重排返回条数` | `前 5 条` | 投研报告最终输出需精简有效信息，5条可兼顾全面性与可读性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：开启问题优化与结果重排功能后，单条投研查询的返回时长超过30秒。原因：未调整`召回条数`与`重排返回条数`的取值，召回的文档数量过多导致重排计算占用过多资源。
- 现象：本地部署环境中，点击创建数据库按钮后弹出`database connection failed`报错。原因：未正确配置信创数据库的连接地址与认证参数，或未开放数据库服务的监听端口。
- 现象：工具选择环节同时触发多个检索请求，返回结果出现重复条目。原因：未配置工具调用的互斥逻辑，单轮会话允许同时发起多个并行检索任务。

## 怎么确认配好了
- 执行一次模拟投研查询，查看返回结果的文档更新时间与当前家居用品行业报告的发布周期匹配度，确认增量同步配置生效。
- 上传一份体积超过1000MB的海关数据文档，确认上传进度正常且无超时中断，验证上传配置合理。
- 调整`召回条数`与`重排返回条数`的取值，多次运行同一条竞品对标查询，对比返回时长与结果数量，确认配置符合业务需求。
- 检查数据库日志，确认仅在sku数据更新时段触发增量同步任务，无全量同步的冗余负载。
