# 家居用品投研知识库建设的部署与升级

## 这个品类的数据长什么样
家居用品投研数据主要来源于轻工制造行业协会的月度分析报告、品牌方的经销商库存台账、主流电商平台的SKU销售监测数据、海关进出口报关单。数据更新节奏覆盖月度、周度与每日：行业报告按月更新，销售监测数据按周更新，实时价格波动按日更新。文档结构包含SKU编码、材质、规格、售价、库存、渠道占比等字段，单位涵盖元/件、件、万元等，单份明细文档常包含多品类SKU的批量参数。

## 这些特征在「部署与升级」这一环带来什么约束
多源异构的数据来源要求部署阶段支持多格式接入配置，避免数据格式冲突。不同更新节奏的数据源需要配置差异化的定时同步任务，避免重复同步或遗漏更新。批量SKU明细文档的体量较大，要求调整文件解析的超时与大小限制，防止解析中断。字段的精细化程度较高，要求配置字段映射规则，确保投研数据的一致性。升级阶段需兼容新增的行业专用数据解析模块，避免因版本更新导致原有数据源的解析异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 家居用品投研数据常包含多SKU的明细表格，单文件体量较大 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 多SKU的批量解析需较长处理时间，避免中途超时中断 |
| `chunkSize` | `800–1200 字符` | 家居用品的产品参数、渠道分析文档篇幅较长，适配长文本分段 |
| `similarityThreshold` | `0.75–0.85` | 需精准匹配同品类SKU的参数与市场数据，避免低相关召回 |
| `recallTopK` | `前8–12条` | 投研分析需兼顾全面性与精准性，平衡返回数据量 |
| `SYNC_CRON_EXPR` | `0 0 2 * * *` / `0 0 * * *` | 适配月度行业报告、周度销售数据的不同更新节奏 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：执行`docker pull`命令返回`404 Not Found`或拉取超时。原因：未配置国内镜像加速地址，家居用品投研场景的镜像包含行业专用数据集，拉取带宽占用较高。
- 现象：升级至`v4.8.14-fix`版本后，语音播报功能无响应，日志显示`cosyvoice module not loaded`。原因：未在`docker-compose.yaml`中添加语音服务的环境变量配置，家居用品投研场景常需生成市场解读的语音文档，依赖新增的语音模块。
- 现象：调用代码运行接口后，客户端无法反序列化返回结果，返回状态码`500 Internal Server Error`。原因：未按新版本要求在`docker-compose.yaml`中配置前端访问地址，导致返回数据格式校验失败。

## 怎么确认配好了
- 执行`docker-compose up -d`后，查看容器日志，确认所有依赖服务启动无报错，根据数据源类型验证同步任务的触发时间是否符合配置。
- 上传一份家居用品SKU明细文档，检查解析后的字段是否与预设的映射规则一致，分段长度是否符合配置要求。
- 发起一次向量召回测试，核对返回的召回条数与配置的`recallTopK`取值一致，相似度匹配结果符合业务需求。
- 升级版本后，验证语音播报功能与代码运行接口的返回结果可被正常解析，无格式报错。
