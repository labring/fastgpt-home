# 小金属投研知识库建设的文档解析与分块

## 这个品类的数据长什么样
小金属行业数据来源包括中国有色金属工业协会小金属分会发布的月度供需报告、矿企年度产能公告、专业现货平台的日报、海关总署进出口统计周报。更新节奏覆盖日更、周更、月更与季度更新，文档多为PDF格式，包含文字分析、图片格式的供需平衡表、柱状图与现货价格表格。字段包含品位（%）、金属吨产量、元/吨度、美元/千克等，部分文档会混用不同单位的同品类数据，专业术语密度较高。

## 这些特征在「文档解析与分块」这一环带来什么约束
小金属行业文档的多源属性与复杂格式，对解析与分块环节提出多重约束。图片格式的表格与图表需要OCR支持才能提取完整文本，大体积季度报告需适配更长的解析时长与更大的上传限制。字段单位与数值强关联，分块时需保留上下文避免割裂，专业术语的密集分布要求分块长度适配专业内容的逻辑单元，不能过短导致语义断裂，也不能过长降低召回精度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_OCR_ENABLE` | 开启 | 小金属行业文档多包含图片格式的现货报价表、产能柱状图，无法直接提取纯文本内容 |
| `CHUNK_MAX_SIZE` | 800–1200 字符 | 小金属文档包含多单位字段（如元/吨度、美元/千克），过长分段会割裂单位与对应数值，过短则丢失供需逻辑关联 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 季度行业供需平衡报告常包含多页图表与数据表格，单文件体积可达数百兆 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 大体积多页文档解析需遍历图表与文本块，避免中途中断 |
| `RECALL_TOP_N` | 前8–12 条 | 小金属投研文档的专业术语密度高，过多召回会引入无关上下文，过少则覆盖不全供需逻辑 |
| `SIMILARITY_THRESHOLD` | 0.75–0.85 | 需过滤重复的行业政策摘要，保留差异化的供需数据片段 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
-  现象：上传单份体积超过500MB的小金属季度报告时，解析进度至90%出现“偏移量超出范围”报错。原因：未调整`UPLOAD_FILE_MAX_SIZE`与`PARSE_FILE_TIMEOUT_SECONDS`参数，大文件解析时内存占用超限导致索引偏移。
-  现象：分块结果中出现“元/吨”与对应数值分离的片段，无法关联小金属品类的报价数据。原因：未设置合理的`CHUNK_MAX_SIZE`，分段时割裂了单位与数值的上下文关联。
-  现象：批量上传多份小金属行业文档时，频繁出现网络错误导致上传中断。原因：未配置`UPLOAD_CONCURRENCY`参数，并发上传过多导致服务器资源耗尽。

## 怎么确认配好了
-  上传一份包含图片格式表格的小金属月度报告，检查解析结果是否包含完整的表格文本与OCR识别的数值。
-  手动拆分一份包含单位字段的文档片段，对比系统分块结果，确认单位与对应数值未被拆分至不同分段。
-  发起一次针对小金属供需数据的投研查询，检查召回结果的条数与相似度是否符合预期，无大量重复内容。
-  上传单份体积超过500MB的季度报告，等待解析完成，确认未出现超时或偏移报错。
