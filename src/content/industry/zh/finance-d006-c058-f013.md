# 小金属投研知识库建设的知识库检索与召回

## 这个品类的数据长什么样
小金属投研数据主要来自行业协会公开报告、海关进出口统计、现货交易平台报价、矿山企业公开披露文件及专业投研机构研报。更新节奏分为每日现货报价、每周供需跟踪、每月行业动态及不定期专项研报。文档类型包含结构化行情表格、非结构化研报文档与政策文件，结构化表格字段包含品种名称、规格型号、产地、报价、涨跌幅度，单位多为元/吨、元/千克或金属含量占比。

## 这些特征在「知识库检索与召回」这一环带来什么约束
小金属数据的多类型、多更新节奏与多字段单位特征，对检索召回环节带来多重约束。结构化行情表格需要精准匹配字段，否则会混入无关的非结构化研报内容。高频更新的现货数据需要设置增量同步机制，避免全量同步带来的资源浪费与数据滞后。长文档研报拆分时需保留上下文关联，避免拆分后语义断裂影响检索相关性。不同单位的报价数据需在召回前做归一化处理，否则会导致同品种不同规格的报价无法正确匹配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `CHUNK_SIZE` | 800–1200 字符 | 小金属研报多包含长段落的供需分析，该长度可保留上下文关联，避免拆分后语义断裂 |
| `RECALL_TOP_K` | 前10条 | 小金属品种较少但细分规格多，需召回足够多的候选结果覆盖不同规格的行情数据 |
| `SIMILARITY_THRESHOLD` | 0.75–0.85 | 规避低相关的非结构化文档，同时保留细分规格的匹配结果 |
| `PARSE_FILE_MAX_SIZE` | 50 MB | 单份行业研报或供需报告通常不超过该大小，避免解析超时 |
| `UPLOAD_INCREMENTAL_INTERVAL` | 3600 秒 | 现货报价每日更新，每小时增量同步可保证数据时效性 |
| `IMAGE_PARSE_ENABLE` | 开启 | 部分行情文档包含K线图与规格标注图，需解析图像中的文字信息 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传包含K线图的文档后，检索结果未提取图像内的文字内容。原因：未开启`IMAGE_PARSE_ENABLE`配置项，仅解析了文档内的原生文本。
- 现象：检索结果中同品种不同产地的报价无法正确匹配。原因：未对结构化表格中的单位做归一化配置，导致元/吨与元/千克的报价被判定为不相关内容。
- 现象：知识库应用返回的回答超出预设的字数限制。原因：未限制知识库召回的上下文总长度，导致召回的多段内容超出后续大模型处理的上下文阈值。

## 怎么确认配好了
- 上传一份包含行情表格与K线图的测试文档，查看解析后的文本是否包含图像内的标注文字，确认配置生效。
- 提交包含小金属细分规格的查询词，核对召回结果的数量是否符合预设的召回条数设置。
- 查看知识库的增量同步日志，确认更新频率与配置的同步间隔一致。
- 触发一次完整的检索流程，核对返回的上下文内容是否存在语义断裂的情况，确认分段配置合理。
