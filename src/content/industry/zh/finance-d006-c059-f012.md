# 工业金属投研知识库建设的模型接入与配置

## 这个品类的数据长什么样
工业金属数据来源包括国内有色金属行业协会公开数据、期货交易所交割仓单数据、海关进出口贸易统计、头部矿山及加工企业定期公告。更新节奏分为实时（期货盘面价格）、每日（现货报价）、每周（社会库存）、每月（供需报告）。文档结构包含结构化表格、半结构化研报、原始公告文档，字段包含产品牌号、产地、规格型号、计价单位、交割标准等级等。

## 这些特征在「模型接入与配置」这一环带来什么约束
多来源、多更新频率的数据要求模型接入时配置分层的调用优先级，适配实时与离线数据的不同请求节奏。结构化字段的单位差异要求配置自定义的单位映射规则，避免模型处理时出现数值混淆。多格式文档要求配置可自定义的解析模板，适配表格、研报、公告的不同结构。高频实时数据的接入需要调整模型的上下文窗口长度，适配短间隔的请求。数值型字段占比高的特征，要求配置召回时的字段匹配规则，提升精准度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 工业金属研报包含多组关联数值字段，需要足够上下文保留数据关联关系 |
| `parseChunkSize` | `600–800 字符` | 结构化表格单条记录字段较多，分段过小割裂字段关联，过大增加召回冗余 |
| `similarityThreshold` | `0.72–0.85` | 工业金属数据数值字段匹配精度要求高，阈值过低引入无关数据，过高导致召回不足 |
| `recallTopK` | `前 6–10 条` | 投研场景需兼顾全面性与精准性，过多召回会增加模型处理负担 |
| `apiRequestTimeout` | `30–60 秒` | 部分行业数据源响应较慢，超时过短会导致数据拉取失败 |
| `customParseRule` | 按「牌号、产地、计价单位」匹配提取字段 | 工业金属结构化数据字段命名标准化程度高，可通过规则快速提取目标字段 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：界面提示指定模型不存在或无法访问，或返回`1742438308259968`错误码。原因：未按照工业金属投研场景的模型调用规范配置模型标识，或未开放对应模型的访问权限。
- 现象：调用嵌入模型时返回请求url错误，或接口返回400状态码。原因：未适配工业金属数据源的接口格式，未在配置中补充专属的请求路径参数。
- 现象：工作流中调用模型后返回空字段，或数据库连接超时。原因：未配置工业金属数据的单位转换规则，导致模型无法识别带特殊单位的数值字段。

## 怎么确认配好了
- 发起单条工业金属现货报价数据的模型调用测试，核对返回结果中是否正确提取了目标字段与计价单位。
- 批量导入不同来源的工业金属文档，核对解析后的分段内容是否保留了字段关联关系。
- 查看模型调用日志，确认请求参数与配置项匹配。
- 测试高频数据的连续调用，核对接口响应状态是否正常。
