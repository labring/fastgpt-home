# 工程机械投研知识库建设的引用来源与溯源

## 这个品类的数据长什么样
工程机械投研数据主要来自行业协会公开报告、主机厂官方产品手册、工程招投标公示数据、终端运营工况日志。数据更新节奏因类型而异：主机厂新品参数每季度更新，招投标数据每日同步，工况日志实时生成。文档结构包含标准化参数表格（含额定起重量、最大作业半径等字段，单位为吨、米、千瓦）、工况适配分析段落、供应链成本拆解明细，每份文档附带发布日期与数据源标识。

## 这些特征在「引用来源与溯源」这一环带来什么约束
多源异构的数据来源要求溯源环节需标记每段引用的数据源类型与权威性等级，避免不同来源的参数冲突；不同更新节奏的数据需要在溯源中附带时间戳，便于筛选时效性符合投研需求的内容；标准化的字段与单位要求溯源时需保留原始单位标注，防止参数混淆；长文档与复杂表格的结构，要求溯源需精准定位到具体段落或表格行，仅关联整份文档不符合要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `相似度阈值` | 0.78-0.82 | 工程机械参数字段标准化程度高，该区间可平衡精准匹配与老旧型号数据的召回覆盖 |
| `召回条数` | 10-15条 | 单份工程机械文档包含多组核心参数，适量召回可覆盖投研所需的多维度数据 |
| `rerank_top_k` | 4-6条 | 重排后需保留最匹配的核心数据源，避免冗余信息干扰投研判断 |
| `引用片段最大长度` | 1000-1500字符 | 适配工程机械工况分析段落、产品参数表的标准排版长度，保留完整上下文 |
| `溯源信息包含字段` | 保留`数据源名称`、`文档发布时间`、`原始页码` | 投研报告需明确标注数据来源的权威性、时效性与精准位置，满足合规要求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为开启`rerank_top_k`后，检索返回的引用片段为空。原因是设置的`rerank_top_k`小于`召回条数`，且未配置兜底召回逻辑，导致重排过滤后无有效片段保留。
- 现象为导出的溯源JSON文件中缺少`原始页码`字段。原因是未在`溯源信息包含字段`配置中勾选该字段，或文档解析环节未开启页码提取功能。
- 现象为多源数据检索后，溯源信息未区分数据源类型。原因是未配置数据源分类标记参数，无法区分行业协会报告、主机厂手册等不同来源的优先级。

## 怎么确认配好了
- 上传一份工程机械产品手册，发起关键词检索后，查看结果侧边栏，确认是否显示配置的溯源字段。
- 调整`相似度阈值`至区间上下限，对比检索结果的召回条数变化，验证阈值取值的合理性。
- 开启重排功能后，检查返回的引用片段数量是否与`rerank_top_k`的设置一致，无异常空值。
- 导出检索结果的溯源JSON文件，核对是否包含所有配置的溯源字段，无缺失项。
