# 工程机械投研知识库建设的文档解析与分块

## 这个品类的数据长什么样
工程机械投研数据主要来自行业协会公开报告、上市工程机械设备厂商的年报与产品手册、政府招投标公告、行业展会资料及第三方调研文档。更新节奏存在差异：行业动态类内容按周更新，上市公司年报按季度或年度发布，产品参数随厂商技术迭代不定期更新，招投标公告随项目进度实时更新。文档结构混合多样，包含纯文字的行业趋势分析、带嵌套表格的技术参数文档、结构化的设备销量数据表，以及标注工况参数的技术手册。字段与单位具有明确针对性，设备参数类字段包含额定功率、最大掘起力、作业半径等，对应单位分别为kW、kN、m，项目类字段包含预算金额、工期，对应单位为万元、天。

## 这些特征在「文档解析与分块」这一环带来什么约束
工程机械投研数据的混合结构特征要求解析环节需同时处理纯文字段落与嵌套表格，避免表格内容被拆分为无关联的零散文本。多类型更新节奏要求分块环节可适配不同文档的解析耗时，避免短文档解析超时或长文档解析不完整。针对性的字段与单位要求分块后需保留字段与单位的绑定关系，避免参数信息丢失。长文本分析报告占比高，分块时需控制单块长度以适配大模型上下文窗口，同时避免跨章节语义割裂。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `enable_advanced_pdf_parse` | 开启 | 工程机械文档多包含嵌套表格与技术参数，增强解析可保留表格结构与字段关联 |
| `chunk_size` | 800–1200 字符 | 工程机械文档含长技术段落与结构化参数，该区间可保留单段语义完整性，适配通用上下文窗口 |
| `chunk_overlap` | 100–150 字符 | 设备参数表与分析段落衔接紧密，重叠设置可避免语义割裂 |
| `table_vector_support` | 开启 | 工程机械文档含大量设备参数表格，开启后可将表格拆分为结构化向量条目 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 大型年报与招投标文档解析耗时较长，该时长可覆盖多数场景 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 大型行业报告PDF体积较大，该阈值可支持完整上传 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：在插件管理界面无法找到`enable_advanced_pdf_parse`配置项，解析PDF后表格内容错乱。原因：本地部署时未安装minerU依赖包，增强解析模块未被加载。
- 现象：开启`table_vector_support`后，解析出的设备参数表仅保留数值，丢失额定功率、斗容等字段名与单位。原因：未同时开启`enable_advanced_pdf_parse`，基础解析无法提取表格的表头语义。
- 现象：通过API拉取飞书多维表数据后，解析结果无结构化字段关联。原因：未配置表格向量支持的映射规则，导致多维表的列名与数值未被绑定。

## 怎么确认配好了
- 上传一份包含嵌套表格的工程机械产品手册PDF，查看解析结果中表格的表头与单元格内容是否完整关联。
- 进入目标知识库的设置页面，确认`enable_advanced_pdf_parse`与`table_vector_support`开关均处于开启状态。
- 上传一份体积较大的行业报告文档，检查解析任务的执行时长是否匹配配置的超时阈值。
- 调用知识库解析API上传小型设备参数表，确认返回的向量数据包含字段名与单位信息。
