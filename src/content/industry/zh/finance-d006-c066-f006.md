# 房建工程投研知识库建设的对话日志与审计

## 这个品类的数据长什么样
房建工程投研的数据主要来源于住建部门发布的工程定额标准、公开招投标项目文件、施工单位的月度施工日志、建材行业协会的价格台账及设计图纸技术说明。数据更新节奏差异明显：建材价格按周或月度更新，工程定额按季度或年度更新，招投标项目则随项目进度实时更新。文档结构包含固定字段：子目编码、建设单位、项目ID、开工日期、计价单位（如元/立方米、工日、吨）、预算金额等，单份文档篇幅从数百字到数万字不等，部分设计图纸的文字说明类文档篇幅较长。

## 这些特征在「对话日志与审计」这一环带来什么约束
房建工程投研数据的专属特征对对话日志与审计提出了明确约束：首先，数据包含项目ID、子目编码等唯一标识字段，要求日志系统需关联对应字段，实现特定项目的精准追溯；其次，多频次的更新节奏要求日志必须记录问答时的数据源版本，避免跨版本审计出现数据偏差；第三，文档篇幅跨度大的特点，要求日志系统支持长文本上下文的完整存储，防止关键信息被截断；最后，多维度的业务字段要求审计界面支持按建设单位、施工部位等自定义维度筛选日志，提升审计排查效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `LOG_RETENTION_DAYS` | `90 天` | 房建工程投研的常规审计追溯周期为季度至半年，90天覆盖多数合规要求 |
| `AUDIT_LOG_FIELDS` | `["project_id", "sub_code", "quote_unit", "query_time"]` | 房建工程数据包含项目ID、子目编码、计价单位等专属业务字段，需纳入审计维度 |
| `MAX_LOG_CONTENT_LENGTH` | `8000 字符` | 房建工程的招投标文件、施工日志文本较长，需完整存储问答上下文避免截断 |
| `USER_IDENTIFIER_FIELD` | `user_external_id` | 需关联企业内部的项目经办人ID，实现精准的操作审计与责任追溯 |
| `LOG_SAMPLING_RATE` | `100%` | 投研问答涉及工程计价、合规性审核，需全量记录日志用于后续审计 |
| `PROXY_LOG_FILTER` | `exclude:["thinking_process"]` | 配置代理后，过滤思考过程字段，避免非问答内容混入历史对话记录 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：对话日志中未显示问答推理时间字段。原因：未开启`ENABLE_REASONING_TIME_LOG`配置项，或配置项取值为`false`。
- 现象：对话日志无法关联到具体项目经办人。原因：未配置`USER_IDENTIFIER_FIELD`为企业内部的项目ID字段，仅使用默认的匿名用户标识。
- 现象：无法批量删除指定项目的对话日志。原因：未配置`AUDIT_LOG_FILTER`为按项目ID筛选的规则，仅支持按全局范围清理日志。

## 怎么确认配好了
- 发起一条针对房建工程子目计价的测试问答，进入日志详情页，验证是否包含配置的审计字段。
- 进入日志管理页面，检查日志保留时长是否符合预设的配置要求，未出现提前清理的情况。
- 尝试批量筛选指定项目ID的日志，验证是否可以精准定位对应问答记录。
- 配置代理后发起测试问答，确认思考过程是否按照预期在日志中展示或隐藏。
