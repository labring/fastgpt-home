# 房建工程投研知识库建设的引用来源与溯源

## 这个品类的数据长什么样
房建工程投研相关数据主要来源于住建部发布的工程建设标准规范、项目招投标文件、施工图设计资料、材料供应商技术手册及现场施工日志。数据更新节奏随文件类型差异较大，国家标准每2至3年修订一次，项目专属文档随施工周期同步更新，材料参数手册每季度更新。文档结构多包含标准条文、参数表格、施工节点说明，核心字段包括项目编号、材料型号、规范文号，常用单位为平方米、立方米、吨等工程计量单位。

## 这些特征在「引用来源与溯源」这一环带来什么约束
房建工程投研数据的多源分散特性，要求溯源系统需同时关联国家标准文号、项目专属编号及材料手册批次号，避免不同来源的同类数据混淆。不同文件的更新节奏差异，要求溯源信息需包含版本标识，确保引用内容与当前有效版本匹配。工程类文档多包含长文本参数表格，分段检索后需精准定位原文的具体页码或段落范围，避免溯源偏移。专用计量字段的存在，要求溯源字段需兼容平方米、立方米等非通用单位的关联标注，确保引用信息的工程场景准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `cite_enable` | 是 | 房建工程投研需明确引用来源，启用后可在对话输出中关联知识库条目 |
| `cite_max_count` | 前10条 | 房建工程数据多关联多份标准或项目文档，限制召回条数避免引用冗余，同时覆盖核心参考来源 |
| `chunk_size` | 800–1200 字符 | 房建工程文档多包含长参数表格与条文，该分段长度可保留完整的工程参数上下文，提升溯源准确性 |
| `cite_version_enable` | 是 | 房建工程国家标准定期修订，启用版本记录可确保引用内容与当前有效版本匹配 |
| `cite_field_map` | 按实测标定 | 房建工程字段包含项目编号、规范文号等专用标识，需映射知识库自定义字段与溯源展示字段 |
| `api_cite_return` | 开启 | 需通过对话接口返回引用ID，满足工程师对接外部系统的溯源需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：对话输出中出现句末引用号乱码，最终输出变为普通引号。原因：未正确配置`cite_format`参数，导致引用符号的转义逻辑与工程文档中的特殊字符冲突。
- 现象：当提问超出知识库覆盖范围时，仍返回知识库条目的引用信息。原因：未开启`rag_strict_mode`配置项，导致系统在无匹配知识库内容时仍生成关联引用，不符合投研场景的严谨性要求。
- 现象：对话请求接口未返回`cite`字段的引用ID。原因：未开启`api_cite_return`配置项，或接口调用时未正确配置返回引用信息的参数，导致溯源数据未被纳入接口响应。

## 怎么确认配好了
- 发起包含房建工程专用术语的提问，检查对话输出末尾的引用格式是否符合预设规则，无乱码或符号错误。
- 发起超出知识库覆盖范围的提问，验证输出中未出现知识库条目的引用信息，符合投研场景的严谨性要求。
- 调用对话接口，检查响应体中是否包含`cite`字段及对应的引用ID，确认溯源数据已被正确返回。
- 查看知识库检索日志，确认分段后的溯源信息关联了正确的文档页码、规范文号或项目编号等专属字段。
