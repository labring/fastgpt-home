# 房建工程投研知识库建设的部署与升级

## 这个品类的数据长什么样
房建工程投研数据主要来自住建部门公开定额文件、招投标公示平台、施工单位归档的项目日志与竣工验收报告、建材供应商的报价台账。数据更新节奏差异明显，建材报价随市场波动更新，工程定额定期修订，招投标项目信息实时发布。单份文档多为结构化表格或长文本报告，包含项目编号、建筑面积、建材型号、施工周期、造价明细等字段，单位涵盖平方米、立方米、元/吨、工作日等。

## 这些特征在「部署与升级」这一环带来什么约束
房建工程投研数据的多源、异更新节奏、混合格式与多单位特征，对部署与升级环节带来多重约束。多源数据接入需适配公开文件与实时接口的不同鉴权方式，部署阶段需提前配置多源同步的路由规则。异更新节奏要求增量拉取逻辑支持按数据类型设置不同的同步周期，升级时需兼容旧版同步配置，避免数据断层。混合结构化与非结构化文档，需预设适配两类格式的解析参数，防止长文本截断或表格字段提取不全。多单位字段需额外配置归一化规则，确保后续检索的单位一致性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600-900 秒` | 单份房建工程文档篇幅较长，包含大量定额说明与造价明细，需足够时间完成完整解析 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 部分竣工报告、定额合集类单文件体积较大，需适配大文件上传需求 |
| `PARSE_CHUNK_SIZE` | `1500-2000 字符` | 房建文档包含连续的专业内容，分段长度适配内容密度，避免上下文断裂或信息截断 |
| `SIMILARITY_THRESHOLD` | `0.75-0.85` | 房建专业术语多，较高阈值可过滤无关通用建筑文档，确保召回内容的相关性 |
| `RECALL_TOP_K` | `前 8-12 条` | 投研需覆盖造价、工期、定额等多维度信息，适量增加召回条数以保证信息完整性 |
| `UNIT_NORMALIZATION_ENABLE` | `开启` | 房建数据包含平方米、立方米、元/吨等多类单位，统一格式可避免检索时的单位不匹配问题 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 执行`docker pull`命令时出现拉取失败报错，返回`manifest unknown`状态码。原因是未指定正确的版本后缀，房建工程场景需使用适配大文件解析的`v4.8.15-fix2`版本镜像，误写为通用版本标签导致无法匹配。
- 配置免登录分享链接后，访问时出现403状态码或页面无法加载。原因是未配置对应节点的跨域权限，房建工程的招投标数据多为公开内容，分享场景需额外配置跨域白名单。
- 上传长文档后解析失败，后台日志显示`parse timeout`。原因是未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时间过短，无法完成长文档的完整解析。

## 怎么确认配好了
- 上传一份典型的房建工程竣工报告，检查解析后的文本是否包含完整的造价明细与项目参数，确认分段与超时配置生效。
- 配置增量同步任务，查看同步日志中不同数据源的拉取时间是否符合预设周期，确认增量同步规则生效。
- 发起一次针对专业术语的检索，检查返回结果的单位是否统一，确认单位归一化配置生效。
- 生成免登录分享链接，在对应网络环境下访问，确认页面可正常加载，确认分享与跨域配置生效。
