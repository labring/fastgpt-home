# 教育服务投研知识库建设的多轮对话与提示词

## 这个品类的数据长什么样
这个品类的数据主要来自教育主管部门公开政策文本、院校学科建设公开报告、教育装备行业招投标数据、权威教育研究机构行业白皮书及教育类主体公开运营信息。政策类文档按季度或专项事件更新，行业白皮书按年度发布，招投标数据按月度更新。文档结构包含文号、发布单位、生效日期等固定元数据，部分报告附带调研样本说明与统计模块。字段包含适用学段、预算金额、中标周期等，对应单位为学段、万元、自然日。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
上述数据特征对多轮对话与提示词环节带来多重约束。首先，元数据字段因文档类型差异存在显著区别，提示词需明确区分政策文本、招投标数据、行业报告的提取规则，避免混淆不同类别的字段信息。其次，政策与招投标数据时效性较强，多轮对话需限制上下文窗口的有效时长，防止调用已失效的政策内容或过时的招投标结果。此外，部分行业报告附带调研样本说明，对话需支持完整上下文回溯，以响应用户针对样本细节的追加提问。最后，不同文档的结构差异要求提示词适配不同的内容解析逻辑，无法使用单一模板覆盖全品类数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 教育服务投研数据包含多类文档，需保留足够上下文关联信息，同时适配主流大模型的上下文窗口限制 |
| `recallTopK` | `前 6–8 条` | 教育投研数据分散且字段多样，适量召回可覆盖多维度信息，避免冗余内容干扰对话 |
| `simThreshold` | `0.75–0.85` | 需区分教育政策新旧版本、招投标项目相似预算区间，避免召回无关内容 |
| `contextExpireTime` | `3600 秒` | 教育政策更新周期多为季度，该时长可避免调用过时内容，同时保留会话连贯性 |
| `promptTemplate` | 按文档类型匹配解析规则，优先提取用户指定字段 | 教育投研数据结构差异显著，需按政策、招投标、行业报告类型适配不同解析逻辑 |
| `streamResponse` | `开启` | 教育投研内容篇幅较长，流式输出可提升交互体验，适配API调用的实时性需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流执行至知识库搜索或AI对话环节后终止，无法完成后续流程。原因：未配置`contextExpireTime`参数，会话上下文超时被清空，无法传递后续环节所需的检索关键词。
- 现象：API调用对话接口仅返回完整静态响应，无流式输出效果。原因：未开启`streamResponse`配置项，或未按要求配置流式数据的接收逻辑。
- 现象：多轮对话中提取的字段与文档实际内容不符，例如混淆政策生效日期与招投标中标周期。原因：未按文档类型配置`promptTemplate`，提示词未明确区分不同文档的字段提取规则。

## 怎么确认配好了
- 发起包含多轮上下文的测试提问，核对对话返回的内容是否包含最新的政策信息与对应元数据，确认上下文未被提前清空。
- 调用API接口测试流式输出，核对响应是否按字符分段返回，确认`streamResponse`配置项已生效。
- 上传不同类型的教育服务投研文档，发起字段提取类提问，核对返回结果是否匹配对应文档的字段规则，确认`promptTemplate`配置合理。
- 查看工作流执行日志，确认会话上下文的传递链路完整，无中途中断或参数丢失的情况。
