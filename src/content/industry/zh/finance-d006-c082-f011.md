# 水产养殖投研知识库建设的文档解析与分块

## 这个品类的数据长什么样
水产养殖投研的数据来源涵盖养殖户现场监测日志、行业协会发布的行情简报、科研院所的养殖实验报告、电商平台的水产价格数据，以及公开的养殖技术文档。更新节奏覆盖实时的水质监测数据、每日的投料记录、月度的出栏与价格报告，以及年度的行业发展分析。文档类型包含结构化的表格报表、纯文本的养殖日志、附带病害诊断图片的案例文档，字段涉及溶解氧、水温、投料量、养殖密度等，单位包含mg/L、℃、kg、亩、立方米等。

## 这些特征在「文档解析与分块」这一环带来什么约束
混合类型的文档结构要求解析逻辑需同时适配结构化表格、纯文本与带图片内容，避免单一解析模式导致的信息丢失。高频更新的短文档与低频长文档并存，需要灵活调整分块粒度，既不能因分块过长导致召回冗余，也不能因分块过碎破坏专业术语的连贯性。带图片的病害案例文档要求解析环节需支持图片OCR提取，否则大模型无法获取图片内的病灶描述信息。公开网页与PDF文档混合导入的场景，需要配置允许的数据源域名，避免非授权链接被解析。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_MODE` | `auto` | 覆盖结构化报表、文本日志、带图片案例的混合文档类型，自动适配不同文档的解析逻辑 |
| `CHUNK_SIZE` | `800–1200 字符` | 平衡水产养殖文档的短监测记录与长技术段落的上下文连贯性，适配常规召回需求 |
| `IMAGE_OCR_ENABLE` | `true` | 水产养殖文档中病害诊断案例占比高，需提取图片内文本供大模型调用 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 大型养殖科研报告解析需较长处理时间，避免超时中断解析流程 |
| `ALLOWED_URL_DOMAINS` | `*.yuque.com, *.agri.gov.cn` | 允许解析公开的行业报告、语雀养殖记录链接，过滤非授权数据源 |
| `TABLE_EXTRACT_MODE` | `keep_structure` | 保留养殖报表的表格结构，避免溶解氧、投料量等结构化数值与单位分离 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传水产病害诊断PDF后，解析结果未包含图片内的病灶描述文本。原因：未开启`IMAGE_OCR_ENABLE`配置，或配置项取值为`false`，未触发图片OCR提取。
- 现象：导入语雀公开分享的养殖记录链接后，系统提示“无法解析该网址”或返回403报错。原因：未将`yuque.com`域名添加至`ALLOWED_URL_DOMAINS`配置列表，或链接未设置为公开可访问权限。
- 现象：解析养殖投料报表后，分块内容中溶解氧数值与mg/L单位分离显示。原因：未启用`TABLE_EXTRACT_MODE`的`keep_structure`配置，导致表格结构被打散为纯文本。

## 怎么确认配好了
- 上传一份包含结构化养殖报表的PDF文档，核对解析结果是否保留表格的行列结构与对应数值单位。
- 上传一份附带病害诊断图片的养殖技术文档，确认解析结果中包含图片内的OCR提取文本。
- 导入一条已设置公开分享权限的语雀链接，确认系统无解析报错且成功拉取文档内容。
- 选取一段长养殖日志文档，测试不同`CHUNK_SIZE`配置下的分块效果，选定适配业务召回逻辑的取值范围。
