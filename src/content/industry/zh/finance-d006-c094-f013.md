# 炼化投研知识库建设的知识库检索与召回

## 这个品类的数据长什么样
炼化投研的数据来源涵盖企业内部DCS系统运行日志、生产台账Excel文件、行业协会公开的炼化产能报告、第三方原油与化工品价格数据库。数据更新节奏存在差异：生产类台账数据每日更新，工艺手册类静态文档仅在工艺迭代时更新，行业研报与行情数据不定期发布。文档类型包含多页PDF工艺说明、结构化表格台账、纯文本研报摘要，字段包含装置进料量、产品产出量、设备运行时长等，对应单位分别为立方米/小时、吨、小时。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据格式要求检索系统适配不同文档的解析规则，避免丢失结构化台账中的关键数值。差异化更新节奏需要区分全量与增量索引策略，防止全量刷新占用过多计算资源。文档长度与结构差异要求分段策略兼顾专业术语的完整性与上下文连贯性，避免拆分破坏工艺描述的逻辑。多类型字段与单位需要统一映射规则，防止因单位不匹配导致检索结果偏差。专业术语密集的文本需要额外的词表增强，提升专业内容的召回精度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | `800–1200 字符` | 炼化文档多为长文本工艺描述，过长分段会丢失上下文关联，过短会破坏专业术语的完整性 |
| `召回条数` | `前6–10 条` | 炼化投研需覆盖工艺、市场、合规等多维度数据，过多结果会增加上下文窗口压力，过少会遗漏关键信息 |
| `相似度阈值` | `0.72–0.85` | 炼化专业术语匹配度要求较高，过低会引入无关文档，过高会遗漏相似工艺方案 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 炼化工艺手册多为多页PDF，单文件体积普遍较大，需适配大型文件上传 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 大型Excel生产台账包含多工作表数据，解析耗时较长，需延长超时时间 |
| `增量更新触发条件` | `按文件修改时间触发` | 炼化生产数据每日更新，按修改时间可精准同步新增或修改的文档 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为上传文档后分段数从显示的初始值变为更高数值，出现重复片段。原因是未开启`文档去重`配置，且分段时未基于文档唯一标识进行分片校验，导致同一文本块被多次拆分索引。
- 现象为搜索特定炼化工艺参数时无召回结果。原因是未配置专业术语同义词表，导致“常压塔”与“常压蒸馏塔”等相似术语无法匹配召回。
- 现象为批量创建多个知识库后，无法通过变量选择指定检索范围。原因是未将知识库变量的可选值配置为对应知识库的唯一标识，仅填写了知识库名称。

## 怎么确认配好了
- 上传单份炼化工艺PDF文档，查看解析后的分段列表，核对分段长度是否符合预设配置范围。
- 发起针对已知炼化工艺参数的检索，核对召回结果的相似度是否落在预设区间内。
- 配置增量更新任务后，修改一份生产台账文件，验证是否仅同步更新该文件的索引内容。
- 配置多知识库变量后，尝试切换变量值，核对检索范围是否对应切换至指定的知识库。
