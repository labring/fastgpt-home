# 玻璃投研知识库建设的模型接入与配置

## 这个品类的数据长什么样
玻璃投研数据主要来源于行业协会公开报告、大宗商品现货交易平台报价、海关进出口报关数据及生产企业月度运营简报。现货价格数据按日更新，产能、进出口数据按周或月度更新，行业研报文档则按季度或项目节点发布。数据文档包含结构化表格与非结构化研报两类，结构化字段涵盖玻璃品类（浮法、光伏、钢化等）、规格（厚度、透光率）、价格（元/重量箱、元/平方米）、产能（万重箱/年）等，非结构化文档多为行业趋势分析与政策解读内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
玻璃投研数据的多更新频率、多结构化字段及细分品类差异，对模型接入与配置提出明确约束。不同数据的更新节奏差异要求配置增量同步规则，区分日更的现货价格与月更的产能数据，避免重复同步或同步滞后。结构化字段存在明确单位与细分品类标签，需配置统一的字段映射规则，防止单位混淆或跨品类数据误召回。非结构化研报文档篇幅较长，需调整分段与上下文长度配置，确保模型能完整解析文档内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 玻璃行业研报PDF多为10至50页，包含多组结构化表格，解析耗时较长 |
| `maxContext` | `8000–16000 字符` | 玻璃投研文档包含多字段对比表格与长段落分析，需足够上下文支撑模型理解 |
| `RECALL_TOP_N` | `前 8–12 条` | 玻璃细分品类较多，需召回足够覆盖不同品类的相关数据，避免遗漏关键信息 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 结构化字段匹配精度要求较高，该阈值可过滤非玻璃品类的无关检索结果 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 行业研报合集体积较大，该配置可支持完整的批量文档上传 |
| `MCP_TOOL_TIMEOUT` | `300 秒` | AntV图表生成需处理多组玻璃价格数据，耗时较通用插件更长 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用MCP插件返回AntV Chart代码块但未渲染图表，原因：未启用`MCP_CHART_RENDER`配置项，或模型提示词未包含渲染图表的明确指令。
- 现象：检索时抛出`Cannot read properties of null (reading 'q')`错误，原因：未正确配置玻璃数据的字段映射，将`weight_box_price`字段误绑定为空的检索参数。
- 现象：接入deepseek code模型后无法生成结构化的玻璃产能表格，原因：未开启`CODE_EXECUTION_PERMISSION`配置，或模型上下文未包含玻璃数据的字段说明。

## 怎么确认配好了
- 上传一份包含玻璃现货价格的PDF文档，查看解析后的结构化字段是否包含`price`、`specification`、`region`且单位匹配预期。
- 发起包含“2024年各区域浮法玻璃出厂价”的查询，核对召回结果中玻璃相关文档的占比是否符合检索需求。
- 调用AntV Chart MCP插件，传入模拟的月度玻璃价格数据，确认界面渲染出对应折线或柱状图表。
- 配置deepseek code模型并发起生成“2024年光伏玻璃产能清单”的请求，确认返回结果包含可执行的代码块与正确的字段映射。
