# 电子元件投研知识库建设的数据库与运维

## 这个品类的数据长什么样
电子元件投研数据主要来源于上游厂商官方规格书、行业协会器件数据库、供应链报价平台及终端应用适配报告。数据更新节奏随器件生命周期变化，新器件发布时批量更新，量产周期内按月更新核心参数，退市器件标注归档。单条数据文档包含器件型号、封装类型、电气参数（如额定电压、工作电流）、机械参数（如引脚间距、外形尺寸）、合规认证信息及替代型号列表。字段包含明确单位，例如电阻值单位为Ω、电容值单位为μF、工作温度范围单位为℃，部分参数支持多单位兼容格式。

## 这些特征在「数据库与运维」这一环带来什么约束
多源分散的数据源要求配置多渠道同步任务，需针对不同数据源的更新频率设置差异化调度规则。多字段带特定单位的特性，要求数据库建立字段校验规则，避免单位不统一导致的检索偏差。替代型号的关联关系需建立跨表索引，提升关联查询效率。大体积的规格书文档要求配置足够的解析超时与存储上限，防止解析中断或存储溢出。退市器件的归档需求，要求配置数据生命周期管理流程，避免无效数据占用存储资源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 电子元件规格书通常包含多页参数表格，完整解析需较长时长，300秒可覆盖多数场景 |
| `RECALL_TOP_K` | `10–15 条` | 电子元件参数字段数量较多，需召回足够条目覆盖完整检索需求，避免关键参数遗漏 |
| `DB_INDEX_FIELDS` | `["器件型号", "封装类型", "工作温度范围"]` | 投研场景下用户常按型号、封装、温度范围检索，建立索引可显著提升查询速度 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 部分厂商发布的完整器件手册PDF体积较大，需支持大文件上传以覆盖全量文档 |
| `DATA_SYNC_INTERVAL` | `86400 秒` | 电子元件量产周期内参数更新频率以月为单位，每日同步可保证数据时效性 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 电子元件参数描述精准度要求高，需过滤低匹配度的冗余检索结果 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：从v4.9.13升级到v4.10.1后，知识库内容未同步显示。原因：未执行对应版本的数据库迁移脚本，导致新版本与旧版本的知识库元数据结构不兼容。
- 现象：新建「问题分类」节点时，使用初始化AI模型触发运行或保存发布报错，切换AI模型后恢复正常。原因：初始化AI模型的向量维度与电子元件知识库的向量存储维度不匹配，导致索引写入失败。
- 现象：数据库查询返回的部分参数字段为空。原因：未对导入的电子元件文档做单位校验，解析过程中无法识别非标准单位格式，导致字段存储为空。

## 怎么确认配好了
- 执行增量数据同步任务，核对同步前后的器件条目数量，确认同步逻辑正常生效。
- 上传一份典型的电子元件规格书，检查解析后的字段是否完整且单位匹配，确认解析配置生效。
- 模拟多用户并发检索场景，观察数据库查询延迟，确认索引配置与并发参数适配。
- 查看数据库运行日志，确认无单位校验失败或字段解析报错，确认数据校验规则正常运行。
