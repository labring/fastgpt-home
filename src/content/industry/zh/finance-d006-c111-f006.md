# 畜禽养殖投研知识库建设的对话日志与审计

## 这个品类的数据长什么样
畜禽养殖投研数据主要来源于行业协会公开监测数据、定点养殖场报送的经营数据、饲料原料交易市场的实时报价。数据更新节奏分多维度：饲料原料价格为日更，存栏、出栏量统计为周更，月度行业分析报告为月更。文档分为结构化数据表与非结构化分析报告两类，结构化数据表包含品类名称、统计周期、存栏量（单位：头/羽）、出栏量、饲料成本（单位：元/吨）、市场均价（单位：元/公斤）等字段，非结构化报告则包含疫病防控分析、行业趋势预判等内容。

## 这些特征在「对话日志与审计」这一环带来什么约束
畜禽养殖数据的多更新频率、多结构类型与字段单位差异，对对话日志与审计提出了明确约束。首先，不同周期的更新数据需通过日志绑定对应版本，避免审计时引用过期行情；其次，结构化数据占比高，日志需精准记录用户查询的具体字段关键词，方便回溯数据调用逻辑；再次，不同文档的单位存在差异（如存栏用头/羽、均价用元/公斤），日志需留存调用文档的单位字段，消除审计时的数值歧义；最后，投研对话常涉及跨品类、跨周期对比，日志需完整记录上下文关联的文档ID，确保审计链路可追溯。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `log_retention_days` | `180 天` | 投研审计需留存至少半年的对话与数据调用记录，符合行业合规要求 |
| `audit_log_include_context` | 开启 | 需完整记录用户提问的上下文内容，支撑指代消除与链路回溯 |
| `document_version_tracking` | 强制开启 | 畜禽养殖数据更新频率高，需绑定调用文档的具体版本，避免引用过期数据 |
| `query_field_extract` | 启用结构化字段提取 | 需记录用户查询的具体数据字段（如“白羽鸡存栏量”），方便审计溯源 |
| `error_log_threshold` | `500 毫秒` | 养殖行情数据时效性强，超时请求需纳入审计范围，确保异常调用可被追溯 |
| `api_request_log_sampling` | `100%` | 投研场景需全量留存日志，避免遗漏关键数据调用链路 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传畜禽养殖行情图片文档后，日志显示上传成功且返回`200 OK`状态码，但知识库节点无法调用该图片，界面按钮置灰。原因：未开启`image_parse_enable`配置，导致图片无法被解析为可检索内容，日志未记录解析失败的`500 Internal Server Error`。
- 现象：审计日志中仅展示用户提问与回答内容，未关联对应的养殖数据文档ID与版本号。原因：未开启`document_version_tracking`配置，导致日志未绑定调用的具体文档版本，无法溯源数据引用的准确性。
- 现象：调用知识库API时，历史对话中的指代性提问（如“对比上月的生猪价格”）无法被正确解析，日志中未记录上下文关联的字段关键词。原因：未启用`query_field_extract`配置，导致日志未提取用户提问中的结构化字段，无法回溯上下文优化逻辑。

## 怎么确认配好了
- 登录FastGPT后台的日志管理模块，随机选取一条畜禽养殖投研对话日志，核对是否包含关联的文档ID、版本号与查询字段关键词。
- 上传一份结构化的畜禽养殖行情数据表文档，查看系统日志是否同时记录上传成功、解析完成与版本生成的完整链路。
- 发起一次包含指代性提问的对话，核对日志是否记录了上下文关联的字段与历史对话标识。
- 查看日志保留策略配置页面，确认日志留存时长符合投研审计的合规要求，且全量日志采集开关已启用。
