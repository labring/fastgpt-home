# 畜禽养殖投研知识库建设的模型接入与配置

## 这个品类的数据长什么样
畜禽养殖相关数据的来源覆盖行业监测机构、饲料供应商、畜牧主管部门与公开技术文档。数据更新节奏覆盖日度、周度、月度多个层级，不同类型数据的更新频率差异明显。文档形态包含结构化的字段表格、半结构化的行业分析片段，以及非结构化的技术说明文本。字段包含能繁母猪存栏量、饲料单耗、出栏周期等专用内容，单位多为头、千克、天。

## 这些特征在「模型接入与配置」这一环带来什么约束
畜禽养殖数据的多层级更新节奏，要求模型接入环节配置可自定义的召回时间窗口，适配日度监测数据的实时调用与月度报告的批量检索。结构化字段占比高的文档形态，需要开启对应的数据结构化解析开关，避免非结构化文本的无效召回。多维度的专用字段，要求配置实体抽取的字段白名单，防止无关字段干扰模型输出。大容量的月度行业台账文档，会拉长解析与加载时长，需要调整对应超时与上传上限参数。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 畜禽养殖月度台账文档通常容量较大，解析耗时较长，默认超时无法完成完整解析 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 单份月度全行业监测台账可能超过常规上限，需适配大容量文档上传 |
| `maxContext` | `8000–12000 字符` | 畜禽养殖研报与技术文档通常篇幅较长，需适配长文本的上下文处理 |
| `召回条数` | `前 8–12 条` | 畜禽养殖数据维度多，适量召回可覆盖存栏、饲料、疫病等多类信息 |
| `相似度阈值` | `0.75–0.85` | 结构化字段的匹配精度较高，可适当提高阈值过滤低相关的非结构化片段 |
| `ENABLE_STRUCTURED_PARSE` | `开启` | 畜禽养殖数据包含大量结构化表格字段，开启后可提升字段抽取与召回的准确性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用模型返回`400 Bad Request`，提示图片格式不兼容。原因是未针对畜禽养殖场景的疫病诊断图片配置允许的格式范围，部分非标准png格式未被纳入白名单。
- 工具调用后返回空响应。原因是未配置`maxToolCall`参数的合理上限，或模型未适配多轮工具调用逻辑，无法完成养殖数据的实时检索。
- 知识库文本理解模型无法识别专用字段。原因是未开启字段抽取开关，未配置专用字段白名单，导致能繁母猪存栏量等专属内容未被正确抽取。

## 怎么确认配好了
- 上传一份畜禽养殖月度台账文档，检查解析后的结构化字段是否完整提取，验证超时与上传上限配置是否生效。
- 发起包含专用字段的检索请求，核对召回结果中是否包含匹配的养殖数据，验证召回规则与相似度阈值的配置合理性。
- 调用配置的模型完成一次工具调用测试，检查是否能正常返回响应内容，验证模型接入与工具调用的配置正确性。
- 上传一张畜禽疫病诊断图片，检查是否能正常完成解析，验证图片格式相关参数的配置是否符合要求。
