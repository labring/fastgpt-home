# 白色家电投研知识库建设的知识库检索与召回

## 这个品类的数据长什么样
白色家电投研数据主要来自厂商公开财报、行业协会能效数据库、电商平台销售榜单、线下渠道调研记录与专业研报。数据更新节奏存在差异，厂商财报按季度更新，电商销售数据每日同步，能效标识合规文档随政策调整更新。文档结构包含结构化参数表（含SKU编码、能效等级、制冷/制热功率等字段）、半结构化研报章节、非结构化用户评价文本，部分文档附带图片与表格附件。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据结构要求检索环节需区分结构化参数与非结构化文本，避免匹配逻辑混淆导致的结果偏差。不同更新频率的数据源需要适配增量更新的时间间隔，防止过时数据混入当前检索结果。字段与单位的多样性（如制冷量以瓦为单位、营收以亿元为单位）要求召回时需匹配单位信息，避免歧义性检索结果。大量细分型号的产品数据会导致基础召回结果冗余，需要通过重排与过滤优化结果相关性，提升投研判断的参考价值。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| :---- | :---- | :---- |
| `similarity_threshold` | 0.72–0.78 | 白色家电产品参数精度要求高，过低会引入无关竞品型号，过高会遗漏同品类细分产品 |
| `recall_top_k` | 前12–15条 | 单款白色家电参数文档较长，基础召回需覆盖多维度参数与研报片段 |
| `chunk_size` | 800–1200 字符 | 白色家电研报多包含长段落的市场分析，分段过长会丢失上下文关联，过短会割裂参数关联 |
| `incremental_update_interval` | 4 小时 | 电商销售数据日更、厂商财报季度更，增量更新兼顾实时性与计算成本 |
| `rerank_top_n` | 前5–8条 | 需保留核心参数与研报结论，避免过多冗余结果干扰投研判断 |
| `allowed_file_extensions` | .pdf, .xlsx, .md | 覆盖研报、结构化参数表、标注文档的常用格式 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：检索结果包含非目标集合的文档，原因：未配置集合过滤参数，未指定仅检索白色家电投研专属集合。
- 现象：上传的md文件中图片无法加载，返回结果中图片字段为空，原因：未将本地图片上传至知识库存储目录，未配置图片路径替换规则。
- 现象：检索返回结果仅为摘要片段，无法获取完整网页内容，原因：未启用网页抓取后的内容解析模块，未配置链接读取权限。

## 怎么确认配好了
- 上传1份带本地图片的md文档与1份结构化excel参数表，检查解析后文档中图片正常显示，字段完整提取。
- 发起针对特定白色家电型号的检索，核对结果仅来自预设的投研集合，无外部无关文档。
- 调整相似度阈值与召回条数，验证检索结果的相关性与数量符合预期。
- 触发增量更新任务，检查新增的电商数据或财报文档被正确索引。
