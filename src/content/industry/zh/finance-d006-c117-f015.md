# 纺织制造投研知识库建设的部署与升级

## 这个品类的数据长什么样
数据来源包括全国纺织工业联合会发布的月度运行数据、上市纺企的季度财报、大宗商品交易所的原料现货报价、工厂端的生产排程与质检文档。更新节奏为原料报价每日更新，行业月度数据滞后7天发布，财报按季度更新。文档多为表格型（产能、库存、成本明细）、长文本型（行业分析报告），部分附带生产流程图与质检照片，字段包含纱支数、克重、坯布幅宽等专业单位。

## 这些特征在「部署与升级」这一环带来什么约束
高频更新的原料报价要求部署时配置增量同步机制，避免全量扫描浪费计算资源；多类型文档（表格、长文本、图片）要求升级时兼容多模态解析模块，适配质检照片的识别需求；专业字段与单位需要提前配置自定义术语词典，避免通用解析模型出现单位识别偏差；长文本财报与行业报告要求调整上下文窗口参数，防止关键数据被截断；增量更新的频率需与各数据源的发布节奏对齐，确保投研数据的时效性与更新一致性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 适配纺织制造领域大型财报、行业报告的文件体积需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 满足长文本财报、带多幅图表的行业报告的解析耗时要求 |
| `enable_multi_modal_parse` | 开启 | 适配包含生产流程图、质检照片的纺织工单文档解析 |
| `custom_terminology_dict` | 上传纺织行业专业术语表 | 避免通用解析模型对纱支、克重等专业单位的识别错误 |
| `incremental_sync_interval` | `86400 秒` | 匹配原料报价每日更新的数据源节奏，兼顾资源占用 |
| `max_context_length` | `12000 字符` | 适配长文本行业分析报告、季度财报的内容长度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：本地部署后创建通用知识库时，图片理解模型选项为空。原因：未在部署配置中启用多模态解析模块，或未加载对应模型依赖包。
- 现象：本地部署MCP Server后，调用时返回`500 Internal Server Error`，日志显示无法连接到代理端点。原因：`mcpserverproxyendpoint`配置项填写错误，未指定正确的本地端口或未开启代理服务。
- 现象：解析大型纺织季度财报时出现`408 Request Timeout`错误。原因：`PARSE_FILE_TIMEOUT_SECONDS`配置值设置过小，未适配长文档的解析耗时。

## 怎么确认配好了
- 上传单份体积符合行业文档规模的纺织行业报告，检查上传与解析流程是否正常完成，确认`UPLOAD_FILE_MAX_SIZE`配置符合实际需求。
- 上传包含质检照片的纺织工单文档，检查是否成功提取图片中的文字与标注，确认多模态解析模块已正常启用。
- 配置增量同步任务后，查看同步日志，确认同步频率与数据源发布节奏对齐，确认`incremental_sync_interval`配置合理。
- 填写本地MCP Server的监听端口至`mcpserverproxyendpoint`，发起测试调用，确认连接状态正常。
