# 航天装备投研知识库建设的引用来源与溯源

## 这个品类的数据长什么样
航天装备投研的数据主要来自国防军工行业公开报告、航天院所发布的公开论文、型号研制阶段的官方公开文档、航天发射任务的实时公开数据、行业标准规范文件。数据更新节奏随型号研制节点、年度行业白皮书发布不定期调整，无固定周期。文档结构多为多章节形式，包含技术参数、研制进度、试验数据、成本构成等模块，字段多带有专用单位，如推力单位千牛、发射窗口单位UTC时间、研制周期单位月等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
航天装备投研数据的特征对溯源环节带来多重约束。首先，文档结构复杂且段落较长，需精准定位引用的具体章节与段落，避免因拆分不当破坏技术参数的上下文关联。其次，字段带有专用单位，溯源时需完整保留单位信息，否则会导致投研结论出现偏差。再次，数据更新无固定周期，需支持增量更新触发逻辑，避免引用过时的型号研制数据。最后，数据来源多为官方公开文档，需明确标注原始文档的名称与章节，满足军工行业投研的合规性要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `api_reference_file_return` | `enabled` | 支持通过API接口返回引用文档的文件名，满足投研人员快速溯源原始文档的需求 |
| `max_reference_count` | `3–5 条` | 航天装备投研文档数据量大，过多引用会干扰决策逻辑，过少则无法提供足够的技术支撑，按实测标定合理区间 |
| `reference_unit_keep` | `enabled` | 航天装备参数带有专用单位，保留单位可确保溯源信息的准确性，避免参数含义被曲解 |
| `parse_segment_length` | `800–1200 字符` | 适配航天装备技术文档的段落长度，避免拆分破坏参数与上下文的关联 |
| `reference_quote_type_check` | `enabled` | 校验变量引用的格式，避免出现`quote type error`报错，匹配投研场景的变量调用需求 |
| `show_reference_source` | `disabled`（按需调整） | 可根据投研报告的展示需求，控制是否展示引用来源，满足不同场景的输出要求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：通过API调用返回的结果中未包含引用的文件名。原因：未开启`api_reference_file_return`配置项，默认关闭该返回字段。
- 现象：变量引用下拉菜单仅显示单个选项，无法选择多个变量。原因：未开启多变量引用的全局配置，默认限制单变量引用。
- 现象：知识库变量引用时返回`quote type error`报错。原因：变量引用格式不符合要求，未使用正确的包裹标识或指定的字段名错误。

## 怎么确认配好了
- 调用对应API接口，检查返回结果中是否包含文件名字段，验证`api_reference_file_return`配置是否生效。
- 尝试在知识库编辑界面选择多个文档变量，检查下拉菜单是否支持多选，验证多变量引用配置是否开启。
- 输入不符合格式的变量引用，检查是否返回`quote type error`报错，验证格式校验配置是否生效。
- 生成投研回答后，检查是否可以隐藏引用来源展示，验证`show_reference_source`配置是否正确。
