# 航天装备投研知识库建设的部署与升级

## 这个品类的数据长什么样
航天装备投研数据主要来自军工集团公开披露的型号立项公告、试验验证报告、行业标准规范、第三方军工咨询机构的公开研报，以及航天发射任务的公开观测记录。更新节奏随型号节点波动，核心型号立项、发射任务节点会触发突发更新，常规研报按季度更新，行业标准文档更新周期较长。文档多为长文本，包含推力、轨道高度、发射窗口等技术参数字段，单位涉及千牛、千米、秒，部分文档包含表格化的载荷配置清单。

## 这些特征在「部署与升级」这一环带来什么约束
航天装备投研数据的长文本、高突发更新频率、特定技术字段单位等特征，对部署与升级环节带来多重约束。长文本文档会拉长解析耗时，需要适配更长的解析超时设置；突发更新要求部署支持增量同步与版本回溯，避免全量重建导致的服务中断；特定技术字段的单位规则，要求知识库解析环节保留字段与单位的绑定关系，不可随意拆分；频繁的版本迭代需求，要求升级流程兼容历史版本的配置迁移，避免版本差异引发解析异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 航天装备投研文档多为长文本，常规解析耗时高于通用场景，600秒可覆盖多数大型试验报告的解析需求 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 航天装备的试验报告、遥感数据集文件体积较大，2000 MB可满足多数单文件上传要求 |
| `CHUNK_MAX_SIZE` | `1500 字符` | 航天装备技术文档包含大量参数表格与长句，1500字符分段可保留参数与上下文的关联完整性 |
| `RECALL_TOP_N` | `前 8 条` | 航天装备投研数据的专业术语密度高，召回8条可覆盖核心技术参数的关联信息 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 平衡召回的精准度与覆盖度，适配专业领域的弱匹配检索需求 |
| `ENABLE_INCREMENTAL_SYNC` | `开启` | 适配航天装备投研数据的突发更新需求，减少全量同步带来的服务压力 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为升级至4.9.10版本后，全局变量配置面板仅显示两个可选值。原因是该版本对全局变量的校验规则进行了调整，仅保留系统内置的基础变量类型，未兼容自定义全局变量的旧版配置格式。
- 现象为跨版本从4.8.10升级至4.9.10-fix2后，部分知识库的技术参数字段出现丢失。原因是不同版本的文档解析器对技术字段的绑定规则存在差异，未执行版本兼容迁移。
- 现象为上传单个体积较大的航天装备试验报告时触发超时报错，日志显示`PARSE_FILE_TIMEOUT`。原因是未调整解析超时配置项，默认值无法覆盖长文本文档的解析耗时。

## 怎么确认配好了
- 上传一份航天装备领域的长文本试验报告，核对解析后的分段长度与配置项取值是否匹配。
- 触发一次增量同步任务，核对系统是否仅同步更新后的文档，未重复处理已解析的历史文件。
- 查看全局变量配置面板，确认自定义变量的展示数量与预期配置一致。
- 上传单个体积符合业务需求的文件，确认上传流程未触发异常报错。
