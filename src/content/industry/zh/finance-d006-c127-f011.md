# 航空装备投研知识库建设的文档解析与分块

## 这个品类的数据长什么样
航空装备投研数据主要来自军工主机厂公开年报、航空发动机研发机构的试验报告、行业协会发布的装备发展白皮书、空域管制与适航认证的公开公告。更新节奏覆盖年度、季度及不定期试飞、认证节点。文档包含标准化技术参数表（含推力、航程、翼展等字段，单位为千牛、千米、米）、系统架构说明文档、分章节的试验验证报告，部分文档附带工程图纸的文字说明。

## 这些特征在「文档解析与分块」这一环带来什么约束
航空装备投研数据的结构化参数多、单位体系特殊，要求解析时精准匹配字段与对应单位，避免参数与单位分离。不定期更新的试飞公告结构不固定，需适配非标准化文档的解析逻辑。长章节的试验报告包含连续的技术推导内容，分块时需保留章节级上下文，避免割裂技术逻辑。附带工程图纸的文字说明与图纸绑定紧密，需避免拆分说明文本与对应图纸的关联信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300–600 秒` | 航空装备文档常包含长章节试验报告，解析耗时高于通用文档，需预留足够处理时间 |
| `分段长度` | `800–1200 字符` | 航空装备技术参数与上下文关联紧密，过长分块会引入无关内容，过短则丢失参数关联逻辑 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 部分航空装备的整机试验报告、图纸合集文件体积较大，需放宽上传上限 |
| `分段重叠率` | `15–20%` | 航空装备技术推导内容连贯性强，重叠分块可保留推导过程的上下文关联 |
| `ENABLE_STRUCTURED_PARSE` | `开启` | 航空装备文档包含标准化技术参数表，开启结构化解析可精准提取字段与对应单位 |
| `PARSE_EXCEL_CONTENT_MODE` | `保留原始格式` | 航空装备Excel文档包含标准化参数表格，保留原始格式可避免参数与单位分离 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 启用PDF解析功能后，服务器内存占用飙升，出现服务卡顿。原因：未限制单文件解析的并发数，且未调整`UPLOAD_FILE_MAX_SIZE`参数，导致大体积航空装备文档占用过多内存资源。
- 上传Excel格式的航空装备参数表后，向量化索引中出现字段与单位分离的情况。原因：未开启结构化Excel解析配置，导致解析时未识别表格结构，拆分参数与单位文本。
- 解析长章节的试飞报告时，日志返回`504 Gateway Timeout`错误，解析任务失败。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时长不足以处理长文档的解析流程。

## 怎么确认配好了
- 上传单份符合配置上限的航空装备文档，查看解析任务的运行日志，确认解析时长未超出预设的超时参数。
- 导出知识库的分块数据，核对技术参数表的字段与对应单位是否绑定完整，确认结构化解析配置已生效。
- 调用知识库分块查询接口，输入航空装备的典型技术关键词，确认返回的分块包含关联的上下文推导内容。
- 上传Excel格式的参数文档，查看分块内容是否保留了原始表格的结构与单位信息，确认Excel解析配置已生效。
