# 调味品投研知识库建设的引用来源与溯源

## 这个品类的数据长什么样
数据源涵盖中国调味品协会公开的行业监测文档、上市调味品企业的定期披露文件、线上线下零售渠道的销售台账、大宗粮油原料的现货交易报价。更新节奏分为日度（原料报价）、周度（零售销售数据）、月度（行业整体运行数据）、季度/年度（企业财报与深度研报）。文档结构包含结构化的CSV销售台账、PDF格式的行业分析报告、Excel格式的企业营收明细、纯文本格式的原料报价单。字段与单位包含产品名称、月度出货量、单位售价、原料成本，其中出货量单位为吨，售价单位为元/千克，成本单位为元/吨。

## 这些特征在「引用来源与溯源」这一环带来什么约束
多数据源的更新节奏差异，要求引用溯源系统需精准标记每条引用内容的采集时间与更新周期，避免将周度零售销售数据用于月度投研结论的支撑。结构化与非结构化文档混合的文档结构，要求溯源需同时支持结构化CSV表格的单元格级定位、PDF研报的页码+段落定位，覆盖不同格式的引用来源。不同数据源的字段命名差异，例如部分零售台账使用“出货量”而行业报告使用“销量”，要求溯源需配置统一的字段映射规则，避免投研分析出现字段混淆。原料报价的日度更新特性，要求溯源需关联具体的交易日期与报价来源，确保引用内容的时效性匹配投研分析的时间窗口。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `recall_top_k` | `前8–12条` | 调味品投研数据覆盖零售、财报、原料等多维度，需召回足够候选来源覆盖核心信息，避免冗余干扰 |
| `similarity_threshold` | `0.75–0.85` | 调味品行业存在通用术语与字段表述差异，该阈值可过滤无关数据同时保留同品类跨渠道信息 |
| `source_citation_enable` | `开启` | 投研分析需明确标注数据来源以符合行业信息规范，同时便于回溯验证逻辑 |
| `parse_table_cell_citation` | `开启` | 调味品数据多以结构化表格呈现，开启单元格级溯源可精准定位引用的具体数据行与字段 |
| `citation_newline_render` | `自动转换为换行` | 解决原始\n无法正确渲染的问题，确保表格与多行列项的溯源内容展示清晰 |
| `max_citation_tokens` | `1200–1500 字符` | 单条调味品结构化数据的完整信息长度多在1000字符以内，该区间可完整保留溯源所需内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：在投研回复的引用模块中，表格内的换行标记\n被直接展示为文本，未实现正常换行效果。原因：未配置`citation_newline_render`为自动转换模式，导致系统保留原始文本中的换行符标记，未将其渲染为页面换行。
- 现象：引用溯源显示的字段名称与投研分析中使用的名称不匹配，例如将台账中的“出货量”标注为“销量”。原因：未配置统一的字段映射规则，溯源系统直接使用原始数据源的字段命名，未完成行业术语的对齐。
- 现象：召回的引用来源数量超出预期，导致回复冗余且溯源信息混乱。原因：`recall_top_k`设置值过高，未根据调味品数据的维度密度调整召回条数，引入了大量非核心的边缘数据。

## 怎么确认配好了
- 上传一份调味品零售台账CSV文件，发起包含“该产品月度出货量”的查询，检查引用模块是否展示具体的单元格位置与来源文件名。
- 输入包含换行标记的测试文本，查看回复的引用模块是否将\n转换为正常换行效果。
- 调整召回条数参数后，发起多维度投研查询，核对召回的来源数量与分析需求匹配。
- 查看投研回复的引用区域，确认所有来源均标注了采集时间与完整的来源信息。
