# 铁矿石投研知识库建设的多轮对话与提示词

## 这个品类的数据长什么样
铁矿石投研相关数据主要来源于大连商品交易所公开行情、国内主要港口装卸台账、钢铁产业链上下游企业公开报价、行业研究机构定期调研报告。数据更新节奏区分类型：现货成交价与港口库存数据每日更新，期货行情实时同步，行业调研报告按周或月度发布。文档多为结构化表格搭配分析段落，包含区域分类、品类等级、交易价格、库存规模、到港周期等字段，单位涵盖元/吨、万吨、自然日等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
铁矿石数据的多源多时效特征，要求多轮对话中需明确区分数据类型的召回范围，避免跨类别返回错误信息。结构化文档占比高的特点，要求提示词需引导模型优先提取表格中的精准字段，不应依赖非结构化文本的模糊分析。多字段分类的属性，要求多轮对话中需逐步引导用户明确区域、品类等级等限定条件，缩小召回范围。实时更新的行情数据，要求配置中需关联最新的数据集同步任务，避免返回过期内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `召回条数` | `前8-12条` | 铁矿石数据字段多且分类细，过多召回会超出上下文窗口，过少会遗漏关键区域或等级的有效数据 |
| `相似度阈值` | `0.75-0.85` | 铁矿石数据的精准度要求高，阈值过低会召回无关品类数据，过高会遗漏同品类不同区域的有效内容 |
| `maxContext` | `8000-12000 字符` | 单篇铁矿石分析报告长度较长，多轮对话需保留多轮交互的上下文信息，避免关键内容被截断 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 结构化表格类的铁矿石文档解析需较长处理时间，避免大体积文档解析失败 |
| `prompt_template` | `优先提取表格中的精准字段，若用户未指定区域或等级，需主动询问补充` | 适配铁矿石数据的多字段分类属性，明确限定条件才能精准召回目标内容 |
| `重排返回条数` | `前4-6条` | 多轮对话中需优先展示最相关的结构化数据，避免信息过载影响交互体验 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 对话中返回`404 status code (no body)`。原因是未正确配置知识库的API调用权限，或关联的数据集未完成同步上传。
- 无法通过提示词指定特定数据集进行搜索。原因是未在提示词模板中明确绑定对应数据集的唯一标识，或未开启多数据集召回的配置开关。
- 对话开场白未显示预设的多个引导问题。原因是未在`prompt_template`中配置开场白的预设问题逻辑，或未开启对话开场白的展示开关。

## 怎么确认配好了
- 发起单轮精准提问，验证是否能召回对应区域、等级的铁矿石数据，若召回范围不符，调整对应配置项的取值。
- 发起多轮交互，验证模型是否会主动询问未明确的限定参数，若未主动询问，调整`prompt_template`的引导逻辑。
- 上传单篇大体积的铁矿石结构化文档，验证是否会触发解析超时报错，若触发，调整`PARSE_FILE_TIMEOUT_SECONDS`的取值。
- 调用对话接口，验证返回结果是否包含引用来源字段，若未包含，开启知识库的来源展示配置项。
