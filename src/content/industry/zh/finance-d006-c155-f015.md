# 饲料投研知识库建设的部署与升级

## 这个品类的数据长什么样
饲料行业投研数据主要来自全国饲料工业协会公开监测数据、养殖终端的每日投料记录、原料供应商的现货报价单、农业农村部发布的饲料添加剂标准。数据更新节奏分为多个层级：原料现货价格每日更新，行业供需分析报告每周发布，合规性标准每季度修订。文档结构包含两类：一类是结构化表格，如原料营养成分表，包含粗蛋白、粗纤维、钙、有效磷等字段，单位为百分比、毫克每千克；另一类是非结构化文档，包括行业研报、政策文件扫描件、养殖端反馈日志。

## 这些特征在「部署与升级」这一环带来什么约束
结构化数据多且包含专业字段与单位，要求部署阶段的文档解析模块支持多字段抽取与单位统一校验，避免出现数据错位或单位混乱。高频更新的原料价格数据，要求升级阶段配置增量同步机制，减少全量重跑带来的资源消耗。非结构化的长文本研报与扫描件，需要调整解析模块的超时与分段参数，避免解析中断。此外，饲料数据涉及养殖端的生产信息，部署与升级时需同步配置敏感数据加密规则，符合行业合规要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | 2000 MB | 饲料行业研报、原料检测报告单份体积偏大，需放宽单文件上传上限 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 900 秒 | 长文本研报、OCR扫描件解析耗时较长，延长超时时间避免解析中断 |
| `maxContext` | 1500–2000 字符 | 饲料数据包含多维度营养参数，需扩大上下文窗口以完整关联字段信息 |
| `召回条数` | 前 8 条 | 饲料投研需覆盖原料、养殖、政策多维度数据，增加召回条数确保信息全面 |
| `相似度阈值` | 按实测标定 | 饲料行业术语专业性强，需结合业务场景调整阈值，避免遗漏相关细分品类数据 |
| `INCREMENTAL_SYNC_INTERVAL` | 每日 2 次 | 原料价格每日更新，配置增量同步频率匹配数据源更新节奏 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：私有部署启动后弹出配置错误提示，日志中出现“配置文件格式非法”字段。原因：未针对饲料行业多结构化字段的解析需求，修改配置文件中的解析规则模板，导致启动校验不通过。
- 现象：离线部署环境中导入批量饲料研报时，系统返回“文档总量超限”报错。原因：未调整`UPLOAD_FILE_MAX_SIZE`与全局文档存储配额，未适配饲料行业文档体积偏大的特征。
- 现象：工作流调用AI对话组件处理饲料营养配比计算时，触发未捕获的异常报错。原因：未设置足够大的`maxContext`参数，导致多字段关联的上下文信息溢出，触发系统异常。

## 怎么确认配好了
- 上传一份标准饲料原料检测报告，检查解析结果是否完整提取预设字段，核对字段单位是否统一。
- 触发一次增量同步任务，检查系统是否仅更新当日新增的数据源内容，未重复处理历史文档。
- 调用工作流中的AI对话组件，输入饲料配方相关查询，检查返回结果是否包含多维度关联数据，未出现上下文溢出提示。
- 查看系统监控面板，确认文件解析任务的运行时长未超过预设的超时阈值。
