# 黑色家电投研知识库建设的知识库检索与召回

## 这个品类的数据长什么样
黑色家电投研数据主要来源于行业协会季度报告、品牌官方技术参数文档、电商平台销量与评价数据、第三方检测机构评测报告及供应链原材料报价文档。数据更新节奏随场景变化：行业报告按季度更新，品牌新品参数随发布周期更新，电商与供应链数据为实时同步。文档结构包含结构化参数表、非结构化评测内容、新品发布会纪要等，字段包含能效等级、面板尺寸、额定功率、上市时间、供应链成本等，对应单位为英寸、瓦、元等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
结构化参数占比高要求检索需同时支持精准匹配与语义检索，避免不同型号参数混淆。多源异构文档格式要求解析插件覆盖全格式，否则会出现部分内容无法索引。实时更新的供应链与电商数据要求检索链路支持增量同步，否则会出现数据滞后。长文档占比高要求分段策略兼顾语义完整性，过短的分段会割裂参数关联，过长的分段会降低检索精度。多字段要求需明确指定检索字段范围，避免无关品类数据被召回。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `分段长度` | `800–1200 字符` | 黑色家电评测文档多为连贯长段落，该区间可兼顾语义完整性与检索精度 |
| `召回条数` | `前10–15条` | 投研需覆盖参数、评测、供应链多维度数据，过多会导致结果冗余，过少覆盖不足 |
| `相似度阈值` | `0.72–0.80` | 结构化参数匹配需较高精度，避免其他家电品类的无关数据混入 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 部分品牌的技术手册PDF页数较多，解析耗时较长 |
| `maxContext` | `4000–6000 字符` | 投研需整合多段参数与评测内容，确保上下文连贯 |
| `重排返回条数` | `前5–8条` | 投研报告需要核心精准内容，避免次要信息干扰决策 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为上传的多级目录文档仅根目录内容可被检索，子目录文件未出现在索引列表中。原因是未开启`RECURSIVE_PARSE_SUBDIRS`配置项，默认仅解析根目录下的文件。
- 现象为上传的.doc文档与带文字的测试图片无法返回检索结果。原因是未启用对应格式的解析插件，或图片未生成OCR文本内容。
- 现象为系统启动时抛出`invalid configuration parameter name "hnsw.iterative_scan"`报错。原因是该参数仅在特定向量库版本中支持，当前部署的向量库版本不兼容。

## 怎么确认配好了
- 上传包含多级子目录的测试文档包，核对索引管理界面是否包含所有子目录下的文件。
- 上传.doc格式的技术参数文档与带标注文字的家电测试图片，执行关键词检索后确认返回对应内容。
- 查看系统启动日志，确认未出现未知配置参数的报错信息。
- 通过指定知识库名称的检索接口，确认仅目标知识库的文档内容被返回。
