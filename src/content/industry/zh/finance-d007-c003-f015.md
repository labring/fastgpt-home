# 专业连锁收益率的部署与升级

## 这个品类的数据长什么样
专业连锁的收益率与行情数据主要来源于门店POS收银系统、供应链进销存系统，以及区域零售行业协会的公开行情数据。数据更新以日频为主，每日凌晨完成前一自然日的全量门店营收与收益率核算，部分实时同步的门店营收数据延迟不超过2小时。文档按门店分组整理，包含单门店日营收明细、单店收益率核算表、区域零售行情汇总表三类结构。字段包含门店唯一标识、营收总额、商品品类营收占比、收益率核算参数、区域平均收益率、数据更新时间，单位为元、百分点、消费人次。

## 这些特征在「部署与升级」这一环带来什么约束
多门店的多数据源接入需求，要求部署环节支持批量数据源配置与自定义字段映射，适配不同连锁品牌的字段差异。日报数据的单文件体量较大，且需在固定时段批量导入，因此需要调整文件上传与解析的超时、容量配置。外部行情数据源的接入需要配置安全白名单，防止未授权访问。升级环节中，随着门店数量增长，数据库检索的性能要求提升，需确保全文索引等优化配置随版本升级同步生效，避免出现检索报错。同时，不同连锁品牌的自定义字段规则存在差异，升级解析模块时需兼容旧版字段映射逻辑，防止数据解析中断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `1000–2000 MB` | 专业连锁的日报数据单文件通常包含数十个门店的明细，单文件大小多在500MB以上，预留足够空间避免上传失败 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600–900 秒` | 批量门店数据的解析流程涉及多字段核算与格式转换，需要较长的超时时间防止任务中断 |
| `TEXT_INDEX_CONFIG` | 开启门店ID、更新时间戳字段的全文索引 | 收益率播报需要快速检索特定门店的历史数据，全文索引可显著提升检索效率 |
| `MAX_CONTEXT` | `8000–12000 字符` | 日报数据包含多门店的明细内容，需要足够的上下文长度来整合完整的播报信息 |
| `RECALL_TOP_K` | `前10–15条` | 专业连锁的收益率播报需要覆盖核心门店与区域行情数据，过多召回会导致内容冗余 |
| `API_WHITELIST` | 添加云服务器公网IP、区域行业协会API的出口IP | 安全接入外部行情数据源，防止未授权的访问请求被拦截 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：升级至4.8.20版本后，知识库检索时报错`text index required for $text query`。原因：该版本默认关闭了MongoDB的全文索引自动创建，专业连锁的多门店数据检索依赖该索引，未手动配置导致检索失败。
- 现象：部署在阿里云ECS上的实例，连接阿里云RDS数据库时出现连接超时。原因：未将ECS的公网IP或专有网络IP添加至RDS的白名单，数据库拒绝未授权的接入请求。
- 现象：部署完成后，调用收益率播报功能时返回的内容仅包含本地门店的基础数据，无预期的区域行情信息。原因：未配置外部行业行情数据源的API密钥与白名单，导致无法拉取外部行情数据。

## 怎么确认配好了
- 上传一份模拟的专业连锁日报数据，检查解析任务的状态是否显示成功，解析后的字段是否与预设的门店、营收、收益率字段一致。
- 执行一次知识库检索，输入特定门店ID，检查是否能正常返回该门店的历史数据，无索引相关报错。
- 调用API接入外部行情数据源，检查返回的响应状态码是否为200，且包含区域收益率相关字段。
- 查看系统的资源监控面板，确认数据库连接数、文件解析线程数处于稳定区间，无异常报错日志。
