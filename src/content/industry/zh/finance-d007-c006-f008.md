# 中药收益率的工具调用与插件

## 这个品类的数据长什么样
用于金融场景下中药相关理财产品收益率与行情日报播报的数据，主要来自全国中药材专业市场挂牌报价、产地收购价监测平台及行业协会公开统计。数据更新节奏以每日固定时段更新为主，热门流通品种可提供日内异动推送。单条数据文档包含药材通用名、规格等级、主产地、当日批发价、终端零售价、市场流通量、数据更新日期等字段。批发价与零售价单位统一为元/千克，流通量单位为吨。

## 这些特征在「工具调用与插件」这一环带来什么约束
用于金融场景的中药收益率与行情播报工具调用，需适配中药数据的多源属性，配置多接口适配逻辑分别对接不同市场的数据源。日内异动数据的更新节奏要求插件轮询间隔匹配市场交易时段，避免生成日报时出现数据滞后。字段包含规格等级、主产地等细分维度，工具调用的入参需覆盖这些筛选条件，否则返回数据无法精准匹配金融产品对应的中药材品类。统一的元/千克单位要求插件内置单位转换逻辑，避免与其他品类的计价单位产生混淆，影响金融场景下的收益率计算。同时，多字段校验会提升参数错误触发概率，需提前配置入参合法性校验规则，保障日报数据的准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_api_timeout` | `300 秒` | 中药相关数据源接口响应通常在1-2分钟，300秒可覆盖峰值延迟场景 |
| `tool_request_retry_times` | `2-3 次` | 多源中药材数据接口可能存在临时波动，少量重试可提升调用成功率 |
| `plugin_data_filter_rule` | 按规格等级、主产地筛选 | 中药数据存在多规格、多产地差异，需精准匹配金融产品对应的中药材品类 |
| `api_key_scope` | 仅授权中药材数据接口 | 限制密钥的访问范围，降低非必要数据泄露的风险 |
| `tool_call_max_results` | `前 10 条` | 单条中药数据包含多字段信息，过多返回结果会超出大模型上下文窗口，影响日报生成效率 |
| `unit_conversion_switch` | 开启 | 统一元/千克的计价单位，避免与其他品类的计价单位产生混淆，保障收益率计算准确性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用工具时返回`400 InternalError.Algo.InvalidParameter`错误，原因：未正确传入规格等级、主产地等必填筛选参数，不符合中药材数据接口的校验规则。
- 工具调用返回的结果字段缺失或单位不一致，原因：未开启`unit_conversion_switch`配置项，未统一元/千克的计价单位。
- 大模型未触发工具调用动作，原因：未在工作流中配置工具调用的触发逻辑，或未为对应模型开启函数调用权限。

## 怎么确认配好了
- 调用测试接口，传入包含规格等级、主产地的测试参数，检查返回结果是否包含对应字段且单位统一为元/千克。
- 查看工作流日志，确认工具调用的重试次数、超时时间配置与预设值一致，无异常报错。
- 触发模拟查询，确认大模型在需要获取中药收益率数据时，会自动调用配置好的工具插件。
- 检查API密钥的权限设置，确认仅授权中药材数据相关接口，无额外访问权限。
