# 乳制品收益率的工作流编排

## 这个品类的数据长什么样
乳制品收益率相关数据主要用于金融领域的行业分析，来源包括全国乳制品工业协会的行业报送数据、线下零售终端的POS采集数据以及头部乳企的公开经营数据。数据更新节奏为每日凌晨完成前一日全量数据更新，支持按产品大类、细分SKU维度拉取。文档格式多为结构化CSV，字段包含产品大类、细分SKU编码、终端售价区间、渠道占比、当日均价，单位涵盖元/升、元/千克、元/盒（250ml标准装）等，无半结构化或非结构化的自由文本内容。

## 这些特征在「工作流编排」这一环带来什么约束
由于乳制品数据来源分散且需多源合并，工作流需配置多个HTTP请求节点分别拉取不同数据源的信息，再通过字段关联完成数据合并。数据每日仅更新一次，因此工作流的定时触发需匹配更新节奏，避免频繁拉取导致接口限流。不同包装的乳制品单位存在差异，工作流需增加统一单位的转换步骤，确保后续收益率计算的一致性。小众SKU的部分字段可能存在空值，工作流需配置空值过滤规则，避免后续计算出现异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `TRIGGER_SCHEDULE` | `0 2 * * *` | 匹配乳制品数据T+1的更新节奏，每日凌晨2点拉取可获取完整前一日数据 |
| `HTTP_REQUEST_TIMEOUT` | `300 秒` | 覆盖多源数据拉取的等待时间，避免因接口响应较慢导致的运行失败 |
| `FIELD_MAPPING_RULE` | 按产品大类+SKU编码关联合并 | 确保多源数据的唯一匹配，避免出现重复或错位的合并结果 |
| `UNIFY_UNIT_SWITCH` | 开启 | 统一不同包装乳制品的价格单位，消除单位差异对收益率计算的影响 |
| `ERROR_RETRY_TIMES` | `2 次` | 应对零售POS接口的偶发波动，降低单次请求失败导致的工作流中断概率 |
| `PARSE_CSV_HEADER` | 自动识别 | 适配乳制品数据字段的动态调整，减少配置维护的工作量 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流运行预览页面正常显示数据，但聊天页面无任何相关内容。原因：工作流的输出节点未配置为可对外共享的上下文输出模式，仅在预览时临时输出数据。
- 现象：工作流中配置form-data类型的HTTP请求，选择文件类型参数后发送请求返回400错误。原因：未指定上传文件的MIME类型，或上传的文件大小超过`UPLOAD_FILE_MAX_SIZE`的限制。
- 现象：工作流中执行乳制品数据文件对比时，提示`Load file error`。原因：上传的文件格式不符合预设的CSV格式要求，或文件编码为非UTF-8导致解析失败。

## 怎么确认配好了
- 手动触发工作流一次，查看运行日志中各HTTP请求的返回状态码是否为200，检查数据合并后的字段是否完整。
- 进入聊天页面发送对应查询指令，查看返回结果中是否包含乳制品收益率的完整字段信息。
- 等待预设的定时触发时间到达后，查看工作流的运行记录是否生成了成功的执行实例。
- 上传测试用的乳制品数据文件，验证文件解析和参数传递是否正常，确认无报错提示。
