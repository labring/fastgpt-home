# 住宅开发收益率的HTTP 接口与外部系统

## 这个品类的数据长什么样
住宅开发项目的收益率数据来源包括房企内部项目核算系统、销售管理系统、融资管理系统，以及属地住建部门的项目备案数据。更新节奏为每日更新前一个自然日的项目运营测算数据。单条数据对应单个住宅开发项目，包含项目唯一标识、项目名称、开发分期、当期运营成本总额、当期销售回款总额、当期收益率测算结果、累计收益率测算结果。成本与回款以人民币元为单位，测算结果以年化测算系数为单位，开发周期以自然月为单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多源数据对接要求同时对接多个不同鉴权方式的HTTP接口，需适配不同系统的安全规范。每日更新的节奏要求接口支持定时触发拉取，且需配置合理的超时时长避免数据拉取中断。单条数据包含多类明细字段，需配置字段过滤规则减少传输负载。住建部门备案接口存在访问频次限制，需配置请求频次控制规则避免触发限流。批量拉取需求要求接口支持按批次拉取项目数据，平衡负载与效率。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `UPSTREAM_API_AUTH_TYPE` | `oauth2_client_credentials` | 适配多数房企内部系统的鉴权标准，符合业务安全要求 |
| `HTTP_REQUEST_TIMEOUT` | `300 秒` | 住宅开发数据需归集多源运营信息，拉取耗时较长，避免中途超时中断 |
| `FIELD_FILTER_LIST` | `["项目名称", "当期收益率测算结果"]` | 过滤非核心字段，减少接口传输数据量，适配收益率播报的轻量化需求 |
| `BATCH_REQUEST_SIZE` | `10 条/次` | 平衡接口负载与数据拉取效率，适配单批次项目处理规模 |
| `RESPONSE_CONTENT_TYPE` | `application/json` | 统一接口返回格式，便于后续知识库内容拼接与解析 |
| `UPSTREAM_API_RATE_LIMIT` | `50 次/分钟` | 适配属地住建部门备案接口的频次限制，避免触发限流报错 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用`content`接口返回`415 Unsupported Media Type`错误，浏览器访问对应链接可正常下载docx文件。原因：未配置`RESPONSE_CONTENT_TYPE`适配文档格式，或未启用远程文件解析的相关配置。
- 现象：升级`4.9`版本后，调用外部接口返回`500 Internal Server Error`，提示模型连接失败。原因：未更新`UPSTREAM_MODEL_API_URL`参数适配新版本的接口地址，或鉴权密钥已过期。
- 现象：调用chat接口时，无法提取url中提供的docx文件内容。原因：未开启`PARSE_REMOTE_FILE`配置项，或未配置`ALLOWED_REMOTE_DOMAINS`包含目标文档的域名。

## 怎么确认配好了
- 执行单次接口调用测试，核对返回数据的字段是否与预设的`FIELD_FILTER_LIST`一致，格式符合业务预期。
- 查看系统运行日志，确认接口请求未触发限流，响应时长未超过配置的超时阈值。
- 触发定时拉取任务，核对拉取的项目数量与配置的`BATCH_REQUEST_SIZE`匹配。
- 传入测试docx文档链接调用解析接口，确认可正常提取文档内容。
