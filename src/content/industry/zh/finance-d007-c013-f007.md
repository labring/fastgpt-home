# 保险收益率的工作流编排

## 这个品类的数据长什么样
这个品类的数据主要来自保险公司官方运营报告、银保监会非银金融监管报送数据及公开经纪平台披露信息。更新节奏存在差异：分红险按年度披露，万能险结算信息按月更新，投连险收益信息按每个交易日更新。文档多为结构化表格形式，包含产品唯一标识、产品类型、披露周期、对应周期的收益数据项、数据发布日期等字段，单位涵盖元每份、元每万元份额等。

## 这些特征在「工作流编排」这一环带来什么约束
不同数据源的更新节奏差异，要求工作流配置多套定时触发规则，分别匹配分红险年度、万能险月度、投连险交易日的披露周期。结构化表格的固定字段格式，要求前置配置专用的表格解析节点，指定产品唯一标识、收益数据项等字段的固定映射关系。多源数据的口径差异，要求增加数据校验环节，核对产品标识的一致性，同时将不同来源的收益字段统一映射为标准命名。不同产品类型的收益清洗与计算逻辑差异，需要配置分支判断节点，按产品类型调用对应的数据处理规则。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `定时触发表达式` | 按产品类型配置对应规则：分红险`0 0 0 1 1 *`，万能险`0 0 0 1 * *`，投连险`0 0 10 * * 1-5` | 匹配各保险产品的披露更新节奏，确保数据在官方发布后及时拉取 |
| `表格解析列映射` | 指定`产品唯一标识,产品类型,披露周期,收益数据项,发布日期` | 匹配保险收益数据结构化文档的固定字段结构，避免解析错误 |
| `去重关键字段` | `产品唯一标识,发布日期` | 避免同一产品同一披露周期的重复数据录入，保证数据准确性 |
| `数据拉取超时时间` | `300 秒` | 覆盖多源拉取时的临时网络延迟，避免工作流无故中断 |
| `分支判断字段` | `产品类型` | 区分不同产品类型的清洗与计算逻辑，适配差异化的业务规则 |
| `最大重试次数` | `3 次` | 应对多源数据拉取时的临时接口波动，提升工作流稳定性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流中配置循环体处理多产品数据时，循环无法在匹配指定产品类型时自动终止，界面无报错但结果未按预期截断。原因：未正确设置`LOOP_TERMINATE_CONDITION`参数的触发条件，或未绑定对应字段的匹配规则。
- 现象：调用外部数据接口拉取保险收益数据时，接口接收的`q`参数仅包含部分查询文本，无法获取完整目标数据。原因：未配置`TOOL_CALL_PARAM_MAPPING`规则，未将完整查询文本映射到目标参数。
- 现象：工作流本地预览可正常返回结果，但发布为免登录窗口后，界面提示无权限或返回空数据。原因：未在发布配置中开放对应数据接口的访问权限，或未配置免登录窗口的上下文传递规则。

## 怎么确认配好了
- 查看定时触发日志，确认对应产品类型的工作流在预设的披露周期内自动启动。
- 上传单份保险收益结构化测试文档，运行解析节点测试，检查输出字段与配置的`表格解析列映射`规则完全匹配。
- 触发循环体处理多产品测试数据，验证在匹配预设条件时循环正常终止。
- 发布免登录测试窗口，发起测试请求，确认返回结果与本地预览阶段的输出一致。
