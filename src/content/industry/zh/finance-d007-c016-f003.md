# 光伏收益率的分享与嵌入

## 这个品类的数据长什么样
光伏收益率与行情日报的数据来源于并网光伏电站的监控终端、电网结算系统及区域气象监测平台。数据更新节奏为每日固定时段产出前一自然日的完整报表。单份日报文档包含电站唯一标识、统计日期、总发电量、自发自用电量、上网电量、上网结算电价、自发自用收益、总收益等字段。发电量字段单位为千瓦时，收益字段单位为人民币元，装机容量关联字段单位为千瓦，所有字段均为结构化数值类型，无自由文本内容。

## 这些特征在「分享与嵌入」这一环带来什么约束
光伏日报的数据多字段强关联、每日更新且部分字段涉及电站经营与电网结算细节，这些特征在分享与嵌入环节带来多重约束。首先，核心字段如结算电价与总收益存在直接计算绑定关系，拆分或单独分享单字段会破坏数据逻辑完整性。其次，每日更新的报表需确保嵌入内容为当日最新版本，若使用静态缓存，缓存时长需控制在24小时以内，避免展示过时数据。另外，部分电站的收益数据涉及内部经营敏感信息，分享与嵌入环节需配套精细的权限校验，仅允许授权主体访问对应报表。同时，单份报表包含多维度结构化字段，嵌入外部页面时需预留足够的布局空间适配字段展示。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `share_expire_time` | `86400 秒` | 匹配光伏日报每日更新的节奏，确保分享链接仅在当日有效，避免访问过时数据 |
| `iframe_allow_origin` | 指定业务域名列表 | 限制仅授权的业务页面可嵌入光伏日报内容，降低敏感经营数据泄露风险 |
| `share_require_password` | 按需开启 | 针对涉及内部结算数据的报表，通过密码校验控制访问范围，匹配光伏数据的敏感属性 |
| `cache_control_header` | `max-age=3600 秒` | 平衡数据新鲜度与加载性能，避免缓存过长导致数据滞后，或过短导致请求过载 |
| `share_show_source_link` | 按需关闭 | 简化嵌入页面的展示内容，避免无关链接干扰光伏日报的核心信息展示 |
| `share_require_login` | `false`（默认关闭） | 适配光伏日报的内部分享场景，仅在需要严格权限控制时开启，匹配数据敏感程度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：开启免登录分享后，访问分享链接仍弹出密码输入框。原因：生成分享链接时未关闭密码校验开关，或链接携带了历史的password参数缓存。
- 现象：通过iframe嵌入的光伏日报页面出现字段溢出、排版错乱。原因：未在嵌入页面中适配FastGPT默认的页面边距与字体样式，或未正确配置`iframe_allow_origin`的跨域权限。
- 现象：在FastGPT 4.9.6版本中，关闭分享链接的原文查看功能后，访问链接仍显示该按钮。原因：未同步更新应用的`share_show_source_link`配置，或使用了旧版本的分享链接生成逻辑。

## 怎么确认配好了
- 生成一条测试分享链接，访问后核对链接的过期时间与配置的`share_expire_time`是否一致。
- 尝试在非授权域名下嵌入分享内容，确认无法正常加载或触发跨域拦截。
- 关闭密码校验后生成分享链接，访问时无身份校验弹窗。
- 嵌入测试页面后，核对字段排版是否符合自定义样式要求，无溢出或错乱。
