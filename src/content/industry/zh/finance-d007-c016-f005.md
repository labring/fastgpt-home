# 光伏收益率的多轮对话与提示词

## 这个品类的数据长什么样
数据来源涵盖并网光伏项目的运行日志、行业协会月度监测报告、第三方运维平台的实时采集数据。更新节奏分两类：单项目实时数据每15分钟更新，行业平均收益率数据每月更新。文档以结构化表格为主要呈现形式，包含项目标识、装机容量、年辐照时长、上网电价、单位运维成本、累计发电量等字段。字段单位分别为千瓦、小时、元/千瓦时、元/千瓦、千瓦时。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
首先，实时数据的15分钟更新频率，要求多轮对话每次调用都需明确指定数据的时间窗口，避免拉取过期信息。其次，行业平均与单项目数据的差异化更新节奏，需要提示词中加入数据来源与类型的限定，防止模型混淆两类数据。再者，多字段的单位差异，需要提示词明确要求输出时附带对应字段的标准单位，避免单位转换错误。最后，单项目数据的绑定需求，要求多轮对话上下文需关联项目标识，防止跨项目数据串用。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 光伏收益率相关数据包含多字段的历史记录，较长上下文可保留项目标识与时间范围限定 |
| `recall_top_k` | `前6–8 条` | 光伏数据包含装机容量、辐照时长、电价等多个关联字段，需召回足够的关联信息但避免冗余干扰 |
| `PROMPT_TEMPLATE` | 固定加入“仅使用指定光伏项目的对应数据，输出需附带每个字段的标准单位” | 需明确限定数据范围与格式，避免模型混淆不同项目或单位错误 |
| `global_variable_scope` | `会话内绑定` | 光伏项目数据需绑定项目ID，防止跨会话或跨项目的数据串用 |
| `maxToolCallTimes` | `3–5 次` | 光伏收益率计算需依次调用辐照量、上网电价、运维成本等多个工具节点，避免无限循环 |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 光伏项目的运维文档、并网协议等文件通常不超过该尺寸，满足常见上传需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：切换会话后，之前绑定的光伏项目ID对应的全局变量无法保留。原因：未将`global_variable_scope`配置为会话内绑定，导致全局变量作用域超出当前会话范围。
- 现象：上传光伏项目的并网协议文档后，系统提示解析失败或返回空字段。原因：未将`UPLOAD_FILE_MAX_SIZE`调整至匹配文档实际尺寸，或提示词未指定解析光伏相关文档的目标字段。
- 现象：调用收益率计算工具后，结果被自动插入到对话历史的末尾。原因：未关闭AI对话节点的“自动追加到上下文”开关，导致工具返回结果被混入对话流。

## 怎么确认配好了
- 发起包含项目ID的测试对话，查看上下文是否保留该项目标识，确认上下文长度与全局变量作用域配置生效。
- 上传符合预期尺寸的光伏文档，检查解析结果是否包含预设的目标字段，确认上传文件尺寸与提示词模板配置正确。
- 调用收益率计算工具，查看返回结果是否仅包含计算值与字段单位，无额外对话内容，确认AI对话节点的自动追加开关已关闭。
- 切换至另一个测试项目会话，验证全局变量是否自动更新为新的项目ID，确认作用域配置符合预期。
