# 光伏收益率的工作流编排

## 这个品类的数据长什么样
面向金融行业的光伏收益率与行情日报的数据来源包含省级电网并网结算报表、第三方电力设备行情API、光伏电站SCADA系统监测数据。数据更新节奏为每日凌晨完成前一日全量数据汇总，日内监测数据每15分钟刷新，但日报播报仅取用前一日的汇总数据。文档多采用结构化JSON或CSV格式，包含装机编号、组件规格、当日发电总量、上网结算电价、运维成本、总收益额等字段。其中发电总量单位为千瓦时，电价单位为元每千瓦时，运维成本单位为元每千瓦装机，总收益额单位为元。

## 这些特征在「工作流编排」这一环带来什么约束
光伏数据的多源属性要求工作流配置并行拉取节点，适配不同数据源的返回格式差异。日报的T+1更新节奏要求触发节点设置为每日固定时间执行，避免提前拉取未完成的更新数据。多字段的唯一标识需求要求配置数据去重与聚合节点，按装机编号分组汇总跨源数据。不同组件规格的计算规则差异要求配置分支判断节点，分流执行对应组件类型的收益率计算逻辑。数据接口的延迟特性要求设置节点超时与重试机制，应对电网接口的偶发响应超时问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `trigger_cron` | `0 0 2 * * ?` | 光伏日报数据通常在每日凌晨2点前完成更新，设置该时间触发可获取完整前一日数据 |
| `data_source_parallel_count` | `2-4` | 光伏数据来源包含电网接口、第三方报价平台等多个渠道，并行拉取可减少总耗时 |
| `data_merge_key` | `装机编号` | 该字段为各数据源中唯一标识单座光伏电站的通用字段，可保证聚合准确性 |
| `node_timeout` | `600 秒` | 电网接口的响应延迟通常在300-500秒之间，预留足够时间避免节点超时失败 |
| `branch_condition_field` | `组件规格` | 不同组件规格的上网电价与运维成本计算规则存在差异，需按该字段分流执行不同计算逻辑 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为工作流执行后仅返回单座光伏电站的收益数据，未覆盖全部装机。原因：未启用工作流的循环遍历功能，未将装机编号数组设置为循环目标。
- 现象为全局变量`select_knowledge_base`的取值固定为初始配置，无法随组件规格自动切换。原因：未配置变量的动态赋值规则，未绑定数据源返回的组件规格字段作为触发条件。
- 现象为文本提取节点执行后返回空结果，无法提取当日上网电价。原因：未配置提取规则的匹配字段，未指定数据源中对应电价的JSON路径。

## 怎么确认配好了
- 核对工作流的定时触发配置，确认触发时间与光伏日报数据的更新节奏匹配。
- 执行单次测试运行，验证各数据源拉取节点返回的字段是否符合预设的聚合规则。
- 检查循环节点的配置，确认已绑定装机编号数组作为遍历目标。
- 查看变量赋值日志，确认`select_knowledge_base`全局变量随数据源返回的组件规格自动更新。
