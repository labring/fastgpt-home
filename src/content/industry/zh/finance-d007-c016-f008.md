# 光伏收益率的工具调用与插件

## 这个品类的数据长什么样
光伏收益率相关数据主要来源于省级电力交易中心公开结算数据、光伏电站运维系统的本地采集数据。数据更新节奏为每日凌晨完成前一日全量数据更新，单条数据采用结构化JSON格式，包含电站唯一标识、装机容量、当日辐照量、当日上网电量、当日结算电价、当日运营成本、当日收益总额等字段。每个字段均对应明确的物理单位，无模糊描述，不同来源的数据字段命名规则统一，无需额外转换即可直接使用。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据的获取要求插件需对接至少两类外部接口，需配置跨接口的数据合并逻辑，确保数据准确性。T+1的更新节奏要求插件缓存策略需匹配每日刷新的周期，避免调用过期数据。结构化且带明确单位的字段特征，要求工具调用时需严格匹配字段名与单位，否则会导致收益率计算错误。批量查询多电站数据的场景，要求插件需支持按电站ID列表的批量请求参数，平衡接口调用效率与数据返回量。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_cache_ttl` | `86400 秒` | 匹配光伏收益率数据T+1的更新节奏，避免调用过期数据 |
| `plugin_request_batch_size` | `10–50 条` | 适配单批次电站数据的查询上限，平衡接口调用效率与负载 |
| `plugin_api_timeout` | `30 秒` | 覆盖多数电力交易接口的常规响应时长，避免触发超时错误 |
| `plugin_field_mapping` | `按接口返回字段名直接映射` | 匹配光伏数据结构化的字段特征，减少字段转换误差 |
| `plugin_response_validation` | `启用单位校验` | 规避不同数据源的单位不一致问题，确保收益率计算准确 |
| `plugin_auth_type` | `API_KEY 鉴权` | 符合多数电力交易接口的鉴权规范，保障数据访问安全 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用绑定光伏数据的插件后，界面返回“模型流响应为空，请检查模型流输出是否正常”的报错，原因是未在插件配置中启用结构化数据返回开关，导致工具无法解析光伏数据的字段结构。
- 现象为在工作流编排页面无法找到已创建的光伏收益率插件，原因是未在插件编辑页开启「工作流可调用」配置项，或插件的API_KEY鉴权参数填写错误。
- 现象为批量查询多电站数据时返回结果条数不足，原因是未将`plugin_request_batch_size`设置为适配查询规模的取值，导致接口返回截断数据。

## 怎么确认配好了
- 登录FastGPT插件管理页面，查看目标光伏收益率插件的状态，确认「已启用」开关处于开启状态。
- 发起单次测试调用，传入合法的光伏电站ID参数，检查返回结果包含预设的全部字段，无空值或格式错误。
- 进入工作流编排界面，在工具调用节点的插件列表中搜索该插件，确认可以正常选中并绑定到流程节点。
- 查看插件的调用日志，核对每次请求的响应时长未超过配置的超时阈值，无超时报错记录。
