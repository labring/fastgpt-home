# 光伏收益率的表单与交互

## 这个品类的数据长什么样
光伏收益率相关数据主要来自并网光伏电站的SCADA监控系统、区域电力交易公开结算报表、电网公司的并网运行数据，用于金融理财场景下的光伏项目收益测算与日报播报。更新节奏分为两类：实时发电数据每15分钟推送更新，日度结算数据每日凌晨完成全量更新。文档结构包含电站唯一标识、装机总容量、当日累计发电量、上网电量、自发自用电量、结算电价、区域电网负荷参考参数等核心字段。字段均带有明确的标准单位：装机容量以千瓦（kW）为单位，发电量以千瓦时（kWh）为单位，电价以元/千瓦时为单位。部分大型电站还会包含组串级的发电数据字段，用于精细化收益率计算。

## 这些特征在「表单与交互」这一环带来什么约束
多源数据接入的需求带来表单需要支持多数据源配置，包括不同类型的监控系统和交易平台接口，因此需要开放端口、认证方式等自定义配置项。分层的更新节奏要求表单支持定时拉取和实时拉取两种同步模式，需分别配置对应触发间隔。标准化的字段与单位要求表单内置针对性的输入校验规则，避免非标准单位或错误字段值被录入。电站唯一标识的批量管理需求，要求表单支持批量导入电站ID列表，减少单条录入的操作成本。收益率计算依赖多字段联动的特性，要求表单支持字段间的自动计算逻辑，无需手动重复录入计算式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `datasource_port` | 1000–65535 整数 | 符合TCP端口分配规范，匹配光伏电站监控系统的默认端口范围 |
| `form_field_mapping` | 按数据源字段名一对一映射 | 匹配光伏数据的标准化字段结构，减少手动调整成本 |
| `data_sync_interval` | 900 秒（实时）或 86400 秒（日度） | 对应实时发电数据和日度结算数据的更新节奏 |
| `form_validation_rule` | 预设「kW」「kWh」「元/千瓦时」单位校验 | 匹配光伏数据的标准单位，避免输入错误 |
| `batch_import_limit` | 前 100 条单次导入 | 平衡表单加载性能与批量操作效率 |
| `form_calculate_trigger` | 字段变更后自动触发 | 支持收益率实时计算，匹配用户交互习惯 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：数据库连接节点的端口输入框置灰无法输入。原因：未开启「自定义数据源端口」的开关，或当前使用的数据源类型不支持端口自定义。
- 现象：表单提交后出现「单位不匹配」报错，或计算结果出现明显偏差。原因：未配置`form_validation_rule`的单位校验规则，或字段映射时错误匹配了非标准字段。
- 现象：语音输入功能无法识别光伏行业专业术语，如「组串」「自发自用比例」。原因：未加载光伏行业的专业词库，或语音识别模型的领域适配未开启。

## 怎么确认配好了
- 打开数据库连接节点配置页，确认`datasource_port`输入框可正常编辑并输入合法端口号。
- 导入一条光伏数据测试样本，确认表单自动匹配字段并显示正确的单位校验提示。
- 手动修改表单中的一个字段，确认收益率计算结果自动更新。
- 调用表单初始化API，确认返回的开场白、必填字段信息与配置内容一致。
