# 光学光电子收益率的模型接入与配置

## 这个品类的数据长什么样
这个品类的数据来自合规公开证券行情接口、行业细分报价平台，每日在收盘后1至2小时完成更新。单条数据以结构化格式存储，每行对应一只上市光学光电子企业或细分品类的当日行情记录。字段包含6位数字格式的证券代码、中文证券名称、当日收盘价（单位：元/股）、当日价格变动额（单位：元/股）、当日成交量（单位：股）、当日成交额（单位：元）、行业分类代码以及数据发布日期（格式为YYYY-MM-DD）。数据会按证券代码与发布日期进行分组归档，单份日报文档的记录数随覆盖范围浮动。

## 这些特征在「模型接入与配置」这一环带来什么约束
每日固定时段更新的特性要求模型调用触发时间需匹配收盘后窗口，避免拉取未完成更新的旧数据。多类带单位的数值字段，要求接入时明确字段映射规则，防止单位混淆引发计算偏差。单份文档记录数浮动的特点，需要配置适配可变长度输入的批量处理参数，避免数据截断或内存溢出。依赖公开接口的数据源，需配置合规的鉴权参数，确保请求合法性。固定格式的发布日期字段，要求模型的上下文清洗环节增加格式校验逻辑，过滤无效数据条目。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `modelInvokeTimeout` | `300 秒` | 光学光电子行情数据的批量处理请求通常在300秒内完成，避免超时中断 |
| `batchProcessMaxRecords` | `500 条` | 适配单份日报常规记录数区间，避免数据截断或内存溢出 |
| `fieldMappingRule` | 按字段名精准匹配 | 数据字段命名固定，精准匹配可避免单位混淆 |
| `apiAuthType` | `API_KEY 鉴权` | 公开行情接口多采用该鉴权方式，符合合规要求 |
| `contextCleanupFormat` | `YYYY-MM-DD` | 匹配数据发布日期的固定格式，快速过滤无效条目 |
| `maxContextTokens` | `8192 令牌` | 适配行情日报结构化数据的令牌消耗，符合多数通用大模型的上下文限制 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：模型接入时调用行情数据接口返回`403 Forbidden`状态码，或界面提示「鉴权失败」。原因：未正确配置公开行情接口的鉴权参数与密钥，导致请求被接口拒绝。
- 现象：配置多个同名模型时，调用时始终使用第一个配置的密钥。原因：未为每个模型配置独立的标识参数，导致系统无法区分同名模型的密钥。
- 现象：工作流节点返回的行情数据包含非当日的历史记录。原因：未配置格式校验规则，未过滤不符合`YYYY-MM-DD`格式的发布日期条目。

## 怎么确认配好了
- 手动触发一次模型调用，核对返回的行情数据是否包含当日的光学光电子品类记录，且字段单位与数据源匹配。
- 发起接口鉴权测试请求，确认返回状态码为`200 OK`。
- 导入一份超出常规记录数的测试数据，确认系统可正常处理可变长度的输入数据集。
- 配置同名多模型标识，切换不同标识发起调用，确认调用时使用对应的密钥参数。
