# 免税收益率的工具调用与插件

## 这个品类的数据长什么样
免税品类的收益率与行情数据主要来自国内离岛免税监管平台、头部免税品牌官方供应链数据及线下门店POS采集数据，更新节奏为每日T+1更新前一自然日的全量数据集。数据格式为结构化JSON或CSV，包含商品类目、运营主体、采集来源标识、当日营收、当日成本、收益率指标、数据更新时间戳等字段，字段单位统一为无百分比的小数形式或标准货币单位，覆盖国内主流离岛免税、市内免税及线上免税商城渠道。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类数据的T+1更新节奏要求工具调用触发频率不得超过每日一次，否则会获取未更新的空数据集。结构化多字段的特性要求工具调用时必须严格匹配预设字段名，否则会出现字段解析异常。多渠道采集的数据源分散特性，要求插件配置多源聚合规则并设置源优先级，避免数据冲突。收益率字段的非百分比小数格式，要求插件中添加格式校验逻辑，过滤非数值类型输入。数据的合规性要求，要求插件配置数据来源白名单，仅接入合规监管平台或官方披露渠道的数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `batch_execution_trigger_frequency` | `每日1次，固定凌晨2点触发` | 匹配免税收益率数据T+1的更新节奏，避免重复调用未更新的数据源 |
| `field_matching_strictness` | `严格匹配` | 该品类字段多且格式固定，严格匹配可避免字段解析错误 |
| `plugin_data_source_whitelist` | `添加海关总署离岛免税监管平台、头部免税品牌官方API` | 确保数据来源合规，规避非正规数据源的风险 |
| `tool_timeout` | `600 秒` | 多源聚合数据时需等待各渠道返回，较长超时可避免中途中断 |
| `response_format_validation` | `启用小数格式校验、必填字段校验` | 该品类收益率字段为非百分比小数，需过滤异常格式输入 |
| `batch_execution_max_concurrency` | `按实测标定` | 不同部署环境的并发承载能力不同，需结合实际运行情况调整 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：批量执行节点在线调试可完成全流程，但API调用时仅执行部分节点或中途中断。原因：未配置批量执行节点的触发频率与数据更新周期匹配，API调用时触发频率超过数据更新节奏，导致获取到未完成的数据集。
- 现象：接口调用工作流后，对话日志中的运行数据字段为空。原因：未开启工具调用的日志采集配置，或字段匹配严格度过高导致有效数据被过滤。
- 现象：V4.12.3版本中自定义插件运行后，输出下载地址持续跳动后才返回结果。原因：插件配置了多源数据聚合，需等待所有渠道返回后才生成最终下载地址，未设置合理的超时等待阈值导致界面延迟展示。

## 怎么确认配好了
- 触发一次工具调用，检查返回数据的字段是否与预设的免税品类数据字段完全匹配。
- 查看工作流运行日志，确认所有配置的数据源均成功接入且无报错信息。
- 连续两日触发工具调用，检查返回数据的更新时间戳是否符合T+1的更新节奏。
- 模拟API调用，核对批量执行节点的执行结果是否与在线调试的结果一致。
