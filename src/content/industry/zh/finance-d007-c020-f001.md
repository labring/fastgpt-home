# 兵器装备收益率的HTTP 接口与外部系统

## 这个品类的数据长什么样
这个品类的数据来源于军工行业专业行情聚合接口、国防科工局公开的装备行业监测数据，每日收盘后完成当日数据更新，周度更新滚动周期收益数据。数据文档为标准JSON格式，单条数据包含装备型号编码、统计日期、当日收益变动值、累计收益变动值、所属生产厂商标识字段。所有收益变动值字段为数值类型，统计日期字段为YYYY-MM-DD格式字符串。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
数据源的专业性要求接口请求必须携带专属认证凭证，否则无法获取有效数据；每日收盘后的固定更新节奏，要求外部系统的同步任务需匹配该频率，避免高频调用触发接口限流；固定的JSON字段结构，要求外部系统需预先定义严格的字段解析规则，无法直接复用通用金融数据的解析逻辑；非通用的字段单位与标识，要求外部系统需配置专属的字段映射与单位转换规则，避免与其他品类的数据混淆。此外，装备型号的唯一性要求接口返回数据需进行去重处理，否则会导致外部系统出现重复数据条目。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `API_REQUEST_TIMEOUT` | `30 秒` | 兵器装备数据源接口的响应延迟通常在10-25秒区间，30秒可覆盖正常响应时长且避免长时间阻塞任务队列 |
| `RETRY_TIMES` | `3 次` | 军工数据源接口可能存在临时限流，3次重试可覆盖大部分临时故障场景，减少数据同步失败概率 |
| `DATA_PARSE_SCHEMA` | 按装备型号编码、统计日期、当日收益变动值、累计收益变动值、所属厂商标识字段映射 | 兵器装备数据的固定JSON结构需严格匹配字段名，避免出现字段解析为空的问题 |
| `REQUEST_AUTH_TYPE` | `Bearer Token` | 军工行业专业数据源普遍采用Bearer Token作为接口认证方式，符合数据接口的安全校验要求 |
| `BATCH_REQUEST_SIZE` | `20 条/次` | 兵器装备单批次数据量适中，20条可平衡请求效率与接口限流限制，避免单次请求数据量过大被拦截 |
| `EXTERNAL_SYNC_CRON` | `每日 16:30` | 国内军工相关数据接口通常在收盘后1.5小时内完成更新，16:30可覆盖正常的更新延迟，确保获取当日最新数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用配置好的HTTP接口返回`401 Unauthorized`状态码，无有效数据返回。原因：未正确配置`REQUEST_AUTH_TYPE`与对应认证令牌，未通过军工数据源的接口安全校验。
- 现象：自定义数据同步脚本运行后提示路径错误，无法加载接口配置文件。原因：未正确填写`LOCAL_FILE_PATH`参数的实际路径，路径格式不符合系统要求。
- 现象：定时同步任务执行后出现重复的装备型号数据，或部分数据字段解析为空。原因：未在`DATA_PARSE_SCHEMA`中配置完整的字段映射规则，或未添加装备型号去重逻辑，导致数据解析异常。

## 怎么确认配好了
- 手动触发一次HTTP接口调用，查看返回的原始数据是否包含预设的装备型号编码、统计日期等核心字段。
- 查看定时同步任务的执行日志，确认无`401`、`504`等错误状态码记录。
- 对比外部系统展示的装备数据条数与接口返回的总条数，确认数据无缺失或重复。
- 验证收益变动值的展示格式，确认已正确应用预设的单位映射规则。
