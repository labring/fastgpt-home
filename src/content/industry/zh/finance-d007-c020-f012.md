# 兵器装备收益率的模型接入与配置

## 这个品类的数据长什么样
兵器装备相关的收益率与行情数据，来源包括国防军工行业公开披露的经营数据、二级市场交易行情数据。更新节奏为每日更新核心行情字段，每季度更新完整经营指标。文档结构多为结构化CSV或JSON格式，包含字段如：军工装备品类标识、统计日期、资产收益率数值、所属集团代码、当日交易总量。字段单位方面，资产收益率数值为无量纲比值，当日交易总量单位为股，统计日期采用YYYY-MM-DD格式。

## 这些特征在「模型接入与配置」这一环带来什么约束
每日更新的行情数据要求模型调用的API接口支持高频拉取，不宜设置过长的缓存周期，否则会导致播报数据滞后于当日行情。结构化的CSV/JSON格式数据要求模型的提示词需明确指定字段解析规则，避免输出非结构化的自然语言内容，影响后续播报的自动化处理。军工装备品类的细分标识较多，需要配置多维度的字段筛选参数，确保模型能精准匹配指定品类的收益率数据。公开披露的经营数据存在发布滞后性，需要配置数据校验环节，过滤延迟的非当日数据，保证播报内容的时效性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 字符 | 兵器装备收益率数据包含多字段，需要足够的上下文容纳解析规则与历史数据示例 |
| `apiRequestTimeout` | 30 秒 | 行情数据接口响应较快，过长超时会导致播报延迟，过短会错过有效数据拉取 |
| `promptTemplate` | 按「统计日期+品类标识+收益率数值+交易数据」的结构化格式输出，保留指定字段 | 兵器装备数据字段多且需精准播报，明确模板可避免模型遗漏关键信息 |
| `dataSourceCacheTTL` | 3600 秒 | 每日更新的行情数据无需长时间缓存，1小时缓存可平衡时效性与接口调用频率 |
| `responseFormat` | JSON | 用于后续播报的结构化数据，JSON格式便于前端渲染与多轮对话传递 |
| `fieldFilterRule` | 仅保留统计日期为当日的记录 | 符合日报播报的时效性要求，过滤滞后的历史数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用接口返回`403 status code (no body)`。原因是未正确配置API密钥的权限范围，或未在FastGPT渠道配置中添加对应接口的白名单IP。
- 模型无法正确识别提示词中的空格分隔字段。原因是提示词未明确指定空格作为字段分隔符的规则，导致模型将连续空格视为无意义字符。
- 模型输出的收益率数据字段缺失。原因是未在`fieldFilterRule`中配置正确的字段筛选条件，导致模型过滤了不必要的有效字段。

## 怎么确认配好了
- 发起一次测试调用，检查返回结果的字段是否与配置的`fieldFilterRule`一致。
- 查看接口调用日志，确认每次调用的响应时间未超过配置的`apiRequestTimeout`值。
- 对比输入的数据源与模型输出的内容，确认输出格式符合配置的`responseFormat`要求。
- 测试间隔1小时后再次调用，检查返回数据是否为最新的当日行情数据，确认缓存配置生效。
