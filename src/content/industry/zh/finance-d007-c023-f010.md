# 军工电子收益率的数据库与运维

## 这个品类的数据长什么样
军工电子领域的收益率相关数据，主要来源为国内证券交易所公开行情接口、军工行业协会公开数据集、合规授权的第三方金融数据接口。数据更新节奏分为两类：每日收盘后更新的实时行情数据，以及季度财报披露后3个工作日内更新的衍生收益率指标数据。单条数据文档包含标的代码、标的名称、当日交易价格区间、当日成交规模、数据采集时间戳、数据来源标识等字段，其中价格类字段单位为人民币元，成交规模类字段单位为万股，时间字段采用UTC+8时区的ISO格式时间戳。数据文档的核心字段均为必填项，缺失将导致后续播报流程异常。

## 这些特征在「数据库与运维」这一环带来什么约束
多数据源接入要求数据库配置细粒度的访问权限控制，避免敏感金融数据泄露。不同更新节奏的数据源需要拆分调度任务，高频行情数据需配置短周期定时同步，低频衍生数据需适配季度级别的调度周期。军工电子数据涉及行业敏感信息，需开启数据库审计日志与敏感字段加密功能，满足合规要求。历史行情数据的快速召回需求，要求建立按采集时间与标的代码的联合索引，同时需按日期分区存储以控制单表数据量。数据源的不稳定性要求配置重试机制与数据补全流程，运维环节需实时监控数据源可用性与数据库写入成功率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MONGO_CONNECTION_STRING` | `mongodb://fastgpt_user:secure_pass@mongo-host:27017/fastgpt?authSource=admin&readPreference=secondaryPreferred` | 支持身份认证与读写分离，适配多数据源高并发写入场景，保障敏感数据访问安全 |
| `VECTOR_DB_REPLICA_NUM` | 3–5个副本 | 提升军工电子行情数据的召回并发能力，保障查询服务的高可用性 |
| `DATA_SYNC_INTERVAL` | 900秒 | 匹配每日行情数据的更新节奏，避免数据延迟超过15分钟 |
| `MONGO_MAX_POOL_SIZE` | 50–80 | 适配批量数据写入场景，避免连接池资源耗尽 |
| `BACKUP_RETENTION_DAYS` | 30天 | 满足合规审计的日志留存要求，同时控制存储成本 |
| `VECTOR_DB_SIMILARITY_THRESHOLD` | 0.75–0.85 | 过滤低相关的检索结果，提升军工电子收益率播报的准确性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：使用第三方MongoDB管理工具直接修改向量库文档后，FastGPT召回结果为空。原因：向量库文档的元数据字段未遵循FastGPT的预设格式，导致系统无法识别有效数据。
- 现象：启动容器后日志报错`retry init root user mongo start connect init root user error`。原因：MongoDB连接串配置错误，或未创建fastgpt专属数据库与用户权限。
- 现象：定时同步军工电子数据任务超时，返回状态码504。原因：未调整`DATA_SYNC_TIMEOUT`参数，默认超时时间不足以完成批量数据拉取与写入。

## 怎么确认配好了
- 登录MongoDB客户端，执行`show dbs`与`show collections`命令，确认存在fastgpt数据库及对应的行情数据集合，核对`collection_time`字段的最新值与当日时间一致。
- 调用FastGPT的向量召回接口，传入军工电子相关的查询词，检查返回结果的条数与配置的召回参数一致。
- 查看容器运行日志，确认无`MONGO_CONNECT_ERROR`或`VECTOR_DB_CONNECT_FAILED`类报错。
- 执行手动备份操作，检查导出文件的元数据与实际知识库数据结构匹配。
