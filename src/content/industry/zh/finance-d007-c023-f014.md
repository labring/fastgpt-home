# 军工电子收益率的表单与交互

## 这个品类的数据长什么样
军工电子的收益率相关数据主要来自沪深交易所军工电子板块的公开交易数据、国防科技工业主管部门发布的行业监测数据、军工电子元器件厂商的公开报价信息。数据更新节奏分为三类：交易类数据每日收盘后更新，行业监测数据每周更新，厂商报价数据每旬更新。单条数据文档包含板块标识、板块分类名称、当日交易均价、当日价格变动额、当日成交量、当日成交总额、核心元器件市场指导价、行业营收占比字段。字段单位分别为：交易均价元，价格变动额元，成交量万股，成交总额万元，元器件指导价元/件。

## 这些特征在「表单与交互」这一环带来什么约束
多源数据的更新节奏差异要求表单支持按数据源配置差异化的刷新间隔，避免无效刷新或数据滞后。细分字段如核心元器件指导价、行业营收占比的存在，要求表单提供可自定义的字段展示列表，适配不同分析场景的需求。军工电子板块的精细化分类要求表单内置细分筛选维度，支持用户按射频、芯片、传感器等子类筛选数据。不同数据源的字段单位存在差异，要求表单支持单位自动匹配或手动调整，保证数据展示的一致性。数据来源的权威性要求表单添加数据源标识的展示开关，满足场景下的信息溯源需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `knowledgeSearch` | 按数据源分组配置多个检索源 | 军工电子数据来自多类数据源，分组检索可匹配不同字段规则 |
| `dynamicValue` | 绑定板块分类下拉选项的选中值 | 支持用户手动选择细分军工电子板块，适配精细化筛选需求 |
| `refreshInterval` | 600–1800 秒，交易类数据单独设为86400秒 | 匹配军工电子多源数据的更新节奏，平衡数据时效性与系统负载 |
| `formFieldList` | 勾选交易均价、价格变动额、成交量等核心字段 | 匹配军工电子场景下的核心分析维度，避免无关字段干扰 |
| `fieldUnitMapping` | 配置「成交量→万股」「成交总额→万元」等映射规则 | 统一不同数据源的字段单位展示，消除格式差异 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 适配军工电子行业数据文档的长度，避免长文档解析超时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 语音输入转文本时报`unmarshal_resp`错误：未配置军工电子场景下的专业术语转写规则，导致专业字段解析失败。
- 动态传入`knowledgeSearch`变量后未检索到匹配文档：未按军工电子的多数据源分类配置检索源，变量未绑定对应数据源的检索配置。
- 数据库连接工具使用变量传入SQL报错：未将军工电子的板块代码等字段做类型校验，变量值未匹配SQL语句的参数格式要求。

## 怎么确认配好了
- 打开表单配置页面，核对`formFieldList`中已勾选的字段与军工电子场景的核心分析维度一致。
- 触发一次数据检索，检查不同数据源返回的字段单位是否按`fieldUnitMapping`的规则统一展示。
- 手动选择细分军工电子板块，确认表单能加载对应板块的最新数据。
- 模拟语音输入军工电子专业术语，检查转写后的文本是否能正确匹配表单字段。
