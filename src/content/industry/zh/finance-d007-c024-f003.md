# 农化制品收益率的分享与嵌入

## 这个品类的数据长什么样
农化制品收益率相关数据主要来自国内农化行业现货交易平台、农业农村部市场预警系统及头部农化企业公开报价渠道。数据更新节奏分为两类：现货单品报价每日更新，周度、月度收益率汇总数据每周固定周期更新。文档结构以多列结构化表格为主，包含产品名称、产地、规格、当日成交价、周期环比、周期同比等字段，单位涵盖元/吨、千克等，单份批量数据文件通常包含数十至上百条单品记录，每行对应一个独立单品的完整数据信息。

## 这些特征在「分享与嵌入」这一环带来什么约束
首先，多列结构化的单品数据存储格式，要求分享嵌入组件支持自定义列筛选与展示，避免返回冗余信息。其次，不同维度数据的更新频率差异，要求分享链接的缓存时长可灵活配置，匹配对应数据的更新周期，防止返回过期内容。第三，部分农化数据存在商业授权限制，要求嵌入功能支持权限校验配置，限制未授权访问。第四，单品数据按行独立存储的结构，要求RAG召回与分享内容可按单品维度精准匹配，避免跨行拼接导致的信息混乱。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `share_cache_ttl` | 日报数据取`3600 秒`，周报数据取`86400 秒` | 匹配农化数据的更新频率，避免返回过期的收益率信息 |
| `embed_iframe_max_width` | `1200px` | 适配多数企业官网的标准内容区域宽度，避免嵌入内容出现横向滚动 |
| `rag_chunk_mode` | 按行分段 | 匹配农化多列excel的单品数据存储格式，避免自动分段规则拆分单条单品的完整信息 |
| `share_auth_enabled` | 开启 | 适配农化数据的商业授权要求，限制未授权用户访问分享内容 |
| `rag_chunk_size` | `800-1200 字符` | 覆盖1-6条单品数据的总长度，保留单品间的上下文关联 |
| `embed_api_timeout` | `60 秒` | 预留足够的多数据源聚合请求时间，避免因数据加载超时导致嵌入失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：嵌入后的农化收益率报表出现跨行拼接的混乱数据。原因：未配置`rag_chunk_mode`为按行分段，使用默认的自动分段规则拆分了单条单品的完整信息。
- 现象：分享链接返回的农化日报数据更新时间滞后超过24小时。原因：未根据数据更新频率调整`share_cache_ttl`参数，使用了默认的长缓存时长，导致缓存未及时刷新。
- 现象：未授权用户可直接访问分享的农化数据链接。原因：未开启`share_auth_enabled`配置，未启用分享鉴权功能，导致分享链接无权限限制。

## 怎么确认配好了
- 打开配置后的分享链接，查看页面展示的数据更新时间，确认与数据源的最新更新时间一致，验证缓存配置生效。
- 将嵌入组件嵌入测试页面，调整浏览器窗口宽度，确认嵌入内容不会出现横向滚动条，验证iframe宽度配置生效。
- 使用未授权的账号访问分享链接，确认页面提示无访问权限，验证鉴权配置生效。
- 上传多列农化excel文件至知识库，查看RAG分段结果，确认每条单品数据被单独作为一个分段，验证分段配置生效。
