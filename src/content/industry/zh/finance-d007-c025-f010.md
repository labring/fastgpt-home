# 农商行收益率的数据库与运维

## 这个品类的数据长什么样
农商行的收益率数据主要来自本行零售信贷产品台账、同业存单发行台账、辖内理财代销产品的每日公开报价，更新节奏为每日营业结束后批量同步生成。数据文档为结构化的关系型表结构，包含机构编码、产品分类、产品编号、收益率基准值、统计日期等核心字段，无嵌套层级，每个条目对应单一产品的单日收益基准数据，字段单位统一为年化收益基准单位，未附带非结构化附件内容。

## 这些特征在「数据库与运维」这一环带来什么约束
多源数据接入的要求，需配置跨数据源的连接与映射规则，校验不同系统字段的一致性，避免数据错位。每日批量更新的节奏，要求运维环节预留非核心业务窗口执行同步任务，避免干扰营业时段的核心交易。按机构编码的字段设计，需配置行级数据权限，确保不同支行的运维人员仅能访问对应辖内的数据。数据的时效性要求，需配置超时重试机制，应对上游系统的临时延迟，保障日报播报的及时性。同时，产品分类粒度较细的特征，要求数据库配置针对性的索引，支撑按分类、日期的高频查询需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_SYNC_CRON` | `0 30 22 * * ?` | 适配农商行每日22点前结束营业的窗口，避免同步干扰核心业务 |
| `DB_CONNECTION_TIMEOUT` | `60 秒` | 覆盖跨核心系统、同业平台的平均响应延迟，避免连接中断 |
| `KNOWLEDGE_BASE_SYNC_RETRY_TIMES` | `3 次` | 应对上游系统临时波动，减少批量同步失败的概率 |
| `WHITELIST_ALLOWED_IPS` | `本行核心业务IP段、代销合作平台IP段` | 限制仅可信来源访问数据库，保障数据安全 |
| `DB_JOIN_INDEX_CONFIG` | `按统计日期、机构编码创建联合索引` | 匹配日报播报按日期、机构过滤的高频查询场景，提升查询性能 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置数据库连接后出现`10060`错误码，无法建立连接。原因：未将FastGPT部署服务器的IP加入数据库白名单，不符合数据库的访问权限限制规则。
- 现象：批量同步数据时出现部分字段为空的情况，知识库内的收益率数据缺失指定分类。原因：未配置跨数据源的字段映射规则，导致不同系统的字段命名差异未被自动对齐。
- 现象：定时同步任务执行后触发超时告警，任务状态显示为失败。原因：同步任务的执行窗口未预留足够缓冲时间，且未调整连接超时参数值，导致上游系统响应超时未完成重试。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证配置的IP、端口、账号密码可正常建立连接，核对返回的字段列表与预设的农商行收益率数据字段一致。
- 手动触发一次定时同步任务，查看任务日志中的同步条数与上游系统的实际数据条数匹配，确认无字段缺失或错位情况。
- 登录数据库管理工具，查看是否已创建预设的联合索引，验证索引的字段组合与配置项一致。
- 检查FastGPT的知识库同步记录，确认每日同步任务的执行状态为成功，无报错信息。
