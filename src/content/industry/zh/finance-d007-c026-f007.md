# 出版收益率的工作流编排

## 这个品类的数据长什么样
该品类的数据来源为持牌金融行情接口、交易所公开披露端口，更新节奏为每个交易日收盘后完成批量汇总，次日发布正式日报。文档以结构化表格为核心载体，包含产品唯一标识、产品全称、当日收益数据、累计收益数据、对标基准数据、发布时间戳等字段。收益类字段采用标准化收益计价单位，文档同时附带数据来源说明与校验标识，确保合规性。

## 这些特征在「工作流编排」这一环带来什么约束
数据源的合规性要求，要求工作流仅调用已完成资质校验的金融数据接口，需配置数据源白名单节点限制非授权接入。每日批量更新的节奏，要求工作流设置定时触发规则，避免频繁调用接口产生冗余开销。结构化表格的文档结构，要求工作流中配置结构化数据解析节点，自动提取指定字段，不依赖大模型泛化识别。多字段的输出要求，需配置字段映射节点，将原始数据字段对齐至出版日报的固定格式，同时需预留数据校验环节，过滤异常字段值。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `trigger_type` | `定时触发，每日固定时段` | 匹配该品类每日批量更新的发布节奏，减少无效调用 |
| `structured_parse_mode` | `表格列提取模式` | 适配该品类结构化表格的数据格式，精准提取目标字段 |
| `field_mapping_list` | `按出版日报格式配置字段对应关系` | 对齐出版产品的固定输出字段要求 |
| `data_source_allowlist` | `添加合规金融数据接口域名` | 满足数据源合规性要求，限制非授权接入 |
| `max_parallel_runs` | `1` | 批量数据处理需串行执行，避免接口调用冲突 |
| `system_prompt_override` | `清空默认系统提示词` | 避免输出中出现固定平台标识文案，符合出版内容规范 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流内配置的多个工具节点未按预期顺序执行，部分节点未触发调用。原因：未启用工作流的顺序执行配置项，默认并行模式下工具触发逻辑独立于配置顺序。
- 现象：最终输出内容末尾附带固定平台标识文案，与配置的输出格式不符。原因：未覆盖默认系统提示词，保留了平台内置的引导文本。
- 现象：日报内容中的连续多行排版失效，换行被自动合并为单行。原因：未在输出提示词中明确指定换行格式，或未开启Markdown渲染配置项，导致换行符被过滤。

## 怎么确认配好了
- 触发工作流一次，查看触发日志，确认触发时段符合配置的定时规则。
- 解析数据源返回的结构化数据，查看字段提取结果，确认所有目标字段均被正确映射。
- 检查最终输出内容，确认无固定平台标识文案，排版符合要求。
- 运行多轮测试，确认所有配置的工具节点均按顺序触发执行。
