# 出版收益率的表单与交互

## 这个品类的数据长什么样
数据来源为公开授权的金融行情数据源与监管披露文件，更新节奏为每个交易日收盘后生成当日报表，文档为结构化的表格格式，包含标准化字段。字段包括产品唯一标识、产品全称、当日单位净值、当日收益额、基准收益参考值、当日交易规模，单位分别为编码、文本、货币单位、货币单位、货币单位、交易单位，无百分比类单位。

## 这些特征在「表单与交互」这一环带来什么约束
结构化表格的标准化字段要求，要求表单支持自定义字段映射与校验规则，适配不同出版机构的字段命名差异。每日固定更新的节奏，要求交互环节区分交易日与非交易日，避免用户在非交易时段提交无效数据。多产品的批量数据特性，要求表单支持分页加载、批量编辑与批量提交，避免界面卡顿与操作超时。同时，金融数据的严谨性要求，需在交互中增加数据预览环节，确保导入文件的字段与业务需求匹配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 出版日报的结构化文件通常包含数百只产品的明细数据，单文件体积通常在数百MB区间，该取值可覆盖常规导入需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 结构化表格文件的解析需要遍历多列数据，复杂场景下耗时较长，该取值可避免提前终止解析 |
| `表单字段映射规则` | 按字段名模糊匹配+手动修正 | 不同出版机构的字段命名存在差异，该配置可降低导入门槛，适配多来源的日报文件 |
| `批量操作并发数` | `10–15` | 批量处理收益率数据时，过高并发会导致数据源接口限流，该区间可平衡处理效率与稳定性 |
| `输入校验开关` | 开启数值型字段校验 | 收益率相关字段为数值类型，开启校验可提前拦截非合法输入，减少后续处理错误 |
| `定时任务触发时间` | `16:30–17:30` | 多数交易日在15:00收盘，后续1-2小时为数据生成窗口期，该时段触发可获取当日完整行情数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为通过iframe嵌套应用后，点击文本触发弹窗带入输入框时，发送按钮呈灰色不可点击状态。原因是嵌入页面的跨域通信未正确配置，导致输入框内容未同步至FastGPT应用的上下文变量，触发了输入为空的校验规则。
- 现象为批量上传结构化日报文件时，前十几条处理正常，后续处理失败。原因是未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，文件解析超时后被强制终止，后续数据未完成加载。
- 现象为导入的日报数据字段过多时，AI对话节点返回空结果。原因是未开启输入长度校验，且未配置`maxContext`参数限制上下文长度，超出模型输入上限后触发隐式报错。

## 怎么确认配好了
- 上传测试用的结构化表格文件，核对字段映射是否自动匹配成功，手动修正不匹配的字段后确认导入无报错。
- 配置定时任务后，在预设触发时段手动触发一次，检查任务日志中是否显示数据解析完成、无异常字段。
- 调整批量操作并发数至不同区间，对比处理耗时与接口返回状态，选取符合业务稳定性要求的取值。
- 嵌入iframe测试跨域通信，触发输入框内容同步后，确认发送按钮可正常点击并提交内容。
