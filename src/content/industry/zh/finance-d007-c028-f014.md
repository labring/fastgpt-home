# 动力煤收益率的表单与交互

## 这个品类的数据长什么样
动力煤的行情数据覆盖港口现货与期货两类来源。现货数据来自秦皇岛港、曹妃甸港等国内主要煤炭港口的每日报价，以及中国煤炭运销协会的行业统计数据；期货数据来自郑州商品交易所的动力煤上市合约。更新节奏上，期货合约行情在交易日实时刷新，港口现货报价每日收盘后更新一次，周度供需数据每周五发布。单条数据文档包含合约/港口名称、交割月份/产地、报价类型、报价金额、当日价格变动、成交量、持仓量、统计日期等字段。报价金额单位为元/吨，期货成交量单位为手，现货成交量单位为吨，当日价格变动以元/吨为计量基准。

## 这些特征在「表单与交互」这一环带来什么约束
动力煤的数据来源与更新节奏差异，要求表单区分数据源类型并配置不同的刷新规则。期货行情的实时性要求表单支持高频拉取，现货数据的每日更新属性则需要配置定时同步任务。字段包含期货与现货两类不同的计量单位，交互界面需明确标注每个字段的单位，避免混淆。交割月份为全年12个标准月份，表单的交割月份选择项需预设固定值，禁止开放自定义输入，减少用户输入错误。不同数据源的更新时间不同，交互界面需展示数据的更新时间戳，让使用者明确当前数据的时效性。成交量与持仓量数值较大，输入框需支持大整数输入并添加格式校验，确保输入内容合法。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `dataSourceType` | `["spot_port", "futures_zce"]` | 动力煤同时覆盖港口现货与郑州商品交易所期货两类数据源，需同时配置 |
| `refreshInterval` | `300 秒`（期货）、`86400 秒`（现货） | 期货行情实时性要求高，现货数据每日更新一次，匹配各自的更新节奏 |
| `fixedOptionList` | `["1月", "2月", "3月", "4月", "5月", "6月", "7月", "8月", "9月", "10月", "11月", "12月"]` | 动力煤期货合约交割月份为全年12个标准月份，需预设固定选项 |
| `inputValidationRule` | `{"min": 0, "unit": "元/吨"}`（报价字段）、`{"min": 0, "unit": "手/吨"}`（成交量字段） | 报价与成交量均为非负数值，需匹配对应单位校验输入合法性 |
| `updateTimeDisplay` | `true` | 需向使用者展示数据的更新时间，确保时效性透明 |
| `formFieldRequired` | `["报价金额", "统计日期"]` | 核心字段不可缺失，避免提交无效的表单内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调试预览时使用知识库变量引用动力煤报价字段时触发`quote type error`报错。原因：未匹配动力煤字段的数值类型配置，将元/吨的数值变量错误按文本类型引用。
- 表单提交后返回的行情数据条数与预期不符，仅返回少量单条数据。原因：未区分期货与现货数据源的返回条数配置，错误使用统一的参数值。
- 配置自定义数据源渠道后调用动力煤数据接口失败，返回`403 Forbidden`状态码。原因：未在配置中添加对应数据源的API密钥，或权限范围未覆盖动力煤行情数据接口。

## 怎么确认配好了
- 打开表单调试界面，选择不同的数据源类型，核对下拉选项是否仅包含预设的交割月份与数据源分类。
- 输入不符合字段格式的测试内容，触发校验逻辑，确认系统会拦截无效输入。
- 手动触发数据同步任务，核对返回的行情数据是否包含正确的字段与单位标注。
- 查看数据更新时间展示项，确认其更新频率符合对应数据源的官方发布节奏。
