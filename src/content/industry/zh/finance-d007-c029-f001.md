# 包装印刷收益率的HTTP 接口与外部系统

## 这个品类的数据长什么样
包装印刷行业的收益率与行情日报数据，主要来源于企业内部ERP生产系统、原材料供应商的公开行情接口，以及轻工制造行业协会的统计数据。数据更新节奏分为两类：每日凌晨更新前一日的全行业行情与企业整体收益率日报，实时工单的生产收益率则按生产批次推送。单份日报文档包含结构化元数据与明细生产记录，字段包括`report_date`、`paper_raw_price`、`ink_cost_per_sqm`、`daily_order_volume`、`qualified_count`、`total_produced_count`、`daily_profit_yield`，各字段单位分别为元/吨、元/平方米、千平方米、件、件、元，无百分比类数值。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
这些数据特征在HTTP接口与外部系统环节带来明确约束。多源异构的字段与不统一的单位，要求接口支持参数化的字段映射与单位转换，否则外部系统无法直接兼容不同来源的数据格式。每日更新的全量日报包含数千条明细记录，单份文档长度较长，接口需要支持分页拉取与批量查询参数，避免单次请求过载。实时工单数据的同步需求要求接口支持Webhook回调模式，替代低效的轮询拉取，同时需要配置请求验证机制，防止非法请求接入。固定的每日更新节奏，要求外部系统的同步调度匹配该时间节点，避免重复拉取或遗漏数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `external_api_timeout` | 300 秒 | 适配多源数据拉取的平均响应时间，避免单次拉取超时中断 |
| `field_unit_conversion_enabled` | 开启 | 适配包装印刷数据多单位的特征，统一输出格式至知识库可识别的标准单位 |
| `max_api_response_length` | 819200 字符 | 覆盖单份日报文档的平均长度，避免触发内容截断报错 |
| `sync_schedule` | 0 1 * * * | 匹配每日凌晨更新的数据源节奏，每日拉取一次全量数据 |
| `webhook_secret` | 按业务密钥生成 | 用于验证外部系统回调请求的合法性，防止恶意调用 |
| `batch_pull_size` | 100 条/次 | 适配单批次工单数据的合理拉取量，避免接口过载 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用配置的外部接口拉取数据时，返回`413 Request Entity Too Large`状态码或`maxLength`报错提示。原因：未配置`max_api_response_length`参数，或取值小于单份日报文档的实际长度，未对长内容进行合理处理。
- 现象：定时同步任务执行后返回`504 Gateway Timeout`状态码，同步流程中断。原因：未设置合理的`external_api_timeout`参数，拉取多源聚合数据时等待时间不足，导致请求超时。
- 现象：外部系统发起Webhook回调后，接口返回`403 Forbidden`状态码，回调请求被拦截。原因：未配置正确的`webhook_secret`，未对回调请求的合法性进行校验，导致权限验证失败。

## 怎么确认配好了
- 手动调用配置的外部接口，核对返回字段与预设的映射规则是否一致，确认单位转换已生效。
- 执行一次手动同步任务，查看同步日志中的响应状态码与返回内容长度，确认未触发截断或超时错误。
- 配置Webhook回调地址，由外部系统发起测试请求，确认接口返回正常状态码且未出现权限报错。
- 导入单份包装印刷日报文档至知识库，检查解析后的文本结构是否符合预期，无字段缺失或格式异常。
