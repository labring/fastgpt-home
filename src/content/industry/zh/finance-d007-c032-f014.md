# 化学原料收益率的表单与交互

## 这个品类的数据长什么样
化学原料的行情数据主要来自行业协会公开报价、大宗商品现货交易平台的每日成交记录，更新节奏为每个交易日17点前完成更新。数据以结构化表格形式存储，包含通用名、执行标准、产地、包装规格、当日加权均价、周度加权均价、月度加权均价、当日涨跌额、周度涨跌额等字段。均价与涨跌额的单位为元/吨，无百分比类统计项。

## 这些特征在「表单与交互」这一环带来什么约束
多源数据来源要求表单支持多渠道数据同步，需提前配置字段映射规则匹配外部数据与系统表单的字段名。固定的交易日更新节奏要求表单的定时拉取任务仅在工作日触发，避免无效更新。细分字段如执行标准、包装规格的存在，要求表单支持按品类、产地的筛选配置，同时需设置数值区间校验以适配化学原料的价格范围。数据更新的时效性要求表单需显示数据的最后更新时间，异常时需触发明确提示。

## 配置怎么定
以下配置适配FastGPT 4.9.7及以上版本：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DATA_SOURCE_TYPE` | `multi_platform_sync` | 化学原料报价来自多个交易平台，同步多源数据可保证覆盖范围 |
| `SCHEDULE_CRON_EXPR` | `0 17 * * 1-5` | 匹配交易日17点前的更新节奏，仅在周一至周五触发任务 |
| `FORM_FIELD_MAPPING` | `{"通用名":"material_name","加权均价":"avg_price","涨跌额":"price_change"}` | 匹配外部数据的标准字段与系统表单字段，适配化学原料的结构化数据结构 |
| `INPUT_RANGE_VALIDATION` | `{"min":0,"max":100000}` | 化学原料均价多处于0至100000元/吨区间，设置范围校验可拦截无效输入 |
| `DATA_UPDATE_TIMEOUT` | `600 秒` | 多源拉取需处理跨平台请求，预留10分钟超时时间可避免中途中断 |
| `ERROR_NOTICE_TRIGGER` | `on_failure` | 数据拉取或表单提交失败时触发通知，便于及时处理异常 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用API嵌入表单时，部分化学原料的规格字段为空。原因：未配置`FORM_FIELD_MAPPING`的规格字段映射，导致外部数据字段未正确绑定到表单组件。
- 现象：定时拉取数据时返回`408 Request Timeout`状态码。原因：未设置`DATA_UPDATE_TIMEOUT`或取值小于300秒，多源拉取未预留足够处理时间。
- 现象：表单在节假日仍触发数据更新。原因：`SCHEDULE_CRON_EXPR`未配置工作日限制，导致非交易日执行了拉取任务。

## 怎么确认配好了
- 手动触发一次数据拉取，检查表单字段是否包含化学原料的通用名、均价、涨跌额等预设项。
- 查看定时任务日志，确认仅在工作日17点左右执行拉取操作。
- 输入超出合理区间的价格数值，校验是否触发输入拦截提示。
- 模拟数据拉取失败场景，确认是否触发预设的错误通知。
