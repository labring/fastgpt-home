# 化纤收益率的HTTP 接口与外部系统

## 这个品类的数据长什么样
化纤行业的收益率与行情数据主要来自国内化纤行业公共报价平台、期货交割库成交公示、头部生产企业的出厂价公告。数据更新节奏分为两类：全量日报在每日收盘后固定时段更新，高频现货报价每30分钟更新一次。数据文档采用标准JSON格式，顶层包含请求标识、数据时间戳，嵌套字段包含品类规格、报价类型、数值、单位等信息。字段单位统一采用工业通用标准，出厂报价以元/吨为单位，成交量以吨为单位，部分细分品类的物性参数附带单独的单位字段。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
由于数据存在全量与高频两种更新节奏，接口需要支持按时间戳拉取增量数据，避免重复拉取全量数据集，降低外部系统的带宽占用。由于字段包含多层嵌套的规格、品类信息，外部系统的解析逻辑需要适配嵌套字段的提取规则，无法直接通过平展字段映射获取目标值。由于不同数据源的调用频次限制存在差异，高频数据接口的调用间隔需要匹配数据源的限流规则，否则会触发拦截。由于单位统一为工业通用标准，外部系统无需额外转换单位，但需要校验返回字段的单位一致性，避免数据计算错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `api_request_interval` | `30 秒` | 适配化纤高频数据的更新节奏，避免触发数据源限流 |
| `response_parse_mode` | `嵌套字段提取` | 适配化纤数据中包含规格、品类的嵌套JSON结构 |
| `request_timeout` | `10 秒` | 覆盖化纤数据源的平均响应时长，避免超时中断调用 |
| `filter_spec` | `涤纶长丝, 锦纶切片` | 限定拉取目标品类的具体规格，减少无效数据返回 |
| `retry_on_failure` | `3 次，间隔 2 秒` | 应对化纤数据源偶发的网络波动，提升调用稳定性 |
| `api_auth_type` | `API_KEY 鉴权` | 符合多数化纤行业数据源的鉴权规范，保障接口调用安全 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用HTTP接口后返回`messages is empty`报错，或接口返回空数据集。未在请求参数中指定目标化纤品类或规格，导致数据源未返回有效数据。
- 接口调用返回429 Too Many Requests状态码。请求间隔配置过短，超过了化纤数据源的调用频次限制。
- 解析返回数据时无法获取规格字段的具体值。未开启嵌套字段解析模式，无法识别JSON中的嵌套规格信息。

## 怎么确认配好了
- 发起单次测试调用，检查返回数据中是否包含目标化纤品类的核心报价字段。
- 查看调用日志，确认请求间隔符合数据源的限流要求。
- 触发模拟超时或网络异常场景，检查重试机制是否按配置执行。
- 对比数据源官方文档，确认返回字段的解析规则与配置一致。
