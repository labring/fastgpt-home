# 医疗器械收益率的分享与嵌入

## 这个品类的数据长什么样
医疗器械收益率与行情日报的数据来源包括国内医疗器械集中采购平台公示数据、医药行业公开行情接口、上市医疗器械主体的公开披露信息。更新节奏为每个交易日收盘后完成全量行情更新，集采相关动态随官方公示节点实时推送。文档结构为结构化日报，包含字段：医疗器械品类编码、通用名称、当日交易均价（单位为元/件）、当日最高价（单位为元/件）、当日最低价（单位为元/件）、当日成交量（单位为批次）、所属细分赛道标签。

## 这些特征在「分享与嵌入」这一环带来什么约束
医疗器械行情与收益率日报的结构化特征，会对分享嵌入环节带来多项约束。多字段带明确单位的结构化数据，要求嵌入前端组件必须匹配对应字段的单位展示，避免数值与单位错位。固定收盘更新与实时推送结合的更新节奏，要求嵌入的分享链接或iframe需配置对应频率的动态刷新，否则会展示过时数据。部分数据来自官方集采平台，嵌入场景需符合数据公示的合规范围，否则会触发权限校验拦截。细分赛道标签的多样性，要求嵌入组件支持自适应字段宽度，避免内容溢出影响阅读。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `allowedEmbedOrigins` | 仅添加业务所属的合规域名 | 限制未授权场景嵌入使用医疗器械数据，符合公开数据的合规使用要求 |
| `shareRefreshInterval` | `300 秒` | 匹配医疗器械行情每日收盘更新的节奏，平衡数据时效性与服务器资源消耗 |
| `customFieldSort` | `品类编码,通用名称,当日交易均价,当日最高价,当日最低价,当日成交量,所属细分赛道` | 贴合医疗器械采购与行情查看的常用阅读顺序，提升信息获取效率 |
| `streamOutput` | 开启 | 实现行情数据更新后实时推送至嵌入页面，降低页面加载延迟 |
| `maxEmbedFieldNum` | `7 个` | 匹配当前结构化日报的字段总量，避免页面冗余展示影响可读性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 嵌入页面出现`403 Forbidden`状态码，无法加载数据。原因是未配置`allowedEmbedOrigins`参数，或添加的域名与实际嵌入场景不符，触发了跨域权限校验拦截。
- 嵌入后的页面展示的医疗器械数据长时间未更新。原因是`shareRefreshInterval`配置为`0`或未开启自动刷新，导致页面加载后仅展示初始缓存数据。
- 嵌入页面的set-cookie请求失效，无法保留用户会话状态。原因是嵌入的iframe未配置正确的沙箱权限，或`allowedEmbedOrigins`未包含当前业务域名，浏览器限制了第三方cookie的写入。

## 怎么确认配好了
- 复制生成的iframe嵌入代码，粘贴至配置的允许域名对应的测试页面，检查页面能否正常加载医疗器械行情数据。
- 等待配置的刷新间隔时长，刷新测试页面，确认数据已更新至最新的收盘或集采公示数据。
- 打开浏览器开发者工具的网络面板，检查嵌入请求的响应头中是否包含正确的cookie权限配置，确认第三方cookie未被拦截。
- 调整自定义字段排序的配置项，刷新测试页面，确认字段展示顺序已按照配置生效。
