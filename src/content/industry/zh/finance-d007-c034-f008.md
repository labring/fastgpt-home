# 医疗器械收益率的工具调用与插件

## 这个品类的数据长什么样
医疗器械收益率相关行情数据的来源为各地医保医用耗材集中采购挂网平台、医药商业流通监测数据库、医疗机构院内采购公开数据。更新节奏为每日更新，覆盖前一日的采购报价变动。文档结构为结构化的CSV或JSON格式，按医用耗材大类分组存储。字段包含医用耗材分类代码、通用名称、注册证编号、供货企业名称、采购区域、供货单价、医疗机构采购单价、数据更新日期。单位方面，单价统一为元/件（或对应包装单位），分类代码为6位数字编码，注册证编号为字母加数字的组合格式。

## 这些特征在「工具调用与插件」这一环带来什么约束
首先，多源异构的数据来源要求工具调用插件适配不同地区的挂网平台页面结构与数据格式，避免因页面布局差异导致的解析失败。其次，每日更新的节奏要求定时触发的工具调用任务需匹配该频率，避免拉取过期或重复数据。第三，包含注册证编号、分类代码等合规性字段，要求工具调用时增加格式校验逻辑，过滤无效的非合规数据。第四，按大类分组的文档结构要求插件支持按分类筛选拉取数据，缩小目标范围以提升调用效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_fetch_interval` | `86400 秒` | 匹配医疗器械行情日报的每日更新节奏，避免重复拉取旧数据 |
| `plugin_multi_source_adapt` | `启用` | 适配不同地区挂网平台的格式差异，确保多源数据均可正常解析 |
| `plugin_incremental_sync` | `启用` | 仅拉取当日更新的变动数据，减少工具调用的资源消耗 |
| `plugin_field_validate_rules` | `注册证编号格式校验、分类代码匹配` | 符合药监部门的编码规范，过滤无效的非合规数据记录 |
| `plugin_api_timeout` | `300 秒` | 预留足够的请求时间，应对多源数据拉取的耗时需求 |
| `plugin_region_filter` | `按指定区域配置` | 缩小拉取范围，匹配用户关注的特定区域行情需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：docker部署4.14.8版本时，日志显示“plugin pull failed”，服务无法正常启动。原因：该版本默认的插件镜像仓库地址未同步更新，导致无法拉取官方维护的工具插件。
- 现象：调用PDF解析插件处理医疗器械采购公告PDF后，提取的采购单价字段为空。原因：未启用`plugin_pdf_enhanced_parse`配置，默认解析无法准确提取表格内的结构化数据。
- 现象：外部调用工作流API时，连续请求后返回429 Too Many Requests状态码。原因：未根据医疗器械数据拉取的资源消耗，配置合理的并发阈值，导致超出平台健康并发上限。

## 怎么确认配好了
- 查看工具调用的运行日志，确认每日定时任务触发后成功拉取到当日的医疗器械行情数据，无拉取失败的报错记录。
- 手动上传一份医疗器械采购公告PDF至解析插件，检查提取结果是否包含注册证编号、采购单价等必填字段。
- 查看平台的并发监控面板，确认外部调用的请求并发量未超过配置的阈值。
- 进入插件配置页面，确认`plugin_multi_source_adapt`、`plugin_incremental_sync`等开关已按要求启用。
