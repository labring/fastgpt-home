# 医美收益率的HTTP 接口与外部系统

## 这个品类的数据长什么样
医美收益率日报的数据来源为医美机构内部的项目运营系统、区域医美行业聚合平台的公开统计接口。更新节奏分为每日凌晨完成前一日全量数据更新，热门项目的实时营收数据每小时同步一次。单条数据文档为标准JSON格式，包含项目唯一标识、服务覆盖区域、项目类别、单位成本、当日总营收、当日总利润、日均客流量字段。单位成本、营收、利润的单位为元，客流量单位为人次，字段存在可选性，部分小众项目可能缺失部分扩展字段。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
医美数据的多源聚合与分时段更新特征，要求接口支持全量与增量两种同步模式，外部系统需配置对应触发规则。区域与项目类别的多维度过滤需求，要求接口提供对应的查询参数，用于缩小拉取数据范围。统一的元单位与浮点数值格式，要求外部系统配置统一的精度处理逻辑，避免数值误差。字段的可选性特征，要求外部系统兼容缺失字段的情况，避免解析失败。实时增量数据的短周期更新，要求定时任务的调度频率匹配接口的同步节奏，防止拉取到未完成更新的临时数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `SYNC_MODE` | 每日03:00执行全量同步，每小时执行增量同步 | 匹配医美数据的定时全量更新与实时增量更新节奏 |
| `FILTER_REGION` | `["华东","华北"]`，按实际对接区域调整 | 匹配医美项目的区域属性，缩小拉取数据范围 |
| `RESPONSE_PRECISION` | `2` | 匹配营收、利润的元单位精度需求，避免浮点误差 |
| `REQUEST_TIMEOUT` | `300 秒` | 适配医美数据接口的响应时长，避免因数据量较大导致超时 |
| `REQUIRED_FIELDS` | `["project_id","当日营收","当日利润"]` | 确保核心收益率计算字段不缺失 |
| `RETRY_TIMES` | `3` | 应对接口调用可能出现的临时网络波动，提升调用成功率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用接口返回`405 Method Not Allowed`状态码。原因：未将接口请求方式配置为POST，或误配置为GET请求。
- 现象：拉取的收益率数据存在字段为空或格式异常的情况。原因：未在配置中指定`REQUIRED_FIELDS`参数，导致拉取了缺失核心字段的非标准数据。
- 现象：接收流数据后无法正确拼接为完整的收益率条目。原因：未按照医美数据的JSON数组格式处理分段返回的流数据，直接拼接原始字节导致解析失败。

## 怎么确认配好了
- 手动触发一次全量同步任务，查看接口返回的原始数据，核对是否包含配置中指定的核心字段。
- 查看同步日志，确认请求方式与接口要求一致，无`405 Method Not Allowed`类错误日志。
- 对比本地系统存储的医美项目数据与接口返回的字段格式，确认精度与单位匹配。
- 定时查看增量同步的触发记录，确认每小时的增量拉取任务正常执行。
