# 医美收益率的分享与嵌入

## 这个品类的数据长什么样
医美收益率相关数据主要来源于医美机构内部运营台账、区域医美行业监测数据库及合作供应链报价更新。数据更新节奏以月度为核心周期，热门项目的临时调价会同步更新至临时数据集，但整体报表每月更新一次。单条数据文档包含项目ID、项目名称、服务成本、结算售价、单项目利润额、月度服务量、区域标签7个字段。服务成本、结算售价、单项目利润额以人民币元为单位，月度服务量以人次为单位，无百分比类统计字段。

## 这些特征在「分享与嵌入」这一环带来什么约束
医美收益率数据的特征直接约束分享与嵌入的配置逻辑。数据包含内部服务成本等敏感字段，嵌入至外部页面时需配置字段过滤规则，避免泄露内部运营信息。数据更新周期为月度，分享链接的缓存周期可匹配月度节奏，减少重复请求的资源消耗。数据字段包含多维度的分类标签，分享与嵌入时需支持公共参数过滤，适配不同合作方的区域或项目类型需求。批量数据的单次加载量较大，需限制分页参数，防止嵌入页面出现加载卡顿或超时问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `shareLinkEnable` | `true` | 开启医美收益率数据的分享与嵌入能力 |
| `shareLinkCacheTTL` | `2592000 秒` | 匹配医美数据月度更新周期，降低重复计算频率 |
| `iframeEmbedExcludeFields` | `["服务成本"]` | 隐藏内部敏感成本数据，仅对外展示公开业务字段 |
| `shareLinkAnonymousVars` | `["项目类型", "区域标签"]` | 免登录场景下传递公共过滤参数，适配不同合作方的筛选需求 |
| `embedMaxItemsPerPage` | `20 条` | 控制单页展示的项目数量，平衡展示完整性与加载性能 |
| `embedDisableExport` | `true` | 关闭iframe内的Markdown导出功能，匹配机构对外展示场景 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：免登录分享链接中配置的自定义区域参数未生效，返回的数据集包含非目标区域的项目数据。原因：免登录场景下无法传递用户自定义变量，需将过滤参数配置为`shareLinkAnonymousVars`，自定义变量无法在该场景生效。
- 现象：嵌入的iframe组件中显示Markdown导出按钮，与机构对外展示的需求不符。原因：未将`embedDisableExport`参数配置为`true`，默认启用了导出功能。
- 现象：批量加载全机构项目数据时，嵌入页面长时间无响应并返回`413 Request Entity Too Large`错误。原因：未限制`embedMaxItemsPerPage`的取值，单次请求的数据量超过接口承载上限。

## 怎么确认配好了
- 打开分享链接的后台预览界面，检查展示的字段是否排除了`服务成本`等敏感项，仅保留公开业务字段。
- 复制免登录分享链接，在未登录的浏览器中打开，验证公共过滤参数是否生效，返回的数据集符合预设的筛选条件。
- 嵌入iframe到本地测试页面，检查是否存在Markdown导出按钮，确认导出功能已被关闭。
- 查看接口请求日志，确认缓存时长匹配`shareLinkCacheTTL`的配置，未出现频繁的全量数据重新计算。
