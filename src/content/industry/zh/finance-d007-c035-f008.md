# 医美收益率的工具调用与插件

## 这个品类的数据长什么样
医美收益率相关数据的来源包括医美行业监测平台的公开报价数据集、合规医美机构的季度运营公示信息、医美耗材的进销差价统计台账。更新节奏为月度全品类更新，热门轻医美项目的单周报价数据每7天同步一次。数据采用结构化表格格式，字段包含项目名称、服务类别、成本价、零售价、服务覆盖城市、统计周期。成本价与零售价的单位为人民币元，服务时长单位为分钟，未设置百分比类统计字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
医美品类的数据分散来源与差异化更新节奏，要求插件需配置多数据源优先级回退逻辑，适配月度与周度的双更新周期。由于数据字段仅包含基础进销价格与城市信息，插件需内置自定义计算规则生成所需的差价指标，需预设字段映射规则避免空值返回。同时，跨城市的定价差异要求插件支持按城市维度过滤请求参数，需配置城市参数的合法性校验机制，确保调用时仅传递已收录的城市代码。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `data_source_priority` | `["公开监测平台", "机构公示数据", "耗材进销台账"]` | 适配医美数据多源分布，优先使用更新更及时的公开监测数据源 |
| `pull_cron` | `0 0 * * 1/1`（周度）、`0 0 1 * *`（月度） | 匹配热门项目周度更新与全品类月度更新的节奏 |
| `field_mapping` | `{"cost": "成本价", "price": "零售价", "city": "服务覆盖城市"}` | 匹配医美数据固有字段命名，避免字段不匹配导致的空值返回 |
| `param_whitelist` | `["北京", "上海", "广州", "深圳", "成都"]` | 限定仅调用已收录城市的有效数据，过滤无效请求参数 |
| `custom_calculate_script` | `price - cost` | 基于现有字段生成差价指标，适配无原生收益率字段的数据结构 |
| `timeout_seconds` | `600秒` | 适配多源数据拉取与计算的耗时需求，避免调用超时中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：插件调用时返回参数为空，或界面提示“参数未找到”。原因：未配置变量回退逻辑，未指定当工作流传入变量为空时，自动使用插件内置的默认参数值。
- 现象：流式回答中未包含模型思考过程内容，仅返回最终计算结果。原因：未开启流式输出的思考内容透传配置，未配置将模型think字段直接写入输出流的规则。
- 现象：批量调用工具时仅返回少量结果，或出现调用失败报错。原因：未正确配置批量执行的分片阈值，未匹配医美数据单批次可处理的最大条目数。

## 怎么确认配好了
- 手动触发一次插件调用，查看返回的字段是否包含预设的差价指标，核对字段映射规则是否生效。
- 检查工作流的定时任务日志，确认拉取间隔与配置的`pull_cron`表达式一致，数据更新周期符合预期。
- 提交包含非法城市参数的测试请求，确认插件会拦截无效请求，返回参数校验失败的提示。
- 开启流式输出测试，确认模型思考过程内容会被直接透传到回答流中，无内容丢失。
