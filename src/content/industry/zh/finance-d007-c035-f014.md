# 医美收益率的表单与交互

## 这个品类的数据长什么样
医美收益率相关数据来源包括医美机构内部业务系统、合作的合规行业数据服务机构。更新节奏为每日固定时点更新前一日的全量核算数据。文档结构为按医美服务项目分类的结构化数据集，包含项目唯一标识、项目大类、当日营收金额、当日运营成本金额、核算日期字段。字段单位中，金额类为人民币元，核算日期采用标准日期格式。数据会按门诊门店、项目类型进行分层聚合，不同层级的聚合维度对应不同的明细字段组合。

## 这些特征在「表单与交互」这一环带来什么约束
数据按门店、项目类型分层聚合，要求表单支持多级联动筛选，先选择门店维度，再选择项目大类，最终定位到具体核算数据。每日固定更新前一日数据，要求表单默认锁定核算日期为前一日，禁止选择未来日期或超出7日的历史数据，避免拉取未生成的数据集。金额字段为人民币元格式，要求表单的数值输入组件限制为非负数值，支持两位小数格式。数据包含内部业务系统与外部行业数据两种来源，要求表单提供数据源切换选项，并在切换时同步更新可筛选的维度范围。此外，部分核算数据需要配套上传凭证文件，要求表单支持多文件上传并校验文件格式与大小。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `FORM_LINKAGE_DEPTH` | `3 级` | 医美收益率数据按门店-项目大类-具体项目的三层维度聚合，匹配层级筛选的交互逻辑 |
| `DEFAULT_DATA_SOURCE` | `内部业务系统` | 内部业务系统数据准确率更高，契合机构日常核算的核心需求 |
| `DATE_PICKER_DEFAULT` | `前一日日期` | 数据每日固定更新前一日的全量核算数据，默认匹配日报播报的使用场景 |
| `UPLOAD_ALLOWED_EXTENSIONS` | `jpg, png, pdf` | 医美核算凭证多为截图、扫描件或正式票据，覆盖主流凭证格式 |
| `UPLOAD_MAX_SIZE` | `10 MB` | 单张高清凭证或PDF票据的常规大小范围，避免超出存储与传输限制 |
| `NUMERIC_INPUT_RANGE` | `≥0 且 ≤1000000` | 单项目当日营收金额的合理区间，拦截异常数值输入 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：表单筛选时无法定位到指定门店或项目的数据集，仅能查看全量数据。原因：未配置数据源的维度筛选权限，或未开启表单的层级联动逻辑，导致无法按门店、项目大类逐步缩小数据范围。
- 现象：上传医美核算凭证时被系统拦截，提示格式不支持。原因：未配置`UPLOAD_ALLOWED_EXTENSIONS`参数，或取值未覆盖jpg、png、pdf等凭证常用格式，导致用户上传的合规文件被拒绝。
- 现象：表单提交后返回空数据或非当日的历史数据。原因：默认选择了未来日期或超过7日的历史数据，而对应日期的数据集尚未生成或未同步完成，无法拉取有效核算数据。

## 怎么确认配好了
- 打开表单配置页面，检查`FORM_LINKAGE_DEPTH`参数是否设置为3级，且层级顺序为门店-项目大类-具体项目，可通过预览表单验证多级筛选逻辑是否生效。
- 进入文件上传配置项，确认`UPLOAD_ALLOWED_EXTENSIONS`包含业务所需的凭证格式，可尝试上传对应格式的测试文件，验证是否能正常提交。
- 查看日期选择器的默认值设置，确认默认锁定为前一日日期，可通过选择未来日期提交测试，验证系统是否拦截非法日期输入。
- 切换数据源选项，确认不同数据源下的可筛选维度范围是否同步更新，验证数据源切换逻辑是否正常生效。
