# 厨卫电器收益率的分享与嵌入

## 这个品类的数据长什么样
厨卫电器的收益率相关数据主要来自国家能效标识数据库、主流电商平台实时售价接口与品牌官方产品参数库。行情类数据每小时更新一次，能耗测算类数据每自然日更新一次。数据以结构化文档形式存储，包含产品SKU编码、产品名称、额定功率、日均标准使用时长、所在地区基准电价、月度能耗成本、月度行业平均能耗成本、当日售价、近7日售价区间下限、近7日售价区间上限等字段，各字段对应单位分别为无单位、无单位、瓦、小时、元/千瓦时、元、元、元、元、元。

## 这些特征在「分享与嵌入」这一环带来什么约束
厨卫电器的数据特征对分享与嵌入环节提出多重约束。首先，行情类数据每小时更新，要求嵌入组件支持高频拉取，避免静态缓存导致的信息滞后。其次，能耗测算数据与地区基准电价强绑定，需支持传入地区编码参数适配不同区域的测算结果。第三，数据需通过SKU编码定位具体产品，分享链接需携带该参数才能返回准确内容。第四，多字段包含不同单位，前端展示需统一转换规则，不能硬编码单位格式。最后，数据涉及产品售价与能耗成本，需限制跨域访问来源，保障数据安全。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `embed_refresh_interval` | `3600 秒` | 匹配厨卫电器行情数据每小时更新的频率，避免展示过时的售价与能耗测算结果 |
| `allowed_share_params` | `sku,region_code` | 厨卫电器数据需通过SKU定位具体产品，同时需传入地区编码适配基准电价参数 |
| `cache_max_age` | `86400 秒` | 适配能耗测算数据的每日更新节奏，减少重复计算开销 |
| `auth_type` | `token_based` | 为分享链接配置身份鉴权，防止未授权访问对应产品的专属数据 |
| `embed_response_format` | `json_with_field_labels` | 标准化返回结构化字段，便于前端按字段匹配对应单位进行展示 |
| `cross_domain_allowlist` | `*.kitchen-appliance-platform.com` | 限制嵌入来源为厨卫电器相关业务域名，保障数据访问安全 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：嵌入生成的分享链接未配置身份鉴权，任意访问者可查看所有厨卫电器的收益率数据。原因：未配置`auth_type`参数，或使用开源版本时未部署自定义鉴权扩展。
- 现象：前端嵌入的对话窗口无法返回厨卫电器的收益率数据。原因：未在`allowed_share_params`中配置SKU与地区编码参数，或未开启跨域访问权限导致数据请求被拦截。
- 现象：小程序嵌入FastGPT对话页面后，页面顶部标题被强制修改且无法通过配置恢复。原因：嵌入代码未指定自定义标题参数，或小程序容器默认拦截了页面标题的自定义配置。

## 怎么确认配好了
- 访问生成的分享链接，传入对应SKU与地区编码参数，检查返回的数据字段是否包含预期的产品名称、当日售价、能耗测算结果等内容。
- 调整`embed_refresh_interval`参数值，等待对应时长后刷新嵌入页面，确认数据是否按配置完成更新。
- 尝试使用未加入`cross_domain_allowlist`的域名嵌入，检查是否触发访问限制提示，确认跨域配置生效。
- 查看嵌入页面的浏览器控制台日志，确认未出现参数缺失或格式错误的提示信息。
