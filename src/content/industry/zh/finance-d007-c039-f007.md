# 厨卫电器收益率的工作流编排

## 这个品类的数据长什么样
厨卫电器收益率相关数据来源于品牌内部ERP系统的供货台账、电商平台公开的成交记录、第三方家电行业监测数据库。数据更新节奏存在差异：单品供货成本每季度随供应链调整更新，终端成交单价每日随销售数据更新，行业品类均价数据每周更新。单份文档对应一款厨卫电器单品，包含SKU编码、型号全称、供货单价、终端成交单价、渠道服务费占比、单台运营分摊成本，字段单位分别为无单位、字符串、元、元、小数、元/台。

## 这些特征在「工作流编排」这一环带来什么约束
多源数据的更新频率差异，要求工作流设置时间戳校验节点，过滤过期的供货成本数据，避免收益率计算偏差。多字段的单位与格式差异，要求前置配置标准化转换节点，统一各数据源的数值格式。SKU编码作为唯一标识，要求检索节点绑定精准匹配规则，避免跨型号文档的误检索。每日更新的成交数据规模较大，要求配置增量同步节点，减少全量拉取的资源占用。多维度的运营成本拆分，要求配置参数拆分节点，将总运营成本按渠道分摊到单品维度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前6-10 条` | 厨卫电器单品收益率文档平均单份长度约1200-1800字符，该区间可覆盖完整单品数据且不超出上下文限制 |
| `相似度阈值` | `0.75-0.85` | 厨卫电器SKU编码与型号名称存在相似性，该区间可避免误匹配跨型号文档 |
| `maxContext` | `9000-11000 字符` | 单组厨卫电器收益率数据的总上下文长度在该区间内，适配多数大模型的上下文窗口 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 多源供应链与销售数据合并解析时，耗时较长，600秒可覆盖全量数据处理流程 |
| `knowledgeSearch`绑定规则 | `按动态传入的SKU编码精准匹配` | 适配动态传值的检索需求，确保检索对应单品的文档 |
| `导出文件格式` | `DOCX` | 适配行业内常用的办公文档查看与分享场景 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用`knowledgeSearch`节点时，动态传入SKU编码后返回0条检索结果。原因：未配置SKU编码与知识库文档元数据的精准匹配规则，导致检索参数与文档标识不对应。
- 现象：工作流执行完成后未生成可下载的文档链接。原因：未在工作流末尾添加文档导出节点，或未配置导出文件的访问权限。
- 现象：工作流执行超时，返回`504`状态码。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时间不足以处理多源供应链与销售数据的合并解析。

## 怎么确认配好了
- 手动传入已知SKU编码到`knowledgeSearch`节点，核对返回的文档是否包含对应单品的完整数据。
- 触发工作流执行，查看节点日志，确认所有数据同步与解析节点的耗时符合预设要求。
- 生成测试文档，核对导出格式与字段内容是否符合预设的业务规则。
- 检查工作流的版本迁移配置，确认从4.8版本迁移的节点参数与最新版本的兼容规则一致。
