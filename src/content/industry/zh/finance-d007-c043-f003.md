# 商业地产收益率的分享与嵌入

## 这个品类的数据长什么样
商业地产收益率数据主要来源于自持物业运营管理系统、第三方不动产数据服务机构。数据更新节奏为每日更新前一自然日的运营统计结果。数据文档为结构化表格格式，每行对应单个商业地产项目，字段包含项目唯一标识、项目名称、所属商圈、业态类型、可出租总面积、当日平均租金、当日出租率比例值、当日实现收益率系数。其中可出租总面积单位为平方米，平均租金单位为元/平方米·天，其余字段无额外标准化单位。

## 这些特征在「分享与嵌入」这一环带来什么约束
商业地产数据的多维度字段、每日更新节奏与结构化格式，会对分享嵌入环节带来三项核心约束。第一，数据包含商圈、业态等细分维度，嵌入组件需要支持通过项目ID、商圈名称等参数定向筛选展示内容，避免展示无关项目数据。第二，每日更新的节奏要求嵌入后的内容自动同步最新数据源，需配置实时拉取逻辑，禁止使用静态缓存的分享链接。第三，不同项目的可选展示字段存在差异，嵌入配置需要支持自定义显示字段列表，防止出现字段缺失或展示错位的情况。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `share_auto_refresh` | `3600 秒` | 商业地产数据每日更新，每小时刷新可保证内容时效性，同时避免频繁请求加重数据源负载 |
| `share_display_fields` | `["project_name", "avg_rent", "occupancy_rate", "yield_coefficient"]` | 商业地产收益率播报的核心展示字段为项目名称、平均租金、出租率与收益率系数，符合目标查看需求 |
| `embed_component_height` | `800–1200 像素` | 商业地产收益率数据包含多列维度，该高度可完整展示常规数量的项目数据，避免内容溢出 |
| `share_filter_params` | `["project_id", "business_district"]` | 商业地产数据的核心筛选维度为项目ID与所属商圈，可精准定向展示目标内容 |
| `share_cache_timeout` | `1800 秒` | 平衡数据时效性与请求负载，避免缓存过期过快导致重复请求 |
| `share_auth_strategy` | `public` | 商业地产收益率日报通常用于内部团队或合作方查看，公开鉴权可简化嵌入流程，如需权限控制可切换为`token` |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 嵌入页面返回403状态码。未正确配置`share_auth_strategy`参数，使用了未授权的鉴权方式导致访问被拦截。
- 嵌入页面展示字段缺失或错位。未在`share_display_fields`中配置目标展示字段，或传入的筛选参数与数据源字段名称不匹配。
- 嵌入内容长时间未更新。将`share_auto_refresh`配置为`0 秒`或未开启自动刷新逻辑，导致使用静态缓存的旧数据。

## 怎么确认配好了
- 访问生成的嵌入链接，确认页面展示的字段与配置的`share_display_fields`一致。
- 修改`share_filter_params`中的项目ID或商圈名称，确认嵌入页面展示的内容同步切换为对应筛选条件下的数据。
- 检查嵌入组件的高度与宽度是否适配所在页面的容器，无内容溢出或显示不全的情况。
- 等待超过配置的`share_cache_timeout`时长后刷新页面，确认页面数据已更新为最新的运营统计结果。
