# 商业地产收益率的工具调用与插件

## 这个品类的数据长什么样
商业地产收益率相关数据主要来源于商业物业运营台账、商圈租赁交易备案系统、第三方商业地产数据聚合平台。数据更新节奏为月度更新租金与运营成本明细，季度更新整体净运营收益率核算结果。单份数据文档为结构化表格格式，每行对应单个独立商业地产项目，包含项目唯一标识、项目坐落位置、可出租面积、实际出租率、月均租金收入、年度运营成本、核算周期内净运营收益、净运营收益率等字段。可出租面积单位为平方米，月均租金收入单位为元/平方米/月，年度运营成本与净运营收益单位为万元，净运营收益率为比例值。

## 这些特征在「工具调用与插件」这一环带来什么约束
商业地产数据的多源分散特征要求工具调用需配置多API聚合逻辑，避免单次调用仅获取单一维度数据。月度/季度的更新节奏要求工具触发周期需匹配数据更新频率，避免频繁调用导致接口限流或无效请求。字段包含多类单位与联动计算逻辑，要求插件需内置单位校验与字段联动规则，防止因单位不统一或字段缺失导致计算错误。项目唯一标识的强绑定要求工具调用参数必须携带项目ID，避免不同项目的数据混淆。同时，商业地产数据的核算逻辑依赖多字段联动，工具调用的参数顺序与完整性需严格匹配数据文档的结构要求，否则将导致收益率计算结果失真。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `timeout` | `300 秒` | 商业地产数据接口通常需聚合多源信息，响应时间较长 |
| `retryCount` | `2 次` | 部分第三方商业地产数据接口存在临时波动，少量重试可提升调用成功率 |
| `paramSchema` | `配置项目ID、核算周期为必填校验项` | 商业地产项目数据需绑定唯一标识与核算周期，避免数据混淆 |
| `apiAuthType` | `API_KEY 认证` | 商业地产数据接口多采用密钥鉴权方式保障数据安全 |
| `mergeMode` | `按项目ID去重后合并` | 多源数据聚合时可能存在重复的项目条目，需统一去重规则 |
| `scheduleCron` | `0 0 2 1 */3 *` | 商业地产收益率数据按季度更新，该表达式匹配每季度第一个工作日凌晨2点触发 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用`apiCollection`接口返回`Invalid URL, code: 500`报错，原因为未配置合法的商业地产数据接口域名，或接口地址存在拼写错误导致解析失败。
- 现象为返回`400 <400> InternalError.Algo.InvalidParameter: Multimodal file size is`报错，原因为上传的商业地产运营数据文件尺寸超出工具节点支持的最大限制，或文件包含未解析的多媒体内容。
- 现象为工作流中工具调用模块的输出无法取消，导致非必要内容被返回，原因为未在工具节点设置中关闭输出透传选项，或未配置输出字段过滤规则。

## 怎么确认配好了
- 手动触发一次工具调用，核对返回的字段是否包含商业地产项目的必要标识与收益率数据，字段单位是否符合预设规则。
- 检查定时触发配置，确认触发周期与商业地产数据的更新节奏匹配，可通过查看工作流日志验证触发是否按时执行。
- 上传测试用的商业地产数据文件，核对参数校验规则是否拦截非法输入，比如非数值类型的租金数据。
- 查看工具节点的输出配置，确认仅保留需要返回的字段，无冗余内容被透传。
