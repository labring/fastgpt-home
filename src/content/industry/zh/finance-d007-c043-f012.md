# 商业地产收益率的模型接入与配置

## 这个品类的数据长什么样
商业地产收益率相关数据主要来源于不动产运营管理系统、产权交易备案平台、区域商业业态监测数据库。核心数据更新节奏分为两类：租金类数据按月更新，估值类数据按季度更新。单条数据以结构化JSON或CSV格式存储，包含项目唯一标识、业态分类、出租率、单位租金、资本化率、统计周期字段。字段单位分别为：项目标识为字符串，业态分类为枚举字符串，出租率为无量纲比例值，单位租金为元/平方米·月，资本化率为无量纲比例值，统计周期为日期字符串。

## 这些特征在「模型接入与配置」这一环带来什么约束
业态分类的枚举属性要求配置校验规则，避免非法输入干扰模型计算。双周期的更新节奏需要适配双调度任务，确保不同维度数据的时效性同步。单位租金与资本化率的特定单位要求，需在向量入库与提示词配置中统一格式，避免模型混淆数值维度。批量查询场景占比偏高，需调整向量召回的并发与批次参数，避免接口限流或超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `embedding_batch_size` | `16–32` | 商业地产单条数据长度适中，该批次范围可平衡向量入库效率与接口负载 |
| `sync_schedule` | `0 0 2 * * && 0 0 4 * *` | 匹配月度租金数据（每月2日同步）与季度估值数据（每季度首月4日同步）的更新节奏 |
| `vector_recall_top_k` | `前8–12条` | 商业地产项目维度较多，适量召回可覆盖相关业态与租金区间的历史数据 |
| `prompt_template_custom` | `请基于提供的商业地产项目结构化数据，计算目标项目的收益率，输出结果需保留原始无量纲比例值，不得添加额外单位转换或修饰内容` | 明确字段单位要求，避免模型混淆不同维度的数值 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 批量CSV导入时单批次数据解析耗时较长，该时长可避免超时中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用知识库接口返回`400 Bad Request`，提示“字段格式不匹配”。原因：未配置业态分类的枚举校验规则，输入了未在预设枚举列表中的分类值。
- 现象：应用调用接口直接返回原始计算结果，未作为上下文传入下游模型。原因：未配置`tool_call_mode`参数为`context_only`，导致工具调用结果直接输出，未存入知识库上下文。
- 现象：定时同步任务多次触发失败，日志显示`ETIMEDOUT`网络超时错误。原因：同步任务调度频率与数据更新周期不匹配，重复请求源接口触发限流。

## 怎么确认配好了
- 上传单条结构化商业地产数据文件，查看管理界面`UPLOAD_FILE_STATUS`字段显示为“已解析”。
- 手动触发一次定时同步任务，核对同步日志中包含月度租金数据与季度估值数据的同步记录。
- 发起知识库召回测试，确认返回的结果条数与`vector_recall_top_k`的配置值一致。
- 输入包含自定义业态分类的查询，检查模型输出未出现格式错误的提示。
