# 国有大行收益率的HTTP 接口与外部系统

## 这个品类的数据长什么样
国有大行的收益率数据来源于官方自营金融产品的公开披露渠道，包括官方门户网站的产品专区、官方合规API接口。数据更新节奏为每日固定时点完成前一日数据的发布，单次更新覆盖全量在售及存续的自营存款、理财子产品。数据文档为结构化格式，包含产品唯一标识、产品名称、收益率类型、收益率数值字段、起投金额、产品期限、更新时间戳等内容，其中收益率字段附带单位标识，期限字段以天或年为单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
国有大行的收益率数据需通过官方合规接口获取，因此外部系统对接需遵循官方的接口鉴权规则。每日仅一次的更新节奏要求HTTP接口的轮询策略需匹配更新时点，避免频繁调用触发限流。结构化的字段命名存在品牌差异，不同国有大行的字段名可能不完全统一，需针对对接主体调整字段映射规则。产品数量较多的特性要求接口需支持分页获取参数，避免单次返回数据量过大导致超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `external_api_timeout` | `30 秒` | 国有大行官方接口响应通常在10-20秒区间，预留合理缓冲时间 |
| `external_api_retry_times` | `3 次` | 应对金融接口偶发的网络波动或临时限流场景 |
| `field_mapping_rule` | 按对接大行的官方文档配置专属字段映射 | 国有大行接口字段命名无统一标准，需严格匹配官方字段名 |
| `polling_interval` | `3600 秒` | 匹配国有大行每日一次的更新节奏，避免触发官方接口限流 |
| `pagination_enabled` | `开启` | 国有大行在售产品数量较多，需分页获取完整数据 |
| `response_parse_mode` | `strict_json` | 官方接口返回标准化JSON格式数据，严格解析可减少格式错误 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用接口返回`404 Not Found`状态码，原因是误填写通用金融数据接口地址，未使用国有大行官方披露的专属收益率数据接口。
- 接口返回的收益率字段为空，原因是未配置`field_mapping_rule`，未匹配对接大行的专属字段命名规则。
- 频繁触发`429 Too Many Requests`限流报错，原因是轮询间隔设置过短，超过官方接口的限流阈值。

## 怎么确认配好了
- 调用配置的外部接口地址，确认返回的HTTP状态码为`200 OK`，且包含预设的字段集合。
- 查看接口调用日志，确认每次调用的间隔符合配置的轮询参数。
- 检查字段映射后的输出，确认所有配置的字段均能被正确解析。
- 对比单次同步结果与官方公开的文档格式，确认字段结构符合预期。
