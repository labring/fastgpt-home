# 国有大行收益率的部署与升级

## 这个品类的数据长什么样
国有大行收益率与行情日报的数据来源为国有大行官方官网、央行公开披露的金融数据平台，更新节奏为每日固定时段发布前一工作日的完整数据。文档格式多为内嵌结构化表格的官方网页、PDF格式报告或Excel附件，包含产品类别、收益率数值、起投门槛、产品期限等核心字段，单位为百分比。不同国有大行的字段命名和排版存在细微差异，但整体结构保持统一。

## 这些特征在「部署与升级」这一环带来什么约束
结构化的数据格式要求部署时需启用专用的结构化文档解析模块，以保障字段提取精度。每日固定更新的需求要求部署定时拉取任务，需配置与数据发布节奏匹配的调度参数。国有大行数据的合规性要求，需限定仅允许访问官方域名，部署时需配置域名白名单。数据字段的细微差异要求升级时需验证字段提取规则的兼容性，避免因版本更新导致解析失效。日报数据的时效性要求升级后需确保知识库同步更新链路未被阻断，否则会影响后续播报的准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_STRUCTURED_ENABLE` | `true` | 国有大行收益率数据为结构化表格格式，启用该参数可提升字段提取精度 |
| `FETCH_DOMAIN_WHITELIST` | `["icbc.com.cn", "abc.com.cn", "boc.cn", "ccb.com.cn", "bankcomm.com", "psbc.com"]` | 限定仅允许访问国有大行官方域名，符合数据合规要求，避免抓取非授权来源数据 |
| `SCHEDULER_CRON_EXPR` | `0 8 * * *` | 匹配国有大行每日早间8点前发布前一工作日数据的节奏，确保每日定时拉取最新数据 |
| `PARSE_FIELD_MAPPING` | `{"产品名称":"product_name","年化收益率":"yield_rate","起投金额":"min_invest"}` | 适配国有大行文档的常见字段命名，减少后续字段映射的手动调整工作量 |
| `FETCH_TIMEOUT_SECONDS` | `600 秒` | 国有大行官网页面加载可能存在合规校验延迟，设置较长超时时间避免拉取任务失败 |
| `UPLOAD_FILE_MAX_SIZE` | `20 MB` | 国有大行发布的日报附件多为小型结构化文档，该取值可覆盖常规附件大小并避免资源浪费 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 执行`docker run --gpus all -itd -p 7231:7231`部署结构化解析插件时出现启动失败报错。原因是未在部署主机上配置与镜像版本匹配的GPU驱动，或未正确授予容器GPU设备访问权限。
- 升级至4.9.0版本后，使用国有大行官方域名创建知识库时，后台日志提示`cannot fetch internal url`。原因是新增的域名白名单校验机制未配置对应官方域名，导致合法拉取请求被拦截。
- 升级FastGPT版本后无法找到文件加工插件。原因是插件市场未完成同步更新，或部署时未启用插件自动更新开关，导致结构化解析插件未正常加载。

## 怎么确认配好了
- 手动触发一次数据拉取任务，查看解析结果中是否正确提取出产品名称、收益率等核心字段。
- 检查定时任务日志，确认每日指定时段是否成功发起拉取请求且无超时或拦截报错。
- 访问配置的白名单域名，验证插件是否能正常抓取页面内容并完成结构化解析。
- 查看插件管理界面，确认结构化解析插件处于启用且运行正常的状态。
