# 塑料橡胶收益率的分享与嵌入

## 这个品类的数据长什么样
塑料橡胶的行情数据来自国内大宗商品期货交易所与现货贸易平台，更新节奏为交易日每15分钟推送一次实时交易报价，当日收盘后1小时内发布当日结算价与全量行情快照。单份数据文档包含品种代码、当日开盘价、最高价、最低价、收盘价、结算价、当日成交量、持仓量、昨日结算价等核心字段，期货报价单位为元/吨，成交量与持仓量单位为交易手数；现货数据额外包含区域贸易均价、当日交易量等字段，部分区域报价采用非标准单位标识。

## 这些特征在「分享与嵌入」这一环带来什么约束
塑料橡胶的多频次实时行情与多字段结构，要求嵌入组件支持按指定时间间隔刷新内容，避免展示过期的行情数据。多维度的字段要求嵌入配置可精准筛选展示字段，避免冗余信息挤占有限的页面展示空间。不同数据源的单位差异要求嵌入时需统一转换或明确标注单位，防止混淆不同品类的报价规则。部分现货报价的非标准化字段命名，要求嵌入组件支持自定义字段映射，适配不同业务场景的展示需求。高频实时数据的推送特性，要求嵌入的iframe或组件具备低延迟加载能力，避免因请求过多导致页面卡顿。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `refreshInterval` | 300–900 秒 | 匹配塑料橡胶行情15分钟的更新间隔，平衡数据时效性与服务器负载 |
| `displayFields` | 收盘价、结算价、成交量、持仓量 | 覆盖核心决策所需的行情指标，避免冗余字段干扰展示 |
| `customFieldMapping` | 按`{"现货报价":"tradePrice"}`格式映射 | 适配塑料橡胶现货报价的非标准化字段命名，统一数据展示格式 |
| `crossDomainWhiteList` | 企业官网域名、内部交易系统域名 | 限制嵌入权限，防止未授权站点调用行情数据 |
| `unitConversionEnabled` | 开启 | 统一不同数据源的价格单位为元/吨，避免展示混乱 |
| `cacheExpireTime` | 600 秒 | 匹配收盘后结算数据的更新周期，缓存非实时场景下的行情快照 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 嵌入后浏览器控制台提示set-cookie失效，或登录状态无法持久化。原因是未将嵌入站点域名加入`crossDomainWhiteList`配置，或未开启`allowCredentials`参数，导致浏览器拦截跨域cookie。
- 嵌入页面展示的行情字段缺失或显示异常。原因是`displayFields`配置中未包含目标字段，或`customFieldMapping`的字段映射关系错误。
- 嵌入组件加载后长时间无响应或请求频繁报错。原因是`refreshInterval`设置过短，且未限制接口调用频次，超出平台限流阈值。

## 怎么确认配好了
- 打开嵌入组件的预览界面，核对展示字段与配置的`displayFields`列表一致，单位统一为元/吨。
- 在嵌入站点的浏览器开发者工具中查看网络请求，确认跨域接口返回状态码为200，无cookie拦截提示。
- 等待15分钟后刷新嵌入页面，确认展示数据更新至最新的行情快照。
- 针对v4.8.10及以上版本，确认免登录嵌入的`anonymousAccessEnabled`配置已开启，无需重复登录即可加载数据。
