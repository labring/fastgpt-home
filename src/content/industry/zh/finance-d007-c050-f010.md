# 塑料橡胶收益率的数据库与运维

## 这个品类的数据长什么样
塑料橡胶相关行情与收益率数据主要来自国内大宗商品期货交易所、行业现货报价平台。更新节奏分为两类：期货品种按交易日实时推送最新交易数据，现货品种按工作日每日更新当日报价。单条数据文档包含品种标识、交割月份、最新交易价格、当日价格变动值、库存水平、成交量等字段。价格单位为元/吨，成交量单位为手，库存单位为万吨。数据字段需严格匹配数据源格式，避免因字段缺失或单位不统一导致入库失败。

## 这些特征在「数据库与运维」这一环带来什么约束
不同更新节奏的数据源需要匹配差异化的同步调度规则，避免并发写入冲突。高精度的价格与库存数值需要使用高精度存储类型，防止浮点运算导致的精度丢失。多来源的数据格式差异需要前置清洗环节，统一字段命名与单位。高频写入的行情数据会对数据库连接池产生较大压力，需合理配置连接参数以避免连接耗尽。同时，行情数据的时效性要求较高，需保证同步任务的稳定性，避免因数据库故障导致数据更新中断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MONGO_CONNECTION_POOL_SIZE` | `10–15` | 塑料橡胶行情数据高频写入，连接池过小会导致连接等待超时，过大则超出MongoDB默认连接上限 |
| `DATA_SYNC_INTERVAL` | `300 秒`（期货）、`86400 秒`（现货） | 匹配期货实时更新、现货每日更新的数据源节奏，避免无效重复同步 |
| `VECTOR_SEARCH_SCORE_THRESHOLD` | `0.75` | 精准匹配品种与行情数据，平衡误匹配与漏匹配的概率 |
| `DB_NUMERIC_PRECISION` | `12,4` | 存储价格与库存数值，保留四位小数满足高精度需求，避免精度丢失 |
| `MONGO_CONNECT_TIMEOUT_MS` | `5000 毫秒` | 平衡网络波动容忍度与任务阻塞时长，避免因短暂网络问题导致同步任务失败 |
| `FASTGPT_VERSION` | `v4.8.10-alpha2` | 适配该版本的配置项命名与参数校验规则，避免版本兼容问题 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为部署后日志出现`retry init root user mongo start connect init root user error`，原因为未正确配置MongoDB连接字符串，包含错误的端口或认证信息，导致初始化失败。
- 现象为向量库中出现重复的行情数据，原因为未配置基于品种+交割月份的唯一标识校验规则，导致重复数据入库。
- 现象为定时同步任务返回`ETIMEDOUT`错误，原因为连接池大小配置过小，无法支撑高频写入的并发请求。

## 怎么确认配好了
- 执行MongoDB官方连接测试命令，验证配置的连接字符串可正常建立认证连接。
- 手动触发一次数据同步任务，查看入库数据的字段完整性与单位一致性，确认与原始数据源匹配。
- 查看数据库连接池监控指标，确认当前活跃连接数未超过配置的最大连接池大小。
- 对比同步后的数据更新时间与数据源的更新节奏，确认同步频率符合预期。
