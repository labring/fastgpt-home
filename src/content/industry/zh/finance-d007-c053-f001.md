# 多元金融收益率的HTTP 接口与外部系统

## 这个品类的数据长什么样
多元金融的收益率数据主要来自非银金融机构的自营产品披露、场外衍生品交易市场的行情接口、行业自律组织的备案公示数据。固定收益类产品每个交易日收盘后更新数据，权益类及另类产品每周披露最新净值与收益率。数据文档采用标准JSON格式，字段包含产品唯一标识、产品全称、七日年化收益数值、近一年收益数值、单位净值数值、信息披露日期。收益类字段为比例数值，净值为货币单位，日期采用ISO 8601格式字符串。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多数据源的分布要求配置多源聚合的同步逻辑，适配机构披露、场外市场、备案接口三类不同来源的数据。不同的更新节奏需要区分定时拉取的周期，避免过度调用或遗漏数据。字段包含多种格式的数值与日期，需要配置严格的校验规则，确保下游处理的格式一致性。场外交易市场接口通常带有调用频率限制，需要设置限流参数防止触发封禁。部分备案接口需要专属鉴权方式，需配置对应的请求头与签名规则，符合数据获取的合规要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `multi_source_sync_enable` | `true` | 适配多元金融多数据源的拉取需求，覆盖机构披露、场外市场、备案接口三类数据来源 |
| `task_schedule_interval` | `3600 秒 / 604800 秒` | 区分固定收益类（每小时拉取一次）和另类产品（每周拉取一次）的更新节奏，匹配数据源披露周期 |
| `field_validation_mode` | `strict` | 校验收益数值、净值、日期的格式，避免因接口返回格式异常导致的下游处理失败 |
| `api_rate_limit` | `100 次 / 分钟` | 匹配场外交易市场接口的限流规则，防止触发调用封禁 |
| `auth_sign_type` | `HMAC-SHA256` | 符合多数非银金融数据接口的鉴权要求，确保请求合法性 |
| `data_sync_filter` | `按披露日期去重` | 避免重复拉取已同步的历史数据，降低接口调用成本 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：接口返回重复的产品收益率数据，状态码为200但结果集中存在多条相同的披露日期记录。原因：未配置按披露日期去重的过滤规则，导致重复拉取历史数据。
- 现象：定时任务触发后出现`429 Too Many Requests`报错。原因：未设置符合数据源要求的限流参数，调用频率超过接口限制。
- 现象：部分另类产品的收益率字段为空，任务执行日志显示格式校验失败。原因：将校验模式设置为`loose`，未严格校验非公开产品的字段格式，导致异常数据被跳过。

## 怎么确认配好了
- 发起单次同步测试请求，核对返回字段的格式是否符合预设校验规则，确认校验逻辑生效。
- 查看定时任务的执行记录，确认不同品类的产品按照对应的更新周期触发拉取。
- 检查数据聚合结果，确认来自多个数据源的记录都被正确整合，无重复条目。
- 模拟接口调用，确认限流配置生效，不会触发调用限制。
