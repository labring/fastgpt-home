# 多元金融收益率的分享与嵌入

## 这个品类的数据长什么样
多元金融收益率与行情日报的数据来源为持牌金融信息服务机构的标准化公开接口、产品管理人的官方披露平台。数据更新节奏为每个交易日收盘后完成当日数据归集，次一交易日早间发布更新。单份日报为结构化表格形式，按产品大类分组，每个产品条目包含唯一标识代码、产品全称、基础信息字段、多周期收益率指标字段。字段类型与单位：产品代码为字符串格式，产品名称为字符串格式，收益率指标为保留四位小数的无量纲数值，净值类指标单位为元。

## 这些特征在「分享与嵌入」这一环带来什么约束
数据源依赖外部合规接口，嵌入环节需配置合法的API调用凭证，且需限制调用频次匹配数据更新节奏，避免触发外部接口的限流规则。结构化多字段的文档结构，要求嵌入组件支持自定义字段展示，适配不同业务系统的表格布局与展示需求。每日固定时点的更新节奏，要求嵌入缓存的过期时间需与更新周期匹配，防止展示过时数据。产品唯一标识字段的存在，要求嵌入环节支持传入参数筛选指定产品的日报数据，满足精准推送的业务需求。同时，数据调用需符合金融信息合规要求，嵌入代码中需避免暴露敏感的API认证信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `apiRequestTimeout` | 30 秒 | 匹配外部金融数据接口的常规响应时长，避免超时中断数据拉取 |
| `corsAllowedOrigins` | 业务系统域名列表 | 限制嵌入请求的来源，防止未授权的跨域调用 |
| `cacheExpireTime` | 86400 秒 | 匹配每日一次的更新周期，确保缓存数据与官方披露节奏一致 |
| `customFieldMapping` | 按业务系统字段映射产品代码、收益率指标 | 适配不同业务系统的表格组件字段要求 |
| `apiAuthKey` | 加密存储的平台专属密钥 | 避免密钥暴露在前端代码中，保障数据调用合规 |
| `requestRateLimit` | 100 次/分钟 | 匹配持牌机构接口的调用频次限制，防止触发限流规则 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 嵌入页面返回403 Forbidden状态码，原因是未配置`corsAllowedOrigins`参数，或传入的业务系统域名未被纳入允许列表。
- 嵌入组件展示过期的收益率数据，原因是`cacheExpireTime`设置与数据更新周期不匹配，导致缓存未及时刷新。
- 嵌入后无法关联业务系统用户身份，原因是未启用`passThroughUserInfo`配置，或未在嵌入代码中正确传递用户身份标识参数。

## 怎么确认配好了
- 调用嵌入代码的预览接口，检查返回的HTTP状态码为200，确认跨域配置生效。
- 临时调整`cacheExpireTime`为短时长，等待对应时长后刷新嵌入页面，确认数据已按配置更新。
- 在业务系统中传入自定义用户身份标识，检查嵌入窗口的权限校验逻辑正常识别该标识。
- 传入指定产品代码参数，确认嵌入页面仅展示对应产品的收益率日报数据。
