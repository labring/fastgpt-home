# 多元金融收益率的模型接入与配置

## 这个品类的数据长什么样
多元金融品类的收益率相关数据，来源为公开行业披露文件、第三方合规数据接口。数据更新节奏为每日T+1更新，单条数据文档包含产品标识、收益指标、规模参数、发布时间等字段。字段涵盖产品编码、产品全称、收益指标值、管理规模、发布日期，单位包含元、亿元等。不同数据源的字段命名存在细微差异，需在接入阶段完成格式统一。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散且覆盖多品类参数，要求配置阶段需添加品类过滤规则，避免混入无关数据。每日T+1的更新节奏，要求模型调用的定时触发频率匹配更新周期，避免调用未更新的旧数据。单条数据包含多字段的结构，要求配置召回时明确指定目标字段，减少无效信息传输。不同数据源的字段命名存在细微差异，要求配置字段映射规则，统一模型输入的字段格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `baseURL` | 对应多元金融数据接口的合规域名 | 匹配专属数据源的访问路径 |
| `apiKey` | 多元金融数据接口专属鉴权密钥 | 避免通用账户密钥的权限限制 |
| `requestTimeout` | `600 秒` | 适配多品类数据聚合的请求耗时 |
| `contextWindowSize` | `800–1200 字符` | 匹配单条日报数据的平均长度 |
| `fieldMapping` | 按数据源字段映射至统一标识 | 统一不同数据源的字段格式 |
| `dataRefreshInterval` | `86400 秒` | 匹配每日T+1的更新节奏 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：使用官网通用账户密钥配置数据接口，返回`403 Forbidden`状态码。原因：通用账户密钥仅具备平台基础访问权限，不支持多元金融专属数据接口的鉴权。
- 现象：在模型提供商列表中无法看到已通过配置文件添加的模型。原因：未在`modelProvider`配置项中填写正确的服务商标识，或配置修改未触发平台缓存刷新。
- 现象：模型完成推理后，界面无即时输出，需手动打开详情页查看结果。原因：未开启自动展示结果的配置开关，或结果字段映射未关联至前端展示节点。

## 怎么确认配好了
- 发起一次单条数据的测试请求，核对返回字段与配置的`fieldMapping`规则是否一致。
- 查看模型调用日志，确认请求耗时未超过配置的`requestTimeout`值。
- 检查模型提供商列表，确认已配置的模型标识已出现在可选列表中。
- 触发一次完整的日报生成流程，核对界面是否自动展示生成结果。
