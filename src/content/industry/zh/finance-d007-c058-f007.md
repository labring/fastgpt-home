# 小金属收益率的工作流编排

## 这个品类的数据长什么样
小金属的数据来自国内有色金属行业专业行情聚合接口，覆盖钨、钼、锡、锑等细分品种的现货与期货行情。现货数据每日收盘后完成全量更新，期货数据每15分钟推送一次最新报价。单条数据为结构化JSON格式，包含品种代码、中文名称、交割等级、当日结算价、价格变动值、持仓量、成交量等字段。结算价单位为元/吨，持仓量单位为手，成交量单位为吨。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的数据特征对工作流编排带来三点核心约束。第一，现货与期货数据更新节奏差异明显，需为不同数据源配置差异化的触发时机，避免高频拉取现货数据造成接口限流。第二，字段包含明确的单位与业务含义，工作流内的参数提取节点需精准匹配字段名，防止混淆结算价与价格变动值的取值逻辑。第三，小众品种的部分字段存在空值情况，需在工作流中添加空值过滤节点，避免后续处理环节报错。此外，小金属细分规格较多，工作流需支持按品种代码进行定向拉取，减少无效数据传输。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发配置` | 现货任务每日16:30触发，期货任务每15分钟触发 | 匹配小金属现货、期货数据的官方更新节奏 |
| `API调用限流阈值` | 10次/分钟 | 适配国内有色金属行情接口的通用调用限制 |
| `字段提取匹配模式` | 精准匹配 | 小金属数据字段包含明确单位与业务含义，需避免字段混淆 |
| `空值过滤开关` | 启用 | 小众小金属品种存在部分字段为空的情况，防止后续处理报错 |
| `结果集返回条数` | 前15条 | 单期收益率播报无需展示全量品种数据，控制输出长度 |
| `TOOL_CALL_TIMEOUT` | 600秒 | 行情接口响应通常在5分钟内完成，避免超时中断任务 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流调用行情接口后，配置的全局变量未被更新，后续节点引用变量时获取到初始默认值。原因：未启用工具节点的变量更新权限，或全局变量的作用域未设置为当前工作流。
- 现象：在V4.8.22版本的工作流中，无法找到自定义提示词模板的配置入口，仅能调整少量基础参数。原因：该版本未开放工作流节点的自定义提示词功能，相关功能在V4.9.7版本及以上正式上线。
- 现象：工作流提取的小金属数据字段出现错位，比如将价格变动值识别为结算价。原因：未开启字段提取的精准匹配模式，未严格匹配字段名进行取值。

## 怎么确认配好了
- 手动触发工作流一次，查看工具调用节点的返回日志，确认拉取的小金属数据字段与接口文档一致。
- 检查全局变量的更新记录，确认工具调用完成后变量值已按配置完成更新。
- 查看工作流的定时任务执行记录，确认现货与期货任务的触发时机符合预设配置。
- 模拟小众品种的数据拉取请求，确认空值过滤节点已正常生效，未触发异常报错。
