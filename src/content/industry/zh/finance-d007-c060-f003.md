# 工程咨询收益率的分享与嵌入

## 这个品类的数据长什么样
工程咨询的收益率相关数据主要来源于造价分析软件导出的测算文件、项目管理系统的API接口，更新节奏按项目节点触发，单项目完成测算后实时更新，批量项目台账按周同步。数据文档为结构化表格形式，每页对应一个咨询标段的单周期测算内容，包含项目编号、测算周期、基准折现率、内部收益率测算值、净现金流总额等字段，字段单位分别为字符串、日期型、小数、小数、万元，未强制要求统一百分比格式，数据明细包含多组现金流明细行。

## 这些特征在「分享与嵌入」这一环带来什么约束
工程咨询数据按项目标段拆分且包含明细层级，嵌入组件需支持按项目标识动态筛选数据，避免泄露无关项目的机密信息。数据源来自多格式导出文件或API接口，嵌入前需完成格式校验，适配不同来源的数据解析逻辑。更新节奏非固定实时，缓存策略需匹配项目同步周期，平衡数据时效性与加载性能。数据明细行数较多，嵌入展示组件需支持层级折叠，适配不同嵌入场景的页面宽度限制。此外，工程咨询数据常需同步至客户门户，分享链接需支持权限绑定，防止未授权访问。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `shareExpireTime` | `7 天` | 匹配工程咨询项目周报/月报的同步周期，避免长期有效的分享链接泄露数据 |
| `embedWidgetFilter` | `project_id:{{current_project}}` | 工程咨询数据按项目标段拆分，需绑定当前嵌入页面的项目标识，防止跨项目数据泄露 |
| `cacheTTL` | `12 小时` | 匹配批量项目数据的周更/日更节奏，平衡数据时效性与加载性能 |
| `customShareIcon` | `工程咨询专属SVG图标` | 替换默认分享图标，匹配工程咨询场景的品牌视觉规范 |
| `crossDomainAllowList` | `["https://project-console.example.com", "https://client-portal.example.com"]` | 限制嵌入域名，防止恶意站点盗用分享内容 |
| `errorRetryCount` | `2 次` | 适配网络波动场景，减少分享嵌入后的加载失败率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：嵌入组件的分享图标未按需求修改，仍保留默认样式。原因：未正确上传符合格式要求的自定义图标，或未在配置项中启用`customShareIcon`参数。
- 现象：海外部署场景下，免登录分享窗口无法正常响应操作，控制台返回跨域错误或状态码504。原因：未将海外业务域名添加至`crossDomainAllowList`配置项，或跨域配置未同步至海外节点。
- 现象：嵌入页面展示的项目数据与目标标段不符，出现无关项目的测算内容。原因：未配置`embedWidgetFilter`参数，或过滤条件绑定的项目标识与数据源字段不匹配。

## 怎么确认配好了
- 打开嵌入页面的开发者工具，检查网络请求中是否携带正确的过滤参数，确认参数与当前项目标识一致。
- 点击嵌入组件的分享按钮，查看弹出窗口的图标是否为自定义上传的样式，确认配置生效。
- 在海外测试环境访问嵌入页面，检查分享窗口能否正常加载并响应操作，确认跨域配置正确。
- 对比嵌入页面展示的测算数据与原始数据源的对应字段，确认数据字段匹配无误。
