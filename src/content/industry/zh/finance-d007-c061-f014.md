# 工程机械收益率的表单与交互

## 这个品类的数据长什么样
工程机械租赁收益率与行情相关数据主要来自全国工程机械租赁联盟公开报价库、厂商售后租赁台账、二手设备交易平台成交记录、工程招标平台台班计价标准。台班单价每日更新，租赁费率每7天更新，二手设备成交数据实时同步，月度收益测算数据按月生成。数据以结构化CSV或API返回的JSON格式存储，字段包含设备唯一编码、型号、使用年限、所在区域、当前台班计价标准、月度租赁时长参考值、单台设备月度可实现收益额、数据更新时间戳。台班计价单位为元/小时，月度收益单位为元/台。

## 这些特征在「表单与交互」这一环带来什么约束
数据来源分散导致不同渠道的字段命名存在差异，要求表单环节支持自定义字段映射规则，统一跨渠道的数据格式。不同数据的更新节奏差异，要求交互环节区分静态配置字段与实时拉取字段，设置差异化的刷新触发逻辑。多区域的业务维度要求表单支持多级区域筛选组件，快速缩小查询范围。单台设备关联参数较多，要求表单支持批量导入与批量校验，减少单条录入的操作成本。结构化数据需配置行业专属的数值校验规则，避免无效数据进入后续流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `field_mapping_mode` | 按设备型号分组匹配标准字段 | 适配多来源的字段命名差异，统一数据格式 |
| `refresh_interval` | 实时数据`3600 秒`，静态数据`604800 秒` | 匹配台班价、租赁费率的更新节奏，避免无效拉取 |
| `batch_import_max_rows` | `500–1000 行/次` | 平衡导入效率与系统负载，适配行业常规台账规模 |
| `data_validation_range` | 台班价`0–600 元/小时`，月度收益`0–60000 元/台` | 覆盖行业常规设备的合理数值区间，过滤异常数据 |
| `search_trigger_fields` | 设备型号、所在区域 | 匹配用户查询的核心维度，减少冗余数据返回 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用文本内容提取节点后返回空字段，触发指定回复后未正确等待用户补充输入。原因：未配置`empty_content_trigger`参数的等待逻辑，导致流程直接终止，未暂停等待新输入。
- 现象：重排后返回的结果条数与配置不符，仅返回相似度最高的单条结果。原因：未正确设置`rerank_top_k`参数的取值，误将参数设为`1`，未使用预期的返回条数。
- 现象：表单提交后出现字段格式报错，提示“数值超出合理范围”。原因：未配置行业专属的`data_validation_range`规则，使用通用校验区间导致合理数值被误判为异常。

## 怎么确认配好了
- 导入一份包含3-5台不同型号工程机械的测试数据，核对字段映射是否正确，无字段丢失或错位。
- 触发实时数据查询，查看返回结果的更新时间是否与数据源的更新节奏匹配，调整`refresh_interval`参数直至符合预期。
- 提交包含异常数值的测试数据，校验`data_validation_range`规则是否能正确拦截无效输入。
- 配置文本内容提取节点，输入模糊的设备信息，查看指定回复是否触发，并确认流程是否暂停等待用户补充输入。
