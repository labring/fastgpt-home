# 影视院线收益率的分享与嵌入

## 这个品类的数据长什么样
影视院线的收益率数据主要来自全国电影票务综合信息管理系统接口、合作院线的内部结算系统，以及公开的影视行业数据接口。更新节奏分为两类：日度汇总收益率数据每日02:00-04:00完成前一日全量数据更新，实时衍生的单场次收益率数据每15分钟刷新一次。单条数据文档结构包含影片标识、影院归属、当日结算票房总额、分账成本总额、运营成本分摊额、净收益总额，以及场次数量、场均观影人次等辅助字段。金额类字段单位为元，人次类单位为人，场次类单位为场。

## 这些特征在「分享与嵌入」这一环带来什么约束
影视院线收益率数据的特征会对分享与嵌入环节带来多重约束。每日仅更新一次的日度汇总数据，要求嵌入组件默认展示前一日的完整统计结果，若需展示实时衍生数据，需单独配置15分钟级别的刷新逻辑。数据包含影院、影片、场次等多维度关联字段，嵌入时需支持通过影院ID、影片ID作为筛选参数，否则无法精准匹配目标主体的收益率信息。金额类字段数值以元为单位，嵌入展示时需配置单位格式化规则，将大额数值转换为万元级展示以优化可读性。部分数据来源接口存在跨域限制，嵌入组件需配置合法的跨域请求头，否则无法正常拉取数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `shareEmbedRefreshInterval` | `86400 秒`（日度数据）或`900 秒`（实时衍生数据） | 匹配影视院线数据的更新节奏，日度数据无需高频刷新，实时衍生数据按15分钟刷新符合行业业务需求 |
| `shareEmbedFilterParams` | `["影院ID", "影片ID", "档期ID"]` | 匹配影视院线收益率数据的多维度关联字段，支持精准筛选目标主体的收益数据 |
| `shareEmbedFormatNumber` | `{"金额": "万元", "人次": "人次", "场次": "场"}` | 适配影视院线数据的单位特征，将大额金额转换为万元级提升可读性 |
| `shareEmbedCorsWhitelist` | `["your-domain.com"]` | 允许指定域名下的嵌入页面发起跨域请求，符合数据接口的跨域校验要求 |
| `shareEmbedCustomIcon` | `base64://your-custom-icon-data` | 替换默认分享嵌入组件的图标，满足品牌定制需求 |
| `shareEmbedAuthMode` | `"none"` 或 `"jwt"` | 根据业务场景选择，免登录模式适合公开分享，JWT模式适合权限管控的内部场景 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：嵌入组件加载后显示默认的官方图标，无法替换为自定义品牌图标。原因：未配置`shareEmbedCustomIcon`参数，或传入的图标文件格式不符合平台要求。
- 现象：海外SaaS版本的嵌入组件发起数据请求后返回错误，点击后无收益率数据展示。原因：未将海外业务域名加入`shareEmbedCorsWhitelist`配置，或跨域请求头未正确设置。
- 现象：开源版本4.8.14中，免登录分享嵌入组件未提供身份验证相关配置项。原因：该版本的分享嵌入模块未集成身份验证功能，需升级至后续版本获取相关配置。

## 怎么确认配好了
- 打开嵌入组件的官方预览页面，检查图标是否为自定义设置的样式，确认`shareEmbedCustomIcon`配置生效。
- 在嵌入页面发起数据请求，查看浏览器控制台的网络请求日志，确认返回状态码为200，无跨域相关错误提示。
- 调整嵌入组件的筛选参数，检查展示的收益率数据是否匹配对应影院或影片的业务信息，确认`shareEmbedFilterParams`配置正确。
- 等待数据更新周期结束后，刷新嵌入页面，检查展示的数据是否为最新的前一日统计结果，确认`shareEmbedRefreshInterval`配置符合数据更新节奏。
