# 影视院线收益率的表单与交互

## 这个品类的数据长什么样
影视院线的收益率相关数据主要来自合作院线票务系统、全国电影票务公开接口，更新节奏为每日固定时段更新前一自然日的票房、观影人次、排片数据，每周更新当周累计营收数据。单条数据文档包含影院编码、影院名称、上映影片名称、当日排片场次、当日票房收入、当日观影人次、单厅平均营收等字段，其中票房收入以人民币元为单位，观影人次以人次为单位，排片场次以场为单位，单厅平均营收以元/场为单位。

## 这些特征在「表单与交互」这一环带来什么约束
影视院线数据的固定更新节奏要求表单仅支持按自然日、自然周预设周期筛选，无法支持自定义非周期时段查询，匹配数据源的更新范围。字段自带明确单位的特征，要求交互表单为每个数值字段绑定对应单位标签，避免用户输入错误单位格式。字段间存在联动关系，当日票房收入与观影人次会共同推导单厅平均营收，表单需要配置字段联动校验规则，自动修正或提示异常组合。数据源接口存在调用频次限制，交互模块需限制批量查询次数，避免触发接口限流。部分关联字段如影院编码与影院名称需支持下拉联动选择，减少手动输入误差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `SQL_VAR_PARSE_MODE` | 严格变量匹配模式 | 影视院线数据的SQL查询常包含影院编码、影片名称等变量，严格模式可避免变量被误解析为SQL关键字，解决变量传入报错问题 |
| `SELECT_OPTION_DYNAMIC` | 开启，绑定院线数据源接口 | 影视院线的影院列表、上映影片随周期更新，动态选项可自动同步最新数据，无需手动维护选项列表 |
| `CHAT_INPUT_FILE_UPLOAD` | 按场景开启 | 部分影视院线场景需上传本地排片报表、票房台账文件，开启后可在聊天输入框显示上传按钮 |
| `FORM_VALIDATE_TIMEOUT` | 30 秒 | 影视院线数据查询需拉取多维度关联数据，30秒可覆盖常规查询时长，避免查询超时报错 |
| `QUERY_LIMIT_PER_MINUTE` | 60 次/分钟 | 院线数据源接口存在调用频次限制，该取值可匹配接口限流规则，避免触发接口拦截 |
| `SQL_EXEC_TIMEOUT` | 15 秒 | 影视院线多表关联查询的执行时长较长，15秒可覆盖常规查询需求，避免SQL执行超时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：执行SQL查询时返回`SQL syntax error`报错，手动输入固定值可正常执行，传入变量参数则失败。原因：未配置`SQL_VAR_PARSE_MODE`为严格变量匹配模式，变量被误解析为SQL关键字，触发语法错误。
- 现象：表单中的影院、影片选项长时间未更新，无法匹配最新上线的影片或新增影院。原因：未开启`SELECT_OPTION_DYNAMIC`配置，选项列表为静态硬编码，未绑定数据源接口自动同步。
- 现象：聊天输入框未显示文件上传按钮，无法上传本地排片报表或票房台账文件。原因：未开启`CHAT_INPUT_FILE_UPLOAD`配置，或配置被误关闭。

## 怎么确认配好了
- 执行包含变量的SQL查询，确认无语法报错，核对变量解析结果与预期一致。
- 触发影院或影片选项的加载，确认选项列表随数据源更新自动同步，无静态硬编码残留。
- 上传本地影视数据文件，确认聊天输入框的上传按钮正常显示，文件可正常解析。
- 发起批量查询请求，确认未触发接口限流拦截，查询结果符合预期。
