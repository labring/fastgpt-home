# 房建工程收益率的多轮对话与提示词

## 这个品类的数据长什么样
房建工程的收益率与行情数据主要来自住建部门区域造价数据库、建材供应链日度报价系统、项目备案的投资档案。核心行情数据按日度更新，区域指导价按周同步至平台。单份日报文档包含工程区域、业态类型、单方成本基准值、核心建材成本占比、单位投资回报测算值、对应工期节点要求等字段。单方成本基准值的单位为元每平方米，单位投资回报测算值的单位为元每万元投入，无百分比类计量字段。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
日度更新的行情数据要求多轮对话需实时关联最新的建材成本与造价基准，避免调用过期历史数据。区域指导价的周更特性要求提示词需明确区分本地与跨区域的造价参数，防止跨区域数据混用。多字段的文档结构要求提示词指定字段提取优先级，优先返回当前查询指定的区域与业态数据。非百分比的计量方式要求提示词明确统一单位换算规则，避免数值混淆。长文档的批量上传需求要求上下文窗口配置适配单份日报的文档长度，防止上下文溢出。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 前8000字符 | 适配FastGPT 4.9.7及以上版本的上下文窗口限制，适配单份房建工程日报的平均文档长度，避免上下文窗口溢出 |
| `recallTopK` | 前6条 | 匹配单份日报的核心字段数量，过滤无关的历史对话数据 |
| `similarityThreshold` | 0.72–0.78 | 适配房建工程数据的字段相似度分布，提升召回内容的相关性 |
| `contextWindowSliceSize` | 1200字符 | 匹配单份日报的段落长度，避免切片破坏数据完整性 |
| `logRetentionDays` | 30天 | 符合行业数据存档的常规周期，控制存储资源占用 |
| `toolCallHideContent` | 开启 | 隐藏工具调用的中间步骤，仅向用户展示整理后的最终播报结果 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：对话中上传多份房建工程日报后，模型返回与当前查询无关的内容。原因：未配置`contextWindowSliceSize`参数，长文档未正确切片，上下文窗口溢出导致数据混乱。
- 现象：工具调用环节展示完整的API请求与响应日志，以及整理后的收益率结果。原因：未开启`toolCallHideContent`配置，工具调用的中间步骤被同步暴露给对话用户。
- 现象：对话进行到第三轮后，模型无法关联前序提到的工程区域与业态参数，返回答非所问的结果。原因：未设置`maxContext`参数的合理取值，或未开启上下文召回开关，历史对话未被正确保留。

## 怎么确认配好了
- 发起包含多份房建工程日报的对话，检查模型返回的内容是否仅包含当前查询相关的字段数据，无无关的历史对话残留。
- 测试工具调用流程，确认最终播报结果中不包含工具调用的中间步骤，仅展示整理后的收益率与行情信息。
- 发起连续多轮的区域与业态参数关联查询，检查模型是否能正确关联前序提问的参数，返回对应区域的工程数据。
- 查看系统日志存档页面，确认日志的保留时长与配置参数一致，且可按需求执行过期日志清理操作。
