# 房建工程收益率的工具调用与插件

## 这个品类的数据长什么样
房建工程收益率相关数据主要来自住建部门发布的区域造价指导价、项目竣工备案的造价结算文件、行业第三方造价咨询机构的月度监测报告。区域指导价按月更新，行业监测数据按周更新，竣工结算数据随项目周期归档。单条数据包含所属行政区域、建筑类型、单体建筑面积、单位造价基准值、分项工程成本占比、市场调整系数等字段。单位造价基准值以元/建筑平方米为单位，分项占比以小数形式记录，市场调整系数为无量纲数值。

## 这些特征在「工具调用与插件」这一环带来什么约束
多来源的数据特征要求工具调用需适配多种数据源格式与认证方式，例如官方API需配置密钥认证，本地归档文件需支持CSV/文档解析。不同更新节奏要求工具的定时触发规则需区分配置，避免频繁拉取过时数据或延迟获取最新指导价。结构化的分项字段要求工具解析规则需针对性映射，无法直接复用通用字段提取模板。统一的单位要求需在调用前校验数据格式，避免跨区域、跨品类的单位混用导致计算偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `data_source_type` | 按数据源类型选择「官方API」「第三方CSV」「项目归档解析」 | 匹配房建工程收益率数据的多来源特征，避免通用数据源适配偏差 |
| `update_cron` | `0 0 2 * *`（每月2日0点）、`0 0 * * 1`（每周一0点） | 对应区域指导价月度更新、行业监测数据周度更新的节奏 |
| `field_mapping_rule` | 按「区域-建筑类型-单位造价基准值-分项工程占比」顺序映射 | 匹配房建工程数据的结构化字段顺序，减少解析错误 |
| `parse_timeout` | `600 秒` | 适配多数据源解析的耗时需求，避免因数据量较大触发超时 |
| `unit_verify_switch` | `开启` | 校验单位造价的「元/建筑平方米」单位，避免跨品类数据混用 |
| `plugin_auth_mode` | 按数据源配置「API密钥」「OAuth2授权」「本地文件读取」 | 匹配不同数据源的认证要求，确保数据拉取权限合法 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用日志返回`400 Invalid JSON payload received. Unknown name`报错，原因是字段映射规则错误，将房建工程特有的「分项工程占比」字段误写为通用字段，导致JSON格式异常。
- PgVector插件升级失败，原因是未提前备份房建工程的历史造价向量数据，升级过程中向量索引结构变更导致数据丢失。
- 模型渠道返回数据异常，原因是未开启`unit_verify_switch`，导致跨区域的单位造价数值混淆，触发参数校验失败。

## 怎么确认配好了
- 手动触发一次工具调用，查看返回的JSON数据字段是否包含「区域」「建筑类型」「单位造价基准值」等房建工程特有的字段。
- 检查插件的定时任务日志，确认在指定触发时间成功拉取到对应周期的最新数据。
- 开启`unit_verify_switch`后，验证工具是否会拦截单位不符的数据源数据。
- 调用文本提取工具，确认能正确提取房建工程结算文档中的分项工程成本占比字段。
