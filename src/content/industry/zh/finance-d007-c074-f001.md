# 教育服务收益率的HTTP接口与外部系统

## 这个品类的数据长什么样
本品类的数据主要来自教育服务机构的内部运营报表、行业协会公开的区域教育服务统计数据集。数据更新节奏为每日凌晨更新前一自然日的日报内容。文档采用结构化格式，单条记录包含服务细分领域、核算周期、投入成本、营收总额、收益率指标等字段。投入成本与营收总额的单位为人民币元，收益率指标为无量纲系数，无固定百分比基准。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
本品类的数据特征对HTTP接口与外部系统环节带来多重约束。数据来源分散的特点要求接口支持多源鉴权机制，适配机构自有API与公开数据集的不同接入规则。每日更新的日报节奏要求接口调用频率需限定为每日1次，避免高频请求占用资源。结构化字段的固定命名要求接口返回的字段需与外部系统的映射配置严格对齐，防止字段缺失或名称不匹配导致解析失败。无固定百分比基准的收益率指标要求外部系统保留原始字段值，不得擅自添加单位转换逻辑。此外，多细分服务领域的分类要求接口支持按服务类型筛选的参数配置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `EXTERNAL_DATA_SYNC_INTERVAL` | `86400 秒` | 匹配教育服务收益率日报的每日更新节奏，避免无效调用 |
| `API_FIELD_MAPPING` | `按服务细分领域/核算周期/投入成本/营收总额/收益率指标映射` | 对齐结构化数据的字段要求，防止解析错误 |
| `HTTP_REQUEST_TIMEOUT` | `30 秒` | 适配公开数据集与机构API的平均响应时长，避免超时中断 |
| `AUTH_TYPE` | `API_KEY 或 OAuth2.0` | 适配多源数据的鉴权需求，覆盖机构自有API与公开数据集的接入规则 |
| `DATA_FILTER_PARAM` | `service_type=职业教育, K12培训` | 支持按教育服务细分领域筛选，匹配多分类的数据特征 |
| `PARSE_RAW_DATA_FLAG` | `true` | 保留原始收益率指标的无量纲值，不得擅自添加单位转换 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：离线环境下触发数据同步时，界面显示加载超时，控制台提示无法解析api.github.com域名。原因：未配置离线环境下的本地数据缓存规则，依赖外部域名解析导致请求失败。
- 现象：外部系统接收数据后，收益率字段显示为空或格式异常。原因：未正确配置`API_FIELD_MAPPING`，字段名称与接口返回值不匹配导致解析失败。
- 现象：调用接口后返回的结果条数超出预期范围。原因：未设置`DATA_FILTER_PARAM`，未按服务类型筛选数据，返回了全量的非目标品类数据。

## 怎么确认配好了
- 手动触发一次数据同步，检查外部系统是否接收到符合预期的结构化数据。
- 查看FastGPT控制台的外部数据源日志，确认接口请求的鉴权信息、请求参数与配置项一致。
- 对比接口返回的原始字段与外部系统存储的字段值，确认未擅自添加单位转换逻辑。
- 等待一个完整的同步周期，检查数据是否按配置的间隔自动更新。
