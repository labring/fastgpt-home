# 教育服务收益率的工作流编排

## 这个品类的数据长什么样
教育服务收益率与行情日报的数据来源为教育行业第三方监测机构公开数据集、合作教育机构的匿名运营报表、教育服务平台的脱敏交易数据。更新节奏为每日更新，统计前一自然日的全量业务数据。文档结构为结构化表格，每行对应一类教育服务类目，包含服务类型标识、单次服务营收额、固定成本分摊额、可变成本分摊额、周期收益总额、数据统计周期字段，单位依次为类目类型、元、元、元、元、日期。字段需按统计周期升序排列，无冗余空字段。

## 这些特征在「工作流编排」这一环带来什么约束
数据来源分散带来多数据源接入的约束，需配置多数据源聚合节点合并不同渠道的数据集。每日更新的节奏要求工作流配置定时触发节点，触发周期设为每日固定时段，避免实时调用超出数据源接口限额。结构化表格的格式要求工作流启用结构化解析节点，自动识别列字段映射规则，无需手动适配每一行数据。多字段的结构要求配置字段校验节点，过滤缺失值与异常格式的条目。按统计周期排序的要求需添加排序节点，按数据统计周期字段完成升序排列。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发配置` | 每日02:00-03:00区间触发 | 避开教育服务业务高峰时段，降低数据源接口限流概率 |
| `多数据源合并规则` | 按服务类目字段作为主键合并 | 确保同一服务类目的多源数据合并后无重复条目 |
| `结构化解析字段映射` | 按预定义列名映射至系统标准字段 | 适配教育服务数据的固定列结构，减少手动配置量 |
| `字段校验阈值` | 缺失值占比超过预设比例时跳过对应条目 | 过滤无效数据，避免异常值影响后续分析 |
| `HTTP请求重试次数` | 3次，间隔60秒 | 应对临时接口波动，保障多源数据拉取成功率 |
| `结果输出格式` | 结构化CSV格式 | 适配后续报表生成工具的导入格式要求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流调用知识库搜索时，变量引用的服务类目字段为空，搜索结果无匹配内容。原因：未在工作流变量配置中绑定数据源解析后的字段，直接使用未赋值的占位变量。
- 现象：工作流执行返回状态码429，提示接口调用限流。原因：未设置合理的定时触发时段，在业务高峰时段调用数据源接口，超出接口调用限额。
- 现象：生成的收益率报表列对齐异常，字段错位。原因：未配置结构化解析字段映射规则，直接使用原始未规整的表格数据进行输出。

## 怎么确认配好了
- 手动触发一次工作流，查看各节点的执行日志，确认多数据源合并后的字段完整且无重复条目。
- 核对定时触发配置的时段，确认该时段内数据源接口的调用压力较低，可通过接口返回的状态码验证限流情况。
- 导出工作流的测试结果，检查字段映射是否匹配预定义列名，排序是否按数据统计周期完成升序排列。
- 输入包含缺失值的测试数据，确认字段校验节点会按预设规则过滤异常条目。
