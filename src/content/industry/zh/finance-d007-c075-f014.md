# 整车收益率的表单与交互

## 这个品类的数据长什么样
整车金融收益率相关数据主要来自车企金融事业部内部运营系统、全国机动车上牌数据平台、区域经销商金融服务联网上报系统。更新节奏为日度更新，当日统计数据于次日凌晨3点前完成全量同步。单条数据文档包含车型编码、生产基地、销售区域、单车金融营收、单车运营成本、渠道服务费六个核心字段。字段单位统一为元/台，无百分比类单位。数据按车型+销售区域维度聚合，单条文档数据体量稳定在120字节上下。

## 这些特征在「表单与交互」这一环带来什么约束
日度更新的特性要求表单查询区间默认锁定为自然日，不支持自定义跨多天的批量查询，避免因金融数据同步节点不一致导致结果偏差。字段按车型+销售区域聚合且单位统一为元/台，因此表单需预设车型编码、销售区域两个必选筛选项，不开放无筛选的全量查询，防止返回数据量过大导致前端卡顿。固定的凌晨3点同步节点，要求交互环节在前端展示最新数据的更新时间戳，避免用户获取未刷新的旧数据。单条数据体量小，表单批量导出功能需限制单次导出的车型+区域组合数量，防止接口响应超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `QUERY_DEFAULT_DATE_RANGE` | 自然日（当日00:00至23:59） | 匹配整车金融收益率数据日度更新的特性，默认提供当日数据查询 |
| `REQUIRED_FORM_FIELDS` | `["车型编码", "销售区域"]` | 数据按车型+销售区域聚合，必选筛选可避免全量无意义查询 |
| `BATCH_EXPORT_MAX_COUNT` | `500 组` | 单条数据体量小，500组组合的导出数据量可控，避免接口超时 |
| `DATA_UPDATE_TIMESTAMP_DISPLAY` | 开启 | 数据同步节点固定，展示时间戳可避免用户获取未刷新的旧数据 |
| `FORM_QUERY_TIMEOUT` | `10 秒` | 数据聚合逻辑简单，10秒可覆盖绝大多数查询场景 |
| `API_RATE_LIMIT_PER_MINUTE` | `60 次` | 匹配经销商上报数据的峰值频率，避免接口被高频请求压垮 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 打开超过6个表单交互页面后，新页面无法加载或返回503状态码。原因：前端默认对单浏览器上下文的并发连接数设置为6，未针对批量数据查询场景调整对应参数。
- 查询结果返回字段缺失，仅包含单车金融营收，无运营成本数据。原因：未在表单配置中勾选需要返回的全量字段，或数据聚合脚本遗漏了对应字段的提取逻辑。
- 调用语音转文字接口时返回“Permission denied by system”报错。原因：未在系统权限配置中开启麦克风访问权限，或workflow中未正确配置语音输入的调用参数。

## 怎么确认配好了
- 打开表单配置界面，核对默认查询区间的设置，确认与业务需求的查询周期匹配。
- 提交无筛选条件的查询请求，确认系统拦截并提示需补充必填筛选字段，验证必选配置生效。
- 查看表单展示的最新数据时间戳，确认与数据同步节点的时间一致，验证时间戳展示配置正确。
- 调用批量导出功能，导出指定数量的组合数据，确认返回的字段与配置的返回字段完全一致。
