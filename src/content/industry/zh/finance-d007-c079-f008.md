# 普钢收益率的工具调用与插件

## 这个品类的数据长什么样
普钢行情与收益率数据来自国内钢铁行业权威现货报价平台与期货交易所公开接口。更新节奏分为两类：现货报价每日固定时段更新一次，期货行情随交易时段实时推送。文档结构为结构化键值对或表格格式，字段包含普钢品类编码、产地、规格参数、现货含税单价、期货主力合约结算价、价格变动差值、发布时间戳，单位统一为元/吨，不包含比例类百分比数据。

## 这些特征在「工具调用与插件」这一环带来什么约束
普钢数据的分类型更新节奏要求工具调用需区分数据源触发时机，现货调用需设置每日固定时段触发，期货调用需绑定交易时段的定时任务。品类与规格的细分字段要求工具调用必须传入明确的筛选参数，否则接口将返回大量冗余或不匹配的数据。单位统一为元/吨的特征，要求插件无需额外进行单位转换，但需校验返回数据的单位一致性，避免后续计算偏差。此外，部分现货平台接口存在调用额度限制，需配置限流规则避免触发封禁。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_call_timeout` | `30 秒` | 普钢数据源接口响应通常在10秒内，30秒可覆盖网络波动场景，避免超时中断调用 |
| `tool_call_rate_limit` | `10 次/分钟` | 符合国内现货平台公开接口的调用额度限制，避免触发限流封禁 |
| `required_tool_params` | `["品类编码", "规格参数", "数据类型"]` | 普钢数据需明确品类、规格与数据类型（现货/期货）才能返回精准结果，遗漏参数将触发参数错误 |
| `response_parse_schema` | `{"fields": ["品类编码", "现货单价", "期货结算价", "价格变动差值", "发布时间"]}` | 匹配普钢行情日报的核心字段需求，过滤冗余数据以优化后续处理 |
| `plugin_mcp_enabled` | `开启` | 标准化对接普钢行情的第三方接口，统一管理工具调用链路与权限 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：返回`400 InternalError.Algo.InvalidParameter`报错，原因：未传入普钢的品类编码或规格参数，导致工具调用的筛选条件缺失，接口无法返回匹配数据。
- 现象：工具调用返回的结果条数远超预期，原因：未指定`required_tool_params`中的数据类型，接口返回混合现货与期货的全量数据，导致结果冗余。
- 现象：界面提示`The tool call is not supported`，原因：未启用`plugin_mcp_enabled`配置，或未在平台中绑定普钢行情的MCP工具，导致平台无法识别可用的调用接口。

## 怎么确认配好了
- 在平台的工具调试界面输入普钢的品类编码、规格参数与数据类型，发起测试调用，检查返回的字段是否与预设的`response_parse_schema`一致。
- 查看工具调用的历史日志，确认调用频次未超过`tool_call_rate_limit`的设置，无限流相关报错。
- 检查平台的插件管理页面，确认`plugin_mcp_enabled`处于开启状态，且已绑定普钢行情的对应MCP工具。
- 手动对比返回的单价数值与官方公开报价的单位，确认未出现单位转换错误。
