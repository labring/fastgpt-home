# 普钢收益率的模型接入与配置

## 这个品类的数据长什么样
普钢数据主要来自国内钢铁现货交易平台、行业协会公开统计及期货市场合约数据。更新节奏分为两类：现货数据每日收盘后更新，期货数据盘中实时更新、盘后结算价每日固定时点更新。数据以结构化文档或API接口形式返回，包含普钢品种标识、产地、当日交易价格、当日结算价格、当日累计成交量、当日持仓量等字段。价格单位为元/吨，成交量单位为吨，持仓量单位为交易手。

## 这些特征在「模型接入与配置」这一环带来什么约束
普钢数据的多更新节奏、结构化字段与行业专属标识特征，对模型接入与配置带来多重约束。首先，需同时支持定时批量拉取与实时流式接入两类数据来源，需配置对应拉取周期与触发机制。其次，数据字段包含行业专属标识，需配置字段映射规则，将接口返回的原生字段与模型所需的标准化字段绑定。此外，需配置品类过滤规则，仅拉取目标普钢品类的数据，避免冗余数据干扰模型输出。最后，需配置单位校验逻辑，确保接入数据的单位符合预设标准，防止异常数据流入。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `data_sync_cron` | `0 18 * * *` | 适配普钢现货数据每日收盘后的更新节奏，确保每日同步最新现货数据 |
| `real_time_pull_interval` | `300 秒` | 匹配普钢期货数据的盘中更新频率，平衡数据时效性与接口调用成本 |
| `field_mapping_rule` | 按「品种标识→product_type，交易价格→trade_price，结算价格→settle_price」绑定 | 匹配普钢数据的原生字段与模型所需的标准化输入字段 |
| `category_filter_key` | 过滤键为`product_type`，匹配值为`Q235螺纹钢`、`普通线材` | 仅拉取目标普钢品类的数据，避免非目标品类数据干扰模型输出 |
| `data_unit_validate` | `开启` | 确保接入数据的单位为元/吨、吨、手，防止异常数据流入模型 |
| `model_input_chunk_size` | `800–1200 字符` | 适配普钢数据字段较多的特征，避免单次输入超出模型上下文限制 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处

- 现象：模型调用返回`404 Not Found`错误，或提示「模型不可用」。原因：未正确配置模型接入的API地址与认证密钥，或选择了未适配的模型类型。
- 现象：接入的普钢数据字段为空，或字段值与实际不符。原因：未正确配置`field_mapping_rule`，或过滤规则绑定了错误的字段键值。
- 现象：定时同步任务无限重启，或日志提示「token encoder错误」。原因：未正确配置模型的token编码参数，或部署环境下的模型依赖包缺失。

## 怎么确认配好了

- 手动触发一次数据拉取，查看返回的普钢数据字段是否完整且符合预设的映射规则。
- 检查模型调用日志，确认没有返回认证错误或接口不可用的提示。
- 运行一次模型推理任务，查看输出是否包含普钢收益率相关的标准化内容。
- 查看定时同步任务的运行记录，确认任务按预设周期正常执行。
