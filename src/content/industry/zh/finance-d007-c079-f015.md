# 普钢收益率的部署与升级

## 这个品类的数据长什么样
普钢行情与收益率数据主要来自国内钢铁行业专业资讯平台、期货交割仓库库存记录及现货贸易成交台账。数据更新节奏固定为每日16:30后发布当日全品类日报文档。单份文档的记录结构包含交易日期、钢材品种、规格型号、产地、现货成交价、收益率、当日成交量、社会库存总量等字段。现货成交价单位为元/吨，成交量单位为吨，社会库存总量单位为万吨。

## 这些特征在「部署与升级」这一环带来什么约束
普钢品类的多品种多规格特征，要求部署时配置按品种维度的数据源分组同步规则，避免字段映射混乱。固定每日16:30的更新节奏，要求部署时配置精准的定时触发参数，升级需避开该时段，防止当日日报生成流程中断。跨数据源的现货与期货联动计算需求，要求配置跨库关联的检索阈值，确保收益率计算的准确性。多字段的单位一致性要求，需在解析环节配置单位校验规则，避免数据混入异常单位。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `SYNC_CRON_EXPRESSION` | `0 30 16 * * ?` | 匹配普钢日报每日16:30的更新节奏，确保定时同步任务按时触发 |
| `PARSE_FIELD_MAPPING` | 按实测标定 | 普钢包含品种、规格、产地等多维度字段，需自定义映射规则适配不同数据源格式 |
| `VECTOR_SPLIT_CHUNK_SIZE` | `800-1200 字符` | 普钢日报单条记录字段较多，该长度可保证单块数据包含完整的品种与行情信息 |
| `RECALL_TOP_K` | `前8条` | 普钢热门品种较多，该召回数可覆盖核心品类同时避免结果冗余 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单份普钢全品类日报文档通常不超过300MB，预留合理冗余空间 |
| `MCP_ENABLED` | `是` | 需支持跨数据源联动计算收益率，推荐使用4.8.17及以上版本以启用该功能 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：访问部署的行情播报服务返回`405 Method Not Allowed`。原因：未配置FastGPT的API网关允许POST请求的路由规则，或端口映射仅开放了GET请求。
- 现象：本地部署中无法启用团队管理功能。原因：未在`TEAM_MANAGEMENT_ENABLED`配置项中设置为`true`，且未重启服务加载最新配置。
- 现象：多节点部署后部分节点无法获取最新普钢日报数据。原因：未配置共享存储卷挂载日报文档目录，导致节点间数据不同步。

## 怎么确认配好了
- 查看定时任务日志，确认在每日16:30触发了普钢日报的同步与解析任务，核对日志中的任务执行时间与配置的`SYNC_CRON_EXPRESSION`是否一致。
- 上传一份测试用的普钢日报文档，查看解析结果中的字段是否与预设的`PARSE_FIELD_MAPPING`规则匹配，确认所有必填字段均被正确提取。
- 发起一次行情播报的查询请求，核对返回结果的召回条数是否符合`RECALL_TOP_K`的配置，且包含目标普钢品种的收益率数据。
- 检查多节点部署的共享存储目录，确认所有节点均可访问到最新的日报文档，且服务重启后配置项未被重置。
