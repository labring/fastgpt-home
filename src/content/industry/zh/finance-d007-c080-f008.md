# 服装家纺收益率的工具调用与插件

## 这个品类的数据长什么样
服装家纺品类的数据源主要包括纺织行业协会公开监测数据、品牌方终端零售台账、大宗商品交易平台的纺织原料报价。更新节奏分批次：原料报价每旬更新，终端零售数据每周更新，渠道动销数据每月更新。文档结构为结构化表格，包含SKU标识、原料类型、采购单价、终端售价、铺货区域、动销累计销量、单位毛利字段。字段单位分别为元/千克（原料）、元/件（终端售价）、个（铺货区域计数）、件（动销累计销量）、元/件（单位毛利）。

## 这些特征在「工具调用与插件」这一环带来什么约束
多数据源的更新节奏不一致，要求工具调用需配置分批次的触发规则，分别匹配不同数据源的更新周期。字段包含SKU标识等细分标识，工具调用时需传入精准的SKU参数过滤数据，避免跨品类数据混入。不同数据源的字段命名存在差异，需在工具配置中添加字段映射规则，统一输出格式。部分数据源的接口调用存在频次限制，需配置调用频率阈值，避免触发限流。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_call_trigger_type` | `定时触发+手动触发` | 服装家纺数据分批次更新，定时触发匹配固定更新节奏，手动触发应对临时数据查询需求 |
| `tool_data_source_timeout` | `300 秒` | 跨多数据源拉取时，原料报价接口响应较快，终端零售数据接口可能因数据量较大延迟较高，300秒可覆盖多数场景 |
| `plugin_field_mapping` | `按SKU标识统一映射为sku_code` | 不同数据源的SKU字段命名存在差异，需统一为标准字段供后续处理 |
| `tool_rate_limit_count` | `10 次/分钟` | 纺织原料交易平台的公开接口有调用频次限制，该取值可避免触发限流报错 |
| `tool_call_max_retries` | `3 次` | 网络波动或接口临时异常时，重试可提升数据拉取成功率 |
| `plugin_output_format` | `结构化JSON数组` | 后续处理环节需统一格式的数据集，便于解析与展示 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具模块在插件配置页面无法找到，返回`404 Not Found`错误。原因：未在后台开启工具调用功能开关，或使用的开源版本未集成对应工具模块。
- 现象：调用embedding模型时返回`invalid_api_key`错误，或无法获取向量数据。原因：未正确配置embedding模型的API密钥参数，或密钥权限不足。
- 现象：插件部署后无法在工作流中调用，界面显示插件未加载，或无法找到插件配置路径。原因：未将插件文件放置到FastGPT指定的插件目录，或目录路径配置错误。

## 怎么确认配好了
- 进入工具配置页面，检查`tool_call_trigger_type`参数是否已设置为对应取值，确认功能开关处于开启状态。
- 发起一次手动工具调用，查看返回结果的字段是否与预设的`plugin_field_mapping`规则一致。
- 查看系统日志，确认未出现`tool_rate_limit_count`相关的限流报错，或`tool_data_source_timeout`相关的超时报错。
- 调用embedding模型接口，确认返回的向量数据格式符合预期，无`invalid_api_key`类错误。
