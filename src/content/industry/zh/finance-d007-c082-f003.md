# 水产养殖收益率的分享与嵌入

## 这个品类的数据长什么样
水产养殖收益率相关数据主要来源于农业农村部渔业监测站点、区域核心水产批发市场的日度采集，以及规模化养殖基地的物联网终端同步数据。数据更新节奏为每日固定时段推送，单份数据文档包含养殖品种、产区、当日收购均价、单位饲料成本、单亩净利润等字段。字段单位统一采用元/千克、元/亩、元/尾等实物计量单元，单条数据文档篇幅约300至800字符。

## 这些特征在「分享与嵌入」这一环带来什么约束
水产养殖数据的多源异构特征，要求嵌入配置中需预设跨源字段映射规则，统一不同采集渠道的核心字段格式。日度更新的节奏，要求分享链接的缓存过期时间不超过24小时，避免展示滞后信息。单份数据文档篇幅差异较大，建议按自有样本统计或实测后，确定嵌入组件的适配高度，防止内容溢出排版。字段采用实物计量单元，嵌入展示模块需额外绑定单位标注逻辑，避免不同品类的计量标准混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `share_cache_ttl` | `86400 秒` | 匹配水产养殖数据日度更新周期，避免展示过时内容 |
| `embed_min_height` | `400–600 像素` | 适配单份数据文档300至800字符的篇幅，防止内容溢出 |
| `field_mapping_template` | `预设水产养殖专属模板` | 统一多源异构数据的`养殖品种`、`单亩净利润`等核心字段格式 |
| `embed_show_unit` | `开启` | 明确标注元/千克、元/亩等实物单位，提升数据可读性 |
| `share_anonymous_enabled` | `开启` | 适配行业从业者快速分享的场景需求，无需强制登录 |
| `embed_custom_css` | `按实测标定` | 适配不同嵌入场景的页面布局，优化展示效果 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：免登录分享链接无法验证访问者身份，原因：开源版本4.8.14及更早版本未内置身份验证模块，需升级至对应支持版本后配置。
- 现象：嵌入组件的分享图标无法自定义修改，原因：未在`embed_custom_css`中配置图标替换的CSS代码，或未开启自定义样式权限。
- 现象：分享链接的访问日志无法查询，原因：未开启`share_log_enabled`配置项，或未启用系统日志存储功能。

## 怎么确认配好了
- 打开预设的分享链接，检查缓存过期提示是否与配置的`share_cache_ttl`匹配，确认内容未展示过时数据。
- 将嵌入代码插入测试页面，调整页面布局，确认嵌入组件的高度适配数据篇幅，无内容溢出。
- 切换至匿名访问模式，查看嵌入展示的字段是否附带单位标注，确认`embed_show_unit`配置生效。
- 进入系统后台日志模块，查询分享链接的访问记录，确认`share_log_enabled`配置已生效。
