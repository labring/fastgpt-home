# 水务收益率的工具调用与插件

## 这个品类的数据长什么样
水务收益率与行情数据主要来自属地水务主管部门的公开运营报表、第三方公用事业行业数据接口以及水务企业的内部运营系统。数据更新节奏为每日更新前一日的运营快照，每周汇总周度收益情况，每月出具完整月度报告。单条数据的文档结构包含主体编码、统计日期、供水单价、污水处理收费标准、运营成本占比、运营收益净额等字段，各字段单位分别为字符串、YYYY-MM-DD格式、元/立方米、元/吨、比例系数、万元，无额外未标注的统计数值。

## 这些特征在「工具调用与插件」这一环带来什么约束
水务数据的多源属性要求插件支持多种鉴权方式，适配官方接口的API_KEY鉴权与内部系统的token鉴权。固定的字段结构与单位要求工具调用时必须严格匹配预设的字段映射规则，避免因字段名或单位不匹配导致数据解析失败。日更的更新节奏要求定时任务需设置在数据汇总完成后触发，同时需控制调用频率，避免触发第三方接口的限流规则。专业计量维度的字段则要求插件内置基础的单位校验逻辑，确保拉取的数据符合业务规则。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_request_timeout` | 300 秒 | 适配多数第三方公用事业数据接口的响应延迟区间 |
| `schedule_trigger_cron` | `0 0 2 * * *` | 匹配水务数据每日凌晨1点前完成汇总的节奏，提前1小时触发拉取 |
| `field_mapping_strategy` | 按专属水务字段映射 | 适配水务日报固定的字段结构，避免通用映射导致的字段不匹配 |
| `data_cleaning_threshold` | 0.8 | 用于过滤异常数据的匹配阈值，适配水务数据的正常波动区间 |
| `plugin_auth_type` | 优先API_KEY鉴权 | 适配多数第三方公用事业数据接口的标准鉴权方式，支持内部系统扩展 |
| `max_request_retries` | 3 次 | 应对接口临时限流，避免重复请求触发更严格的限制规则 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用插件返回`401 Unauthorized`错误，提示需使用app key，不可使用账号密钥。原因：未在插件鉴权配置中正确填写应用级别的app key，误将账号登录的token作为鉴权参数传入。
- 现象：生成的SQL查询语句无法匹配水务数据的专属字段，返回空查询结果。原因：未针对水务数据配置专属字段映射，沿用了通用品类的字段映射逻辑。
- 现象：定时拉取的水务数据出现大量异常值，导致后续播报内容出错。原因：未设置数据清洗阈值，未过滤掉超出正常波动区间的异常数据。

## 怎么确认配好了
- 手动触发一次插件调用，查看返回结果的字段是否与配置的映射规则完全匹配，无缺失或错误映射的字段。
- 检查插件的鉴权日志，确认请求携带的是应用级别的app key，未携带账号登录的token。
- 验证定时任务的触发时间，确认设置的时间晚于水务数据的每日汇总完成节点。
- 运行一次数据清洗测试，确认过滤逻辑可以识别并标记超出正常范围的异常数据。
