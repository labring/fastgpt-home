# 水务收益率的表单与交互

## 这个品类的数据长什么样
水务收益率相关数据主要来自水务企业内部生产调度系统、财务ERP模块，以及当地市政供水主管部门公开的定价备案数据。数据更新节奏为每日凌晨生成前一日的全量汇总文档，文档采用结构化格式，包含统计日期、供水总规模、实际售水量、单位供水生产成本、售水总营收、污水处理补贴收入、管网损耗占比、总运营成本、可分配收益额度等字段，各字段对应单位为立方米、元、万元等标准化计量值。

## 这些特征在「表单与交互」这一环带来什么约束
水务数据的多来源属性要求表单需支持对接多个内部系统的数据源，需配置支持跨系统数据源对接的控件。每日更新的节奏要求表单默认加载前一日数据，且需限制日期选择范围为单日，避免拉取多日数据导致混淆。字段数量较多且与运营流程强绑定，需将表单拆分为基础统计、成本核算、营收构成、收益评估四个模块，减少用户操作负担。标准化的单位要求表单预设固定单位控件，禁止用户自定义输入，防止单位不统一引发的数据错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_call_required` | `true` | 水务收益率数据需从多系统拉取，必须触发工具调用获取真实数据，禁止AI直接生成 |
| `max_context_tokens` | `8000–12000` | 水务数据字段完整，需保留足够上下文避免截断关键报表字段 |
| `rag_recall_count` | `前6条` | 水务日报的关联文档通常为近7日运营报表，召回6条可覆盖全量关联数据且无冗余 |
| `form_field_unit_lock` | `开启` | 水务数据单位为标准化计量值，锁定可避免用户输入错误单位 |
| `date_picker_default_range` | `昨日至昨日` | 日报场景默认加载前一日完整数据，符合业务使用习惯 |
| `tool_call_timeout` | `30 秒` | 水务数据需从多个内部系统同步，30秒可覆盖多数同步场景，避免超时失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用`get_water_income_report`工具时返回`400 Bad Request`，AI未触发工具直接生成内容。原因：未配置`tool_call_required`为`true`，导致AI可自主选择是否调用工具。
- 现象：设置`rag_recall_count`时，可选值仅为固定档位，无法输入自定义数值。原因：未开启自定义召回条数的配置开关，系统仅开放预设的固定选项。
- 现象：配置字符串匹配规则时，选择“等于”或“开始为”触发ELSE分支，选择“包含”或“结束为”触发IF分支。原因：未将判断逻辑与水务结构化数据的字段格式匹配，水务收益率字段多为标准化数值，需使用“等于”规则，不使用模糊匹配。

## 怎么确认配好了
- 触发工具调用测试，检查是否自动调用预设的水务数据拉取工具，不直接生成内容，确认`tool_call_required`配置生效。
- 打开表单配置页面，检查各数据字段的单位是否为预设的固定值，确认`form_field_unit_lock`配置已开启。
- 选择日期选择控件，检查默认加载的日期范围是否为前一日，确认`date_picker_default_range`配置正确。
- 调整召回条数的输入框，检查是否可输入任意正整数，不使用固定档位，确认自定义召回配置已开启。
