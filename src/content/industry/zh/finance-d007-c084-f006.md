# 水处理收益率的对话日志与审计

## 这个品类的数据长什么样
水处理收益率与行情数据主要来自工业水处理系统的运行日志、市政污水处理/供水的在线监测平台，以及第三方环保合规数据接口。日度收益率与行情数据每日凌晨完成全量更新，实时运行参数每15分钟同步一次。单条数据文档包含监测点位唯一标识、处理环节类型、当日产水总量、药剂投加总成本、达标处理量等字段，单位分别为立方米、元、立方米。数据按监测点位与处理环节进行分组归档，单批次数据覆盖当日全流程核算参数。

## 这些特征在「对话日志与审计」这一环带来什么约束
多数据源接入要求日志需区分本地生成与外部接口拉取的不同类型，审计环节需记录每个接口的调用状态与返回结果。高频率实时数据会产生大量日志条目，需按固定时间片进行分片归档，避免单日志文件体积过大影响查询效率。核心字段包含合规审计所需的监测点位与处理量信息，审计环节需校验字段完整性与格式正确性，确保数据可追溯。此外，水处理数据关联环保合规要求，日志需具备不可篡改属性，保障审计过程的可信度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `AUDIT_LOG_RETENTION_DAYS` | `180 天` | 满足环保审计的常规留存周期要求 |
| `external_api_log_enable` | `开启` | 记录外部监测平台与数据接口的调用日志，匹配多数据源特征 |
| `log_shard_interval` | `1 小时` | 适配实时数据每15分钟的更新频率，避免单日志文件过大 |
| `audit_field_whitelist` | `["monitor_point_id", "treatment_process", "daily_production_volume", "chemical_dosage_cost", "qualified_treatment_volume"]` | 仅保留审计所需的核心字段，过滤冗余信息 |
| `LOG_ENCRYPT_ENABLE` | `开启` | 保障日志不可篡改与数据隐私合规 |
| `MAX_SESSION_HISTORY` | `前 20 条对话` | 平衡对话上下文完整性与日志存储压力 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：升级至4.9.0及以上版本后，刷新对话页面显示新对话，但后台日志可查看历史记录。原因：未开启`session_log_sync`配置，导致前端会话日志未同步至本地存储。
- 现象：界面提示“没有权限操作此对话记录”。原因：未在`audit_field_whitelist`中配置当前对话关联的监测点位ID字段，导致权限校验逻辑无法通过。
- 现象：免登录对话窗口无历史记录，但后台日志存在对应条目。原因：未开启`LOG_ENCRYPT_ENABLE`配置，导致加密后的日志无法在免登录前端正常解密加载。

## 怎么确认配好了
- 登录系统后台的日志管理页面，查看`AUDIT_LOG_RETENTION_DAYS`的当前取值，确认与预设留存要求匹配。
- 发起一次关联水处理监测数据的对话，检查后台日志是否完整记录了接口调用、参数校验与结果返回的全流程。
- 进入免登录对话界面，查询历史对话，确认可正常加载已生成的日志条目。
- 尝试操作非本人创建的对话，确认界面弹出权限校验提示。
