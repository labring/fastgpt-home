# 水泥收益率的工作流编排

## 这个品类的数据长什么样
水泥行情数据主要来源于全国建材流通协会、大宗商品电子交易平台，更新节奏为每日17:00左右发布当日文档。文档采用标准化结构化表格形式，包含不同规格标号的水泥出厂价、区域现货报价、对应期货合约结算价等内容，字段涵盖水泥标号、产地、报价数值，单位统一为元/吨。

## 这些特征在「工作流编排」这一环带来什么约束
水泥行情数据的标准化表格格式，要求工作流首环节配置专用的结构化表格解析节点，精准提取指定字段。每日固定更新的节奏，要求工作流配置定时触发节点，匹配行业数据发布的固定时间窗口。多规格标号与区域划分的字段特征，要求工作流增加分组处理环节，按维度拆分数据批次。报价单位固定为元/吨的属性，要求工作流配置单位校验规则，过滤异常单位的字段内容。数据规模随覆盖区域扩展的特点，要求工作流配置合理的批量处理阈值，避免节点过载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发时间` | `每日17:30` | 水泥行情数据在每日17:00后更新，预留30分钟数据同步窗口 |
| `文档解析模式` | `结构化表格解析` | 水泥行情文档为标准化表格格式，可精准提取指定字段 |
| `分组字段` | `水泥标号、产地` | 不同标号、产地的水泥报价差异显著，需按维度拆分处理 |
| `maxContext` | `800-1200 字符` | 单条水泥行情数据的文本长度集中在该区间，避免上下文溢出 |
| `知识库召回条数` | `前3条` | 水泥行业政策、成本数据的相关性较强，少量召回即可覆盖核心参考信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | 批量处理多区域行情文档时，解析耗时较长，预留充足超时时间 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流中纯文本行情数据被错误送入多模态模型处理。原因：未配置数据类型分流节点，未按文本与多模态划分输入链路。
- 现象：工作流执行时提示知识库召回上限不足，返回结果条数少于预期。原因：未根据水泥行情数据的字段数量调整工作流内知识库搜索的引用上限，沿用通用配置的数值。
- 现象：工作流触发后长时间无响应，最终触发超时报错。原因：未设置合理的批量处理阈值，一次性加载过多区域的水泥行情文档，超出节点处理能力。

## 怎么确认配好了
- 查看工作流的定时触发配置，确认触发时间晚于行业行情数据的官方更新节点，可通过模拟触发验证数据时效性。
- 执行单条数据的测试运行，检查解析后的字段是否完整覆盖所需的水泥行情核心信息。
- 查看工作流运行日志，确认数据按类型正确分流至对应处理节点，未出现错误路由的情况。
- 调整测试数据的覆盖范围，核对节点处理的返回结果是否符合预设的约束规则。
