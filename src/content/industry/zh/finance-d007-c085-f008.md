# 水泥收益率的工具调用与插件

## 这个品类的数据长什么样
水泥的现货收益率相关数据来源为国内建材现货交易监测平台、全国水泥行业协会的公开统计端口，更新节奏为每日早间8点更新前一日的区域现货价格及交易数据。数据以结构化JSON或CSV格式提供，包含区域编码、水泥标号、散装/袋装类型、单位售价、当日交易量、库存余量等字段。单位售价的单位为元/吨，交易量单位为吨，库存余量单位为万吨。数据会按行政区域进行分区存储，不同区域的同标号水泥价格差异明显。

## 这些特征在「工具调用与插件」这一环带来什么约束
每日固定更新的节奏要求工具调用需匹配固定定时触发周期，避免高频请求导致的接口限流。多维度的筛选字段要求插件需支持传入区域、标号、包装类型等参数，否则返回数据会包含大量冗余内容，无法直接用于日报播报。结构化数据但字段格式存在差异的特点，要求配置数据解析规则，将原始字段映射为统一的输出格式。依赖第三方公开接口的属性，要求配置认证参数以完成接口访问权限校验，同时需处理接口返回的异常状态码。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `trigger_schedule` | `0 8 * * *` | 匹配水泥现货数据每日早间8点的更新周期，确保拉取到最新的有效数据 |
| `request_header_auth` | `{"Authorization": "Bearer ${API_KEY}"}` | 多数建材监测接口采用Bearer Token认证规范，符合行业通用接口要求 |
| `request_timeout` | `30 秒` | 接口响应通常在10-25秒区间，预留合理缓冲时间避免超时失败 |
| `filter_params` | `["region_code", "specification", "pack_type"]` | 水泥数据存在多维度差异，精准筛选可减少冗余数据，适配日报播报的核心需求 |
| `rate_limit_interval` | `60 秒` | 多数监测接口设置每分钟10次的访问上限，设置间隔可避免触发限流规则 |
| `data_parse_rule` | `按region、specification分组，提取unit_price、inventory字段` | 匹配日报播报的核心数据维度，简化后续内容整理流程 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用接口返回`401 Unauthorized`状态码，接口返回空数据。未正确配置`request_header_auth`参数，未携带符合要求的认证头信息。
- 工具调用返回的水泥数据包含多个区域和标号的冗余内容，无法直接用于日报播报。未配置`filter_params`参数，未对返回数据进行精准筛选。
- 工作流执行时频繁触发超时报错，工具调用任务失败。未设置合理的`request_timeout`或`rate_limit_interval`，超过接口响应时间或触发访问限流。

## 怎么确认配好了
- 手动触发工具调用，查看返回的原始数据是否包含预设的筛选字段，核对区域、标号等参数是否生效。
- 检查工作流日志，确认接口请求的头信息中包含正确的认证参数，无4xx或5xx状态码。
- 等待定时任务触发一次，核对生成的日报数据是否与预期的维度一致。
- 连续触发3次工具调用，查看是否触发限流报错，确认请求间隔设置符合接口要求。
