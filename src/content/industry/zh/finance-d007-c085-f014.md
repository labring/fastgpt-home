# 水泥收益率的表单与交互

## 这个品类的数据长什么样
水泥收益率相关数据的来源为建材行业监测机构、全国性大宗商品现货交易市场的公开报价信息。更新节奏为每日更新一次，在当日交易结束后固定时段发布。单条数据文档包含水泥标号、供应区域、当日交易均价、前一交易日交易均价、当日交易总量五个核心字段。交易均价的单位为元/吨，交易总量的单位为吨，数据未包含百分比类的变动比例表述。

## 这些特征在「表单与交互」这一环带来什么约束
每日固定更新的数据源要求表单的检索触发时间需匹配行业数据源的发布节点，避免返回未更新的旧数据。细分的水泥标号与供应区域字段，要求表单需支持多维度筛选，且筛选选项需与数据源的分类维度完全对齐，否则无法返回精准结果。明确的字段结构要求表单的输出字段需固定匹配数据源预设结构，避免出现字段缺失或错位。数据的分类维度较多，要求表单的批量查询需限制单次请求的范围，避免接口过载影响交互体验。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `RETRIEVE_TOP_N` | `前8条` | 水泥数据按区域和标号拆分后，单批次有效数据量适中，前8条可覆盖主流供应区域与常用标号 |
| `SIMILARITY_THRESHOLD` | `0.72–0.78` | 水泥数据的字段匹配精度要求较高，该区间可过滤无关报价数据 |
| `FORM_FIELD_REQUIRED` | `["标号", "区域"]` | 数据源仅按标号和区域分类，缺失任一维度无法精准检索 |
| `SCHEDULED_RETRIEVE_TIME` | `每日18:40` | 匹配行业数据源在当日18:00前完成更新的发布节奏，确保返回最新数据 |
| `CHAT_INPUT_VALIDATION` | `仅允许预设标号与区域选项` | 避免用户输入未收录的分类，导致检索失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：表单提交后返回`{"message": "common:core.chat"}`错误，原因：未正确配置知识库切换的权限参数，导致无法匹配指定的水泥报价知识库。
- 现象：开源版4.8.17中，循环体执行下标加1后返回null，原因：未在表单的循环配置中启用变量自增的初始值设置，导致下标未完成初始化。
- 现象：用户选择跳过知识库检索的选项后，表单无响应，原因：未在交互配置中为跳过选项绑定对应的触发逻辑，导致请求未被正确路由。

## 怎么确认配好了
- 提交包含预设水泥标号与供应区域的测试请求，核对返回数据的字段与数据源的预设结构是否一致。
- 调整相似度阈值的取值，验证检索结果的匹配精度是否符合业务需求。
- 触发定时刷新任务，核对返回数据的更新时间是否匹配行业数据源的发布节点。
- 测试用户选择跳过检索的交互逻辑，验证表单是否正确执行对应路由。
