# 油服工程收益率的部署与升级

## 这个品类的数据长什么样
油服工程收益率相关数据的来源为企业内部作业台账系统、油气生产监控平台及大宗商品行情接口；更新节奏为每日T+1更新前一日全量作业数据；单条数据文档结构包含作业区块编码、项目编号、作业班组、直接成本、服务产出量、基准油价参考值等字段；字段单位包括元、立方米、工作日等，无百分比类统计值。

## 这些特征在「部署与升级」这一环带来什么约束
多源数据接入的需求要求部署阶段配置跨系统的权限对接参数，避免数据同步时出现权限不足的问题；每日T+1的更新节奏要求定时同步任务的触发窗口匹配业务低峰期，防止与作业系统的高峰时段冲突导致数据同步失败；字段多且包含多维度业务标识的特征，要求部署时配置准确的向量索引字段映射，确保后续语义召回的精准性；数据量随项目规模波动的特点，要求升级阶段可灵活调整向量库的分片策略，适配不同规模的业务数据增长。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `SYNC_CRON` | `0 2 * * *` | 匹配油服工程日报T+1的更新节奏，在业务低峰期执行同步，避免干扰正常作业 |
| `EMBEDDING_MODEL` | `qwen3-embedding-8b` | 适配油服工程结构化业务字段的语义编码需求，支持多维度字段的关联召回 |
| `MAX_SYNC_RECORDS_PER_RUN` | `5000 条` | 匹配单日报文的平均数据量，避免单次同步任务因数据量过大触发超时限制 |
| `VECTOR_DB_SHARD_COUNT` | `按实测标定` | 适配油服项目规模波动的数据量，避免分片配置不合理导致查询或同步卡顿 |
| `DATA_SOURCE_AUTH_TYPE` | `OAuth2 + API Key 双验证` | 适配多系统数据源的权限对接要求，保障数据访问的安全性与合规性 |
| `PARSE_FIELD_MAPPING` | `作业区块→区块编码, 项目编号→项目ID, 直接成本→成本字段` | 匹配油服工程数据的原生字段命名规则，确保索引字段与业务数据准确对应 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 登录系统后出现`{"code":500,"message":"URI malformed"}`报错，该问题在FastGPT v4.9.11版本中较为常见，原因是未正确配置数据源的URI格式，混入了未转义的特殊符号或非法字符。
- 容器启动后无法访问前端页面，该问题在云服务器部署场景中偶有出现，原因是未正确配置容器端口映射，或宿主机上的目标端口已被其他进程占用。
- 系统默认root账号密码每日自动重置为123456，原因是未修改初始化配置中的测试环境自动重置开关，启用了非生产环境的默认重置机制。

## 怎么确认配好了
- 查看系统定时任务日志，确认配置的同步周期有对应的执行记录。
- 手动触发一次数据同步任务，检查同步结果中是否包含油服工程作业的全量配置字段。
- 测试向量检索功能，输入作业相关关键词，确认召回结果的字段与配置的映射规则一致。
- 检查容器端口映射状态，确认前端访问端口未被占用且配置正确。
