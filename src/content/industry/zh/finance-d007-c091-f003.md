# 消费建材收益率的分享与嵌入

## 这个品类的数据长什么样
消费建材的收益率与行情数据主要来自建材流通领域的批发零售监测系统、线下经销商进销存台账、线上电商平台的商品定价与销量数据。线下渠道数据按周更新，线上电商平台的单品数据按日更新，核心热门单品的实时报价每小时更新。数据文档为结构化表格格式，字段包含品类名称、规格型号、出厂单价、批发单价、零售单价、进销差价、周度价格波动值，所有单价与差价均以人民币为计价单位。

## 这些特征在「分享与嵌入」这一环带来什么约束
数据的分层更新节奏要求嵌入组件需支持自定义刷新周期，避免高频调用接口导致资源占用过高，或低频更新导致数据滞后。多字段与固定计价单位要求嵌入配置需支持字段筛选与单位统一展示，避免出现单位混淆或冗余信息。多规格单品的特征要求嵌入组件需支持按品类、规格参数筛选数据，适配不同场景下的展示需求。多数据源聚合的特性要求嵌入时需配置数据缓存时长，平衡实时性与接口调用的频率限制。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `iframeShowCite` | `关闭` | 匹配消费建材行情播报的简洁展示需求，避免引用内容干扰核心数据阅读 |
| `embedCacheTime` | `3600 秒` | 匹配核心单品每小时更新的实时报价节奏，平衡数据时效性与接口调用频率 |
| `shareExpireTime` | `7 天` | 适配消费建材周度更新的线下渠道数据，避免过期链接影响团队协作流转 |
| `embedFilterFields` | `品类名称、批发单价、零售单价、进销差价` | 仅展示用户核心关注的收益率相关字段，精简嵌入内容 |
| `iframeShowHistory` | `开启` | 4.9.1及以上版本需开启该配置，确保免登录窗口可展示历史记录 |
| `iframeMaxHeight` | `600–800 像素` | 适配多字段展示的常规页面布局，避免内容溢出或留白过多 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：iframe嵌入后仍展示引用来源内容。原因：未将`iframeShowCite`参数配置为关闭，默认保留了引用展示逻辑。
- 现象：免登录窗口嵌入项目后加载失败，链接显示为本地调试地址。原因：未在平台配置正确的嵌入域名白名单，导致非授权域名的请求被拦截。
- 现象：4.9.1版本的免登录窗口无法查看历史记录，日志中可查询到历史数据。原因：未开启`iframeShowHistory`配置项，或平台版本低于4.9.1导致该功能未生效。

## 怎么确认配好了
- 打开嵌入后的展示页面，核对展示字段是否与配置的筛选项一致，确认无冗余或缺失的信息。
- 触发数据刷新操作，验证更新间隔是否符合预设的缓存时长要求，确认数据更新节奏匹配业务需求。
- 测试免登录访问权限，确认未登录状态下可正常加载内容，且历史记录展示功能正常。
- 调整嵌入组件的容器尺寸，确认展示内容无溢出或过度留白的情况。
