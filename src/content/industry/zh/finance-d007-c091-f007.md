# 消费建材收益率的工作流编排

## 这个品类的数据长什么样
消费建材收益率相关数据主要来自建材流通领域的行情监测平台与区域线下建材交易数据库，更新节奏为每日交易结束后同步当日全量数据，主要服务于金融机构的消费建材领域理财与行情分析需求。单条数据文档按家装细分品类分类聚合，包含品类全称、标准规格型号、生产产地、当日终端成交价、区域均价对比项、渠道利润测算相关的比值类字段，字段单位多为元/平方米、元/米或无量化比值单位，数据按交易区域进一步拆分归档。

## 这些特征在「工作流编排」这一环带来什么约束
消费建材的数据分类维度多且按区域拆分，要求工作流必须先配置品类过滤节点，限定处理目标细分建材品类，避免冗余数据干扰后续计算。数据更新节奏为每日一次，要求工作流触发时机固定为每日交易结束后的固定时段，不宜设置高频触发。字段单位存在差异，要求工作流中需加入统一单位转换步骤，对齐后续收益率计算的基准格式。多源数据聚合的需求，要求工作流配置多数据源拉取节点，并增加数据去重步骤，确保单条记录的唯一性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `cron` | `0 30 18 * * ?` | 消费建材当日交易数据多在18点前完成归集，该定时触发时机可确保拉取到完整当日数据 |
| `category_filter` | `瓷砖、防水涂料、塑料管材` | 消费建材细分品类较多，限定目标品类可过滤冗余数据，提升工作流运行效率 |
| `unit_conversion_rule` | `统一转换为元/平方米` | 多数消费建材的终端成交价以平方米为计价基准，统一单位可简化后续收益率计算逻辑 |
| `batch_size` | `50 条/次` | 单批次处理数据量过大易导致节点超时，该取值可平衡处理效率与运行稳定性 |
| `timeout` | `600 秒` | 多源数据拉取与格式转换的总耗时通常不超过10分钟，该阈值可覆盖正常处理流程 |
| `global_variable_default` | `按实测标定` | 全局变量的初始值需匹配目标区域的默认参数，不同区域的基准参数存在差异 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流文本生成节点的输出中，保留`{{var_name}}`格式的变量占位符，未替换为实际数据。原因：未在节点配置中开启变量自动替换功能，或使用了不符合系统规范的变量引用语法，导致系统无法识别占位符。
- 现象：工作流执行至工具调用节点时直接报错，运行状态显示为失败。原因：全局变量未设置初始值，或变量更新后未同步至工作流节点，导致工具请求缺失必要的参数信息。
- 现象：工作流处理后返回的消费建材数据包含无关品类的记录，与预设的目标品类不符。原因：未在数据拉取节点前配置品类过滤规则，或过滤规则的匹配逻辑存在偏差，导致冗余数据被纳入处理流程。

## 怎么确认配好了
- 手动触发一次工作流，核对运行起始时间与配置的`cron`表达式是否一致，确认首次执行符合预期。
- 查看工作流的运行日志，确认文本生成节点的输出中，所有变量占位符均已替换为实际数据内容。
- 检查工具调用节点的返回结果，确认拉取的数据仅包含预设的目标消费建材品类，无无关品类的记录。
- 连续执行3次以上的测试运行，确认工作流全流程无超时或报错，运行结果符合配置要求。
