# 游戏收益率的分享与嵌入

## 这个品类的数据长什么样
游戏收益率日报的数据来源为游戏厂商内部运营系统、第三方游戏数据聚合接口。更新节奏为每日凌晨固定时段更新前一自然日的全量数据。文档结构为结构化数据集，每条记录包含游戏唯一编码、当日营收达成率、活跃用户数达成率、付费用户占比达成率等字段。字段单位为相对预设基准的倍数，不使用百分比标识，数据体量适中，单条记录字段数量固定。

## 这些特征在「分享与嵌入」这一环带来什么约束
每日固定更新的全量数据要求分享链接的缓存时效需匹配更新周期，避免返回过期的前一日数据。结构化字段包含多类达成率指标，嵌入环节需支持自定义字段筛选，适配不同场景的信息展示需求。数据依赖外部接口拉取，嵌入时需配置跨域白名单，防止浏览器基于安全策略拦截请求。游戏唯一编码用于定向拉取特定游戏数据，分享链接需携带该参数且需做合法性校验，防止越权访问非授权游戏的数据。此外，日报数据的更新频率固定，嵌入组件的刷新机制需支持按日触发或手动触发，避免频繁请求浪费接口资源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `share_enable_auth` | 开启 | 游戏运营数据通常包含非公开信息，需限制访问主体 |
| `share_expire_seconds` | `86400 秒` | 匹配游戏日报每日更新的周期，确保返回最新前一日数据 |
| `iframe_allowed_domains` | 业务部署的合法域名列表 | 限制iframe嵌入的来源，防止未授权域名调用数据接口 |
| `api_request_timeout` | `15 秒` | 适配游戏数据接口的常规响应时长，避免因网络波动导致请求失败 |
| `custom_share_fields` | 勾选营收、活跃用户、付费转化相关字段 | 匹配游戏日报的结构化字段特征，聚焦核心展示内容 |
| `share_cache_ttl` | `3600 秒` | 平衡数据时效性与接口负载，避免频繁拉取全量数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：分享链接访问时返回403 Forbidden状态码，原因：未开启`share_enable_auth`配置但接口强制校验鉴权信息，导致无权限访问数据。
- 现象：通过iframe嵌入后页面显示空白，直接访问分享链接正常，原因：未配置`iframe_allowed_domains`白名单，浏览器跨域策略拦截了嵌入请求。
- 现象：分享页面展示的字段与预期不符，包含大量非核心数据，原因：未通过`custom_share_fields`配置指定需要展示的字段，默认加载了全量字段。

## 怎么确认配好了
- 复制生成的分享链接，在未登录的浏览器中打开，核对是否按照配置要求展示指定字段或需要鉴权，确认鉴权与字段配置生效。
- 在业务部署的合法域名下编写测试iframe嵌入代码，嵌入分享链接，核对页面是否正常加载无报错，确认跨域配置生效。
- 修改`share_expire_seconds`参数的取值，等待对应时长后再次访问分享链接，核对是否无法访问或返回过期提示，确认过期配置生效。
- 调用数据拉取接口，核对返回结果仅包含`custom_share_fields`中勾选的字段，确认自定义字段配置生效。
