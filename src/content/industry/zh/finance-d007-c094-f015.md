# 炼化收益率的部署与升级

## 这个品类的数据长什么样
炼化收益率日报的数据来源包括炼化企业内部的生产执行系统（MES）、大宗商品交易行情接口、财务核算ERP系统。数据更新节奏为每日更新前一自然日的全量数据，通常在当日24点前完成内部核算后对外发布。数据文档以结构化表格为主，辅以少量文本说明，核心字段包含各生产装置的运行参数、原料采购成本、各终端产品的出厂报价、单位毛利值，单位多为元/吨、吨/小时等实物计量与财务计价单位，无百分比类统计字段。

## 这些特征在「部署与升级」这一环带来什么约束
炼化收益率日报的多源数据特性，要求部署阶段配置适配不同数据源的解析规则，避免跨系统的字段映射错误。日更的更新节奏，要求部署定时触发的同步任务，且需匹配行业数据的当日核算窗口，确保拉取的是完整的前一日数据。结构化字段较多的特性，要求配置字段校验规则，过滤异常空值与格式错误的数据。升级过程中需保留原有的数据源配置与定时任务规则，避免因版本变更导致数据同步中断或格式不兼容，同时需提前验证新版本与现有数据格式的兼容性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DATA_SYNC_CRON` | `0 1 0 * * *` | 炼化行业的当日生产与财务数据通常在当日24点前完成核算，提前1分钟触发同步可确保获取完整的前一日数据 |
| `PARSE_STRUCTURED_DATA` | `开启` | 炼化日报数据多为标准化表格格式，开启结构化解析可自动匹配字段与播报内容的对应关系 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 炼化日报可能包含多装置的月度历史数据附件，单文件体积通常大于通用场景的默认限制 |
| `SYNC_DATA_TIMEOUT` | `1200 秒` | 多源数据拉取、清洗与汇总的处理流程耗时较长，避免同步任务中途超时中断 |
| `SYNC_DATA_RETRY_TIMES` | `3次` | 多源数据源可能存在临时波动，多次重试可确保数据同步成功率 |
| `AUTO_VERSION_UPDATE` | `关闭` | 炼化场景的播报逻辑需与数据格式强绑定，自动升级可能引入不兼容的配置变更 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用播报功能时返回`model not found`报错，原因：未在部署环境中配置对应模型的API密钥与接口地址，或使用的FastGPT版本未适配目标模型。
- 现象：升级版本后定时同步任务无法正常触发，界面返回`500 Internal Server Error`，原因：升级过程中未保留原有的`DATA_SYNC_CRON`配置项，或新版本的配置文件格式发生变更未做适配。
- 现象：修改本地代码后部署无变化，页面显示旧版内容，原因：未将本地修改的代码同步至部署服务器的对应目录，或未重启FastGPT服务加载新代码。

## 怎么确认配好了
- 执行手动数据同步任务，查看同步日志，确认无超时、字段缺失类异常记录。
- 进入FastGPT的模型配置界面，确认目标模型的API密钥与接口地址已正确填写。
- 查看定时任务的执行记录，确认最近一次同步任务已在预设时间完成。
- 修改本地测试代码后，同步至部署目录并重启服务，验证页面内容是否更新。
