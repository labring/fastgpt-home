# 热力收益率的分享与嵌入

## 这个品类的数据长什么样
属于金融领域公用事业板块的热力行业收益率与行情日报数据，来源于公用事业行业监测平台与热力企业内部运营系统，更新节奏为每日更新前一自然日的汇总数据。文档采用分层结构化格式，按行政区划、供热单元逐级分组。字段包含区域标识、供热单元编号、当期收益核算值、同期基准参考值、数据采集时间戳，其中收益核算值与基准参考值采用热力行业通用运营核算单位，无固定百分比类量化标识。

## 这些特征在「分享与嵌入」这一环带来什么约束
这些特征在分享与嵌入环节带来明确的落地约束。每日固定更新的节奏要求嵌入后的组件需配置自动刷新机制，或设置较短的缓存过期时间，避免展示过期的前一日数据，影响信息时效性。分层结构化的文档结构要求分享链接或嵌入参数需支持指定展示层级，例如仅展示省级区域汇总数据或单个供热单元的明细数据，确保分享内容匹配接收方的查看需求。字段间的基准关联逻辑要求嵌入配置需保留字段映射关系，避免拆分展示孤立的核算值，影响数据可读性。同时，公用事业数据的严谨性要求嵌入代码需携带源数据标识参数，确保接收方可追溯数据来源与更新时间。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `iframe_cache_ttl` | `300–3600 秒` | 匹配每日更新的节奏，避免缓存过期或频繁请求 |
| `share_data_level` | `station 或 district` | 适配热力数据按供热单元、区域分层的文档结构 |
| `data_source_tag` | `heat_utility_market` | 标识数据源类型，满足数据溯源要求 |
| `auto_refresh` | `enabled` | 同步每日更新的特性，确保嵌入内容实时更新 |
| `guest_embed_mode` | `enabled` | 支持免登录分享嵌入，适配公开分享场景 |
| `stream_output_switch` | `disabled` | 日报为批量静态数据，无需流式输出 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：嵌入iframe后浏览器控制台出现`Set-Cookie`拦截报错，网络请求返回`401 Unauthorized`状态码。原因：未开启`guest_embed_mode`配置，或未设置跨域兼容的缓存参数，导致会话权限校验失败。
- 现象：免登录分享窗口打开后，未返回预期的流式播报内容，仅展示静态打包文本。原因：误将`stream_output_switch`配置为`disabled`，或未在嵌入参数中开启流式输出开关。
- 现象：嵌入后的热力数据长时间未更新，仍展示多日前的旧数据。原因：将`iframe_cache_ttl`设置为超出数据更新周期的取值，未匹配每日更新的数据源节奏。

## 怎么确认配好了
- 打开嵌入代码的预览链接，检查页面顶部是否显示配置的`data_source_tag`标识，确认数据源溯源信息正常。
- 调整`share_data_level`参数值，验证页面展示的热力数据层级是否符合预期，例如切换至区域层级或供热单元层级。
- 等待一个数据更新周期后刷新嵌入页面，确认数据已更新至最新的采集时间戳，验证自动刷新或缓存配置生效。
- 打开浏览器开发者工具的网络面板，检查iframe请求的`Set-Cookie`响应头是否正常返回，确认会话权限配置正确。
