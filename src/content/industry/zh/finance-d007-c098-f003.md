# 煤化工收益率的分享与嵌入

## 这个品类的数据长什么样
煤化工收益率相关行情数据的数据源主要来自国内煤炭深加工行业协会公开行情库、期货交易所官方行情接口、大宗商品现货交易平台数据接口。数据更新节奏分为三类：现货成交数据每日收盘后更新，期货交易数据随交易时段实时推送，行业统计数据每周或每月更新。单条标准数据文档包含品种编码、品种名称、发布时间、基准价格、当日成交均价、周度平均价格、月度累计成交量字段，单位分别为无、中文名称、ISO 8601格式时间戳、元/吨、元/吨、元/吨、万吨。数据文档无预设百分比类字段，所有变动值以绝对数值呈现。

## 这些特征在「分享与嵌入」这一环带来什么约束
煤化工品类覆盖甲醇、烯烃、尿素等多个细分品种，且数据更新频率差异较大，分享嵌入环节需适配多品种筛选与高频更新需求。高频实时的期货数据要求分享链接与嵌入组件支持定时刷新，避免展示过时内容；多品种的字段结构要求分享页面支持参数化筛选，否则全量数据会导致界面杂乱。此外，煤化工行业从业者多使用中文术语，分享界面的语言适配需匹配行业使用习惯，同时团队场景下需支持多业务线创建多个分享链接，避免数量限制影响业务开展。数据的多单位字段也要求嵌入配置支持自定义展示单位，避免单位混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `anonymous_share_enabled` | `true` | 煤化工行情数据面向行业从业者，无需强制登录即可查看，开启免登录可降低访问门槛 |
| `share_expire_hours` | `24 小时` | 煤化工现货数据每日更新，24小时过期可确保分享内容始终匹配当日最新行情 |
| `iframe_auto_refresh_interval` | `3600 秒` | 平衡数据时效性与服务器负载，适配现货行情的每日更新节奏 |
| `share_filter_params` | `["product_type", "publish_date"]` | 过滤无关品种与历史数据，仅展示目标煤化工品类的当日行情 |
| `share_language` | `zh-CN` | 匹配国内行业从业者的使用习惯，避免煤化工专业术语的翻译偏差 |
| `max_anonymous_share_links_per_app` | `100` | 适配团队多业务线的分享需求，调整默认10个的数量限制 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：Docker部署的实例重启后，已创建的免登录分享链接无法访问，控制台返回`404 Not Found`状态码。原因：未将分享链接的存储目录挂载到宿主机持久化存储，容器重启后本地存储的链接数据被清空。
- 现象：嵌入的iframe界面默认显示英文术语，煤化工专业名称未匹配行业常用表述。原因：未配置`share_language`参数，系统默认使用英文语言，未指定适配国内行业的中文参数。
- 现象：团队版应用创建超过10个免登录分享链接后，新链接创建失败，界面弹出数量超限提示。原因：未调整团队级别的`max_anonymous_share_links_per_app`配置项，默认限制为10个，未根据业务需求扩容。

## 怎么确认配好了
- 访问已创建的分享链接，检查展示的字段与配置的`share_filter_params`一致，确认仅包含目标煤化工品类的当日行情数据。
- 等待配置的`iframe_auto_refresh_interval`时长后刷新嵌入页面，确认页面数据已更新至最新发布时间。
- 尝试创建超过当前配置的`max_anonymous_share_links_per_app`数量的链接，确认未触发超限提示。
- 手动修改分享链接的`lang`参数为`en`，确认界面文本切换为英文，验证语言配置的有效性。
