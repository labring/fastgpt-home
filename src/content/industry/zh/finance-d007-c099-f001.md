# 燃气收益率的HTTP 接口与外部系统

## 这个品类的数据长什么样
燃气收益率的数据源主要来自全国城市燃气协会公开行情接口、地方能源监管部门的每日报送数据。数据更新节奏为每日滞后自然日12小时左右，完成前一日全量行情的汇总发布。文档结构为标准JSON数组格式，每个元素对应单品类单日收益率数据，包含交易日期、燃气品类编码、采购成本单价、销售单价、累计价差系数等字段。其中采购与销售单价的单位为元/立方米，累计价差系数为无量纲数值，未使用百分比类单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
燃气收益率数据的公开接口需认证访问，因此HTTP接口配置需包含合法的认证参数，否则无法获取有效数据。数据每日更新一次，轮询请求的间隔需匹配更新节奏，避免超出第三方接口的频率限制。字段包含明确的品类编码与单位，请求时需指定品类编码过滤目标数据，解析时需严格遵循单位规则，否则会导致后续计算偏差。全量数据的单次返回量较大，需配置分页拉取参数，避免单次请求过载影响系统稳定性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `external_api_url` | 全国城市燃气协会公开行情接口地址 | 该数据源覆盖国内主流燃气品类，数据权威性符合日报播报的合规要求 |
| `request_interval` | `86400 秒` | 燃气收益率数据每日更新一次，轮询间隔匹配数据更新节奏，避免触发接口频率限制 |
| `request_timeout` | `30 秒` | 第三方燃气行情接口的平均响应时长在10-20秒，预留足够缓冲避免超时失败 |
| `filter_category_code` | 指定目标燃气品类编码，如`LNG001` | 区分不同燃气品类的行情数据，确保拉取的是目标品类的收益率信息 |
| `parse_field_mapping` | 将原始字段映射为`date`/`purchase_price`/`sale_price`/`yield_coeff` | 统一内部数据格式，便于后续知识库调用和日报播报生成 |
| `api_auth_type` | `API_KEY 认证` | 多数官方燃气行情接口采用该认证方式，保障数据访问的合法性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 日志中出现`Api response error: undefined`，状态码返回200但无有效数据。原因是未正确配置`filter_category_code`参数，拉取了无匹配品类的空数据，导致接口返回空内容。
- 外部系统调用后出现`504 Gateway Timeout`报错。原因是将`request_timeout`设置为低于10秒，未匹配第三方接口的实际响应时长。
- 知识库解析燃气行情数据时出现字段缺失或格式错误。原因是未配置`parse_field_mapping`参数，未统一内部数据映射规则，导致后续播报生成异常。

## 怎么确认配好了
- 调用配置好的HTTP接口，检查返回的JSON数据中是否包含配置的`filter_category_code`对应的品类数据。
- 查看接口调用日志，确认`request_timeout`设置的时长大于接口实际响应时长，无超时报错。
- 对比原始数据源的字段与内部映射后的字段，确认`parse_field_mapping`配置正确覆盖了所有必填字段。
- 触发知识库的日报播报生成流程，检查输出内容是否包含正确的燃气收益率相关数据。
