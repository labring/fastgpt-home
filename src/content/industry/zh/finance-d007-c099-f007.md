# 燃气收益率的工作流编排

## 这个品类的数据长什么样
公开的公用事业燃气价格监测平台、区域燃气供应企业的官方披露数据为主要数据源，更新节奏为每日更新一次，于当日10点前发布前一自然日的行情数据。文档结构多为结构化表格文件或标准化JSON接口返回内容，字段包含燃气供应品类、当日交易单价、前一周期交易单价、区域标识、数据发布日期，交易单价的单位为元/立方米。

## 这些特征在「工作流编排」这一环带来什么约束
每日固定更新的数据源要求工作流配置定时触发节点，且触发时间需晚于数据发布时间，避免拉取未生成的当日数据。多区域、多品类的燃气数据存在字段命名差异，需配置字段映射环节统一数据格式。收益率计算依赖当日与前一周期的单价数据，需限定拉取的时间窗口为连续两日，避免混入过期或冗余数据。部分区域可能存在当日无交易的情况，需配置空值分支处理逻辑，防止工作流中断。公开监测平台存在调用频次限制，需设置合理的请求间隔与重试机制。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发周期` | 每日1次，固定触发时间为每日10:30 | 匹配燃气日报的发布节奏，确保拉取前一自然日的完整数据 |
| `数据拉取时间偏移` | 提前10分钟触发 | 预留数据同步的缓冲时间，避免因平台延迟导致拉取空数据 |
| `字段映射规则` | 按「品类/区域/当日单价/对比单价/发布日期」映射 | 统一多数据源的字段差异，适配收益率计算的固定字段需求 |
| `时间窗口范围` | 连续2个自然日 | 限定拉取数据的时间范围，仅获取计算所需的当日与前一日数据 |
| `请求重试次数` | 2次，重试间隔60秒 | 应对公开平台的临时调用限制，减少工作流失败概率 |
| `空值处理分支` | 跳过当前品类/区域的计算，记录日志 | 避免因无交易数据导致工作流中断，保留异常排查依据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：文本内容提取组件返回空结果，仅重新添加同配置组件后可正常提取。原因：组件缓存了历史失败的上下文配置，未正确加载最新的数据源字段映射规则。
- 现象：文本内容提取组件在部分大模型调用时无法获取燃气数据字段，切换大模型后恢复正常。原因：不同大模型的上下文窗口大小与指令遵循能力存在差异，小参数模型无法准确匹配结构化数据的提取规则。
- 现象：工作流中调用对话模型时，无法获取用户输入的行情查询参数。原因：未正确使用系统预设的用户问题变量名，导致参数绑定失败。

## 怎么确认配好了
- 手动触发工作流一次，查看拉取到的燃气数据是否包含预设字段，核对字段映射是否与配置一致。
- 模拟无交易数据的场景，查看工作流是否触发空值处理分支并生成对应日志。
- 切换不同的大模型，验证文本提取组件是否能稳定获取燃气数据字段。
- 检查定时触发的运行日志，确认每日固定时间是否成功拉取数据，无重复或遗漏。
