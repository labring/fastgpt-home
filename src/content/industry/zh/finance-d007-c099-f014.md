# 燃气收益率的表单与交互

## 这个品类的数据长什么样
这个品类的数据主要来自区域燃气交易中心的公开报价、国家能源局地方监管机构的行业监测数据，以及上游燃气供应商的每日结算数据。更新节奏为每日固定时段同步前一交易日的全量数据，单次更新数据量适中。文档结构为结构化表格，包含统计日期、燃气品类名称、挂牌基准价、当日价格变动额、当日交易量、区域供需标注字段，字段单位统一为元/立方米、吨、万立方米，无百分比类指标。

## 这些特征在「表单与交互」这一环带来什么约束
由于燃气数据来源分散且字段命名存在差异，表单需支持多数据源的字段别名映射配置，避免因字段名不匹配导致数据提取失败。因数据为每日更新，表单的自动触发更新周期需设置为每日一次，避免高频请求占用资源。因存在多种单位类型，交互环节需内置单位转换逻辑，支持用户配置目标展示单位，防止引用时出现单位不匹配的问题。同时，燃气品类细分较多，表单需支持品类筛选的下拉选项配置，以及区域维度的过滤参数，确保播报内容匹配目标场景。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `field_mapping_mode` | `自定义映射` | 燃气数据源字段命名不统一，需手动匹配数据源字段与播报所需字段 |
| `update_cron` | `0 2 * * *` | 燃气数据为每日T+1更新，该时段可获取最新完整数据 |
| `unit_conversion_enabled` | `开启` | 燃气数据存在元/立方米、吨等多种单位类型，需统一展示单位以避免混淆 |
| `recall_count` | `前3-5条` | 单批次燃气数据量适中，过多召回会导致播报内容冗余 |
| `category_filter` | `按场景预设品类` | 燃气细分品类较多，需过滤非目标品类的数据以聚焦播报内容 |
| `data_source_whitelist` | `配置官方合规数据源` | 燃气数据需确保来源权威，避免使用非正规数据源导致数据错误 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：知识库变量引用时返回`quote type error`报错。原因：未配置燃气数据的字段映射规则，导致变量引用时无法识别字段的格式类型，不符合平台的变量引用格式要求。
- 现象：自定义数据源配置后调用失败，返回`400 Bad Request`状态码。原因：未将燃气数据的合规数据源加入`data_source_whitelist`配置项，平台拦截了非授权的数据源请求。
- 现象：表单生成的播报内容中单位混乱，同时出现元/立方米与吨的展示。原因：未开启`unit_conversion_enabled`配置，未统一转换燃气数据的展示单位，导致交互展示出现不一致。

## 怎么确认配好了
- 手动触发一次数据同步任务，查看返回的结构化数据是否包含预设的燃气相关字段，字段展示单位是否统一。
- 配置变量引用测试用例，验证`quote type error`报错是否不再出现，变量能否正确提取目标燃气数据字段。
- 查看定时任务运行日志，确认每日固定时段是否成功完成数据同步，无超时或异常报错记录。
- 预览表单生成的播报内容，确认仅包含预设的燃气品类与区域数据，无无关字段或混乱单位。
