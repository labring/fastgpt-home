# 特钢收益率的工作流编排

## 这个品类的数据长什么样
特钢收益率与行情数据主要来自国内特钢行业协会、大型特钢生产企业官网及大宗商品现货交易平台。数据更新节奏为每日收盘后1小时内完成当日全品类更新。单份数据文档包含特钢牌号、规格型号、生产产地、当日现货基准价、期货结算价、库存周转天数、当日成交量等字段，单位统一为元/吨，部分细分品类附带工艺参数标注，如淬透性、硬度要求等。

## 这些特征在「工作流编排」这一环带来什么约束
特钢数据多源异构且字段命名不统一，要求工作流中配置多节点并行拉取不同数据源，并添加统一字段映射节点对齐字段名。固定的每日更新节奏要求工作流绑定定时触发规则，且设置合理的超时时间避免错过当日数据更新窗口。细分品类的牌号与规格多样性，要求在数据过滤节点配置基于牌号关键词的筛选规则，仅保留目标特钢品类的行情数据。同时，数据中附带的工艺参数字段需在预处理环节排除，避免干扰收益率计算逻辑。此外，部分特钢品类存在跨数据源的字段缺失情况，要求工作流中配置默认值填充节点，避免后续统计环节出现空值错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发Cron表达式` | `0 19 * * *` | 国内大宗商品行情多在每日17:00-18:00完成当日更新，设置19:00触发可确保获取完整当日数据 |
| `并行数据源拉取节点数` | `2–3 个` | 对接行业协会、现货交易平台两类核心数据源，并行拉取可降低整体执行耗时 |
| `字段映射规则` | 按对接数据源实际字段匹配 | 不同数据源的行情字段命名存在差异，需对齐为统一字段名如`当日现货价` |
| `数据过滤关键词` | `40Cr,65Mn,H13` | 针对目标特钢牌号设置过滤规则，仅保留指定品类的行情数据 |
| `工作流超时阈值` | `600 秒` | 多接口拉取需等待多个响应，设置10分钟超时可覆盖正常拉取时长，避免任务挂起 |
| `输出格式` | `结构化表格` | 收益率日报需清晰展示多维度数据，结构化格式便于后续分发与查看 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流执行后生成的行情报告链接显示为内网IP加端口格式，无法在外网访问。原因：未在文件存储节点配置自定义域名映射规则，默认使用部署环境的内网地址生成链接。
- 现象：工作流中`问题分类`节点无法正确匹配特钢行情相关的查询意图。原因：未导入针对特钢收益率场景的专属分类词库，通用分类规则无法匹配细分领域的专业术语。
- 现象：导入导出工作流配置时出现`$schema`字段相关的语法报错。原因：手动编辑配置文件时修改了`$schema`字段的预设路径，导致配置无法通过FastGPT的格式校验。

## 怎么确认配好了
- 手动触发工作流一次，检查拉取到的数据是否包含目标特钢牌号的行情字段，且字段命名统一。
- 查看工作流执行日志，确认定时触发任务按照预设的Cron表达式按时启动，无超时报错。
- 测试文件上传节点生成的链接，确认可通过外网访问生成的日报文件。
- 提交一条特钢行情相关的测试查询，验证`问题分类`节点的分类结果是否符合预期。
