# 特钢收益率的表单与交互

## 这个品类的数据长什么样
特钢的现货价格、出厂价数据来自国内特钢行业协会的监测数据、钢厂直供的调价台账，以及特钢期货盘面的公开数据。更新节奏存在分层：出厂价数据随钢厂调价实时更新，现货均价数据每日更新，行业整体监测数据每月更新。单条数据文档包含品种编码、规格型号、产地、出厂价、现货均价、库存周转天数等字段。字段单位：出厂价与现货均价以元/吨为单位，库存周转天数以自然日为单位，品种编码为6位字母数字组合，规格型号包含直径、厚度等物理参数。

## 这些特征在「表单与交互」这一环带来什么约束
多源数据的更新节奏存在分层，要求表单支持按时间范围筛选数据，避免用户获取过时或不匹配的行情信息。特钢的规格型号丰富且个性化强，要求表单的规格选择控件支持模糊搜索与联动匹配，降低页面加载与选择成本。多字段的信息结构，要求表单采用分组布局，将价格、规格、库存等字段划分为独立模块，简化用户填写与信息查看流程。不同数据源的权威性差异，要求在交互界面标注数据的采集来源与更新时间，帮助用户区分实时行情与历史监测数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `knowledge_base_select` | 绑定特钢行业专属知识库 | 匹配特钢收益率相关的专属数据源，避免混入通用钢铁品类的无关数据 |
| `max_context_length` | 800–1200 字符 | 适配特钢数据的规格型号、价格信息长度，避免截断关键业务字段 |
| `search_relevance_threshold` | 0.75–0.85 | 过滤低相关的通用钢铁数据，聚焦特钢细分品类的精准匹配结果 |
| `stream_response` | true | 适配实时行情播报的流式输出需求，提升交互响应速度 |
| `parse_timeout` | 300 秒 | 应对多源数据整合时的解析耗时，避免超时中断任务 |
| `form_field_grouping` | 开启 | 将价格、规格、库存等字段分为不同组，简化表单填写与查看逻辑 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用接口设置`stream_response`为`true`时，仅收到部分分段数据，未获取完整结果。原因：未配置结果聚合逻辑，未监听流式返回的`done`状态字段。
- 表单提交后返回空的特钢数据结果。原因：未绑定专属特钢知识库，误选通用钢铁知识库导致数据匹配偏差。
- 表单加载时提示`408 Request Timeout`错误。原因：未调整`parse_timeout`参数，多源数据整合耗时超过默认阈值。

## 怎么确认配好了
- 打开知识库选择控件，确认仅绑定特钢行业专属知识库，未包含其他品类数据源。
- 提交测试表单，选择任意特钢品种与合理时间范围，检查返回结果的字段是否包含特钢专属的规格、产地信息。
- 开启流式响应开关，调用测试接口，确认可以接收到完整的分段数据并聚合为最终结果。
- 查看表单布局，确认价格、规格、库存等字段已按组划分，无重叠或遗漏。
