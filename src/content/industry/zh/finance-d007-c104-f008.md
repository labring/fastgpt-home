# 玻璃收益率的工具调用与插件

## 这个品类的数据长什么样
玻璃收益率相关数据主要来自国内建材现货交易市场公开报价接口、中国建筑玻璃与工业玻璃协会的监测数据库。更新节奏为每个交易日收盘后更新当日核心品类的交易数据，非交易日顺延至下一交易日发布。数据文档为结构化JSON或CSV格式，包含的字段有：玻璃品类名称、厚度规格、产地、当日现货成交价、当日批发指导价、区域供货价，单位为元/重量箱或元/平方米，部分接口会附带近7日的价格波动区间参考数据。

## 这些特征在「工具调用与插件」这一环带来什么约束
玻璃数据的多规格、多区域属性，要求工具调用时必须指定精准的品类参数，否则返回数据无对应参考价值。交易日固定的更新节奏，要求插件的定时触发配置需匹配交易时段，避免在非交易时段调用获取无效的空数据。字段的单位差异，要求工具调用后需统一单位转换逻辑，防止后续收益率计算出现维度偏差。多数建材数据源存在接口限流规则，要求调用频率需控制在合理区间，否则会触发限流错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_call_timeout` | `240–300 秒` | 玻璃数据源接口的平均响应时长在120-200秒区间，预留合理缓冲避免中途中断 |
| `mcp_server_spec` | `填写对应玻璃数据源的OpenAPI 3.0规范文件地址` | 结构化的规范文件可自动解析接口参数与必填项，减少手动配置错误 |
| `required_tool_params` | `["glass_type", "spec_thickness", "region"]` | 玻璃数据存在多规格、多区域差异，必须指定三项核心参数才能获取有效匹配数据 |
| `rate_limit_per_minute` | `10 次` | 多数建材交易公开数据源的限流阈值为每分钟10次调用，超出会返回429状态码 |
| `unit_conversion_strategy` | `按接口返回的默认单位统一转换为元/平方米` | 统一单位可避免后续收益率计算出现维度偏差 |
| `tool_call_retry_count` | `2 次` | 部分接口存在临时网络波动，有限重试可降低单次调用失败的概率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用MCP服务器端工具时发送终止命令后，工具仍在执行并返回冗余数据。原因：未在MCP配置中开启`abort_on_interrupt`参数，导致服务器端无法接收中断信号。
- 现象：工具调用返回的字段为空，无法完成收益率计算。原因：未在`required_tool_params`中指定`glass_type`或`region`参数，数据源未匹配到对应数据，返回空结果。
- 现象：模型输出中途中断，未完成工具调用结果的整理与输出。原因：工具调用超时设置过短，接口响应未完成即触发中断，或未配置`tool_call_retry_count`导致单次调用失败直接终止流程。

## 怎么确认配好了
- 调用测试接口，传入预设的`glass_type`、`spec_thickness`、`region`参数，核对返回字段是否包含所需的成交价、指导价等信息。
- 查看工具调用日志，确认每次调用的响应时长未超过配置的`tool_call_timeout`阈值。
- 模拟连续调用，核对返回的状态码是否未出现429限流错误，确认调用频率符合数据源的限流要求。
- 配置定时触发任务，在交易日收盘后1小时启动调用，核对返回数据是否为当日最新的交易数据。
