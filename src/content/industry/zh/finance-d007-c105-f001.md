# 生物制品收益率的HTTP 接口与外部系统

## 这个品类的数据长什么样
数据来源包含生物制品企业公开财报、医药行业合规行情接口、批签发关联的营收测算数据源。更新节奏为每日更新当日交易行情收益率，每自然周更新细分品类的周度收益率汇总，每月更新年度累计收益率数据。文档结构为标准JSON格式，包含产品编码、产品名称、所属细分赛道、当日收益率、周累计收益率、月累计收益率、更新时间戳字段。收益率字段采用小数格式，未做百分比转化，时间戳采用ISO 8601格式，各字段无嵌套层级，便于直接解析。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多源数据来源要求接口支持多请求地址聚合，需预先配置数据源优先级与失败 fallback 规则。多档更新节奏要求接口支持按时间范围拉取数据，请求参数需包含明确的周期标识字段。小数格式的收益率字段无需接口做格式化处理，外部系统需自行完成单位转换。细分赛道字段的存在要求外部系统预先配置分类映射规则，避免数据分类不匹配。批签发关联数据源存在临时限流风险，接口需配置重试机制与超时参数，保障数据拉取稳定性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `HTTP_REQUEST_TIMEOUT` | `30 秒` | 适配多源数据聚合的接口响应延迟，避免单次请求超时中断流程 |
| `RETRY_MAX_TIMES` | `3 次` | 应对第三方医药数据源的临时限流，减少数据拉取失败率 |
| `REQUEST_CONTENT_TYPE` | `application/json` | 匹配多数医药行业行情接口的请求格式要求 |
| `FIELD_MAPPING_RULE` | `按字段名精准映射` | 适配生物制品收益率数据的多字段结构，避免分类字段错位 |
| `REQUEST_FREQUENCY_LIMIT` | `10 次/分钟` | 符合多数医药数据源的接口调用频次限制 |
| `GLOBAL_VAR_BINDING` | `按业务字段绑定` | 适配全局变量参数的API调用需求，完成业务参数传递 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：HTTP请求返回`422 Unprocessable Entity`，提示`yield_rate`字段格式错误。原因：未按照生物制品数据的小数格式传递收益率参数，误将百分比字符串传入接口。
- 现象：全局变量参数未正确传递，外部系统接收的`product_code`字段为空。原因：未在HTTP接口配置中绑定全局变量参数，未完成字段映射规则配置。
- 现象：接口调用频次超限，返回`429 Too Many Requests`。原因：未配置请求频率限制，超出第三方医药数据源的调用阈值。

## 怎么确认配好了
- 发起单次HTTP请求，验证返回的`yield_rate`字段为小数格式，与数据源返回格式一致。
- 查看接口日志，确认`start_time`与`end_time`参数被正确传递，匹配预期的数据周期范围。
- 模拟连续请求，验证未触发限流报错，确认请求频率配置符合数据源要求。
- 检查全局变量绑定配置，确认`product_code`等业务参数被正确映射到接口请求体中。
