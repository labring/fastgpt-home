# 生物制品收益率的表单与交互

## 这个品类的数据长什么样
生物制品收益率相关数据主要用于金融领域的医药行业投资分析，来源包括国家药监局CDE公开数据库、医药行业第三方监测机构公开数据集，以及上市药企的年度、半年度报告。数据更新节奏存在差异：公开财报数据按季度更新，零售终端监测数据按周更新，临床试验相关的经营数据随研发进展不定期更新。单条数据以结构化CSV或JSON格式存储，包含产品标识、统计周期、单位成本、营收总额、利润率数值等字段，单位成本以元/支为单位，营收总额以万元为单位，利润率以比例数值形式呈现，每条记录对应单一款生物制品在指定周期内的经营表现。

## 这些特征在「表单与交互」这一环带来什么约束
由于生物制品数据来源分散且更新周期差异较大，表单需支持动态加载对应数据源的字段列表，避免展示无效字段。由于单条记录包含多维度经营指标，交互环节需对字段格式做强制校验，例如生产成本字段仅接受数值类型输入。由于部分数据需匹配官方合规编码库，表单需集成自动补全功能，减少用户手动输入的误差。同时，当用户中途切换统计周期时，已填写的非关联字段需自动保留，避免重复录入操作。此外，由于部分数据更新周期较长，表单需支持手动触发数据刷新，确保获取的信息为最新状态。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `form_auto_complete_enabled` | 开启，关联官方生物制品编码库 | 减少手动输入的错误率，匹配已有的合规产品标识 |
| `dynamic_form_field` | 按统计周期切换字段组 | 适配不同数据源的字段差异，避免无效字段展示 |
| `form_input_validation_rule` | 数值字段仅接受正浮点数，文本字段匹配编码库前缀 | 确保录入数据符合业务规范，过滤无效输入 |
| `session_preserve_after_switch` | 开启 | 保留用户已填写的非关联字段，降低重复操作成本 |
| `form_timeout_threshold` | 600 秒 | 适配生物制品数据录入的复杂度，避免中途超时丢失内容 |
| `form_reusable_enabled` | 开启 | 支持多链路复用表单节点，适配不同分支的调用需求 |
| `input_guide_custom_lib` | 按业务场景配置词库，限制词库长度为 800–1200 字符 | 适配输入引导的展示需求，避免触发格式报错 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：表单节点触发后，用户发送新消息未完成交互，流程返回超时错误或空结果。原因：未绑定表单交互的会话超时机制，未设置中断当前交互的兜底逻辑。
- 现象：尝试将其他链路节点接入表单节点时，流程无法正常跳转。原因：未开启表单节点复用配置，未设置跨链路调用的权限。
- 现象：开启输入引导并配置自定义词库后，调试预览界面弹出`Input Guide Error`报错。原因：未校验自定义词库的格式，或词库内容超出系统限制长度。

## 怎么确认配好了
- 触发表单节点，选择不同统计周期，确认对应字段组正确加载，无无效字段展示。
- 填写部分字段后切换数据源，确认已填字段未被清空，会话内容正常保留。
- 输入不符合格式的内容（如非数值的生产成本），确认系统弹出格式校验提示。
- 开启输入引导并导入自定义词库，确认调试预览界面无报错，输入提示正常展示。
- 等待600秒未完成交互，确认系统触发超时中断，或自动跳转至兜底流程。
