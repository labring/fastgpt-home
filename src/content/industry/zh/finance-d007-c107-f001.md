# 电力收益率的HTTP 接口与外部系统

## 这个品类的数据长什么样
电力收益率的日报数据来源于省级电力交易中心、区域电网运营平台的公开交易核算接口。数据按省级行政区域与发电类别分类汇总，文档为结构化JSON数组格式，单条记录包含省级行政区域代码、发电类型、当日交易总电量、平均收益率系数、当日交易笔数等字段。数据更新节奏为每日凌晨完成前一自然日的全量汇总更新，部分区域的临时交易数据每小时同步一次，供实时参考使用。字段单位均采用国际通用计量标准，无百分比类表述，收益率系数以小数形式呈现。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
电力收益率数据的多维度分类特征要求HTTP接口必须支持按区域和发电类型进行筛选，否则返回的全量数据量过大，会增加外部系统的解析与存储负担。固定时段的全量更新要求外部系统需避开每日凌晨的更新窗口发起请求，避免获取到未完成的临时数据或触发接口限流。不同更新频率的双数据源（全量日报与实时增量）需要外部系统区分调用场景，分别配置拉取周期。字段采用非百分比的小数形式与专属行政区域代码，要求外部系统的解析逻辑适配对应格式，避免类型转换错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `api_request_timeout` | `30 秒` | 电力行业数据源接口的常规响应时长在10-25秒区间，30秒可覆盖正常响应场景，避免提前中断请求 |
| `filter_dimensions` | `["province_id", "generation_category"]` | 电力收益率数据按省级行政区域和发电类型分类，指定筛选维度可精准返回目标品类数据，减少无效数据传输 |
| `update_cycle` | `86400 秒` | 电力日报数据每日更新一次，按日周期拉取可保证数据时效性，避免重复请求消耗资源 |
| `retry_strategy` | `重试2次，间隔5 秒` | 电力数据源在每日更新时段可能出现临时响应波动，重试机制可降低请求失败概率 |
| `api_auth_token` | `电力数据源平台颁发的专属调用令牌` | 多数电力交易公开接口需要身份验证，使用专属令牌可确保合法调用权限 |
| `embedding_batch_size` | `50 条/批` | 单条电力收益率数据包含多维度字段，批量50条可平衡接口负载与传输效率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用接口时返回`400 Bad Request`错误，提示参数格式不匹配。原因：误将实时交易接口当作日报接口调用，未适配日报数据的字段结构。
- 插入知识库文档时出现字段缺失报错，`average_revenue_ratio`字段为空。原因：未在接口请求中指定必要的筛选维度，返回了未完成的临时增量数据，部分字段未生成完整。
- 调用多模态Embedding接口时返回`Invalid`格式错误。原因：未将电力收益率数据的小数格式转换为符合要求的字符串格式，导致模型解析失败。

## 怎么确认配好了
- 发起一次接口请求，验证返回的字段包含预设的核心字段，核对字段单位与配置要求一致。
- 检查定时拉取任务的执行日志，确认在每日更新时段外成功获取到完整数据，无超时或重试失败记录。
- 调用知识库检索接口，输入电力收益率相关关键词，验证返回的文档包含正确的区域和发电类型数据。
- 调整筛选维度参数，验证返回的数据范围随参数变化而正确调整。
