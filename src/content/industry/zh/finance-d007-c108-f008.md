# 电商服务收益率的工具调用与插件

## 这个品类的数据长什么样
电商服务收益率相关数据的来源为电商平台开放API、第三方电商数据聚合接口，更新频率为每日一次，于次日凌晨完成全量更新。文档结构为结构化表格或JSON格式，包含店铺标识、商品类目编码、交易总金额、交易总订单数、核心运营成本、核算收益额等字段，字段单位分别为字符串、数字、元、笔、元、元。数据维度覆盖单店铺、单类目、全平台等多个层级，部分接口会返回按时间切片的细分数据。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于数据来源为第三方电商接口，工具调用需配置专属API鉴权参数，且需适配接口的调用频率限制，避免触发限流拦截。每日更新的特性要求工具调用的定时触发配置需匹配数据更新节奏，避免提前调用获取未更新的旧数据。结构化字段包含多维度财务与交易数据，工具入参需支持指定字段筛选，且需配置数据校验规则过滤异常数值。电商服务的收益率数据常关联多店铺、多类目维度，工具输出需支持按维度分组，这要求插件的返回格式需兼容嵌套结构，同时需处理不同接口的字段命名差异。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `API_BASE_URL` | `https://api.ecommerce-data-provider.com` | 匹配目标电商数据接口的官方域名，完成基础地址绑定 |
| `API_AUTH_TOKEN` | 从电商数据平台申请的专属鉴权密钥 | 完成接口身份验证，获取数据访问权限 |
| `cron_expression` | `0 2 * * *` | 匹配电商日报T+1的更新节奏，在数据更新后触发调用 |
| `REQUEST_INTERVAL` | `1–3 秒` | 适配电商接口的调用频率限制，避免触发限流拦截 |
| `timeout` | `30 秒` | 匹配电商接口的平均响应时长，避免工作流超时中断 |
| `FIELD_WHITELIST` | `["店铺ID", "交易日期", "核算收益额"]` | 仅提取收益率计算所需的核心字段，降低数据处理开销 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用节点无法创建连接线，界面无连接小圆圈。原因：未正确配置`API_BASE_URL`或`API_AUTH_TOKEN`导致节点校验失败，系统隐藏了连接配置入口。
- 现象：无法查看MCP服务的详细执行日志。原因：未开启工作流的详细日志采集开关，或未将日志级别配置为`debug`。
- 现象：工具返回的收益率相关字段数值异常或缺失。原因：未配置`FIELD_WHITELIST`包含目标字段，或配置的字段名称与电商接口返回的字段名称不一致。

## 怎么确认配好了
- 手动触发一次工具调用，核对返回数据的字段是否包含配置的核心筛选字段，数据格式与业务需求匹配。
- 查看工作流的执行日志，确认接口请求的域名、鉴权信息与配置项完全一致。
- 等待次日定时任务触发，检查是否成功获取当日更新的电商收益率数据，无超时或限流相关报错。
- 调整`FIELD_WHITELIST`的配置内容，验证不同字段组合下的返回结果是否符合筛选要求。
