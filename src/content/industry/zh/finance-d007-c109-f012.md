# 电子元件收益率的模型接入与配置

## 这个品类的数据长什么样
电子元件的行情与收益率数据主要来源于分销商公开报价接口、行业供应链数据库以及原厂产品定价公告。数据更新节奏存在差异，高频交易品类的报价数据每小时更新，低频品类则每日更新。单条数据文档包含元件唯一标识、生产厂商、封装规格、当前交易单价、周期收益波动值以及数据更新时间戳。字段单位方面，单价以“件”为计价单位，收益波动值以相对基准的差值形式记录，未采用百分比类标准化单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据来源要求配置多数据源切换参数，适配不同接口的鉴权规则与请求格式。更新频率的差异要求配置定时拉取的粒度参数，区分高频与低频品类的拉取间隔。字段包含非标封装规格与唯一标识，要求配置实体匹配阈值参数，适配元件型号的模糊匹配需求。收益波动值的非标准化记录形式，要求配置数值解析转换规则，将原始数据转换为模型可处理的标准化指标。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `api_request_timeout` | 30–60 秒 | 电子元件数据源接口通常返回多字段数据，较长超时可避免正常请求被截断 |
| `batch_fetch_size` | 20–50 条/次 | 适配单批次数据量适中的接口限制，避免单次拉取超出接口承载容量 |
| `entity_match_threshold` | 0.75–0.85 | 适配元件型号的模糊匹配需求，平衡召回准确率与召回范围 |
| `data_pull_interval` | 1 小时 / 24 小时 | 根据品类交易频率选择，高频品类设为1小时，低频品类设为24小时 |
| `value_conversion_rule` | 按基准差值映射 | 将原始非标准化波动数据转换为模型可计算的标准化指标 |
| `auth_type` | 按数据源标定 | 适配不同分销商接口的鉴权方式，包括签名校验、API密钥认证等 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置oneapi接入百度embedding-v1或ollama部署的bge-large-zh-v1.5模型时，返回404错误。原因：未正确填写模型的完整接口路由或标识名称，导致请求无法匹配到目标模型服务。
- 现象：使用内置workflow模版生成电子元件收益率播报时，分类结果差异过大。原因：未针对电子元件的非标封装、厂商等字段调整模型匹配阈值，导致模型对字段的识别稳定性不足。
- 现象：定时拉取数据任务频繁超时。原因：配置的请求超时时间过短，未适配电子元件数据源多字段返回的响应时长。

## 怎么确认配好了
- 调用模型接入的测试接口，输入标准电子元件型号，检查返回结果是否包含配置项中定义的全部字段。
- 查看定时拉取任务的运行日志，确认数据拉取的间隔与配置项一致，且无异常报错信息。
- 输入多组不同封装规格的元件型号，检查模型输出的结果是否符合预设的匹配规则。
- 发起无效鉴权信息的测试请求，确认接口会返回对应鉴权失败的错误提示，验证鉴权配置的有效性。
