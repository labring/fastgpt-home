# 电网设备收益率的HTTP 接口与外部系统

## 这个品类的数据长什么样
电网设备收益率相关数据主要来源于省级电力交易结算系统、设备运维管理平台。数据更新节奏分为每日凌晨2点完成前一日全量汇总，每小时同步增量运行数据。文档采用结构化JSON格式，单条数据包含设备唯一标识、所属变电站名称、当日单位发电量收益、当日总收益、当日等效利用小时数等字段。字段单位分别为字符串、字符串、元/千瓦时、元、小时，未使用百分比类统计单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
电力交易系统的专用接口需要严格的身份校验，因此对接时需适配专用的身份验证规则。数据的增量与全量混合更新节奏，要求接口支持断点续传与增量拉取参数，避免重复同步或遗漏数据。结构化的字段与固定单位要求，需在接口配置中开启严格的字段校验，确保返回数据与预设结构完全匹配。批量设备数据的单次返回量较大，需适配分页查询参数，防止接口超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `incremental_sync_interval` | 3600 秒 | 匹配电网设备数据每小时增量更新的节奏 |
| `full_sync_cron` | 0 2 * * * | 对应每日凌晨2点的全量数据更新任务 |
| `response_page_size` | 100 条 | 适配单次接口返回的设备数据量，避免超时 |
| `field_validate_mode` | strict | 确保返回字段与电网设备数据的预设结构完全匹配 |
| `auth_type` | API_KEY | 适配电力系统专用接口的身份校验要求 |
| `request_timeout` | 120 秒 | 应对大型电网设备数据集的接口响应耗时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用接口生成收益率播报内容时，后一条设备的收益数据叠加了前一条的结果。原因：未配置`incremental_sync_threshold`参数，导致接口返回的增量数据未过滤已同步过的设备标识，出现数据串扰。
- 现象：通过webhook接收电网设备数据时，表格格式的字段无法正确解析。原因：未将`response_parse_mode`设置为`structured_json`，默认解析模式无法适配结构化的电网设备数据文档。
- 现象：本地调试接口时返回403状态码。原因：未使用`API_KEY`类型的身份校验，而是使用了通用的token配置，不符合电力系统接口的身份验证规则。

## 怎么确认配好了
- 发起一次测试请求，检查返回的字段与预设的电网设备数据结构完全匹配，核对字段单位是否符合配置要求。
- 查看接口调用日志，确认请求间隔与`incremental_sync_interval`的设置一致，无频繁超时报错。
- 验证webhook接收端能否正确解析接收到的结构化数据，无字段缺失或格式错误。
- 模拟批量设备数据请求，确认接口返回的分页参数与`response_page_size`的设置匹配，数据完整无遗漏。
