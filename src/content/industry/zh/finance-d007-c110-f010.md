# 电网设备收益率的数据库与运维

## 这个品类的数据长什么样
电网设备收益率相关数据是电力资产理财、电网企业成本核算等金融场景的核心数据源，主要来源于电力交易中心公开API、电网运维管理系统及电力现货市场交易接口。数据更新节奏匹配交易周期，现货市场数据每15分钟更新一次，中长期交易数据每日更新一次。单条数据为结构化记录，包含设备唯一资产编号、所属电网节点编码、交易时段起始时间、基准收益额度（单位为每兆瓦时收益额）、实际收益额度（单位与基准一致）、运行损耗系数（无量纲）、交易批次编号等字段，各字段均采用标准化数值或字符串格式。

## 这些特征在「数据库与运维」这一环带来什么约束
多源数据接入要求数据库支持多接口并行拉取，需配置合理的并发请求限制避免触发数据源限流。按交易周期更新的特性要求数据库采用分区存储策略，按时段分区可快速按周期筛选数据并简化历史数据归档。多字段联合查询的需求需建立联合索引，提升设备与时段组合查询的性能。高频写入的场景要求数据库支持批量写入操作，避免单条写入带来的IO开销。同时，数据需按业务保留周期定期归档，降低在线数据库的存储压力。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `external_api_request_timeout` | `30 秒` | 电网设备数据接口的响应延迟通常在10-20秒，30秒的超时设置可避免无效等待 |
| `db_write_batch_size` | `50 条/批` | 单批次写入过多会导致数据库锁表，过少则增加IO次数，50条可平衡性能与稳定性 |
| `data_sync_interval` | `15 分钟` | 现货市场数据每15分钟更新一次，同步间隔匹配数据源的更新频率 |
| `db_partition_strategy` | `按trading_cycle按月分区` | 交易数据按周期归档，按月分区可快速按时段查询并简化归档操作 |
| `concurrent_api_request_limit` | `20 并发` | 多数电网数据接口有并发限制，20并发符合多数平台的准入阈值 |
| `fastgpt_version_compatible` | `v4.9.14 及以上` | 该版本修复了批量写入的并发冲突问题，适配高频数据同步场景 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用电网数据接口返回`429 Too Many Requests`错误。原因：未配置`concurrent_api_request_limit`参数，并发请求超出数据源接口的限制阈值。
- 现象：数据库写入失败，字段`actual_yield`为空。原因：未按数据源返回的字段映射配置参数，导致字段匹配错误，无法正确写入数值。
- 现象：本地部署时无法连接外部电网数据接口。原因：未配置外部接口访问白名单，或本地网络未配置代理绕过防火墙限制，导致无法发起跨域请求。

## 怎么确认配好了
- 查看FastGPT的外部接口调用日志，确认近10次请求的响应码符合数据源的标准返回值，根据数据源的实际响应规则调整校验标准。
- 执行数据库查询语句，验证按`trading_cycle`分区的表可正常按时段筛选数据，根据业务查询需求调整分区粒度。
- 查看数据库写入监控面板，确认每秒写入条数符合配置的`db_write_batch_size`参数设定，根据系统负载调整并发写入阈值。
- 触发本地部署的数据同步任务，确认可正常拉取外部电网数据接口的内容，根据本地网络环境调整代理或白名单配置。
