# 畜禽养殖收益率的表单与交互

## 这个品类的数据长什么样
畜禽养殖的收益率数据来源包括养殖主体的饲喂台账、出栏称重记录、饲料采购凭证，以及行业协会公开的原料行情数据。数据更新节奏分两类：每日饲喂消耗与原料采购数据按自然日更新，出栏量、存栏量等核心经营数据按周度同步。单份数据文档为结构化表格，包含栏舍编号、存栏头数、饲料采购单价、出栏均重、单位养殖成本等字段，单位分别对应头、千克、元/千克、元/头。

## 这些特征在「表单与交互」这一环带来什么约束
不同更新节奏的数据源要求表单支持按日、周维度切换数据导入的时间范围，避免混入过期或未同步的信息。固定的字段与单位要求需表单内置单位校验规则，防止用户输入不符合业务规范的数值，比如将饲料单价误填为元/吨。多来源的结构化文档需支持批量导入，同时需预设字段匹配逻辑，避免因用户自行调整表格结构导致数据错位。出栏数据的时效性较强，需在表单提交时自动校验数据的更新时间，确保仅导入近7天内的出栏记录。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 畜禽养殖的结构化台账文件多为单页或多页表格，单份文件通常不超过200MB，超过该阈值会触发上传超时。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 包含多栏舍、多批次数据的台账文件解析需遍历行列，600秒可覆盖绝大多数单文件解析场景。 |
| `form_field_matching_mode` | `strict` | 畜禽养殖数据字段有固定业务含义，严格匹配模式可避免字段错位导致的计算错误。 |
| `batch_upload_max_count` | `10 个` | 周度批量导入的台账文件通常不超过10份，该取值可平衡导入效率与系统负载。 |
| `input_unit_validate_enabled` | `enabled` | 畜禽养殖数据有明确的单位要求，开启校验可减少用户输入的单位错误。 |
| `form_template_download_enabled` | `enabled` | 提供标准化表单模板可降低用户适配结构化数据导入的成本，提升导入成功率。 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：批量导入畜禽养殖台账后，栏舍编号、饲料单价等字段显示为空。原因：未使用平台提供的标准化表单模板，自行调整了字段顺序或新增非预设字段，导致系统无法匹配对应数据。
- 现象：上传畜禽养殖台账文件后，系统提示“解析超时”，返回错误码`ERR_PARSE_TIMEOUT`。原因：设置的`PARSE_FILE_TIMEOUT_SECONDS`取值小于600秒，单份台账文件行数超过1000行，解析耗时超出预设阈值。
- 现象：打开表单导入界面时，显示“文档输入功能暂未开放”，返回错误码`ERR_FORM_DISABLED`。原因：部署的版本为4.9.10alpha且未开启表单导入的功能开关，需手动启用对应配置项。

## 怎么确认配好了
- 上传一份提前整理好的畜禽养殖台账模板文件，检查系统是否自动匹配栏舍编号、饲料采购单价等预设字段，并将数据正确填充至表单对应位置。
- 输入一个不符合单位要求的数值（如将饲料单价填为“5 元/吨”），检查是否触发单位校验的提示信息。
- 上传10份符合格式的台账文件，检查是否能正常批量解析并完成导入。
- 查看`PARSE_FILE_TIMEOUT_SECONDS`的配置值，确认其大于单份文件解析的预估耗时。
