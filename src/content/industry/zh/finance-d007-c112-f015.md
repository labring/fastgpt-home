# 白色家电收益率的部署与升级

## 这个品类的数据长什么样
白色家电收益率与行情数据来源包括家电行业协会公开的渠道结算数据、品牌方披露的终端零售数据、大宗商品交易平台的原材料价格联动数据。数据更新节奏为每日更新前一日的全品类行情信息。文档按冷柜、滚筒洗衣机、分体式空调等细分品类分层组织，每个条目包含产品SKU编码、渠道结算单价、终端零售单价、单位利润额字段。单价单位为元/台，单位利润额单位为元。

## 这些特征在「部署与升级」这一环带来什么约束
多源分散的数据来源要求部署阶段需对接多个外部接口，需配置合理的同步超时参数避免任务中断。每日更新的节奏要求定时任务需匹配当日数据产出周期，升级阶段需兼容新增的细分品类字段映射规则。按SKU分层的文档结构要求向量分块需以单SKU为单位，避免跨品类数据混淆。不同品类的单价区间差异较大，需配置归一化规则平衡数据权重，升级时需同步更新归一化参数适配新增品类的价格区间。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DATA_SYNC_TIMEOUT` | `600 秒` | 对接家电行业协会、电商平台、大宗商品平台三个数据源，单次同步耗时较长，600秒可覆盖多数正常同步场景 |
| `CRON_SCHEDULE` | `0 2 * * *` | 每日凌晨2点触发同步，此时外部数据源接口负载较低，可减少同步失败概率 |
| `VECTOR_CHUNK_SIZE` | `800–1200 字符` | 单SKU的完整信息包含型号、单价、利润等字段，该分块长度可完整容纳单SKU的核心数据 |
| `NORMALIZATION_RANGE` | `按实测标定` | 白色家电各品类单价区间差异较大，需根据实际接入的品类范围调整归一化范围 |
| `PROXY_AUTH_ENABLE` | `开启并配置用户名密码` | 内网部署场景需通过带认证的HTTP代理访问外部数据源，避免无法获取行情数据 |
| `PARSE_FIELD_STRICT_MODE` | `关闭` | 新增SKU可能携带临时附加字段，关闭严格模式可兼容动态字段，避免解析失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流执行时报错`Cannot read properties of undefined (reading 'incl')`，原因：未配置动态字段映射，新增的SKU附加字段未被识别，导致解析时读取未定义的属性。
- 现象：数据同步任务持续超时，原因：未配置`DATA_SYNC_TIMEOUT`为合理时长，或内网代理未正确配置用户名密码，无法正常访问外部数据源接口。
- 现象：向量召回结果中跨品类数据权重失衡，原因：未根据接入的白色家电品类调整`NORMALIZATION_RANGE`，导致高价品类与低价品类的数据权重偏差过大。

## 怎么确认配好了
- 执行一次手动数据同步任务，查看同步日志，确认无数据源连接失败提示，根据日志提示调整相关配置。
- 查看向量数据库中的分块数据，确认每个SKU的信息被完整分块，无跨品类混淆或信息截断的情况。
- 触发一次工作流运行，检查返回的行情数据是否包含当日的最新字段，无缺失或格式错误。
- 测试新增SKU的字段解析，确认动态字段可被正常识别并纳入数据播报内容。
