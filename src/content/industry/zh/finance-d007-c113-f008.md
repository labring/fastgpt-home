# 白酒收益率的工具调用与插件

## 这个品类的数据长什么样
白酒行情数据的来源为国内证券交易市场公开行情接口，以及食品饮料行业的公开监测数据。更新节奏为：交易日内每5秒更新一次实时交易数据，每日收盘后生成当日完整的收益率统计数据。文档结构为结构化的表格或JSON格式，包含的字段有：证券代码、证券简称、所属板块、开盘价（元）、收盘价（元）、当日价格变动幅度、累计收益率、成交量（股）、成交额（元）、数据更新时间戳。单位方面，价格类字段以元为单位，成交量以股为单位，成交额以元为单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
白酒行情数据的特征对工具调用与插件环节带来多项约束。首先，公开行情接口需要合法的认证密钥，因此插件配置需绑定对应服务商的API密钥。其次，实时数据每5秒更新一次，工具调用的触发频率不得超过该间隔，否则会返回未更新的重复数据。第三，结构化数据包含固定字段，工具需支持按板块、证券代码等参数筛选，避免返回无关数据。最后，数据传输量随板块覆盖范围扩大而增加，需配置字段过滤参数以优化调用效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `mcp_server_url` | `http://localhost:8081/mcp/aisignal` | 对应白酒行情MCP插件的官方部署地址，新版本默认端口为8081 |
| `mcp_api_key` | `sk-xxxxxxxxxxxxxxxx` | 绑定第三方行情服务商的认证密钥，用于获取合法的白酒板块数据 |
| `tool_cache_ttl` | `5 秒` | 匹配A股实时行情5秒的更新间隔，确保返回最新数据 |
| `tool_request_timeout` | `10 秒` | 适配A股行情接口的常规响应时长，防止因网络延迟导致调用失败 |
| `required_tool_fields` | `["证券代码","证券简称","收盘价","当日价格变动幅度","成交额"]` | 过滤无关字段，减少数据传输量并聚焦核心指标 |
| `trigger_frequency_limit` | `1 次/6秒` | 匹配A股行情接口的调用限制，避免触发限流机制 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：升级`fastgpt-mcp-server`至v0.12.0后，启动时返回`port already in use`错误。原因：新版本默认端口从8080调整为8081，未修改配置文件中的端口参数导致端口冲突。
- 现象：调用白酒行情MCP工具后，模型上下文被清空，无法继续多轮对话。原因：工具调用的响应未正确配置`context_keep`参数，导致FastGPT重置当前会话上下文。
- 现象：在工作流中调用白酒行情工具时，仅能获取单只个股数据，无法按板块或多只个股筛选。原因：未在工作流节点中配置`filter_params`参数，未指定筛选条件导致工具仅返回默认单条数据。

## 怎么确认配好了
- 启动`fastgpt-mcp-server`，查看控制台输出，确认没有连接错误或端口冲突报错。
- 在FastGPT的工具测试页面，调用白酒行情工具，输入板块筛选参数，查看返回结果是否包含预设的核心字段。
- 在工作流中添加工具调用节点，配置多参数筛选条件，运行工作流后查看返回结果是否符合筛选要求。
- 连续调用工具多次，间隔不超过6秒，确认没有返回限流相关的错误码。
