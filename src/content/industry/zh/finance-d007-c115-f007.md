# 种植业收益率的工作流编排

## 这个品类的数据长什么样
种植业收益率相关数据主要来自农业农村部门公开监测数据、种植主体上报的生产台账，以及农资经销商的报价数据。数据更新节奏分两类：大宗粮油作物按周更新，特色经济作物按旬更新。单份数据文档包含地块编码、作物品种、种植周期、单位面积产量、收购指导价、农资投入成本等字段，单位多为亩、公斤、元/公斤、元/亩，部分区域数据会附带土壤墒情、气象影响备注。

## 这些特征在「工作流编排」这一环带来什么约束
多源数据的接入需求要求工作流配置多个独立的数据源拉取节点，分别对接农业部门公开接口、种植主体台账导入接口与农资报价接口。不同品类的更新节奏差异，要求定时触发节点设置差异化的执行周期，避免高频请求浪费资源。字段单位与口径的不统一，要求工作流中嵌入标准化处理环节，完成单位转换与字段映射。部分数据附带的气象影响备注，需要关联第三方气象数据节点完成收益率修正计算，增加了节点间的依赖关系。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `定时触发 cron 表达式` | 大宗作物`0 0 2 * * 1`，特色作物`0 0 3 * * 2` | 匹配对应品类的数据公开更新节奏 |
| `多数据源并行执行数` | `2` | 平衡数据拉取效率与外部接口限流要求 |
| `字段映射规则` | 预设大宗粮油、特色经济作物两类模板 | 适配种植业不同品类的字段口径差异 |
| `工作流节点超时阈值` | `600 秒` | 覆盖多源数据拉取、标准化处理的常规耗时 |
| `API 调用频率限制` | `5 次/分钟` | 符合多数农业公开数据接口的限流标准 |
| `UPLOAD_FILE_MAX_SIZE` | `100 MB` | 适配单份种植生产台账的常规文件尺寸 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流计算的收益率结果字段为空。原因：未配置字段映射规则，拉取的原始数据字段未与收益率计算所需的单产、成本等核心字段对齐。
- 现象：调用工作流API时，`model`字段参数配置错误，导致品类识别节点未正常执行。原因：未明确工作流中各节点的`model`参数对应任务类型，误将分类模型参数传入不匹配的节点。
- 现象：定时工作流执行频繁超时，返回`504 Gateway Timeout`。原因：设置的多数据源并行执行数过高，同时拉取多类数据超出外部接口的限流阈值，且未调整超时阈值适配实际耗时需求。

## 怎么确认配好了
- 手动触发单次工作流，检查各数据源拉取节点是否成功获取对应数据，核对字段映射后的格式是否符合预设的业务要求。
- 查看工作流运行日志，确认各节点的`model`参数匹配对应任务类型，无参数配置冲突。
- 模拟定时触发任务，检查是否在适配业务更新节奏的周期内完成执行，无超时异常报错。
- 导入测试用的种植数据文件，确认文件上传与解析环节无报错，匹配配置的文件尺寸限制要求。
