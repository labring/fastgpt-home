# 纺织制造收益率的工具调用与插件

## 这个品类的数据长什么样
纺织制造的行情数据主要来自国内纺织行业协会的公开监测数据、大宗商品现货交易平台的实时报价。更新节奏分层设置：原料类（如纯棉纱、涤纶长丝）数据每日更新，成品织造类（如面料、成衣坯布）数据每两日更新。文档为结构化表格格式，包含品类标识、当日交易均价、最近周期均价对比、库存总量等字段。不同细分品类的单位存在差异，纱线类单位为元/吨，面料类单位为元/平方米，库存类单位为万米，字段内容随品类细分动态调整。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于纺织制造品类数据来源分散且更新节奏分层，工具调用需支持多源接口聚合配置，避免单次调用仅覆盖单一数据源。不同品类的单位与字段结构存在差异，插件需内置单位转换逻辑与动态字段映射规则，适配纱线、面料等不同细分品类的输出格式。定时触发需按数据更新节奏分层配置，原料类数据每日触发，成品类数据每两日触发，避免调用无效数据。同时需在插件参数中强制要求传入品类标识，防止返回数据与目标品类不匹配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MULTI_SOURCE_TOOL_ENABLE` | `true` | 纺织制造行情数据分散于多个平台，启用多源工具调用可整合全量监测数据 |
| `SCHEDULE_TRIGGER_CONFIG` | `0 0 9 * * ?`（原料类）、`0 0 9 * * 1/2 ?`（成品类） | 原料类数据每日更新，成品类数据每两日更新，按对应节奏配置触发时间 |
| `PLUGIN_REQUIRED_PARAMS` | `["categoryCode", "unitType"]` | 需强制传入品类编码与单位类型参数，避免返回数据与目标品类不匹配 |
| `FIELD_MAPPING_TEMPLATE` | `按品类预设模板加载` | 不同细分品类的字段结构存在差异，预设模板可自动适配字段解析规则 |
| `TOOL_CALL_TIMEOUT` | `120 秒` | 多源聚合调用需更长超时时间，避免因接口响应延迟导致调用失败 |
| `UNIT_CONVERSION_ENABLE` | `true` | 纱线、面料等品类的单位存在差异，启用单位转换可统一输出格式 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用工具返回`400 status code (no body)`错误。原因是未传入必填的`categoryCode`参数，或参数格式不符合接口要求，导致接口无法识别请求内容。
- 工具返回的行情数据单位混乱。原因是未启用`UNIT_CONVERSION_ENABLE`配置，未对不同品类的单位进行统一转换。
- 定时触发仅执行一次后不再运行。原因是错误配置了`SCHEDULE_TRIGGER_CONFIG`为单次触发规则，没有按更新节奏配置循环触发。

## 怎么确认配好了
- 发起单次工具调用，传入已知品类的参数，检查返回数据的字段是否与预设模板匹配。
- 查看工具调用日志，确认是否聚合了多个数据源的返回结果。
- 检查定时任务列表，确认不同品类的触发规则与数据更新节奏一致。
- 模拟传入错误的参数，确认插件会拦截无效请求并返回明确提示。
