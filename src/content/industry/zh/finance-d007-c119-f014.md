# 综合服务收益率的表单与交互

## 这个品类的数据长什么样
综合服务收益率与行情日报的数据来源覆盖场内交易市场公开行情接口、持牌机构提供的理财收益核算数据、合作渠道的代销产品数据。更新节奏为每日固定时段完成全量数据同步，次日上午可对外调用完成校验的当日数据。文档结构以标准化产品为单位，包含基础标识字段、多周期收益字段、关联行情字段。字段需匹配各数据源的原生定义，避免跨源单位不一致，常见字段包含产品编码、产品名称、当日收益水平、近7日收益水平、近30日收益水平、大盘基准收益水平、交易规模，单位涵盖元、万元等原生数据源定义的标准单位。

## 这些特征在「表单与交互」这一环带来什么约束
多数据源的特性要求表单需支持跨源字段校验与单位统一，避免因不同数据源的字段命名、单位差异导致的交互异常。每日固定更新的节奏要求表单的日期查询参数需设置合理范围限制，仅允许查询已同步完成的历史数据，且当日数据需在同步节点后才可发起查询。多周期收益字段的存在要求表单需支持多维度筛选，可按产品类型、周期范围快速定位目标数据。综合服务的产品覆盖范围较广，表单查询的返回数据量较大，需配置分页交互规则，保证界面加载流畅性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `form_field_mapping` | 按业务场景预设字段映射规则 | 综合服务需对接多数据源，统一字段映射可消除跨源命名差异，保证表单交互一致性 |
| `api_timeout` | 120秒 | 多数据源同步可能耗时较长，120秒可覆盖多数常规数据拉取场景，避免请求提前中断 |
| `date_range_restriction` | 近30日至当日 | 收益率日报仅支持查询已同步的历史数据，当日数据需在同步完成后才可查询，该范围可覆盖常规业务需求 |
| `pagination_default_size` | 20条 | 综合服务的产品数量较多，20条可保证界面加载流畅且信息密度合理，符合用户浏览习惯 |
| `response_field_filter` | 按需开启字段过滤 | 避免返回冗余数据，降低接口传输耗时，提升表单交互效率 |
| `workflow_audio_permission` | 按实测标定 | 适配FastGPT 4.9.7及以上版本的权限规则，保证语音输入功能正常触发 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用表单API时返回空数据或字段缺失。原因：未配置`form_field_mapping`规则，导致不同数据源的字段名称不匹配，无法正确提取目标数据。
- 现象：线上版语音输入触发`Permission denied by system`报错。原因：未在系统权限配置中开放语音输入权限，且未在`workflow_audio_permission`参数中开启对应权限，适配版本需为FastGPT 4.9.7及以上。
- 现象：表单无法通过API在第三方平台正常展示。原因：未将表单配置为`public_api_access`模式，或未正确配置跨域白名单参数，导致第三方平台无法发起合法调用。

## 怎么确认配好了
- 提交测试表单，检查返回数据的字段是否与预设的业务场景匹配，无冗余或缺失字段。
- 调用表单API，验证超时时间设置是否合理，无频繁超时或请求被阻断的情况。
- 切换至第三方平台，尝试嵌入表单并提交测试请求，确认接口可正常调用且数据返回正确。
- 触发语音输入功能，提交测试请求，确认无`Permission denied by system`报错且可正常识别输入内容。
