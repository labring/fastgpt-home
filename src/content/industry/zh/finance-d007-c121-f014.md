# 耐火材料收益率的表单与交互

## 这个品类的数据长什么样
耐火材料产业链的收益率与行情数据，来源包括耐火材料行业协会公开统计报表、上游矿产企业出厂报价台账、下游冶金与建材企业采购结算单，用于金融端的收益率与行情日报播报。核心窑炉用品类周度更新，通用品类月度更新。单条数据文档包含品类牌号、生产产地、耐火度等级、出厂结算价、当月批量成交量。出厂结算价单位为元/吨，成交量单位为吨，耐火度等级以行业通用标号划分，无百分比类数值字段。

## 这些特征在「表单与交互」这一环带来什么约束
由于耐火材料数据存在周度与月度两种更新节奏，表单需支持按更新周期切换数据范围筛选，避免跨周期数据混淆。由于品类包含细分牌号与耐火度等级，表单需提供层级化下拉筛选组件，仅允许从预设选项中选择，降低数据匹配误差。由于出厂价与成交量的单位固定为元/吨与吨，表单输入框需预设单位后缀，减少手动输入错误。由于数据来源包含多类企业台账，表单需内置格式校验规则，自动识别牌号与产地的合规组合，避免无效数据导入。当配置节点较多时，表单的折叠分组需按下游应用场景划分，减少页面渲染压力。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 耐火材料台账文件包含多品类细分数据，解析耗时高于通用文档 |
| `BATCH_IMPORT_MAX_ROWS` | `5000 行` | 月度耐火材料统计台账通常包含数千条品类与报价记录，适配批量导入需求 |
| `FORM_INPUT_PRESET_SUFFIX` | `["元/吨", "吨"]` | 出厂价与成交量的单位固定，预设后缀减少手动输入错误 |
| `FORM_FILTER_GROUP_BY` | `下游应用场景` | 耐火材料品类按钢铁窑炉、建材窑炉分组，匹配用户筛选习惯 |
| `WORKFLOW_NODE_COLLAPSE_DEFAULT` | `true` | 多节点配置时默认折叠非激活面板，降低页面渲染压力 |
| `VOICE_INPUT_ENABLE` | `false` | 耐火材料数据字段多为标准化编码与数值，语音输入识别准确率低 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流表单节点输入文字时页面卡顿，接口返回状态码`429`。原因：未开启`WORKFLOW_NODE_COLLAPSE_DEFAULT`配置，多节点同时渲染导致页面资源占用过高。
- 现象：语音输入按钮点击后提示“浏览器不支持语音输入”。原因：未关闭`VOICE_INPUT_ENABLE`配置，且浏览器未加载对应语音识别资源。
- 现象：部署后功能出现非预期变更，无法稳定运行。原因：使用了未经过生产验证的测试版本，未锁定`4.9.10-fix2`版本进行部署。

## 怎么确认配好了
- 上传单条耐火材料台账文件，检查解析后字段是否自动携带预设单位后缀，确认格式校验规则生效。
- 切换表单的更新周期筛选选项，验证返回的数据范围与所选周期匹配。
- 批量导入测试数据，观察页面渲染状态，根据服务器配置调整批量导入的最大行数阈值。
- 点击语音输入按钮，检查界面提示与配置项状态一致，确认语音功能适配当前场景需求。
