# 能源金属收益率的表单与交互

## 这个品类的数据长什么样
能源金属的行情数据主要来自专业大宗商品交易所、行业协会的公开数据源，涵盖锂、钴、镍等常见细分品种，更新节奏区分现货与期货两类：现货数据按交易日固定周期更新，期货数据随交易时段实时推送并在盘后完成汇总。文档结构多为结构化表格格式，包含品种标识、当日基准价格、交易总量、持仓规模等核心字段，部分细分品种会附带产地溢价相关参数，价格单位多为元/吨或美元/吨。

## 这些特征在「表单与交互」这一环带来什么约束
由于数据来源分散且更新节奏存在差异，表单需要支持多数据源配置与切换，交互界面需提供按数据源分类的品种筛选选项。结构化字段较多且存在细分参数，表单需支持自定义字段映射与动态加载字段组。定时拉取任务需匹配不同品类的更新周期，交互界面需提供预设更新时间模板供快速选择。数据校验需覆盖跨源字段一致性，当不同数据源返回字段不匹配时，需在交互界面给出明确提示。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时任务触发时间` | 「交易日15:30、16:30、21:00」 | 匹配国内现货市场收盘、期货市场夜盘收盘的典型更新节点，适配能源金属数据发布节奏 |
| `field_mapping_rules` | 按数据源预设规则自动映射，支持手动调整 | 不同数据源的字段命名存在差异，灵活匹配表单展示需求 |
| `max_response_wait_time` | 300 秒 | 多数据源拉取需等待汇总结果，避免超时中断任务 |
| `form_field_limit` | 前10个高频字段 | 能源金属核心展示字段集中，过多字段会增加交互复杂度 |
| `data_source_switch_enabled` | 开启 | 不同数据源的行情数据存在细微差异，支持用户按需切换查看 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流前序节点的执行结果无法自动带入后续AI对话模块，界面显示输入字段为空。原因：未配置`output_variable_mapping`参数，未将前序节点的输出绑定到后续模块的输入变量。
- 现象：通过HTTP请求节点传递txt格式文件时，后端返回400错误码，无法接收文件内容。原因：未正确设置`request_content_type`为`multipart/form-data`，未将文件字段绑定到请求参数。
- 现象：表单中设置的搜索引用上限未生效，返回结果条数远超配置值。原因：仅在知识库配置中设置了`search_result_limit`，未将该参数同步绑定到表单的展示逻辑中。

## 怎么确认配好了
- 手动触发配置的定时拉取任务，核对表单加载的数据时间戳是否匹配数据源标注的最新更新时间。
- 在表单的数据源切换菜单中选择不同来源，确认展示的字段组与对应数据源的公开结构一致。
- 修改`field_mapping_rules`参数并提交，查看表单是否正确显示调整后的字段名称与排序。
- 模拟多数据源拉取的超时场景，确认界面会弹出符合预期的超时提示信息。
