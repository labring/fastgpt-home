# 能源金属收益率的部署与升级

## 这个品类的数据长什么样
能源金属的行情与收益率数据来源包括上海期货交易所、伦敦金属交易所等专业交易场所，以及大宗商品行业资讯聚合平台。更新节奏为每日收盘后生成当日收益率日报，部分实时行情数据每5至15分钟更新一次。文档结构以结构化表格为主，包含品种标识、交易市场、开盘价、收盘价、结算价、日收益率、持仓量等字段。单位根据交易市场不同分为元/吨、美元/吨等，品种标识包含合约月份后缀，如“沪铜2408”。

## 这些特征在「部署与升级」这一环带来什么约束
多数据源对接要求部署时配置多源数据同步的适配规则，需提前兼容不同交易场所的接口格式与返回字段。每日固定时间更新的节奏要求定时任务的调度需匹配国内和海外市场的收盘窗口，升级时不能随意修改同步间隔导致数据更新错位。多字段与单位差异要求部署时配置字段映射规则，升级时若数据源字段结构调整，需同步更新映射配置避免数据解析失败。能源金属品类丰富，知识库的向量索引需支持多维度字段检索，升级时需兼容旧版本的索引结构，避免现有检索功能失效。时序行情数据的存储需求较高，部署时需提前配置支持高吞吐的数据库，升级时需确保数据库版本兼容现有数据格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `DATA_SYNC_INTERVAL` | `86400 秒` | 能源金属收益率日报为每日更新一次，匹配同步周期 |
| `CLICKHOUSE_DATABASE_URL` | `http://{your_host}:8123/energy_metal` | 时序行情数据适合用ClickHouse存储，默认端口8123适配官方驱动 |
| `PARSE_METADATA_FIELDS` | `["品种名称","交易市场","收盘价","日收益率","持仓量"]` | 覆盖能源金属行情分析的核心字段，减少冗余数据存储 |
| `SYNC_TRIGGER_HOUR` | `17-19` | 覆盖国内期货市场收盘后的数据生成窗口，避免同步过早导致数据未更新 |
| `VECTOR_RECALL_TOP_K` | `前10条` | 能源金属品类较多，精准召回少量高相关结果提升检索效率 |
| `DATA_PARSE_TIMEOUT` | `300 秒` | 多品种批量数据解析需要较长处理时间，避免中途超时中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 升级到4.8.20后执行初始化脚本返回`exit code 1`。原因是未在升级前备份ClickHouse中的能源金属行情数据表，初始化脚本覆盖了已有配置。
- 配置`CLICKHOUSE_DATABASE_URL`后无法连接数据库，返回`Connection refused`错误码。原因是未开放ClickHouse的8123端口，或配置的用户名密码权限不足。
- 调用SearXNG搜索能源金属行业资讯时返回0条结果，后台显示`empty search result`。原因是未配置SearXNG的大宗商品资讯专属搜索站点，默认搜索范围无法覆盖垂直内容。

## 怎么确认配好了
- 查看数据同步任务的日志，确认最后一次同步的时间晚于当日国内期货市场收盘时间，核对同步返回的字段数量与配置的元字段一致。
- 访问ClickHouse的查询界面，执行基础计数查询，确认返回的记录数随每日同步更新。
- 测试调用知识库的检索接口，输入能源金属相关关键词，确认返回的结果包含配置的核心字段。
- 查看容器的启动日志，确认`CLICKHOUSE_DATABASE_URL`等配置项加载成功，无未定义的报错信息。
