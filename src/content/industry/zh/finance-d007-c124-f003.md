# 自动化设备收益率的分享与嵌入

## 这个品类的数据长什么样
该品类的数据来源于自动化设备内置的行情采集终端对接的公开金融数据源、本地交易执行日志与运行参数采集模块。更新节奏为每个交易日收盘后完成当日全量数据汇总，生成单设备专属的数据文档。文档结构为固定表头，包含设备唯一标识、当日累计收益、基准收益对标值、设备运行时长、异常告警标识等字段。单位方面，累计收益以元为单位，运行时长以小时为单位，基准对标值以基准点数为单位，告警标识为布尔类型。

## 这些特征在「分享与嵌入」这一环带来什么约束
该品类的数据专属绑定单台设备且每日固定更新，要求分享嵌入的组件需关联设备唯一标识，避免跨设备数据泄露。固定的文档结构要求嵌入展示组件需适配预设字段布局，无法随意调整字段展示顺序。每日仅一次的更新节奏，要求嵌入组件配置每日定时刷新，不采用实时拉取，减少无效请求。敏感的交易类数据字段，要求分享链接需绑定所属团队账号，提升访问权限管控强度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `share_link_auth_type` | `team_bound` | 匹配自动化设备数据的专属绑定需求，避免无权限访问其他设备数据 |
| `iframe_locale` | `zh-CN` | 适配国内金融场景的字段单位翻译，避免基准点数、运行时长等字段的翻译混乱 |
| `team_share_link_limit` | `100` | 满足单团队多设备的分享需求，匹配每日生成的专属数据量 |
| `refresh_interval` | `86400 秒` | 匹配每日收盘后的数据更新节奏，减少无效请求 |
| `embed_field_order` | `device_id,total_income,benchmark_value,runtime,alert_flag` | 匹配预设的文档结构，保证展示字段顺序与源数据一致 |
| `share_link_expire` | `30 天` | 平衡访问便利性与数据安全，避免长期未使用的链接泄露风险 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：嵌入的iframe界面显示英文，无法切换为中文。原因：未配置`iframe_locale`参数，默认使用平台全局英文语言设置，未匹配金融场景的中文展示需求。
- 现象：团队版账号下创建的免登录分享链接数量达到10个后无法继续创建。原因：未调整`team_share_link_limit`参数，默认配置为10，未适配多设备的分享需求。
- 现象：在4.9.0版本中无法找到分享链接身份鉴权的配置项。原因：该版本将鉴权配置整合到团队权限管理模块，需前往团队设置页面调整。

## 怎么确认配好了
- 打开嵌入的iframe组件，检查界面语言是否与业务场景匹配，确认语言配置生效。
- 尝试创建超过10个的免登录分享链接，确认可以正常生成，验证链接数量限制配置生效。
- 访问分享链接，检查展示的字段顺序与预设配置一致，确认数据结构匹配。
- 等待一个交易日周期后，检查嵌入组件的更新时间是否匹配每日数据汇总的时间节点，确认刷新间隔配置生效。
