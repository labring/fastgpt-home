# 航天装备收益率的工作流编排

## 这个品类的数据长什么样
航天装备的收益率相关数据主要来源于三类系统：在轨卫星的遥测下行系统、地面测试装备的任务调度系统、航天项目的财务核算系统。在轨装备的实时数据每15分钟生成一次更新包，地面测试装备则在单次任务结束后生成全量报告。数据文档多为结构化格式，包含装备唯一标识、任务执行时段、运维成本明细、载荷营收明细、核算周期标识等字段，其中运维与营收数据的单位为法定货币单位，核算周期可按自然日、自然周或单次任务周期划分，部分原始遥测数据会以二进制附件形式附带。

## 这些特征在「工作流编排」这一环带来什么约束
不同来源的数据更新节奏差异较大，需要工作流适配定时拉取与手动触发两种触发模式，避免因数据未就绪导致流程异常。多字段的结构化数据要求工作流配置精准的字段映射规则，防止因字段名不匹配导致数据丢失。附带的二进制遥测附件体积较大，需要工作流支持大文件上传与解析的配置项调整。不同核算周期的需求则要求工作流支持灵活的周期配置，同时需兼容临时任务的手动执行场景。此外，部分数据需经过跨系统的格式转换，工作流需预留数据清洗节点的配置空间。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `workflow_trigger_type` | 定时触发+手动触发 | 兼顾周期性核算任务与临时任务复盘的需求 |
| `UPLOAD_FILE_MAX_SIZE` | 200 MB | 航天装备的遥测附件通常单份体积不超过200MB |
| `data_sync_interval` | 15 分钟 | 匹配在轨航天装备的遥测数据更新频率 |
| `workflow_timeout` | 300 秒 | 覆盖多源数据拉取、格式转换与解析的平均耗时 |
| `variable_mapping_mode` | 按字段名精准匹配 | 航天装备数据字段唯一性强，精准匹配可避免数据错位 |
| `parse_file_type` | CSV、JSON、二进制遥测包 | 覆盖航天装备数据的常见存储与传输格式 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流执行时弹出`UPLOAD_FILE_SIZE_EXCEED`报错，返回状态码413。原因：未调整`UPLOAD_FILE_MAX_SIZE`参数，航天装备的遥测附件体积超出默认限制。
- 现象：工作流的多层分支节点执行后，后续节点无法获取前置选择的参数，流程中断。原因：未配置分支节点的上下文传递规则，导致参数未被带入后续工作流环节。
- 现象：外部平台调用发布后的工作流接口时，传入的全局变量未被正确识别，返回结果缺失核算数据。原因：未在接口发布配置中开启全局变量透传开关，外部传入参数未映射到工作流的全局变量池。

## 怎么确认配好了
- 查看工作流的触发配置页面，确认触发类型与业务需求匹配，核对定时任务的周期是否符合数据更新节奏。
- 上传一份符合航天装备数据格式的测试文件，检查文件上传限制是否生效，解析结果是否包含全部预设字段。
- 调用外部接口传入测试参数，检查全局变量是否被正确映射到工作流节点的参数配置栏。
- 触发一次完整的工作流流程，核对分支节点的分支逻辑是否按预设规则执行，输出结果是否符合预期。
