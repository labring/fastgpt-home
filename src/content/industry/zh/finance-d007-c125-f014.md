# 航天装备收益率的表单与交互

## 这个品类的数据长什么样
航天装备收益率相关数据主要来自国防军工行业公开披露的任务台账、在轨装备运营台账、航天发射任务官方结算文档。更新节奏随任务节点调整，单次任务完成后72小时内更新对应批次数据。文档多为结构化CSV或固定格式的台账表格，字段包含装备型号编码、任务执行周期、直接投入成本、任务合同总额、累计运营时长，单位分别为型号编码、自然日、人民币元、人民币元、自然日。数据无统一的月度固定更新窗口，部分在轨长期运营装备的运营数据按季度更新。

## 这些特征在「表单与交互」这一环带来什么约束
由于航天装备收益率数据来源分散且更新无固定窗口，表单需支持用户上传自定义结构化台账文件。由于字段包含非标准化的任务批次信息，表单需支持字段映射配置，允许用户将上传文档的列与系统预设字段手动绑定。由于直接投入成本、任务合同总额为数值型字段，表单需添加非负数值校验规则，拦截非法输入。由于单次任务数据需关联唯一批次，表单需添加批次号重复校验，避免重复提交同批次数据。部分在轨装备的运营数据需关联长期周期字段，表单需支持自定义时间区间的筛选交互。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 航天装备台账文件通常包含多批次任务数据，1000 MB可覆盖绝大多数台账文件的存储需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 大型台账文件的解析耗时较长，600秒可避免因解析超时导致的任务失败 |
| `UPLOAD_FILE_ACCEPT_TYPES` | `text/csv,application/vnd.ms-excel` | 航天装备台账通常以CSV或Excel格式存储，限定可上传类型可减少无效文件提交 |
| `FORM_FIELD_VALIDATION_ENABLE` | `开启` | 航天装备数据的数值字段需严格校验非负输入，开启后可自动拦截非法数值 |
| `BATCH_UNIQUE_CHECK_ENABLE` | `开启` | 航天装备任务批次具有唯一性，开启后可自动校验批次号的重复提交 |
| `FORM_FIELD_MAPPING_AUTO` | `关闭` | 不同来源的航天装备台账字段顺序存在差异，关闭自动映射后允许用户手动配置字段对应关系 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 上传台账文件后解析失败，返回`413 Request Entity Too Large`错误。未调整`UPLOAD_FILE_MAX_SIZE`参数，默认值过小无法承载大型航天装备台账文件。
- 表单提交后任务超时未完成，返回`504 Gateway Timeout`。未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时间不足以解析大型台账文件。
- 手动配置字段映射后仍出现字段不匹配。开启了`FORM_FIELD_MAPPING_AUTO`参数，系统自动覆盖了用户手动配置的映射关系，导致字段绑定错误。

## 怎么确认配好了
- 上传一个符合航天装备台账格式的测试文件，核对上传进度与解析日志，确认文件未因体积超限被拦截。
- 手动配置字段映射关系后提交测试数据，核对系统是否正确识别各字段的数值与格式。
- 输入重复的批次号提交测试，核对系统是否触发重复校验拦截。
- 等待解析任务完成，核对是否在预设的超时时间内返回解析结果。
