# 航运港口收益率的HTTP 接口与外部系统

## 这个品类的数据长什么样
航运港口收益率的数据主要来自港口企业内部ERP系统、官方航运运价指数平台及第三方海事数据服务商，用于金融领域的航运相关理财、保险产品的行情日报播报。数据更新节奏为每日凌晨生成前一自然日的全量报表，单次拉取包含单港口、单作业品类的完整核算数据。数据文档为标准化JSON格式，无嵌套层级，核心字段包含港口唯一标识、作业品类编码、报告周期、单位作业收益、作业总成本等，字段单位分别对应元/标准箱、元/吨货等细分计价单位，无额外附加统计字段。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
每日全量更新的特性要求外部系统的拉取任务需匹配单日周期，避免频繁请求触发数据源的限流规则。无嵌套的结构化字段设计简化了接口参数的传递逻辑，仅需传入港口代码与报告日期即可精准定位目标数据，但要求外部系统在解析时严格遵循字段名映射，避免因字段错位导致数据错误。多单位的字段设计要求接口返回时需同步标注单位信息，外部系统需单独存储单位参数，防止数值与计价单位不匹配的问题。部分海事数据服务商的接口存在跨时区的时间对齐要求，需在请求参数中明确指定报告周期的时区，确保数据时间维度的一致性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发间隔` | `86400 秒` | 匹配航运港口收益率日报的每日更新节奏，避免频繁请求触发数据源限流 |
| `请求超时时间` | `30 秒` | 应对跨区域海事数据接口的网络延迟，避免任务中断 |
| `API根地址` | `配置为HTTPS协议地址` | 符合语音功能等外部调用的安全要求，适配FastGPT 4.6.9及以上版本的安全校验规则 |
| `请求重试次数` | `2 次` | 应对海事数据接口偶尔的临时波动，减少数据拉取失败率 |
| `返回字段映射规则` | `按字段名直接映射` | 适配航运港口数据无嵌套的结构化格式，降低外部系统解析成本 |
| `SSL证书配置` | `按部署环境导入有效证书` | 满足HTTPS请求的安全校验要求，避免接口调用被拦截 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部接口后对话输出未显示接口返回内容，状态码返回200但output字段为空。原因：未在FastGPT的插件配置中开启结果直接输出的开关，导致接口数据未传递到对话链路。
- 现象：定时任务无法按指定毫秒周期执行，界面显示任务状态异常。原因：误将`定时触发间隔`的单位设置为毫秒，FastGPT默认配置项单位为秒，导致任务执行间隔被错误放大。
- 现象：自定义插件调用外部接口时出现SSL握手失败报错。原因：未将API根地址从HTTP升级为HTTPS，未配置有效SSL证书，不符合FastGPT 4.6.9及以上版本的安全校验规则。

## 怎么确认配好了
- 手动触发一次接口调用，查看FastGPT的插件日志，确认返回的字段与航运港口数据的标准结构一致。
- 检查定时任务的执行记录，确认任务按设定的每日周期触发，无连续失败记录。
- 验证API根地址的HTTPS协议配置，使用curl工具发起请求，确认返回状态码为200且无安全证书报错。
- 查看外部系统对接的数据库，确认已成功存储最新的航运港口收益率数据，字段与映射规则一致。
