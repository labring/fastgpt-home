# 航运港口收益率的表单与交互

## 这个品类的数据长什么样
航运港口收益率相关数据来源包括国际航运行业公开统计接口、港口运营方每日报送的结构化报表、海事监管机构的航线运营数据，主要服务于航运金融的收益率与行情播报需求。数据更新节奏分为两类：核心日报数据每日固定时段更新，实时航线运价数据每小时刷新。文档多为结构化表格格式，包含港口名称、泊位编号、当日吞吐量、单箱运营成本、航线收益率区间、对应船公司代码等字段，单位包含标准集装箱（TEU）、元、美元、航次时长等。

## 这些特征在「表单与交互」这一环带来什么约束
结构化数据格式要求表单支持批量导入与结构化解析，避免零散文本输入的适配成本。多更新频率的数据源需要表单配置两种触发模式，分别适配每日定时拉取与实时手动刷新需求。多单位混合的字段需要交互组件支持单位自动匹配与转换，防止用户输入错误单位导致数据异常。区间型数据字段需要表单添加区间输入校验，同时在交互反馈中明确提示有效值范围。标准化代码字段需要提供下拉选择组件，减少手动输入的错误概率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 航运港口数据文档通常包含多字段结构化内容，解析耗时较长，600秒可覆盖完整解析流程 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 单份港口运营日报的结构化数据文件通常体积较大，1000 MB可满足批量导入需求 |
| `召回条数` | `前 8 条` | 航运港口收益率数据的核心字段集中在前十条内，过多召回会增加冗余计算 |
| `相似度阈值` | `0.75–0.85` | 港口代码、航线名称等字段的匹配精度要求较高，该区间可过滤低匹配度的无关数据 |
| `formFieldAutoMatch` | `开启` | 结构化数据的字段名与系统预设字段匹配度高，自动匹配可减少手动配置工作量 |
| `定时触发任务间隔` | `1440 分钟` | 航运港口收益率日报为每日更新，每日一次定时拉取即可满足需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：国内saas版V4.8.17上传港口运营数据文件后界面提示`413 Request Entity Too Large`，文本对话功能正常。原因：未调整`UPLOAD_FILE_MAX_SIZE`参数，默认值过小导致大文件上传失败。
- 现象：表单生成的收益率播报结果字段缺失，仅显示部分港口数据。原因：未开启`formFieldAutoMatch`，结构化数据的字段未自动匹配到系统预设字段，导致解析不完整。
- 现象：定时生成的收益率日报播报延迟超过2小时。原因：`PARSE_FILE_TIMEOUT_SECONDS`设置过短，未覆盖大型数据文件的解析流程，导致任务中断。

## 怎么确认配好了
- 上传一份测试用的结构化港口数据文件，检查上传进度条是否正常完成，无报错提示。
- 在表单配置页面，手动触发一次数据解析，查看解析后的字段是否与上传文件的表头完全匹配。
- 配置定时触发任务，查看任务日志是否在设定时段正常执行，无超时报错。
- 调用表单交互接口，输入指定港口代码，检查返回的收益率数据是否包含正确的单位与字段值。
