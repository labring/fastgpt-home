# 融资租赁收益率的工具调用与插件

## 这个品类的数据长什么样
融资租赁收益率相关数据主要来源于租赁公司核心业务系统、行业协会公示的租赁资产登记信息及第三方租赁估值平台。数据更新节奏为每日T+1，当日业务结束后生成前一日的收益率核算数据。文档结构为结构化表格或JSON格式，每行对应单个租赁项目，包含`项目唯一标识`、`租赁物类别`、`初始本金总额`、`剩余租赁期限`、`当前折现率`、`当日核算收益率`、`资产状态`等字段。本金单位为元，期限单位为月，收益率以小数形式呈现，无百分比标注。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据来源要求插件需对接两种及以上不同权限的接口，需配置独立的身份校验规则。每日更新的节奏要求工具调用需绑定固定定时任务，避免重复或遗漏拉取数据。结构化字段多且单位格式固定，要求插件需实现字段映射与单位转换逻辑，确保传入大模型或存储的数据格式统一。租赁项目数量较多的特性，要求工具调用需支持批量数据拉取与分页处理，避免单次请求返回数据量过大导致超时。金融类数据的敏感性要求工具调用需开启严格的传输加密与身份校验，防止数据泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_batch_size` | `20-50` | 融资租赁单批次项目数据量较大，20-50条可平衡调用耗时与返回完整性 |
| `tool_request_timeout` | `300 秒` | 对接多源租赁数据接口时，第三方接口响应可能存在延迟，300秒可覆盖多数正常请求 |
| `field_mapping_rule` | 按字段名精准匹配+单位转换 | 融资租赁数据字段存在固定命名规则，需将第三方接口返回的字段映射到平台标准字段，并转换单位格式 |
| `schedule_cron` | `0 18 * * *` | 融资租赁收益率日报需在当日业务结束后生成，每日18点触发工具调用可获取最新数据 |
| `api_signature_type` | `HMAC-SHA256` | 金融类数据接口需严格的身份校验，HMAC-SHA256可保障数据传输安全 |
| `max_return_records` | `500` | 单批次融资租赁项目数量通常在数百级别，500条可覆盖多数场景的全量数据拉取 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用第三方租赁数据接口失败，平台仅返回通用错误提示，无`401 Unauthorized`等具体错误码与信息。原因：未开启工具调用的详细日志开关，无法捕获接口返回的详细错误信息。
- 现象：大模型生成的收益率分析结果与实际租赁项目数据偏差较大。原因：未配置正确的`field_mapping_rule`，导致传入大模型的字段格式与预期不符，影响大模型对数据的理解。
- 现象：免登录窗口的用户使用工具时，无法拉取对应租户的专属租赁数据。原因：未配置`user_id_transparent_param`参数，导致平台无法透传用户身份标识，无法区分不同租户的数据。

## 怎么确认配好了
- 手动触发一次工具调用，核对返回数据的字段与预设的`field_mapping_rule`是否匹配。
- 查看工具调用的详细日志，确认接口请求的`api_signature_type`、`tool_request_timeout`等配置符合设置要求。
- 模拟不同租户的身份场景，验证工具是否可拉取对应租户的专属租赁数据。
- 上传测试用的结构化租赁数据文件，确认字段单位转换逻辑正常生效。
