# 证券收益率的部署与升级

## 这个品类的数据长什么样
证券收益率日报的数据来源为沪深北交易所官方行情接口、中国证券登记结算有限责任公司公开披露数据，以及合规的第三方行情聚合接口。更新节奏为每日交易结束后1至2小时内完成全量更新，实时行情快照每10秒更新一次。文档结构为结构化JSON或CSV格式，包含的字段有：证券代码、证券简称、交易日、当日收盘价（单位：人民币元）、当日收益率（单位：收益率基点）、累计收益率（单位：收益率基点）。数据字段有固定格式约束，如证券代码为6位数字字符串，交易日为YYYY-MM-DD格式的日期字符串。

## 这些特征在「部署与升级」这一环带来什么约束
数据源的合规性要求部署前需申请官方接口的访问权限，未授权的数据源无法接入系统。固定的更新时段要求定时同步任务的触发时间需匹配交易所的数据更新节奏，过早触发会拉取未完成的临时数据，过晚则会错过当日最新数据。结构化的字段格式要求部署时需定义严格的解析schema，字段缺失或格式不匹配会导致数据解析失败。较大的全量数据量要求部署时需配置适配的数据库存储与索引策略，避免查询延迟。数据源的字段变更可能在版本升级时出现，需同步更新解析逻辑，否则会导致后续数据同步失败。实时行情的拉取频率需匹配接口的更新节奏，过度频繁的请求会触发限流封禁。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DATA_SYNC_CRON` | `0 18 * * 1-5` | 匹配沪深交易所每日收盘后1至2小时的更新时段，确保拉取最新的收益率数据 |
| `PARSE_SCHEMA_VERSION` | `v202406` | 适配当前证券收益率日报的标准字段结构，避免字段不匹配导致解析失败 |
| `API_REQUEST_RATE_LIMIT` | `10 次/分钟` | 符合多数证券交易所公开API的调用限制，避免触发限流封禁 |
| `MAX_DATA_STORAGE_DAYS` | `365 天` | 满足证券行业的信息披露留存要求，同时控制存储资源消耗 |
| `MODEL_CONTEXT_WINDOW` | `8192 tokens` | 适配证券收益率日报的结构化内容长度，确保完整加载数据后生成播报内容 |
| `ERROR_RETRY_TIMES` | `3 次` | 平衡接口调用成功率与资源消耗，避免重复请求导致限流 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：OneAPI管理页面无可用渠道选项。原因：未配置证券数据源的合规API密钥，或接口请求未通过身份校验。
- 现象：定时同步任务触发后未生成有效收益率数据。原因：配置的`DATA_SYNC_CRON`时间晚于证券交易所的数据更新时段，导致拉取的数据源为空。
- 现象：版本4.8.20接入grok-3时，模型测试提示错误，但正式调用可正常运行。原因：测试请求的上下文长度超出配置的`MODEL_CONTEXT_WINDOW`阈值，正式调用时自动截断了非核心内容。

## 怎么确认配好了
- 手动执行一次数据同步任务，核对拉取到的原始数据字段是否与当前`PARSE_SCHEMA_VERSION`定义的结构一致。
- 访问OneAPI管理页面，确认已配置的证券行情数据源渠道显示为正常在线状态。
- 提交包含模拟证券收益率数据的模型测试请求，确认返回内容的格式与预期一致。
- 查看系统定时任务日志，确认每日同步任务在匹配交易所更新的时段内完成执行。
