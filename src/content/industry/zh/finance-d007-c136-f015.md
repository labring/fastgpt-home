# 贵金属收益率的部署与升级

## 这个品类的数据长什么样
贵金属行情数据来源涵盖国内贵金属交易所、国际行业协会及专业行情聚合接口。更新节奏匹配对应交易市场的交易时段，国内上市品种在连续交易时段实时推送数据，休市后生成日度结算数据，国际品种跨时区持续更新。单条数据文档包含品种标准代码、交易市场标识、最新成交价、结算参考价、当日价格波动范围、数据更新时间戳。字段单位根据品种类型区分，黄金、铂金等常用单位为元/克，白银等常用单位为元/千克。

## 这些特征在「部署与升级」这一环带来什么约束
贵金属行情的多源属性要求部署阶段需配置多数据源适配器，支持动态切换国内与国际行情接口；实时更新特性要求部署时设置合理的轮询间隔或长连接参数，避免超出接口限流阈值；不同品种的单位差异要求升级阶段新增单位标准化转换逻辑，统一播报输出格式；休市时段的数据更新节奏变化，需配置定时策略切换脚本，确保非交易时段仍能生成合规的日报数据；数据时效性要求部署时设置短超时时间与重试机制，避免播报延迟影响内容准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `DATA_FETCH_INTERVAL` | `30 秒` | 匹配国内贵金属连续交易时段的行情更新节奏，避免超出多数行情接口的限流阈值 |
| `UNIFY_OUTPUT_UNIT` | `元/克` | 统一黄金、铂金等主流品种的输出单位，简化日报播报的格式处理逻辑 |
| `PARSE_DATA_TIMEOUT_SECONDS` | `10 秒` | 适配多数行情接口的常规响应延迟范围，避免因超时中断单条数据拉取流程 |
| `DAILY_REPORT_CRON` | `0 0 8 * * *` | 匹配投资者早间查看日报的常规习惯，确保每日固定时段生成完整日报 |
| `DATASOURCE_FALLBACK_ENABLE` | `开启` | 当主行情接口返回异常时自动切换至备用数据源，保障日报生成服务不中断 |
| `REQUIRED_DATA_FIELDS` | `["symbol","market","price","settle_price","update_time"]` | 过滤冗余字段，仅保留日报所需的核心数据项，降低处理开销 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用贵金属行情接口返回400错误码，提示参数格式非法。原因：未按照接口要求传递带市场前缀的品种代码，混淆国内与国际品种的编码规则，导致接口校验失败。
- 现象：日报生成任务超时，或调用接口返回500 Cannot read property 类报错。原因：未开启数据源 fallback 开关，主接口异常时未自动切换至备用数据源，且未配置合理的超时重试机制，导致任务中断。
- 现象：通过API上传行情数据源配置文件时，后端服务出现无响应或卡死情况。原因：未调整`UPLOAD_FILE_MAX_SIZE`参数适配配置文件的实际大小，针对FastGPT V4.9.7及以上版本，未同步调整`PARSE_FILE_TIMEOUT_SECONDS`延长解析超时时间，导致大文件上传后解析超时触发服务阻塞。

## 怎么确认配好了
- 手动触发一次日报生成任务，检查输出结果中是否包含所有配置的必填字段，且单位统一为预设的目标单位。
- 模拟主行情接口异常，验证系统是否自动切换至备用数据源并生成合规的日报数据。
- 查看系统运行日志，确认数据拉取的间隔符合配置的轮询参数，无频繁触发限流的记录。
- 上传测试用的配置文件，确认上传流程无阻塞，且配置项能正常加载并生效。
