# 通信服务收益率的工具调用与插件

## 这个品类的数据长什么样
通信服务品类的行情与收益率数据，来自国内证券交易所公开行情接口与专业金融数据聚合服务。更新节奏分为两类：实时行情每15秒推送一次，当日收益率日报在每日17:00前完成全量更新。数据文档为结构化JSON格式，包含标的代码、交易日期、当日涨跌幅、成交量、成交额、行业分类标签等字段。字段单位适配国内证券市场通用标准，涨跌幅以百分比计量，成交量以万股为单位，成交额以万元为单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
通信服务品类的数据特征对工具调用与插件环节带来三项核心约束。第一，公开行情接口存在调用频次限制，工具调用频率需匹配接口允许的阈值，避免触发限流。第二，当日收益率日报固定在每日17:00前完成更新，插件触发时机需设置在17:00之后，确保获取完整的当日全量数据。第三，部分通信服务细分标的的行情字段存在空值情况，工具调用逻辑需加入空值校验与默认填充规则，避免流程中断。此外，字段单位需严格适配证券市场标准，输出时需明确标注各类计量信息，避免混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_call_rate_limit` | `10 次/分钟` | 匹配国内证券行情接口的通用调用频次限制，避免触发限流 |
| `daily_report_trigger_time` | `17:10` | 通信服务收益率日报在每日17:00前完成更新，预留10分钟缓冲确保获取完整数据 |
| `field_null_default` | `"暂未披露"` | 部分通信服务细分标的存在行情字段空值，用固定文本替代避免流程中断 |
| `output_unit_annotation` | `开启` | 通信服务数据包含多类计量单位，开启后可明确标注涨跌幅百分比、成交量万股等信息 |
| `batch_exec_timeout` | `600 秒` | 批量获取多只通信服务标的数据需足够的请求与处理时间，避免超时中断 |
| `plugin_response_include_input` | `关闭` | 仅需展示最终收益率播报结果，无需展示工具调用的输入与响应细节 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用输出中展示了冗余的输入与响应内容。原因：未关闭`plugin_response_include_input`配置项，默认保留了工具调用的全量细节。
- 现象：批量执行节点在线调试可正常完成流程，但通过API调用时无法执行完毕。原因：未设置合理的`batch_exec_timeout`参数，API调用的超时阈值低于在线调试的缓冲时间，导致流程中途中断。
- 现象：V4.12.3版本中，自定义插件运行后输出的下载地址会持续跳动后才给出最终结果。原因：插件内部存在异步请求未等待完成，导致返回结果未完全生成即推送至前端。

## 怎么确认配好了
- 触发一次定时工具调用，检查输出内容是否仅包含目标收益率播报结果，无冗余的工具输入与响应细节。
- 发起批量调用测试，核对工具调用的频率未超出行情接口的限制，未触发限流类报错。
- 查看工作流的对话日志，确认运行数据字段已填充完整的工具调用与处理信息。
- 模拟17:10之后的触发时机，检查获取的数据是否包含当日完整的通信服务收益率信息。
