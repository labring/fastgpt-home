# 造纸收益率的表单与交互

## 这个品类的数据长什么样
造纸行业的收益率数据主要来自国内造纸行业协会的公开监测数据、大宗商品现货交易平台的报价数据，以及上市造纸企业的定期公告。数据更新节奏分为两类：当日成品纸与原料的均价数据每日更新一次，在当日交易结束后4小时内完成；月度累计产能与产量数据每月更新一次。数据文档为结构化Excel或CSV格式，每一行对应单一纸种的单日报价数据，包含纸种名称、原料采购均价、成品销售均价、单位产品毛利、月度累计产量等字段，单位统一为元/吨、吨。

## 这些特征在「表单与交互」这一环带来什么约束
纸种品类丰富的特征要求表单支持多纸种的筛选与切换，避免仅支持单一品类的固定配置。数据更新频率的差异要求交互界面提供手动刷新数据的入口，同时支持配置定时同步任务，匹配行业数据的更新节奏。多数据源的接入需求要求表单支持多格式文件上传与外部API对接，适配不同来源的行业数据。字段间存在联动关系的特征要求表单配置联动计算规则，当原料采购均价或成品销售均价变更时自动计算单位产品毛利，减少手动输入误差。批量数据导入的场景要求表单支持数据校验规则，快速识别异常的毛利数值。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 造纸行业日报Excel文件通常不超过100行，解析耗时不超过300秒，避免因超时导致解析失败 |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 单份造纸行业日报文件通常不超过10 MB，预留合理的文件上传上限 |
| `召回条数` | `前 3 条` | 造纸行业的核心数据集中在瓦楞纸、铜版纸、白板纸3个主流品类，无需召回过多条目 |
| `自定义工具触发关键词` | `["造纸日报", "纸价查询", "吨利润计算"]` | 匹配用户常用的查询场景，精准触发自定义工具调用 |
| `表单字段校验规则` | 当原料成本 > 成品售价时标记异常 | 识别经营逻辑异常的数据，提升数据准确性 |
| `定时同步任务周期` | `每日 22:00` | 行业数据通常在当日20:00前更新完成，预留2小时的同步窗口确保数据时效性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：导入造纸日报Excel后，解析结果显示“看起来可能输入了一个不完整的命令或请求。请提供更多的信息，以便更好地提供协助吗？需要什么样的帮助？”，原因：未配置`PARSE_FILE_TIMEOUT_SECONDS`的合理时长，或上传文件超出`UPLOAD_FILE_MAX_SIZE`限制，导致文件解析失败后触发默认提示。
- 现象：AI回复内容中包含“引用标记：［1］”字样，原因：未在知识库配置中关闭引用标记的输出开关，导致召回的数据源引用标记被直接带入回复内容。
- 现象：用户输入指定关键词后未触发自定义接口，原因：未正确配置`自定义工具触发关键词`的匹配规则，或关键词未包含在配置列表中，导致拦截逻辑未生效。

## 怎么确认配好了
- 上传一份测试用的造纸日报Excel文件，检查解析后的字段是否与预设的表单字段一致，确认解析配置生效。
- 触发定时同步任务，检查是否在指定时间完成数据更新，确认同步周期配置正确。
- 输入配置好的触发关键词，检查是否触发自定义工具调用，确认拦截逻辑生效。
- 发起一次纸价查询请求，检查回复内容中是否未包含引用标记，确认引用标记开关已关闭。
