# 钢铁贸易收益率的多轮对话与提示词

## 这个品类的数据长什么样
钢铁贸易的行情与收益率数据主要来自国内现货交易平台、期货交易所交割品种报价、钢厂出厂指导价公示以及区域贸易商的成交台账。更新节奏上，现货报价多为每日上午更新，期货行情随交易时段实时刷新，钢厂指导价以周度或双周为更新周期。文档多以Excel或CSV格式存储，核心列包含品种名称、规格型号、产地、报价单位、当日成交价格、前一周期成交价格、区域库存总量，字段单位统一为元/吨，无额外复合单位，部分细分品类会附带区域运输成本说明。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
数据源分散且更新节奏差异大，多轮对话中需要先明确用户所需的数据类型，避免混淆现货与期货的统计口径。钢铁品种规格复杂，不同规格的同品类产品价格差异显著，提示词需要引导用户明确指定具体的规格型号与产地，否则无法返回精准结果。多轮对话需跟踪上下文的品类信息，避免重复询问基础参数，同时需要统一单位表述，确保所有返回内容均以元/吨为单位。批量导入的贸易台账数据量较大，解析与召回过程需要适配长文本与多字段的处理逻辑，防止上下文溢出导致关键信息丢失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `12000 字符` | 钢铁贸易数据字段多且需保留多轮对话的品种、规格上下文，避免上下文溢出丢失关键信息 |
| `召回条数` | `前 8 条` | 钢铁品种规格多，需召回足够的相关品类数据支撑对话，同时避免冗余信息干扰 |
| `相似度阈值` | `0.72–0.85` | 区分相似规格的钢铁品种（如Φ16mm与Φ18mm HRB400），避免召回不匹配的报价数据 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 解析钢铁贸易的批量报价Excel文件，单文件数据量较大，需延长解析超时时间 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 支持上传月度的钢铁贸易成交汇总文件，满足批量数据导入需求 |
| `分段长度` | `1000 字符` | 拆分长文档的钢铁报价数据，确保每段包含完整的品种、规格与价格信息，便于模型理解 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：对话生成后未在底部显示导出Word的下载链接。原因：未在工作流中配置文件导出节点，或未将生成的日报内容正确绑定至导出节点的输出字段。
- 现象：升级4.9.0版本后，刷新对话页面时原有对话记录丢失，仅显示新对话。原因：未开启对话历史持久化配置，或部署时未正确关联对话存储的数据库实例。
- 现象：配置系统提示词后，AI提示未上传文件，无法读取内置文档的解读内容。原因：未将文档上传至知识库并关联至当前应用，或系统提示词中未正确引用知识库的文档ID与召回规则。

## 怎么确认配好了
- 发起包含具体钢铁品种、规格的测试对话，检查AI是否能准确返回对应品类的价格数据，无歧义表述。
- 上传一份包含多组钢铁报价的Excel文件，检查知识库是否能正确解析所有字段，无缺失或错误。
- 进行多轮连续对话，依次询问不同品类的收益率与行情，检查系统是否能保留上下文信息，无需重复询问基础参数。
- 触发对话导出功能，检查是否能生成包含完整日报内容的Word文件并生成有效下载链接。
