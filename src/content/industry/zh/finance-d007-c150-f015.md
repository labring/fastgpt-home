# 铁矿石收益率的部署与升级

## 这个品类的数据长什么样
铁矿石行情数据主要来自大连商品交易所官方行情接口与国内现货交易平台的每日结算数据。交易日内每15分钟推送一次实时增量行情，每日收盘后生成当日完整的日报文档。文档结构包含合约标识、交割标准、供应产地、当日成交均价、当日最高最低价、当日成交量、当日持仓量。成交均价、最高最低价的单位为元/吨，成交量、持仓量的单位为交易手数。

## 这些特征在「部署与升级」这一环带来什么约束
铁矿石行情的高频更新与固定字段格式，对部署与升级环节提出明确约束。首先，数据源依赖公网接口，内网部署需配置代理转发；其次，实时行情与每日全量数据需分别配置拉取任务，定时间隔需匹配交易所的更新节奏；再者，固定的字段结构要求部署时提前配置字段映射规则，避免解析后出现字段缺失；最后，版本升级时需同步更新接口解析逻辑，防止因数据源接口格式微调导致任务失败。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FIELD_MAPPING` | `{"合约标识":"contract_code","成交均价":"avg_price","成交量":"trade_volume"}` | 匹配铁矿石行情文档的固定字段名，避免知识库解析后字段缺失 |
| `CRON_JOB_INTERVAL` | `15 分钟` | 适配大连商品交易所交易日每15分钟的实时行情更新节奏 |
| `DAILY_FETCH_TIME` | `15:30` | 匹配交易所当日完整行情数据生成的常规时间 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 适配单份铁矿石日报文档的常规大小上限 |
| `PROXY_ENABLED` | `开启` | 适配内网部署场景下访问公网行情接口的需求 |
| `API_REQUEST_TIMEOUT` | `30 秒` | 适配交易所行情接口的常规响应延迟范围，避免超时中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 执行`docker build`命令时出现`ERROR: failed to solve: archive/tar: unknown file mod`报错。原因是未正确配置部署服务器与数据源配置文件的权限映射，导致构建过程中无法正常读取配置文件。
- 调用行情接口时返回`404 - 未找到资源`错误。原因是未将部署服务器IP加入大连商品交易所行情接口的白名单，或配置的合约标识格式不符合交易所要求。
- 升级至4.9.0版本后，铁矿石日报播报的部分字段为空。原因是升级时未同步更新`PARSE_FIELD_MAPPING`配置，新版本的解析规则与旧版字段映射不匹配。

## 怎么确认配好了
- 手动触发一次实时行情拉取任务，检查返回的数据集是否包含所有预设字段，且单位符合元/吨、交易手数的要求。
- 在内网部署环境中，测试访问大连商品交易所行情接口，确认代理配置生效，无连接超时或拒绝类报错。
- 升级版本后，对比升级前后的`PARSE_FIELD_MAPPING`配置，确认字段映射规则未被意外修改。
- 查看FastGPT的任务日志，确认最近15分钟内的实时行情拉取任务均执行成功，无失败记录。
