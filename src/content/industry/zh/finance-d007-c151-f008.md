# 铁路公路收益率的工具调用与插件

## 这个品类的数据长什么样
铁路公路收益率相关数据取自交通运输部路网监测与应急处置中心的公开运营数据集、各区域交通运营主体的官方运营披露文件。更新节奏存在差异：全国干线铁路数据每日更新，省级公路区域数据按工作日更新。文档以结构化CSV或API返回的JSON格式呈现，包含线路编码、运营主体类型、客货周转量、运营总成本、运营总收入等字段，单位分别为字符串、分类标签、百万吨公里、万元人民币、万元人民币。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据源分散且鉴权方式不同，需支持多源凭证配置以分别对接铁路官方接口与区域公路平台；更新节奏差异要求插件支持按不同周期触发拉取任务，避免过度调用或数据滞后；字段命名不统一需配置标准化映射规则，确保不同来源的运营数据可被统一识别；单位存在潜在差异需配置转换逻辑，将不同披露单位的金额数据统一为标准格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_multi_source_auth` | 按数据源类型分别配置API密钥、OAuth2.0凭证 | 铁路与公路数据源的鉴权方式存在差异，需单独配置权限以保证访问合法性 |
| `plugin_update_interval` | 铁路数据设为`86400 秒`，公路区域数据设为`28800 秒` | 匹配两类数据的官方披露更新周期，避免数据滞后或过度调用 |
| `field_mapping_rule` | 配置通用字段映射表，将不同数据源的自定义营收字段映射为统一字段 | 不同运营主体的字段命名存在差异，需标准化处理以确保模型可识别有效数据 |
| `unit_conversion_threshold` | 设置为`10000` | 适配多数数据源披露的金额单位为万元的场景，完成单位统一转换 |
| `plugin_timeout` | `300 秒` | 跨多源数据拉取需较长等待时间，避免提前触发超时中断 |
| `api_rate_limit` | 按实测标定 | 不同数据源的QPS限制存在差异，需根据实际调用情况调整参数 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用插件时返回`connect ECONNREFUSED 172.23.0.2:3001`错误，原因是未正确配置数据源的公网访问权限或内网穿透规则，导致FastGPT服务无法连通目标数据源接口。
- 拉取的铁路公路数据中核心字段为空，原因是未配置`field_mapping_rule`，未将数据源的自定义字段映射为统一标识，导致模型无法识别有效运营数据。
- 连续调用时频繁返回`429 Too Many Requests`错误，原因是未配置`api_rate_limit`参数，未匹配数据源的QPS限制阈值，导致调用频率超限。

## 怎么确认配好了
- 调用测试接口，查看返回的结构化数据是否包含统一命名的核心字段，字段单位与配置的转换规则匹配。
- 查看插件运行日志，确认多源鉴权凭证已通过验证，无连接失败类报错。
- 统计多次调用的耗时，确认耗时未超过配置的超时阈值。
- 核对插件的运行记录，确认数据更新频率与配置的触发周期一致。
