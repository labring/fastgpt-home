# 风电收益率的工具调用与插件

## 这个品类的数据长什么样
风电收益率相关数据主要来源于区域电力交易结算平台、风电场站运维系统的日度结算数据。更新节奏为每日T+1完成前一日全量数据的更新，无法实时获取当日未完成结算的业务数据。文档结构多为结构化JSON接口返回或CSV格式，包含场站唯一标识、统计周期、额定装机容量、实际发电量、上网结算电价、固定运维分摊成本、核算收益值等字段。单位方面，实际发电量以兆瓦时为单位，上网结算电价以元/千瓦时为单位，核算收益值以元为单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
因风电收益率数据按场站独立归集，工具调用需携带场站唯一标识作为筛选参数，否则返回数据无明确业务指向。由于数据采用T+1结算更新，工具调用的查询周期需限定在已完成结算的历史日期，无法查询当日或未完成结算的时段，否则会返回空值或错误数据。接口返回包含多维度运维与结算字段，需明确指定所需返回字段以控制数据传输体积，避免无效数据占用调用资源。多数电力交易数据源存在调用频次限制，需配置工具的调用频率阈值，防止触发限流规则。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `TOOL_CALL_ENABLE` | `是` | 该场景需调用外部数据接口获取风电收益率相关数据，需启用工具调用功能 |
| `tool_timeout` | `30 秒` | 风电交易数据接口响应通常在10-25秒区间，30秒可覆盖多数正常调用场景，避免过早超时 |
| `required_response_fields` | `["场站编码","统计日期","实际发电量","上网电价","核算收益"]` | 仅返回业务必需字段，减少数据传输量，降低解析复杂度 |
| `api_auth_method` | `API_KEY` | 多数电力交易数据源采用API密钥鉴权，需绑定专属密钥以获取数据访问权限 |
| `rate_limit_per_minute` | `10 次` | 区域电力交易平台的公开接口通常限制每分钟调用次数不超过15次，设置10次可避免触发限流 |
| `date_range_policy` | `仅查询T+2及更早日期` | 风电收益率数据为T+1更新，查询当日或前一日当日时段会返回未结算的空数据 |
| `tool_integration_protocol` | `REST_API` | 多数区域电力交易平台提供REST风格的公开接口，自研插件可根据需求选择MCP协议 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用工具时返回`The tool call is not supported`错误，原因是未在FastGPT应用配置中启用工具调用功能，或未为当前模型绑定工具调用权限。
- 现象为调用时间插件获取统计日期时返回格式错误或超时，原因是未按数据源要求指定日期格式参数，或未配置合理的`tool_timeout`参数。
- 现象为4.8.19及以上版本调用本地模型时工具调用失败，原因是新版本中工具调用的模型适配参数发生变更，未同步更新模型的工具调用触发配置。

## 怎么确认配好了
- 在FastGPT的应用调试界面发起单场站的历史数据查询，检查返回结果是否包含预设的`required_response_fields`字段。
- 查看工具调用日志，确认未触发`rate_limit_per_minute`设置的限流规则，且响应时长未超过`tool_timeout`的配置值。
- 尝试查询当日时段的数据，确认返回结果为空或提示未结算，符合T+1更新的业务规则。
- 检查模型配置中的工具调用权限是否开启，确认当前模型支持工具调用功能。
