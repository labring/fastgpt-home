# 风电收益率的模型接入与配置

## 这个品类的数据长什么样
风电收益率日报的数据来源包含风电场站SCADA监控系统、区域电网结算平台、气象观测站点三类，主要用于金融机构的风电资产收益播报与估值参考。数据更新节奏为每日凌晨完成前一日全量结算数据更新，每15分钟推送一次实时功率数据用于当日收益估算。单条数据的文档结构包含场站唯一标识、当日累计发电量、上网结算电量、脱硫煤电价、当日运维成本、补贴结算金额、当日总收益七个固定字段。字段单位分别为：发电量兆瓦时、电价元/兆瓦时、成本与收益元，无百分比类统计指标。

## 这些特征在「模型接入与配置」这一环带来什么约束
风电收益率数据来自场站监控、电网结算、气象站点三类来源，且涉及金融机构的资产估值需求，需支持跨系统拉取与权限校验，避免未授权的敏感数据被调用。固定字段结构要求模型接入需配置结构化数据解析规则，无法仅依赖通用非结构化解析逻辑，确保金融播报的字段准确性。每日全量更新与每15分钟增量推送的混合节奏，要求配置双模式同步机制，避免数据延迟影响金融播报的时效性。同时，数据包含财务敏感字段，需配套配置数据脱敏规则，防止核心资产信息泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `dataSourceRefreshInterval` | `86400 秒 + 900 秒` | 每日全量更新在凌晨完成，每15分钟的增量数据需实时同步，总间隔覆盖全量与增量需求 |
| `structuredDataParseMode` | `严格字段匹配` | 风电收益率数据有固定的七个字段，严格匹配可避免字段解析错位 |
| `dataValidationThreshold` | `按场站额定功率的120%` | 风电实际发电量不会超过额定功率的合理上限，超出则判定为异常数据 |
| `multiSourceSyncTimeout` | `600 秒` | 跨电网与场站的数据源同步需较长响应时间，超时时间过短会导致同步失败 |
| `maxContext` | `8000–12000 字符` | 单场站日报数据加历史对比数据的总长度处于该区间，适配多数开源模型的上下文限制 |
| `reasoningMaxTokens` | `2000 tokens` | 收益率播报的推理步骤有限，该取值可覆盖完整的收益计算与播报逻辑 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用第三方API接口时返回`402 Payment Required`错误码，或界面提示“API权限不足”。原因是未配置正确的API密钥，或使用的API通道未开通对应模型的调用权限。
- 现象为选择本地部署的开源模型时，预设的收益率播报引导词未生效，输出内容偏离主题。原因是未在模型接入配置中开启引导词强制生效参数，或配置的引导词格式不符合模型的token识别规则。
- 现象为模型输出的推理内容未按配置替换为`reasoning_c`标签，或出现未格式化的<think>块。原因是未正确配置模型的输出格式规则，导致自定义标签替换失败。

## 怎么确认配好了
- 手动导入一份模拟的风电收益率日报数据，查看模型解析后的字段是否与原文档的场站ID、发电量等字段完全匹配。
- 触发一次跨数据源同步任务，查看同步日志中是否无超时错误，且数据字段完整无缺失。
- 输入测试prompt，验证模型输出的内容是否符合预设的收益率播报格式，且未出现字段错误或内容偏离主题。
- 查看模型调用的token消耗记录，确认`maxContext`与`reasoningMaxTokens`的配置未超出实际使用的上限。
