# 饰品收益率的分享与嵌入

## 这个品类的数据长什么样
饰品收益率相关数据主要来源于品牌经销商供货台账、线下门店POS销售数据及行业终端监测平台。数据更新节奏为每周同步一次，当周全量数据于次周一凌晨完成更新。文档采用结构化表格形式，核心字段包含SKU编码、饰品品类、供货单价、零售指导价、成本占比系数。其中供货单价与零售指导价的单位为元/件，成本占比系数为0至1区间的无单位小数，未采用百分比形式展示。

## 这些特征在「分享与嵌入」这一环带来什么约束
饰品收益率数据的周度更新频率，要求分享嵌入组件的缓存时长需匹配该周期，避免展示过期数据。结构化的字段体系要求嵌入组件支持自定义字段筛选，不同使用场景需匹配对应字段组合，例如经销商场景需展示供货单价与成本占比系数，消费者场景仅需展示零售指导价。多SKU的品类特征要求分享链接支持参数化筛选，通过URL参数指定品类或SKU即可加载对应数据，减少无效数据传输。同时，非百分比的数值单位需在嵌入前端渲染时做适配，避免出现单位转换错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `shareLinkExpireTime` | `604800 秒` | 匹配饰品收益率数据每周更新的周期，避免过期数据通过分享链接被访问 |
| `embedComponentCacheTTL` | `604800 秒` | 与数据更新周期保持一致，减少重复拉取全量数据的请求开销 |
| `embedAllowedFields` | `["SKU编码", "品类名称", "供货单价", "零售指导价", "成本占比系数"]` | 覆盖饰品收益率相关的核心数据字段，适配经销商、消费者等不同场景的展示需求 |
| `workflowApiAuthType` | `免登录` | 降低访问门槛，符合V4.9.7版本新增的免登录发布功能特性 |
| `apiRequestTimeout` | `30 秒` | 预留足够缓冲时间，适配结构化数据拉取的常规响应时长 |
| `embedCustomParams` | `["category", "skuId"]` | 支持按品类或SKU筛选数据，适配不同页面的定向展示需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流中通过节点获取分享应用URL时，返回结果为空。原因：未在应用发布页面开启分享功能，或调用的节点参数未绑定正确的应用ID。
- 现象：不同浏览器访问同一条免登录链接，获取到的`userId`字段值不一致。原因：未配置免登录模式下的跨会话标识同步，浏览器的本地存储隔离机制导致标识无法统一。
- 现象：用户通过免登录链接删除对话内容后，后台日志中无对应操作记录。原因：V4.9.7版本默认关闭免登录临时会话的日志留存，未手动开启日志保留开关。

## 怎么确认配好了
- 登录FastGPT后台，进入目标应用的发布设置页，核对`shareLinkExpireTime`的配置值是否与饰品数据更新周期匹配。
- 生成嵌入代码并插入到测试网页，加载后确认展示的数据字段与预设的`embedAllowedFields`列表一致。
- 运行绑定了分享链接获取节点的工作流，检查输出结果中是否包含合法的分享URL地址。
- 开启免登录发布模式，使用两个不同浏览器访问生成的链接，确认会话标识的一致性符合配置要求。
