# 饲料收益率的表单与交互

## 这个品类的数据长什么样
这个品类的数据主要来自农业农村部饲料工业监测系统、国内头部饲料企业的ERP同步数据，以及第三方行业报价平台。更新节奏分为两类：大宗原料类饲料每日早8点全量更新，小众定制饲料品类每6小时增量同步。数据文档为结构化表格格式，单条数据包含饲料品种、原料采购成本（元/吨）、加工分摊成本（元/吨）、出厂指导价（元/吨）、单位盈利额（元/吨）、统计日期五个核心字段，无额外冗余统计项。

## 这些特征在「表单与交互」这一环带来什么约束
该品类的数据更新节奏存在差异，要求表单支持按数据更新时间筛选展示内容，同时在界面标注单条数据的最后更新时间，避免使用过时数据生成报表。字段均为带单位的数值类型，表单需配置严格的非负数值校验，拦截非数字、负数输入。多数据源的特性要求表单提供数据源切换的下拉选项，允许用户选择不同的行业监测平台或企业内部数据作为计算依据。此外，由于数据字段固定，表单提交项需与标准数据字段一一对应，防止因字段不匹配导致的同步失败。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 饲料行业结构化数据文件通常不超过200MB，预留合理缓冲空间 |
| `UPLOAD_FILE_ALLOWED_EXTENSIONS` | `["csv", "xlsx", "xls"]` | 饲料行业常用的收益率数据格式为CSV与Excel表格 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | 大型饲料数据文件的解析耗时通常在60-90秒，设置120秒可避免超时报错 |
| `FORM_FIELD_VALIDATION_RULE` | `仅允许正数值与标准字段名` | 饲料数据字段均为带单位的正数值，需拦截非法输入与不匹配字段 |
| `STREAM_RESPONSE_ENABLED` | `开启` | 收益率播报需实时展示计算进度，提升交互流畅度 |
| `WORKFLOW_PLUGIN_INPUT_SCHEMA` | `与标准饲料数据字段一一对应` | 确保插件输入与标准数据格式匹配，避免同步失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流中启用文件上传组件后，调用文档解析工具时返回`413 Request Entity Too Large`错误。原因：未调整`UPLOAD_FILE_MAX_SIZE`参数，默认值过小导致大型饲料数据文件无法上传。
- 现象：添加自定义饲料数据解析插件后，工作流任务中未显示输入输出参数，且无报错日志。原因：未在插件配置中正确声明`WORKFLOW_PLUGIN_INPUT_SCHEMA`与输出字段，导致平台无法识别参数结构。
- 现象：表单提交后出现字段为空的报错，生成的收益率报表数据缺失。原因：表单校验规则未严格限制必填字段，或输入项与标准数据字段不匹配。

## 怎么确认配好了
- 上传一份标准饲料数据文件，检查上传进度与解析结果是否符合预期，确认文件大小与格式符合配置要求。
- 进入工作流插件配置页面，查看输入输出参数是否与标准饲料数据字段一一对应，确认插件声明正确。
- 发起一次收益率播报请求，检查是否以流式方式逐步返回计算结果，确认流式回复配置生效。
- 提交非法数值（如负数、非数字字符）至表单，检查是否触发对应校验拦截，确认表单校验规则生效。
