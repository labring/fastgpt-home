# IT 服务智能尽调报告的HTTP 接口与外部系统

## 这个品类的数据长什么样
IT服务智能尽调报告的数据主要来自工商公开信息平台、厂商官方披露的资质文件、第三方合规认证平台、客户验收交付文档。数据更新节奏随项目交付节点触发，单次更新覆盖对应项目的全量信息。文档结构分为基础资质区、技术能力区、交付实绩区、合规资质区四个模块，包含「服务商统一社会信用代码」、「核心技术人员人数」、「近三年交付项目数」、「合规认证编号」等字段，字段单位分别为字符型、人、整数、字符型。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
IT服务智能尽调报告的数据特征对HTTP接口与外部系统带来多重约束。多源分散的数据来源要求接口支持多套鉴权配置，适配不同外部平台的接入规则。固定的字段结构要求入参必须严格匹配预设字段名，必填字段缺失将导致数据校验失败。非固定的更新节奏需要接口支持按需同步与批量定时同步两种模式，适配不同场景的数据更新需求。单次报告包含多项目信息的特性要求接口支持分页返回，避免单次传输过载。合规相关字段的加密传输需求，要求接口启用HTTPS协议并支持自定义证书配置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `EXTERNAL_API_AUTH_TYPE` | `api_key` 或 `oauth2` | 适配对接的外部平台的鉴权规则，工商公开信息平台多使用api_key，合规认证平台多使用oauth2 |
| `REQUIRED_SYNC_FIELDS` | `["服务商统一社会信用代码","近三年交付项目数"]` | 匹配IT服务尽调报告的核心必填字段，缺失将导致报告无法通过有效性校验 |
| `SYNC_TRIGGER_MODE` | `on_demand` 或 `scheduled` | 适配非固定的更新节奏，按需同步适配临时数据更新，定时同步适配批量周期性更新 |
| `API_PAGE_SIZE` | `20–50` 条/请求 | 平衡单次传输负载与响应速度，避免过大导致接口超时，过小则增加请求次数 |
| `EXTERNAL_SYNC_TIMEOUT` | `300 秒` | 适配多源接口调用的平均响应时长，避免因外部平台响应缓慢导致同步任务失败 |
| `HTTPS_CERT_CONFIG` | 自定义企业内部证书 | 适配内网部署场景，满足企业内部数据传输的安全合规要求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：访问`/api/core/dataset`接口返回502 Bad Gateway错误，原因：v4.14.4版本内网部署时，未正确配置nginx反向代理的端口转发规则，导致请求无法到达FastGPT服务端口。
- 现象：调用外部同步接口后返回`400 Bad Request`，系统日志显示缺失必填字段，原因：入参未包含`REQUIRED_SYNC_FIELDS`配置中指定的核心字段，未匹配尽调报告的数据结构要求。
- 现象：使用`curl`命令调用接口提交尽调数据时返回`413 Request Entity Too Large`，原因：未配置`UPLOAD_FILE_MAX_SIZE`参数，或取值小于单份尽调报告的文件大小。

## 怎么确认配好了
- 调用`/api/core/dataset`接口，传入包含`REQUIRED_SYNC_FIELDS`配置中指定字段的测试数据，检查返回状态码为200，且数据成功同步至对应知识库。
- 查看系统运行日志，确认外部接口调用时鉴权信息正确加载，无鉴权失败相关报错。
- 触发一次按需同步任务，检查同步结果的返回条数符合`API_PAGE_SIZE`的配置预期。
- 上传一份符合常规格式的尽调报告文件，确认上传请求无`413 Request Entity Too Large`类报错。
