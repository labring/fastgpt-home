# 专业服务智能尽调报告的部署与升级

## 这个品类的数据长什么样
专业服务智能尽调报告的数据主要来自工商公示系统、行业监管数据库、客户提交的尽职材料、公开征信报告等公开或授权渠道。数据更新节奏存在差异：工商主体信息按季度更新，征信报告按月度更新，客户提交的尽职材料按需更新。单份报告文档结构固定，包含主体基本信息、关联方排查清单、合规风险提示、财务概览四大模块，字段包含统一社会信用代码、成立日期、注册资本（单位：万元）、营收规模（单位：亿元）等标准化标识项。

## 这些特征在「部署与升级」这一环带来什么约束
多源数据接入需求要求部署阶段需配置多数据源同步的适配参数，避免因数据源格式差异导致解析失败；更新节奏不一致要求升级阶段需支持按不同数据源配置独立的定时同步周期，确保数据新鲜度匹配业务需求；长文档特性要求部署时调整文件解析的超时与体积限制参数，避免大体积尽调报告被截断；多团队协作场景要求升级时补充项目级权限隔离配置，防止不同客户的尽调数据交叉访问。此外，专业服务场景下的报告包含敏感客户信息，部署阶段需配置数据加密与访问审计参数，符合合规要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 单份专业尽调报告通常包含多页附件，单份文件体积较大 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `900 秒` | 长文档解析需更长处理时间，避免中途中断 |
| `maxContext` | `8000–12000 字符` | 尽调报告内容密度高，需保留足够上下文以覆盖核心风险信息 |
| `召回条数` | `前 8 条` | 尽调分析需覆盖多维度风险点，召回过多会增加推理负担 |
| `SYNC_CRON_EXPRESSION` | `0 0 2 * * *` | 按每日凌晨2点配置，避开业务高峰同步工商、征信等公开数据 |
| `HTTPS_CERT_PATH` | `./certs/fullchain.pem` | 本地部署或自有域名需指定合法SSL证书文件路径 |
| `HTTPS_KEY_PATH` | `./certs/privkey.pem` | 对应SSL证书的私钥文件路径 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为部署后知识库无法同步尽调报告数据，返回状态码413 Request Entity Too Large。原因是未调整`UPLOAD_FILE_MAX_SIZE`参数，默认值过小无法容纳大体积尽调报告附件。
- 现象为团队成员无法访问部署的尽调分析程序，无法查看共享应用。原因是未配置团队分组权限，默认仅创建者可访问应用，未开放对应项目组的访问权限。
- 现象为本地部署后无法通过HTTPS访问服务，浏览器提示证书不受信任。原因是未在配置文件中正确指定`HTTPS_CERT_PATH`与`HTTPS_KEY_PATH`参数，证书文件路径配置错误。

## 怎么确认配好了
- 上传一份标准专业尽调报告，检查解析任务日志无超时报错，知识库中显示对应解析完成的文档。
- 邀请测试成员加入对应项目组，验证是否可正常访问部署的尽调分析应用，无权限报错。
- 配置SSL证书后，通过浏览器访问服务地址，检查地址栏显示安全锁标识，无证书警告。
- 手动触发一次数据同步任务，检查知识库中新增对应数据源的向量数据，无同步失败日志。
