# 专用设备智能尽调报告的HTTP 接口与外部系统

## 这个品类的数据长什么样
专用设备智能尽调报告的数据来源包括设备制造商官方技术手册、出厂质检报告、第三方计量校准机构的检测数据、设备运维台账的结构化导出数据。更新节奏存在差异：制造商公开参数更新周期为季度，运维台账数据每日同步，校准报告数据随设备校准周期更新。单份报告的文档结构包含设备基本信息、核心性能参数、合规检测项、运维历史记录。核心字段的单位有明确规范：额定功率单位为千瓦（kW），加工精度单位为微米（μm），运行时长单位为小时（h），安全认证编号为带字母前缀的字符串，设备序列号为16位纯数字串。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
专用设备尽调数据的多源异构特征，要求HTTP接口支持RESTful、SOAP等多种请求协议的适配配置，需分别配置对应请求头、鉴权方式与响应解析规则。核心参数的单位校验约束：接口需强制校验额定功率、加工精度等字段的单位格式，拒绝不符合标准单位的输入数据。不同数据源的更新频率差异，要求配置差异化的定时拉取任务，避免统一配置引发无效请求或数据更新不及时。长文本运维记录的分页拉取需求，要求接口支持分页参数配置，避免单次请求返回过大载荷导致超时。固定格式的序列号与认证编号，需在接口入参环节配置正则表达式规则，过滤无效数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `external_api_timeout` | `600 秒` | 专用设备运维数据的单接口拉取可能包含多页历史记录，600秒可覆盖分页拉取的完整请求周期，避免因数据量较大导致超时。 |
| `unit_validate_enabled` | `开启` | 专用设备参数需严格匹配法定计量单位，开启后可自动校验额定功率、加工精度等字段的单位格式，确保数据合规。 |
| `manufacturer_pull_interval` | `90 天` | 制造商公开参数的更新周期为季度，90天的拉取间隔可匹配其更新节奏，避免无效请求。 |
| `ops_pull_interval` | `1 天` | 运维台账数据每日产生新记录，1天的拉取间隔可确保数据同步的及时性。 |
| `default_page_size` | `20 条` | 单份尽调报告的运维记录分页返回20条可平衡接口载荷与响应速度，适配多数专用设备的运维数据量。 |
| `request_auth_type` | `API_KEY 鉴权` | 多数第三方检测机构、制造商的公开数据接口采用API_KEY鉴权，可配置固定密钥实现安全对接。 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部数据源接口返回`401 Unauthorized`错误，测试时无法完成鉴权。原因：未正确配置`request_auth_type`参数，或填写的API_KEY与第三方接口要求的密钥不匹配。
- 现象：单次拉取返回数据量过大，接口返回`504 Gateway Timeout`错误。原因：未配置`default_page_size`参数，拉取了全部运维历史记录，超出接口载荷限制。
- 现象：加工精度字段在尽调报告中显示为空。原因：未开启`unit_validate_enabled`配置，第三方接口返回的单位为非标准格式（如“mm”，未采用“μm”格式），导致字段解析失败。

## 怎么确认配好了
- 调用配置好的外部数据源接口，查看响应头与返回字段，确认鉴权参数已正确携带，核心字段（如额定功率、序列号）已正常返回。
- 触发一次手动拉取任务，查看任务日志，确认拉取间隔与数据源类型匹配，无超时报错。
- 模拟传入非标准单位的参数，确认接口返回校验失败提示，或自动转换为标准单位（若配置了转换规则）。
- 查看数据同步记录，确认不同数据源的更新频率符合预期，无重复或遗漏的同步记录。
