# 产业园区智能尽调报告的工具调用与插件

## 这个品类的数据长什么样
产业园区的尽调数据来源包括国土空间规划公开平台、园区管委会官方招商台账、不动产登记系统及入驻企业年报。数据更新节奏存在差异：招商入驻数据每月更新，不动产权属数据按季度同步，年度经营年报则每年更新。文档结构分为结构化字段与非结构化文本两部分，结构化字段包含园区总占地面积、容积率、亩均税收、入驻企业清单等，单位涉及亩、平方米、万元/亩/年；非结构化文本包含园区产业定位规划、招商政策说明等内容。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据的分散性要求工具调用同时支持结构化参数查询与非结构化内容抽取，插件需适配不同数据源的接口格式。不同更新周期的数据源需要插件支持自定义缓存过期时间，避免调用过期数据。结构化字段包含复合单位的数值类型，工具调用的参数校验需适配多单位字段的格式要求。园区尽调报告文档篇幅较长，工具调用需支持分页拉取内容，避免单次请求超出上下文长度限制。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `mcp_tool_param_type_strict` | `true` | 产业园区数据包含亩均税收、容积率等带明确类型的字段，严格校验参数类型可避免类型不匹配报错 |
| `tool_call_max_tokens` | `8000–12000 令牌` | 产业园区尽调报告文档篇幅较长，适配长文本工具调用的上下文需求 |
| `tool_call_stream_output` | `false` | 尽调报告输出需完整呈现工具调用结果，关闭流输出可避免内容截断 |
| `workflow_tool_knowledge_ref_enable` | `true` | 结合知识库的园区行业数据，补充工具调用的背景信息 |
| `tool_call_timeout` | `300 秒` | 园区数据来源分散，预留足够时间完成多数据源拉取 |
| `mcp_service_param_type_fix` | `按实测标定` | 修复4.9.6版本中type被固定为string的问题，需根据实际字段调整参数类型规则 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用MCP服务时提示`param type mismatch`错误，或返回的亩均税收字段为字符串类型，或返回的亩均税收字段为非数值类型。原因：部署4.9.6版本时，未调整MCP服务的参数类型校验规则，默认将所有参数强制固定为string类型。
- 现象：工具调用结果以流式分段返回，无法直接拼接为完整的尽调报告文本。原因：未将`tool_call_stream_output`配置项设置为`false`，默认启用了流输出模式。
- 现象：工作流中的工具调用模块未触发任何外部服务请求，无相关日志输出。原因：未配置工具调用的目标服务地址，或插件的访问权限未正确设置。

## 怎么确认配好了
- 发起一次园区入驻企业清单的工具调用请求，查看返回参数的类型是否与预期一致，例如亩均税收字段是否为数值类型，或亩均税收字段是否为字符串类型。
- 触发工具调用，查看输出是否为完整的单段文本，无分段截断的情况。
- 在工作流中运行工具调用模块，查看日志中是否包含知识库召回的相关内容，且工具调用请求已成功发送。
- 检查工具调用模块的运行日志，确认未出现超时报错，且请求已在预设的超时阈值内完成响应。
