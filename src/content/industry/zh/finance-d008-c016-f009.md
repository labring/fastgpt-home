# 光伏智能尽调报告的引用来源与溯源

## 这个品类的数据长什么样
光伏智能尽调报告的数据主要来自电站运维台账、组件出厂检测文档、电网并网上报数据、区域气象辐照数据集。数据更新节奏覆盖实时运维日志、每日发电统计、月度并网报表、季度批次检测报告。单份文档多为结构化表格或长图文报告，包含电站唯一标识、组件型号、辐照强度（单位kWh/㎡）、发电功率（单位kW）、故障编码、检修周期等字段，部分归档报告还附带现场巡检的照片附件。

## 这些特征在「引用来源与溯源」这一环带来什么约束
光伏品类的数据多源异构且字段带明确单位，要求引用溯源时精准匹配字段名与单位，避免不同电站的同名称段混淆。数据格式覆盖结构化台账、图文报告与附件文件，召回时需区分文档类型，关联对应原始存储路径与生成时间。实时运维日志的高频更新特性，要求数据源同步配置匹配更新节奏，确保引用内容为最新有效状态。同型号组件存在多批次检测报告，溯源时需额外匹配生产批次标识，防止引用内容与对应电站的实际参数不匹配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前8-12条` | 光伏尽调报告的引用内容多为多字段关联的长片段，过多召回会导致上下文冗余，过少则无法覆盖电站核心运维与检测数据 |
| `相似度阈值` | `0.72-0.85` | 光伏数据存在大量语义接近的字段，如“辐照强度”与“日照量”，阈值过低会引入无关召回，过高则遗漏有效匹配内容 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 光伏的长图文检测报告包含大量表格与图片解析，需预留足够时间完成文本拆分与元信息提取 |
| `引用去重开关` | `开启` | 同一电站的运维日志可能重复上传至知识库，开启后可避免同一文档片段被多次引用，确保溯源信息唯一 |
| `溯源信息保留字段` | `电站ID,组件型号,生成时间,原始文件名` | 光伏尽调报告的溯源需明确对应电站与文档批次，这些字段可快速定位原始数据来源 |
| `重排返回条数` | `前5-7条` | 重排可优化召回内容的相关性排序，匹配光伏数据多字段关联的特性，减少无效引用 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：100个光伏相关文件上传至同一知识库后，约半数显示训练异常，重新上传后引用时仍出现重复溯源。原因：部分文件的元信息（如电站ID字段）存在格式错误，导致解析时无法正确关联溯源信息，且未开启引用去重导致重复数据未被过滤。
- 现象：语义检索的引用上限设置后，返回的引用内容包含大量非光伏电站的无关数据。原因：未结合光伏数据的语义特性调整相似度阈值，且召回条数设置过高，引入了大量低相关性内容。
- 现象：引用内容模板中使用`{{id}}`时，显示的是知识库集合的ID，未显示单条引用数据的ID。原因：未正确配置溯源信息保留字段，未提取单条数据的唯一标识，导致模板无法正确获取引用数据的ID。

## 怎么确认配好了
- 上传单份光伏检测报告，触发知识库解析，查看解析后的元信息是否包含预设的溯源保留字段，确认字段完整。
- 发起一次光伏电站的尽调查询，查看返回的引用内容是否附带正确的原始文件名与生成时间，确认溯源信息关联正确。
- 上传两份内容重复的光伏运维日志，查看引用列表是否仅保留一条有效溯源记录，确认去重功能生效。
- 调整相似度阈值后发起查询，对比前后的召回内容数量，确认阈值配置对召回结果的影响符合预期。
