# 光伏智能尽调报告的模型接入与配置

## 这个品类的数据长什么样
光伏智能尽调报告的数据来源包括电站现场勘测文件、并网验收检测报告、运维台账及区域气象数据。项目核心参数在项目竣工后按季度同步更新，日常运维数据每日更新。文档多为多页PDF或结构化Excel，分为勘测、运维、并网三个模块，包含组件型号、装机容量、辐照强度、发电总量等字段，单位分别为千瓦峰（kWp）、瓦每平方米（W/㎡）、千瓦时（kWh）等。

## 这些特征在「模型接入与配置」这一环带来什么约束
光伏尽调数据的多源异构特征，要求模型接入环节配置跨源字段对齐规则，避免不同来源的同类参数出现匹配偏差。数据更新节奏存在季度级项目参数与每日级运维数据的差异，需配置增量同步触发机制，减少全量拉取的资源消耗。文档字段多且单位体系独立，需配置前置单位归一化处理步骤，确保模型输入的参数单位统一。单份尽调文档页数较多，需调整解析超时阈值，避免因解析超时导致任务失败。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 单份光伏尽调文档包含多页勘测与运维数据，解析耗时较长 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 光伏尽调文档可能包含大量高清勘测照片与结构化表格，单文件体积较大 |
| `maxContext` | `8000–12000 字符` | 光伏尽调报告字段较多，需足够上下文长度承载完整参数信息 |
| `DATA_SYNC_INTERVAL` | `86400 秒` | 日常运维数据每日更新，按日同步可保证数据时效性 |
| `FIELD_MAPPING_RULE` | 按勘测/运维/并网模块分类映射 | 光伏尽调文档分为三个固定模块，分类映射可减少字段匹配偏差 |
| `NORMALIZE_UNIT_SWITCH` | `开启` | 光伏数据存在多种单位体系，开启后可自动完成单位统一转换 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：本地部署的光伏专用模型添加后无法调用，返回`404 Model not found`错误。原因：未正确配置模型的本地部署路径与端口映射，导致平台无法访问模型服务。
- 现象：解析光伏尽调的Excel文档时，返回通用提示文案，无法提取有效字段。原因：未配置针对光伏行业Excel的自定义解析模板，模型无法识别专属字段格式。
- 现象：调用Qwen3系列模型时，无法启用思考过程配置，输出未包含推理步骤。原因：未在模型接入界面开启`enable_thinking`参数，或当前版本未支持该模型的思考开关功能。

## 怎么确认配好了
- 上传一份标准光伏尽调文档，查看解析后的字段列表是否包含预设的勘测、运维、并网模块字段。
- 触发一次数据同步任务，检查同步日志中是否显示增量拉取的运维数据条数符合预设的更新节奏。
- 调用模型完成一次尽调报告生成任务，查看返回结果中是否包含统一单位的参数数值。
- 查看模型调用日志，确认解析超时、文件上传等环节的耗时符合预设配置的取值范围。
