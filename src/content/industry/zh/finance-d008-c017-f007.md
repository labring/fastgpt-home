# 光学光电子智能尽调报告的工作流编排

## 这个品类的数据长什么样
光学光电子领域的尽调数据主要来自中国光学光电子行业协会公开监测数据、上市主体定期披露报告、第三方供应链价格监测平台、国家知识产权局公开专利信息。更新节奏因数据源不同存在差异，行业监测数据按月度更新，上市公司财报按季度、年度更新，专利数据实时同步，供应链采购数据按周度更新。文档形态包含结构化CSV/Excel表格、PDF格式行业分析报告、半结构化的企业经营台账。核心字段包括产品型号、良品率、月出货量、原材料采购单价、专利授权数量，对应单位分别为型号标识、百分比、万台、元/颗、件。

## 这些特征在「工作流编排」这一环带来什么约束
光学光电子领域的多数据源、多更新节奏、混合文档形态与特殊字段单位，对工作流编排带来多重约束。多数据源并行拉取需适配不同接口权限与返回格式，避免数据拉取冲突。不同更新频率的数据源需绑定独立的定时触发规则，确保核心经营数据按对应周期同步。混合结构化与非结构化文档需分别配置结构化解析节点与大模型文本提取节点，避免格式解析失败。特殊字段如良品率的百分比单位、出货量的万台单位，需在数据校验环节配置匹配规则，防止跨品类数据混淆。批量出货数据的体量较大，需配置分片处理节点，降低单次运行的资源占用。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 光学光电子行业的PDF行业报告通常包含多页结构化表格与专业术语，较长的超时时间可确保完整解析所有内容 |
| `分段长度` | `800–1200 字符` | 该品类的技术文档与经营数据包含长句与专业表述，该区间可保留语义完整性，避免上下文溢出 |
| `召回条数` | `前 8 条` | 尽调报告需覆盖供应链、专利、财务多维度信息，该取值可平衡信息覆盖度与处理效率 |
| `相似度阈值` | `0.75–0.85` | 光学光电子领域的专业术语相似度较高，该区间可过滤无关内容，保留核心匹配结果 |
| `POSTGRESQL_CONN_TIMEOUT` | `30 秒` | 供应链数据的数据库连接需快速响应，较短的超时时间可及时排查连接异常，避免工作流阻塞 |
| `全局变量动态赋值规则` | `按数据源标签匹配` | 光学光电子的数据源分为行业报告、财报、专利库三类，通过标签匹配可自动将数据导入对应知识库，简化后续调用 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：使用数据库连接插件连接PostgreSQL时，界面提示“工作流校验失败，请检查是否缺失、缺值，连线是否正常”。原因：未绑定光学光电子专属的数据库连接参数，或未配置数据源标签与连接配置的映射规则。
- 现象：代码运行节点输出的`result`字段传入AI模型时，触发`chat:ai_input_is_e`报错。原因：未对`result`字段进行字符串序列化处理，导致传入的参数格式不符合模型输入要求。
- 现象：文本提取节点返回的光学光电子专业字段（如良品率、出货量）为空或单位错误。原因：未针对该品类的特殊字段配置自定义提取规则，通用提取规则无法识别专业术语与单位格式。

## 怎么确认配好了
- 触发一次测试运行，查看数据拉取节点是否按配置的数据源标签拉取对应光学光电子数据，核对返回的字段与单位是否符合预期。
- 运行文本提取节点，检查返回的专业字段是否完整，调整对应配置项直至覆盖所有目标字段。
- 触发数据库连接测试，确认连接状态正常，无校验失败提示，核对连接参数是否与光学光电子专属数据源匹配。
- 传入代码运行节点的输出结果至AI模型，确认无格式报错，且模型可正常使用传入的`result`数据生成尽调内容。
