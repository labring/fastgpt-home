# 光学光电子智能尽调报告的引用来源与溯源

## 这个品类的数据长什么样
光学光电子行业的尽调数据来源涵盖中国光学光电子行业协会公开监测报告、企业披露的经营公告、上游设备供应商出货记录及专利局公开文档。更新节奏存在差异，行业协会报告按季度发布，企业经营公告随财报节点更新，专利数据实时同步，设备出货记录按周更新。文档形态以结构化表格与非结构化分析报告为主，部分为PDF格式，包含晶圆尺寸、月度产能、单位生产成本、下游客户占比等字段，产能单位为千片/月，生产成本单位为元/片，晶圆尺寸单位为英寸。

## 这些特征在「引用来源与溯源」这一环带来什么约束
光学光电子行业数据的多源分散与更新节奏差异，要求溯源环节需按数据类型绑定对应更新时间戳，过滤超出有效期的引用内容。结构化表格与非结构化分析报告并存的文档形态，需要适配两套解析规则，避免字段提取错位。精密参数类字段的单位与数值绑定紧密，溯源时需同时匹配字段名与单位标识，防止引用参数失真。专利类来源需关联申请号作为唯一溯源标识，确保引用的专利文档可精准追溯至原始公开页面。

| 配置项 | 建议取法 | 这样取的依据 |

| `PARSE_FILE_TIMEOUT_SECONDS` | 900 秒 | 光学光电子行业报告常包含多页表格与长文本，延长解析超时时间避免大文件解析中断 |
| `chunk_size` | 1000–1500 字符 | 光学光电子参数类内容多为紧凑字段组合，该分段长度可保留参数与上下文的关联，避免拆分后字段断裂 |
| `recall_top_k` | 前 8 条 | 光学光电子尽调需覆盖产能、成本、客户等多维度数据，召回8条可覆盖核心信息来源 |
| `similarity_threshold` | 0.75–0.85 | 精密参数的语义匹配需较高阈值，避免低相关的行业泛文被召回 |
| `source_id_mapping_field` | `patent_application_id`、`industry_report_id` | 光学光电子数据包含专利与行业报告两类核心来源，需按不同源类型绑定对应唯一标识字段 |

## 容易做错的三处
- 现象：上下文引用区域输出未渲染的Markdown语法符号（如#、**），无法正常展示格式。原因：未启用文档解析阶段的Markdown格式保留配置，导致格式标记被当作普通文本保留。
- 现象：溯源时出现`source_id not found`报错，无法关联到对应数据源的唯一标识。原因：上传文件时未正确提取并绑定品类专属的唯一字段，导致无法完成源标识映射。
- 现象：召回的引用条数超出预期，包含大量与光学光电子品类无关的泛行业内容。原因：未设置合理的相似度阈值，导致低匹配度的非专属文档被误召回。

## 怎么确认配好了
- 上传一份光学光电子行业报告，查看解析后的分段内容，确认参数字段与上下文未被拆分断裂。
- 发起一次尽调查询，查看返回的引用来源列表，核对每条来源是否绑定了对应品类的唯一标识字段。
- 检查引用内容的格式展示，确认Markdown语法已被正常渲染。
- 调整召回相关配置后发起重复查询，验证引用条数与匹配度是否符合预设要求。
