# 免税智能尽调报告的工作流编排

## 这个品类的数据长什么样
免税智能尽调报告的数据来源包含三类：海关总署备案的免税经营资质文件、离岛免税及跨境免税政策公告、供应商供货明细凭证。更新节奏无固定周期，政策文件随监管要求不定期更新，经营资质按年度完成年检更新，供货明细按月度同步。文档形态涵盖PDF格式的资质扫描件、Word格式的政策解读稿、Excel格式的供货台账。字段包含统一社会信用代码、资质有效期、免税额度（单位为元/人次）、供货品类编码等，部分政策文本包含嵌套式条款结构。

## 这些特征在「工作流编排」这一环带来什么约束
多数据源的接入需求要求工作流需配置跨源同步节点，分别对接资质备案系统、政策公告库与供货台账系统，避免单一数据源的信息缺失。无固定更新节奏要求工作流需支持灵活的定时触发与手动触发双模式，可在政策发布后立即触发手动同步，避免遗漏临时更新的监管文件。文档形态的多样性要求工作流需适配不同格式的文件解析逻辑，单独配置表格与长文本的解析参数，确保Excel供货台账与PDF资质文件均可被正确解析。特殊字段的单位与编码要求工作流需添加标准化字段处理节点，对免税额度、品类编码进行格式校验与统一映射，避免报告中出现单位混乱或编码错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 免税尽调文档多为长文本且嵌套条款，该长度可保留上下文关联同时避免单段内容过载 |
| `schedule_cron` | `0 0 2 * * *` | 每日凌晨2点触发同步，适配资质年检周期与政策临时更新的补同步需求 |
| `similarity_threshold` | 0.75–0.85 | 免税政策文本多为条款式表述，该阈值可过滤无关关联内容，保留核心政策条款 |
| `PARSE_TIMEOUT` | 600 秒 | 大型资质文件的解析耗时通常较长，该时长可覆盖完整解析流程 |
| `retry_count` | 3 次 | 多数据源接入可能存在临时网络波动，该重试次数可降低同步失败概率 |
| `plugin_retry_times` | 2 次 | 调用外部资质校验接口时可能出现临时异常，该重试次数可提升接口调用成功率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流导入其他环境后，引用的资质校验插件无法加载，界面显示「插件未找到」提示。原因：导出工作流时仅导出了JSON结构文件，未携带插件的本地配置与依赖文件，导致导入环境无法识别插件路径。
- 现象：解析免税供货明细Excel文件时，部分品类编码字段为空。原因：未配置`PARSE_FILE_TYPE`为`excel`，默认解析逻辑仅识别纯文本格式，无法解析表格单元格的嵌套内容。
- 现象：工作流触发后返回`504 Gateway Timeout`错误。原因：`PARSE_TIMEOUT`设置值小于大型资质文件的实际解析耗时，导致解析流程未完成即被终止。

## 怎么确认配好了
- 手动上传单份免税经营资质PDF文件，查看解析后的字段是否包含统一社会信用代码、资质有效期等必填项。
- 触发一次手动同步任务，查看多数据源的接入日志，确认所有数据源均完成数据拉取与解析。
- 调用工作流生成单份测试尽调报告，检查报告中是否正确替换了免税额度、政策条款等动态字段。
- 导出当前工作流的JSON文件，导入至测试环境，确认所有引用的插件与节点均正常加载且无配置报错。
