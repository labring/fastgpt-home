# 农化制品智能尽调报告的部署与升级

## 这个品类的数据长什么样
农化制品智能尽调报告的数据主要来自农业农村部农药登记公告、中国农药工业协会行业周报、生产企业公开年报、海关进出口通关数据及第三方质检报告。数据更新节奏不固定，登记类公告随审批进度发布，行业周报每周更新，年报与进出口数据按季度或年度更新。文档多为结构化表格与半结构化报告，包含产品登记证号、有效成分含量、剂型、生产企业资质、毒性等级、合规检测指标等字段，有效成分含量单位多为质量百分比或克每升，登记证有效期为日期型字段。

## 这些特征在「部署与升级」这一环带来什么约束
农化制品的多源异构数据特征，对部署与升级环节带来多重约束。多源数据的更新节奏差异大，需配置适配不同周期的定时同步任务，避免数据滞后或重复同步。结构化字段存在行业专属单位与校验规则，需在解析环节配置自定义字段映射与合法性校验逻辑，防止无效数据进入知识库。部分质检报告为加密格式，需额外配置对应解析插件的权限参数，保障文件正常解析。本地部署时，还需根据数据量调整后台接口的并发处理阈值，避免同步任务过载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 农化制品尽调报告常包含多页质检报告与行业数据合集，单文件体积较大，需适配大文件上传需求 |
| `MINERU_UPLOAD_LIMIT` | `2048 MB` | 调用本地MinerU解析农化大体积报告时，默认2MB限制无法满足需求，适配农化数据的文件规格 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 大型农化质检报告解析耗时较长，避免中途超时中断解析流程 |
| `SYNC_JOB_INTERVAL` | `3600 秒` | 适配农化数据多源更新节奏，平衡数据及时性与服务器资源占用 |
| `MODEL_WORKFLOW_VISIBLE` | `true` | 确保配置的模型在工作流节点中可见，解决4.14.4版本中常见的模型不可见问题 |
| `FIELD_VALIDATION_ENABLE` | `true` | 农化数据包含毒性等级、合规指标等强校验字段，开启校验可过滤无效数据，提升尽调报告准确性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：4.14.4版本本地部署中，工作流模型节点下拉列表无已配置的启用模型。原因：未将`MODEL_WORKFLOW_VISIBLE`配置为`true`，模型未开放至工作流调用范围。
- 现象：本地部署访问`https://ip:3000`时出现证书错误或无法建立连接。原因：未配置本地HTTPS证书，或端口映射未正确开放3000端口，部分环境下需调整反向代理配置。
- 现象：调用MinerU解析农化尽调报告时，返回“文件大小超出限制”报错。原因：未修改`MINERU_UPLOAD_LIMIT`配置项，沿用默认2MB限制，无法适配农化数据的大文件规格。

## 怎么确认配好了
- 上传一份包含多页质检报告的农化尽调文件，检查解析后字段是否完整且单位符合行业规范，确认上传与解析配置生效。
- 在工作流中添加模型调用节点，查看下拉列表是否包含已配置的模型，确认模型可见性配置正确。
- 启动一次手动同步任务，查看后台日志是否有同步超时或失败记录，调整同步间隔与解析超时配置至适配节奏。
- 提交包含合规字段的测试数据，检查是否触发字段校验拦截，确认数据校验配置生效。
