# 包装印刷智能尽调报告的工具调用与插件

## 这个品类的数据长什么样
包装印刷智能尽调报告的数据来源涵盖生产台账、原辅材料采购凭证、印刷品质检报告、环评备案文件及印刷设计源文件。数据更新节奏随企业报送周期调整，无统一固定频率。文档结构包含结构化报表与扫描件附件两类，结构化报表字段涉及印刷幅面、单批次产能、原材料损耗率、VOCs排放值等，单位多为毫米、万套、百分比、毫克每立方米；扫描件附件多为纸质质检报告、采购发票等实拍文件。

## 这些特征在「工具调用与插件」这一环带来什么约束
包装印刷尽调报告的特有数据特征，对工具调用与插件环节带来三点明确约束。第一，包含纸质扫描件附件，要求插件支持OCR解析与多格式文件处理，否则无法提取纸质质检报告中的关键合规参数。第二，结构化字段包含带单位的物理参数与合规指标，要求工具调用时能保留单位信息并完成精准字段映射，避免数据信息丢失。第三，单份报告文档长度较长且附件体积较大，要求工具调用的上下文窗口与解析时长配置适配长文本与大体积文件的处理需求，防止关键内容被截断或解析失败。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `2048 MB` | 包装印刷尽调报告包含多页扫描件、CAD源文件及原辅材料质检报告，单份文件体积通常不超过2048 MB |
| `PARSE_TIMEOUT_SECONDS` | `600 秒` | 解析大体积扫描件或复杂CAD文件时，需要足够的处理时间避免中途超时 |
| `MCP_TOOL_RETRY_THRESHOLD` | `2 次` | 应对MCP工具调用时的网络波动或临时解析失败，降低任务失败率 |
| `TOOL_FILE_VAR_ENABLE` | `开启` | 支持在自定义工作流的上传文件参数中引用自定义变量，适配不同报告周期的调用需求 |
| `PARSE_FILE_ALLOWED_EXTS` | `pdf,jpg,png,dwg,xlsx` | 覆盖包装印刷尽调报告的常见附件格式，包括印刷设计源文件、质检扫描件及采购台账 |
| `DEFAULT_TIMEOUT` | `1200 秒` | 当发布为API接口时，适配长周期尽调数据的调用等待需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用MCP工具时返回`504 Gateway Timeout`错误，或工具返回空结果。原因：未针对包装印刷大体积文件调整`PARSE_TIMEOUT_SECONDS`配置，导致解析过程超时被中断。
- 现象：上传文件时提示“文件大小超出限制”，无法提交尽调报告附件。原因：未将`UPLOAD_FILE_MAX_SIZE`调整至适配包装印刷附件的取值，仍使用默认的2 MB限制。
- 现象：自定义工作流中上传文件参数无法引用变量，导致无法批量调用不同周期的尽调报告工具。原因：未开启`TOOL_FILE_VAR_ENABLE`配置，限制了上传参数的变量引用能力。

## 怎么确认配好了
- 上传一份包装印刷的CAD源文件或多页扫描件，检查解析后是否能提取完整的印刷幅面、产能等字段，无截断或丢失。
- 调用MCP工具并设置自定义变量作为报告周期参数，检查工具是否能正确接收变量并返回对应周期的尽调数据。
- 发布API接口后，设置10分钟以上的超时时间，发起一次大体积文件的解析调用，检查是否能正常完成返回结果。
- 查看工具调用日志，确认重试机制在模拟的网络波动场景下能自动触发并恢复任务。
