# 包装印刷智能尽调报告的知识库检索与召回

## 这个品类的数据长什么样
包装印刷尽调相关数据主要来源于行业协会公开报告、企业内部生产台账、原辅材料采购凭证、合规检测报告与订单交付记录。数据更新节奏按维度区分：原辅材料价格与行业标准按月度更新，生产工序参数按周度更新，合规检测报告按季度更新。文档多为半结构化表格与多页报表，包含原辅材料型号、克重、采购单价，生产车速、油墨配比，质检批次号、合格率等字段，对应单位为g/㎡、m/min、元/吨等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
半结构化的表格与报表文档，要求检索系统支持字段级精准匹配，以匹配文档内的结构化字段特征，避免仅依赖全文相似度检索导致的参数不匹配结果。不同更新频率的分类数据，要求知识库支持按数据类型触发增量同步，全量同步会占用大量计算资源，无法适配月度、周度、季度的更新节奏。字段附带的特定单位，要求检索时保留单位信息匹配，避免将“150g/㎡”的纸张与“150g”的薄膜混淆。长文档的存在，要求分段策略需适配文档结构，避免拆分跨工序的完整参数段落。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 包装印刷尽调文档多为半结构化报表，单段需包含完整工序参数或原辅材料条目，避免拆分跨字段段落 |
| `相似度阈值` | 0.72–0.80 | 包装印刷字段多为标准化参数，需较高匹配度避免召回无关的原辅材料型号或工序数据 |
| `召回条数` | 前 8 条 | 尽调报告需核对多组参数，足够覆盖原辅材料、工序、质检三类核心数据 |
| `增量同步触发条件` | 按数据分类触发，原辅材料数据按月度、生产数据按周度 | 匹配不同品类数据的更新频率，避免无效全量同步 |
| `字段匹配开关` | 开启 | 包装印刷尽调文档包含多字段结构化数据，开启后可实现精准字段级召回 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 部分企业台账文档页数较多，解析耗时较长，避免超时中断解析任务 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：自定义分隔符设置后，分段结果要么合并多页生产台账段落，要么将单条原辅材料条目拆分为多个片段。原因：未结合包装印刷文档的半结构化特征调整分段长度，仅依赖自定义分隔符导致拆分逻辑与文档结构不匹配。
- 现象：提交中文检索请求后，未召回知识库内的英文合规标准文档。原因：未开启多语言检索适配，或知识库导入时未对英文文档进行分块与向量化处理，导致英文文本无法被正确匹配。
- 现象：检索结果出现单位不匹配的条目，例如将“150g/㎡”的纸张召回为“150g”的薄膜。原因：未开启字段级单位匹配配置，仅依赖全文相似度检索，导致单位信息被忽略。

## 怎么确认配好了
- 上传单条原辅材料报表文档，检查分段结果是否完整保留单条条目，无跨字段拆分或合并。
- 提交包含特定单位的检索请求，例如“120g/㎡的铜版纸采购单价”，检查召回结果是否包含匹配单位的条目。
- 触发增量同步任务，检查知识库是否仅更新指定分类的文档，未触发全量重新解析。
- 开启检索日志，查看召回结果的相似度得分是否符合预设阈值区间，无过低得分的无关条目。
