# 化纤智能尽调报告的部署与升级

## 这个品类的数据长什么样
化纤行业智能尽调的数据来源包括国内大宗商品交易平台、中国化纤工业协会公开数据、海关总署公开报关数据。更新节奏分为三类：现货报价数据每日更新，行业开工与库存数据每周更新，进出口数据每月更新。文档结构分为标准化行情数据表、行业动态分析文档、上下游供需台账，字段包含品名、报价、报价单位、日均产量、库存总量，单位统一为元/吨、吨/日、万吨。

## 这些特征在「部署与升级」这一环带来什么约束
多源数据的更新频率差异，要求部署时配置多套定时同步规则，需匹配不同数据源的更新节奏。文档包含长文本分析与结构化表格，需配置差异化的解析参数，避免长文档超时或结构化数据解析不全。字段单位的标准化需求，需配置数据清洗规则统一不同数据源的单位格式。升级时，插件系统与存储依赖的调整可能影响原有数据同步任务，需针对性适配版本变化。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 单份化纤行业分析文档可达数十页，常规解析时长较长，需延长超时时间保障解析完成 |
| `UPLOAD_FILE_MAX_SIZE` | 2000 MB | 化纤行业的上下游供需台账单文件可达1.8GB，需放宽上传文件最大限制 |
| `maxContext` | 800–1200 字符 | 化纤行情数据的核心字段集中，过长上下文会引入无关信息，压缩上下文长度提升精准度 |
| `RECALL_TOP_N` | 前 8 条 | 化纤行业数据的关联维度较多，适量召回可覆盖核心关联信息，避免冗余数据干扰 |
| `CRON_EXPRESSION` | 分场景配置：每日同步用`0 0 6 * * ?`，每周同步用`0 0 2 * * 1 ?`，每月同步用`0 0 4 1 * * ?` | 匹配不同数据源的更新节奏，保障数据同步的时效性 |
| `SIMILARITY_THRESHOLD` | 0.72–0.78 | 化纤行业数据专业性较强，需过滤低关联度的召回结果，该区间可平衡召回覆盖度与精准度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：升级至4.9.13及以上版本后，模型对话返回结果末尾出现`[Rule]`类追溯符号。原因：该版本新增规则溯源展示功能，默认开启该开关，未手动关闭。
- 现象：升级至4.10.0版本后，插件系统无法正常加载，提示minio连接超时。原因：该版本调整插件存储依赖逻辑，默认要求minio服务公网可访问，未配置内网访问适配参数。
- 现象：上传视频文件后，模型无法识别视频内容，解析任务显示失败。原因：未确认当前FastGPT版本支持视频多模态解析，且未在文件上传配置中添加视频格式白名单。

## 怎么确认配好了
- 执行单份化纤行业文档解析任务，查看解析后的数据字段是否与源文档一致，调整对应解析参数直至解析成功。
- 触发一次定时数据同步任务，查看同步日志中是否有超时或格式错误，匹配定时表达式与数据源更新节奏。
- 发起一次模型对话查询化纤行情数据，查看返回结果是否包含所需字段，调整上下文长度与召回条数直至结果符合预期。
- 测试配置的API接口调用，查看返回结果是否正常，核对密钥与代理配置的正确性。
