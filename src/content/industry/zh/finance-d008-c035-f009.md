# 医美智能尽调报告的引用来源与溯源

## 这个品类的数据长什么样
医美智能尽调报告用于金融场景下的合规核查，数据源主要来自医美机构执业许可证、诊疗项目备案文件、医师执业资质证明、医用耗材注册证与溯源码，以及地方卫健委的监管公示信息。更新节奏为：机构与医师资质按季度更新，耗材注册证随批次更新，诊疗记录随服务完成实时生成。文档结构包含机构信息页、资质清单、项目备案表、耗材溯源台账、诊疗档案摘要，字段包含机构统一社会信用代码、医师执业证编号、耗材注册证号、诊疗项目编码、就诊日期。

## 这些特征在「引用来源与溯源」这一环带来什么约束
医美数据的上述特征为引用来源与溯源环节带来多重约束。监管备案数据的唯一标识要求溯源必须关联可验证的官方编号，不能仅展示机构名称；脱敏诊疗记录需过滤患者隐私信息，仅保留诊疗项目与机构相关内容，因此溯源字段需排除患者个人信息；耗材溯源需包含批次信息，避免跨批次的合规风险；不同数据源的更新频率差异较大，需按类型调整校验周期，确保溯源信息的时效性；医美尽调报告对专业性要求高，需严格过滤低匹配度的无关数据源，避免影响报告可信度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `最大引用条数` | `3-5 条` | 医美尽调报告需保持专业简洁，过多引用会分散阅读注意力 |
| `引用来源白名单` | `["执业许可证", "诊疗备案", "耗材溯源", "医师资质"]` | 匹配医美尽调的核心合规数据源类型 |
| `匹配阈值` | `0.78-0.82` | 医美数据专业度高，需过滤低匹配度的无关溯源内容 |
| `引用展示格式` | `[{来源类型}]{名称}({唯一标识})` | 清晰展示溯源的核心信息，便于快速核对合规性 |
| `溯源更新校验周期` | `每日 1 次` | 医美监管备案数据更新频率稳定，每日校验确保信息时效性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：API响应中`references`字段返回冗余内容，前端展示出现红色标记的引用模块。原因：未配置`referenceDisplayMode`为仅后端返回不展示，或未在请求参数中关闭引用展示开关。
- 现象：配置知识库变量引用时，提交后出现`invalid reference source`错误提示。原因：变量值不在`引用来源白名单`的允许列表内，或变量未正确绑定到合规的数据源类型。
- 现象：召回的溯源信息与医美尽调主题不匹配，出现无关的生活美容机构或非合规耗材信息。原因：`匹配阈值`设置过低，导致低匹配度的无关内容被召回。

## 怎么确认配好了
- 上传脱敏后的医美诊疗记录与机构备案文件，生成智能尽调报告，核对报告末尾的溯源列表是否仅包含预设的数据源类型。
- 调整`匹配阈值`的配置，对比不同取值下召回的溯源信息，确认匹配度符合业务要求。
- 测试多轮对话场景，检查每一轮输出的尽调内容中，溯源信息的展示格式与配置一致。
- 查看系统日志，确认溯源更新校验任务按预设周期执行。
