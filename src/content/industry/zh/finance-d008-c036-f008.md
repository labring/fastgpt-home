# 半导体智能尽调报告的工具调用与插件

## 这个品类的数据长什么样
半导体尽调数据来源包含行业协会公开数据集、晶圆代工厂官方披露文档、上市半导体企业季度财报，适配金融尽调的合规性要求。更新节奏为晶圆产能数据按月更新，制程参数随新制程发布同步更新。文档结构包含核心器件参数、供应链关联信息、产能利用率明细。字段单位包含纳米（制程节点）、瓦特（芯片功耗）、片每月（产能规模）等行业标准单位，部分字段存在多厂商专属命名规则。

## 这些特征在「工具调用与插件」这一环带来什么约束
半导体尽调数据来源分散，需对接多类不同接口，金融尽调场景下需确保工具调用的合规性，因此需配置多端点对接逻辑并记录调用日志。不同数据源更新周期差异显著，需为每个数据源单独配置拉取频率，避免因数据过期影响尽调结论。文档结构复杂且字段存在行业专属命名与单位规范，插件需内置字段映射规则与单位转换逻辑，避免提取结果出现格式错误，影响金融报告的标准化要求。部分批量数据接口返回内容较长，需调整工具调用的响应长度限制以完整获取关键信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `tool_call_timeout` | `300 秒` | 半导体尽调工具多为批量数据拉取，单次请求耗时较长，300秒可覆盖多数场景 |
| `max_tool_calls_per_round` | `8–12` | 半导体尽调需调用多类数据源接口，该区间可平衡调用效率与结果完整性 |
| `HTTP_REQUEST_TIMEOUT` | `60 秒` | 半导体器件参数接口返回数据量较大，60秒可覆盖多数正常响应时长 |
| `MCP_PROTOCOL` | `stdio` | 私有部署版本对SSE协议的兼容存在差异，stdio协议可稳定对接多数自研工具 |
| `tool_response_max_length` | `8000–12000 字符` | 半导体尽调数据的单接口返回内容较长，该区间可完整保留关键参数 |
| `plugin_field_extract_mode` | `structured_only` | 半导体尽调报告需标准化字段，结构化提取可直接适配后续报告生成逻辑 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：私有部署V4.14.1版本导入自定义插件时，界面提示internal server error。原因：未按照FastGPT要求的JSON schema格式编写插件元数据，导致系统无法解析配置。
- 现象：FastGPT V4.9.6版本中，使用SSE协议封装的MCP工具无法被调用，界面提示仅支持stdio进程。原因：该版本的工具调用模块未完全兼容SSE协议，仅支持stdio类型的本地工具进程。
- 现象：调用HTTP请求组件后，提取的半导体产能字段为空或数值异常。原因：未配置字段映射规则，直接使用通配符提取全量响应，未匹配到半导体行业专属的字段命名。

## 怎么确认配好了
- 进入FastGPT的插件管理页面，查看目标插件的运行状态，确认未显示配置异常或加载失败提示。
- 新建测试会话，调用配置好的半导体尽调工具，检查返回结果是否包含预设的半导体专属字段，如制程节点、产能规模。
- 查看系统运行日志，确认工具调用的超时参数与配置项匹配，无连接超时或内部错误日志。
- 配置字段提取规则后，上传模拟的半导体尽调数据接口响应，检查提取结果的字段单位是否符合行业标准。
