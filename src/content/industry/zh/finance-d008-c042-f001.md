# 品牌代运营智能尽调报告的HTTP 接口与外部系统

## 这个品类的数据长什么样
品牌代运营智能尽调报告的数据主要来自品牌方电商平台后台、社交媒体内容管理系统、供应链备案数据库及合规资质文件。数据更新节奏分两类：电商销售、实时舆情数据为小时级更新，资质文件类数据仅在资质变更时同步。单份报告文档结构包含品牌授权资质扫描件解析文本、月度销售流水明细、平台合规备案编号、代运营服务履约记录、第三方舆情监测摘要等字段，其中销售数据单位为元，备案编号为字符串格式，履约记录以天数为单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
品牌代运营尽调报告的多源高频数据需求，要求HTTP接口支持并发调用与速率限制适配，避免高频拉取电商、舆情数据时触发外部系统限流。多数据源对接需求，要求接口支持多组密钥配置，分别适配不同来源的API调用权限。报告包含结构化明细与非结构化文件，要求外部系统接口支持文件流上传与文本解析适配。字段单位差异化特征，要求接口返回时携带明确字段说明，避免跨系统数据解析错误。较长的报告文本内容，要求接口超时时间适配长文本处理需求，避免中途中断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `CHAT_API_KEY` | 按数据源或代运营客户分组生成多组密钥 | 实现不同数据源或客户的调用权限隔离，避免单密钥泄露影响全量对接 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 品牌代运营尽调报告包含的资质扫描件、供应链合作文件通常不超过该大小 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 非结构化文件解析需完成OCR识别与多页文本拆分，耗时较长 |
| `API_RATE_LIMIT` | `100次/分钟` | 适配小时级更新的电商、舆情数据源拉取频率，避免触发外部系统限流规则 |
| `MULTI_KEY_ENABLE` | `开启` | 支持为不同代运营客户分配独立密钥，满足多租户对接需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：接口调用返回403 Forbidden状态码，或无法识别指定的分组密钥。原因：未开启`MULTI_KEY_ENABLE`配置，仅使用默认单密钥，无法匹配分组配置的权限密钥。
- 现象：部署后接口监听固定3000端口，无法通过配置文件或环境变量修改监听端口。原因：未正确覆盖容器的端口环境变量，硬编码端口配置未被自定义配置替换。
- 现象：品牌资质文件上传后，接口返回解析超时错误或仅返回部分文本内容。原因：未将`PARSE_FILE_TIMEOUT_SECONDS`配置调至适配长文件解析的时长，解析流程未完成即被中断。

## 怎么确认配好了
- 调用测试接口传入单份品牌资质扫描件，检查返回的解析文本是否覆盖文件核心内容，确认文件上传与解析配置生效。
- 使用分组生成的专属密钥调用对应数据源接口，检查是否能正常拉取数据且无权限报错，确认多密钥配置生效。
- 模拟高频调用接口，检查是否触发限流拦截，确认速率限制配置符合对接需求。
- 查看部署日志，确认端口配置已被正确加载，无端口冲突相关报错。
