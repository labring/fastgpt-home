# 塑料橡胶智能尽调报告的HTTP 接口与外部系统

## 这个品类的数据长什么样
塑料橡胶类智能尽调报告的数据主要来自大宗商品现货交易平台、海关进出口报关数据库、行业协会月度统计公报以及上游石化生产企业的出厂价公示。数据更新节奏存在分层：现货成交价每日更新，行业库存、进出口数据按旬度同步，月度行业分析报告滞后7个工作日发布。文档结构固定包含品名、牌号、产地、出厂价、现货成交价、社会库存、进出口量等字段，价格类字段单位统一为元/吨，库存、进出口类字段单位为万吨。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
分层更新的数据源要求接口支持自定义轮询频率，适配不同数据的更新节奏，避免过度请求或数据滞后。固定的字段与单位要求接口返回数据严格对齐预设字段名与单位，无需额外转换即可直接写入尽调报告模板。批量拉取的进出口、库存数据量较大，接口需要支持分页查询参数，同时需要配置合理的超时阈值，避免单次请求超时中断。不同数据源的鉴权方式存在差异，接口层需要支持多套鉴权配置的切换与绑定。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `API_REQUEST_TIMEOUT` | `300-600 秒` | 拉取海关进出口、行业协会的批量数据需要较长响应时间，避免单次请求超时中断 |
| `UPSTREAM_API_AUTH_TYPE` | `API_KEY` 或 `CERTIFICATE` | 不同数据源对应不同鉴权方式，需匹配数据源的接入要求 |
| `BATCH_PULL_PAGE_SIZE` | `50-100 条` | 单批次数据量过大易触发接口限流，过小则增加无效请求次数 |
| `FIELD_MAPPING_RULE` | `严格匹配字段名与单位` | 塑料橡胶类数据的字段与单位固定，直接对齐可避免尽调报告出现格式错误 |
| `WEBHOOK_RETRY_TIMES` | `2-3 次` | 接口临时波动时自动重试可降低数据同步失败概率 |
| `REQUEST_RATE_LIMIT` | `10-20 次/分钟` | 匹配多数大宗商品数据源的接口限流阈值，避免触发拦截 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部数据源接口时返回`401 Unauthorized`错误，提示身份验证不通过。原因：未正确配置`UPSTREAM_API_AUTH_TYPE`与对应鉴权参数，或绑定的API密钥已过期。
- 现象：绑定第三方搜索类外部接口时显示操作失败，无法完成授权绑定。原因：未在接口配置中填写正确的关联参数，或接口权限未完成开通。
- 现象：通过第三方接口转发的模型请求，在FastGPT中测试时返回`AttributeError`类报错。原因：未正确映射模型的入参字段，或转发接口未正确兼容目标模型的内部字段。

## 怎么确认配好了
- 发起单次接口请求，检查返回数据的字段名与单位是否与预设的塑料橡胶数据规则一致。
- 配置定时同步任务，查看任务日志中是否存在超时、鉴权失败等报错信息，根据日志调整对应配置项。
- 批量拉取一批数据，核对返回数据的总条数与分页参数的设置是否匹配。
- 绑定多个不同数据源的接口，验证不同鉴权类型的配置是否可以正常切换使用。
