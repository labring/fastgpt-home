# 多元金融智能尽调报告的知识库检索与召回

## 这个品类的数据长什么样
多元金融智能尽调报告的数据来源涵盖工商公示信息、行业协会披露文件、监管机构备案材料、机构内部风控档案及公开行业研报。更新节奏存在差异：监管备案信息随监管动作实时更新，行业研报按季度发布，内部风控档案按月度同步。文档结构通常包含主体基本信息、关联方穿透清单、业务合规记录、财务摘要、风险提示五大模块，字段包含统一社会信用代码、监管处罚文号、关联交易金额、合规评级等级，金额字段单位多为万元或亿元。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多元金融尽调数据来源混杂公开与内部权限内容，需区分不同数据源的访问权限，避免敏感信息泄露。更新节奏的差异要求对不同类型数据设置差异化的增量更新周期，防止索引滞后或冗余。文档篇幅较长且模块间关联紧密，分段检索时需保障语义上下文的完整性，避免拆分破坏跨模块逻辑。字段多且带有特定单位，检索时需匹配字段精准度，防止因单位混淆导致召回结果偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 单份多元金融尽调报告包含多模块关联内容，分段长度适配跨字段语义完整性 |
| `分段重叠率` | 15–20% | 尽调报告中关联方、财务数据等段落关联性强，重叠率保障上下文不出现断裂 |
| `召回条数` | 前10–15条 | 尽调报告需覆盖合规、财务、关联方多维度信息，足够条数保障召回广度 |
| `相似度阈值` | 0.72–0.80 | 多元金融尽调数据字段精准度要求高，阈值过滤低相关的冗余内容 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 单份尽调报告文档篇幅较长，超时设置保障完整解析不中断 |
| `增量更新周期` | 按数据源类型分档配置 | 适配监管备案实时更新、行业报告季度更新的差异化节奏 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：知识库检索结果条数不足，无法覆盖尽调所需的关联方信息。原因：召回条数设置过低，未匹配多元金融尽调报告多维度内容的召回需求。
- 现象：相同查询词返回不同答案，且与私有知识库内容存在偏差。原因：未设置统一的相似度阈值，或分段重叠率配置不合理导致语义片段匹配不一致。
- 现象：工作流调用知识库模块返回空结果。原因：未配置`PARSE_FILE_TIMEOUT_SECONDS`参数，长文档解析超时导致无有效索引生成。

## 怎么确认配好了
- 上传单份完整的多元金融尽调报告，检查解析后的分段数量与文档页数的对应比例是否符合预期。
- 输入包含特定字段的查询词，核对召回结果中是否包含对应字段的精准内容。
- 模拟工作流调用知识库模块，查看返回结果是否包含预期的文档片段。
- 查看增量更新日志，确认不同来源的尽调数据按预设周期完成同步。
