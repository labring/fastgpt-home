# 小金属智能尽调报告的多轮对话与提示词

## 这个品类的数据长什么样
数据来源包括国内有色金属行业协会公开统计、期货交易所现货挂牌数据、海关进出口报关数据、矿山与冶炼企业公开披露的生产数据。更新节奏分为日度（现货价格、库存变动）、月度（进出口总量、行业供需简报）、季度（全品类供需平衡报告）。文档结构多为结构化表格与短文本说明，结构化部分包含品类牌号、产地标识、交易单价、库存余量、进出口量等字段。字段单位多为元/千克、吨、件，部分指标使用标准计量符号标注。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
多源异构的小金属数据更新节奏差异，要求多轮对话系统需保留上下文的品类、地域、统计周期等参数，避免重复询问已明确的信息。结构化文档占比高的特征，要求提示词需明确指定提取指定字段的格式，避免生成非结构化的模糊回答。字段单位的多样性，要求提示词中需包含统一单位转换规则，确保输出结果的计量标准一致。不同更新频率的数据对应不同的数据源调用逻辑，多轮对话流程中需针对未明确的参数生成清晰的追问提示，补充必要的查询条件。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 小金属尽调的多轮对话需保留品类、地域、时间等多轮参数，该范围可覆盖3-5轮交互的上下文内容 |
| `相似度阈值` | `0.75–0.85` | 小金属数据字段多且细分，该阈值可过滤无关的行业通用数据，精准匹配目标品类的字段信息 |
| `分段长度` | `800–1200 字符` | 小金属尽调报告的结构化表格多为短段落拆分，该分段长度可保留完整的字段关联信息，避免拆分破坏数据逻辑 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 部分小金属的进出口数据文档体量较大，该时长可确保完整解析所有结构化字段 |
| `召回条数` | `前6–8条` | 小金属品类细分牌号多，该召回量可覆盖常用的产地、价格、库存等核心字段，避免遗漏关键信息 |
| `语音识别模型` | `按实测标定` | 小金属尽调对话中涉及专业术语发音，需根据实际识别准确率调整对应配置，确保专业术语转换准确 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：多轮对话中后续查询的品类、地域参数被遗漏，输出结果与前一轮查询无关。原因：未配置`maxContext`参数或取值过小，无法保留多轮交互的上下文信息。
- 现象：语音输入后无文字转化内容，或专业术语识别错误。原因：未针对小金属专业术语配置专属语音识别模型，或未开启语音转文字的上下文关联功能。
- 现象：输出的尽调报告字段单位混乱，同时出现元/千克与美元/盎司的混合标注。原因：提示词未明确指定统一单位转换规则，未在配置中添加单位校验的要求。

## 怎么确认配好了
- 发起3轮以上的递进式查询，如先查询当前钽的现货价，再补充询问江西产地的上月库存，最后要求输出结构化表格，核对系统是否保留所有前置参数，未重复询问已明确的信息。
- 上传一份小金属的月度尽调文档，触发解析流程，核对解析后的字段是否包含所有预设的品类、产地、价格等核心信息，无字段缺失或拆分错误。
- 开启语音输入功能，朗读一段包含小金属专业术语的查询语句，核对转写后的文字是否准确还原专业术语与查询意图。
- 调用http节点获取BLOB格式的尽调报告附件，核对界面是否生成可点击的下载链接，且下载后的文件格式与原文件一致。
