# 小金属智能尽调报告的工作流编排

## 这个品类的数据长什么样
小金属数据主要来自国内现货交易平台、行业协会月度统计、期货交易所挂牌合约、海关进出口报关数据。更新节奏分两类：现货报价每日更新，行业产量、库存数据按月度更新，进出口数据按周度更新。标准文档结构包含标的品位、当日均价、周度波动幅度、月度库存总量、年度产能数据，字段多带百分比、吨、元/吨等单位，部分细分品类如稀土还包含磁性能参数指标。

## 这些特征在「工作流编排」这一环带来什么约束
小金属数据的多源多更新节奏，要求工作流需配置多节点并行拉取不同时效的数据，避免单源数据滞后影响报告准确性。不同细分品类的专属字段（如稀土磁性能）要求工作流需支持动态匹配字段模板，无法直接复用通用尽调流程。每日更新的现货数据需在工作流中设置定时触发节点，确保报告生成时使用最新报价，月度库存数据仅需在每月初触发拉取。同时，海关数据的接口调用频次受限，需配置限流节点避免触发接口封禁。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发配置` | 按数据时效拆分：现货数据设为每日09:00触发，月度数据设为每月1日08:00触发 | 匹配小金属数据的多更新节奏，避免冗余拉取 |
| `并行执行节点数` | 设为3–5个 | 适配多源数据拉取（现货、库存、进出口），避免单节点超时 |
| `动态字段映射规则` | 绑定品类专属字段模板 | 覆盖小金属细分品类的特殊参数（如稀土磁性能），适配通用尽调流程无法覆盖的字段 |
| `API请求限流阈值` | 设为10次/分钟 | 符合海关、交易所接口的调用频次限制，避免接口封禁 |
| `输出内容过滤` | 仅保留最终聚合节点的输出 | 屏蔽中间AI节点的冗余输出，符合仅需最终聚合结果的需求 |
| `节点超时时间` | 设为600秒 | 适配多源数据拉取的总耗时，避免工作流中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流运行后返回中间AI节点的冗余内容，最终聚合结果未按预期输出。原因：未开启`输出内容过滤`配置，未屏蔽中间节点的输出内容。
- 现象：尝试导入v4.6.7版本的工作流文件至v4.8.10版本时出现`导入失败：格式不兼容`报错。原因：未使用版本兼容的导出格式，v4.8.10版本调整了工作流配置的JSON结构。
- 现象：通过API调用发布的工作流，用户选择或表单输入组件未弹出交互提示。原因：未在API请求参数中开启`交互模式`开关，默认API调用不自动触发前端交互弹窗。

## 怎么确认配好了
- 手动触发一次工作流，检查返回结果仅包含最终聚合节点的内容，无中间AI节点的冗余输出。
- 查看工作流的运行日志，确认不同时效的数据节点按预设时间触发拉取。
- 调用API测试接口，确认提交表单或选择组件时，前端正常弹出交互提示。
- 检查接口调用频次统计，确认未超过预设的限流阈值，无接口封禁相关提示。
