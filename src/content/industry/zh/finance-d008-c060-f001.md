# 工程咨询智能尽调报告的HTTP 接口与外部系统

## 这个品类的数据长什么样
工程咨询智能尽调报告的数据来源通常为项目立项批复、地质勘察报告、建筑施工图、造价概算书、招投标文件等正式行业文档。更新节奏随项目进度动态调整，从前期策划到竣工阶段按需更新。文档结构一般包含项目概况、技术参数、成本明细、合规性说明四个核心模块，字段包括项目编号、建筑面积、工程造价、勘察点位坐标、合规条款编号等，单位多采用平方米、万元、米等工程行业通用标准单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
工程咨询尽调报告的多源结构化特征，要求HTTP接口支持携带自定义元数据的文件上传与同步。长文本与结构化字段混合的文档结构，要求接口支持分块传输大体积文件，避免单次请求超时。随项目进度动态更新的特性，要求接口支持增量拉取与版本标记功能，避免重复同步全量数据。工程专用的单位体系，要求接口参数支持自定义单位映射规则，确保数据解析后字段单位与原始文档一致。合规条款的编号关联设计，要求接口返回结果保留字段间的关联关系，避免解析后数据错位。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `500–1000 MB` | 工程咨询报告常附带大型施工图、造价清单附件，需适配大体积文件上传 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600–900 秒` | 工程文档包含多格式图纸与长文本内容，解析耗时显著高于通用文档 |
| `API_REQUEST_TIMEOUT` | `300 秒` | 外部系统同步工程数据时，需传输完整元数据与关联文件，请求周期较长 |
| `CUSTOM_FIELD_MAPPING` | `按工程行业常见配置做法配置` | 工程咨询报告包含专用字段与单位，需自定义映射规则匹配原始文档格式 |
| `SYNC_INCREMENTAL_ENABLE` | `开启` | 工程项目进度动态更新，增量同步可减少重复传输与资源占用 |
| `API_AUTH_TYPE` | `Bearer Token` | 符合FastGPT官方接口鉴权规范，适配多数外部工程管理系统的鉴权逻辑 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用自定义外部接口返回404状态码，使用独立工具测试接口可正常通过。原因：FastGPT配置中未正确填写`{{baseURL}}`的完整路径，或`{{authorization}}`参数未携带有效鉴权令牌，导致接口请求无法匹配正确路由。
- 现象：调用`/api/core/dataset/update`接口返回500状态码，浏览器端可正常使用对应功能。原因：FastGPT4.9.0版本中该接口的请求参数格式未匹配官方规范，或外部系统返回的响应数据结构与FastGPT预期的解析规则不一致。
- 现象：同步后的工程尽调报告中，建筑面积等字段丢失单位信息。原因：未配置`CUSTOM_FIELD_MAPPING`参数，未映射工程行业专用的单位规则，导致接口解析时自动丢弃了非通用单位字段。

## 怎么确认配好了
- 调用FastGPT提供的接口调试工具，传入测试用的工程尽调报告元数据，确认接口返回正常响应。
- 查看外部系统同步日志，确认同步操作仅处理了近期修改的项目数据，未全量覆盖所有历史数据。
- 导出接口返回的解析后数据，核对字段名称与单位与原始工程文档的格式一致。
- 检查FastGPT后台的API鉴权配置，确认鉴权参数的取值符合外部系统的鉴权要求。
