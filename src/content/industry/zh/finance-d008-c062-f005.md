# 广告营销智能尽调报告的多轮对话与提示词

## 这个品类的数据长什么样
广告营销智能尽调报告的数据来自主流广告投放管理系统导出文件、第三方广告监测报表、品牌营销活动内部台账。数据更新节奏分为两类：日常投放数据按自然日更新，单次活动的全量尽调数据在活动结束后7个工作日内完成归档。单份尽调报告的文档结构包含活动标识模块、投放渠道模块、素材模块、转化链路模块，字段包含活动编号、渠道名称、素材格式、曝光次数、点击次数、转化单数、单客消费金额、投放时段等，单位对应为次、次、个、元、小时等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
广告营销尽调数据的多源跨系统来源，要求多轮对话需先确认数据的采集渠道与时间范围，避免混用不同周期的投放数据。复杂的多字段结构，要求提示词需明确指定需提取的活动标识、渠道、转化类字段，防止返回无关的非尽调相关内容。不同字段的关联校验规则，例如曝光量需大于等于点击量，需在多轮对话中逐步引导用户校验数据合理性，避免生成逻辑矛盾的报告内容。单次活动的归档周期特性，要求提示词需支持用户指定活动周期参数，适配不同阶段的尽调查询需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 广告营销尽调报告包含多维度关联字段，多轮对话需保留多轮查询条件与数据范围，避免上下文溢出 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单份广告营销尽调报告的结构化数据文件通常不超过此大小，适配批量上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 多字段的结构化尽调文件解析需要较长处理时间，避免提前终止解析流程 |
| `maxTurns` | `10 轮` | 广告营销尽调的查询通常需要3-5轮细化需求，超过10轮会导致上下文冗余，降低响应效率 |
| `相似度阈值` | `0.75` | 需精准匹配用户查询的尽调维度，避免召回无关的投放历史数据 |
| `分段长度` | `1000 字符` | 广告营销尽调报告的字段描述清晰，分段长度适配字段组合的信息密度，提升召回准确性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：对话框上传广告营销尽调报告后，无解析进度提示且后台无报错日志。原因：上传文件大小超出`UPLOAD_FILE_MAX_SIZE`参数配置的阈值，系统静默跳过解析流程。
- 现象：对话界面启动后未自动加载预设的默认查询问题，需手动输入初始提问。原因：未在对话初始化配置中绑定`default_user_prompt`参数，未正确设置启动时的默认提问内容。
- 现象：调用对话接口生成尽调报告时，无法主动终止当前生成进程，返回结果持续堆积。原因：未启用`stop_sequence`参数或未配置正确的终止触发条件，无法接收停止请求。

## 怎么确认配好了
- 上传一份符合广告营销尽调报告格式的测试文件，查看界面是否显示解析进度，后台是否生成对应解析日志。
- 启动对话界面，核对初始加载的提问内容是否与预设的`default_user_prompt`参数一致。
- 发起多轮查询后，调用停止对话的接口，确认当前生成进程被终止，无额外未完成结果返回。
- 复制对话生成的尽调报告内容到外部工具，验证格式是否符合预期，调整系统提示词中的格式规则。
