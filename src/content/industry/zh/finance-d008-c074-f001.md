# 教育服务智能尽调报告的HTTP接口与外部系统

## 这个品类的数据长什么样
教育服务智能尽调报告的数据主要来自教育行政部门公示系统、机构自主提交的合规材料、第三方核验机构的实地核查记录。更新节奏随机构资质变更实时触发，常规合规核验按固定周期更新。文档分为基础资质档案、师资信息清单、学员服务记录三类结构化文档，包含统一社会信用代码、办学许可证有效期、师资从业年限、单班学员上限等字段，附件多为PDF格式的资质扫描件与教学方案文档。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
教育服务智能尽调报告的多分类文档结构，要求HTTP接口支持按资质、师资、服务记录三类数据分别拉取，避免单接口返回冗余内容。字段包含有效期、从业年限等时间与数值类属性，要求接口支持按时间范围、数值区间筛选查询。附件多为PDF格式的扫描件，要求接口支持二进制流与预签名URL两种传输方式适配不同存储场景。合规属性要求接口调用需携带专属校验凭证，避免未授权访问。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 适配教育服务资质扫描件的常见体积，避免大文件传输失败 |
| `API_REQUEST_TIMEOUT` | `300 秒` | 覆盖资质核验、批量拉取师资数据的常规响应时长 |
| `ALLOWED_CONTENT_TYPES` | `application/pdf, application/octet-stream` | 匹配教育服务尽调报告的附件格式 |
| `REQUEST_FILTER_RULE` | `按有效期、从业年限配置筛选条件` | 适配字段中包含时间、数值属性的查询需求 |
| `AUTHENTICATION_TYPE` | `Bearer Token` | 满足教育服务数据的合规访问要求，避免未授权调用 |
| `BATCH_PULL_SIZE` | `按单类文档分页拉取` | 适配多分类文档的结构，避免单次返回数据量过大 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部系统接口返回`400 Bad Request`，目标字段返回为空。原因：未指定数据类型筛选参数，接口无法匹配教育服务尽调报告的专属文档分类。
- 现象：长时间批量数据拉取任务未完成时，接口直接返回超时错误。原因：未将接口超时配置调整为适配批量操作的时长，未启用异步任务回调机制。
- 现象：上传资质扫描件后，无法确认文件索引与数据处理是否完成。原因：未配置接口返回的文件处理状态字段，未绑定处理完成的回调通知。

## 怎么确认配好了
- 调用单类文档拉取接口，验证返回字段包含教育服务尽调报告的专属属性，如办学许可证有效期。
- 上传PDF格式的附件，确认接口返回的传输地址或二进制流可正常解析。
- 使用无效身份凭证调用接口，确认返回对应未授权错误码。
- 发起批量数据拉取请求，检查返回数据量符合配置的分页规则，无冗余内容。
