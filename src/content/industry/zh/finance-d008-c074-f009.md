# 教育服务智能尽调报告的引用来源与溯源

## 这个品类的数据长什么样
教育服务智能尽调报告的数据来源包含教育行政部门备案公示信息、办学资质扫描件、课程开发文档、第三方合规检测报告。更新节奏分为三类：办学资质文件每12个月更新一次，课程大纲每学期调整，监管公示信息实时同步。文档结构分为结构化元数据区与附件区，元数据包含机构统一社会信用代码、办学许可证编号、办学地址、开设课程类别、合规等级，附件区包含资质扫描件、课程大纲PDF、监管整改通知书（如有）。字段与单位包括：统一社会信用代码为18位字符串，办学许可证编号为字母加数字组合，在校学生数为整数，单位为“人”，单节课程时长为数字，单位为“分钟”。

## 这些特征在「引用来源与溯源」这一环带来什么约束
数据来源分散导致需支持多源内容召回，需区分不同来源的更新时效，对资质类内容设置12个月内的召回范围，对课程类内容设置对应学期内的召回范围。文档同时包含结构化元数据与非结构化附件，需同时支持结构化字段精准匹配与附件OCR内容解析溯源。字段存在固定格式要求，需配置字段匹配规则避免溯源错误。附件多为PDF或扫描件，需确保OCR解析流程正常，才能完整关联原始附件的溯源信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前6–8条` | 教育服务尽调报告涉及的合规项、课程信息等内容分散在多个文档，召回过多会引入冗余信息，过少会遗漏关键合规依据 |
| `相似度阈值` | `0.75–0.85` | 教育服务相关术语如“办学许可”“课程时长”有固定表述，阈值过低会引入无关的教育行业非相关内容，过高会遗漏合规类关键文档 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | 教育服务尽调报告常包含多页PDF资质扫描件，OCR解析和文本拆分耗时较长，超时会导致附件内容无法溯源 |
| `分段长度` | `800–1000 字符` | 教育服务文档中的课程大纲、合规条款多为连贯长文本，分段过短会破坏语义完整性，过长会影响精准召回 |
| `enable_source_display` | `开启` | 教育服务尽调报告需明确标注资质文件、监管公示等来源，开启后可展示原始文档的文件名与解析片段 |
| `structured_field_retrieval` | `开启` | 教育服务尽调报告包含统一社会信用代码、办学许可证编号等结构化字段，开启后可精准匹配元数据，避免溯源错误 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：返回的引用内容并非知识库中综合排名第一的文档片段。原因：配置了`相似度阈值`或`重排返回条数`参数，系统优先匹配语义关联度，不依据初始召回排名，或仅返回重排后的Top结果。
- 现象：调用API返回的结果中无关联文件名字段。原因：未开启`enable_source_display`配置项，或未正确配置知识库的溯源展示参数。
- 现象：无法同时引用多个文档变量生成尽调报告片段。原因：未启用多文档关联召回配置，或工作流中仅绑定了单个知识库检索节点。

## 怎么确认配好了
- 在知识库管理界面开启`enable_source_display`配置项后，上传教育机构资质扫描件，发起关键词检索，查看返回结果的溯源模块，确认是否显示原始文件名与解析片段。
- 调用知识库检索API，检查返回结果的`source_info`字段是否包含文档名称、解析片段等内容，确认溯源信息正常返回。
- 配置多文档关联检索节点，上传多份教育服务相关文档，发起检索，查看结果是否同时关联多个文档的溯源信息，确认多变量引用功能正常。
- 调整`相似度阈值`至0.7，发起包含“办学许可证”关键词的检索，查看返回结果的排序是否符合预期，确认参数生效。
