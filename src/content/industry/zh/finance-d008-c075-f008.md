# 整车智能尽调报告的工具调用与插件

## 这个品类的数据长什么样
整车智能尽调报告的数据主要来自工信部机动车产品公告、车企官方技术参数文档、第三方机动车检测机构合规报告。数据更新节奏随车型迭代与合规政策调整，常规车型参数更新周期为季度，新车型发布时同步更新全量参数。文档以结构化参数表为核心，包含车辆识别码、车型名称、整备质量、续航里程、排放标准、动力类型等字段，部分文档附带合规性说明附件，字段单位统一遵循机动车行业标准，如整备质量单位为千克，续航里程单位为千米。

## 这些特征在「工具调用与插件」这一环带来什么约束
结构化参数为主的特征要求工具调用需严格匹配工信部公告的标准字段名，避免参数映射偏差。数据更新的分周期特性要求插件配置定时拉取任务，区分常规参数更新与新车型全量同步的触发逻辑。附带合规附件的文档结构，需要调用文件加工插件解析附件内容，补充到尽调报告中。固定的字段单位要求工具参数校验环节强制校验单位格式，防止传入非标准单位导致的报告数据错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `TOOL_FIELD_MATCH_MODE` | `严格匹配` | 整车尽调数据字段遵循统一行业标准，严格匹配可避免参数映射偏差 |
| `PLUGIN_SYNC_CRON` | `0 0 2 * * *` | 适配常规参数季度更新节奏，每日凌晨同步可覆盖大部分常规更新场景，新车型同步可手动触发补充 |
| `PARSE_FILE_MAX_SIZE` | `10 MB` | 合规检测附件多为单页或多页PDF，单文件大小通常不超过10 MB |
| `TOOL_PARAM_VALIDATE_ENABLE` | `开启` | 整车字段单位固定为行业标准格式，校验可拦截非标准单位输入 |
| `TOOL_RESPONSE_TIMEOUT` | `30 秒` | 工信部公开接口响应稳定，30秒可覆盖批量参数拉取与解析的全流程 |
| `HISTORY_IGNORE_PLUGIN_LOG` | `开启` | 插件调用的内部日志无需纳入上下文记忆，避免干扰后续提问的上下文理解 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：HTTP工具调用时，原有的可选参数配置项消失，无法设置自定义变量。原因：工具配置界面切换至简化编辑模式后，高级可选参数的配置入口被隐藏，需展开高级配置区或切换至JSON编辑模式。
- 现象：指定回复的插件内容被纳入会话历史，干扰后续上下文理解。原因：未开启历史记录忽略插件日志的配置项，插件内部交互的冗余内容被自动添加至会话上下文。
- 现象：调用文件加工插件时返回超时错误，或长时间处于等待响应状态。原因：未根据附件文件大小调整对应配置项，或未升级至支持该插件的最低版本。

## 怎么确认配好了
- 发起一次工具调用测试，检查返回的参数是否与公开的行业标准字段完全匹配，确认字段匹配配置生效。
- 查看会话历史记录，确认插件调用的内部日志未被纳入上下文，检查历史忽略插件日志的配置是否正确开启。
- 上传一份合规检测附件，调用文件加工插件，确认插件可正常解析并返回解析内容，检查相关配置是否适配当前场景。
- 手动触发一次插件定时同步任务，检查是否成功拉取最新的整车参数数据，确认定时任务配置正确。
