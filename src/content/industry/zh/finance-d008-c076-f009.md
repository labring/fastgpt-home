# 文娱用品智能尽调报告的引用来源与溯源

## 这个品类的数据长什么样
在金融领域的文娱品类合规尽调场景中，文娱用品属于轻工制造品类，其数据源主要包含品牌方出具的授权文件、行业协会抽检质检报告、电商平台上架资质备案、版权登记证书四类。数据更新节奏随类型差异调整：版权信息每季度同步最新授权状态，质检报告按年度更新抽检结果，电商上架资质随产品上下架实时变动。文档结构多为结构化表格或带固定字段的PDF，包含品牌名称、产品SKU、版权登记号、生产批次、合规检测项等字段，单位多为元、件等基础计量单元，部分字段为带前缀的字符串编码。

## 这些特征在「引用来源与溯源」这一环带来什么约束
文娱用品的多源异构数据源要求溯源环节区分不同文档的可信度优先级，避免混淆低可信度的电商备案与官方抽检报告。多字段精准匹配的需求要求溯源必须绑定SKU、生产批次等唯一标识，避免召回同品类其他产品的合规信息。结构化文档的固定字段结构，要求开启对应解析规则，确保提取的引用内容包含可溯源的唯一标识，覆盖对应产品的专属合规信息。实时变动的上架资质则要求溯源环节支持动态更新的知识库同步，避免引用过期的备案信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前8-12条` | 文娱用品合规文档多为短条目，过多召回会引入无关内容，过少则无法覆盖完整合规项 |
| `相似度阈值` | `0.75-0.85` | 需精准匹配SKU、批次等唯一字段，阈值过低会召回无关产品的合规信息，过高则可能遗漏有效来源 |
| `PARSE_STRUCTURED_FILE` | `开启` | 文娱用品文档多为结构化表格格式，开启后可提取固定字段用于精准溯源 |
| `知识库更新频率` | `按实时/季度按需配置` | 电商资质实时变动，版权信息按季度更新，需匹配对应数据源的更新节奏 |
| `重排返回条数` | `前3-5条` | 需优先展示官方抽检、品牌授权等高可信度来源，过滤低价值的备案内容 |
| `引用来源显示字段` | `品牌名称+SKU+文档类型` | 需让尽调报告读者快速定位对应合规项的来源主体与类型 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：返回的尽调答案与知识库引用条目完全无关，引用条目未匹配到对应SKU或合规项。原因：未设置`相似度阈值`的精准区间，或未开启结构化解析，导致召回了同品类其他产品的文档。
- 现象：配置企业微信接入后，仅返回引用来源链接，未生成对应答案内容。原因：未配置`召回条数`的合理范围，或知识库更新频率未匹配实时数据源，导致无法获取有效内容生成答案。
- 现象：部分工作流节点无法关闭引用来源展示，或部分节点无法保留引用内容。原因：未针对不同合规文档类型单独配置`引用来源显示字段`，或工作流可见度设置未区分需展示与需隐藏的来源类型。

## 怎么确认配好了
- 上传一份文娱用品的质检报告，触发一次尽调查询，核对返回的引用来源是否包含该报告的SKU与生产批次字段。
- 查看系统日志，确认召回的文档来源类型与配置的可信度优先级一致，无低价值内容被优先展示。
- 调整`引用来源显示字段`的配置，验证不同节点的可见性是否符合预期，确认无需展示的来源未被公开。
- 模拟一次SKU变更后的查询，核对返回的引用内容是否同步更新为最新的资质备案信息。
