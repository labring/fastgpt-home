# 普钢智能尽调报告的HTTP 接口与外部系统

## 这个品类的数据长什么样
普钢智能尽调报告的数据主要来自钢厂生产台账、现货交易平台的实时报价、第三方质检机构的检测报告。更新节奏为现货价格数据每日更新，生产批次数据随出货节奏同步更新，质检报告随每批次产品生成后同步入库。文档通常包含产品规格参数表、化学成分检测表、力学性能数据表、产地与报价明细、批次台账等模块。字段包含炉号、厚度（mm）、抗拉强度（MPa）、屈服强度（MPa）、交货重量（吨）、含税单价（元/吨）等标准化内容，部分字段需适配钢厂内部编码规则。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
普钢尽调报告的多模块表格结构与多字段属性，要求接口支持大体积文件上传与复杂表格解析，否则会出现解析不完整的问题。现货数据的高频更新特性，要求接口支持短缓存或无缓存模式，避免返回过时的报价信息。多维度的字段校验需求，要求接口参数校验规则覆盖化学成分范围、单位一致性等场景，否则会引入数据错误。长文件名的批次报告上传需求，要求接口放宽文件名长度限制，避免触发400错误。跨厂商数据的字段差异，要求接口支持自定义字段映射配置，适配不同钢厂的尽调报告格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 普钢尽调报告常包含多份质检报告、台账表格，单文件体积较大 |
| `PARSE_TABLE_MAX_ROWS` | `2000 行` | 普钢生产台账、报价表常包含数百至上千行数据 |
| `API_CACHE_TTL` | `300 秒` | 普钢现货价格、生产数据日更新，缓存不宜过长 |
| `REQUEST_TIMEOUT` | `600 秒` | 大文件解析、多字段校验耗时较长 |
| `FIELD_VALIDATION_STRICT` | `开启` | 普钢数据字段（如化学成分、规格参数）有明确合规范围，严格校验可减少无效请求 |
| `RESPONSE_INCLUDE_UNIT` | `开启` | 普钢数据需携带单位（MPa、元/吨等），避免字段歧义 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 使用fetch API调用`/api/v1/chat/completions`时出现跨域错误，浏览器控制台显示CORS相关报错。原因是未在后端配置允许的请求源、请求头或请求方法，未正确处理预检请求。
- 上传文件名过长的普钢尽调报告时返回400错误。原因是接口默认的文件名长度限制为255字符，普钢报告常包含炉号、批次等长后缀导致超出限制。
- 通过Markdown上传图片时无法返回`/api/system/img/`开头的可访问URL路径。原因是未配置图片上传的系统存储路径，或未开启自动上传至指定目录的开关。

## 怎么确认配好了
- 发起带`Origin`请求头的测试调用，检查返回状态码为200且无CORS相关报错，确认跨域配置生效。
- 上传包含超过255字符文件名的普钢尽调报告，检查返回状态码为200且文件解析成功，确认文件名长度限制配置正确。
- 通过Markdown插入图片并调用接口，检查返回结果中包含`/api/system/img/`前缀的URL路径，确认图片上传配置正确。
- 调用语音上传接口并传入标准格式的音频文件，检查接口返回解析后的文本内容，确认语音解析配置生效。
