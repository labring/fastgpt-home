# 焦炭智能尽调报告的部署与升级

## 这个品类的数据长什么样
焦炭尽调数据主要来自大连商品交易所公开交割标准、中国炼焦行业协会月度供需报告、沿海港口实时库存台账。数据更新节奏分三类：交割品级与理化指标每日同步交易所行情，周度产量与港口库存每3天更新，月度供需报告于每月10日前发布。单份尽调文档结构固定为核心指标页、区域供需页、价格走势页，字段包含灰分、挥发分、硫分、抗碎强度M40、耐磨强度M10、成交价格元/吨、港口库存万吨等，所有理化指标均标注国标检测方法对应的单位。

## 这些特征在「部署与升级」这一环带来什么约束
焦炭尽调数据的多源多节奏特征，对部署与升级环节带来多重约束。首先，不同数据源的更新频率差异，需要部署时配置差异化的定时同步任务，无法统一使用固定间隔触发逻辑。其次，字段包含国标理化指标与专属单位，需要在数据解析模块预设严格的字段校验与映射规则，避免非标准数据流入知识库。此外，不同周期的文档结构差异，升级时需要适配多套解析模板，无法复用单一解析规则。同时，焦炭交割品级的固定标准要求，部署时需预设字段匹配逻辑，确保外部导入数据与国标指标对齐。最后，单份月度尽调文档内容量较大，需配置适配长文本的向量存储参数，避免核心信息被截断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_VERSION` | `MongoDB 6.0 或 7.0` | 兼容FastGPT官方支持的版本区间，可稳定存储焦炭多源数据的向量索引与元信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 覆盖单份焦炭月度尽调文档的完整解析时长，避免长文档解析中途超时中断 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 适配单份压缩后焦炭月度尽调报告的最大体积，满足全量文档上传需求 |
| `PARSE_SEGMENT_LENGTH` | `1000–1200 字符` | 保留焦炭理化指标与供需数据的上下文关联，避免核心指标与对应数据割裂 |
| `VECTOR_STORE_BATCH_SIZE` | `50 条` | 平衡焦炭多字段数据的存储效率与索引稳定性，避免单批次存储超时 |
| `API_CONFIG_SYNC_MODE` | `按配置文件触发` | 适配焦炭数据第三方API的密钥与地址定期更新需求，避免频繁接口调用异常 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：执行跨版本升级脚本后，系统返回「400 版本不兼容」报错。原因：未提前导出MongoDB的向量存储元数据，直接执行升级脚本导致新旧版本的索引结构无法兼容。
- 现象：导入焦炭尽调文档后，灰分、抗碎强度M40等核心字段显示为空。原因：未配置`PARSE_FIELD_MAPPING`的专属映射规则，解析模块无法识别焦炭行业特有的字段命名格式。
- 现象：调整第三方API配置后，数据同步任务持续失败。原因：未同步更新API调用的授权密钥与接口地址的绑定关系，导致配置项与实际调用参数不匹配。

## 怎么确认配好了
- 登录FastGPT的系统配置页面，核对`MONGODB_VERSION`的配置项与部署环境的实际MongoDB版本是否匹配。
- 上传一份标准焦炭月度尽调文档，查看解析任务的状态为已完成，确认解析时长符合预设的超时阈值范围。
- 触发一次第三方API同步任务，查看同步日志中是否包含焦炭核心指标字段，确认字段映射规则生效。
- 执行升级脚本的预校验命令，查看日志中无版本冲突或配置缺失的提示，确认升级流程的兼容性。
