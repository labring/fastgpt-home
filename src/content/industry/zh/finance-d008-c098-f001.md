# 煤化工智能尽调报告的HTTP 接口与外部系统

## 这个品类的数据长什么样
煤化工尽调报告的数据主要来自国内煤化工产业监测平台、省级能源主管部门公开披露信息、企业季度及年度公开报告。数据更新节奏存在差异：核心产能数据按季度更新，原料与产品价格按周更新，开工与生产数据按月更新。单份报告包含企业基础信息、产能台账、月度生产数据、原料供应链数据、产品销售数据，字段包括企业名称、投产日期、设计产能、实际产量、原料煤到厂价、产品出厂价，对应单位分别为无、年、吨/年、吨、元/吨、元/吨。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
煤化工尽调数据的多频率更新特性，要求HTTP接口支持按数据类别配置拉取周期，避免频繁拉取低更新频率的产能数据导致资源浪费。专用字段与单位的差异，要求接口支持自定义字段映射规则，将外部数据源的字段名转换为平台统一的尽调字段格式，同时校验单位一致性。混合结构化与非结构化的文档结构，要求接口支持同时上传结构化表格与PDF格式的企业说明文件，并适配不同格式的解析逻辑。此外，能源行业数据的合规要求，要求接口携带固定的身份验证参数，且支持配置数据输出的脱敏规则。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 煤化工尽调报告常包含多份结构化表格与长文本企业说明，300秒可覆盖完整解析时长 |
| `UPLOAD_FILE_ALLOWED_EXTENSIONS` | `csv,json,xlsx,pdf` | 煤化工数据源常见格式为Excel台账、CSV统计报表、PDF公开报告与JSON格式的API返回数据 |
| `HTTP_REQUEST_TIMEOUT` | `60 秒` | 外部能源数据接口的响应延迟通常在30-50秒区间，预留10秒缓冲以避免请求中断 |
| `FILE_UPLOAD_MAX_SIZE` | `500 MB` | 单份煤化工尽调报告的附件包（含多份台账与配套说明文件）通常不超过500 MB |
| `RECALL_TOP_K` | `8-12` | 煤化工尽调数据的核心关联字段较多，8-12条可覆盖大部分关联分析需求 |
| `DATA_SYNC_CRON` | `0 0 2 * * *` | 按每日凌晨2点的固定周期同步，适配煤化工数据的每日/每周更新节奏 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部数据接口时返回`401 Unauthorized`且日志显示`empty auth token`。原因：未在接口配置中正确绑定令牌的请求头参数，或令牌字段与第三方平台的认证要求不匹配。
- 现象：上传煤化工Excel台账文件时，系统提示「不支持的文件格式」。原因：未将`xlsx`添加到`UPLOAD_FILE_ALLOWED_EXTENSIONS`配置项中，导致文件被拦截。
- 现象：解析大型煤化工尽调报告时返回`504 Gateway Timeout`。原因：`PARSE_FILE_TIMEOUT_SECONDS`配置值低于实际解析所需时长，导致解析流程被强制终止。

## 怎么确认配好了
- 执行单次文件上传测试，上传一份标准煤化工Excel台账，检查系统是否能正确解析并提取预设字段。
- 调用外部数据接口，传入测试用的令牌参数，检查返回的响应状态码是否符合预期。
- 查看接口配置的`DATA_SYNC_CRON`表达式，确认其匹配煤化工数据的实际更新周期。
- 导出一份测试用的尽调报告数据，检查返回的字段是否与配置的自定义映射规则一致。
