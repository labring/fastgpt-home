# 电子元件智能尽调报告的工具调用与插件

## 这个品类的数据长什么样
电子元件尽调报告的数据来源涵盖原厂规格书、供应链交易数据库、合规认证平台与第三方检测报告。数据更新随原厂新品发布、行业合规标准调整同步推进，供应链交易数据每日更新。单份报告的文档结构包含元件基础型号信息、电气参数、封装规格、合规认证文件、上下游供应商报价快照。字段涵盖元件型号、额定阻值/容值、工作电压、封装尺寸、认证编号、供应商名称，对应单位包含欧姆（Ω）、法拉（F）、伏特（V）、毫米（mm）等专属计量标识。

## 这些特征在「工具调用与插件」这一环带来什么约束
电子元件数据的多源属性要求插件支持同时对接原厂规格书数据库、供应链交易平台与合规认证查询接口，避免单一数据源的信息偏差。参数字段附带专属单位的特征，要求工具调用时需严格校验输入输出的单位匹配，避免阻值、容值等参数的单位转换错误。长文档结构则要求插件支持分页解析与分段上传，适配尽调报告的批量处理需求，同时需限制单批次调用的文档数量，防止接口过载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 电子元件规格书通常包含多页参数表格，解析耗时较长，300秒可覆盖绝大多数长文档解析需求 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单份电子元件尽调报告包含原厂PDF、检测报告等多份附件，500 MB可容纳完整关联文档集合 |
| `tool_call_max_context` | `8000–12000 字符` | 电子元件参数字段较多，需保留足够上下文用于工具调用的参数匹配与结果校验 |
| `plugin_request_timeout` | `120 秒` | 第三方供应链接口的响应延迟通常在60-90秒区间，120秒可覆盖正常请求时长 |
| `file_parse_segment_length` | `1500 字符` | 电子元件规格书的参数表格段落较长，1500字符分段可保留完整参数单元，避免拆分错误 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用工具上传HTML标题与内容时返回`400 Bad Request`，原因是未正确传递`file_title`和`file_content`的必填字段，或字段格式不符合接口校验规则。
- 现象为工作流调用工具时频繁触发`400`错误，原因是工具请求的参数未匹配电子元件尽调报告的字段规范，例如未携带`component_rating`等专属参数。
- 现象为自定义工具被其他应用调用时未生成思考输出，原因是未在工具配置中启用`thought_output_switch`参数，或工作流未配置思考节点与工具调用的联动逻辑。

## 怎么确认配好了
- 调用工具上传单份电子元件规格书PDF，检查返回的`parse_status`字段是否为`success`，根据文档长度调整`PARSE_FILE_TIMEOUT_SECONDS`的取值。
- 触发工具调用请求，查看接口返回的参数是否包含电子元件专属字段，如`resistance_value`、`package_type`，核对字段单位是否符合预设规范。
- 调用非qwen系列模型测试工具调用，检查返回的JSON格式是否符合插件要求，根据模型特性调整`tool_call_format_prompt`参数。
- 启用自定义工具的思考输出开关，触发跨应用调用，检查返回结果是否包含思考过程文本，确认`thought_output_switch`配置生效。
