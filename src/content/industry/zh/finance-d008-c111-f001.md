# 畜禽养殖智能尽调报告的HTTP 接口与外部系统

## 这个品类的数据长什么样
畜禽养殖智能尽调报告的数据主要来自养殖场的RFID溯源系统、当地畜牧兽医部门的检疫备案数据、饲料采购台账与出栏结算单据。数据更新节奏按养殖批次同步，单份报告文档结构分为存栏概况、防疫记录、饲料成本、出栏检疫四个核心模块。字段包含存栏量（单位：头/羽）、出栏重量（单位：千克）、检疫证编号、饲料采购单价（单位：元/千克）、养殖周期起始时间戳等，部分字段需关联对应批次的唯一标识。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
畜禽养殖尽调数据的批次化更新、多源异构特性，对HTTP接口对接提出明确约束。需支持按养殖批次ID精准拉取数据，适配单批次跨月的统计需求。多源数据源的字段命名存在差异，要求接口层需做字段映射转换，统一输出至尽调报告模板。官方检疫数据的合法性校验，需在接口调用时携带签名参数，避免非授权数据接入。单份报告的字段包含多单位计量值，接口返回需保留原始单位标识，无需额外转换。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `external_api_request_timeout` | `240–300 秒` | 畜禽养殖尽调数据需对接多源外部系统，跨系统聚合查询耗时较长，该区间可覆盖多数合规数据源的响应周期 |
| `workflow_variable_kb_selector` | `启用动态引用` | 需通过API调用时传递的批次ID切换对应养殖批次的知识库数据源，适配不同批次的尽调需求 |
| `api_auth_type` | `API_KEY 签名校验` | 畜禽养殖数据涉及养殖主体隐私与官方检疫备案信息，需通过签名校验确保接口调用合法性 |
| `external_data_field_mapping` | `按批次ID映射字段` | 不同外部数据源的字段命名存在差异，需统一映射为尽调报告所需的存栏量、检疫证号等标准字段 |
| `session_msg_retention_days` | `90 天` | 畜禽养殖尽调的批次周期多为3-6个月，保留90天的会话日志可覆盖单批次尽调的全流程排查需求 |
| `kb_search_top_k` | `前6–8 条` | 畜禽养殖尽调报告需兼顾全面性与精准性，该召回条数可覆盖单批次的核心统计数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部接口时返回`401 Unauthorized`状态码，FastGPT界面提示鉴权失败。原因：未配置`api_auth_type`为`API_KEY 签名校验`，或传入的签名参数与外部系统的校验规则不匹配。
- 现象：配置外部API对接后，本地测试接口正常，但FastGPT界面提示用户名密码错误。原因：未在`external_api_auth_type`中配置正确的鉴权参数格式，或传入的密钥未添加系统要求的前缀标识。
- 现象：工作流中配置知识库搜索节点时，选择变量引用知识库后无法加载对应数据源，或返回的结果为空。原因：未开启`workflow_variable_kb_selector`的动态引用权限，或传递的知识库ID参数格式不符合系统要求。

## 怎么确认配好了
- 发起一次API调用，传递养殖批次ID参数，检查工作流是否成功触发对应数据源的知识库搜索，确认变量引用生效。
- 查看外部接口的调用日志，确认返回的字段已完成映射，且保留了原始的单位标识与时间戳信息。
- 模拟鉴权失败的调用请求，确认FastGPT界面返回`401 Unauthorized`的标准报错文案，验证鉴权配置生效。
- 查看会话消息列表，确认对应批次的尽调查询日志已按`session_msg_retention_days`的设置保留，未被提前清理。
