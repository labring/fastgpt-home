# 白酒智能尽调报告的工具调用与插件

## 这个品类的数据长什么样
白酒智能尽调报告的数据主要来自国家及地方食品药品检验检测机构的公开抽检数据、白酒产区行业协会的月度/季度更新的产区数据、上市酒企的年度公开年报及第三方合规审计文档。单份报告文档长度跨度较大，从数百字的批次抽检简报到数万字的全链条溯源报告均有。文档字段包含酒精度（单位%vol）、总酸总酯含量（单位g/L）、原料配比、酿造周期、合规检测项结果、批次编号与生产日期等，部分溯源类文档还包含物流链路与终端销售数据。更新节奏因数据源不同存在差异，抽检数据按批次发布，产区行业数据按月更新，企业年报则按年度同步。

## 这些特征在「工具调用与插件」这一环带来什么约束
白酒尽调数据的多源分散特性，要求插件需配置多数据源适配器，分别对接抽检机构接口、产区协会API与企业年报数据库。文档长度跨度大，需调整工具调用的上下文截断阈值，避免丢失理化指标等关键字段。字段单位的特殊性，要求插件内置单位校验逻辑，自动识别并转换%vol、g/L等专用单位，避免参数解析失败。多源数据更新频率差异，需配置定时拉取任务的差异化调度规则，确保最新抽检数据与年度报告的同步。部分合规字段需权限校验，插件需集成角色权限过滤逻辑，仅向授权调用方返回完整数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `TOOL_CONTEXT_TRUNCATE_LENGTH` | `800–1200 字符` | 白酒尽调报告的核心字段（理化指标、合规检测项）通常集中在该长度区间，避免截断关键信息 |
| `UNIT_VALIDATION_ENABLE` | `开启` | 白酒数据包含%vol、g/L等专用单位，开启后可自动校验并标准化参数单位，避免解析错误 |
| `PLUGIN_DATA_SOURCE_ADAPTERS` | `抽检接口、产区API、企业年报库` | 覆盖白酒尽调数据的三大核心来源，确保插件可拉取全链路数据 |
| `SCHEDULE_INTERVAL` | `3600 秒、86400 秒` | 适配不同数据源的更新节奏，按小时拉取新批次抽检数据，按天同步产区月度数据 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 大尺寸全链条溯源文档的解析耗时较长，避免因超时中断任务 |
| `PLUGIN_PERMISSION_FILTER` | `合规字段可见范围` | 过滤企业未公开的产能、库存等敏感数据，仅向授权节点开放完整字段 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用封装了SSE协议的MCP插件时，界面提示「仅支持stdio进程调用」。原因是FastGPT 4.9.6版本的插件运行环境默认仅启用stdio通信方式，未开放SSE协议支持。
- 现象为将`stream`参数设为`true`时，无法获取工具调用的完整最终结果，仅返回分段数据流。原因是未配置工具调用的结果聚合逻辑，未将分段数据流合并为完整输出。
- 现象为私有部署FastGPT V4.14.1版本时，导入自定义插件提示「internal server error」。原因是插件配置中的接口地址未添加部署环境的白名单，或端口映射存在冲突。

## 怎么确认配好了
- 上传一份白酒批次抽检报告，查看工具调用后提取的理化指标字段是否包含正确的单位，核对`UNIT_VALIDATION_ENABLE`是否生效。
- 配置多数据源适配器后，手动触发插件拉取数据，检查是否同时获取到抽检数据、产区数据与企业年报信息。
- 查看插件运行日志，确认`SCHEDULE_INTERVAL`的调度任务按预设周期执行，无超时报错。
- 切换不同权限角色调用插件，检查合规字段是否按配置过滤，未授权角色无法查看敏感数据。
