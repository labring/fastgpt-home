# 纺织制造智能尽调报告的模型接入与配置

## 这个品类的数据长什么样
纺织制造智能尽调报告的数据主要来自海关进出口报关单、工厂生产台账、原料采购质检报告、供应链上下游交易凭证四类。原料采购数据按月同步，生产台账按周更新，海关报关数据实时同步。文档结构包含结构化采购明细表格、产能报表PDF、质检报告等，特有字段包括纱支规格（单位Ne）、坯布克重（单位g/㎡）、织造密度（单位根/英寸），部分文档包含图像格式的生产车间现场照片与布匹样图。

## 这些特征在「模型接入与配置」这一环带来什么约束
纺织制造尽调数据的多源混合结构与特有行业术语，要求模型接入时需适配结构化表格解析与多模态图像识别能力。原料采购与海关数据的实时/高频更新属性，要求配置中需支持定时增量同步的触发规则，避免全量拉取占用过多资源。特有单位如Ne、g/㎡、根/英寸，需要模型具备行业术语识别能力，避免字段解析错误。长文档如年度产能报表的存在，要求调整上下文窗口与分段参数，适配长文本解析需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `enableMultiModal` | 开启 | 适配纺织尽调报告中的布匹样图、车间照片等图像类文档解析需求 |
| `maxContext` | `8000–16000 令牌` | 适配年度产能报表、长周期交易凭证等长文本文档的上下文处理 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 避免大型海关报关单、批量采购台账解析超时 |
| `incrementalSync` | 开启，同步间隔设为 `24 小时` | 适配原料采购、海关数据的高频更新需求，减少全量同步资源消耗 |
| `fieldExtractThreshold` | `0.75–0.85` | 提升纱支规格、织造密度等特有纺织字段的提取准确率 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 适配批量生产台账、多页海关报关单的上传需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：界面中图像解析选项置灰无法开启，报错显示「不支持多模态输入」。原因：未正确开启`enableMultiModal`配置项，或未绑定支持多模态能力的模型接口。
- 现象：模型测试返回`connector error`，且日志显示请求超时。原因：`PARSE_FILE_TIMEOUT_SECONDS`配置值过小，无法完成大型纺织台账或海关报关单的解析请求。
- 现象：线上saas版无法添加自定义部署的模型，或v4.9.0版本中配置ai proxy后模型测试失败。原因：未正确填写模型代理的接口地址与访问密钥，或未对齐部署模型的上下文窗口参数与平台预设值。

## 怎么确认配好了
- 上传单张布匹样图，检查模型是否能识别图像中的纹理、规格信息，确认多模态配置生效。
- 上传一份100页以上的年度产能报表，检查解析任务是否在`PARSE_FILE_TIMEOUT_SECONDS`配置时长内完成，无超时报错。
- 配置增量同步任务后，等待同步周期结束，检查是否仅新增了当日更新的原料采购数据，无全量重复同步记录。
- 测试提取纱支规格字段，检查返回结果是否包含`Ne`、`g/㎡`等特有单位，无字段解析错误。
