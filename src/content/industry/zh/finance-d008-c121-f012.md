# 耐火材料智能尽调报告的模型接入与配置

## 这个品类的数据长什么样
用于金融尽调的耐火材料数据主要来自生产企业的出厂质检报告、行业协会发布的品类性能标准文档、下游建材工程的现场使用记录，以及对应招投标项目的合规性备案文件。更新节奏：单批次产品的质检数据随生产出货实时更新，行业标准文档每1-2年修订一次，下游使用与备案数据按月汇总。文档结构：单份尽调报告包含产品批号、物理性能、化学成分组成、适用工况范围四个核心模块，字段无统一缩写，部分厂商会自定义附加参数项。

## 这些特征在「模型接入与配置」这一环带来什么约束
这些特征对模型接入与配置环节带来多重约束：首先，多源数据包含结构化质检报告、非结构化标准文档与合规备案文件，要求配置多源数据接入的适配规则；其次，单批次数据实时更新且来源分散，需要配置定时同步与字段映射的容错机制，避免模型使用过期或不匹配的数据源；第三，专业性能指标的命名差异较大，需要配置术语匹配的权重规则，提升参数识别精度；第四，尽调报告包含项目合规性内容，需要配置敏感信息的过滤规则，保障金融场景下的数据合规性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 耐火材料尽调报告包含专业性能图表与多组参数，适配FastGPT V4.9.3版本的解析规则，较长超时可避免解析中断 |
| `maxContext` | `8000–16000 字符` | 单份尽调报告文本长度较长，适配的上下文窗口可完整加载全部核心数据 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 区分相似专业术语的细微差异，避免误匹配非目标性能参数 |
| `RECALL_TOP_N` | `前 8–12 条` | 覆盖尽调报告中多组核心专业指标，避免遗漏关键参数 |
| `SYNC_INTERVAL_HOURS` | `每 6 小时` | 匹配耐火材料生产出货的实时更新节奏，保障数据源时效性 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 适配附带高清质检照片、检测数据表格的完整报告上传需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调试预览界面无法选中已接入的目标模型，或调用时返回`401 Unauthorized`报错。原因：未正确配置模型接入的API密钥与访问地址，或密钥权限不足。
- 现象：解析后的耐火材料尽调报告出现字段错位或参数匹配错误。原因：未配置专业字段的映射规则，无法兼容不同厂商自定义的参数命名格式。
- 现象：模型生成的尽调报告未包含指定批次的性能数据。原因：定时同步间隔设置过长，未及时更新最新批次的质检数据。

## 怎么确认配好了
- 进入模型接入管理界面，验证已配置的API地址、密钥与模型参数是否与目标平台一致。
- 上传单份耐火材料尽调报告，检查解析后的字段是否覆盖核心性能指标，无明显错位。
- 触发一次定时同步任务，验证最新批次的质检数据是否成功导入知识库。
- 在调试预览界面输入专业性能参数查询，检查模型召回的内容是否匹配目标字段。
