# 耐火材料智能尽调报告的知识库检索与召回

## 这个品类的数据长什么样
耐火材料相关数据主要来源于生产企业的出厂检测报告、行业协会发布的技术规范、第三方检测机构的测试报告。数据更新节奏随来源不同存在差异：企业出厂数据随生产批次实时更新，行业规范文档更新周期不固定，第三方测试报告随委托批次生成。单份文档通常包含炉号、化学成分（如Al2O3、SiO2含量）、体积密度、耐压强度、最高使用温度等字段，字段附带明确单位，如g/cm³、MPa、℃。部分检测报告为多页PDF格式，包含图像化的测试曲线与原始数据记录。

## 这些特征在「知识库检索与召回」这一环带来什么约束
耐火材料数据的多来源、差异化更新节奏，要求检索系统支持按来源、更新时间筛选数据。专业字段与固定单位的存在，要求检索匹配需严格对应字段名称与单位，避免因术语表述差异导致匹配失效。长文档与图像化内容的存在，要求分段解析时需保留同批次检测数据的完整性，避免割裂连续的测试逻辑。同时，单份尽调报告需覆盖多组批次数据，召回结果需兼顾覆盖范围与上下文长度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 耐火材料检测报告多包含连续的成分、性能数据，过长分段会割裂同批次检测逻辑，过短则无法覆盖完整测试项 |
| `相似度阈值` | 0.75–0.85 | 该品类专业术语多，需过滤低匹配度的无关文档，同时保留同成分体系的相似检测数据 |
| `召回条数` | 前6–8条 | 单份尽调报告需覆盖多批次检测数据，过多召回会超出上下文窗口，过少则无法覆盖全量关键参数 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 耐火材料检测报告多为多页PDF，包含大量图像化检测数据，解析耗时较长 |
| `增量更新触发阈值` | 按文件修改时间触发 | 企业出厂数据随批次更新频率高，按修改时间触发可及时同步最新批次数据 |
| `重排返回条数` | 前3–4条 | 优先返回与尽调目标匹配度最高的核心检测数据，避免冗余信息干扰大模型输出 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 知识库后台可查询到耐火材料检测数据，但关联问答接口返回内容未包含相关检测参数。原因是分段长度设置过短，将同批次检测数据拆分至多个分段，召回时仅返回部分片段，大模型无法整合完整检测逻辑。
- 创建知识库目录时传入父级ID参数后，新上传的文档仍挂载至根目录。原因是父级ID参数格式错误，未使用系统生成的唯一标识字符串，或传入的ID对应目录不存在。
- 解析耐火材料多页PDF检测报告时，触发`PARSE_FILE_TIMEOUT_SECONDS`对应的超时报错。原因是该配置项的设置值低于实际解析耗时，未考虑多页图像化检测报告的解析时长。

## 怎么确认配好了
- 上传单份耐火材料出厂检测报告，查看解析后的分段内容，确认同批次的化学成分、性能数据未被割裂为多个独立分段。
- 输入专业检索词，核对召回结果的条数与`召回条数`配置一致，且结果包含目标字段的准确匹配内容。
- 触发增量更新操作，查看更新日志，确认仅修改后的批次文件被同步至知识库，未重复解析未修改的文档。
- 调用关联知识库的问答接口，核对返回内容包含解析后的检测数据字段，无缺失的关键参数。
