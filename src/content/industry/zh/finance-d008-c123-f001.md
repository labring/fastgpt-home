# 能源金属智能尽调报告的HTTP 接口与外部系统

## 这个品类的数据长什么样
能源金属品类的尽调报告数据来源涵盖国内有色金属工业协会公开披露数据、上海期货交易所与伦敦金属交易所的行情数据、海关总署进出口备案数据，以及矿山、冶炼企业的公开经营年报。数据更新节奏分维度：现货交易数据每日更新，行业库存数据每周更新，月度供需统计数据每月更新，企业经营财报每季度更新。单份尽调报告的数据模块包含品种分类、市场行情、产业链供需、进出口情况四个核心板块，每个板块对应独立的数据源接口。字段包括品种名称、现货结算价、社会库存总量、月度产量、进出口总量，单位分别为无、元/吨、万吨、吨、吨，跨市场交易数据需进行单位转换。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
不同数据源的更新频率差异要求HTTP接口配置分维度的定时拉取规则，匹配现货、库存、财报等不同数据的更新节奏。多源数据的单位不统一，要求配置统一的字段转换规则，将不同接口返回的元/吨、美元/吨等单位统一为目标格式。固定的尽调报告文档结构，要求配置响应字段的映射规则，将各数据源的原始字段对齐到统一的报告模板字段。部分专业数据源需要API密钥认证，要求配置安全的参数存储与调用逻辑。单次请求返回的海量数据，要求配置分页拉取的参数，避免单次请求超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `HTTP_REQUEST_TIMEOUT` | 300–600 秒 | 匹配多数能源金属数据源接口的响应时长，避免常规行情数据请求超时 |
| `AUTH_API_KEY` | 按数据源要求配置专属密钥 | 多数专业期货、行业协会接口需要API密钥完成身份验证，保障数据访问权限 |
| `SCHEDULE_PULL_INTERVAL` | 1小时（现货数据）、1天（库存数据）、1季度（财报数据） | 匹配不同维度数据的更新节奏，避免重复拉取或数据滞后 |
| `FIELD_MAPPING_RULE` | 按尽调报告模板字段映射 | 统一各数据源的原始字段到报告所需的品种、行情、供需等模块，保障数据结构一致性 |
| `UNIT_CONVERSION_CONFIG` | 启用自动转换，配置汇率与单位换算规则 | 解决不同数据源返回的元/吨、美元/吨等单位不统一的问题，确保报告数据格式一致 |
| `PAGE_SIZE` | 100 条 | 适配能源金属品类数据的单次返回量，避免单次请求数据过大导致超时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：HTTP请求的响应报文Set-Cookie字段未被正确提取，后续请求无法携带认证信息，接口返回401状态码。原因：未启用HTTP请求模块的会话Cookie持久化配置，仅单次获取了认证Cookie未在后续请求中复用。
- 现象：通过API获取的知识库图片链接，在第三方系统中无法正常加载，显示为空或破损。原因：未配置图片链接的跨域访问权限，第三方系统无法直接访问FastGPT内部的API图片接口。
- 现象：API调用对话接口时，仅收到完整的单条响应内容，无法获取流式分块返回的结果。原因：未在请求头中添加`Accept: text/event-stream`参数，未开启流式输出的请求模式。

## 怎么确认配好了
- 手动发起一次HTTP请求，核对返回的原始字段是否与配置的`FIELD_MAPPING_RULE`对齐，确认转换后的字段符合尽调报告模板要求。
- 查看定时任务的执行记录，确认不同数据源的拉取间隔符合配置的`SCHEDULE_PULL_INTERVAL`，无超时或失败的请求。
- 调用对话API并配置`Accept: text/event-stream`请求头，检查是否能接收到分块返回的流式数据。
- 验证第三方系统访问图片链接的权限，确认配置的跨域规则允许目标域名访问内部API图片接口。
