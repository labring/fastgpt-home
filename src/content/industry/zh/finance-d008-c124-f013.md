# 自动化设备智能尽调报告的知识库检索与召回

## 这个品类的数据长什么样
自动化设备的数据源主要包括出厂参数手册、定期维护记录、校准报告、故障排查日志以及行业通用设备标准文档，多用于金融机构开展设备融资租赁、保理业务的智能尽调报告生成。静态参数文档如设备型号、额定功率、运行转速等内容固定，更新节奏为设备投产时一次性上传；动态数据如运行时长、故障频次、更换部件记录则随设备使用定期更新，更新周期从每周到每季度不等。文档格式以PDF、CSV、Excel为主，结构化字段包含设备编号、单位（kW、r/min、小时）、故障代码、维护步骤等，部分文档附带图表和参数对照表。

## 这些特征在「知识库检索与召回」这一环带来什么约束
自动化设备的数据特征对检索召回环节带来多重约束。静态参数的固定性要求检索时需精准匹配设备编号、型号等唯一标识，避免跨型号误召回；动态日志的高频更新要求知识库支持增量同步，确保检索结果包含最新的维护和故障数据。多格式文档并存需要解析环节适配不同字段提取规则，例如CSV日志需正确识别时间戳和对应参数单位，PDF手册需保留表格内的结构化数据。字段附带明确单位的特点，要求检索时需同时匹配参数名称和单位，避免将不同单位的同类参数混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 自动化设备文档多包含长段的参数说明和故障排查步骤，过长分段会丢失上下文关联，过短则无法覆盖完整的参数组合描述 |
| `召回条数` | 前 8–12 条 | 自动化设备尽调需要同时匹配型号、功率、维护周期等多个字段，过多召回会引入无关文档，过少则无法覆盖所有匹配项 |
| `相似度阈值` | 0.75–0.85 | 设备参数的文本描述存在固定格式，阈值过低会引入误匹配，过高则无法召回相似型号的替代方案文档 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 大型设备的维护手册PDF可能包含多页图表和表格，解析耗时较长，超时会导致文档上传失败 |
| `UPLOAD_FILE_MAX_SIZE` | 2000 MB | 批量上传的设备运行日志CSV文件可能单文件体积较大，限制过小会导致大日志文件无法上传 |
| `重排返回条数` | 前 3–5 条 | 尽调报告需要优先展示最匹配的核心参数文档，避免冗余信息干扰 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传WPS导出的CSV格式设备运行日志后，解析后的字段出现乱码。原因：WPS导出的CSV可能使用非UTF-8编码，未配置正确的文件编码解析参数。
- 现象：调用API同时查询同一账号下两个知识库时，返回结果为空或未包含预期的跨库文档。原因：接口请求中未正确携带多个知识库的ID参数，或未开启跨知识库检索的权限设置。
- 现象：检索设备型号相关文档时，返回结果包含大量无关的耗材、配件文档。原因：相似度阈值设置过低，将包含“设备”关键词的非目标文档误召回。

## 怎么确认配好了
- 上传一份标准格式的设备参数PDF和CSV日志，检查解析后的字段是否完整，无乱码现象。
- 调用检索接口，指定单个知识库，核对返回结果的条数与配置的召回条数一致。
- 同时指定两个知识库发起检索，确认返回结果包含两个知识库内的匹配文档。
- 调整相似度阈值，观察检索结果的匹配精准度变化，确认阈值符合业务需求。
