# 融资租赁智能尽调报告的工具调用与插件

## 这个品类的数据长什么样
融资租赁智能尽调报告的数据来源涵盖工商公示系统、中登网租赁物登记平台、企业征信报告、租赁合同原件、租赁物评估报告等。数据更新节奏依类型区分：企业经营类数据按季度更新，租赁物权属变更数据实时同步，租赁合同签约后即时更新。文档结构以尽调清单为核心框架，包含企业主体信息、租赁物明细、还款计划、关联交易核查、征信评级等模块，字段包含租赁物原值、租赁期限、租金费率、承租人征信等级等特有属性，对应单位分别为元、月、%、信用等级标识。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源分散的数据要求工具调用需整合多个独立数据源插件，避免单次调用仅覆盖部分核心信息。租赁物权属数据的实时性要求，需在插件中配置触发式同步开关，确保尽调时的权属状态为最新。长文档如租赁合同、企业财报的存在，要求插件支持分段读取与上下文聚合，避免超出处理上限。特有字段与单位的存在，要求工具调用时需配置专属字段映射规则，防止单位混淆导致的报告错误。跨金融类接口的调用需求，需适配不同数据源的认证与限流规则。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_data_source_list` | `工商公示系统、中登网租赁登记、企业征信报告、租赁物评估平台` | 覆盖融资租赁尽调的核心数据源，确保信息完整性 |
| `plugin_request_timeout` | `120 秒` | 适配跨多金融类接口的响应时长，避免单次调用超时中断 |
| `parse_chunk_size` | `800–1200 字符` | 平衡长文档拆分的上下文完整性与处理效率，适配租赁合同、财报等文件 |
| `field_mapping_mode` | `手动指定单位映射` | 匹配融资租赁数据的特有单位，防止元、%、月等单位混淆 |
| `plugin_max_retries` | `3 次` | 应对金融类接口的临时限流或波动，减少单次请求失败导致的尽调中断 |
| `plugin_batch_query_limit` | `5 条/次` | 适配多数金融类接口的限流规则，避免批量查询触发拦截 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：使用搜索插件后仅返回网页标题与摘要，无法读取完整链接内容。原因：未配置网页抓取子插件，仅启用了基础搜索能力，未开启链接内容拉取开关。
- 现象：工具调用列表中仅显示少量可选模型，无法查看全部可用模型。原因：`available_model_list`配置项仅填写了部分模型标识，未同步接入全量支持的模型列表。
- 现象：HTTP插件调用第三方API返回502错误，同一API在其他工具中调用正常。原因：未配置正确的请求头参数，或`plugin_request_timeout`设置过短导致中间代理超时，未匹配第三方接口的响应规则。

## 怎么确认配好了
- 进入插件管理页面，查看`plugin_data_source_list`配置项，确认已添加融资租赁尽调所需的全部数据源标识。
- 发起单次测试调用，验证不同数据源的返回字段是否包含租赁物原值、租赁期限等核心字段，且单位匹配预期。
- 检查模型选择列表，确认所有目标模型均已出现在可选范围内，无遗漏。
- 触发HTTP插件调用测试，查看返回状态码与响应内容，确认与第三方接口的返回结果一致。
