# 调味品智能尽调报告的HTTP接口与外部系统

## 这个品类的数据长什么样
调味品尽调数据主要来自中国调味品协会公开监测数据、上游大豆、辣椒等原料供应商的每日报价接口、线下连锁商超的动销上报接口。数据更新节奏分为两类：原料成本数据每日更新，终端动销数据每两日更新，合规检测报告随产品批次发布。单份尽调文档结构固定，包含品牌名称、产品SKU、原料成本价、终端零售价、渠道盈利空间、批次检测报告编号等字段，单位为元/千克、元/瓶、批次号等，部分检测字段附带合格判定阈值，以数值形式标注。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
调味品尽调数据的多源异构特征，要求外部系统配置多套鉴权规则，中国调味品协会数据使用API_KEY鉴权，商超动销接口采用OAuth2.0鉴权。不同数据源的更新节奏差异，需要为每个接口配置独立的定时拉取周期，原料成本接口每12小时同步一次，终端动销数据每48小时拉取。字段包含固定合格阈值，HTTP接口返回的检测类字段需在调用后做合规校验，超出阈值的记录需自动过滤。部分上游供应商接口限制单次返回数据量，需实现分页拉取逻辑以适配批量尽调需求。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `EXTERNAL_API_AUTH_TYPE` | 按数据源分别配置为`api_key`、`oauth2` | 适配多源数据的鉴权差异，协会公开数据使用API_KEY鉴权，商超动销数据使用OAuth2.0鉴权 |
| `SYNC_TASK_INTERVAL` | 原料接口设为`43200 秒`，动销接口设为`172800 秒` | 匹配原料数据每日更新、动销数据每两日更新的节奏 |
| `FIELD_VALIDATION_SWITCH` | 开启 | 自动校验检测字段的合格阈值，过滤不合规数据 |
| `PAGE_SIZE` | 设为`100` | 适配多数上游供应商接口单次返回100条数据的限制，避免请求被拦截 |
| `API_REQUEST_TIMEOUT` | 设为`60 秒` | 覆盖批量拉取时的网络延迟，避免超时中断 |
| `SKU_MATCH_PATTERN` | 设为`^[a-zA-Z0-9]+_\d+ml|\d+g$` | 匹配调味品SKU的规格命名规则，精准匹配目标产品数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用系统升级接口返回`POST /api/admin/initv4818 404`错误。原因：未将FastGPT容器端口映射至公网可访问地址，或请求路径未匹配最新版本的接口路由规则。
- 配置外部接口后未获取到会话相关数据。原因：未开启知识库的会话协议开关，或未在接口鉴权配置中添加会话权限字段。
- 部署钉钉机器人时提示“消息接收地址校验失败”。原因：FastGPT的外部接口地址未配置为公网可访问的有效地址，或未正确映射容器端口至公网。

## 怎么确认配好了
- 调用配置的外部接口，查看返回数据的字段是否与预设的尽调文档结构一致，核对字段名称与单位是否匹配。
- 查看定时同步任务的执行日志，确认不同数据源的拉取周期符合配置的`SYNC_TASK_INTERVAL`值。
- 提交批量SKU的拉取请求，确认接口返回的数据量未超过配置的`PAGE_SIZE`限制，无分页截断问题。
- 触发钉钉机器人测试消息，确认接收地址校验通过，消息可正常推送至指定群组。
