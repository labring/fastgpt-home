# 贵金属智能尽调报告的模型接入与配置

## 这个品类的数据长什么样
贵金属智能尽调报告的数据源主要来自上海黄金交易所、伦敦金银市场协会、国内期货交易所的公开接口，以及行业协会发布的供需数据。更新节奏分为三类：现货与期货实时行情为分钟级更新，日度供需报告于次日发布，月度行业动态于次月5日前更新。文档结构包含结构化行情表格与半结构化分析段落，字段涵盖标准化交易代码（如AU9999、AG9999）、计价单位（元/克、美元/盎司）、开盘价、收盘价、涨跌幅、成交量、持仓量等，部分报告包含交割规则与政策变动内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
贵金属行情的实时性要求模型调用需匹配数据更新节奏，避免使用过期的历史数据生成尽调报告。多计价单位的字段差异要求接入时需配置统一的单位转换规则，防止输出内容出现单位混乱。大体积的结构化行情文件与长文本行业分析内容，会增加模型调用的解析与推理耗时，需调整超时与上下文窗口参数。此外，不同贵金属品种的行情指标高度相似，需配置合理的召回与相似度阈值，避免模型混淆品种数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 字符 | 适配贵金属尽调报告的长文本分析需求，避免截断核心行情与供需数据 |
| `UPLOAD_FILE_MAX_SIZE` | 200 MB | 支持导入完整的交易所行情快照、行业研报等尽调素材 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 适配大体积结构化数据文件的解析耗时，避免中途中断 |
| `召回条数` | 前8条 | 覆盖贵金属行情的多维度指标，避免遗漏关键报价与持仓数据 |
| `相似度阈值` | 0.75–0.85 | 区分贵金属不同品种的行情差异，避免混淆AU9999与AG9999的报价 |
| `qwen3 模型支持开关` | 开启 | 适配复杂尽调逻辑的推理需求，满足多维度行情分析的能力要求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用OneAPI时返回504网关超时错误，请求未完成。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，贵金属尽调的大体积行情数据解析耗时超过系统默认阈值。
- 现象：模型输出的贵金属报价单位混乱，同时出现元/克与美元/盎司的混用情况。原因：未配置单位转换映射规则，未对齐数据源与尽调报告的计价单位要求。
- 现象：无法查看OneAPI调用失败的详细日志，无法定位请求异常原因。原因：未开启FastGPT的`API调用日志留存`开关，导致失败请求的完整请求与返回信息未被系统记录。

## 怎么确认配好了
- 上传一份标准的贵金属行情CSV文件，检查解析后的字段是否包含交易代码、计价单位、成交量等必填项，无缺失或乱码。
- 发起一次OneAPI调用请求，查看返回的响应体中是否包含正确的贵金属行情数据，验证`maxContext`参数是否未截断长文本内容。
- 调用测试接口触发一次失败请求，确认`API调用日志留存`开关开启后，可在系统日志中查看到完整的请求与返回信息。
- 切换至qwen3模型发起尽调请求，确认模型可正确输出贵金属供需分析与行情走势判断，无模型不支持的报错。
