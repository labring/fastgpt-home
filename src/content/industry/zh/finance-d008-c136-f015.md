# 贵金属智能尽调报告的部署与升级

## 这个品类的数据长什么样
贵金属智能尽调报告的数据主要来自境内外期货交易所实时行情接口、现货市场报价平台、行业协会库存统计、央行及监管机构的政策文件。数据更新节奏分为分钟级（实时行情、报价）、日度（库存数据）、月度（供需分析报告）三类。单份报告的文档结构包含品种基本信息、历史K线数据、供需平衡表、政策解读四个模块，字段包含最新价（单位元/克、美元/盎司）、涨跌幅、持仓量、库存吨数、报告发布机构与时间等，部分长周期报告可达到数十页篇幅。

## 这些特征在「部署与升级」这一环带来什么约束
贵金属数据的分钟级更新要求部署阶段需配置高频同步任务，升级时需确保数据链路无中断，避免因版本更新导致行情同步延迟。长文档与多字段的结构则要求调整解析与召回的参数阈值，防止长文档解析超时或召回内容冗余。此外，贵金属行情数据的合规性要求较高，部署时需校验数据源的授权资质，升级时需同步更新数据源的配置参数，避免因配置变更导致数据获取失败。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `1200 秒` | 贵金属尽调报告包含长周期供需文档与历史K线数据，解析耗时较长 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 支持批量上传多份历史行情CSV、K线图打包文件 |
| `maxContext` | `8000–12000 字符` | 覆盖贵金属行情、供需、政策等多维度关联所需的上下文长度 |
| `召回条数` | `前 8 条` | 匹配尽调所需的实时行情、历史数据、政策、库存四类核心信息维度 |
| `定时任务触发间隔` | `5 分钟` | 适配贵金属现货与期货行情的分钟级更新节奏 |
| `相似度阈值` | `0.75–0.85` | 区分黄金、白银等相似品种的行情数据，避免召回无关内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：本地部署新增模型后调用文件解析接口，返回`403 status code (no body)`。原因：未正确配置`API_ALLOWED_ORIGINS`参数，未将前端部署域名加入白名单。
- 现象：定时任务未按计划同步贵金属行情数据。原因：将`定时任务触发间隔`设置为过长的周期，未匹配行情的分钟级更新要求。
- 现象：上传尽调报告后无法确认索引是否完成。原因：未启用`文件解析状态回调`配置，未监听`file_parse_status`字段的更新状态。

## 怎么确认配好了
- 手动上传一份标准贵金属尽调报告，检查解析后的文本是否覆盖了行情、供需、政策等核心模块的字段。
- 触发一次定时同步任务，查看向量库中是否新增了对应时间区间的行情数据条目。
- 调用检索接口传入贵金属相关关键词，检查返回结果的字段匹配度是否符合预期。
- 查看系统运行日志，确认无`403 status code`相关的错误输出，数据源配置参数无异常。
