# 造纸智能尽调报告的HTTP 接口与外部系统

## 这个品类的数据长什么样
造纸智能尽调报告的数据主要来自造纸行业协会公开月度报告、上市造纸企业季度财报、木浆与废纸等原材料的现货期货交易平台、企业排污监测台账。数据更新节奏存在差异：原材料报价每日更新，行业协会产能数据月度更新，企业财报按季度发布。文档结构分为产能规模、原材料成本、单位能耗、排污指标、下游需求五大模块，字段包含木浆采购单价（元/吨）、万吨年产能、吨纸综合能耗（千瓦时/吨）等，需严格匹配预设单位与数值格式。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
造纸尽调数据的多源属性与差异化更新节奏，要求HTTP接口需同时对接标准化行业数据接口、企业财报接口与实时原材料报价接口。不同数据源的字段单位存在固定要求，接口需支持返回标准化字段，避免单位转换误差。长文档结构与多字段内容，要求接口支持分页返回以降低单次请求负载。实时类数据源的高频拉取需求，需配置独立的同步任务，与季度更新的财报接口区分调度逻辑，避免资源浪费。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `API_REQUEST_TIMEOUT` | `300 秒` | 造纸尽调数据包含多源接口响应，单接口超时设置过短会导致有效数据被截断 |
| `DATA_SYNC_INTERVAL` | `原材料接口：86400 秒，财报接口：7776000 秒` | 原材料报价每日更新，财报数据每季度更新，差异化间隔可优化资源占用 |
| `FIELD_VALIDATION_RULES` | 校验单位匹配（如元/吨、千瓦时/吨）、数值非负 | 造纸尽调字段有固定单位要求，避免无效数据进入尽调报告 |
| `API_RETRY_TIMES` | `3 次` | 外部接口可能出现临时波动，重试可降低单次请求失败的影响 |
| `RESPONSE_PAGINATION_SIZE` | `100 条/页` | 造纸行业单批次尽调数据量较大，分页可避免接口返回过载 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用外部原材料报价接口返回`403 Forbidden`，原因：未在请求头中携带合法的API密钥，或接口服务商限制了非授权IP的访问。
- 部署后`external_system_manage`页面无法加载，原因：部署时未正确配置外部系统的环境变量端口映射，或依赖包版本存在冲突。
- 配置外部模型提供商后测试返回`404 Not Found`，原因：未正确填写外部系统的模型ID或接口地址，与已配置的提供商信息不匹配。

## 怎么确认配好了
- 调用配置好的外部接口，检查返回的字段是否包含造纸尽调所需的标准化字段，核对单位是否符合预设规则。
- 查看接口日志，确认重试机制在接口临时报错时正常触发，无连续失败的请求。
- 测试不同更新频率的数据源，确认数据同步任务按预设间隔执行。
- 触发尽调报告生成流程，检查外部系统返回的数据是否被正确解析并整合到报告内容中。
