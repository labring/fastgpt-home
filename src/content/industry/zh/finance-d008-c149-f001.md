# 钢铁贸易智能尽调报告的HTTP 接口与外部系统

## 这个品类的数据长什么样
钢铁贸易智能尽调报告的数据来源包括行业协会公开的现货价格台账、港口通关交割记录、钢厂出货明细、下游制造业与建筑行业的采购订单。数据更新节奏存在差异：现货价格每日更新，行业库存每周更新，全品类贸易量每月更新。文档以结构化表格为主，包含贸易主体资质、货物规格（牌号、厚度、宽度）、交易单价（元/吨）、交割地点、账期等字段，部分报告附带钢厂质检报告、通关单据等附件。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多源且更新节奏不一致的数据要求HTTP接口支持按周期拉取不同数据源，需适配每日、每周、每月的同步任务配置。专属字段与规格要求接口需支持自定义字段校验与返回，避免通用参数无法覆盖钢铁贸易的特定数据项。大体积附件与长文本内容要求接口具备大文件解析能力与合理的超时设置，防止数据传输与解析中断。跨区域交割与商业机密属性要求接口配置跨域访问限制，保障数据安全。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `API_REQUEST_TIMEOUT` | `600 秒` | 钢铁贸易尽调数据涉及多源拉取与多字段整合，单份报告生成周期较长，600秒可覆盖全量数据处理流程 |
| `RECALL_TOP_K` | `前8-12条` | 钢铁贸易数据的材质、规格等字段匹配精度要求高，召回过多会引入无关数据，过少则无法覆盖有效信息 |
| `PARSE_FILE_MAX_SIZE` | `2000 MB` | 钢铁贸易尽调报告常附带钢厂质检报告、通关单据等大体积附件，需适配大文件解析需求 |
| `SYNC_CRON_EXPRESSION` | `0 0 2 * * *` 与 `0 0 1 * * 0` | 现货数据每日凌晨更新，库存数据每周日更新，分时段触发同步任务可避免资源冲突 |
| `API_ALLOWED_ORIGINS` | `对应企业内部业务系统域名` | 钢铁贸易数据涉及商业机密，需限制跨域访问来源，保障数据安全 |
| `TEXT_SPLITTER_CHUNK_SIZE` | `800–1200 字符` | 钢铁贸易数据的规格描述较长，分段过长会影响召回精度，过短则增加上下文处理开销 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用HTTP接口返回`413 Request Entity Too Large`错误。原因：未调整`PARSE_FILE_MAX_SIZE`配置，钢铁贸易尽调报告附带的质检报告、通关单据体积超出默认限制。
- 现象：通过API调用生成尽调报告后，无法获取本次调用关联的知识库文件列表。原因：未开启`API_RETURN_SOURCE_DOCS`配置，默认配置未启用源文件返回功能。
- 现象：定时同步任务频繁超时中断。原因：未调整`API_REQUEST_TIMEOUT`配置，默认超时时间过短，无法覆盖多源钢铁数据的拉取与整合周期。

## 怎么确认配好了
- 调用测试接口传入单份钢铁贸易质检附件，检查返回状态码为`200 OK`，确认文件解析配置生效。
- 发起包含`material_grade`、`delivery_location`等专属字段的查询请求，检查返回结果中包含对应字段，确认字段配置正确。
- 查看定时同步任务日志，确认按设定的`SYNC_CRON_EXPRESSION`时间触发，且无超时报错，确认同步配置生效。
- 调用接口时传入跨域白名单外的域名，检查返回`403 Forbidden`错误，确认跨域限制配置生效。
