# 风电智能尽调报告的文档解析与分块

## 这个品类的数据长什么样
风电智能尽调报告的数据主要来源于风机设备的出厂检测文件、现场运维台账、并网验收报告以及第三方检测机构出具的缺陷排查文档。数据更新节奏随文档类型有所区分，月度运维日志为按月更新，年度项目尽调报告为按项目周期更新，单次复检报告则为项目抽检后生成。文档多包含固定格式的结构化表格与半结构化描述段落，核心字段包括风机编号、塔筒高度、叶片长度、检测日期、缺陷等级等，专属单位涵盖千瓦（kW）、转每分钟（rpm）、米（m）等电力设备行业标准单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
风电尽调数据的多来源特性导致文档格式混杂，既有纯文本的运维日志，也有带表格的验收报告，解析时需兼顾结构化字段的完整性与半文本内容的连贯性。专属单位与字段的强关联要求分块时不能随意拆分包含单位的参数描述，否则会导致后续检索时单位与数值分离。长周期的年度报告页数较多，存在跨页的表格与设备信息，分块逻辑需支持跨页内容拼接，避免将完整的单台风机检测记录拆分为多个独立分块。月度短日志的高频更新则要求解析流程具备轻量化处理能力，避免单次解析耗时过长。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxChunkSize` | `800–1200 字符` | 风电尽调文档包含多组结构化检测数据与半结构化描述，该区间可保留单台风机检测记录的完整关联信息 |
| `chunkOverlap` | `100–150 字符` | 风电文档中存在跨分块的设备编号、检测日期字段，重叠可保留上下文关联 |
| `PARSE_EXCEL_ENABLE` | `开启` | 风电尽调的运维台账、并网数据多以Excel格式提交，需保留表格字段与单元格关联 |
| `PARSE_IMAGE_ENABLE` | `开启` | 部分风电检测报告附带现场缺陷照片，需解析图片中的文字标注 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 年度风电项目尽调报告可能包含多批次检测数据，单文件体积较大 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 大体积Excel或多页PDF报告解析耗时较长，避免超时中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传Excel文件后解析结果仅显示表头，无表格内容。原因：未开启`PARSE_EXCEL_ENABLE`配置项，导致Excel表格未被正确识别解析。
- 现象：解析后的分块结果拆分了单台风机的完整检测记录。原因：`maxChunkSize`取值过小，将包含设备编号、缺陷描述的完整段落拆分为多个分块，丢失上下文关联。
- 现象：解析含现场照片的PDF报告时，图片文字未被提取。原因：未开启`PARSE_IMAGE_ENABLE`配置，或未配置图片解析的基础参数。

## 怎么确认配好了
- 上传一份单台风机的月度检测报告，查看解析后的分块结果，确认核心字段未被拆分到不同分块。
- 上传一份包含表格的Excel尽调文件，确认解析结果保留了原始表格的行列结构与字段对应关系。
- 上传一份附带缺陷照片的PDF报告，确认解析结果包含图片中的文字标注内容。
- 上传一份大体积的年度尽调报告，确认解析任务未出现超时报错，且完整覆盖了所有文档内容。
