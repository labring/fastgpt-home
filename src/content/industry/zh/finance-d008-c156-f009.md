# 黑色家电智能尽调报告的引用来源与溯源

## 这个品类的数据长什么样
黑色家电的参数数据主要来自品牌官方产品页、国家能效标识备案数据库、第三方权威检测机构报告。更新节奏为品牌新品参数实时同步，能效数据每季度更新，售后政策随品牌调整不定期更新。单款机型的文档结构包含型号标识、核心性能参数、能效等级、物理尺寸、售后保障等字段，其中功率单位为瓦（W）或千瓦（kW），能效等级以1-3级标注，型号字段需包含品牌前缀与序列编号。

## 这些特征在「引用来源与溯源」这一环带来什么约束
不同数据源的可信度存在差异，官方产品页的参数优先级高于第三方报告，溯源环节需标注来源类型。更新频率较快且存在增量更新需求，需配置周期性同步任务避免数据滞后。字段与单位存在固定规范，召回时需精准匹配字段名与单位，避免跨型号的参数混淆。单款机型的文档片段数量较多，需合理控制召回范围以确保引用的精准性，避免冗余信息干扰尽调结论。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前8-12条` | 黑色家电单款机型的参数文档拆分后片段较多，需覆盖核心参数的完整来源 |
| `相似度阈值` | `0.75-0.85` | 需区分同品牌同系列不同型号的参数，避免召回非目标机型的片段 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 第三方检测报告通常篇幅较长，解析需预留足够时长 |
| `分段长度` | `800-1200 字符` | 黑色家电参数文档的字段块长度适中，分段后可保留完整参数组 |
| `知识库增量同步周期` | `每7天` | 能效数据每季度更新，增量同步可降低全量爬取的资源消耗 |
| `重排返回条数` | `前3-5条` | 需返回最精准的参数来源，避免过多冗余引用干扰尽调结果 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为召回匹配到知识库片段但仅返回单条引用，原因是未配置`重排返回条数`参数，使用默认配置导致仅返回单条结果。
- 现象为解析第三方检测报告时出现`408 Request Timeout`错误，原因是`PARSE_FILE_TIMEOUT_SECONDS`取值过低，未预留足够的文档解析时长。
- 现象为召回结果中出现跨型号的参数混淆，原因是`相似度阈值`设置过高，导致同型号的精准片段未被召回，反而匹配到相似型号的参数片段。

## 怎么确认配好了
- 上传单款黑色家电的参数文档，查看解析后的分段是否保留完整参数组，核对`分段长度`配置是否生效。
- 发起智能尽调查询，查看返回的引用来源是否标注了数据源类型，确认溯源功能已开启。
- 查看知识库同步日志，确认增量同步任务按设定周期执行，核对`知识库增量同步周期`配置。
- 测试同品牌同系列不同型号的查询，确认召回结果仅匹配目标机型的参数片段，验证`相似度阈值`配置的合理性。
