# 农化制品研报检索的工具调用与插件

## 这个品类的数据长什么样
农化制品研报的数据主要来自公开行业协会报告、券商研究所细分品类研报、海关总署进出口数据三类渠道。更新节奏存在差异：券商研报随行业动态按月或季度更新，行业协会数据按季度发布，企业经营数据按年度披露。单篇研报通常包含供需格局、价格走势、政策影响三个核心模块，核心量化字段包括产能规模、市场均价、进出口量，对应单位分别为万吨、元/吨、万吨，部分研报附带历史数据对比表格。

## 这些特征在「工具调用与插件」这一环带来什么约束
品类数据来源分散，要求工具调用需支持多数据源聚合配置，避免重复调用不同接口获取同类数据。不同数据源的更新频率差异较大，部分核心数据如市场价格需高频同步，因此需为对应工具设置针对性的更新触发规则。量化字段单位存在潜在不统一问题，需在工具链中预设单位转换逻辑，避免下游分析出现偏差。研报中包含大量结构化表格数据，需为插件配置表格字段提取规则，优先适配农化品类特有的产能、价格类字段。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolDataSourceList` | `["industry_association", "broker_research", "customs_data"]` | 覆盖农化研报的三类核心数据源，匹配品类数据来源特征 |
| `pluginUpdateInterval` | `3600 秒` | 适配农化市场价格的高频更新需求，保障数据时效性 |
| `fieldUnitMapping` | `{"price": "元/吨", "capacity": "万吨", "stock": "万吨"}` | 统一不同来源的量化字段单位，消除单位偏差 |
| `tableExtractThreshold` | `0.85` | 识别研报中的结构化表格，优先提取农化品类特有的产能、价格类字段 |
| `pluginTimeout` | `600 秒` | 适配多源数据聚合的耗时需求，避免单次工具调用超时 |
| `maxContextWindow` | `8000–12000 字符` | 适配农化研报单篇较长的文本内容，保障上下文完整性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流调用工具时返回500状态码，日志显示“数据库连接超时”。原因：部署时未将工具插件的数据库连接配置正确映射到容器网络，导致插件无法访问预设的农化数据数据库。
- 现象：调用工具后返回的字段单位混乱，部分价格显示为非预设单位。原因：未开启`fieldUnitMapping`配置，未统一不同数据源的量化字段单位。
- 现象：工具调用返回的研报结果条数不足，无法覆盖品类全量数据。原因：未在`toolDataSourceList`中配置全量数据源，遗漏了行业协会或海关数据入口。

## 怎么确认配好了
- 进入工具插件配置页面，核对`toolDataSourceList`是否包含品类所需的三类数据源。
- 发起单次工具调用，检查返回结果中的量化字段单位是否与预设规则一致。
- 查看工具调用日志，确认无连接超时或参数格式错误的报错信息。
- 对比工具返回的研报数据量与公开数据源的披露量，确认覆盖范围符合品类需求。
