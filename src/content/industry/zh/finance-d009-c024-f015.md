# 农化制品研报检索的部署与升级

## 这个品类的数据长什么样
农化制品研报数据主要来自行业协会公开监测数据、上市农化企业定期报告、券商行业深度报告及农业农村部农资监管公示信息。更新节奏覆盖月度价格监测、季度行业供需分析、年度产业规划报告。文档结构多包含产业链核心指标表格、政策条款摘编、上下游供需测算数据，字段包含有效成分占比（单位%）、产能万吨/年、出厂价元/吨、出口量万吨等，部分研报附带合规性检测数据与专利授权信息。

## 这些特征在「部署与升级」这一环带来什么约束
农化制品研报包含结构化产能价格表格、纯文本政策条款及非结构化专利数据，部署时需配置多格式解析规则，适配不同数据类型的提取逻辑。月度监测数据与季度行业报告的高频更新节奏，要求升级环节支持增量同步，避免全量数据重处理占用系统资源。统一的字段单位（如万吨/年、元/吨）要求部署时配置单位标准化映射，防止检索结果出现单位混淆。离线部署场景下，本地数据源的同步延迟，需要在升级环节增加增量数据校验流程，确保数据一致性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 农化研报常包含多页产业链数据与长表格，长文档解析需要更长超时时间 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 单份农化深度研报通常不超过800MB，预留合理上限避免上传失败 |
| `maxContext` | `800–1200 字符` | 农化研报的核心指标与政策解读段落通常在该长度范围内，可覆盖关键检索信息 |
| `召回条数` | `前 8 条` | 农化行业数据多分散在不同研报章节，8条可覆盖完整产业链相关信息 |
| `相似度阈值` | `0.72–0.85` | 农化术语专业性强，该区间可过滤低相关结果，同时保留细分品类的关联数据 |
| `PARSE_CHUNK_SIZE` | `1500 字符` | 农化研报的表格与段落结合紧密，1500字符可保留完整数据单元，避免解析断裂 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：部署后登录界面提示“用户名或密码无效”，接口返回状态码401。原因：未正确配置环境变量`ADMIN_USERNAME`与`ADMIN_PASSWORD`，或部署时未加载.env配置文件。
- 现象：离线部署后上传农化研报无文本提取结果，日志显示`parse failed: no text extracted`。原因：离线环境未挂载官方解析依赖包，或未配置本地结构化解析模块的加载路径。
- 现象：Mac设备上使用Docker Desktop部署时，容器启动失败，报错“volume mount permission denied”。原因：Docker Desktop未授予文件系统访问权限，导致无法挂载本地研报数据目录。

## 怎么确认配好了
- 登录管理后台，验证`ADMIN_USERNAME`与`ADMIN_PASSWORD`的配置值与输入一致，确认登录流程可正常完成。
- 上传单份农化研报，查看解析任务状态为完成，提取的文本未出现关键数据断裂，确认解析配置生效。
- 使用其他设备访问免登录链接，确认页面可正常加载并发起检索请求，确认网络配置生效。
- 查看增量同步日志，确认仅处理新增数据源，无全量重跑的资源占用提示，确认更新配置生效。
