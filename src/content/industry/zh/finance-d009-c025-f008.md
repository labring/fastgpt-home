# 农商行研报检索的工具调用与插件

## 这个品类的数据长什么样
针对农商行的行业研报来源包括地方金融监管部门发布的区域运营监测报告、银行业协会发布的合规指引、区域涉农经济调研衍生的专项研报等。更新节奏随发布主体不同分为月度、季度及不定期三类。文档通常包含监管指标解读、县域存贷数据、合规风险提示、业务优化建议等模块，字段涵盖报告编号、发布机构、发布日期、核心指标数值、适用区域范围，单位多为万元、百分比、机构家数。

## 这些特征在「工具调用与插件」这一环带来什么约束
首先，研报更新周期的多样性要求工具调用的数据源同步配置支持灵活调整，避免固定周期导致数据滞后或冗余。其次，字段与单位的多样性要求工具调用需内置单位标准化解析逻辑，避免因指标单位混用引发参数错误。再者，文档多包含县域级地域限定内容，要求工具调用的检索过滤规则支持细粒度地域匹配，精准定位适配目标区域的研报。另外，部分研报包含高清县域地图、多页统计图表等多模态内容，要求工具调用的文件处理模块适配大体积多模态文件，同时需控制解析耗时以保障调用效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 农商行研报多为长文档且含多模态图表，600秒可覆盖绝大多数解析场景 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 部分区域专项研报包含高清县域地图、多页统计图表，1000 MB可满足常规文件体积需求 |
| `recall_top_k` | `前 8 条` | 农商行研报细分维度较多，过多召回结果会增加工具调用上下文压力，8条可覆盖核心匹配项 |
| `filter_region` | `按报告适用区域匹配` | 农商行研报多绑定特定县域或地市，按地域过滤可提升检索精准度 |
| `unit_normalization` | `自动转换为万元、百分比` | 研报内指标单位存在混用，标准化处理可避免工具调用时的参数解析错误 |
| `tool_call_trigger_threshold` | `0.75` | 农商行研报专业术语较多，该阈值可平衡召回精准度与调用触发效率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用工具时返回`InternalError.Algo.InvalidParameter: Multimodal file size is`相关报错。原因：未正确配置`UPLOAD_FILE_MAX_SIZE`参数，上传的研报多模态文件超过设置的最大体积阈值。
- 现象：工作流中工具调用模块的输出强制返回至对话界面，无法隐藏。原因：未开启`hide_tool_output`配置项，或配置时误将参数设为`false`，导致工具执行结果直接展示。
- 现象：输入文本为“分享”时，工具调用触发的关键词变为“分交”。原因：未配置`input_text_normalization`参数，未处理中文输入的形近字或编码异常，导致工具调用时的参数解析错误。

## 怎么确认配好了
- 上传一份符合农商行研报特征的多模态测试文件，检查解析任务是否在预设的超时时间内完成，无超时报错。
- 输入包含地域、业务关键词的测试问题，触发工具调用，核对召回结果的数量是否符合预设的召回条数，且过滤条件匹配预设的地域范围。
- 调用工具接口时，携带会话ID参数，检查连续两次调用是否共享同一上下文，未出现上下文重置的情况。
- 输入包含多单位术语的测试文本，检查工具调用时是否自动完成单位标准化，未出现参数解析异常。
