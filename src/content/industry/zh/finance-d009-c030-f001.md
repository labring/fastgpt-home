# 化妆品研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
化妆品研报数据主要来源于行业协会公开报告、品牌官方合规备案信息、第三方成分检测机构、主流电商平台销售监测数据及监管公示。更新节奏随品牌新品上线、季度销售周期及监管备案调整波动，无固定周期。单篇文档通常包含成分明细、功效验证数据、竞品对标信息、合规资质字段，其中成分字段多以质量占比为单位，包含备案编号、SKU标识、售价区间等标准化与非标准化混合字段。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多源数据接入需求要求接口支持多套鉴权协议适配，需配置独立的数据源密钥与调用频率限制。无固定更新节奏要求接口支持增量拉取标记，需传递时间戳参数实现增量同步。混合字段结构要求接口请求参数需支持自定义字段映射，将外部数据源字段转换为平台统一格式。成分单位的标准化校验要求接口新增参数校验规则，对质量占比类字段做格式合法性验证。电商监测类数据源的接口通常有QPS限制，需配置接口熔断与重试机制。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `datasource_auth_type` | `multi_key` | 适配多数据源鉴权需求，支持不同来源的API密钥配置 |
| `increment_sync_interval` | `300–1800 秒` | 匹配化妆品研报无固定更新周期的增量拉取节奏 |
| `field_mapping_rule` | `custom` | 适配混合字段结构，支持手动映射外部字段到平台标准字段 |
| `api_qps_limit` | `10–20` | 适配电商监测类数据源的常规QPS限制，避免触发调用封禁 |
| `field_format_check` | `enable` | 对成分占比类字段做格式校验，确保数据合法性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 适配长文档解析需求，化妆品研报单篇长度通常较高 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 接口调用返回`429 Too Many Requests`错误。原因是未配置合理的`api_qps_limit`参数，超出数据源接口的调用频率限制。
- 接口上传的图片无法正常加载。原因是未统一图片base64编码格式，或未配置`UPLOAD_FILE_MAX_SIZE`参数限制文件大小，导致部分大尺寸图片被截断。
- 增量同步后未获取到最新研报数据。原因是未正确传递时间戳参数，或`increment_sync_interval`配置与数据源更新节奏不匹配，导致增量拉取范围错误。

## 怎么确认配好了
- 调用测试接口，返回的鉴权结果与配置的数据源密钥一致，确认多源鉴权配置生效。
- 上传单篇化妆品研报文档，查看解析后的字段是否与配置的`field_mapping_rule`匹配，确认字段映射正确。
- 触发一次增量同步任务，对比同步前后的数据条数，确认增量拉取逻辑正常。
- 调用接口上传测试图片，查看返回的图片链接可正常访问，确认图片上传配置无误。
