# 化学制药研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
化学制药研报的数据来源为医药生物行业合规的公开研报数据库与行业资讯平台，为金融领域的行业研究、投资决策场景提供专业数据支撑，更新节奏随行业核心事件推进，如新药获批、临床试验关键节点更新时即时新增对应研报，常规品类综述类研报按固定周期更新。文档结构通常包含试验方案摘要、化合物参数模块、临床数据汇总、政策解读板块，字段包含化合物通用标识、临床试验分期、申报进度、关键试验数据项，部分数据项附带标准化计量单位，单篇核心技术类研报篇幅跨度较大。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
单篇核心技术类研报篇幅跨度较大，会对HTTP接口的请求超时时间、文档解析的分段长度提出更高要求，避免因内容过长导致解析失败或超时中断。专业字段如化合物标识、临床试验分期的标准化需求，要求接口的召回参数需支持专业术语精准匹配，同时外部系统对接时需配置字段映射规则，适配不同数据源的字段命名差异。更新节奏随行业事件动态调整，要求外部同步接口支持增量拉取模式，避免全量拉取带来的资源消耗。部分数据项附带标准化计量单位，要求接口返回时保留原始单位信息，不得擅自转换，确保外部系统可正确识别与展示。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 化学制药核心研报篇幅较长，需足够时间完成文本解析与结构化处理 |
| `recall_top_k` | `前 10–15 条` | 专业研报内容密度高，过多召回会引入无关信息，过少则无法覆盖核心技术内容 |
| `similarity_threshold` | `0.75–0.85` | 专业术语匹配需较高相似度门槛，避免低相关研报被纳入检索结果 |
| `api_request_timeout` | `900 秒` | 长文本解析、多轮检索及外部系统数据交互的总耗时较长，常规超时时间无法覆盖全流程 |
| `field_mapping_enable` | `开启` | 不同研报数据源的字段命名存在差异，需配置映射规则适配外部系统的数据格式要求 |
| `incremental_sync_interval` | `15 分钟` | 行业核心事件更新频率较高，短间隔同步可确保外部系统及时获取最新研报数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：通过HTTP接口对接外部系统时返回`SSL certificate problem`报错，或出现公网地址校验失败提示。原因：未在接口配置中禁用非信任SSL证书校验，本地部署实例常使用自签名证书，未匹配外部系统的访问要求。
- 现象：API返回的研报数据字段为空，如`compound_id`字段无有效内容。原因：未开启`field_mapping_enable`配置，未将数据源的原始字段映射为外部系统可识别的标准字段格式。
- 现象：HTTP接口请求超时，返回`504 Gateway Timeout`状态码。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`与`api_request_timeout`参数，长文本研报的解析与检索流程未完成即被中断。

## 怎么确认配好了
- 发起单次HTTP接口请求，传入化学制药专业术语作为检索关键词，核对返回结果的字段是否与外部系统的预期格式一致。
- 提交一篇长文本化学制药研报进行解析，确认接口返回的结构化数据完整，无解析失败或截断提示。
- 查看外部系统的同步日志，确认增量同步任务按预设间隔执行，无重复拉取或遗漏更新的记录。
- 调用API创建绑定研报检索知识库的智能体，确认智能体可正常返回基于研报的精准回答，无超时或空结果返回。
