# 化学制药研报检索的工具调用与插件

## 这个品类的数据长什么样
金融场景下的化学制药研报数据主要来源于金融机构投研数据库、药企公开研发文档、CDE审批公示文件、专业医药数据库及同行评议文献。更新节奏随事件触发，CDE审批公示实时更新，药企研发进度研报按季度发布。文档多为结构化与半结构化混合，包含分子活性参数、临床试验数据、合规性字段，字段含IC50值（单位nM）、给药剂量（mg/kg）、试验周期（周）、获批文号等专属医药指标。

## 这些特征在「工具调用与插件」这一环带来什么约束
金融场景下的化学制药研报专属字段与单位差异，要求工具调用时需配置字段映射规则，确保检索结果的数值可对比。实时更新的CDE审批数据，要求工具调用的知识库同步间隔需适配事件触发机制，设置按需同步触发。半结构化的试验表格与分子参数，要求关联插件需支持医药专业格式解析，避免数据提取缺失。多源数据的混合结构，要求工具调用的上下文窗口需适配长文档分段，避免关键试验数据被截断，满足投研场景的完整数据需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `知识库同步触发方式` | `事件触发+按需同步` | 适配金融投研对化学制药审批数据的实时性要求，及时更新研发进度数据 |
| `文档解析分段长度` | `800–1200 字符` | 化学制药研报多含长段试验数据，该分段可保留试验逻辑完整性，避免参数拆分断裂 |
| `召回字段白名单` | `IC50值、给药剂量、试验周期、获批文号` | 限定核心检索字段范围，减少无关数据干扰，匹配金融投研的核心分析需求 |
| `工具调用超时时间` | `300 秒` | 医药数据解析需处理复杂分子参数与多源数据整合，预留足够处理时长 |
| `相似度阈值` | `0.75–0.85` | 化学制药专业术语语义相似度较高，该阈值可过滤低匹配度的非专业内容 |
| `工作流工具调用嵌套层数` | `≤2 层` | 避免多层嵌套导致的上下文溢出，适配化学制药研报检索的分层调用逻辑 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用v4.8.12-alpha版本的API触发嵌套知识库工作流，返回结果为空值。原因是未配置`知识库关联触发权限`，工作流无法调用外部知识库的检索接口。
- 工具调用模块同时输出AI回复与执行分支内容，无法仅保留其一。原因是未关闭`工具调用日志打印开关`，且未在工作流中设置分支执行的条件判断逻辑。
- iframe嵌入应用后，部分浏览器无法显示图像与用户头像。原因是未配置`应用资源跨域白名单`，浏览器的跨域资源共享策略拦截了静态资源加载。

## 怎么确认配好了
- 手动触发一次研报检索请求，检查返回结果的字段是否包含预设的核心参数，确认字段映射配置生效。
- 提交一份包含分子试验数据的测试文档，检查解析后的分段是否保留试验逻辑完整性，确认文档解析配置合理。
- 查看工作流的日志输出，确认仅输出工具调用的必要结果，无冗余的AI回复内容，确认日志打印配置正确。
- 更换不同主流浏览器嵌入应用，检查图像与用户头像是否正常加载，确认跨域配置覆盖常用浏览器的域名规则。
