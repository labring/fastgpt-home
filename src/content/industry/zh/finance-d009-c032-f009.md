# 化学原料研报检索的引用来源与溯源

## 这个品类的数据长什么样
化学原料研报的数据主要来自行业公开监测数据库、上市化工企业定期报告、专业化工细分领域行业期刊及海关进出口数据。更新节奏因数据类型存在差异：现货价格类数据日更，行业供需周报周更，年度深度研报按季度更新。文档结构通常包含原料牌号、CAS号、理化指标、供需数据、价格走势及下游应用占比，核心字段包含纯度百分比、库存量（万吨）、出厂价（元/吨）等，单位随数据维度存在细分差异。

## 这些特征在「引用来源与溯源」这一环带来什么约束
化学原料研报的唯一标识为CAS号，需优先匹配该字段，仅以关键词作为辅助匹配条件，避免同物异名导致的溯源偏差。不同数据源的单位格式存在差异，如价格同时存在元/吨、元/千克，库存量同时存在万吨、吨，需统一单位后才能完成关联引用。研报更新周期跨度大，从日更到季度更新不等，需强制标注数据采集时间戳，避免引用过时内容。部分文档仅标注来源机构未附直接链接，需配置字段提取优先级以获取可溯源的标识信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | 前8–12条 | 化学原料细分品类较多，需覆盖不同机构的监测数据，避免单源偏差 |
| `相似度阈值` | 0.75–0.85 | 化学原料术语专业性强，需平衡召回精准度与覆盖度，避免遗漏细分指标数据 |
| `PARSE_FIELD_PRIORITY` | CAS号 > 原料牌号 > 出厂价格 | 化学原料的唯一标识为CAS号，优先提取该字段作为溯源核心依据 |
| `SOURCE_TIMESTAMP_REQUIRE` | 开启 | 不同研报更新周期差异大，需强制标注数据采集时间以避免引用过时内容 |
| `UNIT_NORMALIZATION_SWITCH` | 开启 | 化学原料数据包含多种单位格式，需统一单位后才能完成关联引用 |
| `MAX_REFERENCE_LENGTH` | 1500–2000 字符 | 化学原料研报包含大量理化数据，需限制单条引用长度以保证上下文清晰 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 未将`PARSE_FIELD_PRIORITY`配置为CAS号优先，导致引用时匹配到相似原料牌号，无法精准匹配目标原料，出现返回内容与提问无关的现象。原因是未利用化学原料的唯一标识作为溯源核心，仅依赖关键词匹配导致偏差。
- 未开启`UNIT_NORMALIZATION_SWITCH`，引用的研报数据单位未统一，出现引用字段数值混乱的报错。原因是化学原料数据存在元/吨、元/千克等多种单位格式，未做归一化处理导致关联失败。
- 配置`MATCH_LANGUAGE`为仅中文，输入中文提问后未引用包含英文CAS号的研报文献。原因是未覆盖英文术语匹配，无法关联知识库中的英文标识类研报内容。

## 怎么确认配好了
- 上传1份包含CAS号的化学原料研报文档，查看知识库解析结果中是否优先提取了CAS号字段。
- 发起包含具体原料牌号的提问，检查返回结果中是否标注了每条引用内容的采集时间与来源机构。
- 测试包含不同单位的数据源，查看生成内容中的数值是否统一为预设单位。
- 发起包含英文CAS号的中文提问，检查是否能匹配到相关研报的引用内容。
