# 化纤研报检索的工具调用与插件

## 这个品类的数据长什么样
化纤研报的数据来源包括国内化纤行业协会公开统计数据、券商化工行业研究报告、合规大宗商品交易平台现货报价数据。更新节奏分为三类：现货价格数据每日更新，行业供需月报每月发布，深度研报按研究团队排期发布。文档结构包含行业综述、供需分析、价格走势、下游需求分析等部分，部分深度研报附带Excel格式的原始数据表附件，字段包括产业链上下游价格、月度产量、产能规模等，单位多为元/吨、万吨。

## 这些特征在「工具调用与插件」这一环带来什么约束
化纤研报包含每日更新的实时现货数据、月度结构化供需报表与非结构化分析文本，工具调用需同时支持实时数据拉取与多格式文档解析。由于化纤产业链上下游关联度高，工具需支持跨数据源联动，例如将上游原料价格与下游细分品类需求数据结合。细分品类较多，工具需支持按品类过滤召回结果，避免无关数据混入。此外，深度研报附带的Excel附件包含多组行业数值，插件需具备结构化数据提取能力，以完整获取研报核心数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 化纤研报附带的Excel附件通常包含多组行业数据表，解析耗时较长，默认超时不足以完成完整解析 |
| `RECALL_CHUNK_SIZE` | 800–1200 字符 | 化纤研报的供需分析段落通常较长，分段过短会割裂数据关联，过长会超出上下文窗口 |
| `TOOL_CALL_MAX_RETRIES` | 3 次 | 大宗商品数据接口可能因网络波动出现请求失败，重试次数不足会导致工具调用失败 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 部分深度研报附带的产业链数据库附件体积较大，默认限制无法覆盖完整数据上传 |
| `SIMILARITY_THRESHOLD` | 0.75–0.85 | 化纤行业术语专业性强，需要较高的相似度阈值过滤无关召回结果，避免非化纤品类的研报被误召回 |
| `TOOL_ALLOWED_DOMAINS` | 国内化纤行业协会接口、合规大宗商品交易平台域名 | 限制工具调用的数据源范围，避免调用非合规接口获取数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用工具时返回`413 Request Entity Too Large`错误码。原因：未调整`UPLOAD_FILE_MAX_SIZE`配置，上传的化纤研报Excel附件超出默认限制。
- 现象：调用工具后无返回结果，无法在系统日志中找到调用记录。原因：未开启`TOOL_CALL_LOG_ENABLE`配置，未启用工具调用日志记录，无法排查OneAPI类工具的调用失败问题。
- 现象：发布的免登录应用调用工具时，无法获取用户标识。原因：未在工具调用配置中开启`PASS_USER_ID_TO_TOOL`参数，导致工具无法接收用户ID信息。

## 怎么确认配好了
- 上传单篇体积超过500MB的化纤研报Excel附件，检查上传进度条正常完成，无文件大小超限提示。
- 发起一次化纤研报检索请求，查看系统日志，确认能看到工具调用记录与结构化数据提取结果。
- 调用工具接口时携带测试用户ID，检查工具端能正常接收并识别该用户标识。
- 在Pad端模拟发起知识库问答请求，确认接口能正常返回检索到的化纤研报数据，无跨域报错。
