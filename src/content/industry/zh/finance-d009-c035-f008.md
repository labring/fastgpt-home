# 医美研报检索的工具调用与插件

## 这个品类的数据长什么样
医美研报数据主要来源于行业协会合规备案文档、第三方医美数据机构的市场调研、医美耗材厂商的技术白皮书，以及合规医美机构的季度运营披露，同时包含医美监管部门发布的行业合规指引摘录。数据更新节奏分为月度、季度与年度：月度更新行业合规动态与单次项目价格监测，季度更新细分品类（如注射类、手术类）的市场参数，年度发布行业整体发展白皮书。文档结构包含执行摘要、细分品类参数表、合规要求说明、典型案例分析四个核心部分，特有字段包括「合规备案编号」「单次操作剂量（单位：单位/毫升）」「客单价（单位：元/人次）」「疗程周期（单位：周）」，且所有数据均附带来源标注字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
医美研报的多源分散特性要求工具调用插件支持多数据源聚合解析，需适配不同格式的备案文档、调研报表与技术白皮书，避免格式解析失败导致的字段提取错误。特有专业字段与单位要求工具调用时自动匹配参数单位，防止因剂量、价格单位不统一导致的检索偏差，例如将「单位」与「毫升」的关联关系自动映射。不同更新节奏的数据需要插件配置定时增量拉取规则，避免全量拉取占用过多服务器资源，同时需处理数据版本差异带来的字段变更问题。长文档结构则要求工具调用环节支持分段解析与上下文保留，确保专业字段的完整匹配，避免因上下文截断导致的参数识别错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chatId` | 必传，格式为`医美研报检索-YYYYMMDD` | 用于区分不同会话的研报检索请求，匹配后台日志的使用者标识 |
| `globalVariables` | 配置为`{"medicalReportScope": "合规备案数据"}` | 绑定医美研报专属检索维度，解决全局变量未生效问题 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 医美研报单份文档长度较长，需延长解析超时时间 |
| `recallTopK` | `前 8 条` | 医美研报细分字段较多，需召回足够多的候选结果以覆盖专业参数 |
| `similarityThreshold` | `0.75–0.85` | 过滤低匹配度的非医美专业数据，避免无关结果混入 |
| `streamMode` | `开启` | 适配仅支持stream模式的大模型，避免调用失败 |
| `API_KEY_AUTH` | `开启校验` | 防止未授权调用，匹配`unAuthApiKey`错误的防护要求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用API时传入`chatId`参数后，后台日志未显示对应标识。原因：未在FastGPT后台开启会话标识绑定配置，或传入格式不符合要求。
- 现象：工具调用中更新全局变量后，检索结果未匹配新的变量值。原因：未在插件配置中启用全局变量同步，或变量更新时机晚于检索触发。
- 现象：调用API返回`{"code":514,"statusText":"unAuthApiKey"}`错误。原因：未配置合法的API密钥校验，或密钥权限未绑定医美研报检索插件。

## 怎么确认配好了
- 发起测试请求，查看后台对话日志，确认`chatId`字段已正确显示在请求参数中。
- 修改全局变量值，发起检索请求，核对返回结果是否匹配新的变量配置。
- 调用API并检查返回状态码，确认未出现`unAuthApiKey`相关错误。
- 调用仅支持stream的大模型，确认返回结果为流式分段输出。
