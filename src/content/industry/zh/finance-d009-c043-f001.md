# 商业地产研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
商业地产研报数据主要来源于行业协会公开报告、商业项目运营方披露的运营数据、商圈调研机构的实地采集信息。数据更新节奏分为两类：基础租金、客流等运营指标按月度更新，专项研报全文不定期发布。文档结构包含商圈区位标识、租金单价、空置率、入驻品牌梯队、租户坪效等字段，其中租金单价单位为元/平方米/天，空置率以百分比为计量标准，部分研报会附带项目平面图的关联链接。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
商业地产研报的多维度数据特征，对HTTP接口与外部系统集成带来多项约束。按月度更新的运营指标，需要接口支持增量拉取逻辑，减少全量数据传输的资源消耗。专项研报的非固定发布节奏，要求接口支持按需触发拉取，适配临时调用需求。多字段的细分维度，需要接口提供按商圈ID、项目名称等多参数筛选的能力，同时返回标准化的字段结构。部分研报附带的图片关联链接，要求接口保留可直接访问的外链格式，适配第三方系统的图片展示场景。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `HTTP_REQUEST_TIMEOUT` | 300–600 秒 | 商业地产研报部分内容包含多维度运营数据，接口拉取时需预留足够响应时间，避免因超时中断拉取流程。 |
| `RECALL_NUMBER` | 前8–12条 | 商业地产研报的细分维度较多，过多召回结果会增加第三方系统展示压力，过少则无法覆盖核心信息。 |
| `PARSE_COOKIE_ENABLE` | 开启 | 部分商业地产数据平台的接口需通过Set-Cookie字段维持会话，开启该配置可自动处理会话关联逻辑。 |
| `API_KEY_PERMISSION` | 仅开放研报检索权限 | 避免应用密钥被滥用，仅授予第三方系统所需的研报检索接口访问权限。 |
| `IMAGE_LINK_EXPIRE` | 24–72 小时 | 商业地产研报附带的项目平面图链接需保持短期有效，适配第三方系统的展示调用周期。 |
| `RESPONSE_FIELD_FILTER` | 保留租金单价、空置率、外链地址 | 过滤非必要字段，减少接口返回数据量，提升外部系统集成效率。 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用`/api/v1/app/create`接口返回403 Forbidden状态码。原因：未配置`API_KEY_PERMISSION`开放应用创建权限，或密钥未绑定对应接口的访问权限。
- 现象：HTTP请求模块无法解析响应中的Set-Cookie字段，后续调用接口返回会话过期。原因：未开启`PARSE_COOKIE_ENABLE`配置，导致会话信息未被自动维护。
- 现象：第三方系统中无法展示知识库上传的研报图片，链接返回404错误。原因：未配置`IMAGE_LINK_EXPIRE`延长有效时间，或未保留原始外链地址，导致图片链接过期或格式错误。

## 怎么确认配好了
- 调用应用创建相关接口，检查返回的应用标识与密钥是否正常生成，确认权限配置生效。
- 发送包含Set-Cookie字段的测试请求，检查接口返回的会话信息是否被自动存储并在后续请求中复用。
- 调用研报检索接口，检查返回结果中是否包含符合业务需求的字段与图片外链，确认字段过滤与映射配置正确。
- 模拟第三方系统调用接口，检查响应数据的计量单位与格式是否符合预期，确认数据标准化配置生效。
