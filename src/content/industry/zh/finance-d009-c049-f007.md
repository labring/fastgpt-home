# 基建工程研报检索的工作流编排

## 这个品类的数据长什么样
基建工程研报及关联数据来源包括住建部门官方项目备案公示、交通水利行业招标公告、券商建筑行业研报、工程咨询专项报告。官方公示文档多为结构化格式，包含项目编号、投资金额（单位：万元）、建设周期、承建单位、所在区域等字段，随项目推进实时更新。券商研报为长文本格式，单篇字数差异较大，建议按自有样本统计或实测后再确定，包含项目概况、投资测算、进度节点、风险提示内容，按季度、月度发布。工程咨询专项报告按需更新，结构包含详细的施工方案与成本拆解。

## 这些特征在「工作流编排」这一环带来什么约束
官方公示的结构化文档包含固定字段，要求工作流支持结构化数据提取与非结构化文本解析的混合处理，需配置对应解析规则适配表格与文本的不同格式。长文本研报单篇篇幅较大，需限制单段拆分长度，避免超出模型上下文窗口，同时需设置合理的召回分片策略。不同来源数据的更新频率差异明显，需为不同数据源配置差异化触发规则，官方项目数据支持实时触发，券商研报适配定时调度。字段自带固定单位，工作流中需保留单位关联逻辑，避免跨接口调用时出现单位转换错误。项目编号作为唯一标识，需作为核心变量贯穿各环节，确保检索定位准确。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_SEGMENT_LENGTH` | `800–1200 字符` | 基建工程研报单段技术细节与数据说明较多，该长度可保证单段语义完整，适配多数模型上下文窗口 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 基建工程数据专业性强，较高阈值可避免无关项目混入，保证检索结果与查询意图匹配 |
| `RECALL_TOP_K` | `前 8 条` | 基建工程研报涉及项目概况、投资、进度等多维度信息，8条可覆盖核心检索需求 |
| `WORKFLOW_TRIGGER_TYPE` | `混合触发` | 官方项目数据需实时响应查询，券商研报可按周定时更新后触发检索，适配不同数据源更新节奏 |
| `EXCEL_PARSE_COLUMN_MAPPING` | `按表头自动匹配` | 基建工程官方公示的Excel表格表头格式固定，自动匹配可减少手动配置工作量 |
| `EXTERNAL_API_TIMEOUT` | `600 秒` | 基建工程多源数据检索可能涉及跨库查询，600秒可保证完整获取全量关联数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 读取上传的Excel文件后返回空字段。原因是未配置`EXCEL_PARSE_COLUMN_MAPPING`的匹配规则，或表头格式与预设映射不匹配，导致解析引擎无法识别有效列。
- 调用外部接口时无法传递动态token值。原因是未将token配置为工作流的全局变量或节点输入参数，未在外部接口调用节点中绑定对应变量，导致每次调用使用固定值或空值。
- 本地调试正常，部署后仅执行第一个对话节点。原因是未配置工作流的全局上下文传递规则，或节点间的变量传递链路中断，导致后续节点无法获取前序节点的输出结果。

## 怎么确认配好了
- 上传一份基建工程官方Excel公示文件，运行解析节点，核对提取的字段是否包含预设的核心字段，调整对应配置直至匹配正确。
- 配置动态变量（如token），在外部接口调用节点中绑定该变量，发起测试调用，查看接口返回结果是否包含预期的动态参数关联数据。
- 分别触发实时数据源与定时数据源的工作流，核对不同来源的检索结果是否符合更新节奏与内容要求，调整触发规则的配置细节。
- 部署工作流并通过外部平台发起多轮对话，核对每个节点的输出是否按链路传递，确认上下文传递正常。
