# 多元金融研报检索的多轮对话与提示词

## 这个品类的数据长什么样
多元金融研报的数据主要来自券商研究所公开报告、行业协会统计文档、第三方金融信息服务机构的细分赛道研报。更新节奏覆盖每日更新的行业动态研报、每周更新的大类资产配置报告、季度更新的年度策略研报。文档结构包含标题、发布机构、发布时间、核心观点、结构化数据表格、风险提示等字段，涉及的单位包括亿元、百分比、评级等级（买入/增持/中性）等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
研报篇幅普遍较长，单篇内容可达数万字符，多轮对话需限制上下文长度避免溢出，同时需保留前置提问关联的研报发布时间、机构等关键信息。细分赛道覆盖广，研报内容专业性强，提示词需明确指定提取特定字段，避免系统混淆不同赛道的研报数据。更新频率较高，提示词需要求调用最新召回的研报数据，避免返回过时内容。部分研报包含嵌入的图表与BLOB格式附件，多轮对话中需支持用户追问附件中的结构化数据，需配置对应的上下文关联逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 多元金融研报单篇篇幅较长，需保留多轮对话中研报的发布时间、机构等关键上下文，避免上下文溢出丢失核心信息 |
| `recallTopK` | `前8–12 条` | 多元金融研报覆盖细分赛道多，过多召回会导致上下文过载，过少则无法覆盖用户所需的细分领域研报内容 |
| `similarityThreshold` | `0.75–0.85` | 研报内容专业性强，需保证召回结果与用户提问的语义匹配度，避免引入无关的行业泛文 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 研报可能包含大量图表与结构化数据，解析耗时较长，需预留足够的解析时间 |
| `speechRecognitionModel` | `平台内置适配金融领域的语音转文字模型` | 针对研报中的专业术语较多，需使用适配金融领域的语音识别模型，提升转写准确率 |
| `enablePublicBlobAccess` | `开启` | 支持用户下载通过HTTP节点获取的BLOB格式研报附件，满足用户对研报原始附件的获取需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：开启语音输入功能后，通过语音发起的提问无文字转化结果，对话框仅显示空白或占位符。原因：未正确配置`speechRecognitionModel`参数，或未启用语音识别功能开关。
- 现象：多轮对话中后续提问无法关联前置提及的研报信息。原因：`maxContext`取值过小，导致前置研报的关键上下文被截断，系统无法识别关联关系。
- 现象：通过HTTP节点获取的BLOB格式研报附件无法在对话框中点击下载。原因：未开启`enablePublicBlobAccess`配置，或未为BLOB对象配置有效的访问有效期。

## 怎么确认配好了
- 发起一轮包含多元金融细分赛道关键词的提问，再发起一轮关联该研报的追问，确认系统能正确关联前置提问的研报信息。
- 进入语音输入配置界面，确认`speechRecognitionModel`参数已完成配置并启用，测试语音输入转写效果。
- 生成或上传BLOB格式的研报附件，点击附件链接确认可正常下载，验证`enablePublicBlobAccess`配置生效。
- 调整`similarityThreshold`参数后，测试提问与召回研报的匹配度，确认召回结果符合预期。
