# 多元金融研报检索的工具调用与插件

## 这个品类的数据长什么样
多元金融研报的数据主要来自券商研究所、第三方金融数据服务商及行业自律组织的公开披露内容。更新节奏以每日新增研报为主，存量研报按季度完成补全与校验。文档结构通常包含标题、发布机构、发布日期、核心逻辑、行业数据、个股评级、附录图表等模块。字段包含标准化的评级标签、以元为单位的目标价、以亿元为单位的营收预测数据，部分研报还包含细分赛道的专项指标与政策解读内容。

## 这些特征在「工具调用与插件」这一环带来什么约束
多元金融研报的多源分散特性要求工具调用插件需支持对接多个数据源的API接口，避免单一数据源的信息覆盖不全。高频更新的需求要求插件需配置定时同步机制，确保知识库能及时获取最新研报内容。单篇研报篇幅较长且包含专业图表与公式，工具调用的分段解析参数需适配长文本处理逻辑。专属字段与单位要求插件在数据提取时需校验字段格式，避免出现单位不匹配的问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 多元金融研报单篇字数较多，且包含专业逻辑与图表说明，分段过短会割裂论证链条，过长会超出上下文窗口限制 |
| `召回条数` | 前8–12条 | 研报内容垂直且专业，过多召回会引入无关信息，过少无法覆盖核心观点与数据支撑内容 |
| `相似度阈值` | 0.75–0.85 | 专业术语匹配要求较高，阈值过低会引入低相关内容，过高会遗漏细分领域的精准研报 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 单篇研报包含多页图表与表格，解析耗时较长，默认超时时长无法完成完整解析 |
| `定时同步间隔` | 24 小时 | 新研报每日发布，定时同步可保证知识库内容的时效性 |
| `API请求重试次数` | 3 次 | 第三方金融数据源接口偶发波动，重试可降低调用失败率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：插件调用返回`403 Forbidden`错误，原因：未配置内部端口访问控制策略，暴露公网端口未添加白名单，导致接口被未授权访问拦截。
- 现象：知识库召回结果中缺少`发布机构`字段，原因：未开启研报元数据提取配置，工具调用时未指定提取专属字段的规则。
- 现象：批量调用curl指令执行后无响应，原因：未设置`Content-Type: application/json`请求头，或请求体格式不符合API规范。

## 怎么确认配好了
- 上传单篇多元金融研报文件，查看解析后的分段内容，确认分段长度符合配置值。
- 发起工具调用请求，查看返回结果的字段，确认包含`目标价`、`发布机构`等专属字段。
- 查看知识库历史调用日志，确认定时同步任务按配置的`定时同步间隔`执行。
- 使用curl指令发起测试调用，确认返回状态码为`200 OK`且结果符合预期。
