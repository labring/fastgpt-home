# 多元金融研报检索的部署与升级

## 这个品类的数据长什么样
多元金融研报的来源包括行业自律组织发布的合规报告、持牌机构公开披露的业务白皮书、第三方金融信息服务商的细分赛道调研文档。更新节奏为季度级行业动态更新、月度级机构经营数据更新。单篇文档长度跨度较大，结构包含业务板块拆解、监管政策解读、核心经营指标、市场规模测算等字段，单位多为亿元、家数等金融统计单位。文档中常包含结构化的业务流程说明、监管合规要求细则，部分文档附带机构内部的业务测算模型片段。

## 这些特征在「部署与升级」这一环带来什么约束
文档长度跨度大且包含长文本片段，要求部署时调整文件解析的超时阈值与分段长度参数，避免长文档解析失败或截断关键业务内容。多字段的结构化金融数据特征，要求配置适配结构化字段的召回与重排规则，提升精准匹配度。季度、月度的分层更新节奏，要求升级时配置增量同步任务，减少全量更新的资源消耗。多来源的数据格式差异，要求部署阶段配置针对性的文档解析模板，兼容不同机构发布的文档排版与结构。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ------ | -------- | ------------ |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 多元金融研报常包含长文本与复杂表格，较长的超时可避免解析中断 |
| `maxContext` | `8000–12000 字符` | 研报文档长度跨度大，充足的上下文可保留完整的业务逻辑与指标关联 |
| `召回条数` | `前 8–10 条` | 结构化字段占比高，过多召回会引入无关的非结构化内容 |
| `相似度阈值` | `0.72–0.78` | 金融数据语义一致性要求较高，过低会引入无关文档，过高会遗漏相关内容 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单篇研报可能包含多页图表与长文本，较大的上传限制可完整导入文档 |
| `重排返回条数` | `前 3–5 条` | 聚焦核心业务相关的检索结果，提升回答精准度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：部署后调用检索接口返回`504 Gateway Timeout`错误，原因是未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，长文本研报的解析过程超出默认超时阈值，导致代理链路中断。
- 现象：模型渠道测试显示连接失败，但服务器端大模型接口可正常访问，原因是未正确配置`AIproxy`的转发规则，未将本地大模型的访问地址与端口映射到FastGPT的指定调用路径。
- 现象：调用API返回的引用文献细节字段为空，原因是未开启检索结果的来源记录配置，或召回条数设置过低，未匹配到可关联的研报文档。

## 怎么确认配好了
- 上传一份典型的多元金融研报文档，检查解析后的文本是否完整保留了业务板块、指标字段，无明显截断或乱码。
- 运行一次测试检索，核对召回结果的数量与相似度符合预设配置，调整相关参数至符合业务需求的范围。
- 调用发布后的API接口，验证返回结果包含模型回答与关联的文献来源细节，确认接口参数配置正确。
- 配置增量同步任务后，查看数据同步日志，确认仅更新了新增或修改后的研报文档，未触发全量同步。
