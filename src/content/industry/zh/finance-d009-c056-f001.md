# 家居用品研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
家居用品研报的数据来源主要为国内券商轻工制造行业研报、国内家居行业公开统计报告、头部家居品牌供应链披露信息。更新节奏为每周更新行业渠道动态，每月更新细分品类产销数据，季度发布全行业趋势研报。文档结构包含行业整体营收规模、细分品类出货量、原材料成本单价、线上渠道营收总额、头部品牌营收总额等字段，单位分别为亿元、万件、元/千克、万元、亿元，单篇研报内容长度差异较大，建议按自有样本统计或实测后再定。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
家居用品研报的数据来源分散，需对接多个外部数据源接口，因此HTTP接口需支持多源数据聚合，并处理不同数据源的格式差异。不同数据类型的更新节奏不同，需配置差异化的定时拉取参数，避免重复拉取或漏更。单篇研报内容较长，接口需支持分页查询或上下文长度限制，避免传输过载。字段单位存在潜在差异，接口需内置单位转换逻辑，保证数据一致性。多维度字段的筛选需求，要求接口支持按细分品类、营收规模等条件进行精准查询。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `externalDataSourceSyncInterval` | 7天、30天、90天（分数据类型配置） | 匹配家居用品研报的周度动态、月度产销、季度趋势的更新节奏 |
| `maxContext` | 8000–12000 字符 | 适配单篇家居用品研报的平均内容长度，避免上下文溢出 |
| `retrieveTopK` | 前8–12条 | 覆盖细分品类研报的常规召回量，保证结果覆盖度 |
| `httpRequestTimeout` | 30 秒 | 适配多源数据聚合的接口响应时长，避免超时失败 |
| `VAR_PARSE_STYLE` | `{{}}` | 适配家居用品研报中的变量引用格式，兼容V4.8.18-FIX2及以上版本的修复逻辑 |
| `externalDataSourceAuthType` | `api_key` | 匹配多数公开家居行业研报数据源的鉴权方式 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部研报接口返回`403 Forbidden`状态码，提示令牌无权使用指定模型。原因：未在外部系统配置中绑定对应模型的权限令牌，或令牌未添加家居用品研报场景所需的模型权限。
- 现象：HTTP节点中引用研报字段时返回空值，或解析结果格式不符合预期。原因：未配置变量解析格式为`{{}}`，未适配V4.8.18-FIX2及以上版本的修复逻辑。
- 现象：在系统界面中无法选择已通过openapi配置的模型。原因：未正确配置外部数据源的鉴权参数，或模型同步间隔未触发列表刷新。

## 怎么确认配好了
- 调用配置的外部数据源接口，返回的结果包含家居用品研报的核心字段，核对字段单位与预设的转换规则匹配。
- 查看定时同步任务的运行日志，确认周度动态数据、月度产销数据、季度趋势研报的同步任务按配置的时间间隔正常执行。
- 在HTTP节点中测试`{{}}`格式的变量引用，确认可以正确解析为研报中的对应内容。
- 发起模型调用请求，确认返回的响应无`403 Forbidden`类权限报错，且结果与家居用品研报主题匹配。
