# 家居用品研报检索的工作流编排

## 这个品类的数据长什么样
家居用品研报的数据来源包括券商轻工制造赛道研究报告、家居行业协会公开调研资料、头部家居企业季度经营披露文档。数据更新随行业季度财报、大型家居展会、相关政策出台的节点发布补充或更新版本。单篇文档包含行业整体概况、细分品类产销跟踪、头部企业动态、政策影响分析四个核心模块。文档包含的字段包括细分品类名称、出货量、终端销售金额、报告发布机构、发布日期，其中出货量采用实物单位计量，涵盖件、套、平方米等不同细分维度，终端销售金额以货币单位计量。

## 这些特征在「工作流编排」这一环带来什么约束
多源数据来源的差异带来解析兼容性约束，不同来源的研报格式涵盖带格式PDF、网页、Excel、结构化文档等类型，需配置多格式解析节点与专属字段映射规则。非固定周期的更新节奏带来调度约束，无法依赖固定定时任务，需支持自定义事件触发与定时触发结合的调度模式。长文档与多模块的结构带来分段处理约束，需按文档模块拆分内容，避免上下文溢出。字段单位与命名的差异带来标准化约束，需配置字段归一化节点，统一不同数据源的字段格式与计量标准。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 家居用品研报多为篇幅较长的分析文档，300秒可覆盖多数单篇文档的解析需求 |
| `分段长度` | `800–1200 字符` | 家居用品研报的分析段落语义连贯，该区间可保证单段内容完整，同时适配知识库上下文窗口限制 |
| `召回条数` | `前 8 条` | 家居用品研报的分析模块较多，该数量可覆盖完整分析逻辑，同时避免冗余信息干扰 |
| `相似度阈值` | `0.70–0.80` | 家居用品研报内容专业性较强，该阈值可过滤低相关性检索结果，保留有效信息 |
| `API_MAX_CONCURRENCY` | `10–15 并发` | 家居用品研报的检索请求多为批量查询，该区间可保证接口稳定性，适配多数调用场景 |
| `字段映射规则` | `按数据源预设映射表自动匹配` | 不同数据源的字段命名与单位存在差异，预设映射表可减少手动配置成本，保证字段标准化 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用工作流API时返回`429 Too Many Requests`状态码，或接口响应延迟显著升高。原因：未根据家居用品研报的批量检索负载配置合理的并发阈值，导致节点资源无法承载请求量。
- 现象：在知识库搜索节点中选择引用变量时，下拉菜单无可选内容。原因：未在工作流中提前定义全局上下文变量，或变量的数据类型与搜索节点的参数校验规则不匹配。
- 现象：数据库连接节点的端口号输入框无法输入有效内容。原因：当前使用的FastGPT版本存在数据库节点的配置兼容问题，或未开启节点的高级配置开关。

## 怎么确认配好了
- 触发一次测试同步，查看多源数据源的解析结果是否完整，字段名称与计量标准是否统一。
- 发起单次检索请求，核对返回的研报片段是否与目标家居细分品类的关键词匹配，召回数量符合预设配置。
- 调用API接口，监控并发请求的响应状态，确认未出现限流类报错。
- 检查数据库连接节点的配置，确认端口号、访问地址等信息可正常保存并通过连通性测试。
