# 小金属研报检索的工作流编排

## 这个品类的数据长什么样
小金属研报数据主要来自中国有色金属工业协会小金属分会月度统计、券商有色行业研究报告、专业现货资讯平台。更新节奏分三类：现货价格与库存数据每日更新，行业供需统计按周或月度发布，券商研报随政策变动、供需拐点实时更新。单篇研报文档结构包含核心供需逻辑、量化指标、成本测算、下游应用分析，字段包含品种名称、交易市场、价格单位（元/吨）、库存单位（吨）等，部分海外研报会附带美元计价的换算数据。

## 这些特征在「工作流编排」这一环带来什么约束
小金属研报的多来源、多更新节奏与差异化格式，会对工作流编排带来多重约束。每日更新的现货价格与库存数据，需要工作流配置定时触发节点，避免调用过时数据。不同数据源的单位差异，如国内用元/吨、海外用美元/吨，需要在工作流中加入数据标准化节点统一字段格式。单篇深度研报可能超过万字，需要配置分段召回的阈值，避免超出模型上下文窗口。细分品种覆盖锂、钴、稀土等多个品类，工作流需要支持按品种标签过滤召回结果，减少无关数据干扰。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发周期` | 每日 00:00、12:00 各触发一次 | 匹配小金属现货数据每日更新的节奏，覆盖早间与晚间的行情变动 |
| `召回条数` | 前 8 条 | 平衡研报信息丰富度与模型上下文窗口占用，避免单轮调用过载 |
| `相似度阈值` | 0.75–0.85 | 过滤低相关的研报内容，聚焦小金属品种的核心供需逻辑 |
| `maxContext` | 8000–12000 字符 | 适配多数小金属研报分段后的长度，避免超出基础大模型的上下文限制 |
| `数据标准化开关` | 开启 | 统一不同数据源的价格、库存单位，消除格式差异带来的识别误差 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 适配长文档解析的耗时，避免深度研报解析超时失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流调用后返回结果延迟超过10秒，或出现`ETIMEDOUT`错误。原因：未配置合理的`PARSE_FILE_TIMEOUT_SECONDS`参数，长文档解析超时未触发重试机制。
- 现象：调用工作流时返回`Key is error. You need to use the app key rather than the account key`报错。原因：调用接口时使用了账号密钥，未使用应用密钥，未正确配置工作流的调用凭证。
- 现象：工作流编辑界面中可选择的全局变量不足，仅显示两个预设项。原因：使用了4.9.10版本的界面，该版本对全局变量的配置入口进行了调整，需进入「应用设置-全局变量」页面添加自定义变量。

## 怎么确认配好了
- 触发一次工作流，查看返回结果的研报品种是否与预设的小金属标签一致，确认过滤逻辑生效。
- 检查工作流的定时触发日志，确认按设定的周期自动运行，无遗漏触发记录。
- 调用工作流接口时，携带正确的应用密钥，验证无密钥错误提示。
- 查看解析后的研报数据字段，确认价格、库存等单位已统一为预设格式，无格式混乱情况。
