# 工业金属研报检索的工作流编排

## 这个品类的数据长什么样
工业金属研报的数据来源包含行业权威统计机构、大宗商品期货交易所、第三方咨询机构及产业链企业公开报告。数据更新节奏分多档：现货行情每日盘后更新，期货主力合约价格随交易时段实时推送，月度供需平衡表、季度产业链分析报告按月/季发布，年度深度研报按季度更新。文档结构通常包含行情数据表、供需平衡表、政策解读、上下游关联分析四个核心模块，字段包含产品名称、交易场所、价格（单位多为美元/吨或元/吨）、库存（单位万吨）、产量（单位万吨）、研报发布机构及评级等。

## 这些特征在「工作流编排」这一环带来什么约束
多频次更新节奏要求工作流需配置分层定时触发节点，区分日度实时数据、月度报告的拉取时机。多单位、多字段的格式特征，要求工作流中嵌入标准化数据清洗节点，完成单位转换、字段映射等预处理。长文档结构则要求设置合理的分段召回阈值，避免单段内容超出模型上下文窗口。行业数据的强关联性，要求工作流支持多数据源关联查询，将不同工业金属品类的行情数据联动调用，提升分析维度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 适配工业金属研报中行情表格、分析段落的常规长度，避免单段内容超出模型上下文限制 |
| `召回条数` | 前 6–8 条 | 工业金属研报数据条目较多，过多召回会引入冗余内容，过少则无法覆盖核心供需数据 |
| `相似度阈值` | 0.72–0.78 | 过滤泛行业非相关研报，保留与工业金属品类强关联的专业内容 |
| `定时触发表达式` | `0 0 9 * * *`（每日9点）、`0 0 1 * * 0`（每周日1点） | 匹配现货数据日更、月度报告每周更新的节奏 |
| `数据清洗规则` | 按单位映射转换 | 适配工业金属数据中美元/吨、元/吨、磅等多单位格式，统一输出标准字段 |
| `工具调用模型` | 支持结构化函数调用的大模型版本 | 满足多数据源查询、行情数据拉取的工具调用需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流中配置的表单输入字段在对话交互界面不显示。原因：未在对话节点的界面配置中开启表单组件显示开关，或未将表单字段绑定到工作流上下文变量。
- 现象：工具调用节点无法自动触发后续指定工具执行。原因：未配置工具调用的触发条件规则，或所选模型未开启结构化函数调用能力。
- 现象：工作流中的变量值仅保留初始写死内容，无法随数据源更新动态变化。原因：未添加变量更新节点，或未将数据源返回值正确绑定到目标变量。

## 怎么确认配好了
- 触发单次测试工作流，查看数据清洗节点的输出日志，确认单位转换后的字段格式符合预期。
- 发起模拟对话，输入与工业金属相关的查询指令，查看召回的研报条目数量是否符合配置的召回条数。
- 检查定时触发节点的cron表达式，确认与对应数据的更新周期匹配。
- 提交表单输入内容，查看对话界面是否正确渲染表单组件，且输入内容能传递到后续工作流节点。
