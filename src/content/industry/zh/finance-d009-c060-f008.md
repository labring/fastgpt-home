# 工程咨询研报检索的工具调用与插件

## 这个品类的数据长什么样
工程咨询研报的数据主要来源于住建部门公开的行业标准、各省市住建厅发布的项目备案档案、中国建设工程造价管理协会等行业机构的专项调研成果，以及第三方工程咨询机构的公开报告。数据更新节奏分为三类：政策类标准每季度更新，项目案例类数据每月同步，行业解读类内容每半年更新。文档结构固定包含封面、政策依据章节、项目核心参数（含建筑面积、造价指标、材料用量等）、技术方案、风险评估及附录的规范编号、适用地区等字段，计量单位采用工程领域通用的平方米、立方米、万元、吨等。

## 这些特征在「工具调用与插件」这一环带来什么约束
工程咨询研报的结构化参数多、单位统一且更新节奏明确，要求工具调用需支持数值字段的精准匹配，避免模糊检索导致的参数偏差。行业数据的多频次更新需要插件支持增量同步配置，确保检索结果始终覆盖最新政策与项目案例。文档中包含大量附录规范编号与关联项目ID，要求工具调用需支持按特定字段进行关联检索，同时需适配长文档的解析与字段提取流程。不同地区的项目参数存在细微差异，需工具调用时可配置地区过滤规则，缩小检索范围，提升专业内容的匹配精度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 字符 | 适配工程咨询研报单篇平均长度，避免截断核心造价、技术参数等关键内容 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 匹配长文档研报中附录字段的解析耗时，防止未完成解析就终止流程 |
| `召回条数` | 前 8 条 | 平衡工程咨询场景下的精准度与专业信息覆盖度，避免冗余结果干扰 |
| `相似度阈值` | 0.75–0.85 | 过滤低关联的通用建筑文档，聚焦专业咨询类研报内容 |
| `API_SESSION_EXPIRY` | 1800 秒 | 支持同一场景下的多轮工具调用会话，确保参数可跨轮次传递 |
| `增量同步间隔` | 7 天 | 适配行业政策与项目数据的更新节奏，保障检索内容的时效性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：多次调用API后会话状态丢失，无法关联上一轮检索的项目参数。原因：未配置`API_SESSION_EXPIRY`参数，或取值过短导致会话自动过期。
- 现象：HTTP请求组件无法接收插件传入的数值字段，返回`Request failed with 400 Bad Request`错误。原因：未对工程咨询研报中的数值型参数（如造价、建筑面积）做格式校验，导致参数不符合API的类型要求。
- 现象：PDF解析后的附录规范编号字段提取为空。原因：`PARSE_FILE_TIMEOUT_SECONDS`取值过短，导致长文档的附录部分未完成解析就被终止。

## 怎么确认配好了
- 发起单篇工程咨询研报的检索请求，检查返回结果的上下文是否包含完整的项目参数与技术方案。
- 发起连续3次关联同一项目的工具调用，确认会话状态未丢失，参数可跨轮次传递。
- 模拟行业数据更新后触发增量同步，检查向量库中是否新增了最新的研报内容。
- 传入数值型参数发起检索，确认HTTP请求能正常携带参数并返回匹配结果。
