# 工程咨询研报检索的文档解析与分块

## 这个品类的数据长什么样
工程咨询研报的数据主要来自建筑装饰类工程咨询机构的内部项目文档、行业协会发布的专项咨询报告、招投标公示文件及合规审查材料。数据更新节奏随项目推进实时调整，行业综述类研报按季度发布。文档多包含固定结构：项目概况、技术方案、造价明细、合规性分析，同时附带CAD图纸、工程量清单表格、BIM模型参数附件。字段包含建筑面积、造价金额、工期时长等，配套专有单位如平方米、万元、日历天，以及建筑抗震等级、施工工艺标准等专业术语。

## 这些特征在「文档解析与分块」这一环带来什么约束
工程咨询研报的多源文档格式要求解析节点支持PDF、DOCX、CAD导出文件等多种格式，尤其是内嵌表格与矢量图纸的解析。实时更新的项目文档需适配批量上传与外部系统主动推送的解析流程，避免仅支持手动单次上传的限制。固定章节结构要求分块环节保留层级逻辑，防止关键信息跨章节拆分。专有字段与单位则要求解析过程保留数值与单位的关联，避免拆分后丢失专业含义。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | 900 秒 | 工程咨询研报常包含大型CAD附件与多页长文档，需足够超时时间保障完整解析 |
| `分段长度` | 800–1200 字符 | 工程咨询研报单章节内容较长，该区间可保留专业段落完整性，避免跨关键信息拆分 |
| `UPLOAD_FILE_MAX_SIZE` | 2000 MB | 支持大型CAD图纸、多页PDF合集的上传需求，适配工程咨询项目的大型附件场景 |
| `保留章节层级` | 开启 | 工程咨询研报章节逻辑清晰，保留层级可帮助后续检索精准匹配对应章节的内容 |
| `解析内嵌表格` | 开启 | 研报中造价明细、工程量清单为核心信息，需完整解析内嵌表格内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为服务器部署后上传文件触发解析时报404错误，原因是未配置静态文件存储路径，前端上传的文件未正确同步至服务器解析节点的可访问目录。
- 现象为解析后的文档无内嵌表格内容，原因是未开启`解析内嵌表格`配置，工程咨询研报中的造价清单、工程量表无法被完整提取。
- 现象为分块结果出现跨章节的内容拼接，原因是`分段长度`设置过小，导致关键的章节标题与对应内容被拆分，丢失上下文关联。

## 怎么确认配好了
- 上传单份200MB以内的CAD导出PDF文档，等待解析完成后检查是否提取完整章节标题与内嵌表格。
- 查看系统日志，确认解析请求未触发超时错误，对应`PARSE_FILE_TIMEOUT_SECONDS`设置符合需求。
- 手动触发外部系统推送文件至知识库，检查解析分块任务是否正常启动并生成对应向量数据。
- 检查文件存储目录的访问权限，确认服务器部署环境下可正常读取上传的文件内容。
