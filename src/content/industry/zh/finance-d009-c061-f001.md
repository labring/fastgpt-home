# 工程机械研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
工程机械研报数据主要来自中国工程机械工业协会公开报告、主机厂官方技术文档、第三方行业数据库。更新节奏以月度行业动态报告、季度市场分析报告为主，年度专项研报为辅。单篇文档结构通常包含整机性能参数、工况适配方案、竞品对标分析、市场供需数据等模块。核心字段包含额定功率、工作重量、作业半径、燃油消耗量等，对应单位分别为千瓦（kW）、吨（t）、米（m）、升/小时（L/h），部分研报会附带区域销量分布统计项。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
工程机械研报的多字段多单位特征，要求HTTP接口支持自定义字段映射，将外部数据源的原始字段名、单位转换为统一格式后传入。月度/季度的更新节奏，要求外部系统对接时配置合理的轮询间隔，避免频繁请求超出数据源接口限流阈值。单篇文档篇幅较长的特点，要求HTTP接口支持分段接收或流式传输，同时调整超时阈值以适配长文档解析。多源数据聚合的需求，要求接口支持多数据源地址的批量配置与优先级排序，确保核心行业数据优先加载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300–600 秒` | 工程机械研报篇幅较长，常规解析时长超出默认值，需延长超时时间避免解析中断 |
| `embedding_batch_size` | `10–20 条` | 工程机械研报字段多且单位复杂，小批量处理可降低嵌入模型调用出错概率 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单篇年度专项研报可能包含大量图表与参数表格，需适配大文件上传需求 |
| `recall_top_k` | `8–12 条` | 工程机械研报的专业字段关联性强，适量召回可覆盖核心参数与市场数据 |
| `api_request_timeout` | `120 秒` | 外部数据源接口响应可能受数据量影响，延长超时可避免正常请求被误判失败 |
| `field_mapping_rule` | 按数据源原始字段名匹配单位后转换 | 工程机械研报的单位体系统一但各数据源命名存在差异，需自定义映射规则 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部多模态模型时无法处理研报中的设备参数图表，返回文本仅包含参数文字。原因：未开启接口的全模态数据传输配置，仅传递文本内容导致图表信息丢失。
- 现象：导入OneAPI地址与密钥后，调用嵌入模型返回`500 Internal Server Error`。原因：未设置正确的嵌入模型接口路径，或请求体未携带工程机械研报的特定字段参数。
- 现象：对接公众号后无法触发研报检索请求，后台无对应请求日志。原因：未配置公众号的HTTP回调地址与FastGPT的webhook端口匹配，导致请求无法正常转发。

## 怎么确认配好了
- 发起单次研报文件上传请求，检查接口返回的解析状态码为`200 OK`，确认超时配置生效。
- 调用嵌入模型接口，传入单条工程机械参数字段，检查返回的向量数据不为空，确认字段映射规则正确。
- 配置外部系统的回调地址，发起测试请求，检查FastGPT后台日志中存在对应请求记录，确认接口连通性正常。
- 发起检索请求，核对返回结果中包含额定功率、作业半径等工程机械专属字段，确认召回规则适配品类特征。
