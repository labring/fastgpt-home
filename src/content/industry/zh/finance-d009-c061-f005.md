# 工程机械研报检索的多轮对话与提示词

## 这个品类的数据长什么样
工程机械研报数据主要来源于公开行业报告、主机厂商公开资料、第三方行业调研数据集。更新节奏分为月度运行数据、季度销量报告、年度产业白皮书，新品参数随发布实时更新。文档结构一般包含行业总览、细分品类数据、产品性能参数、市场份额分析、政策影响内容。字段与单位包括：销量以台为单位，功率以千瓦为单位，作业半径以米为单位，营收以亿元为单位，产品单价以万元为单位。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
工程机械研报普遍单篇篇幅较长，单篇可达数万字符，多轮对话需限制上下文窗口规模，防止模型上下文溢出，丢失关键信息。细分品类字段多且单位统一要求高，提示词需明确指定不同参数的对应关系，避免模型混淆挖掘机斗容与装载机额定功率的单位。数据更新频率存在差异，月度运行数据与年度白皮书更新节奏不同，多轮对话需定期触发知识库召回，确保模型使用最新数据集。不同研报结构差异明显，提示词需明确指定提取字段的固定格式，匹配行业文档的常规排版逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 工程机械单篇研报篇幅可达数万字符，该区间可保留足够多轮对话上下文，避免溢出 |
| `recallCount` | `前 8–12 条` | 工程机械研报包含多类细分参数，适量召回可覆盖销量、功率、作业半径等关键数据 |
| `rerankTopN` | `前 5–7 条` | 过滤冗余召回结果，聚焦与当前提问高度相关的行业数据，降低模型分析干扰 |
| `promptTemplate` | `按研报字段分类整理回答，明确标注参数对应单位` | 工程机械参数单位多样，统一格式可避免模型混淆不同品类的参数定义 |
| `stream` | `false` | 多轮对话需完整返回分析结论与引用来源，非流式可确保内容输出无中断 |
| `apiDetailLevel` | `full` | 需返回完整的知识库引用条目与对应字段，方便后续核对数据来源 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置`promptTemplate`与`referenceTemplate`时混淆两者作用，导致返回结果未正确关联知识库召回内容。原因：未明确`promptTemplate`用于定义模型整体回答规则，`referenceTemplate`用于格式化知识库返回的原始数据。
- 现象：在线对话与API调用返回结果差异显著，API开启`stream=false`、`detail=true`时仍缺失引用来源字段。原因：API请求未正确传递`detail`参数配置，或提示词未要求模型标注引用来源。
- 现象：v4.9.14版本部署后，多轮对话并发请求触发超时报错。原因：未根据服务器算力配置调整`maxConcurrent`参数，默认并发阈值低于实际业务需求。

## 怎么确认配好了
- 发起单轮测试提问，验证返回结果中包含明确的参数单位与分类，核对是否匹配工程机械行业的常规格式。
- 发起多轮连续提问，检查上下文窗口未出现溢出报错，模型可基于历史对话内容延续分析逻辑。
- 调用API接口，核对返回结果中包含`detail`字段对应的知识库引用信息，与在线对话结果一致。
- 调整并发请求数量，验证服务器未触发超时报错，确认并发阈值适配当前业务的实际负载。
