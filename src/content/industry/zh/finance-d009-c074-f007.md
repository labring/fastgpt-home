# 教育服务研报检索的工作流编排

## 这个品类的数据长什么样
这个品类的数据主要来自教育行业第三方调研机构、教育主管部门公开调研资料、教育服务企业内部运营分析报告。政策解读类研报随对应教育政策发布节点更新，行业运营类研报每季度更新。单篇文档结构包含封面、摘要、政策解读、细分领域分析、数据附录，字段包含报告发布日期、发布机构、覆盖学段、核心指标单位，核心指标多以人次、课时数、万元为单位。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的数据特征对工作流编排带来三点约束。第一，数据来源分散，需配置多数据源挂载节点，支持对接第三方调研机构、教育主管部门及企业内部的研报存储路径。第二，更新节奏差异化，需设置分类型的定时同步节点，政策类研报按对应政策发布周期触发同步，运营类研报按季度触发同步。第三，文档结构复杂且包含学段、指标单位等细分字段，需配置章节级分段解析节点，同时添加字段提取节点，提取覆盖学段作为检索过滤条件，保留指标单位以保证检索结果的准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时同步周期` | 政策类`7天`，运营类`90天` | 匹配两类研报的更新节奏，保证知识库数据时效性 |
| `分段长度` | `800–1200 字符` | 适配教育研报章节的信息密度，避免单段内容过长导致上下文溢出 |
| `召回条数` | `前8条` | 覆盖教育研报多细分维度的检索需求，避免遗漏相关内容 |
| `相似度阈值` | `0.75–0.85` | 平衡专业术语匹配的精准度，过滤无关文档同时保留相关细分领域内容 |
| `重排返回条数` | `前5条` | 控制最终展示结果的数量，避免用户信息过载 |
| `知识库筛选变量` | 提取`覆盖学段`字段 | 匹配教育服务研报的核心检索维度，精准过滤目标学段的研报内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用工作流API后返回结果为空或提示“无匹配文档”。原因：未配置知识库筛选变量的字段映射，导致无法正确提取研报的`覆盖学段`字段作为检索过滤条件。
- 现象：配置知识库检索节点时，变量引用参数填写后无匹配结果。原因：未指定变量关联的知识库字段名，仅填写变量名称未绑定研报的`覆盖学段`字段。
- 现象：工作流执行超时，返回`504 Gateway Timeout`错误。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，教育研报单篇文档内容较多，默认超时时间不足以完成文档解析与分段。

## 怎么确认配好了
- 手动触发知识库同步操作，查看同步日志确认对应数据源的研报已成功解析并完成入库。
- 在工作流调试界面输入包含特定教育学段的查询，验证检索结果是否匹配目标学段的研报内容。
- 调用工作流API，检查返回结果是否包含研报的核心字段信息，无空值或缺失情况。
- 查看工作流执行日志，确认文档解析的分段长度符合预设配置，无上下文溢出相关提示。
