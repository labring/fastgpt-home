# 教育服务研报检索的部署与升级

## 这个品类的数据长什么样
教育服务研报主要来自教育行业第三方调研机构、地方教育主管部门公开报告、职业教育校企合作白皮书、民办教育机构运营分析文档。常规行业研报按季度更新，专项政策配套报告随政策发布节点更新。文档包含核心业务模块拆解、运营数据摘要、政策适配性分析、落地场景案例、成本测算模块，涉及在校学生规模、单客服务成本、合作院校数量等字段，对应单位分别为：人、元/人次、所。

## 这些特征在「部署与升级」这一环带来什么约束
教育服务研报单篇篇幅较长且结构复杂，部署时需调整文档解析的超时阈值，避免大体积文档解析中断；常规按季度更新的研报与不定期专项报告并存，升级环节需支持增量同步机制，降低全量同步的服务器负载；字段包含特定业务单位，部署时需配置自定义字段解析规则，确保检索时的字段匹配准确性；部分研报涉及内部教研内容，部署环节需预留权限配置入口，便于后续调整访问范围。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 教育服务研报单篇篇幅较长，需预留足够的文档解析时间 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 单篇深度研报的文件体积可达数百兆，需放宽上传上限 |
| `RECALL_TOP_N` | `前 8–12 条` | 研报内容细分模块较多，需召回足够数量的检索片段确保匹配全面 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 研报包含大量专业术语，需平衡检索精度与内容覆盖范围 |
| `SYNC_CRON` | `0 0 */7 * *` | 常规行业研报按周同步更新，适配季度更新节奏的同时覆盖临时专项报告 |
| `GROUP_ACCESS_CONTROL` | 按角色划分权限规则 | 教育服务场景存在教研、合作机构、实习生等不同访问需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：发布后助手返回无权限访问的报错文案，或部分用户无法查看指定研报内容。原因：未配置角色权限组，默认开放全部知识库权限，未针对低权限角色做范围限制。
- 现象：Ubuntu Server 24.04环境下部署v4.9.3版本时，调用qwen-max模型出现401状态码。原因：未正确配置阿里云API密钥的环境变量，或密钥权限未开通模型调用权限。
- 现象：大体积研报上传后解析失败，查看日志显示超时错误。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时间不足以完成长文档解析。

## 怎么确认配好了
- 上传一篇典型教育服务研报，检查解析后文本是否完整覆盖所有章节，无截断或乱码。
- 配置不同角色的访问规则，使用对应角色的访问凭证验证，确认仅授权角色可访问指定研报内容。
- 设置同步计划后，手动触发增量同步，检查服务器负载指标无异常波动。
- 发起专业术语相关的检索请求，验证召回结果的匹配度符合预设规则。
