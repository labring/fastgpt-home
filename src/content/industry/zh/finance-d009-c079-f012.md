# 普钢研报检索的模型接入与配置

## 这个品类的数据长什么样
普钢研报的来源包括中国钢铁工业协会月度统计资料、国内大宗商品交易平台的现货日报、券商发布的行业跟踪报告与深度研报。更新节奏分为现货价格与库存数据日更，行业周报周度更新，深度研报按需发布。文档结构包含行情模块（含普钢牌号、基准价、日均产量）、供需平衡分析、下游需求拆解、成本端波动解读，字段以具体牌号、物理统计量为核心，单位统一为元/吨、万吨、千立方米等。

## 这些特征在「模型接入与配置」这一环带来什么约束
普钢研报的多来源、结构化特征对模型接入配置带来多重约束。首先，混合了结构化表格与非结构化分析的文档，要求开启结构化解析开关以提取可直接调用的字段。其次，现货数据的高更新频率，要求配置较短的知识库同步周期，平衡实时性与资源占用。再次，不同文档的长度差异较大，从数百字的周度跟踪到数万字的深度报告，需要合理设置分段参数避免关键数据截断。最后，跨来源的单位一致性要求，需配置数据归一化规则以统一不同渠道的统计口径。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `enableStructuredParse` | 开启 | 普钢研报包含大量结构化的价格、产量、库存表格，开启后可提取结构化字段供模型直接调用 |
| `chunkSize` | 800–1200 字符 | 普钢研报的单段分析内容通常在500-1000字符，该区间可保留完整的供需分析逻辑，避免截断关键数据 |
| `chunkOverlap` | 100–150 字符 | 普钢研报的结构化表格常跨页分布，重叠区间可保证表格数据的完整性 |
| `knowledgeBaseSyncInterval` | 12 小时 | 普钢现货价格日更新，行业研报周度更新，12小时同步可平衡实时性与资源消耗 |
| `rerankTopN` | 前 6 条 | 普钢研报的相关结果通常集中在头部，优先召回包含具体牌号、价格的文档可提升回答准确性 |
| `parseExcelEnable` | 开启 | 部分普钢行业数据以Excel表格形式发布，开启后可直接解析表格中的结构化数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用时返回`context length exceeded`错误码413，原因：未对普钢深度研报做合理分段，导致传入模型的上下文超出配置的窗口限制。
- 现象：接入MiniMax模型时返回`invalid api key`或`model not supported`，原因：未在FastGPT模型配置页面正确填写MiniMax的专属接口域名与版本参数。
- 现象：工具调用解析报错，提示`Tool call Parser n`，原因：普钢研报中的结构化表格数据被`think`标签包裹，未配置模型的输出格式参数，导致解析失败。

## 怎么确认配好了
- 上传一份普钢现货价格周报，检查解析结果是否提取出Q235、HRB400等牌号的基准价、周度库存等结构化字段。
- 发起“当前普钢HRB400的价格是多少”的查询，检查返回结果是否包含来自同步知识库的最新数据。
- 测试工具调用功能，输入包含多段研报内容的查询，检查是否未出现上下文溢出报错。
- 查看模型配置页面的同步日志，确认知识库按12小时周期自动同步最新的普钢行业数据。
