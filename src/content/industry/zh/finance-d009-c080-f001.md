# 服装家纺研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
服装家纺研报的数据来源包括国内纺织服饰行业协会公开统计、券商消费组研报、品牌方季度财报公开内容。更新节奏以季度为核心周期，新品上市季会追加临时更新。文档结构包含品类供需数据、原料价格走势、头部品牌动态、供应链风险提示。字段包含发布机构、发布时间、核心数据项、分析结论，部分核心数据项的单位为元/吨、件/月。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
服装家纺研报的数据特征对HTTP接口与外部系统环节带来三点约束。第一，多来源的数据需要对接不同的外部接口，因此接口鉴权配置需要适配多种认证规则。第二，存在临时突发更新的需求，因此需要支持手动触发同步的接口参数。第三，文档包含多维度数据且单位多样，因此接口需要支持指定返回字段，同时添加单位映射的配置项，避免下游系统处理冗余或格式不符的数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `EXTERNAL_DATA_SOURCE_LIST` | `["association_api", "broker_research_api", "brand_finance_api"]` | 覆盖服装家纺研报的三类核心数据源 |
| `SYNC_INTERVAL` | `86400 秒` | 适配季度更新为主的常规更新节奏，预留临时更新的调整空间 |
| `API_RESPONSE_FIELDS` | `["publish_time", "core_data", "analysis"]` | 过滤冗余字段，适配下游系统轻量化调用需求 |
| `REQUEST_TIMEOUT` | `30 秒` | 应对多数据源并发请求的平均延迟，避免长时间阻塞 |
| `AUTH_TYPE` | `multi_auth` | 适配不同外部数据源的差异化鉴权规则 |
| `MANUAL_SYNC_ENABLE` | `true` | 支持新品上市季的临时研报同步需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：平台模型列表未显示配置的数据源模型，修改`BASE_URL`后未生效。原因：未同步更新部署容器的环境变量，或未重启服务使配置生效。
- 现象：调用接口返回`getaddrinfo EN`类报错。原因：花生壳类域名地址未完成网络配置，或本地网络未开放对应端口，导致域名解析失败。
- 现象：调用接口时持续处于连接等待状态，未返回响应体。原因：未设置`REQUEST_TIMEOUT`参数，或超时设置超出下游数据源的响应极限。

## 怎么确认配好了
- 调用接口测试工具，传入研报检索的核心参数，检查返回字段是否包含配置中指定的项。
- 手动触发一次同步任务，查看外部数据源接口的返回结果，确认无连接或鉴权报错。
- 查看平台运行日志，确认接口鉴权配置已正常加载，无鉴权失败的报错信息。
- 对比接口返回的核心数据项与预设的单位映射规则，确认单位转换配置正常生效。
