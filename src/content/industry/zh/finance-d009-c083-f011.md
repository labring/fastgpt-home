# 水务研报检索的文档解析与分块

## 这个品类的数据长什么样
水务研报的数据主要来自中国城镇供水排水协会公开统计、公用事业领域券商研报、水务上市公司定期报告、地方住建部门的水务运营公开数据。数据更新节奏随文档类型不同：上市公司年报按季度、年度更新，行业月度统计数据按月发布，监管政策文件不定期更新。文档形态包含内嵌多列业务表格的PDF研报、独立Excel格式的运营统计报表，常见字段包括日均供水量、污水处理量、单位水处理成本、管网总长度，对应单位分别为万立方米、万吨/日、元/吨、公里。

## 这些特征在「文档解析与分块」这一环带来什么约束
水务研报的多表格嵌入、多字段关联的特征，对文档解析与分块带来多重约束。内嵌业务表格的PDF文档，解析时易出现单元格跨页拆分，导致单条业务数据断裂为两段。独立Excel报表的多列结构，默认自动分块会将跨列的完整业务行拆分为多个片段，破坏数据关联性。水务数据的字段绑定性强，例如供水量与对应水处理成本需同属一个分块，否则检索后无法形成完整业务结论。长文本研报中夹杂多区域水务数据时，固定长度分块会割裂同一区域的连续运营信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_TABLE_ENABLE` | 开启 | 水务研报包含大量结构化业务表格，开启后可完整提取单元格内的业务数据，避免文本解析遗漏表格信息 |
| `AUTO_CHUNK_SEGMENT_LENGTH` | 800–1200 字符 | 水务研报的业务块通常包含2-3个关联字段，该长度可容纳完整的业务单元且避免跨块割裂关联数据 |
| `CHUNK_OVERLAP_RATE` | 10%–15% | 水务数据的关联性较强，重叠分块可确保跨块的业务信息被完整召回，避免关键关联数据被拆分在块边界 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 部分水务行业的月度统计Excel报表单文件体积较大，该阈值可覆盖常规上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 大型Excel报表或多页PDF研报的解析耗时较长，该时长可避免解析中途超时失败 |
| `SKIP_PARSE_DUPLICATE_HEADER` | 开启 | 水务统计Excel报表常包含重复表头行，开启后可自动跳过冗余表头，减少分块内的无效信息 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传多列水务统计Excel后，自动分块结果将跨列的完整业务行拆分为多个独立片段。原因：未开启表格解析开关，或未将分块规则调整为按行拆分，导致分块时按文本宽度随机拆分，破坏业务数据的完整性。
- 现象：解析水务研报PDF时，出现跨页表格的单元格内容被拆分到不同分块的问题。原因：未开启表格跨页合并的配置项，导致跨页的业务数据被割裂，无法形成完整的业务信息块。
- 现象：批量上传水务文档时，解析日志显示包含历史上传的文档内容。原因：未开启仅解析当前上传文件的过滤开关，导致系统加载了历史知识库的文档参与本次解析，产生冗余解析任务。

## 怎么确认配好了
- 上传一份小型水务Excel统计报表，查看解析后的分块内容，确认业务行未被跨列拆分。
- 上传一份包含跨页表格的PDF研报，检查分块结果中是否合并了跨页的表格单元格数据。
- 上传单份水务文档，查看解析日志，确认仅当前上传的文档被解析，未混入历史文档内容。
- 测试检索水务业务数据，确认关联的供水量与成本数据出现在同一或相邻的分块中。
