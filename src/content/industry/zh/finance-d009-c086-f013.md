# 汽车服务研报检索的知识库检索与召回

## 这个品类的数据长什么样
汽车服务研报的数据来源包含主机厂官方技术手册、汽车后市场连锁门店的运营日志、行业协会发布的调研简报、第三方检测机构的实测报告，多为金融与保险机构用于汽车金融、车险业务分析的参考资料。文档结构通常包含车型参数、维保周期、配件型号、服务定价、故障排查流程等字段，部分文档还包含不同工况下的性能测试数据，单位涉及牛·米、千米、小时、元等。新车型相关文档随车型发布更新，运营数据月度更新，行业简报按季度更新。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多维度字段的存在要求检索支持多字段联合匹配，避免单一关键词匹配导致的业务分析偏差。长文本的故障排查流程需保留连贯性，分段时不能截断关键步骤，否则会影响检索结果的实用性。不同来源的文档存在单位表述差异，需对字段进行归一化处理，确保检索时能识别统一的计量标准。不同更新节奏的数据源需适配不同的索引更新频率，保证数据时效性与存储资源的合理分配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `召回条数` | `前10-15条` | 汽车服务研报包含多维度专业内容，该取值可平衡检索结果的覆盖度与上下文长度 |
| `分段长度` | `800-1200字符` | 汽车服务文档常包含连贯的故障排查流程，该长度可保留单流程逻辑的完整性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300秒` | 大型主机厂技术手册文档体积较大，解析需较长处理时间 |
| `相似度阈值` | `0.72-0.80` | 汽车服务研报的专业术语较多，该取值可平衡精准匹配与召回覆盖范围 |
| `增量更新触发周期` | `每月1次` | 后市场运营数据月度更新，行业简报按季度更新，该周期适配多数数据源的更新节奏 |
| `字段归一化规则` | `统一单位映射` | 不同来源文档存在单位表述差异，该配置可消除计量标准不一致导致的检索偏差 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：创建知识库时，文本理解模型下拉框未显示已添加的ollama qwen2.5模型。原因：未在知识库配置中启用对应模型的检索权限，或模型部署的网络路径未配置至平台可访问范围。
- 现象：知识库搜索返回报错信息`invalid configuration parameter name "hnsw.iter"`。原因：向量数据库配置中存在拼写错误的参数名，或旧版本配置文件未适配当前版本的参数规范。
- 现象：发布的助手可被任意访问者读取全部企业知识库文档。原因：未配置知识库的访问权限分组，或未将助手绑定至指定权限组，导致默认开放全量文档访问。

## 怎么确认配好了
- 上传一份包含故障排查流程的汽车服务研报文档，查看解析后的分段是否保留了流程的连贯性，确认分段长度配置生效。
- 发起包含专业术语与单位的检索请求，核对召回结果的相似度得分是否符合预设范围，确认相似度阈值配置生效。
- 检查向量数据库的索引更新日志，确认增量更新任务按配置周期触发，确认增量更新触发周期配置生效。
- 分配测试账号并设置对应权限范围，验证该账号仅可访问指定的知识库文档，确认权限配置生效。
