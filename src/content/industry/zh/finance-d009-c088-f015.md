# 油服工程研报检索的部署与升级

## 这个品类的数据长什么样
油服工程研报的来源主要包括行业协会公开报告、油服企业内部作业统计、第三方专业咨询机构的专项分析文档。更新节奏以月度、季度为常规周期，重大行业事件如油价波动、新钻井技术落地时会有临时补充更新。文档结构通常包含封面说明、核心作业数据表格、行业动态解读、政策影响分析及典型项目案例。字段多为专业计量类，如「钻机总台数」「单井进尺」「作业天数」「单位作业成本」，对应单位为台、米、天、元/米，部分文档包含多页长表格汇总数据。

## 这些特征在「部署与升级」这一环带来什么约束
油服研报的长表格、专业计量字段及非固定更新节奏，对部署与升级环节带来多重约束。长表格与多章节内容会延长文件解析耗时，需调整解析超时参数；专业字段的精准匹配要求知识库索引配置适配专业术语，避免字段映射错误；非固定的更新频率要求升级时支持增量同步配置，无需全量重新导入历史数据；内网部署场景下，需支持带认证的代理配置以访问外部行业数据源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 油服研报常包含多页长表格与多章节内容，解析耗时显著高于通用文档 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 单份年度汇总研报可能超过1000 MB，需预留足够上传空间 |
| `maxContext` | `8000–12000 字符` | 研报单章节专业内容较长，需覆盖足够上下文以支撑精准问答 |
| `RECALL_NUMBER` | `前 8 条` | 油服研报的专业数据分散在多个章节，需召回足够数量的相关片段 |
| `相似度阈值` | `0.75–0.85` | 需过滤低相关性的行业泛文，保留精准匹配的专业数据片段 |
| `PROXY_USERNAME`/`PROXY_PASSWORD` | 按内网代理实际配置填写 | 内网部署时需通过带认证的代理访问外部研报数据源 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：内网部署时加载外部研报数据源失败，日志显示407代理认证错误。原因：仅配置了代理IP与端口，未填写`PROXY_USERNAME`和`PROXY_PASSWORD`，无法通过带认证的代理访问外部数据源。
- 现象：从4.8.14升级到4.8.15后，保存的大模型配置失效，聊天时调用了未绑定的模型。原因：版本升级后模型配置的存储字段发生调整，未同步更新应用内的绑定参数。
- 现象：docker部署的实例中，解析油服研报后检索结果为空。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，长表格解析未完成即进入索引环节，导致部分数据未被加载。

## 怎么确认配好了
- 上传一份单份季度油服研报，查看解析进度是否在`PARSE_FILE_TIMEOUT_SECONDS`设定的时间内完成。
- 发起包含专业术语的提问，比如「当前国内钻机总台数」，核对检索结果是否包含研报中的对应数据。
- 检查`PROXY_USERNAME`和`PROXY_PASSWORD`是否与内网代理规则一致，尝试访问外部研报数据源接口。
- 升级版本后，进入应用设置页面查看模型绑定配置，确认显示的模型标识与预期一致。
