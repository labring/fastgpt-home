# 油气开采研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
油气开采研报数据主要来自国家能源主管部门公开披露文件、全球油气行业咨询机构专项报告、上市油气企业年度及季度运营公告。更新节奏包含固定月度/季度常规更新，以及突发油田事件后的临时补充更新。文档结构通常包含区块勘探参数、单井产能数据、开采成本核算、政策影响分析四个核心模块。字段包含单井日产量（单位：立方米/天）、可采储量（单位：十亿立方米）、开采周期（单位：年）、区块经纬度坐标等专属参数。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
油气开采研报包含大量结构化产能、储量参数与地理坐标，要求HTTP接口支持结构化字段精准匹配与地理范围筛选。固定与临时结合的更新节奏，要求外部系统支持增量同步接口与手动触发全量更新的配置项。单篇研报篇幅较长且包含多模块内容，要求接口支持大文档分段解析与上下文截断参数配置。专属字段的单位与定义差异，要求外部系统在数据对接时需严格匹配字段映射规则，避免参数混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `max_context_length` | 8000–12000 字符 | 单篇油气研报通常包含多组结构化数据与长文本分析，该长度可覆盖完整核心分析段落 |
| `chunk_size` | 1500–2000 字符 | 油气研报的结构化区块（如产能数据）需保持字段完整性，该分段长度可避免拆分单井产能等核心参数 |
| `api_request_timeout` | 300 秒 | 全量同步研报数据时需处理大量结构化字段解析，该时长可覆盖常规批量请求耗时 |
| `cors_allowed_origins` | 企业内部域名列表 | 油气行业数据通常涉及敏感运营信息，需限制跨域访问来源 |
| `structured_recall_top_k` | 前 8 条 | 油气研报的核心结构化参数（如储量、产能）需优先召回，该条数可平衡召回精度与响应速度 |
| `file_upload_max_size` | 500 MB | 单篇大型油气研报PDF可能包含高清勘探图纸，该上限可覆盖常规文件尺寸 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用`api/v1/chat/completions`接口时返回`403 Forbidden`或跨域错误提示。原因：未配置`cors_allowed_origins`参数或配置了开放的通配符，导致外部请求被拦截。
- 现象：通过第三方代理服务转发接口请求时返回长串错误代码。原因：未在代理服务中正确配置结构化字段的参数映射，导致油气研报专属字段无法被正确解析。
- 现象：上传研报PDF时返回`400 Bad Request`错误。原因：文件名包含过长的特殊字符或超过系统限制的长度，触发文件上传校验规则。

## 怎么确认配好了
- 调用接口传入油气研报专属字段（如`单井日产量`），检查返回结果是否包含对应结构化数据。
- 发起跨域请求，验证非配置域名是否被拦截，配置域名是否可正常访问。
- 上传不同长度的测试文件名，确认触发校验的边界值符合业务需求。
- 发起批量同步请求，检查接口是否在`api_request_timeout`配置的时长内完成响应。
