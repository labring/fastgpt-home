# 消费电子研报检索的文档解析与分块

## 这个品类的数据长什么样
消费电子研报的数据主要来自券商研究所消费电子团队、产业链调研机构、行业协会公开报告。更新节奏以季度行业展望、月度细分品类数据为主，新品发布、供应链变动时会追加临时报告。文档结构包含标准化封面、目录、核心数据表格、分层章节分析、附录调研细节。字段包含出货量（单位为百万台/万台）、产品均价（单位为美元/人民币元）、供应链物料成本（单位为美元/件）、产品参数（如屏幕尺寸、电池容量）等，部分报告还会包含跨区域的销售数据。

## 这些特征在「文档解析与分块」这一环带来什么约束
消费电子研报包含大量结构化表格与专业术语密集的长文本，解析时需避免破坏表格结构，否则核心数据会被拆分导致检索不完整。多源数据的单位不一致问题，需要解析时保留原始单位信息，否则检索时无法精准匹配对应品类的统计口径。研报的层级化章节结构清晰，分块时需关联上下文标题，否则检索到的内容无法明确归属智能手机、折叠屏等细分品类。高频更新的文档量较大，解析环节需兼容多格式上传文件，同时控制单文件解析时长，避免超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `分段长度` | 800–1200 字符 | 消费电子研报包含长文本分析与结构化表格，过长会超出上下文窗口限制，过短会割裂专业术语与数据的关联 |
| `分段重叠率` | 10–15% | 保留跨分段的专业术语连贯性，避免“折叠屏手机”等术语被截断在分段末尾 |
| `Excel解析模式` | 保留完整表格 | 消费电子研报的出货量、成本表格是核心检索数据，拆分表格会导致数据不完整 |
| `保留文档章节标题` | 开启 | 消费电子研报层级化结构清晰，附加章节标题可提升检索内容的上下文关联性 |
| `相似度阈值` | 0.75–0.85 | 消费电子研报专业术语密集，过低会引入无关内容，过高会遗漏相关细分数据 |
| `UPLOAD_FILE_MAX_SIZE` | 200–300 MB | 消费电子研报PDF常附带高清产品图表，需适配单文件的较大体积上限 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 上传Excel格式的消费电子研报后，检索国外使用地的产品数据时返回结果少于Excel内的实际条目。原因是未启用`Excel解析模式`的完整表格解析，默认按行拆分单元格内容导致部分地区数据被截断或遗漏。
- 上传PDF格式的研报时，接口返回`413 Request Entity Too Large`报错。原因是未调整`UPLOAD_FILE_MAX_SIZE`参数，消费电子研报的PDF文件常因包含高清产品图超出默认上传上限。
- 检索分块内容时，未匹配到调研样本量、发布日期等辅助数据。原因是未开启保留元数据的配置，辅助数据被排除在分块的有效检索内容外。

## 怎么确认配好了
- 上传单份消费电子研报的Excel文件，查看解析后的分块内容，确认完整表格数据被保留，无单元格内容截断。
- 上传单份PDF研报，检查解析进度状态是否显示为完成，无超时或报错提示。
- 检索某款消费电子产品的出货量数据，确认返回的分块内容包含对应的章节标题与原始单位信息。
- 调整`分段长度`参数后，重新解析同一份研报，检查分块的字符数是否符合预设区间。
