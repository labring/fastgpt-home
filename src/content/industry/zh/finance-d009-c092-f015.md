# 消费电子研报检索的部署与升级

## 这个品类的数据长什么样
消费电子研报是金融理财领域机构与个人投资者的核心参考资料，来源主要覆盖券商研究所行业报告、头部消费电子品牌公开财报、行业协会供应链数据及专业电子媒体内容。更新节奏随新品发布周期波动，在季度新品发布会、国际电子展前后更新密度提升，日常以月度更新为主。文档结构包含核心参数表格、市场规模分析、供应链拆解、竞品对比四个核心模块，字段包含产品型号、芯片制程、电池容量、屏幕尺寸等，对应单位为纳米、毫安时、英寸等。

## 这些特征在「部署与升级」这一环带来什么约束
消费电子研报的多源分散特性要求部署阶段支持批量导入多格式文件，包含PDF格式的完整研报、Excel格式的参数表格及网页形式的行业动态内容，适配金融理财场景下的多源数据整合需求。更新节奏的波动属性，使得升级阶段需调整定时同步规则，避免固定周期无法适配新品发布的突发更新需求，满足金融投资者对实时研报的获取需求。文档内密集的专业参数字段，要求部署时配置实体抽取规则，适配纳米、毫安时等特定单位的精准识别，提升检索匹配的准确性。长文档与多维度对比内容，会增加向量存储与召回的计算负载，升级阶段需优化向量库分片与召回策略，保障检索效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 消费电子研报常包含高清参数图表与长文本分析，单文件体积较大 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `900 秒` | 包含复杂参数表格的长文档解析耗时较长，需预留足够处理时间 |
| `maxContext` | `800–1200 字符` | 研报参数表与竞品对比内容密集，需保留足够上下文以准确匹配专业字段 |
| `召回条数` | `前8条` | 消费电子研报的竞品对比维度较多，需足够召回结果覆盖多类分析需求 |
| `相似度阈值` | `0.72–0.8` | 研报内容专业度较高，需过滤低相关召回结果，避免无效信息干扰 |
| `DOC_SYNC_INTERVAL` | `按行业周期调整` | 消费电子更新节奏随新品发布波动，固定同步周期无法适配突发更新需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：多知识库分类时仅匹配当前查询问题，未关联历史上下文记录，导致分类结果落入兜底类别。原因：未开启`enable_history_context`配置项，或配置的历史轮次参数取值不足。
- 现象：添加Doc2X系统插件后出现解析报错，界面返回504超时状态码。原因：`PARSE_FILE_TIMEOUT_SECONDS`取值设置过短，未适配消费电子研报中长参数表格的解析耗时。
- 现象：海外部署场景下，通过免登录窗口分享的检索功能无响应，无法返回研报查询结果。原因：未配置跨域白名单允许海外访问域名，或`CORS_ALLOW_ORIGINS`参数未包含对应分享域名。

## 怎么确认配好了
- 上传单份符合`UPLOAD_FILE_MAX_SIZE`取值的消费电子研报PDF，检查解析状态显示为成功，且核心参数字段被正确抽取。
- 发起包含具体消费电子型号与专业参数的查询，核对召回结果的相似度得分符合预设阈值区间。
- 测试多知识库分类场景，输入连续多轮相关问题，确认分类结果未落入兜底类别。
- 配置定时同步任务，验证在新品发布周期内自动触发更新，非周期时段暂停同步。
