# 游戏研报检索的工具调用与插件

## 这个品类的数据长什么样
针对金融场景下的游戏行业研报，其数据主要来自专业行业研究机构、垂直数据平台与厂商公开披露信息。更新节奏集中在新游戏上线、季度财报发布节点，日常也会更新行业动态与竞品跟踪内容。文档结构包含核心业务数据、竞品对比、市场分析与政策解读，字段涵盖流水、活跃用户数、用户画像占比、留存率、付费转化率等，单位多为万元、百万级用户等，单篇文档长度从数千字符的短报告到数万字符的深度分析不等。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据源的多样性要求工具调用支持多接口适配与字段统一处理，避免不同来源的数据格式差异导致插件解析失败。研报更新的节点性特征，要求工具调用配置支持定时增量同步，减少资源占用，提升同步效率。文档长度差异大的特点，要求上下文截断参数适配长文本输入，避免关键业务数据被截断后影响工具调用结果。字段单位不统一的情况，要求插件内置单位标准化逻辑，确保数值计算与图表生成的准确性，避免因单位差异导致结果错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 适配游戏研报单篇2000-10000字符的常见长度，避免上下文溢出导致工具调用失败 |
| `plugin_timeout` | `30–60 秒` | 适配FastGPT SaaS 4.9版本的插件运行逻辑与第三方游戏数据接口的响应时长，避免因接口延迟触发超时错误 |
| `dataset_recall_top_k` | `前6–10 条` | 过滤无关研报信息，确保工具调用仅使用与当前问题强相关的内容 |
| `plugin_auto_trigger` | `按研报关键词触发` | 匹配游戏研报中流水、DAU、新品上线等明确工具调用关键词，减少无效触发 |
| `file_parse_chunk_size` | `1000–1500 字符` | 适配游戏研报的段落结构，平衡分块后的上下文关联与处理效率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为FastGPT SaaS 4.9版本中调用基础图表插件后返回`none`，原因是未正确配置游戏研报的字段映射，流水、DAU等数值字段未被插件识别为可绘图数据。
- 现象为尝试调用视觉模型时提示模型未配置，原因是未在`plugin_model_config`中添加对应视觉模型的标识与接口地址。
- 现象为实际发起工具调用但系统日志无对应条目，原因是未开启`plugin_log_enable`配置项，或日志采集阈值设置过高。

## 怎么确认配好了
- 上传一篇测试用游戏研报，触发工具调用，核对插件输入参数是否包含研报内的数值字段与单位。
- 查看`plugin_log`页面，确认工具调用的请求与响应日志被正常记录。
- 调用视觉模型插件，输入游戏相关的截图或描述，核对模型返回结果是否符合预期。
- 调整`maxContext`参数，上传长文本研报，确认上下文未被截断导致工具调用失败。
