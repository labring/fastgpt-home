# 物流研报检索的文档解析与分块

## 这个品类的数据长什么样
物流行业研报的数据源主要来自全国性物流行业协会、头部物流企业公开披露的运营报告、第三方物流咨询机构的专项调研成果。更新节奏分为季度、年度常规报告，以及冷链、跨境物流等专项品类的不定期发布文档。文档结构通常包含行业整体运力概况、细分赛道运营指标、政策影响分析、市场竞争格局与趋势预判。核心统计字段包括干线货运量、仓储周转天数、专线运输单价、企业营收规模，对应单位分别为万吨、自然日、元/吨公里、亿元。

## 这些特征在「文档解析与分块」这一环带来什么约束
数据源多样带来解析复杂度提升，既有结构化的企业财报表格，也有非结构化的政策解读段落，部分文档还包含可视化图表的文字说明，要求解析环节支持多格式内容提取。更新频率不均导致文档篇幅差异较大，常规报告可达数十页，专项报告仅数页，分块规则需适配不同篇幅的文档结构。细分赛道指标差异明显，冷链研报会额外包含温控参数，零担研报侧重网点密度，分块需保留字段关联关系，避免拆分破坏指标与数据的上下文绑定。部分研报包含跨页的完整表格，分块时需避免拆分表格主体，确保数据的完整性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 物流研报多包含长段行业分析与跨页表格，该长度可平衡上下文完整性与检索精度 |
| `分段重叠长度` | 100–150 字符 | 保留跨分块的关键指标关联，避免拆分后丢失数据上下文 |
| `表格解析模式` | 保留完整行结构 | 物流研报的运力、营收数据多以表格呈现，完整行结构可确保指标与数值的对应关系 |
| `分块分隔符` | 章节标题、换行符 | 适配研报的章节式结构，按目录层级拆分可保留文档逻辑结构 |
| `单文档最大分块数` | 50 块 | 避免超长文档生成过多无效分块，同时控制向量库存储开销 |
| `启用图表文本提取` | 按实测标定 | 适配部分研报附带的可视化图表说明，补充图表关联的文字信息 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：分块后核心运力指标与对应数值被拆分到不同分块，检索时无法同时召回。原因：未按照研报的章节或段落边界设置分块分隔符，仅依赖固定长度拆分，破坏了指标与数据的关联关系。
- 现象：上传至服务器后的文档分块结果与本地切分结果差异较大，检索匹配效果不符合预期。原因：本地切分未遵循平台统一的解析规则，未保留物流研报特有的表格结构与字段关联，与服务器的配置参数不匹配。
- 现象：上下文引用区域仅显示纯文本表格内容，无法呈现结构化排版。原因：未启用表格解析配置，分块时未提取表格的行列结构，仅将表格内容作为普通文本拆分。

## 怎么确认配好了
- 上传单份典型物流研报，查看分块预览界面，确认核心章节与表格未被强制拆分。
- 检索研报中的特定指标，确认相邻分块可召回关联的补充数据。
- 导出分块后的文本内容，检查表格内容是否保留了行列对应关系，无乱码或缺失字段。
- 对比不同篇幅的研报分块结果，确认分块规则适配了不同文档的结构特征。
