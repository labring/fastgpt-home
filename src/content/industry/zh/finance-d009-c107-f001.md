# 电力研报检索的HTTP接口与外部系统

## 这个品类的数据长什么样
电力研报的数据主要来自国家能源局官方发布文件、省级电网公司公开运行报告、电力行业专业咨询机构的分析文档。更新节奏随内容类型差异明显：政策解读类研报随行业政策发布实时更新，行业运行数据类按月度、季度周期更新，上市公司电力业务研报随财报披露节奏更新。文档一般包含政策摘要、电力供需分析、区域电网数据、细分品类盈利预测，字段包含「全网最大负荷」「新能源并网容量」「单位供电煤耗」等，对应单位为万千瓦、千瓦、克标准煤/千瓦时。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
电力研报的多源数据来源要求HTTP接口适配不同格式的文档解析，需支持官方公开文件、第三方咨询报告的统一转换。不同更新周期的数据源，要求外部系统配置分类型的定时拉取任务，避免无效拉取或更新滞后。带专属单位的结构化字段，要求接口返回保留原始字段与单位，防止外部系统因单位不匹配导致计算错误。区域电网敏感数据要求接口配置细粒度权限校验，限制未授权访问。单篇研报内容体量较大，接口需支持分页返回，适配外部系统的展示与内存限制。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `RETRIEVE_TOP_K` | `前8-12条` | 电力研报包含大量专业结构化字段，过多召回会引入无关数据，过少则无法覆盖核心分析内容 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 单篇电力研报常附带大量表格与原始数据，解析耗时较长，默认超时时间不足以完成完整解析 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 电力行业研报常附带月度发电量报表等大体积附件，需支持较大文件上传 |
| `SYSTEM_PROMPT` | `仅基于提供的电力研报内容回答，严格保留原文中的单位与字段名称` | 电力研报的单位与字段具有行业专属含义，需避免模型擅自修改或转换 |
| `TIMED_SYNC_CRON` | `0 0 2 * * *`（政策类）与`0 0 1 * * 0`（行业数据类） | 政策类研报更新频率高，行业数据类按月度更新，需分周期配置同步规则 |
| `RETRIEVE_SIMILARITY_THRESHOLD` | `0.75-0.85` | 电力研报专业术语较多，需设置合理阈值过滤低相关的召回结果 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：接口返回的研报内容中「单位供电煤耗」字段显示为无单位的数值。原因：未配置`SYSTEM_PROMPT`要求保留原始字段与单位，导致解析或回答环节擅自转换了行业专属单位。
- 现象：定时同步任务经常触发`504 Gateway Timeout`报错。原因：将`PARSE_FILE_TIMEOUT_SECONDS`设置为默认的300秒，未适配电力研报的大体积与结构化解析需求。
- 现象：外部系统调用接口后返回的结果条数远少于预期的核心分析内容。原因：将`RETRIEVE_TOP_K`设置为小于5的数值，未匹配电力研报的多结构化字段召回需求。

## 怎么确认配好了
- 上传一篇测试用的电力研报，调用检索接口，检查返回结果中是否包含原始的行业专属字段与对应单位。
- 查看定时同步任务的运行日志，确认不同类型的数据源按预设的`TIMED_SYNC_CRON`规则执行同步。
- 模拟未授权的访问请求，确认接口返回权限错误提示，验证细粒度权限配置生效。
- 调整`RETRIEVE_TOP_K`的取值，核对接口返回的结果条数与配置值一致。
