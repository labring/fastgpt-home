# 电力研报检索的工作流编排

## 这个品类的数据长什么样
电力研报的数据主要来自电力行业协会、电力监管机构公开报告、上市电力企业财报及专业咨询机构的调研文档。更新节奏分为三类：月度行业运行报告为固定周期更新，季度/半年度财报按企业披露时点更新，重大政策发布则为即时更新。文档结构包含行业供需数据、分区域装机与发电量数据、电价波动分析、政策解读及重点企业经营情况，字段多带有固定单位，如装机容量单位为万千瓦、发电量为亿千瓦时、电价为元/兆瓦时，同时包含发布日期、政策文号等元数据字段。

## 这些特征在「工作流编排」这一环带来什么约束
电力研报的结构化数据与更新节奏差异，对工作流编排带来多重约束。首先，带固定单位的结构化数据要求工作流中加入字段校验环节，避免单位转换或数值精度错误；其次，多类数据源的更新节奏差异，需配置多触发节点分别适配定时拉取与实时监控场景；再者，单篇研报篇幅跨度大，需设置动态分段参数适配不同长度文档的分片处理；最后，跨区域电力数据的存在，需关联地域维度字段实现精准召回，避免信息错位。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | `800–1200 字符` | 电力研报包含长段政策分析与短段结构化数据，该区间可平衡上下文窗口利用率与信息完整性 |
| `召回条数` | `前8–12条` | 电力研报核心信息集中在头部，过多召回会引入无关内容，过少则遗漏关键数据 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 电力研报部分文档篇幅较长，批量解析需预留足够的响应时长 |
| `定时触发周期` | `每日凌晨2点` | 电力行业月度报告通常在每月初发布，定时拉取可确保数据时效性 |
| `相似度阈值` | `0.75–0.85` | 电力专业术语的语义相似度需高于通用阈值，该区间可过滤无关研报同时保留相关内容 |
| `MCP日志输出级别` | `DEBUG` | 电力研报的结构化字段解析易出现单位转换错误，DEBUG级别可捕获详细日志便于排查 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 工具调用节点返回`Invalid JSON: Bad control character`错误，原因是电力研报中包含未转义的换行符、特殊符号，直接拼接为工具调用参数导致JSON格式校验失败。
- 工作流中工具调用节点无法添加连接线，界面无连接小圆圈控件，原因是节点未完成必填参数配置，或前端渲染异常导致控件未加载。
- 无法查看组件的MCP服务详细日志，原因是未将`MCP日志输出级别`设置为`DEBUG`，或未在工作流运行详情页展开对应节点的日志面板。

## 怎么确认配好了
- 上传单篇电力研报至工作流的文档节点，查看分段后的文本片段，确认分段规则符合配置要求。
- 触发工作流单次运行，检查工具调用节点的返回内容，确认无JSON格式错误。
- 进入对应组件的配置面板，展开高级设置区域，确认`模型ID`参数已正确获取并填写。
- 查看工作流运行详情页，确认MCP服务的解析日志已完整生成并可查看。
