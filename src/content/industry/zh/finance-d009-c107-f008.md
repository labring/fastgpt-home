# 电力研报检索的工具调用与插件

## 这个品类的数据长什么样
电力行业研报的数据源主要包括电力行业协会公开报告、国家能源局官方统计数据、上市电力企业定期财报、第三方能源咨询机构专项分析。更新节奏覆盖周报、月度运营简报、季度产业链分析及年度行业趋势报告，突发电力政策或能源事件会触发即时专项研报。文档结构通常包含核心运营数据、政策解读、上下游产业链联动分析、风险预警模块，核心字段包含装机容量（单位：万千瓦）、发电量（单位：亿千瓦时）、上网电价（单位：元/兆瓦时）、机组利用小时数等专属电力行业指标。

## 这些特征在「工具调用与插件」这一环带来什么约束
电力研报的专属单位与细分字段要求工具调用时需严格匹配数据格式，避免因单位转换错误导致结果偏差。多更新周期的数据源需要插件支持灵活的同步配置，区分常规周报与突发研报的拉取频率。文档的产业链分层结构要求工具调用能精准定位到上游煤炭供应、下游用电需求等细分模块，避免召回无关内容。电力政策相关研报需关联国家能源局等权威数据源的实时接口，因此插件需要适配专属API权限。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_call_timeout` | `120 秒` | 电力研报涉及多数据源聚合分析，常规超时时间不足以完成完整数据拉取与解析 |
| `recall_top_k` | `前 8–12 条` | 电力研报细分维度较多，需召回足够数量的文档覆盖产业链上下游不同模块 |
| `plugin_sync_interval` | `每周1次 / 每日1次` | 电力研报分周报、月报两类常规更新，可按数据源类型配置差异化同步周期 |
| `enable_mcp` | `开启` | 需调用电力行业专属MCP服务获取实时电价、发电量等动态数据 |
| `chunk_size` | `800–1200 字符` | 电力研报包含大量技术段落，该分段长度可保证上下文逻辑完整 |
| `allowed_data_sources` | `["电力行业协会", "国家能源局", "上市电力企业"]` | 过滤非权威数据源，提升工具调用结果的准确性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用时间相关插件获取电力运营数据时返回报错，原因是未配置对应电力数据源的MCP服务访问权限。
- 界面提示`The tool call is not supported`，原因是未开启`enable_mcp`配置项，或未绑定电力行业专属的工具插件。
- 4.8.19版本后调用本地部署的M3E模型失败，原因是版本升级后`model_config`的参数命名格式发生调整，未同步更新配置内容。

## 怎么确认配好了
- 进入FastGPT的工具管理页面，检查`enable_mcp`配置项是否开启，且绑定了电力行业专属的工具插件。
- 发起一次测试调用，输入“查询2024年第三季度全国火电发电量”，查看返回结果是否包含准确的单位与细分数据。
- 查看插件同步日志，确认对应电力数据源的拉取周期与配置的`plugin_sync_interval`一致。
- 检查`model_config`中的本地模型配置，确认本地M3E服务的地址与端口正确，且与当前FastGPT版本适配。
