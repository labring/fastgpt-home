# 电网设备研报检索的引用来源与溯源

## 这个品类的数据长什么样
电网设备研报数据主要来自中国电力企业联合会、电网设备制造企业公开年报、专业电力行业研究机构发布的分析报告。更新节奏以季度行业深度研报、月度厂商动态公告为主。文档结构通常包含核心技术参数（如变压器额定容量、断路器开断电流）、企业营收与产能数据、政策落地影响分析、产业链上下游关联信息。字段包含设备型号、技术指标、单位（如MVA、kV、亿元）、发布机构与发布日期等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
电网设备研报的核心技术参数需精准匹配设备型号，因此溯源环节需保留型号字段作为关键标识。季度行业研报与月度厂商动态的更新频率差异，要求溯源时区分长期行业报告与短期厂商公告的来源层级。文档中包含多单位的技术指标，需在溯源时同步展示对应单位，避免数据混淆。产业链关联信息常跨多篇文档，溯源需支持关联引用的聚合展示，确保用户可追溯完整逻辑链条。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxRecall` | 前8条 | 电网设备研报单篇切块通常包含多组技术参数，需召回足够数量的切块覆盖核心信息，同时避免冗余 |
| `contextWindow` | 1200–1500 字符 | 电网设备研报的技术参数描述较长，该区间可完整展示参数与对应来源关联，符合引用溯源的可读性要求 |
| `quoteDisplay` | 开启 | 需向用户明确展示溯源来源，满足电力行业工程师对数据可信度的核查需求 |
| `quoteFields` | `["设备型号", "发布机构", "发布日期"]` | 电网设备研报的核心溯源标识为设备型号、发布机构与日期，过滤其他非必要字段可简化溯源信息 |
| `parseChunkSize` | 4000–5000 token | 匹配电网设备研报的长文本特征，避免技术参数被拆分导致溯源关联断裂 |
| `similarityThreshold` | 0.75–0.85 | 电网设备技术参数相似度较高，该阈值可过滤低关联的召回结果，提升溯源精准度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：界面返回`quote type error`报错。原因：配置`quoteFields`时传入了非预设字段的参数，或变量格式不符合字符串校验规则，触发系统类型校验失败。
- 现象：回复中未展示任何引用来源信息。原因：误将`quoteDisplay`配置为关闭状态，或知识库未关联对应文件的元数据，导致溯源信息无法提取。
- 现象：设置`contextWindow`为1500字符后，仍出现超出长度的引用内容。原因：未同步调整`parseChunkSize`与`contextWindow`的匹配关系，切块内的长文本未被截断，导致超出设定的引用上限。

## 怎么确认配好了
- 上传一篇电网设备研报切片，发起包含技术参数的提问，核对回复中展示的溯源字段是否包含预设的核心标识。
- 调整`quoteDisplay`配置，切换开关状态后重新发起提问，确认引用信息的展示与开关状态一致。
- 查看知识库解析日志，确认切块大小符合设定值，且未出现参数校验失败的日志条目。
- 测试不同相似度阈值的提问，核对召回结果的数量与阈值设定的匹配度，确认溯源关联的准确性。
