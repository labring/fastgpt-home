# 畜禽养殖研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
畜禽养殖研报的数据主要来源于农业农村部畜禽监测系统、中国畜牧业协会行业报告、第三方农业咨询机构的专项调研文档。更新节奏覆盖多维度，月度出栏、存栏数据每月更新，季度产能、成本数据按季度发布，突发疫病或政策调整相关的临时研报更新频率可达每日。文档结构包含核心养殖指标、区域分布、成本测算、政策影响分析等模块，字段包含能繁母猪存栏量、白羽肉鸡出栏均价、饲料消耗总量等，单位多为万头、元/羽、吨等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多来源的数据要求外部系统对接多种HTTP接口，不同数据源的鉴权方式存在差异，部分使用API密钥，部分采用签名校验或OAuth2协议，需适配多种鉴权逻辑。字段名与单位的不统一，要求接口返回后进行统一映射转换，避免下游系统出现数据混乱。不同更新频率的需求，需要配置灵活的定时拉取任务，支持按小时、日、月等不同周期触发请求。长文档的接口返回需设置合理的分页参数，避免单次请求数据过大触发限流或超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DATA_SOURCE_LIST` | `["agri_moa_api", "china_animal_husbandry_assoc", "third_party_agri_report"]` | 覆盖官方监测、行业协会和第三方研报，满足全维度数据需求 |
| `API_AUTH_TYPE` | `["api_key", "signature", "oauth2"]` | 适配不同数据源的鉴权要求，如农业农村部接口使用签名校验 |
| `DATA_SYNC_INTERVAL` | `["1h", "1d", "1m"]` | 匹配不同数据的更新频率，突发研报每小时拉取，月度数据每日拉取 |
| `FIELD_MAPPING_RULES` | `{"能繁母猪存栏量": "母猪存栏", "出栏均价": "unit_price"}` | 统一不同数据源的字段名，消除单位转换差异 |
| `PARSE_PAGE_SIZE` | `200 条/请求` | 避免单次请求数据过大触发接口限流，减少分页请求次数 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 适配长文档研报的解析耗时，避免提前终止请求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部研报接口返回`404 Not Found`，响应体包含`not found`提示。原因：未正确配置数据源的接口路径，或调用的外部系统未获得接口访问权限。
- 现象：LLM无法触发研报检索的function call逻辑。原因：未将研报检索的接口参数正确绑定到工具配置中，或接口返回格式不符合工具调用的规范要求。
- 现象：检索结果中出现单位不一致的情况，如同时显示“万头”和“头”。原因：未配置统一的字段映射规则，未对不同数据源的单位进行标准化转换。

## 怎么确认配好了
- 发起一次测试接口请求，检查返回的字段是否与配置的映射规则一致，单位是否完成标准化转换。
- 查看定时任务运行日志，确认不同更新频率的数据源按预期触发拉取操作。
- 调用工具调用接口，验证LLM是否能正确触发研报检索并返回匹配的结果。
- 检查接口响应日志，确认未出现超时报错，响应时间符合配置的阈值要求。
