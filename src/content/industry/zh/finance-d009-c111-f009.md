# 畜禽养殖研报检索的引用来源与溯源

## 这个品类的数据长什么样
畜禽养殖研报的数据主要来自行业协会公开数据、券商定期研报、农业农村部监测信息及养殖主体公开披露内容。更新节奏以月度、季度为主，部分核心行情数据按旬度更新。文档结构包含核心数据表格、行情分析、政策解读三个核心板块，字段包含生猪存栏量、肉鸡出栏量、饲料原料价格等，单位多为万头、羽、元/吨，同时附带研报发布机构、发布日期、研报评级等元数据。

## 这些特征在「引用来源与溯源」这一环带来什么约束
畜禽养殖研报的结构化数据占比高且字段单位特殊，要求溯源环节需精准匹配数据字段与对应文档章节，避免混淆不同品类的养殖数据。多源且高频更新的特性要求溯源需关联最新版本的研报内容，防止引用过期数据。文档篇幅较长且格式差异大，要求解析环节需适配不同机构的研报排版，确保溯源时可定位到具体数据段落，避免定位到整份文档。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前8–12条` | 畜禽养殖研报核心数据集中，过多召回会引入无关品类的养殖内容，过少会遗漏关键细分数据 |
| `相似度阈值` | `0.72–0.85` | 研报中存在大量专业术语和相似字段表述，阈值过低会引入无关文档，过高会遗漏精准匹配的细分数据 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `900 秒` | 畜禽养殖研报多包含长数据表格和多章节内容，默认超时设置不足以完成完整解析 |
| `分段长度` | `1000–1500 字符` | 研报中的数据表格和分析段落长度不均，分段过长会丢失字段关联，过短会破坏数据完整性 |
| `重排返回条数` | `前3–5条` | 优先展示最相关的核心研报数据，避免溯源时展示过多非核心文档 |
| `ENABLE_SOURCE_DETAIL` | `按节点配置` | 不同工作流节点需要展示或隐藏溯源内容，适配不同使用场景 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：返回答案未关联知识库引用，或引用内容与答案无逻辑关联。原因：未针对畜禽养殖研报的专业字段调整相似度阈值，导致向量召回匹配到无关研报，或未开启文档分段的字段关联解析。
- 现象：知识库解析超时报错，状态码返回`408 Request Timeout`。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时设置不足以解析包含大型数据表格的长文档。
- 现象：部分工作流节点无法隐藏溯源内容。原因：未正确配置`ENABLE_SOURCE_DETAIL`的节点可见度权限，或未针对不同节点设置独立的来源展示规则。

## 怎么确认配好了
- 上传一份畜禽养殖研报文档，执行解析任务，查看解析后的字段是否包含存栏量、饲料价格等专属字段，确认分段长度配置生效。
- 发起包含专业术语的提问，核对返回的引用来源是否匹配对应研报的发布机构、发布日期，确认相似度阈值和召回条数配置生效。
- 进入工作流节点配置页面，针对不同节点切换`ENABLE_SOURCE_DETAIL`开关，验证对应节点的溯源内容展示状态是否符合预期。
- 查看系统日志，确认解析任务的耗时未超过`PARSE_FILE_TIMEOUT_SECONDS`设置的时长，无超时报错。
