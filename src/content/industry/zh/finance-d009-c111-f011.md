# 畜禽养殖研报检索的文档解析与分块

## 这个品类的数据长什么样
畜禽养殖研报是金融机构、理财服务机构用于行业分析的核心资料，数据来源包括农业农村部监测数据、行业协会月度报告、上市养殖企业定期公告、第三方调研机构专题研报。更新节奏以月度、季度为主，伴随突发疫病、价格波动的临时报告。文档结构包含存栏量、出栏量、饲料成本、疫病监测、产品价格等核心字段，单位多为头、吨、元/千克、元/吨等，部分跨来源报告存在单位标注不一致的情况。

## 这些特征在「文档解析与分块」这一环带来什么约束
畜禽养殖研报的量化数据关联性强，单块内容需保留存栏量与对应价格的关联关系，避免拆分后无法形成有效问答上下文。多页长文档的解析耗时较长，需适配更长的超时阈值。部分报告存在非标准化的图表与手写标注，需支持结构化字段提取与图表文本还原。临时报告的格式不固定，需兼容多种文档模板的解析逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | 1200 秒 | 畜禽养殖研报常包含多页图表与结构化表格，解析耗时较长 |
| `chunk_size` | 800–1200 字符 | 需保留存栏量、价格等关联量化数据的完整上下文 |
| `chunk_overlap` | 150–200 字符 | 保障跨块的结构化数据关联不中断 |
| `enable_structured_parse` | 开启 | 适配研报中的标准化养殖数据字段提取 |
| `enable_excel_parse` | 开启 | 适配畜禽养殖研报中常见的Excel格式统计表格 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 支持单份季度研报完整上传 |
| `marker_pdf_timeout` | 900 秒 | 私有化部署时避免长PDF解析超时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 界面显示文件解析成功，但模型回答未引用文档中的量化数据。原因：分块参数设置不当，将存栏量与对应价格拆分至不同文本块，导致上下文关联断裂。
- 触发`504 Gateway Timeout`报错。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，长文档解析超出默认超时限制。
- 4.8.9 简易模式下部分研报未被自动解析。原因：未根据研报的PDF/Excel格式调整自动解析触发规则，仅按固定后缀判断解析权限。
- 私有化部署marker_pdf解析时出现超时，但解析服务端显示成功。原因：未调整`marker_pdf_timeout`参数，平台侧超时阈值短于解析服务端设置。

## 怎么确认配好了
- 上传一份畜禽养殖季度研报，查看解析后的文本块，确认存栏量、价格等核心字段未被拆分至不同块中。
- 测试上传单份500MB左右的研报，确认上传与解析流程无超时报错。
- 发起基于解析后文档的问答，提问包含核心量化数据的问题，确认模型能准确引用对应内容。
- 查看平台解析日志，确认结构化字段提取结果与原文档内容一致。
- 上传一份Excel格式的养殖统计报表，确认解析后可提取完整的表格数据。
