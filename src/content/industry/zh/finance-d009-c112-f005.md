# 白色家电研报检索的多轮对话与提示词

## 这个品类的数据长什么样
白色家电研报的数据主要来自国内券商家电行业研究所、中国家用电器协会、头部上市公司公开财报及第三方市场调研机构。更新节奏分为三类：月度更新的线下/线上渠道销售数据，季度更新的全品类出货量与均价分析，年度更新的深度行业趋势报告，以及突发政策、新品发布时的即时专题研报。文档多为PDF格式，部分附带可导出的Excel附件，正文结构包含报告基本信息、行业整体概况、细分品类核心数据、竞争格局及未来展望，核心字段包括出货规模（单位：万台）、零售均价（单位：元/台）、头部品牌出货量、政策调整要点及新品技术参数。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
白色家电研报的数据来源分散，包含公开研报、行业协会数据及企业财报，多轮对话需先明确用户所需的数据源类型，提示词需限定召回范围避免混淆。单篇研报包含长文本正文与结构化Excel附件，需支持多格式内容的召回与解析，提示词需区分文本与结构化数据的提取逻辑。核心字段带有固定单位，多轮对话中需统一单位输出，提示词需要求模型标注对应单位。不同数据的更新频率差异较大，用户常需要指定时间范围查询，提示词需加入时间限定的明确要求，避免返回过时数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 单篇白色家电研报正文常超过5000字符，保留足够上下文可支持多轮追问时的上下文关联 |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 单篇研报PDF加配套Excel附件的总大小通常不超过30MB，预留合理缓冲空间 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | 解析带多附件的研报时，常规解析时长约60-90秒，避免超时截断数据 |
| `召回条数` | `前 6 条` | 白色家电细分品类数据分散，需召回足够条目覆盖出货量、均价、渠道等多维度数据 |
| `相似度阈值` | `0.72–0.78` | 过滤泛行业低相关研报，保留与白色家电强相关的内容 |
| `对话历史保留轮次` | `3–5 轮` | 用户常围绕同一研报的不同数据点连续追问，保留3-5轮可维持对话连贯性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 上传Excel格式的研报附件后，对话时无法提取其中的出货量、均价等结构化数据。原因：未开启FastGPT的Excel解析开关，或未配置结构化数据的字段映射规则。
- 调用对话接口时，返回结果未关联用户当前的具体问题。原因：未在提示词模板中正确引用`{{query}}`变量名，导致接口无法传递用户输入的实际内容。
- 调试预览生成的历史记录无法按应用或会话单独清理，只能清空全部工作台数据。原因：未调用指定会话清理接口，或未在清理请求中携带对应应用的唯一标识。

## 怎么确认配好了
- 上传一篇本地白色家电研报，检查解析后的文本是否包含核心字段，验证上传与解析参数是否生效。
- 发起多轮追问，比如先查询“2024年白色家电整体出货规模”，再追问“其中洗衣机品类的相关数据”，检查模型是否能关联前一轮的时间范围，验证上下文配置是否合理。
- 调整`相似度阈值`后发起相同查询，观察召回结果的相关性变化，确认阈值配置符合业务需求。
- 调用历史记录清理接口，指定当前应用的唯一标识，检查调试预览的会话是否被成功清除，验证清理规则的正确性。
