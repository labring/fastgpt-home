# 种植业研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
种植业研报数据主要来自农业农村部官方监测平台、全国农业技术推广服务中心公开报告、地方农科院调研数据及全国农业行业协会公开资料，这类研报是金融机构投研、保险农业险定价、理财类产品底层资产分析的重要参考依据。更新节奏覆盖月度种植动态监测、季度供需分析报告、年度产业发展白皮书，突发农业灾害或政策调整后会生成即时补充文档。文档结构包含核心种植指标、单产与规模数据、病虫害预警信息、农资价格走势、政策解读及市场供需预测等模块，字段多包含亩产量、种植规模、农资单价等具象化生产相关参数，单位多采用农业生产通用的公斤/亩、万亩、元/公斤等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
种植业研报的多源分散特性要求接口支持多数据源地址配置与动态切换，避免单一数据源失效导致检索中断。不同更新节奏的研报需匹配差异化的拉取周期配置，月度报告可按自然月定时拉取，突发应急简报需支持按需触发拉取。文档中包含大量生产类字段与分析文本，接口需支持自定义字段映射规则，适配外部生产管理系统的数据格式要求。同时，多数官方数据源存在访问频次限制，需配置请求限流参数，防止触发访问封禁。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPSTREAM_DATA_SOURCES` | `["农业农村部监测接口", "全国农技中心报告接口", "农科院调研接口"]` | 覆盖种植业研报的权威数据源渠道 |
| `SYNC_CRON_EXPR` | `0 0 2 * * *` | 每日凌晨2点触发全量同步，适配月度报告的常规更新节奏 |
| `FIELD_MAPPING_RULES` | `{"亩产量": "crop_yield", "种植面积": "plant_scale", "农资价格": "agri_input_price"}` | 匹配外部生产管理系统的标准字段命名 |
| `REQUEST_RATE_LIMIT` | `15 次/分钟` | 符合官方公开数据源的访问频次限制 |
| `RESPONSE_CONTENT_TYPE` | `application/json, text/csv` | 适配不同外部系统的数据导入格式需求 |
| `API_TIMEOUT` | `300 秒` | 覆盖长文本研报的检索与解析耗时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用接口时返回`getaddrinfo ENOTFOUND`错误，无法解析请求地址。原因：花生壳等动态域名服务未配置正确的端口映射，或外部系统防火墙拦截了接口请求端口。
- 现象：配置`UPSTREAM_DATA_SOURCES`后，平台未显示可用研报数据。原因：未正确配置`SYNC_CRON_EXPR`的触发规则，或数据源接口未开放公共访问权限。
- 现象：使用Java调用API时长期处于连接等待状态，未返回响应体。原因：未设置`API_TIMEOUT`参数，或超时设置不符合长文本研报的检索耗时需求。

## 怎么确认配好了
- 调用配置的数据源接口，检查返回数据是否包含预设的核心字段，核对字段映射规则是否将本地字段与研报字段正确对应。
- 查看同步任务日志，确认`SYNC_CRON_EXPR`按设定时间触发了全量拉取，且无异常报错。
- 测试不同格式的接口调用，确认返回内容符合预设的`RESPONSE_CONTENT_TYPE`要求。
- 模拟触发按需拉取任务，检查应急类研报是否能正常检索并返回结果。
