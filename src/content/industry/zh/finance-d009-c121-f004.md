# 耐火材料研报检索的向量模型与索引

## 这个品类的数据长什么样
耐火材料研报的来源包括金融机构发布的行业配置研报、行业协会发布的运行简报、上市耐火材料企业的技术研发报告、建材专业期刊的专题文章、国家相关部门发布的应用标准文档。更新节奏存在差异：行业运行类文档按季度更新，技术标准类文档随国标修订周期更新，企业研发文档随项目进度不定期发布，金融机构的配置研报随市场动态不定期更新。文档结构通常包含品类分类、核心性能参数、应用场景匹配、成本构成分析、上下游供需数据模块。核心参数字段包含耐火度、体积密度、热导率，对应单位分别为摄氏度、克每立方厘米、瓦特每米开尔文。

## 这些特征在「向量模型与索引」这一环带来什么约束
耐火材料研报的专业参数密集、术语细分且绑定特定应用场景，会对向量模型与索引环节带来多重约束。首先，大量带固定单位的性能参数需要嵌入模型精准捕捉专业语义，通用嵌入模型难以区分同类参数的细微差异。其次，研报更新节奏不均，季度运行数据与不定期研发文档并存，要求索引支持增量更新以避免全量重建的资源消耗。此外，部分文档包含性能测试图表，需额外适配图像索引模块提取图表内的结构化参数，进一步提升召回精度。同时，参数与应用场景的强绑定关系，要求分块策略优先按功能模块拆分，避免按固定长度拆分割裂语义关联。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `EMBEDDING_MODEL` | `bge-large-zh-v1.5`（或垂直领域微调嵌入模型） | 该模型对中文工业建材专业术语的语义嵌入效果稳定，可精准匹配耐火材料参数与场景的关联 |
| `CHUNK_SIZE` | `800–1200 字符` | 耐火材料研报的核心参数模块长度多集中在该区间，按此拆分可避免割裂参数与应用场景的语义绑定 |
| `RECALL_TOP_K` | `前 8–12 条` | 单篇研报内相关参数的关联文档数量适中，该取值可平衡召回覆盖率与上下文冗余度 |
| `PARSE_TABLE_ENABLE` | `开启` | 耐火材料研报包含大量性能参数表格，开启后可完整提取表格内的结构化数据用于向量化索引 |
| `IMAGE_INDEX_ENABLE` | `按版本配置` | v4.9.0及以上版本商业版默认支持图像索引，本地部署需确认是否加载对应OCR与图像嵌入模型 |
| `EMBEDDING_BATCH_SIZE` | `32–64` | 平衡向量生成的处理速度与显存占用，适配单卡显存16GB以上的部署环境 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：本地部署v4.9.0版本新建知识库时，无图片索引模型选项。原因：该版本的本地部署包默认未集成图像索引所需的OCR与嵌入模型，需手动加载对应插件包。
- 现象：配置`EMBEDDING_API_TYPE`为OneAPI时，向量生成失败，OneAPI返回连接超时或模型不存在报错。原因：未正确配置OneAPI的嵌入模型端点与密钥，或所选嵌入模型未在OneAPI平台完成部署。
- 现象：索引生成后召回的耐火材料参数相关性较低，结果条数偏差较大。原因：未按耐火材料研报的模块特征调整`CHUNK_SIZE`，采用固定短长度拆分导致参数与场景被割裂，或`RECALL_TOP_K`取值不合理。

## 怎么确认配好了
- 进入知识库管理界面，查看已上传的耐火材料研报的解析详情，确认表格内容与图像文本（若有）已被正确提取。
- 测试调用向量生成接口，输入一段耐火材料参数文本，检查返回的向量数据格式是否符合预设标准。
- 配置OneAPI接入的嵌入模型后，发起一次小型向量生成测试，确认无连接报错或模型不存在提示。
- 检索预设的耐火材料专业术语，核对召回结果的相关性与条数，调整对应配置项至符合业务需求的取值。
