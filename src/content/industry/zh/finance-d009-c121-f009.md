# 耐火材料研报检索的引用来源与溯源

## 这个品类的数据长什么样
耐火材料研报数据主要来自行业协会公开报告、上市企业技术研发公告、专业检测机构测试数据及行业期刊，供金融机构的行业分析、理财顾问的产品定价参考。更新节奏以季度常规报告、年度深度研报为主，突发原材料价格波动或行业政策调整时会生成临时补充文档。文档结构包含核心性能参数模块、生产工艺说明、市场供需分析，字段包含耐火度、荷重软化温度、体积密度，对应单位分别为℃、MPa、g/cm³。

## 这些特征在「引用来源与溯源」这一环带来什么约束
耐火材料研报的多源分散特征，结合金融领域的合规要求，要求溯源环节需为不同数据源配置专属标识规则，避免不同来源的同类型参数混淆。季度、年度常规报告与临时补充报告的更新节奏差异，要求溯源时绑定文档的发布时间戳，过滤过期数据，确保分析结论的时效性。专业性能参数与专属单位的组合，要求溯源时精准定位参数对应的原文段落，确保引用内容的准确性。此外，研报中存在大量跨文档对比的参数分析，溯源时需关联同一参数在不同文档中的引用位置，便于用户交叉验证。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前8-12条` | 耐火材料研报参数密集，过多召回会导致溯源段落冗余，过少则无法覆盖核心参数引用 |
| `分段长度` | `1000-1500字符` | 耐火材料研报的性能参数段落通常较长，分段过短会割裂参数与说明文本的关联，过长则增加向量匹配误差 |
| `相似度阈值` | `0.75-0.85` | 专业参数的语义匹配精度要求较高，阈值过低会引入无关文档，过高则无法召回相关研报 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300秒` | 大型耐火材料研报包含大量测试数据，解析耗时较长，默认超时时间可能不足 |
| `重排返回条数` | `前5条` | 需优先返回最匹配的研报，避免用户查看过多冗余溯源内容 |
| `引用来源展示字段` | `文档标题、发布时间、参数原文片段` | 耐火材料行业用户需明确参数的来源文档与发布节点，确认数据时效性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：溯源结果中仅显示文档标题，未展示参数原文片段。原因：未配置`引用来源展示字段`为包含原文片段的组合，仅启用了基础文档元数据展示。
- 现象：工作流中调用知识库搜索节点时，传入的自定义知识库变量无法生效，返回空结果。原因：未将工作流的输入变量与知识库搜索节点的知识库选择参数正确绑定，变量引用格式未匹配系统要求。
- 现象：解析超过100页的大型耐火材料研报后，溯源时出现超时报错。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`至适配大型文档的取值，默认超时时间不足以完成全量解析。

## 怎么确认配好了
- 上传一份测试用耐火材料研报，发起包含专业参数的查询，检查返回结果中是否附带文档元数据与原文片段。
- 配置工作流并传入自定义知识库变量，触发工作流执行，确认知识库搜索节点能正确调用指定知识库。
- 上传超过100页的大型研报，查看解析日志是否出现超时报错，确认超时参数配置符合文档规模需求。
- 调整相似度阈值至不同区间，对比召回结果的相关性，确认阈值取值适配专业参数的语义匹配要求。
