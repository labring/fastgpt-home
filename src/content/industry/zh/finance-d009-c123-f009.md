# 能源金属研报检索的引用来源与溯源

## 这个品类的数据长什么样
能源金属研报数据主要来自头部券商有色团队报告、国内有色行业协会月度统计、上海期货交易所与伦敦金属交易所的现货与期货报价、矿山企业公开产能公告。更新节奏覆盖日度现货价格、周度库存数据、月度供需平衡表、季度行业趋势分析。文档多包含结构化数据表格、政策条款摘录、供需测算模型片段，字段包含金属品类、品位数值、库存总量、价格区间，单位多为吨、元/吨、美元/千克，部分报告附带历史数据对比表格。

## 这些特征在「引用来源与溯源」这一环带来什么约束
能源金属研报的多频率更新特征，要求溯源信息需附带报告发布日期与数据采集时间戳，避免跨周期引用过期现货或库存数据。结构化数据表格占比高，需匹配对应表格的标题与页码，仅引用章节标题无法确保引用片段的精准性。不同来源的单位存在差异，部分海外报告使用美元/盎司，国内报告使用元/吨，溯源需保留原始单位标注，避免单位混淆。行业数据多来自公开交易所与协会，需明确标注数据来源的官方渠道名称。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `相似度阈值` | `0.75–0.85` | 能源金属研报数据精度要求高，需过滤低相关的通用研报片段，该区间可平衡召回精度与召回量 |
| `重排返回条数` | `前6–8条` | 能源金属研报的结构化数据多，需保留足够多的候选片段用于匹配精准溯源，避免因条数过少丢失核心数据表格 |
| `maxContext` | `1200–1500 字符` | 能源金属研报的结构化表格段落较长，该长度可完整包含单张数据表格的核心内容，避免截断导致溯源信息缺失 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `90 秒` | 部分大型行业研报文档包含多页结构化表格，解析耗时较长，该时长可覆盖常规研报的解析流程 |
| `引用上限` | `5–7 条` | 能源金属研报的核心数据分散在少量精准片段中，过多引用会降低回答的聚焦性，同时便于溯源信息的整理 |
| `rerankScoreThreshold` | `0.65–0.7` | 启用重排后需适当降低基础相似度阈值，避免因重排过滤掉部分早期召回的精准结构化数据片段 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：启用重排功能后，检索返回的引用片段为空或无匹配结果。原因：重排得分阈值设置过高，或重排返回条数设置过低，过滤掉了所有符合要求的研报数据片段。
- 现象：解析大型能源金属研报时，系统返回`504 Gateway Timeout`错误。原因：`PARSE_FILE_TIMEOUT_SECONDS`参数取值小于研报解析的实际耗时，导致解析流程被强制中断。
- 现象：引用溯源信息中未包含研报发布日期或数据单位。原因：未配置自定义引用模板，或模板未提取研报元数据中的发布日期、原始数据单位字段，导致溯源信息不完整。

## 怎么确认配好了
- 上传单份能源金属研报文档，核对解析后的分段结果，确认分段长度与配置项的取值逻辑匹配。
- 发起能源金属主题的检索请求，查看返回的引用片段总数，确认符合`引用上限`的设置规则。
- 查看引用溯源的展示内容，确认包含来源渠道、发布时间、原始数据单位等必要字段。
- 检查当前FastGPT版本，确认支持自定义引用模板功能，避免因版本过低无法配置溯源模板。
