# 航天装备研报检索的工具调用与插件

## 这个品类的数据长什么样
航天装备研报的数据源主要来自国防军工行业智库、航天系统内部公开研究成果、行业协会发布的产业动态文档，以及金融机构合规获取的军工细分领域专项研报。更新节奏方面，行业动态类文档随产业事件节点更新，专项研报随项目立项、试验节点发布，无固定周度或月度周期，按需更新。文档结构通常包含项目参数（如运载火箭推力、卫星轨道高度）、型号序列、试验数据、产业链上下游营收数据，字段多带专业单位，比如千牛（kN）、公里（km）、千克（kg），部分公开文档标注适用范围，适配合规使用要求。

## 这些特征在「工具调用与插件」这一环带来什么约束
航天装备研报的分散数据源与无固定更新节奏，要求工具调用支持多源混合拉取与按需同步，无法依赖固定周期的定时任务。文档中包含大量带专业单位的结构化参数，工具调用需配置单位识别与标准化规则，避免分析结果因单位不匹配出现偏差。部分公开文档带有脱敏范围标注，工具调用需关联权限过滤配置，仅调用脱敏后的合规内容。长篇幅专项研报的结构特征，要求工具调用的文档分段规则适配专业参数段落，避免截断核心技术数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 航天装备专项研报篇幅较长，需预留足够的文档解析时间，适配金融研究的批量处理需求 |
| `PARSE_SPLIT_LENGTH` | `1000–1200 字符` | 避免截断包含专业单位的核心技术参数段落，保障金融分析的参数完整性 |
| `recall_top_k` | `前 8–10 条` | 覆盖细分参数的多维度检索需求，保障金融研究的信息覆盖率 |
| `rerank_top_n` | `前 3–5 条` | 精准筛选匹配专业参数的有效文档，减少无关内容对金融分析的干扰 |
| `ACCESS_CONTROL_ENABLE` | `开启` | 适配航天装备研报的脱敏内容权限管理要求，满足金融机构的合规使用标准 |
| `PLUGIN_API_TIMEOUT` | `120 秒` | 适配外部军工行业数据源接口的响应延迟特征，保障工具调用的稳定性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部军工数据源插件时，接口返回参数匹配错误的结果。原因：未配置插件执行的顺序触发规则，导致并行调用打乱了参数匹配的依赖逻辑。
- 现象：检索结果中出现专业单位混淆的情况，如将“千牛（kN）”拆分为“千”和“牛”。原因：未按`PARSE_SPLIT_LENGTH`的建议值配置分段规则，导致单位字段被错误拆分。
- 现象：通过外部系统调用FastGPT工具时返回403权限报错。原因：未开启`ACCESS_CONTROL_ENABLE`配置，或未为调用方配置对应脱敏研报的访问权限。

## 怎么确认配好了
- 上传一份航天装备专项研报，查看解析后的分段结果，确认专业参数与单位未被错误拆分。
- 发起一次研报检索请求，核对返回结果的参数单位与原始文档一致，无混淆情况。
- 配置测试用的外部调用凭证，发起工具调用请求，确认权限校验逻辑正常生效。
- 查看工具调用日志，确认插件执行顺序符合预设的依赖规则，无并行错乱情况。
