# 航空机场研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
航空机场研报数据主要来自民航管理部门公开统计、机场运营方月度运营公告、民航行业咨询机构公开研究报告。更新节奏分为两类：核心运营数据（航班量、吞吐量等）按自然月更新，深度行业研报按季度或专项项目周期发布。文档结构通常包含核心指标表格、运营趋势分析、政策影响解读三个部分，核心字段包括旅客吞吐量（单位：人次）、货邮吞吐量（单位：吨）、起降架次（单位：架次）、单客平均消费（单位：元）等，部分研报还会包含区域航线分布的细分数据。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
航空机场研报的两类数据更新节奏，要求HTTP接口支持按自然月拉取全量运营数据，同时兼容按季度拉取深度研报的批量请求。核心指标的固定单位，要求接口返回字段需严格匹配预设单位，无需外部系统额外转换。单篇深度研报篇幅较长，接口需支持流式返回或分块读取，避免单次请求超时。多维度的细分数据，要求接口支持按机场代码、航线类型等参数筛选，减少无效数据传输量。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 单篇深度航空机场研报篇幅较长，需预留足够解析时间 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 部分专项研报文档体积较大，需支持大文件上传 |
| `召回条数` | `前 10 条` | 航空机场研报核心指标维度较多，需返回足够覆盖关键分析维度的检索结果 |
| `相似度阈值` | `0.75–0.85` | 研报文本专业性较强，需较高阈值过滤无关检索结果 |
| `HTTP_REQUEST_TIMEOUT` | `300 秒` | 外部系统拉取全量月度运营数据时，需较长响应等待时间 |
| `分段长度` | `800–1200 字符` | 航空机场研报段落结构清晰，该分段长度可保留完整语义分析单元 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用研报检索HTTP接口时，提示缺少应用标识参数，无法发起请求。原因：未在请求头中配置`X-App-Id`参数，或未通过官方API创建对应检索应用。
- 现象：调用API上传研报文件，接口返回调用成功但检索结果无对应文档内容。原因：`PARSE_FILE_TIMEOUT_SECONDS`参数设置过短，长文档解析未完成即终止请求。
- 现象：工作流中接收文件流请求时，接口返回空结果或截断错误日志。原因：未调整`UPLOAD_FILE_MAX_SIZE`参数适配大文件，或未配置正确的请求超时时间，导致请求被强制中断。

## 怎么确认配好了
- 发起单次小体积研报文件的上传请求，检查接口返回的解析状态字段是否为`success`，确认解析超时配置符合当前文件体积。
- 调用外部数据拉取接口，验证返回字段的单位与预设的航空机场研报指标单位一致，确认字段匹配配置正确。
- 发起多参数筛选的检索请求，验证返回结果的条数与`召回条数`配置一致，确认检索参数生效。
- 查看系统日志，确认无`request timeout`或`file size exceed limit`类报错，确认超时与文件大小配置适配。
