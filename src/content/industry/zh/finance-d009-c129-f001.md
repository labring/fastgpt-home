# 融资租赁研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
融资租赁研报的数据主要来自行业协会公开报告、监管机构发布的非银金融政策文件、头部租赁企业的季度运营披露。更新节奏存在差异：监管文件随政策发布即时更新，行业协会报告按季度批量产出，企业运营披露多为半年度或年度更新。文档结构包含结构化业务模块与长文本政策模块，结构化字段包含租赁项目编号、承租方主体评级、融资金额（单位为万元）、租赁期限（单位为月）、租金支付频率等，长文本模块则包含行业趋势分析与风险提示内容。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
融资租赁研报的数据来源分散且更新周期差异明显，这要求HTTP接口支持多源数据的增量拉取配置，避免外部系统重复拉取全量冗余数据。研报同时包含结构化业务字段与长文本政策模块，接口需要同时支持结构化参数查询与全文检索两种请求模式，且需内置单位校验逻辑，确保传入的金额、期限参数符合行业通用的万元、月单位规范。此外，部分细分领域的研报数据更新频率较低，接口需支持自定义更新周期的定时同步配置，适配外部系统的拉取节奏。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `retrieval_top_k` | 前8-12条 | 融资租赁研报的结构化字段与长文本内容较多，过多召回会导致上下文溢出，过少则无法覆盖关键业务条款 |
| `similarity_threshold` | 0.72-0.85 | 研报中存在大量专业术语与重复表述，阈值过低会引入无关内容，过高则可能遗漏相关风险提示或政策细节 |
| `sync_interval` | 3600秒或86400秒 | 监管文件即时更新，行业报告按季度更新，可针对不同数据源设置差异化同步间隔，适配研报的更新节奏 |
| `api_timeout` | 600秒 | 研报文档可能包含长文本内容，接口请求需预留足够的解析与拉取时间，避免超时中断 |
| `field_validation_enable` | 开启 | 融资租赁研报的字段存在固定单位规范，开启校验可确保外部系统传入的参数符合行业通用格式 |
| `chunk_max_length` | 800-1200字符 | 研报的长文本政策模块拆分后需保留语义完整性，该长度可兼顾检索精度与上下文窗口利用率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部创建应用接口返回404状态码，无法完成研报检索应用的快速部署。原因：未使用FastGPT官方提供的`/api/v1/apps`接口路径，错误使用了非官方接口端点。
- 现象：传入Claude格式的API请求参数后，接口无法正确解析并返回对应结果。原因：未将FastGPT的接口请求格式切换为兼容Claude的参数结构，未配置对应模型的格式适配规则。
- 现象：搭建完成的FastGPT服务仅支持HTTP访问，无法配置HTTPS加密连接。原因：未在服务启动脚本中配置SSL证书文件路径与监听端口，未启用HTTPS相关的系统参数。

## 怎么确认配好了
- 调用FastGPT提供的外部应用创建接口，传入符合融资租赁研报检索场景的配置参数，确认返回结果包含有效应用标识且无错误提示。
- 向研报检索接口发送包含结构化查询条件的请求，确认响应结果中包含匹配的业务字段数据，无字段缺失情况。
- 配置服务的HTTPS监听参数后，通过标准HTTP客户端工具访问服务端点，确认连接采用加密协议，无证书验证失败提示。
- 发送符合指定模型格式的请求，确认接口返回结果符合预期的参数结构与内容格式。
