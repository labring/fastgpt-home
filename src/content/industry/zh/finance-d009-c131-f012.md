# 装修装饰研报检索的模型接入与配置

## 这个品类的数据长什么样
装修装饰研报数据主要来自行业协会公开报告、建材供应商产品参数文档、装修施工企业内部项目复盘资料、第三方装修趋势调研内容。更新节奏随内容类型差异明显，建材价格类每周更新，行业政策类每月更新，项目案例类不定期发布。文档多为结构化混合格式，包含项目概况、建材选型清单、成本拆解表、施工工艺说明等模块，字段包含材料单价、施工工时、品牌型号、合规标准编号等，部分字段附带单位标识。

## 这些特征在「模型接入与配置」这一环带来什么约束
多来源的混合格式数据要求模型支持多格式解析，且需要适配结构化字段的提取精度。更新频率差异要求配置的向量库同步策略区分内容类型，高频更新的建材数据需设置更短的同步周期。包含大量数值型字段与单位的文档，需要配置专门的数值字段提取与单位对齐的模型插件，避免向量嵌入时单位混淆。项目案例类文档篇幅差异大，需配置分段长度适配长文本嵌入的参数阈值，防止关键信息被截断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `EMBEDDING_MODEL` | `text-embedding-3-large` 或 `bce-embedding-base_v1` | 适配装修研报中长文本与结构化字段的嵌入需求，支持高维度向量提取 |
| `maxContext` | `8000–12000 字符` | 适配装修研报中长文档的分段嵌入，避免截断关键的成本数据与工艺说明 |
| `RECALL_TOP_K` | `前8–12条` | 装修研报中结构化字段多，需召回足够数量的候选文档覆盖不同模块的信息 |
| `RERANK_MODEL` | `bge-reranker-large` | 适配中文装修术语的重排，提升结构化信息的排序精度 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 适配装修研报中多格式混合文档的解析时长，避免超时中断 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 适配装修研报中包含高清图纸附件的文档大小限制 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：界面提示「该令牌无权使用模型：text-embedding-3-large」，日志返回无可用渠道。原因：未使用自定义模型接入方式配置密钥，或密钥未绑定对应模型权限。
- 现象：添加bce-embedding渠道后，界面仍提示无可用向量模型。原因：渠道配置的模型名称与FastGPT内置的模型标识不匹配，未同步渠道状态。
- 现象：重排模型配置项无法勾选，界面显示灰色禁用状态。原因：未在全局配置中开启重排模型的权限开关，或配置文件中的重排模型配置格式错误。

## 怎么确认配好了
- 上传一份装修建材相关的测试文档，查看解析后的结构化字段是否完整提取。
- 发起针对性测试查询，查看召回结果的数量是否符合预设的配置取值。
- 核对模型接入的密钥与权限状态，确认无报错提示。
- 配置重排模型后，发起测试查询，根据业务需求调整相关阈值参数。
