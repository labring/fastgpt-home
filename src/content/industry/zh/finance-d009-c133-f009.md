# 证券研报检索的引用来源与溯源

## 这个品类的数据长什么样
证券研报的数据主要来自持牌证券研究机构发布的公开研报，以及合规金融数据服务商收录的研报库。更新节奏为每个交易日集中更新，伴随上市公司公告、宏观经济数据发布的突发研报可随时更新。单篇研报的文档结构通常包含标题、作者、发布机构、发布时间、投资评级、目标价、核心逻辑、盈利预测、风险提示等字段，其中投资评级为定性表述，目标价以人民币元为单位，盈利预测包含每股收益、市盈率等标准化量化字段。

## 这些特征在「引用来源与溯源」这一环带来什么约束
证券研报的合规属性与结构化特征，对引用溯源环节提出明确约束。首先，研报需标注发布机构与发布时间，溯源环节需完整展示这些字段以满足行业信息披露的合规要求。其次，研报包含目标价、盈利预测等带单位的量化数据，不同研报的同类数据可能存在差异，溯源需精准匹配具体切片的数值与来源，避免混淆。此外，研报更新频率较高，溯源环节需关联最新的研报版本，防止引用过时内容影响决策准确性。最后，单篇研报篇幅较长，切块后的溯源需明确标注切片在原研报中的大致位置，便于用户定位原始内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `引用来源字段` | `发布机构,发布时间,研报标题,原始链接` | 证券研报需满足合规披露要求，配置该字段可完整展示溯源所需的主体、时间、主题与原始访问地址 |
| `maxContext` | `8000-12000 字符` | 适配单篇研报的核心逻辑长度，避免截断包含评级、目标价的关键溯源信息 |
| `召回条数` | `前3-5条` | 证券研报的核心投研逻辑集中，该取值可保留有效信息同时避免冗余 |
| `相似度阈值` | `0.75-0.85` | 过滤低相关性的检索结果，适配证券研报的专业术语密集特征 |
| `分段长度` | `1000-1500 字符` | 保留研报完整的逻辑单元，同时适配多数引用上限的常规设置 |
| `显示引用来源开关` | `开启` | 满足证券行业合规要求，向用户明确展示信息来源 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用知识库引用功能时返回`quote type error`报错。原因：未按要求配置`引用来源字段`的参数格式，或导入的研报切片未包含指定的溯源字段，针对FastGPT 4.6.7及以上版本，该报错多由字段格式不匹配触发。
- 现象：回复内容中未展示任何知识库引用来源。原因：未开启`显示引用来源开关`，或`引用来源字段`的配置为空，导致系统无法提取溯源信息。
- 现象：设置`引用上限`为1500字符后，仍返回超出该长度的研报切片。原因：未将`分段长度`配置为小于引用上限的区间，导致召回的原始切块本身超过了可引用的长度限制。

## 怎么确认配好了
- 上传一份公开的证券研报至知识库，发起一次针对性的检索问答，查看回复中是否包含配置的`引用来源字段`内容。
- 检查系统返回的报错日志，确认未出现`quote type error`相关提示。
- 对比检索到的研报切片长度与设置的`引用上限`，确认切片未超出预设长度。
- 调整`显示引用来源开关`的状态后，再次发起问答，确认引用内容的展示状态符合预期。
