# 通用设备研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
通用设备研报的数据主要来自券商机械设备行业研报、行业协会公开报告、上市公司定期公告。更新节奏随行业事件触发，新品上市、行业景气度数据发布、财报披露期更新频率提升。文档结构一般包含核心设备参数、市场供需数据、竞品对比、政策影响分析，字段包含研报发布机构、发布日期、设备型号、核心参数数值、对应单位、投资评级等，部分研报附带图表数据的结构化提取字段。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
来自多源的结构化参数与单位字段，要求接口支持参数精确匹配、单位校验与跨单位转换；随行业事件波动的更新节奏，要求外部系统支持增量拉取与定时触发的灵活调度；包含长文本分析与结构化图表数据的文档结构，要求接口支持分页返回与多格式数据提取；多维度的筛选字段（如发布机构、设备型号），要求接口提供细粒度的参数化查询能力，避免无效数据传输。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `rag_recall_top_k` | `前8-12条` | 通用设备研报的参数与分析内容关联性强，过多召回会引入无关信息，过少则无法覆盖核心检索需求 |
| `rag_chunk_size` | `800-1200字符` | 通用设备研报的核心参数段落多为短段落，长文本分析部分拆分后需保留上下文关联，避免参数与分析内容拆分断裂 |
| `http_request_timeout` | `600秒` | 部分研报包含大量结构化图表数据，提取与转换耗时较长，超时过短会导致未完成的请求被中断 |
| `parse_field_whitelist` | `["发布机构", "发布日期", "设备型号", "额定功率", "转速"]` | 通用设备研报的核心检索维度为设备相关参数与发布信息，白名单可过滤无关字段提升检索精度 |
| `rag_similarity_threshold` | `0.75-0.85` | 通用设备研报的参数匹配需较高精度，阈值过低会引入低关联内容，过高则无法召回相关分析段落 |
| `api_response_format` | `结构化JSON` | 外部系统对接需标准化格式，便于后续数据解析与入库 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部接口时返回红色数字报错，状态码为400或500。原因：未正确配置外部系统的身份验证参数，或请求头中未携带正确的API密钥。
- 现象：检索结果中出现大量无关的非通用设备研报内容。原因：未配置`parse_field_whitelist`过滤无关字段，或召回条数设置过高引入低关联内容。
- 现象：接口调用超时，返回`ETIMEDOUT`错误。原因：`http_request_timeout`设置过短，未考虑通用设备研报中结构化图表数据的提取耗时。

## 怎么确认配好了
- 发送带设备型号、发布日期范围的测试请求，核对返回结果中是否仅包含通用设备相关研报，且字段包含预设的白名单内容。
- 查看接口返回的参数字段，确认单位格式与预设的目标单位一致，无混乱或缺失情况。
- 模拟批量请求，核对接口返回的响应时间符合业务预期，未出现超时情况。
- 对接外部系统后，核对外部系统入库的数据与接口返回的结构化数据完全一致，无格式错误。
