# 饲料研报检索的HTTP 接口与外部系统

## 这个品类的数据长什么样
这个品类的数据主要来自农业主管部门月度监测报告、全国饲料工业协会的行业调研数据、饲料生产企业公开的产销公告。更新节奏为月度更新核心产销数据，每季度发布深度分析研报。单篇研报文档结构包含核心产能数据、原料成本构成、区域供需分布、政策影响解读四个模块。字段包含配合饲料总产量（万吨）、浓缩饲料产量（万吨）、原料采购均价（元/吨）、区域产量占比（万吨）等，所有数值均带有明确的物理单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据来源分散且更新节奏分层，要求HTTP接口支持多源数据的聚合拉取，同时区分月度增量数据与季度全量研报的拉取模式。单篇研报包含固定结构的四个模块，接口需支持按指定模块精准召回内容，避免返回无关信息。字段带有明确物理单位，接口需同步返回字段的单位元数据，避免下游系统解析错误。单篇研报内容篇幅较长，接口需支持分页参数，控制单次返回的内容长度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `recall_top_k` | `前8-12条` | 饲料研报的核心分析维度集中，过多召回会引入冗余信息，过少则无法覆盖完整分析内容 |
| `api_timeout` | `300 秒` | 季度深度研报的拉取与解析耗时较长，需预留足够的接口响应时间 |
| `ssl_verify_mode` | `跳过自签名证书验证` | 部分内部饲料行业数据源使用自签名证书，该配置可解决连接报错问题 |
| `field_unit_return` | `开启` | 该品类字段带有明确物理单位，开启后可同步返回单位元数据，避免下游系统解析错误 |
| `update_mode` | `增量+全量混合` | 该品类存在月度增量数据与季度全量研报的分层更新节奏，混合模式可兼顾时效性与完整性 |
| `chunk_size` | `1000-1500 字符` | 饲料研报的段落结构清晰，该分段长度可保留完整的分析逻辑，避免截断关键信息 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：HTTP请求返回`SSL certificate problem: self signed certificate in certificate chain`报错，状态码为`495`或`526`。原因：未配置`ssl_verify_mode`为跳过自签名证书验证，直接连接使用自签名证书的内部饲料数据源。
- 现象：调用外部数据源接口返回`404 page not found`报错。原因：未正确配置外部数据源的API路径，或饲料研报的数据源接口路径随季度更新未同步更新配置。
- 现象：接口返回的研报内容被意外截断，未覆盖完整的分析模块。原因：未配置合理的分段与召回参数，或设置了过短的输出限制导致内容被提前截断。

## 怎么确认配好了
- 发起一次测试请求，检查返回的字段是否包含明确的单位元数据，核对字段与饲料研报的核心指标匹配。
- 查看接口返回的响应时长，确认未超过配置的`api_timeout`取值，验证超时配置的有效性。
- 调用增量更新接口，检查仅返回近一个月的饲料产销数据，验证更新模式配置的正确性。
- 发起全量拉取请求，检查返回的内容是否包含四个固定模块，验证召回与分段配置的合理性。
