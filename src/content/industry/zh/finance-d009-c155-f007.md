# 饲料研报检索的工作流编排

## 这个品类的数据长什么样
饲料行业研报数据主要来自农业农村部监测系统、行业协会公开报告、券商农林牧渔研究团队产出品。更新节奏分三类：每日现货行情快报、每周行业供需周报、月度及突发事件驱动的深度分析报告。文档结构包含核心市场指标、供需平衡分析、政策解读与后市展望模块，部分短报告仅包含核心数据摘要，长报告可延伸至产业链上下游联动分析。字段包含原料采购价、配合饲料出厂价、养殖存栏规模等，对应单位分别为元/吨、元/吨、万头。

## 这些特征在「工作流编排」这一环带来什么约束
不同更新节奏的数据源需要配置差异化的定时调度规则，适配每日快报、周报及深度报告的更新周期。文档长度跨度大的特点，要求配置自适应分段解析参数，匹配不同长度文档的解析阈值。多来源的字段单位差异，需要在工作流中嵌入标准化转换节点，统一指标口径。突发事件驱动的临时报告时效性要求更高，需要配置优先级调度逻辑，保障紧急数据的检索响应速度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 饲料研报部分长文档解析耗时较长，600秒可覆盖绝大多数深度报告的解析需求 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 部分深度研报附件包含多张图表与原始数据表格，1000 MB可满足常规上传需求 |
| `maxContext` | `800–1200 字符` | 饲料研报核心指标段落长度集中在该区间，可保障上下文关联的准确性 |
| `召回条数` | `前 10 条` | 饲料行业研报数据源相对集中，过多召回会增加冗余计算 |
| `相似度阈值` | `0.75–0.85` | 需区分行业通用术语与特定饲料品类的专业表述，避免误召回 |
| `重排返回条数` | `前 3 条` | 饲料研报的核心结论相对集中，少量返回即可满足检索需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：在FastGPT 4.14.0及以上版本中，工作流执行上传研报附件时返回`Failed to create post presigned url`报错。原因：未配置对象存储的跨域访问权限，或存储桶的访问策略未开放给工作流执行节点。
- 现象：知识库搜索模块引用变量后，返回的饲料研报结果中自定义字段为空。原因：未在变量赋值环节绑定饲料研报专属的知识库字段映射，或变量引用的路径格式错误。
- 现象：工作流调度后，检索到的饲料研报结果与查询关键词匹配度偏低。原因：相似度阈值配置过高，过滤了部分包含专业术语的有效研报，或未针对饲料行业术语调整召回规则。

## 怎么确认配好了
- 执行单次工作流测试，上传一份标准饲料研报文档，核对解析后的字段是否与原始文档一致。
- 触发定时调度任务，检查不同更新周期的数据源是否按预设时间完成同步与检索。
- 调用工作流测试接口，传入饲料行业专属查询关键词，核对返回结果的条数与匹配度符合预期配置。
- 查看工作流执行日志，确认无`Failed to create post presigned url`类报错，且变量引用环节无异常提示。
