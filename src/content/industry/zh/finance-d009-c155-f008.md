# 饲料研报检索的工具调用与插件

## 这个品类的数据长什么样
饲料研报数据主要来自农业农村部饲料工业管理部门、行业协会公开统计资料，以及专业咨询机构的行业分析报告。更新节奏以月度、季度常规报告为主，伴随行业政策变动、原料价格波动时会发布临时补充文档。文档结构包含行业供需数据、原料价格走势、政策解读、重点企业动态等模块，字段包含原料单价、畜禽存栏量、政策文号、调研样本量等，单篇文档字数多在3000至10000字区间。

## 这些特征在「工具调用与插件」这一环带来什么约束
多来源的数据需要工具调用时区分公开数据源与付费数据源的权限配置，避免因权限不足导致调用失败。固定的月度、季度更新节奏，要求定时触发的工具任务需匹配对应周期，防止重复调用过期数据。复杂的文档结构与多单位字段，需配置字段提取规则适配不同数值单位的解析。单篇文档字数跨度较大，需调整向量模型的分段参数，避免长文本截断丢失核心信息，同时控制单批次调用的文档数量，防止接口超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | `800–1200 字符` | 饲料研报单段信息密度较高，该区间可完整覆盖原料价格、供需数据等核心字段，避免信息截断 |
| `recallTopK` | `前 8–12 条` | 饲料研报涉及多原料、多维度数据，召回过多会增加上下文压力，过少则无法覆盖全量核心信息 |
| `vectorModel` | `按实测标定` | 饲料研报包含大量专业术语与单位字段，需匹配支持农业领域分词的向量模型，具体选型通过测试召回准确率确定 |
| `pluginApiTimeout` | `60 秒` | 部分第三方咨询机构的研报API响应延迟较高，该时长可覆盖多数正常调用场景，避免提前超时 |
| `parseFieldMapping` | `配置原料单价、存栏量等字段的单位转换规则` | 饲料研报中存在元/千克、元/吨等多单位数值，需通过该配置统一输出标准单位 |
| `scheduleCron` | `0 2 1 * * *` | 匹配饲料研报月度常规更新的节奏，确保定时调用获取最新数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用飞书多维表格HTTP插件时返回401状态码，无法成功写入节点输出变量。原因：未在环境变量中配置飞书应用的AccessToken，或配置的密钥权限不足，导致接口鉴权失败。
- 切换向量模型后，知识库召回结果无明显变化。原因：未在`vectorModel`配置项中同步更新模型标识，且未触发知识库重新索引，导致仍使用原模型生成向量。
- 工具调用返回的研报数据中，单位字段为空或格式混乱。原因：未配置`parseFieldMapping`规则，未对不同单位的数值进行统一转换，导致解析失败。

## 怎么确认配好了
- 触发一次工具调用，查看返回的研报数据字段是否包含配置的单位转换结果，核对数值格式是否统一。
- 检查环境变量列表，确认所有插件所需的密钥、API地址均已正确配置，无空值或格式错误。
- 手动修改`vectorModel`配置项，触发知识库重新索引后，查看召回结果的语义匹配度是否符合预期。
- 查看定时任务的执行日志，确认调用时间与`scheduleCron`配置的触发时间一致，无异常延迟或重复调用。
