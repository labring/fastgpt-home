# 黑色家电研报检索的部署与升级

## 这个品类的数据长什么样
黑色家电研报数据主要来自行业协会公开报告、头部品牌官方技术文档、第三方市场调研机构发布的分析内容。更新节奏随新品发布、行业政策调整波动，无固定周期但核心品类研报每季度更新。文档以结构化表格为核心组成部分，包含产品SKU、能效等级、额定功率、市场售价、销量占比等字段，功率单位为千瓦时/年，售价单位为元，部分研报附带竞品参数对比矩阵，单篇文档字数跨度较大。

## 这些特征在「部署与升级」这一环带来什么约束
黑色家电研报的结构化表格占比高、字段单位明确且存在高频检索参数，会对部署与升级环节带来多项约束。解析环节需适配表格结构，否则会丢失核心参数对比信息；字段标准化配置需匹配研报内的单位与字段名，避免检索时出现单位混乱或字段不匹配的问题；非固定更新节奏要求同步配置支持灵活调整触发周期，适配临时发布的新品研报；高频检索字段集中在产品参数类，需针对性配置召回规则，提升检索精准度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_TABLE_ENABLE` | 开启 | 黑色家电研报包含大量结构化表格，开启后可完整保留表格行列结构与字段信息 |
| `UPLOAD_FILE_MAX_SIZE` | 200 MB | 单篇黑色家电研报通常附带多张高清图表，较大上传阈值可完整导入完整文档 |
| `RECALL_FIELD_WHITELIST` | ["SKU", "能效等级", "额定功率", "售价"] | 这些是用户检索黑色家电研报的高频字段，限定后可提升召回精准度 |
| `SYNC_CRON_EXPR` | 0 0 2 * * * | 每日凌晨2点执行同步，适配核心品类每季度更新的节奏，同时可覆盖临时发布的新品研报 |
| `RERANKER_TOP_N` | 前6条 | 黑色家电研报参数密集，6条左右的重排结果可覆盖核心对比维度 |
| `MAX_CHUNK_SIZE` | 800–1200 字符 | 研报内表格段落较长，适中的分块长度可保留上下文关联，避免参数拆分断裂 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：导入JSON格式的黑色家电研报知识库后，系统默认可选知识库列表为空，需手动重新配置。原因：未启用`ENABLE_JSON_KNOWLEDGE_BASE_AUTO_PARSE`参数，针对4.8.22及更早版本，该参数默认未开启，导致JSON元数据未被系统自动识别加载。
- 现象：调用Reranker模型时返回权限错误，无法完成研报内容重排。原因：未正确填写`RERANKER_ACCESS_TOKEN`参数，未从对应模型服务商获取合法的访问令牌，或令牌未绑定对应模型的调用权限。
- 现象：工作流编排时调试面板不显示代码运行步骤的输出内容。原因：未开启`WORKFLOW_DEBUG_SHOW_STEP_OUTPUT`参数，或当前工作流未正确绑定代码执行节点的依赖环境。

## 怎么确认配好了
- 上传单篇包含结构化表格的黑色家电研报，检查解析后的文档是否保留表格的行列结构，确认表格解析配置已生效。
- 手动触发一次知识库同步，查看同步日志中是否显示预设的高频检索字段，确认字段白名单配置正确。
- 启动工作流调试流程，检查代码运行步骤是否显示对应的输出面板，确认调试显示参数已开启。
- 输入针对黑色家电具体参数的检索词，查看召回结果是否匹配目标字段，确认召回配置符合预期。
