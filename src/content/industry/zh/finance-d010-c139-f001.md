# 资质符合性竞价的HTTP 接口与外部系统

## 这个品类的数据长什么样
资质符合性竞价报告的数据主要来源于政府采购公共服务平台、招标方官方发布的招标公告以及行业资质监管数据库。数据更新节奏随招标项目发布实时变动，部分资质证明文件按监管周期更新。文档结构包含项目标识、资质要求条目、符合性判定标准、有效期限、提交时限等核心内容，字段包括`project_id`（项目编号，字符串类型）、`compliance_criteria`（判定标准，文本或枚举类型）、`valid_period`（有效期限，日期类型）、`submit_deadline`（提交截止时间，时间戳类型），部分字段附带单位，如有效期限以“年”或“天”为单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多源数据来源要求接口支持多平台数据拉取的配置，需适配不同平台的接口鉴权规则。实时更新的节奏要求接口同步频率不能过长，否则会错过有效招标项目。字段包含枚举与文本混合类型，要求接口请求参数需严格匹配字段名与格式，不能遗漏核心必填项。部分数据附带附件，要求接口支持文件上传与校验，需配置合理的附件大小限制。另外，资质判定逻辑依赖大模型处理，需将接口与大模型服务绑定，确保调用时可匹配到对应处理能力。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 适配资质证明类附件的常规大小，满足多数招标方文件提交要求 |
| `API_REQUEST_TIMEOUT` | `60 秒` | 覆盖多源招标数据拉取的网络延迟，避免单次请求超时中断 |
| `QUALIFICATION_SYNC_INTERVAL` | `300 秒` | 匹配招标公告实时发布节奏，保障数据时效性 |
| `REQUIRED_SYNC_FIELDS` | `project_id, compliance_criteria, valid_period` | 匹配资质符合性报告的核心必填字段，确保数据完整性 |
| `WEBHOOK_SSL_VERIFY` | `按场景开启` | 适配外部系统的证书配置，解决消息接收地址校验失败问题 |
| `MODEL_BIND_SCOPE` | `自定义配置` | 允许绑定指定大模型处理资质判定逻辑，匹配业务需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用资质符合性接口时返回`400 Bad Request`，提示缺少必填字段。原因：未在`REQUIRED_SYNC_FIELDS`配置中声明核心字段，导致接口校验不通过。
- 现象：部署外部回调接口时提示“消息接收地址校验失败”。原因：未配置公网可访问的接口地址，或未正确设置`WEBHOOK_SSL_VERIFY`参数匹配证书要求。
- 现象：通过openapi配置的模型无法在系统中选中。原因：未将`MODEL_BIND_SCOPE`设置为全局或指定业务场景，导致接口调用无法匹配到对应模型。

## 怎么确认配好了
- 发起单次数据拉取请求，检查返回字段是否包含配置中声明的必填项，核对字段格式与业务要求一致。
- 上传符合常规大小的资质附件，确认接口返回上传成功的状态码。
- 配置回调地址并发起测试请求，确认外部系统可正常接收回调且无校验报错。
- 调用模型绑定接口，验证已配置的模型可被正确检索并调用。
