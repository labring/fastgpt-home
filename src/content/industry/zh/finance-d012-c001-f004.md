# IT 服务营销内容的向量模型与索引

## 这个品类的数据长什么样
IT服务营销内容的来源为厂商自有营销物料库，包含标准化解决方案文档、客户案例汇编、线上推广软文、获客用产品手册、销售跟进话术模板。更新节奏随新品发布、营销活动周期、客户需求调整不定期推进。文档多为结构化与半结构化混合格式，部分包含服务报价框架、交付周期表等表格内容，部分为富文本段落。字段包含服务品类、交付周期、目标客户画像、营销场景标签、版本号。

## 这些特征在「向量模型与索引」这一环带来什么约束
营销内容包含可视化元素与结构化表格，要求向量模型支持多模态嵌入与结构化内容解析，否则会出现嵌入失败或语义丢失。内容更新无固定周期，要求索引系统支持增量触发更新，避免全量重建的资源消耗。字段包含版本号与场景标签，要求索引支持按字段过滤召回，确保仅返回匹配当前营销场景与生效版本的内容。部分文档存在跨渠道重复发布的情况，要求索引内置轻量去重逻辑，避免冗余内容干扰召回结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `embedding_model_type` | `多模态Embedding` | 适配营销物料中包含架构图、流程图等可视化内容的特征，保留视觉语义信息 |
| `index_incremental_trigger` | `按文件更新时间触发` | 适配IT服务营销内容不定期更新的节奏，减少不必要的全量索引重建 |
| `chunk_max_length` | `800–1200 字符` | 平衡段落与表格片段的语义完整性，避免过长文本导致嵌入精度下降 |
| `recall_top_k` | `前6–10条` | 匹配销售线索跟进的信息密度需求，避免冗余内容干扰决策 |
| `vector_db_migration_strategy` | `按版本号映射迁移` | 保留旧版营销内容的向量关联，适配IT服务内容存在版本迭代的特征 |
| `embedding_timeout` | `60 秒` | 适配多模态嵌入的处理时长，避免因超时导致任务失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为接入多模态Embedding模型时测试失败，返回Invalid开头的报错。原因是未针对含可视化元素的营销文档配置多模态嵌入类型，仍使用单模态模型处理内容。
- 现象为升级新版本后voyage索引无法使用，返回400 status code no body。原因是未更新索引字段的格式适配新版本接口要求，传入了空的元数据字段。
- 现象为知识库文件重建索引后旧版本内容仍被召回。原因是未按版本号区分新旧文档的索引关联，未清理旧版向量数据。

## 怎么确认配好了
- 测试包含可视化元素的营销文档，验证多模态Embedding任务无报错，查看嵌入结果的元数据包含视觉特征标识。
- 手动触发一次增量索引，检查索引日志中仅更新了修改后的文件，未触发全量重建。
- 随机抽取旧版和新版营销文档，验证索引召回结果仅包含当前生效版本的内容。
- 调整召回条数参数，验证检索结果的返回条数与配置项匹配。
