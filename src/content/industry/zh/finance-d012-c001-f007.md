# IT 服务营销内容的工作流编排

## 这个品类的数据长什么样
IT服务营销内容的数据来源包括厂商自有营销素材库、公开技术文档、客户需求整理文档。更新节奏随产品迭代、营销活动调整变动，无固定周期，单次更新覆盖单条或多条素材。文档结构多为结构化字段搭配富文本内容，字段包含素材ID、素材类型（如方案白皮书、产品介绍页）、适用客户场景、发布时间、素材内容、关联产品型号，其中素材ID为字符串格式，发布时间采用ISO时间戳，素材内容长度从数百到数万字符不等。

## 这些特征在「工作流编排」这一环带来什么约束
IT服务营销素材的多样类型要求工作流配置分支判断节点，区分方案白皮书、产品介绍页等不同素材的处理逻辑；无固定更新周期的特点，要求工作流支持增量触发机制，避免重复处理旧素材；关联产品型号字段的存在，要求工作流嵌入字段映射步骤，将该字段作为知识库检索的过滤条件；素材内容长度跨度大的特点，要求配置分段处理参数，平衡上下文完整性与检索效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `knowledgeSearch.filterTags` | `["IT服务", 关联产品型号字段值]` | 匹配IT服务品类的营销素材关联的产品型号，精准召回相关知识库内容 |
| `workflow.triggerMode` | 增量触发 | 适配IT服务营销素材无固定更新周期的特点，仅处理新增或修改的素材，避免冗余执行 |
| `segmentMaxLength` | `800–1200 字符` | 适配IT服务方案白皮书、产品介绍页等素材的内容长度，平衡上下文完整性与检索效率 |
| `apiRequestTimeout` | `600 秒` | IT服务营销素材内容较长，处理与知识库交互的流程需预留足够超时时间，避免中途中断 |
| `workflow.nodeBranchCondition` | 按素材类型分支 | 区分不同类型的营销内容，配置差异化的后续处理逻辑 |
| `knowledgeBaseId.dynamicSource` | 关联素材的产品分类字段 | 根据素材关联的产品分类动态选择对应知识库，避免跨品类检索干扰 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为工作流调用知识库时提示“未找到匹配文档”，或AI返回结果未引用上传的营销素材。原因是未将动态传入的知识库过滤参数正确绑定到`knowledgeSearch.filterTags`配置项，导致检索范围未覆盖目标素材。
- 现象为工作流重复处理已处理过的IT服务营销素材。原因是未配置`workflow.triggerMode`为增量触发，仍使用全量触发模式。
- 现象为工作流执行超时中断。原因是未根据素材长度调整`apiRequestTimeout`的取值，使用默认短超时时间无法完成长文档的处理与检索。

## 怎么确认配好了
- 上传一条测试用IT服务营销素材，查看工作流触发日志，确认仅新增素材被处理。
- 在工作流测试面板中传入测试用关联产品型号字段值，检查知识库检索节点的过滤参数是否正确加载。
- 上传长文本测试素材，查看分段处理日志，确认分段参数按配置生效。
- 触发包含长文档处理的测试流程，验证流程未因超时中断。
