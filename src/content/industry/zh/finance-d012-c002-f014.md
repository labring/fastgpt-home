# 专业服务营销内容的表单与交互

## 这个品类的数据长什么样
金融专业服务的营销相关数据主要来自客户提交的风险测评表单、过往资产持仓记录、线下咨询对话记录。数据更新节奏分为两类：客户主动提交的信息实时更新，第三方同步的持仓数据每日更新，咨询对话记录实时存储。文档结构包含结构化字段与非结构化文本两类：结构化字段包括风险承受能力等级、可投资资产规模、咨询频次；非结构化文本包括客户咨询诉求、顾问回复内容。字段与单位有明确规范：风险等级以R1至R5为单位，资产规模以万元为单位，咨询时长以分钟为单位。

## 这些特征在「表单与交互」这一环带来什么约束
结构化字段占比高，要求表单环节支持字段校验与格式限制，例如资产规模必须为正整数，风险等级只能选择预设选项，避免无效输入。非结构化对话占比高，要求交互环节支持上下文记忆与多轮衔接，避免重复提问相同信息。数据包含客户隐私信息，要求表单与交互环节具备权限校验与数据加密机制，仅授权用户可访问对应内容。数据更新频率较高，要求交互环节支持实时加载最新的客户数据与知识库内容，确保营销内容贴合当前客户状态。专业服务诉求复杂，要求输入引导词精准覆盖核心信息点，避免用户输入模糊内容影响后续处理。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `enable_input_guide` | `true`，配置分阶段引导词 | 专业服务需引导用户提供风险等级、资产规模等精准信息，分阶段引导避免信息过载 |
| `custom_kb_url` | 指向私有合规存储的知识库地址 | 专业服务数据含客户隐私，私有地址可避免数据泄露风险 |
| `variable_parse_mode` | `strict_json` | 专业服务表单变量多为结构化字段，严格JSON解析可避免`quote type error`报错 |
| `llm_channel` | `custom`，绑定GPT-4o或Claude 3.5 Sonnet | 专业服务咨询需高阶模型的逻辑推理与信息整合能力，自定义渠道可切换至高性能模型 |
| `rerank_provider` | `custom`，接入Jina Rerank服务 | 专业服务知识库文档多为长文本，重排服务可提升召回内容的精准度 |
| `request_timeout` | `300 秒` | 专业服务咨询可能涉及多轮交互与长文档解析，较长超时可避免中途中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 开启`enable_input_guide`并配置`custom_kb_url`后，调试预览出现`400 Bad Request`报错。原因是自定义知识库地址未添加平台允许的跨域来源，导致请求被拦截。
- 知识库变量引用时出现`quote type error`报错。原因是变量未使用标准双引号包裹，或未开启`strict_variable_parse`配置。
- 在线版可选择的大模型与官方介绍不一致，切换失败。原因是未将`llm_channel`设置为`custom`并绑定对应模型的API密钥，默认渠道仅开放基础通用模型。

## 怎么确认配好了
- 进入调试预览界面，触发输入引导词，界面显示预设的分阶段提示词，确认`enable_input_guide`配置生效。
- 输入包含变量的测试语句，检查是否出现`quote type error`报错，确认`variable_parse_mode`配置正确。
- 在模型配置页面切换至`custom`渠道，输入GPT-4o或Claude 3.5 Sonnet的API密钥，确认在线版模型列表中显示对应型号。
- 发起包含长文本的测试请求，检查请求未在300秒内中断，确认`request_timeout`配置生效。
