# 专业服务营销内容的部署与升级

## 这个品类的数据长什么样
专业服务营销内容的数据主要来自内部合规审核后的营销物料、脱敏客户服务案例、标准化理财咨询话术及合规公告。数据更新节奏随合规要求调整、新产品上线或营销活动启动不定期触发。文档结构多包含固定字段，如产品合规编号、生效日期、适用客群范围，部分物料内嵌合规宣传图片与表格。单份文档长度跨度较大，短则数百字的话术提示，长则数千字的合规解读手册。

## 这些特征在「部署与升级」这一环带来什么约束
专业服务营销内容的特征对部署与升级环节带来多重约束。数据来源分散在不同部门的共享存储或合规系统中，部署阶段需配置跨源数据同步规则，避免遗漏产品合规编号、生效日期等固定字段。更新节奏无固定周期，升级环节需支持增量同步，不采用全量重建，以减少合规内容的重复审核成本。内嵌图片与长文档占比高，解析阶段需适配大文件上传与多模态内容解析，避免出现部分内容无法识别的问题。同时，专业服务内容的合规性要求较高，升级环节需同步更新合规校验规则，确保新增内容符合监管要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 适配专业服务营销内容中内嵌高清合规宣传图与长文档的上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 满足数千字合规解读手册的解析时长要求 |
| `分段长度` | `800–1200 字符` | 保留理财咨询话术与合规内容的上下文连贯性 |
| `召回条数` | `前 5–7 条` | 精准匹配用户咨询的营销场景，避免冗余内容干扰 |
| `相似度阈值` | `0.75–0.85` | 平衡召回精准度与覆盖范围，防止合规内容被错误召回 |
| `重排返回条数` | `前 3 条` | 简化营销内容输出，适配终端展示需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为备份导出的知识库仅生成单个CSV文件，导入后丢失多附件关联关系；原因是未开启`ENABLE_MULTIFILE_BACKUP`配置项，默认导出仅打包核心元数据。
- 现象为部分文档无法识别内嵌图片，返回状态码`413 Request Entity Too Large`；原因是`UPLOAD_FILE_MAX_SIZE`配置值小于图片文件实际大小。
- 现象为启动后无法连接第三方AI接口，报错`500 Internal Server Error`；原因是未适配新版`AI_PROXY`配置规则，仍沿用v4.13.0及之前版本的`ONE_API`环境变量。

## 怎么确认配好了
- 执行知识库备份操作，检查导出文件是否包含多附件的关联元数据，确认无单个CSV打包丢失内容的情况。
- 上传包含内嵌图片的合规营销文档，等待解析完成后查看预览内容，确认图片文本与描述已被正确提取。
- 配置第三方AI接口后发起测试调用，确认返回结果无`500`类报错，接口连接正常。
- 发起相似内容召回测试，验证返回条数与相似度符合预设的`召回条数`与`相似度阈值`配置。
