# 专业连锁营销内容的模型接入与配置

## 这个品类的数据长什么样
金融/保险/理财领域专业连锁的营销内容数据来源包括总部统一品牌素材库、各门店自主编辑的区域保险/理财促销物料、会员触达文案及线下活动宣传资料。数据更新节奏分为两类：总部统一素材按固定周期更新，门店自主物料随临时促销活动随时更新。单篇营销内容的文档结构包含品牌标识、活动主题、适用门店范围、生效时段、投保/认购门槛、联系方式等字段，部分内容附带门店专属的二维码或地址信息，字段包含门店ID（字符串格式）、活动有效期（日期格式）、投保门槛（数字单位）、素材格式（文本/图片/视频）。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的营销数据结构要求接入配置支持多数据源绑定与权限隔离，确保总部与门店的内容不会混淆。投保/认购门槛、门店ID等结构化字段要求配置时开启字段映射校验，确保模型调用时能正确读取并传递门店专属参数。临时更新的营销物料要求配置较短的内容缓存时长，避免调用过时的活动信息。多格式的营销素材（文本、图片、投保规则文本）要求配置多模态模型的兼容参数，适配不同类型的输入输出需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 字符 | 金融/保险/理财领域的专业连锁营销内容多包含完整产品规则与门店信息，较长的上下文窗口可避免截断关键投保/认购规则等核心内容 |
| `modelApiTimeout` | 30 秒 | 金融/保险/理财领域的专业连锁营销内容调用多为实时触达场景，30秒可覆盖多数模型响应与数据拉取的总耗时 |
| `recallCount` | 前 8–12 条 | 区域聚合的营销内容无需过多召回，8-12条可覆盖单门店近期的有效活动信息，同时降低模型推理负担 |
| `enableDynamicDataSync` | 每 1 小时同步 | 门店临时促销活动更新频率较高，每小时同步可确保模型调用的内容为最新有效状态 |
| `fieldMappingConfig` | 映射门店ID、活动有效期、投保门槛 | 营销内容需绑定门店专属参数，字段映射可确保模型调用时传入正确的门店维度信息，避免跨门店内容混淆 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 营销物料可能包含高清图片或长文本素材，600秒可完成完整的内容解析与向量化处理 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用模型时未返回思维链内容，仅返回最终回答。原因：未开启`enableThoughtChain`配置项，或未在模型渠道设置中勾选返回思维链的选项。
- 现象：模型调用返回504网关超时错误。原因：设置的`modelApiTimeout`时长过短，未覆盖营销物料解析与模型响应的总耗时。
- 现象：不同门店调用模型时返回了其他区域的营销内容。原因：未配置`fieldMappingConfig`，未传入门店ID参数，导致模型调用未过滤区域专属内容。

## 怎么确认配好了
- 发起带门店标识参数的测试调用，核对返回内容仅包含对应门店范围内的营销信息，核对逻辑可根据配置的区域过滤规则调整。
- 查看模型调用的日志，确认响应时长未超过配置的超时阈值，阈值根据实际业务的响应要求设定。
- 临时更新一条营销物料的生效时间，等待配置的同步周期结束后再次调用，核对返回内容为更新后的版本。
- 测试多格式的营销物料输入，确认模型可正确解析并生成符合要求的营销内容，适配规则根据物料的格式类型设定。
