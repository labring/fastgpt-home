# 休闲食品营销内容的表单与交互

## 这个品类的数据长什么样
针对金融、保险、理财领域的休闲食品营销场景，相关数据主要来自品牌自有SKU管理系统、电商平台后台销售台账、线下门店动销记录及用户互动问卷。数据更新节奏随新品上市、促销活动调整，常规SKU信息月度更新，临时促销标签随活动周期生效。单条数据文档包含产品名称、规格型号、口味分类、净含量、配料清单、建议售价、适配食用场景等字段，其中净含量单位为克或千克，口味分类多为枚举型固定选项，促销活动字段为临时挂载的非必填项。

## 这些特征在「表单与交互」这一环带来什么约束
针对金融、保险、理财领域的休闲食品营销场景，数据特征对表单与交互环节形成多重约束。SKU信息包含固定枚举类字段，表单需预设下拉选项供选择，避免自由输入导致的字段不统一。临时促销挂载字段随营销活动动态变化，表单需支持动态增删配置项，无需每次调整都修改底层表单结构。净含量的固定单位要求表单自动关联单位选项，无需用户手动输入，减少输入误差。短文本互动反馈的高频使用场景，要求表单集成语音转文字功能，适配不同用户的输入习惯。产品实拍图上传的需求，要求表单限制文件格式与单文件大小，减少无效上传的概率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `VOICE_RECOGNITION_MODEL` | `SenseVoiceSmall` | 适配短语音转写场景，满足休闲食品营销表单的用户反馈录入需求 |
| `FORM_FIELD_DYNAMIC_SWITCH` | `开启` | 支持动态增删临时促销字段，无需每次调整营销活动都修改底层表单结构 |
| `UPLOAD_FILE_ALLOWED_TYPES` | `image/jpeg, image/png, image/webp` | 覆盖休闲食品营销表单常用的产品实拍图格式，避免无效上传 |
| `UPLOAD_FILE_MAX_SIZE` | `5 MB` | 匹配单张产品实拍图的常规大小，减少上传耗时与存储占用 |
| `FORM_INPUT_MAX_LENGTH` | `800–1200 字符` | 限制短文本反馈的输入长度，过滤无效长内容提交 |
| `TOOL_SELECTION_MODEL` | `gpt-4o-mini` | 轻量化模型可快速完成工具选择，适配高级编排中的工具调用需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：表单集成语音识别功能时，无法在模型列表中选择`SenseVoiceSmall`，提交后语音转写功能失效。原因：未在系统设置中开启对应模型的权限，或当前版本`saas4.9`未内置该模型的适配配置。
- 现象：营销表单中嵌入的基础图表插件输入正确参数后，输出结果为`none`，无法生成图表URL。原因：未配置插件的依赖接口权限，或插件调用超时时间设置过短，导致请求未完成即返回空结果。
- 现象：高级编排中配置工具调用时，无法正确触发后续工具执行任务。原因：未指定`TOOL_SELECTION_MODEL`参数，或选择的模型不支持工具调用能力。

## 怎么确认配好了
- 进入表单编辑界面，查看语音识别模型的可选列表，验证语音录入后是否可正常转写为文本内容。
- 上传一张符合预设格式的产品实拍图，确认上传流程正常完成，提交后表单字段可正确关联上传的文件。
- 在高级编排页面配置工具调用，选择预设的工具选择模型，触发测试调用，确认工具可被正常选中并执行。
- 输入超出预设长度限制的测试文本，检查表单是否会弹出输入超限提示，或自动截断超出部分的内容。
