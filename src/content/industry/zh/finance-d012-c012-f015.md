# 住宅开发营销内容的部署与升级

## 这个品类的数据长什么样
住宅开发营销相关数据主要来自售楼处运营台账、官方户型图PDF、预售证公示文件、周边配套区位图、楼书长文档及朋友圈营销文案。数据更新节奏随项目节点变化：开盘前每周更新预售证、样板间开放时间等信息，开盘后每月更新销售去化数据与线下活动安排。文档结构包含结构化表格（预售证信息、户型参数表）与非结构化文本（楼书、活动文案），字段包含`建筑面积`、`套内面积`（单位均为平方米）、`预售证号`、`开盘时间`、`周边配套距离`（单位为米）等固定属性。

## 这些特征在「部署与升级」这一环带来什么约束
结构化与非结构化混合的数据类型，要求部署时同时配置文档解析模块与结构化数据接入接口，避免单一解析规则无法适配全部物料。高频更新的项目节点数据，要求升级时支持增量同步配置，无需每次全量重新上传全部营销物料。固定字段与单位的要求，需要在部署阶段配置字段校验规则，防止解析后的文本出现单位混淆或字段缺失。长文本楼书与短文案并存的内容形态，要求升级时保留分段与召回的差异化配置，避免统一规则导致短文案匹配失效或长文本解析不完整。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 住宅开发的户型图、楼书PDF单文件通常不超过800MB，预留合理冗余空间 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 大型楼书PDF解析需要较长处理时间，避免因超时导致解析失败 |
| `maxContext` | `800–1200 字符` | 匹配住宅营销核心信息的上下文长度需求，兼顾召回精度与响应速度 |
| `召回条数` | `前 3–5 条` | 营销内容匹配无需过多冗余结果，聚焦核心匹配项 |
| `相似度阈值` | `0.75–0.85` | 平衡匹配精度与覆盖范围，避免无关配套数据混入营销内容召回结果 |
| `分段长度` | `1500 字符` | 适配楼书长段落的信息密度，保证单分段内包含完整的户型或配套描述 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 出现`SSL certificate verify failed`报错，无法正常对外提供服务。原因是本地部署时未将SSL证书文件挂载到FastGPT容器的指定目录，导致服务无法读取证书文件。
- 升级至新版本后，`V4.6.7`版本配置的联网插件无法正常调用。原因是升级时未保留原有插件的环境变量配置，导致联网功能依赖的密钥丢失。
- Windows Server 2022环境下docker部署启动失败，返回`container start failed`错误。原因是未正确配置宿主与容器的端口映射，导致80或443端口被其他进程占用。

## 怎么确认配好了
- 上传单份100MB以上的户型图PDF，检查解析任务状态是否在`PARSE_FILE_TIMEOUT_SECONDS`设置的时长内完成。
- 发起包含「户型面积」的查询，检查返回结果的字段是否包含`建筑面积`、`套内面积`等预设字段，无缺失或异常值。
- 重启FastGPT服务后，检查SSL证书相关日志是否无报错，可通过浏览器访问绑定的域名验证证书有效性。
- 升级后检查知识库的`召回条数`配置是否与升级前一致，避免被默认配置值覆盖。
