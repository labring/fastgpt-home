# 光伏营销内容的文档解析与分块

## 这个品类的数据长什么样
来源包括光伏设备厂商的官方营销物料、经销商推广素材、行业营销案例汇编；更新节奏随新品发布、政策调整不定期更新，新品上线时更新频率较高；文档结构多为混合格式，既有结构化的参数表格，也有大段场景化营销文案、招商政策条款，部分文档嵌入产品实拍图、参数对比图表；字段包含产品型号、额定功率、质保年限、适用场景、招商政策细则等，单位多采用行业通用的W、kW、mm等。

## 这些特征在「文档解析与分块」这一环带来什么约束
混合格式的光伏营销文档同时包含结构化参数表格与非结构化营销文案，分块时需避免破坏参数与对应产品的关联逻辑；招商政策、场景介绍类长文本占比高，需保障分块后语义完整，避免拆分政策条款导致逻辑断裂；部分文档嵌入产品参数对比图表，无法直接提取图表内的数值，需保留图表上下文的文本块，确保后续检索可关联到参数信息；离散的型号与功率等参数字段，需在分块时保留字段间的对应关系，避免拆分后无法还原参数关联。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunk_size` | 800–1200 字符 | 光伏营销文档包含长文本政策与结构化参数，该区间可兼顾长文本语义完整性与参数块的紧凑性 |
| `chunk_overlap` | 100–150 字符 | 保障相邻分块间的语义衔接，避免拆分长文案或参数说明时出现逻辑断层 |
| `parse_pdf_mode` | `accurate` | 光伏营销文档常包含参数表格与嵌入图表，该模式可完整提取表格内的离散参数 |
| `max_parse_file_size` | 500 MB | 适配光伏企业批量上传的大型招商手册与行业白皮书，避免因文件过大导致解析失败 |
| `parse_timeout` | 120 秒 | 大型文档解析需更长处理时间，避免因超时中断解析流程 |
| `parse_docx_keep_table_structure` | 开启 | 保留参数表格的行列结构，确保后续分块时可完整保留型号与功率的对应关系 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：本地环境上传文件可正常解析，服务器部署后上传文件触发404错误，解析节点无法获取文件内容。原因：服务器部署时未配置静态文件托管路径，或上传文件的存储目录未开放读写权限，导致解析节点无法访问上传的文件。
- 现象：使用Vllm0.10部署Qwen3-14B时，无法从解析结果中提取光伏参数字段，返回空字段或格式混乱。原因：该模型版本对结构化离散参数的识别适配性不足，未针对光伏行业的参数格式做优化，导致无法准确提取业务字段。
- 现象：批量上传光伏营销文档后，部分分块丢失参数与对应产品的关联关系。原因：分块时未保留相邻参数块的上下文，拆分了参数表格与产品说明的绑定关系，导致后续检索无法关联参数与产品信息。

## 怎么确认配好了
- 上传一份包含结构化参数表格与长文案的光伏营销文档，检查解析结果是否完整提取表格内的业务字段。
- 查看分块结果，确认长文本内容未被拆分为语义不完整的片段。
- 测试不同规模的文档上传，确认解析流程未因文件超出配置上限触发失败。
- 核对解析超时配置，确认大型文档的解析流程未在配置的超时时间前中断。
