# 光学光电子营销内容的表单与交互

## 这个品类的数据长什么样
光学光电子品类的数据主要来自生产MES系统、供应链ERP、产品检测台账与经销商库存系统。生产过程中的光学参数检测数据随生产批次实时更新，库存与销售台账数据每日同步更新。单份产品文档以结构化规格表为主，包含型号、焦距、视场角、透光率、工作温度等字段，单位分别为mm、°、%、℃，部分定制化产品会附带CAD图纸与测试报告附件。

## 这些特征在「表单与交互」这一环带来什么约束
光学光电子品类的专业参数多且单位严格，导致表单需按产品类型动态加载字段，避免非专业用户手动输入错误参数。生产批次与库存数据的实时/定时更新特性，要求表单关联产品数据库自动带出预设规格，减少重复录入。光学文档多为大体积CAD或测试报告，要求表单支持大文件上传并校验格式。营销获客场景下，需区分零售与批量采购的交互流程，批量采购用户需额外提交采购量与应用场景字段。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `FORM_FIELD_DYNAMIC_LOAD` | `开启` | 光学光电子产品参数维度多，按选型类型动态加载字段可降低填写门槛 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 光学CAD图纸与测试报告体积普遍较大，需适配大文件上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 大体积光学文档解析耗时较长，延长超时时间避免解析中断 |
| `FORM_FIELD_PRESET_UNIT` | `开启` | 光学参数单位要求严格，预设单位可避免手动输入错误 |
| `WORKFLOW_FORM_DISPLAY_CONDITION` | `按产品分类触发对应字段` | 区分零售与批量采购场景，优化交互逻辑 |
| `FORM_SUBMIT_NOTICE_WEBHOOK` | `配置企业微信或邮件推送` | 营销获客表单需及时同步线索，保障后续跟进效率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流中配置的表单字段在对话界面无显示。原因：未开启`WORKFLOW_FORM_DISPLAY_CONDITION`的全局开关，或显示条件未匹配用户输入的产品类型。
- 现象：营销表单提交后无线索同步通知。原因：未配置`FORM_SUBMIT_NOTICE_WEBHOOK`，或webhook地址校验失败导致推送中断。
- 现象：上传的光学测试报告解析失败并返回超时错误。原因：`PARSE_FILE_TIMEOUT_SECONDS`设置值小于实际解析耗时，或上传文件超过`UPLOAD_FILE_MAX_SIZE`限制。

## 怎么确认配好了
- 进入高级编排的表单编辑器，选择对应产品分类，验证字段是否自动加载预设参数与单位。
- 提交一条测试表单，查看是否触发`FORM_SUBMIT_NOTICE_WEBHOOK`的推送通知，确认线索同步正常。
- 上传一份符合品类特征的大体积光学文档，验证上传与解析流程是否正常完成。
- 在对话界面触发表单交互，确认不同产品类型下的字段显示逻辑符合预设配置。
