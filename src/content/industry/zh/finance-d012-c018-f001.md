# 光模块营销内容的HTTP 接口与外部系统

## 这个品类的数据长什么样
面向金融行业的光模块营销内容的数据主要来源于厂商官方发布的产品规格书、营销白皮书、行业测试报告及公开技术文档。核心数据包含传输速率、传输距离、接口类型、工作温度范围、功耗等结构化参数，以及应用场景、认证信息、宣传话术等非结构化内容。文档格式以PDF为主，部分包含多页嵌套表格与图文混排结构。参数字段均带有严格的单位定义，例如传输速率单位为Gbps，传输距离单位为km，工作温度单位为℃。新型号光模块的参数更新随量产周期推进，营销物料则随市场推广计划调整，无固定更新周期。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
面向金融行业的光模块营销数据的结构化参数多且单位严格，要求HTTP接口的请求参数需匹配`传输速率`、`传输距离`等固定字段名，且需携带对应单位，避免参数解析错误。PDF格式的规格书包含多页嵌套表格，要求外部解析系统支持跨页表格提取与结构化字段分离，防止核心参数遗漏。新型号迭代周期较长但营销物料更新无固定节奏，要求外部同步机制支持按需拉取，避免固定周期全量同步带来的不必要带宽占用。部分营销物料混有技术参数与宣传文本，要求接口支持结构化字段与非结构化内容的分别提取，适配不同的业务调用需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 光模块规格书PDF通常包含多页参数表格，解析耗时较长，300秒可覆盖完整解析流程 |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 单份光模块营销规格书PDF通常不超过50 MB，超出该范围会增加HTTP接口的负载压力 |
| `TEXT_SPLIT_CHUNK_SIZE` | `800–1200 字符` | 光模块参数字段多为短文本，分段过长会影响召回精度，过短会增加接口调用次数 |
| `API_REQUEST_RETRY_TIMES` | `3 次` | 光模块厂商官网接口可能存在临时波动，3次重试可覆盖多数临时故障 |
| `EMBEDDING_BATCH_SIZE` | `前 20 条` | 光模块营销数据的结构化参数条目较多，批次过大易导致嵌入接口超时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：离线环境上传光模块营销PDF后界面持续显示加载状态，联网后流程恢复正常。原因：部分光模块厂商的产品文档内嵌外链资源，离线环境无法访问，导致文件解析流程阻塞。
- 现象：调用文本嵌入接口返回`400 Bad Request`，提示参数格式不合法。原因：未严格遵循光模块参数的字段与单位规则，例如将`传输速率`的单位`Gbps`误写为`Mbps`，触发接口校验失败。
- 现象：导入光模块营销内容的工作流模板后，画布无任何节点显示。原因：模板中包含非标准的结构化参数定义，无法被系统正确解析加载。

## 怎么确认配好了
- 上传单份光模块规格书PDF，查看解析后的结构化参数列表，确认核心字段与单位是否与原始文档一致。
- 调用HTTP接口发起测试请求，检查返回的结构化数据是否包含光模块营销内容的全部必要参数。
- 模拟离线环境发起文件上传请求，确认流程不会出现无响应的阻塞状态。
- 调整配置项的取值范围，验证接口重试次数、分段长度等参数是否适配当前光模块营销数据的解析需求。
