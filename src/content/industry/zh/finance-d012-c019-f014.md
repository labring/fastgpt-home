# 免税营销内容的表单与交互

## 这个品类的数据长什么样
免税营销相关数据主要来自免税运营商官方商品库、离岛免税政策公告文档、金融机构合作的离岛购物用户表单、免税分期产品参数库。商品SKU与分期产品数据每周同步更新，政策类文档随监管要求不定期调整，用户提交的表单数据实时入库。单条商品文档包含商品名称、完税价格、免税售价、单次限购额度、适用离岛人群范围等字段，字段单位统一为人民币元、件、人次，政策文档则包含政策生效时段、适用区域、额度限制细则。

## 这些特征在「表单与交互」这一环带来什么约束
商品SKU与分期产品的每周更新特性要求表单中的商品、产品选择组件需对接实时同步的数据源，避免出现已下架商品或停售分期产品仍可选择的情况。政策文档的不定期调整特性要求交互中的政策提示弹窗需支持后台快速更新，无需修改前端代码逻辑。用户提交的表单数据实时特性要求表单需添加实时校验逻辑，对单次购物额度、离岛身份信息、分期资质进行前置校验，减少无效提交。字段单位的统一要求需在表单输入框中添加单位提示，避免用户填写错误的数值单位，同时在交互反馈中明确展示校验依据的单位规则。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 免税营销内容通常包含商品详情、政策细则、分期规则，该区间可覆盖多数场景的上下文需求，避免超出模型输入上限 |
| `FORM_FIELD_MAX_LENGTH` | `200 字符` | 免税表单的咨询、备注字段通常无需过长输入，该长度可过滤无效长文本提交 |
| `RECALL_TOP_K` | `前6条` | 免税政策与商品信息表述规范，过多召回会导致上下文冗余，6条可覆盖核心信息需求 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 免税相关文档的语义一致性较强，该阈值可过滤低相关的召回结果，提升交互准确性 |
| `UPLOAD_FILE_MAX_SIZE` | `100 MB` | 免税政策文档、商品手册单文件体积通常较小，该设置可避免过大文件导致的导入失败 |
| `FORM_SUBMIT_TIMEOUT` | `10 秒` | 免税表单包含实时额度校验与资质验证逻辑，10秒可覆盖多数网络环境下的校验与提交耗时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 未配置`maxContext`超限拦截，当用户提交过长的营销文案或咨询内容时，直接触发模型输入上限报错，返回错误码`413`。原因是未提前设置上下文长度校验，将模型原生报错直接暴露给用户。
- 在知识库搜索卡片中未正确绑定表单变量，导致检索时无法匹配免税商品或政策的专属信息。原因是未将表单提交的离岛区域、商品类型等字段值作为检索参数传入搜索节点。
- 知识库导入PDF文档时未调整切块参数，导致免税商品手册的长段落被错误拆分，召回的政策条款不完整。原因是未针对免税文档的长文本结构调整切块长度，丢失关键信息。

## 怎么确认配好了
- 提交超过`maxContext`限制长度的测试文本，确认系统弹出预设的超限提示，不弹出原生报错。
- 在表单中选择已下架的测试商品或停售分期产品，确认组件自动过滤该选项，无法完成选择。
- 上传单份体积超过`100 MB`的测试文件，确认系统弹出文件过大的提示，阻止导入。
- 在表单中填写非人民币的数值，确认系统弹出单位错误的校验提示，阻止提交。
