# 兵器装备营销内容的HTTP接口与外部系统

## 这个品类的数据长什么样
兵器装备营销内容的数据主要来自国防军工领域的官方定型报告、公开外贸装备宣传资料、装备性能参数手册及配套维护文档，多用于金融机构军工主题理财、保险产品的营销获客场景。数据更新节奏稳定，仅在装备定型、重大改型或年度营销物料更新时调整，无高频迭代需求。文档多为结构化与非结构化混合格式，包含装备型号、定型时间、性能指标、使用场景、适配系统等字段，单位以公制为主，部分保留传统军用单位。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
兵器装备营销内容的数据来源具有官方权威性，且金融机构使用该类数据需符合金融广告合规要求，因此HTTP接口需配置双向身份验证机制与数据脱敏选项，避免未授权访问或违规使用敏感信息。数据更新频率低但存在版本差异，接口需支持按装备型号拉取最新版本的内容，同时保留版本标识字段。文档包含结构化性能参数与非结构化宣传文本，接口需同时支持结构化字段解析与多格式文档解析能力。字段单位多为公制与军用单位混合，接口需提供单位转换配置项，确保输出格式统一，符合金融营销内容的展示规范。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `API_AUTH_TOKEN` | 与授权数据源约定的固定令牌 | 兵器装备数据涉及合规要求，需通过令牌验证访问权限 |
| `REQUEST_TIMEOUT` | `600 秒` | 兵器装备营销文档包含多章节内容，解析耗时较长，默认超时不足以完成完整解析 |
| `DATA_SYNC_INTERVAL` | `86400 秒` | 兵器装备营销内容更新频率低，每日同步一次即可覆盖版本更新需求 |
| `PARSE_DOC_UNIT_CONVERT` | `开启，默认公制单位` | 兵器装备数据同时包含公制与军用单位，需统一转换为标准格式 |
| `VERSION_CHECK_ENABLE` | `开启` | 需按装备型号拉取最新版本的营销内容，避免使用过时数据 |
| `MAX_RESPONSE_FIELD_SIZE` | `20000 字符` | 兵器装备营销文档包含详细性能参数与使用场景，需支持长文本返回 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 接口返回结果中包含未预期的`[QUOTE]`格式引用标记，状态码返回200但内容存在冗余标识。原因：未配置`REMOVE_CITE_MARK`参数，或参数取值未正确开启引用移除功能。
- 接口调用超时，状态码返回504。原因：未调整`REQUEST_TIMEOUT`参数，兵器装备文档解析耗时超出默认超时限制。
- 返回的性能参数字段单位不统一，同时出现毫米与英寸标识。原因：未开启`PARSE_DOC_UNIT_CONVERT`参数，或未指定转换目标单位。

## 怎么确认配好了
- 调用配置好的HTTP接口，检查返回结果中无身份验证错误提示，确认访问权限配置生效。
- 对比同步后的营销内容与官方数据源的最新版本，确认版本标识字段正常更新，验证版本检查功能生效。
- 检查返回的性能参数字段的单位格式统一，确认单位转换配置生效。
- 调用接口获取多章节的装备营销文档，确认返回内容未被截断，验证长文本返回配置符合需求。
