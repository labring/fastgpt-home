# 兵器装备营销内容的工作流编排

## 这个品类的数据长什么样
兵器装备营销内容的数据来源包括装备研制单位的官方技术文档、官方宣传物料、政府采购招标公示；更新节奏为新装备定型、年度宣传物料改版时批量更新，配合临时营销活动的单次更新；文档结构多为结构化参数表加场景化说明文本，包含`装备型号`、`作战性能参数`、`适用场景`、`合规审批标识`等字段，部分参数带有明确物理单位，比如千米、千克、发/分钟。

## 这些特征在「工作流编排」这一环带来什么约束
结构化参数与带物理单位的字段要求工作流配置参数类型校验规则，避免单位混用或参数缺失；多来源数据需要配置数据源权限校验节点，区分内部宣传物料与公开招标信息的调用权限；不定期更新节奏要求工作流支持定时同步与手动触发两种更新模式，适配临时营销活动的物料需求；合规审批标识字段要求工作流在营销内容生成前自动校验该字段状态，未通过审批的物料无法进入后续生成环节。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `知识库ID动态绑定` | 通过全局变量`workflow_kb_id`传入 | 适配不同装备品类的知识库调用需求，避免硬编码固定ID |
| `知识库召回阈值` | `0.75–0.85` | 兵器装备参数类内容需较高匹配精度，避免无关装备信息混入营销内容 |
| `全局变量赋值规则` | 优先取工作流传入参数，未获取到则使用插件默认值 | 适配营销内容中动态替换装备型号、参数的需求，同时保障基础功能可用 |
| `知识库同步频率` | `每日凌晨2点 + 手动触发` | 适配新装备定型、年度改版的批量更新节奏，兼顾实时性与资源占用 |
| `工作流节点超时时间` | `600 秒` | 兵器装备文档通常篇幅较长，参数解析与召回需要较长处理时长 |
| `合规校验节点触发条件` | 在营销内容生成节点前执行 | 保障未通过审批的装备物料无法进入生成环节，符合合规要求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用知识库搜索时提示“未找到匹配知识库”或“参数非法”。原因：未通过全局变量正确传入知识库ID，或传入的ID与当前工作流绑定的知识库不匹配。
- 现象：工作流中插件参数无法从指定变量获取，回退到默认值未生效。原因：未正确配置全局变量的赋值优先级，或变量命名与插件参数绑定的变量名不一致。
- 现象：生成的营销内容中出现单位错误或参数缺失。原因：未配置参数类型校验规则，未校验装备参数的单位与字段要求，导致混入不匹配的内容。

## 怎么确认配好了
- 手动触发工作流，传入测试用的`workflow_kb_id`与装备型号参数，检查是否能正常召回对应知识库的内容。
- 触发一次手动知识库同步，检查同步日志中是否显示新增的装备文档与参数信息。
- 故意传入未通过合规审批的物料标识，检查工作流是否在生成节点前拦截该流程。
- 调整知识库召回阈值，验证召回结果的匹配精度是否符合预期配置。
