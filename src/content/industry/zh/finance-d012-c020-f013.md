# 兵器装备营销内容的知识库检索与召回

## 这个品类的数据长什么样
数据来源包括兵器装备官方技术规范文档、定型试验公开资料、金融机构军工主题营销物料、合规宣传材料、装备维护手册。更新节奏随装备定型批次、金融机构年度军工主题营销计划调整，新装备定型或营销内容更新时触发更新。文档结构多为结构化参数表、长文本技术说明、分章节宣传折页、金融产品关联说明，字段包含装备型号、性能参数、适用场景、生产批次、合规标识、关联金融产品代码，单位多为毫米、千米、发/分钟、千克、百分比等专业与金融结合的单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
结构化参数表与长文本技术说明的混合结构，要求检索同时支持字段级精准匹配与语义召回，兼顾军工参数与金融产品信息。专业单位与金融百分比的混合存在，要求保留原始单位分词规则，避免检索歧义。非固定更新周期结合军工与金融营销节奏，要求支持增量同步，减少全量解析的资源消耗。营销物料与内部文档、金融产品说明的混合存储，要求通过多维度标签区分内容类型，避免无关内容被召回。长文档的分段处理需兼顾信息完整性与上下文连贯性，避免拆分破坏参数组与金融关联的逻辑关联。金融营销的合规要求更高，需确保召回内容符合金融监管与军工宣传的双重合规标准。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 兵器装备技术文档多为长段参数说明，该区间可保留单组完整性能参数与金融关联描述，避免拆分割裂 |
| `相似度阈值` | 0.72–0.85 | 专业术语与金融术语混合较多，该区间可过滤低相关的通用语义结果，保留精准匹配装备参数与金融产品的内容 |
| `召回条数` | 前 6 条 | 单篇装备与金融关联文档内容量较大，过多召回会超出上下文窗口限制，该数量可覆盖核心营销获客场景所需信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 大型装备定型文档解析耗时较长，该时长可避免解析中断 |
| `增量同步开关` | 开启 | 兵器装备与金融营销更新周期不固定，增量同步可减少重复解析成本 |
| `标签筛选` | 开启，绑定「合规」「军工营销」「金融产品关联」标签 | 符合金融营销与军工宣传的双重合规要求，过滤非营销或不合规的文档内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：检索结果包含非营销类的内部技术文档或非军工关联的金融产品内容，返回条数超出预期。原因：未开启`标签筛选`配置，未为文档绑定对应标签，导致无关内容被召回。
- 现象：解析大型装备与金融关联手册时出现`504 Gateway Timeout`错误。原因：`PARSE_FILE_TIMEOUT_SECONDS`设置值小于文档实际解析耗时，导致解析中断。
- 现象：无法根据用户输入的装备型号或金融产品代码精准召回对应内容，或无法切换指定知识库进行检索。原因：未正确配置`知识库选择`的全局变量赋值逻辑，导致变量未绑定对应知识库ID，或未启用多字段级检索匹配。

## 怎么确认配好了
- 上传一篇兵器装备与金融关联的营销文档，检查解析后的分段是否保留完整的性能参数与金融关联描述，无割裂情况。
- 输入包含装备型号和金融产品需求的查询，核对召回结果的相似度符合预设区间，条数符合设置要求，且内容同时匹配军工参数与金融产品信息。
- 触发一次增量同步，检查仅新增的文档被解析，未重复处理历史文档。
- 为测试文档绑定指定合规、军工营销与金融产品关联标签，验证检索时仅召回带该标签的内容。
- 测试`知识库选择`的全局变量赋值，确认切换不同知识库后，召回内容仅来自对应知识库。
