# 其他综合营销内容的知识库检索与召回

## 这个品类的数据长什么样
其他综合营销内容的数据主要来自内部跨品类营销素材库、合作方合规审核文档、监管公示的业务指引。更新节奏随营销活动周期调整，单次活动上线前批量更新，日常仅微调合规提示或话术细节。文档多为半结构化格式，包含适用场景、生效时段、合规编号、话术文本、目标客群标签等字段，单位多为字符数、标准日期格式、固定编码格式的合规编号。

## 这些特征在「知识库检索与召回」这一环带来什么约束
跨品类的素材集合要求检索需结合场景标签过滤，避免跨客群的不适用内容被召回。非固定周期的更新节奏要求支持增量上传与增量索引，避免全量重建带来的性能损耗。半结构化文档包含合规编号等强校验字段，检索需支持精确匹配字段与语义召回结合。金融场景的合规要求需优先召回带有合规标识的内容，限制无合规编号的素材被返回。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunk_size` | `800–1200 字符` | 其他综合营销内容多为长话术或活动规则，该分段长度可保留完整语义单元，避免截断合规提示或活动细则 |
| `retrieve_top_k` | `前 6–8 条` | 综合营销内容的相关素材较多，需返回足够数量供后续重排，同时控制上下文长度 |
| `filter_field_enable` | `开启` | 需按`适用场景`、`合规编号`字段过滤，排除非目标客群或不合规的素材 |
| `exact_match_fields` | `["合规编号", "适用场景"]` | 金融营销内容需精确匹配合规标识与使用场景，避免语义相似但不合规的内容被召回 |
| `incremental_index_enable` | `开启` | 营销内容更新周期不固定，增量索引可减少检索延迟与资源占用 |
| `similarity_threshold` | `0.75–0.85` | 平衡召回的相关性与覆盖度，避免漏召回有效营销素材或引入无关内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用知识库变量时返回`quote type error`报错。原因是变量引用的格式不符合要求，未使用正确的包裹符号或引用了不存在的字段。
- 现象为特定知识库中，与用户问题完全匹配的文本chunk无法被召回，新建相同配置的知识库则可正常召回。原因是该知识库的索引缓存未正确刷新，或存在字段过滤规则误匹配了该chunk的适用场景。
- 现象为对话过程中无法将临时生成的营销内容同步添加到知识库。原因是未配置实时增量同步的触发规则，或未开启`auto_update_index`参数。

## 怎么确认配好了
- 上传一份包含合规编号、适用场景的测试营销素材，执行检索测试，验证结果是否包含该素材且符合过滤规则。
- 调用知识库变量接口，传入正确的字段引用格式，验证是否返回`quote type error`以外的正常结果。
- 执行增量更新操作，查看索引刷新日志，确认仅新增的素材被纳入索引。
- 开启引用展示配置，检索结果中是否显示对应的知识库来源信息。
