# 其他综合营销内容的部署与升级

## 这个品类的数据长什么样
其他综合营销内容的数据主要来源于金融机构内部合规部门审核的产品说明、临时营销活动话术、客户分层运营素材，以及合作方提供的合规宣传物料。更新节奏随营销节点变动，常规物料每月更新，临时活动物料可在24小时内完成更新。文档格式包含Word合规说明文档、Excel产品参数表、PDF活动海报配套文案，结构包含物料唯一标识、适用客群标签、合规审批编号、生效与失效时间字段，单位涉及字符数、适用客群量级、活动周期天数。

## 这些特征在「部署与升级」这一环带来什么约束
该品类数据来源分散且格式多样，部署环节需兼容多类型文档解析，避免因格式不支持导致物料丢失。更新频率随营销节点波动，临时物料的快速更新要求部署后支持增量同步配置，无需全量重建知识库。字段包含合规审批编号等敏感标识，部署时需保留原始字段映射，避免合规信息丢失。升级过程中需兼顾历史物料的兼容性，确保更新后旧物料的检索逻辑不受影响，同时适配新增的活动类物料结构。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 综合营销物料中包含的长文档、高清海报配套说明解析耗时较长，需预留充足解析时间 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 该品类物料包含多格式组合文件，需支持大容量单文件上传 |
| `maxContext` | `800–1200 字符` | 营销内容核心话术通常集中在该长度区间，可避免上下文过长导致模型推理过载 |
| `召回条数` | `前 3–5 条` | 营销场景需精准匹配客群与活动场景，过多召回结果会干扰模型输出的针对性 |
| `相似度阈值` | `0.75–0.85` | 平衡合规内容的严格匹配与临时活动物料的灵活召回需求 |
| `增量同步间隔` | `15 分钟` | 适配临时营销物料的快速更新需求，同时控制服务器同步负载 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用本地部署的大模型时返回`404 Not Found`错误，且通过oneapi单独测试接口正常。原因：FastGPT 4.9.0版本中，外部模型接入配置未正确拼接模型接口路径，导致请求地址指向不存在的路由。
- 现象：使用pgvector作为向量库时，导入超过30个知识库后无法新增知识库。原因：未调整pgvector的`max_open_cursors`配置项，默认上限限制了知识库的创建数量。
- 现象：通过Docker部署的系统无法修改登录密码，页面提示密码格式错误。原因：未通过环境变量`ADMIN_PASSWORD`配置初始密码，直接修改容器内配置文件未生效，且未重启容器加载新配置。

## 怎么确认配好了
- 进入模型接入测试页面，发起接口测试，确认返回内容与独立工具测试结果匹配。
- 上传符合品类特征的文档，确认解析完成后无格式报错或内容丢失。
- 发起检索请求，核对召回结果的数量与配置项的设定值一致。
- 修改配置参数后重启服务，确认系统设置页面显示更新后的参数值。
