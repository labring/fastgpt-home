# 军工电子营销内容的知识库检索与召回

## 这个品类的数据长什么样
军工电子营销内容的数据主要来自企业官方宣传物料、技术参数文档、参展宣讲材料、客户对接方案手册。更新节奏随新品发布、资质更新、重大市场项目节点调整，通常按季度或单次项目周期更新。文档结构多包含型号编号、性能参数、适配场景、合规要求等字段，单位采用常见的军工行业计量方式，例如功率以千瓦为单位、频段以吉赫兹为单位、设备重量以千克为单位，部分文档附带技术图纸的文字说明或军标编号。

## 这些特征在「知识库检索与召回」这一环带来什么约束
军工电子营销内容的结构化参数占比高，检索时需兼顾语义关联与参数精准匹配，避免仅依赖语义相似度导致的关键参数遗漏。更新节奏随项目节点波动，召回逻辑需支持增量更新，不采用全量重建的方式，避免影响实时营销内容的调用。文档中包含合规性字段，检索结果需过滤非授权涉密相关内容，同时需自动对齐常见的行业计量单位，避免参数匹配偏差。部分文档包含长段技术说明内容，过长文本会增加嵌入模型的处理负载，需合理设置分段规则以保留信息完整性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `EMBEDDING_MODEL` | `text-embedding-ada-002`或同维度军事领域微调嵌入模型 | 适配军工电子领域的专业术语与结构化参数的语义一致性需求，确保参数匹配精度 |
| `RECALL_TOP_K` | `前8-12条` | 军工电子营销内容的参数项较多，过多召回会导致上下文冗余，过少则遗漏关键性能参数 |
| `PARSE_CHUNK_SIZE` | `800-1200字符` | 保留军工电子文档中参数与应用场景的关联逻辑，避免分段断裂导致的信息丢失 |
| `SIMILARITY_THRESHOLD` | `0.72-0.85` | 过滤低相关的通用营销内容，保留与军工电子型号、参数强匹配的检索结果 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 兼容军工电子文档常附带的高清图纸附件与大型技术手册的上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300秒` | 适配大型技术手册的解析耗时，避免因超时中断导致的上传失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：知识库搜索结果的排序未体现参数匹配优先级，与预期的相似度排序不一致。原因：未启用针对结构化参数的加权召回逻辑，仅依赖基础嵌入相似度生成排序结果。
- 现象：上传xlsx格式表格后，表格内容无法被正确解析，检索时无对应文本片段。原因：未启用FastGPT的Excel解析插件，或表格包含合并单元格、隐藏列等非标准格式导致解析失败。
- 现象：配置非`text-embedding-ada-002`的嵌入模型时，系统返回`undefined model must match "^(text`报错。原因：所选模型未在平台嵌入模型白名单中，或模型名称输入格式不符合平台校验规则。

## 怎么确认配好了
- 上传一份标准军工电子营销xlsx表格，检查解析后的文本片段是否包含表格内的型号、参数内容，确认Excel解析插件已正确启用。
- 输入一条包含军工电子型号与参数的查询词，检查返回结果的排序逻辑是否匹配参数优先级，调整相关配置项至符合预期。
- 上传一份超过100MB的技术手册文档，检查上传进度是否正常完成，确认`UPLOAD_FILE_MAX_SIZE`配置符合当前物料的大小范围。
- 测试嵌入模型切换操作，验证是否能正常生成向量，确认所选模型在平台白名单内且名称格式符合要求。
