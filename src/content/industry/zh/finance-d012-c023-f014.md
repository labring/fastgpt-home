# 军工电子营销内容的表单与交互

## 这个品类的数据长什么样
军工电子相关营销内容的数据主要来源于企业内部研发文档、公开招投标公告、行业标准文档及客户定制需求文档。数据更新节奏随项目节点波动，单个项目周期内可能集中更新多版参数。文档结构多为结构化表格与技术手册结合，包含装备型号、频段范围、功率参数、防护等级、适配场景等字段，部分涉密内容会标注保密级别，单位多采用国际通用军工标准单位，如分贝毫瓦（dBm）、兆赫兹（MHz）、兆帕（MPa）。

## 这些特征在「表单与交互」这一环带来什么约束
军工电子的数据特征对表单与交互环节带来多重约束。结构化字段与标准单位要求表单预设带单位的输入控件，避免手动输入的格式偏差。涉密标注字段需要集成权限校验模块，仅授权用户可编辑对应内容。动态更新的招投标与项目数据，要求表单配置定时同步接口，确保使用最新参数。适配场景字段需预设行业通用选项，减少非标准化输入。长技术手册类附件上传需限制格式与大小，保障后续解析稳定性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 军工电子技术手册单份体积多在50-200MB区间，预留足够上传空间同时避免解析超时 |
| `maxContext` | `8000–12000 字符` | 军工电子文档参数密集，需要足够上下文容纳完整技术参数与场景说明 |
| `RECALL_TOP_N` | `前3条` | 军工电子营销内容的核心参数集中在少量高相关文档中，过多召回会引入冗余信息 |
| `FORM_FIELD_VALIDATOR` | `按军工标准单位校验` | 品类字段需严格匹配dBm、MHz等标准单位，避免输入错误导致后续流程异常 |
| `PLUGIN_TRIGGER_TIMEOUT` | `120 秒` | 军工电子文档解析需较长时间处理复杂参数表格，避免因超时中断任务 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 工作流运行后显示`Cannot convert undefined or null to object`，原因是表单未配置必填字段校验，当涉密字段未授权用户编辑时留空，导致流程传入空值触发类型转换错误。
- 配置表单时未启用军工标准单位校验，导致用户输入非标准单位的参数，后续LLM处理时出现格式混乱。
- 在工作流中引用插件后直接连接代码节点，未配置插件输出的字段映射，导致代码节点接收未定义的输入参数，触发输入报错。

## 怎么确认配好了
- 上传一份军工电子技术手册，检查附件上传控件是否限制了格式与大小，解析后是否完整提取了参数字段。
- 编辑表单字段，验证涉密标注字段是否仅在授权账号下可编辑，普通账号无法修改对应内容。
- 触发工作流测试，传入符合标准单位的参数，检查流程是否正常运行无报错。
- 配置召回条数后，检索相关文档，确认返回的文档数量符合预设的取值范围。
