# 农化制品营销内容的工具调用与插件

## 这个品类的数据长什么样
农化制品的核心数据主要来自农业农村部农药检定所公开登记信息、生产厂商官方产品说明书、合规农资交易平台商品页。数据更新节奏分为两类：官方登记数据按季度更新，厂商新品及修订文档随产品迭代不定期发布。单份产品文档通常包含有效成分标识、适用作物范围、施用量标准、安全间隔期、保质期等字段，其中有效成分含量以克/升为单位，施用量以千克/亩或毫升/亩为单位，文档结构多为参数表格加场景说明文本。

## 这些特征在「工具调用与插件」这一环带来什么约束
农化制品的数据特征对工具调用与插件带来多维度约束。官方登记数据的季度更新周期，要求工具的数据源缓存时长不得超过90天，避免返回过期的登记证号或施用量标准。不同厂商的施用量、有效成分标识单位存在差异，插件需要内置标准化单位转换逻辑，适配营销内容中多场景的展示需求。单份产品文档篇幅较长，工具调用时需设置合理的分段截取阈值，避免单次请求超出上下文限制。同时，农资数据的合规性要求严格，插件需内置来源白名单校验规则，仅允许调用官方备案的数据源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_cache_ttl` | `75 天` | 匹配农化官方登记数据的季度更新周期，避免返回过期的登记证号或施用量标准 |
| `request_timeout` | `30 秒` | 适配农资官方数据源的响应速度，预留足够时间获取长篇幅的产品文档内容 |
| `max_paragraph_length` | `800–1200 字符` | 适配农化产品文档的典型段落长度，避免单次请求超出上下文窗口限制 |
| `allowed_url_patterns` | 仅允许农业农村部农药检定所、生产厂商官方域名 | 满足农资数据的合规性要求，过滤非备案的第三方数据源 |
| `unit_conversion_enabled` | 开启 | 适配不同厂商施用量、有效成分标识的单位差异，标准化后用于营销内容生成 |
| `plugin_available_models` | 包含所有支持联网推理的模型版本 | 覆盖用户实际调用需求，适配如o1-preview等需单独配置权限的模型 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用搜索插件后仅返回简易摘要，无法获取目标网页的完整内容。原因是未配置`max_paragraph_length`参数或取值低于800字符，导致工具仅抓取预设的摘要字段，未触发完整网页内容拉取逻辑。
- 现象为工具调用界面仅显示少量可选模型，无法选择全部支持的模型版本。原因是未正确配置`plugin_available_models`参数，仅将部分模型添加到白名单，未覆盖全量支持联网推理的模型。
- 现象为使用HTTP插件调用农资数据源时返回502错误，且在APIFOX中调用流程正常。原因是未正确设置请求头或未将目标数据源加入`allowed_url_patterns`白名单，导致FastGPT的插件拦截了合规请求。

## 怎么确认配好了
- 发起一次针对官方登记数据源的测试调用，检查返回的登记证号、施用量等字段是否与当前公开信息一致，核对缓存时长是否符合更新周期要求。
- 查看工具调用界面的模型列表，确认是否包含所有需要使用的模型版本，核对`plugin_available_models`的配置范围。
- 构造包含不同单位的施用量参数的测试请求，检查插件是否自动完成单位转换，确认`unit_conversion_enabled`开关状态正确。
- 模拟调用非备案域名的数据源，检查插件是否拦截请求，确认`allowed_url_patterns`的配置生效。
