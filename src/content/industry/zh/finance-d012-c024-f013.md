# 农化制品营销内容的知识库检索与召回

## 这个品类的数据长什么样
农化制品的营销内容数据主要来源于农业保险机构配套的产品登记证文件、田间试验报告、产品说明书、经销商培训材料、合规政策文件及定制化推广文案。数据更新节奏随新产品登记、合规政策变动及季度营销计划调整，无固定周期。文档结构包含结构化字段与长文本段落，结构化字段包括产品名称、有效成分、含量、登记证号、适用作物，单位多为g/L、%或亩用量；长文本部分包含使用方法、注意事项及试验细节，部分文档附带剂量表格。

## 这些特征在「知识库检索与召回」这一环带来什么约束
农化制品的专业字段属性要求检索需严格匹配有效成分、登记证号等精准参数，避免合规性错误；结构化剂量表与长文本试验报告的混合存在，要求检索系统支持分块语义保留与结构化字段提取；无固定周期的更新节奏，要求支持增量式索引同步，避免全量重复构建；作为农业保险获客的配套内容，需支持按适用作物、保险场景过滤召回结果，确保内容匹配种植户的实际需求。专业术语较多的文本需避免过度分块导致语义断裂，影响检索精准度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunk_size` | `800–1200 字符` | 农化制品文档包含长文本使用说明与结构化剂量表，该区间可保留完整语义块，避免专业数据被拆分断裂 |
| `recall_top_k` | `前10条` | 农化营销内容需兼顾合规精准性与场景覆盖度，过多召回结果会增加上下文处理负担 |
| `similarity_threshold` | `0.75–0.85` | 需严格匹配有效成分、登记证号等专业字段，该阈值可过滤低相似度的无关内容 |
| `PARSE_STRUCTURED_TABLE` | `开启` | 农化文档包含剂量表、成分表等结构化数据，开启后可提取字段用于精准检索 |
| `incremental_sync_interval` | `每24小时` | 农化数据更新无固定周期，每日增量同步可兼顾时效性与系统资源消耗 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：在FastGPT 4.8.20版本中，加载包含大量农化试验报告的知识库时页面崩溃。原因：未调整`chunk_size`参数，过大的文本分块导致内存占用超出该版本的默认阈值。
- 现象：通过外部API调用知识库检索功能时返回认证失败或空结果。原因：未配置API访问权限或未正确传入请求参数。
- 现象：新建知识库数据索引后无法检索到新上传的农化文档。原因：未配置增量同步触发规则，仅使用全量同步导致新数据未被及时索引。

## 怎么确认配好了
- 上传一份包含结构化剂量表的农化产品说明书，检查分块结果是否保留了完整的剂量信息，核对`chunk_size`的实际生效情况。
- 发起包含有效成分名称的查询，检查召回结果的相似度得分是否符合预设区间，核对`similarity_threshold`的配置效果。
- 上传一份新的农化营销物料，等待同步完成后发起对应查询，检查新内容是否被成功召回，核对增量同步配置的生效情况。
- 发起包含历史上下文的复合查询，检查召回结果是否关联了历史查询的作物类型，核对上下文关联配置的生效情况。
