# 农商行营销内容的工具调用与插件

## 这个品类的数据长什么样
农商行营销相关数据主要来源于内部客户管理系统、线下网点运营台账、线上服务平台留言、营销活动备案档案。数据更新节奏存在差异：客户画像数据每日批量同步，线上服务留言实时接入，营销活动备案数据随活动筹备进度更新。文档多采用结构化表格形式存储，包含客户唯一标识、客户经营场景、营销触达渠道、活动执行状态等字段，字段单位包括户、人次、自然日。

## 这些特征在「工具调用与插件」这一环带来什么约束
农商行的结构化客户数据与合规备案要求，要求工具调用需精准匹配预设字段，避免模糊召回导致的营销内容不符合客户经营场景。实时线上留言数据的接入，要求插件支持短文本流式输入处理，适配快速响应的营销咨询场景。营销活动备案数据的存在，要求工具调用环节需校验生成内容是否与备案档案匹配，确保合规性。多渠道触达的需求，要求插件支持同时生成适配线下网点与线上服务平台的不同格式营销内容，且需绑定农商行内部系统专属接口，保障数据的准确性与合规性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `TOOL_CALL_MAX_RETRIES` | `2–3 次` | 农商行内部系统接口稳定性适中，重试2-3次可覆盖临时网络波动，避免过度调用占用内部资源 |
| `PLUGIN_DATA_SOURCE_BIND` | `绑定农商行内部客户管理系统接口` | 农商行客户数据属于内部合规数据，需通过专属接口拉取，保障数据准确性与合规性 |
| `TOOL_INPUT_STRUCTURE` | `启用结构化输入校验` | 农商行营销数据多为结构化字段，启用校验可避免无效参数传入，提升调用成功率 |
| `STREAM_OUTPUT_ENABLE` | `开启` | 实时线上留言需快速响应，流式输出可实现边生成边展示，适配营销咨询场景 |
| `PARSE_MARKDOWN_IMAGE_URL` | `配置为内部文件存储域名` | 农商行营销物料图片存储于内部系统，需替换为可被第三方系统访问的域名，确保展示正常 |
| `TOOL_TIMEOUT` | `600 秒` | 内部系统批量数据拉取存在延迟，600秒可覆盖大部分批量查询场景 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为第三方系统展示营销内容时，本地上传的图片无法正常加载，返回`403 Forbidden`或`404 Not Found`错误。原因是未将图片链接替换为内部文件存储的可访问域名，仍使用FastGPT临时存储路径，第三方系统无权限或无法定位该资源。
- 现象为调用API获取营销内容时，未实现流式输出，仅返回完整生成结果。原因是未开启`STREAM_OUTPUT_ENABLE`配置项，或未按照标准流式响应格式接收数据。
- 现象为调用获取当前时间插件时返回`INVALID_REQUEST`错误，无法正常返回结果。原因是未传入插件要求的时区参数，农商行营销内容需适配本地时区，未指定时区导致插件校验失败。

## 怎么确认配好了
- 发起一次工具调用测试，检查返回的客户数据是否包含农商行内部系统的专属字段，确认数据源绑定正确。
- 上传一张营销物料图片，生成包含图片的营销内容，在第三方系统中预览，确认图片可正常展示。
- 开启流式输出开关，调用API生成营销内容，检查是否能逐段接收生成结果，确认流式配置生效。
- 调用获取当前时间插件，检查返回结果是否包含本地时区的时间信息，确认插件参数配置正确。
