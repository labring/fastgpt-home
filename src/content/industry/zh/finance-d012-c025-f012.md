# 农商行营销内容的模型接入与配置

## 这个品类的数据长什么样
农商行营销内容的数据来源多为内部营销系统、辖内支行上报的推广材料、存量客户反馈的话术素材。数据更新随营销活动节奏，单次活动素材无固定更新周期。文档多为纯文本格式，包含营销主题、适用客群、产品编号、活动起止日期等字段，活动有效期以自然日为单位，产品编号为六位数字格式。

## 这些特征在「模型接入与配置」这一环带来什么约束
营销内容多为单篇短文本但随活动频繁更新，要求模型接入环节支持批量短文本解析与快速上下文适配。文档包含农商行专属字段如产品编号、活动有效期，需配置模型的实体抽取规则匹配这些非通用字段。更新无固定周期，需支持动态调整模型的上下文窗口以适配不同长度的新素材。内部素材来源分散，需配置统一的文档上传入口以整合多渠道的营销内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | 100 MB | 农商行营销素材多为单篇短文本，批量上传时单文件上限设为100 MB可平衡存储与加载效率 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 60 秒 | 短文本解析耗时短，60秒超时可避免无效等待，适配频繁更新的素材节奏 |
| `分段长度` | 800–1200 字符 | 适配农商行营销话术的常规长度，避免过度拆分导致语义断裂 |
| `maxContext` | 4096 令牌 | 匹配多数通用大模型的基础上下文上限，满足短文本营销内容的处理需求 |
| `相似度阈值` | 按实测标定 | 需结合农商行营销素材的匹配度需求调整，确保召回结果符合业务场景 |
| `召回条数` | 前3条 | 控制返回的关联营销素材数量，避免信息过载影响营销话术生成 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流节点的模型下拉列表未显示已全局启用的模型，当前版本为4.14.4。原因：未在应用详情页将目标模型关联至当前工作流，或全局配置中未开启「工作流可见」开关。
- 现象：上传txt格式的营销素材后，大模型无法生成有效总结内容。原因：未配置`分段长度`参数适配短文本结构，或`PARSE_FILE_TIMEOUT_SECONDS`设置过短导致解析未完成。
- 现象：调用配置的AIProxy渠道模型时返回500错误。原因：未在AIProxy配置中正确设置模型映射规则，或未填写匹配产品编号、活动有效期等专属字段的解析参数。

## 怎么确认配好了
- 进入FastGPT的全局模型配置页面，检查目标模型的「工作流可用」开关是否开启，确认应用绑定关系是否正确。
- 上传一份测试用的农商行营销素材txt文档，触发工作流运行，查看解析后的文本片段是否包含正确的产品编号、活动有效期字段。
- 在AIProxy配置页面，测试调用已配置的模型，查看接口返回结果是否包含预期的营销内容总结。
- 调整`相似度阈值`参数后，触发关联营销素材的召回测试，确认返回结果的匹配度符合业务需求。
