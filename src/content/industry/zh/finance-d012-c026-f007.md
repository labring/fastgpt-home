# 出版营销内容的工作流编排

## 这个品类的数据长什么样
出版行业的营销内容数据来源包括书稿原稿、排版文件、营销物料三类。书稿原稿多为PDF、EPUB格式，包含书名、作者、ISBN、章节内容等结构化字段；营销物料则涵盖推文脚本、直播分镜脚本、海报文案初稿，格式以Markdown、TXT为主。数据更新节奏按选题周期推进，新书上市前1-3个月集中更新全量内容，日常仅针对营销物料做微调。数据字段存在差异，部分书稿未填写目标受众标签，营销物料的长度跨度从数十字符到数千字符不等。

## 这些特征在「工作流编排」这一环带来什么约束
多格式混合的数据源要求工作流需配置支持多种文件类型的解析节点，需针对不同格式调整解析参数。按选题周期的集中更新模式，要求工作流支持定时触发、手动触发结合的调度方式，避免非周期的无效运行。结构化字段存在缺失与差异，要求工作流的变量引用环节配置默认值，处理空字段场景。营销物料的长度跨度大，要求内容处理节点支持动态调整分段参数，适配短文本与长脚本的处理需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `PARSE_FILE_SUPPORTED_TYPES` | `["pdf", "epub", "md", "txt"]` | 覆盖出版行业书稿原稿、营销物料的常用文件格式 |
| `TRIGGER_MODE` | `["scheduled", "manual", "webhook"]` | 适配出版营销的周期选题调度、临时物料调整的触发需求 |
| `VARIABLE_FALLBACK_VALUE` | `"未填写"` | 处理出版内容字段缺失的场景，避免工作流因空值中断 |
| `CHUNK_SIZE` | `800–1200 字符` | 适配书稿章节、直播脚本的内容长度，平衡上下文召回完整性与处理效率 |
| `MAX_LOOP_TIMES` | `10–20 次` | 限制多平台分发校验等循环环节的执行次数，避免资源无效占用 |
| `MCP_SERVER_URL` | 按实测标定 | 匹配部署的Mermaid MCP Server服务地址，用于生成营销流程图 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流运行时触发`MAX_LOOP_TIMES_EXCEEDED`报错，日志显示循环次数超出限制。原因：未设置`MAX_LOOP_TIMES`参数，或取值未覆盖多平台分发校验的实际循环次数。
- 现象：知识库搜索结果无法正确关联出版书稿的`keyword_group`字段，返回内容与目标关键词不匹配。原因：未在知识库配置中开启变量引用关联，或未指定引用字段的映射规则。
- 现象：用户会话中未显示提交反馈的按钮，工作流无法收集营销效果反馈。原因：未在工作流中添加用户交互节点，或未配置按钮的触发条件与提交参数。

## 怎么确认配好了
- 上传覆盖PDF、EPUB、Markdown、TXT格式的测试文件，确认解析节点可正常读取所有文件内容。
- 触发手动运行与定时调度任务，验证工作流的触发逻辑符合预设的出版营销排期需求。
- 测试变量引用环节，传入缺失部分字段的测试数据，确认流程可正常执行并返回预设的默认值。
- 调用Mermaid MCP Server节点，验证服务调用成功并返回可访问的图片链接。
