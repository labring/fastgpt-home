# 出版营销内容的工具调用与插件

## 这个品类的数据长什么样
金融/保险/理财领域的出版营销内容的数据来源包括内部内容管理系统的理财书籍、保险产品宣传册、基金经理访谈文案的物料库，版权授权素材库，第三方行业书评平台、电商平台用户评价数据，以及跨渠道的曝光与转化数据。更新节奏为新书上市期集中更新，日常随营销活动迭代。文档结构包含结构化元数据字段，如`ISBN`、`书名`、`作者`、`出版日期`、`营销物料类型`、`物料发布渠道`，以及非结构化内容如文案文本、短视频时长参数。字段单位包含`字符`（文案长度）、`秒`（短视频时长）、`条`（物料数量）、`次`（曝光次数）。

## 这些特征在「工具调用与插件」这一环带来什么约束
金融/保险/理财领域的出版营销内容包含合规性要求，结构化元数据包含`ISBN`等唯一标识，要求工具调用支持按唯一标识精准召回，避免模糊匹配带来的合规风险。营销物料类型多样且字段差异大，要求插件配置支持多数据源的字段映射，适配不同格式的理财、保险类物料数据。更新节奏集中且高频迭代，要求工具调用支持增量拉取配置，避免全量同步导致的超时与资源占用过高。长文本营销文案与短物料素材并存的特征，要求工具调用的上下文参数支持动态调整，适配不同长度的内容输入。跨渠道的曝光转化数据要求插件支持多维度的统计字段关联，提升营销内容的分析效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `embedding_chunk_size` | `1000–1500 字符` | 金融/保险/理财类营销文案多为长文本，拆分后需保留语义完整性，避免合规信息丢失 |
| `maxContext` | `8000–12000 字符` | 营销内容常包含完整的宣传段落与用户评论合集，需适配长上下文输入以保留完整信息 |
| `RECALL_TOP_K` | `前 8–12 条` | 单品类营销物料数量有限，过多召回会导致结果冗余，影响调用效率与合规审核 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 长文案、多格式营销物料解析耗时较长，避免中途触发超时错误影响发布节奏 |
| `PLUGIN_DATA_SYNC_INTERVAL` | `3600 秒` | 金融/保险/理财类营销物料日常迭代频率为每日，每小时同步可平衡时效性与资源占用 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：使用应用密钥调用知识库查询接口时返回`403 Forbidden`错误。原因：应用密钥仅支持前端界面调用，后端接口调用需使用API密钥，且需配置对应的数据访问权限。
- 现象：无法找到自定义插件的配置入口，或插件调用时返回空的自定义字段。原因：未在平台插件管理页面完成插件的元数据与数据源映射配置，未正确绑定目标数据的字段。
- 现象：通过API调用返回的结果中未包含引用的文件名。原因：未开启`return_source_file`参数，或在配置时未关联文件元数据的`file_name`字段。

## 怎么确认配好了
- 发起一次工具调用测试，检查返回结果中是否包含配置的数据源字段，核对字段格式是否与金融/保险/理财类营销物料的元数据一致。
- 查看插件调用日志，确认调用时长未超过配置的超时阈值，无超时报错记录。
- 上传一条测试营销物料，检查嵌入与召回流程是否正常，确认召回结果的数量符合配置的召回范围。
- 调用API接口时，检查返回的响应体中是否包含`source_file`字段，确认文件名信息正常返回。
