# 动力煤营销内容的HTTP 接口与外部系统

## 这个品类的数据长什么样
动力煤营销相关的数据主要来自国内沿海港口现货平台、产地监管统计系统与第三方大宗商品交易接口。数据更新节奏为每日1次全量更新，部分实时成交数据每小时更新。文档多为结构化JSON或CSV格式，核心字段包含产地名称、港口代码、平仓单价（单位：元/吨）、发热量（单位：千卡/千克）、港口库存（单位：万吨）、数据发布时间，部分接口会附加当日涨跌幅度可选字段。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
动力煤数据的多更新节奏、多单位字段与专属鉴权规则，对HTTP接口与外部系统配置带来明确约束。每日全量与小时级实时混合的更新场景，要求配置分层拉取逻辑，避免全量拉取浪费带宽或错过实时数据窗口。多单位字段需在接口解析阶段完成统一映射，防止下游营销内容生成时出现单位混淆。专属鉴权接口要求配置细粒度的权限限定，避免跨品类调用导致的数据泄露或接口拦截。可选字段的存在则要求兼容空值处理逻辑，防止内容生成时出现格式错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `HTTP_PULL_INTERVAL` | `3600 秒` | 适配动力煤实时成交数据的每小时更新节奏，平衡数据时效性与接口调用限额 |
| `UNIFIED_DATA_UNIT` | `元/吨、千卡/千克` | 统一解析接口返回的多单位字段，避免下游营销内容生成时出现单位不一致 |
| `NULL_FIELD_HANDLER` | `填充默认提示文本` | 兼容可选字段缺失的情况，防止营销内容生成时出现空值报错 |
| `API_AUTH_SCOPE` | `仅动力煤品类权限` | 匹配行业专属接口的鉴权规则，避免跨品类调用触发拦截 |
| `PARSE_DATA_TIMEOUT` | `10 秒` | 适配大宗商品接口的常规响应速度，避免超时中断拉取任务 |
| `INCREMENTAL_PULL_SWITCH` | `开启` | 针对混合更新节奏的场景，减少重复拉取的带宽与调用开销 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部数据接口返回401状态码，报错文案包含“令牌无权访问目标资源”。原因：未将FastGPT配置的API令牌限定为动力煤专属权限，触发第三方接口的鉴权拦截。
- 现象：生成的营销内容中出现单位混乱，例如将平仓价显示为“800千卡/千克”。原因：未配置统一数据单位映射，直接使用接口返回的原始单位字段进行内容拼接。
- 现象：定时拉取任务触发后返回旧数据或无更新内容。原因：未开启增量拉取开关，或拉取间隔设置与数据更新节奏不匹配。

## 怎么确认配好了
- 调用配置的HTTP接口，检查返回字段的单位是否与预设的统一规则一致，确认单位映射配置生效。
- 模拟接口返回空值的可选字段，触发内容生成流程，检查是否填充了预设的默认提示文本。
- 查看定时拉取任务的运行日志，确认任务触发间隔符合预设配置，未出现频繁限流报错。
- 检查外部系统的鉴权配置，确认仅授予动力煤品类的访问权限，未开放其他品类的调用权限。
