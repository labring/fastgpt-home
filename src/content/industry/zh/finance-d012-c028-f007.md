# 动力煤营销内容的工作流编排

## 这个品类的数据长什么样
动力煤相关数据多来自行业监测平台、港口交割台账与产地生产记录，更新节奏分为实时现货报价、每日库存数据、每周供需简报三类。文档结构以结构化表格为主，部分为带批注的半结构化报告，核心字段包含平仓价、发热量、产地标识、交货港口名称、交易周期，各字段绑定明确单位，如平仓价单位为元/吨，发热量单位为千卡/千克。

## 这些特征在「工作流编排」这一环带来什么约束
多源异构的数据来源与差异化更新节奏，要求工作流配置多节点拉取不同数据源，并设置差异化的定时触发规则。结构化与半结构化混合的文档格式，要求工作流中添加格式转换节点统一数据结构，避免后续处理出错。明确的单位字段要求，需配置参数校验节点过滤异常单位的数值，防止营销内容出现数据混淆。营销内容需匹配实时行情，要求工作流绑定数据更新后的自动执行触发，确保素材时效性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发Cron表达式` | `0 0 8 * * *` | 动力煤现货报价多在每日早间更新，匹配营销内容常规发布节奏 |
| `多数据源拉取超时时间` | `300 秒` | 同时拉取港口、产地两类数据源，避免单次拉取超时中断流程 |
| `文本分段长度` | `800–1200 字符` | 兼顾动力煤营销内容的信息密度与用户阅读体验，避免过长导致信息接收受阻 |
| `HTTP请求文件上传大小限制` | `100 MB` | 适配动力煤批量供需简报的压缩包体积，满足常规数据导入需求 |
| `工作流分支判断条件` | `字段包含「交货港」` | 区分现货与长协数据，适配两类不同的营销素材生成逻辑 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 大型动力煤供需报告的解析需较长时间，避免提前终止解析流程 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为HTTP节点调用后端接口时，无法传递本地txt格式的动力煤数据文件，返回状态码`413`。原因是未调整`UPLOAD_FILE_MAX_SIZE`参数，默认值过小无法容纳批量数据文件。
- 现象为工作流无法直接挂载到机器人对话中，触发时提示无绑定入口。原因是未在机器人配置中开启工作流挂载权限，仅能通过独立运行页面调用工作流。
- 现象为导入他人的json工作流后，文本加工模块未显示在组件库中。原因是导入的工作流依赖的模块未在当前工作区启用，需先在组件库管理中开启对应模块。

## 怎么确认配好了
- 查看定时触发配置的`Cron表达式`，核对是否与动力煤数据更新的实际节奏匹配。
- 运行一次测试工作流，检查多数据源拉取的结果是否包含全部配置的数据源字段。
- 上传一份模拟的动力煤数据txt文件，验证HTTP节点的文件上传功能是否正常返回处理结果。
- 导出工作流的json配置文件，核对文件格式是否符合标准工作流导入规范。
