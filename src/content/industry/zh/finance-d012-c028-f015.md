# 动力煤营销内容的部署与升级

## 这个品类的数据长什么样
动力煤数据来自国内煤炭港口监测系统、电力企业采购台账及行业协会公开统计数据，以结构化表格或CSV文档形式存储。数据更新节奏不均，当日港口挂牌价每日更新，区域库存与跨区运输数据周度更新。文档字段包含产地名称、收到基低位发热量、全硫分、灰分、含税车板价、库存总量、运输流向，单位分别为大卡/千克、%、%、元/吨、万吨。部分跨源数据存在单位表述差异，需额外处理转换。

## 这些特征在「部署与升级」这一环带来什么约束
由于动力煤数据包含多维度结构化字段且更新频率不均，部署时需配置多源数据同步的并行任务，避免单线程拉取超时。升级时需兼容新增的区域运输流向字段，避免旧版解析规则丢失关键信息。同时，因字段单位存在跨源差异，部署阶段需预设单位转换映射表，防止知识库检索时出现单位混淆。批量上传的月度数据文件体积较大，部署时需调整上传限制参数，支持大容量文件提交。周度更新的库存数据需匹配定时同步节奏，避免拉取时间与数据发布错位。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `900 秒` | 动力煤数据文档包含多维度结构化字段，解析时需完成单位转换与字段映射，超时时间需覆盖完整解析流程 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 区域库存与跨区运输的批量数据文件通常体积较大，需支持多份月度数据批量上传 |
| `SYNC_CRON_EXPRESSION` | `0 0 2 * * *` | 动力煤价格数据每日更新，周度库存数据在每周一发布，定时拉取需匹配数据发布节奏 |
| `maxContext` | `8000–12000 字符` | 单份动力煤业务报告的字段说明与数据详情较长，需保留足够上下文用于精准召回 |
| `召回条数` | `前8条` | 动力煤营销内容需覆盖产地、价格、运输多个维度，召回过多会导致内容冗余，过少无法覆盖用户需求 |
| `相似度阈值` | `0.75–0.85` | 动力煤数据字段多且相似度高，需过滤低相关的历史数据，保留精准匹配的业务信息 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 上传动力煤结构化数据文档时，界面弹出“解析超时”报错。原因是未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时间不足以完成多维度字段的单位转换与映射流程。
- 触发营销内容生成后，对话界面显示问答已结束，但右侧详情面板无输出内容。原因是`maxContext`参数设置区间过小，动力煤数据的完整字段信息未被纳入上下文，导致生成环节触发截断错误。
- 升级至v4.8.20版本后，调用知识库检索接口返回500状态码。原因是旧版配置的字段映射规则未兼容新增的区域运输流向字段，导致检索时出现空字段异常。

## 怎么确认配好了
- 上传一份标准动力煤数据文档，检查解析后的字段是否包含预设的业务项，核对单位转换是否符合配置规则。
- 手动触发一次定时同步任务，检查是否按设定的时间拉取最新数据，无数据缺失或格式错误。
- 调用知识库检索接口，输入指定业务关键词，检查返回结果的召回条数与相似度是否符合预设配置要求。
- 启动简易应用并触发营销内容生成，检查是否能正常返回完整文案，无未捕获异常。
