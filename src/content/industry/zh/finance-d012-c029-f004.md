# 包装印刷营销内容的向量模型与索引

## 这个品类的数据长什么样
包装印刷的营销内容主要来源于内部设计系统、ERP生产系统、客户定制需求文档与合作供应商的工艺手册。更新节奏以单个项目为单位，新物料上线或定制需求变更时触发更新。文档结构包含三类：纯文本的工艺说明文档、带结构化表格的物料参数清单（含材质、克重、尺寸等）、带附件的设计规范文件。字段包含物料名称、材质类型、印刷工艺、交付周期、客户编号等，单位多为克（g）、毫米（mm）、平方米（㎡）等工业常用单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
由于包装印刷营销内容包含长文本工艺说明、结构化参数清单与附件型设计文件，向量模型需适配混合文本结构，无法仅依赖纯短文本嵌入逻辑。采用按项目的更新节奏，不采用实时的更新节奏，要求索引支持增量刷新，不支持全量重建，以降低计算资源消耗。多字段的结构化信息需先转换为嵌入兼容的文本格式，避免结构化参数因无法直接嵌入而丢失语义关联。不同物料的文档长度差异显著，需适配可变长度的分段策略，防止截断关键工艺参数或重复嵌入短文本条目。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `EMBEDDING_MODEL` | `bge-large-zh-v1.5`（开源免费）或`text-embedding-3-small` | 包装印刷文档包含专业工业术语，中文嵌入模型可准确匹配工艺、材质等语义，适配主流向量索引的维度要求 |
| `分段长度` | `800–1200 字符` | 兼顾长文本工艺说明的语义完整性与短文本物料参数的召回精度，避免过度拆分或截断关键信息 |
| `分段重叠率` | `10–15%` | 保留工艺步骤、参数说明的上下文关联，防止拆分后丢失跨段落的语义衔接 |
| `RECALL_TOP_K` | `前 6–8 条` | 包装印刷营销内容的检索需求多为匹配具体物料类型，少量精准召回即可覆盖常用业务场景 |
| `SIMILARITY_THRESHOLD` | `0.72–0.78` | 区分相似材质、工艺的文档，避免召回不匹配的物料参数，平衡召回率与精准度 |
| `INDEX_REFRESH_MODE` | `增量刷新` | 匹配按项目更新的文档节奏，无需全量重建索引，降低系统负载 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：检索后返回的结果中无匹配的包装工艺参数。原因：未将结构化字段（如克重、尺寸）转换为嵌入兼容的文本格式，导致向量无法匹配语义查询。
- 现象：本地部署4.9.6版本时，外部索引模型连接失败，返回错误码`Connection refused`。原因：未在系统配置中配置外部索引模型的访问密钥与内网地址，或容器网络未开放对应端口。
- 现象：创建索引后无法关联语言模型上下文，返回`context not found`报错。原因：未在索引配置中绑定对应嵌入模型，导致检索结果无法与原文本源关联，无法生成有效上下文。

## 怎么确认配好了
- 上传一份包装印刷的营销物料文档，查看嵌入任务的日志，确认向量生成成功且无截断报错。
- 发起包含具体物料参数的查询，核对召回结果的字段与原文档的匹配度，调整相似度阈值至符合业务需求的区间。
- 测试增量更新索引的操作，确认新增的物料文档可被正常检索，无需全量重建索引。
- 检查外部索引模型的连接状态，查看系统监控面板中的向量存储读写延迟，确认连接正常。
