# 包装印刷营销内容的文档解析与分块

## 这个品类的数据长什么样
这个品类的营销文档主要来自金融、保险、理财机构的包装印刷推广物料，包括产品宣传册、合同包装手册、客户权益告知书、理财方案样册等。文档更新随业务调整不定期触发，新品上线、合规要求更新或定价调整时会新增或修订。文档多为图文混排结构，部分包含实拍样品图或扫描的纸质样册内容，内置字段包括包装材质、克重、成品尺寸、印刷工艺、报价单价等，对应单位分别为g/㎡、mm、元/千个、个等。

## 这些特征在「文档解析与分块」这一环带来什么约束
图文混排且含扫描件的结构，要求解析环节需支持OCR识别图片内嵌文字，避免丢失实拍样册的参数说明。固定字段带专属单位的特征，要求分块时保留参数与单位的绑定关系，不可拆分参数与对应度量值。文档按业务分为材质、报价、案例等语义块，需按业务逻辑拆分，不应仅按字符长度切割。不定期更新的物料特性，要求解析分块支持增量处理，适配新增或修订文档的快速同步。部分文档包含长表格的报价明细，需避免长表格被无意义截断导致语义断裂。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `ocr_enabled` | 开启 | 包装印刷文档多含实拍图、扫描件，需识别内嵌的参数与说明文字 |
| `chunk_size` | 800–1200 字符 | 文档包含长参数表格与业务描述，该区间可保留语义完整性，避免拆分关键业务块 |
| `chunk_overlap` | 10–15% | 需保留跨块的参数关联，避免材质、尺寸等关键信息被截断在分块边界 |
| `parse_scanned_pdf` | 开启 | 大量老包装样册为扫描件格式，需提取内嵌文字内容 |
| `UPLOAD_FILE_MAX_SIZE` | 200 MB | 支持多页厚样册、高清样册图片的完整上传 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 厚扫描文档或多页样册的解析需更长处理周期 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：知识库搜索时无法召回包装材质、报价等关键参数内容，或召回结果与查询关键词不匹配。原因：分块时未开启OCR识别扫描件或图文混排内容，导致关键参数未被提取到分块文本中。
- 现象：解析任务触发后长时间处于「解析中」状态，最终返回超时错误。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时间不足以处理厚扫描样册的解析流程。
- 现象：分块结果将完整的报价表格拆分为多个不相关的片段，导致搜索时无法获取完整报价信息。原因：仅按固定字符长度分块，未按业务语义块拆分，未配置合理的分块重叠率保留跨块关联。

## 怎么确认配好了
- 上传一份包含扫描件的包装样册PDF，查看解析后的文本内容，确认实拍图中的参数文字已被正确提取。
- 执行知识库搜索测试，输入材质克重、印刷工艺等专属字段关键词，确认可召回包含对应内容的分块结果。
- 查看分块详情页，确认长表格或参数块未被无意义截断，且相邻分块存在合理的重叠内容。
- 上传一份多页包装样册，确认上传与解析流程可正常完成，无报错提示。
