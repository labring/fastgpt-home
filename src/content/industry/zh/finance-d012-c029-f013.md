# 包装印刷营销内容的知识库检索与召回

## 这个品类的数据长什么样
数据来源包括企业自有印刷工艺手册、定制客户的需求文档、样稿扫描件、报价模板库。更新节奏随新材质上线、工艺迭代、大客户定制案例新增而分批更新。文档多为PDF格式的产品样册、Excel格式的报价单、Word格式的工艺说明，部分文档附带实物样稿的高清扫描图。字段包含材质克重（单位g/㎡）、印刷色数、成品尺寸（单位mm）、单批次起订量、交货周期（单位天）、报价单价（单位元/平方米）等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多类型文档的混合存在，要求解析环节适配PDF、Excel、Word等不同格式的结构化提取，避免结构化字段丢失。带明确单位的字段属性，要求检索时支持单位关联的语义匹配，避免出现单位混淆导致的无效召回。分批更新的特性，使得批量重建索引的操作需求频次较高，需要支持批量任务的可控执行。高图文占比的文档依赖OCR提取文本，OCR精度会直接影响召回内容的准确性。同质化内容较多的特点，要求召回环节加入额外的排序规则，避免相似内容的无效堆积。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前8–12条` | 包装印刷营销内容多为结构化的工艺、报价信息，单轮检索无需过多条目，8-12条可覆盖核心需求 |
| `相似度阈值` | `0.72–0.85` | 包装印刷文档存在大量同结构的相似内容，阈值过低会导致无关召回，过高会遗漏有效匹配项 |
| `分段长度` | `800–1200 字符` | 包装印刷的工艺说明、报价单多为短段落加结构化字段，分段过长会丢失字段关联信息，过短会破坏语义完整性 |
| `重排返回条数` | `前4–6条` | 营销内容需优先展示核心样册、报价模板，重排后保留少量高匹配条目即可满足获客场景需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 包装印刷的PDF样册多包含高清图片，OCR解析耗时较长，300秒可覆盖多数单文件解析需求 |
| `REINDEX_BATCH_SIZE` | `20–30 个文件` | 包装印刷的文档更新多为批次性，批量重建索引时20-30个文件可避免服务器负载过高，同时保证任务执行效率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：检索结果中旧的同质化文档排在新文档之前，未按更新时间优先展示。原因：未配置基于文档更新时间的权重加权规则，默认召回排序仅依赖相似度，未加入时间因子。
- 现象：批量重建索引时触发`504 Gateway Timeout`错误。原因：单次重建索引的文件数量超过服务器承载上限，未拆分批次执行。
- 现象：解析后的文档缺失材质克重、尺寸等结构化字段。原因：未开启针对Excel、PDF表格的结构化解析开关，仅提取了纯文本内容。

## 怎么确认配好了
- 上传一份包装印刷的报价单Excel和PDF样册，查看解析后的结构化字段是否包含克重、尺寸、单价等预设信息。
- 提交包含同质化旧文档和新文档的检索请求，核对返回结果中更新时间更近的文档是否排在前列。
- 执行批量重建索引操作，查看任务执行状态是否在预设的批次大小内未触发超时错误。
- 调整相似度阈值后，检索相同关键词，核对返回结果的数量是否符合预设的召回条数范围。
