# 包装印刷营销内容的部署与升级

## 这个品类的数据长什么样
包装印刷营销内容的数据主要来自设计团队的分层源文件（PSD、AI格式）、供应链物料规格表、品牌方提供的产品卖点与促销文案、终端物料投放记录。数据更新随新订单生成、新品上线及月度营销调整触发，无固定批量周期。文档结构包含物料元数据（物料ID、适用规格）、设计内容（矢量图形、文字排版）、关联产品信息（SKU、定价）及投放说明（适用渠道、有效期）。字段与单位遵循印刷行业标准，如尺寸用毫米、色数以CMYK值标注、材质使用通用行业术语。

## 这些特征在「部署与升级」这一环带来什么约束
包装印刷营销内容的大尺寸分层设计文件、多维度行业专属字段及高频更新特性，对部署与升级环节提出明确约束。大尺寸源文件要求部署时适配非通用文档的解析逻辑，避免解析失败或超时。高频更新的物料数据要求升级流程支持增量同步，避免全量重建导致的服务中断。行业专属字段（如材质、印刷色数）要求部署时预留自定义配置空间，无法直接使用通用知识库的字段规则。部分物料关联产品SKU，需配置跨知识库关联参数，确保检索时可联动关联信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 包装印刷的分层设计源文件解析耗时较长，默认超时时间无法完成完整解析 |
| `UPLOAD_FILE_MAX_SIZE` | `1500–2000 MB` | 包装设计源文件（如PSD、AI格式）通常体积较大，需适配大文件上传需求 |
| `RECALL_TOP_N` | `6–10 条` | 包装印刷营销物料包含多维度关联信息，需召回足够数量的相关内容支撑检索 |
| `PARSE_IMAGE_INDEX_ENABLE` | `开启` | 包装设计文件包含大量矢量预览图与工艺示意图，开启图片索引可提升跨物料检索准确性 |
| `SYNC_INCREMENTAL_ENABLE` | `开启` | 包装印刷物料随新订单、新品上线高频更新，增量同步可减少升级时的服务停顿 |
| `CUSTOM_FIELD_MAPPING` | `按物料元数据配置` | 包装印刷物料包含行业专属字段（如材质、印刷色数），需自定义字段映射适配业务需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：本地部署更新版本后，上传文档至知识库时无响应或返回`413 Request Entity Too Large`错误。原因：未同步更新`UPLOAD_FILE_MAX_SIZE`配置，新配置未生效导致大文件上传被拦截。
- 现象：新建知识库时无`图片索引模型`选项，无法对包装设计文件的预览图进行检索。原因：未开启`PARSE_IMAGE_INDEX_ENABLE`配置，若使用4.9.0版本部署，需确认是否已安装对应图片索引插件，该版本默认未内置该功能。
- 现象：Docker部署后，在模型管理界面无法找到第三方模型选项。原因：未在部署脚本中配置对应模型的接入密钥与接口地址环境变量，导致平台无法加载目标模型。

## 怎么确认配好了
- 上传一份包装设计源文件，检查解析任务的完成状态，确认超时配置符合业务需求。
- 上传体积较大的设计文件，检查上传流程是否正常，确认文件大小配置适配物料规格。
- 进入知识库配置界面，查看是否可启用图片索引功能，确认相关配置已开启。
- 触发增量同步操作，检查更新后的物料元数据是否正常同步，确认增量同步配置生效。
