# 化学制药营销内容的HTTP 接口与外部系统

## 这个品类的数据长什么样
化学制药的营销内容主要来源于金融机构（如保险、理财平台）合作药企的医学事务、合规及市场部门的官方素材，更新节奏随药品审批、说明书修订或合作方合规要求变动，无固定周期。文档结构包含结构化与非结构化混合形式：结构化内容包含药品通用名、商品名、适应症、禁忌、合规等级等字段，字段多采用定性描述；非结构化内容包括科普文案、医生沟通材料、会议纪要等，字数跨度从数百字到数万字不等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
金融机构的合规要求要求接口必须携带合规校验参数，且需支持前置校验逻辑；文档跨度大且结构混合，要求接口支持多格式输入输出与分段处理；更新频率不固定，要求接口支持动态拉取，可搭配定期缓存作为优化手段；内容涉及专业医学信息，要求接口具备权限隔离能力，区分金融机构内部不同角色的访问权限。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 化学制药营销内容包含长文档（如临床试验报告），需足够时间完成解析与合规校验 |
| `COMPLIANCE_VALIDATE_SWITCH` | `开启` | 金融机构合作的化学制药内容需符合医药行业合规要求，需在接口层前置校验合规标签 |
| `API_RATE_LIMIT` | `15 次/分钟` | 金融场景下化学制药营销内容的调用场景相对集中，避免触发外部合规接口的限流限制 |
| `RESPONSE_OUTPUT_FORMAT` | `结构化JSON + 原始Markdown` | 同时支持机器读取结构化字段（如药品名称、适应症）与人工审核原始内容 |
| `CACHE_DURATION` | `72 小时` | 药品合规内容更新频率较低，定期缓存可降低外部接口调用开销 |
| `MAX_PARSE_CHUNK_SIZE` | `1000–1500 字符` | 适配化学制药营销内容的分段处理需求，平衡解析效率与上下文完整性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用版本升级初始化接口时返回HTML格式内容，未返回成功提示。原因是部署环境未配置合法HTTPS证书，未添加证书跳过参数的请求被拦截返回错误页面。
- API编排流程无法实现循环生成营销素材。原因是未启用API编排的循环执行配置，或未正确设置循环触发的终止条件。
- 不同用户无法查看各自的历史对话记录。原因是未配置会话隔离参数，接口未携带用户身份标识进行会话区分，导致会话数据被共享。

## 怎么确认配好了
- 执行本地curl命令调用接口，检查返回内容为JSON格式，未返回HTML格式内容，可通过添加`-k`参数匹配无合法证书的部署场景。
- 提交一份典型的化学制药营销文档，检查接口返回的结构化字段包含预设的药品相关信息。
- 配置两个不同的用户身份标识，发起对话请求后分别核对各自的会话记录，确认数据隔离生效。
- 发起超过配置速率的请求，检查接口返回的状态码为`429 Too Many Requests`，确认限流配置生效。
