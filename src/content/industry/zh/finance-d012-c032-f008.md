# 化学原料营销内容的工具调用与插件

## 这个品类的数据长什么样
化学原料的核心数据来源包括公开化工行业数据库、供应商自营报价系统、行业协会发布的供需简报。基础参数如CAS登记号、产品规格、包装形式长期稳定更新；报价类数据每日同步更新，供需趋势数据月度更新。单条结构化数据包含十余项字段，字段包括产品标识、纯度指标、包装单位、当前报价区间、供应商所在地、交货周期等，单条非结构化的产品说明文本长度跨度较大。

## 这些特征在「工具调用与插件」这一环带来什么约束
化学原料的数据特征对工具调用与插件带来明确约束：报价类数据每日更新，要求工具调用配置短周期缓存失效机制，避免返回过时的营销素材；字段包含明确的单位与专属标识如CAS登记号，插件需严格校验参数格式与单位匹配，防止调用时出现参数错位；同时存在结构化与非结构化两类数据，需区分两种数据的调用逻辑，以CAS号作为结构化检索的优先键，提升调用准确性。营销内容需匹配实时行情，工具触发需绑定用户查询的实时性需求，不宜使用长期静态缓存。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `tool_call_cache_ttl` | `300 秒` | 匹配化学原料报价每日更新的频率，避免返回过时的营销素材 |
| `tool_call_param_schema` | `配置CAS号、包装单位、纯度指标的校验规则` | 化学原料字段包含专属标识与明确单位，需严格校验参数格式 |
| `max_tool_call_rounds` | `3 次` | 限制复杂参数校验的循环次数，避免无效调用占用资源 |
| `mcp_custom_headers` | `按目标接口要求配置自定义请求头` | 适配多数化工供应商接口的认证需求 |
| `tool_response_parse_mode` | `结构化优先解析` | 化学原料数据多为结构化字段，优先解析结构化结果提升内容准确性 |
| `tool_trigger_threshold` | `按实测标定` | 适配不同场景下的工具调用置信度要求，避免无效请求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用工具返回400 status code (no body)，界面显示工具调用失败，日志中无响应体内容。原因是未正确配置MCP自定义请求头，导致认证失败后接口返回空响应体。
- 模型函数调用效果差，生成的营销内容未匹配化学原料的专属字段如CAS号。原因是未配置工具调用参数校验规则，模型无法准确识别专属标识，导致调用结果不符合需求。
- 调用Mermaid MCP Server生成流程图失败，工作流中无法获取图片链接。原因是未配置工具响应的解析模式为结构化优先，导致未正确提取Mermaid生成的图片地址字段。

## 怎么确认配好了
- 发起一次包含CAS号的工具调用请求，检查返回结果是否包含最新的产品参数与报价信息。
- 查看工具调用日志，确认请求头已正确携带认证信息，无400类空响应体报错。
- 测试不同格式的参数输入，验证参数校验规则是否拦截不符合要求的请求。
- 生成营销内容，确认内容中包含化学原料的专属字段与实时数据。
