# 化纤营销内容的文档解析与分块

## 这个品类的数据长什么样
化纤行业的营销文档主要来源于金融机构合作的化纤企业内部产品手册、原料检测报告、下游应用案例集与行业标准文件，更新节奏随新品上线、工艺调整或行业标准更新触发。文档结构多包含固定模板：开篇为产品核心参数表格，中间为工艺说明与应用场景描述，结尾为合规声明与联系方式。文档内常见字段包括纤度（单位dtex）、断裂强度（单位cN/dtex）、熔点（单位℃），且常以表格形式对比不同型号产品的参数差异，部分文档会穿插高清产品图片与工艺流程图。

## 这些特征在「文档解析与分块」这一环带来什么约束
化纤营销文档的结构化参数表格与专业单位，要求解析环节需完整保留表格结构与单位关联，避免参数与单位拆分至不同块。长段工艺说明与跨型号参数对比内容，要求分块长度需适配专业术语的完整表述，避免截断核心信息。文档内穿插的图片与参数说明的绑定关系，要求解析环节需关联图片与对应参数块，避免错位。固定模板结构也要求解析逻辑适配常见的参数前置、工艺后置的排版，提升解析准确率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_TABLE_ENABLE` | `开启` | 化纤文档包含大量纤度、强度等结构化参数表格，保留表格结构可保证参数与单位的关联完整性 |
| `chunk_size` | `1200–1500 字符` | 化纤专业术语较长，分块长度适配单段工艺说明或参数组的完整表述，避免截断专业内容 |
| `chunk_overlap` | `150–200 字符` | 保证跨块的专业术语上下文连贯，避免参数与单位被拆分到不同分块 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 化纤营销文档常包含高清产品图片与工艺流程图，允许更大文件上传以完整导入素材 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 长文档解析需足够时间处理表格与图片关联，避免解析超时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：启动解析服务后报显存溢出错误，日志显示未识别到可用GPU。原因：未正确配置CUDA环境变量，或docker启动时未挂载`/dev/nvidia*`设备映射，当使用cuda版本12.8、显卡驱动570的环境时，该配置缺失会导致FastGPT无法调用指定显卡资源。
- 现象：解析后的markdown文档中，参数表格的单位字段丢失。原因：未开启`PARSE_TABLE_ENABLE`配置，默认解析逻辑仅提取纯文本内容，未保留表格结构与关联单位。
- 现象：分块结果中，单块包含多个不相关的产品参数组。原因：`chunk_size`设置过小，导致跨参数组的内容被强制拆分，破坏参数的完整性与可读性。

## 怎么确认配好了
- 上传一份包含纤度参数表格的化纤产品手册，检查解析后的markdown是否保留完整的表格结构与单位字段。
- 查看服务日志，确认识别到指定型号的GPU与可用显存，无显存溢出报错。
- 手动拆分一段长工艺说明文档，核对分块结果是否完整保留专业术语与关联参数，无截断情况。
- 测试上传单份500MB以内的含图片的化纤营销文档，确认解析过程无超时中断。
