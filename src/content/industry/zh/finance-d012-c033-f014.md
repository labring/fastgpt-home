# 化纤营销内容的表单与交互

## 这个品类的数据长什么样
这个品类的数据主要来源于上游炼化企业公开的产能与库存台账、大宗商品贸易平台的实时交易数据、下游纺织终端的订单对接台账。更新节奏存在分层：原料报价按交易日更新，库存与产能数据按周更新，终端订单数据按月更新。文档多为结构化格式，包含产品类别、规格型号、公称纤度、公称强度、库存余量、最新报价、更新日期等字段，其中纤度单位为旦尼尔，强度单位为厘牛/特，报价单位为元/千克，库存单位为吨。

## 这些特征在「表单与交互」这一环带来什么约束
分层更新的数据特征要求表单支持动态数据源切换，分别对接按交易日、周度、月度更新的接口，避免加载过期数据。多字段与特定单位的要求，需要表单内置单位校验规则，拦截不符合行业规范的输入内容。丰富的规格型号分类，要求表单实现联动选项逻辑，选择产品类别后自动加载对应可选的规格参数，减少手动输入错误。同时，营销场景下的表单需要关联数据生成素材，交互上需支持将表单填写的化纤参数一键映射到预设营销话术模板中。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `form_field_validation` | 配置正则匹配规则，允许输入数字加旦尼尔/厘牛/特/元/千克/吨 | 匹配化纤行业标准单位格式，拦截不符合规范的无效输入 |
| `chat_input_max_length` | 800–1200 字符 | 适配化纤规格参数与营销话术的组合输入长度，避免截断关键业务信息 |
| `similarity_top_k` | 前 6 条 | 匹配化纤品类细分规格的数量，召回足够的原料与订单数据支撑营销内容生成 |
| `knowledge_base_sync_interval` | 86400 秒 | 匹配上游原料报价按交易日更新的节奏，确保知识库数据时效性 |
| `form_submit_cooldown` | 60 秒 | 避免短时间内重复提交表单导致的接口请求过载，适配营销表单的提交场景 |
| `rerank_top_n` | 前 3 条 | 筛选最相关的化纤行业数据，生成精准的营销内容素材 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：在对话窗口的预设交互区域添加自定义选择按钮后，提交时配置未生效，界面无对应按钮。原因：未开启表单的自定义组件开关，错误将按钮配置写入普通文本回复模板，未绑定到表单交互模块。
- 现象：调用模型生成营销内容时返回`InvalidParameter`报错，提示参数未正确指定。原因：未在表单配置中绑定化纤品类的必填字段，模型调用时缺失产品类别、规格型号等必要上下文参数。
- 现象：表单提交后生成的营销内容未包含填写的化纤参数。原因：未配置字段映射规则，未将表单填写的纤度、强度等参数映射到营销话术模板的对应占位符中。

## 怎么确认配好了
- 填写包含非标准单位的化纤参数，确认表单会弹出校验提示并拦截无效输入。
- 查看知识库同步日志，确认数据更新周期与配置的`knowledge_base_sync_interval`取值匹配。
- 提交表单并生成营销内容，确认所有填写的化纤字段已正确映射到预设的话术模板中。
- 短时间内连续提交表单，确认触发提交冷却限制后会阻断重复请求。
