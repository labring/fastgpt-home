# 化纤营销内容的部署与升级

## 这个品类的数据长什么样
金融行业服务化纤企业的营销内容数据主要来源于企业内部化纤产品数据库、行业技术白皮书以及营销团队定制的推广物料。更新节奏分为两类：新品上市时触发全量更新，常规每周同步存量产品的参数调整。文档结构为结构化参数条目与非结构化营销话术混合，单篇物料长度跨度较大。结构化字段包含纤维类型、纤度、断裂强力、熔点等，其中纤度单位为分特，断裂强力单位为厘牛，熔点单位为摄氏度。

## 这些特征在「部署与升级」这一环带来什么约束
金融行业服务化纤企业的营销内容包含大量结构化专业参数与长文本营销话术，首先要求部署环节支持结构化字段的自动映射与提取，避免参数遗漏。其次，新品上市的突发更新与常规的存量参数调整，要求升级环节支持增量同步机制，无需全量重新导入全部物料。另外，单篇物料长度跨度较大，需在部署时预设适配的分段与召回阈值，避免长文本截断或短片段无效召回。同时，专业参数的唯一性要求，需在升级时校验字段格式的一致性，防止参数单位或定义混乱。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 化纤营销物料包含长文本与结构化参数，需足够时间完成完整解析 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 部分化纤产品手册包含技术图表与长文档，允许较大文件上传 |
| `分段长度` | `800–1200 字符` | 平衡专业参数与营销话术的上下文完整性，避免截断关键信息 |
| `召回条数` | `前 6–8 条` | 精准匹配化纤专业术语，避免引入过多无关内容 |
| `相似度阈值` | `0.75–0.85` | 保障专业术语的匹配精度，过滤低匹配度的无效内容 |
| `ENABLE_STRUCTURE_PARSE` | `开启` | 自动提取化纤产品的标准化参数字段，提升召回精准度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：部署后调用`getPluginGroups`接口返回500状态码，界面提示未配置商业版链接。原因：未在部署配置中关闭商业版插件依赖，开源版默认启用商业版API加载逻辑。
- 现象：上传的化纤产品手册解析后结构化字段为空。原因：未开启`ENABLE_STRUCTURE_PARSE`配置项，无法自动提取产品参数字段。
- 现象：升级同步后部分产品参数未更新。原因：采用全量同步机制，未启用增量同步机制，未配置增量更新的触发条件，导致存量参数未被覆盖。

## 怎么确认配好了
- 上传一篇包含明确参数的化纤产品手册，查看解析结果中的结构化字段是否符合预期配置，确认`ENABLE_STRUCTURE_PARSE`配置生效。
- 调用`getPluginGroups`接口，检查返回状态码是否正常，确认商业版依赖已正确关闭。
- 触发一次增量更新任务，查看指定产品的参数是否同步更新，确认增量同步机制正常运行。
- 测试长文本物料的解析与召回，确认分段长度与召回配置未导致关键信息丢失或无效召回。
