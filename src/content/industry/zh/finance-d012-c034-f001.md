# 医疗器械营销内容的HTTP 接口与外部系统

## 这个品类的数据长什么样
医疗器械营销内容作为金融/保险/理财领域获客的核心素材，数据主要来源于医疗器械注册证文件、产品说明书、临床研究报告、官方营销物料。数据更新节奏无固定周期，注册证变更、新品上市、政策调整时会触发更新。文档包含结构化与非结构化两类内容：结构化字段包含注册证编号、产品型号、适用科室、规格尺寸（单位为mm、g等）、注册证有效期；非结构化内容为长文本的说明书、临床案例、营销话术。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
作为金融/保险/理财领域的获客素材，结构化字段的固定格式要求接口必须配置专属校验规则，避免无效的注册证编号、规格单位等数据流入系统。无固定更新周期的特性要求接口支持增量同步模式，减少全量拉取带来的资源占用。长文本的说明书与临床报告可能超过单接口传输限制，需要支持分块传输或分片解析。多类型的营销物料格式要求接口适配多种文件解析协议，同时需校验文件内容是否包含医疗器械专属合规信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `900 秒` | 医疗器械说明书、临床报告通常篇幅较长，解析耗时较长，避免超时中断解析流程 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 包含临床数据的营销物料可能体积较大，支持大文件上传适配业务需求 |
| `SYNC_INCREMENTAL_ENABLE` | `开启` | 医疗器械数据更新无固定周期，增量同步可降低接口调用开销与系统负载 |
| `FIELD_VALIDATION_RULES` | `按注册证编号、规格单位配置专属校验规则` | 医疗器械数据字段有固定格式要求，避免无效数据流入知识库与工作流 |
| `RESPONSE_CHUNK_SIZE` | `800–1200 字符` | 长文本营销内容拆分后便于外部系统分段处理，适配多数系统的单次处理上限 |
| `API_RATE_LIMIT` | `80 次/分钟` | 医疗器械营销内容同步频率较低，合理限制避免接口过载 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用HTTP接口时返回`400 Bad Request`且无响应体。原因：未按医疗器械专属字段校验规则传递注册证编号、产品规格等必填字段，或字段格式不符合要求。
- 现象：调用API时指定`model`参数后，返回结果未执行预期的问题分类任务。原因：未将`model`参数绑定至医疗器械营销内容的分类工作流，错误绑定了其他类型模型。
- 现象：调用接口时出现超时错误。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`配置，默认超时时间不足以完成长文本说明书或临床数据的解析。

## 怎么确认配好了
- 调用测试接口，传递符合医疗器械专属字段格式的模拟数据，检查返回的响应状态码符合预期。
- 手动触发增量同步流程，核对拉取到的内容与外部系统存储的最新医疗器械数据一致。
- 上传一份医疗器械营销物料文件，检查解析流程未出现超时中断。
- 查看API发布的工作流配置，确认`model`参数已绑定至匹配的任务类型。
