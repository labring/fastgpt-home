# 医美营销内容的多轮对话与提示词

## 这个品类的数据长什么样
医美营销内容的数据主要来源于机构内部合规部门的项目备案文件、营销团队整理的宣传素材库，以及合作医美平台的公开合规素材与用户咨询历史记录。更新节奏随合规政策调整、新项目上线、季度营销节点变动而调整，无固定周期。文档结构通常按项目类型分为整形、皮肤护理、抗衰等分类，每个分类下包含项目名称、资质备案编号、适用人群范围、禁忌场景、宣传话术规范、关联素材链接等字段，字段多为文本或链接型，无复杂数值单位。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
医美营销内容的合规性要求，要求多轮对话的提示词必须嵌入合规校验逻辑，每轮输出前需核对是否匹配当前项目的备案信息，避免超出合规范围的宣传内容。多类项目分类的特征，要求上下文窗口需按当前对话关联的项目维度进行过滤，避免不同项目的历史上下文混淆模型判断。零散的用户咨询历史特征，要求上下文仅保留最近3轮的精准诉求，减少无关信息对模型的干扰。关联素材链接的特征，要求提示词需配置文件调用的触发规则，确保输出可附带合规的素材资源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContextTokens` | `8000–12000 字符` | 医美营销对话涉及项目细节、合规校验，过长上下文易触发token溢出，该区间可覆盖常规多轮咨询需求 |
| `contextFilterRule` | `按当前对话项目分类过滤` | 医美项目分类多，过滤无关上下文可避免模型混淆不同项目的合规要求与用户诉求 |
| `promptTemplateType` | `分类绑定式` | 不同医美项目的宣传话术规范差异显著，分类绑定提示词可精准匹配对应合规要求 |
| `fileUploadMaxSize` | `≤50 MB` | 医美营销素材包含长文档、高清案例图，该限制可平衡素材可用性与接口处理效率 |
| `responseComplianceCheck` | `开启，关联备案字段校验` | 医美宣传需符合监管要求，校验环节可确保输出话术匹配备案的项目范围与合规条款 |
| `multiModelTokenStrategy` | `独立计数` | 多模型编排时，不同医美项目的对话token消耗差异较大，独立计数可避免单模型token超限影响流程 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 多模型编排对话时出现`413 Request Entity Too Large`错误或总token消耗超限。原因是未配置`multiModelTokenStrategy`为独立计数，导致多模型的token消耗累计超出限额。
- 多轮对话中模型混淆不同用户的医美诉求，输出与前序提问无关的项目内容。原因是未配置`contextFilterRule`按当前对话项目分类过滤，保留了全量历史上下文导致信息混乱。
- 上传医美营销素材后接口返回`invalid file type`或`file size exceeds limit`错误。原因是未在配置中开启文件上传支持，或未指定允许的文件格式与大小范围。

## 怎么确认配好了
- 发起一轮包含明确医美项目分类与合规诉求的测试对话，核对模型输出是否关联当前项目的合规要求。
- 编排多模型对话流程，触发不同token消耗的测试用例，核对各模型的token计数是否独立。
- 上传符合常规大小的医美营销素材，核对接口是否正常返回文件关联链接。
- 配置多轮对话上下文，发起连续3轮不同诉求的咨询，核对模型是否保留前序的精准诉求。
