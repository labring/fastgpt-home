# 医美营销内容的工作流编排

## 这个品类的数据长什么样
医美营销内容在金融行业的营销场景下，核心数据来自金融机构与医美机构合作的配套营销物料、公开平台的医美项目介绍及合规资质文档。更新节奏随合作医美项目上线、季度促销活动调整及医师资质变更动态调整，无固定周期。单篇文档通常包含项目名称、适用人群、合作金融产品名称、医师执业证书编号、项目备案编号、服务周期、收费档位等字段，其中备案编号、资质编号为带固定格式的字符串，收费档位多为区间格式，服务周期以分钟为单位。

## 这些特征在「工作流编排」这一环带来什么约束
医美营销内容的专属字段与动态更新特征，对工作流编排提出明确约束。需增加字段校验环节，确保提取的备案编号、资质编号符合双重监管格式要求；需支持动态触发与定时触发结合的工作流启动方式，适配无固定更新周期的物料更新节奏；需配置精准的文本拆分规则，避免长文档跨模块拆分导致的内容提取偏差；需适配区间格式的收费档位提取，避免单一数值提取的错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 医美营销文档多包含多模块长内容，该区间可避免跨模块拆分导致提取错误 |
| `FIELD_VALIDATE_REGEX` | ^[医]?[美]?项目备案号[0-9A-Z]{10,15}$ | 适配医美项目备案编号的官方格式要求，精准校验合规字段 |
| `HTTP_RETRY_TIMES` | 2–3 次 | 医美营销物料多存储在机构内部文档库，网络波动可能导致拉取失败，该重试次数可平衡成功率与耗时 |
| `TEXT_EXTRACT_PROMPT` | 提取文档中所有项目备案编号、医师执业证书编号及单次服务收费范围 | 精准匹配医美营销内容的核心提取字段，避免无关内容干扰 |
| `WORKFLOW_TRIGGER_MODE` | 手动触发 + 每日凌晨定时触发 | 适配医美营销物料无固定更新周期的特征，兼顾手动更新与自动同步 |
| `SENSITIVE_WORD_CHECK_SWITCH` | 开启 | 医美营销内容需符合医疗广告监管要求，该开关可拦截违规宣传术语 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：文本提取组件返回空内容，重新添加同配置组件后可正常提取。原因：首次配置时未明确限定提取目标为医美专属字段，大模型默认提取范围过宽，未命中实际存在的目标内容。
- 现象：循环调用HTTP节点拉取医美营销物料时出现429状态码，工作流执行失败。原因：未配置HTTP请求的间隔参数，频繁发起请求触发机构内部文档库的限流规则。
- 现象：对话模型节点无法获取用户输入的问题内容，工作流报错变量未定义。原因：未正确调用对话模型内置的用户问题变量，未使用预设的标准变量名。

## 怎么确认配好了
- 手动触发工作流，导入一篇真实的医美营销文档，核对提取结果是否包含所有预设的医美专属字段。
- 配置定时触发规则后，等待预设时间窗口，检查文档库的更新标记是否同步到工作流输出。
- 开启敏感词校验开关后，输入包含违规医疗宣传术语的测试内容，确认校验环节正常拦截。
- 循环调用HTTP节点时，查看接口请求日志，确认请求间隔符合预设参数，未触发限流规则。
