# 半导体营销内容的工具调用与插件

## 这个品类的数据长什么样
半导体营销相关的数据主要来源于原厂产品规格书、供应链库存台账、行业新品公告及竞品参数对比文档。数据更新节奏分为三类：新品发布时实时同步，季度供需数据按季度更新，库存与供货周期数据每日刷新。文档结构包含结构化参数表与非结构化说明文本，结构化字段包含产品型号、制程节点、最大工作频率、静态功耗、封装类型、供货周期，其中制程节点单位为纳米，功耗单位为毫瓦，供货周期单位为周。非结构化文本包含产品应用场景描述、营销卖点说明。

## 这些特征在「工具调用与插件」这一环带来什么约束
半导体营销数据的结构化字段多且带有专有单位，要求工具调用的参数解析模块需精准匹配字段名与单位，避免泛化解析导致的参数错误。不同数据类型的更新频率差异显著，供货周期数据需每日拉取，新品数据需实时同步，要求插件配置支持按数据类型设置不同的缓存周期与拉取频率。营销内容生成常需跨数据源的参数对比，工具调用需支持同时调用原厂数据接口、库存接口与竞品数据接口，合并输出用于内容创作的结构化信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `function_call_max_count` | 3–5 次 | 单次对话内调用多类半导体数据源接口，控制次数避免上下文溢出 |
| `plugin_request_timeout` | 10–15 秒 | 半导体原厂接口响应稳定，设置合理时长避免无效等待 |
| `cache_expire_seconds` | 供货周期数据 86400 秒，新品数据 0 秒 | 匹配不同数据的更新频率，平衡实时性与调用效率 |
| `allowed_units` | ["nm", "mW", "GHz", "周"] | 限定可识别的单位，避免解析错误适配半导体数据格式 |
| `parallel_function_call` | 开启 | 支持同时调用多个数据源接口，提升跨参数对比的生成效率 |
| `function_call_prompt_template` | 按半导体产品参数格式抽取 | 预设模板适配结构化参数解析，降低泛化误差 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：开启工具调用功能后，大模型输出仅包含工具调用指令，未展示中间推理过程。原因：未启用思维过程输出配置项，或所选模型未同时支持工具调用与思维过程生成。
- 现象：工具调用返回的参数值单位错误，例如将制程节点显示为“微米”，实际应为“纳米”。原因：未配置`allowed_units`白名单，大模型泛化解析时误用了非半导体专有单位。
- 现象：工具调用请求超时，返回504状态码。原因：设置的`plugin_request_timeout`时长过短，未匹配半导体原厂接口的正常响应时间。

## 怎么确认配好了
- 发起包含半导体产品参数查询的测试对话，核对工具调用返回的参数是否匹配预设的单位与字段规则。
- 查看工具调用运行日志，确认不同类型数据的拉取与缓存时长符合配置要求。
- 检查对话返回结果，确认是否包含配置启用的思维过程与数据源引用信息。
- 发起跨数据源的参数对比查询，确认工具同时调用了多个配置的数据源接口并合并输出结果。
