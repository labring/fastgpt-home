# 半导体营销内容的知识库检索与召回

## 这个品类的数据长什么样
半导体营销相关数据主要来源于官方技术规格书、新品发布公告、行业标准文档、代理商分销物料及客户应用案例摘要，用于支撑营销获客的内容输出。数据更新无固定周期，随新品发布、行业标准变更或营销物料迭代触发更新。文档结构以结构化参数为主，包含器件型号、引脚定义、电气参数、封装类型、合规认证信息等字段，参数单位多为伏特（V）、毫安（mA）、摄氏度（℃）、引脚数（个）等专业计量标识，部分长文档包含跨章节的技术逻辑关联。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源分散的数据源要求检索系统支持跨文档库的联合索引，避免遗漏不同类型的营销物料，确保获客内容的全面性。无固定更新周期要求配置增量更新机制，确保新品参数、最新公告能及时被检索到，支撑最新营销内容的输出。结构化的参数字段与专业单位要求检索时需匹配字段语义与单位标识，避免将不同参数的器件内容混淆，保证营销内容的准确性。长文档的技术逻辑关联要求分段时保留上下文关联，防止割裂专业参数的完整表述，同时需控制单段长度以平衡检索精度与上下文承载量，提升营销内容的可读性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 半导体技术文档包含长参数句段，过长分段会丢失参数间的关联逻辑，过短会割裂技术表述的完整性 |
| `召回条数` | 前 6–8 条 | 营销内容需覆盖同系列器件的多参数对比，过多召回会导致上下文冗余，过少则无法覆盖完整的技术信息 |
| `相似度阈值` | 0.75–0.85 | 半导体专业术语的语义相似度需严格过滤，避免低匹配度的非目标器件内容被纳入检索结果 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 大型半导体技术白皮书或测试报告解析耗时较长，默认解析时长无法覆盖完整解析流程 |
| `增量更新开关` | 开启 | 半导体数据更新无固定周期，增量更新可及时同步最新发布的营销物料与参数变更内容 |
| `UPLOAD_FILE_MAX_SIZE` | 2000 MB | 单份晶圆测试报告或大型技术白皮书的文件体积较大，需适配大文件上传需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：对话返回的内容未匹配知识库内的半导体器件参数，与预设的营销内容不符。原因：未针对半导体专业术语调整embedding模型的语义适配，或相似度阈值设置过低，引入了无关的非目标文档内容。
- 现象：搜索测试时返回`413 Request Entity Too Large`报错。原因：`UPLOAD_FILE_MAX_SIZE`配置值小于上传的半导体技术文档体积，导致文件上传被拦截。
- 现象：知识库存在相关答案却未触发匹配，反而返回预设的兜底回复。原因：未开启工具调用的知识库优先匹配逻辑，或召回条数设置过少，导致相关文档未被纳入上下文范围。

## 怎么确认配好了
- 上传一份典型的半导体营销文档，检查解析后的分段是否保留了完整的参数句段，无明显的内容割裂。
- 输入包含具体器件型号和参数的查询词，核对召回结果的条数是否符合配置的召回条数范围。
- 触发增量更新后，上传新的新品公告文档，验证新内容是否能被正常检索到。
- 配置兜底回复后，输入知识库未覆盖的查询词，验证是否返回预设的指定回答内容。
