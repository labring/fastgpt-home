# 卫星通信营销内容的知识库检索与召回

## 这个品类的数据长什么样
卫星通信营销内容的数据来源包括卫星运营商官方频段文档、链路测试报告、覆盖区域方案、行业营销话术模板。数据更新节奏随频段政策调整、链路运维优化、营销活动上线不定期变化。文档结构包含数值型参数表、长段落技术说明、短文本营销话术，字段涉及上行频率、下行频率、EIRP值、覆盖半径等，单位多为MHz、dBW、km。

## 这些特征在「知识库检索与召回」这一环带来什么约束
卫星通信数据的数值型参数要求检索支持范围匹配，需调整向量模型的数值编码逻辑，避免参数匹配偏差。长链路测试报告的长文本需设置合理分段阈值，避免拆分后丢失关联的参数说明。短营销话术需调整相似度匹配规则，避免无关内容混入召回结果。不定期更新的运维文档需缩短知识库同步周期，防止召回过时的政策或链路参数内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `1500 MB` | 卫星通信营销文档常包含大体积的链路测试报告、频段分配手册，需放宽单文件上传上限 |
| `分段长度` | `900–1100 字符` | 卫星通信文档的技术段落多为900-1100字符，分段后可保留完整的参数关联说明 |
| `召回条数` | `前6条` | 营销内容需覆盖频段方案、话术模板、覆盖区域等多维度素材，6条可平衡召回覆盖范围与结果精准度 |
| `SIMILARITY_THRESHOLD` | `0.72–0.80` | 卫星通信的数值型参数与短营销话术的相似度匹配，需兼顾精准筛选与召回完整性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `1200 秒` | 大体积卫星文档解析需处理复杂的表格与公式，需延长超时阈值避免解析中断 |
| `KNOWLEDGE_REFRESH_INTERVAL` | `每7天` | 卫星频段政策、链路参数的更新周期多为季度，7天同步可覆盖临时运维调整 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：在社区版v4.9.1-fix2中上传190MB的卫星链路测试报告时，界面返回`offset is out of bounds`报错，且解析任务失败。原因：未调整`UPLOAD_FILE_MAX_SIZE`与`PARSE_FILE_TIMEOUT_SECONDS`参数，大文件分段上传时偏移量计算错误，且解析耗时超出默认阈值触发中断。
- 现象：部署70B大模型后，知识库关联的营销内容回复耗时超过25秒，日志显示模型推理阶段卡顿。原因：未限制召回的文档总字符数，过多的长段落卫星通信文档被纳入上下文，超出模型的有效推理范围。
- 现象：知识库召回结果中混入大量无关的旧频段政策文档，无法匹配当前营销需求。原因：未设置`KNOWLEDGE_REFRESH_INTERVAL`参数，知识库未同步更新最新的卫星运营数据，导致召回过时内容。

## 怎么确认配好了
- 上传单份200MB左右的卫星链路测试报告，检查上传与解析任务是否成功完成，根据结果调整相关参数。
- 发起包含频段参数、营销话术的测试查询，核对召回结果的条数与匹配度，根据匹配效果调整召回相关配置。
- 查看知识库同步日志，确认最新的卫星运营文档是否在设定周期内完成更新，根据更新频率调整同步参数。
- 发起包含长技术段落的测试查询，检查模型回复是否保留了完整的参数关联说明，根据回复完整性调整分段参数。
