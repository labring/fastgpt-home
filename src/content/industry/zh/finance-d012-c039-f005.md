# 厨卫电器营销内容的多轮对话与提示词

## 这个品类的数据长什么样
厨卫电器的营销相关数据主要来源于品牌官方参数手册、电商平台商品详情页、第三方合规检测报告。数据更新随新品上线、国家能效标准调整触发，无固定周期。文档多采用结构化参数表搭配使用说明文本的形式，核心字段包含额定功率（单位W）、有效容积（单位L）、安装外形尺寸（单位mm）、适用电压（单位V）、能效等级，部分产品附带适配户型尺寸、安装预留空间要求等补充字段。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
厨卫电器的结构化参数多且带明确单位，金融营销场景下的多轮对话需先引导用户提供安装空间、户型尺寸等前置需求，再匹配对应产品与金融分期、延保方案，避免直接脱离场景推荐。文档中参数与使用说明文本绑定，提示词需明确区分参数查询与金融方案适配类问答的触发逻辑，防止大模型混淆产品参数与金融费率信息。数据更新无固定周期，多轮对话需在首次调用知识库前校验目标型号的参数时效性，避免返回过时的产品信息或金融政策。字段单位统一要求需在提示词中明确标注，防止大模型出现数值与单位不匹配的输出，影响金融方案的精准推荐。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxHistory` | `3–5 轮` | 厨卫电器金融营销对话多为需求收集+产品匹配+方案推荐的多轮链路，3-5轮可覆盖用户从户型需求到分期方案的完整咨询过程，避免上下文过长导致模型混淆 |
| `chunkSize` | `800–1200 字符` | 厨卫电器参数文档多为结构化表与短文本结合，该分段长度可保留单款产品的完整参数组与适配说明，同时可关联对应产品的金融费率信息，防止参数拆分丢失关联信息 |
| `similarityThreshold` | `0.75–0.85` | 厨卫电器产品型号多且参数相似度高，该阈值可过滤低匹配度的无关产品数据，同时保留同品类不同型号的有效参数对比，便于为用户提供精准的金融分期方案 |
| `topN` | `前 3–5 条` | 单款厨卫电器的核心参数不超过5组，召回过多会导致模型冗余信息过载，影响产品匹配与金融方案推荐的精准度 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | 厨卫电器的参数文档多包含多页结构化表格，较长的超时时间可确保完整解析文件内容，避免解析中断导致参数或金融费率信息缺失 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 厨卫电器的产品手册与金融营销素材多为PDF或XLSX格式，单份文件体积通常不超过该阈值，可覆盖绝大多数营销素材的上传需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置了输入引导与词库后，对话界面未显示预设引导问题。原因：未开启应用的「启用输入引导」总开关，或词库未绑定至当前金融营销的对话场景。
- 现象：上传XLSX格式的产品参数与金融费率表至知识库后，调用对话时模型提示无法读取文件内容。原因：未启用XLSX文件的结构化解析插件，或上传文件时未勾选「自动解析为知识库条目」选项。
- 现象：多轮对话中模型未优先引用指定产品与金融方案的文档内容，而是返回通用行业知识。原因：提示词未明确指定需优先调用指定文件的知识库条目，或召回阈值设置过高导致指定文件的内容未被优先召回。

## 怎么确认配好了
- 进入应用的配置页面，查看输入引导相关开关与绑定词库的内容，确认配置项与预设金融营销场景的要求一致。
- 上传一份测试用的厨卫电器参数与金融费率文件，执行解析任务，查看解析日志是否显示结构化数据提取完成的提示。
- 发起一轮模拟对话，输入与产品参数及金融方案相关的问题，查看模型返回内容是否包含知识库中对应产品的信息与适配的金融方案。
- 测试多轮对话链路，依次输入户型需求、预算、分期意向等信息，确认模型可逐步收集信息并返回适配的产品与金融方案。
