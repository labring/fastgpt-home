# 厨卫电器营销内容的工作流编排

## 这个品类的数据长什么样
厨卫电器的营销相关数据主要来源于品牌官方产品规格书、电商平台商品详情页、售后故障排查文档，以及金融机构合作的家装分期产品列表。数据更新无固定周期，新品上线、功能迭代、能效标准调整或金融合作更新时会触发更新。文档结构以结构化参数表为核心，包含型号、额定参数、适用场景等字段，搭配功能描述文本与多媒体素材链接。字段多带明确单位，如排烟量单位为m³/min、热水产率单位为L/min，部分文档包含金融合作的分期费率与门槛信息。

## 这些特征在「工作流编排」这一环带来什么约束
结构化参数多且带专属单位的特征，要求工作流需配置精准的字段提取节点，避免冗余信息干扰金融营销内容生成。无固定更新周期的特征，要求工作流需支持事件触发与定时校验结合的启动模式，以覆盖新品、能效调整及金融合作更新等多类触发场景。包含多媒体素材与故障代码的特征，要求工作流需区分文本与多媒体处理节点，同时配置专属的分类模型用于故障与功能识别，适配金融营销的合规性要求。安全相关参数与金融费率字段的存在，要求工作流需增加参数校验节点，确保生成内容的合规性与准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `extract_product_fields` | 「指定字段映射：型号、排烟量、热水产率、适用气源」 | 厨卫电器的核心营销与金融合作参数为上述字段，需精准提取避免冗余信息干扰内容生成 |
| `rag_similarity_threshold` | `0.75–0.85` | 过滤低相关的营销素材，保留高匹配的产品参数与金融合作的分期信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 厨卫电器的产品手册与金融合作文档可能包含长文本与图片，较长超时可保证完整解析 |
| `classification_model` | `GPT-4o mini` | 可精准识别厨卫电器专属的故障代码与金融分期门槛，平衡识别准确率与运行成本 |
| `rag_recall_limit` | `前 3 条` | 厨卫电器营销内容需聚焦核心参数与金融信息，过多召回会导致文案冗余 |
| `workflow_timeout` | `900 秒` | 需处理多媒体素材生成与多字段校验，较长超时可避免中途中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流运行界面显示`RUNNING`状态超过预设的`workflow_timeout`时长，最终触发超时报错。原因：未针对包含金融合作信息的长文档设置合理的`PARSE_FILE_TIMEOUT_SECONDS`参数，或并行节点数量过高导致资源竞争。
- 现象：生成的营销内容中出现`[知识库召回：input=xxx, response=xxx]`格式的标记文本。原因：未在工作流的LLM节点配置中关闭知识库引用日志输出，未指定仅使用工具调用结果作为生成依据。
- 现象：工作流中的问题分类节点将厨卫电器的故障代码或金融分期门槛信息错误归类。原因：未针对厨卫电器的专属字段与金融参数配置针对性提示词，使用通用分类模型导致识别偏差。

## 怎么确认配好了
- 上传单份厨卫电器产品手册与金融合作文档，触发工作流运行，核对提取的字段与文档内的参数完全匹配。
- 查看工作流的输出结果，确认未包含知识库召回相关的标记文本。
- 提交包含不同故障代码与分期门槛的售后文档，验证分类节点可正确归类至对应场景。
- 批量运行3-5份测试文档，对比运行耗时，确认符合业务需求的时间阈值。
