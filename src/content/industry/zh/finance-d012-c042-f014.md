# 品牌代运营营销内容的表单与交互

## 这个品类的数据长什么样
品牌代运营的营销内容数据主要来自品牌方的活动报名表单、社交平台用户评论、合作渠道的客户留资。数据更新节奏覆盖实时交互反馈、每日表单汇总、每周 campaign 效果统计。文档形态包含结构化Excel客户留资表、多页Word格式的用户评论合集、单条短文本的用户咨询记录。字段包含敏感联系方式、服务需求类型、预算区间、预约时间，单位对应元、日期格式与品类标签。

## 这些特征在「表单与交互」这一环带来什么约束
这些数据特征对表单与交互环节带来明确约束。实时交互反馈要求系统支持即时响应，避免延迟导致用户流失。敏感联系方式字段需要配置加密存储，防止数据泄露。多页Word评论合集与15000+行Excel数据的长度超出常规阈值，需要适配长文本解析的配置。预算区间与服务类型的结构化字段需要预设可选范围，减少非标准化输入。活动报名的预约时间字段需要联动日历控件，避免无效时间提交。同时，品牌代运营需适配不同合作品牌的话术风格，因此交互环节的提示文案需支持灵活配置，匹配各品牌的营销调性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配10万中文字的Word文档与15000+行Excel数据的上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 避免长文档解析时触发超时中断 |
| `maxContext` | 8000–12000 字符 | 容纳多轮用户咨询与长文档解析后的上下文内容 |
| `召回条数` | 前 8 条 | 匹配品牌代运营多维度的营销素材与用户留资数据 |
| `相似度阈值` | 0.75 | 过滤低匹配度的无效留资与评论数据 |
| `敏感数据脱敏开关` | 开启 | 保护用户提交的联系方式等敏感字段 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：输出内容中包含「引用标记：［1］」字样。原因：未关闭知识库引用标记的自动添加配置，导致检索结果的来源标记被直接带入回复。
- 现象：用户输入指定关键词后未触发自定义接口回复。原因：未配置关键词触发规则，或触发规则的匹配阈值设置过高，导致关键词未被正确识别。
- 现象：15000+行Excel数据解析后返回不完整内容。原因：未调整`UPLOAD_FILE_MAX_SIZE`与`PARSE_FILE_TIMEOUT_SECONDS`的配置，导致长表格解析中断或截断。

## 怎么确认配好了
- 上传单份10万中文字的Word文档与15000+行的Excel数据，核对解析后的内容完整性与解析耗时，调整配置项至符合业务需求。
- 提交包含敏感联系方式的测试表单，核对后台存储的数据是否已完成脱敏处理，验证敏感数据脱敏开关的生效状态。
- 输入预设的关键词，核对系统是否触发自定义接口回复，调整关键词匹配规则至符合预期的触发条件。
- 发起多轮关于营销素材的咨询，核对上下文是否被正确保留，调整`maxContext`的配置至适配多轮对话的长度需求。
