# 固废处理营销内容的模型接入与配置

## 这个品类的数据长什么样
固废处理的营销内容数据来源包括行业政策文件、项目落地案例文档、设备参数手册、客户咨询FAQ及行业调研报告，其中面向金融机构投资者的内容还包含项目融资测算数据。更新节奏存在差异，政策文件随监管要求季度或年度更新，项目案例随新落地项目实时更新，设备参数随产品迭代更新，FAQ随客户咨询新增调整。文档结构分为政策类（含文号、发布单位、适用范围、处置要求）、项目类（含地点、处理量、设备型号、运营数据、融资测算）、设备类（含型号、处理能力、能耗、材质），字段单位包含吨/日、kWh/吨、融资额度等专业计量标识。

## 这些特征在「模型接入与配置」这一环带来什么约束
面向金融机构投资者的固废处理营销内容，需同时包含政策合规性内容与融资测算数据，政策类文档篇幅较长且包含大量专业术语，要求模型具备足够长的上下文窗口以完整处理全文内容，避免信息截断。项目案例同时包含结构化数值与非结构化描述，需配置分层召回规则，区分匹配政策合规内容与项目实操及融资测算内容。设备参数与融资数据的单位与精度要求严格，需确保模型调用时保留字段的原始单位，避免生成错误的计量表述。营销内容更新节奏差异大，需配置定时同步的触发参数，匹配不同类型内容的更新频率，保障内容时效性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–16000 字符` | 固废处理政策与项目文档篇幅较长，需覆盖完整上下文以准确生成合规的营销内容 |
| `chunkSize` | `1200–1500 字符` | 固废设备参数、项目案例的文本结构适合该分段长度，可保留字段完整性与可读性 |
| `similarityThreshold` | `0.72–0.85` | 需区分专业术语与通用表述，避免召回无关的政策或设备内容，提升营销内容的精准性 |
| `recallTopK` | `前6–8 条` | 营销内容需兼顾政策合规性与项目实用性，召回适量内容支撑生成逻辑 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 大型固废项目案例文档解析耗时较长，避免因超时导致解析失败 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 可容纳批量的设备手册、政策汇编等文档，适配批量营销素材的上传需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为添加知识库后调用报错，返回状态码500，原因是未适配固废处理文档的长文本分段，导致分段后上下文溢出，该问题在FastGPT 4.8.14版本中较为常见。
- 现象为模型调用时无法选中配置的本地大模型，原因是未正确配置`API_BASE_URL`指向本地模型的接口地址，或未填写与本地模型一致的模型名称。
- 现象为生成的营销内容中设备参数单位错误，原因是召回内容时未保留原始字段的单位信息，导致模型生成不符合行业规范的计量表述。

## 怎么确认配好了
- 上传一份固废处理设备手册文档，查看解析后的分段是否保留了完整的参数字段与单位，核对分段长度是否符合配置值。
- 发起一次模型调用，查看返回的模型列表是否包含配置的本地大模型，核对接口地址与模型名称是否正确。
- 测试生成一条针对固废处理项目的营销内容，检查生成内容中是否包含准确的政策依据与设备参数，核对召回内容的条数是否符合配置。
- 上传一份超过设定大小的文档，查看是否触发上传限制提示，核对`UPLOAD_FILE_MAX_SIZE`的配置是否生效。
