# 固废处理营销内容的表单与交互

## 这个品类的数据长什么样
固废处理相关数据主要来自企业内部固废处置台账、第三方清运记录、环评备案文件及合规检测报告。数据更新节奏随业务推进调整，日常清运台账每日更新，年度合规备案每季度或年度更新。文档多为结构化Excel表格或合规PDF报告，核心字段包含固废类别、清运重量（单位：吨）、处置单位、备案编号、清运日期，部分长文档包含多批次处置明细与合规说明。

## 这些特征在「表单与交互」这一环带来什么约束
固废处理数据的结构化字段与合规属性，要求表单需针对固废类别设置分级选择控件，重量字段限定单位为吨并添加数值范围校验。多来源的台账数据要求表单支持批量导入结构化文件，同时需校验备案编号等唯一标识字段的重复提交。合规文档的上传环节需限定支持Excel、PDF格式，且对单文件大小设置合理阈值，避免大文件解析超时。长文档的明细内容需支持分段提取，确保营销内容中可精准调用合规数据片段。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 固废处置的合规PDF或Excel台账通常单文件不超过500MB，避免上传超时 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 长文档的合规报告解析需较长时间，300秒可覆盖多数大文件解析需求 |
| `召回条数` | `前8条` | 固废处理的合规数据条目相对专业，少量精准召回可避免信息过载 |
| `相似度阈值` | `0.75` | 需过滤低匹配度的非合规数据，确保调用的内容符合固废处置的专业要求 |
| `表单字段校验规则` | 按实测标定 | 不同企业的固废类别分级存在差异，需适配业务实际的字段校验逻辑 |
| `批量导入模板匹配` | 绑定固废处置台账标准格式 | 固废处理的台账字段固定，绑定标准格式可减少导入错误 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：知识库搜索时通过变量引用选择知识库，返回结果为空或匹配错误。原因：未正确配置`知识库变量绑定参数`，未指定需关联的知识库ID或过滤字段。
- 现象：表单提交后提示“字段格式错误”，但填写内容符合常规逻辑。原因：未适配固废重量字段的单位校验，强制要求填写非吨数值或未开启数值范围校验。
- 现象：批量导入台账文件时，部分处置记录未被解析。原因：未匹配固废处置台账的标准字段顺序，解析模块无法识别对应字段内容。

## 怎么确认配好了
- 上传一份标准固废处置台账文件，检查解析后提取的字段是否与预设表单字段一致。
- 填写表单的固废重量字段，输入非吨数值或超出合理范围的数值，校验提示是否正常触发。
- 配置知识库搜索的变量引用参数，选择绑定的知识库，发起测试查询，检查返回结果是否来自指定知识库。
- 发起批量导入测试，检查导入的记录条数与源文件一致，无遗漏或错误解析的条目。
