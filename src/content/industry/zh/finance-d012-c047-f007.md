# 国有大行营销内容的工作流编排

## 这个品类的数据长什么样
国有大行营销内容的数据主要来源于内部CRM客户管理系统、线下网点营销物料库、手机银行与官方公众号的历史发布素材。数据更新节奏以月度为固定周期，部分紧急营销活动素材会按周追加更新。单条营销内容文档包含产品适配编号、客群标签字段、发布渠道枚举值、生效与失效日期字段，单位分别为纯数字、枚举字符串、枚举值、日期格式。

## 这些特征在「工作流编排」这一环带来什么约束
多源数据接入要求工作流配置多数据源同步节点，需兼容不同系统的接口格式与权限校验规则。固定月度更新与临时追加更新的混合节奏，要求工作流支持定时触发与手动触发两种启动模式，适配常规素材更新与紧急活动需求。客群标签、发布渠道的枚举字段约束，要求工作流中加入格式校验节点，过滤非法枚举值。生效与失效日期字段要求工作流嵌入时间判断节点，自动过滤已过期的营销内容，避免违规发布。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `trigger_mode` | `定时触发+手动触发双模式` | 适配月度固定素材更新与临时紧急营销活动的不同启动需求 |
| `data_source_sync_interval` | `86400 秒` | 匹配月度更新的基础同步节奏，临时素材可通过手动触发跳过定时周期 |
| `enum_field_validate` | `开启，校验客群标签、发布渠道枚举值` | 适配营销内容中固定枚举字段的格式要求，过滤非法输入 |
| `time_filter_threshold` | `当前日期前后1天` | 覆盖营销活动的提前预热与过期收尾缓冲期，自动过滤无效内容 |
| `workflow_call_log_switch` | `开启全链路日志记录` | 满足营销内容生成与分发的可追溯合规要求 |
| `global_var_url_transfer` | `开启，允许携带自定义参数` | 支持按客群标签动态传递参数，适配不同渠道的个性化营销需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用已部署的营销问答应用后，工作流未生成对应对话日志。原因：未开启`workflow_call_log_switch`配置项，导致链路日志未启用。
- 现象：旧工作流运行时弹出“文本加工节点不存在”的报错提示。原因：未开启`text_process_node_compat`兼容模式，升级后默认关闭旧版节点支持。
- 现象：工作流生成的营销内容未过滤过期素材，出现已失效的活动信息。原因：未配置`time_filter_threshold`时间校验节点，未按生效与失效日期过滤内容。

## 怎么确认配好了
- 手动触发一次工作流，检查多数据源是否同步了最新的营销素材，确认同步范围覆盖配置的数据源类型。
- 输入一条包含非法客群标签的测试素材，确认工作流触发格式校验拦截，过滤非法内容。
- 导入一条已过失效日期的测试素材，确认工作流自动过滤该内容，不进入后续处理环节。
- 调用已部署的营销问答应用，检查工作流链路中是否生成完整的对话日志，确认日志记录开关已生效。
