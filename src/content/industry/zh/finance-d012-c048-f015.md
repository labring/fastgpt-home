# 城商行营销内容的部署与升级

## 这个品类的数据长什么样
城商行营销内容的数据主要来自内部营销素材库、合规审批后的产品文档、网点触达话术模板，以及客户分层运营的历史话术数据。更新节奏随营销节点、新品上线及合规要求调整，无固定周期但集中在季度末、节日前及产品迭代期。文档多为结构化模板，包含产品标识、收益说明、额度范围、适用客群、合规提示等字段，部分模板包含客群适配变量，文件格式以PDF、Word及结构化JSON为主。

## 这些特征在「部署与升级」这一环带来什么约束
城商行营销内容的结构化模板属性，要求部署时需配置变量替换的召回匹配规则，确保触达内容可适配不同客群。合规提示字段的强制展示要求，需在知识库召回环节配置优先级参数，避免合规信息遗漏。非固定周期的更新节奏，要求升级流程支持快速替换素材库，无需等待批量同步任务。多格式的文件输入，需配置适配PDF、Word及结构化JSON的解析参数，保障各类营销素材均可被正确提取。同时，城商行的触达场景覆盖线上线下，部署环节需预留渠道适配的扩展接口。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 城商行营销素材包含高清宣传物料及结构化文档，1000 MB可覆盖大部分批量上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 长文档及合规页较多的营销素材解析耗时较长，600秒可保障完整解析 |
| `分段长度` | `800–1200 字符` | 营销内容需保留完整的产品说明及合规提示，该区间可避免拆分破坏内容完整性 |
| `召回条数` | `前 8 条` | 城商行营销内容需兼顾精准性与合规性，8条召回结果可覆盖主要营销场景的信息需求 |
| `相似度阈值` | `0.75–0.85` | 需平衡营销内容的相关性与合规性，该区间可避免召回无关或违规的素材 |
| `重排返回条数` | `前 3 条` | 最终输出需聚焦核心营销信息，3条重排结果可保障触达内容简洁合规 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为使用ollama部署deepseek-8b模型并通过oneapi接口测试后，在FastGPT 4.9.0版本的模型配置页提交后返回404错误。原因是未正确配置oneapi的转发地址或密钥权限，导致FastGPT无法正常调用部署的模型。
- 现象为批量上传城商行营销素材后，部分结构化文档的合规提示字段未被提取。原因是未开启结构化JSON的专属解析开关，导致非标准格式的模板无法被正确识别。
- 现象为知识库可创建数量无法达到预期，无法创建超过30个知识库。原因是使用了pgvector作为向量数据库，其默认配置下的知识库数量上限为30个，未进行数据库参数调整。

## 怎么确认配好了
- 上传一份包含合规提示字段的营销文档，检查解析结果中是否完整保留了所有预设字段，以此确认解析配置是否符合要求。
- 发起一次知识库召回测试，输入与营销内容相关的查询词，核对返回的结果数量是否匹配预设的配置参数。
- 调用部署的模型，输入测试查询语句，确认无接口报错且返回内容符合预期，验证模型调用配置正确。
- 查看向量数据库的连接日志，确认无连接异常报错，验证存储配置生效。
