# 塑料橡胶营销内容的文档解析与分块

## 这个品类的数据长什么样
塑料橡胶品类的数据源主要包括行业协会月度供需报告、生产企业批次质检报告、贸易商实时报价单、产品营销手册及专利技术文档。数据更新节奏随文档类型差异明显，报价单随市场行情实时更新，行业报告按月度发布，质检报告随生产批次生成。文档结构包含结构化参数表格、长文本技术说明、带性能曲线的营销物料，字段涵盖牌号、门尼粘度、邵氏硬度、熔融指数等，单位多为MPa、g/10min、邵氏A等专业化工单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
结构化参数表格的跨页分布要求解析模块识别并保留单元格对应关系，避免参数错位。实时更新的报价单格式多变，包含临时调整的字段，要求支持自定义字段映射。长文本技术说明包含大量专业术语，分块时需保留术语上下文完整性，避免拆分导致参数含义断裂。带性能曲线的营销物料需提取图表关联的文字说明，避免仅提取纯文本丢失关键数据。批量质检报告需按批次分组存储分块内容，便于后续精准召回相关数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxChunkSize` | 800–1200 字符 | 塑料橡胶专业文档包含长句技术说明，该区间可保留术语上下文，避免拆分断裂 |
| `chunkOverlap` | 100–150 字符 | 跨块的专业术语需保留衔接，避免召回时丢失关联参数 |
| `PARSE_TABLE_ENABLE` | 开启 | 品类文档多结构化参数表格，开启后可完整提取单元格数据与对应关系 |
| `PARSE_CHART_TEXT_ENABLE` | 开启 | 营销物料常附性能曲线，开启可提取图表关联的文字说明 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 批量质检报告与行业报告单文件体积较大，该取值适配批量上传需求 |
| `PARSE_TIMEOUT_SECONDS` | 600 秒 | 长文本技术文档解析需较长处理时间，避免超时中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传pdf文档后，界面无解析完成提示且搜索测试结果为空。原因：未开启`PARSE_TABLE_ENABLE`配置，结构化表格参数未被提取，导致分块内容为空。
- 现象：搜索测试返回结果遗漏部分性能参数。原因：`maxChunkSize`取值过小，将包含完整参数的长文本拆分为多个块，部分块未被召回触发。
- 现象：对话中生成的文字内容被纳入知识库分块。原因：未关闭非上传文档的自动解析开关，非目标内容被错误纳入解析流程。

## 怎么确认配好了
- 上传单份结构化参数表格文档，查看解析后的分块内容，确认所有表格单元格数据均被完整提取。
- 上传包含性能曲线的营销物料，核对分块内容中是否包含图表关联的文字说明。
- 上传批量文档，检查数据处理步骤是否生成对应数量的分块，无空值条目。
- 触发搜索测试，输入专业术语如“门尼粘度”，确认召回结果包含对应参数的完整上下文。
