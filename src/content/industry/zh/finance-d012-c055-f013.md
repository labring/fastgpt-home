# 大气治理营销内容的知识库检索与召回

## 这个品类的数据长什么样
大气治理营销内容的数据主要来源于金融机构绿色信贷业务配套的项目交付文档、环评审批报告、技术研发白皮书、客户案例集，以及行业公开的环保标准文件。更新节奏随新政策落地、项目交付完成或营销活动调整按需触发，无固定周期。单份文档通常包含项目名称、治理工艺类型、污染物排放控制参数、适用场景、服务流程等字段，参数单位多为mg/m³、Nm³/h、吨/年等专业环保计量单位，部分营销物料会额外包含客户反馈、方案报价范围等内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束
专业参数与场景化营销内容混合的文档结构，要求检索同时支持精确匹配技术术语和语义匹配场景需求；多来源的数据需要区分官方标准与项目案例，避免召回内容出现标准冲突；按需更新的特性要求支持增量同步，不采用全量重爬，以降低平台负载；较长的技术段落需要合理分段，避免检索时丢失关键逻辑关联。同时，面向企业客户的营销属性要求召回结果需兼顾专业严谨性与易懂性，不能仅返回纯技术文档。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunk_size` | `1000–1500 字符` | 大气治理文档多包含长段工艺参数与案例描述，该分段长度可保留专业逻辑完整性，同时保障检索精准度 |
| `maxContext` | `8000–12000 字符` | 适配长文档的上下文传递需求，避免因上下文截断丢失关键的项目背景与参数信息 |
| `RECALL_TOP_K` | `前 8–12 条` | 兼顾技术细节与营销信息的展示需求，过多结果会分散用户注意力，过少无法覆盖不同客户的关注点 |
| `SIMILARITY_THRESHOLD` | `0.72–0.80` | 平衡专业术语匹配与场景语义匹配，避免无关通用环保内容混入，同时保留适配客户需求的召回结果 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 适配大型环评报告、多页技术白皮书的解析耗时，避免因超时导致文档解析失败 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 容纳包含图纸、数据表格的完整项目文档，避免因文件过大无法上传 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：通过网页静态链接生成知识库时返回`Validation failed: name: Path `name` is required.`错误。原因：未填写知识库条目必填的名称字段，或爬虫抓取的页面未提取到有效标题作为默认名称。
- 现象：查看聊天回答的知识库引用时出现报错，返回`404 Not Found`或字段为空。原因：知识库文档被删除或移动位置，未同步更新索引，或召回的文档路径配置错误。
- 现象：无法接入飞书知识库的数据，无法完成数据同步。原因：未配置飞书开放平台的API权限，或未开启飞书知识库的公开访问权限，导致数据抓取失败。

## 怎么确认配好了
- 上传一份典型的大气治理技术白皮书，检查解析后的分段是否保留了完整的工艺参数段落，无明显截断或逻辑断裂。
- 发起包含专业术语的检索请求，核对召回结果的`name`字段是否匹配文档标题，无缺失或错误。
- 模拟多并发检索请求，检查是否触发限流报错，确认限流参数适配业务请求节奏。
- 查看知识库索引日志，确认新增的营销物料文档已完成增量同步，无解析失败的条目。
