# 小家电营销内容的工具调用与插件

## 这个品类的数据长什么样
小家电营销相关的数据主要来源于品牌方官方商品参数文档、电商平台上架的商品详情字段、金融机构内部的礼品兑换规则台账与实时库存数据。每个SKU对应独立的数据文档，包含商品名称、SKU编码、材质类型等基础属性字段，额定功率、额定电压、净重等性能参数字段，以及适用场景、核心卖点等营销适配字段，还有兑换积分、库存余量等金融场景专属字段。性能参数的单位固定为瓦特（W）、伏特（V）、毫米（mm）等国际通用单位。商品基础参数文档在新品上线或规格调整时更新，兑换规则与库存数据按活动周期或每小时同步更新。

## 这些特征在「工具调用与插件」这一环带来什么约束
小家电的参数字段多且单位固定，工具调用时需要严格匹配字段名与预设单位，避免出现单位转换错误导致的营销内容偏差。兑换规则与库存数据的更新频率较高，插件调用时需要配置短周期的缓存过期时间，避免返回过时的库存或兑换信息。单个SKU的数据包字段数量较多，工具调用的上下文窗口需要预留足够空间承载完整参数，避免截断导致的参数缺失。不同小家电细分品类的字段差异明显，插件需要支持动态加载对应品类的字段映射规则，避免调用错误字段。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolCallTimeout` | `30 秒` | 小家电数据的更新延迟要求，30秒内可获取最新的促销与库存数据，避免超时导致的营销内容滞后 |
| `pluginCacheTTL` | `10 分钟` | 小家电促销活动与库存数据的更新频率，10分钟的缓存周期可平衡数据时效性与接口调用压力 |
| `maxToolCallsPerRequest` | `3–5 次` | 单个SKU的参数字段数量，3-5次工具调用可覆盖基础属性、性能参数与营销卖点的完整获取 |
| `toolFieldMatchThreshold` | `0.85` | 小家电字段名称的标准化程度，0.85的匹配阈值可准确识别参数字段，避免误匹配非目标字段 |
| `mysqlMultiQueryEnabled` | `开启` | 小家电营销内容生成时需要同时执行库存查询与促销信息插入的多行语句，开启后可支持批量SQL操作 |
| `maxContext` | `8000–12000 字符` | 单个SKU的参数数据包长度，该区间可完整承载所有字段信息，避免上下文截断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：执行MySQL数据库插件时返回“multi statements not allowed”报错。原因：未开启`mysqlMultiQueryEnabled`配置项，默认限制单次调用仅执行单条SQL语句，无法处理AI生成的多行查询语句。
- 现象：工具调用结果不稳定，出现参数缺失或单位错误的情况。原因：未加载对应小家电品类的字段映射规则，且未设置合理的`toolFieldMatchThreshold`，导致模型无法准确匹配目标参数字段。
- 现象：并发调用工具接口时触发限流或超时错误。原因：未配置合理的缓存与调用频率参数，导致高频调用相同接口或单次请求占用过多平台资源。

## 怎么确认配好了
- 发起单SKU的工具调用测试，检查返回的参数字段是否与官方文档一致，单位是否符合小家电的通用规范。
- 配置MySQL数据库插件，尝试执行包含INSERT与SELECT的多行语句，确认无报错后完成验证。
- 模拟并发请求，观察接口返回状态码，调整相关配置项至符合业务的实时性与并发需求。
- 查看工具调用日志，确认每次调用的上下文未出现截断，所有参数字段均被完整加载。
