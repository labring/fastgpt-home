# 小金属营销内容的多轮对话与提示词

## 这个品类的数据长什么样
用于金融场景下小金属营销内容的数据，主要来源于国内有色金属工业协会、专业现货交易平台、海关进出口公开数据及矿山企业披露信息。现货报价类数据每日更新，库存与进出口数据每5个工作日更新，行业分析报告每季度更新。数据文档结构分为三类：现货报价表包含品种、产地、规格、报价、价格变动情况相关字段；库存统计表包含仓库位置、库存总量、存储规格字段；进出口数据表包含月度总量、贸易国别、关税税率字段。字段单位统一采用通用大宗商品计价单位，如元/吨、吨、千克。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
用于金融场景的小金属营销内容的多轮对话与提示词，需适配小金属数据的特征：更新周期差异要求多轮对话需区分实时与历史数据的调用时机，避免返回过期的现货价格或滞后的库存数据；专业字段的统计口径分散，需在提示词中固化明确的口径与单位，防止混淆不同来源的统计结果；多源数据的调用规则需预先绑定，避免跨数据源的字段混淆；长周期的行业报告内容需拆分后召回，防止超出上下文窗口限制导致内容截断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 字符 | 小金属数据包含多字段的专业内容，需保留足够上下文避免专业术语断档 |
| `promptTemplate` | 固定指定数据源口径与字段单位 | 小金属统计口径分散，需明确标注报价类型与计价单位，防止结果混淆 |
| `recallTopK` | 前6–8条 | 小金属专业数据相关性强，过多召回会引入无关字段，过少会遗漏关键信息 |
| `similarityThreshold` | 0.75–0.85 | 过滤低相关性的行业杂项数据，保留与小金属营销内容强相关的字段 |
| `streamResponseInterval` | 500–1000 毫秒 | 控制流式输出节奏，适配小金属专业内容的展示逻辑，优化前端加载体验 |
| `apiResponseTimeout` | 300 秒 | 小金属部分数据源接口响应较慢，需预留足够的请求处理时间 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：流式输出内容中的链接点击后仅覆盖当前页面，无法跳转新页面。原因：未在生成的营销内容链接中添加`target="_blank"`属性，导致浏览器默认使用当前窗口加载链接。
- 现象：v4.8.10版本的对话日志详情页内容与实际回答内容不符，多次对话后详情页始终展示同一段内容。原因：未正确设置`sessionId`参数，不同对话会话绑定了相同的上下文标识，日志系统未正确区分会话。
- 现象：流式输出返回间隔固定为4秒，无法调整为1-2秒以优化前端展示效果。原因：未修改`streamResponseInterval`参数的默认配置，仍使用平台预设的4000毫秒间隔。

## 怎么确认配好了
- 发起包含小金属专业术语的测试对话，核对返回内容是否明确标注了约定的统计口径与单位。
- 开启流式输出功能，调整对应参数后，观察前端内容返回的节奏是否符合预设要求。
- 发起多轮独立对话，核对每轮对话的日志详情是否与该轮的实际回答内容匹配。
- 测试生成内容中的链接，点击后确认是否在新浏览器窗口中打开。
