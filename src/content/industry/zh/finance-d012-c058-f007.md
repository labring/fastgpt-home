# 小金属营销内容的工作流编排

## 这个品类的数据长什么样
小金属的行业数据主要来自国内有色金属工业协会的月度简报、专业现货交易平台的实时报价、矿山及冶炼企业的公开产销公告。数据更新节奏分为三类：现货报价每日更新，库存与产销数据每周更新，行业分析报告按月更新。单份数据文档通常包含品种标识、当日现货均价、区域出厂价、月度累计产量、进口出口量、库存周转天数等字段，单位涵盖元/吨、千克、立方米等，部分细分品类还会附带原料纯度参数。

## 这些特征在「工作流编排」这一环带来什么约束
小金属数据的分层更新节奏，要求工作流配置多定时触发节点，分别适配每日、每周、月度的数据拉取任务。字段与单位的多样性，要求数据预处理节点添加多套格式校验规则，针对元/吨、千克等不同单位做转换适配，避免数值计算偏差。细分品类的专属参数差异显著，要求工作流分支节点支持按品类动态加载对应模板与参数，避免通用内容的适配误差。部分行业数据源存在调用频次限制，要求工作流添加限流与自动重试配置，防止触发调用限制导致的任务中断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `workflow_cron_expression` | `0 0 8 * * *`（每日8点）、`0 0 0 * * 0`（每周日0点） | 匹配小金属现货报价、库存数据的官方更新时点 |
| `data_format_check_rules` | `3-5条` | 小金属数据包含现货价、库存、产销三类核心字段，需配置对应校验规则 |
| `api_request_rate_limit` | `10次/分钟` | 符合多数行业公开数据源的调用频次限制 |
| `branch_condition_field` | `metal_category` | 按小金属品类动态切换分支逻辑 |
| `llm_prompt_template` | 按实测标定 | 不同细分小金属品类的营销内容侧重点差异显著 |
| `workflow_retry_max_times` | `3次` | 适配网络波动或接口临时限流的常规重试需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流中调用`llm_chat`节点后，下游节点无法获取最新的上下文数据。原因：未将节点的「新上下文」输出正确连接至下游节点的输入端口，仅使用了「AI回复内容」作为传递数据。
- 现象：批量调用工作流时出现大量429状态码或超时报错。原因：未配置`api_request_rate_limit`参数，或取值超出行业数据源的调用限制。
- 现象：工作流执行完成后，预设的营销内容变量未发生更新。原因：未在变量更新节点配置全局生效范围，导致变量仅在当前节点局部生效。

## 怎么确认配好了
- 手动触发一次工作流，查看数据拉取节点的输出日志，确认拉取的字段与单位与目标数据源一致。
- 切换不同的小金属品类，验证分支节点是否正确加载对应模板，检查生成的营销内容是否匹配品类特性。
- 调用工作流API并传入测试参数，查看返回结果中是否包含正确的变量值与生成内容。
- 查看工作流的监控面板，确认定时触发任务按预设时间执行，无频繁的重试或报错记录。
