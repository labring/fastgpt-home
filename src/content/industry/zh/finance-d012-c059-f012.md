# 工业金属营销内容的模型接入与配置

## 这个品类的数据长什么样
工业金属的数据主要来源于行业协会公开报价平台、现货交易市场实时交易接口、期货交易所合约行情接口。现货数据更新频率为每15分钟至1小时，期货数据按交易日定时更新。文档包含结构化表格与非结构化文本两类，结构化字段包含品名、规格、产地、当日均价、涨跌幅度、库存总量，单位多为元/吨、千克/手；非结构化内容包含行业研报、区域供需分析，单篇文本长度跨度较大。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据结构要求配置针对性的字段抽取规则，避免无效数据混入上下文。高频更新的行情数据要求模型调用的缓存过期时间与数据更新节奏匹配，防止使用过期信息生成营销内容。长文本研报与结构化表格的混合输入，要求调整解析与上下文截断参数，保障核心信息不被丢失。营销内容需结合实时行情，因此模型调用的触发时机需与数据更新节点对齐，避免内容滞后。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 工业金属营销内容需结合研报、实时行情与产品参数，单轮上下文长度需求高于通用场景 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 批量工业金属库存报表、跨区域行情汇总文件解析耗时较长，默认参数无法完成完整解析 |
| `召回条数` | `前6–8 条` | 工业金属营销需精准匹配特定规格、产地的行情数据，过多召回会导致内容冗余 |
| `相似度阈值` | `0.72–0.78` | 工业金属品名、规格辨识度较高，阈值过低会引入无关的品类数据 |
| `重排返回条数` | `前3–4 条` | 营销内容需突出核心行情与供需信息，过多返回结果会分散受众注意力 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 工业金属季度供需研报、全品类库存报表文件体积较大，需适配上传上限 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：模型返回结果中工业金属的产地、规格字段为空。原因：未在配置中指定需要抽取的工业金属专属实体字段，导致模型无法识别有效业务信息。
- 现象：整点触发模型调用后返回状态码504超时错误。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，使用默认短超时值，无法完成批量行情数据的解析。
- 现象：界面提示无可用渠道，oneapi测试模型连通但FastGPT调用失败。原因：未正确匹配工业金属数据源的接口专属标识，或模型别名配置与数据源要求不符，导致渠道分组校验不通过。

## 怎么确认配好了
- 传入工业金属现货行情数据与预设营销文案模板，调用测试接口，检查返回内容是否包含指定的品名、产地、价格字段。
- 查看模型调用日志，确认每次调用的上下文未触发截断，超时时间与配置值一致。
- 模拟整点触发模型调用，检查是否按预期执行，无额外自动执行任务干扰。
- 校验渠道分组配置，确认模型别名与工业金属数据源的接口标识完全匹配，无拼写错误。
