# 工程咨询营销内容的工具调用与插件

## 这个品类的数据长什么样
工程咨询的数据主要来源于内部项目台账、招投标公示平台、资质管理系统、现场勘察报告与合规审核文件。数据更新节奏随项目推进与合规要求调整，无固定周期，单个项目文档篇幅较长，常包含多页合规条款与明细数据。核心字段包括项目编号、项目类型（如建筑装饰工程咨询）、甲方主体、预算金额（单位为万元）、工期（单位为日历天）、参与方资质等级、合规条款清单等，字段格式需符合行业监管要求。

## 这些特征在「工具调用与插件」这一环带来什么约束
工程咨询数据分散在多个独立系统中，需通过多插件对接不同数据源，对插件的多服务并行调用能力提出要求。数据更新无固定周期，工具调用需支持增量同步与按需拉取，避免全量拉取占用过多资源。单份文档篇幅较长，工具调用时需支持长文本解析与分段处理，防止关键合规条款被截断。字段带有行业特有的单位与格式要求，工具调用需内置单位校验逻辑，避免因格式错误导致数据无效。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MCP_SERVICE_TIMEOUT` | `1200 秒` | 工程咨询的复杂事务处理（如多项目数据汇总、合规条款批量校验）耗时较长，默认90秒阈值无法覆盖需求 |
| `PARSE_FILE_MAX_CHARS` | `8000–12000 字符` | 工程咨询的合规报告、项目文档单段内容较长，该取值可避免截断关键监管条款 |
| `RECALL_TOP_K` | `前 3–5 条` | 工程咨询营销内容需精准匹配项目类型与资质要求，过多召回结果会分散目标受众注意力 |
| `MCP_MULTI_SERVICE_ENABLE` | `开启` | 工程咨询数据分散在招投标、ERP、资质管理等多个系统，需通过多插件并行对接获取完整数据 |
| `VALIDATE_FIELD_UNIT` | `开启` | 工程咨询数据带有特定单位（如万元、日历天），开启该配置可校验字段格式，避免无效数据返回 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用自定义MCP服务处理多项目数据汇总时，返回`MCP_SERVICE_TIMEOUT`错误，请求提前终止。原因：工程咨询的复杂事务处理耗时超过默认90秒阈值，未调整`MCP_SERVICE_TIMEOUT`配置。
- 现象：调用工具返回的项目数据中预算字段为空或格式错误。原因：未开启`VALIDATE_FIELD_UNIT`配置，未校验工程咨询数据特有的单位格式，导致无效数据被返回。
- 现象：召回的营销内容包含无关的市政工程或水利工程数据。原因：`RECALL_TOP_K`取值过大，或未按目标项目类型过滤召回结果，导致冗余数据混入。

## 怎么确认配好了
- 发起一次包含多项目数据汇总的测试调用，查看返回结果是否在预期耗时内，未出现超时报错。
- 上传一份工程咨询的合规报告，查看解析后的字段是否包含正确的单位信息，无关键内容被截断。
- 配置多MCP服务对接不同数据源，发起跨系统数据整合调用，查看是否能正常获取并整合各系统的项目数据。
- 发起营销内容匹配测试，查看召回结果是否仅包含目标品类的相关数据，无无关内容混入。
