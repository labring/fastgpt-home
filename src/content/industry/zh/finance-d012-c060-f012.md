# 工程咨询营销内容的模型接入与配置

## 这个品类的数据长什么样
工程咨询的营销内容数据主要来源于金融机构服务建筑工程领域的过往项目咨询报告、投标文件、客户需求纪要、行业规范文档与资质证明文件。数据更新节奏随项目推进或行业规范修订触发，单次项目相关数据更新频率为中标后至交付周期内。文档结构通常包含项目概况、技术方案、报价明细、资质等级、客户反馈等模块，字段涉及项目金额、工期、资质级别等专业单位，无统一固定格式，需适配多类型文档结构。

## 这些特征在「模型接入与配置」这一环带来什么约束
工程咨询营销数据的长文本、多专业字段与非统一格式特征，对模型接入与配置带来多重约束。长文本文档需适配更大的上下文窗口参数，避免关键信息被截断；多专业字段与单位要求配置自定义prompt规范模型输出格式，确保专业术语识别准确；非统一格式的文档需调整解析参数，适配不同结构的文件内容；高频更新的数据则要求配置定时同步任务，确保知识库内容与最新项目进度一致。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | `8000–16000 字符` | 工程咨询营销文档常包含长篇项目方案与资质说明，需容纳完整的上下文信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 大型历史项目报告、资质合集的解析耗时较长，避免中途触发超时错误 |
| `RECALL_TOP_N` | `前 6–8 条` | 营销内容需覆盖多维度的服务案例与技术方案，过多召回会超出模型上下文限制 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 需精准匹配客户咨询的专业需求，过滤无关的通用行业文档 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 工程咨询的批量资质文件、项目库体积较大，适配大文件上传需求 |
| `API_REQUEST_TIMEOUT` | `30 秒` | 专业术语解析与长文本生成需较长响应时间，避免提前中断调用 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用模型时返回`404 status code (no body)`，未正确配置模型接入的API地址，或绑定的模型密钥无效。
- 本地部署模型无法根据上传的文档内容生成针对性回复，仅返回通用内容，未开启知识库召回配置，或召回的文档未正确关联至当前对话上下文。
- 选择非语言模型选项时触发`Message field is required`或`40`错误，未正确配置非语言模型的输入输出格式，或未为其指定匹配的任务触发条件。

## 怎么确认配好了
- 上传单篇典型的工程咨询报告，确认解析界面显示的文本无截断、专业字段丢失情况。
- 输入包含专业术语的测试问题，验证模型输出内容包含上传文档中的项目细节。
- 查看知识库召回日志，确认召回的文档数量与预设配置的召回条数一致。
- 发起模型调用测试，确认返回的状态码为`200`，无预设的报错提示。
