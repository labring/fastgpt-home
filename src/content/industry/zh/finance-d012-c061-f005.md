# 工程机械营销内容的多轮对话与提示词

## 这个品类的数据长什么样
金融/保险/理财领域针对工程机械的营销内容数据主要来自厂商官方产品手册、技术参数文档、经销商区域适配话术库、线下展会物料及售后常见问题集，以及金融机构的工程机械专属融资、保险产品话术库。更新节奏随新品机型发布、合规政策调整及金融产品迭代变动，无固定周期。文档多按机型型号分类，单篇文档通常包含机型编号、额定起重量、作业半径、适用工况、配置选项、合规认证编号等字段，参数字段附带吨、米等明确单位，同时关联对应金融产品的费率、期限等信息。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
作为金融/保险/理财领域的营销内容，需同时匹配工程机械参数与金融产品条款，机型分类多且参数字段带明确单位，要求多轮对话需先引导用户明确具体机型编号、使用场景与资金需求，避免泛化回复。文档更新无固定周期，需在提示词中加入知识库版本校验逻辑，确保调用的营销内容为最新版本。区域适配话术的差异，要求多轮对话前置确认服务区域，匹配对应经销商话术与区域金融产品政策。长文档的参数细节多，提示词需限定召回范围为用户提及的机型相关参数与关联金融产品信息，避免无关内容干扰对话流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 工程机械参数与金融产品关联文档较长，多轮对话需保留足够的机型参数、金融条款上下文，避免丢失关键信息 |
| `RECALL_TOP_N` | `前 6–8 条` | 金融/保险/理财领域的工程机械营销内容需覆盖机型参数、适用工况、金融产品条款等多维度，过多召回会干扰对话逻辑 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 工程机械参数与金融产品精准度要求高，需过滤低匹配度的无关文档，同时保留区域适配话术与产品变体的匹配 |
| `PARSE_CHUNK_SIZE` | `1200–1500 字符` | 单篇产品手册与金融关联文档参数集中，分段过长会导致召回精度下降，过短会增加上下文冗余 |
| `WORKFLOW_MODEL_SELECTOR` | `带细分类能力的专用模型` | 需精准识别用户提及的机型、工况、资金需求等细分信息，适配问题分类与需求匹配需求 |
| `CONVERSATION_TIMEOUT` | `120 秒` | 用户需逐步提供机型、工况、资金需求等多轮信息，超时会中断有效对话流程 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流节点返回的问题分类字段为空，或分类结果与实际机型参数及金融产品不匹配。原因：选用的模型未针对带明确单位的机械参数、细分机型分类及金融产品关键词做适配，无法精准识别专业术语。
- 现象：多轮对话中，上一轮设置的机型编号或资金需求变量在后续对话中无法被调用。原因：未将全局变量的作用域配置为会话级，导致变量仅在单次请求中生效。
- 现象：通过API上传的产品手册或金融关联文档解析后，无对应参数字段的召回结果。原因：上传文件的格式未匹配预设的解析规则，或上传文件大小超出配置限制。

## 怎么确认配好了
- 发起包含具体机型编号、使用场景与资金需求的测试对话，核对多轮上下文是否保留了之前输入的相关信息。
- 触发工作流的问题分类节点，验证分类结果是否匹配测试输入的工程机械相关关键词与金融产品类型。
- 调用API上传标准格式的产品手册与金融关联文档，检查解析后的字段是否包含工程机械专属参数与关联金融产品信息。
- 查看会话日志，确认全局变量在多轮对话中按预期传递，未出现丢失情况。
