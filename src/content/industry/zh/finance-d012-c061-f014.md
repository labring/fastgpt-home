# 工程机械营销内容的表单与交互

## 这个品类的数据长什么样
工程机械的营销数据主要来自厂商官方产品手册、金融机构的工程机械融资租赁业务营销文档、技术参数说明书、销售报价文档及售后维护手册。数据更新节奏随新品发布、配置迭代或合规要求调整，无固定周期。文档结构多以整机核心参数、型号规格、配件明细、操作指引及金融方案要点为核心模块，字段包含额定起重量、最大作业半径、燃油消耗率、月供金额、首付比例等，单位多采用公制标准，如吨、米、升/小时、千瓦，金融类字段则采用百分比、元等单位。

## 这些特征在「表单与交互」这一环带来什么约束
工程机械的多参数、多类型单位及长文档特征，结合金融营销的需求，对表单与交互带来多重约束。核心参数与金融字段的单位多样性要求表单输入框需预设单位选项或自动绑定单位后缀，避免用户输入格式错误。长文档内容的解析需求，要求表单支持批量上传多页产品手册与金融方案文档，并自动提取核心参数与金融要点。营销场景下的需求匹配逻辑，要求表单采用场景联动交互，根据用户输入的作业场景、作业高度等设备参数，自动筛选对应机型的金融方案选项，减少手动录入成本。同时，部分用户会上传设备实拍或工况图片用于需求沟通，因此表单需支持图片上传功能。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_IMAGE_MAX_SIZE` | `5–10 MB` | 工程机械相关的设备实拍、工况图片分辨率较高，5-10MB可覆盖多数高清拍摄需求，同时避免过大文件导致上传超时。 |
| `PARSE_DOC_MAX_LENGTH` | `800–1200 字符` | 工程机械技术文档的核心参数段落多为800-1200字符，该分段长度可完整保留参数关联信息，避免拆分后丢失上下文。 |
| `RECALL_TOP_K` | `前 3–5 条` | 工程机械营销内容的核心参数条目较少，过多召回结果会增加模型处理负担，3-5条可覆盖核心匹配需求。 |
| `FORM_FIELD_UNIT_AUTO_BIND` | `开启` | 工程机械参数单位多样且固定，自动绑定可减少用户输入错误，提升表单填写效率。 |
| `UPLOAD_FILE_TIMEOUT_SECONDS` | `300 秒` | 大型工程机械产品手册多为数十页PDF，300秒可满足大文件的完整上传与解析需求。 |
| `FORM_SCENE_LINKAGE_ENABLE` | `开启` | 工程机械金融营销需匹配作业场景与机型参数，场景联动可简化用户填写流程。 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：表单上传图片后无法正常识别参数，或上传进度卡住。原因：未正确配置`UPLOAD_IMAGE_MAX_SIZE`参数，导致超过限制的图片被拦截或解析失败。
- 现象：知识库导入工程机械文档后，检索结果条数异常偏少或偏多，且响应速度较慢。原因：`PARSE_DOC_MAX_LENGTH`设置不合理，过短拆分导致参数上下文丢失，过长则导致检索匹配精度下降与处理耗时增加。
- 现象：导入多页工程机械PDF文档时，前端页面持续刷新无法选择目标页面。原因：未调整`UPLOAD_FILE_TIMEOUT_SECONDS`参数，大文件解析超时导致前端加载状态异常。

## 怎么确认配好了
- 上传一张符合常规尺寸的工程机械实拍图片，检查上传进度是否正常完成，无报错提示。
- 导入一份小型工程机械产品手册文档，查看解析后的分段是否完整保留核心参数信息，无明显截断或拆分错误。
- 填写表单时选择预设作业场景，检查是否自动加载对应机型的参数与金融方案选项，无需手动输入额外信息。
- 提交表单并触发知识库检索，查看返回结果的匹配度是否符合预期，无过多冗余内容。
