# 广告营销营销内容的工作流编排

## 这个品类的数据长什么样
广告营销的数据主要来自金融机构的广告投放平台后台、营销内容源文件存储库、用户互动留资系统。投放数据按小时或日级更新，营销素材文件随营销活动周期同步更新，用户互动数据实时生成。文档结构包含活动标识、投放渠道、素材编码、曝光量、点击成本等字段，单位涵盖次、元、秒等，素材文件包含金融产品文案、海报源文件、视频剪辑片段等多格式内容。

## 这些特征在「工作流编排」这一环带来什么约束
广告营销的多源异构数据结构，要求工作流配置跨数据源的字段映射节点，统一不同金融投放平台导出数据的格式。实时更新的投放与互动数据，要求工作流支持定时触发或事件触发模式，适配数据同步节奏。多格式的营销素材文件，要求工作流内置适配不同文件类型的解析节点，避免解析失败。不同营销活动的数据隔离需求，要求工作流配置节点级的权限过滤规则，确保金融客户数据访问合规。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120–180 秒` | 金融营销素材包含产品介绍视频、高清海报，解析时长高于通用文档 |
| `maxContext` | `8000–12000 字符` | 金融产品文案、营销脚本通常篇幅较长，需保留足够上下文用于内容分析 |
| `召回条数` | `前 8–12 条` | 单营销活动相关营销内容集中，过多召回会引入冗余关联数据 |
| `工作流触发模式` | `定时触发 + 事件触发双模式` | 投放数据需小时级同步，用户互动数据需实时响应金融获客需求 |
| `TEXT2SQL_TABLE_WHITELIST` | `投放报表表、素材库表、互动留资表` | 限定仅访问业务所需数据表，符合金融数据隔离要求 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 金融营销素材多为高清海报或短时长产品介绍视频，需适配较大文件上传 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流导入其他环境后，引用的自定义插件无法加载，节点显示异常。原因：导出时未绑定插件的本地存储路径，仅复制了工作流JSON配置，导致新环境无法识别插件位置。
- 现象：解析金融营销素材时频繁出现超时错误。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，使用了通用文档的默认超时时长，无法适配长时长的视频或高清素材解析。
- 现象：工作流触发后返回的关联内容过多，超出业务处理范围。原因：未设置合理的`召回条数`参数，召回了过多不相关的历史营销素材，导致结果冗余。

## 怎么确认配好了
- 上传单份测试用金融营销素材，验证解析节点输出的结构化字段与预期一致，确认解析时长未超过配置的超时阈值。
- 触发预设的工作流触发任务，查看执行日志中是否包含正确的数据源字段映射结果，确认跨源数据对齐生效。
- 将工作流导出为JSON文件后导入测试环境，检查所有引用的插件节点无缺失报错，确认路径配置正确。
- 调用TEXT2SQL节点生成查询语句，验证仅能访问白名单内的数据表，无非法表访问提示。
