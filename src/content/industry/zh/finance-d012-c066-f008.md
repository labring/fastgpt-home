# 房建工程营销内容的工具调用与插件

## 这个品类的数据长什么样
房建工程相关的金融营销数据主要来源于合作房建企业的项目备案系统、施工日志台账、建材供应商报价库、招投标文件与项目效果图素材，同时包含金融机构的风控台账与产品适配信息。数据更新节奏因类型不同存在差异：项目备案信息按项目立项至竣工的周期更新，施工日志按每日或每周更新，建材报价按市场行情实时更新，营销素材则随项目进度不定期更新。文档结构包含结构化台账（含项目编号、建筑面积、总造价等字段）、长文本施工记录、结构化建材清单（含型号、规格、单价单位）与多媒体素材文件。

## 这些特征在「工具调用与插件」这一环带来什么约束
房建工程金融营销数据的多源分散特性要求工具调用需支持对接多个异构数据源插件，完成跨房建企业、供应商与金融机构系统的数据聚合。不同数据的更新节奏差异，要求插件需支持定时刷新与实时拉取两种模式，避免营销内容使用过时的建材报价或项目进度数据，影响金融产品适配的准确性。长文本施工记录与结构化字段并存的文档结构，要求插件需同时支持长文本解析与结构化参数传递，适配混合格式的营销内容生成需求，如基于施工日志生成风控报告、基于建材清单生成产品推荐文案。多样的单位体系（如建筑面积以平方米为单位、造价以万元为单位），要求插件需内置单位转换逻辑，防止因参数格式错误导致生成的营销内容出现数据偏差，降低客户信任风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PLUGIN_API_TIMEOUT` | `120-180 秒` | 房建工程的施工图、施工日志等单文件通常较长，需足够时间完成数据解析与插件调用 |
| `UPLOAD_FILE_MAX_SIZE` | `5000 MB` | 房建项目的效果图、施工图等多媒体文件单文件体积通常不超过5GB，需适配大文件上传 |
| `stream` | `true` | 金融营销内容生成需流式返回分段结果，避免客户长时间等待无反馈 |
| `PLUGIN_RETRY_TIMES` | `2-3 次` | 建材报价、招投标数据接口可能因第三方服务波动出现临时错误，重试可降低调用失败率 |
| `PARSE_FILE_MAX_CHARS` | `800000 字符` | 房建项目的长文本施工日志单篇通常不超过80万字，需支持大文本解析 |
| `PLUGIN_FILE_PASS_THROUGH` | 启用 | 房建金融营销内容需嵌入项目文件的结构化数据，启用后可直接传递文件ID参数 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用插件时传入文件类型变量未返回预期结果，报错提示`400 Bad Request`。原因：未使用FastGPT内置的文件ID传递参数，直接上传二进制文件或文件路径导致参数格式不匹配。
- 现象：选择`stream`为`true`调用接口后，仅收到分段片段无法获取完整结果。原因：未监听流式返回的`[DONE]`结束标记，未完成分段结果的拼接。
- 现象：私有部署V4.14.1版本导入插件时提示`internal server error`。原因：插件配置的API接口未添加内网访问白名单，或系统资源不足导致插件加载失败。

## 怎么确认配好了
- 上传一份房建项目的施工图PDF，调用内置的文件解析插件，检查返回的结构化字段是否包含项目编号、建筑面积等预设内容。
- 开启`stream`参数调用营销内容生成插件，通过系统日志查看是否收到`[DONE]`结束标记，确认完整结果可被完整接收。
- 导入自定义的建材报价插件，在测试界面传入已知的建材型号参数，核对返回的报价数据是否与预设数据源一致。
- 查看系统运行日志，确认`PLUGIN_API_TIMEOUT`的配置未触发`504 Gateway Timeout`错误，且重试次数配置符合接口稳定性要求。
