# 教育服务营销内容的工具调用与插件

## 这个品类的数据长什么样
教育服务的营销内容数据主要来源于金融理财课程研发文档、学员投资反馈记录、教学脚本素材、线下理财沙龙物料及线上社群互动内容。更新节奏随业务节点调整，课程迭代、活动上线时批量更新，日常话术微调为零散更新。单篇营销内容文档包含标题、适配投资经验层级、授课主体、核心知识点摘要、报名链接、预计参与人次等字段，其中时长类字段以分钟为单位，文本内容以字符为统计单位，链接字段为标准HTTP格式。

## 这些特征在「工具调用与插件」这一环带来什么约束
教育服务营销内容的多来源、多字段特征，对工具调用与插件提出明确约束。多来源素材需插件支持解析不同格式的输入内容，适配理财课程大纲的结构化文本、社群互动的非结构化口语化内容。字段包含动态链接与实时参与人次数据，要求插件请求参数需绑定可更新的业务字段，避免硬编码静态内容。长文本类的教学脚本素材，需工具调用配置适配长上下文的分段规则，避免截断核心知识点。活动类营销内容的临时更新，要求插件支持触发式同步，不使用固定周期拉取的方式，确保内容时效性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_request_timeout` | `30-60 秒` | 教育服务营销内容的素材解析、活动数据拉取通常耗时较短，过长超时会阻塞对话流程 |
| `tool_call_max_context_length` | `8000-12000 字符` | 教育营销内容常包含长文本的教学脚本或课程详情，需覆盖完整核心信息 |
| `plugin_content_type` | `application/json` 或 `application/x-www-form-urlencoded` | 适配不同业务接口的格式要求，活动报名类接口支持表单格式，素材拉取类接口支持JSON格式 |
| `tool_call_max_tool_num` | `3-5 个` | 教育营销场景需调用的工具通常为素材拉取、数据查询、表单提交三类，过多调用会增加对话延迟 |
| `vector_model_embedding_dim` | `1024` | 匹配bge-large-zh-1.5等主流教育场景适配的向量模型维度，保证语义召回精度 |
| `tool_call_hide_ai_reply` | `开启` | 当仅需返回工具调用生成的营销内容结果时，可隐藏原生AI对话内容，聚焦业务输出 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用插件时返回`415 Unsupported Media Type`错误，原因是未正确配置`plugin_content_type`，使用了与目标接口要求不符的请求格式。
- 工具调用完成后仍返回原生AI对话文本，未隐藏指定内容，原因是未开启`tool_call_hide_ai_reply`配置，或配置后未完成保存生效。
- 插件返回的营销内容无法渲染为自定义卡片样式，原因是未按照平台要求的结构化格式返回响应数据，仅返回了纯文本内容。

## 怎么确认配好了
- 进入插件管理页面，查看`plugin_content_type`配置项，确认与目标接口的要求一致。
- 发起一次模拟调用，查看返回的响应格式是否符合业务接口的预期，检查`415`类错误是否消失。
- 开启`tool_call_hide_ai_reply`配置后，发起测试对话，确认原生AI对话文本未在结果中展示。
- 调用工具拉取教育营销内容数据，检查返回的字段是否包含适配业务的链接、受众层级等信息，确认参数绑定正确。
