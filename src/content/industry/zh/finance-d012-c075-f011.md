# 整车营销内容的文档解析与分块

## 这个品类的数据长什么样
整车营销内容的数据主要来自汽车金融品牌官方营销物料库、经销商推广文档、车型参数公告及线下活动讲稿。更新节奏随新车发布、改款及季度营销方案调整，频率集中在车型周期的关键节点。文档结构包含两类：一类是结构化的车型参数表，包含车型ID、配置代码、续航里程、售价等字段，对应单位分别为无、无、千米、万元；另一类是非结构化的营销话术、活动流程及场景化推广文案，部分文档附带参考配置关联字段。

## 这些特征在「文档解析与分块」这一环带来什么约束
结构化参数表的字段与单位绑定特性，要求解析分块时不能拆分单个参数的完整组合，否则会导致汽车金融营销内容中的参数信息失效。多车型批量文档的存在，要求分块逻辑需按车型聚合相关内容，避免跨车型的参数混淆，影响汽车金融获客时的精准匹配。高频更新的物料特性，要求解析流程需支持增量更新或快速重新解析，保证汽车金融营销内容的时效性。不同经销商提交的文档格式不统一，要求解析逻辑具备格式兼容性，避免因格式差异导致的字段提取失败，影响营销物料的复用。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxChunkSize` | 800–1200 字符 | 整车营销文档包含结构化参数表与长段营销话术，该区间可平衡参数完整性与话术连贯性，避免拆分单个车型的完整参数组 |
| `chunkOverlap` | 100–150 字符 | 跨块的参数与话术需要保留上下文关联，避免召回时丢失前置的车型标识 |
| `parseStructuredTable` | 开启 | 整车营销文档存在大量配置参数表，开启后可保留字段与单位的关联关系，避免参数拆分后丢失对应关系 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 大型全系列车型营销文档包解析耗时较长，该时长可覆盖完整解析流程 |
| `parseReferenceField` | 开启 | 部分营销文档附带车型参考配置字段，开启后可完整提取关联信息 |
| `UPLOAD_PARSE_MAX_SIZE` | 2000 MB | 支持批量上传全系列车型的营销文档包，适配整车品类的多车型物料批量处理 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：解析结果中references字段未被提取，对应字段为空。原因：未开启`parseReferenceField`配置项，该配置项默认未适配整车营销文档中的参考配置关联字段。
- 现象：分块长度不符合预设的800-1200字符区间，出现过度拆分或合并。原因：直接修改源码中的分块参数但未对应到FastGPT 4.9版本的解析模块文件，导致自定义配置未生效。
- 现象：上传整车配置参数表文档后，解析结果中参数与单位分离，无法形成完整的参数块。原因：未开启`parseStructuredTable`配置项，导致结构化表格被当作普通文本逐行拆分。

## 怎么确认配好了
- 上传一份包含结构化参数表的整车营销文档，查看解析后的分块结果，确认每个参数块完整保留字段名、数值与单位关联。
- 进入知识库的解析设置页面，核对分块长度、重叠字符等配置项的取值，确认与预设方案匹配且已保存生效。
- 上传包含参考配置关联字段的测试文档，查看解析结果中是否完整提取对应关联信息，验证参考字段解析配置是否开启。
- 上传单份大型全系列车型营销文档，等待解析完成，确认未出现超时类报错，验证超时配置的合理性。
