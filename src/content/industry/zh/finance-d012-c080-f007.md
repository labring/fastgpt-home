# 服装家纺营销内容的工作流编排

## 这个品类的数据长什么样
服装家纺品类的数据主要来源于品牌内部ERP系统、产品研发文档库、电商平台素材后台。数据更新节奏随营销节点变动，换季前1-2个月集中上新SKU数据，日常每周有补货SKU的信息更新，活动期间会新增促销款临时数据。单条SKU数据包含款号、面料成分（单位为g/㎡）、洗涤说明、尺码表、适配场景等结构化字段，以及主图、详情页文案初稿、用户评价关键词等非结构化素材，文档格式多为PDF、JPG、TXT或结构化表格。

## 这些特征在「工作流编排」这一环带来什么约束
服装家纺品类的多SKU批量更新需求，要求工作流支持批量触发与并发控制，避免单节点过载。结构化字段与非结构化素材并存的特征，要求工作流同时配置文本提取、结构化解析与自然语言生成节点。不同SKU的营销场景差异（如日常款、促销款、换季款），要求工作流配置标签分流分支，适配不同的内容生成逻辑。此外，文件上传类节点需适配高清产品图、检测报告等大体积素材，需严格限制上传与解析的资源占用。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 服装家纺类的面料检测报告、详情页素材文件解析时长多在200秒以内，预留合理缓冲 |
| `UPLOAD_FILE_MAX_SIZE` | `10 MB` | 该品类上传的高清产品图、检测报告PDF等素材通常不超过8MB，超出会触发上传失败 |
| `分段长度` | `800–1200 字符` | 服装家纺的面料说明、洗涤说明等核心文本长度多在500-1000字符，该分段区间可保留完整语义 |
| `WORKFLOW_RUN_TIMEOUT` | `1800 秒` | 批量处理SKU时，单工作流执行包含多轮搜索、文案生成，总时长通常在1500秒以内，预留缓冲 |
| `TAVILY_SEARCH_MAX_RESULTS` | `前 2 条` | 服装家纺营销内容需聚焦面料特性、洗涤规范等精准信息，过多召回会稀释核心上下文 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
-  工作流节点返回`premature close`报错，日志显示连接提前断开。原因：未配置`PARSE_FILE_TIMEOUT_SECONDS`参数，或取值低于实际解析时长，导致文件解析过程中连接被强制关闭。
-  工作流中Tavily搜索节点无返回结果，或提示搜索配置缺失。原因：未在工作流的全局配置中绑定Tavily的API密钥，或未在节点中开启外部搜索权限。
-  调用带文件上传的工作流API时返回`413 Request Entity Too Large`状态码。原因：未将`UPLOAD_FILE_MAX_SIZE`配置调整至匹配品类素材的常见大小，默认配置无法容纳高清家纺产品图。

## 怎么确认配好了
-  上传单份服装家纺的面料检测报告或详情页素材，查看节点执行日志，确认解析时长符合预设配置。
-  触发单SKU的工作流执行，监控总时长，确认未超出预设的执行超时限制。
-  调用带文件上传的工作流API，上传符合品类常见大小的产品素材，确认接口返回无异常。
-  配置Tavily搜索节点并触发执行，验证搜索结果匹配服装家纺营销所需的面料、洗涤等精准信息。
