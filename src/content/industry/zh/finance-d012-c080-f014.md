# 服装家纺营销内容的表单与交互

## 这个品类的数据长什么样
服装家纺的营销相关数据主要来自品牌内部商品管理系统、面料检测档案、线上店铺SKU库与营销素材库。数据更新节奏随新品上架、换季促销、库存调整波动，常规更新周期为周度，大促前会按日同步。单条数据文档以结构化字段为主，包含SKU编码、品类名称、面料成分、克重、标准尺码、建议售价、库存数量、营销适配标签，字段单位多为g/㎡、件、元、厘米等物理或商业通用单位，部分素材文档包含图片URL与短文案。

## 这些特征在「表单与交互」这一环带来什么约束
多SKU属性与动态更新的商品数据，要求表单需支持按SKU编码、品类、尺码等多维度筛选的下拉组件，避免手动输入的格式错误。高频更新的库存、售价等字段，要求表单的可选参数支持动态拉取商品库数据，不使用固定硬编码的选项，确保选项与实时在售商品一致。专业字段如克重、面料成分需配置格式校验规则，限制输入内容的合规性，避免无效数据流入营销内容生成流程。素材关联字段需支持图片URL校验与文件上传接口，适配家纺面料实拍图、商品详情图的录入需求。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前8-12条` | 服装家纺营销素材需覆盖核心SKU属性与适配标签，过多召回会导致内容冗余，过少则无法覆盖营销所需的全部信息 |
| `相似度阈值` | `0.75-0.85` | 需精准匹配目标SKU的面料、尺码等属性，避免召回不相关的商品数据影响营销内容准确性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 部分面料检测报告、高清商品详情图的解析耗时较长，需预留足够的文件处理时间 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 服装家纺的高清产品图、面料样板图文件体积较大，需放宽上传上限以适配素材需求 |
| `表单字段动态刷新周期` | `每12 小时` | 商品库存、售价的更新频率，确保表单可选参数与实时数据同步 |
| `表单必填字段校验` | `SKU编码、建议售价、库存数量` | 这三类字段是营销内容生成的核心基础信息，缺失会导致内容无法正常输出 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用知识库搜索模块时，通过变量引用选择知识库时返回「参数缺失」报错。原因：未明确配置`知识库ID`变量的绑定规则，未在表单中录入目标知识库的唯一标识参数，导致系统无法定位对应知识库资源。
- 现象：表单录入SKU编码后，生成的营销内容未匹配对应面料属性。原因：未开启`表单字段动态刷新`配置，表单可选参数未同步商品库最新数据，导致调用的是过期的SKU信息。
- 现象：提交表单后出现`413 Request Entity Too Large`状态码。原因：未调整`UPLOAD_FILE_MAX_SIZE`配置，上传的高清产品图文件体积超出系统默认上限，导致请求被拦截。

## 怎么确认配好了
- 手动录入一条测试SKU编码，核对表单下拉选项是否与商品库实时数据一致，确认动态刷新配置生效。
- 上传一张符合品类特征的高清面料图，检查上传接口是否正常接收并解析文件，确认上传配置适配需求。
- 触发知识库搜索调用，检查返回结果是否包含目标SKU的核心属性，确认召回与阈值配置符合预期。
- 提交包含必填字段的测试表单，检查系统是否正常拦截缺失必填项的提交请求，确认字段校验配置生效。
