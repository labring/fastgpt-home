# 水产养殖营销内容的文档解析与分块

## 这个品类的数据长什么样
水产养殖的营销与运营数据来源涵盖养殖户日常养殖日志、饲料采购台账、水质检测报告、行业展会宣传物料、短视频脚本与公众号推文。数据更新节奏不一：养殖日志与投料记录为每日更新，行业资讯按月更新，营销物料随活动临时调整。文档格式包含纯文本、Excel报表、内嵌实拍图的Word文档，部分内容来自语雀、飞书等协作平台。文档字段多包含水产专业参数，如溶解氧（单位mg/L）、水温（单位℃）、投料量（单位kg），同时标注养殖品种、塘口编号等专属标识。

## 这些特征在「文档解析与分块」这一环带来什么约束
多来源的零散文档要求解析服务支持跨格式兼容，避免遗漏Excel台账、带图营销物料等不同类型的数据源。高频更新的批量文档需要适配合理的并发处理上限，防止解析超时。文档中包含的专业单位与专属标识，要求分块时保留上下文关联性，不能随意拆分导致专业参数断裂。内嵌的塘口实拍、水质检测图则需要额外的OCR提取能力，确保大模型可获取图片中的有效信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_MAX_SIZE` | 500 MB | 适配水产养殖的大型养殖日志归档、批量Excel报表的解析需求 |
| `chunk_size` | 800–1200 字符 | 保留溶解氧、投料量等专业养殖参数的上下文关联性，避免拆分跨块 |
| `chunk_overlap` | 100–150 字符 | 衔接跨块的养殖周期、水质变化等连续业务信息 |
| `PARSE_IMAGE_ENABLE` | 开启 | 提取营销物料中内嵌的塘口实拍图、水质检测图的OCR文本 |
| `PARSE_OCR_TIMEOUT` | 60 秒 | 适配单张水产实拍图的OCR处理时长 |
| `MAX_PARSE_WORKERS` | 8 | 平衡批量解析养殖文档的资源占用与处理速度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：解析语雀公开链接时返回403 Forbidden报错。原因：未配置语雀公开链接的访问权限，或链接设置为仅团队内可见，无法被解析服务拉取内容。
- 现象：上传包含内嵌图片的水产营销文档后，大模型无法获取图片相关信息。原因：未开启`PARSE_IMAGE_ENABLE`配置，或未启用OCR功能提取图片内嵌文本。
- 现象：调用工具发起HTTP请求时，参数解析正常但请求未执行。原因：请求参数中包含未转义的水产专业符号（如℃、mg/L），导致请求格式校验失败。

## 怎么确认配好了
- 上传单份完整的水产养殖日志文档，查看解析后的分块结果，确认专业养殖参数未被拆分到不同块中。
- 上传包含内嵌水质检测图的营销物料，检查解析结果中是否包含图片的OCR提取文本。
- 导入批量飞书Excel养殖报表，核对解析后的字段列表是否包含预设的养殖专业参数。
- 测试语雀公开链接的解析，确认返回的内容与网页公开展示的内容一致。
