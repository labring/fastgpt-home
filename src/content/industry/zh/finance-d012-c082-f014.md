# 水产养殖营销内容的表单与交互

## 这个品类的数据长什么样
水产养殖营销场景的业务数据包含两类：一类是养殖户的留资信息，包括塘口编号、养殖品种、养殖规模等；另一类是养殖相关的业务数据，来自塘口监测设备、日常巡检日志、饲料采购单据与苗种批次记录。数据来源覆盖实时监测与手动填报两类，更新节奏依字段类型不同：水体溶氧量、pH值等实时数据由设备每小时推送，投喂量、病害记录等手动数据按每日巡检频次更新，苗种与饲料采购数据按批次或月度更新。单条数据的核心字段包含塘口编号、养殖品种、水体参数、投喂量、批次号，单位多为mg/L、kg/亩、℃等专业农业计量标准，文档结构以塘口+批次为核心关联维度，用于生成定制化的营销内容与获客跟进。

## 这些特征在「表单与交互」这一环带来什么约束
实时与手动混合的数据来源，要求表单区分只读展示字段与可编辑字段，避免手动修改实时监测的水体参数，同时简化留资字段，降低养殖户的填报负担。多字段的专业计量需求，要求表单内置单位校验规则，防止录入错误的数值与单位组合，确保营销内容的数据源准确。塘口与批次的关联结构，要求表单强制绑定塘口编号与批次号字段，避免跨塘口、跨批次的数据混淆，便于后续的精准营销跟进。不同字段的更新频率差异，要求表单支持按需加载历史数据，减少重复填报的工作量，提升获客转化效率。同时，水产养殖表单的填报场景多在户外移动设备，要求交互逻辑简洁，减少复杂的层级跳转，适配养殖户的使用习惯。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formFieldMaxCount` | `20 个以内` | 匹配水产养殖营销表单的常规留资字段数量，降低养殖户填报负担 |
| `inputUnitValidation` | `启用，预设kg/亩、mg/L、ppm、℃` | 覆盖水产养殖核心监测字段的单位校验规则，确保数据源准确 |
| `batchFieldBinding` | `绑定塘口ID与养殖品种字段` | 强制关联批次信息，便于后续生成定制化的养殖营销内容 |
| `autoFillHistoricalData` | `开启，按塘口ID自动拉取最近7天数据` | 减少手动录入重复的巡检数据，提升获客表单的填写效率 |
| `formSubmitTimeout` | `25 秒` | 适配户外移动设备的网络传输场景，平衡提交稳定性与响应速度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 点击应用内营销文本触发FastGPT弹窗并带入文本后，弹窗内的发送按钮始终为灰色，无法点击。原因是弹窗绑定的输入框未正确接收外部传入的文本参数，导致输入框检测到内容为空，触发了内置的必填校验逻辑。
- 在AI对话节点提交营销咨询内容时，输入字符数超过模型上限，系统直接返回413状态码。原因是未配置`inputMaxLength`参数的前置校验规则，未在提交前检测输入内容的长度。
- 知识库搜索卡片中选择目标养殖知识库后，变量引用未生效，搜索结果不符合预期。原因是未将知识库选择组件的选中值绑定到搜索变量的作用域，导致变量无法正确获取选中的知识库ID。

## 怎么确认配好了
- 手动录入一条符合水产养殖营销表单规范的测试数据，包含塘口编号、养殖品种与当日投喂量，点击提交，确认表单无校验报错且提交成功。
- 调用预设的营销文本触发链接，传入“帮我分析草鱼塘口的溶氧量数据”，确认弹窗输入框自动填充该文本，发送按钮可正常点击。
- 提交超过`inputMaxLength`预设长度的测试文本到AI对话节点，确认系统在提交前弹出校验提示，不返回后端报错。
- 切换知识库搜索卡片的选中选项，确认搜索结果仅返回对应养殖知识库的内容。
