# 水处理营销内容的工作流编排

## 这个品类的数据长什么样
金融机构面向水处理企业的营销内容数据，主要来自三类来源：水处理企业的水务监测传感器实时采集数据、线下水质检测机构出具的月度电子报告、金融机构收集的水处理企业运维巡检记录。实时监测数据更新频率为秒级，包含监测点编号、采集时间、PH值、浊度、余氯浓度等字段；月度报告多为结构化表格格式，包含采样地点、检测项目、合格判定结果等内容。数据字段多带有明确物理单位，例如PH值无单位、浊度单位为NTU、余氯浓度单位为mg/L，同时包含金融机构侧的企业资质、信贷额度等字段，用于定制化营销内容。

## 这些特征在「工作流编排」这一环带来什么约束
实时秒级的水务监测数据要求工作流节点具备低延迟处理能力，无法使用批量同步的处理逻辑，否则无法生成实时营销话术。多来源的数据格式差异较大，需要在工作流中加入数据标准化预处理节点，统一水处理企业的业务数据与金融机构的客户资质数据的字段映射规则。带物理单位的字段需要额外配置单位校验规则，避免营销内容中出现单位错误影响专业可信度。月度汇总报告的长文本解析需要较长的超时时间，不能使用通用的短文本解析参数。营销内容需要结合实时水质数据与企业资质生成个性化话术，要求工作流支持跨数据源的动态调用，同时需符合金融机构的合规性要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DATABASE_PORT` | `3306` 或 `5432` | 对应MySQL、PostgreSQL的行业通用端口，适配多数水处理数据存储方案 |
| `UPLOAD_FILE_MAX_SIZE` | `20 MB` | 水处理营销物料多为水质报告PDF、现场设备照片，单份文件大小不超过20MB可覆盖多数场景 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 月度水质汇总报告的解析需要较长时间，300秒可避免长文档解析超时 |
| `MODEL_RATE_LIMIT` | `10 次/分钟` | 匹配`qwen3.5-plus`的官方调用限制，避免触发`429 Request rate increased too quickly`报错 |
| `WORKFLOW_TRIGGER_MODE` | `扫码触发 + 定时触发` | 支持营销活动的实时扫码获客，同时可定时生成月度水质科普内容 |
| `FILE_UPLOAD_ENABLE` | `开启` | 支持上传现场设备照片、水质报告进行工作流测试 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为数据库连接节点的端口输入框无响应，原因是未展开节点的高级配置面板，默认隐藏了端口配置项。
- 现象为调用`qwen3.5-plus`工具节点返回`429 Request rate increased too quickly`错误，原因是未配置`MODEL_RATE_LIMIT`参数，调用频率超出模型限制。
- 现象为工作流仅支持单用户扫码触发，无法多人同时接入，原因是未将工作流的分享权限设置为公开且未启用多会话并发功能。

## 怎么确认配好了
- 进入数据库连接节点配置页面，输入预设的端口号，点击测试连接按钮，验证连接状态显示正常。
- 上传单份大小为15MB的水质报告PDF文件，等待解析完成后查看提取的字段是否完整准确。
- 连续发起12次`qwen3.5-plus`工具调用，查看是否触发`429`报错，确认速率限制参数生效。
- 生成工作流分享二维码，使用两台不同设备扫码触发工作流，验证两个会话均可正常执行并返回结果。
