# 水处理营销内容的工具调用与插件

## 这个品类的数据长什么样
用于金融营销的水处理相关数据主要来自在线水质监测传感器、水务运营上报系统与第三方环保数据接口。数据以结构化时序记录为主，单条文档包含监测点标识、采集时间戳、核心水质参数与对应单位。核心参数包括浊度（单位NTU）、化学需氧量（单位mg/L）、pH值（无量纲）、氨氮浓度（单位mg/L），同时附带设备运行状态字段。数据更新频率为每5分钟至1小时一次，部分边缘设备因网络限制会延迟10-30分钟同步。

## 这些特征在「工具调用与插件」这一环带来什么约束
用于金融营销的水处理品类的结构化时序数据特征，对工具调用与插件配置带来多项约束。首先，数据需按监测点与时间范围拉取，因此插件需预设`monitor_point_id`、`start_time`、`end_time`等过滤参数，避免无效数据拉取，适配金融营销中按区域或时段生成内容的需求。其次，参数带有固定单位，插件需自动完成单位映射，无需用户手动调整，否则会导致金融营销内容中的数据标注错误，影响专业可信度。再者，部分设备存在数据延迟同步的情况，工具调用需支持配置重试机制，处理临时无数据返回的场景，避免营销内容生成中断。另外，水务类接口多采用header认证与sse推送模式，插件需兼容自定义请求头与长连接调用，适配实时水质数据的获取需求，满足金融营销中对时效性的要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `tool_request_timeout` | `300 秒` | 水处理数据接口多为内部水务系统，响应延迟通常在1-2分钟，300秒可覆盖多数正常请求与临时网络波动 |
| `plugin_auth_header` | `{"Authorization": "Bearer ${SECRET_WATER_API_KEY}"}` | 多数水务数据接口采用Bearer令牌认证，通过密钥变量可避免硬编码，提升配置安全性 |
| `data_fetch_batch_size` | `前 20 条` | 单条监测数据记录较短，批量拉取20条可满足金融营销内容生成所需的时段数据量，同时避免接口返回过载 |
| `tool_response_parse_mode` | `structured_json` | 水处理数据为结构化时序格式，采用结构化解析可直接提取核心参数，无需额外文本清洗 |
| `sse_connection_timeout` | `600 秒` | 针对sse推送的实时水质数据流，600秒可覆盖数小时的监测数据推送周期，避免频繁重连 |
| `parameter_unit_mapping` | `{"turbidity": "NTU", "cod_mn": "mg/L", "ph_value": ""}` | 水处理参数带有固定单位，预设映射可确保营销内容中的数据标注准确，避免单位混淆 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用水务数据接口返回400 status code (no body)。原因：未正确配置`plugin_auth_header`参数，或传入的API密钥已过期，导致请求未通过认证被直接拒绝。
- 现象：使用Qwen2-72B-Instruct-Int8调用函数时，生成的工具调用参数与实际需求不匹配。原因：未在系统提示词中明确指定水处理参数的字段名与单位要求，导致模型无法正确映射参数。
- 现象：调用Mermaid MCP Server生成流程图时无法获取图片链接。原因：未配置MCP服务的自定义请求头，或未开启工作流中的工具调用权限，导致MCP服务无法正常响应。

## 怎么确认配好了
- 手动触发绑定的工具节点，查看返回的结构化数据是否包含预设的水质参数与对应单位，确认字段映射无误。
- 使用接口调试工具，发送携带配置好的认证头的请求，验证水务数据接口可正常返回数据。
- 查看工作流运行日志，确认工具调用的超时时间与重试次数符合配置要求，无频繁报错。
- 生成测试用的营销内容片段，核对其中引用的水质数据的参数名与单位与实际拉取结果一致。
