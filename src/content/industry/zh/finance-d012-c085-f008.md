# 水泥营销内容的工具调用与插件

## 这个品类的数据长什么样
水泥相关营销数据主要来源于国内建材行业监测平台、区域水泥企业公开报价公示、物流调度公开数据。数据更新节奏区分维度：区域出厂价格数据每日更新，区域库存数据周度更新，行业整体运行数据月度更新。单条数据文档结构包含区域标识、水泥标号、计价单位、统计周期、库存余量、物流节点覆盖数等字段，其中计价单位固定为元/吨，库存余量单位为万吨，水泥标号需遵循P.O/P.C+数字+小数点格式。

## 这些特征在「工具调用与插件」这一环带来什么约束
水泥数据的多更新节奏要求工具调用需按数据类型配置差异化轮询间隔，避免频繁调用触发接口限流。字段的强规范性要求工具调用参数需校验水泥标号与区域编码的格式，否则会返回无效数据。区域属性突出的特征要求工具调用必须绑定区域筛选参数，否则无法匹配到精准的区域营销素材。多数据源的分散特性要求工具需配置多套鉴权参数，分别对接不同类型的建材数据接口，确保数据来源的完整性。同时，统一的单位规范要求工具需预设转换规则，避免输出数据与行业通用单位不符，影响营销内容的可信度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `data_source_type` | `["cement_price", "cement_inventory", "cement_logistics"]` | 覆盖水泥营销所需的核心数据类型，匹配区域报价、库存、物流三类营销素材维度 |
| `update_interval` | `86400 秒（价格数据）、604800 秒（库存数据）` | 对应不同数据的实际更新节奏，避免频繁调用触发接口限流 |
| `field_validation_rules` | `{"标号": "^P\.(O|C)\d+\.\d+$", "区域": "^[A-Z]{2}\d{4}$"}` | 规范水泥标号与区域编码的格式，过滤无效输入数据 |
| `unit_conversion_config` | `{"价格": "元/吨", "库存": "万吨"}` | 匹配水泥行业通用计价与计量单位，统一输出数据格式 |
| `region_filter_enable` | `true` | 适配水泥营销的区域属性，强制开启区域筛选可提升内容精准度 |
| `api_timeout` | `30 秒` | 适配建材数据源接口的常规响应时长，预留合理缓冲时间 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：发起工具调用测试时返回422 Unprocessable Entity错误。原因：未按规范填写水泥标号参数，如使用“425水泥”这类非标准写法，触发字段校验失败。
- 现象：数据链接工具执行SQL语句后返回空结果。原因：未匹配水泥数据表的专属字段结构，直接使用通用建材字段名编写SQL，导致无法查询到有效数据。
- 现象：多模态工具调用时返回400 invalid image错误。原因：上传的水泥包装或物料图片格式不符合要求，或图片大小超出工具预设限制，触发格式校验失败。

## 怎么确认配好了
- 发起单条工具调用请求，输入符合规范的水泥标号与区域编码，核对返回数据的字段与单位是否与配置要求一致。
- 查看工具调用日志，确认接口响应状态码为200，无422、400类错误提示，字段校验环节无异常反馈。
- 手动调整更新间隔参数，触发一次数据拉取操作，核对拉取时间是否符合配置的间隔要求。
- 上传符合格式的水泥相关物料图片，验证多模态工具调用可正常完成流程并生成对应内容。
