# 油服工程营销内容的表单与交互

## 这个品类的数据长什么样
油服工程的数据主要来源于钻井作业日志、完井技术报告、设备运维台账、客户询价单与项目合同。数据更新节奏随项目推进实时调整，单项目周期内的作业节点数据每日更新，归档数据长期留存。文档结构以结构化字段为主，包含作业编号、设备型号、作业压力、流量、施工深度、工期、成本预算等字段，单位多采用行业通用的MPa、m³/h、米等专业计量标准，部分字段需匹配固定格式的编码规则。

## 这些特征在「表单与交互」这一环带来什么约束
油服工程的专业字段与单位要求表单需匹配专属输入控件，避免通用输入框导致的格式错误。实时更新的作业数据要求表单支持联动加载最新数据源，防止提交过时的项目信息。长文档与多字段联动的特性，要求表单支持批量导入与分段解析，同时需校验字段的数值范围与编码格式，确保提交内容符合行业规范。此外，跨项目的营销内容需绑定专属数据源，避免混淆不同项目的作业数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formFieldValidationRules` | 针对压力字段配置`0–140 MPa`区间校验，设备编号匹配`[A-Z]{2}-[0-9]{6}`正则 | 油服工程字段存在专业单位与固定编码格式，需拦截无效输入 |
| `remoteDataRefreshInterval` | `300 秒` | 油服工程作业数据实时更新，定期刷新避免表单加载过时信息 |
| `attachmentParseChunkSize` | `800–1200 字符` | 油服工程报告文档较长，分段解析适配长文本的表单关联需求 |
| `jsonEscapeMode` | `strict` | 避免工具调用时的json序列化生成冗余反斜杠转义 |
| `toolCallDataSourceScope` | `仅绑定当前项目的知识库` | 营销内容需关联对应项目的专属数据，避免跨项目调用无关信息 |
| `apiRequestTimeout` | `60 秒` | 油服工程数据接口返回内容较多，延长超时时间避免请求中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用工具传递参数时，json字符串出现大量额外反斜杠转义字符。原因：未设置`jsonEscapeMode`参数，默认序列化逻辑生成了冗余转义内容。
- 现象：工具调用配置界面无知识库选择下拉框。原因：未开启`toolCallDataSourceScope`的绑定配置，默认屏蔽了跨知识库调用入口。
- 现象：拖拽表单变量到提示词编辑区时界面卡顿明显。原因：表单绑定了高频刷新的数据源，未限制`remoteDataRefreshInterval`的间隔时长，导致前端资源占用过高。

## 怎么确认配好了
- 提交包含专业单位的表单字段，检查是否触发符合预期的格式校验提示。
- 调用工具传递参数，查看接口日志中返回的json字符串无额外反斜杠转义。
- 进入工具调用配置界面，确认存在知识库选择下拉框并可选择指定项目的知识库。
- 拖拽多个表单变量到提示词编辑区，观察界面无明显卡顿现象。
