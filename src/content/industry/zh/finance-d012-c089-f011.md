# 油气开采营销内容的文档解析与分块

## 这个品类的数据长什么样
油气开采领域的营销内容数据源包含勘探评估报告、钻井作业日志、区域油气藏分析文档、招商合作手册及行业合规通知等。数据更新节奏随业务阶段调整：勘探类文档随项目进度阶段性更新，营销物料随推广周期更新，行业合规文件按监管要求更新。文档结构混合专业技术字段与营销表述，专业字段包含孔隙度、渗透率、单井日产油量等，对应单位为%、毫达西(mD)、立方米/日等；内嵌内容包含岩心照片、钻井现场实拍图、油气田分布地图，部分文档内嵌单井产量统计表格。

## 这些特征在「文档解析与分块」这一环带来什么约束
专业技术字段与单位的绑定要求解析时保留完整语义单元，不能拆分字段与对应单位；内嵌图片及表格的存在，要求解析流程支持OCR提取图片文本、结构化提取表格内容，否则会丢失关键业务信息；文档长度跨度大，短则几页的招商手册，长则数十页的勘探报告，要求分块策略兼顾上下文连贯性与检索效率；数据源覆盖本地文件、语雀公开页、飞书文档等多种格式，要求解析配置支持多类型数据源的白名单校验与权限适配；营销内容与专业内容混合排布，要求分块时保留主题关联性，避免将跨主题的内容合并为单一分块。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxChunkSize` | 800–1200 字符 | 油气开采文档混合专业术语与营销表述，过长分块会破坏专业内容的上下文关联，过短则拆分完整的技术表述 |
| `enableImageOCR` | 开启 | 文档内嵌岩心照片、钻井现场图等，OCR可提取图片内的专业标注文字，供大模型关联理解 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 120 秒 | 大型勘探报告、批量营销物料包的解析耗时较长，默认超时时长不足以完成完整加载 |
| `ALLOWED_PARSE_DOMAINS` | `*.yuque.com, *.feishu.cn, local-file` | 覆盖常用的油气开采文档数据源，支持语雀公开页、飞书文档及本地文件导入 |
| `enableChunkOverlap` | 100–150 字符 | 专业术语如「孔隙度」「渗透率」可能跨分块出现，重叠片段可保留上下文连贯性 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 支持导入单份大型勘探报告或批量营销物料包，适配业务文档的体积范围 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
-  解析后图片未被大模型读取：现象为知识库检索结果中无图片关联文本，或调用大模型时无法获取图片内容。原因是未开启`enableImageOCR`配置，仅提取了文档纯文本未处理内嵌图片。
-  语雀公开链接无法完成解析：现象为导入时返回「不支持的数据源类型」报错。原因是未将语雀域名加入`ALLOWED_PARSE_DOMAINS`白名单，或链接未设置为公开可访问状态。
-  HTTP工具调用参数解析正常但未执行：现象为日志显示参数提取完成，但下游工具未触发请求。原因是未配置参数自动注入开关，或绑定的变量名与文档内的专业字段不匹配。

## 怎么确认配好了
-  上传单份油气开采招商手册，检查解析结果中是否包含所有内嵌图片的OCR提取文本，确认`enableImageOCR`配置生效。
-  导入语雀公开的勘探报告链接，验证解析任务状态为「完成」且无报错，确认域名已加入白名单。
-  配置HTTP工具调用并绑定文档内的单井产量字段，触发检索后查看工具调用日志，确认参数已正确传递。
-  导入飞书多维文档，检查解析结果中是否包含表格内的专业字段与对应单位，确认表格解析功能已启用。
