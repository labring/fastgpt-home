# 涂料油墨营销内容的HTTP 接口与外部系统

## 这个品类的数据长什么样
在金融行业的营销内容与获客场景中，涂料油墨的营销内容数据主要来自企业内部配方管理系统、合规备案平台、年度色号更新库及定制化客户需求台账。数据更新节奏随业务调整：基础色号与合规文档随国标修订更新，定制化需求数据随订单实时同步，营销物料模板每季度迭代。文档包含结构化字段：色号编码、产品名称、VOC排放限值（单位g/L）、耐候性等级、执行标准编号，以及非结构化的产品说明书、营销话术模板，单份文档长度从数百字到数万字不等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
涂料油墨的营销内容数据特征为HTTP接口与外部系统集成带来多项约束。结构化字段的标准化要求高，需在接口请求中固定传递色号、VOC限值等必填参数，避免格式不兼容；非结构化文档长度跨度大，需配置分段解析阈值适配长文本；实时同步的定制化订单数据要求接口支持高并发短请求，而季度更新的物料模板则可通过定时拉取降低调用频率；合规字段的单位（如g/L）需强制校验，避免因单位转换错误导致营销内容合规性问题；同时，多来源数据的拼接需在接口层完成格式统一，防止下游调用出现字段缺失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `CUSTOM_READ_FILE_URL` | `http://企业自有涂料油墨数据接口地址` | 直接对接企业内部配方、合规数据，减少中间数据中转环节 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 单份合规备案文档或产品手册长度可达数万字，需足够解析时长 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 覆盖单份最大尺寸的产品说明书、色号样本文档 |
| `maxContext` | `10000 字符` | 适配长段成分说明、营销话术的上下文处理需求 |
| `CHAT_API_TIMEOUT` | `60 秒` | 避免外部系统调用聊天接口时因长文本生成触发超时 |
| `REFERENCE_COUNT_LIMIT` | `前 5 条` | 控制聊天接口返回的引用列表长度，符合涂料油墨营销内容的信息展示习惯 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：在config.json中配置`CUSTOM_READ_FILE_URL`后，接口返回空数据。原因：未在配置项中指定正确的企业数据接口鉴权参数，导致无权限访问涂料油墨的配方与合规数据。
- 现象：聊天接口返回的引用列表条数超出预期。原因：未配置`REFERENCE_COUNT_LIMIT`参数，使用了默认的引用条数阈值，导致返回过多涂料油墨产品的参考文档。
- 现象：外部系统调用聊天接口时出现超时错误。原因：未调整`CHAT_API_TIMEOUT`参数，默认超时时长不足以处理长文本的营销内容生成请求。

## 怎么确认配好了
- 发起测试HTTP请求访问配置的`CUSTOM_READ_FILE_URL`，验证返回数据包含涂料油墨专属的色号编码、VOC排放限值等字段。
- 上传单份长度较大的涂料油墨合规文档，查看解析任务的执行状态，确认未触发超时或文件过大的报错。
- 调用聊天接口并传入自定义的引用条数参数，验证返回的引用列表条数与配置一致。
- 模拟外部系统的批量调用请求，确认接口响应符合业务场景的延迟要求。
