# 涂料油墨营销内容的表单与交互

## 这个品类的数据长什么样
涂料油墨行业的数据主要来源于生产配方库、原料质检报告、MSDS安全技术说明书以及下游应用测试数据。数据更新节奏随原料调价、配方迭代、合规标准更新而调整，无固定周期。文档结构分为结构化参数表与非结构化技术文档两类：结构化字段包含粘度、固含量、密度、干燥时间等，对应专用单位如`mPa·s`、`%`、`g/cm³`；非结构化文档多为多页PDF格式，包含详细的应用场景说明与合规说明。

## 这些特征在「表单与交互」这一环带来什么约束
结构化参数的专用单位要求表单需预设单位选项并强制校验，避免输入错误导致后续匹配失效。非结构化文档体积较大且页数较多，要求表单上传功能需适配大文件与长文档解析。多场景细分的参数分类要求表单需实现联动筛选，根据用户选择的应用场景（如木器涂料、柔性油墨）显示对应字段，减少无效输入项。高频更新的数据要求表单关联的知识库需支持实时同步，避免使用过期参数生成营销内容。同时，营销场景下的表单需收集用户的细分应用需求，对应字段需与知识库的召回规则绑定，确保生成的内容匹配用户实际场景。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 涂料油墨的MSDS、配方文档单份体积可达数百兆，需适配大文件上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | 长文档解析需较长时间，避免因超时中断解析流程 |
| `form_field_unit_validation` | `开启，强制匹配预设单位` | 涂料油墨参数包含`mPa·s`（粘度）、`%`（固含量）、`g/cm³`（密度）等专用单位，强制校验可避免输入错误 |
| `form_field_linkage` | `按应用场景触发字段显示` | 营销表单需区分木器涂料、塑料油墨等细分场景，联动显示对应参数字段，减少无效输入 |
| `retrieval_top_k` | `前6条` | 涂料油墨的匹配参数多为细分场景专用，少量召回即可覆盖核心需求 |
| `form_submit_pre_check` | `开启，校验必填字段完整性` | 表单包含配方编号、原料批次等必填项，前置校验可减少无效提交 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 表单提交后返回参数单位无效报错，日志显示字段格式不匹配。原因是未开启`form_field_unit_validation`配置，未强制校验涂料油墨专用单位。
- 上传MSDS文档后解析失败，界面返回`413`状态码。原因是`UPLOAD_FILE_MAX_SIZE`设置值小于文档实际体积，导致文件上传被拦截。
- 选择应用场景后未显示对应参数字段。原因是`form_field_linkage`配置未绑定正确的场景字段与参数组，联动规则匹配失效。

## 怎么确认配好了
- 上传一份典型的涂料油墨MSDS文档，检查解析后的字段是否正确提取了固含量、粘度等预设参数。
- 在表单中选择细分应用场景，检查是否仅显示该场景对应的参数字段，未显示无关参数项。
- 输入参数时使用非预设单位，检查是否触发单位校验报错，确认校验规则生效。
- 提交完整的必填表单字段，检查是否能正常触发知识库召回或生成匹配的营销内容。
