# 焦煤营销内容的工具调用与插件

## 这个品类的数据长什么样
焦煤相关数据主要来自国内产区现货报价平台、期货交易所合约数据及行业月度供需报告。现货报价每日更新，期货行情实时推送，行业报告按双周或月度频率发布。单条现货数据包含产地名称、规格参数、报价单位、最新报价、成交量、发布时间；批量报告包含区域产能、进出口量、开工率相关统计字段。数据字段围绕产业链供需与交易核心指标展开，无冗余附加项。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散导致需对接多类插件，不同数据源的字段命名存在差异，需配置字段映射规则。不同数据的更新频率差异明显，实时行情需高频轮询，行业报告需定时批量拉取，需为不同插件设置差异化的调用周期。焦煤的规格参数为交易核心依据，工具调用时需严格匹配字段类型与取值范围，避免因参数不匹配导致结果无效。部分数据源存在访问限制，需配置鉴权参数，确保调用权限合规。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `tool_call_max_retries` | `2–3 次` | 焦煤数据源部分接口偶发超时，重试2-3次可降低失败率，避免过度调用消耗配额 |
| `plugin_request_timeout` | `10–30 秒` | 期货接口响应较快，现货平台存在网络延迟，该区间覆盖多数数据源的响应时长 |
| `field_mapping_rule` | 绑定焦煤专属规格字段映射 | 不同数据源的规格参数命名存在差异，需将统一字段名绑定到焦煤核心交易指标 |
| `scheduled_call_interval` | 实时行情为`1 分钟`，行业报告为`1 天` | 实时行情需高频更新以匹配营销内容时效性，行业报告无需高频拉取 |
| `tool_call_output_filter` | 保留`产地、规格参数、报价、发布时间`字段 | 营销内容仅需核心交易与指标数据，过滤冗余字段可提升内容生成效率 |
| `plugin_auth_config` | 按数据源类型配置鉴权参数 | 不同数据源需对应专属的API密钥与请求头，确保调用权限合规 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 工具调用返回的焦煤数据字段缺失或格式混乱，无法直接用于生成营销内容。未配置`field_mapping_rule`，不同数据源的规格参数命名差异未统一，导致抽取结果不一致。
- 使用数据库连接插件执行多行SQL语句时，返回`SQL syntax error`报错。未开启多行查询支持配置，部分数据库插件默认仅允许单条语句执行，无法处理AI生成的多行业务语句。
- 实时行情工具调用频繁超时，返回`504 Gateway Timeout`状态码。未根据数据源调整`plugin_request_timeout`，使用了过短的超时时间，无法适配现货平台的网络延迟。

## 怎么确认配好了
- 手动触发工具调用，检查返回数据的字段是否与预设的`tool_call_output_filter`规则一致，无冗余字段。
- 查看插件调用日志，确认不同数据源的调用周期符合`scheduled_call_interval`的配置，实时行情调用间隔符合要求。
- 执行多行SQL语句测试，确认数据库连接插件可正常返回多条语句的执行结果，无语法报错。
- 调用联网工具时，确认可正常获取指定数据源的引用内容，无权限或访问限制报错。
