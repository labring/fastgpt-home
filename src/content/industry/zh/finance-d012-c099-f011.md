# 燃气营销内容的文档解析与分块

## 这个品类的数据长什么样
燃气营销相关数据主要来源于燃气经营企业的营销物料与业务台账，包括线下活动签到表、线上营销素材备份、区域用户触达台账、燃气具推广产品手册等。更新节奏按文档类型区分：活动类文档按单次活动或季度更新，触达台账按周更新，产品手册按年度更新。文档结构包含多列表格类台账、图文混排的营销推文、PDF格式活动方案，字段包含精确到楼栋的用户地址、用气类型枚举值、触达时间、反馈结果，用气量字段单位为立方米，金额字段单位为元。

## 这些特征在「文档解析与分块」这一环带来什么约束
燃气营销数据的多列表格特征，要求解析工具不能仅识别默认的2列数据，否则会丢失用户地址、用气类型等核心业务字段；高频更新的触达台账需要分块时保留时间与区域的上下文关联，避免业务逻辑断裂；图文混排的营销素材中，图片附带的产品说明文本需要与正文绑定，不能被拆分到无关分块；boolean类型的反馈字段需要保留原始数据类型，否则会在后续条件判断中丢失有效性。此外，大型多页PDF活动方案的长段落，需要按业务模块拆分，不采用固定长度的拆分方式，确保营销方案的完整逻辑被保留。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `excel_parse_max_columns` | `20 列` | 燃气营销触达台账通常包含用户地址、用气类型、触达时间等多列业务字段，默认2列的限制会丢失核心数据 |
| `chunk_size` | `800–1000 字符` | 燃气营销文档包含业务字段与说明文本，该长度可保留单区域触达计划或单产品推广方案的完整上下文 |
| `pdf_enhance_parse_api` | `mineru API` | 燃气营销的PDF物料包含多页表格与图文混排内容，该API可准确提取全列表格数据与图片关联文本 |
| `parse_boolean_as_text` | `false` | 燃气营销文档中的boolean类型反馈字段需要保留原始类型，避免后续条件判断时数据丢失 |
| `chunk_overlap` | `100–150 字符` | 燃气营销触达台账按区域分组，重叠长度可保留区域分组的上下文关联，避免分块后业务逻辑断裂 |
| `parse_file_timeout_seconds` | `120 秒` | 大型Excel触达台账与多页PDF文档的解析需要足够时间，避免因超时导致解析失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传多列燃气触达台账Excel后，知识库仅识别前2列数据，后续列丢失。原因：未调整`excel_parse_max_columns`参数，使用默认的2列限制。
- 现象：启用PDF增强解析后，无法正确提取燃气营销PDF中的嵌套表格与全列数据。原因：未正确配置`pdf_enhance_parse_api`参数指向mineru API，或未完成API权限配置。
- 现象：从业务文档解析得到的boolean类型反馈字段，进入条件判断组件后变为空值。原因：未将`parse_boolean_as_text`参数配置为false，导致解析过程中布尔值被错误转换或丢失。

## 怎么确认配好了
- 上传测试用的燃气触达台账Excel，检查知识库中存储的字段数量是否与原文档一致，确认`excel_parse_max_columns`配置生效。
- 上传包含boolean字段的测试文档，查看解析后的字段类型是否与原数据一致，确认`parse_boolean_as_text`配置正确。
- 上传多页PDF营销方案，查看提取的文本是否包含所有表格列与图文关联内容，确认`pdf_enhance_parse_api`配置指向正确的服务。
- 测试分块后的检索效果，查看是否能通过区域或触达时间精准召回对应分块，确认`chunk_size`与`chunk_overlap`配置符合业务需求。
