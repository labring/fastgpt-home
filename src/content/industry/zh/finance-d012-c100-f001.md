# 物业管理营销内容的HTTP 接口与外部系统

## 这个品类的数据长什么样
物业管理的营销内容数据主要来自物业内部运营系统、业主服务小程序后台、线下活动报备记录。数据更新节奏随场景变化：社区活动通知提前1至7天发布，缴费提醒按自然月固定更新，商户招商信息随入驻情况实时调整。文档结构包含标题、适用楼栋范围、发布时间、附件文件、对接联系人字段，其中楼栋范围字段以「X栋Y单元」格式标注，附件文件支持PDF、JPG、PNG格式，单份附件大小通常符合物业运营的常规上限。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
物业管理的营销内容数据特征对HTTP接口与外部系统带来明确约束。楼栋范围的「X栋Y单元」格式要求接口配置字段校验规则，拦截无效格式的请求参数。附件文件的格式与大小限制，要求接口开启白名单校验与单文件大小阈值配置，避免非法文件传入。实时更新的商户招商信息，要求接口支持高频调用，需配置合理的请求频率限制。按自然月更新的缴费提醒与活动通知，要求接口支持按时间范围、业主分组筛选数据，确保返回内容匹配对应服务对象。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_ALLOW_EXT` | `["pdf", "jpg", "png"]` | 匹配物业管理营销内容常用的海报、通知附件格式 |
| `UPLOAD_FILE_MAX_SIZE` | `100 MB` | 符合物业活动海报、缴费凭证等附件的常规大小上限 |
| `REQUEST_RATE_LIMIT` | `60次/分钟` | 适配商户信息、活动通知的高频更新调用需求 |
| `DATA_FILTER_FIELDS` | `["楼栋范围", "业主分组"]` | 支持按物业运营的核心维度筛选返回的营销内容 |
| `API_TIMEOUT` | `30 秒` | 覆盖大附件解析与多维度数据拼接的处理时长 |
| `MAX_RECALL_RESULTS` | `前8条` | 匹配业主单次接收的营销内容数量上限，避免信息过载 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：前端界面可开启文件上传，但调用对话接口上传文件时返回`400 Bad Request`错误，无法提交附件。原因：未配置`UPLOAD_FILE_ALLOW_EXT`白名单，或传入了物业营销内容未使用的文件格式。
- 现象：使用知识库API拉取营销内容时，返回结果未按楼栋范围筛选，出现跨楼栋的无关通知。原因：未启用`DATA_FILTER_FIELDS`中的楼栋范围过滤，或传入的筛选参数格式不符合「X栋Y单元」的要求。
- 现象：高频调用商户信息接口时返回`429 Too Many Requests`错误，请求被拦截。原因：未配置`REQUEST_RATE_LIMIT`适配物业实时更新的调用频率，导致超出接口限流阈值。

## 怎么确认配好了
- 发起包含物业常用PDF附件的POST请求，检查返回的响应状态码与错误提示，确认文件格式与大小校验生效。
- 传入符合「X栋Y单元」格式的楼栋范围参数，调用数据拉取接口，检查返回结果是否仅包含对应楼栋的营销内容。
- 发起连续调用请求，检查是否触发限流拦截，确认请求频率配置符合业务需求。
- 发起包含大附件的请求，等待处理时长后检查响应，确认接口超时配置适配实际处理需求。
