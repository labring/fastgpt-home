# 物业管理营销内容的文档解析与分块

## 这个品类的数据长什么样
物业管理面向金融/保险/理财领域的营销内容数据，主要来自社区金融服务推广物料、物业费分期方案、社区理财活动通知、业主保险推介手册、项目案场金融配套资料等。更新节奏随金融活动节点变动，新理财产品上线、物业费调整、年度保险推介时会集中更新，日常维护以月度为周期。文档结构包含结构化收费表格、长文本活动说明、内嵌产品介绍图片三类，字段多带有明确单位，如分期费率（%）、物业费单价（元/平方米·月）、理财年化收益率（%），部分文档包含嵌套层级的活动流程说明。

## 这些特征在「文档解析与分块」这一环带来什么约束
结构化的收费表格、费率表格要求解析逻辑保留字段与单元格的对应关系，避免拆分后丢失数据关联；内嵌产品介绍图片需要同步提取文本内容，否则无法完整传递金融营销信息；高频更新的金融活动文档需要适配增量解析逻辑，避免重复全量解析浪费资源；带单位的字段如年化收益率、分期费率若拆分时丢失单位，会导致后续问答出现歧义；长文本的活动方案与产品说明，硬切分块会破坏内容的语义连贯性，需要按自然段落与标题进行拆分；嵌套层级较多的文档结构，需要适配足够的解析深度以覆盖完整内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_TABLE_ENABLE` | `开启` | 针对物业费测算表、费率表格等结构化数据，保留字段与单元格的对应关系 |
| `MAX_PARSE_CHUNK_SIZE` | `800–1200 字符` | 物业管理金融营销文档多为长文本活动方案、产品说明，该区间可保留语义完整性 |
| `PARSE_IMAGE_OCR_ENABLE` | `开启` | 文档中嵌入户型图、产品介绍图等图片，需提取图片内文本关联至上下文 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单项目营销文档包通常包含多份PDF、图片合集，适配大文件上传需求 |
| `PARSE_SEGMENT_SPLITTER` | `按段落+标题` | 避免硬切破坏活动流程、收费规则等连贯内容 |
| `MAX_PARSE_PARAGRAPH_DEPTH` | `3–5 层` | 适配4.9.10版本的文档解析深度要求，覆盖嵌套的活动流程、产品说明层级，避免内容截断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传表格数据集后部分字段为空，解析结果丢失物业费单价、分期费率等结构化数据。原因：未开启`PARSE_TABLE_ENABLE`配置，默认解析逻辑未保留表格单元格与字段的对应关系。
- 现象：嵌入PDF的产品介绍图、户型图未被解析，仅显示空白占位。原因：未开启`PARSE_IMAGE_OCR_ENABLE`配置，或使用的解析模型不支持PDF内嵌图片的OCR提取。
- 现象：将知识库导出后导入新服务器，解析后的分块与原服务器不一致。原因：未固定`MAX_PARSE_CHUNK_SIZE`与`PARSE_SEGMENT_SPLITTER`参数，新环境默认配置与原环境存在差异。

## 怎么确认配好了
- 上传单份结构化表格文档，检查解析结果是否保留原表格的字段与单元格对应关系，核对`PARSE_TABLE_ENABLE`配置状态。
- 上传包含内嵌图片的PDF文档，检查解析结果是否包含图片内提取的文本内容，核对`PARSE_IMAGE_OCR_ENABLE`配置状态。
- 上传单份长文本文档，查看分块结果是否按段落与标题拆分，核对`PARSE_SEGMENT_SPLITTER`配置项。
- 上传嵌套层级较多的长文档，检查解析结果是否覆盖完整内容，核对`MAX_PARSE_PARAGRAPH_DEPTH`参数配置。
