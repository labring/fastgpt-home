# 特钢营销内容的工作流编排

## 这个品类的数据长什么样
特钢相关数据主要来自生产管理系统、质检部门报送台账、销售询价记录与库存管理模块。生产类数据每日更新，库存数据每4小时同步更新，客户询价记录实时录入。数据以结构化表格为主要呈现形式，包含钢号、公称尺寸（单位mm）、交货状态、力学性能指标（单位MPa）、应用场景、库存余量（单位吨）等字段，部分配套技术参数的PDF附件。

## 这些特征在「工作流编排」这一环带来什么约束
多数据源的异构性要求工作流配置跨系统拉取节点，需适配不同数据更新频率设置定时或实时触发规则。结构化字段附带明确物理单位，需在数据清洗节点配置单位校验逻辑，避免不同来源的单位混淆导致内容错误。配套的PDF技术附件存在长文本参数，需配置专用的文档解析节点提取结构化参数。营销内容需关联实时库存与客户询价数据，需设置分支流程触发条件，根据实时数据生成差异化的营销素材。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_PDF_TIMEOUT` | `300 秒` | 特钢配套的PDF技术文档通常不超过10页，300秒可完成完整参数提取 |
| `REDIS_URL` | `redis://:{自定义密码}@{服务器IP}:6379/0` | 用于缓存临时生成的营销素材与会话数据，保障工作流的状态同步 |
| `rag_recall_top_k` | `前 8 条` | 特钢技术参数需精准匹配，过多召回会导致营销内容冗余且偏离需求 |
| `workflow_trigger_mode` | `混合触发` | 适配生产数据每日更新、库存数据每4小时更新的节奏，结合定时与实时触发 |
| `data_clean_unit_check` | `开启` | 特钢数据包含mm、MPa、吨等多单位，校验可避免不同来源的单位混淆 |
| `sub_workflow_global_var_sync` | `开启` | 营销内容生成需跨子流程共享库存、客户询价等全局数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：代码运行节点的变量下拉菜单中无知识库引用选项。原因：未在工作流全局设置中绑定目标知识库，或未开启知识库与工作流的关联权限。
- 现象：嵌套子流程无法读取外层流程的全局变量，导致营销内容无法关联实时库存数据。原因：未开启`sub_workflow_global_var_sync`配置项，或未在子流程中声明全局变量的引用路径。
- 现象：RAG召回结果返回条数超出预期，无法仅输出第一条匹配的技术参数。原因：未将`rag_recall_top_k`配置为`前 1 条`，或未在节点中添加结果截取的过滤规则。

## 怎么确认配好了
- 进入工作流的测试面板，上传一份特钢的PDF技术文档，验证解析节点是否能正确提取钢号、尺寸等核心字段。
- 手动触发一次工作流，查看变量选择面板是否能拉取到已绑定的知识库内容，确认变量调用功能正常。
- 配置一条测试用的库存数据触发条件，模拟库存余量变化，验证工作流是否会触发对应的分支流程。
- 查看工作流的运行日志，确认全局变量能在主流程与子流程之间正常同步，无数据丢失或格式错误。
