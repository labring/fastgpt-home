# 特钢营销内容的表单与交互

## 这个品类的数据长什么样
特钢相关数据主要来源于生产台账、离线质检报告、客户定制订单、库存调拨系统。数据更新节奏按生产批次或每日盘点执行，单批次数据随生产完成即时更新。文档结构多为结构化Excel或CSV表格，包含钢号、断面规格、屈服强度、抗拉强度、交货状态、包装方式、计价单位等字段，字段单位包含MPa、mm、吨、元/吨等专业工业单位。

## 这些特征在「表单与交互」这一环带来什么约束
特钢数据多为结构化表格，包含多维度专业字段，要求表单支持按列名解析并保留原始单位。数据按生产批次更新，单批次文件体积存在波动，要求上传组件支持大文件上传与稳定解析。营销场景需匹配特定钢号、规格的精准需求，要求交互环节支持按指定字段筛选数据。部分客户会提交自定义质检报告，要求表单支持自定义字段映射规则。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 特钢生产台账、质检报告单份文件通常不超过200MB，预留合理缓冲空间 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | 多字段结构化表格需遍历多列数据，避免因解析耗时过长导致中断 |
| `maxContext` | `8000–12000 字符` | 单批次特钢数据包含数十个字段，字符量较大，需适配长上下文输入需求 |
| `召回条数` | `前 6 条` | 营销内容需匹配特定钢号、规格的精准需求，优先返回Top级匹配结果 |
| `表单字段映射规则` | `按列名自动匹配` | 特钢数据字段命名标准化程度较高，自动映射可减少人工配置成本 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传的特钢结构化数据未参与大模型统计总结。原因：未开启`UPLOAD_FILE_PARSE_ENABLE`配置项，或未将上传文件绑定至对话上下文。
- 现象：上传的JSON格式质检报告超出字符限制报错。原因：未调整`maxContext`参数至适配单份文件字符量的区间，默认参数无法覆盖长文本输入。
- 现象：发布的表单页面缩小后再放大，表单内容无法正常显示。原因：未启用响应式布局配置，或未使用适配式容器包裹表单组件。

## 怎么确认配好了
- 上传单份200MB的结构化表格文件，检查解析进度条完成且无报错提示。
- 上传JSON格式的特钢质检数据，查看对话上下文是否包含解析后的字段内容。
- 调整发布页面的缩放比例，检查表单字段、上传组件是否随缩放正常显示。
- 调用模型接口，验证上传的特钢数据是否被纳入统计总结的输入范围。
