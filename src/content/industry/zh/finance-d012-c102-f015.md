# 特钢营销内容的部署与升级

## 这个品类的数据长什么样
特钢营销内容的数据来源包括企业内部生产管理系统、质检报告、销售报价台账、行业供需参考文档。更新节奏随产品研发进度与市场波动调整，产品牌号与规格不定期更新，报价与供货周期每7至15天更新一次。单份营销文档通常包含结构化产品参数表、应用场景说明、合规检测报告附件、历史供货案例，字段涵盖牌号标识、力学性能参数、供货状态标识、交货周期，其中力学性能参数以兆帕、毫米为标准工业单位，无冗余营销修饰字段。

## 这些特征在「部署与升级」这一环带来什么约束
特钢营销内容的结构化参数多、更新频率波动且包含合规文档，对部署与升级环节带来多重约束。需对接企业内部ERP系统拉取实时参数与报价数据，无法仅依赖静态文件存储。文档解析需保留字段与单位关联，避免分块破坏参数完整性。因更新节奏不固定，需配置增量同步机制，减少全量重建带来的服务中断。同时需适配企业局域网的访问规则，支持Nginx二级目录部署以隔离内部系统路径。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 特钢营销文档常包含多页质检报告，需足够时长完成长文档解析 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 单份营销文档可整合多份检测报告PDF，需支持大文件上传 |
| `basePath` | `/fastgpt` | 适配企业内部系统的二级目录部署需求，与其他业务路径隔离 |
| `召回条数` | `前 8-12 条` | 特钢营销内容的参数匹配精度要求高，适量召回避免冗余结果 |
| `相似度阈值` | `0.75-0.85` | 过滤低匹配度的无关内容，保留核心匹配的产品参数信息 |
| `环境变量加载路径` | `./.env.local` | v4.8.13开源版本需通过该路径加载自定义配置，适配本地部署场景 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：访问服务时提示`502 Bad Gateway`错误，或无法通过局域网IP加载界面。原因：仅绑定了容器内部IP，未配置Nginx反向代理的局域网IP映射，导致外部局域网无法连通服务。
- 现象：配置`basePath`为二级目录后，静态资源加载失败，界面显示404错误。原因：仅修改了Next.js的`basePath`配置，未同步更新Nginx的`location`匹配规则与根路径配置。
- 现象：传入营销文档链接后，解析结果仅返回空文本，未提取任何产品参数。原因：未在v4.8.13版本中开启`PARSE_ENABLE_LINK`环境变量，或未调整文档解析超时参数适配长文档。

## 怎么确认配好了
- 在局域网内使用浏览器访问配置的二级目录地址，检查是否能正常加载登录界面，无资源加载报错。
- 上传一份包含多页检测数据的特钢营销文档，等待解析完成后，检查知识库中是否保留了完整的参数字段与单位信息。
- 发起一次基于特钢产品参数的检索，检查返回结果的匹配度符合预设的相似度阈值区间，无冗余低匹配内容。
- 修改知识库中的产品报价数据，触发增量同步任务，检查更新后检索结果是否同步了最新的报价信息。
