# 玻璃营销内容的表单与交互

## 这个品类的数据长什么样
玻璃相关营销数据主要来源于企业内部ERP库存系统、CAD设计图纸库、线下门店的现货台账。现货库存数据每日同步更新，定制加工类数据随客户订单创建实时调整。文档结构以结构化规格字段为主，搭配CAD格式的非结构化附件。核心字段包括玻璃类型、厚度（单位mm）、外形尺寸（长×宽，单位mm）、加工工艺选项、库存状态。

## 这些特征在「表单与交互」这一环带来什么约束
结构化规格字段与CAD附件并存，要求表单支持混合输入模式，同时提供下拉选择与文件上传能力。玻璃的尺寸与厚度字段存在明确单位要求，需在表单中预设单位选项，避免手动输入的格式错误。库存数据实时同步的特性，要求表单的库存状态字段联动后端接口，自动禁用已售罄的玻璃型号。营销内容需关联玻璃选型知识库，要求交互环节根据用户输入的参数自动召回对应工艺、报价的解答内容。定制加工的动态选项，要求表单支持字段联动加载，仅在选中对应玻璃类型时展示可选加工工艺。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 适配玻璃营销表单中CAD图纸、工艺文件的常见上传大小，避免文件超限失败 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | CAD格式文件解析耗时较长，预留足够解析时间 |
| `KNOWLEDGE_RECALL_TOP_K` | `3-5条` | 玻璃选型知识库内容聚焦，少量召回即可覆盖用户常见疑问 |
| `SIMILARITY_THRESHOLD` | `0.75-0.85` | 过滤低相关的知识库内容，确保召回的玻璃选型文档匹配用户需求 |
| `FORM_FIELD_REQUIRED` | `玻璃类型、厚度、加工需求` | 这三类字段为玻璃营销表单的核心必填项，缺失无法生成精准营销内容 |
| `FORM_SUBMIT_TRIGGER` | `绑定企业微信客服` | 匹配商业版本的客户对接需求，确保表单提交后触发后续服务 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：对话界面未展示用户在表单中填写的玻璃规格参数，原因：未配置`FORM_FIELD_SYNC_TO_CHAT`，导致表单数据未同步至对话上下文。
- 现象：提交表单后未触发客服对接流程，无后续联系动作，原因：未配置`FORM_SUBMIT_TRIGGER`的企业微信客服联动逻辑，导致表单提交后未触发通知。
- 现象：上传的CAD文件未被解析，原因：`UPLOAD_FILE_ALLOWED_EXTENSIONS`未包含`.dwg`、`.dxf`等CAD格式后缀，导致文件被拦截。

## 怎么确认配好了
- 在表单编辑器中填写钢化玻璃、10mm厚度、1500×2000mm的测试参数，提交后查看对话上下文是否同步显示该组参数。
- 上传一张小型CAD测试文件，等待解析完成后，确认知识库召回结果包含对应玻璃类型的选型说明。
- 开启语音输入功能，朗读预设的玻璃参数，确认转写后的文本可自动匹配并填充至对应表单字段。
- 上传超过500MB的测试文件，确认系统返回文件大小超出限制的报错信息。
