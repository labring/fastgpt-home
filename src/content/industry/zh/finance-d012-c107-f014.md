# 电力营销内容的表单与交互

## 这个品类的数据长什么样
电力营销相关数据主要来自用电采集系统、客户营销管理系统及线下报装工单。数据更新节奏为每日同步新增的用电户档案、触达记录，每月完成全量历史数据校准。文档以结构化表单为主，核心字段包含10位数字格式的用户户号、用电地址、用电类别（居民/工商业/大工业），计量单位为千瓦时、元/千瓦时，部分场景需关联用户历史缴费记录与用电负荷数据。

## 这些特征在「表单与交互」这一环带来什么约束
10位数字格式的户号要求表单输入控件添加固定长度数字校验，避免无效输入。固定枚举的用电类别字段需限制为单选/多选组件，禁止自由文本输入。不同用电类别的用户需匹配差异化表单字段，需配置动态显示的触发规则。关联用电负荷、缴费记录的字段需支持通过户号自动拉取数据，减少手动输入步骤。部分线下转线上的营销表单需兼容非数字化用户的输入习惯，提供辅助输入提示。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `radio_option_api` | 绑定电力营销系统的用电分类接口 | 实时获取最新的用电类别枚举，适配电力业务的分类更新需求 |
| `input_pattern` | `^\d{10}$` | 匹配10位数字格式的用户户号，快速过滤无效输入 |
| `input_max_length` | `10` | 限制输入长度与户号格式匹配，减少校验逻辑复杂度 |
| `dynamic_field_switch` | 按用电类别触发 | 针对居民、工商业、大工业用户展示差异化表单字段 |
| `auto_fill_trigger` | 户号输入校验通过后触发 | 自动拉取关联的用电地址、缴费记录，减少手动输入步骤 |
| `dialog_display_mode` | 嵌套工作流时隐藏 | 解决嵌套场景下对话框重复显示的交互问题 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：单个工作流中表单节点触发时对话框隐藏，嵌套到其他工作流时对话框仍显示。原因：未配置`dialog_display_mode`的嵌套场景适配规则，默认逻辑未兼容工作流嵌套的交互场景。
- 现象：单选多选组件的选项未实时更新，出现用电类别枚举与系统不一致的情况。原因：未使用`radio_option_api`绑定业务接口，而是手动维护固定枚举，无法同步最新的业务分类调整。
- 现象：表单提交后未触发后续服务流转，出现用户咨询无对接人员的情况。原因：未配置表单提交后的回调触发规则，未关联营销系统的工单分配接口，导致提交数据未流转至对应服务环节。

## 怎么确认配好了
- 输入不符合10位数字格式的户号，检查是否弹出对应格式错误提示，确认`input_pattern`的校验规则生效。
- 切换不同的用电类别选项，检查表单字段是否动态切换显示，确认`dynamic_field_switch`的配置正确。
- 输入正确的10位户号，检查是否自动拉取关联的用电地址等字段，确认`auto_fill_trigger`的触发逻辑正常。
- 将表单节点嵌套至测试工作流中，检查对话框是否按配置隐藏，确认`dialog_display_mode`的适配规则生效。
