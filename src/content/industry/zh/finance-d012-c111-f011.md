# 畜禽养殖营销内容的文档解析与分块

## 这个品类的数据长什么样
该品类的数据主要来自规模化养殖手册、疫病防控指南、饲料配方文档、养殖户社群营销话术、出栏存栏统计报表。更新节奏随业务场景变化：饲料配方随原料行情不定期调整，疫病防控指南随新毒株通报更新，营销物料随季度营销活动迭代。文档形态包含纯文本养殖技巧、带表格的免疫/配比方案、PDF格式行业简报，字段多涉及存栏量、出栏周期、饲料转化率，单位多为头/羽、千克、日龄。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的数据特征对解析分块带来三点约束：其一，大量文档包含带单位的数值表格，解析时需保留表格的行列关联，避免拆分后字段与单位脱节；其二，营销话术与技术文档混存，需区分短文本营销素材和长文本技术方案的分块边界，防止营销话术被强行拆分为过长片段；其三，更新频率不均，部分文档需增量解析，需适配按文件修改时间触发的解析逻辑，避免重复处理已解析内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_TABLE_ENABLE` | 开启 | 该品类文档中饲料配比、免疫时间表等表格占比高，保留表格结构可避免字段与单位脱节 |
| `CHUNK_SIZE` | 800–1200 字符 | 兼顾长文本技术文档的完整上下文与短文本营销素材的语义连贯性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 适配大型养殖行业报告的解析时长需求，避免因超时中断解析流程 |
| `ENABLE_INCREMENTAL_PARSE` | 开启 | 该品类文档更新频率不均，增量解析可减少重复处理已完成解析的文件 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 匹配该品类常见的大型行业简报、养殖手册的文件尺寸范围 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传PDF后界面无解析进度提示，搜索测试返回空结果。原因：未开启`PARSE_TABLE_ENABLE`配置，表格类养殖文档无法被正确提取文本，后续向量化无有效数据。
- 现象：知识库上传文档后向量化环节耗时过长。原因：未调整`CHUNK_SIZE`参数，使用过小的分段长度生成过多分块，增加向量化计算开销。
- 现象：发起对话时，非文档相关的文字提问触发了文档解析流程。原因：未关闭全局的`PARSE_QUESTION_ENABLE`配置，导致所有输入内容均进入文档解析链路。

## 怎么确认配好了
- 上传一份包含结构化表格的测试文档，核对解析后的文本是否保留字段与单位的关联关系。
- 查看解析日志，确认单份文档的解析时长未超出配置的超时阈值，无超时中断记录。
- 上传已更新的同一份文档，核对系统仅对修改后的内容执行解析，未重复处理历史文件。
- 发起非文档相关的文字提问，核对输入内容未触发文档解析流程，仅进入常规问答链路。
