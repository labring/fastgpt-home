# 白色家电营销内容的工作流编排

## 这个品类的数据长什么样
白色家电营销内容依赖的数据主要来自产品官方参数文档、电商平台商品页、售后运维台账。数据更新无固定周期，随新品上线、促销活动调整或合规要求触发。单份数据文档包含SKU编码、产品型号、能效等级、外形尺寸（毫米）、额定功率（瓦）、上市日期、适用场景等字段，部分衍生素材还包含用户反馈的使用痛点关键词。字段均绑定明确单位，不同SKU的字段内容差异较大，需按个体单独匹配。

## 这些特征在「工作流编排」这一环带来什么约束
字段绑定明确单位且SKU间差异大，要求工作流中需配置字段格式校验节点，确保提取的尺寸、功率等参数单位统一，避免营销内容出现单位错误。数据更新无固定周期，无法依赖定时触发，需配置按SKU更新或人工触发的节点，保障营销素材随数据实时同步。多来源数据存在格式差异，需在工作流中添加数据归一化节点，统一不同平台提取的参数结构。营销内容需匹配对应SKU的专属参数，要求工作流支持按SKU分组处理节点，避免不同产品的参数混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `FILE_UPLOAD_MAX_SIZE` | `500 MB` | 白色家电产品说明书多为PDF或高清图片，500 MB可覆盖绝大多数单文件素材的上传需求 |
| `PARSE_DOCUMENT_TIMEOUT` | `120 秒` | 产品说明书包含较多图文内容，解析耗时较长，120秒可保障完整解析 |
| `MODEL_API_RATE_LIMIT` | `80 请求/分钟` | 匹配`qwen3.5-plus`模型的官方调用限制，避免触发`429`请求超限报错 |
| `GLOBAL_VAR_SCOPE` | `按工作流实例隔离` | 不同营销内容的全局变量需独立存储，避免跨实例变量冲突 |
| `ERROR_CAPTURE_ENABLE` | `开启` | 捕获节点报错信息，便于排查流程异常 |
| `ALLOWED_FILE_EXTENSIONS` | `pdf, jpg, png` | 覆盖白色家电营销素材常用的文档格式，避免上传失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用`qwen3.5-plus`模型节点时返回`429 Request rate increased too quickly`报错，未配置`MODEL_API_RATE_LIMIT`参数，或取值超出模型允许的请求速率上限。
- 工作流中无法获取全局变量值，对应字段显示为空，未正确配置`GLOBAL_VAR_SCOPE`参数，变量作用域未匹配当前工作流的执行范围。
- 上传白色家电产品说明书图片时解析失败，未在`ALLOWED_FILE_EXTENSIONS`中添加`jpg`或`png`格式，导致节点拒绝接收非指定格式的文件。

## 怎么确认配好了
- 上传一份白色家电产品说明书PDF，检查文件解析节点是否返回正确的SKU编码、能效等级等字段内容。
- 连续触发10次模型调用节点，检查是否出现`429`状态码报错，验证速率限制配置生效。
- 在工作流中添加全局变量调用节点，输入预设变量值后执行流程，检查返回值是否与预设内容一致。
- 故意触发节点报错，例如断开上游数据连接，检查错误捕获节点是否正常触发并记录报错日志。
