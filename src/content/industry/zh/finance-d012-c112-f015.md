# 白色家电营销内容的部署与升级

## 这个品类的数据长什么样
金融场景下的白色家电营销内容数据主要来源于合作品牌的官方产品规格书、电商平台结构化参数页、售后维护手册及品牌方官方营销物料。数据更新节奏随新品上线调整，新品密集期更新频率较高，常规时段按季度或年度更新。文档包含结构化参数与非结构化营销文案两类：结构化部分以型号、容量、功率、能效等级为核心字段，配套升、瓦、千克等标准单位；非结构化部分包含产品卖点、使用场景说明等内容。

## 这些特征在「部署与升级」这一环带来什么约束
结构化参数字段多且带固定单位的特征，要求部署时配置结构化文档的字段映射规则，避免解析后字段混乱。更新节奏随新品上线波动的特点，要求升级环节支持批量知识库更新与版本回滚，适配突发的内容更新需求。文档包含结构化与非混合类内容的特征，要求部署时针对不同文档类型配置差异化的解析参数，分别适配表格解析与通用文本解析。能效等级等参数随国标更新的情况，要求升级时同步调整参数校验逻辑，确保新上传的文档符合最新标准。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_TABLE_ENABLE` | `开启` | 白色家电营销内容包含大量结构化参数表格，开启后可准确提取字段与单位 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300-600 秒` | 单份完整产品手册包含多页表格与文本，需足够时间完成完整解析 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 批量上传的营销物料合集或多型号手册文件体积较大，适配批量部署需求 |
| `分段长度` | `800-1200 字符` | 平衡长段落使用说明与短卖点文案的上下文连贯性，避免分割过碎或过长 |
| `召回条数` | `前6-8条` | 单用户咨询通常聚焦1-2款家电产品，少量召回即可覆盖核心参考信息 |
| `相似度阈值` | `0.75-0.85` | 家电参数相似度较高，该区间可过滤无关内容，保留匹配度较高的产品信息 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：私有化部署升级版本后，点击知识库的文件详情，显示`Invalid dataset file key`。原因：升级过程中未同步更新数据集文件的关联密钥配置，旧版本密钥与新版本系统不兼容。
- 现象：非商业版本部署后，无法配置API密钥的使用时长与调用次数限制。原因：未启用密钥管控相关的系统配置，或配置参数未正确加载至运行环境。
- 现象：上传大型产品手册文件时，解析任务超时失败。原因：`PARSE_FILE_TIMEOUT_SECONDS`配置取值过低，未适配长文档的解析耗时需求。

## 怎么确认配好了
- 上传一份标准的白色家电产品手册，检查解析后的字段是否完整提取型号、容量、功率等核心参数。
- 触发一次批量知识库更新任务，确认所有上传的文档均完成解析并同步至知识库。
- 配置API密钥后，测试密钥的使用时长与调用次数限制是否按预设规则生效。
- 发起一次针对家电产品的检索请求，检查召回的内容匹配度是否符合预设的检索规则。
