# 种植业营销内容的HTTP 接口与外部系统

## 这个品类的数据长什么样
种植业的营销内容数据主要来自农业行业资讯平台、合作农资厂商的素材库、内部种植基地的生产记录。更新节奏随场景变化：农资促销素材按季度或营销活动周期更新，种植技术指南随农时（如每季作物的种植节点）调整，种植户案例素材不定期新增。文档多为结构化格式，包含素材ID、素材类型（文案/图片/视频）、适用作物、适用农时、发布时间、素材内容、标签字段。字段包含`crop_type`（作物类型，单位为作物名称）、`planting_period`（种植周期，单位为月）、`publish_time`（发布时间，采用ISO8601格式）等标准化标识。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
种植业营销内容的数据源特征会直接约束接口配置与调用逻辑。首先，按农时和品类分类的素材要求接口支持按`crop_type`、`planting_period`等字段筛选，避免拉取无关内容；其次，非实时更新的素材特性要求接口支持增量拉取，减少不必要的流量消耗；第三，多类型素材（文案、图片、视频）需要接口兼容不同格式的内容解析，适配不同场景的展示需求；最后，关联的参考链接字段要求接口返回标准化的`reference_url`字段，以便后续渲染展示。这些约束需要在接口对接时提前匹配参数规则，避免出现字段不兼容或请求无效的问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `external_material_api_url` | `https://api.agri-marketing.com/v1/promotion-materials` | 对接种植业专属营销素材库的标准RESTful接口地址 |
| `sync_interval` | `86400 秒` | 种植业营销素材更新周期多为每日或每周，每日同步可保证素材时效性 |
| `filter_crop_category` | `水稻,小麦,蔬菜` | 按作物品类筛选素材，匹配种植业营销的精准触达需求 |
| `api_request_timeout` | `25 秒` | 农业行业API接口响应普遍较慢，25秒可覆盖绝大多数正常请求时长 |
| `auth_method` | `API_KEY` | 外部素材接口多采用API密钥授权，可有效防止未授权访问 |
| `render_reference_link` | `开启` | 种植业营销素材常附带农资购买、农技资讯链接，开启后可在对话界面正常展示 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用模型测试接口返回`404 Not Found`，容器日志显示`Api response error: /api/core/ai/model/test?model=Doubao-l`。原因：填写的`model_id`未与外部模型提供商的实际模型标识完全匹配，存在截断或拼写错误。
- 现象：使用知识库对话的API key调用外部素材接口时提示未授权。原因：未为外部接口单独配置专属API密钥，误用了知识库的授权凭证，不同系统的授权凭证互不通用。
- 现象：接入第三方联网API后，对话中未渲染参考链接。原因：未开启`render_reference_link`配置项，或未在接口返回的素材中携带标准的`reference_url`字段。

## 怎么确认配好了
- 调用FastGPT的外部数据源测试接口，检查返回的素材列表中包含预期的作物类型和营销内容，确认接口连通性正常。
- 发起一次模型测试请求，核对返回的模型响应状态码为`200 OK`，且模型ID与配置项中的值完全一致。
- 发起包含参考链接的营销内容对话，检查对话界面中是否正常渲染出链接文本，可点击跳转至对应页面。
- 查看同步任务日志，确认最近一次同步任务执行成功，未出现超时或授权错误。
