# 种植业营销内容的模型接入与配置

## 这个品类的数据长什么样
种植业相关数据主要来自种植户生产台账、农资供销平台、区域气象监测站、农产品行情数据库及标准化种植技术文档，同时结合金融机构的农业保险、种植贷等产品参数。数据更新节奏随农事周期与金融产品更新节奏调整，常规种植记录按周更新，气象与行情数据按日更新，金融产品参数按季度更新。文档多为结构化表格或短文本，字段包含地块编号、作物品种、种植周期、农资使用量、单产预期、保险费率、贷款额度等，单位多为亩、公斤、摄氏度、元/千克、%等农业与金融通用计量标准。

## 这些特征在「模型接入与配置」这一环带来什么约束
种植业数据与金融产品参数的结合要求模型接入时需配置跨数据源的字段映射规则，避免农业与金融字段的匹配偏差；按周/日/季的差异化更新节奏，要求配置多周期的增量同步触发参数，避免全量拉取占用过多调用资源；农业专用计量单位与金融术语，要求模型调用时需开启行业术语识别开关，确保输出内容符合农业与金融双行业的规范；短文本为主的文档结构，无需配置过长的上下文召回长度，可降低大模型调用成本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `800–1200 字符` | 种植业与金融结合的营销文档多为短文本，无需过长上下文，可降低大模型调用成本 |
| `相似度阈值` | `0.65–0.75` | 种植业数据与金融产品参数字段明确，中等阈值可过滤无关匹配结果，保留有效场景与金融产品信息 |
| `RECALL_TOP_N` | `前3–5条` | 单条结合类文档信息密度较高，少量召回即可覆盖营销内容所需的种植与金融场景数据 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 批量种植台账与金融产品文档解析可能耗时较长，避免中途超时中断任务 |
| `MODEL_API_TIMEOUT` | `30 秒` | 农业与金融双术语处理需额外计算时间，合理延长超时时间避免误判调用失败 |
| `增量同步配置` | `按周触发+季度全量同步` | 种植业生产记录按周更新，金融产品参数按季更新，双周期同步可覆盖全部数据的更新节奏 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 选择千问模型提交对话任务后，界面提示`connection error`，开启代理工具后仍重复出现该提示。原因是未在FastGPT的模型渠道配置中正确填写代理服务器地址与端口，或代理规则未覆盖千问模型API的请求域名。
- 在模型提供商页面点击新增渠道，填写配置信息后提交，弹出类型错误提示`getModifierState不是一个函数`。原因是浏览器本地缓存了旧版的页面静态资源，或当前使用的浏览器版本不兼容页面的事件监听逻辑。
- 大模型调用任务显示欠费，但对应API密钥的账户后台仍有可用余额。原因是未在FastGPT的计费配置中正确绑定账户的计费模式，或系统未同步更新账户的最新余额数据。

## 怎么确认配好了
- 上传一份结合种植数据与金融产品参数的测试文档，触发模型生成营销内容，核对返回内容是否正确关联作物种植情况与金融产品信息。
- 查看模型调用日志详情，确认每次调用的超时时间符合配置的`MODEL_API_TIMEOUT`取值，未出现提前中断的情况。
- 手动触发一次按周增量同步任务，核对仅同步了最近一周的种植数据与季度内更新的金融产品参数。
- 提交一次测试调用，核对返回结果的召回条数符合配置的`RECALL_TOP_N`取值，未出现异常数量的匹配内容。
