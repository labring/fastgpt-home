# 种植业营销内容的知识库检索与召回

## 这个品类的数据长什么样
面向种植业的金融/保险/理财营销内容，数据来源包括农业技术推广站公开文档、农资厂商产品说明、金融机构面向种植户的营销物料、区域农业局种植补贴政策解读。更新节奏存在差异，政策类内容随补贴调整更新，农资参数类文档随新品发布更新，营销物料随推广周期更新。文档结构以结构化表格、长文本说明为主，包含品种名称、种植规模、保费费率、补贴额度等字段，单位涵盖亩、元/亩、百分比等专业参数。

## 这些特征在「知识库检索与召回」这一环带来什么约束
结构化表格占比高的特征要求检索系统支持结构化数据的向量生成，否则表格内的保费、补贴等专业参数无法被有效召回。字段带专属单位的特征要求检索环节需处理单位一致性，避免因单位不匹配导致召回无关内容。更新频率差异大的特征要求采用分批次增量更新策略，避免全量更新耗时过长。长文本政策说明较多的特征要求合理设置分段参数，确保召回的上下文信息完整且不冗余。场景化关键词占比高的特征要求检索模型适配农业金融专业术语，提升精准匹配度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxChunkSize` | 800–1200 字符 | 面向种植业的金融营销长文本说明较多，该分段长度可保留完整的补贴政策解读或保费方案，避免语义断裂 |
| `ENABLE_TABLE_VECTOR` | 开启 | 面向种植业的金融营销内容包含大量结构化表格，如保费测算表、补贴申领清单，开启后可生成表格内容的向量索引 |
| `RECALL_TOP_N` | 前6–8条 | 单条面向种植业的金融营销内容覆盖的场景较窄，召回过多会分散相关性，过少会遗漏适配种植户的专业需求 |
| `SIMILARITY_THRESHOLD` | 0.72–0.78 | 农业金融术语多为专业词汇，阈值过低会召回无关内容，过高会遗漏匹配度稍低的专业场景 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 900 秒 | 大型种植补贴政策手册解析耗时较长，该时长可避免常规文档解析超时失败 |
| `UPLOAD_API_BATCH_SIZE` | 10–20 条/次 | 面向种植业的金融营销内容多为批量的农资理财方案或保险产品说明，批量上传可减少接口调用次数 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用知识库导入接口时返回413状态码，无法完成种植业金融营销内容的上传。原因：未配置`UPLOAD_FILE_MAX_SIZE`参数，或上传的单篇营销文档大小超出默认限制。
- 现象：导入的保费测算表格无法被检索到，检索结果未包含表格内的费率、保额等参数。原因：未开启`ENABLE_TABLE_VECTOR`配置，未生成表格内容的向量索引。
- 现象：通过自定义API拉取飞书多维表的种植业补贴数据后，检索结果为空。原因：未将多维表的字段映射为FastGPT支持的文本向量格式，未配置正确的数据源同步触发规则。

## 怎么确认配好了
- 上传包含结构化保费表格的种植业金融营销文档，查看知识库解析日志，确认表格内容被完整识别并生成向量索引。
- 输入针对性的农业金融场景关键词，核对检索返回的结果条数，调整相似度阈值至适配专业术语的区间。
- 调用知识库导入接口上传单篇营销文档，确认接口返回成功状态，核对上传流程未触发异常限制。
- 导出知识库训练后的文本内容，确认数据格式与上传的营销物料一致，验证存储与导出流程正常。
