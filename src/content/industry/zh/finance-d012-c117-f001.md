# 纺织制造营销内容的HTTP 接口与外部系统

## 这个品类的数据长什么样
纺织制造的营销内容数据主要来源于企业内部的生产管理系统、面料库存数据库、合规检测平台及品牌营销素材库。数据更新节奏因类型不同存在差异：生产排期、实时库存数据更新频率较高，营销素材、合规报告按需上传或批量更新。单条营销内容文档包含固定业务字段：面料编号、克重、纤维成分占比、起订量、交货周期、合规检测报告编号、适配服饰品类，其中克重单位为g/㎡，起订量单位为米，交货周期单位为天，合规报告编号为字符串格式。文档通常伴随高清面料样卡图片、检测报告PDF附件，单附件体积跨度较大。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
纺织制造营销内容的专属字段与附件特征，对HTTP接口与外部系统配置提出明确约束。专属业务字段要求接口支持自定义字段映射，避免通用字段模板无法适配面料编号、克重等行业专属参数。高频更新的生产排期与库存数据，要求接口轮询间隔匹配更新节奏，避免数据滞后影响营销内容准确性。大体积的图片与检测报告附件，要求接口支持更大的文件上传与传输限制，避免传输中断。同时，不同区域经销商的专属库存数据，要求接口集成权限校验逻辑，确保数据访问合规。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `API_REQUEST_TIMEOUT` | `300 秒` | 纺织营销内容关联的检测报告、样卡图片等附件体积较大，接口拉取时需足够超时时间避免中断 |
| `PARSE_CUSTOM_FIELD_MAPPING` | `面料编号→fabric_id,克重→weight_g_per_sqm,起订量→min_order_qty` | 适配纺织制造专属业务字段，将系统通用字段映射为行业常用命名 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 纺织营销素材包含高清样卡、多页检测报告PDF，单文件体积远超通用品类 |
| `WEBHOOK_TRIGGER_INTERVAL` | `300 秒` | 匹配生产排期、库存数据的高频更新节奏，避免数据滞后 |
| `RESPONSE_INCLUDE_CITATIONS` | `开启` | 纺织营销内容需关联检测报告、库存数据作为引用依据，满足调用方获取详细信息的需求 |
| `HTTPS_CERT_PATH` | `/etc/ssl/certs/mkcert.pem` | 本地部署时使用mkcert生成的证书，指定证书文件路径完成HTTPS配置 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用接口返回`413 Request Entity Too Large`错误。原因：未调整`UPLOAD_FILE_MAX_SIZE`配置，未适配纺织营销素材的大文件体积。
- 现象：工作流发布后的链接仍为`http://localhost:3000/chat/`格式，无法外部访问。原因：未配置`SERVER_PUBLIC_URL`参数，未将部署的公网域名填入对应配置项。
- 现象：调用Ollama接入的接口返回`connection refused`错误。原因：未将`OLLAMA_API_BASE`配置为本地部署的实际IP与端口，误填为默认本地地址未修改。

## 怎么确认配好了
- 访问配置的公网域名，检查是否能正常加载FastGPT界面，验证HTTPS证书配置是否生效。
- 发起测试调用，传入纺织营销内容的测试字段，检查接口返回的字段是否与配置的`PARSE_CUSTOM_FIELD_MAPPING`规则一致。
- 上传高清面料样卡或检测报告PDF，检查文件上传是否成功，未触发`413 Request Entity Too Large`错误。
- 调用知识库问答的API接口，检查返回结果中是否包含引用的文献或检测报告编号，验证`RESPONSE_INCLUDE_CITATIONS`配置是否生效。
