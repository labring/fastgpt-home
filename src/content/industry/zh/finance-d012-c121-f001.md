# 耐火材料营销内容的HTTP 接口与外部系统

## 这个品类的数据长什么样
耐火材料的营销数据主要来源于生产管理系统、质检检测报表、销售对接记录与技术文档库。数据更新节奏分为三类：每日更新的实时质检数据，每周调整的产品报价与库存数据，按需更新的营销案例与技术手册。数据结构包含结构化字段与非结构化附件：结构化字段涵盖产品牌号、化学成分占比、体积密度、耐压强度等参数，单位多为g/cm³、MPa、供货天数；非结构化附件包含产品说明书、窑炉配套图纸等大体积文件。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
结构化的技术参数要求接口支持严格的字段类型校验，避免数值型参数被错误转换为字符串格式。多更新频率的数据源需要区分拉取周期，例如质检数据需高频拉取以保证时效性，报价数据可低频同步以降低接口压力。大体积的非结构化附件要求接口支持断点续传与大容量文件上传，同时需要配置合理的超时时间以应对大文件传输。多条件的查询需求需要支持组合参数传递，例如按应用窑型、产品牌号筛选数据，避免全量拉取导致的接口负载过高。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `知识库分块长度` | 800–1200 字符 | 耐火材料产品文档多包含长段技术参数说明，分块过长会打断参数关联逻辑，过短会丢失上下文信息 |
| `HTTP请求超时时间` | 300 秒 | 耐火材料的质检数据接口单次拉取数据量较大，需预留足够的传输与处理时间 |
| `召回相似度阈值` | 0.75–0.85 | 营销场景需匹配客户具体窑型需求，阈值过低会引入无关参数，过高会遗漏精准匹配的技术方案 |
| `外部API鉴权头` | 填入第三方接口的`Authorization`字段值 | 符合多数第三方API的鉴权规范，适配第三方接口的鉴权要求 |
| `文件上传最大尺寸` | 2000 MB | 耐火材料的产品手册、窑炉配套图纸多为大体积PDF或CAD文件，需支持大容量上传 |
| `工作流动态知识库绑定` | 开启 | 营销场景需根据客户输入动态切换知识库，动态绑定可适配不同业务场景 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置第三方API接口时，测试通过但在正式调用时返回`401 Unauthorized`错误。原因：未将鉴权参数正确填入`外部API鉴权头`配置项，或密钥未同步更新。
- 现象：工作流中配置【知识库搜索】节点时，无法通过API传入的变量绑定目标知识库。原因：未开启工作流的动态知识库绑定权限，或变量未映射为合法的知识库ID格式。
- 现象：调用质检数据接口后返回空结果，且无明确报错提示。原因：未根据耐火材料数据的更新频率调整接口拉取周期，请求时数据源尚未完成当日更新。

## 怎么确认配好了
- 发起一次模拟API调用，传入耐火材料典型的产品牌号与应用窑型参数，检查返回结果是否包含匹配的产品参数与营销内容。
- 查看FastGPT的工作流执行日志，确认【知识库搜索】节点正确解析传入的变量，无变量绑定失败的提示信息。
- 检查外部接口的调用记录，确认请求频率符合配置的分级限制，未触发外部系统的限流拦截。
- 上传一份耐火材料的产品手册PDF，确认文件上传成功且分块处理后的内容可被正常召回。
