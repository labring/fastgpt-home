# 耐火材料营销内容的工作流编排

## 这个品类的数据长什么样
面向金融行业的耐火材料营销内容数据来源包括企业内部产品手册、行业标准规范文档、客户询价沟通记录与供应商原料参数文件。数据更新节奏随业务场景调整：原料参数随原料行情每季度调整，新品营销物料随推广计划不定期更新。文档结构包含长文本产品说明、结构化参数表与零散的客户咨询文本，核心字段包括化学成分占比、使用温度范围、抗压强度，单位多为百分比、摄氏度、兆帕。

## 这些特征在「工作流编排」这一环带来什么约束
面向金融行业的耐火材料营销内容，其数据特征对工作流编排带来以下约束：长文本产品说明与结构化参数表并存的特征，要求工作流需同时支持长上下文解析与结构化字段抽取。专业术语密集的文档内容，要求文本提取节点需适配耐火材料专属参数名，避免通用解析逻辑遗漏金融客户关注的核心营销卖点。更新频率不固定的营销物料，要求工作流触发模式需支持按需拉取与增量同步，避免固定定时任务导致数据过时影响获客效果。多源数据整合的需求，要求工作流需串联网盘、CRM、行业网站等多个数据节点，确保营销内容的数据源覆盖全面。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 耐火材料产品文档多为数千字的PDF或Word，常规超时时间不足以完成完整解析 |
| `text_extract_chunk_size` | `800–1200 字符` | 耐火材料专业术语密集，分段过长会导致大模型拆分关键参数组，过短会破坏术语连贯性 |
| `rag_top_k` | `前 3–5 条` | 营销内容需精准匹配客户选型咨询，过多召回会引入与当前需求无关的冗余参数 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 耐火材料的质检报告、批量产品手册多为中大型文件，需适配单文件上传上限 |
| `workflow_trigger_mode` | `按需触发+定时增量同步` | 营销物料更新不定期，同时需定期同步最新的原料行情与产品参数 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 文本提取节点返回空字段或乱码，仅部分大模型可正常解析耐火材料参数。原因：未配置`text_extract_prompt`的专业术语适配规则，导致通用大模型无法识别耐火材料专属参数名。
- 工作流调用上传的产品手册时提示文件不存在。原因：未确认`UPLOAD_FILE_STORAGE_PATH`的默认存放目录，直接使用相对路径调用文件。
- 工作流执行超时，状态码返回`504 Gateway Timeout`。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`的取值，使用默认值导致长文档解析超时。

## 怎么确认配好了
- 上传一份标准耐火材料产品手册，运行工作流后核对提取的字段是否与文档内的参数一致，调整`field_mapping_rule`直到匹配度符合业务要求。
- 触发一次按需执行的工作流，查看日志中文件解析的耗时，确认`PARSE_FILE_TIMEOUT_SECONDS`的取值大于实际解析耗时。
- 测试不同大模型调用文本提取节点，确认所有目标大模型均可正常提取专业参数，调整`text_extract_prompt`适配不同模型的上下文理解能力。
- 检查工作流的触发日志，确认按需触发与定时增量同步均正常执行，未出现文件调用失败的报错。
