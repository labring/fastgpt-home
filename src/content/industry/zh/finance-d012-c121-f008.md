# 耐火材料营销内容的工具调用与插件

## 这个品类的数据长什么样
耐火材料的数据来源包括全国耐火材料标准化技术委员会发布的标准文件、生产厂商的出厂检验报告、工业窑炉运行的实时采集数据。更新节奏分为三类：标准文件每年度修订，出厂报告随每批次产品更新，实时监测数据每数秒更新。文档结构包含产品标识、核心性能参数、适配工况说明、合规认证标识四类字段，字段单位包括兆帕、摄氏度、立方米每小时等，单份完整文档长度跨度较大。

## 这些特征在「工具调用与插件」这一环带来什么约束
耐火材料数据的多批次动态更新特性，要求工具调用必须支持按批次标识拉取最新质检数据，避免使用静态缓存导致的参数偏差。实时工况监测数据的高频更新，要求插件的定时触发间隔匹配数秒级的更新节奏，确保获取的信息时效性。专业性能参数与特定单位的绑定，要求插件的解析规则预设耐火材料专属字段映射，避免通用解析出现单位混淆或参数错位。长文本的产品说明书与标准文件，要求工具调用的上下文处理上限适配万字符级的文本长度，保障完整信息摄入。合规认证标识作为营销核心卖点，要求插件的检索规则优先关联该字段，提升内容精准度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `pluginRequestTimeout` | `300 秒` | 耐火材料长文档解析与批量数据拉取需要足够时长，默认超时时长无法覆盖完整流程 |
| `maxPluginContextLength` | `8000–12000 字符` | 适配单份耐火材料产品说明书或标准文档的长度区间，保障完整信息摄入 |
| `pluginBatchPullInterval` | `5 秒` | 匹配实时工况监测数据的数秒级更新节奏，确保获取信息的时效性 |
| `pluginFieldMappingRule` | 预设耐火材料专属字段映射 | 耐火材料存在专属性能参数与单位，需与通用字段做差异化绑定避免解析错误 |
| `pluginRecallPriority` | 合规认证字段权重提升 | 合规认证是耐火材料营销内容的核心卖点，需优先关联该字段提升内容精准度 |
| `pluginParseMode` | 专业文档解析模式 | 适配耐火材料文档中的行业专属术语与单位，提升解析准确率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：添加Doc2X系统插件后触发调用返回`504 Gateway Timeout`错误。原因：未调整`pluginRequestTimeout`参数适配耐火材料长文档的解析时长，默认超时时长不足以完成完整解析。
- 现象：在工作流中引用插件后执行代码节点，触发参数识别失败报错。原因：未配置`pluginFieldMappingRule`，导致插件返回的耐火材料专属字段无法被代码节点正确映射识别。
- 现象：使用搜索插件检索后仅返回简易摘要，无法读取完整网页内容。原因：未启用插件的网页全文抓取配置，仅调用了摘要检索接口，未适配耐火材料营销内容需要完整文档支撑的需求。

## 怎么确认配好了
- 进入插件管理页面，核对当前部署的开源版版本为v4.8.15-fix-emb-page及以上，确保插件功能兼容性。
- 发起一次批量拉取耐火材料批次数据的测试调用，确认返回字段与预设的`pluginFieldMappingRule`完全匹配。
- 触发搜索插件检索耐火材料相关内容，确认返回结果包含完整网页链接并支持全文抓取配置。
- 查看插件调用日志，确认无字段解析错误或超时报错，匹配配置后的预期运行状态。
