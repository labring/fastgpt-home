# 耐火材料营销内容的文档解析与分块

## 这个品类的数据长什么样
面向金融领域的耐火材料相关营销文档，主要来源于为金融客户定制的耐火材料配套方案手册、第三方检测报告、行业标准文件及营销推广物料。文档更新随产品配方迭代、行业标准修订及针对金融场景的营销物料更新同步调整，无固定周期。文档多包含产品牌号、化学成分占比、物理性能参数、适配金融场景窑炉的应用说明、检测数据表格及合规标注。常见字段与单位包括耐压强度（MPa）、荷重软化温度（℃）、体积密度（g/cm³）、执行标准编号等，部分文档会附带金融数据中心窑炉适配案例的详细参数。

## 这些特征在「文档解析与分块」这一环带来什么约束
面向金融领域的耐火材料营销文档包含大量绑定单位的物理参数表格、长段专业说明及跨页的产品对比内容，部分文档还包含金融合规相关的标注内容。参数与单位强绑定，拆分后会丢失参数含义，因此解析时需保留表格结构与参数组的完整性。长段落多涉及窑炉适配场景的连续说明，若拆分不当会破坏场景逻辑。部分文档跨页展示同一产品的完整检测数据，需避免跨页分块导致的信息割裂。同时，营销物料中的产品牌号与对应参数需保持上下文关联，防止分块后出现参数与牌号不匹配的问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `2048 MB` | 耐火材料文档常包含高清检测图像与长文本，需支持较大文件上传，避免因文件超限报错 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 长文档及含复杂表格的解析需更长处理时间，防止中途超时中断 |
| `chunk_size` | `800–1200 字符` | 适配耐火材料参数组与场景说明的长度，避免拆分参数与场景关联 |
| `chunk_overlap` | `100–150 字符` | 保留相邻分块的参数上下文，防止专业参数组被拆分断裂 |
| `enable_table_parse` | `开启` | 保留文档中化学成分、性能参数表格的结构，避免表格内容被无序拆分 |
| `custom_separator` | `["\n\n", "### ", "#### "]` | 匹配耐火材料文档的章节标题与段落分隔，符合文档原生结构 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传3MB的耐火材料营销PDF时弹出文件超限报错。原因：未调整`UPLOAD_FILE_MAX_SIZE`配置项，使用的默认阈值小于上传文件大小。
- 现象：设置自定义分隔符后，分块结果要么合并多个产品参数段落，要么将单组性能参数拆分为多个独立块。原因：未匹配耐火材料文档的章节层级与参数组分隔规则，且分段长度未适配参数组的平均长度。
- 现象：解析后的分块内容中，化学成分参数与对应单位完全分离。原因：未开启表格解析功能，导致文档中的参数表格被拆分为零散文本，丢失参数与单位的绑定关系。

## 怎么确认配好了
- 上传单份典型耐火材料文档，查看上传状态与解析日志，确认文件未因超限被拦截。
- 查看解析后的分块预览，检查参数表格的结构是否完整，参数与单位是否绑定在一起。
- 调整`chunk_size`与`custom_separator`配置后，对比不同设置下的分块结果，确认段落与参数组未被异常拆分或合并。
- 测试长文档的解析耗时，确认未出现超时中断的情况，可对应调整`PARSE_FILE_TIMEOUT_SECONDS`配置。
