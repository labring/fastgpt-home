# 耐火材料营销内容的表单与交互

## 这个品类的数据长什么样
耐火材料相关数据主要来源于企业内部生产台账、第三方检测机构报告、行业标准文档及客户采购需求文档。生产批次数据随每一批次的生产完成实时更新，行业标准文档按行业标准更新周期定期更新，产品理化参数随工艺调整不定期更新。数据文档多为结构化的PDF质检报告、Excel批次数据表或标准化技术说明书，核心字段包含耐火度、体积密度、耐压强度、使用温度范围等，字段均附带专业物理单位。

## 这些特征在「表单与交互」这一环带来什么约束
耐火材料的专业理化参数需明确单位，因此表单需支持带单位的字段输入，避免客户混淆指标含义；批次数据随生产动态更新，表单需支持关联最新的批次参数，无法使用静态默认值；附件多为质检报告、CAD图纸、技术协议等较大文件，因此表单需支持大容量附件上传；客户需求分为标准现货和定制开发两类，需区分字段组简化填写流程，避免冗余字段干扰客户填写。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 耐火材料相关的质检报告、CAD图纸、技术协议等附件通常不超过该大小 |
| `form_field_unit_suffix` | `自动追加专业单位（℃/MPa/g/cm³）` | 耐火材料参数需明确单位，避免客户输入时混淆指标含义 |
| `form_batch_auto_sync` | `按生产批次同步最新参数` | 耐火材料批次理化参数随生产动态更新，需获取最新数据匹配客户需求 |
| `form_field_group_switch` | `按标准产品/定制开发分组` | 客户需求分为标准现货和定制开发两类，分组后可简化表单填写流程 |
| `form_enable_captcha` | `开启` | 避免垃圾表单提交，提升有效销售线索的质量 |
| `form_submit_notify` | `推送到内部销售工单系统` | 营销团队需及时接收表单提交的线索，提升响应效率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：表单提交后无内部通知，销售团队未收到线索。原因：未配置`form_submit_notify`参数，或通知渠道设置错误。
- 现象：对话中无法显示表单交互内容，输入字段未加载。原因：未配置工作流中的`form_enable_display`参数，或表单字段配置与对话流程节点不匹配。
- 现象：表单附件上传失败，提示文件过大。原因：`UPLOAD_FILE_MAX_SIZE`参数设置过小，未匹配耐火材料相关附件的实际大小。

## 怎么确认配好了
- 填写测试表单，上传符合耐火材料参数的附件，核对附件是否成功上传并显示在后台。
- 触发表单提交，核对内部通知渠道是否收到测试提交的线索信息。
- 查看表单字段，确认专业单位已自动追加到对应参数字段后。
- 切换标准产品和定制产品的分组选项，核对表单字段是否按分组正确显示。
