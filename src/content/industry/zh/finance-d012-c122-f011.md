# 股份制银行营销内容的文档解析与分块

## 这个品类的数据长什么样
股份制银行的营销内容数据主要来源于内部营销团队产出的官方物料，包括结构化的Excel客群清单、预算分配表，非结构化的PDF活动方案、海报文案、电话话术脚本等。数据更新节奏随营销节点变动，新品上线、季度营销活动启动时更新频率较高，日常更新频次较低。文档结构混合长文本段落、多页PDF、嵌套表格与短话术片段，字段包含活动ID、投放渠道、客群标签、预算额度（单位为万元）、生效日期等明确的业务标识与单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
混合结构化与非结构化的文档类型，要求解析流程同时支持纯文本提取与表格结构还原，避免丢失业务数据的关联关系；高频更新的营销物料要求解析流程轻量化，避免过长的等待时间影响运营效率；带有明确单位与业务字段的内容，要求分块时保留字段与对应内容的绑定，避免拆分后语义断裂；多页长文档的解析需要适配复杂排版，确保分块后的上下文连贯性符合业务查询需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 股份制银行营销物料常包含多页PDF或复杂嵌套Excel，该取值可覆盖多数文档的解析时长需求，避免中途超时中断 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 适配季度营销方案合集、多渠道投放清单等批量文档的上传需求，避免因文件过大被拦截 |
| `分段长度` | `800–1200 字符` | 营销内容包含话术片段与业务数据，该区间可平衡语义完整性与检索精度，避免过长导致上下文丢失或过短破坏业务关联 |
| `enable_table_parse` | `开启` | 营销物料常包含Excel格式的客群分层表、预算清单，开启后可保留表格结构与单元格对应关系 |
| `metadata_extract_mode` | `强制绑定字段` | 营销文档包含活动ID、预算单位等特定业务字段，该模式可保留元数据与对应文本的绑定关系 |
| `retry_parse_times` | `3 次` | 部分复杂文档解析可能偶发异常，重试可提升解析成功率，避免单次解析失败影响运营流程 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为上传Excel格式的客群清单后，解析结果仅提取纯文本，表格列名与单元格内容错位丢失。原因是未开启`enable_table_parse`配置，默认解析逻辑未针对结构化表格做适配。
- 现象为上传营销文档后，解析时长超过5分钟后返回`504 Gateway Timeout`，重启服务器后问题未解决。原因是`PARSE_FILE_TIMEOUT_SECONDS`配置取值低于文档实际解析所需时长，且未同步调整服务器网关超时阈值。
- 现象为分块后的内容中，营销话术与对应的活动ID字段分离，无法通过检索关联到对应业务信息。原因是未设置`metadata_extract_mode`为绑定模式，拆分时未保留元数据与文本的关联。

## 怎么确认配好了
- 上传测试用的Excel营销物料，核对解析结果中的表格列名与单元格内容是否完整，确认表格解析配置生效。
- 上传单页PDF格式的营销方案文档，查看解析耗时记录，确认`PARSE_FILE_TIMEOUT_SECONDS`取值大于实际解析时长。
- 查看分块后的文档片段，核对活动ID、预算数值等字段是否与对应文本内容绑定，确认元数据绑定配置正确。
- 上传批量营销文档合集，确认上传与解析流程未触发文件大小限制。
