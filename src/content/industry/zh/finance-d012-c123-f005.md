# 能源金属营销内容的多轮对话与提示词

## 这个品类的数据长什么样
能源金属相关数据来自大宗商品行情服务平台、行业协会公开报告、上游生产企业公开披露的生产销售信息。更新节奏分为多档：现货交易价格每日更新，周度库存、月度产量数据按周/月更新，季度行业供需报告按季度发布。单条数据文档包含品种名称、产地规格、当日现货报价、周度均价、月度累计产出量、社会库存总量等字段，单位统一为元/吨、吨或万吨，每条数据附带数据采集时间戳。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
能源金属数据的多档更新节奏要求多轮对话需明确用户所需数据的时间维度，避免调用过时信息。字段包含多类规格与统计维度，提示词需引导用户逐步明确品种、产地规格、统计周期等参数，否则易出现报价与需求不匹配的问题。单条数据附带的单位信息需在对话中明确校验，防止混淆元/吨与万元/吨等单位差异。同时，高频更新的现货价格数据会占用较多上下文空间，需限制上下文窗口的历史数据留存长度，避免冗余信息干扰当前查询。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `6000–10000 token` | 能源金属单条行情数据占用约200-300 token，保留最近5轮对话上下文即可覆盖连续查询需求，避免冗余旧数据干扰 |
| `systemPrompt` | 需明确询问用户所需能源金属的品种、规格、统计周期及单位需求，未明确时补充提问 | 能源金属字段多且规格差异显著，引导用户补充关键参数可避免返回错误信息 |
| `toolCallTimeout` | `30 秒` | 大宗商品数据源接口响应通常在10-20秒，设置30秒超时可覆盖网络波动场景，避免对话超时中断 |
| `maxToolCalls` | `2–3 次` | 能源金属的常规查询仅需1-2次工具调用获取行情与库存数据，过多调用会增加用户等待时长 |
| `responseFormat` | 固定字段模板，包含品种、规格、报价、统计周期、单位 | 标准化返回格式可让用户快速获取关键信息，避免格式混乱 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：AI对话响应超时，界面显示「请求超时」状态码。原因：未设置合理的`toolCallTimeout`参数，或调用大宗商品数据源时未优化接口请求逻辑，导致等待时间超出预期。
- 现象：调用图表工具生成能源金属价格走势图表后，界面显示空白。原因：未在提示词中明确要求图表工具调用时携带完整的时间范围与品种参数，导致工具调用时缺失必要的数据源过滤条件，无法生成有效图表。
- 现象：AI对话节点返回空内容或「工具调用失败」报错文案。原因：未在系统提示词中添加异常处理逻辑，当数据源接口返回空数据时，未引导用户更换查询条件或补充信息，直接返回空结果。

## 怎么确认配好了
- 发起包含多维度参数的查询，核对系统是否会主动补充询问未明确的信息，确认提示词配置生效。
- 发起连续多轮相关查询，核对上下文是否保留了之前提及的品种、规格等关键参数，未出现参数混淆。
- 触发工具调用场景，核对响应时长是否符合业务需求，确认超时配置合理。
- 模拟数据源返回空数据的场景，核对系统是否会返回明确的引导提示，不会返回空内容或未处理的报错。
