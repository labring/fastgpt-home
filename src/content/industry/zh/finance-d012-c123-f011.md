# 能源金属营销内容的文档解析与分块

## 这个品类的数据长什么样
能源金属相关数据主要来自行业协会月度/季度报告、上市公司年度年报、现货交易平台日报、海关进出口统计文档。数据更新节奏覆盖每日（现货报价）、季度（行业供需分析）、年度（产业规划）三类。文档形态包含结构化Excel报价表（含品名、品位、产地、计价单位等字段）、PDF格式研报（含图表、嵌套表格与专业术语）、数据库导出的结构化交易记录。计价单位包含元/吨、美元/磅等细分规格，部分文档会标注交割等级与质检标准。

## 这些特征在「文档解析与分块」这一环带来什么约束
多源异构的文档形态要求解析模块适配不同格式的内容提取规则，避免结构化表格的表头嵌套、PDF图表的文本偏移问题。不同更新频率的文档对应不同的分块逻辑：高频现货数据需保持单块内容紧凑，避免跨块的价格对比逻辑断裂；低频研报需按章节划分分块，保留完整的产业分析上下文。此外，能源金属特有的专业术语与多单位体系，要求分块时需保留术语完整性，避免拆分如“电池级碳酸锂99.5%品位”这类组合表述，同时需兼容单位转换的前置处理空间。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_EXCEL_ENABLE_TABLE` | 开启 | 能源金属文档包含大量结构化报价表格，开启后可完整提取单元格字段与格式 |
| `CHUNK_SIZE` | 800–1200 字符 | 能源金属研报包含专业术语与长句，该区间可保留术语完整性，避免拆分专业表述 |
| `CHUNK_OVERLAP_RATE` | 10–15% | 长文档分块后需保留上下文关联，避免跨块的专业逻辑断裂 |
| `PARSE_FILE_MAX_SIZE` | 500 MB | 单份能源金属行业研报或批量报价表文件通常不超过该阈值，避免解析超时 |
| `ENABLE_DOC_SPLIT_BY_HEADING` | 开启 | 能源金属文档按章节划分（如现货市场、供需分析），按标题分块可保留逻辑单元完整性 |
| `PARSE_TABLE_EXTRACT_MODE` | 合并单元格解析 | 能源金属报价表常存在合并表头，该模式可完整提取关联字段 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 批量上传多份能源金属PDF研报后，提取结果仅汇总单份文档内容，未按文件逐一拆分。未开启`SPLIT_DOC_BY_UPLOAD_FILE`参数，系统默认将所有上传文档合并解析。
- 上传能源金属Excel报价表后，部分字段（如品位等级）为空或格式错乱。未开启`PARSE_EXCEL_ENABLE_TABLE`参数，或未配置`PARSE_TABLE_EXTRACT_MODE`为合并单元格解析，导致嵌套表头无法正确识别。
- 上传锂矿供需研报后，问答时出现专业术语混淆或上下文缺失。`CHUNK_SIZE`设置过小，且未开启`ENABLE_DOC_SPLIT_BY_HEADING`，导致逻辑单元被强制拆分，丢失完整的产业分析逻辑。

## 怎么确认配好了
- 上传单份能源金属Excel报价表，查看解析后的表格字段是否完整覆盖原文档的品名、规格、价格、单位等列，确认配置项生效。
- 上传单份长PDF行业研报，检查分块结果是否按章节标题划分，确认逻辑单元未被强制拆分。
- 批量上传多份能源金属文档，查看任务列表中是否按单个文件生成独立解析条目，确认批量分块配置正确。
- 提取单份文档的分块内容，检查专业术语与计价单位是否完整保留，确认分块参数配置符合品类需求。
