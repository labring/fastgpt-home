# 能源金属营销内容的模型接入与配置

## 这个品类的数据长什么样
能源金属相关数据多来自国内国际大宗商品交易所、行业协会及供应链企业公开披露。现货报价数据每日收盘后更新，行业库存、产量调研数据月度更新，政策文件不定期发布。文档多为结构化表格搭配简短分析，字段包含品种名称、规格型号、报价区间、成交总量、统计周期、发布单位，单位多为元/吨、吨、千克，部分进口相关数据会附带美元计价字段。

## 这些特征在「模型接入与配置」这一环带来什么约束
能源金属数据的结构化特征要求接入时启用结构化解析模式，避免非通用拆分导致的字段错位。不同数据源的更新节奏差异，需要配置差异化的知识库刷新规则，避免数据过时或冗余更新。多样的计价单位要求在配置中预设统一转换逻辑，防止模型混淆不同单位的计算结果。短文本为主的文档结构，需要适配小上下文窗口的召回策略，避免引入无关的长文本干扰。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_STRUCTURED_TABLE` | 开启 | 适配能源金属数据的结构化表格格式，避免拆分错误 |
| `RECALL_TOP_N` | 3-5条 | 能源金属单篇文档内容较短，过多召回会引入无关数据 |
| `SIMILARITY_THRESHOLD` | 0.75-0.85 | 过滤低匹配度的非相关品种数据，避免混淆不同金属品类 |
| `KNOWLEDGE_REFRESH_CRON` | 0 0 * * *（现货数据）、0 0 1 * *（行业数据） | 匹配不同数据源的更新节奏 |
| `API_REQUEST_TIMEOUT` | 600秒 | 适配行业数据接口的响应延迟，避免超时中断 |
| `maxContext` | 8000-12000字符 | 适配短文本拼接后的总上下文长度，避免超出模型限额 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置模型URL和密钥后，测试返回401 Unauthorized报错。原因：未正确配置模型服务商的密钥权限，或URL指向了非官方接口地址。
- 现象：通过API调用时返回Connection error。原因：未开放FastGPT所在服务器的出站端口权限，或模型接口存在访问限制。
- 现象：模型仅返回单条匹配文本块，未综合多个结果。原因：`RECALL_TOP_N`参数被设置为1，或相似度阈值设置过高，过滤了所有低匹配度但相关的结果。

## 怎么确认配好了
- 进入模型调试界面，输入包含锂、钴等能源金属的查询，核对返回结果是否包含多来源的结构化数据片段。
- 查看知识库管理页的刷新记录，确认现货数据每日、行业数据每月按计划完成更新。
- 调用配置好的API接口，检查响应状态码是否为200，且返回内容包含多条匹配的文档片段。
- 修改`SIMILARITY_THRESHOLD`参数，验证召回的文本块数量是否随阈值调整发生符合预期的变化。
