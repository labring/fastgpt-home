# 自动化设备营销内容的文档解析与分块

## 这个品类的数据长什么样
金融领域自动化设备的营销文档主要来自官方设备手册、选型参数表、行业应用案例集及营销推广物料。数据更新节奏随新机型发布、合规标准调整或核心参数变更触发，无固定周期。文档多为结构化表格与段落结合的形式，包含设备型号、额定功率、运行尺寸、承重范围、认证标识等字段，字段单位多为国际标准单位，如千瓦（kW）、转每分钟（rpm）、千克（kg），部分文档包含金融场景适配说明。

## 这些特征在「文档解析与分块」这一环带来什么约束
金融领域自动化设备的营销文档包含结构化技术参数与金融场景适配说明，解析时需保留表格行列结构，避免参数拆分混乱。文档存在大量带明确单位的技术字段，分块需保证同类型参数组不被跨块截断，确保检索时参数信息完整。部分文档包含长段落金融场景应用描述，需匹配段落边界进行分块，避免割裂场景逻辑。同时文档更新无固定周期，需支持增量解析与分块，适配新物料快速入库以支撑获客营销活动。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | `800–1200 字符` | 金融自动化设备文档包含技术参数与场景描述，该区间可平衡参数完整性与检索密度。 |
| `分段重叠率` | `10%–15%` | 技术参数段落边界明确，重叠率可避免跨块参数丢失，同时降低重复检索开销。 |
| `PARSE_TABLE_MODE` | `保留完整表格块` | 金融自动化设备文档的技术参数多以表格呈现，完整表格块可保证参数组检索的完整性，适配金融客户对设备性能的查询需求。 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单份金融自动化设备选型手册或案例集文件通常不超过该大小，避免上传超时。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 大型多页设备手册解析需较长时间，该时长可覆盖多数文档解析需求。 |
| `增量解析开关` | `开启` | 金融自动化设备文档更新无固定周期，增量解析可减少重复解析开销，适配快速上线营销物料的需求。 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：同一份CSV格式的金融自动化设备选型表在版本升级后无法正常分块，日志返回解析失败。原因：版本更新后CSV解析的字段映射规则调整，原有文档的非标准列名未被兼容。
- 现象：知识库文档分块数量超出阈值时触发内存溢出报错，无法完成索引。原因：未调整默认分块上限，未适配金融自动化设备文档长选型表的拆分需求。
- 现象：线上环境解析文档时返回Cannot redefine property: toString错误。原因：文档中存在与内置原型方法重名的自定义字段，解析时触发属性重定义冲突。

## 怎么确认配好了
- 上传一份典型的金融自动化设备选型手册文档，查看解析后的文本结构，确认表格内容未被拆分为零散段落。
- 执行分块测试，观察分块结果，调整对应配置项，确保分块逻辑匹配文档的参数与场景结构。
- 触发增量解析任务，验证新增的金融自动化设备营销物料可被正常解析并完成分块。
- 运行模拟解析任务，排查并修复属性重定义、超时等异常报错。
