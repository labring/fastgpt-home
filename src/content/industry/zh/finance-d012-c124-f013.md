# 自动化设备营销内容的知识库检索与召回

## 这个品类的数据长什么样
自动化设备营销相关数据主要来自金融场景下的智能理财终端、ATM机等设备的选型手册、技术参数表、应用案例文档、营销推广物料及售后维护指南。更新节奏：新品上线、固件升级或金融营销活动调整时不定期更新。文档结构：包含设备型号、额定功率、安装尺寸、金融合规认证等结构化字段，搭配长文本的银行网点/厅堂应用场景说明，部分物料为扫描版PDF格式。字段单位多包含工业标准单位，如kW、mm、V等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
金融场景下的自动化设备数据兼具结构化参数与非结构化文本，且存在扫描版文档，要求检索系统同时支持结构化字段精准匹配与非文本内容召回。更新节奏不固定，需支持增量同步配置，避免全量重新索引带来的资源消耗，适配金融机构灵活的营销物料更新需求。文档长度差异大，从单页参数表到数十页应用案例，需自适应分段逻辑，避免破坏参数关联或丢失上下文。带单位的技术参数需保留单位信息进行匹配，否则易出现型号混淆或参数匹配偏差，影响金融客户的选型决策。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `PARSE_OCR_ENABLE` | 开启 | 金融场景的自动化设备营销文档常包含扫描版PDF产品手册，需OCR提取文本内容 |
| `RECALL_TOP_K` | 前10-15条 | 自动化设备选型参数较多，需覆盖足够候选结果以匹配精准型号与金融场景应用需求 |
| `SEGMENT_MAX_LENGTH` | 800-1200字符 | 技术参数文档段落较长，分段过长会丢失上下文关联，过短会破坏参数组的完整性 |
| `STRUCTURED_FIELD_WEIGHT` | 型号字段权重设为2.0，参数字段设为1.5 | 金融客户检索自动化设备时优先关注型号与核心技术参数，需提升对应字段的检索优先级 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 单份设备选型手册常包含多页技术参数与应用案例，需允许较大文件上传 |
| `SEARCH_SIMILARITY_THRESHOLD` | 0.75-0.85 | 需过滤低匹配度的无关设备文档，保留精准匹配的选型与营销内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：知识库搜索返回`invalid configuration parameter name "hnsw.max_scan_tuple"`报错。原因：向量库索引配置参数名拼写错误，或未在系统中启用对应参数的支持版本。
- 现象：批量检索多份自动化设备文档时响应超时。原因：未限制召回条数，或未启用向量库的近似最近邻搜索加速，导致全量遍历文档库。
- 现象：扫描版设备选型手册上传后检索无匹配结果。原因：未开启OCR解析配置，或OCR识别精度不足导致文本提取失败。

## 怎么确认配好了
- 上传一份扫描版自动化设备手册，检查解析后是否提取出设备型号与技术参数文本。
- 发起单条设备选型关键词检索，核对返回结果的条数与匹配度是否符合预期配置。
- 查看系统日志与向量库索引状态，确认`hnsw.max_scan_tuple`等参数已正确配置且无语法错误。
- 发起多条关联设备选型的批量检索，验证系统是否能按配置返回对应批次的召回结果。
