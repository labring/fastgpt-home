# 航天装备营销内容的表单与交互

## 这个品类的数据长什么样
航天装备营销相关的数据主要来源于研发设计文档、定型试验报告、批量生产清单及运维工况记录。数据更新节奏与型号迭代、年度工况汇总同步，通常为季度或年度更新，单次更新内容覆盖单型号的全生命周期参数。文档多为结构化手册，包含总体参数、动力系统、载荷配置、试验验证、交付周期等固定章节。字段包含型号编号、定型时间、最大起飞重量、有效载荷、续航时长等，单位多为千克、吨、小时、米等物理量单位。

## 这些特征在「表单与交互」这一环带来什么约束
航天装备数据的结构化多字段与专业单位要求，要求表单需预设专业字段的单位选项，避免非专业输入错误。文档篇幅较长且存在大尺寸试验报告，要求表单支持大文件上传并配置合理的分片上传规则。型号迭代带来的参数更新，要求表单的选型联动功能可实时关联最新参数库，避免展示过时信息。同时，部分涉密场景下的表单需限制敏感字段的可见范围，仅对授权用户开放对应输入项，防止涉密信息泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 航天装备的试验报告、设计手册单文件尺寸通常较大，需适配长文档上传需求 |
| `PARSE_FILE_CHUNK_SIZE` | `1000–1500 字符` | 航天装备文档结构清晰，该分段长度可保留章节语义完整性，便于后续检索 |
| `UPLOAD_FILE_TIMEOUT_SECONDS` | `600 秒` | 大尺寸文档上传解析耗时较长，需预留足够的处理时间 |
| `FORM_FIELD_PRESET_UNITS` | 预设千克、吨、小时、米等物理单位选项 | 航天装备参数多带有标准物理单位，可减少输入错误 |
| `FORM_FIELD_LINKAGE_TRIGGER` | 按选型字段变更触发 | 型号选型会关联对应参数，实时联动可保证表单数据准确性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为表单的单选、多选选项无法通过外部参数动态生成，仅显示固定默认选项。原因是未正确配置表单字段的动态参数绑定规则，未将选型参数与预设的航天装备型号库关联。
- 现象为上传的航天装备试验报告解析后出现内容截断或语义断裂。原因是分段长度配置不合理，过长导致章节语义被拆分，过短导致检索精度下降。
- 现象为表单提交后返回413请求实体过大或504网关超时错误。原因是未调整对应上传配置参数，大尺寸文档上传解析超出默认限制。

## 怎么确认配好了
- 上传一份符合航天装备文档格式的测试文件，检查上传进度与解析结果是否正常，根据解析完整性调整分段长度配置。
- 配置表单的动态选型字段，选择不同的航天装备型号，验证关联的参数选项是否同步更新。
- 提交包含大尺寸附件的测试表单，检查接口响应时长，根据实际耗时调整超时参数。
- 查看表单的字段单位预设，确认专业参数的单位选项是否覆盖常用的航天装备参数类型。
