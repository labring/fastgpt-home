# 航空机场营销内容的文档解析与分块

## 这个品类的数据长什么样
航空机场的营销内容文档主要来源于机场营销部内部方案、官方宣传物料包、会员体系运营文档。更新节奏随航季变更全量更新，节假日、换季营销活动前会新增临时文档，日常运营文档每周同步更新。文档结构包含活动主题、执行时段、覆盖航站楼、触达客群、投放渠道、预算明细等字段，配套包含海报文案、短信模板、电子屏宣传语等附属内容，字段单位包含小时、人次、万元等。

## 这些特征在「文档解析与分块」这一环带来什么约束
航空机场营销文档的航季更新、多字段绑定、多渠道配套内容特征，对解析分块带来多重约束。需区分历史航季与当前有效文档，避免召回过时内容；需保留投放时段、覆盖航站楼等精准字段的绑定关系，不能拆分跨航站楼、跨时段的关联活动内容；需完整保留文档内的表格结构，防止预算、投放渠道明细丢失；需将附属文案与主活动绑定，避免拆分后出现文案与活动不匹配的情况。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxChunkSize` | 800–1200 字符 | 航空机场营销文档包含多字段绑定内容，该区间可保留单活动的完整投放信息与配套文案 |
| `chunkOverlap` | 150–200 字符 | 避免拆分跨航季、跨渠道的关联内容，保留上下文连贯性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 部分营销文档包含多格式嵌入素材，如航班时刻表表格、海报链接，需足够解析时间 |
| `UPLOAD_FILE_MAX_SIZE` | 20 MB | 机场营销文档常包含批量海报素材包，支持更大文件上传 |
| `recall_similarity_threshold` | 0.75 | 过滤低匹配度的过时航季文档，确保召回当前有效营销内容 |
| `enable_table_parse` | 开启 | 保留文档内预算、投放渠道的表格结构，避免解析后信息丢失 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：marker-pdf调用返回请求错误，或本地docker部署v4.8.14版本时解析文档提示连接失败。原因：未正确配置本地解析服务的端口映射，导致FastGPT无法连通marker-pdf容器。
- 现象：解析后的分块混入跨航季的过时营销内容，或召回结果与当前活动无关。原因：相似度阈值设置过低，未过滤历史航季的文档，或未为分块添加航季时间元数据标签。
- 现象：解析后的文档拆分后丢失预算表格或投放渠道的关联信息。原因：未开启表格解析开关，或分段长度设置不当，将表格内容拆分到不同分块中。

## 怎么确认配好了
- 上传一份当前航季的机场营销文档，检查解析后的分块是否保留了活动主题、执行时段、覆盖航站楼的完整信息。
- 查看解析服务的日志，确认无marker-pdf连接错误或超时报错，核对上传文件大小符合配置的限制。
- 测试召回功能，输入与文档内客群、活动相关的查询，确认返回的分块包含原文档的原文答复，无无关内容混入。
- 检查分块的重叠度设置，确认相邻分块包含部分重复的上下文内容，避免关键信息被拆分丢失。
