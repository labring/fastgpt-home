# 航空机场营销内容的部署与升级

## 这个品类的数据长什么样
金融/保险/理财行业在航空机场的营销相关数据，来自金融机构的产品物料库、航空机场的运营管理系统。数据更新节奏分为两类：机场客流与广告位数据每15分钟更新一次，金融产品信息随营销活动调整，每周更新。文档多为结构化PDF、CSV或在线网页格式，包含产品名称、投保规则、航站楼代码、广告位编号、投放时段等字段，单位多为三位字母航站楼代码、标准时间格式、平方米级尺寸单位。

## 这些特征在「部署与升级」这一环带来什么约束
金融营销内容需结合机场实时客流数据调整投放，要求部署时支持低延迟的场景数据同步；金融产品文档的合规性要求知识库解析时保留原始信息，不可随意修改内容；机场广告位的尺寸、时段限制要求配置适配不同格式的营销物料；多语言营销需求要求配置支持多语言上下文处理。升级时需避免中断数据源连接，确保实时客流数据同步不影响营销内容的精准投放。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 航空机场营销文档包含长文本产品说明、机场导览信息，需足够解析时间完成结构化处理 |
| `maxContext` | `800–1200 字符` | 旅客问询多围绕机场场景下的金融产品，该上下文长度适配常见问询场景 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 机场广告高清物料、金融产品宣传报表体积较大，需适配大文件上传需求 |
| `召回条数` | `前 6 条` | 营销内容需匹配精准的广告位、机场场景与金融产品，过多召回会干扰结果准确性 |
| `相似度阈值` | `0.75–0.85` | 过滤无关机场场景数据，保留高度匹配的营销素材与问询内容 |
| `SCHEDULED_SYNC_INTERVAL` | `15 分钟` | 机场客流数据实时性要求高，该间隔适配实时更新需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：通过ngrok等工具暴露外网后，移动设备无法加载聊天界面，呈现白屏。原因：未配置`CORS_ALLOWED_ORIGINS`参数，未包含移动设备访问的临时域名。
- 现象：大模型调用时GPU使用率偏低，CPU单核占用达100%。原因：未开启`USE_GPU_INFERENCE`参数，或未指定`GPU_DEVICE_ID`绑定对应显卡。
- 现象：V4.9版本配置在线模型后无法正常调用。原因：未在`MODEL_API_KEY`中填写对应密钥，或未开启`ENABLE_ONLINE_MODEL`参数。

## 怎么确认配好了
- 上传包含金融产品说明与机场广告位信息的结构化文档，检查解析结果是否保留所有原始字段，无格式错乱或乱码。
- 发起包含航站楼查询的模拟请求，验证返回结果的召回条数与配置的`召回条数`参数一致。
- 查看系统监控指标，确认`SCHEDULED_SYNC_INTERVAL`配置下，机场场景数据同步的成功率符合预期。
- 从非内网移动设备访问部署地址，验证聊天界面可正常加载，无白屏或权限报错。
