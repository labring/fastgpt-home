# 航空装备营销内容的工作流编排

## 这个品类的数据长什么样
在金融保险理财场景下，航空装备的营销相关数据来源涵盖设计研发文档、试飞测试台账、供应链参数手册及官方营销素材库。数据更新节奏无固定周期，新机型发布、合规文档修订时会批量更新，日常维护按需触发。文档结构差异显著，单份性能白皮书可达数十页，营销话术则仅数百字。字段包含最大起飞重量（单位千克/磅）、巡航速度（单位千米/小时/节）、订单交付周期（单位月）等，同时存在型号序列号、批次号等专属标识字段。

## 这些特征在「工作流编排」这一环带来什么约束
多源分散的数据来源要求工作流需配置跨源数据聚合节点，实现设计文档、试飞数据与营销素材的统一拉取。文档长度跨度大的特征，要求工作流支持自适应分段配置，适配长文档解析与短话术生成的不同需求。特殊单位混用的情况，要求工作流内置单位转换规则节点，自动统一营销场景的单位标准。专属字段绑定需求，要求工作流配置型号与参数的映射规则，避免跨型号参数混淆。无固定更新周期的特征，要求工作流支持事件触发与手动触发两种模式，适配按需更新的场景。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `workflow_trigger_mode` | `事件触发 + 手动触发` | 航空装备营销内容更新无固定周期，需响应新机型发布、合规文档更新等事件，同时支持手动调整内容 |
| `max_paragraph_length` | `800–1200 字符` | 航空装备性能文档单段内容不宜过长，避免模型上下文溢出，同时适配短营销话术的分段需求 |
| `unit_conversion_enable` | `开启` | 航空装备数据同时使用公制与英制单位，需自动转换为营销场景统一使用的公制单位，避免参数混淆 |
| `field_mapping_rule` | `按型号绑定专属参数` | 航空装备营销内容需精准关联对应型号的起飞重量、巡航速度等专属参数，避免跨型号参数混用 |
| `workflow_timeout` | `600 秒` | 长文档解析与多源数据聚合需要较长处理时间，避免超时中断 |
| `llm_model_for_classification` | `按实测标定` | 适配航空装备型号分类的提示词识别需求，优先选择支持长上下文的模型 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流输出结果中包含知识库检索的输入输出日志片段，原因：未关闭工作流节点的日志透传配置，导致非目标内容被带入最终输出。
- 现象：型号分类节点识别准确率偏低，存在同型号不同表述被误判的情况，原因：未针对航空装备型号命名规则调整提示词，使用通用分类模型导致识别精度不足。
- 现象：外部MCP插件调用失败，返回`403 Forbidden`状态码，原因：未在工作流节点中配置MCP插件的访问密钥与权限范围，导致接口调用被拦截。

## 怎么确认配好了
- 触发一次手动工作流执行，检查输出结果仅包含目标营销内容，无额外的检索日志片段。
- 导入一份同时包含公制与英制单位的航空装备参数文档，核对输出内容中的单位已统一为预设的营销场景单位。
- 提交包含不同型号标识的营销需求，核对输出内容关联的参数与对应型号完全匹配。
- 配置并触发外部MCP插件调用，检查接口返回状态码符合正常调用结果，无权限或超时报错。
