# 装修装饰营销内容的工具调用与插件

## 这个品类的数据长什么样
装修装饰场景的营销内容数据主要来自金融机构内部装修贷客户的需求文档、合作装修企业的案例库、建材供应商的参数文档。数据更新节奏为建材参数每月同步一次，装修案例库每季度新增内容。单篇文档包含户型尺寸、建材型号、施工节点、报价明细等字段，各字段附带对应单位，例如户型面积以平方米为单位，建材单价以元/平方米为单位，施工工期以天为单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
建材参数的月度更新要求工具调用时需定时同步最新数据源，避免使用过期参数。多字段且带单位的文档结构，要求插件参数需严格匹配字段名与单位，防止参数赋值错误。单篇文档内容较长，工具调用前需先完成分段抽取与字段结构化，确保传入参数的完整性。线下施工记录的非结构化片段，要求工具需支持先完成字段提取再执行后续调用逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_schema_import_format` | `OpenAPI V3` | 适配装修装饰场景多字段的参数结构，符合行业通用的插件导入规范 |
| `tool_call_timeout` | `120 秒` | 装修装饰场景的参数抽取与数据拉取需处理多字段文档，120秒可覆盖常规处理时长 |
| `context_window_segment_length` | `800–1200 字符` | 单篇装修案例文档的核心字段集中在该长度范围内，可避免分段截断关键参数 |
| `tool_param_validate_threshold` | `0.9` | 需严格匹配装修装饰场景的字段名与单位，避免低匹配度的参数赋值 |
| `plugin_sync_interval` | `每月1次` | 建材参数的更新频率为每月同步，需保持插件数据源与供应商数据一致 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为工具调用时返回`400 Bad Request`错误，提示参数格式不匹配。原因是未按装修装饰场景的字段单位要求赋值，例如将户型面积的单位设为元，未使用平方米。
- 现象为传入工具的参数`q`仅包含部分内容，未覆盖核心字段。原因是未对装修案例文档进行结构化分段，直接截取片段传入`q`参数，导致关键信息缺失。
- 现象为插件调用时返回过期的建材报价数据。原因是未配置定期同步数据源的周期，使用了缓存的旧版参数。

## 怎么确认配好了
- 执行一次工具调用测试，查看返回的参数是否与装修案例文档中的字段完全匹配。
- 检查插件的数据源同步日志，确认最近一次同步的时间与配置的同步周期一致。
- 模拟触发参数校验流程，验证不同单位的字段赋值是否被正确拦截。
- 导入插件的schema文件，确认格式与配置项指定的`tool_schema_import_format`一致。
