# 证券营销内容的工作流编排

## 这个品类的数据长什么样
证券营销内容依赖的数据主要来自交易所公开披露平台、券商内部研报系统、第三方行情接口。更新节奏：上市公司公告随披露实时推送，行业研报按工作日分批更新，行情数据在交易时段实时刷新。文档多为结构化表头搭配非结构化正文，包含证券代码、发布主体、评级、核心业务数据字段，单位涵盖元、万元、份额。部分文档附带附件格式的详细测算表，需单独解析提取有效内容。

## 这些特征在「工作流编排」这一环带来什么约束
上述数据特征对工作流编排带来多重约束。实时推送的公告与交易时段刷新的行情数据，要求工作流支持事件触发的调度模式，适配高频数据更新节奏。多来源的异构文档，要求工作流配置适配不同格式的解析节点，同时通过字段映射统一数据口径。附带附件的文档需额外配置附件解析环节，适配PDF、表格类附件的内容提取。部分数据的时效性要求工作流内置时间校验逻辑，过滤超出有效期的内容，避免营销内容使用过时信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 证券类文档含长正文与附件，需足够时间完成解析 |
| `max_context_length` | `8000–16000 字符` | 营销内容需整合多份研报、公告的完整内容，避免截断关键信息 |
| `tool_call_order` | `按节点绑定顺序执行` | 证券营销内容需按“行情数据→研报分析→合规校验”的逻辑依次调用工具，确保流程可控 |
| `classification_threshold` | `0.75–0.85` | 精准识别用户咨询的证券品类，避免误分类导致内容偏差 |
| `reply_node_max_lines` | `按内容自动换行` | 支持连续多行换行，清晰呈现结构化的营销数据与逻辑 |
| `remove_default_prompt` | `开启` | 保持专业营销话术，避免生成平台自带的默认介绍文本 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流中绑定多个工具后，部分工具未触发或执行顺序混乱。原因：未配置`tool_call_order`为按绑定顺序执行，默认采用并行调用模式导致时序异常。
- 现象：AI生成的营销内容末尾附带固定的平台介绍文本。原因：未开启`remove_default_prompt`配置，保留了系统默认的提示词内容。
- 现象：指定回复节点生成的内容无法实现连续多行换行，排版混乱。原因：未将`reply_node_max_lines`配置为按内容自动换行，强制限制了换行数量或未启用换行解析。

## 怎么确认配好了
- 触发一次测试工作流，查看工具调用日志，确认所有绑定的工具按预期顺序执行。
- 生成一条营销内容，检查末尾是否存在平台自带的默认介绍文本，确认`remove_default_prompt`配置生效。
- 上传一份带附件的证券公告，查看解析结果是否完整提取了正文与附件内容，确认`PARSE_FILE_TIMEOUT_SECONDS`配置合理。
- 模拟用户咨询不同品类的证券问题，查看分类节点的识别结果是否符合预期，确认`classification_threshold`配置适配场景需求。
