# 证券营销内容的表单与交互

## 这个品类的数据长什么样
证券营销相关的数据主要来源于券商内部合规审核通过的营销物料、公开投研报告、用户留资表单。更新节奏方面，合规营销物料需完成内部审核后更新，投研报告随市场动态调整，用户留资数据实时同步至系统。文档结构包含强制合规字段，如风险揭示内容、产品编码、年化收益区间，同时支持自定义留资字段。字段包括用户姓名、11位联系电话、风险测评得分、意向产品代码，其中风险测评得分以整数区间标注，年化收益以百分比为单位，产品代码为6位阿拉伯数字。

## 这些特征在「表单与交互」这一环带来什么约束
强制合规字段要求表单必须设置必填项，且校验规则严格匹配监管要求，不可省略风险揭示等核心内容。实时更新的产品数据要求交互环节支持动态数据源拉取，避免使用静态缓存导致的产品信息过期。用户留资字段的格式规范需要在交互节点中配置实时校验，防止无效数据提交。营销内容需关联已备案的合规素材，因此表单生成的推荐内容必须绑定已审核的素材ID，禁止调用未备案的物料。同时，表单提交后的数据需同步至合规审核链路，确保全流程符合监管要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `form_required_fields` | `["risk_disclosure", "phone_number", "product_code"]` | 匹配证券营销表单的强制合规字段要求，确保核心信息不缺失 |
| `form_field_validation_rules` | `{"phone_number": "regex:^1[3-9]\\d{9}$", "product_code": "regex:^\\d{6}$"}` | 校验留资字段的格式，符合证券行业数据规范 |
| `dynamic_data_source_timeout` | `10 秒` | 适配实时拉取合规产品数据的网络延迟，避免超时导致表单加载失败 |
| `workflow_trigger_condition` | `form_submit_success` | 绑定表单提交成功后的工作流触发，确保合规校验与素材调用在提交后执行 |
| `ai_response_content_filter` | `["risk_promise", "guaranteed_income"]` | 拦截违规承诺收益的回复内容，符合证券营销合规要求 |
| `form_submit_webhook` | `https://internal-compliance-check.fastgpt.com/verify` | 同步表单数据到合规审核系统，满足监管备案要求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：本地部署后版本与安装时选择的4.8.20不一致，显示为4.8.17，表单配置的合规字段模板缺失。原因：未指定GitHub仓库的tag拉取代码，误拉取了旧版本分支。
- 现象：在指定回复节点中手动输入`<video src="xxx"></video>`后，前端仅显示文本标签，无视频元素。原因：未开启`markdown_render_media_tags`配置项，默认未启用非文本类Markdown标签解析。
- 现象：通过API调用工作流传入知识库ID变量，知识库搜索节点未返回对应结果。原因：未将变量格式设置为`${kb_id}`的模板语法，或未在工作流入口配置接收外部传入的变量参数。

## 怎么确认配好了
- 进入表单配置界面，核对必填字段列表是否包含监管要求的强制项。
- 提交格式不符合规范的测试数据，验证字段校验规则是否触发拦截提示。
- 触发工作流执行，确认知识库搜索节点可正确读取外部传入的变量参数。
- 查看模型提供商配置页面，确认自定义模型或本地部署的模型已被添加到可选列表。
