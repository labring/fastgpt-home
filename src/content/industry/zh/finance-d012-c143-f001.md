# 软件开发营销内容的HTTP 接口与外部系统

## 这个品类的数据长什么样
软件开发营销内容的数据以技术导向的结构化文档与富文本营销素材为主，来源包括内部研发产出的API规范、版本更新说明、技术白皮书、演示Demo包，以及营销活动配套的宣传物料。数据更新节奏随软件版本迭代与营销活动调整，大版本迭代周期通常为1-3个月，小补丁与临时营销物料更新频率无固定周期。文档结构通常包含接口入参/出参字段、错误码对照表、调用示例，字段多包含`api_name`、`param_type`、`response_code`，单位多为字节、毫秒、标准ISO时间戳格式。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
结构化技术文档的强校验需求要求HTTP接口开启严格的参数白名单校验，避免非预期字段导致外部系统解析错误。版本迭代带来的内容更新要求外部系统支持动态拉取最新接口元数据，避免硬编码参数导致的兼容问题。富文本营销素材的二进制传输需求要求接口支持`multipart/form-data`或`application/octet-stream`格式。字段单位的固定性要求接口返回字段附带明确单位标识，保障跨系统解析一致性。金融场景下的营销数据还需符合合规要求，要求传输过程加密鉴权。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `UPLOAD_MARKETING_FILE_MAX_SIZE` | `500 MB` | 软件开发营销素材包含API文档包、演示视频、技术白皮书，单文件体积通常适配该上限，避免上传失败 |
| `API_REQUEST_TIMEOUT` | `300 秒` | 批量拉取营销内容接口数据、同步版本文档时，较长超时可覆盖正常请求耗时，避免中断 |
| `ENABLE_STRICT_PARAM_VALIDATION` | `开启` | 软件开发营销内容的接口参数需严格匹配规范，严格校验可过滤无效请求，提升外部系统解析准确性 |
| `SYNC_MARKETING_API_DOC_CRON` | `0 0 * * *` | 每日凌晨同步一次，适配软件开发版本迭代周期，及时更新外部系统的接口元数据 |
| `REQUIRE_HTTPS_FOR_EXTERNAL` | `开启` | 金融场景下营销数据传输需符合合规要求，保障敏感数据安全 |
| `BINARY_TRANSFER_COMPRESSION` | `gzip` | 大体积营销素材传输时，压缩可降低带宽占用，提升传输效率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部接口传输营销素材时返回`413 Request Entity Too Large`状态码。原因：未正确配置`UPLOAD_MARKETING_FILE_MAX_SIZE`，上传文件体积超出接口允许上限。
- 现象：无法从文件上传节点直接获取二进制数据并发起HTTP请求。原因：未开启对应二进制传输配置项，默认返回的是文件存储路径，未返回原始二进制流。
- 现象：调用`tokenLogin`接口切换团队后，外部系统存储的团队数据未同步更新。原因：未配置团队数据同步的回调接口，仅本地缓存未同步至外部系统。

## 怎么确认配好了
- 发起一次小体积营销素材的上传请求，检查返回的`content_length`字段与实际文件大小一致，确认参数校验配置生效。
- 配置外部系统回调地址，发起团队切换操作，检查外部系统是否收到同步的团队数据，确认鉴权与同步配置正确。
- 查看接口日志，确认所有外部HTTP请求均使用HTTPS协议，确认加密传输配置生效。
- 手动触发一次API文档同步任务，检查外部系统拉取的文档字段与官方公开文档一致，确认版本同步配置正确。
