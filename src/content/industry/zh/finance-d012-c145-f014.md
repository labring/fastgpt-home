# 通信设备营销内容的表单与交互

## 这个品类的数据长什么样
通信设备的数据来源包括设备内置射频、功耗传感器采集的运行参数，后台运维系统同步的设备SN编号、固件版本、部署批次信息，以及销售环节录入的客户关联设备信息。文档以结构化字段为主，附带少量非结构化的故障排查日志片段。核心字段包含SN编号（字符串类型，唯一标识）、信号强度（单位dBm）、在线时长（单位小时）、固件版本号（字符串）。核心运行参数每数秒同步一次，配置类信息随设备变更触发更新，非结构化日志按需上传。

## 这些特征在「表单与交互」这一环带来什么约束
通信设备的多维度结构化参数与唯一标识属性，要求表单支持按设备型号动态加载对应字段，避免冗余展示。实时更新的运行参数要求表单支持定时刷新，不能依赖静态缓存。SN编号等唯一标识的查询需要精确匹配，防止模糊匹配导致的设备信息错位。固定单位的参数字段需要自带单位提示，防止用户输入错误单位引发的后续流程异常。部分参数存在合法取值区间，表单需要配置范围校验，拦截无效提交。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `form_dynamic_field_trigger` | 按设备型号选择触发 | 通信设备参数随型号差异较大，按选择触发可精简表单展示内容 |
| `input_validate_unit` | 绑定预设单位（如dBm、小时） | 通信设备参数存在固定单位，可避免用户输入错误单位 |
| `search_match_type` | 精确匹配 | SN编号等唯一标识需要精确查询，防止模糊匹配导致的设备信息偏差 |
| `form_refresh_cycle` | 10–30 秒 | 匹配核心运行参数的更新频率，保证表单展示数据的实时性 |
| `form_submit_check_range` | 按设备品类预设范围 | 通信设备参数存在合法取值区间，拦截无效提交内容 |
| `form_upload_allow_types` | 仅允许日志文件、配置文件 | 营销场景中仅需收集设备运维日志与配置文档，过滤无关文件 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：选择设备型号后，对应参数字段未自动加载。原因：未正确配置`form_dynamic_field_trigger`的触发逻辑，或触发条件绑定错误。
- 现象：提交表单时提示数据库查询报错，手动输入固定值可正常执行。原因：未将表单字段正确映射为SQL查询变量，或变量格式不符合数据库连接要求。
- 现象：表单输入框未显示单位提示，用户输入错误单位导致校验失败。原因：未开启`input_validate_unit`配置，或未绑定对应参数的预设单位。

## 怎么确认配好了
- 依次选择不同型号的通信设备，核对对应参数字段是否自动加载并显示正确单位。
- 输入不符合合法区间的参数值，核对是否触发对应的校验提示。
- 输入设备SN编号，核对是否触发精确匹配的查询结果。
- 等待配置的刷新周期，核对表单展示的运行参数是否同步更新。
