# 通用设备营销内容的工作流编排

## 这个品类的数据长什么样
金融领域的通用设备营销内容数据主要来源于设备出厂参数文档、金融场景运维日志、银行/保险机构的招投标文件及行业合规手册。数据更新节奏分两类：定型设备参数每季度随版本迭代更新，运维类数据每日同步更新。单份文档结构固定，包含设备型号、额定功率、适配金融场景、参考采购报价等字段，字段单位多为kW、mm、台、套等工业标准单位，部分定制化设备需补充合规认证相关参数项。

## 这些特征在「工作流编排」这一环带来什么约束
金融领域通用设备的多源分散数据要求工作流需配置多数据源对接节点，适配不同格式的出厂参数、运维日志及合规文件。分阶段更新的特征要求工作流设置差异化触发规则，定型设备参数采用定时同步节点，运维数据配置实时拉取触发。固定字段与单位要求工作流内置字段映射与单位格式化组件，避免参数与单位不匹配导致的金融场景适配文案错误。定制化设备的合规参数则要求工作流支持条件分支节点，根据设备类型跳转对应合规认证信息的提取与文案生成流程，满足金融机构的合规审核要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时同步周期` | 标准产品设为`每6小时`，非标定制产品设为`每24小时` | 标准产品参数更新节奏稳定，低频同步即可覆盖需求；非标产品更新频次低，减少不必要的资源占用 |
| `字段映射规则` | 按原始文档字段名一对一绑定，补充单位转换映射 | 匹配通用设备文档的固定字段结构，避免参数与单位分离导致的文案错误，适配金融机构对设备合规信息的提取需求 |
| `maxContext` | `800-1200字符` | 覆盖设备核心参数与适用场景，避免过长导致大模型生成冗余内容，过短丢失关键信息 |
| `空知识库触发策略` | 直接调用本地参数库生成文案 | 对应通用设备知识库为空时的场景，避免无数据时触发无效的大模型搜索，满足金融机构对合规信息的快速生成要求 |
| `节点超时时间` | `300秒` | 适配多数据源拉取、格式转换与文案生成的整体处理时长，避免因超时中断流程 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流节点右侧与下方连接点配置后，流程执行顺序异常。原因：未区分连接点的触发逻辑，右侧连接点为条件分支触发，下方连接点为串行执行触发，混用导致流程跳转错误。
- 现象：知识库为空时，工作流仍触发大模型搜索并返回无结果提示。原因：未配置`空知识库触发策略`为直接生成参数文案，默认触发了大模型召回流程。
- 现象：恢复备份节点后，合规认证参数丢失。原因：备份仅导出了工作流节点配置，未同步绑定的合规文档与字段映射规则，恢复时未勾选关联资源选项。

## 怎么确认配好了
- 触发一次标准产品的工作流，核对生成的营销文案是否包含预设的核心参数与单位，确认字段映射配置生效。
- 模拟非标设备的输入参数，验证工作流是否跳转至定制化参数提取分支，确认条件分支规则生效。
- 清空绑定的知识库，触发工作流后核对是否直接生成基于本地参数库的文案，确认空知识库策略生效。
- 调整定时同步周期，查看数据源节点的同步日志，确认同步频率符合配置要求。
