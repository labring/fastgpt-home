# 造纸营销内容的模型接入与配置

## 这个品类的数据长什么样
造纸营销内容的数据来源包括自有产品规格文档、下游包装与印刷客户的需求反馈文档、行业品类标准文件，以及电商渠道的在售产品详情。更新节奏随业务节点调整：产品规格文档随新品投产更新，客户需求文档随订单周期更新，行业标准文件按年度节奏更新。文档多为多段式结构，开头标注产品品类，中间罗列物理参数与交付信息，结尾补充起订量与交付周期。字段包含克重、幅宽、耐破强度、起订量等，对应单位分别为g/㎡、mm、kPa、吨。

## 这些特征在「模型接入与配置」这一环带来什么约束
造纸营销内容的专业参数与单位要求严格，模型接入时需配置参数解析映射规则，匹配字段与对应单位，避免解析后参数格式混乱。文档长度与结构差异较大，长文档可能超出模型上下文窗口，需按产品品类拆分段落，避免跨品类参数混淆。更新频率不均且以业务节点为核心触发条件，需配置增量同步规则，适配新品上线与订单变化的同步需求。营销咨询多聚焦特定参数，召回范围需限定在产品与交付信息内，避免无关内容干扰模型输出。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–16000 字符` | 造纸营销文档多包含多组专业参数，单组参数约占500字符，该区间可容纳16组完整产品参数，适配批量营销内容生成需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | 造纸产品文档包含详细物理参数解析，单文档解析耗时较长，120秒可覆盖绝大多数文档解析场景 |
| `RECALL_TOP_N` | `前 3–5 条` | 造纸客户咨询多聚焦1-2个核心参数，召回过多内容会干扰模型输出，该范围可精准匹配需求 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 造纸参数字段专业性强，需较高相似度匹配才能准确召回对应产品文档，避免无关内容被选中 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 造纸营销文档多包含高清产品图片与详细参数表格，单文档体积较大，该取值可满足上传需求 |
| `SYNC_TRIGGER_MODE` | `按新品投产节点触发` | 造纸产品更新以新品投产为核心节点，该触发方式可减少无效同步次数，保障文档时效性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用大模型时返回“400 Bad Request”错误，原因：未配置造纸专业参数的单位校验规则，将带单位的字段直接传入模型，导致请求格式不符合要求。
- 现象：知识库召回结果包含无关的行业标准文档，原因：未限定召回字段范围，仅使用通用召回规则，导致非营销相关的内容被选中。
- 现象：人工客服转接功能无法触发，原因：未配置针对造纸定制化需求的触发条件，仅设置了通用的“无法回答”触发规则。

## 怎么确认配好了
- 上传一份造纸产品文档，检查解析后的字段是否包含克重、幅宽等专业参数，确认单位映射是否正确。
- 发起模拟咨询，输入包含特定造纸参数的问题，检查召回的知识库内容是否匹配对应参数的产品文档。
- 触发一次新品文档同步，检查同步日志是否显示新品文档已成功导入知识库。
- 模拟定制化造纸需求的咨询，检查是否触发人工客服转接流程。
