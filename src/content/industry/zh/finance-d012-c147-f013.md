# 造纸营销内容的知识库检索与召回

## 这个品类的数据长什么样
造纸营销相关的知识库数据主要来源于企业内部的产品规格手册、原料质检报告、生产工艺文档、定制化客户方案、行业展会宣传资料及下游包装印刷客户的反馈文档。数据更新节奏随原料价格波动、产能调整及新产品投产同步，通常为月度或季度更新。文档结构包含长篇幅的工艺描述、结构化的参数表格，以及整理好的营销话术库与成功案例合集，字段涵盖产品型号、原料配比、合规认证编号等，单位多为g/㎡、mm、t/d等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
造纸类数据的长文档与结构化参数并存的特征，要求检索系统需兼顾长上下文关联与精准参数匹配。高频更新的原料与产能数据，要求检索环节支持增量同步以避免召回过时内容。营销场景下的内容需求与生产文档需求存在差异，需区分检索的目标场景，避免非营销类文档干扰结果。多维度的参数字段也要求检索系统支持多字段过滤，确保召回内容与营销需求匹配。同时，大型文档的存在要求系统具备大文件解析与存储能力，避免因文件拆分不当导致检索精度下降。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_CHUNK_SIZE` | 800–1200 字符 | 造纸类文档多包含长句工艺描述与结构化参数，该长度可平衡上下文关联度与检索精度 |
| `UPLOAD_FILE_MAX_SIZE` | 2000 MB | 覆盖造纸企业的大型生产工艺手册与合规文档，突破单文件100M的默认限制 |
| `召回条数` | 前8–12条 | 造纸营销内容常需匹配多维度产品参数，足够条数可覆盖组合检索需求 |
| `相似度阈值` | 0.72–0.80 | 区分产品型号、原料类型等易混淆的细分参数，避免低相关召回 |
| `增量同步间隔` | 72 小时 | 适配造纸企业原料与产能的月度更新节奏，平衡实时性与集群资源消耗 |
| `重排返回条数` | 前4–6条 | 聚焦营销场景下的核心推荐内容，避免过多冗余参数干扰营销话术生成 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：检索结果与营销话术需求完全不匹配，返回大量生产参数，未包含客户需要的产品营销内容。原因：未针对造纸营销场景调整相似度阈值与召回条数，召回了过多非营销类的工艺文档。
- 现象：系统返回`insufficient_quota`报错，提示上游负载已饱和。原因：未配置合理的增量同步间隔，全量同步任务频繁占用集群资源，导致并发检索请求被限流。
- 现象：单文件上传失败，界面提示文件大小超限。原因：未调整`UPLOAD_FILE_MAX_SIZE`参数，沿用默认的100M限制，无法上传造纸企业的大型合规手册或生产工艺文档。

## 怎么确认配好了
- 上传一份造纸企业的完整生产工艺手册，检查解析后的分段数量与长度是否符合预设的`PARSE_CHUNK_SIZE`范围。
- 发起一次针对营销话术的检索请求，核对返回结果的条数与相似度得分是否符合配置的`召回条数`与`相似度阈值`。
- 查看同步任务日志，确认增量同步任务按预设间隔执行，未出现频繁触发的全量同步操作。
- 上传单份超过100M的造纸合规文档，确认上传任务可正常完成，未触发文件大小超限报错。
