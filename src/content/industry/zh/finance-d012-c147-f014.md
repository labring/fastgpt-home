# 造纸营销内容的表单与交互

## 这个品类的数据长什么样
本场景面向金融机构为造纸类轻工制造企业提供营销内容与获客服务，造纸行业的营销相关数据主要来自生产控制系统、原料采购台账、成品仓储报表三类数据源。数据更新节奏以生产批次为单位，单批次生产完成后同步更新全量对应参数。文档结构多为结构化表格形式，每行对应一个成品批次，包含原料种类、定量、幅宽、环压强度、交货日期、批次编号等字段。字段单位分别为无（种类、编号）、g/㎡（定量）、mm（幅宽）、kN·m（环压强度）、天（交货日期），无百分比类统计数值。

## 这些特征在「表单与交互」这一环带来什么约束
作为金融机构服务造纸企业的营销获客工具，造纸行业的批次化数据特征要求表单支持按批次编号筛选查询，避免跨批次数据混淆。多字段且含专业物理参数的结构，要求表单提供折叠非高频字段的交互能力，防止界面过于拥挤。不同品类造纸（如包装纸、文化纸）的必填参数差异较大，要求表单支持动态切换字段组。数据来自多系统同步的特性，要求表单支持批量文件上传与多格式解析，同时需校验字段数值合法性，防止无效数据进入营销内容生成流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 造纸行业的质检报告多包含高清扫描件与批量Excel，单文件上限需覆盖单批次全量数据包 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 批量Excel解析需遍历多字段，长文件解析耗时较长，避免中途超时中断 |
| `FORM_FIELD_COLLAPSE_THRESHOLD` | 12 个 | 造纸表单包含原料、物理指标、交付信息等多组字段，超过阈值自动折叠非高频字段，简化交互 |
| `DYNAMIC_FORM_FIELD_SWITCH` | 开启 | 区分包装纸、文化纸、特种纸等品类，切换对应必填字段组，适配不同营销场景 |
| `HTTP_REQUEST_RETRY_TIMES` | 2 次 | 造纸数据多来自外部系统同步，网络波动可能导致请求失败，重试降低提交失败率 |
| `BASE64_ENCODE_ENABLE` | 开启 | 营销内容中需嵌入质检报告图片，base64编码可直接在前端渲染，无需额外存储 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 上传质检报告图片后界面显示解析结果为空，日志中出现“base64编码缺失”报错，原因是未开启`BASE64_ENCODE_ENABLE`配置，导致图片无法转换为可传递的格式。
- 输入语音后界面显示“音频解析失败”，无任何返回内容，原因是未开启`AUDIO_PARSE_ENABLE`配置，且未配置语音转文字的接口权限。
- 连接业务数据库时提示“访问被拒绝”，无法读取造纸业务数据，原因是未在数据库连接配置中指定专属账号与访问白名单参数。

## 怎么确认配好了
- 上传符合品类规格的质检文件，核对解析后的字段与预设表单字段一致。
- 切换表单品类选项，确认动态加载的字段组匹配对应品类的参数要求。
- 发起图片上传请求，检查返回结果包含可识别的编码格式字符串。
- 提交表单后核对系统日志，确认无超时或连接失败的报错记录。
