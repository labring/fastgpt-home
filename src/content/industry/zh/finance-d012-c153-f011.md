# 风电营销内容的文档解析与分块

## 这个品类的数据长什么样
风电营销相关的文档，主要用于金融机构的风电项目投融资获客，来源包括风电项目可研报告、机组设备参数手册、区域风电资源评估资料、客户成功案例白皮书、合规性审批文件等。更新节奏随项目推进、设备迭代与营销周期调整，无固定周期。文档格式包含多页PDF、内嵌工程计算公式的Word文档、带数字签名的合规文件，以及大量结构化表格。字段与单位涵盖功率（千瓦kW、兆瓦MW）、轮毂高度（米m）、扫风面积（平方米㎡）、发电量（千瓦时kWh）、风速（米每秒m/s）等工程相关参数。

## 这些特征在「文档解析与分块」这一环带来什么约束
风电营销文档的特征对解析与分块环节带来多重约束。首先，大量结构化参数表要求解析引擎精准识别表格边界，避免跨页表格被错误拆分，同时保留原始字段与单位的对应关系。其次，带数字签名的合规文件需兼容加密签名格式，常规解析引擎无法读取此类文件的有效内容。第三，包含工程计算公式的文档需保留公式的语义结构，纯文本转换会导致逻辑丢失。第四，单份文档跨度从单页营销物料到数十页可研报告，需自适应调整分块阈值，避免短文档过度拆分或长文档超出上下文窗口。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_PDF_SIGN_SUPPORT` | `true` | 风电营销文档常包含带数字签名的合规性文件，需开启签名兼容解析模式，适配FastGPT V4.9.1及以上版本 |
| `chunk_size` | `800–1200 字符` | 风电文档包含长段工程描述与结构化参数，该区间可平衡上下文连贯性与分块粒度 |
| `PARSE_TABLE_EXTRACT_MODE` | `structured_table` | 风电营销文档包含大量机组参数、项目预算等结构化表格，需保留表格的行列结构，不采用纯文本转换 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单份风电可研报告可能包含多页图纸与参数附件，需适配大容量文件上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | 大容量风电文档解析需更长处理周期，避免因超时导致解析失败 |
| `enable_formula_recognition` | `true` | 风电文档包含发电量测算、载荷计算等工程公式，需保留公式语义以确保后续检索准确 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用Doc2x工具解析风电文档时返回读取文件错误，报错信息被截断为`Only support .txt, .m`。原因：上传的文件格式未被当前解析引擎支持，或文件扩展名与实际内容不匹配。
- 现象：带数字签名的风电项目PDF上传后，解析结果无有效文本内容。原因：未开启带签名PDF的兼容解析模式，常规解析引擎无法读取加密签名后的文档内容。
- 现象：通过API生成的文档阅读链接点击后提示权限错误或页面无法访问。原因：解析生成的临时链接未配置正确的访问时效，或文件解析过程中出现中断导致链接失效。

## 怎么确认配好了
- 上传一份带数字签名的风电合规PDF，检查解析结果是否包含完整的文本与参数内容。
- 上传一份包含结构化参数表的风电文档，检查解析结果是否保留表格的行列结构与原始字段单位。
- 调整`chunk_size`参数后，对比不同分块长度下的解析结果，确认分块粒度适配当前文档的内容长度。
- 上传大容量风电可研报告，检查解析过程是否超时，确认`PARSE_FILE_TIMEOUT_SECONDS`配置符合文档处理需求。
