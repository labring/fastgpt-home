# 饰品营销内容的表单与交互

## 这个品类的数据长什么样
饰品营销内容的数据主要来自金融机构自有贵金属SKU管理系统、合作品牌的商品库及质检报告。数据更新节奏随营销节点波动，新品上线期每周更新，常规时段每月同步。单条数据文档结构固定，包含SKU编码、材质成分、实物尺寸、克重、适配场景、设计风格、库存状态、理财关联属性等字段。尺寸字段单位多为毫米或厘米，克重单位为克，材质字段需明确标注纯度或镀层工艺，避免模糊表述。

## 这些特征在「表单与交互」这一环带来什么约束
SKU编码的唯一性要求表单字段需支持精确匹配校验，避免因编码重复导致金融营销内容的合规性问题。材质、尺寸的细分字段要求交互组件优先提供预设选项，不开放自由输入，减少数据偏差带来的合规风险。库存状态的实时性要求表单需对接实时数据接口，避免展示已售罄的贵金属饰品，影响客户信任。营销节点的高频更新要求表单配置可快速切换预设字段组，适配不同理财主题的营销内容收集。尺寸字段的单位差异要求交互时自动关联单位提示，避免用户输入时出现单位混淆，提升数据准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `RE_RANK_TOP_K` | `3-5条` | 贵金属饰品营销内容的核心特征（纯度、克重、设计风格）较少，重排后保留少量高匹配结果即可满足合规的内容生成需求，避免冗余信息干扰。 |
| `TEXT_EXTRACT_THRESHOLD` | `0.75-0.85` | 贵金属饰品相关文本的专属关键词（如“999金”“投资银条”）辨识度较高，阈值设置在该区间可过滤低匹配的无效提取结果，同时保留有效信息。 |
| `FORM_FIELD_PRESET_COUNT` | `8-10个` | 单条饰品营销表单需覆盖SKU编码、材质、尺寸等核心字段，预设字段数量控制在该区间可避免页面过于冗长，同时满足金融营销的信息收集需求。 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600秒` | 贵金属饰品相关的商品详情文档可能包含高清图片的OCR解析，或长文本的结构化提取，600秒的超时设置可覆盖复杂解析流程。 |
| `FORM_INPUT_UNIT_PROMPT` | `自动补全mm/g` | 贵金属饰品的尺寸、克重字段需明确单位，自动补全提示可减少用户输入错误，提升数据准确性与合规性。 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：表单提交后提取字段为空，或文本提取节点返回空结果。原因：未针对金融领域贵金属饰品的专属关键词配置专属提取词表，导致通用提取模型无法识别品类专属术语。
- 现象：启用重排模型后，生成的营销内容仅使用单条最高匹配结果。原因：未调整`RE_RANK_TOP_K`参数，默认取值仅返回1条结果，未覆盖贵金属饰品多维度特征的组合需求。
- 现象：表单输入尺寸字段时出现单位混淆，如用户输入“10”被识别为“10厘米”，未被识别为“10毫米”。原因：未开启`FORM_INPUT_UNIT_PROMPT`配置，未对贵金属饰品专属字段添加单位提示规则。

## 怎么确认配好了
- 提交测试用的贵金属饰品描述文本，核对文本提取节点返回的字段是否与输入内容匹配，调整`TEXT_EXTRACT_THRESHOLD`至符合业务需求的区间。
- 启用重排模型后，查看生成结果的来源条数，调整`RE_RANK_TOP_K`参数至覆盖所需特征的数量。
- 模拟表单输入不同单位的尺寸值，检查系统是否自动关联单位提示，确认`FORM_INPUT_UNIT_PROMPT`配置生效。
- 上传包含贵金属饰品详情的长文档，检查解析耗时是否在预设的`PARSE_FILE_TIMEOUT_SECONDS`范围内，避免超时报错。
