# 黑色家电营销内容的部署与升级

## 这个品类的数据长什么样
金融场景下的黑色家电营销内容数据，主要来自合作品牌的官方产品规格库、线下终端的销售辅助物料库，以及线上合作渠道的用户反馈素材。数据更新节奏随新品上市周期与平台获客活动调整，新品发布或活动上线阶段更新频率较高，常规周期内更新量稳定。文档分为结构化参数文档与非结构化营销素材两类：结构化文档包含SKU编号、屏幕尺寸、额定功率、能效等级等字段，单位多为厘米、瓦、等级标识；非结构化素材则包含产品卖点文案、场景化宣传视频脚本、用户体验分享片段。

## 这些特征在「部署与升级」这一环带来什么约束
金融场景下的黑色家电营销内容需关联平台的获客活动规则，结构化参数的字段标准化程度高但SKU数量较多，部署阶段需支持多SKU的批量关联导入与活动标签绑定，升级环节需适配新增产品字段的解析逻辑与活动规则更新。非结构化营销素材包含长文案、场景化视频，对文件解析的时长与大小限制要求更高。不同黑色家电细分品类的核心参数差异显著，部署时需支持自定义字段映射规则，避免跨品类解析冲突。此外，营销内容需同步至平台的获客渠道，部署环节需配置渠道接口的访问权限，升级时需调整内容推送的触发规则以匹配活动节奏。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 黑色家电的营销物料包含长文档与视频素材，需预留足够的解析时长 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 单份黑色家电宣传视频或完整产品手册的体积通常较大，需适配常规物料上传需求 |
| `CHUNK_SIZE` | `800–1200 字符` | 黑色家电产品参数与营销文案的信息密度较高，分段长度需覆盖完整的参数组或卖点段落 |
| `UPLOAD_ALLOWED_EXTENSIONS` | `["pdf", "docx", "mp4", "txt"]` | 覆盖黑色家电常用的营销物料格式，包括产品手册、销售文档、宣传视频与参数文本 |
| `SYNC_EXTERNAL_DATA_INTERVAL` | `15 分钟` | 线下终端的活动信息更新频率较高，需及时同步至营销内容知识库 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：镜像打包部署后，上传的附件无法被识别，本地开发环境可正常完成总结分析，无明确报错文案。原因：容器内的文件解析依赖的静态资源未随镜像打包完成同步，或容器的文件挂载路径配置错误。
- 现象：部署在docker容器内的实例无法访问外部数据源，无法同步营销活动相关的信息。原因：docker容器的网络模式配置为桥接模式但未开放对应端口，或主机的防火墙规则限制了容器的出站请求。
- 现象：调用代码运行插件时返回AxiosError 404状态码。原因：插件请求的外部接口路径配置错误，或接口未在部署环境中完成部署与暴露。

## 怎么确认配好了
- 上传一份典型的黑色家电产品手册PDF，检查解析后的文本块是否包含完整的参数条目，核对解析时长是否符合预期配置。
- 配置外部数据源同步任务，手动触发一次同步，检查知识库中是否新增了对应SKU的活动信息，核对同步间隔是否匹配业务需求。
- 运行代码运行插件，请求预设的测试接口，检查返回结果是否符合预期，确认网络访问权限配置正确。
- 在高级编排流程中添加判断器与AI对话节点，输入测试用户问题，检查AI对话节点是否能获取并使用初始用户问题进行回复。
