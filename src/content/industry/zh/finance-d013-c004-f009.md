# 专用设备融资日报的引用来源与溯源

## 这个品类的数据长什么样
专用设备融资日报的数据主要来自全国工程机械工业协会的每日销售报备、持牌融资租赁公司的系统同步数据、主机厂的终端销售台账。更新节奏为每日凌晨更新前一日全量数据。文档以结构化CSV或Excel格式呈现，核心字段包含设备型号编码、出厂序列号、单笔融资金额（单位：万元）、租赁期限（单位：月）、放款日期、承租方注册地，部分文档附带设备工况参数补充项。

## 这些特征在「引用来源与溯源」这一环带来什么约束
专用设备融资日报的多源结构化特征，对引用溯源带来三项核心约束。其一，每日全量更新的节奏要求溯源系统支持按放款日期精准筛选数据源，避免跨日数据混同。其二，包含出厂序列号、设备型号编码等唯一标识字段，需要配置字段级溯源锚点，仅依托文档标题完成关联无法满足配置要求。其三，数据来自行业协会、融资租赁公司等多渠道，需保留每个字段的原始数据源标签，确保单笔融资记录的全链路溯源可验证。另外，设备型号编码存在行业通用与厂商自定义的差异，需在溯源时匹配官方编码体系，避免命名差异导致的匹配失效。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前10条` | 专用设备融资日报单文档字段较多，过多召回会导致上下文冗余，10条可覆盖核心融资记录的溯源需求 |
| `相似度阈值` | `0.75–0.85` | 设备型号编码、出厂序列号等字段匹配精度要求高，阈值过低会引入无关数据，过高则可能遗漏正确匹配项 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 单份专用设备融资日报的结构化数据量较大，解析耗时较长，300秒可覆盖常规文档的解析需求 |
| `溯源锚定字段` | `出厂序列号` | 出厂序列号为单笔融资记录的唯一标识，可精准关联对应数据，避免设备型号重名导致的溯源错误 |
| `数据源日期筛选规则` | `按放款日期匹配` | 日报数据按每日更新，按放款日期筛选可精准定位对应日期的融资记录，避免跨日数据干扰 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为检索后返回结果仅展示引用链接，无对应融资日报内容。原因是未配置`溯源锚定字段`，或锚定字段选择错误，导致系统无法匹配到结构化数据的具体内容，仅返回数据源文档信息。
- 现象为插件调用后返回`408 Request Timeout`错误。原因是`PARSE_FILE_TIMEOUT_SECONDS`配置值小于实际解析耗时，专用设备融资日报的结构化数据量较大，常规解析时长超过配置阈值导致超时。
- 现象为检索结果中出现非当日的融资记录，且溯源标签混乱。原因是`数据源日期筛选规则`配置为按文档上传日期匹配，未按放款日期匹配，导致跨日数据被错误召回。

## 怎么确认配好了
- 上传单份专用设备融资日报文档，查看解析后的字段列表，确认核心标识字段已被正确识别并提取。
- 输入包含具体出厂序列号的查询词，核对检索结果是否仅返回对应日期的融资记录，确认日期筛选规则生效。
- 调整`相似度阈值`至预设区间，验证检索结果的匹配精度是否符合业务需求，无过多无关结果或遗漏正确项。
- 查看系统日志，确认解析文档的耗时未超过配置阈值，无超时报错记录。
