# 专用设备融资日报的知识库检索与召回

## 这个品类的数据长什么样
专用设备融资日报的数据主要来自行业协会设备采购备案数据、厂商销售台账及金融机构融资租赁放款记录。更新节奏为每日更新，单条日报文档包含设备型号、出厂编号、融资主体名称、放款金额、放款日期、还款周期、设备估值等字段。金额单位为万元，日期格式为YYYY-MM-DD，设备型号字段包含品牌前缀与具体规格参数，部分文档附带设备现场勘验照片的文本标注。

## 这些特征在「知识库检索与召回」这一环带来什么约束
每日更新的数据源要求检索链路支持增量同步配置，避免全量重复拉取导致的资源浪费。多字段且带规格参数的文档结构，要求召回环节优先匹配设备型号、放款日期等核心字段，避免召回非目标设备的融资记录。金额字段的单位一致性要求在预处理阶段统一标准化，防止因单位差异导致的检索偏差。附带的文本标注内容则需要额外开启OCR文本提取配置，确保完整覆盖文档信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 专用设备融资日报文档可能附带较多文本标注，解析耗时较长，600秒可覆盖完整解析流程 |
| `maxContext` | `800–1200 字符` | 单条日报核心信息集中，过长的上下文会引入无关字段，该区间可保留完整核心融资信息 |
| `召回条数` | `前 6–8 条` | 专用设备融资场景下单设备的融资记录分布集中，过多召回会导致上下文冗余 |
| `相似度阈值` | `0.75–0.85` | 需区分同品牌不同型号设备的融资记录，阈值过低会召回无关设备，过高则可能遗漏有效记录 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 单份批量日报文件可能包含多设备条目，允许较大文件避免上传截断 |
| `增量同步触发周期` | `每 24 小时` | 数据源为每日更新的融资日报，同步周期匹配更新节奏确保数据时效性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为配置知识库后调用接口返回418状态码，原因是知识库的字段映射配置未与专用设备融资日报的固定字段匹配，导致解析后文本格式不符合检索链路要求。
- 现象为上传多份日报文件时提示存储空间不足，原因是未调整`UPLOAD_FILE_MAX_SIZE`配置，且未开启知识库的分片上传功能。
- 现象为检索结果未包含当日更新的融资数据，原因是未配置`增量同步触发周期`，仍使用手动同步模式，无法自动拉取每日更新的数据源。

## 怎么确认配好了
- 进入知识库的解析管理页面，查看单份日报文档的解析预览，确认所有预设字段均被正确提取，无格式异常。
- 发起针对特定设备型号的检索请求，核对召回结果的设备型号字段与检索关键词完全匹配。
- 查看增量同步任务的执行日志，确认每日均有新的融资日报文档完成同步。
- 调整相似度阈值与召回条数配置，验证结果的相关性与数量可随配置变化而调整。
