# 个护用品融资日报的工具调用与插件

## 这个品类的数据长什么样
个护用品融资日报的数据来源为全国企业信用信息公示系统、行业协会公开备案的品牌融资信息、电商平台品牌方提交的融资申报数据。更新节奏为每日抓取前一日公开披露的融资事件，当日完成数据整理。单条数据文档结构包含品牌名称、个护细分品类（如洁面、护发、香氛）、融资金额、投资方、融资轮次、披露日期、品牌属地字段，其中融资金额单位为万元人民币，披露日期采用YYYY-MM-DD格式。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据采集的特征要求工具调用时配置多源数据去重参数，避免重复录入同一条融资事件。每日更新的节奏要求定时触发的工具调用周期设为每日，且数据拉取窗口限定为前一日公开披露的信息。字段包含个护细分品类的分类项，需要插件支持按细分品类过滤的参数配置。融资金额统一采用万元为单位，要求工具调用内置单位标准化处理逻辑，确保数据格式一致。披露日期的固定格式要求插件内置格式校验规则，过滤不符合格式的异常数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时任务触发周期` | `每日 02:00` | 匹配个护融资日报每日更新前一日数据的节奏，凌晨拉取可避开业务高峰 |
| `多源数据去重相似度阈值` | `0.85` | 过滤同一条融资事件的重复采集条目，同时保留不同来源的有效差异信息 |
| `数据拉取窗口` | `前1日 00:00至23:59` | 限定仅拉取前一日公开披露的融资信息，符合日报的统计范围 |
| `字段过滤规则` | `仅保留个护细分品类条目` | 聚焦当前细分场景的目标数据，排除其他行业的融资条目 |
| `单位标准化开关` | `开启` | 统一融资金额的单位为万元人民币，避免数据格式混乱 |
| `日期格式校验开关` | `开启` | 确保披露日期符合YYYY-MM-DD格式，过滤异常数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置BI图表插件后，返回的数据源地址为`api.example.com`，无法对接自有个护融资日报数据源。原因：未在插件的`API基础地址`配置项中修改为自有数据源的实际地址。
- 现象：调用`/api/core/dataset/update`接口更新个护融资日报的知识库时返回500状态码，浏览器访问该接口正常。原因：API调用节点未配置正确的`请求身份令牌`，导致服务端校验失败。
- 现象：工作流中调用外部模型生成个护融资日报分析时，无法实现流式输出，仅返回完整分析结果。原因：未开启工作流节点的`流式响应`开关，且未适配外部模型的流式输出参数。

## 怎么确认配好了
- 手动触发一次工具调用，核对拉取的数据是否仅包含个护细分品类的融资条目，确认字段与预设结构一致。
- 检查BI图表插件的数据源地址配置，确认与自有个护融资日报的API地址匹配。
- 调用知识库更新接口，验证返回状态码符合预期，无权限或格式异常提示。
测试工作流的流式输出节点，确认结果按分段返回，完整内容一次性输出。
