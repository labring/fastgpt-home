# 中药融资日报的工具调用与插件

## 这个品类的数据长什么样
中药融资日报的数据主要来源于公开企业融资公告、地方股权交易中心披露信息及行业资讯平台的融资汇总。更新节奏为每日更新，覆盖当日及近3个工作日的中药领域融资项目动态。单篇日报文档包含多条融资条目，每条条目固定包含企业名称、中药细分赛道分类、融资金额、融资轮次、投资方主体、披露日期6个核心字段。融资金额单位统一为万元人民币，融资轮次字段包含天使轮、Pre-A、A轮等标准化分类，企业赛道字段会标注具体中药品类如饮片、中成药、中药创新药等。

## 这些特征在「工具调用与插件」这一环带来什么约束
中药融资日报的每日更新节奏，要求工具调用的定时触发配置需设置为每日固定时段拉取，且缓存过期时间需匹配24小时更新周期，避免返回过期数据。核心字段中融资金额以万元为单位，工具调用参数需添加单位校验规则，防止出现单位转换错误。中药细分赛道的分类字段存在差异化命名，工具调用的字段映射配置需支持自定义匹配，确保能准确筛选饮片、中成药等指定品类。融资轮次的枚举分类固定，可通过工具参数配置枚举值范围，减少无效数据返回。同时单篇文档包含多条融资条目，工具调用的结果分页参数需适配条目数量，避免单次返回数据过载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_call_timeout` | `300 秒` | 中药融资日报的数据拉取涉及多平台接口汇总，300秒可覆盖多数接口响应时长 |
| `tool_filter_fields` | `企业名称,中药赛道,融资金额,融资轮次,披露日期` | 仅保留核心业务字段，减少工具返回冗余数据 |
| `tool_cache_expire` | `86400 秒` | 日报数据每日更新，缓存过期时间匹配更新周期，确保数据时效性 |
| `tool_enum_values` | `天使轮,Pre-A轮,A轮,B轮,C轮,Pre-IPO` | 中药融资常见的轮次分类，限制工具查询范围 |
| `tool_pagination_size` | `前 20 条` | 单篇日报融资条目通常不超过20条，避免返回过多数据影响处理效率 |
| `plugin_request_method` | `GET` | 融资数据接口多为公开只读接口，GET请求符合接口规范 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用中药融资日报插件时返回`400 Bad Request`状态码，日志显示必填字段缺失。原因：未在`tool_filter_fields`参数中配置中药赛道过滤字段，导致接口无法识别指定品类的融资数据请求。
- 现象：父工作流调用子工作流处理融资日报时，子工作流`用户选择`节点后的节点无执行日志。原因：子工作流的`用户选择`节点开启了手动触发模式，父工作流调用时未传递触发参数，导致节点阻塞无法继续执行。
- 现象：配置DeepSeek模型进行工具调用时，界面提示未生成思考内容。原因：未开启`tool_think_output`开关，或FastGPT V4.8.20版本中模型工具调用适配未完成配置。

## 怎么确认配好了
- 手动触发工具调用，查看返回数据的字段是否包含预设的`企业名称`、`中药赛道`等核心字段，确认过滤配置生效。
- 检查工具调用的日志，确认接口响应时长未超过`300 秒`的超时设置，无超时报错记录。
- 触发定时任务，查看次日拉取的数据是否为当日最新的融资日报，确认缓存过期配置生效。
- 测试不同融资轮次的过滤参数，确认返回数据仅包含配置的枚举轮次范围，无无效轮次条目。
