# 中药融资日报的知识库检索与召回

## 这个品类的数据长什么样
中药融资日报的数据来源于沪深北交易所公开披露的上市公司公告、全国股转系统挂牌公司信息、地方金融监管部门的融资备案公示，以及中药行业协会发布的行业融资动态。更新节奏为交易日每日更新，非交易日暂停更新。单条数据文档结构包含企业全称、统一社会信用代码、融资轮次、融资金额（单位多为人民币万元）、投资方名单、融资完成时间、所属中药细分赛道、公告原文链接。字段中会标注企业是否为中药全产业链布局主体，部分数据附带融资方的核心产品品类说明。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散导致不同渠道的字段格式存在差异，部分公告仅提供模糊金额表述，需先完成标准化清洗才能纳入知识库。交易日每日更新的节奏要求知识库配置增量同步任务，避免召回超过24小时的过时数据。字段中包含统一社会信用代码、中药细分赛道等精准标识，要求检索时支持按企业主体、赛道进行过滤召回。模糊金额与精确金额并存的情况，需要调整相似度匹配的权重，优先召回含明确金额的条目。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 中药融资日报的单份公告文档通常不超过10MB，批量上传总大小限制设为500MB可满足单日批量导入需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 部分长公告包含多页财务表格与附件，解析耗时较长，600秒可覆盖绝大多数解析场景 |
| `maxContext` | `800–1200 字符` | 单条中药融资日报的核心信息长度集中在该区间，超出部分会引入冗余内容，降低检索相关性 |
| `召回条数` | `前 8 条` | 中药融资日报的交易日新增条目通常在10条以内，召回8条可覆盖主要融资动态且避免结果过载 |
| `相似度阈值` | `0.72–0.85` | 需区分模糊金额与精确金额的匹配度，阈值过低会引入无关条目，过高则会遗漏部分有效模糊匹配结果 |
| `重排返回条数` | `前 3 条` | 中药融资日报的核心检索需求为最新融资动态，重排后返回前3条可优先展示最相关的结果 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传包含内嵌图片的DOCX文档时，界面返回`400 Bad Request`错误，提示文件格式不正确。原因：未开启知识库解析模块的图片OCR开关，导致内嵌图片无法被提取文本，触发格式校验失败。
- 现象：调用知识库文件列表接口时，返回的`file_list`字段为空数组。原因：未正确配置接口请求的认证头信息，或请求地址未指向对应知识库的部署节点。
- 现象：新建知识库后导入的中药融资日报数据出现核心字段缺失。原因：未按照预设的数据源字段结构整理导入文件，导致必填的融资轮次、金额等字段未被系统识别。

## 怎么确认配好了
- 执行单份含图片的DOCX文档上传测试，确认解析任务无报错。
- 调用知识库文件列表接口，核对返回的文件元信息包含预设的数据源字段。
- 发起核心关键词检索，检查返回结果的条数与预设召回规则匹配。
- 触发手动增量同步，核对同步后知识库新增的条目与当日数据源更新条目一致。
- 尝试批量下载知识库中的文件，确认下载功能正常触发。
