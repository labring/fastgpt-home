# 乳制品融资日报的工作流编排

## 这个品类的数据长什么样
乳制品融资日报的数据来源包括地方金融综合服务平台、乳制品供应链金融服务商的业务系统及行业自律组织的监测数据。数据按自然日更新，于次日汇总生成前一日的全量融资记录。文档以结构化表格形式存储，核心字段包含融资主体全称、融资金额、融资期限、融资用途、放款机构、放款日期、质押物类型，其中融资金额单位为万元，融资期限单位为自然日或自然月，质押物类型多涉及生鲜乳、包装材料、生产设备等乳制品产业链相关物资。

## 这些特征在「工作流编排」这一环带来什么约束
每日固定时段的更新要求工作流需配置定时触发节点，避免重复处理旧数据或遗漏当日新增记录。多来源的结构化数据格式差异，要求工作流内置多格式解析适配模块，兼容CSV、API接口返回及结构化文档的导入。乳制品产业链专属的质押物类型与融资主体分类，要求工作流在数据提取后增加产业链标签匹配环节，确保后续分析的精准性。统一的金额与期限单位规则，要求工作流在数值提取阶段增加单位校验与转换逻辑，避免跨来源数据的单位混乱。批量处理的全量数据量，要求工作流配置合理的分片处理阈值，防止单次任务超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `CRON_EXPRESSION` | `0 30 1 * * ?`（每日凌晨1点30分触发） | 匹配乳制品融资日报T+1更新的节奏，避免与当日业务高峰冲突 |
| `PARSE_FILE_SUPPORTED_TYPES` | `csv,json,xlsx` | 覆盖地方金融平台、供应链服务商的主流导出格式，减少解析失败概率 |
| `FIELD_VALIDATION_RULES` | 融资金额单位统一为万元，融资期限≥1自然日 | 匹配乳制品融资日报的字段数值与单位规则，过滤无效数据与单位混乱的记录 |
| `BATCH_PROCESS_CHUNK_SIZE` | `500 条/分片` | 平衡处理效率与单次任务资源占用，适配乳制品产业链的单日融资记录量级 |
| `HTTP_REQUEST_TIMEOUT` | `600 秒` | 应对多来源数据拉取的网络延迟，避免因超时中断任务 |
| `RETRY_TIMES_ON_FAILURE` | `2 次` | 减少临时网络波动导致的任务失败，避免过度重试占用资源 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流中配置的HTTP请求节点未被执行，或运行时出现`400 Bad Request`、`504 Gateway Timeout`错误，仅执行AI对话环节。原因：未将HTTP请求节点设置为AI对话节点的前置依赖，或未在工作流链路中正确连接节点顺序，导致任务未按预设流程执行。
- 现象：上传的乳制品融资相关图片（如生鲜乳质押照片）被误解析为文本内容，导致质押物字段提取为空。原因：未配置文件类型过滤规则，或文件解析的类型识别优先级未正确设置，导致图片被当作文本文件处理。
- 现象：多节点部署环境下，同一批融资日报数据被多次处理。原因：未配置全局任务锁或分布式队列，导致多个工作流节点同时触发定时任务，重复执行数据拉取与解析流程。

## 怎么确认配好了
- 手动触发一次工作流，检查任务日志中是否包含所有配置的HTTP请求节点的执行记录，确认节点链路执行顺序符合预设要求。
- 上传一份标准的乳制品融资日报文件，检查解析后的字段是否包含预设的核心信息，确认字段校验规则生效。
- 查看工作流的定时触发日志，确认在每日固定时段自动触发任务，无重复执行记录。
- 模拟异常请求场景，检查工作流是否按配置的超时时间与重试规则处理异常情况。
