# 乳制品融资日报的部署与升级

## 这个品类的数据长什么样
乳制品融资日报的数据主要来自地方金融监管局融资备案公示、企业工商年报融资板块、第三方征信机构的企业动态披露端口。数据更新节奏为每日T+1更新，单份日报包含单条或多条乳制品相关企业融资记录。文档结构以结构化表格为主，字段包含企业全称、乳制品细分赛道、融资金额（单位：万元）、融资轮次、投资方主体、披露日期、对接金融机构。部分未公开融资的记录仅包含企业名称与初步融资意向，无明确金额字段。

## 这些特征在「部署与升级」这一环带来什么约束
乳制品融资日报的每日T+1更新节奏，要求部署时配置定时拉取任务的重试机制与批量拉取阈值，适配单日多笔融资记录的拉取规模。部分记录缺失融资金额字段，要求知识库解析时配置字段容错规则，避免空字段导致的检索异常。乳制品细分赛道的分类多样性，要求配置向量召回的赛道字段过滤规则，精准筛选乳制品相关数据。第三方数据源的API鉴权要求，需在工作流节点中配置专属鉴权参数，防止拉取权限不足。本地部署时，pdf格式日报的表格结构复杂，需调整minerU解析的表格识别阈值，避免解析错乱。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 适配乳制品融资日报复杂表格结构的解析耗时需求 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 容纳单批次批量导入的多份结构化日报文件 |
| `maxContext` | `8000–12000 字符` | 完整承载多条融资记录的字段信息与关联内容 |
| `召回条数` | `前 10 条` | 匹配单日乳制品融资记录的常规数量规模 |
| `相似度阈值` | `0.75` | 精准筛选乳制品细分赛道的融资记录，过滤非相关行业数据 |
| `WORKFLOW_HTTP_TIMEOUT` | `30 秒` | 适配第三方数据源API的常规响应时长 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：4.14.4版本中，账号后台配置的启用模型未在工作流节点的模型下拉列表中显示。原因：未在系统配置文件中开启对应模型的工作流可见权限，或未重启服务加载最新配置。
- 现象：勾选增强pdf解析功能后，乳制品日报的表格列对齐错乱，字段提取缺失。原因：未调整minerU的表格识别阈值参数，默认阈值无法适配日报的密集表格布局。
- 现象：工作流http请求节点接收POST请求后，后台接口无法解析上传的body内容。原因：未将body格式设置为application/json，或未正确匹配接口要求的字段结构。

## 怎么确认配好了
- 上传单份乳制品融资日报pdf文件，查看解析结果的表格字段是否完整，无明显错位。
- 触发定时拉取任务，检查工作流日志中是否存在超时或权限报错，确认拉取成功。
- 在知识库检索界面输入乳制品相关关键词，查看召回结果是否仅包含乳制品赛道的融资记录。
- 启动工作流测试节点，发送模拟POST请求，确认后台接口可正常接收并解析json格式的body内容。
