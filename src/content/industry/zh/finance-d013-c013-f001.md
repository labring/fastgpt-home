# 保险融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
保险融资日报的数据来源于保险机构核心业务系统的保单质押交易流水、资金管理系统的融资台账，更新节奏为每日固定时段生成前一自然日的汇总数据。文档采用结构化表格或JSON格式，数据粒度为单保险机构单产品类型的当日融资明细，字段包含报告日期、保险机构编码、保单质押融资金额、当日增减额、产品类型等，单位统一为人民币元，无额外自定义单位字段。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
保险融资日报的细粒度结构化特征，要求HTTP接口需支持按保险机构编码、报告日期、产品类型进行精准过滤，避免返回过量无效数据。固定的更新时段要求接口调用的定时任务需匹配生成时段，防止获取未完成生成的空数据集。金融类数值字段的精度要求，需配置接口的数值校验规则，避免浮点数误差影响业务使用。同时，由于数据属于非银金融敏感信息，接口需额外配置鉴权范围限制，仅允许授权密钥访问该类数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `api_key_permission` | `限定为非银金融数据访问权限` | 保险融资日报属于敏感金融数据，需限制接口密钥的访问范围，避免数据泄露 |
| `request_timeout` | `30 秒` | 保险融资日报的汇总数据生成需一定处理时长，30秒可覆盖多数正常调用场景，避免请求提前中断 |
| `max_return_items` | `前 1000 条` | 保险融资日报的单批次数据量有限，限制返回条目可降低接口响应耗时 |
| `date_format_strict` | `强制使用 YYYY-MM-DD 格式` | 保险融资日报的日期字段格式固定，严格校验可避免无效查询 |
| `numeric_precision` | `保留两位小数` | 金融类数据需符合人民币计价的精度规范，避免数值误差 |
| `rate_limit` | `100 次/分钟` | 保险融资日报更新频率为每日一次，过高的调用频率无实际业务价值，同时可降低服务器负载 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用`api/core/datas`接口创建知识库集合时，返回`400 Bad Request`错误，提示字段格式不匹配。原因是未将保险融资日报的`policy_pledge_amount`字段的类型映射为数值型，误配置为字符串类型，导致数据校验失败。
- 定时通过HTTP接口拉取保险融资日报时，连续返回空数据。原因是轮询请求的发起时间早于日报每日固定生成的时段，获取到未完成生成的空数据集。
- 调用HTTP接口时返回`504 Gateway Timeout`错误。原因是未配置合理的`request_timeout`参数，请求等待时长不足导致超时。

## 怎么确认配好了
- 发起单条指定保险机构编码与报告日期的HTTP查询请求，核对返回字段的名称、格式是否与保险融资日报的预设结构一致。
- 配置拉取任务，将发起时段设置为晚于日报生成完成的固定时间，核对返回数据是否包含有效业务数值。
- 调用知识库集合创建接口导入测试数据，核对导入后的字段类型是否与配置的映射规则匹配。
- 查看接口调用日志，确认所有请求的鉴权参数均通过校验，未返回鉴权相关错误状态码。
