# 保险融资日报的部署与升级

## 这个品类的数据长什么样
保险融资日报的数据来自保险机构内部承保系统、合作银行的融资放款台账，以及监管报送的备案数据。更新节奏为每日凌晨批量同步前一自然日的业务数据。单份日报文档以承保主体为分组维度，包含保单编号、融资金额、到期还款日、承保险种类型、实际偿付进度等字段，其中金额字段统一使用人民币元为单位，日期字段遵循YYYY-MM-DD格式。

## 这些特征在「部署与升级」这一环带来什么约束
保险融资日报的数据多源异构、按承保主体分组且包含强校验字段的特征，对部署与升级环节带来明确约束。部署阶段需提前配置多数据源对接适配，兼容承保系统、银行台账、监管数据的不同接口格式。升级阶段需保留原有字段映射规则，避免因字段格式调整导致日报数据解析失败。同时需适配每日批量同步的节奏，配置定时任务的重试机制与超时阈值，防止凌晨同步窗口内的数据源波动引发任务中断。还需适配按承保主体分组的业务逻辑，配置向量召回的聚合策略，确保后续检索结果符合业务分组要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 保险融资日报多为批量结构化文档，单份解析耗时较长，该时长可避免提前超时中断任务 |
| `RECALL_TOP_K` | `15` | 日报包含多维度关联字段，需召回足够数量的关联数据以支撑业务检索 |
| `SIMILARITY_THRESHOLD` | `0.75` | 保险业务数据字段关联性较强，过高阈值会过滤有效关联结果，过低则引入无关信息 |
| `PARSE_CHUNK_SIZE` | `800–1200 字符` | 日报包含金额、日期等结构化字段，分段过长会破坏字段关联逻辑，过短则增加检索冗余 |
| `DATA_SYNC_CRON` | `0 0 3 * * ?` | 适配每日凌晨3点同步前一日业务数据的节奏，避开业务高峰时段 |
| `AI_PROXY_ENABLED` | `按部署环境标定` | 部分部署环境可直接对接OneAPI，无需额外启动AI代理，可降低资源占用 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：部署升级后调用接口返回`403 Forbidden`错误，无法通过OneAPI直接对接模型。原因：未正确配置`AI_PROXY_ENABLED`参数，新版本默认启用AI代理，需调整参数或同步配置代理地址。
- 现象：自部署版本v4.15.1中，部分保险融资日报文档无法识别内嵌图片，检索时无法命中图片内的保单编号信息。原因：未开启图片解析插件或未配置`PARSE_IMAGE_ENABLED`参数的正确取值，导致含图片的文档解析不完整。
- 现象：使用vllm本地部署模型时，对话返回结果中`reasoning`字段为空，无法展示思考过程。原因：未开启vllm的流式输出配置，或未在模型调用参数中启用对应开关，导致思考内容未被正确捕获。

## 怎么确认配好了
- 执行一次手动同步任务，核对日志中是否存在数据源连接异常、字段格式不匹配的报错信息，确认多数据源对接配置正常。
- 上传一份标准保险融资日报文档，检查解析后的字段是否完整匹配预设映射规则，确认分段与解析参数配置符合业务数据特征。
- 发起一次业务检索请求，查看返回结果的召回数量与关联匹配度，根据实际检索需求调整对应配置项。
- 等待次日凌晨的定时同步任务执行完成，核对数据库中生成的日报数据是否覆盖前一自然日的业务范围，确认定时任务配置正确。
