# 储能融资日报的工作流编排

## 这个品类的数据长什么样
储能融资日报的数据主要来自地方能源主管部门的项目融资备案公示、国内储能行业投融资数据库的每日更新、电力设备厂商的公开项目披露。更新节奏为每日凌晨完成前一日数据的汇总与校验。单条数据为结构化条目，包含项目编号、储能装机容量（单位：MW）、融资金额（单位：万元人民币）、投资方主体、落地区域、备案日期、融资完成日期7个核心字段，部分条目会补充政策补贴额度、项目建设周期字段。

## 这些特征在「工作流编排」这一环带来什么约束
多源异构的数据来源要求工作流配置多并行拉取节点，适配不同数据源的接口鉴权与分页规则。每日更新的节奏要求工作流触发周期设为每日固定时段，且需配置增量拉取逻辑，仅同步前一日新增条目，避免重复处理历史数据。储能项目的装机容量、融资金额带有明确单位，工作流的字段抽取节点需配置单位标准化规则，将不同来源的非统一单位转换为标准格式。部分条目缺失核心字段，需配置字段校验分支，对缺失关键信息的条目执行跳过或标记异常的处理逻辑。融资完成日期与备案日期存在时序约束，需在工作流中加入日期合法性校验节点，拦截时序异常的条目。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `CRON 表达式` | `0 0 0 * * *` | 匹配每日凌晨的更新节奏，适配储能融资日报的每日发布周期 |
| `数据源并发上限` | `2–4 个` | 多源拉取时避免超出第三方接口的速率限制，同时保证拉取效率 |
| `字段标准化规则` | `将融资金额统一转换为万元单位，将装机容量统一转换为MW单位` | 储能融资日报的核心字段带有非统一单位，需标准化后用于后续分析 |
| `增量同步开关` | `开启` | 仅同步前一日新增条目，避免重复处理历史数据，降低工作流运行负载 |
| `工具调用后处理脚本` | `按实测标定` | 需针对抽取的融资信息字符串执行特定字段抽取，适配工具调用结果不稳定的场景 |
| `节点超时时间` | `600 秒` | 多源拉取与字段校验的总耗时需控制在合理范围，避免工作流超时中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：开启知识库插件的问题优化后，即使在最终回答插件中关闭，工作流调用时仍触发优化逻辑。原因：未在工作流的独立知识库节点中单独关闭优化开关，全局配置覆盖了节点级设置。
- 现象：工具调用节点返回结果格式混乱，或抽取的目标字段为空。原因：未配置工具调用后的后处理脚本，未对返回的字符串执行格式校验与特定字段抽取。
- 现象：嵌入业务系统后，工作流无法识别业务用户身份，请求被拦截。原因：未在发起工作流的HTTP请求中携带用户身份标识参数，工作流未配置身份校验分支。

## 怎么确认配好了
- 查看工作流的`CRON 表达式`配置项，确认触发时间与储能融资日报的更新节奏匹配。
- 运行一次测试工作流，检查多源拉取的数据源是否全部正常返回数据，字段是否完成标准化转换。
- 模拟业务系统发起HTTP请求，携带用户身份标识参数，确认工作流能正确接收并校验身份。
- 触发工具调用节点，检查后处理脚本是否能正确抽取目标字段，返回结果符合预期格式。
