# 光伏融资日报的工具调用与插件

## 这个品类的数据长什么样
光伏融资日报的数据主要来自地方能源局项目备案公示、国内光伏电站开发企业公开披露信息、第三方电力设备行业数据服务机构。数据更新节奏为每日更新，覆盖当日完成备案或放款的分布式光伏、集中式光伏项目。单份日报文档结构包含项目备案编号、装机容量（单位MWp）、融资额度（单位万元）、项目所在地、投资方主体、合作放款银行、实际放款日期等标准化字段，部分项目会附带备案批复文件扫描件或融资协议摘要。

## 这些特征在「工具调用与插件」这一环带来什么约束
每日更新的数据源要求工具调用需配置每日定时触发逻辑，并通过项目备案编号作为唯一标识实现增量拉取，避免重复处理历史数据。标准化字段包含带单位的装机容量与融资额度，工具调用时需内置单位校验规则，防止跨品类的单位混淆。部分项目附带备案批复扫描件，工具需支持对远程附件URL的下载与解析，同时需处理不同来源附件格式差异带来的解析异常。多数据源的字段映射需求，要求插件配置支持自定义字段匹配规则，适配不同数据服务商的输出格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `request_timeout` | `60 秒` | 光伏融资日报的接口响应通常在30秒内，设置60秒可覆盖网络波动与附件下载场景 |
| `incremental_sync_key` | `project_record_id` | 光伏融资日报的项目备案编号为唯一稳定标识，可用于增量拉取去重 |
| `max_attachment_size` | `10 MB` | 光伏备案批复扫描件单文件大小通常不超过5 MB，设置10 MB可覆盖合规上传范围 |
| `field_mapping_config` | 按实测标定 | 不同数据服务商的字段命名存在差异，需根据实际数据源调整映射关系 |
| `schedule_cron` | `0 8 * * *` | 光伏融资日报通常在每日早8点前更新，设置每日8点触发可匹配数据源更新节奏 |
| `attachment_parse_enabled` | `开启` | 部分光伏项目融资日报附带备案扫描件，需启用附件解析以提取关键信息 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用接口返回`Failed to fetch`错误，且日志显示无法下载附件。原因是未配置`max_attachment_size`参数或取值过小，导致大尺寸的光伏备案扫描件无法完成下载。
- 拉取的数据出现重复条目。原因是未设置`incremental_sync_key`参数，或使用了非唯一标识作为同步键，导致无法正确去重历史数据。
- 解析后的字段出现单位混淆，如将装机容量的`MWp`识别为`kW`。原因是未配置`field_mapping_config`中的单位校验规则，直接复用了其他品类的字段映射配置。

## 怎么确认配好了
- 手动触发一次插件调用，查看返回结果中是否包含当日最新的光伏项目融资信息，核对项目备案编号是否与数据源公示内容一致。
- 检查插件配置中的附件解析开关状态，上传一份光伏备案扫描件测试，确认解析后的文本内容可被正常读取。
- 等待一个完整的定时触发周期后，查看拉取的数据列表，确认无重复的项目备案编号条目。
- 调用工具获取单条数据的字段详情，核对装机容量、融资额度的单位是否与数据源标注一致。
