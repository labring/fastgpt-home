# 光学光电子融资日报的工作流编排

## 这个品类的数据长什么样
光学光电子领域的融资日报数据主要来自沪深北交易所公开披露的上市公司公告、行业自律组织的月度统计公示及券商公开研报。数据每日在当日交易结束后统一更新，单份日报文档包含企业全称、证券代码、融资方式、融资金额、披露日期、投资方主体、所属细分赛道共7项核心字段，金额单位统一为万元，日期格式为YYYY-MM-DD，附带原始公告的在线链接。

## 这些特征在「工作流编排」这一环带来什么约束
每日更新的数据源要求工作流需配置固定时段触发，避免提前抓取未完成披露的信息。多源数据存在重复条目，需配置数据去重节点过滤冗余内容。核心字段包含证券代码与细分赛道，需设置分类筛选规则，仅保留光学光电子赛道的融资条目。附带的原始公告链接需绑定到结果中，支持后续原文档预览调用。金额字段以万元为单位，需配置单位校验节点，避免混入其他品类的计量数据导致格式异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时任务 cron 表达式` | `0 18 * * *` | 匹配国内证券市场当日交易结束后的更新时段，避免抓取未披露数据 |
| `数据去重匹配字段` | `企业全称+披露日期` | 过滤同企业同日发布的重复融资公告条目 |
| `拉取条目上限` | `前15条` | 光学光电子赛道每日融资披露数量有限，无需拉取过多冗余内容 |
| `原文件链接绑定开关` | `开启` | 关联原始公告链接，支持后续原文档在线预览调用 |
| `字段格式校验规则` | `金额字段强制校验为万元单位` | 匹配品类数据统一的金额计量标准，避免格式异常 |
| `节点超时时间` | `600 秒` | 适配多源数据拉取与清洗的耗时需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用节点执行后直接停止，无返回结果。原因：未配置数据源的访问权限白名单，导致工作流无法拉取交易所公开数据。
- 现象：生成的分享链接指向本地地址。原因：部署环节未配置公网访问域名，仅保留默认本地端口配置。
- 现象：无法调用原文件在线预览功能。原因：未在工作流中绑定原始公告链接字段，仅导入了清洗后的结构化数据。

## 怎么确认配好了
- 手动触发工作流，验证返回结果是否匹配预设的光学光电子赛道筛选条件。
- 查看工作流运行日志，确认定时任务按配置的时段执行，无节点超时或报错记录。
- 检查结果字段的格式，确认金额单位符合品类统一标准，无异常内容。
- 测试结果中的链接跳转，确认可正常访问原始公告页面。
