# 光学光电子融资日报的知识库检索与召回

## 这个品类的数据长什么样
光学光电子融资日报的数据来源于行业自律组织的公开披露数据库、上市/挂牌公司公告、专业财经资讯平台的结构化提取。数据更新频率为每日T+1更新前一日的融资交易信息，文档多为结构化Excel格式，包含固定表头字段，主要字段包括融资主体名称、所属细分赛道、融资轮次、融资金额、融资金额单位、投资方名单、融资完成日期、披露媒体来源，单位多为人民币万元，部分跨境融资项目会标注外币单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
结构化的固定字段要求检索时需匹配特定字段，需避免全文模糊检索，否则会混入无关的非融资类信息。每日增量更新的特性要求配置增量索引同步逻辑，避免全量重建索引带来的资源消耗与延迟。单份文档包含10000+行数据，若未合理拆分文档块，会导致召回内容超出大模型上下文窗口限制。字段包含多种单位的融资金额，若未在预处理阶段统一单位，会出现数值与单位不匹配的检索错误，影响匹配精度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | 800–1200 字符 | 光学光电子融资日报单条结构化数据的字段组合长度适中，该区间可覆盖单家企业的完整融资信息，同时避免单块过大导致的上下文溢出 |
| `召回条数` | 前 3–5 条 | 融资日报的检索需求多为精准匹配特定企业或轮次，过多召回会引入无关数据，过少则可能遗漏有效信息 |
| `相似度阈值` | 0.75–0.85 | 结构化数据的字段匹配精度要求较高，阈值过低会引入错误匹配，过高则可能无法召回有效结果 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 单份10000+行的Excel文件解析耗时较长，300秒可保证完整解析无超时 |
| `增量同步开关` | 开启 | 融资日报为每日更新的增量数据，开启增量同步可减少索引重建的资源消耗，提升更新效率 |
| `单位统一预处理` | 开启 | 融资金额字段包含多种单位，预处理阶段统一为万元可避免检索时的单位不匹配问题 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：检索结果中显示「引用标记：［1］」字样。原因：未关闭知识库检索结果的引用标记输出配置，导致大模型生成内容时自动拼接了源数据的引用标识。
- 现象：单份10000+行的Excel文件解析失败，任务状态显示超时。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时间不足，无法完成大规模结构化文件的解析。
- 现象：检索召回的内容块超出大模型上下文窗口限制，出现截断或报错。原因：未设置合理的`分段长度`参数，直接上传完整Excel文件未拆分文档块，导致单块内容过长。

## 怎么确认配好了
- 上传单份1000行以内的测试Excel文件，查看解析后的文档块长度，调整`分段长度`参数至符合预期的块大小。
- 发起包含特定融资主体、融资轮次的测试提问，核对召回结果的条数是否符合配置的`召回条数`参数。
- 检查知识库的同步日志，确认每日增量更新任务是否自动触发并完成。
- 查看解析后的字段信息，确认融资金额的单位已统一为标准单位。
