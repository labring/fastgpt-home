# 光学光电子融资日报的部署与升级

## 这个品类的数据长什么样
光学光电子融资日报的数据来源为沪深北交易所、全国中小企业股份转让系统的公开融资公告，以及行业第三方数据平台的公开汇总。更新节奏为每个交易日收盘后更新当日披露的融资事件，非交易日顺延至下一交易日更新。文档为结构化格式，单条记录包含`证券代码`、`证券简称`、`融资主体`、`投资方机构`、`融资金额`、`融资轮次`、`披露日期`、`公告链接`字段。融资金额以人民币万元为单位，部分大额融资会标注亿元，`证券代码`需匹配交易所编码规则。

## 这些特征在「部署与升级」这一环带来什么约束
多源数据的格式差异要求配置多数据源的解析适配规则，避免因公告格式不统一导致数据丢失。交易日更新的特性要求定时任务调度绑定交易所交易日历，不使用自然日周期，防止非交易日生成无效数据。结构化字段的单位与编码规则要求在数据预处理环节配置统一转换与校验逻辑，确保`融资金额`、`证券代码`等字段格式一致。公告链接的可访问性要求配置超时重试机制，避免因链接失效导致文档解析失败。升级时需同步更新行业分类标签库，确保融资事件的赛道分类匹配多数机构采用的最新行业分类标准。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 光学光电子融资日报的单篇公告内容通常在1000-2000字符，300秒的超时时间足够完成解析，避免短内容触发过长等待 |
| `召回条数` | `前 8 条` | 该品类单日融资事件数量通常在5-15条，召回8条可覆盖当日全部有效融资信息，避免遗漏关键数据 |
| `相似度阈值` | `0.75–0.85` | 融资日报的关键词匹配需兼顾准确性与召回率，该区间可过滤无关的行业资讯，保留与光学光电子直接相关的融资内容 |
| `分段长度` | `1000–1200 字符` | 单篇融资公告的核心信息集中在1000字符左右，该分段长度可保证关键信息不被拆分，提升检索准确性 |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 单份融资日报汇总文件通常不超过20 MB，预留足够空间应对批量上传与临时缓存场景 |
| `SCHEDULE_CRON_EXPRESSION` | `0 18 * * 1-5` | 适配沪深北交易所交易日（周一至周五），在每日收盘后触发数据同步任务，避免非交易日生成无效数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：对话时频繁出现`Request Timeout`报错，状态码504。原因：未针对光学光电子融资日报的公告链接配置超时重试机制，当公告链接响应缓慢时直接触发超时。
- 现象：知识库召回的融资信息包含非光学光电子领域的内容。原因：`相似度阈值`设置过低，导致无关行业的融资资讯被误召回。
- 现象：非交易日生成了融资日报数据。原因：定时任务的Cron表达式使用了自然日周期，未绑定交易所交易日历，导致周末、节假日生成无效数据。
