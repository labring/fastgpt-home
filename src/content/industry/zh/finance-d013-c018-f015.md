# 光模块融资日报的部署与升级

## 这个品类的数据长什么样
光模块融资日报的数据来源为公开企业融资公告、行业投融资信息平台及供应链上下游披露的光模块相关融资动态。更新节奏为每日更新当日披露的融资事件，单条数据包含厂商名称、融资轮次、融资金额、投资方、披露日期、对应光模块产品规格、应用场景等字段。融资金额单位为人民币万元或亿元，披露日期采用YYYY-MM-DD格式，产品规格以数字加G标识。

## 这些特征在「部署与升级」这一环带来什么约束
每日更新的特性要求部署时配置的定时拉取任务需匹配每日更新节奏，否则无法覆盖当日最新融资事件。光模块产品规格的细分字段要求在数据解析环节需配置关键词过滤，避免将其他通信品类的融资数据混入。多数据源的字段命名差异要求部署时配置统一的字段映射规则，确保核心信息的一致性。融资金额的单位混用情况要求在数据清洗环节增加自动转换逻辑。升级时需兼容新增的光模块产品规格对应的解析规则，避免新披露的融资数据无法被正确识别。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `SYNC_CRON` | `0 0 1 * * *` | 匹配光模块融资日报的每日更新节奏，确保每日拉取最新披露的融资事件 |
| `PARSE_KEYWORD_WHITELIST` | `100G,400G,800G,1.6T,光模块` | 过滤非光模块品类的融资数据，仅保留对应规格的光模块相关融资条目 |
| `FIELD_MAPPING_CONFIG` | 按接入数据源的实际字段配置 | 不同投融资平台的字段命名存在差异，需映射厂商名称、融资金额等核心字段 |
| `AMOUNT_UNIT_AUTO_CONVERT` | 开启 | 统一融资金额的单位格式，避免出现万元与亿元混用的情况 |
| `PARSE_TIMEOUT_SECONDS` | `600 秒` | 覆盖光模块融资日报的常规解析时长，防止因数据量波动导致解析中断 |
| `ONEAPI_CHANNEL_ENABLE` | 按实际接入的大模型配置 | 确保OneAPI页面显示已配置的大模型渠道，支持融资日报的问答分析 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为部署完成后，OneAPI渠道列表为空，无法选择对应大模型。原因是未开启`ONEAPI_CHANNEL_ENABLE`配置项，或未配置对应大模型的接入密钥。
- 现象为无法找到官方docker离线部署包，部署流程中断。原因是未在部署包管理页面下载对应版本的离线镜像包，或未正确配置离线部署的镜像加载路径。
- 现象为版本4.8.20接入grok-3时，测试环节提示错误，但引用后可正常运行。原因是测试接口与实际调用接口的参数校验逻辑存在差异，测试环节触发了额外的参数校验限制。

## 怎么确认配好了
- 查看定时同步任务的执行日志，确认每日是否成功拉取到光模块融资数据，核对拉取的条数是否符合预期。
- 进入OneAPI渠道管理页面，确认已配置的大模型渠道是否显示在列表中，检查配置的密钥是否有效。
- 随机抽取一条融资数据，查看解析后的字段是否完整匹配预设的映射规则，确认单位转换是否生效。
- 触发一次手动解析测试，确认解析流程未出现超时或格式错误。
