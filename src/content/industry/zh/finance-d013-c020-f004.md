# 兵器装备融资日报的向量模型与索引

## 这个品类的数据长什么样
兵器装备融资日报的数据来源于军工行业公开披露渠道，包括兵器装备集团官方公告、证券交易所挂牌信息、专业军工投融资平台的公开数据。更新节奏为每日一次，于当日交易收盘后完成当日披露事件的汇总整理。单份日报文档以结构化表格为主体，附带单条融资事件的详情说明，核心字段包括标的名称、所属兵器装备子板块、融资轮次、融资金额、投资方主体、披露日期、公告来源链接，其中融资金额需标注单位以区分万元与亿元。

## 这些特征在「向量模型与索引」这一环带来什么约束
每日固定增量更新的特性要求索引支持轻量化的增量写入，避免全量重建带来的计算资源浪费。结构化与非结构化文本混合的内容结构，需要同时支持向量嵌入与元数据过滤的结合使用，以满足按特定维度筛选的需求。融资金额的单位差异可能导致元数据匹配偏差，需在索引前统一单位格式。披露日期作为核心时间维度，要求索引支持按时间范围快速筛选，以匹配用户按周期查询的使用习惯。此外，跨渠道转引的融资事件可能存在重复内容，需要索引具备基础的去重能力。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `incremental_index` | `开启` | 融资日报为每日增量更新，全量重建索引会占用大量计算资源，增量写入可匹配更新节奏 |
| `chunk_size` | `800–1200 字符` | 单条融资事件的文本描述长度多在该区间，过长会导致向量嵌入失真，过短则丢失上下文关联 |
| `chunk_overlap` | `50–80 字符` | 保留相邻分段的上下文关联，防止关键信息在分段时断裂 |
| `similarity_top_k` | `前8–12条` | 单日披露的有效融资事件数量有限，过多召回会引入无关数据，过少则无法覆盖潜在关联信息 |
| `score_threshold` | `0.80–0.87` | 过滤跨渠道转引的重复融资事件，同时保留不同来源的合理文本差异 |
| `metadata_fields` | `["标的名称", "披露日期", "融资金额单位", "融资轮次"]` | 这些字段是用户筛选融资信息的核心维度，纳入元数据索引可加速精准查询 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：索引中出现多条完全一致的融资事件记录，或召回结果中重复出现同一标的的融资信息。原因：未开启增量索引的去重逻辑，或未设置合理的相似度阈值过滤重复嵌入向量。
- 现象：调用向量模型时返回`401 Unauthorized`错误码，无法完成嵌入任务。原因：未正确配置向量模型的API密钥，或密钥权限不足，或使用了过期的密钥。
- 现象：自定义切分的文档块顺序与最终召回的索引顺序不一致，出现内容错位。原因：未保留原始文档块的顺序标识，或自动去重功能打乱了原始分段的排列逻辑。

## 怎么确认配好了
- 上传单条测试融资日报数据，查看知识库解析后的分段结果，确认分段长度与设置的`chunk_size`匹配。
- 发起两次相同的融资事件查询，对比召回结果的重复情况，调整`score_threshold`直至重复内容被合理过滤。
- 查看索引更新日志，确认每日增量更新任务正常触发，无异常的全量重建日志记录。
- 配置元数据过滤条件，筛选特定标的或日期的融资信息，确认召回结果仅包含符合条件的条目。
