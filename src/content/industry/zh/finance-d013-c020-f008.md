# 兵器装备融资日报的工具调用与插件

## 这个品类的数据长什么样
兵器装备融资日报的数据来源为国防科工局公开备案信息、兵器装备集团官方公告、军工行业合规披露平台及上市公司定期报告。数据每日更新，覆盖当日披露的兵器装备领域各类融资项目。单篇文档包含融资主体全称、所属子品类、融资类型、融资金额、披露日期、审批单位、关联项目编号等字段，融资金额单位统一为万元人民币，披露日期采用ISO 8601标准格式，部分涉密项目会隐去敏感字段仅保留合规披露信息。

## 这些特征在「工具调用与插件」这一环带来什么约束
兵器装备融资日报的多源公开数据包含涉密隐字段、固定字段格式与专属分类逻辑，对工具调用与插件环节带来三项核心约束。其一，需配置字段过滤规则，自动隐去未授权披露的敏感信息，避免合规风险。其二，因数据每日更新，插件的定时拉取任务需设置为每日触发，且需校验最新披露日期的时间戳，避免重复拉取旧数据。其三，专属子品类字段要求插件支持按兵器装备细分赛道筛选参数，需预先配置分类映射表，确保调用时的精准匹配。同时，固定的金额单位要求插件内置格式转换逻辑，统一输出为万元人民币格式，适配下游分析需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时拉取周期` | `每日 00:30` | 数据每日更新，合规披露数据多在当日凌晨完成备案，提前30分钟拉取可覆盖当日最新数据 |
| `敏感字段过滤规则` | 隐去涉密主体编号、未公开融资金额细节 | 数据包含涉密备案字段，需符合军工信息披露合规要求 |
| `数据分类映射配置` | 按兵器装备子品类映射为预设标签 | 数据包含专属子品类字段，需统一分类逻辑适配下游调用 |
| `单位统一转换开关` | `开启并固定为万元人民币` | 融资金额字段统一采用万元单位，需避免格式混乱 |
| `重复数据去重阈值` | `1 天` | 数据为日报格式，单日数据无重复，超过1天的重复数据可判定为冗余 |
| `插件输入参数校验` | 仅允许按披露日期、子品类筛选 | 核心调用场景为按时间或赛道查询融资信息，需限制无效参数输入 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：使用curl调用插件时返回`400 Bad Request`，报错包含`The dollar ($) prefixed field '$schema'`字样。原因：请求体中未正确转义`$schema`字段，或传入了未在插件配置中定义的带$前缀的自定义参数。
- 现象：无法在系统界面查询到插件的历史调用记录。原因：未开启`调用日志存储`配置项，或日志保留时长设置小于数据更新周期。
- 现象：插件返回的融资数据字段缺失或格式混乱。原因：未配置`敏感字段过滤规则`，或未开启`单位统一转换开关`，导致涉密字段或非标准单位数据被直接返回。

## 怎么确认配好了
- 执行手动插件调用，传入预设的披露日期与兵器装备子品类参数，核对返回结果的字段与格式是否符合配置要求。
- 查看系统的调用日志模块，确认本次手动调用的记录已被正常生成并存储。
- 启动定时拉取任务的测试触发，检查目标数据源中是否生成了符合当日披露范围的融资数据条目。
- 传入包含`$schema`字段的测试请求，确认系统返回的错误提示符合参数校验规则，无未处理的异常格式问题。
