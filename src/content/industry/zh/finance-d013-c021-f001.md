# 其他综合融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
其他综合融资日报的数据来源涵盖地方金融综合服务平台、企业内部融资台账汇总及第三方合规征信聚合渠道。更新节奏为每日更新，于当日22点前完成当日全量数据汇总。单条数据文档结构包含主体统一社会信用代码、融资主体名称、融资总规模、融资期限、融资用途分类、报送机构标识6个核心字段，金额单位为万元，期限单位为自然日，无嵌套子字段。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
数据多源接入的特征要求接口支持多套鉴权凭证配置，适配不同来源的API密钥校验规则。每日T+1更新的节奏要求接口拉取超时阈值设置为不低于300秒，避免全量数据拉取超时中断。字段包含统一社会信用代码的要求，要求接口请求参数需支持传入该字段作为匹配标识，避免不同融资主体的数据混淆。金额单位为万元的特征，要求接口返回字段需明确标注单位，或默认统一使用万元作为返回单位，无需外部系统额外转换。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `api_auth_type` | `api_key + signature` | 适配多源接入的鉴权需求，满足不同数据来源的校验规则 |
| `pull_timeout_seconds` | `300 秒` | 匹配每日全量数据拉取的耗时要求，避免超时中断 |
| `request_match_field` | `统一社会信用代码` | 基于数据字段特征，实现融资主体的精准匹配 |
| `return_amount_unit` | `万元` | 匹配数据原生单位，减少外部系统的单位转换成本 |
| `multi_source_credential_switch` | `开启` | 适配多渠道数据接入的配置需求 |
| `duplicate_data_filter` | `开启` | 避免多源接入时出现重复数据记录 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用接口上传关联的融资日报附件时，文件名含中文时返回`400 Bad Request`错误，或文件名在外部系统接收后显示为乱码。原因：未在HTTP请求头中设置`Content-Type`为`multipart/form-data; charset=utf-8`，导致中文文件名的编码未正确传递。
- 现象：调用拉取接口返回`401 Unauthorized`，且已在配置中填入`api_key`参数。原因：未同时配置对应数据来源的签名校验参数，或签名生成逻辑未匹配接入渠道的鉴权规则。
- 现象：每日定时拉取任务频繁返回`504 Gateway Timeout`错误。原因：拉取超时阈值设置过低，无法覆盖全量融资日报数据的拉取耗时。

## 怎么确认配好了
- 发起单次拉取请求，检查返回数据的核心字段是否与预设的`request_match_field`参数匹配，确认数据关联逻辑生效。
- 上传含中文文件名的测试附件，检查接口返回状态码为`200 OK`，且文件名在返回结果中无乱码。
- 配置定时拉取任务，等待一个完整更新周期后，检查外部系统接收的数据量与当日融资日报的全量数据量一致，无遗漏或重复记录。
- 使用无效的`api_key`发起鉴权请求，确认返回`401 Unauthorized`状态码，验证鉴权配置正常生效。
