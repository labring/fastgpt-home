# 军工电子融资日报的工具调用与插件

## 这个品类的数据长什么样
军工电子融资日报的数据来源为军工行业公开信息披露平台、证券交易所指定公告平台、行业协会公开数据集。更新节奏为每日更新，覆盖前一工作日发生的融资事件。文档采用结构化表格形式，包含披露日期、企业统一社会信用代码、企业名称、融资轮次、融资金额、投资方名单、公告文号、信息来源链接等字段。字段单位方面，融资金额以万元为单位，披露日期采用YYYY-MM-DD格式，统一社会信用代码为18位字符格式。

## 这些特征在「工具调用与插件」这一环带来什么约束
军工电子融资日报的多字段属性与每日更新节奏，对工具调用与插件提出多项约束。披露日期与统一社会信用代码的标准化字段要求，插件需要配置字段校验规则，过滤无效的企业标识与错误格式的日期数据。每日更新的节奏要求插件的定时拉取任务设置为每日触发，且需要实现增量数据比对逻辑，避免重复处理已归档的融资事件。融资金额以万元为单位的固定格式，要求工具调用时对传入的金额参数做单位校验，防止出现单位转换错误导致的数据异常。不同来源的公开数据可能存在字段命名差异，插件需要配置标准化映射规则，将各渠道的字段统一为预设的标准格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_fetch_schedule` | `0 0 1 * * *`（每日凌晨1点触发） | 匹配军工电子融资日报每日更新的节奏，在数据发布后第一时间拉取最新内容 |
| `field_mapping_config` | 按军工电子融资日报标准字段映射 | 适配多来源数据的字段命名差异，将各渠道数据统一为披露日期、企业名称、融资金额等标准格式 |
| `amount_unit_validation` | `开启` | 依据融资金额固定以万元为单位的要求，校验传入的金额参数单位，避免数据异常 |
| `incremental_data_sync` | `开启` | 减少重复数据处理，适配每日增量更新的融资日报特征 |
| `enterprise_code_check` | `开启` | 校验统一社会信用代码的合法性，过滤无效的军工电子企业融资数据 |
| `plugin_request_timeout` | `300 秒` | 适配单条融资事件数据量较小的特征，设置合理超时阈值 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用工具时返回`400 Bad Request`错误。原因：未按要求传入标准化的统一社会信用代码字段，或融资金额参数未标注万元单位，触发接口校验拦截。
- 工具返回的融资事件存在重复条目。原因：未开启增量同步配置，或拉取计划设置间隔短于数据更新周期，导致重复拉取已处理的数据。
- 工具调用的输出内容未在聊天窗口隐藏。原因：未开启工具调用输出隐藏配置，或配置项未正确关联当前插件任务。

## 怎么确认配好了
- 手动触发一次插件拉取任务，查看拉取到的融资事件字段是否包含披露日期、企业名称、融资金额、公告链接等标准字段，确认字段映射配置生效。
- 模拟传入不符合万元单位的融资金额参数，检查工具是否返回校验失败的提示，确认金额单位校验配置生效。
- 连续两天触发拉取任务，检查第二天拉取的事件是否包含第一天已处理的条目，确认增量同步配置生效。
- 查看插件运行日志，确认拉取任务按预设的每日计划触发，确认拉取计划配置生效。
