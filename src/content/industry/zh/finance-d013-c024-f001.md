# 农化制品融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
农化制品融资日报的数据来源包括全国企业信用信息公示系统、地方金融监管局备案信息、行业媒体公开报道。更新节奏为每个工作日更新当日披露的农化制品相关融资事件，非工作日临时披露的内容会在次工作日补更。单条数据的文档结构包含融资主体名称、融资方式、融资金额、投资方、融资发生日期、所属农化细分品类、原始披露链接等字段。融资金额统一以人民币万元为单位，日期格式为YYYY-MM-DD，数据按披露时间倒序排列，无额外聚合处理。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
农化制品融资数据的细分品类属性要求接口支持按品类过滤的参数，外部系统对接时需配置对应过滤规则，避免混入其他行业数据。数据仅在工作日更新，外部系统的定时拉取任务需适配工作日调度，避免非工作日拉取到空数据集。融资金额以万元为单位，外部系统在数据存储、展示或跨系统传输时，需统一单位处理，避免与其他行业采用亿元为单位的数据产生混淆。接口需返回原始披露链接，外部系统需支持链接的溯源存储或跳转。部分融资事件涉及未公开信息，接口需做权限校验，仅返回公开可查内容，外部系统对接时需配置正确的认证参数。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `timeout` | `30 秒` | 农化融资日报接口返回数据量适中，30秒可覆盖完整拉取，避免超时中断 |
| `max_retries` | `2 次` | 应对接口临时限流，重试次数过多会增加服务器负载 |
| `request_interval` | `3600 秒` | 匹配工作日每日更新的节奏，避免频繁拉取重复数据 |
| `field_mapping` | `{"融资金额(万元)":"finance_amount"}` | 统一接口字段与内部存储字段的映射关系，适配农化品类特有的万元单位 |
| `auth_type` | `api_key` | 多数公开行业融资数据接口采用API密钥认证，符合数据授权要求 |
| `parse_mode` | `json` | 接口返回标准JSON格式，结构化解析更高效 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：接口拉取后融资金额字段显示为0或空。原因：未配置`field_mapping`，未将接口返回的“融资金额(万元)”映射为内部标准字段，导致系统无法识别对应数据。
- 现象：调用接口返回429状态码，频繁触发限流。原因：未设置`request_interval`，轮询间隔短于1小时，超出接口公开调用频率限制。
- 现象：本地部署版本重启后接口配置丢失。原因：未将接口配置的持久化目录挂载到外部存储，容器重启后本地临时目录数据被清空。

## 怎么确认配好了
- 发起一次手动接口调用，检查返回数据中是否包含农化制品融资的核心字段，核对`field_mapping`配置是否正确匹配字段名。
- 查看接口调用日志，确认`request_interval`设置生效，两次拉取请求的间隔符合预期。
- 验证重启部署环境后，接口配置未丢失，确认持久化目录挂载正确。
- 测试异常场景下的重试逻辑，确认`max_retries`配置触发后接口恢复正常。
