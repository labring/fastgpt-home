# 出版融资日报的工具调用与插件

## 这个品类的数据长什么样
出版融资日报的数据来源于境内外证券交易所公开披露的融资公告、出版行业协会发布的行业融资动态，以及头部出版集团的官方披露信息。更新节奏为每个工作日同步最新披露内容，非工作日无更新。单条数据文档结构包含融资主体全称、融资轮次、融资金额（单位为万元或亿元）、投资方名单、披露日期、所属出版细分赛道、资金投向共7个核心字段，部分条目附带融资协议签署细节。

## 这些特征在「工具调用与插件」这一环带来什么约束
按工作日更新的特征要求工具调用需配置定时触发的时间窗口，避开非工作日的无效请求。融资金额单位不统一的特征，需在插件解析环节增加单位归一化处理逻辑，避免金额计算偏差。所属出版细分赛道字段的非标准化命名，需在工具调用前配置字段映射规则，将不同披露主体的赛道表述统一为标准分类。单条数据附带的附加细节长度差异较大，需调整插件的内容截取参数与超时设置，适配长文本解析需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 出版融资日报的解析文档可能包含多轮融资条目，长文本解析需要足够超时时间，避免中途中断 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 批量导入的融资日报汇总文档可能包含数千条条目，需允许较大的单文件上传限制 |
| `plugin_parse_chunk_size` | `800–1200 字符` | 融资日报的字段多为短文本但存在长金额说明，分段长度适配字段拆分与解析精度 |
| `tool_call_trigger_cron` | `0 9-18 * * 1-5` | 按工作日的工作时段触发工具调用，避开非工作日的无效请求，匹配数据更新节奏 |
| `field_mapping_rules` | 按披露主体预设映射表 | 出版行业融资赛道的命名不统一，需将自定义字段映射为标准分类，适配后续数据分析 |
| `plugin_doc_normalize` | 开启金额单位归一化 | 融资金额存在万元、亿元混用的情况，需自动转换为统一单位提升工具调用准确性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为Doc2x插件解析上传的融资日报语料时返回空结果，原因是未配置出版行业融资文档的字段映射规则，导致插件无法识别融资主体、金额等核心字段。
- 现象为通过API调用工具时返回的结果未包含知识库关联文件信息，原因是未开启`tool_call_return_source_files`参数，或未在工具配置中启用源文件返回功能。
- 现象为替换文档解析工具后无法正常加载融资日报数据，原因是未修改`PARSE_ENGINE_TYPE`配置项为新解析工具的对应标识，导致插件调用引擎不匹配。

## 怎么确认配好了
- 上传单条出版融资日报测试文档，通过插件解析界面查看字段是否正确映射为标准分类，确认字段映射配置生效。
- 触发定时工具调用任务，查看任务日志中是否包含按预设时间窗口执行的记录，确认定时触发配置生效。
- 调用API发起工具请求，查看返回结果中是否包含关联文件的路径与名称，确认源文件返回配置开启。
- 尝试上传批量出版融资日报汇总文档，确认上传界面无报错，验证上传大小限制配置生效。
