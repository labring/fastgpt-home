# 动力煤融资日报的引用来源与溯源

## 这个品类的数据长什么样
动力煤融资日报的数据主要来自国内煤炭行业协会、沿海港口交易台账、郑州商品交易所动力煤期货配套融资公告，每日更新1次。单份日报文档结构固定，包含发布日期、产地、平仓价格、年化融资成本、银行授信额度、交易主体名称6类核心字段，其中价格单位为元/吨，融资成本单位为年化百分比，授信额度单位为万元，单条数据条目清晰，无嵌套复杂的层级结构。

## 这些特征在「引用来源与溯源」这一环带来什么约束
每日更新的属性要求溯源环节需自动匹配最新的发布日期字段，避免引用过期数据。核心字段与金融强相关的特点，要求溯源必须精准绑定具体的产地、交易主体与发布机构，不能泛泛引用行业通用内容。固定的文档结构与明确的单位要求，意味着溯源时需校验字段与单位的一致性，防止出现价格与授信额度的单位混淆。同时，单份日报的条目数量较多，需控制召回与引用的范围，避免无关条目干扰溯源准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity_threshold` | 0.75-0.85 | 动力煤融资日报的字段精准度要求高，该区间可过滤低相关的通用煤炭数据，保留与融资、价格强相关的内容 |
| `recall_top_k` | 前8-12条 | 日报单页包含多组数据条目，该召回范围可覆盖当日核心交易与融资信息，避免遗漏关键溯源素材 |
| `rerank_top_n` | 前3-5条 | 融资相关信息需最高相关性，重排后保留最精准的3-5条内容，确保溯源片段聚焦核心业务 |
| `max_citation_length` | 600-1000字符 | 单条核心数据包含多字段，该长度可完整展示产地、价格、融资成本等关键溯源信息 |
| `citation_source_require_field` | 开启「产地」「发布日期」「交易机构」校验 | 动力煤融资日报的溯源需明确数据发布主体与具体产地，该配置可避免模糊引用 |
| `parse_file_chunk_size` | 800-1200字符 | 日报文档结构固定，该分块大小可完整保留单组数据的字段信息，避免割裂关键内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：开启`rerank_top_n`后出现引用为空的提示，界面显示无匹配检索结果。原因：将`similarity_threshold`设置为0.9以上，导致重排前的召回结果被过度过滤，无法提供有效重排素材。
- 现象：导出工作流JSON文件后导入新环境，引用的数据源配置无法正常加载。原因：仅导出了工作流配置，未同步导出关联的数据源连接密钥与权限配置，导致新环境无法识别数据源路径。
- 现象：引用片段中出现单位混淆，例如将授信额度的「万元」显示为「元/吨」。原因：未开启`citation_source_require_field`的单位校验，召回时未匹配字段对应的单位信息。

## 怎么确认配好了
- 上传一份标准的动力煤融资日报文档，发起检索任务，检查返回的引用片段是否包含「产地」「发布日期」「交易机构」三类必填字段。
- 调整`similarity_threshold`至0.7，发起批量检索，确认召回的片段数量符合`recall_top_k`的设定范围，无大量无关的通用煤炭行业内容混入。
- 开启重排功能后，检查返回的引用条数是否在`rerank_top_n`的设定区间内，无超出范围的冗余片段。
- 导出工作流与关联的数据源配置，导入新的工作空间后，确认数据源连接状态正常，无报错提示。
