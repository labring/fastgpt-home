# 包装印刷融资日报的工具调用与插件

## 这个品类的数据长什么样
包装印刷融资日报的数据来源包括包装印刷企业公开披露的融资公告、行业融资监测数据库、地方金融服务平台备案信息。更新节奏为每日更新当日公开的单笔融资项目，每周生成全品类汇总日报。单条数据包含企业名称、所属包装印刷细分领域、融资方式、融资金额、融资方、投资方、披露日期、所属区域等字段。融资金额单位为万元人民币，披露日期格式为YYYY-MM-DD，不同数据源的字段命名存在细微差异。

## 这些特征在「工具调用与插件」这一环带来什么约束
包装印刷融资日报的数据分散于多类公开渠道，要求工具调用插件支持多数据源聚合拉取，避免遗漏跨平台的融资信息。每日更新的频率要求定时任务触发间隔匹配自然日周期，且需配置增量拉取逻辑，防止重复录入已处理的融资项目。细分领域字段的差异化命名，要求插件支持自定义字段映射规则，适配不同数据源的字段差异。融资金额的单位不一致问题，要求插件内置单位转换逻辑，统一输出为预设的万元人民币格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_data_source_list` | `["public_finance_notice", "industry_finance_monitor", "local_finance_platform"]` | 覆盖包装印刷融资的三类核心公开数据源 |
| `plugin_sync_interval` | `86400 秒` | 匹配融资日报每日更新的自然日周期 |
| `field_mapping_rules` | `{"融资金额":"募资额","所属领域":"细分赛道"}` | 适配不同数据源的字段命名差异 |
| `unit_conversion_config` | `{"元":"万元","人民币":"万元"}` | 统一所有数据源的融资金额输出单位 |
| `incremental_sync_enabled` | `true` | 避免重复处理已同步的历史融资项目 |
| `plugin_timeout` | `300 秒` | 适配多数据源拉取的整体耗时需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用FLUX插件生成包装印刷融资日报可视化内容时，所有参数配置正确但返回失败，界面显示`plugin_execution_failed`状态码。原因：未将Lora文件上传至平台指定的插件存储目录，导致插件无法加载指定的`flux_Q版齐天大圣.s`模型文件。
- 现象：在4.8.22版本的工作流中，开启知识库插件的问题优化后，最终回答中混入非包装印刷领域的融资数据。原因：未在插件配置中添加领域过滤规则，未限定仅拉取包装印刷相关的融资信息。
- 现象：上传包装印刷融资日报PDF附件后，工具调用返回的markdown文本缺失明细表格字段。原因：未启用`pdf_table_extract`开关，导致PDF内的融资明细表格未被正确提取。

## 怎么确认配好了
- 执行单次手动触发插件拉取，检查返回结果中是否仅包含包装印刷领域的融资数据，且字段名称与配置的映射规则一致。
- 查看插件运行日志，确认同步间隔触发频率与配置的`plugin_sync_interval`参数匹配，无重复拉取记录。
- 测试单位转换逻辑，输入不同单位的融资金额，确认输出结果统一为预设的万元单位。
- 上传测试用的包装印刷融资日报PDF，检查解析后的markdown文本是否包含完整的融资明细表格。
