# 化妆品融资日报的工具调用与插件

## 这个品类的数据长什么样
化妆品领域融资日报的数据来源包括企业工商变更公示平台、行业垂直媒体报道、私募股权备案数据库。数据更新节奏为每日同步当日公开披露的融资事件，无固定批量推送频次。单条融资记录的文档结构包含主体全称、品牌赛道分类、融资金额、投资方名单、融资发生日期、披露来源。字段方面，融资金额单位为人民币万元，投资方为数组格式，融资轮次为标准化枚举文本，披露来源为纯文本链接或平台名称。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散要求工具调用配置多源API聚合的触发规则，避免遗漏跨平台的融资事件。融资事件时效性强，要求工具调用设置较短的超时区间，防止延迟导致日报内容滞后。投资方为数组格式字段，工具调用的结果解析模块需要支持嵌套数组的提取与格式化。化妆品赛道的细分分类较多，工具调用需配置赛道筛选参数，确保仅返回美容护理赛道的融资记录，排除非相关领域的融资条目。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_call_timeout` | `300 秒` | 化妆品融资日报数据时效性强，过长超时会导致日报内容滞后 |
| `multi_source_api_batch_size` | `3 个` | 平衡多源API请求的成功率与并发效率 |
| `parse_nested_array` | `开启` | 投资方字段为数组格式，需正确提取并格式化 |
| `filter_track_field` | `美容护理` | 仅返回美容护理赛道的融资事件，匹配细分品类需求 |
| `daily_trigger_interval` | `1440 分钟` | 匹配每日更新的融资日报节奏 |
| `result_unit_convert` | `转换为人民币万元` | 统一融资日报的金额展示单位，避免混淆 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 工具调用完成后，结果面板显示完整的API请求与响应日志，原因：未关闭`show_tool_call_log`配置项的默认输出。
- 提取的投资方字段为空，原因：未开启`parse_nested_array`配置项，无法识别数组格式的投资方数据。
- 工具调用执行中无法主动终止，返回`ETIMEDOUT`错误，原因：未配置`tool_call_terminate_api`参数，未绑定终止执行的触发逻辑。

## 怎么确认配好了
- 手动触发一次工具调用，检查返回结果仅包含美容护理赛道的融资事件，确认赛道筛选配置生效。
- 查看工具调用日志，确认嵌套数组字段（如投资方）被正确提取并格式化，确认嵌套数组解析配置生效。
- 检查结果中的融资金额单位统一为人民币万元，确认金额单位转换配置生效。
- 等待次日自动触发任务，确认日报生成无延迟，确认每日触发间隔配置生效。
