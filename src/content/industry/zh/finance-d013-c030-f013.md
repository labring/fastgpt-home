# 化妆品融资日报的知识库检索与召回

## 这个品类的数据长什么样
化妆品融资日报的数据来源于公开披露渠道，包括品牌官方公告、行业媒体报道、监管机构备案文件。更新节奏为每日凌晨同步前一日的公开融资事件，临时发布的融资公告将实时补录入库。单条数据以单次融资事件为核心单元，包含品牌名称、融资轮次、融资金额（单位：人民币万元/亿元）、投资方机构、披露时间、所属细分赛道（如面部护理、彩妆、香水）、核心SKU品类等字段，部分条目附带品牌业务简介片段。

## 这些特征在「知识库检索与召回」这一环带来什么约束
化妆品融资日报的时效性要求较高，因此检索环节需优先召回近7日的最新融资事件，避免返回过时信息。数据包含多个明确的业务字段，需支持按赛道、轮次等元数据过滤检索结果，提升精准度。单条数据的字段关联紧密，分块时需保留字段完整性，避免拆分后丢失核心业务信息。此外，跨媒体转发的重复融资公告较多，需在召回前完成去重处理，防止结果冗余。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | 前10条 | 化妆品融资日报的单日报文量通常在数十条，前10条可覆盖核心最新事件，避免结果过载 |
| `相似度阈值` | 0.75–0.85 | 融资事件的核心关键词（品牌名、轮次）匹配度要求高，阈值过低会引入无关结果，过高会遗漏弱匹配的相似融资事件 |
| `增量同步间隔` | 1 小时 | 融资事件可能有临时公告，1小时间隔可保证数据时效性，符合日报的更新节奏 |
| `分段长度` | 800–1200 字符 | 单条融资事件的文本长度通常在500-1000字符，分段长度覆盖完整事件且避免拆分跨字段的关联信息 |
| `元数据过滤开关` | 开启 | 化妆品融资数据包含赛道、轮次等元数据，开启后可支持按业务属性精准过滤检索结果 |
| `去重阈值` | 0.9 | 跨媒体转发的融资公告文本相似度极高，阈值0.9可有效去除重复数据且保留不同来源的有效补充信息 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：提问与化妆品融资日报完全无关时，仍触发知识库检索并返回相关结果。原因：未设置`相似度阈值`参数，或阈值设置高于实际需要的匹配标准，导致低相关性文本被误召回。
- 现象：检索结果中，品牌业务简介等辅助字段的排序优先于融资金额、融资轮次等核心信息。原因：未为核心检索字段配置权重，导致辅助文本的语义匹配权重超过核心业务字段。
- 现象：上传融资日报文件后，无法通过指定集合ID检索到对应内容。原因：上传接口未正确返回`collection_id`和`file_id`，或未将`file_id`绑定到目标集合，导致检索时无法定位到目标知识库文件。

## 怎么确认配好了
- 执行模拟检索，输入已知的化妆品融资事件关键词，核对返回结果的排序是否优先包含最新披露的事件。
- 上传测试文件，通过接口获取`collection_id`和`file_id`，执行关联绑定操作后，检索对应关键词，确认可召回测试文件内的内容。
- 输入与融资日报无关的测试问题，核对返回结果是否触发预设的无关问题回复，不返回知识库内的内容。
- 调整`相似度阈值`参数，输入弱匹配的关键词，核对召回结果的数量是否符合预期的过滤效果。
