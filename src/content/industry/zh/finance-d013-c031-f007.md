# 化学制药融资日报的工作流编排

## 这个品类的数据长什么样
化学制药融资日报的数据来源为公开融资披露平台、境内外交易所公告及药企官方公告。更新节奏为每日更新，覆盖当日及前一交易日披露的融资事件。单条数据文档结构包含融资方全称、融资轮次、融资金额（单位为人民币万元或亿元）、投资方名单、融资披露日期、所属细分赛道字段。数据字段需严格匹配行业通用的融资披露格式，部分跨境融资事件会附带外币计价金额及汇率换算字段。

## 这些特征在「工作流编排」这一环带来什么约束
多源数据来源要求工作流配置多并行拉取节点，适配不同披露平台的接口格式。每日更新的节奏要求工作流设置每日定时触发，且配置去重逻辑，避免重复录入已处理的融资事件。融资金额的多单位属性要求工作流加入单位校验与转换节点，统一输出为标准计价单位。细分赛道字段的多样性要求工作流配置分类映射规则，将非标准赛道名称对齐至行业通用分类体系。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发周期` | `每日 09:00` | 适配融资披露的次日更新节奏，确保拉取当日最新公告 |
| `多源拉取并发数` | `3–5 个` | 避免超过公开披露平台的接口调用限制 |
| `字段映射唯一键` | `按「融资方名称+融资披露日期」作为唯一键` | 避免重复录入同一融资事件 |
| `单位转换节点配置` | `将所有金额统一转换为人民币万元` | 统一数据口径，便于后续分析 |
| `HTTP 请求超时时间` | `30 秒` | 适配公开披露平台的接口响应速度，避免超时中断 |
| `分类映射规则` | `匹配化学制药细分赛道的行业标准分类库` | 对齐行业通用赛道命名，统一数据维度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为工作流中HTTP节点返回内容无法传递至AI对话节点，提示「变量未定义」。原因是未在HTTP节点配置「输出变量名」，或变量名拼写与对话节点引用的名称不一致。
- 现象为代码运行节点的输出无法被后续AI对话节点读取，日志显示「目标变量不存在」。原因是代码节点未开启「输出至工作流变量」开关，或输出的变量格式不符合JSON规范。
- 现象为无法找到工作流导入入口，或导入后节点布局错乱。原因是未在对应项目的工作流管理页面操作，或导入文件的版本与当前平台版本不兼容。

## 怎么确认配好了
- 手动触发一次工作流，检查各节点的输出日志，确认多源拉取节点返回的字段与预设一致。
- 查看工作流的定时触发配置，确认触发时间与融资披露的更新节奏匹配。
- 测试代码运行节点的输出，确认后续节点可正常读取变量值。
- 检查全局变量的使用场景，确认仅用于跨会话的固定配置，未作为临时数据存储。
