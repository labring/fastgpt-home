# 化学原料融资日报的工具调用与插件

## 这个品类的数据长什么样
化学原料融资日报的数据主要来自全国银行间同业拆借中心公开披露的企业融资公告、化工行业协会每日融资统计数据库，以及沪深北交易所的上市公司临时公告。数据更新节奏为每日更新，覆盖当日披露的全品类化学原料相关企业融资动态。单篇日报文档结构包含融资主体全称、对应化学原料品类、融资类型（授信、债券、股权等）、融资金额、融资期限、发布机构、发布日期等字段，其中融资金额单位为万元人民币，融资期限单位为自然月或自然日，发布日期采用标准年月日格式。

## 这些特征在「工具调用与插件」这一环带来什么约束
化学原料融资日报的数据来源分散，要求工具调用需支持多API源的聚合配置，否则会遗漏跨平台的融资动态。每日更新的节奏要求工具触发周期需匹配自然日，否则无法覆盖当日全量数据。固定的字段结构要求工具调用的参数校验需严格匹配`融资金额``融资期限`等字段的单位与格式，避免无效数据流入。同时，融资主体限定为化学原料生产企业，需配置基础筛选规则过滤非相关主体的融资记录，降低后续处理成本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_api_batch_count` | `1–3` | 化学原料融资日报的公开数据源通常覆盖1-3个平台，批量调用过多会触发接口限流 |
| `tool_trigger_cron` | `0 8 * * *` | 匹配多数融资公告的常规披露时间，确保每日8点前拉取前一日的全量数据 |
| `UPLOAD_FILE_MAX_SIZE` | `10 MB` | 单篇融资日报的文档大小通常不超过8MB，预留合理缓冲空间 |
| `tool_param_validate_mode` | `strict` | 需严格校验`融资金额``融资期限`的单位与格式，避免混入非标准数据 |
| `tool_output_filter_rule` | `仅保留化学原料相关融资记录` | 过滤非对应品类的融资主体数据，确保输出内容精准匹配细分场景 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 出现`400 InternalError.Algo.InvalidParameter: Multimodal file size is`报错，原因是未正确配置`UPLOAD_FILE_MAX_SIZE`参数，上传的融资日报文档大小超出预设阈值。
- 工作流中工具调用的输出无法手动取消，导致最终结果包含冗余的工具执行日志，原因是未开启`tool_output_optional`配置项，默认强制返回工具调用结果。
- 输入文本经处理后出现字符错误（如“分享”变为“分交”），导致工具调用参数解析失败，原因是未配置`input_text_preprocess`参数，未对输入文本进行归一化校验。

## 怎么确认配好了
- 手动触发一次工具调用，检查返回的融资记录是否仅包含化学原料相关主体，核对`tool_output_filter_rule`的配置是否生效。
- 上传一份超过8MB的模拟融资日报文档，查看是否触发相关校验报错，确认`UPLOAD_FILE_MAX_SIZE`的配置合理。
- 查看定时任务的执行日志，确认工具在每日8点左右触发拉取，核对`tool_trigger_cron`的配置与预期一致。
- 输入存在拼写误差的测试文本（如“分交”），查看工具是否能正确解析为目标参数，确认`input_text_preprocess`配置生效。
