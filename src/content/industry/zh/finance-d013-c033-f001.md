# 化纤融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
化纤融资日报的数据来源于国内大宗商品现货交易市场的公开披露信息、化纤行业自律组织的每日监测报表。更新节奏为每个交易日收盘后1小时内完成全量更新。单条数据文档以结构化格式存储，包含交易品种、当日融资买入金额、融资余额、融券卖出量、当日结算价等核心字段，其中金额类字段单位为人民币万元，成交量类单位为交易手数，结算价单位为人民币元/吨。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
化纤融资日报的数据源分散且更新窗口集中，要求HTTP接口支持多源数据聚合拉取，避免因单源接口延迟导致整体数据滞后。交易日收盘后1小时的更新节奏，要求接口请求超时阈值设置不低于45分钟，适配全量数据拉取的耗时。多品种多字段的结构化数据，要求接口支持按交易品种、日期参数筛选返回结果，同时内置字段单位转换逻辑，将不同源的金额、成交量单位统一为标准格式，降低外部系统的适配成本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `apiTimeout` | 45 分钟 | 适配化纤融资日报全量数据拉取的耗时，避免触发超时错误 |
| `fieldMapping` | 将源字段映射为标准名称，统一单位为万元/手/元/吨 | 解决多源数据字段名、单位不一致的问题，简化外部系统解析 |
| `maxBatchSize` | 按业务场景自定义 | 控制单次接口返回的数据条数，优化外部系统的加载性能 |
| `sourceAuthType` | API_KEY 鉴权 | 适配多数公开行业数据源的鉴权要求，统一对接流程 |
| `updateSchedule` | 每个交易日收盘后1小时内触发 | 匹配行业数据的更新节奏，确保获取最新的融资日报数据 |
| `responseFormat` | JSON 结构化格式 | 标准化返回格式，便于外部系统直接解析处理 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用关联大模型的接口返回`500 Internal Server Error`，无法在平台后台找到对应请求日志。原因：未开启`apiLogEnable`配置，未启用接口请求日志的存储，导致无法排查调用失败的原因。
- 现象：外部系统接收到的化纤品种字段与本地维护的品类列表不匹配。原因：未配置`fieldMapping`规则，未将源数据的非标准品类字段映射为目标系统的统一名称。
- 现象：接口请求在交易日非更新时段触发时返回空数据。原因：未按照`updateSchedule`配置触发拉取，此时行业数据源尚未完成当日数据更新，未返回有效内容。

## 怎么确认配好了
- 发起一次按指定交易日、品种筛选的接口请求，核对返回字段的名称与单位符合配置的标准格式。
- 查看平台后台的接口日志，确认请求触发时间与配置的`updateSchedule`一致。
- 上传测试用的化纤行业文档，确认接口可以正常接收并完成解析。
- 调用批量数据接口，核对返回条数符合配置的`maxBatchSize`设置。
