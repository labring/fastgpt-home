# 化纤融资日报的工具调用与插件

## 这个品类的数据长什么样
数据来源包括中国化纤工业协会行业监测数据库、国内大宗商品现货交易平台的融资备案数据。更新节奏为每日8:30前完成前一交易日的全量数据更新。文档结构为结构化表格，包含品种名称、当日融资授信总额、单笔融资平均利率、库存周转天数、现货成交均价五个核心字段，单位分别为万元、%、天、元/吨。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据来源要求工具调用需同时对接行业协会与现货平台的接口，需配置两套独立的鉴权参数与请求头。每日固定更新的节奏要求工具触发需绑定每日定时任务，避免拉取未完成更新的旧数据。结构化表格的固定字段结构要求工具调用需明确指定提取字段，不可随意调整返回内容的结构。不同字段的单位差异要求工具调用时需配置字段格式校验规则，防止出现单位不匹配的计算错误。化纤品类的细分品种较多，工具调用需支持按品种名称作为筛选参数，精准拉取对应品类的融资数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `request_timeout` | 600 秒 | 适配跨平台拉取行业数据的平均延迟，避免因数据拉取过慢触发超时错误 |
| `cron_schedule` | 0 30 8 * * * | 匹配数据每日8:30前完成更新的节奏，确保拉取到最新的前一日数据 |
| `field_whitelist` | ["品种名称","当日融资授信总额","单笔融资平均利率","库存周转天数","现货成交均价"] | 仅提取预设的核心字段，避免冗余数据干扰工具调用结果 |
| `auth_config` | 按数据源分别配置API_KEY与请求头 | 适配多源数据对接的鉴权要求，区分行业协会与现货平台的鉴权规则 |
| `data_unit_convert` | 按字段匹配对应单位 | 确保授信总额以万元、成交均价以元/吨的格式统一输出，避免单位混乱 |
| `filter_params` | 支持传入"品种名称"作为筛选条件 | 适配化纤品类细分多的特征，精准拉取指定品种的融资数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用返回`400 Bad Request`错误，提示请求路径未找到。原因：未正确配置数据源的API请求地址，将测试环境地址直接沿用至生产环境。
- 现象：定时触发工具后无数据返回，工作流日志显示鉴权失败。原因：未针对行业协会与现货平台分别配置独立的鉴权参数，导致其中一类数据源无法通过校验。

## 怎么确认配好了
- 手动触发工具调用，检查返回结果的字段是否与预设的`field_whitelist`完全一致。
- 查看工作流日志，确认工具调用的请求头与鉴权参数与配置的`auth_config`匹配。
- 验证定时任务的触发时间，确认与`cron_schedule`的表达式一致。
- 输入指定的化纤品种名称作为筛选参数，检查工具是否仅返回对应品类的数据。
