# 医疗器械融资日报的工作流编排

## 这个品类的数据长什么样
医疗器械融资日报的数据来源涵盖国内医疗器械行业协会公开披露信息、上市公司定期公告、一级市场融资数据库及地方药监部门备案公示。数据更新节奏为每日更新，覆盖前一交易日及公开渠道披露的最新融资动态。单条数据条目包含融资方名称、核心医疗器械品类、融资金额、投资方主体、融资轮次、披露日期、所属地域等字段，其中融资金额单位统一为万元，融资轮次以公开披露的标准表述为准，医疗器械品类字段需匹配影像设备、体外诊断试剂、医用耗材等预设分类。

## 这些特征在「工作流编排」这一环带来什么约束
每日更新的属性要求工作流配置定时触发机制，避免手动执行的滞后性。多字段且带特定分类规则的结构，要求工作流内置字段校验节点，确保医疗器械品类、融资金额单位等字段符合标准格式。多源数据拉取的需求，要求工作流支持外部文件链接传入，整合不同渠道的数据源。单条数据的文本长度差异，要求配置合理的文本分段规则，避免拆分后丢失关键融资信息。此外，融资数据的时效性要求工作流在数据拉取后需快速完成清洗与汇总，对节点执行时长提出明确约束。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `SCHEDULE_CRON` | `0 8 * * *`（每日8点触发） | 匹配融资日报的每日更新节奏，确保早间产出当日前一日的汇总数据 |
| `PARSE_DATA_TIMEOUT` | `600 秒` | 覆盖多源数据拉取、清洗及分类校验的耗时需求 |
| `TEXT_SPLIT_CHUNK_SIZE` | `800–1200 字符` | 适配单条融资记录的文本长度，避免分段拆分导致关键信息丢失 |
| `FIELD_VALIDATION_RULE` | 预设医疗器械品类枚举值 | 校验融资方所属器械分类字段，确保数据分类符合行业标准 |
| `GLOBAL_VAR_STORAGE` | 开启 | 跨工作流步骤传递融资统计汇总数据，避免数据丢失 |
| `TOOL_INPUT_ALLOW_FILE_LINK` | 开启 | 允许传入外部数据源文件链接，适配多源数据整合的业务需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 运行工作流时返回`400 BAD REQUEST`错误，原因是未配置`FIELD_VALIDATION_RULE`，导致非法医疗器械品类字段触发校验失败。
- 工作流作为工具调用时，传入的上传文件链接字段为空，原因是未开启`TOOL_INPUT_ALLOW_FILE_LINK`配置，系统拦截了外部文件链接参数。
- 同一对话中修改全局变量后，后续步骤无法获取更新后的值，原因是未开启`GLOBAL_VAR_STORAGE`，全局变量未持久化保存，仅在当前步骤临时生效。

## 怎么确认配好了
- 手动触发工作流，查看执行日志的时间戳，确认触发时机符合预设的`SCHEDULE_CRON`配置。
- 上传包含非法医疗器械品类的测试数据，检查工作流是否拦截异常输入，确认`FIELD_VALIDATION_RULE`生效。
- 调用绑定该工作流的工具，上传测试文件并传入文件链接，检查工作流是否能正常读取链接内容，确认`TOOL_INPUT_ALLOW_FILE_LINK`配置生效。
- 查看全局变量存储面板，确认跨步骤传递的融资统计数据未丢失，确认`GLOBAL_VAR_STORAGE`配置生效。
