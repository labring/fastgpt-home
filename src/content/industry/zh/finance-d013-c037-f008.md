# 卫星通信融资日报的工具调用与插件

## 这个品类的数据长什么样
卫星通信融资日报的数据来源为公开的项目立项公告、行业监管披露文件及第三方行业数据库。更新节奏为每日凌晨完成当日数据归集与整理。单篇文档结构固定，包含卫星项目标识、发射窗口时间、融资主体、融资金额、通信频段范围、项目落地区域6个核心字段，部分补充项包含技术参数与合作方信息，字段单位统一遵循行业通用规范，融资金额以万元或亿元为标注单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
卫星通信融资日报的固定字段与结构化特征，要求工具调用时需严格匹配预设的字段解析规则，避免因字段缺失或格式错误导致解析失败。每日更新的节奏要求插件定时任务需配置为每日触发，且需通过日期参数精准拉取当日最新数据，避免重复获取历史内容。通信频段、发射窗口等专属字段，要求工具调用需支持按特定维度的筛选参数，适配行业检索需求。同时，融资金额的多单位格式，要求插件需内置单位转换逻辑，统一输出标准格式的数值信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `daily_sync_cron` | `0 2 * * *` | 匹配行业日报的每日更新节奏，避开公开数据源的接口访问高峰时段 |
| `response_parse_schema` | 预设包含`project_id`、`launch_window`、`financing_amount`、`frequency_band`的JSON Schema | 匹配卫星通信融资日报的固定字段结构，提升解析准确率 |
| `request_timeout` | `30 秒` | 公开数据源接口响应通常在10-25秒区间，预留足够缓冲时间避免超时中断 |
| `filter_date_range` | `近24小时` | 匹配日报的每日更新属性，仅拉取当日最新披露的融资数据 |
| `unit_conversion_enabled` | `开启` | 融资金额存在万元与亿元混用的情况，统一转换为万元可降低下游处理复杂度 |
| `request_retries` | `3次` | 公开接口可能存在临时波动，重试可降低拉取失败概率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：插件调用返回`415 Unsupported Media Type`错误码，原因：未正确配置请求头的`Content-Type`参数，采用了`application/x-www-form-urlencoded`的参数序列化方式，未匹配接口要求的`application/json`格式。
- 现象：本地调用接口正常，但部署环境调用返回`Connection refused`错误，原因：未将本地调试的`localhost`域名替换为部署环境的合法域名，且未配置接口访问的白名单规则。
- 现象：插件返回的融资数据字段缺失`frequency_band`信息，原因：未使用匹配卫星通信融资日报的解析Schema，误用通用融资文档的解析模板，无法识别行业专属字段。

## 怎么确认配好了
- 查看插件定时任务的执行日志，确认每日拉取任务未出现超时或异常报错。
- 手动触发一次插件调用，核对返回数据包含预设的核心字段，且字段格式符合业务要求。
- 测试按`frequency_band`参数筛选数据，确认返回结果匹配筛选条件。
- 验证插件请求的参数序列化方式与请求头配置符合接口要求。
