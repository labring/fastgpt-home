# 卫星通信融资日报的部署与升级

## 这个品类的数据长什么样
该品类的数据来源为卫星通信项目融资备案公示、公开招投标平台的融资公告及行业监测机构的每日汇总。更新节奏为每日1次，更新当日0点至24点收录的卫星通信领域融资条目。单条数据文档包含`卫星标识`、`融资主体全称`、`融资金额`、`资金到账状态`、`融资用途`、`发布渠道`、`数据采集时间`等字段，其中融资金额单位为人民币万元，发布渠道为标准URL格式，数据采集时间精确到分钟。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据特征对部署与升级环节带来多项约束。每日定时拉取的更新节奏，要求部署时配置`CRON_EXPRESSION`适配每日1次的拉取周期，并预留足够的超时时间应对多数据源拉取。字段包含标准URL与精确时间戳，要求部署时开启数据格式校验模块，配置`DATA_VALIDATE_RULE`过滤无效链接与时间格式错误的条目。融资金额固定单位为人民币万元，需在部署阶段配置字段校验规则，拦截非万元单位的融资数据。升级时若调整数据源接口，需兼容原有字段的存储结构，避免下游解析环节出现字段缺失或格式异常。同时，部分数据源需通过合规的网络访问路径，部署时需配置`NETWORK_WHITELIST`允许访问对应公开平台，防止拉取失败。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `APP_CONTEXT_PATH` | `/fastgpt` | 适配统一的应用访问路径规范，便于统一管理与反向代理配置 |
| `CRON_EXPRESSION` | `0 2 * * *` | 每日凌晨2点执行数据拉取任务，避开日间业务高峰时段 |
| `DATA_VALIDATE_RULE` | `{"amount_unit": "万元", "url_format": "valid"}` | 校验融资金额的单位格式与发布渠道的URL合法性，过滤无效数据 |
| `PARSE_TIMEOUT_SECONDS` | `300 秒` | 预留足够时长处理多源数据的解析与入库，避免中途超时中断任务 |
| `NETWORK_WHITELIST` | `["satellite-monitor.org", "public-bid.com"]` | 允许访问指定数据源平台，规避网络拦截导致的数据拉取失败 |
| `MAX_BATCH_RECORDS` | `800 条` | 限制单批次处理的融资日报条目数量，避免内存占用过高导致服务异常 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：修改`ROOT_PASSWORD`环境变量后，登录页面仍提示默认密码或验证失败。原因：未同步重启容器使配置生效，或未更新容器内的本地配置文件。
- 现象：Docker部署后访问地址出现转圈圈后失败，返回`504 Gateway Timeout`状态码。原因：未配置`NETWORK_WHITELIST`允许访问数据源平台，数据拉取任务超时导致服务阻塞。
- 现象：配置访问上下文后，应用静态资源无法正常加载，页面样式错乱。原因：未同步更新反向代理的配置规则，导致静态资源路径匹配错误。

## 怎么确认配好了
- 手动触发定时拉取任务，查看系统日志，确认任务在指定周期内正常触发，无格式校验报错与超时中断。
- 访问配置的`APP_CONTEXT_PATH`对应的完整路径，确认页面可以正常加载，无状态码报错。
- 手动导入一条符合格式的测试融资日报数据，确认数据被正确解析与存储，无字段缺失或格式异常。
- 查看服务的网络连接状态，确认可以正常访问配置的数据源白名单平台。
