# 厨卫电器融资日报的工具调用与插件

## 这个品类的数据长什么样
这个品类的数据来自公开企业融资披露公告、行业供应链融资备案信息及指定财经媒体的公开报道。每日汇总当日新增及近7日的关联融资事件，生成当日日报。单条融资条目包含企业全称、厨卫电器主营品类、融资轮次、融资金额区间、投资方名单、披露日期、融资用途说明。融资金额以万元人民币为单位，披露日期采用ISO 8601标准日期格式，部分条目附带关联供应链厂商的补充信息。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据特征对工具调用与插件环节带来多项约束。多源分散的数据源需要配置多API聚合的参数，避免单一数据源覆盖不全。每日更新的节奏要求设置定时拉取的间隔为24小时，防止数据滞后或重复拉取。融资金额以区间形式呈现的字段，需要配置区间匹配的过滤规则，适配非固定数值的查询需求。附带的供应链厂商关联信息，需要配置关联字段的召回阈值，确保相关信息被同步纳入调用结果。主营品类字段的存在，要求工具调用时默认添加厨卫电器的品类过滤条件，避免混入其他行业的融资数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `max_tool_calls` | `3–5 次` | 厨卫电器融资日报的单日融资事件数量有限，限制调用次数可避免无效循环，同时覆盖多轮查询需求 |
| `trigger_keywords` | `["厨卫电器", "融资", "供应链融资"]` | 配置精准触发词，确保仅在查询与厨卫电器融资相关内容时唤起工具调用 |
| `data_update_interval` | `86400 秒` | 匹配该品类日报每日更新的节奏，确保工具拉取的数据源为最新的当日汇总数据 |
| `field_match_rule` | `range_based` | 适配融资金额以区间形式呈现的字段，支持按金额区间进行精准匹配查询 |
| `plugin_api_timeout` | `30 秒` | 对接多源公开数据源时，设置合理超时时间，避免因单数据源响应缓慢导致整体调用失败 |
| `return_metadata_fields` | `["融资用途", "供应链厂商"]` | 保留该品类特有的补充信息字段，满足细分场景的信息完整性需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：Docker部署的4.8.23版本应用，工具调用时部分模型无法触发工具逻辑。原因：未在应用配置中开启「工具调用开关」，且未将工具API地址配置为可访问的内网或公网地址。
- 现象：调用对话接口时，`detail: true`返回的知识库调用参数无法与流式返回结果同步解析。原因：未配置流式返回的元数据绑定规则，导致工具调用的参数与对话流数据分离。
- 现象：尝试调用联网工具获取最新融资数据时，返回结果为空或提示网络错误。原因：未在插件配置中添加公开数据源的API白名单，或未配置合理的联网请求超时参数。

## 怎么确认配好了
- 提交包含「厨卫电器融资」关键词的测试查询，查看工具是否被正常触发。
- 检查工具调用返回的结果，确认仅包含厨卫电器相关的融资条目，且包含预设的补充字段。
- 查看应用日志，确认工具调用的拉取间隔符合预设规则，无重复或滞后的拉取记录。
- 手动调用对话接口并携带`detail: true`参数，验证返回结果中包含工具调用的完整参数与流式对话数据。
