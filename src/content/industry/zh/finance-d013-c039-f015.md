# 厨卫电器融资日报的部署与升级

## 这个品类的数据长什么样
厨卫电器融资日报的数据来源为品牌方经销商管理系统、主流电商平台交易后台、合作银行授信台账三类。更新节奏为每日凌晨同步前一个工作日的全量数据，增量变更实时推送。单条数据文档结构包含SKU编码、品牌归属、品类细分（如嵌入式燃气灶、壁挂式浴霸）、当日终端出货额、上游供应商应付款项、当日融资申请笔数、获批额度、实际到账金额。字段单位分别为：出货额单位为人民币元，应付款项单位为万元，获批额度单位为万元，到账金额单位为万元，申请笔数为整数。

## 这些特征在「部署与升级」这一环带来什么约束
品类细分多且SKU数量庞大，部署时需配置多维度字段过滤规则，避免跨品类数据混淆。每日固定更新的节奏要求部署定时同步任务，全量拉取会占用过多服务器资源，需设置增量同步逻辑。字段包含多类单位与敏感融资数据，需统一字段映射规则并配置访问权限，避免解析错误与数据泄露。升级版本时，需兼容新增的厨卫电器细分品类，不能破坏原有索引结构，需配置动态字段适配逻辑，确保新增品类的字段能正确纳入索引体系。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `INDEX_FIELD_FILTER` | 按品类+SKU编码过滤 | 适配厨卫电器多细分品类、多SKU的特征，避免跨品类数据混淆 |
| `SYNC_INTERVAL_HOURS` | 24小时 | 匹配融资日报每日更新的节奏，避免频繁拉取占用带宽 |
| `PARSE_FIELD_UNIT_MAPPING` | 预设出货额→元、应付款→万元的映射规则 | 统一不同数据源的单位格式，避免字段解析错误 |
| `MAX_RECALL_FILTER_COUNT` | 前10条 | 限制单轮召回的品类数量，适配厨卫电器细分品类多的场景 |
| `API_KEY_SCOPE` | 仅融资数据组可见 | 保护融资相关敏感字段的访问权限 |
| `UPGRADE_REINDEX_ENABLED` | true | 升级版本时自动触发增量重索引，兼容新增SKU品类 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：针对4.8.22版本，本地部署后无法访问OneAPI服务，界面提示`ETIMEDOUT`连接超时。原因：未配置`ONEAPI_BASE_URL`参数的本地映射路径，且未开放对应端口的出站权限。
- 现象：添加豆包模型后提示API key无效，无法完成配置。原因：未在`MODEL_API_KEY_CONFIG`中正确配置密钥作用域，或密钥格式不符合平台要求。
- 现象：按品类过滤融资日报时，返回结果为空。原因：未在`INDEX_FIELD_FILTER`中配置品类与SKU编码的关联规则，导致索引未正确绑定分类信息。

## 怎么确认配好了
- 查看数据同步日志，确认每日凌晨的增量同步任务正常完成，无报错信息。
- 测试按品类、SKU编码过滤数据，确认返回结果与预设的过滤规则一致。
- 尝试添加新的模型，确认API key配置后能正常调用，无权限报错。
- 查看团队成员管理界面，确认成员数量限制参数与实际使用人数匹配，无超限提示。
