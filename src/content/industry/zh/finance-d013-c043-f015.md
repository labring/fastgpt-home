# 商业地产融资日报的部署与升级

## 这个品类的数据长什么样
商业地产融资日报的数据来源为地方住建部门地产融资监测平台、合作银行授信台账系统及商业地产项目方报送的备案材料。数据更新节奏为每日凌晨完成前一日全量数据同步。单份日报文档以结构化表格形式存储，核心字段包含项目全称、所属商圈、融资主体资质等级、融资金额、融资方式、实际放款日期、资金投向范围，其中融资金额单位为万元，商圈字段为行政区搭配具体商业地块标识。

## 这些特征在「部署与升级」这一环带来什么约束
商业地产融资日报的结构化字段多且包含枚举类资质字段，要求部署时配置自定义字段映射规则，避免通用解析模板出现字段错位。每日凌晨的全量同步节奏，需将定时任务触发窗口设置在业务低峰期，同时配置增量同步断点续传机制，防止重复拉取或数据遗漏。融资主体资质等级的枚举项需提前在平台维护，版本升级时需兼容旧版枚举项，避免历史数据解析失败。资金投向范围的文本长度较长，需调整文档解析的分段参数，防止长文本截断导致字段提取不全。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 商业地产融资日报的资金投向文本较长，避免长文档解析超时 |
| `PARSE_CHUNK_SIZE` | `800–1200 字符` | 适配长文本字段的分段提取，防止内容截断 |
| `SYNC_CRON_EXPRESSION` | `0 3 * * *` | 匹配每日凌晨3点的同步节奏，避开业务高峰 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 适配批量导入多项目融资日报的文件大小需求 |
| `RECALL_SCORE_THRESHOLD` | `0.75–0.85` | 过滤低匹配度的融资主体资质字段，提升解析准确性 |
| `CUSTOM_FIELD_MAPPING` | 按日报字段逐一映射 | 适配商业地产融资日报的专属枚举字段，避免通用模板错位 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：执行docker compose启动时出现`failed to pull image redis:7.2`报错，镜像拉取失败。原因：4.9.1及以上版本新增了redis镜像依赖，官方镜像源在部分网络环境下无法正常拉取。
- 现象：无GPU服务器启动容器时出现`OCI runtime create failed`报错，容器启动失败。原因：默认配置启用了GPU加速参数，未修改配置关闭该选项导致无GPU环境下启动异常。
- 现象：导入融资日报后，融资主体资质字段出现大量空值或解析错误。原因：未配置自定义字段映射规则，使用通用解析模板无法匹配商业地产专属的枚举字段。

## 怎么确认配好了
- 运行配置校验命令，确认定时同步任务的触发规则与业务更新节奏一致。
- 上传单份测试用商业地产融资日报文档，核对解析后的字段与日报原生结构是否匹配。
- 查看容器运行日志，确认redis服务正常启动，无镜像拉取相关报错。
- 触发一次手动同步任务，验证增量同步仅处理新增数据，无重复拉取行为。
