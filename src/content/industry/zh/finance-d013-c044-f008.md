# 商业物业融资日报的工具调用与插件

## 这个品类的数据长什么样
该品类的数据来源于商业物业运营管理系统的每日台账、合作金融机构的融资对接接口、地方金融监管的备案数据库。数据更新节奏为每日凌晨完成前一日全量同步。文档为结构化表格格式，每行对应单个物业项目的融资相关信息，包含项目名称、物业坐落地址、可运营面积（单位平方米）、融资申请金额（单位万元）、审批通过金额（单位万元）、放款日期、融资机构名称、融资期限（单位月）、资金用途等字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据特征对工具调用与插件配置带来多项约束。多源数据来源要求配置多套MCP服务对接，且需统一处理不同接口的返回格式差异。每日更新的节奏要求定时触发的工具调用任务匹配数据同步周期，避免调用过时信息。结构化表格的格式要求工具调用时指定精准的字段提取规则，避免返回无关内容。不同字段的单位差异（平方米、万元、月）要求插件内置单位校验逻辑，防止计算时出现单位不匹配的错误。单个物业项目可能存在多笔融资记录，需要工具调用支持按项目ID去重，确保返回数据的唯一性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MCP_SERVER_URLS` | `["http://物业运营数据接口地址", "http://金融机构融资接口地址", "http://监管备案接口地址"]` | 该品类需对接三类数据源，多地址配置可实现多源融资数据拉取 |
| `SCHEDULE_CRON` | `"0 1 * * *"` | 数据每日凌晨同步，该表达式可在每日凌晨1点触发工具调用，匹配数据更新节奏 |
| `PARSE_FIELD_RULE` | `"提取字段：项目名称,物业坐落,融资申请金额,审批通过金额,放款日期"` | 结构化表格格式要求精准提取指定字段，避免返回冗余无关信息 |
| `UNIT_VALIDATION_ENABLE` | `true` | 不同字段存在平方米、万元、月等单位差异，开启校验可避免单位不匹配错误 |
| `ENABLE_DUPLICATE_CHECK` | `true` | 单个物业项目可能存在多笔融资记录，开启去重可确保返回数据唯一性 |
| `MAX_TOOL_CALL_STEPS` | `3` | 多源数据拉取最多需要3次工具调用，避免无效循环调用 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用时触发知识库搜索，但返回的结果未包含对应物业项目的运营文档。原因：未在工具调用配置中绑定对应物业分类的知识库索引，导致搜索范围与工具数据的业务场景不匹配。
- 现象：部署MCP服务后调用返回503状态码。原因：未在4.9.6版本中配置MCP服务的健康检查端口与访问权限，导致平台无法正常识别服务的可用状态。
- 现象：工具返回的字段数值出现计算错误，如将面积的平方米数值与融资金额的万元数值直接相加。原因：未开启`UNIT_VALIDATION_ENABLE`配置，插件未对不同字段的单位进行校验，导致数据计算逻辑异常。

## 怎么确认配好了
- 手动触发工具调用任务，检查返回结果是否包含配置中指定的字段，且字段单位符合业务要求。
- 查看平台的定时任务日志，确认每日凌晨的工具调用是否正常执行，且拉取的数据时间范围匹配前一日的更新周期。
- 测试多源数据拉取，检查是否能同时获取三类数据源的融资信息，且无重复的物业项目记录。
- 触发关联的知识库搜索，确认搜索结果与当前工具调用的物业项目范围一致。
