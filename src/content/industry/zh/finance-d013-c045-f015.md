# 商用车融资日报的部署与升级

## 这个品类的数据长什么样
商用车融资日报的数据来源于合作商用车经销商运营系统、金融机构放款核心系统及车辆动态监控平台。更新节奏为每日生成前一自然日的全量或增量报表，T日凌晨完成当日数据归集。文档为结构化格式，单份文件按车辆识别码（VIN）分组，每条数据包含车辆识别码、车型类别、融资本金、放款日期、首期还款日、累计运营里程、挂靠主体等字段。其中融资本金单位为万元，累计运营里程单位为公里，无冗余非业务字段。

## 这些特征在「部署与升级」这一环带来什么约束
该品类数据的唯一标识为VIN码，部署时需配置主键校验规则，避免重复导入同车辆的融资数据。字段包含单位明确的数值型字段，部署时需配置单位转换与校验逻辑，防止与其他品类的单位规则混淆。日报按每日固定节奏更新，部署时需将定时同步任务的触发时间与数据源生成节奏对齐，避免数据滞后或重复。数据关联挂靠主体信息，部署时需配置跨表关联的查询超时参数，防止因关联数据过多导致查询失败。升级时需兼容旧版配置文件的迁移逻辑，避免因配置格式变更导致服务中断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 商用车融资日报单文件包含多组车辆数据，解析校验耗时较长，需延长超时时间 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单份商用车融资日报的结构化文件通常不超过该大小，避免上传中断 |
| `SYNC_INCREMENTAL_FIELD` | `update_time` | 该品类日报按每日更新，以`update_time`作为增量同步标识可精准匹配数据更新节奏 |
| `RDS_WHITELIST_IP` | `FastGPT部署服务器公网IP` | 阿里云RDS默认拦截非白名单访问，需配置部署服务器IP以建立数据库连接 |
| `VERSION_COMPATIBLE_MODE` | `auto_migrate` | 升级至v4.8.20及以上版本时，自动迁移旧版`config.json`配置，无需手动修改 |
| `MAX_CONTEXT_LENGTH` | `8000 字符` | 商用车融资日报单条数据字段较多，需足够上下文长度完成字段映射与校验 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：连接阿里云RDS时报错`Access denied for user 'xxx'@'xxx' (using password: YES)`，状态码1045。原因：未将FastGPT部署服务器的公网IP添加至RDS白名单，导致访问被拦截。
- 现象：升级至v4.8.20后仍提示读取`config.json`配置。原因：未开启版本兼容的自动配置迁移开关，旧版配置文件未被自动替换。
- 现象：部署后版本显示为v4.8.17，与目标v4.8.20不符。原因：拉取镜像时未指定版本标签，默认拉取了旧版稳定镜像，未执行指定版本的拉取命令。

## 怎么确认配好了
- 上传一份模拟的商用车融资日报文件，执行解析测试，核对解析后的字段是否包含`vin`、`累计运营里程`、`融资本金`等特有字段，字段单位与业务预期一致。
- 登录阿里云RDS控制台，查看白名单列表，确认FastGPT部署服务器的公网IP已被添加至允许访问列表。
- 查看FastGPT系统的版本信息页面，确认当前运行版本为目标版本，无配置文件读取相关报错日志。
- 触发一次手动同步任务，核对同步后的数据库中新增的数据条数与上传文件的条目数一致。
