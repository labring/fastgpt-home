# 固废处理融资日报的引用来源与溯源

## 这个品类的数据长什么样
固废处理融资日报的数据来源主要为全国公共资源交易平台、地方生态环境部门官方公示、行业专项融资数据库。更新节奏为每日更新，覆盖当日及近7日内的固废处理领域融资项目。文档结构以结构化表格为主，附带项目简要说明，核心字段包含项目名称、固废处理细分类型、融资金额、融资主体、投资主体、发布日期、原始来源链接，金额单位多为万元或亿元。

## 这些特征在「引用来源与溯源」这一环带来什么约束
固废处理融资日报的多官方数据源特性，要求溯源系统支持校验不同平台链接的有效性与权威性，防止非合规来源混入数据。每日更新的节奏，要求溯源配置的定时拉取间隔适配每日数据刷新周期，避免数据滞后或遗漏。结构化的字段设计，要求溯源环节精准绑定每个字段对应的原始数据位置，不能仅关联整页文档。固废处理细分类型的多样性，要求溯源信息同时记录项目分类标签的原始标注来源，确保分类信息可追溯。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `source_link_check` | `开启` | 固废处理融资日报的来源多为官方平台，开启校验可过滤无效或非合规链接 |
| `crawl_interval` | `86400 秒` | 数据每日更新，匹配日报的刷新周期，确保每日拉取最新数据 |
| `max_chunk_size` | `800–1200 字符` | 适配结构化表格与项目说明的内容长度，避免拆分破坏字段关联 |
| `recall_top_k` | `前 6 条` | 单篇日报的融资项目数量通常有限，召回过多会引入无关内容 |
| `field_source_bind` | `按字段绑定原始位置` | 结构化文档的每个字段需对应独立溯源信息，确保每个数据项可追溯 |
| `parse_timeout` | `300 秒` | 多源拉取时需足够时间完成多个平台的链接校验与文档解析 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：输入中文提问后，返回结果未引用知识库中固废处理融资日报的对应来源链接。原因：未开启`source_link_citation`配置，或召回分段时丢失了原始链接字段。
- 现象：系统返回`408 Request Timeout`错误。原因：`parse_timeout`设置值小于实际多源拉取与解析的总耗时，导致任务中断。
- 现象：无法正常解析Notion格式的固废处理融资日报来源链接。原因：未配置支持第三方协作平台链接的解析规则，仅适配了标准HTTP/HTTPS公开网页链接。

## 怎么确认配好了
- 手动上传一篇固废处理融资日报的示例文档，查看解析后的数据字段是否完整保留原始来源链接。
- 发起一条针对具体融资项目的中文提问，确认返回结果中附带了该项目对应的原始来源链接。
- 查看系统日志，确认未出现`408 Request Timeout`或`400 Bad Request`类的链接校验错误。
- 调整`recall_top_k`的取值，验证召回结果的数量是否符合预期的项目覆盖范围。
