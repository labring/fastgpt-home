# 国有大行融资日报的工作流编排

## 这个品类的数据长什么样
这个品类的数据来自国有大行总行运营管理部门每日归集的对公信贷、同业拆借、零售融资的核心交易系统数据，经内部合规校验后生成标准化日报文件。更新节奏为每日固定时点生成前一自然日的完整报表。文档结构为固定列宽的TXT格式或结构化CSV格式，包含业务主体编码、业务发生日期、投放金额、到期日期、授信额度、业务类型等字段，金额字段单位为人民币亿元，笔数字段为整数计数，日期字段为YYYY-MM-DD格式。

## 这些特征在「工作流编排」这一环带来什么约束
首先，数据来源为国有大行内部专属业务系统，工作流的数据源配置需对接专用内部接口，需配置专属身份认证参数。其次，更新节奏为每日固定时点生成前一日报表，工作流需配置定时触发规则，匹配日报生成后的处理窗口。第三，文档格式为固定列宽或结构化CSV，工作流的文档解析节点需配置对应格式的解析参数，严格匹配字段列的位置或名称，避免解析错位。第四，字段包含合规校验要求，工作流需配置字段合法性校验步骤，过滤异常数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `HTTP_REQUEST_TIMEOUT` | 600 秒 | 对接国有大行内部系统时，内部接口响应延迟通常较高，600秒可覆盖完整数据拉取流程 |
| `文档解析模式` | 固定列宽解析 | 国有大行融资日报多采用固定列宽TXT格式，匹配该模式可准确提取各字段内容 |
| `字段校验规则` | 金额字段≥0，业务编码长度为16位 | 匹配国有大行内部业务编码规范与金额合规要求，过滤异常数据 |
| `SSL_VERIFY_ENABLE` | 开启 | 国有大行内部接口需加密传输，开启SSL校验可确保数据传输安全 |
| `工作流节点串联顺序` | 数据源节点→文档解析节点→字段校验节点→结果输出节点 | 遵循数据处理的正向流程，避免前置节点未完成导致后续节点报错 |
| `文件输出格式` | TXT | 匹配国有大行融资日报的内部接收格式要求，便于后续系统对接 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：HTTP请求节点无法传递TXT格式的文件参数，返回400 Bad Request错误。原因：未配置`multipart/form-data`请求头，导致后端无法识别文件流。
- 现象：工作流中无法找到文本加工模块，导入的外部工作流可正常显示该模块。原因：未开启工作流的高级功能开关，或当前使用的FastGPT版本未更新至支持该模块的版本。
- 现象：在机器人配置页面添加工作流节点时，无法选择已创建的融资日报工作流，仅能单独运行工作流。原因：未将工作流配置为可被机器人调用的共享节点，或未开启工作流的对外暴露权限。

## 怎么确认配好了
- 手动触发工作流，查看HTTP请求节点的运行日志，确认成功拉取到完整的日报文件。
- 查看文档解析节点的输出结果，确认所有配置的字段均被正确提取。
- 输入预设的异常数据（如负金额、不符合长度要求的业务编码），验证字段校验节点是否会拦截该数据。
- 查看结果输出节点的生成文件，确认格式与国有大行内部要求的TXT格式一致。
