# 基建工程融资日报的引用来源与溯源

## 这个品类的数据长什么样
基建工程融资日报的数据主要来自住建部门公开公示文件、商业银行授信披露公告、行业协会统计简报。数据更新节奏为每个工作日发布当日最新披露的融资项目信息。单篇文档结构包含项目名称、承建主体、融资金额、融资方式、发布日期、披露来源链接等字段，其中融资金额以万元或亿元为单位，部分项目会附带地方发改委批复文号。

## 这些特征在「引用来源与溯源」这一环带来什么约束
基建工程融资日报的官方公示来源多带有明确的发布主体与链接，要求溯源时需匹配披露来源的官方域名，避免非授权转载内容混入。单篇文档包含多维度字段，召回时需精准匹配项目名称、融资金额等核心字段，否则溯源结果会出现关联错误。工作日更新的节奏要求知识库同步频率与发布周期对齐，否则溯源内容会滞后于最新披露信息。部分项目附带批复文号，溯源时需将该字段纳入关联校验，确保引用内容与原始披露完全对应。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity_threshold` | 0.65–0.75 | 基建工程融资日报核心字段辨识度高，该区间可过滤低关联的非项目类内容，同时保留同项目不同披露来源的关联结果 |
| `retrieval_limit` | 前8条 | 单篇日报内容紧凑，8条召回可覆盖单项目多来源披露信息，避免冗余 |
| `rerank_top_n` | 前5条 | 优先展示官方发布的权威来源，符合基建项目融资信息的合规展示要求 |
| `sync_interval` | 24小时 | 匹配工作日更新节奏，每日同步可确保溯源内容覆盖当日最新披露项目 |
| `enable_source_verify` | 开启 | 校验官方域名，避免非授权转载的内容被当作溯源来源 |
| `required_match_fields` | 项目名称、融资金额 | 确保召回内容与目标项目的核心信息匹配，避免字段错位导致的溯源错误 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：设置`similarity_threshold`为1后，仍出现大量非目标项目的引用内容。原因：基建工程融资日报的项目名称存在简称、全称混用情况，严格1的相似度阈值无法匹配变体表述，导致部分有效来源被过滤或无关内容混入。
- 现象：引用来源中出现无法访问的链接，或显示状态码404。原因：未开启`enable_source_verify`配置，未过滤已失效的官方公示链接，部分旧披露内容的链接已被平台下线。
- 现象：溯源结果未包含地方发改委批复文号对应的内容。原因：未将`required_match_fields`配置为包含批复文号，仅匹配项目名称与金额，导致关联字段缺失的内容无法被正确召回。

## 怎么确认配好了
- 进入知识库管理界面，查看`sync_interval`配置项，确认取值与工作日更新节奏匹配。
- 发起一条包含具体基建项目名称与融资金额的查询，查看返回结果的引用列表，确认官方域名的链接占比符合预期。
- 手动调整`similarity_threshold`的取值，对比前后两次查询结果的关联数量变化，验证配置生效。
- 复制一条已失效的官方链接加入测试知识库，发起相关查询，确认系统未将该失效链接纳入有效引用来源。
