# 多元金融融资日报的工具调用与插件

## 这个品类的数据长什么样
多元金融融资日报的数据主要来源于地方金融监管局的非银机构报送系统、第三方征信机构的公开披露数据集以及交易所固定收益平台的项目公示。更新节奏为每日凌晨更新前一自然日的全量融资项目数据，支持按融资主体、资金方类型筛选下载。文档结构为标准化结构化格式，单条数据包含融资主体名称、主体细分类型、融资金额、融资期限、资金方类型、融资用途、披露日期等字段，其中金额单位统一为万元，期限单位以自然日或自然月标注。

## 这些特征在「工具调用与插件」这一环带来什么约束
标准化结构化的字段要求工具调用时需严格匹配字段名，避免因字段模糊匹配导致的数据错位；每日更新的频率要求插件定时拉取的周期需与数据更新节奏对齐，避免重复拉取旧数据或遗漏当日最新条目；多源数据来源的特性要求工具调用需配置多源校验逻辑，确保返回数据的一致性；字段单位的固定性要求插件在数据整合阶段需统一单位转换规则，避免出现金额单位混乱的问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_fetch_interval` | `86400 秒` | 匹配多元金融融资日报T+1的更新节奏，避免重复拉取旧数据 |
| `tool_call_field_match_mode` | `精确匹配` | 融资日报字段标准化程度高，精确匹配可避免字段错位与数据混淆 |
| `max_context_window` | `8000–12000 字符` | 单条融资项目包含多组字段，充足的上下文窗口可容纳多笔项目的完整信息 |
| `workflow_api_timeout` | `600 秒` | 多源数据拉取与校验需预留足够时长，避免拉取过程超时中断 |
| `rag_recall_top_k` | `前 10 条` | 聚焦大额或重点融资项目，减少冗余数据对工具调用结果的干扰 |
| `workflow_trigger_keywords` | `按融资主体名称匹配` | 适配按特定融资主体筛选融资日报的业务需求，精准触发自定义接口 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用返回的融资日报数据中，字段后附带知识库引用标记[1]。原因：未关闭工具调用结果与知识库召回的关联开关，导致大模型在整合结果时混入了知识库片段的引用标识。
- 现象：输入指定融资主体关键词后，未触发自定义接口回复，直接返回默认回答。原因：未在`workflow_trigger_keywords`配置中绑定自定义接口的触发规则，或规则未设置为最高优先级。
- 现象：调用工作流拉取融资日报时返回`408 Request Timeout`错误。原因：未将`workflow_api_timeout`配置调整至适配多源数据拉取的时长，导致数据拉取过程超时。

## 怎么确认配好了
- 手动触发工具调用，查看返回的融资日报数据是否仅包含前一日的披露条目，无多余引用标记。
- 输入预设的触发关键词，确认系统跳转至自定义接口并返回对应内容。
- 查看工作流运行日志，确认`plugin_fetch_interval`参数的执行周期与预期一致，无重复拉取记录。
- 传入缺失必填参数的测试请求，确认返回对应错误码，验证参数校验逻辑生效。
