# 多元金融融资日报的部署与升级

## 这个品类的数据长什么样
多元金融融资日报的数据主要来自非银金融机构的内部融资台账、同业拆借系统及公开债券发行公告。每日更新频率为收盘后12小时内完成全量同步。文档以结构化表格为核心载体，附带单条融资项目的补充公告附件。标准字段包含融资主体全称、融资规模（单位为万元或亿元）、融资期限、年化利率区间、资金方类型、公告发布日期，部分条目包含担保方信息与资金用途说明。

## 这些特征在「部署与升级」这一环带来什么约束
该品类数据的高频更新特性要求部署时配置短周期的增量同步任务，避免全量拉取占用过多系统资源。文档以结构化表格为核心的结构，要求解析环节优先启用表格结构化提取模式，适配字段规整的数据源。字段附带不同单位的要求，需要在数据预处理环节配置单位归一化规则，确保后续分析的一致性。附件格式包含公告类PDF与结构化文档，需额外配置对应格式的解析插件，适配非标准排版的补充材料。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `SYNC_INTERVAL_MINUTES` | `15–30 分钟` | 数据每日收盘后12小时内更新，短周期增量同步可保证数据时效性 |
| `PARSE_TABLE_ENABLED` | `开启` | 文档以结构化表格为核心载体，启用后可精准提取规整的字段信息 |
| `DATA_UNIT_NORMALIZATION` | `启用并配置万元/亿元自动转换规则` | 融资规模字段存在双单位格式，需统一单位后适配下游处理逻辑 |
| `PARSE_ATTACHMENT_SUPPORT` | `PDF、DOCX、HTML` | 补充附件多为公告类文档，覆盖主流格式可完整收录数据内容 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 单份公告附件可能包含多页内容，较长超时可避免解析中断 |
| `MAX_INCREMENT_SYNC_SIZE` | `500 条/次` | 每日增量数据量适中，单次同步条数可避免接口调用超时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：解析日志显示`ocr error`报错。原因：未配置对应格式的OCR解析插件，或附件中的公告图片分辨率不足导致识别失败。
- 现象：调用模型时返回`401 Unauthorized`或`invalid api key`报错。原因：未正确配置模型密钥的环境变量，或使用的模型镜像未完成初始化拉取。
- 现象：新部署环境启动后提示字段缺失或格式不匹配报错。原因：未配置数据预处理环节的单位归一化规则，导致融资规模字段的双单位格式无法被下游流程识别。

## 怎么确认配好了
- 执行手动触发的增量同步任务，核对同步完成后的数据条目数与数据源当日更新量匹配。
- 随机选取5条融资日报数据，核对提取的字段内容与原始文档的对应信息一致。
- 运行模型调用测试脚本，确认无密钥类报错且返回结果包含预设的融资相关字段。
- 查看系统解析日志，确认OCR解析环节未出现异常报错，附件处理流程正常执行。
