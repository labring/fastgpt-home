# 大气治理融资日报的引用来源与溯源

## 这个品类的数据长什么样
大气治理融资日报的数据主要来自生态环境部门公开项目公示、地方发改委融资备案公告、行业协会统计简报及上市企业定期公告。数据更新节奏为每日更新，覆盖当日新公示的大气治理相关投融资项目。单篇文档包含项目名称、所属行政区域、总投资规模、融资主体、到位资金额度、批复日期、官方公示链接等字段，总投资与到位资金单位统一为万元。

## 这些特征在「引用来源与溯源」这一环带来什么约束
数据来源分散且多为官方公开渠道，要求溯源环节需关联每个项目对应的唯一官方公示标识与备案ID，避免跨数据源混淆。每日更新的节奏要求溯源配置支持增量拉取与去重，防止重复引用同一条融资记录。字段中包含的官方公示链接需作为核心溯源凭证，需配置自动校验链接有效性的逻辑，避免引用失效内容。同时，大气治理项目的融资信息存在区域细分属性，溯源环节需保留行政区域字段作为分类依据，便于按区域回溯对应数据源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `citation_source_type` | `官方公示链接+唯一项目ID` | 大气治理融资日报的核心溯源凭证为官方公示链接与项目备案ID，可精准匹配数据源 |
| `citation_update_interval` | `86400 秒` | 数据每日更新，按自然日周期拉取可覆盖当日新增融资项目 |
| `verify_citation_url` | `开启，超时阈值30 秒` | 官方公示链接存在时效性，需定期校验可用性，避免引用失效内容 |
| `chunk_max_length` | `800–1200 字符` | 单篇融资日报包含多字段信息，分段长度适配字段完整性与上下文关联 |
| `retrieve_top_k` | `前 3 条` | 大气治理融资项目信息集中度高，召回过多条目会增加溯源复杂度 |
| `citation_field_include` | `项目名称、行政区域、公示链接` | 核心溯源需保留可验证的关键字段，避免冗余信息干扰 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用对话接口返回的回答中无`cite_id`字段。原因是未配置`citation_source_type`参数，未开启引用溯源的唯一标识生成逻辑。
- 现象为查看知识库引用时出现`400 Bad Request`报错。原因是`chunk_max_length`取值过大，导致文档分段超出接口处理上限。
- 现象为知识库搜索的变量引用无法正确关联大气治理项目的区域字段。原因是未在`citation_field_include`中配置行政区域字段，导致溯源时丢失分类依据。

## 怎么确认配好了
- 发起包含大气治理融资项目关键词的知识库搜索，查看返回结果的引用模块，确认每个引用项均附带官方公示链接与唯一标识。
- 查看系统定时任务日志，确认每日拉取任务成功执行，无链接校验失败或超时记录。
- 调用对话接口，检查返回的回答中包含`cite_id`字段与对应溯源链接。
- 调整`retrieve_top_k`参数后，核对召回条目数量与配置取值一致。
