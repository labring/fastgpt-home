# 大气治理融资日报的知识库检索与召回

## 这个品类的数据长什么样
大气治理融资日报的数据主要来自地方生态环境部门项目公示、发改委融资备案公告、专业环保产业咨询机构的公开调研数据。更新节奏为每个工作日更新，覆盖当日及近3个工作日内的大气治理相关融资项目。单份文档结构固定，包含项目名称、所属区域、治理类型（如VOCs管控、扬尘防治）、融资金额、融资主体、投资方、备案日期共7个核心字段，其中融资金额单位为万元，日期字段采用YYYY-MM-DD格式，部分文档附带项目审批文号。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类数据来源分散且格式多样，包含PDF公示文件、Excel备案表、网页新闻稿等多种形态，导致知识库上传时需兼容多类文件解析逻辑，分块策略需兼顾结构化字段与非结构化项目描述内容。固定字段与多类治理类型的组合，要求检索时需同时匹配核心字段语义与治理场景特征，避免泛化召回无关项目。每日更新的节奏要求知识库增量同步机制需支持按日期增量拉取，且需避免重复收录同项目的多版本融资信息。数值型的融资金额字段，需支持结构化提取与范围检索，提升检索精准度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 800–1200 字符 | 大气治理融资日报包含长文本的项目背景描述与结构化字段，该区间可平衡上下文完整性与检索精准度 |
| `topK` | 前8–12条 | 单工作日内的融资项目数量适中，该取值可覆盖当日及近两日的有效项目，避免召回冗余 |
| `similarityThreshold` | 0.72–0.78 | 治理类型与融资主体存在较多语义近似表述，该区间可过滤低相关结果同时保留同义词匹配结果 |
| `incrementalUpdateInterval` | 每4小时 | 匹配工作日更新节奏，避免延迟过久或重复拉取 |
| `structuredExtractFields` | 项目名称,所属区域,治理类型,融资金额,备案日期 | 对应日报固定字段，开启结构化提取后可支持精准字段检索 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传大气治理融资日报文件后，检索特定项目名称无匹配结果。原因：未开启结构化字段提取功能，或分块长度设置过长导致项目名称被截断，无法被语义检索匹配。
- 现象：语义检索返回结果中出现大量重复的同项目融资信息。原因：未设置`maxContextWindow`参数或引用上限取值过大，导致同一项目的多份文档片段被重复召回。
- 现象：知识库搜索时返回报错`invalid configuration parameter name "hnsw.max_scan_tuple`。原因：手动修改了向量检索引擎的底层配置参数，未使用平台提供的官方参数配置，导致参数名不被当前版本支持。

## 怎么确认配好了
- 上传1份典型的大气治理融资日报文档，查看解析后的分块内容，确认核心字段被正确提取与分块。
- 发起针对特定治理类型的检索，核对返回结果的治理类型匹配度，调整相似度阈值至符合业务需求。
- 手动触发一次增量同步，查看同步日志确认当日最新的融资项目被成功收录，无重复条目。
- 查看向量库配置页面，确认未手动修改非官方允许的底层参数，避免出现配置报错。
