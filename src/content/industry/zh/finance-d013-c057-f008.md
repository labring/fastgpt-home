# 小家电融资日报的工具调用与插件

## 这个品类的数据长什么样
小家电融资日报数据主要来自家电行业供应链金融服务平台、品牌方商家融资台账及电商平台交易履约记录。数据更新节奏为每日T+1同步前一日全量融资交易。单份日报文档按SKU维度拆分，核心字段包含SKU编码、品牌名称、单SKU融资额度（单位：万元）、放款日期、供应链合作方名称、融资期限（单位：天）、回款履约状态。所有字段均为结构化格式，无自由文本冗余内容。

## 这些特征在「工具调用与插件」这一环带来什么约束
小家电融资日报的SKU维度拆分特征，要求工具调用需按SKU做批量处理，避免单次请求过载。每日T+1的更新节奏，限定插件定时触发的频率为每日一次，不宜设置更高的调用频次。固定的结构化字段要求工具调用的参数需严格匹配预设字段名，无法兼容非预设字段的查询。小家电SKU数量较多的场景下，工具调用需支持分页参数，控制单次返回的条目数。融资额度与期限的固定单位，要求插件在数据返回时统一转换为预设单位，避免单位混乱。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_batch_size` | `10-20 条/请求` | 小家电SKU数量较多，批量过大会触发接口限流，过小会增加调用次数 |
| `schedule_trigger_cron` | `0 1 8 * * *` | 融资日报为T+1更新，每日早8点可获取前一日全量数据，匹配更新节奏 |
| `tool_field_strict_match` | `开启` | 小家电融资日报为结构化固定字段，严格匹配可避免无效查询 |
| `response_unit_convert` | `统一转换为万元/天` | 融资额度与期限的固定单位要求，避免返回结果单位混乱 |
| `tool_pagination_enable` | `开启` | 小家电SKU数量较多，分页可控制单次请求的数据量，降低接口压力 |
| `tool_request_timeout` | `600 秒` | 结构化数据的批量处理需要一定解析时间，避免超时中断请求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用返回`429 Too Many Requests`状态码，原因：未配置合理的批量调用参数，单次请求处理的SKU数量超出接口限流阈值。
- 现象：自定义插件调用后返回字段为空，原因：未开启`tool_field_strict_match`配置，工具尝试匹配非预设的小家电融资日报字段，无法获取有效数据。
- 现象：定时插件触发时间与融资日报更新节奏不符，原因：Cron表达式配置错误，未设置为匹配T+1更新的每日触发窗口，导致调用时无最新数据可用。

## 怎么确认配好了
- 查看工具调用日志，确认单次请求的条目数符合配置的批量参数，无短时间内大量触发的请求记录。
- 手动触发一次插件调用，检查返回结果的字段与小家电融资日报的预设字段完全匹配，无单位混乱的情况。
- 等待一个定时触发周期，确认插件在预设时间自动执行，且返回的是对应周期的融资日报数据。
- 模拟超出批量限制的请求，验证限流相关配置是否生效，无异常报错出现。
