# 小金属融资日报的工作流编排

## 这个品类的数据长什么样
小金属融资日报的数据主要来自国内专业小金属现货交易平台、海关进出口数据监测机构及金融终端的融资融券模块。数据更新节奏为每日收盘后T+1更新，通常在当日17:00后完成全量数据同步。文档结构分为单品种汇总表与全品类汇总表两种形式：单品种文档包含当日融资买入额、融资余额、融券卖出量、融券余量、现货成交价、行业动态等字段；全品类汇总表则按分类排列所有小金属品种的当日融资数据。字段单位存在明确区分：融资类指标以万元为单位，现货价格以元/吨为单位，成交量以吨为单位。

## 这些特征在「工作流编排」这一环带来什么约束
小金属品类的分散性导致融资日报数据来源多且字段标识存在细微差异，要求工作流需配置多数据源对齐规则，避免字段映射错误。每日固定时间更新的特性要求工作流需绑定精准的定时触发节点，预留数据同步缓冲时间，防止因数据未就绪导致的提取失败。多品种多字段的结构要求工作流需按品种分组处理数据，避免不同品种的指标混同。同时，融资类与现货类指标的单位差异，要求工作流需配置单位校验节点，防止后续分析环节出现单位不统一的问题。此外，小金属行业资讯量相对较少，知识库召回时需控制召回范围，避免引入无关内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发时间` | `每日17:30` | 小金属融资数据通常在17:00后更新，预留30分钟数据同步时间，确保拉取到完整当日数据 |
| `多数据源合并规则` | `按品种名称+统计日期匹配` | 小金属融资日报数据来自多个平台，需通过唯一标识对齐不同来源的同字段数据 |
| `文本内容提取` | `按字段名精准匹配` | 小金属融资日报字段包含`融资买入额(万元)`、`当日收盘价(元/吨)`等明确标识，无需模糊匹配 |
| `全局变量继承开关` | `关闭` | 适配4.8.10版本，避免从带必填全局变量的工作流切换后触发前序校验 |
| `超时阈值` | `600 秒` | 多数据源拉取分散的小金属品种数据，需要较长处理时间，默认阈值无法覆盖全量品种 |
| `知识库召回条数` | `前3条` | 小金属行业资讯量相对较少，过多召回会引入无关内容，影响数据准确性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：文本内容提取组件从绑定的知识库中提取内容时返回空。原因：未配置知识库召回的字段过滤规则，导致召回内容未包含目标融资日报字段。
- 现象：从配置了必填全局变量的工作流切换后，执行时仍触发前序工作流的必填校验。原因：未关闭`全局变量继承开关`，导致跨工作流变量校验冲突，适配4.8.10版本时该问题尤为突出。
- 现象：多数据源拉取小金属融资数据时出现超时错误。原因：未调整`超时阈值`参数，小金属品种较多导致数据拉取处理时间超过默认阈值。

## 怎么确认配好了
- 手动触发工作流，检查各数据源拉取的字段是否与当日小金属融资日报的公开数据一致。
- 验证定时触发功能，确认在设定时间后自动启动工作流，且无提前或延迟执行的情况。
- 测试跨工作流切换操作，确认执行时不会触发前序工作流的全局变量校验。
- 查看工作流运行日志，确认各节点执行时间未超过设定的超时阈值，无数据拉取失败的报错。
