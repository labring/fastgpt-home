# 小金属融资日报的引用来源与溯源

## 这个品类的数据长什么样
小金属融资日报数据主要来自国内有色金属现货交易平台、期货交易所及行业自律组织。数据更新节奏为每日17:00前完成当日收盘后全量更新，单份日报文档按品种分类排版，包含品种名称、融资买入额、融资余额、融券卖出量、库存总量等核心字段，单位统一为人民币万元与物理吨，文档内每条数据对应唯一的交易时段标识与来源机构编号。

## 这些特征在「引用来源与溯源」这一环带来什么约束
小金属融资日报多来源的特性要求溯源环节需关联每条数据对应的原始发布机构，避免跨来源采集的数据混淆。按品种分类的排版结构，要求检索时需绑定品种标识与溯源信息，确保返回结果的溯源标签与对应数据块完全匹配。每日固定更新的节奏，要求溯源环节校验数据的时间戳，过滤超过24小时的过期数据，保证回复内容的时效性。字段与单位的特殊性，要求溯源信息中需完整保留人民币万元、物理吨等单位标注，避免跨品类数据混用导致的信息偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunk_size` | `5000 token` | 匹配小金属融资日报单份文档的平均数据密度，避免单切块拆分过多或过少的有效数据条目 |
| `召回条数` | `前10条` | 小金属融资日报单份文档包含10-20个品种数据，召回10条可覆盖多数常规查询的目标品种 |
| `相似度阈值` | `0.8` | 小金属品种名称无大量同音易混项，该阈值可精准过滤无关检索结果 |
| `引用上限` | `1500 字符` | 符合用户社区常见配置，且可承载每条数据对应的来源、时间、字段等完整溯源信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 单份小金属融资日报文档数据量较大，解析过程需较长时间，避免提前超时导致解析失败 |
| `重排返回条数` | `前6条` | 对召回结果进行二次筛选，保留与查询主题相关性较高的溯源数据，避免冗余信息干扰 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置`引用上限`为1500字符后，仍出现检索结果超出该上限的情况。原因：未同步调整`chunk_size`与`引用上限`的匹配关系，单切块内容过长导致单条返回数据超出引用限制。
- 现象：生成的回复中未包含引用文件的地址。原因：未开启知识库溯源功能，或未在系统提示词中配置包含来源文件地址的输出格式。
- 现象：检索返回的溯源数据中单位标注缺失。原因：未在知识库解析配置中开启保留原始字段单位的选项，导致切块数据丢失单位信息。

## 怎么确认配好了
- 上传一份小金属融资日报文档，查看知识库解析后的切块内容，确认每个切块包含完整的来源、时间、字段及单位信息。
- 发起一条针对特定小金属品种的融资日报查询，查看返回结果的引用标签，确认每条引用都包含对应的来源机构与更新时间。
- 调整`引用上限`为1000字符，发起查询，确认返回的溯源内容总长度不超过该设置值。
