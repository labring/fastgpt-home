# 工程咨询融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
工程咨询融资日报的数据来源为项目融资台账、合作银行放款回执、属地住建部门项目备案接口。更新节奏为每日凌晨完成前一日全量数据同步。单条数据文档结构包含项目唯一标识、工程咨询服务范围、对接银行主体、当日放款金额、融资到账日期、项目建设节点、资金用途共7个核心字段。金额单位为万元，日期格式为YYYY-MM-DD，地区字段精确到地级市。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多来源数据要求接口需兼容不同鉴权协议，部分合作银行接口需使用专用证书校验。每日全量同步的更新节奏，要求HTTP请求需设置合理的批量拉取阈值，避免单次请求数据量过大导致超时。字段包含精确到地级市的地区信息与万元单位的金额，要求外部系统需提前配置字段映射规则，统一单位与格式后再接入。项目唯一标识字段要求接口返回数据需携带不可重复的主键，用于外部系统去重存储。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `BATCH_PULL_SIZE` | `50–100 条/请求` | 匹配每日全量数据的体量，避免单次请求超时 |
| `AUTH_TYPE` | `多协议适配模式` | 兼容银行、住建部门等不同来源的鉴权要求 |
| `FIELD_MAPPING_RULE` | `按字段名一对一映射，金额自动乘以10000` | 统一外部系统的金额单位为元，匹配内部存储规范 |
| `REQUEST_INTERVAL` | `1–3 秒/请求` | 避免触发合作数据源的频率限制 |
| `DATA_DEDUPLICATION_KEY` | `项目唯一标识字段` | 确保外部系统存储数据无重复 |
| `TIMEOUT_THRESHOLD` | `600 秒` | 适配多渠道接口的响应延迟差异，避免提前终止请求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用接口返回`429 Too Many Requests`状态码，原因是未设置`REQUEST_INTERVAL`配置项，触发合作数据源的频率限制。
- 现象为外部系统接收的融资金额与实际放款金额不符，原因是未配置`FIELD_MAPPING_RULE`的金额转换规则，未将万元单位转换为目标系统的元单位。
- 现象为AI生成内容未引用融资日报的HTTP返回数据，原因是未在工作流中配置HTTP接口响应字段的映射，导致AI无法识别有效输入内容。

## 怎么确认配好了
- 发起单次HTTP请求，检查返回字段是否包含所有核心数据项，确认字段映射规则已生效。
- 连续发起多次请求，检查返回状态码无`429`类频率限制错误，确认请求间隔配置合理。
- 导入测试数据至外部系统，检查无重复数据条目，确认去重配置已正确关联主键字段。
- 触发AI调用该接口的工作流，检查生成内容包含融资日报的核心信息，确认字段映射与输入配置无误。
