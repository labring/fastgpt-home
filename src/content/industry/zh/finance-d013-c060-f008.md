# 工程咨询融资日报的工具调用与插件

## 这个品类的数据长什么样
工程咨询融资日报的数据主要来源于工程招投标公示平台、合作银行授信台账、项目方融资报备系统。数据更新节奏为每日凌晨批量同步前一日全量更新条目。单份日报文档按单个融资项目为基础单元，包含项目编号、项目名称、所属区域、融资主体、融资金额、融资方式、审批状态、放款时间等字段。融资金额单位为万元，时间字段采用标准年月日格式，项目类型字段标注市政、商业地产、基建等细分类别。

## 这些特征在「工具调用与插件」这一环带来什么约束
工程咨询融资日报的每日全量更新特征，要求工具调用触发频率限定为每日一次，避免重复拉取历史条目导致数据冗余。多字段且带明确单位的文档结构，要求工具调用插件配置字段映射规则，将融资金额的万元单位与业务系统的金额字段对齐，同时标准化时间字段格式。唯一标识的项目编号字段，要求插件内置去重逻辑，避免重复导入或展示。细分的项目类型与区域字段，要求插件支持按指定维度过滤数据，适配工程咨询场景的分区域、分类别统计需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `触发周期` | 每日凌晨00:30-01:00 | 匹配工程咨询融资日报的每日全量更新节奏，避免与业务系统的日间运维时段冲突 |
| `字段映射` | 将`融资金额`映射为`amount`（单位：万元），`放款时间`映射为`loan_date` | 对齐业务系统的字段命名与单位规范，避免数据解析错误 |
| `去重开关` | 开启，基于`项目编号`字段去重 | 匹配日报按项目为单元的文档结构，消除重复拉取的历史条目 |
| `过滤条件` | 按`审批状态`为「已放款」或「审批通过」过滤 | 适配工程咨询场景的有效融资数据需求，过滤无效待审批条目 |
| `超时时间` | 600秒 | 适配批量拉取多项目数据的耗时需求，避免因数据量较大导致的调用中断 |
| `返回条目上限` | 前200条 | 匹配单份日报的常规条目规模，避免返回数据过多导致的处理延迟 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用节点重复返回同一融资项目的多条数据。原因：未开启基于`项目编号`的去重开关，未限定触发周期为每日一次，导致重复拉取历史更新条目。
- 现象：工具调用返回的融资金额数值异常，例如显示为百万级，正常应为万元级。原因：未配置`字段映射`规则，未对齐单位规范，导致数据解析时单位转换错误。
- 现象：工具调用节点无法接收外部传入的动态过滤参数。原因：未将工具节点的过滤条件配置为可接收外部变量的引用格式，导致无法通过API传递自定义参数。

## 怎么确认配好了
- 触发工具调用节点，检查返回数据的更新时间是否为前一日的融资条目，确认触发周期配置生效。
- 查看返回数据的字段名称与单位，对照配置的`字段映射`规则，确认数据解析正确。
- 检查返回数据中是否存在重复的`项目编号`条目，确认去重开关配置生效。
- 传入动态过滤参数，检查返回数据是否匹配指定的`审批状态`或区域条件，确认变量引用配置生效。
