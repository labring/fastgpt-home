# 工程咨询融资日报的模型接入与配置

## 这个品类的数据长什么样
工程咨询融资日报的数据主要来源于工程咨询机构的项目融资台账、合作银行的授信审批记录、地方发改委公开的基建项目融资公示。更新节奏为每日更新，覆盖前一自然日的新增及变更融资项目。文档结构以单项目为基本单元，包含项目编号、项目名称、所属区域、总融资金额、当日新增融资额、融资方主体、资金方类型、融资方式、发布日期共9个字段，金额字段单位统一为万元，日期字段格式为YYYY-MM-DD。

## 这些特征在「模型接入与配置」这一环带来什么约束
工程咨询融资日报的数据源特性对模型接入与配置环节带来多项约束。每日更新的数据源要求配置定时增量同步机制，避免全量拉取带来的计算冗余与资源浪费；多字段且带明确金额单位的结构化设计，要求配置字段映射规则，确保模型输出的结构化结果与原始数据字段一一对应；单条数据长度适中但批量召回需覆盖同区域同类型项目，要求调整上下文窗口与召回条数参数，平衡信息完整性与上下文溢出风险；数据源包含公开公示与内部台账的混合特性，要求配置权限分层的知识库访问规则，区分内部敏感数据与公开可展示内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 字符 | 工程咨询融资日报单条项目数据约300-500字符，批量召回10-15条完整数据后，需容纳所有内容避免上下文溢出 |
| `retrievalTopK` | 前12条 | 需覆盖同区域同类型项目的横向对比分析，召回过多会增加上下文压力，过少则丢失关键对比维度 |
| `similarityThreshold` | 0.72–0.80 | 需过滤低匹配度的非融资类项目数据，同时保留同细分领域的关联项目，适配工程咨询场景的精准检索需求 |
| `incrementalSyncInterval` | 86400 秒 | 匹配融资日报每日更新的发布节奏，仅同步前一日新增数据，减少不必要的计算开销 |
| `enable_thinking` | 关闭 | 融资日报分析需直接输出结构化结果，无需中间思考过程，避免干扰结果可读性 |
| `referenceRender` | 开启 | 需渲染原始数据的来源链接，方便工程咨询人员验证数据真实性与合规性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 配置`enable_thinking`为关闭后，输出仍包含<think>标签。针对开源版V4.8.21及以上版本，原因是未在模型参数中同步关闭思考输出开关，或使用的模型本身不支持该配置项。
- 使用知识库对话应用的API key调用时提示未授权。原因是未绑定对应知识库的访问权限，或API key的有效期已过期，未在平台中配置正确的权限规则。
- 接入第三方联网API后，返回结果中reference链接未渲染。原因是未开启`referenceRender`配置项，或未正确配置链接解析的跳转规则导致无法正常展示。

## 怎么确认配好了
- 发起单项目融资日报的查询，检查输出结果是否包含完整的字段信息，无多余的<think>标签。
- 调用知识库API接口，使用合法的API key发起请求，确认返回状态码为200且无未授权相关提示。
- 查看查询结果的reference区域，确认链接已以可点击的形式展示，可正常跳转至原始数据源。
- 等待一个完整的同步周期，检查知识库中是否自动更新了前一日的新增融资项目数据。
