# 工程咨询融资日报的部署与升级

## 这个品类的数据长什么样
工程咨询融资日报的数据来源于内部工程管理系统、合作金融机构的接口、政务项目备案平台。更新频率为每日固定时段同步，文档格式为结构化CSV或JSON。单条数据对应单个工程咨询项目的当日融资动态，字段包含项目唯一标识、工程名称、建设地点、融资金额（单位：万元）、融资主体、出资机构、审批进度、到账日期，无额外非结构化附加内容。

## 这些特征在「部署与升级」这一环带来什么约束
每日固定时段的批量数据同步要求部署时配置精准的定时触发规则，避免与业务高峰冲突。结构化固定字段要求部署前完成字段与向量模型的映射配置，防止索引失败。融资金额的数值单位要求配置数据清洗规则，统一单位格式。高频更新场景要求升级时采用滚动发布策略，避免同步流程中断。多字段关联的查询需求要求部署时开启关联字段的召回配置，保障查询准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `SYNC_CRON_EXPR` | `0 0 2 * * ?` | 匹配工程咨询融资日报每日凌晨完成的数据汇总节奏，避开业务高峰时段 |
| `PARSE_FIELD_MAPPING` | `{"项目唯一标识":"id","工程名称":"title","融资金额":"amount","到账日期":"date"}` | 匹配工程咨询融资日报的标准字段命名，确保数据正确映射至向量索引 |
| `VECTOR_SIMILARITY_THRESHOLD` | `0.75` | 工程咨询项目的融资信息关联度较高，该阈值可过滤无关结果，保留有效召回 |
| `RECALL_TOP_K` | `前10条` | 工程咨询融资日报的单页查询需求覆盖范围适中，10条可保障结果完整性与可读性 |
| `DATA_CLEAN_RULE` | `统一金额单位为万元，过滤审批状态为“驳回”的条目` | 聚焦有效融资动态，统一单位格式避免索引异常 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 适配批量同步的结构化数据体量，保障完整解析过程不被中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：部署后无法加载国产化芯片架构下的向量模型，日志返回`Illegal instruction`错误。原因：未提前适配鲲鹏920架构的依赖镜像，直接使用通用镜像部署。
- 现象：SaaS版本运行代码执行节点时返回`500 Internal Server Error`。原因：未配置本地环境依赖，直接调用远程资源导致权限校验失败。
- 现象：配置本地M3E作为索引模型后，召回结果为空。原因：未在模型配置页面指定本地模型的部署地址与端口，导致无法建立连接。

## 怎么确认配好了
- 手动触发一次数据同步，查看同步日志中是否存在字段映射失败的提示，确认配置的字段与源数据字段一致。
- 发起测试查询，输入工程咨询项目的融资相关关键词，核对召回结果的字段与源数据字段匹配度，调整相似度阈值或召回条数。
- 查看定时任务的执行记录，确认每日同步任务在预设时间自动启动并完成，无超时或中断情况。
- 检查模型配置页面，确认本地M3E模型的部署地址、端口与调用参数已正确填写，可通过模型测试接口验证连通性。
- 确认部署使用的FastGPT版本为最新稳定版，避免因旧版本漏洞导致同步异常。
