# 工程机械融资日报的部署与升级

## 这个品类的数据长什么样
工程机械融资日报的数据来源包括工程机械整机厂商的融资租赁系统、合作银行的对公信贷台账、工程机械行业协会的设备备案数据库。数据更新节奏为每日凌晨完成全量同步与增量更新，单份日报文档包含单台或多台设备的融资全链路信息，文档结构分为头部汇总字段与明细条目字段。核心字段包括设备编号、租赁方统一社会信用代码、放款金额、还款逾期天数、设备额定功率，其中放款金额单位为元，设备额定功率单位为kW，还款周期单位为自然日，无冗余的百分比类统计字段。

## 这些特征在「部署与升级」这一环带来什么约束
多源数据对接的需求要求部署阶段需配置多数据源的连接参数与权限校验规则，避免因数据源兼容性问题导致同步失败。每日固定更新的节奏要求定时任务的触发时间需避开业务高峰，升级阶段需确保定时任务的调度配置不被覆盖，否则会导致日报数据更新中断。字段的特定单位规则要求数据解析环节需配置单位校验逻辑，升级后需兼容旧版字段映射，否则会出现解析后数据单位混乱的问题。批量设备明细的文档结构要求解析超时时间需设置合理阈值，避免因单份文档过大导致解析中断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DATA_SYNC_SOURCE_LIST` | `["manufacturer_finance", "bank_credit", "industry_assoc"]` | 覆盖工程机械融资日报的三类核心数据来源，保障数据完整性 |
| `PARSE_FIELD_UNIT_MAPPING` | `{"放款金额":"元", "额定功率":"kW", "还款周期":"自然日"}` | 匹配该品类日报的特定字段单位规则，避免解析后数据单位混乱 |
| `SYNC_TASK_CRON` | `0 2 * * *` | 每日凌晨2点触发同步任务，避开当日业务操作高峰，不影响数据实时性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 单份日报包含多台设备的明细台账，需足够超时时间防止解析中断 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 适配批量设备融资台账的大文件上传需求，避免文件被拦截 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：容器启动后持续重启，无法访问服务接口。原因：未正确配置多源数据同步的权限参数，导致数据源连接失败，容器健康检查不通过。
- 现象：构建部署镜像时提示找不到`rehype-raw`模块，即使已执行依赖安装命令。原因：构建镜像时未将依赖安装步骤写入Dockerfile，或依赖安装时未指定正确的包管理镜像源。
- 现象：无外网私有化部署后，工作流编辑界面显示“Application error: a client-side exception”。原因：未提前拉取前端静态资源的离线包，前端页面无法加载必要的脚本文件。

## 怎么确认配好了
- 执行容器日志查看命令，确认多源数据同步任务无连接报错、解析超时报错。
- 进入平台的解析配置界面，核对字段单位映射配置与预设规则是否一致。
- 上传单条测试用的工程机械融资日报数据，验证解析后字段的单位、格式符合预期。
- 检查定时任务的触发时间，确认同步任务未在业务高峰时段执行。
