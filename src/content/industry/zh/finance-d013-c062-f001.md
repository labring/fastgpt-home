# 广告营销融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
广告营销品类的融资日报数据主要来自传媒行业第三方融资监测平台、广告主投放后台及公开融资披露文件。数据按自然日更新，每日凌晨完成当日数据归集。文档采用结构化格式，包含广告主主体名称、融资轮次标识、融资金额、核心投放渠道等字段，其中融资金额单位为万元，投放渠道字段为枚举类文本，融资轮次字段包含种子轮、天使轮、A轮等标准标识。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
广告营销融资日报的固定更新节奏要求HTTP接口需配置每日定点触发的定时任务，避免拉取未完成归集的当日临时数据。结构化字段包含枚举类文本与金额数值，接口对接时需校验返回字段的枚举值合法性，例如融资轮次是否属于预设的标准枚举集合。融资金额统一以万元为单位，接口需额外配置单位校验逻辑，避免数据源返回其他单位导致的数值偏差。固定的文档结构让接口入参仅需指定日期范围即可完成数据拉取，无需额外动态适配字段。同时，广告主主体名称存在重复或简称变体，接口需支持模糊匹配或主体ID映射，避免数据关联错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `CRON_EXPRESSION` | `0 2 * * *` | 匹配广告营销融资日报的每日凌晨数据归集完成时间，避免拉取未完成的临时数据 |
| `HTTP_TIMEOUT` | `600 秒` | 适配大额融资数据的接口返回延迟，避免因数据量较大触发超时中断 |
| `FIELD_VALIDATION_ENABLE` | 开启 | 校验融资轮次、投放渠道等枚举字段是否符合预设规则，过滤非法数据 |
| `UNIT_CONVERT_RATE` | `1` | 匹配数据源默认返回的万元单位，无需额外数值缩放 |
| `RETRY_MAX_TIMES` | `2 次` | 应对广告平台接口偶尔的临时波动，避免单次请求失败导致数据拉取中断 |
| `ENUM_WHITELIST` | `种子轮,天使轮,A轮,B轮,C轮,Pre-IPO` | 覆盖广告营销领域常见的融资轮次类型，限制非法枚举值传入 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用融资日报接口后触发`400 Bad Request`报错。原因：未在接口入参中指定正确的日期范围，或传入了未在`ENUM_WHITELIST`中的融资轮次参数，导致请求格式非法。
- 现象：HTTP接口返回的融资金额数值与公开披露值不符。原因：未设置`UNIT_CONVERT_RATE`参数，误将数据源返回的元单位转换为万元，导致数值放大10000倍。
- 现象：接口返回的长文本融资日报无法完整推送至下游系统。原因：未开启`LONG_TEXT_SPLIT`开关，长文本超出下游系统的单次接收上限，导致推送失败。

## 怎么确认配好了
- 手动触发一次HTTP接口请求，查看返回结果是否包含广告主主体名称、融资轮次、融资金额等全部预设字段。
- 选取已知披露信息的历史日期，拉取对应融资日报数据，核对融资金额单位为万元，数值与公开信息一致。
- 模拟接口超时场景，查看是否触发预设的重试机制，重试后是否能正常拉取数据。
- 配置定时任务触发，次日查看是否自动拉取当日融资日报数据并推送至指定下游系统。
