# 房建工程融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
房建工程融资日报的数据来源为项目建设方的每日资金报送、合作银行的放款明细台账、地方住建部门的项目资金监管系统。更新节奏为每日凌晨更新前一日的融资数据。单份日报文档包含项目唯一标识、建设地址、总包方全称、当日融资到账额、累计授信额度、资金拨付用途、对应工程进度节点等字段，金额单位统一为万元，日期字段格式为YYYY-MM-DD。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
房建工程融资日报的专属数据特征，会对HTTP接口与外部系统对接带来多重约束。项目专属标识、工程进度节点等非通用字段，要求接口需支持按项目编号、日期范围精准筛选返回内容，避免返回冗余数据。每日更新的节奏，要求定时拉取任务的间隔匹配更新频率，避免高频请求触发接口限流。金额字段以万元为单位，外部系统对接时需统一单位换算逻辑，确保数据展示与业务计算一致。单份日报包含多维度资金信息，接口需支持批量拉取指定日期区间内的多个项目数据，提升同步效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `sync_interval` | `86400 秒` | 匹配房建工程融资日报每日更新的节奏，避免无效请求 |
| `request_timeout` | `30 秒` | 单批次拉取多项目数据量较大，预留足够的请求响应时间 |
| `return_fields` | `项目编号,项目名称,当日融资到账额,工程进度节点` | 覆盖房建融资日报核心业务字段，减少冗余数据传输 |
| `unit_conversion` | `万元转元` | 多数外部业务系统以元为金额单位，统一换算逻辑保障数据准确 |
| `batch_query_limit` | `前 50 条` | 控制单次拉取的项目数量，降低接口负载与传输压力 |
| `auth_type` | `API_KEY 鉴权` | 房建项目融资数据涉及金融敏感信息，保障接口访问安全 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用接口返回`400 Bad Request`状态码，现象是接口返回“缺少必填字段project_id”。原因是对接时未在请求参数中加入房建项目专属的唯一标识字段，仅传入了通用的日期参数。
- 知识库召回结果未包含房建工程的进度节点信息，现象是召回的融资日报内容缺失工程进度字段。原因是配置的`return_fields`参数未包含该字段，导致接口未返回对应数据。
- 定时同步任务频繁触发报错，现象是日志中出现`Too Many Requests`错误。原因是同步间隔设置过短，超过了接口的限流阈值，导致请求被拦截。

## 怎么确认配好了
- 发起单次接口请求，传入已知的房建项目编号与日期，检查返回结果是否包含预设的核心字段。
- 查看定时同步任务的执行日志，确认请求间隔符合预设的`sync_interval`配置，无频繁触发的报错。
- 对接外部系统后，核对展示的金额数值与接口返回的万元数值是否匹配，确认单位换算逻辑生效。
- 测试批量拉取功能，传入指定日期区间与项目范围，检查返回的项目数量符合预设的批量限制。
