# 房建工程融资日报的部署与升级

## 这个品类的数据长什么样
房建工程融资日报的数据主要来自住建部门项目备案系统、合作银行的授信放款台账、施工方提交的进度款融资申请。更新节奏为每日凌晨批量归集前一日的全量有效数据。单份日报文档结构分为项目基础信息、融资明细、资金用途三个模块，核心字段包含项目编号、施工许可编号、融资金额（单位：万元）、到账时间、担保方式，部分项目附带进度节点对应的融资占比字段。

## 这些特征在「部署与升级」这一环带来什么约束
多源数据接入要求部署时配置跨系统接口鉴权参数，避免因权限配置错误导致数据拉取失败。每日批量更新的节奏要求定时任务调度配置适配凌晨低峰时段，同时预留数据校验窗口。特定字段如施工许可编号、项目编号的格式校验规则，需在部署时预设，升级时不能随意调整字段解析逻辑。可选字段进度节点融资占比的兼容处理，需在升级包中保留旧版解析逻辑，避免存量数据无法正常加载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `CRON_EXPRESSION` | `0 0 3 * * *` | 适配每日凌晨3点的批量数据归集节奏，避开业务高峰时段 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `900 秒` | 房建融资日报单份文档数据量较大，需预留充足的解析时间 |
| `DATA_SYNC_RETRY_TIMES` | `3 次` | 多源数据拉取易受网络波动影响，设置合理重试次数保障数据完整性 |
| `FIELD_VALIDATION_STRICTNESS` | `宽松模式` | 部分老旧项目的融资字段格式不规范，宽松模式可兼容存量数据 |
| `MAX_BATCH_SIZE` | `500 条/批` | 适配每日归集的项目数量规模，避免单批数据过载导致部署节点卡顿 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 房建融资日报附带的项目图纸、合同附件较多，需预留足够的上传空间 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 升级至v4.8.22后，数据同步任务出现「引用资源无法下载」报错，状态码为403。原因是升级包未正确更新多源数据对接的鉴权配置文件，导致原有接口权限失效。
- 部署完成后初始界面为中文，完成首次数据牵引后界面切换为英文。原因是未在环境变量中固定`DEFAULT_LANGUAGE`参数，数据同步任务触发了全局语言配置重置。
- 调用本地部署的大模型时出现「模型未找到」报错。原因是未在`LOCAL_LLM_ENDPOINT`配置项中填写正确的本地模型服务地址，或未开放对应端口的访问权限。

## 怎么确认配好了
- 手动触发一次数据同步任务，查看同步日志中是否存在字段校验失败的提示，确认`FIELD_VALIDATION_STRICTNESS`配置符合预期。
- 检查定时任务调度面板，确认`CRON_EXPRESSION`配置的执行时间与预设的每日归集时段一致。
- 上传一份测试用的房建融资日报文档，确认文档解析完成后核心字段可正常提取，无超时报错。
- 访问本地模型服务地址，确认`LOCAL_LLM_ENDPOINT`配置的地址可正常连通，无网络拦截问题。
