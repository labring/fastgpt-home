# 投资平台融资日报的知识库检索与召回

## 这个品类的数据长什么样
投资平台融资日报的数据主要来自公开监管披露平台、企业官方融资公告、第三方交易数据接口。更新节奏为交易日每日更新，非交易日暂停同步。单条文档以结构化字段为主，包含融资主体全称、融资金额（单位为万元或亿元）、融资轮次、投资方名单、披露日期、所属行业分类、项目简介等字段。文档整体篇幅差异较大，建议按自有样本统计或实测后确定单条篇幅情况，部分附带结构化明细表格。

## 这些特征在「知识库检索与召回」这一环带来什么约束
公开分散的数据源要求支持多源文档合并去重，避免重复收录同一份融资公告。每日更新的节奏要求适配增量同步机制，避免全量同步占用过多服务器资源。结构化字段占比高的特征要求优先支持字段级召回，仅依赖全文检索无法精准匹配用户需求。核心字段如披露日期、融资金额的检索优先级更高，需调整检索权重匹配用户真实筛选逻辑。短篇幅文档的分段要求不宜过长，避免拆分后割裂结构化字段的关联信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `召回条数` | 前8-12条 | 融资日报单批次检索条目较多，过多结果会增加用户筛选成本，过少则无法覆盖当日全部有效融资信息 |
| `相似度阈值` | 0.72-0.85 | 结构化字段匹配优先级高于全文匹配，该区间可过滤低相关的非目标融资条目，同时保留同行业同轮次的相关结果 |
| `分段长度` | 1000-1500字符 | 单条融资日报文档篇幅较短，该分段长度可保留完整的结构化字段与项目说明，避免拆分后割裂信息 |
| `增量更新触发周期` | 每日凌晨2点 | 融资日报数据在交易日收盘后更新，非交易时段同步可避免占用业务时段的服务器资源 |
| `多源合并去重开关` | 开启 | 不同平台转引同一份融资公告会产生重复条目，开启后可基于`披露日期`+`融资主体`字段自动去重 |
| `字段权重配置` | 对`披露日期`、`融资金额`、`融资轮次`设置1.5倍权重 | 这些是用户检索融资日报的核心筛选条件，提升权重可优先返回匹配度更高的结果 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：检索结果出现大量重复的同主体融资公告条目。原因：未开启`多源合并去重开关`，或未配置`披露日期`+`融资主体`作为去重唯一标识。
- 现象：检索返回结果条数远低于预期，且未命中核心结构化字段。原因：`相似度阈值`设置高于0.88，过滤了部分匹配度符合要求的结构化条目，或`召回条数`取值过小。
- 现象：增量更新任务返回`408 Request Timeout`错误。原因：将`增量更新触发周期`设置在交易日交易时段，当日融资数据量较大导致同步超时。

## 怎么确认配好了
- 上传1份测试用融资日报文档，查看解析后的字段列表，确认`融资金额`、`融资轮次`等核心字段被完整提取。
- 发起包含「2024年Q3半导体行业融资」的检索，核对返回结果的去重情况与核心字段匹配优先级。
- 查看增量更新任务的运行日志，确认当日同步任务成功完成，无超时或字段解析错误。
- 导出当前知识库的索引配置文件，核对`字段权重配置`与`多源合并去重开关`的设置与预期一致。
