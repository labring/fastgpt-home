# 教育服务融资日报的引用来源与溯源

## 这个品类的数据长什么样
教育服务融资日报的数据主要来自公开的教育机构融资公告、行业第三方投融资数据库、地方教育主管部门公示信息。更新节奏为每个工作日更新一次，覆盖前一日及近期披露的融资动态。单篇日报文档结构固定，包含融资主体全称、所属教育细分赛道、融资金额（单位为万元或亿元）、投资方名单、融资轮次、披露日期、原始发布链接等字段。每条数据对应唯一的公开披露来源，无内部未公开信息，且所有字段均来自原始披露内容，无二次加工。

## 这些特征在「引用来源与溯源」这一环带来什么约束
教育服务融资日报的数据特征会从三个维度约束溯源环节。首先，每条融资条目绑定唯一的公开原始链接，溯源时需直接指向该链接，不得仅引用第三方聚合平台的中转地址，确保信息来源可追溯至原始披露方。其次，数据按工作日每日更新，溯源环节需校验披露日期与日报发布日期的匹配关系，防止混入过期或非当日披露的融资信息。第三，融资金额包含万元、亿元两种单位，且所属赛道表述来自原始披露，溯源时需完整保留原始单位与赛道标签，不得擅自转换或修改，避免信息偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前10条` | 教育服务融资日报单篇文档条目数量有限，过多召回会增加上下文长度，过少则无法覆盖全部相关融资动态 |
| `相似度阈值` | `0.75–0.85` | 融资日报的核心关键词（如融资轮次、赛道名称）辨识度较高，阈值过低会引入无关行业资讯，过高则可能遗漏匹配条目 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 单篇融资日报通常包含数十条融资条目，文档解析耗时较长，默认超时设置无法覆盖完整解析流程 |
| `引用来源展示开关` | `开启` | 教育服务融资日报的溯源需求明确，需向使用者展示原始披露链接，确保信息可追溯 |
| `重排返回条数` | `前5条` | 重排环节用于进一步过滤低相关性结果，5条即可保留最核心的融资动态，兼顾信息密度与可读性 |
| `向量模型` | `按实测标定` | 不同向量模型对金融领域专业术语的编码效果存在差异，需根据实际召回准确率调整适配 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传或解析融资日报文档时出现报错`Cannot redefine property: toString`。原因：文档中存在与系统内置方法重名的自定义字段，导致属性重定义冲突。
- 现象：召回结果中未展示原始来源链接。原因：未开启`引用来源展示开关`配置，或知识库绑定的文件未保留原始发布链接的元数据。
- 现象：切换向量模型后，知识库召回结果未发生变化。原因：未对已上传的融资日报文档重新生成向量索引，仍使用旧模型的编码结果。

## 怎么确认配好了
- 上传一篇测试用的教育服务融资日报文档，查看解析后的字段是否完整保留了原始披露的融资金额单位、赛道标签与发布链接。
- 发起包含教育服务融资相关关键词的查询，查看召回结果的条数是否符合配置的`召回条数`取值。
- 点击召回结果的来源链接，确认跳转至原始公开披露页面，不跳转至第三方聚合平台。
- 切换向量模型后，重新生成文档索引并发起查询，对比两次召回结果的相关性差异，确认配置生效。
