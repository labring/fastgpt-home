# 教育服务融资日报的文档解析与分块

## 这个品类的数据长什么样
教育服务融资日报的数据来源涵盖公开投融资披露平台、教育赛道行业数据库、机构提交的融资备案文件。更新节奏为每日更新，覆盖当日发布的全量教育服务领域融资信息。文档格式包含PDF公告、Excel汇总表、结构化网页表格三类，核心字段包括融资方名称、所属教育赛道、融资金额、融资轮次、投资方名单、披露日期。融资金额单位以万元或亿元为主，融资轮次使用标准化创投术语，披露日期采用YYYY-MM-DD格式。

## 这些特征在「文档解析与分块」这一环带来什么约束
多格式的数据源要求解析环节需兼容PDF、Excel、网页三种格式，避免因格式适配问题丢失结构化数据。每日更新的时效性要求解析任务需在短时间内完成，避免延迟影响日报的同步更新。文档以结构化表格为核心载体，跨行跨列的合并单元格与固定字段顺序，要求分块环节需保留数据的行列关联关系，不能随意拆分单条融资项目的完整信息。字段的标准化属性要求分块时需按字段组聚合内容，避免将同一项目的不同字段分散至多个分块中。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_TABLE_MODE` | 智能表格解析+行列对齐 | 教育服务融资日报核心数据存储于结构化表格中，该模式可保留合并单元格与行列关联关系 |
| `MAX_SEGMENT_LENGTH` | 800–1000 字符 | 单条融资项目的完整信息约300–600字符，预留上下文关联空间避免拆分关键信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 60 秒 | 单份教育服务融资日报文件通常不超过5 MB，60秒可覆盖全量解析与分块流程 |
| `ENABLE_TABLE_CHUNK` | 开启 | 需将表格数据作为独立分块保留，避免纯文本分块破坏表格的结构化逻辑 |
| `RECALL_FIELD_PRIORITY` | 按「融资方名称>融资金额>融资轮次」排序 | 用户检索时优先关注核心融资信息，该配置可调整召回结果的展示顺序 |
| `UPLOAD_FILE_MAX_SIZE` | 10 MB | 单份教育服务融资日报的汇总文件最大不超过5 MB，10 MB可预留合理冗余空间 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：使用OCR解析教育服务融资日报的PDF版本时，出现中文乱码，部分机构名称、赛道名称显示为乱码字符。原因：未配置OCR识别的中文语言包，默认识别引擎仅支持英文文本，无法正确解析中文专有名词。
- 现象：导入Excel格式的融资日报后，知识库内预览的表格与原文件行列对应关系不符，部分跨行的融资项目信息被拆分。原因：未启用智能表格解析模式，默认的纯文本解析逻辑无法识别Excel中的合并单元格与行列关联关系。
- 现象：检索融资日报内容时，投资方名单这类辅助数据的召回优先级高于融资金额、融资轮次等核心信息。原因：未配置字段级召回优先级，系统默认按分块的文本顺序进行召回，未区分数据的重要性层级。

## 怎么确认配好了
- 上传单份教育服务融资日报的示例文件，查看解析后的文本预览，确认中文文本无乱码，表格结构与原文件一致。
- 触发分块操作后，查看分块列表，确认每个分块包含完整的单条融资项目信息，未出现将同一项目的不同字段拆分至不同分块的情况。
- 发起检索测试，输入目标赛道或轮次关键词，确认召回结果的排序符合预设的字段优先级规则。
- 查看解析任务的运行日志，确认任务未出现超时报错，解析耗时符合预期配置。
