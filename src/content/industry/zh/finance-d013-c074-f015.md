# 教育服务融资日报的部署与升级

## 这个品类的数据长什么样
教育服务融资日报的数据主要来自公开投融资披露平台、行业监管公示渠道及教育服务机构自主发布的融资公告。数据更新节奏为每日固定时段同步当日披露的融资信息，部分延迟披露的记录会在次日补更。单篇日报文档以结构化表格为主体，每条融资记录包含主体名称、融资轮次、融资金额、投资方名单、完成时间、核心业务赛道共6个核心字段，金额单位统一标注为人民币万元或亿元。

## 这些特征在「部署与升级」这一环带来什么约束
教育服务融资日报的多源数据来源要求部署时配置多源数据同步的并发上限，避免同时拉取导致接口限流。每日固定更新的节奏要求定时任务参数匹配行业披露时段，否则会出现数据滞后或重复拉取。结构化字段多且需统一格式，部署时需配置字段映射规则，适配不同来源的字段命名差异。升级过程中需保证历史融资数据的持久化加载，避免版本更新导致已存储的日报数据丢失。同时，批量融资记录的召回需调整上下文长度参数，避免超出模型处理上限。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `CRON_EXPRESSION` | `0 18 * * *` | 国内投融资披露通常在每日18:00后更新，定时任务在此时触发拉取可覆盖当日全部披露信息 |
| `MAX_SYNC_CONCURRENCY` | `3` | 多源拉取时避免超出公开平台的接口限流阈值，实测3个并发可平衡拉取效率与稳定性 |
| `maxContext` | `8000–12000 字符` | 单篇日报包含数十条融资记录，总字符量通常在该区间内，适配主流大模型上下文窗口 |
| `RECALL_TOP_N` | `前10条` | 教育服务融资日报的核心关注条目通常为头部融资事件，召回10条可覆盖主要分析需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 批量结构化文档解析需较长时间，避免因超时中断解析流程 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单篇月度汇总的教育服务融资日报文档通常不超过该大小，适配批量导入需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：升级至v4.9.0版本后，刷新对话页面时历史融资日报对话记录消失，仅显示新对话入口。原因：升级过程中未保留`chat_history_storage_path`配置项的原有路径，导致历史会话数据未被加载。
- 现象：批量导入月度融资日报文档时，解析后仅返回部分字段内容。原因：未配置`FIELD_MAPPING_RULES`参数，导致不同来源的字段命名差异未被统一映射。
- 现象：调用TTS接口生成融资日报播报内容时出现`400 Bad Request`错误。原因：未指定私有化TTS模型的`model_path`参数，或传入的文本长度超出模型支持上限。

## 怎么确认配好了
- 手动触发一次数据拉取任务，查看同步日志中是否显示所有配置的数据源均成功拉取，无接口限流报错。
- 导入单篇教育服务融资日报文档，检查解析后的字段是否与预设的映射规则完全匹配，无缺失或错乱。
- 发起一轮基于融资日报的对话，查看返回结果的召回条数符合`RECALL_TOP_N`的配置设定，上下文未出现截断。
- 升级版本前备份会话存储路径，升级完成后验证历史会话记录可正常加载，无丢失情况。
