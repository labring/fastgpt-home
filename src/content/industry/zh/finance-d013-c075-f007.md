# 整车融资日报的工作流编排

## 这个品类的数据长什么样
整车融资日报的数据来源于车企生产端的整车出库台账、经销商端的库存质押申请数据、合作金融机构的放款与回款流水。数据按自然日更新，每日凌晨完成前一日全量数据的汇总。文档以经销商为一级分组，每个分组下按车型VIN码排列条目，核心字段包含经销商编号、车型识别码、在库整车台数、单台质押融资金额、累计放款总额、放款日期、到期还款日，单位分别为台、元、元、日期、日期。

## 这些特征在「工作流编排」这一环带来什么约束
整车融资日报的数据跨车企、经销商、金融机构三个系统，要求工作流配置跨数据源并行拉取节点，避免串行拉取导致的执行超时。数据按自然日更新，工作流需设置每日凌晨的定时触发，且需预留缓冲窗口适配各系统的数据同步延迟。按经销商与VIN码的分组逻辑，要求工作流配置字段标准化映射节点，将不同系统的非标字段转换为统一格式。金额字段精度要求严格，需添加数值校验节点，拦截异常浮点值与负值。跨系统数据的一致性要求，需在工作流中添加数据对账环节，确保各系统的放款金额与库存数据匹配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发配置` | `每日 01:00-02:00 触发` | 避开各系统数据同步的峰值窗口，确保拉取到完整的前一日数据 |
| `多数据源并行拉取阈值` | `同时拉取3个数据源` | 适配整车融资日报跨三个系统的对接需求，避免并行数过高导致接口限流 |
| `字段映射规则` | `按「源字段→目标字段」的一对一映射，覆盖全部核心字段` | 确保不同系统的非标字段统一为融资日报的标准格式 |
| `数值校验节点配置` | `校验金额字段范围为0至100000000元` | 匹配单台整车质押融资的常规金额区间，拦截异常值 |
| `MCP工具调用配置` | `绑定工作流全局变量至工具入参` | 满足跨工具调用的身份验证需求，解决全局变量传递问题 |
| `工具自动选择触发条件` | `按数据异常率阈值触发` | 让模型自主判断是否调用异常排查工具，适配灵活的业务逻辑 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为工作流运行时MCP工具入参的token字段为空，报错提示「缺少身份验证参数」。原因是未将工作流全局变量正确绑定至MCP工具的入参配置项。
- 现象为工作流每次运行都强制调用工具，未根据数据情况自主选择。原因是未配置工具自动触发的条件阈值，仅设置了固定调用规则。
- 现象为钉钉webhook推送的日报格式混乱，字段错位。原因是未将标准化后的字段按预设模板映射至webhook的请求体，直接使用原始非标准化数据。

## 怎么确认配好了
- 查看工作流的定时触发日志，确认每日指定时段有触发记录，核对触发时间是否符合预设窗口。
- 手动触发一次工作流，查看各数据源的拉取结果，确认所有核心字段均被正确映射。
- 提交模拟异常数据，验证数值校验节点是否拦截异常值，MCP工具是否正确接收全局变量token。
- 查看钉钉webhook的推送记录，确认推送内容的字段格式与预设模板一致。
