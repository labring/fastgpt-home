# 文娱用品融资日报的多轮对话与提示词

## 这个品类的数据长什么样
文娱用品融资日报的数据来源包括公开股权融资披露平台、行业监测数据库及地方文创产业扶持公示信息。更新节奏为每日更新，覆盖当日披露的全品类文娱用品融资项目。单份日报文档以表格形式呈现，每条融资项目包含标的名称、所属细分品类（如潮玩、电竞外设、文创周边等）、融资金额、融资轮次、投资方、披露日期六个核心字段。融资金额单位为万元人民币，融资轮次字段采用通用创投术语表述，披露日期格式为YYYY-MM-DD。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
首先，数据来源分散导致不同渠道的字段格式存在细微差异，多轮对话需要预设统一的字段映射规则，避免模型混淆不同来源的项目信息。其次，每日更新的特性要求多轮对话支持增量数据查询，仅拉取指定日期范围内的融资项目，减少无效上下文占用。此外，文娱用品细分品类繁杂，提示词需要明确指定过滤条件，确保模型输出仅包含目标品类的融资信息。最后，字段包含金额与轮次等关键信息，多轮对话中需避免模型对单位或轮次定义产生误判，需在提示词中固定字段解释规则。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 文娱用品融资日报单条项目约200字符，多轮对话需保留最近30条历史上下文，该范围可覆盖完整对话逻辑 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `60 秒` | 单份日报文档通常不超过10MB，解析耗时不会超出该阈值，避免超时中断 |
| `RECALL_TOP_K` | `前 10 条` | 文娱融资日报的核心信息集中在最近10条披露项目，该取值可确保模型输出聚焦最新动态 |
| `PROMPT_TEMPLATE` | `固定前缀+按轮次/品类分类输出+用户追问补充过滤` | 适配文娱用品细分品类多、轮次信息关键的特征，明确模型输出格式 |
| `UPLOAD_FILE_MAX_SIZE` | `10 MB` | 匹配单份日报文档的常规大小，避免因文件过大导致上传失败 |
| `DIALOG_LOG_EXPORT_ENABLE` | `开启` | 支持导出完整对话记录，满足后续数据复盘与校验需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用对话日志导出接口返回空数据或404状态码。原因：未开启`DIALOG_LOG_EXPORT_ENABLE`配置项，且未配置对应的数据拉取权限角色。
- 现象：合并两个AI对话输出后出现内容混乱、字段重叠。原因：未在`PROMPT_TEMPLATE`中指定固定的输出分隔符，导致模型输出格式不统一。
- 现象：上传文娱产品相关图片后，模型无法完成解读。原因：未开启`IMAGE_PARSE_ENABLE`配置项，且未配置OCR解析的基础参数。

## 怎么确认配好了
- 发起一轮包含「潮玩融资」「Pre-A轮」关键词的对话，核对模型输出是否仅包含文娱用品品类的融资项目数据。
- 调用`GET /api/dialog/history`接口，核对返回的对话记录是否包含完整的用户与模型交互内容。
- 上传一张包含融资信息的文娱用品相关图片，核对模型是否能正确提取图片中的文本与关键数据。
- 修改`CUSTOM_ICON_URL`参数并上传对应图标文件，刷新对话窗口页面，核对图标是否更新为目标样式。
