# 旅游景区融资日报的工作流编排

## 这个品类的数据长什么样
旅游景区融资日报的数据来源于景区票务系统的当日营收台账、文旅部门的景区经营监管报表、合作银行的授信审批与到账记录三类渠道。数据更新节奏为每日一次，于次日凌晨生成前一日的汇总报表。文档结构以结构化表格为主，附带单条融资记录的备注字段。核心字段包含景区唯一标识、景区名称、当日关联融资申请额度、银行批复金额、到账日期、授信类型、票据编号，其中额度类字段单位为万元，日期字段采用YYYY-MM-DD格式。

## 这些特征在「工作流编排」这一环带来什么约束
多数据源的接入要求工作流配置跨系统的数据拉取与合并规则，需保证各渠道数据的唯一标识匹配。每日固定更新的特性要求工作流配置定时触发机制，避免手动执行的延迟风险。结构化字段的标准化要求需配置字段校验节点，过滤空值或格式异常的数据。不同渠道的字段命名差异，例如银行记录的“批复金额”与景区台账的“审批额度”需统一映射，增加了数据转换的配置复杂度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发频率` | `每日 02:00` | 融资日报汇总前一日数据，凌晨执行可完成当日数据的完整拉取与处理 |
| `多数据源映射规则` | `按景区ID字段关联` | 景区ID为各数据源的唯一标识，可确保不同渠道的数据准确合并 |
| `字段必填校验开关` | `开启` | 融资类核心字段为空会导致后续AI分析环节失效，校验可提前拦截异常数据 |
| `代码节点超时时间` | `300 秒` | 多数据源拉取与格式转换的常规耗时在200秒以内，预留合理缓冲时间 |
| `知识库召回相似度阈值` | `0.75` | 景区融资相关的政策、合作文档需达到该匹配度，才能为分析提供有效参考 |
| `AI上下文最大字符数` | `8000 字符` | 融资日报的结构化数据加关联文档的总长度适配该阈值，避免输入溢出 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 运行工作流时返回`chat:ai_input_is_e`错误码，原因：代码节点的执行结果未正确拼接至AI模型的输入参数中，导致输入格式不符合要求。
- 全局变量绑定的“选择知识库”选项无匹配的景区分类知识库，原因：未配置变量的动态赋值逻辑，未将景区ID与对应知识库的标签进行关联。
- 文本提取节点返回的融资额度字段为空，原因：未指定数据源的目标列名或未配置字段匹配的正则表达式，导致无法从多源数据中准确提取目标内容。

## 怎么确认配好了
- 查看定时触发任务的运行日志，确认各数据源的拉取结果与预期一致，核对核心字段的完整性。
- 手动触发一次工作流，检查代码节点的输出结果是否符合融资日报的字段要求，验证拼接后的AI输入格式正常。
- 检查全局变量的动态赋值配置，确认“选择知识库”的选项随景区分类自动匹配。
- 测试文本提取节点的输出，确认目标字段的提取结果无空值或异常格式。
