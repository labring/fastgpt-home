# 旅游景区融资日报的模型接入与配置

## 这个品类的数据长什么样
旅游景区融资日报的数据来源包含景区自身运营票务系统、属地文旅监管平台的统计报送、合作金融机构的融资业务台账三类。数据更新节奏为每日凌晨完成前一日全量数据的汇总与发布。文档格式多为结构化CSV或JSON，包含景区统一社会信用代码、景区名称、当日接待游客量、当日经营性收入、累计融资余额、当日新增融资申请额、已审批待放款金额、合作金融机构名单等字段，其中经营性收入与融资类字段的单位存在元与万元的差异。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散导致跨源字段命名与格式存在差异，需配置多源数据接入的校验与映射规则，避免字段冲突。每日更新的全量数据要求配置精准的定时同步周期，确保模型调用时获取最新数据集。多类字段与单位差异需配置单位转换规则，统一模型输入的格式标准。结构化的数据格式要求调整模型解析模式，适配结构化数据的提取与分析逻辑，避免非结构化解析导致的字段丢失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `PARSE_MODE` | `structured` | 适配旅游景区融资日报的结构化CSV/JSON数据格式，避免非结构化解析的字段丢失 |
| `SYNC_CRON_EXPRESSION` | `0 0 2 * * *` | 匹配每日凌晨2点更新前一日数据的节奏，确保模型调用时获取最新日报数据 |
| `FIELD_MAPPING_LIST` | `["景区名称":"name","当日营收":"revenue","当日融资申请额":"apply_amt"]` | 映射数据源字段与模型输入字段，解决多源数据字段命名差异问题 |
| `DATA_SOURCE_MAX_RETRY` | `3 次` | 应对合作金融机构接口不稳定的场景，减少单次调用失败导致的任务中断 |
| `MAX_CONTEXT_LENGTH` | `8000 字符` | 适配融资日报单份数据的字段总量，避免超出模型上下文窗口限制 |
| `UNIT_CONVERSION_RULE` | `{"revenue":"元→万元","apply_amt":"元→万元"}` | 统一不同数据源的单位格式，确保模型输入数据的单位一致性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用多模态模型解析景区实拍的门票、客流监控图片时返回`415 Unsupported Media Type`报错。原因：未配置`ALLOWED_MEDIA_TYPES`参数，未将景区常用的HEIC、WebP格式纳入允许范围。
- 现象：当主融资分析模型调用失败返回`500 Internal Server Error`时，工作流未自动切换至备用模型。原因：未在工作流中配置错误捕获分支，未启用模型降级触发逻辑。
- 现象：通过OneAPI转发的国产模型请求返回`invalid api key`错误。原因：未更新OneAPI的镜像版本，旧版本存在密钥校验逻辑缺陷，无法适配国产模型的密钥格式。

## 怎么确认配好了
- 执行一次手动同步任务，查看数据同步日志，确认所有配置的字段均成功映射并加载。
- 发起一次模型调用请求，检查返回结果中是否包含所有配置的目标字段，无缺失或格式错误。
- 模拟模型调用失败的场景，验证工作流是否自动触发备用模型或错误处理逻辑。
- 查看数据源接入的监控面板，确认每日定时同步任务按预设周期正常执行，无超时或中断记录。
