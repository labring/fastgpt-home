# 普钢融资日报的引用来源与溯源

## 这个品类的数据长什么样
普钢融资日报的数据主要来自国内大宗商品流通监测平台、钢铁行业协会的每日直报数据源，每日凌晨完成前一日全量数据更新。单份文档按统计日期、行政区域、普钢细分品类（如螺纹钢、热轧卷板）分层组织，包含`统计日期`、`区域名称`、`品类名称`、`融资库存总量`（单位：万吨）、`当日入库量`（单位：万吨）、`当日出库量`（单位：万吨）、`期末库存余量`（单位：万吨）、`融资企业备案数量`（单位：家）等结构化字段，无非结构化附加内容。

## 这些特征在「引用来源与溯源」这一环带来什么约束
普钢融资日报的每日全量更新、多维度分层的结构化特征，对引用溯源环节带来三点核心约束。第一，需绑定`统计日期`字段作为溯源锚点，避免跨周期数据混淆，确保召回的是对应日期的融资数据。第二，需同时匹配`区域名称`与`品类名称`作为精准过滤维度，防止同区域内不同普钢细分品类的数据交叉召回。第三，由于部分数据源存在字段别名差异，需配置字段别名映射规则，将`质押库存总量`、`仓单库存总量`等非标准名称统一映射为标准字段名，保证溯源时的字段一致性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | 前10条 | 普钢融资日报单日报文的有效字段组合不超过8组，召回10条可覆盖全区域全品类的必要数据，避免冗余召回 |
| `相似度阈值` | 0.75–0.85 | 普钢融资日报为结构化数据，需较高匹配精度，避免召回非目标日期、区域的无关数据 |
| `字段过滤规则` | 按`统计日期`、`区域名称`、`品类名称`配置精准匹配 | 这三个字段是普钢融资日报的核心分层维度，可快速缩小召回范围，提升溯源精准度 |
| `别名映射配置` | 将`质押库存总量`、`仓单库存总量`映射为标准字段`融资库存总量` | 部分数据源会使用上述别名指代普钢融资库存数据，统一映射可保证溯源时的字段一致性 |
| `数据更新校验开关` | 开启按统计日期校验更新状态 | 普钢融资日报为每日全量更新，需确保调用的是当日已完成更新的完整数据，避免调用未同步完成的临时数据 |
| `上下文召回范围` | 单文档内精准匹配 | 单份普钢融资日报文档为单日全量数据，无需跨文档召回，避免引入无关日期的数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：在知识库搜索节点配置过滤条件时，选择`变量引用`选项无可选字段，无法绑定`统计日期`等普钢融资日报的专属字段。原因：未先在工作流中配置变量输入节点，或未将普钢融资日报的结构化字段映射为工作流可识别的变量类型，导致系统无法加载对应可选值。
- 现象：召回的普钢数据包含非目标品类的内容，如同时出现螺纹钢与热轧卷板的融资库存数据。原因：未配置`品类名称`作为精准过滤规则，仅通过日期和区域过滤，导致同区域内不同普钢细分品类的数据被交叉召回。
- 现象：返回的溯源数据中`融资库存总量`字段为空，或显示为未定义。原因：未配置`别名映射配置`，未将数据源中使用的`质押库存总量`等别名统一映射为标准字段名，导致系统无法识别对应数据字段。

## 怎么确认配好了
- 手动触发绑定该配置的工作流，输入已知的`统计日期`、`区域名称`、`品类名称`变量，核对召回结果是否仅包含对应维度的普钢融资日报数据。
- 查看知识库的同步日志，确认普钢融资日报的数据源已完成每日自动同步，且字段别名映射规则未触发异常报错。
- 调用工作流的测试节点，检查返回的结构化数据中是否包含标准字段`融资库存总量`、`当日入库量`等，无缺失或未定义的字段。
- 调整配置项的取值，验证召回结果的数量与精准度是否符合业务需求。
