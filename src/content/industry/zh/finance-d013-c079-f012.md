# 普钢融资日报的模型接入与配置

## 这个品类的数据长什么样
普钢融资日报的数据来源于国内钢铁现货交易市场的每日成交台账、钢厂的票据融资报备系统及第三方大宗商品资讯平台。更新节奏为每个工作日收盘后同步生成当日数据。文档为结构化表格格式，包含日期、钢种类别、产地、融资额度、融资期限、年化融资成本、质押物规格、结算方式等字段。其中融资额度单位为万元，融资期限单位为天，质押物规格标注为直径、长度等物理参数。

## 这些特征在「模型接入与配置」这一环带来什么约束
每日更新的结构化数据要求模型接入时配置定时同步任务的触发频率为每个工作日一次，避免重复拉取或遗漏当日更新数据。普钢品类下细分钢种较多，需配置实体识别参数以精准匹配螺纹钢、圆钢等子类，防止跨品类数据混淆。结构化表格的多字段特性要求明确映射规则，区分数值型与文本型字段的解析逻辑，避免字段错位。数据单位统一为万元、天等，需指定数值字段的单位解析规则，确保后续RAG召回时的数值对比准确。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `syncSchedule` | 每个工作日 18:00 执行一次 | 匹配普钢融资日报T+1的更新节奏，避免重复同步或遗漏当日数据 |
| `fieldMappingRule` | 按「日期→date、融资额度→number(万元)、钢种→string」映射 | 适配普钢融资日报的结构化字段结构，防止字段解析错位 |
| `entityRecognitionThreshold` | 0.85 | 精准识别普钢细分钢种，避免与其他钢铁品类混淆 |
| `maxContextWindow` | 8000 字符 | 适配单份普钢融资日报的平均文档长度，确保完整解析单日报表内容 |
| `errorRetryCount` | 3 次 | 应对第三方资讯平台偶发的接口波动，保障数据拉取稳定性 |
| `jsonParseStrict` | 关闭 | 兼容部分非标准结构化导出的普钢融资日报文件，提升适配性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置代理模型时返回`404 body not found`错误。原因：未针对普钢融资日报的数据源单独配置代理路径，与通用模型的代理规则产生冲突。
- 现象：知识库搜索返回的内容无法识别为标准JSON格式。原因：使用`qwen-max`模型时，未关闭模型的结构化输出强制校验，导致返回格式不符合预设的解析规则。
- 现象：索引模型与文本模型混搭配置后，召回结果出现字段错位。原因：未为不同模型配置独立的字段映射规则，导致跨模型的字段解析逻辑不一致。

## 怎么确认配好了
- 查看同步任务的执行日志，确认触发频率与预设的同步计划一致，无异常中断记录。
- 导入单份普钢融资日报测试文件，检查字段解析结果与原始数据的字段对应关系正确。
- 触发实体识别测试，验证模型能够准确匹配普钢品类下的细分钢种名称。
- 调用知识库搜索接口，检查返回的结构化数据格式符合预设的解析规则。
