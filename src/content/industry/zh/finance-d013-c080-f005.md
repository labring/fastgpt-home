# 服装家纺融资日报的多轮对话与提示词

## 这个品类的数据长什么样
服装家纺融资日报的数据来源为国内纺织服饰行业协会公开披露的企业融资备案信息、地方金融监管部门公示的投融资动态，以及第三方征信机构整理的产业端融资台账。更新节奏为每个工作日更新，非工作日无新增数据。单条融资记录的文档结构包含企业全称、融资轮次、融资金额、投资方主体、融资公告日期、企业主营细分品类、关联供应链节点信息，其中融资金额固定以万元人民币为单位。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
工作日更新的节奏要求对话上下文自动过滤非工作日的过期融资记录，避免返回已过时的动态内容。细分品类字段的存在，要求提示词严格限定召回范围为服装家纺赛道的融资数据，防止混入其他纺织服饰子类的记录。融资金额附带固定单位的特性，要求提示词统一单位换算逻辑，避免出现单位混淆的输出。供应链节点字段的关联属性，要求多轮对话保留上下文历史，支持用户追问融资方的上下游关联动态。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 前 8–12 轮对话 | 服装家纺融资日报的交互多为短链路多轮，过长上下文会稀释精准召回的融资数据 |
| `similarityThreshold` | 0.75–0.85 | 服装家纺融资数据字段标准化程度较高，该区间可过滤无关行业融资记录同时保留细分品类精准数据 |
| `recallNum` | 前 6–10 条 | 单条服装家纺融资数据信息量适中，该取值可平衡信息密度与输出简洁度 |
| `rerankNum` | 前 4–6 条 | 优先筛选服装家纺赛道的融资记录，过滤非目标品类的干扰结果 |
| `knowledgeBaseFilter` | 仅匹配「服装家纺融资日报」标签的文档 | 确保对话结果仅关联当前细分品类的融资数据，避免混入其他行业信息 |
| `autoClearHistory` | 会话结束后 1 小时自动清空 | 避免过期对话上下文干扰当日融资数据的召回逻辑 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用知识库关联接口时返回404状态码，原因：未正确填写目标知识库的`knowledgeBaseId`参数，或未将该知识库添加至应用的权限白名单。
- 现象：对话返回的融资数据包含非服装家纺品类的记录，原因：未配置`knowledgeBaseFilter`为对应标签，导致召回了其他行业的融资文档。
- 现象：对话中融资金额出现单位混淆，例如同时出现万元与亿元表述，原因：未在提示词中明确统一单位的要求，或未在配置中添加字段格式校验规则。

## 怎么确认配好了
- 发起单轮对话，输入「查看今日服装家纺融资动态」，核对返回结果的所有记录均属于服装家纺品类。
- 发起两轮连续对话，例如先询问某家纺企业的融资情况，再追问该投资方的其他投资项目，核对对话上下文被正确保留且未混入过期数据。
- 调用关联知识库的API接口，传入`knowledgeBaseFilter`参数，核对返回结果仅包含目标品类的融资文档。
- 查看模型调用日志，确认返回的融资金额均统一使用预设单位，且上下文窗口未超出配置的`maxContext`轮数。
