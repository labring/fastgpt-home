# 服装家纺融资日报的工作流编排

## 这个品类的数据长什么样
服装家纺融资日报的数据主要来自国内纺织服饰行业供应链金融服务平台、商业银行对公信贷台账，以及服装家纺产业链上下游企业的日常回款报备数据。数据更新节奏为T+1，即当日融资数据于次日凌晨完成同步。文档结构为结构化JSON数组或CSV格式，单条数据包含`enterprise_name`、`credit_limit`、`daily_loan_amount`、`daily_repayment_amount`、`financing_channel`、`report_date`六个核心字段，其中金额类字段单位统一为万元，无额外单位后缀。

## 这些特征在「工作流编排」这一环带来什么约束
服装家纺融资日报的多源数据特征，要求工作流需支持混合数据源接入，需配置字段映射规则适配不同平台的字段名差异。T+1的更新节奏要求工作流触发时机固定为每日凌晨，避免获取未完成的当日数据。金额类字段的单位一致性要求工作流需增加数据校验环节，过滤非数值或异常的条目。批量数据的处理需求要求工作流需设置单次处理上限，避免单实例负载过高导致超时。同时，服装家纺行业的融资主体覆盖面料厂、代工厂、品牌商等多类角色，需配置分支节点按主体类型分类统计数据，适配不同角色的融资数据统计需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `trigger_mode` | 每日定时触发，时间设为02:00-03:00 | 匹配服装家纺融资日报T+1更新的节奏，确保获取完整的前一日融资数据 |
| `data_source_type` | 结构化数据库查询+API拉取混合模式 | 覆盖商业银行台账和供应链金融平台的多源数据，满足全量数据采集需求 |
| `field_mapping_rules` | 预设5组行业通用映射规则，支持自定义修改 | 适配不同数据源的字段名差异，减少手动调整的成本 |
| `batch_process_limit` | 单次处理不超过200条数据 | 避免单工作流实例负载过高，降低超时风险 |
| `timeout_threshold` | 600秒 | 适配多源数据拉取和批量校验的耗时需求，满足行业数据处理的平均时长 |
| `error_notify_webhook` | 绑定自定义机器人地址 | 及时接收工作流异常通知，便于快速排查问题 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 表单输入节点的默认值引用变量失败，现象为表单配置的默认值未加载对应企业ID变量，生成的日报缺失企业维度数据，原因是未开启「变量解析开关」，或变量作用域未覆盖表单节点。
- DB节点查询结果无法直接使用，现象为DB节点返回的原始SQL查询结果为未解析的JSON字符串，需额外编写代码完成结构化转换，原因是未开启「自动解析JSON结果」配置项。
- 高并发MCP调用返回空值，现象为1秒2-3次并发调用时，MCP节点返回`null`，查看日志发现返回状态码429，原因是未设置并发请求限流参数，触发第三方接口的限流阈值。

## 怎么确认配好了
- 手动触发一次测试工作流，查看节点运行日志，确认`daily_loan_amount`等核心字段已正确完成映射，无字段缺失或类型错误。
- 提交10条模拟测试数据，检查`batch_process_limit`配置是否生效，工作流无超时报错。
- 传入包含异常数值的测试数据，确认工作流触发错误通知并拦截异常数据。
- 查看工作流运行统计面板，确认每日定时触发的执行时间符合预设区间。
