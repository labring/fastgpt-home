# 水产养殖融资日报的部署与升级

## 这个品类的数据长什么样
水产养殖融资日报的数据来源为地方水产行业主管部门的每日融资报送台账、农业信贷担保机构的当日放款记录，更新节奏为每日凌晨更新前一日全量数据。单份文档为结构化表格格式，单条记录包含主体名称、统一社会信用代码、融资类型、申请金额、实际放款金额、放款日期、资金用途、审批机构、审批状态等字段，其中金额单位统一为万元，资金用途多包含苗种采购、塘口运维、设备更新等水产养殖专属表述，部分地区报送的文档列顺序存在差异。

## 这些特征在「部署与升级」这一环带来什么约束
数据来源分散且格式不统一，要求部署阶段配置多源数据适配规则，避免因列顺序差异导致解析失败；每日固定时段更新的节奏，要求定时同步任务的周期与更新节奏匹配，且升级时需保留任务执行节点，避免中断当日数据同步；字段包含统一社会信用代码、万元级金额等特定格式内容，要求部署时配置对应的数据校验规则，确保字段格式合规；资金用途为自由文本且包含行业专属术语，要求升级时可快速迭代自定义实体识别模型，适配不断新增的养殖场景表述；单日均条目数随养殖旺季波动，要求部署时配置动态调整的存储分片阈值，平衡查询效率与存储成本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 水产养殖融资日报单文件条目较多但单条解析耗时短，300秒可覆盖批量解析的超时需求 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单份水产养殖融资日报的汇总文件通常不超过200MB，预留合理缓冲空间 |
| `CRON_SYNC_SCHEDULE` | `0 1 2 * * *` | 匹配数据每日凌晨更新前一日数据的节奏，凌晨时段系统负载较低 |
| `RECALL_TOP_K` | `前 10 条` | 融资日报的核心业务信息集中在近期10条记录内，过多召回会增加冗余计算 |
| `VECTOR_STORE_SHARD_SIZE` | `10000 条/分片` | 适配单日均条目数的波动范围，平衡向量存储的查询效率与存储成本 |
| `PLUGIN_CHART_ENABLED` | `开启` | 满足生成融资趋势图表的业务需求，匹配场景核心功能 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：文件解析后核心字段为空，如融资主体名称、放款金额字段缺失。原因：未配置多源数据的列映射规则，不同地区报送的表格列顺序不一致，导致解析时字段匹配错误。
- 现象：基础图表插件输出为`none`，未生成预期图表URL。原因：未开启`PLUGIN_CHART_ENABLED`配置项，或传入的数据源字段未匹配插件要求的数值型字段，例如未正确关联放款金额字段。
- 现象：定时同步任务未执行，当日数据未完成更新。原因：`CRON_SYNC_SCHEDULE`配置的时间格式错误，或部署时未授予定时任务的系统执行权限，部分旧版本如4.8.22存在定时任务权限配置遗漏的问题。

## 怎么确认配好了
- 手动上传一份符合业务场景的测试水产养殖融资日报文件，核对解析后的字段是否完整匹配预设的映射规则。
- 触发一次定时同步任务，查看系统日志中是否无报错且测试数据已同步至向量存储。
- 调用基础图表插件，传入已验证的数据源参数，确认返回内容不为空且符合业务格式要求。
- 检查上传文件大小限制配置，上传超出对应阈值的测试文件，确认系统拦截逻辑生效。
