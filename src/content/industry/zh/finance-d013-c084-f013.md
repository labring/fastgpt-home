# 水处理融资日报的知识库检索与召回

## 这个品类的数据长什么样
数据来源主要为地方生态环境部门公示、国家级环保项目融资平台公开信息、政策性银行融资公告。更新节奏为每日更新，覆盖当日及近3个工作日的水处理相关融资动态。单条文档为结构化条目，包含项目名称、所属区域、融资主体、融资金额、融资方式、审批日期、资金投向（如污水管网改造、污泥处置设施升级）等字段。融资金额单位为万元或亿元，日期字段采用YYYY-MM-DD格式，部分条目附带项目批复文号。

## 这些特征在「知识库检索与召回」这一环带来什么约束
每日更新的数据源要求检索链路支持定时增量同步，避免数据滞后影响时效性。多结构化字段搭配混合单位（万元、亿元），需要在预处理阶段统一单位格式，或在检索匹配时关联字段单位进行校验。部分条目存在字段缺失（如未标注批复文号），召回环节需允许非必填字段匹配，避免遗漏有效结果。单条数据体量小但条目总量随每日更新逐步累积，需限制初始召回范围，避免无效结果过载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 单条水处理融资日报文档体量小，批量导入Excel时300秒足够完成解析，避免超时中断任务。 |
| `分段长度` | `800–1200 字符` | 单条结构化条目约200字符，该分段长度可合并3-5条连续条目，保留项目关联信息，避免拆分破坏融资项目的完整描述。 |
| `召回条数` | `前 8 条` | 融资日报检索多针对特定区域或当日项目，8条可覆盖多数场景的结果需求，避免过多冗余信息干扰大模型推理。 |
| `相似度阈值` | `0.72–0.85` | 融资相关信息表述差异较小，阈值过低会引入无关结果，过高则可能遗漏有效匹配项，需按实测标定调整。 |
| `增量同步间隔` | `每 24 小时` | 数据源为每日更新的融资日报，24小时同步可保证知识库数据与公开信息的时效性匹配。 |
| `MAX_CONTEXT` | `4000 字符` | 单批次召回的分段内容总和不宜超过上下文窗口限制，4000字符可容纳约15-20条融资项目信息，满足大模型推理需求。 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用知识库关联接口时返回`400 Bad Request`错误，原因是未正确配置知识库与对话链路的绑定参数，导致接口鉴权或权限校验失败。
- 现象为Excel导入的融资日报条目被合并为单个分段，原因是未设置`自定义分隔符`参数，或沿用了默认的换行符规则，未适配Excel单行为一条数据的格式要求。
- 现象为检索返回的融资项目与查询需求无关，原因是未针对水处理融资的结构化字段调整`相似度阈值`，或未开启字段级匹配配置，导致仅匹配关键词字面，未匹配业务含义。

## 怎么确认配好了
- 执行一次Excel文件导入测试，查看解析后的分段是否按单行为一条条目拆分，确认分段配置与分隔符设置生效。
- 发起一次检索测试，统计返回结果的条数，确认召回条数配置与实际返回结果一致。
- 对比检索结果与原始数据源，检查融资金额、区域等字段的匹配逻辑是否符合预期，确认相似度阈值的取值适配业务需求。
- 查看定时同步任务的运行日志，确认增量同步间隔配置下的任务每日正常执行，无超时或失败记录。
