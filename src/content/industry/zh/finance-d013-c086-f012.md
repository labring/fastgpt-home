# 汽车服务融资日报的模型接入与配置

## 这个品类的数据长什么样
汽车服务融资日报的数据来源于汽车经销商的融资申请台账、合作金融机构的车贷审批系统以及供应链金融平台的结算记录。数据更新节奏为每日凌晨同步前一日的全量业务数据，文档结构为标准化的二维表格，包含经销商ID、经销商名称、车型系列、融资申请笔数、单笔融资金额区间、实际到账金额、逾期笔数、还款日分布、合作金融机构数等字段，其中金额字段单位为人民币元，日期字段格式为YYYY-MM-DD，车型系列为枚举类型的固定名称。

## 这些特征在「模型接入与配置」这一环带来什么约束
每日更新的数据源要求配置定时触发的任务节点，避免手动同步导致的数据延迟；多字段类型混合的结构化数据，要求配置结构化数据解析规则，确保模型正确识别枚举字段、数值字段与日期字段的关联关系；金额字段跨度较大的特点，要求配置向量归一化参数，避免不同量级的数值对检索精度造成影响；单条数据包含的字段数量较多，要求配置合理的上下文截断参数，防止超出模型的token限制。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `embedding_normalization` | 开启 | 融资日报包含跨度较大的金额字段，开启后可统一向量数值范围，提升检索匹配精度，对应4.8.23版本新增的向量模型归一化配置能力 |
| `schedule_interval` | `86400 秒` | 融资日报为每日更新的业务数据，定时同步间隔匹配数据更新频率，确保模型使用最新的业务信息 |
| `tool_choice` | `auto` | 支持模型自主判断是否调用结构化数据解析工具，适配融资日报多字段关联的查询需求，解决模型无法自主调用工具的问题 |
| `max_token_per_chunk` | `1000-1200 字符` | 单条经销商数据包含多个字段，按此范围分块可保留核心业务信息，同时避免超出模型上下文限制 |
| `parse_structured_data` | 开启 | 融资日报为标准化二维表格，开启后可自动提取字段关联关系，提升模型对结构化数据的理解效率 |
| `image_analysis_enabled` | 关闭 | 融资日报为文本结构化数据，无需多模态视觉分析，避免触发不必要的图像下载与解析流程 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：模型流响应为空，界面提示「模型流响应为空，请检查模型流输出」。原因：未开启`embedding_normalization`，且金额字段数值跨度大导致向量生成异常，触发模型响应截断，对应4.9.2版本中部分模型接入失败的常见问题。
- 现象：多模态视觉模型调用接口报错，无法完成图片分析。原因：开启了`image_analysis_enabled`但未配置合法的图片下载白名单，或数据源中的图片链接无法被平台访问，与用户反馈的Qwen2.5-vl调用错误场景一致。
- 现象：工作流中模型未自主调用工具，仅直接返回文本结果。原因：将`tool_choice`配置为固定的工具名称，不使用`auto`，限制了模型根据查询需求自主选择工具的权限。

## 怎么确认配好了
- 手动触发一次数据同步任务，检查结构化数据解析后的字段映射是否与原始日报的字段名称、单位一致。
- 发起包含金额字段的查询，确认模型返回的结果中金额数值与原始数据匹配，单位未出现混淆。
- 查看工作流的定时任务日志，确认任务按设定间隔自动触发，无超时或失败记录。
- 测试包含多字段关联的查询需求，确认模型根据查询内容自主选择是否调用结构化数据解析工具。
