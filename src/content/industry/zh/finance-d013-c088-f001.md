# 油服工程融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
油服工程融资日报的数据来源为油服工程企业的公开融资披露公告、油气行业投融资数据库、区域能源监管部门公开信息，更新节奏为每日更新当日披露的融资事件。单条数据文档结构包含项目名称、油服服务类型、融资主体名称、融资金额、融资轮次、投资方主体、披露日期、项目所在油气区块等字段。融资金额以万元为单位，融资轮次包含天使轮、Pre-A轮、A轮等标准轮次类型，披露日期采用YYYY-MM-DD格式，油服服务类型涵盖钻井、测井、油气工程总包等细分品类。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
由于数据来源包含多类公开及监管信息，需对接多源API接口并配置对应鉴权权限；每日更新的节奏要求接口调度匹配每日拉取的频率，避免拉取延迟或重复；专属字段如油气区块、油服服务类型，要求接口支持按字段过滤与映射；融资金额存在不同计价单位，要求接口支持单位统一转换；单条数据包含多维度字段，要求接口分页参数适配合理的返回条目数，避免接口返回过载影响工作流处理。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `request_timeout` | `300 秒` | 油服工程融资日报数据包含多维度字段，接口响应时间不宜过短，避免中途中断拉取任务 |
| `api_auth_type` | `API_KEY 鉴权 | 多数油气行业数据源多为企业级接口，需配置鉴权信息保障访问权限 |
| `field_mapping` | `按油服工程融资日报字段映射` | 需将数据源字段与油服工程专属字段如油气区块、油服服务类型做对应，匹配数据字段 |
| `data_pagination` | `每页 20 条` | 单条数据条目适中，避免接口返回过载，适配工作流处理效率 |
| `duplicate_removal` | `按披露日期+融资主体` | 避免重复拉取同一主体同一日期的融资事件，保障数据唯一性 |
| `unit_conversion` | `统一转换为万元` | 统一融资金额的展示单位，适配统一数据标准 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用接口返回`400 Bad Request`，融资轮次字段格式错误，原因是未配置`field_mapping`时未将融资轮次的枚举值映射为油服工程融资场景的标准轮次。
- 现象：工作流调用接口时返回`401 Unauthorized`，原因是未正确配置`api_auth_type`为`API_KEY`且未填写正确的数据源密钥，无法访问目标接口。
- 现象：脚本运行后拉取的数据与当日披露的融资事件不符，原因是未设置`request_interval`为`86400 秒`，未匹配油服工程融资日报的每日更新节奏。

## 怎么确认配好了
- 向配置的`api_endpoint`发起测试请求，验证返回结果包含油气区块、油服服务类型等专属字段，确认字段映射正确。
- 查看接口返回的分页条目数，检查返回结果符合`data_pagination`的设置。
- 触发一次拉取任务，检查是否有重复的融资事件被过滤，确认`duplicate_removal`规则生效。
- 验证鉴权配置，确认接口返回`200 OK`，无鉴权相关报错。
