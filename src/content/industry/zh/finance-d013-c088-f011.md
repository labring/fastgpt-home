# 油服工程融资日报的文档解析与分块

## 这个品类的数据长什么样
油服工程融资日报的数据来源包括公开交易所披露的油服企业融资公告、行业资讯平台的每日融资汇总、油服主体自主发布的项目文件。更新节奏为每日更新，当日汇总前一自然日的全领域融资事件。文档格式以批量导出的PDF报表或结构化Excel表格为主，部分文件内嵌项目示意图、投资方logo。核心字段包含油服项目名称、融资金额、投资方主体、融资轮次、披露日期、服务细分品类（如钻井工程、油气勘探），金额单位多为万元或亿元，融资轮次使用行业通用表述。

## 这些特征在「文档解析与分块」这一环带来什么约束
每日更新的批量文件要求解析流程具备较高的批量处理效率，需避免单文件解析超时。文档格式多样且含图文混排内容，需同时兼容PDF与Excel格式，且需绑定内嵌图片与对应文本数据。字段包含细分服务品类，分块时需以单条融资事件为最小单元，避免跨事件的内容混淆。部分文件存在固定页眉页脚，需过滤非业务相关的标识内容，否则会导致分块结果冗余。此外，不同来源的文档可能存在字段顺序差异，需确保解析时的字段上下文关联准确。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 单份油服融资日报的批量汇总文件通常不超过50MB，该取值可覆盖绝大多数常规文件的上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300–600 秒` | 油服融资日报的单份文件多为10-50MB，该超时区间可覆盖完整的解析与分块流程 |
| `chunk_size` | `800–1200 字符` | 单条融资事件的核心信息约600-1000字符，该取值可预留上下文关联空间，避免内容截断 |
| `enable_image_parse` | `开启` | 油服融资日报常内嵌项目示意图、投资方logo，开启后可提取图文关联的分块内容 |
| `excel_parse_mode` | `按行绑定单元格内容` | Excel版融资日报的融资数据按行排列，该配置可确保每行数据与内嵌图片绑定，避免内容分离 |
| `exclude_header_footer` | `自动识别并排除` | 每日融资日报的页眉页脚包含固定平台标识、日期水印，该配置可过滤非业务相关内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：PDF格式的油服融资日报解析后，内嵌的项目示意图未被提取，仅返回纯文本内容。原因：未开启`enable_image_parse`配置，导致解析时忽略PDF中的图文混排内容。
- 现象：Excel格式的油服融资日报解析后，内嵌的项目示意图与对应行的融资数据分离。原因：未配置`excel_parse_mode`为按行绑定单元格内容，仅提取了单元格内的文本数据。
- 现象：批量上传多份油服融资日报时，部分任务超时并返回`504 Gateway Timeout`状态码。原因：`PARSE_FILE_TIMEOUT_SECONDS`配置值设置过低，未覆盖大尺寸汇总文件的完整解析流程。

## 怎么确认配好了
- 上传单份典型的油服融资日报PDF文件，查看解析结果中的图文关联情况，确认内嵌图片已与对应文本绑定。
- 上传Excel格式的油服融资日报，检查每一行的融资数据是否与内嵌的项目示意图或投资方logo对应。
- 批量上传3-5份不同格式的油服融资日报，查看解析任务的完成状态，确认无批量超时或文件过大报错。
- 提取部分分块内容，检查固定的页眉页脚标识是否未被纳入分块结果。
