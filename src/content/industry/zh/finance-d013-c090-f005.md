# 涂料油墨融资日报的多轮对话与提示词

## 这个品类的数据长什么样
涂料油墨融资日报的数据来源包括全国涂料工业信息中心公开备案信息、地方金融监管局企业融资公示、供应链金融服务平台交易台账。数据更新节奏为每日更新，前一自然日的融资动态在当日上午完成汇总发布。文档结构以结构化表格为主，附带单条大额融资公告附件，字段包含融资主体全称、融资发生日期、融资金额、融资类型、资金方名称、披露媒体来源、所属涂料油墨细分赛道，融资金额单位为万元人民币，部分批量汇总文档包含15000行以上的明细数据，单条大额公告文档可达10万中文字符。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
数据来源分散导致字段格式不统一，需要在多轮对话中先完成字段对齐，避免返回结果出现字段缺失或格式错误。批量明细数据与长文档的存在，要求多轮对话上下文需支持分段加载与逐步整合，防止上下文溢出导致响应失败。每日更新的动态属性，要求提示词中配置实时数据拉取触发条件，避免返回过时信息。融资金额的单位一致性校验需求，需要在提示词中加入单位转换规则，防止出现金额量级错误。长文档的解析耗时较长，需要在多轮对话中预留足够的等待时间，避免提前终止会话。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 适配10万中文字文档拆分后的单段长度，避免上下文溢出 |
| `UPLOAD_FILE_MAX_SIZE` | `1024 MB` | 容纳15000行明细excel与10万中文字的公告文档 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 为长文档解析与字段对齐预留足够时间 |
| `召回条数` | `前10条` | 匹配涂料油墨融资日报每日动态的常规数量，减少上下文占用 |
| `相似度阈值` | `0.75` | 区分同主体不同时间的融资记录，避免重复召回 |
| `maxTokens` | `4096` | 控制单轮对话的输出长度，避免超长响应超时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：前端调用`/api/v1/chat/completions`接口返回CORS跨域错误或`403 Forbidden`状态码，原因：未配置允许访问的域名白名单，或私有化部署的反向代理未放行对应接口路径。
- 现象：无法获取每次对话的token消耗明细，原因：未开启全局token统计配置，或绑定的模型与token计算模型不匹配。
- 现象：处理10万中文字的word文档或15000行excel数据时，多轮对话无响应，或完成知识库搜索后输出延迟较高，原因：未设置合适的`maxContext`与召回条数配置，导致上下文加载过多数据或解析超时。

## 怎么确认配好了
- 发起一次包含融资日报数据的多轮对话，检查返回结果的字段是否与数据源一致，根据不一致情况调整提示词的字段对齐规则。
- 上传15000行excel与10万中文字的word文档，确认解析完成时间在预设的超时阈值内，根据实际耗时调整对应配置项。
- 测试不同域名的前端调用接口，确认无跨域错误，根据实际访问来源更新域名白名单配置。
- 发起多次连续对话，检查token消耗统计是否正常生成，根据统计结果调整上下文与输出长度配置。
