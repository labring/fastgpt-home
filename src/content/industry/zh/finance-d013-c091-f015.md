# 消费建材融资日报的部署与升级

## 这个品类的数据长什么样
消费建材融资日报的数据来源为地方住建部门建材项目备案库、供应链金融机构放款台账、行业经销商融资报送数据。更新节奏为每日凌晨完成前一日全量数据同步。单条数据文档结构包含项目标识、建材细分品类、融资主体名称、融资金额、放款机构、放款日期、项目所在城市字段。融资金额单位为万元，日期字段采用ISO标准日期格式，项目标识为唯一编码字符串。

## 这些特征在「部署与升级」这一环带来什么约束
数据多源的特性要求部署阶段配置多数据源接入适配规则，避免因格式差异导致解析失败。每日更新的节奏要求升级阶段调整定时同步任务的触发周期，确保数据时效性。细分品类字段的存在要求配置分类召回规则，匹配不同建材子类的查询需求。融资金额以万元为单位的设定，要求在数值解析环节配置单位转换校验，防止出现金额偏差。唯一项目标识的存在要求开启知识库去重配置，避免重复数据占用存储空间。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `SYNC_CRON` | `0 1 * * *` | 匹配每日凌晨同步前一日数据的更新节奏，避免占用业务高峰时段资源 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 单份日报文档解析通常耗时不超过2分钟，多源批量上传需预留足够容错时间 |
| `分段长度` | `800–1200 字符` | 消费建材融资日报字段多且短，分段长度适配字段组合后的文本长度，避免语义割裂 |
| `相似度阈值` | `0.75–0.85` | 区分不同建材细分品类的融资记录，避免无关结果混入召回列表 |
| `召回条数` | `前 8 条` | 单份日报数据量适中，8条召回可覆盖完整的项目融资信息维度 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 适配批量导入的月度汇总报表大小，避免上传失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：对话时出现`Request Timeout`报错，状态码504。原因：未根据消费建材融资日报的解析需求调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时间过短导致解析未完成。
- 现象：召回结果中混入非消费建材品类的融资记录。原因：未设置`相似度阈值`或阈值设置过低，未过滤无关品类的匹配结果。
- 现象：定时同步任务未按时更新数据。原因：`SYNC_CRON`表达式配置错误，未匹配每日凌晨同步的更新节奏，或未验证时区设置与数据源更新时区一致。

## 怎么确认配好了
- 上传单份测试用消费建材融资日报文档，查看解析结果的字段完整性，确认所有预设字段均被正确提取。
- 发起包含消费建材细分品类的查询，核对召回结果的条数与`召回条数`的设置一致，调整阈值以匹配预期匹配精度。
- 手动触发一次定时同步任务，查看任务日志确认数据同步完成且无解析错误，验证`SYNC_CRON`的触发逻辑。
- 上传批量汇总报表，确认上传进度正常且未触发`UPLOAD_FILE_MAX_SIZE`限制，调整参数以适配批量导入需求。
