# 消费电子融资日报的部署与升级

## 这个品类的数据长什么样
消费电子融资日报的数据来自品牌方内部融资审批系统、经销商回款台账、第三方供应链金融服务商的交易接口。每日更新前一自然日的全量交易数据。单条记录包含消费电子品类名称、SKU编码、经销商主体、放款机构、放款金额、放款日期、还款周期、资金成本率。放款金额以人民币元为单位，还款周期以自然日为单位，资金成本率以小数形式标注。

## 这些特征在「部署与升级」这一环带来什么约束
多源数据对接要求部署阶段配置多接口适配逻辑，升级阶段需兼容新旧接口的字段差异。每日T+1的更新节奏要求定时任务的触发频率需匹配数据更新周期，避免数据滞后或重复拉取。包含SKU编码、放款金额等细分字段要求部署阶段配置针对性的数据校验规则，升级阶段需兼容新增品类字段的解析逻辑。跨主体的数据来源要求部署阶段配置权限隔离策略，升级阶段需更新权限映射规则以适配新的合作机构。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DATA_SYNC_CRON` | `0 1 * * *` | 消费电子融资日报为T+1更新，每天凌晨1点执行可完成前一日数据拉取与清洗，适配每日更新节奏 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 消费电子融资日报的批量导入文件包含多SKU明细，该取值可适配批量导入的文件体积需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 批量导入的融资日报文件包含大量品类明细数据，需预留足够时间完成字段解析与校验 |
| `PROXY_URL` | `http://your-proxy-domain:8080` | 对接第三方供应链金融服务商数据时，通过代理规避跨域或访问限制，适配aiproxy配置逻辑 |
| `LOCAL_MODEL_ENABLED` | `true` | 适配FastGPT 4.9.1及以上版本，消费电子融资日报的字段校验需本地语义匹配，无需依赖外部API |
| `VOLUME_MOUNT_PATH` | `/app/data/financing_daily` | 将导入的日报文件持久化存储，便于容器重启后仍可触发自动同步更新 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：访问绑定自定义域名的FastGPT实例时返回400 Bad Request状态码。原因：未正确配置`SERVER_DOMAIN`参数，未将自定义域名添加至允许访问列表。
- 现象：调用模型处理融资日报字段时返回“模型渠道未配置”报错。原因：未明确`PROXY_URL`的配置范围，误将aiproxy仅绑定至官方模型渠道，未适配消费电子融资日报所需的本地语义校验需求。
- 现象：Docker部署的FastGPT重启后，此前上传的融资日报文件无法触发自动同步。原因：未在docker-compose.yml中配置`VOLUME_MOUNT_PATH`指向持久化目录，导致上传文件随容器销毁丢失。

## 怎么确认配好了
- 手动触发一次数据同步任务，核对拉取的融资日报数据字段与预设的消费电子品类结构一致，确认字段匹配逻辑符合品类定义。
- 访问绑定的自定义域名，验证页面可正常加载且无接口报错，确认域名配置参数正确。
- 调用模型处理单条融资日报记录，验证可正常完成字段校验与语义匹配，确认本地模型或代理配置正确。
- 重启部署容器，检查持久化存储目录中的导入文件未丢失，确认卷挂载配置正确。
