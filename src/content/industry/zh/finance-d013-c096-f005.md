# 焦炭融资日报的多轮对话与提示词

## 这个品类的数据长什么样
焦炭融资日报的数据来源为国内大宗商品现货交易平台、期货交割库运营方发布的官方日报，以及合作金融机构的融资台账数据。更新节奏为每日凌晨更新前一日全量数据。文档以结构化表格为主，包含报告日期、品类标识、产地信息、出库结算价、港口仓储价、融资金额、融资周期、授信主体相关字段。单位方面，价格类字段单位为元/吨，融资金额单位为万元，融资周期单位为自然日。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
焦炭融资日报的每日全量更新特征，要求多轮对话中需限定召回数据的时间范围为最近24小时，避免跨日数据混淆。结构化的文档字段结构，要求提示词需明确指定提取出库结算价、港口仓储价等专属字段的格式，防止大模型混淆字段对应关系。多源数据来源的特征，需要在提示词中明确优先使用官方交割库与金融机构台账数据，避免非权威内容干扰。焦炭品类专属的产地、仓储相关字段，要求多轮对话中需保留上下文的品类标识，防止跨品类查询时出现字段错位。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | 前8条 | 焦炭融资日报的每日数据条目有限，过多召回会引入无关内容，过少则覆盖不足 |
| `相似度阈值` | 0.72–0.78 | 结构化文档的字段匹配度要求较高，该区间可过滤低相关性的非焦炭品类融资数据 |
| `maxContext` | 1200–1500 字符 | 焦炭融资日报的单份文档长度适中，该范围可保留足够上下文同时避免上下文溢出 |
| `分段长度` | 600 字符 | 结构化表格的字段组长度适配该分段，可保证字段关联不被拆分 |
| `重排返回条数` | 前4条 | 每日更新的有效数据条目较少，重排后保留核心条目即可满足多轮对话需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：多轮对话中触发知识库检索后返回空结果，但在知识库管理后台的测试检索功能中可正常匹配目标文档。原因：未配置合理的召回数据时间范围，当日焦炭融资日报全量数据更新后，向量库的索引刷新延迟导致部分条目未被及时召回。
- 现象：调用对话接口时返回404 Invalid URL (POST /api/chat/completions) 错误。原因：未正确配置对话接口的网关地址，或接口版本与当前部署的服务版本不匹配，导致请求路径无效。
- 现象：工作流执行至大模型处理环节后，AI已生成回复，但后续的结果流转步骤未执行，对话直接结束。原因：未在提示词中明确指定输出格式的闭合标记，导致大模型生成的内容超出工作流预设的解析边界，触发工作流异常终止。

## 怎么确认配好了
- 进入知识库管理后台的检索测试页面，输入焦炭融资日报相关的查询词，核对返回的文档数量与配置的相关参数是否一致。
- 调用对话接口并携带测试用的请求参数，检查返回的HTTP状态码是否符合预期，确认接口路径与版本配置正确。
- 触发完整工作流执行，观察日志中是否有符合提示词要求的输出格式，确认格式约束被正确执行。
- 模拟多轮对话，依次切换不同报告日期的焦炭融资日报查询，核对上下文保留的品类与日期信息是否正确。
