# 焦炭融资日报的模型接入与配置

## 这个品类的数据长什么样
焦炭融资日报数据主要来源于国内大宗商品现货交易平台、行业自律组织公开统计、港口仓储库存台账及期货交易所结算数据。数据更新节奏为每日固定时点更新前一交易日的全量信息。单份日报文档结构包含当日基准成交价、港口总库存、上下游企业开工率、融资融券余额、标准仓单数量等字段，其中价格单位为元/吨，库存与仓单单位为万吨，融资余额单位为万元。

## 这些特征在「模型接入与配置」这一环带来什么约束
每日固定时点更新的特性要求配置定时拉取任务的触发窗口与数据更新周期匹配，避免拉取到未完成更新的脏数据。多字段带明确单位的结构，要求配置字段校验规则，对价格、库存等字段的单位格式进行强制校验，防止模型输出错误单位的结果。多源数据来源的整合需求，要求配置多源数据的融合权重，优先采信期货交易所与行业协会的权威数据。融资相关字段与仓单数据的强关联特性，要求配置召回时的关联匹配规则，确保融资数据与对应仓单信息绑定，提升分析准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `REQUEST_TIMEOUT` | `300 秒` | 焦炭融资日报单份数据量有限，300秒可完成多源拉取与基础校验，避免超时中断任务 |
| `maxContext` | `8000–12000 字符` | 日报包含多字段关联分析，足够的上下文窗口可保留完整字段信息与历史关联数据 |
| `FIELD_VALIDATION` | `启用单位校验，匹配元/吨、万吨、万元格式` | 日报字段均有固定单位，强制校验可防止模型输出错误单位的分析结果 |
| `SOURCE_WEIGHT` | `期货交易所0.4、行业协会0.3、现货平台0.2、港口0.1` | 不同来源权威性存在差异，优先采信期货与行业协会的公开统计数据 |
| `ASSOCIATED_RECALL` | `绑定融资余额与标准仓单字段` | 焦炭融资日报中融资数据与仓单数量强相关，绑定后可提升关联分析的准确性 |
| `MODEL_INFERENCE_TIMEOUT` | `600 秒` | 多源数据融合后的模型推理需较长处理时间，避免因超时导致任务失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：模型调用返回`504 Gateway Timeout`错误，或任务状态显示为「超时失败」。原因：未配置合理的`REQUEST_TIMEOUT`与`MODEL_INFERENCE_TIMEOUT`参数，超时阈值设置过短，无法覆盖多源数据拉取与融合的耗时。
- 现象：工具调用时模型输出超出预设范围的推理结果，或无法限制模型仅使用指定数据源。原因：未配置`SOURCE_WEIGHT`与`ASSOCIATED_RECALL`参数，未绑定关联字段与设置数据源优先级，导致模型自主调用未授权的数据源。
- 现象：配置第三方数据源时提示拒绝访问，更换其他配置方式后无此问题。原因：未正确配置数据源的API密钥与访问白名单，或未在平台中添加对应数据源的授权IP段，导致接口调用被拦截。

## 怎么确认配好了
- 执行一次手动拉取任务，查看拉取到的字段是否包含所有预设的焦炭融资日报字段，检查单位格式是否符合要求。
- 查看数据源权重配置面板，确认各来源的权重分配与预设规则一致，无异常调整。
- 发起一次模型推理测试，查看输出结果是否绑定了融资余额与标准仓单字段，未出现无关数据源的信息。
- 查看任务日志，确认无超时报错与访问拒绝的提示，任务执行状态为成功。
