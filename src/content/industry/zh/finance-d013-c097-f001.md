# 焦煤融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
焦煤融资日报的数据来源为全国煤炭交易中心焦煤专区挂牌数据、沿海港口焦煤融资库存监测公开数据。更新节奏为每日02:00前完成当日全量数据汇总。文档结构为结构化JSON或表格格式，包含融资主体全称、焦煤品级（主焦煤、1/3焦煤等细分品类）、交割港口、融资额度（单位：万元）、融资期限（单位：自然日）、挂牌起始时间、剩余可融额度等核心字段，无冗余嵌套字段，所有核心字段均为必填项。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
焦煤融资日报的固定数据源与每日更新节奏，要求HTTP接口调度需设置每日一次的拉取周期，避免频繁请求触发数据源限流。核心字段的固定枚举与单位要求，要求接口返回的字段需严格匹配预设映射规则，否则下游系统无法识别有效数据。多来源的数据整合需求，要求HTTP接口需支持同时对接多个煤炭交易平台的端点，并统一返回格式。此外，焦煤品类的细分属性要求接口需支持按品级、交割地点进行过滤，减少冗余数据传输。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `timeout` | `30 秒` | 焦煤融资日报数据量较小，超时设置过长会占用调度资源，过短会导致未完成数据拉取 |
| `field_mapping` | `{"融资主体":"subject","焦煤品级":"grade","交割地点":"port","融资额度":"amount","融资期限":"term"}` | 匹配FastGPT知识库解析的标准字段名，避免下游调用时字段不匹配 |
| `schedule_interval` | `86400 秒` | 焦煤融资日报每日更新一次，重复拉取会触发数据源限流 |
| `auth_type` | `api_key` | 多数煤炭交易数据源使用API密钥鉴权，符合FastGPT的标准鉴权流程 |
| `response_format` | `json` | 焦煤融资日报的结构化数据更适合JSON格式解析，便于字段提取 |
| `filter_rules` | `{"grade": ["主焦煤", "1/3焦煤"]}` | 聚焦主流焦煤品类的融资数据，过滤非核心品类的冗余数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用外部接口时返回`Api response error`或界面提示“未授权访问”，原因是未正确配置鉴权参数，或未将应用API key与外部数据源绑定，导致FastGPT无法完成接口校验。
- 现象为返回`Model response empty`错误，原因是字段映射配置与接口返回的实际字段不匹配，无法提取到焦煤融资日报的核心业务字段。
- 现象为拉取的融资日报数据更新时间滞后超过预设周期，原因是定时拉取间隔配置错误，未设置为符合数据源更新节奏的调度周期，导致获取到过期数据。

## 怎么确认配好了
- 执行接口测试请求，对比返回的JSON字段与配置的`field_mapping`是否完全一致。
- 查看调度任务日志，确认拉取动作按预设时间触发，且无超时或报错记录。
- 核对拉取到的焦煤融资日报数据，确认包含配置的`filter_rules`中指定的核心品类。
- 使用无效鉴权参数发起请求，确认触发授权失败提示，验证鉴权逻辑正常生效。
