# 焦煤融资日报的工作流编排

## 这个品类的数据长什么样
焦煤融资日报的数据主要来源于国内主要煤炭交易平台、北方港口现货交易系统以及钢厂采购台账。数据更新节奏为每日凌晨完成前一交易日的全量数据更新，单份日报文档按产地分组，包含主焦煤、1/3焦煤等细分煤种规格的交易数据。核心字段包括交易日、产地名称、煤种规格、平仓价、车板价、单日成交量、港口库存量，价格单位为元/吨，成交量与库存量单位为万吨。

## 这些特征在「工作流编排」这一环带来什么约束
每日固定时间更新的特性要求工作流配置精准的定时触发节点，避开数据更新的峰值时段以保证数据完整性。按产地与煤种规格分组的文档结构，要求工作流中配置按指定字段做数据分组的处理节点，避免跨规格数据混淆。多字段且带固定单位的结构，要求在数据清洗环节配置单位校验规则，防止数值与单位不匹配的异常数据流入后续流程。细分煤种较多的特点，要求知识库检索环节需按煤种规格做精准过滤，防止无关品类数据混入检索结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发时间` | `每日02:00` | 焦煤融资日报通常在凌晨完成数据更新，提前2小时触发可确保获取最新完整数据集 |
| `知识库相似度阈值` | `0.75` | 焦煤细分规格较多，需过滤低匹配度的无关煤种数据，保证检索结果精准 |
| `上下文召回条数` | `前3条` | 焦煤融资日报的历史查询多聚焦单一日志的多规格对比，少量召回可避免结果冗余 |
| `全局变量初始化配置` | `固定绑定焦煤产地列表` | 工作流需按产地分组处理数据，预定义变量可减少重复查询开销 |
| `节点输出过滤规则` | `仅保留最终输出节点` | 中间AI对话节点的结果无需对外输出，可避免冗余信息混入最终报告 |
| `数据格式校验超时` | `600秒` | 单份焦煤融资日报数据量较大，需预留足够时间完成字段校验与单位转换 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：知识库检索结果混杂非焦煤品类数据，字段为空或单位错误。原因：未配置`知识库相似度阈值`或阈值设置过低，未开启数据字段单位校验规则。
- 现象：工作流运行时无法调用预定义的产地全局变量。原因：未在工作流初始化节点完成全局变量的绑定配置，或变量作用域设置为仅单次运行。
- 现象：中间AI对话节点的回复内容被包含在最终输出结果中。原因：未配置`节点输出过滤规则`，默认保留所有工作流节点的输出内容。

## 怎么确认配好了
- 手动触发工作流，查看定时触发节点的运行日志，确认触发时间与预设值一致。
- 运行知识库检索节点，对比检索结果与焦煤融资日报的字段结构，确认仅召回焦煤相关数据。
- 检查全局变量存储节点，确认预定义的焦煤产地列表已正确加载并可被后续节点调用。
- 运行完整工作流后，查看最终输出内容，确认仅包含预设的最终节点输出内容。
