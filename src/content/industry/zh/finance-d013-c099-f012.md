# 燃气融资日报的模型接入与配置

## 这个品类的数据长什么样
燃气融资日报的数据来源涵盖燃气经营企业的内部采购台账、下游用户收费结算系统、地方公用事业监管平台的供气备案数据。数据更新节奏为每日固定时段同步前一日的全量业务与财务数据。单份日报文档结构按日期、供气批次、采购量、采购单价、销售回款额、融资申请额度、偿债备用金余额等字段组织。其中采购量单位为万立方米，采购单价单位为元/立方米，融资金额单位为万元，回款周期单位为天，所有字段均需保持固定格式与单位匹配，避免出现跨字段单位混用的情况。

## 这些特征在「模型接入与配置」这一环带来什么约束
燃气融资日报的多源数据来源要求模型接入层支持多接口聚合拉取，避免单一数据源故障导致数据中断。每日固定更新的节奏要求配置项支持定时触发与增量拉取，防止重复拉取全量数据占用系统资源。字段的固定单位与结构要求模型调用的prompt需明确指定字段映射规则，避免解析时出现单位错误或字段缺失。同时，融资相关数据涉及财务敏感信息，配置环节需额外开启数据脱敏与权限校验规则，防止敏感数据泄露。此外，单份日报的字段数量较多，模型的上下文窗口需适配文档长度，避免出现内容截断导致的分析偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `MODEL_API_TIMEOUT` | `300 秒` | 燃气融资日报的数据来源包含内部财务与运营系统，接口响应存在一定延迟，300秒可覆盖多数正常请求时长 |
| `MAX_RETRY_TIMES` | `3 次` | 多源数据接入时可能出现单次接口请求失败，重试机制可提升数据拉取的稳定性 |
| `LOAD_BALANCE_STRATEGY` | `轮询模式` | 适配多模型节点部署场景，均衡分配请求压力，避免单个节点过载 |
| `DATA_PARSE_SCHEMA` | `按燃气融资日报标准字段映射` | 明确采购量、融资金额等带单位字段的映射规则，避免解析时出现格式错误 |
| `CONTEXT_WINDOW_SIZE` | `8000–12000 字符` | 单份燃气融资日报的文档长度通常在数千字符，适配多数通用大模型的上下文窗口要求 |
| `LOCAL_MODEL_ALLOWED` | `开启` | 支持本地部署的模型接入，适配轻量化部署需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：本地部署的ollama模型接入后测试显示失败，界面返回`500 Internal Server Error`。原因：未配置`MODEL_API_BASE_URL`为本地ollama的实际访问地址，且未开放本地网络权限允许跨域请求。
- 现象：多模型节点接入时出现请求集中在单个节点，导致接口超时。原因：未开启`LOAD_BALANCE_STRATEGY`的轮询配置，仅使用默认的单节点路由逻辑。
- 现象：模型返回的融资日报数据缺失“供气均价”字段。原因：未配置`DATA_PARSE_SCHEMA`的严格校验规则，导致未提前映射的字段被自动过滤或遗漏。

## 怎么确认配好了
- 调用系统内置的测试接口，查看返回的融资日报数据是否包含预设的全部字段，字段单位是否与数据源保持一致。
- 查看系统运行日志，确认多模型节点下的请求被均匀分配，无单个节点的请求量远超其他节点的情况。
- 模拟数据源接口断线，查看系统是否自动触发重试或切换备用节点，未出现长时间无响应的情况。
- 验证定时更新任务，确认每日固定时段自动拉取最新的燃气融资日报数据，无延迟或遗漏更新的情况。
