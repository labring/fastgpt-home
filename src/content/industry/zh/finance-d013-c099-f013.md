# 燃气融资日报的知识库检索与召回

## 这个品类的数据长什么样
燃气融资日报的数据来源于燃气企业内部融资台账、地方公用事业监管平台备案信息、供应链金融交易记录。数据更新节奏为每日更新前一日的全部融资交易记录。单条数据为结构化条目，包含交易标识、上游供气主体名称、下游用气主体名称、融资金额、融资期限、资金成本费率、交易日期、备案凭证编号等字段。融资金额单位为万元人民币，融资期限单位为自然日或自然月，资金成本费率以小数形式体现。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源数据的格式差异要求检索前完成字段标准化处理，避免因主体名称简写、金额单位不一致导致的匹配错误。每日增量更新的节奏要求配置精准的同步触发机制，避免全量重扫资源浪费。多字段的结构化属性要求检索支持多条件联合过滤，仅依赖单一关键词匹配无法精准命中目标融资记录。时效性强的特征要求召回时自动过滤过期数据，减少无效结果占用上下文资源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `RECALL_TOP_N` | 前10条 | 燃气融资日报单日均交易条目通常在10条以内，过多召回会增加上下文处理压力 |
| `SIMILARITY_THRESHOLD` | 0.75-0.85 | 结构化字段匹配需要较高相似度阈值，避免无关主体的融资记录被召回 |
| `PARSE_INCREMENTAL_SYNC_INTERVAL` | 86400 秒 | 数据每日更新一次，每日同步一次即可覆盖最新的融资日报数据 |
| `FIELD_MATCH_WEIGHT` | 交易主体:0.3,交易金额:0.2,交易期限:0.2,交易日期:0.3 | 融资日报检索中主体和日期是核心过滤条件，需赋予更高权重 |
| `DOCUMENT_EXPIRE_DAYS` | 30 天 | 融资日报数据仅需保留近30日的有效记录，过期数据自动过滤无需检索 |
| `PARSE_FILE_MAX_SIZE` | 100 MB | 单份燃气融资日报的结构化导入文件通常不超过该大小，避免导入超时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：执行知识库搜索测试时返回空结果或界面提示“未找到匹配内容”。原因：未针对燃气融资日报的结构化字段配置字段匹配权重，仅依赖全局关键词匹配，无法精准命中主体、金额等核心检索条件。
- 现象：启动知识库检索任务时返回报错`invalid configuration parameter name "hnsw.iter"`。原因：将索引引擎的内部调试参数错误填入FastGPT的全局配置表单，未使用平台提供的标准化参数配置项。
- 现象：非绑定企业账号可查看并检索本企业上传的燃气融资日报数据。原因：未开启企业级权限隔离配置，未将知识库与对应企业账号进行绑定映射。

## 怎么确认配好了
- 上传单份燃气融资日报的测试文件，执行检索测试，核对返回结果的字段是否与上传数据一致。
- 查看知识库配置页面的同步日志，确认增量同步任务按预设间隔自动执行。
- 验证权限隔离配置，使用非绑定企业账号尝试检索，确认无法访问对应知识库。
- 调整相似度阈值，观察检索结果的匹配精度变化，确认配置符合业务需求。
