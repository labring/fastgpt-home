# 玻璃融资日报的工具调用与插件

## 这个品类的数据长什么样
玻璃融资日报的数据来源于国内建筑材料仓单公共服务平台、各地建材行业协会的每日融资台账汇总。数据更新频率为每日固定更新一次，固定在每日8:00前完成前一交易日的全量数据同步，临时补更仅覆盖当日16:00前新增的小额质押记录。数据采用结构化表格格式存储，每行对应一笔玻璃仓单质押融资记录，包含登记机构编码、玻璃品类名称、公称厚度、仓单面积、质押物总张数、融资金额、仓单估值、融资方统一社会信用代码、登记日期等字段，其中面积单位为平方米，金额单位为万元，厚度单位为毫米。

## 这些特征在「工具调用与插件」这一环带来什么约束
固定每日更新的节奏要求工具调用需指定固定的拉取时间窗口，避免拉取未完成同步的不完整数据。多类带单位的数值字段要求插件配置统一的单位映射规则，将不同来源的厚度、面积、金额字段对齐为标准口径。临时补更机制要求插件支持增量拉取逻辑，通过登记日期字段筛选当日16:00后的新增记录，避免重复拉取存量数据。结构化的表格格式要求插件内置CSV解析适配器，同时需校验必填字段的完整性，防止因字段缺失导致的调用失败。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `fetch_timeout` | `600 秒` | 适配玻璃融资日报全量数据源的拉取时长，避免因数据量较大导致的调用中断 |
| `unit_conversion_rule` | `{"公称厚度":"毫米","仓单面积":"平方米","融资金额":"万元"}` | 统一各数据源的单位格式，确保字段解析后对齐标准口径 |
| `incremental_sync_enabled` | `true` | 启用增量拉取逻辑，仅同步当日16:00后新增的记录，减少重复数据处理 |
| `required_fields` | `["登记日期","玻璃品类名称","融资金额"]` | 配置必填校验字段，过滤缺失核心信息的无效融资记录 |
| `parse_mode` | `structured_csv` | 选择结构化CSV解析模式，适配数据源的标准输出格式，降低解析出错概率 |
| `retry_max_times` | `3` | 设置最大重试次数，应对临时的数据源接口波动，提升调用稳定性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用返回结果耗时过长或触发`ETIMEDOUT`错误码。原因：未针对玻璃融资日报的全量数据规模调整`fetch_timeout`配置，使用默认短超时设置，导致数据未拉取完成即中断。
- 现象：插件解析后的数据字段单位混乱，部分厚度数值与实际口径不符。原因：未配置`unit_conversion_rule`参数，未统一各数据源的单位格式，导致解析后的字段口径不一致。
- 现象：工具调用返回大量重复的存量融资记录。原因：未启用`incremental_sync_enabled`配置，未通过`登记日期`字段筛选当日新增记录，执行了全量重复拉取。

## 怎么确认配好了
- 执行单次全量拉取，检查返回的记录中是否包含当日最新的登记日期数据，核对单位是否统一为毫米、平方米、万元。
- 配置增量拉取任务，查看返回的记录是否仅包含当日16:00后新增的融资条目，无存量重复数据。
- 模拟接口临时波动场景，触发工具调用重试，确认系统会自动执行重试且次数符合预设配置。
- 提交包含缺失必填字段的测试数据，查看是否被过滤，仅保留包含完整核心信息的记录。
