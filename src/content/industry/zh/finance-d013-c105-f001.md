# 生物制品融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
数据来源涵盖专业医药投融资资讯平台、上市企业公开公告及行业监管披露渠道。更新节奏为每日更新前一自然日的全量新增及修正融资记录。单条数据包含融资主体名称、融资轮次、融资金额及币种、投资方名单、融资公告日期、核心产品管线、所属细分赛道等字段，其中核心产品管线字段包含适应症、研发阶段等详细信息。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
数据包含较长的核心产品管线文本内容，会增加单条接口返回的payload大小，因此接口调用的超时时间需要适配长文本传输。融资金额存在多币种标注，接口参数需要支持币种字段的识别与标准化。核心产品管线包含细分赛道信息，接口需要支持按赛道过滤的查询参数。数据每日更新，接口的增量拉取参数需要支持按日期范围筛选，避免获取全量数据导致的带宽占用。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `API_REQUEST_TIMEOUT` | `120 秒` | 单条数据包含长文本管线信息，常规超时时间不足以完成完整传输 |
| `RESPONSE_FIELD_FILTER` | `保留全部字段` | 生物制品融资数据的核心管线、赛道字段为业务必需，不可随意过滤 |
| `CURRENCY_STANDARDIZATION` | `自动转换为人民币元` | 多数国内业务场景使用人民币计价，可统一币种格式降低后续处理成本 |
| `DATE_RANGE_INCREMENT` | `每日凌晨2点拉取前一日数据` | 匹配数据每日更新前一日记录的节奏，避免重复或遗漏拉取 |
| `API_AUTH_TYPE` | `API_KEY 鉴权` | 融资数据属于行业敏感信息，需通过固定密钥校验调用合法性 |
| `PAYLOAD_MAX_SIZE` | `2048 KB` | 适配单条融资数据的长文本payload传输需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用接口时返回`Invalid URL, code: 500`，原因是未正确配置接口的基础地址参数，将本地测试地址直接用于生产环境调用。
- 触发`InternalError.Algo.InvalidParameter: Multimodal file size is`报错，原因是未设置`PAYLOAD_MAX_SIZE`参数，或取值小于单条融资数据的文本payload大小。
- 拉取到的融资数据缺少核心产品管线字段，原因是错误配置了`RESPONSE_FIELD_FILTER`参数，过滤了非预设的业务字段。

## 怎么确认配好了
- 发起单条数据查询请求，核对返回结果包含融资主体、核心产品管线等预设字段，字段格式与业务需求一致。
- 配置每日定时拉取任务，检查拉取周期与数据更新节奏匹配，无重复或遗漏的记录。
- 查看接口调用的响应日志，确认未出现超时或payload超限的报错。
- 测试包含多币种的融资数据请求，确认返回结果的币种格式已完成统一。
