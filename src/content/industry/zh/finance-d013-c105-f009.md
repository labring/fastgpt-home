# 生物制品融资日报的引用来源与溯源

## 这个品类的数据长什么样
生物制品融资日报的数据主要来自上市药企公告、一级市场融资数据库、医药行业协会披露信息，更新节奏为每日更新一次。单篇文档通常包含融资主体全称、融资轮次、融资金额（单位多为万元或亿元）、参与投资方名单、官方披露链接、发布日期等字段，部分文档会附带简短的融资用途说明，数据格式以结构化表格或带明确字段标注的文本块为主，核心信息集中在单页前半段。

## 这些特征在「引用来源与溯源」这一环带来什么约束
每日更新的节奏要求溯源环节配置增量拉取逻辑，避免重复引用历史数据，减少无效存储与检索开销。结构化的字段设计要求优先通过字段匹配定位来源内容，避免使用全文检索，确保引用的融资轮次、金额等核心信息准确对应。官方披露链接作为核心溯源依据，需优先绑定企业公告或行业协会发布的原始链接，不绑定第三方聚合页面，以保证信息权威性。部分文档附带的融资用途说明需单独标记来源，避免与核心融资信息混淆，防止引用内容出现错位。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | 前10条 | 生物制品融资日报单条核心信息集中，过多召回会引入无关内容，10条可覆盖当日全部有效融资事件 |
| `相似度阈值` | 0.75 | 结构化字段匹配度要求高，0.75可过滤低匹配度的第三方聚合内容，保留官方披露信息 |
| `增量同步间隔` | 86400 秒 | 对应每日更新的融资日报节奏，避免频繁拉取占用系统资源 |
| `引用来源绑定规则` | 优先匹配`官方披露链接`字段 | 生物制品融资信息的权威性依赖官方公告，需优先绑定该字段作为溯源依据 |
| `字段校验开关` | 开启 | 校验融资金额、融资轮次等必填字段的完整性，避免引用缺失关键信息的内容 |
| `上下文召回长度` | 800–1200 字符 | 单篇融资日报核心内容长度集中在该区间，可完整保留引用所需的关键信息 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 配置`召回条数`时尝试设置300左右的数值，却仅能选择100或900的固定档位。原因是未查看配置项的可选区间说明，直接使用了非预设档位的数值。
- 查看完整响应时出现引用内容缺失融资金额单位的情况。原因是未开启`字段校验开关`，未校验必填字段的完整性，导致引用了未补充单位的异常数据。
- 尝试引用HTTP返回的融资日报内容时提示格式错误。原因是未配置结构化字段映射规则，未将HTTP返回的原始字段与系统要求的`融资主体`、`融资金额`等字段绑定。

## 怎么确认配好了
- 执行一次手动同步，查看同步日志中是否仅显示当日更新的生物制品融资数据，确认增量同步配置生效。
- 随机抽取一条同步后的文档，查看引用溯源链接是否指向企业公告或行业协会官方页面，确认来源绑定规则生效。
- 触发一次问答请求，查看返回的引用内容是否包含完整的融资金额、单位及轮次信息，确认字段校验配置生效。
- 调整`相似度阈值`的测试值，查看低匹配度的第三方聚合内容是否被自动过滤，确认阈值配置生效。
