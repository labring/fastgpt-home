# 电力融资日报的多轮对话与提示词

## 这个品类的数据长什么样
电力融资日报的数据来源为地方能源监管部门公开披露文件、电力企业官方公告及行业融资备案平台。更新节奏为每日更新，当日披露的融资数据于次日10点前完成汇总。文档结构以结构化表格为主，包含融资主体全称、融资金额（万元）、融资用途、授信机构、发布日期5个核心字段，部分补充项包含项目类型（如风电、光伏）、融资期限（月）。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
电力融资日报的结构化字段特性要求多轮对话中需明确指定提取固定字段，避免模型生成未定义的额外内容。每日更新的节奏要求提示词中嵌入当日日期的校验提示，确保模型仅使用当日及前一日的汇总数据。特定的单位规则要求提示词中明确标注融资金额需以万元为单位，融资期限需以月为单位，防止单位混淆。结构化文档的固定字段顺序要求多轮对话中需按文档原有字段顺序整理输出结果，符合行业使用习惯。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 电力融资日报单份文档通常在2000-5000字符，多轮对话需保留3轮上下文，该区间可覆盖完整上下文需求 |
| `prompt_template` | `“请按以下字段顺序整理融资日报数据：融资主体全称、融资金额（万元）、融资用途、授信机构、发布日期、融资期限（月），仅使用文档内信息，不编造内容”` | 匹配电力融资日报的固定字段结构与行业使用习惯 |
| `VAR_API_PASS_THROUGH` | `开启` | 支持通过API传入自定义变量（如当日查询日期），解决变量传入不生效的问题 |
| `text_extract_threshold` | `0.75` | 电力融资日报的结构化字段辨识度较高，该阈值可过滤低匹配度的无关内容 |
| `response_language` | `按输入语言匹配` | 适配不同语言的提示词与知识库内容，避免强制输出单一语言 |
| `parse_file_timeout` | `600 秒` | 解析批量电力融资日报文档需较长时间，该时长可避免解析超时报错 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用API传入提示词变量后，返回结果未替换变量内容，与预设场景无关。原因：未开启`VAR_API_PASS_THROUGH`配置项，或变量格式不符合`{{变量名}}`的模板规范。
- 现象：上传电力融资日报文档后，文本提取未命中核心字段时，未触发预设的用户提示回复。原因：未配置`text_extract_fallback`触发条件，或未连接等待用户输入的流程节点。
- 现象：部署自定义模型后，解析上传的电力融资日报文件时报错。原因：未配置`parse_file_max_size`为适配文档大小的取值，或模型的文件解析插件未适配结构化表格文档。

## 怎么确认配好了
- 调用测试API传入自定义变量，检查返回结果是否正确替换变量内容。
- 上传一份不包含完整核心字段的电力融资日报文档，检查是否触发预设的文本提取失败提示。
- 输入英文提示词并上传英文知识库文档，检查模型输出语言与提示词语言一致。
- 上传单份电力融资日报文档，检查解析完成时间未超过预设的超时阈值。
