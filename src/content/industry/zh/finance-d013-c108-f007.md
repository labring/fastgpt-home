# 电商服务融资日报的工作流编排

## 这个品类的数据长什么样
电商服务融资日报的数据来源于电商平台开放的交易结算接口与商家端对账文件，每日凌晨固定时间生成前一自然日的完整报表。报表采用结构化表格格式，单份文件覆盖多家合作店铺，每行对应一家店铺的融资相关数据。字段包含店铺唯一标识、店铺经营类目、当日有效订单总额、当日可申请融资额度、累计已融余额、当日融资申请笔数、当日成功到账金额、当日手续费支出。金额类字段单位为元，笔数字段为整数，无额外聚合统计字段。

## 这些特征在「工作流编排」这一环带来什么约束
日报每日固定更新，工作流需匹配该节奏配置定时触发，无法依赖实时触发逻辑。单份文件包含多店铺数据，需按店铺唯一标识拆分处理，避免跨店铺数据混淆。字段包含动态变化的融资额度与手续费参数，需将这些字段绑定为工作流可调用的动态变量，无法使用硬编码参数。不同店铺对应独立的外部接口调用凭证，需为每家店铺单独配置调用参数，避免凭证混用。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `workflow_trigger_type` | `定时触发` | 电商服务融资日报每日固定时间生成，定时触发匹配数据更新节奏 |
| `PARSE_FILE_MAX_ROWS` | `5000 行` | 单份电商融资日报通常覆盖数千家店铺，该取值可覆盖多数场景且避免解析超时 |
| `variable_bind_mode` | `按行字段绑定` | 日报每行对应唯一店铺，需将每行的店铺ID、额度等字段绑定为工作流变量 |
| `external_api_timeout` | `30 秒` | 电商融资接口响应通常在合理区间内，该取值预留足够缓冲时间 |
| `workflow_retry_count` | `2 次` | 融资接口可能因网络波动出现临时失败，重试可降低任务失败率 |
| `global_variable_scope` | `按执行实例隔离` | 不同店铺的调用凭证、额度参数独立，隔离作用域可避免变量冲突 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：无法为不同店铺绑定独立的融资接口调用凭证。原因：在FASTGPT4.9.1版本中错误将凭证配置为全局静态变量，未按店铺ID动态绑定工作流变量。
- 现象：工作流解析上传的Excel文件后，无法提取指定字段的内容。原因：未配置`PARSE_FILE_FIELD_MAPPING`参数，未指定需要提取的店铺ID、融资额度等业务字段。
- 现象：工作流在平台内运行正常，部署到外部对话界面后无法处理后续请求。原因：未将工作流的输入参数配置为动态可替换，导致会话上下文无法更新店铺相关变量。

## 怎么确认配好了
- 上传一份模拟的电商融资日报文件，运行工作流，核对解析后的字段是否与原文件的业务字段一致。
- 查看工作流的执行日志，确认每个店铺的动态变量都被正确绑定，未出现变量为空的情况。
- 调用绑定的外部融资接口，核对返回结果是否与工作流中传入的店铺参数匹配。
- 配置定时触发任务，等待下一个日报生成周期，确认工作流自动执行且结果符合预期。
