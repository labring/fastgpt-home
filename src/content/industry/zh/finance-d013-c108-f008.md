# 电商服务融资日报的工具调用与插件

## 这个品类的数据长什么样
电商服务融资日报的数据来源于电商平台商家结算系统、供应链金融合作机构的接口，每日凌晨更新前一自然日的统计数据。单份文档按商家维度聚合，包含商家唯一标识、当日交易流水总额、融资申请提交笔数、审批通过额度、实际到账金额、待还款本金、当日融资费率等字段。金额字段单位为元，笔数字段单位为笔，日期字段采用YYYY-MM-DD格式，部分接口会返回分拆的子订单融资明细条目。

## 这些特征在「工具调用与插件」这一环带来什么约束
电商服务融资日报的数据每日更新的特征，要求工具调用触发周期固定为每日一次，避免高频调用触发接口限流。按商家聚合的文档结构，要求插件调用时必须传入商家唯一标识作为必选参数，否则无法返回对应商家的统计数据。分拆的子订单明细条目，要求插件支持分页参数传入，获取完整数据。金额字段的精度要求，要求工具调用时保留两位小数处理返回值，避免数据失真。不同合作机构的字段命名差异，要求插件配置支持自定义字段映射，适配多数据源的返回格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_call_cron` | `0 0 2 * * ?` | 匹配电商服务融资日报每日凌晨更新的节奏，确保调用时已有完整前一日数据 |
| `tool_required_params` | `["merchant_id", "stat_date"]` | 单份日报按日期和商家聚合，传入这两个参数可精准定位目标数据 |
| `tool_api_timeout` | `600 秒` | 批量获取子订单明细时接口响应可能较长，600秒可覆盖多数延迟场景 |
| `tool_field_mapping` | `{"trade_amount":"流水总额", "fin_rate":"当日费率"}` | 适配不同供应链金融机构的字段命名差异，统一内部调用的字段格式 |
| `tool_batch_limit` | `20 条/次` | 平衡接口负载与数据获取效率，避免单次请求数据量过大触发限流 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：界面中无法找到插件导入的入口，提示“路径不存在”。原因：未在FastGPT的插件管理页面选择对应工作空间，或上传的插件文件格式不符合要求。
- 现象：调用工具时传入的`q`参数未包含用户提问中的具体商家ID，导致返回数据为空。原因：未将用户提问中的商家标识提取为必选参数，未配置参数映射规则将用户输入映射到工具的`merchant_id`字段。
- 现象：工具调用返回状态码429，请求被限流。原因：未设置合理的调用频率，频繁触发接口限流，或未配置分页参数导致单次请求数据量过大。

## 怎么确认配好了
- 手动触发一次工具调用，检查返回的字段是否包含预设的映射字段，核对数据是否与目标数据源一致。
- 配置定时任务，查看任务日志中是否有成功的调用记录，确认触发周期符合预期。
- 传入错误的必选参数，检查工具是否返回参数缺失的报错提示，确认必选参数校验生效。
- 调整批量获取的参数，检查返回的数据条数是否符合配置的限制，确认分页逻辑生效。
