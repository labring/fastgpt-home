# 电网设备融资日报的工作流编排

## 这个品类的数据长什么样
电网设备融资日报的数据主要来自电网企业采购公示、设备厂商融资备案台账、地方金融监管部门的授信公开信息。更新节奏为每日更新，当日数据于次日12点前完成汇总。文档以结构化表格为核心，附带项目背景说明，包含设备型号（单位为台、套）、单台融资额度（单位为万元）、授信期限（单位为月）、中标日期、融资合作机构、项目所在电网区域等字段，部分条目会标注设备额定容量（单位为MVA）。

## 这些特征在「工作流编排」这一环带来什么约束
电网设备融资日报的多源数据特征，要求工作流配置多数据源聚合节点，适配不同数据源的格式差异。每日更新的节奏要求工作流设置定时触发规则，固定每日固定时段启动，同时配置延迟重试机制，应对部分数据源当日数据延迟的情况。字段包含多类单位的要求，需要配置单位校验节点，过滤不符合预设单位的条目，避免数据混入错误格式。结构化表格为主的文档结构，要求工作流优先配置结构化数据提取节点，提升提取准确率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发配置` | `每日 09:00 触发` | 匹配电网融资日报的行业常规早间报送节奏 |
| `多数据源聚合超时时间` | `120 秒` | 多源数据接口响应通常较快，超时设置避免整体工作流延迟 |
| `结构化数据字段映射规则` | `将“融资金额”“授信额度”统一映射为“单台融资额度”` | 不同数据源字段命名存在差异，统一字段名提升后续处理一致性 |
| `单位校验规则` | `仅保留“万元”“MVA”“月”三类单位` | 电网设备融资日报的标准单位范围固定，过滤非标准单位条目 |
| `必填字段校验规则` | `校验“设备型号”“融资额度”“中标日期”非空` | 缺失核心字段的条目无法形成有效日报内容 |
| `文档解析模式` | `结构化表格解析模式` | 日报文档以结构化表格为核心，专用解析模式提升提取准确率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流运行后提取的字段为空，原因：未配置结构化数据字段映射规则，不同数据源的字段名差异未被识别，导致提取内容无法正常匹配。
- 现象：工作流运行后无语音输出配置入口，原因：误将智能体的语音设置逻辑套用至工作流，工作流默认不集成语音输出配置项。
- 现象：工作流无法支持用户选择是否跳过知识库检索环节，原因：未在工作流入口配置用户变量选择节点，未开放对应选择权限，无法响应用户的自定义需求。

## 怎么确认配好了
- 手动触发一次工作流，核对提取的字段是否与数据源的原始字段一致，确认字段映射规则生效。
- 查看工作流运行日志，确认定时触发任务按预设时间启动，无超时报错记录。
- 上传一份包含非标准单位的测试数据，确认单位校验节点过滤了不符合要求的条目。
- 在工作流入口添加测试变量，确认用户可选择是否跳过知识库检索环节，配置项正常响应。
