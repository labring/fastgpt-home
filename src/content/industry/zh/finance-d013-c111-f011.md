# 畜禽养殖融资日报的文档解析与分块

## 这个品类的数据长什么样
畜禽养殖融资日报的数据主要来源于地方畜牧产业服务平台、金融机构涉农信贷台账、行业资讯平台的每日汇总。更新节奏为每日更新，部分区域为隔日汇总。文档以结构化表格为核心载体，附带少量文字说明融资背景，如补栏需求、扩栏计划等。核心字段包含融资主体名称、融资金额、融资期限、涉及畜禽品类、报送区域，单位分别为万元、天/月、头/羽、行政区域名称。

## 这些特征在「文档解析与分块」这一环带来什么约束
结构化表格为主的文档结构要求解析环节需精准识别单元格与字段的对应关系，避免拆分后丢失字段关联。每日更新的高频属性带来批量上传的需求，需确保解析任务可稳定处理单份或多份文档。核心字段与畜禽品类、融资主体强绑定的特征，要求分块时不能割裂同一主体的完整信息，否则会导致检索时上下文断裂。部分文档附带的非结构化补充说明，需与表格内容绑定解析，避免仅提取表格导致信息缺失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | `800–1200 字符` | 畜禽养殖融资日报的单条融资信息关联字段较多，该长度可完整包含单家主体的融资详情与关联养殖品类说明，避免拆分后上下文断裂 |
| `启用表格解析` | `开启` | 文档以结构化表格为核心载体，开启后可保留字段与单元格的对应关系，避免提取的信息零散 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 批量上传多份日报文件时，单文件解析耗时较长，该时长可覆盖常规100页以内的Excel/Word文档解析 |
| `自定义分段规则` | `按表格行组+文末说明分段` | 融资日报的核心信息按行分布，按行组分段可保留单主体的完整融资信息，避免跨表格行拆分 |
| `过滤重复表头` | `开启` | 多页日报文档常重复出现表头，开启后可减少冗余内容，避免分块时混入无效表头信息 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单份汇总类融资日报文件通常不超过此阈值，超出则需拆分上传 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传融资日报文档后，知识库搜索无结果，界面显示解析失败错误。原因：未开启`启用表格解析`配置，结构化表格内容未被正确提取，导致分块后无有效检索内容。
- 现象：自定义分段规则设置后，分块结果仍出现跨养殖主体的内容拼接。原因：未将`自定义分段规则`配置为按表格行组分段，默认按字符长度拆分导致同一分块包含多家主体的融资信息。
- 现象：上传Excel格式的融资日报后，部分工作表内容未被解析。原因：未开启`PARSE_EXCEL_SHEET_ALL`配置，仅默认解析第一个工作表，导致其他区域的融资数据丢失。

## 怎么确认配好了
- 上传单份测试用融资日报文档，查看解析后的分块预览，确认核心融资字段完整保留在同一分块内。
- 进入知识库搜索测试页面，输入测试关键词，确认可检索到对应分块内容。
- 批量上传3-5份同类型日报文档，查看解析任务的状态日志，确认无超时或解析失败报错。
- 调整`分段长度`参数后重新上传，对比分块结果，确认分块逻辑符合预设规则。
