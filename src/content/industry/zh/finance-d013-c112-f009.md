# 白色家电融资日报的引用来源与溯源

## 这个品类的数据长什么样
白色家电融资日报的数据来源为家电行业供应链金融披露平台、上市家电企业公告、区域产业金融服务平台。更新节奏为每日凌晨更新前一工作日的全量融资事件。文档结构为单条融资记录包含融资主体名称、融资金额、融资期限、资金方名称、公开披露日期、数据源标识字段。单位方面，融资金额以人民币万元为单位，融资期限以自然日或月为单位，披露日期采用YYYY-MM-DD格式。

## 这些特征在「引用来源与溯源」这一环带来什么约束
白色家电融资日报的多源分散特征，要求溯源环节需明确区分不同数据源的记录，避免跨品类或跨平台的融资事件混淆。每日更新的节奏要求溯源配置需支持按日期过滤，仅召回最近一个周期内的有效数据，防止引用过期或非当日的融资记录。字段中包含相似名称的融资主体（如不同区域的同类型家电供应商），要求溯源环节需设置合理的匹配阈值，过滤低匹配度的无关记录，确保引用的准确性。此外，带单位的金额字段需统一格式，避免引用时出现单位混乱的问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `reference_source_field` | `数据源标识` | 该字段存储每条融资记录的来源平台名称，用于在引用时明确标注数据源，匹配白色家电融资日报多源分散的特征 |
| `召回条数` | `前6–10条` | 白色家电融资日报单日报文量适中，限制该范围可避免输出冗余，同时覆盖主要融资事件 |
| `相似度阈值` | `0.72–0.88` | 白色家电融资主体名称存在相似性，该阈值可过滤低匹配度的无关记录，避免引用错误 |
| `日期过滤开关` | `开启` | 结合`披露日期`字段，限定召回最近1个自然日的数据，匹配日报的更新节奏，避免引用过期内容 |
| `引用展示模式` | `展示数据源+披露日期` | 白色家电融资信息需明确溯源，该配置可同时展示数据源和披露日期，满足合规性要求 |
| `字段映射规则` | `融资金额→金额（单位：万元）` | 统一字段显示格式，避免因原始数据单位不一致导致的引用混乱 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用后返回`quote type error`报错信息。原因：未正确配置`字段映射规则`，将原始数据中的数值型融资金额字段转换为可被解析的文本格式，导致变量类型不匹配。
- 现象：引用配置下拉菜单仅显示单个可选变量，无法添加多个数据源关联的引用条目。原因：未开启`多源引用绑定`配置项，或未将`reference_source_field`设置为支持多字段关联的模式。
- 现象：生成的回复中未展示知识库引用的披露地址。原因：未在`引用展示模式`中开启地址展示选项，或未在`字段映射规则`中绑定包含披露链接的字段。

## 怎么确认配好了
- 上传单条测试用白色家电融资日报数据，核对`字段映射规则`是否完成对应字段的格式转换。
- 发起针对性测试查询，确认返回结果中展示了配置的数据源标识和披露日期信息。
- 打开引用配置界面，确认下拉菜单可选择多个关联的数据源字段进行绑定。
- 查看系统日志，确认未触发`quote type error`类型的解析错误。
