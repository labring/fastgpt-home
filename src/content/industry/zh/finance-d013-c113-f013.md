# 白酒融资日报的知识库检索与召回

## 这个品类的数据长什么样
白酒融资日报的数据主要来自中国酒业协会发布的行业监测数据、上市酒企的临时公告、酒类流通平台的交易备案信息、地方金融监管局的融资备案公示。更新节奏为每日更新，单份日报文档包含当日全量白酒行业融资事件。文档结构以结构化表格为主，包含融资主体全称及简称、融资金额（单位为万元或亿元）、融资轮次、投资方名单、融资完成日期、产品品类、所属产区等字段，附带少量公告原文的文本备注。

## 这些特征在「知识库检索与召回」这一环带来什么约束
结构化表格占比高，要求检索系统支持精准字段匹配，避免全文检索导致的字段混淆。每日增量更新的特性，要求配置增量同步任务，避免全量解析重复消耗资源。字段包含明确的单位与细分品类标签，要求召回结果保留完整字段信息，避免单位歧义。融资主体存在简称与全称的差异，要求配置同义词匹配规则，提升召回精准度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_STRUCTURED_TABLE_ENABLE` | 开启 | 白酒融资日报以结构化表格为核心数据载体，开启后可保留字段结构与单位信息 |
| `UPLOAD_INCREMENTAL_ENABLE` | 开启 | 日报每日更新增量数据，增量解析可大幅降低单次处理耗时 |
| `RECALL_TOP_K` | 前10条 | 融资日报信息密度较高，过多召回会增加上下文冗余，影响最终回答效率 |
| `SIMILARITY_THRESHOLD` | 0.75-0.85 | 融资主体存在简称与全称的差异，较高阈值可避免无关主体的误召回 |
| `PARSE_CHUNK_SIZE` | 800-1200字符 | 拆分结构化表格时需保留完整字段组，该区间可平衡信息完整性与检索精度 |
| `RECALL_RERANK_TOP_N` | 前3条 | 优先返回最新完成的融资事件，重排后可提升结果的时效性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：检索耗时超过10秒，界面加载延迟明显。原因：未开启增量更新配置，每日全量解析全量日报数据，导致解析与检索压力过载。
- 现象：调用知识库问答时返回截断的报错信息，如`error: { 2024-12-`。原因：升级到4.8.12版本后未同步更新结构化解析插件的依赖包，导致表格解析失败后错误信息未完整抛出。
- 现象：召回结果中出现融资金额单位混淆，如同时展示“500万元”与“5亿元”的同主体融资信息。原因：未开启结构化字段匹配，仅依赖全文检索导致单位字段信息丢失。

## 怎么确认配好了
- 查看知识库的更新任务日志，确认每日仅触发增量解析任务，无全量解析的重复执行记录。
- 输入包含融资主体简称、轮次及单位的测试检索词，核对召回结果是否完整保留对应字段的全部信息。
- 查看系统监控面板的检索耗时指标，根据业务对时效性的要求调整相似度阈值与召回条数。
- 发起版本兼容测试，确认调用知识库问答时返回的错误信息完整，无截断情况。
