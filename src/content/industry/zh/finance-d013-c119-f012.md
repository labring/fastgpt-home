# 综合服务融资日报的模型接入与配置

## 这个品类的数据长什么样
综合服务融资日报的数据来源于交易所公开融资融券披露、官方金融统计平台及合规金融数据源，更新节奏为每日固定时段完成全量聚合。文档为结构化多表关联格式，包含当日及近段周期的融资相关指标，字段涵盖融资余额、融资买入额、融券余量、融券卖出量等，各字段均绑定明确的计量单位，无额外非结构化附加内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源聚合的多表关联结构要求接入环节需配置跨表关联规则，确保拉取的数据集完整。固定时段更新的节奏要求定时同步任务的触发时点与数据源更新流程匹配，防止拉取未完成的半更新数据。带明确计量单位的字段要求模型调用时需保留字段单位绑定关系，避免数值与单位错位。结构化格式要求优先使用结构化查询接口，以保证数据格式一致性，适配模型的结构化输入要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `sync_cron` | `0 5 * * *` | 匹配数据源每日固定时段的更新完成时点，避免拉取未就绪的半更新数据 |
| `multi_table_join_config` | 按日期字段关联融资余额表、融资买入表、融券余量表 | 综合服务融资日报的多源数据表通过日期字段实现唯一关联，保证数据集完整性 |
| `field_unit_preserve` | 开启 | 数据字段均绑定明确计量单位，保留单位可避免模型推理时的数值与单位错位问题 |
| `data_query_mode` | 结构化SQL查询 | 数据源为结构化多表格式，结构化查询可保证数据格式一致性，适配模型的结构化输入要求 |
| `sync_timeout` | `600 秒` | 多表关联查询需聚合多源数据，预留充足的拉取与处理时间 |
| `max_return_rows` | `前 30 行` | 综合服务融资日报的单日报文档包含近30日滚动数据，匹配常规分析与推理的样本需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用数据接口时返回字段不存在或表结构不匹配错误。未提前确认综合服务融资日报对应的多表结构，直接使用通用表名发起查询。
- 本地部署推理节点后，调用时报错`model_not_found`。启动推理节点时使用的`--model-uid`参数与平台配置的模型标识不一致，未匹配适配的模型标识。
- 在部分浏览器中调用问答接口时返回`403 Forbidden`状态码。未配置浏览器兼容的跨域请求头，部分版本浏览器的安全策略拦截了非合规的跨域请求。

## 怎么确认配好了
- 执行一次手动同步任务，查看同步日志，确认无表关联失败、字段缺失或超时报错。
- 发起一次模型调用请求，检查返回结果中是否保留了所有配置的字段及对应计量单位，无数值与单位错位情况。
- 打开浏览器控制台，发起接口调用请求，确认无跨域相关报错。
- 验证定时同步任务的触发，确认任务在预设时点自动执行，日志显示同步完成。
