# 耐火材料融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
耐火材料融资日报的数据来源于国内耐火材料行业协会的公开融资备案、企业披露的定向增发与供应链融资公告，以及第三方大宗商品融资监测平台的交易记录。数据更新节奏为每个工作日18点前完成前一日数据的汇总发布，文档采用结构化JSON格式，单条记录包含企业统一社会信用代码、耐火材料主营品类、融资额度（单位万元）、融资期限（单位月）、融资渠道类型、公告发布日期、所属省份等字段，批量接口返回包含多条记录的数组。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
由于数据包含企业统一社会信用代码等敏感信息，接口需配置专属鉴权参数，避免未授权访问；因采用T+1的工作日更新节奏，外部系统的定时拉取任务需匹配工作日触发时机，避免拉取未完成更新的数据集；因字段包含细分的耐火材料主营品类，接口需支持按品类关键词过滤，减少外部系统的二次清洗开销；因融资额度默认单位为万元，接口返回的数值需保留统一单位，避免与其他品类的融资数据产生解析冲突；因批量返回数组结构，接口需支持分页参数，适配不同外部系统的拉取容量需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `API_KEY` | `与数据提供方约定的专属密钥` | 用于接口鉴权，保护耐火材料融资日报的敏感企业与融资数据 |
| `CRON_EXPRESSION` | `0 19 * * 1-5` | 匹配工作日19点的更新节奏，拉取前一日的完整融资日报数据 |
| `BATCH_SIZE` | `150 条/请求` | 适配批量接口的返回容量，平衡拉取效率与请求稳定性 |
| `REQUEST_TIMEOUT` | `30 秒` | 覆盖正常接口响应时长，避免因数据量波动触发超时错误 |
| `FILTER_RULE` | `主营品类包含耐火材料关键词` | 过滤非耐火类融资记录，减少外部系统的二次清洗开销 |
| `DATA_UNIT_POLICY` | `保留原始万元单位` | 匹配融资日报的额度字段默认单位，统一外部系统的解析逻辑 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用接口返回413 Request Entity Too Large状态码。原因：未配置合理的`BATCH_SIZE`参数，单次拉取的融资日报数据量超过接口允许的最大请求体限制。
- 触发URIError: URI malformed报错。原因：未对融资日报中含特殊字符的企业名称、主营品类字段进行URL编码，导致接口请求的URI参数格式错误。
- 本地部署时无法正常调用外部接口，提示鉴权失败。原因：未正确配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`参数，未匹配数据提供方的接口地址与密钥。

## 怎么确认配好了
- 发起单次接口请求，核对返回字段的单位与主营品类是否符合耐火材料融资日报的特征，调整对应配置项直至匹配。
- 查看定时拉取任务的执行日志，确认在工作日指定时间触发拉取，调整`CRON_EXPRESSION`直至匹配更新节奏。
- 构造含特殊字符的测试请求，验证接口请求无格式错误，调整URL编码逻辑或鉴权参数直至正常响应。
- 调整单次拉取的数量阈值，验证接口返回状态码无异常，调整`BATCH_SIZE`直至符合接口限制。
