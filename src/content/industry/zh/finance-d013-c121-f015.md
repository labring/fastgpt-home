# 耐火材料融资日报的部署与升级

## 这个品类的数据长什么样
耐火材料融资日报的数据主要来自行业协会公开统计、大宗商品交易平台的实时报价、钢厂及耐火材料厂商的采购融资备案信息。数据更新节奏为每日一次，当日生成前一日的完整日报。单份日报文档包含当日日期、耐火材料细分品种（如镁碳砖、高铝砖、浇注料等）、产地、出厂含税单价、环比变化幅度、对应融资产品的年化成本、企业授信额度等字段。单价单位为元/吨，融资成本单位为年化百分比，授信额度单位为万元。文档多为结构化表格形式，附带少量行业短评或相关图片。

## 这些特征在「部署与升级」这一环带来什么约束
耐火材料融资日报的多品种结构化特征，要求部署时需配置精准的字段解析规则，避免不同品类的字段混淆。每日固定更新的节奏，需要设置稳定的定时拉取与同步任务，升级过程中需保障任务不中断，避免日报数据缺失。多来源的数据可能存在格式差异，部署阶段需配置统一的格式校验规则。若需解析日报附带的行业图片，本地接入多模态模型时需适配模型的本地部署端口与网段。升级新版本后，需验证原有第三方服务的配置兼容性，避免功能失效。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 耐火材料融资日报包含多品类的结构化表格，解析过程耗时较长，需预留足够的解析时间 |
| `SCHEDULE_PULL_INTERVAL` | 86400 秒 | 日报每日更新一次，匹配固定的拉取节奏 |
| `UPLOAD_FILE_MAX_SIZE` | 50 MB | 单份日报文档体积较小，批量导入时限制单文件上限避免资源浪费 |
| `SIMILARITY_THRESHOLD` | 0.72 | 过滤低相关性的历史日报数据，保障针对耐火材料品种的检索结果精准度 |
| `LOCAL_VLM_ENDPOINT` | http://127.0.0.1:8000 | 适配本地部署的cogvlm模型端口，用于解析日报附带的行业图片 |
| `WHISPER_API_URL` | http://localhost:8001/v1 | 适配升级后的whisper服务地址，保障语音转写功能正常运行 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：iframe嵌入内网映射的外网地址后页面空白，直接访问外网地址正常。原因：未将iframe嵌入的域名添加至FastGPT的跨域白名单，或免登录窗口的授权域名未配置正确。
- 现象：升级至4.8.17版本后，whisper语音转写功能失效，控制台提示POST /v1/audio/transcriptions 404错误。原因：新版本中whisper的默认API路径发生变更，未同步更新`WHISPER_API_URL`的配置值。
- 现象：本地部署的cogvlm模型可直接调用返回正确结果，但通过FastGPT调用时返回空结果。原因：FastGPT配置的`LOCAL_VLM_ENDPOINT`未指向模型实际监听的端口，或未开放对应端口的内网访问权限。

## 怎么确认配好了
- 手动触发一次定时拉取任务，检查知识库中是否生成当日的耐火材料融资日报文档，且字段完整。
- 调用向量检索接口，输入指定的耐火材料品种关键词，验证返回结果的字段与预设的日报字段匹配。
- 访问配置的外网地址，通过iframe嵌入至测试页面，确认页面加载无空白或报错。
- 测试whisper转写与cogvlm图片识别功能，确认调用后返回正常结果。
