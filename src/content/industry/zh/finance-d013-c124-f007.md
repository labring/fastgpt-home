# 自动化设备融资日报的工作流编排

## 这个品类的数据长什么样
自动化设备融资日报的数据来源于企业内部设备管理系统、采购台账系统及融资业务办理系统。数据更新节奏为每日T+1同步前一工作日的业务记录。文档为结构化表格格式，包含设备编号、设备型号、采购合同号、融资金额、放款日期、还款期数、剩余还款额、经办机构等字段。金额字段单位为元，日期字段格式为YYYY-MM-DD，还款期数字段单位为期。

## 这些特征在「工作流编排」这一环带来什么约束
自动化设备融资日报的数据结构化程度高且字段关联紧密，工作流编排需内置字段校验规则，校验融资金额、剩余还款额等数值字段的合法性，避免空值或异常数值进入后续环节。数据每日T+1更新的节奏，要求工作流配置定时触发节点，固定在每日凌晨拉取前一日的业务记录，防止重复拉取或遗漏数据。设备编号作为唯一标识，工作流需添加按设备编号去重的节点，避免同一设备重复计入统计。金额字段单位固定为元，工作流需统一转换非标准单位的输入数据，确保统计口径一致。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发配置` | 每日 00:30 触发，拉取前一日 00:00-23:59 的数据 | 匹配融资日报数据T+1更新的节奏，避免跨日数据混淆 |
| `字段校验规则` | 校验融资金额>0、放款日期格式为YYYY-MM-DD，过滤空值记录 | 确保进入流程的数据合法，避免后续计算或统计出现异常 |
| `设备编号去重配置` | 按设备编号字段去重，保留最新一条记录 | 设备编号为唯一业务标识，防止同一设备重复计入日报统计 |
| `金额格式转换` | 将所有金额字段统一转换为元单位 | 融资日报金额字段固定单位为元，统一统计口径避免偏差 |
| `工作流超时阈值` | 600 秒 | 单批次设备数据量较大时，预留足够的拉取和处理时间，按实测标定 |
| `知识库插件开关` | 关闭 | 融资日报为结构化数据处理场景，无需调用知识库补充信息，避免无关内容干扰 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流调试面板不显示`代码运行`节点步骤，无法查看中间执行日志。原因：未开启工作流的调试日志开关，或节点配置未正确绑定输入输出参数。
- 现象：导入外部工作流配置后，第二个工作流输出符合预期，但中间结果字段为空或数值异常。原因：导入的配置未同步关联数据源的字段映射规则，导致字段匹配错位。
- 现象：在4.8.22版本中，开启知识库插件的问题优化后，即使关闭最终AI回答插件的知识库开关，仍会调用知识库内容。原因：版本存在插件开关联动逻辑bug，需升级至对应修复版本。

## 怎么确认配好了
- 手动触发工作流一次，核对拉取的数据范围是否为前一工作日的记录，确认定时触发的时间配置正确。
- 导入一条测试用的异常数据，确认工作流会过滤该条记录，校验规则生效。
- 查看工作流的执行日志，确认设备编号去重节点已正确执行，无重复记录被统计。
- 检查工作流的权限配置，确认对应聊天角色可调用该工作流，触发执行无权限报错。
