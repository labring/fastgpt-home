# 自动化设备融资日报的工具调用与插件

## 这个品类的数据长什么样
自动化设备融资日报的数据主要来源于行业协会设备采购备案数据库、银行对公信贷放款系统、融资租赁公司交易台账三类渠道。数据更新节奏为每日更新，当日交易数据于次日凌晨完成汇总同步。单份日报文档按设备大类分组，包含设备唯一编号、采购方主体名称、融资金额（单位：万元）、融资期限（单位：月）、放款日期、设备型号、制造商全称等固定字段，部分补充条目包含担保方信息与还款计划摘要。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于数据来源涉及三类不同系统，工具调用需支持多源接口对接与数据聚合，需配置跨源认证与格式转换规则。每日更新的属性要求工具调用的定时任务需匹配日更节奏，同时需配置增量同步逻辑避免重复拉取历史数据。字段附带特定单位的特性，要求工具调用过程中需加入单位校验环节，防止非标准数值流入后续处理流程。设备唯一编号作为核心标识，需在工具调用时作为去重与关联查询的关键参数，否则会导致数据混乱。此外，融资类数据的敏感性要求工具调用时需配置权限校验，限制未授权的接口访问。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `tool_request_timeout` | `300 秒` | 自动化设备融资日报单批次数据量较大，接口响应时间通常较长，该取值可覆盖多数正常请求周期 |
| `tool_batch_size` | `50 条/次` | 单日报文条目较多，该批量取值可平衡接口负载与处理效率 |
| `field_unit_check_enabled` | `开启` | 需校验融资金额单位为万元、融资期限单位为月，避免脏数据进入系统 |
| `incremental_sync_interval` | `每日 0 点` | 匹配融资日报的日更更新节奏，确保当日数据按时完成同步 |
| `mcp_server_connection_timeout` | `60 秒` | 对接外部行业协会或银行接口时，该取值可保障稳定的连接建立时长 |
| `max_tool_call_retry` | `3 次` | 应对临时接口波动，避免单次请求失败导致整体任务中断 |
| `mcp_protocol` | `SSE` | 适配4.8及以上版本的MCP工具调用标准 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用工具时返回413 Request Entity Too Large错误，原因是未配置`UPLOAD_FILE_MAX_SIZE`或取值过小，导致批量拉取的融资日报数据超过接口允许的请求体大小。
- 使用大模型调用工具时，无法限制模型仅触发插件调用，原因是未开启`tool_call_only`配置项，或模型参数未正确设置为强制工具调用模式。
- 配置MCP工具时无法建立SSE连接，原因是未正确设置`mcp_server_url`与`mcp_auth_token`，或SSE连接的超时参数配置过短，导致连接提前中断。

## 怎么确认配好了
- 手动触发一次工具调用，检查返回的融资日报数据是否包含设备编号、融资金额等必填字段，且单位符合预设要求。
- 查看工具调用日志，确认请求未触发413错误，重试次数未超过配置的`max_tool_call_retry`值。
- 验证MCP服务连接状态，确认SSE连接无超时报错，且能正常拉取到最新的设备融资数据。
- 检查定时任务执行记录，确认每日同步任务正常触发，无重复或遗漏的数据条目。
