# 自动化设备融资日报的模型接入与配置

## 这个品类的数据长什么样
自动化设备融资日报的数据主要来自设备厂商销售回款台账、融资租赁机构放款系统、公共招投标平台中标公示。数据更新节奏为每日T+1更新前一自然日的交易记录。文档以结构化表格为核心载体，包含设备型号、采购主体、融资金额、放款日期、租赁期限、还款期数、设备序列号等字段。其中融资金额单位为人民币元，放款日期采用YYYY-MM-DD格式，还款期数为正整数，设备序列号为字母与数字组合的唯一标识。

## 这些特征在「模型接入与配置」这一环带来什么约束
自动化设备融资日报的多源分散数据特征，要求配置多数据源适配参数，确保不同系统的结构化数据可统一解析。每日T+1的更新节奏，要求配置定时同步任务的`schedule_cron`参数，匹配行业通用的凌晨数据更新窗口。固定字段格式与唯一标识的要求，要求`field_mapping`需严格匹配预设字段名，`date_format`需指定为YYYY-MM-DD格式，同时需开启`enable_duplicate_removal`以过滤重复的设备交易记录。货币字段的单位约束，要求配置`currency_unit`参数为人民币元，避免模型处理时出现单位混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `schedule_cron` | `0 2 * * *` | 适配多数数据源的T+1数据更新窗口，避免数据未就绪就触发同步 |
| `field_mapping` | 按数据源字段名严格映射，例如`设备型号`→`device_model`、`融资金额`→`loan_amount` | 匹配结构化数据的字段唯一性要求，避免映射错误导致模型计算偏差 |
| `date_format` | `YYYY-MM-DD` | 符合融资日报中放款日期的标准格式，确保模型可正确识别时间字段 |
| `enable_duplicate_removal` | `开启` | 设备序列号为唯一标识，可过滤重复的交易记录，提升数据准确性 |
| `currency_unit` | `人民币元` | 融资日报的金额字段默认以人民币计价，避免模型输出单位错误 |
| `data_parse_timeout` | `600 秒` | 多源数据同步时可能存在多接口调用延迟，预留足够的处理时间 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：模型对融资金额的合计结果出现偏差，或输出的金额单位混杂。原因：未正确配置`currency_unit`参数，或`field_mapping`时将非金额字段纳入合计计算。
- 现象：模型返回的融资日报时间与实际数据时间不符，滞后或超前。原因：未设置`date_format`参数，或定时任务`schedule_cron`未匹配T+1更新窗口，导致模型使用旧数据或未同步最新数据。
- 现象：自定义API接入后无法正常调用融资数据源，或返回报错状态码。原因：未正确配置`api_auth_type`参数，或未将数据源接口的请求头、密钥填入对应配置项。

## 怎么确认配好了
- 查看数据同步日志，确认所有配置的数据源均成功拉取当日数据，无报错状态码。
- 手动抽取一条结构化数据，验证模型映射的字段与原始数据完全一致，无字段错位。
- 触发一次定时同步任务，检查生成的融资日报中金额合计结果与原始数据的汇总值匹配。
- 核对模型输出的时间字段与原始数据的放款日期一致，符合T+1的更新节奏。
