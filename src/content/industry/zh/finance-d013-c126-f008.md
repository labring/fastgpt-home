# 航空机场融资日报的工具调用与插件

## 这个品类的数据长什么样
航空机场融资日报的数据来源包括民用航空监管机构的公开公告、机场运营主体的官方披露、第三方航空金融数据平台的每日更新。数据更新节奏为每日T+1发布，覆盖前一日的机场相关融资动态。文档结构包含结构化表格与非结构化公告摘要两部分，核心字段包括IATA三字机场代码、融资主体全称、融资金额（单位：万元人民币）、融资方式、融资用途、发布日期与数据来源，其中日期采用YYYY-MM-DD格式，机场代码为3位大写英文字母。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源公开数据源的格式差异要求工具调用支持混合解析逻辑，需同时处理结构化表格与非结构化PDF公告。每日更新的节奏要求插件配置定时触发周期与数据更新频率匹配，避免重复拉取或延迟更新。字段中融资金额的单位存在公告内的不一致性，需插件内置单位转换逻辑统一为万元。机场代码的标准化要求工具调用需支持按三字码过滤数据，缩小查询范围。结构化与非结构化混合的文档结构，要求插件同时支持字段提取与关键词抓取能力。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 适配航空机场融资公告PDF的常见文件大小，避免上传失败 |
| `data_source_whitelist` | `["caac.gov.cn", "airport-group.com.cn", "sec.gov.cn"]` | 限定合法公开数据源，过滤无效或非法内容 |
| `update_interval` | `86400 秒` | 匹配融资日报的每日更新节奏，避免频繁请求触发限流 |
| `file_parse_timeout` | `300 秒` | 预留充足时间解析PDF格式的公告文档，避免解析超时 |
| `stream_response` | `true` 或 `false` | 根据下游接收端的处理能力选择，实时展示用`true`，批量处理用`false` |
| `amount_unit_convert` | `true` | 统一融资金额单位为万元，适配下游分析的统一格式要求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用API时返回`413 Request Entity Too Large`错误，原因是未正确配置`UPLOAD_FILE_MAX_SIZE`参数，超过平台允许的文件上传上限。
- 插件调用时文件参数传递失败，返回`invalid file parameter`错误，原因是未按照插件要求的格式传递文件URL或base64编码内容，未绑定正确的文件变量名。
- 使用`v4.12.3`版本调用工具时频繁出现`tool_call_failed`报错，原因是该版本的工具调用逻辑未兼容多源公告格式，无法正确处理非结构化内容的解析。
- 开启`stream_response: true`后无法获取完整结果，原因是未正确拼接流式返回的所有分段数据，仅读取了部分内容。

## 怎么确认配好了
- 发起一次测试调用，传入指定的机场代码参数，检查返回结果中是否仅包含对应机场的融资日报数据。
- 上传一份标准的航空机场融资公告PDF，检查插件是否能正确提取出融资金额、融资方式等核心字段，无明显缺失或错误。
- 开启`stream_response`参数，调用接口后逐段接收返回内容，确认所有分段拼接后得到完整的日报数据。
- 查看插件运行日志，确认数据源白名单内的链接均能正常抓取，无超时或访问被拒绝的记录。
