# 航空装备融资日报的工具调用与插件

## 这个品类的数据长什么样
航空装备融资日报的数据来源为沪深北交易所公开融资公告、军工行业信息聚合平台，更新节奏为每个交易日收盘后更新当日披露的航空装备领域融资事件。文档采用单条结构化事件条目格式，包含字段：融资方名称、航空装备产品线范围、融资金额（单位：万元人民币）、融资轮次、投资方机构清单、披露日期，其中披露日期采用YYYY-MM-DD标准格式，投资方机构清单为数组类型的文本集合。

## 这些特征在「工具调用与插件」这一环带来什么约束
航空装备融资日报的交易日更新节奏，要求工具调用的定时触发规则需绑定交易日日历，避免非交易日执行拉取任务产生空数据。结构化字段中包含航空装备产品线范围，需在工具调用时添加品类过滤参数，仅拉取对应机型、整机制造相关的融资事件，防止混入民用消费或其他军工细分领域的融资数据。融资金额固定以万元人民币为单位，插件解析时需预设单位校验逻辑，避免与其他品类融资日报的亿元单位产生混淆。投资方清单为数组格式，工具调用后的结果处理环节需适配数组类型字段的遍历与提取，无法直接按单字符串字段进行拼接。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `tool_call_cron` | `0 18 * * 1-5` | 匹配交易日收盘后的定时拉取时机，适配航空装备融资日报的披露节奏 |
| `tool_filter_schema` | `{"target_industry": "航空装备", "amount_unit": "万元人民币"}` | 过滤非目标品类与单位的融资数据，仅保留航空装备领域的结构化条目 |
| `max_context_tokens` | `8000-16000` | 容纳多轮工具调用的参数与结果，适配航空装备融资日报较多的结构化字段 |
| `array_field_parse_mode` | `full_extract` | 完整提取投资方清单的所有机构名称，适配数组类型的字段格式 |
| `tool_call_timeout` | `600 秒` | 为批量拉取与解析预留足够处理时间，避免中途超时中断任务 |
| `api_request_retry_times` | `2-3` | 抵消金融数据接口的临时波动，降低工具调用的失败概率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用MySQL工具插件时返回`400 status code (no body)`，原因是未正确配置数据库连接的超时参数，导致连接建立后未及时发送请求引发连接断开，返回空响应体。
- 调用工作流API时未获取到预期的上下文内容，原因是未在API请求的`chat_history`字段中传入历史对话数据，尽管工作流内部开启了上下文开关，但API调用未携带必要的上下文参数。
- 工具调用结果与预设的问题分类逻辑不匹配，原因是在API请求的`model`字段中指定了仅支持基础问答的模型，未使用适配工具调用的模型版本，无法正确解析工具调用指令。

## 怎么确认配好了
- 手动触发一次工具调用任务，检查返回结果的行业与单位字段，确认仅包含航空装备领域且单位为万元人民币的融资数据。
- 查看工作流的上下文日志，确认多轮工具调用的参数与历史结果被正确存储，验证上下文窗口配置符合业务需求。
- 测试解析投资方清单字段，确认所有机构名称均被完整提取，验证数组解析模式的配置生效。
- 模拟非交易日触发定时任务，检查任务调度日志，确认未执行拉取操作，验证定时触发规则与交易日日历的绑定配置正确。
