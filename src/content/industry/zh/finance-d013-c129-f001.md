# 融资租赁融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
融资租赁融资日报的数据来源为公司核心业务系统、资金划付流水系统及风控管理模块，更新节奏为每日凌晨生成前一自然日的全量数据。文档结构为单条记录对应单个租赁项目当日的融资与回款情况，整体采用结构化格式，包含项目编号、承租人统一社会信用代码、融资金额、当期应收租金、当期实收租金、逾期天数等字段，所有金额类字段统一以万元为单位，日期格式固定为YYYY-MM-DD，每条记录通过项目编号与日期组合实现唯一标识。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
由于数据源覆盖多业务模块，HTTP接口需支持多维度参数校验，确保拉取的数据仅包含授权范围内的项目信息；由于每日仅生成前一日的全量数据，接口轮询间隔需匹配数据生成节奏，避免频繁请求占用系统资源；字段固定以万元为单位且包含唯一标识组合，接口需强制返回指定字段，同时支持按项目编号、日期范围筛选；单日报记录数随业务规模增长可能较多，接口需配置分页参数，防止返回数据体量过大引发超时或传输失败。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `sync_interval` | `24 小时` | 匹配融资租赁融资日报每日生成一次的更新节奏，避免重复拉取无效数据 |
| `request_timeout` | `600 秒` | 覆盖多数据源拉取的等待时长，防止中途中断请求导致数据不完整 |
| `response_format` | `JSON 数组 / CSV 表格` | 适配不同外部系统的处理需求，JSON用于数据分析，CSV用于财务对账 |
| `field_mapping` | `按项目编号+日期映射唯一标识` | 确保融资租赁项目数据与后续回款、风控数据准确关联，避免数据混淆 |
| `auth_type` | `API 签名认证` | 保障包含金融敏感信息的融资日报数据传输安全 |
| `max_page_size` | `100 条/页` | 平衡单页数据传输效率与体量，防止因数据过大引发超时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用接口返回400状态码，且请求体未被正确解析。原因：未按照融资租赁融资日报的字段要求传递参数，例如遗漏`project_id`或`date`字段，导致接口无法匹配对应数据范围。
- 现象：接口返回的金额字段与本地系统数值偏差较大。原因：未配置字段单位转换规则，直接将接口返回的万元数值与本地系统的元单位数值进行计算。
- 现象：触发`URIError: URI malformed`报错。原因：在拼接接口请求URL时，未对承租人名称等包含特殊字符的字段进行URL编码，导致URL格式不符合规范。

## 怎么确认配好了
- 发起一次按指定日期和项目编号的接口请求，核对返回的字段是否包含预设的必填项。
- 查看接口请求日志，确认签名认证信息已正确携带，且超时时间设置符合业务场景需求。
- 对比接口返回的金额数值与本地系统的原始数据，确认单位转换规则已生效。
- 模拟连续24小时的请求，检查接口返回的数据未出现重复或遗漏的情况。
