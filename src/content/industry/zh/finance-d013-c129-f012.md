# 融资租赁融资日报的模型接入与配置

## 这个品类的数据长什么样
融资租赁融资日报的数据来源于融资租赁公司核心业务系统、租赁物登记台账及公开征信公示信息，更新节奏为每日一次，通常在当日凌晨生成。文档以结构化表格为核心载体，包含租赁项目编号、承租人名称、租赁物类型、融资金额（单位：万元）、放款日期、到期日期、当日回款额、逾期天数等固定字段，部分报表附带单户租赁物的估值明细。

## 这些特征在「模型接入与配置」这一环带来什么约束
结构化为主的数据格式要求不能使用通用文档解析模式，需针对性配置结构化解析规则，否则会丢失字段对应关系。每日更新的特性要求同步周期与报表生成节奏匹配，避免数据滞后或重复同步。固定且带特定单位的字段，需严格配置字段映射规则，防止模型混淆单位或调用错误字段。单份报表的业务条目数量有限，过多的召回或上下文长度会导致冗余信息干扰模型对核心数据的识别。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_DOCUMENT_MODE` | `structured_table` | 融资租赁融资日报以结构化表格为核心数据载体，该模式可保留字段与单元格的原始对应关系，避免通用解析打乱字段层级。 |
| `SYNC_FREQUENCY` | `daily 00:30` | 日报数据每日凌晨生成，该同步周期可在数据更新后第一时间完成知识库同步。 |
| `maxContext` | `8000–12000 字符` | 单份日报的结构化内容加上上下文对话历史，需控制在模型上下文窗口内，避免截断关键融资信息。 |
| `RECALL_TOP_K` | `前 3–5 条` | 单日报表的有效业务条目有限，过多召回会导致上下文冗余，影响模型对核心数据的识别。 |
| `RERANK_THRESHOLD` | `0.75–0.85` | 需过滤低相关性的历史报表条目，仅保留与当前查询高度匹配的当日融资数据。 |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 单份月度汇总的融资日报附件通常不超过该阈值，避免过大文件导致解析超时。 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：模型对话时弹出`connection error`提示，或接口返回`502 Bad Gateway`状态码。原因：未配置模型接入的代理节点，或第三方数据接口未开通调用白名单权限。
- 现象：导入中英文对照的融资日报知识库后，模型回答时未调用对应中文字段的内容，返回的答案与知识库内容无关。原因：未开启`ENABLE_CHINESE_SEGMENT`配置项，或解析模式设置为通用文本，未设置为结构化表格，导致中英文混合的字段映射失效。
- 现象：关联知识库后，模型思考过程中提示「未提供具体知识库内容」，且知识库同步状态显示「完成」但预览无数据。原因：未设置`PARSE_FILE_TIMEOUT_SECONDS`的合理时长，或单日报表的字段数量超过解析器默认上限，导致解析失败未生成索引。

## 怎么确认配好了
- 进入知识库管理页面，查看解析后的结构化字段列表，核对是否包含融资租赁融资日报的核心字段，字段映射是否与原始报表一致。
- 触发一次手动同步，查看同步日志中是否存在`parse_success`标记，无报错记录则说明解析与同步配置正常。
- 发起测试查询，输入与当日融资业务相关的问题，核对模型返回的结果是否来自当日的融资日报数据，且字段单位符合报表要求。
- 检查模型接入的配置面板，确认`RERANK_MODEL`已绑定对应重排模型，且模型接口的调用权限已开通。
