# 装修装饰融资日报的工作流编排

## 这个品类的数据长什么样
装修装饰融资日报的数据来源为装修装饰企业的财务台账、合作金融机构的放款接口、行业协会的项目报送数据。更新节奏为每日生成前一日的全量汇总数据，报送时间为T+1自然日。文档结构为单页结构化表格，包含项目编号、装修项目名称、申请融资金额、到账周期、对接机构、报送日期等字段，其中金额类字段单位为万元，周期类字段单位为自然日，所有字段格式固定，无随机变动项。

## 这些特征在「工作流编排」这一环带来什么约束
装修装饰融资日报的多数据源特性要求工作流配置多个异构接口调用节点，适配不同的认证与数据返回格式；每日T+1的更新节奏要求配置定时触发节点，匹配固定的拉取窗口，避免重复拉取或遗漏前一日数据；固定格式的结构化字段要求配置数据校验与映射节点，过滤无效字段、完成跨系统的格式转换；部分数据来自非标准化的企业报送，要求配置字段标准化处理环节，确保数据格式统一。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发周期` | `每日 09:00` | 匹配装修装饰融资日报T+1的更新节奏，在当日数据完成报送后第一时间拉取处理 |
| `接口调用超时时间` | `600 秒` | 适配合作金融机构接口的响应速度，避免因超时中断数据拉取 |
| `数据字段映射规则` | `按字段名精准匹配` | 装修装饰融资日报的字段格式固定，通过名称匹配可快速完成跨系统数据转换 |
| `工作流重试次数` | `2 次` | 应对临时的接口波动或网络抖动，降低单次执行失败的概率 |
| `节点执行总超时时间` | `1200 秒` | 全量拉取当日融资日报数据需处理较多条目，预留足够的执行时长 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流执行到数据库连接节点后无响应，状态显示为执行超时。原因：未设置数据库连接的超时参数，或超时时间配置低于实际业务所需时长，导致装修装饰项目融资数据的查询请求未完成就被终止。
- 现象：发布的工作流链接指向localhost地址，无法通过公网访问。原因：未在发布环节配置公网域名绑定，默认使用本地启动的服务地址。
- 现象：导入装修装饰融资日报的长文档后，出现大量字段为空的情况。原因：使用标题层级作为文档分隔符，未匹配该品类日报的结构化表格格式，导致表格内的跨行数据被错误拆分。

## 怎么确认配好了
- 手动触发工作流一次，查看各节点的执行日志，确认数据源拉取、字段映射、数据校验环节均正常完成。
- 访问发布后的工作流链接，验证是否能正常加载对话界面，且链接域名非本地地址。
- 导入一份标准装修装饰融资日报文档，查看分割后的片段是否保留完整的表格字段结构。
- 检查定时任务的触发记录，确认在每日指定时间自动触发工作流执行。
