# 装修装饰融资日报的部署与升级

## 这个品类的数据长什么样
装修装饰融资日报的数据来源于装修装饰企业的财务核算系统、合作银行的放款接口、供应链金融管理平台。数据更新节奏为每日生成前一工作日的完整条目，单份文档包含单项目的多维度融资信息，文档结构为单工作表的表格形式。字段包含装修合同编号、融资方名称、担保方信息、放款金额、到账日期、还款节点、逾期天数等，金额字段单位为人民币万元，天数字段单位为自然日，每条记录对应一个独立的融资项目。

## 这些特征在「部署与升级」这一环带来什么约束
装修装饰融资日报的多源数据来源要求部署时配置统一的格式转换规则，避免不同数据源的字段命名差异导致解析异常。每日更新的节奏要求定时任务的触发周期与日报生成周期对齐，确保同步获取最新数据，避免遗漏或重复获取历史条目。带单位的数值型字段要求部署时配置字段校验逻辑，过滤无效格式的数值数据，保证知识库存储数据的准确性。单份文档包含多条独立融资项目的特性，要求配置去重逻辑，避免同一融资项目被重复录入知识库。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 装修装饰融资日报单份数据量适中，600秒足够完成全量解析，避免超时中断 |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 单份装修装饰融资日报文件通常不超过50 MB，超出阈值可自动拆分上传 |
| `CRON_SCHEDULE` | `0 0 9 * * *` | 匹配装修装饰融资日报每日08:00前的生成周期，提前1小时触发同步获取最新数据 |
| `相似度阈值` | `0.75` | 融资项目的合同编号为唯一标识，0.75的阈值可准确过滤重复条目，避免冗余存储 |
| `分段长度` | `800–1200 字符` | 适配装修装饰融资日报的字段组合文本长度，提升向量召回的精度 |
| `DUPLICATE_REMOVE_ENABLE` | `开启` | 针对合同编号等唯一字段，开启去重可保证知识库数据的唯一性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 导入后部分融资字段为空，界面显示“字段解析失败”。原因是Excel中金额、日期字段设置了自定义单元格格式，未使用通用格式，导致解析时无法提取有效数据。
- 导入大文件时报错状态码504 Gateway Timeout。原因是`PARSE_FILE_TIMEOUT_SECONDS`配置值小于实际解析所需时长，未预留足够的解析时间。
- 定时同步后知识库出现重复融资条目。原因是未开启`DUPLICATE_REMOVE_ENABLE`配置，未对合同编号等唯一标识字段做去重处理。

## 怎么确认配好了
- 上传单份装修装饰融资日报Excel，检查解析后的字段是否与原文档一致，无缺失或错误格式。
- 手动触发一次定时同步任务，查看知识库是否生成当日的融资数据条目。
- 输入包含“装修项目融资”的查询词，核对召回的条目数量与配置的`召回条数`一致。
- 查看系统日志，确认无字段解析失败、超时报错的记录。
