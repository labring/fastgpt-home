# 调味品融资日报的多轮对话与提示词

## 这个品类的数据长什么样
调味品融资日报的数据来源为公开企业融资公告、行业媒体的企业动态汇总、地方金融监管备案公示。更新节奏为融资事件公开披露后2个工作日内完成条目更新。单条文档结构包含企业全称、细分调味品品类、融资金额、融资轮次、投资方名单、融资完成时间、主营调味品产品线等字段，融资金额单位为万元或亿元，细分品类涵盖酱油、蚝油、调味酱等常见调味品类别。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
由于调味品细分品类丰富，多轮对话需先引导用户明确目标细分品类，避免匹配到无关行业的企业融资数据。融资事件更新频率较快，对话需默认返回近7个工作日内的最新数据，提示词需加入数据时效性校验规则。单条数据包含多类字段且涉及金额单位，多轮交互中需统一金额单位表述，避免歧义。投资方名单可能包含多家主体，需支持按用户需求展开单家投资方背景的追问，无需一次性输出全部信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 调味品融资日报单条数据长度适中，多轮对话需保留3-5轮交互上下文，避免关键信息丢失 |
| `相似度阈值` | `0.75–0.85` | 需过滤与调味品融资无关的检索结果，同时保留细分品类的匹配结果，避免误判 |
| `分段长度` | `1000 字符` | 融资日报条目分散，分段后可按单条融资事件为单位拆分，提升检索精度 |
| `maxHistoryTurns` | `5 轮` | 用户对融资日报的追问通常集中在近3轮内，保留5轮即可覆盖多数交互场景，减少冗余计算 |
| `promptTemplate` | 按调味品细分品类+融资轮次+时间范围检索 | 引导模型优先匹配用户指定的细分品类，避免混淆其他行业的融资数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：多轮对话中无法识别用户指定的调味品细分品类，返回无关行业的融资数据。原因：系统提示词未预设调味品细分品类的分类规则，模型无法精准匹配检索条件。
- 现象：调用本地部署的LLM时，对话界面显示调用的模型为GPT系列，无法正常生成回复。原因：未在FastGPT的模型配置中关闭默认模型映射，导致第三方调用时强制替换为预设模型。
- 现象：上传融资日报文档时返回400 invalid image错误。原因：未正确配置文档解析的图片处理参数，导致文档内的品类标签图片无法被识别，触发格式校验失败。

## 怎么确认配好了
- 进入FastGPT的应用调试界面，输入指定调味品细分品类的融资日报查询，核对返回结果的品类匹配度。
- 开启多轮对话模式，连续发起3轮以上的追问，核对上下文是否被正确保留并用于后续检索。
- 检查模型配置页面，确认未开启默认模型替换选项，确保调用的是预设的本地LLM。
- 上传一份测试用的调味品融资日报文档，核对解析后的字段是否与预设的文档结构一致。
