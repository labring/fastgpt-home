# 调味品融资日报的工具调用与插件

## 这个品类的数据长什么样
调味品融资日报的数据来源包括全国食品工业协会监测的公开融资备案信息、地方商务部门公示的企业投融资动态、第三方工商变更公告。数据按日更新，每日凌晨同步前一日的披露内容。单份标准日报文档为结构化表格格式，包含融资主体名称、所属调味品细分品类、融资金额、融资轮次、投资方、披露日期、所在地区7个核心字段。融资金额单位为万元人民币，融资轮次采用创投行业通用术语，披露日期采用YYYY-MM-DD标准格式。

## 这些特征在「工具调用与插件」这一环带来什么约束
调味品融资日报的结构化表格特征要求工具调用需开启专用的结构化表格解析模式，适配多列字段的精准提取。按日更新的属性要求工具配置定时触发任务时，设置为每日凌晨执行增量拉取，避免全量同步的资源浪费。核心字段包含细分品类与金额单位，要求工具调用时需增加品类过滤逻辑，且自动校验融资金额的单位格式，确保提取数据的一致性。标准化的日期字段要求工具支持YYYY-MM-DD格式的日期解析，避免因格式偏差导致字段为空或解析错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `PARSE_DOC_TABLE_MODE` | `结构化表格提取` | 适配调味品融资日报的标准表格格式，精准提取多列核心字段 |
| `SCHEDULER_CRON_EXPR` | `0 0 0 * * *` | 匹配每日凌晨的增量拉取需求，避免全量同步的资源消耗 |
| `TOOL_FILTER_CONDITION` | `所属调味品细分品类`字段非空 | 过滤非调味品主体的融资条目，确保工具仅处理目标品类数据 |
| `PARSE_FIELD_UNIT_CHECK` | `启用` | 校验融资金额的万元单位格式，避免提取到错误的金额数值 |
| `DATE_PARSE_PATTERN` | `YYYY-MM-DD` | 匹配披露日期的标准格式，提升日期字段的解析成功率 |
| `MAX_PARSE_RETRY_TIMES` | `3 次` | 应对临时的文档加载延迟，提升整体解析的稳定性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：切换非Qwen系列模型后，工具调用返回`Tool call failed`报错。原因：未配置工具调用的模型适配参数，部分模型不支持结构化工具调用的请求格式。
- 现象：工具调用出现并发执行，导致重复拉取同一条融资数据。原因：未配置增量拉取的时间戳过滤条件，导致定时任务重复触发历史数据。
- 现象：通过API调用工具后，解析结果中的披露日期字段为空。原因：未配置正确的日期解析格式，导致日期字段无法被正常提取。

## 怎么确认配好了
- 手动上传一份标准调味品融资日报样本，查看解析结果的核心字段是否完整，确认结构化解析模式生效。
- 触发一次测试定时任务，查看任务执行日志，确认仅拉取当日披露的融资数据，无历史数据重复加载。
- 切换不同模型测试工具调用流程，确认无工具调用相关的报错信息。
- 查看字段校验日志，确认融资金额的单位格式被正常校验，无异常数值提取。
