# 软件开发融资日报的多轮对话与提示词

## 这个品类的数据长什么样
软件开发领域的融资日报数据主要来自公开交易场所的企业融资披露公告、合规第三方金融数据接口。更新节奏为每个工作日当日收盘后完成当日数据归集，非工作日无更新。单份日报文档包含企业主体、融资轮次、融资金额、投资方阵容、融资完成日期、所属技术赛道等字段，融资金额单位统一为人民币万元或美元计价，部分条目附带融资方的核心业务简介。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
每日更新的特性要求多轮对话流程中需明确告知用户数据仅覆盖工作日披露的融资信息，避免用户查询非工作日的内容。固定字段结构要求提示词需严格限定问答仅基于日报内的企业主体、融资轮次、金额等公开字段，禁止生成未披露的额外业务信息。融资金额的单位差异化要求提示词需统一要求输出金额时标注对应计价单位，避免人民币与美元口径混淆。同时，单日报文的条目数量较多，提示词需引导用户限定查询范围，避免返回过量无意义的结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `前20轮对话` | 软件开发融资日报的问答多围绕单条或少量融资条目展开，过多上下文会干扰核心信息提取 |
| `systemPrompt` | `严格基于上传的软件开发融资日报文档作答，仅使用文档内公开字段，金额需标注计价单位，仅覆盖工作日披露数据` | 匹配该品类数据的字段与更新约束，避免生成无关或错误信息 |
| `召回条数` | `前3条` | 单条融资条目信息集中，过多召回会导致上下文冗余，影响回答精准度 |
| `相似度阈值` | `0.75` | 过滤低相关性的融资条目，同时保留同赛道或同轮次的关联信息 |
| `maxToken` | `8000` | 单份融资日报文档长度适中，8000token可覆盖完整的单日报文内容 |
| `toolCallEnable` | `关闭` | 软件开发融资日报的问答仅需基于知识库内容作答，无需调用外部工具 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用知识库问答时返回`401 No auth credentials found`错误。原因：未正确配置FastGPT的API密钥或知识库访问权限，导致请求未携带有效认证信息。
- 现象：对话中用户触发语音输入后，语音内容未转换为文字。原因：未开启语音转文字的模型绑定配置，或绑定的语音模型未完成授权流程。
- 现象：对话中返回的融资金额未标注计价单位。原因：系统提示词未明确要求标注单位，导致模型生成的回答不符合数据字段规范。

## 怎么确认配好了
- 向智能体发送测试查询，例如「2024年10月15日有哪些软件开发企业完成融资？」，核对返回结果是否仅包含工作日的披露数据。
- 发送包含金额查询的测试问题，例如「某软件开发企业的融资金额是多少？」，核对返回结果是否标注了计价单位。
- 查看对话上下文记录，核对系统是否自动限制了上下文轮次，避免冗余信息干扰。
- 检查知识库召回日志，核对召回的条目数量是否符合配置的`召回条数`参数。
