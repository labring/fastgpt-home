# 通信服务融资日报的工作流编排

## 这个品类的数据长什么样
通信服务融资日报的数据来源包括全国公共资源交易平台、通信行业专项监测数据库、企业公开融资公告。更新节奏为每日归集前一个自然日的公开融资信息，当日完成数据清洗与结构化。文档多采用JSON或CSV的结构化格式，包含标准化字段：融资主体名称为文本，所属通信服务细分赛道为分类文本，融资金额以万元为单位的数值，融资轮次为枚举文本，投资方为数组文本，公告日期为标准日期格式，披露来源为文本。

## 这些特征在「工作流编排」这一环带来什么约束
数据来源分散导致不同渠道的字段格式存在差异，例如部分披露信息的金额单位混用，需要工作流配置统一的字段对齐与单位转换步骤。每日更新的节奏要求工作流需设置固定定时触发，避免频繁抓取导致重复数据或触发平台访问限制。枚举型的融资轮次字段需要工作流配置校验节点，过滤无效的轮次表述。投资方为数组类型的字段，要求工作流支持数组遍历节点，以处理多投资方的信息提取。日期字段的校验需限定在当日前一日的范围，避免拉取历史重复数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `trigger_cron` | `0 7 * * *` | 匹配通信服务融资日报每日归集前一日数据的需求，早间触发可确保当日获取最新披露信息 |
| `field_mapping_mode` | `strict+custom_mapping` | 不同来源的字段格式存在差异，严格模式可过滤格式异常数据，自定义映射可统一字段命名 |
| `array_traversal_limit` | `10` | 单条融资信息的投资方数量通常不超过10家，限制遍历次数可避免工作流超时 |
| `validate_date_range` | `[${prev_day}, ${today}]` | 仅归集前一日的融资公告，过滤历史重复数据 |
| `enum_check_list` | `["天使轮", "Pre-A轮", "A轮", "B轮", "战略投资"]` | 覆盖通信服务领域常见的融资轮次，可校验无效轮次表述 |
| `output_format` | `csv` | 结构化融资数据适合用CSV格式存储，便于后续处理与导入 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流本地预览可正常返回结果，发布免登录窗口后返回空数据或报错。原因：发布后触发的定时任务未正确配置数据来源的访问权限，或未同步预览阶段的自定义字段映射规则。
- 现象：循环体无法按指定条件终止，循环持续执行超出预期次数。原因：未正确配置`loop_break_condition`参数的匹配逻辑，或未指定正确的判断字段。
- 现象：调用工具时传入的`q`参数未包含融资主体的精准名称，导致工具返回无关结果。原因：未在工作流中配置字段提取节点，将原始数据中的主体名称准确映射到工具调用的参数中。

## 怎么确认配好了
- 手动触发一次工作流，查看运行日志中的字段提取结果，确认融资主体、金额等核心字段已正确映射。
- 检查定时触发配置，确认`trigger_cron`的执行时间与数据更新节奏匹配。
- 测试循环体的终止条件，传入包含指定轮次的测试数据，确认循环在满足条件时正常退出。
- 调用工具节点，传入模拟的融资主体名称，确认`q`参数已正确传入目标字段的值。
