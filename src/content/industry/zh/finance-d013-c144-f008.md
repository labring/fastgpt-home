# 通信服务融资日报的工具调用与插件

## 这个品类的数据长什么样
通信服务融资日报的数据主要来自公开披露的行业融资公告、通信行业协会的信息汇总、上市主体的定期及临时报告。更新节奏为每日更新，覆盖前一个自然日的全行业通信服务类融资事件。单篇日报文档包含结构化条目，每条条目包含主体全称、融资轮次、融资金额与单位、投资方名单、通信服务细分赛道、落地应用场景、信息披露日期等字段，其中融资金额字段支持万元、亿元两种单位，部分未公开具体金额的事件会标注「未披露」。

## 这些特征在「工具调用与插件」这一环带来什么约束
通信服务融资日报的多单位字段、每日更新节奏、细分赛道分类及未披露金额条目等特征，对工具调用与插件环节带来多项约束。首先，融资金额的双单位设计，要求插件配置单位自动识别与统一转换逻辑，避免大模型输出格式混乱。其次，每日更新的数据源特性，要求插件设置每日定时拉取任务，并基于披露日期字段实现增量拉取，减少重复数据处理。第三，细分赛道的结构化分类，要求插件支持按通信服务赛道作为参数进行筛选调用，匹配精准查询需求。最后，未披露金额的条目，要求插件配置异常字段的处理逻辑，避免大模型生成无效内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_fetch_interval` | `86400 秒` | 匹配通信服务融资日报每日更新的数据源节奏，确保拉取频率与数据更新同步 |
| `plugin_incremental_fetch_key` | `disclosure_date` | 以披露日期作为增量拉取的唯一标识，避免重复拉取历史数据 |
| `field_unit_conversion_rule` | `自动识别万元/亿元并统一转换为亿元单位` | 统一融资金额的输出格式，降低大模型对多单位的识别误差 |
| `plugin_abnormal_field_handle` | `替换为「融资金额未披露」占位符` | 处理未公开金额的条目，避免大模型生成无意义的模糊内容 |
| `tool_call_timeout` | `300 秒` | 适配全量通信服务融资数据的拉取耗时，避免网络请求中途超时中断 |
| `filter_track_type` | `按通信服务细分赛道开启参数筛选` | 支持用户按云通信、5G基建等赛道精准查询，提升工具调用的匹配度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用完成后无法正常切换至无工具的用户对话链路。原因：未在插件配置中开启工具调用结束后自动恢复普通对话模式的选项，导致会话始终绑定工具调用规则。
- 现象：输出内容中残留「引用标记：［1］」类字样。原因：未在插件结果处理环节添加引用标记过滤逻辑，且知识库召回的引用输出开关未关闭，导致标记随结果带入最终输出。
- 现象：拉取的通信服务融资数据出现大量重复条目。原因：未配置基于披露日期的增量拉取规则，或增量拉取的标识字段与数据源实际更新字段不匹配，导致重复拉取历史数据。

## 怎么确认配好了
- 手动触发一次插件调用，核对返回的融资数据的披露日期范围是否与预设的拉取周期匹配。
- 检查插件返回的融资金额字段，确认双单位已统一转换为预设格式，未披露条目显示对应占位符。
- 模拟包含通信服务细分赛道关键词的用户查询，确认插件可按参数筛选对应赛道的融资数据。
- 完成一次完整工具调用流程后，发起无工具调用的普通查询，确认会话链路已正常切换。
