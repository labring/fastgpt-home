# 通信设备融资日报的工具调用与插件

## 这个品类的数据长什么样
通信设备融资日报的数据来源于全国公共资源交易平台、通信行业监测数据库及上市公司公开公告，每日更新一次。单条数据包含设备细分类型（如光模块、基站天线、核心网设备）、融资主体名称、融资金额（单位：万元）、融资轮次、披露日期、交易主体所在地等字段，部分未公开的定向融资项目会标注为待确认状态，文档以结构化JSON或CSV格式存储。

## 这些特征在「工具调用与插件」这一环带来什么约束
每日更新的数据源要求工具配置增量拉取逻辑，避免重复处理历史数据，降低资源占用。结构化的字段体系要求工具调用时严格匹配预设字段映射，防止解析错位导致数据混乱。细分设备品类的多样性要求工具支持按设备类型设置过滤参数，精准匹配目标数据集。未公开融资项目的标注要求工具配置空值过滤规则，剔除无效数据项，避免影响后续分析。跨多源拉取的场景要求工具配置合理的超时阈值，适配不同数据源的响应速度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_fetch_interval` | `86400 秒` | 匹配通信设备融资日报每日更新的发布节奏，避免重复拉取历史数据 |
| `field_mapping_strategy` | 严格匹配预设字段 | 适配数据源的结构化格式，确保融资金额、设备类型等核心字段正确解析 |
| `filter_rule` | 仅保留已披露融资项目 | 过滤待确认状态的无效数据，提升工具返回结果的有效性 |
| `plugin_request_timeout` | `300 秒` | 预留足够时间完成跨多源数据拉取，避免因响应超时导致任务失败 |
| `empty_value_policy` | 跳过该条记录 | 处理未公开融资项目的字段缺失问题，防止无效数据进入后续流程 |
| `data_batch_size` | `500 条` | 平衡单次请求的传输效率与数据完整性，避免单次请求数据量过大 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：插件调用返回`400 Bad Request`错误，提示核心字段缺失。原因：未配置严格匹配的字段映射规则，将第三方数据源的非标准字段直接传入工具。
- 现象：在开源版4.8.17中无法找到自定义插件的配置路径。原因：未进入「插件管理」页面的「自定义插件」模块，误将知识库文件上传路径当作插件部署路径。
- 现象：工具返回的融资数据包含大量未披露的空值记录。原因：未配置空值过滤规则，未跳过待确认状态的融资项目。

## 怎么确认配好了
- 进入插件测试页面，手动触发一次数据拉取，检查返回的字段是否与预设映射规则完全匹配。
- 查看插件运行日志，确认最近一次拉取的时间间隔符合`plugin_fetch_interval`的配置值。
- 检查返回数据的过滤结果，确认无待确认状态的无效记录。
- 模拟单次拉取最大数据量的请求，确认未触发`plugin_request_timeout`配置的超时限制。
