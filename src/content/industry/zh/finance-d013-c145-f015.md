# 通信设备融资日报的部署与升级

## 这个品类的数据长什么样
通信设备融资日报数据主要来自全国公共资源交易平台、运营商内部集采公示、通信设备厂商中标公告。更新节奏为每个工作日更新当日新增的招投标与融资项目。单篇文档包含项目编号、采购主体、中标设备品类（如基带单元、光传输模块）、中标金额、交付周期、资质门槛等字段，金额单位为万元，交付周期单位为自然日，部分项目附带技术参数要求附件。

## 这些特征在「部署与升级」这一环带来什么约束
通信设备融资日报的多源数据拉取、字段差异清洗、定时更新等需求，对部署与升级环节提出明确约束。多平台数据源的接口格式不统一，部署时需配置灵活的字段映射规则，避免因数据源变更导致数据解析失败。工作日高频更新的特性要求部署的定时任务调度需避开业务高峰，升级需选择非工作日或低峰窗口，防止中断当日日报生成。另外，通信设备项目附带的技术参数附件体积较大，需预留足够的存储与解析资源，升级时需同步验证附件解析逻辑的兼容性。同时，金额字段的精度要求较高，部署时需配置合适的存储格式，避免数值精度丢失影响后续统计。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `FETCH_TIMEOUT_SECONDS` | `300 秒` | 适配多招投标平台的响应延迟，避免单源拉取超时中断整体任务 |
| `SCHEDULER_CRON_EXPR` | `0 9 * * 1-5` | 匹配工作日上午9点的更新节奏，避开业务高峰时段 |
| `DATA_FIELD_MAPPING` | `{"中标价":"成交金额","中标方":"供应商"}` | 统一不同数据源的字段命名差异，简化数据清洗逻辑 |
| `PARSE_ATTACHMENT_MAX_SIZE` | `50 MB` | 适配通信设备技术参数附件的常规体积，过滤无效大文件 |
| `DATA_STORAGE_PRECISION` | `2` | 符合财务金额统计的精度要求，避免数值精度丢失 |
| `UPGRADE_GRAYSCALE` | `开启` | 降低升级风险，保障日报生成服务的连续性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 升级至4.9版本后，调用模型接口返回`500 Internal Server Error`，提示模型配置字段缺失。原因：升级脚本未同步更新模型关联的环境变量配置，导致原有配置项被覆盖或未加载。
- 执行`curl --location --request POST 'https://{{host}}/api/admin/initv490'`命令后返回`403 Forbidden`。原因：未配置管理员API密钥，或密钥权限不足，无法执行初始化升级接口。
- 生成的融资日报中「中标金额」字段为空值。原因：未配置`DATA_FIELD_MAPPING`参数，未适配数据源的字段命名差异，导致清洗逻辑无法匹配到对应数据。

## 怎么确认配好了
- 查看定时任务调度日志，确认任务触发时间符合预设规则，无执行失败记录。
- 手动触发一次数据拉取流程，核对解析后的字段与数据源的命名、单位匹配一致。
- 上传单份通信设备技术参数附件，验证解析流程无报错且内容完整。
- 执行升级验证接口，确认服务版本更新至目标版本，核心服务无异常重启。
