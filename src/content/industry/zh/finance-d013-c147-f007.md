# 造纸融资日报的工作流编排

## 这个品类的数据长什么样
造纸融资日报的数据来源包含行业协会公开统计数据、第三方大宗商品交易平台的造纸原材料融资成交数据、合作银行脱敏后的授信台账数据。数据更新节奏为每日凌晨更新前一交易日的全量数据。文档采用结构化JSON或CSV格式，单条记录对应单笔融资业务，包含汇总统计行。核心字段包括融资主体名称、当日融资发生额（单位：人民币元）、融资类型（票据/授信/质押）、对应原材料品类（木浆/废纸/再生纸）、融资到期日、资金方名称。

## 这些特征在「工作流编排」这一环带来什么约束
多数据源的拉取时序存在差异，银行脱敏台账数据比大宗商品平台数据晚2小时更新，因此工作流需设置延迟拉取节点，协调不同数据源的拉取时机。每日固定时间生成日报的刚性要求，需配置精准的定时触发规则，严格控制工作流总执行时长，确保在行业报送截止前完成全流程。不同数据源的字段命名差异较大，需配置统一的字段映射规则，避免下游分析出现字段不匹配的问题。涉及企业与金融机构的敏感信息，需内置数据脱敏节点，确保数据符合金融信息披露规范。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `触发时间表达式` | `0 0 7 * * ?` | 匹配每日7点触发，确保8点前完成日报生成，符合行业报送习惯 |
| `HTTP请求超时时间` | `30 秒` | 造纸融资数据的第三方接口响应通常在20秒内，预留10秒缓冲避免超时 |
| `字段映射规则` | `{"融资金额":"当日融资发生额","原料品类":"对应原材料品类"}` | 统一多源数据的字段命名，避免下游分析出错 |
| `数据脱敏规则` | `隐藏统一社会信用代码后4位` | 符合金融数据脱敏的通用要求，保护企业敏感信息 |
| `工作流重试次数` | `2次` | 应对第三方接口临时波动，避免单次拉取失败导致日报生成中断 |
| `嵌套表单自动隐藏` | `开启` | 适配子工作流调用场景，避免弹窗干扰整体流程 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 工作流执行后返回`KeyError: '当日融资发生额'`报错，现象是节点日志显示字段未找到，原因是未配置统一的字段映射规则，未将第三方数据源的`融资金额`字段映射为标准字段名。
- 嵌套工作流中的表单输入节点弹窗持续显示，现象是当造纸融资日报工作流作为子工作流被调用时，浏览器端始终弹出表单输入框，原因是未在子工作流的表单节点中开启`嵌套模式自动隐藏`配置项，导致弹窗不受父工作流的上下文控制。
- 调用自定义Python代码节点失败，现象是工作流状态显示为`执行失败`，日志中显示`ModuleNotFoundError: No module named 'pandas'`，原因是未在工作流运行环境中安装造纸行业数据处理所需的第三方依赖库。

## 怎么确认配好了
- 手动触发工作流，查看节点日志中各数据源的拉取状态，确认所有HTTP请求节点返回200状态码。
- 导出生成的融资日报样本，核对`当日融资发生额`、`融资主体`等核心字段的取值与原始数据源一致。
- 等待次日定时触发，确认工作流在指定时间内完成执行，未出现超时或重试失败的情况。
- 调用子工作流测试嵌套场景，确认表单输入节点弹窗自动隐藏，无异常弹窗显示。
