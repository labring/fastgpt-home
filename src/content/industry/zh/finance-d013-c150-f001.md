# 铁矿石融资日报的HTTP 接口与外部系统

## 这个品类的数据长什么样
铁矿石融资日报的数据主要来自国内铁矿石港口现货交易平台、银行授信系统及期货交割仓库的官方报送数据。更新节奏为每日更新，通常在当日凌晨生成前一自然日的完整报表。文档以结构化表格形式呈现，核心字段包含铁矿石产地、规格型号、现货成交价、融资授信额度、质押货物重量，其中成交价单位为元/湿吨，授信额度单位为万元，重量单位为吨。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
铁矿石融资日报的每日更新特性，要求HTTP接口需适配定时拉取或事件推送的调用节奏，超时阈值需预留足够时间等待当日凌晨的批量数据生成。结构化多字段的报表格式，要求接口返回的JSON结构需严格匹配预设的核心字段，不可缺失产地、成交价等必填项。不同规格铁矿石的可选字段存在细微差异，要求接口需支持动态返回非必填参数，避免调用失败。大额授信额度的数值范围较大，要求接口需兼容64位整数类型，防止数值精度丢失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `request_timeout` | 600 秒 | 适配每日凌晨批量生成的报表数据拉取，避免因数据量较大导致超时 |
| `auth_type` | Basic Auth | 多数大宗商品数据源平台采用基础认证方式对接外部系统 |
| `field_mapping_mode` | 严格匹配模式 | 确保结构化报表的核心字段无缺失，匹配预设的铁矿石融资日报字段 |
| `response_data_type` | JSON 数组 | 符合结构化报表的多条目数据返回格式 |
| `max_batch_size` | 50 条/请求 | 适配单批次铁矿石数据的合理量级，避免接口过载 |
| `retry_on_error` | 状态码 5xx 或 429 | 针对服务器过载或临时故障的自动重试逻辑 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用接口后返回的对话记录列表中，AI回复与用户提问的关联字段缺失。原因是未正确配置`field_mapping_mode`为严格匹配模式，导致接口返回的关联字段未被正确提取。
- 现象为HTTP接口调用返回401未授权错误。原因是未在`auth_type`配置项中正确填入Basic Auth的账号密码，或账号密码格式包含特殊字符未做转义。
- 现象为在线调试批量执行节点可正常完成，但通过API调用工作流时批量节点未执行完毕。原因是API调用的并发数超过了`max_batch_size`的配置阈值，且未设置队列等待逻辑。

## 怎么确认配好了
- 调用测试接口，检查返回的JSON数据中是否包含铁矿石产地、成交价等核心字段，字段名称与预设配置一致。
- 查看接口返回的状态码，确认200 OK状态下的返回数据结构符合预期，无异常错误码。
- 对比本地调试与API调用的返回结果，确认批量请求的执行数量与配置的批量阈值匹配。
- 检查工作流的对话日志，确认接口调用的请求与返回数据已被正确记录，无空值或缺失项。
