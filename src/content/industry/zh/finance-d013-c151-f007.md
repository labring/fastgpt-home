# 铁路公路融资日报的工作流编排

## 这个品类的数据长什么样
铁路公路融资日报的数据主要来自国铁集团运营统计系统、各省交通厅项目融资台账及公开招投标公告。更新节奏为每日T+1发布，覆盖当日新增及存量项目的当日融资动态。文档为结构化表格格式，包含项目唯一编码、所属路段/线路、总投资规模、当期融资额度、资金来源类型、资金到位累计额字段，单位统一使用亿元、万元及自然天数。

## 这些特征在「工作流编排」这一环带来什么约束
由于数据来源分散且格式存在差异，工作流需要配置多源数据拉取节点，适配不同系统的接口规范。每日T+1的更新节奏要求工作流设置定时触发规则，且需配置增量拉取逻辑，避免重复处理历史数据。结构化字段包含唯一项目编码，工作流需配置基于该编码的数据去重环节，确保单项目仅生成一条日报记录。字段单位存在跨来源的格式差异，需配置统一单位转换节点，将不同来源的金额字段对齐为标准单位。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `CRON_EXPRESSION` | `0 0 2 * * *` | 适配每日T+1的更新节奏，确保拉取前一日的融资数据 |
| `INCREMENTAL_SYNC_ENABLED` | `true` | 避免重复处理历史融资项目数据，符合每日更新的节奏要求 |
| `UNIQUE_KEY_FIELD` | `项目唯一编码` | 基于该字段进行数据去重，确保单项目仅生成一条日报记录，匹配结构化文档的字段设计 |
| `UNIT_CONVERSION_RULE` | `按1亿元=10000万元转换` | 对齐跨来源的金额单位差异，统一输出标准单位的融资数据 |
| `MAX_BRANCH_COUNT` | `10` | 适配铁路、公路两类数据源的分支拉取需求，避免节点执行过载 |
| `API_RESPONSE_TIMEOUT` | `600 秒` | 适配多源接口的响应时长，避免因数据拉取过慢导致工作流中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用节点执行后，同时生成AI回复文本与下一级分支的执行请求。原因：未在节点配置中关闭默认的联动执行开关，导致并行触发后续逻辑。
- 现象：使用API调用工作流时返回空值，嵌套知识库助手节点未生成有效回复。原因：工作流版本为v4.8.10及以上，未正确绑定知识库助手的输入变量格式。
- 现象：变量引用配置时弹出`quote type error`报错，无法保存配置。原因：输入的变量参数未使用标准JSON格式包裹，或字段名包含未转义的特殊字符。

## 怎么确认配好了
- 手动触发工作流执行，核对拉取到的项目数据与公开数据源的对应字段是否一致。
- 查看工作流运行日志，确认增量拉取逻辑仅处理新增数据，无历史数据重复处理。
- 配置多分支链路接入同一节点，验证不同来源的输入数据均可正常流转至后续环节。
- 调用工作流API接口，检查返回结果的字段格式是否符合预设的结构化要求。
