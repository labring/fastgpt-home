# 鞋类融资日报的HTTP接口与外部系统

## 这个品类的数据长什么样
鞋类融资日报的数据主要来自鞋类品牌的供应链金融模块、合作商业银行的对公放款台账、下游经销商的预付款备案系统，以及鞋材供应商的融资申请记录。更新节奏为每日生成前一自然日的完整报表，即T+1更新。单份日报为结构化数组格式，每行对应一笔融资业务，包含`主体名称`、`融资金额`、`融资类型`、`放款日期`、`回款状态`、`融资期限`等字段。其中`融资金额`单位为人民币元，`融资期限`单位为自然日，`放款日期`采用YYYY-MM-DD格式。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
鞋类融资日报的多源数据来源，要求HTTP接口支持对接至少3类外部系统，需配置独立的鉴权参数适配不同合作方的接口规则。每日T+1的更新节奏，要求接口轮询间隔不宜低于6小时，避免重复拉取未更新的数据。结构化的数组型文档，要求接口返回数据需支持按字段名精准匹配，同时需配置字段映射规则，将外部系统的自定义字段转换为统一的业务字段。鞋类融资主体存在代工厂、鞋材供应商、经销商等细分类型，要求接口参数中需支持按主体类型过滤数据，同时返回字段需包含该细分类型标识。单笔融资金额跨度较大，接口需支持按金额范围筛选的参数配置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `external_api_auth_type` | 按合作方接口类型选择`api_key`或`basic_auth` | 适配鞋类融资对接的银行与供应链系统的不同鉴权要求 |
| `polling_interval` | `6 小时` | 匹配每日T+1的更新节奏，避免频繁拉取产生无效请求 |
| `field_mapping_rules` | 配置`{"loan_amount":"融资金额","loan_date":"放款日期","subject_type":"主体类型"}`类映射 | 统一不同外部系统的字段命名差异，确保数据解析一致性 |
| `request_timeout` | `30 秒` | 平衡接口响应速度与批量数据拉取的完整性，避免单接口请求超时中断流程 |
| `filter_subject_types` | 开启`true`并指定主体类型列表 | 精准筛选鞋类专属的融资主体数据，排除无关业务条目 |
| `max_batch_size` | `100 条` | 适配单份鞋类融资日报的常规数据量，避免单次请求超出外部接口的容量限制 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部接口返回`403 Forbidden`状态码，且日志显示鉴权参数未正确传递。原因：未针对鞋类融资对接的不同合作方配置独立的鉴权参数，混用了同一套鉴权配置。
- 现象：拉取的数据中`融资金额`字段为空或数值单位不一致。原因：未配置`field_mapping_rules`，直接使用外部接口返回的原始字段名，部分银行接口使用`amt`作为字段标识，未使用`融资金额`作为字段标识，且未统一单位转换规则。
- 现象：在企业内网环境调用外部接口失败，日志显示无法建立SSL连接。原因：未配置`https_proxy`参数，未允许HTTP插件通过代理访问外部系统，导致无法对接银行或供应链系统的内网接口。

## 怎么确认配好了
- 调用测试接口，传入模拟的鞋类融资主体参数，检查返回数据的字段是否与配置的`field_mapping_rules`匹配。
- 查看接口调用日志，确认鉴权参数已正确传递，未出现`403 Forbidden`或`401 Unauthorized`状态码。
- 模拟每日T+1的拉取请求，检查返回数据的时间范围是否仅覆盖前一自然日，未包含历史重复条目。
- 在内网测试环境中配置`https_proxy`参数，验证是否可正常访问企业内网的供应链金融系统接口。
