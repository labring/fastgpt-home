# 风电融资日报的部署与升级

## 这个品类的数据长什么样
风电融资日报的数据主要来源于并网风电场的每日发电上报数据、合作银行的授信审批系统、地方能源监管平台的项目备案信息。更新节奏为每日凌晨更新前一日的全量数据。单篇文档结构包含项目唯一标识、风电场经纬度、装机容量（单位兆瓦）、当日上网电量、累计融资额度、合作金融机构、授信批复期限（单位月）、审批进度状态等字段，部分文档会附带项目环评备案编号。

## 这些特征在「部署与升级」这一环带来什么约束
每日全量更新的特性要求部署时配置定时增量同步任务，避免全量拉取占用过多集群资源。多数据源接入的需求需要预设多个适配不同鉴权规则的数据源连接器，适配银行授信系统、能源监管平台的不同接口权限。字段包含数值型的装机容量、融资额度，需在向量召回前配置数值归一化规则，保证跨字段检索的精度。升级环节需预留数据同步的缓冲窗口，避免更新时段与版本升级冲突导致当日日报数据缺失。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `SYNC_TASK_CRON` | `0 0 3 * * *` | 匹配每日凌晨3点更新前一日数据的调度需求，避开业务高峰时段 |
| `MILVUS_VECTOR_DIM` | `1536` | 适配m3e系列模型的向量维度，保证风电融资日报文本与数值特征的向量存储匹配 |
| `MONGODB_WRITE_CONCURRENCY` | `5` | 适配每日全量更新的写入吞吐量，避免并发过高导致数据库锁表 |
| `RECALL_TOP_N` | `前10条` | 匹配风电融资日报单篇文档的核心字段覆盖需求，保证检索结果覆盖关键信息 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 适配部分附带长文本环评报告的风电融资日报文档大小 |
| `PARSE_TIMEOUT_SECONDS` | `600 秒` | 处理包含复杂附件的日报文档，避免解析任务中途超时 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：拉取Docker镜像超时，报错显示`network error: timeout`。原因：未配置国内镜像源或代理，风电融资日报的部署镜像依赖多个基础组件，默认源拉取速度过慢。
- 现象：向量检索结果为空，界面显示`no matching documents`。原因：未配置数值型字段的归一化规则，风电融资日报中的装机容量、融资额度等数值字段与文本特征的向量空间不匹配。
- 现象：每日同步任务中断，MongoDB容器日志显示`connection refused`。原因：未正确配置`MONGODB_WRITE_CONCURRENCY`参数，并发写入超出数据库承载上限，触发连接断开报错。

## 怎么确认配好了
- 执行手动同步任务，查看数据源同步日志，确认所有配置的数据源均成功拉取数据。
- 发起向量检索请求，核对返回结果的字段与风电融资日报的预设字段一致。
- 查看定时同步任务的运行记录，确认每日凌晨的同步任务未出现异常报错。
- 测试上传单份风电融资日报附件，确认解析任务未触发超时错误。
