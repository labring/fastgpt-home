# 饰品融资日报的工作流编排

## 这个品类的数据长什么样
饰品融资日报数据主要来自饰品品牌的存货质押融资系统、供应链金融平台的每日对账文件、线下门店当日回款台账。数据更新节奏为每日凌晨更新前一日全量数据，部分异常补录数据当日生效。单条数据包含SKU编号、原料品类、采购单价、质押比例、授信额度、当日放款金额、回款截止日期、合作金融机构名称。其中采购单价单位为元/克或元/件，授信额度单位为万元，放款金额单位为万元。文档以结构化csv或excel格式存储，每条数据对应单款饰品的当日融资相关信息。

## 这些特征在「工作流编排」这一环带来什么约束
饰品融资日报的多数据源特性要求工作流配置多格式适配节点，需同时支持结构化文件、接口拉取两种接入方式，适配不同分隔符的csv与excel解析规则。每日更新的节奏要求配置定时触发节点，设置每日凌晨执行，同时需配置增量数据识别逻辑，避免重复处理当日补录的记录。字段与单位的差异要求配置字段映射节点，统一不同品类的单位转换规则，将元/克、元/件的采购单价统一为标准格式。饰品SKU的多批次特性要求配置联合去重节点，基于SKU编号与日期字段过滤重复数据。数据校验环节需针对采购单价、放款金额的合法性校验，防止异常数据流入后续环节。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `trigger_cron` | `0 0 * * *` | 匹配饰品融资日报每日凌晨更新的节奏，在数据更新后立即启动工作流 |
| `file_delimiter` | `,` | 适配多数供应链平台导出的逗号分隔csv格式文件，部分excel格式文件可单独配置为`\t` |
| `deduplicate_keys` | `["sku_code", "report_date"]` | 基于饰品SKU编号与报告日期联合去重，避免重复处理同一饰品的当日融资记录 |
| `field_mapping` | `{"采购单价": "purchase_price", "放款金额": "loan_amount"}` | 统一原始字段名与工作流内部标准字段匹配，适配后续节点的字段调用要求 |
| `parse_timeout` | `600 秒` | 预留充足时间完成单批次csv或excel文件的解析，避免节点超时 |
| `file_quote_char` | `"` | 正确识别双引号包裹的饰品SKU编号，避免csv解析时的文本拆分错误 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流启动校验失败，界面提示请检查节点是否正确填值及连线是否正常。原因：未按数据源节点→字段映射节点→数据校验节点的顺序配置连线，或遗漏了`report_date`字段的必填配置，导致校验环节无法获取必要数据。
- 现象：处理含双引号的饰品SKU编号时，出现字段解析失败的报错。原因：未配置`file_quote_char`为`"`，未正确识别双引号包裹的SKU内容，导致csv解析时将双引号内的文本错误拆分。
- 现象：配置平行流程处理融资日报数据时，运行结果出现重复的饰品融资记录。原因：未为平行流程统一`report_date`的过滤条件，导致多个并行节点处理了相同日期的融资数据，产生重复记录。

## 怎么确认配好了
- 导入单条含双引号的饰品SKU的测试数据，运行工作流，查看节点日志，确认字段解析无异常。
- 验证定时触发节点的`trigger_cron`表达式是否匹配数据每日更新的节奏，确认触发时间符合预期。
- 运行工作流后，检查去重节点的输出结果，确认无重复的SKU与日期的联合记录。
- 查看数据校验节点的日志，确认异常数据（如负的放款金额）被过滤或标记。
