# 饲料融资日报的引用来源与溯源

## 这个品类的数据长什么样
饲料融资日报的数据来源涵盖全国饲料工业协会资讯平台、农业农村部畜牧兽医局监测数据库、上市饲料企业公告披露渠道。数据更新节奏为每日更新，单条记录的文档结构包含主体名称、融资类型、融资金额、披露日期、发布渠道、关联饲料品类、资金方等字段。融资金额的默认单位为人民币万元，披露日期多采用ISO标准日期格式，部分非官方来源会使用短横线分隔的月日年格式。

## 这些特征在「引用来源与溯源」这一环带来什么约束
饲料融资日报的数据来源分散，涵盖行业协会、企业公告与监管渠道，要求溯源环节需支持多源数据的交叉校验，避免引用非权威来源的信息。数据每日更新，需支持增量拉取配置，防止重复拉取历史数据。字段包含关联饲料品类、融资金额、披露日期等专属字段，需配置字段映射规则，将关联品类与当前场景绑定，同时统一金额单位与日期格式，确保引用内容的字段一致性。部分来源存在反爬机制，需配置合理的请求间隔与请求头参数，保障数据拉取的稳定性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回源配置` | 配置为「全国饲料工业协会资讯库+农业农村部监测库+企业公告库」 | 匹配饲料融资日报的多源权威数据特征，覆盖核心发布渠道 |
| `增量拉取开关` | 开启，设置增量拉取周期为`24小时` | 适配每日更新的日报节奏，避免重复处理历史数据 |
| `字段映射规则` | 配置「关联饲料品类」「融资金额」「披露日期」为必填映射字段 | 匹配饲料融资日报的专属字段结构，保障溯源信息完整 |
| `单位统一转换` | 设置金额转换规则为「统一转换为万元」 | 适配饲料融资日报的金额单位默认格式，消除单位歧义 |
| `日期解析格式` | 配置支持「YYYY-MM-DD」「MM/DD/YYYY」两种解析规则 | 适配不同来源平台的日期格式差异，保障日期字段解析准确性 |
| `请求间隔阈值` | 设置为`3–5秒` | 规避多数行业资讯平台的反爬限制，保障数据拉取成功率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为「知识库搜索节点选择变量引用时无可选值，无法关联已配置的饲料品类字段」，原因是未在数据源配置中开启字段变量导出权限，导致变量未进入可选列表。
- 现象为「引用内容出现金额单位混乱，同时出现元与亿元的记录」，原因是未配置`单位统一转换`参数，未对不同来源的金额字段做统一转换。
- 现象为「每日拉取时出现大量重复的历史融资记录」，原因是未开启`增量拉取开关`，或增量拉取周期设置超过24小时，未匹配日报的更新节奏。

## 怎么确认配好了
- 手动触发一次数据拉取，查看拉取日志中是否包含配置的三个召回源的请求记录，确认数据源配置生效。
- 检查拉取到的单条数据，确认关联饲料品类、融资金额、披露日期等字段已正确映射，无缺失或格式错误。
- 连续运行两次拉取任务，确认第二次拉取未返回首次已拉取的历史记录，验证增量拉取配置生效。
- 查看引用模板生成的内容，确认金额字段已统一转换为万元格式，日期格式符合预期。
