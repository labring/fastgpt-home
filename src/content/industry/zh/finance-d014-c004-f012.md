# 专用设备财报分析的模型接入与配置

## 这个品类的数据长什么样
专用设备品类的财报数据主要来自境内外证券交易所公开的上市公司定期报告、行业主管部门发布的月度/季度运行数据。数据更新节奏以季度财报为核心节点，年度财报补充完整业务明细。文档结构包含专用设备制造业务营收占比、单台设备均价、在手订单金额、产能利用率等字段，字段单位多为人民币万元、台套，部分细分品类还包含核心零部件采购占比等专项字段。

## 这些特征在「模型接入与配置」这一环带来什么约束
专用设备财报的混合结构化特征，要求模型接入时配置混合格式解析插件，适配表格与长文本的同时提取业务指标。固定的更新周期，需要配置定时同步任务的触发规则，匹配季度、年度财报的披露节点。多维度的业务字段存在统计口径差异，需要在模型配置中添加实体分类规则，区分专用设备与通用设备的统计数据。部分报告存在计价单位不统一的情况，需配置前置数据清洗规则完成单位转换，避免分析结果出现数值偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | `12000–16000 字符` | 专用设备财报的业务明细章节通常长达数千字符，需容纳完整的指标上下文 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `900 秒` | 单份包含多页结构化表格的财报文件，解析耗时较通用品类更长 |
| `RECALL_TOP_K` | `前 8 条` | 专用设备财报的核心指标分散在多个段落，需召回足够的上下文片段支撑分析 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 年度财报的PDF或Excel文件可能包含多季度明细数据，体积较大 |
| `RAG_SIMILARITY_THRESHOLD` | `0.75–0.85` | 专用设备业务术语专业性较强，需较高阈值过滤非相关的检索结果 |
| `SCHEDULE_SYNC_CRON` | `0 0 10 * * 1,4` | 匹配A股季度财报披露后的工作日节点，定时同步最新财报数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：接入模型测试时返回`404 status code (no body)`，且配置页面的模型信息已完整填写。原因：未正确配置模型的API接口地址或访问密钥权限，导致请求无法正常发起。
- 现象：FastGPT 4.8.9版本简易模式下，上传财报文件后，大模型未自动解析文件内容。原因：未开启简易模式下的`AUTO_PARSE_FILE`配置项，或模型上下文窗口不足以容纳解析后的全部文本。
- 现象：向量数据库无法完成批量训练，仅支持单文件调整参数后重新上传。原因：未将`BATCH_EMBEDDING_ENABLE`参数设置为开启状态，且未使用平台支持的批量数据上传格式。

## 怎么确认配好了
- 执行单次财报文件上传测试，查看解析后的文本片段是否包含专用设备财报的核心业务字段，确认解析规则匹配品类特征。
- 触发定时同步任务，查看数据同步日志是否匹配预设的Cron表达式，且同步的财报数据为最新披露的报告版本。
- 发起模型调用测试，查看检索结果的召回条数是否符合配置的召回参数要求，且相似度符合预设阈值规则。
- 测试网络搜索接点的调用，确认模型可正确整合搜索结果内容，且系统提示词包含对应的引用格式指令。
