# 中药财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
中药财报数据来源包括中药上市企业的官方披露公告、行业监管机构发布的行业运行数据、中药材专业市场的公开报价数据。更新节奏分为固定周期与实时两类：定期财报按季度、年度固定更新，行业运行数据按月度更新，市场报价按日更新。单份财报文档包含企业经营数据、生产端数据、产品营收结构、研发投入明细等模块，字段包含生产基地面积、饮片产能、单品营收、研发投入金额等，单位分别为亩、吨、元、万元。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
中药财报数据的多源、多更新频率特征，要求HTTP接口支持按数据源配置定时拉取任务，区分固定周期的全量同步与增量同步逻辑。生产端的亩、吨等非通用财务单位字段，要求接口支持单位映射配置，适配外部系统的默认单位规则。细分的生产、研发字段需求，要求接口开放按字段维度筛选的参数，避免返回冗余数据。多数据源的鉴权差异，要求接口支持多套API密钥的动态切换配置，适配不同数据源的鉴权要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `SYNC_DATA_INTERVAL` | 3600 秒（全量同步）、300 秒（增量同步） | 匹配财报数据的更新频率，全量同步覆盖季度/年度固定披露周期，增量同步适配实时市场数据 |
| `FIELD_UNIT_MAPPING` | 启用单位映射规则 | 适配中药财报中亩、吨等非通用财务单位，与外部系统的单位体系对齐 |
| `API_AUTH_TYPE` | 多密钥动态鉴权 | 适配不同数据源的鉴权要求，比如交易所API使用令牌鉴权，市场API使用签名鉴权 |
| `REQUEST_TIMEOUT` | 600 秒 | 覆盖多源数据聚合的最长响应时间，避免因数据量较大导致超时 |
| `BATCH_SYNC_SIZE` | 100 条/次 | 平衡接口负载与同步效率，适配单批次财报数据的返回量 |
| `FILTER_FIELD_LIST` | 生产基地面积,饮片产能,单品营收 | 按需筛选核心字段，减少外部系统的数据处理压力 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用财报数据接口时，传入不同的`pageNum`参数，返回的数据集完全一致。原因：接口未正确实现分页逻辑，未基于`pageNum`参数偏移查询结果集。
- 现象：调用关联的外部数据接口时，接口自动关闭服务并返回`429 Too Many Requests`状态码。原因：接口鉴权配置过期，或并发请求超出调用限额，触发自动限流。
- 现象：外部系统接收到的中药财报数据中，生产基地面积字段显示为异常数值。原因：未配置`FIELD_UNIT_MAPPING`，接口直接返回原始单位数据，与外部系统的解析规则冲突。

## 怎么确认配好了
- 调用测试接口，传入不同的`pageNum`参数，核对返回结果集的偏移量是否符合预期。
- 查看接口返回的字段单位，确认与外部系统的单位规则一致，可通过对比原始数据与返回数据的字段格式完成核对。
- 模拟多数据源调用，确认接口能自动切换鉴权方式完成请求，无鉴权失败日志。
- 检查定时同步任务的运行日志，确认按配置的间隔触发同步动作，无异常中断记录。
