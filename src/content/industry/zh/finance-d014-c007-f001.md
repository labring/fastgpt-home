# 乳制品财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
乳制品财报数据主要来自境内外证券交易所披露平台、行业协会公开数据库。更新节奏为每季度终了后1个月内披露季报，年度终了后4个月内披露年报。文档以结构化表格搭配文字说明的形式呈现，核心字段包含营业收入、营业成本、原奶采购量、包装材料成本、线下渠道营收金额等，单位分别为人民币万元、万元、吨、万元、万元。单份完整年报文档篇幅较长，包含多维度的经营数据明细。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
乳制品财报的专属字段与其他食品饮料品类存在差异，例如原奶采购量、包装材料成本等字段在多数消费品财报中并不常见，因此HTTP接口的字段映射规则需要单独适配。数据源的更新节奏固定为季度和年度，无需高频调用接口，但单次请求需处理较长篇幅的文档，因此接口调用的超时设置需要预留足够时长。此外，部分披露平台的接口存在调用频率限制，需要配置合理的请求速率阈值，避免触发限流规则。当数据需同步至外部系统时，需匹配外部系统支持的字段格式，否则会导致数据写入失败。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `HTTP_REQUEST_TIMEOUT` | `300-600 秒` | 乳制品财报文档篇幅较长，拉取与解析需充足时长 |
| `PARSE_FIELD_MAPPING` | 映射`营业收入`、`原奶采购量`、`营业成本`等专属字段 | 乳制品财报核心字段与其他品类存在差异，需精准匹配 |
| `ASYNC_TASK_POLL_INTERVAL` | `30 秒` | 财报数据处理耗时较长，轮询间隔兼顾及时性与资源占用 |
| `UPLOAD_FILE_MAX_RETRIES` | `3 次` | 应对网络波动导致的接口调用失败，减少手动重试成本 |
| `REQUEST_RATE_LIMIT` | `10 次/分钟` | 适配多数证券披露平台的调用频率限制，避免触发限流 |
| `EXTERNAL_SYSTEM_AUTH_TYPE` | `Bearer Token` | 匹配多数外部系统的标准认证规则，保障调用安全性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用HTTP接口拉取财报数据时返回`504 Gateway Timeout`状态码，原因是未针对乳制品财报的长文档调整超时配置，使用了默认的短时超设置。
- FastGPT节点输出的变量存入外部系统时无数据写入，原因是未配置乳制品财报专属的字段映射，导致外部系统无法识别传入的字段格式。
- 调用上传文件API后无法确认文件索引完成，原因是未配置异步轮询的校验参数，无法通过接口返回的状态字段判断处理进度。

## 怎么确认配好了
- 发起单次HTTP请求拉取单季度乳制品财报数据，核对返回字段与预设的字段映射规则是否一致。
- 触发一次接口调用，确认外部系统接收并存储了对应的数据条目。
- 上传一份乳制品财报的结构化文件，通过轮询接口确认处理状态更新为完成。
- 模拟短暂网络中断，检查接口是否按配置的重试规则执行自动重连。
