# 储能财报分析的工具调用与插件

## 这个品类的数据长什么样
储能财报数据主要来源于境内外证券交易所公开披露的定期报告、行业公开数据库。更新节奏为季度报告每季度结束后1至2个月发布，年度报告于次年4月30日前完成披露。文档分为结构化财务报表与非结构化经营分析两部分，结构化字段包含装机容量（单位：MW）、储能项目营收（单位：万元）、单位储能系统成本（单位：元/kWh）等，非结构化部分包含项目落地进度、行业政策影响分析等内容。

## 这些特征在「工具调用与插件」这一环带来什么约束
储能财报的结构化字段带有专属单位与业务属性，工具调用时需精准匹配字段映射规则，避免单位转换错误。季度与年度的固定更新节奏要求插件配置定时拉取任务，同步更新本地缓存的财报数据，防止使用过时信息。非结构化经营分析文本篇幅较长，工具调用时需适配长文本拆分逻辑，避免超出上下文长度限制。特有业务字段如装机容量、并网时间，需要工具支持自定义字段提取配置，无法直接复用通用财报工具的字段模板。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_field_mapping` | 新增储能专属字段映射，将「装机容量」单位统一为MW，「单位储能成本」单位统一为元/kWh | 储能财报包含通用财务字段与专属业务字段，需精准匹配避免解析错误 |
| `tool_fetch_cron` | `0 0 2 * *`（每日凌晨2点执行增量同步） | 季度财报更新周期为1-2个月，每日增量同步可保证数据时效性，避开业务高峰时段 |
| `max_context_window` | `8000–12000 字符` | 非结构化经营分析文本篇幅较长，需适配长文本处理需求，避免上下文溢出 |
| `tool_call_timeout` | `300 秒` | 财报数据拉取与多字段解析需处理多份文档，需预留足够的执行时间 |
| `parse_chunk_size` | `1000–1500 字符` | 长文本分段处理可降低上下文溢出风险，适配财报文档的篇幅特征 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用返回的储能财报字段为空，原因是未配置储能专属业务字段的映射规则，通用财报工具模板无法识别「装机容量」「单位储能成本」等特有字段。
- 现象：工具调用返回`504 Gateway Timeout`错误，原因是未调整`tool_call_timeout`配置，默认超时时间不足以完成多份财报文档的拉取与解析。
- 现象：模型提供商页面无工具调用日志入口，原因是未在系统设置中开启工具调用日志的展示开关，或未配置日志收集的权限规则。

## 怎么确认配好了
- 发起工具调用，检查返回结果是否包含储能专属业务字段，且单位匹配配置规则。
- 查看工具调用日志，确认定时拉取任务按配置的执行规则运行，无失败记录。
- 上传储能财报文档，检查解析后的文本分段长度符合配置区间。
- 进入系统设置页面，确认工具调用日志展示开关已开启，可在对应页面查看日志。
