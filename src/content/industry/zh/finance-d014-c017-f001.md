# 光学光电子财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
光学光电子品类的财报数据主要来自境内外证券交易所公开披露的定期报告与临时公告，更新节奏分为固定周期与不定期两类：固定周期为季度、半年度与年度报告，临时公告涵盖产能变动、新品量产、大客户合作等突发事项。数据文档包含通用财务字段与品类专属业务字段，通用字段包括营收、净利润、现金流等，专属字段包含面板出货量、LED封装产量、摄像头模组销量、分产品毛利率等，单位多为亿元、百万片、万颗等。数据格式同时支持结构化JSON与原始公告PDF附件。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
光学光电子财报的多维度业务字段要求接口返回结构化的细分数据，因此外部系统需支持指定返回字段的过滤配置。固定与不定期结合的更新节奏，要求接口同时支持按固定报告期与自定义时间范围查询，适配临时公告的拉取需求。品类专属的出货量、产能等数据需跨期聚合分析，会拉长单接口请求的耗时，因此外部系统需适配更长的超时阈值。此外，部分数据需关联原始公告PDF，接口需同时支持结构化数据与附件下载的双返回模式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `request_timeout` | `300 秒` | 光学光电子财报需拉取多期跨期聚合数据，单请求耗时较长，默认超时时长不足以完成数据拉取 |
| `query_period_type` | `quarterly,annual,temporary` | 覆盖品类财报的固定报告期与临时公告场景，匹配披露节奏 |
| `return_fields_filter` | `total_revenue,product_revenue,shipment_volume,gross_margin` | 仅拉取品类特有的细分业务字段，减少无效数据传输与解析成本 |
| `incremental_sync_switch` | `true` | 适配临时公告不定期更新的特征，避免重复拉取全量历史数据 |
| `api_auth_type` | `api_key` | 多数第三方光学光电子财报数据接口采用API密钥认证，符合行业通用配置规范 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用接口返回`getaddrinfo ENOTFOUND`错误，原因是光学光电子财报数据接口多配置企业专属域名白名单，动态域名服务未被授权，导致解析失败。
- 接口返回的结构化数据缺少产品细分营收字段，原因是未指定`return_fields_filter`参数，默认返回的通用字段未覆盖品类特有的业务数据。
- 调用后长时间无响应并触发超时报错，原因是未调整`request_timeout`参数，使用默认短超时无法适配多字段跨期聚合的耗时。

## 怎么确认配好了
- 调用测试接口，检查返回字段是否包含光学光电子财报特有的产品出货量、分品类营收等字段，确认`return_fields_filter`配置生效。
- 触发增量拉取任务，检查是否仅返回指定报告期内的新增公告数据，确认`incremental_sync_switch`配置正确。
- 查看接口调用日志，确认`request_timeout`参数匹配实际拉取耗时，无超时报错。
- 验证域名解析与白名单配置，确认工作流节点使用的域名可被正常解析，且已加入接口授权白名单。
