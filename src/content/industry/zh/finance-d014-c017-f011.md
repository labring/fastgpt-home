# 光学光电子财报分析的文档解析与分块

## 这个品类的数据长什么样
光学光电子品类的财报数据主要来自上市公司定期报告、行业公开研报及供应链披露文件。更新节奏以季度、年度为核心周期，同时伴随产能调整、新品发布等临时公告。文档结构包含标准化财务报表模块，以及细分业务板块数据，如显示面板出货量、LED芯片良率、研发投入金额等字段，单位涵盖万片、毫安时、像素等物理量及货币单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
光学光电子财报的多模块混合结构，要求解析环节精准区分财务报表与细分业务板块内容，避免跨模块的无效分块。临时公告的非标准化格式，会导致通用解析规则无法适配，需额外适配不同公告模板。细分业务字段的单位多样性，如显示面板出货量同时存在万片与片的标注，要求解析时关联字段与对应单位，避免数据歧义。文档内嵌入的产能、良率相关图表，需同步提取图表内文本与数值，否则分块会丢失核心业务指标。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_PDF_IMAGES` | 开启 | 光学光电子财报包含大量产能、出货量相关可视化图表，需提取图片内嵌文本与数值 |
| `CHUNK_MAX_SIZE` | 800–1200 字符 | 财报包含长段财务说明与短业务数据，该区间可平衡上下文关联性与分块精准度 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 120 秒 | 大型年度报告PDF包含多表格与复杂图表，解析耗时高于通用品类 |
| `METADATA_EXTRACT_FIELDS` | `["报告期", "显示面板出货量", "LED芯片良率", "研发投入金额"]` | 光学光电子财报核心业务元数据为上述字段，便于后续检索关联 |
| `UPLOAD_FILE_ALLOW_EXTENSIONS` | `["pdf", "docx", "xlsx"]` | 光学光电子财报常见格式包含PDF定期报告、Word行业研报、Excel业务数据表 |
| `PARSE_ENGINE` | `fastgpt-default`（或自定义解析引擎） | 光学光电子财报包含复杂表格与图表，专用解析引擎可提升提取精度，可通过该配置切换工具 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传PDF财报后，解析结果中无图片内嵌文本或图片无法显示。原因：未开启`PARSE_PDF_IMAGES`配置项，仅提取纯文本内容。
- 现象：检索到分块后，无法关联报告期、出货量等元数据。原因：未配置`METADATA_EXTRACT_FIELDS`指定提取字段，或元数据提取规则未绑定对应财报模块。
- 现象：上传Excel格式的业务数据表失败。原因：未将`xlsx`加入`UPLOAD_FILE_ALLOW_EXTENSIONS`配置项，或配置项格式错误。

## 怎么确认配好了
- 上传包含产能折线图的PDF财报，查看解析结果是否提取图表内的数值与标注。
- 上传.xlsx格式的业务数据表，确认文件可正常上传并完成解析。
- 配置`METADATA_EXTRACT_FIELDS`后，提交包含业务字段的检索请求，验证返回分块是否携带对应元数据。
- 上传超过100页的年度报告，确认解析过程未触发超时报错。
