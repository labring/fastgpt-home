# 光学光电子财报分析的模型接入与配置

## 这个品类的数据长什么样
光学光电子品类的财报数据主要来自沪深北交易所官方披露平台、上市公司投资者关系板块。更新节奏为定期报告按年度、半年度、季度固定节点披露，临时公告随经营动态实时更新。文档结构包含核心财务报表、经营数据汇总、业务板块分析。字段包含营收总额、出货量、产能规模等，单位分别为人民币亿元、万颗、千平方米每月，不同公司的细分业务披露格式存在一定差异。

## 这些特征在「模型接入与配置」这一环带来什么约束
财报文档长度跨度大，单份年报核心章节可达数千字符，要求模型接入时配置足够的上下文窗口容量，避免截断关键经营数据。细分业务字段无统一格式，需配置自定义抽取规则的参数，适配不同公司的披露差异。临时公告实时更新，要求模型接入支持动态触发的调用配置，适配实时数据的调用需求。多源数据来源需配置不同文件的解析优先级，确保最新披露的公告优先被调用。不同单位的字段需配置标准化转换参数，统一数据口径以保障分析准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–16000 字符` | 光学光电子财报单份核心业务章节通常为3000-8000字符，预留足够空间避免截断关键经营数据 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | 大型年报解析需较长处理时间，避免因超时中断完整解析流程 |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 单份年报PDF通常不超过20 MB，预留空间应对多页合并的批量文件上传 |
| `customExtractPrompt` | 提取营收、出货量、产能数据，统一单位为亿元、万颗、千平方米每月 | 光学光电子细分字段格式不统一，明确标准化抽取规则可避免数据口径混乱 |
| `concurrentLimit` | `3–5 并发` | 匹配公开财报披露平台与多数通用大模型接口的限流阈值，避免触发429错误 |
| `similarityThreshold` | `0.75–0.85` | 财报字段语义相似度较高，该区间可过滤低匹配度的无关数据，保障抽取精度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：接入本地大模型后调用时报500错误，查看日志显示模型响应格式异常。原因：未配置适配财报长文本的`maxContext`参数，导致输入超出模型支持上限触发内部错误。
- 现象：批量解析光学光电子财报时频繁返回429状态码。原因：未设置合理的`concurrentLimit`参数，并发请求超出接口限流阈值。
- 现象：抽取的经营数据单位不一致，出现「万颗」与「百万颗」混杂的情况。原因：未在`customExtractPrompt`中明确标准化转换规则，未统一数据口径。

## 怎么确认配好了
- 上传单份50页的光学光电子年报PDF，检查解析后文本未出现截断提示，确认`maxContext`与`PARSE_FILE_TIMEOUT_SECONDS`配置符合当前模型与文档长度。
- 提交3个以上不同公司的财报文件，检查抽取结果的单位统一，确认`customExtractPrompt`的标准化规则生效。
- 发起批量调用测试，观察接口返回状态码无429，确认`concurrentLimit`配置匹配实际限流要求。
- 调用模型生成财报分析摘要，检查输出包含核心经营数据，确认`similarityThreshold`过滤了低匹配度的无关内容。
