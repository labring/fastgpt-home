# 军工电子财报分析的引用来源与溯源

## 这个品类的数据长什么样
军工电子行业的财报数据主要来自沪深交易所公开披露的上市公司定期报告、临时公告，以及国防军工行业协会发布的行业运行数据。更新节奏分为固定周期与临时触发两类：年度报告、半年度报告、季度报告按监管要求固定披露，重大合同签订、产能调整等临时公告则无固定更新节奏。文档结构包含营收构成（细分至军工配套、民品业务）、研发投入、在手订单、合同负债等字段，单位以万元、亿元为主，部分专业披露项会采用标准化行业计量单位。公开披露内容会对涉密信息做简化处理，仅保留可公开的业务板块数据。

## 这些特征在「引用来源与溯源」这一环带来什么约束
军工电子财报的多源分散特性要求溯源环节需关联交易所官网、公司公告、行业协会数据库等多个数据源，避免单一来源的信息偏差。固定与临时结合的更新节奏，要求溯源功能支持实时拉取最新临时公告，同时缓存固定周期的报告内容。细分业务字段与专业术语密集的特点，要求召回环节需精准匹配军工电子专属的营收分类、研发指标等字段，避免召回同行业其他品类的无关财报内容。长文档与涉密简化的特征，要求溯源环节需精准定位对应段落的来源，避免因分段不当导致溯源信息与分析内容不匹配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `引用展示位置` | `段落末尾` | 符合军工电子财报分析的专业阅读习惯，便于用户直接关联分析内容与对应数据来源 |
| `最大召回段落数` | `前6-8条` | 军工电子财报细分字段较多，需覆盖足够的关联数据，同时避免召回冗余内容干扰分析 |
| `知识库文件解析分段长度` | `800-1200字符` | 军工电子财报包含大量专业术语与业务细分描述，分段过长会丢失上下文关联，过短会破坏专业表述完整性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300-600秒` | 军工电子年报文件体积较大，解析与溯源拉取耗时较长，需预留足够的处理时间 |
| `免登录分享引用权限` | `按应用配置开启` | 军工相关财报数据涉及行业敏感信息，需通过权限控制避免未授权访问 |
| `相似度阈值` | `0.75-0.85` | 军工电子财报的专业术语相似度较高，需设置合理阈值过滤无关召回内容，提升溯源精准度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：免登录分享链接访问应用时，引用查看原文功能开启后仍无法显示。原因：未正确配置`免登录分享引用权限`参数，或配置后未完成应用重启生效。
- 现象：4.9.7版本部署后，知识库回答段落末尾未显示引用标记。原因：`引用展示位置`参数未设置为`段落末尾`，或未开启全局引用溯源总开关。
- 现象：连续两次发起军工电子财报分析提问后，第二次回答未关联第一次的分析内容，出现答非所问的情况。原因：`maxContext`参数取值过低，未保留足够的财报分析上下文，或`上下文关联阈值`设置不合理。

## 怎么确认配好了
- 上传一份军工电子上市公司的公开财报文件，发起针对性提问，检查回答段落末尾是否显示引用标记与来源链接。
- 复制应用的免登录分享链接，在未登录状态下访问，测试引用查看原文功能是否可正常跳转至对应数据源。
- 发起连续两次财报分析相关提问，检查第二次回答是否关联第一次的分析上下文与引用来源。
- 查看知识库解析日志，确认文件分段长度与超时时间的配置值与实际处理参数一致。
