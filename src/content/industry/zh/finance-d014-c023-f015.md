# 军工电子财报分析的部署与升级

## 这个品类的数据长什么样
军工电子财报数据主要来自公开披露的上市公司定期报告、临时公告，以及行业协会发布的公开统计资料。更新节奏遵循A股披露规则，季度报告每季度末后一个月内发布，半年度报告每半年末后两个月内发布，年度报告每年度末后四个月内发布，临时公告随重大事项发生即时发布。文档结构包含核心财务报表、军工业务营收明细、科研投入相关模块、订单及交付数据模块，字段多包含业务分类营收、资产规模、研发投入金额等，单位以万元、亿元、台套为常见计量标准。

## 这些特征在「部署与升级」这一环带来什么约束
军工电子财报的多源分散、分层更新、复杂文档结构及专属字段特征，对部署与升级环节带来多重约束。多源数据拉取需配置跨平台对接规则，部署阶段需预设交易所公告接口、行业协会数据接口的适配参数。分层更新节奏要求部署时设置固定周期任务与事件触发任务并行的同步机制，升级阶段需新增临时公告的即时同步触发逻辑。复杂文档结构与专属字段则要求部署时配置自定义解析模板，升级阶段需迭代字段映射规则以适配新披露的业务分类。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 军工电子财报单文档长度可达数十万字符，常规解析时长较长，需预留足够超时时间 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 单份年度财报的PDF或Excel文件体积较大，需适配大文件上传需求 |
| `CHUNK_SIZE` | `800–1200 字符` | 军工电子财报包含多业务模块，分段过长会丢失上下文关联，过短会破坏字段完整性 |
| `SYNC_CRON_EXPR` | `0 0 2 * * *` 与 `0 0 10 * * 1,3,5` | 定期报告披露集中在工作日非高峰时段，分时段同步可避免资源占用过高 |
| `SIMILARITY_THRESHOLD` | `0.72–0.78` | 军工电子财报的专业字段关联性强，需较高相似度阈值过滤无关匹配结果 |
| `RE_RANK_TOP_N` | `前 3 条` | 军工电子财报的专业术语密集，重排过多结果会降低检索精准度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：通过Docker部署后无法修改登录密码，容器重启后配置失效。原因：未将FastGPT的配置目录挂载到宿主机本地路径，密码配置仅存储在容器内部，容器重建后配置丢失。
- 现象：启动容器后返回`500 Internal Server Error`，日志显示数据库连接超时。原因：未正确配置数据库连接参数，或数据库服务未在指定端口开放访问权限，4.9版本及以上需额外配置数据库连接池参数。
- 现象：通过ngrok暴露外网后，iOS设备访问页面显示白屏，macOS与Windows设备可正常访问。原因：未配置HTTPS证书，ngrok的HTTP协议在iOS系统的浏览器中存在兼容性限制，无法正常加载前端资源。

## 怎么确认配好了
- 执行手动数据同步任务，核对同步后的知识库中是否包含预设的军工电子财报核心字段，确认字段映射规则与配置一致。
- 上传一份测试用的军工电子财报文档，查看解析后的分段结果是否符合配置的分段区间，检查是否出现关键内容截断或丢失。
- 访问暴露的外网地址，使用不同类型设备测试页面加载情况，确认前端资源无加载异常。
- 查看容器运行日志，确认数据库连接、定时同步任务均正常运行，无报错信息。
