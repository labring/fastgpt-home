# 农化制品财报分析的引用来源与溯源

## 这个品类的数据长什么样
农化制品财报的数据主要来源于境内外证券交易所公开披露的定期报告、行业自律组织发布的产业运行数据，以及对应公司官网发布的年度报告。更新节奏为季度报告每季度末后1至2个月披露，年度报告于次年4月底前完成披露，临时公告随产能调整、原料价格变动等事项发生后2个交易日内披露。单份财报文档包含管理层讨论与分析、财务报表及附注，其中农化品类专属字段包括主要产品销量、产能利用率、上游原料采购占比、环保投入金额等，单位多为人民币元、吨，部分涉及出口的业务会附带美元计价的营收数据。

## 这些特征在「引用来源与溯源」这一环带来什么约束
农化财报的专属字段需要精准匹配溯源，不能仅依赖通用财务字段的提取规则，否则会遗漏产品销量、产能等核心分析数据。临时公告的高频更新要求溯源环节支持实时抓取与时间戳校验，避免引用过期的临时数据。不同市场的披露格式存在差异，A股财报的产品明细多以表格形式呈现，港股财报则多以段落形式描述，这要求溯源环节适配多格式的结构化提取规则。此外，部分细分产能数据仅在行业协会报告中披露，需要溯源环节支持跨数据源的关联匹配，将交易所财报与行业数据进行绑定溯源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `rag_source_filter` | `["交易所公告", "行业协会报告", "公司官网年报"]` | 覆盖农化财报的核心数据源，避免无关内容混入分析结果 |
| `recall_top_k` | `前 8 条` | 农化财报包含较多专属细分字段，需要足够的召回量覆盖产品、产能等分析所需数据 |
| `parse_chunk_size` | `1200 字符` | 农化财报的产品明细、成本构成段落较长，适配长段落的结构化拆分，避免丢失上下文 |
| `source_citation_mode` | `full_path_with_timestamp` | 需保留原始数据源的披露时间戳，避免引用过期的临时公告数据 |
| `citation_link_enabled` | `开启` | 满足合规性要求，为分析结果提供可追溯的原始依据 |
| `timeout_threshold` | `900 秒` | 农化财报的解析涉及多表格与专属字段提取，需要更长的解析超时时间以保证完整解析 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：回复内容中出现冗余的知识库引用链接，或无法关闭引用链接展示。原因：未正确配置`citation_link_enabled`参数，或未将`source_citation_mode`设置为仅展示文本，将其设置为完整链接。
- 现象：召回结果中未包含农化专属的产能、产品销量数据。原因：未在`rag_source_filter`中加入行业协会报告数据源，或`recall_top_k`的取值设置过低，无法覆盖细分字段的相关内容。
- 现象：配置变量引用规则后，温度调节按钮消失，无法调整生成温度。原因：未开启高级参数配置开关，或未单独配置`llm_temperature`的变量映射规则，导致变量引用模式下锁定了默认参数。

## 怎么确认配好了
- 上传一份目标农化公司的年度财报文档，查看解析后的字段是否包含产品销量、产能利用率等专属内容。
- 发起一次针对农化产品营收的分析查询，检查返回结果中是否附带了原始数据源的披露时间和访问路径。
- 测试触发变量引用功能，确认可以通过配置项调整`llm_temperature`的取值，且温度调节按钮未消失。
- 查看召回结果列表，确认包含交易所公告、行业协会报告等预设的数据源类型。
