# 农化制品财报分析的部署与升级

## 这个品类的数据长什么样
农化制品财报数据主要来源于上市公司公开披露的年度、半年度、季度报告，以及行业协会发布的月度农化产品供需数据、原料价格指数。更新节奏分为两类：定期财报按季度、半年度、年度披露，行业数据按月更新。文档结构包含财务报表合并页、主营业务构成（农药、化肥、植保助剂等细分品类营收占比）、产能与产量明细、原材料采购成本占比、研发投入明细等章节；行业数据文档多为结构化表格形式，包含产品名称、当期价格、产能利用率等字段。字段单位以万元、亿元为统计营收，以万吨、千吨为统计产能与产量，以元/吨为统计产品价格。

## 这些特征在「部署与升级」这一环带来什么约束
农化财报数据的多源混合特性要求部署时支持多格式解析，需配置自定义解析服务适配PDF财报与结构化行业表格文档。不同数据源的更新频率差异，需要为定期财报与行业数据分别设置差异化的定时同步周期。农化财报包含大量细分业务字段，向量数据库召回时需适配多维度检索，避免遗漏关键业务信息。单份完整年度财报PDF页数超100，解析时需要更长的超时时间与更大的文件上传限制，防止解析中断。部分财报存在单位混用情况，升级时需配置数据清洗规则统一字段单位，保证后续分析的准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `CUSTOM_PARSE_SERVICE_URL` | `http://your-custom-parse-ip:3001` | 农化财报PDF包含多格式表格与长文本，官方默认解析服务适配性不足，需部署自定义解析服务 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 单份完整农化年度财报PDF页数超100，常规超时时间无法完成完整解析 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 完整财报PDF与配套行业数据文档的总大小通常超出默认限制 |
| `chunkSize` | `1200–1500 字符` | 农化财报细分业务段落较长，需增大分段长度保留完整语义单元 |
| `topN` | `前 8–10 条` | 农化财报包含多细分业务维度，需召回足够数量的相关段落覆盖业务细节 |
| `similarityThreshold` | `0.78–0.85` | 农化行业术语专业性强，需提高阈值过滤低相关的通用财报内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：自定义PDF解析服务无法接入，上传农化财报后显示解析失败，日志返回`504 Gateway Timeout`。原因：未正确配置`CUSTOM_PARSE_SERVICE_URL`参数，或自定义解析服务端口未开放公网访问权限。
- 现象：部署的FastGPT实例扫描出CVE-2024-46982漏洞，提示NextJS版本为14.2.5。原因：未及时升级到修复该漏洞的FastGPT版本，未更新依赖包版本。
- 现象：知识库检索测试页面无编辑入口，无法调整召回参数。原因：误将检索测试页作为参数配置入口，需进入对应知识库的内容管理页面调整配置。

## 怎么确认配好了
- 上传一份单份农化年度财报PDF，等待解析完成后查看解析后的文本是否包含完整的细分业务营收数据，确认解析服务正常运行。
- 执行一次预设的定时同步任务，检查行业数据文档是否按配置周期自动更新到知识库中，确认同步配置生效。
- 进入对应知识库的参数配置页面，调整相似度阈值与召回条数参数后发起检索测试，验证召回结果的相关性与数量符合业务需求。
- 查看实例的系统日志，确认无文件大小限制相关的报错信息，确认上传配置正常。
