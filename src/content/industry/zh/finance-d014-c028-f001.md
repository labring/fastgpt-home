# 动力煤财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
动力煤财报相关数据来源包括国内煤炭行业协会月度供需报告、动力煤上市企业季度/年度财报、国家能源局行业监测数据。更新节奏分为两类：行业监测数据为月度更新，企业财报为季度、年度披露。文档结构上，行业报告包含供需规模、价格区间、库存水平、政策导向四个模块；企业财报包含合并财务报表及动力煤业务营收占比专项说明。字段与单位存在差异：行业数据多使用元/吨、万吨、万吨/日，财报数据多使用万元、亿元，需针对单位差异做统一处理。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
动力煤财报数据的多源分散特征，要求外部系统对接多个独立HTTP接口，需配置多数据源的身份验证与权限规则。不同数据的更新节奏差异，要求接口调度需区分定时触发与事件触发两种模式，避免无效调用。字段与单位的不统一，要求接口返回数据需经过格式转换才能适配下游分析逻辑。单份财报文档篇幅较长，要求接口的文件解析模块需支持长文本分段处理，避免解析超时或内容截断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `CRON_EXPRESSION` | `0 0 2 * * *`（每日凌晨2点） | 适配动力煤行业月度数据的每日同步需求，避开业务高峰时段 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 单份动力煤财报文档篇幅较长，需预留充足的解析时间 |
| `FIELD_UNIT_CONVERT_ENABLE` | `开启` | 动力煤数据包含元/吨、万吨、万元等多类单位，需开启自动转换以统一格式 |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 单份年度财报文档体积通常不超过该阈值，避免接口传输超时 |
| `SYNC_DATA_BATCH_SIZE` | `10 条` | 适配财报数据的批量拉取节奏，避免接口请求过载 |
| `RESPONSE_FIELD_FILTER` | 保留动力煤业务相关字段 | 过滤非核心字段，简化外部系统对接的字段处理逻辑 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用外部财报接口返回401未授权错误，无法获取数据。原因：未正确配置接口身份令牌的过期刷新逻辑，令牌过期后未自动更新，导致接口调用失败。
- 批量拉取财报数据时，部分核心字段为空。原因：未配置`RESPONSE_FIELD_FILTER`的精准过滤规则，误过滤了动力煤业务相关的关键字段。
- 接口调用返回504网关超时错误。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`的配置值，默认超时时间不足以解析长篇幅的动力煤财报文档。

## 怎么确认配好了
- 调用配置好的外部接口，查看返回的字段是否包含动力煤业务相关的核心数据，确认字段映射与单位转换生效。
- 查看定时任务日志，确认接口在配置的时间点自动触发同步，无失败记录。
- 上传单份动力煤财报文档至接口，确认解析后的分段内容完整，无截断或丢失。
- 测试身份令牌的过期场景，确认系统自动触发令牌刷新后，接口调用恢复正常。
