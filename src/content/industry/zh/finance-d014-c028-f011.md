# 动力煤财报分析的文档解析与分块

## 这个品类的数据长什么样
动力煤财报的数据来源包括煤炭行业协会月度供需报告、上市煤企季度年报、港口交割数据及期货交易所公告。更新节奏分为月度、季度与年度三类，月度数据于次月中下旬发布，季度数据于季后15个工作日内公开，年度财报需于次年4月底前完成披露。文档结构包含结构化表格与非结构化分析段落，字段涵盖动力煤热值（单位为大卡/千克）、平仓价格（单位为元/吨）、港口库存（单位为万吨）、铁路运输量等，部分文档还包含行业政策解读与市场预判内容。

## 这些特征在「文档解析与分块」这一环带来什么约束
动力煤财报的多来源、混合格式与特定字段特征，对文档解析与分块环节带来多重约束。首先，多来源的文档格式差异要求解析环节需适配PDF、Word、Excel、CSV等多种文件类型，避免格式不支持导致解析失败。其次，高频更新的文件量要求分块流程支持批量处理，且需控制单文件解析耗时以适配月度批量上传需求。再者，带特定单位的结构化字段需保留关联关系，避免拆分后导致数据语义丢失，同时需区分长段分析与紧凑表格的分块粒度，平衡上下文完整性与后续检索效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_TABLE_ENABLE` | 开启 | 动力煤财报包含大量结构化价格、库存与供需表格，保留表格结构可避免核心数据被拆分 |
| `分段长度` | 800–1200 字符 | 平衡长段分析文本的上下文完整性与结构化表格的分块粒度，适配动力煤财报的混合内容结构 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 适配大型季度财报PDF的多页图表、表格解析耗时，避免中途中断 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 覆盖大型年度财报与批量上传的文件大小需求，避免上传被拦截 |
| `UPLOAD_FILE_ALLOWED_EXTENSIONS` | ["pdf", "docx", "xlsx", "csv"] | 覆盖动力煤财报的常见发布格式，包括上市公司年报、行业协会报告、交易数据文件 |
| `SIMILARITY_THRESHOLD` | 0.75 | 区分动力煤财报中易混淆的热值、价格字段关联度，避免分块时引入无关内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传动力煤财报Excel文件后，解析节点显示未工作，后台日志返回`413 Request Entity Too Large`错误。原因：未调整`UPLOAD_FILE_MAX_SIZE`配置项，默认值过小无法容纳大型季度财报文件。
- 现象：解析后的分块内容中，动力煤平仓价格数据与对应5500大卡热值单位被拆分到不同块中。原因：`分段长度`设置过短，将包含单位关联的完整字段拆分为两段，破坏数据语义完整性。
- 现象：仅抓取到动力煤财报中部分港口库存数据，其余行业供需字段为空。原因：未开启`PARSE_TABLE_ENABLE`配置，结构化表格的非首行数据未被正确识别，导致部分字段丢失。

## 怎么确认配好了
- 上传一份标准的动力煤月度财报Excel文件，查看解析后的数据表格是否完整保留了热值、价格、库存等字段的关联关系。
- 查看解析任务的后台日志，确认未出现超时错误或格式不支持的报错提示。
- 随机抽取一段分块内容，检查是否将包含单位的完整数据块作为独立单元，未出现拆分错误。
- 批量上传3份以上不同格式的动力煤财报文件，包括PDF年报、Word分析报告与CSV交易数据，确认所有文件均能正常完成解析与分块流程。
