# 包装印刷财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
包装印刷企业的财报数据主要来自境内外证券交易所公开披露的定期报告、企业官方发布的年度/半年度/月度经营简报，供金融、保险、理财领域的分析场景使用。更新节奏以固定报告期为主，年度报告每年更新一次，半年度报告每半年更新一次，部分头部企业会同步发布月度生产经营数据。文档结构包含企业整体营收、细分板块营收（如包装材料、标签印刷、礼盒定制）、原材料采购成本占比、产能利用率、单位产品能耗、单客平均收入等字段，字段单位分别为万元、吨、千瓦时/吨等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
由于财报数据按固定报告期更新，外部接口需要支持按报告期参数精准拉取数据，避免拉取冗余或过期信息。由于包含细分板块营收、单位能耗等专属业务字段，接口返回的字段需支持灵活筛选，否则会传输大量非必要数据，增加传输成本。由于存在多维度的业务指标，外部系统对接时需兼容多字段的批量拉取，同时需要明确的字段单位映射，避免数据分析时出现单位混淆。另外，部分包装印刷企业的月度经营数据接口存在调用频次限制，需合理配置同步节奏，避免触发限流。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `SYNC_DATA_INTERVAL` | 3600–86400 秒 | 适配包装印刷财报按报告期更新的频率，平衡数据新鲜度与接口调用成本 |
| `API_REQUEST_TIMEOUT` | 30–60 秒 | 包装印刷财报数据接口可能包含多板块细分字段，较长超时可避免拉取不完整 |
| `FIELD_FILTER_ENABLE` | 开启 | 允许指定返回字段，适配包装印刷财报特有的纸浆采购成本、产能吨数等专属字段 |
| `RESPONSE_FIELD_WHITELIST` | 营收总额,包装材料营收,印刷服务营收,产能利用率,单位能耗 | 过滤非必要字段，减少数据传输量，聚焦核心分析指标 |
| `AUTH_TYPE` | API_KEY 鉴权 | 适配多数公开财报数据源的鉴权方式，避免频繁令牌刷新导致的连接中断 |
| `MAX_BATCH_SIZE` | 50 条 | 适配单批次拉取的财报数据量，避免接口返回过载导致的同步失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：WEB界面调用外部财报接口返回503 Service Unavailable，系统日志显示连接超时。原因：未配置静态地址映射，外部数据源容器重启后地址变更，未同步更新FastGPT的接口配置项，该问题在V4.8.20-FIX2版本的本地部署场景中较为常见。
- 现象：拉取的财报数据中包装印刷专属字段为空，无法提取产能利用率或单位能耗数据。原因：未开启`FIELD_FILTER_ENABLE`配置，或`RESPONSE_FIELD_WHITELIST`未包含对应专属字段。
- 现象：单次同步财报数据时触发`REQUEST_TIMEOUT`错误。原因：同步间隔设置过短，同时拉取了多个历史报告期的全量数据，超出`API_REQUEST_TIMEOUT`的阈值限制。

## 怎么确认配好了
- 执行FastGPT外部数据源的测试调用，查看返回结果是否包含包装印刷财报的专属字段，如产能利用率、单位能耗。
- 查看同步任务日志，确认数据按设定的`SYNC_DATA_INTERVAL`周期拉取，无频繁触发的调用记录。
- 在WEB界面的知识库搜索栏输入财报相关关键词，验证返回结果的字段单位与公开披露信息一致。
- 模拟外部数据源地址变更，验证配置的静态地址映射是否生效，避免后续连接失败。
