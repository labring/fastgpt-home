# 包装印刷财报分析的多轮对话与提示词

## 这个品类的数据长什么样
包装印刷行业的财报数据主要来自上市公司公开披露的定期报告，按季度、年度周期更新，披露时点符合监管要求。文档多为PDF格式，结构包含经营情况讨论与分析、合并财务报表及附注。核心字段涵盖营业收入、营业成本、毛利率，以及包装印刷特有的产能利用率、原材料采购量、单批次印刷成本等，字段单位多采用人民币万元、产能吨数、印刷万张等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
包装印刷财报文档篇幅较长，且包含通用财务字段与行业专属字段，多轮对话环节需适配长上下文输入，避免因上下文截断丢失关键数据。行业特有的产能、原材料采购量等字段，要求提示词明确区分通用财务指标与包装印刷业务指标，防止模型混淆。财报按固定周期更新，多轮对话需保留当前财报的披露周期信息，避免跨周期调用数据。部分字段存在单位差异，提示词需统一要求数据标注单位，或明确指定输出单位，防止出现单位混乱的结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 包装印刷单份财报解析后文本多在5000-10000字符，适配多轮对话的上下文留存需求 |
| `json_schema` | `包含行业专属字段校验规则` | 包装印刷财报存在产能、原材料采购量等特有字段，需校验输出格式合规 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 长财报文档解析耗时较长，避免因超时中断数据加载 |
| `retrieval_top_k` | `前 5–7 条` | 包装印刷财报字段多且分散，召回适量条目覆盖核心业务与财务指标 |
| `similarity_threshold` | `0.75–0.85` | 过滤低相关的通用财务问答，聚焦包装印刷专属业务数据 |
| `system_prompt_template` | `明确标注财报周期与单位要求，调用平台内置时间变量` | 包装印刷财报需明确披露周期，统一单位要求，内置时间变量可确保落款时间准确合规 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置`json_schema`后模型输出出现字段缺失，无法匹配包装印刷财报的特有指标。原因：未在schema中加入产能、原材料采购量等专属字段的校验规则，导致模型无法生成符合要求的内容。
- 现象：重新打开历史对话时，自动回复内容为空，无法加载之前的对话上下文。原因：未开启`auto_save_chat_history`配置，或保存范围仅覆盖单轮对话未保留多轮交互数据。
- 现象：工作流模式下的财报分析任务耗时明显长于单独调试环节。原因：未调整`maxContext`适配长财报文档，或召回条数设置过高，导致大量冗余数据被加载处理。

## 怎么确认配好了
- 上传一份包装印刷财报文档，发起包含通用财务与行业专属字段的连续提问，检查多轮对话的上下文是否被正确保留。
- 配置`json_schema`后，发起包含包装印刷特有指标的提问，验证输出格式是否符合预设的校验规则。
- 查看对话历史记录，确认每一轮的回复内容都被完整保存，无缺失或清空情况。
- 发起包含时间变量的提示词测试，检查落款时间是否自动匹配平台当前日期，无固定错误值。
