# 包装印刷财报分析的工具调用与插件

## 这个品类的数据长什么样
包装印刷企业的财报数据主要来自公开披露的定期报告，包括年度、半年度及季度报告，行业配套数据来自轻工制造行业协会的公开统计。财报文档以结构化表格为主，辅以文字附注说明。核心字段包含主营业务收入（包装印刷板块）、原材料采购成本、固定资产（印刷设备原值）、存货（纸浆、油墨等）、产能规模及运营相关明细。数据更新节奏与公开披露周期一致，定期报告按自然年度、半年度、季度节点更新，行业统计数据按月度更新。字段单位涵盖人民币元、吨、平方米、台等，不同企业披露的字段口径存在差异。

## 这些特征在「工具调用与插件」这一环带来什么约束
包装印刷财报的多口径披露、多单位字段及非标准化格式，会对工具调用与插件的配置和运行产生多重约束。不同企业披露的包装印刷业务字段存在口径差异，插件需要支持自定义字段映射规则，避免匹配失效。财报中的结构化表格内容较多，插件需要适配多格式表格解析，防止字段错位或内容截断。行业配套数据按月度更新，工具调用的数据源同步频率需匹配该节奏，避免使用过时数据。多单位字段的存在，要求插件内置单位校验与自动转换逻辑，保障后续计算的准确性。定期报告的固定披露周期，允许工具调用绑定触发节点，但需兼容临时补充公告的实时更新。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_TABLE_MAX_COLUMNS` | `20 列` | 包装印刷财报的业务表格多包含10至15个核心字段，预留冗余可适配不同企业的披露格式 |
| `TOOL_DATA_SYNC_INTERVAL` | `7200 秒` | 包装印刷行业配套数据按月更新，该间隔可兼顾数据时效性与系统资源占用 |
| `PLUGIN_CUSTOM_FIELD_MAPPING` | `开启` | 包装印刷企业财报披露口径不统一，开启自定义映射可适配多来源的业务数据 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 包装印刷财报包含多页结构化表格与附注，较长超时时间可保障完整解析 |
| `TOOL_CALL_MAX_RETRIES` | `3 次` | 字段匹配失败或数据源临时不可用时，有限重试可降低工具调用失败率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：点击插件触发按钮无响应，界面返回`400 Bad Request`错误。原因：未配置`PLUGIN_CUSTOM_FIELD_MAPPING`，插件无法匹配包装印刷财报的非标准化业务字段，导致请求参数缺失。
- 现象：OneAPI日志显示凌晨时段频繁触发工具调用，导致余额超额消耗。原因：未设置`TOOL_DATA_SYNC_INTERVAL`的时段过滤规则，系统按固定间隔自动同步数据，夜间同步任务未被屏蔽。
- 现象：单轮对话中仅首次触发插件提示，后续提问无法唤起插件选择界面。原因：开启了`PLUGIN_SINGLE_TRIGGER_PER_CONVERSATION`参数，默认限制插件仅在单轮对话中生效一次。
