# 化学制药财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
化学制药行业财报数据主要来自境内外证券交易所公开披露平台、上市药企投资者关系官网。更新节奏以季度报、年度报告为主，伴随临时业绩快报、重大事项公告同步更新。文档结构包含合并资产负债表、利润表、现金流量表，以及研发投入明细、原料药产能与成本、专利资产账面值等专项板块。字段包含研发资本化支出、单批次原料药生产成本、管线项目累计投入金额，单位多为万元或亿元，部分跨境披露数据会附带汇率换算字段。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
化学制药财报的多源分散特性，要求HTTP接口支持对接证券交易所、药企IR官网等多个数据源，需配置多源数据聚合逻辑。定期更新的属性要求接口设置定时拉取任务，避免缓存数据与最新财报不同步。专项细分字段如研发资本化支出、原料药单位成本，需在接口请求中指定对应报表模块参数，否则返回的通用财报数据无法覆盖分析需求。部分境外披露平台的接口存在访问频率限制，需配置请求节流规则，同时需适配不同数据源的单位换算逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `request_timeout` | `600 秒` | 化学制药财报接口返回内容包含多模块明细，避免因超时中断数据拉取 |
| `batch_request_interval` | `10 秒` | 适配境外证券交易所披露接口的访问频率限制 |
| `required_query_params` | `{"module": "rnd_and_cost", "unit": "ten_thousand_cny"}` | 精准获取研发与成本模块数据，统一金额单位为万元人民币 |
| `max_response_size` | `2000 KB` | 覆盖单份季度报的完整接口返回内容 |
| `retry_max_times` | `3 次` | 应对接口临时波动导致的请求失败 |
| `authentication_type` | `api_key` | 匹配多数公开披露平台的鉴权规则 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：界面显示的召回数据条数与实际传入下游接口的条数不符。原因：未正确配置响应大小或字段过滤参数，导致数据截断与实际拉取量不匹配。
- 现象：接口请求频繁触发`429 Too Many Requests`报错。原因：未设置请求间隔参数，请求频率超出境外披露平台的访问限制阈值。
- 现象：接口调用返回`401 Unauthorized`错误，确认鉴权参数配置无误。原因：未适配对应数据源的鉴权格式，部分境外平台要求在请求头中携带特定前缀的认证信息。

## 怎么确认配好了
- 发起单次测试请求，核对返回数据中是否包含预设的细分业务字段。
- 模拟定时拉取流程，检查接口返回数据的更新时间与对应数据源的最新披露时间是否匹配。
- 发起连续多次请求，确认未触发访问限制类报错，验证节流配置的有效性。
- 查看接口返回的完整内容，确认未被无故截断，匹配配置的响应大小限制。
