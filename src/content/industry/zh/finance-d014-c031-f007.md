# 化学制药财报分析的工作流编排

## 这个品类的数据长什么样
化学制药财报数据主要来自境内外证券交易所披露的定期报告、药企官方披露的研发管线公告及财务补充文件。更新节奏遵循监管要求，季度报告于季度结束后1-2个月内发布，年度报告于年度结束后4个月内发布。文档结构包含合并财务报表、管理层讨论与分析、研发投入明细、管线进展披露等模块。字段包含研发投入金额、临床管线数量、专利申请量等，单位多为万元、亿元，临床阶段以罗马数字标注阶段等级。

## 这些特征在「工作流编排」这一环带来什么约束
数据来源分散的特征要求工作流配置多源数据拉取节点，对接交易所披露平台与药企官方公告接口。固定更新节奏要求工作流绑定定时触发规则，按季度或年度触发全量分析任务。单份文档篇幅较长的特征，要求工作流配置分段解析参数，控制单段文本长度，避免模型上下文溢出。特殊字段与标注规则，要求信息抽取节点配置自定义实体抽取模板，匹配临床阶段罗马数字、研发投入金额等专属字段。数据关联需求要求工作流加入跨模块数据绑定节点，整合财务数据与管线披露信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 化学制药财报单段解析文本较长，需适配长上下文处理需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 财报文档篇幅较大，解析耗时较长，避免任务超时中断 |
| `custom_entity_schema` | `配置临床阶段、研发投入金额、管线数量模板` | 化学制药财报包含专属实体字段，需自定义抽取规则匹配专属信息 |
| `schedule_trigger_cron` | `0 0 2 1-10 1,4,7,10 *` | 匹配财报季度披露周期，按季度定时触发全量分析任务 |
| `global_variable_scope` | `按用户ID隔离` | 不同使用者需独立访问专属分析结果，避免全局变量值冲突 |
| `custom_guide_prompt` | `预设财报分析引导语模板` | 生成贴合化学制药场景的专属引导语，替代默认配置 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用工作流API时返回结果无上下文关联，日志显示`context_mismatch`错误码。原因：未在API请求参数中传入`user_id`字段，导致工作流无法关联对应会话的上下文配置。
- 现象：工作流无法加载历史会话保存的全局变量，界面弹出`variable_unavailable`提示。原因：未开启`global_variable_scope`的用户隔离配置，或未在历史会话中完成目标全局变量的持久化存储。
- 现象：AI生成财报分析结果后，仅展示系统默认的猜你想问条目，未展示自定义引导语。原因：未启用`custom_guide_prompt`配置，或引导语模板未针对化学制药财报场景进行适配。

## 怎么确认配好了
- 发起一次测试调用，传入预设`user_id`参数，核对返回结果是否关联对应会话的上下文信息。
- 手动触发一次解析任务，查看执行日志，确认任务耗时未超出配置的超时阈值。
- 切换不同测试账号执行任务，核对同名全局变量的存储值是否独立，互不覆盖。
- 查看分析结果页，确认展示的引导语内容与预设的化学制药财报分析模板一致。
