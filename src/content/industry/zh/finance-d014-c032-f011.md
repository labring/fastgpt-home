# 化学原料财报分析的文档解析与分块

## 这个品类的数据长什么样
化学原料品类的财报数据主要来源于境内外上市公司公开披露的年度、季度报告，以及行业协会发布的月度经营数据。更新节奏为年度报告每年披露一次，季度报告每季度披露一次，行业数据按月更新。文档多为PDF格式，包含结构化财务表格、非结构化的经营分析段落，字段涵盖产能、产量、原材料采购额、产品营收等，单位多为吨、千克、万元等。部分文档还包含跨页的产品明细表格与附注条目。

## 这些特征在「文档解析与分块」这一环带来什么约束
化学原料品类的文档混合结构化表格与非结构化段落，要求解析流程需精准识别表格边界，避免跨页表格被错误拆分。品类内产品明细条目多且细碎，分块时需保留产品与对应财务数据的关联，不能割裂上下文关联。月度更新的行业数据导致文档批次多，解析流程需兼容不同格式的行业报告模板。部分财报附注存在嵌套的明细条目，分块时需保留层级关系，保障后续检索的信息完整性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_TABLE_ENABLE` | 开启 | 化学原料财报包含大量产品产能、营收的结构化表格，开启后可保留表格结构完整性 |
| `CHUNK_SIZE` | 800–1200 字符 | 化学原料财报的产品明细段落多为中等长度，该区间可保留单产品的完整经营与财务关联信息 |
| `CHUNK_OVERLAP` | 100–150 字符 | 避免跨分块的产品关联信息被割裂，保障上下文连贯性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 单份年度财报PDF页数较多，且包含大量表格解析，需预留足够处理时间 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 部分行业报告包含多期历史数据，文件体积较大，需适配上传限制 |
| `PARSE_NESTED_TABLE` | 开启 | 化学原料财报附注存在嵌套的产品明细表格，开启后可完整提取嵌套层级信息 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传多份行业月度报告后，向量化处理耗时显著增加。原因：未调整`CHUNK_SIZE`与`CHUNK_OVERLAP`参数，分块过细导致分块数量激增，拖慢后续向量化流程。
- 现象：发起非文档类提问后，系统触发了文档解析流程。原因：未正确配置`QUESTION_TRIGGER_PARSE`参数，导致所有提问均触发文档解析逻辑。
- 现象：上传财报PDF后，数据处理步骤完成后知识库搜索结果为空。原因：未开启`PARSE_TABLE_ENABLE`参数，结构化表格内容未被提取，导致有效分块缺失。

## 怎么确认配好了
- 上传单份100页以上的化学原料财报PDF，查看解析日志中的表格提取条目数量，验证`PARSE_TABLE_ENABLE`与`PARSE_NESTED_TABLE`参数的生效状态。
- 随机抽取一份已解析的文档，查看分块内容是否包含完整的产品名称与对应财务数据，验证`CHUNK_SIZE`与`CHUNK_OVERLAP`的合理性。
- 发起非文档类提问，确认系统未触发文档解析流程，验证`QUESTION_TRIGGER_PARSE`参数的配置正确性。
- 上传接近最大限制体积的测试文件，确认上传与解析流程未触发超时错误，验证`PARSE_FILE_TIMEOUT_SECONDS`与`UPLOAD_FILE_MAX_SIZE`的适配性。
