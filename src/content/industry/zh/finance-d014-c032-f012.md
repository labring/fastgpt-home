# 化学原料财报分析的模型接入与配置

## 这个品类的数据长什么样
化学原料品类的财报数据主要来自上市公司年度/季度报告、交易所公开公告及行业协会月度监测数据。更新节奏分为固定周期：年度报告次年4月前披露，季度报告季后15日内披露，临时公告随经营异动实时发布。文档结构包含标准化财务报表模块、产能/销量/原材料成本等经营数据模块、行业对比分析模块，字段多带明确单位，如万吨、元/吨、万元，无大量嵌套的复杂非结构化文本块。

## 这些特征在「模型接入与配置」这一环带来什么约束
固定披露周期的财报数据要求模型接入配置支持定时触发与临时触发两种模式，适配常规报告与突发经营公告的不同更新节奏。多字段绑定明确单位的经营数据，要求配置中开启字段与单位的关联校验，避免解析后单位丢失或混淆。文档结构以结构化模块为主的特征，可简化分段规则，但需针对财务报表与经营数据模块设置差异化的字段提取精度。实时发布的临时公告，要求配置的超时阈值需匹配快速响应需求，避免因等待过久导致数据延迟。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–16000 字符` | 化学原料单份季度财报核心数据约5000-12000字符，需完整加载关键模块 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | 结构化财报文档解析无需复杂处理，120秒可覆盖常规加载与字段提取流程 |
| `RECALL_TOP_N` | `前6–10 条` | 化学原料财报核心经营字段约5-8个，召回过多会引入无关数据干扰产能、成本等关键分析 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 需精准匹配财务字段与经营数据的关联关系，避免低相似度的无关字段被召回 |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 单份年度财报PDF通常不超过30 MB，预留冗余空间应对多文档批量上传 |
| `MODEL_CONTEXT_WINDOW` | 按模型实际上限设置 | 需匹配大模型自身的上下文承载能力，避免超出限制导致解析中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：大模型节点返回`500 Gateway forwarding error because service is disconnected`。原因：未配置模型接入的超时重连机制，或模型服务实例意外下线导致连接中断。
- 现象：模型解析后的财报字段丢失单位信息。原因：未开启字段与单位的关联校验配置，导致解析过程中剥离了字段绑定的单位数据。
- 现象：模型厂商图标加载失败，界面显示空白占位。原因：未配置正确的模型厂商标识映射，或网络访问限制导致图标资源无法正常加载。

## 怎么确认配好了
- 上传单份季度财报文档，检查解析后的字段是否完整保留单位信息，核对配置的上下文长度是否覆盖文档核心内容。
- 触发定时任务模拟常规财报更新流程，检查节点是否按预设周期自动触发解析，确认超时阈值匹配文档加载时长。
- 上传多份财报文档批量测试，检查召回的字段数量符合配置范围，无无关数据混入。
- 模拟模型服务临时下线再恢复，检查节点是否自动重连并恢复正常解析，验证重连配置是否生效。
