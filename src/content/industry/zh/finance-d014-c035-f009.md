# 医美财报分析的引用来源与溯源

## 这个品类的数据长什么样
医美财报数据主要来自医美机构自主披露的季度/年度审计报告、属地卫生健康与市场监管部门的医美机构经营公示数据、上游医美耗材与设备供应商的供货台账。数据更新节奏随披露周期调整，机构年度审计报告每年更新1次，季度经营数据每季度更新，监管公示数据每月更新。文档结构通常包含营收分类、单客消费额、获客成本、耗材采购成本、合规记录等字段，单位多为人民币元、人次、万元。

## 这些特征在「引用来源与溯源」这一环带来什么约束
医美财报数据来源分散，涵盖机构内部报表、外部监管公示、上游供应商台账三类，要求溯源功能支持多源数据的关联标记。不同来源数据更新节奏差异明显，季度审计报告与月度监管数据需分别匹配对应时间范围的溯源标记。医美财报包含合规整改记录等敏感字段，溯源时需同步标注数据来源的合规资质。不同来源文档格式差异较大，包括PDF审计报告、网页公示、Excel台账，需适配不同格式的溯源跳转链接。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | 前8–12条 | 医美财报单份文档块数较多，需覆盖足够多的关联数据块 |
| `相似度阈值` | 0.72–0.85 | 医美财报字段专业性强，需过滤低匹配度的无关数据 |
| `引用来源展示开关` | 按需开启 | 符合医美行业合规披露的溯源要求，支持用户自主选择是否展示 |
| `重排返回条数` | 前3–5条 | 优先展示与财报核心指标关联度最高的来源，避免信息过载 |
| `分段长度` | 1000–1500 字符 | 医美财报包含长段落的合规说明，需适配长文本块的溯源关联 |
| `源文件跳转配置` | 保留原文件路径 | 适配审计报告、监管公示等不同格式的原始披露链接 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：对话时展示的引用来源为空，原因：未开启`引用来源展示开关`配置项，或未正确关联源文件至对应知识库。
- 现象：对话时强制展示引用来源无法关闭，原因：配置时误将`引用来源展示开关`设置为固定开启状态，未保留可选关闭的配置项。
- 现象：引用溯源链接无法正常跳转，原因：`源文件跳转配置`未匹配原始披露页面的URL格式，或源文件路径配置有误。

## 怎么确认配好了
- 进入目标知识库的配置页面，查看`引用来源展示开关`的当前状态是否符合需求。
- 发起包含医美财报核心指标的测试提问，检查返回结果中展示的引用来源条数是否与`召回条数`的配置值一致。
- 点击返回结果中的引用来源链接，确认可跳转至原始披露页面或对应源文件。
- 查看知识库的`分段长度`配置，确认取值与医美财报文档的平均段落长度匹配。
