# 半导体财报分析的工作流编排

## 这个品类的数据长什么样
半导体财报数据来源包括证券交易所公开披露的定期报告、行业公开统计文档。更新节奏为季度报告每季度结束后1至2个月发布，年度报告于次年第一季度内发布，临时公告随重大事项同步更新。文档结构包含业务板块营收、研发投入金额、晶圆出货规模、单位产品售价、存货周转周期等字段，单位分别为人民币或美元、万元、万片、美元/片、天数。

## 这些特征在「工作流编排」这一环带来什么约束
数据来源分散，需在工作流中配置多源数据拉取节点，分别对接交易所披露接口与行业统计渠道。更新节奏差异大，需设置多组定时触发规则区分季度、年度与临时公告的拉取周期。单文档篇幅较长，需调整解析与分段参数适配长文本内容。行业专属字段与单位较多，需在数据清洗节点完成单位标准化与字段映射，避免分析偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ------ | -------- | ------------ |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 半导体年度财报单文档页数较多，解析耗时较长 |
| `maxChunkSize` | `1000–1500 字符` | 适配财报中长句和专业术语，平衡语义完整性与召回精度 |
| `RECALL_TOP_K` | `前 8–12 条` | 财报分析需覆盖多维度字段，需召回足够数量的相关片段 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 区分专业术语与通用词汇的匹配度，过滤无关召回内容 |
| `GLOBAL_VAR_DATA_TYPE` | 按变量用途标定 | 营收类变量用数字类型，企业标识类用文本类型，知识库关联类用枚举类型 |
| `WORKFLOW_TRIGGER_CRON` | `0 0 2 * * 1`（每周一凌晨2点） | 适配季度财报的常规更新节奏，避开业务高峰时段 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：自定义知识库选择的全局变量在运行时无法关联指定知识库。原因：未正确设置变量数据类型，未绑定知识库ID的可选值范围。
- 现象：工作流解析半导体财报文档时触发`408 Request Timeout`错误。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认取值不足以解析长篇幅文档。
- 现象：工作流输出的营收数据与公开披露值存在偏差。原因：未在数据清洗节点完成单位统一，未对不同币种的营收数据做标准化转换。

## 怎么确认配好了
- 手动上传一份半导体行业财报PDF，检查解析后的文本分段是否符合预期，调整`maxChunkSize`参数至适配文档内容。
- 触发一次工作流并传入用户唯一标识，查看工作流日志是否包含该标识，确认日志关联功能正常。
- 运行工作流并输入财报相关查询，检查召回的相关片段数量是否符合预设的`RECALL_TOP_K`设置。
- 验证自定义全局变量的可选值是否包含所需的半导体行业知识库，确认变量绑定正确。
