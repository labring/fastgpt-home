# 卫星通信财报分析的模型接入与配置

## 这个品类的数据长什么样
卫星通信财报数据主要来自上市卫星运营企业的公开披露报告、行业监管机构发布的运营统计文件。更新节奏以季度财报、年度年报为核心周期，临时运营调整公告不定期发布。文档结构包含核心经营数据模块，字段涵盖卫星转发器租赁收入、带宽服务费、运维成本、频段使用费、在网卫星数量、可用带宽总量等，收入类字段单位多为万元、亿元，带宽类单位为Mbps、GHz，用户规模类单位为万户。

## 这些特征在「模型接入与配置」这一环带来什么约束
卫星通信财报的高频更新与多专业字段特征，对模型接入配置带来多重约束。高频更新要求配置项支持动态调整调用频率，避免缓存过期导致数据滞后。多专业字段与混合单位的结构，要求模型配置中嵌入领域专属的格式校验规则，确保输出字段与财报结构对齐。长文档的存在，要求配置适配长上下文窗口的模型，或启用分段处理参数，避免截断关键经营数据。临时公告的不确定性，要求配置支持按需触发模型调用，固定周期执行难以覆盖突发数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–16000 字符` | 适配单份卫星通信财报文档的长文本长度，避免关键经营数据被截断 |
| `chunkSize` | `1000–1500 字符` | 拆分财报文档时保留专业字段完整性，避免跨段截断转发器租赁、频段使用费等核心字段 |
| `callFrequencyLimit` | `10 次/分钟` | 匹配财报高频更新的节奏，平衡模型调用效率与服务稳定性 |
| `systemPrompt` | `嵌入卫星通信财报专业字段校验规则，要求输出对齐文档字段结构与单位` | 适配专业数据格式要求，避免输出与实际财报字段不符的结果 |
| `modelId` | `支持长上下文与专业领域适配的大模型` | 处理长文档与专业术语，提升财报分析的准确性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 适配长财报文档的解析耗时，避免因解析超时导致任务失败 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置第三方模型后发起请求返回405状态码。原因：未正确配置模型的API访问密钥或请求头参数，导致接口拒绝调用请求。
- 现象：fastgpt_v4.9.11版本接入qwen3-embedding-8b嵌入模型后，文件索引状态持续显示“索引中”。原因：嵌入模型的输入格式与平台要求不匹配，或索引任务的超时参数设置过短，导致解析进程未正常完成。
- 现象：工作流中无法找到模型ID的查看入口。原因：未进入对应模型节点的高级配置面板，导致隐藏的模型ID字段未在界面中展示。

## 怎么确认配好了
- 进入模型配置面板，核对`modelId`与所选模型的官方标识是否一致。
- 上传一份小型卫星通信财报文档，触发模型调用，检查返回结果是否包含财报核心字段且格式对齐。
- 查看系统日志，确认模型调用请求的返回状态码为200，无异常报错信息。
- 调整测试文档的长度，验证`maxContext`参数是否能适配长文本输入，无截断现象。
