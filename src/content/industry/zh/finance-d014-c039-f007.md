# 厨卫电器财报分析的工作流编排

## 这个品类的数据长什么样
厨卫电器企业的定期披露报告，包括季度报、半年报、年报，来源为证券交易所公开披露平台、企业投资者关系官网。更新节奏为季度报告每季度结束后1-2个月更新，年度报告于次年4月底前完成更新。文档结构包含整体营收、分产品线营收（油烟机、燃气灶、热水器等）、毛利率、销量、单位售价等模块，部分报告附带原材料成本占比、渠道销售占比等补充数据。营收字段单位多为万元，销量单位为台，单价单位为元/台，毛利率为百分比形式的数值字段。

## 这些特征在「工作流编排」这一环带来什么约束
季度级的更新节奏要求工作流需按固定季度周期触发，避免过度调用或错过最新数据。分产品线的细分字段要求工作流需设置专门的字段映射节点，区分不同厨卫电器品类的营收数据，避免字段混淆。公开披露的PDF格式文档要求工作流需配置适配表格提取的解析节点，处理不同排版的财报PDF。多字段的复杂结构要求工作流需增加数据校验节点，确保核心字段未缺失。合规性要求工作流需保留数据来源的溯源记录，避免后续分析的合规风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时调度触发周期` | `90 天` | 匹配厨卫电器企业季度财报的更新周期，确保每次运行获取最新数据 |
| `PDF解析分段长度` | `800–1200 字符` | 适配厨卫电器财报中营收表格的段落长度，避免表格被拆分导致识别失败 |
| `知识库召回条数` | `前 6 条` | 厨卫电器财报核心数据条目较少，该取值可覆盖全部关键信息且避免冗余 |
| `变量作用域` | `用户级` | 区分不同使用者的分析需求，避免全局变量导致的数据混淆 |
| `节点重试次数` | `3 次` | 应对PDF解析或知识库检索的偶发网络或格式错误，提升工作流稳定性 |
| `全局变量绑定` | `绑定 datasetid 到工作流上下文` | 确保知识库检索节点可正确引用预设的财报知识库ID |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流中配置的AI对话输出内容仍在前端展示。原因：未勾选`节点输出隐藏`的`仅内部使用`选项，导致输出内容被暴露给前端调用者。
- 现象：基于问题分类的工作流测试时，仅第一个问题触发知识库检索，后续问题无检索结果。原因：未在分类节点后重置`上下文缓存`，后续请求复用了首次检索的上下文，导致匹配逻辑失效。
- 现象：工作流中配置的全局变量`datasetid`无法被知识库检索节点引用。原因：未在全局变量配置中开启`工作流上下文可见`，或未在节点参数中正确绑定变量的引用路径。

## 怎么确认配好了
- 触发一次手动运行的工作流，查看执行日志，确认定时调度节点的触发时间符合预设的90天周期。
- 检查PDF解析节点的输出结果，确认分产品线的营收、毛利率等厨卫电器核心字段已被正确提取。
- 使用不同的测试用户ID调用工作流，检查用户级变量的取值是否独立生效，无跨用户数据混淆。
- 发起多轮不同的财报分析问题，确认每个问题都能触发知识库检索并返回对应结果。
