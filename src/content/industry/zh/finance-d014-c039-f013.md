# 厨卫电器财报分析的知识库检索与召回

## 这个品类的数据长什么样
厨卫电器品类的财报数据主要来自上市厨卫电器企业的年度、季度正式报告，以及行业第三方监测机构发布的月度出货数据。数据更新节奏为年度年报、季度季报固定更新，行业监测数据按月更新。文档多为结构化表格与段落结合，包含分品类营收、渠道占比、单位成本、出货量等字段，营收与出货量单位分别为万元与万台，毛利率以百分比标注。

## 这些特征在「知识库检索与召回」这一环带来什么约束
分品类营收、渠道占比等结构化字段多，要求检索时能精准匹配品类关键词与指标字段，避免召回无关的泛行业内容。不同数据源更新节奏差异大，需要配置增量更新任务区分财报与行业监测数据的同步周期，防止新旧数据混用。结构化表格中的单位字段需被识别，避免检索结果出现单位混淆。同时，财报内容合规性要求高，需确保召回数据来自官方公开渠道，排除非合规内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 厨卫财报单文件通常在10-50MB，解析时长较长，300秒可覆盖多数文件解析需求 |
| `chunk_size` | `800–1200 字符` | 财报包含长段落与结构化表格，该分段长度可保留指标与上下文关联，避免拆分破坏数据完整性 |
| `top_k` | `前 8 条` | 厨卫品类财报指标维度多，需召回足够数量的相关条目支撑分析，同时避免冗余 |
| `similarity_threshold` | `0.75–0.85` | 需过滤低相关性的行业泛内容，精准匹配财报中的具体品类指标 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单份年度财报PDF通常不超过50MB，预留足够空间应对批量上传场景 |
| `rerank_top_n` | `前 3 条` | 需对召回的条目做二次排序，聚焦最相关的核心财报数据，提升分析效率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：服务器每日固定时段出现磁盘读写峰值，触发资源耗尽告警。原因：未配置增量更新任务，每日全量重新生成向量库，导致磁盘IO与内存占用过载。
- 现象：后台删除知识库中的问答对后，检索结果仍保留对应内容。原因：未手动触发向量库同步刷新，旧向量数据未从索引中移除。
- 现象：上传财报文件时，任务卡在「1组索引」或「2组索引」阶段，无明确报错。原因：使用`m3e-large`模型时，未调整`batch_size`参数，单批次处理数据量超出模型承载上限。

## 怎么确认配好了
- 执行一次单份财报文件上传，查看解析日志中对应参数是否生效，无超时报错。
- 发起检索测试，输入指定品类指标关键词，核对召回结果的字段单位与原始文档一致。
- 配置增量更新任务后，查看同步日志，确认仅更新新增或修改的数据源，无全量重建操作。
- 测试权限控制功能，使用非授权账号发起检索，确认无法访问涉密财报数据。
