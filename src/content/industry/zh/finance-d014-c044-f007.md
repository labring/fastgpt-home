# 商业物业财报分析的工作流编排

## 这个品类的数据长什么样
商业物业财报的数据来源包括内部收费系统、能耗管理平台、商户签约档案与公共区域运维记录。更新节奏分为月度日常运营数据、季度汇总报表、年度正式财报三类。文档结构同时包含结构化的CSV/Excel收支明细表格，以及PDF格式的年度财报报告，报告内按收支类别拆分明细。字段包含应收租金总额、实收租金总额、公共区域能耗总费用、商户入驻面积、维修支出等，单位为元或平方米，无统一的百分比类统计项。

## 这些特征在「工作流编排」这一环带来什么约束
商业物业财报的数据多源且格式混杂，要求工作流必须配置格式适配节点，完成结构化表格与非结构化PDF文档的统一解析。不同周期的财报数据要求工作流支持按月度、季度、年度的定时触发配置，避免数据汇总周期错位。多字段的单位差异要求工作流增加单位校验环节，防止不同维度数据的数值混淆。单个项目的财报数据独立且维度固定，要求工作流支持按项目预设变量，避免跨项目数据串用。大型物业项目的财报数据量较大，要求工作流节点配置合理的超时阈值，防止解析过程中断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 适配商业物业财报多表汇总、格式解析的耗时需求，避免大型项目数据解析中断 |
| `表单输入字段配置` | `应收租金总额`、`实收租金总额`、`公共区域能耗支出` | 匹配商业物业财报的核心统计维度，覆盖基础分析需求 |
| `用户选择组件选项` | `月度财报`、`季度财报`、`年度财报` | 对应商业物业财报的标准统计周期，贴合业务查询场景 |
| `知识库关联变量` | `按项目维度预设固定ID` | 每个商业物业项目的知识库独立，避免跨项目数据混淆 |
| `代码节点变量提取规则` | `匹配\d+元`、`匹配\d+平方米` | 适配商业物业财报字段的单位格式，精准提取有效数值 |
| `API请求超时阈值` | `120 秒` | 适配外部物业系统数据拉取的网络耗时，避免请求中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：API调用时无用户交互提示，表单输入或用户选择组件未生效。原因：未开启`API触发时启用用户交互`配置项，导致发布后API调用跳过前端交互环节。
- 现象：配置`知识库关联变量`后运行报错，提示变量未定义。原因：未在工作流全局变量中提前预设对应项目的知识库ID，或变量命名与配置项不匹配。
- 现象：代码节点运行后无法提取`resultTimes`和`trafficFlowCounts`变量。原因：未在代码节点中配置正确的变量映射规则，或原始数据中对应字段的格式与正则提取规则不匹配。

## 怎么确认配好了
- 触发一次手动测试调用，检查交互组件是否按配置的选项展示，输入内容是否能正确传递到工作流后续节点。
- 查看代码节点的运行日志，确认`resultTimes`、`trafficFlowCounts`等字段是否被正确提取并传递到后续分析环节。
- 调用正式API接口，检查返回结果是否包含配置的财报分析维度数据，无缺失或格式错误。
- 验证定时触发任务，确认到指定周期后工作流是否自动启动并生成对应财报汇总数据。
