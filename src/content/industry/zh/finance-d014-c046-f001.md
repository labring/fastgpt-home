# 固废处理财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
固废处理品类的财报数据主要来源于企业环保申报系统、属地生态环境部门的固废监管平台及第三方检测机构的合规报告。数据更新节奏为月度处置台账实时同步，年度综合财报每季度末批量更新。文档结构包含固废产生总量、分类处置量、综合利用率、危险废物合规处置率、处置设施运行时长等字段，单位多为吨、立方米、小时，部分指标以百分比标注。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
固废处理财报的数据多源、更新节奏分层且字段单位有明确规范，会对HTTP接口与外部系统环节带来多重约束。跨来源数据拉取需要接口支持对接多类异构系统，适配不同的认证协议。分层更新节奏要求配置两种触发逻辑，短间隔轮询适配月度台账同步，周期批量拉取适配季度财报汇总。字段与单位的严格要求需要接口返回的字段名与财报模板完全匹配，避免数值错位。同时，敏感环保数据的调用需携带合法身份凭证，防止非授权访问。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `webhook_trigger_mode` | 按「实时+定时」双模式 | 适配月度台账实时同步与季度财报批量拉取的分层更新需求 |
| `data_sync_interval` | 300 秒（月度台账）、86400 秒（季度批量） | 匹配固废处置数据的实时性与批量更新的频率要求 |
| `field_matching_strictness` | 严格匹配字段名与单位 | 避免财报生成时出现数值与单位错位的错误 |
| `auth_token_required` | 开启并绑定企业专属密钥 | 确保敏感环保数据的调用合规性 |
| `batch_pull_page_size` | 100 条/页 | 平衡接口调用效率与单次数据传输量 |
| `timeout_threshold` | 600 秒 | 适配批量拉取季度财报时的接口响应时长需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 启动容器后无法连接外部OneAPI服务，日志显示连接超时或拒绝。原因是未在docker compose配置文件中配置`ONEAPI_BASE_URL`与`ONEAPI_API_KEY`参数，导致系统无法定位外部接口地址。
- 配置多表格格式的webhook推送后，接收端仅收到单条数据。原因是未开启`batch_webhook_enable`参数，未启用批量数据推送模式。
- 飞书webhook推送失败，界面提示无效的配置信息。原因是未按照最新文档更新签名验证参数，原文档中的配置步骤已调整未同步更新。

## 怎么确认配好了
- 调用配置好的HTTP接口，检查返回的字段名与单位是否与固废财报模板完全匹配。
- 触发定时同步任务，查看外部系统的数据是否按预设的间隔完成拉取。
- 测试webhook推送，确认多表格格式的数据是否完整推送到指定接收端。
- 查看容器日志，确认无连接超时或认证失败的报错信息。
