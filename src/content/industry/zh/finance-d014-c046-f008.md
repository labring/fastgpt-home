# 固废处理财报分析的工具调用与插件

## 这个品类的数据长什么样
固废处理企业的财报数据来源包括企业公开披露的定期报告、属地生态环境部门的监管公示数据、第三方合规监测报告。更新节奏分为三类：年度财报按自然年度更新，季度运营数据每季度末后一月发布，月度处置台账数据按月更新。文档结构包含正文核心指标模块与明细台账附件，字段涵盖处置总量、处置类型占比、单位处置成本、合规达标时长等，单位多为吨、万元、自然日。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源分散的数据来源要求配置多插件并行调用逻辑，需处理不同数据源的权限校验与接口格式差异。不同更新频率的数据源需匹配对应调度周期，避免重复拉取或数据滞后。大型明细台账附件要求工具适配大文件解析，需调整文件处理的阈值参数。固废专用字段命名无统一规范，需配置字段映射规则完成标准化转换，保障后续分析的一致性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `multi_plugin_parallel_count` | `2-3` | 固废财报数据源通常为2-3个，并行调用过多会触发第三方接口限流 |
| `parse_file_max_size` | `500 MB` | 固废处理台账附件多为大型明细报表，需适配大文件解析需求 |
| `plugin_request_timeout` | `120 秒` | 跨平台拉取监管公示数据需较长响应时间，避免提前中断调用 |
| `field_mapping_rule` | 按实测标定 | 固废专用字段命名无统一规范，需根据对接数据源调整映射逻辑 |
| `scheduled_trigger_cron` | 年度数据取`0 0 1 1 *`，月度数据取`0 0 2 * *` | 匹配对应数据源的年度、月度更新发布周期 |
| `api_signature_verify` | `开启` | 固废数据多来自监管平台，需校验调用合法性保障数据合规 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用OneAPI对接的模型时，界面提示“空密钥错误”，无法完成模型配置。原因：未在FastGPT的插件配置中正确填入OneAPI的完整请求地址，仅填入密钥导致接口请求路径缺失。
- 现象：发布带全局变量的工作流接口后，外部调用返回结果为空，或全局变量未生效。原因：未在外部调用的请求参数中携带`global_vars`字段，或字段格式不符合接口约定的JSON结构。
- 现象：文本内容提取工具运行后提示“提取字段不存在”，但源文件中存在对应内容。原因：未将固废财报中的专用字段名（如“一般固废处置量”）正确配置到提取工具的目标字段映射中，导致工具无法识别目标内容。

## 怎么确认配好了
- 调用内置的插件调试工具，输入固废财报的测试数据源，核对多插件并行调用的返回结果是否覆盖所有配置的指标项。
- 查看定时触发任务的运行日志，确认按配置的周期自动拉取数据的动作是否按计划执行。
- 查看字段映射的预览界面，确认固废专用字段是否被正确转换为预设的分析指标格式。
- 发起一次完整的工作流测试，核对最终生成的分析报告是否包含固废处理的核心业务数据。
