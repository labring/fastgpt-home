# 国有大行财报分析的知识库检索与召回

## 这个品类的数据长什么样
国有大行财报数据主要来自官方年度、半年度、季度业绩报告及监管披露文件，更新节奏固定，年度报告于次年4月底前发布，半年度报告于8月底前发布，季度报告于季后15日内发布。文档多为PDF或DOCX格式，结构包含财务报表正文、业务分析章节、风险管控说明及详细附注，字段涵盖资产规模、净利润、不良贷款率等，计量单位以人民币亿元为主，部分指标以百分比作为计量形式。

## 这些特征在「知识库检索与召回」这一环带来什么约束
国有大行财报的固定更新节奏要求知识库配置定时同步任务，确保检索数据与最新披露内容一致。多章节长文档结构要求检索时保留跨段落上下文关联，避免割裂业务分析与财务数据的逻辑。多字段且带特定计量单位的特征，要求检索时需匹配字段名与单位，减少无关召回结果。PDF与DOCX混合格式的文档，要求解析模块兼容两种格式的文本提取，确保附注等细节内容可被正常检索。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 国有大行完整财报单文件体积较大，解析耗时较长 |
| `maxContext` | `800–1200 字符` | 财报长文档需保留足够上下文，关联业务分析与财务数据 |
| `召回条数` | `前 8–10 条` | 财报指标多且关联紧密，适量召回可覆盖核心分析维度 |
| `相似度阈值` | `0.75–0.85` | 财报术语专业性强，需较高匹配度过滤无关内容 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 完整年度财报PDF或DOCX文件通常可达数百兆级别 |
| `PARSE_CHUNK_OVERLAP` | `100–150 字符` | 财报章节间逻辑紧密，重叠分段可保留上下文连贯性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用知识库`content`接口返回`415 Unsupported Media Type`错误，浏览器访问对应链接可正常下载DOCX文件。原因：未在知识库配置中添加DOCX格式的解析支持白名单，或接口请求头未声明兼容的文档类型。
- 多级目录存储的季度财报附件无法被全部检索，部分DOCX文档内的财务表格内容未被提取。原因：未开启知识库的多级目录递归扫描功能，且未配置DOCX表格文本提取的启用参数。
- 检索结果中混入大量非财报类的内部管理文档，召回条数超出预设范围。原因：未设置知识库的文档分类标签过滤规则，或相似度阈值设置过低，导致无关内容被召回。

## 怎么确认配好了
- 上传一份完整的国有大行年度财报PDF文件，检查解析后的文本分段是否保留章节标题与核心数据的关联。
- 手动触发一次定时同步任务，核对知识库内的文档更新时间与官方披露的财报发布时间是否一致。
- 输入财报相关的专业术语，检查检索结果是否仅包含财报类文档，且召回条数符合预设配置。
- 调用知识库`content`接口，验证返回的文本格式与解析后的分段结构是否符合预期。
