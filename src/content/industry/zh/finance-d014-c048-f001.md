# 城商行财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
城商行财报数据主要来自官方监管披露平台、自身公开年报与季度报告。更新节奏为季度报告于季后45个工作日内披露，年度报告于次年4月末前完成公开。文档结构包含资产负债表、利润表、现金流量表及核心监管指标附表，字段涵盖核心一级资本充足率、不良贷款率、拨备覆盖率等，单位多为百分比或人民币亿元。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
城商行财报的固定披露节奏要求HTTP接口需适配定时拉取窗口，避免在未披露时段拉取无效数据。多字段且含监管专用指标的结构，要求接口支持指定字段筛选与校验，减少无效数据传输。多来源的数据特性要求接口适配不同数据源的认证方式与返回格式，同时支持增量拉取逻辑，降低全量拉取的资源消耗。金融数据的敏感性要求接口需启用加密传输配置，保障数据交互安全。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `api_request_timeout` | `300–600 秒` | 适配多源财报数据拉取的耗时需求，避免因数据量大导致超时中断 |
| `data_source_whitelist` | `["银保监会披露平台", "城商行官方官网"]` | 限定合法数据源范围，拦截非授权来源的无效请求 |
| `field_filter_enable` | `开启` | 仅拉取财报分析所需的核心字段，减少数据传输量与解析耗时 |
| `encrypt_transport` | `开启TLS 1.2+` | 符合金融数据传输的安全规范，保障交互过程的数据保密性 |
| `incremental_sync_interval` | `每日 2 次` | 匹配城商行季度报的披露窗口与临时更新场景，平衡实时性与资源消耗 |
| `response_format_check` | `开启` | 校验返回数据的字段完整性与格式合规性，避免异常数据进入分析流程 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用接口返回`connection error`错误提示，原因是未配置合法数据源白名单，接口拦截了非授权来源的请求。
- 接口调用返回的分析结果未关联预设知识库内容，原因是未开启字段筛选配置，拉取的财报数据未命中知识库绑定的字段规则。
- 平台前端测试的答案与接口调用结果不一致，原因是未启用增量同步配置，接口拉取的是缓存的旧版财报数据。

## 怎么确认配好了
- 发起一次测试接口请求，检查返回状态码为`200 OK`，确认连接与认证配置生效。
- 查看接口返回的字段列表，确认仅包含预设的核心财报字段，验证字段筛选配置生效。
- 对比平台前端测试结果与接口返回结果，确认两者使用的财报数据版本一致，验证同步配置生效。
- 检查接口请求的日志，确认启用了TLS加密传输，验证安全配置生效。
