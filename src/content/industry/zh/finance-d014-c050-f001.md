# 塑料橡胶财报分析的HTTP接口与外部系统

## 这个品类的数据长什么样
塑料橡胶品类的财报数据主要来自交易所公开披露的上市公司定期报告、行业协会产销简报及大宗商品现货平台公开信息。更新节奏分为季度、年度两类，季度财报在季度结束后15个工作日内发布，年度财报需在次年4月底前完成披露。文档以PDF或结构化表格形式呈现，相关数据分散在业务分部报告、原材料采购与成本构成章节，包含分板块营收金额、产能规模、原材料采购占比等字段，单位涵盖万元、万吨等。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
塑料橡胶品类的数据来源分散、格式多样且更新周期分层，给HTTP接口与外部系统对接带来多重约束。需支持对接多类外部数据源接口，因此需配置统一的重试与超时兜底机制；需适配PDF与结构化表格两类文档格式，接口需内置不同解析逻辑的路由规则；需按季度、年度的更新节奏触发拉取任务，需新增数据时间戳校验逻辑避免重复拉取旧数据；同时需处理不同数据源的字段命名与单位差异，需配置字段映射与单位转换规则，确保数据对齐无误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 塑料橡胶财报PDF通常包含多页业务明细，完整解析需较长时间，600秒可覆盖全量解析流程 |
| `externalApiRetryCount` | `2 次` | 财报数据源多为公开行业平台，接口稳定性中等，2次重试可覆盖临时网络波动 |
| `fieldMappingStrategy` | `按业务关键词匹配` | 不同上市公司的塑料橡胶板块字段命名存在差异，通过关键词匹配可自动对齐目标字段 |
| `dataSyncCron` | `0 2 * * 1,4,7,10` | 匹配季度末全量拉取、日常增量校验的更新节奏，每周固定时间触发基础校验 |
| `unitConversionEnabled` | `开启` | 不同数据源的营收、产能单位存在差异，开启转换可确保数据统一格式 |
| `streamResponseChunkSize` | `800-1200 字符` | 财报分析结果通常篇幅较长，该分段长度可平衡前端展示流畅度与接口传输效率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部财报数据源接口返回`400`状态码，且响应体提示字段不匹配。原因：未启用`fieldMappingStrategy`配置，直接使用硬编码字段拉取数据，未适配不同上市公司的字段差异。
- 现象：流式输出财报分析结果时，点击内嵌链接仅覆盖当前页面无法跳转新窗口。原因：未配置流式返回的链接跳转规则，前端渲染逻辑未为外部链接添加新窗口触发属性。
- 现象：对话日志中展示的分析内容与实际返回的财报数据不一致，多次调用后日志内容始终相同。原因：未配置数据缓存的过期时间，旧的财报数据缓存未被自动清理，导致重复返回旧数据。

## 怎么确认配好了
- 手动触发一次数据拉取任务，检查接口返回的字段是否与配置的`fieldMappingStrategy`匹配，确认字段对齐无误。
- 查看`PARSE_FILE_TIMEOUT_SECONDS`配置的生效日志，确认解析耗时未超过设定的阈值，无超时报错。
- 测试流式输出功能，点击返回内容中的链接，确认可跳转至新页面，且返回速度可通过`streamResponseChunkSize`调整。
- 检查数据同步的定时任务日志，确认按`dataSyncCron`配置的周期正常触发，无遗漏或重复拉取。
