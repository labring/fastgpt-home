# 塑料橡胶财报分析的部署与升级

## 这个品类的数据长什么样
塑料橡胶行业的财报数据来源包括境内外证券交易所公开披露的上市公司定期报告、专业行业数据库、行业协会发布的月度产销监测数据。更新节奏为年度完整财报每年披露一次，季度财报每季度更新，行业配套监测数据按月更新。文档多为PDF格式，包含结构化的财务报表与行业产销数据表格，核心字段包括营收、总产量、单位生产成本、毛利率、进出口总量等，单位多为万吨、元/吨、百分比。

## 这些特征在「部署与升级」这一环带来什么约束
塑料橡胶财报及配套行业数据单份体量较大，且更新频率较高，对部署与升级环节带来多重约束。多源数据的单位差异要求部署时配置统一的字段映射与单位转换规则，避免分析结果出现单位混乱。高频更新的季度、月度数据需要适配增量解析与向量存储的增量同步逻辑，升级时需兼容原有增量更新配置，避免全量重跑导致的资源占用过高。结构化报表占比高，需调整文档解析的表格提取优先级，防止解析超时或内容丢失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `PARSE_FILE_TIMEOUT_SECONDS` | 600–900 秒 | 单份财报PDF包含多页结构化报表，体量大，需延长解析超时时间 |
| `UPLOAD_FILE_MAX_SIZE` | 2000 MB | 支持导入完整年度财报及配套行业数据文件，避免大文件上传失败 |
| `maxContext` | 1500–2000 字符 | 财报文本包含长段落的财务说明，需扩大上下文窗口以保留完整语义 |
| `相似度阈值` | 0.75–0.85 | 过滤低相关的行业数据片段，避免冗余信息干扰财报分析 |
| `召回条数` | 前 8–10 条 | 财报分析需覆盖核心财务指标与行业关联数据，适当增加召回量以保证信息完整 |
| `EMBEDDING_BATCH_SIZE` | 32 | 适配大体积文档的向量生成批次，平衡解析速度与资源占用 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：导入财报分析插件时弹出`internal server error`报错。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，大体积财报解析超时触发服务端错误。
- 现象：更新版本后模型厂商图标加载失败。原因：升级时未保留原有静态资源映射配置，或未同步更新前端依赖的图标文件路径。
- 现象：知识库磁盘占用远超预期。原因：未配置增量向量存储规则，全量重新生成嵌入向量导致原文件、分割后文件块与嵌入向量数据重复占用磁盘空间。

## 怎么确认配好了
- 上传一份典型的塑料橡胶财报PDF，检查解析后的文本是否包含完整的财务表格与行业数据字段，核对解析耗时是否符合预设的超时参数范围。
- 查看知识库磁盘占用统计，确认仅包含原文件、分割后文件块与嵌入向量三类数据，无重复存储的内容。
- 重启服务后验证模型厂商图标正常加载，无加载失败提示。
- 触发增量更新任务，检查仅新增的财报数据被同步至知识库，未触发全量重解析。
