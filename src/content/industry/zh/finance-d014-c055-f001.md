# 大气治理财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
大气治理品类的财报数据主要来自相关企业公开披露的定期报告、行业协会发布的经营简报及项目中标公告。数据更新节奏以季度、年度为核心周期，部分临时项目进度数据会随企业经营公告不定期更新。单份财报文档包含营收构成、项目合同金额、污染物处理设备产能、运维服务单价等字段，营收类字段单位为人民币元，处理设备相关字段单位为立方米/小时、吨/年或套，合同金额字段单位为人民币万元。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
大气治理财报的多源数据来源，要求HTTP接口支持多数据源鉴权配置，适配不同平台的API调用规则。不同更新节奏的数据源，需要接口支持定时拉取与手动触发拉取两种模式，匹配季度定期披露与临时公告的更新需求。字段与单位的多样性，要求接口支持自定义字段映射与单位转换逻辑，避免跨系统数据格式不兼容。部分非结构化的中标公告文档，需要接口适配PDF、Word等多格式解析的参数配置，保障财报中非结构化数据的有效提取。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 大气治理财报文档通常包含多页结构化与非结构化内容，较长的超时时长可保障完整数据提取 |
| `CRON_EXPRESSION` | 0 0 2 */3 * | 匹配上市公司季度财报的披露周期，定时拉取最新财报数据 |
| `API_KEY` | 为每个数据源分配独立密钥，存储于系统环境变量 | 区分不同数据源的调用权限，避免单一密钥泄露影响全链路数据对接 |
| `FIELD_MAPPING_RULE` | 自定义映射规则，配置污染物处理量、营收等字段的单位转换逻辑 | 适配大气治理财报字段与单位的多样性，统一跨系统数据格式 |
| `MAX_RETRY_TIMES` | 3 次 | 应对外部数据源接口的临时波动，保障数据拉取的稳定性 |
| `ALLOWED_PARSE_TYPES` | PDF、DOCX、TXT | 覆盖大气治理财报常见的披露文档格式，支持多类型数据解析 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用HTTP接口返回404错误，日志显示`POST /api/admin/initv4818 404`。原因：未正确执行版本升级脚本，或升级后未重启服务导致接口路径未更新。
- 现象：配置HTTPS接口后无法正常调用，nginx反向代理配置不生效。原因：未正确配置nginx的SSL证书绑定与请求转发规则，忽略了HTTP头转发配置。
- 现象：知识库接口返回结果无会话上下文数据。原因：未开启会话协议配置，或未在接口请求中携带正确的会话标识参数。

## 怎么确认配好了
- 调用配置完成的HTTP接口，传入测试用的财报数据源链接，核对返回数据的字段是否与预设的映射规则匹配。
- 查看系统定时任务日志，确认数据拉取任务按配置的周期自动执行。
- 使用不同的数据源密钥调用接口，验证仅授权的密钥可成功获取对应数据。
- 上传大气治理财报的PDF文档至系统，检查解析结果是否覆盖了营收、项目合同等核心字段。
