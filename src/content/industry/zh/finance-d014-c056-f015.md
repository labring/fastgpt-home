# 家居用品财报分析的部署与升级

## 这个品类的数据长什么样
家居用品行业的财报数据主要来源于上市公司公开披露的定期报告、轻工制造行业协会公开统计数据。数据更新遵循季度与年度披露规则，季度报告于每季度结束后1-2个月发布，年度报告于次年4月前完成披露。文档多为PDF格式，包含合并资产负债表、利润表、现金流量表等核心财务报表，同时覆盖家纺、家具、厨具等细分品类的营收拆解、线上线下渠道占比等数据。字段涵盖营收、归母净利润、毛利率、存货周转率等，单位多采用万元或元。

## 这些特征在「部署与升级」这一环带来什么约束
家居用品财报的长文档结构、多细分字段、固定披露周期等特征，对部署与升级环节提出明确约束。长文档要求延长文件解析的超时阈值，避免解析中断；多细分字段需要配置精准的召回过滤规则，确保提取的信息匹配分析需求；固定的披露周期要求配置定时同步任务，保证数据时效性；复杂的表格结构则需要启用高精度的表格解析模式，减少字段提取错误。此外，版本升级可能调整存储与接口配置，需适配家居用品数据的存储与调用需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 家居用品完整年报PDF篇幅较长，常规解析时长无法覆盖全部内容 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 单份完整年报PDF体积可达数百MB，需预留足够上传空间 |
| `maxContext` | 8000–12000 字符 | 财报内容密集，需足够上下文支撑模型完成细分品类的营收分析 |
| `RECALL_TOP_K` | 前 10 条 | 财报包含多组细分字段，需召回足够相关数据支撑分析 |
| `SYNC_CRON_EXPR` | "0 0 2 1,4,7,10 *" | 匹配季度财报披露后1-2天的同步周期，保证数据时效性 |
| `PARSE_TABLE_MODE` | "accurate" | 财报表格字段复杂，高精度模式可减少字段提取错误 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：升级至4.9.13版本后，模型返回结果末尾出现`[rule]`类追溯符号。原因：未关闭`SHOW_RETRIEVAL_RULE`配置项，该版本默认启用了检索规则展示功能。
- 现象：升级至4.10.0版本后，minio存储无法同步内网环境的财报数据，返回"public network required"错误。原因：4.10.0版本调整了插件系统的存储配置，默认要求minio公网可访问，未修改`MINIO_PUBLIC_ACCESS`配置项适配内网场景。
- 现象：视频文件上传后无法被模型识别，返回"unsupported file type"报错。原因：未升级至支持视频解析的版本，或未开启`ENABLE_VIDEO_PARSE`配置项。

## 怎么确认配好了
- 上传单份家居用品上市公司完整年报PDF，验证解析后的文本与表格无缺失，字段匹配预设的分析需求。
- 手动触发一次定时同步任务，核对向量库内的更新时间与配置的同步周期一致。
- 发起财报分析提问，验证返回结果未包含额外的追溯标记，且覆盖所需的细分品类数据。
- 测试大模型接口的连通性，验证调用无报错，返回内容符合预期。
