# 小家电财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
小家电财报分析的数据主要来源于企业公开定期报告、第三方行业监测数据库及电商平台公开销售数据。更新节奏分为三类：季度财报数据每3个月更新一次，年度财报每年更新一次，电商销售相关数据每月更新。单份文档包含品类营收明细、成本拆分、渠道分布、研发投入等模块，结构化数据以表格形式嵌入报告正文，非结构化数据为文字分析段落。核心字段包含小家电品类营收、出货量、单位生产成本等，营收单位为人民币元，出货量单位为台，单位生产成本单位为人民币元/台。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
多数据源的接入需求要求HTTP接口支持适配不同的鉴权方式，包括API Key、客户端凭证等。更新频率的差异需要接口支持定时拉取、增量拉取与全量拉取的切换配置。字段命名与单位的不统一，要求接口返回数据后需通过映射规则完成标准化处理。小家电财报文档长度跨度较大，从季度报告的数十页到年度报告的上百页，要求接口支持大文件传输与分页拉取，同时需调整解析超时与文本分段设置。品类细分较多的特性，要求接口支持按具体小家电品类筛选返回数据，避免引入无关信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `external_api_auth_type` | `api_key` 或 `oauth2_client_credentials` | 小家电财报数据源多使用API Key或客户端凭证认证，适配不同第三方接口的鉴权要求 |
| `parse_file_timeout_seconds` | `600 秒` | 小家电年度财报文档长度较长，解析需足够时间完成文本拆分与结构化提取 |
| `rag_recall_top_k` | `前 10 条` | 小家电财报数据字段相对集中，过多召回会引入无关内容，过少则遗漏关键信息 |
| `external_api_rate_limit` | `5 次/分钟` | 多数第三方行业监测接口对小家电数据的调用频率有限制，避免触发限流 |
| `field_mapping_rule` | 按数据源预设规则自动映射 | 小家电财报数据字段命名差异大，自动映射可减少手动配置工作量，适配FastGPT v4.9.7-fix2及以上版本的配置逻辑 |
| `chunk_size` | `800–1200 字符` | 小家电财报的结构化表格与文字分析段落长度适中，该分段可保留完整语义单元 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部财报数据源接口返回`401 Unauthorized`状态码，原因：未正确配置`external_api_auth_type`，使用了错误的认证凭证或未匹配数据源的鉴权规则。
- 现象：解析小家电年度财报文档时触发`504 Gateway Timeout`，原因：`parse_file_timeout_seconds`设置值过低，未适配年度财报较长的解析时长。
- 现象：拉取的小家电数据部分核心字段为空，原因：未配置`field_mapping_rule`，未将第三方数据源的自定义字段映射为统一的财报分析字段。

## 怎么确认配好了
- 调用配置完成的外部接口，查看返回的HTTP状态码，确认鉴权配置生效。
- 上传一份小家电财报文档，查看解析后的结构化字段是否包含品类相关的核心数据，确认字段映射规则生效。
- 查看接口调用日志，核对调用频率是否符合`external_api_rate_limit`的设置。
- 触发检索任务，检查返回结果的相关性，确认召回条数符合业务需求。
