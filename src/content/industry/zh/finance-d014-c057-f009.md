# 小家电财报分析的引用来源与溯源

## 这个品类的数据长什么样
小家电相关财报数据主要来自上市公司公开披露的定期报告、临时公告，以及行业协会发布的公开统计文档。更新节奏为季度、半年度、年度固定披露，临时公告随事件触发更新。文档多为PDF格式的交易所官方披露文件，部分平台提供结构化解析版本。字段包含披露主体名称、报告期、小家电板块营收金额（单位为人民币元）、销量（单位为万台）、原材料成本占比相关数值、销售区域占比相关数值等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
数据来源依赖交易所官方披露，因此溯源环节需要关联公告编号等唯一标识，确保溯源结果的官方权威性。固定更新节奏要求召回配置需限定报告期范围，避免引入过期的非当期数据。多文档格式（PDF与结构化版本）要求解析配置需支持两种格式的精准提取，尤其是段落级的定位。小家电板块作为主营业务的细分部分，需要配置关键词过滤，将召回范围限定在小家电相关段落，避免其他业务板块的内容干扰。不同字段的单位差异要求溯源结果需同步标注对应单位，避免信息混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `知识库召回条数` | `前6-10条` | 小家电财报的小家电相关段落分布集中，过多召回会引入其他业务板块的无关内容，过少则无法覆盖完整分析所需的信息 |
| `相似度阈值` | `0.72-0.85` | 小家电财报的关键词辨识度较高，阈值过低会引入非相关财报段落，过高则可能遗漏有效信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120 秒` | 小家电财报的PDF文档通常包含多页详细板块分析，解析耗时较长，超时会导致解析失败 |
| `分段长度` | `800-1200 字符` | 小家电相关财报段落多为结构化的业务分析，分段过长会丢失段落级溯源的精准性，过短则会割裂业务逻辑 |
| `启用段落级溯源` | `开启` | 小家电财报的业务板块划分清晰，段落级溯源可以精准定位到小家电相关的具体披露内容，仅覆盖小家电相关的具体披露内容 |
| `公告编号关联开关` | `开启` | 小家电财报的披露文件带有唯一公告编号，开启后可以将溯源结果关联到官方披露的唯一标识，提升溯源可信度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为基于问题分类的工作流中，仅第一个问题返回知识库引用标识，后续问题的返回结果无任何引用相关内容。原因是工作流未配置会话上下文的引用溯源开关，或未在后续节点中继承知识库召回的配置参数，导致后续问答无法触发溯源逻辑。
- 现象为生成结果中出现红色错误提示，提示内容为「无法定位引用来源」或类似表述。原因是未开启公告编号关联开关，或解析后的文档未保留披露文件的唯一标识，导致溯源所需的官方关联信息缺失。
- 现象为用户请求移除引用标识，但返回的结构化内容仍包含引用元数据，仅前端展示的引用标记被隐藏。原因是混淆了引用展示开关与溯源数据生成开关，仅关闭前端展示不会移除返回内容中的引用元数据，导致接口返回仍携带相关信息。

## 怎么确认配好了
- 上传一份小家电企业的公开财报PDF，执行解析后查看解析结果中的段落标记，确认段落级溯源的标记是否正确。
- 发起一次小家电财报分析的查询，查看返回结果中是否包含披露主体、报告期等溯源字段，确认溯源信息是否完整。
- 调整知识库召回条数的配置，发起多次查询，验证召回结果的数量是否符合配置的取值区间。
- 触发工作流的多轮问答流程，确认每一轮问答的返回结果均包含有效的溯源信息。
