# 小金属财报分析的向量模型与索引

## 这个品类的数据长什么样
小金属财报数据主要来自上市公司定期报告、交易所公开公告及行业协会调研数据，更新节奏以季度、年度为核心周期，临时产能或价格变动公告会随机触发更新。文档结构包含核心财务指标表格、产量库存明细、原料采购成本、产品售价波动项，字段包含金属品位占比、实物吨数、单位毛利、同比变动数值，单位多为吨、元/千克、元/吨。

## 这些特征在「向量模型与索引」这一环带来什么约束
小金属财报的专业字段与更新特性，对向量模型与索引环节形成多重约束。高频且随机的临时公告更新，要求索引支持增量同步，不采用全量重建方式，避免重复计算资源浪费。文档同时包含结构化表格与非结构化分析文本，需要配置分块规则区分两类内容，避免向量编码混淆专业术语与通用表述。专业字段如金属品位、实物吨数等需要向量模型适配有色金属领域术语，否则召回精度不足。单份财报的结构化数据字段较多，向量索引需支持多字段关联召回，提升匹配准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunk_size` | 800–1200 字符 | 小金属财报包含结构化表格与非结构化分析，该区间可平衡专业术语完整性与向量编码密度 |
| `recall_top_k` | 前6–8条 | 小金属财报专业字段密集，需召回足够数量的片段以覆盖核心指标 |
| `similarity_threshold` | 0.72–0.78 | 适配专业术语的语义匹配精度，避免无关片段召回 |
| `index_refresh_interval` | 15–30 分钟 | 匹配临时公告的随机更新节奏，平衡索引负载与实时性 |
| `enable_structured_parse` | 开启 | 可提取财报中的金属产量、成本表格字段，优化向量索引的结构化关联 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 覆盖单份年度财报的完整附件内容，避免上传截断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：本地部署v4.9.0版本的知识库中，文档解析与索引增强选项未显示。原因：开源版默认未启用商业版专属的解析增强插件，需通过配置文件开启对应功能开关。
- 现象：Embedding模型通过OneAPI调用时报错，返回400或502状态码。原因：OneAPI配置的模型地址未适配小金属领域的专业术语向量编码需求，或接口超时阈值设置过低。
- 现象：知识库召回结果条数少于配置的`recall_top_k`数量。原因：未开启结构化解析，导致非结构化文本的语义匹配阈值被误设过高，过滤了有效片段。

## 怎么确认配好了
- 上传一份小金属公司的季度财报PDF，检查解析后是否提取了金属产量、单位成本等结构化字段。
- 发起一次财报分析查询，核对召回的片段数量是否在配置的`recall_top_k`区间内。
- 提交一份临时公告文档，检查索引是否在设定的`index_refresh_interval`时间内完成更新。
- 查看OneAPI的接口日志，确认Embedding模型的调用请求无超时或格式错误。
