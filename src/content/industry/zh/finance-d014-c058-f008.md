# 小金属财报分析的工具调用与插件

## 这个品类的数据长什么样
小金属财报数据主要来自国内小金属行业协会公开披露、对应上市公司定期报告、专业现货交易平台公开报价。数据更新节奏分两类：上市公司财报按季度、年度固定更新，行业现货与供需数据每日更新。文档结构包含核心品类的产量、库存、进出口量、平均品位、现货价格等字段，单位多为吨、元/吨、品位百分比，部分细分品类需标注氧化物折算含量。

## 这些特征在「工具调用与插件」这一环带来什么约束
小金属财报与现货数据的多更新节奏，要求工具调用需区分季度财报批量拉取与实时现货数据的接口适配。不同品类的单位与折算规则差异，要求插件需配置字段单位映射逻辑，避免数值与单位不匹配。细分品类的专属字段（如钨矿WO3品位），要求工具调用需支持精准字段筛选，避免返回冗余数据。财报数据的批量拉取规模较大，需适配更长的超时阈值与分页拉取逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `tool_call_timeout` | 300–600 秒 | 适配小金属财报批量拉取的长耗时需求，避免单条工具调用超时中断 |
| `plugin_field_mapping` | 按品类预设映射规则 | 匹配小金属特有的单位与折算字段，如将WO3品位映射为标准输出字段 |
| `data_pull_batch_size` | 50–100 条/次 | 平衡拉取效率与接口负载，适配财报数据的批量查询场景 |
| `unit_conversion_enabled` | 开启 | 统一处理元/吨、美元/吨等多单位数据，避免结果单位混乱 |
| `MCP_DEPLOY_PORT` | 8080–8090 | 预留常用端口区间，避免与本地服务端口冲突 |
| `tool_call_retry_count` | 2 次 | 应对小金属数据接口偶发的波动，降低调用失败率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 配置MySQL工具调用后对话返回400 status code (no body)。原因是未正确配置小金属财报数据的字段筛选规则，导致请求参数包含无效的细分品类字段，触发接口校验失败。
- 调用自定义代码插件拉取小金属现货数据时提示AggregateError Code:ETIMEDOUT。原因是未调整`tool_call_timeout`参数，小金属现货数据的实时拉取耗时超过默认阈值，导致连接超时。
- 未开启单位转换配置导致生成的财报分析结果中出现单位混乱。原因是未配置`plugin_field_mapping`规则，未统一处理小金属特有的氧化物折算单位与价格单位。

## 怎么确认配好了
- 发起单条小金属品类的财报数据工具调用，检查返回结果的字段与单位是否与预设映射规则一致。
- 测试批量拉取财报数据，确认调用耗时未超过配置的`tool_call_timeout`阈值，无超时报错。
- 查看MCP部署日志，确认服务在指定端口正常监听，无端口冲突报错。
- 触发自定义代码插件调用，检查是否能正确拉取小金属现货数据，无连接超时提示。
