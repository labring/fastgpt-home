# 工程机械财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
工程机械行业的财报数据主要来自上市企业公开披露的定期报告，包括季度报告、半年度报告与年度报告，部分企业还会按月度披露核心设备的运营与销售数据。文档结构包含合并财务报表（资产负债表、利润表、现金流量表）、管理层讨论与分析板块，以及细分业务营收明细，如挖掘机、装载机、起重机等机型的营收占比。核心字段涵盖主营业务收入、细分业务营收、应收账款、存货、设备销量等，单位多为人民币元、万元、台等。数据更新周期与披露要求绑定，定期报告按季度、半年度、年度节奏更新，月度运营数据则按月度周期更新。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
工程机械财报的细分业务维度多、数据结构混合了结构化报表与非结构化分析文本，同时更新周期存在差异，这些特征对接口与外部系统环节带来多重约束。首先，细分业务字段较多，接口需要支持按业务板块筛选的参数，避免返回冗余数据。其次，数据来源包含企业财报与行业公开数据，不同数据源的字段单位可能存在差异，需要接口层完成单位统一转换。再者，更新周期包含月度、季度、年度，需要配置多套定时拉取规则适配不同数据的更新节奏。最后，财报文档篇幅较长，接口调用与解析需要预留足够的耗时空间，避免超时中断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 工程机械财报PDF通常包含多页财务报表与业务分析内容，解析耗时较长 |
| `HTTP_REQUEST_TIMEOUT` | `60 秒` | 外部财报数据源接口响应存在一定延迟，预留足够的请求时长 |
| `RETRY_MAX_TIMES` | `2 次` | 应对临时网络波动或接口临时限流场景，避免单次请求失败导致任务中断 |
| `DATA_UNIT_NORMALIZATION` | `开启` | 不同数据源返回的货币单位存在元、万元等差异，统一单位可简化后续分析逻辑 |
| `SCHEDULE_CRON_EXPR` | `0 0 2 * * *（月度数据）、0 0 3 1-15 * *（季度/年度数据）` | 匹配工程机械财报的披露更新节奏，避免重复拉取或遗漏更新 |
| `STRUCTURED_FIELD_MAPPING` | `按工程机械财报标准字段映射` | 适配工程机械财报特有的细分业务字段，确保拉取的数据符合分析需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部财报数据源接口返回`400 Bad Request`，原因：未正确配置`STRUCTURED_FIELD_MAPPING`参数，请求字段与数据源要求不匹配，导致接口返回格式错误。
- 现象：内部部署的FastGPT节点访问管理页面或调用外部接口时出现`net::ERR_INCOMPLETE_RESPONSE`，原因：未配置跨域允许的外部数据源域名，浏览器拦截了跨域请求。
- 现象：定时拉取任务重复触发相同周期的财报数据，原因：`SCHEDULE_CRON_EXPR`的触发频率与数据更新周期不匹配，例如按日拉取仅按季度更新的年度财报数据。

## 怎么确认配好了
- 发起单次结构化数据拉取请求，对比返回字段与预设的工程机械财报标准字段是否一致。
- 手动上传一份公开的工程机械企业财报PDF，检查解析后的文本是否覆盖核心财务报表与业务分析内容。
- 查看系统接口调用日志，确认最近3次外部数据源请求的返回状态码为`200 OK`。
- 检查定时任务管理界面，确认任务触发周期与财报披露节奏匹配。
