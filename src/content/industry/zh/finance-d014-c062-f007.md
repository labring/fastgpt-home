# 广告营销财报分析的工作流编排

## 这个品类的数据长什么样
广告营销行业的财报数据主要来自品牌方的营销费用核算台账、第三方媒介监测平台的投放明细、广告代理公司的月度结算报表。更新节奏多为月度或季度周期，单份文档结构包含投放渠道分类、单次投放预算、实际消耗、转化量、对应营收关联字段，字段单位涵盖人民币元、千次曝光成本（CPM）、单次点击成本（CPC）等，部分数据会附带投放时段、素材类型的附属字段。

## 这些特征在「工作流编排」这一环带来什么约束
广告营销财报数据多源分散的特征，要求工作流需配置多工具并行拉取节点，分别对接台账、监测平台与结算报表接口。固定更新周期要求工作流绑定定时触发规则，避免无效拉取旧数据。字段单位与分类的多样性，要求工作流中嵌入字段标准化处理环节，统一CPM、CPC与人民币元的格式映射。跨渠道投放的关联数据，需要在工作流中加入字段匹配校验步骤，确保投放消耗与对应营收数据的关联准确。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时触发周期` | `每月1次` 或 `每季度1次` | 匹配广告营销财报的常规更新节奏 |
| `多工具并发上限` | `3-5 个` | 对接台账、监测平台、结算报表三类核心数据源，避免并发超限 |
| `工具调用超时时间` | `600 秒` | 跨平台拉取营销数据的响应时长普遍较长 |
| `字段映射规则` | 按 `渠道名称`、`实际消耗`、`转化量` 固定映射 | 统一多源数据的字段格式，避免关联错误 |
| `召回条数` | `前3条` | 广告营销财报字段集中，无需过多召回冗余数据 |
| `全局变量作用域` | `工作流全局` | 确保工具调用环节可读取更新后的变量值 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流中调用工具时无法获取分享应用的URL地址，返回空值或404错误。原因：未在工作流的全局配置中开启应用分享权限，或调用节点未正确引用对应全局变量。
- 现象：工作流执行时提示「自定义提示词模板不可用」，无法修改系统提示词。原因：使用的开源版本为V4.8.22及更早版本，该功能在V4.9.7版本后正式开放。
- 现象：工作流中更新全局变量后，工具调用环节无法读取最新变量值。原因：未将全局变量作用域设置为工作流全局，仅在节点局部定义变量。

## 怎么确认配好了
- 手动触发一次工作流，检查各数据拉取节点的返回结果是否包含预期的渠道、消耗、转化字段，字段格式是否统一。
- 查看工作流的定时触发配置，确认触发时间与广告营销财报的更新周期一致，无重叠或遗漏的触发时段。
- 测试全局变量更新功能，在工具调用环节修改变量后，验证后续节点是否能读取到最新的变量值。
- 检查系统提示词配置，确认当前版本支持自定义提示词模板，且模板内容与财报分析的任务要求匹配。
