# 广告营销财报分析的模型接入与配置

## 这个品类的数据长什么样
广告营销财报的数据主要来自广告代理公司内部投放台账、媒体资源采购合同、投放效果监测报表、品牌营销预算执行明细，以及行业公开监测数据。数据更新节奏分两类：投放执行数据按自然日更新，财报汇总数据按季度或半年度披露。文档以结构化表格为核心，包含投放渠道、投放金额、曝光量、点击量、转化数、投放周期等字段，单位涵盖元、次、个等通用计量标准，部分文档附带非结构化的投放策略说明附件。

## 这些特征在「模型接入与配置」这一环带来什么约束
广告营销财报的结构化字段多、更新节奏分层的特征，对模型接入配置带来明确约束。按日更新的投放执行数据，要求配置的向量数据库同步频率适配日级更新，避免数据滞后影响分析准确性。明确的字段单位要求开启字段校验配置，防止模型混淆不同计量标准的数值。少量非结构化附件则需要配置合理的分段解析参数，适配长文本内容的拆分与召回。固定周期的财报汇总数据，可配置定时触发的模型调用任务，匹配生成报告的时间节点。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `vectorDbSyncInterval` | `86400 秒` | 匹配广告投放数据按自然日更新的节奏，确保召回数据与最新投放情况一致 |
| `chunkSize` | `800–1200 字符` | 适配广告营销财报中结构化表格与非结构化附件混合的文本长度，避免拆分过碎或过长影响召回精度 |
| `fieldValidationEnabled` | `开启` | 广告营销财报包含多类带单位的数值字段，开启校验可防止模型混淆元、万元等计量标准 |
| `scheduledTaskCron` | `0 0 2 * * 1` | 匹配季度财报汇总的披露周期，每周一凌晨触发财报分析任务，适配固定的报告生成节奏 |
| `disableThoughtOutput` | `开启` | 广告营销财报分析输出需聚焦结果，禁用思考过程可避免输出冗余内容，符合行业报告的输出规范 |
| `searchTopK` | `前 8 条` | 平衡召回数据的全面性与分析效率，适配广告营销数据多渠道的召回需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：在模型配置中开启`disableThoughtOutput`后，生成的财报分析结果仍包含`think`标签包裹的思考内容。原因：未将禁用思考输出的配置同步到工作流调用的模型实例，或配置未正确生效。
- 现象：工作流中配置的财报分析节点，无法选择已创建的简易广告营销分析模型。原因：未将该模型绑定到对应工作流的权限范围，或模型的准入配置未开放给当前工作流使用的角色。
- 现象：调用模型生成财报报告时出现`504 Gateway Timeout`错误。原因：未调整`chunkSize`适配广告营销财报中的长文本附件，单段文本长度超出模型支持的最大输入限制，导致调用超时。

## 怎么确认配好了
- 查看向量数据库的同步日志，确认最近一次同步的时间与广告投放数据的更新时间匹配，核对同步频率是否符合配置要求。
- 提交一段包含多字段的广告营销财报样本，检查模型输出是否包含禁用的思考内容，确认`disableThoughtOutput`配置生效。
- 触发定时任务，核对任务触发时间与配置的`scheduledTaskCron`表达式是否一致，确认任务调度正常。
- 调用模型分析长文本附件，检查返回结果的分段是否合理，未出现因`chunkSize`设置不当导致的截断或超时。
