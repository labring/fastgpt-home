# 影视院线财报分析的部署与升级

## 这个品类的数据长什么样
影视院线的财报数据主要来自院线公司内部运营系统、第三方票房统计平台，以及季度、年度公开财报。日常运营数据按每日、每周更新，正式财报按季度、年度发布。文档包含结构化的票房营收、广告植入收入、场地租赁成本、人力支出字段，单位多为人民币元、观影人次、放映场次，同时附带非结构化的运营复盘说明与影院明细备注。

## 这些特征在「部署与升级」这一环带来什么约束
影视院线的日常运营数据需高频接入，要求部署时配置稳定的定时拉取任务，避免数据延迟。正式财报文档体积较大且包含多影院明细，要求升级时保留旧版字段抽取规则的兼容配置，防止历史数据解析失效。同时多影院的明细数据会生成较长的非结构化文本，需要调整文档解析的分段参数，避免截断关键信息。公开财报的排版差异较大，升级时需同步更新排版适配逻辑，确保字段抽取准确率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600–900 秒 | 影视院线财报文档包含多影院明细，解析耗时较长，需延长超时时间避免中断 |
| `UPLOAD_FILE_MAX_SIZE` | 1000–2000 MB | 季度财报可能包含大量影院运营明细，需支持大文件上传 |
| `BASE_PATH` | `/fastgpt` | 配合Nginx配置二级目录访问，避免端口冲突 |
| `DOC_PARSE_SEGMENT_LENGTH` | 800–1200 字符 | 适配财报中长段落的运营说明，避免分段截断关键信息 |
| `RECALL_TOP_N` | 10–15 条 | 财报数据字段较多，需召回足够数量的上下文片段用于准确抽取 |
| `ENV_FILE_PATH` | `/opt/fastgpt/.env` | v4.8.13版本需指定环境变量文件路径，统一管理配置参数 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 访问页面时提示404错误，或局域网IP无法正常加载前端界面。原因是未正确配置`BASE_PATH`参数，同时未同步更新Nginx的反向代理配置，导致路由匹配失败。
- 文档解析任务超时失败，返回`504 Gateway Timeout`状态码。原因是未将`PARSE_FILE_TIMEOUT_SECONDS`调整至适配财报文档的取值，默认超时时间不足以完成长文档解析。
- 传入财报链接后无法解析出结构化字段，仅返回纯文本内容。原因是升级到v4.8.13版本后，未重新配置文档解析的字段抽取模板，导致原有适配影视院线财报的规则未生效。

## 怎么确认配好了
- 访问配置了二级目录的域名路径，确认前端界面正常加载，无404或502错误。
- 上传一份小型的院线运营日报文档，等待解析完成后，确认结构化字段被正确抽取。
- 修改`PARSE_FILE_TIMEOUT_SECONDS`参数后，提交一份体积较大的季度财报文档，确认解析任务未中途中断。
- 查看环境变量配置文件，确认v4.8.13版本的必填参数已正确填写，无缺失或格式错误。
