# 房建工程财报分析的工作流编排

## 这个品类的数据长什么样
房建工程财报数据主要来源于项目施工方的月度成本台账、甲方出具的进度款结算单、住建部门备案的项目财务档案，以及上市建筑企业披露的房建业务板块季度财报。数据更新节奏以月度为主，部分年度汇总财报按季度更新。文档多为结构化表格或带明细的PDF，包含分项工程费用、人力成本、材料采购额、机械使用费、税费等字段，单位以元、万元、平方米为主，部分明细字段标注施工节点对应的费用数值。

## 这些特征在「工作流编排」这一环带来什么约束
房建工程财报的数据来源分散，包含台账、结算单、备案档案等多种类型，要求工作流支持对接多数据源节点，统一处理不同格式的输入。月度更新的节奏要求工作流配置定时触发规则，按固定周期执行。文档包含结构化表格与非结构化PDF，需要同时配置结构化数据提取节点与PDF解析节点。细分字段较多，且不同来源的字段命名存在差异，要求工作流配置字段映射环节，完成跨来源的字段对齐。部分数据存在单位差异，需要配置单位转换节点，统一计量口径。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `定时任务间隔` | `每月1次，固定每月5日执行` | 匹配房建工程财报月度更新的发布节奏，确保数据获取的时效性 |
| `数据库连接超时时间` | `600 秒` | 房建工程财报数据多来自大型台账或汇总数据库，超时时间需适配大体积数据的读取流程 |
| `JSONPath提取规则` | `$..[?(@.分项工程名称 =~ /土建|安装/)]` | 针对房建工程财报的细分工程字段，定向提取指定类型的费用数据，减少无效信息干扰 |
| `PDF解析分段长度` | `800–1200 字符` | 房建工程财报PDF多包含长明细表格，分段长度适配长文本的解析与字段提取 |
| `字段映射匹配模式` | `按字段中文名匹配` | 不同来源的房建财报字段命名差异较大，中文名匹配模式更易完成跨来源的字段对齐 |
| `变量传递开关` | `开启` | 需将提取的分项费用数据传递至下游的汇总计算节点，符合财报分析的完整流程逻辑 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置HTTP请求节点后，界面无JSONPath提取变量的入口，无法将响应内容传递至下游节点。原因：未开启工作流的高级变量配置开关，或未在响应处理环节选择提取模式。
- 现象：尝试导出工作流配置时，系统提示无对应权限或功能未开放。原因：未绑定对应权限的工作流套餐，或未在项目设置中开启工作流导出功能。
- 现象：配置MSSQL数据库连接节点时，抛出报错`Failed to connect to jyfkk:1433 - 38BBDDC3AF7F0000`。原因：数据库地址配置错误，或本地防火墙阻断了1433端口的访问，导致无法建立连接。

## 怎么确认配好了
- 手动触发一次工作流，查看各节点的运行日志，确认数据源节点成功读取到房建工程财报的对应字段。
- 检查JSONPath提取节点的预览结果，确认提取的分项工程费用数据与源数据一致。
- 查看字段映射节点的输出结果，确认不同来源的字段已完成对齐。
- 验证变量传递环节，确认下游节点成功接收上游提取的费用变量。
