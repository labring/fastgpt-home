# 教育服务财报分析的模型接入与配置

## 这个品类的数据长什么样
教育服务品类的财报数据主要来自机构自主披露的经审计年度/半年度财务报告、办学备案公示信息，以及行业监管部门公开的办学运营数据。数据更新节奏为年度审计报告每年更新一次，季度运营数据每季度同步更新。文档结构通常包含营收明细、成本构成、现金流状况、在校生规模、校区布局等板块，字段涵盖具体营收金额、师资投入金额、场地租赁成本、在校学生人数，单位以人民币元、人次、校区数量为核心。

## 这些特征在「模型接入与配置」这一环带来什么约束
教育服务财报的多源分散数据特征，要求配置支持结构化表格与非结构化文本混合接入的适配规则，避免解析时出现字段遗漏或格式错乱。固定的更新节奏，要求配置定时同步任务以匹配年度、季度的数据更新周期，确保分析使用的始终是最新的财报数据。非标准化的办学相关字段，要求配置自定义字段映射与提取规则，适配不同机构披露的字段差异，避免因字段名称不统一导致的分析误差。单份财报文档长度较长的特征，要求配置长文本拆分与分段处理参数，避免超出模型上下文窗口限制，确保模型能完整读取财报内容。来自公开备案的数据，要求配置外网访问权限以拉取公示信息，补充本地存储的财报数据维度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `model_node_output_mode` | `仅返回任务结果` | 避免模型输出内容混入业务对话流，匹配财报分析的单一任务输出需求 |
| `external_access_enable` | `开启`或`关闭` | 需要拉取公开备案的外网办学数据时开启，仅使用本地存储的机构财报数据时关闭 |
| `text_chunk_size` | `800–1200 字符` | 适配教育服务财报较长的单份文档长度，同时匹配多数通用大模型的上下文窗口限制 |
| `schedule_sync_interval` | `90 天` 或 `365 天` | 匹配季度运营数据、年度审计报告的固定更新节奏 |
| `custom_field_mapping` | `按机构披露字段自定义配置` | 适配教育服务财报非标准化的办学相关字段，兼容不同机构的披露格式 |
| `response_format` | `json_object` 或 `按实测标定` | 需要结构化输出分析结果时使用json_object格式，适配下游数据对接场景 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置大模型节点后，任务结果混入对话流返回内容，界面调试时可见额外对话文本。原因：未将`model_node_output_mode`配置为`仅返回任务结果`，沿用了默认的对话式输出模式。
- 现象：拉取公开备案的办学数据失败，系统提示无法访问外部资源。原因：未将`external_access_enable`配置为`开启`，默认限制了外网访问权限。
- 现象：模型生成的财报分析内容出现虚构的办学数据或营收明细。原因：未对输入的财报文档进行长文本分段处理，导致模型仅读取部分内容，或未配置字段校验规则过滤未匹配的异常数据。

## 怎么确认配好了
- 上传单份教育服务财报文档，检查解析后的字段是否与原文披露内容匹配，确认字段映射配置符合预期。
- 手动触发一次数据同步任务，核对更新后的财报数据时间是否与配置的同步周期匹配，确认定时同步规则生效。
- 发起一次完整的财报分析任务，检查返回结果仅包含预设的分析内容，无额外对话类输出，确认输出模式配置生效。
- 尝试拉取公开备案的办学数据，检查是否能正常获取目标信息，确认外网访问权限配置符合需求。
