# 教育服务财报分析的部署与升级

## 这个品类的数据长什么样
教育服务财报数据主要来自机构内部运营台账、年度审计报告及属地教育主管部门备案的办学收支数据。更新节奏以季度为基础周期，年度会发布经审计的正式版本。文档多为多页PDF格式，包含固定字段：办学主体备案编号、在读学生规模、单生均收费标准、场地租赁成本、师资薪酬占比，单位涵盖元、万元、人、平方米等。

## 这些特征在「部署与升级」这一环带来什么约束
教育服务财报的多源数据特征要求部署时配置多数据源对接的权限与映射规则，避免数据同步缺失。季度更新的节奏要求设置定时同步任务的周期参数，确保财报数据及时更新。长文档PDF格式要求调整文件解析的超时与分段配置，适配复杂内容的解析流程。固定字段的结构要求自定义知识库的字段映射配置，防止通用解析导致的字段识别偏差。升级时需保留历史备案数据的导入逻辑，避免版本更新后历史财报无法正常读取。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 教育服务财报PDF通常页数多、内容复杂，常规超时时间不足以完成解析 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 年度审计财报PDF体积可能较大，需适配长文档上传需求 |
| `maxContext` | `8000–12000 字符` | 财报内容连贯且字段分散，需足够上下文保证分析的完整性 |
| `召回条数` | `前 8 条` | 财报包含多类业务字段，需召回足够知识库片段覆盖全部分析维度 |
| `相似度阈值` | `0.75–0.85` | 需过滤低相关的非财报类文档，保留精准的办学数据片段 |
| `定时同步任务周期` | `每 90 天` | 财报按季度更新，匹配基础更新节奏保障数据时效性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：上传教育服务财报PDF后显示「文件解析超时」，或解析后核心字段为空。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时间不足以完成长文档解析。
- 现象：多校区管理员无法访问专属财报数据，出现「权限不足」报错。原因：未配置多角色权限分组，默认开放全部数据访问权限。
- 现象：升级到4.8.20-fix2版本后，自定义PDF解析服务无法正常启动。原因：未在环境变量中配置`PDF_PARSE_SERVICE_URL`参数，或参数格式存在错误。

## 怎么确认配好了
- 上传一份测试用的教育服务财报PDF，检查解析后字段是否与预设的业务字段匹配完整。
- 测试不同角色的账号访问权限，确认非授权账号无法查看敏感财报数据。
- 触发一次定时同步任务，检查是否成功拉取最新的备案数据。
- 调用智能体API发起财报分析请求，检查返回结果是否覆盖全部核心业务字段。
