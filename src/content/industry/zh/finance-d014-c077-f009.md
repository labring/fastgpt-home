# 旅游景区财报分析的引用来源与溯源

## 这个品类的数据长什么样
旅游景区财报的数据来源覆盖文旅主管部门公开公示数据、景区官方披露的年度或季度运营报告、第三方文旅产业监测平台的公开数据。更新节奏为：季度运营数据每季度结束后30日内完成更新，年度财报则在次年4月30日前完成披露。文档多为结构化表格或PDF格式，包含游客接待人次、门票销售收入、配套业态营收、运营成本、净利润等字段，部分景区会披露索道、演艺、文创等细分业态的营收数据，单位多为人次与人民币元。

## 这些特征在「引用来源与溯源」这一环带来什么约束
首先，数据来源分散且包含网页、PDF、Notion文档等多种格式，要求溯源环节支持识别并校验不同类型的来源链接，包括网页链接与Notion文档链接。其次，财报数据存在固定的披露周期，需匹配对应时间范围的召回规则，避免调用未更新的历史数据。再者，财报包含细分业态的专属字段与明确单位，溯源环节需保留原始字段名与单位信息，确保引用时的内容一致性。另外，部分数据为PDF格式的结构化文档，需在解析时保留原始页码与段落位置，为溯源提供精准的定位依据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `RECALL_SOURCE_TYPE` | `["web","notion","pdf_parse"]` | 覆盖景区财报的常见来源格式，支持网页、Notion文档与PDF解析后的溯源 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 匹配景区财报的结构化特征，过滤低相关的非财报内容，同时保留细分业态的关联数据 |
| `MAX_RECALL_COUNT` | `前8条` | 适配景区财报的多来源数据量，避免召回过多无关内容，同时覆盖主要营收与成本项 |
| `PARSE_PDF_KEEP_PAGE` | `开启` | 保留PDF格式财报的原始页码信息，为溯源提供精准定位依据 |
| `SOURCE_LINK_VALIDATE` | `开启` | 校验所有召回来源的链接有效性，避免引用失效的第三方监测平台数据 |
| `CONTEXT_WINDOW_RESERVE` | `1200–1500 字符` | 保留原始数据的上下文信息，确保引用时的内容完整性，适配财报的长段落描述 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用后返回的引用内容包含未关联的非财报数据，或字段单位显示异常。原因：未配置`SIMILARITY_THRESHOLD`的合理区间，或未开启`SOURCE_LINK_VALIDATE`，导致召回了无关的景区动态内容。
- 现象：系统提示无法解析引用的Notion链接或网页链接。原因：未将`RECALL_SOURCE_TYPE`配置为包含对应来源类型，或未完成对应数据源的授权配置。
- 现象：召回的财报数据未显示原始页码或段落位置。原因：未开启`PARSE_PDF_KEEP_PAGE`配置，导致PDF解析时丢失溯源定位信息。

## 怎么确认配好了
- 上传一份景区财报的PDF文档，查看解析后的内容是否保留原始页码与段落标记，确认`PARSE_PDF_KEEP_PAGE`配置生效。
- 配置测试用的网页链接与Notion链接作为知识库来源，发起测试提问，查看是否能正确召回对应内容并显示来源链接，确认`RECALL_SOURCE_TYPE`配置覆盖对应类型。
- 调整`SIMILARITY_THRESHOLD`的取值，对比不同取值下的召回结果条数，确认取值符合景区财报的内容相关性要求。
- 查看系统日志，确认所有召回的来源链接均通过有效性校验，无失效链接被召回，确认`SOURCE_LINK_VALIDATE`配置开启。
