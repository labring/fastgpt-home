# 服装家纺财报分析的工作流编排

## 这个品类的数据长什么样
服装家纺行业的财报数据主要来源于境内证券交易所公开披露平台、公司官方投资者关系栏目。数据按固定周期更新：年度报告于次年4月30日前披露，半年度报告于当年8月31日前披露，季度报告于季后15日内披露。单份财报文档通常包含合并财务报表、管理层讨论与分析板块，其中服装家纺品类的专属字段包括品牌门店数量、直营加盟占比、单店坪效、面料采购成本、库存周转天数，对应单位分别为家、百分比、元/平方米/年、人民币元、天。

## 这些特征在「工作流编排」这一环带来什么约束
固定周期的披露节奏要求工作流需匹配财报发布节点设置定时触发，避免错过最新数据的分析时机。专属字段的存在要求信息抽取环节需针对服装家纺的经营指标做定制化实体识别，通用财报抽取模型无法精准定位这些细分字段。长文档的篇幅特性要求工作流需适配长文本拆分与上下文处理，防止超出大模型的上下文窗口限制。临时经营简报的高频更新还要求工作流支持非定时触发的手动或事件触发模式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–16000 字符` | 服装家纺财报拆分后的单段文本长度通常处于该区间，适配主流大模型的上下文窗口范围 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 长财报文档的解析耗时较长，预留足够时间避免解析过程超时中断 |
| `知识库召回条数` | `前 8 条` | 服装家纺财报的关联信息集中在少数经营字段，召回过多会引入无关内容干扰分析 |
| `钉钉webhook 节点配置` | `按团队运维提供的专属地址配置签名校验` | 需将分析结果推送至指定工作群，签名校验可避免非法请求拦截 |
| `HTTP节点BLOB响应处理` | `转为临时下载链接并绑定对话上下文` | 支持用户在对话框点击下载解析后的财报内容，满足结果交付需求 |
| `高级编排功能开关` | `按账号权限开启` | 未开启该权限时无法使用多节点串联的自定义工作流，限制复杂分析流程的搭建 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流执行后钉钉webhook无推送消息，状态码返回403。原因：未配置正确的钉钉webhook签名校验参数，导致请求被网关拦截。
- 现象：对话中无法点击下载BLOB格式的财报解析结果。原因：未将HTTP返回的BLOB对象转换为可公开访问的临时链接，仅在工作流本地缓存未对外暴露。
- 现象：工作流执行时提示「高级编排功能未启用」。原因：未在账号权限管理中开启高级编排功能开关，无法使用多节点串联的自定义工作流。

## 怎么确认配好了
- 手动触发一次工作流，查看执行日志中的解析时长，确认未超出预设的超时阈值。
- 向对话发送包含指定财报字段的问题，验证返回内容是否精准匹配预设的知识库条目。
- 向对话发送测试请求，验证是否可以点击生成的下载链接获取对应文件。
- 检查指定工作群是否收到工作流执行完成的推送消息，确认推送配置生效。
