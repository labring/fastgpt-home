# 水产养殖财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
水产养殖财报的数据来源包括各地水产技术推广站的塘口监测数据、上市养殖企业的公开披露报告、全国水产技术推广总站的行业统计报送。更新节奏覆盖旬度水质与投料数据、月度养殖产量数据、季度与年度综合财报。文档结构以结构化表格为主，包含塘口养殖面积、养殖品种、单位投料量、成活率、亩产量、饲料系数等字段，其中面积单位为亩，投料量与产量单位多为千克/亩或吨/公顷，饲料系数为无量纲比值。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多源数据来源要求接口支持跨平台拉取，需兼容不同数据源的鉴权方式与返回格式。不同时间粒度的更新节奏要求接口支持按旬、月、季、年等维度筛选数据，同时需处理数据重复覆盖的问题。专属字段与单位要求接口返回的原始数据需保留原生单位，避免平台自动转换导致的数值偏差。地域细分的数据特征要求接口支持按养殖区域、省份等参数进行数据过滤，减少无效数据拉取的开销。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `external_data_source_type` | 「结构化API数据源」 | 水产养殖财报数据多为标准化表格结构，适合通过API直接拉取结构化内容 |
| `api_request_timeout` | `300 秒` | 水产数据多需跨多源聚合，单次请求耗时较长，避免超时中断数据拉取 |
| `field_mapping_rule` | 按水产养殖财报标准字段映射 | 该品类存在专属字段如「亩产量」「饲料系数」，需与平台内置字段对齐以保障分析准确性 |
| `batch_fetch_interval` | `86400 秒` | 月度监测数据每日更新，按单日周期批量拉取可匹配数据更新节奏 |
| `api_auth_type` | `API Key 认证` | 多数外部水产行业数据接口采用密钥鉴权，符合通用安全配置规范 |
| `keyword_intercept_rule` | 按养殖品类、财报周期配置触发词 | 适配水产养殖财报分析的专属查询场景，精准触发外部接口调用 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
-  现象：调用外部数据源接口返回`401 Unauthorized`状态码，日志显示鉴权失败。原因：未正确配置`api_auth_type`参数，或未将生成的API密钥同步至外部数据源平台。
-  现象：知识库中关联的水产数据字段为空，或单位与预期不符。原因：未配置`field_mapping_rule`参数，未将外部接口返回的专属字段（如「投料量kg/亩」）映射为平台可识别的标准化字段。
-  现象：用户输入指定财报查询关键词后，未触发外部自定义接口，直接返回默认回答。原因：未正确配置`keyword_intercept_rule`参数，或未将自定义接口的回调地址录入平台外部服务配置。

## 怎么确认配好了
-  发起一次测试请求，查看返回的字段是否包含水产养殖财报专属字段，核对字段单位是否与预设要求一致。
-  使用独立的API调试工具调用配置好的外部接口，确认返回状态码为`200 OK`，且数据格式符合预期。
-  配置关键词拦截规则后，输入预设的触发关键词，查看平台是否调用外部自定义接口返回对应结果。
-  查看数据同步日志，确认按配置的`batch_fetch_interval`周期完成数据拉取与更新。
