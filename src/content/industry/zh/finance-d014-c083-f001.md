# 水务财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
水务行业财报数据主要来自上市水务企业的年度报告、季度公告及月度运营简报，更新节奏以季度为基础频率，年度报告需经审计后发布。文档结构包含通用财务报表模块，同时包含水务专属运营数据板块，字段涵盖供水销售量、污水处理量、管网总长度等，单位多为万立方米、公里、万元人民币，部分运营指标会标注报告期内的日均数据。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
水务财报的多模块结构与专属运营字段，要求HTTP接口需支持跨数据源拉取，同时兼容通用财务字段与供水销售量、管网长度等专属指标。季度与月度的差异化更新节奏，需要接口配置可调整拉取周期，适配不同报告频率的数据源。财报文档的长度差异，要求接口支持分页参数，避免单次返回数据超出传输阈值。同时，审计溯源的需求，要求接口返回数据需附带公告来源的唯一标识字段，确保数据可验证。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `api_request_timeout` | `300 秒` | 水务财报文档通常包含长段运营说明，该时长可覆盖数据拉取与初步解析流程，避免超时中断 |
| `rag_chunk_size` | `800–1200 字符` | 水务财报的运营数据文本较长，该区间可保证单块文本语义完整，同时避免块间信息割裂 |
| `external_data_source_type` | `structured + unstructured` | 水务财报同时包含结构化财务表格与非结构化运营描述，需同时适配两种数据格式的解析 |
| `field_mapping_rules` | `按财报模块分组映射` | 水务财报分为财务报表与运营数据两大模块，分组映射可避免字段混淆，提升检索准确性 |
| `api_pagination_enable` | `true` | 年度水务财报文档长度差异较大，分页拉取可降低单次接口负载，提升数据同步效率 |
| `data_update_cron` | `按数据源报告周期配置` | 水务财报按季度、月度更新，该配置可适配多频率的数据源同步需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用外部水务财报数据源接口时，返回「权限不足」错误，状态码403。原因：未配置第三方数据源的API密钥授权，仅使用平台内置积分调用接口，未绑定对应数据源的访问权限。
- 现象：知识库召回的水务财报数据字段缺失，例如缺少「管网总长度」指标。原因：未在字段映射规则中配置专属运营字段的映射关系，仅同步了通用财务字段。
- 现象：接口拉取数据超时，返回504状态码。原因：未调整接口超时时间，默认超时时长不足以覆盖长文档的拉取与解析流程。

## 怎么确认配好了
- 发起一次测试接口调用，检查返回数据是否包含水务专属运营字段与通用财务字段，核对字段单位是否符合品类特征。
- 查看接口日志，确认拉取周期与配置的`data_update_cron`一致，无异常超时或重复拉取记录。
- 测试分页拉取功能，确认返回数据可按配置的分页参数拆分，无单次返回数据过大的情况。
- 验证数据源的权限配置，发起跨账号调用测试，确认第三方数据源的访问权限已正常绑定。
