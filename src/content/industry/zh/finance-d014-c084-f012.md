# 水处理财报分析的模型接入与配置

## 这个品类的数据长什么样
水处理企业的财报分析数据主要来自环保监管部门的强制报送数据、企业内部运维日志系统、第三方水质监测机构公开报告。数据更新节奏分为小时/日度的日常运维明细数据，以及季度、年度的正式财报汇总文档。单份财报文档通常包含进水水质指标、出水达标情况、药剂投加量、能耗成本、运维人力成本等结构化字段，单位涵盖mg/L、kg、kWh、元等细分计量标准，部分文档还会附随现场监测的图片附件。

## 这些特征在「模型接入与配置」这一环带来什么约束
水处理财报分析的数据特征对模型接入与配置带来明确约束。多源异构的数据来源需要配置多向量库索引，分别适配结构化监管字段、非结构化运维日志与图片附件。小时级的日常运维明细数据量较大，需要调整向量入库的批次参数，避免单批次处理超时。部分财报附带现场监测图片，需要配置支持图片理解的模型接口，并调整图片预处理参数以适配模型输入要求。结构化字段的特定计量单位，需要在系统prompt中明确标注，避免模型混淆不同指标的数值含义。同时需控制长文档的分段长度，适配财报的长文本解析需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_MAX_SIZE` | `1000 MB` | 水处理财报常包含多份历史监测数据附件，需适配大文件上传需求 |
| `maxContext` | `8000–12000 字符` | 单份季度/年度财报文档通常超过万字，需适配长上下文处理 |
| `vectorStore_batchSize` | `50–100 条/批` | 日度运维明细数据条目较多，调整批次大小避免向量入库超时 |
| `imageUnderstanding_enable` | `开启` | 部分财报附带现场水质监测图片，需支持多模态内容解析 |
| `retrieval_topK` | `前 8–12 条` | 财报分析需召回多维度指标数据，避免遗漏关键关联信息 |
| `system_prompt` | 固定包含「所有数值需标注对应计量单位」的约束 | 水处理指标包含mg/L、kg、kWh等多样单位，明确模型输出规范 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：自定义向量模型接入后，调用时始终触发大语言模型，未触发向量检索。原因：未在渠道配置中明确指定模型类型为向量检索，或未将向量模型与大语言模型分配至独立的调用链路。
- 现象：调用指定模型时返回测试失败，接口返回403状态码。原因：未配置正确的API访问密钥，或请求域名未添加至系统白名单。
- 现象：设置多轮对话轮次参数后，模型无法保留上一问题的关联信息。原因：未同步调整上下文窗口参数匹配对话轮次配置，或未开启会话上下文持久化开关。

## 怎么确认配好了
- 上传一份包含结构化字段和图片附件的测试财报，查看向量库索引列表，确认对应文档已被拆分并生成向量嵌入。
- 发起包含多轮提问的测试会话，核对模型是否能关联前一轮提问的指标参数进行回答。
- 运行模型调用测试接口，查看返回结果是否标注了所有数值对应的计量单位。
- 查看系统日志，确认向量检索请求与大语言模型请求分别调用了对应配置的模型接口。
