# 汽车服务财报分析的引用来源与溯源

## 这个品类的数据长什么样
面向金融领域的汽车服务品类财报数据，主要来自公开披露的汽车经销、维修服务及汽车金融企业年度/半年度财报、汽车流通行业协会月度经营数据报告，以及门店月度经营台账。公开财报按季度或年度更新，行业报告与内部台账按月度更新。文档结构包含合并营收、成本明细、经营分部数据，字段涵盖单店营收、客单价、维修工时费、配件采购成本，单位统一为人民币元或万元，无额外非标单位。

## 这些特征在「引用来源与溯源」这一环带来什么约束
面向金融领域的汽车服务财报，数据来源分散，包含公开披露文件、行业协会报告与门店内部台账，不同数据源的更新节奏差异较大，要求引用溯源环节区分数据源的时效性与可信度，同时符合金融监管的合规要求。文档包含多业务板块的明细数据，需精准匹配用户查询的业务场景，避免召回无关分部的内容。字段维度较细，需限制单条召回内容的字段范围，防止冗余信息干扰回答。此外，内部台账属于非公开数据，需在溯源时明确标注数据源类型，确保合规性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前8条` | 汽车服务财报的业务板块较多，需覆盖维修、销售等多个场景的相关数据，8条可平衡召回覆盖度与信息冗余 |
| `相似度阈值` | `0.75–0.85` | 财报数据的专业术语较多，该区间可兼顾专业语义的召回精准度与场景覆盖度 |
| `重排返回条数` | `前5条` | 单条财报数据的字段较多，限制返回条数可避免信息过载，同时保留核心明细内容 |
| `分段长度` | `800–1200 字符` | 财报文档的明细段落较长，该分段长度可保留完整的业务板块数据，避免截断关键信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 大型财报文档的解析耗时较长，300秒可覆盖多数公开财报与行业报告的解析需求 |
| `引用模板` | `按数据源标注来源+文档标题+章节号` | 汽车服务财报的数据源类型多样，明确标注可提升溯源的合规性与可读性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：连续发起多轮查询后，后续问题引用的数据源与前序查询的业务场景无关，回答答非所问。原因：未启用上下文关联召回配置，仅基于当前单条查询独立检索，未继承前序的业务场景关键词。
- 现象：解析大型财报文档时触发`408 Request Timeout`或`504 Gateway Timeout`错误。原因：`PARSE_FILE_TIMEOUT_SECONDS`配置值过低，未覆盖大型财报文档的实际解析耗时。
- 现象：召回的引用内容包含无关的业务板块数据，未匹配用户查询的具体场景。原因：未配置按业务板块的过滤规则，或`相似度阈值`取值过低，召回了语义关联较弱的内容。

## 怎么确认配好了
- 上传一份汽车服务企业的公开财报文档，触发解析后查看解析后的分段内容，确认分段长度符合预设配置。
- 发起包含具体业务场景的查询，查看召回的引用条数与数据源标注是否符合配置要求。
- 发起连续多轮查询，确认每轮查询的引用数据源均与当前查询的业务场景匹配，无跨场景的无关内容。
- 查看知识库的配置面板，确认`相似度阈值`、`PARSE_FILE_TIMEOUT_SECONDS`等参数的取值与预设配置一致。
