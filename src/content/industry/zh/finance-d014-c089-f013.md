# 油气开采财报分析的知识库检索与召回

## 这个品类的数据长什么样
油气开采行业的财报数据主要来源于上市油气企业的年度、季度公开财报，油气行业监管机构发布的开采许可、生产统计月报，以及油田运营方的内部生产记录。数据更新节奏分为季度（财报）、月度（生产数据）与年度（储量评估报告）三类。文档结构通常包含勘探开发成本拆分、油气当量产量、单井生产数据、资本支出、储量替代率等模块，字段单位多采用油气当量桶（boe）、立方米、桶、美元或万元人民币等专业计量标准。

## 这些特征在「知识库检索与召回」这一环带来什么约束
专业术语密集的字段要求检索系统具备专业语义匹配能力，避免通用财务内容干扰结果；多更新频率的文档需要按时间戳过滤召回范围，确保返回最新的生产与财报数据；长文档结构要求切分时保留上下文关联，防止割裂专业术语所在的完整语义单元；多维度的字段内容需要精准匹配查询意图，例如用户查询单井产量时，需召回对应字段的内容，避免混杂无关的资本支出数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `分段长度` | `800–1200 字符` | 油气财报文档包含长句与专业术语，过长会导致上下文关联丢失，过短会割裂语义单元，该区间可平衡切分粒度与语义完整性 |
| `召回条数` | `前6–8 条` | 油气财报相关查询需覆盖储量、成本、产量等多个维度的信息，该取值可在上下文窗口限制内覆盖核心需求 |
| `相似度阈值` | `0.72–0.78` | 专业术语的语义相似度要求高于通用内容，该区间可过滤低匹配度的无关文档片段 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 单份油气年报或行业报告体积较大，解析过程需要更长时间，避免因超时导致文档解析失败 |
| `重排返回条数` | `前3–4 条` | 需保留最相关的核心数据内容，避免过多冗余信息占用上下文窗口 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 单份行业研究报告或大型油田财报的体积通常较大，该取值可适配常规上传需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：知识库管理页面可查看所有上传文档内容，但发起对话时模型提示知识库无可用内容。原因：迁移知识库时未完成向量索引的重建流程，或未正确关联知识库到对应应用的工具调用配置。
- 现象：上传单份油气财报文档后，系统提示切分块数超过3000，无法完成索引。原因：未调整`分段长度`参数扩大单块字符数，或未开启多文档分块聚合配置，导致单文档块数超限。
- 现象：发起包含油气专业术语的查询时，检索结果中混杂大量非相关的通用财务内容。原因：未设置合理的相似度阈值，导致低相似度的无关内容被召回。

## 怎么确认配好了
- 查看向量索引的生成日志，确认所有上传的油气财报文档均已完成向量化处理，无失败条目。
- 发起包含油气专业术语的测试查询，核对检索结果中是否包含对应字段的内容，调整相似度阈值以过滤无关结果。
- 测试多文档混合检索，确认不同更新频率的文档（如季度财报与月度生产数据）均可按时间戳被正确召回。
- 验证工具调用配置，确认知识库已被关联到对应应用的检索环节，无配置遗漏。
