# 涂料油墨财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
涂料油墨品类的财报数据主要来自上市公司定期报告、行业协会公开统计数据及第三方基础化工数据平台。数据更新节奏分两类：上市公司财报按季度、年度同步更新，行业供需数据按月度更新。单份财报文档结构包含核心财务指标、原材料采购占比、产能产量明细、环保合规支出等字段，其中原材料价格字段单位多为元/千克，产能单位为吨/年，营收明细字段以万元为计价单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
涂料油墨品类的财报数据特征，对HTTP接口与外部系统对接带来明确约束。多来源数据需适配不同鉴权规则，行业协会数据接口需配置专属API密钥，上市公司财报接口需确认合规的官方数据调用权限。不同更新节奏要求定时同步任务的触发周期匹配，季度财报同步需设置季度级触发，月度行业供需数据需按月触发。多字段的结构化解析需求，要求接口返回格式支持指定字段精准提取，同时需在数据流转环节增加单位一致性校验，避免跨来源数据单位不匹配导致的分析偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 单份涂料油墨财报PDF通常包含多页财务明细，300秒可覆盖完整解析与接口请求时长 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 单份年度财报PDF体量多在100-150 MB区间，200 MB预留合理余量 |
| `REQUEST_RETRY_TIMES` | `3 次` | 第三方化工数据接口偶发波动，有限重试可降低同步失败概率 |
| `SYNC_CRON_PATTERN` | `"0 0 3 * * 2"` | 上市公司财报通常在季后15日内披露，每周二凌晨3点同步可覆盖最新公开数据 |
| `FIELD_FILTER_LIST` | `["原材料采购占比", "产能利用率", "营收分类"]` | 聚焦涂料油墨财报核心分析字段，过滤非必要内容提升接口处理效率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：接口调用时返回`413 Request Entity Too Large`错误。原因：未正确配置`UPLOAD_FILE_MAX_SIZE`参数，导致超过阈值的财报文件被拦截。
- 现象：调用外部重排接口后返回空内容，结构化分析结果缺失。原因：未针对涂料油墨财报的长文本配置合理的召回条数参数，超出接口最大返回条数限制。
- 现象：定时同步任务触发后返回`504 Gateway Timeout`错误。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，长文档解析时长超过接口网关限制。

## 怎么确认配好了
- 发起单份标准体量财报文件的接口调用测试，检查返回结果是否包含预设的核心分析字段。
- 查看定时同步任务的执行日志，确认任务触发周期与预设的更新节奏匹配。
- 模拟第三方接口临时异常的场景，检查是否按配置的重试规则触发重试流程。
- 抽取接口返回的部分数据字段，对比预设的单位规则，确认单位一致性校验正常生效。
