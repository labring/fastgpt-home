# 游戏财报分析的工具调用与插件

## 这个品类的数据长什么样
数据来源包括证券交易所公开披露的上市游戏公司定期报告、行业第三方监测机构的游戏业务细分数据；更新节奏为季度财报每3个月更新一次，年度财报每年更新，部分月度业务数据按自然月更新；文档结构通常包含合并财务报表板块，以及游戏业务专项说明章节，涵盖自研游戏收入、代理游戏分成、用户付费相关数据；字段包含营收金额（单位为人民币元或万元）、付费用户数（单位为人）、平均每用户流水（单位为元）、研发投入金额（单位为万元）等，部分报告还包含新游上线周期、版本更新频率相关的业务字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散且包含结构化与非结构化内容，要求工具调用同时支持数据库查询与文档解析能力；固定的更新节奏要求插件配置定时触发任务，确保每次调用获取最新披露的财报数据；包含通用财务与游戏专项的文档结构，要求工具支持按指定板块精准召回数据，过滤无关字段；字段单位存在元与万元的差异，需要插件配置统一的单位转换规则；部分月度业务数据更新频率更高，要求工具支持按时间范围精准筛选，避免混入过期数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `plugin_data_source_type` | `structured_db + unstructured_doc` | 游戏财报包含结构化财务数据和非结构化的业务专项说明，需同时支持两类数据源调用 |
| `trigger_schedule` | `daily 09:00`（财报披露窗口期）或`on_demand` | 季度财报按固定周期披露，按需调用可确保获取最新数据，日常可按需触发 |
| `data_filter_tags` | `game_business_section` | 游戏财报包含通用财务与游戏专项板块，按业务板块筛选可过滤无关数据，提升分析精度 |
| `unit_conversion_mode` | `uniform_to_ten_thousand_yuan` | 游戏财报中营收金额同时存在元与万元单位，统一转换为万元可简化后续分析逻辑 |
| `api_request_timeout` | `300 秒` | 多数据源调用需等待数据库查询与文档解析完成，300秒可覆盖多数常规调用场景 |
| `cors_allowed_origins` | `["https://your-platform-domain.com"]` | 限制跨域访问来源，确保服务端调用安全合规 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：数据库查询插件返回`500 Internal Server Error`，日志显示`invalid table name`。原因：未针对游戏财报的专项业务表配置查询权限，插件尝试调用通用财务表导致匹配失败。
- 现象：API调用服务时前端控制台抛出跨域错误，无法接收插件返回结果。原因：未配置正确的跨域允许域名列表，服务端未放行调用方的访问来源。
- 现象：模型输出的财报分析结果无法自动生成结构化文档，仅返回纯文本片段。原因：未启用文档生成插件的格式转换配置，未指定输出为适配财报的表格或分栏格式。

## 怎么确认配好了
- 触发一次插件调用，查看返回数据的字段是否仅包含预设的游戏业务板块内容，核对字段单位是否统一。
- 调用API接口，使用非允许域名发起请求，确认是否返回跨域拦截提示；使用允许域名发起请求则正常返回结果。
- 配置定时触发任务，等待预设时间后查看数据更新记录，确认是否按计划获取了最新的财报数据。
- 发起文档生成请求，查看输出结果是否包含预设的表格格式与业务字段，确认格式符合预期。
