# 热力财报分析的工作流编排

## 这个品类的数据长什么样
热力品类的财报数据主要来源于企业ERP财务模块、能源计量系统的采集数据及公开监管报表。更新节奏匹配财季、财年的财报披露周期，同时支持运营级数据的周度更新。文档以结构化报表为主，包含业务板块营收、供热量、单位供热成本、燃料采购成本、产能利用率等字段，供热量单位为吉焦（GJ），供热面积为万平方米（万㎡），营收单位为人民币万元，单位供热煤耗单位为千克标准煤/吉焦（kgce/GJ）。

## 这些特征在「工作流编排」这一环带来什么约束
热力品类的财报数据兼具结构化财务字段与非结构化计量报表，且指标单位存在行业专属规范，这为工作流编排带来三点约束。需配置多源数据接入节点，适配异构数据格式。需内置单位校验环节，统一供热量、能耗等指标的计量标准，避免跨数据源的单位偏差。需按财季、财年的固定周期配置调度触发，匹配财报披露节奏，同时支持运营级数据的周度触发需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `workflowTriggerMode` | `按财季定时触发 + 手动触发` | 匹配热力财报按财季披露的更新节奏，同时支持临时数据校验的手动执行 |
| `retrievalTopK` | `前8条` | 热力财报的能耗、营收指标关联度高，召回过多会引入无关数据，过少则无法覆盖业务关联维度 |
| `similarityThreshold` | `0.72–0.78` | 热力行业指标术语专业性强，需平衡召回精准度与覆盖度，避免遗漏关键业务字段 |
| `variableScope` | `用户级` | 不同热力企业的供热面积、基准能耗指标存在差异，用户级变量可实现同配置下的多租户适配 |
| `parseFileTimeoutSeconds` | `600 秒` | 热力财报的计量报表可能包含多页历史数据，解析耗时较长，需预留足够超时时间 |
| `maxContext` | `800–1200 字符` | 热力财报的业务指标描述简洁，适配该长度可保留核心业务信息 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：知识库检索节点无法引用配置好的全局变量`datasetId`，界面显示「变量未找到」。原因：未在工作流全局变量设置中开启该变量的全局访问权限，或变量名称拼写与配置时不一致。
- 现象：基于问题分类的工作流测试时，仅第一个分类分支能返回知识库引用结果，后续分支无匹配内容。原因：后续分类分支未正确绑定知识库检索节点，或未将分类后的查询参数传递至检索节点。
- 现象：工作流中配置的AI对话节点输出内容无法隐藏，所有节点结果均展示在最终交互界面。原因：未在AI对话节点的高级配置中关闭「结果输出」开关，或未使用节点隐藏容器功能。

## 怎么确认配好了
- 触发工作流的定时调度任务，查看调度日志中数据接入节点的字段校验结果，确认单位与业务指标匹配。
- 切换不同测试用户ID，运行工作流，查看变量值是否按用户隔离，无跨用户数据串用。
- 配置测试用的热力财报样本，运行工作流，检查AI生成的分析报告是否包含供热量、单位煤耗等核心指标。
- 查看工作流的节点运行日志，确认所有节点未触发超时报错，检索召回条数符合配置的`前8条`。
