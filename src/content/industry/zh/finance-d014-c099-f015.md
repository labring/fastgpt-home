# 燃气财报分析的部署与升级

## 这个品类的数据长什么样
燃气行业财报数据主要来自上市燃气企业公开年报、季度报告，以及属地能源监管机构发布的月度运营简报。数据更新节奏以年度、季度为核心周期，部分区域运营数据按月更新。文档结构包含核心经营指标、管网基建数据、用户规模、成本构成等模块，字段包括燃气销售量（单位：立方米）、管道长度（单位：千米）、终端用户数（单位：万户）、单位供气价格（单位：元/立方米）等，部分财报还会附带区域燃气运营的定性描述。

## 这些特征在「部署与升级」这一环带来什么约束
燃气行业财报数据的多源分散特性，要求部署阶段配置多数据源接入的并发控制参数，避免同时拉取多个公开公告导致接口限流。不同周期的更新节奏，需要在升级时调整定时同步任务的调度规则，区分年度、季度、月度数据的触发频率。字段与单位的特异性，要求部署时配置文档解析的字段映射模板，匹配燃气行业专属的指标名称与单位格式，避免解析后出现字段错位或单位混乱。部分财报附带区域运营的定性描述，需要在升级时调整内容召回阈值，优先提取结构化经营指标，聚焦核心业务数据。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 燃气财报PDF通常包含多页结构化表格与图表，需更长时间完成完整解析 |
| `UPLOAD_FILE_MAX_SIZE` | `600 MB` | 上市燃气企业年度财报PDF体积通常可达数百兆，需适配大文件上传需求 |
| `分段长度` | `800–1200 字符` | 燃气财报字段多为结构化指标，分段长度适配财报中长文本的成本说明与运营数据段落 |
| `相似度阈值` | `0.75–0.85` | 需精准匹配燃气行业专属指标名称，避免召回非相关的通用财报内容 |
| `召回条数` | `前 6 条` | 燃气财报核心指标集中在前三分之一章节，召回适量条目可平衡精度与响应速度 |
| `SYNC_DATA_CRON` | `0 0 2 * * *` 与 `0 0 1 * * 1,2,3` | 分别适配季度财报的每周同步与年度财报的月度同步需求，匹配燃气行业数据更新周期 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：使用docker部署fastgpt:v4.14.5.1时容器持续重启，前端页面无法加载。原因：未正确挂载本地存储目录以持久化配置与会话数据，导致容器启动后无法读取必要文件。
- 现象：配置API密钥后发现无法限制使用时长与调用次数。原因：社区版默认未开启API密钥的权限管控模块，需手动启用对应配置项或插件。
- 现象：上传燃气财报后解析结果出现字段错位。原因：未加载燃气行业专属的文档解析模板，使用通用财报解析规则导致字段匹配错误。

## 怎么确认配好了
- 上传一份本地保存的燃气企业财报PDF，查看解析后的字段列表是否包含燃气销售量、管道长度等专属指标，确认字段映射配置生效。
- 手动触发一次定时同步任务，查看数据源拉取的日志是否包含对应周期的财报数据，确认调度规则匹配行业更新节奏。
- 调用测试API传入燃气财报相关的查询词，查看返回结果的召回条数与相似度是否符合预设配置。
- 重启部署容器后检查服务运行状态，确认无端口冲突或配置文件读取失败的报错。
