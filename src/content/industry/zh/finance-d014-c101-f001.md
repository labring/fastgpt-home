# 物流财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
物流财报分析的数据主要来自企业内部运单管理系统、仓储节点监控平台、第三方货运数据接口及监管要求的年度/季度财报模板。数据更新节奏分为两类：日常运营数据按周更新，季度/年度财报数据按官方披露周期更新。单份文档包含运单总数量、干线运输单位成本、仓储周转率、单均配送时长、营收拆分项等字段，其中运单量单位为“单”，运输成本单位为“元/单”或“万元”，周转率单位为“次/周期”，时长单位为“小时”。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
物流财报分析的多源数据特征，对HTTP接口与外部系统环节带来多重约束。多源数据接入需适配不同第三方接口的鉴权规则，部分货运数据接口需专用API密钥，且调用频率存在上限。按周更新的运营数据体量较大，单次拉取需配置分页参数避免超时。季度财报的结构化字段较多，需在请求中指定明确的字段筛选条件，减少无效数据传输。敏感运营数据需启用HTTPS加密传输，同时配置访问白名单限制调用来源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 物流财报常包含批量运单表格、仓储报表，单份文件通常不超过800MB |
| `API_REQUEST_TIMEOUT` | `300 秒` | 多源数据拉取需拼接多个接口返回结果，耗时较长 |
| `FIELD_FILTER_RULE` | `按财报披露模板指定字段` | 物流财报有固定披露字段，避免返回冗余数据 |
| `CRON_SCHEDULE` | `0 2 * * 1` | 日常运营数据按周更新，每周一拉取上周完整数据 |
| `HTTPS_ENCRYPT_ENABLE` | `true` | 物流数据包含运营敏感信息，需加密传输 |
| `WHITELIST_IP_RANGE` | `企业内部网段+授权第三方IP` | 限制接口访问来源，保障数据安全 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：使用fetch调用`/api/v1/chat/completions`接口时返回`403 Forbidden`或跨域错误提示。原因：未配置接口跨域白名单，或白名单未包含前端部署域名。
- 现象：上传包含长文件名的物流运单表格时返回`400 Bad Request`错误。原因：接口未配置长文件名处理规则，服务器对文件名长度默认限制为255字符。
- 现象：通过Markdown上传图片时无法获取`/api/system/img/xxx.png`格式的可访问URL，或调用语音上传接口提交物流运营语音记录时返回失败。原因：未开启文件上传的路径映射配置，或未配置静态资源访问路由及对应文件类型的上传权限。

## 怎么确认配好了
- 调用测试接口拉取单份物流运营数据，检查返回字段是否包含预设的财报披露项，确认字段筛选规则生效。
- 上传单份符合配置上限的物流报表文件，检查上传进度及返回结果，确认文件大小限制配置生效。
- 配置定时拉取任务后，等待一个更新周期，检查数据是否按计划更新，确认CRON调度配置生效。
- 从非白名单IP调用接口，检查是否返回访问受限提示，确认白名单配置生效。
