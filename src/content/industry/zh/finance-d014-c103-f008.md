# 环境监测财报分析的工具调用与插件

## 这个品类的数据长什么样
环境监测相关财报数据多用于金融机构的企业ESG评级、授信审批等场景，主要来源于公开生态环境监测站点API、企业自有环保传感器网关、第三方环境数据服务商接口。实时点位数据的更新节奏为每1至5分钟一次，月度汇总财报数据则固定在每月5日前发布。文档结构包含监测点位标识、污染物类别、采样浓度、采样时间、合规判定结果、点位经纬度等字段。浓度值的单位为μg/m³，采样时间采用ISO 8601格式，合规判定字段为布尔值或枚举类型，部分数据源还会附带点位所属行政区域信息。

## 这些特征在「工具调用与插件」这一环带来什么约束
实时点位数据的高频更新要求工具调用的轮询间隔不超过采样周期，避免获取到重复或过期数据。月度汇总财报数据的固定发布周期，要求插件配置的定时触发任务时间与数据发布节奏对齐，确保拉取到完整的月度统计数据。字段包含经纬度、污染物代码等格式敏感内容，要求工具调用时增加参数校验逻辑，确保传入的点位标识、污染物代码符合数据源的预设规则。合规判定字段的枚举类型，要求插件支持对返回结果的字段映射，将原始枚举值转换为财报分析所需的标准化文本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_poll_interval` | `60 秒` | 环境监测实时数据采样周期多为1-5分钟，60秒轮询可覆盖多数点位的更新节奏，同时避免频繁调用超出接口限额 |
| `batch_fetch_window` | `30 天` | 环境监测财报分析多以月度为统计周期，30天窗口可覆盖完整月度数据的拉取需求，同时避免单次拉取数据量过大 |
| `param_validation_enabled` | `开启` | 环境监测数据包含经纬度、污染物代码等格式敏感字段，开启参数校验可过滤无效请求，降低调用失败率 |
| `plugin_timeout` | `120 秒` | 环境监测数据可能涉及多点位批量拉取，120秒超时可覆盖多数批量请求的处理时长，避免中途中断 |
| `stop_sequence` | `["<|endoftext|>", "数据结束"]` | 环境监测财报分析的输出内容较长，结合大模型原生停止符与业务专属标记，可确保生成内容精准截断 |
| `field_mapping_rule` | `按数据源预设字段映射` | 不同环境监测数据源的字段名称存在差异，按预设规则映射可确保财报分析所需的字段完整且格式统一 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 配置`stop_sequence`时仅添加大模型原生停止符，未添加业务专属结束标记，导致输出内容超出预期范围。原因是环境监测财报数据的输出长度较长，仅依赖大模型原生停止符可能无法精准截断，需补充业务专属标记。
- 调用第三方环境数据接口时返回`404 Not Found`错误。原因是未正确配置接口路径或模型版本参数，导致请求指向不存在的API端点。
- 本地部署FastGPT运行代码插件时抛出`AxiosError 404`。原因是插件代码中配置的后端服务地址错误，或对应接口未正确部署启动。

## 怎么确认配好了
- 发起单次工具调用请求，检查返回的环境监测数据字段是否与数据源预设结构一致，核对经纬度、浓度值的单位是否符合预期。
- 查看工具调用日志，确认轮询间隔与配置的`tool_poll_interval`一致，无频繁或超时的调用记录。
- 触发批量拉取任务，检查返回的数据量是否与设定的`batch_fetch_window`匹配，无缺失或冗余的统计周期数据。
- 测试插件的停止序列配置，观察大模型生成的内容是否在业务专属结束标记处停止，无额外冗余输出。
