# 玻璃财报分析的知识库检索与召回

## 这个品类的数据长什么样
玻璃品类的财报相关数据主要来自行业协会月度生产通报、上市公司定期报告及公开招投标数据。数据更新节奏分为月度、季度与年度三类，月度数据含出厂均价、产能利用率，季度与年度数据含营收结构、单位生产成本、毛利率等核心指标。文档多为结构化表格与文字分析结合，字段包含产品类型、产量、单价、营收构成、能耗指标等，单位多为吨、元/平方米、万元、千克标准煤/重量箱等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
玻璃品类的财报数据混合了高频月度指标与低频年度财报，要求检索环节支持按更新时间、数据类型进行精准过滤。结构化字段多且单位不统一，需在召回前自动对齐单位，避免因单位差异导致无效召回。长文档包含多产品类别的数据，分段处理时需保留产品类型与时间标签，确保检索结果能匹配到对应细分品类的内容。行业数据与企业财报混合存储，需通过数据源标签区分，防止跨主体数据混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 玻璃财报文档包含长表格与多页图文，解析耗时高于通用文档 |
| `分段长度` | `800–1200 字符` | 玻璃财报结构化字段密集，分段需保留字段关联完整性，避免拆分破坏数据逻辑 |
| `召回条数` | `前 8 条` | 玻璃财报分析需覆盖产量、价格、成本等多维度指标，需足够召回量支撑匹配 |
| `相似度阈值` | `0.72–0.80` | 结构化数据的字段匹配需兼顾精准度，避免召回跨品类或不相关的玻璃品类数据 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 年度行业汇编与企业财报文档体积较大，需放宽上传限制 |
| `重排返回条数` | `前 4 条` | 优先返回最相关的结构化数据，提升财报分析的检索效率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：知识库上传含内嵌图片的玻璃财报文档后，检索结果中图片无法正常显示。原因：默认解析配置未开启图片索引与存储，仅提取了文字内容，图片链接未被纳入检索库。
- 现象：上传javadoc生成的HTML接口文档后，知识库未解析出结构化接口字段与参数。原因：默认文档解析器仅支持纯文本与标准表格格式，HTML内嵌的动态渲染内容无法被直接识别。
- 现象：检索玻璃品类的特定产能指标时，召回结果条数远低于预期。原因：召回条数配置过低，未覆盖足够多的相关文档片段，导致部分细分数据未被召回。

## 怎么确认配好了
- 上传一份小型玻璃月度财报文档，查看知识库解析后的分段内容，确认分段长度符合预设配置。
- 发起包含玻璃品类特定指标的检索请求，核对召回结果的数量与相关性是否匹配业务需求。
- 上传一份体积较大的年度行业汇编文档，确认上传未触发文件大小限制相关的报错。
- 检索包含内嵌图片的玻璃财报文档，确认检索结果中包含图片的关联信息（若已开启图片索引配置）。
