# 生物制品财报分析的多轮对话与提示词

## 这个品类的数据长什么样
生物制品企业的财报数据主要来自境内外证券交易所披露的定期报告、临时公告，以及企业官方披露的研发管线、批签发信息。更新节奏遵循监管要求，季度报告于季度结束后45日内披露，年度报告于年度结束后120日内披露，临时公告随重大事件实时更新。文档结构包含合并财务报表、主营业务收入拆分（按疫苗、血制品、单抗等细分品类列示具体营收金额）、研发投入明细、临床管线进度、管理层讨论与分析等模块。字段涵盖营收金额、批签发数量、单剂定价、研发阶段、临床时间节点等，单位多为人民币元、万剂、万元，以及日期格式。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
生物制品财报的数据分散来源与复杂结构，对多轮对话与提示词配置带来多重约束。首先，不同数据源更新节奏差异较大，定期报告的静态数据与批签发、临时公告的动态数据需在对话中区分调用，提示词需明确指定数据源的时间范围与类型。其次，细分品类的营收拆分、研发管线等字段需精准定位，提示词需限定提取范围，避免混淆不同生物制品子类的业务数据。此外，多字段的单位差异要求对话过程中需统一单位校准，提示词需明确要求输出结果附带对应单位。最后，跨模块的业务关联，如临床进度与对应营收贡献，需要保留上下文记忆，多轮对话需配置足够的上下文窗口长度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–16000 字符` | 生物制品财报包含多模块细分内容，多轮对话需保留多回合业务关联上下文，避免上下文溢出 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 财报文档含细分营收拆分、研发管线明细等长内容，解析耗时较长，需延长超时时间 |
| `召回条数` | `前 8–10 条` | 生物制品财报的细分字段较多，需召回足够的细分数据支撑精准对话 |
| `相似度阈值` | `0.75–0.85` | 需过滤行业通用非财报数据，精准匹配生物制品财报的专属字段与内容 |
| `工作流全局变量` | `按数据源分类配置` | 生物制品财报数据来自定期报告、批签发、研发管线等多类来源，需分类传递参数 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 年度财报文档包含完整业务明细，单文件体积较大，需适配上传上限 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流运行后，AI对话节点的输入字段为空，无法读取代码运行节点的输出内容。原因：未将代码节点的输出结果绑定至对话节点的输入参数，未配置工作流的变量传递规则。
- 现象：多轮对话中输出的营收数据包含非目标品类的业务金额，或未按指定细分品类拆分。原因：提示词未明确限定提取的生物制品子类范围，未关联对应财报文档的细分字段。
- 现象：升级至v4.8.10版本后，仅包含十几个字的提问，回答直接一次性输出完整内容，未采用流式返回。原因：未配置`stream_response`参数为启用状态，或上下文窗口设置超出模型支持范围导致提前终止流式输出。

## 怎么确认配好了
- 上传单份年度财报文档，检查知识库解析结果是否包含细分营收拆分、研发管线等目标字段，确认解析配置符合业务需求。
- 发起包含多轮追问的测试对话，例如先询问某季度总营收，再追问疫苗业务营收金额，检查对话上下文是否被正确保留，输出结果关联对应细分数据。
- 运行包含代码节点与对话节点的工作流，检查对话节点是否能正确读取代码节点的输出内容，确认变量传递配置无误。
- 发起短文本测试提问，检查回答是否采用流式输出，确认流式输出配置已按要求启用。
