# 电力财报分析的工具调用与插件

## 这个品类的数据长什么样
电力行业财报数据主要来自国家能源局公开披露文件、电力上市公司年度及季度报告、地方电网运营公示。更新节奏分为年度完整财报（每年4月前披露上年经审计数据）、季度运营简报（每季度结束后15日内发布当期数据）、月度发电量/售电量快报（每月5日前发布上月数据）。文档结构包含通用财务报表与电力专项字段，专项字段涵盖上网电价、装机容量、供电煤耗等，单位多为千瓦时（kWh）、兆瓦（MW）、元/兆瓦时、万千瓦。

## 这些特征在「工具调用与插件」这一环带来什么约束
电力行业财报数据的多源分散特性，要求工具调用需支持对接国家能源局、上市公司披露平台等多个数据源的接口，需配置多源请求优先级与去重规则。月度运营数据的高频更新需求，要求插件支持按日/周触发的轻量调用任务，避免占用全量财报调用的资源。专项字段的非标准化命名，要求工具调用需配置字段映射规则，适配不同数据源的字段差异。电力相关字段的特殊单位，要求插件内置单位校验逻辑，防止提取数值与单位不匹配的错误结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `tool_call_timeout` | 600 秒 | 电力财报接口返回数据量较大，包含多份专项报表，常规30秒超时不足以完成完整请求 |
| `plugin_request_retry` | 2次，间隔10秒 | 公开披露站点可能存在访问限流，重试机制可降低临时访问失败的影响 |
| `field_mapping_rules` | 按数据源预设映射表 | 不同平台的电力专项字段命名存在差异，预设映射可统一提取目标字段 |
| `data_source_filter` | 仅启用国家能源局、头部电力上市公司披露接口 | 避免接入非权威数据源导致的数据偏差 |
| `scheduled_task_interval` | 月度数据为7天，年度数据为1天 | 匹配不同类型数据的更新频率，减少无效调用 |
| `unit_validation_enabled` | 开启 | 电力字段单位多样，校验可避免提取错误的数值与单位组合 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：私有部署V4.14.1版本导入插件时提示`internal server error`。原因：未在环境变量中配置`PLUGIN_ALLOWED_DOMAINS`白名单，导致插件接口被拦截。
- 现象：使用SSE协议封装的MCP工具时，在本地部署环境中提示仅支持stdio进程。原因：FastGPT内置的MCP适配器默认启用stdio模式，未开启SSE兼容配置。
- 现象：调用HTTP请求组件后提取的电力专项字段为空。原因：未配置`field_mapping_rules`，工具无法识别非通用财务字段的命名规则。

## 怎么确认配好了
- 发起单次工具调用请求，查看返回结果中是否包含电力专项字段且单位匹配预设规则。
- 检查定时任务日志，确认不同更新频率的插件调用任务按预设间隔触发。
- 模拟访问限流场景，验证插件请求重试机制是否生效，无连续失败报错。
- 导入测试用的电力财报数据源，确认字段映射规则是否正确转换字段名称。
