# 电力财报分析的文档解析与分块

## 这个品类的数据长什么样
电力行业财报数据主要来自上市电力企业的定期公开报告、电力监管机构发布的行业运行数据，更新节奏以季度、半年度、年度为核心周期，部分月度运营数据同步更新。文档结构通常包含财务核心指标、发电业务明细、输电配电数据、成本构成四大模块，字段涉及装机容量、上网电量、供电煤耗、单位售电成本等，单位多采用万千瓦、亿千瓦时、克标准煤/千瓦时、元/兆瓦时等专业计量标准。

## 这些特征在「文档解析与分块」这一环带来什么约束
电力财报的多模块结构化数据，要求解析环节精准识别跨模块的字段关联，避免拆分时割裂发电成本与上网电量的对应关系。单篇定期报告页数较多，需适配长文档的分段边界，防止将同一业务模块的内容拆分为多个独立块。专业计量字段的单位固定性，要求解析时保留数值与单位的绑定关系，避免出现字段匹配错误。月度运营数据的高频更新，要求解析流程适配批量小文档的快速处理，避免单文档解析超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 电力行业单篇年度财报页数较多，解析耗时较长，600秒可覆盖绝大多数长文档处理需求 |
| `分段长度` | `800–1200 字符` | 电力财报包含长句的专业业务描述，800-1200字符可保留业务模块完整性，避免拆分关键数据 |
| `CHUNK_OVERLAP` | `10–15%` | 电力财报存在较多跨段关联的业务数据，重叠率可保证上下文连贯性，避免关键信息断裂 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 大型年度财报单文件体积可能超出常规限制，1000MB可覆盖多数行业报告的上传需求 |
| `ENABLE_FIELD_MATCH` | `开启` | 电力财报存在固定格式的专业字段与单位，开启后可绑定数值与对应单位，避免解析匹配错误 |
| `PARSE_BATCH_SIZE` | `按实测标定` | 月度运营数据批量上传时，批次大小需平衡处理效率与系统资源占用，按实测结果调整 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为上传电力财报PDF后，数据处理环节返回空结果。原因是未开启`ENABLE_FIELD_MATCH`配置，导致结构化字段无法被识别，数据清洗后无有效内容。
- 现象为批量上传月度运营报告时，部分文档解析超时，界面显示`504 Gateway Timeout`错误。原因是`PARSE_FILE_TIMEOUT_SECONDS`配置取值低于600秒，长文档处理未完成即被中断。
- 现象为搜索测试返回结果中，数值与单位分离，例如仅显示“300”，未显示“300 克标准煤/千瓦时”。原因是未保留分块时的字段绑定关系，解析环节未关联数值与对应单位。

## 怎么确认配好了
- 上传单篇长周期电力财报，确认解析流程无超时报错，进度正常完成。
- 选取包含专业计量字段的文档片段，查看分块结果中数值与对应单位是否关联完整。
- 批量上传多份小型月度运营报告，确认数据处理环节无空结果返回。
- 调整分块相关配置，对比不同取值下的分块效果，确认业务模块未被不合理拆分。
