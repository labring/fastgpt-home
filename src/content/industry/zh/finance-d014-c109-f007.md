# 电子元件财报分析的工作流编排

## 这个品类的数据长什么样
电子元件行业财报数据主要来自境内外证券交易所披露平台、行业协会公开统计库。更新节奏为每季度终了后30日内披露季度财报，年度终了后4个月内披露年度财报。单份财报文档多为数十页的结构化PDF或网页格式，包含合并财务报表、细分业务营收占比、产能与出货量数据、原材料成本结构等字段，字段单位涵盖人民币元、万台、千片、百分比等，部分细分品类财报会附带晶圆良率、封装产能等专项参数。

## 这些特征在「工作流编排」这一环带来什么约束
电子元件财报的固定更新节奏，要求工作流配置定时触发节点，适配季度、年度的批量执行周期，避免无效调用。文档篇幅较长且包含多板块结构化数据，需设置合理的上下文长度限制与分段解析规则，防止大模型上下文溢出。细分品类附带的专项参数，要求工作流支持自定义字段提取配置，适配电容、芯片等不同电子元件品类的差异化数据需求。公开财报存在排版差异，需配置容错的文件解析节点，处理非标准格式的披露文件。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300-600 秒` | 电子元件财报PDF多为数十页，解析耗时较长，避免超时中断流程 |
| `maxContext` | `8000-12000 字符` | 财报包含多板块结构化数据，需保留足够上下文确保大模型理解完整业务逻辑 |
| `知识库召回条数` | `前8-12 条` | 电子元件财报字段较多，需召回足够数量的结构化片段覆盖核心数据 |
| `批量执行并发数` | `2-5 个` | 公开披露平台存在访问限流，过高并发会触发拦截 |
| `大模型温度` | `0.1-0.3` | 财报分析需保持数据准确性，不宜使用过高温度参数 |
| `指定搜索文件列表` | `按财报发布时间筛选` | 仅检索目标周期内的电子元件财报，避免返回无关数据 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：知识库搜索节点返回非目标财报文件，原因是未配置`指定搜索文件列表`参数，仅使用全局知识库范围检索。
- 现象：在线调试可完成批量执行流程，但API调用时批量节点未完整执行，原因是未设置`批量执行超时时间`，API请求超时中断流程。
- 现象：将AI对话节点切换为变量引用模式后，温度设置按钮消失，无法调整生成参数，原因是变量引用模式默认继承上游上下文参数，未开放独立配置入口。

## 怎么确认配好了
- 上传单份电子元件财报文件，触发工作流执行，检查文件解析节点的输出字段是否匹配预设的自定义映射规则。
- 发起批量执行任务，对比在线调试与API调用的执行状态，确认批量节点的执行流程完整。
- 查看工作流的对话日志，确认运行数据字段已记录完整的节点执行信息。
- 修改大模型温度参数，验证生成的财报分析内容的严谨性符合需求。
