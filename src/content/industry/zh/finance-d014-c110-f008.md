# 电网设备财报分析的工具调用与插件

## 这个品类的数据长什么样
电网设备企业的财报数据来源为境内外证券交易所公开披露的定期报告、企业官方投资者关系公告。数据按季度、半年度、年度固定周期更新，重大订单、技术突破类临时公告会补充发布。文档结构包含合并财务报表、经营情况讨论与分析、核心业务板块营收拆解、研发投入明细等内容。字段涉及电网专用设备营收占比、电网项目在手订单金额、并网设备相关指标等，单位多为亿元、百分比、台套数。

## 这些特征在「工具调用与插件」这一环带来什么约束
固定周期更新的特性要求工具调用插件配置定时同步任务，匹配财报披露的时间窗口触发拉取与解析，避免遗漏最新公告。细分业务字段的专属需求，要求工具调用时加载针对电网设备营收占比、在手电网项目订单的自定义抽取模板，替代通用财报抽取逻辑。长文档结构带来的解析压力，要求插件配置合理的分段与上下文拼接规则，避免拆分后丢失跨页的业务关联信息。公开披露的格式差异，要求工具调用时自动识别财报中的单位标注，完成营收、订单金额的统一转换，确保后续分析的数值一致性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `900 秒` | 电网设备财报PDF常包含多页业务拆解内容，过长的解析时长可避免中途超时 |
| `chunkSize` | `1000–1500 字符` | 适配财报中长段落的业务描述，同时保留跨段的业务关联信息 |
| `customExtractPrompt` | `针对电网设备企业财报，抽取输变电/配电设备营收占比、在手电网项目订单金额、研发投入占营收比例` | 匹配电网设备财报的专属字段需求，替代通用抽取逻辑 |
| `scheduleCron` | `0 0 2 10-15,25-30 * *` | 适配上市公司财报披露的固定周期，确保拉取最新公告 |
| `similarityThreshold` | `0.75–0.85` | 筛选财报中与电网业务强相关的段落，过滤无关的财务附注内容 |
| `pluginCallRateLimit` | `5 次/分钟` | 避免频繁调用交易所公开API触发访问限制 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为调用财报解析插件返回`connect ECONNREFUSED 172.23.0.2:3001`错误，原因是部署的插件服务未正常启动或端口映射配置有误。
- 现象为插件抽取的电网设备专属营收字段结果为空，原因是未加载针对电网设备业务的自定义抽取模板，使用通用财报抽取逻辑无法识别细分字段。
- 现象为连续调用财报接口触发429 Too Many Requests状态码，原因是未配置插件调用速率限制，超出公开数据接口的访问阈值。

## 怎么确认配好了
- 手动上传一份电网设备上市公司的公开财报PDF，检查解析结果是否能正确提取输变电设备营收占比等专属字段。
- 查看定时任务日志，确认在财报披露窗口期内是否自动触发了数据拉取与解析任务。
- 模拟高频调用插件接口，检查是否触发速率限制，确认配置的调用限制生效。
- 检查插件服务的端口监听状态，确认无连接拒绝类错误的触发条件。
