# 白酒财报分析的工具调用与插件

## 这个品类的数据长什么样
白酒行业上市公司的财报数据主要来源于上海证券交易所、深圳证券交易所的公开披露平台，以及白酒行业协会发布的行业运行数据。年度报告于每个会计年度结束后四个月内披露，半年度报告于上半年结束后两个月内披露，季度报告于前三个月、九个月结束后一个月内披露。单份财报文档通常包含财务报表正文、附注、管理层讨论与分析等部分，财务报表部分包含标准化的资产负债表、利润表、现金流量表及相关附表，核心字段以人民币元为单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
白酒财报的数据来源分散，需同时调用交易所披露接口与行业协会数据插件，因此需配置多源插件聚合能力。披露时间固定且集中在窗口期，需设置定时触发的工具调用任务，避免错过最新数据。财报文档篇幅较长，需调整解析参数避免截断核心内容。行业特有字段如预收款项、基酒存货相关数据，需插件适配专用字段的提取与解析逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `plugin_multi_source_enable` | `true` | 适配白酒财报多数据源需求，支持同时调用交易所披露接口与行业协会数据插件 |
| `plugin_trigger_schedule` | `0 0 9 1-31 4,8,10,1 *` | 匹配年报、半年报、季报的披露窗口期，定时触发工具调用任务 |
| `parse_max_length` | `8000 字符` | 适配白酒财报单份文档篇幅较长的特点，避免解析时截断核心财务与业务内容 |
| `tool_call_max_retries` | `3 次` | 应对交易所接口可能的临时访问限制，设置合理重试次数保障数据拉取成功率 |
| `global_variable_scope` | `team` | 支持在团队内共享白酒财报分析的通用参数，统一行业基准与分析规则 |
| `plugin_display_name` | `白酒财报数据插件` | 区分系统内部代码名与列表页展示名称，提升插件管理与调用的辨识度 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工具调用未返回知识库中的白酒行业基准数据，且生成的分析内容偏离预设逻辑。原因：未配置`plugin_knowledge_base_bind`参数，未将知识库与工具调用链路绑定。
- 现象：插件列表页展示的名称与系统插件管理页的代码名称不一致。原因：未在插件配置中设置`plugin_display_name`参数，系统默认使用内部代码名作为列表页展示名称。
- 现象：工具调用返回结果中多出无关数字或文本，且与模型原始输入的提示词无关。原因：未关闭`tool_call_auto_fill`参数，系统自动补充了未定义的占位符内容。

## 怎么确认配好了
- 触发一次定时任务，查看工具调用日志中是否同时包含交易所数据与行业协会数据的返回结果，核对数据源是否符合配置要求。
- 进入插件管理页面，对比系统内部代码名与插件列表页的展示名称，确认`plugin_display_name`参数已正确设置。
- 提交一份白酒财报文档进行解析，查看解析后的文本是否完整保留了核心字段，未出现截断情况。
- 调用API传入预设的全局变量，查看工具调用链路中是否正确读取了全局变量的取值，确认`global_variable_scope`参数的配置符合需求。
