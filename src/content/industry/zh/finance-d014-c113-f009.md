# 白酒财报分析的引用来源与溯源

## 这个品类的数据长什么样
白酒财报数据主要来自上市公司公开年报、季度报告，以及行业协会、第三方监测机构发布的月度销售数据。更新节奏为年度报告于次年4月30日前披露，季度报告于季后15日内披露，部分线下渠道的月度销售数据每周更新。文档结构包含合并资产负债表、利润表，以及分品类营收、产能销量明细字段，单位多为千元、吨、百分比，部分数据需按会计规则调整关联交易后统计。

## 这些特征在「引用来源与溯源」这一环带来什么约束
白酒财报数据来源分散，既有上市公司官方披露的标准化年报、季报，也有第三方行业监测机构发布的非标准化渠道数据，要求溯源环节明确区分披露主体与数据类型。分品类营收、产能明细嵌套在报表附注或专项说明中，需精准匹配到具体条目，避免溯源模糊。不同报告期的字段口径可能存在会计政策调整，溯源时需关联对应报告期的政策说明。数据更新周期差异显著，需在溯源信息中标注披露时间，确保引用时效性符合业务需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | `前8-12条` | 白酒财报单份文档包含多维度明细数据，需召回足够条目覆盖分品类营收、产能等核心字段，避免遗漏关键信息 |
| `相似度阈值` | `0.75-0.85` | 白酒财报字段标准化程度较高，阈值过低易引入无关行业监测数据，过高则可能遗漏同口径的关联披露内容 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 单份年度白酒财报文档字数较多，结构化解析需预留充足时间完成字段提取与关联匹配 |
| `分段长度` | `800-1200 字符` | 白酒财报的明细条目多为段落式描述，该分段长度适配字段提取与精准召回的需求 |
| `引用来源展示格式` | `「文档名+章节名+披露日期」` | 白酒财报需明确标注披露主体与时间，便于用户追溯原始数据的口径与时效性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用对话接口时未返回知识库id与溯源条目信息，仅返回纯文本答案。原因：未开启`enable_quote_source`参数，或配置中未启用溯源展示开关。
- 现象：知识库召回的引用文件与实际关联的财报条目不匹配。原因：召回条数设置过低，或相似度阈值超出合理区间，导致未匹配到正确的分品类明细条目。
- 现象：流式返回的溯源信息格式混乱，未标注披露日期。原因：引用来源展示格式配置错误，未包含日期字段，或解析环节未提取文档的披露时间元数据。

## 怎么确认配好了
- 发起单份白酒年度财报的召回测试，检查返回结果中是否包含明确的文档名、对应章节与披露时间的溯源信息。
- 调用对话接口，验证返回结果中是否包含知识库关联的溯源字段，确认字段内容与原始文档条目一致。
- 调整召回条数与相似度阈值，对比不同配置下的召回结果，确认匹配结果覆盖白酒财报的分品类明细等核心内容。
- 提交单份超长篇幅的白酒财报文档，验证解析环节是否在预设时间内完成，未出现超时报错。
