# 白酒财报分析的模型接入与配置

## 这个品类的数据长什么样
白酒上市公司的财报数据主要来源于沪深交易所公开披露的定期报告，更新节奏固定：年度报告于次年4月30日前披露，半年度报告于每年8月31日前披露，季度报告于季度结束后1个月内披露。单份文档通常包含合并财务报表、经营情况讨论与分析、核心产品产销数据等模块，字段涵盖报告期、营业收入、分品类营收、产能产量、税费等，单位多为人民币元、吨，无统一的非标准化附加字段。

## 这些特征在「模型接入与配置」这一环带来什么约束
白酒财报的固定披露周期要求配置定时同步任务的触发节点，匹配各报告期的披露截止时间；文档包含结构化财务表格与非结构化经营分析文本，要求模型接入时同时支持结构化数据解析与长文本上下文处理；分品类营收、产销数据等专属字段的存在，要求配置字段映射规则时精准匹配特定业务字段，避免混淆通用财务字段与白酒细分品类数据；单份文档篇幅较长，要求配置合理的分段与召回参数，避免上下文截断导致分析偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 白酒财报文档篇幅较长，常规解析时长可能超过平台默认值，600秒可覆盖完整解析流程 |
| `maxContext` | `8000–16000 字符` | 单份财报包含多模块内容，需保留足够上下文以关联不同板块的财务与经营数据 |
| `RECALL_TOP_N` | `前 8–12 条` | 白酒财报的核心数据分布在多个段落，需召回足够数量的相关片段以支撑全面分析 |
| `FUNCTION_CALL_ENABLE` | `开启` | 需调用工具完成多期财报数据对比、字段提取等操作，适配财报分析的流程化需求 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 头部白酒企业的年度财报PDF或Excel文件通常不超过该大小，避免上传失败 |
| `SYSTEM_PROMPT` | 「请基于提供的白酒上市公司财报数据，完成结构化提取与经营分析，优先聚焦白酒产品营收、产销数据等核心字段」 | 引导模型聚焦白酒细分品类的专属数据，避免混淆其他业务板块信息 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为配置ollama模型后，自定义系统提示词未生效，模型输出未聚焦白酒财报专属分析内容。原因是未在模型接入配置中正确绑定针对白酒财报的系统提示词，或ollama模型的提示词传递格式与平台要求不匹配。
- 现象为调用模型时无法触发工具搜索，多期财报对比流程无法自动执行。原因是未选择支持function call的模型版本，或未开启平台的函数调用配置开关，导致无法调用外部工具结合上下文完成分析。
- 现象为访问OneApi代理地址时无法加载页面，界面显示404错误或连接超时。原因是未正确配置OneApi的端口映射与启动参数，或部署版本与平台当前版本存在兼容性冲突。

## 怎么确认配好了
- 上传一份测试用的白酒财报文档，核对解析后的数据字段是否覆盖配置中指定的白酒专属业务字段。
- 发起包含多期财报对比的测试请求，核对模型是否能触发预设的工具调用流程。
- 查看模型输出内容，核对是否符合配置的系统提示词的聚焦要求。
- 检查OneApi代理服务的运行状态，确认无启动报错或端口冲突。
