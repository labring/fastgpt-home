# 耐火材料财报分析的工具调用与插件

## 这个品类的数据长什么样
耐火材料相关财报数据主要来自上市公司公开披露的季度报告、年度报告，以及行业协会发布的月度监测数据。更新节奏为季度财报每季度结束后1个月内更新，年度财报每年结束后4个月内更新，行业监测数据按月更新。文档结构为财报中“主营业务分析”章节下的细分产品板块，包含耐火材料业务营收、单位产品平均售价、原材料采购量、产能吨数等字段，单位多为吨、元人民币。

## 这些特征在「工具调用与插件」这一环带来什么约束
耐火材料业务板块在整体财报中占比通常较低，工具调用需精准定位细分章节，避免抓取全量财报导致的上下文冗余。多数据源（企业财报、行业监测数据）的更新频率不同，插件需支持按不同时间范围拉取数据，保障分析的时效性。字段单位多为吨、元人民币，工具调用时需统一单位转换，避免不同数据源的单位不匹配问题。部分财报包含产能分布、成本构成等图表数据，插件需支持图片资源的加载与解析，否则会导致分析内容缺失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `tool_call_timeout` | `300 秒` | 耐火材料财报数据量较大，解析与跨数据源调用需要较长处理时间 |
| `mcp_resource_filter` | `["耐火材料", "主营业务分析", "季度报告"]` | 精准定位财报中的细分板块，过滤无关内容，提升工具调用效率 |
| `plugin_data_unit_conversion` | `自动转换为吨、元人民币` | 统一不同数据源的单位格式，避免分析时出现单位不匹配的问题 |
| `max_context_tokens` | `16384` | 适配长文档财报的解析需求，保障上下文信息完整 |
| `tool_call_retry_count` | `2 次` | 应对网络波动或数据源临时不可用的情况，减少调用失败率 |
| `plugin_auth_scope` | `["财报数据源", "行业数据接口"]` | 限制插件访问权限，保障数据调用的安全性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用工具加载财报中的图表时出现Cannot load image相关报错。原因是未配置插件的图片资源代理，导致跨域请求无法正常访问图表资源。
- 配置MongoDB数据库连接时出现MongoServerError报错。原因是使用beta4版本时，内置MongoDB驱动版本与4.4.29存在兼容性冲突，导致连接验证失败。
- 使用MCP工具查询企业专利信息时返回无相关记录。原因是未从财报中提取正确的企业标识字段，传入工具的查询参数与目标企业不匹配。

## 怎么确认配好了
- 上传一份耐火材料上市公司的公开财报文档，运行工具调用，检查返回结果是否仅包含耐火材料业务相关的字段与数据。
- 运行工具调用后，查看返回数据的单位格式，确认已统一转换为吨、元人民币。
- 查看插件运行日志，确认MongoDB连接无权限错误或版本兼容问题。
- 传入财报中披露的企业信息至MCP工具，检查是否能返回匹配的业务数据。
