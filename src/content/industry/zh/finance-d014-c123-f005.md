# 能源金属财报分析的多轮对话与提示词

## 这个品类的数据长什么样
能源金属财报数据主要来自上市公司公开年报、行业协会月度报告、期货交易所行情数据。更新节奏分为两类：定期财报按季度、年度固定更新，行业现货与期货数据按日或实时更新。文档多为PDF格式，结构包含产量、库存、冶炼成本、金属品位、营收拆分等字段，单位涵盖吨、元/吨、千千瓦时等，部分报告附带多期对比表格与趋势图表。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
能源金属财报的多维度专业字段、分批次更新节奏与长文档特征，对多轮对话与提示词配置带来多重约束。多维度专业字段需要在对话中保留前置限定条件，例如指定金属品位、统计周期，避免模型混淆不同品类或周期的数据。长文档内容需要限制上下文窗口大小，防止超出模型处理上限导致关键信息丢失。不同更新节奏的数据需要在提示词中明确区分来源，避免将实时现货数据与定期财报数据混用。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 字符 | 能源金属单份财报常超3000字符，需保留多轮对话的财报参数与上下文，避免截断关键信息 |
| `UPLOAD_FILE_MAX_SIZE` | 50 MB | 能源金属财报常附带多期对比图表，单份文件体积高于通用文档，需适配大文件上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 财报解析需提取多维度表格数据，耗时高于普通文本文档，需延长超时阈值 |
| `召回条数` | 前8条 | 能源金属财报字段数量多，需召回足够相关的财报片段支撑多轮追问与细节验证 |
| `presignedUrlExpireSeconds` | 3600 秒 | 大文件上传需延长预签名URL有效期，避免上传中途出现`fail to create post presigned url`报错 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 对话返回非标准JSON格式，界面显示结果包含冗余自然语言。原因是提示词未明确要求仅输出指定结构的JSON，未禁用额外说明内容。
- 升级至4.14.3后上传能源金属财报附件时提示`fail to create post presigned url`。原因是未调整`presignedUrlExpireSeconds`参数适配新版上传逻辑，或S3存储桶的跨域配置未同步更新。
- 多轮追问财报数据后返回结果缺失关键字段。原因是未开启上下文保留配置，导致后续对话丢失之前指定的金属品类、统计周期等限定条件。

## 怎么确认配好了
- 上传一份标准能源金属财报PDF，检查解析后提取的字段是否包含产量、冶炼成本、金属品位等专属信息，确认解析逻辑适配品类特征。
- 发起多轮对话，先询问某季度的营收数据，再追问对应季度的单位冶炼能耗，检查上下文是否被正确保留，后续回复能关联前置限定条件。
- 上传超过20MB的能源金属财报文件，确认上传流程无报错，解析任务能在300秒内正常完成。
- 测试触发附件上传流程，检查预签名URL生成无异常，无超时类报错，确认S3存储配置与参数设置匹配。
