# 航空装备财报分析的工具调用与插件

## 这个品类的数据长什么样
航空装备行业的财报数据主要来自上市企业公开披露的年度、半年度、季度报告，以及行业协会发布的公开统计信息。数据更新节奏以定期报告为主，季度报告每3个月更新一次，年度报告每年更新一次，同时包含临时公告类的实时更新内容，如重大订单、产能变动公告。单份财报文档结构包含财务核心数据、业务经营数据两大模块，字段涵盖营业收入、营业成本、研发费用、在手订单金额、交付飞行器数量、维修服务营收等，单位涵盖人民币元、架、飞行小时等。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据的整合需求明确，财报数据来自交易所披露平台与企业临时公告，工具调用需支持对接多个数据源以获取完整信息。实时性需求明确，临时公告的更新频率较高，需配置定时刷新数据集的插件规则。字段类型复杂，包含财务数值与实物业务指标，插件需支持多类型字段的提取与对齐，避免单位混淆。单份文档篇幅较长，工具调用需适配长文本解析的能力，避免因文档过长导致解析失败或上下文截断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 航空装备财报单份文档包含多期对比数据与业务细节，解析耗时较长 |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 单份年度财报PDF可能包含大量图表与附件，需适配较大文件的上传需求 |
| `召回条数` | `前8条` | 财报相关问题需覆盖财务、交付、研发等多个业务模块，需足够的上下文支撑 |
| `相似度阈值` | `0.75` | 航空装备财报包含大量专业术语，需过滤低相关的召回结果以提升准确性 |
| `maxContext` | `12000 字符` | 长财报的上下文窗口需求较高，需保留足够的历史信息以支撑复杂查询 |
| `WORKFLOW_PLUGIN_API_TIMEOUT` | `300 秒` | 跨数据源调用插件时，接口响应耗时较长，需延长超时时间避免任务中断 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用BI图表插件时返回的地址为`api.example.com`，无法访问企业内部数据源。未在插件配置中修改目标API的基础地址，使用了默认测试地址。
- 调用`/api/core/dataset/update`接口时返回500状态码，浏览器可正常访问该接口。未在API请求头中携带正确的身份验证令牌，导致接口鉴权失败。
- 工作流中调用代码运行模块时，仅返回完整结果无法实现流式输出。未在代码中配置流式响应的格式，未将结果逐段推送至工作流节点。

## 怎么确认配好了
- 上传单份航空装备财报文档，查看解析结果是否完整提取了品类专属的财务与业务字段。
- 发起针对财报交付量、研发投入的查询，核对召回的上下文覆盖对应业务模块。
- 触发工作流中的插件调用，查看返回结果的数据源地址与配置的目标地址一致。
- 调用数据集更新接口，核对接口返回状态码符合预期，且文档更新完成。
