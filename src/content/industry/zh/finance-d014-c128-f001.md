# 航运港口财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
航运港口财报数据主要来自港务局官方公开统计报表、交通运输部港口行业月度监测数据。更新节奏以月度、季度、年度为核心周期，部分实时作业数据按日更新。文档结构包含结构化统计表格与业务说明文字，核心字段包括集装箱吞吐量（单位：TEU）、货物装卸总量（单位：吨）、泊位作业时长（单位：小时）、航线运营班次（单位：班/周），部分细分报表还包含单港区作业数据、跨境航线占比等专项字段。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多周期数据需求要求接口支持按日、月、季、年等不同时间粒度拉取，且需兼容批量拉取历史数据的场景；实时作业数据的高频需求，要求接口支持短间隔轮询或Webhook推送配置；结构化字段的单位一致性要求，需在接口参数中明确指定数据单位，避免跨数据源转换误差；专项字段的差异化需求，要求接口支持自定义参数筛选指定港区或航线数据，同时需兼容不同报表的字段映射规则。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DATA_SOURCE_TYPE` | 选择「外部API数据源」 | 航运港口财报数据多来自官方公开API或定制化统计接口，非内置知识库 |
| `API_REQUEST_INTERVAL` | `300–600 秒` | 官方港口数据更新周期多为月度/季度，高频轮询会触发接口限流 |
| `API_RESPONSE_PARSER_MODE` | 选择「结构化表格解析」 | 港口财报数据以结构化表格为核心展示形式，该模式可精准提取字段与单位 |
| `API_UNIT_AUTO_CONVERT` | 开启 | 不同数据源可能存在单位差异（如TEU与标准箱的混用），自动转换可统一数据格式 |
| `MAX_BATCH_RECORDS` | `50 条` | 单批次拉取过多数据会导致接口超时，50条适配多数港口统计接口的分页限制 |
| `API_AUTH_TYPE` | 选择「API_KEY 鉴权」 | 多数官方港口统计接口采用API密钥鉴权，无需复杂的用户名密码流程 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 接口调用返回`401 Unauthorized`状态码，且控制台提示鉴权失败。原因：未正确配置`API_KEY`参数，或使用了过期的鉴权密钥，部分港口接口需绑定专属IP白名单。
- 自定义HTTP工具的可选参数配置项消失，无法添加新的请求参数。原因：未开启「高级参数配置」开关，或在部署升级后未重新同步工具配置模板。
- 数据库查询工作流返回空结果，且日志显示SQL语句语法错误。原因：未适配港口财报数据的字段命名规则（如将`container_throughput`误写为`trans_vol`），或未添加时间范围过滤条件导致返回数据过多被截断。

## 怎么确认配好了
- 发起单次测试请求，检查返回数据的字段与单位是否与目标港口财报数据一致。
- 查看接口调用日志，确认请求间隔符合配置的`API_REQUEST_INTERVAL`参数，无频繁触发的限流报错。
- 验证批量拉取功能，确认返回数据的条数不超过配置的`MAX_BATCH_RECORDS`限制。
- 测试鉴权配置，确认使用无效密钥时会触发`401 Unauthorized`错误，有效密钥可正常返回数据。
