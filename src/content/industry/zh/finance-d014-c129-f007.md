# 融资租赁财报分析的工作流编排

## 这个品类的数据长什么样
融资租赁相关财报数据主要来源于企业内部财务核算系统、监管报送的专项报表及外部征信披露信息。数据更新节奏匹配财报披露周期，内部业务台账按实际业务发生频次同步。文档结构包含合并资产负债表、利润表、现金流量表，以及租赁资产专项附注，其中专项附注会披露应收融资租赁款净额、租赁收入、未担保余值等明细字段，字段单位多采用人民币元或万元。

## 这些特征在「工作流编排」这一环带来什么约束
多数据源的来源要求工作流支持多输入节点的聚合配置，适配内部财务系统、监管报表等不同渠道的数据接入。财报固定的披露周期要求工作流配置定时触发的时间参数，匹配季度、半年度或年度的任务启动节奏。租赁资产专项附注的明细字段较多，要求信息提取环节配置精准的字段映射规则，避免无关信息干扰核心分析。不同业务的币种单位差异，要求工作流添加统一的单位转换处理节点，确保分析数据的一致性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 融资租赁财报包含专项附注，数据量较大，需预留足够的解析与接口调用时间 |
| `rag_recall_similarity_threshold` | 0.70–0.75 | 过滤低相关的通用财报片段，精准召回应收融资租赁款、租赁收入等核心字段内容 |
| `workflow_trigger_cron` | 按财报披露周期配置（如季度末后3天） | 匹配财报数据的更新节奏，确保任务在最新财报发布后自动启动 |
| `parse_chunk_length` | 1000–1200 字符 | 适配财报附注的段落长度，避免分段过碎导致字段提取断裂，或过长导致上下文溢出 |
| `multi_data_merge_strategy` | 按核心字段名映射聚合 | 适配多数据源的字段命名差异，统一内部财务系统与监管报表的数据格式 |
| `filter_invalid_records` | 开启 | 过滤财报中未披露租赁资产明细的异常条目，避免无效数据进入分析环节 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：工作流执行超时，返回`504 Gateway Timeout`状态码。原因：未针对融资租赁财报的大体积数据调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时间不足以完成解析与多数据源聚合。
- 现象：不同知识库的输出未按预设分类展示，所有结果合并输出。原因：未在工作流中配置分支节点，未为业务制度、专家解读、合规校验分别绑定对应知识库的检索节点。
- 现象：HTTP自定义输入节点的接口无法接收传入变量，返回`400 Bad Request`。原因：未按照接口约定的参数名传递变量，未在工作流节点中配置正确的请求体格式。

## 怎么确认配好了
- 查看工作流的定时触发配置，核对触发时间与所在机构的财报披露周期是否匹配。
- 运行单次测试任务，检查核心字段的提取结果是否包含应收融资租赁款、租赁收入等融资租赁专属内容。
- 调用HTTP自定义节点的测试接口，传入预设变量，确认接口能正常返回预期响应。
- 触发多知识库分支测试，检查不同知识库的检索结果是否按预设分类输出。
