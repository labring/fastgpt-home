# 融资租赁财报分析的引用来源与溯源

## 这个品类的数据长什么样
融资租赁财报数据主要来源于租赁项目台账、监管报送报表、应收租金回款记录三类文件。更新节奏为月度更新，单份项目明细文档包含项目编号、租赁本金、剩余租期、应收租金总额、逾期天数等字段，单份合并财报文档分为项目明细、财务汇总、风险提示三个模块。所有字段均使用通用单位，无额外自定义格式。

## 这些特征在「引用来源与溯源」这一环带来什么约束
融资租赁财报多源分散的特征，要求溯源环节需关联项目编号、租赁本金等唯一标识字段，避免不同文档间的信息混淆。月度更新的节奏要求溯源系统需支持按更新时间筛选源文件，确保返回的引用为最新数据。文档分项目明细与财务汇总的结构，召回时需优先匹配项目ID，不匹配泛关键词，缩小溯源范围。字段中包含的逾期天数、应收租金总额等具体数值，要求溯源时需保留原始字段的单位与精度，不得擅自修改。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `datasetRecallTopK` | 前 8 条 | 融资租赁财报包含多关联项目，需足够召回量覆盖分散的源文档 |
| `recallThreshold` | 0.75–0.85 | 过滤低匹配度的非项目关联内容，避免溯源到无关租赁项目 |
| `sourceReferenceEnable` | 开启 | 符合融资租赁行业的信息溯源监管要求，强制展示引用来源 |
| `parseChunkSize` | 1200–1500 字符 | 适配融资租赁财报的长字段结构，避免截断项目编号、租赁本金等关键标识 |
| `referenceGroupByField` | 按`项目编号`分组 | 合并同一租赁项目的多文档溯源信息，提升阅读清晰度 |
| `version` | 4.9.4 及以上 | 修复该版本中引用开关异常显示的问题，确保溯源功能正常生效 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：返回的引用文件与提问关联的租赁项目不匹配，字段显示错误。原因：未按`项目编号`配置分组召回，召回时匹配了泛关键词，未匹配唯一标识。
- 现象：4.9.4版本中，即使关闭`sourceReferenceEnable`配置项，仍强制展示引用内容。原因：该版本存在配置项缓存未生效的已知问题，需重启服务重置配置。
- 现象：引用的源文档内容被截断或修改，与原文不一致。原因：`parseChunkSize`配置过小，截断了包含项目编号的关键段落，导致溯源匹配失败。

## 怎么确认配好了
- 上传一份测试用的融资租赁项目台账文档，发起包含该项目编号的提问，核对返回的引用列表中是否包含该文档。
- 调整`recallThreshold`配置项，发起低匹配度的泛提问，确认未返回无关的租赁项目文档。
- 检查`sourceReferenceEnable`配置项的实际生效状态，确认开关状态与展示结果一致。
- 查看引用展示格式，确认同一项目的多文档已按`项目编号`分组展示。
