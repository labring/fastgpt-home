# 装修装饰财报分析的工作流编排

## 这个品类的数据长什么样
装修装饰行业的财报数据主要来自企业公开披露的年度、季度报告，以及内部项目台账、行业协会发布的经营统计资料。数据更新节奏为年度报告按财年更新，季度报告每季度末发布，内部项目数据随项目节点按月更新。财报文档结构包含营收分类（家装、公装、供应链业务）、分项毛利率、在手订单总额、单项目造价等字段，单位分别为万元、百分比、万元、元/平方米。

## 这些特征在「工作流编排」这一环带来什么约束
由于装修装饰财报同时包含公开披露的标准化报表与企业内部非标准化项目台账数据，工作流需支持知识库与MCP工具的分流调用。不同数据源的更新节奏差异，要求工作流配置多定时触发节点，分别适配季度财报更新与月度项目数据同步。财报字段包含特定单位的数值项，工作流需内置单位校验规则，避免跨单位计算错误。长文档年报的分段处理需匹配行业文档的常规篇幅，防止内容截断导致分析偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `知识库召回条数` | `前8-12条` | 装修装饰财报的业务字段分散在多个文档段落，该召回量可覆盖核心分析维度且避免上下文过载 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300秒` | 装修装饰年度财报包含项目明细、招投标附件等长内容，常规解析时长超出通用文档阈值 |
| `UPLOAD_FILE_MAX_SIZE` | `200 MB` | 支持大型装修企业的多附件财报上传，匹配行业财报的常规附件总大小 |
| `表单输入节点默认值` | `${global.target_company_code}` | 批量分析场景下，绑定全局企业代码变量可减少重复配置，适配多企业财报分析需求 |
| `相似度阈值` | `0.75` | 装修装饰行业财报术语具有较高辨识度，该阈值可过滤非相关行业的召回内容 |
| `条件分支节点-分流规则` | `按关键词匹配` | 公开财报数据存储于知识库，内部项目数据通过MCP工具调用，关键词如“在手订单”“项目台账”触发MCP调用 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：表单输入节点的默认值无法获取全局变量，提交后字段为空。原因：未在全局变量配置中提前定义目标企业代码变量，或变量引用格式未使用`${}`包裹。
- 现象：工作流触发MCP调用与知识库召回的分流错误，出现非预期的工具调用。原因：分流规则的关键词匹配逻辑未覆盖装修装饰行业的专属术语，或条件分支节点的判断顺序配置错误。
- 现象：上传财报文件后解析失败，返回`413 Request Entity Too Large`错误。原因：未将`UPLOAD_FILE_MAX_SIZE`配置调整至适配行业财报的大小，超过平台默认限制。

## 怎么确认配好了
- 上传一份装修装饰企业的季度财报文档，检查解析后的字段是否包含营收分类、毛利率等行业专属项，确认解析配置生效。
- 触发一次工作流测试，输入包含“在手订单”的测试关键词，确认工作流自动触发MCP工具调用，其余关键词触发知识库召回，验证分流规则生效。
- 查看表单输入节点的配置，确认默认值已绑定全局变量，批量测试时无需手动修改企业代码，验证默认值配置生效。
- 提交一份超过平台默认大小的装修装饰财报附件，检查是否触发上传限制提示，确认`UPLOAD_FILE_MAX_SIZE`配置生效。
