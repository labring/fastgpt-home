# 计算机设备财报分析的工作流编排

## 这个品类的数据长什么样
计算机设备品类的财报数据主要来自境内外证券交易所披露平台、上市公司官方公告及行业合规数据库，多用于金融、理财领域的设备采购与投资分析。数据更新以季度、年度为固定节奏，同时伴随重大采购、产能调整等事项发布临时补充公告。单份财报文档包含标准化财务报表模块，同时附带细分业务板块数据，其中与品类相关的字段包括固定资产原值、累计折旧、存货账面余额、研发投入金额等，单位统一为人民币元或万元。

## 这些特征在「工作流编排」这一环带来什么约束
计算机设备财报的多源分散特性，要求工作流配置多数据源拉取节点，并适配不同平台的接口鉴权规则，满足金融领域的数据合规要求。固定周期与临时突发的数据更新节奏，要求工作流支持定时触发与手动触发两种模式，同时配置分支判断节点区分定期报告与临时公告的处理逻辑，适配金融机构的定期风控与临时投资分析需求。细分字段较多且与品类强绑定，要求工作流中配置字段提取节点，定向筛选固定资产、研发投入等专属字段，避免通用财报节点抓取无关数据影响分析准确性。单份财报文档篇幅较长，要求配置分段处理节点控制单批次处理的文本长度，避免节点执行超时影响业务流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `数据源鉴权方式` | `OAuth2 或 API Key 鉴权` | 适配证券交易所披露接口的合规鉴权规则，保障数据拉取权限合法 |
| `触发模式` | `定时触发+手动触发双模式` | 覆盖季度/年度固定财报更新与临时公告的突发处理需求 |
| `分段处理长度` | `800–1200 字符` | 控制单批次文本处理规模，避免节点执行超时 |
| `字段映射规则` | `按设备专属字段预设映射表` | 定向提取固定资产、研发投入等计算机设备品类相关数据 |
| `知识库关联ID` | `按财报披露年度预设固定ID` | 匹配对应周期的行业知识库内容，提升分析准确性 |
| `代码运行节点超时时间` | `600 秒` | 预留足够时长完成多维度财报数据的计算与整理 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：AI问答节点无法接收文本拼接节点传入的完整内容，返回结果缺失或提示格式错误。原因：文本拼接节点未开启纯文本输出配置，或未在工作流中配置参数类型转换规则，导致传入内容格式不符合AI问答节点的输入要求。
- 现象：4.6.9版本高级编排中，判断器节点后的AI问答节点无法获取初始用户问题。原因：未在判断器节点的输出参数中绑定初始用户问题的上下文变量，导致后续节点无法调用该参数。
- 现象：代码运行节点调用外部模型时无流式返回内容，或返回内容无法拼接为完整结果。原因：未在代码节点中配置流式输出的响应参数，未正确处理数据流的分片传输逻辑。

## 怎么确认配好了
- 手动触发工作流拉取单份季度财报数据，核对数据源拉取节点返回的字段是否包含预设的计算机设备专属财务数据。
- 分别上传定期报告与临时公告格式的测试文件，确认工作流自动进入对应处理分支。
- 执行代码运行节点的测试任务，核对节点返回的数据流符合预设的流式输出规则。
- 查看工作流运行日志，确认入口参数已正确传递至对应节点，无格式报错或参数缺失。
