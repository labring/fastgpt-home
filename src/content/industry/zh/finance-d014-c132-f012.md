# 计算机设备财报分析的模型接入与配置

## 这个品类的数据长什么样
计算机设备品类的财报数据主要来自境内外证券交易所披露的上市公司定期报告，以及行业公开的第三方财报数据库。更新节奏以季度报、年报为主，季度报告于每季度结束后45天内披露，年度报告于年度结束后4个月内披露。文档以PDF格式为主，包含结构化报表与非结构化附注，核心字段包括固定资产-计算机设备、营业收入-计算机整机销售收入、存货-库存计算机设备，部分披露销量的字段会附带台数单位，金额字段统一以人民币万元为计量标准。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据同时包含结构化报表字段与非结构化附注文本，要求模型配置需兼顾结构化信息提取与非结构化语义理解。财报披露节奏固定，需配置定时数据拉取或刷新的周期匹配披露时间，避免使用非固定频率的更新策略。计算机设备专属的细分字段与其他行业财报存在差异，需在模型配置中明确限定字段范围，防止模型混淆其他品类的财报信息。部分数据同时包含金额与台数双维度，需配置参数保障模型能正确关联数值与对应单位。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `systemPrompt` | 请针对计算机设备上市公司财报，提取固定资产-计算机设备、营业收入-计算机整机销售收入、存货-库存计算机设备三个核心字段，结合披露的销量数据生成分析报告 | 明确限定品类专属分析范围，避免模型提取无关行业的财报字段 |
| `maxContext` | `8000–12000 字符` | 计算机设备财报的结构化报表与附注内容较长，需匹配大模型的上下文窗口避免内容截断 |
| `apiKey` | 从对应大模型平台申请的专属访问密钥 | 保障模型调用的权限隔离与调用量统计准确 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 计算机设备财报PDF通常包含多页报表与附注，解析耗时较长 |
| `chunkSize` | `1000–1500 字符` | 财报附注包含大量设备相关的技术细节与明细，分块需覆盖完整语义单元 |
| `similarityThreshold` | `0.75–0.85` | 需精准匹配计算机设备专属的财报字段，避免召回无关行业的文档内容 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 测试模型时出现`[] is too short - 'messages'`报错，原因是未正确配置系统提示词或初始调用消息为空，导致模型请求的消息数组长度不符合要求。
- 触发分析时返回422状态码，原因是配置的大模型API参数存在错误，例如模型名称拼写错误或上下文长度超出大模型限额。
- 配置大模型API密钥后未生效，原因是未在FastGPT的模型管理页面完成密钥绑定，或未将对应模型设置为工作流的调用节点。

## 怎么确认配好了
- 在FastGPT的模型测试页面输入计算机设备财报的示例片段，核对模型是否能正确提取预设的三个核心字段。
- 上传单份计算机设备财报PDF，查看解析后的分块内容是否覆盖核心报表与附注部分。
- 触发一次完整的财报分析工作流，检查返回结果是否包含预设的字段分析内容。
- 查看模型调用日志，确认API密钥验证通过且无参数错误提示。
