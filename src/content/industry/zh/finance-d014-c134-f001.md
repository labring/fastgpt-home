# 调味品财报分析的HTTP 接口与外部系统

## 这个品类的数据长什么样
调味品品类的财报数据来源为境内外证券交易所公开披露的上市公司定期报告、企业官方经营简报。数据更新节奏为每季度、每半年度、每年度。文档多为PDF格式的正式报告，部分披露结构化明细数据。文档结构包含分产品营收明细、原材料采购总额、销售费用总额、期末存货余额等字段，单位统一为人民币万元。分产品营收明细会细分酱油、调味酱、复合调味料等品类的营收规模，原材料采购总额包含大豆、包装材料等大类的采购金额。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
调味品品类的财报数据特征对HTTP接口与外部系统存在多重约束。首先，数据来源多为PDF格式的正式报告，接口需适配PDF文件的结构化解析能力，支持提取内嵌表格内容。其次，分产品营收明细包含多个细分品类，接口需支持多维度字段的参数校验与返回，适配多字段的配置。数据更新节奏为季度级，接口需支持按季度周期触发数据同步，避免无效频繁调用。此外，文档中包含多类采购、费用、存货等大额数值字段，接口需统一校验数值单位为人民币万元，防止传入错误单位的参数。部分企业的财报文档体积较大，接口需适配大文件上传的超时与解析时长配置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_PDF_TABLE_MODE | `启用表格结构化提取 | 调味品财报多为PDF内嵌表格，需提取结构化分析所需的分产品营收、采购明细 |
| `UPLOAD_FILE_MAX_SIZE | `100–200 MB | 单份年度调味品企业财报PDF体积较大，需适配大额文件上传与解析 |
| `API_REQUEST_TIMEOUT | `240–300 秒 | 大体积PDF解析耗时较长，需匹配完整上传与解析流程 |
| `EXTRACT_REQUIRED_FIELDS | `分产品营收,原材料采购总额,期末存货余额 | 调味品财报核心分析字段需固定提取，避免冗余数据干扰分析 |
| `SYNC_TRIGGER_FREQUENCY | `按季度触发 | 调味品财报按季度、半年度、年度更新，匹配数据同步节奏 |
| `ALLOWED_FILE_EXTENSIONS | `pdf,csv | 覆盖交易所披露的PDF财报与部分结构化CSV文件，适配用户上传需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用接口上传CSV格式的财报文件后，生成的数据集与界面手动上传生成的数据集字段不一致。原因：未配置`ALLOWED_FILE_EXTENSIONS`包含CSV格式，或未正确配置`CSV_FIELD_MAPPING`，导致CSV文件的字段映射与界面默认配置不匹配。
- 现象：发送HTTP请求时返回`400 Bad Request`，提示参数格式错误。原因：未将请求头的`Content-Type`设置为`application/json`，导致接口无法正确解析传入的请求体。
- 现象：调用外部系统接入后，返回的财报数据中复合调味料的营收数据为空。原因：未在`EXTRACT_REQUIRED_FIELDS`中配置复合调味料相关提取字段，导致接口未提取该品类的营收数据。

## 怎么确认配好了
1. 上传一份测试用的调味品企业财报PDF，核对接口返回的字段是否覆盖配置的`EXTRACT_REQUIRED_FIELDS`列表中的内容。
2. 发送`Content-Type`为`application/json`的请求体，确认接口返回200状态码，无参数解析报错。
3. 触发一次按季度周期的同步任务，等待任务完成后，核对返回的数据集包含分产品营收、原材料采购总额等核心字段。
4. 上传一份测试用的CSV格式财报文件，确认接口正常解析并返回结构化数据，无格式报错。
