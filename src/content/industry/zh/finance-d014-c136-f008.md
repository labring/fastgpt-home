# 贵金属财报分析的工具调用与插件

## 这个品类的数据长什么样
贵金属财报与交易数据的来源包括伦敦金银市场协会（LBMA）的定盘价数据、上海黄金交易所的国内交易数据、国家统计局的贵金属行业统计数据，以及上市金企的公开财报。数据更新节奏存在显著差异：日内交易数据每15分钟更新一次，月度库存数据于每月5日前发布，季度财报则按上市企业披露周期更新。数据文档多为结构化表格或PDF格式，核心字段包括交易品种名称、交易单位、当日成交均价、单日成交总量、月末库存余量、季度营收中贵金属相关部分的金额，单位涵盖美元/盎司、人民币/克、千克等。

## 这些特征在「工具调用与插件」这一环带来什么约束
多来源的数据结构与鉴权方式存在差异，要求插件对接多个独立API端点，提升接口配置的复杂度。不同数据的更新周期差异显著，需为日内交易数据、月度库存数据、季度财报分别设置差异化的拉取调度规则，避免无效请求或数据过期。跨市场的单位不统一问题，要求工具调用时内置单位转换逻辑，确保分析结果的计价单位一致。财报类数据的PDF格式存在非标准化的表格布局，需要插件集成专用的表格提取模块，精准匹配贵金属财报的专属内容结构。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PLUGIN_API_TIMEOUT` | `30 秒` | 贵金属日内交易数据接口响应通常在10秒内，超时设置过长会阻塞流水线运行 |
| `PARSE_PDF_TIMEOUT_SECONDS` | `600 秒` | 上市金企的财报PDF通常包含多页表格与图表，解析耗时较长 |
| `PLUGIN_REQUEST_HEADERS` | `{"Content-Type": "application/json", "X-API-Key": "{{user_secret}}"}` | 多数贵金属数据源API要求JSON格式请求体与API密钥鉴权 |
| `DATA_UNIT_CONVERSION` | `启用，目标单位为人民币/克` | 国内主流贵金属交易计价单位为人民币/克，统一单位可简化后续分析逻辑 |
| `PLUGIN_SCHEDULE_POLICY` | `按数据类型分组配置：日内数据每15分钟拉取，月度库存数据每月1次，季度财报数据每季度1次` | 匹配不同数据源的官方更新节奏，避免无效请求与数据过期 |
| `HTTP_RETRY_MAX_TIMES` | `3 次` | 贵金属数据源接口偶发波动，有限重试可降低请求失败率 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 调用贵金属数据源API返回`Failed to fetch`错误，且接口地址配置无误。原因：未配置正确的鉴权请求头，或未允许指定域名的跨域请求，部分贵金属数据源API会拦截非授权域名的请求。
- 插件解析财报后返回的字段为空，无法提取贵金属相关营收数据。原因：未开启PDF解析的表格提取开关，或解析规则未匹配贵金属财报的专属表格布局，导致核心数据未被识别。
- 配置定时拉取任务后，日内交易数据始终未更新。原因：将所有数据类型的拉取间隔设置为相同值，未区分日内交易数据与季度财报的更新节奏，导致任务触发频率不符合数据源的更新周期。

## 怎么确认配好了
- 手动触发插件调用，查看返回结果中是否包含贵金属交易数据的指定字段，且计价单位与配置的目标单位一致。
- 查看插件运行日志，确认定时任务按配置的间隔执行，日内数据任务的执行频率符合设置的15分钟周期。
- 上传一份上市金企的财报PDF，验证插件是否能提取出贵金属相关的交易与营收数据字段。
- 调用鉴权接口，返回有效业务数据，未返回鉴权失败提示，确认请求头配置的API密钥与格式正确。
