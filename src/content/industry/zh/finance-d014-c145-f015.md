# 通信设备财报分析的部署与升级

## 这个品类的数据长什么样
通信设备品类的财报数据主要服务于金融、保险、理财领域的行业分析需求，数据来源包括公开交易所公告、行业协会月度监测报告、运营商公开招标信息三类渠道。更新节奏分为三类：季度财报每3个月更新一次，月度行业出货量数据每月更新，招标公告随发布实时更新。文档形式包含结构化PDF财报、Excel格式的行业统计表格、网页版公告页面，字段包含营收（单位：人民币亿元）、净利润（单位：人民币亿元）、基站出货量（单位：万台）、光模块销量（单位：万件）等，部分文档会同时包含结构化表格与非结构化业务分析段落。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据更新频率存在季度、月度、实时三类差异，需配置多套定时同步任务以匹配不同数据的更新周期。结构化与非结构化数据混合的文档结构，要求部署时同时配置结构化解析规则与通用文本解析规则，避免解析丢失关键字段。特定的单位与字段分类，要求在数据清洗环节配置单位转换与标签映射规则，确保后续分析的准确性。通信设备财报单文件体积通常较大，需预留足够的解析与存储资源，避免同步过程中出现中断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600-900 秒 | 通信设备财报单文件体积通常较大，且包含多页结构化表格，需延长解析超时时间避免任务中断 |
| `UPLOAD_FILE_MAX_SIZE` | 2000 MB | 支持批量上传季度财报合集及行业统计数据集，适配多文件同步的业务需求 |
| `schedule_interval` | 0 0 1 */3 *（每3个月）/ 0 0 1 * *（每月） | 按数据更新频率配置，季度财报数据设置为每3个月同步一次，月度监测数据设置为每月同步一次 |
| `chunk_size` | 1000-1500 字符 | 通信设备财报包含长段落业务分析与拆分后的结构化表格文本，该区间可保留上下文完整性 |
| `retrieval_top_k` | 前8-12条 | 财报数据字段细分较多，需召回足够数量的相关片段以覆盖完整分析维度 |
| `LOCAL_EMBEDDING_MODEL_PATH` | ./models/m3e-large | 适配本地部署的M3E索引模型需求，需指向模型文件所在的本地目录 |
| `DOCKER_PLATFORM` | linux/arm64 | 适配鲲鹏920芯片架构与麒麟v10操作系统的国产化部署需求 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：部署后镜像无法在鲲鹏920芯片上运行，提示`exec format error`。原因：未指定`linux/arm64`构建平台，默认镜像适配x86架构，且未使用支持arm架构的FastGPT v0.9.2及以上版本，无法在arm架构设备上启动。
- 现象：本地部署M3E模型后，索引召回结果为空。原因：未正确配置`LOCAL_EMBEDDING_MODEL_PATH`指向模型文件目录，或未开启本地嵌入功能开关。
- 现象：SaaS版本运行代码执行节点时出现`500 Internal Server Error`。原因：未适配通信设备财报的自定义字段与单位，代码节点中未正确映射营收、出货量等字段的取值逻辑。

## 怎么确认配好了
- 上传一份通信设备季度财报PDF，查看解析后的文本片段是否包含正确的营收、出货量字段与对应单位。
- 触发一次定时同步任务，查看数据同步日志是否显示任务完成且无超时报错。
- 测试本地嵌入模型配置，输入一段财报文本，查看嵌入向量生成日志无异常提示。
- 运行代码执行节点，输入预设的财报字段组合，查看输出结果是否符合预设的分析格式。
