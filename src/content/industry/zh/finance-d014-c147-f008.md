# 造纸财报分析的工具调用与插件

## 这个品类的数据长什么样
造纸行业财报数据主要来自交易所公开披露平台、行业协会统计数据库及上市企业官方公告。数据更新节奏固定，季度报告于季后15个工作日内发布，年度报告于次年4月30日前完成披露，临时公告随原材料价格波动、产能调整等重大事项同步更新。财报文档多为PDF格式，部分季度报告附带结构化Excel附件，核心字段包含分品类产销总量、木浆/废纸采购量、吨纸生产成本、营收拆分数据，单位多为吨、万元、元/吨，部分关联数据需从多段公告文本中拼接提取。

## 这些特征在「工具调用与插件」这一环带来什么约束
造纸行业财报的多格式、多来源特征，要求工具调用环节同时适配PDF文本解析与结构化Excel数据提取。部分核心数据需跨公告拼接，因此插件需支持多接口联动调用，按公告发布时间顺序拼接字段。固定更新周期与临时公告的混合发布节奏，要求插件同时支持定时触发与手动触发两种调用模式。行业专属字段如吨纸生产成本、木浆采购占比，要求工具调用时支持自定义字段映射规则，避免通用解析模板的适配误差。部分公开数据未做结构化标注，需通过正则匹配提取，因此插件需内置造纸行业专属的正则匹配规则库。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 造纸行业财报PDF通常包含多页产销与成本数据，常规解析时长覆盖多数场景需求，300秒可预留足够缓冲时间 |
| `HTTP_REQUEST_RETRY_TIMES` | `3 次` | 交易所公开披露平台存在临时访问限流，重试3次可降低临时访问失败导致的任务中断 |
| `CUSTOM_PARSE_TEMPLATE` | `造纸财报专属字段映射规则` | 通用解析模板无法识别木浆采购量、吨纸生产成本等行业专属字段，需配置对应字段的提取规则 |
| `TRIGGER_MODE` | `定时触发+手动触发` | 季度报告更新周期固定，临时公告需随时调用，两种模式结合可覆盖全场景数据获取需求 |
| `GLOBAL_VAR_INIT_VALUE` | `造纸行业基准参数集` | 需预设吨纸成本均值、木浆采购占比等基准值，用于后续财报数据的横向对比分析 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：配置`GLOBAL_VAR_INIT_VALUE`后，全局变量未按预设值初始化，后续调用中变量值为空。原因：未在工作流启动节点绑定全局变量初始化配置，仅在插件配置中填写初始值未生效。
- 现象：工作流发起财报查询请求后，工具调用环节返回`429 Too Many Requests`错误。原因：未配置`HTTP_REQUEST_RETRY_TIMES`参数，或重试规则未适配交易所披露平台的访问限流要求。
- 现象：调用第三方API获取财报数据后，无法将响应内容写入全局变量。原因：未在HTTP请求组件中开启响应变量绑定开关，或绑定的字段名称与后续调用的变量名不匹配。

## 怎么确认配好了
- 上传单份造纸行业季度财报PDF，触发解析任务，核对解析结果中是否包含木浆采购量、吨纸成本等专属字段，确认自定义解析规则已正确加载。
- 分别通过定时触发与手动触发两种模式调用插件，核对任务均能正常启动并完成数据获取，确认双模式配置生效。
- 查看全局变量列表，确认预设的造纸行业基准参数已正确加载，核对变量值与配置的初始值一致。
- 多次调用数据接口，核对接口调用是否按配置触发重试机制，确认重试规则已正确配置。
