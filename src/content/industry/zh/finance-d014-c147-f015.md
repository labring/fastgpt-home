# 造纸财报分析的部署与升级

## 这个品类的数据长什么样
造纸行业财报数据主要来自境内证券交易所披露的上市公司定期报告，以及中国造纸协会发布的行业运行统计。更新节奏分为三类：上市公司年度、半年度定期报告按披露周期更新，行业产能、开工率数据按月度更新，原材料价格数据按周度更新。文档结构包含两类：上市公司财报PDF包含财务报表、经营分析、产能与成本明细章节，结构化行业数据多为固定格式的表格文件。字段涵盖营收、产能、单位产品能耗、原材料消耗等，单位分别为人民币元、万吨每年、千瓦时每吨、绝干吨浆每吨纸。

## 这些特征在「部署与升级」这一环带来什么约束
多源数据的更新周期差异，要求部署时配置分层的定时同步规则，避免同步任务冲突。造纸财报包含大量工业生产相关的细分字段，需配置专属的字段映射规则，与通用财务字段区分。单份年度财报PDF篇幅较长，可能超出默认的文件解析上限，需调整解析相关参数。行业数据格式可能随协会发布标准更新，升级时需兼容旧版与新版字段结构，避免数据解析失败。此外，造纸企业财报内的细分产品营收数据较多，需配置知识库集合分类存储，防止搜索时混入无关内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `PARSE_FILE_TIMEOUT_SECONDS` | 900 秒 | 造纸年度财报PDF篇幅较长，需预留足够的解析时间，避免中途超时中断 |
| `UPLOAD_FILE_MAX_SIZE` | 2000 MB | 单份完整年度财报PDF体积较大，适配大文件上传的需求 |
| `maxContext` | 8000–12000 字符 | 匹配造纸财报长文本的上下文窗口需求，避免截断关键的产能、成本明细数据 |
| `召回条数` | 前10条 | 覆盖造纸财报多维度的细分字段，确保召回足够相关的业务数据 |
| `SYNC_DATA_CRON` | `0 0 3 * * *`、`0 0 1 * * 0`、`0 0 1 1 * *` | 分别对应周度原材料数据、月度行业数据、年度财报的定时同步调度 |
| `知识库集合过滤规则` | 按「财报主体+报告周期」分组 | 区分上市公司财报与行业统计数据，避免跨集合搜索返回无关结果 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：知识库搜索指定集合时返回大量无关结果，原因：未配置`知识库集合过滤规则`，导致系统跨所有集合召回数据。
- 现象：V4.12.3版本中自定义插件运行后，输出下载地址反复跳动后才给出结果，原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，长文本解析过程中触发超时重连，导致输出状态反复更新。
- 现象：上传造纸财报PDF后解析失败，返回状态码504，原因：未将`UPLOAD_FILE_MAX_SIZE`调整至适配大文件的取值，或`PARSE_FILE_TIMEOUT_SECONDS`设置过短，导致解析过程超时。

## 怎么确认配好了
- 上传一份造纸企业年度财报PDF，核对解析后的文本与原文件内容匹配度，调整`PARSE_FILE_TIMEOUT_SECONDS`至无截断的取值。
- 发起知识库搜索请求，指定目标集合名称，确认返回结果仅来自该集合，验证`知识库集合过滤规则`的配置有效性。
- 查看定时同步任务的执行日志，确认各数据源按预设的调度周期完成同步，核对`SYNC_DATA_CRON`表达式的正确性。
- 使用多个账号登录系统，确认可同时访问同一知识库并编辑内容，验证协作权限配置的有效性。
