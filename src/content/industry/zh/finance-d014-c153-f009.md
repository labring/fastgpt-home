# 风电财报分析的引用来源与溯源

## 这个品类的数据长什么样
风电行业财报数据主要来自上市风电企业的定期披露报告、行业自律组织的公开统计资料，以及风电项目的运营台账。更新节奏以年度、半年度定期报告为主，部分并网项目的运营数据按月更新。文档结构包含风电业务板块的营收、装机容量、发电量、单位造价等核心字段，单位多采用千瓦、兆瓦、千瓦时、元/千瓦等，部分数据会附带项目编号、并网时间等关联标识。

## 这些特征在「引用来源与溯源」这一环带来什么约束
风电财报的定期更新节奏要求溯源时需匹配数据的发布时间与报告周期，避免引用过期或未披露的内容。风电业务数据常与企业整体财报混合披露，需精准定位风电板块的关联片段，否则易引入非风电业务的无关内容。项目级运营数据的溯源需要关联具体项目编号，而部分公开统计资料未标注项目细节，增加了精准溯源的难度。此外，不同来源的风电数据可能采用不同单位，如装机容量同时标注千瓦与兆瓦，需统一单位后再完成关联溯源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `召回条数` | 前8–12条 | 风电财报单块业务内容较长，需召回足够片段覆盖风电板块核心数据，避免遗漏关键信息 |
| `相似度阈值` | 0.75–0.85 | 风电财报包含大量专业术语，较高阈值可过滤非相关的通用财报内容，精准匹配风电业务片段 |
| `分段长度` | 3000–5000 字符 | 适配风电财报的长文本特征，匹配常见的5000token知识库切块配置，避免切割破坏业务逻辑关联 |
| `引用展示格式` | 含文件名称+段落页码+发布日期 | 风电财报需明确披露时间与板块归属，该格式可清晰标注来源的业务属性与时间节点 |
| `maxContext` | 12000–15000 字符 | 适配8–12条召回片段的总长度，匹配FastGPT 4.6.7版本的上下文处理逻辑，避免超出引用上限 |
| `重排返回条数` | 前3–5条 | 聚焦核心风电业务片段，避免过多引用导致内容冗余，提升溯源信息的可读性 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用知识库引用时返回`quote type error`报错。原因：未正确配置知识库的引用格式参数，或输入的引用变量未匹配预设的格式规则，比如未指定引用来源的类型字段。
- 现象：生成的回复中未展示知识库引用内容。原因：未开启`引用展示`配置项，或`引用展示格式`的参数配置错误，导致引用片段无法被正确提取并展示。
- 现象：知识库切块大小设置为5000token，召回匹配片段后，最终引用内容超出预设的1500字符上限。原因：未同步调整`maxContext`参数与`引用上限`配置，仅限制单条引用长度，未控制总召回内容的整合长度，导致超出预期。

## 怎么确认配好了
- 上传风电企业的财报片段，触发知识库检索，核对返回的引用片段是否仅覆盖风电业务相关内容。
- 查看回复中的引用标识，确认是否包含预设的溯源相关信息，如文件来源、发布时间等。
- 调整知识库切块与上下文参数，模拟业务场景，核对最终引用内容的长度是否符合配置预期。
- 触发引用格式校验场景，验证报错提示与配置的引用格式规则是否匹配。
