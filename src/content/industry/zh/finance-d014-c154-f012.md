# 饰品财报分析的模型接入与配置

## 这个品类的数据长什么样
饰品品类的财报数据主要来自境内外证券交易所披露的上市公司定期报告、品牌方公开的经营公告。数据更新节奏为季度报告每季度末后1个月内发布，年度报告于次年4月底前发布。文档多为PDF格式，包含结构化财务报表与非结构化经营分析内容，字段包含存货分类（按原材料、库存商品划分，单位为千克、件）、分品类营收、渠道收入占比、单位产品成本等，部分贵金属饰品相关财报还会标注贵金属含量与计价基准。

## 这些特征在「模型接入与配置」这一环带来什么约束
饰品品类财报的结构化字段包含带单位的存货、分品类营收等内容，且部分报告包含贵金属含量等特殊标注，要求模型接入时需支持带单位字段的精准提取。季度/年度的固定更新节奏，要求配置定时拉取任务时需匹配披露窗口，避免重复拉取或遗漏最新报告。PDF格式的文档结构包含嵌套表格，需确保解析组件能正确识别跨页表格内容，同时需限定解析范围为财报核心章节，排除无关的公告附件。另外，分品类营收的字段命名可能存在差异，需配置字段映射规则适配不同披露格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PARSE_PDF_TABLE_MODE` | `advanced` | 饰品财报包含嵌套跨页的财务表格，advanced模式可精准识别结构化字段与跨页内容 |
| `RECALL_CHUNK_SIZE` | `800–1200 字符` | 饰品财报的分品类营收、存货分析多分布在中等长度段落，该区间可完整覆盖核心分析信息 |
| `SCHEDULE_PULL_INTERVAL` | `7 天` | 季度财报更新周期为3个月，7天间隔可在披露窗口内及时拉取最新报告，同时避免冗余请求 |
| `FIELD_MAPPING_RULE` | `按财报章节+关键词匹配` | 不同品牌的饰品财报字段命名存在差异，通过章节（如「存货情况」）加关键词（如「黄金饰品营收」）可精准提取目标字段 |
| `UPLOAD_FILE_MAX_SIZE` | `50 MB` | 单份上市公司年度财报PDF的大小多在20-40 MB区间，该取值可覆盖绝大多数场景 |
| `SIMILARITY_THRESHOLD` | `0.75–0.85` | 过滤非核心的公告附件内容，仅保留与财报分析相关的高相关片段 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象为配置模型URL与密钥后，测试接口返回`401 Unauthorized`错误。原因是未正确配置模型的身份验证密钥，或密钥权限未开放对应财报分析的调用范围。
- 现象为调试时弹出`Connection error`提示。原因是配置的模型URL未正确指向可用的模型服务节点，或网络策略限制了跨域访问。
- 现象为通过API渠道发布后无法正常调用财报分析功能。原因是未在FastGPT的API配置中开启对应模型的访问权限，或请求头未携带正确的身份令牌。

## 怎么确认配好了
- 上传一份本地的饰品上市公司财报PDF，检查解析后的结构化字段是否包含存货、分品类营收等目标内容，核对字段单位是否与财报原文一致。
- 运行一次定时拉取任务，检查是否成功拉取到最新的公开财报数据，且未遗漏核心章节内容。
- 调用测试API接口，传入预设的财报分析提示词，检查返回结果是否包含准确的分品类营收、存货分析等内容。
- 查看模型调用日志，确认每次请求的响应状态码均为`200 OK`，无`401`或连接错误记录。
