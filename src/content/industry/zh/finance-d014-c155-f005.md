# 饲料财报分析的多轮对话与提示词

## 这个品类的数据长什么样
饲料财报相关数据的来源包括上市饲料企业的公开定期报告、行业协会发布的月度/季度产业监测数据、原材料期货市场的公开报价数据。更新节奏分为三类：企业定期报告按年度、半年度、季度披露，行业监测数据按月更新，原材料报价按日更新。单份财报文档通常包含营收与销量拆分、原材料成本占比、单吨盈利、下游养殖需求占比、产能利用率等板块，部分行业数据文档会按养殖品类拆分数据维度。核心字段包括分品类饲料销量、单吨销售价格、原材料采购成本、净利润、经营性现金流净额，单位多为万吨、元/吨、万元。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
饲料财报数据的多维度细分属性，要求多轮对话需精准保留品类、成本、销量等上下文限定，避免大模型混淆不同养殖品类的统计字段。不同更新频率的数据（如季度静态财报与实时原材料价格）需要在提示词中明确调用范围，防止大模型混用历史静态数据与实时动态信息。大规模明细销售数据（如10万条记录）会增加知识库召回与文档解析的负载，需要调整对话与解析的配置参数以适配数据规模。多轮对话中用户可能连续切换分析维度，提示词需明确每次交互的主题聚焦点，避免上下文溢出导致的逻辑混乱。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 字符 | 饲料财报数据维度多，多轮对话需保留品类、成本、销量等多维度上下文，避免丢失关键限定 |
| `相似度阈值` | 0.75–0.85 | 饲料数据字段细分（如猪料/禽料销量），需过滤低匹配度的无关文档，避免混淆不同品类数据 |
| `召回条数` | 前8–12条 | 单份饲料财报文档包含多板块数据，需召回足够数量的文档覆盖不同分析维度 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 饲料行业数据文档可能包含百万级明细数据，需延长解析超时时间以完成完整解析 |
| `重排返回条数` | 前5–7条 | 对召回的文档按相关性重排，优先返回与当前对话主题匹配的饲料细分品类数据 |
| `知识库绑定规则` | 按「饲料行业财报」标签绑定 | 避免多轮对话中召回非饲料品类的财报数据，确保上下文聚焦 |

> 本页给出的参数取值均为常规建议，用于确定配置的起点。实际取值受材料形态、数据量与业务规则影响，具体问题需具体分析，建议在自有样本上实测后再定。

## 容易做错的三处
- 现象：调用对话接口时返回非饲料品类的财报数据。原因：未在请求参数中绑定专属饲料行业财报知识库，导致召回了其他品类的文档。
- 现象：多轮对话中切换分析维度后，大模型仍沿用之前的品类限定，出现字段匹配错误。原因：未在提示词中明确每次对话的维度重置规则，导致上下文窗口保留了过期的限定条件。
- 现象：上传10万条销售明细数据时出现超时报错。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数至足够时长，默认超时时间不足以处理大规模明细数据。

## 怎么确认配好了
- 发起单轮对话测试，提问某一具体饲料品类的营收数据，核对返回结果是否仅包含饲料行业的相关字段，无无关品类数据。
- 发起连续多轮对话，依次提问不同品类的销量、关联原材料成本的影响，核对每次回复是否保留之前的对话上下文限定。
- 上传单份包含大规模明细数据的销售表格，核对系统是否能在设定的超时时间内完成解析并返回解析结果。
- 查看知识库绑定设置，确认已将饲料行业财报相关文档归类至专属标签下，避免与其他知识库混淆。
