# 权限内文件隔离的内部制度与数据问答：部署与升级

## 这个品类的数据长什么样
权限内文件隔离的数据源来自国央企内部的正式制度文件、权限限定的业务台账与数据报表。更新节奏随内部制度修订、业务数据迭代不定期触发，无固定周期。单份文档多为带权限标识的结构化文本，包含文件密级、访问部门范围、生效日期等字段，文件大小通常在几MB到几十MB区间，单篇文本字数跨度较大，从数百字符到数万字符不等。本文档适配FastGPT v4.17.0版本。

## 这些特征在「部署与升级」这一环带来什么约束
权限内文件隔离的数据源特征会对部署与升级环节带来多重约束。首先，文档包含密级、部门权限等字段，部署时需要对接内部身份认证系统完成权限映射，因此需提前配置`REDIS_URL`与`ROOT_KEY`相关的校验链路，确保访问权限匹配。其次，单份文档大小跨度大且更新无固定周期，部署时需预留适配多规格文档的存储资源，`STORAGE_S3_ENDPOINT`的配置需符合内部对象存储的接入规范。另外，权限隔离规则需在部署阶段完成初始绑定，升级过程中不能随意修改权限映射逻辑，否则会导致部分用户无法访问对应权限内的文档。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `REDIS_URL` | `redis://:自定义密码@内网Redis地址:6379/0` | 用于存储权限校验会话与缓存，需对接内部Redis集群，保障权限数据读写稳定 |
| `STORAGE_S3_ENDPOINT` | `http://内网对象存储域名:9000` | 适配内部对象存储的接入地址，用于存储权限隔离的文档与索引数据 |
| `ROOT_KEY` | `自定义强随机字符串，长度不低于32位` | 作为系统根权限的校验密钥，需与内部权限管理系统的密钥对齐，避免越权访问 |
| `MONGODB_URI` | `mongodb://用户名:密码@内网Mongo地址:27017/fastgpt?authSource=admin` | 存储权限配置与文档元数据，需配置内网访问的认证信息 |
| `DB_MAX_LINK` | `20–30` | 适配权限隔离场景下多用户并发访问的数据库连接数，避免连接耗尽 |
| `FE_DOMAIN` | `https://内部问答平台专属域名` | 配置前端访问域名，确保权限校验的回调地址符合内部网络安全规范 |

## 容易做错的三处
- 现象：Docker部署后无法插入权限配置数据，界面显示数据库连接超时。原因：未使用内网地址配置`MONGODB_URI`，容器无法连通内部数据库集群，导致元数据无法写入。
- 现象：处理权限内长文档时，问答结果出现内容截断或答非所问。原因：未合理配置`DB_MAX_LINK`的连接数，并发访问时数据库连接耗尽，无法完整读取文档内容。
- 现象：升级后语音发布功能无法正常使用，提示回调地址不安全。原因：未将`FE_DOMAIN`的配置从HTTP地址更新为HTTPS地址，不符合内部网络的安全访问要求。

## 怎么确认配好了
- 登录FastGPT后台的权限配置页面，确认已绑定的部门与文档权限映射关系与内部制度要求一致。
- 调用内部数据库测试接口，验证`MONGODB_URI`与`REDIS_URL`的连通性，确保无连接超时或认证失败报错。
- 上传一份测试用的权限内文档，使用不同部门的测试账号访问，确认仅授权用户可查看对应内容。
- 访问`FE_DOMAIN`配置的地址，验证前端页面可正常加载且无安全证书相关提示。
