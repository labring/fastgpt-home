# 主动公开与政策发布的办事咨询与答复：工具调用与插件

## 这个品类的数据长什么样
本品类数据主要来自政府门户网站、公文系统、政府信息公开目录、政策文件库、新闻发布会材料。数据更新频率为每日。日常文档包含政策文件、政策解读稿、公开目录、信息发布审批单、新闻通稿、网站栏目更新记录。文档字段包含公开属性标识、保密审查状态、发布渠道归属、受众范围、审批流程节点信息等，部分文档附带关联的图文素材链接。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源分散的数据来源要求工具调用适配不同接口的鉴权与数据拉取逻辑，避免跨系统数据格式不兼容的问题。每日更新的频率要求工具配置定时增量同步任务，防止全量拉取占用过多资源。多样的文档类型与字段差异，要求插件预设针对政策文件、审批单等不同文档的解析规则，确保字段提取准确。需嵌入敏感信息校验环节，规避涉密或敏感信息误公开的风险。主动发布的属性要求工具联动网站栏目与新媒体账号的同步逻辑，保障发布时效性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配多类型文档的工具调用需求，自动匹配政策文件、审批单等不同解析插件 |
| 单次搜索上限 | 前5条 | 匹配每日更新的政策文件数量规模，避免冗余数据占用上下文空间 |
| 重排 | 开启 | 优化政策解读稿与公开目录的检索相关性，提升信息匹配精度 |
| 最大上下文 | 8000–12000 token | 适配政策文件与解读稿的长文本处理需求，按实测标定 |
| 定时触发间隔 | 12–24小时 | 适配每日增量数据的更新节奏，避免全量拉取资源过载 |
| `functionCall` | 开启 | 强制工具调用输出符合预设的结构化格式，确保公开属性、保密状态等字段提取准确 |

## 容易做错的三处
- 工作流输出谷歌搜索结果为数组格式的对象，无法直接生成政策解读文本。原因是未配置`functionCall`强制结构化输出，工具调用未指定格式转换规则。
- MCP服务调用频繁中断或不触发。原因是未设置适配每日增量数据更新的定时同步触发逻辑，导致工具调用资源占用过载。
- 插件调用返回的图文素材显示不全。原因是未在配置中限定上下文长度，长文本内容截断导致素材链接未完整加载。

## 怎么确认配好了
- 触发一次政策文件解析测试，检查工具调用输出的结构化字段是否包含公开属性、保密状态等预设字段。
- 查看工具调用日志，确认单次搜索返回的结果条数符合配置的上限要求。
- 模拟每日增量数据同步任务，检查插件是否能正常拉取新生成的公开目录与审批单数据。
- 测试MCP服务调用流程，确认入参变量可正常绑定到工具调用的请求参数中。
