# 产权、资产与国有资本管理的办事咨询与答复：向量模型与索引

## 这个品类的数据长什么样
本品类数据主要来自国资监管信息系统、企业资产管理系统、产权交易所系统、评估机构报告及财务报表。日常文档包含产权登记表、资产评估报告、产权转让方案、进场交易公告、资产处置审批单，字段覆盖资产标识、权属主体、交易状态、评估结果等。数据更新频率为月度，文档兼具结构化表单字段与半结构化说明文本，单份文档长度跨度较大，部分进场交易公告文本量较大。

## 这些特征在「向量模型与索引」这一环带来什么约束
月度更新的频率要求索引支持批量增量同步，避免全量重建带来的资源消耗。文档兼具结构化字段与半结构化文本，分块处理时需兼顾单个资产标识、权属信息的完整性，避免拆分破坏语义关联。多来源的数据格式差异，要求预处理环节统一字段命名与文本格式，确保向量化过程中特征对齐。单份文档长度跨度较大，需适配不同长度的文本分块策略，同时合理设置`maxToken`与`defaultToken`参数，避免长文本语义丢失或短文本特征不足。同时，办事咨询场景聚焦国资专有术语，向量模型需适配行业专业语义表达。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 本品类文档兼具结构化字段与半结构化文本，该区间可平衡语义完整性与分块粒度 |
| 分块重叠长度 | 100–150 字符 | 避免分块拆分资产权属、交易流程等关键语义单元，保障跨块信息关联 |
| `maxToken` | 4096 | 适配主流向量模型的输入上限，满足长文档分块后的上下文拼接需求 |
| 相似度阈值 | 按实测标定 | 本行业专有术语较多，不同业务场景的语义匹配阈值差异较大 |
| 单次搜索上限 | 前 10 条 | 兼顾办事咨询场景的召回全面性与结果展示效率 |
| `defaultToken` | 1024 | 平衡查询向量的特征维度与系统计算资源消耗 |

## 容易做错的三处
- 现象：调用创建训练订单接口后，知识库任务状态显示失败，未生成对应索引。原因：未配置本品类专属文档的格式映射规则，无法识别产权登记表、资产评估报告等文档的结构化字段。
- 现象：重复发起相同的资产权属咨询查询，系统每次都触发向量数据库检索，未复用历史结果。原因：未开启查询缓存配置，或缓存有效期设置不符合本品类月度数据更新的节奏。
- 现象：上传包含评估报告附图的文档后，检索结果仅返回文本内容，未关联对应图片资源。原因：未配置图片向量化与文本向量的关联索引逻辑，仅完成了文本部分的向量化处理。

## 怎么确认配好了
本核对流程基于FastGPT v4.17.0版本操作。
- 执行一次批量同步本品类历史文档的操作，查看索引生成进度与任务日志，确认无格式报错。
- 发起一条资产权属相关的咨询查询，核对返回结果的字段是否覆盖本品类的核心业务信息。
- 调整相似度阈值后发起相同查询，对比返回结果的条数变化，确认阈值配置生效。
- 开启查询缓存后，重复发起相同咨询，确认系统未重复触发向量数据库检索。
