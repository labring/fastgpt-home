# 产权、资产与国有资本管理的办事咨询与答复：模型接入与配置

## 这个品类的数据长什么样
本品类数据来自国资监管信息系统、企业资产管理系统、产权交易所系统、评估机构报告与财务报表，更新频率为月度。日常文档包含产权登记表、资产评估报告、产权转让方案、进场交易公告、资产处置审批单，各文档包含权属编号、资产类别、账面价值、评估基准日、交易标的等固定字段，文档体量存在明显差异。

## 这些特征在「模型接入与配置」这一环带来什么约束
月度更新的数据源要求模型接入环节配置定期全量同步的调度逻辑，避免数据滞后于业务更新节奏。多来源的文档格式差异，需要在配置中适配不同的解析规则以准确提取权属、评估值等核心字段。固定字段的业务要求，模型输出需严格匹配预设字段，不能生成无关或错误内容。单文档体量差异较大的特征，会对上下文长度限制、召回片段的筛选规则带来约束，需平衡召回精度与响应速度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配产权转让方案、资产评估报告等单文档的体量，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 控制单轮回答的输出长度，确保办事咨询的响应简洁明确 |
| `quoteMaxToken` | 1500–2000 字符 | 限制召回片段的总长度，匹配业务文档的典型片段体量 |
| `temperature` | 0.1–0.3 | 降低回答的随机性，确保权属、评估值等关键业务信息的准确性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写对应地址 | 适配自建代理的访问路径，确保模型调用的连通性 |
| `AIPROXY_API_TOKEN` | 按实测标定 | 匹配代理服务的认证要求，避免未授权访问报错 |

## 容易做错的三处
- 调用模型时返回401 unauthorized报错，原因是未正确配置`AIPROXY_API_TOKEN`或代理地址无效，导致认证失败。
- 工作流的AI模型下拉列表为空，原因是未完成模型代理的基础配置，或代理服务未适配FastGPT v4.17.0的接入标准。
- 召回的资产片段与当前咨询不匹配，原因是未合理设置`quoteMaxToken`，导致召回片段过长或过短，无法精准匹配业务需求。

## 怎么确认配好了
- 执行模型连通性测试，查看返回结果是否包含合法的业务字段，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置正确。
- 上传单份资产评估报告进行测试，检查上下文加载是否正常，确认`maxContext`与`quoteMaxToken`的取值适配文档体量。
- 发起产权转让相关的咨询，检查模型输出是否严格匹配权属编号、评估值等固定字段，确认`temperature`的取值符合业务要求。
- 触发月度数据同步任务，查看同步日志是否正常完成，确认调度配置与数据源的更新频率匹配。
