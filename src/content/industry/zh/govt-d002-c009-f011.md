# 公共数据目录与开放的办事咨询与答复：表单与交互

## 这个品类的数据长什么样
本品类数据涵盖公共数据资源目录、数据开放清单、数据项说明、脱敏规则、接口文档及更新频率说明等文档，数据来源为地方公共数据开放平台、一体化大数据平台、部门业务数据库与电子证照库。数据按月度更新，核心字段包含数据项名称、开放范围、脱敏要求、接口地址、更新周期，所有内容均为结构化或半结构化格式，需明确标注授权边界与使用条件。FastGPT v4.17.0 支持对接该类数据源。

## 这些特征在「表单与交互」这一环带来什么约束
月度更新的频率要求表单需支持定期同步数据目录的变更，避免交互中展示过时数据项，防止目录与实际数据不一致。多来源的数据需在表单中区分数据所属部门与开放平台，防止混淆。结构化的字段要求表单输入需匹配固定格式，比如接口地址需校验URL格式，脱敏规则需预设可选值，避免无效输入引发数据泄露风险。数据项的授权边界需要在交互环节明确提示用户需遵守的使用要求，避免违规调用。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 绑定公共数据目录字段的输入框，限制输入长度为 200 字符 | 数据项说明文档的字段长度多在150字符以内，预留合理余量 |
| `userSelect` | 预设部门、开放平台两类选项，支持多选 | 数据来源包含多部门与平台，需明确数据归属 |
| 表单校验开关 | 开启，校验URL格式、脱敏规则选项合法性 | 接口文档与脱敏规则为固定格式，需避免无效输入 |
| 数据同步周期 | 30 天 | 本品类数据按月度更新，同步周期匹配更新频率 |
| 交互提示文案 | 包含数据使用授权要求、更新周期说明 | 需明确告知用户数据的开放条件与时效性 |
| 超时设置 | 60 秒 | 接口调用需预留足够的响应时间，避免频繁超时 |

## 容易做错的三处
- 现象为工作流中配置的`formInput`组件未在对话界面显示，交互内容为空。原因是未开启表单的对话渲染开关，或绑定的字段未正确关联公共数据目录的数据源。
- 现象为用户提交商业咨询表单后未收到对接通知。原因是未配置表单提交后的回调触发逻辑，或回调参数未正确匹配企业微信的消息推送规则。
- 现象为表单输入的脱敏规则选项未按预设展示，或选项与实际数据开放清单不符。原因是未定期同步数据目录的更新内容，或预设选项未覆盖最新的开放规则。

## 怎么确认配好了
- 打开测试对话界面，输入与公共数据目录相关的查询，确认表单组件正常加载并显示预设字段。
- 提交测试表单，检查是否触发对应回调或同步逻辑，验证数据来源同步周期是否按设定执行。
- 输入不符合格式的内容，确认表单触发校验提示，验证校验规则生效。
- 调整同步周期参数，检查数据目录的展示内容是否按新周期更新，验证配置生效。
