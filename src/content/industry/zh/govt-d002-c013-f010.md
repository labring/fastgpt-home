# 内控评价、审计与整改的办事咨询与答复：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自中央企业内控部门、审计部、财务部及下属企业、外部审计机构的内控系统、ERP、财务共享系统、审计管理系统与采购合同项目系统。日常文档包含内控自评报告、审计通知书、审计工作底稿、问题清单、整改台账、整改销号证明，字段涵盖问题描述、整改措施、佐证材料关联、销号状态等。数据更新频率为年度，文档结构多为结构化表格与段落结合的业务报告格式。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散于多套业务系统，需跨源整合后导入知识库，且更新频率低，无需高频增量同步。文档包含结构化表格与非结构化段落，检索时需兼顾字段精准匹配与全文语义召回。整改台账、销号证明等文档关联具体问题与责任主体，检索需支持按关联字段定向召回。审计工作底稿等原始凭证类文档需保留原始链接与佐证信息，检索结果需关联完整业务链路信息。单次检索需覆盖年度内的全部审计与整改文档，避免遗漏跨周期的问题整改记录。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 适配审计问题的语义匹配精度，避免召回无关的整改文档 |
| `limit` | 前10条 | 覆盖单次审计核查所需的问题与整改记录数量，避免结果过载 |
| `searchMode` | hybrid | 结合语义检索与关键词检索，适配结构化文档与非结构化段落的混合检索需求 |
| `usingReRank` | 开启 | 对召回结果重排，优先匹配审计问题与整改要求的强关联内容 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户提问扩展检索词，覆盖审计相关的同义词与业务术语 |
| `collectionIds` | 按审计/内控专属数据集配置 | 限定检索范围，避免混入非本品类的业务文档 |

## 容易做错的三处
- 检索结果条数远少于预期，仅返回几百条。原因：未配置`collectionIds`限定检索范围，误将全平台数据集纳入检索，或未导入完整年度的审计与整改文档。
- 检索结果无法匹配精准的审计问题描述，召回大量无关的财务报销文档。原因：未开启`usingReRank`或`similarity`阈值设置不合理，导致语义匹配精度不足。
- 导入的审计工作底稿中内嵌图片无法正常显示。原因：未将图片上传至平台支持的在线图床，直接使用本地文件路径作为链接，导致知识库无法加载图片资源。

## 怎么确认配好了
- 提交一条典型审计问题提问，核对检索结果是否包含对应问题清单与整改台账文档。
- 检查检索结果的排序，确认关联度高的文档排在前列。
- 导入一份包含内嵌图片的审计工作底稿，验证图片可正常加载。
- 导出知识库文件，核对文件大小与导入的文档总量匹配。
