# 参保登记与缴费核定的办事咨询与答复：工具调用与插件

本页面内容基于FastGPT v4.17.0版本的工具调用与插件功能规范。

## 这个品类的数据长什么样
本品类数据来自社会保险经办系统、税务社保费征收系统、市场主体登记信息及公安民政数据共享渠道，更新频率为每日。日常关联文档包括参保登记表、缴费基数申报表、人员增减表、社保费核定单、个人权益记录。数据字段包含单位主体标识、人员身份信息、缴费基数、核定缴费金额等，格式多为结构化表单或标准化报表，无大量非结构化文本内容。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据接入要求工具调用需同时对接社保经办、税务征收、市场主体登记等多个系统接口，需处理不同系统的接口格式差异。每日更新的数据源要求工具调用需配置合理的同步与刷新规则，避免使用过期数据生成咨询答复。结构化的表单文档要求工具调用需预设标准化的参数解析规则，适配结构化返回结果。涉及人员身份与缴费核心数据，工具调用需额外配置权限校验环节，确保仅授权主体可访问敏感信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工具调用超时时间 | 600 秒 | 需覆盖多系统接口请求的平均响应时长，避免因单系统延迟导致调用失败 |
| `toolChoice` | `auto` | 适配多数据源调用场景，自动选择匹配的工具完成数据查询与校验 |
| 单次工具调用返回条数上限 | 前20条 | 适配本品类数据量规模，避免返回冗余信息 |
| 上下文窗口大小 | 8000–12000 token | 适配社保数据的字段长度需求 |
| `functionCall` | 仅启用参保登记与缴费核定相关函数 | 聚焦本品类核心业务场景，避免无关函数调用消耗资源 |
| 函数调用参数校验 | 开启必填字段校验 | 匹配参保登记、缴费核定的结构化表单字段要求，过滤无效请求 |
| 插件权限配置 | 仅开放社保经办、税务征收等指定数据源插件 | 遵循数据访问权限管控要求，避免敏感数据泄露 |
| 结果解析模式 | 结构化字段提取 | 适配本品类标准化文档与数据格式，快速提取核心咨询答复所需信息 |
| 工作流结果绑定 | 绑定会话上下文变量 | 确保工具调用返回的缴费核定、人员增减信息可同步至咨询答复流程 |

## 容易做错的三处
- 现象为工作流节点执行工具调用后，后续节点无法获取到返回的结构化数据。原因是未配置工具调用结果的上下文绑定，导致返回值未同步至工作流变量池。
- 现象为调用模型查询社保数据时，界面显示的token消耗与实际API调用账单不一致。原因是工具调用的参数校验、多系统接口请求的日志未被计入界面统计范围，仅统计了模型生成的prompt部分。
- 现象为调用外部接口生成标准化报表后，无法将结果关联至用户咨询答复。原因是未配置文件存储与会话绑定的插件节点，未将返回的二进制数据转换为可分发的附件格式。

## 怎么确认配好了
- 发起模拟参保人员的咨询请求，验证工具调用能否返回符合本品类文档格式的结构化数据。
- 查看工具调用日志，确认多源系统接口的请求与返回流程正常。
- 检查权限配置项，确认仅授权的数据源插件可被调用。
- 触发超时场景测试，验证超时时间配置是否符合预设规则。
