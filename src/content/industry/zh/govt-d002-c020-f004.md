# 国土空间规划编制与实施评估的办事咨询与答复：工作流编排

## 这个品类的数据长什么样
该品类的日常文档包含国土空间总体规划、详细规划、专项规划、规划实施评估报告、公众意见汇总五类核心文件，数据来源为国土空间基础信息平台、自然资源调查监测数据、人口经济统计、遥感影像，更新频率为年。文档包含空间坐标、规划约束指标、公众意见条目等字段，无统一固定格式，需根据规划类型调整结构，单份文档长度跨度较大。

## 这些特征在「工作流编排」这一环带来什么约束
年更新频率意味着知识库无需高频刷新，可固定配置定期同步任务。多源异构数据来源要求工作流需支持跨数据源检索与格式兼容，适配空间数据、统计数据等不同类型内容。文档结构不统一，需在检索环节增加分类筛选逻辑，避免无关数据混入。需汇总多源空间数据与公众意见，导致工作流节点间数据传递量较大，需配置合理的上下文长度限制。规划审批关联的出错后果要求工作流增加校验环节，确保核心数据准确无误。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 绑定规划指标、公众意见、空间坐标三类变量 | 该品类核心文档需关联三类数据，确保检索与生成环节精准匹配业务需求 |
| `nodeId` | 绑定知识库检索节点、按钮触发节点的ID | 需精准调用对应环节的资源，避免工作流链路混乱 |
| 知识库选择 | 绑定国土空间基础信息平台知识库、规划报告知识库 | 数据来源固定，专属知识库可过滤无关内容 |
| 单次搜索上限 | 前5条 | 多源数据需精简后汇总，避免信息过载影响审批效率 |
| 超时设置 | 600 秒 | 空间数据处理耗时较长，需预留足够的检索与生成时间 |
| 最大上下文长度 | 800–1200 字符 | 适配多源数据汇总后的文本长度，避免超出处理上限 |

## 容易做错的三处
- 现象：知识库检索结果包含大量无关文档，原因：未绑定该品类专属的知识库，错误调用通用行业知识库，导致检索精度下降。
- 现象：会话中触发按钮未正常弹出，原因：未配置`nodeId`绑定触发节点，导致工作流链路断裂，无法正常渲染交互组件。
- 现象：生成的Mermaid流程图链接无法加载，原因：未正确通过`variables`引用空间规划数据字段，导致生成参数缺失，无法生成有效链接。

## 怎么确认配好了
- 检查`variables`是否绑定了规划指标、公众意见、空间坐标三类核心数据，确认无遗漏。
- 测试触发按钮，确认点击后能正常提交测试意见，且数据能同步至对应工作流节点。
- 调用Mermaid MCP Server，输入规划相关参数，验证生成的流程图链接可正常访问。
- 检索专属知识库，确认返回结果仅包含该品类的规划文档与相关数据。
