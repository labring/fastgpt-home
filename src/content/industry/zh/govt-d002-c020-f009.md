# 国土空间规划编制与实施评估的办事咨询与答复：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源包括国土空间基础信息平台、自然资源调查监测数据、人口经济统计、遥感影像，更新频率为年。日常处理的文档包含国土空间总体规划、详细规划、专项规划、规划实施评估报告、公众意见汇总，涵盖空间矢量图层、属性统计字段与非结构化反馈内容，涉及区域空间布局、管控指标、公众诉求等核心信息。

## 这些特征在「模型接入与配置」这一环带来什么约束
年更新的数据特征要求知识库同步周期适配年度数据更新节奏，避免使用过期的规划内容。多源异构的数据结构要求模型配置支持空间图层、统计报表与公众意见等混合格式内容的解析与关联。长篇幅的规划文档要求配置足够的上下文窗口以承载完整的业务数据片段，避免关键信息丢失。同时，规划审批延误的出错后果要求配置稳定的模型调用重试机制与错误捕获逻辑，保障答复的准确性与及时性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 国土空间规划文档篇幅较长，需承载完整的规划文本、关联数据与公众意见片段 |
| `maxTokens` | 4000–6000 token | 控制办事咨询答复的单轮输出长度，适配通用模型接口的输出限制 |
| `quoteMaxToken` | 2000–3000 token | 确保可从规划报告、实施评估材料中提取足够的合规依据片段支撑答复 |
| `temperature` | 0.2–0.4 | 规划答复需保持严谨性，避免生成与政策不符的随意内容 |
| `AIPROXY_API_ENDPOINT` | 合规的国内模型代理端点 | 适配自然资源部门的数据安全与合规要求，避免跨境数据传输风险 |
| `toolChoice` | auto | 自动调用必要的工具处理空间数据解析、多源数据关联等复杂任务 |

## 容易做错的三处
- 现象：文本提取组件返回空结果，或无法从知识库引用中提取规划文档内容。原因：未配置`quoteMaxToken`参数的合理取值，导致提取的依据片段长度不足，或未开启对应工具的文档解析权限。
- 现象：调用模型时提示无可用模型权限。原因：未正确配置`AIPROXY_API_TOKEN`参数，或代理端点的权限未开通，导致无法正常调用模型接口。
- 现象：模型调用超时或返回结果截断。原因：未根据规划文档的实际长度调整`maxContext`或`maxTokens`参数，超出了模型接口的承载上限。

## 怎么确认配好了
- 上传一份典型的国土空间总体规划文档，测试从知识库中引用该文档的内容提取，检查返回结果是否包含文档片段。
- 配置完成后发起一条规划咨询类的测试问题，检查模型是否能正常返回答复且无报错提示。
- 核对`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置内容，确保与使用的模型服务信息一致。
- 调整`temperature`参数后发起测试，检查答复内容的严谨性是否符合预期，确认参数取值适配业务需求。
