# 土地使用权、矿业权与国有产权交易的办事咨询与答复：多轮对话与提示词

## 这个品类的数据长什么样
该品类的数据主要来自全国公共资源交易平台、自然资源交易系统、产权交易所系统及国资监管系统，更新频率为每日。日常涉及的文档包括出让公告、交易须知、竞买申请、保证金凭证、成交确认书、挂牌结果公告、产权转让说明书等，文档通常包含标的权属说明、参数信息、交易流程指引、资金凭证及成交确认类内容，字段涉及标的位置、权属状态、竞买要求、保证金金额等核心信息。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
数据每日更新的特性要求多轮对话上下文需实时关联最新的挂牌、公告或交易信息，避免引用过期内容。文档结构跨度较大，从简短的交易须知到篇幅较长的产权转让说明书，提示词需适配不同长度的上下文输入，确保核心信息不被截断。权属、估值、保证金等为核心业务字段，多轮对话需聚焦这些内容的核对与澄清，不得偏离交易标的的核心逻辑。不同系统的数据格式存在差异，提示词需明确统一的信息提取口径，避免混淆不同来源的字段定义。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `messages` | 保留最近10条对话记录，单条消息不超过1500字符 | 适配该品类文档的分段长度，避免上下文溢出影响模型理解 |
| `variables` | 预设权属核验、保证金规则、交易流程三类业务变量 | 快速调用品类专属规则，减少重复提示词编写成本 |
| 最大上下文 | 8000–12000字符，按实测标定 | 覆盖多数产权转让说明书、挂牌公告的核心内容篇幅 |
| 单次搜索上限 | 前6条 | 匹配公共资源交易平台的公示信息展示条数，符合业务人员的信息获取习惯 |
| 问题优化 | 开启 | 对用户咨询进行拆解，聚焦权属、保证金等核心字段，提升回复精准度 |
| `chatId` | 绑定交易标的专属ID | 区分不同标的的对话上下文，避免跨标的信息混淆 |

## 容易做错的三处
- 上传竞买申请、保证金凭证等交易文件时，对话框始终不解析，后台无报错。原因：未配置适配该品类文档的分块规则，或文件上传时未正确关联对话上下文。
- 将AI对话内容复制到飞书对话后，markdown格式丢失，仅显示纯文本。原因：未开启对话内容的格式保留配置，或导出时未选择正确的格式选项。
- 无法通过API停止当前正在运行的咨询对话。原因：未正确调用绑定`chatId`的对话终止接口，或接口参数未匹配当前会话的唯一标识。

## 怎么确认配好了
- 上传一份产权转让说明书，检查对话上下文是否能正确提取标的权属、保证金金额等核心字段。
- 调用`messages`接口，查看当前对话的上下文记录条数是否符合预设的10条限制。
- 测试上传交易类文件，确认解析后能在对话中显示文件内容的分块信息。
- 尝试通过绑定`chatId`的API终止对话，确认对话能正常停止。
