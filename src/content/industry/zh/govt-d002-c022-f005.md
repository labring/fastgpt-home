# 土地使用权、矿业权与国有产权交易的办事咨询与答复：工具调用与插件

本文档基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
该品类的数据通常来自全国公共资源交易平台、自然资源交易系统、产权交易所系统及国资监管系统，每日更新。日常文档包含出让公告、交易须知、竞买申请、保证金凭证、成交确认书、挂牌结果公告、产权转让说明书，核心字段涵盖标的权属信息、交易限制条件、保证金金额、竞价规则、成交确认编号等，单位涉及平方米、万元、宗等资源资产权属相关计量标准。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据来源要求工具调用需配置多系统对接适配逻辑，保障数据同步的完整性。每日更新频率要求插件设置定时增量拉取任务，避免数据滞后影响咨询答复准确性。多样的文档类型要求工具调用针对不同文档预设专属解析规则，精准提取权属、保证金、竞价规则等核心字段。核心字段涉及国有资产权属，工具调用的`functionCall`参数需预设专属校验函数，参数校验环节需强化合法性检查，防止因字段提取错误引发交易风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配该品类多类型交易文档的工具调用需求，无需手动限定单一函数 |
| `functionCall` | `["extract_transaction_info", "verify_asset_right"]` | 针对土地、矿业权、国有产权交易的核心业务，预设提取交易信息与校验权属的函数 |
| 单次搜索上限 | 前8条 | 该品类单条办事咨询通常关联3-7条相关交易文档，前8条可覆盖绝大多数咨询场景 |
| 最大上下文长度 | 8000-12000 token | 交易类文档包含出让公告、成交确认书等多段内容，该区间可完整承载核心业务信息 |
| 超时阈值 | 600秒 | 跨公共资源交易、自然资源系统等多源数据调用，600秒可覆盖多数跨系统响应时长 |
| 问题优化开关 | 开启 | 该品类咨询涉及专业权属术语，开启后可优化问题表述，提升工具调用匹配精度 |

## 容易做错的三处
- 调用工具时返回401状态码，原因：未正确配置对接公共资源交易平台的API密钥权限，或密钥未绑定该品类专属的交易数据访问范围。
- 工具调用后提取的标的权属信息缺失，原因：未针对土地使用权、矿业权等不同交易类型预设差异化的字段提取规则，导致无法匹配对应文档结构。
- 工具调用触发超时报错，原因：未设置适配多源系统的超时阈值，或跨系统数据拉取时未启用增量同步逻辑，导致请求时长超出预设限制。

## 怎么确认配好了
- 发起一条针对国有产权转让的咨询，核对工具调用返回的文档是否包含出让公告、成交确认书等该品类专属文档。
- 检查API密钥配置项，确认密钥已绑定公共资源交易平台的访问权限，无跨品类数据访问限制。
- 触发工具调用，查看日志中是否包含该品类专属的权属校验函数调用记录，无报错信息。
- 模拟跨系统数据拉取，确认工具在预设时长内可完成多源数据同步，无超时报错。
