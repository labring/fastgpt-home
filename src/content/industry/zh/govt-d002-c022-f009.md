# 土地使用权、矿业权与国有产权交易的办事咨询与答复：模型接入与配置

## 这个品类的数据长什么样
该品类数据通常来自全国公共资源交易平台、自然资源交易系统、产权交易所系统及国资监管系统，每日更新。日常文档包含出让公告、交易须知、竞买申请、保证金凭证、成交确认书、挂牌结果公告、产权转让说明书，核心字段包含交易标的权属信息、限制条件、竞价规则、保证金标准与成交确认细节，数据围绕资源资产权利的交易全流程生成。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类数据来源分散且每日更新，要求模型接入环节需支持多数据源的格式适配与增量同步，避免因数据滞后影响咨询答复准确性。文档类型跨度大，从简短的保证金凭证到数千字的出让公告，需适配不同长度的文本分块与召回逻辑。核心字段聚焦权属、限制条件、竞价规则等关键交易信息，模型配置需优先保障这些字段的召回权重与匹配精度，同时需严格校验返回内容的合规性，防止因错误答复引发成交无效或资产流失争议。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配该品类长文档（如出让公告、产权转让说明书）的上下文需求，避免截断核心交易信息 |
| `maxTokens` | 2000–3000 token | 匹配办事咨询答复的长度需求，既覆盖完整交易规则说明，又避免输出冗余内容 |
| `quoteMaxToken` | 1500–2000 token | 保障召回的交易文档片段（如权属说明、竞价规则）能完整纳入上下文，不被截断 |
| `temperature` | 0.1–0.3 | 降低随机输出概率，保障权属、竞价规则等关键信息的答复准确性 |
| `AIPROXY_API_ENDPOINT` | 对应部署的FastGPT代理地址 | 适配多数据源接入的代理转发需求，统一接口调用路径 |
| `AIPROXY_API_TOKEN` | 按系统分配的专属密钥 | 保障接口调用的身份验证，防止未授权访问 |

## 容易做错的三处
- 配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`后，调用API返回401 Unauthorized错误。原因是密钥配置有误，或代理地址未绑定对应访问权限。
- 调试模型时出现Connection error提示。原因是代理地址无法正常访问，或网络策略限制了与模型服务的通信链路。
- 模型仅返回单个匹配文本块，未输出多份文档的综合答复内容。原因是`quoteMaxToken`配置值过小，仅能容纳单条文档片段，或召回逻辑未设置多结果召回规则。

## 怎么确认配好了
- 发起API调用测试，核对返回的HTTP状态码符合正常响应范围，无身份验证类报错。
- 输入包含交易权属、竞价规则的咨询问题，核对返回内容引用了多份不同的业务文档片段。
- 调整`temperature`参数后，多次调用同一咨询问题，核对返回内容的核心交易信息无明显随机偏差。
- 查看系统同步日志，确认业务数据的更新频率符合预设的每日更新要求。
