# 土地使用权、矿业权与国有产权交易的办事咨询与答复：表单与交互

## 这个品类的数据长什么样
该品类数据主要来自全国公共资源交易平台、自然资源交易系统、产权交易所系统及国资监管系统，更新频率为每日。日常文档包含出让公告、交易须知、竞买申请、保证金凭证、成交确认书、挂牌结果公告、产权转让说明书，核心字段涵盖交易标的权属信息、限制条件、保证金金额、竞价规则及成交确认细节，单位多为平方米、万元、宗等与资源资产权利相关的标准单位。

## 这些特征在「表单与交互」这一环带来什么约束
数据来源分散且每日更新，要求表单交互环节需支持多数据源的实时关联调用，确保咨询内容匹配最新的挂牌与审核状态。文档类型多样且字段专业，需配置适配权属、竞价规则等专业术语的输入校验逻辑。核心字段涉及权属证明、保证金金额等关键信息，交互环节需强化必填项与格式校验，减少无效提交。数据关联交易合规性，表单需联动前置环节的审核状态，避免出现不符合要求的咨询或申请提交。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的界面逻辑。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 按竞买申请、保证金缴纳等场景预设固定字段组 | 匹配品类核心文档的固定字段结构，减少用户输入错误 |
| `userSelect` | 按出让/转让、竞买/竞价场景预设选项 | 匹配公共资源交易的常规业务分类，降低输入复杂度 |
| 单次搜索上限 | 前6–10条 | 覆盖多数交易标的的关联文档数量，避免结果过载 |
| 输入格式校验 | 匹配平方米、万元等专业单位 | 适配品类核心字段的单位规范，减少格式错误 |
| 会话超时阈值 | 900秒 | 匹配多数交易咨询的完整交互周期，确保会话连贯性 |
| 知识库关联规则 | 按业务场景绑定对应数据源 | 匹配品类多系统分散的数据来源，提升搜索精准度 |

## 容易做错的三处
- 现象：调用时仅返回单一场景的搜索结果，无法覆盖跨系统的咨询需求。原因：未配置按业务场景绑定对应知识库的规则，仅绑定了单一数据源。
- 现象：搜索结果无法区分不同交易类型的文档，匹配精度不足。原因：未针对不同业务场景配置独立的向量索引，仅使用单一组向量模型处理全量数据。
- 现象：表单提交后出现字段格式错误，且无法获取明确的报错提示。原因：未配置匹配专业单位的输入格式校验，导致非标准单位的输入被拦截。

## 怎么确认配好了
- 发起不同业务类型的测试咨询，确认返回的文档与当前选择的业务场景匹配。
- 输入包含专业单位的测试内容，确认格式校验逻辑正常拦截非标准输入。
- 提交预设的字段组表单，确认所有必填项均完成校验且无格式错误。
- 等待超过设置的会话超时阈值，确认会话状态正常保存或提示重新发起咨询。
