# 工程建设项目审批的办事咨询与答复：工具调用与插件

## 这个品类的数据长什么样
本品类数据来自工程建设项目审批管理系统、施工图审查系统、企业资质库、信用平台，更新频率为每日。日常处理的文档包含施工许可申请、施工图审查合格书、质量安全监督手续、竣工验收备案表等，字段涵盖审批节点、参建单位资质、人员信息、材料提交状态等，数据维度围绕项目审批全流程的许可、备案与合规信息展开，无统一固定的单文档字数或字段数量上限。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类多源数据的特性要求工具调用需适配工程建设项目审批管理系统、施工图审查系统等多个独立数据源的接口格式，避免跨系统数据对接异常。每日更新的数据频率要求工具调用的缓存策略需匹配更新节奏，防止返回过期审批节点或资质信息。多类审批文档的差异化字段，要求工具能识别不同文档的专属信息维度，精准提取所需内容。同时，审批流程出错会导致无证施工或备案失败，工具调用的结果校验环节需覆盖参建单位资质、材料完整性等核心字段，保障审批流程合规。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 设为`auto` | 适配工程审批场景中需动态决策是否调用资质查询、材料校验等工具的需求，由模型自主判断调用时机 |
| `functionCall` | 开启并指定允许调用的工具范围为资质库查询、审批节点跟踪两类 | 限制工具调用的边界，避免调用与审批无关的外部接口，符合本品类数据的使用范围 |
| 工具调用超时时间 | 300 秒 | 匹配多系统接口的平均响应时长，避免因单个数据源响应缓慢导致整体流程中断 |
| 文档自动识别开关 | 开启 | 自动区分施工许可申请、施工图审查合格书等不同类型的审批文档，适配多类文档的字段提取需求 |
| 数据同步频率 | 每日凌晨 2 点 | 匹配本品类数据的日更新节奏，保证工具调用时获取的是最新的审批与资质信息 |
| 结果校验规则 | 按实测标定 | 针对参建单位资质、审批节点状态等核心字段设置校验逻辑，确保返回数据符合审批要求 |

## 容易做错的三处
- 现象：调用自定义外部接口后返回字段为空或状态码异常。原因：未在插件配置中指定本品类所需的数据源接口地址与参数格式，导致无法正确对接工程建设项目审批管理系统或资质库。
- 现象：模型未自动读取施工图审查合格书等审批文档内容。原因：未开启自动文件上传后的工具调用模式，或未配置`toolChoice`为`auto`，导致模型无法自主判断是否需要读取文档。
- 现象：工具调用返回过期的审批节点信息。原因：未配置数据同步频率与本品类日更新节奏匹配，使用了缓存的旧数据。

## 怎么确认配好了
- 发起包含参建单位资质查询需求的测试会话，检查工具是否自动调用预设的资质库查询接口并返回对应结果。
- 上传施工许可申请文档，检查模型是否自动触发文档内容读取并提取申请单位、项目名称等核心信息。
- 查看工具调用日志，确认所有调用的接口均为预先配置的工程审批相关数据源，无无关外部调用。
- 等待每日同步任务执行完成后，发起审批节点跟踪请求，检查返回的节点信息为最新更新的数据。
