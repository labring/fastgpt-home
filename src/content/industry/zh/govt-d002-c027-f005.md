# 工程建设项目招投标的办事咨询与答复：工具调用与插件

## 这个品类的数据长什么样
本品类数据来源为全国公共资源交易平台、地方公共资源交易平台、工程审批系统及招标投标监管系统，更新频率为每日。日常处理的文档包括招标公告、资格预审文件、招标文件、投标文件、评标报告、中标候选人公示及中标结果公告，文档字段多包含标段划分、资格条件、工程量清单、评标专家记录、中标信息等，不同平台的文档字段格式存在差异。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散且每日更新，要求工具调用需适配多平台API接口，避免单次调用超时引发数据获取失败。文档类型多样且字段不统一，需插件支持动态匹配不同文档的字段结构，避免无法解析资格条件、工程量清单等核心内容。中标结果类文档的更新直接关联项目进度，工具调用需保障数据实时性，否则可能引发异议投诉或项目延误。同时，招投标相关数据涉及合规性要求，插件需过滤敏感信息，避免违规内容泄露。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配招投标场景下动态触发工具调用的需求，无需手动指定工具类型 |
| `functionCall` | 按工具返回结果自动触发 | 适配办事咨询场景下的动态问答逻辑，无需提前预设调用流程 |
| 单次搜索上限 | 前 8 条 | 匹配招投标文档的字段密度，覆盖常见的资格条件、标段信息等核心内容 |
| 最大上下文 | 8000–12000 字符 | 容纳完整的招标公告、评标报告等长文档内容，避免截断关键信息 |
| 日志收集与管理 | 全链路记录 | 覆盖工具调用、API请求、结果返回的全流程，便于排查合规与执行问题 |
| 知识库访问权限 | 按角色分级配置 | 区分内部工作人员与公众的知识库访问范围，保障招投标数据的合规性 |

## 容易做错的三处
- 调用后返回`401 Unauthorized`报错，原因是未正确获取并配置访问密钥，误用公开知识库的访问地址作为调用凭证。
- 工具顺序执行时出现参数为空的结果，原因是未在插件间配置参数传递规则，导致前序调用获取的评标专家数据无法传入后续的异议处理环节。
- 导入WordPress网站代码后无法匹配招投标文档字段，原因是未启用插件的专业文档解析模式，仅使用通用文本分块逻辑处理结构化内容。

## 怎么确认配好了
- 发起一条针对招标公告的办事咨询，检查工具调用是否自动触发文档检索，确认`toolChoice`配置生效。
- 查看日志记录，确认全链路的API请求、参数传递和结果返回均被完整收集，验证日志配置正确。
- 尝试调用工具生成中标结果的咨询答复，检查是否适配了招投标场景的专业术语，验证问题优化配置生效。
- 测试不同来源的招投标文档，确认插件可以正确解析标段划分、资格条件等字段，验证字段匹配逻辑正常。
