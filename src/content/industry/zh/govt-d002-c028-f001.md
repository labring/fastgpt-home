# 市场主体登记与许可的办事咨询与答复：HTTP 接口与外部系统

## 这个品类的数据长什么样
本品类数据主要来自企业登记全程电子化系统、国家企业信用信息公示系统、电子营业执照系统与住所信息库，每日更新。日常关联文档包含设立登记申请书、章程、股东决议、住所证明、营业执照、食品经营许可申请等。数据字段涵盖主体名称、统一社会信用代码、住所地址、许可类别、申请状态、办理进度等，所有字段均严格匹配官方登记规范，无额外自定义统计字段。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
数据来源多为官方政务系统，接口需遵循政务网安全规范，需配置`Authorization`参数携带合法政务网关令牌。每日更新的数据源要求接口同步频率匹配日更节奏，避免缓存过期导致数据偏差。关联文档多为结构化表单与证照文件，接口需支持多类型附件上传校验，字段校验需严格匹配官方登记表单的必填项规则，不可遗漏住所、股东信息等核心字段。政务系统接口通常有严格的调用频次限制，需配置合理的请求间隔，防止触发限流规则。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer 政务网关颁发的服务令牌` | 遵循官方政务接口的身份校验要求，确保调用权限合法 |
| 请求超时设置 | `60 秒` | 匹配政务系统核验业务的常规响应时长，避免提前中断请求 |
| 请求间隔配置 | `10–15 秒` | 匹配政务系统的调用频次限制，防止触发限流 |
| `variables` | 绑定统一社会信用代码、申请主体名称等核心业务变量 | 动态代入专属业务参数，适配不同登记与许可申请场景 |
| `responseData` | 仅返回状态码、申请进度、驳回原因三个核心字段 | 过滤冗余返回内容，减少数据处理开销，匹配咨询答复的核心需求 |
| 附件上传校验 | 限制单文件大小不超过 1000 MB | 匹配日常关联文档的常规大小范围，符合政务系统上传规范 |

## 容易做错的三处
- 现象：调用政务接口返回401 Unauthorized状态码，原因：未正确配置`Authorization`参数，未携带合法的政务网关服务令牌。
- 现象：浏览器控制台提示跨域请求错误，无法正常调用外部接口，原因：未在政务网关配置允许的FastGPT调用域名，未正确处理跨域请求头。
- 现象：接口返回的`responseData`包含大量非必要字段，导致咨询答复内容冗余，原因：未按业务需求过滤返回数据，直接使用政务接口的全量返回结果。

## 怎么确认配好了
- 使用FastGPT v4.17.0的接口调试工具发起测试调用，检查返回的`responseData`是否仅包含业务所需的核心字段，确认数据过滤配置生效。
- 查看接口调用日志，确认`Authorization`参数已正确携带令牌，无身份校验失败记录。
- 模拟连续发起请求，检查是否触发政务系统的限流规则，确认请求间隔配置符合系统要求。
- 上传测试用的住所证明文件，检查附件上传校验是否正常拦截超出阈值的文件，确认配置生效。
