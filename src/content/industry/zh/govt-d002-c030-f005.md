# 建设工程质量安全监督的办事咨询与答复：工具调用与插件

## 这个品类的数据长什么样
建设工程质量安全监督领域的核心数据来自工程质量安全监管系统、施工现场实名制平台、监理日志及检测报告，更新频率为每周一次。日常处理的文档包含监督计划、监督检查记录、隐患整改通知书、质量问题处理单、竣工验收监督报告，各文档包含主体单位信息、现场检查项、整改要求、验收核查项等字段，无统一固定单位，部分字段需关联现场实测数据。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散且每周更新，要求工具调用需支持多数据源同步拉取，避免单次调用数据不全。文档类型多样且字段关联紧密，需插件支持按文档类型匹配调用规则，避免混淆不同业务文档的字段逻辑。隐患整改闭环及竣工验收核对环节依赖实时数据校验，要求工具调用具备短周期数据刷新能力，否则无法支撑现场即时核查需求。数据关联出错会引发质量安全事故，需插件在调用失败时触发告警，避免错误数据流入咨询答复环节。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工具调用触发规则 | 按文档类型匹配 | 匹配本品类文档类型多样的特征，针对监督计划、整改通知书等不同文档配置对应调用逻辑 |
| 数据源同步间隔 | 168 小时（7天） | 匹配数据每周更新的频率，避免同步过频占用资源或过慢导致数据滞后 |
| `toolChoice` 参数配置 | 自动匹配对应数据源的工具 | 依据多数据源分散的特征，自动匹配对应数据源的调用接口，减少手动配置成本 |
| 调用失败重试次数 | 3 次 | 应对施工现场网络波动或系统临时故障，避免单次调用失败直接终止流程 |
| 结果返回条数 | 前 3 条 | 依据单周期数据量规模，返回最相关的文档条目，避免结果过多干扰答复 |
| 超时阈值 | 600 秒 | 匹配现场核查的即时性需求，避免过长等待影响办事咨询响应 |

## 容易做错的三处
- 现象：调用住建质安站专属监管系统接口返回鉴权失败。原因：未针对该系统的专属鉴权规则配置插件密钥，直接使用通用鉴权参数。
- 现象：工具调用返回结果条数与预期不符。原因：误将结果返回条数设置为超出单周期数据量的数值，导致返回冗余或缺失关键条目。
- 现象：插件无法自动生成隐患整改跟踪相关代码。原因：未配置对应文档类型的字段映射规则，无法提取隐患整改通知书中的关键信息用于代码生成。

## 怎么确认配好了
- 手动触发针对监督检查记录的工具调用，核对返回的文档类型与配置的匹配规则一致。
- 模拟系统临时故障，触发调用失败，确认插件会按配置的重试次数执行重试。
- 查看FastGPT v4.17.0版本的工具调用日志，确认`toolChoice`参数按自动匹配规则关联到对应数据源的调用接口。
- 输入竣工验收相关咨询，核对返回的结果条数符合配置的前3条要求。
