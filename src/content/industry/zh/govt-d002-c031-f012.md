# 建设项目环评审批的办事咨询与答复：部署与升级

## 这个品类的数据长什么样
本品类的数据来源于全国建设项目环评统一申报和审批系统、生态环境分区管控成果、排污许可平台、监测数据，更新频率不定期。日常处理的文档包括环境影响报告书或报告表、审批申请、公众参与说明、技术评估意见、环评批复，文档结构包含项目基本信息、类别等级、污染防治措施、公众参与反馈等核心字段，不同文档的字段复杂度与体积差异较大，部分报告书文档体积可达数百兆。

## 这些特征在「部署与升级」这一环带来什么约束
多源且不定期更新的数据来源，要求部署时支持灵活接入不同系统的数据源，升级过程中需保障数据同步不中断。文档结构与体积的差异，要求配置适配多格式文档的解析与存储能力，避免大体积文件上传失败。核心业务环节的高风险属性，要求部署的服务具备高可用性，升级时需预留回滚方案防止影响审批流程。并发请求随项目申报高峰波动，需配置足够的资源支撑峰值流量。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30` | 环评审批业务存在申报高峰时段，该连接数可支撑并发的文档检索与存储请求，避免数据库连接超限 |
| `MONGODB_URI` | `mongodb://username:password@host:port/epi_approval?authSource=admin` | 用于存储环评报告书、公众参与说明等非结构化文档，专用MongoDB实例可保障读写性能与数据安全 |
| `REDIS_URL` | `redis://:your_redis_password@redis-host:6379/0` | 缓存高频查询的项目分类、生态环境分区管控数据，降低后端数据库的重复请求压力 |
| `FE_DOMAIN` | `https://epi-approval.your-government-domain.gov.cn` | 绑定官方办事咨询的合规域名，确保用户访问路径符合政务服务要求 |
| `STORAGE_S3_ENDPOINT` | `https://s3-cn-beijing.aliyuncs.com` | 用于存储大体积的环评报告书与批复文件，适配政务云合规的存储服务标准 |

## 容易做错的三处
- 现象：无法通过内网穿透地址正常访问FastGPT服务，前端返回403或404状态码。原因：未在`FE_DOMAIN`配置中绑定穿透后的公网域名，服务校验请求来源时拦截了非配置域名的访问。
- 现象：升级后出现数据库连接报错，日志提示「too many connections」。原因：未调整`DB_MAX_LINK`参数，沿用默认的低连接数配置，无法支撑环评审批业务的并发请求。
- 现象：检索结果中未包含最新的生态环境分区管控数据。原因：未配置定时同步任务拉取不定期更新的数据源，缓存的旧数据未及时刷新。

## 怎么确认配好了
- 登录FastGPT后台的系统监控页面，查看数据库连接数，确认当前连接数未达到`DB_MAX_LINK`配置的上限。
- 上传一份标准环评报告表文档，测试解析与检索功能，确认可正常提取项目类别、污染防治措施等核心字段。
- 访问配置的`FE_DOMAIN`域名，验证前端页面可正常加载，且无跨域或资源加载失败的提示。
- 触发一次大体积环评报告书的上传操作，确认`STORAGE_S3_ENDPOINT`配置的存储服务可正常接收并存储文件。
