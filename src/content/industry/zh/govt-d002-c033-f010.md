# 招标采购合规管理的办事咨询与答复：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自国央企采购平台、公共资源交易平台、供应商库、合同管理系统及审计问题库，更新频率为每日。日常处理的文档包含采购计划、需求说明书、招标文件、评标记录、合同、验收单、供应商投诉材料，数据字段涵盖采购主体、预算依据、采购方式、评分细则、供应商资质、履约验收信息等，单份文档长度跨度较大，从数百字符到数万字符。

## 这些特征在「知识库检索与召回」这一环带来什么约束
本品类数据来源分散且每日更新，要求检索环节支持增量同步与跨源数据的关联检索。文档类型覆盖采购计划、评标记录等多类，结构差异显著，需适配不同格式的文本解析与字段匹配。数据字段包含采购方式、预算依据、评分细则等合规相关核心信息，检索需精准定位特定字段内容以支撑合规校验。同时需兼顾企业内部采购规则与国资监管要求，召回结果需覆盖两类规则对应的文档条目，避免遗漏合规校验依据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配本品类合规相关内容的精准度要求，避免召回无关的非合规文档 |
| `limit` | 前10条 | 覆盖招标采购全流程的合规校验所需的相关文档数量，同时控制上下文长度 |
| `searchMode` | `vector` | 适配本品类多类型合规文档的语义匹配需求，符合FastGPT v4.17.0版本的语义检索配置规范 |
| `usingReRank` | 开启 | 对初始召回结果进行二次排序，提升高合规风险相关文档的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户咨询的合规关键词扩展检索范围，覆盖采购方式、资质要求等相关文档 |
| `collectionIds` | 按招标采购合规专属目录指定 | 限定检索范围仅覆盖本品类专属文档，避免混入其他业务模块的无关数据 |

## 容易做错的三处
- 检索时出现`invalid configuration parameter name "hnsw.max_scan_tuples"`报错。原因是误用了非指定配置清单内的参数名，未使用FastGPT官方支持的检索配置项。
- 知识库页面可查看所有文档，但对话时模型提示知识库为空。原因是未正确指定`collectionIds`配置项，检索范围未关联到实际存储文档的目录，或数据库迁移后未同步更新目录关联配置。
- 升级版本后知识库内容未同步显示。原因是未执行数据库迁移步骤，或迁移过程中未完整同步合规文档的元数据与向量数据。

## 怎么确认配好了
- 查看检索配置面板，确认所有配置项均为FastGPT官方支持的指定清单内项，无额外非清单参数。
- 发起一条针对采购方式校验的测试咨询，核对召回结果是否包含对应采购计划、招标文件等合规文档。
- 执行增量同步操作，确认每日更新的合规文档可被检索召回，无遗漏。
- 检查`collectionIds`配置，确认仅包含招标采购合规专属目录的ID，未混入其他业务目录的文档。
