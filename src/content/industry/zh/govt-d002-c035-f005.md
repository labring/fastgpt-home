# 排污许可管理的办事咨询与答复：工具调用与插件

## 这个品类的数据长什么样
这个品类的核心数据来自全国排污许可证管理信息平台、企业环保台账、在线监测系统、环境统计系统四类渠道。典型使用主体为生态环境部门排污许可管理岗、排污单位环保部门、第三方环保服务机构，日常流转的文档包含排污许可证申请表、执行报告、自行监测方案、台账记录、变更申请、许可证副本等类型。数据更新频率为季度，各渠道数据同步周期保持一致。数据字段涵盖许可排放限值、排污口位置、自行监测要求、变更事项等，无统一固定单位，需匹配对应文档的专业计量规则。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据的接入要求工具调用需支持对接四类不同系统的接口，避免数据割裂。季度更新的频率要求工具缓存周期需与数据同步节奏匹配，防止返回过期的许可信息。多样的文档类型要求插件需适配不同格式的文档解析，覆盖申请表、执行报告等全品类业务文档。数据字段无统一单位的特征要求工具调用时需保留原始字段的专业计量标识，避免单位转换错误。同时，该品类出错后果严重，工具调用需增加前置校验环节，确保输入参数符合排污许可的业务规则。

本文档基于FastGPT v4.17.0版本编写，以下为针对该场景的工具调用与插件配置说明：

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 排污许可相关咨询需自动匹配对应工具，无需手动指定调用目标 |
| `functionCall` | `enabled` | 需调用外部系统接口获取实时排污许可数据，保障咨询内容的时效性 |
| 单次搜索上限 | 前8条 | 排污许可相关文档条目较多，取前8条可覆盖核心业务信息 |
| 最大上下文长度 | 8000–12000 token | 排污许可执行报告等文档内容较长，需足够上下文支撑准确匹配 |
| 接口超时时间 | 600 秒 | 跨系统调取排污许可数据需较长响应时间，避免提前触发超时中断 |
| 缓存周期 | 90天 | 匹配该品类数据季度更新的频率，保障返回信息的时效性 |

## 容易做错的三处
- 调用飞书多维表格的HTTP工具时返回403 Forbidden状态码。原因是未在工具配置中正确绑定对应环境变量的权限令牌，或未配置跨域请求头。
- 问题优化环节无法调用模型，提示密钥缺失。原因是未在配置中关联环境变量参数，导致工具调用时无法获取密钥信息。
- 调用上传文件API后返回成功，但查询文件索引接口返回空数据。原因是未配置轮询校验工具的返回字段，或未匹配排污许可文件的专属索引校验逻辑。

## 怎么确认配好了
- 发起一条排污许可变更申请的咨询，检查工具是否自动调用对应数据源接口并返回匹配内容。
- 查看工具调用日志，确认环境变量参数已被正确加载，无缺失或错误配置。
- 提交测试用的排污许可执行报告文档，检查搜索结果是否匹配文档内的排放限值、监测要求等核心字段。
- 触发工具调用超时场景，确认系统返回符合预期的错误提示，无异常无响应。
