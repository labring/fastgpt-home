# 排污许可管理的办事咨询与答复：表单与交互

## 这个品类的数据长什么样
这个品类的核心数据来自全国排污许可证管理信息平台、企业环保台账、在线监测系统、环境统计系统，更新频率为季度。日常业务文档包含排污许可证申请表、执行报告、自行监测方案、台账记录、变更申请、许可证副本，字段覆盖排放限值、台账编号、监测数据、变更事项等，无统一固定单位，需匹配对应文档的行业技术规范字段。服务主体涉及生态环境部门排污许可管理岗、排污单位环保部门、第三方环保服务机构，数据使用需符合监管要求。

## 这些特征在「表单与交互」这一环带来什么约束
数据多源且按季度更新，要求表单交互需支持多知识库挂载并按季度同步更新，避免使用过时的许可限值或台账数据。文档类型多样且字段需匹配行业技术规范，要求表单需预设对应业务场景的字段校验规则，确保输入内容符合排污许可管理的业务要求。数据使用涉及监管合规，要求交互环节需限定数据源范围，防止非合规数据被用于咨询答复。多主体参与的业务场景，要求表单需支持按用户角色预设不同的交互流程，适配管理岗、企业岗、第三方机构的不同咨询需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 绑定排污许可核心字段，设置100-500字符输入限制，必填校验提示为“请填写与排污许可业务相关的有效信息” | 匹配品类业务文档的字段要求，避免无效输入，确保咨询内容精准 |
| `userSelect` | 预设“排污许可证申请”“执行报告提交”“变更申请”三个选项，按输入内容自动匹配 | 覆盖品类核心业务场景，减少用户输入成本，提升咨询匹配效率 |
| 知识库挂载范围 | 仅挂载全国排污许可证管理信息平台、企业环保台账的合规数据 | 符合监管要求，确保咨询内容的权威性与合规性 |
| 知识库同步周期 | 按季度同步 | 匹配品类数据的季度更新频率，确保咨询数据与官方更新同步 |
| 结果展示条数 | 前3条 | 品类咨询内容集中，过多结果会增加用户筛选成本 |
| 超时处理配置 | 设置为60秒超时，返回“当前咨询请求超时，请稍后重试或联系对应咨询岗” | 适配多平台数据调用的延迟情况，提供清晰的异常反馈 |

## 容易做错的三处
- 现象：`formInput`提取不到排污许可相关字段时，直接返回无匹配结果，未触发预设提示。原因：未配置`formInput`的空值校验及指定回复逻辑，无法引导用户补充有效信息。
- 现象：未根据业务类型切换对应知识库，无法精准匹配排污许可证申请、执行报告等不同场景的咨询内容。原因：未绑定`userSelect`选项与知识库挂载范围的关联规则，无法实现按业务场景筛选数据源。
- 现象：返回的咨询结果包含非排污许可管理的生态环境类内容，超出业务边界。原因：未配置结果展示的过滤规则，未限定仅展示排污许可相关的文档类型。

## 怎么确认配好了
- 提交模拟的排污许可证变更申请相关输入，检查`formInput`是否触发必填校验及对应提示文案。
- 选择`userSelect`中的“执行报告提交”选项，检查是否自动切换至对应知识库的搜索结果。
- 模拟超时请求，检查是否返回预设的超时提示文案。
- 查看知识库同步日志，确认同步周期符合季度更新的要求。
