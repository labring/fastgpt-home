# 排污许可管理的办事咨询与答复：部署与升级

## 这个品类的数据长什么样
本品类数据来源包括全国排污许可证管理信息平台、企业环保台账、在线监测系统及环境统计系统。日常涉及的文档包含排污许可证申请表、执行报告、自行监测方案、台账记录、变更申请及许可证副本。数据按季度更新，核心字段涵盖许可排放限值、监测指标、台账周期、变更事项等，单位多采用污染物浓度（mg/m³）、排放量（吨/年）等环保行业标准单位。

## 这些特征在「部署与升级」这一环带来什么约束
本内容适配FastGPT v4.17.0版本。本品类数据来源分散且更新周期固定，部署时需适配多源数据接入配置，确保可从全国排污许可证管理信息平台、企业台账等渠道同步数据。文档类型多样，部署需配置兼容多格式的解析模块，适配申请表、执行报告等不同文档结构。因排污许可管理涉及合规监管，数据存储需符合保密要求，因此部署时需优先选择私有部署的存储服务。季度更新的特性要求部署定时同步任务，升级前需完成存量数据备份，避免更新中断导致监管环节出错。同时因出错后果涉及合规处罚，需配置异常告警链路，确保数据校验失败时及时触发通知。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30 个` | 本品类单季度数据量较大，需平衡连接数与内存占用，按实测标定 |
| `MONGODB_URI` | 指向本地或私有云部署的MongoDB实例地址 | 存储排污许可相关的台账、执行报告等非结构化文档，保障数据存储安全 |
| `REDIS_URL` | 配置为本地Redis服务地址，内存配额 `1000 MB` | 缓存高频查询的许可限值、监测指标数据，降低多源数据源的访问延迟 |
| `STORAGE_S3_ENDPOINT` | 指向企业内部对象存储服务端点 | 存储排污许可证副本、自行监测方案等大体积文档，符合行业数据留存要求 |
| `FE_DOMAIN` | 配置为内部办公域名或专属访问地址 | 限定办事咨询答复的访问范围，仅对生态环境部门及合规机构开放 |
| `ROOT_KEY` | 按企业内部密钥管理规范生成 | 配置系统管理员权限，避免非授权用户修改排污许可相关的核心配置 |

## 容易做错的三处
- `aiproxy`容器运行后出现`curl: (7) Failed to connect`类报错，现象为容器日志显示连接外部服务失败，原因是未正确配置`STORAGE_S3_ENDPOINT`或`REDIS_URL`指向的服务未正常启动。
- 升级版本后出现文档解析异常，现象为旧版排污许可证副本无法正常提取核心字段信息，原因是未提前迁移存量文档的解析格式，未兼容新版FastGPT的文档处理逻辑。
- 配置`DB_MAX_LINK`取值过高，现象为数据库连接池耗尽，页面返回503状态码，原因是未结合本品类季度数据量调整连接数，导致内存占用超出服务器配额。

## 怎么确认配好了
- 执行`docker ps`命令，确认`fastgpt`、`redis`、`mongodb`及`aiproxy`相关容器均处于正常运行状态。
- 上传一份排污许可证申请表文档，验证解析后可正常提取许可排放限值、监测指标等核心字段。
- 发起一条模拟办事咨询查询，确认系统可返回对应执行报告的核对结果，无空值或错误返回。
- 查看`aiproxy`容器日志，无`curl`连接失败或超时类报错，确认服务链路正常。
