# 政务服务事项目录与办事指南维护的办事咨询与答复：工具调用与插件

## 这个品类的数据长什么样
该品类的维护主体通常为审改办、政务服务数据管理局等部门，核心数据取自国家政务服务事项基本目录、行政许可事项清单及地方政务服务事项库，更新节奏为月度。日常维护的文档包含政务服务事项基本目录、实施清单、办事指南、标准材料目录、流程图与常见问题，文档结构以事项为核心单元，包含事项名称、受理条件、申请材料清单等标准化字段，无自定义非标准字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源的官方性要求工具调用需严格对接合规政务数据接口，不可使用非官方数据源。月度更新节奏要求工具调用的缓存策略需匹配更新周期，避免返回过期事项信息。标准化的文档字段要求工具调用的参数映射需严格对应预设字段，不可随意自定义映射规则。同时，该品类最耗时的比对与校验环节，要求工具调用支持批量处理多份目录与清单，减少人工重复操作。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 该品类需自动调用政务数据接口完成字段校验与比对，无需手动指定自定义工具函数 |
| `functionCall` | `禁用` | 该品类仅需调用官方政务数据接口，无需启用自定义函数调用功能 |
| 缓存周期 | `25–35 天` | 匹配该品类月度更新的节奏，避免缓存过期或使用旧数据 |
| 批量处理上限 | `前 200 条` | 适配政务事项目录的单次处理规模，避免接口请求过载 |
| 超时时间 | `600 秒` | 政务数据接口通常响应较慢，预留足够的请求处理时长 |

## 容易做错的三处
- 现象：调用政务数据接口返回 "Failed to fetch" 报错。原因：未配置匹配政务数据接口的超时时间，或接口地址未添加官方政务服务平台的白名单权限。
- 现象：多模态分析办事指南图片时返回空结果。原因：未配置图片下载的缓存路径，或网络权限限制导致无法拉取图片资源。
- 现象：批量处理事项时仅返回部分校验结果。原因：未设置合理的批量处理上限，超出接口单次请求的最大数据量限制。

## 怎么确认配好了
- 发起单次事项校验请求，核对返回结果与本地政务事项数据的字段一致性。
- 查看工具调用日志，确认`toolChoice`参数为`auto`且未触发`functionCall`。
- 模拟月度更新场景，验证缓存周期内的请求不会返回过期数据。
- 发起批量处理请求，核对返回结果条数与设置的批量处理上限匹配。
