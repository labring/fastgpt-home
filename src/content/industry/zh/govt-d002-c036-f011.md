# 政务服务事项目录与办事指南维护的办事咨询与答复：表单与交互

## 这个品类的数据长什么样
这个品类的核心文档包括政务服务事项基本目录、实施清单、办事指南、标准材料目录、流程图、常见问题。数据来源为国家政务服务事项基本目录、行政许可事项清单、权责清单及地方政务服务事项库，更新频率通常为每月一次。文档按事项分类层级组织，包含受理条件、申请材料、办理流程等固定字段，字段需严格匹配上级下发的标准口径，无自定义冗余字段，所有内容需保持与上级目录的一致性。

## 这些特征在「表单与交互」这一环带来什么约束
由于数据更新频率通常为每月一次，且涉及多份层级化文档的字段一致性校验，表单与交互环节需支持批量导入与批量编辑功能，降低单次手动录入的误差。同时，所有字段需严格匹配上级下发的标准口径，因此表单需内置字段校验规则，确保受理条件、申请材料等核心字段无遗漏或口径偏差。另外，政务事项分类固定，交互组件需支持按分类预设选项，减少人工输入的随意性，避免出现线上线下办事口径不一致的问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 开启变量绑定与字段校验，允许上传最大1000 MB的附件文件 | 用于绑定政务事项的标准字段，自动带入预设值，同时支持上传标准材料目录的配套附件 |
| `userSelect` | 按政务事项分类预设选项，按分类触发对应知识库检索 | 政务事项分类固定，预设选项可减少录入误差，按分类触发可匹配对应事项的知识库内容 |
| 表单批量导入设置 | 支持CSV格式导入，字段映射匹配标准目录字段 | 适配每月一次的更新频率，批量导入可提升维护效率，避免手动录入的偏差 |
| 字段校验规则 | 开启必填项校验与跨字段一致性校验 | 确保受理条件、申请材料等核心字段完整，避免出现线上线下办事口径不一致的问题 |
| 超时阈值 | 300 秒 | 适配政务数据的批量导入与校验操作，避免因数据量较大导致的导入超时 |

## 容易做错的三处
- 表单输入组件无法传入预设变量，提交的办事指南字段与标准目录不一致。原因是未正确配置`formInput`的变量映射规则，未将表单字段映射到政务事项的标准字段库。
- 表单输入框不支持上传文件，无法提交标准材料目录的配套附件。原因是未开启`formInput`的文件上传功能，未配置允许上传的文件类型与大小上限。
- 页面仅支持选择单向量模型，无法为多组政务事项数据配置对应向量库，仅能使用固定知识库进行检索。原因是未通过`userSelect`配置按事项分类绑定不同向量模型与知识库。

## 怎么确认配好了
- 打开FastGPT v4.17.0的表单编辑页面，检查`formInput`组件是否已绑定政务事项的标准字段，尝试输入测试字段值，查看是否自动映射到对应变量。
- 上传一份符合标准格式的CSV文件，检查表单是否自动匹配字段并完成批量导入，无报错提示。
- 选择不同的政务事项分类，检查系统是否自动切换至对应知识库进行检索，返回的结果与所选分类匹配。
- 尝试上传格式合规的附件文件，检查表单是否允许上传并保存文件路径，无权限报错。
