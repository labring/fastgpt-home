# 法务合规与重大风险管理的办事咨询与答复：工具调用与插件

## 这个品类的数据长什么样
本品类数据来源于企业合同管理系统、合规风险数据库、法律法规库、案件管理系统、举报平台，更新频率为月度。日常生成的文档包括合规风险清单、合同法律审核意见、重大事项法律意见书、合规审查表、违规举报调查报告。数据字段覆盖合规风险等级、合同条款合规性、重大事项法律风险点、举报线索处置进度等，无统一固定单位，随文档类型调整。

## 这些特征在「工具调用与插件」这一环带来什么约束
月度更新的数据源要求工具调用的知识库同步周期匹配月度节奏，避免频繁同步占用系统资源。多系统来源的数据要求插件需对接多个异构系统API，处理不同系统的文档格式差异与字段规范。多样的文档类型要求工具调用适配不同字段的提取逻辑，例如合同条款合规性字段与举报线索处置进度字段的差异化处理。严重的出错后果要求工具调用配置失败重试与告警机制，同时需支持关系型数据的关联查询，适配合规风险与合同、案件的实体关系。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` 或指定合规审查工具 | 适配法务合规场景的工具调用需求，精准触发对应功能模块 |
| 知识库同步周期 | `30 天` | 匹配业务数据月度更新频率，避免不必要的同步资源消耗 |
| 插件对接数据源数量 | `不超过 5 个` | 适配多系统数据来源的实际接入规模，降低接口调用冲突概率 |
| `functionCall` | `按问题触发` | 针对合规风险识别、合同审查等高频场景，确保工具调用按需执行 |
| 失败重试次数 | `2 次` | 平衡调用成功率与资源消耗，适配法务场景对结果可靠性的要求 |
| 上下文窗口长度 | `8000–12000 token` | 容纳合规审查、重大事项意见书等长文档的上下文信息，确保分析完整 |

## 容易做错的三处
- 现象：调用工具时返回「未找到匹配的知识库」，原因：未在工作流或API请求中正确传入绑定的知识库ID，或知识库ID与数据源不匹配。
- 现象：工具调用返回的合规风险关联结果缺失实体关系，原因：未开启关系型索引配置，仅使用扁平化实体索引，无法匹配合规风险与合同、案件的关联逻辑。
- 现象：API调用工作流上传文件后返回格式错误，原因：未按照要求使用multipart/form-data格式封装文件参数，或文件大小超出插件预设限制。

## 怎么确认配好了
- 查看工具调用日志，确认每次调用都能正确匹配到配置的数据源与知识库，无空字段或错误ID提示。
- 触发一次月度同步任务，检查数据源的文档是否完整同步至知识库，匹配业务数据的更新节奏。
- 提交包含合规风险与合同关联的测试问题，验证工具调用是否返回符合预期的关系型分析结果。
- 模拟一次API调用工作流的请求，检查返回的响应状态码为正常范围，无格式错误提示。
