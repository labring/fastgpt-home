# 法务合规与重大风险管理的办事咨询与答复：文档解析与分块

## 这个品类的数据长什么样
本品类数据主要来自企业合同管理系统、合规风险数据库、法律法规库、案件管理系统与举报平台，更新频率为月度。日常处理的文档包含合规风险清单、合同法律审核意见、重大事项法律意见书、合规审查表、违规举报调查报告。文档多为结构化字段与非结构化文本混合的内容，部分附带盖章标注、附件链接等信息，无统一固定格式，需适配多类型文件的解析需求。

## 这些特征在「文档解析与分块」这一环带来什么约束
月度批量更新的数据源要求支持批量文件解析与调度，避免单次解析过载。多类型文档混合结构化字段与非结构化文本的特征，要求解析环节同时适配字段提取与自由文本拆分，防止破坏合规信息的关联逻辑。文档格式不统一的现状，需要灵活的自定义解析规则，适配不同系统导出的排版差异。部分文档包含敏感合规信息，解析过程需保留原始标注与关联节点，避免丢失关键合规依据。长文本类的法律意见书与审核意见，需控制分块边界，防止拆分破坏完整的法律论证逻辑。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 本品类文档多为长文本法律文件，该区间可平衡语义完整性与检索粒度，避免拆分破坏法律条款的完整逻辑 |
| `chunkSplitter` | 按段落+标题拆分 | 合规类文档多有明确层级标题与段落逻辑，按此拆分可保留文档结构关联，便于后续合规风险检索 |
| `customPdfParse` | 开启 | 本品类PDF文档多包含合规表单、盖章标注等非标准排版，自定义解析可适配特殊格式，完整提取结构化信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 大型法律意见书、案件调查报告文件体积较大，需足够解析时长以完成完整内容提取 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 部分批量合规文档包的单文件体积较大，需适配批量上传的文件大小限制 |
| `chunkSettingMode` | 自定义模式 | 本品类文档格式差异较大，自定义模式可灵活调整分块规则，适配不同类型的合规文档 |

## 容易做错的三处
- 现象：上传Word文档后，解析结果中的图片链接未携带预设域名，无法在对话中正常加载。原因：未开启自定义解析中的图片路径替换规则，仅保留了本地相对路径。
- 现象：解析大型合规报告时出现超时报错，页面返回连接中断提示。原因：`PARSE_FILE_TIMEOUT_SECONDS`配置取值过小，未适配长文档的解析耗时。
- 现象：解析PDF表单文档时仅提取到纯文本内容，无法识别表单中的结构化字段。原因：未开启`customPdfParse`配置，使用默认通用解析无法适配合规表单的特殊排版。

## 怎么确认配好了
- 上传单份典型文档（如合同法律审核意见），检查解析结果的文本完整性与结构层级是否符合预期。
- 上传多格式混合的文档包，验证批量解析的成功率与各类型文件的适配效果。
- 调整分块参数后，检索测试文档中的关键合规条款，确认检索结果的语义关联性符合需求。
- 上传超出常规体积的文档，验证解析超时配置是否生效，无异常报错。
