# 特种设备安全监管的办事咨询与答复：HTTP 接口与外部系统

## 这个品类的数据长什么样
本品类的数据覆盖特种设备全生命周期相关文档，包括使用登记证、定期检验报告、维保记录、隐患整改通知书、事故报告及作业人员证书等。数据主要来自特种设备安全监察系统、检验检测机构系统、使用单位台账及作业人员证书库，更新频率为月度。单条数据包含设备编号、登记状态、检验周期、维保单位、作业人员资质编号等字段，字段值多为文本或状态标识，无统一固定单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
月度更新的频率决定接口无需高频调用，可配置为定时同步任务。多来源的数据来源要求接口兼容不同系统的返回格式，需支持灵活的参数适配规则。全生命周期的文档类型覆盖文本、状态标识等，接口需支持结构化数据与文件类数据的混合传输。设备监管的高风险属性要求接口返回数据需经过基础校验，避免错误数据流入后续流程，同时需配置失败重试机制以应对外部系统波动。日常业务中核对设备登记、检验周期及作业人员资质的环节耗时较长，接口返回的结构化字段可直接用于自动化校验，降低人工成本。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | 携带 `Bearer ` 前缀的鉴权令牌 | 适配外部特种设备监管系统的标准鉴权要求 |
| 请求超时时间 | 30–60 秒 | 匹配外部系统的平均响应耗时 |
| `variables` | 绑定设备编号、检验周期、作业人员资质编号 | 用于动态生成接口请求参数 |
| `responseData` 解析规则 | 提取结构化的设备状态、检验结果字段 | 用于后续的业务校验流程 |
| 失败重试次数 | 2 次 | 平衡接口稳定性与请求负载 |
| 单次请求最大数据量 | 1000 MB | 匹配外部监管系统的文件传输限制 |

## 容易做错的三处
- 条件判断组件处理布尔类型返回值后字段为空：原因是未将`responseData`解析为明确的布尔格式，直接传入的字符串或非标准类型无法被组件识别。
- 接口请求报`getaddrinfo ENOTFOUND`错误：原因是配置的外部系统域名未在网络白名单内，或域名拼写错误。
- HTTP请求携带相对路径文件时处理失败：原因是未将相对路径拼接为完整可访问的URL，且未移除请求中附带的临时token参数。

## 怎么确认配好了
- 调用测试接口，检查`Authorization`参数是否正确携带，返回状态码为200。
- 查看`responseData`解析结果，确认业务字段已被正确提取并绑定到`variables`中。
- 模拟异常场景触发重试机制，确认接口在失败后会按配置的重试次数尝试重发请求。
- 上传测试文件并生成相对路径，确认拼接后的完整URL可被外部系统正常访问。
