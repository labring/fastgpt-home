# 环境执法与监测监管的办事咨询与答复：部署与升级

## 这个品类的数据长什么样
本品类数据来自在线监控平台、污染源自动监测数据、生态环境执法系统及第三方检测报告，更新频率为每日。日常处理的文档包含现场检查记录、采样记录、监测报告、责令改正决定书、行政处罚决定书，单份文档包含采样点位、监测因子、执法时间、处罚依据等字段，无统一固定单位，随检测项目或执法文书要求变化。数据以结构化的监测数值与非结构化的执法文书混合形态存在，需覆盖实时上传的在线数据与归档的历史执法档案。

## 这些特征在「部署与升级」这一环带来什么约束
本品类多源混合的数据特征，要求部署阶段配置兼容结构化监测数据与非结构化执法文书的存储方案，升级至FastGPT v4.17.0版本时，需注意保留原有数据库的元数据关联，避免升级后历史执法档案无法正常检索。每日更新的实时在线数据，要求部署时预留足够的读写带宽与定时同步任务配置，升级过程中不能中断数据同步链路。执法文书与检测报告格式不统一的特点，要求部署时配置灵活的文档解析规则，升级后需验证解析逻辑适配现有业务文档，避免出现字段提取错误。同时，执法数据的敏感性要求部署与升级时严格遵循权限隔离配置，防止数据泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://env_user:env_pass@host:port/fastgpt_env` | 本品类执法与监测数据体量较大，需指定专属数据库实例，关联生态环境执法系统的结构化数据存储 |
| `REDIS_URL` | `redis://:env_redis_pass@host:port/0` | 每日更新的实时监测数据需缓存高频查询的执法点位信息，降低数据库读写压力 |
| `STORAGE_S3_ENDPOINT` | `https://s3-cn-beijing.volces.com`（或本地对象存储地址） | 执法文书与监测报告需持久化存储，兼容多区域的对象存储服务，满足数据归档需求 |
| `FILE_TOKEN_KEY` | `32 位随机字符串` | 需为执法文档生成唯一访问令牌，防止未授权访问敏感执法数据 |
| `DB_MAX_LINK` | `20–30 个连接` | 本品类每日有大量监测数据写入与执法文档查询，需限制数据库连接数避免资源耗尽 |
| `ROOT_KEY` | `复杂度不低于12位的随机字符串` | 私有化部署时需配置最高权限密钥，用于初始化系统与管理用户权限 |

## 容易做错的三处
- 现象：部署后调用咨询功能返回401 unauthorized错误。原因：未正确配置`ROOT_KEY`或未在应用权限中绑定合法的API密钥，导致系统无法验证请求合法性。
- 现象：本地Docker Compose部署后无法注册新用户。原因：默认部署配置未开启公共注册开关，且未配置管理员手动创建用户流程，导致新用户无法获取访问权限。
- 现象：配置第三方大模型密钥后无法正常调用。原因：未将密钥绑定至对应知识库的应用配置中，或部署时未开放对应大模型的访问端口，导致FastGPT无法与大模型服务建立连接。

## 怎么确认配好了
- 执行`docker logs fastgpt`命令，查看数据库连接日志，确认无连接超时或权限拒绝报错，调整配置至符合当前数据体量的取值。
- 上传一份现场检查记录文档，验证解析后能正确提取核心业务字段，确认文档可正常访问且存储路径配置正确。
- 发起一次基于监测数据的咨询测试，确认返回结果包含最新的在线监控数据与历史执法档案，验证缓存逻辑正常生效。
- 登录系统后台，确认管理员账号可正常创建新用户，验证注册功能的配置符合业务权限要求。
