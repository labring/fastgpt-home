# 用地预审与规划许可的办事咨询与答复：模型接入与配置
本文适用于 FastGPT v4.17.0

## 这个品类的数据长什么样
该品类的核心数据来源于国土空间规划一张图、项目审批监管平台、土地利用现状库、生态保护红线数据，更新频率不定期。日常对接的文档包括用地预审与选址意见书、建设用地规划许可证、建设工程规划许可证、红线图、规划条件，文档字段包含项目选址范围、用地规模、规划管控要求、前置审批条件等，无统一固定的单位格式，需结合具体审批文件匹配对应字段与数值，覆盖项目从预审到许可全流程的审批依据与管控规则。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散且更新不定期，要求模型接入配置需支持实时检索或定期同步最新的规划与审批数据，避免使用过期信息。文档类型包含矢量图纸与文本文件，需配置适配多模态输入的参数以处理红线图等图纸类数据。字段无统一固定格式，要求模型需准确识别并匹配不同文档的字段内容，同时需限制生成内容的随意性，确保答复符合自然资源管控的严谨要求。此外，出错后果直接影响项目立项与开工，需强化答复的依据引用与准确性校验。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 用地预审与规划许可相关文档长度较长，需覆盖多份审批文件与规划管控数据，确保上下文完整 |
| `maxTokens` | 4000–6000 token | 办事咨询答复需包含详细的合规性说明与依据，避免截断关键审批规则与项目要求 |
| `quoteMaxToken` | 2000–3000 token | 需完整引用规划红线、审批意见等核心文档片段，确保答复的依据可追溯 |
| `temperature` | 0.1–0.3 | 办事咨询需严谨准确，避免生成模糊或不符合自然资源管控规范的内容 |
| `toolChoice` | auto | 支持模型自主调用知识库检索规划数据与审批记录，提升答复的准确性 |
| `AIPROXY_API_ENDPOINT` | 按模型服务商提供的地址填写 | 完成私有化或云平台大模型的接入端点配置，确保通信正常 |
| `AIPROXY_API_TOKEN` | 按平台分配的密钥填写 | 完成模型接入的身份验证，确保访问权限合法 |

## 容易做错的三处
- 测试模型时返回404错误，原因是`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`配置错误，未与已验证的模型服务配置对齐。
- 模型输出无思考过程，原因是`toolChoice`设置为限制模式或未开启模型原生思考输出开关，导致仅返回结论性内容。
- 模型推理延迟超出预期，原因是`maxContext`设置超出模型支持的上下文窗口，或资源分配不足导致推理耗时增加。

## 怎么确认配好了
- 提交包含项目选址范围与规划管控要求的咨询问题，核对返回结果中是否包含对应文档的准确引用片段。
- 切换不同的模型接入配置，确认模型能够正常返回符合用地预审与规划许可规范的答复内容。
- 检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置，确保与模型服务商的验证信息一致。
- 调整`temperature`参数，验证答复的严谨性是否符合办事咨询的要求。
