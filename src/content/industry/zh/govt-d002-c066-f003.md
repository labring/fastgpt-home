# 化工新材料的办事咨询与答复：多轮对话与提示词
FastGPT v4.17.0

## 这个品类的数据长什么样
化工新材料的办事咨询数据主要来源于行业协会公示的产品备案信息、企业公开的产品说明书、国家标准与行业规范文档、安全技术说明书（MSDS）。数据更新节奏分为两类：新产品备案信息按季度更新，国标行标文档随政策调整不定期更新，企业内部文档按月度更新。文档结构包含产品名称、牌号、核心性能参数如拉伸强度、热变形温度、密度等，附带明确的单位标识，应用领域、合规性说明等字段。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
化工新材料的数据特征对多轮对话与提示词配置带来多重约束。首先，文档中附带明确单位的性能参数要求多轮对话必须保留上下文的单位信息，避免不同牌号材料的参数混淆；其次，合规性内容与备案信息要求提示词必须强制关联文档来源字段，确保答复符合行业规范；第三，不同更新节奏的数据源要求定期刷新知识库分块，避免使用过期的备案信息；最后，长文本的技术文档要求对话上下文不能过度截断，否则会丢失关键参数的关联信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 化工新材料文档多为带参数的技术文本，分块过长会导致召回精度下降，过短则破坏参数上下文完整性 |
| 重叠长度 | 100–150 字符 | 避免性能参数、合规条款被分块截断，保证跨块信息的连贯性 |
| 最大上下文 | 4000–6000 token | 适配多轮对话中用户反复询问的牌号、参数等信息的上下文留存 |
| `variables` | 绑定产品牌号、应用场景变量 | 针对细分品类的精准检索，减少无关召回 |
| 单次搜索上限 | 前6条 | 化工新材料的核心参数集中在前几条召回结果中，过多结果会干扰对话逻辑 |
| 问题优化 | 开启 | 帮助用户明确模糊的技术咨询，比如将模糊表述优化为具体参数查询 |

## 容易做错的三处
- 上传化工新材料的技术文档时返回500错误。原因是文档中包含大量带特殊符号的性能参数，分块时未正确处理转义导致解析失败。
- 工作流中串联多个AI对话模块后，最终输出包含所有模块的对话结果。原因是未配置`messages`的上下文截断规则，导致所有历史对话被带入最终输出。
- 首次发起化工新材料咨询对话时响应延迟超过3秒，后续对话速度正常。原因是知识库分块未做预加载，首次请求时触发分块加载与召回流程。

## 怎么确认配好了
- 上传一份典型的化工新材料产品说明书，发起多轮对话，验证上下文保留的参数单位未出现错误。
- 配置`chatId`绑定会话标识，发起两次独立会话，验证不同会话之间的上下文不会互相干扰。
- 触发一次多轮对话，检查最终输出仅保留所需的最后一轮结果，无多余历史对话内容。
- 调整最大上下文配置，验证首次对话的响应延迟符合预期要求。
