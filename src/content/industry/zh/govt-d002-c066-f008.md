# 化工新材料的办事咨询与答复：文档解析与分块

## 这个品类的数据长什么样
化工新材料的办事咨询与答复数据主要来自企业内部Confluence知识库、行业合规文档、年度检测报告、PDF年报及Excel批次数据。数据更新节奏随业务场景变化：项目类文档随研发进度不定期更新，年度合规报告按自然年度更新，批次检测数据随生产计划同步更新。文档结构包含带专业参数表格的PDF、带海量行数据的Excel、带流程说明的Word，字段多包含材料牌号、拉伸强度、热变形温度等性能参数，配套MPa、℃等专业单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
内网Confluence作为核心内部数据源，要求解析工具支持内网环境访问配置，否则无法提取内部办事流程与合规说明。长PDF年报与检测报告单份可达千页，解析耗时较长，需适配大文件处理逻辑。Excel文件包含表头与10000+行批次数据，默认分块易破坏参数与单位的关联，导致咨询匹配精度下降。专业参数与单位绑定的文档结构，要求分块时保留完整语义单元，避免拆分跨字段的专业内容。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配化工新材料文档的段落密度，保留单个性能参数与对应单位的完整关联 |
| `chunkSplitter` | 按段落+页眉页脚过滤 | 避免拆分跨页的专业表格与参数内容，适配长文档结构 |
| `customPdfParse` | 启用OCR模式 | 处理扫描版检测报告与非可编辑PDF文档，完整提取文字与表格内容 |
| `UPLOAD_FILE_MAX_SIZE` | 2000 MB | 支持单份千页PDF年报与大容量Excel文件的上传 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 1200 秒 | 适配长文档与大容量文件的解析耗时，避免中途超时中断 |
| `chunkSettingMode` | 手动配置 | 针对Excel的10000+行数据调整分块粒度，避免默认分块过大导致语义断裂 |

## 容易做错的三处
- 内网Confluence页面无法解析出内容，原因是未配置内网访问代理或权限，未针对内网资源调整解析参数。
- 上千页PDF年报解析后出现超时报错或结果为空，原因是`PARSE_FILE_TIMEOUT_SECONDS`设置过短，未启用长文档优化模式。
- Excel文件解析后分块丢失表头与对应行数据的关联，原因是未手动调整`chunkSize`参数，使用默认分块逻辑拆分专业数据。

## 怎么确认配好了
- 上传单份500页PDF年报，检查解析状态是否在合理时间内完成，无超时相关报错。
- 上传包含10000+行数据的Excel文件，查看分块结果是否保留表头与对应行的完整绑定，无参数与单位拆分断裂的情况。
- 测试内网Confluence页面链接，确认解析后能提取到完整的办事流程说明与合规文档内容。
- 调整`chunkSize`参数后，验证分块后的文本是否完整包含单个专业性能参数及对应单位，无语义拆分错误。
