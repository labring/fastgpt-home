# 化工新材料的办事咨询与答复：表单与交互

本文档基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
化工新材料的办事咨询数据主要来源于国央企化工板块的官方备案公示、行业协会合规申报材料与企业公开的产品技术文档。数据更新节奏以新牌号发布、季度合规审核为节点，无实时更新需求。单份文档包含牌号、CAS号、密度、熔点、闪点、合规等级、应用场景等字段，字段需严格匹配法定单位，如密度用`g/cm³`、温度参数用`℃`，部分合规字段需匹配官方发布的资质编码规则。

## 这些特征在「表单与交互」这一环带来什么约束
化工新材料数据包含大量专业化工参数与严格的单位要求，因此表单需预设合法的字段选项与单位校验规则，避免无效输入；数据来源多为官方备案材料，核心字段固定且无灵活调整空间，因此表单需限制自定义字段的添加范围，仅允许补充非核心的临时信息；部分数据涉及合规资质与敏感参数，因此表单需区分公开填写与内部权限的交互逻辑，限制未授权用户访问敏感字段；数据更新节奏非实时，因此表单需支持关联历史备案数据的快速查询入口，减少重复录入操作。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `formInput` | 按字段类型绑定单位校验，密度字段绑定`g/cm³`、熔点字段绑定`℃`，取值范围为预设专业参数库的合法区间，按实测标定 | 化工新材料参数有严格单位与数值要求，避免无效输入 |
| `userSelect` | 预设CAS号、牌号、合规等级三类下拉选项，单次选择上限为1项 | 核心查询字段固定，减少用户输入错误 |
| 输入引导词库 | 导入化工新材料专业术语词库，包含10000条以内的专业术语 | 匹配专业咨询场景的术语需求，提升交互准确性 |
| 节点链路配置 | 允许从任意流程节点跳转至表单节点，支持携带已填字段参数 | 满足多分支复用表单链路的业务需求 |
| 变量引用校验 | 启用格式校验，仅允许引用`{{变量名}}`格式的系统变量与自定义变量 | 避免出现quote type error类的格式错误 |
| 大模型调用配置 | 设置单次调用超时时间为60秒，返回结果条数限制为前3条 | 匹配专业咨询的信息密度需求，避免超时或信息过载 |

## 容易做错的三处
- 现象：尝试从其他流程节点跳转至表单节点时，无法携带已填参数，链路跳转失败。原因：未开启节点链路复用的参数传递开关，未配置跳转时的参数映射规则。
- 现象：开启输入引导并配置自定义词库后，调试预览界面弹出报错。原因：自定义词库文件格式不符合要求，或词库中包含非法字符导致解析失败。
- 现象：引用知识库变量时出现quote type error报错。原因：变量未按`{{变量名}}`的标准格式书写，或引用了未定义的自定义变量。
- 现象：在线版可选择的大模型与官方介绍不一致。原因：未在平台后台配置对应大模型的API密钥与权限，或当前账号未开通对应大模型的使用权限。

## 怎么确认配好了
- 进入表单配置页面，检查每个字段是否绑定了对应的单位校验规则，输入非法数值时是否弹出对应提示。
- 测试从任意流程节点跳转至表单节点，确认已填参数是否自动填充至对应表单字段。
- 输入符合格式的变量引用，确认调试预览界面无quote type error报错。
- 配置自定义词库后，在调试界面输入专业术语，确认输入引导是否正确匹配词库内容。
