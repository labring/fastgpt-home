# 化肥农药的办事咨询与答复：HTTP接口与外部系统

## 这个品类的数据长什么样
化肥农药的办事咨询数据主要来自农业农村部农药登记数据库、化肥生产许可备案系统及地方农业执法抽检公示信息。数据更新随新登记证核发、许可变更及抽检结果发布调整，核心登记信息按季度同步。单条数据包含登记证编号、产品通用名、生产主体、有效成分浓度、适用作物、安全间隔期等字段，有效成分浓度单位为克/升，办事流程文档包含申请材料清单、审批节点说明等结构化内容。本页面适配FastGPT v4.17.0版本。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
化肥农药数据的多字段结构化特征要求HTTP接口需支持按业务维度传递精准参数，例如登记证编号、适用作物类型，避免模糊查询导致结果匹配偏差。数据更新无固定周期的特点，要求接口配置增量同步逻辑，仅拉取变更后的数据集以降低传输开销。办事咨询场景的业务关联性强，接口返回的`responseData`需按农资业务字段映射，确保AI可提取有效成分、审批节点等关键信息用于答复。同时，农资数据的监管属性要求接口需携带合法校验参数，保障数据调用合规性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer 业务专属密钥` | 农资监管类数据需通过授权校验，保障调用合规性 |
| `variables` | 绑定登记证编号、适用作物、申请主体类型 | 化肥农药办事咨询需精准匹配对应业务数据，变量需覆盖核心业务字段 |
| `responseData` | 仅返回登记证字段、审批节点字段、安全间隔期字段 | 办事咨询场景仅需核心业务信息，过滤无关内容可提升答复效率 |
| 单次搜索上限 | 前3条 | 避免冗余结果干扰AI对关键业务信息的提取 |
| 超时时间 | 600秒 | 跨部门农资数据接口可能存在延迟，较长超时可避免正常请求被中断 |
| 最大上下文长度 | 8000–12000 token | 化肥农药数据字段较多，需足够上下文承载完整业务信息 |

## 容易做错的三处
- 发起POST请求后接口返回200状态码，但`responseData`字段为空。未在`variables`中绑定化肥农药专属业务参数，导致系统无法匹配到对应数据。
- 调用接口后返回的结果包含大量非业务无关内容，无法直接用于答复。未对`responseData`配置过滤规则，返回了全量未加工的原始数据。
- 上传化肥农药产品登记文档后解析失败，无法提取有效字段。未按结构化文档的字段结构配置分块规则，导致长文本被错误截断，丢失关键业务信息。

## 怎么确认配好了
- 调用测试接口，检查`Authorization`参数是否被正确携带，返回状态码为200。
- 查看接口返回的`responseData`字段，确认仅包含预设的化肥农药业务字段。
- 传入测试用的登记证编号，检查返回结果是否匹配对应产品的业务信息。
- 调整`variables`参数后重新调用，确认返回结果随参数变化而更新。
