# 化肥农药的办事咨询与答复：文档解析与分块

## 这个品类的数据长什么样
化肥农药的办事咨询文档主要来自农业农村部门备案公示、企业自主提交的产品登记材料、田间试验报告与政策通知。数据更新随新农药登记、政策修订或行业标准更新触发，无固定周期。文档形态包含PDF格式的登记证文件、Word格式的使用说明书、结构化表格形式的成分与剂量说明。字段包含有效成分含量、适用作物范围、使用剂量、安全间隔期，单位涉及克/升、毫克/千克、公顷、毫升等专业农业化工单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
备案类PDF多为带官方页眉页脚的扫描件或排版复杂的电子文档，解析时需精准剥离冗余页眉页脚，避免无关信息混入分块内容。结构化的成分与剂量表格字段绑定紧密，若拆分不当会将适用作物与对应使用剂量分割到不同分块，无法支撑精准的咨询匹配。长文本政策文件的章节标题与正文绑定紧密，分块时需保留上下文关联，避免用户查询政策条款时获取不完整内容。部分文档附带的单位换算说明需与对应条目绑定，否则答复时会丢失剂量的专业单位信息。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `customPdfParse` | 开启 | 化肥农药备案类PDF多为扫描件或带复杂页眉页脚的官方格式，开启自定义解析可优化OCR识别与冗余内容剥离效果 |
| `chunkSize` | 800–1200 字符 | 文档包含长文本政策文件与结构化剂量表格，该区间可平衡上下文完整性与分块匹配精度 |
| `chunkSplitter` | 按段落+标题 | 文档章节标题与正文绑定紧密，按段落+标题拆分可保留专业术语与对应说明的上下文关联 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 单份多页试验报告或批量备案文档解析耗时较长，该时长可覆盖多数文档的完整解析需求 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 部分企业提交的批量备案材料或长周期试验报告体积较大，该上限可满足常规上传需求 |
| `chunkSettingMode` | 手动配置 | 不同类型文档（登记证、政策、使用说明书）的分块需求差异显著，手动配置可适配细分场景 |

## 容易做错的三处
-  解析时出现「CUDA out of memory」报错，且系统无法识别已安装的GPU设备。原因：未在FastGPT容器中正确挂载GPU驱动与CUDA环境，化肥农药的备案PDF多为多页扫描件，解析时OCR计算量较大，超出容器分配的显存阈值。
-  结构化剂量表格被拆分为多个独立分块，无法关联对应适用作物信息。原因：未配置`chunkSplitter`按标题+段落拆分，默认分块逻辑割裂了表格与前置的作物说明文本。
-  上传超过1GB的批量备案文档时，解析任务直接超时失败。原因：`PARSE_FILE_TIMEOUT_SECONDS`配置值低于文档解析实际耗时，未适配化肥农药长文档的解析需求。

## 怎么确认配好了
-  上传一份典型的化肥农药备案PDF，查看解析后的文本内容，确认非正文的页眉页脚等冗余信息已被有效剥离。
-  随机抽取一条结构化剂量表格条目，核对其与对应适用作物的说明文本是否被整合在同一个分块内。
-  上传不同体积的测试文档，验证解析任务是否在预设的超时阈值范围内完成。
-  调整分块长度配置后，查看生成的分块文本长度是否符合预设的区间要求。
