# 化肥农药的办事咨询与答复：知识库检索与召回

## 这个品类的数据长什么样
化肥农药的办事咨询数据主要来源于农业农村部农药检定所的登记公告、生产企业的产品备案文档、国家及行业标准文本、田间药效与残留试验报告。国家标准与行业标准每1-2年修订一次，企业备案数据随产品上市实时更新，登记公告按季度发布。单篇文档多为结构化表格或规范格式的技术说明，包含产品名称、登记证号、有效成分含量、适用作物、使用剂量等字段，单位涉及g/L、%、kg/ha等专业计量标准。

## 这些特征在「知识库检索与召回」这一环带来什么约束
结构化文档占比高，要求检索时需支持字段级精准匹配，避免跨字段的无效关联；专业计量单位多样，需在检索前完成单位归一化处理，防止因单位混淆导致的召回错误；数据更新节奏存在实时与定期两类，需配置增量同步与全量同步结合的更新机制，保障检索结果的时效性；单篇文档内容紧凑且专业术语集中，需在分块时保留文档单元的完整性，避免拆分破坏语义关联。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本，具体参数配置如下：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 化肥农药文档多为结构化专业内容，该区间可过滤低匹配度的无关结果，保留精准匹配的登记信息与标准文本 |
| `limit` | 前10条 | 单篇产品文档内容紧凑，过多召回结果会超出上下文窗口，10条可覆盖典型咨询所需的全部关联信息 |
| `searchMode` | semantic+keyword | 兼顾专业术语的语义匹配与登记证号、成分名称的精准关键词匹配，适配结构化数据的检索需求 |
| `usingReRank` | 开启 | 结构化文档的语义相似度易受字段顺序干扰，重排可优先返回匹配核心字段（如有效成分、适用作物）的结果 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可将用户的口语化咨询（如“小麦除草剂怎么用”）扩展为包含专业术语的检索词，匹配标准文档中的规范表述 |
| `collectionIds` | 业务专属化肥、农药知识库集合ID | 隔离不同品类的知识库数据，避免召回无关的农业技术文档，保障检索精准性 |

## 容易做错的三处
- 现象：检索结果中出现单位不匹配的内容，例如返回“每亩使用50g”的结果对应实际应为“每公顷使用50g”。原因：未在文档预处理阶段配置单位归一规则，导致不同单位的同类型数据被混淆召回。
- 现象：调用知识库时返回“未找到匹配结果”，且日志显示`collectionIds`参数为空。原因：未正确绑定业务专属的知识库集合ID，检索范围覆盖了无关的非化肥农药文档。
- 现象：LLM生成回答时引用了知识库外的非合规内容，例如未登记的农药使用方法。原因：未严格配置检索召回的过滤规则，导致召回结果未限制在已备案的化肥农药数据范围内。

## 怎么确认配好了
- 上传单篇带明确单位的化肥成分文档，发起检索“有效成分含量为XX%的尿素产品”，核对返回结果的单位与文档一致。
- 查看检索日志，确认`collectionIds`参数携带了业务专属的集合标识，无空值或错误ID。
- 发起口语化咨询“小麦田用什么除草剂”，核对返回结果中包含适用作物字段的匹配内容，且未出现未备案的产品信息。
- 调整`similarity`参数至0.7，确认返回结果中出现低匹配度的无关内容，验证阈值配置生效。
