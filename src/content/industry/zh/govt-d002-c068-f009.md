# 医药流通的办事咨询与答复：模型接入与配置
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这个品类的数据长什么样
医药流通领域的业务数据主要来自企业经营台账、药品监管备案系统与药品包装、资质扫描件。经营台账包含药品流通流向、批次、数量等字段，单位涉及盒、箱、批次号；监管备案数据包含统一社会信用代码、药品批准文号、经营许可证编号等结构化字段。经营资质类数据随企业变更实时更新，进销存类数据每日更新，药品目录类数据按季度更新，同时附带大量图片类材料。

## 这些特征在「模型接入与配置」这一环带来什么约束
医药流通数据包含专业药品术语、结构化的资质与交易字段，且附带大量图片类材料，同时数据更新节奏存在差异。专业术语与长文本的交易记录要求模型具备足够的上下文承载能力，避免信息截断；图片类材料需模型支持视觉识别功能，否则无法解析资质与包装信息；不同更新频率的数据需匹配对应的调用频次，避免高频调用导致的服务压力，同时需适配结构化字段的精准查询需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `vision` | 开启 | 医药流通数据包含药品包装、经营许可证等图片类材料，需支持图片识别以解析相关资质与包装信息 |
| `maxContext` | 8000–12000 token | 医药流通数据包含专业术语与长文本的交易记录，需足够的上下文承载完整的业务信息 |
| `maxTokens` | 2000 token | 限制单次回复的长度，适配办事咨询的常规答复范围，避免输出冗余内容 |
| `temperature` | 0.2–0.4 | 办事咨询需准确答复政策与业务流程，不宜过高的随机性以避免专业术语错误 |
| `toolChoice` | auto | 需根据用户咨询自动调用工具查询药品流通信息或资质数据，提升答复准确性 |
| `AIPROXY_API_ENDPOINT` | 填写部署节点的公网接口地址 | 适配本地或私有部署的模型服务，确保数据调用符合合规要求 |

## 容易做错的三处
- 现象：开启`vision`配置后，上传药品包装图片无识别结果，界面提示无法提供图片内容。原因：未在对话节点单独开启图片识别开关，或接入的模型未适配视觉能力。
- 现象：连接VLLM部署的Qwen3-Embedding-8B模型时出现连接报错。原因：`AIPROXY_API_ENDPOINT`配置的地址未包含正确的嵌入模型接口路径，或`AIPROXY_API_TOKEN`权限不足。
- 现象：模型调用工具时偶尔中断输出。原因：`maxContext`配置值过小，导致上下文溢出触发中断，或`maxTokens`设置超出模型支持的上限。

## 怎么确认配好了
- 上传药品包装或经营许可证扫描件至对话节点，查看是否能返回对应识别结果。
- 调用配置的模型接口，验证`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的连通性，确认无报错返回。
- 发起包含专业药品术语或流通流程的咨询，查看回复是否符合业务逻辑且未出现随机错误。
- 测试工具调用流程，确认模型能自动触发工具查询相关医药流通数据或资质信息。
