# 危化品储运的办事咨询与答复：工作流编排

## 这个品类的数据长什么样
危化品储运的数据来自危化品安全监管备案平台、企业自有储运台账、合规性检验报告三类来源。备案数据包含品名、UN编号、存储阈值、运输路线等固定字段，更新节奏为每季度同步；台账数据包含实时存储量、巡检记录、设备状态等字段，每日同步更新。文档格式多为结构化表格或标准化报告，字段单位包含摄氏度、吨、立方米等专属计量标准，UN编号为固定5位数字格式。

## 这些特征在「工作流编排」这一环带来什么约束
危化品储运数据的固定字段格式要求工作流节点支持精准匹配UN编号等标识字段，避免检索结果偏差；专属计量单位要求工作流配置时校验输入参数与数据字段的单位一致性，防止合规判断错误。差异化的更新节奏要求关联的知识库设置不同的同步周期，保障数据时效性。多维度的合规字段则要求工作流拆分不同检索节点，避免单次检索过载影响响应速度。FastGPT v4.17.0版本的工作流节点需适配这些特征，否则会出现检索匹配错误或数据不同步的问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 知识库同步间隔 | 分两类设置：备案库按90天，台账库按1天 | 匹配危化品储运备案数据与台账数据的更新节奏 |
| `variables` | 绑定UN编号、存储温度、合规阈值字段 | 对应危化品储运数据的核心标识与合规参数 |
| `nodeId` | 绑定检索节点的唯一标识 | 用于精准关联危化品储运数据的检索节点 |
| 文件上传节点权限 | 开启图片、PDF文档上传，限制单文件大小不超过1000 MB | 适配储运现场巡检图片、合规报告文档的上传需求 |
| 节点超时设置 | 600秒 | 匹配跨部门调取危化品合规数据的响应时长 |
| 搜索召回条数 | 前8条 | 平衡检索效率与合规信息的完整性 |

## 容易做错的三处
- 选择知识库引用变量时界面下拉框无可选值，原因是未将危化品储运的核心数据字段绑定到`variables`参数。
- 数据库连接节点无法输入端口号，原因是未开启节点的高级配置权限，或数据库驱动未适配危化品台账的专用数据库类型。
- 工作流发布后无法多人扫码接入，原因是未设置共享权限或未将工作流配置为公开可访问模式。

## 怎么确认配好了
- 进入工作流的变量配置页面，检查是否已绑定危化品储运的核心字段。
- 触发测试调用，上传危化品储运相关的巡检图片或合规文档，确认文件上传节点正常接收。
- 手动触发工作流，查看知识库检索结果是否包含对应品类的合规数据。
- 检查数据库连接节点的端口号配置项是否可正常输入并保存。
