# 危化品储运的办事咨询与答复：部署与升级

## 这个品类的数据长什么样
危化品储运的办事咨询数据主要来自企业内部储运台账、应急管理部门危化品监管系统、行业合规标准文档三类。数据包含结构化字段与非结构化内容：结构化字段包括危化品编号、CAS号、存储温度阈值、存储量、运输路线、审批单号等，非结构化内容包括应急处置手册、作业指导书等。数据更新节奏差异明显，监管类数据每日同步更新，企业内部台账实时更新，合规标准文档每季度修订。文档按储运节点、物料信息、审批流程、应急处置四个模块组织，字段需匹配监管合规要求。

## 这些特征在「部署与升级」这一环带来什么约束
危化品储运数据的多源异构与合规属性，对部署与升级环节提出明确约束。结构化字段需保留关联性，部署时需配置字段映射规则，避免分块破坏CAS号、存储量等关键合规信息。多源数据的更新频率差异，需拆分增量同步任务，适配每日更新的监管数据与实时更新的企业台账。数据涉及安全合规，存储与缓存配置需强化权限校验，升级时需兼容旧版数据格式，避免同步中断导致合规信息缺失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 10–15 个 | 适配多源数据同步的并发连接需求，避免并发请求耗尽连接池 |
| `STORAGE_S3_ENDPOINT` | 符合等保要求的私有存储桶端点 | 存储涉密的危化品储运数据，保障数据安全合规 |
| `REDIS_URL` | 带密码认证、600 秒超时的缓存服务地址 | 缓存高频查询的合规字段数据，降低主数据库负载 |
| `MONGODB_URI` | 多源数据聚合库的安全连接地址 | 关联结构化储运台账与非结构化应急文档，实现统一检索 |
| `FILE_TOKEN_KEY` | 32位随机加密字符串 | 加密危化品文档的访问令牌，防止未授权访问敏感内容 |
| `FE_DOMAIN` | 企业内部办公域名 | 限定咨询答复的访问边界，适配内部办公场景 |

## 容易做错的三处
- 现象：容器持续重启，日志显示数据库连接配额耗尽。原因：未配置`DB_MAX_LINK`的合理取值，并发同步请求超出数据库连接上限。
- 现象：导入的危化品数据字段缺失，知识库检索结果不完整。原因：未针对结构化数据配置字段映射规则，分块时破坏了CAS号、存储量等关键合规字段的关联性。
- 现象：外部监管网站的知识库内容无法实时更新。原因：未配置多源数据同步规则，直接使用通用知识库导入流程处理结构化监管数据。

## 怎么确认配好了
- 执行数据库连接测试命令，验证`MONGODB_URI`的连接状态，确认无权限报错或超时提示。
- 上传一份危化品储运的结构化台账与非结构化应急文档，检查字段解析完整性与存储路径是否匹配`STORAGE_S3_ENDPOINT`的配置。
- 发起一条测试咨询，验证缓存功能是否正常，高频查询的响应速度符合预期。
- 访问`FE_DOMAIN`指定的域名，确认咨询界面可正常加载且无跨域报错。
