# 发电装备制造的办事咨询与答复：模型接入与配置

## 这个品类的数据长什么样
发电装备制造的业务数据主要来自设备运行日志、检修维护文档、行业国标规范与备件库存台账。运行日志按设备运行周期生成，更新频率为每小时至每日；检修文档在单次维护完成后同步更新。文档结构包含设备参数表（含型号、额定功率、运行时长字段）、故障排查手册（分故障现象、原因、处置步骤模块）、备件编码清单（含编码、名称、库存数量字段），字段多带明确物理单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
发电装备制造的业务数据特征对模型接入配置带来多重约束。设备运行日志的时序性与实时更新要求模型可承载近7天的连续数据，对`maxContext`的容量提出明确需求；单篇故障排查手册长度可达数万字符，需配置适配长文本处理的参数；备件台账包含多单位数值字段，需确保模型输入的字段映射准确匹配物理单位；内网部署的设备数据不允许外发，因此模型接入需优先选择内网可访问的部署路径，同时限制外网请求的触发范围。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 15000–20000 token | 适配单篇故障手册+7天运行日志的总长度需求，避免上下文截断丢失关键信息 |
| `maxTokens` | 4000–6000 token | 匹配发电装备故障排查的常规回复长度，确保处置步骤可完整输出 |
| `quoteMaxToken` | 3000–4000 token | 限制引用的设备文档片段长度，避免单条引用占用过多上下文空间 |
| `temperature` | 0.2–0.4 | 降低随机性，确保故障排查与参数查询的回复符合行业规范与固定逻辑 |
| `AIPROXY_API_ENDPOINT` | 内网部署的模型服务地址 | 适配发电装备数据不允许外发的安全要求，避免敏感数据泄露 |
| `AIPROXY_API_TOKEN` | 内网模型专属访问密钥 | 限制仅内网授权节点可调用模型服务，提升数据安全性 |

## 容易做错的三处
- 现象：配置`AIPROXY_API_ENDPOINT`为外网地址后，FastGPT返回「模型连接超时」或「403 Forbidden」报错。原因：发电装备的核心运行数据不允许外发，外网地址无法匹配内网数据访问的安全策略，导致请求被拦截或无法建立连接。
- 现象：调用模型后返回的故障排查步骤缺失关键参数值。原因：`maxContext`取值过小，导致7天运行日志的时序数据被截断，模型无法获取设备当前运行时长等关键参考信息。
- 现象：使用视觉类模型接入后返回空值。原因：未正确配置`toolChoice`参数，未指定模型需启用视觉处理能力，导致模型无法解析上传的设备故障图片数据。

## 怎么确认配好了
- 在FastGPT v4.17.0版本的内网环境下调用测试接口，输入设备运行参数查询指令，核对返回结果是否包含匹配的设备型号与运行时长信息。
- 上传单篇故障排查手册片段，查看模型返回的引用来源是否准确匹配文档中的故障现象与处置步骤。
- 查看FastGPT的日志面板，确认模型请求的发送地址为内网部署的服务地址，无外网请求流量。
- 调整`temperature`参数后，多次输入同一故障查询指令，核对返回结果的逻辑一致性是否符合预期。
