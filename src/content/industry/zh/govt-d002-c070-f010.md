# 发电装备制造的办事咨询与答复：知识库检索与召回

## 这个品类的数据长什么样
发电装备制造的知识库数据主要来源于企业内部研发设计文档、运维检修手册、零部件规格书、行业技术标准文件，更新节奏随新机型投产、行业标准修订或运维经验积累调整。文档包含结构化参数表与非结构化操作说明两类内容，字段涵盖设备型号、额定容量、运行温度范围、故障代码等，单位多为兆瓦、转每分钟、摄氏度等，单篇文档长度跨度从数百字符的故障代码说明到数万字符的整机运维手册。

## 这些特征在「知识库检索与召回」这一环带来什么约束
文档中的结构化参数要求检索同时支持关键词匹配与数值范围匹配，避免召回参数单位或数值不符的无关内容；非结构化文档长度跨度大，分块与召回时需适配不同长度的文本，防止长文本被过度截断或短文本无法覆盖完整语义；数据更新无固定周期，需支持灵活的增量同步机制，确保新机型文档及时纳入知识库；部分内部运维文档涉及业务细节，检索时需结合权限控制，避免敏感内容被非授权调用。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.72–0.85` | 发电装备参数类文档需要较高的匹配精度，避免召回参数单位或数值不符的无关内容 |
| `limit` | `前8–12条` | 单篇运维文档的相关召回结果不宜过多，避免上下文溢出影响后续生成效果 |
| `searchMode` | 混合检索 | 兼顾关键词匹配与数值参数的精准匹配，适配文档中的结构化与非结构化内容 |
| `usingReRank` | 开启 | 对长文本运维文档的召回结果进行二次排序，提升最终召回内容的相关性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 通过扩展用户咨询的问题，补充“额定功率”“转速”等发电装备专属关键词，适配参数检索需求 |
| `collectionIds` | 指定发电装备业务相关的知识库集合ID | 仅召回目标业务的文档，排除无关业务的知识库内容 |

## 容易做错的三处
- 现象：通过API上传知识库文件时，中文文件名显示为乱码。原因：未在API请求头中指定正确的字符编码格式，导致文件名参数传输时出现编码错误。
- 现象：创建知识库时无法选择本地部署的ChatGLM2模型，即使已通过OneAPI接入。原因：未在FastGPT v4.17.0的模型配置页面中添加对应OneAPI的自定义模型渠道，或配置的模型名称与OneAPI返回的模型标识不匹配。
- 现象：导入Notion链接作为知识库来源时，无法正常抓取页面内容。原因：未配置Notion的API访问权限，或链接未开放公开/团队访问权限，导致无法获取页面数据。

## 怎么确认配好了
- 上传单篇发电装备运维文档作为测试数据，发起包含“故障代码”“检修步骤”的咨询，核对召回结果是否包含目标内容。
- 查看检索统计面板，确认召回结果的数量与`limit`参数的设置一致。
- 验证API上传功能，上传含中文文件名的测试文件，确认文件名显示无乱码。
- 检查知识库的关联集合，确认仅包含发电装备相关的`collectionIds`，无无关业务内容。
