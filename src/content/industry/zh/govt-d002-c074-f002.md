# 国有资产管理公司的办事咨询与答复：向量模型与索引

## 这个品类的数据长什么样
数据来源包括内部办事指南手册、国资监管政策文件、过往用户咨询台账、线下办事窗口记录。更新节奏为政策类文档按监管要求不定期更新，办事指南按事项调整实时或每周更新，咨询台账每日同步。文档结构分为结构化事项类（含事项名称、办理条件、材料清单、办理时限）与非结构化问答类（含咨询问题、答复内容、办理结果），字段包含事项编码、办理主体、咨询用户类型等，单位多为工作日、条、人次。

## 这些特征在「向量模型与索引」这一环带来什么约束
办事指南的长文本需合理拆分以保留完整语义，避免分块后丢失事项关联；监管政策的专业术语多，需向量模型适配国资领域专有词汇，提升匹配精度；数据更新频率不均，要求索引支持增量构建，避免全量重建占用资源；多字段混合的数据需统一向量处理逻辑，确保不同类型文档的检索一致性；短文本的咨询问答需保留上下文关联，避免拆分后语义断裂。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 国有资产管理公司办事指南多为结构化长文本，该区间可保留单个办事事项的完整语义 |
| 重叠长度 | 100–150 字符 | 衔接相邻分块的上下文，避免长文本拆分后出现语义断裂 |
| 相似度阈值 | 0.72–0.80 | 过滤低相关检索结果，适配国资领域专业术语较多的场景，保障答复准确性 |
| 单次搜索上限 | 前 8 条 | 办事咨询需精准结果，过多结果会增加筛选成本，符合用户快速获取信息的需求 |
| `maxToken` | 8000 token | 适配主流向量模型的输入限制，保障检索后拼接的上下文可完整传入生成环节 |
| 问题优化 | 开启 | 优化用户口语化的办事咨询问题，提升检索匹配的精准度 |

## 容易做错的三处
- 现象：上传办事指南文档后，检索结果出现大量不相关的政策片段，无法精准匹配咨询问题。原因：未设置合理的分块长度与重叠长度，导致分块语义断裂，检索时匹配到无关内容。
- 现象：本地部署FastGPT v4.17.0后，新建知识库时未显示图片索引模型选项。原因：未开启对应功能权限，或本地部署包未集成适配场景的图片索引插件。
- 现象：增量更新国资监管政策文档后，检索结果未包含新内容。原因：未配置增量索引触发规则，或增量更新的触发条件未匹配文档更新标签。

## 怎么确认配好了
- 上传一份典型的办事指南文档，查看系统生成的分块结果，确认分块长度与重叠长度符合配置区间。
- 输入一条高频办事咨询问题，核对检索返回的结果条数与相似度评分，确认阈值与搜索上限配置生效。
- 上传一份更新后的政策文件，等待索引构建完成后检索相关关键词，确认新内容已被纳入检索范围。
- 查看向量模型的调用日志，确认匹配结果的相似度评分处于设定的阈值区间内。
