# 国有资产管理公司的办事咨询与答复：知识库检索与召回

## 这个品类的数据长什么样
国有资产管理公司的数据源涵盖国资监管部门备案的资产权属文件、集团内部资产台账、产权交易公告、企业年度经营报告及内部办事流程手册。数据更新节奏分为两类：资产权属变动、审批节点调整等实时更新，月度监管报表、年度报告按固定周期同步。文档结构多包含资产编码、权属单位、账面价值、处置权限、审批流程等字段，单位涉及万元、平方米、股权比例等业务常用单位，部分文档为长文本格式的政策解读与办事指南。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源分散的数据源要求检索覆盖不同格式的文档类型，需支持结构化字段与非结构化文本的混合匹配。实时更新的资产数据要求检索链路支持增量同步触发，避免召回过期的资产信息。字段与单位的多样性要求检索规则需兼容数值单位的统一匹配，防止因单位差异导致的召回失败。长文本类的年度报告则需要合理的分块策略，保留字段间的上下文关联，避免拆分后丢失关键业务逻辑。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.65–0.75 | 匹配国资办事咨询的严谨性需求，过滤低相关结果的同时覆盖核心业务关键词 |
| `limit` | 前6–10 条 | 适配国资办事流程涉及多节点的咨询场景，保留足够上下文供后续答复生成 |
| `searchMode` | `vector` | 适配结构化资产台账与非结构化办事手册的混合检索场景，兼顾精准度与召回范围 |
| `usingReRank` | 开启，重排上限为前10 条 | 过滤初步检索中的弱相关结果，提升国资政策、资产处置流程类内容的召回准确性 |
| `datasetSearchUsingExtensionQuery` | 关闭 | 严格匹配国有资产管理的原始业务文档内容，避免扩展查询偏离合规性要求 |
| `collectionIds` | 按本公司专属资产知识库ID填充 | 限定检索范围仅覆盖本公司的合规业务数据，防止跨库检索引入无关内容 |

## 容易做错的三处
- 检索得分超出0-1区间，例如界面显示4000多分，原因是误用了非归一化的相似度计算逻辑，或未正确配置`similarity`参数的取值范围。
- 工作台查询指定文档时返回无结果，原因是`collectionIds`未绑定对应知识库，或文档未完成索引同步。
- 复杂表格内容无法被正确召回，原因是未将表格按行/列拆分为带字段的检索单元，或分块时丢失了表格的结构关联。

## 怎么确认配好了
- 手动输入资产编码、办事流程关键词，验证检索结果包含对应台账或指南文档。
- 查看工作流日志，确认`collectionIds`参数已正确传入知识库检索节点。
- 调整`similarity`参数的取值区间，验证检索结果条数随阈值变化符合预期。
- 触发一次增量更新操作，验证新上传的资产变动文档可被正常检索到。
