# 国有资本投资公司的办事咨询与答复：模型接入与配置

## 这个品类的数据长什么样
国有资本投资公司的办事咨询数据主要来源于内部办事指南文档、国资监管政策文件、历史咨询答复记录与审批流程档案。数据更新随国资政策调整、内部流程优化同步进行，核心文档更新周期为季度级，历史咨询记录按归档要求留存。单份文档通常包含事项编号、办理主体、申请材料清单、办理时限、常见问题等结构化字段，材料清单标注所需份数，办理时限以工作日为单位，常见问题按咨询主题分类整理。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的办事咨询数据包含结构化字段与分类标签，要求模型能准确提取事项编号、办理时限等关键信息，需适配结构化数据的上下文处理逻辑。季度级的更新节奏要求知识库同步周期无需过短，但需确保接入的模型能兼容定期更新的文档格式。历史咨询记录的分类标签要求模型调用时能按主题召回相关内容，需合理限制单次召回的文档数量。部分文档包含明确的单位标注（如工作日、申请材料份数），需确保模型生成答复时不会混淆单位表述，避免出现不符合国资监管要求的内容偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 适配FastGPT v4.17.0的上下文处理上限，可容纳多份办事指南与历史咨询记录 |
| `temperature` | `0.2–0.4` | 办事咨询需准确的流程说明，不宜生成发散内容，避免出现不符合监管要求的表述 |
| `quoteMaxToken` | `2000–3000 字符` | 单份办事指南文档长度通常在1000-2000字符，需确保召回的文档内容完整且不超出上下文限制 |
| `toolChoice` | `auto` | 办事咨询可能需要调用知识库召回工具，自动选择工具能提升答复的准确性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境的代理地址填写 | 合规调用大模型接口，避免直接暴露密钥 |
| `AIPROXY_API_TOKEN` | 按实际申请的代理密钥填写 | 安全调用大模型接口，防止密钥泄露 |

## 容易做错的三处
- 现象为大模型调用返回500状态码或超时，原因是未正确配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或代理网络出现波动。
- 现象为生成的答复中出现单位混淆（如将工作日写为自然日），原因是`temperature`取值过高，导致模型生成发散内容，未严格匹配文档中的单位标注。
- 现象为向量生成时提示内容长度超出限制，原因是未结合`quoteMaxToken`的取值调整文档分块逻辑，导致分块内容超出向量模型支持的长度。

## 怎么确认配好了
- 调用测试接口，输入典型办事咨询问题，核对返回结果中是否包含准确的事项编号、办理时限等结构化信息。
- 手动触发知识库更新，检查更新日志中是否显示文档解析成功，无格式报错。
- 模拟大模型调用失败场景，检查是否触发预设的重试逻辑，或返回明确的错误提示。
- 查看配置页面的`AIPROXY_API_TOKEN`与`AIPROXY_API_ENDPOINT`字段，确认已正确填写且无格式错误。
