# 城市水务的办事咨询与答复：工作流编排

## 这个品类的数据长什么样
城市水务的办事咨询与答复数据来源包括官方办事系统、管网运维数据库、用户咨询归档库。更新节奏分为三类：管网压力、流量等实时监测数据为秒级更新，办事工单、收费数据按每日更新，常见问题知识库按每周同步。文档结构包含结构化字段与非结构化文本：结构化字段含事项编号、办理节点、材料清单、收费单价（单位为元/立方米）等；非结构化文本含办事指南详情、用户咨询回复原文等。

## 这些特征在「工作流编排」这一环带来什么约束
实时监测数据的秒级更新要求工作流避免过长缓存，否则会导致咨询内容滞后于当前水务状态。结构化字段的固定格式要求工作流的表单输入节点匹配字段类型，例如收费单价字段需限制非数字输入。办事工单的每日更新要求工作流的定时触发节点按每日周期执行同步。常见问题知识库的每周更新要求工作流的知识库召回节点同步周期匹配该频率。水务办事事项类型较多，需通过工作流分支判断，根据用户输入的事项类型匹配对应处理路径。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 表单输入节点触发规则 | 仅当前工作流内隐藏对话框，嵌套时禁用弹窗 | 匹配城市水务办事咨询的用户交互场景，避免嵌套调用时重复弹窗 |
| 知识库同步周期 | 7天 | 匹配常见问题库的每周更新节奏，减少无效同步操作 |
| 工作流超时阈值 | 300秒 | 适配水务数据查询的常规响应时长，避免长时间等待导致用户体验下降 |
| 上下文窗口大小 | 2000 token | 匹配水务办事咨询的文本长度，避免超出模型处理上限 |
| `variables` 配置 | 绑定管网压力、收费单价等专属字段 | 匹配城市水务数据的结构化特征，确保参数传递准确无误 |
| `nodeId` 配置 | 绑定表单节点与知识库召回节点的固定ID | 确保分支判断逻辑稳定，适配多类型水务办事事项的工作流分支 |
| 单次召回结果条数 | 前6条 | 匹配水务办事事项的常见问题数量，避免信息过载影响响应速度 |

## 容易做错的三处
- 现象为调用自定义Python代码函数时返回报错状态码500，原因是未在工作流的代码节点中配置正确的依赖包导入路径，导致依赖缺失。
- 现象为表单输入节点嵌套在父工作流中时，对话框持续显示，原因是未在表单节点的触发配置中关闭嵌套场景隐藏弹窗的开关，导致全局弹窗规则未生效。
- 现象为工作流运行耗时超过预设阈值，原因是未限制单次召回的结果条数，导致过多的知识库文档被加载，拖慢运行速度。

## 怎么确认配好了
- 触发测试表单提交，查看工作流日志中是否正确传递了水务办事的专属字段值。
- 检查知识库同步任务的执行记录，确认按预设周期完成更新。
- 模拟嵌套工作流调用，确认表单节点的对话框未显示。
- 运行工作流并查看耗时日志，确认未超过预设的超时阈值。
