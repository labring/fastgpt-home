# 城市水务的办事咨询与答复：工具调用与插件

## 这个品类的数据长什么样
城市水务的办事咨询数据主要来自市政水务运营的内部管理系统，涵盖供水报装、排水报修、水质查询、缴费办理等官方办事事项的指南内容。数据更新节奏为分层同步：水质监测数据每小时更新，办事工单与常见问答每日更新。文档以结构化字段与非结构化文本混合呈现，结构化字段包含事项名称、办理时限（单位为工作日）、所需材料清单、咨询电话等，非结构化内容为事项办理的详细流程与常见问题解答。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于数据包含结构化字段与非结构化文本，工具调用需要同时支持结构化参数查询与非结构化内容检索，避免返回不完整的办事信息。高频更新的特性要求插件需配置定时同步任务，确保调用的是最新的水务办事数据。字段自带专属单位（如水质指标单位为mg/L、办理时限单位为工作日），工具调用时需自动适配单位格式，防止返回不符合用户认知的数值表述。此外，办事咨询场景的问题聚焦于具体事项，工具调用的上下文需限制在相关事项范围内，避免冗余信息干扰。

本页适用 FastGPT v4.17.0 版本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配水务办事指南的单条内容长度，避免块内信息断裂 |
| 单次工具调用上限 | 前 3 条 | 水务办事事项数量集中，过多会导致上下文冗余 |
| 工具调用超时时间 | 60 秒 | 匹配市政水务系统接口的常规响应时长 |
| 重排策略 | 按相关性从高到低 | 优先返回用户最常咨询的办事事项 |
| `toolChoice` | auto | 允许模型自主选择是否调用工具处理水务办事咨询 |
| `functionCall` | 绑定水务办事自定义函数 | 确保工具调用的数据源与知识库的水务数据保持一致 |

## 容易做错的三处
- 工具调用结果未关联到知识库检索内容。原因是未将知识库的水务办事数据绑定到工具调用的数据源，导致工具无法调用对应事项的详细办理流程。
- 工具调用响应超时。原因是工具调用超时时间设置过短，未匹配市政水务系统接口的常规响应时长。
- 工具调用返回结果为空。原因是未配置水务办事数据的定时同步任务，知识库未加载最新的办事事项与问答内容。

## 怎么确认配好了
- 发起包含“如何办理水表报装”的测试提问，查看工具调用是否返回对应的办事事项内容。
- 查看工具调用日志，确认响应时长符合设置的超时时间要求。
- 检查数据源同步状态，确认水务办事数据已完成最新一次的同步更新。
- 测试包含单位表述的提问，如“当前水质达标吗”，确认工具返回的指标单位与官方表述一致。
