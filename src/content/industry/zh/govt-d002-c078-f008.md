# 城市水务的办事咨询与答复：文档解析与分块

## 这个品类的数据长什么样
城市水务的办事咨询与答复数据主要来自城投水务的官方办事指南、管网运维文档、缴费须知、报修流程手册，更新节奏按需或按月更新。文档类型涵盖PDF格式的管网图纸说明、Word格式的办事流程手册、标准化的办事指引文件，包含办事事项编号、办理时限、收费标准、服务热线等字段，单位多为立方米、元/吨、工作日等。

## 这些特征在「文档解析与分块」这一环带来什么约束
管网图纸类PDF包含图表与文本混合内容，常规解析工具难以完整提取结构化信息，需适配混合格式解析。标准化办事指引的固定章节结构要求分块不破坏业务逻辑，需按章节边界拆分，避免硬截断。部分文档单份篇幅较长，分块长度需匹配业务咨询的常见问题范围，避免拆分后丢失上下文关联。按需更新的文档需支持增量解析，减少重复处理成本。

## 配置怎么定
本配置方案适配FastGPT v4.17.0版本，具体参数配置如下：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 匹配城市水务办事文档的章节段落长度，避免拆分后丢失办事流程、收费标准等完整业务信息 |
| `chunkSplitter` | 按章节拆分 | 适配标准化办事指引的固定结构，保留业务逻辑的完整性 |
| `customPdfParse` | 启用混合格式解析 | 处理包含管网图纸、图表的PDF文档，完整提取文本与图形关联信息 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配单份大型管网运维PDF文档的上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 避免大型文档解析过程中出现超时报错 |
| `chunkSettingMode` | 手动配置 | 针对水务文档的特殊结构调整分块参数，适配业务咨询的上下文需求 |

## 容易做错的三处
- 上传大型管网PDF后解析失败，返回超时状态码。原因是未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时长不足以完成大型文档解析。
- 部分含管网图纸的PDF无法识别有效文本。原因是未启用`customPdfParse`混合格式解析，常规解析仅能提取纯文本内容，丢失图纸关联的说明信息。
- 工作流中调用文档解析工具报错，无法读取上传文件地址。原因是未配置对应环境变量，本地部署环境无法直接访问本地上传文件路径。

## 怎么确认配好了
- 上传一份典型的水务办事指南PDF，检查解析后文本是否包含完整的办事事项、办理时限等字段。
- 调整`chunkSize`参数后，查看分块结果是否按章节拆分，未出现跨章节的不完整段落。
- 上传一份100 MB左右的管网运维文档，验证解析过程未触发超时报错。
- 查看系统配置项，确认`UPLOAD_FILE_MAX_SIZE`与`PARSE_FILE_TIMEOUT_SECONDS`的取值符合当前文档处理需求。
