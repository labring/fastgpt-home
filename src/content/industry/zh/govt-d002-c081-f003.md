# 基础化工的办事咨询与答复：多轮对话与提示词

## 这个品类的数据长什么样
基础化工办事咨询与答复的数据主要来自各地工信、应急管理部门发布的基础化工企业合规办事指南，包括危险化学品生产许可、新建项目安全审查等事项的官方文档，以及行业合规手册。数据更新随官方政策发布节奏调整，无固定周期。文档多为结构化格式，包含事项名称、办理主体、办理时限（单位为工作日）、申请材料清单、审批节点等字段，部分文档附带现场核查要求与常见问题解答。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
基础化工办事数据的结构化字段与合规属性，要求多轮对话需明确引导用户按事项分类提问，避免跨事项混淆。办理时限以工作日为单位的字段，要求提示词中明确区分自然日与工作日的计算规则，防止回复出现时间单位错误。无固定更新周期的数据源，要求对话流程中嵌入知识库同步校验环节，确保调用的是最新政策文档。同时，申请材料清单的多条目属性，要求多轮对话按顺序逐步收集材料信息，避免用户一次性提交大量信息导致遗漏。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chatId` | 按会话生成唯一标识，按实测标定 | 用于区分不同用户的办事咨询会话，避免上下文混淆 |
| `messages` | 保留最近8–12轮对话内容 | 基础化工办事咨询多为多轮材料收集，足够的上下文可完整传递用户诉求与历史指引 |
| `variables` | 预设事项分类、办理时限单位变量 | 快速定位对应知识库的办事指南片段，提升检索精准度 |
| 问题优化 | 开启 | 基础化工事项名称复杂，问题优化可提炼用户核心诉求 |
| 单次搜索上限 | 前5–7条 | 匹配基础化工办事数据的条目密度，避免冗余信息干扰 |
| 最大上下文 | 7000–13000 token | 覆盖基础化工办事文档的多章节内容，确保回复信息完整 |

## 容易做错的三处
- 调用对话组件时出现未捕获的异常，通常是配置文件中`variables`或`messages`的格式不符合要求，未按系统预设的JSON结构传递参数。
- 生成的回复未参考知识库文档，原因是未将基础化工办事指南的专属知识库绑定至对话流程，或搜索配置的筛选条件设置偏差，导致检索范围错误。
- 对话页面或知识库页面崩溃，原因是使用的FastGPT版本与部署环境的依赖包不兼容，需升级至FastGPT v4.17.0并重新安装依赖。

## 怎么确认配好了
- 发起测试对话，输入基础化工办事相关的问题，检查回复中是否包含知识库内的合规内容，确认检索范围正确。
- 查看会话日志，确认`chatId`、`messages`参数已按预设格式传递，无格式错误。
- 触发多轮材料收集流程，检查系统是否按顺序引导用户提交申请材料，未遗漏必要字段。
- 重启部署服务后，验证对话页面与知识库页面无崩溃现象，确认版本适配正确。
