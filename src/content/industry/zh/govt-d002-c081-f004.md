# 基础化工的办事咨询与答复：工作流编排

## 这个品类的数据长什么样
基础化工的办事咨询与答复数据主要来自企业内部的工艺操作规程、原料质检报告、设备运维日志、合规性标准文档，以及行业公开的基础化工技术规范。数据更新节奏分为三类：内部工艺规程随工艺迭代按需更新，原料质检报告随批次生成，行业标准文档按年度发布。文档结构以章节化为主，包含物料名称、工艺参数、安全阈值、操作步骤等字段，字段附带专业单位。

## 这些特征在「工作流编排」这一环带来什么约束
基础化工数据的专业单位要求工作流中`variables`绑定的参数必须匹配对应单位，避免格式冲突。数据的章节化结构要求工作流分块时保留上下文关联，不能随意截断跨章节的合规条款。内部数据按需更新的特性要求工作流配置按需触发的数据源刷新节点，适配行业标准的年度更新周期。多类型数据的混合调用要求工作流中设置节点间的校验逻辑，确保合规性数据与业务数据的一致性。同时，基础化工的安全合规要求需要在工作流中嵌入强制校验环节，避免遗漏关键条款。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 绑定物料编码、工艺参数、合规条款等字段，按实测标定 | 匹配基础化工业务数据的字段结构，确保参数格式正确 |
| `nodeId` | 按“化工-模块-序号”命名，如chem-proc-01、chem-comp-02 | 便于跨工作流复制组件时识别，避免标识冲突 |
| 数据源刷新频率 | 按文档类型分：工艺规程设为7天，合规文档设为30天 | 适配基础化工工艺迭代和行业标准的更新周期 |
| 工具调用超时时间 | 600秒 | 覆盖基础化工合规校验、参数查询的常规耗时 |
| 上下文长度限制 | 800–1200字符 | 保留基础化工文档的章节核心内容，避免冗余数据干扰 |
| 节点连接校验 | 开启参数格式校验 | 确保跨节点传递的化工数据符合专业单位要求 |

## 容易做错的三处
- 现象：工具调用节点返回Invalid JSON: Bad control chara报错 | 原因：工作流中`variables`绑定的化工数据包含换行符或不可见控制字符，未做转义处理
- 现象：无法将工作流中的组件粘贴到其他工作流，移动组件时无响应 | 原因：未正确配置`nodeId`的命名规则，跨工作流复制时组件标识冲突
- 现象：工作流中的合规校验节点无法添加连接线，无连接小圆圈 | 原因：节点的`nodeId`配置为空或格式错误，系统无法识别节点连接关系

## 怎么确认配好了
- 打开FastGPT v4.17.0的工作流变量配置面板，检查`variables`绑定的字段是否包含基础化工的物料、工艺参数等业务字段
- 测试工具调用节点，输入带标准单位的化工参数，确认返回结果无格式错误
- 复制一个工作流节点，粘贴到新的工作流中，检查组件连接正常
- 查看数据源刷新日志，确认按预设频率更新对应文档
