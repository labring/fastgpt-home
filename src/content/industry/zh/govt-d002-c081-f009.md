# 基础化工的办事咨询与答复：模型接入与配置

## 这个品类的数据长什么样
基础化工办事咨询相关的数据来源包括企业内部的生产工艺规程、物料安全技术说明书（MSDS）、设备维护操作手册、政府监管部门发布的化工合规指南、过往办事咨询工单记录等。更新节奏为：合规指南按季度随监管要求更新，工艺规程随生产技改调整，MSDS随物料配方变更同步更新，工单记录实时留存。文档结构以结构化参数文档为主，包含明确的章节号、物料名称、操作参数、单位（如MPa、℃、kg/h），同时存在非结构化的操作日志、咨询对话历史。

## 这些特征在「模型接入与配置」这一环带来什么约束
基础化工的结构化参数文档要求模型检索时精准匹配字段与单位，因此配置时需确保索引环节保留字段的原始格式与单位信息；长段落的工艺说明与合规条款需要足够的上下文窗口，因此需调整相关上下文参数的取值；数据敏感性较高，需采用本地部署的模型服务，因此需配置代理端点与鉴权信息指向本地资源；非结构化的工单历史需要稳定的会话上下文，因此需合理设置会话过期时间，避免上下文丢失影响咨询体验。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 基础化工文档多包含长段落的工艺说明与合规条款，需保留足够上下文避免关键参数与流程被截断 |
| `maxTokens` | `4000–6000 token` | 化工办事咨询的答复需覆盖物料参数、操作步骤等完整内容，避免关键信息缺失 |
| `quoteMaxToken` | `1500–2000 token` | 需准确引用MSDS、工艺规程中的具体条款，确保答复的合规性与准确性 |
| `toolChoice` | `auto` | 化工咨询可能涉及参数查询、合规校验等不同场景，自动选择工具调用更灵活适配需求 |
| `temperature` | `0.1–0.3` | 化工场景需严谨的参数与流程答复，较低的温度值可减少随机性，提升答复准确性 |
| `AIPROXY_API_ENDPOINT` | `http://本地部署ollama的地址:11434/v1` | 基础化工数据敏感性强，本地部署可避免敏感数据外泄 |

## 容易做错的三处
- 现象：调用FastGPT API发送连续间隔较短的咨询问题时，后续请求需等待前序生成完成。原因：未配置会话并发隔离，默认会话上下文绑定单线程处理逻辑，无法同时响应多个请求。
- 现象：Docker私有部署后调用本地ollama服务返回报错。原因：`AIPROXY_API_ENDPOINT`未正确配置为本地ollama服务的访问地址，或未开放对应端口的访问权限。
- 现象：检索化工合规文档时返回结果与查询需求匹配度低。原因：未按化工文档的结构化章节拆分内容块，导致块内参数与上下文绑定混乱，匹配逻辑失效。

## 怎么确认配好了
- 发起本地ollama服务的连通性测试，检查`AIPROXY_API_ENDPOINT`配置是否能正常返回模型列表。
- 发送一条包含化工参数的测试咨询，核对答复中引用的文档片段是否与源数据的内容、单位一致。
- 发起两个间隔较短的连续咨询请求，确认可以同时响应且无排队等待现象。
- 调整`temperature`参数后发起测试，确认答复的严谨性符合化工办事咨询的场景要求。
