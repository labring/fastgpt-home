# 基础设施建设的办事咨询与答复：文档解析与分块

## 这个品类的数据长什么样
基础设施建设领域的办事咨询与答复数据，主要来自项目全周期的政务办事台账、施工技术文档、验收备案文件。数据随项目推进或新政务诉求提交更新，单次更新量随项目阶段波动。文档多为结构化与半结构化混合，包含诉求编号、提交主体、答复内容、关联项目编码、施工段参数等字段，附带的附件常包含CAD图纸、施工规范PDF、计量清单表格，字段单位涉及米、立方米、工作日等工程专用单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的混合文档结构要求解析环节同时适配文本、表格与工程图纸附件，避免破坏施工术语、计量参数的上下文关联。大体积的PDF规范文件与CAD图纸会拉长解析耗时，需要适配更长的超时阈值。半结构化的台账数据包含关联项目编码、施工段号等强关联字段，分块时需保留字段与对应内容的绑定关系，防止拆分后丢失上下文关联。实时更新的政务诉求台账要求解析流程支持低延迟批量处理，避免新提交的咨询答复无法及时完成入库。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配工程文档中长段落的技术说明，避免拆分破坏施工术语与参数的上下文关联 |
| `chunkSplitter` | 按段落+自定义分隔符 | 适配台账的结构化分段与技术文档的章节分隔，可配置“施工段”“诉求编号”作为自定义分隔符 |
| `customPdfParse` | 启用表格识别+图纸文本提取 | 适配PDF格式的施工规范与计量清单，保留表格列与行的对应关系 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 120–180 秒 | 适配大体积CAD图纸与长PDF规范的解析耗时，避免因超时导致解析失败 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 适配大型项目的全套施工图纸与备案文件上传需求 |
| `chunkSettingMode` | 手动配置 | 允许针对不同文档类型（台账、图纸、规范）单独调整分块参数，适配多格式混合场景 |

## 容易做错的三处
- 现象：上传大型CAD图纸或长PDF规范后，界面显示解析失败，后台日志返回超时状态码。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时长不足以完成大体积工程文档的解析。
- 现象：解析计量清单表格后，分块内容丢失表格列对应关系，部分字段为空。原因：未启用`customPdfParse`的表格识别功能，仅使用默认文本解析逻辑拆分内容。
- 现象：配置自定义JS处理解析结果后，最终分块内容未按预期执行修改，无对应执行日志。原因：未在`chunkSettingMode`中开启自定义解析脚本的启用选项，或脚本未绑定至当前品类的文档解析任务。

## 怎么确认配好了
- 上传单份500 MB以内的大型PDF规范文件，等待解析完成后查看分块结果，确认施工术语未被错误拆分。
- 上传包含表格的计量清单文档，检查分块内容是否保留表格行列的对应关系，无字段缺失。
- 调整`PARSE_FILE_TIMEOUT_SECONDS`参数后，上传大型CAD图纸，确认解析过程无超时报错。
- 配置自定义JS脚本并绑定至当前解析流程，上传测试文档后查看分块结果是否按脚本要求完成修改。
