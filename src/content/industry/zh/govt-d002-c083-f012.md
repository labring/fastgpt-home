# 基础设施建设的办事咨询与答复：部署与升级
本文基于FastGPT v4.17.0版本编写，针对基础设施建设领域办事咨询与答复功能的部署与升级环节提供配置指引。

## 这个品类的数据长什么样
数据主要来源于建筑施工项目的报建审批文件、现场施工答疑台账、政务办事咨询工单存档、工程验收文档。更新节奏随项目进度调整，项目启动时批量导入初始数据，施工节点变更、政策更新时实时补充。单份文档通常包含项目编号、施工标段范围、咨询问题原文、官方答复内容、办理时限、责任主体字段，部分文档附带CAD图纸、施工视频等附件，字段单位包括“工作日”“平方米”“公里”等，无统一固定的文档长度上限。

## 这些特征在「部署与升级」这一环带来什么约束
基础设施建设的办事咨询数据包含多类型附件与结构化字段，要求部署时需适配大体积文件存储与结构化数据读写。数据更新节奏不稳定，既有批量导入的历史项目数据，也有实时提交的咨询工单，需配置可动态调整的并发连接机制。不同施工标段的数据需严格隔离，避免跨项目数据泄露，因此需绑定专属访问域名与权限控制配置。部分数据附带非文本附件，需配置专属存储节点以保障读写效率，同时需预先定义数据库索引以加速结构化字段的查询。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://admin:securepass@db-host:27017/fastgpt_construction?authSource=admin` | 存储项目咨询工单、答复内容与工程关联数据，需配置数据库认证与专属库名 |
| `STORAGE_S3_ENDPOINT` | `https://s3.[自建存储区域].com` | 存储工程图纸、施工视频等大体积附件，适配基础设施建设数据的存储需求 |
| `FILE_TOKEN_KEY` | `随机生成的 32 位十六进制字符串` | 加密绑定工程附件的访问权限，确保仅授权用户可查看对应标段的文件 |
| `DB_MAX_LINK` | `10–12 个` | 适配多项目并发的数据库访问请求，避免连接池耗尽导致服务卡顿 |
| `FE_DOMAIN` | `https://construction-query.[企业域名].com` | 绑定专属访问域名，实现不同施工标段的办事咨询数据隔离 |
| `ROOT_KEY` | `仅首次部署时生成的随机密钥` | 配置系统最高管理权限，避免默认密钥带来的安全风险 |

## 容易做错的三处
- 现象：Docker部署FastGPT后，无法找到`packages/plugins/register`目录，无法加载自定义插件。原因：未在镜像构建脚本中添加插件初始化命令，导致目录未自动生成。
- 现象：本地部署工作流节点较多时，输入文字出现卡顿。原因：未配置`REDIS_URL`启用缓存服务，高频的节点状态更新直接请求数据库，导致IO负载过高。
- 现象：尝试导入办事咨询模板时提示权限不足。原因：未生成专属`ROOT_KEY`密钥，无法获取系统管理员权限以访问模板导入接口。

## 怎么确认配好了
- 执行数据库连接测试命令，验证`MONGODB_URI`配置的数据库可正常读写项目相关的结构化数据。
- 上传一份工程图纸附件，通过`FILE_TOKEN_KEY`生成的访问链接测试，确认仅授权账号可查看对应标段的文件。
- 访问配置的`FE_DOMAIN`域名，确认可正常加载办事咨询的前端页面与关联的项目数据。
- 发起多并发的咨询查询请求，确认`DB_MAX_LINK`配置的连接数未出现耗尽类的报错提示。
