# 工程机械的办事咨询与答复：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据主要来自设备原厂运维手册、故障代码数据库、备件清单规范与现场作业指导书。数据更新节奏随设备固件迭代或行业规范调整，通常为季度级更新。单篇文档结构固定，包含故障现象描述、排查步骤、对应备件型号、安全操作要求等模块，字段包含带字母+数字组合的故障代码、12位数字格式的备件编号、以小时/兆帕为单位的作业参数与压力值。

## 这些特征在「模型接入与配置」这一环带来什么约束
工程机械数据的固定结构与专用字段，对模型接入与配置环节带来多项约束。带字母数字组合的故障代码需模型准确匹配，因此需调整上下文保留长度以覆盖关联信息。以小时、兆帕为单位的参数要求答复内容精确，不宜过度发散。长文本的作业指导书需限制单条引用的长度，避免拆分后逻辑断裂。季度级的更新节奏要求配置同步周期与更新频率匹配，确保知识库内容始终与最新规范一致。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 工程机械故障排查文档通常包含多步骤关联逻辑，需保留足够上下文以准确匹配咨询内容 |
| `maxTokens` | 4000–6000 token | 单条办事咨询答复需覆盖故障代码、排查步骤与备件信息，避免截断关键内容 |
| `quoteMaxToken` | 1000–1500 字符 | 引用的设备手册片段需完整呈现参数与操作要求，防止拆分后逻辑断裂 |
| `temperature` | 0.2–0.4 | 办事咨询需严格匹配设备规范与作业要求，不宜生成过于发散的内容 |
| `AIPROXY_API_ENDPOINT` | 按云平台提供的专属调用地址填写 | 适配私有化部署下的云大模型调用路径 |
| `AIPROXY_API_TOKEN` | 与云平台生成的访问密钥完全一致 | 确保调用权限验证通过，避免身份验证失败 |

## 容易做错的三处
-  新增模型提供商后界面提示配置无效，无法发起测试调用。原因：未使用FastGPT v4.17.0的可视化配置入口，错误通过提交PR的方式添加自定义提供商。
-  接入DeepSeek R1后答复无思考过程，日志未显示中间推理步骤。原因：未开启`toolChoice`对应的思考过程开关，默认配置下该选项处于关闭状态。
-  OneAPI已测试通过的模型在FastGPT中返回404错误，测试弹窗显示状态码404。原因：模型ID填写内容与FastGPT要求的标识格式不匹配，未使用OneAPI返回的标准模型名称。

## 怎么确认配好了
-  进入模型提供商管理页面，选择新增的模型点击测试按钮，查看返回结果是否包含正常的模型响应内容。
-  导入一份工程机械故障手册文档，发起包含具体故障代码的咨询，核对返回结果中引用的文档片段是否完整准确。
-  调整`temperature`参数后发起三次相同的咨询，确认答复内容的一致性符合预期。
-  查看知识库同步日志，确认工程机械相关文档的更新频率与预设配置匹配。
