# 成品油销售的办事咨询与答复：向量模型与索引

## 这个品类的数据长什么样
成品油销售的办事咨询数据主要来源于加油站运营手册、油品价目表、发票办理指引、投诉处理规范、加油卡业务流程文档。数据包含结构化与非结构化两类：结构化数据包含油品型号、单价、生效时间、办理节点等字段，单位为元/升、次、件；非结构化数据为流程说明、常见问题解答。价目表随调价实时更新，运营手册按季度或合规要求更新，办事指引文档长期稳定更新。

## 这些特征在「向量模型与索引」这一环带来什么约束
结构化数据的字段固定且更新频繁，要求向量索引支持按字段元数据过滤，避免召回过期的价目信息；非结构化办事指引文本较长，需合理切分以保留语义完整性，避免跨块截断流程说明。短文本类办事咨询问题占比高，要求向量召回的匹配精度适配短文本语义，同时需支持近实时索引更新以同步最新价目表数据。此外，不同加油站的业务流程存在细微差异，索引需支持按站点维度隔离数据，避免跨站点的咨询结果混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配成品油销售文档的结构化片段与非结构化流程文本，保证语义完整性 |
| 重叠长度 | 100–200 字符 | 避免跨块的价目调整说明、办事流程被截断，保证上下文连贯 |
| 相似度阈值 | 0.75–0.85 | 适配办事咨询的短文本问题，过滤低匹配度的过期文档或无关流程 |
| 单次搜索上限 | 前 8 条 | 加油站办事咨询的关联文档数量集中，过多会增加上下文冗余 |
| `defaultToken` | 4096 | 适配Qwen3-Embedding-8B的最大输入token数，保证长文本办事指引完整嵌入 |
| `maxToken` | 8192 | 覆盖知识库检索后拼接的完整办事流程上下文长度需求 |

## 容易做错的三处
- 现象：连接VLLM部署的Qwen3-Embedding-8B时返回连接超时或500状态码。原因：未将VLLM服务端口开放至FastGPT部署的网络环境，或配置中填写的模型接口地址有误。
- 现象：知识库磁盘占用统计仅显示原文件大小，未包含分割后的文件块与嵌入向量。原因：未正确配置FastGPT的向量存储路径，导致嵌入向量未被计入总占用统计。
- 现象：检索结果条数与设置的单次搜索上限不符，且未过滤过期价目信息。原因：未为结构化的价目表数据配置元数据过滤规则，导致过期的调价文档被召回。

## 怎么确认配好了
- 上传一份本地的油品价目表文档，执行对应油品的单价查询测试，查看检索结果是否包含该文档的对应片段。
- 进入FastGPT v4.17.0的知识库管理页面，查看磁盘占用统计，确认显示原文件、分割块、嵌入向量三部分的总占用。
- 查看向量模型的调用日志，确认Qwen3-Embedding-8B的请求被正常接收并返回嵌入向量结果。
- 修改分块长度配置，重新触发文档切分，查看知识库的文档列表中是否显示更新后的块数量。
