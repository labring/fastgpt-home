# 房建工程总承包的办事咨询与答复：模型接入与配置

## 这个品类的数据长什么样
房建工程总承包的办事咨询相关数据主要来自住建部门发布的审批指南、项目招投标文件、施工过程日志、竣工验收报告及项目合同文件。数据更新随项目推进节奏调整，施工阶段按月更新进度类文档，验收完成后归档锁定。单份文档通常包含项目编号、标段范围、审批节点要求、材料清单、验收标准等字段，单位多采用平方米、日历天、万元、吨等工程领域通用标准单位。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 房建项目相关文档多为长文本，需容纳多份审批指南与施工日志的拼接内容，避免关键信息被截断 |
| `maxTokens` | 2000–3000 token | 办事咨询答复需覆盖具体审批要求与操作步骤，控制输出长度以保障响应效率 |
| `quoteMaxToken` | 3000–4000 token | 需保留完整的文档引用片段，确保答复中的审批依据可追溯，符合工程咨询的严谨性要求 |
| `toolChoice` | auto | 办事咨询涉及审批节点查询、材料清单核对等多类工具调用需求，自动选择工具可提升响应准确性 |
| `temperature` | 0.3–0.5 | 办事咨询需严谨准确的专业内容，避免生成过于发散的非标准表述 |
| `AIPROXY_API_TOKEN` | 填写部署生成的专属令牌 | 保障模型调用的身份验证安全，防止未授权访问 |

## 容易做错的三处
- 现象：工具调用返回结果中额外出现无意义的数字0。原因：未限定`toolChoice`的调用场景，模型误触发了无关的数值处理工具。
- 现象：答复中未包含知识库引用的完整审批依据内容。原因：`quoteMaxToken`配置取值过小，导致引用的长文档片段被截断。
- 现象：模型调用时提示缺少模型权限。原因：`AIPROXY_API_TOKEN`配置错误，未使用部署生成的有效验证令牌。

## 怎么确认配好了
- 发起一条包含长文本审批要求的测试查询，核对答复未出现关键内容截断，确认`maxContext`与`quoteMaxToken`配置适配当前数据长度。
- 发起包含多环节审批咨询的测试查询，核对模型自动触发对应工具调用，确认`toolChoice`配置符合场景需求。
- 提交测试请求后查看接口返回日志，核对`AIPROXY_API_TOKEN`与调用链路的身份验证信息无异常。
- 调整`temperature`参数后发起测试，核对答复的严谨性变化符合预期，确认参数配置适配业务需求。
