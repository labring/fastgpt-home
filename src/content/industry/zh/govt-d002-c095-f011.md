# 新能源开发的办事咨询与答复：表单与交互

## 这个品类的数据长什么样
新能源开发办事咨询与答复的数据主要来源于政务能源项目审批系统、现场踏勘记录、电网接入批复文件及用户提交的办事咨询工单。数据更新节奏随项目阶段变化：立项筹备阶段每周更新，审批阶段每日更新，办结后归档留存。文档结构分为办事事项、所需材料、办理流程、咨询回复四个模块，字段包含事项编码、办理时限（单位为工作日）、材料清单（含格式要求）、咨询渠道及项目专属的用地、环评相关字段。

## 这些特征在「表单与交互」这一环带来什么约束
新能源开发办事咨询的数据字段多且随事项动态变化，要求表单支持按用户选择的办事事项加载对应字段，避免固定表单的冗余展示。数据更新频率较高，需保证交互环节的知识库同步频率匹配业务节奏，防止返回过时的审批规则或材料要求。材料清单附带格式要求，需在交互中加入格式校验与提示，减少用户提交无效材料。不同项目的专属字段差异较大，需支持动态扩展表单项以适配风电、光伏等不同类型的新能源开发项目。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `userSelect` | 绑定新能源开发专属事项编码列表 | 覆盖风电、光伏等不同类型的办事事项，实现动态字段加载 |
| `formInput` | 限制输入长度为800-1200字符 | 匹配用户咨询内容的合理范围，避免过长内容影响处理效率 |
| 知识库同步周期 | 每日凌晨2点-4点执行 | 匹配审批阶段每日更新的数据节奏，避开业务高峰时段 |
| 材料格式校验 | 绑定预设的材料格式正则规则 | 对应数据中明确的材料格式要求，减少无效提交 |
| 单次咨询结果展示 | 展示前3条 | 符合办事咨询的信息密度需求，避免过多信息干扰用户 |

## 容易做错的三处
- 聊天窗口输出办事咨询问题时提示“没有选择知识库”，原因是未将新能源开发项目审批知识库绑定到当前交互场景的`userSelect`对应事项中。
- 代码运行节点中无法选择知识库引用的变量，原因是未开启表单与知识库的上下文联动配置，导致变量池未加载对应知识库内容。
- 提交表单后返回的咨询结果条数与预期不符，原因是未正确配置单次展示的结果条目数，或未关联对应事项的专属知识库数据范围。

## 怎么确认配好了
- 选择风电项目审批事项，检查表单是否自动加载对应用地、环评相关的材料字段。
- 触发知识库同步任务，查看后台日志是否在设定的凌晨时段完成数据更新。
- 输入不符合格式要求的材料信息，检查是否弹出对应的格式校验提示。
- 模拟用户咨询新能源项目审批的问题，确认返回的结果中包含专属的审批规则内容。
