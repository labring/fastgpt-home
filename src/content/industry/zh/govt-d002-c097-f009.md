# 核电运营的办事咨询与答复：模型接入与配置

## 这个品类的数据长什么样
核电运营办事咨询与答复的数据主要来自内部运维流程文档、值班咨询台账、应急响应手册与现场处置记录。数据更新节奏为日常咨询台账每日同步，标准流程手册每季度修订。单份文档多为结构化内容，包含咨询编号、发起部门、问题类型、处置时限、反馈结果等字段，部分现场记录包含操作步骤、设备编号与时间戳，单位涵盖小时、项、人次等。

## 这些特征在「模型接入与配置」这一环带来什么约束
结构化字段多的特征要求模型能准确识别字段名与对应取值，避免生成错误的字段映射。每日更新的咨询台账要求配置中支持高频增量同步，避免索引滞后影响最新咨询的答复。现场记录包含设备编号与精确时间戳，要求模型调用时能关联对应上下文，确保答复的准确性。单份文档篇幅较长，要求配置中合理划分上下文窗口，避免超出模型处理上限。国央企场景下的数据安全要求，也对模型调用的身份验证与数据传输提出了明确约束。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配核电运营文档的结构化内容长度，避免截断关键流程与字段信息 |
| `maxTokens` | 2000–3000 token | 匹配办事咨询答复的常规长度，确保覆盖完整处置步骤与参考依据 |
| `quoteMaxToken` | 1500 token | 限制引用的文档片段长度，避免引入无关内容干扰咨询答复 |
| `temperature` | 0.1–0.3 | 适配核电运营的严谨性要求，降低答复的随机性，确保流程描述准确 |
| `AIPROXY_API_ENDPOINT` | 按企业内网部署的代理地址填写 | 适配核电运营的数据安全要求，避免敏感数据外流 |
| `AIPROXY_API_TOKEN` | 绑定专属权限的密钥 | 确保只有授权节点可调用模型，符合国央企数据安全规范 |

## 容易做错的三处
- 现象为调用模型时返回接口不可用提示，无法正常更新咨询数据。原因是未使用最新的代理镜像部署服务，或代理端点配置未同步更新。
- 现象为生成的答复未严格遵循预设格式，仅通过提示词无法保证输出一致性。原因是未启用内置的结构化输出配置，依赖提示词的方式无法稳定约束输出格式。
- 现象为外部模型在FastGPT中调用被拒绝，但curl测试正常。原因是未配置正确的代理端点，或请求头中缺少必要的身份验证参数，导致调用链路存在拦截。

## 怎么确认配好了
本核对流程适用于FastGPT v4.17.0版本。
- 检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置值，确保与部署的代理服务参数一致，可通过基础curl测试验证连通性。
- 提交一条模拟的核电运维咨询问题，查看生成的答复是否包含准确的流程步骤与字段信息，核对上下文窗口是否未出现关键内容截断。
- 测试结构化输出功能，确认生成的答复是否符合预设的格式要求，无需依赖额外提示词即可生成规范结构。
- 模拟高频增量数据同步，查看索引更新是否正常，确保最新的咨询台账内容可被模型正常引用。
