# 民航机场的办事咨询与答复：HTTP 接口与外部系统

## 这个品类的数据长什么样
民航机场办事咨询的数据主要来自机场运营管理系统、航班动态平台、官方发布的问询知识库，以及线下问询柜台的历史交互记录。数据更新节奏区分两类：航班相关咨询数据实时同步，公告类咨询内容按官方发布节点更新。单条咨询文档包含咨询分类标签、关联业务节点（值机、安检、行李提取等）、标准答复文本、关联航班号或航站楼信息、最后更新时间戳，字段单位统一使用中文标准表述，如航班号为字母加数字组合，时效标注为分钟。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
航班相关数据的实时性要求，要求HTTP接口配置合理的超时时间，避免延迟影响用户咨询响应。多来源数据的同步需求，要求接口支持并行调用不同业务系统的数据源，同时适配不同更新频率的数据格式。关联航班号和航站楼的字段校验规则，要求接口请求参数必须包含分类标签或关联标识，否则无法匹配对应知识库内容。线下历史交互数据的批量拉取需求，要求接口支持分页参数，适配不同规模的问询数据同步。机场内网部署的场景限制，要求接口支持内网域名解析，避免公网访问的权限问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer ${机场内部API密钥}` | 机场内部业务接口通常采用Bearer令牌鉴权，保障接口访问安全 |
| 请求超时时间 | `30–60 秒` | 航班相关咨询的响应时效要求，避免过长延迟影响用户体验 |
| `variables` | 传入咨询分类、关联航站楼或航班号 | 民航咨询数据需绑定具体业务场景，精准匹配对应知识库内容 |
| 分页拉取上限 | `前 200 条` | 线下历史问询数据的单次同步规模，控制接口单次请求的负载 |
| `responseData` | 仅提取标准答复文本与关联标识 | 仅需核心咨询内容用于生成最终答复，减少不必要的数据传输 |
| 内网域名解析配置 | 使用机场内网DNS地址 | 部署在内网环境的FastGPT服务器无法访问公网，需通过内网域名调用业务接口 |

## 容易做错的三处
- 现象：接口返回304状态码。原因：未正确配置机场内网API的鉴权参数，导致缓存校验失败，无法获取最新咨询数据。
- 现象：数据库连接报错提示Access denied。原因：未将FastGPT服务器的内网IP加入机场数据库的白名单，导致权限校验不通过。
- 现象：调用接口后返回空的咨询内容。原因：未通过`variables`传入关联航站楼或航班号参数，无法匹配对应场景的知识库内容。

## 怎么确认配好了
- 调用配置好的HTTP接口，传入测试用的咨询分类与关联参数，检查返回的`responseData`是否包含符合民航场景的标准答复文本。
- 查看FastGPT v4.17.0的系统日志，确认`Authorization`鉴权参数已正确携带，无鉴权失败报错。
- 在测试环境中模拟用户咨询，触发接口调用，核对返回内容与机场官方知识库的标准答复是否一致。
- 在内网环境下测试接口的超时触发逻辑，确认请求在设定的超时时间内完成响应。
