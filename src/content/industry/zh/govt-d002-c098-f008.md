# 民航机场的办事咨询与答复：文档解析与分块

本文基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
民航机场办事咨询与答复相关数据主要来源于官方航站楼指引手册、季度航班排班表、临时航班调整公告、旅客服务须知等文档。数据更新节奏分为两类：固定周期更新的季度航班排班表、年度服务手册，以及实时更新的临时航班变动、临时管控通知。文档结构包含混合格式：带多个sheet的结构化Excel排班表、带标题层级的PDF服务指南、Word格式的办事流程说明。字段包含航班号、起降时间、航站楼编号、行李提取区编号、服务咨询电话等，单位涵盖分钟、航站楼编号、电话号码等多类型字段。

## 这些特征在「文档解析与分块」这一环带来什么约束
民航机场的办事咨询文档兼具结构化数据与非结构化文本的混合特征，且存在多sheet的Excel排班表、实时更新的临时通知等特殊数据形态。多sheet的Excel文件若仅解析默认sheet，会丢失大量跨分区的航班与地勤信息；实时更新的临时通知若分块过长，会导致检索时无法精准匹配最新的航班变动信息；混合格式文档若统一使用单一解析规则，会丢失结构化数据的列关联与非结构化文本的标题层级。此外，机场文档的单文件体积可能较大，需适配大文件上传与解析的时长限制。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 民航机场办事文档包含结构化航班数据与非结构化服务说明，该区间可平衡信息完整性与检索精度 |
| `chunkSplitter` | 按段落+标题拆分 | 机场文档有明确的服务流程章节与航班分区标题，按标题拆分可保留上下文关联 |
| `customPdfParse` | 开启文本层优先解析 | 机场PDF服务手册多为扫描件与文本混合，优先解析文本层可保留可检索内容 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 机场可能上传完整季度的航班排班Excel包，该上限可覆盖常规批量上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 多sheet的大型Excel解析耗时较长，该时长可避免超时中断 |
| `chunkSettingMode` | 手动配置 | 需针对不同文档类型调整分块规则，手动配置可适配机场文档的混合结构 |

## 容易做错的三处
- 现象：解析Excel文件后无法获取sheet页名称，解析结果仅包含默认sheet的内容。原因：未开启自定义解析配置或未指定多sheet识别规则。
- 现象：导入PPT或DOC文档后勾选PDF增强功能，无有效解析结果。原因：PDF增强功能仅适配PDF格式文档，非PDF文档需使用对应格式的解析模式。
- 现象：知识库导入Excel文件时仅识别两列数据，其余列内容丢失。原因：默认启用了CSV解析模式，该模式仅支持单列或两列结构化数据读取。

## 怎么确认配好了
- 上传单sheet的Excel航班表，检查解析后是否包含完整的多列数据与sheet名称。
- 上传非PDF格式的办事流程文档，确认未勾选PDF增强时可正常生成可检索的分块内容。
- 上传100MB以内的大型机场服务手册PDF，检查解析过程未触发超时提示。
- 查看分块后的文档片段，确认保留了原文档的标题层级与上下文关联。
