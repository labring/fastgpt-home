# 油田工程服务的办事咨询与答复：模型接入与配置

## 这个品类的数据长什么样
数据主要来自油田工程服务的作业记录、流程规范、现场反馈文档，以及办事窗口的历史咨询台账。更新节奏为单次项目完结后即时归档更新，或月度批量同步全量有效文档。单篇文档多为结构化与半结构化混合，包含作业编号、施工地点、压力/排量等带单位的技术参数、审批节点、咨询事项分类等字段，部分长文档包含多页施工步骤与合规要求。

## 这些特征在「模型接入与配置」这一环带来什么约束
油田工程服务的文档包含大量带单位的技术参数与结构化作业流程，要求模型在召回与生成时保留单位与字段完整性。多文档混合的结构要求配置时需区分技术参数类与办事流程类内容的召回权重。单次项目完结后即时更新的文档，要求知识库同步周期适配作业节奏，避免过时数据参与咨询答复。长文档占比高的特性，要求上下文配置需预留足够空间以覆盖完整作业环节信息，防止关键内容截断。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 油田工程文档多为长文本，需覆盖完整作业流程与参数信息，避免关键内容截断 |
| `temperature` | 0.1–0.3 | 办事咨询与技术答复需严谨准确，不宜生成偏离事实的内容 |
| `quoteMaxToken` | 2000–3000 字符 | 需保留带单位的技术参数与审批节点的完整引用内容 |
| `toolChoice` | auto | 需根据咨询内容自动选择是否调用知识库或工具，适配流程咨询与技术参数查询的不同场景 |
| `AIPROXY_API_ENDPOINT` | 部署节点的专属API地址 | 确保请求路由至指定模型服务，避免跨区域延迟 |
| `AIPROXY_API_TOKEN` | 绑定专属权限的令牌 | 限制访问范围，保障油田内部数据的安全性 |

## 容易做错的三处
- 现象：重复配置Qwen/Qwen3-Embedding-8B模型时，原有配置被覆盖，知识库索引失效。原因：FastGPT的模型配置机制默认以模型名称作为唯一标识，未提供额外标识区分同名称不同实例的配置。
- 现象：大模型调用知识库后，输出内容中包含“引用标记：［1］”字样。原因：配置时未关闭引用标记的自动生成逻辑，或未配置正确的输出格式过滤规则。
- 现象：导入油田工程文档构建知识库时，出现markdown格式解析异常。原因：导入文档中包含未转义的特殊字符，或分块配置未适配长文本的markdown结构，导致解析错误。

## 怎么确认配好了
- 发起一条包含油田技术参数的测试咨询，核对输出内容是否保留参数单位与完整引用信息。
- 查看FastGPT v4.17.0的模型调用日志，确认请求路由至配置的`AIPROXY_API_ENDPOINT`地址，令牌验证状态正常。
- 导入单篇长文档测试，检查上下文配置是否覆盖完整内容，未出现关键信息截断。
- 尝试重复添加同名模型配置，检查是否出现覆盖提示或允许保留多实例的选项，验证模型配置机制是否符合预期。
