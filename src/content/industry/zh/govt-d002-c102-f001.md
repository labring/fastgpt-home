# 炼化生产的办事咨询与答复：HTTP 接口与外部系统

## 这个品类的数据长什么样
炼化生产的办事咨询数据主要来源于装置工艺DCS台账、生产调度工单系统、安全巡检记录、设备运维日志四类系统。数据更新节奏存在差异：调度工单随事件实时生成，工艺参数每15分钟批量更新，巡检记录按每班频次提交，运维日志随设备异常事件触发更新。单条咨询数据的文档结构包含咨询类型、关联装置ID、时间戳、上报人、问题详情、处理进度六个核心字段，字段单位需符合炼化行业标准，如压力为MPa、温度为℃、流量为m³/h，工单编号统一采用LY-YYYYMMDD-XXXX的格式。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
数据来源分散在多个独立系统，要求HTTP接口支持对接多外部系统的鉴权与数据拉取，需通过`Authorization`参数完成统一鉴权。不同数据的更新节奏差异，要求接口同时适配实时轮询与批量同步两种调用模式。字段与单位的标准化要求，需在接口请求与响应环节完成字段映射与单位转换，避免因格式不匹配导致数据解析失败。炼化生产数据涉及生产安全与合规信息，接口调用需严格遵循权限管控规则，防止敏感数据泄露。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 请求头鉴权 | Bearer {炼化生产系统专属API密钥} | 符合炼化行业外部系统的鉴权标准，保障业务数据安全 |
| 变量映射 | `variables` 绑定关联装置ID与时间范围参数 | 匹配炼化办事咨询的业务字段规则，精准获取目标数据 |
| 响应数据过滤 | `responseData` 仅返回已完成处理的办事咨询条目 | 过滤无效信息，提升业务处理效率 |
| 超时设置 | 600 秒 | 适配炼化系统数据传输的延迟特性，避免接口调用中断 |
| 单位转换 | 统一转换为炼化行业标准单位（MPa、℃、m³/h） | 确保外部系统返回的参数可被正确解析 |
| 重试策略 | 失败后重试3次，间隔10秒 | 应对炼化网络波动或系统临时故障，保障调用稳定性 |

## 容易做错的三处
- 现象：调用接口返回401未授权错误，日志显示鉴权失败。原因：未正确配置`Authorization`参数，或使用了与炼化系统不匹配的API密钥。
- 现象：工作流中HTTP请求的body参数无法转为可用变量。原因：未在工作流配置中开启变量绑定，或未将body参数的键名与预设变量对应。
- 现象：接口返回的咨询数据字段缺失或单位不符。原因：未正确配置变量映射规则，未匹配炼化生产数据的字段与单位标准。

## 怎么确认配好了
- 调用测试接口，查看返回的鉴权状态码为200，确认请求头鉴权配置生效。
- 传入预设的关联装置ID与时间范围参数，查看返回数据的字段与炼化生产业务规则匹配。
- 模拟超时或异常请求场景，查看系统是否触发预设的重试策略。
- 查看工作流变量绑定日志，确认body参数已被正确解析为可调用的工作流变量。
