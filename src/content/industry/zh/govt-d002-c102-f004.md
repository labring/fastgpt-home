# 炼化生产的办事咨询与答复：工作流编排

## 这个品类的数据长什么样
炼化生产办事咨询相关数据主要来自装置实时运行日志、设备台账、工艺操作规程、安全巡检记录及内部办事审批档案。实时运行参数每10秒更新一次，台账与规程类文档每季度更新一次。单条数据包含设备编号、工艺参数、巡检时间、审批节点、咨询问题、答复内容等字段，压力单位为MPa，温度单位为℃，流量单位为m³/h，审批状态为固定枚举值。

## 这些特征在「工作流编排」这一环带来什么约束
基于FastGPT v4.17.0版本的工作流编排逻辑，需适配以下数据特征带来的约束：实时运行参数的高频更新要求工作流调用数据时需指定最新时间戳拉取，避免使用过期参数。字段的固定单位要求工作流内的参数校验规则需匹配MPa、℃、m³/h等专属单位，防止参数类型不匹配导致的调用失败。审批节点的枚举值约束工作流的条件分支节点需严格对应已定义的审批状态枚举，避免分支逻辑错误。多源数据聚合时需按设备编号关联不同数据源，防止数据错位。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 绑定实时运行数据的时间戳字段 | 实时数据更新频率为10秒，需确保每次调用使用最新参数 |
| `nodeId` | 绑定数据拉取节点的唯一标识 | 确保工作流调用指定数据源的正确节点，避免跨节点调用错误 |
| 全局变量引用 | 预设炼化工艺固定参数（如常压塔设计压力3.2MPa） | 固定参数无需实时更新，简化重复配置流程 |
| 节点超时设置 | 60秒 | 跨多数据源拉取炼化数据的平均耗时在30-50秒区间，按实测标定 |
| 参数校验规则 | 匹配MPa、℃、m³/h等单位 | 数据字段自带专属单位，需校验参数格式合法性 |
| 上下文长度 | 800–1200字符 | 办事咨询的问题与答复内容通常在千字以内，过长会增加模型调用负载 |

## 容易做错的三处
- 工作流调用接口返回`chat:LLM_model_response_empty`，现象是大模型节点返回空响应字段。原因是未配置重试机制，或超时设置过短导致数据拉取未完成就触发模型调用。
- 变量更新未生效，现象是工作流中`variables`绑定的参数未随实时数据更新。原因是未指定时间戳参数拉取最新数据，仍使用缓存的旧值。
- 全局变量使用错误，现象是工作流中引用的全局变量未匹配炼化工艺的固定单位。原因是全局变量未预设带单位的参数值，直接使用纯数值导致校验失败。

## 怎么确认配好了
- 调用测试接口，检查返回的`variables`参数是否包含最新的实时运行数据，核对时间戳是否与当前时间匹配。
- 触发工作流后查看节点日志，确认`nodeId`指向的数据源节点正确返回对应设备的工艺参数。
- 检查参数校验规则，确认所有炼化专属单位字段均已配置匹配的校验逻辑，无格式错误。
- 模拟大模型调用，确认响应为空时触发预设的重试流程，验证异常处理逻辑生效。
