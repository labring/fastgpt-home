# 炼化生产的办事咨询与答复：模型接入与配置

## 这些特征在「模型接入与配置」这一环带来什么约束
实时更新的工艺参数要求模型能快速响应短查询，需限制单次推理的上下文上限。长文本的操作规范与故障案例需要模型支持大上下文窗口，需调整`maxContext`与`maxTokens`参数。带明确单位的结构化工艺数据要求模型能准确识别单位关联，需配置参数适配结构化字段解析。半结构化的巡检日志需要模型能提取关键信息，需调整输出格式相关配置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配炼化生产长文本的操作规范与故障案例，避免上下文截断 |
| `maxTokens` | 2000–3000 token | 满足故障处置步骤、工艺参数解读的输出长度需求 |
| `quoteMaxToken` | 1500 token | 限制引用的文档片段长度，确保模型能聚焦关键工艺与故障信息 |
| `temperature` | 0.3–0.5 | 降低输出随机性，保证工艺参数、处置流程的表述准确一致 |
| `AIPROXY_API_ENDPOINT` | 按部署节点填写专属接口地址 | 适配算力服务器的部署环境，确保模型调用链路正常 |
| `AIPROXY_API_TOKEN` | 填写项目绑定的访问密钥 | 保证接口调用的身份验证有效，防止未授权访问 |

## 容易做错的三处
- 现象：检索后重排结果始终为false，测试环节显示正常但线上调用无有效重排结果。原因：未在模型接入配置中绑定正确的重排模型部署地址，或配置的`quoteMaxToken`参数与重排模型的输入长度要求不匹配。
- 现象：长文本的装置操作规程无法被内容提取组件正常解析，返回空字段。原因：未调整`maxContext`参数适配长文档长度，导致模型无法完整读取输入的文档片段。
- 现象：模型输出仅为文字描述，未生成工艺参数对比的饼图或柱状图。原因：未在提示词中明确指定可视化输出格式，且未配置支持图表生成的模型适配规则。

## 怎么确认配好了
- 发起包含结构化工艺参数的测试查询，核对模型输出是否准确识别参数单位与数值，确认`temperature`参数的取值符合预期。
- 导入单篇长文本的装置操作规程，测试模型是否能完整读取并提取关键步骤，确认`maxContext`与`maxTokens`参数的配置适配文档长度。
- 调用重排模型关联接口，发起检索后核对重排结果的排序逻辑是否符合预期，确认重排模型的绑定配置正确。
- 发起包含图表生成要求的测试查询，核对模型输出是否包含指定格式的可视化内容，确认提示词与模型适配规则的配置匹配。
