# 煤化工的办事咨询与答复：知识库检索与召回

## 这个品类的数据长什么样
煤化工办事咨询与答复的数据主要来自企业内部工艺规程、安全操作规范、政府审批办事指南、历史工单回复档案。数据更新节奏分两类：固定文档每季度或年度随政策、工艺迭代更新，实时工单数据随用户咨询同步新增。文档多为带章节结构的PDF或结构化表单，字段包含工艺参数（单位为MPa、℃、t/h）、审批流程节点、咨询分类标签与回复时效要求。

## 这些特征在「知识库检索与召回」这一环带来什么约束
煤化工办事咨询数据的多源混合、结构化参数与合规性要求，对检索召回带来多重约束。带章节的PDF与结构化表单要求检索时保留上下文关联，避免召回断章的工艺片段。带单位的工艺参数字段需要精准匹配实体与单位，防止参数混淆导致错误答复。实时工单与固定文档的更新节奏差异，要求区分增量同步与全量更新的触发逻辑，同时需校验召回文档的版本合规性，确保返回的是最新版审批与安全规范。

## 配置怎么定
以下配置适用于 FastGPT v4.17.0。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 煤化工工艺参数与合规文档对精度要求高，过低会引入无关内容，过高可能遗漏有效合规片段 |
| `limit` | 前8条 | 办事咨询的有效回复通常集中在少量相关片段，过多会超出上下文窗口限制 |
| `searchMode` | hybrid | 结合关键词匹配与语义检索，适配结构化参数与自然语言咨询的混合查询 |
| `usingReRank` | 开启 | 煤化工文档专业性强，重排可过滤低相关性的非专业片段，提升答复准确性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 办事咨询常出现缩写或行业术语，扩展查询可覆盖更多专业文档 |
| `collectionIds` | 按业务分组指定 | 煤化工需区分工艺、安全、审批三类知识库，避免跨品类召回无关内容 |

## 容易做错的三处
- 调用对话接口时未返回关联知识库ID，仅显示通用答复内容。原因：未通过`collectionIds`限定检索的知识库集合，系统未标记召回内容的来源标识，导致无法追溯具体引用的知识库。
- 上传扫描版PDF办事指南后，检索无法匹配到有效文本片段。原因：未启用OCR文本提取配置，仅解析了扫描图像的二进制数据，未生成可检索的文本块。
- 业务系统通过接口新增知识库后，前端检索无对应结果返回。原因：未等待知识库向量生成与同步完成即发起检索，或未在检索请求中指定新增知识库的`collectionIds`，导致检索范围未覆盖新增内容。

## 怎么确认配好了
- 发起测试查询，验证返回结果中包含预设的煤化工工艺参数与合规文档片段，确认检索范围符合`collectionIds`的配置。
- 查看检索日志，确认`similarity`与`limit`参数的实际生效值与配置一致，无异常截断或低相关性内容。
- 上传测试用的扫描版PDF，验证系统自动完成OCR识别并生成可检索的文本块，确认重排与扩展查询功能正常生效。
- 调用对话接口，检查返回结果中是否包含关联知识库的标识字段，确认来源追溯功能正常。
