# 煤化工的办事咨询与答复：表单与交互

## 这个品类的数据长什么样
煤化工办事咨询与答复的数据来源于国央企煤化工板块的内部办事台账、属地政务服务中心煤炭行业事项库。数据更新节奏为每季度同步一次政务事项变更。文档结构为结构化表格形式，包含事项编码、事项名称、办理层级、申请材料明细、法定办理时限、咨询联系方式等字段。其中办理时限单位为工作日，申请材料单位为份或纸质原件，部分材料需附带环评批复编号等行业专属标识。

## 这些特征在「表单与交互」这一环带来什么约束
数据的固定结构化字段要求表单需严格匹配预设项，不得随意新增非必要字段，避免与台账数据格式不兼容。按季度更新的特性要求表单的下拉选项不能实时调用动态接口，需定期批量同步数据源。专属字段与单位要求表单的时间选择组件需过滤法定节假日，仅允许选择工作日，上传控件需匹配煤化工审批材料的格式与命名规则。跨部门办事的咨询联系方式字段需与属地政务平台的官方号码保持一致，不得自定义。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 启用固定字段模式，预设事项编码、申请材料、办理时限3个核心字段 | 煤化工办事数据为固定结构化格式，匹配预设字段可保证数据与台账兼容 |
| `userSelect` | 预设10个高频办事选项，按属地与事项类型分类排序 | 煤化工企业办事集中在项目审批、安全备案等高频事项，分类排序提升查找效率 |
| 提交超时时间 | 600 秒 | 煤化工办事表单需上传多份大型审批文件，提交耗时较长 |
| 选项更新频率 | 每90天同步一次 | 办事数据按季度更新，定期同步保证选项准确性 |
| 文件上传限制 | 支持PDF、DOCX格式，单文件上限1000 MB | 煤化工审批材料多为大型图纸或报告文件，适配其文件规格 |

## 容易做错的三处
- 现象：嵌套到其他工作流时，`formInput`控件对话框始终显示。原因：未在嵌套配置中调整弹窗触发规则，沿用了独立工作流的默认弹窗显示逻辑。
- 现象：单选选项未匹配最新的煤化工办事事项。原因：未按季度更新`userSelect`的数据源，使用了过期的台账数据。
- 现象：上传煤化工审批图纸后提交失败。原因：未设置正确的文件格式与大小限制，上传文件超出了预设的单文件上限。

## 怎么确认配好了
- 打开FastGPT v4.17.0的表单编辑页面，检查`formInput`的预设字段是否包含煤化工办事所需的事项编码、申请材料等专属字段。
- 触发`userSelect`控件，查看选项是否按属地与事项类型分类排序。
- 以嵌套方式调用该表单，检查弹窗显示状态是否符合当前工作流的配置要求。
- 上传一份测试用的煤化工审批文件，检查上传与提交流程是否正常。
