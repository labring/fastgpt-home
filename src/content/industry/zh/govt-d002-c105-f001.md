# 煤炭运销的办事咨询与答复：HTTP 接口与外部系统

## 这个品类的数据长什么样
数据主要来自煤炭运销全流程的内部业务系统，包括运单管理、装卸调度、结算对账模块。更新节奏覆盖实时（运单生成、装卸进度）与定时（日度结算、周度运力统计）两类。单条数据文档结构包含运单编号、煤炭品类、发运地、目的地、实际发运重量、发运时间、经办人信息等字段，重量单位为吨，时间字段精确到分钟，运单编号为16位字符串。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
实时生成的运单与装卸进度数据要求接口响应延迟不超过5秒，否则无法支撑办事咨询的即时答复需求。多字段的业务数据需要接口请求体严格匹配预设字段，避免因字段缺失或格式错误导致数据解析失败。重量字段统一使用吨作为单位，接口传输时需校验单位一致性，防止出现公斤与吨的转换误差。敏感的结算数据需通过接口的`Authorization`参数做权限校验，仅允许授权的外部系统调用。批量拉取日度统计数据时，接口需支持按时间区间分页查询，适配数据更新的定时节奏。本文适配FastGPT v4.17.0版本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | 固定前缀为`Bearer `加业务系统分配的令牌，有效期180天 | 适配煤炭运销业务数据的敏感权限要求，避免未授权调用 |
| 超时时间 | 3–5秒 | 匹配实时运单数据的响应延迟约束，满足即时咨询需求 |
| `variables` | 绑定运单编号、发运时间区间等业务变量 | 支持动态传入用户查询的具体业务参数 |
| 批量查询上限 | 前20条数据 | 适配单次办事咨询的答复数据量限制，避免信息过载 |
| `responseData` | 仅返回运单状态、实际发运重量、目的地等核心字段 | 减少接口传输负载，加快答复速度 |
| 请求重试次数 | 2次 | 应对网络波动导致的接口调用失败，提升调用稳定性 |

## 容易做错的三处
- 现象：调用接口获取运单数据时返回`401 Unauthorized`状态码。原因：未正确配置`Authorization`参数，令牌格式错误或已过期。
- 现象：接口返回的`responseData`字段包含冗余信息，导致办事咨询答复出现无关内容。原因：未限制`responseData`返回的字段范围，包含了结算金额等非必要数据。
- 现象：通过接口上传的煤炭运单图片无法正常加载，官方测试界面的同图片可正常显示。原因：接口传输时未匹配官方的base64编码规则，或未正确处理图片的二进制格式转换。

## 怎么确认配好了
- 调用配置好的接口，传入预设的运单编号变量，检查返回的`responseData`是否包含预期的核心业务字段。
- 查看接口调用日志，确认`Authorization`参数已正确携带且格式符合要求。
- 上传测试用的煤炭运单图片至接口，在测试环境中验证图片能否正常加载显示。
- 模拟网络波动场景，检查接口是否按照设定的重试次数进行重试，未出现连续调用失败。
