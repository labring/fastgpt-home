# 煤电一体化的办事咨询与答复：模型接入与配置

## 这个品类的数据长什么样
煤电一体化的业务数据来自矿井生产管理系统、电力调度平台、煤炭购销台账、环保监测终端等内部业务系统。更新节奏分为三类：实时运行指标（如产煤量、发电负荷）秒级更新，静态台账（如矿井资质、设备档案）每日更新，购销与合规文档按需更新。文档以结构化字段为主，包含矿井编号、产煤量（单位：吨）、发电负荷（单位：兆瓦）、当日耗煤量（单位：吨）、环保排放指标（单位：毫克/立方米）等，单份月度调度报表的文本长度可达数万字符。

## 这些特征在「模型接入与配置」这一环带来什么约束
煤电一体化的数据特征对模型接入与配置带来多重约束。首先，数据包含秒级更新的实时运行指标与按需更新的合规文档，要求配置能适配不同更新频率的知识库切片，避免数据滞后影响咨询答复准确性。其次，字段包含专业业务单位，要求模型能准确识别单位与业务含义，需确保配置匹配业务场景的理解需求。第三，单份月度调度报表长度可达数万字符，容易超出模型默认上下文限制，需要合理调整相关参数。第四，数据涉及生产安全与合规，模型调用的API端点与密钥配置需符合国央企数据安全访问规范。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `AIPROXY_API_ENDPOINT` | 填写对应模型平台的官方代理端点 | 适配跨平台模型接入，符合国央企网络安全访问要求 |
| `AIPROXY_API_TOKEN` | 填写对应平台的有效访问密钥 | 保障模型调用的身份验证，符合数据安全规范 |
| `maxContext` | 8000–12000 字符 | 适配煤电一体化业务文档的平均长度，避免上下文溢出 |
| `maxTokens` | 4000–6000 | 限制单次回复的token数量，避免生成内容超出业务需求 |
| `quoteMaxToken` | 2000–3000 字符 | 限定引用知识库内容的总长度，确保上下文与回复的比例合理 |
| `toolChoice` | auto | 支持AI自动识别需要调用的工具，适配多业务场景的咨询需求 |
| `temperature` | 0.3–0.5 | 降低回复的随机性，确保业务答复的准确性与规范性 |

## 容易做错的三处
- 模型调用返回401状态码，或提示「无访问权限」。未正确配置`AIPROXY_API_TOKEN`，或密钥已过期失效。
- 对话中上传的煤电一体化业务文档无法被正确处理，出现上下文溢出报错。未根据业务文档的平均长度调整`maxContext`参数，参数取值过小。
- AI无法自动识别需要调用的工具，回复内容与业务需求不匹配。未将`toolChoice`设为auto，或配置了固定的工具调用模式。

## 怎么确认配好了
- 在FastGPT v4.17.0环境中，测试调用配置的模型，输入煤电一体化业务相关的咨询问题，检查返回结果是否包含正确的业务字段与单位。
- 上传一份典型的煤电一体化月度调度报表文档，验证文档切片与上下文加载是否正常，无溢出报错。
- 开启工具自动调用功能，输入需要调用工具的咨询问题，检查AI是否能自动匹配并调用对应工具。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置未出现格式错误。
