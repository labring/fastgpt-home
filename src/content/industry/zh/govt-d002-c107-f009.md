# 煤矿生产的办事咨询与答复：模型接入与配置

## 这个品类的数据长什么样
煤矿生产的办事咨询与答复数据，主要来源于内部调度台账、各科室发布的办事指南、安全规程配套的办事流程文档。数据更新无固定周期，新的办事流程出台、安全政策调整时会同步更新。单条数据包含咨询问题、官方答复、办理部门、办理时限、所需材料清单、咨询渠道等字段，其中办理时限以天为单位，材料清单以件为单位，文档多为结构化段落与表格混合格式。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散于多个内部业务系统，要求接入配置支持多数据源对接，避免数据孤岛。文档结构包含表格与段落混合内容，要求模型上下文参数适配混合格式的文本长度。数据更新无固定周期，要求增量更新配置可灵活调整触发时机。部分办事数据涉及生产安全敏感信息，要求接入配置需保障内网传输安全，限制公网暴露范围。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 煤矿办事咨询的上下文通常包含多个流程步骤与材料清单，需足够长度承载完整业务信息 |
| `maxTokens` | 2000–3000 token | 办事答复需清晰说明办理要求，该取值可平衡输出长度与信息密度 |
| `quoteMaxToken` | 3000–4000 token | 需引用足够的原始办事文档内容作为答复依据，保障信息准确性 |
| `temperature` | 0.3–0.5 | 办事答复需严谨准确，较低的温度参数可降低生成内容的随机性 |
| `AIPROXY_API_ENDPOINT` | 煤矿内部专属代理地址 | 保障敏感办事数据不出内网，符合信息安全要求 |
| `AIPROXY_API_TOKEN` | 分配的专属鉴权令牌 | 实现接入权限的精细化管控，避免未授权访问 |

## 容易做错的三处
- 现象：接入内部办事渠道时提示地址校验失败，原因是未配置公网可访问的回调地址，或未正确适配SSL证书校验规则。
- 现象：模型输出的办事答复遗漏关键办理材料，原因是`maxContext`参数取值过小，导致上下文内容被截断。
- 现象：自定义模型提供商无法在配置界面选中，原因是未在FastGPT v4.17.0中启用自定义模型权限，或未正确配置API端点与令牌。

## 怎么确认配好了
- 发起一条覆盖完整办事流程的测试咨询，核对模型返回的答复是否包含准确的办理部门、时限与材料清单，核对引用内容是否来自内部办事文档。
- 检查鉴权配置项`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，确认二者匹配当前部署的内部代理环境。
- 调整`maxContext`参数，测试长文本咨询场景，确认答复未出现关键内容截断。
- 输入非标准办事问题，验证模型是否返回符合规范的引导答复。
