# 电网企业的办事咨询与答复：向量模型与索引

## 这个品类的数据长什么样
电网企业办事咨询与答复的数据主要来源于官方办事指南、线下营业厅公告、客服工单记录、电力抢修台账、电价与收费调整通知等。数据更新节奏不一：办事指南随政策调整季度更新，客服工单实时生成，电价通知按月度发布。文档结构包含长文本（如电网改造实施方案）、结构化表格（如业务办理清单、电价表）、短文本FAQ。字段包含业务编号、办理时限、所需材料、联系电话、收费标准等，单位涉及元/千瓦时、工作日、小时等。

## 这些特征在「向量模型与索引」这一环带来什么约束
电网业务数据的多结构特征要求索引同时支持长文本分块与表格字段的多向量嵌入，否则无法准确检索到表格内的收费标准、办理流程等关键信息。实时工单的高频更新要求索引增量更新频率匹配业务数据的生成节奏，避免检索结果滞后。长文档的单块长度需适配向量模型的token限制，否则会出现嵌入失败。多字段的业务数据需确保索引覆盖核心业务字段，避免因字段遗漏导致检索精度下降。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配电网办事指南、工单等单条文本的平均长度，避免单块token超出模型限制 |
| 重叠长度 | 100–150 字符 | 保留跨块的关键业务衔接信息，如办理流程的前后步骤 |
| 相似度阈值 | 0.72–0.80 按实测标定 | 适配电网专业术语的语义相似度，避免误匹配或漏匹配业务条目 |
| 单次搜索上限 | 前 8 条 | 覆盖常见咨询的相关业务范围，避免结果过多干扰用户判断 |
| `defaultToken` | 4096 token | 适配电网长文档的向量嵌入长度要求 |
| `maxToken` | 8192 token | 匹配对话上下文的总长度限制，包含检索到的业务数据 |

## 容易做错的三处
- 配置自定义向量模型后测试直接报错，界面弹出“请求失败”提示，原因是未正确填写自定义请求地址的完整路径，或apikey未开通对应模型的访问权限。
- 刷新页面后提示“检测到没有可用的索引模型”，系统状态显示索引模型未就绪，原因是未保存向量模型的配置，或配置的模型接口超时未响应。
- 表格数据无法生成多向量，检索结果中未包含表格内的字段信息，原因是未开启知识库的多向量支持开关，或表格数据未按列拆分嵌入向量。

## 怎么确认配好了
- 进入FastGPT v4.17.0的知识库设置页面，查看向量模型配置项的状态，确认显示为“已启用”。
- 上传一条包含业务表格的电网文档，检查是否生成多向量条目，可通过向量日志查看嵌入结果。
- 发起一条测试咨询，检索结果中包含对应业务的字段信息，验证相似度匹配符合预期。
- 保存配置后刷新页面，确认不再弹出“检测到没有可用的索引模型”提示。
