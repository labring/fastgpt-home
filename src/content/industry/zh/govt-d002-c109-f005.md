# 电网企业的办事咨询与答复：工具调用与插件
本文适用于FastGPT v4.17.0版本

## 这个品类的数据长什么样
电网企业办事咨询与答复的数据主要来源于95598热线录音转写、线下营业厅咨询记录、线上营业厅工单、官方发布的电价政策与停电公告。数据更新节奏分为实时与定期两类：用户实时提交的咨询与工单随提交新增归档，政策类文档随官方发布更新。单条数据包含咨询时间、用户户号、诉求类型、答复内容、办理进度字段，其中户号为10位数字格式，时长字段以分钟为单位，金额字段以元为单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
电网咨询数据包含用户户号等敏感信息，工具调用时需校验用户权限，避免泄露非授权信息。诉求类型覆盖停电查询、电价核算、报装咨询等专业场景，需调用专属插件匹配电网内部接口。数据更新频率较高，插件需支持定期同步最新政策与工单数据，确保答复内容准确。部分咨询涉及长文本政策文件，工具调用时需适配长文档解析逻辑，避免信息截断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配电网咨询的多类型诉求，自动触发对应工具 |
| `functionCall` | 开启 | 支持调用电网专属的电价查询、停电公告查询插件 |
| 插件调用超时时间 | 15-20秒 | 电网内部接口调用可能存在一定延迟，预留足够响应时间 |
| 知识库召回条数 | 前6条 | 覆盖常见电网咨询场景，避免信息过载影响答复效率 |
| 上下文窗口大小 | 8000 token | 适配电网咨询的长上下文需求，支持用户提供的户号、历史诉求等信息 |

## 容易做错的三处
- 现象：调用OpenApi聊天接口时返回“tool_call_invalid”报错。原因：未正确设置`toolChoice`参数为允许的取值，导致工具调用格式不符合要求。
- 现象：输入十几个字的简单问题时，回答一次性输出，未启用流式返回。原因：未在界面配置中开启流式输出选项，或上下文窗口设置超出当前版本支持范围。
- 现象：尝试替换内置文档解析工具后，无法解析电网的PDF政策文件。原因：未在配置项中指定新工具的适配文档类型，导致电网专属长文档解析失败。

## 怎么确认配好了
- 发起包含电网专业诉求的测试提问，观察是否自动触发对应工具调用。
- 查看工具调用日志，确认`functionCall`参数被正确识别并执行。
- 调用OpenApi聊天接口，检查返回结果中是否包含工具调用相关字段。
- 测试输入短文本提问，确认返回结果为分段流式输出。
