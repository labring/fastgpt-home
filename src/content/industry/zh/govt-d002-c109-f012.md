# 电网企业的办事咨询与答复：部署与升级

## 这个品类的数据长什么样
电网企业办事咨询与答复的数据主要来源于95598热线转写文本、线下办事窗口的咨询台账、用电业务工单系统的记录。数据按日更新，每日生成新的咨询条目。单条数据包含咨询内容、用户身份类型（居民/企业）、业务分类（报装、报修、缴费等）、所属供电区域、咨询发起时间、历史办理进度等字段，部分条目附带用户上传的用电账单、设备照片等非结构化附件。数据结构兼顾结构化元数据与非结构化文本，覆盖从用户发起咨询到办结答复的全流程信息。

## 这些特征在「部署与升级」这一环带来什么约束
多源异构的数据来源要求部署时支持多格式数据接入，需适配电网内部已有的工单系统、热线转写工具的接口规范。日更的更新节奏要求知识库的向量同步周期需匹配每日数据刷新的节奏，避免数据滞后。丰富的元数据字段要求知识库配置时需映射对应业务字段，保障检索时可按供电区域、业务类型精准过滤。内网部署的普遍需求要求所有配置需适配内网网络环境，避免公网访问带来的安全风险与延迟问题。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30` | 电网咨询数据的日并发请求量稳定，连接池需覆盖日常客服咨询与知识库检索的并发需求 |
| `MONGODB_URI` | `mongodb://[内网数据库IP]:27017/fastgpt?authSource=admin` | 电网业务数据存储在内网MongoDB，需指定内网地址与认证源，保障数据访问安全 |
| `REDIS_URL` | `redis://:[自定义密码]@[内网Redis地址]:6379/0` | 高频会话缓存与检索结果缓存需内网Redis支撑，避免公网延迟影响用户体验 |
| `STORAGE_S3_ENDPOINT` | `http://[内网对象存储IP]:9000` | 电网咨询的附件文件需存储在内网对象存储，符合数据安全合规要求 |
| `FE_DOMAIN` | `https://[电网内网服务域名]` | 对接电网内部办公系统的域名，避免跨域配置导致的界面加载异常 |

## 容易做错的三处
- 现象：Docker打包部署后启动失败，日志提示数据库连接超时。原因：未将`MONGODB_URI`配置为电网内网的数据库地址，误使用公网地址或未配置内网访问权限。
- 现象：调用http编排节点后，对话界面未显示该节点的输出内容。原因：未开启对话上下文的输出透传配置，或编排节点的返回字段未匹配FastGPT的标准输出格式。
- 现象：调用内网部署的模型服务时，FastGPT报错连接超时或格式不兼容。原因：未将`FE_DOMAIN`配置为内网域名，或未将base64格式的图片识别输入转换为符合模型要求的image_url格式。

## 怎么确认配好了
- 登录FastGPT后台的系统状态面板，查看数据库连接模块，确认`MONGODB_URI`与`REDIS_URL`对应的连接状态为正常。
- 发起一条模拟电网用电咨询的测试对话，发起后查看对话界面，确认http编排节点的返回内容正常展示在对话流中。
- 在内网环境下调用已配置的模型服务接口，确认可以正常获取模型响应，无连接超时或格式错误提示。
- 上传一张模拟的用电业务附件，确认可以通过FastGPT的文件存储模块正常预览与下载，无权限报错。
