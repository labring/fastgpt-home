# 矿山采选的办事咨询与答复：表单与交互

## 这个品类的数据长什么样
矿山采选的业务数据主要来自井下开采台账、选矿车间流程参数、设备运维日志、安全巡检记录。数据更新节奏分实时（如井下通风压力、设备运行状态）、每日（生产班产量、耗材消耗量）、每周（安全排查汇总、选矿回收率统计）三类。单份文档通常包含设备编号、开采深度、选矿回收率、隐患等级、巡检时段等字段，单位涉及米、吨、小时、百分比等，部分涉密生产数据需做脱敏处理。

## 这些特征在「表单与交互」这一环带来什么约束
实时类数据字段要求表单支持实时接口同步，避免手动输入导致的参数偏差。涉密字段需在表单中配置权限校验规则，仅对应岗位账号可编辑或查看。多单位混合的字段需添加单位提示与自动转换逻辑，防止输入单位不统一引发的格式错误。业务场景拆分的表单模块需按采矿、选矿、安全三类划分，避免单页字段过多导致交互卡顿。专业术语字段需预设可选值，减少非规范输入。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 表单分块 | 按采矿、选矿、安全三类拆分 | 匹配矿山采选的业务场景划分，减少单页交互复杂度 |
| `formInput` 输入校验规则 | 预设专业术语可选值+单位提示 | 适配矿山采选的专业字段与单位规范 |
| `userSelect` 权限配置 | 按岗位划分编辑权限，涉密字段仅开放给安全岗 | 符合矿山数据的安全管控要求 |
| 实时数据同步间隔 | 30–60 秒 | 匹配井下压力、通风量等实时参数的更新节奏 |
| 表单提交防抖时长 | 1000 毫秒 | 避免重复提交生产上报表单 |
| 字段默认值更新逻辑 | 按数据类型匹配更新频率 | 对应实时/每日/每周的数据更新节奏 |

## 容易做错的三处
- 现象：表单提交后出现「字段格式不匹配」报错，查看日志显示单位未被识别。原因：未配置多单位自动转换逻辑，导致输入的吨与千克混合后无法匹配后台字段要求。
- 现象：本地部署后表单页面在加载10个以上专业字段时出现卡顿，输入文字延迟明显。原因：未按业务场景拆分表单模块，单页加载的字段与关联数据过多。
- 现象：涉密字段被非授权账号编辑后提交，后台出现数据越权访问日志。原因：未配置`userSelect`权限校验规则，或权限划分未匹配岗位权责。

## 怎么确认配好了
- 切换不同岗位账号，检查对应字段的编辑权限是否符合预设规则。
- 输入带有不同单位的专业字段内容，查看是否弹出单位提示或自动完成转换。
- 模拟提交10个以上字段的表单，观察页面加载与输入响应速度是否符合预期。
- 触发实时数据拉取，查看表单字段是否按设定节奏更新为最新值。
