# 通信工程建设的办事咨询与答复：知识库检索与召回

## 这个品类的数据长什么样
通信工程建设办事咨询与答复的数据主要来源于行业施工规范、验收标准、报建审批流程文档、运维手册及线下办事窗口的历史咨询记录。行业规范每1-2年同步更新，历史咨询记录实时入库。文档结构包含事项编码、办理流程、所需材料、审批时限、收费标准等字段，部分为结构化表格，历史咨询记录为非结构化问答文本，单位涵盖工作日、份、元、平方米等工程相关计量标准。

## 这些特征在「知识库检索与召回」这一环带来什么约束
专业术语密集的文档要求检索需兼顾语义匹配与精确匹配，避免因术语差异导致召回失败。结构化流程文档与非结构化历史记录混合的数据源，要求检索模式需同时支持全文检索与语义检索，覆盖不同类型的咨询问题。数据更新频率较低但单次文档篇幅较长，要求分块时需保留流程的完整性，避免割裂步骤逻辑。历史咨询记录的实时同步要求检索服务具备低延迟拉取能力，保障最新咨询数据的可用性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.85 | 通信工程专业术语多，该区间可过滤无关结果，保留有效语义匹配内容 |
| `limit` | 前8条 | 办事咨询需覆盖常见流程与特殊场景，过多结果会干扰用户判断 |
| `searchMode` | 混合检索 | 适配单份文档最长可达2000字符的内容，覆盖结构化与非结构化数据源 |
| `usingReRank` | 开启 | 专业术语易导致语义相近结果混杂，重排可提升结果相关性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 办事咨询常使用简称，扩展查询可匹配全称规范术语 |
| `collectionIds` | 绑定通信工程建设事项知识库集合 | 精准匹配本品类专属数据，避免召回无关领域内容 |

本文基于FastGPT v4.17.0版本配置规范。

## 容易做错的三处
- 现象为检索时返回`Connection error`报错，原因为未配置正确的知识库存储路径或远端服务访问权限，导致无法正常拉取通信工程建设的专属文档。
- 现象为检索结果条数远低于预期，原因为`similarity`取值设置过高，过滤掉了包含专业术语的有效匹配结果。
- 现象为输出内容未标注知识库来源，原因为未开启检索结果溯源配置，或未绑定专属的`collectionIds`集合。

## 怎么确认配好了
- 上传1份通信工程建设的报建流程文档，发起包含“基站报建”“光缆熔接”等专业术语的咨询，核对检索结果是否包含该文档的相关内容。
- 查看FastGPT后台的检索日志，确认`searchMode`、`usingReRank`等配置参数与预设值一致。
- 发起测试查询，核对输出结果是否附带知识库来源标识，确认溯源功能正常。
- 调整`similarity`的取值范围，观察检索结果的数量变化，验证配置生效。
