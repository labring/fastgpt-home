# 通信工程建设的办事咨询与答复：表单与交互

## 这个品类的数据长什么样
通信工程建设办事咨询的数据来源于项目报建申请、现场勘查记录、审批流转工单及用户咨询留言。数据更新随项目推进实时同步，单条咨询工单的文档结构包含项目编号、建设地点、施工段范围、申请事项类型、提交材料清单等字段，字段单位多为千米、平方米、项等标准化工程类单位，文档长度跨度较大，从数百字符的简单咨询到数千字符的详细申请材料不等。

## 这些特征在「表单与交互」这一环带来什么约束
通信工程建设办事咨询的数据跨度大、字段单位多样且随项目动态更新，要求表单支持动态加载字段与单位选项，避免固定模板无法适配不同施工阶段的咨询需求。项目编号等唯一标识字段需要实时校验唯一性，防止重复提交的工单混入流程。不同咨询类型的必填项差异明显，如报建咨询需上传施工图纸，运维咨询需提供故障点位坐标，交互环节需根据用户选择的咨询类型自动切换必填字段与输入格式。同时，实时同步的数据要求表单提交后即时触发数据校验与同步，避免出现数据滞后的交互异常。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 表单输入组件 | 为不同咨询场景切换`formInput`的文本、坐标、文件上传模式 | 适配工程咨询中文字描述、点位标注、材料上传等多样输入需求 |
| 用户选择组件 | 预设报建、现场勘查、验收、运维等`userSelect`可选值 | 覆盖通信工程建设的常见咨询分类，统一交互逻辑 |
| 动态必填项配置 | 绑定咨询类型自动切换必填字段 | 匹配不同咨询场景的材料提交要求，减少无效输入 |
| 单字段输入上限 | 800–1200字符 | 适配工程咨询文档的常规长度范围 |
| 交互超时阈值 | 600秒 | 匹配工程咨询的审批流转常规时长 |
| 文件上传限制 | 单文件上限100 MB | 适配工程图纸、勘查报告等文件的常规大小 |

## 容易做错的三处
- 现象为通过iframe嵌入应用后，点击外部文本触发弹窗并将文本带入输入框时，发送按钮呈灰色不可点击状态。原因是未配置`formInput`组件的联动触发逻辑，导致输入框内容未被正确识别为有效输入。
- 现象为批量上传工程咨询语料时，前十几条处理正常，后续条目无响应或报错。原因是未设置动态字段的批量校验规则，导致长文档或多字段的批量数据无法正常解析。
- 现象为用户输入的工程类专业术语无法被正确识别，返回不匹配的答复内容。原因是未通过`userSelect`组件预设标准化咨询分类，导致模型无法匹配预设的知识库条目。

## 怎么确认配好了
- 切换不同的咨询分类选项，核对表单的必填字段与输入格式是否随选择自动调整。
- 上传不同类型的工程相关文件，确认上传组件的校验逻辑正常生效。
- 在iframe嵌入的应用场景中，通过外部触发将文本带入输入框，确认输入框状态可被正确识别。
- 输入不同长度的测试文本，确认系统会触发对应配置的长度校验提示。
