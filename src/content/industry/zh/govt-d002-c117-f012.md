# 通信铁塔与基础设施的办事咨询与答复：部署与升级

## 这个品类的数据长什么样
通信铁塔与基础设施的业务数据来源于运维工单、基站巡检报告、用户咨询记录与基站运行日志。数据更新节奏分为三类：运维工单实时生成，巡检报告按每日或每周更新，基站运行日志按分钟级推送。文档结构包含工单编号、基站编码、问题类型、故障等级、处理进度、用户联系方式、故障描述、现场照片附件等字段。基站编码为11位数字字符串，故障等级分为三级，时间字段采用UTC+8时区格式，附件支持最大1000 MB的图片与文档文件。

## 这些特征在「部署与升级」这一环带来什么约束
数据的实时性要求部署时需配置高并发的数据库连接池，避免多基站并发咨询导致连接耗尽。附件体积较大的特征要求存储配置需支持大文件上传与下载，需匹配专用的云存储端点。固定字段格式要求升级时需保留原有数据结构的兼容性，避免因字段不匹配导致工单与巡检数据导入失败。实时日志的高频推送要求缓存配置需及时更新会话与状态数据，避免出现咨询延迟或数据不一致的情况。升级环节需采用灰度发布策略，确保服务中断不会影响核心的基站运维咨询业务。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `DB_MAX_LINK` | `120–180` | 支撑多基站并发咨询与数据查询，避免连接耗尽 |
| `MONGODB_URI` | `mongodb://[账号]:[密码]@[主机]:27017/comm_tower` | 存储专属的运维工单与巡检数据，指定专用数据库名 |
| `REDIS_URL` | `redis://[账号]:[密码]@[主机]:6379/1` | 缓存实时咨询会话与基站状态，过期时间设为300秒 |
| `STORAGE_S3_ENDPOINT` | `https://s3-[区域].cloudprovider.com` | 存储基站巡检照片与运维文档，匹配云存储服务商的访问端点 |
| `FILE_TOKEN_KEY` | `32位随机十六进制字符串` | 加密附件下载链接，防止未授权访问 |
| `ROOT_KEY` | `符合企业安全规范的强密钥` | 管理系统最高权限，保障配置与数据的安全访问 |

## 容易做错的三处
- 现象：新部署系统无法发起对话，控制台提示密钥验证失败。原因：未正确配置`ROOT_KEY`或`FILE_TOKEN_KEY`，导致会话身份校验环节出错，无法建立有效咨询链路。
- 现象：执行docker run --gpus all -itd -p 7231:7231部署marker_images:v0.1时出现容器启动失败。原因：未在宿主机正确安装GPU驱动依赖，或容器权限未开放GPU访问，无法调用图像解析算力处理基站现场照片。
- 现象：升级至FastGPT v4.17.0后，通过URL导入基站运维文档时后台日志提示cannot fetch internal url。原因：未配置`FE_DOMAIN`为内部网络可访问的域名，系统拦截了非信任来源的URL请求，导致文档抓取失败。

## 怎么确认配好了
- 执行`docker ps`命令，查看marker_images容器状态为Up，无异常退出记录。
- 登录FastGPT后台，输入测试密钥验证`ROOT_KEY`配置，无权限报错或会话中断问题。
- 上传一张基站巡检照片，验证附件可正常存储与下载，确认`STORAGE_S3_ENDPOINT`配置生效。
- 发起一条模拟的基站咨询对话，验证会话链路正常，无连接超时或密钥错误提示。
