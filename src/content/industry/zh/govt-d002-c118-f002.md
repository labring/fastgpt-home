# 金属材料加工的办事咨询与答复：向量模型与索引

## 这个品类的数据长什么样
金属材料加工的办事咨询与答复数据，主要来源于企业内部的工艺标准手册、质检报告、办事流程指南、现场巡检记录及历史咨询话术。数据更新节奏分为两类：通用工艺标准按季度或年度更新，日常咨询话术与巡检记录实时同步。文档结构包含专有牌号、物理性能参数、办理流程节点、责任部门等字段，单位涵盖MPa、HRC、工作日等专业计量标识，单篇文档长度从数十字符的咨询条目到数千字符的完整工艺规范不等。

## 这些特征在「向量模型与索引」这一环带来什么约束
金属材料加工的专业术语多、参数字段多且带单位，要求向量模型具备专业领域语义编码能力，避免对牌号、标准号等关键信息的编码失真。文档长度差异大，既有数十字符的客户咨询话术，又有数千字符的完整工艺规范，需灵活适配分块规则，避免破坏专业内容的完整性。数据更新兼具实时与定期属性，需支持增量索引与全量索引的切换配置，适配巡检记录的实时同步与工艺标准的定期更新。多字段的参数特征要求向量索引支持字段权重配置，优先匹配工艺参数与咨询关键词的关联度。

## 配置怎么定
本文基于FastGPT v4.17.0版本展开说明，配置时需注意`maxToken`与所选embedding模型的最大输入长度匹配。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配金属材料加工文档既有短咨询条目又有长工艺标准的长度特征，避免分块破坏专业术语完整性 |
| 重叠长度 | 100–200 字符 | 保留跨分块的工艺参数上下文，避免分块后断裂的牌号、标准号关联失效 |
| 相似度阈值 | 0.72–0.80 | 匹配金属材料专业术语的语义相似度区间，过滤低相关性的非专业咨询内容 |
| 单次搜索上限 | 前 8 条 | 覆盖常见办事咨询的多场景结果需求，避免过多冗余结果干扰答复 |
| `maxToken` | 8192 | 适配Qwen3-Embedding-8B模型的最大输入长度限制，避免超长文档截断丢失关键信息 |
| `defaultToken` | 1024 | 适配常见咨询话术的输入长度，平衡编码效率与内容完整性 |

## 容易做错的三处
- 现象：配置Qwen3-Embedding-8B后再次添加同名模型导致原有配置被覆盖。原因：FastGPT平台默认仅允许单个embedding模型唯一激活配置，未提前规划模型切换流程导致配置丢失。
- 现象：本地部署M3E模型构建知识库后，返回结果条数与公网版存在差异。原因：本地部署时未正确匹配公网版的相似度阈值与搜索上限参数，导致召回规则不一致。
- 现象：上传长工艺标准文档后，分块内容出现工艺参数断裂。原因：未根据文档长度调整分块参数，将长文档强制按固定短长度分块，导致关键牌号、性能参数被拆分到不同分块中。

## 怎么确认配好了
- 上传单篇金属材料工艺标准文档，检查FastGPT分块预览界面是否保留完整的专有牌号、标准号等专业内容。
- 发起包含专业术语的咨询，查看检索结果的相似度得分是否落在预设的阈值区间内。
- 尝试添加Qwen3-Embedding-8B与M3E两个模型，确认平台不会自动覆盖已有激活配置。
- 测试本地部署的M3E模型，检查向量检索的响应时间是否符合业务场景需求。
