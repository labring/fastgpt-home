# 金属材料加工的办事咨询与答复：文档解析与分块

本文适配FastGPT v4.17.0版本，以下为金属材料加工领域办事咨询与答复场景下的文档解析与分块配置指南。

## 这个品类的数据长什么样
金属材料加工领域的办事咨询与答复数据，主要来源于企业内部工艺作业指导书、金属材料检验报告、办事指南及归档的客户咨询答复记录。数据随工艺迭代、标准改版或业务新增咨询同步更新，文档多包含结构化表格（如成分占比表、力学性能参数表）、长段落工艺说明与标准化办事流程，字段含材料牌号、力学性能指标、办事所需材料清单等，单位多为MPa、%、mm等专业计量标准。

## 这些特征在「文档解析与分块」这一环带来什么约束
金属材料加工的文档含大量结构化表格与专业参数，解析环节需完整保留表格内的字段对应关系，避免参数拆分后无法关联对应材料牌号。长段落工艺说明与连贯的办事流程要求分块时保留上下文关联，防止截断关键操作步骤或咨询答复的完整逻辑。部分文档体积较大，需支持大文件解析，避免因文件大小限制无法上传完整业务资料，同时适配专业术语与标准化参数格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配金属材料文档的专业参数密度，保留单条工艺或检验数据的完整性，避免截断关键指标 |
| `chunkSplitter` | 按段落+表格分隔 | 匹配文档的结构化特征，保留表格与对应说明的上下文关联，防止表格内容脱离说明文本 |
| `customPdfParse` | 开启表格识别模式 | 适配文档中常见的成分表、性能参数表，避免解析后表格内容丢失或错乱 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 支持上传完整的大型工艺手册或年度检验报告，满足全量业务文档的解析需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 覆盖大型金属材料文档的完整解析流程，避免因超时中断解析任务 |
| `chunkSettingMode` | 手动配置 | 针对专业领域文档的特殊结构，手动调整参数比自动模式更适配业务场景 |

## 容易做错的三处
- 现象：上传含成分表的PDF文档后，解析结果中表格字段为空或仅显示部分行。原因：未开启`customPdfParse`的表格识别模式，导致结构化表格无法被正确提取。
- 现象：本地部署版本上传文件后，解析节点无进度更新且无报错日志。原因：`PARSE_FILE_TIMEOUT_SECONDS`设置过短，大型工艺文档解析未完成即被强制终止。
- 现象：分块后同一材料牌号的力学性能参数被拆分到不同块中。原因：`chunkSize`设置过小，截断了包含完整参数组的连贯段落。

## 怎么确认配好了
- 上传一份包含金属材料成分表与工艺说明的测试文档，检查解析结果是否完整保留表格的所有行与字段信息。
- 查看系统解析日志，确认`PARSE_FILE_TIMEOUT_SECONDS`未触发超时报错，解析流程正常完成。
- 随机抽取一段长文档的分块结果，检查是否未截断关键的工艺参数与对应说明文本。
- 上传体积接近1000 MB的测试文档，确认系统未触发文件大小限制报错。
