# 金属材料加工的办事咨询与答复：知识库检索与召回

## 这个品类的数据长什么样
金属材料加工的业务数据主要来自行业通用标准手册、企业内部生产工艺卡、质检报告、金属牌号性能数据库。数据来源包括国家钢铁有色行业标准、企业研发与生产记录，更新节奏随行业标准修订、企业工艺调整不定期触发。文档结构多按金属牌号分类，包含成分占比、力学性能、热加工温度、切削参数、缺陷修复方案等字段，单位涉及MPa、mm、℃、%等专业工业单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
金属材料加工的专业术语密集、参数精度要求高，且数据字段多为定量指标，语义检索需精准匹配成分、工艺等专业表述。多牌号分类的文档结构要求检索需按牌号维度过滤召回结果，避免跨牌号参数混淆。定量字段的单位一致性要求检索时需自动关联单位信息，防止出现单位不匹配的错误召回。同时，生产现场的咨询多为实时工艺调整类问题，需保证检索响应速度匹配现场决策节奏，避免过长等待影响业务推进。

## 配置怎么定
以下配置适配FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配金属材料加工的专业术语精度要求，过滤低相关的非牌号类结果 |
| `limit` | 前10条 | 覆盖常见工艺问题的多维度参数需求，同时避免结果过多超出上下文长度 |
| `usingReRank` | 开启 | 对初步召回的结果按工艺相关性二次排序，修正单一语义相似度的偏差 |
| `searchMode` | 语义检索 | 适配专业术语的语义匹配需求，替代关键词检索的生硬匹配问题 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展工艺类问题的同义词，比如将“淬火”扩展为“热处理淬火工艺”，覆盖专业表述变体 |
| `collectionIds` | 指定对应金属材料加工知识库的集合ID | 限定检索范围，避免混入其他品类的文档数据 |

## 容易做错的三处
- 界面显示语义检索得分高于0.9但结果包含无关的非金属材料参数。原因是未配置`collectionIds`限定检索集合，导致召回了其他品类的文档数据。
- 开启重排模型后，最终输入大模型的结果仅保留1条。原因是错误设置了重排后的结果截断规则，未保留足够的多维度参考参数。
- 单次问题回答等待超过15秒。原因是未优化检索的批量召回数量，且未开启数据集的向量索引缓存，导致每次检索都重新计算向量相似度。

## 怎么确认配好了
- 提交一个包含具体金属牌号和工艺参数的咨询问题，检查召回结果是否仅包含金属材料加工品类的文档数据。
- 查看检索结果的相似度得分分布，确认得分区间符合配置的`similarity`阈值要求。
- 测试3次以上重复提交相同问题，确认响应时间稳定在合理区间内。
- 开启重排功能后，检查排序后的结果是否优先匹配咨询的核心工艺需求。
