# 钢铁冶炼的办事咨询与答复：模型接入与配置

本配置指南适用于FastGPT v4.17.0版本。

## 这个品类的数据长什么样
钢铁冶炼办事咨询与答复的数据源主要包括内部工艺台账、设备运维记录、政务办事咨询工单、冶炼标准规范文档。数据更新节奏：工艺标准文档按季度更新，运维记录与咨询工单实时生成。文档结构分为两类，结构化工单包含咨询ID、设备型号、冶炼环节、问题描述、处理结果等字段，非结构化工艺文档按炼铁、炼钢、轧钢等环节分章节，字段包含温度、压力、处理时长等专业单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
结构化工单的固定字段要求模型接入时需支持指定字段的精准提取，避免通用分块导致的信息丢失；非结构化工艺文档篇幅较长，需适配更长的上下文窗口以完整加载相关内容。实时生成的咨询工单要求模型响应延迟匹配业务处理时效，不能出现过长等待。专业单位与术语的特殊性，要求模型配置需适配领域词汇的识别与解析，避免生成错误的参数解读。同时多模态咨询场景下，需支持设备故障图片、工艺图纸的识别，对`vision`配置提出明确要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配钢铁冶炼单篇工艺文档与多工单拼接后的总长度需求 |
| `maxTokens` | 2000–3000 token | 满足复杂工艺问题的完整答复输出长度 |
| `vision` | 开启 | 适配设备故障图片、工艺图纸的咨询识别场景 |
| `temperature` | 0.3–0.5 | 保证专业答复的准确性，降低随意生成的概率 |
| `AIPROXY_API_ENDPOINT` | 填写VLLM部署的本地接口完整地址 | 对接本地部署的大模型服务 |
| `AIPROXY_API_TOKEN` | 填写部署时生成的访问密钥 | 完成本地模型的身份验证 |

## 容易做错的三处
- 开启`vision`配置后，上传设备图片咨询时返回无法识别图片内容。原因：仅在全局配置中开启`vision`参数，未在AI对话节点同步开启图片识别开关。
- 连接VLLM部署的Qwen3-Embedding-8B模型时返回连接报错。原因：未正确填写`AIPROXY_API_ENDPOINT`的端口路径，或未配置对应模型的接口认证参数。
- 配置`maxTokens`取值过高时，模型响应超时。原因：未匹配本地部署模型的最大输出token限制，超出硬件承载能力。

## 怎么确认配好了
- 提交包含冶炼工艺参数的测试咨询，核对答复内容是否准确匹配文档中的专业单位与数值。
- 上传设备故障图片并发起咨询，核对模型是否返回与图片相关的分析内容。
- 查看接口调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的请求返回状态码为200。
- 调整`temperature`参数后发起多次同类咨询，核对答复内容的一致性是否符合预期。
