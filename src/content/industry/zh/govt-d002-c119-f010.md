# 钢铁冶炼的办事咨询与答复：知识库检索与召回

## 这个品类的数据长什么样
钢铁冶炼的办事咨询数据主要来源于生产台账、工艺规程、质检报告、设备运维记录与安全操作规范。数据更新节奏分为三类：设备运行数据实时同步，生产日报每日更新，月度工艺总结按月归档。文档包含结构化字段如炉号、冶炼批次、钢种牌号，以及非结构化的工艺步骤、故障排查流程，常用单位包含摄氏度、小时、吨等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
结构化字段多且关联紧密，要求检索时需结合元数据进行精准过滤，避免无关结果混入。实时更新的设备数据要求召回链路具备较短的延迟，适配办事咨询的即时性需求。文档存在明确的层级逻辑，如工艺规程的章节从属关系，直接分段会丢失层级关联，影响检索的语义匹配准确性。部分文档包含专业术语与单位，需确保检索时匹配对应字段的单位格式，避免歧义。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.85 | 匹配钢铁冶炼专业术语的语义相似度区间，兼顾召回覆盖率与精准度，按实测标定 |
| `limit` | 前10条 | 匹配办事咨询的单次查询结果展示上限，避免结果过多超出上下文窗口 |
| `searchMode` | 全文检索+元数据过滤 | 适配结构化字段与非结构化文本混合的文档结构，优先匹配关键词与元数据关联 |
| `usingReRank` | 开启 | 对召回结果按语义相关性重排，优化钢铁冶炼专业内容的排序逻辑 |
| `datasetSearchUsingExtensionQuery` | 开启 | 针对办事咨询的模糊提问，自动扩展查询词，覆盖工艺术语的同义词与别称 |
| `collectionIds` | 绑定冶炼工艺、设备运维、质检报告三个数据集 | 限定检索范围，避免跨品类无关数据干扰 |

## 容易做错的三处
- 现象：检索结果条数过多，AI回答中途截断。原因：未设置合理的`limit`参数，召回的结果超出上下文窗口上限。
- 现象：检索结果未携带元数据，无法关联对应炉号、钢种信息。原因：未开启元数据绑定配置，或未在检索时指定关联字段。
- 现象：markdown格式的工艺文档检索后逻辑丢失，匹配结果分散。原因：未保留文档的层级结构，直接分段导致标题与从属内容的语义关联断裂。

## 怎么确认配好了
本核对流程适配FastGPT v4.17.0版本。
- 发起一条包含钢种牌号与设备名称的测试查询，核对返回结果的条数与`limit`设置一致。
- 查看检索结果的元数据字段，确认炉号、冶炼批次等信息已同步返回。
- 上传一份带层级标题的工艺规程文档，检索对应章节的问题，确认结果保留了层级关联。
- 触发模糊提问测试，确认系统自动扩展了专业术语的同义词查询。
