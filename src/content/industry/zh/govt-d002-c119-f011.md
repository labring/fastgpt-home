# 钢铁冶炼的办事咨询与答复：表单与交互
本文基于FastGPT v4.17.0版本配置

## 这个品类的数据长什么样
钢铁冶炼的办事咨询数据主要来自现场生产控制系统、质检台账、设备运维日志及行业工艺标准文档。数据更新节奏分为两类：现场实时采集的工艺参数实时更新，月度汇总的质检报告与设备检修记录按自然周更新。文档结构包含结构化的参数表单与非结构化的工艺手册，核心字段包括铁水温度、冶炼周期、原料配比、设备运行时长，对应单位分别为摄氏度、分钟、百分比、小时。

## 这些特征在「表单与交互」这一环带来什么约束
钢铁冶炼的数据特征对表单与交互环节带来多重约束。实时采集的工艺参数要求表单控件支持实时拉取最新数据，避免使用静态缓存的旧值。核心字段带有固定单位，交互设计需强制关联单位提示，防止输入值与标准单位不符。长文档的上传需求要求表单支持大体积文件提交，适配多格式解析。不同冶炼工序的字段差异明显，交互需支持按工序预设表单模板，减少重复配置操作。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 表单输入控件 | 用`formInput`配置为带固定单位提示的输入框 | 钢铁冶炼核心字段带有明确单位，可避免输入值与标准不符 |
| 单选多选生成 | 用`userSelect`配置为按工序预设选项集 | 不同冶炼工序的咨询场景差异明显，预设选项可简化用户操作 |
| 文件上传配置 | 最大上传1000 MB，支持PDF、CSV格式 | 冶炼相关文档多为长PDF工艺手册与结构化报表，需适配大体积文件 |
| 实时数据同步 | 同步间隔为60秒 | 现场工艺参数变化较快，60秒可保证咨询所用数据的时效性 |
| 输入字符限制 | 单字段最大输入800–1200字符 | 冶炼咨询的参数描述通常在该区间内，可避免过长内容影响加载 |

## 容易做错的三处
- 现象：单选多选选项无法通过参数动态生成，仅显示固定选项；原因：未正确绑定`userSelect`的参数数据源，直接硬编码了静态选项。
- 现象：上传的冶炼工艺PDF无法正常解析，或系统返回文件大小超限报错；原因：未配置支持PDF格式的文件上传规则，或上传文件超过预设的最大体积限制。
- 现象：提交办事咨询表单后无后续对接反馈，后台无法匹配咨询场景；原因：未将业务关联字段设为必填项，导致关键信息缺失无法分配处理资源。

## 怎么确认配好了
- 提交一条测试咨询，核对输入控件是否自动显示对应单位提示。
- 上传一份标准冶炼工艺PDF，确认上传流程无报错且解析内容可匹配表单字段。
- 切换预设的工序模板，确认表单字段与选项集同步更新。
- 模拟实时参数拉取操作，确认数据更新频率符合预设标准。
