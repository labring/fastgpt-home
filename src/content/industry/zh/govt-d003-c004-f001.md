# 主动公开与政策发布的台账汇总与报告生成：HTTP 接口与外部系统

## 这个品类的数据长什么样
本品类的数据来源包括政府门户网站、公文系统、政府信息公开目录、政策文件库、新闻发布会材料。日常文档涵盖政策文件、政策解读稿、公开目录、信息发布审批单、新闻通稿、网站栏目更新记录。数据更新频率为每日，字段包含文件标识、公开属性、发布时限、栏目归属、保密审查状态等，单位多为文件份数、发布日期、栏目编码等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
由于数据来源分散且每日更新，HTTP接口需支持多源数据拉取与增量同步，避免重复拉取全量数据。文档类型多样，接口需适配政策文件、公开目录等不同格式的字段校验，确保公开属性、保密审查状态等关键字段完整传递。因需同步多个网站栏目与新媒体账号，接口需支持批量推送任务，且需携带栏目归属、发布时限等字段完成精准分发。同时，需兼容政务系统的身份校验规则，避免未授权访问触发安全拦截。

## 配置怎么定
本配置项适配FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | 配置为Bearer令牌格式，携带政务网关分配的密钥 | 符合政务系统通用的API鉴权规范 |
| 同步触发频率 | 每 24 小时触发一次增量同步 | 匹配数据每日更新的频率 |
| 单次推送条数 | 50–100 条 | 避免政务接口限流导致推送失败 |
| `responseData` | 校验该字段中是否包含发布成功标识 | 确保接口调用结果可追溯 |
| 超时阈值 | 600 秒 | 适配政务系统接口的响应延迟情况 |
| `variables` | 配置为包含公开属性、发布时限的动态变量 | 适配政务文档的个性化字段要求 |

## 容易做错的三处
- 配置`Authorization`头时未携带政务网关分配的有效密钥，接口返回401未授权状态码，无法完成数据拉取或推送。
- 编辑HTTP请求的body内容后未保存配置，导致请求体携带错误的字段组合，无法通过政务系统的格式校验。
- 未配置增量同步逻辑，全量拉取每日数据时触发政务接口限流，导致接口返回503服务不可用状态，同步任务失败。

## 怎么确认配好了
- 调用配置的HTTP接口，检查返回的`responseData`中包含预期的政务系统响应字段，验证鉴权逻辑生效。
- 触发一次测试同步任务，核对推送的文档字段与本地台账字段一致，确认映射规则生效。
- 查看接口调用日志，确认超时阈值未触发频繁中断，同步任务的执行频率符合每日更新的要求。
- 检查批量推送的条数设置，确保单次推送的数量符合政务平台的接口限制要求。
