# 主动公开与政策发布的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
本品类的数据来自政府门户网站、公文系统、政府信息公开目录、政策文件库及新闻发布会材料，更新频率为每日。日常文档包含政策文件、政策解读稿、公开目录、信息发布审批单、新闻通稿及网站栏目更新记录，文档字段涵盖文件编号、发布主体、公开属性、保密等级、发布时限、栏目归属等，单份文档篇幅跨度较大，从数百字的通知到数十页的政策细则均有覆盖。

## 这些特征在「工具调用与插件」这一环带来什么约束
每日更新的数据源要求工具调用配置定时同步任务，避免数据滞后影响台账时效性。多来源、多格式的文档需要插件适配公文系统专有格式、长pdf文件解析，避免出现部分文档无法读取的问题。文档字段的多样性要求工具调用时支持自定义字段提取规则，确保台账能覆盖文件编号、公开属性等核心信息。长篇幅文档的处理需要调整插件调用参数，避免因单文件过大触发报错，同时需适配不同来源的文档格式差异。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 自动匹配适用工具，适配政策文件、新闻通稿等多类型文档的处理需求 |
| `functionCall` | `开启` | 强制模型返回结构化工具调用结果，便于台账字段的标准化汇总 |
| 大文件解析超时时间 | `1000–1500 秒` | 适配数百页的pdf文档解析，避免长文件处理触发超时报错 |
| 插件调用重试次数 | `2–4 次` | 应对临时网络波动或插件服务异常，提升调用成功率 |
| 自定义字段提取规则 | 按实测标定 | 适配本品类文档特有的文件编号、公开属性、保密等级等字段 |

## 容易做错的三处
- 现象：调用长文档解析插件时，数百页pdf文件触发报错，数十页文件可正常完成。原因：未调整大文件解析超时时间，单文件处理时长超出插件默认限制。
- 现象：工具调用实际执行成功，但平台未生成对应调用日志。原因：未开启工具调用日志采集配置，或日志采集阈值设置过高。
- 现象：本地部署的解析插件调用时返回Cannot read properties of undefined报错。原因：插件版本与FastGPT版本不兼容，或本地部署的插件依赖未正确配置。

## 怎么确认配好了
- 上传一份百页级pdf政策文档，触发工具调用流程，检查是否能正常完成解析并生成结构化数据。
- 查看工具调用日志模块，确认有对应本次调用的完整记录生成。
- 检查生成的台账数据，确认包含文件编号、公开属性等本品类核心字段。
- 模拟每日定时同步任务，确认数据源更新后能自动触发工具调用流程。
