# 主动公开与政策发布的台账汇总与报告生成：文档解析与分块

## 这个品类的数据长什么样
本品类数据主要来自政府门户网站、公文系统、政府信息公开目录、政策文件库及新闻发布会材料，更新频率为每日。日常处理的文档包含政策文件、政策解读稿、公开目录、信息发布审批单、新闻通稿与网站栏目更新记录，文档多包含发文机关、文号、发布日期、公开属性、栏目归属等字段，部分解读稿附带图文素材。

## 这些特征在「文档解析与分块」这一环带来什么约束
每日批量更新的文档要求解析流程具备批量处理能力，避免单文件解析耗时过长影响整体效率。多类型文档覆盖纯文本、带图文的政策解读稿，要求解析配置适配多种格式，兼顾文本与图文内容的提取。需精准提取公开属性、文号、发布日期等关键字段，分块时需保留字段与对应内容的上下文关联，确保后续台账汇总时可准确关联信息。同时，多平台同步发布的需求要求分块结果可按栏目、发布时间快速归类，便于后续报告生成。

## 配置怎么定
本文档适配FastGPT v4.17.0版本的文档解析与分块功能。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配政策文件、解读稿的段落长度，保留关键字段与上下文的关联，避免分块割裂文号、发布日期等核心信息 |
| `chunkSplitter` | 按段落+标题分隔 | 适配政策类文档的层级结构，按章节、段落拆分，便于后续按栏目、发布时间归类汇总 |
| `customPdfParse` | 开启结构化解析 | 针对政策文件的PDF格式，提取文本与内嵌字段，避免纯文本解析丢失格式与关键信息 |
| `UPLOAD_FILE_MAX_SIZE` | 100 MB | 适配批量上传的政策文件、新闻通稿等文档，满足日常批量处理的文件上限需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 应对带图文的政策解读稿解析耗时，避免批量处理时出现超时中断 |
| `chunkSettingMode` | 手动配置 | 适配多类型文档的差异化需求，针对公开目录、审批单等短文档调整分块参数 |

## 容易做错的三处
- 上传图像地址后解析结果为空或报错。原因是未配置图像解析的适配参数，或文档中图像链接的访问权限受限，无法被系统正常拉取解析。
- 批量上传政策文件时出现超时报错。原因是配置的`PARSE_FILE_TIMEOUT_SECONDS`取值过短，未适配带图文的政策解读稿的解析耗时。
- 台账汇总时无法关联文号与对应政策内容。原因是`chunkSize`设置过小，将同一文号的内容拆分至多个块中，丢失上下文关联。

## 怎么确认配好了
- 上传单份政策文件PDF，查看解析后的文本结构，确认标题、段落、核心字段是否完整提取。
- 配置`chunkSize`后，手动拆分一段政策文本，验证分块长度符合设定的区间。
- 上传批量文档，检查解析任务的状态，确认未出现批量处理超时问题。
- 调用对应API接口，验证图像解析参数的传递格式，确认解析结果包含图像相关内容。
