# 产权、资产与国有资本管理的台账汇总与报告生成：工作流编排

## 这个品类的数据长什么样
数据来源包括国资监管信息系统、企业资产管理系统、产权交易所系统、评估机构报告与财务报表，更新频率为月度。日常文档包含产权登记表、资产评估报告、产权转让方案、进场交易公告、资产处置审批单，既有结构化的字段如权属编号、资产原值、评估值，也有非结构化的PDF报告与图片类证明材料，数据结构包含多层级资产明细与审批流程节点。

## 这些特征在「工作流编排」这一环带来什么约束
多源数据的拉取要求工作流配置多组数据变量，避免跨系统接口冲突。月度更新的节奏需要绑定定时触发节点，确保数据同步与汇总的周期性。大节点的台账数据与非结构化文档容易超出AI上下文长度，需要拆分处理或配置适配的上下文上限。图片类证明材料的导入需要额外的格式转换步骤，否则无法被AI模型直接识别。同时，流程出错可能引发严重后果，需要配置失败重试与审计日志节点。

## 配置怎么定
本章节配置基于FastGPT v4.17.0版本的工作流编排逻辑。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `variables` | 配置国资监管、资产管理等多系统数据变量组 | 适配多源数据拉取需求，避免单变量冲突 |
| 分块长度 | 800–1200 字符 | 拆分大节点台账数据，规避AI上下文超限报错 |
| 最大上下文 | 16000 token | 匹配主流AI模型的上下文承载上限，适配台账汇总的内容量 |
| 重试次数 | 2–3 次 | 应对国资系统接口偶发波动，降低流程失败率 |
| 定时触发周期 | 每月1日 09:00 | 匹配月度数据更新的业务节奏 |
| 文件上传大小限制 | 1000 MB | 容纳大型资产评估报告等非结构化文档 |
| `nodeId` | 绑定数据校验、AI分析、报告生成的核心节点 | 确保工作流节点按业务逻辑顺序执行 |

## 容易做错的三处
- 工作流执行时提示上下文长度超限，返回400状态码。原因是未对大节点台账数据进行分块处理，直接传入AI模型超出上下文上限。
- 图片导入后生成的分析结果为空字段。原因是未配置图片转base64的脚本节点，未将图片编码正确传入AI模型。
- 通过API调用工作流时返回参数错误，无法上传文件。原因是未按照要求的格式传递文件与`variables`参数，导致接口校验失败。

## 怎么确认配好了
- 手动触发工作流，检查`variables`配置的多系统数据是否正确拉取到对应节点中。
- 上传单份大型资产评估报告，验证是否出现上下文超限报错，确认分块与上下文配置生效。
- 上传测试图片，运行图片转base64的脚本节点，检查输出的编码格式是否符合AI模型的输入要求。
- 调用测试API上传文件，检查返回的状态码是否符合预期，确认接口配置正确。
