# 产权、资产与国有资本管理的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
本品类的数据来源包括国资监管信息系统、企业资产管理系统、产权交易所系统、评估机构报告及财务报表，更新频率为月度。日常处理的文档包含产权登记表、资产评估报告、产权转让方案、进场交易公告、资产处置审批单，数据结构兼具结构化表单与非结构化报告两类，字段涵盖资产权属编号、评估基准值、交易对价、审批流转节点标识等，单位涉及万元、平方米、件等。

## 这些特征在「工具调用与插件」这一环带来什么约束
月度更新的特性要求工具调用需适配定时触发的周期配置，保障台账数据的时效性。多源异构的数据来源，要求插件的HTTP请求参数需适配不同系统的接口格式，部分系统需携带专属权限令牌完成认证。混合结构化与非结构化的文档类型，要求工具调用需区分解析规则，对结构化表单直接提取字段，对非结构化报告先完成信息抽取再整理。此外，该品类数据出错会引发国有资产流失等严重后果，因此工具调用需配置异常捕获与校验逻辑，确保提取字段符合标准化要求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 设为`auto`，指定包含资产台账提取、报告生成的工具列表 | 适配多工具协同的台账汇总与报告生成需求，自动匹配对应功能的工具 |
| 定时触发配置 | 设为每月1日0点执行 | 匹配数据月度更新的频率，保障台账汇总的时效性 |
| 异常重试机制 | 重试次数设为3次，重试间隔设为60秒 | 应对国资系统接口偶发波动，降低调用失败率 |
| `functionCall` | 开启强制结构化输出 | 保障提取的资产字段符合标准化格式，便于台账汇总与报告生成 |
| 数据源参数校验 | 开启必填字段校验 | 适配多源系统的接口格式差异，避免无效请求 |

## 容易做错的三处
- 现象为调用第三方大模型时返回`{"object":"error","message":"Only allowed now"}`，原因是未正确配置自定义模型的接入参数，未在FastGPT中完成对应模型的密钥与接口地址绑定。
- 现象为导入国资相关文档时返回500错误，原因是未适配文档的混合结构化与非结构化格式，插件未正确区分表单与报告的解析逻辑。
- 现象为HTTP工具调用解析参数后未执行实际操作，原因是未配置数据源的权限令牌，接口请求缺少必要的认证字段，导致请求被拦截。

## 怎么确认配好了
- 手动触发一次工具调用，检查返回结果中是否包含资产权属编号、评估值等必填字段，字段格式是否符合标准化要求。
- 查看插件调用日志，确认HTTP请求的参数与数据源接口要求一致，无缺失的认证字段。
- 测试定时触发功能，确认在月度触发时间点后，台账数据已完成自动汇总与更新。
- 模拟接口异常场景，检查系统是否触发重试机制并记录异常日志。
