# 产权、资产与国有资本管理的台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
本品类数据主要来自国资监管信息系统、企业资产管理系统、产权交易所系统、评估机构报告及财务报表。日常处理的文档包含产权登记表、资产评估报告、产权转让方案、进场交易公告、资产处置审批单，包含资产编号、权属主体、评估值、交易状态等字段，单位涉及货币、面积、数量等。数据更新频率为月度，需整合多系统跨周期的存量资产与交易数据。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类数据多来源且格式存在差异，需配置适配多文档类型的上下文处理逻辑，避免因格式不兼容导致解析失败。月度批量更新的特性要求配置支持大批次数据处理的参数，防止单次处理超时。资产权属与交易数据的字段复杂度较高，需限定合理的上下文长度，确保模型能准确提取核心信息。同时，数据处理出错会引发严重后果，需配置完善的失败重试与校验机制。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配本品类多文档拼接后的上下文长度，避免超出模型承载上限 |
| `maxTokens` | 4000 token | 匹配产权、资产类报告的核心内容输出长度，确保完整生成汇总报告 |
| `quoteMaxToken` | 2000 token | 限定引用源文档的片段长度，保证引用内容与核心任务的关联性 |
| `temperature` | 0.2–0.4 | 降低生成随机性，确保台账汇总与报告的格式与内容符合国资管理规范 |
| `AIPROXY_API_ENDPOINT` | 按对接的模型服务商提供的地址填写 | 用于配置模型调用的接口地址，确保与部署环境的网络连通性 |
| `AIPROXY_API_TOKEN` | 按服务商生成的密钥填写 | 用于身份验证，保障模型调用的安全性 |

## 容易做错的三处
- 配置`AIPROXY_API_ENDPOINT`时填写错误的接口地址，测试时出现超时错误。原因是未核对接口地址与部署环境的网络连通性，或未正确配置代理规则。
- 启用`text-embedding-3-large`作为索引模型后任务卡住不动。原因是未调整`maxContext`适配该模型的输入长度限制，导致上下文溢出未触发明确报错。
- 将代码块输出的String类result直接传入模型时，出现Question is empty报错。原因是未对result进行格式校验，残留的换行符或特殊字符导致模型无法识别有效提问内容。

## 怎么确认配好了
- 调用配置好的接口，传入单份产权登记表文档，检查接口返回的响应状态码为200。
- 提交批量月度资产数据，观察任务执行时长符合预期，未出现长时间无响应的情况。
- 生成一份台账汇总报告，核对报告中提取的资产字段与源文档内容一致。
- 模拟接口调用失败场景，检查系统是否按配置触发重试机制。
