# 公共数据目录与开放的台账汇总与报告生成：向量模型与索引

## 这个品类的数据长什么样
本品类数据主要来自地方公共数据开放平台、一体化大数据平台、部门业务数据库及电子证照库，更新频率为每月一次。日常处理的文档包括公共数据资源目录、数据开放清单、数据项说明、脱敏规则、接口文档与更新频率说明，字段包含数据项名称、归属部门、开放条件、脱敏方式、接口地址、更新周期等，多为结构化内容与技术说明类文档。

## 这些特征在「向量模型与索引」这一环带来什么约束
每月固定更新的批量数据要求索引支持增量同步与全量重建，避免重复处理全量历史数据。结构化字段与技术文档混合的内容，需要适配不同文本长度的分块逻辑，避免拆分破坏接口地址、脱敏规则这类关键信息。数据来源分散且需严格管控授权边界，索引构建时需关联数据项的授权属性，防止非授权数据被检索。同时，台账汇总与报告生成的下游需求要求索引召回的结果需精准匹配数据项的开放条件，避免召回不符合要求的内容。

## 配置怎么定
本配置适用于FastGPT v4.17.0。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配公共数据目录、接口文档的混合文本长度，避免拆分关键技术字段 |
| 重叠长度 | 50–80 字符 | 保留跨分块的接口地址、脱敏规则等关键信息，防止上下文断裂 |
| 相似度阈值 | 0.75–0.85 | 匹配公共数据项的精准检索需求，过滤低相关性的非目标数据项 |
| 单次搜索上限 | 前10条 | 适配台账汇总的批量数据梳理需求，控制单轮召回的结果数量 |
| `defaultToken` | 8192 | 适配长文档的上下文处理，满足接口文档、完整数据项说明的输入要求 |
| `maxToken` | 16384 | 支持大批次台账汇总的上下文拼接，避免截断关键汇总逻辑 |

## 容易做错的三处
- 升级新版本后尝试迁移老向量库数据时，系统提示格式不兼容无法导入。原因是新版本索引的存储结构与旧版本存在差异，未提前配置数据映射规则完成格式转换。
- 配置voyage索引后发起检索请求，返回400状态码且无返回内容。原因是未正确配置模型访问密钥与请求参数，导致接口请求无效。
- 执行全量索引重建任务后，服务器读写资源持续占用过高，每日出现进程被强制终止的情况。原因是未设置分块处理的并发上限与单次任务的资源阈值，批量处理月度更新的全量数据时超出服务器承载能力。

## 怎么确认配好了
- 手动上传一份典型的公共数据目录文档，执行索引构建后，检查分块后的文本是否完整保留接口地址、脱敏规则等关键信息。
- 发起一次检索测试，输入数据项名称关键词，核对召回结果的条数与字段是否符合预设的单次搜索上限。
- 执行一次增量索引同步，验证月度更新的新增数据是否成功写入索引，未出现重复或遗漏。
- 查看系统监控面板，确认索引构建任务的内存与磁盘占用处于合理区间，未出现资源耗尽的情况。
