# 公共数据目录与开放的台账汇总与报告生成：数据库与运维

## 这个品类的数据长什么样
本品类处理的数据涵盖公共数据资源目录、数据开放清单、数据项说明、脱敏规则、接口文档、更新频率说明等结构化文档。数据来源为地方公共数据开放平台、一体化大数据平台、部门业务数据库、电子证照库，更新频率为月度。数据字段包含数据项唯一标识、所属部门、数据格式、脱敏要求、开放权限、更新周期、关联接口地址等，单条关联接口的批量数据体量存在较大差异，部分数据可达GB级。

## 这些特征在「数据库与运维」这一环带来什么约束
月度更新的频率要求定期执行批量数据同步，对数据库的连接稳定性与批量写入效率提出明确要求。多源异构的数据格式与字段差异，需要适配不同类型数据库的读写规则，避免格式转换后的数据无法正常写入。结构化字段包含敏感权限与接口地址，需配置细粒度的访问控制与数据脱敏存储规则，防止敏感信息泄露。数据体量差异较大的特性，要求数据库预留弹性存储空间，同时避免大体积数据查询导致的运维压力。此外，公共数据目录需与实际开放数据保持一致，需定期执行数据一致性校验，防止出现目录与实际数据不符的问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://fastgpt:securepass@mongodb-host:27017/fastgpt_public_data?authSource=admin` | 存储公共数据目录、脱敏规则等半结构化文档，专用数据库实例隔离政务数据与其他业务数据 |
| `PG_URL` | `postgresql://fastgpt:securepass@pg-host:5432/fastgpt_struct?sslmode=require` | 存储结构化数据项、接口地址等带索引的结构化数据，开启SSL保障传输安全 |
| `DB_MAX_LINK` | `20–30` | 适配月度批量同步与日常查询的并发需求，避免数据库连接池耗尽 |
| `REDIS_URL` | `redis://:redispass@redis-host:6379/0` | 缓存高频访问的公共数据目录条目，降低数据库的重复查询压力 |

本配置适用于FastGPT v4.17.0版本。

## 容易做错的三处
- 现象为启动服务后提示数据库连接失败，报错包含connection refused或invalid credentials。原因是未正确配置`MONGODB_URI`或`PG_URL`的连接参数，未使用政务系统专用的数据库账号与权限。
- 现象为查询结构化数据时提示column vector does not exist。原因是未在PostgreSQL实例中提前安装并启用vector扩展，或扩展安装后未执行初始化脚本同步字段结构。
- 现象为月度批量同步数据时出现超时错误，报错显示connection pool exhausted。原因是`DB_MAX_LINK`设置值小于并发连接需求，导致数据库连接池无法支撑同步请求。

## 怎么确认配好了
- 执行FastGPT内置的数据库连接测试工具，验证`MONGODB_URI`与`PG_URL`对应的数据库实例可正常执行读写操作。
- 查看Redis监控指标，确认`REDIS_URL`对应的缓存实例正常运行，高频访问的公共数据条目缓存命中率符合业务预期。
- 发起单次小型数据同步测试，导入模拟的公共数据项，验证导入后字段完整、格式符合数据库预设规则。
- 模拟多并发查询请求，确认数据库连接池未出现耗尽情况，查询响应时间满足业务要求。
