# 公共数据目录与开放的台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据主要来自地方公共数据开放平台、一体化大数据平台、部门业务数据库与电子证照库，更新频率为月度。日常文档包含公共数据资源目录、数据开放清单、数据项说明、脱敏规则、接口文档与更新频率说明，数据字段涵盖数据项名称、开放范围、脱敏要求、接口地址、更新周期与授权边界等，均为结构化或半结构化的可开放数据资产。

## 这些特征在「知识库检索与召回」这一环带来什么约束
月度更新的特性要求知识库需按固定周期完成全量数据同步，避免召回过期的开放数据项或更新后的接口信息。结构化为主的文档结构要求检索需精准匹配数据字段，减少无关结果的干扰。脱敏规则与授权边界的存在，要求召回环节需自动过滤未开放或超出授权范围的数据内容。多类文档并行存在的场景，需要明确检索范围限定在公共数据目录相关的文档集合内，避免混入其他政务公开内容，确保台账汇总的准确性与合规性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 公共数据目录字段需精准匹配，该区间适配结构化字段的检索精度要求，避免召回无关数据项 |
| `limit` | 前10条 | 本品类月度更新的文档批次通常规模可控，10条可覆盖单次台账汇总所需的核心数据，避免上下文溢出 |
| `searchMode` | 精准匹配 | 本品类数据多为结构化字段，精准匹配模式可减少非目标数据的召回，符合台账汇总的严谨性要求 |
| `usingReRank` | 开启 | 月度更新的文档集合存在大量相似字段，重排可提升高相关数据的排序优先级，确保报告生成的内容准确性 |
| `datasetSearchUsingExtensionQuery` | 关闭 | 公共数据目录的字段定义明确，无需额外扩展查询词，避免引入与数据项无关的冗余内容 |
| `collectionIds` | 绑定公共数据目录专属集合 | 确保检索范围仅覆盖本品类的文档，避免混入其他政务文档，符合数据治理的边界要求 |

## 容易做错的三处
- 现象：添加公共数据目录知识库后，调用检索接口返回报错信息，或本地部署的大模型在添加知识库后无法正常响应。原因：未正确绑定专属集合，检索范围覆盖了非目标文档，或`similarity`阈值设置不合理，导致召回内容超出合规范围。
- 现象：检索结果条数与配置的`limit`参数不符，出现超出或不足的情况。原因：未正确设置`collectionIds`，检索范围包含了其他集合的文档，或重排环节过滤了部分符合要求的结果。
- 现象：生成的台账报告中出现未脱敏的数据项内容或超出授权范围的开放说明。原因：未在检索召回环节关联脱敏规则与授权边界文档，或`searchMode`设置为模糊匹配，召回了未标注合规要求的数据项。

## 怎么确认配好了
- 查看知识库集合绑定情况，确认仅包含公共数据目录相关文档，核对`collectionIds`参数与实际集合ID一致，参考FastGPT v4.17.0的集合配置规范。
- 发起测试检索，输入数据项名称关键词，检查返回结果的字段是否与品类文档结构匹配，确认`similarity`阈值符合业务精度要求。
- 触发台账汇总任务，检查生成的报告内容是否仅包含已开放的数据项与对应接口说明，未出现未授权或脱敏内容。
- 等待月度同步周期结束后，验证检索结果是否包含最新更新的数据项，确认同步流程正常运行。
