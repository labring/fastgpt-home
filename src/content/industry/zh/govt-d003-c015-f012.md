# 医保基金监管稽核的台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
本品类的数据来源于医保智能监控系统、基金监管规则库、医保结算数据、药品耗材追溯码及举报线索。日常处理的文档包括稽核通知书、检查工作底稿、疑点清单、约谈记录、处理决定书与整改报告，字段覆盖违规认定项、整改完成情况、处理依据等，更新频率为月度。数据需从多系统同步整合，且需匹配稽核流程的文档格式要求，支撑从疑点筛选到处理意见形成的全环节汇总。

## 这些特征在「部署与升级」这一环带来什么约束
月度更新的批量数据要求部署时配置稳定的数据库连接池与定时同步任务，避免数据同步中断。多源异构的数据来源需要适配不同的存储与接口配置，确保稽核数据、规则库与举报线索的一致性。文档格式的多样性要求平台支持多类型文件解析，同时需保障处理过程中的数据完整性，避免因配置错误导致稽核台账缺失关键字段。此外，稽核流程的耗时环节较多，需合理配置任务队列资源，防止因资源不足导致任务超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 10–15 | 适配月度批量同步的多源数据连接需求，避免连接池耗尽 |
| `MONGODB_URI` | 部署的MongoDB实例连接地址（含认证信息） | 用于存储稽核疑点清单、整改报告等非结构化文档数据 |
| `REDIS_URL` | 部署的Redis实例连接地址，超时设置为 300 秒 | 缓存高频访问的基金监管规则库数据，降低重复查询开销 |
| `STORAGE_S3_ENDPOINT` | 部署的对象存储服务访问端点 | 用于存储批量导出的稽核台账与报告文件 |
| `FILE_TOKEN_KEY` | 32 字符的自定义密钥字符串 | 用于生成稽核文档的访问令牌，保障数据安全 |

## 容易做错的三处
- 现象：升级到FastGPT v4.17.0后，aiproxy容器启动后频繁出现curl执行失败的报错。原因：未正确配置`STORAGE_S3_ENDPOINT`对应的对象存储权限，导致稽核台账文件无法正常拉取。
- 现象：工作流中无法读取部署时自定义的环境变量。原因：未在容器启动参数中添加环境变量透传配置，导致平台无法获取自定义参数。
- 现象：月度数据同步任务频繁超时失败。原因：`DB_MAX_LINK`设置过低，导致多源数据同步时数据库连接池耗尽，无法完成数据拉取。

## 怎么确认配好了
- 登录FastGPT后台的配置页面，查看`MONGODB_URI`的连通性测试结果，显示正常。
- 触发一次模拟的月度数据同步任务，查看任务日志，确认多源数据均成功拉取并完成整合。
- 在工作流中添加读取环境变量的节点，输入自定义环境变量名，确认能正常返回预设值。
- 查看aiproxy容器的运行日志，无连续的curl报错信息，服务运行稳定。
