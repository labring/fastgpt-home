# 国土空间规划编制与实施评估的台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来源于国土空间基础信息平台、自然资源调查监测数据、人口经济统计数据与遥感影像，更新频率为年度。日常产出文档包含国土空间总体规划、详细规划、专项规划、规划实施评估报告及公众意见汇总，数据字段涵盖空间范围、约束指标、布局要求、意见反馈等，单位多采用公顷、平方公里、人口数等空间与社会经济统计单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类数据为年度更新的多源空间与社会经济信息，体量较大且字段单位不统一，要求模型接入时需配置足够的上下文容量，避免截断核心规划数据。非结构化的公众意见与规划文档占比高，需合理设置上下文截断参数，确保关键信息完整保留。规划类文档对严谨性要求高，需开启原始数据引用保留功能，避免输出内容脱离原始依据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配年度汇总的多源规划文档与数据体量，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 满足单份规划实施评估报告的生成长度需求，平衡输出完整性与响应速度 |
| `quoteMaxToken` | 1500 token | 保留足够的原始数据引用内容，符合规划文档的严谨性要求 |
| `temperature` | 0.2–0.4 | 降低输出随机性，确保规划指标与约束条件的准确性 |
| `toolChoice` | auto | 自动适配多源数据调用工具的需求，无需手动指定工具类型 |
| `AIPROXY_API_TOKEN` | 按平台生成的专属令牌填写 | 完成身份验证，保障API调用的安全性 |

## 容易做错的三处
- 出现`model stream response is empty`报错，终端curl请求可正常返回结果。原因是FastGPT v4.17.0版本的上下文截断参数配置不合理，导致模型无法获取完整输入内容。
- 升级版本后m3e模型无法正确调用。原因是未同步更新模型接入的代理配置参数，导致请求路由异常。
- 大模型API返回参数错误提示。原因是未正确配置`quoteMaxToken`参数，导致模型输出的引用内容超出预设长度，触发API校验规则。

## 怎么确认配好了
- 执行终端curl命令调用模型接口，检查返回结果是否包含规划数据相关的结构化内容与引用标记。
- 上传单份详细规划文档进行测试，确认生成的汇总内容包含原始数据的来源标注。
- 调整`temperature`参数至0.1与0.5分别测试，对比输出结果的一致性，验证参数配置的有效性。
- 检查`AIPROXY_API_TOKEN`与`AIPROXY_API_ENDPOINT`的填写内容，确保与平台提供的信息完全一致。
