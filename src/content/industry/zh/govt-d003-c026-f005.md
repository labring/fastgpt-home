# 工程建设项目审批的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
本品类数据主要来自工程建设项目审批管理系统、施工图审查系统、企业资质库及公共信用平台，更新频率为每日。日常处理的文档包括施工许可申请材料、施工图审查合格书、质量安全监督手续、竣工验收备案表，数据字段围绕项目全审批流程设置，涵盖项目标识、建设单位信息、参建单位资质、审批节点状态等，每份文档均绑定对应项目的唯一标识，数据结构与审批流程强关联。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类的数据多源且每日更新，要求工具调用需适配多系统数据拉取，避免跨系统数据不一致。日常文档类型多样，文本提取工具需兼容不同格式的审批材料，确保字段提取的完整性。数据绑定唯一项目标识的要求，使得工具调用需精准传递项目ID作为参数，避免台账数据混淆。审批流程强关联的数据结构，要求工具调用需支持按审批节点筛选数据，保障汇总报告的环节对应性，同时需处理不同系统返回的数据格式差异，确保整合后的台账结构统一。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配多工具调用场景，自动匹配审批流程所需的工具类型 |
| 文本提取工具格式支持 | 支持PDF、Word、扫描件格式 | 日常审批文档包含施工许可申请、施工图审查合格书等多格式材料 |
| `functionCall` | `enabled` | 需要调用外部系统获取实时审批数据，生成结构化台账与报告 |
| 数据源同步间隔 | `86400 秒` | 匹配本品类数据每日更新的频率，保障台账数据时效性 |
| 单次工具返回条数 | `前20条` | 适配单项目审批数据规模，避免超出上下文长度限制 |
| 工具调用超时阈值 | `600 秒` | 预留足够时间完成多源数据拉取与格式转换，避免调用超时 |

## 容易做错的三处
- 现象：调用仅支持stream模式的大模型时，界面报错`error`，调用日志显示获取数据异常。原因：未在模型配置中开启stream模式适配，导致模型返回格式与平台要求不匹配。
- 现象：文本提取工具返回`400 Invalid JSON payload. Unknown name`报错。原因：工具调用时传递了未定义的字段参数，不符合审批文档提取的字段规范。

## 怎么确认配好了
- 触发一次工具调用，检查返回的审批数据是否包含项目唯一标识，确认项目ID绑定配置生效。
- 上传不同格式的审批文档，验证文本提取工具是否能正确提取对应字段，确认格式适配配置生效。
- 查看模型调用日志，确认`toolChoice`和`functionCall`参数被正确传递，无格式错误。
- 手动触发数据源同步，检查同步后的台账数据是否与外部系统的当日更新数据一致，确认同步间隔配置符合业务要求。
