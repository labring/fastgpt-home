# 投资项目立项与后评价的台账汇总与报告生成：数据库与运维

仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这个品类的数据长什么样
本品类数据覆盖中央企业战略投资部、项目公司、国资监管部门及外部咨询评估机构的投资全流程，来源包括国资委投资监管系统、企业ERP与项目管理系统、行业市场数据、审计和财务报表。日常关联文档涵盖年度投资计划、项目建议书、可行性研究报告、尽职调查报告、资产评估报告、投资后评价报告。数据按季度更新，字段包含项目立项信息、投决会材料、投产后评价数据等，无统一固定单位，随文档类型与业务模块变化。

## 这些特征在「数据库与运维」这一环带来什么约束
本品类的数据特征对数据库与运维环节带来多重约束。多源数据接入要求数据库支持异构数据源对接，适配国资委投资监管系统、企业ERP、行业市场数据等不同接口格式。季度更新节奏要求运维环节配置定期同步调度任务，保障数据时效性。多类型文档与灵活字段要求数据库支持半结构化数据存储，避免硬编码字段限制业务扩展。国资相关数据的合规要求，需要数据库配置严格的访问控制与备份机制，同时支持数据恢复流程，应对数据丢失风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PG_URL` | `postgresql://username:password@host:5432/fastgpt_asset` | 适配央企ERP与监管系统的结构化数据存储需求，支持事务性操作 |
| `MONGODB_URI` | `mongodb://username:password@host:27017/asset_review?authSource=admin` | 存储半结构化的项目文档与非结构化报告，支持灵活字段扩展 |
| `DB_MAX_LINK` | `20–30` | 匹配季度性数据同步的并发请求量，避免数据库连接耗尽 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 缓存高频访问的项目台账数据，降低数据库查询压力 |
| 数据库备份路径 | `/data/backup/asset_project` | 按季度备份频率配置，匹配数据更新周期，保障合规恢复需求 |

## 容易做错的三处
- 现象：数据库连接报错提示访问被拒绝，或接口返回403状态码。原因：未将部署环境的对外请求IP加入数据库访问白名单，不符合国资数据访问的安全配置要求。
- 现象：运行多行SQL语句时返回语法错误，或执行中断。原因：数据库连接插件未配置允许多行查询执行，或未正确拆分多语句执行逻辑，适配本品类多文档关联的批量数据写入需求时出现偏差。
- 现象：恢复备份的项目文件后，知识库与智能体配置为空，无法加载原有数据。原因：仅恢复了项目文件而未同步恢复数据库的台账与报告存储数据，未遵循本品类数据与配置分离的备份流程。

## 怎么确认配好了
- 运行数据库连通性测试工具，验证`PG_URL`、`MONGODB_URI`与`REDIS_URL`的连接状态，确认访问权限配置正确。
- 触发一次临时数据同步任务，检查从各来源系统拉取的项目数据是否完整，确认同步逻辑生效。
- 执行数据库备份与恢复测试流程，验证备份文件可正常加载，确认数据恢复机制可用。
- 查看数据库连接数监控面板，确认当前连接数未超过`DB_MAX_LINK`的配置阈值，确认连接池配置合理。
