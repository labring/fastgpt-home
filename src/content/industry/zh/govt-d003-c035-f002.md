# 排污许可管理的台账汇总与报告生成：向量模型与索引

## 这个品类的数据长什么样
本品类服务的日常文档包括排污许可证申请表、执行报告、自行监测方案、台账记录、变更申请、许可证副本。数据来源涵盖全国排污许可证管理信息平台、企业环保台账、在线监测系统、环境统计系统。更新频率为季度，文档包含固定许可限值、排放边界、监测数据等字段，单位涉及排放浓度、排放量等。服务主体为生态环境部门排污许可管理岗、排污单位环保部门、第三方环保服务机构。

## 这些特征在「向量模型与索引」这一环带来什么约束
多源数据来源要求索引需兼容结构化表格、文本报告、监测数据等多种格式，需配置适配不同格式的长度差异。季度更新的频率要求增量索引的调度逻辑适配批量数据处理，避免单次索引过载。固定许可限值、排放边界等结构化内容，要求索引的匹配精度需满足监管要求，避免遗漏关键信息。不同文档的结构差异要求分块策略需适配不同长度的文本，确保关键字段的完整性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配排污许可类文档的平均长度，覆盖多数台账、执行报告的内容范围 |
| 重叠长度 | 100–200 字符 | 保障跨分块的上下文连贯性，避免拆分许可限值的连续内容 |
| 相似度阈值 | 0.75–0.85 | 平衡精准匹配与召回范围，适配监管类业务的准确性要求 |
| defaultToken | 4096 | 符合多数排污许可文档的token承载量，适配FastGPT v4.17.0的默认适配标准 |
| maxToken | 8192 | 支持长执行报告、变更申请等长文本的上下文需求 |
| 单次搜索上限 | 前 5 条 | 匹配监管类业务的精准召回需求，避免冗余数据干扰审核判断 |

## 容易做错的三处
- 升级版本后CSV文件分块报错。现象：导入CSV格式的企业环保台账后，界面显示分块异常日志，无法生成有效索引块。原因：升级后系统对CSV字段的解析规则调整，未适配排污许可台账的多字段嵌套结构。
- 知识库索引卡住未完成。现象：索引进度条长期停留在中间位置，后台日志显示超时错误。原因：未调整单次处理的数据量，未适配季度更新的大量台账与监测数据。
- 搜索结果返回无关文档。现象：检索“某行业许可限值”时，返回了环评审批类文档，未匹配到排污许可相关内容。原因：相似度阈值设置过低，召回了非许可范围内的文档内容。

## 怎么确认配好了
- 上传单份排污许可证副本，查看分块预览功能，确认分块后的内容完整覆盖原始文档，无关键字段被截断。
- 触发增量索引任务，等待索引完成后，检查进度条显示100%，无异常报错日志。
- 输入“核对某排污限值”类问题，查看返回结果的来源文档均属于排污许可类文件，无跨品类的文档。
- 调整相似度阈值，测试不同阈值下的召回结果，确认符合业务审核的精度要求。
