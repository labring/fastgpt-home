# 政务服务事项目录与办事指南维护的台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
该品类的核心数据来自国家政务服务事项基本目录、行政许可事项清单及地方政务服务事项库，通常按月更新。日常维护的文档包含政务服务事项基本目录、实施清单、办事指南、标准材料目录、流程图与常见问题，单份办事指南通常包含事项名称、受理条件、申请材料、办理流程等结构化字段，部分文档还附带跨层级的事项关联信息。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类数据来源分散且按月更新，需定期同步多源目录数据，模型接入需适配批量数据校验的场景。办事指南字段多且结构化要求高，模型处理需兼顾字段完整性校验与跨层级事项关联比对。月度更新的节奏要求配置的批量处理效率适配同步周期，避免因模型调用超时导致更新中断。政务事项的合规性要求，模型调用需保证结果口径一致，避免出现线上线下办事标准偏差。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的界面参数。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 办事指南及关联文档的总长度通常较大，需容纳多份目录与指南的上下文内容，按实测标定 |
| `maxTokens` | `2000–3000 token` | 台账汇总与报告生成的单轮输出需覆盖事项清单、校验结果等内容，避免超出模型输出上限 |
| `quoteMaxToken` | `500 token` | 需截取办事指南中的关键字段作为引用内容，避免超出引用长度限制 |
| `temperature` | `0.1–0.3` | 需保证事项校验与汇总结果的一致性，避免生成随机偏差的口径内容 |
| `AIPROXY_API_ENDPOINT` | 政务专属模型部署地址 | 需使用政务领域适配模型，保障数据安全与调用稳定性 |
| `AIPROXY_API_TOKEN` | 绑定专属权限的密钥 | 政务数据涉及敏感信息，需通过专属密钥限制调用权限，防止数据泄露 |

## 容易做错的三处
- 离线接入reranker模型后提示`rerank error`，原因是未配置模型的访问权限或部署地址与`AIPROXY_API_ENDPOINT`的参数值不匹配。
- 视觉模型调用时图片上传成功但按钮无法触发，原因是未启用`vision`参数的配置开关，或前端调用逻辑未绑定模型加载状态。
- 使用`bge-m3`向量模型时语义检索值异常偏大，原因是未校准模型的匹配逻辑，或批量导入数据时未正确对齐事项字段格式。

## 怎么确认配好了
- 调用`AIPROXY_API_ENDPOINT`对应的模型接口，使用测试用的政务事项文档发起校验请求，检查返回结果是否包含字段完整性提示。
- 查看模型调用日志，确认`maxContext`和`maxTokens`的参数值在请求中被正确传递，无截断或超限报错。
- 模拟月度更新的批量数据导入流程，检查模型处理的批次数量与配置的批量上限是否匹配。
- 多次调用同一校验任务，验证`temperature`参数设置后返回的结果是否保持一致。
