# 政府信息依申请公开的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
本品类数据来自政府信息公开平台、机关档案系统、公文系统、部门业务台账及政务公开相关规范。日常处理的文档包含政府信息公开申请表、补正告知书、征求第三方意见函、答复书、送达回证与行政复议答辩材料。数据更新无固定周期，随单条申请的办理进度同步更新。数据字段包含申请编号、申请人主体信息、申请内容指向、办理环节节点、答复结果与救济途径记录，无统一固定单位，随具体业务场景调整。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散导致工具调用需适配多类政务系统接口，需配置跨源数据拉取的适配规则，避免接口兼容性错误。文档类型多样且结构差异明显，需针对不同文档类型配置专属字段提取规则，防止格式解析失败。更新无固定周期，需设置触发式工具调用逻辑，仅在申请状态变更时触发调用，确保数据时效性。办理环节涉及第三方权益与法定救济途径，工具调用需保留敏感字段校验环节，防止涉密或敏感信息泄露。出错后果明确，需配置失败重试与异常告警机制，避免超期办理或错误答复。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工具调用触发方式 | 按申请状态变更触发 | 适配数据更新无固定周期的业务特征，避免无效拉取 |
| `toolChoice` | 自动选择工具 | 匹配多源数据拉取与字段提取的复合需求，适配FastGPT v4.17.0版本的工具调度逻辑 |
| 文档解析规则 | 按文档类型分配置 | 覆盖申请表、答复书等多样政务文档结构，提升字段提取准确率 |
| 失败重试次数与间隔 | 3 次，间隔 60 秒 | 应对政务系统接口偶发波动，保障调用成功率 |
| 单次请求超时阈值 | 600 秒 | 适配政务系统较长的响应周期，避免因超时终止调用 |
| 检索结果上限 | 前5条 | 避免返回过多无关政务信息，聚焦核心申请相关数据 |

## 容易做错的三处
- 现象：工具调用节点无法添加连接线，界面无连接小圆圈。原因：未开启对应工具的调试模式，或配置项未保存导致节点状态异常。
- 现象：工作流执行超时，返回状态码 504。原因：未配置合理的超时阈值与重试机制，未适配政务系统较长的响应周期。
- 现象：无法查看MCP服务的详细运行日志。原因：未将日志输出级别配置为详细，或日志存储路径未正确设置。

## 怎么确认配好了
- 手动触发一次工具调用，检查是否能拉取对应政务系统的申请数据，验证触发逻辑是否生效。
- 查看工具调用日志，确认敏感信息校验环节正常拦截涉密或第三方权益相关内容。
- 模拟异常接口响应，检查是否按配置触发失败重试与告警流程。
- 上传不同类型的政务文档，验证字段提取结果是否符合预设规则。
