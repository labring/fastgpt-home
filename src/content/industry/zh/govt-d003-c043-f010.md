# 特种设备安全监管的台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据覆盖特种设备全生命周期相关文档，包括使用登记证、定期检验报告、维保记录、隐患整改通知书、事故报告、作业人员证书。数据来源为特种设备安全监察系统、检验检测机构系统、使用单位台账、作业人员证书库，更新频率为月度。单份文档包含设备编号、使用单位、检验周期、维保日期、资质有效期等核心字段，不同文档的字段侧重不同，如作业人员证书侧重证书编号与有效期，检验报告侧重下次检验日期。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源数据来源要求检索需关联多个独立数据集，避免遗漏跨系统的设备关联信息。月度更新频率要求知识库同步周期匹配数据更新节奏，确保召回的台账与报告信息为最新状态。多样的文档类型与差异化字段要求针对不同文档配置专属检索规则，如针对作业人员证书优先匹配有效期字段，针对检验报告优先匹配下次检验日期字段。台账汇总需批量关联设备、检验、维保、整改等多类文档，要求召回结果可按设备标识分组，便于后续汇总统计。

## 配置怎么定
本配置基于FastGPT v4.17.0版本适配，具体如下：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配特种设备监管文档的字段精度，避免低相关的非监管类文档混入 |
| `limit` | 前10条 | 台账汇总需批量关联单设备的检验、维保、整改等多类文档，单次召回足够覆盖核心监管记录 |
| `searchMode` | hybrid | 结合关键词与语义检索，适配设备编号、检验日期等结构化字段与维保描述等非结构化内容 |
| `usingReRank` | 开启 | 对召回结果按业务相关性重排，优先返回检验周期、资质有效期等核心监管字段的匹配结果 |
| `datasetSearchUsingExtensionQuery` | 开启 | 扩展检索范围，覆盖多源系统导入的不同格式文档，避免遗漏跨系统关联数据 |
| `collectionIds` | 按监管域配置的数据集ID列表 | 精准限定检索范围为特种设备登记、检验、维保、作业人员证书等专属数据集，排除无关数据 |

## 容易做错的三处
- 现象：上传文本数据集时提示`fail to create post presigned url`或`failed to create post p`报错。原因：未正确配置S3存储的访问密钥与桶权限，或数据集存储路径配置错误，导致无法生成预签名上传链接。
- 现象：检索结果无法关联对应设备的检验与维保记录。原因：未通过`collectionIds`限定检索范围为特种设备专属数据集，或`similarity`阈值设置过低导致无关结果混入，无法精准匹配设备标识字段。
- 现象：调用sse协议封装的MCP时提示仅支持stdio进程。原因：使用的FastGPT版本低于v4.14.0，sse协议的跨进程调用适配未完全实现，无法识别封装后的MCP。

## 怎么确认配好了
- 手动上传单份特种设备使用登记证，检索时确认能召回该设备的关联检验报告与维保记录。
- 查看知识库同步日志，确认月级数据的同步任务按计划执行，无失败记录。
- 调整`similarity`阈值，验证召回结果的相关性符合监管文档的匹配要求，无过多无关的非监管类文档混入。
- 检查数据集配置，确认`collectionIds`仅包含特种设备监管相关的数据集ID，无无关数据集混入。
