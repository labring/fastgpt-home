# 用地预审与规划许可的台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据主要来自国土空间规划一张图、项目审批监管平台、土地利用现状库、生态保护红线数据，更新频率不定期。日常处理的文档包括用地预审与选址意见书、建设用地规划许可证、建设工程规划许可证、红线图、规划条件，字段覆盖项目选址范围、用地规模、规划管控要求、前置审批条件等，单位多采用平方米、公顷等国土空间标准计量单位，数据结构随项目类型略有差异。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散且更新无固定周期，要求知识库检索需支持多源数据的关联召回，避免遗漏最新的生态保护红线或规划管控调整信息。文档类型多样且字段专业，需要针对不同文档设置专属的检索匹配规则，确保红线图、规划条件等图纸类文档的文本内容能被准确识别。项目关联的数据关联性强，检索时需优先召回与当前项目选址、用地规模直接相关的条目，避免无关数据干扰台账汇总与报告生成的准确性。

## 配置怎么定
本文基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 匹配国土空间规划类专业文档的语义相似度阈值，避免召回无关的非用地类数据 |
| `limit` | `前8–12条` | 覆盖单个项目审批所需的前置条件、红线要求等核心数据，避免上下文过长影响生成效率 |
| `searchMode` | `向量+关键词混合检索` | 兼顾专业术语的语义匹配与红线图、规划条件等文档的关键词精准召回 |
| `usingReRank` | `开启` | 对召回的条目进行二次排序，优先筛选与当前项目选址、用地规模直接相关的结果 |
| `datasetSearchUsingExtensionQuery` | `开启` | 自动扩展检索关键词，覆盖项目审批中可能涉及的发改、住建等前置审批关联信息 |
| `collectionIds` | `按业务域指定专属集合ID` | 隔离用地预审与规划许可类数据与其他自然资源品类数据，避免数据混淆 |

## 容易做错的三处
- 现象：调用API时返回“未指定知识库”的报错，状态码400。原因：未在请求参数中正确配置`collectionIds`，或传入的集合ID不属于当前业务域的专属知识库。
- 现象：本地docker部署的两个实例无法正常通信，调用外部API连接知识库时出现超时。原因：未正确配置跨容器网络访问权限，导致第二个实例无法访问专属知识库服务，需调整docker网络设置或指定正确的知识库服务地址。
- 现象：导入的需登录的网页链接内容无法被检索到，检索结果为空。原因：未处理登录态限制，FastGPT无法正常爬取需要登录的网页内容，需提前配置开放链接访问权限或代理。

## 怎么确认配好了
- 手动上传一份用地预审与选址意见书的示例文档，执行检索测试，确认能召回该文档的相关内容。
- 查看知识库检索日志，确认返回结果的`similarity`分值落在设定的0.75–0.85区间内。
- 检查API请求参数，确认`collectionIds`已指定当前业务域的专属集合ID，无跨品类数据被召回。
- 模拟台账汇总场景，输入包含项目选址、用地规模的查询词，确认召回的结果包含红线图、规划条件等核心文档内容。
