# 行政许可审批的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
本品类数据主要来自全国一体化政务服务平台事项库、行政许可事项清单、部门业务审批系统及电子证照库，更新频率为每日。日常处理的文档包含办事指南、申请表、承诺书、受理通知书、补正告知书、准予行政许可决定书、许可证照等，数据字段涵盖事项名称、申请主体信息、受理编号、审批状态、办结节点、证照编号等，涉及的审批事项覆盖各行业领域的法定许可要求，所有数据均符合政务服务统一格式规范，无额外自定义非标准字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类的数据来源分散且每日更新，要求工具调用需配置定时同步任务以获取最新事项清单与电子证照数据。日常处理的文档格式多样，插件需适配政务服务标准文档的解析规则，确保准确提取受理编号、审批状态等核心业务字段。由于数据需严格匹配法定许可依据，工具调用时需限定仅调用预设的政务审批相关工具，不得调用未授权的外部接口。跨部门数据调取需通过专用插件对接不同业务系统，需处理格式转换与权限校验环节，避免数据泄露或格式错误导致的超期办结风险。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工具调用触发时机 | 审批节点完成后10分钟内 | 匹配政务服务办结后即时汇总的业务要求 |
| 单次工具调用超时时间 | 600秒 | 覆盖跨部门调取电子证照的常规响应时长 |
| `toolChoice` 参数 | 固定为 `auto` | 让系统自主选择适配行政许可审批的工具调用路径 |
| 插件权限范围 | 仅允许调用事项库、电子证照库、审批系统三类插件 | 符合政务数据安全管控要求 |
| 上下文窗口大小 | 8000–12000 token | 容纳完整的许可事项清单与单批次审批台账数据 |
| `functionCall` 参数 | 按实测标定 | 适配不同审批场景下的工具调用格式要求 |

## 容易做错的三处
- 现象：自定义前端页面调用接口时返回字段为空或格式错误。原因：未在请求参数中正确传递政务审批专属的业务字段，如受理编号、事项名称，未遵循接口的参数规范。
- 现象：调用会话接口时无法生效预设的台账汇总提示词。原因：未正确绑定`functionCall`参数与预设提示词，或提示词未匹配行政许可审批的法定事项边界。
- 现象：插件调用跨部门业务系统时触发权限拦截。原因：未限定插件的调用范围，尝试调用未授权的政务系统接口，混淆了插件与工作流的使用场景，违反数据安全管控要求。

## 怎么确认配好了
- 发起单次审批台账汇总测试，检查工具调用是否自动调取对应事项的最新清单数据，核对返回字段是否包含预设的政务审批核心字段。
- 查看插件调用日志，确认仅调用了配置范围内的事项库、电子证照库、审批系统插件，无未授权接口调用记录。
- 模拟超时场景，检查工具调用是否触发预设的重试机制，确认超时时间配置符合业务响应要求。
- 验证身份验证token的传递流程，确认调用接口时携带的token符合FastGPT官网的验证规范。
