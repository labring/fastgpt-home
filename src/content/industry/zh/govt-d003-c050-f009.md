# 财政支出绩效评价的台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
本品类的数据主要来自预算管理一体化系统、项目申报材料、资金支付数据、业务系统台账及满意度调查，更新频率为年度。日常处理的文档包含绩效目标表、自评表、绩效评价报告、佐证材料清单与整改报告，数据字段包含项目标识、资金拨付节点、绩效指标对应项、佐证材料关联路径等，整体为批量结构化与非结构化混合的年度更新数据集。

## 这些特征在「模型接入与配置」这一环带来什么约束
年度批量更新的混合数据特征，要求模型接入配置支持多文档类型解析与批量上下文关联。多来源数据需适配不同格式的文档解析，尤其是内嵌图片的佐证材料需视觉理解能力。年更特性无需高频增量同步，但单次处理的文档量较大，需限制单次上下文长度避免溢出。同时，绩效评价的严谨性要求模型输出需保持稳定，配置需兼顾效率与准确性，且需对接财政系统的身份校验以满足合规要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配年度批量处理的多份绩效文档，保留自评表、佐证材料、整改报告的完整上下文关联 |
| `vision` | 开启 | 处理绩效报告、佐证材料中的内嵌图片，如验收照片、支付凭证扫描件等非结构化视觉信息 |
| `temperature` | 0.2–0.4 | 保证绩效评分、整改建议的表述严谨，降低主观偏差，符合财政评价的合规要求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写本地或公有云端点 | 适配调用本地部署大模型的需求，满足部分机构的数据本地化部署要求 |
| `AIPROXY_API_TOKEN` | 按实际生成的密钥填写 | 实现身份校验，支持禁止匿名访问，对接外部财政系统时的安全对接 |
| `maxTokens` | 4000–6000 token | 适配单份绩效评价报告的生成长度，避免输出内容被意外截断 |

## 容易做错的三处
- 测试模型调用正常但FastGPT后台看不到模型：现象为模型管理页面未显示已配置的目标模型，接口自测返回成功但后台无记录。原因是未正确填写`AIPROXY_API_TOKEN`或端点地址，导致身份校验失败，模型未完成挂载同步。
- 文档解析后内嵌图片无法被模型识别：现象为上传含图片的佐证材料后，模型输出未提及图片内容。原因是未开启`vision`配置项，未启用视觉理解能力，无法读取图片中的佐证信息。
- 外部系统调用API后无有效响应：现象为前端发起请求后返回空数据或报错。原因是未正确封装API参数，或未匹配FastGPT的对话接口格式，导致请求无法被正确解析。

## 怎么确认配好了
- 进入FastGPT v4.17.0的模型管理页面，检查已配置的模型列表中是否存在目标模型，确认`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`填写无误。
- 上传一份包含内嵌图片的绩效佐证材料，发起解析测试，确认模型可以返回包含图片内容描述的结果。
- 调用外部系统的API接口，传入测试用的绩效台账数据，检查是否能正常返回汇总后的报告片段。
- 配置访问权限策略，验证匿名用户无法访问模型配置页面和对话接口，确认身份校验生效。
