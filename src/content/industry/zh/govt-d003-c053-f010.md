# 部门预算编制的台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
本品类的典型使用主体为财政局预算处、预算单位财务处及主管部门财务司局。日常处理的文档包括部门预算草案、项目申报书、绩效目标表、人员经费测算表、预算批复等，数据来源涵盖预算管理一体化系统、部门人员编制系统、以前年度决算、项目库及财政部预算编制通知。数据更新频率为年度，核心文档包含固定字段如项目编码、预算金额、绩效指标等，最耗时的工作环节为测算人员公用与项目支出、审核项目入库与绩效目标、汇总下属单位预算数据。

## 这些特征在「知识库检索与召回」这一环带来什么约束
年度更新的特性使得无需高频增量同步知识库，仅需在预算编制周期前完成全量更新即可。多源数据来源要求检索需覆盖不同系统导出的文档，需支持跨集合的召回范围限定。固定字段的文档结构要求检索需兼顾语义匹配与精确字段匹配，避免无关结果混入。汇总下属单位预算的工作需求，要求单次召回的文档数量需满足多单位台账的整合需求，同时需控制上下文长度以适配后续报告生成环节。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 相似度阈值 | 0.72–0.80 | 匹配部门预算文档的固定字段精度要求，过滤低相关结果 |
| 单次搜索上限 | 前12–18 条 | 满足汇总多下属单位台账的召回量需求，同时控制上下文长度 |
| 搜索模式 | 向量+全文检索 | 兼顾语义匹配和预算文档的字段精确匹配 |
| 知识库文件大小限制 | 1000 MB | 适配预算文档的大文件上传需求，避免解析失败 |
| 检索超时时间 | 300–600 秒 | 适配多系统数据的检索延迟，避免请求中断 |
| 最大上下文长度 | 8000–10000 字符 | 适配部门预算汇总报告的长文本生成需求 |

## 容易做错的三处
- 现象：调用知识库文件列表接口返回空数组，或通过curl请求获取文件列表无有效结果。原因：未正确绑定对应预算类知识库的集合ID，检索范围限定错误。
- 现象：上传带内嵌图片的docx文档时，界面提示文件格式不正确。原因：未开启FastGPT对docx内嵌图片的解析支持，或文档存在损坏的图片嵌入结构。
- 现象：知识库原文下载链接通过nginx代理后无法正常访问。原因：未配置完整的nginx代理路径规则，未覆盖知识库静态资源的访问路径。

## 怎么确认配好了
- 执行预设的curl请求获取知识库文件列表，确认返回结果包含已上传的预算类文档。
- 上传带内嵌图片的docx文档，确认解析过程无格式报错提示。
- 发起检索请求，检查返回结果的相似度阈值符合预设范围，且召回数量符合单次搜索上限要求。
- 验证知识库原文下载链接可通过配置的nginx代理正常访问，无跳转异常。
