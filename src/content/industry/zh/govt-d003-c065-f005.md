# 勘察设计的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
勘察设计的台账数据主要来源于现场踏勘记录、岩土勘察报告、施工图设计文件、报审审批文档等。数据更新节奏随项目节点推进，完成一次勘察点位核验、图纸版本更新后即生成新的台账条目。单份台账文档包含项目编号、勘察点位坐标、岩土承载力特征值（单位kPa）、设计荷载值、图纸版本号、报审日期等固定字段，同时关联dwg格式的施工图纸、pdf格式的审查意见等附件文件，单批次台账可包含数十至上百条点位记录。

## 这些特征在「工具调用与插件」这一环带来什么约束
勘察设计台账包含专业岩土参数与图纸附件，工具调用需支持dwg、pdf格式的文件解析，同时需校验参数的专业单位与取值范围，避免错误数据流入报告。台账数据随项目节点不定期更新，工具调用需支持增量同步与批量处理，单次处理的条目数需匹配项目规模。部分大型勘察项目的图纸解析耗时较长，工具调用需配置合理的超时阈值，避免任务中断。多点位台账的汇总需循环处理单条记录，工具调用需支持数组类型的入参绑定，确保每个点位的台账数据被正确处理，需遵循FastGPT v4.17.0的插件配置规范。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 设为 `auto` | 自动匹配台账解析、参数校验、报告生成等多类工具，适配勘察设计多环节的调用需求 |
| 单次工具调用上限 | 前10条 | 避免单次处理过多点位数据导致超时，符合勘察设计台账单批次处理的合理规模 |
| 文件解析格式 | 仅开启dwg、pdf | 过滤非勘察设计相关文件格式，减少无效解析开销 |
| 参数校验开关 | 开启 | 校验岩土参数、荷载数值的专业单位与取值范围，确保报告数据的专业性 |
| `functionCall` 超时设置 | 600秒 | 适配大型勘察项目图纸解析的耗时需求，避免中途中断任务 |
| 批量任务处理模式 | 异步触发 | 支持多批次台账数据的并行处理，提升调用效率 |

## 容易做错的三处
- 工作流中添加自定义插件后无输入输出参数显示。原因是未在插件配置中声明入参出参的类型与字段名，未匹配FastGPT v4.17.0的插件注册要求。
- 对话上传勘察图纸文件后解析报错。原因是未配置勘察设计专用的dwg/pdf解析插件，或上传文件大小超过1000 MB的限制。
- 调用聊天接口响应缓慢。原因是未限制单次工具调用的台账条数，或未开启批量任务的异步处理模式。

## 怎么确认配好了
- 上传一份dwg格式的勘察点位台账文件，查看解析后提取的字段是否包含项目编号、岩土承载力特征值等核心内容。
- 在工作流中添加自定义插件，确认输入输出参数栏显示已配置的字段名称与类型。
- 发起包含10条台账数据的测试调用，查看响应时长符合预期。
- 检查工具调用日志，确认未出现参数校验失败或文件解析错误的报错信息。
