# 化工新材料的台账汇总与报告生成：多轮对话与提示词

## 这个品类的数据长什么样
化工新材料的台账数据来源包括生产班组每日填报的投料记录、质检中心的批次检测报告、供应链部门的原料入库出库台账、研发部的配方迭代文档。数据随生产批次实时更新，或每日完成批量同步。单份台账文档包含批次号、原料名称、投料量、检测指标（如纯度、粘度）、入库时间、产出成品型号等字段，字段单位包含千克、百分比、毫帕秒、小时等，不同批次的台账条目相互独立，关联信息需通过批次号关联。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
化工新材料台账的批次关联特性要求多轮对话必须绑定唯一标识，避免跨批次数据混淆。专业的检测指标单位需要提示词明确要求保留，防止模型转换或丢失单位信息，影响报告的专业性。数据更新频繁且单批次文档长度较长，需要限定上下文窗口范围，避免加载冗余或过时数据，导致响应延迟或内容截断。台账包含生产与研发两类内容，提示词需要明确区分查询范围，防止模型混淆不同类型的文档信息，生成不符合业务需求的结果。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，具体参数设置如下：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 上下文窗口大小 | 8000–12000 token | 匹配单批次台账加关联报告的总长度，避免截断关键数据 |
| `chatId` 绑定规则 | 绑定生产批次号 | 确保多轮对话仅关联对应批次的台账数据，避免跨批次混淆 |
| `messages` 历史截断阈值 | 保留最近10轮对话 | 过滤冗余历史，避免上下文过载影响响应速度 |
| 提示词格式校验开关 | 开启 | 强制模型输出符合台账报告的标准格式，匹配业务需求 |
| `variables` 预设参数 | 填入批次号、检测指标范围 | 为模型提供明确的查询约束，缩小搜索范围 |
| 最大响应token数 | 2000–3000 token | 适配单份报告的常规输出长度，避免输出过长 |

## 容易做错的三处
- 现象：调用API上传台账文件后，对话节点无法读取文件内容。原因：未在`variables`中配置文件读取的关联参数，导致模型无法定位上传的文件路径。
- 现象：AI对话节点的输出直接返回至对话界面，无法单独提取为报告结果。原因：未开启独立结果输出设置，默认将节点输出绑定至对话流。
- 现象：连续发起多轮查询后，模型遗忘之前指定的批次号，生成错误的台账汇总。原因：未绑定`chatId`到固定批次号，导致上下文丢失批次关联信息。

## 怎么确认配好了
- 输入测试批次号，查看模型是否仅返回对应批次的台账数据，确认`chatId`绑定生效。
- 触发对话节点，检查节点输出是否仅包含报告内容，无额外对话提示，确认输出设置正确。
- 连续发起3轮关于不同批次的查询，确认模型能正确区分批次，验证上下文记忆功能正常。
- 提交自定义JSON格式要求，检查模型输出是否符合预设的字段结构，确认格式校验开关生效。
