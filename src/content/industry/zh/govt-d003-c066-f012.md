# 化工新材料的台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
化工新材料的台账数据主要来源于生产执行系统、质检部门的纸质报告电子化存档、仓库库存管理系统。数据更新节奏随生产批次与库存变动触发，单次生产完成后更新对应批次的台账信息，每日完成全库存盘点更新。台账文档多为结构化表格格式，包含材料牌号、批次号、生产批号、纯度值、库存量、入库日期、检验合格标识等字段，单位涉及百分比、千克、立方米、件等。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据来源包含多系统结构化与非结构化内容，部署时需同时兼容关系型与非关系型数据库，需分别配置对应连接参数。数据更新频率较高且并发导入场景较多，需调整数据库连接池的最大连接数，避免并发请求耗尽连接。台账字段包含特定行业单位与校验规则，部署时需配置文件校验密钥以保障导入数据的格式合法性。化工材料台账可能包含敏感生产信息，升级时需确保存储配置符合企业数据安全规范，避免数据泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MONGODB_URI` | `mongodb://chem_admin:secure_pass@db-host:27017/chem_ledger?authSource=admin` | 存储非结构化的质检报告附件与历史台账快照 |
| `PG_URL` | `postgresql://chem_user:db_pass@db-host:5432/chemical_material?sslmode=require` | 存储结构化台账主数据，支持复杂的批次与库存查询 |
| `DB_MAX_LINK` | `20–30 个` | 应对多批次材料同时导入的并发连接需求，避免连接耗尽 |
| `REDIS_URL` | `redis://:redis_pass@cache-host:6379/0` | 缓存高频查询的台账字段映射与用户权限配置，加速报告生成 |
| `STORAGE_S3_ENDPOINT` | `https://s3.enterprise-chemical-storage.com` | 存储批量导出的台账报告与质检附件，保障数据存储安全 |
| `FE_DOMAIN` | `https://fastgpt.chemical-enterprise.com` | 配置前端访问域名，用于生成合法的报告跳转链接 |

## 容易做错的三处
- 现象：执行`docker build -f ./projects/`命令时返回依赖版本不匹配报错。原因：未使用FastGPT v4.17.0指定的Node.js与Python版本进行构建，或未正确安装项目依赖包。
- 现象：本地部署后无法正常创建台账数据库。原因：未正确填写`PG_URL`或`MONGODB_URI`的连接参数，或数据库未开放部署服务器的访问权限。
- 现象：生成的台账报告无法正常跳转至企业微信OA链接。原因：未正确配置`FE_DOMAIN`为企业合法域名，导致OA系统拦截了跨域跳转请求。

## 怎么确认配好了
- 执行数据库连接测试命令，验证`PG_URL`与`MONGODB_URI`的连接状态，确认无超时或权限报错。
- 上传一份标准化工台账Excel文件，执行导入测试，确认所有字段均可正常解析并存储至对应数据库。
- 访问`FE_DOMAIN`绑定的前端地址，确认台账汇总页面可正常加载并显示测试导入的批次数据。
- 生成一份简易台账报告，确认报告中包含正确的材料信息与单位，且跳转链接可正常访问。
