# 危化品储运的台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
危化品储运的台账数据来源于储运现场巡检记录、入库出库单据、罐体监测系统导出的CSV文件，更新节奏为每班次或每日更新。文档结构为固定表头的结构化CSV格式，字段包含危化品名称、规格型号、存储位置、入库量（吨）、出库量（吨）、巡检时间、温度（℃）、压力（MPa）、经办人等，单位统一且固定，单条数据长度适中但整体数据量随储运规模增长。

## 这些特征在「知识库检索与召回」这一环带来什么约束
固定表头的CSV结构要求检索时需匹配字段名与单位，不能依赖泛化语义匹配；高频更新节奏要求知识库需配置定时同步任务，确保召回数据为最新台账内容；固定单位与数值类型要求检索时需过滤非匹配单位的结果，避免无效数据混入；中文字段名的广泛使用增加了编码解析的风险，需确保导入格式符合标准要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配危化品台账的精准字段与数值需求，过滤低相关性结果 |
| `limit` | 前10条 | 单次召回适量台账条目，满足汇总与报告生成的批量处理需求 |
| `searchMode` | 精准匹配 | 适配结构化台账的固定字段与单位，避免语义模糊匹配带来的错误结果 |
| `usingReRank` | 开启 | 对召回结果按相关性二次排序，优化台账字段匹配的准确性 |
| `datasetSearchUsingExtensionQuery` | 关闭 | 危化品台账数据结构固定，扩展查询词易导致非目标字段的匹配 |
| `collectionIds` | `["65a1b2c3d4e5f67890abcdef"]` | 限定检索范围为危化品储运专属台账集合，避免混入其他品类数据 |

## 容易做错的三处
- CSV文件导入知识库后中文字段出现乱码，英文内容正常。原因是未指定CSV文件的编码格式为UTF-8，导致中文字节解析错误。
- 错误使用文本数据集功能上传结构化CSV台账。原因是未意识到结构化CSV需通过模版导入功能匹配固定字段，文本数据集仅支持非结构化文本，无法保留字段关联关系。
- 召回结果条数与配置的`limit`取值不符，出现大量冗余或缺失的台账条目。原因是未关闭`datasetSearchUsingExtensionQuery`，扩展查询词导致匹配到非目标字段的内容。

## 怎么确认配好了
- 上传一份测试用的危化品CSV台账，检查导入后字段是否完整显示，无乱码情况。
- 发起一个台账汇总相关的查询，核对召回结果的条数与配置的`limit`取值一致。
- 查看知识库的向量存储日志，确认召回结果的相似度处于配置的`similarity`区间内。
- 检查磁盘占用统计，确认知识库存储包含原文件、分割后的块与嵌入向量，总占用量符合部署规模要求。
