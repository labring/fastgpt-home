# 发电装备制造的台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
发电装备制造的台账数据主要来自设备出厂合格证、运行日志、定期检修记录、企业设备管理系统。数据更新节奏分为日常运行参数每日同步、月度检修记录每周更新、年度大修后全量台账更新。单条台账文档包含设备编号、型号、额定功率、运行电压阈值、检修周期、上次检修时间等字段，单位多为kV、A、小时、天，结构固定且字段关联紧密。

## 这些特征在「知识库检索与召回」这一环带来什么约束
发电装备台账的字段与单位关联紧密，检索时需精准匹配参数单位，避免因语义模糊召回错误的设备数据。单条文档长度较长，分块处理时需保留字段关联关系，防止拆分后丢失设备编号与运行参数的对应信息。数据更新存在日常增量与年度全量两种场景，知识库检索环节需适配增量索引与全量重建的配置，确保检索结果与最新台账数据同步。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 发电装备台账有明确的参数阈值，该区间可过滤低匹配度的无关文档，保留精准匹配的设备数据 |
| `limit` | `前8–12条` | 单条台账数据条目较多，该取值范围可控制返回结果总量，适配常规上下文窗口限制 |
| `searchMode` | `vector+keyword` | 需同时匹配语义关联的运行问题与设备编号、参数单位等精准字段，兼顾语义召回与精准匹配 |
| `usingReRank` | `开启` | 长文档分块后可能存在语义重复的片段，重排可优化结果排序，提升核心台账数据的召回优先级 |
| `datasetSearchUsingExtensionQuery` | `关闭` | 台账数据结构固定，无需扩展查询词，避免因额外语义匹配引入无关的设备文档 |
| `collectionIds` | `指定专属发电装备台账集合ID` | 隔离其他品类的知识库数据，确保检索范围仅覆盖当前场景的台账文档 |

## 容易做错的三处
- 现象是调用API创建知识库时，未获取到解析状态返回值，原因是未开启API的状态同步回调配置，无法感知解析中、就绪、失败的状态变化。
- 现象是导入发电装备台账数据集后，数据集状态持续显示“索引中”，原因是未按数据更新节奏配置全量/增量索引触发规则，且单条台账文档长度超出默认分块上限。
- 现象是检索返回的语义相似度值达到10000+，原因是误用了非适配结构化数据的向量模型，未切换到对应模型的匹配区间，导致数值计算逻辑异常。

## 怎么确认配好了
- 查看知识库数据集的索引状态，确认在导入完成后15分钟内转为“就绪”状态。
- 执行测试检索，输入具体设备型号关键词，查看返回结果的`similarity`值是否落在预设区间内。
- 调用工作流测试接口，确认执行链路从问题优化到AI对话完整走完，无中途中断的情况。
- 检查API返回的解析状态字段，确认包含解析中、就绪、失败的明确标识信息。
