# 发电集团的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
发电集团的台账数据主要来自生产运行管控系统、燃料管理平台、财务核算模块与设备运维档案。数据更新节奏按生产班次或自然日更新，单台账文档包含设备运行时长、发电负荷、燃料消耗量、检修记录、核算成本等字段，单位涵盖小时、兆瓦、吨、元等，文档结构按业务模块分块存储，单份台账文档长度跨度较大，从数百字符到数千字符不等。

## 这些特征在「工具调用与插件」这一环带来什么约束
发电集团台账数据的多源异构特性，要求工具调用环节需同时对接生产、燃料、财务等多个独立系统的接口，需配置跨源数据聚合的插件逻辑。数据按班次或日更新的节奏，决定了工具调用的触发时机需匹配业务数据产出周期，避免调用未完成更新的数据源。字段与单位的多样性，要求插件内置标准化映射规则，将不同系统的自定义字段转换为统一格式。单文档长度跨度大的特点，要求工具调用的上下文处理逻辑适配不同长度的输入内容，避免截断关键业务信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工具调用超时设置 | 600–900 秒 | 适配多源数据聚合的平均响应周期 |
| `toolChoice` | auto | 适配发电集团台账数据的多源调用需求，自动匹配对应系统接口 |
| 插件字段映射规则 | 预设发电业务字段映射表 | 匹配不同系统台账字段与单位的异构特性 |
| 上下文长度限制 | 8000–12000 token | 适配单份台账文档的长度跨度 |
| 工具调用重试次数 | 2 次 | 抵消单次网络波动或系统临时延迟的影响 |
| `functionCall` | 开启参数格式校验 | 确保传入的台账数据字段符合业务规范 |

## 容易做错的三处
- 调用后长时间无响应，状态码显示504或请求超时。原因是未适配发电集团多源数据聚合的长响应周期，超时设置过短。
- 工具调用结果仅在重新进入会话后显示，当前会话对话框无结果。原因是未开启工具调用结果的实时渲染配置，导致结果缓存延迟加载。

## 怎么确认配好了
- 发起一次跨系统台账数据调用，检查工具调用日志中的响应时长是否符合预设的超时设置区间。
- 触发工具调用后，查看当前会话对话框是否实时显示工具调用结果，确认渲染配置生效。
- 调用包含多字段的台账数据，检查插件返回的结果是否完成了字段与单位的标准化映射。
