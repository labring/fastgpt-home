# 国有产业基金的台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
国有产业基金的数据主要来源于国资监管报送系统、基金管理人运营台账、项目投后管理档案及财政拨付凭证。数据更新节奏为月度更新基础台账、季度更新运营汇总、年度更新绩效报告，临时项目出资、退出变动实时同步。单份文档多为结构化表格形式，包含基金主体名称、出资方类型、认缴金额、实缴进度、投资项目清单、退出收益、持股比例等字段，金额单位多为万元或亿元，时间单位为自然年月，持股比例为百分比数值。

## 这些特征在「知识库检索与召回」这一环带来什么约束
国有产业基金的结构化数据特征要求检索需优先匹配精准字段，避免使用泛化全文检索的逻辑，防止混入无关的财政政策文档。月度高频更新的特性要求知识库同步周期需匹配更新节奏，否则会出现数据滞后的情况。多字段关联的台账内容，需要检索系统支持按字段组合筛选，例如同时匹配基金名称和出资时间。单批次检索的条目数量需合理控制，避免超出上下文窗口导致报告生成截断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.72–0.88 | 国有产业基金台账有明确的字段匹配规则，阈值过低会混入无关的财政政策文档，阈值过高会遗漏部分关联度符合要求的台账条目 |
| `limit` | 前8–12条 | 单份台账汇总需覆盖最多10个核心基金项目，过多的检索结果会超出上下文窗口，影响报告生成的连贯性 |
| `usingReRank` | 开启 | 台账数据的字段关联强度较高，重排功能可基于语义关联重新排序结果，提升核心字段匹配条目的展示优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 国有产业基金存在大量专属术语，例如“实缴出资额”“退出年化收益率”，扩展查询可覆盖术语的同义词与近义词，提升检索召回范围 |
| `searchMode` | hybrid | 结合向量检索与字段匹配，兼顾语义关联与精准字段匹配，适配台账的结构化与半结构化混合数据特征 |
| `collectionIds` | 国有产业基金专属数据集ID | 限定检索范围仅覆盖本品类的台账数据，避免混入其他品类的知识库内容 |

## 容易做错的三处
- 检索结果包含大量非基金台账的无关文档，原因是未限定`collectionIds`参数为国有产业基金专属数据集，导致检索范围覆盖了其他品类的知识库内容。
- 问答时无法召回最新的月度台账更新数据，原因是知识库增量同步周期设置为每周，未匹配台账月度更新的节奏，导致最新数据未及时同步至检索库。
- 检索结果的相关度偏低，部分正确的出资进度条目未排在前列，原因是未开启`usingReRank`功能，仅依赖基础向量检索的初始排序，无法体现字段关联的优先级。

## 怎么确认配好了
- 登录FastGPT v4.17.0的知识库管理后台，查看对应数据集的同步日志，确认月度台账的增量同步任务每日触发并完成。
- 输入测试查询“某国有产业基金2024年上半年实缴出资进度”，检查返回结果是否包含对应基金的实缴金额、进度百分比等核心字段的准确条目。
- 进入检索配置面板，确认`usingReRank`、`datasetSearchUsingExtensionQuery`均处于开启状态，`similarity`阈值设置在0.72–0.88区间内。
- 测试批量检索10条不同基金的台账数据，确认单次返回的条目数在8–12条范围内，未出现超出上下文窗口的截断情况。
