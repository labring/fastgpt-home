# 国有资本投资公司的台账汇总与报告生成：多轮对话与提示词

## 这个品类的数据长什么样
国有资本投资公司的台账数据主要来源于国资监管平台、集团ERP系统及各子公司上报的月度经营报表。更新节奏为子公司台账每周更新，集团级汇总台账每日同步。单份台账文档包含项目名称、项目编号、出资主体、认缴出资额、实缴出资进度、当期回款金额、责任部门、上报日期等字段，其中金额类字段单位为万元，进度类字段以阶段节点表述。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
台账数据来源分散且更新频率存在差异，多轮对话需先校验用户提问的时间范围与数据更新节点匹配，避免调用过期数据。单台账条目包含多类专业字段，提示词需明确指定提取与汇总规则，防止生成的报告遗漏关键信息。集团级台账条目数量较多，多轮对话中需支持分步筛选，先引导用户明确汇总维度，再逐步生成对应报告，避免单次请求超出承载上限。此外，数据更新频率较高，需在对话中支持动态刷新数据源的操作。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 最大上下文长度 | 8000–12000 token | 承载多轮对话的`messages`历史与台账数据 |
| 单次历史消息保留数 | 前20条 | 控制`messages`参数的长度，避免请求超时 |
| 动态变量绑定 | 绑定台账数据的`variables`字段 | 实现多轮对话中调用最新的子公司台账数据 |
| 对话超时阈值 | 600秒 | 适配台账汇总的复杂计算耗时 |
| 提示词预设模板 | 按项目/出资主体分类 | 匹配国有资本投资公司的台账字段规则 |
| 缓存更新周期 | 24小时 | 匹配集团台账的每日同步节奏 |

## 容易做错的三处
- 现象：对话时出现Request Time报错，界面显示请求超时。原因：未设置合理的对话超时阈值，台账汇总的复杂计算未在预设时间内完成。
- 现象：iframe嵌入的对话框显示英文界面。原因：未配置对应中文的界面参数，未绑定语言相关的`variables`字段。
- 现象：生成的台账汇总报告字段缺失或格式混乱。原因：提示词未明确指定国有资本投资公司台账的专属字段规则，未关联正确的`variables`绑定数据源。

## 怎么确认配好了
- 发起单轮台账汇总请求，核对返回结果包含预设的台账专属字段。
- 发起连续多轮对话，核对系统保留的历史消息数量符合配置规则。
- 触发数据更新操作，核对调用的台账数据与最新同步的数据源匹配。
- 测试iframe嵌入场景，核对对话框显示为中文界面。
