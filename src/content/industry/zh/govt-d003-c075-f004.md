# 国有资本投资公司的台账汇总与报告生成：工作流编排

## 这个品类的数据长什么样
国有资本投资公司的台账数据主要来源于国资监管报送系统、集团内部财务核算模块、子公司定期报送的投资与股权管理报表。数据更新节奏为子公司按周报送基础明细，集团级汇总按月度整合，季度完成最终监管报告用台账。文档以结构化表格为主，包含项目编号、投资金额（单位：万元）、参股比例、子公司主体名称、合规校验标识等字段，部分台账附带审批类非结构化附件。

## 这些特征在「工作流编排」这一环带来什么约束
数据来源分散且更新周期分层，要求工作流配置多源数据拉取节点，完成跨系统字段的标准化映射；结构化字段包含合规校验标识，要求工作流嵌入合规校验环节，过滤异常数据后再进入汇总环节；非结构化附件的存在，要求工作流支持附件解析与格式转换节点，适配不同类型的监管报送要求；数据体量随集团层级扩张增长，要求工作流配置上下文长度适配的节点，避免单次处理超出模型限制。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 定时触发周期 | 按周/月/季分段配置，例如周度拉取子公司数据、月度整合集团数据、季度生成监管报告 | 匹配国有资本投资公司台账的分层更新节奏 |
| 多源数据拉取节点 | 按数据来源绑定对应系统接口，单次拉取上限设为1000条 | 适配子公司报送的数据体量，避免接口超时 |
| 变量更新触发 | `variables` 变更后自动触发下游节点 | 解决变量未自动更新的问题，确保台账数据同步 |
| 上下文长度设置 | 8000–12000 token | 适配大型节点数据结构的处理需求，避免超出模型限制 |
| 附件格式转换 | 按实测标定的base64转换脚本 | 适配图片、PDF附件的标准化处理，满足监管报送的格式要求 |
| 节点ID配置 | `nodeId` 绑定对应数据拉取节点 | 精准定位工作流中的数据来源节点，避免调度错误 |
| 异常节点重试 | 失败后重试2次，间隔60秒 | 应对网络波动或系统临时卡顿，保障工作流稳定性 |

## 容易做错的三处
- 现象：工作流运行后`variables`字段未自动更新，台账数据未同步到下游节点。原因：未配置变量触发规则，仅手动触发节点导致数据未联动。
- 现象：大型节点数据结构运行时触发上下文超限报错，返回状态码413。原因：未根据数据体量调整上下文长度设置，直接使用默认参数处理超大规模台账数据。
- 现象：图片附件导入后无法生成base64编码，工作流节点返回空结果。原因：未配置格式转换脚本，或脚本未正确绑定图片导入节点的输出参数。

## 怎么确认配好了
- 手动触发一次工作流，检查多源数据拉取节点的输出是否包含所有配置的数据源字段。
- 查看定时任务日志，确认按设定周期自动触发工作流的记录存在。
- 导入大型节点数据结构，核对上下文长度设置是否匹配当前数据体量。
- 上传测试图片附件，确认base64编码转换节点输出非空结果。
