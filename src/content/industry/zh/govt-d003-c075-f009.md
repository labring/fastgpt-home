# 国有资本投资公司的台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
国有资本投资公司的台账数据主要来源于国资监管平台、内部ERP系统、参股企业月度报送文件。数据更新分为月度批量更新与实时异动更新两类，月度批量更新在每月终了后3个工作日内完成，实时异动更新针对单笔投资的进度变化即时同步。台账文档为结构化表格格式，包含项目ID、投资主体、被投企业名称、出资额（单位：万元）、实缴到位金额、监管主体层级、项目立项时间等字段，部分关联报告还包含项目可行性研究的简短文本附件。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源数据的格式差异要求模型接入时配置统一的字段映射规则，避免不同来源的数据导致模型识别混乱。月度批量更新的数据量较大，单次输入的上下文长度容易超出基础配置，需要调整上下文参数以覆盖完整的台账数据。台账数据的严谨性要求模型输出的字段准确性，因此需要限制模型的随机性参数。实时异动数据的快速生成需求，要求模型调用的端点与权限配置适配国资系统的网络访问限制。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 覆盖3期月度台账的结构化数据与关联报告文本，避免上下文截断导致字段丢失 |
| `maxTokens` | 4000–6000 token | 限制单轮报告生成的输出长度，符合国资报告的规范篇幅要求 |
| `temperature` | 0.1–0.3 | 保持结构化字段输出的准确性，减少无关信息的生成，适配台账数据的严谨性要求 |
| `AIPROXY_API_ENDPOINT` | 部署所在区域的官方代理端点 | 适配国资系统的网络访问限制，确保模型调用的稳定性 |
| `AIPROXY_API_TOKEN` | 企业专属密钥配置 | 符合国资监管的安全要求，避免未授权的模型调用 |
| `toolChoice` | none | 台账汇总与报告生成无需调用外部工具，直接基于结构化数据生成即可 |

## 容易做错的三处
- 现象：调用GPT-4o mini时输入含“350”的短文本触发400报错，更换其他模型后恢复正常。原因：模型接入配置中`AIPROXY_API_TOKEN`的权限未覆盖该模型的特定请求规则，或代理端点未适配该模型的输入格式要求。
- 现象：生成报告时仅返回完整内容，无流式输出效果。原因：模型接入配置中未开启对应模型的流式调用设置，或代理端点未支持流式传输。
- 现象：Reranker模型调用失败，无法完成内容重排。原因：未正确配置`AIPROXY_API_TOKEN`的重排模型专属权限，或代理端点未指向重排模型的正确路径。

## 怎么确认配好了
- 上传单条含“350”的台账测试数据，调用GPT-4o mini，检查是否触发400报错，若未触发则说明模型权限与端点配置正常。
- 开启测试生成功能，观察返回内容是否分批次推送，确认流式输出是否生效。
- 生成月度台账汇总报告，检查报告中所有字段的单位与取值是否统一，确认上下文未被截断。
- 调用Reranker模型测试，检查是否能正常返回重排后的结果，确认token与权限配置正确。
