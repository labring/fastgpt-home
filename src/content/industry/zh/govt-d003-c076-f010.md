# 国有资本运营公司的台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
国有资本运营公司的台账数据主要来自国资监管平台报送数据、集团本部及各级子公司的财务核算系统、产权登记系统。更新节奏为月度基础数据每日同步，季度全量汇总台账每季度末5个工作日内完成更新。单条台账文档包含主体识别码、所属层级、资产总额、长期股权投资金额、当期营收、上缴利润金额、报告起始与结束日期等字段，字段单位统一为万元与自然日，无自定义非标准化字段。

## 这些特征在「知识库检索与召回」这一环带来什么约束
国有资本运营公司的台账数据多源分散、更新节奏分层，且字段格式标准化，这对知识库检索与召回环节带来多重约束。多源数据需要关联多个数据集才能完成完整召回，分层更新要求区分全量与增量数据集的召回优先级，避免过期数据混入结果。标准化字段需要精准匹配关键词，避免模糊召回带来的无效内容，同时单次召回的内容量需要适配后续台账汇总与报告生成的上下文窗口，避免超出处理上限。此外，台账数据的量化字段较多，需要兼顾数值匹配与文本描述的召回准确性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本编写。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `collectionIds` | 按国资监管报送、集团财务、产权登记三类分别配置数据集ID集合，包含2-4个数据集 | 覆盖台账数据的全部来源，避免遗漏关键子公司的台账信息 |
| `limit` | 前 20 条 | 国有资本运营公司单份台账报告需整合多子公司数据，20条可覆盖典型汇总需求，同时避免上下文溢出 |
| `similarity` | 0.72–0.78 | 台账数据包含固定字段与量化数值，该区间可过滤低匹配度的无关数据，同时保留同层级子公司的相关台账 |
| `searchMode` | 精准匹配字段 | 台账数据有标准化字段格式，精准匹配可提升字段类关键词的召回准确率 |
| `usingReRank` | 开启 | 多数据集召回的结果存在冗余，重排可优先返回与台账汇总需求最相关的内容 |
| `datasetSearchUsingExtensionQuery` | 关闭 | 台账数据字段标准化，无需扩展查询词即可精准匹配，避免引入无关内容 |

## 容易做错的三处
- 现象：调用独立知识库搜索接口时返回结果条数符合配置的`limit`值，但工作流内的知识库检索节点返回结果条数远低于配置值。原因：未区分独立检索与工作流内检索的参数配置，工作流内的检索节点默认引用上限更低，未单独调整适配国有资本运营公司的台账数据量需求。
- 现象：检索结果中包含上一季度的过期台账数据。原因：未将全量更新的季度台账数据集与增量更新的月度台账数据集分别配置`collectionIds`，导致过期数据被一同召回。
- 现象：检索结果包含大量与台账字段无关的文档。原因：将`searchMode`设置为模糊匹配，未针对标准化台账字段使用精准匹配模式，导致无关内容被召回。

## 怎么确认配好了
- 查看数据集关联配置页面，确认`collectionIds`参数包含国资监管报送、集团财务、产权登记三类对应的数据集ID。
- 执行模拟检索，输入某子公司的主体识别码，核对返回结果的字段是否包含资产总额、营收净额等台账核心字段，且匹配度处于0.72–0.78区间内。
- 测试工作流内的检索节点，确认返回结果条数与独立检索节点的配置`limit`值一致。
- 检查重排功能是否开启，确认检索结果的排序与台账汇总的核心需求匹配。
