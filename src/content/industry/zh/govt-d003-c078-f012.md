# 城市水务的台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
城市水务的台账数据来自管网压力监测节点、水厂中控系统、排水泵站采集设备与人工巡检记录。数据更新节奏分为实时（核心监测点）、每小时（常规巡检数据）、每日（汇总报表）三类。单条设备台账文档包含监测点编码、采集时间戳、水压值、流量值、浊度值、设备运行状态字段，单位分别为MPa、m³/h、NTU与启停状态标识。月度汇总台账按区域、设备类型分组，整合单日数据生成统计条目。

## 这些特征在「部署与升级」这一环带来什么约束
城市水务台账数据的多源实时接入与高频更新，要求部署阶段预留足够的数据库连接资源，避免并发写入超时。不同更新节奏的数据源需要匹配差异化的定时任务调度规则，升级过程中若调整数据源同步逻辑，需避免中断核心监测节点的数据采集链路。台账文档长度跨度大，从单条监测数据到区域汇总报表，要求向量存储与上下文窗口配置适配不同长度的文本处理需求。同时水务数据的字段标准化程度较高，部署阶段需提前配置字段映射规则，避免升级后出现字段解析异常。

## 配置怎么定
以下配置项适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `200–300` | 适配多监测点并发写入的数据库连接需求，避免连接池耗尽 |
| `MONGODB_URI` | 指向水务台账专用的分片MongoDB实例 | 存储非结构化的巡检记录与汇总报表，支持大文本字段查询 |
| `REDIS_URL` | 配置为高可用集群地址 | 缓存实时监测数据与用户会话信息，降低数据库查询压力 |
| `STORAGE_S3_ENDPOINT` | 指向水务内网对象存储服务地址 | 存储原始采集数据与生成的报告文件，保障数据本地化合规 |
| `ROOT_KEY` | 按部署环境生成高强度随机字符串 | 用于系统管理员身份验证，避免默认密钥导致的未授权访问 |
| `FE_DOMAIN` | 填写水务内网部署的前端访问域名 | 限制前端资源的跨域访问范围，适配内网使用场景 |

## 容易做错的三处
- 升级后进入工作流提示配置错误，无法加载数据源：原因是升级过程中未同步更新`MONGODB_URI`的权限配置，导致应用无法连接水务台账数据库。
- 保存模型配置后聊天自动切换为其他大模型：原因是升级后前端配置缓存未清空，或`FILE_TOKEN_KEY`未正确配置导致会话状态异常。
- 登录时提示用户名密码错误：原因是部署时未正确初始化`ROOT_KEY`关联的管理员账号，或数据库初始化脚本未执行完成。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`DB_MAX_LINK`配置的连接池可同时承载至少200个并发连接。
- 上传一份水务月度汇总台账文档，触发报告生成任务，确认生成的报告文件可通过`STORAGE_S3_ENDPOINT`对应的存储地址正常下载。
- 使用管理员账号登录系统，验证`FE_DOMAIN`配置的域名可正常访问前端页面，且会话登录状态无异常。
- 模拟实时监测数据写入，确认数据可正常同步至数据库，无字段解析或写入失败的日志记录。
