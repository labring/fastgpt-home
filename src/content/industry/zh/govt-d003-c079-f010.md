# 城市燃气的台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
城市燃气的台账数据主要来源于场站巡检日志、用户缴费档案、管网运维记录三类系统。数据更新节奏为巡检数据实时同步至平台，缴费台账每日更新，管网基础数据每月完成校准。单份台账文档多为包含多工作表的Excel文件或带多级目录的docx文件，包含场站编号、巡检时间、管道压力值、用户开户地址、缴费金额等字段，单位涵盖千帕、立方米、人民币元等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多工作表的Excel与多级目录docx格式的台账，会导致基础检索无法覆盖所有子表或子目录内的内容，需调整检索模式以支持跨结构召回。字段包含大量专业单位与标识性编号，检索时需匹配字段名与单位才能召回有效结果，否则易返回无关的通用燃气知识。高频更新的实时巡检数据与月度校准的管网数据，要求检索环节适配不同更新频率的数据源，避免召回过期或未同步的内容。单份文档长度跨度大，需适配短文本巡检记录与长文本报告的分块与召回逻辑。

## 配置怎么定
本文基于FastGPT v4.17.0版本进行配置说明，具体参数配置如下：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.65–0.75 | 适配燃气台账的专业字段匹配精度，避免召回无关的通用燃气文档 |
| `limit` | 前8–12条 | 覆盖单份长文档的多段落分块，同时控制上下文窗口占用不超过12000 token |
| `searchMode` | 全文检索 | 支持跨工作表、多级目录的文档内容召回，适配多格式台账的结构 |
| `usingReRank` | 开启 | 对召回的结果按相关性重新排序，过滤掉字段匹配但语义无关的结果 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展检索关键词，匹配台账中的场站编号、用户编号等标识字段 |
| `collectionIds` | 按燃气台账专属数据集填写 | 隔离其他品类的知识库数据，避免召回非燃气类的无关内容 |

## 容易做错的三处
- 现象：调用知识库检索接口返回格式不支持错误，浏览器访问链接可正常下载docx文件。原因：未配置针对多工作表Excel或多级目录docx的扩展检索适配，或接口未正确处理内嵌文档内容。
- 现象：检索结果包含大量非燃气台账的无关内容，召回条数远超设定上限。原因：未指定`collectionIds`为专属燃气台账数据集，或`similarity`阈值设置过低。
- 现象：多级目录下的子文档未被检索到，仅根目录文档被召回。原因：未开启`searchMode`为全文检索模式，或未配置`datasetSearchUsingExtensionQuery`支持多级目录遍历。

## 怎么确认配好了
- 上传一份带多级目录的docx燃气台账文档，执行检索测试，确认子目录内的内容被成功召回。
- 传入场站编号作为检索关键词，确认返回结果包含匹配的场站编号、压力值等专业字段，无关结果被有效过滤。
- 查看检索日志，确认`searchMode`、`usingReRank`等配置参数被正确加载，无参数冲突提示。
- 模拟用户选择跳过检索的操作，确认检索环节未触发，直接进入后续的台账汇总与报告生成流程。
