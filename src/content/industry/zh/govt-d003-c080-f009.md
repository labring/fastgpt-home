# 城投平台的台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
城投平台的台账数据主要来源于内部项目管理系统、财务核算系统、融资台账系统。核心台账分为每日增量更新的项目执行台账，与每月5日前更新的月度汇总台账。文档以多页结构化表格为主要形式，单页字段包含项目编号、项目类型、责任主体、预算总额、实际支出、完成节点、备注，字段单位多为万元、亿元、自然日，部分台账会附带少量非结构化的项目补充说明文本。

## 这些特征在「模型接入与配置」这一环带来什么约束
结构化多字段的台账格式要求模型能精准匹配字段名称与单位，因此需限制模型的随机性输出；月度汇总台账的单文档长度可达数千字符，需配置足够的上下文窗口以承载完整的输入数据；每日增量同步的特性要求模型能快速区分新老数据，避免重复处理历史台账内容；部分台账附带的非结构化说明文本，需模型能同时处理结构化与非结构化数据的混合输入，因此需配置可同时处理两类数据的模型调用参数。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配月度汇总台账的多页结构化内容，承载完整的上下文信息 |
| `maxTokens` | 2000–3000 token | 满足单份台账汇总报告的生成长度，避免输出截断 |
| `temperature` | 0.1–0.3 | 降低模型发散性，确保字段匹配与单位识别的准确性 |
| `toolChoice` | auto | 允许模型自主选择是否调用工具辅助台账数据的汇总计算 |
| `AIPROXY_API_ENDPOINT` | 按FastGPT官方提供的对应模型专属接入地址填写 | 适配国内模型的访问路径，避免跨区域访问延迟 |
| `AIPROXY_API_TOKEN` | 绑定对应模型的专属密钥 | 确保接口调用的身份验证有效，防止令牌无效报错 |

## 容易做错的三处
- 现象：配置`AIPROXY_API_TOKEN`后界面显示无效令牌，接口返回401状态码。原因：未将令牌绑定至对应模型的专属权限，或粘贴密钥时混入了多余空格与换行符。
- 现象：选择GPT-4o mini模型输入“350怎么样”触发400报错，更换其他模型后请求正常。原因：该模型的`maxTokens`阈值低于当前请求的最小输入输出长度，或请求格式未匹配模型要求的输入结构。
- 现象：模型生成的汇总报告需等待全部内容完成后一次性返回，无分段流式输出。原因：未启用FastGPT的流式响应配置开关，或接口未正确适配流式传输的协议要求。

## 怎么确认配好了
- 提交包含10条以上结构化台账字段的测试数据，检查接口返回状态码为200，无令牌无效或格式错误提示。
- 查看模型返回的汇总内容，确认字段与输入台账的字段完全匹配，单位识别准确无误。
- 测试输入简短测试指令，观察是否有流式分段返回的内容，确认流式配置生效。
- 提交月度全量台账数据，检查生成的报告长度符合`maxTokens`的配置范围，无输出截断情况。
