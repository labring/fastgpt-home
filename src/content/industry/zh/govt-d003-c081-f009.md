# 基础化工的台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
基础化工的台账数据主要来自生产车间DCS控制系统、物料流转ERP模块、质检实验室LIMS系统三类核心数据源。数据更新节奏为每班（8小时）同步一次生产投料、反应参数、产出数据，每日同步一次质检结果与物料库存数据。单条台账文档包含物料编码、批次号、投料量、反应温度、停留时间、合格产出量、质检合格率等固定字段，单位统一为吨、摄氏度、小时、百分比，部分车间会新增自定义工艺参数字段。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的台账数据存在字段名不一致的问题，例如不同车间对“合格产出量”的命名可能存在差异，要求模型接入时需先配置统一的字段映射规则，避免模型混淆不同系统的字段定义。高频更新的生产数据要求模型上下文窗口能覆盖至少3个生产班次的历史台账，否则无法完成跨班次的汇总分析。长周期的月度报告生成需要处理累计数百条台账数据，需限制生成token数量防止内容截断。此外，化工台账包含敏感工艺参数，需通过内部网络传输数据，不能直接调用公网模型接口。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 覆盖至少3个生产班次的历史台账数据，保障跨班次汇总的完整性 |
| `maxTokens` | 16000 token | 适配月度台账报告的生成长度，避免输出内容被截断 |
| `quoteMaxToken` | 2000 token | 限制单条引用的质检报告片段长度，防止上下文过载 |
| `temperature` | 0.1–0.3 | 降低生成随机性，保障台账数据的格式与数值准确性 |
| `AIPROXY_API_ENDPOINT` | 企业内部化工云代理地址 | 规避公网调用风险，适配企业内部网络环境 |
| `AIPROXY_API_TOKEN` | 企业专属代理令牌 | 验证内部调用权限，保障敏感工艺数据的传输安全 |

## 容易做错的三处
- 现象：模型输出的台账字段出现多余空格或字母大写，原因：未在提示词中明确要求保留原始字段格式与大小写，且配置的`temperature`过高导致生成随机性过强。
- 现象：模型调用返回403权限错误，原因：未配置正确的`AIPROXY_API_TOKEN`或代理地址，导致内部权限验证失败。
- 现象：月度报告生成超时，原因：`maxContext`设置过小，未覆盖足够的历史台账数据，导致模型多次调用上下文触发超时，或`maxTokens`设置超出当前模型的最大生成上限。

## 怎么确认配好了
- 进入FastGPT v4.17.0的模型测试页面，输入单条台账数据的汇总请求，检查输出是否保留原始字段的大小写与空格格式。
- 查看模型调用日志，确认请求地址与`AIPROXY_API_ENDPOINT`一致，令牌验证无报错。
- 导入10条连续班次的台账数据，触发月度报告生成，检查输出内容是否完整覆盖所有输入数据，无截断现象。
- 调整`temperature`至0.2后再次测试，确认输出结果的随机性降低，数据一致性提升。
