# 基础电信运营的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
基础电信运营的台账数据来源为计费系统、基站运维系统、用户服务工单库与政企客户对接系统。数据更新节奏覆盖实时（计费流量、通话记录）、小时级（节点负载）与日级（巡检台账）。文档多为结构化表格格式，字段包含基站唯一标识、流量使用量（单位GB）、通话时长（单位分钟）、工单编号、处理状态、统计周期与归属区域，部分台账附带图片格式的巡检点位照片。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 自动匹配多工具，按数据源优先级排序 | 基础电信运营台账需对接计费、运维等多系统，自动匹配可减少手动配置成本 |
| 单次工具调用条目上限 | 前 2000 条 | 单台账数据量较大，限制条目可避免接口超时 |
| 图片处理插件触发规则 | 检测到巡检类台账字段时自动触发 | 仅巡检台账附带图片，按需触发可降低资源消耗 |
| `functionCall` | 强制指定结构化输出格式 | 台账汇总需生成标准报告，结构化输出可确保字段完整性 |
| 工具调用超时时间 | 600 秒 | 电信接口数据量较大，600秒可覆盖多数数据拉取场景 |
| 鉴权方式选择 | 使用应用密钥，不使用账号密钥 | 电信系统接口多要求应用级鉴权，可避免调用报错 |

## 容易做错的三处
- 现象：调用工具时返回“鉴权失败”报错，提示需使用应用密钥。原因：未按配置要求使用应用密钥，误将账号密钥填入鉴权参数。

- 现象：工具调用后未替换图片路径为远程链接。原因：未配置图片处理插件的触发规则，或触发条件与台账字段不匹配。

## 怎么确认配好了
- 触发工具调用测试，查看鉴权日志，确认使用的是应用密钥，未使用账号密钥。
- 调用包含图片的巡检台账，查看输出结果，确认图片路径已替换为远程服务器链接。
- 运行API调用工作流，查看返回结果，确认包含结构化的台账汇总数据。
- 检查工具调用的运行日志，确认单次调用的条目数符合预设要求。
