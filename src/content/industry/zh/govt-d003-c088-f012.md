# 工程咨询监理的台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
工程咨询监理的台账数据来源于现场旁站记录、材料报验单、工序验收单、整改闭环单等业务单据，更新节奏随施工进度波动，单日更新量随工序密集程度变化。文档以项目、标段、工序为三级层级结构，字段包含监理单位名称、标段编号、工序名称、验收时间、整改项清单、闭合状态、关联图纸编号等，单位涵盖天、份、平方米、立方米等工程常用计量标准。

## 这些特征在「部署与升级」这一环带来什么约束
由于台账数据的更新频率随施工进度波动，部署时需预留弹性计算资源以应对单日峰值同步需求。三级层级化的文档结构与多字段校验要求，使得升级时需保留原有字段映射规则，避免数据导入时出现格式错误。多维度的业务单据来源要求部署时配置多数据源同步通道，防止单一路径故障导致台账更新中断。同时，工程类数据的合规性要求，使得存储与权限配置需符合行业数据安全规范，升级时需同步迁移加密配置避免数据泄露风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30 个` | 适配工程监理台账批量同步的并发连接需求，避免数据库连接耗尽 |
| `MONGODB_URI` | `mongodb://[用户名]:[密码]@[主机]:[端口]/fastgpt_nj?authSource=admin` | 存储台账的历史归档数据，需指定专属数据库实例隔离业务数据 |
| `REDIS_URL` | `redis://:[密码]@[主机]:[端口]/0` | 缓存临时同步的台账增量数据，降低数据库重复查询压力 |
| `STORAGE_S3_ENDPOINT` | `https://[自定义合规存储域名]` | 存储大型验收图纸与台账附件，适配工程数据的合规存储要求 |
| `FILE_TOKEN_KEY` | `32 位随机字符串` | 加密台账附件的下载链接，防止未授权访问敏感工程数据 |
| `ROOT_KEY` | `符合企业安全规范的密钥` | 管理系统最高权限账号，保障台账数据的访问与操作安全 |

## 容易做错的三处
- 现象：本地打包部署后，修改的台账字段校验规则未生效，界面显示字段为空。原因：未将自定义的字段校验配置文件挂载到容器的指定挂载目录，导致镜像内置的默认配置被优先加载。
- 现象：升级到FastGPT v4.17.0后，加载配置文件中的存储参数失败，页面提示配置项无法识别。原因：该版本对对象存储配置的解析逻辑进行了调整，未同步更新配置文件的参数命名格式。
- 现象：私有化部署完成后，无法获取商业级技术支持与功能授权。原因：未在部署前提交私有化部署备案，未完成商业授权与部署实例的绑定流程。

## 怎么确认配好了
- 执行内置的数据库连接测试工具，验证`DB_MAX_LINK`配置的并发连接数是否符合设定范围，无连接超时报错。
- 上传一份测试用的监理台账Excel文件与关联图纸，确认附件可正常上传至`STORAGE_S3_ENDPOINT`指定的存储节点，且下载链接可正常生成并访问。
- 启动一次增量同步任务，检查`REDIS_URL`的缓存命中率是否稳定，无频繁的数据库重连日志。
- 登录最高权限账号，确认可正常创建、修改台账字段校验规则，无权限不足的报错提示。
