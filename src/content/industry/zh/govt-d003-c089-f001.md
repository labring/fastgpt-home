# 工程机械的台账汇总与报告生成：HTTP 接口与外部系统

## 这个品类的数据长什么样
工程机械的台账数据主要来自设备物联网终端、现场运维系统、售后维修日志三类来源。数据更新节奏分为两类：设备实时工况数据每秒更新，每日汇总的运行时长、维护记录等数据每日凌晨更新。单条台账文档包含设备编号、型号、额定功率、累计运行时长（单位：小时）、当日油耗（单位：升）、最近一次维护日期、作业次数（单位：次）等字段，单条完整文档长度符合常规业务数据的标准范围。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多来源异构数据需要接口支持同时拉取不同系统的台账数据，因此接口需兼容多种数据格式的解析逻辑。实时工况数据的短间隔更新要求接口支持高频调用，需配置合理的超时时间避免请求被中断。工程机械台账特有的单位（小时、升、次）要求接口在数据传输与解析时保留单位信息，避免字段解析错误。单设备单日数据量较大，批量拉取时需支持分页参数，防止单次请求过载影响系统稳定性。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 单次请求上限 | 前 20 条 | 适配单批次多设备台账的数据量，避免请求超时 |
| 超时时间 | 600 秒 | 适配国央企内部系统的网络延迟与批量数据拉取耗时 |
| 鉴权方式 | Bearer Token | 匹配国央企内部系统的通用鉴权规范 |
| 变量映射规则 | 按台账字段一一对应 | 确保传入参数与工程机械台账的设备编号、运行时长等字段匹配 |
| 响应格式 | JSON | 与FastGPT的接口解析要求保持一致 |
| 分块长度 | 800–1200 字符 | 适配单条台账文档的平均长度 |

## 容易做错的三处
- 调用接口返回401 Unauthorized，未携带有效鉴权信息。原因是未正确配置`Authorization`头，使用了过期或无效的鉴权密钥。
- 调用共享链接时无法关联指定设备的台账数据，返回的报告为空。原因是未在接口配置中添加自定义变量，未将设备ID作为参数传入。
- 生成的报告中作业时长单位显示错误，或猜你想问的内容未关联当前设备的台账数据。原因是未在`variables`或`responseData`中配置字段映射规则，导致数据解析或上下文关联失败。

## 怎么确认配好了
- 发送测试请求，查看返回的JSON结构是否包含设备编号、累计运行时长、当日油耗等工程机械台账特有字段。
- 检查接口返回的状态码为200 OK，`Authorization`头携带的鉴权信息有效。
- 验证批量请求的结果条数与配置的单次请求上限一致，无数据截断情况。
- 查看生成的报告，确认作业时长、油耗等字段的单位与台账数据一致，无解析错误。
