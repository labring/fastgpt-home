# 工程机械的台账汇总与报告生成：数据库与运维

## 这个品类的数据长什么样
工程机械台账数据主要来自设备出厂参数包、车载传感器实时上传的作业工况数据、运维人员录入的巡检与保养记录。数据更新节奏为单次作业结束后同步作业时长、油耗、吊装重量等实时字段，每日凌晨批量更新当日巡检记录，每月底同步月度保养台账与工况汇总数据。单设备台账文档包含设备编号、型号、额定起重量、累计作业时长、最近维保日期、所属项目等字段，字段单位多为吨、小时、日期格式，部分字段为枚举类文本，如设备运行状态。

## 这些特征在「数据库与运维」这一环带来什么约束
高频实时作业数据会带来短时间内的大量写入请求，要求数据库连接池配置适配高并发写入场景。多字段混合的台账结构，需要为设备编号、所属项目等高频查询字段建立索引，避免全表扫描导致的查询延迟。月度批量同步的保养台账与工况数据量较大，需按月份对历史台账数据进行分区存储，降低单表查询压力。枚举类字段如设备运行状态需统一校验规则，防止无效数据写入数据库，影响后续汇总与报告生成的准确性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://admin:securepass@db-host:27017/construction_machinery?authSource=admin` | 工程机械台账包含非结构化的保养照片、作业日志片段，MongoDB适合存储半结构化数据，指定专属数据库名隔离业务数据 |
| `PG_URL` | `postgresql://admin:securepass@db-host:5432/structured_assets?sslmode=require` | 设备编号、额定起重量等结构化字段适合PostgreSQL存储，开启SSL保障数据传输安全 |
| `DB_MAX_LINK` | `20–30 个连接` | 单设备实时数据写入频率高，连接池需覆盖并发的读写请求，避免连接耗尽导致的写入失败 |
| `REDIS_URL` | `redis://:securepass@cache-host:6379/0` | 用于缓存高频查询的设备基础信息，减少数据库直接查询压力，加速台账汇总响应 |

## 容易做错的三处
- 现象：数据库连接超时，返回状态码504，单条消息处理耗时超过30秒。原因：未根据实时数据更新频率调整`DB_MAX_LINK`配置，连接池耗尽导致新请求无法获取连接。
- 现象：本地部署后无法创建台账专属数据库，提示权限不足。原因：未在`PG_URL`或`MONGODB_URI`中配置拥有数据库创建权限的账号，或未提前创建对应数据库实例。
- 现象：工具选择出现并发重复调用，导致台账汇总结果出现重复条目。原因：未通过Redis缓存锁定当前汇总任务的唯一执行标识，多个进程同时触发相同的台账拉取请求。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`MONGODB_URI`与`PG_URL`配置可正常建立连接，无权限或地址错误提示。
- 提交一条模拟的设备作业数据，确认数据可正确写入对应数据库表或集合，字段格式与单位符合预设规则。
- 发起批量台账汇总请求，观察Redis缓存的命中情况，确认高频查询的设备基础信息可被正常缓存。
- 调整`DB_MAX_LINK`配置至建议区间，模拟10个并发写入请求，确认无连接耗尽报错。
