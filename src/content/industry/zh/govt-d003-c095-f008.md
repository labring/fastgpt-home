# 新能源开发的台账汇总与报告生成：文档解析与分块

## 这个品类的数据长什么样
新能源开发的台账与报告数据主要来源于项目立项文件、现场运维记录、并网验收报告、发电量统计报表等。数据更新节奏随项目阶段调整，立项与审批阶段按节点同步文件，运维阶段按周或月度更新运行数据。文档格式混合存在结构化Excel台账、带图表与公式的PDF报告、Word审批文件等类型。字段包含项目编号、装机容量、并网时间、累计发电量、运维时长、耗材用量等，单位涉及千瓦、千瓦时、小时、立方米等。

## 这些特征在「文档解析与分块」这一环带来什么约束
混合格式的文档同时包含结构化表格与复杂公式，要求解析工具同时支持结构化内容提取与公式识别。多来源的文档格式不统一，需要适配不同解析引擎以保证提取一致性。台账字段多且单位多样，分块时需保留字段与业务逻辑的关联关系，避免拆分后字段断裂或信息丢失。不定期更新的文档需支持增量解析与分块，避免重复处理全量历史数据，提升处理效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 800–1200 字符 | 新能源开发台账常包含长段落的运维说明与结构化表格，该区间可平衡上下文完整性与分块粒度 |
| `chunkSplitter` | 按段落+标题分割 | 台账文档有明确的项目章节与字段分组，按标题分段可保留业务逻辑关联 |
| `customPdfParse` | 启用 | 部分并网验收PDF包含复杂数学公式与嵌套表格，启用自定义解析可提升公式与结构化内容提取准确率 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 单份大型并网报告页数较多，需预留足够解析时间避免超时 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 项目归档PDF常包含高清图纸与附件，需放宽上传上限适配全量文档上传 |
| `chunkSettingMode` | 手动配置 | 需针对不同类型的台账文档（运维日志/审批报告）调整分块参数，手动配置可灵活适配场景 |

## 容易做错的三处
-  执行`docker run --gpus all -itd -p 7231:7231`启动`marker_images:v0.1`镜像时出现报错，原因是本地FastGPT版本与镜像版本不兼容，未使用与FastGPT v4.17.0匹配的镜像版本。
-  知识库里的PDF点击分块预览返回无法读取该文件内容，原因是未启用`customPdfParse`配置，或上传文件超出`UPLOAD_FILE_MAX_SIZE`限制。
-  配置飞书知识库后无法同步PPT和PDF文档，原因是未开启对应文档类型的同步权限，或`PARSE_FILE_TIMEOUT_SECONDS`设置过短导致大型文档解析超时。

## 怎么确认配好了
-  上传一份包含复杂数学公式的并网验收PDF，检查解析结果中公式是否可正常显示。
-  上传一份超过500 MB的项目归档文档，确认上传与解析流程未触发超时或文件大小限制报错。
-  对结构化Excel台账文档进行分块预览，检查字段是否完整保留且未被错误拆分。
-  调整`chunkSize`参数后重新执行分块操作，确认分块后的内容长度符合预设配置区间。
