# 有色金属冶炼的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
有色金属冶炼的台账数据来源包括现场工控系统、质检实验室管理系统、生产调度ERP系统三类。更新节奏分为三类：工艺参数类数据每15分钟更新一次，班组生产台账每日更新，月度综合汇总数据每月更新。文档多为结构化表格格式，包含炉次编号、生产时长、投入原料重量、产出金属量、单位能耗、当班人员编号、异常报警次数、质检合格批次计数等字段，单位涵盖千克、小时、吨标准煤/吨金属等，单批次台账记录可达数千条。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据来源要求工具调用需配置多数据源拉取的规则，分别适配不同工控、质检、ERP系统的接口格式与权限要求。更新节奏的差异要求为不同类型的台账数据设置差异化的调用间隔，避免重复拉取实时数据或延迟拉取月度汇总数据。多字段关联的结构化数据要求工具调用时需明确关联键，防止不同炉次的台账数据错位聚合。结构化表格格式要求插件需适配列名匹配、数据类型校验的逻辑，确保解析后的台账数据可用于后续汇总计算与报告生成。

## 配置怎么定
本页面的配置说明基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | 自动 | 适配多工具调用场景，自动匹配台账汇总所需的数据源拉取、数据聚合工具 |
| `functionCall` | 启用 | 支持结构化数据解析，适配有色金属冶炼台账的多字段关联需求 |
| 数据源拉取间隔 | 15分钟–24小时 | 覆盖实时工艺数据和月度汇总数据的更新节奏 |
| 关联字段匹配规则 | 按炉号匹配 | 匹配台账数据中的唯一标识字段，避免跨批次数据错位 |
| 单次返回条数 | 前1000条 | 限制单次工具调用返回的数据量，避免系统过载 |
| 超时阈值 | 600秒 | 适配多源数据拉取和结构化解析的耗时需求 |

## 容易做错的三处
- 调用工具时返回`You need to use the app key rather than the account key`报错，原因是未配置应用级调用密钥，误用账号密钥发起工具调用请求。
- 工具返回的台账数据字段为空，原因是未指定正确的关联字段，导致多源数据无法完成匹配关联。
- 单次工具调用触发超时，原因是未限制单次返回的数据条数，拉取了超出系统处理上限的大量台账记录。

## 怎么确认配好了
- 发起工具调用请求，检查响应结果中包含正确的冶炼台账字段数据。
- 查看工具调用日志，确认拉取的数据间隔符合预设的15分钟–24小时范围。
- 测试密钥校验场景，确认出现密钥错误时返回指定的校验失败提示文案。
- 验证结构化数据解析结果，确认关联字段匹配后的数据聚合逻辑正常。
