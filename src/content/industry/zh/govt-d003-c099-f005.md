# 油气勘探开发的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
油气勘探开发的台账数据主要来自录井数据采集系统、测井解释平台、油气生产物联网平台、开发计划管理系统。实时生产数据每15分钟刷新，单井基础台账每季度更新，月度开发报告每月生成。单井台账包含井号、井深、岩性、日产油量、含水率等字段，单位涵盖米、立方米、吨、百分比；区块汇总台账包含累计产油量、新增探明储量、单井产能等字段，数据结构按勘探开发阶段分层归类。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散的特征要求工具调用环节需编排多源HTTP插件，按数据类型触发拉取请求。不同更新节奏的数据源，需要设置差异化的轮询间隔，避免频繁调用实时系统或遗漏静态台账更新。字段单位不统一的问题，需要插件内置单位转换逻辑，确保汇总数据的一致性。长文档结构则要求工具调用的上下文配置适配大文本处理，避免截断关键台账信息。

## 配置怎么定
本文基于FastGPT v4.17.0版本配置。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 多源插件触发顺序 | 按数据更新优先级排序，实时数据先拉取 | 匹配油气勘探开发数据的实时性要求 |
| `toolChoice` | 自动 | 适配多工具调用场景，无需手动指定工具 |
| `functionCall` | 批量开启 | 支持同时调用多个数据拉取插件 |
| 插件超时时间 | 600秒 | 适配长文档读取与跨系统数据汇总的耗时 |
| 单位转换开关 | 开启 | 统一不同系统的字段单位 |
| 上下文长度 | 8000–12000 token | 适配长台账文档的处理需求 |

## 容易做错的三处
- 调用外部API后返回空字段，原因是未在插件配置中添加对应油气生产系统的认证密钥，请求未被授权。
- 工具调用结果直接输出，未被保存为上下文资料传入大模型，原因是未在工作流中添加结果中转节点，未将工具返回的台账数据保存为可用资料。
- 插件执行超时，原因是未调整插件超时时间，长台账文档的读取与汇总耗时超过默认阈值。

## 怎么确认配好了
- 进入FastGPT的插件管理页面，检查每个数据源插件的认证状态，显示已成功连接。
- 运行测试工作流，查看工具调用日志，确认所有配置的插件均成功拉取对应系统的台账数据。
- 发起API调用，检查返回的响应体中包含汇总后的台账字段，且单位已完成统一转换。
- 查看工作流节点的输出结果，确认工具调用结果被正确保存为上下文资料，未直接对外输出。
