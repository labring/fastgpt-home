# 油气勘探开发的台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
油气勘探开发的台账数据主要来源于勘探井位档案、测井原始数据、试油分析报告、开发动态监测报表等。单井台账按完井周期更新，区域开发汇总台账按月或季度更新。文档包含结构化字段与非结构化附件，结构化字段包括井号、井深（单位米）、日产油量（单位立方米）、地层压力（单位兆帕）等，单井文档长度多在数十页，区域汇总文档可达上百页。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据的结构化程度差异较大，既包含规整的表格字段，也包含半结构化的分析文本，要求模型能够适配混合格式的输入，因此需要合理设置上下文长度参数。高频更新的数据源要求调用频率需匹配更新节奏，避免超出API调用限制。专用的字段与单位要求模型具备领域知识准确性，不宜设置过高的随机性参数。长文档占比高的特点也要求调整最大上下文与输出token的限额。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单井与区域汇总台账的长文档拼接需求，FastGPT v4.17.0版本支持该范围的上下文配置 |
| `maxTokens` | 2000–3000 token | 保障报告生成的输出长度满足台账汇总的完整内容要求 |
| `temperature` | 0.3–0.5 | 降低生成随机性，确保井号、专用单位等字段识别准确 |
| `AIPROXY_API_ENDPOINT` | 平台分配的专属节点地址 | 适配油气勘探数据的合规传输要求，避免跨区域访问限制 |
| `AIPROXY_API_TOKEN` | 绑定专属权限的密钥 | 限制调用范围，防止非授权访问敏感的勘探开发数据 |
| `toolChoice` | auto | 自动选择适配的工具处理结构化表格与非结构化文本，提升汇总效率 |

## 容易做错的三处
- 报错提示“当前分组default下对于模型whisper-1无可用渠道”，原因是未将语音识别模型绑定到对应分组，或配置的模型名称与平台注册的名称不一致。
- 半夜持续触发API调用导致余额消耗，原因是未配置定时任务的调用频率限制，或数据源同步脚本未设置合理的间隔时间，导致高频重复调用。
- 生成的报告中出现单位识别错误，比如将“立方米”识别为“吨”，原因是temperature参数设置过高，导致模型生成内容随机性过大，忽略了油气领域的专用单位规则。

## 怎么确认配好了
- 上传单井台账与区域汇总文档发起测试调用，查看返回的日志中是否包含准确的井号、井深等结构化字段。
- 检查API调用日志，确认调用频率符合预设的间隔要求，无异常高频触发的记录。
- 验证生成的报告格式与预设的台账汇总模板一致，无明显的字段错位或单位错误。
- 测试不同类型的数据源，包括测井数据、试油报告，确认`toolChoice`自动适配的功能正常生效。
