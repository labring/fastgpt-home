# 油气勘探开发的台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
油气勘探开发的台账数据来源包括钻井作业记录系统、测井分析平台、试油测试数据库，更新节奏随单井作业节点完成或每日批次汇总生成。文档结构包含井号标识、作业深度、岩性分类、物性参数、流体产出量等核心字段，字段单位涵盖米、吨、立方米等，单份台账文档长度随作业环节推进逐步扩充。

## 这些特征在「部署与升级」这一环带来什么约束
油气勘探开发台账的数据多源分散、单份文档长度跨度大且随作业环节扩充，会对部署与升级带来多重约束。多源数据对接要求部署阶段提前配置兼容不同数据库的连接参数，避免数据同步中断。单份文档较长的特性要求调整数据库连接池参数，保障批量台账读取时的稳定性。批次化的更新节奏要求升级过程支持增量部署，避免全量重启打断正在进行的汇总任务。同时，台账包含的作业敏感数据，要求部署时严格配置访问密钥相关参数，强化数据权限管控。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本，适配油气勘探开发台账的部署与升级需求：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `10–20 个` | 适配油气勘探开发台账批量读取的并发需求，避免连接池耗尽 |
| `REDIS_URL` | 按实测标定的缓存节点地址 | 缓存大量台账元数据与汇总中间结果，降低数据库重复查询压力 |
| `STORAGE_S3_ENDPOINT` | 对应企业内部对象存储的接入地址 | 存储大型台账文档与生成的报告文件，保障数据本地化存储 |
| `ROOT_KEY` | `复杂度不低于16位的随机字符串` | 管控平台最高权限访问，符合国央企数据安全要求 |
| `FILE_TOKEN_KEY` | 独立于`ROOT_KEY`的加密密钥 | 生成台账报告的分享令牌，分离权限层级 |
| `FE_DOMAIN` | 企业内部访问的域名或IP:8080 | 配置工作台与分享链接的合法访问路径 |

## 容易做错的三处
- 尝试在docker-compose.yml中配置多个API密钥后，平台无法按预设模型组合调用服务。未遵循平台要求的数组格式配置密钥变量，仅添加单个密钥条目导致配置解析异常。
- Windows主机重启后，FastGPT工作台生成的免登录分享链接无法访问，页面提示资源不存在。未将`FE_DOMAIN`配置为固定的本地访问地址，Docker容器重启后端口发生临时变更，原链接绑定的端口失效。
- 批量汇总大型油气台账时，任务频繁触发超时报错，日志显示连接池耗尽。未根据台账数据量调整`DB_MAX_LINK`的取值，默认连接数不足以支撑批量读取的并发需求。

## 怎么确认配好了
- 登录平台后台，查看数据库连接状态面板，确认配置的`MONGODB_URI`与`PG_URL`对应的数据源连接正常，无持续报错。
- 上传一份测试用的油气勘探台账文档，触发汇总任务，检查生成的报告是否包含所有预设的核心字段，无异常缺失。
- 生成一条免登录分享链接，重启部署环境后访问该链接，确认页面可正常加载且无需重复登录验证。
- 查看平台运行日志，确认配置的`STORAGE_S3_ENDPOINT`对应的存储服务可正常读写台账与报告文件，无权限或连接报错。
