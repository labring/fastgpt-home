# 炼化生产的台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
炼化生产的台账数据来源为分布式控制系统（DCS）、罐区液位监测系统、化验室质检报表、生产调度日志等。更新节奏分为三类：实时工艺参数秒级更新，每日班组台账每日更新，月度能耗报表每月更新。文档以装置编号、操作时间、物料类型为核心结构，包含流量、温度、压力等工艺参数，以及质检合格率、能耗指标等字段，单位统一采用炼化行业标准，如流量为立方米/小时、温度为摄氏度、压力为兆帕。

## 这些特征在「知识库检索与召回」这一环带来什么约束
实时工艺参数的秒级更新要求知识库支持增量同步，避免召回过期数据。多源数据的整合要求检索范围限定在专属炼化台账知识库，防止混入其他业务数据。复杂的专业字段与单位要求检索匹配时需关联专业术语与固定字段，不能仅依赖语义匹配。长文档的批量记录要求分块时保留装置、批次等上下文信息，避免拆分后丢失关键关联。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `similarity` | 0.75–0.85 | 炼化台账包含大量专业术语与固定格式，阈值过低会引入无关装置数据，过高会遗漏同批次关联台账 |
| `limit` | 前10–15条 | 单份炼化台账包含多组工艺参数，过多召回会超出上下文窗口，过少无法覆盖完整工艺链路 |
| `searchMode` | vector + fulltext | 兼顾语义匹配与关键词匹配，适配台账既有工艺描述又有固定字段的结构 |
| `usingReRank` | 开启 | 炼化数据专业关联性强，重排可过滤语义相似但工艺场景不匹配的结果 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充装置编号、批次号等专业字段的检索词，提升精准匹配度 |
| `collectionIds` | 按绑定的炼化生产台账知识库ID填写 | 限定检索范围，避免混入其他品类的知识库数据 |

## 容易做错的三处
- 现象：检索结果中出现非炼化生产的台账数据，原因：未正确填写`collectionIds`参数，检索范围未限定在目标炼化知识库内。
- 现象：本地知识库的检索请求触发外网访问限制，无法正常返回结果，原因：未在FastGPT后台配置外网访问权限，默认限制了本地知识库的外网调用。
- 现象：检索结果未包含指定批次的工艺参数，原因：`similarity`阈值设置过高，导致匹配不到语义相近但字段不完全一致的台账数据。

## 怎么确认配好了
- 查看FastGPT后台的知识库列表，确认`collectionIds`参数对应的知识库ID与目标炼化台账知识库一致。
- 发起一次针对已知装置编号的检索，检查返回结果是否包含该装置的台账数据。
- 调整`similarity`阈值，观察检索结果的数量变化，确认阈值符合业务需求。
- 开启`usingReRank`后，对比重排前后的结果排序，确认重排功能生效。
