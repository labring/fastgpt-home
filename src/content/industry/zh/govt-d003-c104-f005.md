# 煤化工的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
煤化工的台账数据主要来自生产装置DCS实时采集系统、煤质化验室离线检测报表、储运环节计量单据。数据随生产流程节点触发更新，如每班交接班、单批次生产结束时生成完整条目。文档为结构化表格形式，包含设备编号、物料参数、操作参数、时间戳等字段，字段单位涵盖毫米、摄氏度、立方米每小时、吨等，无通用台账的冗余字段，全部字段与煤化工生产环节强绑定。本场景的工具调用配置适用于FastGPT v4.17.0版本。

## 这些特征在「工具调用与插件」这一环带来什么约束
首先，数据随固定生产节点更新，要求工具调用的触发逻辑必须绑定交接班、班后汇总等预设节点，无法适配随机触发的调用场景。其次，专用字段如磨煤机出口温度、入炉煤粒度的单位与通用台账存在差异，插件的参数解析规则需预设煤化工专用字段映射，避免参数解析错误。第三，单台账条目包含数十个结构化字段，工具调用的单次数据拉取上限需适配该规模，防止模型上下文过载。第四，台账数据关联多系统来源，插件的数据源配置需支持跨系统拉取。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配多工具联动需求，自动选择台账拉取、数据校验、报告生成工具 |
| `functionCall` | 按预设函数列表调用 | 固定调用煤化工台账拉取、参数校验、报告生成三个专用函数 |
| 工具调用触发时机 | 绑定班后汇总节点 | 匹配煤化工台账的更新节奏，避免拉取未完成的临时数据 |
| 数据源拉取上限 | 单批次50条记录 | 适配单台账的字段规模，避免上下文溢出 |
| 参数解析规则 | 启用煤化工专用字段映射 | 适配入炉煤粒度、磨煤机温度等专用字段的单位与含义 |
| 上下文长度限制 | 8000 token | 适配多台账汇总后的文本长度，避免模型截断 |

## 容易做错的三处
- 调用工具时返回“无效API Key”报错，或工具调用无响应。原因：混淆了全局通用API Key与工作流专用API Key，未使用工作流绑定的密钥配置。
- 生成的报告中混杂知识库搜索的输入输出日志。原因：未在工作流配置中关闭非必要的日志输出，或工具调用链路未过滤知识库相关上下文。
- 从CURL导入插件配置后无法点击确认按钮。原因：未正确填写CURL中的请求头与参数格式，或未匹配FastGPT的插件接口规范。

## 怎么确认配好了
- 触发预设的班后汇总节点，检查工具是否自动拉取对应批次的台账数据。
- 查看工作流运行日志，确认未出现知识库搜索的输入输出字段。
- 导入CURL格式的插件配置，确认界面显示“保存成功”提示。
- 调用工具后，检查返回的参数是否匹配煤化工台账的专用字段与单位。
