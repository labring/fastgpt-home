# 船舶制造的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
船舶制造的台账数据来源为船舶建造全流程的工序管理系统、物料管理系统与质检系统，随单个分段完工、月度节点验收同步更新。单份台账文档包含结构化字段与附件图纸，字段涵盖分段编号、钢材批次号、焊接电流、焊接电压、完工日期、检验记录编号等，单位包含毫米、安培、工时、吨等，部分台账附带CAD分段图纸附件。

## 这些特征在「工具调用与插件」这一环带来什么约束
船舶制造台账的多字段专业属性，要求工具调用时需严格匹配字段名与单位，避免参数解析错误；单份台账附带的CAD图纸附件体积较大，会增加工具调用的传输耗时，需配置合理的超时阈值；多工序台账的跨系统拉取，要求工具调用支持多数据源的字段映射规则，确保汇总时数据口径统一；高频更新的台账数据，需配置工具调用的数据源同步频率，匹配节点验收的更新节奏。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配多工具调用场景，自动匹配台账汇总所需的数据源拉取、字段映射工具 |
| `functionCall` | 按字段匹配触发 | 确保工具调用仅在检测到台账字段请求时启动，避免无效调用 |
| 工具调用超时时间 | `120–180 秒` | 适配船舶制造台账附带的CAD图纸传输耗时，避免大文件传输中断调用 |
| 数据源同步频率 | 每 8 小时 | 匹配船舶制造月度节点验收的更新节奏，平衡数据时效性与系统负载 |
| 附件上传限制 | 单文件不超过 500 MB | 适配船舶制造台账附带的分段图纸尺寸，避免传输失败 |
| 字段映射规则 | 按实测标定 | 匹配船舶制造台账的专业字段与单位，确保汇总数据的准确性 |

## 容易做错的三处
- 现象：工具调用返回的台账数据仅显示数值，未附带专业单位，如焊接电流仅显示数值未标注安培。原因：未配置字段映射规则，导致工具调用时未自动补全船舶制造台账的标准单位。
- 现象：上传的船舶分段图纸附件无法作为参数传入绑定的工作流，工作流执行时报参数字段为空。原因：未开启工具调用的文件链接自动生成配置，导致上传文件未生成可传递的访问链接。
- 现象：调用MCP类型的工具时出现连接失败报错，无法拉取台账数据。原因：未配置MCP server的正确访问地址与认证参数，且未确认MCP server的开源部署适配性。

## 怎么确认配好了
- 发起包含船舶制造台账专业字段的查询，使用FastGPT v4.17.0版本的工具调用功能进行测试，核对返回字段是否附带标准单位，如安培、毫米等。
- 上传一份小型船舶分段图纸附件，触发工具调用，检查绑定的工作流是否能接收到有效的文件访问链接。
- 配置跨系统台账数据源调用，核对返回数据的字段口径是否统一，无重复或错位条目。
- 测试MCP类型工具的调用，确认连接正常且能拉取到有效的台账数据。
