# 通信工程建设的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
通信工程建设的台账数据来源于施工日志、监理报验单、材料采购入库单、竣工验收报告等多类业务文档。数据更新节奏随施工节点动态调整，日常每日更新，大型攻坚节点可按需实时同步。单条台账文档包含项目唯一标识、施工区域、材料名称、规格型号、数量、对应单位（米、吨、套、平方米等）、施工日期、验收状态等固定字段，无统一固定长度，小型项目单页台账约100-500字符，大型项目单批次台账可达数千字符。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据来源要求工具调用需联动多个独立数据源插件，无法通过单一插件完成全量数据拉取。多单位字段要求工具调用逻辑需内置单位校验与统一转换规则，避免汇总时出现单位不匹配的计算错误。动态更新节奏要求工具调用可配置定时触发或事件触发模式，适配不同施工节点的数据更新频率。单文档长度跨度大的特点要求工具调用需适配可变长度的上下文处理，避免因单批次数据过多导致上下文溢出。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 支持自动匹配通信工程台账汇总所需的多类工具，无需手动指定单个函数，适配多源数据拉取与格式转换需求 |
| 函数调用超时时间 | `300-600 秒` | 通信工程台账数据量波动较大，该区间可覆盖小型项目快速汇总与大型项目复杂计算的时长 |
| 批量数据拉取上限 | `前 200 条` | 单批次拉取过多会导致上下文溢出，符合通信工程台账单页数据的常规规模 |
| 单位转换插件触发规则 | 按字段单位类型自动触发 | 通信工程台账包含米、吨、套等多类单位，需自动转换为统一核算单位后再进行汇总 |
| `functionCall` | `enabled` | 启用显式函数调用模式，确保台账汇总逻辑可被精准追踪与调试，符合工程类场景的合规性要求 |

本页面的配置适用于FastGPT v4.17.0版本。

## 容易做错的三处
- 界面返回`code:514`、`unAuthApiKey`报错，原因：未正确绑定通信工程场景专属的大模型API密钥，或密钥权限未覆盖台账汇总工具调用范围。
- 调用日志显示“获取数据异常”，原因：未配置多数据源插件的联动规则，导致无法同时拉取施工、监理、采购三类台账数据。
- 大模型调用返回“error”且日志显示模式不匹配，原因：未在FastGPT的模型配置中开启stream模式支持，导致仅支持stream的大模型无法正常响应请求。

## 怎么确认配好了
- 手动触发台账汇总工具调用，检查返回结果是否包含所有预设字段的统一单位转换后的数据。
- 查看FastGPT的调用日志，确认无`code:514`或“获取数据异常”类报错。
- 验证stream模式配置，通过实时日志确认大模型返回为流式输出。
- 调整批量拉取数量，确认单批次拉取数据不超过预设上限。
