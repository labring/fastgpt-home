# 金属材料加工的台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
金属材料加工的台账数据主要来自车间工控采集系统、理化检测实验室系统及仓储管理系统。数据按生产批次生成更新，单次生产批次完成后同步全量数据。单批次台账文档包含炉号、批次号、轧制温度、厚度公差、抗拉强度、屈服强度等字段，单位分别为℃、mm、MPa等，文档结构为结构化表格形式，单批次数据量随加工复杂度波动。本页面内容基于FastGPT v4.17.0版本编写。

## 这些特征在「工具调用与插件」这一环带来什么约束
金属材料加工的结构化批次数据特征，要求工具调用需精准匹配炉号、批次号等唯一标识字段，避免跨批次数据混淆。按批次更新的节奏，要求插件触发需绑定生产批次节点，仅在批次完成后调用工具拉取数据。字段带专属单位的特征，要求工具调用需内置单位校验逻辑，确保检测数据的单位与台账字段匹配。多源数据聚合的需求，要求插件支持跨工控、检测、仓储系统的数据拼接。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工具调用触发条件 | 绑定生产批次完成节点 | 匹配数据按生产批次更新的特征 |
| 单次工具调用数据上限 | 前200条记录 | 适配单批次常规加工数据体量 |
| `toolChoice` | auto | 支持自动匹配多源数据处理工具 |
| `functionCall` | 开启结构化模式 | 适配台账结构化字段的精准调用 |
| 单位校验开关 | 开启 | 匹配台账字段带专属单位的要求 |
| 插件超时阈值 | 600秒 | 适配跨工控、检测系统的数据拉取延迟 |
| 知识库关联范围 | 绑定当前生产批次台账 | 避免跨批次数据干扰 |
| 图片解析工具开关 | 开启 | 支持接入jpg格式的金相检测报告图片 |

## 容易做错的三处
- 现象：工具调用时知识库召回跨批次数据，导致报告生成出现无关内容。原因：未配置绑定当前生产批次的知识库关联范围，召回范围未限制在单批次台账内。
- 现象：部署MCP server后工具调用无响应，返回连接失败状态码。原因：未将MCP server的监听端口开放至对应生产系统网段，无法正常拉取车间采集的加工数据。
- 现象：上传jpg格式的金相检测报告后，工具调用无法解析图片内容，返回格式不支持报错。原因：未开启图片解析工具开关，未配置对应格式的图片解析插件。

## 怎么确认配好了
- 触发一次完整流程，查看对话token消耗日志，确认符合FastGPT的token计算规则，输入与输出token的统计范围符合预期。
- 触发一次模拟生产批次完成的节点，检查工具调用是否自动拉起，且仅拉取当前批次的台账数据。
- 查看工具调用日志，确认`toolChoice`参数的自动选择逻辑匹配当前数据处理需求。
- 上传模拟的jpg格式金相检测报告，检查插件是否自动解析图片内容并提取对应字段。
