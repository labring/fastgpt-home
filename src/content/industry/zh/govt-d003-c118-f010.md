# 金属材料加工的台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
金属材料加工的台账数据来源包括生产执行系统、在线质检设备、仓储管理系统与设备运维日志，更新节奏按生产批次完成后同步，或每日批量同步全量批次数据。文档包含结构化字段与非结构化附件，结构化字段涵盖炉号、材质牌号、轧制温度、轧制压力、检验硬度、入库重量等，对应专业单位为℃、MPa、HB、吨；非结构化附件包括扫描版质检报告、电子档工艺卡等。单份工艺类文档通常长度较长，每份台账关联多份辅助文档。

## 这些特征在「知识库检索与召回」这一环带来什么约束
金属材料加工台账的专业术语与专用单位，要求检索环节需支持带单位的语义匹配与精确关键词匹配，避免因单位或术语不匹配导致召回失效。按批次更新的数据特征，要求单次检索需覆盖同批次关联的多类文档，保障台账汇总的完整性。长文档与多文档关联的特征，要求检索配置需兼顾单文档切分的完整性与多文档召回的覆盖度，避免因切分破坏字段关联或遗漏辅助文档。业务数据的隔离需求，需严格限定检索范围至专属目录，防止跨品类数据混入检索结果。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.72–0.80 | 金属材料加工台账包含专业术语与专用单位，该区间可过滤无关召回结果，保留同材质、同工艺的关联数据 |
| `limit` | 前12条 | 单批次台账关联多类辅助文档，取前12条可覆盖多数场景下的关联数据，避免遗漏关键参数 |
| `searchMode` | hybrid | 支持关键词与语义混合检索，适配结构化字段与非结构化工艺文档的混合查询需求 |
| `usingReRank` | 开启 | 专业术语的语义匹配易出现偏差，重排可修正相似度排序，优先返回与台账字段匹配度更高的结果 |
| `datasetSearchUsingExtensionQuery` | 开启 | 台账汇总查询常包含扩展关联需求，优化查询可召回关联的隐藏字段与辅助文档 |
| `collectionIds` | 对应金属材料加工台账专属目录的ID | 隔离业务数据，避免召回其他品类的文档，保障检索精准性 |

## 容易做错的三处
- 现象：对话时模型提示知识库无可用内容，但知识库页面可正常查看文档。原因：未正确同步索引数据，或未绑定正确的`collectionIds`参数，导致检索引擎未加载目标目录的文档。
- 现象：检索结果包含大量非金属材料加工的行政文档或其他品类的台账数据。原因：`similarity`阈值设置过低，或未开启`searchMode`的混合检索模式，导致泛化召回无关内容。
- 现象：上传的长工艺文档无法被检索命中。原因：单文档切分块数超过3000，未拆分文档为多个子文件，导致部分块未被索引。

## 怎么确认配好了
- 上传一份包含炉号、轧制温度的测试台账文档，发起包含“[炉号]的质检数据”的查询，核对返回结果包含该文档的对应字段。
- 查看FastGPT后台的检索日志，确认`collectionIds`参数已绑定金属材料加工台账的专属目录，无跨业务数据集的召回记录。
- 上传一份长度超过10000字符的工艺文档，确认上传后切分块数未超过3000，且发起“该工艺的轧制参数”查询可命中相关内容。
- 发起“某批次的全量关联台账”的汇总查询，核对返回结果覆盖了工单、质检、库存等多类关联文档。
