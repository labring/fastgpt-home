# 12345热线工单办理的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据通常来自12345热线平台、承办单位业务系统、官方知识库及回访评价数据，更新频率为每日。日常文档包含诉求登记单、派单记录、办理答复、延期申请、退回说明与政策知识库条目，字段包含诉求编号、承办主体、诉求类型、答复内容、回访结果等，单条数据围绕群众诉求闭环形成完整链路。

## 这些特征在「知识库检索与召回」这一环带来什么约束
每日更新的数据要求检索环节支持增量同步，避免全量索引占用过多资源。多类型的工单类文档存在口语化诉求与规范政策文本的差异，需要适配混合文本的召回逻辑。数据围绕群众诉求闭环，要求召回内容需关联对应诉求的派单、答复历史，且需限定检索范围至12345专属政策与业务文档，避免无关内容干扰。同时，工单办理的出错后果关联超期、重办等，要求召回结果需具备较高匹配精度，避免无效检索延误办理。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配12345口语化诉求与规范政策文本的语义差异，平衡召回精度与覆盖范围 |
| `limit` | 前8条 | 适配工单办理的单次答复需要，避免过多上下文超出处理上限 |
| `searchMode` | hybrid | 结合关键词与语义检索，覆盖诉求中的关键词与政策依据的精准匹配 |
| `usingReRank` | 开启 | 对召回结果重排序，过滤低匹配度的政策条目，提升答复准确性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于原诉求生成扩展查询，覆盖诉求中的隐含政策需求 |
| `collectionIds` | 专属12345工单与政策数据集ID | 限定检索范围至专属数据集，避免无关内容干扰 |

## 容易做错的三处
- 现象：上传多文件时无响应，单个文件上传后长时间转码后出现网络失败报错。原因：未配置对应数据集的文件上传阈值，或本地部署环境的存储配额不足，导致大文件或多文件上传超时。
- 现象：新建知识库时未显示图片理解或索引模型选项。原因：FastGPT v4.17.0以下版本未内置该功能，且本地部署未额外安装对应模型包，仅商业版部署默认包含该配置。
- 现象：检索召回结果未在答复正文中关联知识库引用来源。原因：未开启知识库引用输出的配置开关，或未在提示词中加入引用来源的固定格式要求。

## 怎么确认配好了
- 上传1条包含政策关键词的诉求文本，查看检索返回的结果条数是否符合`limit`配置的取值。
- 检查数据集检索范围，确认仅包含12345专属的工单与政策文档，无外部无关数据集。
- 发起测试查询，查看返回结果是否经过重排序，且关联了对应的知识库来源。
- 模拟批量上传文档，确认上传过程无超时或网络失败报错，符合配置的上传阈值要求。
