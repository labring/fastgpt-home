# 主动公开与政策发布的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源包括政府门户网站、公文系统、政府信息公开目录、政策文件库、新闻发布会材料。数据更新频率为每日。日常处理的文档包含政策文件、政策解读稿、公开目录、信息发布审批单、新闻通稿、网站栏目更新记录。文档字段通常包含文件编号、公开属性、保密等级、发布时限、所属栏目等，格式多为结构化公文或标准化网页内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
每日更新的数据源要求配置支持增量同步与全量更新的切换，避免重复加载历史数据。多来源的文档格式差异要求配置适配不同的文本解析规则，确保政策原文、公开目录等内容的完整提取。政务文档的严谨性要求模型输出必须严格匹配政策依据，不能出现偏离原文的解读。同时，公开属性与保密等级字段需要被纳入召回与过滤规则，防止涉密或不应公开的内容被纳入问答范围。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | `8000–12000 token` | 政务类文档篇幅较长，需容纳足够的政策原文与公开目录内容，避免截断关键依据信息 |
| `maxTokens` | `2000–3000 token` | 政策与制度依据问答需覆盖政策要点、解读逻辑等完整内容，保障输出长度满足需求 |
| `quoteMaxToken` | `4000 token` | 需完整引用政策文件原文作为问答依据，避免长文本内容被截断导致依据不完整 |
| `temperature` | `0.1–0.3` | 政务问答需严格匹配政策原文，降低随机性，确保回答的严谨性与准确性 |
| `toolChoice` | `none` | 该场景仅基于已接入的政策文档生成回答，无需调用外部工具获取额外数据 |
| `AIPROXY_API_ENDPOINT` | 填写内部部署的API代理地址 | 适配内部网络访问限制，保障模型调用的稳定性与安全性 |
| `AIPROXY_API_TOKEN` | 填写分配的代理验证密钥 | 实现模型调用的身份验证，防止未授权访问 |

## 容易做错的三处
- 调用模型时返回`401 Unauthorized`错误，原因：未正确配置`AIPROXY_API_TOKEN`或`AIPROXY_API_ENDPOINT`参数，导致身份验证失败。
- 发布渠道生成的回答与本地测试结果不一致，原因：更新工作流配置后未重新关联发布渠道，旧的模型参数仍被使用。
- 回答中引用的政策原文出现断句或内容缺失，原因：设置的`quoteMaxToken`值过小，截断了长文本政策文件的完整内容。

## 怎么确认配好了
- 调用配置的`AIPROXY_API_ENDPOINT`接口，使用配置的`AIPROXY_API_TOKEN`发起测试请求，确认返回正常的模型响应。
- 上传一条篇幅较长的政策文件，测试`maxContext`与`quoteMaxToken`的取值，确认文档内容可完整加载，无截断情况。
- 设置`temperature`为0.2，多次测试同一政策相关问题，确认回答内容一致，无明显随机性偏差。
- 配置`toolChoice`为`none`，测试问答流程，确认模型未尝试调用外部工具，仅基于已接入文档生成回答。
