# 产权、资产与国有资本管理的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
本品类涉及的文档包含产权登记表、资产评估报告、产权转让方案、进场交易公告、资产处置审批单等。数据主要来自国资监管信息系统、企业资产管理系统、产权交易所系统、评估机构报告与财务报表。数据更新频率为月度，文档结构多包含权属编号、资产类别、账面金额、评估值、交易审批节点等字段，字段需严格匹配国资管理的标准化格式要求。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类的数据来源涉及内部系统与外部机构报告，需在模型接入时配置权限隔离规则，避免敏感国资信息泄露。月度更新频率要求召回与同步机制适配低频数据节奏，无需高频触发更新。文档字段存在跨主体的标准化差异，需确保模型能准确匹配不同来源的字段格式。同时，出错后果严重，需严格配置模型的引用校验与来源溯源能力，确保生成内容符合国资管理规范。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配产权转让方案、资产评估报告等长文档的上下文需求，确保政策条款与资产数据的关联匹配 |
| `maxTokens` | 2000–3000 token | 控制单轮问答的输出长度，避免生成超出国资审批文档格式的内容 |
| `quoteMaxToken` | 1500 token | 限制引用的政策原文与资产文档片段长度，确保引用内容精准且符合合规要求 |
| `temperature` | 0.1–0.3 | 降低生成随机性，确保政策与资产数据的匹配结果严谨，符合国资管理的合规性要求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写官方接入地址 | 适配国资系统内部网络环境，确保模型调用的稳定性与安全性 |
| `AIPROXY_API_TOKEN` | 按实测标定的密钥有效期 | 适配月度数据更新的节奏，定期轮换密钥以保障接口安全 |

## 容易做错的三处
- 尝试使用原生模型密钥时无法完成接入，提示接口调用失败。原因：未正确填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`参数，或未适配模型的官方接入规则。
- 添加第三方模型渠道后测试通过，但部署后显示渠道不可用。原因：未考虑国资系统的内网隔离限制，未配置代理或访问白名单。
- 发起政策问答时提示「当前分组 default 下无可用渠道」。原因：未将配置的模型渠道绑定至对应问答分组，或渠道权限未正确分配。

## 怎么确认配好了
- 执行模型连通性测试，确认接口返回正常，无渠道不可用或调用失败提示。
- 上传单份产权登记表与对应政策文件，发起问答测试，检查模型是否能正确关联两者内容。
- 查看上下文加载日志，确认文档片段加载长度符合配置参数的预期范围。
- 将配置的模型渠道绑定至对应问答分组，验证问答调用时无分组无可用渠道报错。
