# 医保费用结算审核的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
这个品类的日常数据来自全国医疗保障信息平台、医院HIS和医保接口、医保目录和编码库、异地就医结算平台，更新频率为每日。典型文档包含医保结算清单、费用明细、病案首页、处方、拒付清单、结算对账单，核心字段涵盖诊疗项目编码、药品耗材编码、费用金额、参保人信息、就医机构信息等，所有字段均遵循国家医保统一规范，无自定义特殊单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
每日更新的数据要求检索系统需支持增量同步机制，避免全量拉取带来的资源消耗。文档中包含大量标准化编码字段，要求检索匹配需兼顾精确编码匹配与语义匹配，确保政策依据与费用明细的对应关系准确。单次审核可能涉及多份政策条款的关联查询，需限定检索范围在合规的医保政策知识库内，防止无关内容干扰。同时，医保政策条款表述严谨，召回结果需按相关性排序，避免非核心条款影响审核效率。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `similarity` | `0.72–0.88` | 医保政策条款表述严谨，该阈值可兼顾精确匹配与召回范围，避免漏判或误判 |
| `limit` | `3–6条` | 单次医保费用结算审核对应的政策依据通常不超过6份，限定数量可提升审核效率 |
| `usingReRank` | 开启 | 需对召回的政策条款按相关性排序，确保核心政策优先展示 |
| `datasetSearchUsingExtensionQuery` | 关闭 | 医保政策术语严谨，不宜扩展查询范围，避免引入无关内容 |
| `collectionIds` | 指定对应医保政策知识库的ID | 限定检索范围仅包含合规的官方政策文档，确保审核依据的权威性 |

## 容易做错的三处
- 现象：配置变量引用时出现`quote type error`报错，界面提示字段格式异常。原因：未按医保政策文档的字段格式封装变量，例如直接引用编码字段时未添加正确的引用标记。
- 现象：相同审核问题在新旧知识库中召回结果不一致，新库可正常召回旧库无法召回。原因：旧知识库的文档分块未保留诊疗项目编码等核心字段，或分块长度超出匹配阈值范围。
- 现象：对话返回的审核结果未展示知识库引用来源。原因：未开启检索结果的引用展示开关，或配置中未开启关联引用输出功能。

## 怎么确认配好了
- 提交单条医保费用结算审核测试请求，核对返回结果是否包含匹配的政策依据文档。
- 查看检索日志，确认召回结果的数量符合设定的`limit`参数范围。
- 验证变量引用配置，确认无格式报错，可正常解析医保相关字段。
- 开启引用展示配置，确认返回结果附带对应的知识库来源信息。
