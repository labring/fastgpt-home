# 医疗机构监督与公共卫生检查的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据来源为卫生监督信息系统、医疗机构电子化注册系统、投诉举报平台、执法检查记录。日常文档涵盖监督检查表、医疗机构执业许可证、整改通知书、监督意见书、处罚案卷。数据更新节奏为月度，文档包含机构资质、人员资质、消毒诊疗记录、整改跟踪等字段，以合规相关的结构化与半结构化内容为主，无额外统计类数值。

## 这些特征在「知识库检索与召回」这一环带来什么约束
月度更新的节奏要求知识库同步周期匹配月度，避免频繁更新占用系统资源。多类型文档的结构差异较大，需适配不同文档的分块逻辑，确保半结构化的执法文书与结构化的资质文件均能被有效解析。数据用于合规监督场景，检索结果需精准匹配政策依据，需限制无关内容的干扰。字段多围绕机构资质、整改跟踪等核心执法需求，检索关键词需贴合执法场景的合规条款，避免泛化召回。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 本品类用于合规监督，需精准匹配政策条款，避免低相似度的无关内容干扰执法判断 |
| `limit` | 8–12 条 | 匹配执法人员需要的核心政策依据，过多结果会超出上下文承载上限，影响执法人员快速查阅 |
| `searchMode` | strict | 本品类需精准匹配政策与机构资质相关内容，严格模式可减少无关召回，提升检索精准度 |
| `usingReRank` | 开启 | 提升高相关结果的排序准确性，确保优先返回最贴合政策依据的内容，辅助执法人员快速定位合规依据 |
| `datasetSearchUsingExtensionQuery` | 开启 | 针对政策依据的问句优化，补充执法场景的政策关键词，提升召回精准度 |
| `collectionIds` | 绑定本品类专属数据集ID | 确保仅检索卫健监督相关的合规文档，避免混入无关数据集内容，保障检索结果的专业性 |

## 容易做错的三处
- 现象：问答拆分环节触发Invalid array length报错，必现。原因：本品类的执法文书包含长文本，未调整分块参数导致数组溢出。
- 现象：检索完成后重排模型持续占用显存。原因：未配置检索后自动卸载模型的相关设置，导致显存未被及时释放。
- 现象：无法导入医疗机构执业许可证的markdown格式文件。原因：markdown文件包含自定义表格或特殊格式元素，未适配FastGPT的markdown导入校验规则，导致解析失败。

## 怎么确认配好了
- 触发一次政策依据问答，检查返回结果的相似度是否符合设定的`similarity`区间。
- 查看检索返回的结果条数是否在设定的`limit`范围内。
- 验证重排模型是否在检索完成后自动卸载，查看系统显存占用情况。
- 导入一份本品类专属文档，确认能正常被检索到，验证`collectionIds`绑定是否正确。
- 检查知识库同步周期是否设置为月度，匹配本品类的数据更新节奏。
