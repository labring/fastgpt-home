# 国土空间规划编制与实施评估的政策与制度依据问答：工具调用与插件

## 这个品类的数据长什么样
该品类的日常文档包含国土空间总体规划、详细规划、专项规划、规划实施评估报告、公众意见汇总等，数据来源为国土空间基础信息平台、自然资源调查监测数据、人口经济统计数据与遥感影像。数据更新频率为每年一次，文档多为多章节结构化内容，包含空间坐标、约束指标、区域范围等字段，单位涉及平方公里、人口数、项目用地面积等，单份文档篇幅跨度较大，从数千字到数万字不等。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据更新频率为每年一次，因此工具调用无需高频同步数据源，可配置按固定周期拉取数据。文档篇幅跨度大，长文本会超出上下文限制，需要对文档进行分块处理。多源数据包含空间坐标、约束指标等专用字段，普通文本处理插件无法直接解析，需搭配专用空间数据解析插件。非结构化的公众意见汇总文本，需先配置文本清洗插件完成格式统一，才能用于问答生成。同时，多源数据的整合需求，要求插件支持跨数据源的调用逻辑，减少手动汇总的工作量。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 该品类政策问答需根据用户问题自动选择内置工具或专用插件，无需手动指定调用目标 |
| 分块长度 | `800–1200 字符` | 单份文档篇幅跨度大，该区间可平衡上下文长度限制与政策条款的信息完整性 |
| 单次搜索上限 | `前 6 条` | 多源数据来源较多，限定搜索条数可避免冗余信息干扰政策条款的提取 |
| `functionCall` | `enabled` | 政策与制度依据问答需要调用专用空间数据查询插件，启用函数调用可触发工具执行 |
| 超时时间 | `120 秒` | 空间数据查询需加载遥感影像或基础信息平台数据，该时长可覆盖多数查询场景 |
| 问题优化 | `开启` | 规划政策问题多包含专业术语，优化后可提升工具调用的准确性 |

## 容易做错的三处
- 现象为长文档的政策问答结果不准确，原因是未配置合适的分块长度，导致关键政策条款被截断或冗余信息过多。
- 现象为插件执行后返回空结果且扣除积分，原因是未配置专用空间数据解析插件，无法识别文档中的空间坐标字段，导致工具调用失败。
- 现象为无法找到定时执行工具入口，原因是未在FastGPT v4.17.0的插件管理中开启定时任务功能，或未绑定对应执行权限。

## 怎么确认配好了
- 发起包含空间坐标的政策查询，检查是否触发专用空间数据解析插件并返回对应结果。
- 上传一份万字级别的规划文档，检查问答系统是否自动分块处理并完整返回政策条款。
- 查看插件管理页面，确认`toolChoice`和`functionCall`的配置已生效。
- 测试定时拉取数据的任务，检查是否按设定周期同步国土空间基础信息平台的数据。
