# 国土空间规划编制与实施评估的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
本品类的数据主要来自国土空间基础信息平台、自然资源调查监测数据、人口经济统计、遥感影像，更新频率为年。日常处理的文档包含国土空间总体规划、详细规划、专项规划、规划实施评估报告、公众意见汇总，文档结构多包含空间坐标字段、规划约束指标、审批流程节点、部门与公众意见条目，字段单位涉及公顷、平方千米、人口数、百分比等空间与统计类单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类的年更新多源异构数据特征，要求模型接入时配置批量文档导入与增量同步逻辑，避免重复处理历史数据。文档包含空间坐标、约束指标、公众意见等混合结构，需确保配置的文本解析规则能准确识别空间类字段与统计单位，防止解析偏差。多部门与公众意见的混合内容，要求配置的上下文窗口适配多格式文本长度，同时过滤无关干扰项，保障政策依据问答的聚焦性。政务类数据来源的属性，要求配置的API调用权限适配政务数据安全调用的相关规范。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的参数规则。

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 本品类文档多为多页规划报告与多源数据汇总，需容纳足够的上下文以关联政策条款与规划内容 |
| `maxTokens` | 2000–3000 token | 政策依据问答需输出结构化的条款引用与解释，限制输出长度避免冗余 |
| `quoteMaxToken` | 1500 字符 | 需精准截取规划文档中的政策原文片段，避免过长片段干扰问答准确性 |
| `temperature` | 0.2–0.4 | 政策依据问答需保持表述严谨，不宜过度随机化 |
| `AIPROXY_API_ENDPOINT` | 按政务网络环境配置专属接入地址 | 本品类数据多为政务敏感信息，需通过合规的代理地址保障数据传输安全 |
| `toolChoice` | auto | 需根据用户问题自动触发知识库检索工具，确保政策依据的准确性 |

## 容易做错的三处
- 现象：调用后偶发返回空内容，状态码显示200但响应字段为空。原因：未配置`maxContext`的合理取值，导致多源文档的上下文溢出，模型无法提取有效政策依据。
- 现象：相同政策问题返回不同答案，知识库检索结果不一致。原因：未设置`quoteMaxToken`的固定截取规则，导致每次检索的原文片段范围不一致，引发答案差异。
- 现象：语音功能开启后无法正常调用语音模型。原因：未在`AIPROXY_API_ENDPOINT`中配置语音模型专属的接入路径，或未配置正确的`AIPROXY_API_TOKEN`权限。

## 怎么确认配好了
- 导入1份完整的国土空间总体规划文档，测试调用政策依据问答，检查上下文窗口是否正常加载文档全部关键内容。
- 输入相同的政策类问题3次，核对返回的政策原文引用片段是否一致，验证检索规则的稳定性。
- 查看API调用日志，确认`AIPROXY_API_ENDPOINT`的请求地址与配置一致，无权限或连接报错。
- 开启语音功能后，测试语音转文字与文字转语音的完整链路，确认模型调用无异常。
