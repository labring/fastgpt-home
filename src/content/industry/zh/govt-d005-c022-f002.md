# 土地使用权、矿业权与国有产权交易的政策与制度依据问答：向量模型与索引

## 这个品类的数据长什么样
本品类的数据通常来自全国公共资源交易平台、自然资源交易系统、产权交易所系统及国资监管系统，更新频率为每日。日常文档包含出让公告、交易须知、竞买申请、保证金凭证、成交确认书、挂牌结果公告、产权转让说明书等，文档结构差异明显：出让公告含标的区位与权属说明，产权转让说明书含标的估值与交易条件，字段涵盖标的编号、权属状态、竞买要求、保证金标准等。

## 这些特征在「向量模型与索引」这一环带来什么约束
每日更新的数据特征要求索引支持增量更新，避免全量重建带来的资源消耗与延迟。文档结构差异明显，分块时需适配不同文档的内容逻辑，例如出让公告的区位描述与产权转让说明书的交易条件需分别按语义块拆分，避免跨块语义断裂。专业字段如权属状态、竞买要求等需被向量模型精准捕捉，因此模型需适配公共资源交易领域的专业术语。同时，关键信息的召回准确率直接影响后续业务流程，需严格控制召回结果的相关性，避免因错误匹配导致交易流程受阻。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配本品类文档的平均内容密度，避免单块包含过多不相关的专业术语，同时保证语义完整性 |
| 重叠长度 | 100–200 字符 | 弥补分块时的语义断裂，确保跨块的关键信息如权属限制条件不被拆分 |
| 相似度阈值 | 0.75–0.85 | 过滤低相关性结果，避免无关的交易公告干扰政策依据的召回 |
| 单次搜索上限 | 前 10 条 | 平衡召回范围与响应速度，覆盖多数场景下的相关政策与交易文档 |
| `maxToken` | 4000 token | 限制单轮问答的上下文长度，适配FastGPT v4.17.0的模型调用上限，避免超时报错 |
| `defaultToken` | 2000 token | 设定默认的向量生成长度，兼顾专业术语的语义完整性与计算效率 |

## 容易做错的三处
- 现象：向量召回结果中缺失关键的权属限制条款，返回结果条数远少于预期。原因：分块长度设置过大，将包含多个独立条款的文档拆分为过少块，导致关键信息被截断。
- 现象：调用向量模型时出现超时报错，界面显示状态码504。原因：`maxToken`设置超出FastGPT v4.17.0的模型调用上限，或单次搜索上限设置过高导致计算资源耗尽。
- 现象：尝试接入自定义向量模型时无法正常调用，提示不兼容。原因：未按平台要求配置模型的调用参数，或混用不同类型的向量模型与索引规则，未统一预处理逻辑。

## 怎么确认配好了
- 上传单篇产权转让说明书文档，测试分块后的结果，确认每块的内容语义完整，无跨条款拆分的情况。
- 发起包含权属条件查询的测试问题，核对召回结果的相似度分值是否在预设阈值范围内，无明显低相关性结果。
- 查看索引更新日志，确认每日增量更新任务正常执行，无失败记录。
- 切换不同的向量模型，测试调用是否正常，确认参数配置生效。
