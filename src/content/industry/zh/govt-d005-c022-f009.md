# 土地使用权、矿业权与国有产权交易的政策与制度依据问答：模型接入与配置

本文基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
该品类的业务数据主要来自全国公共资源交易平台、自然资源交易系统、产权交易所系统及国资监管系统，更新频率为每日。日常产生的文档类型包含出让公告、交易须知、竞买申请、保证金凭证、成交确认书、挂牌结果公告、产权转让说明书等，不同文档的结构与字段侧重不同，例如权属类文档包含标的位置、权利类型等字段，交易类文档包含竞价规则、保证金要求等内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
多来源的系统数据要求配置适配不同数据源的接入路径，保障数据同步的完整性。日更的更新频率要求配置定时同步任务，确保模型检索的政策与交易数据始终为最新版本。多样的文档结构与字段要求调整上下文窗口配置，适配不同长度的文档内容，避免关键信息被截断。交易标的的权属与政策关联属性要求提升检索精准度，防止出现权属匹配错误或政策依据偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | `8000–12000 token` | 该品类单篇典型文档（如产权转让说明书）长度较长，需容纳足够上下文以关联政策依据 |
| `maxTokens` | `4000–6000 token` | 政策问答需完整输出依据条文，避免回答被截断 |
| `quoteMaxToken` | `2000–3000 token` | 需保留足够原文片段用于溯源政策文件，保障回答的可信度 |
| `temperature` | `0.1–0.3` | 政策问答需严谨，降低生成内容的随机性，避免偏离业务依据 |
| `toolChoice` | `auto` | 自动调用检索工具获取最新的交易与政策数据，适配实时更新的业务场景 |
| `vision` | `enabled` | 支持解析宗地图、权证等图片类权属材料，覆盖该品类的视觉输入需求 |
| `AIPROXY_API_ENDPOINT` | 填写对应大模型的官方接入地址 | 保障模型调用的连通性与正确性 |
| `AIPROXY_API_TOKEN` | 填写平台分配的身份验证密钥 | 完成接口调用的身份校验，保障数据传输安全 |

## 容易做错的三处
- 现象为模型测试时提示404 no body，原因是未正确配置`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`，导致接口调用的身份验证或地址参数错误。
- 现象为语音转文本时出现unmarshal_resp报错，原因是`maxTokens`设置区间过小，模型生成的回答超出限制被截断，无法完成响应序列化。
- 现象为图片分析流程无法正常运行，原因是未启用`vision`配置项，且未将图片转换为符合要求的base64格式，导致模型无法解析视觉类权属材料。

## 怎么确认配好了
- 手动上传一篇该品类的典型文档，触发政策问答，检查返回结果是否关联了对应的政策依据片段。
- 查看数据源同步日志，确认每日自动同步任务正常执行，无报错信息。
- 调用模型接口，检查返回的响应格式符合预设规则，无截断或序列化错误。
- 测试视觉输入功能，上传宗地图片或权证扫描件，检查模型能否正确解析图片中的权属信息并关联政策依据。
