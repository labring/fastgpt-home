# 安全生产隐患排查治理的政策与制度依据问答：工具调用与插件

## 这个品类的数据长什么样
本品类数据主要来自安全生产监管系统、企业隐患自查系统、执法检查记录、事故统计系统，更新频率为每日。日常文档包含隐患排查清单、隐患治理台账、整改通知书、复查记录、重大隐患挂牌督办单，单份文档通常包含隐患标识、整改责任主体、整改时限、复查结论等结构化字段，部分文档附带现场检查照片、整改前后对比影像等非结构化内容，单份文档大小通常在100–500 MB区间。

## 这些特征在「工具调用与插件」这一环带来什么约束
每日更新的多源数据要求工具调用配置支持增量拉取逻辑，避免重复处理过期数据。混合结构化与非结构化的文档类型，要求插件适配表格解析与多模态内容识别能力。多系统来源的数据需配置跨源鉴权规则，保障数据访问权限合规。隐患编号、整改时限等核心字段的准确性要求工具调用返回结果需严格对齐原始文档字段，不可擅自调整字段映射关系。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 支持自动选择匹配当前业务的工具，适配政策问答与隐患数据查询的混合需求，适配FastGPT v4.17.0版本的工具调度逻辑 |
| `functionCall` | `开启` | 强制模型按指定格式调用工具，确保政策依据问答的返回结果符合合规文档的结构化输出要求 |
| 单次工具调用上限 | `前6条` | 匹配每日更新的隐患数据量级，避免返回过多冗余信息影响模型理解 |
| 工具调用超时时间 | `30–60 秒` | 适配多系统数据拉取与文档解析的耗时需求，平衡响应速度与数据完整性 |
| 单次调用数据量上限 | `500 MB` | 适配本品类单份文档的平均大小，避免因数据过大导致调用失败 |
| 字段映射规则 | 按原始文档字段名对齐 | 保障隐患数据的准确性，避免字段不匹配导致的政策对照错误 |

## 容易做错的三处
- 现象：调用多模态工具处理隐患现场照片时返回格式错误报错。原因：未正确配置多模态内容的输入格式参数，未按工具要求传递图片base64编码或标准URL格式。
- 现象：传入隐患文档链接后无法解析出内容，仅显示版本更新提示。原因：未更新文档解析插件的适配规则，未针对本品类的清单、台账类文档调整解析逻辑。
- 现象：调用部署的模型时偶发返回空内容，且过程卡住后报错。原因：未配置工具调用的超时重试机制，单次调用超时后未触发自动重试，导致请求被丢弃。

## 怎么确认配好了
- 发起一次政策依据问答请求，检查工具调用日志是否正确匹配配置的工具列表。
- 上传一份隐患排查清单文档，验证解析结果是否包含文档内的核心字段，无缺失或错误映射。
- 传入一张现场检查照片，确认多模态工具能正确识别图片中的隐患标识文字。
- 模拟多系统数据拉取请求，检查跨源鉴权配置是否生效，无权限异常报错。
