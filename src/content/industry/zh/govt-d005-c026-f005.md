# 工程建设项目审批的政策与制度依据问答：工具调用与插件

## 这个品类的数据长什么样
本品类数据来自工程建设项目审批管理系统、施工图审查系统、企业资质库、信用平台，更新频率为每日一次。日常文档包含施工许可申请、施工图审查合格书、质量安全监督手续、竣工验收备案表，字段涵盖项目唯一标识、参建单位资质等级、审批节点状态、申请材料清单等，单位多为标准项目编号、资质等级、日期格式，无自定义非标准单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源覆盖多个独立系统，要求工具调用需支持跨数据源接口适配，避免单一数据源无法覆盖全部政策与制度依据。日更频率要求插件需配置每日同步任务，确保返回的政策内容与最新业务数据一致。文档字段多且存在关联关系，工具调用需支持精准字段映射，避免提取无关内容干扰问答准确性。审批环节涉及多方资质核验，工具调用需绑定对应资质库接口，确保返回的参建单位资质信息真实有效。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 自动匹配与工程建设项目审批政策依据相关的工具，无需手动指定 |
| `functionCall` | 开启 | 允许调用外部接口获取政策与制度依据的实时数据 |
| 工具调用超时时间 | `600 秒` | 跨系统获取多源数据耗时较长，预留足够响应时间 |
| 单次工具调用返回条数 | `前 5 条` | 控制返回内容长度，避免超出上下文窗口限制 |
| 插件数据源同步频率 | `每日 1 次` | 匹配业务数据日更的更新节奏，确保数据时效性 |
| 字段映射规则 | 绑定项目编号、参建单位资质字段 | 精准提取工程审批相关文档的核心字段 |

## 容易做错的三处
- 现象：调用工具时返回`{"object":"error","message":"Only allowed now"`，原因：未在FastGPT v4.17.0中配置模型调用的权限范围，或工具调用触发条件未匹配政策问答场景。
- 现象：HTTP请求参数解析正常但工具未执行，原因：插件配置中未绑定工程建设项目审批管理系统、企业资质库等对应数据源接口，导致调用无目标地址。
- 现象：返回的政策依据结果中缺少竣工验收备案表相关字段，原因：未配置对应数据源的字段提取映射，遗漏了竣工验收备案表的专属字段。

## 怎么确认配好了
- 触发工程建设项目政策依据问答测试，查看FastGPT v4.17.0后台的工具调用日志，确认存在对应数据源接口的请求记录。
- 检查插件配置页面的数据源同步状态，确认每日同步任务的执行状态为成功。
- 模拟提交施工许可申请查询，验证返回结果包含施工许可申请、参建单位资质等预设字段。
- 查看问答结果的上下文窗口，确认工具返回内容未超出预设的长度限制。
