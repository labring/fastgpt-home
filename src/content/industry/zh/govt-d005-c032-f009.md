# 投资项目立项与后评价的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
本品类的核心数据来自国资委投资监管系统、企业ERP与项目管理系统、行业市场数据、审计及财务报表，日常处理的文档包括年度投资计划、项目建议书、可行性研究报告、尽职调查报告、资产评估报告、投资后评价报告。数据更新频率为季度，核心文档结构包含项目基本信息、技术分析、财务测算、合规依据等模块，字段覆盖投资金额、进度节点、合规条款等，单位随文档类型与业务场景动态调整。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源覆盖多系统且更新周期固定，要求模型接入需适配内部网络环境与权限管控要求，避免数据泄露；文档类型多样且长度差异显著，需合理配置上下文长度以覆盖可研报告、后评价报告等核心合规依据；政策依据问答对准确性要求极高，需严格控制生成随机性，确保输出内容符合国资监管要求；部分文档包含图文附件，需支持多模态解析能力；季度更新的数据需定期同步向量库，避免使用过期的政策与项目信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配投资项目立项与后评价的多文档上下文长度，覆盖可研报告、后评价报告等核心合规材料 |
| `temperature` | 0.1–0.3 | 政策依据问答需保持严谨性，降低生成内容的随机性，避免出现不符合制度的表述 |
| `vision` | 开启 | 支持解析项目文档中的图文附件，匹配立项与后评价材料的常见格式 |
| `maxTokens` | 2000–3000 token | 控制单轮回答长度，确保政策依据引用的完整性与可读性，避免输出过长内容 |
| `AIPROXY_API_ENDPOINT` | 按内部部署环境填写 | 适配国央企内部网络的访问路径，确保数据传输符合安全合规要求 |
| `AIPROXY_API_TOKEN` | 绑定专属权限密钥 | 限制模型访问权限，符合国资监管的安全管控标准 |

## 容易做错的三处
- 开启`vision`功能后提示无可用渠道，原因是未配置多模态模型的API密钥或未开通内部网络访问权限。
- 界面右上角无创建模型标识，原因是当前账号未获得对应模型的分组使用权限，或未完成FastGPT v4.17.0的版本升级。
- 搜索耗时过长且硬盘IO占用偏高，原因是未限制`maxContext`的取值范围，导致系统加载过多历史项目与政策文档数据。

## 怎么确认配好了
- 发起包含项目文档附件的查询，检查是否能正确解析图片内容并关联对应政策依据。
- 查看API调用日志，确认`AIPROXY_API_TOKEN`的调用记录与绑定权限一致。
- 测试多轮合规问答，检查回答中引用的政策与项目数据与当前系统内的最新信息匹配。
- 监控系统运行指标，确认响应时间与硬盘IO占用处于合理区间。
