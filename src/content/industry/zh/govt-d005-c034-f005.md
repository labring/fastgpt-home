# 招生入学与学籍管理的政策与制度依据问答：工具调用与插件

## 这个品类的数据长什么样
本品类数据涵盖入学报名表、学籍信息表、转学申请、招生计划、录取名册、学籍异动审批表等文档，数据来源为全国中小学生学籍信息管理系统、地方招生入学平台、户籍与房产数据、学校教务系统。数据更新频率为每日，核心字段包含学生身份标识、入学资格核验项、学籍异动审批状态、录取批次等，仅围绕学生入学与学籍流转相关信息展开。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类的数据来源分散且每日更新，要求工具调用需配置定时同步机制，确保获取的政策依据与学籍、招生数据为最新版本。核心文档为结构化表单与审批材料，工具调用需限定查询字段范围，避免返回无关信息。涉及户籍房产核验环节，需调用外部政务系统接口，需处理跨系统数据格式兼容问题。由于出错会导致学籍异常或录取争议，工具调用需增加前置校验逻辑，避免无效或错误的政策依据调用。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配政策问答场景下的自动工具调用需求，无需手动指定工具 |
| 工具调用触发条件 | 当用户问题包含「学籍」「入学」「政策」「转学」关键词时触发 | 匹配本品类核心业务场景，避免无关触发 |
| 单次工具调用超时时间 | 15–20 秒 | 适配政务系统接口响应速度，避免长时间等待导致会话中断 |
| 知识库召回关联范围 | 仅召回招生入学与学籍管理类文档 | 过滤无关知识库内容，聚焦本品类业务数据 |
| `functionCall` | 开启参数校验模式 | 确保工具调用的参数符合本品类文档的字段格式要求 |
| 工具调用结果整合方式 | 按政策依据、学籍数据、核验结果分类拼接 | 清晰呈现政策与实际业务数据的对应关系 |

## 容易做错的三处
- 现象：工具调用模块未执行任何工具，会话日志中无工具调用记录。原因：未配置匹配本品类关键词的触发规则，或触发条件的关键词设置覆盖不全。
- 现象：调用外部户籍核验工具时返回504超时错误。原因：单次工具调用超时时间设置过短，未适配政务系统的实际响应时长。
- 现象：部署MCP server服务后无法正常调用工具。原因：未将本地服务端口开放至允许访问的网段，或未在平台中正确配置服务地址。

## 怎么确认配好了
- 输入包含「转学申请」的测试问题，查看会话日志是否触发工具调用。
- 进入工具调用配置面板，确认`toolChoice`设置为`auto`且`functionCall`的参数校验模式已开启。
- 输入仅包含「资助政策」的测试问题，确认未触发工具调用，验证触发规则的准确性。
- 等待1个数据更新周期后，查询最新的学籍异动数据，确认工具调用能获取到当日更新的信息。
