# 招生入学与学籍管理的政策与制度依据问答：文档解析与分块

## 这个品类的数据长什么样
这个品类的数据主要来自全国中小学生学籍信息管理系统、地方招生入学平台、户籍和房产数据、学校教务系统，更新频率为每日。日常处理的文档包括入学报名表、学籍信息表、转学申请、招生计划、录取名册、学籍异动审批表，兼具结构化表格字段与非结构化政策文本，字段覆盖学生身份信息、户籍房产核验条件、学籍异动审批流程、招生录取规则等，无额外非业务核心的统计数据。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的数据特征对文档解析与分块带来明确约束：多来源数据混合，需区分结构化学籍表格与非结构化政策文本的解析规则，避免身份、房产等核心字段提取错位；每日更新的高频小批量文档，需适配快速解析流程以满足实时政策问答需求；文档内包含学籍异动审批节点、招生录取规则等关键内容，分块需保留上下文关联，避免拆分后无法完整传递逻辑；结构化表格的字段需精准提取，否则将直接影响后续资格核验与政策问答的准确性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配招生政策文档与学籍表格的字段密度，避免拆分后丢失政策上下文或表格关联信息 |
| `customPdfParse` | 开启 | 适配入学报名表、学籍异动审批表等带表单字段的PDF文档，准确提取结构化表单内容 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 60–120 秒 | 对应每日新增的单份招生文档大小，避免大文件解析超时 |
| `UPLOAD_FILE_MAX_SIZE` | 50–100 MB | 适配招生计划、录取名册等批量文档的上传需求 |
| `chunkSplitter` | 按段落+标题拆分 | 匹配政策文档的章节结构与学籍表格的行上下文，保证问答时能关联到对应审批规则 |

## 容易做错的三处
- 现象：自定义PDF解析服务调用后返回超时报错，界面显示解析失败。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时长不足以处理批量学籍表格文件。
- 现象：导入的csv学籍表格仅显示前两列数据，其余字段未被提取。原因：未配置对应字段提取规则，默认解析逻辑仅读取csv文件的前两列内容。
- 现象：解析后的招生政策文档分块截断了完整的转学审批流程说明。原因：`chunkSize`设置过小，将完整的审批步骤拆分为多个独立块，丢失上下文关联。

## 怎么确认配好了
- 上传单份完整的招生政策PDF文档，查看解析后分块内容是否保留完整章节标题与段落逻辑，无强制截断情况。
- 上传包含多字段的csv学籍表格文件，确认所有预设字段均被正确提取并展示，无遗漏或仅显示前两列的情况。
- 调整`PARSE_FILE_TIMEOUT_SECONDS`参数后，上传预设`UPLOAD_FILE_MAX_SIZE`以内的录取名册文件，验证解析无超时报错。
- 测试`chunkSize`为1000字符时，转学申请文档的分块是否未截断审批节点说明，可完整传递流程逻辑。
