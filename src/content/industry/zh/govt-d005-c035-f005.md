# 排污许可管理的政策与制度依据问答：工具调用与插件

## 这个品类的数据长什么样
该品类的数据覆盖排污单位证后管理全流程相关文档，包括排污许可证申请表、执行报告、自行监测方案、台账记录、变更申请及许可证副本。数据来源为全国排污许可证管理信息平台、企业环保台账、在线监测系统与环境统计系统，按季度更新。数据字段包含行业技术规范对应限值、排放口参数、自行监测结果、执行报告填报内容等，涉及排放浓度、排放量的标准计量值及台账记录的时间戳信息。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据按季度更新，工具调用需适配批量季度数据的同步校验逻辑，避免调用过期或未更新的信息。多类文档结构差异显著，需针对排污许可证副本、执行报告等不同文档类型配置差异化的插件触发规则。数据来源分散，需通过插件对接全国排污许可证管理信息平台、在线监测系统等多个外部系统拉取原始数据。字段涉及环保专业计量，工具调用时需匹配对应单位转换逻辑，确保问答内容的计量准确性。证后监管的严谨性要求工具调用结果需关联原始数据溯源，保证问答依据的合规性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配排污许可管理中多类政策文档的自动调用需求，无需手动指定工具 |
| `functionCall` | 严格模式 | 确保工具调用返回的政策依据符合环保监管的严谨要求，避免非合规内容 |
| 插件触发规则 | 按文档类型匹配 | 针对排污许可证副本、执行报告等不同文档，调用对应政策依据的插件 |
| 外部数据拉取超时 | 300 秒 | 适配全国排污许可证管理信息平台等跨系统数据拉取的网络延迟情况 |
| 召回结果上限 | 前 5 条 | 确保问答引用的政策依据数量可控，符合监管文档的查阅习惯 |

*注：本页配置基于 FastGPT v4.17.0 版本*

## 容易做错的三处
- 现象：调用`toolChoice`时返回非预期的工具类型，或无工具被调用。原因：未针对排污许可管理的政策文档类型配置对应的`toolChoice`触发规则，导致模型无法匹配正确的调用逻辑。
- 现象：发布应用后通过API调用时返回空结果或状态码400。原因：未正确配置外部系统对接的插件参数，未完成全国排污许可证管理信息平台等数据源的授权与连接。
- 现象：导入HTTP插件后无法正常调用政策数据接口。原因：未在插件配置中填写正确的接口地址与请求头，未适配排污许可数据接口的认证要求。

## 怎么确认配好了
- 手动触发针对排污许可证副本的问答，检查返回结果是否关联了对应文档的政策依据。
- 调用API传入执行报告相关的问题，查看返回结果是否包含匹配的字段与数据来源。
- 查看插件运行日志，确认外部系统的数据拉取请求已成功发送并返回有效内容。
- 调整`toolChoice`配置为手动模式，验证模型是否能正确提示选择对应的政策调用工具。
