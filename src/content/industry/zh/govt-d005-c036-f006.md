# 政务服务事项目录与办事指南维护的政策与制度依据问答：引用来源与溯源

## 这个品类的数据长什么样
该品类的日常文档包含政务服务事项基本目录、实施清单、办事指南、标准材料目录、流程图及常见问题。数据来源为国家政务服务事项基本目录、行政许可事项清单、权责清单与地方政务服务事项库，更新频率通常为每月一次。文档字段覆盖事项名称、受理条件、申请材料清单、办事流程等，无固定统一单位，字段完整性需符合政务服务标准化规范。

## 这些特征在「引用来源与溯源」这一环带来什么约束
该品类的数据来源覆盖国家到地方多层级政务目录，引用溯源需明确标注数据所属层级与发布单位。月度更新的特性要求定期同步知识库源数据，确保问答内容与最新政策一致。多字段的文档结构，要求引用时精准匹配事项对应的具体文档片段，避免跨字段混淆。作为规则维护类工作，引用需严格对应政策条文与事项条目，不可关联单个办件数据。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | 适配政务文档单条片段的长度，避免截断关键政策表述 |
| `responseData` | 返回完整引用元数据 | 满足政务溯源需展示发布单位、更新时间的合规要求 |
| `detail` | 开启详细溯源 | 明确指向具体文档的章节位置，便于校验引用准确性 |
| 召回结果上限 | 前3条 | 避免过多引用导致内容冗余，聚焦核心政策依据 |
| 知识库同步周期 | 每月一次 | 匹配该品类数据的月度更新节奏，确保内容时效性 |
| 接口超时时间 | 600 秒 | 适配政务文档的加载时长，避免因内容过长导致请求中断 |

## 容易做错的三处
- 工具调用模块连接知识库后无法输出引用内容，原因是未开启`responseData`配置，未启用返回引用元数据的设置，导致接口未返回引用标识。
- 对话输出出现句末引用符号乱码，输出后变回标准引号，原因是引用元数据的格式解析未适配政务文档的多字段结构，未正确转义特殊字符。
- 知识库无匹配内容时仍返回非目标文件的引用，原因是召回阈值设置不合理，未过滤无关文档片段，错误关联了非当前政务事项的内容。

## 怎么确认配好了
- 发起包含明确政务事项名称的测试提问，检查输出内容是否附带来源文档的发布单位、更新时间等元数据。
- 查看对话请求的接口返回结果，确认包含引用相关的字段信息，验证`responseData`与`detail`配置是否生效。
- 触发知识库同步任务，检查同步日志，确认同步周期符合每月一次的要求，匹配品类数据更新节奏。
- 输入未覆盖的非目标事项提问，确认输出未附带无关引用内容，验证召回逻辑的准确性。
