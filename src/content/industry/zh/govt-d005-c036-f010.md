# 政务服务事项目录与办事指南维护的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的核心文档通常包含政务服务事项基本目录、实施清单、办事指南、标准材料目录与流程图等。数据主要取自国家政务服务事项基本目录、行政许可事项清单、权责清单及地方政务服务事项库，更新频率为每月一次。文档多为结构化表格与规范文本，包含事项编码、实施层级、受理条件、申请材料清单等固定字段，无自定义单位类字段。

## 这些特征在「知识库检索与召回」这一环带来什么约束
月度更新的数据源要求知识库需配置定期同步任务，避免数据滞后影响业务。结构化的文档格式要求检索需兼顾表格字段与文本内容的匹配精度，避免模糊匹配导致的字段错位。多来源的跨层级数据需通过数据集分组区分国家、省、市、县四级目录，防止不同层级的事项条目混淆。固定字段的存在要求检索召回结果需优先匹配事项编码、实施层级等核心标识，确保检索结果与业务需求对齐。

## 配置怎么定
以下配置说明基于FastGPT v4.17.0版本的功能逻辑。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.80 | 适配结构化政务文档的字段匹配精度，避免召回无关的事项条目 |
| `limit` | 前8条 | 覆盖单事项的关联文档（目录、指南、材料清单等），同时控制上下文长度 |
| `searchMode` | 混合检索 | 同时匹配文本关键词与结构化字段，适配政务文档的多维度内容 |
| `usingReRank` | 开启 | 对初始召回结果二次排序，修正关键词匹配的优先级偏差 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于原问题生成扩展查询词，覆盖政策文件中的同义表述 |
| `collectionIds` | 按行政层级分组 | 区分国家、省、市、县级数据集，避免跨层级数据混淆 |

## 容易做错的三处
- 现象：调试模式下检索结果显示文档下载链接，发布应用后链接消失。原因：未在发布配置中开启文档引用权限，或数据集未配置公开访问权限。
- 现象：上传政务服务事项PDF文档后向量化耗时过长。原因：未开启文档分块优化，或使用了超出系统处理上限的大尺寸文档。
- 现象：知识库搜索配置的引用上限与工作流中搜索配置的上限不一致。原因：未注意到应用端与工作流端的检索参数默认配置存在差异，未手动统一配置项取值。

## 怎么确认配好了
- 执行调试模式检索，检查召回结果是否包含对应层级的政务事项文档，且匹配字段符合预期。
- 触发一次月度同步任务，确认数据源更新后知识库能自动拉取最新的事项目录与指南文档。
- 查看检索日志，确认召回结果的相似度得分落在配置的区间内，且重排后的结果排序合理。
- 测试不同层级的事项查询，确认不同`collectionIds`对应的数据集仅召回对应行政层级的文档。
