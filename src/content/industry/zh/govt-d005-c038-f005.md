# 政府采购项目的政策与制度依据问答：工具调用与插件

## 这个品类的数据长什么样
该品类的数据来源包括中国政府采购网、地方政府采购网、财政一体化系统、采购人预算系统及供应商信用记录，更新频率为每日更新。日常处理的文档涵盖采购需求、采购计划、招标文件、投标文件、评标报告、中标公告、采购合同、质疑答复等，文档结构包含采购项目明细、政策依据关联字段、监管要求标识等，涉及采购人、财政监管部门、采购代理机构、评审专家等多方主体的业务信息。

## 这些特征在「工具调用与插件」这一环带来什么约束
每日更新的数据源要求工具调用需配置定时同步机制，确保问答数据与官方发布内容保持一致。多类型的业务文档要求插件需支持多格式解析，包括PDF格式的招标文件与评标报告。多数据源对接需求要求插件配置需区分不同系统的认证方式与接口规范。同时，政府采购业务的监管要求严格，工具调用的结果需可溯源至原始文档，因此需配置持久化存储插件保存解析后的业务数据。此外，不同文档的字段差异要求`toolChoice`需适配不同类型政策依据的调用逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | 自动 | 适配政府采购多类型政策文档的问答场景，自动匹配对应调用逻辑 |
| `functionCall` | 启用 | 用于调用外部插件拉取最新政府采购数据，保障问答内容实时性 |
| 定时同步周期 | 每日 0 点 | 匹配数据源日更新频率，确保问答数据始终为最新版本 |
| 文档存储插件 | MinIO | 保存解析后的采购文档与中间结果，适配日更数据的持久化需求 |
| 文档存储容量 | 1000–2000 MB | 覆盖全量采购项目文档的存储需求 |
| 单次返回结果条数 | 前10条 | 控制问答返回的政策依据数量，避免信息过载 |
| PDF增强解析 | 启用 | 适配招标文件、评标报告等PDF格式文档的解析需求 |

## 容易做错的三处
- 现象：启用PDF增强解析后仍无法解析政府采购招标文件的PDF，原因：未在插件配置中开启PDF增强解析开关，或上传的PDF文件格式不符合标准。

## 怎么确认配好了
- 手动触发一次定时同步任务，检查MinIO存储桶中是否生成对应政府采购文档的解析副本。
- 调用API发起政策问答请求，验证返回结果中包含对应采购项目的政策依据内容。
- 查看插件管理页面，确认多数据源连接、PDF增强解析等配置项状态为启用。
- 模拟数据库连接请求，检查是否能正常拉取财政一体化系统中的采购计划数据。
