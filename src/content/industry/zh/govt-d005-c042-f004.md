# 法务合规与重大风险管理的政策与制度依据问答：工作流编排

## 这个品类的数据长什么样
该品类的核心数据来自企业合同管理系统、合规风险数据库、法律法规库、案件管理系统、举报平台，日常处理的文档包括合规风险清单、合同法律审核意见、重大事项法律意见书、合规审查表、违规举报调查报告。数据更新频率为月度，文档结构多包含合规条款、审核意见、处理结果等字段，无统一固定单位，需按文档类型适配字段格式。

## 这些特征在「工作流编排」这一环带来什么约束
多数据源接入要求工作流需绑定多个数据来源变量，确保问答可调用全量合规相关数据；月度更新频率要求工作流配置同步周期匹配数据更新节奏，避免使用过期内容；文档类型多样要求分块规则适配不同长度的审核意见、审查表等内容；出错后果严重要求工作流必须配置引用校验环节，确保返回内容符合合规要求。

## 配置怎么定
本文档基于FastGPT v4.17.0版本编写，配置项及建议如下：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 绑定合规风险数据库、合同管理系统、法律法规库三个数据源 | 匹配该品类多数据源的业务数据特征 |
| `nodeId` | 对应合规问答工作流的根节点ID | 确保工作流调试与触发绑定正确节点 |
| 单次召回上限 | 前5条 | 避免过多无关内容干扰大模型判断，符合合规问答的精准性要求 |
| 上下文长度限制 | 8000–12000 token | 适配合规文档的平均长度，确保完整调用相关合规依据 |
| 引用校验触发 | 按实测标定 | 匹配该品类出错后果严重的业务特征，确保校验逻辑有效 |
| 失败重试次数 | 2次 | 应对多数据源调用可能出现的临时异常，避免工作流直接中断 |

## 容易做错的三处
- 调试工作流时无法停止当前节点，界面显示调试状态持续运行：原因是未正确配置`nodeId`参数，未绑定对应工作流节点的唯一标识，导致调试进程无法精准终止。
- 变量选择下拉菜单仅能选择单个变量，无法引用多数据源内容：原因是`variables`配置未添加多数据源绑定项，仅绑定了单一数据源变量。
- 大模型返回的答案未标注引用来源或引用内容与问题不匹配：原因是未配置引用校验触发规则，未将大模型生成内容与知识库中的合规文档进行匹配校验。

## 怎么确认配好了
- 检查`variables`配置是否绑定了合规风险数据库、合同管理系统、法律法规库三个指定数据源。
- 触发工作流测试，确认变量选择下拉菜单可选择多个绑定的数据源变量。
- 提交测试用的合规审查请求，查看大模型是否返回引用校验结果，标注知识库来源。
- 进入工作流调试模式，尝试停止当前节点，确认调试状态可正常终止。
