# 法务合规与重大风险管理的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据来源为企业合同管理系统、合规风险数据库、法律法规库、案件管理系统、举报平台。数据更新频率为月度，日常文档包含合规风险清单、合同法律审核意见、重大事项法律意见书、合规审查表、违规举报调查报告。文档结构多为事项关联依据、审核意见、处理结果三类核心字段，无统一的单位类字段，不同来源的文档格式存在差异。

## 这些特征在「知识库检索与召回」这一环带来什么约束
月度更新的频率要求知识库同步周期需匹配更新节奏，避免频繁同步占用系统资源。多来源、多格式的文档特征，要求检索系统需适配不同文档的字段结构，避免因格式差异导致召回偏差。合规内容的严谨性要求，需严格控制检索结果的相关性，防止低相关内容干扰合规判断。多系统的数据来源，需限定检索范围在合规专属数据集内，避免无关数据混入检索结果。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配法务合规文档的严谨性要求，平衡召回覆盖率与结果相关性 |
| `limit` | 前10条 | 适配月度更新的合规文档体量，平衡检索效率与结果覆盖范围 |
| `searchMode` | 精准匹配 | 针对合规依据的条款式内容，优先匹配关键词的精准对应关系 |
| `usingReRank` | 开启 | 提升高相关合规文档的排序优先级，强化检索结果的严谨性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充政策制度的同义词扩展，覆盖不同表述的合规依据 |
| `collectionIds` | 按合规专属数据集配置 | 限定检索范围在法务合规相关的知识库集合，避免无关数据干扰 |

## 容易做错的三处
- 导入的PDF合规文档在检索结果中无法打开。未配置文档解析的专属适配规则，或备份恢复时未同步关联的解析插件配置。
- 检索完成后重排模型持续占用显存。未设置检索流程结束后自动卸载重排模型的逻辑，导致显存资源被长期占用。
- 检索结果未命中核心合规依据条款。未开启`datasetSearchUsingExtensionQuery`扩展查询，无法覆盖政策制度的同义表述，漏召回关键依据。

## 怎么确认配好了
- 进入FastGPT的知识库检索测试页面，输入合规风险相关的典型问题，核对返回结果的文档类型是否均属于合规相关文档。
- 查看检索配置面板，确认`usingReRank`、`datasetSearchUsingExtensionQuery`的开关状态与预设配置一致。
- 模拟月度数据更新流程，验证知识库同步任务是否能正常触发并完成更新。
- 检查检索结果的排序，确认高相关的合规依据文档排在前列，符合预设的匹配要求。
