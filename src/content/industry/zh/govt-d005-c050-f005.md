# 财政支出绩效评价的政策与制度依据问答：工具调用与插件

## 这个品类的数据长什么样
本品类数据来源包括预算管理一体化系统、项目申报材料、资金支付数据、业务系统台账与满意度调查结果，更新频率为年度。日常处理的文档包含绩效目标表、自评表、绩效评价报告、佐证材料清单与整改报告，数据字段涵盖绩效量化指标、资金拨付节点、佐证材料编号、评价得分项与整改完成状态等，无额外自定义统计字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
年度更新的特性要求工具调用缓存策略适配年度数据周期，避免重复调用存量数据。多来源的数据对接需求，要求插件支持对接预算管理一体化系统、业务台账系统等多类数据源的API接口。文档结构的多样性，需要工具调用模块适配绩效目标表、自评报告等不同格式的文档解析规则。固定的字段体系要求工具调用的输出结果严格匹配预设字段，避免无关内容混入问答流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `"auto"` | 适配多类政策文档与绩效数据的自动工具选择逻辑 |
| `functionCall` | `"strict"` | 确保工具调用输出严格匹配绩效指标、资金节点等预设字段 |
| 工具调用运行记录开关 | 关闭 | 避免生成冗余的运行记录内容 |
| API调用超时时间 | `120 秒` | 适配年度批量数据查询的响应延迟 |
| 工具调用重试次数 | `2 次` | 应对多系统对接的临时连接异常 |
| 数据缓存有效期 | `365 天` | 适配本品类年度更新的特性，避免重复调用存量数据 |

## 容易做错的三处
- 现象：工具调用模块持续输出运行记录，干扰正常问答流程。原因：未关闭工具调用运行记录的默认开关，导致全量日志被同步返回。
- 现象：调用外部工具时出现连接失败报错，无法正常获取绩效数据。原因：未设置合理的重试次数与超时时间，无法应对预算管理一体化系统的临时连接波动。
- 现象：工具调用返回的内容与预设绩效字段不匹配，无法直接用于评价报告生成。原因：未开启`functionCall`的严格模式，导致工具输出混入无关字段的内容。

## 怎么确认配好了
- 发起单条政策依据问答测试，确认工具调用的运行记录未随最终回答同步输出。
- 对接预算管理一体化系统的测试接口，发起数据查询请求，确认工具调用可正常获取对应数据源的内容。
- 输入包含绩效指标的测试问题，检查工具调用输出是否严格匹配预设的绩效字段与文档格式。
- 测试禁用流输出功能，确认问答流程的内容返回符合预期格式。
