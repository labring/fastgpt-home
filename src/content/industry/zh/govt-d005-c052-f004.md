# 部门决算与财务报告的政策与制度依据问答：工作流编排

## 这个品类的数据长什么样
这个品类的典型数据来自预算管理一体化系统、国库集中支付系统、会计核算系统与资产管理系统，更新频率为年度周期，于每年年度结束后启动处理。日常生成的文档包含部门决算报表、资产负债表、收入支出决算表、决算说明及政府财务报告，文档结构以标准化报表字段与文字说明为主，涵盖实际收支、资产负债及预算执行差异相关内容。本页面配置基于FastGPT v4.17.0版本。

## 这些特征在「工作流编排」这一环带来什么约束
年度更新的特性要求工作流的知识库同步配置为每年1次，避免高频无效更新。多源数据来源决定工作流需绑定`nodeId`对应的多系统检索节点，确保覆盖全部相关政策依据文档。标准化的报表与说明结构，要求工作流针对差异说明、收支核对等核心环节配置精准检索规则，同时需适配出错后果的约束，强化引用内容的合规性校验。节点超时需设置为60秒，避免长时间等待检索结果，符合年度决算的处理节奏。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 单次搜索引用上限 | 前10条 | 部门决算单条文档内容较长，过多引用会超出token限制 |
| 自动触发配置 | 会话启动时触发 | 无需用户手动发送消息即可启动政策依据问答流程 |
| `variables` 配置 | 按接口调用时传入业务参数 | 适配不同预算单位的决算场景需求 |
| 引用校验节点 | 启用大模型校验 | 确保检索到的政策依据符合决算相关要求 |
| 上下文长度限制 | 8000–12000 token | 覆盖决算文档与政策依据的完整内容 |
| `nodeId` 配置 | 绑定多源数据检索节点 | 整合预算管理一体化、国库集中支付等系统的数据源 |

## 容易做错的三处
- 现象：接口调用时传入`variables`参数后返回结果不符合预期，原因是未将变量与决算场景的业务参数正确绑定。
- 现象：单次搜索引用上限设置为2000后，回答token超过限制，出现内容截断或接口报错，原因是未考虑部门决算文档单条内容的长度。
- 现象：未配置自动触发节点，需要用户手动发送消息才开始回复，原因是未启用会话启动触发的工作流配置。

## 怎么确认配好了
- 启动空白会话，查看是否自动触发工作流并返回与政策依据相关的内容。
- 调用API接口，传入预设的`variables`参数，验证返回结果是否匹配传入的业务场景。
- 调整单次搜索引用上限为5条，查看返回结果的token数量是否符合预期。
- 触发引用校验节点，输入一条不符合决算政策的引用内容，验证是否能识别并返回异常提示。
