# 部门决算与财务报告的政策与制度依据问答：部署与升级

## 这个品类的数据长什么样
本品类的数据主要来自预算管理一体化系统、国库集中支付系统、会计核算系统与资产管理系统，更新频率为年度周期。日常产出的文档包含部门决算报表、资产负债表、收入支出决算表、决算说明、政府财务报告，数据字段涵盖收支明细、资产负债余额、预算执行差异说明等，单位以人民币元为核心计量标准，所有数据需匹配财政部门统一的报表格式规范。

## 这些特征在「部署与升级」这一环带来什么约束
本品类的年度更新周期要求部署阶段需配置稳定的批量数据同步机制，适配多系统来源的数据接入。固定的文档结构与统一的报表格式，要求知识库索引需匹配部门决算报表的章节划分，确保问答能精准定位对应内容。多系统数据来源需提前配置合规的数据源连接，内网部署场景下需调整网络访问策略，避免跨系统数据拉取失败。年度决算的高合规性要求，需在升级阶段强化问答结果的来源溯源能力，确保政策依据匹配准确。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://fastgpt:securepass@internal-mongo:27017/financial?authSource=admin` | 存储决算报表的结构化数据与政策关联条目，支持年度批量数据写入 |
| `PG_URL` | `postgresql://financial:dbpass@internal-pg:5432/finance?sslmode=require` | 存储问答的历史记录与权限配置，保障数据的事务一致性 |
| `REDIS_URL` | `redis://:redispass@internal-redis:6379/1` | 缓存高频政策问答的匹配结果，降低重复计算的资源消耗 |
| `STORAGE_S3_ENDPOINT` | `http://internal-s3:9000` | 适配内网部署的本地对象存储，存储原始决算文档与解析后的文本内容 |
| `ROOT_KEY` | `32位随机大写小写加数字组合字符串` | 保障内网后台管理的访问权限安全，防止未授权操作 |
| `DB_MAX_LINK` | `100 个连接` | 限制数据库的最大并发连接数，适配年度批量决算数据的导入场景 |

## 容易做错的三处
- 现象：内网部署时出现数据库连接超时报错，状态码504。原因：未配置内网系统的IP白名单，导致跨系统数据拉取被拦截。
- 现象：重启服务器后，Docker 容器内的配置与知识库数据全部清空。原因：未挂载本地卷持久化存储数据库与缓存数据，容器重启后临时文件被清除。
- 现象：调用政策问答接口时返回空结果。原因：未将决算报表的章节结构与知识库分块匹配，导致问答无法定位对应政策依据。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`MONGODB_URI`与`PG_URL`的连接状态，确保无超时或权限报错。
- 上传一份年度决算报表的示例文件，检查`STORAGE_S3_ENDPOINT`是否能正常存储与解析文件。
- 发起一条针对部门决算报表格式的政策问答，验证返回结果能匹配对应的文档章节与数据来源。
- 重启Docker容器后，检查知识库与配置数据是否完整保留，确认持久化存储配置生效。
