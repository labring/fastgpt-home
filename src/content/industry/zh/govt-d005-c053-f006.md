# 部门预算编制的政策与制度依据问答：引用来源与溯源

## 这个品类的数据长什么样
本品类涉及的数据主要来自预算管理一体化系统、部门人员编制系统、以前年度决算数据、项目库及财政部发布的年度预算编制通知。日常产出的文档包括部门预算草案、项目申报书、绩效目标表、人员经费测算表、预算批复文件。数据更新频率为年度周期，核心字段包含预算编制依据、项目支出明细、人员编制基数等，单位多为万元、人等财政核算标准格式。

## 这些特征在「引用来源与溯源」这一环带来什么约束
年度更新的特性要求知识库需按年度完成全量数据同步，避免跨周期引用失效。多源数据的混合使用，要求溯源环节需关联不同系统的元数据标记，明确每条政策依据的来源系统与发布主体。文档层级复杂且包含明细字段，溯源需支持从问答结果直接跳转至对应预算草案条款、项目申报书章节或财政部通知原文。同时，预算编制的合规性要求极高，溯源结果需直接匹配审核环节的校验规则，无法提供精准来源的内容会导致预算申请被退回。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 1200–1800 token | 匹配部门预算编制相关文档的单条引用内容长度，确保完整提取政策依据原文 |
| `responseData` | 开启来源字段返回 | 用于携带知识库中对应文档的元数据，包括来源系统、发布时间、文档类型 |
| `detail` | 开启详细溯源模式 | 支持返回引用内容在原始文档中的具体页码或章节位置 |
| 单次搜索上限 | 前6条召回结果 | 覆盖部门预算编制常用的政策依据类型，避免遗漏关键参考文件 |
| 上下文窗口 | 8000–10000 字符 | 容纳多份预算编制相关文档的关联内容，确保问答时可调用完整政策链条 |
| 重排阈值 | 按实测标定 | 适配财政政策文档的语义相似度判断，避免召回无关的跨年度预算数据 |

## 容易做错的三处
- 现象：调用后返回的引用字段为空，无法展示来源文档信息。原因：未开启`responseData`配置项，未启用来源元数据返回功能。
- 现象：召回结果与提问内容无关，例如用年度预算编制问题召回了往年决算的冗余数据。原因：未设置合理的重排阈值，或未限定搜索范围为当前年度的预算编制政策文档。
- 现象：引用内容被截断，无法展示完整的政策条款原文。原因：`quoteMaxToken`取值过小，未匹配部门预算编制文档的单条引用长度要求。

## 怎么确认配好了
- 发起包含“XX年度部门预算编制依据”的测试提问，检查返回结果中是否包含明确的来源文档名称与章节信息。
- 查看返回结果的元数据字段，确认是否携带`responseData`配置项对应的来源系统、发布时间等标记。
- 测试不同长度的政策类提问，检查引用内容是否完整，未出现截断情况。
- 模拟跨年度的提问场景，确认召回结果仅包含当前年度的有效预算编制政策数据。
