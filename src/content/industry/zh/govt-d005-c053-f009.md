# 部门预算编制的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自预算管理一体化系统、部门人员编制系统、以前年度决算、项目库及财政部发布的预算编制通知。日常处理的文档包含部门预算草案、项目申报书、绩效目标表、人员经费测算表、预算批复等。数据更新频率为年度，通常在每年预算编制周期内完成一次全量更新。文档字段包含项目编码、人员编制数、经费测算值、绩效目标等，单位需结合具体业务场景匹配，无统一固定标准。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据年度更新且来源分散，要求模型接入需支持非高频的全量或增量数据同步，避免无效的重复调用。多类型业务文档的混合处理，要求配置环节需适配不同格式的文本解析，同时需调整上下文窗口以容纳完整的政策与预算文档。数据严谨性要求高，需限制模型生成的随机性，同时需确保调用日志可留存备查。内网部署的场景要求配置无需依赖公网资源，可直接调用内网部署的模型API。此外，政策与制度依据的问答需精准匹配条文内容，对模型的上下文召回精度有明确要求。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配部门预算政策文档及年度预算报表的总长度，避免截断关键政策依据 |
| `maxTokens` | 2000–3000 token | 限制单轮回答的输出长度，确保政策与制度依据的回答清晰完整，符合预算审核的阅读习惯 |
| `temperature` | 0.1–0.3 | 降低模型生成的随机性，提升政策引用的准确性，适配预算编制的严谨性要求 |
| `AIPROXY_API_ENDPOINT` | 内网部署的大模型服务访问地址 | 适配内网部署的模型环境，无需依赖公网资源 |
| `AIPROXY_API_TOKEN` | 内网模型分配的访问密钥 | 验证内网模型的调用权限，确保接口访问安全 |
| `quoteMaxToken` | 1500 token | 限制引用的文档片段长度，聚焦核心政策条款，避免冗余信息干扰问答结果 |

## 容易做错的三处
- 现象：切换模型渠道时返回304状态码，或调用日志显示获取数据异常。原因：本地前端项目未清理缓存导致接口请求未更新，或内网环境下的代理配置未正确转发模型API请求。
- 现象：仅支持stream模式的大模型调用失败，返回格式错误或无有效内容。原因：未在模型配置中适配stream模式的返回格式，未正确处理流式数据的拼接逻辑。
- 现象：调用模型渠道时弹出报错弹窗，日志显示获取数据异常。原因：`AIPROXY_API_TOKEN`配置错误，或内网模型的访问权限未开放给FastGPT部署服务器。

## 怎么确认配好了
- 调用内网模型的测试接口，验证`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`的配置是否生效，查看返回的模型响应是否正常。
- 上传单份预算政策文档，测试`maxContext`和`quoteMaxToken`的配置是否能完整加载并引用文档内容，无截断情况。
- 调整`temperature`参数，对比不同取值下的政策问答结果，确认生成内容的严谨性符合业务要求。
- 开启stream模式测试，验证流式返回的内容能否正常拼接并展示为完整的问答结果。
