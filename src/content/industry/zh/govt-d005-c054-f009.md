# 防汛防灾与应急值守的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
本品类的典型数据来自气象预警系统、水文监测系统、应急指挥平台、基层报灾系统与视频监控。日常处理的文档包含值班记录、预警通知、会商纪要、灾情速报、应急处置方案、物资调拨单，字段包含雨情水情数值、预警等级、处置时限、物资品类与数量等。数据更新频率为每日，部分实时预警数据更新间隔更短，文档结构多为结构化字段与非结构化文本混合的格式。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据多为实时更新的混合格式文本，且需快速支撑会商与预警处置，因此模型接入需适配高频更新的数据源。混合结构的文档要求配置支持多类型文本解析，避免结构化字段丢失或非结构化内容截断。同时，预警与处置的时效性要求限制了上下文窗口与生成时长，需平衡内容完整性与响应速度。此外，数据来源跨多个内部系统，需确保模型调用的接口稳定性，适配多源数据的格式转换需求。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配会商纪要、灾情速报等多文档拼接的上下文需求，避免关键政策依据被截断 |
| `maxTokens` | 2000–3000 token | 满足政策条款解读、处置方案生成的内容长度，避免生成不完整 |
| `quoteMaxToken` | 1500 token | 限制引用文档的片段长度，确保检索到的政策依据与业务场景匹配 |
| `temperature` | 0.2–0.4 | 降低生成随机性，确保政策解读的准确性，避免出现不符合制度要求的表述 |
| `toolChoice` | auto | 自动调用检索工具获取最新政策与实时数据，适配应急场景的快速响应需求 |
| `AIPROXY_API_TOKEN` | 按权限申请的专属密钥 | 保障接口调用的安全性，避免未授权访问内部应急数据 |

## 容易做错的三处
- 调用知识库索引生成接口时模型变更，现象为检索结果与历史配置下的结果不一致，原因是未同步更新原有知识库的嵌入模型配置，导致新旧向量空间不匹配。
- 配置三方大模型API时出现调用失败，现象为接口返回401状态码或连接超时，原因是未正确填写`AIPROXY_API_TOKEN`或`AIPROXY_API_ENDPOINT`，或未配置跨部门系统的访问权限。
- Docker部署代理服务异常，现象为服务持续重启且无法访问接口，原因是未正确挂载配置文件或端口映射错误，导致服务无法正常启动。

## 怎么确认配好了
- 发起测试调用，输入防汛政策相关问题，检查返回结果是否包含检索到的最新政策依据与实时数据。
- 查看知识库索引日志，确认嵌入模型与配置项一致，无报错信息。
- 调整`temperature`参数，检查生成内容的随机性变化，确认配置生效。
- 模拟跨部门数据接入，验证`toolChoice`配置是否自动触发检索工具获取对应系统的数据。
