# 防汛防灾与应急值守的政策与制度依据问答：部署与升级

## 这个品类的数据长什么样
这个品类的数据主要来自气象预警系统、水文监测系统、应急指挥平台、基层报灾系统与视频监控。日常处理的文档包含值班记录、预警通知、会商纪要、灾情速报、应急处置方案、物资调拨单，其中值班记录包含值守时段、灾情等级、处置状态字段，预警通知包含预警级别、生效时段字段，部分文档关联雨量毫米、转移人数人次等单位。数据更新频率为每日，需同步当日最新的雨情水情、预警信息与处置动态。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据特征对部署与升级环节带来明确约束。多源数据对接需求要求配置兼容多个系统的连接参数，避免出现接口调用冲突。每日更新的频率要求设置合理的增量同步周期，保障政策与制度依据的实时性。多样的文档类型与带单位的字段，要求解析流程适配结构化表格、纯文本等不同格式，同时支持单位语义匹配。应急场景的实时性要求，需在升级时保留旧版接口兼容性，避免影响日常值守与预警响应。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `DB_MAX_LINK` | 100–200 条 | 防汛防灾场景需同时对接气象、水文等多个数据源，该参数限制数据库连接池上限，避免资源耗尽 |
| `REDIS_URL` | 本地 Redis 服务地址，端口 6379 | 用于缓存实时预警信息与用户会话，保障应急场景下的快速响应 |
| `STORAGE_S3_ENDPOINT` | 本地对象存储服务地址 | 用于存储值班记录、灾情速报等非结构化文档，适配每日增量更新的数据量 |
| `FILE_TOKEN_KEY` | 随机生成的 32 位字符串 | 用于加密文件上传请求，避免未授权访问应急相关的敏感文档 |
| `ROOT_KEY` | 随机生成的 64 位字符串 | 用于配置系统管理员权限，保障应急值守后台的访问安全 |
| `FE_DOMAIN` | 部署服务器的公网域名 | 用于配置外部平台调用的回调地址，适配应急指挥平台的接口对接需求 |

## 容易做错的三处
- 现象：调用接口后返回空响应，需展开详情才能查看完整问答内容。原因：未正确配置`FILE_TOKEN_KEY`导致文件解析权限不足，政策与制度依据文档无法被正常召回，仅在详情页暴露底层错误信息。
- 现象：部署后外部平台调用聊天接口出现超时错误。原因：未调整`DB_MAX_LINK`参数，连接池耗尽导致数据库请求阻塞，无法及时返回政策依据问答结果。
- 现象：启用工作流文件上传后，解析文档地址时报错。原因：未正确配置`STORAGE_S3_ENDPOINT`，无法访问本地存储的防汛文档，导致文件解析流程中断。

## 怎么确认配好了
- 登录FastGPT后台，检查`REDIS_URL`配置项是否指向正常运行的Redis服务，可通过redis-cli ping命令验证连接状态。
- 上传一份本地防汛预警通知文档，测试文件上传与解析流程，确认无权限或存储相关报错。
- 调用外部平台聊天接口，验证响应时长符合应急场景的实时要求，可通过多次请求对比稳定性。
- 查看系统日志，确认数据库连接池的使用量未超过`DB_MAX_LINK`的配置上限。
