# 食品安全监督抽检的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据主要来自食品安全抽检监测系统、国家市场监管总局抽检结果查询系统、检验机构LIMS及企业台账。日常文档包含抽检计划、抽样单、检验报告、不合格食品核查处置报告、风险控制通告，数据更新频率为月度。数据字段涵盖抽检批次、样品名称、检验项目、不合格项、处置措施等，无额外自定义单位，核心文档以结构化表单与非结构化报告结合为主。

## 这些特征在「知识库检索与召回」这一环带来什么约束
月度更新的数据要求检索召回需适配周期性数据刷新，避免引用过期文档。混合结构化与非结构化的文档结构，需要适配多格式内容的分块与精准匹配。多源数据接入的需求，需确保检索范围覆盖全部合规数据源。不合格处置相关文档的时效性要求极高，需优先召回最新发布的风险控制与处置通告，同时保障检验报告的字段匹配精度，避免关联错误。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 适配检验报告、抽样单等结构化文档的字段匹配精度，避免召回无关的非抽检类政策文档 |
| `limit` | 前6条 | 覆盖单次问答所需的政策依据与抽检相关文档，避免上下文过载 |
| `searchMode` | hybrid | 兼顾关键词匹配与语义检索，适配混合结构化与非结构化的抽检文档 |
| `usingReRank` | 开启 | 对召回的前10条结果进行重排，优先匹配不合格处置、检验报告等高优先级文档 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户问题扩展检索词，覆盖抽检计划、风险通告等不同类型的文档 |
| `collectionIds` | 绑定指定的食品安全抽检数据集 | 限定检索范围至合规的抽检相关数据源，避免混入其他品类的政策文档 |

## 容易做错的三处
- 现象：提问要求匹配同时满足A、B、C三项要求的抽检政策依据，返回结果仅覆盖部分条件，无法完整匹配全部需求。原因：未开启`datasetSearchUsingExtensionQuery`，未对用户问题进行语义扩展，导致召回的文档未覆盖全部相关政策条目。
- 现象：导入食品安全监管相关的微信公众号链接后，无法检索到对应文档，界面显示导入成功但检索无结果。原因：未将导入的数据集正确关联至指定的抽检业务集合，或未开启文档预处理流程。
- 现象：检索结果中混入非食品安全抽检类的政策文档，与当前业务无关。原因：未配置`collectionIds`限定检索范围，导致检索范围覆盖了其他品类的数据集。

## 怎么确认配好了
- 执行测试提问，输入「不合格食品核查处置的政策依据」，检查检索结果是否包含最新的风险控制通告与处置报告。
- 查看检索结果的来源标签，确认仅包含绑定的食品安全抽检数据集内容，无无关文档。
- 测试多条件提问，输入「同时满足抽样规范、检验标准、处置要求的抽检政策」，检查返回结果是否覆盖全部相关条目。
- 开启`usingReRank`后，查看重排后的结果排序是否优先展示高优先级的检验报告与处置文档。
