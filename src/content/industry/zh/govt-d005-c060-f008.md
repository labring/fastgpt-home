# 仓储物流的政策与制度依据问答：文档解析与分块

## 这个品类的数据长什么样
仓储物流领域的政策与制度依据文档，主要来源于交通运输部、地方物流监管部门、企业内部仓储管理委员会。更新节奏为年度政策修订与按需更新内部制度。文档多为正式公文格式，包含文号、生效日期、章节条款，内嵌结构化表格（如仓储费率表、合规检查清单）与位图（如仓库布局图、消防标识）。字段包含政策编号、适用区域、处罚条款、执行标准等，单位涉及平方米、吨、小时等物流与仓储专用计量项。

## 这些特征在「文档解析与分块」这一环带来什么约束
仓储政策文档的层级化结构要求分块不能割裂章、节、条的逻辑关联，否则问答时无法准确匹配合规依据。内嵌的表格与图片会增加解析复杂度，未适配的解析逻辑可能导致表格内容丢失、图片引用报错。长篇幅的区域级仓储管理办法可能达到数百页，分块时需预留足够的上下文连贯性，避免拆分同一条款的前置条件与执行要求。同时，文档的生效日期与适用区域字段需完整保留，否则无法支撑精准的政策匹配问答。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配仓储政策文档的条款长度，可保留单条或相邻关联合规条款的完整性，避免拆分逻辑连贯的要求 |
| `chunkSplitter` | 按段落+标题层级 | 匹配政策文档的章、节、条层级结构，确保分块不割裂上下文关联 |
| `customPdfParse` | 启用结构化提取优化 | 仓储政策文档常包含表格与位图，启用后可完整提取表格内容并正确处理图片引用，避免渲染异常 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 长篇幅政策文档解析耗时较长，该时长可覆盖多数单份文档的完整解析流程 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 支持大体积区域级仓储政策文档的完整上传与解析 |

## 容易做错的三处
- 上传包含仓库布局图的docx文档后，返回结果显示`Invalid image file`报错。原因是未启用`customPdfParse`的图片提取优化，未适配仓储文档中的位图格式。
- 解析大体积仓储政策文件时，日志持续报`slow operation xxxxms`。原因是`PARSE_FILE_TIMEOUT_SECONDS`设置过短，未预留足够时长完成长文档的结构化解析。
- 政策文档中的Markdown表格输出后无法正常渲染，展示内容被截断。原因是`chunkSize`设置过小，拆分时割裂了表格的完整行或列结构。

## 怎么确认配好了
- 上传一份包含仓储费率表格与仓库布局图的政策文档，查看解析后的文本是否完整保留表格结构与图片引用标识。
- 上传一份超过300页的仓储管理办法文档，检查解析进度是否在`PARSE_FILE_TIMEOUT_SECONDS`设定的时长内完成。
- 调整`chunkSize`至不同区间，对比分块结果是否保留相邻条款的关联性，无无故拆分的独立合规条款。
- 查看系统日志，确认解析过程中未出现`Invalid image file`或超时类报错。
