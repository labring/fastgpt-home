# 化工新材料的政策与制度依据问答：多轮对话与提示词

## 这个品类的数据长什么样
化工新材料的政策数据来源为工信部、国家发改委发布的产业指导目录、新材料产业发展规划，以及各省市工信部门出台的地方配套细则、专项补贴政策。国家级政策每1-2年修订一次，地方细则每季度随产业动态调整。文档包含政策文号、发布主体、生效日期、适用细分领域、核心条款、申报条件等内容，字段含统一国民经济行业分类代码，单位涉及万吨/年、万元等产业量化指标，数据格式以官方PDF、结构化网页文本为主，单份文档长度从数百到数万字符不等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
政策文档长且包含多层级合规条款，多轮对话需保留政策文号、生效时间等核心标识，否则会出现新旧政策混淆的问题。地方细则更新频率较高，提示词需动态绑定最新生效时间的过滤条件，避免调用过期政策内容。细分领域的国民经济行业分类代码需用户在多轮中逐步补充，因此对话上下文需保留每一轮补充信息，确保召回范围精准。长文本政策无法一次性加载至模型上下文，需通过分块召回整合，因此需限制单次召回条目数量，避免上下文过载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 最大上下文 | 8000–12000 token | 适配化工新材料政策文档的长文本长度，避免截断核心政策标识与生效时间 |
| 单次召回上限 | 前6条 | 控制召回的政策条目数量，避免多轮对话中混淆不同文号的条款 |
| 对话记录保存时长 | 30天 | 符合国央企政务数据留存的常规合规要求 |
| `messages` 参数 | 保留前10轮对话上下文 | 覆盖用户在多轮中补充的区域、细分品类等限定信息，确保上下文连贯 |
| `variables` 参数 | 绑定区域、细分品类、生效时间字段 | 自动过滤过期政策，精准匹配用户的细分需求 |
| `chatId` 参数 | 绑定对话唯一标识 | 区分不同用户的对话上下文，避免跨对话的信息混淆 |

## 容易做错的三处
- 现象：执行长文本政策解析任务时，界面显示任务正常完成但抛出“The value of "offset" is out of range”报错。原因：未限制单次加载的政策文档分块长度，导致长文本超出模型输入的token上限，触发偏移量异常。
- 现象：多轮对话中无法精准召回对应区域的化工新材料补贴政策。原因：未在`variables`中绑定区域、细分品类等限定字段，导致召回范围覆盖全量政策，无法匹配用户的具体需求。
- 现象：对话记录自动清空时长超出预期。原因：未按合规要求设置对话保存时长，或误将保存时间配置为小于30天的数值，不符合国央企政务数据留存的规范要求。

## 怎么确认配好了
本文基于FastGPT v4.17.0版本，可通过以下动作核对配置是否生效：
- 发起包含区域、细分品类的多轮对话，检查召回的政策是否匹配用户补充的限定条件。
- 查看对话记录列表，确认超过30天的对话条目已被自动清理。
- 测试长文本政策解析任务，确认无偏移量相关报错。
- 在`messages`参数配置界面，查看上下文保留轮次是否符合预设的10轮要求。
- 检查`chatId`参数是否绑定了对话唯一标识，确保不同用户的对话上下文互不干扰。
