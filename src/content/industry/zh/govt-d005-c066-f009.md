# 化工新材料的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
化工新材料的政策与制度依据数据，来源于工业和信息化部、国家发展改革委发布的官方政策文件，以及全国化工新材料标准化技术委员会的标准文本。数据更新随新政策、标准出台不定期进行，文档多为结构化条款文本，按条款层级划分内容，包含政策文号、发布主体、生效日期、适用范围、具体管控要求等字段，部分附件包含产能、能耗等量化指标，单位涵盖吨、千克、标准煤以及政策生效的自然日期格式。

## 这些特征在「模型接入与配置」这一环带来什么约束
化工新材料政策文档多为长文本结构化条款，且存在层级化的内容结构，这要求模型接入时需适配长上下文处理能力，避免截断关键条款。政策更新无固定周期，部分新政策发布频率较高，数据源同步配置需支持按需触发更新。政策文档包含文号、生效日期、适用领域等专属字段，检索与问答配置需关联这些元数据，确保返回结果与对应政策精准绑定。部分政策附件包含产能、能耗等量化指标，模型提取时需适配行业通用单位的识别逻辑，避免单位识别错误。在FastGPT v4.17.0版本中，所有模型配置均通过页面完成，无需修改本地配置文件。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配化工新材料政策文档的长文本结构，完整保留条款上下文关联 |
| `quoteMaxToken` | 2000–3000 token | 确保引用的政策条款原文完整，不截断关键管控内容 |
| `temperature` | 0.1–0.3 | 严格匹配政策原文内容，降低生成内容的随机性 |
| `AIPROXY_API_ENDPOINT` | 部署的模型网关实际地址 | 统一管理模型调用链路，简化多模型切换运维 |
| `AIPROXY_API_TOKEN` | 网关分配的访问密钥 | 实现模型调用的权限管控，保障接口安全 |
| `maxTokens` | 1500–2000 token | 覆盖多条款关联的政策问答回复需求，避免回复不完整 |

## 容易做错的三处
- 调用模型时返回`status code 404`错误。原因是未正确填写`AIPROXY_API_ENDPOINT`参数，或网关地址配置错误，导致无法找到模型服务接口。
- 上传政策文件后可正常下载，但大模型提示未上传。原因是文件处理逻辑未适配长文本政策文档，分块时丢失了文件元数据标识，导致系统无法识别已上传文件。
- 模型问答返回结果与政策原文偏差较大。原因是`temperature`取值过高，导致生成内容偏离原文要求，不符合政策问答的严谨性需求。

## 怎么确认配好了
- 核对模型网关的访问地址与密钥配置，确保与FastGPT内的参数一致。
- 上传单篇化工新材料政策文档，发起针对文档内具体条款的测试问答，验证返回结果包含对应条款内容。
- 发起跨文档的政策关联问答，验证模型能正确匹配不同政策的适用范围与条款。
- 测试长文本政策文档的问答，验证返回结果未出现内容截断情况。
