# 化肥农药的政策与制度依据问答：多轮对话与提示词

## 这个品类的数据长什么样
化肥农药政策与制度依据数据主要来自农业农村部、工信部及各省级农业农村部门的公开官方文件，更新节奏随新政策出台实时同步，常规月度开展批量更新。文档包含政策原文、官方解读、配套实施细则三类，核心字段包括政策文号、发布单位、生效日期、适用地域范围与核心条款，字段格式统一遵循政务公开标准，无自定义单位或特殊格式要求。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
政策文档单篇常超五千字符，多轮对话需严格限制上下文长度避免溢出。字段包含生效日期与适用地域，提示词需明确要求模型引用具体文号与日期，同时需在多轮对话中引导用户补充地域信息以匹配对应政策。更新频率较快，提示词需加入优先使用最新发布文件的约束，避免返回过时政策内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 最大上下文长度 | 8000–12000 字符 | 适配化肥农药政策单篇长文本的多轮对话场景，避免`messages`上下文溢出 |
| 问题优化开关 | 开启 | 政策问答涉及专业术语，优化后可提升召回准确性与表述规范性 |
| 单次召回条数 | 前6 条 | 化肥农药政策文件总量有限，过多结果会干扰模型判断 |
| 上下文与超时配置 | 按实测标定，超时时间设为600 秒 | 适配FastGPT v4.17.0的`messages`上下文处理逻辑，避免长文本查询等待过久 |
| 会话持久化配置 | 开启 | 确保多轮对话的`chatId`上下文连贯，避免会话中断后数据丢失 |
| 提示词变量绑定 | 绑定政策文号与生效日期，通过`variables`传递 | 强制回复中包含合规性要求的核心信息，会话存储配额设为1000 MB |

## 容易做错的三处
- 对话中尝试上传语音文件后无响应 | 化肥农药政策问答场景未配置语音识别插件，默认仅支持文本输入
- 模型输出Markdown表格时显示`...[hide X char]`且内容截断 | 未合理设置上下文截断阈值，长表格内容被系统自动截断
- 主动关闭对话窗口后，聊天记录未同步至数据库 | 未启用会话持久化配置，临时会话数据未自动归档

## 怎么确认配好了
- 发起包含具体化肥农药政策文号的查询，核对回复中是否准确引用了对应文号与生效日期
- 发起连续多轮的政策相关提问，检查上下文内容是否完整保留且未出现异常截断
- 测试包含Markdown表格的政策解读查询，确认表格完整展示无隐藏字符提示
- 模拟短时间内多次对话请求，确认触发限流时返回符合预期的报错信息
