# 化肥农药的政策与制度依据问答：工作流编排

## 这个品类的数据长什么样
化肥农药相关政策与制度依据数据，主要来源于农业农村部、国家标准化管理委员会、国家应急管理部、国家工信部、农业农村部的官方公开渠道，更新节奏为新政策出台、新标准实施时同步更新。文档多为条款式结构，包含文号、发布主体、生效日期、适用范围、具体条款等字段，字段单位涉及吨、公顷、千克、百分比等多种类型。

## 这些特征在「工作流编排」这一环带来什么约束
化肥农药相关政策文档多为长文本条款式结构，且包含多维度字段，工作流编排时需适配长文本拆分与多字段提取。因数据更新节奏不固定，工作流需配置定期数据源同步节点。因字段单位多样，工作流需添加单位统一转换节点。因政策存在生效日期与适用范围，工作流需校验问答触发时的时间与地域匹配性，避免引用失效或不适用的政策内容。

## 配置怎么定
本配置方案基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配化肥农药政策条款式长文本的拆分粒度，平衡召回精度与上下文长度 |
| 重叠长度 | 100–200 字符 | 避免条款拆分后上下文断裂，维持政策内容的逻辑连贯性 |
| 单次搜索上限 | 前10条 | 匹配化肥农药政策数据的召回量级，过滤冗余信息 |
| 最大上下文 | 6000 字符 | 适配工作流的上下文处理能力，避免超出承载阈值 |
| `variables` | 绑定政策文号、生效日期、适用范围字段 | 保障问答时能精准调用对应政策属性 |
| `nodeId` | 绑定数据源同步节点与问答节点 | 确保工作流节点间的数据流转正常 |

## 容易做错的三处
- 工作流运行时弹出`bootstrap-legacy-autofill-overlay.js:6247 Uncaught TypeError: Cannot r`类报错：原因是未正确绑定`variables`对应的政策字段，导致节点间数据传递异常。
- 添加自定义政策查询插件后，工作流节点无输入输出参数显示：原因是未在`nodeId`配置中正确关联插件的参数映射，或插件未完成保存生效。
- 私有部署场景下工作流运行报错提示配置文件异常：原因是未正确配置数据源的访问权限，或配置文件格式不符合要求。

## 怎么确认配好了
- 触发工作流测试，检查分块后的文本片段是否完整覆盖政策条款，无明显上下文断裂。
- 查看`variables`绑定的字段是否正确对应政策文档中的文号、生效日期、适用范围等属性，无空值或错误映射。
- 运行工作流后，检查`nodeId`关联的节点是否正常流转数据，无中断提示。
- 模拟查询已失效的政策文号，确认工作流会自动过滤相关结果或提示内容失效。
