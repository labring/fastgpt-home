# 危化品储运的政策与制度依据问答：工具调用与插件

## 这个品类的数据长什么样
危化品储运的政策与制度依据数据，来源为应急管理部、交通运输部、生态环境部发布的官方公告、国家标准、行业标准及地方实施细则。数据更新随新政策发布同步调整，无固定周期。文档结构分为政策原文、条款解读、适用储运场景说明三个部分，字段包含政策编号、发布单位、生效日期、适用区域、存储/运输合规要求、处罚条款等，单位涉及文号编号、日期格式、存储量限值、温度阈值等。

## 这些特征在「工具调用与插件」这一环带来什么约束
危化品储运政策数据的长文本、多字段特征，要求工具调用需精准匹配单条政策条款，避免上下文溢出。官方数据源的合规校验需求，要求插件需在调用时验证数据来源合法性，防止非合规内容被引用。政策更新无固定周期的特点，要求插件需定期拉取最新政策库，仅在新政策发布时更新缓存。多字段的结构化特征，要求工具调用需支持按字段筛选召回结果，确保返回内容与用户提问的合规场景强相关。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配危化品政策条款的多分支调用需求，自动选择匹配的合规条款工具 |
| `functionCall` | 开启 | 强制模型输出结构化的政策字段结果，便于后续合规校验与引用 |
| 单次召回条数 | 前3条 | 匹配单条政策条款的合理长度，避免超出上下文窗口限制 |
| 上下文窗口长度 | 8000–12000 token | 适配长政策文档的完整召回与解读需求 |
| 超时时间 | 60秒 | 应对官方政策数据源的拉取与解析延迟 |
| 重排开关 | 开启 | 按政策生效优先级排序召回结果，符合合规审核要求 |

## 容易做错的三处
- 对话返回自然语言的政策片段，未提取到结构化字段。原因是未开启`functionCall`配置，模型未按要求输出指定格式的结果。
- 调用接口未返回关联的知识库标识。原因是未绑定专属的危化品政策知识库，或召回阈值设置过高导致未匹配到有效数据。
- 工具调用频繁触发超时报错。原因是超时时间设置过短，无法完成官方政策数据源的完整拉取与解析。

## 怎么确认配好了
- 发起包含具体危化品储运合规要求的提问，检查返回结果是否为结构化的字段列表，包含政策编号、生效日期等信息。
- 查看对话日志，确认返回结果中包含关联的知识库标识字段。
- 模拟延迟场景，验证配置的超时时间是否能覆盖官方数据源的正常拉取延迟。
- 测试不同政策关键词的召回，确认结果按生效优先级排序。
