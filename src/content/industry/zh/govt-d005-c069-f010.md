# 危化品储运的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
来源为应急管理部、交通运输部、生态环境部等官方监管机构发布的合规文件、行业标准及地方监管细则。更新节奏随新政策出台同步调整，无固定周期。文档多为条款式结构，包含储运条件、审批流程、应急处置要求等内容，字段涵盖文件文号、发布机构、生效日期、计量单位（如立方米、吨、摄氏度）等，单篇文档的长度跨度较大，从数百字的地方细则到数万字的国家级标准均有覆盖。

## 这些特征在「知识库检索与召回」这一环带来什么约束
官方发布的政策文本严谨性强，要求检索结果需匹配原文表述，因此检索阈值需设置合理区间。条款式文档结构导致长文本需按条款边界切割，避免语义断裂影响召回精度。字段包含专业计量单位与元数据，检索时需保留字段关联信息，避免因单位歧义或元数据缺失导致匹配偏差。更新随政策变动同步，需定期执行增量同步，确保知识库内容与最新监管要求一致。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 危化品政策内容严谨，需较高匹配度过滤无关条款，同时保留足够候选结果覆盖问答需求 |
| `limit` | 前8条 | 单条政策条款内容精准，少量召回即可覆盖核心问答范围，避免上下文溢出 |
| `searchMode` | semantic | 政策文本语义逻辑紧密，语义搜索比关键词搜索更贴合政策问答的语义匹配需求 |
| `usingReRank` | 开启 | 提升高相关结果的排序优先级，避免低匹配但关键词重合的非核心条款靠前展示 |
| `datasetSearchUsingExtensionQuery` | 开启 | 针对政策问题自动扩展相关监管术语，提升对不同表述方式的政策条款的召回覆盖度 |
| `collectionIds` | 对应危化品储运政策知识库的集合ID | 限定检索范围，避免混入其他品类的政策文档，确保问答仅关联目标领域内容 |

## 容易做错的三处
- 调用知识库查询接口返回空结果，无匹配内容。原因：应用与知识库分属不同团队，未配置跨团队知识库访问权限。
- 检索结果出现大量无关的通用化工条款，与危化品储运场景不匹配。原因：相似度阈值设置过低，召回了非精准匹配的内容。
- 长政策文档的关键条款未被召回，或回答出现语义断裂。原因：分块未按条款边界切割，导致单块内容语义不完整，无法被有效匹配。

## 怎么确认配好了
- 进入FastGPT v4.17.0的应用配置页，核对关联的知识库集合ID与目标危化品储运政策库的ID一致。
- 发起单条政策相关的测试查询，查看返回结果的相似度得分是否处于0.75–0.85区间内。
- 开启重排功能后，核对排序第一的结果是否为与问题最相关的政策条款。
- 检查知识库同步日志，确认最新发布的政策文件已完成增量同步。
