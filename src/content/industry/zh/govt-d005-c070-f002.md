# 发电装备制造的政策与制度依据问答：向量模型与索引

## 这个品类的数据长什么样
发电装备制造领域的政策与制度依据数据，主要来源于国家能源局、工业和信息化部发布的装备制造行业合规文件、行业协会制定的标准规范，以及地方政府出台的产业扶持政策。数据更新节奏随政策修订、新国标出台调整，无固定周期。文档结构包含政策文号、发布单位、生效日期、适用装备类型、条款原文等字段，部分长文档按章节划分条款，单位以条款章节号、生效日期格式为主，未使用复杂量化单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
政策文档的层级化结构要求分块时保留文号、生效日期等元数据，避免破坏条款的完整合规性；长文本条款需要适配嵌入模型的token上限，防止分块截断关键内容；数据更新不频繁但需及时同步，索引流程需支持增量更新；专业术语密集的政策文本需要嵌入模型具备领域适配能力，确保向量匹配的精准性；元数据字段（如生效日期）需作为索引标签，便于后续按时间范围筛选政策依据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配政策条款的单段长度，避免破坏完整合规条款的语义完整性 |
| 重叠长度 | 100–200 字符 | 保留跨块的政策上下文，防止分块截断跨章节的关联合规要求 |
| `defaultToken` | 8192 | 匹配Qwen3-Embedding-8B的输入token上限，适配分块后的政策文本长度 |
| 相似度阈值 | 0.75–0.85 按实测标定 | 过滤非核心政策条款，确保问答匹配的精准性，避免无关内容干扰 |
| 单次搜索上限 | 前6条 | 覆盖同领域的相关政策文件，避免遗漏必要的合规依据 |
| `maxToken` | 16384 | 适配检索后上下文拼接的总长度，满足长政策文本的完整问答需求 |

## 容易做错的三处
- 现象：文件状态持续显示“索引中”，长时间未完成索引。原因：配置的`defaultToken`未匹配嵌入模型的输入上限，导致分块文本无法完成向量化流程。
- 现象：检索结果出现重复的政策条款条目。原因：重叠长度设置过大，导致分块重叠比例过高，索引时生成了大量重复的向量数据。
- 现象：同名嵌入模型配置被自动覆盖，无法同时使用本地M3E与Qwen3-Embedding-8B。原因：未为不同场景配置独立的模型别名，系统默认以模型名称作为唯一标识，导致后续配置覆盖前置配置。

## 怎么确认配好了
- 进入FastGPT v4.17.0的模型管理页面，查看已配置的嵌入模型列表，确认目标模型（如Qwen3-Embedding-8B、本地部署的M3E）存在且未被覆盖。
- 上传单条政策文档，等待索引完成后查看分块预览，确认分块长度符合预设区间且保留了政策文号、生效日期等元数据。
- 发起政策相关测试提问，查看检索结果的条数与相似度得分，确认匹配结果符合预设阈值要求。
- 检查系统运行日志，确认无嵌入模型调用超时或分块失败的报错信息。
