# 发电装备制造的政策与制度依据问答：引用来源与溯源

## 这个品类的数据长什么样
发电装备制造领域的政策与制度依据数据，主要来源于国家能源局、工业和信息化部、国务院国有资产监督管理委员会的官方公开文件，以及中国电力企业联合会发布的行业标准。数据更新随正式政策发布即时生效，行业标准每1至2年完成一次修订。文档结构包含政策文号、发布单位、发布日期、适用装备类型（如汽轮机组、发电机组件）、合规条款、关联处罚条款等字段，字段单位多采用条款编号、适用机组功率等级等行业通用表述。本文档基于FastGPT v4.17.0版本的配置逻辑编写。

## 这些特征在「引用来源与溯源」这一环带来什么约束
发电装备制造的政策数据带有明确的行业细分标签与精准条款定位，要求溯源环节必须绑定政策文号、发布单位等唯一标识，避免仅引用正文内容导致溯源模糊。适用装备类型的细分字段要求检索时需关联对应品类的装备参数，过滤无关政策内容，降低溯源噪声。政策更新频率较高，要求知识库同步周期匹配官方发布节奏，确保溯源内容的时效性。文档包含附件与分层条款，溯源环节需支持关联附件内容并精准定位具体条款位置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 最大上下文 | 8000–12000 token | 发电装备制造政策文档条款密集，需容纳足够多关联条款，避免截断关键溯源信息 |
| `quoteMaxToken` | 2000–3000 token | 限制单条溯源内容的token消耗，适配长条款特征，控制大模型输入成本 |
| 返回源数据 | 开启 | 直接输出知识库原文，满足政策依据问答对原文合规性的要求 |
| 单次搜索上限 | 前6条 | 发电装备政策数量适中，选取前6条可覆盖核心合规依据，避免冗余干扰 |
| `responseData` | 开启 | 强制返回知识库原文内容，无需大模型改写，保证溯源内容原始性 |
| `detail` | 开启条款级定位 | 精准匹配政策中的具体条款编号，提升溯源内容的定位精度 |

## 容易做错的三处
- 现象为工作流中配置的全局变量datasetid在知识库检索节点中未生效，对应字段为空。原因是未在检索节点的数据源配置中绑定全局变量映射，仅在全局变量面板设置未关联节点参数。
- 现象为AI输出的政策内容被添加非原文的修饰性表述，与知识库原文不一致。原因是未开启`responseData`配置，导致大模型对检索到的原文进行了二次加工。
- 现象为检索节点传入的token数超过预设阈值，导致工作流出现超时或报错。原因是未配置`quoteMaxToken`限制单条溯源内容的token长度，导致长文档被完整传入大模型。

## 怎么确认配好了
- 进入知识库检索节点的配置面板，检查全局变量是否已正确映射到数据源参数，触发测试检索查看返回结果的数据源标识是否匹配预设值。
- 开启`responseData`配置后，发起测试问答，查看返回内容是否与知识库原文完全一致，无额外添加的修饰性语句。
- 查看工作流运行日志，确认检索节点传入的token数未超过`quoteMaxToken`的预设值，无异常截断或超额消耗。
- 调整单次搜索上限参数，发起多轮测试问答，确认返回的政策条款数量符合配置要求。
