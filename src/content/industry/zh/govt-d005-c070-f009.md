# 发电装备制造的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
数据主要来源于国家能源局、工业和信息化部发布的发电装备制造相关政策文件、行业标准及合规要求。更新节奏随政策正式发布同步调整，无固定周期。单份文档包含政策文号、发布单位、生效日期、适用场景、具体条款等字段，部分长文档拆分后仍保留完整的政策层级结构，单位以标准公文格式为准，无自定义特殊单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
政策文档的字段明确且层级清晰，要求检索时需精准匹配特定文号或生效日期的文档，避免跨政策混淆。长文本占比高，需预留足够的上下文处理空间。无固定更新周期，知识库需支持灵活的文档更新机制。字段的标准化要求检索模型需准确识别政策条款的层级，确保回答引用的准确性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的界面与参数逻辑制定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 发电装备制造政策文档普遍较长，需加载足够的上下文以覆盖完整政策内容 |
| `maxTokens` | 2000–3000 token | 政策问答需详细阐述条款依据，预留充足的回答生成空间 |
| `quoteMaxToken` | 1500–2000 字符 | 确保可完整引用政策原文的核心条款，避免截断关键内容 |
| `temperature` | 0.1–0.3 | 政策问答需保持严谨性，降低随机生成的偏差 |
| `toolChoice` | auto | 自动判断是否需要调用检索工具获取政策依据，适配不同提问场景 |
| `AIPROXY_API_ENDPOINT` | 按所使用大模型的官方代理地址填写 | 合规调用大模型接口，确保数据传输安全 |

## 容易做错的三处
- 现象为检索结果包含多个不相关的政策文件，无法精准匹配指定的装备制造政策文档。原因是未通过知识库分组或提示词限定召回范围，导致模型召回无关数据。
- 现象为接口返回429 Too Many Requests状态码，调用频繁失败。原因是未配置合理的调用频率控制，并发请求超出大模型接口的配额限制。
- 现象为生成的回答引用的政策条款不完整。原因是`quoteMaxToken`设置过小，无法完整加载并引用政策原文的核心内容。

## 怎么确认配好了
- 上传单份目标发电装备制造政策文档，发起针对性提问，核对检索结果仅包含该文档的内容。
- 发起10次并发测试请求，核对接口未返回429状态码，确认调用频率符合限制要求。
- 查看生成回答的引用片段，核对引用内容的长度与`quoteMaxToken`的设置匹配。
- 调整`temperature`参数至0.2与0.3分别发起提问，核对两次回答的核心内容一致性，确认参数生效。
