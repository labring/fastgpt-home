# 发电装备制造的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
发电装备制造的政策与制度依据数据，主要来源于国家能源局、工业和信息化部发布的行业政策文件，以及GB系列发电装备相关国家标准。数据更新节奏随政策发布节点调整，无固定月度频次。文档结构包含政策全文、条款标注、适用装备范围说明，字段包含政策编号、发布单位、生效日期、适配装备类型，单位涉及兆瓦（MW）、兆帕（MPa）等行业标准单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
政策来源分散且包含跨部门文件，要求检索环节支持多数据集并行召回并按发布单位做权重区分。文档包含长文本政策全文、结构化标准表格与条款摘要，需适配不同内容格式的分块规则，避免长文本截断导致关键信息丢失。适配装备类型字段与行业专用单位，要求检索时关联字段匹配，优先召回适配目标装备的政策条目，同时避免单位术语不匹配导致的召回偏差。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 适配政策文本的语义相似度要求，避免召回无关政策或遗漏核心条款 |
| `limit` | 前10条 | 平衡召回覆盖范围与上下文长度，适配政策文档的长文本特性 |
| `searchMode` | `vector` | 优先语义召回政策条款，结合结构化字段过滤适配装备类型 |
| `usingReRank` | 开启 | 对召回结果按语义相关性重排，优化长政策文本的排序准确性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展政策相关的行业术语，覆盖同义词与单位表述 |
| `collectionIds` | 对应发电装备政策数据集的ID | 限定检索范围至专属政策知识库，避免混入其他品类数据 |

## 容易做错的三处
- 现象：导入飞书多维文档或Excel格式的政策表格后，检索结果无法正确匹配表格内的参数值。原因：未启用数据集的结构化文档解析功能，分块规则未针对表格字段做单独处理。
- 现象：检索召回的政策条款中包含无关的非发电装备领域内容。原因：未通过`collectionIds`限定检索范围至专属发电装备政策数据集，导致混入其他品类的知识库数据。
- 现象：导入的PDF格式政策文件在检索结果预览中无法正常加载。原因：未配置PDF文本提取的分页参数，或文件存在加密导致无法完整解析文本内容。

## 怎么确认配好了
- 上传一份发电装备领域的政策Excel表格，发起检索，确认表格内的参数值能被正确召回并匹配查询。
- 查看检索配置的`collectionIds`参数，确认仅包含发电装备政策相关的数据集ID，无其他无关数据集。
- 发起包含行业专用单位的查询，比如“300MW汽轮机的合规政策”，确认召回结果优先匹配适配该装备的条目。
- 开启`usingReRank`后，对比重排前后的检索结果顺序，确认高相关性条目被优先展示。
