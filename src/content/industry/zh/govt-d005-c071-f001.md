# 发电集团的政策与制度依据问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
发电集团的政策与制度依据数据，主要来源于集团内部合规管理部门发布的正式合规文件、国家能源局及国资委发布的能源电力行业政策规章。数据更新节奏为每季度常规更新，遇行业新规或紧急政策调整时即时推送。单份政策文档为结构化格式，包含政策文号、发布主体、适用场景、条款内容、生效日期等固定字段，条款内容以“条”为单位，生效日期采用YYYY-MM-DD格式。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
政策数据的结构化字段要求接口返回内容需包含文号、生效日期等元数据，方便下游内部系统做合规校验与归档。政策文号与生效日期的精准匹配需求，要求接口需支持通过指定参数限定检索范围。紧急政策的即时更新要求接口支持增量拉取模式，避免全量同步占用过多内部带宽。发电集团内部多系统联动的场景，要求接口需兼容统一的身份鉴权规范，确保跨系统调用的安全性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 身份校验方式 | 传入`Authorization`头携带Bearer令牌 | 适配发电集团内部统一的身份鉴权体系，符合FastGPT v4.17.0 版本的接口鉴权规范 |
| 请求超时时间 | 600 秒 | 匹配内部系统接口调用的最长等待时长，避免因内部流程延迟导致调用失败 |
| 返回数据格式 | 结构化JSON | 对应政策文档的文号、生效日期等字段解析需求，便于下游系统直接提取使用 |
| 检索限定参数 | 传入`variables`参数携带政策文号与生效日期 | 精准定位目标政策条款，缩小检索范围提升回答准确性 |
| 最大召回条数 | 前 5 条 | 避免返回过多冗余政策内容干扰回答，符合内部合规查询的常规使用场景 |
| 上下文窗口大小 | 800–1200 字符 | 适配单条政策条款的标准长度范围，确保完整展示条款内容 |

## 容易做错的三处
-  调用政策检索接口时未传入`variables`参数指定政策文号，导致返回的内容匹配范围过大。现象是返回结果包含无关政策条款，原因是未通过参数限定检索目标。
-  配置飞书Webhook回调时未正确绑定`responseData`字段，导致推送的通知无有效政策信息。现象是接收端收到的消息内容为空，原因是未映射正确的返回数据节点。
-  未设置合理的请求超时时间，触发接口调用超时报错。现象是日志中出现`Api response error: undefined`类报错，原因是超时阈值低于内部系统的接口响应时长。

## 怎么确认配好了
-  调用接口传入测试用的政策文号与生效日期，检查返回的`responseData`是否包含对应条款的完整元数据。
-  查看接口调用日志，确认`Authorization`头已正确携带有效令牌，无鉴权失败相关报错。
-  上传测试用的政策PDF文件，检查文件集合创建接口是否返回成功且包含解析后的文本内容。
-  触发飞书Webhook回调，检查接收端是否收到包含政策条款内容的有效消息。
