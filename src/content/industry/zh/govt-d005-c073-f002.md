# 国有产业基金的政策与制度依据问答：向量模型与索引

## 这个品类的数据长什么样
国有产业基金政策与制度依据类数据主要来源于国资委、财政部及地方国资监管机构的官方公开文件，同时包含基金自身的出资协议、管理章程等内部制度文档。文档格式多为PDF或官方网页格式，篇幅跨度较大，字段包含文件编号、发布机构、生效日期、条款层级、原文正文等，条款按条、款、项分层标注。数据更新无固定周期，随国家及地方新政策发布、基金内部制度调整触发更新。

## 这些特征在「向量模型与索引」这一环带来什么约束
单篇文档篇幅跨度大，要求分块策略适配长短文本，避免单块内容过长超出模型限制。元数据字段丰富，需明确向量建模仅针对正文内容，避免元数据干扰召回精度。数据更新无固定周期，需配置增量索引触发逻辑，仅同步更新后的文件，减少全量索引的资源消耗。政策文件存在层级与废止关系，需在索引时关联元数据标签，便于后续检索时过滤无效内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配国有产业基金政策文档的单条款长度，避免单块token超出`maxToken`限制 |
| 重叠长度 | 100–200 字符 | 防止政策条款被分块截断导致上下文断裂，保障语义连贯性 |
| 相似度阈值 | 0.72–0.78 | 平衡政策问答的召回准确率与覆盖度，适配官方文件的严谨性要求 |
| 单次搜索上限 | 前 10 条 | 控制返回结果量级，避免上下文过长超出`defaultToken`限制 |
| 重排模型 | 开启 | 优化政策文档的语义排序，提升精准匹配度 |
| 最大上下文长度 | 6000–8000 token | 适配国有产业基金政策问答的多条款组合需求，符合FastGPT v4.17.0版本的通用参数范围 |

## 容易做错的三处
- 现象：开启重排模型后，在线召回测试结果未发生变化。原因：未在知识库索引配置中同步开启重排模型的关联开关，或重排模型的调用参数未匹配主向量模型的维度。
- 现象：索引过程报错提示参数超限。原因：分块长度设置超出`maxToken`允许范围，导致单块向量生成失败。
- 现象：检索结果包含已废止的政策文件。原因：未配置元数据过滤规则，未关联政策文件的生效与废止状态标签。

## 怎么确认配好了
- 进入FastGPT v4.17.0版本的知识库索引配置页面，核对分块长度、重叠长度的设置值与预设方案一致。
- 发起单次测试检索，查看返回结果的条数是否符合单次搜索上限的配置。
- 启用重排模型后，对比开启前后的检索结果排序差异，确认重排逻辑生效。
- 上传一份测试用的政策文件，验证增量索引是否能正常同步更新内容。
