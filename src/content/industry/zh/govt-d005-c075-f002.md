# 国有资本投资公司的政策与制度依据问答：向量模型与索引

## 这个品类的数据长什么样
国有资本投资公司的政策与制度依据数据，主要来源于国资委发布的规范性文件、集团本级的投资运营管理制度、子公司的合规执行细则及年度监管考核要求。数据更新无固定周期，随监管政策修订、集团战略调整或子公司制度更新同步发布。单份文档包含文件编号、发布主体、生效日期、条款层级、适用场景等字段，条款以条、款、项为最小单位，整体文档结构严谨且层级清晰。

## 这些特征在「向量模型与索引」这一环带来什么约束
数据来源分散且更新无固定周期，要求索引系统支持多源增量同步，避免全量重建带来的性能损耗。文档包含明确的生效日期与文件编号字段，要求索引绑定元数据以实现按时间、文号的精准过滤，确保召回的政策文件符合当前适用范围。单份文档的条款层级清晰，分块时需保留层级标识，防止检索结果无法定位到具体政策条款。政策文件的严谨性要求索引的召回逻辑需过滤低匹配度的无关内容，避免误导合规判断。`defaultToken`可用于调整默认的上下文填充参数，适配不同长度的政策文档。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 匹配国有资本政策文件单条条款的常规长度，避免语义割裂 |
| 重叠长度 | 100–150 字符 | 保留跨分块的政策条款上下文，确保检索时的语义连贯性 |
| 相似度阈值 | 0.75–0.85 按实测标定 | 适配政策文件的严谨语义，过滤低匹配度的无关内容 |
| 单次搜索上限 | 前10条 | 控制召回的政策文件数量，避免上下文过载影响合规判断 |
| `maxToken` | 8000 token | 匹配FastGPT v4.17.0的上下文窗口限制，确保完整加载政策条款内容 |
| 问题优化 | 开启 | 优化政策相关查询的表述，提升召回精准度 |

## 容易做错的三处
- 向量召回结果中出现已失效的政策文件。未配置生效日期的过滤规则，索引未绑定发布时间元数据，导致召回过期内容。
- 调用向量模型时返回权限错误，curl测试正常。未在FastGPT的向量库配置中添加对应服务的访问白名单，仅配置了基础API密钥，导致服务拦截请求。
- 无法通过mongodb直接管理向量库的增删操作。向量库的增删需遵循FastGPT的索引同步规则，直接操作mongodb会导致向量数据与源政策文件不一致。

## 怎么确认配好了
- 上传单份国有资本政策文件，检查分块后的文档是否保留了预设的元数据字段。
- 发起一条政策相关查询，核对召回结果的过滤规则是否与配置的要求一致。
- 触发一次增量更新任务，检查向量库的更新范围与源数据的更新范围匹配。
- 调用向量模型接口，确认返回的结果与直接接口测试的结果一致。
