# 国有资本投资公司的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
国有资本投资公司的政策与制度依据数据主要来自国务院国资委发布的监管指引、集团本级及下属子公司的内部管理制度、年度经营考核文件与合规备案材料。数据更新随监管政策发布、内部制度修订同步触发，无固定周期但核心文件生效前需完成入库。单篇文档通常包含文号、发布主体、生效日期、适用范围、条款细则、附件清单等字段，文档长度跨度较大，从500字符到20000字符，字段以文本类为主，部分包含结构化的考核指标数值。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散覆盖国资委监管文件、集团内部制度与子公司合规文档，要求检索系统需按文件层级、类型划分独立知识库集合，检索时需限定集合范围以过滤无关结果。无固定更新周期的特征，要求配置支持增量同步与手动触发更新的机制，确保最新政策及时完成入库。文档包含文号、生效日期等结构化字段，需配套属性过滤规则，优先召回在有效期内、匹配适用范围的政策内容。长文档跨度较大的特征，要求分块时兼顾条款完整性，避免拆分核心监管要求与执行细则。本配置基于FastGPT v4.17.0版本完成验证。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.72–0.85` | 政策文件需较高匹配精度，避免召回与业务场景无关的非核心制度 |
| `limit` | `前10–15条` | 政策类问答需覆盖不同层级的相关依据，过少会遗漏关键监管要求 |
| `searchMode` | `vector+keyword` | 政策文件包含明确文号、关键词等结构化信息，结合语义检索可提升召回精准度 |
| `usingReRank` | 开启 | 长文档分块后可能存在语义分散，重排可将核心条款的检索结果前置 |
| `datasetSearchUsingExtensionQuery` | 开启 | 政策表述存在同义词关联，例如“国有资本运营”与“国有资本投资”的延伸匹配需求 |
| `collectionIds` | 指定集团本级与国资委监管文件的集合ID | 过滤子公司非通用政策，缩小检索范围以提升结果相关性 |

## 容易做错的三处
- 调用API添加或删除数据后，检索结果未同步更新。原因：未正确指定`collectionIds`参数，导致数据被写入未关联当前检索任务的知识库集合中。
- 传入自定义引用数据后，检索结果未关联对应政策原文。原因：未按照系统要求的结构化格式传入引用字段，或字段名称与预设的引用匹配规则不匹配。
- 首次发起政策问答检索无法召回目标文件，第二次检索可正常返回结果。原因：知识库的向量索引未完成实时更新，首次检索使用旧索引缓存，第二次触发索引刷新后召回正确结果。

## 怎么确认配好了
- 上传一篇测试用的集团内部政策文件，检索包含文件中核心文号的查询词，核对召回结果是否包含该文件。
- 调整`similarity`的取值范围，观察检索结果的匹配精度变化，确认配置项生效。
- 切换`searchMode`的不同模式，对比检索结果的覆盖范围，验证配置的实际作用。
- 调用FastGPT的数据集管理API添加一条测试数据，检索对应关键词，确认数据可被正常召回。
