# 国有资本运营公司的政策与制度依据问答：工作流编排

## 这个品类的数据长什么样
国有资本运营公司的政策与制度依据数据主要来源于国务院国资委官方发布的国有资本运营监管文件、行业专项规章制度，以及公司内部印发的运营管理细则。数据更新节奏随监管政策发布节奏调整，新文件发布后1-3个工作日完成同步。单份文档通常包含文号、发布单位、生效日期、条款层级（条、款、项）、具体执行要求等字段，部分文档附带配套解读附件，整体结构层级清晰，条款关联性强。

## 这些特征在「工作流编排」这一环带来什么约束
国有资本运营公司的政策数据特征会对工作流编排带来三点核心约束。第一，数据包含文号、生效日期等结构化字段，工作流需通过`variables`配置过滤规则，仅检索生效期内的有效政策，避免引用失效文件。第二，文档层级清晰、条款关联性强，工作流需支持按条、款、项拆分检索结果，防止长文本超出上下文长度限制。第三，数据更新随监管政策动态调整，工作流需接入定时同步节点，确保检索数据源与最新政策保持同步。部分文档附带配套解读附件，工作流需支持关联检索附件内容，补充政策依据的细节说明。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ------ | -------- | ------------ |
| 问题优化 | 开启，优化阈值按实测标定 | 国有资本运营政策文本多为正式公文，问题优化可提升检索关键词与政策条款的匹配精度 |
| 单次搜索上限 | 前8条 | 政策文档条款关联性强，前8条可覆盖核心政策依据，避免冗余结果干扰 |
| 最大上下文 | 8000–12000 token | 政策文本包含多级条款与附件内容，该区间可完整承载核心检索结果与上下文信息 |
| 变量过滤 | 配置`variables`为生效日期、文号 | 结构化字段可精准过滤失效政策，仅返回当前有效的制度依据 |
| 节点超时 | 600秒 | 政策数据检索需关联附件内容，较长超时时间可确保完整获取所有关联数据 |
| 节点ID | 绑定政策知识库的`nodeId` | 确保工作流仅调用指定的国有资本运营政策知识库 |

## 容易做错的三处
- 现象：AI对话环节输出的政策依据未携带文号、生效日期等元数据，字段为空。原因：未在工作流中配置`variables`参数绑定结构化字段，检索结果未携带必要的政策标识信息。
- 现象：工作流执行时触发超时报错，界面显示请求超时提示。原因：未调整节点超时配置，政策数据关联配套附件时的检索耗时超过默认阈值。
- 现象：同时启用知识库节点的问题优化功能与独立问题优化节点，导致检索结果出现冗余优化痕迹。原因：未区分两类节点的适用场景，重复执行了文本优化逻辑。

## 怎么确认配好了
- 手动触发一次工作流，查看检索结果的元数据字段，确认文号、生效日期等信息已正确携带。
- 检查工作流的定时同步节点配置，确认同步周期与政策更新节奏匹配。
- 查看工作流日志，确认单次搜索返回的结果条数符合预期配置。
- 测试不同生效日期的政策检索，确认过滤规则仅返回当前有效的制度文件。
