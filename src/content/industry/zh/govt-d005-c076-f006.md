# 国有资本运营公司的政策与制度依据问答：引用来源与溯源

## 这个品类的数据长什么样
国有资本运营公司的政策与制度依据数据，来源为国资委发布的国有资本监管政策、集团内部运营管理制度、地方国资监管部门的配套文件。数据更新节奏为：国资委政策发布后1-3天内完成同步，集团内部文件随修订实时更新。文档为结构化正式公文，包含政策文号、发布主体、生效日期、条款编号、适用范围等固定字段，单条条款内容完整，格式规范统一。

## 这些特征在「引用来源与溯源」这一环带来什么约束
结构化的固定字段要求溯源时必须关联文号、生效日期等元数据，确保引用来源的官方性与时效性；更新频率较高要求配置定期增量同步任务，避免知识库内容滞后于最新政策；单条条款内容完整的特征要求预留足够的上下文空间，确保引用内容可完整承载；政策的监管属性要求严格限定引用范围，仅纳入官方发布的合规数据源，禁止混入非官方内容。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 字符 | 政策文档单条条款内容完整，该取值可完整承载引用内容并避免上下文溢出 |
| `responseData` | 返回引用源的文号、生效时间、发布主体 | 政策溯源需明确官方来源标识与时效性信息，符合国有资本监管的合规要求 |
| `detail` | 开启 | 需展示引用条款的完整内容，确保政策依据的匹配精度 |
| 单次搜索上限 | 前3条 | 国有资本政策体系层级清晰，过多引用会导致回答冗余，影响阅读效率 |
| 同步频率 | 每日增量同步 | 国资委政策更新频率较高，每日同步可确保知识库内容与官方要求一致 |

## 容易做错的三处
- 现象为回答中显示引用了政策文档，但生成内容与知识库中的条款完全不匹配，原因是配置`quoteMaxToken`取值过小，导致召回的引用内容被截断，无法匹配生成逻辑。
- 现象为仅文本数据集被纳入溯源结果，其他格式的政策数据集未被召回，原因是未开启对应格式数据集的召回开关，未适配国有资本政策文档的结构化字段提取规则。
- 现象为动态绑定知识库搜索参数时，未返回对应的引用文档，原因是未将动态参数正确关联到知识库搜索节点，导致搜索范围未覆盖目标政策文档。

## 怎么确认配好了
- 进入知识库管理页面，查看同步日志，确认政策文档已按每日增量同步规则完成更新。
- 发起国有资本政策相关的测试提问，查看回答中是否包含引用源的文号、生效时间等元数据字段。
- 测试不同格式的政策数据集，确认所有支持的格式均被纳入召回范围。
- 查看回答的引用模块，确认引用内容的长度符合配置的`quoteMaxToken`取值。
