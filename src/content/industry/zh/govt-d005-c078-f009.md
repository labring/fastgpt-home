# 城市水务的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
城市水务的政策数据主要来源于住建部、水利部官方政务平台及地方水务、住建部门官网。数据更新节奏为新政策发布后72小时内同步，季度性监管文件更新时同步增量内容。文档为结构化政策条目，包含政策ID、文号、发布主体、生效时间、适用区域、条款编号、条款内容、量化指标及对应单位等字段，量化指标单位多为立方米/户·月、升/人·日等水务专用单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
城市水务政策数据的特征对模型接入与配置带来三项核心约束：其一，政策按行政区域划分且更新频繁，要求配置时支持按区域过滤召回的上下文，且需设置自动同步知识库的周期，保障数据时效性；其二，条款包含专用量化单位，要求模型调用时保留单位识别与校验，避免出现单位混淆的错误；其三，文档包含文号、生效时间等元数据，要求配置时开启引用元数据输出，确保问答可溯源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 字符` | 城市水务政策单条条款较长，需容纳多份关联政策的上下文，避免截断关键信息，适配FastGPT v4.17.0版本的上下文处理上限 |
| `quoteMaxToken` | `1500 token` | 需完整引用政策条款的核心内容，确保问答时可溯源的引用片段足够详实，覆盖条款中的量化指标与单位 |
| `temperature` | `0.1–0.3` | 政策问答需严格遵循原文，不宜生成偏离依据的内容，较低温度可提升回答的严谨性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写官方接入地址 | 匹配所选大模型的接入规范，确保请求正常转发 |
| `AIPROXY_API_TOKEN` | 填写绑定的代理密钥 | 用于身份验证，保障接入请求的安全性 |
| `toolChoice` | `none` | 政策问答无需调用外部工具，直接基于知识库内容生成回答即可 |

## 容易做错的三处
- 现象：在浏览器中打开配置页面时出现“访问受限”提示，无法完成模型接入设置。原因：未使用FastGPT支持的浏览器版本，或浏览器开启了严格的隐私拦截规则。
- 现象：模型召回的政策内容丢失单位信息，出现“用水定额”与“用水量”混淆的错误。原因：未设置`quoteMaxToken`参数的合理取值，导致引用片段被截断，丢失关键单位字段。
- 现象：知识库同步后新发布的水务政策未被召回，问答结果仍使用旧版条款。原因：未配置自动同步的触发规则，或同步周期设置过长，未及时拉取最新政策数据。

## 怎么确认配好了
- 发起一次针对特定区域水务政策的问答测试，检查返回结果中是否包含政策的文号、生效时间等元数据，确认引用元数据配置生效。
- 提交一份包含不同行政区域的政策查询，检查召回的上下文是否仅包含对应区域的政策内容，确认区域过滤配置生效。
- 手动触发一次知识库同步，等待同步完成后查询新发布的政策，确认自动同步配置生效。
- 查看模型调用日志，检查请求的`maxContext`、`temperature`等参数是否与配置一致，确认接入参数配置生效。
