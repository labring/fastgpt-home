# 城市燃气的政策与制度依据问答：向量模型与索引

## 这个品类的数据长什么样
城市燃气领域的政策与制度依据数据，主要来自住建部、各省市燃气主管部门、城投集团的官方公开文件与内部合规文档。数据更新随新政策出台、地方细则修订触发，无固定周期但季度新增量稳定。文档包含规范性文件、安全操作指南、经营许可指引等类型，结构包含发布文号、生效日期、适用区域、条款细则等字段，单篇文档长度从数百字符到数万字符不等。

## 这些特征在「向量模型与索引」这一环带来什么约束
城市燃气政策文档的跨度差异、结构化元数据与地域绑定特征，对向量模型与索引环节带来多重约束。短问答类指引与长规范类文件的长度差异，要求分块策略需适配不同文档类型，避免过细导致语义割裂或过粗丢失关键政策条款。地域与生效日期字段的存在，要求索引时保留元数据标签，便于后续召回时按区域、时效过滤无关结果。无固定更新周期的特性，要求增量索引机制可按需触发，避免全量索引占用过多系统资源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| 分块长度 | 800–1200 字符 | 适配城市燃气政策文档从数百到数万字符的跨度，避免单块语义断裂或冗余 |
| 重叠长度 | 100–200 字符 | 弥补分块边界的语义断层，确保政策条款的连贯性 |
| 相似度阈值 | 0.72–0.85 | 过滤城市燃气政策中相似表述的低关联召回结果，匹配政策问答的精准需求 |
| 单次召回上限 | 前 8 条 | 控制上下文总长度，适配政策问答的信息密度 |
| 重排 | 开启 | 优化召回结果的排序，突出与问题直接相关的政策条款 |
| `maxToken` | 3500–4000 token | 限制单轮问答的上下文总长度，避免超出模型处理上限 |

## 容易做错的三处
- 现象：本地部署FastGPT v4.17.0后，新建知识库时未显示图片自动索引选项。原因：该功能需加载商业版专属插件，本地部署默认未启用对应模块。
- 现象：召回结果中出现跨区域的城市燃气政策，与当前服务地域不匹配。原因：索引时未保留地域元数据标签，未配置按区域过滤的召回规则。
- 现象：单篇长政策文档的召回结果碎片化，无法覆盖完整条款。原因：分块长度设置过小，导致政策条款被拆分后语义断裂。

## 怎么确认配好了
- 上传一篇城市燃气的政策文档，查看分块后的结果是否覆盖完整条款，无明显语义断裂。
- 输入区域化的政策问题，确认召回结果仅包含对应区域的政策文件。
- 测试不同长度的文档上传，验证分块策略是否适配长规范与短问答的不同场景。
- 查看知识库索引日志，确认增量索引可按需触发，无全量重复索引的异常。
