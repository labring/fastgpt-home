# 城市燃气的政策与制度依据问答：工作流编排

## 这个品类的数据长什么样
城市燃气政策与制度依据的数据源主要来自住建部、属地燃气监管部门及城投燃气企业的官方公开文件，更新随新政策发布即时同步。文档以规范性文件、通知公告为主，结构包含文件文号、发布主体、生效日期、条款条目、适用地域范围。字段含政策类别、执行标准编号、处罚条款细则等，适用地域字段标注地级市或区县层级，条款数量以“条”为单位。

## 这些特征在「工作流编排」这一环带来什么约束
城市燃气政策文档体量差异较大，部分省级政策单份超万字，工作流需支持分段召回以适配模型上下文限制；政策适用地域明确且层级固定，需配置变量提取节点匹配对应地域的数据源，避免跨区域政策混淆；政策更新无固定周期，需配置数据源自动同步节点确保知识库实时更新；条款层级多且细节繁杂，需配置上下文裁剪节点过滤无关内容，提升回答精准度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `variables` | 按「地域+政策类型」格式传入 | 城市燃气政策按地域和类型分类，该格式可精准匹配对应数据源 |
| `nodeId` | 绑定专属燃气政策知识库的节点ID | 避免调用无关品类的知识库数据，提升召回精准度 |
| 分块长度 | 800–1200 字符 | 城市燃气政策条款多为短段落，该长度可完整覆盖单条政策细则 |
| 单次召回上限 | 前 8 条 | 政策文件条目较多，过多召回会超出模型上下文限制 |
| 超时设置 | 600 秒 | FastGPT v4.17.0版本默认超时为300秒，该时长可适配多数政策文档的检索与生成流程 |
| 变量校验规则 | 校验输入是否包含地级市名称 | 城市燃气政策适用地域明确，无地域信息无法精准匹配对应数据源 |

## 容易做错的三处
- 现象为API调用工作流嵌套知识库助手时返回空值，原因是未配置地域变量提取节点，未匹配到对应城市的燃气政策数据源。
- 现象为知识库变量引用时提示`quote type error`，原因是未按`variables`要求的格式传入参数，未做变量类型校验。
- 现象为工具调用模块同时输出AI回复与执行下一级分支，原因是未配置分支触发条件，工作流未区分生成结果与工具调用的执行时序。

## 怎么确认配好了
- 传入包含地级市名称与燃气政策类型的测试变量，检查工作流是否触发对应知识库的召回结果。
- 查看工作流运行日志，确认`variables`参数格式符合配置要求，无`quote type error`报错。
- 模拟API调用，检查返回结果不为空，且包含匹配地域的政策条款。
- 调整超时设置后，测试执行时长超过300秒的场景，确认工作流未异常中断。
