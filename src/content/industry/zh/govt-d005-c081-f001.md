# 基础化工的政策与制度依据问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
基础化工的政策与制度依据数据主要来源于应急管理部、生态环境部、工业和信息化部发布的官方文件，以及各省级工信部门出台的地方实施细则。数据更新节奏随政策发布实时同步，无固定周期。文档结构包含政策文号、发布单位、生效日期、适用行业范围、具体条款、罚则条款等字段，其中政策条款多为长文本格式，单篇文档长度可达数千字符，字段单位以字符串、日期格式为主，无统一数值单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
基础化工政策数据的长文本特性，要求HTTP接口返回的内容不能过度截断，需保留核心条款的完整上下文。政策的实时更新特性要求接口配置合理的缓存策略，避免返回过时的政策内容。多字段的文档结构要求接口调用时需传递明确的行业过滤参数，确保返回的内容仅针对基础化工领域。此外，政策数据的合规性要求，使得接口鉴权环节需要严格配置，防止未授权访问。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| Authorization | Bearer {FastGPT v4.17.0 绑定的专属API密钥} | 基础化工政策数据属于合规性内容，需通过鉴权防止非授权调用 |
| variables | {"targetIndustry": "基础化工", "policyStatus": "现行有效"} | 限定查询范围，过滤非基础化工类政策与已失效文件，提升问答准确性 |
| responseData | 提取政策文号、发布日期、核心条款字段，返回前800-1200字符 | 适配大模型上下文长度，同时保留政策的关键信息 |
| 单次请求超时时间 | 600秒 | 基础化工政策文档篇幅较长，避免因请求超时中断查询流程 |
| 最大上下文长度 | 8000 token | 匹配长文本政策条款，保证大模型可以完整读取政策内容 |

## 容易做错的三处
- 现象：调用接口后返回“Model response empty”，原因：未在variables中配置基础化工行业过滤参数，导致返回的政策数据与查询意图不匹配，大模型无法生成有效回答。
- 现象：接口调用失败，返回401未授权状态码，原因：Authorization参数未正确添加Bearer前缀，或使用了过期的API密钥。
- 现象：接口返回的政策内容不完整，原因：responseData配置的返回字符长度过短，截断了政策的核心条款内容。

## 怎么确认配好了
- 调用配置好的HTTP接口，检查返回的JSON数据是否包含政策文号、发布日期等预设字段。
- 向接口传入测试查询“基础化工安全生产相关政策”，确认返回的内容均属于基础化工领域。
- 查看接口响应时长，确认未超过配置的单次请求超时时间。
- 在FastGPT平台中对接该HTTP接口，发起真实的政策问答查询，验证返回结果的准确性。
