# 基础化工的政策与制度依据问答：引用来源与溯源

## 这个品类的数据长什么样
基础化工领域的政策与制度依据数据，主要来自国家及地方工信、应急管理、生态环境部门发布的化工安全生产、产业指导、环保合规类政策文件，更新随政策正式发布实时同步。文档多为带统一文号、发布主体、生效日期的结构化文本，包含条、款、项的层级划分，字段包含政策全称、发文编号、发布单位、生效时间、具体条款内容，部分文件附带附件清单与官方解读说明。

## 这些特征在「引用来源与溯源」这一环带来什么约束
基础化工政策数据的结构化层级特征，要求溯源时需保留条、款、项的层级标识，确保引用的具体条款可精准定位。统一文号与生效日期作为核心溯源字段，需在引用时同步展示，避免溯源模糊。政策更新无固定周期，需配置实时同步机制，防止引用失效版本。部分政策附带解读文件，需明确区分政策原文与解读内容，避免溯源混淆。

以下配置基于FastGPT v4.17.0版本。
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | 基础化工政策单条条款长度多在300–800 token，预留足够空间容纳完整条款与溯源信息 |
| `responseData` | 开启溯源字段返回 | 需返回政策文号、发布单位、生效日期等核心溯源字段 |
| `detail` | 完整层级展示 | 需保留条、款、项的层级划分，保证引用条款的精准定位 |
| 召回文档上限 | 前6条 | 基础化工政策关联文档通常不超过5条，预留1条冗余避免遗漏 |
| 引用超时阈值 | 60 秒 | 结构化政策文件检索耗时可控，设置合理超时保障响应效率 |
| 溯源信息展示 | 强制附加 | 需在回答末尾同步展示所有引用的政策溯源信息，符合合规要求 |

## 容易做错的三处
- 现象：回答末尾未展示政策溯源的文号、生效日期等核心信息，仅显示模糊的文件名。原因：未开启溯源字段返回配置，或未配置完整层级展示选项。
- 现象：回答中未附带任何引用溯源信息，或用户无法通过展示内容找到原始政策文件的入口。原因：误关闭了溯源信息展示开关，或未配置强制附加溯源信息的选项。
- 现象：回答截断了引用的政策条款内容，无法完整展示所引用的具体条款。原因：`quoteMaxToken` 设置过低，未预留足够空间容纳完整条款与配套溯源信息。

## 怎么确认配好了
- 发起一条包含具体政策条款的查询，核对回答末尾是否展示了政策文号、发布单位、生效日期等溯源信息。
- 查看配置界面的相关开关状态，确认溯源字段返回与层级展示选项是否已正确配置。
- 测试查询多条不同的政策条款，核对回答中引用的条款是否包含条、款、项的层级信息。
- 调整`quoteMaxToken`的取值，验证回答是否能完整展示不同长度的政策条款内容。
