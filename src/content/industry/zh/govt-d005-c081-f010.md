# 基础化工的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
基础化工领域的政策与制度依据数据，主要来源于应急管理部危化品监管司、工信部原材料工业司、生态环境部大气环境司发布的官方公告，以及中国石油和化学工业联合会发布的行业标准文本。数据更新随新政策出台不定期触发，单份文档长度从数百字到数万字不等，文档结构统一包含发布文号、生效日期、适用场景、条款细则，字段包含政策类别、监管主体、合规要求、罚则条目，单位多以条款项、文号编号为标识。

## 这些特征在「知识库检索与召回」这一环带来什么约束
基础化工政策文档的长文本跨度，要求检索环节需保留条款上下文关联，避免直接分段导致的条款割裂；政策带有明确生效日期与发布文号，要求召回结果需支持时效性过滤，避免返回过期失效的政策内容；字段包含精准的监管主体与合规要求，要求检索可支持定向字段匹配，防止无关品类的政策混入结果；数据更新无固定周期，要求知识库支持按文号或发布时间快速增量更新，保障检索数据的时效性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 基础化工政策文本严谨，需较高匹配度确保合规性，避免无关政策条目被召回 |
| `limit` | 前10条 | 基础化工政策条目较多，过多结果会超出上下文窗口，影响回答准确性 |
| `searchMode` | 向量检索+关键词混合 | 政策文本既有专业术语也有明确关键词，混合模式可兼顾语义匹配和精准关键词命中 |
| `usingReRank` | 开启，重排后保留前5条 | 基础化工政策存在相似表述，重排可过滤语义重复条目，提升结果相关性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 政策问题常包含专业缩写（如VOCs、危化品），优化可补充关联术语，提升召回覆盖度 |
| `collectionIds` | 绑定专属政策集合 | 避免混入其他品类的政策文档，保证检索范围精准 |

## 容易做错的三处
- 现象：检索结果返回的政策内容不完整，单条条款被拆分后丢失上下文关联。原因：采用直接分段且未设置上下文重叠，导致政策条款被拆分后无法还原完整逻辑。
- 现象：单轮检索耗时超过10秒，响应速度未达预期。原因：未开启`usingReRank`或重排后保留条目过多，且未限制`limit`取值，导致冗余计算量过大。
- 现象：返回结果中包含本地图片地址，无法通过外部链接正常访问。原因：知识库导入时未替换政策文档中的本地图片链接，未配置外部资源映射规则。

## 怎么确认配好了
- 上传一份测试政策文档，发起包含对应政策文号的提问，核对返回结果是否包含目标条款。
- 调整`similarity`取值，观察召回结果的匹配度变化，确认阈值设置生效。
- 发起包含专业术语的提问，核对是否开启`datasetSearchUsingExtensionQuery`后补充了关联术语的召回结果。
- 查看检索日志，确认返回结果条数与`limit`取值的匹配度符合预期。
