# 基础设施建设的政策与制度依据问答：文档解析与分块

## 这个品类的数据长什么样
基础设施建设领域的政策与制度依据数据主要来源于住建部、各省市住建管理部门发布的行业规范、招投标管理办法、施工许可政策、质量安全标准等文档。文档更新节奏随新政策出台、行业标准修订不定期更新。文档多为多章节结构，包含政策文号、发布单位、发布日期、适用范围、具体条款等字段，部分文档会包含“万元”“平方米”“工期”等专用单位，部分扫描版文档存在排版复杂的表格与格式。

## 这些特征在「文档解析与分块」这一环带来什么约束
政策文件章节嵌套层级多，分块时需保留章节标题与条款的上下文关联，避免拆分核心政策条款。扫描版政策文档存在OCR识别风险，需启用高精度解析流程。文档中包含专用单位的字段需要完整保留，否则会影响后续问答的准确性。大文件的政策文档体积较大，解析时容易超时，需调整超时阈值适配大模型无法识别解析内容。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配基础设施建设政策文件单条条款的长度，避免拆分核心政策条款，保留文号与单位信息 |
| `chunkSplitter` | 按标题+段落拆分 | 匹配政策文件的章节层级结构，确保分块后上下文完整 |
| `customPdfParse` | 开启 | 适配扫描版政策文档，启用高精度解析，减少OCR Error问题 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 适配大型基础设施建设政策pdf文档，避免解析超时 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 支持大型招投标政策文档的上传与解析 |
| `chunkSettingMode` | 手动模式 | 针对政策文件的特殊结构，手动调整分块规则，适配不同类型的政策文档 |

## 容易做错的三处
- 找不到高精度解析功能无法启用：原因是未开启`customPdfParse`配置，或未在FastGPT v4.17.0版本中启用对应设置。
- 出现OCR Error报错：原因是未开启高精度PDF解析，或上传的扫描版政策文档未启用OCR功能。
- 大模型未触发文件解析：原因是`chunkSettingMode`未配置为手动模式，或分块规则不匹配政策文件结构，导致大模型无法识别解析内容。

## 怎么确认配好了
- 上传扫描版基础设施建设政策文档，检查解析结果是否保留了原文的文号、发布单位、章节标题，确认`customPdfParse`开启后OCR效果正常。
- 上传100MB左右的政策pdf，检查解析是否在`PARSE_FILE_TIMEOUT_SECONDS内完成。
- 查看分块后的文本，确认每个分块的长度在800–1200字符区间内。
- 确认FastGPT v4.17.0版本，检查配置项是否已正确保存。
