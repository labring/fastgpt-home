# 成品油销售的政策与制度依据问答：工具调用与插件

## 这个品类的数据长什么样
数据来源为国家能源主管部门、各省市商务监管部门发布的成品油零售合规文件、价格管控规范、安全运营标准，以及行业统一的政策汇编文档。更新节奏为新政策发布后7个工作日内完成同步，常规合规条款每季度复核修订。文档为结构化的政策条目，包含政策文号、发布单位、生效日期、适用区域、核心执行细则等字段，单篇文档长度从数百字到数千字不等，部分区域政策会附带本地专属的备案流程要求。本页面适配FastGPT v4.17.0版本。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于政策存在区域专属条款与时效性要求，工具调用需要支持基于适用区域、生效日期进行参数筛选，确保返回的政策内容匹配当前场景。结构化的政策字段要求工具调用时能精准提取政策文号、生效日期等元数据，用于结果溯源与合规校验。单篇文档长度跨度较大，工具调用的上下文处理能力需要适配从数百到数千字符的政策文本，避免截断核心执行细则。同时，政策更新频率要求插件需支持定期同步官方数据源的配置项，保障问答内容的时效性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配政策问答中随机触发工具调用的场景，无需手动指定函数 |
| `functionCall` | 允许自动调用 | 政策问答需要频繁调取结构化政策字段，自动调用可提升响应效率 |
| 区域政策匹配优先级 | 前3条匹配当前适用区域的政策条目 | 区域专属政策数量有限，优先返回本地生效的合规内容 |
| 上下文窗口上限 | 8000 token | 适配单篇数千字符的政策文档，避免截断核心执行细则 |
| 数据源同步周期 | 7天 | 匹配政策常规复核的更新节奏，保障问答内容的时效性 |
| 元数据提取开关 | 开启 | 需要提取政策文号、生效日期用于结果校验，符合合规溯源要求 |

## 容易做错的三处
- 现象：调用本地部署的大模型时，即使开启工具调用相关开关，仍无法触发政策数据查询工具。原因：本地模型的工具调用协议未适配FastGPT的`functionCall`格式要求，无法正确解析工具调用参数。
- 现象：配置通用账户KEY作为聚合BASE_URI时，返回的政策内容未区分区域适用范围。原因：未绑定区域筛选的上下文参数，工具调用时未传入当前场景的适用区域信息。
- 现象：在工作流中调用文档解析工具处理政策文件时，出现字段为空或超时报错。原因：未设置适配长文本政策文档的上下文窗口上限，工具调用时超出处理阈值。

## 怎么确认配好了
- 发起包含明确区域属性的政策查询，核对返回结果是否包含对应区域的专属政策条款。
- 触发工具调用后，查看系统日志是否包含提取的政策文号、生效日期等元数据字段。
- 上传单篇长文本政策文档，确认工具调用未出现截断或超时类报错。
- 等待配置的数据源同步周期结束后，查看是否自动更新了最新的政策条目。
