# 成品油销售的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
成品油销售相关政策数据主要来源于国家能源局、商务部及各地商务、市场监管部门发布的成品油流通管理办法、零售经营规范等官方文件。数据更新节奏随政策修订不定期调整，单次政策文档篇幅从数百到数千字符不等。文档固定包含发布文号、生效日期、适用区域、核心条款等字段，核心字段单位涉及升、吨、元/升、平方米等与经营场景直接相关的计量与管理单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
政策文档的不定期更新要求知识库同步配置支持按需触发的增量更新，避免过时政策被检索。不同政策文档的篇幅差异较大，需适配上下文长度参数以完整加载单篇政策条款。文档中包含多类计量与管理单位，需确保模型在检索与生成时准确区分同类单位的适用场景，避免出现单位混淆的回答。同时文号与生效日期作为核心标识，需在检索时优先匹配用户问题中提及的政策文号或时间范围。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 适配单篇政策文档的平均篇幅，避免截断核心条款 |
| `maxTokens` | `2000–3000 token` | 控制单次回答的输出长度，符合政策解读的简洁性要求 |
| `quoteMaxToken` | `1500–2000 token` | 限制引用的政策文本总长度，确保引用内容与问题高度相关 |
| `temperature` | `0.1–0.3` | 降低回答的随机性，确保政策解读的准确性与严谨性 |
| `toolChoice` | `auto` | 允许模型自主判断是否需要调用检索工具获取政策依据 |
| `vision` | `false` | 政策文档多为纯文本格式，无需启用图片理解功能 |

## 容易做错的三处
- 检索结果仅返回少量政策条款，无法覆盖用户问题的全部依据。原因：`maxContext` 参数取值过低，导致无法加载完整的政策文档片段，或`quoteMaxToken` 限制过严，过滤了部分相关内容。
- 界面中无法看到图片理解模型配置选项。原因：未启用对应功能权限，且当前绑定的政策文档无图片资源，默认关闭了`vision` 功能。
- 模型直接拒绝回答知识库外的政策相关问题。原因：`toolChoice` 被强制设置为`none`，禁止模型调用检索工具，导致无法补充获取未录入的政策内容。

## 怎么确认配好了
- 上传一篇本地的成品油政策文档，发起包含文号、生效日期的查询，核对返回结果中是否准确引用了对应条款。
- 调整`temperature` 参数的取值范围，观察模型回答的严谨性变化，确认参数已生效。
- 测试不同篇幅的政策文档，确认回答未出现内容截断的情况，验证`maxContext` 参数的适配性。
- 触发知识库增量更新，确认系统能正常同步新发布的政策文件，验证更新配置的有效性。
