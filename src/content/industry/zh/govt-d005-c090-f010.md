# 成品油销售的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
成品油销售的政策与制度依据数据，主要来源于国家级行业主管部门、地方商务与市场监管部门发布的规范性文件，以及石油石化销售企业内部的合规执行手册。文档结构包含发布主体、文号、生效日期、适用区域、核心条款、违规处置条款等字段，部分量化合规要求使用“升”“吨”“平方米”等标准单位。更新节奏随监管政策调整同步更新，核心政策文件更新频率较低，补充性执行细则更新频率较高，无固定周期。

## 这些特征在「知识库检索与召回」这一环带来什么约束
政策文件存在版本差异，需在召回环节过滤已失效的旧版文件，因此检索需关联生效日期字段进行有效性校验；文档包含明确的适用区域、业务主体条款，召回结果需匹配用户提问的地域与经营场景，避免跨区域合规风险；核心条款多为正式合规要求，检索结果需准确对应条款原文，避免语义偏移引发合规问题；部分补充性执行细则更新频率较高，需定期同步知识库，防止召回过时的执行标准。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 成品油政策条款多为严谨表述，该区间可平衡召回完整性与准确性，过滤低匹配度的无关结果 |
| `limit` | 前10条 | 政策条款数量有限，过多结果会增加上下文处理负担，10条可覆盖核心相关条款 |
| `searchMode` | 精准匹配 | 政策检索需准确对应条款原文，精准匹配模式可避免无关语义干扰，提升合规检索准确性 |
| `usingReRank` | 开启 | 对召回结果进行重排，可优先展示与政策条款匹配度更高的内容，优化检索结果排序逻辑 |
| `datasetSearchUsingExtensionQuery` | 关闭 | 政策问题无需扩展查询，直接匹配原文即可避免引入无关内容，确保检索结果的严谨性 |
| `collectionIds` | 指定合规政策专属集合ID | 避免混入非政策类知识库内容，确保检索范围仅覆盖成品油销售相关政策文件 |

## 容易做错的三处
- 现象：检索时提示`invalid configuration parameter name "hnsw.max_scan_tuples"`，或搜索返回无结果。原因：使用了FastGPT官方未支持的自定义向量检索参数，未采用指定的配置项清单。
- 现象：召回结果包含已失效的旧版政策文件。原因：未在检索配置中关联生效日期字段进行有效性过滤，导致过期条款被纳入召回范围。
- 现象：检索结果混入非成品油销售的政策内容。原因：未正确指定`collectionIds`参数，检索范围覆盖了无关的知识库集合，导致跨品类内容被召回。

## 怎么确认配好了
- 发起一条针对具体成品油零售合规条款的提问，检查返回结果是否包含对应政策的原文内容。
- 查看检索配置的参数值，确认`similarity`、`limit`等配置项符合预设规则。
- 验证检索范围是否仅覆盖成品油销售政策专属知识库集合，避免混入无关内容。
- 测试提交已失效政策的关键词，确认结果被过滤，无过期条款返回。
