# 油气勘探开发的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
油气勘探开发的政策与制度依据数据主要来自自然资源部、行业主管部门及所属企业内部合规文档，更新随新政策发布、制度修订触发。文档多为结构化政策原文、配套解读文件，包含政策文号、发布单位、生效日期、适用勘探区块范围、合规操作条款等字段，单位多为标准公文格式的编号、日期、区域范围表述。

## 这些特征在「模型接入与配置」这一环带来什么约束
油气勘探开发的政策文档多为长文本且包含专业合规条款，要求模型接入时需适配长上下文处理能力，避免截断核心合规内容。数据更新无固定周期，需配置可灵活触发的文档同步机制，确保问答使用的政策版本最新。不同勘探区块的适用政策存在差异，需在配置中支持按区域、文号等字段精准召回，避免跨场景的合规风险。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 油气勘探开发政策文档多为长文本，需完整加载政策原文、配套解读以覆盖完整合规依据 |
| `temperature` | `0.1–0.3` | 政策问答需保持表述严谨，避免生成偏离官方条款的模糊内容 |
| `quoteMaxToken` | `2000–3000 token` | 需保留政策原文的完整条款作为引用依据，确保问答内容可追溯 |
| `AIPROXY_API_ENDPOINT` | 对应模型官方公开接入地址 | 确保模型调用链路的稳定性与兼容性 |
| `AIPROXY_API_TOKEN` | 平台分配的专属调用密钥 | 保障模型调用的权限安全与访问合法性 |
| `toolChoice` | `auto` | 可根据查询需求自动判断是否需要关联补充政策文档，适配不同场景的问答逻辑 |

## 容易做错的三处
- 现象：配置`AIPROXY_API_ENDPOINT`后，界面未显示对应模型名称，无法选择使用。原因：未将模型名称与接入端点正确绑定，或端点地址格式不符合平台校验规则。
- 现象：问答返回内容截断政策原文核心条款。原因：`maxContext`或`quoteMaxToken`取值过小，无法完整加载长文档内容。
- 现象：生成的政策解读与官方条款存在偏差。原因：`temperature`取值过高，导致模型生成非严谨的表述内容。

## 怎么确认配好了
- 发起单条政策相关查询，检查返回结果是否包含配置中指定的政策字段与条款。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的调用参数与配置一致。
- 测试长文本政策文档的加载，确认未出现内容截断的情况。
- 调整查询关键词，验证不同场景下的召回结果是否符合配置的区域、文号等过滤规则。
