# 油气勘探开发的政策与制度依据问答：部署与升级

## 这个品类的数据长什么样
油气勘探开发的政策与制度依据数据，主要来自自然资源部、国家能源局发布的行业规范，各油田企业的内部生产管理制度，以及石油天然气行业标准。数据更新无固定周期，新政策发布或标准修订时同步更新。单份政策文档通常包含文号、发布单位、生效日期、适用勘探区块范围、核心条款等结构化字段，文档长度多在5000-20000字符，部分行业标准包含多章节的技术要求与合规条款，字段单位涉及平方千米、立方米、吨等勘探相关计量标准。

## 这些特征在「部署与升级」这一环带来什么约束
多源分散的政策数据来源，要求部署时支持多格式文档的批量导入与元数据统一管理。无固定更新周期的特性，要求升级流程中支持增量同步配置，避免全量重导带来的服务中断。长文档与多字段的结构，要求向量数据库与关系型数据库分别适配非结构化文本与结构化元数据的存储需求，同时需要配置足够的连接池与缓存资源，应对合规检索时的高频查询。FastGPT v4.17.0的部署模板已针对该场景的多源数据导入做了优化，此外，勘探相关的计量字段需要在检索时保留单位关联，部署时需确保元数据字段的映射配置准确。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MONGODB_URI` | `mongodb://admin:securepass@db-host:27017/og_policy?authSource=admin` | 存储政策文档的非结构化文本与向量索引，适配多源文档的复杂元数据存储 |
| `PG_URL` | `postgresql://admin:securepass@db-host:5432/og_metadata` | 存储结构化的政策文号、发布日期、适用区块等字段，支持按文号精准检索 |
| `REDIS_URL` | `redis://:securepass@cache-host:6379/0` | 缓存高频查询的政策问答对，降低数据库的重复查询负载 |
| `STORAGE_S3_ENDPOINT` | `https://s3-cn-north-1.amazonaws.com` | 存储上传的政策原文PDF、Word文件，适配大体积文档的存储与读取 |
| `DB_MAX_LINK` | `20–30 个` | 匹配油气勘探政策数据的并发查询量，避免连接池过载影响服务稳定性 |
| `FILE_TOKEN_KEY` | `32位随机生成的十六进制字符串` | 加密上传的政策文件访问令牌，防止未授权的文档访问与解析 |
| `FE_DOMAIN` | `https://og-policy.example.com` | 配置前端访问的域名，确保前端资源的加载路径正确 |

## 容易做错的三处
- 现象：启动容器后提示数据库连接失败，界面无法加载政策文档列表。原因：未正确配置`MONGODB_URI`或`PG_URL`的连接参数，或数据库未开放容器所在网段的访问权限。
- 现象：本地部署上传政策PDF后，检索结果为空。原因：未正确配置`FILE_TOKEN_KEY`，导致文件解析服务无法获取上传文档的访问权限，无法完成文本拆分与向量化。
- 现象：云版本登录时提示初始密码不存在，无法完成管理员登录。原因：未在部署流程中配置`ROOT_KEY`生成初始管理员凭证，或未完成初始化配置步骤。

## 怎么确认配好了
- 执行`docker ps`命令，确认所有依赖的数据库、缓存、存储服务容器均处于运行状态。
- 上传一份测试用的油气勘探政策文档，在检索界面输入关键词，确认能返回匹配的文档片段与元数据信息。
- 访问`FE_DOMAIN`对应的前端地址，使用配置的管理员账号登录后台，确认元数据已同步至关系型数据库。
- 查看`REDIS_URL`对应的缓存监控面板，确认有缓存命中记录，说明高频查询已被正常缓存。
