# 油田工程服务的政策与制度依据问答：工具调用与插件

## 这个品类的数据长什么样
油田工程服务的政策与制度依据数据主要来自国家能源局发布的石油工程行业规范、国有石油企业内部作业安全与合规制度、地方能源监管部门的专项作业要求。数据更新随新政策文件出台触发，无固定周期。单份文档包含政策文号、发布单位、生效日期、适用作业场景、条款细则等字段，内容按条款分块呈现，部分文档附带作业流程配套的合规校验要求，字段以纯文本为主，无复杂嵌套格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工具调用功能 | 开启 | 启用政策问答的工具调用能力 |
| `toolChoice` | `auto` | 自动选择适配的政策数据源进行调用 |
| `functionCall` | 开启 | 启用工具调用的函数执行逻辑 |
| 单次召回条款数量 | 前6条 | 适配单份政策文档的条款密度，避免上下文溢出 |
| 上下文窗口限制 | 8000 token | 适配长文本政策文档的召回存储需求 |
| 插件调用超时 | 600秒 | 匹配政策文档的平均加载与解析耗时 |
| 生效日期过滤 | 启用 | 基于文档中的生效日期字段过滤过期内容 |
| 作业场景绑定 | 关联油田工程作业类型 | 缩小召回范围，提升匹配精准度 |

## 容易做错的三处
- 调用工具时返回400状态码，提示参数格式错误。原因是未正确配置`toolChoice`参数，或传入的政策文档字段格式与插件预设不匹配。
- 工具调用后返回空结果，无有效政策内容。原因是未启用生效日期过滤，召回了过期的政策文档，或作业场景绑定参数设置错误。
- 工具调用触发失败，提示模型不支持工具调用功能。原因是未选择支持`functionCall`的模型，或模型部署配置未开启工具调用能力。

## 怎么确认配好了
- 进入插件配置界面，确认工具调用功能开关处于开启状态。
- 输入包含具体油田工程作业类型的政策查询语句，触发工具调用，查看是否返回对应场景的政策条款。
- 查看工具调用日志，确认`toolChoice`参数被正确设置为`auto`。
- 输入包含指定生效日期的查询，验证是否仅召回对应时间段内的政策内容。
