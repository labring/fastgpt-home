# 油田工程服务的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
油田工程服务的政策与制度依据数据，主要来源于国家能源局、属地能源监管部门及服务所属国央企的内部合规文档。数据更新节奏随政策正式发布或修订同步触发，无固定周期。文档多为结构化政策原文，包含政策编号、发布主体、适用作业环节、合规条款、生效日期等字段，涉及米、兆帕、人次、万元等油田工程作业常用计量标准。

## 这些特征在「模型接入与配置」这一环带来什么约束
政策文档的结构化特征要求模型接入时需保留原文的字段关联，避免拆分后丢失政策编号与适用场景的绑定关系。非固定更新周期的数据源，要求配置中需支持手动触发数据刷新的入口，适配政策临时修订的场景。涉及工程类计量单位的内容，需确保模型在召回时能准确匹配作业参数与政策要求的单位一致性，避免因单位转换误差导致合规判断偏差。同时，政策内容多涉及合规条款，需限制模型输出时的冗余信息，仅保留与用户提问直接相关的政策依据。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |

| `maxContext` | `8000–12000 token` | 政策文档通常篇幅较长，需保留足够上下文以关联多条款的合规要求，适配油田作业多环节的政策联动查询 |
| `maxTokens` | `2000–3000 token` | 限制单轮回答长度，避免输出过长的政策原文堆砌，聚焦用户提问直接相关的核心合规依据 |
| `quoteMaxToken` | `1500 token` | 限定召回的政策片段总长度，确保匹配内容精准且不超出模型处理上限，避免冗余内容干扰回答 |
| `temperature` | `0.1–0.3` | 政策问答需保持严谨性，降低随机性以确保回答与政策原文的表述一致，符合合规场景的要求 |
| `AIPROXY_API_ENDPOINT` | 按部署服务商提供的专属地址填写 | 适配国央企内部网络环境，明确区分自定义请求地址与代理地址的配置边界，避免外部访问限制导致调用失败 |
| `AIPROXY_API_TOKEN` | 按分配的专属密钥填写 | 确保调用权限的安全性，仅允许授权主体访问油田工程服务的政策问答服务 |

## 容易做错的三处
- 测试工作流时，回答末尾固定携带“FastGPT 是一个基于大语言模型(LLM)的知识库问答系统”语句。原因是未在模型配置中关闭默认的系统提示词，该提示词为平台内置的初始化内容。
- 调用模型时出现403权限错误。原因是`AIPROXY_API_TOKEN`配置错误或未绑定对应服务权限，无法通过代理校验。
- 用户系统接入后，不同用户的历史对话出现跨账号展示。原因是未配置独立的用户身份校验参数，导致对话数据未绑定对应用户标识。

## 怎么确认配好了
- 发起一条针对具体油田作业合规的提问，核对回答中是否仅包含政策原文相关内容，无冗余的平台标识语句。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`的调用请求已成功发送，无连接超时或权限报错。
- 调整`temperature`参数后发起相同提问，核对回答内容的一致性变化是否符合预期，验证参数生效。
- 上传最新修订的政策文档，触发数据刷新后发起对应提问，确认召回内容已同步更新。
