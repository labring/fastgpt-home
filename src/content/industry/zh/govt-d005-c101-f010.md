# 港口航运的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
港口航运政策与制度依据的数据主要来自交通运输部水运局公开规范性文件、各直属海事局监管细则、国际海事组织公约及港口集团内部合规文档。更新节奏为新政策印发后72小时内同步至知识库，文档结构包含政策文号、发布单位、生效日期、适用港口范围、监管条款等字段，部分长文档为整本管理办法，短文档为单条通知，无统一固定篇幅。

## 这些特征在「知识库检索与召回」这一环带来什么约束
政策文档的时效性要求召回结果必须匹配当前生效版本，需关联生效日期字段过滤过期内容；不同港口的监管细则存在地域差异，需按港口属地维度限定召回范围；长政策文本的条款关联性强，分割时需保留条款完整性，避免拆分破坏语义逻辑；高频更新的政策要求知识库支持增量同步，避免召回旧版无效内容。同时政策文本严谨性高，召回内容需严格对应原文，不得出现语义偏差。

## 配置怎么定
本页面基于FastGPT v4.17.0版本的配置逻辑编写，以下为针对港口航运政策问答场景的检索召回配置建议：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 港口政策文本严谨，需保证召回内容与问题语义高度匹配，避免无关政策混入 |
| `limit` | `前6条` | 港口政策条目较多，过多结果会超出上下文承载长度，过少则无法覆盖全监管场景 |
| `searchMode` | `vector` | 政策文本包含大量专业术语与结构化条款，向量检索可精准匹配关键词与语义关联 |
| `usingReRank` | `开启` | 需对召回结果按相关性排序，确保贴合度较高的政策条款优先返回，提升检索精准度 |
| `datasetSearchUsingExtensionQuery` | `关闭` | 政策问答需严格匹配原文，不宜扩展问题语义导致偏离预设知识库内容 |
| `collectionIds` | `指定港口航运政策专属数据集ID` | 隔离其他品类知识库，仅召回港口航运政策相关内容，避免跨品类干扰 |

## 容易做错的三处
- 现象：检索结果包含非港口航运政策的无关内容，原因：未配置`collectionIds`限定专属数据集，导致其他品类知识库内容被召回。
- 现象：返回内容未严格匹配知识库原文，出现语义扩展或改写，原因：开启了`datasetSearchUsingExtensionQuery`，问题语义被自动扩展，偏离预设问答对或政策原文。
- 现象：向量化时报错提示速率超限，日志显示接口限流触发，原因：未调整批量提交的文档批次，单次提交数量过大，导致embedding接口触发限流。

## 怎么确认配好了
- 查看检索日志，确认召回结果均来自港口航运政策专属数据集，无跨品类内容混入。
- 提交预设的政策原文问题，核对返回内容与知识库原文完全一致，无语义扩展或改写。
- 提交不同港口属地的政策问题，确认仅召回对应地域的政策条款，无跨区域内容返回。
- 测试批量向量化提交，确认无速率超限报错，提交批次符合接口限流要求。
