# 炼化生产的政策与制度依据问答：向量模型与索引

## 这个品类的数据长什么样
炼化生产的政策与制度依据数据，来源包括国家及地方能源监管、生态环境部门发布的行业合规政策、安全生产标准，集团内部的生产管理制度、环保排放细则、设备运维规范。更新节奏为国家层面政策每季度至半年更新一次，内部文档随合规要求调整每季度修订。文档单篇长度跨度较大，包含文号、发布单位、生效日期、条款内容、适用场景等字段，涉及ppm、立方米、吨、小时等专业单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
文档包含明确的元数据字段，要求索引时关联存储文号、生效日期等信息，以便后续按合规时间范围精准召回。单篇文档长度跨度较大，短则数百字符的合规通知，长则数千字符的制度汇编，需要适配灵活的分块策略避免信息断裂。涉及大量工业专业术语与特定单位，需选择适配工业领域语义编码的向量模型，保障专业内容的匹配精度。更新频率不固定且存在增量更新需求，需配置支持增量嵌入任务，避免全量重建索引带来的资源浪费。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配炼化政策文档的长度跨度，避免分块过碎丢失上下文或过长导致语义编码偏差 |
| 重叠长度 | 100–200 字符 | 保留跨分块的政策条款关联，确保专业内容的语义连贯性 |
| 相似度阈值 | 0.75–0.85 | 过滤低相关召回结果，适配工业专业术语的语义匹配精度 |
| 单次搜索上限 | 前10条 | 控制召回结果数量，避免超出上下文承载上限 |
| `defaultToken` | 8192 | 适配常规政策文档的嵌入长度，保障核心条款不被截断 |
| `maxToken` | 16384 | 覆盖超长合规汇编的嵌入需求，避免关键内容丢失 |

## 容易做错的三处
- 切换向量模型后知识库嵌入进度停滞且无法回退，原因是未先清空原有嵌入缓存，直接修改模型配置导致索引任务冲突。
- 配置嵌入模型后测试返回404错误，原因是未正确填写模型接入的API密钥与服务端点参数，导致请求无法匹配有效接口。
- 批量重嵌入后多语言召回率无改善，原因是未针对多语言文档调整分块与语义编码配置，导致专业术语的跨语言语义匹配失效。

## 怎么确认配好了
- 进入FastGPT v4.17.0版本的知识库设置页面，查看向量模型配置项，确认所选模型与当前配置一致。
- 上传一篇测试用的炼化政策文档，触发嵌入任务，查看任务状态显示为完成且无报错日志。
- 发起与炼化合规相关的测试查询，查看召回结果的相似度分值符合预设阈值区间。
- 尝试修改向量模型配置，确认可以正常保存并切换，无进度卡死或无法回退的情况。
