# 炼化生产的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
炼化生产的政策与制度依据数据主要来自国家能源局、国务院国资委、中国石油和化学工业联合会发布的官方文件，以及炼化企业内部合规管理文档。数据更新节奏随政策修订触发，内部制度按年度或重大合规调整更新。文档多为结构化长文本，包含文号、发布单位、生效日期、条款编号、适用场景、罚则等字段，条款以“第X条”为单位，生效日期采用YYYY-MM-DD格式，部分跨区域政策附带地方执行细则。

## 这些特征在「模型接入与配置」这一环带来什么约束
炼化政策文档单篇长度可达数千字符，且包含多维度合规字段，要求模型接入时需适配长上下文与精准字段匹配。数据更新节奏非高频但需同步及时，配置环节需支持按需刷新数据源。政策内容涉及生产安全、环保排放等刚性要求，回答需严格贴合原文，不宜出现过度发散的生成内容。部分政策文件附带地方执行细则，需支持多文档关联召回，对上下文窗口与召回逻辑提出额外约束。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000-12000 token | 适配单篇炼化政策文档的长度，容纳多份关联政策原文与企业内部制度 |
| `maxTokens` | 2000-3000 token | 保证合规问答的回答长度足以覆盖完整条款解释，同时避免冗余生成 |
| `quoteMaxToken` | 1500-2000 token | 限制单条引用文档的token占比，确保上下文窗口可容纳多条政策引用 |
| `temperature` | 0.1-0.3 | 贴合政策原文的严谨性，降低生成内容的随机性，避免偏离官方条款 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配本地或云端部署的API地址，保证模型调用链路正常 |
| `AIPROXY_API_TOKEN` | 按服务商提供的密钥填写 | 完成模型调用的身份验证，确保访问权限合法 |

## 容易做错的三处
- 上传炼化政策文档后显示解析超时，状态码显示504。原因是未调整`maxContext`适配长文档，默认上下文窗口不足以容纳单篇政策全文。
- 合规问答结果与政策原文存在偏差，条款引用不准确。原因是`temperature`取值过高，生成内容出现随机发散，未贴合官方表述。
- 本地部署Qwen14B 32K模型时，上传文件后解析失败，重启服务器无效。原因是`AIPROXY_API_ENDPOINT`配置错误，或`AIPROXY_API_TOKEN`过期未更新，导致模型调用链路中断。

## 怎么确认配好了
- 上传单篇炼化行业合规政策文档，检查系统召回的引用片段是否包含正确的文号、发布单位与条款内容。
- 发起包含具体条款的合规问答，验证返回结果是否准确匹配政策原文，无额外发散内容。
- 上传更新后的企业内部合规制度，确认数据源刷新后，新内容可被正常召回与引用。
- 查看系统日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置无报错，模型调用链路正常。
