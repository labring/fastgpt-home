# 煤化工的政策与制度依据问答：文档解析与分块

本文适配FastGPT v4.17.0版本

## 这个品类的数据长什么样
煤化工政策与制度依据数据主要来自国家发改委、国家能源局、应急管理部及行业主管部门公开印发的正式文件，更新随新政策发布、现有条款修订同步推进。文档多为PDF格式，部分附带官方在线网页版，结构包含文号、印发单位、发布日期、正文条款、附件附表，字段含政策编号、适用场景、执行标准，单位多涉及吨标准煤、万吨产能、运行小时数等。

## 这些特征在「文档解析与分块」这一环带来什么约束
煤化工政策文档多为带附件的PDF，部分存在内嵌图表、工艺公式，部分可通过语雀公开链接获取。文档条款层级清晰但长文本较多，拆分时需避免割裂政策条款逻辑。公开链接格式需符合官方发布规范，非标准链接可能导致解析失败。内嵌图片需提取后关联至对应文本块，否则大模型无法获取配图对应的政策说明内容。长文档的解析超时风险较高，需调整超时配置适配文件大小。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 煤化工政策文档单条款长度多在500-1000字符，该区间可保留条款完整性，避免过度拆分或块度过长 |
| `chunkSplitter` | 按段落+标题拆分 | 政策文档多按条款、章节划分层级，按段落+标题拆分可保留单条政策的完整逻辑 |
| `customPdfParse` | 启用内嵌图片提取 | 煤化工政策文档常附带工艺流程图、能耗附表等内嵌图片，启用后可将图片关联至对应文本块 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 单份政策文档多为10-50页，该超时区间可覆盖长文档解析耗时，避免中途中断 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 部分煤化工政策合集文档体积较大，该上限可支持完整文件上传解析 |
| `chunkSettingMode` | 手动配置 | 需针对煤化工政策的条款结构调整分块规则，手动配置可灵活适配文档特征 |

## 容易做错的三处
- 现象为上传语雀公开分享链接后，知识库解析任务失败，界面提示无法识别数据源类型。原因是未使用完全公开的分享权限链接，仅设置内部或部分权限的语雀链接无法被正常解析。
- 现象为解析后的煤化工政策文档文本块未携带内嵌的工艺流程图、能耗附表图片，大模型无法获取配图对应的政策说明内容。原因是未启用`customPdfParse`配置的内嵌图片提取功能。
- 现象为单份50页以上的煤化工政策合集文档解析中断，返回超时错误提示。原因是`PARSE_FILE_TIMEOUT_SECONDS`设置值过低，未覆盖长文档的完整解析耗时。

## 怎么确认配好了
- 上传一份包含内嵌工艺流程图的煤化工政策PDF，查看解析结果中的文本是否关联了对应的图片标记。
- 检查解析后的文本块是否保留了完整的政策条款层级与文号信息，未出现条款被割裂的情况。
- 上传一份体积较大的煤化工政策合集文档，确认解析过程未出现超时中断。
- 手动调整`chunkSize`参数后，对比不同配置下的分块结果，确认分块逻辑符合政策文档的结构特征。
