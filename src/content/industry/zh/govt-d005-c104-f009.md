# 煤化工的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
煤化工政策与制度依据的数据源主要为国家能源局、生态环境部、省级发改委发布的正式公文与行业标准，更新节奏随新政策出台不定期调整。文档多为PDF或官方网页格式，结构包含文件文号、发布单位、生效日期、适用范围与具体条款，字段涵盖项目审批要求、能耗限额、污染物排放限值等内容，单位多采用万吨/年、吨标准煤/万元等行业通用计量方式。本页面基于FastGPT v4.17.0版本编写。

## 这些特征在「模型接入与配置」这一环带来什么约束
煤化工政策与制度依据多为长文本公文，包含固定生效时间与适用范围，要求模型调用时需保留条款完整度，避免截断关键审批或合规要求；不同政策文件格式差异较大，存在纯文本、内嵌表格等形式，需适配多格式解析逻辑；政策更新无固定周期，知识库同步需匹配官方发布节奏，模型配置需支持增量更新；政策条款涉及专业计量数值，需确保数值提取与上下文关联准确，避免出现合规判断偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 煤化工政策文件多为长文本，需保留完整政策条款上下文，避免截断关键审批或合规要求 |
| `maxTokens` | 2000–3000 token | 政策问答需输出完整条款解读与依据，单次回复token量需覆盖完整解析结果 |
| `quoteMaxToken` | 4000 token | 需关联匹配政策原文片段，限制引用片段的token总量以避免上下文溢出 |
| `temperature` | 0.1–0.3 | 政策问答需保持严谨准确，降低随机性以确保条款引用与解读的一致性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写本地API地址 | 适配本地部署的Qwen、DeepSeek模型调用需求，确保数据不外流 |
| `AIPROXY_API_TOKEN` | 填写模型专属访问密钥 | 验证模型调用权限，确保合法访问部署的大模型服务 |

## 容易做错的三处
- 现象：本地部署Qwen14B 32K模型后，上传政策文件解析超时并提示请求失败。原因：未调整`maxContext`参数适配长文本政策文件，超出模型上下文窗口导致调用中断。
- 现象：模型调用的token消耗超出预期，计费或资源占用异常。原因：未配置`quoteMaxToken`限制引用片段的token总量，导致冗余政策原文被反复加载。
- 现象：上传内嵌图片的政策PDF后，无法提取图片中的政策条款。原因：未正确配置`vision`参数，且煤化工政策文档的内嵌图片多为扫描版或非标准格式，现有解析模型无法准确识别文字内容。

## 怎么确认配好了
- 上传单篇10页以上的煤化工政策PDF，查看解析完成状态是否正常，确认无超时或报错提示。
- 发起政策条款查询，核对模型返回的引用片段是否与上传的政策原文一致，确认上下文关联准确。
- 切换部署的模型类型，验证API调用是否能正常完成，确认参数配置匹配模型要求。
- 查看系统日志，确认token消耗范围符合配置的`maxTokens`与`quoteMaxToken`参数设定。
