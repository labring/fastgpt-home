# 煤炭运销的政策与制度依据问答：工具调用与插件

## 这个品类的数据长什么样
煤炭运销的政策与制度依据数据主要来自国家能源局、省级能源监管部门、煤炭行业协会发布的官方文件，以及大型煤炭运销企业内部的合规运销制度。数据更新无固定周期，新政策出台或制度修订时同步更新。单份文档多为数千字符的正式公文结构，包含文号、发布单位、生效日期、适用区域、核心运销条款等字段，运量相关字段单位为万吨，费率单位为元/吨。

## 这些特征在「工具调用与插件」这一环带来什么约束
煤炭运销政策文档篇幅较长且结构正式，工具调用时需适配长上下文的输入输出限制，避免截断核心合规条款。数据来源的官方属性要求插件调用时需校验文档的发布主体与版本，防止调用过期或非官方的错误内容。字段的专业化属性要求工具调用的参数需精准对应文号、生效日期、适用区域等专属字段，避免泛化匹配导致结果偏差。无固定更新周期则要求插件配置定期同步知识库的触发机制，确保调用的政策内容为最新有效版本。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本编写。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `functionCall` | 强制触发 | 适配政策条款的结构化提取需求，精准返回指定的合规字段内容 |
| 上下文窗口大小 | 8000–12000 token | 适配单份政策公文的篇幅，避免核心运销条款被截断 |
| 文档来源校验开关 | 开启 | 确保调用的政策文件来自国家能源局等指定官方主体 |
| 知识库同步周期 | 7天 | 适配政策不定期更新的节奏，平衡时效性与同步成本 |
| 字段匹配精度 | 严格匹配 | 对应政策文档的专属字段格式，避免泛化匹配错误 |
| 插件超时时间 | 300秒 | 适配长文档解析与跨源校验的耗时需求 |

## 容易做错的三处
- 现象为通过HTTP节点调用飞书多维表格时返回403状态码，原因是未正确配置飞书应用的权限范围，未授予多维表格的编辑权限。
- 现象为工具调用返回的政策条款被截断，原因是上下文窗口大小设置过小，未适配单份政策文档的篇幅。
- 现象为接入MCP后工具调用无响应，原因是未正确绑定MCP的访问密钥与FastGPT的环境变量配置，导致无法调用外部数据源。

## 怎么确认配好了
- 发起一次政策查询测试，检查返回结果的发布单位是否为指定的官方主体，确认文档来源校验配置生效。
- 查看工具调用的日志，确认返回的政策条款未被截断，验证上下文窗口设置符合需求。
- 触发知识库手动同步操作，检查知识库更新记录，确认同步周期配置符合预期。
- 发起包含字段要求的查询，检查返回结果是否精准匹配文号、生效日期等专属字段，验证字段匹配精度配置生效。
