# 煤电一体化的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
煤电一体化的政策与制度依据数据主要来自国家能源局、国务院国资委及各省级能源主管部门的公开规范性文件、行业标准文档。数据更新节奏随政策发布调整，无固定周期，新政策出台后同步更新。单篇文档通常包含文件文号、发布单位、生效日期、适用场景、核心条款等字段，条款以条、款、项为层级单位，部分文档附带配套解读文件。

## 这些特征在「模型接入与配置」这一环带来什么约束
政策文档多为长文本且层级清晰，要求模型能准确识别条款层级与关联内容，因此对上下文窗口的处理有明确要求。政策文号、生效日期等结构化字段需精准匹配，要求向量模型对结构化信息的编码能力达标。非固定更新的数据源意味着配置需支持动态切换知识库，且需定期校验数据源的有效性。长文档的分块需适配条款层级，避免割裂上下文关联，同时需保证召回的政策条款能准确对应用户查询的场景。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配煤电一体化政策长文档的上下文关联，避免关键条款被截断 |
| `maxTokens` | 2000–3000 token | 满足政策解读类回答的输出长度需求，避免回答不完整 |
| `quoteMaxToken` | 1500–2000 token | 保证召回的政策原文片段足够覆盖用户查询的场景细节 |
| `temperature` | 0.1–0.3 | 保持政策回答的严谨性，避免生成偏离依据的内容 |
| `AIPROXY_API_ENDPOINT` | 对应部署模型的官方接入地址 | 确保模型调用的链路正常 |
| `AIPROXY_API_TOKEN` | 从模型服务商获取的有效密钥 | 完成模型接入的身份验证 |

## 容易做错的三处
- 现象：调用多模态模型处理政策文档中的配图时返回格式错误，提示图片格式不支持。原因：未按照要求将图片转换为PNG或JPG格式，且未在请求中正确携带图片URL或base64编码内容。
- 现象：配置`maxContext`参数后，召回的政策条款仍出现上下文割裂。原因：未适配政策文档的条款层级进行分块，直接按固定长度截断长文档，导致条款关联关系丢失。
- 现象：修改FastGPT服务密码后无法正常重启模型接入功能。原因：未同时重启依赖模型调用的相关服务进程，仅重启主服务导致配置未同步生效。

## 怎么确认配好了
- 发起包含煤电政策核心术语的测试查询，核对返回结果中是否包含准确的政策条款引用。
- 在FastGPT v4.17.0的系统设置中查看模型配置项，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`未出现空值或错误字符。
- 调整`temperature`参数的取值，观察回答的严谨性变化是否符合预期。
- 上传一篇测试用的煤电政策文档，验证召回的片段是否与文档内容匹配。
