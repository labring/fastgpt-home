# 煤电一体化的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
煤电一体化的政策与制度依据数据主要来自国家能源局、国务院国资委及各省市能源主管部门的正式公文、行业标准文件，同时包含行业协会发布的政策解读文档。数据更新节奏随政策修订动态调整，常规政策按季度批量更新，临时专项政策发布后24小时内完成同步。单篇文档结构包含政策文号、发布单位、发布日期、适用范围、正文条款、配套解读五个核心字段，字段单位包括文号编号、年月日、适用区域范围等，无统一固定的数值型单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
煤电一体化政策文档的正式性要求检索结果必须精准匹配政策文号与执行节点，不能仅依赖正文关键词召回，否则会导致引用的政策依据无效。文档包含多字段元数据，检索时需同时匹配元数据与正文内容，否则无法准确关联到对应政策文件。单篇文档可能存在较长正文内容，超出常规文件大小限制，导致上传与分块难度增加。临时政策的快速更新需求，要求知识库检索配置支持增量同步，避免因数据滞后影响问答准确性。大量政策文档同时存在时，无约束的检索会导致召回结果冗余，增加token消耗与响应延迟。

## 配置怎么定
使用本配置方案需确保使用FastGPT v4.17.0及以上版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 煤电政策文本正式性强，需严格匹配政策核心表述，避免低相关召回 |
| `limit` | 前3–5条 | 政策问答需精准引用，过多结果会增加token消耗，符合国央企政策文档的精准需求 |
| `searchMode` | semantic + metadata | 结合语义和元数据检索，优先匹配政策编号、适用范围字段，保障政策依据的准确性 |
| `usingReRank` | 开启 | 对召回结果按政策时效性和相关性二次排序，优先返回最新发布的政策文件 |
| `datasetSearchUsingExtensionQuery` | 开启 | 针对政策术语进行扩展查询，将“煤电一体化”扩展为“煤电联营”“煤电协同发展”，覆盖政策中的同义表述 |
| `collectionIds` | 绑定专属煤电政策知识库集合 | 避免检索到其他品类的政策文档，确保召回范围精准 |

## 容易做错的三处
- 现象：工作台知识库简单应用中每次仅返回1条引用结果，无法召回多个匹配文档。原因：未正确配置`limit`参数，或检索模式仅匹配单文档元数据，未开启多文档召回逻辑。
- 现象：问答响应超时，token消耗超出阈值。原因：未根据煤电政策文档的长文本特征调整分块配置，或`limit`取值过高，导致召回过多长文本片段。

## 怎么确认配好了
- 进入知识库检索测试界面，输入煤电政策相关问题，查看返回结果的引用条数是否符合配置的`limit`取值。
- 查看检索日志，确认召回结果同时包含政策元数据（如文号、发布单位）和正文关键词匹配。
- 上传单篇超过100MB的煤电政策文档，确认系统可正常分块上传，未触发文件大小限制报错。
- 模拟临时政策的增量更新，上传新发布的专项政策文件，确认知识库可在1小时内完成同步。
