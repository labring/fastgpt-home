# 矿山采选的政策与制度依据问答：工具调用与插件

## 这个品类的数据长什么样
矿山采选的政策与制度依据数据主要来源于自然资源部、省级矿山安全监管部门、行业协会的公开官方文件与实时更新的监管公告。数据更新节奏为新政策发布当日同步入库，常规政策每季度复核一次。文档结构包含政策文号、发布单位、生效日期、适用矿山类型、具体条款、配套附件（如安全规程、开采标准）等字段，字段包含行业分类（金属矿/非金属矿）、产能要求、处罚阈值，单位涉及万吨/年、立方米/秒、平方米等矿山采选专属计量标准。

## 这些特征在「工具调用与插件」这一环带来什么约束
矿山采选政策数据来源分散，需对接多个官方API与静态文件库，因此工具调用需支持多源聚合配置；政策文档包含长文本条款与附件，单次拉取数据量较大，需设置合理的超时与分页规则；字段包含细分矿山类型，工具调用时需携带对应筛选参数，避免返回无关政策内容；附件需单独下载解析，因此插件需支持文件流处理与格式转换。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `"auto"` | 自动匹配工具调用与直接回复的场景，适配政策问答中既有条款查询又有综合解读的需求 |
| `functionCall` | 开启 | 强制绑定预设的政策数据拉取工具，避免生成无关内容，确保问答依据准确 |
| 工具调用超时时间 | 120 秒 | 矿山采选政策文档包含多章节附件，需预留足够时间完成全量数据拉取 |
| 工具结果缓存规则 | 按政策文号缓存，有效期7天 | 多数政策发布后短期无变更，缓存可减少重复API调用，降低延迟 |
| HTTP工具集请求参数 | 携带矿山类型筛选字段，取值为金属矿/非金属矿 | 筛选对应矿山品类的政策数据，避免返回无关的通用政策内容 |
| 工具调用返回格式 | 结构化JSON | 便于后续对政策条款进行拆分、比对，提升问答的精准性 |

## 容易做错的三处
- 调用政策API工具时返回`Invalid URL`，状态码500。原因是未正确填写官方政策接口的完整请求路径，或携带的筛选参数格式不符合接口校验规则。
- 工具调用节点执行后同时输出工具结果和冗余的AI生成回复。原因是未开启`functionCall`的强制调用模式，导致系统自动生成了额外的解读内容。
- 无法连接内部矿山政策台账数据库获取结构化数据。原因是未部署适配的数据库连接插件，或未将FastGPT服务IP加入数据库的访问白名单。

## 怎么确认配好了
- 手动触发工具调用节点，查看返回的JSON数据是否包含对应矿山品类的政策条款，且无无关的通用政策内容。
- 查看工具调用日志，确认超时时间设置符合120秒的要求，无频繁超时报错记录。
- 检查缓存配置，同一政策文号的两次间隔较短的调用是否复用了缓存结果，且缓存有效期内未重新发起拉取请求。
- 验证`functionCall`模式下，是否仅调用预设的政策工具，未生成无官方依据的回复内容。
