# 船舶制造的政策与制度依据问答：模型接入与配置

## 这个品类的数据长什么样
船舶制造领域的政策与制度依据数据，主要来源于工业和信息化部、交通运输部及地方海事管理机构发布的行业标准、建造规范、监管文件。数据更新随新政策出台或旧版修订调整，无固定周期。文档多为结构化章节式文本，包含文号、生效日期、适用船型、技术指标、合规要求等字段，单位多采用国际通用的船舶行业标准单位，如总吨、船长米、主机功率千瓦等。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–16000 token | 船舶制造政策文档单篇长度多在数千字符，需完整加载上下文以准确匹配政策条款 |
| `maxTokens` | 2000–3000 token | 政策问答需生成详细合规依据，输出长度需覆盖完整条款引用 |
| `quoteMaxToken` | 1000–1500 token | 需完整引用政策原文片段，避免截断关键合规要求 |
| `temperature` | 0.1–0.3 | 政策问答需严格匹配原文，不宜生成发散内容 |
| `AIPROXY_API_ENDPOINT` | 本地VLLM部署的API地址（如http://localhost:8000/v1） | 对接本地部署的大模型需指定正确的服务端点 |
| `AIPROXY_API_TOKEN` | 本地模型服务生成的访问令牌 | 验证本地模型服务的访问权限 |

## 容易做错的三处
- 现象：调用本地VLLM模型时返回503状态码，或提示连接超时。原因：未正确配置`AIPROXY_API_ENDPOINT`的端口路径，或本地模型服务未正常启动。
- 现象：问答返回的政策条款不完整，或出现截断。原因：`quoteMaxToken`取值过小，导致引用的政策原文片段被截断。
- 现象：上传政策文档后无法正确匹配专业术语，或上下文加载不全。原因：未选择适配工业领域的嵌入模型，或`maxContext`取值不足，无法加载完整文档内容。

## 怎么确认配好了
- 调用本地VLLM模型的健康检查接口，验证`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`配置正确。
- 上传一篇船舶制造政策文档，发起合规性查询，测试返回的上下文是否完整覆盖文档内容，确认`maxContext`取值符合需求。
- 发起针对具体船型的政策查询，验证返回的引用片段未被截断，确认`quoteMaxToken`取值合理。
- 调整`temperature`参数，验证生成的回答是否严格匹配政策原文，无发散内容。
