# 船舶制造的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
船舶制造领域的政策与制度依据数据，主要来源于工信部装备工业一司、交通运输部海事局、中国船舶工业行业协会发布的官方红头文件、行业标准、监管细则。数据更新随新政策出台、标准修订触发，无固定周期。文档多为结构化公文，包含发布文号、生效日期、适用场景、条款细则等字段，部分标准文档附带技术参数表格，单位涉及毫米、吨、千瓦等船舶制造专用计量标准。

## 这些特征在「知识库检索与召回」这一环带来什么约束
船舶制造的政策数据特征会对检索召回带来多重约束。结构化公文的多字段属性，要求检索需同时匹配内容与发布文号、生效日期等元数据，避免召回过期或不适用的政策。标准文档附带的技术参数表格，要求分段时保留表格结构，防止召回内容丢失专用计量参数。无固定更新周期的数据源，需要配置增量同步逻辑，确保召回内容始终匹配最新政策。专业术语密集的文本，需适配`searchMode`的精准匹配逻辑，同时开启`usingReRank`的二次重排与`datasetSearchUsingExtensionQuery`的术语扩展，提升召回精准度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 相似度阈值 | 0.75–0.85 | 船舶制造政策文本专业度高，需过滤低匹配度结果，该区间可平衡召回覆盖与精准度 |
| 单次搜索上限 | 前8条 | 政策文档多为长文本，单次召回8条可覆盖核心条款与关联补充文件 |
| 搜索模式 | 精准匹配 | 政策检索需严格匹配条款内容与元数据，精准模式可避免无关召回 |
| 重排开关 | 开启 | 专业术语多的文本需二次重排，提升高匹配结果的排序优先级 |
| 问题优化开关 | 开启 | 可基于用户问题扩展行业专属术语，比如将“造船规范”扩展为“中国造船质量标准” |
| 知识库集合ID | 按实际绑定的船舶政策数据集填写 | 确保仅检索指定领域的政策数据，避免混入无关文档 |

## 容易做错的三处
- 无法加载自建的Qdrant向量数据库作为知识库，原因是未在FastGPT中配置自定义向量库的连接参数，仅使用了平台默认的向量存储服务。
- 调用API时提示授权失败，原因是未在应用配置中绑定正确的知识库权限，或API key的有效期已过期。
- 分段后的内容丢失word文档的目录结构，原因是未开启按文档结构分段的设置，直接按固定字符长度拆分，导致目录与内容脱节。

## 怎么确认配好了
- 进入FastGPT v4.17.0的知识库管理页面，查看已绑定的数据集是否包含船舶制造政策相关文档，确认集合ID与配置项一致。
- 发起一条测试查询，比如“船舶制造的CCS认证要求”，查看召回结果是否包含匹配的政策条款，且排序符合预期。
- 检查API调用日志，确认请求中携带的API key有效，且未出现权限相关的报错信息。
- 查看分段后的文档预览，确认长文档的分段保留了核心条款与元数据，未出现内容断裂或结构丢失。
