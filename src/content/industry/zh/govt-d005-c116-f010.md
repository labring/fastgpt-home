# 通信工程建设的政策与制度依据问答：知识库检索与召回

## 这个品类的数据长什么样
通信工程建设的政策与制度依据数据主要来自工信部、住建部及各省市通信管理局发布的行业规范、立项审批文件与合规细则。数据更新随行业标准修订与地方政策出台，通常按季度或年度更新。单篇文档通常包含发布文号、生效日期、适用建设场景、核心合规条款等字段，部分文档附带工程预算、验收标准等配套内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束
通信工程建设政策数据的多来源、分场景特征，对检索召回带来三项核心约束。首先数据覆盖国家级行业标准与地方执行细则，需支持跨多个数据集联合召回；其次每份文档标注生效日期与适用区域，检索时需按时间与地域维度过滤有效结果；最后文档按建设场景拆分条款，需匹配基站铺设、管线架设等细分关键词，避免召回无关合规要求。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.72–0.80 | 通信工程政策条款专业度高，需过滤低相关结果，该区间可平衡召回覆盖与精准度 |
| `limit` | 前8条 | 单篇政策文档内容较长，过多召回结果会超出上下文上限，8条可覆盖核心合规依据 |
| `searchMode` | 精准匹配 | 政策条款需严格匹配关键词，模糊匹配易引入无关行业规范，精准模式可提升结果相关性 |
| `usingReRank` | 开启 | 专业文档的语义相似度易受术语干扰，重排可基于上下文语义修正召回排序 |
| `datasetSearchUsingExtensionQuery` | 开启 | 政策术语存在行业缩写（如5G基站、FTTH），扩展查询可补充同义词召回 |
| `collectionIds` | 按建设场景绑定对应数据集 | 不同建设场景对应不同政策集，绑定指定数据集可减少无效召回 |

## 容易做错的三处
- 现象：调用知识库时返回参数格式错误，提示`datasetId`字段无效。原因：未使用FastGPT指定的变量引用格式，误将通用模板`[{datasetId: xxx}]`用于数据集绑定，未按平台要求配置对应数据集。
- 现象：知识库上传后长期处于索引中状态。原因：通信工程政策文档多为长文本且包含专业技术表格，索引时需处理复杂格式转换，超出默认索引超时阈值。
- 现象：无法基于企业身份筛选可用的知识库记录。原因：未在数据集配置中启用权限标识符功能，未为知识库条目添加企业专属标识字段。

## 怎么确认配好了
- 提交测试检索请求，输入具体建设场景关键词（如“5G基站验收标准”），核对返回结果的生效日期与适用地域是否匹配检索条件。
- 查看检索结果的排序，确认重排后的结果与专业术语的语义匹配度符合预期。
- 检查数据集绑定配置，确认已按建设场景关联对应政策文档集，无跨无关数据集的召回。
- 测试变量引用与权限过滤，确认指定标识符可正确过滤对应知识库条目。
