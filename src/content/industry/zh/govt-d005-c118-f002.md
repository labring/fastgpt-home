# 金属材料加工的政策与制度依据问答：向量模型与索引

## 这个品类的数据长什么样
金属材料加工的政策与制度依据数据主要来源于工业和信息化部、国有资产监督管理委员会发布的钢铁有色行业专项政策，以及国家金属材料相关国家标准、行业标准文档，还有企业内部合规生产的制度文件。数据更新节奏随政策发布周期调整，国家标准每3-5年修订一次，行业政策随产业调整不定期更新。文档多为结构化文本，包含政策文号、发布单位、生效日期、适用工艺范围、技术指标要求等字段，涉及兆帕、毫米、吨等金属加工常用参数单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
金属材料加工的政策数据特征会对向量模型与索引环节带来多重约束。结构化字段多且包含专业参数单位，纯文本向量召回无法精准区分政策文号、生效日期与技术指标，需要针对关键字段设置加权索引规则。更新周期不固定且存在新旧政策并行的情况，需要配置增量索引同步逻辑，确保最新政策优先被召回。文档片段常包含连续的工艺技术要求，分块时需保留上下文关联，避免割裂完整的合规条款。不同政策的适用范围存在层级差异，需加入分类标签字段缩小召回范围，提升匹配精度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 金属加工政策文档常包含连续的工艺条款，该长度可保留完整的合规要求上下文，避免分块割裂技术指标。 |
| 重叠长度 | 150–200 字符 | 政策文档的技术指标常跨分块出现，重叠长度可确保相邻分块共享关键参数信息，提升召回完整性。 |
| `maxToken` | 4096 token | 金属加工政策文档的单条合规条款常包含多个参数单位，该token上限可容纳完整的分块内容，避免截断关键信息。 |
| 相似度阈值 | 0.72–0.80 | 政策匹配需兼顾精准性与覆盖度，该区间可过滤无关政策文档，同时召回符合要求的合规依据。 |
| 单次搜索上限 | 前 8 条 | 金属加工政策的适用范围存在层级差异，召回适量条目可覆盖不同层级的合规要求，避免遗漏。 |
| `defaultToken` | 2048 token | 用户查询的政策相关问题通常为中等长度，该token上限可承载标准的查询扩展上下文，提升匹配效果。 |

## 容易做错的三处
- 现象：索引模型与文本模型混用后出现召回结果乱序，状态码返回200但匹配精度低于预期。原因：未按照金属加工政策的专业参数特征统一配置模型类型，不同模型的向量空间维度不一致，导致召回结果无法有效排序。
- 现象：分块长度设置为500字符后，界面显示部分分块内容缺失，合规条款被割裂。原因：未考虑金属加工政策文档中连续工艺条款的长度，分块过短导致无法承载完整的技术指标描述。
- 现象：尝试引入关系型索引后，系统返回字段为空的提示，无法加载政策的关联条款。原因：未针对金属加工政策的结构化字段配置关联索引规则，默认的扁平化索引无法识别政策间的层级关联。

## 怎么确认配好了
本核对流程基于FastGPT v4.17.0版本实现。
- 上传单条金属加工政策文档，查看分块预览界面，确认分块未割裂连续的工艺技术条款。
- 发起一条针对具体工艺合规的查询，查看召回结果的相似度得分，确认得分区间符合预设的阈值范围。
- 上传更新后的政策文档，查看索引同步日志，确认增量索引已完成且旧政策未被优先召回。
- 查看系统的向量模型调用日志，确认`maxToken`与`defaultToken`的配置未触发截断提示。
