# 金属材料加工的政策与制度依据问答：多轮对话与提示词

## 这个品类的数据长什么样
金属材料加工领域的政策与制度依据数据主要来源于国家发改委、工信部及各省市工信部门发布的行业规范性文件、国家标准与行业标准。数据随正式政策发布同步更新，无固定周期。文档多以正式公文格式存在，包含发文文号、发布单位、生效日期、适用范围、具体条款等字段，条款内容按章节划分，部分文件附带量化指标与单位要求，涉及产能置换、环保排放、产品质量检验等细分场景。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
政策文档的固定结构要求多轮对话需跟踪用户提及的发文文号、生效日期等元数据，避免在后续追问中丢失关键依据。无固定更新周期要求提示词需明确要求引用当前最新生效的政策版本，避免返回已废止文件。条款按章节划分的特征，要求多轮对话中需关联用户当前问题与之前提及的具体条款范围，确保回答的针对性。政策适用范围的字段差异，要求提示词中需明确限定金属材料加工领域的细分场景，缩小检索范围，避免跨领域政策被错误召回。

## 配置怎么定
本配置方案适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 对话ID绑定 | 绑定项目编码+对话序列 | 确保多轮对话上下文与特定金属材料加工政策咨询项目绑定，避免跨项目混淆 |
| 上下文保留轮次 | 最近4轮 | 金属材料加工政策问答常涉及条款追溯，4轮可覆盖常规追问逻辑，避免上下文溢出 |
| 自定义变量 | 注入当前生效政策版本号 | 确保回答引用的政策为最新发布的有效版本，符合领域内合规要求 |
| 单次召回上限 | 前5条 | 政策类文档多为关联条目，5条可覆盖同主题下的不同层级政策，避免冗余信息干扰 |
| 文档分块阈值 | 1000–1500 字符 | 匹配金属材料加工政策文档的单条款长度，确保分块后仍保留完整的条款逻辑 |

## 容易做错的三处
- 现象：对话页上传金属材料加工政策文档时返回503报错，但后台日志显示文件上传成功。原因：未设置符合金属材料加工政策文档长度的分块阈值，导致大文件解析超时触发服务异常。
- 现象：多轮对话中后续回答未关联之前提及的政策文号。原因：未正确配置对话ID绑定规则，导致上下文未被正确关联，每轮对话独立检索导致信息丢失。
- 现象：回答中引用了已废止的政策文件。原因：未在自定义变量中注入当前生效的金属材料加工政策版本筛选条件，导致召回了过期的政策文档。

## 怎么确认配好了
- 上传一篇金属材料加工领域的正式政策文档，检查解析后的分块内容是否包含发文文号、生效日期等核心字段。
- 发起两轮关联的政策问答，例如先查询某文号的政策条款，再追问该条款的适用场景，检查后续回答是否保留了第一轮提及的文号信息。
- 测试上传已明确标注废止的政策文件，确认系统未召回该类文档，验证版本筛选配置生效。
- 查看对话记录的绑定信息，确认不同项目的对话上下文未出现跨项目混淆的情况。
