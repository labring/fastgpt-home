# 金属材料加工的政策与制度依据问答：文档解析与分块

## 这个品类的数据长什么样
金属材料加工领域的政策与制度依据文档，主要来源于工业和信息化部、国有资产监督管理委员会及地方行业主管部门的公开规范性文件、行业标准。文档更新随政策修订或标准迭代进行，无固定周期。文档多为结构化条款，包含政策文号、发布单位、生效日期、适用金属品类（如碳钢、铝合金），附带技术参数字段，单位多为兆帕（MPa）、毫米（mm）、百分比（%）等，部分附件包含批量金属牌号对照表与检测流程说明。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的政策文档存在结构化条款与附件表格混合的特征，会对文档解析与分块带来多重约束。结构化条款需保留文号与对应内容的绑定关系，避免拆分时割裂关键信息。附件中的金属牌号对照表、检测参数表格，需保留行列结构，不可拆分为零散文本。跨页连续条款需自动合并，防止内容断裂影响后续问答准确性。同时，文档中大量专业单位需与对应参数绑定，避免解析后单位与数值分离。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 金属加工政策文档单条款长度多在500-1000字符，该区间可完整覆盖单条政策条款，避免拆分割裂 |
| `chunkSplitter` | 按标题+段落拆分 | 政策文档以条款标题为核心标识，按此拆分可保留文号与条款的绑定关系 |
| `customPdfParse` | 开启 | 适配政策文档中混合的表格、公式与结构化条款，提升解析完整性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 大型政策文档包含多页附件表格，需足够时间完成全量解析 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 部分行业标准文档包含批量金属牌号数据，支持更大文件上传 |
| `chunkSettingMode` | 手动配置 | 针对不同类型的政策文档（纯条款/带附件）可灵活调整分块参数 |

## 容易做错的三处
- 现象：PDF上传后显示解析超时，返回状态码504。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时长不足以完成含多页附件表格的政策文档解析。
- 现象：导入金属牌号csv表格后，仅前两列数据被识别。原因：未开启`customPdfParse`的表格识别模式，默认解析逻辑仅提取文本列，未完整读取多列结构化数据。
- 现象：分块后政策文号与对应条款分离，问答时无法关联匹配。原因：`chunkSplitter`配置为按换行符拆分，未绑定标题与条款的关联关系。

## 怎么确认配好了
- 上传单页政策条款文档，查看解析后的分块结果，确认条款与文号未被拆分。
- 上传包含金属牌号表格的csv文件，核对解析后的数据列数与原文件一致。
- 上传大型政策文档，查看解析进度，确认未触发超时提示。
- 调整`chunkSize`参数后上传测试文档，查看分块长度是否符合预期配置。
