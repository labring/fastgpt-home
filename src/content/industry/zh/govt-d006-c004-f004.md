# 主动公开与政策发布的文书与材料起草：工作流编排

## 这些特征在「工作流编排」这一环带来什么约束
多源数据来源要求工作流需配置跨系统拉取节点，兼容公文系统导出格式、门户网站结构化数据及政策库的半结构化文本。日更频率要求触发规则需设置为每日定时执行，避免错过发布周期。多类文档类型要求工作流分支节点按公开目录、政策解读、审批单等分类处理，匹配不同字段校验逻辑。公开属性与保密审查字段要求前置配置合规校验节点，拦截不符合要求的文档进入发布环节。多平台同步需求要求工作流需配置多输出节点，分别对接不同网站栏目与新媒体账号。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| 触发方式 | 按定时任务触发，每日 9:00 执行 | 数据更新频率为每日，需匹配日常发布周期要求 |
| `variables` 参数配置 | 包含公开属性校验规则、保密审查阈值、目标栏目列表 | 需动态传递品类专属的校验与发布参数，适配不同场景需求 |
| 分支节点绑定 | 按文档类型绑定对应`nodeId` | 不同文档需执行差异化处理逻辑，需精准关联对应处理节点 |
| 合规校验节点 | 配置公开属性与保密审查校验规则 | 需前置拦截不符合要求的文档，规避出错后果 |
| 多输出节点 | 绑定2-3个目标平台输出 | 需同步多个网站栏目与新媒体账号，覆盖日常发布需求 |
| 超时设置 | 设置为 600 秒 | 跨系统拉取数据需预留足够响应时间，按实测标定 |

## 容易做错的三处
- 工作流在运行预览页面可正常执行并输出结果，在聊天页面调用时无返回内容。未配置聊天页面的`variables`参数传递，导致工作流无法获取品类专属的公开属性校验规则等动态参数。
- 在工作流的HTTP请求节点中，选择form-data格式时无法正确配置文件类型参数，请求执行失败。未选择对应文件上传的输入组件，或未绑定本地文件或系统文件路径参数。
- 上传文件进行对比时提示Load file error，知识上传可正常执行。工作流节点未正确关联文件上传的数据源，或文件格式不符合工作流预设的校验规则。

## 怎么确认配好了
- 触发工作流的定时任务，查看各节点的执行日志，确认多源数据拉取、合规校验、多输出环节均正常完成。
- 手动传入一条测试文档，核对工作流是否按文档类型触发对应分支节点，是否拦截不符合公开属性要求的文档。
- 调用聊天页面的工作流接口，确认`variables`参数传递正确，可正常获取返回结果。
- 检查多输出节点的绑定配置，确认是否覆盖了目标网站栏目与新媒体账号。
