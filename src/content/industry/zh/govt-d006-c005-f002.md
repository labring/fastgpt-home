# 产权、资产与国有资本管理的文书与材料起草：向量模型与索引

## 这个品类的数据长什么样
这个品类的日常文档包括产权登记表、资产评估报告、产权转让方案、进场交易公告、资产处置审批单等。数据主要来自国资监管信息系统、企业资产管理系统、产权交易所系统、评估机构报告及财务报表，更新频率为月度。单份文档结构包含权属标识、资产明细、审批流程节点等字段，部分文档包含结构化数值与非结构化描述内容，数据体量随存量资产规模变化，无固定统一格式模板。

## 这些特征在「向量模型与索引」这一环带来什么约束
月度更新的数据特征要求索引配置需适配批量增量更新的节奏，避免频繁全量索引带来的资源消耗。多来源的文档格式差异要求索引支持混合类型内容的向量化处理，确保结构化字段与非结构化描述均能被正确编码。单份文档长度跨度较大，从简短的审批单到长篇的评估报告均有覆盖，需保证向量模型的token处理能力适配不同长度的文本。同时，由于出错后果涉及国有资产流失等风险，索引的召回精度需满足业务审核的严谨性要求，避免关键权属信息遗漏。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配该品类文档的平均长度，避免单块内容过于分散或超出模型处理上限 |
| 重叠长度 | 100–200 字符 | 确保跨块的关键信息如资产编号、权属声明不会被截断 |
| `maxToken` | 8192 token | 适配长篇资产评估报告的内容编码，避免因token超限导致内容丢失 |
| `defaultToken` | 4096 token | 匹配多数场景下的常规文本处理需求，平衡计算资源与召回效果 |
| 相似度阈值 | 0.75–0.85 | 过滤低相关结果，确保召回内容与产权、资产相关的核心诉求匹配 |
| 单次搜索上限 | 前 10 条 | 控制返回结果的数量，避免冗余信息干扰审核环节 |

## 容易做错的三处
- 现象：更新FastGPT版本后，原索引的知识库无法支持向量检索，搜索无结果。原因：新版本的索引构建逻辑调整，原索引的向量编码格式与新版本不兼容，需重新构建索引，不能直接复用旧数据。
- 现象：同一CSV文件在升级版本后出现分块报错。原因：新版本对CSV的字段解析规则调整，原文件中存在未处理的特殊字符或空字段，导致分块流程中断。
- 现象：检索结果无法命中资产权属相关的关键内容。原因：相似度阈值设置过高，过滤掉了部分低分值但关键的匹配结果，或分块长度设置过短导致关键信息被拆分丢失。

## 怎么确认配好了
- 导入单份典型文档（如产权转让方案），检查分块预览界面是否完整保留核心字段与内容，无明显截断或丢失。
- 发起针对资产权属编号的检索，确认召回结果包含对应文档的相关片段，且数量符合单次搜索上限的设置。
- 调整相似度阈值后发起检索，观察结果数量的变化是否符合预期，验证阈值的过滤效果。
- 执行增量索引更新，检查系统是否能正常识别新增的月度数据，无报错或遗漏。
