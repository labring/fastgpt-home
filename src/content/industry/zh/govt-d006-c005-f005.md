# 产权、资产与国有资本管理的文书与材料起草：工具调用与插件

## 这个品类的数据长什么样
本品类涉及的核心数据来自国资监管信息系统、企业资产管理系统、产权交易所系统、评估机构报告及财务报表，更新周期为月度。日常处理的文档包含产权登记表、资产评估报告、产权转让方案、进场交易公告、资产处置审批单，文档结构多包含权属主体、资产明细、评估值、交易条件等固定字段，单位涉及万元、平方米、件等资产相关计量标准。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散且月度更新，要求工具调用需对接多系统接口，需适配不同系统的字段格式与权限规则。文档结构固定但字段较多，工具调用需精准匹配产权、资产相关字段，避免遗漏权属信息或交易条件。月度更新的批量数据需工具支持批量处理，避免单次调用过载。出错后果严重，工具调用需增加前置校验环节，确保生成的文书符合权属、交易要求，防止生成错误材料导致国有资产流失或交易被叫停。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 绑定专属产权文书生成工具 | 确保调用逻辑聚焦国有资产相关的文书生成，避免泛化工具调用 |
| `functionCall` | 开启强制调用模式 | 强制生成的文书包含资产权属、交易条件等必填字段，符合业务规范 |
| 最大上下文长度 | 8000–12000 token | 覆盖月度批量的资产数据、历史审批单及评估报告内容 |
| 单次调用超时阈值 | 600 秒 | 适配批量资产明细的读取与校验时长，避免调用中断 |
| 工具重试次数 | 2 次 | 应对多系统接口的临时异常，保障数据获取的稳定性 |

## 容易做错的三处
- 现象：调用非通义千问模型时出现工具调用报错，返回字段为空或格式错误。原因：未针对模型适配工具调用的格式要求，部分模型对`functionCall`格式的兼容性存在差异。
- 现象：工具调用出现并发请求，导致系统返回重复的工具选择结果或状态异常。原因：未配置工具调用的互斥触发规则，多线程请求同时触发工具选择逻辑。
- 现象：调用文档读取插件时无法获取资产系统内的最新数据。原因：未配置插件对接国资监管系统的月度数据更新接口，仅读取了本地缓存的旧数据。

## 怎么确认配好了
- 发起一次模拟调用，传入单条资产处置审批单数据，检查生成的文书是否包含权属主体、资产明细、审批流程等必填字段。
- 查看FastGPT v4.17.0的工具调用日志，确认每次调用均触发预设的产权文书生成工具，未出现泛化调用。
- 测试多批次月度批量数据的调用，检查是否出现超时或数据截断问题，调整相关配置项至符合业务需求。
- 触发异常接口调用场景，检查是否触发预设的重试机制，确认工具调用的稳定性。
