# 产权、资产与国有资本管理的文书与材料起草：引用来源与溯源

## 这个品类的数据长什么样
本品类的数据主要来自国资监管信息系统、企业资产管理系统、产权交易所系统、评估机构报告及财务报表，更新频率为每月一次。日常生成的文书包含产权登记表、资产评估报告、产权转让方案、进场交易公告、资产处置审批单，文档结构包含权属编号、资产类别、评估值、交易审批状态等核心字段，单份核心文档长度多在千字符级别。

## 这些特征在「引用来源与溯源」这一环带来什么约束
多源异构的数据来源需要关联多个独立知识库，需确保不同系统的知识库权限配置与字段映射准确。每月一次的官方更新频率要求知识库同步周期匹配，避免引用过期的资产信息。文档包含明确的权属、交易等敏感字段，引用时需精准匹配对应资产条目，不能混淆不同主体的资产信息。同时，该品类的引用溯源出错会导致国有资产流失、交易被叫停等严重后果，需确保溯源信息完整可查。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 单次召回条数 | 前6条 | 匹配单轮提问覆盖的核心资产文档数量 |
| `quoteMaxToken` | 1500–2000 token | 适配本品类单份核心文书的平均长度 |
| `responseData` | 开启返回关联文档元数据 | 满足溯源时展示文档来源、生成时间的需求 |
| `detail` | 开启详细溯源模式 | 支持展示引用文档的核心字段细节 |
| 知识库同步频率 | 每月1次 | 匹配本品类数据的官方更新节奏 |

## 容易做错的三处
- 回答未包含知识库关联的资产内容，但引用列表显示匹配到知识库条目。原因是未正确配置`responseData`的元数据关联，或召回的知识库内容未正确注入回答上下文。
- 引用的文档字段与实际资产文档不符，比如将A资产的评估值引用到B资产的转让方案中。原因是知识库分块时未保留唯一权属编号字段，导致召回内容与目标资产不匹配。
- 知识库同步完成后仍引用旧数据。原因是同步周期设置长于本品类每月一次的更新频率，导致未拉取最新的资产变更信息。

## 怎么确认配好了
- 确认当前部署的FastGPT版本为v4.17.0。
- 检查知识库同步日志，确认最近一次同步完成且无报错信息。
- 发起针对特定资产的测试提问，查看回答下方的引用列表是否包含匹配的产权或评估文档条目。
- 查看引用详情，确认展示的字段包含资产权属编号、评估值等核心信息。
- 测试提问超出`quoteMaxToken`限制的内容，查看回答是否按配置进行截断并标注来源。
