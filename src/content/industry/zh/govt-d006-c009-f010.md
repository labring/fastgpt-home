# 公共数据目录与开放的文书与材料起草：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据主要来自地方公共数据开放平台、一体化大数据平台、部门业务数据库、电子证照库，更新频率为月度。日常产出的文档包含公共数据资源目录、数据开放清单、数据项说明、脱敏规则、接口文档、更新频率说明，文档结构兼具结构化字段与非结构化正文，字段涵盖数据项名称、开放范围、脱敏方式、接口地址、更新周期、授权条件等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
月度更新的数据源要求知识库同步频率匹配更新周期，避免检索结果包含过时数据。多来源、多类型文档的混合场景，要求检索同时覆盖结构化字段与非结构化正文，避免遗漏关键信息。数据项与脱敏规则强绑定的特征，要求检索结果需精准关联对应数据的授权与脱敏要求，防止出现数据泄露风险。同时，单份文书起草需关联的内容条目有限，需控制检索结果的数量，避免上下文过载影响生成质量。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配公共数据目录的字段严谨性，避免低相关数据项混入起草文书 |
| `limit` | 前10条 | 适配单份文书起草需关联的少量数据项，控制上下文长度 |
| `searchMode` | 全文检索+字段检索 | 覆盖文档正文和结构化字段，适配目录的多类型内容 |
| `usingReRank` | 开启 | 对接口文档、脱敏规则这类专业内容优化排序精度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展数据项相关的政务同义词，适配行业术语多样性 |
| `collectionIds` | 按绑定的公共数据目录数据集填写 | 限定检索范围，避免无关数据干扰检索结果 |

## 容易做错的三处
- 现象：检索结果返回「无权访问数据集」报错，或返回空结果。原因：未将对应部门的数据集绑定到当前知识库，或配置了错误的`collectionIds`参数。
- 现象：点击检索结果无法打开切片前的原文件预览。原因：未开启知识库的原文件存储配置，或未正确关联源文档与切片内容。
- 现象：上传PDF格式的接口文档后未生成有效检索切片。原因：未正确部署pdf-marker服务，或未在FastGPT配置中指定该服务的访问端口。

## 怎么确认配好了
- 手动输入一条常见数据项名称，检查检索结果是否包含对应的数据项说明、接口文档等关联内容。
- 查看检索结果的元数据，确认是否关联了正确的部门数据集，避免跨部门无关数据混入。
- 开启`usingReRank`后，检查专业术语类内容的排序是否符合业务逻辑，优先展示高相关的脱敏规则或接口说明。
- 点击检索结果的关联预览链接，确认能打开切片前的源文档，验证原文件预览功能正常。
