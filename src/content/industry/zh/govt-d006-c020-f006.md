# 国土空间规划编制与实施评估的文书与材料起草：引用来源与溯源

## 这个品类的数据长什么样
本品类数据来源固定为国土空间基础信息平台、自然资源调查监测数据、人口经济统计、遥感影像四类，更新频率为年度。日常产出文档包含国土空间总体规划、详细规划、专项规划、规划实施评估报告、公众意见汇总等，文档结构涵盖文本描述、空间坐标、面积指标、统计数值等字段，单位通常为公顷、十进制经纬度、万人等，单份规划文档可覆盖多类数据源的关联内容。

## 这些特征在「引用来源与溯源」这一环带来什么约束
年度更新的数据源要求知识库需定期完成全量同步，确保引用内容与最新政策、监测数据一致。多源数据的混合引用需精准标记每个条目对应的原始来源平台与数据集，避免混淆不同渠道的统计结果。复杂的文档结构与空间关联字段，要求溯源信息需同时包含文本段落与对应空间范围，满足规划审批的合规性要求，出错后易引发规划审批延误，因此溯源环节需具备可追溯的完整链路。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | 国土空间规划文档单段引用内容较长，需覆盖完整数据说明与空间范围 |
| `responseData` | 开启 | 需完整溯源原始数据来源与条目，匹配规划审批的合规要求 |
| `detail` | 开启 | 需展示引用数据的具体字段，如坐标、面积等，满足规划文档的严谨性 |
| 单次搜索上限 | 前6条 | 覆盖主要来源数据集，避免冗余信息干扰规划文本撰写 |
| 上下文窗口长度 | 15000–20000 字符 | 规划文档篇幅较长，需保留多轮引用的上下文关联 |

## 容易做错的三处
- 现象：生成的引用内容仅显示数据id，未展示具体字段与来源说明。原因：未开启`detail`配置项，未启用详情展示功能。
- 现象：设置变量引用模式后，温度设置按钮消失，无法调整生成参数。原因：FastGPT v4.17.0中，变量引用模式默认锁定生成参数，需通过预设模板配置温度参数。
- 现象：引用数据条数不足，无法覆盖规划所需的多源数据源。原因：单次搜索上限设置过低，未匹配多源数据的覆盖需求。

## 怎么确认配好了
- 生成单篇规划文档的引用片段，检查是否包含原始数据来源与具体字段信息。
- 测试变量引用模式，确认可通过预设模板调整生成参数，恢复温度设置功能。
- 验证引用数据条数符合预期的覆盖范围，可匹配规划所需的多源数据源。
- 查看引用内容的token数，确认处于800–1200 token区间内，符合文档展示要求。
