# 安全生产隐患排查治理的文书与材料起草：知识库检索与召回

## 这个品类的数据长什么样

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源数据的接入要求检索范围需限定在指定的业务数据集内，避免无关内容干扰合规检索；每日更新的频率要求配置自动增量同步任务，确保检索使用的知识库内容与最新业务数据同步。多样的文档类型需要适配不同的检索匹配逻辑，兼顾专业术语与标准条文的精准匹配。同时，由于数据直接关联安全生产合规要求，检索召回的结果需具备较高的置信度，需通过参数调整优化精准度，避免遗漏关键的隐患判定与整改相关内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 平衡精准匹配与召回覆盖，避免低相关结果干扰安全生产合规检索 |
| `limit` | `前8–12条` | 控制上下文长度，同时覆盖多类业务文档的相关内容 |
| `searchMode` | `vector + keyword` | 兼顾语义匹配与专业关键词匹配，适配隐患排查相关的标准术语 |
| `usingReRank` | `开启` | 对召回结果进行二次排序，提升高相关内容的优先级，强化合规检索的准确性 |
| `datasetSearchUsingExtensionQuery` | `开启` | 自动扩展查询词，覆盖隐患排查的同义表述，提升召回覆盖范围 |
| `collectionIds` | `绑定安全生产监管、企业自查等指定数据集` | 限定检索范围，确保召回内容贴合本品类的业务数据 |

## 容易做错的三处
- 现象：检索结果中出现大量重复的隐患治理台账文件，原因：未对上传至知识库的文档执行去重校验，或多数据源同步时未过滤重复条目。
- 现象：无法查看单篇业务文档的历史调用记录，原因：未开启知识库的调用日志采集开关，或日志存储配置未覆盖检索环节的操作。
- 现象：检索返回的内容未匹配到重大隐患判定标准的相关条款，原因：`similarity`参数设置过高，导致部分低匹配度但关键的标准条款被过滤，或未配置`datasetSearchUsingExtensionQuery`导致查询词覆盖范围不足。

## 怎么确认配好了
- 进入FastGPT知识库管理界面，查看指定数据集的同步日志，确认每日增量同步任务正常执行。
- 发起一条针对隐患整改通知书的检索请求，核对返回结果的条数与`limit`参数配置的取值一致。
- 开启检索日志功能，发起一次检索操作，查看日志中是否记录了本次调用的参数和召回结果。
- 上传一份重复的隐患排查清单文件，检查检索结果中是否未返回重复条目。
