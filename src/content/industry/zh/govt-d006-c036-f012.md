# 政务服务事项目录与办事指南维护的文书与材料起草：部署与升级

## 这个品类的数据长什么样
这个品类的日常文档包括政务服务事项基本目录、实施清单、办事指南、标准材料目录、流程图、常见问题等。数据来源为国家政务服务事项基本目录、行政许可事项清单、权责清单及地方政务服务事项库等官方数据源，更新频率为月度。文档结构包含事项唯一标识、实施主体类别、申请材料明细、受理条件、办理流程节点等字段，部分文档存在多字段关联的嵌套结构。

## 这些特征在「部署与升级」这一环带来什么约束
月度更新频率要求部署后支持稳定的增量数据同步机制，避免全量重导带来的服务中断。官方数据源的合规性要求配置项需支持对接标准化政务数据接口，同时多文档关联的结构需要向量数据库支持多字段关联检索。字段完整性校验的业务需求，要求部署环节配置数据校验规则，拦截缺失关键字段的条目。该品类不处理单个申请人的具体办件，部署时无需配置面向终端用户的高并发限流规则，只需保障内部运维场景的稳定性。云环境部署时，需适配云服务商的网络访问控制策略，确保数据库与存储服务的访问安全。

## 配置怎么定
以下配置项适配FastGPT v4.17.0的部署规范。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://govadmin:SecurePass123@rds-host:27017/gov_service?authSource=admin` | 对接政务事项数据存储的专用MongoDB实例，满足多文档关联存储需求 |
| `REDIS_URL` | `redis://:RedisPass456@redis-host:6379/0` | 缓存高频访问的事项基础信息，降低数据库查询压力 |
| `DB_MAX_LINK` | `20–30` | 适配月度增量同步的并发连接数，避免数据库连接耗尽 |
| `STORAGE_S3_ENDPOINT` | `oss-cn-hangzhou.aliyuncs.com`（阿里云场景） | 存储办事指南附件、流程图等文档，符合政务数据存储合规要求 |
| `FE_DOMAIN` | `https://gov-fastgpt-internal.example.com` | 配置内部运维界面的访问域名，确保操作权限可控 |

## 容易做错的三处
- 升级FastGPT版本后，知识库检索报错包含`text index required for $text query`的提示。原因：未在升级后重新创建MongoDB的全文索引，政务事项数据的文本检索依赖该索引。
- 阿里云环境部署时，无法连接云RDS数据库，提示连接超时或权限不足。原因：未将FastGPT部署实例的IP添加至RDS实例的访问白名单，未配置正确的数据库连接参数。
- 部署后仅能展示基础事项列表，无法加载办事指南的关联附件与流程信息。原因：未配置`STORAGE_S3_ENDPOINT`等存储相关参数，导致附件资源无法正常读取。

## 怎么确认配好了
- 执行数据库连接测试命令，验证`MONGODB_URI`配置的MongoDB实例可正常建立连接。
- 上传一份测试用的办事指南附件，通过`STORAGE_S3_ENDPOINT`配置的存储端点访问该文件，确认存储链路正常。
- 触发一次增量数据同步任务，查看同步日志中无字段缺失或连接异常的报错信息。
- 检索测试用的政务事项关键词，确认检索结果返回符合预期的事项条目与关联文档。
