# 特种设备安全监管的文书与材料起草：工具调用与插件

## 这个品类的数据长什么样
本品类的数据来源为特种设备安全监察系统、检验检测机构系统、使用单位台账、作业人员证书库，更新频率为月度。日常需处理的文档包含使用登记证、定期检验报告、维保记录、隐患整改通知书、事故报告、作业人员证书，核心字段包含设备唯一编号、检验有效期、维保周期、作业人员证号、隐患整改状态、设备类型等，所有文档均绑定对应特种设备的唯一标识，字段格式需严格匹配监管系统的校验规则。

## 这些特征在「工具调用与插件」这一环带来什么约束
多数据源的接入需求要求插件需支持对接多个异构系统的接口，需针对不同系统配置独立的认证与数据拉取规则。月度更新的频率要求工具调用的缓存与筛选逻辑需匹配月度周期，避免拉取过期或未更新的数据。强绑定设备唯一标识的文档结构要求工具调用需精准匹配字段关联关系，例如自动关联设备编号与对应检验报告的有效期。高风险监管属性要求工具调用的权限校验与失败处理需更严格，防止敏感数据泄露或错误文书生成。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `toolChoice` | `auto` | 适配多工具调用场景，自动选择匹配特种设备监管的文书起草与数据拉取工具 |
| `functionCall` | 开启 | 强制触发结构化函数调用，确保生成的文书字段符合监管文档的格式与校验规则 |
| 工具调用超时时间 | 60-90秒 | 对接多系统数据源需等待数据返回，避免超时中断高风险监管文书的生成流程 |
| 工具认证配置 | 配置`Authorization`请求头 | 对接带认证的SSE接口，符合特种设备监管系统的安全访问要求，该配置在FastGPT v4.17.0版本中支持自定义请求头 |
| Mermaid插件启用开关 | 开启 | 生成监管所需的流程图，如隐患整改流程、检验周期跟踪图，匹配文书可视化需求 |
| 工具调用重试次数 | 2次 | 应对临时网络波动，保障高风险监管文书生成的稳定性 |

## 容易做错的三处
- 现象：调用带header认证的SSE接口时报错，提示未授权，返回状态码401；原因：未在工具配置中添加`Authorization`请求头，未匹配监管系统的认证要求。
- 现象：Mermaid生成的流程图仅返回文本代码，无法获取图片链接；原因：未启用Mermaid MCP Server的图片生成插件，或未配置图片存储的访问路径。
- 现象：工具调用返回的维保记录条数不符，未拉取到当月更新的条目；原因：工具调用的数据源筛选条件未匹配月度更新频率，未设置按更新时间筛选的参数。

## 怎么确认配好了
- 发起测试调用，输入特种设备设备编号，检查工具是否能拉取对应使用登记证、检验报告的字段数据。
- 配置带`Authorization`头的SSE接口工具，发起测试请求，确认返回状态码为200且无未授权报错。
- 启用Mermaid插件，输入隐患整改流程的描述，检查是否生成可生成图片链接的代码块。
- 设置工具调用重试次数为2次，模拟临时网络中断，检查是否自动重试并完成调用。
