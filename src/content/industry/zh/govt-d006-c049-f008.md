# 规范性文件合法性审核的文书与材料起草：文档解析与分块

## 这个品类的数据长什么样
该品类服务的典型主体为司法行政部门、部门法规处及政府办公室政策法规岗，日常处理的文档包含规范性文件草案、起草说明、合法性审核意见、征求意见汇总、备案报告。数据来源为法规规章库、上位法数据库、部门政策文件库及行政规范性文件备案系统，更新频率不定期。文档多为正式公文格式，包含条款编号、法条引用、部门签章等固定字段，无自定义业务单位字段。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 规范性文件多包含法条与配套说明，该长度可保留单条审核逻辑的完整上下文，避免拆分关键条款 |
| `chunkSplitter` | 按章节+语义分割 | 文档具备固定章节结构，按章节拆分可保留审核事项的完整关联，适配合法性审核的逐条审查需求 |
| `customPdfParse` | 开启增强解析模式 | 部分上传文件为扫描格式的pdf，增强解析可提取文字内容，避免因识别不全导致审核遗漏 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 规范性文件可能包含多页附件与参考资料，该上限可覆盖常规审核文件的大小需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 大型合规文档解析耗时较长，该时长可避免超时中断解析流程 |
| `chunkSettingMode` | 手动配置模式 | 需针对不同来源的文档调整分块参数，适配法规库与本地上传文件的格式差异 |

## 容易做错的三处
- 现象：上传扫描版pdf文档后，解析结果文字识别不全或为空。原因：未开启`customPdfParse`增强解析模式，无法识别扫描格式的图像型文字内容。
- 现象：上传excel格式的审核辅助文件后，向量化索引结果与原表格内容不符。原因：未配置适配表格的分块规则，表格内容被错误拆分，导致审核时无法匹配完整数据条目。
- 现象：解析超过50页的规范性文件时触发超时报错。原因：`PARSE_FILE_TIMEOUT_SECONDS`取值过低，未预留足够的解析时长。

## 怎么确认配好了
- 上传测试用的扫描版pdf文档，查看解析结果是否包含完整文字内容，确认`customPdfParse`配置生效。
- 上传不同格式的测试文件，检查分块结果是否保留章节与法条的完整关联，确认`chunkSplitter`与`chunkSize`配置符合需求。
- 上传单份最大允许大小的测试文件，确认上传与解析流程未触发`UPLOAD_FILE_MAX_SIZE`或`PARSE_FILE_TIMEOUT_SECONDS`限制。
- 查看解析日志，确认分块后的内容无关键字段缺失，适配合法性审核的比对需求。
