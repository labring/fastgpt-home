# 部门决算与财务报告的文书与材料起草：模型接入与配置

## 这个品类的数据长什么样
本品类数据来自预算管理一体化系统、国库集中支付系统、会计核算系统与资产管理系统，按年度更新。日常产出的文书与材料包含部门决算报表、资产负债表、收入支出决算表、决算说明、政府财务报告，文档包含固定格式的报表字段、收支明细、资产负债数据与差异说明，字段多包含预算编码、收支科目、金额单位、填报单位标识等，需匹配官方统一格式要求。

## 这些特征在「模型接入与配置」这一环带来什么约束
年度更新的特性要求模型接入配置需适配批量年度数据的处理节奏，避免单次调用超时。多系统来源的数据需在配置中明确关联对应数据源的字段映射规则，确保账表核对环节的字段匹配准确性。固定格式的文档结构要求配置的上下文截取规则需适配报表的分页与字段顺序，避免遗漏关键差异说明内容。本品类聚焦实际收支与已发生的资产负债情况，配置需侧重历史数据的关联与差异说明的严谨性，区别于预算编制品类侧重未来推演的逻辑。多品类文档的混合处理需通过配置区分不同文档的处理逻辑，防止决算报表与说明的字段混淆。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配年度决算文档的总长度，覆盖多系统导出的完整报表与说明内容 |
| `maxTokens` | 4000 token | 限制单轮生成的文书输出长度，符合决算报告的官方排版规范 |
| `quoteMaxToken` | 1500 token | 限定引用知识库中关联数据的长度，确保账表核对的引用内容准确且不溢出上下文 |
| `toolChoice` | auto | 允许模型自主选择是否调用工具完成数据汇总与差异核对，适配复杂的决算场景 |
| `temperature` | 0.2–0.4 | 降低生成随机性，确保决算数据的字段与数值表述符合官方格式要求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写本地或云端接口地址 | 适配多系统数据源的访问路径，确保模型可正常拉取关联的预算与收支数据 |

## 容易做错的三处
- 现象：模型输出内容仅包含中文，且未遵循英文prompt的指令要求。原因：未在模型接入配置中指定目标语言关联规则，或配置的上下文优先加载了中文知识库内容。
- 现象：工作流调试时出现连接超时报错。原因：`maxContext`配置值过大，超出了模型接口的单次调用上限，或`AIPROXY_API_ENDPOINT`配置的地址无法正常访问数据源。
- 现象：生成的决算说明未包含预算执行差异的核对内容。原因：`quoteMaxToken`配置值过小，无法完整引用关联的国库支付数据，导致模型遗漏关键差异说明。

## 怎么确认配好了
- 调用测试接口，输入单份年度决算报表的摘要，检查生成的文书是否包含正确的收支科目与金额单位。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`的请求地址与数据源的访问路径一致，无连接异常。
- 调整`temperature`参数至0.3，多次调用同一测试prompt，检查生成内容的字段一致性是否符合预期。
- 验证`maxTokens`配置，确保生成的决算说明未被截断，符合官方文档的篇幅要求。
