# 部门预算编制的文书与材料起草：文档解析与分块

## 这个品类的数据长什么样
服务主体通常为财政局预算处、预算单位财务处等，日常处理的文档包括部门预算草案、项目申报书、绩效目标表、人员经费测算表、预算批复等。数据多来自预算管理一体化系统、部门人员编制系统、以前年度决算、项目库及财政部预算编制通知，按年度更新。文档多包含单位编码、项目金额、人员编制数、绩效目标等结构化字段与说明性文本，部分文档存在跨系统关联的嵌套数据结构。

## 这些特征在「文档解析与分块」这一环带来什么约束
年度更新的特性要求解析流程适配批量历史数据与当年新增文档的格式差异；多来源的嵌套数据结构需要精准识别跨系统关联字段，避免分块时割裂关联信息；结构化字段与说明文本混合的文档，需要区分核心预算数据与辅助说明内容，防止分块破坏预算项目的完整性；不同文档类型的格式差异，要求解析规则具备类型适配性，避免统一分块逻辑导致的字段丢失或冗余。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配预算文档中单个项目的描述长度，避免拆分核心预算项目信息 |
| `chunkSplitter` | 按段落+标题分级 | 匹配预算文档的标题层级与段落结构，保留项目申报、测算说明的逻辑完整性 |
| `customPdfParse` | 开启结构化解析模式 | 适配预算文档中多表格嵌套的常见格式，准确提取单元格内的预算数据与关联说明 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 兼容批量导入的往年决算、项目库文档的常见大小 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 适配大型预算草案文档的解析耗时，避免超时中断 |
| `chunkSettingMode` | 手动配置 | 允许针对不同类型的预算文档调整分块规则，适配差异化的文档结构 |

## 容易做错的三处
- 现象：部分PDF格式的预算文档无法完成解析，界面显示解析失败状态。原因：未开启`customPdfParse`的结构化解析模式，无法识别预算文档中嵌套的多表格结构。
- 现象：上传大型部门预算文件后触发超时报错，返回状态码504。原因：`PARSE_FILE_TIMEOUT_SECONDS`配置值低于文档实际解析耗时。
- 现象：工作流中调用文档解析工具后返回空字段或零散文本。原因：未匹配预算文档的分块规则，将完整的预算项目拆分为无关联的零散文本块。

## 怎么确认配好了
- 上传单份典型预算文档（如项目申报书），查看解析后的文本块是否保留完整的项目标题与金额信息。
- 检查`UPLOAD_FILE_MAX_SIZE`配置是否覆盖当前导入的最大文档体积，上传对应大小的测试文件验证无截断或上传失败。
- 查看`PARSE_FILE_TIMEOUT_SECONDS`的配置值，对比批量解析大型文档的实际耗时，确认无提前中断情况。
- 针对不同类型的预算文档，切换分块规则后验证解析结果的字段完整性。
