# 化工新材料的文书与材料起草：知识库检索与召回

## 这个品类的数据长什么样
化工新材料的核心数据来源于企业内部的工艺规程、新材料性能检测报告、行业通用标准文件、合规备案材料。数据更新节奏随新品研发进度或合规要求调整，无固定周期。文档多为长文本PDF或结构化表格，包含材料牌号、性能参数（如拉伸强度、热变形温度）、合成工艺步骤、安全技术说明书等字段，单位多为MPa、℃、kg/m³等工程单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
化工新材料的长文本工艺文档与结构化参数表格混合的文档结构，要求检索环节需同时支持文本语义召回与结构化字段匹配；工程参数类内容的单位一致性要求，需在召回时过滤单位不匹配的结果；无固定更新周期的数据源，需在检索前校验数据的最新版本标识；文书起草场景下对召回内容的合规性要求高，需限定召回范围为指定数据集内的有效内容，避免无关数据干扰起草结果。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 化工新材料参数类内容需较高匹配精度，避免低相关结果混入合规文书 |
| `limit` | 前8条 | 覆盖足够参考依据的同时，控制上下文长度适配文书起草的模型输入限制 |
| `searchMode` | hybrid | 适配混合的文本与结构化表格文档结构，同时支持语义与字段匹配 |
| `usingReRank` | 开启 | 二次排序召回结果，过滤语义匹配但参数单位不符的无效内容 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动补充化工专业术语，提升工程参数的检索匹配精度 |
| `collectionIds` | 绑定专属数据集ID | 限定检索范围为化工新材料专属文档，避免召回无关业务内容 |

## 容易做错的三处
- 现象：上传化工新材料的PDF或CSV文档时，出现`fail to create post presigned url`报错。原因：未正确配置对象存储的访问密钥与桶权限，导致无法生成预签名上传链接。
- 现象：检索时无法限定仅搜索化工新材料专属数据集，召回了其他品类的文档。原因：未正确配置`collectionIds`参数，或绑定了错误的数据集ID。
- 现象：本地部署FastGPT后，开启增强PDF解析功能，无法正确解析化工新材料工艺手册中的表格内容。原因：未正确配置minerU服务的访问地址，或未在后台开启minerU关联设置。

## 怎么确认配好了
- 查看数据集绑定配置，确认`collectionIds`已指向化工新材料专属数据集
- 发起一次检索测试，检查召回结果是否仅包含化工新材料相关文档
- 验证参数阈值配置，确认`similarity`取值符合预设的精度要求
- 测试结构化表格与长文本的召回效果，确认`searchMode`与`usingReRank`的配置生效
