# 化肥农药的文书与材料起草：引用来源与溯源

## 这个品类的数据长什么样
化肥农药领域的文书数据主要来自农业农村部农药登记公告、肥料登记管理平台备案文件、行业国标与行标文档，以及生产企业提交的合规材料。数据更新节奏为季度同步登记信息，年度更新标准规范。单份文档多为结构化表单或技术手册，包含登记证号、有效成分含量、适用作物范围、施用剂量、安全间隔期等字段，单位多采用g/L、kg/公顷、亩施用量等农业生产常用计量标准。

## 这些特征在「引用来源与溯源」这一环带来什么约束
结构化字段多但单位不统一的特征，要求溯源环节需匹配字段与对应计量标准，避免引用时混淆有效成分浓度、施用剂量的计量差异。季度更新的登记数据，要求溯源时自动校验引用文档的更新时间，确保使用最新有效版本。多来源的合规材料，要求溯源时关联登记证号作为唯一标识，避免不同企业同类产品的文档混淆。长文档形式的技术资料，要求溯源时精准定位引用片段的段落或页码位置，确保溯源信息可被快速核查。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，适配化肥农药领域的文书起草溯源需求。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 单次搜索上限 | 前3–5条 | 化肥农药专业文档内容集中，少量精准结果即可支撑文书起草，避免冗余信息干扰 |
| `quoteMaxToken` | 800–1200 token | 匹配单份技术文档的典型引用片段长度，避免Token溢出导致内容截断 |
| 最大上下文长度 | 2000–3000 token | 适配多来源合规材料的整合需求，确保引用信息完整纳入上下文 |
| `responseData` | 带来源标识的结构化格式 | 适配需展示登记证号、更新时间的溯源要求，确保引用信息可被直接提取核查 |
| `detail` | 开启完整溯源信息 | 包含文档来源、更新时间、字段对应关系，满足合规文书的溯源核查标准 |
| 更新时间校验 | 开启季度校验 | 匹配化肥农药登记数据季度更新的节奏，确保引用的是最新有效版本 |

## 容易做错的三处
- 现象：回答返回上下文过长报错，或生成内容被截断。原因：未针对化肥农药技术文档的典型长度调整`quoteMaxToken`参数，设置值超出模型上下文承载范围。
- 现象：引用的溯源信息仅包含文档标题，未显示登记证号、有效成分等专属字段。原因：未开启`detail`配置项，未启用完整溯源信息的展示逻辑。
- 现象：生成的文书引用了已过期的农药登记证数据。原因：未配置更新时间校验规则，未按季度更新节奏筛选最新的登记文档。

## 怎么确认配好了
- 上传1份典型的化肥农药登记文档，触发文书起草流程，检查生成内容中引用片段的Token长度是否符合预设范围。
- 查看生成回答的溯源面板，确认是否包含登记证号、更新时间等专属字段，验证`detail`配置是否生效。
- 模拟引用过期数据的场景，验证系统是否自动过滤超出更新周期的文档，确认更新时间校验规则正常运行。
- 调整单次搜索上限参数，检查生成回答的引用结果条数是否匹配设置值。
