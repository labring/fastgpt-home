# 危化品储运的文书与材料起草：工具调用与插件
本文档基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
危化品储运的业务数据主要来源于企业内部的储运作业系统、危化品台账管理模块以及属地应急管理部门的合规备案文档。数据更新以每班作业结束后同步为主，部分实时作业记录会在完成后10分钟内更新。单份文书相关数据文档包含危化品通用名、CAS登记号、存储罐位编号、当日收发量、存储温度、作业审批人、合规校验编号等字段，字段单位涵盖吨、立方米、摄氏度、小时等，部分字段为属地监管的合规必填项。

## 这些特征在「工具调用与插件」这一环带来什么约束
危化品储运的数据字段包含大量合规必填项，且部分字段需与外部监管系统实时校验，因此工具调用需严格匹配字段格式与单位，避免因格式错误导致生成的文书不合规。数据更新频率较高，插件需支持实时拉取最新作业记录，否则生成的文书会出现数据过时的问题。不同危化品的合规文书模板差异较大，插件需根据传入的危化品CAS号自动匹配对应模板，工具调用的参数需携带明确的字段映射规则，确保生成的文书符合属地监管要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | auto | 适配危化品储运文书起草的多场景需求，自动选择匹配的合规模板与数据源 |
| 插件请求超时时间 | 300 秒 | 危化品数据拉取需对接多系统，耗时较长，避免因超时中断请求 |
| 上下文窗口上限 | 8000–12000 token | 需整合多份储运作业记录与合规文档，足够的上下文确保文书内容完整 |
| 插件参数过滤规则 | 按危化品品名、存储罐位编号筛选 | 精准拉取对应作业的最新数据，避免无关信息干扰文书生成 |
| 流式响应开关 | 启用 | 适配部分模型的非流式调用限制，确保Agent节点正常处理返回结果 |
| 模板匹配阈值 | 前 5 条 | 优先匹配最贴合的危化品合规模板，确保文书格式正确 |

部分复杂场景下可手动指定`functionCall`来绑定特定的合规校验插件。

## 容易做错的三处
- 插件调用返回结果为空，且日志显示模型不支持非流式请求。原因是未正确配置`toolChoice`为auto，且未启用流式响应开关，导致Agent节点无法正确处理模型返回的内容。
- 生成的储运文书缺少CAS号或合规校验编号字段。原因是未在插件配置中绑定危化品台账的必填字段，工具调用时未携带对应的字段映射参数。
- 嵌入第三方Vue3项目后接口调用失败。原因是未在FastGPT的API白名单中添加项目的域名，且未正确携带API密钥进行身份验证。

## 怎么确认配好了
- 手动触发一次文书起草请求，检查生成的文书是否包含危化品品名、存储量、CAS号等必填字段。
- 查看FastGPT的插件调用日志，确认每次请求都能拉取到最新的危化品储运作业数据，且数据更新时间与实际作业时间一致。
- 测试不同的危化品品名，确认插件能自动匹配对应的合规文书模板，生成的文书格式符合属地监管要求。
- 在第三方项目中嵌入FastGPT的前端组件，检查页面能否正常发起API请求，且返回的文书内容与直接在FastGPT官网测试的结果一致。
