# 发电装备制造的文书与材料起草：模型接入与配置

## 这个品类的数据长什么样
发电装备制造的文书数据主要来自机组设计图纸配套技术说明书、生产工艺规程、出厂质检报告、招投标技术文件、运维检修台账。数据更新随新机型投产、年度合规检查或重大技改项目推进调整，单份文档常包含额定功率、转子重量、绝缘等级等结构化字段，单位多采用兆瓦、吨、千伏等工业标准单位，部分长文档附带图纸索引与参数对照表。

## 这些特征在「模型接入与配置」这一环带来什么约束
发电装备制造的文书存在长文本占比高、结构化参数多、更新节奏随项目波动的特征，会对模型接入配置带来约束。长文本需适配模型上下文窗口限制，避免截断核心机组参数；结构化字段需明确模型输出格式，确保额定功率、转子重量等参数提取准确；随项目更新的文档需配置可快速同步的数据源连接，避免模型调用时使用过期数据；工业标准单位的存在需确保模型输出与文档单位一致，减少转换误差。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配发电装备制造长文档的上下文需求，避免截断核心机组参数与长文本内容 |
| `temperature` | 0.1–0.3 | 降低随机输出，确保结构化参数提取的一致性，符合工业文档的严谨性要求 |
| `quoteMaxToken` | 1500 token | 限制引用文档的长度，优先匹配机组设计参数相关的核心片段 |
| `toolChoice` | auto | 自动触发工具调用，用于提取结构化参数或查询最新运维数据 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配企业内部的代理服务地址，保障数据传输安全 |
| `AIPROXY_API_TOKEN` | 从企业权限管理系统获取 | 遵循内部安全规范，避免凭证泄露 |

## 容易做错的三处
- 现象：生成的文书中附带完整的模型思考过程，未按要求仅输出最终文档内容。原因：未配置针对性prompt约束，且未限制`maxTokens`参数，导致模型输出非预期的中间步骤。
- 现象：模型调用返回连接失败或权限错误。原因：未正确填写代理服务相关配置，或代理服务未开放对应调用权限。
- 现象：提取的机组额定功率、转子重量等参数与文档实际值不符。原因：未启用`toolChoice`自动工具调用，或未明确模型输出的结构化格式，导致参数提取偏差。

## 怎么确认配好了
- 提交一份典型的发电装备制造长文档，核对模型调用时的上下文占用提示，确认未触发强制截断。
- 输入包含结构化参数的查询，核对模型输出的参数格式与文档字段一致，确认工具调用配置生效。
- 调用配置的代理服务接口，确认鉴权与数据传输流程正常完成。
- 模拟多并发调用场景，核对不同调用节点的分配情况，确认负载分配逻辑符合预期。
