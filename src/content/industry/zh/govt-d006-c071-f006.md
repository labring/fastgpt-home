# 发电集团的文书与材料起草：引用来源与溯源

本配置方案适配FastGPT v4.17.0版本。

## 这个品类的数据长什么样
发电集团的文书与材料起草相关数据，主要来源于集团内部的发电运行日报、机组检修规程、安全操作规范、国家能源局发布的电力行业政策文件。数据更新节奏分为两类：运维类数据每日同步更新，政策类文件按发文周期不定期更新。文档结构多为带章节号、文件编号的正式公文，字段包含适用机组编号、发布日期、技术参数指标，单位涉及兆瓦、吨标准煤/千瓦时等电力行业专用单位。

## 这些特征在「引用来源与溯源」这一环带来什么约束
发电集团文书的专用字段与分类逻辑，要求溯源时需精准匹配到对应机组、发布时间的具体段落，避免泛泛引用整份文档。高频更新的运维数据，要求溯源功能需支持实时或每日同步的知识库更新，避免引用过时内容。正式公文的章节结构，要求溯源功能可定位到具体段落，提升引用的准确性。多字段分类的文档，要求配置时需支持按字段筛选召回条目，减少无关内容干扰。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | 适配发电集团正式文书的单段引用长度，避免上下文溢出 |
| `responseData` | 包含文件编号、段落索引的结构化格式 | 精准匹配发电文书的字段特征，便于溯源 |
| `detail` | 开启 | 覆盖发电运维文档的技术细节段落，满足溯源精度要求 |
| 单次召回上限 | 前3–5 条 | 避免过多无关的发电规程条目干扰引用准确性 |
| 知识库同步周期 | 每日1 次 | 适配发电运维数据的日常更新节奏，保证引用数据时效性 |
| 源文件筛选条件 | 按机组编号、发布日期过滤 | 匹配发电集团文书的分类字段，缩小召回范围 |

## 容易做错的三处
- 现象：导入知识库后可选列表为空，原因：未配置知识库与当前应用的关联权限，或同步周期未触发导致知识库未加载。
- 现象：调用时提示引用上限不足，原因：`quoteMaxToken`设置过小，或单次召回上限过高超出上下文窗口。
- 现象：引用的源文件无法下载，原因：`responseData`未配置包含文件访问路径，或文件存储路径权限不足。

## 怎么确认配好了
- 查看应用关联的知识库列表，确认目标发电相关知识库已添加且同步状态为已完成。
- 发起测试提问，查看返回结果中是否包含文件编号、段落索引等结构化溯源信息。
- 点击返回结果中的源文件链接，确认可以正常访问对应文档的指定段落。
- 调整`quoteMaxToken`参数后，验证引用内容的长度符合预期设置。
