# 国有产业基金的文书与材料起草：模型接入与配置
本文适用于FastGPT v4.17.0版本的国有产业基金文书起草场景的模型接入与配置。

## 这个品类的数据长什么样
国有产业基金的文书与材料主要来源于内部项目库的基金设立方案、出资协议、备案登记文件、年度运营报告。更新节奏随项目立项、条款修订触发，无固定周期。文档结构多包含固定表头与结构化字段，字段包括基金认缴总规模（单位亿元）、存续期限（单位年）、出资方资质要求、返投比例等，单份文档长度通常在10至50页区间。

## 这些特征在「模型接入与配置」这一环带来什么约束
结构化字段与固定文档结构要求模型输出需严格匹配预设字段格式，避免出现单位错误或字段缺失。长文档与多页内容要求上下文窗口需适配完整内容加载，防止关键信息截断。高频更新的内部文档要求知识库同步频率与项目进度对齐，确保模型调用的数据源时效性。专业术语的唯一性要求模型需绑定行业专属prompt，避免通用术语混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 12000–15000 token | 国有产业基金文书包含多页协议与尽调内容，需容纳完整上下文以避免关键条款截断 |
| `maxTokens` | 3000–4000 token | 单份起草文书需覆盖完整条款内容，控制输出长度符合基金文档的规范格式 |
| `quoteMaxToken` | 2000–2500 token | 需引用内部备案文件与监管要求片段，限制引用内容长度以保证输出聚焦 |
| `toolChoice` | auto | 根据起草需求自动选择是否调用知识库检索内部合规文档 |
| `temperature` | 0.3–0.5 | 基金文书需严谨规范，降低输出随机性以确保条款表述准确 |
| `AIPROXY_API_ENDPOINT` | 按本地部署的大模型接入地址填写 | 适配私有部署的大模型链路，保障数据不出境合规要求 |

## 容易做错的三处
- 现象：模型测试时弹出「这个是图像模型，为什么不支持打开图像选项」的提示，原因：误将`vision`参数配置为`true`，或接入了不具备视觉能力的通用大模型，导致界面出现无关的图像选项。
- 现象：重启docker容器与大模型服务后，模型测试提示连接超时，原因：未按启动顺序先启动大模型服务再启动FastGPT容器，导致服务链路未正常建立。
- 现象：生成的文书中出现过期的基金备案条款，原因：未配置`quoteMaxToken`限制引用范围，导致模型调用了未更新的旧知识库内容。

## 怎么确认配好了
- 执行FastGPT的模型测试功能，输入「起草一份产业基金的设立方案初稿」的标准prompt，核对输出是否包含预设的结构化字段。
- 查看FastGPT的模型调用日志，确认请求参数中`maxContext`、`maxTokens`的取值与配置一致。
- 重启docker容器与大模型服务后，再次发起测试，验证连接状态显示正常无报错。
- 导入一份内部基金备案文档片段作为测试素材，确认模型能正确引用其中的条款内容。
