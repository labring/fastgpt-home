# 国有资产管理公司的文书与材料起草：模型接入与配置

## 这个品类的数据长什么样
国有资产管理公司的文书数据主要来源于国资监管部门发布的规范性文件、公司内部的资产处置方案、产权登记材料、年度运营报告及风控合规文档。数据更新节奏为监管文件按月、按季度更新，内部文档随项目推进实时生成。文档结构多包含固定抬头（含国资专属编号、资产标的信息）、分章节正文、合规签章落款，字段多涉及资产原值、评估值、持股比例、划转批复文号等，单位以万元、平方米、百分比为主。

## 这些特征在「模型接入与配置」这一环带来什么约束
国资文书的固定格式与专属字段要求模型生成内容严格匹配官方模板，需精准提取与填充结构化信息。长文档如年度运营报告篇幅可达数万字符，对模型的上下文窗口容量提出较高要求。内部文档随项目实时生成，需配置数据源的实时同步触发机制以保证知识库时效性。合规类文书需严格遵循国资监管表述，对模型输出的合规性校验存在额外约束，同时需避免跨境数据传输风险。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配国资文书动辄数千字符的长文档上下文需求，避免截断核心资产数据 |
| `maxTokens` | 2000–3000 token | 满足单份文书起草的输出长度要求，覆盖完整的方案或报告内容 |
| `temperature` | 0.1–0.3 | 降低生成随机性，确保国资文书的格式与表述符合官方合规要求 |
| `toolChoice` | auto | 允许模型自动选择是否调用检索工具，补充最新国资监管政策数据 |
| `AIPROXY_API_ENDPOINT` | 国内合规大模型服务地址 | 适配国资数据的境内存储与合规要求，避免跨境数据传输风险 |
| `AIPROXY_API_TOKEN` | 按服务方提供的专属密钥配置 | 确保接口调用的身份合法性，符合国资系统的安全管控要求 |

## 容易做错的三处
- 现象：生成的资产处置方案中，资产原值字段出现数值偏差或格式错误。原因：未针对国资文书的结构化字段配置专属提示词，或`temperature`取值过高导致生成随机性增强。
- 现象：处理长文档时出现模型响应超时。原因：未调整`maxTokens`适配长文档生成需求，或接口调用的超时阈值未匹配大模型响应时长。
- 现象：升级FastGPT版本后，预设的模型配置失效，聊天时调用的模型与预设不符。原因：升级过程中未保留`AIPROXY_API_TOKEN`与`AIPROXY_API_ENDPOINT`的配置信息，系统加载默认模型参数。

## 怎么确认配好了
- 上传一份标准国资产权登记文档，检查生成的文书是否包含正确的资产编号、评估值等结构化字段。
- 查看模型接口调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置已被正确读取，无认证报错。
- 生成一份长文档草稿，检查输出长度符合`maxTokens`的设置，未出现强制截断。
- 调整`temperature`参数后，对比两次生成的文书内容，确认生成随机性符合预期。
