# 国有资本投资公司的文书与材料起草：工具调用与插件

本页面适配FastGPT v4.17.0版本。

## 这个品类的数据长什么样
国有资本投资公司的文书与材料数据主要来源于内部投资项目可研报告、三会决议文件、国资监管报表、年度工作报告及公司章程。更新节奏随业务节点推进，项目类文档随立项、审批、落地阶段动态更新，年度类文档按自然年度固定更新。文档多采用国资系统统一模板，包含项目编号、出资主体、审批文号、涉密等级、投资额等标准化字段，单位多为万元、亿元、人次等。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散且涉及内部业务系统与国资监管平台，要求工具调用需支持多源数据拉取的适配配置，避免跨平台数据同步异常。文档字段标准化但覆盖范围广，`toolChoice`需精准匹配指定字段，避免提取无关内容干扰文书生成。涉密文档占比高，需在插件中嵌入权限校验逻辑，仅允许授权角色调用涉密数据。不同类型文档更新节奏差异大，需为不同数据源配置差异化的调用频次阈值，防止过度拉取或数据滞后。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 自动匹配文书类型选择对应工具，无需手动切换调用逻辑 |
| `functionCall` | 按指定字段触发 | 精准提取国资文档的项目编号、投资额等标准化字段，避免无效内容 |
| 知识库内容访问权限 | 按角色分级配置，涉密文档仅开放给核心管理岗 | 符合国有资本投资公司的国资监管保密要求，防止敏感信息泄露 |
| 日志收集与管理 | 留存调用时长、返回字段、错误码的完整日志，留存周期不低于180天 | 满足国资审计的追溯要求，可复现工具调用全流程 |
| 单次工具调用上限 | 前8-12条匹配数据，单条不超过500 KB | 平衡数据充足性与生成效率，避免冗余信息干扰文书起草 |
| 工具调用超时阈值 | 600秒 | 适配国资文档较长的字段提取与数据拉取时长，防止中途中断 |

## 容易做错的三处
- 调用工具时返回`invalid api key`错误，原因：未正确获取应用的appId作为调用密钥，误将其他标识填入配置项。
- 工具调用后返回的字段为空，原因：未匹配到国有资本投资公司文档的标准化字段，插件未适配国资系统的统一模板结构。
- 多工具顺序执行时出现执行中断，原因：未配置超时阈值，长文档的字段提取操作超出默认时长导致失败。

## 怎么确认配好了
- 发起一次针对国资项目文档的工具调用，核对返回字段是否包含预设的项目编号、投资额等内容。
- 查看日志收集模块，确认已生成包含调用时长、错误码的完整记录，且留存周期符合要求。
- 以非授权角色尝试调用涉密文档，确认无法获取对应敏感内容。
- 测试多工具顺序执行流程，确认无中断或超时报错。
