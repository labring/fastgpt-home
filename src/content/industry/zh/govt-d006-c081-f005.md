# 基础化工的文书与材料起草：工具调用与插件

## 这个品类的数据长什么样
基础化工的文书数据主要来源于企业内部工艺规程、原料质检报告、安全技术说明书及行业合规文件。数据按原料批次、生产周期更新，合规类文件随监管政策调整。文档包含结构化参数表与非结构化说明文本，字段涵盖物料编码、工艺温度、压力、批次号等，单位多采用吨、立方米、摄氏度、兆帕等行业标准单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
基础化工的结构化参数表与非结构化合规文本混合的特征，要求工具调用插件同时支持结构化数据读取与长文本解析。按批次、生产周期更新的数据，要求插件支持动态拉取最新批次信息，避免使用过期数据。固定字段的合规文件，要求工具调用参数匹配物料编码、工艺参数等固定字段。长文本工艺说明超出上下文限制时，需通过工具调用拆分分段处理，同时需兼容行业特有单位的转换校验。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` 或 指定合规校验、数据拉取工具名 | 基础化工文书起草需匹配合规校验与数据拉取两类工具，auto模式自动适配场景，指定工具名可限定调用范围 |
| `functionCall` | 开启 | 基础化工文书需生成参数化内容，开启后可通过函数调用插入结构化物料、工艺参数 |
| 数据库插件数据源配置 | 配置为企业内部原料库、工艺库，指定字符编码为utf8mb4 | 基础化工数据含中文物料名称与参数，utf8mb4可避免中文乱码问题 |
| 工具调用超时设置 | 300–600 秒 | 基础化工批量数据拉取需较长耗时，超时设置需覆盖多批次数据查询流程 |
| 单次工具调用返回条数 | 前 5–10 条 | 基础化工文书无需过多冗余数据，限定条数可提升查询效率 |
| 最大上下文长度 | 8000–12000 token | 基础化工长文本工艺规程需完整加载，适配长上下文解析需求 |
| 基础图表插件轴配置 | 配置X轴为物料编码、Y轴为工艺参数，单位匹配行业标准 | 基础化工文书常需配套参数图表，固定轴字段与单位可确保文书合规性 |

## 容易做错的三处
- 现象：工具调用同时输出AI回复与执行分支日志，且未按预期仅执行单一路径。原因：未正确配置`toolChoice`参数，默认auto模式同时触发多分支执行。
- 现象：数据库插件连接后返回中文字段为空或乱码。原因：未将数据库字符编码配置为utf8mb4，基础化工物料名称含中文生僻字，通用编码无法完整解析。
- 现象：基础图表插件生成的图表单位与文书要求不符。原因：未按行业标准配置图表轴单位，直接使用默认单位导致合规性问题。

## 怎么确认配好了
- 调用工具调用测试接口，查看`toolChoice`参数是否按配置生效，工具调用范围符合预期。
- 执行数据库插件查询，验证中文物料名称、参数可正常显示无乱码。
- 生成基础化工文书草稿，检查图表轴字段与单位是否匹配行业标准。
- 测试长文本工艺规程解析，确认上下文加载无截断或报错。
