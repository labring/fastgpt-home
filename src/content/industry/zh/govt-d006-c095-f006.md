# 新能源开发的文书与材料起草：引用来源与溯源

## 这个品类的数据长什么样
新能源开发的文书与材料数据主要来自项目立项审批、环境影响评价、并网验收、土地预审等官方批复文件及项目内部执行文档。数据更新节奏随项目阶段推进，可研报告、并网方案等核心文档在对应审批节点完成更新。文档多为章节式结构化内容，包含项目编号、用地面积、装机容量、审批文号等固定字段，单位多采用公顷、兆瓦、千瓦时等行业标准计量表述。

## 这些特征在「引用来源与溯源」这一环带来什么约束
新能源开发的文书数据特征对引用溯源环节带来多重约束。首先，核心数据来自官方批复文件，溯源需精准匹配具体审批文号与发布主体，无法仅依赖模糊的来源标注。其次，文档随项目阶段阶段性更新，溯源时需校验引用内容的版本时效性，避免使用过期的可研或验收材料。再者，文档包含固定专业字段与计量单位，溯源需明确标注字段对应的章节位置，确保引用内容的可追溯性。最后，部分文书包含技术计算依据，溯源需同时关联数据来源与推导过程，保障引用的合规性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 相似度阈值 | 0.75–0.85 | 新能源开发文书专业术语密集，该区间可过滤低相关的非专业内容，平衡召回精度与覆盖范围 |
| 单次搜索上限 | 前8条 | 新能源项目文书的核心参考信息多集中在前几个召回结果，8条可覆盖主要内容且避免冗余 |
| 重排 | 开启 | 专业文档的语义相似度易受术语干扰，重排可修正检索结果的排序，提升核心片段的匹配度 |
| `quoteMaxToken` | 1200–1500 token | 新能源文书单段有效内容较长，该区间可保障引用片段包含完整的专业表述与计算依据 |
| `detail` | 开启 | 需完整展示引用内容的章节与字段信息，便于后续溯源核查 |
| `responseData` | 仅返回引用片段与来源 | 聚焦文书起草所需的精准内容，避免返回无关信息干扰起草过程 |

## 容易做错的三处
- 开启重排后出现引用片段为空的现象，原因是重排过滤了相似度阈值内的所有结果，导致无符合要求的检索片段返回。
- 配置`quoteMaxToken`过小，导致引用片段被截断，无法完整展示新能源文书中的专业计算依据与字段信息。
- 未校验文档版本导致引用过期的可研报告内容，现象为溯源标注的审批文号与当前项目阶段的最新批复不符。

## 怎么确认配好了
- 上传一份新能源项目的环评报告，发起起草相关文书的请求，查看返回结果中是否标注了具体的审批文号与章节位置。
- 调整重排开关，对比两次检索结果的排序变化，确认重排功能正常生效。
- 查看引用片段的长度，确认是否符合`quoteMaxToken`设置的区间，未出现截断情况。
- 测试不同相似度阈值的取值，观察召回结果的数量变化，确认阈值配置符合预期。
