# 新能源开发的文书与材料起草：模型接入与配置

## 这个品类的数据长什么样
新能源开发的文书与材料主要来源于项目全流程的审批文件、技术方案、现场勘测记录，更新节奏随项目推进阶段调整，立项阶段更新立项申请材料，环评阶段更新环评报告，并网阶段更新并网验收文件。文档结构多包含固定章节：项目概况、技术参数、审批流程、附件清单，字段包含装机容量（单位MW）、并网电压（单位kV）、占地面积（单位公顷）、审批文号、项目编号等，部分文档附带jpg格式的项目图纸或扫描审批文件。

## 这些特征在「模型接入与配置」这一环带来什么约束
新能源开发文书的固定字段与专业术语，要求模型输出需精准匹配预设格式与领域知识，避免生成不符合审批规范的内容；文档附带的jpg格式附件，要求模型具备视觉输入能力以解析图片中的参数与信息；单份文书常包含多页内容，需控制上下文长度以避免超出模型阈值；不同项目阶段的文书更新频率不同，需保证接口调用的稳定性以适配实时数据需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 新能源开发单份文书常超5000字符，需保留足够上下文匹配项目历史数据与审批要求 |
| `maxTokens` | 2000–3000 token | 文书起草需生成完整段落或结构化表格，避免输出内容被截断 |
| `vision` | 开启 | 新能源文书常附项目图纸、扫描版审批文件，需支持图片内容解析与信息提取 |
| `temperature` | 0.3–0.5 | 文书需符合官方规范格式，降低生成随机性，保证输出内容的一致性 |
| `AIPROXY_API_ENDPOINT` | 按服务商提供的专属地址填写 | 适配不同大模型的接口调用路径，保障请求正确转发 |
| `AIPROXY_API_TOKEN` | 填写平台分配的专属密钥 | 完成接口身份验证，确保调用权限合法有效 |

## 容易做错的三处
- 现象：上传的jpg项目图纸无法被AI模块解析，界面显示“无法读取附件内容”。原因：未开启`vision`配置项，模型未获得视觉输入能力，无法处理图片格式的文书附件。
- 现象：使用Qwen2-72B-Instruct-Int8时，函数调用输出不符合预期，生成大量无关内容。原因：`temperature`取值过高，且未设置`toolChoice`为强制函数调用模式，模型未遵循预设的调用规则。
- 现象：商业版接入第三方大模型时返回401权限错误。原因：未正确填写`AIPROXY_API_TOKEN`，或使用了与`AIPROXY_API_ENDPOINT`不匹配的密钥，导致身份验证失败。

## 怎么确认配好了
- 上传一张新能源项目的jpg图纸，触发AI模块发起内容提取请求，检查是否能准确提取图纸中的装机容量、并网电压等参数信息。
- 配置`toolChoice`为强制模式后，发起包含结构化函数调用要求的文书起草请求，检查模型是否按要求生成符合格式的输出内容。
- 查看FastGPT v4.17.0的接口调用日志，确认`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`的请求参数已正确携带，无401、404类报错。
- 调整`temperature`至0.3–0.5区间，多次发起相同的文书起草请求，检查输出内容的一致性是否符合预期。
