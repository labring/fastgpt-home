# 炼化生产的文书与材料起草：HTTP 接口与外部系统

## 这个品类的数据长什么样
炼化生产的文书与材料起草相关数据，主要来自分布式控制系统（DCS）、设备管理系统（EAM）、现场巡检终端与生产调度台账。数据更新节奏覆盖实时（如工艺参数波动记录）、每班（如巡检日志）、每日（如物料平衡报表）三类。文档以结构化字段为主，包含装置编号、巡检时段、介质温度（℃）、压力（MPa）、物料流量（m³/h）、操作人员工号等标准化字段，同时附带非结构化的异常情况备注。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
数据的多更新节奏要求HTTP接口支持两种调用模式：单次触发拉取历史批量数据，以及定时触发同步实时增量数据。结构化字段的标准化属性要求接口参数需严格匹配预设字段名与工业单位，避免格式解析失败。生产相关数据的安全合规属性，要求接口配置加密传输与权限校验机制。多系统数据源的关联需求，要求接口支持传入多系统标识作为过滤条件，实现跨系统数据的联合调用。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 认证配置 | 配置`Authorization`参数为Bearer Token格式 | 匹配FastGPT v4.17.0的安全配置规范，满足炼化生产数据的安全校验要求 |
| 请求参数 | 传入`variables`参数包含装置编号、巡检时段等字段 | 精准匹配结构化数据的过滤需求，缩小数据返回范围 |
| 响应解析 | 按`responseData`指定字段提取内容 | 减少无效数据传输，提升文书生成的效率 |
| 轮询周期 | 600秒 | 适配实时工艺数据的更新节奏，避免频繁调用占用系统资源 |
| 超时阈值 | 30秒 | 避免长时间等待阻塞生产流程，适配工业系统的响应要求 |
| 分页上限 | 前100条 | 适配单批次数据量的合理范围，避免接口返回数据过大 |

## 容易做错的三处
- 调用接口时返回401未授权错误，原因是未正确配置`Authorization`参数，或令牌未按要求更新。
- 传入`variables`参数后接口返回字段为空，原因是参数名与目标系统的字段命名不匹配，未使用炼化生产标准化的字段名称。
- 本地部署后生成的访问链接仍指向localhost，原因是未在系统配置中正确配置外部访问域名，仅启用了本地HTTP服务。

## 怎么确认配好了
- 调用测试接口，查看返回的`responseData`是否包含预设的炼化生产字段，如装置编号、介质温度等。
- 手动传入测试用的`variables`参数，验证接口是否能过滤出对应装置的历史数据。
- 检查系统日志，确认接口请求的超时时间符合配置的阈值，未出现频繁超时报错。
- 查看外部系统的接入日志，确认请求的认证信息与IP地址符合配置要求，无拦截记录。
