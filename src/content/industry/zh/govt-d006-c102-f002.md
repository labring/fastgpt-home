# 炼化生产的文书与材料起草：向量模型与索引

## 这个品类的数据长什么样
炼化生产的文书数据主要来自装置操作规程、检修记录、质量检验报告、生产日报、物料平衡表及安全合规文件。数据更新节奏分为两类：日常生产日报为每日更新，检修记录随事件触发更新，合规类文件按季度或年度批量更新。文档结构包含长文本工艺描述与结构化表格，结构化字段包含装置ID、生产班次、检测数值等，配套单位涵盖吨、立方米、摄氏度、帕斯卡等专业工业单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
长文本工艺描述占比高，切分时需避免破坏单工序的完整逻辑，否则向量检索会丢失关键工艺关联；结构化字段与专业单位的特殊性，要求索引需同时支持语义向量匹配与字段精准匹配，防止出现设备编号与工艺描述的误匹配；更新频率的差异化，需要索引支持增量更新以适配每日新增的生产数据，同时保留全量更新能力用于合规文件的批量导入。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| 分块长度 | 800–1200 字符 | 炼化生产文书多包含连续工艺步骤描述，该长度可保留单工序的完整逻辑，避免切分破坏工艺关联 |
| 重叠长度 | 50–100 字符 | 弥补长文本切分后的上下文断层，确保工艺步骤的前后衔接被向量索引覆盖 |
| 相似度阈值 | 0.72–0.85 | 炼化场景工艺术语专业性强，该区间可过滤低相关结果，避免误匹配非目标设备的规程 |
| 单次搜索上限 | 前6条 | 匹配炼化生产文书的信息量需求，避免过多冗余结果干扰起草逻辑 |
| `maxToken` | 4000 | 适配长文书的上下文召回，确保起草时可调用完整的工艺参数与合规要求 |
| `defaultToken` | 1500 | 适配炼化专业术语的向量编码长度，确保术语匹配的准确性 |
| 去重开关 | 按场景关闭 | 针对包含重复结构化块的检修记录，关闭自动去重可保留自定义切分的索引顺序 |

## 容易做错的三处
- 现象：自定义切分的文档存入知识库后，重复块被自动移除，导致索引顺序与预先规划的切分序列不符。原因：默认索引配置开启了自动去重开关，未针对炼化生产中包含重复结构化块的检修记录调整去重规则。
- 现象：切换向量模型后，搜索返回的相似度数值超出0-1区间，无法通过界面上的过滤设置筛选有效结果。原因：未开启向量模型的相似度归一化配置，导致输出原始未校准的分值。
- 现象：批量导入炼化生产的长文档时，系统提示索引构建超时，无法完成导入。原因：未配置增量索引规则，每次更新都执行全量索引重建，未针对每日更新的生产日报做增量处理。

## 怎么确认配好了
- 上传单份炼化生产操作规程，检查切分后的块数与自定义切分规则一致，确认无异常合并或拆分。
- 发起针对特定设备编号的检索，检查召回结果包含对应设备的工艺文档，确认字段匹配与向量检索的协同生效。
- 查看FastGPT v4.17.0的索引构建日志，确认增量更新仅处理新增的生产日报文档，无全量重建的记录。
- 测试相似度过滤功能，调整阈值后观察返回结果的数量变化，确认配置参数正常生效。
