# 炼化生产的文书与材料起草：多轮对话与提示词

## 这个品类的数据长什么样
炼化生产的文书与材料主要来源于工艺规程、设备台账、安全操作规程、检修记录、物料平衡表等内部业务文档。文档更新节奏随类型差异明显：工艺规程每半年至一年更新一次，设备台账按月度更新，检修记录随现场作业实时生成。文档结构包含固定字段与动态参数，固定字段如设备编号、工序号，动态参数如操作压力、温度、进料量，单位涵盖MPa、℃、t/h、m³等工业标准单位，部分文档包含工艺流程图、参数表等结构化内容。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
炼化生产的文书数据包含大量带单位的精准参数、结构化表格与图片类文档，多轮对话需跟踪用户对特定设备或工序的连续提问，因此需要稳定的上下文隔离机制。参数类字段的单位要求提示词必须明确指定校验规则，避免返回无单位或错误单位的结果。图片类文档无法通过纯文本检索直接返回完整内容，需额外配置图片解析适配逻辑。同时，不同文档的更新频率差异要求对话能实时获取最新的检修记录与台账数据，避免使用过期信息生成合规性文书。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chatId` | 唯一会话标识，按业务场景生成 | 隔离不同用户或场景的对话上下文，避免请求排队与上下文混淆，适配FastGPT v4.17.0的会话管理规则 |
| `messages` | 保留前10轮对话，单轮内容不超过800字符 | 平衡上下文完整性与响应速度，适配炼化文书的长文本内容特征 |
| `variables` | 预设设备编号、工艺工序等业务变量，按实测标定 | 快速定位对应品类的专属文档，减少无效检索范围 |
| 相似度阈值 | 0.75–0.85 | 炼化文档的参数精准度要求高，避免低匹配度的无关条目干扰结果 |
| 单次搜索上限 | 前6条 | 炼化相关文档的有效匹配条目集中，过多条目会增加上下文处理负担 |
| 最大上下文 | 4000 token | 适配多轮对话的上下文存储需求，避免超出模型上下文窗口限制 |

## 容易做错的三处
- 现象：使用严格问答模板发起查询时，若知识库中存在图片地址条目，界面返回“未找到答案”。原因：严格问答模板仅匹配文本型知识库条目，无法解析图片地址对应的结构化内容。
- 现象：短时间内连续发送对话请求，后续请求无法即时响应。原因：未通过`chatId`隔离不同会话上下文，导致请求排队等待上下文资源释放。
- 现象：调用API时返回“没有权限操作此对话记录”。原因：未正确关联会话所属的合法权限范围，或`chatId`参数未绑定有效会话标识。

## 怎么确认配好了
- 发起单轮对话请求，输入炼化工艺参数相关问题，核对返回结果是否匹配预设的知识库条目。
- 连续发送3条针对不同炼化设备的提问，核对`chatId`是否能正确保留每轮对话的上下文信息，实现连续提问的逻辑关联。
- 上传一张炼化工艺流程图图片至知识库，使用非严格问答模板发起查询，核对是否能正确返回图片地址或相关解析内容。
- 调用API时携带合法的会话权限参数，核对是否不会返回权限错误提示。
