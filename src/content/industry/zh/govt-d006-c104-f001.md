# 煤化工的文书与材料起草：HTTP 接口与外部系统

## 这个品类的数据长什么样
煤化工文书与材料起草的数据主要来自企业DCS控制系统、MES生产管理系统、安全巡检平台。核心数据包括工艺炉温、进料速率、设备运行时长、安全合规记录等。数据更新节奏分两类：实时工艺参数每15秒同步一次，台账类文档每日凌晨完成批量同步更新。文档结构按生产单元划分，每个文档包含设备编号、工艺阈值、操作步骤、合规校验项，字段统一标注物理单位，如温度单位为℃、流量单位为立方米/小时。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
实时工艺参数的高频同步要求接口单次请求耗时控制在合理范围，避免数据延迟影响文书生成。批量台账类文档数据量较大，需支持分页获取参数，防止单次传输过载导致接口报错。煤化工文书字段多带物理单位，接口需校验传入参数的单位格式，确保与系统预设单位匹配。部分工艺文档涉及生产机密，接口需通过身份校验拦截未授权的外部调用。同时，煤化工设备编号规则统一，接口需支持按设备编号精准检索数据，提升文书起草效率。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 接口超时时间 | 10–15 秒 | 匹配煤化工实时工艺参数的更新频率，避免数据延迟 |
| 身份校验配置 | 携带`Authorization`参数 | 符合煤化工生产数据的安全管控要求，拦截未授权调用 |
| 变量映射规则 | 绑定设备编号、工艺阈值变量 | 精准匹配煤化工文书的字段要求，减少人工修正 |
| 响应数据处理 | 提取`responseData`中的核心字段 | 过滤冗余数据，加快文书生成速度 |
| 分页参数设置 | 单次获取 20–30 条数据 | 适配煤化工批量台账数据的传输规模，避免接口过载 |
| 上下文注入 | 注入`variables`中的工艺参数 | 为文书起草提供实时生产依据 |

## 容易做错的三处
- 接口返回401未授权状态码，无法拉取生产数据。原因：未正确配置身份校验参数，未携带有效`Authorization`信息。
- 生成的文书中工艺参数单位错误，如炉温标注为“立方米/小时”。原因：未校验外部系统返回数据的单位格式，直接使用原始值填充文书字段。
- 单次调用接口超时，导致文书生成中断。原因：未设置适配煤化工实时数据的超时时间，请求耗时超过预设阈值。

## 怎么确认配好了
- 调用测试接口，检查返回头中是否包含正确的身份校验结果，确认`Authorization`配置生效。
- 手动传入带标准单位的工艺参数，核对生成文书中的字段单位是否与预设一致。
- 发起批量数据请求，检查返回的`responseData`字段是否包含预期数量的有效数据。
- 查看接口日志，确认`variables`中的工艺参数已正确注入到文书模板中。
