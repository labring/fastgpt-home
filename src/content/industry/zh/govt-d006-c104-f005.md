# 煤化工的文书与材料起草：工具调用与插件

## 这个品类的数据长什么样
煤化工的数据源主要包括装置DCS系统日志、月度生产报表、环保合规备案文件、项目可研报告与物料台账。更新节奏分为三类：实时更新的工艺参数、每日更新的生产台账、季度更新的合规备案文件。文档结构包含结构化的工艺参数表（字段含反应釜温度、进料速率，单位为℃、m³/h）、安全检查清单、合同文本、材料申请单，部分文档包含固定格式的审批流程字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
煤化工的生产数据包含实时工艺参数、固定格式的合规文档与多类型业务台账，这对工具调用与插件带来多重约束。实时工艺数据的短更新周期要求工具支持高频次数据拉取，避免因超时或延迟导致文书生成的参数偏差。专业单位如MPa、t/h、℃的广泛使用，要求插件内置煤化工行业的单位映射规则，避免参数匹配错误。多类型文档的混合输入，要求工具支持对结构化台账、半结构化合规文件与非结构化报告的统一解析，适配不同字段提取逻辑。固定格式的合规备案文件，要求插件预设对应字段的提取模板，减少人工配置成本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工具调用模式 | `functionCall` | 需要精准调用煤化工专用插件，避免通用调用导致的参数混乱 |
| 超时时间 | 300-600 秒 | 煤化工数据拉取涉及多源台账与实时工艺数据，需预留足够的网络与解析时间 |
| 插件数据源范围 | 仅允许DCS日志、生产报表、合规文件 | 过滤无关数据源，避免非煤化工数据干扰文书生成 |
| 结果返回上限 | 前10条 | 煤化工文书通常仅需最新的核心生产与合规数据，过多结果会增加上下文负荷 |
| 单位转换开关 | 开启 | 煤化工文档包含大量专业单位，开启后可自动统一单位格式，提升字段匹配准确率 |
| 文档解析优先级 | 结构化文档优先 | 煤化工的生产台账与合规文件多为结构化格式，优先解析可提升提取效率 |

## 容易做错的三处
- 现象：调用煤化工专用插件时出现504超时报错。原因：未针对煤化工多源数据的拉取需求调整超时时间，默认超时时长不足以完成多台账的解析与数据整合。
- 现象：工作流中接入MCP功能后无法触发插件调用。原因：未正确配置工具调用模式为`functionCall`，或未将插件绑定至对应工作流节点。
- 现象：调用时提示工作流ID无效，无法完成插件调用。原因：未从FastGPT工作流管理界面正确复制工作流ID，或粘贴时混入了空格、标点等额外字符。

## 怎么确认配好了
- 手动触发一次工具调用，查看返回的参数是否包含煤化工专用字段如反应釜温度、进料速率，核对单位是否符合预期。
- 查看工作流日志，确认插件调用的超时时间与配置一致，无超时报错。
- 检查插件数据源过滤规则，确认仅允许煤化工相关的文档类型被调用。
- 验证工作流ID的粘贴位置正确，无多余字符，确保调用指向正确的工作流节点。
