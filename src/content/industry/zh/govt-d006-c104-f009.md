# 煤化工的文书与材料起草：模型接入与配置

## 这个品类的数据长什么样
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这些特征在「模型接入与配置」这一环带来什么约束
煤化工文书包含大量工业专业术语与固定格式的参数字段，要求模型接入时优先选择适配工业领域的模型，避免通用模型对专业术语的误解析。文档的分阶段更新特性要求知识库同步周期匹配项目进度，避免使用过时数据。长文档与多字段结构要求模型上下文与引用片段的配置预留足够空间，确保完整读取工艺参数与审批信息。安全类文书的严谨性要求限制模型的随机生成倾向，避免出现不符合规范的内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填写绑定煤化工项目组的代理地址 | 确保调用链路专属，避免跨项目权限冲突 |
| `AIPROXY_API_TOKEN` | 填写团队分配的专属令牌 | 限制模型调用权限仅开放给授权人员 |
| `temperature` | 0.2–0.4 | 煤化工文书需严格匹配工艺参数与规范，低温度可降低随机生成偏差 |
| `maxContext` | 8000–12000 token | 适配可研报告、安全报告等长文本的上下文读取需求 |
| `quoteMaxToken` | 2000–3000 字符 | 确保检索到的设备参数、审批文件等完整片段传入模型 |
| `maxTokens` | 1500–2000 token | 满足单份煤化工文书的标准输出长度 |

## 容易做错的三处
- 添加`AIPROXY_API_TOKEN`后调用返回404 page not found，原因是代理地址配置错误，未匹配令牌绑定的专属端点。
- 索引到了相关工艺参数文档，但模型未引用该内容，原因是`quoteMaxToken`取值过小，导致检索到的文档片段被截断无法被模型识别。
- 无法查看团队成员的模型使用记录，原因是未开启团队权限审计配置，或未分配对应查看角色。

## 怎么确认配好了
- 调用FastGPT测试接口，传入包含煤化工工艺参数的prompt，检查返回结果是否包含匹配的文档片段。
- 查看代理调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的请求返回200状态码，无404报错。
- 调整`temperature`参数，对比不同取值下的文书严谨性，确认输出符合煤化工文档的规范要求。
- 检查知识库索引的煤化工文档，确认检索结果与模型输出的引用内容一致。
