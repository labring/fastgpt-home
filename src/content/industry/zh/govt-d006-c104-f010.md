# 煤化工的文书与材料起草：知识库检索与召回

## 这个品类的数据长什么样
煤化工文书与材料起草依赖的数据来源包括煤化工装置的工艺技术规程、物料平衡台账、安全操作规范、项目可研报告、日常运维记录与合规审批文件。文档类型覆盖结构化表格、长文本规程、带附图的操作手册三类，其中结构化表格多包含物料配比、能耗参数、设备编号等字段，单位涉及吨、立方米、千焦等工业标准单位。工艺类文档每年度或重大技改后更新，运维台账随设备运行状态实时补充，部分涉密合规文件仅在审批节点更新。

## 这些特征在「知识库检索与召回」这一环带来什么约束
煤化工数据的结构化表格占比高，普通文本分块会丢失表格的行列关联信息，需针对性处理表格拆分与关联召回；长文本工艺规程篇幅动辄数千字符，分块长度需适配长文本的上下文连贯性，避免拆分后破坏工艺逻辑的完整性；物料参数附带明确单位，检索时需匹配单位相关关键词以提升召回精度，避免将不同单位的参数混淆；实时运维台账的高频更新，要求知识库同步周期适配更新节奏，避免召回过时数据；带附图的操作手册需同步提取图片内嵌的工艺说明，否则无法关联图文对应的操作要求。

## 配置怎么定
FastGPT v4.17.0版本下，以下配置项适配煤化工场景的检索与召回需求：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 相似度阈值 | 0.75–0.85 | 匹配煤化工工艺参数的精准度要求，避免召回无关的通用化工文档 |
| 单次搜索上限 | 前8条 | 覆盖煤化工单份文书所需的参考文档范围，避免上下文过载 |
| 搜索模式 | 混合检索 | 兼顾结构化表格与长文本规程的召回效果，适配煤化工文档的混合结构 |
| 重排开关 | 开启 | 对初始召回结果排序优化，修正关键词匹配的偏差，提升专业内容的优先级 |
| 问题优化 | 开启 | 针对煤化工专业术语优化检索query，提升专业内容的召回相关性 |
| 指定知识库集合 | 绑定煤化工专属数据集 | 隔离通用化工数据与煤化工专属文档，避免跨品类数据干扰 |

## 容易做错的三处
- 现象：上传煤化工物料平衡Excel表格后，检索时无法召回表格内的物料配比参数。原因：未启用结构化数据解析配置，直接按普通长文本分块，丢失了表格的行列关联信息。
- 现象：检索结果中混杂大量通用化工文档，未命中煤化工专属工艺内容。原因：未通过`collectionIds`指定煤化工专属知识库集合，召回了跨品类的冗余数据。
- 现象：配置后首次检索返回结果条数远低于预期。原因：相似度阈值设置过高，过滤掉了部分相关但关键词匹配度略低的煤化工文档。

## 怎么确认配好了
- 上传一份煤化工工艺规程文档，发起检索“某煤化工装置的物料配比”，核对返回结果是否包含该文档的对应内容。
- 查看知识库集合绑定状态，确认仅包含煤化工专属的工艺、运维、合规类文档，无无关品类的数据。
- 发起一次带结构化表格的检索请求，核对返回结果是否包含表格内的参数信息。
- 调整相似度阈值后发起两次检索，对比结果条数变化，确认阈值配置生效。
