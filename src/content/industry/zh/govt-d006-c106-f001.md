# 煤电一体化的文书与材料起草：HTTP 接口与外部系统

## 这个品类的数据长什么样
煤电一体化场景的文书数据主要来源于内部生产调度系统、煤炭购销台账与发电运行报表。数据按生产班次同步更新，每日生成多份归档文档。文档结构包含机组编号、煤炭入厂量、机组负荷、发电时长、合规检查项等固定字段，其中煤炭入厂量单位为吨，机组负荷单位为兆瓦，发电时长单位为小时。文档多为带结构化字段的PDF或Word格式，部分同步至企业内部数据库。本页面适配FastGPT v4.17.0版本。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
由于数据来源于企业内网的生产系统与台账，HTTP接口需配置内网访问权限，禁止直接使用公网域名对接。固定字段的文档结构要求请求参数需严格匹配预设字段名，避免字段不匹配导致数据提取失败。按班次更新的同步节奏要求接口轮询间隔需匹配生产排班周期，不宜设置过短或过长的请求间隔。多格式的文档载体要求接口需兼容PDF与Word格式的附件拉取，需额外配置格式解析适配参数。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer 企业内网API密钥` | 内网接口需身份验证，防止未授权访问 |
| `variables` | 绑定机组编号、煤炭入厂量等预设字段变量 | 匹配场景内固定字段的文档结构，确保数据提取准确 |
| 请求超时时间 | 600 秒 | 内网数据拉取通常需要300-500秒，预留足够缓冲时间 |
| `responseData` | 提取前5-7条匹配文档的结构化字段 | 单班次生成的归档文档数量通常在此区间，按实测标定 |
| 格式解析适配 | 开启PDF与Word格式支持，单文件大小不超过1000 MB | 场景内单份文档通常不超过该大小，避免请求过载 |

## 容易做错的三处
- 现象：HTTP response返回200状态码但下游提取的变量为空。原因：未通过`responseData`配置项指定正确的字段提取路径，或请求字段与场景内预设字段不匹配。
- 现象：启动容器服务时出现网络连接失败的报错日志。原因：未配置内网访问权限，尝试访问公网接口导致无法建立连接。
- 现象：接口请求在300秒内被强制终止。原因：请求超时时间设置过短，未匹配内网数据拉取的实际耗时。

## 怎么确认配好了
- 在FastGPT v4.17.0版本的工作流中，手动触发一次HTTP请求，查看返回的response body，核对`responseData`配置的提取字段是否与场景内文档的预设字段一致。
- 检查`Authorization`配置的密钥是否与内网接口要求的身份验证格式匹配，确保无格式错误。
- 模拟生产班次的时间间隔发起请求，确认接口能正常拉取对应时段的文档数据。
- 开启格式解析日志，确认PDF与Word格式的文档能被正常识别并提取字段。
