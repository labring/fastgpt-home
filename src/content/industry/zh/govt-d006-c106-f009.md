# 煤电一体化的文书与材料起草：模型接入与配置

## 这个品类的数据长什么样
煤电一体化场景的文档来源包括企业生产调度日志、安全检查记录、项目申报材料、月度经营总结、煤炭开采与电力生产台账等。更新节奏分为三类：调度日志为每日更新，月度总结为每月固定节点更新，安全规程与行业标准文档为季度或年度更新。文档结构包含单份数十页的长文本报告，以及单条记录的短字段，字段涵盖矿井编号、发电量、煤耗率、供电量等，单位涉及万千瓦时、吨标准煤、兆瓦等。

## 这些特征在「模型接入与配置」这一环带来什么约束
煤电一体化的文档兼具长文本报告与短字段记录的特征，要求模型接入时需适配不同长度的输入输出，避免截断关键生产或安全数据。不同数据源的更新频率差异，要求配置索引策略时区分高频与低频更新的文档类型，平衡数据时效性与存储成本。行业特定的字段与单位，要求模型配置时需加入针对性的上下文引导，确保生成的文书符合行业规范。同时，国央企与公共服务场景的数据本地化需求，要求模型接入需支持本地API部署与鉴权，保障数据安全。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 煤电一体化文档多为长文本报告，需容纳完整的生产计划、安全检查汇总等内容，避免关键信息被截断 |
| `maxTokens` | 2000–3000 token | 适配煤电行业标准文书的输出长度，确保生成的总结、申报材料等内容完整且符合格式要求 |
| `quoteMaxToken` | 1500 token | 匹配行业文档中长段落引用的需求，确保合规性说明、数据来源等引用内容完整展示 |
| `temperature` | 0.3–0.5 | 文书起草需保持专业严谨的风格，降低输出的随机性，避免出现不符合行业规范的表述 |
| `AIPROXY_API_ENDPOINT` | 本地部署地址加标准API路径，如`http://127.0.0.1:8080/v1` | 适配煤电企业数据本地化部署的需求，支持对接本地部署的文档解析工具 |
| `AIPROXY_API_TOKEN` | 企业自定义的鉴权令牌 | 保障内部数据调用的安全性，符合国央企与公共服务场景的数据安全规范 |

## 容易做错的三处
- 现象：工作流中无法选择已配置的模型，模型列表显示为空。原因：未在FastGPT v4.17.0的模型配置页勾选「启用」选项，或配置未同步到工作流模块。
- 现象：调用本地部署的MinerU解析服务返回503状态码。原因：本地Docker容器的端口未正确映射，或`AIPROXY_API_ENDPOINT`配置的地址与实际部署的MinerU服务地址不一致。
- 现象：生成的文书材料出现单位错误或字段缺失。原因：未针对煤电行业的特定字段配置模型的上下文引导，导致模型未正确识别数据格式。

## 怎么确认配好了
- 进入模型配置页面，检查已添加的模型状态为启用，且`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`填写无误。
- 上传一份煤电行业的标准文档（如月度生产总结），触发模型调用，查看返回结果是否包含完整的行业术语与合规格式。
- 配置工作流节点，选择已接入的模型，确认节点可正常保存并预览调用结果。
- 使用curl命令调用本地部署的MinerU服务，确认返回的解析内容格式符合预期，无报错或异常。
