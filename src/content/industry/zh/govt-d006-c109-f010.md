# 电网企业的文书与材料起草：知识库检索与召回

## 这个品类的数据长什么样
电网企业的文书与材料起草数据主要来自内部安全规程、作业指导书、运维手册、招投标文件及合规性文档。数据更新随行业标准修订、年度合规审查及新业务上线按季度或年度触发。单份文档通常包含章节编号、条款说明、适用电压等级、作业流程步骤等结构化字段，部分现场作业记录为非结构化文本，单位涉及千伏、小时、公里等电力行业专用计量标识。

## 这些特征在「知识库检索与召回」这一环带来什么约束
电网企业文书的结构化字段与专用计量单位，要求检索时需匹配条款适用的电压等级、作业区域等字段，避免召回不适用的内容。非结构化的现场作业记录占比不低，需兼顾关键词召回与语义匹配。按季度或年度更新的数据，无需高频同步知识库，可配置定时增量更新任务。专用单位的存在，要求检索逻辑需识别并关联电力行业计量术语，提升召回精准度。

## 配置怎么定
本文适配FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 电网文书对合规性要求高，该区间可过滤低相似度的无关内容，平衡召回覆盖与精准度 |
| `limit` | `前8条` | 单份电网文书通常篇幅较长，8条召回结果可覆盖核心条款，避免上下文溢出 |
| `searchMode` | `semantic+keyword` | 兼顾结构化字段的关键词匹配与非结构化内容的语义召回，适配电网文书混合结构 |
| `usingReRank` | `开启` | 电网文书条款关联性强，重排可进一步过滤语义接近但不相关的召回结果 |
| `datasetSearchUsingExtensionQuery` | `开启` | 电网专业术语多，扩展查询可补充同义词匹配，提升对专用术语的召回能力 |
| `collectionIds` | `指定电网合规文档、作业指导书集合ID` | 限定检索范围，避免召回非相关的企业内部非文书类数据 |

## 容易做错的三处
- 现象：调用网页静态链接生成知识库时返回`Validation failed: name: Path `name` is required.`。原因：未为电网文档集合配置必填的文档名称字段，或上传文档时未填写基础标识名称。
- 现象：查看聊天回答的知识库引用时出现报错，返回空引用或状态码异常。原因：检索范围未限定为电网专属文档集合，或`similarity`阈值设置过低导致无效召回。
- 现象：无法召回飞书存储的电网内部文书数据，或回答中强制展示无关引用内容。原因：未将飞书知识库添加至`collectionIds`的检索范围中，或未关闭非必要的跨源检索开关。

## 怎么确认配好了
- 上传一份电网作业指导书文档，查看知识库集合的字段是否包含文档名称、适用电压等级等必填项。
- 发起检索测试，输入“10kV线路运维规程”，核对召回结果的`similarity`分值是否符合预设区间。
- 查看检索结果的引用来源，确认仅展示电网专属文档集合的内容，未混入非相关数据。
- 关闭引用展示开关后，发起检索，确认回答中未展示知识库引用内容。
