# 船舶制造的文书与材料起草：知识库检索与召回

## 这个品类的数据长什么样
船舶制造的文书与材料起草相关数据，主要来源为船级社规范文件、船舶设计图纸配套技术说明书、分段建造工艺规程、节点验收报告及全船交付文档。数据更新节奏随建造项目节点动态调整，分段建造阶段更新分段工艺文档，整船合拢后更新总装工艺内容，交付前更新全套验收材料。文档多为多章节长文本结构，包含船型、船级社编号、建造批次、材料牌号等固定字段，单位采用行业专属的毫米、兆帕、节（航速）等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
船舶制造的文书数据多为长章节技术文档，单份文档字数较多，会导致单块召回内容过长，影响上下文精度。文档包含船级社编号、材料牌号等精准标识字段，以及专属单位术语，需要兼顾语义召回与精确匹配的权重调整。数据按项目维度管理且动态更新，不同项目的文档版本独立，需要支持按项目绑定知识库集合，避免跨项目数据混淆。专业术语较多，普通语义检索可能无法覆盖专属表述的变体，需要额外的查询扩展能力。

## 配置怎么定
本文基于FastGPT v4.17.0版本进行配置说明。
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `similarity` | 0.72–0.80 | 船舶制造文档多为专业技术内容，语义相似度阈值过低会引入无关文档，过高则遗漏相关参数内容，按实测标定 |
| `limit` | 前8条 | 单份船舶建造文档包含多类参数，召回过多会超出上下文窗口，过少则无法覆盖完整工艺要求 |
| `searchMode` | hybrid | 兼顾语义召回与精确匹配，适配文档中精准字段与专业术语的混合检索需求 |
| `usingReRank` | 开启 | 船舶文档的专业术语较多，重排可过滤语义相近但不匹配的结果，提升召回准确性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可基于用户问题自动生成专业扩展查询，覆盖船舶制造的专属术语变体，比如“航速”与“最大航速”的关联 |
| `collectionIds` | 绑定对应项目的知识库集合ID | 船舶制造按项目管理文档，绑定对应项目的集合ID可避免跨项目数据干扰 |

## 容易做错的三处
- 本地部署环境下，知识库检索结果未返回图片索引内容，界面显示图片字段为空。原因是未配置船舶制造文档中配套图纸图片的路径映射规则，默认索引仅抓取文本内容，未关联图片资源链接。
- 检索返回结果条数与配置的`limit`参数不符，实际返回条数超出设定值。原因是未关闭重排后的结果截断逻辑，重排模块会自动补充相关结果导致超出上限。
- 用户输入船舶制造专属术语如“分段建造”时，检索召回结果与预期不符。原因是未开启`datasetSearchUsingExtensionQuery`，未生成专业术语的扩展查询，无法覆盖术语的同义或关联表述。

## 怎么确认配好了
- 上传单份船舶建造工艺文档，触发知识库索引，查看索引日志中是否包含文档内的图片路径字段。
- 输入包含船级社编号的查询语句，核对检索结果的`similarity`分值是否落在设定的0.72–0.80区间内。
- 开启`usingReRank`后，对比开启前后的检索结果条数，确认重排模块正常过滤无关结果。
- 绑定指定项目的`collectionIds`，输入跨项目的查询语句，确认未返回其他项目的文档内容。
