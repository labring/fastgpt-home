# 金属材料加工的文书与材料起草：文档解析与分块

## 这个品类的数据长什么样
金属材料加工的文书数据主要来源于生产车间的工艺规程、原材料材质单、成品检验报告、设备运行日志。数据更新随生产批次推进，单批次生产完成后同步更新对应文档。文档多包含结构化表格，如合金成分占比、力学性能参数表，同时伴随长文本格式的工艺操作说明。核心字段包含材料牌号、炉批号、抗拉强度、延伸率，常用单位为MPa、%与质量占比数值。部分文档还会附带工艺示意图或设备参数图像，与文本内容绑定关联。

## 这些特征在「文档解析与分块」这一环带来什么约束
结构化表格占比高的特征要求解析环节保留表格的行列结构，避免分块时拆分完整的成分或性能参数表。长文本工艺说明与批次绑定的更新节奏，要求分块长度适配单批次工艺的信息密度，避免跨批次的内容被分到同一块。固定的单位与字段关联，要求分块时保留字段与对应参数、单位的绑定关系，避免参数与单位分离。附带的工艺示意图需要解析工具关联对应文本内容，避免图像与说明文本分离，影响后续检索准确性。

## 配置怎么定
以下配置项均适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配金属材料加工文档中工艺说明与参数表的信息密度，避免单块内容过载或过碎 |
| `chunkSplitter` | 按段落+表格拆分 | 匹配文档中长文本工艺说明与结构化表格的混合结构，保留内容完整性 |
| `customPdfParse` | 启用MinerU解析模式 | 支持解析表格、嵌入图像与复杂排版的金属材料加工文档，适配材质单、检验报告的格式 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 覆盖长文档（如月度工艺汇总）的解析耗时，避免因超时导致解析失败 |
| `chunkSettingMode` | 手动配置 | 针对金属材料加工文档的混合结构，灵活调整分块规则与解析参数 |

## 容易做错的三处
- 现象：上传包含外部图像链接或嵌入工艺图的文档时，解析任务失败，返回状态码400或“无法解析非标准文件格式”。原因：未启用`customPdfParse`的MinerU解析模式，默认解析工具无法处理图像地址关联的文档内容。
- 现象：本地部署MinerU并通过curl验证端口连通后，FastGPT勾选增强PDF解析仍无法调用解析服务。原因：未在FastGPT的系统配置中填写MinerU的本地API访问地址与端口，解析请求未正确转发至MinerU容器。
- 现象：解析后的金属成分表格仅生成单条向量，无法按表格行列拆分多向量。原因：未将`chunkSplitter`配置为支持表格拆分的模式，分块逻辑未识别结构化表格的行列结构。

## 怎么确认配好了
- 上传一份标准的金属材质单PDF，查看解析结果中的表格是否完整保留行列结构。
- 在知识库设置界面，检查`customPdfParse`选项的启用状态，确认MinerU的API地址配置无误。
- 测试解析一份包含长文本工艺说明的文档，查看分块后的内容是否未拆分完整的工艺步骤段落。
- 查看解析任务的运行日志，确认未出现超时相关报错，且任务执行时长符合预设的超时参数范围。
