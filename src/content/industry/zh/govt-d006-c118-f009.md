# 金属材料加工的文书与材料起草：模型接入与配置

## 这个品类的数据长什么样
金属材料加工的文书与材料起草相关数据，主要来源于企业内部ERP系统、质量管理系统（QMS）、工艺文件库及国家金属材料标准文档。数据更新节奏分为两类：批次性文档如来料检验单、质量证明书随生产流程实时生成，工艺规程、外协合同等则在工艺调整、标准更新时定期修订。文档结构多包含固定字段：材料牌号、炉批号、加工工艺参数（如加热温度、轧制压力）、力学性能指标（如抗拉强度、屈服强度），字段单位多为摄氏度、兆帕、每分钟转数等专业工业单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
金属材料加工的专业数据特征，对模型接入与配置带来明确约束。首先，包含大量带固定单位的结构化数值参数，要求模型生成内容需严格匹配行业规范，因此需限制模型的随机性。其次，批次性文档的单份数据量波动较大，需配置合适的上下文窗口以完整加载相关数据。第三，国央企场景下的数据保密性要求，需将模型调用限制在企业内网环境，避免公网传输敏感信息。此外，行业标准文档的定期更新，要求知识库同步周期需匹配企业的标准修订节奏，确保模型引用的参考内容时效性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 单批次对应的工艺文件、质量证明书等关联文档的总token数通常处于该区间，可避免上下文溢出导致的内容截断 |
| `maxTokens` | 2000–3000 token | 金属材料加工的单份文书如质量证明书、工艺规程的标准输出长度，适配该取值可平衡生成效率与内容完整性 |
| `temperature` | 0.2–0.4 | 需严格匹配专业术语与固定单位，该参数区间可降低模型的随机性，减少生成不符合行业规范的内容 |
| `AIPROXY_API_ENDPOINT` | 企业内网私有代理端点（如`http://internal-ai-proxy:8080/v1`） | 适配国央企数据保密要求，将模型调用限制在企业内网网络内，避免敏感数据外泄 |
| `AIPROXY_API_TOKEN` | 按用户动态生成的访问密钥 | 可实现用户级的访问权限控制，避免公用密钥导致的对话与记录共享问题 |

## 容易做错的三处
- 现象：界面无法显示新增的模型配置，重启FastGPT v4.17.0后仍无变化。原因：未将模型配置文件放置在FastGPT指定的加载目录，或配置格式不符合系统要求。
- 现象：调用模型时返回连接超时错误，状态码504。原因：`AIPROXY_API_ENDPOINT`配置为非内网地址，未通过企业防火墙的访问控制策略，导致无法连接私有模型服务。
- 现象：生成的文书中出现错误的性能单位，例如将抗拉强度标注为“800”未附带MPa单位。原因：`temperature`参数设置过高，模型生成内容偏离行业规范，混淆了数值与单位的对应关系。

## 怎么确认配好了
- 上传一份真实的金属材料来料检验单与工艺规程到知识库，触发文书起草任务，检查模型是否能正确提取炉号、材料牌号等核心字段。
- 查看FastGPT的模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置被正确加载，无连接失败或权限错误记录。
- 生成一份质量证明书草稿，检查输出内容是否包含符合行业标准的单位与参数格式，无明显的专业术语错误。
- 测试多用户访问场景，使用不同的`AIPROXY_API_TOKEN`发起调用，确认各用户的对话记录与生成内容相互隔离，无数据共享问题。
