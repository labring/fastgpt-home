# 公共数据目录与开放的申报材料与案卷审核：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自地方公共数据开放平台、一体化大数据平台、部门业务数据库及电子证照库，更新频率为每月一次。日常文档包含公共数据资源目录、数据开放清单、数据项说明、脱敏规则、接口文档、更新频率说明，文档结构以结构化字段组合为主，包含数据项名称、开放范围、脱敏要求、接口地址、更新周期等核心字段，无额外非结构化冗余内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
每月固定更新的数据源要求配置支持周期性数据同步校验，避免目录与实际数据不一致。结构化为主的文档结构，要求模型输入需适配结构化字段提取，避免非结构化解析的冗余开销。多来源数据需统一格式，要求配置中支持多数据源的格式转换规则，确保数据一致性。脱敏规则与接口文档的关联，要求模型配置需绑定对应数据项的脱敏参数，防止数据泄露。长文本的案卷审核场景，要求上下文窗口配置需适配单批次审核材料的长度，避免截断关键信息。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配月度更新的全量目录文档及单批次案卷审核的上下文长度，避免关键信息截断 |
| `temperature` | 0.1–0.3 | 用于案卷审核的严谨性场景，降低输出随机性，确保审核结果一致性 |
| `maxTokens` | 2000–3000 token | 限制单条审核结果的输出长度，适配申报材料的字段校验需求 |
| `toolChoice` | auto | 自动选择工具调用，用于接口文档校验与数据项匹配 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写标准接口地址 | 适配政务场景的私有部署网络环境，确保数据不泄露 |
| `AIPROXY_API_TOKEN` | 按实测标定的安全密钥 | 保障接口调用的身份验证安全，符合政务数据访问规范 |

## 容易做错的三处
- 调用模型时出现`Unexpected end of JSON input`报错，原因是本地部署模型的上下文溢出导致响应截断，未完整返回符合要求的JSON结构。
- 长文本申报材料审核时出现答非所问的情况，原因是`maxContext`配置不足，无法承载完整的上下文信息，导致模型丢失关键审核依据。
- 审核结果中出现未在脱敏规则中定义的字段内容，原因是未绑定对应数据项的脱敏配置，导致模型输出超出允许范围的信息。

## 怎么确认配好了
- 执行单次全量公共数据目录文档的解析测试，核对输出字段与源文档一致，调整配置项直至匹配。
- 提交月度更新的模拟数据同步任务，检查是否出现数据不一致或泄露的提示，确认脱敏与格式转换规则生效。
- 调用测试接口，验证`AIPROXY_API_TOKEN`与`AIPROXY_API_ENDPOINT`的配置可正常完成身份验证与数据请求。
- 提交多批次长文本申报材料，核对模型输出的审核结果未出现答非所问或冗余内容，调整相关配置项直至符合要求。
