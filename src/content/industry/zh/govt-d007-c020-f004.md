# 国土空间规划编制与实施评估的申报材料与案卷审核：工作流编排

## 这个品类的数据长什么样
该品类的日常文档包含国土空间总体规划、详细规划、专项规划、规划实施评估报告、公众意见汇总等，数据来源涵盖国土空间基础信息平台、自然资源调查监测数据、人口经济统计数据与遥感影像。数据多包含区域空间边界坐标、设施布局点位、约束性指标、审批节点编号等字段，文档结构多为结构化表格搭配空间附件，更新以年度为周期，单次数据体量较大，涉及多源格式的业务材料与案卷，部分文档包含矢量图层附件，字段精度要求较高。

## 这些特征在「工作流编排」这一环带来什么约束
多源数据的体量与格式差异要求工作流需设置分阶段解析与聚合节点，避免单次上下文过载。年度更新的数据源需要配置定期同步规则，确保工作流调用的数据与最新规划要求一致。复杂的文档结构需要工作流支持多格式解析组件，适配空间附件与文本材料的混合输入。同时，案卷审核的严谨性要求工作流配置流转校验节点，确保申报材料完整，避免出现审批延误等问题。此外，该品类处理整片区域与多年约束的规划内容，工作流需支持长周期的节点流转与多轮数据校验，贴合规划编制的业务逻辑。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本制定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 绑定`{{currentDate}}`、规划范围坐标变量 | 满足提示词落款时间需求，关联业务专属数据字段 |

| RAG知识库绑定 | 绑定国土空间规划标准库、区域基础数据子集 | 匹配品类专属的文档与数据来源 |
| MCP工具调用配置 | 按`nodeId`顺序调用空间数据校验、意见汇总工具 | 贴合规划编制的业务流程顺序 |
| 单次搜索上限 | 前 8 条 | 避免过多空间数据过载工作流上下文 |
| 数据源同步周期 | 1 年 | 匹配品类数据的年度更新频率 |
| 上下文长度限制 | 8000 token | 适配多源混合文档的解析需求 |

## 容易做错的三处
- 工作流执行时提示“上下文长度超限”，原因：未设置上下文长度限制，或单次搜索上限过高，加载了过多国土空间规划文档与遥感影像数据。
- 分享链接无法正常访问，原因：未在工作流分享配置中开启对应鉴权开关，或配置的权限规则与业务部门要求不符。
- 工作流流转后出现审批延误标记，原因：未配置案卷材料完整性校验节点，遗漏公众意见汇总文档。

## 怎么确认配好了
- 测试工作流运行，查看提示词落款时间是否与系统当前日期一致。
- 触发RAG调用，确认返回的文档来自绑定的国土空间规划专属知识库。
- 检查工作流分享配置页面，确认鉴权开关已开启并匹配部门权限规则。
- 尝试导出绑定了MCP工具的独立节点，确认导出文件格式符合业务归档要求。
- 查看数据源同步配置，确认同步周期与品类数据的年度更新节奏匹配。
