# 土地使用权、矿业权与国有产权交易的申报材料与案卷审核：模型接入与配置

## 这个品类的数据长什么样
该品类数据主要来自全国公共资源交易平台、自然资源交易系统、产权交易所系统及国资监管系统，每日更新。日常处理的文档包含出让公告、交易须知、竞买申请、保证金凭证、成交确认书、挂牌结果公告、产权转让说明书等，核心字段涉及交易标的权属信息、限制条件、保证金金额、成交确认细节等，数据结构围绕资源资产权利的交易流程构建。

## 这些特征在「模型接入与配置」这一环带来什么约束
不同来源的系统数据格式存在差异，模型接入需适配多套数据接口的返回结构，避免解析错误。每日更新的业务数据要求配置支持高频同步的触发逻辑，防止数据滞后影响审核效率。多样的文档类型与差异化的核心字段，需要模型针对不同文档预设专属的识别规则，确保权属、保证金、成交确认等关键信息提取准确。同时，数据关联的出错后果严重，配置需强化关键信息的校验逻辑，减少误判风险。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 该品类文档较长，包含权属说明、交易流程等多段内容，足够上下文容纳完整的审核材料与历史数据 |
| `maxTokens` | `4000–6000 token` | 满足审核核心内容的输出长度需求，避免截断关键的权属校验或成交确认结论 |
| `temperature` | `0.1–0.3` | 审核需严格准确，降低生成随机性，确保对权属、保证金等关键信息的识别一致性 |
| `AIPROXY_API_ENDPOINT` | 对应模型服务商的专属接入地址 | 适配该品类高合规性的数据传输要求，确保接口调用的稳定性 |
| `AIPROXY_API_TOKEN` | 绑定专属业务权限的令牌值 | 区分业务场景的访问权限，保障国资、自然资源相关数据的访问安全 |
| `toolChoice` | `auto` | 支持模型自主选择是否调用工具辅助校验权属信息，适配多文档的审核场景 |

## 容易做错的三处
- 现象：agent执行详情页面显示链接断开，接口返回超时错误。原因：未配置适配公共资源交易系统的超时阈值，导致长文档审核时接口调用超时。
- 现象：上传风格参考文件与业务内容文件后，模型生成的审核材料不符合预期风格。原因：未启用`vision`参数，无法识别参考文件的格式与排版风格。
- 现象：模型提供商管理页面未展示调用日志。原因：未绑定包含日志查看权限的`AIPROXY_API_TOKEN`，或未开启上下文日志的采集配置。

## 怎么确认配好了
- 手动上传1份竞买申请与1份成交确认书，核对模型提取的标的权属、保证金金额字段是否与原文一致，调整相关参数直到提取准确率符合业务要求。
- 配置定时同步任务，查看数据更新是否与业务系统的发布节奏匹配，调整同步触发逻辑适配每日更新的频率。
- 进入模型提供商管理页面，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置值与服务商提供的信息一致，验证接口连通性。
- 测试调用长文档审核任务，查看上下文与输出长度配置是否避免了内容截断，确保所有关键交易信息都被完整处理。
