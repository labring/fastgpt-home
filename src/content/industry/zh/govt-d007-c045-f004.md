# 用地预审与规划许可的申报材料与案卷审核：工作流编排

## 这个品类的数据长什么样
本品类的数据来源包括国土空间规划一张图、项目审批监管平台、土地利用现状库、生态保护红线数据，更新频率不定期。日常处理的文档包含用地预审与选址意见书、建设用地规划许可证、建设工程规划许可证、红线图、规划条件，文档包含项目选址范围、用地规模、规划管控要求、红线坐标等结构化字段与图形化空间数据，需关联多来源的空间与审批数据完成校验。

## 这些特征在「工作流编排」这一环带来什么约束
本品类的数据多源且更新不定期，要求工作流需支持实时拉取最新的国土空间规划、生态保护红线等数据进行合规校验。文档包含结构化字段与图形化红线数据，需在工作流中配置多类型数据的解析与关联节点。项目审核的核心耗时环节集中于选址合规性、用地规模与红线冲突校验，工作流需将该类校验拆分为独立可配置的节点，同时需加入跨部门前置条件协调的流转分支，适配实际审批流程逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 知识库搜索文件范围 | 绑定项目专属的红线图、规划条件文件集合 | 本品类审核需聚焦项目专属规划文档，避免无关数据干扰校验 |
| 批量执行节点循环上限 | 3-5次，按实测标定 | 需协调发改、住建、生态等跨部门前置条件，循环次数匹配实际协调节点数 |
| 大模型参数绑定 | 通过`variables`参数设置为0.2-0.5 | 审核类任务需稳定输出合规结论，避免生成随机化内容 |
| 节点超时时间 | 600秒 | 空间数据校验、多源数据拉取需较长处理时长，避免流程中断 |
| 知识库ID获取方式 | 从FastGPT知识库管理页详情页复制 | 需精准绑定本品类专属知识库，确保搜索覆盖标准文档 |
| 上下文隔离配置 | 开启后绑定`nodeId`对应节点的上下文 | 适配多节点并行处理时的上下文隔离需求 |

## 容易做错的三处
- 现象：配置知识库搜索节点时，未指定项目专属文件集合，返回结果条数远超预期。原因：未按照本品类审核需求限定搜索范围，默认检索全量知识库数据，导致冗余信息干扰校验。
- 现象：通过API调用工作流时，批量执行节点未完成全部循环，返回状态码504。原因：批量执行节点循环上限设置过高，且未配置超时重试机制，超出API调用的默认时长限制。
- 现象：开启变量引用后，大模型温度设置按钮消失，无法调整生成参数。原因：FastGPT v4.17.0版本中，变量引用模式下原生设置项被隐藏，需通过代码绑定参数实现调整。

## 怎么确认配好了
- 核对FastGPT知识库管理页面的已绑定文件，确认与工作流配置的搜索范围一致。
- 执行单节点调试，验证知识库搜索结果仅包含预设的项目专属文档。
- 调用API触发完整工作流，查看批量执行节点的执行日志，确认循环流程正常完成。
- 检查大模型参数绑定配置，确保变量引用模式下的参数已正确关联。
