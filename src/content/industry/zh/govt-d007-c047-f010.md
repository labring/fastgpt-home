# 行政处罚案卷办理的申报材料与案卷审核：知识库检索与召回

## 这个品类的数据长什么样
本品类服务于市场监管、生态环境等执法机构，日常处理的文档包含现场检查笔录、询问笔录、证据清单、行政处罚事先告知书、听证告知书、处罚决定书、送达回证。数据来源于行政执法办案系统、执法记录仪影像、国家企业信用信息公示系统及部门监管数据库，更新频率为每日。文档多为执法专用格式，包含执法人员信息、当事人信息、违法事实、法定条款、裁量基准等专属字段。

## 这些特征在「知识库检索与召回」这一环带来什么约束
执法专用文档的专属术语与固定格式，要求检索需精准匹配专业表述，避免通用检索的歧义。数据每日更新，需保障知识库同步频率与业务数据更新节奏一致，确保召回最新的监管信息与办案记录。不同于行政检查，必须形成可追溯的处罚证据链，要求检索结果需覆盖证据链所需的全部文档类型，且匹配度符合法定审核标准。多源数据的混合调用需严格限定检索范围，防止混入无关业务内容影响审核效率。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 行政处罚案卷涉及执法术语与法定文书，需过滤低匹配度的无关内容，保障检索精准性 |
| `limit` | 前10条 | 案卷审核需关联笔录、法条、裁量基准等多类文档，控制返回条数避免上下文溢出 |
| `searchMode` | 专业文档匹配 | 针对执法专用文书的术语体系优化召回逻辑，避免通用检索的歧义 |
| `usingReRank` | 开启 | 对初始召回结果按语义相关性二次排序，提升核心法条与合规文书的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动补充执法领域相关的同义词与规范表述，覆盖“裁量基准”“违法事实”等专业术语 |
| `collectionIds` | 绑定执法办案专属知识库 | 仅检索已上传的执法笔录、处罚决定书等专属文档，避免混入无关业务数据 |

## 容易做错的三处
- 现象：调用检索接口后返回空结果，或无法召回指定的执法文书。原因：未正确配置`collectionIds`参数，未绑定对应执法办案专属知识库。
- 现象：检索结果包含大量非执法类通用文档，低匹配度内容被优先召回。原因：未设置合理的`similarity`阈值，或未开启`searchMode`的专业文档匹配模式。
- 现象：检索返回结果条数不足，无法覆盖案卷审核所需的全部文档类型。原因：`limit`参数设置过低，或未开启`datasetSearchUsingExtensionQuery`覆盖专业术语的同义词。

## 怎么确认配好了
- 进入FastGPT知识库管理页面，确认已上传现场检查笔录、处罚决定书等执法专用文档，并记录对应的集合ID。
- 调用检索接口，传入配置好的`similarity`、`limit`等参数，输入“行政处罚裁量基准”等专业术语，核对返回结果的文档类型与匹配度。
- 模拟案卷审核场景，输入某类违法事实的查询词，确认召回结果包含对应的证据清单、询问笔录模板与法定条款。
- 查看检索日志，确认每次检索仅调用绑定的执法办案专属知识库，未返回无关业务数据。
