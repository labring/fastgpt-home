# 化工新材料的申报材料与案卷审核：向量模型与索引

## 这个品类的数据长什么样
化工新材料的申报与案卷审核数据主要来自企业研发台账、专利申报文件、安监备案材料、项目验收案卷等。数据更新节奏为项目立项时批量导入全量材料，日常仅补充新备案的检测报告与变更材料。文档结构包含结构化字段与非结构化内容：结构化字段包括材料编号、申报日期、原料配比、检测数据等，附带g/mol、℃、MPa等专业单位；非结构化内容为多页PDF实验报告、扫描版案卷原件。

## 这些特征在「向量模型与索引」这一环带来什么约束
结构化字段与专业单位要求索引系统同时支持元数据精准匹配与文本语义召回；长文档与批量更新的特性要求索引支持增量重建，避免全量重复处理；多来源的文档格式差异要求分块策略适配不同长度的文本内容；涉密与合规字段的存在要求索引前需完成字段合法性校验，过滤敏感内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配化工实验报告的段落长度，避免块内语义断裂 |
| 重叠长度 | 100–200 字符 | 保留跨块的实验数据关联，避免关键配比信息被截断 |
| 相似度阈值 | 0.75–0.85 | 匹配化工材料的检测数据精度，过滤低相关的申报材料 |
| 单次搜索上限 | 前 8 条 | 覆盖常见案卷的关联材料数量，避免冗余召回 |
| maxToken | 4000 token | 适配申报材料的上下文长度，满足合规校验的完整信息需求 |
| defaultToken | 1000 token | 处理短字段的元数据检索，平衡召回精度与速度 |

## 容易做错的三处
- 现象：切换知识库索引时返回60秒超时状态码。原因：未针对化工新材料长文档配置合理的分块与召回参数，导致索引重建时数据处理耗时超出系统默认阈值。
- 现象：知识库持续显示训练中或重建状态，超过24小时无法完成索引切换。原因：未启用增量索引模式，对全量历史申报材料进行了重复全量索引。
- 现象：批量添加索引的请求返回格式校验失败。原因：未过滤申报材料中的涉密或超规格字段，导致索引入库时出现格式不匹配。

## 怎么确认配好了
- 导入一份典型的化工申报案卷，使用FastGPT v4.17.0的内置索引测试工具查看生成耗时，调整参数直至耗时符合业务预期。
- 发起一次检索请求，核对返回结果的数量与相关性，调整相似度阈值与单次搜索上限至符合业务需求。
- 查看系统索引日志，确认增量索引仅处理新增材料，未触发全量重建流程。
- 提交批量索引请求，确认参数配置符合系统接口要求，无格式校验报错。
