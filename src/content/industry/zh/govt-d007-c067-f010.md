# 化肥农药的申报材料与案卷审核：知识库检索与召回

## 这个品类的数据长什么样
化肥农药的申报与案卷审核数据主要来源于农业农村部农药与肥料登记备案库、企业提交的正式申请材料、第三方质检报告与田间试验档案。数据更新随年度新登记产品审批节奏同步调整，同时伴随行业标准修订每季度更新一次。文档多为固定格式的Word或PDF文件，包含登记证号、有效成分含量、生产企业名称、审批文号等标准字段，单位多采用g/L、kg/ha、质量百分比等农业化工专用计量方式。

## 这些特征在「知识库检索与召回」这一环带来什么约束
固定的标准字段与专用计量单位，要求检索时需同时匹配字段名与单位信息，避免出现有效成分含量与单位不对应的召回结果。多为Word/PDF格式的结构化文档，解析后需保留章节标题作为上下文关联信息，否则无法准确定位到对应产品的登记条款。年度与季度的混合更新节奏，需要配置增量同步任务，确保备案库与企业申请材料的最新版本被纳入知识库。大量同类产品的相似申报材料，要求召回时需过滤冗余结果，避免重复内容干扰审核判断。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，适配化肥农药申报材料与案卷审核的专属检索需求。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 匹配化肥农药登记字段的精准度要求，避免过低导致无关材料召回，过高遗漏有效合规内容 |
| `limit` | `前 8 条` | 单批次召回结果覆盖多数申报材料的核心审核点，同时控制上下文长度 |
| `searchMode` | `vector + keyword` | 兼顾语义匹配与字段关键词匹配，适配固定字段与结构化文档的检索需求 |
| `usingReRank` | `开启` | 对召回结果按相关性重新排序，解决同类产品申报材料相似度高导致的排序混乱问题 |
| `datasetSearchUsingExtensionQuery` | `开启` | 自动扩展审核相关的同义术语，比如将“有效成分”关联“活性成分”，适配行业专用术语差异 |
| `collectionIds` | `指定农药/肥料登记库集合ID` | 限定检索范围仅覆盖化肥农药相关的申报与案卷数据，避免跨品类内容干扰 |

## 容易做错的三处
- 现象：检索结果中附带知识库文件的引用链接，审核人员无法直接使用。原因：未关闭检索结果的元数据输出开关，默认携带了文件来源链接。
- 现象：上传doc/docx文件后，检索结果未包含章节标题，无法定位到具体审批条款。原因：未开启文档解析时的章节标题提取配置，仅提取了纯正文内容。
- 现象：AI回答超出知识库范围，引入了非备案的产品信息。原因：未配置严格的知识库内容限定规则，允许模型调用外部知识生成回答。

## 怎么确认配好了
- 上传一份标准的化肥农药登记申请文档，执行检索后核对返回结果是否包含对应的章节标题信息。
- 发起一次检索请求，检查返回结果中是否未附带文件来源链接，确认引用开关已关闭。
- 输入一条知识库外的行业术语，检查AI是否无法生成对应回答，确认内容限定规则生效。
- 提交包含不同单位的检索词，比如“有效成分含量”与“g/L”，确认检索结果仅匹配对应单位的登记数据。
