# 危化品储运的申报材料与案卷审核：向量模型与索引

## 这个品类的数据长什么样
危化品储运的申报材料与案卷审核数据主要来自企业储运台账、安监部门备案文件、出入库审批单、罐区检测报告及应急处置预案等。数据更新节奏随业务变动触发，出入库单据实时更新，年度备案文件按周期同步。文档包含结构化字段，如危化品名称、CAS登记号、存储量、存储位置、审批文号，同时包含非结构化文本说明、检测数据备注，以及资质证书、罐区照片等图片类附件。单份案卷通常包含多份关联文档，整体篇幅跨度较大。

## 这些特征在「向量模型与索引」这一环带来什么约束
结构化字段与非结构化文本并存的特征，要求向量模型需兼顾标准化字段的精确匹配与长文本的语义理解。多附件聚合的案卷结构，要求索引支持批量文件的关联索引，避免单文档索引的孤立性。图片类附件的存在，要求索引需支持跨模态的内容识别与关联。高频更新的业务数据，要求索引支持增量更新模式，减少全量重新索引的资源消耗。字段附带的标准化单位（如吨、立方米），需在分块与向量化过程中保留，避免语义丢失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配危化品申报材料中单份审批文件的平均长度，避免过短导致语义割裂 |
| 重叠长度 | 100–150 字符 | 保留跨分块的上下文关联，适配长文本的案卷审核内容 |
| `defaultToken` | 1024–2048 token | 适配常规检索的上下文承载，匹配单案卷的平均内容量 |
| 相似度阈值 | 0.75–0.85 按实测标定 | 匹配危化品名称、CAS号等标准化字段的检索匹配精度 |
| 单次搜索上限 | 前10条 | 控制返回结果的冗余度，适配单案卷审核的检索范围 |
| `maxToken` | 4096 token | 适配大模型上下文窗口，承载多份附件的拼接内容 |

## 容易做错的三处
- 现象：索引后文档分段数与上传时显示不符，出现重复分段。原因：未设置合理的重叠长度，导致长文本的分块边界重叠计算错误，或未跳过案卷中重复的页眉页脚内容。
- 现象：升级版本后原有可检索内容无法命中。原因：未保留原向量模型配置，或新的索引分块规则与旧版本不一致，导致原有向量数据无法匹配新的检索逻辑。
- 现象：批量更新向量模型时需单文件逐一操作。原因：未启用增量索引模式，默认采用全量重新索引逻辑，或未配置批量处理的文件数量上限。

## 怎么确认配好了
- 上传单份典型危化品审批文件，查看分块预览界面，确认分段长度符合预期，无明显语义割裂。
- 输入标准化检索词（如某危化品的CAS号），核对返回结果的分段内容与原始文档的匹配度。
- 执行批量索引操作，查看索引进度日志，确认无异常报错或分段重复提示。
- 对比升级前后的检索结果，确认原有可检索内容仍可正常命中。
