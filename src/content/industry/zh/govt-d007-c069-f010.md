# 危化品储运的申报材料与案卷审核：知识库检索与召回

## 这个品类的数据长什么样
危化品储运的申报材料与案卷审核数据，主要来源于企业内部储运台账、安监部门备案审批文件、危化品安全技术说明书（MSDS）、日常作业记录与合规案卷。数据更新节奏分为两类：日常作业记录随每日储运操作实时更新，备案类文件随审批节点或季度合规检查更新。文档结构包含固定专业字段：危化品通用名称、CAS登记号、存储仓位编号、审批文号、有效期、闪点、防爆等级，单位涵盖吨、立方米、摄氏度、兆帕等专业计量标准。

## 这些特征在「知识库检索与召回」这一环带来什么约束
专业字段与术语的存在，要求检索需精准匹配专业表述，避免泛化召回无关内容；文档长度差异悬殊，短则单页审批单不足500字符，长则整本储运方案超10万字，需适配不同长度的分块与检索逻辑；更新节奏的差异，要求同步机制区分实时增量与定期全量更新，避免数据滞后或冗余；合规性要求严格，检索结果需覆盖审批所需的全部合规条款，不能遗漏关键字段信息。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配危化品专业术语的精准度要求，过滤低匹配度的无关文档 |
| `limit` | 前10条 | 覆盖单次申报审核的常见条目数量，控制上下文总长度 |
| `searchMode` | 向量搜索+关键词混合 | 适配结构化字段与专业术语的双重检索需求 |
| `usingReRank` | 开启 | 对初始召回结果进行二次排序，修正专业术语匹配偏差的内容 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充生成合规相关的扩展查询词，匹配备案文件中的隐含要求 |
| `collectionIds` | 按实际部署的知识库集合ID填写 | 限定检索范围，避免跨品类数据干扰检索结果 |

## 容易做错的三处
- 调用API拉取文档库时返回参数错误。原因：未正确配置`collectionIds`参数，或传入的集合ID与实际部署的知识库不匹配。
- 升级FastGPT v4.17.0后，点击知识库文件详情显示“Invalid dataset file key”报错。原因：升级后未重新同步知识库的文件密钥映射，或旧版本的文件索引未完成迁移。
- 相同知识库下检索耗时明显增加。原因：未关闭冗余的扩展查询配置，或`similarity`阈值设置过低导致召回过多无效文档。

## 怎么确认配好了
- 输入专业检索词，例如“某危化品的存储审批要求”，检查返回结果是否包含对应备案文档的审批文号、存储条件等字段。
- 查看检索日志，确认`similarity`参数生效，返回结果的匹配度处于预设区间内。
- 调用API拉取接口，传入正确的`collectionIds`，验证能正常获取指定知识库的文档列表。
- 模拟升级后的操作场景，检查知识库文件详情页无报错，确认密钥映射已完成更新。
