# 发电装备制造的申报材料与案卷审核：部署与升级

## 这个品类的数据长什么样
发电装备制造的申报材料与案卷审核数据，主要来源为设备设计图纸、制造工艺规程、资质申报文件、质检报告、归档案卷等。更新节奏随项目立项、制造节点、资质年审触发，无固定周期。文档结构包含结构化元数据（如设备型号、制造批次、合规编号、额定功率）与非结构化长文本（如工艺说明、审核笔录），部分文件为CAD格式的二进制文档，字段单位涵盖kW、小时、件等。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `STORAGE_S3_ENDPOINT` | 适配内部对象存储的端点地址，如`http://192.168.1.100:9000`，单文件上限设为`500 MB` | 发电装备的申报材料包含大型CAD图纸和工艺文档，单份文件体积较大 |
| `DB_MAX_LINK` | `20–30 个` | 该品类的申报材料涉及多表关联的结构化数据，需要足够的数据库连接池支持并发审核请求 |
| `MONGODB_URI` | 带认证参数的连接字符串，如`mongodb://user:pass@host:27017/fastgpt?authSource=admin` | 案卷审核数据需要非结构化存储归档，MongoDB适配半结构化的案卷元数据 |
| `REDIS_URL` | 带密码的独立Redis实例地址，如`redis://:pass@host:6379/0` | 需要缓存审核状态、批量任务进度，降低数据库压力 |
| `FILE_TOKEN_KEY` | 32位随机字符串，按实测标定 | 需要安全生成文件访问令牌，防止未授权访问涉密申报材料 |
| `FE_DOMAIN` | 部署服务的公网或内网域名，如`https://fastgpt.manufacture.gov.cn` | 需要统一前端访问入口，适配内部办公网络的域名规则 |

## 容易做错的三处
- 现象：执行docker pull fastgpt命令时返回拉取超时或镜像不存在。原因：未配置国内镜像加速源，或使用了过期的镜像标签。
- 现象：导入审核专用插件时弹出internal server error提示。原因：`DB_MAX_LINK`配置取值过低，并发导入请求耗尽数据库连接池资源。
- 现象：服务器磁盘占用持续增长，无法查询知识库磁盘占用详情。原因：未区分原文件、分割块、嵌入向量的存储路径，未配置定期清理冗余数据的规则。

## 怎么确认配好了
- 执行docker ps命令，确认FastGPT容器及依赖的MongoDB、Redis容器均处于运行状态。
- 上传一份500 MB以内的大型CAD图纸，确认文件上传成功且可在知识库中检索到对应元数据。
- 发起一条批量案卷审核任务，确认任务进度可在后台实时展示，无数据库连接超时报错。
- 访问`FE_DOMAIN`配置的域名，确认前端页面可正常加载且无资源加载失败提示。
