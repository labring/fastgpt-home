# 发电集团的申报材料与案卷审核：知识库检索与召回

## 这个品类的数据长什么样
发电集团申报材料与案卷审核的数据主要来自内部项目申报文件、电力业务案卷，包括并网验收案卷、技改项目申报案卷、煤耗核算案卷等。数据更新以单次申报批次批量上传为主，日常新增案卷按月度归档更新。单份文档多为结构化表格搭配长文本说明，包含项目编号、机组编号、申报日期、审批状态、能耗数据、合规条款等字段，单位涉及兆瓦（MW）、标准煤吨（tce）、元、自然日等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
结构化字段与长文本混合的文档结构，要求检索同时支持语义匹配与字段精准筛选，避免仅语义检索遗漏关键合规条款。批次性的更新节奏，无需配置实时同步任务，可按归档周期触发知识库训练。高合规性要求的业务场景，需要严格限定检索范围仅覆盖发电集团专属文档，防止引入无关品类的审核材料。单份文档篇幅较长，分块长度需要适配长文本上下文，避免拆分过度破坏语义完整性或过长导致上下文溢出。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配申报材料的合规条款与案卷细节，过滤低相关的检索结果 |
| `limit` | 前10条 | 单批次申报材料数量较多，控制召回条数避免上下文token过载 |
| `searchMode` | hybrid | 适配结构化字段与长文本描述的混合文档，兼顾语义匹配与字段筛选 |
| `usingReRank` | 开启 | 长文本案卷的语义相关性区分度较低，重排可提升结果精准度 |
| `datasetSearchUsingExtensionQuery` | 关闭 | 申报材料与案卷有固定业务格式，扩展查询易引入无关业务内容 |
| `collectionIds` | 发电集团申报案卷专属集合ID | 限定检索范围仅覆盖本品类专属知识库，防止跨品类数据干扰 |

## 容易做错的三处
- 召回结果包含非本品类的审核材料：界面返回的检索结果混杂其他行业的申报文档，原因是未正确配置`collectionIds`参数，未限定检索集合范围。
- 回答出现知识库未收录的外部内容：审核回复中出现未上传的政策或行业标准内容，原因是未启用严格的知识库内容限制，允许调用外部生成能力。
- 导出知识库文件明细失败：调用接口后返回空结果或404状态码，原因是未使用“知识库接口”章节下的正确端点，或未携带有效权限参数。

## 怎么确认配好了
- 上传一份专属测试文档，检索文档内的专属关键词，确认召回结果仅来自当前配置的专属集合内的内容。
- 调用导出知识库文件明细接口，确认返回结果包含当前集合内所有上传文件的名称、上传时间与文件大小。
- 发起一个未在知识库中收录的业务问题，确认返回预设的自定义无结果回答。
- 查看检索日志，确认`searchMode`、`usingReRank`等参数的实际生效状态与配置一致。
