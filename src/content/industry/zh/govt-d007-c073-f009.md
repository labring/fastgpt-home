# 国有产业基金的申报材料与案卷审核：模型接入与配置

## 这个品类的数据长什么样
国有产业基金的申报材料与案卷数据主要来源于国资监管平台、基金管理人内部申报系统及申报主体提交的电子文档。更新节奏随项目申报周期波动，集中在季度或年度申报窗口期，日常有少量补充案卷提交。文档包含标准化申报书、财务审计报告、项目可行性研究文件、资质证明材料，字段包含基金认缴规模（单位亿元）、申报主体信用等级、项目总投资额（单位万元）、审批流程节点编号等，单份案卷文本长度跨度较大，从数千字符到数万字符不等。

## 这些特征在「模型接入与配置」这一环带来什么约束
国有产业基金的申报材料与案卷特征对模型接入配置带来多重约束。单份案卷文本长度跨度大，从数千到数万字符，要求模型上下文窗口配置适配长文本处理，避免截断核心审批字段。字段包含特定专业单位与国资监管术语，要求模型调用参数适配精准校验需求，避免生成偏差。申报周期集中在窗口期会产生批量并发请求，需配置合理的请求超时参数，避免批量任务中断。部分案卷包含扫描件形式的资质证明，需适配多模态处理配置以支持非结构化文本校验。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | `8000–16000 token` | 适配单份国有产业基金案卷的文本跨度，避免核心审批字段被截断 |
| `maxTokens` | `2000–4000 token` | 满足申报材料审核的详细输出需求，同时控制单轮请求的资源消耗 |
| `temperature` | `0.1–0.3` | 保障审核结果的精准性，避免国资术语与专业字段的生成偏差 |
| `toolChoice` | `auto` | 支持根据审核需求自动调用工具校验资质文件与财务数据，适配案卷审核的多步骤校验逻辑 |
| `vision` | 开启 | 支持扫描件形式的资质证明文件的文本提取与校验，覆盖非结构化案卷的处理需求 |
| `AIPROXY_API_TOKEN` | 按对应模型服务商的密钥填写 | 完成模型接入的身份验证，确保请求合法有效 |

## 容易做错的三处
- 现象：批量审核任务出现`504 Gateway Timeout`报错，或任务长时间无响应。原因：未针对集中申报期的并发请求调整相关参数，导致单轮请求耗时过长超出阈值。
- 现象：工具调用时模型始终使用推理模式，无法限制为仅调用工具。原因：未正确配置`toolChoice`参数，或参数取值不符合模型支持的格式要求。
- 现象：配置第三方模型服务时提示拒绝访问，使用其他接入方式无此问题。原因：未正确填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或密钥权限未覆盖审核所需的模型调用范围。

## 怎么确认配好了
- 上传单份最长的国有产业基金案卷，查看模型输出是否完整包含所有核心审批字段，无明显截断。
- 发起批量测试请求，观察任务执行状态，确认无持续超时或中断情况。
- 提交包含扫描件的资质证明材料，确认模型可正确提取并校验其中的文本信息。
- 检查模型调用日志，确认`toolChoice`参数按配置自动触发工具调用，无异常参数报错。
