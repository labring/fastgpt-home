# 国有资产管理公司的申报材料与案卷审核：模型接入与配置

## 这个品类的数据长什么样
国有资产管理公司的申报材料与案卷审核数据主要来源于内部国资项目申报系统、资产处置档案库、项目审批卷宗。数据更新随单项目申报流程触发，项目办结后归档固化。单份文档通常包含项目编号、资产类别、申报金额、审批节点记录、附件清单等固定字段，单位多涉及万元、评估基准日、建筑面积等专业国资管理场景。

## 这些特征在「模型接入与配置」这一环带来什么约束
项目申报与案卷数据随单项目流程动态更新，要求模型接入环节支持实时关联最新归档的项目文档，避免使用离线固化的知识库副本。单份案卷文档长度较长且包含多字段专业信息，需适配长上下文处理能力，防止截断关键审批节点与资产数据。不同项目的字段组合存在差异，需配置可灵活适配字段提取的模型参数，同时需限制单次处理的文档总规模，避免超出模型负载与系统性能阈值。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单份长案卷文档与关联附件的总内容长度，避免截断核心审批信息 |
| `maxTokens` | 2000–3000 token | 控制单轮模型输出的审核结论长度，适配案卷审核的结构化输出需求 |
| `quoteMaxToken` | 1500 字符 | 限制模型引用的原始文档片段长度，确保引用内容精准且不占用过多上下文 |
| `temperature` | 0.1–0.3 | 降低输出随机性，保障审核结论的一致性与合规性，符合国资管理的严谨要求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写专属接口地址 | 适配国有资产管理系统的内网访问需求，确保数据传输安全 |
| `AIPROXY_API_TOKEN` | 绑定专属权限令牌 | 限制接口调用范围，保障国资项目数据的访问安全 |

## 容易做错的三处
- 现象：模型调用返回403权限错误，原因：未正确配置`AIPROXY_API_TOKEN`，使用了过期或无对应项目权限的令牌。
- 现象：模型输出中混入其他国资项目的无关内容，原因：未限制`maxContext`的上下文范围，加载了非当前审核项目的文档数据。
- 现象：单次审核处理超过预设时长后中断，原因：未合理设置`maxTokens`，模型输出过长超出系统超时限制。

## 怎么确认配好了
- 提交测试用的单份案卷文档，检查模型是否能正确提取项目编号、资产类别等核心字段，核对输出是否包含当前测试项目的专属信息。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`的配置与部署环境匹配，无连接失败记录。
- 调整`temperature`参数后，多次提交相同测试文档，确认输出结论的一致性符合预期。
- 测试长文档输入，检查模型是否能完整处理案卷内容，未出现关键信息截断的情况。
