# 国有资产管理公司的申报材料与案卷审核：知识库检索与召回

## 这个品类的数据长什么样
国有资产管理公司的申报材料与案卷审核数据，来源包括国资监管平台的申报台账、内部审批流转的案卷文档、资产评估机构出具的专项报告、产权登记的纸质档案扫描件等。数据更新随年度国资审计、季度申报批次不定期推进，无固定周期。文档多采用固定模板结构，包含申报主体统一社会信用代码、资产账面值（单位万元）、审批节点签字记录、国资监管编号等字段；部分案卷为多页PDF或PPT格式，内嵌图表与表格内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散在多个内部系统，要求检索需跨多个数据集召回关联内容；文档包含国资监管专属术语与结构化字段，要求检索需同时匹配专业语义与字段信息；长文档与多格式文件并存，要求解析与分块策略适配复杂内嵌内容；更新节奏不定期，要求知识库支持增量同步与批量更新；单份案卷数据量较大，要求召回结果需控制上下文总长度，避免超出模型处理上限。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.85 | 国有资产申报材料存在专属专业术语，需过滤低匹配度的非专业内容，避免无关案卷干扰审核流程 |
| `limit` | 前8–12条 | 单份申报案卷涉及多维度资产信息，需覆盖足够的关联文档，同时控制上下文总长度不超过模型阈值 |
| `searchMode` | `vector` | 需匹配申报材料中的国资编号、评估值等结构化字段与非结构化文本的混合内容，向量检索适配专业术语匹配 |
| `usingReRank` | 开启 | 长文档拆分后可能存在语义分散，重排可提升高相关片段的排序优先级，优化审核检索的准确性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 申报材料常使用国资监管的简称或行业黑话，扩展查询可覆盖更多同义术语，提升召回覆盖率 |
| `collectionIds` | 指定对应国资申报案卷、评估报告的数据集ID | 需隔离非业务相关的知识库内容，避免召回无关文档干扰审核判断 |

## 容易做错的三处
- 现象：上传PPT、PDF格式的国资申报材料时，知识库同步失败，界面显示“文件解析失败”。原因：未开启对应文档格式的解析插件，或文档存在加密、内嵌大量高清图片导致解析超时。
- 现象：批量上传申报案卷时，部分文件转码耗时超过300秒后弹出网络失败提示。原因：单文件体积超过100 MB，或服务器并发上传线程数不足，导致超时中断。
- 现象：本地部署FastGPT v4.9.0版本时，新建知识库无图片理解模型选项。原因：该版本默认未集成图片理解模型插件，需手动安装对应扩展包后才可启用。

## 怎么确认配好了
- 上传1份国资申报PDF文件，查看知识库解析结果是否包含资产明细、审批文号等核心字段，确认格式解析正常。
- 发起包含“国资编号”“评估值”的查询，检查召回结果的`similarity`得分是否在预设的0.72–0.85区间内，确认相似度阈值生效。
- 开启`usingReRank`后，对比重排前后的结果排序，确认高相关文档的位置是否提前，验证重排功能正常。
- 发起查询后，检查返回结果是否包含召回文档的来源标识与片段内容，确认知识库引用内容正常输出。
- 测试批量上传5份以上的申报案卷，确认所有文件均完成解析并同步至对应数据集，确认批量上传功能正常。
