# 国有资本投资公司的申报材料与案卷审核：模型接入与配置

## 这个品类的数据长什么样
数据主要来源于国有资本投资公司内部的项目申报系统、国资监管报备平台及历史案卷归档库。单次申报批次的材料包含结构化申报表单、非结构化文档（如项目可行性报告、资质证明扫描件），案卷则按项目编号、申报主体、审核节点分类归档。文档更新节奏匹配申报周期，常规月度或季度批次更新，历史案卷为归档后定期全量同步。字段包含项目ID、申报金额（单位：万元）、审核状态、提交时间等，部分材料包含多页扫描件与表格类内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源混合的数据结构要求模型接入需同时支持结构化字段解析与非结构化文本、图像内容的处理；申报材料与案卷的长文本属性，要求配置需适配足够的上下文承载能力，避免关键审核信息被截断；申报材料中图像类内容的占比，要求接入支持视觉能力的模型；批次性的更新节奏，要求模型调用的触发逻辑需匹配申报周期，避免无效的实时资源消耗；历史案卷的关联审核需求，要求上下文配置需覆盖足够的历史数据量，保证审核的一致性与准确性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 12000–15000 token | 申报材料与案卷多为长文本，需覆盖完整项目文档及关联历史案卷，避免关键审核信息丢失 |
| `maxTokens` | 2000–3000 token | 审核结果需包含详细判定依据，该取值范围可覆盖完整的审核结论与解释内容 |
| `vision` | `true` | 申报材料常包含扫描版资质文件、财务报表截图，需视觉模型解析图像类内容 |
| `temperature` | 0.1–0.3 | 审核工作需严谨统一，该取值范围可降低输出随机性，保证判定标准一致 |
| `AIPROXY_API_ENDPOINT` | 对应千问72B VL模型的官方接入地址 | 需调用视觉大模型解析图像类申报材料，需配置正确的模型服务端点 |
| `AIPROXY_API_TOKEN` | 申请获取的专属服务密钥 | 保证模型调用的身份验证与权限控制，避免未授权访问 |

## 容易做错的三处
- 现象：上传带扫描件的申报材料后，模型未解析图像内容，仅返回文本审核结果。原因：未将`vision`参数配置为`true`，或未绑定支持视觉能力的模型服务。
- 现象：审核结果仅包含`<think>`标签包裹的内容，无最终判定输出。原因：`maxTokens`取值过低，无法容纳完整的输出内容，或模型调用配置中未开启完整结果返回开关。
- 现象：模型调用日志返回401状态码，提示身份验证失败。原因：`AIPROXY_API_TOKEN`配置错误，未填写正确的专属服务密钥，或密钥已过期失效。

## 怎么确认配好了
- 上传单份包含扫描件的申报材料，查看模型是否能正确解析图像内容并生成完整的审核意见。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置无格式错误，未出现401、404等异常状态码。
- 测试多批次申报数据的批量调用，确认`maxContext`与`maxTokens`的配置未导致输出截断或内容缺失。
- 检查最终输出结果，确认`<think>`标签已被自动隐藏，仅保留清晰的审核结论与依据。
