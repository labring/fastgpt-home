# 国有资本运营公司的申报材料与案卷审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
数据主要来自国资监管报送系统、内部项目管理档案及申报主体提交的电子材料。更新节奏随单个申报项目流程推进，审核完成后转为归档静态数据。文档结构包含结构化元数据与附件包，元数据字段含项目唯一标识、申报主体统一社会信用代码、审核节点状态、材料总大小，附件包含PDF扫描件、Excel表单等，字段单位统一遵循国资系统公示的规范格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 接口超时时间 | 600 秒 | 适配单份大附件的传输与审核解析时长 |
| `Authorization` | 固定服务账号密钥 | 匹配国资系统的权限校验规则，避免未授权访问 |
| `variables` | 绑定项目编号变量 | 实现按单个申报项目拉取对应案卷数据 |
| 大文件上传阈值 | 1000 MB | 覆盖国有资本运营公司常见的申报材料附件上限 |
| `responseData` | 仅返回结构化审核字段 | 减少无效数据传输，提升接口调用效率 |
| 请求重试次数 | 3 次 | 应对临时网络波动，避免单次调用失败 |

## 容易做错的三处
- 调用接口返回跨域拦截报错，状态码显示CORS相关异常。原因：未配置接口允许的调用域名白名单，未开启跨域请求适配。
- 接口调用返回`401 Unauthorized`，或FastGPT测试时提示权限不足。原因：`Authorization`参数配置的服务账号密钥未通过国资系统的权限校验。
- 上传大型申报案卷时提示传输失败，文件上传进度中断。原因：未调整大文件上传阈值，或未配置适配大文件的接口超时设置。

## 怎么确认配好了
- 调用配置好的接口，传入测试用的项目编号，检查返回的`responseData`是否包含预期的结构化元数据字段。
- 使用FastGPT v4.17.0的接口测试工具，携带正确的`Authorization`参数发起请求，确认返回状态码为200。
- 上传单份体积符合业务上限的测试材料，检查接口是否能正常接收并返回处理结果。
- 配置`variables`绑定的项目变量，发起多次调用，确认每次调用仅拉取对应项目的案卷数据。
