# 基础化工的申报材料与案卷审核：模型接入与配置

## 这个品类的数据长什么样
基础化工的申报材料与案卷审核数据，主要来自企业内部审批流转系统、属地化工监管部门备案存档。数据包含结构化字段与非结构化技术说明，结构化字段涵盖项目名称、生产规模、原料配比、安全评价编号等，非结构化部分包含环评报告、工艺流程图说明、合规自查文件等。数据更新随申报批次或季度备案周期推进，单份案卷或申报材料的文本长度跨度较大，涉及质量、压力、体积等标准计量单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
基础化工场景的申报材料与案卷包含大量专业技术文本与结构化合规字段，要求模型接入配置宜适配长上下文处理、专业术语匹配与合规字段精准关联。长文本技术说明会增加检索分块数量，拉长整体响应时长，宜调整上下文容纳参数；结构化字段的精准匹配要求检索工具优先关联固定字段，避免无关内容干扰；监管相关的审核逻辑宜保持严谨的输出风格，同时宜适配专属API节点以保障数据传输合规。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 基础化工申报材料常包含长段工艺说明与多页案卷，宜容纳足够上下文以关联专业参数与审核逻辑 |
| `maxTokens` | 2000–3000 token | 审核回复需覆盖合规判断与技术说明，避免截断关键结论或参数 |
| `quoteMaxToken` | 1500–2000 字符 | 案卷引用需保留完整技术片段，避免拆分原料配比、压力值等核心专业信息 |
| `toolChoice` | auto | 宜自动触发案卷检索工具，精准匹配申报材料中的合规字段与审核要求 |
| `temperature` | 0.1–0.3 | 审核需保持严谨风格，避免生成偏离合规要求的主观判断内容 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写专属节点 | 适配基础化工场景的合规数据传输要求，降低跨区域调用延迟 |

## 容易做错的三处
- 知识库搜索超时40秒：现象为检索返回超时提示或状态码504，原因是未调整`maxContext`适配长文档，导致分块数量过多拉长检索耗时。
- oneapi调用参数未生效：现象为配置的`temperature`未生效，回复仍存在随机波动，原因是未正确绑定专属`AIPROXY_API_TOKEN`，使用了默认共享密钥。
- 网页调试与飞书接入结果不一致：现象为网页调试返回精准合规结论，飞书接入返回模糊答案，原因是飞书接入场景未配置`toolChoice`为auto，未自动触发案卷检索工具。

## 怎么确认配好了
- 上传一份典型基础化工申报案卷，检查检索返回的引用片段是否包含完整的原料配比、安全评价编号等结构化字段。
- 发起审核请求，查看FastGPT v4.17.0的调用日志，确认`maxContext`的实际调用值符合配置区间。
- 测试不同`temperature`参数的回复差异，确认输出风格随设置发生对应变化。
- 检查API调用日志，确认`AIPROXY_API_TOKEN`已正确携带在请求头中。
