# 大宗商品贸易的申报材料与案卷审核：知识库检索与召回

## 这个品类的数据长什么样
大宗商品贸易的申报材料与案卷审核数据，主要来源为贸易合同、报关单、质检报告、仓单及资金结算凭证。数据更新随单笔贸易业务节点触发，单份申报材料在审核完成后归档更新，案卷则按月度批次整合归档。单份文档多为多页PDF或结构化表格，包含货物品名、HS编码、交易数量、结算金额、报关口岸等字段，数量单位多为吨、立方米，金额单位为人民币或美元，单案卷关联材料数可达数十份。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据特征对检索召回带来四项核心约束。其一，包含HS编码、交易数量等专业结构化字段，需支持字段级精准匹配，避免泛化召回无关材料；其二，单案卷关联数十份关联材料，召回结果需按案卷维度聚合，避免单份材料重复返回；其三，数据随单笔业务节点更新，知识库需支持增量同步更新，无需全量刷新即可覆盖最新申报材料；其四，存在吨、立方米等多类数量单位，检索时需关联单位字段校验，提升匹配准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.72–0.85` | 大宗商品申报材料包含专业术语，阈值过低会引入无关材料，过高则无法召回匹配度足够的合规材料，适配FastGPT v4.17.0版本的参数规则 |
| `limit` | `前12–18条` | 单案卷关联材料较多，需召回足够覆盖关联项的结果，同时避免上下文超出模型处理上限 |
| `searchMode` | `vector+keyword` | 兼顾专业术语的语义匹配与HS编码等结构化字段的精准匹配，提升召回全面性 |
| `usingReRank` | `开启` | 申报材料相似度较高，重排可过滤语义接近但业务无关的结果，提升检索准确性 |
| `datasetSearchUsingExtensionQuery` | `开启` | 可将申报关键词扩展为包含HS编码、贸易主体的扩展查询，匹配更精准的案卷材料 |
| `collectionIds` | `绑定对应大宗商品贸易案卷知识库的集合ID` | 限定检索范围至专用知识库，避免混入其他品类的无关数据 |

## 容易做错的三处
- 现象：导入结构化申报材料的CSV文件后，中文字段出现乱码。原因：未在导入环节指定UTF-8编码格式，或本地源文件编码与导入配置不匹配。
- 现象：调用检索接口时返回无权限访问的报错，鉴权参数配置无误。原因：未将检索节点绑定至对应业务角色的权限组，或`collectionIds`配置包含未授权的知识库集合。
- 现象：在线对话可召回指定案卷材料，API调用时未返回对应结果。原因：API调用未传递与当前业务关联的变量参数，导致`datasetSearchUsingExtensionQuery`无法生成精准扩展查询。

## 怎么确认配好了
- 上传单份大宗商品报关单CSV文件，检查导入后的字段显示是否完整，中文无乱码。
- 在检索节点配置界面，确认`collectionIds`已绑定对应业务的知识库集合，无多余集合混入。
- 发起测试检索，输入包含HS编码的关键词，检查召回结果是否按案卷维度聚合，无重复材料。
- 调用API接口，传递与在线对话一致的上下文变量，对比返回结果与在线对话的匹配度。
