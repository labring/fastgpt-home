# 成品油销售的申报材料与案卷审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
成品油销售的申报材料与案卷审核数据主要来源于加油站销售台账、增值税开票记录、油品质检报告及线下审批表单。数据更新节奏分为实时与批量两类，单笔申报提交后即时更新，批量月度汇总申报按固定周期同步。文档结构包含申报主体统一社会信用代码、油品品类编码、销售数量（单位为升或吨）、结算单价、审批节点流转记录、质检报告编号等字段，部分字段需匹配石油石化行业的国标编码规则。本页面基于FastGPT v4.17.0版本编写。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
成品油销售申报数据的国标编码要求，要求外部接口需预先配置编码校验规则，避免传入不符合行业标准的品类或编号。实时更新的申报数据要求HTTP接口配置较短的超时阈值，确保单笔请求的响应速度匹配业务审批节奏。批量月度申报的大体积案卷数据，要求接口支持分段传输或分块上传，避免单次请求超出负载限制。不同业务场景下的单位差异（升、吨），要求接口参数需明确指定单位字段，防止数据解析错误。审批节点的流转记录需同步至外部系统，要求接口支持携带多状态变更的时间戳参数。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {企业API密钥}` | 符合石油石化行业接口鉴权的通用规范，确保外部系统的访问权限可控 |
| `variables` | `{"unit": "升", "standard_code": "GB 17930-2016"}` | 匹配成品油销售的单位与行业标准编码，确保数据传递的一致性 |
| `responseData` | `仅返回审批状态与校验结果` | 精简返回内容，适配案卷审核的轻量同步需求，减少网络传输负载 |
| 请求超时时间 | `30-60 秒` | 适配单笔申报数据的处理时长，避免因审批流程中的人工干预导致超时 |
| 分块上传阈值 | `1000 MB` | 匹配批量案卷数据的最大单包传输上限，符合多数外部存储系统的配置要求 |
| 编码校验开关 | 开启 | 防止传入不符合国标编码的油品品类数据，降低外部系统的校验成本 |

## 容易做错的三处
- 现象：调用接口时返回`403 Forbidden`状态码。原因：未正确配置`Authorization`参数，使用了过期或无权限的API密钥，无法通过外部系统的鉴权校验。
- 现象：外部系统无法获取上传案卷的二进制数据，仅收到空字段。原因：未在接口配置中开启二进制数据流传输，导致`responseData`参数未正确返回文件的二进制内容。
- 现象：批量申报时接口频繁超时。原因：未配置分块上传阈值，单次传输的案卷数据体积超出接口负载上限，触发超时机制。

## 怎么确认配好了
- 发送一条符合国标编码的测试申报数据，检查`responseData`返回的校验结果是否符合预期。
- 查看接口调用日志，确认`Authorization`参数被正确携带且未被篡改。
- 模拟批量传输大体积案卷数据，确认接口未触发超时错误。
- 对比外部系统接收到的字段与本地申报数据的字段，确认单位与编码字段匹配。
