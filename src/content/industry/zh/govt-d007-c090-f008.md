# 成品油销售的申报材料与案卷审核：文档解析与分块

## 这个品类的数据长什么样
成品油销售的申报材料与案卷审核数据主要来源于加油站进销存台账、合规审批单、增值税发票存根、专项检查案卷等。数据更新节奏随申报周期而定，日常零售申报按日更新，季度与年度合规案卷在项目办结后归档。文档形态包含结构化Excel表格（含多列字段）、PDF格式审批文件，字段涵盖油品品类、销售数量、营收金额、审批节点、检查结果等，单位涉及升、吨、元、万元等。

## 这些特征在「文档解析与分块」这一环带来什么约束
多列结构化Excel文档会带来字段识别混乱的问题，若分块逻辑未适配多列结构，易导致跨列数据拼接错误。PDF审批单中的嵌套表格、手写批注会增加解析难度，若未启用增强解析，可能丢失关键审批节点信息。按申报周期更新的批量文档，需适配固定字段结构的分块规则，避免因字段顺序变化导致检索匹配失效。批量案卷文件的大小差异较大，需设置合理的解析与分块参数，防止超时或分块不完整。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配成品油申报材料中多列表格与审批文本的混合结构，避免单块内容跨页或跨字段 |
| `chunkSplitter` | 按段落与表格边界拆分 | 适配文档中既有连贯审批说明又有多列数据表格的结构，保留数据关联性 |
| `customPdfParse` | 启用mineru增强解析 | 适配PDF审批单中的嵌套表格与手写批注，提升结构化字段提取准确率 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配批量案卷与大型进销存台账的上传需求，避免大文件上传失败 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 适配大型案卷文件的解析耗时，防止因解析超时导致任务失败 |
| `chunkSettingMode` | 手动配置 | 适配成品油文档的混合结构，可灵活调整分块规则与解析参数 |

## 容易做错的三处
- 现象：上传多列结构化Excel文件后，仅识别前两列数据，其余列字段丢失。原因：未将`chunkSplitter`配置为按表格边界拆分，默认分块逻辑仅提取连续文本，未适配多列表格结构。
- 现象：调用`customPdfParse`启用mineru增强解析后，PDF中的审批签字字段无法被正确提取。原因：未在系统中配置mineru API的访问密钥，导致增强解析功能未正常生效。
- 现象：解析后的boolean类型字段进入条件判断组件后变为空值。原因：未在数据映射环节将解析出的boolean类型字段转换为可识别的格式，组件无法读取非标准布尔值导致丢失。

## 怎么确认配好了
- 上传一份典型的成品油进销存Excel表格，查看解析后的字段列表，确认所有列的字段均被正确识别。
- 上传一份包含嵌套表格的PDF审批单，检查解析结果中是否保留了所有表格内容与审批节点信息。
- 上传一份超过预设大小的大型案卷文件，确认解析任务在预设的超时时间内完成，未出现超时报错。
- 配置条件判断组件对接解析后的boolean字段，执行测试用例，确认组件可正常读取并处理该字段值。
