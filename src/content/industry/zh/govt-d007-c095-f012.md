# 新能源开发的申报材料与案卷审核：部署与升级

## 这个品类的数据长什么样
新能源开发的申报材料与案卷审核数据，主要来源于项目立项申请、国土空间预审意见、环境影响评价报告、并网验收文件等官方审批文档。数据更新节奏随项目审批节点推进，单次审批周期内更新1至3次。单份文档多为10至50页的PDF或Word格式，包含项目名称、建设地点、装机容量（单位MW）、总投资（万元）、申报主体、审批进度等固定字段，部分案卷会附带现场勘测照片与卫星影像附件。

## 这些特征在「部署与升级」这一环带来什么约束
新能源开发申报材料单份体积较大且包含多类型附件，部署时需预留足够的文件存储与解析资源。数据字段包含带固定单位的数值型内容，升级数据库时需确保字段类型与单位校验规则兼容。项目审批的阶段性更新要求部署的同步任务支持增量拉取与版本留存，避免全量重复处理。多部门协同的案卷流转需要配置跨节点的权限与数据同步规则，升级时需保留原有权限配置的兼容性。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150 个连接` | 适配单份长文档解析时的数据库连接并发需求，避免连接耗尽 |
| `MONGODB_URI` | `mongodb://username:password@host:port/dbname?authSource=admin` | 存储案卷的元数据与审批记录，需配置认证信息保障数据安全 |
| `STORAGE_S3_ENDPOINT` | `https://s3-cn-beijing.volces.com`（或对应私有存储节点地址） | 存储申报材料的PDF、影像等大体积附件，适配多类型文件的存储需求 |
| `REDIS_URL` | `redis://:password@host:port/0` | 缓存解析后的文档分片与审批状态，提升检索响应速度 |
| `FE_DOMAIN` | `https://fastgpt.your-domain.com` | 配置前端访问域名，适配内部审批系统的对接需求 |
| `ROOT_KEY` | `自定义复杂字符串` | 配置系统最高权限密钥，保障部署后的初始权限安全 |

## 容易做错的三处
- 现象：镜像拉取超时或提示`manifest unknown`错误。原因：使用了非官方的FastGPT镜像标签，或未配置国内镜像加速源适配网络环境。
- 现象：导入申报材料后字段缺失或单位校验失败。原因：未配置对应字段的格式校验规则，导致数值型字段未按MW、万元等单位完成格式转换。
- 现象：导入审批插件时提示`internal server error`。原因：升级后未同步更新插件依赖的环境变量配置，导致插件与当前系统版本不兼容。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`MONGODB_URI`与`REDIS_URL`配置的连通性，确认连接数未超过`DB_MAX_LINK`的限制。
- 上传一份新能源开发申报材料的示例文档，触发解析流程，确认附件可正常存储至`STORAGE_S3_ENDPOINT`对应的存储节点。
- 访问`FE_DOMAIN`配置的前端地址，验证页面可正常加载且无资源加载失败提示。
- 配置增量同步任务，上传一份更新后的案卷材料，确认系统可识别版本差异并完成增量处理。
