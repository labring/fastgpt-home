# 油气勘探开发的申报材料与案卷审核：HTTP 接口与外部系统

仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这个品类的数据长什么样
油气勘探开发的申报材料与案卷审核数据主要来源于现场勘探采集系统、钻井工程数据库、储量评审档案库。单份案卷包含勘探井号、测井深度、岩芯样本数据、油气储量估算值、审批流程节点记录等内容，更新节奏随单井作业完成实时更新，项目结题时批量归档。数据字段多附带物理单位，测井深度以米为单位，油气储量估算以万吨为单位，文档常附带高清岩芯扫描件或结构化地质报表附件。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多源异构的数据来源要求接口支持跨系统数据拉取与多格式适配，需兼容不同业务系统的鉴权规则。实时与批量结合的更新节奏，要求接口同时支持单次小批量请求与批量任务提交模式。复杂的文档结构与带单位的字段要求，需在接口层完成字段格式校验与单位一致性校验，避免数据流转错误。附带的大体积附件则要求接口支持分段上传与大文件传输配置，适配油气勘探数据的存储需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 鉴权方式 | 携带`Authorization`头的Bearer Token认证 | 符合油气勘探系统的内部安全访问规范，保障接口调用权限 |
| 请求超时时间 | 600 秒 | 适配单份案卷数据的完整处理周期，避免因数据量大导致请求中断 |
| 单文件上传上限 | 1000 MB | 匹配岩芯扫描件、高清地质报告等附件的常见体积范围 |
| 响应数据提取配置 | 从`responseData`字段提取核心案卷数据 | 精准获取业务所需的审核结果信息，避免冗余数据流转 |
| 变量映射配置 | 将接口返回的`variables`字段映射为案卷审批状态 | 实现接口数据与外部审批系统的字段对齐 |
| 跨域白名单配置 | 添加油气勘探前端业务系统的域名 | 允许指定业务域名发起跨域请求 |

## 容易做错的三处
- 现象：使用fetch api调用接口时触发跨域拦截，控制台显示CORS相关报错。原因：未在跨域白名单配置中添加油气勘探业务系统的前端域名，导致请求被浏览器拦截。
- 现象：上传文件名长度超过200字符时返回400错误。原因：接口未对上传文件名进行长度校验或转义处理，超出操作系统文件路径的字符限制。
- 现象：调用接口后返回的`responseData`字段为空，无法获取案卷审核结果。原因：未正确配置响应数据提取规则，未关联到油气勘探案卷的核心业务字段。

## 怎么确认配好了
- 发起一次携带`Authorization`头的测试请求，检查返回的响应头中包含正确的跨域允许头。
- 上传不同长度的测试文件，验证文件名在合理范围内时可正常提交，超过限制时返回明确的错误提示。
- 调用接口后查看`responseData`字段，确认包含勘探井号、测井深度等油气勘探专属字段。
- 配置回调地址后，触发一次案卷审核流程，确认外部系统能收到正确的回调通知。
