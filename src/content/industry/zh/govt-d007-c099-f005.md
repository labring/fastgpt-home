# 油气勘探开发的申报材料与案卷审核：工具调用与插件

## 这个品类的数据长什么样
这个品类的数据主要来源于勘探作业产出的钻井日志、储量评估报告、行政审批案卷等原始文件，更新节奏随勘探项目节点或年度储量复盘推进。单份文档结构包含勘探区块编号、井号、孔隙度、渗透率等地质参数，以及申报批次、审核状态、审批意见等流程字段，参数单位遵循石油石化行业标准，单份文档长度跨度较大，部分专项案卷可达到数万字符规模。

## 这些特征在「工具调用与插件」这一环带来什么约束
地质参数的专属单位与字段要求，要求工具调用时需内置行业标准参数校验逻辑，避免因单位不匹配导致审核结果偏差。文档长度跨度大的特征，要求插件需支持分批拉取长文本数据，避免单次调用超出上下文限制。数据源分散在作业系统与审批卷宗中，工具调用需适配多源数据的接口对接，同时需遵循国央企内部的数据权限规则，仅允许授权角色触发对应工具。此外，申报材料的版本唯一性要求，工具需支持校验文档的最新版本标识，避免调用过期数据。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` 或 绑定「油气案卷校验」专属函数 | 支持自动匹配审核场景所需工具，或固定调用预设的行业专属工具函数 |
| `functionCall` | `strict: true` | 强制模型仅调用指定工具，避免生成无关内容，适配油气审核的严谨性要求 |
| 工具调用超时时间 | `300–600 秒` | 油气申报材料通常包含多份长文档，完整拉取与校验需较长时间，该区间可覆盖多数常规场景 |
| 单次调用文档条数 | `前 3–5 条` | 避免单次调用数据量过大导致接口异常，同时保证审核所需的案卷样本充足 |
| 参数校验开关 | 开启 | 油气行业参数有固定单位与取值范围，开启校验可提前拦截错误数据 |

## 容易做错的三处
- 调用工具时返回413状态码，界面提示请求体超出限制。原因：单次调用拉取的油气案卷文档数量过多，或单份申报材料的长度超出接口允许的最大请求体规格。
- 使用qwen3模型时，工具调用后仍生成非工具调用的推理内容，无法限制模型仅使用工具调用模式。原因：未正确配置`functionCall`的严格模式，模型默认推理优先级高于工具调用触发规则。
- 工具调用的中间步骤直接展示在最终审核结果中，未做隐藏处理。原因：未开启工具调用过程隐藏的配置项，或配置项取值不符合场景需求。

## 怎么确认配好了
- 触发一次测试审核，查看工具调用的返回结果是否包含油气专属参数的校验信息，确认参数校验开关生效。
- 提交一份超出常规长度的申报材料，检查工具调用是否触发异常，确认超时时间配置匹配当前场景的文档处理需求。
- 切换至qwen3模型发起测试，确认工具调用仅生成符合要求的函数调用指令，无额外推理内容，确认工具调用模式配置生效。
- 查看工具调用的日志记录，确认单次调用拉取的文档条数符合预设的场景需求，确认调用条数配置生效。
