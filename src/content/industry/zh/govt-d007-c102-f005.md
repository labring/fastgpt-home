# 炼化生产的申报材料与案卷审核：工具调用与插件

## 这个品类的数据长什么样
数据主要来自炼化装置运行台账、安全合规申报文件、质检分析报告及案卷归档审批记录。来源覆盖生产环节的实时采集数据与事后归档的审批文档，更新节奏随单次申报周期或月度归档节点推进。文档结构包含装置编号、物料批次、原料消耗量、产品收率、安全检测项、审批流程节点等字段，单位多采用吨、立方米、小时、兆帕、摄氏度等工业标准计量单元。

## 这些特征在「工具调用与插件」这一环带来什么约束
炼化生产的申报材料与案卷数据包含多字段工业计量单元，要求工具调用时需严格匹配预设字段名与单位规则，避免参数解析错误。数据来源涵盖实时采集的运行数据与归档的审批文档，插件需同时支持实时API调用与静态文档解析两种模式。单份案卷或申报材料篇幅较长，可通过`toolChoice`配置自动适配长文本处理需求，且需针对结构化台账与半结构化审批记录分别配置解析规则。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配炼化申报材料中结构化台账与半结构化审批记录混合的场景，自动选择适配的工具调用逻辑 |
| `functionCall` | 开启 | 需要工具调用读取台账字段与案卷审批节点，强制触发函数调用以保证参数解析的准确性 |
| 工具调用超时时间 | 300–600 秒 | 炼化数据查询可能涉及多节点台账汇总，需预留足够的响应时长，按实测标定调整区间 |
| 工具调用返回条数上限 | 前 10 条 | 单份申报材料涉及的台账与案卷条目较多，限制返回条数避免上下文溢出 |
| 字段匹配阈值 | 0.95 | 炼化字段名称具有强工业规范性，需较高匹配度避免错配物料批次、能耗单位等关键信息 |

## 容易做错的三处
- 现象：工具调用返回结果为空，或返回的字段与申报材料的预设字段不匹配。原因：未匹配炼化申报材料的专属字段名，仅使用通用字段关键词检索，导致无法定位物料批次、能耗数据等核心内容。
- 现象：调用工具时返回400状态码，日志显示参数格式校验失败。原因：请求参数中携带了不符合工业计量规范的单位，例如将“吨”误写为“升”，触发接口校验规则拦截。
- 现象：工作流中工具调用环节超时中断，界面显示请求超时提示。原因：未配置适配长案卷的超时时间，单份申报材料的多节点数据查询超出默认超时限制。

## 怎么确认配好了
- 手动触发工具调用，输入一份已知字段的炼化申报材料样本，核对返回结果是否包含预设的装置编号、物料批次等字段。
- 查看工具调用日志，确认请求参数中的单位与字段名符合炼化工业标准，无格式错误。
- 模拟单次申报的全流程调用，检查工具调用环节是否能正确衔接台账数据与案卷审批记录的读取。
- 调整工具调用的超时时间，测试长文本案卷的调用是否能正常完成，无中断报错。
