# 煤化工的申报材料与案卷审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
煤化工申报材料与案卷审核的数据主要来自企业生产台账、环评审批档案、安全验收文档及月度产能报表。数据更新节奏按申报周期划分，月度常规申报为每月更新，重大项目案卷为立项后按需更新。单份申报文档包含项目编号、煤种品类、产能规模、污染物排放指标、审批节点记录等字段，单位涵盖吨、立方米、毫克每立方米，部分案卷附带结构化Excel附件与PDF扫描件。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
煤化工申报材料与案卷审核的数据特征对HTTP接口带来多重约束。多来源的混合格式数据要求接口兼容PDF、Excel等多种输入格式，需内置基础格式校验逻辑。分周期的更新节奏要求接口支持定时调用与手动触发两种调用模式，适配月度常规申报与临时项目案卷的不同场景。特定字段与单位要求接口需对产能、污染物指标等字段做单位校验，避免传入不符合煤化工行业规范的数值。大体积案卷附件则要求接口支持分片上传机制，防止单次请求超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 认证方式 | `Authorization` 头携带Bearer令牌 | 符合工业系统接口的通用安全规范，适配国央企内部权限管控要求 |
| 请求超时时间 | 600 秒 | 煤化工案卷文件体积较大，常规申报材料解析需较长处理时间 |
| 响应数据格式 | JSON | 便于外部系统解析申报结果与审核状态字段 |
| 变量映射规则 | 绑定项目编号、煤种类型为固定入参 | 匹配煤化工申报材料的核心标识字段，减少重复录入 |
| 重试触发条件 | 响应状态码为5xx且重试间隔不超过30 秒 | 适配外部系统偶发波动，避免频繁重试加重服务器负担 |
| 最大重试次数 | 3 次 | 平衡接口稳定性与资源消耗，符合国央企系统的运维规范 |

## 容易做错的三处
- 现象为接口返回状态码400，且报错文案包含“字段格式非法”。原因是未对煤化工申报材料的产能、污染物指标字段做单位校验，传入了不符合行业规范的数值单位。
- 现象为单次接口调用耗时超过预设阈值后触发超时错误。原因是请求超时时间设置过短，未适配煤化工大体积案卷文件的解析时长。
- 现象为外部系统接收的`responseData`字段为空。原因是未正确配置响应数据提取规则，未关联到审核结果的核心业务字段。
