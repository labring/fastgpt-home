# 煤化工的申报材料与案卷审核：工具调用与插件

## 这个品类的数据长什么样
煤化工申报材料与案卷的数据主要来自国央企煤化工项目的立项申请、安全预评价报告、环保验收材料、月度生产申报报表及归档案卷。数据来源涵盖企业内部生产台账与外部政务审批公文，更新节奏分为项目启动时的一次性批量导入，与月度/季度的周期性更新。单份文档包含项目编号、企业名称、装置类型、产能数据、审批文号等固定字段，产能单位多为吨/年、立方米/小时，单份案卷由多份异构文档组合而成。

## 这些特征在「工具调用与插件」这一环带来什么约束
煤化工申报材料的固定字段与专用单位要求，要求工具调用插件需内置字段校验规则，避免提取的产能数值与吨/年等预设单位不匹配。多份异构的案卷结构，要求插件支持批量读取PDF、Excel台账等不同格式的文档，并统一输出结构化数据。周期性的更新节奏，要求工具的数据源配置需支持按固定周期拉取最新台账，适配月度申报的业务流程。长篇幅的环评类材料，要求工具调用的上下文处理需适配长文本，避免截断关键审批条款。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配多工具调用场景，自动匹配申报材料校验、数据库查询等工具 |
| `functionCall` | `enabled` | 强制触发结构化工具调用，确保申报字段提取的格式一致性 |
| 数据源同步周期 | 每月1日 0点 | 匹配煤化工月度生产申报的固定更新节奏 |
| 文档解析分块长度 | 800–1200 字符 | 适配长篇幅环评报告的分段处理，避免关键条款截断 |
| 错误重试次数 | 3 次 | 应对国央企审批系统接口的偶发波动 |

## 容易做错的三处
- 现象：调用字段提取工具时返回“单位不匹配”报错，手动核对原文后发现产能数值未携带预设单位，原因：未在配置中指定煤化工专用字段的单位校验规则，导致提取结果与业务要求不符。
- 现象：调用数据库工具时传入变量后执行失败，手动执行SQL语句正常，原因：未将申报材料中的项目编号作为参数绑定到SQL语句的变量位，导致变量未正确替换。
- 现象：工作流中无法调用数据库工具，连接状态显示异常，原因：未将煤化工专用的数据源配置绑定到工作流节点，导致工具无法访问企业内部台账数据库。

## 怎么确认配好了
- 手动传入单份煤化工申报材料的样本，检查工具提取的项目编号、产能数据是否与原文一致。
- 触发一次定时同步任务，检查数据源是否成功拉取最新的台账数据。
- 模拟偶发接口波动，测试工具调用的重试机制是否生效。
- 检查工具调用日志，确认所有字段的校验规则已正确应用。
