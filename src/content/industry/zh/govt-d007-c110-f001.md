## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
矿山采选申报材料与案卷的文档长度跨度大、专属字段多，首先要求HTTP接口的请求体上限需适配5000字符以上的单份文档，避免截断关键内容。专属计量字段要求接口参数校验规则需匹配万吨/年、平方公里等采矿行业单位，否则会导致参数校验失败。节点式的更新节奏要求接口触发逻辑绑定项目立项、年度审核等明确事件，不宜设置高频自动调用。同时，案卷材料涉及采矿安全与产能信息，要求接口的`Authorization`校验需绑定专属角色权限，防止未授权访问。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | 携带采矿行业专属的服务账号令牌 | 匹配矿山采选系统的权限校验规则，防止未授权访问 |
| `variables` | 预设项目编号、矿种类型为固定变量 | 适配申报材料的批量提交场景，减少重复参数录入 |
| `responseData` | 解析返回字段中的审核状态、备案编号 | 直接提取案卷审核的核心结果，无需二次处理 |
| 请求超时时间 | 60-120秒 | 适配大型申报材料的解析与传输时长，避免超时中断 |
| 文件上传大小限制 | 1000 MB | 容纳单批次矿山地质勘探报告的完整附件 |

## 容易做错的三处
- 现象：调用文件上传接口后智能体后端进程卡死，接口返回200状态码但无响应结果。原因：未限制单批次上传文件的总大小，矿山采选的地质勘探报告附件体积较大，超出系统默认内存处理阈值。
- 现象：接口校验失败返回403状态码，无法提交申报材料。原因：未使用`Authorization`参数携带专属服务令牌，使用了通用API密钥。
- 现象：解析`responseData`时丢失核定产能字段。原因：未在`variables`中预设矿种与产能的关联变量，导致接口返回字段映射错误。

## 怎么确认配好了
- 调用测试接口提交一份标准矿山申报材料，检查`responseData`是否返回了预期的审核状态与备案编号。
- 查看接口日志，确认`Authorization`参数已正确携带且未触发权限校验失败。
- 上传单份矿山地质勘探报告附件，验证接口未出现超时或进程卡死情况。
- 调整`variables`中的项目编号变量，提交测试数据，确认参数替换生效。
