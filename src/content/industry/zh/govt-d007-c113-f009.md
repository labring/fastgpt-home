# 船舶制造的申报材料与案卷审核：模型接入与配置
本文基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
船舶制造的申报材料与案卷，主要来源于船舶建造项目的设计文档、船级社检验报告、企业内部生产台账及合规申报文件。更新节奏随项目建造节点推进，初步设计、详细设计、完工检验等阶段均会产生新的材料。文档包含结构化申报书、二维/三维图纸文本、资质证书与检验记录，字段涵盖船型编号、建造批次号、材料牌号、船体尺寸（毫米）、排水量（吨）、检验日期等专业信息。

## 这些特征在「模型接入与配置」这一环带来什么约束
专业字段与图纸文本的组合，要求模型能识别船舶制造领域的专业术语与结构化信息，需适配高精度的向量模型与支持视觉解析的能力。按项目节点更新的批量文档，要求配置支持增量同步与大上下文加载，避免单次导入数据溢出限制。内网部署的企业环境，无法访问公网模型服务，需配置内网模型的接入参数。申报材料的合规审核要求，需严格控制模型输出的严谨性，避免生成偏差内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 船舶申报材料包含多份文档片段，需容纳足够的上下文以覆盖核心审核内容 |
| `maxTokens` | `4096 token` | 控制单次模型输出的长度，避免超出模型接口的限制 |
| `temperature` | `0.1–0.3` | 合规审核需严谨的输出逻辑，避免模型生成偏离事实的内容 |
| `quoteMaxToken` | `2000–3000 token` | 需提取足够的案卷原文作为审核依据，确保匹配内容的完整性 |
| `vision` | `enabled` | 申报材料包含船体结构图纸等视觉类文档，需支持图像解析能力 |
| `AIPROXY_API_ENDPOINT` | 内网部署模型的API地址 | 企业内网无法访问公网，需配置内网模型的接入端点 |

## 容易做错的三处
- 现象：调用模型返回`error`提示，日志显示获取数据异常。原因：未正确配置`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`，或参数填写错误，导致无法连通指定的模型服务。
- 现象：模型调用超时，返回连接失败状态码。原因：FastGPT服务器处于内网环境，未适配内网模型的接入配置，错误使用公网模型的接入参数，无法完成请求转发。
- 现象：审核结果未匹配到关键案卷字段，匹配精度不足。原因：`temperature`取值过高，模型生成内容偏离严谨的审核逻辑，或`maxContext`配置过小，未完整加载申报材料的核心内容。

## 怎么确认配好了
- 测试内网模型的连通性，发起一次测试调用，核对返回结果是否符合预期，调整`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`直至调用成功。
- 上传一份典型的船舶申报材料，触发审核流程，核对返回的上下文是否包含完整的材料内容，调整`maxContext`和`quoteMaxToken`直至覆盖核心文档片段。
- 导入一份带船体图纸的申报材料，核对模型是否能解析图纸中的专业信息，确认`vision`配置已开启且模型支持视觉解析。
- 查看模型调用日志，确认返回内容包含思维链相关字段，核对模型是否支持并开启了思维链输出功能。
