# 不动产登记的业务办理流程引导：知识库检索与召回

本文所有配置示例基于FastGPT v4.17.0版本。

## 这个品类的数据长什么样
不动产登记业务的核心数据来自不动产登记信息系统、地籍调查数据库、房屋交易网签系统、税务系统、电子证照库，更新频率为每日。日常涉及的文档包含登记申请书、权属证明、测绘成果、税费凭证、不动产权证书、登记簿等，文档结构涵盖权属主体信息、测绘参数、税费明细、权利限制状态等字段，无统一固定的单文档格式，部分文档为结构化字段，部分为非结构化文本。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源多且异构，要求检索需适配不同格式的文档内容，避免因格式差异遗漏关键信息；每日更新的频率要求检索覆盖最新的登记数据，确保业务办理的时效性；核心业务为不动产权利确认，要求召回内容精准命中权属来源、限制状态、测绘比对等核心字段，避免无关内容干扰核验流程；出错后果直接关联登记错误与产权纠纷，要求检索的置信度需满足业务合规要求，不能引入低匹配度的内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配不动产权属相关的精准内容，过滤低相关的非业务文档，适配登记业务的高合规要求 |
| `limit` | 前8条 | 覆盖核验权属来源、测绘比对、税费凭证等多类业务文档的必要信息，避免召回过多导致上下文溢出 |
| `searchMode` | hybrid | 结合全文检索与向量检索，适配异构的登记业务文档格式，兼顾结构化字段与非结构化文本的召回效果 |
| `usingReRank` | 开启 | 对召回结果按相关性重排，优先返回权属来源、限制状态等核心业务字段的匹配内容，提升生成回答的针对性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户问题自动扩展相关业务术语，将「过户」「抵押」等常用表述关联至对应登记类型的文档，提升召回精准度 |
| `collectionIds` | 按不动产登记专属数据集配置 | 限定检索范围仅包含登记申请书、权属证明等专属文档，避免引入其他品类的无关数据 |

## 容易做错的三处
- 现象：检索命中知识库文档，但生成回答仅精简概括未展示具体条款内容。原因：未开启`datasetSearchUsingExtensionQuery`，未关联具体条款的字段信息，导致模型无法获取完整文档内容。
- 现象：单次检索耗时超过30秒，页面返回超时状态码。原因：未限定`collectionIds`至专属数据集，检索范围覆盖过多异构系统文档，导致向量召回计算量过大。
- 现象：同一问题每次召回结果条数不一致。原因：未固定`similarity`阈值，或未开启`usingReRank`的固定排序规则，导致召回结果的随机性较强。

## 怎么确认配好了
- 发起包含「权属来源证明」的测试查询，检查召回结果是否包含登记申请书、权属证明类文档。
- 查看检索日志，确认召回结果的数量符合`limit`的配置取值，且排序符合`usingReRank`的重排规则。
- 测试连续发起3次相同查询，确认召回结果的条数与排序一致。
- 验证配置了`collectionIds`的专属数据集，检索结果未包含非不动产登记类的文档内容。
