# 医保基金监管稽核的业务办理流程引导：工具调用与插件

## 这个品类的数据长什么样
本品类数据主要来自医保智能监控系统、基金监管规则库、医保结算数据、药品耗材追溯码、举报线索，更新频率为月。日常处理的文档包括稽核通知书、检查工作底稿、疑点清单、约谈记录、处理决定书、整改报告，字段涵盖违规类型、涉事主体信息、核查进度、涉及金额等，单位多为人次、元、追溯码编号等。数据围绕欺诈骗保及基金违规使用相关信息展开，适配事后稽核与专项检查的业务场景。

## 这些特征在「工具调用与插件」这一环带来什么约束
月度更新的数据要求工具调用需适配批量数据拉取的节奏，避免高频请求超出数据源接口限制。多类型文档的字段差异，要求工具调用需支持动态适配不同文档的参数格式，避免字段不匹配导致解析失败。医保相关数据的敏感属性，要求工具调用需配置权限校验环节，防止非授权访问。事后稽核的专项检查属性，要求工具调用可灵活触发单次或批量任务，适配不同检查规模的需求。核心的疑点筛选环节耗时较长，工具调用需能快速拉取关联数据，减少人工操作的等待时间。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| toolChoice | `auto` | 适配稽核场景下的多工具动态调用需求，自动匹配数据拉取、规则校验等不同任务 |
| 返回内容控制 | 仅返回工具执行结果 | 符合业务办理流程引导中不输出冗余AI回复的需求，聚焦稽核相关数据 |
| HTTP工具集配置 | 关联医保结算数据接口、规则库接口 | 覆盖稽核所需的核心数据来源，满足疑点筛选与核查的调用需求 |
| 请求超时设置 | 300–600 秒 | 适配月度批量数据拉取的耗时需求，避免因数据量较大导致请求中断 |
| 结果返回条数 | 前 10 条 | 优先展示高优先级疑点，符合专项检查的快速排查需求，按实测可调整 |
| functionCall | `enabled` | 支持结构化调用合规工具，确保稽核数据的格式符合监管文档要求 |

## 容易做错的三处
- 配置HTTP工具集时出现`Invalid URL, code: 500`报错。原因是未正确配置医保数据源接口的完整路径，或接口权限未开放导致请求被拦截。
- 工具调用节点输出了冗余的AI自然语言回复。原因是未关闭默认的AI回复生成开关，或返回内容控制配置未设置为仅返回工具结果。
- 无法调用Oracle数据库拉取医保结算数据。原因是未安装对应数据库的驱动插件，或数据库连接参数中的端口、用户名配置错误。

## 怎么确认配好了
- 发起一次测试调用，查看返回结果是否包含稽核所需的疑点清单、结算数据等核心字段。
- 检查工具调用节点的输出日志，确认未出现`Invalid URL`或超时报错。
- 验证`functionCall`参数是否启用，确保工具调用返回的结果为结构化格式。
- 调整结果返回条数，确认界面可展示对应数量的稽核数据条目。
