# 医保基金监管稽核的业务办理流程引导：部署与升级

## 这个品类的数据长什么样
该品类的数据来源包括医保智能监控系统、基金监管规则库、医保结算数据、药品耗材追溯码与举报线索，更新频率为月度。日常处理的文档包含稽核通知书、检查工作底稿、疑点清单、约谈记录、处理决定书与整改报告，核心字段涉及违规疑点标识、费用金额、检查流程节点等，核心处理环节为从结算数据中筛选疑点、调阅病历处方和收费记录、认定违规费用并形成处理意见。

## 这些特征在「部署与升级」这一环带来什么约束
月度更新的数据来源要求部署时配置稳定的定期同步链路，保障规则库、结算数据的及时拉取。多类型结构化与非结构化文档的处理需求，要求存储配置支持多格式文件的读写与索引。核心处理环节的高耗时特性，要求部署时预留足够的计算资源支撑批量数据运算，同时需配置缓存机制减少重复调用。此外，违规认定的出错后果要求升级时保留回滚路径，避免配置变更影响稽核流程。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本，具体配置项、建议取法及依据如下：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30` | 适配月度批量稽核数据的并发读取需求，避免连接池耗尽 |
| `REDIS_URL` | 本地缓存实例或专属云缓存服务 | 存储稽核疑点缓存与会话数据，降低数据库重复查询压力 |
| `STORAGE_S3_ENDPOINT` | 合规的云存储服务节点 | 适配药品耗材追溯码、病历扫描件等大文件的存储与调取 |
| `MONGODB_URI` | 独立高可用数据库实例 | 存储非结构化的稽核文档与举报线索数据，保障读写性能 |
| `PG_URL` | 企业级关系型数据库服务 | 存储稽核流程的结构化数据，支持复杂条件查询与审计 |
| `FILE_TOKEN_KEY` | 随机生成的32位字符串 | 保障文件访问的安全性，防止未授权调取稽核文档 |

## 容易做错的三处
- 工作流画布拖动节点时出现数秒延迟，原因是未配置`REDIS_URL`启用缓存，导致画布状态频繁读写数据库，拖慢界面响应。
- 知识库召回的稽核疑点与当前批次不匹配，原因是未按月度更新频率配置数据同步任务，导致存储的结算数据过期。
- Docker部署启动失败，原因是未选择适配的Linux操作系统镜像，导致依赖的运行环境无法正常加载。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`DB_MAX_LINK`配置的连接池是否能支撑批量数据读取。
- 触发月度数据同步任务，检查`STORAGE_S3_ENDPOINT`是否能正常存储稽核文档与药品耗材追溯码文件。
- 启动工作流画布，拖动多个稽核流程节点，确认界面响应延迟符合日常使用要求。
- 查看缓存监控面板，确认`REDIS_URL`对应的缓存服务正在正常存储会话与稽核疑点数据。
