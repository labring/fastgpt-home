# 土地使用权、矿业权与国有产权交易的业务办理流程引导：模型接入与配置

## 这个品类的数据长什么样
该品类数据通常来自全国公共资源交易平台、自然资源交易系统、产权交易所系统及国资监管系统，更新频率为每日。日常文档包含出让公告、交易须知、竞买申请、保证金凭证、成交确认书、挂牌结果公告、产权转让说明书等，核心字段涵盖交易标的权属信息、限制条件、竞价规则、保证金金额、成交确认条款等，文档结构以结构化表单与非结构化公告文本结合为主。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据来源分散且每日更新，要求模型接入时需适配多系统数据拉取的接口兼容性，避免因数据源格式差异导致的解析失败。日常文档兼具结构化表单与非结构化公告文本，需配置适配混合格式的上下文拆分与召回规则。核心字段涉及权属、竞价规则等敏感信息，需限制模型输出范围以符合合规要求。交易流程出错后果严重，需配置严格的上下文校验与结果溯源机制，确保业务环节的准确性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配该品类多文档拼接的上下文需求，避免因上下文不足导致权属信息遗漏 |
| `maxTokens` | 2000–3000 token | 匹配交易类文档的输出长度需求，确保成交确认、竞价规则等核心内容完整输出 |
| `quoteMaxToken` | 1500 token | 限制引用文档的长度，聚焦交易标的权属、保证金要求等关键信息 |
| `temperature` | 0.1–0.3 | 降低随机性，确保业务引导内容的准确性与合规性，避免生成不符合交易规则的内容 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写专属接口地址 | 适配该品类数据的专属拉取与处理链路，保障数据安全性 |
| `toolChoice` | auto | 允许模型自动选择工具处理结构化数据与非结构化文本的解析需求 |

## 容易做错的三处
- 进入工作台编辑页面显示“未配置语言模型”报错，原因是未正确填写`AIPROXY_API_TOKEN`或`AIPROXY_API_ENDPOINT`参数，导致平台无法识别可用模型。
- 工作流问题分类中AI模型选项为空，原因是未完成基础模型的接入配置，或配置的模型未通过平台的有效性校验。
- 对话时提示“模型流响应为空，请检查模型流输出是否正常”，原因是`maxTokens`设置过低，导致模型输出被截断为空，或数据源拉取失败导致无有效上下文传入。

## 怎么确认配好了
- 检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`参数是否与部署环境匹配，可通过调用基础接口测试连通性。
- 测试调用模型生成一段交易须知的引导内容，核对输出是否包含该品类核心字段的准确表述。
- 导入一份该品类的典型文档，测试上下文召回与引用功能，确认召回内容与文档核心信息一致。
- 模拟迁移知识库后的对话场景，验证模型是否能正确读取知识库中的交易标的信息。
