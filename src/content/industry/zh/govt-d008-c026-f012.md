# 工程建设项目审批的业务办理流程引导：部署与升级

## 这个品类的数据长什么样
本品类的数据围绕工程建设项目全审批流程产生，日常文档包括施工许可申请、施工图审查合格书、质量安全监督手续、竣工验收备案表。数据来源为工程建设项目审批管理系统、施工图审查系统、企业资质库、信用平台，每日更新。数据字段包含项目唯一标识、参建单位资质信息、各审批环节节点状态、申请材料清单等，格式多为文本、编号类，无专用单位字段。

## 这些特征在「部署与升级」这一环带来什么约束
本品类的数据来源分散且每日更新，日常文档格式多样，对部署与升级带来以下约束：需配置稳定的数据库连接以适配多源审批数据的持久化存储，确保每日同步链路保持稳定，避免数据同步中断。日常文档包含多种格式，需配置文件存储与访问权限，适配各类申请材料的存储与调用。升级时需保证外部系统数据拉取的兼容性，避免因版本更新导致审批节点数据同步中断，同时需配置足够的连接池资源，支撑批量并行的审批流程引导任务运行。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PG_URL` | `postgresql://admin:securepass@db-host:5432/fastgpt?schema=public` | 适配本品类多源审批数据的持久化存储需求，支持docker部署的数据库容器适配 |
| `MONGODB_URI` | `mongodb://admin:securepass@mongo-host:27017/fastgpt` | 存储审批节点的动态状态与并行运行的任务数据 |
| `DB_MAX_LINK` | `8–12` | 支撑每日更新的大量审批数据的连接池管理，避免连接耗尽 |
| `REDIS_URL` | `redis://:securepass@redis-host:6379/0?timeout=600秒` | 缓存高频访问的审批节点数据，降低数据库查询压力 |
| `FILE_TOKEN_KEY` | `32位随机生成的安全字符串` | 保障施工许可、竣工验收备案等文档的访问权限 |
| `STORAGE_S3_ENDPOINT` | `http://s3.your-domain.com` | 存储各类审批文档与申请材料 |

## 容易做错的三处
- 现象：FastGPT v4.17.0版本的docker本地部署后，隔数小时出现数据库连接报错，需删除PG容器重新部署才能恢复。原因：未配置`PG_URL`的连接池超时设置，或连接未自动释放，导致数据库连接耗尽。
- 现象：批量运行的审批流程引导任务无法并行执行。原因：未开启对应版本的并行任务配置，FastGPT v4.17.0及以上版本支持并行批量任务，需确认版本适配。
- 现象：调用海外大模型生成审批流程引导内容失败。原因：未配置`ROOT_KEY`或对应模型的访问权限，且未适配海外大模型的对接配置。

## 怎么确认配好了
- 运行数据库连接测试脚本，验证`PG_URL`与`MONGODB_URI`的连接状态正常，连接池连接数符合`DB_MAX_LINK`的配置取值。
- 上传一份施工许可申请文档，通过`FILE_TOKEN_KEY`生成的访问链接可正常下载，`STORAGE_S3_ENDPOINT`存储的文档可正常读取。
- 启动10个并行的审批流程引导测试任务，验证任务可正常并行执行，无连接耗尽或超时报错。
- 访问`https://fastgpt.your-domain.com配置的业务引导页面，查看页面可正常加载，且审批节点信息可正常展示。
