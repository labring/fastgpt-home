# 投资项目立项与后评价的业务办理流程引导：模型接入与配置

## 这个品类的数据长什么样
本品类的数据主要来自国资委投资监管系统、企业ERP与项目管理系统、行业市场公开数据、审计及财务报表。数据更新节奏为季度级。日常处理的文档包含年度投资计划、项目建议书、可行性研究报告、尽职调查报告、资产评估报告、投资后评价报告，文档结构多包含项目基本信息、审批流程节点记录、财务测算模块、投后运营跟踪指标等，字段包含项目编号、建设周期、核心业务参数等，单位随文档原生格式适配。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类的数据特征对模型接入与配置带来多维度约束。季度级的数据更新节奏要求知识库同步周期匹配更新频率，避免数据滞后影响业务引导准确性。多样且结构复杂的长文本文档，要求配置适配长文本处理的上下文参数。多源异构的数据来源，要求模型调用时明确字段映射规则，确保跨系统数据的准确识别。涉及国资管理的业务属性，要求配置合规的模型调用权限与日志记录参数，保障数据安全。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 本品类文档多为长文本，需容纳多份可研、后评价报告的完整上下文，确保模型能关联全量业务信息 |
| `maxTokens` | 2000–3000 token | 需生成完整的流程引导说明或投决会材料摘要，避免输出内容被截断 |
| `temperature` | 0.2–0.4 | 业务办理流程需严谨准确，降低输出随机性，确保引导步骤符合监管相关要求 |
| `toolChoice` | auto | 可根据用户输入自动选择是否调用知识库或工具，适配多类型业务咨询场景 |
| `AIPROXY_API_ENDPOINT` | 企业专属内部代理地址 | 适配企业内部网络环境，保障数据传输安全，符合国资数据合规要求 |
| `AIPROXY_API_TOKEN` | 定期轮换的加密令牌 | 防止令牌泄露导致未授权访问，保障模型调用的安全性 |

## 容易做错的三处
- 现象：在第三方API平台配置模型后，FastGPT页面调用无响应或返回连接报错。原因：未正确配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或代理地址未开放内部网络访问权限。
- 现象：本地部署的第三方大模型无法在模型思考设置中生效。原因：未将模型接入地址配置为本地服务地址，或未启用FastGPT的第三方模型接入选项。
- 现象：工作流中前一个AI模型的输出结果无法更新为空值。原因：未正确配置变量更新的触发条件，或变量类型设置为不可修改的只读模式。

## 怎么确认配好了
- 测试调用模型，输入一份项目建议书片段，检查模型是否能正确返回业务办理流程引导内容，确认上下文参数配置符合预期。
- 查看模型调用日志，验证`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置是否正确，无连接报错或权限异常。
- 触发工作流变量更新操作，检查前序模型输出是否能被正确置空，确认变量配置符合业务需求。
- 调整`temperature`参数并测试输出，验证输出内容的严谨性是否符合业务办理的要求。
