# 排污许可管理的业务办理流程引导：部署与升级

## 这个品类的数据长什么样
本品类数据主要来自全国排污许可证管理信息平台、企业环保台账、在线监测系统及环境统计系统。日常关联文档包含排污许可证申请表、执行报告、自行监测方案、台账记录、变更申请及许可证副本。数据更新周期为季度，核心字段涵盖许可排放限值、监测指标阈值、台账时段范围等，对应单位包含排放浓度单位、年排放量限额等，文档结构按办理环节分为申请类、执行类、监管类三类。

## 这些特征在「部署与升级」这一环带来什么约束
本品类数据来源分散、更新周期固定且文档类型多样，部署时需适配多源数据的接入配置，确保季度性数据同步任务稳定运行。由于核心数据关联排污许可的合规性，部署环节需配置可靠的数据库连接与存储方案，避免数据丢失或同步异常。升级过程需保证业务办理引导的连续性，不能中断现有用户的流程访问，同时需兼容旧版文档的解析逻辑，适配不同版本的排污许可文档结构。另外，数据字段的单位与合规要求强绑定，部署时需确保解析规则与行业技术规范对齐，避免出现限值匹配错误。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本，具体参数说明如下：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:port/ep_db?authSource=admin`，兼容mongo:4.4.29版本 | 存储企业环保台账、在线监测系统的结构化数据，适配低CPU环境下的MongoDB版本要求 |
| `PG_URL` | `postgresql://username:password@host:port/排污许可管理_db` | 存储全国排污许可证管理信息平台的结构化申请、变更数据，支持复杂查询与权限控制 |
| `REDIS_URL` | `redis://:password@host:port/0` | 缓存季度更新的许可限值数据、用户会话信息，降低数据库查询压力 |
| `STORAGE_S3_ENDPOINT` | `按本地存储或云存储服务商地址配置` | 存储自行监测报告、台账记录等非结构化文档，支持多类型文件的上传与下载 |
| `DB_MAX_LINK` | `20–30 个` | 适配季度数据同步的并发请求量，避免数据库连接耗尽 |
| `ROOT_KEY` | `按系统安全要求生成随机字符串` | 配置系统管理员权限验证，防止未授权访问部署后的服务 |

## 容易做错的三处
- 现象：部署开源版容器后返回`getPluginGroups 500`错误，界面提示未配置商业版链接。原因：开源版代码未包含proAPI相关模块，直接沿用商业版部署脚本或配置项导致接口调用失败。
- 现象：尝试集群部署时出现节点间数据同步异常。原因：未正确配置多节点共享的`REDIS_URL`与`STORAGE_S3_ENDPOINT`，导致各节点缓存与存储数据不一致。
- 现象：替换MongoDB镜像为mongo:4.4.29后启动失败，提示版本校验异常。原因：未关闭FastGPT内置的MongoDB版本强制校验逻辑，或配置的`MONGODB_URI`指向的数据库未完成初始化。

## 怎么确认配好了
- 执行`docker logs 容器名称`，检查数据库连接相关日志，无`连接超时`或`认证失败`报错。
- 访问`FE_DOMAIN`对应的前端地址，尝试加载排污许可相关的文档解析预览功能，确认无格式解析错误。
- 触发一次模拟的季度数据同步任务，检查`STORAGE_S3_ENDPOINT`对应的存储目录是否生成新的同步日志文件。
- 使用`ROOT_KEY`调用系统管理接口，验证管理员权限验证逻辑正常生效。
