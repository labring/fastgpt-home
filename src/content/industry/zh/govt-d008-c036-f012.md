## 这些特征在「部署与升级」这一环带来什么约束
由于数据来自官方权威源且需按月更新，部署时需配置可对接官方政务数据接口的权限通道，同时支持批量导入结构化本地文档。因文档字段需严格匹配上级规范，部署阶段需预设字段完整性校验规则，拦截不符合格式的导入数据。按月更新的特性要求升级环节支持定时同步任务的快速配置，同时保留历史数据回滚能力，避免更新异常导致办事口径不一致。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | 本地部署时填写自建MongoDB实例的连接地址，商业版填写专属集群地址 | 存储政务事项全量文档的元数据与历史版本，需兼容批量读写需求 |
| `REDIS_URL` | 6379 端口的本地Redis实例地址，或托管Redis服务的连接串 | 缓存高频访问的事项字段与同步任务状态，降低数据库负载 |
| `STORAGE_S3_ENDPOINT` | 本地MinIO实例地址或云存储服务商的终端节点 | 存储办事指南的附件材料、流程图等大文件，需适配批量上传场景 |
| `DB_MAX_LINK` | 100–150 个 | 控制数据库连接池规模，适配每月一次的批量同步任务与日常查询 |
| `FE_DOMAIN` | 本地部署时填写服务器公网IP加端口，或绑定的官方域名 | 配置办事指南预览的跳转路径，确保政务系统内可正常访问 |
| `FILE_TOKEN_KEY` | 按业务要求生成的32位随机字符串 | 加密办事指南附件的下载令牌，防止未授权访问 |

## 容易做错的三处
- 现象：上传办事指南文档后，文件解析节点无响应，日志显示连接超时。原因：未正确配置`STORAGE_S3_ENDPOINT`或`REDIS_URL`，导致文件存储或缓存链路中断。
- 现象：Windows Docker部署完成后，访问页面显示无法连接。原因：未开放`FE_DOMAIN`指定的端口，或Docker容器端口映射配置错误。
- 现象：批量导入事项目录后，部分字段为空。原因：未预设字段校验规则，导入的文档未匹配上级目录的字段规范，未被拦截导致入库异常。

## 怎么确认配好了
- 执行一次手动数据同步任务，确认政务事项文档可成功导入，无格式校验报错。
- 上传测试用的办事指南附件，确认文件可正常存储并生成可访问的预览链接。
- 访问配置的`FE_DOMAIN`地址，确认页面可正常加载，无连接失败提示。
- 调整定时同步任务的触发间隔，验证任务是否按设定规则执行。
