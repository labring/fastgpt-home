# 政府采购项目的业务办理流程引导：工具调用与插件

## 这个品类的数据长什么样
该品类的数据主要来自中国政府采购网、地方政府采购网、财政一体化系统、采购人预算系统及供应商信用记录，更新频率为每日。日常涉及的文档包括采购需求、采购计划、招标文件、投标文件、评标报告、中标公告、采购合同与质疑答复。数据字段覆盖采购主体信息、项目预算、供应商资质、评审标准、合同条款等，无统一固定的单位字段，需随对应文档类型匹配业务场景下的单位规则。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据来源分散且需每日同步，要求工具调用插件支持对接多类官方系统与内部业务系统，避免数据滞后影响业务办理节奏。日常文档类型多样，不同文档对应不同业务字段，工具调用需适配多类文档的格式与字段提取规则。出错后果直接关联废标、监管处罚，工具调用的参数校验与结果审核需更严格。同时，业务流程需遵循政府采购相关监管要求，工具调用的触发逻辑需匹配业务办理的关键节点。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的工具调用系统：

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `toolChoice` | 设为`auto`，仅匹配政府采购相关业务触发 | 适配细分场景的业务边界，避免无关调用 |
| `functionCall` | 启用，限定调用文档解析、资质校验类工具 | 匹配该品类核心业务环节的工具需求 |
| 工具调用超时时间 | 600 秒 | 政府采购相关文档通常体量较大，数据校验需较长处理时长 |
| 上下文窗口大小 | 8000–12000 token | 覆盖采购需求、招标文件等多类文档的完整内容 |
| 单次工具调用参数长度 | 4096 字符 | 适配政府采购文档的字段长度上限，避免参数截断 |
| 跨域白名单配置 | 加入政府采购相关系统域名 | 解决iframe嵌入的浏览器兼容问题 |

## 容易做错的三处
- iframe嵌入的应用界面无图像与头像，仅在部分浏览器可正常加载。原因：未配置浏览器兼容的跨域插件参数，部分浏览器的安全策略拦截了非官方域的资源加载。
- 工具调用同时输出AI回复与下一级分支执行内容，且内容被打印。原因：未关闭工具调用的结果回显开关，未配置分支执行的触发条件与回显逻辑的互斥规则。
- 无法启用Qwen2.5的工具调用功能。原因：未在平台开启对应模型的`functionCall`支持，未完成模型与工具调用的绑定配置。

## 怎么确认配好了
- 触发模拟政府采购项目的业务请求，检查工具调用是否仅在匹配相关文档时触发。
- 查看工具调用的日志，确认`functionCall`调用的工具类型与配置一致。
- 模拟异常数据输入，检查工具调用的校验逻辑是否生效。
- 测试不同浏览器的iframe嵌入效果，确认跨域配置是否符合要求。
