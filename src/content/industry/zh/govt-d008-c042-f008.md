# 法务合规与重大风险管理的业务办理流程引导：文档解析与分块

## 这个品类的数据长什么样
本品类的核心数据来自企业合同管理系统、合规风险数据库、法律法规库、案件管理系统与举报平台。日常处理的文档包含合规风险清单、合同法律审核意见、重大事项法律意见书、合规审查表、违规举报调查报告。数据更新频率为月度，文档多具备固定结构，包含风险等级、审核结论、违规事项等字段，无统一固定单位，单份文档篇幅跨度较大，从数页的合规审查表到数十页的案件调查报告均有覆盖。

## 这些特征在「文档解析与分块」这一环带来什么约束
多来源的文档格式存在差异，PDF可能包含固定排版的合规表单，DOCX则多带有结构化的审核流程字段，要求解析环节适配多种排版格式。月度更新的批量文档意味着需要处理单批次多份文件，对上传与解析的稳定性有要求。合规类文档的核心信息集中在审核意见、风险判定等段落，分块时需保留上下文关联，避免拆分核心逻辑。同时，数据涉及经营合规敏感内容，解析后的分块需准确保留原有字段，不得遗漏关键信息，否则可能影响后续业务办理流程引导的准确性。

以下配置基于FastGPT v4.17.0版本制定，适配本品类的文档特征与业务需求：
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 合规类文档多包含长段落的审核意见与风险分析，过长分块会丢失上下文关联，过短则破坏单条条款的完整逻辑，适配本品类常见文档的结构特征 |
| `chunkSplitter` | 按段落+标题拆分 | 合规文档多有明确的章节标题与条款分段，按段落拆分可保留单条审核意见或风险项的完整逻辑，避免跨段落拆分核心结论 |
| `customPdfParse` | 开启 | 合规类PDF多包含加密表单或固定排版的审核意见书，开启自定义解析可准确提取文本字段，避免格式错乱导致的信息丢失 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 合规文档可能包含批量合同或案件卷宗，设置合理上限避免上传失败，适配月度批量更新的处理需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 大型合规卷宗解析耗时较长，延长超时时间避免中途中断，满足批量文档处理的稳定性要求 |

## 容易做错的三处
- 上传合规类PDF后文本字段为空，原因是未开启`customPdfParse`，无法适配合规文档的固定排版格式，导致核心审核意见未被提取。
- 外部系统推送的合规文档未被正确解析，原因是未配置对应文件存储目录，导致系统无法读取推送的文件完成解析切片。
- 尝试上传合规相关的音视频举报材料后无法解析，原因是当前文档解析仅支持PDF、DOCX格式，未适配音视频文件的解析逻辑。

## 怎么确认配好了
- 上传一份标准合规审查表PDF，检查解析后的文本是否完整提取了审核意见、风险等级等核心字段。
- 上传一份100MB左右的合同卷宗，确认解析过程未触发超时错误，且分块结果完整。
- 查看分块结果，确认单块内容未拆分合同审核的核心条款与对应结论。
- 配置`customPdfParse`后，检查加密合规表单的文本提取是否正常，无格式错乱问题。
