# 环境执法与监测监管的业务办理流程引导：部署与升级

## 这个品类的数据长什么样
本品类的核心数据来自生态环境在线监控平台、污染源自动监测系统、执法业务系统及第三方检测机构提交的报告。日常处理的文档包含现场检查记录、采样记录、监测报告、责令改正决定书与行政处罚决定书，涵盖检查点位、污染物浓度、执法文书编号、整改要求等字段。数据更新频率为每日，覆盖实时工况、监测结果与执法进度信息，数据来源多为内网部署的业务系统与监测设备。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据来源多为内网部署的业务系统与监测设备，部署时需支持带身份验证的http代理配置，适配内网环境下的外部依赖访问需求。每日更新的海量监测与执法数据，要求部署时配置足够的数据库连接池与存储容量，避免并发访问时出现性能瓶颈。多类型混合的执法文档需要适配不同格式的解析规则，升级时需保障解析逻辑的兼容性。执法证据类数据的合规性要求，部署与升级过程中需配置数据加密与权限控制机制，避免敏感信息泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150 条` | 适配每日更新的监测数据与执法文档的并发访问需求，避免数据库连接耗尽 |
| `MONGODB_URI` | `内网MongoDB服务地址，添加身份验证参数` | 存储执法记录、监测报告等非结构化文档，适配内网部署场景 |
| `REDIS_URL` | `内网Redis服务地址，配置访问密码` | 缓存实时执法数据与会话信息，保障每日高频更新的响应速度 |
| `FILE_TOKEN_KEY` | `32位随机生成字符串` | 加密执法文档的访问令牌，保障监测数据与执法文书的存储安全 |
| `STORAGE_S3_ENDPOINT` | `内网对象存储服务地址` | 存储采样记录、监测报告等大体积文件，适配内网存储需求 |

## 容易做错的三处
- 现象：内网部署时无法访问外部依赖资源，日志提示连接超时。原因：仅配置了代理IP与端口，未添加用户名与密码验证，无法通过代理身份校验。
- 现象：升级至FastGPT v4.17.0后，应用配置的自定义大模型被重置为默认模型，无法保存指定配置。原因：升级过程中未备份原有配置文件，导致系统参数被覆盖重置。
- 现象：进入工作流编辑器时弹出数据库连接失败提示。原因：`DB_MAX_LINK`配置值设置过低，并发访问执法数据时耗尽了数据库连接池。

## 怎么确认配好了
- 执行代理配置测试脚本，验证内网环境下可通过带身份验证的代理访问外部依赖资源。
- 上传一份采样记录文档，验证系统可正常解析并存储至指定的对象存储位置。
- 查看数据库连接池监控面板，确认当前活跃连接数未超过`DB_MAX_LINK`配置的阈值。
- 登录系统管理员后台，验证`ROOT_KEY`权限可正常访问配置管理页面。
