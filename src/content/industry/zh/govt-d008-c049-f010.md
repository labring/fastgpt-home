# 规范性文件合法性审核的业务办理流程引导：知识库检索与召回

## 这个品类的数据长什么样
本品类数据主要来自法规规章库、上位法数据库、部门政策文件库及行政规范性文件备案系统，更新频率不定期。日常处理的文档包含规范性文件草案、起草说明、合法性审核意见、征求意见汇总与备案报告。数据字段围绕政策制定权限、条文表述、程序合规性展开，无统一固定单位，需结合具体文件内容匹配审核依据。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散且更新无固定周期，需确保检索覆盖全量合规依据库，避免遗漏上位法或最新政策。文档类型多样，既有长文本草案也有结构化汇总表，需适配不同格式的召回逻辑。审核核心聚焦制定权限与条文合法性，要求检索结果精准匹配审核维度。单次审核需比对多份依据，召回结果的数量与相关性直接影响审核效率与准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.88 | 匹配规范性文件审核所需的精准合规依据，避免低相关结果干扰审核判断 |
| `limit` | 前8–12条 | 单次审核需比对多份依据，8-12条可覆盖主要上位法与政策文件，避免结果过多超出处理范围 |
| `searchMode` | 语义检索 | 适配抽象政策规则的审核需求，精准匹配条文合法性相关的语义内容 |
| `usingReRank` | 开启 | 对初始召回结果二次排序，提升与审核维度强相关的结果优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展审核相关的查询词，覆盖制定权限、程序合规等多维度检索场景 |
| `collectionIds` | 绑定专属合规依据库 | 限定检索范围为法规规章库、上位法数据库等集合，避免无关数据干扰 |

## 容易做错的三处
- 检索耗时超过4秒，界面显示超时状态。原因是未限定检索集合范围，全量扫描全库数据导致检索负载过高。
- 召回结果包含非合规依据类文档，字段为空或与审核维度无关。原因是`collectionIds`配置错误，未绑定专属合规依据库。
- 多行表格类文档检索结果缺失关键内容。原因是未针对xlsx格式文档做适配处理，仅提取纯文本导致表格结构信息丢失。

## 怎么确认配好了
- 查看知识库检索日志，确认检索范围仅包含预设的合规依据库集合。
- 触发一次模拟审核检索，核对召回结果的相似度分值符合预设区间。
- 导入xlsx格式的征求意见汇总文档，确认检索时可完整提取表格内的意见内容。
- 测试检索耗时，调整`limit`与`similarity`参数至符合业务审核的效率与精度要求。
