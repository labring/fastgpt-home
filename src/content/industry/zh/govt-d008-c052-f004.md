# 部门决算与财务报告的业务办理流程引导：工作流编排

## 这个品类的数据长什么样
本品类服务于预算单位财务处、财政局国库处、主管部门财务司局，数据来自预算管理一体化系统、国库集中支付系统、会计核算系统与资产管理系统，更新频率为年度周期。日常处理的文档包含部门决算报表、资产负债表、收入支出决算表、决算说明、政府财务报告，涵盖预算执行明细、收支结余、资产负债明细等标准化字段，单位以元为基准，部分报表需按行政层级汇总下级单位上报数据。

## 这些特征在「工作流编排」这一环带来什么约束
年度更新的周期要求工作流需适配批量年度数据处理，避免频繁触发非周期任务；多系统来源的数据特征要求工作流需支持多`variables`动态接入，匹配不同系统的输出格式；复杂的文档结构要求工作流预设多节点解析流程，分别处理报表与说明类文档；账表核对的耗时环节要求工作流加入自动校验节点，减少人工核对量；严重的出错后果要求工作流设置异常拦截环节，避免错误数据进入汇总与上报环节；层级汇总的需求要求工作流支持下级单位数据的自动归集与校验。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 知识库选择 | 绑定对应年度的部门决算专用知识库 | 适配年度更新的数据特征，避免跨年度数据干扰搜索结果 |
| `variables` | 配置国库支付数据、账面核算数据两个动态变量 | 匹配多系统来源的数据接入需求，支持动态传参调用 |
| 单次文档上传上限 | 1000 MB | 适配决算报表与说明的批量文档存储与解析需求 |
| 工作流节点触发条件 | 按文档上传完成状态触发 | 确保数据在完整上传后进入解析与校验环节 |
| 异常拦截节点 | 匹配账表差异阈值按实测标定 | 避免错误数据进入后续汇总与上报环节 |
| 导出配置 | 绑定word导出格式，触发节点为工作流完成 | 适配决算报告的官方标准化导出需求 |

## 容易做错的三处
- 工作流执行后知识库搜索无匹配文档，界面显示结果为空。原因是动态传参时未将`variables`配置的系统数据与绑定的知识库关联，导致搜索范围未覆盖目标业务数据。
- 工作流执行超时终止，日志返回执行超时状态码。原因是未调整节点执行超时时间，决算文档批量解析与校验耗时较长，默认超时设置无法覆盖完整处理周期。
- 工作流从旧版本迁移后节点配置失效，无法触发导出环节。原因是未按照版本更新说明迁移`nodeId`对应的节点标识，旧版本的节点配置与新版本的节点规则不兼容。

## 怎么确认配好了
- 上传单份年度决算报表文档，触发工作流，检查知识库搜索结果是否匹配上传文档的关键词与业务字段。
- 配置`variables`动态传参，传入模拟的国库支付数据与账面核算数据，检查工作流节点是否正确接收参数并执行匹配校验。
- 触发工作流完成后，检查对话界面是否生成可下载的word格式报告链接。
- 查看工作流执行日志，确认所有节点均正常执行，无异常报错信息。
