# 部门决算与财务报告的业务办理流程引导：部署与升级

## 这个品类的数据长什么样
本品类数据来自预算管理一体化系统、国库集中支付系统、会计核算系统、资产管理系统，更新频率为年度周期。日常文档包含部门决算报表、资产负债表、收入支出决算表、决算说明、政府财务报告，结构涵盖收支明细、资产负债明细、预算执行差异说明等模块，字段覆盖实际收支金额、资产存量、负债情况及相关解释说明内容，无固定统一的单文档格式，需适配多类型财政核算文档的解析需求。

## 这些特征在「部署与升级」这一环带来什么约束
本品类数据年度集中更新且来源多系统，部署阶段需适配多数据源对接配置，避免跨系统数据同步时出现格式不兼容或缺失。文档结构包含报表、明细表格与说明文本，需配置支持多格式文档的解析规则，确保不同类型财政文档均可被正确读取与拆分。数据核对环节耗时且出错后果严重，部署时需预留足够的计算资源用于账表核对与差异分析，升级阶段需保留历史数据的可追溯配置，避免年度数据丢失或口径变更影响后续流程。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://admin:yourpass@mongodb-host:27017/fastgpt?authSource=admin` | 存储年度决算与财务报告的全量文档与元数据，需配置正确的认证信息与数据库指向 |
| `PG_URL` | `postgresql://admin:yourpass@pg-host:5432/fastgpt?sslmode=disable` | 存储流程引导的配置规则、用户交互日志与流程节点数据，适配结构化数据的快速查询 |
| `REDIS_URL` | `redis://:yourpass@redis-host:6379/0` | 缓存高频调用的报表解析结果与流程节点数据，缩短业务办理的响应时间 |
| `DB_MAX_LINK` | `20–30` | 应对年度集中的数据同步与查询请求，避免数据库连接耗尽导致服务中断 |
| `STORAGE_S3_ENDPOINT` | `按部署使用的对象存储服务商接口地址填写` | 存储大体积的决算报表附件与历史归档数据，保障年度文档的长期存储 |
| `ROOT_KEY` | `自定义复杂度不低于16位的密钥串` | 配置系统管理员权限，保障流程引导的核心配置不被未授权账号修改 |

## 容易做错的三处
- 界面显示模型渠道不可用，且One API渠道测试显示通过。原因是未在FastGPT配置中正确填写模型对接的密钥或调用地址，或未将渠道绑定至对应的流程引导应用。
- 对话时出现令牌无效报错。原因是对接One API时生成的令牌未绑定对应模型权限，或配置的`FILE_TOKEN_KEY`与One API的令牌不匹配，导致请求被拦截。
- 源码部署后无法正常加载流程引导页面。原因是未配置`FE_DOMAIN`为FastGPT的公网访问地址，导致前端资源加载出现跨域问题。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`MONGODB_URI`、`PG_URL`与`REDIS_URL`的连通性，确认无连接超时或认证失败提示。
- 上传一份年度决算报表样本，检查解析结果是否包含报表内的收支明细与说明文本，验证`STORAGE_S3_ENDPOINT`的附件存储功能正常，上传的文件可正常下载。
- 使用管理员账号登录系统，修改流程引导的节点配置，验证`ROOT_KEY`权限生效，未授权账号无法访问配置修改页面。
- 调用模型对接接口，使用One API的有效令牌发起测试请求，确认渠道状态显示正常，无令牌无效或权限不足的报错。
