# 部门预算编制的业务办理流程引导：工具调用与插件

## 这个品类的数据长什么样
这个品类的数据来源包括预算管理一体化系统、部门人员编制系统、以前年度决算、项目库、财政部预算编制通知，更新频率为年度。日常文档包含部门预算草案、项目申报书、绩效目标表、人员经费测算表、预算批复等，数据字段通常覆盖人员编制数、项目支出明细、绩效目标指标、年度预算额度等，单位涉及万元、人、项目项等。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源覆盖多套跨部门系统，工具调用需要适配不同系统的返回格式，实现多源数据的联动拉取。年度更新频率允许工具调用的缓存策略按年度周期刷新，减少无效请求。日常文档包含表格类与文本类混合结构，工具调用需要适配多样的文档解析逻辑。字段覆盖人员、项目、绩效多维度，工具调用的参数需要匹配多类数据的字段映射，确保数据关联准确。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本进行设置。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 部门预算编制涉及多类工具调用场景，自动选择适配工具可贴合业务需求 |
| `functionCall` | `enabled` | 需要调用外部数据源接口获取预算相关数据，启用函数调用可实现数据拉取与关联处理 |
| 工具调用超时设置 | `300–600 秒` | 跨多系统拉取预算数据需要一定处理时间，该区间可覆盖多数数据拉取场景，按实测标定 |
| 工具调用重试次数 | `2 次` | 预算数据接口偶发波动，有限重试可降低调用失败概率，避免过度请求 |
| 文档解析格式适配 | 支持表格、文本混合结构 | 部门预算编制的日常文档包含人员经费测算表等表格类文件与预算批复等文本类文件，混合适配可完整解析数据 |

## 容易做错的三处
- 现象：调用预算数据相关工具时，模型返回`chat：llm—model—response-empty`的报错信息。原因：未正确启用`functionCall`配置，工具调用链路未正常触发，模型无法获取所需的预算数据。
- 现象：生成部门预算编制流程引导时，生成的流程图出现节点缺失或样式异常。原因：未配置适配混合格式文档的解析规则，无法完整提取人员经费测算表、项目申报书中的关键字段。
- 现象：工具调用完成后，返回结果中包含了工具调用的原始请求与响应日志。原因：未关闭工具调用日志的默认输出配置，导致非业务相关的日志内容被包含在最终结果中。

## 怎么确认配好了
- 发起针对部门预算编制的测试查询，核对工具调用是否按配置触发并返回对应业务数据。
- 检查工具调用的返回结果，确认仅包含AI生成的流程引导内容，无额外的工具调用日志信息。
- 模拟数据源异常场景，核对工具调用是否按配置的重试规则进行处理。
- 上传不同类型的预算文档，核对解析结果是否适配混合格式的文档结构。
