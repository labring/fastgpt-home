# 部门预算编制的业务办理流程引导：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据来自预算管理一体化系统、部门人员编制系统、以前年度决算、项目库及财政部预算编制通知。日常处理的文档包含部门预算草案、项目申报书、绩效目标表、人员经费测算表、预算批复等，涵盖资金额度、人员编制、绩效指标等多类业务字段。数据更新节奏为年度周期，无高频实时更新的业务数据。

## 这些特征在「模型接入与配置」这一环带来什么约束
年度更新的批量数据要求模型接入需支持大批次文档解析与增量更新适配；多来源的混合文档格式，需要配置适配不同文档结构的分块规则；涉及财政资金与绩效的敏感业务字段，要求模型输出需严格匹配预设字段格式，避免歧义；汇总类任务的长上下文处理需求，需要限制单轮输入的token总量，防止模型超出处理上限。同时，国央企的网络安全要求，需要配置专属的API访问节点与权限密钥。

## 配置怎么定
本配置方案适配FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配部门预算类文档的批量上下文长度，避免截断核心预算数据 |
| `maxTokens` | 2000–3000 token | 控制单轮业务引导的输出长度，确保预算编制步骤清晰完整 |
| `quoteMaxToken` | 1200–1500 字符 | 限制引用源文档的长度，聚焦当前年度的预算申报规则与历史数据 |
| `temperature` | 0.2–0.4 | 降低输出随机性，确保预算流程引导的严谨性，符合财政业务规范 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写合规节点 | 适配国央企的网络访问要求，保障数据传输安全 |
| `AIPROXY_API_TOKEN` | 绑定专属权限的密钥 | 隔离不同预算单位的访问权限，符合财政数据安全管理要求 |

## 容易做错的三处
- 调用时返回503状态码，提示default分组下模型text-embedding不可用。原因是未为预算编制场景单独配置embedding模型分组，默认分组资源被其他业务占用。
- 模型输出的预算步骤出现字段单位错误，比如将万元误写为元。原因是未配置`temperature`参数控制输出严谨性，导致模型生成不符合财政业务规范的内容。
- 知识库召回的文档混入非本年度的历史预算数据。原因是未基于年度更新频率配置上下文过滤规则，未限定召回数据的时间范围。

## 怎么确认配好了
- 上传单份当前年度的部门预算草案文档，核对模型召回的源文档是否包含当前年度的预算编制规则，调整上下文过滤的时间范围。
- 发起预算流程引导测试，核对输出内容的字段格式是否与业务文档一致，调整`temperature`参数的取值区间。
- 调用API接口，检查返回的状态码是否正常，验证`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`的配置有效性。
- 测试批量文档导入，确认模型处理的上下文长度未触发截断，调整`maxContext`参数的取值。
