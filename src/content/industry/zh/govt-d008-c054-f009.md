# 防汛防灾与应急值守的业务办理流程引导：模型接入与配置

本文档适用于FastGPT v4.17.0版本的模型接入配置。

## 这个品类的数据长什么样
该品类的数据主要来自气象预警系统、水文监测系统、应急指挥平台、基层报灾系统与视频监控。日常留存的文档包含值班记录、预警通知、会商纪要、灾情速报、应急处置方案、物资调拨单。数据更新以日为周期，部分实时预警数据会高频同步。文档字段包含雨情水情数值、预警等级、受灾区域、物资存量、人员转移台账等，附带毫米、立方米每秒、人数等专用单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据来源要求配置兼容不同接口格式的接入规则，避免数据解析错误。高频更新的实时预警与灾情数据，要求模型上下文长度适配短周期业务场景，避免过期数据干扰判断。专用字段与单位的存在，要求模型配置适配专业术语识别规则，确保对雨情、水情等专业内容的准确理解。跨部门调度的业务需求，要求工具调用的响应延迟符合应急处置的实时性要求，避免流程卡顿。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配防汛业务的多源数据汇总需求，避免截断关键会商纪要与灾情速报内容 |
| `maxTokens` | 4000–6000 token | 满足应急处置方案、物资调拨单等长文本的生成需求，同时控制单次推理成本 |
| `toolChoice` | auto | 支持自动调用水文、气象相关工具，适配实时预警响应的业务场景 |
| `temperature` | 0.2–0.4 | 降低随机输出，确保预警信息、调度指令的表述严谨准确 |
| `AIPROXY_API_ENDPOINT` | 按部署平台实际接入地址填写 | 适配不同模型服务的调用路径，确保接口连通性 |
| `AIPROXY_API_TOKEN` | 按平台分配的密钥填写 | 完成身份验证，避免拒绝访问问题 |

## 容易做错的三处
- 现象：配置模型接入时提示拒绝访问，使用其他平台接入无此问题。原因：未正确配置`AIPROXY_API_TOKEN`或`AIPROXY_API_ENDPOINT`的路径参数，导致身份验证失败或接口调用异常。
- 现象：使用Qwen3模型时，无法限制模型不使用推理模式，输出内容偏离业务需求。原因：未正确配置`toolChoice`参数，或未指定禁止推理模式的触发规则，导致模型默认启用推理链路。
- 现象：重复配置`Qwen/Qwen3-Embedding-8B`嵌入模型时，原有配置被覆盖，无法同时使用多个同名称嵌入模型。原因：未为每个嵌入模型配置唯一标识，平台默认以模型名称作为唯一键，导致同名配置被覆盖。

## 怎么确认配好了
- 调用测试接口，输入模拟的雨情数据与灾情速报，检查模型是否能正确识别专业字段与单位。
- 查看接口日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的调用请求返回正常状态码，无身份验证报错。
- 测试多轮对话场景，检查`maxContext`参数是否能保留多轮会商纪要的关键内容，未出现截断。
- 尝试添加不同标识的嵌入模型，确认配置不会被同名模型覆盖，确保每个模型拥有独立的配置项。
