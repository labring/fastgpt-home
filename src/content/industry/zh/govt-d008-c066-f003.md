# 化工新材料的业务办理流程引导：多轮对话与提示词

## 这个品类的数据长什么样
化工新材料业务办理的数据来源于企业内部生产备案系统、行业合规手册、业务审批表单。数据更新节奏随企业合规调整，无固定周期但每月至少同步一次。文档结构包含申请材料清单、审批节点说明、合规校验规则三类核心内容，字段包含材料牌号、批次号、安全技术说明书编号、申请吨数，单位多采用千克、吨、批次。部分合规文档长度可达数万字符，单次申请表单长度约数百字符。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
化工新材料业务数据字段多且带专属单位，多轮对话需逐步引导用户提供必填字段，避免一次性输出过多信息导致混淆。长合规文档会占用大量上下文空间，需限制对话上下文的长度与范围，防止超出模型处理上限。业务审批节点层级明确，多轮对话需跟踪当前所处环节，不能跳过前置校验步骤。数据更新无固定周期，提示词需明确告知用户数据的最新同步时间，避免提供过时合规要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `messages` | 保留最近5轮有效对话 + 绑定的业务变量 | 化工新材料业务需跟踪申请进度与必填字段，避免上下文冗余 |
| `variables` | 绑定牌号、批次号、申请吨数3个必填字段，单位统一为吨或千克 | 固定业务表单校验规则，减少用户重复输入 |
| `chatId` | 绑定单次业务办理的唯一会话ID | 区分不同用户的申请流程，避免对话记录混淆 |
| 对话超时时间 | 600 秒 | 化工业务办理流程较长，预留足够用户补充材料的时间 |
| 上下文截断阈值 | 8000–12000 字符 | 适配化工合规文档的长度，防止超出模型处理上限 |
| 工具调用触发条件 | 当`variables`缺失必填字段时触发 | 自动引导用户补充材料，符合业务办理逻辑 |

## 容易做错的三处
- 调用数据库工具返回400状态码（无响应体）：未在`variables`中绑定数据库查询所需的业务字段，导致工具调用参数缺失。
- 无法在对话界面添加联网按钮与切换模型：未开启工作流的自定义交互配置，未绑定模型切换节点。
- Docker Compose部署后无法清除对话记录：未挂载对话存储卷，或未执行对应清理命令。

## 怎么确认配好了
- 发起测试对话，输入化工新材料牌号与批次号，检查`variables`是否自动绑定对应字段。
- 触发工具调用，查看是否能正确调取业务数据库的审批节点信息，无参数报错。
- 在对话界面尝试切换模型，确认能正常切换指定的大模型版本。
- 等待600秒，检查对话是否自动超时关闭，符合配置的超时时间要求。
