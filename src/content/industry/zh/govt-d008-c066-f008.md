# 化工新材料的业务办理流程引导：文档解析与分块

## 这个品类的数据长什么样
化工新材料的业务办理相关数据主要来源于企业内部的工艺规程文件、产品执行标准、安全环保评估报告、业务审批流程模板等。数据更新节奏随新产品投产、工艺迭代或合规要求调整，无固定周期。文档多为长文本格式，包含结构化参数表、流程节点说明、合规性条款等内容，字段涵盖产品牌号、密度、熔点、执行标准号、审批节点等，单位包含g/cm³、℃、MPa等专业化工计量标识。

## 这些特征在「文档解析与分块」这一环带来什么约束
化工文档的长文本特性要求分块不能过度拆分关键参数与上下文，避免业务引导出现信息断裂。内嵌的结构化表格需要保留原始格式，否则无法准确传递合规要求与工艺参数。非固定更新频率意味着解析环节需支持增量同步，避免重复解析全量文档。专业计量字段的单位与数值绑定，分块时需确保二者不被拆分，否则会影响后续业务引导的准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配化工文档的长参数段与流程节点，避免拆分数值与绑定的单位 |
| `chunkSplitter` | 按段落+标题拆分 | 保留工艺说明与审批流程的上下文关联，确保业务引导逻辑连贯 |
| `customPdfParse` | 开启内嵌表格识别模式 | 适配化工文档中大量存在的合规表格、参数对照表结构 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 兼容大型安全环保报告、年度工艺手册等大体积文档 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 为长文档解析预留充足耗时，避免中途中断 |
| `chunkSettingMode` | 手动配置 | 可根据不同类型的业务文档灵活调整分块规则 |

## 容易做错的三处
- 上传本地文件后调用文档解析工具返回报错，原因是未正确配置`UPLOAD_FILE_MAX_SIZE`，超过设定阈值导致文件被拦截。
- 部分PDF格式的产品标准文档无法识别，原因是未开启`customPdfParse`的内嵌表格识别模式，带结构化表格的文档解析失败。
- 分块结果中出现单独的数值或单位字段，原因是`chunkSize`设置过小，拆分时切断了参数与对应单位的绑定关系。

## 怎么确认配好了
- 在FastGPT v4.17.0环境下，上传单份体积不超过1000 MB的化工工艺手册，检查解析任务是否在600秒内完成且无超时报错。
- 上传包含内嵌参数表格的PDF标准文档，检查解析结果中表格的行列结构与原始文档一致。
- 查看分块后的文本片段，确认每个片段内的工艺数值与对应计量单位未被拆分。
- 切换`chunkSettingMode`至自动配置，验证分块规则是否随文档类型自动调整。
