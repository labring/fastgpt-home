# 化工新材料的业务办理流程引导：表单与交互
本文基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
化工新材料业务办理相关数据主要来源于企业内部生产管理系统、原料采购台账、下游客户订单表单及属地应急管理部门的合规备案文档。数据更新节奏覆盖实时（订单、批次信息）、每日（原料库存）、每季度（合规检测报告）三类。文档结构包含原料牌号、批次编号、安全检测项、办理流程节点、审批权限字段，字段单位多为吨、千克、批次号、检测报告编号，部分字段需匹配国家化工行业标准格式。

## 这些特征在「表单与交互」这一环带来什么约束
化工新材料业务数据的多更新节奏要求表单支持动态加载不同时效的数据源，实时订单数据需在提交时同步拉取最新库存余量，避免超量下单。多字段且带行业标准单位的特征，要求表单为每个字段配置单位提示与格式校验规则，例如批次号需匹配“字母+数字+日期”的固定格式，重量字段需自动识别并转换为统一计量单位。合规备案相关字段需强制关联附件上传入口，确保提交时同步提交检测报告等合规材料。复杂的流程节点字段需支持分步折叠展示，避免单页表单内容过多导致操作失误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 单字段输入长度限制 800–1200 字符 | 覆盖化工材料检测说明、工艺参数描述等常规长文本输入需求 |
| `userSelect` | 预设选项分页展示，每页 10–15 条 | 化工原料牌号、审批角色等可选值数量较多，分页可优化交互体验 |
| 输入框超时时间 | 600 秒 | 化工业务办理需上传较大体积的检测报告附件，或填写多步骤表单，该时长可避免正常操作被中断 |
| 附件上传限制 | 单文件上限 1000 MB | 化工合规检测报告多为多页PDF或扫描件，该大小可覆盖常规文档需求 |
| 表单分步展开 | 按流程节点分组展开 | 化工业务办理表单字段较多，分组可降低操作复杂度 |
| 必填字段校验 | 提交前实时校验 | 避免因必填字段遗漏导致的流程回退，符合化工业务的合规要求 |

## 容易做错的三处
- 现象：选择原料牌号的`userSelect`组件加载后无可选数据。原因：未配置对应数据源的动态拉取规则，或数据源更新频率与表单加载时机不匹配。
- 现象：表单提交后输入框未自动重置，持续保留上一次输入内容。原因：未开启`formInput`的提交后清空配置，或工作流中未添加输入框重置节点。
- 现象：代码运行节点执行时校验失败，提示包含历史记录字段。原因：未过滤工作流输入中的历史会话数据，直接将其传入代码运行节点，触发参数校验规则。

## 怎么确认配好了
- 打开表单编辑页面，选择任意`formInput`字段，验证输入长度限制提示是否正常展示。
- 进入`userSelect`组件配置页，测试触发数据源拉取，确认可选列表正常加载。
- 提交测试表单，检查输入框是否在提交后自动清空，附件上传功能是否正常触发。
- 模拟包含历史记录的输入，触发代码运行节点校验，确认校验规则正常生效。
