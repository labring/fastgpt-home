# 化肥农药的业务办理流程引导：文档解析与分块

## 这个品类的数据长什么样
化肥农药相关业务办理的文档主要来自农业农村部门备案文件、农资经营许可档案、农药登记证、肥料配方报告等。文档更新随行业备案与经营许可复核节奏调整，包含结构化表格（如成分含量表、使用剂量表）、长段落合规说明、标准化业务办理流程节点等结构。字段包含有效成分含量、登记证号、使用剂量单位等农业专属参数，部分文档附带多语言合规注释。

## 这些特征在「文档解析与分块」这一环带来什么约束
文档中的结构化表格需完整提取字段，避免拆分跨单元格的参数内容；长段落合规说明与流程节点需保留逻辑连贯性，不能将连续的业务步骤拆分至不同块中；农业专属单位与对应参数需绑定，不能拆分至跨单位的分块内容；批量解析的备案文档体积较大，需适配合理的超时与文件大小限制，避免解析失败。

## 配置怎么定
当前适配FastGPT v4.17.0版本的配置逻辑如下：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配化肥农药文档中长合规段落与结构化表格的组合长度，避免拆分跨关键字段的内容 |
| `chunkSplitter` | 按段落+标题拆分 | 匹配文档按章节、流程节点划分的结构，保留业务办理流程的逻辑连贯性 |
| `customPdfParse` | 启用表格提取模式 | 针对文档中大量成分表、用量表的结构化内容，确保完整提取表格字段 |
| `UPLOAD_FILE_MAX_SIZE` | 100 MB | 适配单份农资备案文档的常见体积，避免超出解析上限 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 应对长文档解析时的合规说明章节加载耗时，确保完整解析 |
| `chunkSettingMode` | 手动配置 | 针对行业特定的单位与字段绑定需求，灵活调整分块规则 |

## 容易做错的三处
- 解析后的文档缺失表格字段，知识库展示中无成分含量或用量信息。原因是未启用`customPdfParse`的表格提取模式，默认解析逻辑未完整抓取结构化表格内容。
- 批量解析部分文件提示超时，任务状态显示为失败。原因是未调整`PARSE_FILE_TIMEOUT_SECONDS`的取值，长备案文档的解析耗时超出默认设置。
- 分块后的内容跨业务流程节点，如将“申请材料提交”与“现场核验”拆分至不同块中。原因是`chunkSize`设置过小，且未按标题+段落拆分分块规则。

## 怎么确认配好了
- 上传单份包含成分表格的农药登记证文档，检查解析结果中的表格字段是否完整提取，确认`customPdfParse`的配置生效。
- 查看批量解析任务的日志，确认所有文件的解析耗时未超过`PARSE_FILE_TIMEOUT_SECONDS`的设置值，无超时报错。
- 随机抽取分块后的内容，检查是否按文档标题与段落划分，未出现跨业务流程的拆分。
- 调整`chunkSize`的取值并重新解析测试文档，观察分块后的内容长度是否符合预期，确认`chunkSettingMode`为手动配置状态。
