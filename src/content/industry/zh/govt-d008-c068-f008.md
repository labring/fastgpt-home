# 医药流通的业务办理流程引导：文档解析与分块

以下配置基于FastGPT v4.17.0版本。

## 这个品类的数据长什么样
医药流通的业务数据主要来自GSP合规文档、采购入库出库订单、药品流通追溯报告、内部业务办理流程手册四类。数据来源包含本地PDF、Excel表格、语雀公开分享页面与企业内部系统导出文件。更新节奏随业务节点变动，采购订单随交易生成实时更新，合规文档每季度随监管要求修订，追溯报告随药品流通环节逐次更新。文档结构包含长文本合规说明、表格型业务清单与带内嵌图片的流程指南，字段包含药品通用名、批准文号、批号、流通节点与办理时限，单位多为盒、箱、批次与自然日。

## 这些特征在「文档解析与分块」这一环带来什么约束
多来源的数据格式要求解析工具兼容PDF、Excel与网页链接，单一解析配置无法覆盖全部场景。高频更新的业务文档需支持快速同步，避免因解析延迟影响业务办理引导的时效性。长文本合规文档与表格型订单混合存在，分块时需避免拆分药品批号、流通时限等关键业务字段，否则会导致流程引导出现信息断裂。内嵌图片的流程指南需支持图片提取，否则无法完整传递业务办理的可视化步骤。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配医药流通文档的长文本与表格结构，保留业务字段完整性 |
| `chunkSplitter` | 按段落+标题拆分 | 匹配业务流程文档的步骤标题与段落划分，避免截断流程逻辑 |
| `customPdfParse` | 启用OCR模式 | 适配扫描版GSP合规文档，提取内嵌图片与印刷文本内容 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 支持批量上传大体积的流通追溯文档，避免解析超时中断 |
| `chunkSettingMode` | 手动配置 | 可针对合规手册、采购订单等不同文档类型调整分块参数 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 兼容企业导出的批量业务数据文件 |

## 容易做错的三处
- 现象：上传语雀公开链接后，系统提示“无法获取网页内容”。原因：未确认语雀链接是否为完全公开可访问状态，医药流通的内部流程文档常设置部门权限，导致解析请求无法获取内容。
- 现象：解析后的扫描版GSP文档仅显示文本，无内嵌的流程示意图。原因：未启用`customPdfParse`的OCR图片提取配置，扫描版的药品流通流程指南无法提取图片信息。
- 现象：调用HTTP业务工具时，后台日志显示参数解析成功，但工具未触发预设的审批流程。原因：未将分块后的业务字段与工具调用参数绑定，导致大模型无法获取正确的业务上下文触发规则。

## 怎么确认配好了
- 上传一份扫描版GSP合规文档，查看解析结果是否包含原文档中的药品流通流程示意图与印刷文本。
- 上传一份批量采购订单Excel，检查分块后的内容是否保留了完整的药品批号、流通节点与办理时限字段。
- 输入一条公开可访问的语雀业务流程链接，确认解析任务状态为“完成”且内容无明显缺失。
- 触发一次工具调用测试，确认后台日志显示参数被正确传递且工具执行记录正常。
