# 危化品储运的业务办理流程引导：表单与交互

仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这个品类的数据长什么样
危化品储运的数据主要来自企业内部储运台账、属地应急管理部门的危化品备案数据库。数据更新节奏为企业台账每日更新，备案数据每周同步。单条文档结构包含储运主体统一社会信用代码、危化品通用名称、CAS登记号、存储库区编号、存储量（单位为吨或立方米）、合规存储条件、审批文号等字段，字段需严格匹配安监部门公示的合规格式。

## 这些特征在「表单与交互」这一环带来什么约束
危化品储运数据的合规字段要求，要求表单需对统一社会信用代码、CAS号、存储量等字段设置格式校验规则，避免不合规数据提交。数据来源包含官方备案库，要求表单支持通过备案编号快速关联已有合规数据，减少手动输入错误。数据更新频率较高，要求表单的危化品选项列表需支持每日动态拉取最新备案数据。不同危化品的存储量单位存在差异，要求表单支持单位自动匹配或手动切换，适配多品类数据录入。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 为每个合规字段配置独立输入框，添加格式校验规则 | 危化品储运数据字段有严格合规格式，需提前校验避免无效提交 |
| `userSelect` | 配置每日动态拉取的危化品备案列表作为下拉选项 | 官方备案数据实时更新，固定选项无法匹配最新合规品类 |
| `formInput` | 为存储量字段绑定单位切换选项，支持吨、立方米、升的选择 | 不同危化品的存储计量标准存在差异，适配多品类数据录入 |
| 表单提交校验超时 | 15-20秒 | 需等待备案数据关联查询完成，超时时间不宜过短 |
| 外部变量绑定 | 开启备案编号变量传入功能 | 支持从外部系统传入备案编号，自动关联已有合规数据 |
| 文件上传配置 | 为合规证明字段开启图片/文档上传功能 | 需支持存储证明、审批文件等合规材料的提交 |

## 容易做错的三处
- 现象：提交表单后出现「字段格式不匹配」报错，且无法自动修正。原因：未针对危化品专属字段（如CAS号、统一社会信用代码）配置对应格式校验规则，导致合规数据被拦截。
- 现象：选择特定危化品品类后，关联的知识库搜索结果为空。原因：未将危化品品类与对应合规知识库绑定，仅使用通用知识库进行搜索，无法匹配细分场景的合规文档。
- 现象：表单无法上传存储证明等文件，导致合规材料提交失败。原因：未配置`formInput`的文件上传参数，仅开启了文本输入功能。

## 怎么确认配好了
- 手动输入一个符合格式的CAS号，检查是否触发格式校验，错误格式时弹出对应提示。
- 输入备案编号后，检查对应存储主体、危化品名称等字段是否自动填充完整。
- 切换危化品品类，确认存储量的单位选项是否同步更新，适配对应品类的计量标准。
- 手动上传一张合规证明图片，检查是否能正常提交并保存。
- 提交测试数据，检查是否在15-20秒内完成校验并返回正确结果。
