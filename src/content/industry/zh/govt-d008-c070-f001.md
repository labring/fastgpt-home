# 发电装备制造的业务办理流程引导：HTTP 接口与外部系统

## 这个品类的数据长什么样
发电装备制造的业务办理流程相关数据主要来源于设备运维管理系统、企业资源计划（ERP）系统、生产调度平台三类核心数据源。数据更新节奏分为三类：设备实时运行参数每10秒更新一次，工单办理状态实时同步，月度备件库存、年度产能报表每日更新。数据结构为标准化JSON格式，核心字段包括设备ID、工单编号、当前办理节点、预计完成时长，单位统一为设备参数对应国际标准单位，如温度为℃、压力为MPa，工单时长为分钟。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
发电装备制造的数据特征对HTTP接口与外部系统环节带来多重约束。高频更新的实时设备参数要求接口具备低延迟响应能力，避免数据滞后影响流程引导的准确性。多数据源的结构化数据需要接口支持严格的字段校验，确保传入的设备ID、工单状态等字段格式符合业务规范。业务办理流程涉及多部门审批，接口调用需携带完整的权限上下文，防止越权访问敏感生产数据。同时，多节点关联的工单数据要求接口支持按工单编号关联查询多环节信息，减少重复调用外部系统的次数。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {发电装备制造系统专属API密钥}` | 适配内部专网部署的鉴权要求，防止未授权接入生产数据 |
| `variables` | `{"device_id": "GEN-003", "work_order_status": "pending"}` | 匹配发电装备工单、设备的核心业务字段，精准触发流程引导 |
| `responseData` | 仅返回当前办理节点、预计完成时长 | 适配业务办理流程引导的轻量化数据需求，降低接口传输负载 |
| 接口超时时间 | 600 秒 | 发电装备的业务办理流程涉及多环节审批，需预留足够的接口响应时长 |
| 上下文传递 | 前 3 条历史对话 | 匹配发电装备业务办理的短流程特征，避免冗余上下文占用接口带宽 |

## 容易做错的三处
- 接口返回`401 Unauthorized`状态码，业务办理流程引导无法加载数据。原因是未正确配置`Authorization`参数，使用了过期或无权限的API密钥。
- 接口返回空的响应数据，流程引导节点显示空白。原因是未正确配置`responseData`过滤规则，返回了不符合业务需求的字段导致解析失败。
- 容器启动后3000端口无法访问，日志仅显示到启动初始化步骤。原因是未正确配置`variables`参数中的设备ID，导致外部系统校验失败，接口调用阻塞。

## 怎么确认配好了
- 调用配置好的HTTP接口，检查返回的响应数据是否包含当前办理节点、预计完成时长字段。
- 验证鉴权方式的有效性，使用无效密钥发起调用，确认返回`401 Unauthorized`状态码。
- 调整`variables`中的设备ID为测试环境的真实设备，检查接口是否返回对应工单的办理流程数据。
