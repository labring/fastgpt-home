# 发电装备制造的业务办理流程引导：工具调用与插件

## 这个品类的数据长什么样
发电装备制造的业务办理数据主要来自设备运维日志、零部件质检报告、项目BOM清单与行业技术标准文档。数据更新节奏随业务环节变化：运维日志随设备运行实时生成，BOM清单在项目立项或变更时更新，行业标准文档每季度或年度修订。单份文档以设备或工单为单位，包含部件编号、额定功率、运行温度阈值、维护周期、故障代码等字段，字段单位统一使用国际标准单位，如kW、℃、小时、次。

## 这些特征在「工具调用与插件」这一环带来什么约束
发电装备制造的数据特征对工具调用与插件环节带来多重约束。实时生成的运维日志要求工具调用的本地缓存时长不宜过长，避免返回过时的设备运行数据。项目级的BOM清单变更频繁，要求插件支持动态绑定项目编号作为调用参数，确保拉取的备件信息与当前工单匹配。设备故障代码与运行参数存在强绑定关系，要求工具调用必须携带设备唯一编号作为必选输入项，否则无法精准匹配对应故障处理流程。行业技术标准文档的结构化字段固定，要求插件的输出格式需严格遵循标准字段命名，避免参数不匹配导致调用失败。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工具调用超时时间 | 300–600 秒 | 发电装备制造的业务数据多涉及跨系统拉取，如运维日志、备件库存数据，较长的超时时间可避免因数据拉取延迟导致调用失败。 |
| `toolChoice` | `auto` | 业务办理流程涉及多类工具调用，如工单查询、备件申领，自动模式可根据用户输入自动选择合适工具。 |
| 必选参数校验 | 启用设备编号、工单ID作为必选校验项 | 发电装备的业务数据均绑定设备或工单标识，缺失标识将无法匹配对应业务数据。 |
| 插件缓存时长 | 1–4 小时 | 运维日志的更新频率为分钟级，BOM清单变更频率较低，缓存时长设置为1-4小时可平衡数据时效性与调用性能。 |
| `functionCall` | 按业务工具列表启用 | 将业务办理中常用的工单查询、备件申领、故障排查工具纳入可调用范围，确保模型可按需调用。 |
| 工作流嵌套调用校验 | 启用子工作流执行状态回传 | 避免出现子工作流执行完成后父工作流无法接收执行结果的问题，匹配实际业务办理的流程联动需求。 |

## 容易做错的三处
- 现象：父工作流调用子工作流后，子工作流中用户选择节点之后的所有节点未执行。原因：未启用子工作流的执行状态回传配置，父工作流无法获取子工作流的执行进度，终止后续联动流程。
- 现象：调用内置工具获取业务数据时，返回空的响应内容。原因：未配置工具调用的必选参数校验，或模型未正确绑定工具的输入输出格式，导致工具无法正常拉取对应数据。
- 现象：调用视觉工具处理png格式图片时，返回400格式错误。原因：未在工具配置中添加png格式的允许范围，或近期模型接口更新了格式校验规则，导致合法格式被拦截。

## 怎么确认配好了
- 在FastGPT v4.17.0版本的测试面板中，手动触发工具调用，输入完整的必选参数，如设备编号、工单ID，检查是否能返回对应业务数据。
- 配置`toolChoice`为`auto`后，输入包含多类业务需求的测试语句，检查模型是否自动选择匹配的工具。
- 触发工作流嵌套调用，检查子工作流执行完成后，父工作流是否能正确接收执行结果并继续后续流程。
- 调用视觉工具上传png格式图片，检查是否能正常返回处理结果，无格式报错。
