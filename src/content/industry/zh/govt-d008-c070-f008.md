# 发电装备制造的业务办理流程引导：文档解析与分块

以下配置基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
发电装备制造的业务文档主要来源于企业内部设备运维手册、生产工艺规程、质检报告、招投标合规文件，以及行业监管的技术标准文档。文档更新节奏随新设备投产、工艺迭代或监管要求调整，无固定周期。文档结构多包含固定章节模块，内嵌结构化参数表格、设备参数明细与长段落操作说明，字段多涉及兆瓦、千伏、运行小时数等专业单位，部分文档附带设备图纸标注与物料清单。

## 这些特征在「文档解析与分块」这一环带来什么约束
发电装备制造的长文本多、结构化内容密集的文档特征，对文档解析与分块带来多重约束。长段落与连贯的业务流程内容，要求分块需保留语义上下文，避免割裂操作步骤、故障排查逻辑；内嵌的参数表格与明细字段，要求解析工具需保留原始排版与行列关联，防止参数值与对应说明脱节；单份文档体积可达数百兆，易触发上传与解析超时、内存超限问题；专业术语密集的内容，要求分块边界需贴合业务语义，确保问答对提取的准确性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 发电装备文档含长段落与专业参数，该区间可保留语义完整性，避免参数与说明被割裂 |
| `chunkSplitter` | 按语义段落拆分 | 适配设备运维手册、工艺规程等含连贯业务流程的文档，避免割裂操作步骤 |
| `customPdfParse` | 启用结构化解析模式 | 适配文档内的参数表格、设备图纸标注，保留原始排版与字段关联 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 覆盖单份大型设备手册的体积上限，防止上传中断 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 为大文件解析预留充足处理时间，避免中途超时终止 |
| `chunkSettingMode` | 手动配置 | 可针对运维手册、质检报告等不同文档类型调整分块参数，适配业务场景 |

## 容易做错的三处
- 上传大体积PDF文档至知识库时，解析进度至90%左右弹出“偏移量超出范围”报错。原因：未调整`UPLOAD_FILE_MAX_SIZE`与`PARSE_FILE_TIMEOUT_SECONDS`参数，大文件解析超时或内存占用超限。
- 通过创建文件集合API上传与平台直接上传同一份发电装备文档，生成的chunk分段结果不一致。原因：未统一配置`chunkSettingMode`与`chunkSplitter`参数，API与平台默认分块规则存在差异。
- 直接对设备运维文档执行分块后，无法提取有效业务问答对。原因：未启用`customPdfParse`结构化解析，且分块未按语义拆分，割裂了问答关联的上下文。

## 怎么确认配好了
- 上传单份500 MB以上的发电装备手册，检查解析进度是否完成，无偏移量报错。
- 对比API上传与平台直接上传同一份文档的分块结果，确认分段逻辑一致。
- 查看解析后的chunk内容，确认设备参数表格、操作步骤段落未被割裂。
- 测试提取文档内的业务问答对，确认关联上下文被完整保留在单个chunk内。
