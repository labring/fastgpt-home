# 发电集团的业务办理流程引导：文档解析与分块
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这个品类的数据长什么样
发电集团的业务办理文档主要来源于内部业务流程手册、电力合规审批表单、月度检修台账、集团级合规汇编等。更新节奏随合规要求调整，年度合规文件每年更新，内部业务流程在重大政策调整后更新。文档结构多包含固定审批节点、材料清单、时限要求，伴随大量结构化表格，字段包含机组编号、审批时限、申请部门、设备型号等，单位涵盖工作日、MW、台套等。

## 这些特征在「文档解析与分块」这一环带来什么约束
发电集团的业务文档包含大量结构化表格与固定逻辑的审批流程，要求文档解析环节保留表格结构与字段完整性，避免拆分跨节点的流程内容。部分文档单份篇幅可达数百页，解析耗时较长，需适配更长的超时设置。文档类型差异显著，既有数页的临时审批表单，也有数十页的年度合规手册，需支持灵活的分块配置。同时，紧急更新的业务文档需快速完成解析，不能因配置限制导致训练延迟。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配发电集团业务文档中审批流程、材料清单的单段信息长度，避免拆分跨审批节点的内容 |
| `chunkSplitter` | 按标题+段落拆分 | 匹配业务文档按章节、节点划分的结构，保留审批流程的逻辑完整性 |
| `customPdfParse` | 开启表格解析模式 | 适配文档中大量设备台账、审批表单的表格结构，还原字段与单位信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 应对单份合规手册类文档的长文本解析耗时，避免超时中断 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 支持上传集团级的年度合规汇编文档，满足批量训练需求 |
| `chunkSettingMode` | 手动配置 | 针对不同类型的业务文档灵活调整分块参数，适配差异化内容结构 |

## 容易做错的三处
- 上传PDF后搜索测试结果为空，且无解析完成提示。原因是未开启`customPdfParse`的表格解析模式，导致表单类文档的字段无法被提取，数据处理环节为空。
- 本地部署后知识库训练时数据处理为空。原因是`UPLOAD_FILE_MAX_SIZE`配置低于上传文档的实际大小，文件未完全上传即被截断。
- 对话功能时而出现异常。原因是`PARSE_FILE_TIMEOUT_SECONDS`设置过短，长文档解析未完成即进入训练环节，导致知识库内容缺失。

## 怎么确认配好了
- 上传一份集团内部的审批表单PDF，查看解析后的文本是否保留表格的行列结构与字段单位。
- 上传一份超过500页的合规手册文档，确认解析过程未出现超时报错。
- 调整`chunkSize`参数后，分块预览界面显示的内容未跨审批节点或关键流程段。
- 测试上传不同大小的文档，确认上传进度与解析状态正常显示。
