# 发电集团的业务办理流程引导：表单与交互

## 这个品类的数据长什么样
发电集团的业务办理数据来源为内部ERP系统、各下属电厂工单台账及线下业务归档文件。数据更新节奏为每日同步核心业务字段，每周全量更新归档历史数据。单条业务数据的文档结构包含业务ID、申请主体、申请类型、提交时间、所需材料列表、当前办理环节、对接人联系方式。字段格式有明确规范：业务ID为纯数字字符串，提交时间为标准时间戳格式，对接人联系方式为带区号的手机号格式，所需材料列表为多段文本。

## 这些特征在「表单与交互」这一环带来什么约束
内部多系统同步的数据存在字段格式差异，要求表单支持自定义字段映射规则，适配不同来源的业务数据。每日更新的业务材料清单，要求表单加载时实时拉取最新版本，避免出现已取消的材料选项。业务ID、手机号等特定格式字段，要求表单内置格式校验逻辑，拦截不符合规范的输入。多业务类型的动态字段需求，要求表单支持按申请类型切换配置项，避免固定字段导致的冗余或缺失。同时，发电集团业务涉及内部权限管控，要求表单对接角色权限体系，限制不同岗位的可见字段与操作权限。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 表单输入校验规则 | 针对业务ID、手机号分别配置专用正则表达式 | 适配发电集团业务数据的特定格式要求，拦截无效输入 |
| 动态字段加载逻辑 | 按申请类型加载对应材料字段 | 匹配多业务类型的表单结构差异，避免字段冗余 |
| 数据源同步周期 | 每日凌晨2点同步 | 匹配业务数据每日更新的节奏，保证表单字段实时性 |
| `formInput` | 开启输入防抖，防抖间隔300毫秒 | 适配FastGPT v4.17.0版本的表单配置逻辑，减少高频输入触发的重复校验请求，降低系统负载 |
| `userSelect` | 按岗位角色限定可选业务范围 | 适配内部权限管控要求，避免越权操作 |
| 单次上传上限 | 5个文件，单文件最大100 MB | 匹配发电集团业务材料的常规大小和数量要求 |

## 容易做错的三处
- 现象：表单上传的发电集团业务材料（如工程审批单、用电申请单）无法正常解析，界面提示“文档格式不支持”。原因：未配置发电集团常用的专业文档格式解析规则，仅支持通用办公文档格式。
- 现象：表单提交后返回“字段格式错误”，但输入内容符合业务规范。原因：内置的输入校验正则未适配发电集团业务ID的长字符串格式，拦截了合法输入。
- 现象：关联业务知识库的表单仅返回单条匹配结果。原因：默认召回逻辑仅取相似度最高的单条结果，未调整为适配业务办理所需的多来源参考信息。

## 怎么确认配好了
- 提交一条符合发电集团业务规范的测试数据，校验规则未拦截合法输入，确认校验配置生效。
- 切换不同的业务申请类型，确认表单加载的材料字段对应匹配，确认动态配置生效。
- 上传发电集团常用的专业文档，确认可以正常解析并提取内容，确认格式规则配置生效。
- 提交表单后查看关联知识库的召回结果，确认返回条数符合业务办理的实际需求，调整`userSelect`的召回配置至合适范围。
