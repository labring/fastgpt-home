# 发电集团的业务办理流程引导：部署与升级

## 这个品类的数据长什么样
发电集团的业务办理流程引导数据，主要来源于内部OA系统、电力业务办理平台及最新电力监管政策文件。数据按业务类型划分为并网申请、用电报装、资质审核等多个模块，每个模块包含办理步骤、所需材料清单、办理时限、咨询渠道等字段。数据更新节奏随政策调整或业务流程优化触发，单次更新覆盖对应业务模块的全量文档，文档以结构化文本为主，部分包含附件格式说明，字段统一使用电力行业标准术语，办理时限单位为工作日，材料清单标注格式要求。

## 这些特征在「部署与升级」这一环带来什么约束
发电集团的业务数据包含大量电力专业术语与结构化字段，部署时需适配内网环境的代理配置，确保能拉取更新后的政策文档。数据更新频率随业务调整波动，升级过程中需保留自定义术语库配置，避免专业术语识别偏差。结构化文档的字段差异会影响向量库的索引结构，部署前需校验现有数据与新版本FastGPT的字段映射规则。敏感业务数据的存储需遵循电力行业数据安全规范，对应存储配置需符合加密要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `80–120 条连接` | 适配发电集团业务办理的并发访问量，避免数据库连接耗尽 |
| `MONGODB_URI` | `mongodb://fastgpt-user:secure-pass@internal-mongo:27017/fastgpt_db?authSource=admin` | 对接集团内网专属MongoDB实例，使用专用权限账号，符合数据安全要求 |
| `REDIS_URL` | `redis://:redis-secure-pass@internal-redis:6379/1` | 内网部署的Redis缓存服务，使用独立数据库索引，隔离业务会话与其他缓存数据 |
| `STORAGE_S3_ENDPOINT` | `http://power-group-s3:9000` | 对接集团内部对象存储服务，适配内网访问路径，用于存储业务文档与聊天附件 |
| FE_DOMAIN | `https://fastgpt.business.power.com` | 使用集团内部二级域名，便于内网用户直接访问，符合内部系统命名规范 |
| `FILE_TOKEN_KEY` | `随机生成32位字符` | 用于文件上传的令牌签名，保障附件访问的安全性 |

## 容易做错的三处
- 内网环境下无法拉取外部政策文档，界面显示连接超时。未配置带用户名密码的HTTP代理，导致无法通过代理访问互联网获取最新业务数据。
- 升级至FastGPT v4.17.0后，自定义电力专业术语库失效，业务引导中的专业词识别出现偏差。未备份并恢复部署阶段的配置文件，导致升级后配置重置。
- 保存大模型配置后，聊天时调用的模型与设置不符。未正确验证管理员权限，导致配置未成功写入系统，调用默认模型参数。

## 怎么确认配好了
- 执行`docker ps`命令，查看FastGPT相关容器的运行状态，确认所有容器处于正常运行状态。
- 在内网环境中访问`FE_DOMAIN`配置的域名，验证是否能正常打开系统首页并加载业务文档。
- 上传一份电力业务办理的结构化文档，验证向量库是否能正确生成索引并完成分词。
- 尝试修改管理员配置，验证配置是否能成功保存并生效，无报错提示。
