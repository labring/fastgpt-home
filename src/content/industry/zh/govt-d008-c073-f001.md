# 国有产业基金的业务办理流程引导：HTTP 接口与外部系统

## 这个品类的数据长什么样
国有产业基金的业务办理数据主要来源于国有资本投资运营平台的项目申报台账、审批节点记录、资金拨付档案三类系统。数据更新节奏随单笔业务办理流程触发，每个审批节点完成后实时更新对应业务条目。单条业务数据的文档结构为结构化JSON格式，包含项目ID、申报主体全称、申请金额（单位：万元）、当前审批节点状态、经办人账号、提交时间（格式：YYYY-MM-DD HH:mm:ss）等字段，其中审批节点状态为固定枚举值。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
国有产业基金的业务数据来源分散，需对接多套外部系统，因此接口鉴权需适配不同系统的身份校验规则，需通过`Authorization`参数携带合法服务密钥完成校验。数据的结构化要求严格，仅允许传递预定义的枚举字段与数值字段，因此接口返回的`responseData`需精准过滤非业务字段，避免破坏流程引导的字段映射逻辑。数据更新的实时性要求较高，单次接口调用的响应时长需控制在合理范围，同时全局变量的赋值需严格匹配`variables`配置的字段路径，确保业务流程能正确获取最新的审批状态与资金信息。

## 配置怎么定
本页面的配置规则基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {国资监管平台分配的服务访问密钥}` | 国有产业基金对接的外部业务系统采用OAuth2鉴权，需携带合法密钥完成身份校验 |
| `variables` | `映射为projectId、applyAmount、approvalStatus、operator` | 国有产业基金业务数据包含项目ID、申请金额、审批状态、经办人等核心业务字段 |
| `responseData` | `仅提取顶层结构化业务字段，过滤系统级元数据` | 外部接口返回数据包含冗余的系统日志、调用链路等非业务字段，需精准提取有效数据 |
| 接口超时设置 | 30 秒 | 国有产业基金业务办理的单次接口响应需控制在合理范围，避免流程阻塞 |
| 全局变量触发规则 | 仅在接口返回200状态码时触发 | 确保仅在接口调用成功后才更新业务流程的全局变量 |

## 容易做错的三处
- 现象：工作流全局变量未正确获取接口返回的业务数据，字段值为空或格式错误。原因：未按照`variables`配置项的映射规则指定正确的字段路径，错误提取了接口返回的非业务嵌套字段。
- 现象：接口调用返回400状态码，提示图片格式不支持。原因：未校验上传的业务附件格式，提交了不符合国有产业基金业务要求的文件类型。
- 现象：关联新建知识库的对话接口调用失败，无法绑定对应业务项目。原因：未将接口返回的知识库ID正确赋值到全局变量，导致对话流程无法匹配业务数据。

## 怎么确认配好了
- 调用测试接口，查看返回的`responseData`是否仅包含配置的业务字段，无冗余的系统级元数据。
- 手动校验`Authorization`配置的密钥有效性，通过调用鉴权接口返回200状态码完成验证。
- 触发模拟业务流程，查看全局变量面板是否正确映射了接口返回的项目ID、申请金额等字段。
- 模拟30秒的接口延迟场景，确认流程未出现阻塞或超时报错。
