# 国有产业基金的业务办理流程引导：模型接入与配置

## 这个品类的数据长什么样
国有产业基金的业务办理流程相关数据，来源包括基金备案登记表、项目申报材料、审批流转记录、出资拨付凭证、政策合规文件等。数据更新节奏随业务节点触发，项目立项、审批通过、资金拨付等环节完成后即时更新。文档结构包含结构化字段与非结构化文本，结构化字段包括基金主体编码、申报项目编号、审批层级、出资额度（单位：亿元）等，非结构化内容包括尽调报告、流程说明文档等，单份文档长度跨度较大。

## 这些特征在「模型接入与配置」这一环带来什么约束
国有产业基金的数据特征会对模型接入与配置带来多项约束。首先，结构化与非结构化混合的数据格式，要求模型接入时适配多类型文档的解析规则，避免遗漏结构化字段的关键信息。其次，数据更新无固定周期，需配置支持增量同步的知识库更新机制，确保业务流程的最新信息被及时纳入。再者，字段带有专属单位与编码规则，模型调用时需保留字段的原始格式，防止出现单位混淆或信息失真。最后，业务流程文档的节点多、逻辑复杂，需精准控制上下文与引用长度，保障模型能完整调用流程相关信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配国有产业基金业务文档的平均长度，避免截断审批流程、项目尽调等核心内容 |
| `quoteMaxToken` | 1500–2000 token | 匹配单份核心业务文档的关键段落长度，确保引用的流程说明完整可被模型识别 |
| `temperature` | 0.1–0.3 | 降低生成随机性，保证业务流程引导的回答符合官方合规要求与实际操作逻辑 |
| `toolChoice` | auto | 允许模型按需调用检索工具，处理跨多个审批节点的复杂流程查询 |
| `AIPROXY_API_ENDPOINT` | 按FastGPT v4.17.0平台分配的专属接入地址填写 | 保障模型调用的合规性与链路稳定性 |
| `AIPROXY_API_TOKEN` | 按FastGPT v4.17.0平台分配的专属密钥填写 | 完成接口调用的身份验证，防止未授权访问 |

## 容易做错的三处
- 现象：语义检索召回多条相关内容，但模型返回未找到相关信息。原因：`maxContext`设置过小，召回的引用内容被截断后无法被模型完整解析。
- 现象：模型响应耗时过长，超出业务办理的实时等待阈值。原因：`quoteMaxToken`设置过高，导致单次传入的引用内容过多，超出大模型的处理上限。
- 现象：知识库同步后未更新最新业务流程。原因：未适配国有产业基金的结构化字段格式，增量同步时无法正确识别更新的编码与额度信息。

## 怎么确认配好了
- 提交包含具体国有产业基金项目审批节点的查询，核对返回内容中引用的文档片段与知识库内的原始内容一致。
- 查看FastGPT平台的模型调用日志，确认`quoteMaxToken`的实际使用值处于配置的取值区间内。
- 模拟多并发查询场景，验证响应速度符合业务办理的实时性要求。
- 检查接口调用的返回状态码，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置正确，无认证或连接错误。
