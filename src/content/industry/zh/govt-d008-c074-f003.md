# 国有资产管理公司的业务办理流程引导：多轮对话与提示词

## 这个品类的数据长什么样
国有资产管理公司的业务数据来源于国资监管系统的存量资产备案数据、内部业务审批台账、产权登记档案与资产处置申请单。更新节奏为重大资产变动实时同步，常规业务台账按月更新。文档结构包含结构化表单与非结构化审批说明，结构化字段含资产编号、权属主体、审批节点、办理时限，单位多为万元、件、工作日。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
结构化字段与非结构化文档并存的特征，要求多轮对话需引导用户明确资产编号以缩小检索范围，避免返回无关数据。实时更新的重大资产变动数据，要求提示词中嵌入数据时效性校验逻辑，确保调用的是最新备案信息。审批节点的层级差异，要求多轮对话根据对话发起者的角色权限，过滤超出权限的审批流程信息，避免返回无权限查看的内容。月度更新的常规台账，要求提示词中明确数据更新周期，防止用户获取过时的业务办理时限信息。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 最大上下文 | 8000–12000 token | 适配国有资产管理公司业务文档的字段数量与审批流程长度，避免上下文溢出 |
| `chatId` 参数 | 绑定唯一会话标识 | 实现多轮对话的上下文连贯管理，确保同一会话内的业务引导逻辑一致 |
| `messages` 参数 | 保留最近10轮对话记录 | 避免过长上下文干扰当前业务办理流程的引导逻辑 |
| `variables` 参数 | 绑定资产编号、经办人角色变量 | 实现多轮对话中动态调用对应权限的业务数据 |
| 对话引用开关 | 关闭非必要引用 | 匹配业务办理场景中简洁展示流程信息的需求 |
| 对话开场白快捷按键 | 预设3个高频问题（如“资产处置流程”“产权登记要求”“审批节点查询”） | 简化用户发起业务咨询的操作步骤 |

## 容易做错的三处
- 对话返回“没有权限操作此对话记录”报错。未在`variables`中绑定经办人角色变量，导致提示词未过滤超出权限的审批流程信息。
- 知识库回答末尾自动附加引用内容。未关闭对话引用开关，默认启用了全量文档引用展示。
- 对话快捷按键未触发对应预设问题。未将快捷按键的预设问题与业务办理的高频场景绑定，或配置的触发逻辑未关联`messages`参数的上下文更新。

## 怎么确认配好了
- 发起包含资产编号的测试对话，检查返回的审批流程信息是否与对应资产的权限范围匹配。
- 查看回答内容末尾，确认未出现未授权的引用内容。
- 点击对话开场白的快捷按键，检查是否自动发送对应预设问题并返回相关流程引导。
- 发起多轮对话，检查上下文是否保留最近10轮记录且未出现逻辑混乱。
