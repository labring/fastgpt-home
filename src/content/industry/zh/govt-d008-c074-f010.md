# 国有资产管理公司的业务办理流程引导：知识库检索与召回

## 这个品类的数据长什么样
国有资产管理公司的业务数据主要来源于国资监管部门发布的规范性文件、公司内部业务办理规程、资产处置台账、产权登记档案及日常审批留痕文档。数据更新节奏分两类：政策类文档随监管要求调整，更新周期无固定频次；内部业务流程、资产台账类数据随业务办理动态更新。单份文档通常包含流程步骤、审批节点、提交材料清单、责任部门、办理时限等字段，资产相关字段附带万元、工作日等标准化单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
政策类文档更新无固定频次，要求知识库同步机制需适配不定期更新需求，避免召回过期监管要求。内部资产台账包含带单位的数值字段，检索时需匹配字段与单位的对应关系，防止因单位混淆返回错误流程指引。业务办理文档结构标准化，检索需优先召回包含具体审批节点、材料清单的精准片段，过滤泛化内容。部分业务文档涉及内部审批权限，检索召回需关联对应部门的权限范围，确保返回内容仅对授权用户可见。

## 配置怎么定
本文适配FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.78 | 匹配业务办理流程中精准的步骤、节点描述，过滤低相关的泛化内容，适配国资政策与内部流程的严谨性 |
| `limit` | 前8条 | 业务流程文档结构标准化，单场景相关文档数量适中，8条可覆盖完整审批链路的指引内容 |
| `searchMode` | 语义搜索 | 匹配业务流程中的步骤、材料等结构化文本，适配长流程的上下文关联需求 |
| `usingReRank` | 开启 | 对召回的候选结果按相关性重新排序，确保最贴合办理需求的流程步骤优先返回 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充业务场景的专属术语，比如将“资产处置”关联到国资监管的标准表述，提升检索召回的精准度 |
| `collectionIds` | 绑定专属业务集合 | 隔离国资政策、内部流程、资产台账三类数据，避免跨品类文档干扰检索结果 |

## 容易做错的三处
- 现象：AI生成的业务办理指引末尾固定附加“FastGPT 是一个基于大语言模型(LLM)的知识库问答系统”无关内容。原因：未在系统提示词中关闭默认品牌输出配置，导致强制追加固定宣传话术。
- 现象：通过docker-compose部署后，页面内的工作流列表、知识库列表为空，但调用接口可正常返回检索结果。原因：部署时未配置持久化存储挂载，容器重启后本地存储的应用配置、知识库索引数据丢失，后端接口依赖的数据库服务仍正常运行。
- 现象：检索召回的流程指引片段不完整，缺失关键审批节点内容。原因：知识库最大引用条数设置过低，或最大上下文参数配置不足，导致无法加载完整的业务流程文档内容。

## 怎么确认配好了
- 手动输入一条业务办理相关的查询，核对返回结果的来源文档是否属于绑定的专属知识库集合。
- 调整相似度阈值后，观察召回结果的相关度变化，确认阈值配置对检索结果的过滤效果符合预期。
- 开启问题优化功能后，输入包含国资专属术语的查询，核对检索结果是否匹配更精准的业务流程内容。
- 关闭重排功能后，对比召回结果的排序，确认重排配置对结果优先级的调整作用正常。
