## 这些特征在「工具调用与插件」这一环带来什么约束
结构化字段多且需匹配国资业务标准编码，导致工具调用时需严格校验传入参数的格式与编码规则，避免因字段不匹配导致调用失败。业务数据更新节奏非实时，插件调用时需限定缓存有效期，避免使用过期的审批节点数据。业务办理流程环节顺序固定，工具调用需按审批序列触发，不能跨环节调用，否则会导致流程引导错误。涉及出资人批复的字段，工具需关联国资监管外部接口，需额外配置权限校验逻辑，防止越权访问。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 设为`auto`，仅在明确需要调用国资业务插件时设为`required` | 适配国有资本投资公司业务办理的灵活调用需求，auto模式可自动判断是否需要调用工具，required模式可强制触发流程引导所需的插件调用 |
| `functionCall` | 开启，参数格式限定为国资业务字段标准 | 确保工具调用返回的参数符合内部业务文档的字段要求，避免格式不匹配 |
| 插件缓存有效期 | 7天 | 匹配国资业务数据的月度更新节奏，避免缓存过期或过长导致数据不一致 |
| 工具调用校验规则 | 开启国资编码校验 | 匹配业务数据的标准编码要求，防止传入非法字段 |
| 跨环节调用限制 | 开启 | 遵循国有资本投资公司业务办理的固定流程顺序，避免引导错误 |
| 超时阈值 | 600秒 | 适配国资业务办理的常规审批时长，避免因等待过长导致流程中断 |
| 插件联网源配置 | 替换为国内可访问的联网插件 | 适配国内网络环境，避免因谷歌插件无法访问导致工具调用失败 |

## 容易做错的三处
- 调用OpenApi聊天接口时返回参数格式错误提示，状态码400。未按照国资业务字段标准配置`functionCall`的参数格式，导致传入的工具调用参数不符合要求。
- 面对简短业务查询时直接一次性返回结果，未触发流式输出。未正确配置`toolChoice`的自动判断逻辑，导致未启用流式交互模式。
- 内容提取节点无法调用自建模型接口。未在插件配置中开启自建模型适配选项，导致节点仅支持内置模型调用。

## 怎么确认配好了
- 发起包含国资业务字段的测试请求，检查工具调用返回的参数是否符合内部文档的字段要求。
- 查看插件调用日志，确认是否按照业务流程顺序触发工具调用，未出现跨环节调用。
- 验证缓存有效期配置，检查超过设定时长后是否自动刷新业务数据。
- 测试`toolChoice`设为`required`的场景，确认工具是否强制触发插件调用。
