# 国有资本投资公司的业务办理流程引导：表单与交互

## 这个品类的数据长什么样
国有资本投资公司的业务办理数据主要来源于内部国资监管系统、项目申报管理系统与财务核算平台。数据更新节奏遵循国资监管部门的固定周期，包括月度、季度与年度更新。文档结构以单个业务项目为单位，包含项目主体基本信息、申报材料清单、审批节点字段等模块。字段包含项目投资额（单位：万元）、申报日期（格式：YYYY-MM-DD）、审批状态（枚举值：待提交/审核中/已通过/已驳回）、资金来源类型等国资专项要求的内容，部分字段需符合国资监管的标准化格式要求。

## 这些特征在「表单与交互」这一环带来什么约束
国有资本投资公司的业务数据多源且字段标准化程度高，要求表单交互需匹配国资监管的固定格式与枚举规则，避免因输入错误导致数据无法同步至内部系统。多模块的文档结构使得表单字段数量较多，需合理拆分以避免单次加载过多内容导致交互卡顿。固定更新周期要求表单校验规则需与数据更新节奏对齐，确保输入内容符合后续同步的格式要求。同时，部分字段需关联内部国资监管系统的枚举字典，需保证表单选项与内部系统的一致性，避免出现数据不匹配的情况。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 表单输入框配置 | 为国资专项字段添加固定单位提示，如「项目投资额（万元）」 | 匹配国有资本投资公司数据的字段单位要求 |
| 下拉选择组件 | 限定审批状态、资金来源等字段的可选值为枚举字典 | 对应国资监管要求的固定枚举字段 |
| `formInput` 校验规则 | 强制匹配字段格式，如申报日期为YYYY-MM-DD | 适配多系统同步的标准化数据格式 |
| `userSelect` 数据源 | 关联内部国资监管系统的枚举字典 | 保证表单数据与内部系统的一致性 |
| 表单分块加载 | 按审批节点拆分表单字段 | 避免一次性加载过多字段导致交互卡顿 |
| 输入超时阈值 | 300 秒 | 适配国资业务办理的较长流程时长 |

## 容易做错的三处
- 现象：尝试将其他链路节点跳转至表单节点时，无法触发表单加载。原因：未配置表单节点的跨链路跳转权限，未开启`formInput`的复用开关。
- 现象：开启输入引导并配置自定义词库地址后，调试预览出现报错。原因：自定义词库地址未绑定对应国资业务的专属词库，或词库格式不符合FastGPT v4.17.0的要求。
- 现象：引用知识库变量时出现quote type error报错。原因：变量引用格式未匹配字段类型，如对枚举字段使用了文本型引用方式。

## 怎么确认配好了
- 核对表单字段的单位提示是否与内部数据的字段单位一致，如项目投资额是否标注为万元。
- 测试下拉选择组件的可选值是否与国资监管系统的枚举字典完全匹配。
- 触发跨链路跳转至表单节点，确认表单可正常加载并接收传入的参数。
- 输入符合格式要求的测试数据，确认`formInput`的校验规则可正常拦截错误格式的输入。
