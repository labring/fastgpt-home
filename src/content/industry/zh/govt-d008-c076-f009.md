# 国有资本运营公司的业务办理流程引导：模型接入与配置

## 这个品类的数据长什么样
国有资本运营公司的业务办理数据主要来源于国资监管平台报送的业务台账、内部各业务部门的流程规范文档与办理记录。数据更新节奏随业务流程调整同步触发，日常按季度批量更新。单条结构化数据包含事项ID、事项名称、办理环节序号、环节名称、办理主体、所需材料清单、审批要求、办结时限（单位为工作日），同时配套非结构化的办事指南PDF文档，文档内包含流程步骤、常见问题等内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
国有资本运营公司的业务数据特征对模型接入与配置带来三点核心约束。第一，混合结构化业务台账与非结构化办事指南的双数据源结构，要求配置时同时适配结构化字段的精准匹配与非结构化文档的分块解析逻辑。第二，数据字段包含办结时限且单位为工作日，需在模型配置中锁定单位映射规则，避免生成引导时出现单位混淆。第三，数据按季度更新，向量库的同步周期需匹配该节奏，确保召回的流程数据始终与最新业务要求一致。此外，业务事项ID的唯一性要求召回环节按事项ID分组，避免跨事项的流程信息混淆。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |

| `maxContext` | `8000–12000 token` | 业务办理流程的文档包含多环节步骤与材料清单，需要足够上下文承载完整流程信息 |
| `temperature` | `0.1–0.3` | 国有资本运营业务需严谨准确，不宜生成过于发散的流程引导内容 |
| `quoteMaxToken` | `2000–3000 token` | 办事指南文档的单块内容长度适中，需保留足够的原文引用细节 |
| `toolChoice` | `auto` | 业务办理引导需自动选择合适的工具调用流程查询与材料匹配功能 |
| `AIPROXY_API_ENDPOINT` | 本地部署的大模型服务地址 | 需对接本地部署的大模型以保障国有资本运营数据的安全 |
| `AIPROXY_API_TOKEN` | 按本地部署配置生成的密钥 | 用于验证模型服务的访问权限，保障接口调用的安全性 |

## 容易做错的三处
- 调用本地部署模型时返回401 Unauthorized报错。原因是未正确配置`AIPROXY_API_TOKEN`参数，或密钥与本地模型服务的验证密钥不匹配。
- 模型生成的流程引导中出现办结时限单位错误。原因是未锁定字段的单位映射规则，导致模型混淆工作日与自然日的表述。
- 召回的流程数据与最新业务要求不符。原因是向量库同步周期未匹配季度更新节奏，导致过期数据被召回。

## 怎么确认配好了
- 检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置值，确认与本地模型服务的地址和密钥一致。
- 发起一次测试查询，核对返回的流程引导中是否包含正确的办结时限单位。
- 触发向量库同步任务，确认同步后的数据条目数与最新业务台账一致。
- 调整模型生成参数后发起多次测试，确认生成内容的严谨性符合业务要求。
