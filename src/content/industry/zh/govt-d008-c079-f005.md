# 城市燃气的业务办理流程引导：工具调用与插件

## 这个品类的数据长什么样
城市燃气业务办理流程引导的数据主要来源于属地城投旗下燃气运营系统、政务服务平台燃气业务模块，每日凌晨完成全量业务节点数据同步。单条数据为结构化JSON格式，包含办理事项唯一标识、事项名称、阶梯式流程步骤、必填材料清单、法定办理时限、当前办理节点状态等字段。时限单位为工作日，办理量统计单位为件，网点地址字段精确到街道门牌号，无冗余嵌套层级。

## 这些特征在「工具调用与插件」这一环带来什么约束
属地专属数据源要求工具调用时需配置对应燃气运营系统的专属访问密钥，无法复用通用政务接口。每日同步的更新节奏要求工具调用的缓存有效期设为不超过24小时，避免返回过期的办理节点数据。结构化JSON的固定字段要求工具调用的参数解析逻辑严格匹配预设字段名，需通过`functionCall`确保返回格式符合要求，不可随意调整映射规则。办理时限以工作日为单位，插件需自动将数字转换为符合用户认知的表述，不可直接返回原始数字。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配城市燃气业务办理流程的多步骤引导需求，自动匹配对应工具 |
| `functionCall` | 开启 | 确保工具调用时严格按照预设参数格式返回结构化结果，适配燃气业务数据的字段校验 |
| 工具调用超时时间 | 600 秒 | 燃气业务办理流程数据包含多节点步骤，完整拉取需较长时间，避免因超时中断调用 |
| 插件缓存有效期 | 23 小时 | 匹配数据源每日凌晨同步的节奏，避免缓存过期或数据滞后 |
| 单次调用返回条目上限 | 前 10 条 | 适配燃气业务办理流程的单页展示需求，避免返回过多数据导致页面卡顿 |
| 插件请求重试次数 | 2 次 | 避免因临时网络波动导致调用失败，提升工具调用的稳定性 |
| 参数校验开关 | 开启 | 针对燃气业务数据的固定字段格式，校验返回结果的字段完整性与格式正确性 |
| 结果格式化规则 | 转换时限单位为工作日 | 适配燃气业务办理时限的单位要求，将原始数字转换为符合用户认知的表述 |

## 容易做错的三处
- 现象为确认插件时弹出MongoServerError报错，提示$符号前缀不合法。原因是燃气业务数据中包含带$符号的字段名，在连接mongo:4.4.29版本数据库时，未对字段名做转义处理，触发数据库语法校验规则。
- 现象为调用MCP工具查询企业专利信息时返回无记录，但工具测试环节可正常返回结果。原因是工具调用时未正确传递企业统一社会信用代码参数，仅传递了企业名称，导致匹配不到对应数据。
- 现象为使用Markdown转文件插件时显示上传文件失败。原因是燃气业务办理流程的步骤文本包含大量换行与特殊符号，未先对文本做格式清洗，导致插件无法生成合法的Markdown文件。

## 怎么确认配好了
- 进入FastGPT v4.17.0的工具调试面板，输入燃气业务办理的测试事项ID，调用配置好的工具，检查返回结果的字段是否与预设的燃气业务数据结构一致。
- 查看插件的缓存日志，确认数据同步间隔符合预设的缓存有效期规则，无过期数据返回。
- 模拟工具调用时的异常参数输入，检查参数校验开关是否正常触发拦截，避免无效请求进入数据源。
- 触发Markdown转文件操作，检查生成的文件格式是否符合燃气业务流程文本的排版要求，无报错提示。
