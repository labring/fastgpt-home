# 基础化工的业务办理流程引导：HTTP 接口与外部系统

## 这个品类的数据长什么样
基础化工的业务办理数据主要来自生产执行系统（MES）、物料库存台账、安全监管上报系统。生产节点的实时数据每15分钟更新一次，库存台账每日凌晨同步，安监上报文档按周归档。单份业务办理文档包含申请单号、物料编码、批次号、办理状态、当前环节、提交时间等字段，物料编码为12位字符串，批次号含字母与数字组合，时间字段采用ISO 8601格式，部分工艺参数字段单位为兆帕、立方米每小时。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
本页面内容基于FastGPT v4.17.0版本编写。基础化工业务数据的多来源、差异化更新节奏，对HTTP接口与外部系统对接带来明确约束。实时生产数据的高频更新要求接口配置合理的超时与重试策略，避免响应延迟阻断业务流程。结构化字段的严格格式要求，需在请求参数中精准匹配物料编码、批次号的命名规则与格式。不同数据的更新周期差异，需对应配置差异化的拉取频率，避免频繁调用低频更新的接口占用资源。部分工艺参数的特有单位，需在接口返回后完成标准化转换，适配业务办理流程的校验规则。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 请求超时时间 | 600秒 | 覆盖基础化工业务办理的平均响应时长，避免提前中断请求 |
| 重试次数 | 3次 | 平衡接口调用成功率与系统资源占用 |
| `Authorization` | Bearer 格式，取值为外部系统分配的接口密钥 | 符合外部系统的身份校验要求，规避凭证类报错 |
| `variables` | 映射申请单号、物料编码为请求参数 | 确保接口请求携带完整的业务标识字段 |
| `responseData` | 提取办理状态、当前环节字段 | 快速获取业务节点信息，支撑流程引导逻辑 |
| 凭证刷新周期 | 按实测标定 | 适配外部系统的密钥更新规则，避免凭证失效 |

## 容易做错的三处
- 调用接口返回401或403状态码，日志或界面提示凭证校验失败。原因是未正确配置`Authorization`参数的格式，或使用了与外部系统不匹配的身份凭证。
- 接口返回的业务字段为空，无法匹配流程引导的分支条件。原因是`variables`映射的参数名与外部系统的字段名不一致，未正确传递业务标识信息。
- 接口调用多次重试后仍失败，导致业务流程中断。原因是未设置合理的重试触发条件，或重试次数配置过多占用系统资源。

## 怎么确认配好了
- 调用配置完成的HTTP接口，核对返回的`responseData`是否包含业务办理所需的核心字段。
- 模拟不同的业务办理节点状态，验证接口返回的字段是否能正确匹配流程引导的对应分支。
- 检查`Authorization`参数的配置格式，确认符合外部系统的身份校验规则。
- 查看接口调用日志，确认`variables`映射的参数是否正确传递了业务标识信息。
