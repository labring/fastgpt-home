# 基础化工的业务办理流程引导：文档解析与分块

## 这个品类的数据长什么样
基础化工领域的业务办理相关文档，主要来源于企业内部生产操作规程、安全合规文件、物料安全技术说明书（MSDS）、项目立项审批材料、设备运维记录。文档更新随合规要求调整、新项目落地同步推进，无固定周期但单次更新的单份文档篇幅较长。文档多包含固定字段，如物料编号、安全等级、操作步骤，单位常用吨、千克、MPa、℃，部分文档内嵌复杂物料衡算公式与多列数据表格。

## 这些特征在「文档解析与分块」这一环带来什么约束
长篇幅的生产规程与项目文档，若分块不合理会割裂操作步骤的上下文逻辑，影响后续流程引导的连贯性。内嵌的物料衡算公式与多列表格，对解析工具的格式还原能力提出更高要求，解析失败会导致关键数据丢失。固定字段与专用单位的存在，要求分块时需保留字段间的关联关系，避免拆分后字段错位。复杂合规参数的准确提取，直接决定业务办理流程引导的合规性，解析偏差会引发后续流程错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配基础化工文档中长操作段落与物料衡算公式的排版，避免单块内容过载或上下文割裂 |
| `chunkSplitter` | 按段落+标题锚点 | 匹配化工文档的章节式结构，保留操作步骤、合规条款与对应字段的关联性 |
| `customPdfParse` | 启用 | 支持复杂公式与多列表格的还原，适配物料安全技术说明书、生产规程中的内嵌格式 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 应对长篇幅化工文档的解析耗时，避免因超时中断解析流程 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配基础化工领域大容量的项目文档与运维记录上传需求 |
| `chunkSettingMode` | 手动模式 | 可针对不同类型文档（如MSDS、生产规程）调整分块规则，适配字段关联要求 |

## 容易做错的三处
- 现象：知识库里的PDF文档点击分块预览时返回「无法读取该文件内容」。原因：未启用`customPdfParse`配置，无法解析化工文档中内嵌的复杂公式或多列表格，导致解析失败。
- 现象：线上版本可正常返回复杂公式，本地版本解析失败。原因：本地部署的FastGPT v4.17.0版本与线上版本不一致，且未配置适配化工公式解析的专用解析组件，导致公式解析逻辑缺失。
- 现象：docker部署专用解析组件时出现运行报错。原因：未正确挂载GPU资源或镜像版本不匹配基础化工文档解析的依赖要求，导致解析组件无法正常启动。

## 怎么确认配好了
- 上传一份包含复杂公式与表格的基础化工PDF文档，查看解析后的文本格式是否完整还原公式与表格结构。
- 调整`chunkSize`的取值范围，验证不同长度下的分块结果是否保留了操作步骤的上下文关联性。
- 检查`PARSE_FILE_TIMEOUT_SECONDS`的配置，上传单份大容量文档，确认解析过程未出现超时中断。
- 切换`chunkSettingMode`为手动模式，针对不同类型的化工文档测试分块规则的适配效果。
