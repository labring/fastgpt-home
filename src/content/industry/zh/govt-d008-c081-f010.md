# 基础化工的业务办理流程引导：知识库检索与召回

## 这个品类的数据长什么样
基础化工的业务办理相关数据主要来源于企业内部的生产工艺规程、设备运维手册、行政审批流程规范、合规性检查记录。数据更新节奏随工艺迭代、合规要求调整，常规工艺文档每季度复核更新，临时审批流程随项目变动即时更新。文档多为结构化与半结构化混合，包含工艺参数（带MPa、℃、吨/小时等单位）、审批节点顺序、设备型号、合规标准编号等固定字段，部分文档附带设备实拍图与流程示意图。

## 这些特征在「知识库检索与召回」这一环带来什么约束
基础化工数据中的结构化参数与单位字段，要求检索时同时支持语义匹配与精准字段匹配，避免因单位换算误差导致召回错误。文档附带的流程示意图与设备实拍图，需要适配图文混合检索逻辑，避免仅检索文本时遗漏可视化流程指引。长文本的工艺规程分块时，需保留相邻节点的上下文关联，防止拆分后丢失审批流程的完整链路信息。合规类文档的版本字段需纳入检索过滤条件，避免返回过期的旧版流程规范。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.80 | 适配基础化工参数类文本的语义匹配精度，避免过低召回无关流程，过高遗漏相近工艺步骤 |
| `limit` | 前8条 | 基础化工业务办理流程的节点通常不超过6个，保留8条结果可覆盖完整流程与备选方案 |
| `searchMode` | hybrid | 支持语义检索与精准字段匹配，适配结构化参数与半结构化流程文本的混合检索需求 |
| `usingReRank` | 开启 | 基础化工文档存在大量参数细节，重排可过滤语义相似但参数不匹配的结果 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展业务办理类问题的同义词，比如将“动火审批”扩展为“动火作业许可办理流程” |
| `collectionIds` | 绑定基础化工专属知识库ID | 隔离其他品类的知识库数据，避免召回非本业务域的文档 |

## 容易做错的三处
- 检索返回的结果中嵌入的流程示意图无法正常加载，原因是上传文档时未将图片资源上传至绑定的静态资源目录，或未配置图片访问的跨域权限。
- 使用`bge-m3`向量模型时语义检索得分异常偏高，原因是未开启`usingReRank`，且未设置合理的`similarity`阈值，导致低关联度的长文本参数被误判为高匹配结果。
- 检索返回的业务节点顺序混乱，原因是分块时未保留流程节点的上下文关联，拆分后的文本块丢失了原文档的审批链路顺序。

## 怎么确认配好了
- 使用FastGPT v4.17.0版本的平台，上传一份包含工艺参数与示意图的测试文档，发起“动火作业审批流程”类问题的检索，检查结果中嵌入的图片是否正常加载。
- 调整`similarity`的取值区间，对比不同阈值下的召回结果，确认匹配精度符合业务场景的筛选需求。
- 开启`usingReRank`后，验证重排后的结果是否优先返回参数匹配度更高的流程文档。
- 检查检索结果的来源标识，确认仅包含绑定的基础化工专属知识库中的文档，无其他业务域的数据混入。
