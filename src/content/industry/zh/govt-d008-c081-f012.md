# 基础化工的业务办理流程引导：部署与升级

## 这个品类的数据长什么样
基础化工的业务办理数据主要来自生产台账、安全巡检记录、设备运维文档及行政审批材料。数据来源覆盖生产全流程，日常巡检记录每日更新，设备台账每月同步更新，行政审批类文档按需生成。单份文档结构包含设备编号、运行参数、操作步骤、审批节点等字段，单位涉及MPa、m³/h、吨等工业标准单位，部分年度安全合规文档可达数十页。

## 这些特征在「部署与升级」这一环带来什么约束
基础化工业务办理数据的多字段、长文档及差异化更新节奏，对部署与升级环节提出明确约束。大量数十页的合规文档需要适配分块长度的合理配置，避免语义断裂；多维度工业参数字段要求向量索引匹配多属性检索逻辑，降低跨字段查询的延迟；每日更新的巡检数据与月度更新的台账需对应增量同步的调度规则，升级时需兼容存量旧格式数据，避免迁移过程中字段映射错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:27017/fastgpt?authSource=admin` | 存储业务办理的审批记录、巡检数据，需匹配工业数据的持久化存储要求 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 缓存高频访问的设备参数查询结果，降低数据库负载 |
| `STORAGE_S3_ENDPOINT` | `http://minio-host:9000` | 存储数十页的合规文档，需适配大文件上传的带宽要求 |
| `DB_MAX_LINK` | `1000–1500 次` | 匹配单份合规文档的分块上限，避免单次加载过多数据导致超时 |
| `FILE_TOKEN_KEY` | `自定义随机32位字符串` | 保障本地部署的文档访问权限，防止未授权访问 |
| `FE_DOMAIN` | `https://your-fastgpt-domain.com` | 配置业务办理引导页面的访问域名，适配内部办公网络访问 |

## 容易做错的三处
- 现象：调用文档处理页面报错`Cannot read properties of undefined`，日志显示未加载到文档元数据。原因：未配置`FILE_TOKEN_KEY`导致文档访问权限校验失败，无法读取基础化工巡检文档的字段信息。
- 现象：升级至FastGPT v4.17.0后，内部分享的文档链接无法正常访问。原因：新版本调整了文档访问鉴权逻辑，未重新生成匹配的`FILE_TOKEN_KEY`导致校验不通过。
- 现象：知识库检索结果未返回设备运行参数字段。原因：未配置匹配多维度工业字段的索引规则，导致跨字段检索时丢失关键业务信息。

## 怎么确认配好了
- 访问配置的`FE_DOMAIN`，验证业务办理引导页面可正常加载基础化工的文档列表。
- 上传一份基础化工的巡检记录文档，验证分块处理后可正常生成向量索引。
- 调用知识库检索接口，验证可返回包含设备编号、运行参数的匹配结果。
- 查看`REDIS_URL`对应的缓存监控，验证高频查询的设备参数结果已被缓存。
