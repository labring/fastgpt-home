# 基础设施建设的业务办理流程引导：部署与升级

## 这个品类的数据长什么样
基础设施建设的业务办理流程引导数据，来源为施工许可审批、进度报备、竣工验收等官方流程表单与项目台账。数据更新节奏随项目节点变动，审批环节调整、材料补正通知发布时同步更新。单份文档包含项目编号、施工区域、审批环节、必备材料、办理时限等字段，字段单位多为平方米、工作日、项等，部分文档附带结构化的流程步骤清单与施工图纸附件。

## 这些特征在「部署与升级」这一环带来什么约束
基础设施建设的业务办理流程数据来源分散且字段差异较大，部署时需适配多源结构化表单的解析规则，避免字段映射错误。数据更新无固定周期，升级时需配置增量同步机制，确保流程信息实时同步。单份文档包含多步骤流程与大体积附件材料，部署时需预留足够的存储与上下文处理容量。部分流程材料包含敏感的施工数据，升级后需验证访问权限配置的安全性。

## 配置怎么定
本配置规则适配FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | 指向独立部署的副本集实例，包含认证信息 | 基础设施建设项目数据量随推进持续增长，副本集可保障读写稳定性与故障恢复能力 |
| `REDIS_URL` | 配置为内存不低于8 GB的专属实例 | 需缓存大量审批节点的实时状态与用户会话上下文，保障流程引导的响应速度 |
| `STORAGE_S3_ENDPOINT` | 适配本地对象存储服务的访问端点，绑定专属存储桶 | 基础设施建设项目包含大量施工图纸、验收报告等大体积附件，本地对象存储可降低存储成本 |
| `DB_MAX_LINK` | 设为200–300 | 多项目并行办理时，数据库连接数需覆盖并发的流程查询与数据写入请求 |
| `FE_DOMAIN` | 配置为项目专属的二级域名 | 便于区分不同基建项目的流程引导页面，提升访问安全性 |
| `FILE_TOKEN_KEY` | 生成32位随机字符串 | 用于加密流程附件的访问令牌，防止未授权访问敏感施工材料 |

## 容易做错的三处
- 升级后刷新对话页面显示新对话，历史记录为空。原因是升级时未保留`REDIS_URL`关联的会话缓存目录，或配置的`REDIS_URL`指向了空实例。
- 配置`STORAGE_S3_ENDPOINT`后无法加载施工图纸附件。原因是未正确配置存储桶的访问权限，或连接串未包含存储桶名称与路径前缀。
- 流程查询返回结果条数不足。原因是`DB_MAX_LINK`设置过低，数据库连接池耗尽导致部分查询请求被拒绝。

## 怎么确认配好了
- 访问`FE_DOMAIN`绑定的流程引导页面，提交一个基础的流程查询请求，检查后台数据库日志中无连接超时报错。
- 上传一份施工图纸附件，验证`STORAGE_S3_ENDPOINT`对应的存储桶中生成了对应文件，且页面可正常下载附件。
- 发起多并发的流程查询请求，检查`REDIS_URL`的内存使用率未超过阈值，会话缓存未出现过期异常。
- 执行版本升级脚本后，查看后台启动日志中无配置项加载失败的报错信息，确认所有参数已生效。
