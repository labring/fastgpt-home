# 工程咨询监理的业务办理流程引导：工具调用与插件

## 这个品类的数据长什么样
工程咨询监理的数据来源为旁站记录、分项验收报告、进度管控台账、造价审核文件等项目文档，更新节奏按单项目的施工节点触发，例如隐蔽工程验收后、竣工验收前更新。文档结构包含项目唯一编号、监理单位全称、验收项名称、整改项清单、整改完成率、对应施工标段等字段，部分字段附带专属单位，例如平方米、工期天数、整改项数量，单份文档长度跨度较大，从数百字符到数万字符不等。

## 这些特征在「工具调用与插件」这一环带来什么约束
监理数据的字段关联紧密，工具调用需要严格匹配预设字段顺序，否则会导致解析结果错位。数据按项目节点更新，插件触发时机需绑定对应施工节点，避免无效调用。文档格式多样，包含PDF、Excel、Word等，插件需支持多格式解析适配。字段附带专属单位，工具调用后需增加单位校验环节，确保数据合规。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 插件触发时机 | 绑定项目隐蔽验收、竣工验收节点 | 匹配监理数据按项目节点更新的节奏 |
| 输入字段映射规则 | 按项目编号、验收内容、整改状态排序映射 | 匹配监理文档的固定字段结构 |
| 单次工具调用数据上限 | 不超过4000 字符 | 避免大体积监理文件导致的调用超时 |
| `toolChoice` | 自动匹配 | 适配不同格式监理文档的自动解析需求 |
| 结果字段校验 | 开启单位合法性校验 | 匹配监理数据的平方米、工期天等单位规范 |

## 容易做错的三处
- 现象：工作流中添加自定义监理插件后，输入输出参数栏为空，无报错日志。原因：未在插件配置中绑定监理数据的标准字段映射规则，导致系统无法识别参数结构。
- 现象：调用工具时出现响应超时，日志显示请求时长超过60 秒。原因：未限制单次工具调用的监理数据量，大体积进度台账文件导致模型加载耗时过长。
- 现象：上传监理PDF文档后解析结果为空，无法提取整改项信息。原因：未开启PDF格式文件的解析适配开关，导致文档无法被正确读取。

## 怎么确认配好了
- 进入FastGPT v4.17.0的工作流编辑页面，添加配置好的监理插件，确认输入输出参数栏显示预设的项目编号、验收内容等字段。
- 上传一份标准监理验收报告，触发插件调用，查看返回结果是否包含正确的整改项、验收状态等字段。
- 模拟项目隐蔽验收节点触发插件，确认插件自动执行调用，无手动触发异常。
- 查看工具调用日志，确认单次调用数据量未超过预设上限，无超时报错。
