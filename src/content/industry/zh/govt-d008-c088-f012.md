# 工程咨询监理的业务办理流程引导：部署与升级

## 这个品类的数据长什么样
工程咨询监理的数据主要来源于项目现场的旁站记录、监理日志、分项验收报告、进度管控台账及整改闭环文件。单个项目周期内，数据按周或验收节点同步更新。文档以结构化表格为主，附加PDF或扫描件格式的附件，包含监理单位、项目编号、验收日期、整改项清单、整改完成率等字段，单位涵盖自然日、平方米、万元等工程类标准单位。

## 这些特征在「部署与升级」这一环带来什么约束
工程咨询监理的数据包含结构化表格与大量扫描附件，部署时需配置适配大文件存储的参数，避免附件上传或读取失败。数据随项目节点按周或验收节点更新，升级过程中需保证存量项目的历史数据可正常读取，避免中断正在进行的流程引导。字段包含工程类标准单位，部署时需校验字段格式与单位匹配规则，避免流程引导中出现单位混淆。多项目并行产生的数据量较大，升级时需预留足够的数据库存储空间，防止数据写入超时或连接超限。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `STORAGE_S3_ENDPOINT` | `http://192.168.1.100:9000` | 适配监理数据中的扫描附件存储需求，支持大文件上传与读取 |
| `DB_MAX_LINK` | `20–30` | 匹配多项目并行的数据库并发读写需求，避免连接超限 |
| `REDIS_URL` | `redis://:your_password@127.0.0.1:6379/0` | 缓存流程引导的临时会话数据，降低数据库读取压力 |
| `FILE_TOKEN_KEY` | `按项目专属密钥生成` | 保障监理项目附件的访问权限，防止未授权下载 |
| `PG_URL` | `postgresql://db_user:db_pass@db-host:5432/fastgpt` | 存储结构化的监理项目字段数据，支持按项目编号快速检索 |

## 容易做错的三处
- 现象：工作流调试返回截断的“workflow error {"message":"Dangerous behavio”报错。原因：未配置`FILE_TOKEN_KEY`导致附件权限校验失败，或`DB_MAX_LINK`设置过低引发数据库连接超限。
- 现象：Windows系统重启后，部署的模型与应用配置全部丢失。原因：未将配置文件挂载至系统持久化存储目录，重启后临时目录的配置被系统清空。
- 现象：流程引导页面无法加载历史监理项目的结构化数据。原因：`PG_URL`配置错误，导致数据库连接失败或数据检索异常。

## 怎么确认配好了
- 上传一份监理项目的扫描附件，验证文件可正常存储并通过链接下载，确认`STORAGE_S3_ENDPOINT`配置有效。
- 启动3个以上并行的模拟数据写入任务，检查数据库连接数未超出`DB_MAX_LINK`设置的上限，确认并发读写正常。
- 重启部署服务器，验证配置文件未丢失，模型与应用列表可正常加载，确认持久化配置生效。
- 发起流程引导请求，检查结构化字段的单位匹配校验正常，确认`PG_URL`配置有效。
