# 工程机械的业务办理流程引导：模型接入与配置

## 这个品类的数据长什么样
工程机械的业务办理相关数据主要来源于设备出厂参数文档、现场运维日志、维保工单记录与工况采集数据。出厂参数为静态文档，包含设备型号、序列号、额定参数等固定信息；运维日志为高频更新的实时数据，记录运行时长、工况压力、故障代码等；维保工单记录按工单周期更新，包含更换部件、检修时间等内容。数据字段包含大量专业工程单位，如小时、兆帕（MPa）、转每分钟（r/min）等，单条文档长度差异显著，从数百字符的参数表到数万字符的完整维保手册。

## 这些特征在「模型接入与配置」这一环带来什么约束
静态与动态数据的更新频率差异，要求在模型接入时分别配置不同的数据源同步策略，避免静态数据重复同步或动态数据更新滞后。专业工程单位与多字段结构，要求配置的模型需具备行业术语解析能力，因此需选择适配工程机械场景的模型端点。文档长度跨度大，既存在短参数表也存在长维保手册，需适配不同长度的上下文处理，避免截断核心信息或占用过多计算资源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `AIPROXY_API_ENDPOINT` | 填写行业微调后的工程机械大模型部署地址 | 工程机械业务需专业术语兼容，使用场景适配的模型端点可提升流程引导的准确性 |
| `AIPROXY_API_TOKEN` | 填写对应模型平台颁发的专属调用密钥 | 保障接口调用的身份验证与权限控制，防止未授权访问 |
| `maxContext` | `8000–12000 token` | 覆盖完整的设备维保手册与连续运行日志上下文，避免截断核心业务信息 |
| `maxTokens` | `2000–3000 token` | 控制单轮流程指引的输出长度，确保步骤清晰易读，避免冗余内容 |
| `quoteMaxToken` | `1500–2000 字符` | 精准提取设备故障代码、运行参数等核心引用字段，过滤无关内容干扰 |
| `temperature` | `0.3–0.5` | 降低随机输出概率，确保业务办理流程的描述严谨准确，符合工程场景的严谨性要求 |

*本配置规则基于FastGPT v4.17.0版本*

## 容易做错的三处
- 现象：接口调用返回401未授权错误，界面提示“认证失败”。原因：未正确填写`AIPROXY_API_TOKEN`，或密钥与配置的`AIPROXY_API_ENDPOINT`不匹配，混用了其他场景的API凭证。
- 现象：配置第三方端点后，模型选择列表未显示对应模型，选择框为空。原因：`AIPROXY_API_ENDPOINT`的路径配置错误，或端点未返回有效的模型元数据，导致系统无法拉取可用模型列表。
- 现象：生成的流程指引出现专业单位识别错误，比如将“MPa”误识别为其他单位。原因：未选择适配工程机械场景的微调模型，或`temperature`取值过高导致随机化解析专业术语。

## 怎么确认配好了
- 输入工程机械常见故障代码，调用模型生成流程指引，核对是否包含对应设备的标准办理步骤。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置参数与实际填写一致，无拼写或格式错误。
- 检查向量库同步记录，确认设备运维日志、维保文档等数据源已按配置的更新频率完成同步。
- 上传单台设备的完整维保手册，测试模型能否正确提取核心参数并生成连贯的业务办理引导。
