# 成品油销售的业务办理流程引导：向量模型与索引

## 这个品类的数据长什么样
成品油销售的业务办理相关数据，主要来源于线下加油站的业务台账、线上官方小程序的用户办理记录、ERP进销存系统的进销数据、加油卡管理系统的交易日志。数据更新节奏分为实时与定期两类：线下交易与线上即时办理数据实时更新，每日业务台账与月度进销数据按自然日定期同步。文档结构包含办理节点清单、所需材料说明、流程步骤、表单字段等，字段包含车牌号码、加油量、支付金额、办理时长等，部分字段附带明确单位。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 匹配成品油业务办理文档的单流程步骤长度，避免拆分完整办理节点 |
| 重叠长度 | 100–200 字符 | 保留相邻流程步骤的上下文关联，避免分块后丢失办理逻辑 |
| 相似度阈值 | 0.75–0.85 | 过滤低匹配度的无关业务数据，精准匹配用户咨询的办理环节 |
| 单次搜索上限 | 前 8 条 | 适配业务办理流程的节点数量，返回足够的步骤信息且不冗余 |
| `defaultToken` | 4096 | 适配大模型的默认token限制，保证流程说明的完整展示 |
| `maxToken` | 8192 | 适配长文档的拼接需求，覆盖完整的业务办理全流程 |

## 容易做错的三处
- 上传10M以上的成品油业务台账文件时，分块后出现部分chunk向量化失败，界面显示“向量生成异常”。原因是分块长度设置过大，拆分了包含完整办理节点的段落，导致向量化时上下文关联缺失。
- 更新FastGPT版本从4.9到4.10后，原有成品油知识库无法返回检索结果，界面显示“无匹配结果”。原因是版本升级后向量模型的嵌入维度发生变化，原有索引未重新生成。
- 服务器因多文件批量上传崩溃重启后，知识库处于“未就绪”状态且无自动索引动作，界面显示“索引未启动”。原因是未开启增量自动索引配置，仅支持手动触发全量索引。

## 怎么确认配好了
- 上传单份10M以内的成品油业务办理文档，查看分块预览界面，确认未拆分完整的办理流程节点。
- 提交模拟用户咨询，如“如何申请加油卡开票”，查看检索返回的结果条数，确认符合单次搜索上限的配置。
- 查看向量模型的运行日志，确认生成的向量维度与当前配置的模型维度一致。
- 上传更新后的业务数据，查看知识库是否自动触发增量索引，无需手动操作。
