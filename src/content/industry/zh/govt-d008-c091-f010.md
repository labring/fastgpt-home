# 房建工程总承包的业务办理流程引导：知识库检索与召回

## 这个品类的数据长什么样
房建工程总承包的数据源主要包含项目全周期施工管理文档、住建部门发布的房建施工规范、项目招投标文件、现场签证单与竣工验收资料。更新节奏随项目进度调整，项目节点变更时即时更新。文档多为长文本结构，单份文档字符数跨度较大，字段包含项目标段编号、施工节点、验收标准、材料规格，单位涉及平方米、立方米、工日、吨等工程专业单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
房建工程总承包的长文档结构会导致单文档内存在多个独立施工节点，检索时需避免召回跨节点的无关内容，保障结果精准匹配用户查询的施工环节。专业字段与单位的存在，要求检索匹配需关联字段语义与单位特征，减少误召回情况。不定期更新的数据源，要求召回环节支持增量同步，保障最新现场签证、变更内容被优先覆盖。多来源文档的权威性差异，要求召回时可区分官方规范与现场执行文档的权重。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.72–0.80 | 匹配房建专业术语的语义相似度阈值，避免误召回无关施工节点 |
| `limit` | 前8条 | 适配单项目文档的多节点分布，覆盖核心施工环节内容 |
| `searchMode` | 语义搜索 | 匹配房建工程的专业语义关联，提升召回精度 |
| `usingReRank` | 开启 | 对召回结果按查询相关性重新排序，修正长文档分块后的局部语义偏差 |
| `datasetSearchUsingExtensionQuery` | 开启 | 扩展查询词以覆盖房建专业同义词，比如将“混凝土”扩展为“砼”“现浇混凝土” |
| `collectionIds` | 绑定对应房建项目的标段编号作为数据集ID | 隔离不同房建项目的知识库，避免跨项目内容干扰 |

## 容易做错的三处
- 上传房建项目的长文档时返回`fail to create post presigned url`报错。原因是未配置FastGPT的对象存储密钥与存储桶权限，大体积工程文档的存储校验失败导致预签名URL生成失败。
- 检索时召回非当前项目的知识库内容，结果超出预期范围。原因是未正确配置`collectionIds`参数，未绑定专属项目数据集，导致跨项目的施工文档被误召回。
- 导入房建项目的材料清单CSV文件时返回`datasetId is required for S3 files`报错。原因是未指定目标数据集ID，房建项目的CSV需按标段分类存储，未绑定数据集导致无法关联存储路径。

## 怎么确认配好了
- 上传单份房建项目的施工组织设计文档，检查上传状态显示完成，无预签名URL相关报错。
- 发起包含“某楼层混凝土用量”的查询，检查召回结果仅包含当前绑定项目的数据集内容，无跨项目文档。
- 开启`usingReRank`后，检查召回结果的排序与查询语义匹配度符合预期，核心施工节点内容优先展示。
- 导入CSV格式的材料清单，检查无`datasetId is required`相关报错，导入进度正常。
