# 房建工程总承包的业务办理流程引导：部署与升级

## 这个品类的数据长什么样
房建工程总承包的业务办理数据主要来自项目管理系统、住建部门审批平台及内部审批台账，更新节奏随项目推进节点调整，单次报审文档通常包含标段划分、施工区域范围、工序进度明细等内容。文档以结构化表格和分段说明为主，包含标段编号、施工面积（单位：平方米）、报审工序名称、审批节点状态、报审提交日期等字段，单份完整项目报审文档长度通常在5000至15000字符之间，部分包含图纸附件的文档体积可达1000 MB以上。

## 这些特征在「部署与升级」这一环带来什么约束
房建工程总承包的业务办理文档长度跨度大，且包含大量结构化表格与专业术语，部署时需适配长文本解析与专业词向量匹配能力。更新节奏的不确定性要求部署的向量数据库支持动态扩容，避免高峰期索引阻塞。多标段并行报审的场景，需配置足够的并发处理资源，防止单节点过载。升级过程中需保留原有项目审批台账的字段映射规则，避免历史数据无法正常关联，同时需兼容住建部门审批平台的接口格式变更，防止升级后无法同步官方审批状态。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `200–300 个连接` | 适配房建项目多标段并行发起的业务办理请求，避免数据库连接池耗尽 |
| `REDIS_URL` | `redis://:自定义密码@内网主机地址:6379/0` | 用于缓存审批节点状态与用户会话，保障高并发下的响应速度 |
| `STORAGE_S3_ENDPOINT` | `按内部对象存储服务商的内网地址配置` | 存储房建项目的报审图纸、进度照片等附件，内网部署可降低传输延迟 |
| `MONGODB_URI` | `mongodb://用户名:自定义密码@内网主机地址:27017/fastgpt?authSource=admin` | 存储项目审批台账与流程日志，支持结构化查询 |
| `FILE_TOKEN_KEY` | `随机生成的32位字符串` | 用于签署文件上传令牌，防止未授权访问项目附件 |
| `ROOT_KEY` | `按企业内部安全规范配置的复杂密钥` | 管理系统最高权限，保障业务办理流程的配置权限安全 |

## 容易做错的三处
- 现象：升级FastGPT v4.17.0后，m3e模型无法正常发起调用请求，日志显示模型接口返回404状态码。原因：升级过程中未同步更新模型配置文件中的接口地址，导致指向了已废弃的模型服务地址。
- 现象：docker部署的FastGPT运行时，文件解析模块上报split相关报错日志，且上传的房建项目报审文档无法生成有效向量库。原因：部署时未挂载正确的文件解析临时目录，导致split操作无法读取待处理的文档内容。
- 现象：无网络环境下尝试升级FastGPT版本时，升级脚本无法拉取依赖镜像，部署进程中断。原因：升级脚本默认从公共镜像仓库拉取组件，未配置本地镜像源路径，导致离线环境下无法完成升级。

## 怎么确认配好了
- 发起一次模拟房建项目报审文档的上传，检查文件解析模块的日志是否显示split操作成功完成，无报错信息。
- 提交一条业务办理流程的测试请求，核对向量数据库中是否生成了对应文档的索引条目，且字段与上传文档的结构一致。
- 查看系统的数据库连接池监控面板，确认`DB_MAX_LINK`配置的连接数未出现耗尽情况，并发请求处理无明显延迟。
- 测试调用本地部署的大模型接口，确认业务办理流程的引导回复能正确关联项目文档中的工序、进度等内容。
