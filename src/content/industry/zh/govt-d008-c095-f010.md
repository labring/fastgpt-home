# 新能源开发的业务办理流程引导：知识库检索与召回

## 这个品类的数据长什么样
数据来源包括国家能源局新能源项目备案规范、省级发改委并网流程指引、项目前期审批表单模板及地方政务服务中心办理细则；更新随国家及地方能源政策调整、新增项目备案案例动态同步；文档多为章节式条款结构，包含审批节点序号、材料要求、办理时限、责任部门等字段，单位涉及工作日、兆瓦、万元等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
章节式长条款结构要求检索时需避免上下文断裂，确保审批节点的完整关联；明确的字段与单位要求检索需精准匹配关键词，避免因单位混淆导致结果偏差；多来源文档的格式差异需统一预处理逻辑，保障检索一致性；动态更新的数据要求知识库同步频率匹配政策调整节奏，防止过期政策内容被召回。

## 配置怎么定
本配置基于FastGPT v4.17.0版本的功能逻辑。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配新能源业务办理的精准性需求，过滤低相关的政务内容 |
| `limit` | 前6条 | 覆盖单个新能源项目办理的核心审批节点数量，确保上下文支撑完整引导 |
| `usingReRank` | 开启 | 优化长文本检索后的排序结果，提升高相关审批节点的召回优先级 |
| `searchMode` | 语义搜索 | 适配用户自然语言提问场景，匹配对办理步骤的模糊查询需求 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充业务场景关键词，提升新能源专属文档的召回精准度 |
| `collectionIds` | 按项目类型绑定对应数据集ID | 定向检索新能源开发专属文档，排除无关政务内容 |

## 容易做错的三处
- 现象：私有化部署升级版本后，点击知识库文件详情显示“Invalid dataset file key”。原因：升级过程中未同步更新数据集关联的密钥配置，导致原有文件索引无法匹配新的系统密钥。
- 现象：通过API拉取文档库时返回大量非新能源开发的政务内容。原因：未正确指定`collectionIds`参数，导致检索范围覆盖全量政务文档，干扰业务引导结果。
- 现象：用户提问“并网流程”时，召回结果缺少核心材料清单条目。原因：未开启`datasetSearchUsingExtensionQuery`，未补充场景相关关键词，导致部分关联文档未被精准召回。

## 怎么确认配好了
- 进入FastGPT知识库管理界面，核对绑定的`collectionIds`是否对应新能源开发专属数据集。
- 发起测试提问，例如“新能源项目备案办理流程”，查看返回结果的排序是否符合业务节点逻辑。
- 调用API接口拉取文档库，检查返回结果是否仅包含新能源开发相关的业务办理内容。
- 升级部署版本后，点击任意知识库文件详情，确认界面无“Invalid dataset file key”报错提示。
