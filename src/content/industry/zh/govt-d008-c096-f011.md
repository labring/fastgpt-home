# 有色金属冶炼的业务办理流程引导：表单与交互

## 这个品类的数据长什么样
有色金属冶炼的业务数据来自生产DCS控制系统、原料仓储台账、成品质检报告三类系统。生产过程的工艺参数每15分钟更新一次，批次质检数据随每炉次产出同步更新。标准文档结构包含原料批次标识、熔炼温度、熔炼时长、成品目标金属含量、能耗记录、流转节点编号等字段，其中温度单位为摄氏度，时长单位为小时，金属含量单位为克/千克，能耗单位为千瓦时。

## 这些特征在「表单与交互」这一环带来什么约束
实时更新的工艺参数要求表单支持动态加载最新的合理区间参考值，避免使用静态固定选项。批次化的流转数据要求表单必须绑定唯一的批次标识字段，防止跨批次数据混淆。带专业单位的字段需要表单自带单位校验能力，防止用户输入错误单位导致数据无效。多流转节点的流程需要表单支持节点状态的勾选选择，匹配冶炼业务的多环节审批逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 表单输入校验规则 | 绑定字段单位与合理数据范围，如熔炼温度限制在800-1600摄氏度 | 冶炼工艺参数有固定合理区间，避免无效输入 |
| 变量绑定设置 | 关联原料批次号与质检报告ID | 冶炼数据按批次流转，需绑定唯一标识避免数据错乱 |
| 输入框类型选择 | `formInput` 搭配单位后缀，`userSelect` 用于流转节点选择，日期输入框用于时间节点记录 | 专业字段需单位校验，流转节点需固定选项减少错误，时间节点需标准化日期格式 |
| 提交超时设置 | 600 秒 | 冶炼批次数据量较大，批量提交需更长响应时间 |
| 批量提交限制 | 前 10 条 | 匹配单炉次或单批次的处理规模，避免超出系统处理上限 |

## 容易做错的三处
- 现象：提交后提示部分必填字段为空，原因：未配置批次号、工艺参数等核心字段的必填校验，导致用户遗漏冶炼流程的关键标识。
- 现象：JSON输入框无法插入系统变量，原因：未将输入框配置为支持变量调用的`formInput`类型，或未开启变量插入权限。
- 现象：日期输入框无法自动填充计划日期，原因：未绑定生产计划的变量数据源，导致日期需手动输入易出现格式错误。

## 怎么确认配好了
- 手动输入不符合设定单位的内容，查看是否弹出对应的校验提示。
- 在JSON输入框中尝试插入预设的批次变量，确认可正常调用并生成合法JSON格式。
- 点击日期输入框，选择预设的计划日期，查看是否自动填充正确格式的日期内容。
- 提交单条测试数据，查看返回结果是否正确关联对应的批次标识与工艺参数。
- 提交超过设定上限的批量数据，查看系统是否触发提交限制的提示信息。
