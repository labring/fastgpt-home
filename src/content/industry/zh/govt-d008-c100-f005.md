# 油田工程服务的业务办理流程引导：工具调用与插件

## 这个品类的数据长什么样
油田工程服务的数据主要来自现场作业调度系统、施工日志数据库与设备运维平台。数据更新随单批次作业流程推进，单次作业的工单数据在作业完成后归档。单条数据包含作业工单编号、施工区域坐标、工序节点序列、配套物料规格、安全校验项清单与审批流转节点信息，字段多为字符串、整数与枚举值，单位涵盖平方千米、件、小时等工程常用单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
作业工单编号的唯一性要求工具调用时需精准匹配字段格式，避免模糊查询导致的工单混淆。工序节点的序列性要求插件需按顺序触发审批、物料申领等环节，不能打乱既定流程。安全校验项的枚举值限制需插件在调用前校验参数范围，防止传入非法配置。物料规格的多单位兼容要求工具需支持单位转换逻辑，适配不同作业场景的输入习惯。作业数据的归档属性要求插件调用时需区分在线作业工单与历史归档数据，分别配置不同的超时与重试策略。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工具调用超时时间 | 120–180 秒 | 匹配油田工程作业的单环节平均处理时长，避免因现场网络波动触发无效重试 |
| `toolChoice` | auto | 适配多工序节点的动态调用需求，无需手动指定具体工具 |
| 单次工具调用返回上限 | 前 8 条 | 匹配单批次作业的关联工单与物料数量，避免返回冗余数据 |
| 上下文窗口大小 | 4000–6000 token | 承载完整的作业工单与审批流转的全量信息，防止关键节点丢失 |
| 安全参数校验开关 | 开启 | 匹配油田工程的合规要求，拦截非法输入的作业参数 |
本配置适用于FastGPT v4.17.0版本。

## 容易做错的三处
- 导入插件时提示internal server error，原因是未适配油田工程数据的枚举字段校验规则，导致插件配置参数与系统字段不匹配。
- 调用MCP工具时提示不支持指定协议，原因是未使用stdio进程封装工具，错误配置了sse协议的调用方式。
- 提取接口输出字段时结果为空，原因是未匹配油田工程数据的嵌套字段层级，直接调用顶层字段导致无法获取目标内容。

## 怎么确认配好了
- 提交测试作业工单，查看工具调用日志，确认`toolChoice`自动触发了对应工序的工具节点。
- 导入配置完成的插件，执行本地调试，检查是否返回匹配油田工程数据格式的测试结果。
- 模拟非法参数输入，确认工具触发安全校验拦截，返回合规提示。
- 查看接口返回的字段提取结果，确认已正确匹配作业工单的嵌套字段内容。
