# 油田工程服务的业务办理流程引导：部署与升级

## 这个品类的数据长什么样
油田工程服务的业务办理数据主要来源于现场施工日志、设备运维台账、项目审批单据与跨部门协作工单。数据按单个项目批次提交更新，更新周期随项目进度灵活调整，单次提交的文档通常包含项目编号、施工环节、审批节点、责任人、时限要求等核心字段，部分设备相关数据会附带工况参数与检测数值，字段单位涵盖小时、天、台次等工程领域标准单位。

## 这些特征在「部署与升级」这一环带来什么约束
油田工程服务的项目批次化数据提交，要求部署时需支持按项目维度划分知识库分片，避免单库数据过载。灵活的更新周期需要系统支持手动触发增量同步与定时自动同步双模式，适配不同油田项目的进度节奏。多字段混合的文档结构，要求部署时配置的向量模型需兼容多类型字段的向量化处理，避免数值类参数丢失语义信息。跨部门协作工单的跨节点流转，要求部署后的流程引导工具可同步调用多部门的审批状态接口，确保流程节点的实时性。升级环节需保留原有项目分片的配置，避免历史数据索引失效，同时兼容新增的工程类字段解析规则。本页面配置基于FastGPT v4.17.0版本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 1000–1500 条 | 适配油田工程服务单批次项目的文档链接上限，避免数据库连接溢出 |
| `MONGODB_URI` | 油田内网MongoDB实例专属地址 | 存储项目审批工单与施工日志的结构化数据，使用内网地址保障数据安全 |
| `REDIS_URL` | 192.168.xxx.xxx:6379?password=自定义强密码 | 缓存流程节点的实时审批状态，通过密码保障访问安全 |
| `STORAGE_S3_ENDPOINT` | 油田内部对象存储服务地址 | 存储施工过程中的图纸、视频等大文件，适配内网存储需求 |
| `FE_DOMAIN` | 油田工程服务业务系统内网域名 | 配置流程引导工具的前端访问地址，确保仅内部网络可访问 |
| `ROOT_KEY` | 油田运维团队自定义的最高权限密钥 | 管理系统的核心配置权限，仅授权专属运维人员使用 |

## 容易做错的三处
- 现象：工作流编排调试界面中代码运行步骤未显示。原因：部署时未正确配置`ROOT_KEY`权限，导致代码运行节点的权限校验未通过，节点被隐藏。
- 现象：导入油田工程服务项目文档后，知识库选择框为空。原因：配置`MONGODB_URI`时未指向正确的项目工单数据库，系统无法读取已上传的知识库关联信息。
- 现象：Reranker模型调用失败，返回参数无效报错。原因：未正确获取油田内部模型服务的ACCESS Token，或Token配置未同步到部署实例的环境变量中。

## 怎么确认配好了
- 登录FastGPT后台，查看核心配置项的取值，确认与油田内部运维规范一致。
- 手动触发一次项目文档的增量同步，检查知识库中是否自动加载对应项目的审批工单与施工日志。
- 启动一条测试项目的工作流调试，确认代码运行节点正常显示并可执行，无权限相关报错。
- 调用Reranker模型接口，检查是否能正常获取返回结果，无Token或权限相关报错。
