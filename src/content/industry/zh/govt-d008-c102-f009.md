# 炼化生产的业务办理流程引导：模型接入与配置

仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这个品类的数据长什么样
炼化生产的业务数据主要来自生产实时控制系统、设备巡检台账、物料流转记录与安全合规手册。实时工艺参数数据按秒级更新，设备巡检与物料流转台账按日同步，安全合规文档按需更新。单份业务办理文档（如动火作业票、设备维保申请）通常包含作业区域编码、审批节点序列、有效期、风险等级字段，参数类数据统一使用MPa、℃、立方米/小时作为计量单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
实时秒级更新的工艺参数要求模型接入时配置合理的上下文刷新间隔，避免缓存过期数据导致引导偏差。多字段的业务文档结构要求模型需精准匹配字段与审批节点，需限制生成内容的冗余度。不同数据源的更新节奏差异，要求配置分层的召回规则，区分实时参数与静态文档的调用优先级。统一的计量单位要求模型在生成引导时自动适配现场使用的单位体系，避免单位转换错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 覆盖炼化业务的多节点审批流程与实时工艺参数的上下文需求，避免截断关键信息 |
| `maxTokens` | 2000–3000 token | 限制单轮引导输出长度，适配现场操作人员的阅读节奏，避免信息过载 |
| `quoteMaxToken` | 1500 字符 | 限定召回的业务文档总长度，确保匹配的合规条款与工艺参数准确且不冗余 |
| `temperature` | 0.3–0.5 | 降低生成随机性，保障业务引导的规范性与准确性，符合炼化生产的严谨要求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写私有代理地址 | 适配炼化场景的离线部署需求，保障核心数据不出厂 |
| `AIPROXY_API_TOKEN` | 与代理服务绑定的专属密钥 | 确保接入权限的安全性，避免未授权调用 |

## 容易做错的三处
- 部署后调用报错`do_request_failed`，提示请求超时或地址无效。原因是未正确配置`AIPROXY_API_ENDPOINT`为私有代理的实际地址，或未在防火墙开放对应端口。
- 生成的引导内容出现单位转换错误，比如将MPa显示为bar。原因是未在模型配置中明确要求适配炼化现场的法定计量单位，未通过预设约束规范输出格式。
- 召回的业务文档与当前办理业务不匹配，结果条数过多或过少。原因是未合理设置`quoteMaxToken`，导致召回范围过大或过小，未匹配文档的业务分类标签。

## 怎么确认配好了
- 手动输入一条炼化业务办理的典型问题，核对模型返回的引导是否包含正确的审批节点与参数要求。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`的请求地址与实际部署地址一致，无拼写错误。
- 测试不同更新频率的数据源调用，确认实时参数与静态文档的召回结果符合预期。
- 调整`temperature`参数，验证生成内容的随机性变化是否符合业务严谨性需求。
