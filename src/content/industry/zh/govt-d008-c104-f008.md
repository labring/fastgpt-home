# 煤化工的业务办理流程引导：文档解析与分块

## 这个品类的数据长什么样
煤化工业务办理流程相关的数据主要来源于生产现场的设备运维日志、工艺操作规程、安全审批表单、月度生产报表四类。数据更新节奏随业务类型差异较大：设备运维日志按班次更新，工艺规程按年度修订，安全审批表单随单次业务触发生成，月度生产报表按自然月更新。文档结构包含结构化CSV表格（如设备参数表）、长文本PDF（如全流程工艺手册）、固定字段表单（如动火作业审批单），字段包含设备编号、工艺参数、时间戳，单位多为MPa、t/h、m³等工业标准单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
煤化工文档的长文本特性要求分块不能过度拆分技术逻辑，避免破坏工艺节点的关联性；结构化CSV表格的固定字段格式要求解析工具保留列关联关系，否则会导致参数与单位分离；专有工业术语与单位的存在要求解析过程不能丢失格式细节，否则会影响后续检索准确性；批量上传的月度生产报表体积较大，要求系统支持更大的单文件上传上限与更长的解析超时时间；零散的审批单文档要求分块逻辑适配单条业务的完整流程，不能跨业务拆分内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 1000–1500 字符 | 适配煤化工长文本工艺文档的段落长度，避免拆分破坏工艺逻辑 |
| `chunkSplitter` | 按段落+标题拆分 | 保留文档的层级结构，适配工艺规程的章节划分 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 1200 秒 | 支持单份大型工艺规程PDF的完整解析 |
| `UPLOAD_FILE_MAX_SIZE` | 2000 MB | 适配批量上传月度生产报表合集的体积需求 |
| `customPdfParse` | 启用 | 保留煤化工文档中的表格、公式与专有单位格式 |
| 第三方文档解析集成 | 对接minerU | 提升煤化工专有工业术语与格式的解析准确率 |
| `chunkSettingMode` | 手动配置 | 针对不同类型文档（报表/规程/审批单）调整分块参数 |

## 容易做错的三处
- 分块后总块数超过3000，界面弹出索引异常提示。原因是未针对煤化工的长文档设置合理的`chunkSize`，单文件拆分块数超出系统默认阈值。
- 升级FastGPT v4.17.0后CSV文件解析报错。原因是新版本对结构化文档的解析逻辑进行了更新，未重新配置`UPLOAD_FILE_MAX_SIZE`导致大体积CSV上传失败。
- 解析后的分块丢失设备参数的单位信息。原因是未启用`customPdfParse`，默认解析模式无法保留煤化工文档中的MPa、t/h等专有单位格式。

## 怎么确认配好了
- 上传单份500页以上的工艺规程PDF，查看解析后的分块列表，确认每个分块包含完整的工艺节点描述。
- 检查后台上传配置项，确认`UPLOAD_FILE_MAX_SIZE`设置符合当前上传文档的最大体积要求。
- 导入一份包含设备参数与单位的CSV报表，验证解析后的分块保留了所有列关联关系与单位信息。
- 运行批量解析测试，确认单份文档的解析耗时未超过`PARSE_FILE_TIMEOUT_SECONDS`设置的阈值。
- 查看第三方解析工具的集成日志，确认minerU的对接配置已生效。
