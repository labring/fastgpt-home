# 煤化工的业务办理流程引导：表单与交互

## 这个品类的数据长什么样
煤化工业务办理数据来源于国央企内部的项目审批系统、安全环保监管申报平台。数据更新节奏随业务办理节点推进，单次办理周期内数据仅在环节变更时更新。文档以结构化表单为核心，包含申请主体统一社会信用代码、项目备案编号、设计产能（单位：万吨/年）、核心工艺类型、申报日期等字段，部分关联文档附带工艺流程图PDF附件。

## 这些特征在「表单与交互」这一环带来什么约束
煤化工业务办理的结构化字段存在固定单位与专属分类，交互环节需强制校验字段格式与单位匹配，避免无效输入。数据随办理节点更新，表单需支持动态加载当前审批环节的必填字段，避免冗余内容。关联工艺流程图等大附件的提交，需要适配稳定的上传交互逻辑，防止超时中断。不同项目的工艺类型选项固定，交互中需提供预选菜单，减少手动输入错误。业务办理流程的多环节衔接，需在表单交互中明确当前步骤与后续步骤的跳转逻辑，避免流程混乱。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 按业务环节拆分，每个环节对应一组输入字段 | 煤化工业务办理分多个审批环节，拆分后可明确当前步骤的交互范围 |
| 用户输入校验 | 校验字段格式与预设单位匹配，例如产能仅允许填写正整数加万吨/年 | 煤化工表单字段存在固定单位要求，校验可减少无效数据 |
| `userSelect` | 预设工艺类型选项，包含煤制烯烃、煤制天然气等常见类型 | 煤化工工艺类型分类固定，预选可提升交互效率 |
| 单次上传附件上限 | 2 个，每个不超过 500 MB | 工艺流程图等附件体积较大，限制数量避免上传超时 |
| 上传超时设置 | 600 秒 | 大附件上传需要足够时间，按实测标定 |

## 容易做错的三处
- 现象：引用自定义插件并接入代码运行环节后，点击表单输入框触发报错，界面显示「输入参数无效」。原因：未在`formInput`配置中绑定插件所需的输入字段，导致代码运行时无法获取对应参数。
- 现象：多轮业务办理对话中，前一轮AI输出的项目编号未自动填充到当前表单的对应字段，需手动重复输入。原因：未开启`userSelect`的上下文继承配置，未将前序对话的输出结果作为当前表单的默认值。
- 现象：上传工艺流程图附件时，超过配置的附件大小限制后直接失败，无明确提示。原因：未配置附件上传的错误提示逻辑，大文件上传超时后未向用户反馈具体问题。

## 怎么确认配好了
- 进入表单配置页面，逐一核对每个业务环节的输入字段与煤化工业务表单的实际字段一致。
- 触发审批节点切换操作，确认仅加载当前环节的必填字段，非当前环节字段未显示。
- 上传测试附件，确认上传流程符合配置的数量与大小限制，无异常报错。
- 模拟多轮对话交互，确认前序对话生成的项目编号等数据可自动填充到对应表单字段。
