# 电网企业的业务办理流程引导：模型接入与配置

## 这个品类的数据长什么样
电网企业业务办理流程引导的数据主要来源于内部营销业务系统、营业厅工单库、官方发布的用电业务办理指南。数据更新节奏为实时同步工单状态，每日更新完整流程文档。单条业务数据包含业务编号、办理环节、所需材料清单、办理时限、咨询渠道等字段，其中材料清单以结构化列表形式存储，时限字段以工作日或小时为单位，部分文档包含跨页的流程示意图与附件说明。

## 这些特征在「模型接入与配置」这一环带来什么约束
业务数据的结构化字段与非结构化文档混合的特征，要求模型接入配置需同时适配结构化检索与自然语言解析。实时同步的工单数据要求配置支持动态数据更新，避免模型调用过时的业务信息。较长的流程文档与多字段结构，要求上下文处理配置需覆盖完整的环节信息，防止关键内容被截断。多列结构化Excel格式的业务数据导入需求，要求分块配置需支持按行拆分数据，避免跨列字段的关联关系被破坏。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 电网业务流程文档通常包含多环节内容，需覆盖完整的上下文信息以避免关键环节遗漏 |
| `maxTokens` | 1500–2000 token | 单条业务指引回复需清晰完整，避免超出接口响应长度限制 |
| `quoteMaxToken` | 2000–3000 字符 | 需完整引用业务材料清单、办理时限等核心内容，保障引用信息准确 |
| `temperature` | 0.2–0.4 | 业务办理流程需保持严谨准确，降低模型生成内容的随机性 |
| `toolChoice` | auto | 自动触发知识库检索，匹配实时更新的业务工单与流程文档 |
| `AIPROXY_API_ENDPOINT` | 企业内部代理服务地址 | 保障业务数据不流出企业内网，符合合规要求 |
| `AIPROXY_API_TOKEN` | 企业统一分配的服务密钥 | 实现接口权限管控，防止未授权访问 |

## 容易做错的三处
- 现象：导入多列业务办理Excel后，检索结果字段混乱，跨列数据被错误合并。原因：未按每行作为分段配置数据拆分规则，导致系统自动分块时打乱列字段关联。
- 现象：调用自定义代理渠道返回403状态码，接口请求失败。原因：未使用企业专属的`AIPROXY_API_TOKEN`，使用通用密钥导致权限校验不通过。
- 现象：生成的业务指引中出现无关业务内容，偏离电网办理流程规范。原因：`temperature`取值过高，模型生成内容的随机性超出业务严谨性要求。

## 怎么确认配好了
- 查看FastGPT v4.17.0的模型接入日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的请求能返回正常状态码，具体阈值按企业代理接口的校验规则标定。
- 发起模拟用电业务咨询请求，检查返回的流程指引是否包含完整的业务环节、材料清单与时限要求，匹配度按实际业务场景的需求标定。
- 导入测试用的多列业务Excel文件，确认检索结果按每行作为分段拆分，字段对应准确，按业务文档的结构要求标定。
- 测试敏感词过滤功能，确认违规业务表述被正确拦截，拦截规则按企业合规管理的要求标定。
