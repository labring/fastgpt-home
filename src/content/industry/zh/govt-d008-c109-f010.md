# 电网企业的业务办理流程引导：知识库检索与召回

## 这个品类的数据长什么样
电网企业的业务办理相关数据主要来源于官方业务规程、业扩报装手册、停电报修细则、电价政策文件等内部文档。更新节奏随政策调整、流程迭代临时触发，常规按季度更新存量文档。文档结构以业务大类为核心分组，每个分组下包含办理步骤、所需材料、办理时限、咨询渠道等内容，字段包含业务编号、办理窗口、联系电话等，单位多为工作日、元/千瓦时、户等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
业务大类的分组结构要求检索需限定对应文件夹范围，避免跨业务召回无关内容；字段包含精准业务标识，可用于过滤召回结果；文档时效性强，需优先召回最新版本的流程文件；单份文档篇幅较长，需合理设置分块参数以保证召回内容的完整性与可读性。同时，用户查询多为具体业务场景，需精准匹配术语，避免泛化检索导致的无效结果。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.80 | 匹配电网业务术语的精准度，避免召回无关的电价政策或通用服务文档 |
| `limit` | 前8条 | 电网业务文档单业务条目集中，过多结果会超出上下文长度限制，影响问答连贯性 |
| `searchMode` | `vector` | 优先匹配业务流程的语义关联，结合关键词检索补充精准业务关键词 |
| `usingReRank` | 开启 | 对召回的结果按业务相关性重排，优先展示与用户查询最匹配的办理流程文档 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充业务相关同义词，如将“报装”匹配为“新装用电”，覆盖用户多样化查询表述 |
| `collectionIds` | 按业务文件夹ID指定 | 限定检索范围在电网业务办理的知识库集合中，避免混入其他品类的非业务文档 |

## 容易做错的三处
- 调用API上传文档失败，或页面上传Markdown文档无响应。原因：未指定`collectionIds`参数，或文档中包含未转义的特殊字符，导致解析流程中断。
- 导入语雀公开链接时提示解析错误。原因：未开启语雀链接的公开访问权限，或链接未指向可直接抓取的文档页面，无法作为知识库数据源。
- 删除包含大量业务文档的文件夹时触发60000ms超时。原因：电网业务文档数量多且层级深，批量删除未配置分批处理，超出默认超时阈值。

## 怎么确认配好了
- 提交业务相关查询（如“居民新装电表流程”），检查召回结果是否仅包含电网业务办理的文档，无无关内容。
- 上传一份测试用的电网业务文档或导入合规的公开链接，查看上传状态是否显示成功，无报错提示。
- 触发批量删除测试文件夹的操作，确认操作在60秒内完成，未触发超时报错。
- 查看问答结果中的图片链接，手动访问确认可正常加载。
