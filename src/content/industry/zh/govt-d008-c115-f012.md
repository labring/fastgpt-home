## 这些特征在「部署与升级」这一环带来什么约束
轨道交通装备业务数据的结构化程度高且包含唯一标识字段，要求数据库连接配置需支持高并发读写，避免单连接阻塞业务同步。实时或批量更新的节奏要求缓存配置适配短周期数据刷新，防止旧数据被误加载。附件类检修报告的存储需求，要求对象存储配置适配PDF等非结构化文件的上传与读取。装备编号的唯一性要求数据关联逻辑需严格匹配标识字段，避免跨装备数据混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 20–30 个 | 适配轨道交通装备业务数据的高并发读写需求，避免连接池耗尽 |
| `STORAGE_S3_ENDPOINT` | 对应企业对象存储的内网访问地址 | 适配检修报告等大附件的高速存储与读取，降低公网传输延迟 |
| `REDIS_URL` | 配置为带密码验证的内网Redis实例地址 | 支撑短周期数据缓存与实时同步校验，保障业务数据时效性 |
| `FILE_TOKEN_KEY` | 按业务场景生成的32位随机字符串 | 用于附件下载的权限校验，防止未授权访问检修报告等敏感文件 |
| `ROOT_KEY` | 配置为复杂随机字符串 | 限制平台管理员权限访问，保障业务办理流程配置的安全性 |
| `FE_DOMAIN` | 部署服务的内网或公网访问域名 | 适配业务办理页面的资源加载与回调逻辑 |

## 容易做错的三处
- 配置`DB_MAX_LINK`取值过低时，会出现业务数据同步超时的报错日志，原因是连接池无法支撑批量检修工单的并发读写请求。
- 未正确填写`MONGODB_URI`的连接字符串时，会出现知识库无法加载图片的界面提示，原因是数据库连接异常无法读取附件元数据。
- 未配置`STORAGE_S3_ENDPOINT`的内网访问地址时，会返回500 Internal Server Error的接口响应，原因是公网访问对象存储的延迟过高或权限不足。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`DB_MAX_LINK`配置的连接池是否可正常分配连接。
- 上传一份轨道交通装备的检修报告PDF，通过业务办理页面验证附件是否可正常下载。
- 发起一笔模拟的业务办理流程，检查数据是否可正常同步至数据库并更新状态。
- 调用缓存服务测试接口，验证`REDIS_URL`配置的缓存服务是否可正常存储临时会话数据。
