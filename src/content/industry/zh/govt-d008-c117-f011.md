# 通信铁塔与基础设施的业务办理流程引导：表单与交互

## 这个品类的数据长什么样
通信铁塔与基础设施的业务办理数据来源为铁塔运维管理系统、基站资源调度平台及运营商基站档案库。数据更新节奏为每日全量同步一次。文档结构包含基站唯一标识、塔型参数、建设高度、负载功率、维护周期、审批节点状态等字段。字段对应明确物理单位，如塔高以米为单位，负载功率以千瓦为单位，维护周期以天为单位。审批节点状态字段为枚举类型，包含待审核、通过、驳回三类固定值。

## 这些特征在「表单与交互」这一环带来什么约束
数据字段多且存在强依赖关系，塔型参数直接决定可选负载范围，因此表单需配置字段联动逻辑，避免用户选择无效组合。数据每日同步更新，表单需展示数据最后更新时间，提示用户优先使用最新获取的数据。字段带有明确物理单位，表单需支持单位自动匹配或强制校验，防止用户输入无单位或错误单位的内容。基站唯一标识采用固定格式，表单需配置格式校验规则，确保输入内容符合系统识别标准。枚举类型的审批节点状态字段，需预设固定选项，禁止用户自定义输入。

## 配置怎么定
本页面适配FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 开启格式校验，限定输入为“TC”前缀+6位数字 | 基站唯一标识采用固定格式，确保系统可准确识别 |
| `userSelect` | 开启塔型与负载参数联动，仅展示当前塔型对应的可选负载值 | 塔型与负载参数存在强依赖关系，避免无效选择 |
| 数据时效性提示 | 显示数据最后更新时间，提示每24小时同步一次 | 数据更新节奏为每日全量同步，需提醒用户使用最新数据 |
| 单位自动匹配 | 自动填充字段对应单位，如塔高默认带米，功率默认带千瓦 | 字段带有明确物理单位，减少用户输入错误 |
| 字段必填规则 | 必填基站ID、塔型、维护周期字段 | 这三类为业务办理的核心必填信息 |
| 错误重试阈值 | 允许3次输入错误后触发人工核验通道 | 避免无效提交占用系统处理资源 |

## 容易做错的三处
- 现象为引用插件后执行代码节点时弹出输入报错，提示“参数未绑定”；原因是表单配置中未将插件所需的`formInput`字段与工作流输入节点正确关联。
- 现象为用户选择塔型后，负载参数列表无匹配项；原因是未开启`userSelect`的联动配置，导致选项未按塔型过滤。
- 现象为提交的表单数据与系统内最新数据不一致；原因是未配置数据时效性提示，用户使用了超过24小时未更新的旧数据提交。

## 怎么确认配好了
- 填写符合“TC”前缀+6位数字格式的基站ID，确认格式校验提示正常显示。
- 选择任意塔型，确认负载参数列表自动更新为对应塔型的可选值。
- 查看表单底部的最后更新时间提示，确认与每日同步的周期一致。
- 提交测试表单，确认无参数未绑定类的报错信息。
