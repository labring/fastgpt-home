# 会议精神摘要的党建学习助手：模型接入与配置

## 这个品类的数据长什么样
数据来源为各级党建会议的官方文字实录、现场录音转写文本，更新节奏为单场会议结束后1至3天生成对应文档。文档结构包含会议主题、召开时间、核心发言要点、集体决议事项、后续工作要求等固定字段，单篇文档长度跨度较大，以单场会议的完整记录为最小数据单元，无统一固定单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
党建会议精神摘要的数据来源包含官方实录与转写文本，存在长文本跨度、结构固定的特征。长文本跨度要求模型接入时需适配不同长度的输入内容，避免截断核心决议与后续工作要求等关键信息。固定的文档结构要求配置需支持按预设字段定向提取，避免无关内容干扰摘要生成。单次会议生成单篇文档的更新节奏，无需高频增量同步配置，可按单批次任务完成接入适配。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 会议实录通常为数千字符，该区间可覆盖单篇文档的核心内容，避免关键信息被截断 |
| `maxTokens` | `2000–3000 token` | 摘要需涵盖会议核心要点与决议，该输出长度可平衡信息完整性与可读性 |
| `temperature` | `0.1–0.3` | 党建内容需保持严谨准确，该参数区间可降低生成内容的随机性 |
| `AIPROXY_API_ENDPOINT` | 按部署服务商提供的专属地址填写 | 匹配模型调用的网络路径，确保请求可正确送达目标模型 |
| `AIPROXY_API_TOKEN` | 按分配的专属密钥填写 | 完成模型调用的身份验证，确保请求可被目标模型识别 |
| `toolChoice` | `none` | 会议精神摘要仅需文本生成，无需调用外部工具辅助 |

## 容易做错的三处
- 现象为模型接入后显示检测失败，返回连接超时或401状态码。原因是未正确填写`AIPROXY_API_TOKEN`或`AIPROXY_API_ENDPOINT`的参数值，导致身份验证或网络路径不匹配。
- 现象为工作流节点调用时返回全局上下文内容，未仅使用当前任务的上下文。原因是未在节点配置中指定仅使用当前会话上下文，或开启了全局上下文同步开关。
- 现象为添加多个同名模型时无法区分调用请求。原因是未为每个模型配置独立的`AIPROXY_API_TOKEN`，或未在平台中为不同模型设置唯一标识。

## 怎么确认配好了
- 提交单篇测试会议实录，查看模型返回的摘要内容是否包含会议核心要点与决议事项。
- 检查模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的参数值已正确加载，无空值或错误字符。
- 测试多模型配置场景，验证不同模型的调用请求可按配置的密钥正确区分。
- 调整`temperature`参数后提交测试，确认生成内容的严谨性随参数调整发生符合预期的变化。
