# 会议精神摘要的党建学习助手：部署与升级

## 这个品类的数据长什么样
会议精神摘要的数据来源包括党政机关官方发布的会议公报、现场录音转写的原始文本、参会单位提交的会议纪要。更新节奏随会议召开周期同步，单次任务的文本长度跨度较大。文档结构包含会议主题、召开时间、核心部署、参会范围、后续落实要求等固定字段，字段无强制统一单位，仅按内容自然分段。

## 这些特征在「部署与升级」这一环带来什么约束
会议精神摘要的数据来源多样、长度跨度大且结构固定，会对部署与升级环节带来多重约束。部署阶段需适配多格式输入，支持官方公报、录音转写文本、参会纪要等不同来源的内容接入；需配置适配长文本的处理参数，避免因文本过长导致处理失败。升级阶段需兼容新增的转写格式与字段结构，同时优化长文本拆分与同步逻辑，保障不同周期会议的任务处理稳定性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@localhost:27017/fastgpt?authSource=admin` | 存储会议文本与摘要的结构化数据，需配置正确的认证与库指向 |
| `REDIS_URL` | `redis://:yourpassword@localhost:6379/0` | 缓存会议文本的分块结果与检索索引，保障快速调用 |
| `DB_MAX_LINK` | `300 秒` | 适配长文本处理的超时限制，覆盖多数会议文本的处理时长 |
| `STORAGE_S3_ENDPOINT` | 按实测标定 | 存储录音转写的原始文件与生成的摘要文件，需适配本地或云存储配置 |
| `ROOT_KEY` | `32 位随机字符串` | 管理后台的最高权限认证，保障部署安全 |
| `FE_DOMAIN` | `https://your-domain.com` | 前端页面的访问域名，保障接口调用的跨域合法性 |

## 容易做错的三处
- 现象：执行`docker compose up -d`时返回`Error response from daemon`相关报错。原因：未正确配置`MONGODB_URI`或`REDIS_URL`的连接参数，导致容器无法拉起依赖服务。
- 现象：升级到FastGPT v4.17.0后出现`TypeError: Cannot read properties of undefined`报错。原因：未同步更新`FILE_TOKEN_KEY`的配置值，导致文件处理环节的密钥校验失败。
- 现象：会议精神摘要生成速度过慢，单次任务超时。原因：未调整`DB_MAX_LINK`的超时参数，或未对超长会议文本进行预拆分，导致处理超时。

## 怎么确认配好了
- 执行`docker compose ps`，确认所有依赖服务与应用容器处于运行状态。
- 访问`FE_DOMAIN`配置的域名，登录管理后台验证`ROOT_KEY`的权限配置是否生效。
- 上传一段测试用的会议文本，触发摘要生成任务，确认任务能正常完成无报错。
- 检查`STORAGE_S3_ENDPOINT`对应的存储桶，确认生成的会议摘要文件已正确上传。
