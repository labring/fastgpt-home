# 党建资料检索的党建学习助手：引用来源与溯源

## 这个品类的数据长什么样
党建资料检索的数据源主要来自中央及地方党建官方平台、单位内部党建档案库、公开权威党建文献汇编。更新节奏按需同步或按固定周期执行，单篇文档包含规范标题、分段正文、发布主体、发布时间等标准化结构。其字段统一为文档标识、来源归属、主题标签，统计单位为单份党建学习资料，内容覆盖党的理论学习、政策解读、活动纪实等类别。

## 这些特征在「引用来源与溯源」这一环带来什么约束
党建资料的官方权威来源要求溯源必须完整展示发布主体与发布时间，不得省略关键归属信息。固定的更新节奏要求知识库同步周期匹配资料更新频率，避免溯源内容与最新发布的党建资料脱节。明确的文档结构与统一字段规范，要求引用时需关联原文档的完整标识，同时需返回预设的主题标签等专属信息，确保溯源的准确性与完整性，仅展示片段内容无法完整呈现资料的官方属性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | 党建资料单段切片内容通常较长，该取值可完整保留引用片段的上下文，避免截断关键表述 |
| `responseData` | 开启 | 需同时返回模型回答与引用文献细节，满足党建学习中验证资料权威性的需求 |
| `detail` | 开启 | 党建资料包含发布主体、发布时间等专属字段，全量返回可完整展示溯源信息 |
| 单次召回片段上限 | 前3条 | 党建资料检索需聚焦核心权威内容，避免过多片段干扰学习阅读 |
| 知识库同步周期 | 7–14 天 | 匹配多数党建资料的固定更新节奏，确保溯源文档与最新发布内容保持一致 |
| 原文档预览关联 | 开启切片与原文档绑定 | 支持查看切片对应的原文件详情，便于学习时查阅完整内容 |

## 容易做错的三处
- 调用API仅返回模型回答文本，无引用文献的细节信息。原因：未开启`responseData`配置开关，未指定返回引用详情的参数。
- 终端回复界面中未展示引用板块，或引用字段为空。原因：未配置`detail`参数开启全量字段返回，或知识库同步周期与党建资料的更新节奏不匹配，导致引用关联的文档信息缺失。
- 在oneAPI测试模型通过后，FastGPT引用时返回红色数字报错。原因：未正确配置`quoteMaxToken`的取值范围，或未匹配党建资料切片的token长度，导致参数校验失败。

## 怎么确认配好了
- 调用对应API接口，检查返回结果中是否包含引用详情字段与文档全量信息。
- 在终端界面发起党建资料检索提问，确认回复下方是否展示引用板块及对应文献的发布主体、发布时间等信息。
- 点击引用链接，确认是否可跳转至原文件的完整预览页面。
- 查看知识库同步日志，确认同步周期与党建资料的更新节奏匹配。
