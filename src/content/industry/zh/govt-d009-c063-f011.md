# 党建资料检索的党建学习助手：表单与交互

## 这个品类的数据长什么样
党建资料检索的数据源多来自官方党建出版物、地方党史档案、权威党建宣传平台的公开内容，更新节奏随最新政策发布、主题教育活动推进调整。单篇文档多包含多层级标题、段落、引用标注及发布单位、日期等元数据，结构严谨且带有明确的分类属性，如理论学习、党史教育、政策解读等。文档以文本格式为主，部分包含规范的markdown排版，字段涵盖标题、发布主体、内容主题、发布时间等，检索单位以单篇或单章节为基础单元。本配置方案适配FastGPT v4.17.0版本。

## 这些特征在「表单与交互」这一环带来什么约束
党建资料的层级化结构要求交互环节需保留内容的从属逻辑，避免拆分时破坏章节关联；多字段元数据则要求表单支持按分类、发布时间等维度筛选，仅依赖关键词匹配无法覆盖完整检索需求。高频更新的数据源要求交互界面可配置定期同步规则，确保检索内容时效性。同时，党建资料包含大量专有名词与官方表述，交互环节需适配这类术语的语义理解，避免检索偏差。此外，部分用户上传的文档格式多样，交互环节需明确支持的格式范围，减少解析错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配党建资料的章节长度，保留单章节内的完整逻辑 |
| 重叠长度 | 100–150 字符 | 避免跨章节内容被截断，维持相邻段落的上下文关联 |
| `formInput` | 开启前置字段校验 | 过滤无效检索关键词，仅允许符合党建资料检索场景的输入格式 |
| 单次搜索上限 | 前 10 条 | 聚焦核心检索结果，避免冗余内容干扰学习参考 |
| 问题优化 | 按实测标定 | 适配党建领域专有名词，优化提问的语义匹配精度 |
| `userSelect` | 开启分类筛选选项 | 匹配党建资料的主题、发布单位等元数据，缩小检索范围 |

## 容易做错的三处
- 现象：上传任意党建资料文件后界面弹出“文件解析失败”提示，后台日志返回400状态码。原因：未针对党建资料的专有格式配置解析规则，默认解析逻辑无法识别文档中的页眉页脚标注。
- 现象：导入markdown格式的党建资料后，检索结果无法关联对应章节的从属内容。原因：分块配置未保留标题层级，仅按纯段落拆分导致文档逻辑丢失。
- 现象：输入中文提问后，检索结果未包含知识库中的英文党建文献。原因：未开启跨语言检索的交互开关，仅配置了中文语义匹配规则。

## 怎么确认配好了
- 上传一篇带多层级标题的markdown党建资料，检查检索结果是否能关联到对应章节的内容。
- 输入包含党建专有名词的提问，检查交互界面是否自动弹出分类筛选选项。
- 上传单篇超过2000字符的党建资料，检查是否按配置的分块长度正确拆分。
- 测试上传非支持格式的文件，检查是否弹出明确的格式错误提示。
