# 学习测验出题的党建学习助手：文档解析与分块

## 这个品类的数据长什么样
党建学习测验出题的数据源主要为官方党建学习资料、内部党建培训文档、自定义测验题库表格。更新节奏随党建学习计划调整，不定期新增学习材料与题库内容。文档类型包含纯文本学习手册、多列格式的Excel题库、带排版的PDF党建文件，结构化字段包含知识点主题、题干、选项、正确答案、解析内容，部分文档带有层级化标题与发布元数据。

## 这些特征在「文档解析与分块」这一环带来什么约束
党建学习测验出题的数据包含结构化表格与连贯文本两类，多列Excel题库的分块需避免跨列内容混杂，否则会导致测验题的题干、选项、答案被拆分到不同块中，影响后续出题的准确性。长文本学习材料的分块需保留知识点完整性，不能将同一专题的学习内容拆分为多个无关联块，否则会割裂学习逻辑。单附件上传场景下，需确保仅解析当前上传文件，避免历史文档被误纳入解析范围，否则会干扰测验题的精准匹配与出题结果。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的文档解析模块，适配党建学习测验出题的场景需求。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配党建学习材料与测验题的常规长度，保留单题或单段学习内容的完整性 |
| `chunkSplitter` | 按行分割（Excel）、按标题+段落分割（PDF） | 针对多列Excel题库，按行分割可确保每行题目内容作为独立分块；针对PDF党建手册，按标题+段落可保留知识点的关联逻辑 |
| `customPdfParse` | 开启 | 保留PDF文档原有排版结构，避免党建材料的标题、段落被系统自动打乱 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 为大型Excel题库或多页PDF文档提供充足解析时长，避免因超时导致解析失败 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配大容量党建题库文件的上传需求，防止因文件尺寸超限被拦截 |
| `chunkSettingMode` | 手动配置 | 可针对不同类型的党建文档分别调整分块规则，精准匹配测验出题的解析需求 |

## 容易做错的三处
- 上传多列Excel题库后，自动分块结果杂乱，每行题目被拆分到不同分块中。原因是默认分块规则按段落或通用换行分割，未针对结构化表格调整分块逻辑。
- 上传单份党建文档时，历史上传的文档内容被一并解析加载。原因是未开启单文件独立解析模式，系统默认执行全量已上传文档的批量解析。
- 解析大型多页PDF党建手册时出现超时报错，任务状态显示超时异常。原因是未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时长不足以完成多页文档的完整解析。

## 怎么确认配好了
- 上传一份测试用的多列Excel题库，查看解析后的分块列表，确认每行题目内容形成独立分块。
- 上传单份带标题的PDF党建学习手册，查看解析结果是否保留原有标题与对应段落的关联关系。
- 检查解析任务日志，确认仅当前上传的文档被纳入解析范围，无历史文档内容被加载。
- 等待解析任务完成后，查看任务状态是否显示成功，无报错或异常提示。
