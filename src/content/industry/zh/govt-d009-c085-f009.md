# 学习测验出题的党建学习助手：模型接入与配置

## 这个品类的数据长什么样
党建学习测验出题的核心数据来源为官方党建知识库、公开党建政策文档及内部党建学习材料，更新节奏随政策发布或季度动态调整。单条数据包含主题分类、原文内容、发布日期三个核心字段，单位以“篇”“条目”为统计标准。原文内容为规范文本，无冗余格式，长度跨度覆盖中小篇幅的政策解读到完整的党建活动记录。

## 这些特征在「模型接入与配置」这一环带来什么约束
党建学习测验出题的固定主题分类字段要求模型调用时需精准匹配对应分类的知识库内容，因此模型接入环节需配置上下文携带分类信息的参数。单条原文内容长度跨度较大，需限制单轮传入模型的文本总量，避免超出模型上下文窗口限制。数据更新随政策发布动态调整，需配置自动同步知识库的触发逻辑，确保模型调用时使用最新的党建学习材料。同时测验出题需严格基于给定的知识库内容，需限制模型调用外部无关信息的权限。

## 配置怎么定
本配置基于FastGPT v4.17.0版本的参数逻辑制定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配党建原文的长度跨度，避免截断核心出题依据的内容 |
| `maxTokens` | 1500–2000 token | 控制单份测验题的输出长度，确保符合党建学习材料的出题范围 |
| `quoteMaxToken` | 3000 token | 限制单轮引用的知识库原文长度，确保模型仅使用有效出题素材 |
| `temperature` | 0.2–0.4 | 降低生成随机性，确保出题内容严格匹配党建知识库的规范表述 |
| `toolChoice` | "none" | 禁止调用外部工具，确保出题仅基于配置的党建知识库内容 |
| `AIPROXY_API_ENDPOINT` | 按部署的模型服务地址填写 | 对接合规的大模型服务，确保数据传输符合安全要求 |
| `AIPROXY_API_TOKEN` | 按服务商提供的密钥填写 | 验证模型服务的访问权限，保障调用的合法性 |

## 容易做错的三处
- 现象：调用模型时返回“无效的API端点”报错，原因：未正确填写`AIPROXY_API_ENDPOINT`参数，或部署的模型服务未适配fastgpt的调用格式。
- 现象：生成的测验题包含非党建知识库的外部内容，原因：未将`toolChoice`设置为“none”，模型调用了外部工具获取无关信息。
- 现象：生成的测验题参考了过多无关的知识库条目，原因：未限制模型仅选取匹配度靠前的知识库条目，导致混入非目标主题的党建材料。

## 怎么确认配好了
- 进入模型管理页面，查看已配置的模型参数，确认`maxContext`、`maxTokens`等参数的取值与配置要求一致。
- 手动触发一次测验出题任务，查看生成的题目是否仅基于配置的党建知识库内容，无外部无关信息。
- 检查模型调用日志，确认API请求携带了正确的`AIPROXY_API_TOKEN`和`AIPROXY_API_ENDPOINT`参数，无报错返回。
- 测试不同分类的党建知识库内容，确认生成的测验题与对应分类的主题匹配，无跨分类的错误内容。
