# 学习测验出题的党建学习助手：分享与嵌入

仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这个品类的数据长什么样
党建学习助手的学习测验出题品类，数据来源为党建官方学习材料、主题教育文件、标准化党建题库。更新节奏随党建主题活动调整，新政策或主题发布后同步更新。每份数据以单道测验题为最小单位，包含结构化字段：题干文本、备选项集合、正确答案、解析说明、关联知识点标签。无复杂多媒体嵌入，仅题干可携带少量格式标记。

## 这些特征在「分享与嵌入」这一环带来什么约束
单题体量小的特征决定嵌入容器无需过大，适配业务系统的侧边栏或内嵌卡片布局。结构化字段的特点允许灵活配置分享内容的展示范围，可选择仅暴露题干或同步完整题目（含答案解析），需匹配业务场景的权限管控要求。非实时的更新节奏要求嵌入链接支持定期刷新，避免内容过时。同时，党建学习内容的属性要求分享与嵌入环节需符合内部权限规范，防止非授权内容扩散。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分享可见范围 | 按业务场景选择内部可见/公开 | 党建测验题多为内部学习资料，需匹配权限管控要求 |
| 嵌入容器尺寸 | 300–500 像素宽度，按实测标定高度 | 单道测验题内容体量小，适配业务系统侧边栏或内嵌卡片布局 |
| 是否显示Markdown导出按钮 | 关闭 | 内部学习场景无需对外导出，避免非授权的题目扩散 |
| `shareId` 绑定配置 | 绑定业务系统用户权限标识 | 确保仅授权用户可访问对应测验题，符合党建学习的保密规范 |
| 内容刷新周期 | 1–7 天，按实测标定 | 适配党建内容的非实时更新节奏，平衡内容时效性与服务器资源消耗 |

## 容易做错的三处
- 现象：免登录嵌入窗口显示Markdown导出按钮，原因：未在配置中关闭导出按钮选项，默认保留了对外导出功能。
- 现象：嵌入后的测验题内容未随源题库更新，原因：未配置内容刷新周期，使用了默认的长间隔或未开启自动刷新逻辑。
- 现象：触发分享操作时，输入的关键词被错误转换，原因：未对嵌入组件的输入参数做基础字符校验，导致编码或输入异常引发字符转换错误。

## 怎么确认配好了
- 访问嵌入后的页面，检查导出按钮是否按配置要求显示或隐藏。
- 模拟不同权限的用户访问嵌入内容，确认仅授权用户可查看对应范围的题目内容。
- 修改源题库的题目内容，等待配置的刷新周期后，检查嵌入页面的内容是否同步更新。
- 触发分享操作，确认输入的参数能正确传递，无异常字符转换。
