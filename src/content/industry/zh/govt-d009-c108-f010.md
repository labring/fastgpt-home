# 理论学习问答的党建学习助手：知识库检索与召回

## 这个品类的数据长什么样
党建理论学习问答的数据主要来源于中央及地方党委发布的权威文献、党内法规、学习纲要、专题党课材料，以及内部党建培训文档。数据更新节奏随权威文件发布同步调整，内部文档按需更新，通常每周或每月完成一次同步。文档多为正式文稿，具备固定的章节结构，包含标题、正文、引用、落款等字段，部分采用问答形式呈现学习内容，单篇文档长度跨度较大。

## 这些特征在「知识库检索与召回」这一环带来什么约束
权威资料的高可信度要求检索优先召回官方发布的文档，避免非权威内容混入。文档结构固定且长度跨度大，分块时需保留章节逻辑，防止破坏理论表述的连贯性。更新频率不固定，需支持增量同步和全量刷新两种模式。部分文档附带外部学习链接，召回时需正确处理链接格式与访问权限，确保用户可正常访问。用户提问多围绕政策解读与理论名词，需精准匹配核心概念，避免泛泛的无关内容。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| similarity | 0.75–0.85 | 确保召回的党建理论内容与提问核心匹配，避免无关内容混入 |
| limit | 前6–8条 | 覆盖核心理论要点，同时控制上下文总长度符合模型输入限制 |
| usingReRank | 开启 | 党建内容多存在逻辑层级，重排可提升高相关文档的排序优先级 |
| datasetSearchUsingExtensionQuery | 开启 | 将用户口语化提问转换为标准理论表述，提升召回精准度 |
| collectionIds | 绑定党建专属知识库ID | 隔离其他业务数据，确保仅召回党建学习相关文档 |
| searchMode | 语义搜索 | 适配理论学习问答的语义匹配需求 |

## 容易做错的三处
- 现象：调用知识库接口返回文档URL，点击访问时提示“Only support .txt”。原因：导入的党建文档包含非文本格式的外部链接，或知识库配置未开放对应文档类型的访问权限。
- 现象：检索结果与理论提问匹配度低，无法精准解答学习疑问。原因：未设置合理的similarity阈值，或未开启`datasetSearchUsingExtensionQuery`优化提问表述，导致召回内容偏离核心理论要点。
- 现象：上传知识库文档时出现“Request failed with status code 400”。原因：飞书知识库同步时未配置正确的应用权限，或文档包含未转义的特殊字符导致解析失败。

## 怎么确认配好了
- 输入一个典型的党建理论提问，查看检索结果是否优先召回中央及地方党委发布的权威文档。
- 检查检索结果的排序，高相关内容是否排在前列，验证`usingReRank`是否生效。
- 导入一篇测试用的党建文档，确认检索时可以正确召回其中的核心内容，验证similarity阈值设置合理。
- 查看知识库配置页面，确认`collectionIds`已绑定党建专属知识库，隔离其他业务数据。
