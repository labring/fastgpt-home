# 理论学习问答的党建学习助手：分享与嵌入

## 这个品类的数据长什么样
该品类的数据来源为中央及地方官方党建出版物、最新政策解读文件、内部标准化学习题库。更新节奏随上级政策发布及季度学习计划动态调整。单条数据为标准化问答条目，包含问题文本、标准答案、关联理论主题、发布日期四个核心字段，单条内容长度多在300至1500字符区间，无额外非结构化附件。

## 这些特征在「分享与嵌入」这一环带来什么约束
标准化问答结构要求嵌入时保留关联理论主题、发布日期等元字段，否则无法体现学习内容的权威性与关联性。动态更新节奏要求分享链接或嵌入代码需支持实时同步最新题库，避免嵌入内容滞后于政策更新。党建学习内容的内部管控属性，要求嵌入环节需支持业务系统用户身份关联，同时兼容不同内核浏览器的免登录窗口调用，否则可能出现访问拦截或报错。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `shareId` | 对应党建学习应用的唯一标识 | 用于生成专属分享链接与嵌入代码，确保关联正确的理论学习题库 |
| 分享链接有效期 | 7 天 | 适配党建学习季度更新节奏，避免长期失效影响学习访问 |
| 嵌入窗口高度 | 600–800 像素 | 适配单条问答内容的展示长度，避免内容截断或空白过多 |
| 身份关联方式 | 业务系统令牌转发 | 符合党建内容的内部管控要求，实现用户身份与FastGPT平台的绑定 |
| 自动同步开关 | 开启 | 匹配题库随政策动态更新的特征，保证嵌入内容始终为最新版本 |
| 错误重试次数 | 3 次 | 应对网络波动导致的访问失败，提升嵌入功能的稳定性 |

## 容易做错的三处
- 现象为免登录窗口在Trident内核浏览器中加载失败，界面显示“无法加载资源”或状态码403；原因是未配置兼容Trident内核的嵌入脚本跨域规则，导致浏览器安全策略拦截请求。
- 现象为嵌入后业务系统用户无法访问党建学习内容，问答结果为空；原因是未配置业务系统令牌转发的身份关联逻辑，FastGPT无法验证用户的内部访问权限。
- 现象为嵌入窗口内问答内容显示不完整，出现截断或滚动条异常；原因是嵌入窗口高度设置不符合单条问答的展示需求，未适配内容长度区间。

## 怎么确认配好了
- 调用`shareId`对应的分享链接，在Chrome和Trident内核浏览器中分别打开，确认页面加载无报错。
- 模拟业务系统用户发起问答请求，确认返回结果包含关联的理论主题与发布日期元数据。
- 发布一条新的党建学习问答条目，等待10分钟后刷新嵌入页面，确认新内容已同步展示。
- 断开业务系统的令牌转发配置，确认嵌入页面提示未授权访问，验证身份关联逻辑生效。
