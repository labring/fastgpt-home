# “高效办成一件事”联办的党建学习问答：部署与升级

## 这个品类的数据长什么样
该品类的数据主要来源于国家政务服务平台“一件事”专区、地方一体化政务服务平台、电子证照库及各部门审批系统，更新频率为每日。日常处理的文档包括联办事项清单、一次性告知单、联办申请表、材料流转单、并联审批意见、办结回执，字段包含事项关联部门、申请材料要求、办理节点、党建相关政务指引等，文档格式非标准化，部分文档包含附件材料。

## 这些特征在「部署与升级」这一环带来什么约束
每日更新的数据要求部署时配置增量同步的定时任务，避免全量同步占用过多系统资源。多部门异构数据源的接入需要配置兼容不同格式的解析规则，适配联办文档的非标准化结构。党建学习问答的场景要求数据关联政务事项与党建指引，部署时需预设字段映射规则。政务场景常需离线部署，因此还需配置本地存储与内网访问的相关参数，确保数据与服务可在无公网环境下运行。

## 配置怎么定
本配置指南适用于FastGPT v4.17.0版本，以下配置项均为政务内网部署场景下的推荐设置。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | 本地容器映射的 27017 端口连接串，格式为`mongodb://username:password@host:27017/dbname` | 适配政务数据的本地存储需求，确保离线部署时联办文档与问答数据可正常访问 |
| `REDIS_URL` | 127.0.0.1:6379，密码按部署环境配置 | 支撑会话缓存与增量同步的状态管理，符合每日更新数据的缓存时效要求 |
| `DB_MAX_LINK` | 20–30 个 | 适配多部门数据源的并发连接上限，避免单连接阻塞每日的数据同步任务 |
| `STORAGE_S3_ENDPOINT` | 政务内网的本地对象存储地址，如`http://10.0.0.1:9000` | 用于存储联办文档附件与党建问答素材，保障离线部署场景下的文件访问 |
| `FE_DOMAIN` | 政务内网的访问域名，如`http://internal-gov-fastgpt` | 适配政务场景的内网部署要求，确保内部工作人员可正常访问问答服务 |
| `ROOT_KEY` | 自定义的强密码字符串，长度不低于 16 位 | 保障后台管理接口的访问安全，符合政务系统的权限管控要求 |

## 容易做错的三处
- 离线部署后党建问答的政务文档文本提取无效，仅返回空字段。原因是未配置本地存储的文件访问权限，导致容器无法读取联办事项清单等离线文档。
- 配置外部检索工具后，部分联办事项的相关内容无法被检索到。原因是未适配政务内网的网络隔离规则，导致检索源无法正常访问。
- 二次修改容器内代码后重启服务无生效。原因是未将本地代码目录挂载到容器内部，直接修改容器内文件会在重启后被重置。

## 怎么确认配好了
- 执行`docker logs fastgpt`查看启动日志，确认`MONGODB_URI`与`REDIS_URL`的连接状态无超时或认证失败报错。
- 上传一份联办事项清单文档，触发文本提取任务，检查提取结果是否包含事项关联部门、申请材料要求等核心字段。
- 手动触发一次增量同步任务，查看同步日志，确认多部门数据源的文档可正常拉取并更新到知识库中。
- 访问`FE_DOMAIN`的党建问答页面，在内网环境下验证可正常检索联办事项相关的党建政务内容。
