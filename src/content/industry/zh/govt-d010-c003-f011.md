# 不动产登记的党建学习问答：表单与交互

## 这个品类的数据长什么样
不动产登记相关数据来源于不动产登记信息系统、地籍调查数据库、房屋交易网签系统、税务系统、电子证照库，更新频率为日。日常涉及的文档包括登记申请书、权属证明、测绘成果、税费凭证、不动产权证书、登记簿，字段涵盖不动产坐落、权利人信息、权属来源、限制状态、测绘面积等，所有字段均沿用政务系统标准格式，无额外自定义单位或字段。

## 这些特征在「表单与交互」这一环带来什么约束
由于数据来源分散且每日更新，表单交互需支持实时拉取最新的登记信息与权属状态，避免使用过期数据引发登记错误。日常文档类型多样，表单需适配不同文档的字段格式，例如测绘成果的面积录入、权属证明的编号校验，需针对不同文档设置差异化的输入规则。因登记错误会引发产权纠纷或行政诉讼，表单需增加前置校验环节，对必填字段、格式不符的输入实时给出提示。作为不动产权利确认的核心环节，表单交互需聚焦权属来源、限制状态等核心问答内容，避免无关信息干扰党建学习的问答准确性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `formInput` | 配置为支持多字段联动校验 | 适配不动产登记文档的多字段关联校验需求，例如权属人信息与不动产权号的匹配校验 |
| `userSelect` | 设置为单选+多选混合模式 | 满足党建学习问答中政策选项、登记场景的选择需求，支持导入自定义登记类型选项 |
| 单次搜索上限 | 前5条 | 不动产登记核心数据条目量级可控，前5条可覆盖权属来源、限制状态等核心问答所需信息 |
| 上下文长度 | 800–1200 字符 | 适配登记申请书、测绘成果等单份文档的常规字符长度，保证问答上下文完整 |
| 超时阈值 | 60 秒 | 匹配政务系统接口的平均响应时长，避免因等待过久导致交互中断 |
| 重排开关 | 开启 | 针对多源数据的召回结果进行排序，优先展示权属相关的核心信息 |

## 容易做错的三处
- 现象：配置党建问答的变量引用时，出现`quote type error`报错，界面弹出格式错误提示。原因：未按照不动产登记的字段命名规范定义变量，例如误将`{不动产权证书编号}`写为`{证书号}`，导致系统无法识别合法的引用类型。
- 现象：配置表单的大模型调用时，可选模型与官方介绍不一致，无法选择GPT4或Claude 3.5。原因：未在系统后台开启对应大模型的接入权限，且未完成自定义渠道的密钥配置与接口连通性测试。
- 现象：启用表单的重排功能后，召回结果未按核心权属信息排序，出现无关内容前置的情况。原因：未正确配置重排的触发条件，或未指定重排的核心字段为权属来源、限制状态等不动产登记核心数据。

## 怎么确认配好了
- 输入测试用的不动产坐落与权利人信息，检查`formInput`配置的联动校验是否触发，无格式错误提示。
- 发起党建相关的不动产权属问答，查看召回结果是否优先展示权属来源、限制状态等核心字段。
- 查看系统日志，确认变量引用未出现`quote type error`报错，接口调用正常。
- 模拟多源数据召回场景，确认从地籍调查数据库、税务系统拉取的信息同步更新至问答结果中。
