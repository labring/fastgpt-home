# 产权、资产与国有资本管理的党建学习问答：向量模型与索引

## 这个品类的数据长什么样
本品类数据主要来自国资监管信息系统、企业资产管理系统、产权交易所系统、评估机构报告及财务报表，更新频率为每月一次。日常文档包含产权登记表、资产评估报告、产权转让方案、进场交易公告、资产处置审批单，数据字段包含资产编号、权属单位、评估值、交易状态等，单份文档包含结构化表格与非结构化文本混合内容，部分专项文档篇幅跨度较大。

## 这些特征在「向量模型与索引」这一环带来什么约束
多源异构的数据来源要求索引支持多格式数据的统一导入与向量化处理；月更的更新频率要求增量索引的调度周期匹配业务更新节奏，避免索引内容滞后于实际业务数据。混合结构化与非结构化的文档结构要求分块策略兼顾资产编号、评估值等关键字段的完整性，避免拆分破坏业务关联。精准的业务字段需求要求向量模型能够区分核心业务标识与通用文本，提升党建问答场景下的检索精准度。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配本品类混合结构的业务文档，避免截断资产编号、评估值等关键字段 |
| 重叠长度 | 50–80 字符 | 保留分块间的上下文关联，避免拆分后丢失文档逻辑连贯性 |
| `maxToken` | 4096 token | 匹配主流向量模型的输入上限，适配本品类长文档的向量化需求 |
| `defaultToken` | 2048 token | 适配向量模型的默认输入截断阈值，避免长文本被过度截断 |
| 相似度阈值 | 按实测标定 | 适配国资业务文档的语义相似度判断标准，结合党建问答场景调整 |
| 单次搜索上限 | 前 10 条 | 平衡检索效率与结果覆盖度，满足业务精准检索的需求 |
| 重排 | 开启 | 优化语义检索结果的排序逻辑，提升党建问答场景下的内容相关性 |

## 容易做错的三处
- 现象：语义检索返回的结果分数普遍偏高，且包含大量与党建问答无关的资产交易细节。原因：未针对本品类的精准业务字段调整相似度阈值，直接沿用通用场景的默认参数，导致低相关性内容被误判为高匹配结果。
- 现象：上传的党建学习辅助素材未参与检索匹配。原因：未开启辅助数据的向量化配置，导致辅助材料未被纳入索引库，无法被语义检索召回。
- 现象：单份产权转让文档生成多组向量后，检索结果出现重复片段。原因：分块长度设置过短且未配置重叠长度，导致同一业务逻辑被拆分为多个独立片段，生成多组重复向量。

## 怎么确认配好了
- 上传一份典型的资产评估报告，执行包含资产编号的检索测试，核对结果是否优先命中相关文档。
- 查看索引管理界面的更新日志，确认每月自动触发的增量索引任务已正常执行。
- 调整分块长度参数后，重新向量化单份长文档，核对生成的向量数量与预期分块数一致。
- 导入党建学习素材后，执行相关党建主题的检索，确认素材内容被正确召回。
