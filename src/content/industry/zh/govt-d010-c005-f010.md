# 产权、资产与国有资本管理的党建学习问答：知识库检索与召回

## 这个品类的数据长什么样
这个品类的日常文档包括产权登记表、资产评估报告、产权转让方案、进场交易公告、资产处置审批单，数据来源涵盖国资监管信息系统、企业资产管理系统、产权交易所系统、评估机构报告、财务报表。数据包含结构化字段与非结构化文本，如资产权属编号、评估基准日、交易审批状态等，更新频率为月度，服务主体为国资监管机构产权处、央企资产管理部、产权交易机构、评估机构。

## 这些特征在「知识库检索与召回」这一环带来什么约束
品类数据包含万级行的结构化Excel表与长文档报告，月度更新的特性要求检索系统可适配增量数据同步。多来源、多格式的数据需要统一预处理逻辑，确保检索一致性。党建学习问答需兼顾国资业务术语与党建关键词，检索需同时覆盖业务字段与主题关联内容。数据总量较大，需严格控制召回范围与结果长度，避免token超量与检索效率下降。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.72–0.85` | 业务文档包含国资专业术语与结构化字段，阈值过低会引入无关结果，过高会漏召回有效业务与党建关联内容，按实测标定 |
| `limit` | 前3–5条 | 单条资产或党建内容的信息密度较高，过多召回会超出token限制，同时影响检索响应速度 |
| `searchMode` | 向量检索+关键词混合 | 数据包含结构化字段与自由文本，混合模式可兼顾字段匹配与语义关联，适配党建问答的关键词需求 |
| `usingReRank` | 开启 | 长文档与多来源数据容易出现语义偏差，重排可提升结果相关性，适配党建学习问答的精准性要求 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可将党建与国资业务相关的扩展词加入检索，提升跨主题关联召回效果 |
| `collectionIds` | 绑定产权资产专属数据集与党建学习数据集 | 需隔离无关业务数据，确保检索范围仅覆盖当前品类的文档与党建学习内容 |

## 容易做错的三处
- 现象：检索返回的单条结果占用token超量，或召回内容无法匹配细分的产权或党建问题。原因：未根据品类文档长度调整分块参数，沿用通用分块配置，未适配产权转让方案、资产评估报告等长文档的结构。
- 现象：知识库召回为空时，无法触发预设的联网搜索，或错误触发搜索。原因：未正确配置检索为空的触发逻辑，未区分业务无关的闲聊问题与无匹配结果的业务问题。
- 现象：闲聊问题被误召回为有效结果。原因：未设置合理的`similarity`阈值，或未加入专属过滤规则，导致低相关性的闲聊内容被纳入检索结果。

## 怎么确认配好了
- 上传单份产权登记表与党建学习材料，执行检索，核对召回结果的条数是否符合`limit`配置，相关性是否符合`similarity`阈值要求。
- 构造无匹配内容的闲聊问题，核对是否触发预设的过滤逻辑或联网搜索（若已配置）。
- 导入10000行的Excel资产数据，执行批量检索测试，核对系统响应时间与token消耗是否符合预期。
- 查看FastGPT v4.17.0的检索日志，确认`usingReRank`与`datasetSearchUsingExtensionQuery`是否正常生效。
