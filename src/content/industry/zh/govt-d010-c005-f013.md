# 产权、资产与国有资本管理的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
本品类数据主要来自国资监管信息系统、企业资产管理系统、产权交易所系统、评估机构报告及财务报表。日常文档包含产权登记表、资产评估报告、产权转让方案、进场交易公告、资产处置审批单，字段覆盖权属标识、评估参数、交易条件、审批状态等，数据更新频率为月度，单次文档体量从数页到数十页不等。

## 这些特征在「分享与嵌入」这一环带来什么约束
多源异构的数据来源要求分享与嵌入环节需精准关联对应系统的数据源权限，避免跨系统数据泄露。月度更新频率决定了知识库同步周期需匹配业务节奏，过短会增加系统负载，过长则无法及时同步最新资产信息。复杂的文档结构要求嵌入的问答系统需保留业务字段完整性，不能因分块破坏权属、交易条件等核心信息。同时，国有资产相关内容的敏感性要求分享与嵌入需严格控制访问权限，仅授权内部人员可获取完整内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分享权限设置 | 仅内部授权账号可访问 | 匹配国有资产数据的敏感属性，避免非授权获取核心业务信息 |
| `shareId` 关联配置 | 绑定党建学习问答场景下的产权资产知识库 | 确保分享与嵌入的问答内容精准匹配本品类的业务数据 |
| 文档分块长度 | 800–1200字符 | 适配产权资产类文档的字段完整性，避免破坏业务信息 |
| 嵌入页面适配 | 适配内网页面1200px宽度，按实测标定 | 贴合国资系统内网的通用页面布局，避免嵌入后出现错位 |
| 同步周期设置 | 30天 | 匹配本品类月度更新的数据节奏，平衡数据时效性与系统负载 |
| 访问超时设置 | 600秒 | 匹配国资系统内网的平均访问延迟，避免请求被中途截断 |

## 容易做错的三处
- 现象：嵌入页面加载后未返回匹配的产权资产或党建问答数据，原因：未将`shareId`绑定至对应品类的专属知识库，导致调用了无关数据源。
- 现象：分享链接无需登录即可访问全部敏感内容，原因：误关闭了分享权限校验开关，违反国有资产数据的安全管理规范（对应社区关于鉴权变更的疑问）。
- 现象：iframe嵌入后页面出现横向滚动条或内容截断，原因：未适配国资系统内网的页面容器尺寸，直接使用了默认嵌入参数。

## 怎么确认配好了
- 使用FastGPT v4.17.0生成的分享链接，使用内部授权账号访问，验证可加载党建学习问答内容及关联的产权资产相关文档。
- 将生成的iframe代码嵌入测试内网页面，验证页面布局无错位、内容加载完整且响应正常。
- 检查知识库同步日志，确认最近30天内的资产登记、评估、交易类文档已完成同步更新。
- 使用非授权账号访问分享链接，验证系统拦截访问请求，符合权限管控要求。
