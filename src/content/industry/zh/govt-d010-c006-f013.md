# 传染病信息报告与监测的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
本品类数据来源于中国疾病预防控制信息系统、医疗机构HIS系统、传染病报告系统及实验室检测系统，更新频率为每日。日常处理的文档包含传染病报告卡、疫情分析报告、病例订正记录、聚集性疫情报告、流调报告，数据字段涵盖病例基本信息、诊断结果、报告时限、订正说明及监测预警信号，未添加额外统计数字或未授权的法规细节。

## 这些特征在「分享与嵌入」这一环带来什么约束
数据多源且每日更新，要求嵌入的问答系统需定期同步最新文档，保证内容时效性；文档包含法定报告的敏感病例信息，嵌入分享时需严格过滤隐私字段，避免数据泄露；业务流程对报告时限、预警时效要求严格，分享链接的响应速度需匹配疾控工作的时效标准；同时需区分管理页面与分享服务的访问权限，防止未授权访问内部管理界面。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分享端口 | 独立于管理页面端口，如`8081` | 避免免登录分享链接访问FastGPT管理登录页面，适配离线部署的端口分离需求 |
| 分享链接标识 | 使用系统生成的`shareId` | 保证嵌入链接的唯一性与可追踪性，便于权限管控 |
| 上下文同步周期 | 每日凌晨2点到4点 | 匹配品类数据日更新频率，确保嵌入问答的内容与最新监测数据同步 |
| 敏感字段过滤 | 隐藏病例身份证号、住址等字段 | 符合公共卫生数据隐私保护要求，防止敏感信息泄露 |
| 推荐问题触发延迟 | `10 秒`内返回 | 引导用户缩小问题范围，适配党建学习问答的交互逻辑 |
| 接口超时阈值 | `30 秒` | 匹配疾控业务的响应时效要求，避免长时间等待影响工作流程 |

## 容易做错的三处
- 现象：免登录分享链接可直接跳转至FastGPT管理登录页面。原因：分享服务与管理页面使用了同一端口，未做权限隔离配置。
- 现象：嵌入的问答返回结果包含未脱敏的病例隐私信息。原因：未配置敏感字段过滤规则，直接推送了原始业务文档内容。
- 现象：嵌入的推荐问题与传染病监测、党建学习场景不匹配。原因：未绑定品类专属的文档库，使用了通用问答知识库。

## 怎么确认配好了
- 打开生成的分享链接，确认无法跳转到FastGPT管理登录页面。
- 提交包含病例隐私信息的测试提问，确认返回结果中无敏感字段内容。
- 等待每日同步周期结束后，提交涉及当日更新数据的问题，确认返回内容包含最新的监测信息。
- 点击嵌入的推荐问题按钮，确认返回的问题围绕传染病监测或党建学习相关主题。
