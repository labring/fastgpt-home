# 公共数据目录与开放的党建学习问答：向量模型与索引

## 这个品类的数据长什么样
本品类的数据主要来自地方公共数据开放平台、一体化大数据平台、部门业务数据库及电子证照库。日常维护的文档包括公共数据资源目录、数据开放清单、数据项说明、脱敏规则、接口文档、更新频率说明。数据更新频率为月度，单条数据包含数据项名称、开放范围、脱敏方式、接口地址、更新周期等结构化字段，部分关联非结构化的接口调用说明文档。

## 这些特征在「向量模型与索引」这一环带来什么约束
月度更新的特性要求优先配置增量索引逻辑，避免全量重建带来的额外耗时。结构化字段占比高，其中开放范围、脱敏规则等与党建学习问答相关的字段需要设置差异化召回权重。接口文档属于长文本内容，需要适配合理的分块长度，避免语义割裂。数据项数量较多且字段边界清晰，需确保向量模型生成的维度与字段语义匹配，同时需在向量生成环节过滤未脱敏的敏感数据，防止信息泄露。

## 配置怎么定
本配置基于 FastGPT v4.17.0 版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配公共数据目录的单条数据项说明、接口文档的语义完整性，避免长文本分块后语义断裂 |
| 重叠长度 | 100–200 字符 | 保证相邻分块间的语义连贯性，覆盖数据项名称与关联说明的衔接内容 |
| 相似度阈值 | 按实测标定 | 适配结构化字段与非结构化文档混合的召回需求，平衡精准度与召回率 |
| 单次搜索上限 | 前 5 条 | 匹配党建学习问答的单轮查询场景，避免返回过多无关数据项 |
| maxToken | 8192 | 适配text-embedding-ada-002的最大输入限制，兼容长接口文档的向量生成 |
| defaultToken | 1024 | 适配单条数据项说明的常规长度，平衡向量生成效率与语义完整性 |

## 容易做错的三处
- 界面显示“索引中”状态长时间无变化：原因是未适配公共数据目录的月度更新节奏，增量索引的触发周期未匹配数据更新频率，或分块长度设置过大导致单批次处理耗时过长。
- 调用向量模型时报错：原因是未将本地部署的m3e模型正确添加至可用渠道，或配置的`defaultToken`超出模型支持的最大输入长度。
- 知识库检索结果无匹配数据：原因是未针对公共数据目录的结构化字段设置对应召回规则，仅检索了非结构化文本，遗漏数据项名称、开放范围等关键字段的语义匹配。

## 怎么确认配好了
- 上传单条公共数据目录文档，查看向量生成日志，确认无敏感数据泄露提示。
- 触发增量索引任务，核对更新时间与数据月度更新周期是否匹配。
- 输入党建相关的查询词，检索结果包含对应数据项的开放范围、脱敏规则等内容。
- 检查模型渠道配置，确认已添加的text-embedding-ada-002或本地m3e模型处于可用状态。
