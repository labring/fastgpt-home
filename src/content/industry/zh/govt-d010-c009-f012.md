# 公共数据目录与开放的党建学习问答：部署与升级

## 这个品类的数据长什么样
本品类的数据均为政务领域结构化公共资产，来源包括地方公共数据开放平台、一体化大数据平台、部门业务数据库与电子证照库。日常维护的文档包含公共数据资源目录、数据开放清单、数据项说明、脱敏规则、接口文档与更新频率说明。数据更新频率为每月一次，核心字段包含数据项名称、开放范围、脱敏要求、接口地址、更新周期等，仅包含可共享或开放的结构化数据资产，不涉及通用政务公开的非结构化内容，重点标注数据共享与开放的授权边界。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据来源涉及多类政务平台，部署时需适配不同的数据库与存储接口，需提前配置对应的数据连接参数。每月一次的更新节奏要求升级时支持增量同步配置，避免全量重导数据占用过多政务服务器资源。结构化数据的固定字段规范要求知识库导入时需匹配预设字段格式，否则会出现数据项缺失或匹配错误。脱敏规则与接口文档的绑定要求部署时需同步配置数据校验逻辑，防止未脱敏的敏感数据流入党建问答环节。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://<username>:<password>@<host>:<port>/fastgpt?authSource=admin` | 存储党建问答的对话历史与知识库元数据，适配政务内网数据库的访问格式 |
| `PG_URL` | `postgresql://<username>:<password>@<host>:<port>/fastgpt` | 存储结构化的公共数据目录元数据，支持复杂的字段查询与过滤 |
| `DB_MAX_LINK` | `20–30 条` | 适配每月批量更新公共数据目录时的数据库连接池上限，避免占用过多政务服务器资源 |
| `STORAGE_S3_ENDPOINT` | `内网对象存储地址` | 存储脱敏后的公共数据文档与接口文档附件，符合政务数据存储的安全要求 |
| `REDIS_URL` | `redis://<password>@<host>:<port>/0` | 缓存公共数据目录的高频查询结果，降低数据库的访问压力 |
| `ROOT_KEY` | `按企业内网安全规则配置` | 管理平台的根密钥，保障配置与知识库的访问权限安全 |

## 容易做错的三处
- 启动后报错`connection refused`，无法创建数据库。原因是未正确配置`MONGODB_URI`或`PG_URL`指向的数据库未完成初始化，或数据库未开放对应端口的访问权限。
- 党建问答无法返回公共数据开放平台的相关内容。原因是未配置内网访问公共数据开放平台的白名单或代理，导致问答系统无法获取公开数据。
- Windows11环境下执行`docker build -f ./projects/`命令失败，提示`no such file or directory`。原因是未指定正确的Dockerfile路径，或项目目录结构与部署脚本不匹配。

## 怎么确认配好了
- 登录FastGPT v4.17.0管理后台，进入数据库连接配置页面，运行`MONGODB_URI`与`PG_URL`的连接测试，确认测试结果为通过。
- 导入一份标准的公共数据资源目录文档，检查导入后的知识库数据项是否完整匹配原文档的字段与内容。
- 发起包含公共数据查询的党建学习问答，确认返回结果包含脱敏后的正确数据项说明与接口地址。
- 触发一次增量同步任务，检查更新后的公共数据目录是否正常同步到知识库，且更新时间与实际更新周期匹配。
