# 公路养护与路产路权管理的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
该品类的日常文档包含养护计划、巡查日志、病害处置单、涉路施工许可、路产损坏赔偿单等，数据来源于公路养护管理系统、桥隧监测系统、路政巡查系统、交通流量监测数据。数据更新节奏为每日更新，文档结构以设施状态、作业记录、审批凭证为核心字段，字段多包含设施编号、养护里程、处置时限、赔偿金额等单位明确的业务参数。

## 这些特征在「分享与嵌入」这一环带来什么约束
每日更新的业务数据要求嵌入后的问答系统需定期同步知识库，避免使用过时的养护或审批信息影响党建学习内容的准确性。多类业务文档的混合存储，要求分享配置中需区分不同文档的检索优先级，确保党建学习问答能准确关联路产相关的业务内容。路政执法与养护作业的场景差异，要求嵌入页面的上下文传递需适配不同岗位的查询逻辑，同时分享链接的参数传递需兼容不同内部系统的接口格式。数据字段包含明确单位，嵌入后的问答输出需保留对应单位，避免因单位缺失引发业务歧义。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的逻辑制定。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分享链接有效期 | 7 天 | 适配公路养护业务的周度作业计划更新节奏，避免链接过期影响日常党建学习问答调用 |
| `shareId` 绑定范围 | 仅内部业务系统域名 | 防止外部非授权场景调用党建问答知识库，保障路产数据安全 |
| 嵌入页面标题自定义 | 固定为「公路养护党建学习问答」 | 避免小程序嵌入时被意外修改，匹配业务场景的统一展示需求 |
| 上下文同步频率 | 每日凌晨 2 点 | 匹配业务数据的日更新节奏，确保问答系统使用最新的养护与巡查数据 |
| URL参数传递开关 | 开启 | 支持通过链接带入党建学习的主题参数，适配不同班组的学习场景 |

## 容易做错的三处
- 现象：小程序嵌入对话页面后，顶部标题被意外修改且无法通过常规设置恢复。原因：未开启嵌入页面标题自定义锁定，或自定义标题配置未持久化保存。
- 现象：发布的iframe嵌入页面无机器人回复，调试区域显示正常。原因：未在分享配置中开放对应域名的跨域权限，或知识库未同步最新的路产养护数据。
- 现象：通过分享URL传递全局变量未生效。原因：未开启URL参数传递配置，或传递的参数名称与系统预设的全局变量字段不匹配。

## 怎么确认配好了
- 打开嵌入后的页面，检查顶部标题是否为预设的「公路养护党建学习问答」，确认未被意外修改。
- 在调试区域输入养护相关的党建学习问题，查看是否能返回匹配的巡查日志或审批文档内容。
- 尝试通过带参数的分享链接访问，确认全局变量参数能被系统正确识别并应用。
- 等待每日数据同步后，再次测试问答结果是否包含最新的养护计划内容。
