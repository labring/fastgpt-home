# 内控评价、审计与整改的党建学习问答：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据来自中央企业内控系统、ERP、财务共享系统、审计管理系统、采购合同项目系统，更新频率为年度。日常文档包含内控自评报告、审计通知书、审计工作底稿、问题清单、整改台账、整改销号证明，文档结构多包含问题描述、整改要求、佐证材料标识、销号状态等字段，部分文档附带图片类佐证材料，数据来源覆盖多业务系统，需统一整合至知识库中。

## 这些特征在「知识库检索与召回」这一环带来什么约束
本品类的数据特征对检索召回环节带来多重约束。多系统来源的数据格式不统一，需适配不同数据源的导入规则；年度更新的频率决定了无需高频增量同步，可采用定期全量更新；带图片佐证的文档要求检索系统支持多模态内容索引与输出；审计问题与整改记录的强关联属性，要求检索精准匹配问题对应的整改台账，避免无关内容混入；出错后果直接关联监管要求，需保障检索结果的置信度，减少误召回。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 内控审计数据需精准匹配问题描述，该区间可平衡召回率与精准度，避免无关整改记录干扰 |
| `limit` | 前10条 | 审计整改数据条目相对规整，10条可覆盖单次查询的典型关联整改、问题清单内容 |
| `searchMode` | 语义检索 | 适配党建学习问答中对政策、整改要求的语义匹配需求，替代关键词检索的生硬匹配 |
| `usingReRank` | 开启 | 审计问题多为结构化描述，重排可进一步过滤低相关结果，提升检索准确性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 党建学习问答需关联政策与整改动作，扩展查询可补充相关党建政策关键词，匹配更全面 |
| `collectionIds` | 按业务域指定 | 区分内控、审计、整改不同数据集，避免跨域无关数据混入检索结果 |

## 容易做错的三处
- 现象：对话中无法输出知识库中存储的图片URL内容。原因：未配置多模态数据的检索输出规则，仅索引了文本元数据，未关联图片资源地址。
- 现象：导入PPT格式的审计工作底稿时，仅提取文字未保留内嵌图片。原因：未启用文档解析时的图片提取开关，或分块配置未覆盖图片字段。
- 现象：检索结果中相同整改问题被多次独立展示，未自动合并。原因：未启用搜索引用合并功能，或合并规则未匹配到重复的整改记录条目。

## 怎么确认配好了
- 执行包含具体整改问题关键词的测试查询，核对返回结果的条目数与`limit`设置一致。
- 上传包含图片的整改销号证明文档，检索后确认结果中包含图片URL字段。
- 导入PPT格式的审计通知书，检查解析结果是否同时包含文档内的文字与内嵌图片内容。
- 调整`similarity`阈值，验证检索结果的精准度变化符合预期。
