# 国土空间规划编制与实施评估的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
数据来源包括国土空间基础信息平台、自然资源调查监测数据、人口经济统计数据、遥感影像。更新频率为年周期，日常处理的文档包含国土空间总体规划、详细规划、专项规划、规划实施评估报告、公众意见汇总等。数据字段涵盖空间坐标、约束指标、人口经济统计数值、遥感影像元数据等，单文档长度差异较大，多源数据格式存在明显区别。

## 这些特征在「模型接入与配置」这一环带来什么约束
年周期的更新节奏意味着无需频繁刷新知识库，但每次更新需整合多源异构数据，对模型的上下文容纳能力提出要求。文档长度差异大，需适配不同长度的规划文本与空间数据，避免上下文溢出。党建学习问答需严谨准确，模型参数需兼顾内容合规性与信息准确性，同时需确保引用的规划文档片段可追溯，避免出现与实际规划冲突的回答。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配规划文档与评估报告的总长度，容纳多源数据的上下文信息 |
| `maxTokens` | 4000–6000 token | 满足党建问答的回答长度需求，同时避免单次调用超时 |
| `temperature` | 0.2–0.4 | 保障党建学习问答的严谨性，降低回答的发散性 |
| `quoteMaxToken` | 1500–2000 token | 确保可引用足够的规划文档片段作为回答依据 |
| `AIPROXY_API_ENDPOINT` | 部署内部代理的访问地址 | 适配内部网络环境，规避公网调用的安全风险 |
| `AIPROXY_API_TOKEN` | 环境变量存储的密钥 | 避免密钥明文泄露，符合数据安全管理要求 |

## 容易做错的三处
- 现象：直接调用重排模型API返回参数错误。原因：未在FastGPT的应用配置中绑定重排模型到党建问答工作流，仅单独调用API无法接入处理流程。
- 现象：整点时段自动触发GPT-4-turbo调用，无定期执行任务配置。原因：FastGPT v4.17.0默认开启整点模型缓存刷新，未手动关闭该配置项。
- 现象：部分PDF文件上传后内容为空。原因：未启用`vision`参数，扫描版PDF的图像内容未被OCR识别，仅支持纯文本PDF。

## 怎么确认配好了
- 在FastGPT v4.17.0的模型管理页面，测试`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`的配置，返回正常的模型响应。
- 上传不同格式的规划文档与PDF文件，确认所有文件内容被正确解析，无空内容报错。
- 触发党建问答的测试请求，查看返回结果是否引用了规划文档的片段，且无无可用渠道的提示。
- 调整`temperature`参数为0.3，测试问答的严谨性，确认回答符合党建学习的规范要求。
