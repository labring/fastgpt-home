# 国库集中支付与报销审核的党建学习问答：表单与交互

## 这个品类的数据长什么样
本品类的数据来自国库集中支付系统、预算管理一体化系统、电子发票平台、合同管理系统，更新频率为每日。日常处理的文档包含支付申请、用款计划、发票、合同、验收单、报销审批单、支付凭证，字段涉及预算指标编号、经济分类代码、支付金额、合同编号、票据校验码等，单条数据围绕单笔资金支付的全流程审核环节展开。

## 这些特征在「表单与交互」这一环带来什么约束
多源数据来源要求表单需支持跨系统数据拉取与字段绑定，减少人工录入的重复操作与误差。日更的数据属性要求表单交互需支持实时拉取最新预算指标与票据信息，确保审核依据的时效性。多类文档与单笔支付的聚焦属性，要求表单需按审核环节拆分字段组，同时校验必填字段的完整性。严重的出错后果要求表单需增加退单提示、违规拦截等交互环节，降低资金错付与审计风险。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的规则制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 支持多文档上传与字段映射 | 品类需处理发票、合同等多类审核文档，需将上传文件内容与对应审核字段绑定 |
| `userSelect` | 预设预算单位、审核岗角色选项 | 典型主体为预算单位财务、国库支付中心等岗位，需标准化不同角色的操作权限 |
| 上传文件大小限制 | 100–500 MB 按实测标定 | 品类文档包含合同、验收单等大体积文件，需适配实际上传需求 |
| 提交超时阈值 | 600 秒 | 多源数据拉取需一定耗时，避免因网络波动导致提交失败 |
| 单次上传文件数 | 不超过10个 | 单审核批次的关联文档数量通常在10个以内，避免表单加载卡顿 |
| 输入字符数限制 | 8000–12000 字符 按实测标定 | 品类审核数据包含多字段拼接的json内容，需适配长文本输入需求 |

## 容易做错的三处
- 现象：表单提交后弹出数据源连接失败提示，或无法拉取国库集中支付系统的预算指标数据。原因：未正确配置国库集中支付系统等四类业务系统的连接参数，导致无法访问品类依赖的业务数据源。
- 现象：上传的发票、合同等文档未参与党建学习问答的内容检索，问答结果未关联上传文件的相关信息。原因：未将上传文件绑定到`formInput`输入组件，或未开启文档自动解析的配置开关。
- 现象：提交的json格式审核数据被自动截断，无法完成统计总结或问答生成。原因：未调整表单的输入字符数阈值，超出系统默认的字符限制。

## 怎么确认配好了
- 进入表单配置页面，验证国库集中支付系统等四类数据源的连接状态，确认可拉取测试用的预算指标数据。
- 上传品类对应的发票、合同文档，检查是否能在党建学习问答的检索结果中匹配到对应文件的内容。
- 提交包含完整必填字段的测试数据，确认无字段缺失、超时或连接报错。
- 调整输入字符数阈值后，提交超长json格式的测试数据，确认不会被自动截断。
