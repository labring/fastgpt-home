# 国库集中支付与报销审核的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
本品类的数据来源于国库集中支付系统、预算管理一体化系统、电子发票平台、合同管理系统，更新频率为每日。日常处理的文档包含支付申请、用款计划、发票、合同、验收单、报销审批单、支付凭证，核心字段覆盖预算指标、经济分类、票据编号、合同条款、验收记录与资金金额等，所有数据围绕单笔资金支付的合规审核流程生成，属于财政管理的日常执行环节数据。

## 这些特征在「分享与嵌入」这一环带来什么约束
本品类数据的日更特性要求分享与嵌入的知识库需配置定期更新机制，确保问答内容匹配最新的支付与报销单据信息。单笔审核关联多类单据的结构，要求嵌入会话需保留上下文关联，避免问答断裂影响审核效率。数据涉及财政合规相关内容，要求分享链接需严格限定访问权限，同时需支持语种自定义适配不同使用群体。此外，敏感业务数据的溯源需求，要求分享链接需支持日志记录与查看功能，满足审计要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分享链接语种设置 | 按会话场景单独配置，不跟随控制台主界面 | 适配内外网不同使用群体的语言需求，解决语种不一致的使用问题 |
| 分享提示语显示 | 可单独开启或关闭 | 满足不同使用场景下的界面简洁需求，支持隐藏无关提示内容 |
| `shareId` 绑定规则 | 限定为当前品类的知识库ID | 确保分享的会话仅调用国库集中支付与报销审核相关业务数据，避免混入其他品类内容 |
| 嵌入会话上下文长度 | 800–1200 字符 | 匹配单笔支付审核相关单据的信息长度，保证问答的上下文关联完整 |
| 分享链接访问日志权限 | 绑定控制台管理员角色 | 确保敏感操作的审计可追溯，符合财政管理的合规要求 |
| 会话超时设置 | 600 秒 | 适配财政审核的常规操作时长，防止会话中途失效 |

## 容易做错的三处
- 分享链接显示的语种与控制台主界面设置不符，无法适配指定使用群体 | 原因是未单独配置分享链接的语种选项，默认跟随控制台全局语言设置。
- 无法查看分享链接对应的他人问答记录，日志入口显示无权限或为空 | 原因是未授予对应角色分享日志的查看权限，或未开启分享链接的日志记录功能。
- 嵌入会话返回非本品类的业务数据，如预算编制相关内容 | 原因是未通过`shareId`绑定限定数据源范围，混入了其他财政品类的知识库内容。

## 怎么确认配好了
- 打开分享链接，切换语种设置选项，确认显示的界面语言与配置的目标语种一致。
- 使用非管理员账号访问分享链接，确认提示语是否按配置显示或隐藏，符合预期效果。
- 登录控制台的日志管理页面，查看分享链接对应的会话记录，确认能获取到对应问答内容。
- 向嵌入会话提问非本品类的业务问题，确认返回结果为空或提示无法回答，确保数据源限定生效。
