# 土地使用权、矿业权与国有产权交易的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
该品类数据主要来自全国公共资源交易平台、自然资源交易系统、产权交易所系统及国资监管系统，更新频率为每日。日常文档包含出让公告、交易须知、竞买申请、保证金凭证、成交确认书、挂牌结果公告、产权转让说明书，通常包含权属编号、交易标的类型、保证金金额、挂牌起始价等专业字段，单位涉及平方米、万元、宗等。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散且每日更新，要求配置支持多系统增量同步的接入逻辑，避免全量拉取占用过多计算资源。文档类型多样且包含专业权属、金额字段，需适配不同文档长度的分块规则，确保专业字段不被意外截断。权属信息直接关联交易合规性，模型调用时需严格限定上下文范围，防止引入无关数据导致权属判断错误。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 匹配产权转让说明书等长文档的上下文长度，避免截断核心权属信息 |
| `maxTokens` | 2000–3000 token | 控制党建问答的回复长度，确保涵盖交易规则与权属说明的完整内容 |
| `quoteMaxToken` | 1500 token | 限定引用的交易文档片段长度，保证引用内容精准且不超出上下文限制 |
| `temperature` | 0.2–0.4 | 降低党建问答的随机性，确保权属、交易流程等专业内容表述准确 |
| `vision` | 关闭 | 该品类核心文档以结构化文本为主，无图片理解需求，可减少资源消耗 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写专属端点 | 适配国内合规的API调用路径，确保数据传输符合公共资源交易的安全要求 |
| `AIPROXY_API_TOKEN` | 填写平台分配的专属密钥 | 确保API调用的身份验证有效，避免请求被拦截或拒绝 |

## 容易做错的三处
- 调用渠道链接时返回“undefined”is not valid json：原因是配置的`AIPROXY_API_ENDPOINT`未正确适配部署环境，导致API请求格式异常。
- 误开启`vision`参数并尝试配置图片理解模型：原因是未明确该品类核心文档以结构化文本为主，无需图片解析能力，导致冗余配置。
- 错误设置`toolChoice`为强制调用工具：原因是党建问答场景无需调用外部工具，强制调用会导致流程中断，返回无效结果。

## 怎么确认配好了
- 执行增量同步测试，查看数据更新日志，确认每日增量数据正常拉取。
- 输入党建相关的交易合规问题，查看回复中是否准确引用了权属、交易规则等核心字段。
- 调用渠道链接发起测试请求，确认返回结果格式为合法JSON，无异常报错。
- 检查`vision`参数状态，确认未开启且未触发图片解析任务，减少不必要的资源占用。
