# 学生资助与奖补审核的党建学习问答：知识库检索与召回
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这个品类的数据长什么样
本品类的数据来源包括全国学生资助管理信息系统、学校学籍系统、民政低保特困数据及财政支付系统，更新周期为每学期。日常处理的文档涵盖家庭经济困难认定表、资助申请表、奖助学金评审表、发放名单与公示材料，数据形态包含结构化表单、半结构化公示文本两类，字段涉及身份标识、家庭经济状况、资助资格判定依据及资金发放相关信息。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源要求检索环节支持跨数据集关联匹配，避免割裂的数据源导致资格判定遗漏。学期级的更新周期要求知识库同步策略兼顾增量更新与全量校验，平衡数据时效性与系统负载。混合了结构化表单与半结构化公示文本的数据特征，需要检索配置适配不同格式的字段匹配规则。同时，该品类的出错后果直接关联学生权益与政务公信力，要求召回结果需精准覆盖资格判定所需的全部核心字段。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 适配结构化表单与半结构化文本的混合匹配需求，平衡精准度与召回覆盖范围 |
| `limit` | 前10条 | 覆盖评审、发放名单等多批次数据的检索需求，避免单批次结果遗漏核心判定依据 |
| `searchMode` | 全文检索+字段匹配 | 适配混合了结构化字段与文本描述的文档类型，支持按关键词与字段值双重召回 |
| `usingReRank` | 开启 | 提升高置信度结果的排序优先级，确保资格判定所需的关键材料优先返回 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展党建学习相关的政策表述，匹配党建学习问答场景下的关联检索需求 |
| `collectionIds` | 按资助类文档集合指定 | 限定检索范围至学生资助相关的专属数据集，避免无关内容干扰检索结果 |

## 容易做错的三处
- 现象：检索过程中返回无权访问报错，或无法加载指定文档的详情。原因：未正确配置`collectionIds`限定检索范围，或数据集的访问权限未开放至当前工作流的调用主体。
- 现象：召回的检索片段无法关联原文档的在线预览入口。原因：未采集文档的元数据存储路径，或未在工作流中配置原文件预览的跳转逻辑。
- 现象：结构化表单类文档未被正确召回，或匹配结果与关键词关联度较低。原因：`searchMode`未切换至适配结构化字段的匹配模式，仅使用全文检索导致字段匹配失效。

## 怎么确认配好了
- 输入包含家庭经济困难认定、奖助学金发放等关键词的测试查询，核对返回结果是否包含本品类的核心文档类型。
- 调整`similarity`的取值区间，通过多轮测试确认召回结果的精准度与覆盖范围符合业务校验需求。
- 查看检索结果的元数据，确认是否关联了原文档的存储路径，支持后续的原文件查看操作。
- 测试限定`collectionIds`的检索范围，确认仅本品类的资助类文档被纳入召回结果。
