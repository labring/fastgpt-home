# 工程建设项目招投标的党建学习问答：部署与升级

## 这个品类的数据长什么样
本品类的数据覆盖工程建设招投标全流程文档，包括招标公告、资格预审文件、招标文件、投标文件、评标报告、中标候选人公示、中标结果公告，以及配套的党建学习相关行业政策文件。数据来源为全国公共资源交易平台、地方交易平台、工程审批系统、招标投标监管系统，按日更新。文档包含标段划分、资格条件、评标规则、中标结果等核心字段，部分文档涉及工程量清单、施工周期等专项内容。

## 这些特征在「部署与升级」这一环带来什么约束
本指南基于FastGPT v4.17.0版本编写。本品类数据来源分散且按日更新，部署时需适配多平台数据接入的存储配置，确保每日增量同步的稳定性。文档类型多样且结构差异明显，需针对不同文档预设匹配的索引规则，避免检索偏差。由于招投标流程出错后果直接关联项目进度与合规风险，部署与升级环节需预留回滚节点，同时配置数据校验逻辑，确保接入文档的字段完整性。另外，党建学习问答需关联招投标领域党建要求，需单独配置专属知识库的关联路径，避免与通用业务数据混淆。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | 填写对应公共资源交易数据的只读实例连接串 | 用于存储招投标与党建知识库的结构化文档，只读实例避免写入风险 |
| `REDIS_URL` | 配置本地缓存实例的连接地址，缓存有效期设为86400秒 | 按日更新的数据源需每日刷新缓存，避免读取过期数据 |
| `DB_MAX_LINK` | 设为15–20条并发连接 | 适配多平台每日增量同步的请求量，避免连接池耗尽 |
| `STORAGE_S3_ENDPOINT` | 填写对应云存储服务商的终端节点 | 用于存储招投标文档的附件与党建学习素材的二进制文件 |
| `FE_DOMAIN` | 填写平台对外访问的域名 | 用于生成知识库检索结果的跳转链接，适配内部办公场景的访问路径 |

## 容易做错的三处
- 界面提示需要9.0以上版本的pnpm，部署脚本无法执行。原因是未提前配置对应版本的pnpm环境，或使用了系统默认的低版本pnpm执行部署命令。
- 开源重排序模型部署后检索结果为空。原因是未正确配置模型的加载路径与端口映射，或未在知识库配置中启用重排序功能。
- 升级后无法访问后台管理页面，提示权限错误。原因是未保留`ROOT_KEY`的原有配置值，导致升级后重置了管理员密钥，无法验证登录权限。

## 怎么确认配好了
- 执行每日增量同步脚本，检查后台日志是否显示同步任务成功完成，核对同步的文档数量与数据源更新量匹配。
- 提交一条包含招投标专有术语的党建相关问题，检索结果返回对应关联的政策与业务文档，验证知识库关联逻辑生效。
- 修改`FE_DOMAIN`配置后，访问平台前端页面，检查所有跳转链接的域名是否更新为新配置值。
- 重启服务后，检查`REDIS_URL`对应的缓存实例是否正常建立连接，无连接超时报错。
