# 市场主体登记与许可的党建学习问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的日常文档包含设立登记申请书、章程、股东决议、住所证明、营业执照、食品经营许可申请等标准化材料，数据来源于企业登记全程电子化系统、国家企业信用信息公示系统、电子营业执照系统及住所信息库。数据更新频率为每日，文档以结构化表单和规范文本为主，字段涵盖主体名称、住所信息、股东信息、许可类型等，整体结构规整，无大量非标准化冗余内容，覆盖市场主体登记与许可的全流程环节。

## 这些特征在「知识库检索与召回」这一环带来什么约束
每日更新的数据源要求检索链路支持增量同步与实时召回，避免因数据滞后导致的登记许可判断错误。结构化文档的明确字段要求检索需兼顾精准关键词匹配与语义理解，减少无关召回结果。覆盖全流程的文档类型需要知识库按业务环节拆分检索范围，确保召回内容与党建学习中涉及的登记许可规范高度匹配。跨系统数据源的格式差异，要求检索前完成统一格式解析，避免字段解析异常影响召回准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 匹配登记许可的精准字段需求，过滤低相似度的无关文档，确保召回内容与业务强相关 |
| `limit` | `前8–12条` | 覆盖登记、许可、变更、注销等全流程文档类型，确保召回结果足够支撑党建学习中的业务判断 |
| `searchMode` | `vector+keyword` | 适配结构化文档的字段精准匹配与语义检索双重需求，兼顾关键词的精准性与语义的泛化性 |
| `usingReRank` | `开启` | 提升高相关结果的排序优先级，修正纯向量检索可能出现的语义偏差，优化结果展示顺序 |
| `datasetSearchUsingExtensionQuery` | `开启` | 补充党建学习相关的扩展检索词，覆盖规范表述与业务术语的差异，提升检索召回的全面性 |
| `collectionIds` | `按业务环节绑定对应知识库集合` | 精准限定检索范围，避免跨品类文档的干扰，确保召回内容仅涉及市场主体登记与许可领域 |

## 容易做错的三处
- 现象为私有部署环境下无法找到图片数据集的添加设置，原因是FastGPT v4.17.0版本的私有部署包未默认集成图片解析扩展插件，需手动部署对应模块。
- 现象为无法查看单篇资料的历史调用日志，原因是未开启知识库的日志采集配置，导致检索行为未被记录。
- 现象为检索返回结果条数与配置不符，原因是未正确设置`limit`参数的取值范围，导致召回上限被错误调整。

## 怎么确认配好了
- 手动输入一条登记许可相关的党建学习问题，核对检索结果的文档类型是否匹配预设的业务范围。
- 查看知识库的日志面板，确认检索请求携带了正确的`collectionIds`参数，限定了对应业务集合。
- 测试不同关键词的检索请求，验证向量与关键词混合检索模式是否生效，确保结果排序符合业务预期。
- 检查增量同步任务的运行状态，确认每日更新的数据源已同步至知识库，避免数据滞后影响召回准确性。
