# 市容环卫与城管执法案件的党建学习问答：知识库检索与召回

本页面配置基于FastGPT v4.17.0版本。

## 这个品类的数据长什么样
该品类的典型数据来自城管执法局、街道综合执法队、环卫中心及网格员的日常工作产出。日常文档包含巡查记录、案件立案审批表、现场照片、责令改正通知书、处罚决定书、结案报告等，数据来源覆盖城管执法平台、城市运行网格平台、视频监控及群众投诉工单。数据更新频率为每日，覆盖现场取证、案件流转、整改执行全流程的最新信息。文档结构包含结构化字段与非结构化文本、图片混合内容，部分字段关联执法场景的特定业务逻辑。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源混合的数据来源要求检索支持跨平台、多类型文档的联合召回，避免遗漏来自网格工单或视频监控的关键线索。日更的更新频率要求检索链路支持增量同步，确保最新的案件记录与整改信息可快速纳入检索范围。非结构化的现场照片与文本混合文档，要求检索不仅覆盖文本语义，还需关联图片元数据或关联说明内容。执法场景的精准性要求，意味着检索结果需严格匹配案件的违法类型与责任主体，避免召回无关内容影响现场处置判断。党建学习问答的场景需求，还需将执法规范与党建学习内容做关联匹配，确保回答同时符合业务要求与党建导向。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配城管执法案件的精准度要求，避免召回无关的日常巡查记录，同时保留有效案件关联内容 |
| `limit` | 前8条 | 兼顾上下文长度与信息覆盖，适配执法场景的多维度参考需求，避免过长上下文导致模型混淆 |
| `searchMode` | 混合检索 | 支持文本、结构化字段与图片元数据的联合召回，适配该品类多类型文档的检索需求 |
| `usingReRank` | 开启 | 对初始召回结果重排序，修正语义偏差，提升违法类型判断与责任主体匹配的准确性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于党建学习问答的场景扩展查询词，关联执法规范与党建要求的关联内容，满足场景化检索需求 |
| `collectionIds` | 绑定对应城管执法、党建知识库的集合ID | 限定检索范围，避免混入无关业务数据，确保检索结果聚焦目标场景 |

## 容易做错的三处
-  复杂执法场景问题无法得到准确回答，召回结果的有效匹配率偏低。原因：未调整`similarity`阈值，取值过高导致遗漏有效案件记录，或过低导致混入无关巡查内容。
-  语义检索无法命中包含特定业务关键词的知识块。原因：未开启`datasetSearchUsingExtensionQuery`，未针对党建学习问答场景扩展关联查询词，导致关键词未被正确识别。
-  检索到图片地址时提示未找到答案，更换对话模板后可正常回复。原因：未配置多模态检索支持，仅对纯文本内容做语义匹配，未处理图片地址关联的说明文本或元数据。

## 怎么确认配好了
-  提交5条典型执法场景问题与3条党建学习关联问题，核对召回结果是否覆盖目标业务与党建内容。
-  查看知识库同步日志，确认每日新增的案件文档是否自动完成检索索引更新。
-  调用API时传入指定的`collectionIds`参数，验证检索范围仅包含城管执法与党建相关的知识库集合。
-  上传测试用的现场照片关联文档，验证是否可通过图片元数据召回对应的执法规范内容。
