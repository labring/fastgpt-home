# 投资项目立项与后评价的党建学习问答：向量模型与索引

## 这个品类的数据长什么样
本品类数据主要来自国资委投资监管系统、企业ERP与项目管理系统、行业市场数据、审计及财务报表，更新频率为季度。日常处理的文档包括年度投资计划、项目建议书、可行性研究报告、尽职调查报告、资产评估报告、投资后评价报告，文档多包含项目投资、进度节点、风控条款、后评价指标等结构化与半结构化字段，无统一固定的单文档长度标准。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类的数据来源分散且更新周期固定，要求索引环节支持跨系统数据的增量同步与定期全量更新。文档类型覆盖多类专业报告，部分报告篇幅较长，需适配不同文档的分块规则，避免关键业务信息被截断。数据包含项目投资、风控、后评价等专业字段，向量召回需优先匹配业务相关的核心内容，同时需保障索引的稳定性，避免因数据错误引发后续决策偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配本品类多数专业报告的段落长度，避免拆分关键业务语句 |
| 重叠长度 | 100–150 字符 | 保障相邻分块间的上下文连贯性，覆盖跨块的项目节点描述 |
| 相似度阈值 | 0.75–0.85 按实测标定 | 平衡专业内容的召回精度与召回范围，适配国资监管相关的严谨要求 |
| 重排 | 开启，取前3–5条 | 针对多字段的专业查询，通过重排过滤无关结果，聚焦核心投资与后评价内容 |
| maxToken | 8000 | 适配多数专业报告的上下文长度需求，避免截断重要风控与财务信息 |
| defaultToken | 1000 | 控制单轮问答的返回长度，符合党建学习问答的信息输出规范 |

## 容易做错的三处
- 现象：开启重排配置后，在线召回测试返回结果条数与配置的重排数量不符。原因：未在知识库索引环节同步开启重排开关，仅在问答环节配置未生效。
- 现象：上传专业报告中的图表附件后，索引结果未包含图表相关的文本或元数据。原因：本地部署版本未启用图片索引模型，该功能需依赖对应插件支持。
- 现象：知识库索引过程中出现连接超时报错，OneAPI返回连接失败状态码。原因：未正确配置Embedding模型的调用地址与密钥，导致向量生成环节无法正常连通外部服务。

## 怎么确认配好了
- 查看FastGPT v4.17.0的知识库索引日志，确认分块后的文档数量与原文档数量匹配，无明显截断报错。
- 执行单条专业查询，验证召回结果包含项目投资、风控等核心字段的相关内容。
- 开启重排配置后，对比开启前后的召回结果排序，确认结果顺序发生调整。
- 检查Embedding模型的连接状态，确认无连续的连接失败日志。
