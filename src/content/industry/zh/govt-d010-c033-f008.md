# 招标采购合规管理的党建学习问答：文档解析与分块

## 这个品类的数据长什么样
本品类的数据来自国央企采购平台、公共资源交易平台、供应商库、合同管理系统及审计问题库，更新频率为每日。日常处理的文档包含采购计划、需求说明书、招标文件、评标记录、合同、验收单与供应商投诉材料，涵盖结构化表格数据与非结构化文本内容，字段涉及采购方式、预算依据、评分办法、供应商资格条件等，部分文档包含多页表格与嵌套格式。

## 这些特征在「文档解析与分块」这一环带来什么约束
本品类的多来源、高频更新文档特征，要求文档解析需适配多种格式，包括带嵌套表格的PDF与结构化CSV文件。采购类文档常包含跨页的合规条款与评分细则，分块时需保留上下文关联，避免拆分关键合规逻辑。每日更新的批量文档需控制解析耗时，同时需准确提取表格字段，避免遗漏关键数据。部分文档涉及审计与纪检内容，需完整保留原文细节，防止解析丢失对合规审查有重要作用的依据。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配采购类文档中跨页的合规条款与表格段落，保留上下文完整性 |
| `chunkSplitter` | 按段落+页眉页脚过滤 | 匹配采购文档的章节结构，避免拆分评标记录、合同条款这类连续合规内容 |
| `customPdfParse` | 启用 | 适配本品类文档中嵌套表格、多格式混合的PDF文件，替代默认解析的局限性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 应对批量大体积采购文档的解析耗时，避免超时中断 |
| `UPLOAD_FILE_MAX_SIZE` | 100–200 MB | 适配大型招标文件、供应商投诉材料的上传需求 |
| `chunkSettingMode` | 手动配置 | 针对不同文档类型（如招标文件、合同）调整分块规则，满足合规审查的精度要求 |

## 容易做错的三处
- 现象：CSV表格数据仅导入前两列，解析后字段缺失。原因：未针对采购类文档的多列结构化数据调整解析规则，默认解析逻辑限制了字段提取范围。
- 现象：自定义PDF解析服务调用超时，任务状态显示失败。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，大型招标文件的解析耗时超出默认阈值。
- 现象：分块后合规条款被拆分，无法关联上下文。原因：`chunkSize`取值过小，截断了跨页的采购方式、预算依据等关键合规内容。

## 怎么确认配好了
- 上传一份标准招标文件PDF，检查解析后的文本是否包含完整的评分办法、供应商资格条款，无明显内容遗漏。
- 上传一份结构化CSV采购数据，确认提取的字段覆盖采购编号、预算金额、供应商资质等必要字段，无仅保留前两列的情况。
- 查看解析任务的日志，确认`PARSE_FILE_TIMEOUT_SECONDS`参数生效，无超时报错记录。
- 调整`chunkSize`参数后，对比分块结果，确保跨页的合规段落未被强制拆分。
