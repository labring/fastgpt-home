# 招标采购合规管理的党建学习问答：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据来源包括企业采购平台、公共资源交易平台、供应商库、合同管理系统、审计问题库，更新频率为每日。日常文档涵盖采购计划、需求说明书、招标文件、评标记录、合同、验收单、供应商投诉材料，核心字段包含采购方式、预算依据、评分办法、供应商资格条件、履约验收条款等，文档多为结构化与非结构化混合形式，无统一固定格式。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源要求检索范围需精准限定，避免混入非招标采购的无关文档；每日更新的特性要求检索链路适配增量同步的数据集，确保召回内容为最新合规条款；文档混合结构化表格与非结构化文本，需适配不同内容的分块与编码规则；核心字段涉及采购合规的关键判断项，检索需优先匹配这些字段的语义关联，否则可能引发串标围标、审计整改等风险。同时党建学习问答的场景要求检索结果需关联党建相关的采购合规要求，需扩展查询的语义覆盖范围。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的参数逻辑制定。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 招标采购合规需精准匹配合规条款，该阈值可过滤低相关结果，避免审计与采购决策受干扰 |
| `limit` | 前8条 | 平衡上下文长度与召回覆盖范围，避免过多冗余内容挤占token配额，同时覆盖关键合规依据 |
| `searchMode` | `vector` | 招标采购文档多为语义明确的合规规则，向量检索可精准匹配相似的采购合规条款 |
| `usingReRank` | 开启 | 针对相似问题较多的场景，重排可过滤语义偏差的召回结果，提升合规判断的准确性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 适配党建学习问答场景，扩展查询可补充党建相关的采购合规指引，贴合业务需求 |
| `collectionIds` | 指定招标采购合规专属数据集ID | 限定检索范围仅覆盖本品类的文档，避免混入其他品类的无关内容 |

## 容易做错的三处
- 现象：检索返回结果为空，或从知识库引用中提取的内容为空。原因：未配置`collectionIds`限定检索范围，导致检索覆盖了非招标采购合规的数据集，无法匹配到对应内容。
- 现象：相似的非合规问题（如系统密码找回类）被优先召回。原因：`similarity`阈值设置过低，且未开启`usingReRank`，导致低相关的非合规内容干扰检索结果。
- 现象：无法输出文档内的图片内容。原因：未启用文档解析的图片提取功能，或知识库配置未开启图片索引，导致图片内容未被纳入检索与召回范围。

## 怎么确认配好了
- 手动输入采购方式、预算依据相关的合规问题，核对召回结果是否仅包含招标采购合规文档的内容。
- 调整`similarity`阈值，观察召回结果的相关性变化，确认符合业务场景的精准度要求。
- 上传测试用的招标采购文档，验证是否能正确召回对应条款，且无无关内容混入。
- 对比开启和关闭`usingReRank`后的召回结果，确认重排功能正常生效。
