# 排污许可管理的党建学习问答：引用来源与溯源

## 这个品类的数据长什么样
本品类数据来源包括全国排污许可证管理信息平台、企业环保台账、在线监测系统、环境统计系统。日常文档涵盖排污许可证申请表、执行报告、自行监测方案、台账记录、变更申请、许可证副本。数据按季度更新，包含许可排放限值、排放口信息、监测频次、执行合规情况等字段，无统一固定单位，随具体文档的字段要求变化。

## 这些特征在「引用来源与溯源」这一环带来什么约束
数据来源分散且多系统同源，溯源时需明确匹配对应平台的文档唯一标识，避免跨源数据混淆。按季度更新的特性要求优先调取最新季度的有效文档版本，确保党建学习问答引用的内容符合当前合规要求。文档类型多样，需区分排污许可证副本、执行报告、自行监测方案等不同文档的引用逻辑，匹配对应岗位的学习需求。字段无统一单位，需在溯源时保留原始文档的字段标注，确保引用内容的准确性。

## 配置怎么定
本配置说明基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | 排污许可核心文档的有效内容长度集中在该区间，可完整覆盖关键合规条款与数据 |
| `responseData` | 开启 | 需在党建学习问答中展示引用来源，开启后可返回关联文档的元信息，满足溯源要求 |
| `detail` | 完整 | 需保留原始文档的字段标注与版本标识，便于学习人员核对具体内容 |
| 单次搜索上限 | 前5条 | 排污许可相关有效文档数量有限，过多条目会分散学习注意力，聚焦核心引用内容 |

## 容易做错的三处
- 现象：正式聊天界面未展示排污许可文档的引用来源，仅调试页面可见。原因：未开启`responseData`配置项，或配置未同步至正式部署环境。
- 现象：引用的文档条数超出预设范围，无法固定为指定数量。原因：未设置单次搜索上限配置，或配置取值未匹配排污许可文档的实际分布情况。
- 现象：引用内容被截断，缺失关键的许可排放限值字段。原因：`quoteMaxToken`配置取值过小，无法覆盖单份核心文档的完整有效内容。

## 怎么确认配好了
- 发起包含排污许可相关问题的测试对话，查看回复中是否附带关联文档的元信息。
- 调整`quoteMaxToken`配置后，核对引用内容的长度是否符合预期。
- 切换至正式部署环境，验证引用来源的展示效果与调试页面一致。
- 测试不同类型的排污许可文档问题，确认对应文档的溯源信息准确匹配。
