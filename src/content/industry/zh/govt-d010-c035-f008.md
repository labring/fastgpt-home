# 排污许可管理的党建学习问答：文档解析与分块

## 这个品类的数据长什么样
本品类数据主要来自全国排污许可证管理信息平台、企业环保台账、在线监测系统及环境统计系统，更新频率为季度。日常处理的文档包含排污许可证申请表、执行报告、自行监测方案、台账记录、变更申请及许可证副本，文档多包含行业技术规范、许可限值、监测数据、排放边界等结构化与半结构化字段，部分台账记录为逐笔登记的流水格式。

## 这些特征在「文档解析与分块」这一环带来什么约束
季度更新的批量文档要求解析分块支持批量处理，避免单文件解析超时。不同文档类型结构差异明显，标准化申请表与多章节执行报告、零散台账记录的格式需求不同，需适配多种文档结构的分块逻辑。许可限值、排放边界等核心合规字段需精准定位，分块不能破坏字段与关联上下文的绑定，否则会影响后续党建学习问答中合规性核查的准确性。在线监测系统导出的原始数据格式多样，需兼容非标准PDF、CSV等格式的解析。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 排污许可类文档包含长文本章节与零散字段，该区间可平衡上下文完整性与分块粒度，适配党建学习问答中对合规条款、监测数据的精准召回 |
| `chunkSplitter` | 按段落+标题拆分 | 文档包含标题层级与段落结构，按此拆分可保留章节逻辑，避免将许可限值与关联规范拆分至不同分块 |
| `customPdfParse` | 开启高精度OCR模式 | 部分台账记录为扫描版PDF，高精度OCR可准确识别手写或印刷的监测数据，降低解析错误率 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 单份排污许可执行报告通常页数较多，600秒可覆盖批量文件的解析耗时，避免因超时导致解析失败 |
| `chunkSettingMode` | 手动配置 | 不同文档类型（申请表、执行报告）的分块需求差异较大，手动配置可针对性调整参数，适配党建学习问答的场景要求 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 排污许可类单份执行报告通常不超过50页，1000 MB可覆盖批量上传的最大文件需求，避免因文件过大导致上传失败 |

## 容易做错的三处
- 无法找到自定义PDF解析相关配置入口：原因是未部署对应解析插件，或FastGPT版本低于v4.17.0，需确认插件状态与版本适配情况。
- 解析扫描版排污台账时出现OCR Error报错：原因是高精度OCR模式未正确启用，或上传的扫描件分辨率不足，导致文字识别失败。
- 批量上传排污执行报告时部分文件未被解析：原因是`PARSE_FILE_TIMEOUT_SECONDS`设置过短，或文件大小超过`UPLOAD_FILE_MAX_SIZE`限制，导致解析任务被强制终止。

## 怎么确认配好了
- 上传一份标准排污许可证副本PDF，查看解析后分块的标题与正文是否保留原有层级，无内容丢失。
- 上传扫描版排污台账文件，检查解析结果中是否能正确识别监测数据字段，无乱码或缺失。
- 配置`PARSE_FILE_TIMEOUT_SECONDS`为600秒后，上传单份页数超过50页的执行报告，确认解析任务无超时报错。
- 切换`chunkSettingMode`至手动配置，调整`chunkSize`至不同区间，验证分块后的文本长度符合预期。
