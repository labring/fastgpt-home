# 排污许可管理的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
本品类的数据来源包括全国排污许可证管理信息平台、企业环保台账、在线监测系统、环境统计系统，更新频率为季度。日常涉及的文档类型涵盖排污许可证申请表、执行报告、自行监测方案、台账记录、变更申请、许可证副本，数据字段包含许可排放限值、排放口信息、监测要求、合规判定标准等，兼具结构化数值与非结构化说明内容，需适配党建学习场景下的合规问答需求。

## 这些特征在「分享与嵌入」这一环带来什么约束
数据来源分散且按季更新，因此嵌入到党建学习系统时，需配置固定的同步周期以保证数据时效性。文档包含多类结构化与非结构化内容，嵌入后的对话界面需支持按文档类型筛选召回结果，避免无关内容干扰党建学习的聚焦性。数据涉及生态环境合规相关内容，分享链接需配置基础权限校验，防止未授权访问。单条数据字段较多，上下文窗口需预留足够空间，避免召回内容超出前端展示限制，影响问答体验。

## 配置怎么定
本文基于FastGPT v4.17.0版本进行配置说明。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分享链接有效期 | 7 天 | 适配党建学习阶段性培训的周期，覆盖单次学习活动的使用需求 |
| `shareId` | 绑定专属排污许可党建知识库ID | 确保仅关联预设的合规文档与问答数据集，避免跨场景数据混淆 |
| 嵌入页面主题配色 | 匹配党建主题色调 | 适配嵌入系统的整体界面风格，强化场景辨识度 |
| 历史对话保留时长 | 30 天 | 满足党建学习的问答复盘与学习记录需求 |
| 免登录会话时长 | 24 小时 | 兼顾学习便捷性与数据访问安全 |
| 自定义对话图标 | 100×100 像素 PNG 格式 | 符合系统支持的上传规范，适配党建学习场景的视觉表达 |

## 容易做错的三处
- 现象：嵌入后页面无法加载预设的排污许可文档内容。原因：未通过`shareId`绑定正确的专属知识库，导致调用的数据集与党建问答所需的排污许可数据不匹配。
- 现象：尝试嵌入时仅获取到API接口凭证，无预制前端组件。原因：未在应用发布时选择“分享嵌入”模式，仅生成了纯API调用配置，无法直接嵌入现有系统。
- 现象：分享链接打开后历史对话记录为空。原因：未开启历史对话存储配置，或配置的保留时长过短导致记录被自动清除。

## 怎么确认配好了
- 复制生成的分享链接，在浏览器中打开，检查页面是否加载了排污许可相关的文档分类与合规问答示例。
- 发起一条包含排污许可术语的问题，确认返回结果匹配预设的知识库内容，无无关信息干扰。
- 将嵌入代码添加到目标系统的对应页面中，检查页面样式是否与嵌入环境的整体风格一致。
- 发起一次对话后关闭页面，重新打开分享链接，确认历史对话记录可正常展示。
