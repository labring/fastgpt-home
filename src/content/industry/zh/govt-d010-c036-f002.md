# 政务服务事项目录与办事指南维护的党建学习问答：向量模型与索引

## 这个品类的数据长什么样
本品类的数据主要来自国家政务服务事项基本目录、行政许可事项清单、权责清单及地方政务服务事项库，更新频率为月度。日常处理的文档包含政务服务事项基本目录、实施清单、办事指南、标准材料目录、流程图及常见问题，每个事项的文档具备标准化字段结构，涵盖事项名称、受理条件、申请材料、办理流程等固定项。

## 这些特征在「向量模型与索引」这一环带来什么约束
政务事项数据的标准化字段结构要求向量分块需保留字段关联关系，避免切割破坏受理条件、申请材料等关键业务信息；月度更新频率要求索引支持增量同步，减少全量重建的资源消耗；文档包含长文本办事指南与结构化材料清单，需适配混合格式的向量编码；党建问答场景要求召回结果严格匹配政务口径，因此需严格控制相似度阈值，避免低匹配度内容干扰问答准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配单条政务事项文档的常规文本长度，避免切割破坏受理条件、申请材料等关键字段 |
| 重叠长度 | 50–100 字符 | 保留跨块的上下文关联，确保办事流程、材料清单的表述完整 |
| 相似度阈值 | 0.75–0.85 按实测标定 | 保障召回结果符合政务口径一致性要求，平衡召回覆盖率与精准度 |
| `maxToken` | 4096 token | 适配党建问答的长上下文召回需求，覆盖跨事项关联的信息范围 |
| 重排 | 开启 | 过滤低相关性召回结果，提升党建问答的内容精准度 |
| 单次搜索上限 | 前10条 | 控制返回结果的数量，避免冗余信息干扰问答逻辑 |

## 容易做错的三处
- 现象：知识库上传包含流程图的办事指南后，图片相关的索引结果为空，或界面无图片索引模型配置选项。原因：本地部署版本未启用图片索引插件，或未正确加载对应模型依赖包。

- 现象：开启重排模型后，在线召回测试返回的结果未按相关性排序，或未过滤低匹配项。原因：重排模型的调用配置未关联到当前知识库的索引环节，或相似度阈值设置过高导致重排模型无有效输入数据。

## 怎么确认配好了
- 上传单条标准化政务办事指南文档，查看分块后的文本片段，确认未切割关键业务字段。
- 发起党建相关的政务问答测试，查看召回结果的来源文档是否为已上传的政务事项目录或指南。
- 调整相似度阈值后，观察召回结果的数量变化，确认阈值配置生效。
- 检查向量模型的调用日志，确认无连接报错或参数异常。
