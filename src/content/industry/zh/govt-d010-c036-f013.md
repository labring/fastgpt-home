# 政务服务事项目录与办事指南维护的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
数据主要来自国家政务服务事项基本目录、行政许可事项清单、权责清单及地方政务服务事项库，更新频率为月度。日常维护的文档包含政务服务事项基本目录、实施清单、办事指南、标准材料目录、流程图及常见问题，核心字段涵盖事项编码、受理条件、申请材料清单等，无固定统一的单位格式，需按事项类别匹配对应规范。

## 这些特征在「分享与嵌入」这一环带来什么约束
政务服务事项目录与办事指南的业务数据更新频率为月度，嵌入后的问答内容需定期同步最新维护的事项信息，避免出现线上线下办事口径不一致的问题。数据包含多维度业务字段，嵌入配置需限定召回范围，防止无关内容干扰问答准确性。由于数据涉及内部政务规则，嵌入场景需限制访问权限，防止非授权场景调用敏感业务内容。同时，该品类的维护工作涉及事项校验，嵌入后的回答需确保与当前最新的事项信息完全匹配，否则可能引发业务整改风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `shareId` | 对应政务服务事项知识库的专属标识 | 用于定位专属问答知识库，确保分享内容匹配当前维护的业务数据，避免跨品类调用 |
| 嵌入窗口高度 | 600–800 像素 | 适配政务文档页面的常规布局，容纳事项列表、问答交互区域，避免页面溢出影响阅读 |
| 上下文召回条数 | 前3–5条 | 政务数据字段较多，限定召回条数可避免无关内容干扰，聚焦事项编码、受理条件等核心业务字段 |
| 回答缓存时长 | 7200 秒（2小时） | 政务数据月度更新，缓存时长短于更新周期，确保嵌入内容不会长期滞后于最新维护的事项信息 |
| 鉴权模式 | 内部域名白名单 | 政务数据属于内部敏感业务内容，限制嵌入域名可防止非授权场景调用，保障业务数据安全 |

## 容易做错的三处
- 现象：嵌入后宿主页面的顶部标题被强制修改且无法恢复。原因：未关闭嵌入模板的标题覆盖配置，默认将FastGPT的页面标题同步到宿主页面。
- 现象：分享链接无身份鉴权，外部可随意访问内部政务事项数据。原因：未开启`shareId`对应的权限校验开关，直接公开分享了包含敏感业务目录的问答知识库。
- 现象：后端无法获取模型返回的回答内容。原因：未配置嵌入后的回调接口，或未正确绑定iframe的message事件监听，未接收来自FastGPT的交互数据。

## 怎么确认配好了
- 打开嵌入后的页面，输入党建相关的政务事项问题，核对返回内容匹配当前维护的最新事项目录。
- 从非授权域名访问嵌入链接，确认无法正常加载问答内容或提示权限不足。
- 查看宿主页面的标题，确认未被强制修改为FastGPT默认标题。
- 监听宿主页面的message事件，触发问答交互后，确认能接收到模型返回的回答数据。
