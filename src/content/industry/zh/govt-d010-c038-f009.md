# 政府采购项目的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
本品类的数据来源包括中国政府采购网、地方政府采购网、财政一体化系统、采购人预算系统及供应商信用记录，更新频率为每日，服务对象包括采购人单位、财政部门政府采购监管处、采购代理机构、评审专家。日常文档涵盖采购需求、采购计划、招标文件、投标文件、评标报告、中标公告、采购合同、质疑答复等，包含采购项目编号、预算金额、供应商资质要求、评标细则等标准化字段，文档结构随业务环节变化，不同环节的文档字段与格式差异明显。

## 这些特征在「模型接入与配置」这一环带来什么约束
每日更新的数据源要求模型接入配置支持增量同步与定时拉取，避免全量重复处理带来的资源浪费。多类型、字段差异明显的文档，要求配置适配不同文档的解析逻辑，避免因字段不匹配导致的问答偏差。政府采购业务的严谨性要求，模型输出需严格基于官方文档内容，不能生成无依据的表述，同时需兼容监管相关的合规性要求，不能偏离政府采购的通用规则。此外，不同业务主体的问答需求差异较大，配置需支持灵活调整问答的侧重点。

## 配置怎么定
本配置基于FastGPT v4.17.0版本的参数逻辑，针对政府采购项目的党建学习问答场景优化：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配政府采购文档的长文本上下文，避免截断采购需求、评标细则等关键内容 |
| `toolChoice` | auto | 支持模型自主判断是否需要读取上传的政府采购相关文档，匹配党建学习问答中结合文件内容作答的场景 |
| `temperature` | 0.1–0.3 | 确保问答内容严谨合规，符合政府采购官方表述风格，避免生成不符合监管要求的内容 |
| `vision` | 关闭 | 政府采购相关文档多为纯文本格式，无需视觉解析能力，可节省模型调用成本 |
| `AIPROXY_API_TOKEN` | 按平台分配的专属密钥 | 保障模型调用的身份合法性，适配政府采购场景下的安全要求 |
| `maxTokens` | 1500–2000 token | 控制单轮问答的输出长度，确保回复简洁严谨，符合采购相关说明的规范 |

## 容易做错的三处
- 现象：开启简易模式上传政府采购相关PDF后，界面显示工具调用日志为空，模型未读取文件内容或错误调用工具。原因：未将`toolChoice`配置为auto，或未在问答提示词中明确要求结合上传文档作答。
- 现象：上传3MB左右的政府采购PDF时报错，知识库索引进度停滞。原因：未调整`maxContext`适配长文本解析，或使用的模型不支持政府采购文档的复杂字段解析。
- 现象：调用VL模型时，回复内容出现不符合政府采购规范的表述。原因：混淆了普通LLM与VL模型的配置逻辑，未针对政府采购文档的文本特征调整`temperature`等参数。

## 怎么确认配好了
- 上传一份典型的政府采购招标文件，发起结合党建要求解读采购流程的问答，核对模型是否调用文件工具读取文档内容并结合内容作答。
- 上传3MB左右的政府采购相关PDF文档，检查索引进度是否在合理时间内完成，无报错提示。
- 查看模型调用日志，确认`AIPROXY_API_TOKEN`和`AIPROXY_API_ENDPOINT`配置正确，无鉴权失败或超时记录。
- 调整`temperature`参数至0.2左右，发起测试，确认回复内容的严谨性符合政府采购文档的官方表述风格。
