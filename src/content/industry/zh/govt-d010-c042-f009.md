# 法务合规与重大风险管理的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自企业合同管理系统、合规风险数据库、法律法规库、案件管理系统与举报平台。日常处理的文档包含合规风险清单、合同法律审核意见、重大事项法律意见书、合规审查表、违规举报调查报告。数据更新频率为月度，文档多为结构化表单或带审批流程的正式文书，包含风险等级、审核意见编号、关联业务事项等字段，无统一固定单位，字段与单位随文档类型变化。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散且覆盖多业务系统，需适配不同系统的接口格式完成接入，避免因格式不兼容导致数据同步失败。月度更新的数据集需定期同步，需配置稳定的增量更新流程，确保最新合规数据能及时被模型调用。文档类型多样，从结构化表单到正式意见书，需适配不同的文本拆分逻辑，避免拆分后破坏文档的语义完整性。涉及合规风险、违规线索等敏感内容，需严格控制模型调用的权限与内容范围，防止敏感信息泄露。出错后果严重，需配置可靠的错误捕获与重试机制，避免因配置失误引发合规风险或声誉损害。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配合规文档较长的上下文长度，覆盖多份关联审核文件的内容 |
| `maxTokens` | 2000–3000 token | 满足合规意见、风险报告等长文本的输出需求，避免截断关键结论 |
| `quoteMaxToken` | 1500 token | 限定引用源文档的长度，确保引用内容符合合规文档的引用规范 |
| `temperature` | 0.1–0.3 | 降低输出随机性，确保合规相关回答的严谨性与一致性 |
| `AIPROXY_API_ENDPOINT` | 按企业部署的vLLM服务地址填写 | 适配自主部署的大模型接入需求，符合企业数据不出域的合规要求 |
| `AIPROXY_API_TOKEN` | 填写企业部署的vLLM服务的访问密钥 | 完成自主部署模型的身份验证，确保接入安全 |

## 容易做错的三处
- 配置`vision`为开启后，界面无法打开图像选项。原因是该场景核心处理文本类合规文档，未配置图像输入数据源，开启后引发参数冲突。
- 本地部署vLLM模型后，模型测试返回`connector error`。原因是未正确填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或网络策略限制了FastGPT与部署节点的通信。
- 未设置合理的`maxContext`参数，导致长文档的上下文被截断。原因是未考虑合规文档的实际长度，直接使用默认参数，无法覆盖多份关联文件的内容。

## 怎么确认配好了
- 执行模型连通性测试，检查是否能正常返回合规相关的问答结果，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置有效。
- 上传一份典型的合规审查表，测试模型输出是否覆盖文档核心字段，确认`maxContext`与`maxTokens`参数适配文档长度。
- 配置月度数据同步任务，验证系统能否按计划从合规数据库拉取更新内容，确认数据源接入流程正常。
- 调整`temperature`参数至区间边界，观察输出内容的严谨性变化，确认参数生效。
