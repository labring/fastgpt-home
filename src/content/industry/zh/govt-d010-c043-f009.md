# 特种设备安全监管的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
本品类的数据主要来自特种设备安全监察系统、检验检测机构系统、使用单位台账及作业人员证书库。日常文档包含使用登记证、定期检验报告、维保记录、隐患整改通知书、事故报告、作业人员证书，各文档含设备编号、检验有效期、维保周期、作业人员资质编号等固定字段。数据更新频率为月度，需同步最新的检验结果、维保记录及人员资质变动信息。

## 这些特征在「模型接入与配置」这一环带来什么约束
本文档适用于FastGPT v4.17.0版本。本品类数据来源分散且月度更新，要求模型接入时需支持多数据源的增量同步配置，避免全量重复拉取占用资源。数据包含结构化证书、长文本报告等多种格式，需适配不同长度的上下文输入，因此`maxContext`与`maxTokens`的配置需预留足够空间。同时监管数据对准确性要求高，需严格控制生成的随机性，约束temperature的取值区间。另外，党建学习问答需结合监管政策与设备数据，需确保模型能关联两类数据的上下文。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 需容纳多份定期检验报告、维保记录的长文本上下文，覆盖党建政策与特种设备数据的关联需求 |
| `temperature` | 0.1–0.3 | 监管数据与党建问答需高准确性，降低生成的随机性，避免无关或错误内容 |
| `quoteMaxToken` | 2000–3000 token | 需完整引用隐患整改通知书、事故报告等长文档片段，确保引用内容准确完整 |
| `AIPROXY_API_ENDPOINT` | 填写对应大模型代理的服务地址 | 实现模型的安全调用与流量管控，确保平台可正常访问目标模型 |
| `AIPROXY_API_TOKEN` | 填写平台分配的认证令牌 | 验证调用权限，防止未授权访问，保障数据与模型调用的安全性 |
| `toolChoice` | auto | 自动触发知识库召回与工具调用，完成党建政策与特种设备监管数据的关联问答 |

## 容易做错的三处
- 工作流中AI模型选项为空，无法选择目标模型。原因是未正确配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，代理服务未连通，平台无法拉取可用模型列表。
- 对话时提示“模型流响应为空，请检查模型流输出是否正常”。原因是`maxTokens`配置过低，超出模型单次输出上限，或代理服务返回的响应被截断。
- 迁移知识库后对话时提示知识库为空，但页面可查看文档。原因是未重新配置模型的知识库召回关联，或增量同步未完成，模型未加载最新的特种设备数据。

## 怎么确认配好了
- 进入模型接入配置页面，检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的填写格式，发起连通性测试，确认返回可用模型列表。
- 发起测试对话，输入结合党建政策与特种设备监管的提问，检查模型是否能正确关联文档内容并生成符合要求的回答。
- 触发知识库的月度同步任务，查看同步日志，确认无报错且数据已更新至模型上下文。
- 调整`temperature`至测试区间，验证生成回答的随机性符合预期，无过度发散内容。
