# 特种设备安全监管的党建学习问答：部署与升级

## 这个品类的数据长什么样
该品类的数据覆盖特种设备全生命周期相关文档，包括使用登记证、定期检验报告、维保记录、隐患整改通知书、事故报告、作业人员证书。数据主要来自特种设备安全监察系统、检验检测机构系统、使用单位台账及作业人员证书库，更新频率为每月一次。单份文档包含设备编号、检验周期、维保单位、作业人员资质编号等结构化字段，部分文档附带PDF格式的扫描件，整体数据体量随监管设备数量动态变化。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据来源分散且更新周期固定，部署时需适配多系统对接的接口配置，避免因接口兼容性问题导致数据同步失败。月更的更新节奏要求部署时配置增量同步任务，减少全量拉取带来的资源占用。文档包含结构化编码字段与PDF扫描件，需针对性配置存储与向量处理参数，确保两类数据均可被正确检索。监管类数据的准确性要求高，部署环节需增加数据一致性校验的配置项，避免错误数据流入问答库。升级过程中需保留原有数据同步与存储配置，防止历史监管数据丢失或同步中断。

## 配置怎么定
以下配置项基于FastGPT v4.17.0版本的标准部署流程制定：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 100–200 条/分钟 | 适配特种设备数据月更的增量同步频次，避免数据库连接过载 |
| `MONGODB_URI` | 本地私有部署实例连接串 | 存储结构化监管文档与问答对话日志，符合监管数据的本地存储合规要求 |
| `REDIS_URL` | 本地Redis实例连接串，配置缓存过期时间为7200秒 | 缓存高频检索的设备资质数据，适配月更的更新节奏减少重复查询 |
| `STORAGE_S3_ENDPOINT` | 本地对象存储服务地址 | 存储PDF格式的检验报告、隐患通知书扫描件，适配多类型文档的存储需求 |
| `FE_DOMAIN` | 内网访问域名或本地IP | 适配私有化部署的内网使用场景，避免公网暴露监管数据 |

## 容易做错的三处
- 修改`config.json`后重启容器，模型列表未更新。原因是未正确挂载配置文件目录，或容器内配置文件未被应用程序读取。
- 点击知识库模块报错，返回字段为空的提示。原因是未正确配置`PG_URL`或`REDIS_URL`，导致数据库连接失败，无法加载知识库元数据。
- 问答结果中设备数据与最新台账不符。原因是未配置增量同步任务，或同步任务的更新频率设置过长，未匹配月度更新的业务节奏。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`MONGODB_URI`、`PG_URL`、`REDIS_URL`的连接状态，确认连接串配置正确。
- 手动触发一次增量同步任务，检查同步日志中是否存在设备数据、文档的成功导入记录，确认数据同步链路正常。
- 访问`FE_DOMAIN`对应的前端地址，登录系统后查看模型列表是否包含配置的接入模型，确认前端配置生效。
- 上传一份特种设备检验报告的PDF文件，确认文件可正常存储并生成向量索引，验证`STORAGE_S3_ENDPOINT`的配置有效。
