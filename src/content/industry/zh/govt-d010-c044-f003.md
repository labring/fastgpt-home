# 环境执法与监测监管的党建学习问答：多轮对话与提示词

## 这个品类的数据长什么样
本品类服务于生态环境执法支队、监测站等主体的党建学习问答场景，数据来源包括在线监控平台、污染源自动监测数据、生态环境执法系统及第三方检测报告，更新频率为每日。日常文档涵盖现场检查记录、采样记录、监测报告、责令改正决定书、行政处罚决定书，文档包含执法时间、点位、监测指标、数值、处置要求等字段，单位涉及浓度、流量、时长等，单份文档篇幅从数百到数千字符不等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
党建学习问答需结合执法业务场景开展，每日更新的高频数据要求多轮对话上下文需及时同步最新监测与执法记录，避免引用过时数据影响学习准确性。多类结构化文档的字段差异，需要提示词明确指定对应文档的检索范围，防止跨文档字段混淆导致学习偏差。现场执法类文档的非标准化表述，需要多轮对话中逐步澄清关键词，确保检索匹配准确，帮助执法人员掌握规范。单次对话需关联多份执法与监测数据，提示词需限定上下文窗口的有效数据量，避免冗余信息干扰模型输出的学习内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 单次搜索上限 | 前5条 | 党建学习问答需关联多类执法与监测文档，前5条可覆盖核心执法证据链，满足学习需求 |
| 最大上下文 | 8000–12000 token | 适配FastGPT v4.17.0的界面设置，覆盖多份执法文书与监测报告的上下文长度，避免信息截断 |
| 问题优化 | 开启 | 针对现场记录的非标准化表述与党建相关的执法规范表述，优化后可提升检索匹配精度 |
| 重排 | 开启 | 按相关性排序检索结果，确保执法证据的优先级匹配党建学习的问答需求 |
| `chatId` | 绑定会话ID | 确保多轮对话的上下文关联，避免跨会话数据混淆，维持学习会话的一致性 |
| `variables` | 预设执法场景变量 | 限定检索范围为当前执法支队的专属文档与党建学习相关的执法规范材料，缩小检索区间 |

## 容易做错的三处
- 党建学习问答中无法输出文档内的图片URL。原因：提示词未明确要求提取文档中的URL字段，或上下文未加载对应文档的完整元数据。
- 多轮党建学习对话中检索结果混入其他执法支队的文档。原因：未绑定`chatId`或未设置会话专属变量，导致跨会话数据混淆。
- 党建学习对话超时无返回。原因：单次搜索上限设置过高，同时检索多份超大数据量的执法文书，超出系统处理阈值。

## 怎么确认配好了
- 发起包含“执法规范”“党建引领”关键词的对话，检查返回结果是否包含对应执法文档的字段信息。
- 查看会话日志，确认`chatId`与当前会话绑定，无跨会话数据混入。
- 测试包含图片URL的执法文档对话，确认返回结果中包含正确的URL链接。
- 调整单次搜索上限后，验证检索结果的数量符合党建学习问答的需求。
