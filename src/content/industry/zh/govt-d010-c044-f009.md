# 环境执法与监测监管的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
本品类的数据来自在线监控平台、污染源自动监测数据、生态环境执法系统、第三方检测报告，每日更新。日常文档包含现场检查记录、采样记录、监测报告、责令改正决定书、行政处罚决定书，各文档包含专属字段，如采样记录含采样点位、检测指标与浓度数值，执法文书含执法主体、违法事实描述与处理意见，党建学习资料则包含理论要点与实践案例。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据每日更新的特性，要求模型接入时配置适配高频增量同步的逻辑，确保检索结果为最新执法与监测数据。多来源文档的格式与字段差异显著，要求模型能统一解析不同结构的文本内容。执法与党建问答的双重需求，要求模型同时支持专业执法术语与党建理论的准确调用。执法文档的严谨性要求，需限制模型的自由生成幅度，避免出现与事实不符的结论。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `temperature` | 0.1–0.3 | 执法与党建问答需保持严谨，低温度可限制模型自由生成，确保结论准确 |
| `maxContext` | 8000–12000 token | 适配多来源执法文档与党建资料的上下文长度，覆盖完整检索结果 |
| `quoteMaxToken` | 1500 字符 | 保留执法文书、监测报告等长文档的引用片段，满足溯源要求 |
| `toolChoice` | auto | 允许模型根据问题自动选择是否调用检索工具，兼顾党建理论与执法数据的调用 |
| `AIPROXY_API_ENDPOINT` | 按平台提供的专属地址填写 | 适配环境执法数据的合规传输要求 |
| `AIPROXY_API_TOKEN` | 按实测标定的权限令牌 | 确保数据访问的安全性，避免未授权调用 |

## 容易做错的三处
- 界面弹出“当前分组 default 下对于模型 gpt-4o-mini 无可用渠道”的报错，无法发起问答。原因：未在FastGPT平台配置对应模型的接入密钥或端点，或分组权限未正确分配。
- 重排序环节无法选择指定的大语言模型，配置项无对应选项。原因：未开启对应模型的插件适配，或模型未添加到平台的可用模型列表中。
- 问答结果未引用执法文档原文，仅生成泛泛结论。原因：`quoteMaxToken`配置值过小，无法保留足够的文档引用片段。

## 怎么确认配好了
使用FastGPT v4.17.0版本进行以下核对：
- 发起包含执法术语与党建内容的测试问题，检查模型是否能正确关联两类数据。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置被正确读取。
- 验证问答结果是否附带文档引用来源，确认引用片段的长度符合预期。
- 测试高频更新的执法数据，确认检索结果能同步最新的监测或执法记录。
