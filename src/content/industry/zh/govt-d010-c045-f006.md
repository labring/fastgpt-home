# 用地预审与规划许可的党建学习问答：引用来源与溯源

## 这个品类的数据长什么样
本品类的核心数据来自国土空间规划一张图、项目审批监管平台、土地利用现状库、生态保护红线数据。日常产出的文档包括用地预审与选址意见书、建设用地规划许可证、建设工程规划许可证、红线图、规划条件，文档包含项目主体、用地范围、规划管控要求、审批节点等字段。数据更新频率不定期，同步节奏随项目审批进度与国土空间规划调整变动。

## 这些特征在「引用来源与溯源」这一环带来什么约束
数据来源分散的特征要求溯源环节需关联多个官方平台的元数据，确保引用的审批文件与原始系统记录完全匹配。文档类型多样且结构不统一，需针对不同文档配置差异化的引用锚点规则，避免混淆红线图与规划条件的字段信息。数据更新不定期，需在每次问答前校验数据源的最新同步状态，防止引用过期的规划管控数据。同时，该品类出错后果直接影响项目立项，溯源环节需保留完整的引用链路，便于后续核查。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | 匹配本品类单份审批文档的平均长度，确保完整引用核心审批内容 |
| `responseData` | 开启 | 用于返回原始文档的元数据，包括文档类型、生成时间、来源平台 |
| `detail` | 完整 | 保留引用来源的完整路径，便于追溯至国土空间规划一张图或项目审批监管平台 |
| 单次搜索上限 | 前3条 | 匹配本品类单项目审批涉及的关联文档数量，避免冗余引用 |
| 上下文窗口 | 2000 字符 | 适配党建学习问答中对政策与审批依据的关联查询需求 |
| 超时阈值 | 60 秒 | 适配本品类数据源的平均响应时长，避免查询超时中断 |

## 容易做错的三处
- 配置`quoteMaxToken`时取值过小，导致引用的审批文件被截断，界面显示“引用内容不完整”报错。原因是未匹配本品类单份文档的平均长度，未预留足够的token空间承载完整的用地范围与规划指标信息。
- 未针对党建学习场景过滤冗余元数据，导致回答中出现项目审批监管平台的内部接口字段。原因是未关闭非必要的`responseData`子项，暴露了内部系统信息。
- 在工作流调用中未配置引用隐藏规则，导致回答中显示知识库搜索的input和response原始内容。原因是未设置仅展示最终答案与合规引用的规则，误保留了工具调用的中间环节信息。

## 怎么确认配好了
- 发起党建学习类的用地预审相关问题，检查回答末尾的引用列表是否包含对应文档的类型与来源平台名称。
- 查看引用内容的完整度，确认未出现截断的审批字段或红线坐标信息。
- 触发工作流调用场景，检查回答仅展示最终答案与合规引用，无工具调用的中间环节内容。
- 模拟数据源更新场景，确认问答系统能自动拉取最新的规划管控数据，无过期引用提示。
