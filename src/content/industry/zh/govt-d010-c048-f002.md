# 行政许可审批的党建学习问答：向量模型与索引

## 这个品类的数据长什么样
本品类的数据来自全国一体化政务服务平台事项库、行政许可事项清单、部门业务审批系统及电子证照库，更新频率为每日。日常文档包含党建学习相关的办事指南、申请表、承诺书、受理通知书、补正告知书、准予行政许可决定书、许可证照，各文档均带有标准化字段，如办事指南含事项编码、办理条件，申请表含申请人信息、申请事项，电子证照含证照编号、有效期等，整体为结构化与半结构化结合的政务审批专属文档，覆盖党建学习许可的全流程文书。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类数据的多来源、每日更新特性，要求索引支持增量构建与增量更新，避免全量重建带来的时间成本，适配党建学习问答的实时数据需求。文档包含标准化字段与非结构化正文，分块时需兼顾字段完整性与语义连贯性，避免拆分后丢失事项编码、办理条件等关键标识，确保党建学习相关的审批要求被准确召回。政务审批文档的法定属性要求索引召回需严格匹配党建许可的事项边界，防止跨事项的语义混淆，同时需适配不同文档类型的文本结构，保障问答的准确性。

以下配置基于FastGPT v4.17.0版本。
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配党建学习办事指南、决定书等文档的语义单元长度，避免拆分后关键审批逻辑断裂 |
| 重叠长度 | 100–150 字符 | 保留相邻分块的语义衔接，防止跨块的办理条件、依据等关键信息被割裂 |
| defaultToken | 8192 | 匹配多数政务文档的总token需求，覆盖完整的党建许可事项清单与审批流程内容 |
| maxToken | 16384 | 支持包含多份电子证照、完整党建学习办事流程的长文本索引构建 |
| 相似度阈值 | 0.75–0.85 按实测标定 | 匹配行政许可事项的严格匹配需求，过滤低相关性的跨党建许可事项文档 |
| 单次搜索上限 | 前 10 条 | 控制召回结果的数量，避免过多非核心审批文档干扰党建学习问答的准确性 |

## 容易做错的三处
- 现象：未选择系统预设的合规embedding模型时，创建党建学习知识库索引触发报错，报错文案包含“undefined model must match "^(text”。原因：未正确匹配系统支持的embedding模型命名规则，选择了未注册的模型名称。
- 现象：更换embedding模型后，已导入的党建学习知识库无法直接复用原有索引，需重新生成索引。原因：原有索引基于旧模型的向量空间构建，新模型的向量空间与旧模型不兼容，无法直接映射。
- 现象：党建学习问答的搜索结果排序不符合预期，未按与审批事项的相似度优先级展示。原因：未正确配置相似度阈值与搜索上限，或未启用基于党建许可事项匹配的重排逻辑，导致排序逻辑未按业务需求生效。

## 怎么确认配好了
- 导入单份党建学习办事指南文档，检查索引分块后的语义完整性，确认分块长度与重叠长度的配置适配文档结构。
- 更换embedding模型后，触发已有党建学习知识库的索引重建，验证无报错且生成流程正常。
- 发起党建学习相关的审批事项问答，检查召回结果的数量与排序符合业务需求，确认相关配置的适配性。
- 查看索引更新日志，确认每日增量更新任务按计划执行，匹配数据的日更新频率。
