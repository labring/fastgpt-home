# 行政许可审批的党建学习问答：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自全国一体化政务服务平台事项库、行政许可事项清单、部门业务审批系统及电子证照库，按日更新。日常文档包含办事指南、申请表、承诺书、受理通知书、补正告知书、准予行政许可决定书、许可证照等，字段涵盖事项编码、办理条件、申请材料清单、审批流程、证照有效期等，无统一单位，部分字段需严格匹配法定许可事项边界。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据按日更新的要求，要求检索环节需配置每日增量同步机制，确保召回内容与最新事项清单、审批流程一致。多类型文档的存在，需要适配不同文档结构的分块规则，避免结构化字段被拆分丢失关键信息。以法定许可事项为边界的业务要求，要求检索需按事项分组匹配，避免跨事项的无关内容被召回。电子证照库的关联需求，要求检索链路需打通系统间字段映射，确保申请材料与证照的准确核对。

## 配置怎么定
本文档基于FastGPT v4.17.0版本配置规则编写。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配行政许可事项的法定边界，需保证检索结果与事项编码、办理条件的强关联，避免低相关内容混入 |
| `limit` | 前 8 条 | 行政许可审批的申请材料需逐项匹配，单次召回过多内容会超出上下文窗口，同时保证覆盖全部必要的办理要求 |
| `searchMode` | `vector` | 行政许可事项需精准匹配设定依据和办理条件，向量检索可实现语义与关键词的双重匹配，适配行政许可事项的精准匹配需求 |
| `usingReRank` | 开启 | 多类型文档的召回结果需二次排序，确保最相关的办事指南、审批决定书等核心文档排在前列 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可通过扩展用户问题，补充法定许可事项的关键词，提升对专业术语的匹配精度 |
| `collectionIds` | 按行政许可事项分组配置 | 匹配业务中以法定许可事项为边界的要求，确保检索仅针对对应事项的文档集合 |

## 容易做错的三处
- 检索时提示“当前分组 default 下对于模型 gpt-4o-mini 无可用渠道”，原因是未按行政许可事项配置专属`collectionIds`，使用了默认分组且未绑定对应模型渠道。
- 配置变量引用知识库时未明确参数，导致检索无法精准匹配对应事项的文档集合，原因是未参考事项库的字段映射规则配置检索范围。
- 知识库内的电子证照图片链接在回复中显示为“input an image”，原因是未开启文档扩展检索的图片渲染配置，或未正确映射证照库的图片存储路径。

## 怎么确认配好了
- 执行单次检索测试，输入对应行政许可事项的关键词，检查召回结果是否仅包含该事项对应的文档，无跨事项内容。
- 查看系统日志，确认每日增量同步任务正常执行，无数据更新失败的报错记录。
- 测试变量引用知识库的配置，输入对应事项的编码，验证检索结果是否自动匹配该事项的文档集合。
- 上传测试用的办事指南文档，检索后确认返回结果包含文档内的办理条件、申请材料清单等核心内容。
