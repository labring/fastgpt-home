# 行政许可审批的党建学习问答：表单与交互

本文基于 FastGPT v4.17.0 版本编写。

## 这个品类的数据长什么样
本场景下的党建学习问答围绕行政许可审批业务展开，数据来源于全国一体化政务服务平台事项库、行政许可事项清单、部门业务审批系统及电子证照库，每日更新。日常文档包含办事指南、申请表、承诺书、受理通知书、补正告知书、准予行政许可决定书、许可证照，同时涵盖党建相关的政务政策文件，字段涵盖事项编码、申请主体资质、提交材料明细、法定办理条件、党建政策要点等，所有字段均遵循政务服务标准化格式，无自定义单位。

## 这些特征在「表单与交互」这一环带来什么约束
本场景下的党建学习问答结合行政许可审批业务，数据标准化程度高且每日更新，要求表单字段必须严格匹配政务服务事项库的法定字段与党建政策要点，不得随意增减或自定义非标准化项。多类审批文档与党建政策文件的存在，要求表单支持分模块录入不同申请材料与学习内容，同时关联电子证照调取接口以自动填充合规信息。法定办理条件与党建政策的明确性，要求交互环节实时校验提交内容与两者的匹配度，避免因信息不符导致后续流程出错。同时，数据来源分散于多个系统，表单需支持跨系统数据联动，减少人工录入成本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 表单输入组件 | 启用多字段分组，按审批材料与党建学习模块拆分 | 匹配日常文档的分类结构，降低录入与学习的复杂度 |
| `formInput` | 配置必填项校验，错误提示文案为「请填写完整的申请或学习信息」 | 确保提交内容符合法定表单与党建问答的要求，避免无效提交 |
| `userSelect` | 预设官方政务事项清单与党建政策分类选项，禁止手动输入 | 严格匹配事项库与政策库的标准化内容，防止非法定或非合规内容录入 |
| 单次搜索上限 | 前5条 | 匹配行政许可审批的材料核对与党建问答的精准检索需求，避免冗余结果干扰 |
| 上下文调用上限 | 800–1200 字符 | 适配审批文档与党建政策文件的长度，保证检索结果覆盖完整办理条件与政策要点 |
| 校验超时时间 | 600 秒 | 避免因系统响应延迟导致表单提交卡顿，符合政务服务的时效要求 |
| 文件上传大小限制 | 1000 MB | 适配政务类文档与党建学习资料的存储要求，避免大文件上传失败 |

## 容易做错的三处
- 现象：`formInput`绑定的变量字段提交后为空，原因：未配置变量映射规则，未关联政务事项库或党建政策库的动态数据源。
- 现象：表单输入框无法上传电子证照或党建学习资料文件，提交时返回格式错误，原因：未开启文件上传组件的政务与党建文档格式校验，未关联电子证照库的自动校验逻辑。
- 现象：切换审批事项类型或党建政策分类后，未自动切换对应知识库的检索范围，仅能通过手动配置判断器实现，原因：未将`userSelect`组件的选中值与知识库关联规则绑定，依赖全局检索导致结果不匹配。

## 怎么确认配好了
- 打开表单预览页面，选择任意法定行政许可事项或党建政策分类，核对表单字段是否与对应内容的标准格式一致。
- 提交测试申请，检查是否能自动关联对应事项的知识库内容，检索结果是否包含办理条件与党建政策要点。
- 上传政务类文档或党建学习资料，检查是否触发格式校验并提示正确的错误信息。
- 切换`userSelect`组件的选项，确认知识库检索范围自动更新，无需手动调整配置。
