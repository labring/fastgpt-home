# 行政许可审批的党建学习问答：分享与嵌入

本文基于 FastGPT v4.17.0 版本编写。

## 这个品类的数据长什么样
行政许可审批场景下的党建学习问答数据，来源包括全国一体化政务服务平台事项库、行政许可事项清单、部门业务审批系统与电子证照库，更新频率为每日。日常涉及的文档涵盖办事指南、申请表、承诺书、受理通知书、补正告知书、准予行政许可决定书与许可证照等，数据字段包含事项名称、设定依据、办理条件、申请材料要求、审批流程与结果信息等，无额外自定义统计类字段。

## 这些特征在「分享与嵌入」这一环带来什么约束
行政许可事项数量较多且每日更新，要求分享与嵌入的内容需实时同步最新数据，无法依赖静态缓存。文档类型跨度大，既有数百字符的补正告知书，也有数千字符的办事指南，嵌入界面需适配不同长度的内容展示。数据关联法定审批流程，分享链接与嵌入页面需严格管控访问权限，防止未授权获取内部审批文档。同时，单场景下需覆盖多事项的党建学习问答，对免登录分享链接的数量有较高需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 免登录分享链接数量 | 10–100 个，按团队订阅套餐权限调整 | 行政许可事项覆盖范围广，单政务服务中心或审批处室需创建多个对应党建问答的分享链接 |
| iframe界面语言 | 简体中文 | 面向国内政务人员与企业办事人员，符合日常使用习惯 |
| `shareId`生成规则 | 按行政许可事项编码生成唯一值 | 确保每个事项的党建问答分享链接对应唯一标识，便于权限管控与数据关联 |
| 分享内容缓存时长 | 15–60 分钟，按实测标定 | 平衡数据实时性与访问性能，适配每日更新的事项与证照数据 |
| 嵌入页面沙箱配置 | 允许表单提交、禁止脚本执行 | 保障嵌入场景的安全性，防止恶意操作与数据篡改 |
| 分享链接鉴权开关 | 开启 | 行政许可相关数据为法定公开内容，但需管控内部文档的访问范围 |

## 容易做错的三处
- 现象：嵌入的问答界面显示英文文案。原因：未在嵌入配置中指定界面语言为简体中文，默认加载英文本地化文件。
- 现象：创建第11个免登录分享链接时提示超出限额。原因：未调整团队订阅套餐内的免登录分享链接数量限制，默认限额为10个。
- 现象：分享链接打开后无法加载最新的行政许可事项数据。原因：分享内容缓存时长设置过长，未同步每日更新的事项清单与证照信息。

## 怎么确认配好了
- 尝试创建15个免登录分享链接，确认无限额报错提示。
- 在嵌入代码中指定简体中文语言参数，打开嵌入页面确认界面文字为简体中文。
- 手动更新一条关联的行政许可事项数据，等待缓存过期后刷新分享页面，确认内容已同步更新。
- 检查iframe嵌入的沙箱配置，尝试在嵌入页面提交测试表单，确认无异常拦截。
