# 财政支出绩效评价的党建学习问答：知识库检索与召回

## 这个品类的数据长什么样
本品类用于党建学习问答的财政支出绩效评价相关数据，来自预算管理一体化系统、项目申报材料、资金支付数据、业务台账及满意度调查，更新频率为年。日常文档包含绩效目标表、自评表、绩效评价报告、佐证材料清单、整改报告，部分文档还会关联党建与业务融合的绩效指标内容，数据字段多涉及项目编号、资金额度、绩效指标完成情况、整改措施等，无固定统一单位，需结合具体项目场景匹配信息关联关系。

## 这些特征在「知识库检索与召回」这一环带来什么约束
年更新频率决定无需高频增量索引，但单次索引数据量较大，需适配批量索引流程。多类型文档结构差异显著，需确保检索环节兼容不同格式的文本解析结果。数据字段包含项目编号、资金额度、绩效指标完成情况等，检索需精准匹配项目关联信息，避免无关结果干扰。党建学习问答场景下还需确保结果覆盖政策与业务融合内容，因此语义匹配的精度要求更高。同时需关联佐证材料与绩效报告的关联内容，召回环节需支持跨文档关联检索，确保覆盖完整绩效评价链路的信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.72–0.80 | 匹配绩效评价类文本的精准度需求，避免过低导致无关结果，过高遗漏相关佐证材料 |
| `limit` | 前10–15 条 | 覆盖单项目绩效评价所需的自评、报告、佐证等多类文档，避免召回量过少导致信息不全 |
| `searchMode` | 语义搜索 | 适配绩效指标、整改措施等非结构化文本的语义匹配需求，满足党建学习问答的政策与业务结合场景 |
| `usingReRank` | 开启 | 对初始召回结果进行二次排序，修正语义匹配的偏差，突出与绩效目标关联度更高的内容 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户问题自动扩展相关绩效评价关键词，补充项目编号、资金类别等隐藏关联信息 |
| `collectionIds` | 绩效评价专属数据集ID | 限定检索范围在财政支出绩效评价相关文档集合内，避免混入其他品类数据 |

## 容易做错的三处
- 现象：搜索后返回结果条数远低于`limit`配置的取值，或无相关结果。原因：`similarity`阈值设置过高，过滤掉了与绩效目标关联度较弱但仍相关的佐证材料。
- 现象：检索结果混入非绩效评价类文档，如预算编制材料。原因：`collectionIds`未限定为绩效评价专属数据集，检索范围覆盖了其他品类的文档集合。
- 现象：搜索结果未关联项目佐证材料，仅返回绩效自评表内容。原因：未开启`datasetSearchUsingExtensionQuery`，未自动扩展项目编号、资金类别等关联关键词，无法覆盖跨文档的关联信息。

## 怎么确认配好了
- 进入FastGPT v4.17.0的知识库管理页面，查看`collectionIds`是否已绑定绩效评价专属数据集。
- 发起一条测试问题，如“某项目的绩效自评与党建融合情况”，检查返回结果的条数是否符合`limit`配置的取值。
- 查看检索结果的排序，确认高关联度的绩效评价报告、佐证材料排在前列，验证`usingReRank`是否生效。
- 测试扩展查询功能，输入仅包含项目名称的问题，确认系统自动补充了绩效指标、资金额度等相关关键词。
