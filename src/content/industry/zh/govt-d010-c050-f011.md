# 财政支出绩效评价的党建学习问答：表单与交互

## 这个品类的数据长什么样
本品类涉及的主体包括财政局绩效处、预算单位、第三方评价机构及主管部门。日常产生的文档包含绩效目标表、自评表、绩效评价报告、佐证材料清单、整改报告。数据来源于预算管理一体化系统、项目申报材料、资金支付数据、业务系统台账及满意度调查，更新频率为年。最耗时的环节为收集项目产出和效果佐证、核验资金支出与绩效目标的对应关系、撰写问题及整改建议。出错后果包括项目评分偏低、预算压减、整改被跟踪或问责。与审计类品类的差别在于，本品类聚焦财政资金使用的绩效目标与效果证据，不涉及资金合规性核查。

## 这些特征在「表单与交互」这一环带来什么约束
年更新频率决定表单无需高频同步实时数据，可采用离线批量上传的交互方式。多类型文档的存在要求表单支持差异化字段映射，适配绩效目标表、自评表等不同格式的文件。收集佐证材料的高耗时环节，需要表单支持多文件批量上传及标签分类功能，减少人工整理成本。核验资金与绩效目标的对应关系，要求表单内置字段关联校验规则，避免数据不匹配的情况。严格的出错后果要求表单设置必填项校验与数据一致性检查，降低人工失误概率。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 单字段最大输入 800–1200 字符 | 匹配绩效评价报告的常规单段落篇幅 |
| `userSelect` | 选项上限 20 条 | 覆盖财政局、预算单位、第三方机构等所有业务主体角色 |
| 文档上传限制 | 单文件最大 100 MB，支持格式为 PDF、Excel、Word | 适配绩效评价报告、佐证材料等常见文档类型 |
| 校验规则触发时机 | 表单提交前 600 秒内完成全量校验 | 避免长时间等待导致的用户流失 |
| 工具调用权限 | 仅开放内部数据源访问，禁用公网搜索 | 符合财政数据的保密要求 |
| 结果展示条数 | 前 5 条匹配结果优先展示 | 聚焦核心绩效指标的关联数据 |

## 容易做错的三处
- 部署关联的钉钉机器人时，界面返回“消息接收地址校验失败”报错。原因是未配置公网可访问的服务地址，或未正确开放对应端口，导致平台无法接收机器人回调消息。
- 提交表单后部分字段为空，无法生成对应绩效评价内容。原因是未将`formInput`组件与后台数据字段正确绑定，导致输入内容未被采集。
- 使用第三方模型接口时出现参数解析错误，无法正常调用模型工具。原因是未匹配模型要求的输入格式，或未正确配置工具调用的权限范围。

## 怎么确认配好了
- 上传一份标准绩效目标表，检查表单是否自动识别对应字段并完成初步映射。
- 触发`userSelect`组件，确认可选择的角色选项覆盖财政局、预算单位等所有业务主体类型。
- 提交测试数据，检查是否触发符合配置的校验规则并返回清晰提示。
- 调用配置的模型工具，确认可正常访问内部数据源并返回关联的绩效数据。
