# 部门决算与财务报告的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
本品类的数据来自预算管理一体化系统、国库集中支付系统、会计核算系统、资产管理系统，更新周期为年度。日常产出的文档包含部门决算报表、资产负债表、收入支出决算表、决算说明、政府财务报告，文档结构以结构化表格搭配文字说明为主，字段涵盖收支明细、资产负债余额、预算执行差异说明等财政专用字段，单位多为元、万元等通用财政计量标准，无额外非业务类字段。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类年度更新的低频批量数据特征，要求模型接入配置适配单次大段文本输入，需限制上下文长度避免溢出。结构化报表与文字说明混合的文档结构，要求配置开启模型的表格识别与字段关联能力，确保对收支明细、差异说明的准确理解。多系统来源的数据需统一格式，配置环节需明确数据解析的字段映射规则，避免因字段不匹配导致问答偏差。同时因出错后果严重，需严格配置引用校验环节，确保生成内容与原始数据的一致性，避免出现账实不符或口径错误的问题。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配年度决算文档的大段文本输入，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 限制单轮问答输出长度，确保党建学习问答内容聚焦且合规 |
| `quoteMaxToken` | 1500 token | 限制引用原始文档的长度，确保生成内容与原始数据匹配，避免冗余引用 |
| `temperature` | 0.1–0.3 | 降低生成随机性，确保财政数据与党建内容结合时的准确性 |
| `AIPROXY_API_TOKEN` | 按部署环境填写有效密钥 | 确保模型调用的身份验证通过，避免访问被拒绝 |
| `toolChoice` | auto | 自动选择合适的工具处理结构化报表与文字说明，提升问答准确性 |

## 容易做错的三处
- 现象：上传部门决算的Word文档后，模型生成内容为空。原因：未开启文档解析的结构化表格识别配置，导致报表字段无法被正确提取。
- 现象：对话回复中携带大量#、*等非必要标点符号。原因：未关闭对话界面的Markdown自动渲染开关，导致文档内的格式标记被直接输出。
- 现象：模型调用返回超时错误。原因：未调整`maxContext`参数适配年度批量文档的长度，超出模型上下文承载上限。

## 怎么确认配好了
- 上传单份部门决算报表文档，发起包含收支明细查询的问题，检查生成内容是否准确匹配文档内的字段信息。
- 发起包含党建学习相关的问答，检查回复是否未携带无关的格式标点符号。
- 发起多轮连续问答，检查模型调用是否无超时错误，上下文关联是否正常。
- 核对`AIPROXY_API_TOKEN`与`AIPROXY_API_ENDPOINT`的配置，确认模型调用可正常返回结果。
