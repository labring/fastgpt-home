# 部门预算编制的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
该品类的日常文档包含部门预算草案、项目申报书、绩效目标表、人员经费测算表、预算批复等，同时包含党建学习相关的预算配套参考文档，数据来自预算管理一体化系统、部门人员编制系统、以前年度决算、项目库及财政部预算编制通知。数据更新频率为年度，文档多包含预算金额、人员编制数、项目绩效指标等字段，单位涉及万元、人、项目个数等，内容多为年度资金申报与安排相关的结构化与半结构化数据。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 覆盖年度预算相关的多文档上下文，避免截断关键的预算申报与绩效数据 |
| `quoteMaxToken` | `2000–3000 token` | 确保引用的预算文档片段完整，满足财政审核的溯源要求 |
| `temperature` | `0.1–0.3` | 适配预算编制内容的严谨性需求，降低模型输出的随机性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写实际代理地址 | 适配FastGPT的代理接入规则，确保模型调用链路正常 |
| `AIPROXY_API_TOKEN` | 与代理服务匹配的密钥 | 完成模型调用的身份验证，保障接入安全 |
| `vision` | 开启 | 支持解析预算表格、绩效目标表等多模态文档，提升内容提取准确性 |

## 容易做错的三处
- 现象：使用OneAPI转发模型请求时，出现参数校验失败报错。原因：未按FastGPT要求传递`maxContext`等配置项，参数格式与模型要求不匹配。
- 现象：无法查看模型调用的参数日志，无法追溯请求细节。原因：未开启请求日志记录的相关配置，或日志存储路径未正确配置。
- 现象：接入百度系模型时出现兼容性报错，无法正常调用。原因：未通过适配的代理服务转发请求，未正确配置模型接入的专属参数。

## 怎么确认配好了
- 发起一次预算文档的问答测试，检查模型输出是否关联了正确的原始文档片段，确认引用配置生效。
- 查看模型调用日志，确认包含完整的请求参数与返回结果，验证日志记录配置正常。
- 提交包含预算表格的测试文档，检查模型解析结果是否准确，确认`vision`配置是否正常生效。
- 调整`temperature`参数取值，对比不同取值下的模型输出严谨性，确认参数配置效果符合需求。
