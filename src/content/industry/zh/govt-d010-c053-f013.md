# 部门预算编制的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
本品类的数据主要来自预算管理一体化系统、部门人员编制系统、以前年度决算、项目库及财政部预算编制通知，更新频率为年度。日常处理的文档包括部门预算草案、项目申报书、绩效目标表、人员经费测算表、预算批复等，数据字段涉及项目编码、经费额度、人员编制数、绩效指标等，单位涵盖万元、人数、项目周期等，所有数据均为财政管理相关的内部业务内容。

## 这些特征在「分享与嵌入」这一环带来什么约束
由于本品类数据按年度更新，嵌入后的知识库需定期同步最新的预算编制通知、当年项目库数据，否则问答结果会使用过时信息。日常文档多为结构化的预算相关文件，分享与嵌入时需精准关联对应部门的预算知识库节点，避免混入非预算类党建学习内容。数据来源多为内部财政系统，嵌入配置需匹配内部权限规则，确保仅授权人员可访问关联预算数据的党建问答内容，同时需避免敏感预算字段被无权限用户获取。

以下配置基于FastGPT v4.17.0版本，其中`shareId`为关联问答应用的唯一标识，需确保`shareId`与部署的应用实例完全匹配。
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分享链接权限 | 内部组织可见 | 本品类数据涉及财政预算敏感信息，需限制非授权访问 |
| 知识库绑定范围 | 绑定对应部门的预算编制党建知识库 | 确保问答仅调用本品类的预算文档与党建学习内容 |
| 全局语言设置 | 按使用场景匹配，如中文/英文 | 适配不同使用人员的语言习惯 |
| 上下文长度 | 800–1200 字符 | 匹配预算文档的单块内容长度，避免截断关键字段 |
| 接口超时时间 | 600 秒 | 给足预算数据查询与党建内容整合的处理时间 |
| `shareId` | 绑定对应部署的问答应用ID | 精准关联指定的部门预算编制党建问答场景 |

## 容易做错的三处
- 嵌入页面的显示语言与预设配置不符，原因是未在分享配置中正确设置全局语言参数。
- 免登录分享链接中自定义变量无法正常显示，原因是未将自定义变量配置为允许在分享场景下传递。
- 问答返回的预算数据为上一年度内容，原因是未按年度更新频率同步绑定的知识库数据。

## 怎么确认配好了
- 打开分享嵌入的页面，检查显示语言是否符合预设的全局语言设置。
- 生成免登录分享链接，传入预设的自定义变量，验证变量是否正常显示。
- 发起包含预算编制相关内容的党建问答，验证返回结果使用的是当前年度的预算文档数据。
- 尝试使用非授权账号访问分享链接，确认无法正常获取问答内容。
