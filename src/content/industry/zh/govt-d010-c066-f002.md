# 化工新材料的党建学习问答：向量模型与索引

## 这个品类的数据长什么样
化工新材料领域的党建学习数据主要来自企业内部党建管理系统、上级党委下发的正式文件、支部党课课件及党员学习台账。数据更新随上级党建任务节点触发，日常党课记录每周归档，正式文件在收到后24小时内同步入库。文档结构包含标题、正文、发布日期、所属支部、关联党建主题字段，其中正文多为长段落格式，部分包含内嵌的政策条款与学习要求，无统一的固定章节划分。

## 这些特征在「向量模型与索引」这一环带来什么约束
长段落为主的正文结构要求分块时需兼顾党建主题的完整性，避免将政策条款拆分至不同块中。关联党建主题的元数据字段可用于构建过滤索引，缩小检索范围，但需匹配向量模型的元数据支持能力。每周归档的日常党课记录与每日同步的正式文件，要求索引支持增量更新模式，避免全量重建带来的资源占用。无固定章节划分的文档，无法通过章节标题直接定位学习内容，需依赖向量相似度匹配完成精准召回。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，适配化工新材料党建学习场景的向量模型与索引环节。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 匹配化工新材料党建文档的长段落结构，避免拆分政策条款 |
| 重叠长度 | 100–150 字符 | 保留相邻块的上下文关联，确保长段落的主题连贯性 |
| `defaultToken` | 8192 token | 适配主流嵌入模型的输入上限，满足长文档分块后的向量生成需求 |
| 相似度阈值 | 0.72–0.80 按实测标定 | 过滤低相关的党建内容，避免无关学习资料被召回 |
| 单次搜索上限 | 前 8 条 | 控制检索结果数量，适配党建问答的精准性要求 |
| `maxToken` | 16384 token | 限制单轮问答的上下文总长度，避免超出模型处理能力 |

## 容易做错的三处
- 出现503状态码，提示对应模型无可用渠道。原因是未正确配置嵌入模型的渠道参数，导致向量模型调用链路中断。
- 检索结果条数与预期不符，出现大量无关内容。原因是相似度阈值设置过低，未过滤低相关的党建文档。
- 启动服务后无法加载配置的API密钥。原因是未在docker-compose.yml中声明环境变量，或未重建容器使配置生效。

## 怎么确认配好了
- 上传一篇典型的化工新材料党建文档，检查分块后的内容是否保留了完整的政策条款，无强制拆分。
- 发起一条党建相关的测试提问，查看检索结果的条数是否符合单次搜索上限的设置。
- 查看向量模型调用日志，确认`defaultToken`和`maxToken`的取值未超出模型支持范围。
- 手动修改相似度阈值，验证检索结果的相关性是否随阈值调整发生变化。
