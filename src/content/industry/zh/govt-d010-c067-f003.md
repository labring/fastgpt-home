# 化肥农药的党建学习问答：多轮对话与提示词

## 这个品类的数据长什么样
化肥农药行业党建学习数据主要来源于所属国央企化工板块的党建档案库、农业农村部相关政策汇编、行业党委统一配发的学习材料。更新频率为月度更新行业监管政策文件、季度更新党委集中学习课件。文档结构包含政策条款、学习要点、配套问答题目，字段包含发布主体、生效时段、适用品类、核心要求，涉及章节编号、题号等单位标识。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
数据中包含不同化肥农药品类的专属适用要求，多轮对话需要持续跟踪用户提及的具体品类，避免跨品类的政策混淆。月度更新的政策文件要求定期同步知识库，提示词需加入最新政策的生效时段校验，确保对话内容符合当前有效要求。结构化的问答题库需要在多轮对话中匹配上下文的品类，精准调取对应题目，长文本政策内容需在提示词中限定关联范围，避免无关片段干扰回答准确性。

## 配置怎么定
本配置方案基于FastGPT v4.17.0版本，针对化肥农药党建学习场景的多轮对话与提示词环节设置如下：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 变量配置 `variables` | 预设当前会话的化肥/农药品类 | 确保多轮对话始终关联对应品类的党建学习内容 |
| 历史消息 `messages` 轮次限制 | 前 8–12 轮 | 避免过长上下文导致的信息过载，适配党建问答的常规对话长度 |
| 会话标识 `chatId` 绑定规则 | 绑定企业党建账号唯一标识 | 实现单账号会话的权限隔离与台账关联 |
| 对话记录保存时长 | 30–90 天 | 符合国央企党建资料留存的常规周期 |
| 知识库权限范围 | 仅开放化肥农药行业党建资料 | 匹配品类专属的学习数据边界 |
| 上下文窗口上限 | 8000–12000 token | 适配长文本政策文档的读取需求 |

## 容易做错的三处
- 现象：对话记录保存时长设置超出范围后，页面提示“会话存储异常”。原因：未匹配化肥农药党建场景的留存周期，误设置为180天以上超出平台默认存储上限。
- 现象：调用知识库时返回无关的医药党建资料。原因：未配置品类专属的知识库权限范围，未限定仅调取化肥农药行业的党建数据。
- 现象：执行长文本政策解读任务时，控制台报错“The value of 'offset' is out of range”。原因：未限制长文本分块的上下文关联范围，导致分块偏移超出文档实际长度。

## 怎么确认配好了
- 发起会话并指定具体化肥或农药品类（如尿素、除草剂），检查返回的党建学习内容仅包含对应品类的政策与问答。
- 查看会话历史列表，确认超过30天的旧会话未被自动清理，符合预设的保存时长。
- 调用`variables`预设字段，验证会话中自动绑定当前提及的品类参数。
- 测试长文本政策解析任务，确认无偏移报错且返回内容完整覆盖指定文档片段。
