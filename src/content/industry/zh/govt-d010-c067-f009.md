# 化肥农药的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
化肥农药所属国央企化工板块的党建学习数据，来源为党群工作部归档的内部学习材料、行业党建结合生产的专项文件。数据随党群工作部署定期更新，文档多为段落式长文本，部分包含结构化条目，字段包含发布主体、生效日期、核心论述，单位多为“章节”“条目”。

## 这些特征在「模型接入与配置」这一环带来什么约束
党建学习材料多为长段落文本，部分包含结构化条目，会对上下文窗口设置提出明确要求。部分文档包含跨章节的关联论述，需要调整召回匹配的关联逻辑。定期更新的行业专项党建文件，需要匹配固定的同步周期，避免数据滞后。化肥农药领域的党建内容需严格匹配行业政策表述，对模型输出的一致性有更高要求。

## 配置怎么定
本配置基于FastGPT v4.17.0版本的参数逻辑制定，具体如下：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配化肥农药党建长文本学习材料的上下文召回需求，避免截断核心关联内容 |
| `maxTokens` | 1500–2000 token | 匹配党建问答的回答长度需求，保证覆盖完整的政策解读或学习要点 |
| `quoteMaxToken` | 2000–3000 token | 限制单条引用文档的长度，避免单条引用占用过多上下文空间 |
| `temperature` | 0.1–0.3 | 保证党建问答输出的表述一致性，符合官方政策的严谨性要求 |
| `toolChoice` | auto | 按需调用知识库召回工具，适配党建问答的精准匹配需求 |
| `AIPROXY_API_TOKEN` | 与代理服务绑定的有效令牌 | 保证模型调用的身份合法性，避免未授权访问 |

## 容易做错的三处
- 出现`Unexpected end of JSON input`报错。原因是未正确配置`AIPROXY_API_TOKEN`或代理地址，导致模型请求返回不完整的JSON格式响应。
- 长文本问答时出现答非所问的情况。原因是`maxContext`设置过小，无法召回足够的关联上下文内容，导致模型缺乏足够的参考依据。
- 上传QA格式的知识库文件后，模型输出不符合预设格式。原因是未开启`toolChoice`的精准匹配配置，导致模型未严格按照知识库中的QA条目进行输出。

## 怎么确认配好了
- 发起党建学习相关的长文本问答测试，核对模型返回的内容是否包含知识库中对应的政策条文或学习要点。
- 查看模型调用日志，确认`maxContext`和`maxTokens`的实际使用值符合预设配置，无异常截断情况。
- 模拟未授权的API请求，确认返回结果为身份验证失败，验证`AIPROXY_API_TOKEN`的配置有效性。
- 上传测试用的QA格式文件，发起对应问题的问答，核对模型输出是否严格匹配知识库中的预设答案。
