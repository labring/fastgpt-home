# 危化品储运的党建学习问答：部署与升级

## 这个品类的数据长什么样
数据主要来自企业内部党建管理系统的制度文本、储运班组月度学习记录、危化品储运安全相关的党建宣讲材料。更新节奏为每月同步一次企业内部党建库，单次更新文档量随党建活动开展调整。文档结构多为段落式长文本，附带字段包括所属支部、学习主题、发布日期、储运岗位适配标签，文档单位以篇、次为统计维度。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据包含岗位适配标签，部署时需要配置岗位权限过滤规则，确保仅储运岗位人员可访问对应党建内容；长文本占比高，升级时需要保留合理的分块与索引配置，避免解析失败；每月增量更新的需求，要求部署时配置增量同步脚本，升级过程中不能破坏同步逻辑；文档存储涉及企业内部合规要求，需要使用私有存储路径，不能使用公共存储服务。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `DB_MAX_LINK` | 800 | 适配危化品储运党建长文档的内部链接关联，避免单条数据链接超限 |
| `FILE_TOKEN_KEY` | 64位加密字符串 | 用于加密知识库文件访问密钥，符合国企数据安全合规要求 |
| `STORAGE_S3_ENDPOINT` | 企业私有对象存储节点地址 | 存储危化品储运党建相关的文档附件，保障数据不对外泄露 |
| `REDIS_URL` | 本地高可用Redis实例地址 | 缓存党建问答的检索结果，提升响应速度 |
| `ROOT_KEY` | 企业内部管理员专属密钥 | 限制仅授权人员可管理党建知识库 |

## 容易做错的三处
- 升级后点击知识库文件详情显示“Invalid dataset file key ”：原因是升级过程中未同步更新`FILE_TOKEN_KEY`配置，导致原有文件密钥无法被解密验证。
- 未配置非商业版本API密钥的时长与使用次数限制：原因是部署时未开启密钥管控相关配置，导致党建问答接口存在滥用风险。
