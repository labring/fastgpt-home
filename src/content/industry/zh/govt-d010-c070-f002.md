# 发电装备制造的党建学习问答：向量模型与索引

## 这个品类的数据长什么样
发电装备制造企业的党建学习数据主要来自内部党建台账、三会一课记录、月度标准化学习资料、党员活动档案及生产一线融合党建材料。数据更新节奏分为实时更新的临时党建通知、月度更新的学习文稿、季度更新的党员考核与活动总结文档。文档结构包含纯文本学习材料、带参与人次、完成时长字段的活动记录表，以及带考核得分单位为分的党员绩效关联文档。

## 这些特征在「向量模型与索引」这一环带来什么约束
实时更新的临时党建通知要求支持高频增量索引，避免全量重建占用过多系统资源。带参与人次、完成时长的活动记录表，以及带考核得分的文档，需要适配结构化数据的向量处理，避免分块时丢失表格内的字段关联。生产结合的党建材料包含设备编号、生产批次等专业字段，需保留原始单位与语义，防止向量编码出现语义偏差。长文本党课材料需要合理拆分，避免单块内容超出向量模型的token承载上限。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配党建学习材料的单块语义完整性，避免过长导致向量编码偏差，过短破坏上下文关联 |
| 重叠长度 | 100–150 字符 | 保留相邻分块的语义衔接，防止跨块的党建知识点被拆分断裂 |
| `maxToken` | 8192 | 匹配主流嵌入模型的最大token限制，适配长文本党课材料的分块要求 |
| 单次搜索上限 | 前 8 条 | 平衡党建问答的召回覆盖度与响应速度，避免过多无关结果干扰答案准确性 |
| 重排 | 启用 | 对召回的党建学习材料进行语义排序，优先匹配用户提问的核心知识点 |
| `defaultToken` | 4096 | 配置默认的单轮对话上下文token上限，适配党建问答的常规对话长度 |

## 容易做错的三处
- 点击启用嵌入模型后填写自定义请求地址与API密钥，测试直接报错。原因是未匹配发电装备制造党建数据的字段格式，或自定义请求地址未正确指向嵌入模型的合规接口。
- 刷新页面后提示“检测到没有可用的索引模型”。原因是未在知识库设置中关联当前党建知识库与已配置的嵌入模型，或模型配置未保存生效。
- 无法为表格数据开启多向量支持。原因是未开启知识库的结构化数据解析开关，或未针对表格中的人次、得分等字段单独配置向量提取规则。

## 怎么确认配好了
- 进入FastGPT v4.17.0版本的知识库向量模型配置页面，确认已选择的嵌入模型与自定义请求地址、API密钥匹配，点击测试按钮无报错。
- 上传一份党建活动表格文档，查看解析后的数据是否保留了参与人次、完成时长等原始字段与单位。
- 新建测试对话，输入党建相关提问，查看召回结果的条数符合单次搜索上限的配置。
- 查看知识库的索引状态面板，确认索引任务已完成且无失败日志。
