# 发电装备制造的党建学习问答：多轮对话与提示词

## 这个品类的数据长什么样
数据来源为发电装备制造企业内部党建管理系统、党委办公室下发的正式文件、行业党建共建共享文档库。更新节奏为每月同步一次最新学习主题与政策解读文档。文档以结构化章节呈现，包含主题标题、正文段落、附件链接，字段包含发布单位、发布日期、适用支部范围，单篇文档字符数多在5000至15000字符区间。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
单篇文档字符数较高，多轮对话的上下文拼接时需避免超出模型支持的长度限制，需通过`messages`参数精准截取有效历史对话，避免冗余内容占用上下文窗口。数据每月更新一次，提示词需配置与更新周期匹配的文档库同步逻辑，避免调用过时的党建学习内容。文档包含适用支部范围字段，需通过`variables`传入当前对话所属支部信息，过滤非适用的党建文档，确保问答内容贴合当前支部的学习要求。同时，发电装备制造场景下的党建问题常关联生产场景，需在提示词中嵌入生产相关的约束条件，避免问答脱离业务实际。

## 配置怎么定
以下配置说明基于FastGPT v4.17.0版本

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `messages` | 保留最近3轮对话 | 发电装备制造党建问题多关联连续生产场景，3轮对话可覆盖完整业务关联的学习提问链条，避免上下文过长 |
| `chatId` | 绑定当前支部的唯一标识 | 用于关联`variables`中的支部范围参数，确保对话上下文仅针对当前支部的学习数据 |
| `variables` | 传入当前支部所属单位、学习主题字段 | 用于过滤文档库中非适用的党建内容，贴合发电装备制造场景的业务关联要求 |
| 上下文保留时长 | 7天 | 匹配支部月度学习的推进节奏，避免过期对话干扰当前问答 |
| 文档召回上限 | 前3条匹配结果 | 单篇党建文档字符数较高，限制召回条数可避免上下文过载，同时覆盖核心学习内容 |
| 提示词模板更新 | 每月同步一次 | 匹配党建数据的更新周期，确保提示词与最新学习主题对齐 |

## 容易做错的三处
- 现象：同一会话ID多次访问时，问答上下文出现不连贯的内容，部分历史对话未被正确保留。原因：工作流中为不同AI模型节点配置了不一致的`messages`参数保留轮次，导致上下文拼接逻辑混乱。
- 现象：界面弹出“上下文长度超出限制”的报错提示，无法完成问答。原因：未限制`messages`参数保留的对话轮次，同时未过滤冗余的历史内容，导致上下文占用超出模型支持范围。
- 现象：召回的党建文档包含其他支部的学习内容，与当前对话场景不匹配。原因：未通过`variables`参数传入当前支部的范围信息，提示词未加入过滤逻辑，导致召回内容不符合适用范围要求。

## 怎么确认配好了
- 发起一次包含2轮连续提问的测试对话，查看系统返回的上下文是否包含前一轮的提问与回答内容，确认`messages`参数配置生效。
- 手动修改`variables`参数中的支部范围字段，发起提问，查看召回的文档是否仅包含对应支部的学习内容，确认过滤逻辑生效。
- 等待1天后再次访问同一会话ID，查看系统是否保留了修改后的上下文内容，确认上下文保留时长配置符合要求。
- 检查提示词模板的更新记录，确认与党建数据的更新周期一致，确保提示词与最新学习内容对齐。
