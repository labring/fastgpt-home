# 发电装备制造的党建学习问答：文档解析与分块

## 这个品类的数据长什么样
发电装备制造领域的党建学习问答数据，主要来源于上级党委下发的正式文件、企业内部支部三会一课记录、党员学习培训课件、年度党建汇编资料，以及结合生产场景的党建主题文档。数据更新节奏随上级部署与内部培训计划调整，正式文件按季度更新，临时学习资料按需发布。文档类型涵盖带文号的公文、分章节的PPT课件、结构化Excel台账与PDF手册，字段包含文件编号、发布日期、学习主题、关联装备类型，单位涉及学习时长、参与人次、文件页数等。

## 这些特征在「文档解析与分块」这一环带来什么约束
正式公文的固定格式要求解析时保留元数据，避免分块后丢失文号与签发单位等关键信息；PPT课件与PDF手册内嵌的设备示意图关联文本，需完整提取以保留党建知识点与生产场景的绑定关系；结构化Excel台账包含多维度字段，若仅提取可见列会导致关联数据缺失，影响检索精度；大型年度党建汇编文件体量较大，解析耗时较长，需适配更长的处理周期。此外，结合发电装备生产的党建内容常包含长段论述，分块时需平衡完整性与检索粒度，避免内容断裂或分块过碎。

## 配置怎么定
FastGPT v4.17.0版本下，以下配置项可针对性适配发电装备制造党建学习场景的文档解析与分块需求：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 800–1200 字符 | 发电装备制造的党建文档常包含结合生产场景的长段论述，该区间可保留知识点与装备关联的完整上下文，避免分块断裂 |
| `chunkSplitter` | 按段落+标题拆分 | 党建文档多有层级标题与分点论述，按此拆分可保留内容逻辑，适配检索时的语义关联 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 700–900 秒 | 大型PDF培训课件或多页Excel台账解析耗时较长，该区间可避免超时报错，适配发电装备制造党建资料的体量 |
| `customPdfParse` | 启用自定义解析模式 | 发电装备党建文档常包含设备示意图内嵌文本，自定义解析可完整提取图文关联内容，避免文本丢失 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 部分年度党建汇编文件体量较大，该设置可允许上传完整资料，避免因文件过大被拦截 |
| `chunkSettingMode` | 手动配置 | 需针对不同类型的党建文档（公文/课件/台账）调整分块参数，手动模式可灵活适配 |

## 容易做错的三处
- 现象：解析大型党建PDF课件时触发超时报错，界面显示请求超时。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，使用默认值导致无法完成大型文档解析。
- 现象：上传Excel党员学习台账后，检索时返回的数据条数远少于源文件，且无法筛选关联装备类型的条目。原因：未启用完整字段提取配置，仅提取了可见列，导致关联字段丢失，检索范围受限。
- 现象：上传内嵌汽轮机示意图的PDF党建文档后，分块结果丢失示意图旁的文本说明。原因：未开启`customPdfParse`自定义解析模式，默认解析仅提取纯文本，忽略了图文关联内容。

## 怎么确认配好了
- 上传一份典型的发电装备党建PDF课件，查看解析后的文本是否包含内嵌的设备说明文本，确认`customPdfParse`配置生效。
- 上传一份大型Excel台账，等待解析完成后查看任务日志，确认未出现超时报错，验证`PARSE_FILE_TIMEOUT_SECONDS`配置合理。
- 检索党建文档中的“汽轮机检修党员先锋岗”相关内容，查看返回结果是否保留了完整的主题与装备关联上下文，验证`chunkSize`与`chunkSplitter`配置适配内容逻辑。
- 上传一份超过500MB的党建汇编文件，确认上传成功，验证`UPLOAD_FILE_MAX_SIZE`配置符合需求。
