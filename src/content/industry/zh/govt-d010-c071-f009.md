# 发电集团的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
发电集团党建学习问答的数据源主要来自内部党建工作平台、党委下发的正式文件、月度学习汇编及临时通知。常规政策文件按月更新，临时学习通知随发布即时同步。文档多为结构化格式，包含标题、正文内容、发布主体、发布日期、主题标签等字段，以篇、章节为基础统计单位，单篇文档篇幅跨度较大，部分政策文件内容较长。

## 这些特征在「模型接入与配置」这一环带来什么约束
党建数据的正式性要求回答内容必须严谨准确，因此模型调用需适配长文本上下文处理，避免截断核心政策表述；数据更新存在常规批量与临时即时两种场景，需配置支持按需刷新与定时同步的数据源规则；文档自带的主题标签字段可用于精准召回，需配置支持按标签过滤的检索逻辑；部分文档篇幅较长，需限制单轮回答的输出长度，确保答疑简洁清晰。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配发电集团党建文档的长文本上下文需求，避免截断核心政策表述 |
| `maxTokens` | 2000–3000 token | 控制单轮回答长度，符合党建学习问答的精准答疑需求 |
| `quoteMaxToken` | 1200–1800 token | 限制引用的党建文档片段长度，确保引用内容完整且不冗余 |
| `toolChoice` | auto | 允许模型自主选择是否调用工具，适配党建问答中可能需要的政策检索需求 |
| `temperature` | 0.2–0.4 | 降低回答随机性，确保党建内容表述的严谨性与权威性 |
| `AIPROXY_API_ENDPOINT` | 按接入模型的官方接口地址填写 | 适配所选大模型的调用路径，确保请求正常转发 |
| `AIPROXY_API_TOKEN` | 按平台生成的专属令牌填写 | 完成接口身份验证，保障调用权限合法 |

## 容易做错的三处
- 现象：调用模型时返回401未授权错误，或调试预览界面无模型响应。原因：未正确配置`AIPROXY_API_TOKEN`与`AIPROXY_API_ENDPOINT`，或令牌权限未覆盖所选大模型。
- 现象：长文档问答时回答内容被截断，核心政策表述缺失。原因：`maxContext`取值过小，未适配党建文档的长文本上下文需求。
- 现象：非工具调用模式下未引用党建知识库内容，仅返回通用回答。原因：未正确绑定党建知识库数据源，或`quoteMaxToken`配置不合理导致召回内容未被纳入上下文。

## 怎么确认配好了
- 进入FastGPT v4.17.0的模型调试界面，输入党建相关专业问题，查看返回结果是否包含党建知识库的专属内容。
- 查看模型调用日志，确认接口请求地址与`AIPROXY_API_ENDPOINT`配置一致，无4xx或5xx类报错。
- 调整`temperature`参数，验证回答内容的严谨性是否符合党建内容的表述要求。
- 上传一篇测试用党建文档，确认数据源同步后可被正常召回并用于问答。
