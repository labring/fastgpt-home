# 国有产业基金的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
国有产业基金党建学习问答的数据来源于企业内部党建档案库、上级国资委下发的党建指导文件、年度支部党课课件与活动记录。数据更新频率为每月一次，单篇文档包含主题标题、正文内容、发布日期、所属支部分类等字段，文档结构按党建学习模块分为理论学习、政策解读、活动纪实三类，单篇文档字数区间为800-15000字符，无统一固定格式要求。

## 这些特征在「分享与嵌入」这一环带来什么约束
国有产业基金党建数据按支部、主题分类存储，且每月更新，分享与嵌入环节需匹配这些特征设置对应约束。首先需配置分类过滤规则，避免非目标党建内容被召回；其次需将分享链接的缓存有效期设置为与数据更新周期匹配的时长，防止返回过期内容；再者，单篇文档字数跨度较大，嵌入后的上下文召回长度需支持动态调整，适配长文档的问答需求；最后，部分党建资料带有内部使用标识，需配置权限校验规则，确保仅授权用户可访问嵌入后的问答页面。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `shareId`绑定应用范围 | 仅绑定党建学习问答专属应用 | 确保分享嵌入的问答仅调用党建相关数据，避免跨品类数据混淆 |
| 分享链接缓存时长 | 30天 | 匹配国有产业基金党建数据每月更新的频率，避免缓存过期与数据更新不同步 |
| 嵌入页面语言设置 | 简体中文（可按需切换为英语） | 适配内部员工主要使用语言，满足对外展示的多语言需求 |
| 免登录会话保留时长 | 120分钟 | 匹配单次党建学习研讨的周期，避免会话过期打断问答流程 |
| 嵌入容器尺寸 | 宽度100%，高度600-800像素 | 适配内部系统页面布局，保证问答界面显示完整 |
| 语音输入功能开关 | 开启（按实测标定） | 方便党建学习时快速输入问题，提升问答效率 |

## 容易做错的三处
- 现象：免登录页面的语音输入长按后秒数保持00:00，发送内容无反馈。原因：未配置语音输入的音频上传超时阈值，导致链路中断。
- 现象：嵌入网页后的问答页面语言不一致，部分模块显示非预设语言。原因：未全局设置嵌入页面的语言参数，仅调整了部分界面元素的语言。
- 现象：免登录链接无法携带`shareId`，无法维持同一会话多次问答。原因：未开启免登录链接的会话持久化配置，导致每次访问生成新会话。

## 怎么确认配好了
- 访问生成的分享链接，确认页面显示语言与预设配置一致。
- 发起一次党建相关问答，关闭页面后重新访问链接，确认可延续之前的会话流程。
- 测试语音输入功能，确认输入过程中秒数正常更新，提交内容无异常。
- 将嵌入代码部署至测试页面，确认问答界面尺寸适配页面布局，无内容溢出。
