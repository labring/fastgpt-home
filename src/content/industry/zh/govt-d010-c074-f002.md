# 国有资产管理公司的党建学习问答：向量模型与索引

## 这个品类的数据长什么样
国有资产管理公司的党建学习数据主要来自内部党建管理平台、上级国资监管部门下发的党建指导文件、公司党委印发的学习材料、支部三会一课记录、党员个人学习档案。更新节奏为月度新增学习计划、季度更新党建工作总结，临时下发的政策文件随发布同步更新。文档多为PDF、DOCX格式，包含标题、发布单位、发布日期、正文内容、关联标签字段，部分附带学习课件、活动记录附件，字段包含文件编号、所属支部、学习主题等。

## 这些特征在「向量模型与索引」这一环带来什么约束
党建文档的元数据包含发布单位、所属支部、学习主题等字段，要求索引需支持按元数据精准过滤，避免跨支部、非关联党建内容被误召回。文档多为正式公文格式，正文结构规整，向量模型需适配正式文本的语义提取，避免拆分时丢失关键政策表述。更新节奏包含月度批量更新与临时新增，索引需支持增量同步，减少全量重建的耗时。部分文档附带学习课件附件，需支持多文件关联的向量索引，确保课件内容与正文内容统一关联。

## 配置怎么定
本页面基于FastGPT v4.17.0版本的向量模型与索引逻辑进行配置说明。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 党建文档多为规整的正式公文，该长度可保留完整的政策表述与学习内容，避免拆分破坏语义单元 |
| 重叠长度 | 100–150 字符 | 党建文档正文存在连贯段落结构，重叠长度可确保相邻分块间的语义衔接，避免上下文断裂 |
| `defaultToken` | 200 token | 党建文档分块后的默认token数，确保每个分块的语义完整性 |
| `maxToken` | 4000 token | 党建问答需覆盖完整的政策原文与关联学习资料，4000 token可满足常规问答的上下文需求 |
| 相似度阈值 | 0.72–0.80 | 党建内容语义相关性要求较高，该区间可过滤低相关召回结果，确保召回内容贴合党建主题 |
| 单次搜索上限 | 前8条 | 党建问答需覆盖相关政策文件、学习材料与支部活动记录，前8条可满足常规信息需求 |

## 容易做错的三处
- 现象：单个党建文档长时间处于索引中，界面显示索引未完成。原因：未配置适配党建文档长段落的分块规则，导致分块耗时过长，索引进程阻塞。
- 现象：切换知识库索引时出现60秒超时报错。原因：未设置合理的`maxToken`与单次搜索上限配置，导致索引重建时的向量嵌入任务占用系统资源过高，触发超时限制。
- 现象：党建知识库内文件数量少但长时间处于训练中，无法完成索引重建。原因：未开启增量索引配置，每次切换时触发全量索引，导致耗时超出合理范围。

## 怎么确认配好了
- 上传一份标准党建公文文档，检查分块结果的文本长度是否落在配置的800–1200字符区间内。
- 提交党建相关的测试问题，核对召回结果的相似度得分是否在配置的0.72–0.80区间内。
- 切换已配置的党建知识库，查看索引重建耗时是否未触发60秒超时报错。
- 查看系统索引日志，确认增量索引任务正常运行，未出现进程阻塞的情况。
