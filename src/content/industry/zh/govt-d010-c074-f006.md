# 国有资产管理公司的党建学习问答：引用来源与溯源

## 这个品类的数据长什么样
国有资产管理公司的党建学习问答数据主要来源于国资监管部门发布的党建工作规范、公司党委印发的学习手册、上级党组织的指导文件及内部党建活动记录。数据更新节奏为每月常规更新，遇重要党建会议、政策调整时即时补充。单篇文档结构包含标题、发布主体、发布日期、核心内容、适用范围五个固定字段，无额外自定义单位，内容以规范文本为主，无复杂图表或非结构化素材。

## 这些特征在「引用来源与溯源」这一环带来什么约束
由于数据来源均为官方正式文档，溯源环节需准确匹配发布主体与发布日期，确保引用内容的权威性。固定的文档结构要求溯源信息需从标题、发布主体、发布日期字段直接提取，无需额外解析非结构化内容。月度常规更新与即时补充的节奏，要求溯源关联的知识库版本需同步更新标记，避免返回过时的党建学习材料。同时，党建内容的严肃性要求溯源信息需完整展示来源层级，确保问答中的引用可追溯至原始发文单位。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | 匹配党建文档核心内容长度，完整展示引用原文，避免截断关键表述 |
| `responseData` | 开启 | 确保问答结果附带结构化的引用来源信息，满足溯源需求 |
| `detail` | 完整模式 | 提取文档全部元数据，包括发布主体、发布日期等字段，用于完整溯源 |
| 知识库同步频率 | 每月1次 | 匹配党建数据月度更新节奏，确保溯源信息与最新文档同步 |
| 引用来源展示条数 | 前3条 | 避免信息过载，同时覆盖核心参考来源 |

## 容易做错的三处
- 现象：问答返回结果中无引用来源字段，或字段内容为空。原因：未开启`responseData`配置项，或配置取值为关闭状态。
- 现象：通过nginx代理部署后，无法正常下载知识库原文链接。原因：未将知识库原文的静态资源路径纳入代理规则，仅代理了问答接口流量。
- 现象：通过post请求调用FastGPT接口后，接口返回状态码正常但无content字段内容。原因：未启用`detail`配置项的完整模式，仅返回精简问答文本，未包含引用来源数据。

## 怎么确认配好了
- 发起党建相关的测试问题，查看问答结果下方是否展示了来源信息条目。
- 核对配置项的取值是否符合业务需求，例如引用最大token数是否覆盖核心文档长度。
- 调用接口获取返回数据，确认`responseData`字段包含完整的引用元数据。
- 模拟知识库更新后发起提问，确认新的引用来源可被正确检索展示。
