# 国有资产管理公司的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
国有资产管理公司的党建学习数据主要来自内部党建档案系统、上级党委下发的正式文件、各支部的月度学习记录与心得。数据更新节奏为：上级党委文件随发布同步更新，支部学习记录每季度汇总归档。单篇文档结构包含标题、发布单位、发布时间、正文、适用范围五个核心字段，字段单位分别为字符、全称、年月日、MB、部门范围。文档正文长度跨度较大，短则数百字符，长则数千字符。

## 这些特征在「分享与嵌入」这一环带来什么约束
党建数据的多源分散特性要求分享链接需关联身份鉴权，避免非授权用户访问仅限内部的党建内容。月度/季度的更新节奏要求嵌入页面的缓存时长不能过长，否则会出现内容滞后的情况。文档包含适用范围字段，需在嵌入配置中按部门过滤召回结果，确保不同支部的员工只能访问对应范围内的党建资料。文档长度跨度大的特点，要求上下文截取参数需适配不同长度的文档，避免出现上下文溢出或冗余的问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分享链接鉴权方式 | 开启身份鉴权，绑定公司内部账号体系 | 党建数据存在内部权限层级，需限制非授权用户访问 |
| `shareId` 绑定范围 | 绑定对应支部的专属党建知识库 | 国有资产管理公司各支部党建数据独立，需按部门隔离访问权限 |
| 嵌入缓存时长 | 600 秒 | 党建文档月度更新，该时长兼顾时效性与页面加载速度 |
| 移动端适配开关 | 开启自适应布局 | 党建学习场景下员工多通过移动设备开展学习 |
| 上下文召回上限 | 前8条匹配结果 | 党建文档结构规整，无需过多冗余上下文干扰学习 |

## 容易做错的三处
- 现象：分享配置界面未显示身份鉴权选项，原因：未在FastGPT后台开启对应知识库的权限管控开关，或使用的FastGPT版本低于v4.17.0。
- 现象：iframe嵌入页面登录后自动登出，原因：嵌入页面的域名未添加至允许跨域列表，或鉴权cookie的跨域配置未开启。
- 现象：嵌入的问答机器人在移动端无法正常显示输入区域，原因：未开启移动端自适应布局配置，或自定义样式覆盖了响应式显示规则。

## 怎么确认配好了
- 复制生成的分享链接，使用非授权账号访问，检查是否弹出权限验证提示或直接拒绝访问。
- 在移动设备浏览器打开嵌入页面，检查问答机器人的输入框、回复区域是否适配屏幕尺寸，无横向滚动或元素重叠。
- 等待配置的缓存时长后刷新嵌入页面，检查是否加载了最新的党建文档内容。
- 打开FastGPT后台的分享管理页面，查看对应`shareId`的配置状态是否显示为已启用。
