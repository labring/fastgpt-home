# 国有资本投资公司的党建学习问答：向量模型与索引

## 这个品类的数据长什么样
国有资本投资公司的党建学习数据主要来源于内部党建资料库、上级党委下发的政策文件、支部日常学习记录、党员学习台账等。文档结构包含固定字段，如文件标题、发布单位、发布日期、正文内容、所属支部或管理单元，单位以篇、条、字符为常见标识。数据更新节奏不固定，新政策下发、季度学习计划更新时会批量新增内容，日常也会有零散的学习心得、通知类文档补充。

## 这些特征在「向量模型与索引」这一环带来什么约束
多源异构且带结构化元数据的党建文档，要求向量索引需绑定元数据字段，实现后续问答时的精准溯源。不定期的批量更新与零散新增，要求支持增量索引更新，避免全量重跑带来的资源消耗。部分政策文件篇幅较长，需适配长文本的分块策略，防止单块内容超出向量模型的编码上限。固定的发布单位、支部字段可作为召回过滤条件，缩小搜索范围，提升问答效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配国有资本投资公司党建文档的常见篇幅，避免单块超出向量模型编码上限 |
| 重叠长度 | 100–200 字符 | 保证相邻文本块的语义连贯性，防止长文档分块后丢失上下文关联 |
| 相似度阈值 | 0.75–0.85 | 满足党建问答的严谨性要求，过滤低相关性召回结果，确保回答贴合提问主题 |
| 单次搜索上限 | 前 5 条 | 控制返回的上下文数量，避免超出`maxToken`限制，同时保证回答的信息充分性 |
| 最大上下文 | 4000 token | 匹配主流向量模型的输入上限，确保召回的文本块可完整嵌入问答上下文 |
| 默认令牌数 | `defaultToken` 设为 2000 | 为非核心问答场景预留合理的上下文空间，平衡资源占用与回答完整性 |

## 容易做错的三处
- 搜索结果无法关联原始文档的标题、发布单位等元数据。原因：未在索引配置中开启元数据绑定功能，仅对正文内容生成向量，丢失了文档的结构化字段信息。
- 调用Doubao-embedding模型时出现接口报错。原因：未在向量模型配置中正确填写模型的认证密钥与接口地址，导致无法正常生成向量。
- 问答上下文超出模型限制导致报错。原因：未设置合理的`maxToken`与单次搜索上限，召回的文本块总长度超出模型输入上限，无法完成编码。

## 怎么确认配好了
- 在FastGPT v4.17.0的界面中上传一篇党建政策文件，查看分块后的文本块长度是否落在800–1200字符区间，相邻块是否存在100–200字符的重叠内容。
- 发起党建相关提问，检查返回的回答是否关联了原始文档的元数据，如文件标题、发布日期等信息。
- 测试调用Doubao-embedding模型，确认向量生成接口返回正常，无连接超时或认证失败的报错。
- 调整相似度阈值，观察召回结果的相关性变化，确认配置生效。
