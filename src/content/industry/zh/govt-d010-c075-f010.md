# 国有资本投资公司的党建学习问答：知识库检索与召回

## 这个品类的数据长什么样
数据来源包括国有资本投资公司内部党委发布的学习手册、三会一课记录、廉政教育材料，以及上级国有资产监督管理机构下发的党建指导文件，更新节奏为每月更新内部学习资料、每季度更新上级政策文档。文档多为结构化格式，包含标题、发布主体、发布日期、内容分类字段，内容以理论阐述、工作规范为主，单篇文档长度跨度较大，部分包含附件转译的文本内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散在内部OA、共享盘等不同渠道，要求检索配置支持多数据源关联召回；更新节奏不统一，需要设置匹配业务周期的增量同步触发规则，避免数据滞后或重复索引；文档带有明确的党建分类标签，要求检索支持按标签过滤结果，确保召回内容贴合学习主题；部分文档篇幅较长，需要合理的分块策略避免语义断裂，同时控制单块长度适配模型上下文；部分文档带有内部权限标识，要求结合权限控制召回范围，避免敏感内容泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.72–0.85` | 党建内容语义相似度较高，该区间可过滤低相关结果同时保留足够召回量 |
| `limit` | `前8条` | 党建学习问答需覆盖多维度学习材料，8条左右可满足多场景参考需求 |
| `searchMode` | `向量检索+关键词混合` | 党建文档既有明确关键词（如“三会一课”）又有语义关联内容，混合模式召回更全面 |
| `usingReRank` | `开启` | 党建内容语义相近的条目较多，重排可提升结果相关性排序准确性 |
| `datasetSearchUsingExtensionQuery` | `开启` | 党建问题常带有行业专属表述，扩展查询可覆盖更多相关文档 |
| `collectionIds` | `绑定党建专属数据集ID` | 隔离其他品类数据，确保召回结果仅来自国有资本投资公司党建知识库 |

## 容易做错的三处
- 现象：调用API检索时返回空结果或无匹配内容。原因：未正确配置`collectionIds`参数绑定对应党建数据集，导致检索范围未覆盖目标数据。
- 现象：对话页面或知识库页面出现崩溃报错。原因：未限制`limit`参数取值，单次召回过多文档导致上下文溢出，触发FastGPT v4.17.0的资源限制规则。
- 现象：检索结果混入非党建类的国资运营内容。原因：未开启`searchMode`的分类过滤，或未通过`collectionIds`限定数据集范围，导致召回了其他品类的文档。

## 怎么确认配好了
- 查看FastGPT的检索配置面板，确认`collectionIds`已绑定国有资本投资公司党建专属数据集ID。
- 发起测试查询，输入党建相关问题，验证返回结果的标题、内容均来自党建类文档，无跨品类内容。
- 调整`similarity`参数区间，观察召回结果的相关性变化，确认取值符合业务对精准度的要求。
- 触发增量同步任务，等待预设的同步周期，确认新上传的党建文档可被正常检索到。
