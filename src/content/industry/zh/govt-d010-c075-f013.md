# 国有资本投资公司的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
国有资本投资公司的党建学习问答数据，主要来源于公司党委办公室下发的正式文件、三会一课会议记录、党建活动档案以及最新党内政策解读材料。数据更新节奏为每月同步一次常规学习内容，遇重大政策发布或重要党建活动时即时更新。文档结构包含标题、发布单位、发布日期、正文、适用范围等字段，发布日期采用YYYY-MM-DD格式，正文字数区间从数百到数千字符不等，部分涉密文件标注有内部使用标识。

## 这些特征在「分享与嵌入」这一环带来什么约束
党建学习数据包含内部涉密内容，因此分享与嵌入环节需严格控制访问权限，避免非授权用户获取敏感信息。数据定期更新的特性要求嵌入的知识库需匹配更新频率，确保分享内容的时效性。结构化的文档字段支持按发布单位、发布日期筛选分享内容，可定向为特定支部推送学习问答。同时，党建内容的权威性要求分享链接需保留来源标识，便于用户追溯官方文件。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 免登录分享链接数量 | 100 个 | 覆盖公司各支部的学习分享需求，匹配团队版套餐的扩展配置规则 |
| iframe界面语言 | 简体中文 | 适配内部员工的使用习惯，避免出现英文界面的阅读障碍 |
| 分享链接鉴权开关 | 开启 | 防止非授权用户访问内部党建学习内容，符合涉密信息管理要求 |
| 分享有效期 | 30 天 | 匹配月度学习计划的周期，确保内容在学习周期内有效 |
| 嵌入弹窗触发方式 | 点击触发 | 避免页面加载时自动弹窗干扰用户浏览，符合内部办公场景的使用逻辑 |
| `shareId`参数配置 | 与应用唯一标识一致 | 确保嵌入的iframe指向正确的党建学习问答应用，避免链接指向错误 |

## 容易做错的三处
- 免登录分享链接创建至第11个时弹出“链接数量超限”报错，原因是团队版套餐默认限制为10个免登录链接，未提前申请调整数量。
- iframe嵌入的问答弹窗显示英文界面，原因是未将界面语言配置为简体中文，默认采用系统语言或英文展示。
- 无法找到分享链接身份鉴权的配置入口，原因是使用FastGPT v4.17.0版本，鉴权配置已整合至应用权限设置页面，旧版本的分享配置页已无该选项。

## 怎么确认配好了
- 打开生成的分享链接，检查界面语言是否为简体中文。
- 尝试创建第11个免登录分享链接，确认无数量限制报错。
- 复制嵌入的iframe代码，检查其中的`shareId`参数是否与测试应用的唯一标识一致，访问嵌入页面确认可正常加载问答内容。
- 测试未授权用户访问分享链接，确认无法获取问答内容，验证鉴权功能生效。
