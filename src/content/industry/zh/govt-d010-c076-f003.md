# 国有资本运营公司的党建学习问答：多轮对话与提示词

## 这个品类的数据长什么样
国有资本运营公司的党建学习问答数据主要来源于内部党建工作档案、党委中心组学习材料、国资监管部门发布的党建规范文件。数据更新节奏为每月同步最新党建动态，每季度更新标准化学习手册。文档多为结构化的正式文本，包含文件编号、发布单位、发布日期、适用范围等字段，单篇文档长度多在数千到数万字符区间，无零散非结构化内容。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
正式结构化的党建文档要求多轮对话需严格保留官方表述，避免随意改写政策内容。固定更新节奏要求知识库需按周期增量同步最新文件，提示词需明确限定检索范围为当前有效版本的党建材料，避免引用过时内容。多字段的文档结构要求多轮对话中需支持回溯文件编号、发布单位等元数据，确保引用内容的准确性与合规性。同时正式文本的长文档属性，要求多轮上下文窗口需适配长文本拆分后的关联检索逻辑，避免上下文断裂导致的政策解读偏差。

## 配置怎么定
本配置基于 FastGPT v4.17.0 版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配国有资本运营公司党建文档的正式文本结构，避免拆分破坏政策表述的完整性 |
| 重叠长度 | 100–150 字符 | 保留相邻分块的关联上下文，确保多轮对话中能连贯回溯政策内容 |

| 最大上下文 | 8000 字符 | 适配多轮对话的历史交互，保留足够的官方表述上下文 |
| 提示词优化 | 开启 | 针对正式政策表述优化用户提问与回复格式，提升检索精准度 |

## 容易做错的三处
- 对话返回内容携带大量#、*等标点符号，原因是未关闭知识库分块时的markdown格式标记残留，或提示词未明确要求输出纯文本格式。
- 调用对话接口未返回引用的知识库id，原因是未开启对话日志的元数据记录配置，或未在提示词中要求返回引用来源标识。
- 本地部署时知识库内的图片URL无法在对话中输出，原因是未配置外部图片访问权限，或提示词未明确允许嵌入外部资源链接。

## 怎么确认配好了
- 发起包含党建政策关键词的单轮提问，核对返回内容的分块关联逻辑是否符合预设的分块长度要求。
- 发起连续多轮提问，核对`chatId`是否持续关联同一对话上下文，`messages`数组是否正确保留历史交互内容。
- 查看对话返回的元数据，确认是否包含引用的知识库文件编号、发布单位等信息。
- 核对`variables`是否正确传递了党建场景的专属上下文参数，如文件适用范围限定。
- 测试包含图片URL的知识库内容，核对返回内容是否正确引用该URL链接。
