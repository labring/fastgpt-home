# 城市燃气的党建学习问答：多轮对话与提示词

## 这个品类的数据长什么样
城市燃气行业的党建学习数据，主要来源于企业党委办公室归档的内部学习台账、上级党组织下发的政策解读文件、内部党课录音转写文本。更新节奏为每周同步新的学习任务与政策要点，单篇文档多为分章节的Word或PDF格式，包含学习主题、发布单位、发布日期、核心要点、考核要求等字段，单篇文档长度多在5000到10000字符区间内。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
党建学习数据的分章节结构要求多轮对话需精准匹配对应章节的内容，避免跨章节的无关信息干扰。更新频率的要求意味着提示词需明确优先使用最新的学习资料，确保回答时效性。专属字段的存在则要求对话配置需绑定对应支部或场站的专属数据，避免不同主体的学习内容混淆。长文档的特性则限制了多轮对话的上下文窗口上限，防止内容溢出导致关键信息丢失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 最大上下文长度 | 8000–12000 字符 | 适配单篇党建学习文档与多轮对话历史的总长度，避免内容截断 |
| 问题优化开关 | 开启 | 针对燃气党建涉及的政策术语与专业表述，优化后可提升问题理解精度 |
| 单次召回上限 | 前6条 | 匹配党建学习资料的关联密度，避免过多冗余信息干扰对话 |
| `variables`绑定 | 绑定企业支部ID字段 | 区分不同支部的专属学习数据，确保对话返回对应场站的党建内容 |
| 对话超时时间 | 600 秒 | 适配长文本解读与多轮追问的处理需求，避免中途中断 |

## 容易做错的三处
- 现象：多轮对话中后续提问的答案未延续前文上下文，出现内容脱节。原因：未正确配置`messages`参数的上下文传递规则，导致对话历史未被纳入检索范围。
- 现象：提示词设置后未生效，返回的党建内容不符合预设要求。原因：提示词未明确限定仅使用本企业城市燃气党建学习数据，且未指定优先匹配的字段。
- 现象：上传的党建学习PPT附件无法被检索到。原因：未开启对应文档格式的解析功能，且未在提示词中说明需优先读取附件内容。

## 怎么确认配好了
- 发起测试提问，输入“请结合本月党建学习内容讲解燃气安全相关要求”，查看返回内容是否包含当月最新的学习要点。
- 发起多轮对话，先提问“上周的党课主题是什么”，再追问“该主题对应的燃气场站考核要求”，查看第二次回答是否延续前文的主题上下文。
- 查看`variables`参数的绑定配置，确认已关联企业支部ID字段，确保不同支部的对话匹配对应专属数据。
- 检查`chatId`的配置，确认每个对话会话的ID唯一，避免不同会话的上下文混淆。
- 确认当前使用的FastGPT版本为v4.17.0，确保配置项的功能正常生效。
