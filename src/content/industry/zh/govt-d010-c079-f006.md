# 城市燃气的党建学习问答：引用来源与溯源

## 这个品类的数据长什么样
城市燃气企业的党建学习数据来源为内部党建档案库、上级国资与党委下发的学习文件、线下党课整理的电子文档。更新节奏为每周同步最新学习通知、每月更新固定党课课件。文档多为带层级标题的规范文本，包含发布主体、发布日期、核心学习要点三个固定字段，单篇文档长度集中在1000-5000字符区间，以批量MB级文件包形式存储。

## 这些特征在「引用来源与溯源」这一环带来什么约束
党建数据的固定发布元数据，要求溯源环节必须关联发布主体与发布日期，确保引用内容的权威性。周/月级的更新节奏，要求溯源时支持增量同步校验，避免返回过期的学习材料。带层级标题的文档结构，要求引用时能精准定位到对应学习要点的段落，关联具体段落，避免泛泛关联整个文档。批量文件包的存储形式，要求溯源环节支持批量导入时的元数据自动映射，防止引用来源字段缺失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 匹配党建学习文档的段落结构，避免块内内容割裂 |
| 相似度阈值 | 0.75–0.85 | 过滤燃气运营类无关数据，仅召回党建学习相关内容 |
| 单次搜索上限 | 前 5 条 | 控制溯源返回的引用条数，适配党建问答的精简需求 |
| `quoteMaxToken` | 1000 token | 限制引用内容的长度，避免冗余信息干扰党建学习场景 |
| `responseData` | 开启答案与引用分离 | 确保溯源信息与答案同步展示，便于核对 |
| `detail` | 按场景配置 | 按需开启详细溯源，展示发布主体与发布日期 |

## 容易做错的三处
- 现象：返回的答案与知识库引用无关联，引用内容并非党建学习相关文档。原因：未配置相似度阈值过滤非党建类的燃气运营数据，导致召回无关内容。
- 现象：引用来源字段为空，无法查看原文详情。原因：批量导入党建文档时未映射发布主体、发布日期字段，导致溯源元数据缺失。
- 现象：工作流中部分场景无法关闭引用展示。原因：未区分配置`detail`参数的触发条件，导致所有场景统一开启详细溯源。

## 怎么确认配好了
- 发起党建相关提问，检查返回内容是否仅关联党建学习文档，无燃气运营类无关内容。
- 查看答案下方的引用区域，确认每条引用都包含发布主体、发布日期等元数据字段。
- 在FastGPT v4.17.0版本的系统日志中，验证每次召回的引用条数符合单次搜索上限的配置值。
- 切换不同场景的问答配置，验证`detail`参数是否可单独开启或关闭，符合场景需求。
