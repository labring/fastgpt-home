# 城市燃气的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
城市燃气党建学习的数据来源为企业内部党建管理系统、上级党委下发的学习文件、内部党课录制课件、党员学习考核题库。更新节奏为每周新增当期学习素材，每月更新季度考核题库与党建要点汇总。文档结构包含主题标题、发布单位、发布日期、学习要点、考核要求等字段，单篇文档长度从数百字符的学习提示到数千字符的党课讲稿不等，学时以“小时”为单位，考核分值以“分”为单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
由于数据来自内网系统与官方渠道，接入时需配置内网访问权限，禁止直接公网拉取。由于文档长度差异较大，需适配不同长度的上下文输入，避免截断核心内容。由于更新频率分周度与月度，需设置定期同步的触发机制，确保知识库内容时效性。由于党建内容需严格符合官方口径，需限制模型生成的随机性，避免出现不符合规范的表述。由于存在考核题库与学习材料两类内容，需分类配置知识库，避免无关内容干扰问答准确性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配城市燃气党建学习的长课件与多文档问答场景，避免截断核心学习内容 |
| `maxTokens` | 2000 token | 控制单轮回答的输出长度，符合党建问答简洁准确的要求，避免冗余表述 |
| `quoteMaxToken` | 1500 token | 限制引用的文档总长度，确保引用内容贴合党建学习的核心要点，不占用过多上下文 |
| `temperature` | 0.1–0.3 | 降低生成随机性，保证党建回答符合官方统一口径，避免出现不符合规范的表述 |
| `AIPROXY_API_ENDPOINT` | 企业内网代理地址 | 适配城市燃气党建数据的内网部署场景，保障数据传输安全 |
| `AIPROXY_API_TOKEN` | 企业专属鉴权令牌 | 对接内部代理接口的身份校验，防止未授权访问党建知识库 |

## 容易做错的三处
- 调用模型时出现“上下文溢出”报错，原因是未调整`maxContext`参数，传入的党建长课件内容超过模型支持的上下文上限。
- 生成的党建回答出现不符合官方口径的表述，原因是`temperature`参数设置过高，生成内容偏离统一规范。
- 无法触发从大模型回答到人工客服的转接，原因是未正确配置`toolChoice`参数，模型无法识别需要转人工的场景。

## 怎么确认配好了
- 上传一篇城市燃气党建长课件，发起相关问答，检查回答是否完整引用课件内容，无截断情况。
- 发起多轮党建相关提问，检查回答的表述是否符合官方统一口径，无偏差内容。
- 配置内网代理与鉴权令牌后，测试能否正常拉取内部党建系统的数据源，无访问报错。
- 触发预设的转人工触发词，检查模型是否能正确识别并触发转接流程。
