# 城投平台的党建学习问答：文档解析与分块

## 这个品类的数据长什么样
城投平台党建学习相关数据主要来源于内部党建台账、上级党委下发的规范性文件、季度党员学习手册及月度主题会议纪要。数据更新节奏随上级党委部署调整，常规指导性文件每月更新，专项学习材料按需发布。文档多为红头公文格式，包含文件编号、发布单位、发布日期、学习主题与正文内容，部分归档材料附带手写学习批注，文档长度从数页到数十页不等。

## 这些特征在「文档解析与分块」这一环带来什么约束
红头公文的固定格式要求解析工具准确识别标题层级与段落结构，避免分块割裂核心论述内容。内部手写批注与正文混杂的情况，需要单独提取批注关联的上下文，防止无关内容混入学习问答知识库。文档长度跨度大的特点，要求分块配置可灵活调整，适配短文档与长文件的不同拆分需求。按需发布的专项材料，要求解析流程支持快速批量导入，适配临时学习任务的部署节奏。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | `800–1200 字符` | 城投党建文档多为段落式论述，该区间可保留单段核心信息不被割裂 |
| `chunkSplitter` | 按标题与段落拆分 | 党建文档多有明确标题层级，按此拆分可保证每个分块对应完整学习单元 |
| `customPdfParse` | 开启 | 城投党建文档多为带格式的PDF文件，开启后可保留标题层级与段落结构 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120–180 秒` | 长文档解析需要足够时间完成格式识别与内容提取，避免超时失败 |
| `chunkSettingMode` | 手动配置 | 城投党建文档格式差异较大，手动配置可灵活调整分块参数适配不同类型材料 |
| `UPLOAD_FILE_MAX_SIZE` | `500 MB` | 城投党建单份文档多不超过该大小，适配常规上传需求 |

## 容易做错的三处
- 现象：批量上传多个党建文档后，分块结果无法对应原始文件，搜索时出现跨文件的无关内容。原因：未配置按文件维度的分块分组规则，导致所有文件的解析内容混合存储。
- 现象：解析长文档时出现超时报错，界面显示解析超时提示。原因：配置的`PARSE_FILE_TIMEOUT_SECONDS`时长不足，未适配城投党建长文档的解析耗时。
- 现象：知识库搜索测试无法命中目标内容，搜索结果为空或偏离主题。原因：分块时未保留标题层级，导致问答模型无法关联上下文主题，或分块长度过大导致语义碎片化。

## 怎么确认配好了
- 上传单份典型党建文档，检查解析后的分块是否保留标题层级与段落完整性，调整对应参数至符合预期。
- 批量上传多份不同格式的党建材料，验证每份文件的分块结果可单独关联原始文件，无内容交叉混淆。
- 触发长文档解析任务，确认未出现超时报错，核对`PARSE_FILE_TIMEOUT_SECONDS`配置时长适配当前文档长度。
- 提交搜索测试，验证目标主题的分块内容可被准确召回，调整分块参数至搜索结果符合预期。
