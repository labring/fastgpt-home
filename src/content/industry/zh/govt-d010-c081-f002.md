# 基础化工的党建学习问答：向量模型与索引
本页面基于FastGPT v4.17.0版本进行配置说明。

## 这个品类的数据长什么样
基础化工领域的党建学习数据主要来源于国企化工单位的内部党建台账、月度党课课件、行业党建通报及支部学习记录。数据更新节奏为每月一次，随当月党建活动完成同步更新。文档以长文本为主，包含统一的章节编号、发布日期、所属支部等结构化字段，正文多为数千字符的连贯表述，部分文档包含化工领域专属术语与党建政策结合的内容，无固定格式模板。

## 这些特征在「向量模型与索引」这一环带来什么约束
基础化工党建文档的长篇幅特性，要求向量索引需结合章节边界进行分块，避免无差别硬切将完整党建表述切割为独立块；月度固定更新的节奏，使得索引可采用定时全量同步策略，无需实时增量更新，降低系统资源消耗；文档包含结构化字段的特性，要求索引时需指定党建专属字段作为检索范围，避免混入化工生产数据等无关内容；文档中跨领域术语结合的特点，要求向量模型需具备准确编码的能力，确保检索匹配的精准度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配基础化工党建文档的单章节篇幅，避免单块内容过于分散或冗余 |
| 重叠长度 | 100–150 字符 | 保留相邻分块的上下文关联，防止关键党建表述被切割 |
| `maxToken` | 4096 token | 匹配主流开源向量模型的输入上限，适配长文档分块后的拼接需求 |
| 相似度阈值 | 0.72–0.78 | 过滤低关联的通用表述，精准匹配基础化工党建的主题内容 |
| 单次搜索上限 | 前 6 条 | 覆盖该场景下常见的党建问题数量，避免遗漏关键检索结果 |
| `defaultToken` | 2048 token | 设定默认上下文长度，平衡检索结果完整性与模型调用成本 |

## 容易做错的三处
- 检索结果与提问无关且包含大量非党建内容：现象是界面返回的结果包含化工生产数据等无关信息，原因是未限定仅检索党建专属字段，误将全表数据纳入索引范围。
- 应用配置导出后无法正常导入：现象是导入后检索逻辑失效，关联知识库丢失，原因是未勾选知识库关联项的导出选项，导致配置与数据源脱节。
- 向量模型返回token超限报错：现象是日志显示`maxToken`超出限制，原因是分块长度设置过大，未适配基础化工党建文档的长篇幅特性。

## 怎么确认配好了
- 上传一篇标准基础化工党建文档，检查分块后的内容是否保留章节逻辑，无强制切割的关键党建表述。
- 提交党建相关提问，核对返回结果的相似度分值是否落在设定的阈值区间内，无明显低关联内容。
- 执行一次全量索引同步，检查同步耗时是否符合预期，无超时报错。
- 导出应用配置后重新导入，确认检索逻辑与知识库关联关系未发生变化。
