# 基础化工的党建学习问答：多轮对话与提示词

## 这个品类的数据长什么样
基础化工的党建学习问答数据主要来源于企业内部党建档案库、上级国资委及行业党委下发的正式文件、班组日常学习记录与党员心得体会。数据更新节奏随上级文件发布周期调整，内部学习记录每周同步更新。文档多为结构化格式，包含文件标题、发布单位、发布日期、正文内容、适用范围等字段，字段单位多采用标准公文格式，如发布日期以YYYY-MM-DD记录，文件编号以“[年份]XX号”格式标注，正文内容多为段落式文本，部分包含学习要点条目。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
数据来源分散且格式不统一，多轮对话需先对不同来源的内容做格式对齐，避免跨来源的元数据冲突。更新频率不稳定，提示词需定期触发数据同步校验，防止调用过时的党建文件内容。字段包含公文类元数据，多轮对话的`messages`数组拼接需保留发布单位、发布日期等关键信息，确保问答时能关联对应文件的合规性。基础化工场景下党建问答常涉及安全合规相关内容，提示词需明确限定仅使用已归档的内部数据，避免生成超出范围的内容。多轮对话的上下文长度需适配基础化工党建文档的平均长度，避免截断关键学习要点。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 对话记录保存时间 | 30–90 天 | 基础化工党建数据需符合国资监管的存档要求，保留周期匹配内部审计周期 |
| `chatId` 配置 | 绑定企业党建专属会话ID前缀 | 区分不同支部或班组的对话上下文，避免跨会话数据混淆 |
| 最大上下文长度 | 1500–2000 字符 | 基础化工党建文档多为结构化公文，过长上下文易导致冗余信息干扰 |
| 知识库权限控制 | 按部门角色划分访问范围 | 不同班组的党建学习内容需匹配所属支部的权限，防止涉密文件泄露 |
| 问题优化开关 | 开启 | 基础化工党建术语较多，优化后可提升多轮对话的上下文理解准确性 |
| `variables` 配置 | 预设党建专属变量如「当前支部」「学习周期」 | 实现多轮对话中动态关联对应支部的学习数据 |

## 容易做错的三处
- 现象为对话记录未按预期保存，或保存时长超出设置范围，原因是未在对应配置项中正确设置保存周期，或未绑定`chatId`导致会话上下文无法关联存档规则。
- 现象为知识库返回超出权限范围的基础化工涉密党建文件，原因是未配置按角色划分的知识库权限，或权限规则未匹配基础化工党建数据的涉密分级要求。
- 现象为多轮对话中上下文拼接出现冗余的非党建内容，原因是未在提示词中限定仅调用基础化工党建专属数据集，或最大上下文长度设置过长导致无关信息被纳入。

## 怎么确认配好了
- 发起一条测试对话，查看对话记录列表，确认会话保存时长符合预设周期。
- 使用不同角色账号发起对话，验证仅能访问对应权限范围内的党建知识库内容。
- 发起多轮连续提问，检查上下文是否能正确关联前序对话的党建术语与内容。
- 查看配置面板中的`variables`与`chatId`参数，确认已绑定基础化工党建专属的预设值。
