# 基础化工的党建学习问答：知识库检索与召回

## 这个品类的数据长什么样
基础化工领域国央企党建学习数据主要来自党委办公室存档的内部材料、上级党委下发的政策文件、内部党课课件、月度学习计划与台账。更新节奏集中在每月新增下发的政策文件、每季度更新的学习要点汇编。文档多为PDF、Word格式的长文本，部分为结构化Excel台账，字段包含文件编号、发布单位、发布日期、学习主题，单位为篇、份与标准日期格式。

## 这些特征在「知识库检索与召回」这一环带来什么约束
长文本党课课件与政策文件需要合理分块，避免跨段落的上下文断裂影响语义召回精度。结构化Excel台账包含多列权限相关字段，要求检索支持按发布单位过滤，匹配不同子公司的党建资源权限。大量官方话术类文本的语义相似度分布集中，原始检索排序容易出现偏差，需要额外的重排环节修正。批量上传的大文件易触发索引超时，需要调整单批次上传数据量阈值。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `similarity` | 0.65–0.72 | 基础化工党建文本的语义相似度集中在该区间，可过滤低相关的通用话术结果 |
| `limit` | 前10条 | 党建学习问答需精准匹配核心内容，前10条结果可覆盖绝大多数用户需求 |
| `searchMode` | 混合检索 | 兼顾关键词匹配与语义召回，适配党建政策文件的固定术语与灵活提问场景 |
| `usingReRank` | 开启 | 修正基础化工党建文本中官方话术导致的原始相似度排序偏差 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充党建领域的同义词与术语扩展，提升冷门政策问题的召回率 |
| `collectionIds` | 对应企业专属党建知识库ID | 按所属企业划分知识库集合，实现资源权限隔离 |

## 容易做错的三处
- 知识库上传后状态长期停留在索引中：界面显示索引进度条无变化超过10分钟，原因是基础化工党建文档多为长PDF或批量上传的多列Excel台账，单批次数据量过大，超出默认索引处理阈值。
- 检索结果排序异常，低分数结果排名靠前：返回结果中`similarity`分数为0.5208的条目排在1.2717的条目之前，原因是未开启`usingReRank`重排功能，基础化工党建文本多为标准化官方话术，原始语义相似度计算易出现误判。
- 无法导入Excel格式文件或CSV列数超出限制：上传Excel文件时提示格式不支持，上传CSV文件时仅前两列被索引，原因是未配置支持多列结构化数据的解析规则，基础化工党建学习台账通常包含学习日期、参会人员、学习主题等多列字段，默认CSV解析仅支持两列数据。

## 怎么确认配好了
- 上传单份10页的党建PDF文档，查看索引状态在5分钟内完成，无超时报错提示。
- 输入党建相关问题，核对返回结果的排序逻辑，低`similarity`分数的结果不会排在高分数结果之前。
- 上传多列CSV格式的党建学习台账，确认所有字段被正确索引并可按字段过滤检索。
- 配置`collectionIds`后，仅检索指定党建知识库的内容，排除其他业务板块的非党建数据。
