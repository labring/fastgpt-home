# 基础化工的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
基础化工领域党建学习问答的数据来源为内部党建档案库、行业党委统一配发的学习资料、专项党建活动课件。更新节奏为季度例行更新，配合上级党建主题活动时按需追加内容。单篇文档包含标题、正文、发布机构、发布日期四个字段，正文以规范公文格式为主，单篇长度多在800-4000字符区间。

## 这些特征在「分享与嵌入」这一环带来什么约束
文档长度跨度较大，嵌入时的上下文截取配置需覆盖800-4000字符的内容，避免截断关键表述。文档附带发布机构、日期字段，分享链接需默认携带元数据展示参数，确保嵌入后信息完整。更新节奏灵活，分享链接的缓存有效期需匹配更新周期，避免展示过时内容。内部使用场景下，嵌入环节需配置权限校验参数，防止未授权访问内部党建资料。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `shareId` | 与基础化工党建知识库绑定的唯一标识 | 用于精准定位专属问答内容，确保分享与嵌入的指向性 |
| 分享链接缓存有效期 | 7200–86400 秒 | 匹配季度更新周期与临时任务的发布节奏，避免缓存过时内容 |
| 嵌入页面权限控制 | 仅内部IP白名单 | 适配基础化工党建资料的内部使用场景，防止未授权访问 |
| URL参数传递开关 | 开启 | 支持通过URL带入全局变量，满足灵活调用需求 |
| 元数据展示开关 | 开启 | 保留发布机构、发布日期字段，确保党建学习内容的权威性与时效性 |
| 嵌入容器尺寸适配 | 100%宽度、600–1200 像素高度 | 适配不同场景下的页面嵌入需求 |

## 容易做错的三处
- 现象：嵌入后出现「iframe主动中断主应用代码在子应用运行」报错。原因：嵌入容器尺寸设置超出父页面承载范围，或权限校验参数配置冲突导致跨域拦截。
- 现象：分享链接无法通过URL参数带入全局变量。原因：未开启URL参数传递开关，或参数命名不符合平台规范。
- 现象：嵌入页面展示的党建内容缺少发布日期字段。原因：元数据展示开关未开启，或缓存有效期过长导致元数据未同步更新。
