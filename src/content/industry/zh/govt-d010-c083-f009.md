# 基础设施建设的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
基础设施建设领域的党建学习数据主要来源于项目临时党支部的台账、施工班组学习记录、上级党委下发的党建材料及项目开工、竣工等节点的专题学习文档。数据更新随项目施工节点与月度支部学习计划浮动，无固定周期。文档多为PDF、Word格式，结构包含学习主题、主讲人、学习时长（单位：小时）、签到编号、标段名称、施工区域等字段，部分文档附带配套学习课件附件。

## 这些特征在「模型接入与配置」这一环带来什么约束
首先，数据包含标段、施工区域等项目专属标注字段，要求模型接入时需绑定对应项目的专属知识库，避免跨标段党建内容混淆。其次，单篇党建文档篇幅较长，多为数千字符的会议纪要、学习课件，对上下文窗口容量提出明确约束。数据更新节奏随项目节点浮动，需配置可灵活调整的知识库同步周期，适配基建项目的党建学习更新节奏。结构化字段如学习时长、签到编号，需模型在问答时准确关联对应场景，因此需配置对应的上下文匹配规则，确保问答内容贴合项目实际。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配基建党建长文档的上下文需求，避免截断包含标段、施工区域的关键信息 |
| `maxTokens` | 2000–3000 token | 控制单轮回答的输出长度，适配党建问答的详细解释需求，避免超出接口限制 |
| `quoteMaxToken` | 1500–2000 token | 确保引用的党建文档片段完整覆盖学习主题、项目标段等核心内容 |
| `temperature` | 0.2–0.4 | 降低回答的随机性，保证党建问答内容的准确性与官方性，符合党建学习的严谨要求 |
| `AIPROXY_API_ENDPOINT` | 项目专属的内网代理接口地址 | 适配基建项目的专线访问需求，避免公网访问的安全风险 |
| `AIPROXY_API_TOKEN` | 项目专属的访问密钥 | 限制非授权访问，匹配基建项目的安全管理规范 |

## 容易做错的三处
- 现象：配置`AIPROXY_API_TOKEN`后，FastGPT后台无法显示接入的模型。原因：未将密钥的权限范围配置为允许访问基建党建专属的知识库接口，或密钥未及时更新。
- 现象：调用API返回的党建问答结果缺失项目标段信息。原因：`maxContext`取值过小，截断了包含标段标注的上下文文档片段。
- 现象：语音模型接入后出现连接超时报错。原因：未配置适配专线网络的`AIPROXY_API_ENDPOINT`，使用公网地址导致基建项目内网无法正常访问。

## 怎么确认配好了
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
1. 进入FastGPT的模型管理页面，查看已接入的模型列表，确认目标模型处于启用状态。
2. 发起一条包含项目标段、学习主题的测试问答，验证返回结果中包含对应项目的专属党建内容。
3. 调用外部API接口，传入预设的测试问题，检查返回的响应格式符合预设的结构要求。
4. 调整`temperature`参数为0.5，发起同一条测试问答，对比两次结果的差异，确认参数生效。
