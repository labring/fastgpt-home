# 大宗商品贸易的党建学习问答：部署与升级

## 这个品类的数据长什么样
大宗商品贸易领域的党建学习数据主要来自所属国央企商贸物流板块的官方党建档案、月度集中学习材料及行业党建政策通报。数据更新以月度固定更新为主，临时政策文件会即时同步。文档多为PDF或Word格式，包含文件标题、发布单位、发布日期、核心内容摘要等字段，单份文档长度从数千到数万字符不等，存储单位以MB计量。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `STORAGE_S3_ENDPOINT` | 国内合规的对象存储节点地址 | 大宗商品贸易党建数据需符合国内数据驻留要求，国内节点可保障数据合规性 |
| `MONGODB_URI` | 配置副本集连接串，分配1000 MB以上存储空间 | 党建文档数据量随月度更新累积，副本集可保障数据读写稳定性，预留空间可应对后续增量数据 |
| `REDIS_URL` | 配置带持久化的实例，内存配额不低于2048 MB | 需缓存高频访问的党建政策文件元数据，持久化可防止重启后缓存丢失，2048 MB可覆盖日均同步的文档元数据缓存需求 |
| `DB_MAX_LINK` | 设置为20–30 | 大宗商品贸易党建数据的召回请求量适中，该区间可平衡并发连接与服务器资源占用 |
| `FE_DOMAIN` | 填写国央企内部私有网络域名 | 部署场景为内部私有化使用，绑定内部域名可避免外部网络访问风险 |

## 容易做错的三处
- 现象：新建党建问答应用后触发问答时无返回结果，或返回内容与党建主题无关。原因：未配置`MONGODB_URI`的专属数据库实例，导致元数据与向量库关联失效。
- 现象：删除自建应用时提示network error，无法完成删除操作。原因：`FE_DOMAIN`配置为外部公网地址，而部署环境为内部私有网络，跨域请求被拦截。
- 现象：定时同步党建文档任务执行失败，日志显示存储权限异常。原因：`STORAGE_S3_ENDPOINT`配置的存储节点未开放内部网络访问权限，导致无法拉取新的党建材料。

## 怎么确认配好了
- 访问`FE_DOMAIN`绑定的内部地址，登录FastGPT后台，上传一份测试用的党建文档，检查存储节点是否能正常完成上传与存储。
- 执行数据库连接校验脚本，查看并发连接数是否稳定在`DB_MAX_LINK`配置的区间内，无连接超时或断开报错。
- 手动触发一次党建文档的增量同步任务，登录`REDIS_URL`对应的缓存实例，检查是否存在最新上传的文档元数据缓存。
- 新建一个测试用的党建问答应用，输入党建相关问题，验证召回结果与上传文档的内容匹配度符合预期。
