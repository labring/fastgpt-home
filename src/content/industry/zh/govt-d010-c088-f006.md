# 工程咨询监理的党建学习问答：引用来源与溯源

## 这个品类的数据长什么样
工程咨询监理领域的党建学习问答数据，主要来源于项目现场党建台账、企业内部党建工作手册、住建及国资监管部门发布的党建规范文件。数据更新节奏为每月一次，随项目党建活动开展同步新增内容。单份文档结构包含文件标题、发布单位、生效日期、适用监理场景、核心学习要点五个固定字段，无额外自定义单位，内容以规范性条文、学习任务清单为主。本文基于FastGPT v4.17.0版本编写。

## 这些特征在「引用来源与溯源」这一环带来什么约束
工程咨询监理党建学习数据分散在项目现场台账与监管部门文件中，导致引用溯源需同时关联项目编号与文件发布标识，避免跨项目混淆。数据每月更新的节奏，要求溯源环节需同步匹配知识库的最新索引版本，防止引用已失效的旧版规范。文档固定的字段结构，要求溯源时必须提取发布单位、生效日期作为溯源依据，仅依赖文件名无法区分同标题的不同项目文件。规范性条文为主的内容，要求溯源需标注对应的监理场景，确保引用的合规性与场景匹配度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | 工程咨询监理党建文档以规范性条文为主，单条引用的token量需适配内容长度，避免截断核心信息 |
| `responseData` | 包含文件名、发布单位、生效日期 | 匹配监理党建文档的固定字段结构，确保溯源信息完整可追溯 |
| `detail` | 开启 | 需展示文档核心学习要点，为引用内容提供场景化补充说明 |
| 单次搜索上限 | 前6条 | 监理党建相关知识库条目相对集中，过多搜索结果会增加上下文冗余 |
| 分块重叠长度 | 50–80 字符 | 适配党建文档的长段落结构，避免关键条文被分块截断 |

## 容易做错的三处
- 界面弹出“quote type error”报错。原因是引用时输入的变量格式未匹配工程咨询监理党建文档的固定字段结构，未按要求调用发布单位、生效日期等预设字段。
- 调用API返回的结果中未包含引用文件名。原因是未开启`responseData`配置，或未正确绑定监理项目的文档标识参数。
- 引用结果仅返回单条文档。原因是单次搜索上限设置为低于3的数值，未覆盖监理党建场景下的多文档关联需求。

## 怎么确认配好了
- 提交党建学习相关的测试问题，查看回复中是否包含预设的文档字段信息，如发布单位、生效日期。
- 调用API接口，检查返回的溯源字段是否包含文件名等必要信息。
- 调整配置项的取值，验证引用内容的完整性与准确性。
- 测试多变量引用场景，确认可关联多个监理党建文档的字段信息。
