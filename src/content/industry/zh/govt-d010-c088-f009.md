# 工程咨询监理的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
工程咨询监理的党建学习问答数据主要来源于企业内部党建台账、项目驻地的集中学习记录、上级党委下发的政策文件。数据更新节奏为每月同步上级新发布的党建政策，每季度更新内部学习纪要与项目专属学习资料。单篇文档多为完整政策原文、PPT课件转写文本，包含文件编号、发布单位、发布日期、适用监理标段等字段，部分文档附带项目驻地的区域标注与工期关联信息。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据包含监理标段、项目驻地、工期关联等专属字段，要求模型接入时支持按业务维度过滤召回的文档，避免跨标段的无关党建内容混入上下文。单篇文档存在较长的课件转写文本，要求配置时限制单条召回内容的长度，防止超出模型上下文窗口。数据更新节奏为月度同步上级政策、季度更新内部资料，要求模型调用时优先召回最新发布的文件，需配置检索的时间范围参数。部分文档附带项目专属标注，要求上下文保留原始字段，避免丢失业务关联信息，影响问答的针对性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配工程咨询监理党建文档的长度，避免截断关键的标段、政策原文信息，FastGPT v4.17.0版本默认值为4000 token，需手动调整至该区间。 |
| `maxTokens` | 1500–2000 token | 控制单轮问答的输出长度，符合党建学习问答的严谨性要求，避免生成冗余内容。 |
| `quoteMaxToken` | 300–500 字符 | 限制单条召回文档的引用长度，适配监理项目专属文档的分段特征，防止上下文溢出。 |
| `temperature` | 0.2–0.4 | 降低生成随机性，确保党建问答内容符合官方政策的表述风格，避免出现偏差。 |
| `AIPROXY_API_ENDPOINT` | 按部署服务商提供的国内模型接口地址填写 | 适配国内模型直连需求，解决跨区域调用的延迟问题，对应无效令牌报错的核心配置项。 |
| `toolChoice` | auto | 允许模型自动选择是否调用检索工具，适配包含项目标段信息的过滤需求，提升问答的业务针对性。 |

## 容易做错的三处
- 现象：调用国内模型时返回“无效令牌”错误，第三方接口测试工具可正常验证令牌有效性。原因：直连模型时未正确配置`AIPROXY_API_ENDPOINT`指向模型官方接口，误使用了第三方中转平台的配置参数。
- 现象：调用bge-reranker模型时，GPU显存占用随调用快速增长至6-7G，多卡环境下每张GPU均出现该问题。原因：未限制重排任务的并发调用数量，导致每个请求都单独加载模型实例，占用过多显存资源。
- 现象：党建学习问答页面弹出免登窗口，无法正常使用。原因：未在FastGPT系统配置中关闭公共访问弹窗，或未配置企业内部的身份验证规则。

## 怎么确认配好了
- 发起包含具体监理标段关键词的党建问题测试，检查返回结果是否仅匹配对应标段的党建文档，确认业务过滤配置生效。
- 调用包含长文档片段的问答，检查输出内容未出现强制截断，确认上下文与输出长度配置符合文档特征。
- 查看模型调用日志，确认无无效令牌、接口超时类报错，验证令牌与接口地址配置的正确性。
- 发起连续多轮问答请求，检查GPU显存占用未出现异常增长，确认重排模型的并发配置合理。
