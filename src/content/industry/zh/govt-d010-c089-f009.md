# 工程机械的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
数据来源为所属国央企装备制造板块的党建部门发布的学习资料、支部会议记录、党员学习档案，更新节奏为每月随新的党建工作要求同步更新。单篇文档多为结构化的文本文件，包含主题、发布时间、所属支部、学习要点四个固定字段，内容以政策原文、官方解读文稿为主，无复杂多媒体内容，篇幅集中在500至2000字符区间。

## 这些特征在「模型接入与配置」这一环带来什么约束
党建学习数据的固定字段与更新节奏，会对模型接入配置带来多维度约束。首先，文档包含四个固定字段，配置时需明确上下文提取的关联维度，确保召回内容匹配党建业务的场景需求。其次，单篇文档篇幅适中，无需过大的上下文窗口限制，避免浪费计算资源。每月同步的更新节奏要求向量库的增量更新周期匹配该频率，避免数据滞后或冗余。最后，无多媒体内容的特征，无需开启视觉相关的模型配置项，简化配置流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 800–1200 字符 | 匹配工程机械党建学习单篇文档的平均篇幅，避免上下文溢出 |
| `maxTokens` | 1500–2000 token | 适配党建问答的回复长度需求，确保覆盖完整的政策解读内容 |
| `quoteMaxToken` | 300–500 token | 限制单条召回文档的引用长度，贴合党建学习资料的段落结构 |
| `temperature` | 0.2–0.4 | 降低随机性，确保党建问答的回复符合官方政策表述的严谨性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写本地API地址 | 适配本地部署的模型调用需求，确保数据链路可控 |
| `AIPROXY_API_TOKEN` | 自定义加密字符串 | 保障模型调用的身份验证安全，符合国央企数据安全要求 |

## 容易做错的三处
- 现象为当党建知识库为空时，工作流未触发兜底逻辑，直接返回无匹配结果，原因是未配置空知识库的 fallback 调用设置。
- 现象为调用模型时返回401未授权错误，日志显示API令牌校验失败，原因是`AIPROXY_API_TOKEN`配置值与部署的代理服务不匹配。
- 现象为向量库召回结果条数异常，原因是`maxContext`配置值超出模型的上下文处理上限，导致召回逻辑被阻断。

## 怎么确认配好了
- 登录FastGPT v4.17.0后台的模型配置页面，核对`maxContext`、`temperature`等参数的取值是否与预设配置一致。
- 上传一篇测试用的党建学习文档，触发问答测试，检查返回结果中是否包含匹配的知识库引用。
- 清空测试知识库，触发问答请求，检查是否触发了兜底的大模型调用逻辑。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`的调用请求正常返回200状态码。
