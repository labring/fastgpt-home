# 工程机械的党建学习问答：知识库检索与召回

## 这个品类的数据长什么样
工程机械领域党建学习数据主要来源于装备制造国央企的内部党建台账、月度更新的行业党建规范文件、一线班组的学习记录。文档多为PDF格式的政策原文、PPT格式的学习课件、结构化的问答手册，包含文件编号、发布单位、发布日期、适用作业场景等字段，课件附带时长标注，单份文档大小多在10–500 MB区间，更新频率为每月一次，新政策发布时会临时追加更新。

## 这些特征在「知识库检索与召回」这一环带来什么约束
工程机械党建数据包含结构化政策字段、图文类学习课件与问答手册，多份单文档体积较大，要求检索系统支持多模态内容匹配与结构化字段关联。月度更新的频率要求检索链路支持增量同步，避免全量重建带来的资源占用。一线班组的学习记录多为口语化内容，要求召回模型适配口语化提问与专业术语的对齐，同时需过滤无关的作业参数内容，确保检索结果聚焦党建主题。

## 配置怎么定
本章节配置基于FastGPT v4.17.0版本适配，具体参数如下：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.72–0.80 | 过滤与党建主题无关的工程机械作业参数内容，聚焦语义匹配度达标结果 |
| `limit` | 前6条 | 适配单份文档体积较大的场景，控制单次召回的上下文总长度 |
| `searchMode` | hybrid | 结合语义检索与结构化字段匹配，适配包含政策编号、发布日期的结构化党建文档 |
| `usingReRank` | 开启 | 优化图文混合的党建学习课件的召回排序，提升内容相关性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 对一线班组的口语化提问进行语义扩展，匹配更贴合党建学习的召回结果 |
| `collectionIds` | 仅指定党建学习专属集合 | 隔离其他业务知识库的内容，避免检索结果混入非党建类文档 |

## 容易做错的三处
- 现象：导入xlsx格式的党建学习台账后，检索结果无法匹配表格内的结构化条目。原因：未开启文档扩展解析功能，未正确配置表格内容的语义分块规则。
- 现象：上传包含图文的党建学习课件后，无法召回图片关联的文字内容。原因：未启用多模态检索配置，未开启图文解析开关。
- 现象：更换嵌入模型时出现报错，提示模型匹配异常。原因：未使用FastGPT官方支持的嵌入模型，或未同步更新检索链路的模型绑定配置。

## 怎么确认配好了
- 上传一份测试用的xlsx党建台账，发起包含台账内政策条目的提问，核对是否能召回对应内容。
- 上传一份带图文的党建课件，发起针对课件内图片主题的提问，核对是否能召回关联内容。
- 发起包含口语化表述的党建学习提问，核对召回结果是否聚焦党建主题，未混入无关内容。
- 调整对话配置中的引用显示开关，发起提问，核对返回结果是否符合预期的引用展示状态。
