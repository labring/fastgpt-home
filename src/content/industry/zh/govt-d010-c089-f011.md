# 工程机械的党建学习问答：表单与交互

## 这个品类的数据长什么样
工程机械党建学习相关的数据，来源为国央企装备制造板块的基层党建台账、施工班组月度学习记录、设备运维关联的党员学习档案、项目党建联建材料。更新节奏为按月更新，每批次更新对应月度的班组学习完成情况与考核数据。文档结构分为班组学习签到表、月度学习总结、设备配套党建学习手册、党员打卡记录四类，字段包含班组ID、设备编号、学习主题、完成时长、打卡时间、考核得分，时长单位为分钟，打卡时间为标准日期格式，考核得分为百分制数值。

## 这些特征在「表单与交互」这一环带来什么约束
工程机械党建学习数据的关联字段、更新节奏与文档结构，对表单与交互环节带来明确约束。首先，数据包含班组ID与设备编号的关联字段，要求表单必须支持按设备或班组维度筛选关联党建数据，避免跨项目的无效数据加载。其次，数据按月更新，要求交互环节支持按时间范围拉取对应批次的学习材料，适配国央企党建台账的归档节奏。第三，文档分为四类固定结构，要求表单预设对应分类的选择项，减少手动输入的误差。第四，字段包含时长、得分等数值型内容，要求交互环节支持基础数值校验，避免无效数据录入。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 绑定设备编号、班组ID字段 | 匹配党建学习台账的核心关联标识，实现数据自动关联 |
| `userSelect` | 预设党员姓名、班组名称选项 | 减少手动输入的格式误差，适配基层党建的人员结构 |

| 单次问答上限 | 前3条 | 匹配班组单次学习的讨论与问答频次 |
| 上下文窗口 | 1500 token | 适配单班组月度学习的内容总量 |
| 超时阈值 | 60 秒 | 适配国央企内网的常规访问延迟情况 |

## 容易做错的三处
- 现象：问答对提取结果拆分混乱，出现跨文档的无关内容。原因：未先按文档结构拆分内容，直接使用QA拆分引导词处理整批数据。
- 现象：节点提示词未在每次用户输入时生效，问答结果偏离党建主题。原因：未将提示词挂载到对应交互节点，仅在全局配置中设置。
- 现象：全局变量调试后为空，无法关联设备相关的党建数据。原因：未绑定工程机械党建数据的关联字段作为变量来源，仅使用通用占位符。

## 怎么确认配好了
- 提交包含设备编号与班组名称的测试表单，检查是否自动加载对应班组的党建学习材料。
- 选择预设的分类选项，确认交互弹窗仅加载对应类别的学习文档。
- 触发问答提取功能，检查输出的问答对均来自当前加载的文档内容。
- 模拟超过60秒的延迟场景，确认系统返回合理的超时提示信息。
