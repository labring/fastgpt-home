# 成品油销售的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
成品油销售领域的党建学习数据主要来源于上级党委下发的学习文件、各销售站点的党日活动档案、党员学习签到记录与心得报告。数据来源分为固定下发的标准化课件与实时更新的站点一线记录，更新节奏为上级文件按季度同步，站点记录按月度更新。文档格式包含PDF课件、Word活动台账与纯文本心得，结构上分为学习主题、参会人员、学习时长（单位：小时）、考核得分等固定字段，部分课件包含活动现场照片与宣传海报。

## 这些特征在「模型接入与配置」这一环带来什么约束
党建学习数据包含多格式文档与结构化、非结构化混合内容，要求模型支持多源数据解析与字段精准匹配。带图片的课件需模型具备多模态识别能力，确保问答可关联图片内容。站点数据分散在不同层级的存储节点，接入时需适配跨源数据拉取逻辑。固定字段的标准化要求模型召回时精准匹配主题、时长等字段，避免混淆非党建类业务数据。月度与季度的更新节奏需配置定期同步的触发规则，保证问答数据的时效性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `vision` | 开启 | 党建课件常包含活动照片、宣传海报，需模型识别图片内容以完整回答相关问题 |
| `maxContext` | 8000–12000 token | 党建学习问答需关联多份课件与活动记录，保留足够上下文保证回答的连贯性 |
| `maxTokens` | 2000–3000 token | 党建问答需输出详细解读，同时避免过长导致的API调用超时 |
| `quoteMaxToken` | 4000 token | 需召回足够的党建文档片段作为引用依据，确保回答符合党建内容的严谨性要求 |
| `temperature` | 0.2–0.4 | 党建问答需保持严谨准确，不宜过度发散，避免偏离官方内容 |
| `AIPROXY_API_ENDPOINT` | 按内部部署的代理地址填写 | 适配国央企内部网络环境，通过代理转发API请求 |
| `AIPROXY_API_TOKEN` | 填写代理分配的专属令牌 | 验证API调用的合法权限，确保内部数据访问安全 |

## 容易做错的三处
- 重启FastGPT服务后，API渠道与令牌配置丢失，原因是未将配置存储至本地持久化目录，仅临时保存在内存中。
- 上传包含图片的党建PDF后，模型无法识别图片内容，原因是未开启`vision`配置项，或未使用支持多模态能力的模型。
- AI对话输出的内容无法通过工作流其他模块二次处理并回显至对话框，原因是未配置工作流的输出转发规则，仅启用了原生AI对话的直接输出。

## 怎么确认配好了
- 上传包含活动照片的党建课件PDF，发起关于图片内容的问答，核对模型能否正确描述图片细节。
- 发起党建主题相关的问答，检查输出内容是否附带对应的文档片段引用，确认召回逻辑生效。
- 重启FastGPT v4.17.0服务后，查看API代理的端点与令牌配置是否仍保留，确认持久化生效。
- 调整`temperature`参数后发起问答，观察回答的严谨程度是否随参数变化，确认配置生效。
