# 成品油销售的党建学习问答：部署与升级

## 这个品类的数据长什么样
这个品类的数据主要来源于石油石化系统内部党建管理平台、上级党委下发的正式文件、一线加油站的学习记录汇编。更新节奏遵循上级党建工作部署，常规学习资料按季度更新，临时学习任务触发即时更新。文档结构分为政策类文件（带文号、发布主体、生效范围）、学习解读材料（分要点、思考题）、标准化问答题库（带题型、考核等级），字段包含发布单位、适用层级、发布日期，无额外自定义单位字段。

## 这些特征在「部署与升级」这一环带来什么约束
由于党建数据存在明确的适用层级、发布主体与固定结构，部署时需针对不同层级的加油站站点配置数据访问权限，避免跨层级的无效数据推送。临时更新的特性要求升级流程保留增量数据同步接口，支持快速接入新的学习材料。标准化问答题库的固定字段格式，要求部署时预设对应的数据解析模板，减少后续数据导入的适配成本。同时，数据多来源于内部党建管理平台，部署环节需配置内部系统的对接权限，适配现有数据流转链路。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定，适配成品油销售党建学习问答的部署需求。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:port/database?authSource=admin` | 适配内部党建数据的结构化存储需求，确保多站点数据隔离 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 用于缓存高频访问的党建问答数据，降低数据库负载 |
| `STORAGE_S3_ENDPOINT` | `http://internal-storage.sales-petro.com:9000` | 对接内部对象存储服务，存储党建文件与题库附件 |
| `DB_MAX_LINK` | `200–300 连接` | 适配多站点并发访问的数据库连接需求，避免连接耗尽 |
| `FE_DOMAIN` | `https://dangjian.sales.sinopec.com` | 配置党建问答模块的访问域名，匹配内部业务域名规范 |
| `FILE_TOKEN_KEY` | `32位随机字符串` | 用于加密文件上传请求，防止未授权的党建材料上传 |

## 容易做错的三处
- 现象：升级后上传党建文件或文本数据集失败，但模版导入功能可正常上传文件。原因：未正确配置`STORAGE_S3_ENDPOINT`的内部存储权限，导致非模版文件的上传请求无法通过内部存储校验。
- 现象：部署后出现`Failed to parse URL from /model/getProviders`报错。原因：未正确配置`MONGODB_URI`或`REDIS_URL`的连接参数，导致系统无法初始化模型服务依赖的存储链路。
- 现象：尝试建立索引模型渠道时，无法正确解析导入的党建题库。原因：未预设对应党建数据结构的解析模板，导致导入的题库无法被正确索引。

## 怎么确认配好了
- 执行内部党建数据的批量导入测试，核对导入后的数据字段与原始文档结构一致。
- 发起跨层级的问答请求，验证不同层级的站点只能访问对应权限的党建学习内容。
- 重启服务后检查系统日志，确认`MONGODB_URI`、`REDIS_URL`等配置项无连接报错。
- 上传非模版类的党建文件，验证上传与索引流程正常完成。
