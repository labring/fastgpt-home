# 房建工程总承包的党建学习问答：文档解析与分块

## 这个品类的数据长什么样
房建工程总承包的党建学习相关数据主要来自项目支部的学习台账、上级住建系统党委下发的红头文件、现场临时学习PPT、语雀或飞书共享的学习纪要。数据更新节奏随项目节点调整，日常月度支部学习材料每月更新，季度性党建考核文件每季度更新，临时应急学习材料按需发布。文档类型包含带内嵌图片的PDF、结构化Excel打卡表、在线富文本文档，字段包含文件编号、发布单位、学习主题、参与人次、学时时长。

## 这些特征在「文档解析与分块」这一环带来什么约束
房建工程总承包的党建学习数据特征，对文档解析与分块带来多重约束。带内嵌图片的红头文件、学习PPT，需要完整提取图片中的文字与标注内容，否则会丢失学习要点的完整信息。结构化Excel打卡表包含参与人次、学时时长等数值字段，分块时需保留字段与对应学习记录的关联，避免拆分后数据脱节。临时发布的应急学习材料格式不统一，需适配多种数据源的解析规则。批量月度台账文档的累积，要求解析与分块流程需适配合理的大小与超时限制。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ------ | -------- | ------------ |
| `chunkSize` | 800–1200 字符 | 房建党建文档包含学习主题、纪要内容与打卡数据，该长度可保留单条学习活动的完整上下文，避免分块割裂关联信息 |
| `chunkSplitter` | 按段落+标题拆分 | 党建文档多有明确的章节标题与段落划分，按此拆分可保留学习内容的逻辑结构，避免打乱学习流程的上下文关联 |
| `customPdfParse` | 开启 | 房建党建文档常内嵌图片与批注，开启自定义PDF解析可完整提取图片文字内容，解决图片无法传递给大模型的问题 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配项目大型党建培训PPT与批量台账文档的大小上限，避免因文件过大无法完成上传 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 预留足够时间用于批量解析大型文档，避免因超时导致解析任务中断 |
| `chunkSettingMode` | 手动配置 | 针对党建文档的结构化与非结构化混合内容，自定义分块规则适配不同类型数据源 |

## 容易做错的三处
- 现象：解析语雀公开分享链接时，界面返回“不支持的链接格式”报错，解析任务失败。原因：未确认语雀链接为公开可访问的知识库专属链接，误使用了带权限限制或非知识库类的链接。
- 现象：上传带内嵌图片的党建PDF文档后，大模型检索结果未包含图片中的文字内容。原因：未开启`customPdfParse`配置，使用默认解析模式无法提取图片内嵌文字。
- 现象：批量上传Excel党建打卡表后，解析结果中参与人次、学时等数值字段为空。原因：未配置结构化数据解析规则，数值字段被误判为无意义文本过滤。

## 怎么确认配好了
- 上传一份带内嵌图片的党建PDF文档，查看解析后的文本内容是否包含图片中的文字标注，确认`customPdfParse`配置生效。
- 上传语雀公开分享的党建学习文档链接，检查解析任务是否正常完成，无格式报错，确认数据源类型适配。
- 上传单份大小接近配置上限的党建培训PPT，确认上传与解析流程未触发超时或文件大小限制报错。
- 调整分块参数后解析同一份党建纪要文档，对比分块结果的上下文完整性，确认分块规则符合业务需求。
