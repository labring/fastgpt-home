# 政企信息化服务的党建学习问答：文档解析与分块

## 这个品类的数据长什么样
本品类的数据主要来自国央企、政府及公共服务机构的党建内部管理系统、学习平台存档文件。数据更新以月度常规同步为主，伴随临时政策下发、专题学习材料追加的不定期更新。文档类型包含正式政策pdf、带内嵌学习照片的excel台账、结构化会议纪要word及标准化党建手册，字段涵盖文件标题、发布主体、生效日期、正文内容、内嵌图片资源与附件关联标识，无统一固定格式，存在大量非标准化排版内容。

## 这些特征在「文档解析与分块」这一环带来什么约束
非标准化的文档排版会导致通用解析模块无法准确识别段落边界，增加分块的语义割裂风险。带内嵌图片的excel台账需额外处理图片提取与关联，避免解析后丢失可视化学习素材。单次上传文件可能包含多份党建材料，需支持多文档批量解析的上下文隔离。不同字段的信息权重存在差异，正文内容需优先作为分块主体，而图片、附件标识需单独关联至对应文本块，避免语义错位。同时不定期的临时材料更新要求解析流程具备快速适配新格式的灵活性。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `UPLOAD_FILE_MAX_SIZE` | `2000 MB` | 适配党建材料中可能包含多份高清图片的大型excel、pdf文档，避免上传截断 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `900 秒` | 覆盖大型多页pdf、内嵌大量图片的excel的解析耗时，避免中途超时中断 |
| `customPdfParse` | `启用` | 适配党建文档常见的页眉页脚、自定义章节编号等非标准排版，提升段落识别准确率 |
| `chunkSplitter` | `按段落+语义分割` | 贴合党建材料的章节、段落语义逻辑，避免生硬拆分导致语义断裂 |
| `chunkSize` | `800–1200 字符` | 平衡上下文完整性与检索精度，适配党建内容的长段落表述习惯 |
| `chunkSettingMode` | `手动配置` | 允许针对不同类型的党建文档（如政策文件、学习台账）调整分块参数，适配多样数据结构 |

## 容易做错的三处
- 现象：上传带内嵌图片的excel党建台账后，解析结果仅包含文本内容，无图片关联信息，无法将图片同步发送至大模型。原因：未启用针对excel内嵌资源的解析开关，仅提取了表格文本未同步关联图片资源。
- 现象：上传党建政策pdf后，解析生成的markdown格式混乱，标题与正文错位，章节层级丢失。原因：未启用`customPdfParse`配置，使用通用解析模块无法适配党建文档常见的页眉页脚、自定义章节编号等特殊排版格式。
- 现象：上传超过500页的大型党建手册时，解析任务触发后长时间无响应，最终返回超时报错。原因：`PARSE_FILE_TIMEOUT_SECONDS`设置值过低，未覆盖多页文档的完整解析耗时。

## 怎么确认配好了
- 上传一份包含内嵌学习照片的excel党建台账，检查解析结果中是否包含图片的关联标识或可调用的资源链接。
- 上传一份带有自定义页眉页脚的党建政策pdf，检查解析后的markdown文本是否准确保留了章节层级与核心正文内容。
- 调整`chunkSize`参数后，对比不同取值下的分块结果，确认语义完整性符合业务检索需求。
- 上传一份超过1500 MB的大型文档包，确认上传与解析流程未出现截断或超时报错。
