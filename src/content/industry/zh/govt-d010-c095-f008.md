# 新能源开发的党建学习问答：文档解析与分块

本页面配置说明基于FastGPT v4.17.0版本。

## 这个品类的数据长什么样
新能源开发领域的党建学习数据主要来源于内部党建工作平台、新能源项目配套的支部活动档案、上级党委下发的政策文件，以及飞书、语雀等协作工具中的内部文档。数据更新节奏为月度更新支部活动记录、季度更新标准化学习手册，不定期同步最新党建政策。文档类型涵盖带内嵌图片的学习课件、带统计表格的党费台账、纯文本的学习心得，以及多维文档形式的党员发展进度表。字段包含文档标题、发布日期、所属项目支部、活动参与人次，单位涉及人次、季度、元等。

## 这些特征在「文档解析与分块」这一环带来什么约束
新能源党建文档包含内嵌图片的课件、多列结构的台账表格，以及跨平台的协作链接，要求解析环节需覆盖图片文本提取、多格式文件解析与合法数据源识别。长文本的项目党建学习材料与大型台账文件，会增加解析耗时与分块难度，需调整分块规则以保留语义完整性。不同数据源的格式差异，要求解析配置需适配语雀公开链接、飞书多维文档等多种输入类型，避免出现解析失败或内容丢失的情况。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 1000–1500 字符 | 新能源党建文档多为带政策条款、活动记录的长文本，分块过长会破坏上下文关联，过短会增加token消耗，按该品类文档的平均结构实测标定 |
| `chunkSplitter` | 按段落+标题拆分 | 党建文档有明确的章节标题与段落划分，按段落拆分可保留语义完整性，适配后续问答的精准匹配需求 |
| `customPdfParse` | 启用OCR模式 | 部分党建课件为扫描件或内嵌图片格式，启用OCR可提取图片中的文字内容，避免丢失图片承载的党建学习信息 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 新能源党建文档可能包含大型Excel台账或多维表格文件，放宽上传上限可支持完整导入完整的业务与党建关联数据 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 大型多维表格或长文档的解析耗时较长，设置600秒可避免中途超时中断解析流程 |
| `chunkSettingMode` | 手动配置 | 需针对新能源党建文档的特殊结构（如内嵌图片、多列表格）调整分块规则，手动配置比自动模式更灵活适配场景需求 |

## 容易做错的三处
- 现象：解析后的知识库未包含内嵌图片的文本内容，大模型无法调用图片中的党建学习信息。原因：未启用`customPdfParse`的OCR模式，仅提取了文档的纯文本内容。
- 现象：上传语雀公开分享链接后提示解析失败，无法生成知识库条目。原因：未确认链接为公开可访问的单文档链接，或链接类型为团队空间首页、文件夹等非文档类地址。
- 现象：导入飞书多维文档后，部分列的党建统计数据未被索引。原因：未开启飞书知识库的多维文档解析权限，或分块规则未适配多维表格的多列结构。

## 怎么确认配好了
- 上传一张带内嵌图片的党建课件PDF，查看解析后的文本内容是否包含图片中的文字信息。
- 粘贴一个公开可访问的语雀文档链接，确认解析状态显示为成功并生成对应知识库条目。
- 上传一个小型飞书多维表格文件，确认所有列的党建相关数据均被正确索引。
- 上传一个100MB左右的Excel党建台账，确认解析过程未出现超时提示。
