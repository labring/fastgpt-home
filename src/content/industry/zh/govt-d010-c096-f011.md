# 有色金属冶炼的党建学习问答：表单与交互
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这个品类的数据长什么样
有色金属冶炼领域的党建学习数据主要来源于所属国央企党委的内部党建知识库、冶炼行业党委发布的《冶炼企业党建工作规范》《党员学习手册》等文件。数据更新节奏为每季度同步一次，单篇文档多为5000-15000字符的结构化文本，包含文件编号、发布单位、发布日期、学习主题等字段，部分配套的政策解读文档会附带PDF格式的附件，单文件大小多在1-5 MB区间。

## 这些特征在「表单与交互」这一环带来什么约束
数据的结构化字段要求表单需支持绑定指定字段作为默认值，避免重复录入党建学习相关的固定信息；季度更新的同步节奏要求表单的数据源配置需匹配季度同步周期，确保展示的学习内容为最新版本；PDF附件的存在要求表单需支持二进制流或base64格式的文件上传组件，适配附件提交需求；冶炼行业党建内容的专业属性要求表单需内置行业术语提示，降低输入错误率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 绑定党建学习主题字段为默认值 | 匹配结构化数据的字段属性，减少手动录入 |
| `userSelect` | 限定为冶炼厂党委下辖支部范围 | 适配国央企党建的分级管理要求 |
| 文件上传配置 | 支持PDF格式，单文件上限 5 MB | 匹配现有附件的大小区间，避免资源溢出 |
| 超时阈值 | 60 秒 | 适配大附件上传的传输时长需求 |
| 默认值引用规则 | 引用全局变量中的当前用户所属支部 | 实现个性化的党建学习表单推送 |

## 容易做错的三处
- 表单默认值无法正确引用全局变量，表现为界面显示为空或默认值未更新。原因是未正确绑定结构化数据的字段路径，未匹配全局变量的命名规则。
- 文件上传失败，表现为提示“文件格式不支持”或上传进度卡住。原因是未配置支持PDF格式的上传白名单，或未适配base64格式的二进制流输入。
- 表单提交后学习内容未同步更新，表现为展示的文档为旧版本。原因是未将表单的数据源同步周期设置为与季度更新节奏匹配。

## 怎么确认配好了
- 打开表单配置页面，检查`formInput`节点是否绑定了预设的党建学习字段，查看默认值是否正确加载。
- 测试上传PDF格式的文件，确认系统可以接收并解析二进制流或base64编码的文件内容。
- 切换不同支部的测试账号，确认`userSelect`组件仅展示对应范围内的支部选项。
- 手动触发数据源同步，检查表单关联的学习文档是否更新为最新版本。
