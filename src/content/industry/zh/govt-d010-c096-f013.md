# 有色金属冶炼的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
有色金属冶炼领域的党建学习问答数据，主要来源于企业内部党建工作台账、集团党委下发的行业党建指导文件、有色金属冶炼专属的党建政策汇编。数据更新节奏为每月同步内部党建活动记录，每季度更新行业政策与实操案例文档。单篇文档结构包含标题、发布主体、发布日期、适配场景字段，内容覆盖冶炼车间党建规范、安全生产党建联动、党员先锋岗实操指南等，文档以结构化文本形式存储，单篇大小区间为100–500 KB。

## 这些特征在「分享与嵌入」这一环带来什么约束
有色金属冶炼党建学习数据的结构化场景字段，要求嵌入时保留场景关联配置，确保问答仅返回对应冶炼车间或业务线的党建内容。月度更新的内部台账数据，要求分享链接支持动态同步最新内容，避免出现过时的党建活动信息。专业术语密集的文档结构，要求嵌入界面默认保留中文界面，防止术语翻译偏差。企业内部使用的属性，要求支持调整免登录分享链接的创建数量，适配不同规模的党建学习小组需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 免登录分享链接创建数量 | `10–100 个` | 适配不同规模的党建学习小组，满足多车间、多支部的分享需求 |
| 分享界面语言 | 中文 | 有色金属冶炼党建内容包含大量专业术语，使用中文界面可避免翻译偏差，符合内部使用场景 |
| `shareId` | 绑定对应党建问答应用 | 确保分享的问答仅返回有色金属冶炼党建相关的内容，避免跨品类数据混淆 |
| 嵌入弹窗的自动加载触发 | 页面加载完成后延迟 2 秒触发 | 避免嵌入弹窗影响冶炼企业内网页面的加载速度，保障生产系统的流畅性 |
| 分享链接的有效期 | `30 天` | 匹配月度更新的党建台账数据周期，确保分享内容与最新内部记录同步 |

## 容易做错的三处
- 现象：嵌入后的对话框显示英文界面。原因：未将分享界面语言配置为中文，沿用了平台默认的英文设置。
- 现象：创建免登录分享链接时提示超出数量限制，无法创建第11个链接。原因：未调整免登录分享链接的创建数量配置，沿用了默认的10个上限。
- 现象：分享链接无法正常访问，提示身份验证失败。原因：未确认FastGPT v4.17.0版本的分享鉴权规则，错误沿用了旧版本的鉴权配置。

## 怎么确认配好了
- 打开配置好的嵌入代码，在测试页面加载后，点击弹窗触发按钮，检查界面是否为中文。
- 尝试创建免登录分享链接，确认创建数量未被默认限制拦截，可创建至所需数量。
- 复制`shareId`对应的分享链接，在浏览器中打开，检查返回的问答内容是否仅包含有色金属冶炼党建相关的内容。
- 等待30天后重新打开分享链接，检查是否提示链接过期或自动更新了最新的党建内容。
