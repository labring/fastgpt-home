# 核电运营的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
核电运营场景下的党建学习问答数据，主要来源于企业内部党建管理系统、党委下发的行业党建结合安全生产的专项文件、各班组的月度学习记录。数据更新节奏为月度更新班组学习内容，每季度更新党内法规及核电专属党建规范。文档结构多为带章节编号的正式文件，包含文件编号、发布部门、发布日期、适用班组等字段，部分文档附带学习考核要求、心得模板等附件，字段与单位均遵循国央企公文规范，无自定义非标准单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
党建数据的专属字段要求召回结果需匹配对应班组的学习内容，因此配置环节需支持按部门、班组字段过滤召回文档；长文档及附件的存在，要求上下文窗口需容纳足够多的召回片段，避免截断专业术语与关键要求；月度/季度的更新节奏，要求配置自动同步触发机制，确保知识库内容与官方文件保持同步；核电专属党建术语的存在，要求模型需适配行业专业词汇的语义理解，避免召回无关的通用党建内容。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 核电党建文档常包含多章节的学习材料，需容纳足够上下文匹配班组专属内容 |
| `maxTokens` | 2000 token | 党建问答需生成详细的学习指引与合规说明，避免截断关键内容 |
| `quoteMaxToken` | 1500 字符 | 需保留“两票三制”“核安全文化”等核电专属党建术语的完整表述 |
| `temperature` | 0.3–0.5 | 保持党建问答的严谨性，避免生成偏离官方文件的发散内容 |
| `AIPROXY_API_ENDPOINT` | 按部署节点填写 | 适配企业内部网络的API访问路径，保障数据传输安全 |
| `AIPROXY_API_TOKEN` | 绑定企业专属密钥 | 符合国央企数据安全合规要求，限制未授权访问 |

## 容易做错的三处
- 现象：知识库问答结果匹配度显著下降，返回结果未包含新导入的党建文件内容。原因：仅更新了模型配置，未触发原有文档的向量索引重新生成，导致向量库与新配置不匹配。
- 现象：调用问答接口返回结果仅依赖大模型通用知识，未引用企业内部党建文档。原因：未配置`toolChoice`为强制调用知识库召回，模型未检索专属数据。
- 现象：问答结果出现超出官方文件的发散内容，如未提及核电安全生产相关的党建要求。原因：`temperature`参数设置过高，模型生成了偏离合规要求的内容。

## 怎么确认配好了
- 上传一份核电运行部的专属党建学习文件，发起对应班组的学习提问，核对返回结果中包含该文件的具体章节与要求。
- 查看知识库的索引日志，确认向量生成任务已完成且无报错提示。
- 调用测试接口，检查返回结果中引用的文档字段包含发布部门、适用班组等专属信息。
- 调整`temperature`参数至不同区间，验证问答结果的严谨性是否符合预期。
