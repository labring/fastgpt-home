# 民航机场的党建学习问答：多轮对话与提示词

## 这个品类的数据长什么样
民航机场党建学习问答的数据来源于机场自有党建档案库、上级民航党建主管部门发布的公开文件。更新节奏随上级政策调整同步进行，每月至少更新一次。文档采用标准化党政公文格式，包含标题、主送机关、正文、附件说明等标准字段，每个文档附带发布单位、生效日期标识。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
民航党建文档的标准化格式要求多轮对话中不能随意拆分破坏文件结构，需保留完整的公文逻辑。专属的民航基层党建场景限定了问答的适用范围，提示词需明确区分通用党建内容与民航行业党建的具体要求。每月更新的数据源要求对话系统的知识库同步周期匹配更新节奏，避免出现内容过时的情况。多轮交互中需保留民航党建专属术语的上下文，防止模型混淆通用概念与行业专属表述。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配民航党建公文的段落长度，避免拆分破坏文件结构，FastGPT v4.17.0版本下该取值可平衡上下文完整性与检索效率 |
| 重叠长度 | 100–150 字符 | 保留跨块的党建术语上下文，防止多轮对话中术语断裂影响理解 |
| 最大上下文 | 前 8 轮对话 | 匹配民航党建问答的多轮交互深度，避免上下文过载导致模型响应异常 |
| `chatId` | 绑定机场党组织专属会话标识 | 区分不同支部的对话记录，防止会话归属混淆，保障权限校验正确 |
| 系统提示词 | 限定民航基层党建场景的问答模板 | 明确回答需结合民航行业党建的具体要求，避免生成通用党建的无关内容 |
| `variables` | 注入机场党建专属文件ID | 让模型优先读取对应知识库的内容，提升检索精准度 |

## 容易做错的三处
- 打开对话页面显示“没有权限操作此对话记录”，原因是未将`chatId`绑定至机场党组织的专属权限组，导致会话归属校验失败。
- 对话中触发文档读取时返回“未上传文件”提示，原因是未通过`variables`注入对应民航党建文档的唯一标识，模型无法定位知识库内的目标内容。
- 对话完成后无word下载入口，原因是未配置基于`messages`的会话内容导出触发规则，未绑定完整对话数据至导出任务。

## 怎么确认配好了
- 发起包含民航党建专属术语的首轮提问，检查对话上下文是否完整保留提问内容。
- 调用`chatId`相关接口查看会话归属，确认与目标党组织的权限组匹配。
- 触发文档读取操作，验证模型是否能正确读取对应民航党建文档的内容。
- 完成一轮多轮对话后，检查是否生成可点击的word下载链接。
