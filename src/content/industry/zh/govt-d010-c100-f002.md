# 油田工程服务的党建学习问答：向量模型与索引

## 这个品类的数据长什么样
油田工程服务的党建学习数据主要来自内部党建台账、上级党委下发的学习文件、岗位专属党建手册、现场主题党日活动记录。数据更新节奏不固定，上级文件随政策调整不定期更新，内部学习材料按月度或季度计划更新。单篇文档结构包含标题、正文、发布单位、关联岗位场景（如钻井队、修井队）、发布日期字段，部分文档包含表格、要点列表等格式，文档单篇长度从数百字符到数千字符不等。

## 这些特征在「向量模型与索引」这一环带来什么约束
油田党建数据包含大量行业专有名词，如三会一课、主题教育、党员责任区等，分块时需避免切割专有名词导致语义丢失。文档关联岗位场景的字段要求索引支持按场景过滤，缩小检索范围。数据更新节奏不固定，需支持增量索引更新，避免全量重建带来的资源消耗。长文档的分块需保留上下文关联，确保问答时能完整还原党建学习内容的逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| 分块长度 | 800–1200 字符 | 适配油田党建文档的段落长度，避免切割专有名词 |
| 重叠长度 | 100–150 字符 | 保留分块间的上下文关联，确保党建内容逻辑连贯 |
| `maxToken` | 8192 token | 适配FastGPT v4.17.0的向量模型输入上限，覆盖长文档分块的内容承载 |
| 相似度阈值 | 0.75–0.85 区间 | 过滤低匹配度的检索结果，聚焦有效党建学习内容 |
| 单次搜索上限 | 前 8 条 | 平衡检索召回率与响应速度，满足日常党建问答需求 |
| `defaultToken` | 4096 token | 设置默认上下文窗口，适配基础党建问答的内容展示 |

## 容易做错的三处
- 现象：向量化请求响应超时，或向量服务返回参数错误。原因：仅传入单文本切片发起请求，未启用批处理配置，未利用向量服务的batch处理能力。
- 现象：检索结果无法显示原始文档的分块位置信息，或分块索引字段为空。原因：未开启分块索引的元数据存储开关，未记录分块对应的原始文档路径与起始偏移。
- 现象：配置阿里multimodal-embedding-v1模型后，向量化请求返回格式错误。原因：未适配模型的输入输出格式，未正确配置模型的API调用参数。

## 怎么确认配好了
- 上传一篇包含专有名词的油田党建文档，查看分块预览界面，确认无专有名词被截断。
- 发起党建相关的测试查询，查看检索结果的元数据字段，确认分块索引信息完整。
- 配置自定义向量模型后，发起测试向量化请求，验证返回的向量维度与模型官方参数一致。
- 调整相似度阈值，观察检索结果的数量变化，确认阈值设置符合当前业务的召回需求。
