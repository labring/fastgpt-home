# 油田工程服务的党建学习问答：引用来源与溯源

## 这个品类的数据长什么样
油田工程服务的党建学习数据来源为内部党建工作文件、三会一课记录、岗位廉政教育材料及行业党建规范指南。更新节奏为每月同步一次，随月度党建学习计划更新。文档多采用PDF、Word格式，结构包含标题、正文、发布单位、发布日期、所属作业区等字段。字符数多在500至5000区间，部分音频转写的学习笔记附带时长单位。

## 这些特征在「引用来源与溯源」这一环带来什么约束
党建数据的固定发布单位与日期字段，要求溯源信息必须包含这些元数据，确保引用内容的官方性与可追溯性。月度更新的节奏要求知识库同步需匹配周期，避免引用过期的学习材料。文档的固定结构与字段，要求引用时需精准关联对应元数据，不能仅提取无标识的正文内容。部分长文档的分块需求，要求引用片段需保留上下文关联，避免断章取义影响学习内容的准确性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，其中`quoteMaxToken`对应最大引用token数配置，`responseData`对应返回来源字段配置，`detail`对应详情展示配置。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 最大引用token数 | 600–1000 token | 适配油田党建文档单段引用的字符量，避免截断关键内容 |
| 返回来源字段 | 包含发布单位、发布日期 | 匹配油田党建数据的固有字段，确保溯源信息完整 |
| 详情展示 | 开启 | 展示引用片段的前后关联内容，辅助验证引用的准确性 |
| 单次召回上限 | 前3条 | 避免过多引用导致内容冗余，符合党建学习问答的简洁要求 |
| 知识库同步频率 | 每月1次 | 匹配油田党建材料的月度更新节奏 |
| 溯源字段优先级 | 按发布单位+发布日期 | 贴合油田党建数据的层级与时间属性 |

## 容易做错的三处
- 界面展示的引用片段出现乱码。原因是未对油田党建文档中的专业术语、缩写（如作业区代码、党建专有名词）做编码适配，导致解析时出现字符转换错误。
- 回答中未显示知识库引用的来源信息。原因是未开启返回来源字段的配置，导致接口未返回对应的发布单位、发布日期等溯源字段。
- 引用内容超出回答篇幅导致排版混乱。原因是未限制最大引用token数的取值，导致引用片段过长，破坏问答的整体可读性。

## 怎么确认配好了
- 发起党建相关的查询，查看回答末尾是否出现标注了发布单位、发布日期的来源条目。
- 检查回答中的引用片段，确认片段长度符合预设的引用token限制，未出现严重截断或过长的情况。
- 上传一份测试用的油田党建文档，触发知识库同步，确认同步频率符合配置的更新周期。
- 查看接口返回的字段，确认包含预设的溯源相关元数据。
