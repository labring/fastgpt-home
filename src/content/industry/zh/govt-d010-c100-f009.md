# 油田工程服务的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
油田工程服务的党建学习问答数据主要来源于内部党建档案库、月度支部学习材料、上级党委下发的指导文件以及季度党建考核题库。数据更新节奏随官方文件下发同步调整，上级指导性文件随政策调整实时更新，支部学习材料每月更新，会议纪要按周归档。文档统一采用标准公文结构，包含标题、发布单位、发布日期、正文内容，部分材料附带配套学习思考题，字段包含文件编号、学习主题、适用支部范围，单位以“篇”“次”为统计标识。

## 这些特征在「模型接入与配置」这一环带来什么约束
油田工程服务党建数据的多源更新节奏差异，要求配置按不同数据源设置独立的同步触发周期，避免出现内容时效性偏差。文档附带配套思考题的结构，要求在向量入库环节区分正文与题目内容，防止匹配时混入非学习正文的考核内容。适用支部范围的字段，要求配置基于用户角色的上下文过滤规则，确保问答内容匹配对应支部的学习范围。长篇幅的党建文件则要求调整上下文相关参数，避免关键政策表述被截断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | `8000–12000 token` | 油田党建文档多为长篇幅公文，该区间可完整承载单篇核心内容与关联上下文 |
| `maxTokens` | `2000 token` | 党建问答以政策解释、学习要点为主，单次回答无需过长篇幅，避免冗余 |
| `quoteMaxToken` | `3000 token` | 需完整引用党建文件原文作为问答依据，该长度可覆盖多数单篇文件的核心段落 |
| `temperature` | `0.1–0.3` | 党建内容需保持政策口径严谨，较低温度可减少随机性偏差 |
| `AIPROXY_API_ENDPOINT` | 填写企业内部代理地址 | 保障数据传输与调用的内部安全性，符合国央企合规要求 |
| `AIPROXY_API_TOKEN` | 按企业密钥管理规范配置 | 遵循国央企信息安全要求，避免密钥泄露 |

## 容易做错的三处
- 现象：调用时提示“当前分组 default 下对于模型 gpt-4o-mini 无可用渠道”，原因：未在对应分组中配置`AIPROXY_API_TOKEN`与`AIPROXY_API_ENDPOINT`，或密钥与代理地址不匹配。
- 现象：问答结果未引用油田党建文档原文，仅生成通用表述，原因：未正确配置`quoteMaxToken`参数，导致引用内容被截断或无法匹配。
- 现象：返回结果包含非支部范围内的党建内容，原因：未启用基于用户角色的上下文过滤配置，未关联适用支部范围字段进行匹配。

## 怎么确认配好了
- 在FastGPT v4.17.0后台的模型配置页面，检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`是否正确填写，可通过调用测试接口验证连通性。
- 发起党建相关测试提问，核对返回结果中是否包含匹配的油田党建文档原文，确认参数承载效果符合预期。
- 测试不同支部角色的用户提问，确认返回内容仅包含对应支部范围内的党建学习材料，验证上下文过滤配置生效。
- 调整`temperature`参数后发起测试，观察回答的严谨性变化，确认参数取值符合党建内容的严谨性要求。
