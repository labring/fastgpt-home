# 港口航运的党建学习问答：向量模型与索引

## 这个品类的数据长什么样
港口航运领域的党建学习问答数据主要来源于港口集团党建内网的官方文档、支部月度学习计划、“三会一课”会议纪要、一线党员学习心得及上级党委下发的政策文件。数据更新节奏为每周同步支部动态、每月更新党委学习安排，文档多为PDF或Word格式，结构包含标题、正文、发布单位、发布日期，内容常包含“三会一课”“党员先锋岗”等党建专属术语，同时夹杂港口泊位调度、集装箱作业等行业专业表述。

## 这些特征在「向量模型与索引」这一环带来什么约束
党建专属术语与行业专业表述的混合存在，要求向量模型需保留跨领域语义关联，避免单一领域的语义丢失；文档格式多样且包含固定党建板块，要求索引支持多格式解析与结构化语义提取；每周/每月的增量更新节奏，要求索引具备增量索引能力，避免全量重建带来的性能损耗；支部数量增长带来的数据量扩张，要求索引的存储容量可按需扩展，同时保留单轮问答的上下文承载能力。

## 配置怎么定
本配置适用于FastGPT v4.17.0。
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| 分块长度 | 800–1200 字符 | 适配党建文档与港口专业术语的段落逻辑，避免切片割裂“三会一课”“泊位调度”等连贯表述 |
| 重叠长度 | 100–150 字符 | 保留跨分块的语义关联，防止专业术语被分块截断后无法识别 |
| 相似度阈值 | 0.72–0.85 | 过滤非党建的港口业务内容，精准匹配党建学习问答的语义需求 |
| 单次搜索上限 | 前 8 条 | 平衡召回精度与上下文长度，适配单轮问答的内容承载上限 |
| `defaultToken` | 4096 token | 匹配Qwen3-Embedding-8B的输入上限，避免向量化过程中截断核心语义 |
| `maxToken` | 8192 token | 适配大模型上下文窗口，保留足够的党建学习材料语义信息 |

## 容易做错的三处
- 现象：界面显示本地部署的VLLM嵌入模型连接失败，日志包含504超时报错。原因：未将VLLM部署的Qwen3-Embedding-8B的端口暴露至FastGPT所在网络，且未配置正确的API访问地址。
- 现象：知识库磁盘占用统计显示包含原文件、分割块与向量数据三部分，但实际占用远超预期。原因：未关闭非党建内容的自动导入开关，导致无关的港口业务文件被纳入向量存储。
- 现象：发起党建问题问答时，召回的相关文档条数少于配置的单次搜索上限。原因：分块长度过短，导致党建专属术语被拆分，向量模型无法识别完整语义关联。

## 怎么确认配好了
- 上传一篇包含党建术语与港口专业表述的测试文档，手动查看切分后的分块内容，确认核心术语未被截断。
- 发起一条党建相关测试问题，查看召回的文档条数符合配置的单次搜索上限，且内容均关联党建主题。
- 检查磁盘存储路径，确认向量数据、分块文件与原文件的存储逻辑符合配置要求，无冗余文件堆积。
- 查看模型连接日志，确认无超时或认证报错，向量生成流程正常完成。
