# 港口航运的党建学习问答：多轮对话与提示词

## 这个品类的数据长什么样
港口航运领域的党建学习数据主要来源于集团党群部发布的官方文件、下属支部的学习记录、上级交通系统的党建要求文档，以及内部培训课件与会议纪要。数据更新节奏为每月集中更新一次，日常随新政策补充。文档多为结构化格式，包含标题、正文段落、附件链接，字段涵盖发布部门、发布日期、主题分类与适用岗位，文档大小多为几百KB至几MB。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
党建数据的岗位分类字段要求多轮对话需根据用户角色调整回答的专业度，避免对一线船员与岸基管理岗使用过于笼统的表述。文档中的附件链接与长文本内容，要求多轮对话需保留上下文关联，避免丢失关键政策段落。月度更新的节奏要求配置定期同步机制，确保问答内容始终匹配最新官方口径。内嵌的视频转写内容则要求分块长度适配长文本处理，避免超出模型上下文限制。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配港口党建文档的段落结构，避免单块内容超出模型承载上限 |
| 重叠长度 | 150–200 字符 | 保留跨块的上下文关联，确保党建政策的连贯解读 |
| `variables`配置 | 按用户角色预设岗位标签 | 适配文档中的岗位分类字段，精准匹配对应学习资料 |
| `chatId`会话管理 | 绑定港口内部工号 | 保留多轮对话的历史上下文，跟踪用户的学习进度与提问轨迹 |
| 触发同步频率 | 每月1次 | 匹配党建资料的月度更新节奏，确保数据时效性 |
| 最大上下文长度 | 4000–6000 token | 适配多轮对话的历史提问与回答，避免截断关键内容 |

## 容易做错的三处
- 现象：多轮对话中中英文开场白无法同时生效，仅显示单一语言内容。原因：未在`variables`中配置语言切换的触发规则，未绑定用户的语言使用场景。
- 现象：导入的Markdown格式党建文档中，内嵌图片无法正常加载。原因：未在文档同步流程中配置图片域名自动补全规则，仅在Word导入时触发了域名替换。
- 现象：长文档导入后出现上下文截断，无法完整回答党建政策的关联问题。原因：未配置合理的分块长度与重叠长度，导致关键政策段落被拆分丢失。

## 怎么确认配好了
- 使用FastGPT v4.17.0版本的平台发起测试会话，选择不同岗位角色提问，验证回答内容是否匹配对应分类的党建资料。
- 上传包含内嵌图片的Markdown格式党建文档，检查对话中图片是否正常加载。
- 触发工具调用流程，确认最终回答仅包含面向党员的内容，无中间日志展示。
- 导入超过模型上下文长度的长文档，发起关联提问，验证回答是否覆盖完整政策内容，并检查`messages`历史上下文是否被正确保留。
