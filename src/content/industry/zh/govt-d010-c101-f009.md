# 港口航运的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
港区党建学习问答的数据来源包括各支部的日常学习记录、上级党委下发的党建指导文件、港区党建宣传栏公开内容，部分关联港区生产的党建内容会附带岗位适配说明。数据更新节奏为日常随支部活动动态更新，每月完成集中归档。文档结构多包含标题、正文段落、发布单位、发布日期，单篇文档长度跨度较大，部分长文档会附带多段岗位相关的补充说明。

## 这些特征在「模型接入与配置」这一环带来什么约束
港区党建文档长度跨度大的特征，要求模型接入时需适配不同长度的上下文输入，避免截断包含岗位适配说明的关键信息。党建内容需严格匹配官方文件表述，对模型生成的严谨性有较高要求。日常动态更新的文档，要求配置的召回机制可适配增量更新逻辑，避免旧数据干扰新问答。部分文档附带岗位适配说明，要求召回时需关联对应字段，确保问答内容贴合港区一线场景。

## 配置怎么定
本文基于 FastGPT v4.17.0 版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配港区党建文档跨度大的特征，完整保留包含岗位适配说明的长文档内容 |
| `temperature` | 0.1–0.3 | 确保党建问答严格匹配官方文件表述，降低生成内容的随机性 |
| `quoteMaxToken` | 2000–3000 字符 | 保留足够的原文引用内容，支撑党建问答的准确性 |
| `maxTokens` | 1500–2000 token | 控制单轮问答的生成长度，避免输出冗余内容 |
| `AIPROXY_API_ENDPOINT` | 按部署的代理地址填写 | 适配港口内部网络访问限制，确保模型调用链路稳定 |
| `AIPROXY_API_TOKEN` | 按代理平台分配的密钥填写 | 完成模型调用的身份验证，避免未授权访问 |

## 容易做错的三处
- 出现503状态码报错，提示当前分组下对应模型无可用渠道。原因是未正确配置模型分组，或代理渠道未同步绑定对应模型。
- 调用时出现connection error。原因是`AIPROXY_API_ENDPOINT`填写错误，或内部网络无法访问代理地址。
- 生成的党建问答内容偏离官方表述。原因是`temperature`取值过高，导致模型生成内容随机性过大。

## 怎么确认配好了
- 填写`AIPROXY_API_TOKEN`和`AIPROXY_API_ENDPOINT`后，执行模型连通性测试，确认返回正常响应。
- 导入一篇包含岗位适配说明的港区党建长文档，测试配置是否完整保留文档关键内容。
- 发起党建相关测试提问，确认生成内容严格匹配官方文件表述，无明显偏差。
- 发起多条不同长度的测试提问，确认单轮生成长度符合`maxTokens`的配置限制。
