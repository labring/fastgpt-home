# 炼化生产的党建学习问答：向量模型与索引

## 这个品类的数据长什么样
炼化生产领域的党建学习数据，来源为企业党委办公室下发的年度党建学习计划、三会一课记录、主题党日活动台账、行业党建合规文件，以及党员个人学习心得归档。更新节奏为每月更新当月学习材料，每季度更新党员学习台账与活动记录。文档多为PDF格式正式文件，包含标题、发布单位、发布日期、正文内容、附件链接，字段涵盖学习主题、学时要求、考核节点、参与党员范围，单位涉及学时、人次、活动场次。

## 这些特征在「向量模型与索引」这一环带来什么约束
单篇党建文档正文可达数千字符，且包含附件链接，要求向量分块需适配长文本拆分，避免截断关键党建术语与行业专属表述。数据更新频率为月/季，索引更新策略需匹配该节奏，避免索引滞后于最新学习材料。字段包含党建专属术语与炼化行业专属表述，如“三会一课”“装置检修党建联动”，要求向量模型需具备领域术语识别能力，避免语义偏差。台账类数据为结构化表格，需支持多向量生成以覆盖表格字段与内容，确保查询时能召回完整台账信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配炼化党建单篇文档的正文长度，避免单块内容过长超出模型处理上限 |
| 重叠长度 | 100–150 字符 | 确保长文档拆分后相邻块的语义连贯性，覆盖党建主题的跨块表述 |
| 相似度阈值 | 0.75–0.85 | 过滤低匹配度的非党建内容，聚焦与查询主题相关的学习材料 |
| 单次搜索上限 | 前 10 条 | 平衡召回范围与响应速度，适配党建问答的单主题查询需求 |
| `maxToken` | 8000 token | 适配长文档的向量生成与上下文拼接需求，符合FastGPT v4.17.0的默认配置范围 |
| `defaultToken` | 1000 token | 配置单条向量的基础token长度，匹配党建文档的平均分块大小 |

## 容易做错的三处
- 点击启用豆包Doubao-embedding-large索引模型，填写自定义请求地址和apikey后测试直接报错。原因是自定义请求地址未适配炼化党建数据的字段校验规则，或apikey的权限未开放向量生成接口。
- 刷新页面后显示“检测到没有可用的索引模型”报错。原因是未将配置的向量模型关联至当前党建知识库，或配置项未完成保存即退出页面。
- 未开启表格数据的多向量支持，导致党建台账类表格的查询召回结果为空。原因是未在知识库设置中勾选表格多向量选项，无法为表格字段生成独立向量片段。

## 怎么确认配好了
- 进入知识库设置页面，查看向量模型配置项显示已启用且无报错提示。
- 上传一篇炼化党建的正式学习文件，等待索引完成后查看向量生成日志无异常提示。
- 发起与党建学习相关的查询，验证召回的文档与查询主题匹配度符合预期。
- 查看知识库的向量索引统计面板，确认已生成对应数量的向量片段。
