# 炼化生产的党建学习问答：模型接入与配置

本文基于 FastGPT v4.17.0 版本编写，针对炼化生产领域党建学习问答的模型接入与配置场景提供具体指引。

## 这个品类的数据长什么样
数据主要来自炼化板块内部党建档案库、党委下发的正式文件、班组月度学习台账，更新节奏为党委文件随下发实时更新，班组学习材料每月更新一次。文档多为带层级标题的Markdown或PDF格式，包含发布文号、发布单位、发布日期等元数据字段，部分材料会关联对应生产班组的安全学习要求，字段单位多采用“人次”“小时”“批次”等内部统计单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
内部党建材料包含专属元数据字段，模型接入时需保留发布文号、发布单位等信息用于问答溯源，增加了元数据绑定的配置约束。月度更新的班组学习材料要求向量库同步周期匹配更新节奏，避免数据滞后。部分材料关联生产班组安全要求，文档长度差异较大，需适配不同长度的文本分块与嵌入配置，防止长文本截断导致信息丢失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 炼化党建材料多结合生产班组内容，单条关联文档长度较长，需保留足够上下文 |
| `maxTokens` | 4000 token | 控制单轮回答长度，适配内部系统与外部渠道的接收限制 |
| `quoteMaxToken` | 2000–3000 token | 匹配炼化党建材料的单份文档平均长度，确保引用内容完整 |
| `temperature` | 0.3–0.5 | 保持党建问答的严谨性，避免生成偏离官方文件的表述 |
| `AIPROXY_API_ENDPOINT` | 按部署平台填写实际地址 | 适配自研或第三方部署的大模型接入路径 |
| `AIPROXY_API_TOKEN` | 填写平台分配的密钥 | 确保接口调用的身份验证合规 |

## 容易做错的三处
- 开启重排模型后仅返回单条引用结果。现象：问答界面仅展示1条引用文档，接口日志显示仅单条结果被传入模型。原因：误将`quoteMaxToken`设置为单条文档的长度，导致仅最高相似度的结果可被完整纳入上下文。
- 上传炼化党建PDF文件后解析失败。现象：界面显示“文件解析失败”，接口返回状态码400。原因：未适配炼化党建材料中内嵌的生产班组编号等特殊字段，导致分块时触发格式错误。
- 模型调用超时。现象：单轮问答超过30秒无回复，接口返回504状态码。原因：`maxContext`设置过大，导致模型加载上下文耗时过长，超出系统默认超时阈值。

## 怎么确认配好了
- 上传1份炼化板块党委下发的正式党建文件，核对引用结果中是否包含发布文号、发布单位等元数据字段。
- 发起包含“班组安全学习”的党建问题提问，检查回答内容与官方文件表述一致。
- 查看系统接口日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置正确，无身份验证报错。
- 调整`temperature`参数至0.4，验证回答的严谨性符合党建问答的要求。
