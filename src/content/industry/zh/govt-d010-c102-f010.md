# 炼化生产的党建学习问答：知识库检索与召回

## 这个品类的数据长什么样
炼化生产领域的党建学习数据主要来源于国企内部党建档案库、石油石化行业党建专项指导文件、生产现场的党员学习台账。数据更新节奏为每月一次，覆盖政策原文、现场党建案例、装置检修期间的专项学习课件三类文档。文档字段包含文件编号、发布单位、适用生产场景、发布日期，单篇文档长度从数百字符到数千字符不等，文件大小多在100 KB到5 MB区间。

## 这些特征在「知识库检索与召回」这一环带来什么约束
首先，内部专属数据源要求检索范围必须限定在炼化党建专属知识库，不可引入公开通用党建内容。其次，月度更新节奏要求知识库同步任务需配置固定周期触发，避免召回过期或未更新的学习材料。再次，文档长度跨度大的特点要求检索分块策略需适配不同长度的文档，避免长文档截断关键内容或短文档分块过碎。最后，适用生产场景的字段要求检索需关联炼化生产关键词，如装置检修、安全示范岗等，提升场景匹配度。FastGPT v4.17.0版本的检索逻辑可适配此类场景约束。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的知识库检索与召回逻辑：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.72–0.78 | 匹配炼化党建文档的专业术语密度，过滤无关通用党建内容 |
| `limit` | 8 | 适配炼化党建文档的单篇长度，控制上下文总字符量 |
| `searchMode` | hybrid | 结合关键词与语义检索，覆盖政策原文、现场案例两类文档 |
| `usingReRank` | true | 对召回结果按炼化场景相关性重排，提升精准度 |
| `datasetSearchUsingExtensionQuery` | false | 关闭额外扩展查询，避免引入非炼化场景的党建信息 |
| `collectionIds` | ["col_oil_refining_party"] | 限定检索范围仅为炼化党建专属知识库，避免跨品类检索 |

## 容易做错的三处
- 现象：即使关闭`datasetSearchUsingExtensionQuery`参数，检索结果仍带有非知识库来源的补全信息。原因：未同步确认`usingReRank`的关联逻辑未触发额外扩展，或配置未在系统中生效。
- 现象：docker部署PG数据库环境下，知识库索引建立失败，界面显示索引状态异常。原因：未为PG数据库分配足够的内存资源，或未配置正确的连接超时参数，导致索引构建过程中断。
- 现象：调用检索接口后返回空结果，无匹配的炼化党建文档。原因：未指定`collectionIds`参数，导致检索范围未限定在炼化党建专属知识库内，或指定的集合ID错误。

## 怎么确认配好了
- 提交炼化党建专属问题，核对检索结果是否仅来自配置的知识库集合，无外部无关内容。
- 查看检索日志，确认`similarity`参数的匹配阈值符合预设区间，过滤了非相关内容。
- 测试关闭扩展查询后，结果中无额外补全的非知识库信息。
- 检查索引建立状态，确认无异常报错，索引同步周期符合月度更新要求。
