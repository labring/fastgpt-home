# 煤炭运销的党建学习问答：表单与交互

## 这个品类的数据长什么样
煤炭运销领域的党建学习数据主要来源于企业内部党委宣传部上传的标准化文档，包括党课课件、党建制度汇编、时政学习要点、支部活动记录等。数据更新节奏为每周一次，由管理员批量上传或同步官方党建平台内容。文档多为PDF或Word格式，结构遵循标准党建文档层级：一级标题为党课主题，二级标题为章节内容，三级标题为具体学习要点，字段包含文档标题、发布日期、所属运销支部、内容摘要，单位以字符、MB、YYYY-MM-DD格式标注。

## 这些特征在「表单与交互」这一环带来什么约束
内部专属数据源要求表单需配置权限校验，仅允许党建管理员上传或修改资料，避免非授权内容混入。每周更新的节奏决定了数据源同步需设置固定周期，不宜过于频繁占用系统资源。文档的层级结构要求表单分块需匹配标题层级，确保问答时上下文逻辑连贯。字段中的所属支部属性，要求表单交互需支持按支部分类筛选数据，方便精准匹配运销分部的学习需求。专业术语如“运销调度”“煤炭保供”的存在，要求变量引用需支持自定义字段映射，避免格式错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `formInput` | 单行文本+多行文本+日期选择器组合 | 适配党建学习问答需收集的用户学习进度、具体疑问、提问日期等信息，覆盖不同类型的输入需求 |
| `userSelect` | 按运销支部分组的多选框 | 匹配煤炭运销企业多分部的组织架构，方便按支部筛选学习数据，提升交互精准度 |
| 数据源同步频率 | 每周凌晨2:00执行 | 匹配党建资料每周更新的节奏，避免高频同步占用系统资源 |
| 接口超时时间 | 600秒 | 适配煤炭运销党建文档的加载速度，避免因文档体积较大出现请求中断 |
| 变量引用格式 | {{字段名}}标准模板语法 | 符合FastGPT v4.17.0的变量调用规范，避免出现格式类报错 |
| 上下文召回数量 | 前5条匹配结果 | 平衡党建问答的上下文丰富度与响应速度，避免冗余信息干扰 |

## 容易做错的三处
- 调用变量时出现「quote type error」报错，原因是未使用标准的{{字段名}}模板语法，混入了非模板格式的引号或特殊字符。
- 表单提交后无数据返回，原因是未配置对应数据源的访问权限，普通用户无法读取党建资料库的内容。
- 用户选择组件无法按支部分组展示，原因是未在配置中开启分组显示选项，直接展示了全部用户列表。

## 怎么确认配好了
- 上传一份煤炭运销党建的示例文档，检查表单是否能正确识别文档的标题层级与字段信息。
- 提交一条测试表单，验证变量引用是否能正确提取文档中的字段，不出现报错提示。
- 查看系统同步日志，确认每周凌晨2:00的数据源同步任务正常执行，无超时或失败记录。
- 测试用户选择组件，确认能按运销支部分组展示可选用户列表，筛选功能正常生效。
