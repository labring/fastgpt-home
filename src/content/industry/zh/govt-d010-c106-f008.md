# 煤电一体化的党建学习问答：文档解析与分块
本文基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
煤电一体化党建学习问答的数据来源于企业党群部门归档的内部资料，包括上级党建政策原文、支部学习课件、党课会议纪要、专项学习汇编等。更新节奏按需调整，上级部署新学习任务时即时更新，日常每月补充新的学习材料。文档格式涵盖PDF、Word、TXT、PPT，部分为带内嵌图片的扫描件，结构多按章节、段落划分，包含固定的发文文号、发布单位与正文内容，无统一固定的标准化字段格式。

## 这些特征在「文档解析与分块」这一环带来什么约束
多格式混合的文档要求解析引擎兼容多种文件类型，扫描件与内嵌图片的存在需要额外的OCR支持。按需更新的特性要求解析工具支持批量上传与定时同步任务，避免临时任务堆积。长文本与章节化的结构要求分块时保留语义边界，避免跨章节拼接导致检索偏差。非标准化的字段格式要求解析引擎自动识别正文内容，过滤冗余的格式标记与发文元数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 煤电一体化党建文档多为长文本政策与学习材料，该区间可保留单块内容的语义完整性 |
| `chunkSplitter` | 按段落+标题分割 | 党建文档按章节、段落组织内容，按此规则分割可保证分块语义独立，便于精准检索 |
| `customPdfParse` | 开启OCR模式 | 部分党建文档为扫描件或带内嵌图片的PDF，开启后可提取图片内的文字内容 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 单份大型党建学习汇编文件解析耗时较长，该时长可避免大文件解析中途中断 |
| `chunkSettingMode` | 手动配置 | 需针对煤电党建文档的长文本特征调整分块参数，手动配置可适配专属场景 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 适配批量上传的大型党建学习汇编文件，避免因文件过大无法完成解析 |

## 容易做错的三处
- 上传后缀修改后的非标准格式文档（如将代码类文档改后缀为TXT混入党建资料），解析后无有效内容。原因：FastGPT文档解析依赖文件原生格式识别，修改后缀无法改变文件实际编码与结构，导致解析引擎无法匹配正确的解析规则。
- 批量上传大型党建学习汇编文件后，界面长期显示索引中。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时间不足以完成大文件解析与分块，导致任务挂起。
- 上传包含内嵌图片的PDF党建课件后，图片内文字未被纳入分块内容。原因：未开启`customPdfParse`的OCR模式，仅依赖文本提取逻辑，无法识别图片内嵌文字。

## 怎么确认配好了
- 上传一份典型的煤电党建文档，查看解析后的分块结果，确认分块边界与文档章节、段落对齐。
- 检查解析任务的日志，确认未出现超时报错，且解析耗时符合预期。
- 上传包含内嵌图片的PDF文档，确认图片内文字被正确提取并纳入分块内容。
- 使用chunk模式调用pushdata api上传测试文档，确认任务在合理时间内完成索引，无长期挂起状态。
