# 煤电一体化的党建学习问答：知识库检索与召回

## 这个品类的数据长什么样
煤电一体化党建学习问答的数据源主要来自国央企煤炭板块的党建管理系统，包含Word格式的党课讲义、PDF格式的上级党建文件、Excel格式的党员学习考勤与统计台账三类主要文档。更新节奏分为两类：正式党建学习材料每月随集团政策同步更新，临时学习通知与海外项目组党建台账按周增量更新。文档字段包含文件标题、发布单位、发布日期、适用场景、学习时长、参与人次等，单位涉及小时、人次、MB等，部分Excel台账包含结构化的适用地区字段。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多格式混合的数据源要求检索系统支持跨格式的语义匹配与结构化字段过滤，避免仅支持单一文档格式导致的Excel数据遗漏。适用场景字段的存在要求检索需精准匹配“国内/海外项目”等细分条件，否则会出现海外党建数据召回不足的问题。不同更新节奏的数据源需要配置灵活的增量同步规则，避免旧数据覆盖新内容或新数据未及时入库。长文档与短文档并存的结构要求检索分块策略适配不同长度的内容，保证语义召回的完整性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `similarity` | 0.75–0.85 | 适配党建内容的语义相似度匹配区间，过滤低相关的非党建类结果 |
| `limit` | 前10条 | 匹配党建学习问答的单次召回数量，保证上下文长度符合对话场景要求 |
| `searchMode` | 精准匹配 | 针对结构化字段（如适用场景）的精准检索需求，避免模糊匹配导致的无关结果混入 |
| `usingReRank` | 开启 | 对初始召回结果进行二次排序，提升党建内容的相关性排序精度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展党建相关同义词查询，如“三会一课”扩展为支部会议、党课学习等，覆盖更多语义场景 |
| `collectionIds` | 指定煤炭板块党建集合ID | 限定检索范围，避免混入其他业务板块的非党建文档 |

## 容易做错的三处
- 现象：检索Excel中的海外项目党建数据时，返回结果条数远少于Excel内的有效条目。原因：未开启`datasetSearchUsingExtensionQuery`，或`searchMode`设置为模糊匹配，无法精准匹配“使用地为国外”的结构化字段。
- 现象：调用自建系统对接FastGPT接口时，返回`Error: write EPROT`错误。原因：未正确配置HTTPS安全证书，或请求未携带合法的API认证密钥。
- 现象：知识库检索返回`Query read timeout`错误。原因：`limit`设置过高，导致单次检索的数据量超出系统超时阈值，或未合理配置`usingReRank`导致排序环节耗时过长。

## 怎么确认配好了
- 上传一份包含“使用地为国外”的党建考勤Excel，执行检索关键词“海外项目党建学习”，核对返回结果是否包含该文件的对应条目。
- 查看FastGPT后台的知识库配置页面，确认`collectionIds`仅勾选了煤炭板块党建相关的集合，无其他无关集合被纳入检索范围。
- 执行一次长文档党课讲义的检索，检查返回结果的排序是否符合党建内容的相关性优先级，确认`usingReRank`已生效。
- 调用FastGPT的知识库检索API，检查返回结果的`similarity`值是否落在0.75–0.85区间内，确认配置参数生效。
- 确认当前使用的FastGPT版本为v4.17.0，避免参数配置不兼容。
