# 煤矿生产的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
煤矿生产领域的党建学习数据主要来源于企业内部党建档案、班前会学习记录、月度安全党建台账、上级党组织下发的专项学习通知等。数据更新节奏覆盖日常与定期：班前会记录每日更新，月度台账每月更新，专项通知按需发布。文档类型包含PDF格式的学习课件、TXT格式的学习笔记、结构化表格形式的签到与考核记录，字段包含学习主题、学习时间、参会人数、学习内容摘要、考核结果，单位涉及“人”“小时”“次”等。

## 这些特征在「模型接入与配置」这一环带来什么约束
多格式混合的数据要求模型接入配置适配PDF、TXT、结构化表格的解析规则，避免出现字段提取错误。专属党建术语（如煤矿安全党建相关的“双基建设”“班前会廉政提醒”）要求模型上下文保留足够的关联范围，确保问答内容符合官方表述。高频更新的班前会记录要求配置按需触发的索引刷新机制，保障数据时效性。长文本的季度党建总结要求调整上下文窗口与输出长度的参数设置，避免内容截断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配煤矿党建长文本学习材料，保留足够的上下文关联范围，覆盖专属术语的关联需求 |
| `maxTokens` | 4000–6000 token | 满足长文档总结、问答生成的输出长度需求，避免截断党建专属内容 |
| `quoteMaxToken` | 2000–3000 token | 限定引用的党建文档片段长度，确保模型能精准匹配煤矿党建相关的问答场景 |
| `temperature` | 0.2–0.4 | 降低回答的随机性，保证党建问答内容符合官方标准表述，避免偏离专属术语 |
| `AIPROXY_API_ENDPOINT` | 本地部署的MinerU解析服务地址（如`http://127.0.0.1:8000`） | 适配本地部署的文档解析需求，匹配煤矿党建数据的多格式解析要求 |
| `AIPROXY_API_TOKEN` | 自定义的服务访问密钥 | 保障内部党建数据的访问安全，符合企业内部数据权限管理规范 |

## 容易做错的三处
- 现象：工作流中模型图标无法正常显示，上传党建相关文档时提示网络错误。原因：未正确配置`AIPROXY_API_ENDPOINT`指向本地MinerU服务，或MinerU服务端口未开放至FastGPT部署环境。
- 现象：无法建立党建文档的索引模型渠道。原因：未在FastGPT系统设置中配置`AIPROXY_API_TOKEN`，导致解析服务鉴权失败，无法完成索引创建。
- 现象：生成的党建问答内容偏离煤矿专属术语，或长文档总结被截断。原因：`maxContext`取值过低，未保留足够的上下文关联范围，或`maxTokens`设置不足导致输出被截断。

## 怎么确认配好了
- 上传一份煤矿党建相关的PDF文档（如班前会学习记录），检查解析后是否能正确提取参会人员、学习主题等字段。
- 在FastGPT v4.17.0的工作流中添加模型节点，确认模型图标正常显示，且能正常调用解析后的文档内容进行问答。
- 发起党建相关的测试提问（如“煤矿班组的主题党日流程是什么”），检查回答是否包含正确的专属术语，且未出现内容截断。
- 检查`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`的配置，通过系统日志确认解析服务调用成功，无鉴权报错。
