# 煤矿生产的党建学习问答：表单与交互

## 这个品类的数据长什么样
煤矿生产领域的党建学习问答数据主要来自煤炭国企内部党建管理系统、党委宣传部下发的学习文件、支部党课课件与会议纪要。数据更新节奏为每月新增月度学习要点、每季度更新专题党课内容，文档多为PDF或Word格式，结构包含主题标题、发布单位、发布日期、正文段落与附件链接，单篇文档字数跨度较大，字段含文件编号、主题分类等，存储单位以MB计。FastGPT v4.17.0版本可完整支持上述数据格式的导入与解析。

## 这些特征在「表单与交互」这一环带来什么约束
单篇文档字数跨度大的特征，要求表单交互支持自适应的文档解析阈值，避免长文档解析超时或短文档拆分冗余。内部文档含附件链接的特征，要求表单交互增加附件识别与同步上传的选项，确保关联材料被纳入知识库。固定更新节奏的特征，要求表单的定时同步配置可匹配月度、季度的更新周期，无需每次手动触发。字段含主题分类的特征，要求交互表单支持按党建主题分类的筛选选项，便于精准召回学习内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 匹配煤矿党建文档的常规段落长度，避免拆分破坏语义连贯性 |
| 单次导入上限 | 500 MB | 适配单篇大型党课课件或多文档打包导入的存储需求 |
| `formInput` | 按文档分类触发 | 匹配党建学习问答的主题分类字段，精准召回对应分类的知识库内容 |
| `userSelect` | 前3–5条召回结果 | 符合党员学习时的信息获取习惯，避免过多选项造成干扰 |
| 最大上下文 | 4000–6000 token | 适配长文档解析后的上下文传递需求，确保问答逻辑连贯 |
| 问题优化 | 开启 | 优化党建专属术语的语义理解，提升问答准确性 |

## 容易做错的三处
- 现象：导入党建PDF文档时，页面页数加载条持续刷新，无法选中指定页码。原因：未配置适配长文档的分块长度，导致解析时分页逻辑阻塞。
- 现象：语音输入党建相关问题时，无法识别“三会一课”“主题党日”等专属术语。原因：未开启问题优化配置，语义识别未适配党建场景的专属词汇。
- 现象：调用外部模型时，问答结果与党建知识库内容不匹配。原因：未按文档分类配置`userSelect`的召回范围，导致召回结果偏离党建主题。

## 怎么确认配好了
- 上传一篇典型的煤矿党建文档，检查解析后的分块数量与预设分块长度匹配。
- 测试`formInput`触发的问答流程，确认召回结果仅包含对应分类的党建内容。
- 发起语音输入测试，确认问题优化后的语义理解符合党建场景需求。
- 查看导入文档的大小，确认未超过单次导入上限。
