# 电网企业的党建学习问答：引用来源与溯源

## 这个品类的数据长什么样
电网企业党建学习问答的数据源为内部党建管理系统、党委宣传部发布的正式文件、支部学习台账、党员教育课件等。更新节奏随上级党建部署及内部学习计划动态调整，核心政策文件更新周期不超过15天，日常学习素材按需同步。单篇文档多为结构化内容，包含文件标题、发布单位、发布日期、正文段落、附件链接等字段；部分视频课件的转写文本附带视频时长、主讲人、授课主题等字段，所有正式文件均带有明确的发布文号与溯源标识。

## 这些特征在「引用来源与溯源」这一环带来什么约束
电网党建学习需符合国企合规要求，所有问答内容必须可追溯至官方发布的正式素材，因此溯源环节需精准匹配文档自带的发布标识。结构化文档的固定字段为溯源提供了明确依据，需优先提取发布单位、文号等信息，避免模糊指代。视频转写文本的原始链接需完整保留，确保学习人员可直接访问原始素材。文档的段落结构要求溯源片段不能割裂上下文，需保留原文的完整逻辑，同时需按发布时间排序，优先展示最新的政策内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | 电网党建文档单篇正文多为1000-3000字符，按token换算后该区间可覆盖完整核心段落，同时避免超出上下文限制 |
| `responseData` | 返回包含发布单位、发布文号、发布日期、原始链接的字段 | 电网党建学习需明确合规溯源标识，该配置可直接提取文档自带的官方字段，满足国企党建的合规要求 |
| `detail` | 开启 | 党建学习问答需展示完整来源片段，开启后可返回原文的精准上下文，便于验证内容准确性 |
| 单次搜索上限 | 前3条 | 电网党建学习的核心政策文件数量有限，过多的搜索结果会分散注意力，优先展示最新发布的权威内容 |
| 分块长度 | `800–1000 字符` | 电网党建文档多为结构化段落，分块长度匹配文档段落长度可避免割裂上下文，提升溯源准确性 |
| 结果排序 | 按发布日期倒序 | 党建学习需优先使用最新的政策文件，按发布时间排序可确保返回的内容符合最新学习要求 |

## 容易做错的三处
- 现象：在工作流中引用党建问答插件后添加代码运行节点，触发输入时返回`400 Bad Request`错误，提示参数缺失。原因：未正确配置`responseData`参数，未返回插件要求的标准化输出字段，导致代码节点无法解析返回内容。
- 现象：设置引用条数时无法选择100-900区间的数值，仅能选择100或900。原因：未使用FastGPT v4.17.0版本，旧版本的引用条数配置仅提供固定档位，未开放自定义区间设置。
- 现象：返回的溯源内容仅包含正文片段，未显示发布单位与文号。原因：分块长度设置过小，导致文档头部的溯源字段被截断，无法被检索到并纳入返回内容。

## 怎么确认配好了
- 发起党建相关问题测试，查看返回结果中是否包含明确的来源标识，如发布单位、发布日期等字段。
- 检查返回的引用片段长度是否符合预期，可通过调整`quoteMaxToken`参数修改返回的token数量。
- 多次发起相同问题测试，确认返回的溯源结果按发布时间排序，优先展示最新的党建文件。
- 在工作流中添加日志节点，查看插件返回的完整数据结构，确认`responseData`配置的字段已正确返回。
