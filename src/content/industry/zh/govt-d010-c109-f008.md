# 电网企业的党建学习问答：文档解析与分块

本文档基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
电网企业党建学习问答的数据源主要来自内部党建管理系统、上级党组织下发的政策文件、三会一课会议记录、学习手册及内部培训PPT。文档更新节奏不固定，上级政策文件随工作部署不定期更新，内部学习材料按季度或月度批量更新。文档包含正式公文格式的标题、文号、发文单位、发布日期，会议纪要多为语音转写内容，学习台账常以Excel表格形式记录学习时长（单位为小时）等数据。

## 这些特征在「文档解析与分块」这一环带来什么约束
正式公文的页眉页脚、文号等冗余信息会干扰正文提取，需精准过滤；语音转写的会议纪要存在口语化断句，分块时需保留上下文语义关联；Excel格式的学习台账包含结构化表格数据，需适配表格解析规则以提取单元格内容；不定期的批量大型文档上传，要求解析流程具备足够的容错性与超时处理能力；文档附带的发文单位、发布日期等元数据，需与正文分块绑定，用于后续检索结果的溯源展示。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 电网党建文档既有正式公文的长段落，也有学习要点的短条目，该区间能平衡上下文完整性和检索精度 |
| `chunkSplitter` | 按标题+段落 | 党建文档有明确的章节标题和段落结构，按此规则分块可保留语义完整性 |
| `UPLOAD_FILE_MAX_SIZE` | 200 MB | 电网企业上传的党建学习材料可能包含多页PDF、大型PPT合集，该上限可覆盖多数业务场景 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 大型多页党建文档解析耗时较长，该区间可避免超时导致的解析失败 |
| `customPdfParse` | 启用 | 电网党建PDF文档常包含页眉页脚、文号等冗余信息，启用自定义解析可精准提取正文内容 |

## 容易做错的三处
- 现象：上传Excel格式的党建学习台账后，解析结果为空或仅提取表头。原因：未启用表格文件解析适配，默认解析规则未覆盖结构化表格类党建文档。
- 现象：大型党建PDF文档解析任务显示超时，状态码为504。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时阈值不足以支撑大型文档的解析流程。
- 现象：检索返回的分块结果未附带发文单位、发布日期等元数据。原因：未配置元数据绑定规则，仅提取了文档正文内容，未关联文档属性字段。

## 怎么确认配好了
- 上传一份典型的电网党建PDF文档，查看解析后的分块内容，确认章节标题和正文段落被正确拆分。
- 上传一份Excel格式的党建学习台账，检查解析结果是否包含表格单元格内容，无空值或缺失字段。
- 提交测试查询，查看返回结果是否附带文档的发文单位、发布日期等元数据信息。
- 调整`chunkSize`参数后，重新上传测试文档，确认分块长度符合预期设置。
