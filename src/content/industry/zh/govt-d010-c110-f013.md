# 矿山采选的党建学习问答：分享与嵌入

## 这个品类的数据长什么样
矿山采选领域的党建学习问答数据，主要来源于企业党委的党建工作台账、上级国资委及属地党委下发的学习文件、内部支部会议纪要与学习心得归档。数据更新按周同步上级新部署的党建主题，按月更新内部学习活动记录。单份文档多为结构化文本，包含发布单位、发布日期、学习主题字段，附件多为PDF格式的党课课件，正文以千字级段落为主，涉及单位包括页数、字符数、发布批次编号。

## 这些特征在「分享与嵌入」这一环带来什么约束
党建数据的PDF附件属性，要求嵌入的问答组件支持附件文本提取与检索，否则无法覆盖课件类学习内容。周级别的更新节奏，要求分享链接或嵌入代码的缓存时长不超过7天，避免返回过时的党建学习资料。结构化的字段信息，要求嵌入配置中可绑定按发布单位、发布日期的过滤规则，确保问答仅返回对应支部或时段的学习内容。矿山采选多在内网部署场景，嵌入组件需支持内网域名白名单配置，防止外部非法访问。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分享链接有效期 | 7天 | 匹配矿山党建数据周级更新节奏，避免返回过时内容 |
| 嵌入组件适配移动端 | 开启 | 适配矿山采选现场员工多使用移动设备开展学习的场景 |
| 会话绑定chatId | 开启 | 支持同一会话多次发送消息，满足连贯学习问答的需求 |
| 内网域名白名单 | 添加企业内网域名 | 适配矿山采选多在内网部署的场景，防止外部非法访问 |
| `shareId` | 绑定党建问答专属知识库ID | 确保嵌入组件仅调用矿山党建学习相关的数据集 |
| 最大上下文长度 | 8000 token | 适配党建文档千字级段落的上下文召回需求 |

本配置基于FastGPT v4.17.0版本。

## 容易做错的三处
- 现象：iframe嵌入后管理员登录后台时，嵌入的问答会话意外退出。原因：嵌入组件与后台使用了同源的会话缓存机制，导致登录状态被覆盖。
- 现象：嵌入的问答组件在移动端无法正常显示输入框，提交按钮无响应。原因：未开启嵌入组件的移动端适配配置，未设置响应式布局参数。
- 现象：嵌入页面发起的问答返回了非目标支部的党建内容。原因：未配置按发布单位或发布日期的过滤规则，导致调用了其他部门的知识库数据。

## 怎么确认配好了
- 使用移动设备访问嵌入组件的预览页面，确认输入框、提交按钮可正常触发，页面无横向溢出。
- 在嵌入页面连续发送多条党建相关问题，确认会话未中断，上下文连贯，无需重新发起会话。
- 使用非企业内网域名访问嵌入页面，确认组件无法正常加载，验证白名单配置生效。
- 等待预设的分享链接有效期结束后，访问原链接，确认无法正常获取问答内容，验证有效期配置生效。
