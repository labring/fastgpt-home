# 粮食储备的党建学习问答：表单与交互

## 这个品类的数据长什么样
粮食储备领域的党建学习问答数据主要来源于内部党建管理平台、粮食储备行业政策汇编及储备库站的支部学习记录。数据更新节奏为每月一次，随新政策发布、季度学习计划调整同步更新。单篇文档结构包含政策文号、发布主体、核心条款、配套解读、关联储备业务场景说明等字段，字段单位包含字符数、发布日期格式、学习时长要求（分钟）等，文档长度跨度较大，从数百字符的学习要点到数千字符的政策全文。本文基于FastGPT v4.17.0版本的配置逻辑编写。

## 这些特征在「表单与交互」这一环带来什么约束
粮食储备党建学习数据的月度更新节奏，要求表单数据源配置需支持定时同步任务，避免频繁拉取导致的资源占用。文档长度跨度大的特征，要求表单需支持分段加载与分类筛选，避免单页加载过多内容影响交互流畅度。字段包含政策文号、关联储备业务场景的设计，要求表单交互需提供多维度筛选入口，同时需校验输入内容与关联业务场景的匹配性。学习时长字段的存在，要求表单交互需增加时长校验逻辑，防止输入不符合要求的数值。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 绑定政策文号、储备业务分类两个字段 | 匹配党建学习数据中的政策文号与关联业务场景字段，实现定向问答 |
| `userSelect` | 按学习主题分组展示前5-8条结果 | 适配文档长度跨度大的特征，避免单页展示过多内容 |
| 数据源同步周期 | 720 小时（30天） | 匹配数据月度更新的节奏，减少不必要的拉取请求 |
| 输入项校验规则 | 校验学习时长输入值在30-120分钟区间 | 匹配数据中学习时长要求的字段特征 |
| 交互触发方式 | 填写完成所有必填项后自动触发 | 避免因未完成输入导致的无效问答请求 |

## 容易做错的三处
- 现象：运行工作流后显示`Cannot convert undefined or null to object`报错。原因：未正确绑定`formInput`对应的字段，导致输入项为空值传入工作流。
- 现象：交互对话中无法根据AI输出结果进行条件选择。原因：未配置`userSelect`的联动规则，未将AI输出的主题标签映射为筛选条件。
- 现象：首次AI对话的输出无法作为第二次对话的输入。原因：未开启上下文传递配置，未将首次输出的关键字段保存为临时变量供后续调用。

## 怎么确认配好了
- 手动填写表单中的政策文号、储备业务分类字段，点击触发按钮，检查是否返回对应主题的党建学习问答内容。
- 查看数据源同步日志，确认最近一次同步的时间与设定的同步周期匹配。
- 输入不符合学习时长要求的数值，检查是否触发对应的校验提示。
- 完成首次对话后，检查后续对话是否能调用首次输出的内容作为提问依据。
