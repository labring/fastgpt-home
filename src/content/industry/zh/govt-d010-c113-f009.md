# 船舶制造的党建学习问答：模型接入与配置

## 这个品类的数据长什么样
船舶制造领域的党建学习问答数据，主要来源于企业内部党建档案库、上级党委下发的行业专项学习材料、内部党课课件及党员学习记录。数据更新节奏为每月同步上级政策文件，每季度更新内部党课及学习总结文档。单篇文档包含标题、正文、发布单位、发布日期、所属支部等字段，部分文档涉及船舶制造专有党建结合生产的表述，文档长度跨度从数百字符到上万字符不等。

## 这些特征在「模型接入与配置」这一环带来什么约束
船舶制造党建数据包含专有行业术语与结构化元数据，要求模型接入时需适配专有表述的语义理解，避免出现术语误解。文档长度跨度大，要求配置需覆盖不同长度的上下文处理需求，避免截断核心内容。数据更新频率明确，要求配置定时同步任务的触发规则，保证问答内容与最新党建材料同步。结构化元数据的存在，要求配置中需明确引用源文档的元信息，提升回答的可信度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配船舶制造党建文档的长上下文需求，覆盖单篇年度党建总结或完整党课课件的内容 |
| `maxTokens` | 2000–3000 token | 控制单轮回答长度，匹配船舶制造党建问答的场景需求，保证回答包含足够的专有术语解释 |
| `quoteMaxToken` | 1500 token | 限制引用的源文档片段总长度，贴合船舶制造党建数据的单段内容长度特征 |
| `temperature` | 0.2–0.4 | 降低回答随机性，保证党建问答内容的严谨性，符合国央企党建场景的规范要求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写对应节点 | 适配不同部署场景的模型调用路径，确保模型接入的稳定性 |
| `AIPROXY_API_TOKEN` | 按实际分配的密钥填写 | 保证模型调用的身份验证合规，符合国央企系统的安全管理要求 |

## 容易做错的三处
- 调用模型后返回空内容，原因是未正确配置`quoteMaxToken`参数，导致引用的船舶制造党建文档片段超出限制被截断，无法生成有效回答。
- 升级FastGPT v4.17.0后，模型回答末尾出现规则追溯展示符号，原因是未关闭模型的规则引用默认展示配置，导致额外内容被追加至回答末尾。
- 本地部署模型后无法正常发起问答请求，原因是未将`AIPROXY_API_ENDPOINT`配置为本地模型的实际访问地址，导致API请求无法连通目标模型。

## 怎么确认配好了
- 发起一条船舶制造党建相关的测试问题，例如“船舶制造企业如何结合生产开展主题党日活动”，检查回答是否包含对应专有术语且无空内容。
- 查看模型调用日志，确认`AIPROXY_API_TOKEN`验证通过，无身份验证相关的报错信息。
- 调整`temperature`参数至不同区间后发起多轮测试，确认回答的随机性符合预期，无过度发散或内容缺失的情况。
- 检查回答末尾是否无额外的规则追溯符号，确认配置生效。
