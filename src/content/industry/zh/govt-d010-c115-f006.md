# 轨道交通装备的党建学习问答：引用来源与溯源

## 这个品类的数据长什么样
轨道交通装备制造企业的党建学习数据，来源为企业内部党建工作平台、上级国资委党委下发的标准化学习文件、各分厂的月度学习纪要。更新节奏为每周更新1次学习课件，每月更新1次党委正式文件。文档采用统一结构化格式，包含标题、正文段落、发布主体、发布日期、关联政策编号5个固定字段，字段均为纯文本或标准YYYY-MM-DD日期格式，无嵌套附件或非结构化内容。

## 这些特征在「引用来源与溯源」这一环带来什么约束
党建学习文档的固定发布主体与政策编号字段，要求溯源环节需同步展示这些非正文信息，确保溯源内容完整匹配原始文档。每周/月度的更新节奏，要求溯源需自动标注文档的最新发布日期，避免返回过期的学习材料。纯文本结构化的文档格式，要求溯源提取的字段需与原始文档字段完全一致，不可篡改或遗漏字段内容。同时，轨道交通装备企业的党建文档多存储于内部专网，溯源链接需适配内网访问权限，确保授权用户可直接跳转至原始文档。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `quoteMaxToken` | 3000–5000 token | 轨道交通装备党建文档单篇多为1000–3000字符，预留足够token用于完整提取所有文档字段与正文 |
| 单次搜索上限 | 前3条 | 匹配党建学习问答的精准性需求，避免过多冗余文档干扰溯源判断 |
| `responseData` | 包含标题、发布主体、发布日期、关联编号 | 匹配文档固定结构，确保溯源展示的字段与原始文档完全一致 |
| 溯源链接生成规则 | 绑定企业内网访问域名 | 适配企业内部专网的访问权限，确保授权用户可正常跳转至原始文档 |
| `detail` | 开启完整字段展示 | 补充发布主体与政策编号等非正文信息，强化溯源的可信度 |
| 上下文窗口限制 | 8000–10000 token | 适配多文档拼接后的总长度，避免截断关键溯源信息 |

## 容易做错的三处
- 现象：工作流中配置的引用条数仅返回2条，远低于知识库搜索的上限。原因：未区分知识库搜索与工作流的`quoteMaxToken`默认参数，工作流默认取值更低。
- 现象：溯源展示的内容仅包含正文，未显示发布单位与政策编号。原因：未配置`responseData`提取指定字段，仅返回了纯文本正文内容。
- 现象：点击溯源链接无法访问原始文档。原因：未适配企业内网域名，使用了公网链接格式生成溯源地址。

## 怎么确认配好了
- 发起党建学习相关提问，检查返回结果中是否附带了文档的发布主体、发布日期等配置要求的字段。
- 查看工作流或知识库节点的配置面板，确认`quoteMaxToken`的取值与当前场景的文档长度匹配。
- 点击溯源链接，验证是否可在企业内网环境下正常访问原始文档。
- 对比不同提问的溯源结果条数，确认单次搜索上限的配置已生效。
