# 通信工程建设的党建学习问答：多轮对话与提示词
本页面适配FastGPT v4.17.0版本。

## 这个品类的数据长什么样
通信工程建设领域的党建学习问答数据，主要来源于通信行业各级党委下发的标准化党建学习手册、项目临时党支部的学习台账、工程现场的党建宣传材料。数据更新节奏为每月更新最新党建政策要点，每季度更新适配工程场景的党建案例。单份文档为结构化格式，包含主题分类、适用工程场景、学习要求、考核标准等字段，以基础文档条目为统计单位，部分现场学习材料为音频转写后的结构化文本。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
通信工程建设党建数据的分散来源，要求多轮对话系统支持跨手册、台账、转写文本的上下文关联，避免仅依赖单份文档的问答局限。月度与季度的更新节奏，要求提示词配置定期同步最新政策的触发逻辑，确保返回内容贴合当前党建要求。结构化字段中的适用工程场景，要求多轮对话在提示词中绑定对应工程类型的过滤规则，仅返回适配基站建设、光缆铺设等场景的党建内容。音频转写文本的格式误差，要求多轮对话预处理环节增加术语校验，修正转写中的专业术语错误，保障问答准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chatId` | 按用户设备生成唯一标识 | 实现免登陆场景下的历史对话存储，匹配社区用户的相关提问 |
| `messages` | 保留前10条对话记录 | 适配通信工程党建学习的多轮讨论节奏，避免过长上下文干扰 |
| `variables` | 绑定工程场景字段 | 基于通信工程党建数据的适用场景字段，过滤非适配的问答内容 |
| 上下文窗口大小 | 8000–12000 token | 适配通信工程党建文档的多轮对话上下文长度 |
| 提示词更新频率 | 每月1次 | 匹配党建政策的月度更新节奏，保障问答内容时效性 |
| 对话开场白快捷按键 | 预设3个高频党建问题 | 支持用户一键发送问题，适配现场工程人员的学习习惯 |

## 容易做错的三处
- 现象：免登陆场景下历史对话记录为空。原因：未使用`chatId`绑定用户设备标识，导致会话存储与用户身份解绑。
- 现象：对话开场白的快捷按键点击后无内容发送。原因：未配置按键对应的预设问题参数，未绑定消息发送触发逻辑。
- 现象：对话中出现不必要的引用来源展示。原因：未在对话配置中禁用引用展示功能，导致系统默认开启引用输出。

## 怎么确认配好了
- 执行免登陆会话测试，发起两轮对话后退出系统，重新进入后查看历史对话是否保留，确认`chatId`配置生效。
- 点击对话开场白的快捷按键，查看输入框是否自动填充预设问题，确认快捷触发逻辑配置生效。
- 输入特定工程场景的问题，查看返回结果是否仅包含该场景下的党建内容，确认`variables`场景过滤配置生效。
- 发起多轮对话，查看上下文是否按预设条数保留，确认`messages`参数配置生效。
