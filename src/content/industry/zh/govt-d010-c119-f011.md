# 钢铁冶炼的党建学习问答：表单与交互

## 这个品类的数据长什么样
本品类的数据主要来自钢铁冶炼类国央企的党建管理系统、党委办公室归档文件、班组学习台账。数据更新节奏分为三类：上级党建政策通知实时同步，月度学习计划每月初更新，季度考核档案每季度末归档。文档形态包含标准化问答题库、学习课件、签到表单三类，字段包含学习主题、发布单位、发布日期、考核分值、答题时长要求，单位依次为无、无、日期、分、分钟。

## 这些特征在「表单与交互」这一环带来什么约束
党建问答题库的标准化属性要求交互表单必须预设固定答题选项，避免自由输入导致答案与标准答案不符。钢铁冶炼班组的轮班作业模式，要求表单支持按班组、班次配置答题权限，仅对应班组用户可访问对应学习内容。大型学习课件的存在要求表单上传环节限制单文件体积，避免解析超时。季度考核档案的归档要求，要求交互流程可关联对应季度的题库与签到数据，实现学习记录的自动归档。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `userSelect` | 配置为绑定炼钢一班、炼钢二班、检修班3个预设选项 | 匹配钢铁冶炼班组的作业分组模式 |
| `formInput` | 800–1200 字符 | 适配党建问答的答题描述常规长度 |
| 文件上传单文件限制 | 100 MB | 适配大型党建学习课件的常见体积 |
| 答题超时阈值 | 600 秒 | 符合单题答题的合理作业时长 |
| 表单提交触发方式 | 点击提交按钮后触发 | 匹配党建学习的正式提交流程 |

## 容易做错的三处
- 现象：提交党建问答表单时提示输入内容超限，无法完成提交。原因：未配置`formInput`的最大字符数限制，或限制值小于用户输入的答题内容长度。
- 现象：调用党建学习考核的工作流后，`userSelect`节点后的权限校验节点未执行。原因：`userSelect`节点的输出未正确绑定后续节点的触发条件，导致流程中断。
- 现象：上传党建课件后解析失败，界面显示文件格式不支持。原因：未配置表单上传允许的文件类型，仅开放了文本格式，未包含PDF、Word等课件格式。

## 怎么确认配好了
- 进入表单编辑页面，核对`userSelect`的预设选项是否匹配业务需要的班组分组。
- 测试上传不同类型的党建课件文件，确认表单支持的文件类型符合配置要求。
- 模拟输入答题内容，验证表单的输入长度限制是否符合业务场景的实际需求。
- 触发工作流调用，确认`userSelect`节点的输出可正常流转至后续流程节点。
