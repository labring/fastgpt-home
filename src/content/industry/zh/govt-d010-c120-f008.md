# 铁路运营的党建学习问答：文档解析与分块

## 这个品类的数据长什么样
铁路运营党建学习的数据源主要来自内部党委发布的正式学习文件、支部会议纪要、线上党课课件，以及共享平台存储的党建知识库文档。更新节奏随季度学习计划调整，无固定周期但每月均有新增内容。文档多为PDF、Word格式，部分内嵌PPT截图、活动照片与考核进度表格，字段包含文件编号、发布部门、发布日期与学习主题，部分文档附带学时、考核次数等单位信息。

## 这些特征在「文档解析与分块」这一环带来什么约束
铁路运营党建学习的文档特征对解析分块带来多重约束。正式红头文件的固定标题层级与编号逻辑，要求解析时保留结构完整性，避免分块割裂文件逻辑；内嵌PPT截图、活动照片与考核表格，需要识别并关联对应上下文，确保大模型可获取图文关联信息；多来源的分散文档需支持批量解析，同时需适配不同格式的解析规则；附带学时、考核次数等单位的内容，需保留单位与对应文本的绑定关系，避免语义断裂。

## 配置怎么定
以下配置项均基于FastGPT v4.17.0版本的官方设置：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | `800–1200 字符` | 铁路党建文档多为正式行文，单块长度适配常规语义单元，避免过长导致嵌入失效或过短破坏上下文关联 |
| `chunkSplitter` | 按标题与段落分隔 | 文档存在固定标题层级，按标题分块可保留语义完整性，适配红头文件的结构特征 |
| `customPdfParse` | 开启 | 铁路党建文档多为PDF格式，开启自定义解析可保留内嵌图片与表格的关联信息，解决图文分离问题 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 单份党建文档可能包含多页课件与图片，需足够超时时间完成完整解析，避免中途中断 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 铁路党建文档单份大小通常符合该区间，设置该值可避免超大文件占用过多解析资源 |
| `chunkSettingMode` | 手动配置 | 需针对铁路党建文档的结构特征调整分块规则，手动配置可适配特定格式需求 |

## 容易做错的三处
- 现象：解析后的知识库结果中无内嵌图片的关联文本，或图片无法被大模型调用。原因：未开启`customPdfParse`配置，默认解析逻辑未保留内嵌图片与上下文的绑定关系。
- 现象：导入语雀公开分享链接时提示解析失败，或返回空知识库内容。原因：使用了非公开可访问的语雀链接，或链接未被系统识别为合法的知识库数据源格式。
- 现象：调用工具发起HTTP请求时，参数解析正常但未执行对应操作。原因：未配置工具的权限参数，或请求超时时间设置过短导致提前中断。

## 怎么确认配好了
- 上传一份包含内嵌图片的党建PDF文档，核对解析结果中是否保留图片与对应文本的关联关系。
- 导入一条公开可访问的党建类语雀共享链接，确认解析任务正常完成并生成有效分块。
- 调整`chunkSplitter`配置后，检查分块结果是否保留了文档的标题层级与逻辑结构。
- 上传一份飞书多维文档，确认解析系统生成了对应的知识库索引条目。
