# 公文格式校对的公文辅助：工具调用与插件

## 这个品类的数据长什么样
公文格式校对的数据来源于国央企、公共服务领域的正式公文文稿与官方公文格式规范文档。数据随新的公文印发要求更新，更新节奏与官方发文标准同步。单份文档结构固定，包含版头、主体、版记三大模块，包含发文字号、密级、紧急程度、标题、正文、成文日期等标准化字段，字段需符合官方规定的格式要求，内容以纯文本为主，附带少量基础格式标记。

## 这些特征在「工具调用与插件」这一环带来什么约束
固定的文档结构要求工具调用需精准匹配版头、主体、版记的模块校验逻辑，不能泛化处理。随官方标准更新的数据要求工具插件需支持定期同步最新格式规则，避免校验逻辑滞后。标准化字段的强制校验要求工具调用节点需针对每个字段单独配置校验规则，确保覆盖所有强制校验项。纯文本为主的内容要求插件调用时需优先处理文本字段，避免非文本内容干扰校验。公文格式的严格顺序要求工具调用的校验步骤需匹配官方规定的文档排版顺序，不能打乱校验逻辑。

## 配置怎么定
本页面适配FastGPT v4.17.0版本的工具调用与插件配置逻辑。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 设为`{"type": "function", "function": {"name": "gov_document_format_check"}}` | 明确指定调用公文格式校验的专用工具，避免模型生成无关回复 |
| `functionCall` | 开启强制调用模式，仅返回校验结果 | 聚焦校验结果输出，符合无额外AI回复的使用需求 |
| HTTP工具集接口配置 | 目标接口地址填写官方校验API地址，超时时间设为30秒 | 适配公共服务场景的网络环境，超时时长匹配校验逻辑的执行周期 |
| 校验字段范围 | 选择官方规定的18个标准字段 | 确保覆盖所有强制校验的格式要求，避免遗漏关键校验项 |
| 规则更新频率 | 按每月1次同步官方最新标准 | 适配官方公文格式标准的更新节奏，保证校验逻辑的时效性 |

## 容易做错的三处
- 现象：调用HTTP工具集时返回`message: Invalid URL, code: 500`。原因：未正确配置工具集的目标接口地址，或接口地址未适配公共服务网络的访问限制。
- 现象：工具调用节点返回空的校验结果或无有效字段。原因：未针对公文的标准化字段配置`toolChoice`参数，导致校验工具未被正确触发。
- 现象：调用后返回截断的报错信息`Multimodal file size is`。原因：上传的公文文档超出工具允许的单文件大小限制，未提前对上传文件进行尺寸过滤。

## 怎么确认配好了
- 测试调用单份符合官方标准的公文文档，检查是否返回对应字段的校验结果。
- 查看工具调用日志，确认`toolChoice`参数已正确指定校验工具，无无关的模型回复输出。
- 触发规则更新同步动作，检查工具是否能拉取最新的官方格式标准配置。
- 模拟调用不符合尺寸要求的公文文档，确认工具会触发对应异常提示。
