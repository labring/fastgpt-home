# 讲话稿与汇报材料起草的公文辅助：工具调用与插件

## 这个品类的数据长什么样
讲话稿与汇报材料的数据源主要来自国央企、政府部门的内部公文存档系统、过往会议发言底稿、部门汇报台账。更新节奏随工作周期而定，包含月度、季度、年度常规汇报，以及临时专项工作汇报两种类型。文档结构固定，包含主送机关、文号、正文（背景说明、工作进展、现存问题、下一步计划）、落款单位与日期等模块，核心字段包括主题、起草人、审批状态、报送层级，内容多在1000-5000字符区间，单位以字符、日期、层级编号为主。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的固定文档结构要求工具调用需匹配特定文本格式提取字段，例如从文号、落款中提取单位信息。内部数据源的权限限制要求插件需配置身份验证规则，避免越权访问敏感公文。内容长度跨度较大，要求工具调用支持动态调整上下文窗口，适配不同篇幅的材料处理。报送层级的差异则要求插件可根据接收对象调整内容详略，确保输出符合对应层级的汇报规范。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | 设为`"auto"`，或指定为`"function"` | 适配该品类需要调用结构化提取、数据查询类插件的场景 |
| `functionCall` | 开启函数调用，单次调用参数数量不超过5个 | 匹配该品类文档的核心字段数量，避免参数过载导致调用失败 |
| 插件数据源权限 | 配置内部系统白名单，仅允许访问已授权的公文存档库 | 保障内部文档访问的合规性，符合行业数据安全要求 |
| 调用超时阈值 | 设为`30–60 秒` | 适配该品类文档的平均处理时长，避免因文档过长导致超时 |
| 上下文窗口长度 | 设为`8000–12000 token` | 适配该品类1000-5000字符的文档长度，避免截断核心内容 |
| 内容匹配规则 | 按文档结构字段匹配召回历史材料 | 匹配讲话稿/汇报材料的固定格式特征，提升召回内容的相关性 |

## 容易做错的三处
- 配置`toolChoice`和`functionCall`参数后，内容提取节点返回空字段。原因：未正确配置自建模型的接口权限，或参数取值不符合插件的调用要求。
- 调用插件时返回401未授权错误，使用Postman调用同一密钥正常。原因：插件配置中未正确携带身份验证参数，或密钥的权限范围未覆盖插件接口。
- 调用联网类插件时无法获取外部数据。原因：未配置适配国内网络环境的代理或替代插件，导致无法正常发起网络请求。

## 怎么确认配好了
- 手动触发一次插件调用，检查返回结果是否包含讲话稿/汇报材料的核心字段，如主题、报送层级、落款单位。
- 查看插件调用日志，确认`toolChoice`和`functionCall`参数被正确传递至接口。
- 尝试调用未授权的内部文档库，确认系统触发权限拦截，验证数据源配置的有效性。
- 调整插件调用的参数数量，检查是否触发预期的内容提取或数据查询动作，确认参数配置生效。
