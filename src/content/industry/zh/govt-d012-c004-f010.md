# 主动公开与政策发布的内部办公与员工服务：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来源包括政府门户网站、公文系统、政府信息公开目录、政策文件库、新闻发布会材料。更新频率为每日。日常文档包含政策文件、政策解读稿、公开目录、信息发布审批单、新闻通稿、网站栏目更新记录。数据字段包含公开属性、保密等级、发布时限、所属栏目、审批状态等，部分文档附带发布审批流程记录与多渠道同步标记。

## 这些特征在「知识库检索与召回」这一环带来什么约束
每日更新的数据源要求检索环节支持增量同步与增量召回，避免全量扫描消耗过多资源。多类型文档的结构差异要求检索配置适配不同文档的字段特征，例如政策文件需优先匹配文号与条款，公开目录需匹配栏目与发布时间。公开属性与保密等级字段的存在，要求检索结果需自动过滤未达到公开标准的内容，防止敏感信息流出。多渠道同步标记则要求召回结果需匹配目标发布渠道的栏目规则，确保检索内容符合对应发布场景的要求。

以下配置基于FastGPT v4.17.0版本制定。
## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 过滤低匹配度内容，避免非相关政策或解读混入检索结果，符合政务内容的精准性要求 |
| `limit` | 前 8 条 | 控制单次召回结果数量，适配内部办公场景下的快速查阅需求，同时避免过多内容占用上下文 |
| `searchMode` | hybrid | 结合语义与关键词匹配，兼顾政策文件的条款精准匹配与公开目录的关键词检索需求 |
| `usingReRank` | 开启 | 对初始召回结果进行重排序，提升高相关性内容的展示优先级，适配政策内容的重要性差异 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展检索词，补充政策相关的同义词与简称，适配政务术语的多样性 |
| `collectionIds` | 按业务分组配置 | 区分公开目录、政策文件等不同数据集，确保检索范围限定在对应业务文档内 |

## 容易做错的三处
- 检索结果返回条数与配置的`limit`参数不符，现象为界面展示的结果条数超出或少于预设值，原因是未同步更新工作流中检索节点的参数配置，或混淆了全局与单节点的参数设置。
- CSV文件上传后无法按自定义分隔符拆分内容，现象为文件内容未按预期分割为独立文本块，出现整行未拆分的情况，原因是未正确勾选自定义分隔符选项，或输入的分隔符包含不可见字符。
- 检索节点的使用者鉴权不生效，现象为未授权的内部员工仍可访问涉密或未公开的政策文档，原因是未将鉴权规则绑定至对应知识库集合，或鉴权配置的范围未覆盖当前检索节点的数据集。

## 怎么确认配好了
- 上传一份测试用的政策文件与公开目录，执行检索操作，核对返回结果的条数与`limit`参数的预设值一致。
- 模拟涉密文档的检索请求，确认结果中未包含该类文档，验证过滤规则生效。
- 上传一份使用自定义分隔符的CSV测试文件，查看文本块拆分结果是否符合预期。
- 检查检索节点的鉴权配置，确认仅授权范围内的用户可触发检索操作。
