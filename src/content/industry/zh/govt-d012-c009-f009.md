# 公共数据目录与开放的内部办公与员工服务：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据主要来源于地方公共数据开放平台、一体化大数据平台、部门业务数据库与电子证照库。日常维护的文档包括公共数据资源目录、数据开放清单、数据项说明、脱敏规则、接口文档与更新频率说明。数据更新频率为每月一次，单份文档包含数据项名称、开放条件、脱敏要求、调用接口、更新周期等结构化字段，部分文档附带接口调用示例与权限说明。

## 这些特征在「模型接入与配置」这一环带来什么约束
月更的数据更新节奏要求模型接入配置需匹配同步周期，避免使用过期的目录内容。结构化的文档字段与接口说明，要求配置需支持精准召回特定字段内容，同时需校验数据开放条件与脱敏规则。多来源的数据需要统一的上下文管理，避免不同部门的数据格式差异导致模型输出混乱。此外，接口文档的参数复杂度，要求配置需限制单条引用的长度，防止上下文溢出影响召回效果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配公共数据目录与开放清单的总长度，避免截断核心权限与接口信息 |
| `maxTokens` | 2000 token | 覆盖单条数据项说明的完整输出，包含脱敏规则与调用参数 |
| `quoteMaxToken` | 1200–1500 字符 | 限制单条引用数据的长度，确保可同时召回多条数据项用于综合输出 |
| `temperature` | 0.2–0.4 | 保持数据输出的准确性，减少无关内容生成，符合政务数据的严谨要求 |
| `AIPROXY_API_ENDPOINT` | 按FastGPT v4.17.0平台提供的官方地址填写 | 确保模型调用链路正常，适配公共数据接口的访问规则 |
| `AIPROXY_API_TOKEN` | 填写平台分配的专属密钥 | 保障接口调用的身份验证安全，防止未授权访问 |

## 容易做错的三处
- 现象：调试时出现Connection error报错。原因：未正确填写`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`，或公共数据开放平台的接口访问权限未向配置节点开放。
- 现象：模型仅返回匹配度最高的一个文本块。原因：未合理配置`quoteMaxToken`，单条数据项占用了全部可用上下文，导致无法召回多条结果进行综合输出。
- 现象：无法对模型输出的公共数据说明内容进行润色扩写。原因：未开启`toolChoice`配置，或未将完整的公共数据目录与开放清单纳入模型上下文范围。

## 怎么确认配好了
- 核对`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`是否与FastGPT v4.17.0平台发放的信息一致，发起测试调用查看是否返回正常的结构化数据响应。
- 配置`maxContext`与`quoteMaxToken`后，导入单份数据开放清单，测试召回结果的条数是否符合预期的多块数据输出。
- 设置`temperature`为0.2–0.4区间，测试生成的公共数据说明内容是否保持准确且无冗余。
- 开启`toolChoice`配置，测试模型是否能基于导入的目录内容完成指定的润色扩写操作。
