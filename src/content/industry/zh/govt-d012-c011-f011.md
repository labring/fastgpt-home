# 养老、工伤、失业待遇核定的内部办公与员工服务：表单与交互

## 这个品类的数据长什么样
本品类数据来自社会保险经办系统、个人权益记录、劳动关系和工伤认定系统、电子社保卡平台，更新频率为每日。日常关联文档包含待遇申领表、缴费年限证明、退休审批表、工伤认定材料、失业保险金申领材料，数据字段包含缴费年限、待遇计发基数、认定编号、申领人身份信息等，单位涵盖年、月、元、条等，单份文档数据量随业务复杂度波动。

## 这些特征在「表单与交互」这一环带来什么约束
跨系统数据源要求表单支持联动加载关联字段，输入身份信息后自动拉取对应缴费年限、认定材料等数据。多类型文档对应差异化字段，需通过条件渲染区分养老、工伤、失业待遇核定的表单模块。数据单位不统一，需在表单中添加单位转换提示，避免录入错误。每日更新的数据源要求表单提交前触发最新数据校验，防止使用过期信息。严格的出错后果要求表单设置多层必填校验，减少漏填错填风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 触发延迟设为`800 毫秒`，联动接口超时设为`10 秒` | 社保数据接口响应普遍在5-10秒，延迟设置避免频繁触发接口调用 |
| 用户选择节点 | 按待遇类型分组展示选项，默认展开养老待遇模块 | 三类业务场景差异较大，分组可减少用户查找成本 |
| 表单校验规则 | 身份信息字段校验长度为`18 位`，缴费年限字段取值区间为`0–120 年` | 符合社保经办的身份信息和缴费年限常规范围 |
| 输入内容上限 | 单字段输入上限为`2000 字符` | 适配待遇申领说明类内容的常规长度 |
| 工作流变量配置 | 允许API传递知识库ID作为入参变量 | 适配不同经办场景调用对应社保政策知识库的需求 |

## 容易做错的三处
- 现象：调用工作流时传递知识库变量后，知识库搜索节点无法读取变量内容。原因：未将变量配置为工作流入参，或变量作用域未覆盖知识库搜索节点。
- 现象：工作流A调用工作流B后，工作流B中`userSelect`节点后的所有节点停止执行。原因：未设置`userSelect`节点的默认提交动作，或子工作流未正确接收父工作流传递的上下文参数。
- 现象：输入待遇申领说明内容时触发报错，提示内容超出上限。原因：未调整表单输入内容上限配置，使用了默认的较小字符限制。

## 怎么确认配好了
- 确认当前使用的FastGPT版本为v4.17.0。
- 触发申领人身份信息输入，检查是否自动拉取对应缴费年限、认定材料等关联数据。
- 切换待遇类型选项，检查表单模块是否按选择正确切换显示。
- 调用API传递知识库ID变量，检查知识库搜索节点是否能正确读取变量内容。
