# 国土空间规划编制与实施评估的内部办公与员工服务：文档解析与分块

## 这个品类的数据长什么样
本品类的日常文档包含国土空间总体规划、详细规划、专项规划及规划实施评估报告、公众意见汇总等。数据主要来自国土空间基础信息平台、自然资源调查监测数据、人口经济统计资料与遥感影像成果，更新频率为年度。文档多包含空间坐标、约束指标、区域范围等字段，单位涉及平方公里、公顷、人口数等，结构上既有纯文本说明，也嵌入表格、空间数据附件与图表。

## 这些特征在「文档解析与分块」这一环带来什么约束
多源数据来源要求解析环节兼容不同格式的附属文件，包括遥感影像附件、结构化表格与空间坐标文本。年度更新的特性意味着单次解析的文档体量较大，需兼顾解析效率与完整性。文档中包含的空间约束指标、区域范围等特定字段，要求分块时保留上下文关联性，避免割裂跨页的指标说明。同时，文档内的图表、公式类内容，需在解析时保留格式关联，防止分块后无法还原数据逻辑。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `chunkSize` | 800–1200 字符 | 本品类文档多包含长文本的指标说明与空间范围描述，该区间可平衡上下文完整性与检索精度 |
| `chunkSplitter` | 按段落+标题 | 本品类文档按规划章节、指标项分层，按标题分块可保留章节逻辑 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 大型规划文档解析耗时较长，该时长可覆盖全量内容解析 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 单份规划文档可能包含多期遥感影像附件，需允许较大文件上传 |
| `customPdfParse` | 开启 | 本品类文档多包含内嵌表格与空间坐标，自定义解析可优化格式还原效果 |
| `chunkSettingMode` | 手动配置 | 需针对不同文档类型调整分块规则，适配多源数据格式 |

## 容易做错的三处
- 现象：上传含图片的docx文件后解析失败，返回`Invalid image file`报错。原因：未开启`customPdfParse`配置，默认解析引擎无法兼容规划文档中嵌入的遥感影像缩略图或空间标注图片。
- 现象：解析大型规划文档时，日志持续报`slow operation xxxxms`，且仅抓取到部分数据。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认时长不足以完成全量内容解析，导致解析中断。
- 现象：Markdown格式的表格内容在检索后展示被截断。原因：`chunkSize`配置过小，割裂了表格的完整行或跨页的指标说明，导致分块时丢失表格上下文。

## 怎么确认配好了
- 上传一份包含图片与表格的小型规划文档，查看解析结果是否完整还原图片占位与表格格式。
- 查看`PARSE_FILE_TIMEOUT_SECONDS`配置项，确认其取值大于600秒，可通过上传100 MB以上的测试文档验证解析是否超时。
- 随机抽取文档中的跨页指标说明，检查分块结果是否保留了指标的前后文关联。
- 检查`UPLOAD_FILE_MAX_SIZE`配置是否设置为1000 MB以上，可尝试上传包含遥感影像附件的测试文件验证上传与解析流程。
