# 土地使用权、矿业权与国有产权交易的内部办公与员工服务：工具调用与插件

## 这个品类的数据长什么样
该品类的核心数据来自全国公共资源交易平台、自然资源交易系统、产权交易所系统、国资监管系统，更新频率为每日。日常文档包含出让公告、交易须知、竞买申请、保证金凭证、成交确认书、挂牌结果公告、产权转让说明书，字段涵盖权属编号、交易标的类型、保证金金额、竞买资格条件等，单位包含亩、万元、宗等资源资产专属计量方式，单份文档的核心字段集中且关联度较高。

## 这些特征在「工具调用与插件」这一环带来什么约束
多数据源的接入需求要求插件需适配不同系统的API格式与权限规则；日更的数据更新频率要求工具调用需匹配定时同步逻辑，避免使用过期的交易数据；多样的文档结构要求工具调用需适配不同文档的解析规则，精准提取权属、竞价等核心字段；专属的字段与单位要求工具调用的参数校验需覆盖资源资产相关的合规规则，确保数据的准确性与一致性。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，具体配置项及建议如下：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配该品类多类交易文档的工具调用需求，自动选择合适的工具完成权属校验或数据查询 |
| 单次工具调用上限 | `前3条` | 该品类的交易文档单批次核心字段集中，过多调用会增加系统校验成本与耗时，避免冗余数据干扰核心流程 |
| 工具调用超时时间 | `60-90秒` | 对接多系统数据源时，同步交易数据的耗时较长，需预留足够的响应时间以完成完整的权属校验或数据拉取 |
| 问题优化 | `启用，使用业务专属prompt` | 该品类的权属、竞价相关问题存在专属语义特征，专属prompt可减少歧义，提升工具调用的准确性与合规性 |
| 知识库同步频率 | `每日凌晨2点` | 匹配数据日更的更新频率，选择低峰期同步可避免影响日常办公业务 |
| 最大上下文长度 | `8000 token` | 匹配该品类交易相关的权属材料、竞价记录的长文本上下文需求，确保完整提取关键信息 |
| `functionCall` | `仅允许权属校验、竞价相关工具` | 聚焦该品类的核心交易环节，避免调用无关工具引发数据混乱或合规风险 |

## 容易做错的三处
- 现象：调用工具时返回`messages is empty`错误。原因：未在请求体中正确填充历史对话上下文，尤其是未携带与权属查询、竞价相关的系统提示词。
- 现象：工具调用返回的结果缺少权属编号或保证金金额等核心字段。原因：未配置对应数据源的API参数校验，未过滤非交易类的冗余数据。
- 现象：工具调用频繁触发超时错误。原因：将工具调用超时时间设置过短，未匹配对接多系统数据源的实际耗时。

## 怎么确认配好了
- 发起包含土地权属查询的测试请求，查看系统日志，确认`toolChoice`参数被正确触发，工具调用链路正常。
- 检查工具调用返回的结果，确认包含交易须知、权属编号、保证金金额等该品类核心文档字段。
- 模拟每日数据同步场景，确认工具调用能按时拉取最新的挂牌结果公告数据。
- 连续发起多次测试请求，确认未出现`messages is empty`或超时类错误。
