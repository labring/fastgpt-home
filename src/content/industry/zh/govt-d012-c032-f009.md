# 投资项目立项与后评价的内部办公与员工服务：模型接入与配置

仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这个品类的数据长什么样
本品类的数据主要来自国资委投资监管系统、企业ERP与项目管理系统、行业市场数据、审计及财务报表。日常处理的文档包含年度投资计划、项目建议书、可行性研究报告、尽职调查报告、资产评估报告、投资后评价报告。数据更新节奏为季度级，核心字段涵盖项目标识、投资规模、实施周期、评估结论等，部分字段需结合行业分类匹配对应口径。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类的数据来源分散且更新周期固定，要求模型接入环节需支持多系统数据的批量同步与增量更新，避免重复加载季度外的历史数据。核心文档篇幅跨度大，从简短的立项申请到数十页的后评价报告均有覆盖，对上下文窗口的适配性提出明确要求。同时，数据关联国资监管要求，配置环节需确保工具调用的可追溯性，且需匹配业务场景的审批流程逻辑，避免生成不符合监管要求的内容。另外，数据字段无统一固定单位，需配置环节支持自定义字段映射规则，适配不同项目的口径差异。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 适配从立项申请到后评价报告的全量文档上下文，避免关键信息截断 |
| `maxTokens` | `4000–6000 token` | 平衡生成内容长度与响应速度，满足投决材料整理、后评价报告撰写的输出需求 |
| `temperature` | `0.3–0.5` | 降低生成内容的随机性，确保项目数据与评估结论的严谨性，符合国资监管的合规要求 |
| `toolChoice` | `auto` | 自动触发工具调用以获取最新的项目管理系统数据与监管政策信息，适配动态更新的业务场景 |
| `quoteMaxToken` | `2000–3000 token` | 保留足够的原文引用片段，支撑后评价报告的论证逻辑与合规溯源 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写专属接口地址 | 确保模型调用链路通畅，适配企业内部网络的访问限制 |

## 容易做错的三处
- 现象：数据源配置页面显示已绑定飞书相关服务，但检索时仅返回云盘零散文件，未匹配到项目建议书等结构化文档。原因：未在飞书数据源配置中选择正确的知识库类型，误绑定了通用云盘目录。
- 现象：嵌入模型调用返回401状态码，或部署日志显示接口密钥无效。原因：未正确填写`AIPROXY_API_TOKEN`，或未为当前FastGPT实例申请对应模型的调用权限。
- 现象：工具调用环节无返回结果，或生成的后评价报告未引用项目核心数据。原因：`toolChoice`被强制设置为`none`，未开启自动工具调用，或`maxContext`设置过小，无法覆盖必要的项目上下文信息。

## 怎么确认配好了
- 测试检索指定的年度投资计划文档，确认返回结果包含完整的项目条目与对应字段，无遗漏或冗余内容。
- 触发工具调用测试，验证是否能自动获取最新的项目管理系统数据，生成符合业务逻辑的中间结果。
- 查看部署日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置正确，无接口调用报错。
- 调整`temperature`参数后，对比两次生成的项目建议书内容，确认输出严谨性符合业务场景要求。
