# 排污许可管理的内部办公与员工服务：多轮对话与提示词

## 这个品类的数据长什么样
本品类数据来自全国排污许可证管理信息平台、企业环保台账、在线监测系统、环境统计系统，更新频率为季度。日常处理的文档包括排污许可证申请表、执行报告、自行监测方案、台账记录、变更申请、许可证副本，核心字段包含许可限值、排放口信息、监测数据、变更事项等。本品类聚焦投产后的证后监管，不同于环评审批，不包含前置审批环节的内容，核心业务为核对合规要求与实际执行情况。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
多系统来源的数据要求多轮对话需保留跨平台的上下文关联，避免重复调取历史数据；季度更新的执行报告、台账等文档，要求提示词需适配季度性的业务核对周期，确保对话中引用的数据为最新版本；合规类文档的严格性要求多轮对话需完整保留历史许可条款、变更记录，防止核对时出现条款遗漏；岗位核心工作为核对、审核类操作，要求多轮对话需快速关联对应排污单位的专属数据，提升操作效率。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chatId` | 绑定统一社会信用代码+岗位ID | 确保多轮对话上下文隔离，避免不同排污单位的对话数据混淆 |
| `messages` | 保留最近20轮对话内容 | 覆盖季度内的完整沟通周期，容纳历史申请、变更、核对记录，同时控制上下文长度 |
| `variables` | 预设对应单位的许可限值、排放口清单、最新执行报告版本号 | 快速调用业务核心数据，减少重复检索耗时 |
| 最大上下文长度 | 8000–12000 token | 适配排污许可相关文档的长度，容纳多轮对话和关联的文档片段 |
| 问题优化 | 开启 | 自动补全员工提问中省略的排污单位信息，提升对话准确性 |
| 猜你想问 | 绑定排污许可业务关键词 | 生成符合岗位需求的推荐问题，覆盖核对、审核等核心环节 |

## 容易做错的三处
- 现象：调用对话记录删除接口后，日志显示`chatId`关联的记录未被清除，返回状态码400。原因：未将`chatId`绑定唯一的排污单位标识，导致删除操作匹配到其他单位的对话数据。
- 现象：上传飞书在线文档作为数据源后，对话无法读取文档内的自行监测方案内容。原因：未配置`variables`关联文档的共享权限标识，导致对话上下文无法访问私有文档数据。
- 现象：上传自行监测方案的PDF文件后，对话返回文件解析失败，提示字段为空。原因：未配置`messages`上下文允许携带文件解析后的元数据，导致系统无法关联文件内容与对话提问。

## 怎么确认配好了
- 发起模拟对话，输入某排污单位的变更申请相关问题，检查`chatId`是否绑定了正确的统一社会信用代码，确保上下文仅保留该单位的对话内容。
- 上传排污许可执行报告文件，发起核对许可限值的提问，检查`variables`是否正确加载了预设的许可限值数据，返回结果包含对应字段。
- 开启猜你想问功能，查看推荐问题是否包含“核对自行监测数据与许可限值”“检查台账记录合规性”等排污许可相关内容。
- 调用删除对话记录的接口，检查对应`chatId`的对话数据是否被完全清除，返回状态码200。
