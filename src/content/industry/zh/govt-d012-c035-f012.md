# 排污许可管理的内部办公与员工服务：部署与升级

本页面基于FastGPT v4.17.0版本的部署流程编写。

## 这个品类的数据长什么样
该品类的数据主要来自全国排污许可证管理信息平台、企业环保台账、在线监测系统、环境统计系统，更新频率为季度。日常处理的文档包括排污许可证申请表、执行报告、自行监测方案、台账记录、变更申请及许可证副本，文档需匹配对应行业技术规范、许可限值、自行监测数据与台账信息，字段涵盖排放口信息、污染物种类、排放浓度、总量限值等，单位多为mg/L、t/a等环境监测与排放相关标准单位。

## 这些特征在「部署与升级」这一环带来什么约束
季度更新的数据要求部署时配置稳定的增量同步机制，避免全量拉取占用过多数据库与网络资源。多类型结构化文档需支持按文档类型配置不同的处理规则，适配申请表、执行报告等不同结构的内容。数据来源分散需配置多数据源对接组件，确保从各系统同步数据的兼容性与准确性。排污许可相关信息的合规性要求部署后需保留完整的操作日志，便于后续监管溯源。同时，该品类涉及的字段专业性强，需在部署时配置自定义字段映射规则，适配不同行业的排放限值与台账格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30` | 适配季度批量同步排污许可数据的数据库连接需求，避免连接池耗尽影响同步效率 |
| `REDIS_URL` | 按实测标定 | 用于缓存季度更新的排污许可数据与用户操作会话，降低数据源查询压力 |
| `STORAGE_S3_ENDPOINT` | 对应企业内部对象存储服务的内网地址 | 存储排污许可相关的大型文档、监测数据与日志文件，保障数据存储的安全性与访问速度 |
| `FILE_TOKEN_KEY` | 自定义32位随机字符串 | 保障上传的自行监测报告、台账等敏感文件的访问权限，防止非授权下载 |
| `ROOT_KEY` | 仅内部运维人员知晓的复杂密钥 | 控制平台的最高权限，避免非授权人员修改许可数据配置与系统设置 |

## 容易做错的三处
- 打开OneAPI页面无可用渠道：现象为进入OneAPI管理界面后未显示已配置的模型渠道，原因是未正确配置`ROOT_KEY`权限，导致非授权用户无法加载渠道列表。
- 无法获取Docker离线部署包：现象为执行部署命令时无法拉取依赖镜像，原因是未提前准备适配FastGPT v4.17.0版本的离线镜像包，未在离线环境中完成镜像导入。
- 模型测试提示错误但运行可执行：现象为配置模型后点击测试返回报错提示，而在对话引用模型时可正常调用，原因是测试接口的超时阈值设置过短，未适配排污许可数据同步时的长耗时请求。

## 怎么确认配好了
- 执行数据库连接测试，查看连接池连接数在触发季度数据同步时未超过`DB_MAX_LINK`的配置值。
- 上传一份排污许可证副本文档，验证文件可正常存储并通过`FILE_TOKEN_KEY`生成的临时链接可正常访问。
- 触发一次模拟的季度数据同步任务，确认全国排污许可证管理信息平台、企业环保台账等数据源的数据可正常拉取并写入系统。
- 查看系统操作日志，确认所有配置修改与数据同步操作均记录完整，无权限异常或连接错误提示。
