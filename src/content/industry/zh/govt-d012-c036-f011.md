# 政务服务事项目录与办事指南维护的内部办公与员工服务：表单与交互

## 这个品类的数据长什么样
该品类的核心文档包括政务服务事项基本目录、实施清单、办事指南、标准材料目录、流程图与常见问题。数据通常取自国家政务服务事项基本目录、行政许可事项清单、权责清单及地方政务服务事项库，更新频率为每月一次。单份事项文档包含事项编码、事项名称、受理条件、申请材料清单、办理流程等标准化字段，部分字段需匹配上级目录的统一编码规则，材料清单需明确每份材料的形式、份数与提交要求。

## 这些特征在「表单与交互」这一环带来什么约束
数据来源的跨层级特性要求表单需支持多源数据的比对校验，避免本级事项与上级目录编码不一致。月度更新的节奏要求表单支持批量导入与增量更新，减少重复手动录入的工作量。字段的标准化要求需对受理条件、申请材料等核心字段设置强制校验，确保办事指南的字段完整性。同时，不同部门的事项文档存在细微字段差异，表单需支持自定义字段映射，适配各主体的本地管理需求。FastGPT v4.17.0的表单配置可适配上述约束。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 表单输入校验规则 | 对事项编码、申请材料份数设置强制校验，编码需匹配6位行政区划码+8位顺序码格式 | 依据国家政务服务事项编码的统一规范，确保事项唯一性 |
| 批量导入模板 | 预设标准模板，单次导入上限1000条，支持自定义字段扩展 | 适配月度更新的批量数据导入需求，减少格式错误 |
| 字段映射配置 | 映射上级目录字段与本地管理字段，保留1:1映射的默认选项 | 解决不同层级数据的字段差异问题 |
| `formInput` 超时设置 | 600秒 | 适配长文本的受理条件、办事指南内容录入 |
| `userSelect` 多选上限 | 前10条 | 限制单次选择的上级目录事项或关联知识库条目，避免批量操作过载 |
| 表单提交校验 | 触发字段完整性校验后返回未通过项清单 | 确保提交的事项文档符合基本格式要求 |

## 容易做错的三处
- 表单输入长文本后，页面缩放导致内容丢失。现象为界面展示的文本内容清空，无报错提示。原因是未配置`formInput`的本地缓存机制，页面缩放触发重绘时未保留用户输入的长文本。
- 未启用字段完整性校验，导致不完整的事项数据提交。现象为提交后仅提示保存成功，但缺少受理条件或申请材料字段。原因是未开启表单的强制校验规则，未拦截录入不完整的内容。
- 无法选择多个关联知识库用于事项校验。现象为配置校验规则时仅能选择单个知识库，无法批量关联多个上级目录知识库。原因是未调整`userSelect`的多选上限配置，限制了关联知识库的数量。

## 怎么确认配好了
- 手动录入一条超过500字符的受理条件文本，缩放页面后检查文本是否完整保留。
- 提交一份缺少申请材料字段的测试事项，检查是否返回字段缺失的具体提示。
- 配置`userSelect`的多选上限为前10条，尝试选择11个上级目录知识库，检查是否触发数量限制提示。
- 导入一份格式正确的测试事项模板，检查导入后的数据是否完整匹配预设的字段映射规则。
