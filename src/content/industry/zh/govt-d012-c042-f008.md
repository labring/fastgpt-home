# 法务合规与重大风险管理的内部办公与员工服务：文档解析与分块

## 这个品类的数据长什么样
本品类的数据来自企业合同管理系统、合规风险数据库、法律法规库、案件管理系统、举报平台，更新频率为月度。日常处理的文档包括合规风险清单、合同法律审核意见、重大事项法律意见书、合规审查表、违规举报调查报告。文档包含层级标题、结构化表格、长文本合规条款，部分文档附带证明图片或关联附件，单份大型报告的文本量较大。

## 这些特征在「文档解析与分块」这一环带来什么约束
多源数据的格式差异要求解析环节适配不同系统导出的文档结构，避免遗漏关键字段。月度批量更新的文档量较大，解析需支持稳定的批量处理能力。文档包含结构化表格与层级化合规条款，分块逻辑需保留内容上下文关联，避免破坏条款的完整逻辑。部分文档附带证明图片，解析需兼容图片嵌入格式，确保文本提取完整。解析结果的准确性直接关联合规审查质量，出错将引发重大法律风险，因此对解析完整性要求较高。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 800–1200 字符 | 合规文档包含长文本条款与结构化表格，该区间可保留上下文完整性，避免分块过碎破坏逻辑或过粗导致冗余 |
| `chunkSplitter` | 按段落+标题拆分 | 合规文档存在层级化的合规条款与审查节点，按标题拆分可保留文档逻辑结构，便于后续风险识别 |
| `customPdfParse` | 开启 | 适配合规文档中嵌入的证明图片、盖章区域与结构化表格，提取准确的文本与字段信息 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 支持导入包含多份附件的重大事项法律意见书，覆盖批量月度更新的大型文档需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 适配大型合规报告的解析耗时，避免因超时中断解析流程 |
| `chunkSettingMode` | 手动模式 | 可针对合同审核意见、合规审查表等不同文档类型调整分块参数，适配多样的文档结构 |

## 容易做错的三处
- 上传docx格式的合规审查表时，返回`Invalid image file`报错。原因是未开启`customPdfParse`的图片适配解析，默认解析逻辑无法处理文档中嵌入的合规证明图片。
- 导入数据库导出的合规风险清单时，仅抓取到部分表格数据。原因是未调整`chunkSplitter`适配表格结构，默认分块逻辑截断了表格行数据。
- Docker部署FastGPT v4.17.0后，上传大型合规报告解析时，日志持续报`slow operation xxxxms`。原因是`PARSE_FILE_TIMEOUT_SECONDS`设置值过低，无法完成大型文档的全量解析。

## 怎么确认配好了
- 上传带嵌入图片的docx格式违规举报调查报告，检查解析结果无报错且文本与图片关联信息完整。
- 上传数据库导出的完整合规审查表，检查解析结果包含全部表格字段与审核节点信息。
- 上传1000 MB以内的大型重大事项法律意见书，检查解析过程未触发超时提示。
- 调整`chunkSize`参数至不同区间，对比两种设置下的文本上下文保留情况，确认符合业务需求。
