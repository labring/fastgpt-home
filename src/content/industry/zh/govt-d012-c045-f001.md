# 用地预审与规划许可的内部办公与员工服务：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据主要来自国土空间规划一张图、项目审批监管平台、土地利用现状库、生态保护红线数据，更新频率不定期。日常流转的文档包括用地预审与选址意见书、建设用地规划许可证、建设工程规划许可证、红线图、规划条件，数据包含项目选址坐标、用地规模、管控边界、前置审批条件等字段，无统一固定的标准化单位，随项目实际情况匹配对应国土空间规划指标。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据来源分散且更新无固定周期，要求HTTP接口支持对接多套外部系统并适配不同的认证规则。日常流转的文档类型多样，接口需兼容矢量文件、PDF、结构化审批表单等多种格式的传输与解析。数据包含项目选址、红线范围等核心管控字段，接口返回的结构化数据需匹配国土空间规划的标准字段格式，便于内部办公系统完成选址冲突核对与前置条件协调，同时需具备异常数据拦截能力，避免错误数据流入审批流程。

## 配置怎么定
本文档适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | Bearer 外部系统API密钥 | 对接外部审批监管平台、国土空间规划一张图等系统时，符合OAuth2标准认证要求 |
| `variables` | 传入项目ID、红线坐标范围、生态保护红线图层标识 | 精准拉取对应项目的规划数据，避免全量拉取占用带宽 |
| `responseData` | 仅返回项目选址冲突项、前置审批缺失项、合规性校验结果 | 减少无效数据传输，适配内部办公系统的审核环节需求 |
| 超时时间 | 600 秒 | 用地预审数据拉取涉及多图层校验，需预留足够的响应时长 |
| 重试次数 | 3 次，间隔 10 秒 | 应对外部系统临时波动，避免单次请求失败导致审批流程阻塞 |

## 容易做错的三处
- 现象：调用接口时返回「401 Unauthorized」状态码，原因：未正确配置`Authorization`参数，或外部系统API密钥过期。
- 现象：接口接收的PDF或矢量文件无法被解析，返回空的`responseData`，原因：未配置适配多格式文档的传输头，或上传文件大小超出外部系统限制。
- 现象：流式响应中断，无法获取完整的校验结果，原因：未设置合理的超时参数，或外部系统未开启流式传输支持。

## 怎么确认配好了
- 调用测试接口，传入已知合规的项目参数，核对返回的`responseData`是否包含预期的合规校验结果。
- 检查`Authorization`参数是否匹配外部系统的认证要求，可通过调用外部系统的公开健康接口验证。
- 上传单份和多份符合格式的文档，确认接口能正常接收并返回解析结果。
- 模拟外部系统临时超时，确认接口会按配置的重试规则执行重试操作。
