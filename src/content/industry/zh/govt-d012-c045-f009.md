# 用地预审与规划许可的内部办公与员工服务：模型接入与配置

## 这个品类的数据长什么样
本品类数据主要来自国土空间规划一张图、项目审批监管平台、土地利用现状库、生态保护红线数据，更新频率不定期。日常处理的文档包括用地预审与选址意见书、建设用地规划许可证、建设工程规划许可证、红线图、规划条件，其中结构化文档包含项目主体信息、选址范围、用地规模、规划管控要求等字段，矢量图形类文档包含空间坐标与边界信息。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类数据的多源异构特征要求模型接入环节需同时兼容结构化文档与矢量空间数据的解析，不定期更新的数据源则要求配置支持动态调整数据同步范围。用地预审与规划许可的业务数据涉及空间坐标与管控指标的双重校验，模型需能关联空间信息与文本规则，且因出错后果影响项目立项与开工，配置环节需严格控制输出准确性。此外，跨部门协调前置条件的业务流程，要求模型接入可对接项目审批监管平台的接口，适配不同数据源的权限与格式要求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 本品类需关联多份前置审批文档与空间数据，需容纳足够上下文完成关联校验 |
| `maxTokens` | `4000–6000 token` | 业务校验需生成完整合规性分析，避免输出截断导致核心信息缺失 |
| `quoteMaxToken` | `2000 token` | 需引用红线图、规划条件等核心文档片段，控制引用内容长度以保证可读性 |
| `temperature` | `0.1–0.3` | 业务需严格符合规划管控规则，降低输出随机性以保证校验准确性 |
| `toolChoice` | `auto` | 需根据输入自动选择文本校验或空间解析工具，适配多源数据处理需求 |
| `AIPROXY_API_TOKEN` | 绑定专属团队密钥 | 满足模型隔离需求，便于后续按团队或用户核算模型调用费用 |

## 容易做错的三处
- 现象：模型调用耗时超过10秒，单次对话响应延迟明显。原因：未适配本品类多源空间数据的解析逻辑，或`maxContext`设置过大导致上下文加载耗时过长。
- 现象：接入多模态Embedding模型时测试失败，返回包含`Invalid`的报错信息。原因：未正确配置多模态数据的解析规则，或未匹配模型支持的文档格式与输入参数。
- 现象：团队内不同用户或部门的模型调用费用无法区分核算。原因：未使用专属团队密钥绑定模型调用，或未正确配置模型隔离相关的接入参数。

## 怎么确认配好了
- 发起包含项目选址范围与规划管控要求的测试请求，核对模型输出是否关联了对应数据源的核心信息。
- 模拟多源数据混合输入，检查模型是否能自动适配不同格式的文档与空间数据，完成校验逻辑。
- 查看模型调用日志，确认每个请求的响应时长符合业务预期，无异常超时情况。
- 验证不同团队或用户的密钥绑定后，模型调用的权限与费用统计是否可独立区分。
