# 财政支出绩效评价的内部办公与员工服务：部署与升级

## 这个品类的数据长什么样
本品类数据主要来自预算管理一体化系统、项目申报材料、资金支付数据、业务系统台账及满意度调查，更新频率为年度。日常处理的文档包含绩效目标表、自评表、绩效评价报告、佐证材料清单与整改报告，文档字段涵盖项目编号、资金额度、绩效指标、佐证材料关联标识等，无固定统一单位，需随具体项目匹配对应核算单位。数据关联逻辑复杂，需保障不同来源数据的一致性与关联性。

## 这些特征在「部署与升级」这一环带来什么约束
本品类年度更新的数据批量性强，单次导入数据量较大，要求部署环节配置适配大容量数据的存储连接参数。多来源的业务数据需对接预算管理一体化系统等多个外部系统，需预留灵活的数据源配置空间。多样的文档类型包含结构化表格与非结构化报告，要求部署时配置支持多格式文件解析的适配项。绩效数据关联逻辑复杂，需保障数据库连接的稳定性与查询效率，避免因连接过载导致任务中断。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `10–15 个连接` | 适配年度批量导入的大流量数据库连接需求，避免连接池耗尽 |
| `REDIS_URL` | 内部缓存实例地址 | 用于缓存绩效指标关联数据，适配多系统数据同步的缓存频率 |
| `STORAGE_S3_ENDPOINT` | 单位内部对象存储服务地址 | 用于存储佐证材料与整改报告等大体积文档，保障内部数据访问权限 |
| `MONGODB_URI` | 独立专用实例连接串 | 存储绩效评价报告与自评表等非结构化文档，与业务数据库隔离 |
| `PG_URL` | 预算管理一体化系统只读权限地址 | 用于拉取资金支付与项目申报的基础数据，保障数据安全性 |
| `FE_DOMAIN` | 内部办公系统二级域名 | 适配内部员工服务的访问权限，仅开放给单位内部网络 |

## 容易做错的三处
- Docker启动时出现OCI runtime create failed报错，原因是部署环境未配置无GPU兼容的启动参数，部分镜像依赖GPU加速环境导致启动失败。
- Redis镜像拉取失败，即使配置网络代理仍无法拉取，原因是新版本新增Redis镜像依赖，旧版本无对应镜像包。
- 工作流中MCP工具无法获取全局变量token，原因是未开启全局变量的工具访问权限，导致工具无法读取上下文参数。

## 怎么确认配好了
- 执行批量导入绩效目标表的测试任务，检查数据库连接池连接数未超过`DB_MAX_LINK`的配置值。
- 尝试拉取预算管理一体化系统的资金支付数据，验证`PG_URL`配置的只读权限正常。
- 上传佐证材料文档，检查存储路径与`STORAGE_S3_ENDPOINT`配置一致。
- 启动MCP工具测试，验证全局变量可正常传递至工具参数中。
