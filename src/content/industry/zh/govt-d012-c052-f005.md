# 部门决算与财务报告的内部办公与员工服务：工具调用与插件

## 这个品类的数据长什么样
本品类数据均来自预算管理一体化系统、国库集中支付系统、会计核算系统与资产管理系统，更新周期为年度。日常产出文档包含部门决算报表、资产负债表、收入支出决算表、决算说明、政府财务报告，文档字段涵盖收支明细、资产负债余额、预算执行差异说明等，单位多为元、万元，部分报表需按层级汇总下级单位数据。

## 这些特征在「工具调用与插件」这一环带来什么约束
年度更新的特性决定工具调用无需高频触发，可固定绑定年度数据源范围。多系统异构的数据来源，要求插件支持跨系统数据拉取与格式标准化处理。复杂的多文档结构，需工具调用支持分模块解析指定报表字段，完成字段与单位的映射。下级单位数据汇总需求，要求插件具备层级数据聚合能力，控制单次调用返回的数据量上限，避免超时。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 按实测标定 | 适配部门决算场景下多工具协同调用的需求，支持自动匹配或指定对应工具 |
| `functionCall` | 强制开启 | 确保工具调用严格遵循预设规则，适配结构化报表的字段提取与映射需求 |
| 工具调用超时 | 600 秒 | 跨系统拉取年度汇总数据耗时较长，预留充足处理时间 |
| 单次工具调用数据上限 | 前 800–1200 条 | 控制单轮调用返回的数据体量，避免超出上下文窗口限制 |
| 工具调用重试次数 | 2 次 | 平衡数据拉取成功率与整体处理时长，适配年度批量数据的处理节奏 |

## 容易做错的三处
- 现象为调用图表工具生成决算报表可视化图表时，输出为空。原因是未正确映射决算数据的收支明细字段与图表展示维度，导致工具无法获取有效数据。
- 现象为工作流中选择工具时返回400错误。原因是配置的工具调用参数未匹配部门决算数据的格式要求，或单次调用数据量超出系统限制。
- 现象为使用非qwen系列模型调用工具时触发报错。原因是部分模型对`functionCall`格式的支持存在差异，未适配部门决算结构化数据的调用规则。

## 怎么确认配好了
- 发起单次工具调用，拉取单份部门决算报表的核心字段，核对返回数据与源系统数据是否一致。
- 测试跨系统数据拉取流程，确认可同时从预算管理一体化系统与会计核算系统获取对应数据。
- 触发工具调用重试逻辑，验证在单次调用失败后，系统将按配置次数自动重试并完成数据汇总。
- 查看工具调用日志，确认`functionCall`格式的参数被正确解析，无格式报错。
