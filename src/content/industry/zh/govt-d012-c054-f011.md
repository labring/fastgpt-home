# 防汛防灾与应急值守的内部办公与员工服务：表单与交互

## 这个品类的数据长什么样
该品类数据主要来自气象预警系统、水文监测系统、应急指挥平台、基层报灾系统与视频监控。日常处理的文档包含值班记录、预警通知、会商纪要、灾情速报、应急处置方案、物资调拨单。数据更新频率为日度，部分实时监测数据会高频同步。文档字段多包含雨情毫米数、水位米数、人员数量、物资品类与调拨量等带单位的量化指标，部分非结构化文本需关联具体灾情场景。

## 这些特征在「表单与交互」这一环带来什么约束
多源数据接入要求表单需支持快速关联外部系统字段，减少手动录入误差。日度更新与实时监测的双重节奏，要求交互组件支持即时提交与批量导入两种模式。文档字段多带量化单位，表单需预设单位选项，避免非标准化输入。跨部门调度场景下，表单需支持权限分级配置，仅允许对应岗位人员填写特定字段，同时支持流转状态同步。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 表单输入组件 | 绑定雨情、水位等必填字段，预设「毫米」「米」单位选项 | 需快速录入带单位的量化数据，避免手动输入错误 |
| 用户选择组件 | 预设「暴雨红色预警」「洪水橙色预警」「一般险情」选项，支持单选 | 适配会商纪要与处置方案的分类选择需求 |
| 提交校验规则 | 开启必填字段校验，超时阈值设为30秒 | 确保录入数据的及时性与完整性 |
| 权限分级配置 | 按岗位划分填写范围，仅允许值班岗填写值班记录 | 适配跨部门调度的权限管控要求 |
| 批量导入配置 | 支持CSV格式导入，匹配预设字段映射 | 适配日度汇总大量值班记录与调拨单的需求 |

## 容易做错的三处
- 调用API访问工作流中的交互组件时，未弹出用户输入弹窗。原因是未在工作流配置中开启「API调用时触发交互」的开关。
- 表单输入组件无法传入预设全局变量。原因是未将变量正确绑定到表单字段的默认值配置项中。
- 导入多列Excel文件时，字段匹配出现错位。原因是未按文档字段顺序配置导入映射，导致数据与字段不对应。

## 怎么确认配好了
- 进入FastGPT v4.17.0的工作流测试页面，触发表单输入组件，检查预设单位与选项是否正确加载。
- 调用配置好的API接口提交测试数据，检查是否触发校验规则并返回正确的校验结果。
- 使用非授权岗位的账号登录系统，检查是否无法访问指定表单的敏感字段。
- 导入测试用的Excel文件，检查字段映射是否与预设配置完全一致。
