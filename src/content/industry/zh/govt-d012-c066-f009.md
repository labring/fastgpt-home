# 化工新材料的内部办公与员工服务：模型接入与配置

## 这个品类的数据长什么样
化工新材料的内部办公数据主要来源于生产台账、研发实验记录、质量检测报告、供应链物料清单。生产台账按每日批次更新，记录批次号、原料牌号、生产时间、能耗数据等字段；研发实验记录按需更新，包含实验条件、配方比例、性能测试结果；质量检测报告按批次生成，包含拉伸强度、热变形温度等带单位的性能参数。文档多为结构化文本与半结构化表格混合，单份文档长度差异较大，从数百字符到数千字符不等。FastGPT v4.17.0适配该类数据的解析逻辑。

## 这些特征在「模型接入与配置」这一环带来什么约束
结构化字段多且附带专属单位，要求模型能精准识别字段名与单位，避免参数匹配错误；文档长度差异大，需要适配不同长度的上下文输入，避免截断关键信息；生产数据每日更新，要求模型能调用实时数据源生成针对性查询；研发与质量数据包含大量专业术语，需要模型具备领域语义理解能力。这些约束决定了模型接入时需针对性调整上下文窗口、温度系数等参数，同时需配置适配化工领域的嵌入模型与接口代理。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单份研发记录或多批次生产台账的总长度需求，容纳更多历史对话与文档片段 |
| `maxTokens` | 4000 token | 匹配内部办公问答的单次回复长度，避免超出接口返回限制 |
| `temperature` | 0.2–0.4 | 降低生成随机性，确保物料参数、SQL查询等内容的精准性，符合化工领域的严谨性要求 |
| `quoteMaxToken` | 2000–3000 token | 匹配单份质量检测报告的文本长度，确保召回的文档片段完整覆盖关键性能参数 |
| `toolChoice` | auto | 自动触发工具调用，生成符合生产台账结构的SQL查询，适配内部办公的数据分析需求 |
| `AIPROXY_API_TOKEN` | 企业专属代理绑定的密钥 | 确保接口鉴权通过，避免测试时出现鉴权相关报错 |

## 容易做错的三处
- 测试qwen-max模型时出现“cannot read properties”报错，原因是未正确配置`AIPROXY_API_TOKEN`，导致接口鉴权失败，无法正常调用模型接口。
- 选择m3e模型供应商时出现选型偏差，原因是未选用化工领域微调的嵌入模型，通用模型无法精准匹配专业术语与单位，导致语义召回精度不足。
- 工具调用的中间执行日志在聊天窗口显示，原因是未关闭工具结果展示配置，导致员工在使用时看到冗余的后台执行步骤。

## 怎么确认配好了
- 进入FastGPT v4.17.0的模型测试页面，输入“查询2024年第15批次的聚丙烯热变形温度”，核对返回结果是否匹配对应批次的质量检测报告数据。
- 提交模型调用请求，检查界面是否出现“cannot read properties”类报错，确认`AIPROXY_API_TOKEN`配置正确。
- 发起一次工具调用请求，核对聊天窗口仅显示最终回答，无中间工具执行日志。
- 调整`temperature`参数至0.1与0.5，对比两次生成的SQL查询语句，确认参数调整后结果的精准性符合预期。
