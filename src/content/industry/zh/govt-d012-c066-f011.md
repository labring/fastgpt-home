# 化工新材料的内部办公与员工服务：表单与交互

## 这个品类的数据长什么样
化工新材料的业务数据主要来自研发实验室合成台账、生产中控DCS系统、供应链采购入库单与质检报告。研发数据按合成批次更新，生产数据实时同步，采购与质检数据按入库批次更新。单份文档通常包含物料编码、批次号、合成工艺参数、质检指标、库存余量与供应商关联信息。字段多为结构化数值型与枚举型，单位涵盖摄氏度、小时、千克、微米等。

## 这些特征在「表单与交互」这一环带来什么约束
研发批次的合成参数多为连续数值，表单需支持区间输入与精度校验，避免输入超出设备运行范围。质检数据的枚举项需固定可选值，防止录入不规范的质检结果。多系统关联的业务数据需在表单中嵌入跨数据源的变量引用，确保批次信息同步更新。实时生产数据相关的表单需设置短间隔自动保存，避免数据丢失。物料编码的唯一性校验需对接企业主数据系统，防止重复录入。员工服务类表单如耗材申领需关联现有库存数据，避免超量申请。

## 配置怎么定
以下配置适用于 FastGPT v4.17.0：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `formInput` 字段校验规则 | 按字段类型匹配对应校验逻辑 | 适配化工新材料业务的数值、枚举类字段特征 |
| `userSelect` 组件数据源 | 绑定企业主数据系统的物料编码与批次列表 | 确保表单可选值与主数据一致 |
| 自动保存间隔 | 30–60 秒 | 适配实时生产数据的同步需求 |
| 表单上传文件大小限制 | 500–1000 MB | 适配化工新材料研发文档与质检报告的存储需求 |
| 表单输入字符上限 | 800–1200 字符 | 适配研发台账的单条记录长度要求 |
| 字段唯一性校验 | 开启物料编码与批次号校验 | 避免重复录入研发或生产批次数据 |
| 表单提交触发条件 | 完成所有必填项校验后提交 | 确保业务数据的完整性 |

## 容易做错的三处
- 现象：配置`formInput`绑定全局变量后，调试到下一节点时提示输入为空。原因：未将全局变量的作用域设置为当前工作流，或变量绑定未触发实时更新。
- 现象：使用`userSelect`组件配置大模型调用时，无法找到温度参数设置入口。原因：未在组件配置中开启「高级参数」展开项，温度参数默认隐藏。
- 现象：在谷歌浏览器中点击表单复制按钮，提示无法复制且生成的Markdown内容无换行。原因：未在表单配置中开启「自动换行标记」，或浏览器权限未开放剪贴板访问。

## 怎么确认配好了
- 打开表单预览页面，输入任意符合业务规则的数值，校验提示应匹配字段类型要求。
- 选择`userSelect`组件的下拉选项，确认可选值与企业主数据系统的物料列表一致。
- 提交表单后，查看工作流日志，确认全局变量已正确传递至下一节点且无空值报错。
- 触发自动保存功能，等待30秒后刷新页面，确认表单数据未丢失。
