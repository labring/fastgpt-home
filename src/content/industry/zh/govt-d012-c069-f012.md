# 危化品储运的内部办公与员工服务：部署与升级

## 这个品类的数据长什么样
危化品储运的业务数据主要来源于企业仓储管理系统、巡检终端、ERP系统及操作人员日志。数据来源覆盖存储台账、出库入库单据、班次巡检记录、设备运行参数四类。更新节奏分为三类：存储台账随危化品出入库月度更新，出库入库单据随业务实时生成，班次巡检记录与设备运行参数按每班次或实时更新。单条数据的标准字段包含危化品编号、存储仓位编号、环境温湿度、存储重量、巡检人员ID、异常标记，温湿度单位为摄氏度、存储重量单位为千克，巡检时间精确到秒。

## 这些特征在「部署与升级」这一环带来什么约束
危化品储运的数据实时性强且包含敏感业务字段，部署与升级环节需优先保障数据安全与访问稳定性。实时生成的巡检记录会产生高频数据库访问，需配置足够的连接池资源以应对并发请求。多来源的数据格式存在差异，部署时需预设字段校验规则，避免异常数据流入系统。月度更新的存储台账数据量较大，升级过程中需预留足够的数据库迁移时间。敏感字段的存储需使用私有存储节点，升级时需同步验证密钥配置的有效性，防止数据泄露风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150` | 危化品储运的实时巡检与业务单据会产生高频数据库连接，该取值可覆盖并发访问需求 |
| `REDIS_URL` | `redis://内网IP:6379` | 用于缓存实时巡检状态与用户会话，内网部署可降低延迟与安全风险 |
| `STORAGE_S3_ENDPOINT` | 企业私有存储节点地址 | 危化品数据属于敏感业务数据，需存储在企业自有节点以保障数据安全 |
| `FE_DOMAIN` | 企业内网域名或映射后的外网域名 | 适配内部办公与员工服务的访问场景，支持内网与外网两种访问模式 |
| `FILE_TOKEN_KEY` | 32位随机字符串 | 用于验证文件上传请求的合法性，保障巡检照片、设备日志等附件的上传安全 |
| `PG_URL` | 专用PostgreSQL实例地址 | 结构化的存储台账与操作人员日志适合存储在关系型数据库中，保障数据查询效率 |

## 容易做错的三处
- 现象：无法找到插件部署路径，原因：未在系统配置中开启插件管理模块，导致对应菜单未加载。
- 现象：iframe嵌入页面后显示空白，直接访问地址正常，原因：免登录窗口生成的token未携带正确的跨域配置参数，导致浏览器拦截跨域请求。

## 怎么确认配好了
- 访问`FE_DOMAIN`对应的地址，登录系统后查看插件管理页面是否正常加载，确认插件部署功能可用。
- 提交一条测试巡检数据，检查`PG_URL`或`MONGODB_URI`对应的数据库中是否生成对应记录，确认数据存储正常。
- 尝试上传一张测试图片，确认文件上传接口返回正常，且文件能正确存入`STORAGE_S3_ENDPOINT`对应的存储节点。
- 查看系统日志，确认`DB_MAX_LINK`的连接数未超过配置阈值，无数据库连接异常报错。
