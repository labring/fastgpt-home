# 国有产业基金的内部办公与员工服务：向量模型与索引

## 这个品类的数据长什么样
国有产业基金内部办公与员工服务相关的数据，来源包括内部办公系统的飞书/钉钉文档、投研报告、投决会议纪要、基金运营报表、员工手册与部门制度文档。更新节奏涵盖月度运营报表的定时更新、投研报告的不定期更新、员工手册的季度/年度更新。文档结构包含结构化表格与非结构化文本，字段涉及项目编码、员工工号、部门名称等，单位包含万元、月、年等。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配产业基金投研文档、会议纪要的长文本结构，避免单块内容跨业务逻辑 |
| 重叠长度 | 50–100 字符 | 保留跨分块的上下文关联，防止长文档核心信息被分割在块外 |
| 相似度阈值 | 0.72–0.85 | 匹配产业基金内部文档的专业术语密度，过滤低相关的检索结果 |
| 单次搜索上限 | 前 10 条 | 控制内部办公场景的检索返回量，避免信息过载 |
| `maxToken` | 8192 | 适配长文档的向量编码需求，覆盖多数产业基金内部文档的长度 |
| `defaultToken` | 按实测标定 | 适配外接API的向量模型调用限额，避免超额扣费 |

## 容易做错的三处
- 现象：向量模型配置页面显示“连接超时”或“API调用失败”，无法在oneapi中添加无GPU本地向量模型。原因：未正确配置向量模型的本地端口映射，或oneapi的模型接入格式与FastGPT要求不匹配。
- 现象：导出的索引数据仅包含知识库整体内容，无法按业务分类、数据类型拆分导出。原因：未开启知识库的分目录索引配置，仅启用了全局知识库导出规则。
- 现象：飞书文件夹内的excel文件、多维文档无法被成功解析并索引。原因：未在FastGPT数据源配置中启用飞书excel与多维文档的解析插件，或飞书应用的权限未覆盖对应目标文件夹。

## 怎么确认配好了
- 上传单份产业基金投研文档，检查分块后的文本是否覆盖完整业务逻辑，无明显内容截断。
- 发起内部办公相关检索，核对返回结果的相似度与业务相关性是否符合预设预期。
- 触发一次增量索引，检查更新后的文档是否能被正确检索到，无遗漏或重复条目。
- 查看向量模型的调用日志，确认`maxToken`与`defaultToken`的配置未触发超额限制。
