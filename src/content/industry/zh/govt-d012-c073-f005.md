# 国有产业基金的内部办公与员工服务：工具调用与插件

## 这个品类的数据长什么样
国有产业基金的数据主要来源于国资监管备案系统、内部投研台账与项目管理平台。数据包含基金认缴规模、实缴金额、投后项目清单、单个项目投资额、出资方主体信息等字段，单位分别为亿元、万元。备案类基础信息每季度更新，投后项目动态每周同步，内部运营台账每日更新，单条数据的条目数随管理的基金数量浮动。

## 这些特征在「工具调用与插件」这一环带来什么约束
国有产业基金的数据字段关联复杂，包含跨主体的认缴、实缴与投后信息，工具调用需支持嵌套参数传递，以匹配跨主体、多维度的查询需求。不同数据源更新节奏差异较大，插件需区分配置拉取周期，避免高频拉取每日更新的内部台账造成资源占用。字段单位包含亿元、万元等不同量级，插件需内置单位转换逻辑，确保返回数据格式与内部办公系统的展示要求一致。投后项目数据存在动态调整，工具调用需支持增量拉取，减少全量数据传输的带宽消耗。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 手动指定为 `functionCall` | 适配产业基金多参数嵌套的工具调用场景 |
| 拉取数据源周期 | 按数据源类型区分配置，内部台账设为1小时，备案数据设为24小时 | 匹配不同数据源的更新节奏，减少无效请求 |
| JSON输入框变量绑定 | 开启变量映射开关 | 支持将内部OA的项目ID、基金代码等变量直接注入JSON参数 |
| 数据单位转换 | 启用内置单位转换规则 | 统一亿元与万元的展示格式，匹配内部办公系统的显示要求 |
| 超时阈值 | 30秒 | 适配内部办公网络的平均延迟水平 |
| 权限过滤开关 | 开启权限校验 | 符合国资数据安全管控的最小权限原则 |

## 容易做错的三处
- 现象：JSON输入框内无法选中预设变量，参数提交后显示字段为空。原因：未开启JSON输入框的变量映射开关，导致系统无法识别注入的变量占位符。
- 现象：调用本地MCP服务时返回连接超时错误。原因：未配置本地服务的内网访问白名单，或插件的网络请求未指向正确的本地端口。
- 现象：插件返回的URL图片地址无法在内部办公系统展示。原因：未将图片URL的域名添加至插件的白名单配置，或未开启图片资源的跨域访问支持。

## 怎么确认配好了
- 提交测试调用，查看返回数据的字段与单位是否与内部台账的格式一致。
- 检查工具调用日志，确认变量已正确注入JSON输入框的参数中。
- 模拟不同数据源的拉取请求，验证拉取周期是否符合预设配置。
- 调用受限权限的项目数据，确认返回结果仅包含授权范围内的信息。
