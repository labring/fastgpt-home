# 国有产业基金的内部办公与员工服务：知识库检索与召回

## 这个品类的数据长什么样
国有产业基金的内部办公数据来源包括内部投研文档、合规审批档案、员工管理制度、项目台账、监管政策文件。更新节奏为投研类文档按季度更新，政策类随监管要求即时更新，员工手册随组织架构调整不定期更新。文档结构包含结构化字段与非结构化内容，结构化字段有项目编码、投资额度、合规条款编号、部门归属等，非结构化内容包含长文本投研纪要、PPT演示材料、PDF合规文件，字段单位涉及亿元、项目周期（月）、审批文号等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
国有产业基金的文档特征对检索召回带来多重约束。长文本投研纪要需合理拆分以保留语义完整性，避免分块过短导致上下文断裂或过长超出上下文窗口。带精准字段的文档需兼顾语义召回与字段精准匹配，防止仅匹配语义但字段不符的无效结果。不定期更新的监管政策与项目台账需配置增量同步机制，确保检索数据与最新业务状态一致。多模态投路演PPT需支持图文混合召回，避免仅提取文字丢失关键视觉关联信息。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 适配产业基金合规文档的严谨性要求，平衡召回精度与覆盖范围，避免过低导致无效结果过多或过高遗漏相关合规条款。 |
| `limit` | 前8条 | 匹配单轮检索的上下文窗口上限，结合产业基金内部办公的信息需求，避免过多结果导致上下文溢出。 |
| `searchMode` | hybrid | 兼顾语义召回与字段精准匹配，适配同时包含结构化字段与非结构化文本的产业基金文档结构。 |
| `usingReRank` | 开启 | 对初始召回结果进行重排，优化长文本投研文档的相关性排序，提升员工检索的精准度。 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展用户查询的同义表述，覆盖产业基金内部常用的简称与行业术语，提升检索覆盖范围。 |
| `collectionIds` | 按业务模块划分的集合ID | 区分投研、合规、员工服务等不同知识库集合，避免跨模块无关结果干扰检索。 |

## 容易做错的三处
-  现象：导入PPT格式的投路演文档后，检索结果仅包含文字内容，无图片关联信息。原因：未开启多模态文档的图文关联召回配置，仅提取了文本内容，未关联图片中的关键视觉信息。
-  现象：检索结果的引用来源分散，无法合并展示同一项目的多份关联文档。原因：未启用搜索引用合并功能，未将同一业务主题的文档结果进行聚合，导致检索结果展示效率降低。
-  现象：无法将HTTP接口返回的实时项目数据作为知识库检索源。原因：未配置外部数据源同步规则，未将HTTP接口返回的结构化数据转换为知识库可识别的文档格式，导致无法纳入检索范围。

## 怎么确认配好了
-  上传一份测试用的多模态文档，发起针对性检索，确认返回结果包含文本与关联的视觉信息。
-  发起包含结构化字段的查询，确认返回结果匹配指定字段的文档，无无关内容。
-  提交包含行业内部简称的查询，确认检索结果覆盖了扩展后的同义表述内容。
-  查看检索结果的引用模块，确认同一业务主题的文档已聚合展示。
