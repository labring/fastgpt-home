# 国有产业基金的内部办公与员工服务：表单与交互

## 这个品类的数据长什么样
国有产业基金的内部办公数据主要来自投决管理系统、出资人台账模块、财务核算系统及人力审批模块。数据更新节奏覆盖每日（投决进度、审批流转状态）、月度（财务收支、出资到账情况）、季度（出资人权益变动）三类。文档以结构化表单为主，包含项目立项申请、员工出差审批、薪酬调整申请等类型，字段涵盖项目编号、出资额、审批节点、提交时间等，单位包含万元、人次、自然日等，无自由格式的非结构化文本占比过高的情况，多数文档为结构化填报内容。

## 这些特征在「表单与交互」这一环带来什么约束
结构化的字段类型要求表单控件需匹配对应格式，例如金额字段需使用数值输入框，不使用自由文本框，枚举字段需使用下拉选择控件。不同更新节奏的数据需适配交互刷新逻辑，例如审批节点的用户列表需按审批层级定时刷新，避免过时的权限配置。字段附带的单位要求输入校验规则需自动绑定单位提示，防止输入时遗漏或错误添加单位。国有业务的合规要求需在交互中增加留痕环节，例如提交前的二次确认弹窗，确保操作可追溯。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 表单输入校验 | 对金额字段限制数值格式并附加万元单位提示 | 产业基金内部表单包含出资额等金额字段，需避免单位输入错误 |
| 用户选择范围 | 限定为当前审批节点的上级及同级部门用户 | 国有产业基金审批需按层级流转，需限制可选用户的权限范围 |
| 提交前置确认 | 开启`formInput`的二次弹窗验证 | 国有业务需留存操作痕迹，避免误提交导致的合规风险 |
| 超时阈值 | `300 秒` | 跨部门审批的交互时长通常较长，需预留足够的操作时间 |
| 字段联动规则 | 当项目类型选择“股权投资”时自动加载出资额必填字段 | 产业基金不同项目类型对应不同的必填表单字段，需自动适配 |
| 重排结果召回 | 配置为返回`前5条`结果 | 匹配基金内部表单的多文档关联需求，避免召回结果不足 |

## 容易做错的三处
- 现象：重排模型调用后仅返回1条相似度最高的结果，未按配置返回指定条数。原因：未开启`formInput`的多结果召回开关，导致重排结果被强制截断。
- 现象：提交表单后，关联的尽调文档字段显示为空，无法正常关联。原因：未配置`userSelect`的权限过滤规则，导致非审批节点用户无法访问对应文档库。
- 现象：金额字段输入“500万元”后，系统自动清除“万元”后缀导致校验失败。原因：未开启表单输入校验的单位适配规则，仅允许纯数值输入。

## 怎么确认配好了
- 打开任意产业基金内部表单，测试金额字段输入时是否自动显示万元单位提示，输入非数值字符时是否弹出校验提示。
- 选择审批节点对应的岗位，确认下拉用户列表仅显示当前部门及上级层级的账号，无无关用户出现。
- 提交表单时触发二次确认弹窗，确认提交后系统生成包含操作人、提交时间的审计日志记录。
- 调用重排模型测试，查看返回结果条数是否与`formInput`配置的召回条数一致，验证多结果召回功能正常。
