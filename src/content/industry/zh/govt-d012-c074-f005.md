# 国有资产管理公司的内部办公与员工服务：工具调用与插件

## 这个品类的数据长什么样
国有资产管理公司的内部办公数据主要来源于国资监管系统、内部财务台账、资产权属证明文件及日常运营记录。数据更新节奏分为两类：月度异动更新（如资产调拨、处置）与年度全面盘点更新。文档结构以结构化台账为主，单条资产卡片包含资产编号、入账日期、账面价值、使用部门、存放地点、权属状态等字段，账面价值以万元为单位，使用年限以年为单位，批量资产清单多为Excel或CSV格式。

## 这些特征在「工具调用与插件」这一环带来什么约束
资产数据包含权属状态、账面价值等敏感字段，工具调用需限定可访问的字段列表，防止越权访问敏感信息。数据更新存在月度异动与年度盘点的差异节奏，插件需支持增量同步配置，仅拉取更新后的资产条目，避免全量拉取占用过多系统资源。结构化台账字段多且格式固定，工具调用需支持精准字段匹配，避免泛化查询返回无关数据。批量资产操作场景常见，插件需兼容多行SQL语句执行，同时限制修改类语句的权限范围，保障数据安全。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的插件系统设计，适配国有资产管理公司的内部办公场景：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配国有资产场景下的多工具自动选择需求，无需手动指定工具 |
| `functionCall` | `启用` | 强制模型生成符合格式的工具调用请求，避免返回非结构化结果 |
| 数据库连接超时 | `300 秒` | 国有资产数据库查询通常涉及多表关联，需预留足够的响应时间 |
| 批量查询条数上限 | `前 20 条` | 单次查询返回过多数据会超出上下文窗口，同时适配国有资产批量盘点的常规需求 |
| 敏感数据脱敏开关 | `启用` | 资产权属、账面价值等字段属于敏感信息，需在工具返回结果前自动脱敏 |
| 工具调用重试次数 | `2 次` | 网络波动或数据库临时卡顿可能导致调用失败，有限重试可提升成功率 |

## 容易做错的三处
- 现象：工具调用返回的资产数据字段缺失或格式错误。原因：未配置字段访问白名单，模型尝试访问未授权的敏感字段，或未指定固定的结果解析格式。
- 现象：执行多行SQL查询时出现报错，无法同时运行insert和select语句。原因：数据库插件未启用多行语句执行开关，或配置了仅允许单语句执行的权限限制。
- 现象：工具调用结果不稳定，部分查询返回空值。原因：未配置增量同步机制，使用了过期的缓存数据，或未设置合理的重试次数，单次调用失败后未自动重试。

## 怎么确认配好了
- 发起一次资产台账的批量查询请求，核对返回结果的字段是否与配置的白名单一致。
- 执行包含多行SQL语句的测试请求，确认无权限报错且结果符合预期。
- 模拟一次工具调用失败的场景，确认系统自动触发重试机制并在重试后返回正常结果。
- 启用敏感数据脱敏开关后，查看工具返回结果，确认敏感字段已被正确处理。
