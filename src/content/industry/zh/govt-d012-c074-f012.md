# 国有资产管理公司的内部办公与员工服务：部署与升级
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这个品类的数据长什么样
国有资产管理公司的内部办公与员工服务数据主要来源于国资监管台账系统、内部OA办公系统、财务核算系统及员工档案库。国资数据以资产全生命周期信息为主，包含资产编号、账面原值、使用部门、存放地点等固定字段，单位多为万元、平方米、台（套），更新节奏为月度或季度同步；内部办公数据涵盖员工考勤、审批流程、会议安排等，日常实时更新，文档结构多为标准化表单与结构化报表。

## 这些特征在「部署与升级」这一环带来什么约束
国资数据的固定字段与合规存储要求，决定部署时需提前配置符合国资监管标准的存储与数据库映射规则，升级时不能随意调整字段结构，避免破坏原有数据关联；内部办公数据的实时性需求，要求部署时合理配置缓存服务，升级过程中需保障会话不中断；资产类文档存在单文件体积较大的特点，升级时需兼容大文件上传的存储配置，同时需提前备份存量资产数据，防止升级过程中数据丢失。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `DB_MAX_LINK` | `200–300 个连接` | 匹配国有资产管理公司日常资产台账查询、办公系统交互的并发连接需求 |
| `STORAGE_S3_ENDPOINT` | 国资云存储服务商提供的专属接入地址 | 满足国资数据存储的合规性要求 |
| `REDIS_URL` | 内部专属缓存集群连接地址 | 保障内部办公会话与资产缓存的稳定性 |
| `FILE_TOKEN_KEY` | `32 位随机加密字符串` | 防止文件上传请求被恶意篡改 |
| `FE_DOMAIN` | 公司内部办公二级域名 | 限制前端访问的合法域名范围 |
| `ROOT_KEY` | 按内部权限管控规则设置的密钥 | 保障管理员操作的权限安全 |

## 容易做错的三处
- 升级后模型厂商图标加载失败。现象为前端页面中模型厂商的logo无法正常显示，控制台提示资源路径不存在。原因是升级时未同步更新前端静态资源的部署路径配置，导致厂商图标资源未正确加载。
- 对话中添加附件时提示`fail to create post presigned url`。现象为点击添加附件按钮后弹出该报错，无法完成文件上传。原因是`STORAGE_S3_ENDPOINT`配置错误，或S3存储桶的访问权限未开放，导致无法生成合法的预签名上传链接。
- 迁移S3存储后RAG上传文件报错。现象为文件上传进度卡住或直接失败，后台日志显示存储连接异常。原因是未调整`DB_MAX_LINK`适配新增的文件上传并发请求，导致数据库连接耗尽，无法处理上传请求。

## 怎么确认配好了
- 登录FastGPT后台的监控面板，查看数据库连接数指标，确认当前连接数未超过配置的`DB_MAX_LINK`上限。
- 上传一份符合国资文档格式的测试文件，验证预签名链接生成正常且文件可成功上传至指定存储位置。
- 访问公司内部办公域名，打开FastGPT前端页面，验证所有静态资源均可正常加载，无报错提示。
- 使用配置的`ROOT_KEY`执行管理员权限测试，确认可正常执行系统配置修改操作，权限校验生效。
