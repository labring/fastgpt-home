# 国有资本投资公司的内部办公与员工服务：模型接入与配置

## 这个品类的数据长什么样
国有资本投资公司的内部办公数据主要来源于国资监管报送系统、内部OA平台、财务核算系统、人力管理系统与项目管理平台。数据更新节奏覆盖实时（如员工考勤、项目进度）、每日（如财务日报）与按需（如临时请示报告）三类。文档结构包含结构化报表（如国资月度监管表、员工薪酬明细）与非结构化文档（如会议纪要、项目可研报告），字段包含统一国资编码、员工工号、项目编号，金额单位多为万元，时间字段格式为YYYY-MM-DD。

## 这些特征在「模型接入与配置」这一环带来什么约束
国资数据的敏感性要求模型接口需采用私有部署方式，因此需配置专属的`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`保障访问安全。结构化报表占比高的场景，要求模型支持自动工具调用以完成SQL查询，需合理设置`toolChoice`参数。长文档与多轮对话的需求，要求调整`maxContext`与`maxTokens`的取值以承载完整上下文。数据更新频率的差异，需匹配不同场景下的知识库刷新周期，避免 stale 数据影响问答准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 内部办公文档多为长文档，包含项目报告、国资监管报表，需足够上下文承载历史对话与文档内容 |
| `maxTokens` | `4000–6000 token` | 员工服务类问答多为结构化查询与文档总结，避免超出模型输出上限 |
| `toolChoice` | `auto` | 需支持SQL查询内部财务、人力系统数据，自动选择工具调用 |
| `temperature` | `0.1–0.3` | 内部办公问答需要准确的信息输出，避免生成无关内容 |
| `AIPROXY_API_ENDPOINT` | 私有部署模型的专属接口地址 | 国有资本投资公司数据敏感，需使用本地私有部署的模型接口 |
| `AIPROXY_API_TOKEN` | 私有部署模型的专属访问令牌 | 保障接口访问的安全性，防止未授权访问 |

## 容易做错的三处
- 现象：私有部署的Qwen3-32B模型调用MCP MySQL查询服务时返回报错，日志显示接口连通性异常。原因：未正确配置`AIPROXY_API_ENDPOINT`指向私有模型的实际部署地址，导致请求无法送达目标模型。
- 现象：知识库问答时提示需配置文本理解模型，但已配置知识库关联模型。原因：未将知识库绑定的模型同时配置为文本理解模型，或模型类型未匹配内部办公文档的结构化与非混合格式。
- 现象：MarkPDF容器内的模型无法正常加载，文档解析失败。原因：未提前拉取模型镜像至本地容器环境，或镜像拉取过程中断导致模型文件不完整。

## 怎么确认配好了
- 执行本地私有模型的连通性测试，向`AIPROXY_API_ENDPOINT`发送标准请求，确认返回正常的模型响应。
- 上传一份包含结构化报表与非结构化会议纪要的测试文档，触发知识库问答，确认无需额外配置文本理解模型即可正常解析。
- 配置`toolChoice`为`auto`后，发起包含SQL查询需求的测试提问，确认模型自动调用MCP工具完成数据查询。
- 查看FastGPT v4.17.0版本下的配置面板，确认`maxContext`与`maxTokens`的取值匹配当前内部办公文档的平均长度与对话上下文需求。
