# 基础化工的内部办公与员工服务：模型接入与配置

## 这个品类的数据长什么样
基础化工的内部办公数据主要来源于生产运行报表、设备台账档案、工艺操作手册、安全合规规程四类。生产运行报表按班次更新，设备台账在故障检修或季度巡检后更新，工艺手册与安全规程为静态文档，仅在版本迭代时更新。文档结构包含章节编号、专业参数字段，字段多带专属单位，如压力单位MPa、流量单位m³/h、温度单位℃，部分文档包含工艺流程图与设备布局图。

## 这些特征在「模型接入与配置」这一环带来什么约束
基础化工的数据特征对模型接入配置带来多维度约束。多源异构的数据需要适配不同格式的接入规则，长文本工艺文档与时序化的生产报表需要调整上下文容纳能力，专业术语与专属单位要求模型输出保持严谨性，图片类文档则需要开启视觉识别能力。同时，不同数据源的更新频率差异，要求配置差异化的知识库同步周期，避免数据过时或冗余加载，且需保证接入的API节点能够处理批量的专业参数查询请求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 基础化工工艺文档单篇长度较长，需容纳多段工艺参数与历史对话上下文 |
| `temperature` | 0.2–0.4 | 基础化工术语严谨，低温度值减少幻觉，保证参数与规程表述准确 |
| `vision` | 开启 | 基础化工存在大量工艺流程图、设备布局图，需识别图片中的标注与专业参数 |
| `toolChoice` | auto | 内部办公场景需自动调用工具处理设备查询、工单调度等任务 |
| `quoteMaxToken` | 1500–2000 token | 需引用长段的设备台账、安全规程原文，保证引用内容完整无截断 |
| `AIPROXY_API_ENDPOINT` | 按部署集群指定 | 适配基础化工数据处理的算力需求，绑定专属代理节点以保障响应速度 |

## 容易做错的三处
- 现象：工作流中尝试接入MCP功能时，界面提示无法加载外部插件。原因：未在工作流配置中开启外部工具调用权限，或`toolChoice`被强制设置为none，限制了工具接入能力。
- 现象：开启语音识别功能后，界面提示浏览器不支持语音输入。原因：未在FastGPT v4.17.0的前端配置中启用语音识别兼容模式，或浏览器的语音API接口未被授权。
- 现象：知识库配置了重排模型，但问答返回的重排结果字段为false。原因：未在问答流程的配置中勾选启用重排选项，或重排模型的调用密钥未正确绑定到目标知识库。

## 怎么确认配好了
- 提交一条包含工艺参数的查询，检查返回结果中是否包含正确的单位与字段，验证`temperature`与`maxContext`的配置效果。
- 在工作流中添加外部工具调用节点，尝试触发一次设备数据查询，确认工具能否正常调用，验证`toolChoice`与`AIPROXY_API_ENDPOINT`的配置。
- 上传一张工艺流程图文档，查看模型能否正确识别图中的标注与参数，验证`vision`的配置是否生效。
- 触发一次问答流程，检查返回结果中是否包含引用的原文片段，验证`quoteMaxToken`的配置是否合理。
