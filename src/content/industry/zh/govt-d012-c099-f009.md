# 油气勘探开发的内部办公与员工服务：模型接入与配置

## 这个品类的数据长什么样
油气勘探开发的数据主要来源于钻井实时日志、地震勘探采集文件、油藏模拟报告、井场巡检记录等现场与实验室产出的资料。数据更新节奏覆盖实时（钻井过程中的参数采集）、每日（当日井况汇总）、月度（油藏动态分析报告）。文档结构包含结构化字段与非结构化文本两类，结构化字段包括井号、井深（单位米）、孔隙度、渗透率（单位mD）等，非结构化内容包括现场工作日志、专业分析文档、地震解释图像配套文本。单条数据长度差异显著，短则数行的实时日志，长则数十页的综合分析报告。

## 这些特征在「模型接入与配置」这一环带来什么约束
因为数据包含大量油气领域专属专业术语与特定计量单位，模型接入时需确认目标模型支持领域适配或可通过prompt引导专业语义理解。数据长度跨度大的特点，要求上下文与输出token的配置需具备弹性，避免短数据浪费资源或长数据被截断。实时更新的数据要求API调用的超时设置需适配数据拉取的延迟，防止因等待超时导致任务失败。结构化与非结构化混合的数据形态，要求模型的工具调用配置可根据查询类型自动适配，兼顾结构化字段解析与自然语言回答的需求。另外，部分专业任务需严谨的输出格式，因此温度参数的配置需匹配任务需求，避免生成无关或不准确的专业结论。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–16000 token | 油气勘探报告与日志组合的上下文长度通常覆盖多组专业数据，该区间可完整承载单井分析所需的历史数据 |
| `maxTokens` | 2000–4000 token | 针对油藏分析、钻井方案生成等任务，专业回答需包含足够细节，该区间可覆盖典型输出长度 |
| `quoteMaxToken` | 1000–2000 字符 | 需引用的勘探日志、钻井数据片段长度适中，该设置可平衡引用完整性与上下文占用 |
| `toolChoice` | auto | 需根据用户查询自动选择是否调用专业数据解析工具，适配结构化与非结构化混合数据的处理需求 |
| `temperature` | 0.2–0.4 | 油气领域专业任务需严谨输出，较低温度可减少无关信息生成，保证结果准确性 |
| `AIPROXY_API_ENDPOINT` | 按服务商提供的专属接入地址填写 | 需绑定对应模型的访问路径，确保请求路由正确 |
| `AIPROXY_API_TOKEN` | 按服务商生成的密钥填写 | 用于身份验证，防止未授权访问模型接口 |

## 容易做错的三处
- 现象：调用模型后返回响应为空，日志显示“模型流响应为空”。原因：未正确配置`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`，导致请求无法正常到达模型服务端。
- 现象：curl测试可正常获取模型回复，但FastGPT内调用无结果。原因：FastGPT v4.17.0版本中，未适配当前模型的流式响应格式，或`maxContext`设置过小导致上下文被截断后触发异常。
- 现象：升级版本后专业模型无法正确调用。原因：新版本中`temperature`或`toolChoice`的默认配置发生变更，未针对油气领域专业任务重新标定参数。

## 怎么确认配好了
- 执行curl命令调用模型接口，验证基础连通性与响应格式是否符合FastGPT v4.17.0版本的适配要求。
- 导入单组油气勘探日志数据，测试`maxContext`与`maxTokens`的设置是否可完整承载输入并生成有效回答。
- 调整`temperature`参数，观察生成结果的严谨性是否符合专业任务需求。
- 检查`AIPROXY_API_TOKEN`的有效期与权限范围，确保未出现过期或权限不足的情况。
