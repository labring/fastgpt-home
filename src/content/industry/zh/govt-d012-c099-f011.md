# 油气勘探开发的内部办公与员工服务：表单与交互

## 这个品类的数据长什么样
油气勘探开发的数据来源包括野外勘探采集终端、钻井平台自控系统、地面生产监控平台。数据分为实时工况数据与批量勘探报告两类，更新节奏涵盖秒级（钻井工况）与天级（区域勘探报告）。文档结构包含井位编号、测井深度、孔隙度、渗透率、流体密度等字段，单位涵盖米、兆帕、立方米/天、克/立方厘米等，部分文档为带格式的勘探日志PDF或结构化CSV文件。

## 这些特征在「表单与交互」这一环带来什么约束
油气勘探开发的数据包含实时工况数据与批量勘探报告，单份文档字段多且带专业单位，部分数据来自传感器终端的批量导出。这要求表单需支持多字段联动校验，比如井号与对应深度范围的匹配；需预设专业单位选项避免输入错误；需支持大文件分片上传以适配批量勘探报告的提交；需针对实时数据做防抖处理避免重复提交；同时需区分临时草稿保存与正式提交的更新逻辑，适配不同数据的更新节奏。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 800–1200 字符 | 适配勘探报告的单段文本输入长度，避免超出系统默认限制 |
| `userSelect` | 前10条可选值 | 匹配单井常用的勘探参数选项，减少用户输入成本 |
| 文件上传限制 | 1000 MB 分片上传 | 适配批量地震勘探数据的上传需求 |
| 提交防抖时长 | 30 秒 | 避免实时工况数据的重复提交 |
| 表单字段校验 | 按专业单位预设 | 匹配油气勘探数据的字段单位规范 |
| 草稿保存间隔 | 600 秒 | 适配长表单填写的中断场景，避免数据丢失 |

## 容易做错的三处
- 现象：提交勘探报告表单时提示输入字符超限，无法完成提交。原因：未调整`formInput`的字符数配置，使用了系统默认的较小限制值。
- 现象：发布的表单页面缩放后，专业单位选项或长文本内容丢失。原因：表单组件未开启固定布局适配，或未设置最小宽度约束。
- 现象：选择关联知识库时无法多选，或无法匹配指定的勘探数据知识库。原因：未正确配置知识库变量的选择规则，未开启多知识库选择功能。

## 怎么确认配好了
- 上传一份1000 MB以内的勘探数据CSV文件，确认分片上传功能正常触发，无上传失败提示。
- 填写表单的井号字段，确认对应深度范围的联动校验正常触发，不符合规范的输入被拦截。
- 缩放表单页面至不同比例，确认所有字段、选项及文本内容均正常显示，无丢失情况。
- 提交测试表单后，查看FastGPT v4.17.0版本的后台日志，确认提交的字符数未超出预设的`formInput`限制值。
