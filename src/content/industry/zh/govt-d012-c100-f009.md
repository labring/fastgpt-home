# 油田工程服务的内部办公与员工服务：模型接入与配置

## 这个品类的数据长什么样
油田工程服务的数据主要来自现场施工日志、设备运维台账、安全巡检报告、人员排班档案。数据来源覆盖钻井、压裂、修井等作业环节，施工日志按作业班次每日更新，运维台账随设备运行状态实时同步。单份文档多为结构化与半结构化混合格式，包含作业井号、作业时长、设备压力值、巡检人员编号等字段，字段单位涵盖小时、兆帕、人次等，部分文档附带现场拍摄的设备工况照片。

## 这些特征在「模型接入与配置」这一环带来什么约束
油田工程服务的混合数据结构与实时更新特性，对模型接入配置带来多重约束。多模态数据（如设备工况照片）要求开启模型的视觉处理能力，需正确配置`vision`参数。长篇幅的作业日志与运维台账，需要调整上下文与token限制，避免内容截断。专业作业术语占比高，需控制生成参数的严谨性，避免术语误解。实时同步的设备数据要求接入接口的响应延迟符合作业节奏，需合理设置接口相关配置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `vision` | 开启（当接入设备工况照片时），关闭（仅处理文本数据） | 匹配油田工程服务的多模态数据需求，仅在存在图像类文档时启用 |
| `maxContext` | 8000–12000 token | 适配长篇幅的作业日志与运维台账，避免核心作业信息被截断 |
| `temperature` | 0.2–0.4 | 降低生成随机性，保障专业术语与作业流程描述的准确性 |
| `quoteMaxToken` | 1500–2000 token | 保留足够的引用文本细节，支撑内部办公场景的问题溯源 |
| `AIPROXY_API_ENDPOINT` | 按实际部署的代理地址填写，默认端口为3000 | 适配油田内网的访问限制，避免跨网访问的安全问题 |
| `AIPROXY_API_TOKEN` | 与代理服务配置的令牌一致 | 保障接口访问的安全性，防止未授权接入 |

## 容易做错的三处
- 现象：配置`AIPROXY_API_ENDPOINT`时填写错误端口号，仍能正常发起接口请求。原因：部分代理服务未严格校验端口合法性，导致错误配置未被及时拦截，后续可能出现响应异常或数据泄露。
- 现象：内部办公问答的检索结果相似度分数普遍偏高，更换向量模型后未得到改善。原因：未针对油田工程服务的专业术语优化文本处理逻辑，导致分块后的文本语义过于宽泛，匹配度计算出现偏差。
- 现象：单条结构化数据生成多组向量嵌入时，无法在界面完成配置。原因：未在FastGPT v4.17.0版本中开启多向量关联设置，导致系统仅支持单模型单向量绑定。

## 怎么确认配好了
- 查看模型接入的状态面板，确认所有配置项的参数值与填写内容一致。
- 上传一份典型的油田作业日志文档，触发模型调用，检查返回结果是否包含准确的专业术语与作业细节。
- 模拟内部员工的常见办公问题，如查询某班次的作业记录，验证检索结果的相关性符合业务预期。
- 检查接口调用日志，确认响应延迟符合作业场景的实时性要求。
