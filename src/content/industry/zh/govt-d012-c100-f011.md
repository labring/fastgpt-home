# 油田工程服务的内部办公与员工服务：表单与交互

## 这个品类的数据长什么样
油田工程服务的数据主要来自现场施工日志、设备巡检台账、材料申领单据、现场作业人员考勤记录。数据更新以单次作业完成后实时提交、每日批量汇总两种节奏为主。单份文档通常包含作业标段编号、设备序列号、作业时长、耗材使用量、人员出勤信息等字段，字段多为结构化数值或固定枚举项，单位涵盖立方米、小时、台套、人次等工程类标准单位。

## 这些特征在「表单与交互」这一环带来什么约束
油田工程服务的结构化字段与枚举项较多，要求表单支持预设固定枚举选项，避免自由输入导致的格式不统一。现场作业数据实时提交的需求，要求表单支持离线缓存提交，待网络恢复后同步上传。多标段作业的场景下，表单需要支持标段层级联动选择，避免跨标段数据混淆。部分耗材用量需匹配设备型号关联的单位校验规则，需在表单中嵌入单位自动匹配逻辑，减少输入错误。

## 配置怎么定
本文基于FastGPT v4.17.0版本进行配置说明。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 文件上传设置 | 允许上传PDF、Excel、JPEG、CAD格式文件，单文件上限1000 MB | 油田工程服务需提交施工图纸、巡检照片、耗材清单等多类型文件，单份图纸或日志文件通常不超过1000 MB |
| `formInput` 校验规则 | 数值输入绑定对应工程单位，枚举项匹配作业标段/设备类型 | 该品类字段多为结构化数值与固定枚举，可减少格式错误 |
| `userSelect` 联动逻辑 | 按作业标段联动设备型号下拉选项 | 不同标段对应专属设备型号，可简化输入步骤 |
| 提交触发时机 | 支持实时提交与批量提交两种模式 | 现场作业可实时提交巡检数据，项目部可每日批量汇总提交 |
| 离线缓存配置 | 缓存时长72小时，缓存数据上限500 MB | 油田现场网络信号不稳定，需支持较长时间的离线数据暂存 |

## 容易做错的三处
- 表单提交后文件无法同步至后端存储，提示“文件格式不支持”。原因是未在文件上传设置中添加油田工程服务常用的CAD、施工日志PDF格式，仅开放了通用格式。
- 代码运行节点中无法选择知识库引用，变量下拉列表为空。原因是未先在全局配置中绑定知识库数据源，或未在表单中配置知识库关联的触发参数。
- 输入问题后提示“没有选择知识库”，但已在聊天窗口绑定对应知识库。原因是未将知识库的调用权限与当前表单的交互会话绑定，会话上下文未关联指定知识库。

## 怎么确认配好了
- 上传一份油田工程常用的CAD施工图纸，检查是否能正常提交并存储至指定位置。
- 选择作业标段后，检查设备型号下拉选项是否自动更新为对应标段的可用型号。
- 断开网络后填写表单数据，恢复网络后检查数据是否自动同步至后端系统。
- 触发代码运行节点，检查下拉列表中是否出现已绑定的知识库引用选项。
