# 煤化工的内部办公与员工服务：知识库检索与召回

## 这个品类的数据长什么样
煤化工领域国央企内部办公与员工服务的业务数据，主要来自安全操作规程、设备运维手册、生产调度日志、员工培训课件、煤炭质检报告等。更新节奏存在差异：安全规程、设备手册随技改、法规更新调整周期较长，生产调度日志每日更新，培训课件按季度更新。文档包含数百页的长文本规程、结构化的设备台账（含设备编号、运行参数）、非结构化的PDF、Word、Excel格式文件，字段多包含专业参数，如运行温度、检修周期、灰分指标等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
长文本规程的存在，要求切片时需保留上下文关联，避免割裂专业操作步骤；结构化台账与多格式文档的混合，要求检索需同时支持语义匹配与字段关联，精准匹配设备参数类内容；不同文档的更新节奏差异，要求支持增量更新与全量更新的灵活配置，适配不同数据的更新频率；专业术语密集的内容，要求检索需精准匹配专业语义，避免无关的通用结果干扰内部办公与员工服务的查询需求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的逻辑制定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.72–0.85` | 煤化工文档多为专业技术内容，需较高相似度阈值过滤无关结果，避免安全、运维类错误匹配 |
| `limit` | `前6–10条` | 内部办公涉及多类文档，适量召回结果覆盖不同场景的参考需求，避免结果过载 |
| `searchMode` | `混合检索` | 兼顾全文语义匹配与结构化字段匹配，适配煤化工文档中既有文本描述又有参数指标的结构 |
| `usingReRank` | `开启` | 专业文档语义相似度易受术语干扰，重排可优化结果排序准确性，提升专业内容的匹配优先级 |
| `datasetSearchUsingExtensionQuery` | `开启` | 内部员工提问常使用口语化表述，扩展查询可关联专业术语，提升召回匹配度 |
| `collectionIds` | `绑定对应煤化工知识库集合ID` | 隔离不同业务线文档，避免非相关数据干扰检索结果，保障内部办公数据的安全性 |

## 容易做错的三处
- 现象：检索结果点击详情，无法查看切片前的原文档完整内容。原因：知识库配置中未关联原文件存储路径，或切片时未保留原文件与切片的关联元数据。
- 现象：上传煤化工的PDF设备手册后，检索召回结果未包含设备参数章节内容。原因：`similarity`阈值设置过高，过滤了包含专业参数的精准但语义匹配度略低的切片。
- 现象：智能体编辑页面加载后无交互响应，无法配置检索参数。原因：未正确指定`collectionIds`对应的知识库集合，导致页面无法加载关联的知识库数据。

## 怎么确认配好了
- 提交一条煤化工专业问题，如“XX型号泵的检修周期”，核对检索结果是否包含对应文档的切片内容。
- 调整`similarity`阈值，观察检索结果的数量变化，确认阈值生效。
- 开启`usingReRank`后，对比重排前后的结果排序，确认重排功能正常。
- 点击检索结果的详情链接，确认可跳转至原文件的对应位置预览。
