# 煤电一体化的内部办公与员工服务：部署与升级

## 这个品类的数据长什么样
煤电一体化场景的数据主要来源于煤矿采掘、电厂生产的实时监控系统，企业内部OA、考勤管理、薪资核算平台，以及员工培训档案。生产类数据更新频率为秒级至分钟级，办公类数据按日或按需更新，员工档案数据按月更新。数据文档包含设备运行参数、办公流程节点、员工身份与绩效字段，单位涵盖吨、千瓦时、人次、元等。

## 这些特征在「部署与升级」这一环带来什么约束
本指南适用于FastGPT v4.17.0版本。煤电一体化场景的实时生产数据更新频率高、数据体量较大，要求部署环节的数据库连接需支持高并发与长连接，避免超时中断。多源数据接入需兼容不同格式的参数字段，升级时需确保新旧版本的数据解析逻辑兼容，防止生产数据丢失。员工隐私数据的存储与传输需符合合规要求，部署时需配置加密参数。同时，批量办公流程数据的处理需预留足够的内存与存储资源，避免服务卡顿。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://[用户名]:[密码]@[内网IP]:27017/fastgpt?authSource=admin` | 适配煤电一体化场景的多源数据存储，内网部署可保障生产数据传输安全 |
| `DB_MAX_LINK` | `500–800` | 应对实时生产数据的高并发连接需求，避免连接耗尽导致服务中断 |
| `STORAGE_S3_ENDPOINT` | `内网对象存储服务地址` | 存储大量设备监控日志与员工档案文件，内网访问可降低延迟并保障数据安全 |
| `FE_DOMAIN` | `https://内部办公域名` | 适配企业内部HTTPS访问要求，符合办公场景的安全规范 |
| `FILE_TOKEN_KEY` | `按企业内部密钥管理规则生成的随机字符串` | 加密员工文件下载链接，防止未授权访问隐私数据 |
| `ROOT_KEY` | `仅在初始化时配置，后续通过内部权限系统管理` | 限制超级管理员权限，避免误操作影响生产与办公服务 |

## 容易做错的三处
- 现象：本地开发环境执行`pnpm dev`时显示数据库连接超时，无法启动服务。原因：未配置正确的内网`MONGODB_URI`，或数据库端口未开放防火墙规则，导致服务无法访问数据源。
- 现象：Docker部署后临时文件占用磁盘空间持续增长，未找到可安全删除的日志文件。原因：未配置`STORAGE_S3_ENDPOINT`使用对象存储，临时文件默认存储在容器本地，未设置自动清理策略。
- 现象：前端访问页面无法加载HTTPS资源，出现证书错误。原因：未正确配置`FE_DOMAIN`为HTTPS地址，或未将域名SSL证书挂载到部署容器中。

## 怎么确认配好了
- 执行数据库连接测试命令，验证`MONGODB_URI`配置的地址可正常连通，无超时报错。
- 访问配置的`FE_DOMAIN`地址，确认前端页面可正常加载，且内部办公功能可正常调用。
- 上传测试文件至系统，确认文件存储路径符合`STORAGE_S3_ENDPOINT`配置的对象存储服务，无存储报错。
- 查看服务日志，确认`DB_MAX_LINK`配置的连接数未出现耗尽告警，服务运行稳定。
