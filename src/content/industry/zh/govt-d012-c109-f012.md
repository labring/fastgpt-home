# 电网企业的内部办公与员工服务：部署与升级

## 这个品类的数据长什么样
电网企业内部办公与员工服务的数据，主要来自企业内部OA系统、运维工单平台、员工服务门户及培训管理系统。文档结构包含工单编号、所属运维班组、问题分类、处理状态、关联输电/配电设备编码、提交与办结时间戳。字段中关联设备编码为带字母的混合编码格式，时间类字段采用ISO 8601格式。更新节奏随业务触发：工单实时提交、考勤数据每日同步、培训档案每周更新，无固定批量同步周期。

## 这些特征在「部署与升级」这一环带来什么约束
本品类的数据包含带混合编码的关联设备字段、多时间戳字段，且更新触发场景多样。部署时需确保数据库连接串`MONGODB_URI`或`PG_URL`指向企业内部专属数据库，避免与其他业务数据的字段匹配冲突。实时提交的工单会带来较高的并发请求，需通过`DB_MAX_LINK`配置合理的数据库连接池上限，防止连接耗尽。员工服务产生的培训文档、工单附件等文件，需通过`STORAGE_S3_ENDPOINT`配置企业内部对象存储端点，降低公网传输延迟。升级时需保留原有字段映射规则，避免关联数据读取异常。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | 企业内部MongoDB实例的专属连接串，包含数据库认证信息 | 本品类数据需关联设备编码字段，使用专属库可避免与其他业务数据混淆 |
| `DB_MAX_LINK` | 100–150 个 | 内部工单实时提交带来较高并发，需维持足够的数据库连接池容量 |
| `STORAGE_S3_ENDPOINT` | 企业内部对象存储的访问端点 | 员工服务产生的培训文档、工单附件需通过内部存储传输，降低传输延迟 |
| `FE_DOMAIN` | 企业内部专属域名，如 `https://fastgpt.energy-grid.com` | 限定内部访问域名，符合企业网络安全规范 |
| `REDIS_URL` | 企业内部Redis缓存实例连接串 | 缓存员工会话与工单状态，提升内部访问的响应速度 |
| `ROOT_KEY` | 按企业内部安全规范生成的随机字符串 | 用于管理后台的最高权限验证，保障系统安全 |

## 容易做错的三处
- 现象：容器启动后前端页面持续加载转圈，最终返回502状态码。原因：未正确配置`FE_DOMAIN`与后端服务的端口映射，导致前端无法连接后端API。
- 现象：无法通过`/fastgpt`上下文路径访问所有应用。原因：未正确配置前端反向代理的路径重写规则，或`FE_DOMAIN`未包含指定的上下文路径。
- 现象：重启服务后数据写入流程持续超过2小时未完成。原因：未调整`DB_MAX_LINK`的连接数上限，导致数据库连接耗尽，数据写入线程阻塞。

## 怎么确认配好了
- 访问配置的`FE_DOMAIN`路径，确认前端页面正常加载，无加载失败或报错提示。
- 提交一条测试工单，填写关联设备编码字段，查看数据库中是否能正常存储与读取该字段内容。
- 登录企业内部对象存储控制台，检查`STORAGE_S3_ENDPOINT`对应的存储桶，确认上传的测试文件已成功写入。
- 查看数据库连接池监控面板，确认当前活跃连接数未超过`DB_MAX_LINK`的配置上限。
