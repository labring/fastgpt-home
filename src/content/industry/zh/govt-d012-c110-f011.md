# 矿山采选的内部办公与员工服务：表单与交互

## 这个品类的数据长什么样
矿山采选的数据主要来自井下传感设备、生产调度系统、设备台账库与员工考勤系统。实时类数据包含设备运行电流、巷道通风量，每日更新的为设备维护记录与班组排班表，月度更新的为选矿回收率报表。文档结构多为结构化表单，字段包含设备编号、巡检时间、隐患等级、处理状态，单位多为吨、米、小时、台，同时附带员工工号、班组归属等人员相关字段。

## 这些特征在「表单与交互」这一环带来什么约束
实时传感数据的高频更新要求表单支持实时拉取最新字段值，避免使用缓存超时的数据。结构化字段占比高，需限制自由输入项，优先使用预设选项的组件。员工工号、班组等关联字段需对接现有考勤系统接口，确保输入值与企业内部数据一致。大型选矿报表文档的上传需适配大体积文件，避免单次加载超时，同时需支持分块上传以降低失败概率。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `userSelect` | 绑定企业考勤系统接口，加载前5条匹配选项 | 矿山采选员工工号、班组为固定关联字段，避免自由输入错误，适配FastGPT v4.17.0版本组件规则 |
| `formInput` | 限制输入长度为 0–2000 字符 | 巡检记录、隐患描述等文本内容无需过长输入，降低页面加载压力 |
| 单次提交超时时间 | 600 秒 | 大型选矿报表上传或多字段提交需较长响应时间 |
| 文件上传大小限制 | 1000 MB 以内 | 矿山采选的月度报表、设备台账文件体积较大 |
| 表单分步展示 | 按巡检类型拆分表单 | 矿山采选表单字段多，拆分后降低填写复杂度 |
| 输入校验规则 | 匹配设备编号格式（如字母+数字组合） | 设备编号为固定格式字段，避免无效输入 |

## 容易做错的三处
- 现象：上传任何矿山采选相关文档均触发文件上传失败提示，文本对话功能可正常使用。原因：未配置对应品类的大体积文件上传适配参数，或上传接口超时阈值设置过低。
- 现象：表单中`userSelect`组件加载的员工选项为空，提交时显示工号或班组字段无效。原因：未正确对接企业考勤系统接口，或接口返回数据格式与组件预设不匹配。
- 现象：填写多字段表单后提交无响应，等待一段时间后显示超时错误。原因：未设置足够长的提交超时时间，或大型文档上传时未开启分块上传配置。

## 怎么确认配好了
- 打开表单页面，检查`userSelect`组件是否加载出企业内部的工号、班组选项，确认接口对接正常。
- 上传一张符合品类特征的大体积文档，检查是否能正常完成上传与提交。
- 填写表单的自由输入项，检查是否符合预设的输入长度限制与格式校验规则。
- 触发表单提交操作，确认等待时间符合设置的超时阈值，未出现无响应或超时报错。
