# 船舶制造的内部办公与员工服务：模型接入与配置

## 这个品类的数据长什么样
船舶制造内部办公与员工服务的数据源主要包括生产过程MP4视频、CAD/SOLIDWORKS设计图纸、设备维保日志、生产工单、船员考勤记录与办公OA文档。其中结构化数据如工单、考勤记录包含固定字段，如设备ID、维修时间、主机功率（单位千瓦）、吃水深度（单位米）；非结构化数据如图纸、视频体积较大，更新节奏随项目节点与日常运维调整，生产工单实时更新，维保日志按周归档，设计图纸仅在项目迭代时更新。FastGPT v4.17.0版本的工具链支持该类数据的批量导入与解析。

## 这些特征在「模型接入与配置」这一环带来什么约束
结构化数据的固定字段要求模型能精准匹配业务术语与单位，避免解析错误；非结构化的视频与图纸数据需启用多模态处理能力，否则无法识别内容。大体积的视频文件会生成较长的URL，若未适配模型的输入限制，可能导致识别失败。不同数据源的更新节奏差异，要求模型接入时支持动态调用最新数据，同时需平衡上下文长度与处理效率，避免因长文档导致的超时或响应延迟。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `vision` | 开启 | 船舶制造内部办公存在大量生产过程MP4视频、设计图纸等多模态文档，需启用多模态识别能力，FastGPT v4.17.0版本的多模态模块支持该场景 |
| `maxContext` | 8000–12000 token | 内部办公文档包含长工单记录、多页设计图纸，需适配长上下文处理需求 |
| `temperature` | 0.3–0.6 | 船舶制造专业术语多，需平衡回答准确性与灵活性，避免过度发散 |
| `maxTokens` | 2000–3000 token | 内部员工咨询多为设备问题、流程查询，需控制单轮回答长度，避免超出接口限制 |
| `AIPROXY_API_TOKEN` | 按平台生成的专属密钥 | 保障模型调用的身份合法性，防止未授权访问 |
| `toolChoice` | auto | 支持根据用户需求自动调用工具，适配内部办公的流程查询、数据检索场景 |

## 容易做错的三处
- 现象：上传船舶生产过程的MP4视频文件后，模型返回无法识别视频内容，或生成的识别结果存在乱码。原因：未开启`vision`配置项，或未正确配置多模态模型的API端点，FastGPT v4.17.0版本的多模态模块对长URL处理有特定要求，未适配会导致识别失败。
- 现象：调用模型接口时返回格式不符合内部系统的对接要求，无法直接用于展示。原因：未在模型配置中明确指定响应格式，导致返回内容与预期不符。
- 现象：在工作流中无法添加联网检索按钮，或无法切换当前对话的模型，且内置嵌入页面不可用，仅能通过API访问。原因：未在工作流配置中启用工具调用与模型切换功能，且未按新版要求配置API授权与自定义前端对接逻辑。

## 怎么确认配好了
- 上传船舶生产过程的MP4视频文件，检查模型是否能返回视频内容的结构化摘要，验证多模态配置是否生效。
- 发起包含专业术语的设备维保咨询，检查模型回答的术语准确性与回答长度是否符合预期，验证温度与上下文配置是否合理。
- 调用API接口发起请求，检查返回的响应格式是否符合内部系统的对接要求，验证接口密钥与端点配置是否正确。
- 在工作流中添加工具调用节点，检查是否能正常切换模型并触发联网检索，验证工具调用配置是否生效。
