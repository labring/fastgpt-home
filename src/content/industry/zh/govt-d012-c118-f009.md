# 金属材料加工的内部办公与员工服务：模型接入与配置

## 这个品类的数据长什么样
金属材料加工的内部办公数据主要来源于生产车间PLC控制系统、在线质检设备、企业ERP物料管理系统及设备运维日志。数据按类型分为实时工序参数、每日质检报告、月度物料库存台账三类，更新节奏覆盖实时、每日、月度。单份文档多包含工序编号、批次号、检测数值及对应单位（如MPa、mm、℃），字段固定且与生产流程强绑定，无冗余非结构化内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
实时更新的工序参数要求知识库同步周期适配数据更新节奏，避免返回过时信息；带固定单位的专业字段要求模型输出严格匹配预设单位，需在提示词中明确约束；长文档结构要求调整上下文容纳参数，避免内容截断；多源异构数据要求配置时明确数据接入的格式校验规则，确保不同系统的字段统一映射。同时，国央企内部环境要求数据接入不跨域，需适配内网部署的API端点。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 金属加工文档多含长段落的工序参数与质检数据，需容纳多份关联文档的上下文 |
| `quoteMaxToken` | 1500–2000 token | 单份质检报告或设备日志的核心内容长度，确保引用内容完整且不溢出上下文 |
| `temperature` | 0.1–0.3 | 专业参数查询需严格匹配标准术语，降低随机输出概率 |
| `vision` | 开启 | 支持质检报告中的探伤图片、工艺图纸的识别与展示，匹配内部办公的图片返回需求 |
| `AIPROXY_API_ENDPOINT` | 按企业内网部署地址填写 | 适配国央企内部网络环境，确保数据不出域 |
| `AIPROXY_API_TOKEN` | 存储于企业密钥管理系统 | 符合国央企数据安全要求，避免明文泄露 |

## 容易做错的三处
- 智能客服返回内容包含图片但未正常展示，现象为界面仅显示文本无图片占位或链接。原因是未开启`vision`配置项，大模型无法识别并关联图片资源。
- 同一模型配置于两个渠道后出现调用不稳定，现象为随机切换渠道或优先使用非预期渠道。原因是未明确配置优先级规则，或未按平台默认优先级逻辑调整参数。
- 工作流运行报错提示“上下文溢出”，现象为运行日志返回token超限错误。原因是`maxContext`配置值低于当前批次关联文档的总token数，未匹配金属加工长文档的内容长度。

## 怎么确认配好了
- 发起包含专业参数（如屈服强度、轧制温度）的查询，核对返回内容是否匹配预设的字段与单位。
- 上传包含图片的质检报告文档，发起关联图片的查询，核对返回结果是否包含图片展示。
- 同时配置两个同类型模型渠道，发起高频查询，核对调用渠道是否符合预设的优先级规则。
- 查看工作流运行日志，核对是否出现上下文超限、密钥无效等报错信息。
