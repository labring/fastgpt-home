# 高速公路运营的内部办公与员工服务：表单与交互

## 这个品类的数据长什么样
高速公路运营的内部数据来自收费站收费系统、服务区运维系统、监控中心调度平台、员工考勤系统。更新节奏：过车数据实时更新，排班、耗材数据每日更新，巡检数据按单次巡检周期更新。文档结构包含工单记录表、排班表、设备巡检表、通行量统计表。字段与单位包括车道编号（单位：个）、通行量（单位：辆次）、巡检时间（单位：YYYY-MM-DD HH:mm）、耗材余量（单位：件）、员工工号（无单位）。

## 这些特征在「表单与交互」这一环带来什么约束
实时过车数据要求表单输入需支持快速同步，避免延迟导致数据不一致。多字段的工单表单需按业务场景分块，比如收费工单、运维工单分开，降低填写复杂度。跨部门协作的表单需配置权限范围，仅允许对应岗位员工填写或审核。设备巡检表单需设置必填字段，比如故障等级、整改时限，避免遗漏关键信息影响运营安全。员工可能佩戴手套或手部沾附油污，要求表单支持语音输入等非接触交互方式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 全局变量中的当前员工工号、当前车道编号 | 高速公路运营的工单需绑定经办人与对应作业区域，确保责任清晰 |
| 用户选择范围 | 当前部门下的运维/收费人员 | 内部办公仅允许同岗位员工协作处理对应业务，避免跨部门误操作 |
| 表单提交校验 | 必填字段为车道编号、故障类型、整改时限 | 避免无效工单提交，保障运维与收费流程的规范性 |
| `userSelect` | 前5条匹配的待办工单 | 高速运营的待办工单数量适中，限制条数可提升查询效率 |
| 免登录语音输入设置 | 输入超时时间5秒，音频最大大小100 MB | 适配员工手部沾油污的场景，避免超时或文件过大导致交互失败 |
| 工作流触发延迟 | 表单提交后延迟10秒触发 | 等待跨系统数据同步完成，避免工作流调用未更新的旧数据 |

## 容易做错的三处
- 现象：`formInput`节点的默认值引用全局变量后出现字段为空。原因：未在全局变量中配置当前员工工号、车道编号等高速运营专属变量，或变量作用域未覆盖当前工作流。
- 现象：免登录页面的语音输入发送后不显示内容，或长按输入时计时始终为00:00。原因：未配置语音输入的超时阈值，或网络延迟导致音频上传未完成即触发提交。
- 现象：批量执行工单时任务提前中断，显示运行次数超限。原因：未调整工作流运行次数的配置项，默认值未适配批量工单处理场景。

## 怎么确认配好了
- 提交测试工单，检查`formInput`节点是否自动填充当前员工工号与对应车道编号。
- 测试免登录语音输入，确认输入时长正常且内容成功显示在表单中。
- 触发配置好的工作流，检查是否按延迟时间启动且运行次数符合预期。
- 故意不填写必填字段提交表单，确认弹出对应的校验提示。
