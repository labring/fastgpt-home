# 报销规则问答的员工服务台：文档解析与分块

## 这个品类的数据长什么样
该品类的数据主要来源于国央企内部财务部门发布的报销管理制度文件，包括年度更新的细则、专项报销补充通知。文档多为结构化排版，按报销类别、限额标准、审批流程分章节编排，包含具体金额阈值、凭证要求、时限规定等字段，单位多为元、工作日、人次等。更新节奏以年度正式修订为主，临时补充通知随政策调整发布，单份文档结构清晰，条款间存在明确的逻辑关联。

## 这些特征在「文档解析与分块」这一环带来什么约束
结构化文档中夹杂复杂表格与绑定金额阈值的条款，若分块时拆分跨页表格内容，会丢失限额与对应报销类别的关联关系。条款间存在明确逻辑关联，分块长度过短会割裂审批流程与对应费用标准的说明，过长则会引入无关条款影响检索精度。文档更新频率不固定，解析后的分块需支持快速匹配最新政策条目，避免因固定分块导致新旧条款混淆。字段多为带单位的精准数值，解析时需保留单位与数值的绑定关系，防止分块后单位与数值分离。

本配置说明适配FastGPT v4.17.0版本。
## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | `800–1200 字符` | 报销规则文档的单条核心条款长度多在500-800字符，800-1200字符的分块可保留单类报销规则的完整逻辑，避免割裂关联内容 |
| `chunkSplitter` | 按段落+表格识别拆分 | 报销文档包含结构化表格与段落说明，按段落结合表格识别拆分可保留表格内的完整限额信息与对应条款 |
| `customPdfParse` | 启用 | 内置解析无法准确识别报销文档中的嵌套表格与条款绑定的限额信息，自定义解析可适配结构化财务文档的排版特征 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120–180 秒` | 单份报销规则文档多为多页结构化内容，120-180秒的超时设置可保证复杂表格与长文档的完整解析 |
| `chunkSettingMode` | 手动配置 | 报销规则文档的排版固定且逻辑强关联，手动配置可避免自动分块导致的条款割裂，适配特定文档结构 |

## 容易做错的三处
- 现象：上传报销规则PDF后，知识库中表格内容缺失或格式混乱。原因：未启用`customPdfParse`配置，内置解析无法准确识别嵌套表格与条款绑定的限额信息。
- 现象：解析报销规则文档时返回超时错误。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时时长不足以完成多页复杂文档的解析。
- 现象：检索报销规则时，同一类限额的条款被拆分到多个分块中，无法匹配完整逻辑。原因：`chunkSize`设置过小，导致单条完整的报销规则被拆分为多个分块，割裂了逻辑关联。

## 怎么确认配好了
- 上传单份报销规则PDF，查看解析后的分块列表，确认每个分块包含完整的报销类别与对应限额说明。
- 检查解析结果中的表格内容，确认所有单元格的数值与单位均完整保留，未出现拆分丢失的情况。
- 模拟发起报销规则检索请求，确认可一次性获取包含审批流程、限额标准的完整分块内容。
- 调整指定配置项后重新上传文档，对比分块结果的完整性，确认配置生效。
