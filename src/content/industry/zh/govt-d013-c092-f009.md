# 报销规则问答的员工服务台：模型接入与配置

仅作参考；请以目标 FastGPT 发布版本与部署文档核验。

## 这个品类的数据长什么样
报销规则问答的数据来源于企业内部正式发布的财务报销管理制度文档、阶段性更新的报销政策通知。数据更新节奏随企业财务政策调整而定，无固定周期，新政策发布后同步更新。文档结构按报销场景分类，包含差旅费、办公费、招待费等大类，每个大类下细分具体项目，字段涵盖项目名称、单人单次限额、审批层级要求、合规凭证类型，单位多为元、人次、自然日。

## 这些特征在「模型接入与配置」这一环带来什么约束
报销规则问答的数据按场景分类且包含明确金额、层级要求，要求模型输出需严格匹配当前生效政策，不能超出给定限额。数据更新无固定周期，要求配置中支持快速同步更新后的知识库内容。不同报销场景的规则差异较大，模型需精准区分不同大类的适用条件，避免跨场景套用规则。字段中的金额单位统一为元，模型需准确识别并校验数值与单位的对应关系，防止出现单位混淆导致的错误回答。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 报销规则文档多为分场景的结构化内容，足够的上下文可确保模型获取完整的规则细节 |
| `maxTokens` | 1500–2000 token | 单条报销问答的回答需清晰列明限额、流程，该长度可覆盖常规回答需求且避免冗余 |
| `quoteMaxToken` | 600 token | 需引用的报销规则条目多为短段落，限制该参数可确保引用内容精准且不超出上下文范围 |
| `temperature` | 0.1–0.3 | 报销规则需严格合规，较低的温度值可保证回答的确定性，减少随机偏差 |
| `toolChoice` | auto | 需根据用户问题自动判断是否调用知识库检索，自动模式可适配不同场景的问答需求 |
| `AIPROXY_API_TOKEN` | 按平台分配的密钥填写 | 用于身份验证，确保模型调用的安全性与合法性 |
| `AIPROXY_API_ENDPOINT` | 按部署节点实际地址填写 | 用于指定模型调用的接口路由地址，确保请求能正确传递到目标模型 |

## 容易做错的三处
- 调用时返回`422 "Messages token length must"`报错，原因是配置的`maxContext`参数值过小，无法容纳用户问题与引用的规则文档内容，超出模型支持的上下文长度限制。
- 配置`AIPROXY_API_ENDPOINT`后请求无响应，原因是未正确填写节点对应的接口地址，或网络策略限制了对该地址的访问。
- AI对话节点输出冗余内容，原因是未限制`maxTokens`参数，模型生成的回答超出了所需范围，且未配置结果过滤规则。

## 怎么确认配好了
- 提交测试问题，如“差旅费单人单日限额是多少”，核对回答是否匹配当前配置的知识库内容。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`的配置已被正确读取，无身份验证或路由错误。
- 调整`temperature`参数后观察回答的一致性，确认参数调整对回答的影响符合预期。
- 触发知识库更新操作，验证配置的更新机制是否正常生效，新政策内容可被模型正确检索。
