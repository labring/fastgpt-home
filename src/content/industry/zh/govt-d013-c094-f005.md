# 新员工入职引导的员工服务台：工具调用与插件

## 这个品类的数据长什么样
新员工入职引导的数据主要来源于企业HR系统的入职档案、官方员工手册、部门工位指引文档、IT设备领用流程表。数据更新节奏为入职前1-3天批量同步，入职当天若有临时调整（如对接人变更、工位变动）会即时更新。文档结构以流程节点为核心，包含签到、设备领取、部门对接、账号开通等模块。字段包含员工工号、部门名称、入职日期、对接人手机号、工位编号等，其中手机号为11位数字格式，工位编号为字母加数字组合格式，入职日期采用YYYY-MM-DD标准格式。本页配置基于FastGPT v4.17.0版本。

## 这些特征在「工具调用与插件」这一环带来什么约束
HR系统的数据源要求工具调用需对接企业内部开放API，需配置合法的身份校验参数。批量与临时混合的更新节奏，要求工具调用支持按需刷新缓存，避免使用过期的员工信息。多节点的流程结构，要求工具调用可根据当前引导节点自动匹配对应插件，比如设备领取环节调用设备管理插件，部门对接环节调用通讯录插件。动态的员工专属字段，要求工具入参需绑定员工工号等唯一标识，确保返回的信息匹配当前引导的新员工。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 设为`auto` | 允许模型根据入职引导的流程节点自动选择对应工具，适配多步骤的入职场景 |
| `functionCall` | 开启强制函数调用模式 | 确保工具调用的返回结果符合入职引导的结构化输出要求，避免非预期的自然语言回复 |
| 工具调用超时时间 | 30-60秒 | 适配HR系统、设备管理系统的常规接口响应时长，避免超时中断入职流程 |
| 插件授权配置 | 绑定HR系统、设备管理、通讯录插件的官方密钥 | 确保工具调用能合法访问对应系统的专属数据 |
| 工具触发规则 | 按员工工号动态绑定入参 | 确保每个新员工的引导流程调用对应个人专属的工具数据 |

## 容易做错的三处
- 现象：工具调用时返回模型不支持函数调用的报错，状态码为400。原因：未正确配置`functionCall`参数，使用了不支持工具调用的模型版本。
- 现象：第三方浏览器调用FastGPT接口时返回跨域拦截提示。原因：未在FastGPT网关配置中添加对应业务域名的跨域白名单。
- 现象：调用入职知识库搜索时返回无匹配结果，界面提示“未找到相关文档”。原因：未将员工手册、工位指引等入职相关文档正确关联到对应知识库分类。

## 怎么确认配好了
- 触发模拟新员工入职流程，检查是否自动调用对应节点的工具并返回符合预期的结构化信息。
- 查看工具调用日志，确认`toolChoice`参数已生效，模型自动选择了匹配当前流程节点的工具。
- 提交跨域测试请求，确认浏览器端不再收到跨域拦截报错。
- 临时调整测试员工的工位信息，检查工具调用后是否能获取到更新后的工位数据。
