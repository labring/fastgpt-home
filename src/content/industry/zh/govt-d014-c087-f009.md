# 工单自动分类的热线知识库与工单辅助：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据来源于热线呼叫中心的来电转录文本、内部工单管理系统的工单条目。每笔新的用户来电或工单提交时同步更新数据，更新节奏为实时接入。单条工单文档包含诉求标题、详细描述、来电时间、用户标识、初始派单候选标签等字段，其中来电时间格式为YYYY-MM-DD HH:MM:SS，诉求描述为无固定长度的纯文本内容，无统一格式约束。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 4000–6000 token | 单条工单通常包含标题、详细描述与历史交互，需覆盖完整的单条工单上下文 |
| `maxTokens` | 1000–1500 token | 分类结果需包含一级分类标签、二级分类标签与简要匹配说明，输出长度需满足需求 |
| `temperature` | 0.1–0.3 | 工单自动分类需稳定一致的结果，避免因随机偏差导致分类错误 |
| `AIPROXY_API_ENDPOINT` | 按部署模型的服务商提供的标准API地址填写 | 适配自建或第三方托管的大模型接口，确保调用链路正确 |
| `AIPROXY_API_TOKEN` | 按服务商生成的有效访问密钥填写 | 完成模型接口的身份验证，防止未授权访问 |
| `toolChoice` | none | 工单自动分类仅需文本分类能力，无需调用外部工具 |

## 容易做错的三处
- 调用模型时返回401未授权错误。原因是`AIPROXY_API_TOKEN`填写错误或过期，未正确配置接口访问密钥。
- 分类结果为空或无明确分类标签。原因是`maxTokens`设置过小，分类结果被截断无法完整输出，或`temperature`设置过高导致输出不稳定。
- 第三方模型配置后无法正常调用，页面显示模型加载失败或调用超时。原因是`AIPROXY_API_ENDPOINT`填写错误，未正确指向代理地址，或未在第三方平台开启对应模型的调用权限。

## 怎么确认配好了
- 上传一条真实的测试工单文本，在模型配置页面触发单次调用，查看返回的分类结果是否符合业务预期。
- 检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的填写内容，可通过标准HTTP请求工具测试接口连通性，确认无访问错误。
- 调整`temperature`参数的取值，观察多次调用同一条工单的分类结果，确认输出无明显随机偏差。
- 模拟批量工单流入场景，查看模型调用的延迟情况，确认无超时报错影响业务流程。
