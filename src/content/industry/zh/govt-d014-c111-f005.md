# 答复口径推荐的热线知识库与工单辅助：工具调用与插件

## 这个品类的数据长什么样
本页适配FastGPT v4.17.0版本，答复口径推荐的数据主要来自热线平台归档的历史工单、官方发布的政策问答、客服团队维护的标准答复口径库。更新节奏为工单办结后1小时内同步增量数据，官方政策更新后24小时内完成全量刷新。单条数据包含用户诉求原文、办结答复原文、诉求分类标签、办理部门字段，所有字段均为纯文本格式，无嵌套结构，单条数据长度多在200至800字符区间。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于数据字段均为纯文本且无嵌套结构，工具调用时无需额外解析复杂嵌套结构，可直接提取指定字段用于召回匹配。因更新频率较高且支持增量同步，工具调用的缓存有效期需设置为不超过1小时，避免返回过时的答复口径。单条数据长度区间明确，工具调用时需限制单次召回的总字符数，防止超出模型上下文窗口上限。诉求分类标签的存在，要求工具调用时可按分类标签过滤召回结果，提升匹配精准度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配热线诉求的多样化分类，自动匹配对应答复口径召回工具 |
| `functionCall` | `[{"name":"recall_reply","parameters":{"query":"{{user_query}}","category":"{{user_category}}"}}]` | 按用户提交的诉求分类标签，精准召回对应领域的答复口径 |
| 缓存有效期 | `30 分钟` | 匹配数据增量更新频率，平衡实时性与接口调用效率 |
| 单次召回上限 | `前 3 条` | 单条口径长度适中，3条总长度符合模型上下文窗口要求 |
| 接口超时时间 | `60 秒` | 适配热线场景的快速响应需求，避免用户等待过久 |
| 跨域允许配置 | 添加热线平台域名至允许列表 | 允许第三方系统通过浏览器调用FastGPT开放接口 |

## 容易做错的三处
- 调用时返回模型不支持工具调用的报错，原因是未选择支持`functionCall`或`toolChoice`的模型类型。
- 第三方浏览器调用接口返回403权限错误，原因是未将热线平台的域名添加至FastGPT的跨域允许配置中。
- 召回的答复口径与用户诉求不匹配，原因是未在工具调用参数中传入用户诉求的分类标签，导致召回范围过大。

## 怎么确认配好了
- 调用工具接口后，检查返回结果中是否包含`functionCall`或`toolChoice`对应的召回参数，确认参数格式正确。
- 模拟不同分类的用户诉求，调用接口后查看召回的答复口径是否匹配对应分类，确认过滤逻辑生效。
- 查看接口调用日志，确认超时时间、缓存有效期等配置项与预设值一致，无异常报错。
- 从第三方系统发起浏览器调用，确认接口可正常返回结果，无跨域相关报错。
