# 答复口径推荐的热线知识库与工单辅助：部署与升级

## 这个品类的数据长什么样
本品类的数据主要来自内部热线工单系统、已审核的标准答复库与用户咨询日志。数据更新节奏为每日凌晨同步当日归档的工单数据，紧急更新的标准答复可手动触发同步。单条数据的文档结构包含咨询问题、标准答复内容、工单标签、受理时间、办结结果与工单编号等字段，其中咨询问题与标准答复以纯文本形式存储，工单标签为分类字符串，受理时间为标准时间戳格式。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据来源为内部敏感业务系统，部署时需配置内网可访问的数据库与存储参数，避免数据泄露。每日定时同步的更新节奏要求升级过程中保留同步任务的配置，避免数据同步中断导致口径更新不及时。多字段的文档结构要求部署时明确字段映射规则，确保召回数据的完整性与准确性。敏感的内部咨询与工单数据要求部署时开启存储加密，符合内部合规要求。升级时需兼容旧版字段映射规则，避免历史同步数据无法被正常识别。

## 配置怎么定
仅作参考；请以目标 FastGPT 发布版本与部署文档核验。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MONGODB_URI` | `mongodb://内网MongoDB地址:27017/fastgpt?authSource=admin` | 存储工单与口径的结构化数据，内网部署适配内部网络安全要求 |
| `REDIS_URL` | `redis://内网Redis地址:6379/0` | 缓存同步的口径数据与会话信息，保障内网访问速度与数据安全 |
| `STORAGE_S3_ENDPOINT` | `内网对象存储服务地址` | 存储归档的工单附件与大体积口径文档，适配内部合规存储规则 |
| `DB_MAX_LINK` | `20–30 个` | 平衡数据库并发访问与资源占用，适配内部系统的数据库连接上限 |
| `ROOT_KEY` | `按内部运维规范生成的强密钥` | 管理平台的最高权限验证，避免未授权访问内部配置 |
| `FE_DOMAIN` | `内网前端访问域名` | 配置前端服务的访问地址，适配内部办公网络的访问规则 |

## 容易做错的三处
- 现象：导入口径同步插件时返回`internal server error`。原因：未正确配置`MONGODB_URI`或`REDIS_URL`的内网访问权限，服务无法正常连接内部数据源。
- 现象：版本升级后模型厂商图标无法加载。原因：未同步更新`FE_DOMAIN`的配置值，前端无法获取正确的静态资源访问地址。
- 现象：知识库磁盘占用持续超出预期。原因：未开启归档数据的自动清理策略，或未正确配置`STORAGE_S3_ENDPOINT`的存储路径映射，导致冗余的分割文件块与嵌入向量未被释放。

## 怎么确认配好了
- 执行内网连通性测试，确认`MONGODB_URI`与`REDIS_URL`对应的服务可正常访问。
- 手动触发一次口径数据同步任务，查看同步日志无报错且成功导入历史工单数据。
- 访问前端管理页面，确认模型厂商图标可正常加载，无资源加载失败提示。
- 查看存储监控面板，确认口径数据与嵌入向量的存储路径符合配置的`STORAGE_S3_ENDPOINT`要求。
