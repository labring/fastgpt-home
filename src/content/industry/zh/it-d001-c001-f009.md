# CDN与边缘加速配置的代码与变更评审辅助：工具调用与插件

## 这个品类的数据长什么样
该品类的数据主要来自CDN控制台、DNS解析记录、边缘节点访问日志与监控告警系统。日常关联文档包括域名接入单、缓存规则配置单、刷新预热操作记录、故障根因分析报告。数据更新节奏为每日汇总或随配置变更实时同步，字段包含域名、缓存有效期、边缘节点IP、访问流量、告警触发阈值等，无统一固定统计口径，仅按单次变更或周期归档。本页面内容适配FastGPT v4.17.0版本。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据多源分散且更新节奏差异大，工具调用需适配CDN控制台、DNS解析、访问日志等不同数据源的API认证与格式要求，需处理配置变更后的实时同步延迟。日常关联文档以域名维度为核心，插件需绑定域名上下文完成规则校验与变更核对。高频耗时环节如缓存规则调试、异常节点排查，要求工具调用封装标准化操作接口，同时需在变更评审环节校验缓存TTL、刷新量等字段的合法性，避免因参数错误导致访问异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配CDN场景下多工具自动调用的需求，无需手动指定工具类型 |
| `functionCall` | `enabled` | 支持结构化参数返回，便于在变更评审中提取缓存规则、域名信息等核心字段 |
| 工具调用超时时间 | `300 秒` | CDN控制台与边缘节点接口的响应通常在200秒内，该取值可覆盖多数正常调用场景 |
| 单次工具调用返回条目上限 | `前 10 条` | 限制CDN访问日志、告警数据的返回量，避免超出上下文窗口导致内容截断 |
| MCP认证配置 | 自定义Header | 适配多数企业CDN接口的认证要求，满足带认证的SSE接口接入需求 |
| 工具调用触发时机 | 变更提交后自动触发 | 在评审阶段提前校验配置合法性，减少人工核对域名备案、缓存规则的耗时 |

## 容易做错的三处
- 现象：调用带Header认证的SSE类型CDN接口时返回401未授权错误。原因：未在MCP配置中正确添加自定义认证Header字段，或字段值与CDN控制台的API密钥不匹配。
- 现象：`functionCall`配置开启后，模型返回的缓存规则参数仍为自然语言格式，无法直接用于变更校验。原因：未将`toolChoice`设置为`auto`，或未指定正确的工具调用模板，导致模型未按结构化格式返回参数。
- 现象：尝试调用Mermaid MCP Server生成流程图时，工作流中无法获取有效图片链接。原因：未在工具调用配置中配置MCP Server的回调地址，或未开放对应端口的访问权限，导致生成的图片无法被正常访问。

## 怎么确认配好了
- 提交一条测试域名变更配置，触发工具自动调用，检查是否能拉取该域名的现有缓存规则与备案状态。
- 发起一次模拟调用，验证自定义Header认证是否生效，确认返回的CDN访问日志数据格式符合预期。
- 查看工作流日志，确认`functionCall`与`toolChoice`配置已被正确加载，无参数缺失或格式错误。
- 测试Mermaid MCP Server调用，确认生成的流程图链接可在FastGPT的对话界面正常预览。
