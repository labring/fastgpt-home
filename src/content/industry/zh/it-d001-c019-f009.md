# 众包标注人员管理的代码与变更评审辅助：工具调用与插件

## 这个品类的数据长什么样
该品类的数据主要来自众包平台的人员台账、标注质量抽检结果、标注人员培训考试记录、财务系统的结算明细。日常维护的文档包括人员准入规则、岗位培训材料、月度绩效表、季度结算清单。数据更新频率多为每日（人员在岗状态、当日标注质量）或每月（绩效汇总、结算数据），核心字段包含人员唯一标识、准入审核状态、培训合格等级、单批次标注准确率、结算周期与金额等。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于数据来源分散，工具调用需支持对接众包平台、标注质量系统、财务系统的多源接口，需提前配置字段映射规则以统一数据格式。因数据更新周期分日/月，工具触发需区分定时任务的执行频率，日更数据适配每日同步，月更数据适配月度批量拉取。日常文档包含准入规则与绩效表，工具调用需支持读取指定格式的文档提取审核条件，用于自动生成人员评审逻辑。同时，为避免质量波动与结算错误，工具调用需加入字段合法性校验环节，防止参数错误导致的错付漏付。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 该场景需自动匹配适配众包标注人员管理的工具，无需手动指定调用目标 |
| `functionCall` | 开启 | 需调用外部接口拉取标注人员绩效、结算数据，启用函数调用可实现参数化数据获取 |
| 工具调用超时时间 | `600 秒` | 众包平台批量数据拉取通常耗时较长，600秒可覆盖多数常规同步场景，按实测标定 |
| 文档读取格式 | 表格、PDF 文本 | 日常维护的人员准入规则、绩效表多为表格或PDF格式，需支持读取结构化内容 |
| 定时触发周期 | 每日、每月 | 数据更新频率分为日更（在岗状态、当日质量）与月更（绩效汇总、结算），对应不同同步周期 |

## 容易做错的三处
- 现象：工具调用出现超时报错，返回状态码504。原因：未配置合理的超时时间，默认超时时长不足，无法完成批量标注人员数据的拉取。
- 现象：调用工具时返回字段为空，无法获取标注人员绩效数据。原因：未正确配置`functionCall`的参数映射，未关联众包平台的人员ID字段，导致接口请求参数错误。
- 现象：工具返回的评审结果为纯文本，无结构化格式。原因：未指定返回格式，未启用结构化输出，导致前端解析后展示单调。

## 怎么确认配好了
- 手动触发工具调用，查看返回的标注人员数据是否包含核心业务字段，核对字段映射是否与配置一致。
- 查看工具调用日志，确认超时时间配置生效，无频繁超时报错。
- 检查定时任务的执行记录，确认日更与月更数据分别按预设周期完成同步。
- 调用测试接口，验证`toolChoice`自动选择工具的逻辑是否适配当前场景的需求，同时确认返回内容为结构化格式。
