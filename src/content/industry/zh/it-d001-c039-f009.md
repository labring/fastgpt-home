# 后端服务开发的代码与变更评审辅助：工具调用与插件

## 这个品类的数据长什么样
本品类的数据主要来自代码仓库、API网关日志、数据库、配置中心，更新频率为每日或每版本发布时。日常产出的文档包含接口设计文档、数据库变更单、代码评审记录、发布说明，其中接口设计文档包含接口路径、请求参数、响应格式等字段，数据库变更单记录表结构修改内容，代码评审记录包含评审意见与修改标记。数据字段多围绕接口契约、事务边界、异常日志ID等后端专属内容展开。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类的数据来源分散且更新节奏不固定，工具调用需适配代码仓库、API网关日志等多类数据源的访问权限与解析格式。日常文档结构差异较大，插件需支持接口设计文档、数据库变更单等不同类型文件的字段提取。不同于前端应用开发，后端服务开发更关注业务规则、数据一致性和服务稳定性，因此工具调用的参数需匹配接口契约、事务边界等后端专属字段，避免调用逻辑与后端服务的核心约束冲突。同时频繁的更新要求工具调用结果需保持与最新数据的同步性，防止评审依据出现偏差。

## 配置怎么定
以下配置规则适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配后端服务开发中多工具并行调用的场景，自动匹配任务类型选择对应工具 |
| `functionCall` | 单次调用不超过 3 个函数 | 避免单次请求超出后端服务的接口并发限制，降低调用失败风险 |
| 工具调用超时阈值 | 300 秒 | 匹配后端服务通用的接口超时标准，防止任务因等待过久被强制终止 |
| 数据源范围 | 近 7 天的代码提交与变更记录 | 聚焦当前评审周期内的内容，符合代码评审的时效性要求 |
| 上下文长度 | 8000 token | 适配后端服务开发中长文档解析需求，如完整的接口设计与变更说明文档 |

## 容易做错的三处
- 自定义代码调用报错提示AggregateError Code:ETIMEDOUT，原因是未配置匹配后端服务的超时阈值，导致调用外部依赖时等待时长超出系统限制。
- 添加MySQL数据库工具调用后返回400状态码且无响应体，原因是未正确配置数据库连接的权限与地址参数，导致工具无法建立有效连接。
- 配置`functionCall`时调用函数数量超出限制，导致接口契约校验失败，原因是未遵循单次调用函数数量的配置规则。

## 怎么确认配好了
- 发起一次模拟代码变更评审的工具调用请求，检查返回结果是否包含预期的接口契约校验内容。
- 查看工具调用日志，确认数据源范围仅包含指定周期内的后端服务相关数据。
- 测试自定义代码调用的超时场景，验证触发报错的时长是否符合预设的阈值规则。
- 核对`functionCall`的配置数量，确认单次调用的函数数量未超出预设限制。
