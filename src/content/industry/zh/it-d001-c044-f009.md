# 安全产品规则运营的代码与变更评审辅助：工具调用与插件

## 这个品类的数据长什么样
本品类的数据主要来自WAF、IDS、防火墙及威胁情报平台，更新频率为每日或随防护事件触发。日常产出的文档包含规则变更单、拦截日志、误报分析报告、策略回滚记录，字段通常包含规则唯一标识、拦截阈值配置、生效时间、误报触发次数、攻击匹配特征等，无统一强制格式，需适配各安全产品的导出规范。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源异构的数据来源要求工具调用需兼容WAF、IDS等不同安全产品的认证与数据拉取协议，适配非统一的日志格式。高频更新节奏要求插件支持增量同步与实时事件拉取，避免全量拉取带来的性能消耗。文档格式的灵活性要求前置配置格式转换插件，将原始日志转化为可用于评审的标准化字段。误报样本的波动特征要求动态调整工具调用的并发阈值，防止资源耗尽。规则变更的审批流程要求工具调用需关联变更单的审批状态，确保评审动作与变更流程同步。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配安全产品规则运营的多工具调用场景，自动选择日志解析或规则校验工具完成评审辅助 |
| `functionCall` | `enabled` | 支持将模型输出的规则调整建议转化为可执行的配置参数，适配变更评审的自动化输出需求 |
| 安全产品API超时阈值 | `300–600 秒` | 适配安全产品日志拉取的延迟特性，避免全量同步或增量拉取时因超时中断流程 |
| 增量同步间隔 | 按实测标定，推荐 `10–30 分钟` | 平衡数据实时性与服务器资源消耗，适配每日或随事件触发的更新节奏 |
| 单次日志拉取上限 | `前 500 条` | 控制单次工具调用的负载，防止因单批次数据过大导致服务卡顿 |
| 单次日志格式转换上限 | `800–1200 字符` | 控制单次转换的负载，避免因单批次数据过大导致工具调用失败 |

## 容易做错的三处
- 现象：调用FastGPT API发起对话后，无法主动中断模型生成过程，后续请求需等待前序任务执行完成。原因：未配置`toolChoice`为可中断模式，或未启用会话级的任务终止接口，导致请求队列未及时释放。
- 现象：配置自定义URL的文档解析工具后，无数据返回且未触发报错。原因：未将自定义URL添加至安全产品规则运营的数据源白名单，或URL返回的内容格式超出插件预设的解析范围。
- 现象：工作流运行后未生成符合要求的文档格式结果。原因：未启用`functionCall`的输出格式约束，模型输出的规则调整内容未被转化为标准的文档字段结构。

## 怎么确认配好了
- 发起一次测试性的规则变更评审请求，验证模型输出的规则调整建议可被自动转化为可执行的配置参数，确认`functionCall`功能正常生效。
- 配置自定义URL的数据源，发起文档解析调用，检查返回的日志字段是否包含规则ID、拦截阈值等核心信息，确认格式转换插件正常工作。
- 发起增量同步测试，检查是否按预设间隔拉取安全产品的拦截日志，确认API超时阈值与增量同步间隔配置符合业务需求。
- 检查FastGPT服务端的跨域配置，验证外部域名可正常发起API请求，确认跨域设置符合安全产品规则运营的访问需求。
