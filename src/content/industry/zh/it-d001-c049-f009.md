# 客户培训与使用手册的代码与变更评审辅助：工具调用与插件

## 这个品类的数据长什么样
这个品类的典型使用主体为客户成功经理、培训讲师与产品运营，日常产出的文档包含培训课件、用户手册、培训签到表、问题答疑清单。数据主要来源于产品帮助中心、客户组织架构、培训录屏与工单系统，更新频率为每单或每版本。文档结构覆盖操作指引、权限说明、答疑记录等类型，无统一固定字段，数据体量随客户单量与版本迭代波动。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据来源分散且更新频繁，要求工具调用需支持对接多类数据源，包括静态文档与动态工单、录屏数据。文档结构无统一格式，需工具插件适配不同的输入解析规则。高频更新的特性要求工具调用链路支持定时同步最新的培训与工单数据，避免使用过期内容辅助评审。同时，该品类的核心耗时环节集中在权限讲解与步骤演示，工具调用需优先关联对应场景的知识库条目，提升辅助效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | 设为`auto` | 适配客户培训文档多类型内容的自动工具选择需求 |
| `functionCall` | 开启 | 支持结构化调用MCP服务完成代码评审相关的查询与数据拉取 |
| 工具调用超时阈值 | 600秒 | 匹配培训录屏、工单数据的批量处理时长 |
| 知识库召回上限 | 前10条 | 适配客户培训文档的单批次数据体量 |
| 上下文窗口大小 | 8000–12000 token | 容纳完整的用户手册与评审代码片段 |

## 容易做错的三处
- 发起代码评审相关查询后无工具触发，界面显示「未启用工具」，原因是未将`toolChoice`设置为`auto`或指定对应工具类型。
- 调用工具后返回的内容与当前培训手册问题无关，出现跨品类的通用答疑内容，原因是召回的知识库未限定为客户培训与使用手册的专属数据源。
- 本地部署模型调用MCP服务返回连接超时错误，错误码504，原因是本地模型未配置允许调用外部工具的白名单规则。

## 怎么确认配好了
- 发起包含代码评审关键词的查询，查看FastGPT v4.17.0的工具调用日志是否生成对应记录。
- 检查工具调用返回结果是否包含客户培训文档的相关内容，如权限说明、操作步骤等。
- 验证本地部署模型调用MCP服务时无连接报错，确认工具调用链路正常。
- 调整查询关键词为非培训相关内容，确认工具不会触发无关的知识库召回。
