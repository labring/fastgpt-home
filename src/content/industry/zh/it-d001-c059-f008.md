# 广告素材审核的代码与变更评审辅助：工作流编排

## 这个品类的数据长什么样
广告素材审核的数据来源包括广告平台投放素材、落地页截图、商品资质文件与广告法合规条款库。数据更新节奏分为实时与每日批量两种，实时更新对应单条素材提交后的即时审核，日更对应批量代理商素材的集中校验。日常需处理的文档包含单条素材的文案内容、落地页URL与截图、审核人员标注的违规点记录、修改迭代的版本日志。数据字段涵盖素材唯一标识、违规类型编码、审核状态、落地页校验结果等，无统一固定单位，部分字段以字符数、条目数为统计维度。

## 这些特征在「工作流编排」这一环带来什么约束
多源数据来源要求工作流需配置独立节点对接广告平台、落地页服务与合规条款库，避免数据拉取冲突。实时与日更的混合更新节奏，要求工作流支持事件触发与定时拉取两种启动方式，适配不同审核场景。多样的文档类型与字段结构，要求工作流内的`variables`需定义适配不同文档的分类变量，如素材文案长度、落地页合规状态。单条素材审核出错会导致广告被拒、账户受限，要求工作流必须加入校验节点与失败回溯分支，确保异常环节可被快速定位。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本的工作流编排功能。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 触发时机 | 按素材更新事件触发，或每日凌晨2点批量拉取 | 适配单条素材即时审核与批量代理商素材的集中校验需求 |
| `variables` | 定义`违规次数统计`、`素材类型`、`落地页校验结果`三类变量 | 适配广告素材审核的分类统计与跨节点状态同步需求 |
| `nodeId` | 为文案检查节点、落地页核对节点分配唯一标识 | 便于工作流节点间的数据流转与失败回溯定位 |
| 失败重试次数 | 3次，间隔60秒 | 应对临时网络波动或广告平台接口调用失败的场景 |
| 超长文本处理阈值 | 800–1200 字符 | 适配广告素材文案的常规长度范围，避免节点超时 |
| 变量作用域 | 全局 | 适配跨节点的审核状态同步需求，确保变量值在整个工作流中可被读取 |

## 容易做错的三处
- 变量更新后界面无变化，表现为`variables`定义的统计数值未随审核进度更新，原因是未将变量作用域设置为全局，仅在单次节点内生效。
- 超长文案生成结果被截断，表现为返回的审核意见仅包含部分文案内容，原因是未设置适配广告素材长度的处理阈值，超出节点默认处理上限。
- 工作流节点无触发记录，表现为`nodeId`对应的文案检查节点始终处于待处理状态，原因是未正确关联素材更新事件与触发节点的绑定关系。

## 怎么确认配好了
- 上传一条包含违规文案的广告素材，检查工作流是否自动触发文案检查节点，确认触发时机配置生效。
- 手动触发`variables`的违规次数更新操作，查看变量面板确认数值正确累加，验证变量配置与作用域设置正确。
- 模拟广告平台接口返回异常，检查工作流是否触发失败重试机制，验证重试次数与间隔配置生效。
- 查看`nodeId`对应的节点日志，确认数据流转正常，无字段缺失或格式错误。
