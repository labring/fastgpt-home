# 投放计划搭建的代码与变更评审辅助：工具调用与插件

## 这个品类的数据长什么样
投放计划搭建的日常文档包含投放计划、定向设置、预算排期、转化追踪配置。数据来源包括广告平台API、用户画像系统、预算表、归因工具，更新频率为每日或按单次活动周期更新。文档字段包含定向维度参数、预算额度与单位、转化事件类型、归因规则配置等，各字段需严格匹配对应数据源的格式要求，无统一固定格式。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据依赖要求工具调用需适配不同广告平台的API格式，需通过插件完成跨数据源的字段映射。作为广告上线前的配置环节，高频更新特性要求工具调用的缓存时长需匹配数据更新节奏，避免使用过期的投放配置数据。多字段结构要求工具调用时需明确校验返回字段的合法性，防止因字段不匹配导致投放计划无法启动。文档与数据源的格式绑定要求工具调用的参数需严格遵循对应平台的命名规则，避免数据错位。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配不同广告平台工具的自动调用选择，无需手动指定工具 |
| `functionCall` | 强制返回转化追踪配置字段 | 确保工具返回的字段与投放计划文档的转化追踪配置一致 |
| 工具调用缓存时长 | 300 秒 | 匹配投放计划的日更更新频率，避免使用过期的投放配置数据 |
| 调用超时阈值 | 60 秒 | 防止广告平台API响应延迟导致工作流中断 |
| 单次调用结果上限 | 10 条 | 匹配投放计划文档的字段数量，避免返回过多冗余数据 |
| 上下文窗口大小 | 2000 字符 | 适配投放计划文档的文本长度要求 |

## 容易做错的三处
- 工作流中无法获取MCP工具返回的投放计划参数值，现象是节点输出字段为空，原因是未在`functionCall`配置中明确指定需要返回的字段范围。
- 调用Mongo查询工具时，模型上报的token消耗与实际API调用消耗不一致，现象是日志中显示的token数值存在差异，原因是工具调用时默认携带了冗余的上下文元数据。
- 知识库调用后返回无关的投放效果数据，现象是回答内容偏离当前投放计划搭建的查询主题，原因是未对工具调用的数据源范围进行定向限定。

## 怎么确认配好了
- 启动测试工作流，查看工具调用节点的输出日志，确认返回的字段与配置中指定的范围一致。
- 对比模型上报的token消耗与Mongo或广告平台API的实际消耗记录，确认差值符合预期。
- 输入与投放计划搭建相关的查询，验证返回内容仅包含当前配置的数据源信息。
- 在FastGPT v4.17.0环境中调整工具调用的超时阈值，测试超过阈值时的工作流响应，确认异常处理逻辑生效。
