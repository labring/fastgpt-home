# 机柜上架与布线的代码与变更评审辅助：工具调用与插件

## 这个品类的数据长什么样
服务主体为IDC运维工程师、网络工程师及设备实施人员；数据来源为DCIM系统、资产管理系统、网络拓扑图及客户服务工单；日常产出上架申请单、机柜布线图、端口标签表、施工记录等文档；字段包含机位编号、线缆规格、端口标识、施工日期等，单位涉及机架单位U、线缆长度米、端口序号等；数据更新节奏为每单作业更新一次，日常运维文档每日同步核对。

## 这些特征在「工具调用与插件」这一环带来什么约束
多数据源的接入需求要求插件需配置多套鉴权规则，避免跨系统调用失败；非结构化的布线图与结构化的工单数据并存，需要工具同时支持结构化字段校验与多模态内容识别；数据更新随工单流转，工具触发时机需绑定工单状态变更，避免调用过时数据；出错后果直接影响业务交付，工具需增加跨数据源一致性校验环节，降低端口接错等风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配多工具自动调度，匹配机柜上架场景下多数据源调用需求 |
| 插件鉴权配置 | 按对接系统生成的密钥填写，超时时间设为30秒 | 适配DCIM、资产系统等不同鉴权逻辑，避免调用超时中断评审 |
| 多模态工具调用阈值 | 置信度阈值设为0.75 | 用于校验布线图识别的端口标识准确性，匹配业务验收标准 |
| 工具触发时机 | 按工单提交后10分钟触发 | 匹配上架申请的审批流转节奏，避免提前调用导致数据未更新 |
| 上下文窗口大小 | 8000 token | 容纳机柜布线图、端口标签表等多文档的评审内容 |
| `functionCall` | 开启循环触发上限为2次 | 适配多轮端口校验的评审需求，避免无效循环调用 |

## 容易做错的三处
- 调用智谱多模态模型时持续报参数错误，使用OpenAI协议直接调用OneApi接口却可成功。原因是未正确配置多模态工具的专属鉴权参数，或未将`toolChoice`设置为适配多模态调用的模式。
- 升级到FastGPT v4.17.0后，插件编辑页面无论是否操作，顶部始终提示“未保存”，点击保存按钮后仍无变化。原因是前端状态同步逻辑未正确绑定保存接口的返回结果，导致页面状态标记未更新。
- 配置多轮评审工具时，仅通过提示词引导模型思考，未实际触发多次工具调用。原因是未正确设置`functionCall`的循环触发条件，或未绑定工单状态变更作为调用触发节点。

## 怎么确认配好了
- 触发一次测试工单，查看工具调用日志，确认多数据源接口均返回有效数据。
- 上传一张机柜布线图，调用多模态工具，确认返回的端口标识识别结果符合预期。
- 修改插件配置后点击保存，查看页面状态标记是否更新为“已保存”。
- 配置跨数据源校验规则，导入不一致的端口数据，确认工具触发告警提示。
