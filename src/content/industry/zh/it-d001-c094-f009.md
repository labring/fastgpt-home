# 用户验收测试支持的代码与变更评审辅助：工具调用与插件

## 这个品类的数据长什么样
本品类的典型参与主体为实施顾问、测试经理、客户业务代表。日常产出与使用的文档包含UAT用例、验收问题单、验收报告、签字确认单。数据来源涵盖需求规格、测试环境配置、客户业务样例、缺陷管理系统。数据更新频率为每阶段或每版本一次，文档结构固定，UAT用例包含场景、前置条件、预期结果字段，验收问题单包含缺陷标识、复现步骤、严重程度字段，无额外自定义非标准字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于数据来源分散在需求、测试环境、客户样例等多个系统，工具调用需要支持多源数据的关联拉取配置。因更新频率为阶段/版本级，插件需要支持按版本触发的增量同步机制，避免全量拉取占用过多资源。文档结构固定的特征要求工具调用参数需匹配固定字段，无需额外适配非标准字段。参与主体包含客户业务代表的特征，要求插件需配置角色权限校验规则，区分内部与客户侧的访问权限。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 支持自动选择适配UAT评审场景的工具，无需手动指定 |
| `functionCall` | `[{"name":"fetch_uat_review_data","parameters":{"doc_type":["uat_case","acceptance_issue"]}}]` | 匹配UAT用例与验收问题单的文档类型，精准拉取目标数据 |
| 单次工具调用超时 | `600 秒` | UAT评审数据拉取涉及多源关联，预留充足的响应时间 |
| 数据源关联范围 | 当前版本关联的需求、测试环境、客户样例数据 | 限定在当前阶段的有效数据，避免冗余内容干扰评审 |
| 同步触发时机 | 每版本发布前2-5天 | 匹配本品类每阶段/每版本的更新频率，提前同步最新数据 |
| 权限校验开关 | 开启 | 适配客户业务代表参与的场景，区分不同角色的访问权限 |

## 容易做错的三处
- 现象：调用工具时返回connection error报错。原因：未正确配置数据源对接的基础参数，无法连通UAT用例、验收问题单所在的存储系统。
- 现象：API调用返回的结果未包含预期的UAT知识库内容。原因：未在`functionCall`参数中指定拉取UAT相关文档的类型，工具未触发对应知识库的关联查询。
- 现象：工具调用返回的验收结论字段为空。原因：未配置按版本触发的同步机制，未拉取最新的验收报告数据。

## 怎么确认配好了
- 进入FastGPT v4.17.0的插件管理页面，查看已配置的UAT评审工具的参数列表，确认`toolChoice`和`functionCall`参数已正确填写。
- 发起一次测试调用，检查返回结果中是否包含当前版本关联的UAT用例、验收问题单数据。
- 模拟版本更新触发同步，检查数据源是否自动拉取了最新的验收报告和签字确认单数据。
- 切换不同角色账号发起调用，确认权限校验配置生效，非授权角色无法访问敏感的客户业务数据。
