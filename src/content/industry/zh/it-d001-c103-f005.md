# 美术资产生产管理的代码与变更评审辅助：多轮对话与提示词

## 这个品类的数据长什么样
该品类的数据主要来自美术资产库、项目管理系统、引擎资源包与外包交付包。日常流转的文档包含美术需求单、资产规格表、外包反馈表与验收记录。文档字段包含角色编号、场景尺寸、纹理分辨率、返修项、验收评分等，部分文档附带单位，如像素、面数、帧率。数据更新频率为每日或每周，随资产制作、外包交付与项目验收节奏变动。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
数据来源分散的特点要求多轮对话需整合跨系统的上下文，避免评审时遗漏项目管理系统的规格要求或外包反馈的返修内容。文档字段与单位的多样性要求提示词需明确适配不同文档的格式，防止因字段不匹配导致评审错误。数据更新频率的波动要求提示词需定期同步最新的资产规格，确保评审依据的时效性。同时，出错后果关联资源不匹配与性能超标，要求多轮对话需自动校验字段一致性，提前拦截不符合规格的资产变更。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `messages` | 保留前20条对话上下文 | 美术资产评审的上下文多为规格、返修记录，20轮足够覆盖单次评审周期 |
| `variables` | 绑定美术资产库、项目管理系统的权限变量 | 自动拉取指定账号下的应用关联数据，减少手动录入的误差 |
| `chatId` | 关联项目ID生成唯一会话ID | 确保同项目的评审对话上下文互不干扰，避免跨项目数据混淆 |
| 最大上下文长度 | 8000–12000 字符 | 适配美术资产文档的长文本内容，避免截断关键的规格参数 |
| 图片识别开关 | 按实测标定 | 需匹配多模态模型能力，适配引擎导出的资产预览图格式 |
| 引用文件展示 | 关闭 | 符合FastGPT v4.17.0版本的配置逻辑，适配简洁评审场景 |

## 容易做错的三处
- 现象：上传资产预览图后，模型回复无法提供图片内容。原因：未在多模态模型配置中开启图片识别权限，或提示词未声明支持图片输入解析。
- 现象：对话回复末尾自动附带引用文件列表，无法关闭。原因：未在对话节点配置中关闭引用文件展示开关，或提示词未明确要求隐藏引用内容。
- 现象：无法获取指定账号下指定应用的提示词内容。原因：未配置`variables`绑定目标账号的权限参数，或会话ID未关联对应应用的授权信息。

## 怎么确认配好了
- 上传一张引擎导出的资产预览图，发起测试对话，查看模型是否能正确解析图片内容并生成对应评审建议。
- 配置`variables`绑定测试账号的目标应用，发起「获取当前应用提示词」的查询，查看是否能正常拉取到对应内容。
- 发起包含美术需求单字段的测试对话，查看回复末尾是否无额外引用文件列表，确认展示开关已关闭。
- 切换不同项目ID生成`chatId`，发起两次独立的评审对话，验证两次会话的上下文互不干扰。
