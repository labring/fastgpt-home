# 美术资产生产管理的代码与变更评审辅助：工作流编排

## 这个品类的数据长什么样
美术资产生产管理场景的数据主要来自美术资产库、项目管理系统、引擎资源及外包交付包。日常维护的文档包含美术需求单、资产规格表、外包反馈表与验收记录。数据更新频率通常为日度或周度，字段涵盖资产唯一标识、规格参数（如面数、分辨率）、交付时间、验收状态等，部分资产附带二进制文件或资源包。

## 这些特征在「工作流编排」这一环带来什么约束
多源数据的接入要求工作流支持跨系统的`variables`提取，避免重复录入或格式不一致。不同文档的字段差异要求工作流配置分层的参数映射规则，适配需求单、规格表等不同文档的结构。日/周级的更新节奏要求工作流触发时机匹配数据同步周期，避免评审滞后。资产文件的二进制特性要求工作流预留文件校验与存储环节，防止资源不匹配或性能超标问题。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `variables` | 按美术需求单、资产规格字段映射 | 匹配日常文档的字段结构，提取评审所需核心参数 |
| `nodeId` | 按资产类型分组配置 | 区分角色、场景、特效资产的独立评审流程 |
| 超时阈值 | 600秒 | 适配外包交付包的常规处理周期 |
| 触发频率 | 每日凌晨1点 | 匹配数据日更的更新节奏 |
| 单次处理资产数 | 不超过50个 | 避免引擎导入时的性能超标 |
| 文件存储上限 | 1000 MB | 适配美术资产包的常规大小 |

## 容易做错的三处
- 现象：工作流上传美术资产交付包时出现Failed to create post presigned url报错。原因：未正确配置`variables`中的文件存储路径参数，导致签名生成失败。
- 现象：工作流节点仅使用当前节点上下文，无法提取跨节点的资产规格数据。原因：未开启节点上下文继承配置，导致全局数据无法被调用。
- 现象：调用工作流API时图片参数无法正确传递，接口返回参数缺失错误。原因：未按要求以multipart/form-data格式封装图片字段，导致参数解析失败。

## 怎么确认配好了
- 查看工作流的`variables`配置，确认已映射美术需求单、资产规格的对应字段。
- 查看`nodeId`配置，确认已按角色、场景、特效等资产类型分组。
- 触发一次测试工作流，检查是否生成符合资产类型的评审节点。
- 调用工作流API，验证图片参数可正常上传并完成解析。
