# 落地页转化优化的代码与变更评审辅助：引用来源与溯源

## 这个品类的数据长什么样
落地页转化优化的核心数据来源包括落地页访问日志、热力图、表单数据、广告来源参数。日常产出的文档包含落地页方案、埋点需求文档、AB测试报告、表单字段清单。数据更新频率以周为单位或随单次营销活动调整，字段涵盖页面路径、停留时长、表单提交率、广告渠道标识等，不同文档的字段维度存在差异，部分文档需关联多类数据交叉验证。

## 这些特征在「引用来源与溯源」这一环带来什么约束
落地页转化优化的数据来源分散且维度多样，要求引用来源与溯源环节需精准匹配不同类型的数据源文档，避免召回无关内容。文档更新频率不固定，部分随营销活动临时生成，需确保检索上下文与当前活动的最新文档对齐。文档字段存在差异化，部分字段为专属标识，需在检索时针对性匹配关键词。若溯源环节出错，将导致线索无法归因、广告成本无法精准核算，影响后续优化决策。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `quoteMaxToken` | `800–1200 token` | 适配落地页方案、AB测试报告等文档的平均长度，避免截断关键的页面路径或表单字段信息 |
| 相似度阈值 | `0.75–0.85` | 匹配落地页专属的页面路径、广告渠道标识等精准内容，过滤无关的通用业务文档 |
| 单次搜索上限 | `前6条` | 落地页优化的关联文档数量通常有限，过多召回会增加上下文冗余，降低检索效率 |
| 重排 | 开启 | 落地页数据包含多维度指标，重排可优化片段排序，提升与检索需求的匹配度 |
| `responseData` | `仅返回引用片段` | 聚焦落地页的具体文档片段，避免返回全量冗余内容，便于快速溯源 |
| `detail` | `开启` | 展示引用片段的完整来源路径与文档元数据，满足落地页优化的归因需求 |

## 容易做错的三处
- 开启重排功能后出现引用片段为空的现象，原因是重排的过滤阈值设置过高，过滤掉了符合基础相似度要求的落地页相关片段。
- `quoteMaxToken`设置值过小，导致引用片段被截断，现象是返回的引用来源仅显示部分内容，无法完整展示落地页方案的关键信息。
- 导出工作流并导入新环境后，引用的知识库插件无法正常加载，原因是未同步绑定知识库的关联配置，仅导出工作流文件未携带数据源的绑定信息。

## 怎么确认配好了
- 上传一份测试用的落地页方案文档，发起包含“落地页路径”“表单字段”关键词的检索，核对返回的引用片段是否匹配文档中的对应内容。
- 调整相似度阈值，观察引用片段的召回数量变化，确认阈值设置符合当前业务的匹配精度要求。
- 导出工作流文件后导入FastGPT v4.17.0的新环境，检查引用的知识库数据源是否正常显示，无缺失提示。
- 查看`responseData`返回结果，确认仅包含预期的引用来源片段，无额外的非关联内容。
