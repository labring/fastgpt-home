# 语音标注与转写的代码与变更评审辅助：工具调用与插件

## 这个品类的数据长什么样
语音标注与转写品类的核心数据来自音频文件、标注平台导出的标注结果、专有词表、抽检样本等。日常产出的文档包含转写规范、音频交付清单、质检报告、说话人标注表等。数据更新频率多为日更或按交付批次更新。该品类的核心环节耗时集中在噪声片段判断、说话人区分、专有词校对环节，出错会引发识别训练偏差、转写返工或交付延期。与文本标注品类不同，需先将音频内容转换为结构化文本后开展后续标注工作。

## 这些特征在「工具调用与插件」这一环带来什么约束
音频转写的原始数据体量较大，且需结合专有词表校验，工具调用需适配批量音频处理的上下文需求。按交付批次更新的数据要求工具调用支持按批次触发任务，避免重复处理已标注内容。噪声片段判断、说话人区分等耗时环节，需工具调用能合理分配计算资源，避免单次请求超时。结构化文本的输出格式需与标注平台的字段对齐，工具返回结果需包含准确的说话人标识、专有词匹配项等信息，确保后续标注流程可直接复用。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配语音标注中多变的专有词校验、说话人区分场景，自动选择合适的工具执行任务 |
| 工具调用超时阈值 | 600 秒 | 匹配噪声片段判断、说话人区分等耗时环节的平均处理时长，避免请求中断 |
| 单次请求最大音频数量 | 10 条 | 适配按批次交付的音频清单规模，平衡请求负载与处理效率 |
| 单次请求最大内容量 | 800–1200 字符 | 适配单条音频转写后的文本长度，避免超出系统处理上限 |
| `functionCall` | 启用强制格式校验 | 确保工具返回的结构化文本符合标注平台的字段要求，减少后续校验成本 |

本配置适用于FastGPT v4.17.0版本。

## 容易做错的三处
- 现象：直接调用模型API响应快速，但在FastGPT中配置工具调用后响应延迟明显。原因：未根据语音标注的耗时环节调整超时阈值，或未合理设置单次请求的内容量，导致系统资源分配不足。
- 现象：工具调用返回结果缺失说话人标识或专有词匹配项。原因：未启用`functionCall`的强制格式校验，未对齐标注平台的字段要求。
- 现象：工具调用与知识库搜索无法联动，无法调用专有词表完成校对。原因：未将知识库中的专有词表正确绑定至工具调用流程，导致工具无法获取校验所需的词库数据。

## 怎么确认配好了
- 上传单条带专有词的音频文件，触发工具调用，检查返回结果是否包含准确的说话人标识与专有词匹配项。
- 查看工具调用日志，确认单次请求的耗时未超过预设的600秒阈值。
- 测试按交付批次触发工具调用，检查是否仅处理未标注的音频文件，无重复调用情况。
- 对比工具返回的结构化文本与说话人标注表的格式，确认字段对齐一致。
