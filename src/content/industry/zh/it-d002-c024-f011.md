# 信息流广告创意测试的发布说明与运营报告汇总：数据库与运维

## 这个品类的数据长什么样
这个品类的数据主要来自广告投放平台、素材库、用户互动与转化统计系统。日常产出的文档包含创意脚本、素材测试表、投放数据报告与迭代清单。数据更新频率以日度或周度为主，单条数据包含创意标识、素材类型、投放时段、点击率、转化成本、测试周期等字段，单位涵盖次、元、小时、天等，不同测试批次的数据会按创意分组归集。

## 这些特征在「数据库与运维」这一环带来什么约束
数据来源分散于多个系统，需配置多数据库连接适配不同的结构化与非结构化数据格式。按日度或周度的更新频率，要求数据库连接需支持稳定的批量拉取机制，避免频繁建立连接占用服务器资源。创意测试的多批次数据按创意分组归集的需求，要求数据库需支持按创意标识、测试周期的多维度索引，提升跨批次数据的查询效率。投放数据与素材测试数据的关联分析需求，需保证跨表关联的一致性，同时需预留字段扩展空间以适配新增的创意变量维度。数据异常会直接影响投放效果判断，因此数据库运维需保障数据同步的稳定性与查询的及时性，避免因数据延迟或错误导致测试结论偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:27017/fastgpt_ad_creative` | 适配信息流广告创意测试的非结构化测试数据存储，按业务数据量匹配数据库实例规格 |
| `PG_URL` | `postgresql://user:pass@host:5432/ad_creative_db?sslmode=require` | 用于存储结构化的素材测试表、投放数据报告，支持多维度索引查询 |
| `DB_MAX_LINK` | `20–30 个连接` | 适配日度批量数据拉取的并发需求，避免连接数过高占用服务器资源 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 缓存高频查询的创意测试指标，降低数据库直接查询压力 |
| 数据库连接超时时间 | `30 秒` | 适配广告平台接口的响应延迟范围，避免因超时导致数据拉取中断 |

## 容易做错的三处
- 调用数据库工具时无任何输出，界面返回连接超时状态码504。原因是未配置`MONGODB_URI`的访问权限，导致FastGPT无法与广告平台数据源建立连接。
- 传入变量执行SQL语句时报错，手动执行相同SQL无异常。原因是未对变量中的特殊字符做转义处理，破坏了SQL语法结构。
- 容器部署的FastGPT无法调用数据库工具。原因是容器未映射数据库端口，且未配置跨容器网络连通策略，无法与数据库实例建立连接。

## 怎么确认配好了
- 登录FastGPT v4.17.0的后台数据库配置页面，验证`MONGODB_URI`、`PG_URL`的连接状态显示为正常。
- 新建测试工作流，传入包含特殊字符的变量执行SQL查询，确认返回结果与手动执行一致。
- 查看FastGPT容器的运行日志，确认无数据库连接失败、超时的报错信息。
- 模拟日度数据拉取任务，确认数据库能正常批量拉取广告平台的测试数据。
