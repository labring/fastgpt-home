# 售前技术方案的发布说明与运营报告汇总：定时任务与自动化

## 这个品类的数据长什么样
售前技术方案相关数据主要来源于客户访谈、招标文件、厂商产品资料及历史项目方案。日常产出的文档包含技术方案书、客户需求调研表、报价清单、演示脚本四类，字段通常包含方案版本号、发布时间、客户标识、技术路线、报价明细、演示脚本版本等。与投标文件编制类文档不同，该品类文档核心聚焦技术路线与实施边界的明确。数据更新频率为每单或每周，单次处理的文档体量随项目规模有所差异。

## 这些特征在「定时任务与自动化」这一环带来什么约束
由于数据来源分散且需适配多类文档格式，定时任务需支持多源数据拉取与格式兼容处理。数据更新频率为每单或每周，意味着任务触发周期不宜过于频繁，需匹配项目推进节奏。同时，售前技术方案的出错会直接影响投标结果，因此任务需配置失败告警与重试机制，避免因临时异常导致方案发布延误或数据错误。此外，不同项目的文档结构差异较大，自动化流程需支持灵活配置字段提取规则，适配不同场景的汇总需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 任务触发周期 | 每 12 小时 或 每周一 0 点 | 匹配售前技术方案每单或每周的更新频率 |
| 多源数据拉取范围 | 客户访谈纪要、招标文件附件、厂商产品资料 | 覆盖该品类的核心数据来源 |
| 支持的文档格式 | .docx、.pdf、.md | 适配日常产出的四类文档类型 |
| 失败重试次数 | 3 次 | 避免临时网络波动导致任务失败 |
| 任务执行超时时间 | 1800 秒 | 覆盖大型方案文档的处理时长 |
| 告警触发阈值 | 连续 2 次执行失败 | 及时感知严重异常，避免影响项目进度 |

## 容易做错的三处
- 现象：界面弹出“无法使用浏览器自动复制，请手动复制下面内容”的提示，原因：未配置跨域访问权限，导致自动化生成的发布内容无法调用浏览器原生复制接口。
- 现象：自动生成的需求文档未匹配指定的产品信息字段，原因：未在任务配置中绑定对应厂商产品资料的数据源，导致提取字段不完整。
- 现象：定时任务执行后未生成运营报告文件，原因：未设置任务执行成功后的输出路径，导致结果文件未落地存储。

## 怎么确认配好了
- 手动触发一次定时任务，检查是否生成符合格式的发布说明与运营报告文件。
- 查看 FastGPT v4.17.0 的任务日志，确认多源数据拉取、文档处理、结果输出各环节无报错。
- 模拟一次配置的复制或pdf下载流程，确认功能可正常触发。
- 等待预设的任务触发周期，确认任务按计划自动执行并生成对应文件。
