# 图像标注项目的发布说明与运营报告汇总：定时任务与自动化

## 这个品类的数据长什么样
图像标注项目的核心数据包含标注规范文档、框选样例图集、质检报告、返工清单四类日常文档，数据来源为待标注图片样本、内部标注平台、目标类别字典及抽检结果。不同于文本标注项目，本品类数据聚焦视觉目标的位置坐标与类别标签，更新节奏以日度或单批次标注任务完成节点为准，单批次数据包含单组图片的标注坐标、类别标签、质检评分及返工要求字段，按标注项与批次维度归档，无固定统一单位。

## 这些特征在「定时任务与自动化」这一环带来什么约束
图像标注项目的多源混合数据结构，要求定时任务需同时对接标注平台API与本地文件存储，拉取图片标注结果与质检文档。按日度或单批次触发的更新节奏，需限制任务单次执行的批次范围，避免单次拉取数据量过载。同时，标注数据包含结构化字段与图片附件，自动化汇总环节需区分结构化报表与非结构化附件的处理逻辑，防止任务因附件解析失败中断。此外，标注数据的隐私性要求任务执行过程中需对图片样本做脱敏处理，避免敏感数据泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 任务触发周期 | 日度 / 单批次标注完成后1小时内 | 匹配标注项目日度更新或单批次交付的节奏，避免延迟汇总运营数据 |
| 单次拉取数据上限 | 前200条标注记录 | 适配标注平台接口单次返回限制，防止超时或数据截断 |
| 报告生成格式 | Markdown + 附件打包 | 匹配标注团队日常查阅的文档习惯，便于嵌入团队共享空间 |
| 失败重试次数 | 3次，间隔600秒 | 应对标注平台临时接口波动，避免因单次异常终止任务 |
| 自定义API请求头处理 | 关闭自动追加Bearer令牌 | 适配标注平台的鉴权规则，避免接口鉴权失败 |

## 容易做错的三处
- 现象：调用标注平台API时自动携带Bearer令牌，导致接口鉴权失败。原因：未在配置中关闭自动追加请求头的开关，默认将Bearer令牌附加到自定义API请求中。
- 现象：定时任务执行后报告中缺少返工清单数据。原因：未将返工清单的存储路径加入任务拉取的文件列表，仅拉取了标注记录数据。
- 现象：任务执行超时被终止。原因：单次拉取数据上限设置过高，超出FastGPT v4.17.0的单任务数据处理阈值。

## 怎么确认配好了
- 手动触发一次定时任务，检查生成的报告是否包含标注规范、质检报告、返工清单三类文档
- 查看任务日志，确认拉取的标注记录条数与预设的单次拉取数据上限一致
- 验证自定义API请求未自动携带Bearer令牌，确保接口鉴权正常
- 等待一个触发周期后，检查报告是否按时生成并推送到指定位置
