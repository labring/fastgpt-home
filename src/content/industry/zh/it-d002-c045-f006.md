# 安全培训与钓鱼演练的发布说明与运营报告汇总：定时任务与自动化

## 这个品类的数据长什么样
该品类的核心数据来自员工通讯录、企业邮件网关、内部培训平台及钓鱼演练点击统计系统，部分考核得分数据来自培训平台的在线答题模块。日常产出的文档包含标准化培训课件、单次演练方案、钓鱼邮件模板与最终演练结果报告。数据更新节奏通常为季度或年度，部分高频临时演练场景可按需调整更新频率。数据字段包含演练人群范围、邮件发送记录、点击行为数据、培训考核得分等，无统一固定单位，需结合单次演练场景匹配对应维度。

## 这些特征在「定时任务与自动化」这一环带来什么约束
该品类的数据来源分散且类型多样，要求定时任务需适配多系统接口对接与权限校验，避免跨数据源同步时的权限校验冲突。日常文档格式不统一，自动化流程需预设多类文档的解析与归档规则，确保演练材料与结果报告的分类存储符合内训与审计要求。数据更新节奏灵活，定时任务的触发周期需支持自定义调整，适配季度常规演练与临时应急演练的不同需求。全量数据汇总为复盘核心，自动化任务需保障数据源拉取的完整性，否则将引发审计缺项或整改无证据的风险。

## 配置怎么定
本配置基于FastGPT v4.17.0版本的定时任务模块，具体参数设置如下：
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| 定时触发周期 | 按演练计划设定，支持`1 天`、`7 天`、`30 天`或自定义周期 | 适配季度/年度常规演练与临时场景的灵活调度 |
| 数据源拉取范围 | 勾选员工通讯录、邮件网关、点击统计三个核心数据源 | 覆盖演练人群、发送记录与行为数据的完整采集 |
| 结果报告归档路径 | 固定至企业安全运营专属目录 | 满足审计时的快速检索需求 |
| 失败重试次数 | `3 次`，重试间隔`60 秒` | 应对临时网络波动或接口超时导致的任务中断 |
| 异常告警触发阈值 | 任务失败率超过`10%`时触发告警 | 及时定位批量数据拉取异常问题 |
| 文档自动分类规则 | 按演练类型匹配对应文件夹 | 区分培训课件、演练方案与结果报告的存储逻辑 |

## 容易做错的三处
- 现象：定时任务执行后，分类调用次数统计字段为空。原因：未勾选员工通讯录数据源，导致分类人群范围未同步，无法统计对应分类的调用数据。
- 现象：定时生成的运营报告中出现文档内容冲突的字段。原因：未配置文档去重与冲突校验规则，导致多份演练材料的同一字段出现不一致内容。
- 现象：企业微信外部群主动发送消息失败，返回状态码403。原因：未配置外部群会话权限，或定时任务的机器人账号未加入目标外部群。

## 怎么确认配好了
- 查看定时任务的触发日志，确认所有配置的数据源均成功拉取数据。
- 手动触发一次任务，检查生成的结果报告是否按预设路径归档并分类存储。
- 模拟一次数据源接口异常，验证任务是否按配置触发重试与告警。
- 核对单次演练的统计数据，确认分类调用次数、点击数据等字段与实际采集结果一致。
