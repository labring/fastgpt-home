# 安全培训与钓鱼演练的发布说明与运营报告汇总：工作流编排

## 这个品类的数据长什么样
该品类的数据来源包括员工通讯录、邮件网关、内部培训平台与点击统计工具。日常产出的文档包含培训课件、钓鱼演练方案、邮件模板与演练结果报告。数据更新节奏通常为季度或年度。数据字段涵盖演练人群标识、邮件发送时间、点击行为记录、培训完成进度与复盘结论，无固定统计单位，随单次演练的具体场景调整。

## 这些特征在「工作流编排」这一环带来什么约束
数据来源分散，工作流需配置跨源数据拉取节点对接员工通讯录、邮件网关等系统，确保演练人群与点击数据的完整获取。更新频率较低，工作流可设置按周期触发，无需高频运行，适配季度或年度的演练计划节奏。文档类型多样，工作流需支持多格式文件处理节点，适配培训课件、邮件模板与演练报告的上传、流转与归档。演练人群筛选环节耗时，工作流需嵌入预设人群分组节点，减少手动操作步骤，提升配置效率。复盘环节依赖全量数据汇总，需配置结果整合节点确保数据字段完整，支撑最终的运营报告生成。不同于安全基线检查，该品类针对人员安全意识与行为，工作流需侧重人群与行为数据的整合，聚焦人员相关的演练数据与结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `variables` | 包含员工ID、演练批次号、邮件模板路径 | 匹配演练数据的核心字段，支撑人群筛选与模板调用 |
| 数据库连接节点 | 按实测标定端口号配置 | 对接员工通讯录与培训平台数据库，确保数据拉取正常 |
| 文件上传节点 | 支持PDF、TXT、HTML格式，上限1000 MB | 适配培训课件、邮件模板的上传与流转需求 |
| 工具调用限流 | 按实测标定请求间隔，设置600秒内最多10次调用 | 避免触发qwen3.5-plus模型的调用频率限制 |
| `nodeId` | 绑定邮件发送节点与统计节点的关联ID | 确保工作流中数据流转的链路准确，避免数据错位 |
| 工作流触发方式 | 按周期触发，每季度执行一次 | 匹配该品类季度或年度的更新频率 |

## 容易做错的三处
- 数据库连接节点无法输入端口号，原因是未在FastGPT v4.17.0版本中开启高级配置开关。
- 工作流运行时无法上传测试图片，原因是未配置文件上传节点的允许格式与大小上限，未开启文件上传功能。
- 工具调用节点频繁返回429 Request rate increased too quickly报错，原因是未设置合理的请求限流配置，调用频率超出模型的限制阈值。

## 怎么确认配好了
- 执行一次测试工作流，查看数据库节点是否能正常拉取员工通讯录数据，确认字段完整。
- 上传测试格式的文件，确认文件上传节点能正常接收并流转文件，无格式或大小报错。
- 触发一次工具调用，查看返回结果是否符合预期，无429类报错。
- 检查`variables`与`nodeId`的配置是否与工作流节点的实际ID、变量名匹配，确保数据流转链路正确。
