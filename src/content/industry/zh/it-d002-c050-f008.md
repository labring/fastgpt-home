# 客户开通与租户初始化的发布说明与运营报告汇总：工作流编排

## 这个品类的数据长什么样
该品类的数据主要来源于CRM系统、合同订单库、身份管理系统及产品后台。日常关联文档包括开通申请单、租户配置表、管理员账号清单、交付确认单，数据更新以每单或每日为节奏。数据字段涵盖客户基础信息、权限范围、初始配置参数、账号清单等，无统一固定的统计口径，需随单次开通业务动态生成与更新。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的数据来源分散且更新节奏随单次业务变动，要求工作流编排需支持多数据源的动态拉取与字段映射，避免硬编码固定参数。日常文档的字段结构随客户需求灵活调整，需通过`variables`配置实现字段的动态绑定。最耗时的人工核对环节需嵌入自动校验节点，减少手动干预。出错后果直接影响客户交付，需配置异常捕获与通知节点，确保问题及时触达责任人。同时，与客户数据导入迁移的差异要求工作流优先执行账号创建与基础权限配置，再同步后续业务数据。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `variables` | 绑定开通申请单、租户配置表的字段映射 | 匹配品类数据的文档结构，实现业务字段自动流转 |
| 节点触发条件 | 按CRM订单状态变更触发 | 对应数据来源的更新节奏，确保流程随业务推进自动启动 |
| `nodeId` | 绑定身份系统账号创建节点ID | 精准定位租户初始化核心环节，便于后续异常排查与日志追溯 |
| 超时重试次数 | 3次 | 应对多系统接口调用的不稳定场景，平衡流程效率与成功率 |
| 重试间隔 | 10秒 | 适配身份管理系统的接口限流规则，避免频繁触发限制 |
| 单次批量创建账号数 | 前5条 | 适配身份管理系统的单次创建上限，避免接口超限 |
| 异常通知渠道 | 绑定管理员账号清单的企业微信/邮箱 | 匹配品类的文档清单，确保出错时及时触达对应责任人 |

## 容易做错的三处
- 现象：工作流中的文本提取节点无法选择可用模型，下拉框无选项。原因：租户初始化时未同步模型权限配置，未通过`variables`绑定对应租户的模型权限参数。
- 现象：全局Number类型计数器变量执行更新后数值无变化，无法实现自增。原因：未在`variables`配置中开启变量可写权限，或节点触发顺序错误导致变量未被正确加载。
- 现象：调试工作流时，代码运行节点未在面板中显示。原因：未在工作流编排界面开启调试模式，或节点类型未正确关联到FastGPT内置代码运行组件。

## 怎么确认配好了
- 触发测试工作流，检查是否自动拉取CRM中的最新开通申请单数据并映射到对应`variables`字段。
- 查看租户初始化节点的执行日志，确认账号创建、权限配置环节无报错，且生成的管理员账号清单与申请单匹配。
- 模拟配置错误场景，验证异常触发时是否按规则推送通知到指定的管理员账号渠道。
- 导出当前工作流配置，检查`nodeId`参数是否与本地租户初始化节点的ID匹配，确保跨工作流导入时的兼容性。
