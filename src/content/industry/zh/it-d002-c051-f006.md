# 客户数据导入迁移的发布说明与运营报告汇总：定时任务与自动化

## 这个品类的数据长什么样
该品类的数据主要来自客户历史业务系统、CSV或Excel标准模板、数据库导出文件，以及FastGPT产品的导入日志。日常配套文档包含数据导入模板、迁移执行方案、字段映射对照表、迁移验证报告。数据更新节奏为每单或不定期，无固定周期。数据字段包含业务实体字段、导入状态标识、错误编码与提示信息，单位涵盖数据条数、文件存储容量等。

## 这些特征在「定时任务与自动化」这一环带来什么约束
数据来源的多样性要求定时任务支持多类型数据源接入配置，适配本地文件、数据库导出等不同导入路径。不同于客户开通与租户初始化的基础配置，该品类处理的是已有业务数据，因此任务需支持历史数据的批量导入与校验。更新节奏的不固定性，要求任务触发方式兼顾定时调度与手动触发两种模式，适配临时迁移需求。字段映射与脏数据清洗环节的高耗时，要求定时任务可复用预配置的映射规则与清洗策略，减少重复操作。数据出错的严重后果，要求任务内置重试机制、断点续传能力与完整日志留存，便于问题回溯与修复。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 任务触发方式 | 定时调度 + 手动触发 | 适配不定期的迁移需求，兼顾自动执行与临时调整，该配置在FastGPT v4.17.0版本中已原生支持 |
| 数据源接入类型 | 本地文件/数据库导出/API拉取 | 覆盖该品类常见的数据来源渠道，满足不同客户的导入场景 |
| 字段映射规则复用 | 保存预设映射表 | 减少重复配置，匹配高耗时的字段映射环节，提升迁移效率 |
| 任务重试次数 | 3次（间隔60秒） | 应对临时网络波动或小概率导入错误，避免单次失败直接终止任务 |
| 日志留存时长 | 30天 | 满足问题回溯与迁移验证报告生成的需求 |
| 单次导入数据上限 | 10万条 | 平衡导入效率与系统负载，按实测标定 |

## 容易做错的三处
- 现象：API请求失败: 404 - 未找到资源，原因：定时任务配置的数据源连接地址未正确匹配FastGPT导入接口路径，或目标数据库表已被删除。
- 现象：全局变量值未自动更新，原因：未在定时任务配置中开启变量同步开关，或映射规则中未绑定对应全局变量字段。
- 现象：导入后分类调用次数统计字段为空，原因：字段映射时未将调用次数字段正确关联至目标业务字段，或脏数据清洗规则过滤了该字段。

## 怎么确认配好了
- 进入FastGPT定时任务管理页面，查看已创建的客户数据导入迁移任务，确认触发方式、数据源类型与预设配置一致。
- 上传一份测试用的CSV模板，执行一次手动触发任务，查看导入日志是否生成且无报错。
- 修改预设的字段映射规则，保存后再次查看任务配置，确认映射规则已同步更新。
- 查看任务日志留存时长设置，确认已匹配预设的30天留存周期。
