# 工单受理与问题分级的发布说明与运营报告汇总：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据来源于工单系统、聊天记录、产品日志及客户合同SLA，更新频率为日级或实时。日常文档包含客户工单、问题分级表、处理记录与服务报告，核心字段包括工单唯一标识、问题分类标签、分级等级、处理状态、响应时限要求与责任团队分配信息，所有数据围绕客户反馈的问题受理与分级全流程生成。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
数据来源分散且更新节奏存在差异，要求HTTP接口支持多源数据的拉取或推送，需适配不同系统的鉴权与数据格式规范。工单与分级数据的实时性要求，决定接口需配置合理的超时阈值，避免因上游系统延迟导致流程中断。字段包含分级等级、责任团队等结构化信息，要求接口传输格式需支持基础字段校验，确保分级数据准确流转。SLA相关数据需严格匹配时限要求，接口需记录请求与响应时间，便于后续运营报告的汇总与分析。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `Authorization` | 携带应用API Key的Bearer格式 | 用于外部系统调用FastGPT接口的鉴权，符合通用HTTP接口鉴权规范 |
| `variables` | 传入工单ID、问题分级等级、责任团队等业务参数 | 用于将工单受理的核心业务数据传递至接口流程，实现数据联动 |
| `responseData` | 包含工单状态、分级结果、处理时长的结构化格式 | 用于标准化输出运营报告所需的汇总数据，便于后续统计分析 |
| `AIPROXY_API_ENDPOINT`（AI Proxy服务根地址环境变量） | `http://aiproxy:3000` 或部署后实际根地址 | 满足FastGPT v4.17.0起的必填环境变量要求，不可附加/v1或其他路径后缀，不属于单模型服务地址 |
| `AIPROXY_API_TOKEN`（AI Proxy管理员Token环境变量） | 与AI Proxy服务端配置一致的非空字符串 | 属于App/Admin服务端必填环境变量，用于服务启动校验，不可用于外部调用应用API的鉴权 |
| 请求超时时间 | 600秒 | 适配工单数据拉取的实时性要求，避免因上游系统延迟导致流程中断 |

## 容易做错的三处
- 现象：调用外部接口时提示消息接收地址校验失败，或无法正常接收工单推送数据。排查项：检查接口地址是否具备公网访问能力，或是否正确配置SSL证书校验规则。
- 现象：接口返回字段为空或格式异常，无法生成符合要求的运营报告。排查项：检查是否通过`variables`参数传递正确的业务字段，或是否按要求配置`responseData`的结构化输出格式。
- 现象：App/Admin服务启动失败，提示AI Proxy配置缺失。排查项：检查是否将AI Proxy环境变量填写至应用API请求头或工作流全局变量中，或未在App/Admin服务端部署阶段配置对应必填环境变量。

## 怎么确认配好了
- 检查App/Admin服务的启动日志，确认无AI Proxy必填环境变量缺失或格式错误的报错信息。
- 发起测试HTTP请求，传入预设的工单业务参数，验证`responseData`返回的字段是否符合运营报告所需的结构。
- 核对AI Proxy的环境变量配置，确保`AIPROXY_API_ENDPOINT`未附加额外路径后缀，且`AIPROXY_API_TOKEN`与AI Proxy服务端的配置完全一致。
- 模拟工单数据的推送或拉取动作，确认接口可正常接收并处理业务数据，无异常报错。
