# 广告素材审核的发布说明与运营报告汇总：定时任务与自动化

## 这个品类的数据长什么样
该品类的数据主要来自广告投放平台、落地页链接、商品资质文件及通用广告法合规条款，更新频率为日级或实时。日常处理的文档包含广告素材文案、落地页截图、审核人员出具的整改意见、广告主提交的修改记录。数据字段包含素材唯一标识、投放渠道类型、违规内容类型、审核状态、最后修改时间，不同来源的数据格式存在差异，部分落地页截图为非结构化图片文件，文案素材为纯文本格式。

## 这些特征在「定时任务与自动化」这一环带来什么约束
由于数据来源包含多平台接口、静态文件及规则文本，定时任务需支持跨数据源拉取，避免遗漏跨渠道素材。数据更新频率覆盖实时到日级，任务触发时机需匹配对应素材的更新节奏，实时素材可配置为事件触发，日更素材可采用定时触发。文档包含非结构化图片与纯文本，任务流程需适配两种格式的解析与校验。逐条审核的业务特性要求单次任务处理的素材数量需控制在合理区间，避免任务超时或资源过载，保障审核流程的稳定性。违规后果直接关联广告账户风险，任务失败后需触发快速告警与重试机制。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 任务触发时机 | 每15分钟（实时素材）、每日凌晨2点（日更素材） | 匹配素材的实时/日级更新频率，避免任务冗余或延迟 |
| 单次处理素材数 | 前200条 | 适配单任务的资源负载上限，避免超时或中断 |
| 超时阈值 | 600秒 | 覆盖单素材审核的平均耗时，预留临时网络波动的缓冲时间 |
| 失败重试次数 | 2次 | 覆盖临时接口波动或格式解析异常的场景，减少无效重试 |
| 告警触发条件 | 连续3次任务失败 | 及时通知相关人员处理异常，避免违规风险累积 |
| 文档格式适配 | 自动识别图片/文本格式 | 适配落地页截图与文案素材的混合处理需求 |

## 容易做错的三处
- 现象：任务执行后仅部分渠道的素材出现在审核结果中，原因：未配置跨广告平台的数据源拉取范围，仅拉取了单一渠道的素材。
- 现象：定时任务生成报告后，系统提示无法自动复制，需手动操作，原因：未在系统设置中开启自动复制权限，或浏览器拦截了页面复制请求。
- 现象：知识库导入的广告素材文案出现块丢失，原因：分割参数设置未匹配素材文案的实际长度，未预留足够的文本缓冲空间。

## 怎么确认配好了
- 手动触发一次测试任务，核对拉取的素材数量与配置的单次处理上限一致。
- 查看任务执行日志，确认无格式解析错误、超时报错或数据源连接失败记录。
- 模拟一次任务失败场景，验证告警规则是否正常触发通知。
- 触发报告生成操作，确认自动复制功能可正常完成，无需手动干预。
