# 广告账户开户审核的发布说明与运营报告汇总：上下文与 token

## 这个品类的数据长什么样
这个品类的数据主要来自广告平台后台、国家企业信用信息公示系统、客户提交的开户申请材料、行业准入规则。日常处理的文档包含开户申请单、营业执照扫描件、对应行业经营资质文件、开户审核记录。数据更新节奏为每日批量同步或随单次开户申请触发。数据字段包含主体身份标识、行业类目、资质有效期、审核节点状态等，无统一固定单位，随不同材料类型调整。

## 这些特征在「上下文与 token」这一环带来什么约束
开户审核的材料包含结构化表单与非结构化文档，不同材料的长度差异大，营业执照类文档通常较短，行业资质文件可能较长。数据更新触发无固定周期，单次处理可能包含多份跨来源材料，需将分散的审核相关信息整合为上下文。由于审核需匹配最新的行业准入规则，上下文需包含最新的规则文本，同时需避免token超限导致内容截断。部分客户提交的材料存在格式不规范情况，需在上下文整合时自动过滤无效冗余内容，避免占用过多token配额。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配开户审核所需的多份材料与规则文本整合，避免单次调用token超限 |
| `quoteMaxToken` | 1500–2000 token | 限制单份资质文件的提取token占比，防止上下文被单份长文本占用过多配额 |
| 单次召回上限 | 前3条审核记录 | 匹配日常审核的核心关联数据，减少无关信息占用上下文空间 |
| 上下文过滤阈值 | 按实测标定 | 适配不同格式的客户提交材料，自动排除无效冗余内容 |
| FastGPT版本 | FastGPT v4.17.0 | 确保参数配置与当前平台版本兼容，避免功能异常 |

## 容易做错的三处
- 配置App/Admin服务端环境变量`AIPROXY_API_ENDPOINT`（AI Proxy服务的根地址）与`AIPROXY_API_TOKEN`（匹配AI Proxy服务端配置的非空管理员Token）时填写错误，可能导致启动校验失败或接口调用失败，界面返回连接超时或401状态码。排查：检查变量配置是否与AI Proxy服务端配置一致，是否遗漏特殊字符。
- 新增审核账户时触发E11000重复键错误，提示集合wisegpt存在重复数据。原因是未配置上下文去重规则，导致重复的主体资质信息被多次写入上下文缓存。
- 导入Excel格式的批量开户记录时出现token溢出，导致任务中断。原因是未设置合理的`quoteMaxToken`参数，将过长的单条记录直接作为上下文片段，超出token配额限制。

## 怎么确认配好了
- 提交一份模拟开户申请，查看上下文预览面板中显示的材料与规则内容是否完整且无冗余。
- 输入超出`maxContext`配置上限的测试文本，确认系统会自动截断或弹出超限提示。
- 核对App/Admin服务端部署的环境变量`AIPROXY_API_ENDPOINT`（AI Proxy服务的根地址）与`AIPROXY_API_TOKEN`（匹配AI Proxy服务端配置的非空管理员Token）的配置值，确保与AI Proxy服务端配置的对应信息一致。
- 导入10000行的批量开户记录，查看分块后的token占用情况，确认无明显溢出或异常截断。
