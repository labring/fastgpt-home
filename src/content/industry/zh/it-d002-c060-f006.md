# 广告账户开户审核的发布说明与运营报告汇总：定时任务与自动化

## 这个品类的数据长什么样
该品类的数据主要来自广告平台后台、国家企业信用信息公示系统、客户提交的开户申请、营业执照、行业资质材料，以及公开的行业准入规则。业务产生的文档包含开户申请单、资质扫描件、审核记录台账等，字段涵盖主体名称、资质编号、审核状态、补正要求等。数据更新节奏以单次开户申请触发为主，部分汇总类报表按日更新。

## 这些特征在「定时任务与自动化」这一环带来什么约束
数据来源分散，需定时拉取广告平台后台的审核进度、外部公示系统的资质核验结果，对多源数据同步的稳定性有较高要求。更新节奏兼具单次触发与日度汇总，需区分不同任务的触发条件，避免重复执行或遗漏更新。日常文档包含非结构化扫描件与结构化表格，自动化处理需适配多种格式的输入输出。最耗时的资质核验环节需调用外部接口，存在超时风险，需配置合理的重试与告警机制。出错后果直接关联开户成功率与合规性，需确保任务失败后可快速追溯与补正。

## 配置怎么定
本配置基于FastGPT v4.17.0版本的功能逻辑。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 定时触发规则 | 按单次申请触发+每日23:00全量汇总 | 单次开户申请需实时同步审核进度，每日汇总生成运营报表符合业务更新频率 |
| 多源数据拉取超时时间 | 600秒 | 资质核验需调用外部公示系统接口，预留足够响应时间避免中途中断 |
| 审核记录存储阈值 | 前1000条审核记录 | 保留近期核心业务数据，避免存储资源过载 |
| 失败任务重试次数 | 3次 | 平衡接口调用成功率与资源消耗 |
| 告警触发条件 | 任务失败超过2次 | 及时通知运营人员处理异常，避免影响开户流程 |
| 文档格式适配配置 | 自动识别PDF/Word结构化字段 | 适配日常提交的资质材料格式，减少人工处理成本 |

## 容易做错的三处
- 现象：定时生成的运营报告出现超时中断，日志返回`ETIMEDOUT`状态码。原因：未设置合理的多源数据拉取超时时间，导致外部资质核验接口响应超时未被终止。
- 现象：自动化审核流程占用过多系统内存，后续任务无法正常启动。原因：未配置单任务的内存使用上限，未开启闲置资源自动释放规则。
- 现象：无法按照固定格式生成审核发布说明，文档排版混乱、字段缺失。原因：未配置基于固定Word模板的文档生成规则，未指定需填充的字段映射关系。

## 怎么确认配好了
- 手动触发单次开户申请的定时任务，核对拉取的资质数据是否与广告平台后台、国家企业信用信息公示系统的信息一致。
- 查看任务日志，确认失败任务的重试次数符合配置要求，超时任务会被自动终止。
- 生成一份日度运营报告，核对报告中的字段是否与预设的文档格式一致，未出现无关数据。
- 模拟一次资质核验接口超时的场景，确认系统会触发告警并记录失败日志。
