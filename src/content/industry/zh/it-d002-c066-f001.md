# 搜索广告关键词管理的发布说明与运营报告汇总：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据主要来自搜索广告后台、搜索词报告、竞价排名数据与落地页数据。日常产出的文档包含关键词清单、否词表、出价记录与搜索词报告，单份文件通常包含数千条带匹配类型、出价金额的条目，否词表则标注需屏蔽的搜索词类别。数据更新频率一般为每日或每周，部分实时竞价场景下会按小时同步。数据字段多为文本、数值类型，包含关键词文本、匹配模式、点击量、转化成本等核心指标，结构相对扁平。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
该品类的数据特征会对HTTP接口与外部系统集成带来多维度约束。首先，数据来源涉及多个搜索广告后台与业务系统，需通过`Authorization`参数配置多套身份验证方式，适配不同平台的鉴权规则。其次，数据更新频率覆盖日、周甚至实时场景，接口轮询间隔需支持灵活配置，避免频繁请求超出平台限流阈值。此外，单份关键词清单条目较多，接口请求体与响应体需支持分页参数，同时需校验字段长度，防止出现数据过长导致的存储报错。最后，核心指标多为数值与文本类型，接口需预设基础参数校验规则，适配不同业务场景的数据格式要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `Authorization` | `Bearer {token}` 或 `Basic {base64_credential}` | 适配多数搜索广告平台的标准鉴权格式，兼容FastGPT v4.17.0的外部接口调用规则 |
| 单次请求最大条目数 | `500–1000 条` | 匹配多数搜索广告后台的接口限流阈值，避免请求被拦截 |
| 数据更新同步间隔 | `3600 秒` 或按业务场景标定 | 适配日/周级别的数据更新频率，平衡实时性与接口调用成本 |
| `variables` | 绑定关键词清单ID、否词表路径等业务变量 | 实现接口调用时动态加载对应品类的业务数据，无需硬编码配置 |
| `responseData` 解析规则 | 按搜索词报告的字段映射配置响应字段 | 直接将接口返回数据映射为FastGPT可识别的运营报告格式，减少二次处理成本 |
| 接口超时阈值 | `60 秒` | 适配搜索广告后台的接口响应平均时长，避免长时间等待导致的调用失败 |

## 容易做错的三处
- 调用接口时返回`Error 1406 (22001): Data too long`报错，原因是未配置字段长度校验，关键词或出价记录的文本长度超出了外部系统的存储字段限制。
- 接口返回的运营报告数据条数与预期不符，原因是未设置分页参数或分页阈值配置错误，导致仅返回了部分数据。
- 接口调用频繁触发限流拦截，原因是同步间隔配置过短，超出了搜索广告后台的接口调用频率限制。

## 怎么确认配好了
- 调用测试接口，检查`Authorization`参数是否被正确携带，可通过FastGPT的接口调试日志查看请求头内容。
- 对比接口返回的`responseData`与本地存储的关键词清单，确认字段映射是否符合配置要求。
- 调整同步间隔参数，观察接口调用频率是否符合预期，可通过外部系统的后台日志查看请求次数。
- 模拟超长关键词的请求，校验接口是否触发字段长度校验，确认配置生效。
