# 文本标注项目的发布说明与运营报告汇总：数据库与运维

## 这个品类的数据长什么样
文本标注项目的数据主要来源于客户语料、标注平台产出的标注结果、自定义词表以及质检抽样结果。日常关联的文档包括标注规范、待标注样本包、质检报告和问题反馈表。数据更新节奏按日或按标注批次执行，单条数据包含文本内容、标注标签、标注人标识、质检结果、标注耗时等字段，字段与单位随具体标注任务调整，无统一固定格式。

## 这些特征在「数据库与运维」这一环带来什么约束
文本标注项目的数据特征对数据库与运维环节带来多重约束。多来源的数据需要对接客户语料、标注平台结果、词表与质检数据，要求系统兼容多种数据格式与接入方式。按日或按批次的更新节奏，需要数据库支持批量写入与增量同步，避免全量重导带来的性能损耗。多角色参与的业务流程，要求配置细粒度的数据库访问权限，区分标注员、质检员与管理员的操作范围。文本数据的语义特性，还要求存储层支持语义关联检索，同时保障标注与质检数据的一致性，防止错位引发后续问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://<user>:<pass>@<host>:27017/text_label?authSource=admin` | 存储非结构化文本、标注标签等数据，适配文本标注的灵活存储需求 |
| `PG_URL` | `postgresql://<user>:<pass>@<host>:5432/label_ops?sslmode=require` | 存储标注规范、质检报告等结构化业务数据，支持事务性操作 |
| `DB_MAX_LINK` | `20–30 个连接` | 匹配日均批量标注任务的并发连接需求，避免连接池资源耗尽 |
| `REDIS_URL` | `redis://:<pass>@<host>:6379/1` | 缓存高频调用的词表、标注规则，降低数据库查询延迟 |
| 数据库连接超时阈值 | `30 秒` | 适配多数据源对接的等待时长，防止外部数据源响应慢阻塞任务 |

## 容易做错的三处
- 现象：MongoDB 连接状态查询返回失败，日志显示认证错误。原因：未在`MONGODB_URI`中配置正确的认证源或账号密码，导致无法正常接入数据库。
- 现象：尝试配置Oracle数据库连接时无对应选项，无法完成接入。原因：FastGPT v4.17.0 当前仅支持配置`MONGODB_URI`、`PG_URL`两类数据库连接参数，未开放Oracle数据库的接入配置。
- 现象：编排流程中连接MSSQL数据库报错，提示连接超时，但本地可视化工具可正常连接。原因：FastGPT 运行环境的网络策略限制了出站端口访问，或编排流程中配置的数据库地址与本地测试地址不一致，导致无法建立连接。

## 怎么确认配好了
- 运行内置的数据库连通性测试工具，验证`MONGODB_URI`与`PG_URL`对应的数据库可正常建立连接并执行读写操作。
- 查看系统连接池监控面板，确认当前活跃数据库连接数未超出配置的最大连接限制。
- 提交一批测试标注数据，检查数据是否能按预设的更新节奏同步至对应数据库。
- 访问标注规则查询接口，确认高频访问的词表与标注规范已从缓存中读取，不直接查询数据库。
