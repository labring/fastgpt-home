# 等级保护测评咨询的发布说明与运营报告汇总：定时任务与自动化

## 这个品类的数据长什么样
等级保护测评咨询的日常数据包含定级报告、差距分析报告、整改方案、测评报告四类核心文档，数据来源覆盖测评工具输出结果、现场访谈记录、资产系统清单、安全设备运行日志。数据更新以单个测评项目为周期，单项目完成后完成全量更新，年度内跨项目数据无高频迭代。文档结构按等保标准固定字段，包含控制项编号、合规要求、差距项描述、整改措施等内容，无频繁变化的非结构化附加字段。

## 这些特征在「定时任务与自动化」这一环带来什么约束
该品类的数据更新以单项目为周期，无需高频执行自动化任务，需匹配项目节奏配置触发时机。四类核心文档结构固定但单份体积较大，单次处理过多会触发内容长度限制，需拆分处理任务。数据来源分散，需从测评工具、日志、清单等多系统提取字段，自动化流程需完成跨源数据关联。最耗时的定级材料梳理、差距核对环节需自动化替代人工，同时需严格保障数据准确性，否则会引发测评不通过、整改延期等严重后果。定时任务需支持按项目节点触发，同时可适配固定周期的批量汇总需求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 定时任务触发周期 | 按项目节点触发，或每7天一次（按实测标定） | 数据更新频率为单项目/年，避免频繁执行浪费资源，同时满足批量汇总需求 |
| 单次处理文档数量 | 10-15个每次 | 匹配知识库上传单次限制，避免触发内容长度超限报错 |
| 任务超时阈值 | 3600秒 | 单份定级报告或测评报告处理耗时较长，预留充足执行时间 |
| 失败重试次数 | 2次 | 避免重复执行占用过多资源，同时覆盖临时网络或工具调用异常 |
| 检索后模型卸载 | 开启自动卸载 | 释放重排模型占用的显存资源，避免任务间资源冲突 |
| 文档自动分类 | 按文档类型归类 | 匹配四类核心文档的固定结构，便于后续运营报告的分类汇总 |

## 容易做错的三处
- 执行定时任务时触发maxLength报错，原因是单次处理文档数量超过配置阈值，未按要求拆分任务批次。
- 检索后重排模型持续占用显存，原因是未开启检索完成后自动卸载模型的配置，导致资源无法释放。
- 运营报告生成后部分字段为空，原因是未正确配置多源数据的字段映射，未关联测评工具、日志等数据源的对应内容。

## 怎么确认配好了
- 手动触发一次测试任务，核对处理的文档数量符合配置的单次处理量要求。
- 查看任务执行日志，确认无内容长度超限、超时等报错，且生成的运营报告包含所有预设字段。
- 等待预设的定时周期，确认任务自动执行并生成对应周期的汇总文档。
- 模拟任务失败场景，确认告警通知正常触发至指定接收方。
