# 美术资产生产管理的发布说明与运营报告汇总：定时任务与自动化

## 这个品类的数据长什么样
该品类的数据主要来自美术资产库、项目管理系统、引擎资源包及外包交付包，更新频率多为日度或周度。日常关联文档包含美术需求单、资产规格表、外包反馈表与验收记录，其中资产规格表包含面数、纹理分辨率、文件格式等字段，外包反馈表记录返修次数、交付时效，验收记录标注资源匹配状态与性能指标。本页适配FastGPT v4.17.0版本。

## 这些特征在「定时任务与自动化」这一环带来什么约束
多源数据的分散存储要求定时任务支持跨系统拉取，避免手动汇总的误差。日度/周度的更新节奏需要匹配任务触发周期，避免重复拉取或遗漏更新内容。多样的文档结构与特定字段要求自动化流程预设字段校验规则，确保汇总数据的格式统一。外包交付包的非标准化格式，需要在定时任务中加入格式校验环节，防止不匹配资源进入后续流程。引擎导入检查的前置校验，可通过自动化定时扫描资产库完成，减少人工核对的耗时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 任务触发周期 | 按数据更新频率设定，可选`每日凌晨2点`或`每周一凌晨1点` | 匹配美术资产库、外包交付包的日/周更新节奏，避免重复处理或遗漏 |
| 数据源拉取范围 | 仅拉取当日/当周新增的美术资产与外包交付包 | 减少无效数据处理量，提升任务执行效率 |
| 字段校验规则 | 匹配资产规格表的面数、纹理分辨率等必填字段 | 确保汇总数据符合项目要求，规避资源不匹配风险 |
| 失败重试次数 | `3次`，重试间隔`600秒` | 应对临时网络波动或系统接口不稳定的情况，降低任务失败概率 |
| 异常告警触发阈值 | 任务失败次数达到`2次`时触发告警 | 及时通知运维人员处理异常，避免影响后续发布流程 |
| 汇总结果输出格式 | 与项目管理系统兼容的JSON或CSV格式 | 方便后续导入系统进行发布说明与运营报告的整合 |

## 容易做错的三处
-  现象：配置了指定工具调用后，仍出现AI自动回复内容，导致输出不符合预期。原因：未关闭任务中的自动AI回复开关，工具调用与自动回复逻辑未做隔离配置。
-  现象：非配置的整点时刻自动触发GPT模型调用，出现额外的API消耗。原因：未关闭全局的定时模型调用开关，或存在未被发现的隐藏定时任务配置。
-  现象：跨APP切换后触发定时任务时，仍校验前一个APP的必填全局变量，出现「缺少必填参数」报错。原因：未在任务配置中清空关联的旧APP全局变量绑定，导致任务沿用历史配置。

## 怎么确认配好了
-  手动触发一次定时任务，检查拉取的数据范围是否仅包含当日/当周新增的资产与交付包。
-  查看任务执行日志，确认字段校验环节未遗漏必填项，且异常重试逻辑正常触发。
-  导出汇总结果，核对格式与项目管理系统的导入要求是否一致。
-  模拟异常场景（如临时断开数据源连接），确认告警规则正常触发并推送通知。
