# 集成测试与接口测试的发布说明与运营报告汇总：数据库与运维

## 这个品类的数据长什么样
这个品类的数据主要来自接口管理平台、测试环境日志、数据库与消息队列，更新频率为每日或每版本发布时。日常产出的文档包括接口测试用例、联调问题单、环境说明与测试报告。接口测试用例包含接口地址、请求参数、预期响应字段；联调问题单记录异常链路节点与排查进度；测试报告包含通过率、单接口响应耗时等字段。数据按测试环境与版本维度关联存储，支撑发布说明与运营报告的汇总与复盘工作。

## 这些特征在「数据库与运维」这一环带来什么约束
该品类的数据多源且按版本、测试环境关联，要求数据库运维环节支持多源数据同步与按维度归档。每日或每版本的更新频率，需要配置定时拉取接口日志、测试报告的任务，避免数据积压。不同类型的测试文档结构差异大，需按接口测试用例、联调问题单、测试报告分表存储，降低查询复杂度。链路问题定位的高耗时需求，要求数据库索引覆盖接口地址、请求参数与响应状态字段，同时需配置数据备份与容灾策略，防止联调阻塞时数据丢失影响发布进度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://fastgpt_test:test123@192.168.1.100:27017/fastgpt_test?authSource=admin` | 存储非结构化的联调问题单与测试日志，适配多环境测试数据隔离，符合FastGPT v4.17.0版本的存储规范 |
| `PG_URL` | `postgresql://test_user:test456@192.168.1.101:5432/fastgpt_test_db?sslmode=prefer` | 存储结构化的接口测试用例与测试报告，支持复杂条件查询，适配测试数据的多维度统计 |
| `DB_MAX_LINK` | `25 连接` | 平衡测试环境的并发测试任务与数据库资源占用，避免连接溢出导致测试任务中断 |
| `REDIS_URL` | `redis://:test789@192.168.1.102:6379/1` | 缓存高频访问的接口地址与预期响应数据，缩短链路问题定位耗时 |
| 数据备份保留时长 | `30–90 天` | 覆盖完整的版本迭代周期，满足联调问题回溯与发布复盘需求 |

## 容易做错的三处
- 现象：配置`MONGODB_URI`连接Docker部署的数据库后，知识库数据未同步至测试环境，页面显示空的测试报告列表。原因：未在数据库用户权限中开放测试环境的访问权限，且未重启服务加载更新后的数据库配置。
- 现象：批量执行接口测试时出现「connection pool exhausted」报错。原因：`DB_MAX_LINK`配置值低于当前并发测试任务的连接需求，导致连接池耗尽无法新建连接。
- 现象：查询联调问题单时返回结果条数与实际不符。原因：未为接口地址、请求参数字段配置数据库索引，导致模糊查询无法准确匹配目标数据。

## 怎么确认配好了
- 执行对应数据库的连接命令，验证是否能成功登录`MONGODB_URI`或`PG_URL`配置的数据库实例，并查询到测试用例集合。
- 查看FastGPT服务的运行日志，确认没有数据库连接超时、权限拒绝或连接池耗尽的报错信息。
- 提交一次小型接口测试任务，等待任务完成后查看测试报告是否正常生成并写入对应数据库。
- 登录Redis管理工具，检查是否存在缓存的接口测试相关键值，验证`REDIS_URL`配置的缓存服务是否正常运行。
