# CDN与边缘加速配置的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
通常，该品类的数据来源包括CDN控制台、DNS解析记录、访问日志与监控告警。日常产出的文档包含域名接入单、缓存规则配置、刷新预热记录、故障分析报告，字段多涉及域名标识、缓存规则ID、刷新请求量、告警阈值等，字段无统一固定单位，多为字符串、数字类型。数据更新频率为每日或随配置变更实时更新，核心文档围绕公网内容分发的配置与合规校验展开。本文基于FastGPT v4.17.0版本编写。

## 这些特征在「模型接入与配置」这一环带来什么约束
CDN品类的数据以域名、缓存规则等配置类内容为主，且更新频率较高，要求模型接入配置需适配短平快的合规审查场景，比如快速核对域名备案、校验缓存规则合规性。数据来源分散在控制台与日志中，需配置支持对接多源数据的接口权限；文档字段多为结构化配置项，要求模型上下文长度适配单份文档的字段总量；同时，配置出错会直接影响公网访问，要求模型调用的稳定性与准确性需匹配业务可用性要求，避免因模型配置错误导致CDN服务异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `AIPROXY_API_ENDPOINT` | AI Proxy服务的根地址（如`http://aiproxy:3000`） | 为AI Proxy服务的访问地址，不可附加/v1或/chat/completions等API路径，非单模型服务地址 |
| `AIPROXY_API_TOKEN` | AI Proxy服务端配置的管理员Token，与服务端配置一致且非空 | 用于AI Proxy服务的身份验证，非模型供应商密钥或应用API Key |
| `maxContext` | 8000–12000 token | 适配CDN域名接入单、缓存规则文档的字段总量，避免上下文内容被截断 |
| `maxTokens` | 2000–3000 token | 平衡合规审查的输出长度与响应速度，满足CDN故障排查的信息需求 |
| `vision` | false | 多数CDN配置文档为文本格式，无需额外的图片识别能力 |
| `temperature` | 0.3–0.5 | 保持审查结果的严谨性，避免生成不符合合规要求的不确定内容 |

## 容易做错的三处
- 调用模型时返回“无法提供图片内容”，原因是未关闭`vision`配置项，模型误触发多模态识别逻辑，无法处理纯文本的CDN配置文档。
- 配置后出现连接超时或404报错，排查项为`AIPROXY_API_ENDPOINT`是否为AI Proxy服务的正确根地址，未附加额外API路径，且可正常访问；`AIPROXY_API_TOKEN`是否与服务端配置一致且非空
- 缓存规则审查结果出现遗漏，原因是`maxContext`取值过小，导致部分域名备案信息、缓存规则细节被截断，模型无法完整匹配合规校验要求。

## 怎么确认配好了
- 输入一条完整的CDN域名接入单文本内容，调用模型进行合规审查，检查返回结果是否包含备案核对、缓存规则匹配的相关结论。
- 查看FastGPT的模型调用日志，确认`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`的配置未触发权限错误或连接错误。
- 调整`maxContext`和`maxTokens`的取值，测试不同长度的CDN文档输入，确认输出未出现上下文截断提示。
- 关闭`vision`配置项，测试包含图片的输入场景，确认模型不会返回与图片识别相关的错误提示。
