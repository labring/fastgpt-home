# IT服务台工单处理的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源于企业ITSM系统、电话或聊天记录、资产系统与内部知识库。日常生成的文档包括服务请求单、事件工单、处理记录、用户满意度表，数据更新频率为日级或实时。单条数据包含工单编号、提交人信息、问题描述、处理状态、关联资产编号、满意度评分等字段，每条记录对应单次技术支持请求的全流程信息。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类数据来源分散且更新实时，要求模型接入配置需支持多源数据同步读取，同时适配工单及关联文档的长文本上下文特征。工单包含结构化与非结构化混合字段，配置需支持按字段维度提取关键信息以完成合规校验。实时更新的数据要求配置的上下文刷新周期匹配业务节奏，避免因数据滞后导致合规审查失效。此外，合规材料审查需确保不泄露员工与资产敏感信息，配置需包含敏感信息过滤的相关设置。

## 配置怎么定
本文档适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配工单及关联文档的长文本上下文需求，避免截断关键合规信息 |
| `maxTokens` | 2000–3000 token | 控制单轮回复长度，满足工单分类、合规审查的短平快输出要求 |
| `temperature` | 0.2–0.4 | 降低回复随机性，确保合规审查结果的一致性与准确性 |
| `toolChoice` | auto | 自动选择调用工具完成工单字段提取与合规校验，适配多步骤处理流程 |
| `AIPROXY_API_ENDPOINT` | 填写AI Proxy服务的根地址，例如 http://aiproxy:3000，不得附加 /v1 或 /chat/completions 路径 | 为App/Admin服务端必需配置的环境变量，指定AI Proxy服务访问地址 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的非空管理员Token | 为App/Admin服务端必需配置的环境变量，用于AI Proxy服务鉴权，不得使用应用API Key、模型供应商密钥等其他令牌 |

## 容易做错的三处
- 调试预览界面中选中的本地模型被自动替换为其他模型。可验证排查项：检查App/Admin服务端是否配置了`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`环境变量，且取值符合官方要求；检查模型渠道配置是否正确。
- 工单合规审查结果为空或字段提取错误。原因是`maxContext`配置值过小，截断了工单中的关键合规相关文本，导致模型无法完成完整校验。
- 模型调用超时。原因是`maxTokens`配置值过大，超出模型接口的响应阈值，导致处理时长超过业务允许范围。

## 怎么确认配好了
- 检查App/Admin服务端的环境变量配置，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的取值符合官方要求。
- 创建测试工单，触发模型处理流程，查看返回结果中是否包含工单关键字段的合规校验信息。
- 调整`maxContext`与`maxTokens`的配置值，通过多次测试确认处理结果完整且符合业务要求。
- 查看平台日志，确认无模型鉴权失败或接口调用错误的记录。
