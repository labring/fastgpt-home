# 事件响应与故障处理的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源于监控告警、日志平台、APM工具及用户反馈，更新节奏为实时或每次事件触发。日常处理的文档包含故障工单、事件时间线、应急预案、故障通报，文档字段多包含事件编号、发生时间、影响范围、处置步骤、通报对象等，无固定统一格式，随事件场景动态调整。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据来源分散且更新节奏灵活，要求模型接入环节支持多源数据的快速整合与拉取。日常文档无固定格式，需配置适配非结构化文本的解析逻辑，避免因格式差异导致内容提取失败。单次事件的处置窗口有限，需控制模型推理的耗时与输出长度，保障响应效率。故障通报涉及合规内容，需确保返回的参考材料准确且可溯源。实时更新的数据要求配置项支持动态调整上下文长度，避免超出模型处理上限。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的参数逻辑制定：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | `8000–12000 token` | 适配单次事件的多源文档整合需求，避免超出模型上下文限制 |
| `maxTokens` | `2000–3000 token` | 控制单次推理输出长度，适配故障处置的快速响应要求 |
| `quoteMaxToken` | `1500 token` | 限定参考材料的总token数，确保合规审查时的内容精准且不冗余 |
| `toolChoice` | `auto` | 自动选择是否调用工具，适配多源数据拉取的动态需求 |
| `temperature` | `0.2–0.4` | 降低输出随机性，确保合规审查结果的一致性与准确性 |
| `AIPROXY_API_ENDPOINT` | 填写AI Proxy服务的根地址，例如`http://aiproxy:3000`，不得附加`/v1`或`/chat/completions`等路径后缀，不得指向单模型服务地址 | 配置AI Proxy服务的访问根地址，为App/Admin服务端必填环境变量 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的管理员Token，不得为空 | 配置AI Proxy服务的身份验证凭证，为App/Admin服务端必填环境变量 |

## 容易做错的三处
- 现象为模型仅返回1个知识库匹配文本块，无法输出综合结果。原因是未调整关联配置，仅拉取了最高匹配度的单条内容。
- 现象为文档解析节点配置完成后，模型无法读取上传的故障工单或应急预案文件。原因是未正确配置文件存储路径的访问权限，或解析节点的触发逻辑未绑定事件上传动作。
- 现象为模型调用返回认证失败或请求url错误的报错，启动校验失败。排查项为`AIPROXY_API_TOKEN`填写错误，或`AIPROXY_API_ENDPOINT`指向非AI Proxy服务根地址或附加了非法路径后缀。

## 怎么确认配好了
- 发起模拟事件的测试请求，核对模型返回的参考材料数量是否符合预期，调整相关配置以匹配需求。
- 上传测试用的故障工单文件，验证模型是否能正确读取并关联解析后的文本内容，检查文件访问权限配置。
- 验证App/Admin服务端启动校验通过，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置符合要求。
- 调整`temperature`参数，验证输出结果的随机性是否符合合规审查的严谨性要求，按需调整取值区间。
