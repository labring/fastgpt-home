# 云主机交付与资源开通的安全与合规材料审查：权限与数据隔离

## 这个品类的数据长什么样
该品类的数据主要来自云管理平台、订单系统、IAM、计费系统，更新节奏为每单或实时。日常关联文档包含资源开通单、实例配置表、账号权限单、交付确认单，字段包含实例规格（vCPU核数、内存GB）、部署区域、IAM角色标识、计费周期、资源状态等。数据结构以单条资源交付流程为单元，每条数据绑定对应订单、权限申请与交付确认记录。

## 这些特征在「权限与数据隔离」这一环带来什么约束
多系统来源的数据要求权限校验覆盖云管理、订单、IAM、计费全链路，避免单一系统权限漏洞导致跨模块越权。实时或单条更新的特性要求隔离配置随资源创建、权限变更实时生效，无法依赖离线批量校验。多类关联文档对应不同权限边界，需为资源开通单、实例配置表、交付确认单分别配置独立访问权限，防止非授权人员修改规格或篡改交付记录。跨系统数据绑定的特性要求权限校验与资源实际状态同步，避免权限失效后仍能调用已分配资源。

## 配置怎么定
本配置基于FastGPT v4.17.0版本制定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `teamId` | 与云IAM团队ID完全匹配 | 确保FastGPT团队权限与云平台IAM权限对齐，避免跨团队资源越权 |
| `tmbId` | 绑定实例专属标识，取值范围 1000–9999 | 为每个云主机实例分配唯一隔离标识，防止不同实例间串访 |
| 资源访问白名单 | 仅包含指定运维IP段，范围 192.168.1.0/24 至 192.168.255.0/24 | 限制非授权终端访问资源配置页面，降低外部攻击风险 |
| API调用权限 | 按订单ID校验，超时时间 30 秒 | 确保API调用仅能访问对应订单关联的资源，避免无权限调用 |
| 权限变更审计 | 记录所有权限修改操作，保留时长 180 天 | 留存操作溯源依据，满足合规审查要求 |
| 团队权限组 | 按部门划分，仅开放对应品类的操作权限，单组最大成员数 50 人 | 避免跨部门权限交叉，细化不同岗位的操作边界 |

## 容易做错的三处
- 现象为调用FastGPT API返回403无权限报错，原因是未将`teamId`与云IAM团队ID绑定，导致权限校验逻辑不生效。
- 现象为不同部门成员可查看彼此的资源开通单，原因是未为不同`teamId`配置独立的权限组，跨团队权限未完全隔离。
- 现象为本地部署后无法启用团队管理功能，原因是未在配置文件中开启团队权限模块，未绑定`teamId`对应的权限校验规则。

## 怎么确认配好了
- 调用FastGPT API时传入`teamId`参数，验证返回结果仅包含对应团队的云主机资源列表。
- 尝试使用非授权IP访问资源配置页面，确认页面返回权限不足提示或无法加载内容。
- 删除团队成员后，检查云IAM系统中该成员的权限是否同步移除，验证其无法再访问对应云主机资源。
- 在本地部署环境中开启团队管理配置，验证新增团队后可正常绑定`teamId`参数。
