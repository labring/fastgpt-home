# 云资源合规审计的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
本品类的数据主要来自云审计日志、IAM权限系统、CMDB资源清单、安全基线扫描结果。日常产出的文档包括合规检查表、权限审计报告、资源清单、整改跟踪表，文档字段包含资源ID、权限配置项、合规状态、整改责任人等。数据更新频率为月或季度，单次批量数据规模较大，需覆盖全量云资源的权限与配置信息。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类的多源结构化与半结构化数据混合、单次批量规模大的特征，要求模型接入时需适配大上下文窗口需求，避免截断合规检查表、权限审计报告中的关键字段。低更新频率但全量数据覆盖的特点，要求配置参数时需平衡上下文长度与推理效率，避免因上下文超限导致关键合规证据丢失。专业合规字段的准确识别需求，要求模型推理参数需适配专业场景，同时需匹配数据规模调整检索与上下文传递的token阈值，避免因参数配置不当导致检索结果无法被模型有效利用。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配本品类全量合规文档、权限审计报告的批量数据规模，避免截断关键合规字段 |
| `maxTokens` | 2000–3000 token | 满足合规审查场景下模型输出整改建议、异常判定结论的长度需求 |
| `quoteMaxToken` | 5000–8000 token | 匹配本品类检索到的资源清单、权限日志等单条检索结果的长度，确保检索内容可被完整纳入上下文 |
| `temperature` | 0.1–0.3 | 适配合规审查的严谨性需求，降低模型输出的随机性，确保判定结果稳定一致 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions路径，不得填写单模型服务地址 | 作为App/Admin服务端环境变量，指定AI Proxy服务的访问地址，确保模型调用通过AI Proxy转发 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的非空管理员Token | 作为App/Admin服务端环境变量，用于与AI Proxy服务端进行身份校验，保障调用安全 |

## 容易做错的三处
- 现象：知识库检索返回多条结果，但模型输出未找到相关答案。原因：`quoteMaxToken`设置不当，导致检索到的合规文档片段无法被完整纳入模型上下文，或超出`maxContext`设置的窗口被截断。
- 现象：模型推理耗时超出预设阈值。原因：`maxContext`设置超出模型实际支持的上限，或`quoteMaxToken`未匹配检索结果规模，导致模型需处理过量上下文数据。
- 现象：Basic Auth API接入的模型无法正常调用。原因：上游模型渠道的Basic Auth身份验证配置不当，或模型渠道地址配置错误，导致身份校验失败。

## 怎么确认配好了
- 查看FastGPT v4.17.0的模型调用日志，确认每次调用传入的上下文token数未超出`maxContext`的设置范围，且检索引用的token数符合`quoteMaxToken`的配置。
- 提交一份已知包含合规异常的测试数据，验证模型输出的判定结果与检索到的文档内容匹配，且输出无明显随机偏差。
- 测试Basic Auth API模型的接入链路，确认调用时可正常返回身份验证通过的响应，无401或403类报错。
- 调整`temperature`参数至0.2，多次提交相同测试问题，验证模型输出结果的一致性。
