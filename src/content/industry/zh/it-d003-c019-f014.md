# 众包标注人员管理的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自众包平台后台、标注质量统计报表、人员培训考试记录、财务结算系统。日常处理的文档包含人员准入规则、岗位培训材料、月度绩效表、季度结算清单。数据更新节奏分为日更与月更，日更数据包含当日标注完成量、质检结果，月更数据包含人员绩效排名、月度结算明细。数据字段包含人员唯一标识、准入审核状态、培训考核得分、当日任务完成数、结算金额等，无统一固定单位，随文档类型变化。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据来源分散，涉及众包平台、质检系统、培训记录与财务系统，要求模型接入环节需支持多源数据对接，配置适配不同接口格式的调用规则。数据更新节奏存在日更与月更差异，需模型支持动态加载最新数据，同时需调整上下文长度参数，适配不同周期的文档处理需求。日常处理的文档类型多样，包含规则文本、考核答卷、绩效报表与结算清单，需模型适配不同文本结构，同时需限制上下文token数量避免处理溢出。涉及人员与财务敏感信息，需额外配置安全校验参数，防止敏感数据泄露。

## 配置怎么定
本文档基于FastGPT v4.17.0版本编写。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配包含人员准入规则、绩效表的多文档批量处理，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 用于生成人员绩效分析、结算核对结果，平衡输出长度与处理速度 |
| `temperature` | 0.2–0.4 | 保障合规审查结果的一致性，避免审核标准出现不必要波动 |
| `toolChoice` | auto | 自动选择合适的工具处理多源数据查询与格式转换，适配不同文档类型 |
| `AIPROXY_API_ENDPOINT` | AI Proxy 服务的根地址，例如 http://aiproxy:3000（不得附加 /v1 或 /chat/completions，非单模型地址） | 为 App/Admin 服务端配置的 AI Proxy 服务根地址，确保接口连通性 |
| `AIPROXY_API_TOKEN` | 与 AI Proxy 服务端配置一致的管理员 Token，不能为空 | 保障 AI Proxy 接口调用的安全性，防止未授权访问，不得使用应用 API Key、模型供应商密钥等替代 |

## 容易做错的三处
- 调用接口返回“使用了错误的API Key”提示。排查项：是否混淆了 AI Proxy 管理员 Token 与应用 API Key、模型供应商密钥等，未使用正确的 AI Proxy 管理员 Token 配置服务端环境变量。
- 模型运行时间显示异常，在线模型仅显示首token耗时，离线模型显示总耗时。原因是未统一配置模型调用的时间统计规则，不同部署环境的统计逻辑存在差异。
- 批量处理结算清单时出现结果截断。原因是未合理设置`maxTokens`参数，导致超出限制的输出内容被自动截断，无法完整生成结算核对结果。

## 怎么确认配好了
- 调用测试接口传入单份人员准入规则文档，检查返回结果是否包含合规审核结论，核对返回内容与输入文档的关联度。
- 查看 App/Admin 服务端启动日志或环境变量配置，确认`AIPROXY_API_TOKEN`与`AIPROXY_API_ENDPOINT`的配置值与部署环境一致，无空值或错误字符（该变量为服务端环境变量，不得配置在工作流全局变量、应用 API 请求头等位置）。
- 批量传入不同更新周期的文档（日更任务数据与月更结算清单），检查模型是否能正常加载并处理不同长度的上下文。
- 模拟包含人员身份与财务金额的测试数据，检查模型是否触发安全校验逻辑，无敏感数据泄露风险。
