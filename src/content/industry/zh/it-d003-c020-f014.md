# 供应商与设备到货管理的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据通常来自ERP系统、供应商发货单、物流信息及设备厂商后台，更新节奏按单或按周产生。日常处理的文档包含采购订单、到货验收单、序列号清单与发票资料，数据字段多包含采购标识、设备型号、序列号、到货时间、验收状态与开票信息，部分文档附带二进制格式的扫描件或电子凭证。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源数据接入需适配不同接口协议与格式解析规则，导致模型调用的数据源配置需覆盖多类来源。按单更新的批量特性要求设置合理的上下文窗口，避免单次请求超出模型限制。结构化字段与非结构化凭证混合的输入，需配置对应的内容拆分与提取规则。安全合规审查要求对敏感信息脱敏，需在模型配置中开启对应处理逻辑，保障数据使用合规性。

## 配置怎么定
本配置说明适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `maxContext` | 8000–12000 token | 适配单批次采购单、到货验收单的总文本长度，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 限制单轮审查结果的输出长度，符合合规材料的文档输出规范 |
| `quoteMaxToken` | 500–800 token | 限制引用的原始文档片段长度，确保审查内容的合规性 |
| `toolChoice` | auto | 自动触发工具调用以提取序列号、型号等结构化字段，提升提取准确性 |
| `vision` | 开启 | 支持解析到货验收单的扫描件、发票的电子凭证图片，覆盖非结构化输入场景 |
| `temperature` | 0.2–0.4 | 降低输出随机性，确保合规审查结果的一致性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写AI Proxy服务根地址，例如http://aiproxy:3000，不要附加/v1或/chat/completions，不是VLLM/Ollama/Xinference等单模型地址 | 为App/Admin服务端必需环境变量，确保请求正常路由至AI Proxy服务 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的非空管理员Token，不是应用API Key、模型供应商密钥等 | 为App/Admin服务端必需环境变量，完成AI Proxy服务身份验证，保障请求合法性 |

## 容易做错的三处
- 现象：工具调用的中间步骤内容显示在合规审查的公开界面，原因：未在模型配置中关闭工具输出的会话展示，导致合规材料的中间处理过程泄露。
- 现象：图片格式的发货单、发票无法被正确解析，原因：未开启`vision`配置项，导致模型无法识别非结构化的图像类文档。
- 现象：提取的设备型号与实际到货设备不符，原因：`temperature`配置值超出0.2–0.4的合理区间，导致模型输出随机性过大，出现字段提取错误。

## 怎么确认配好了
- 提交单份采购订单与对应到货验收单的组合数据，检查模型是否能正确提取设备型号、序列号等核心字段。
- 上传一张设备相关的扫描图片，验证模型是否能识别图像中的文本信息并完成提取。
- 发起工具调用请求，确认工具返回的结构化数据被正确整合到审查结果中，且中间步骤未对外展示。
- 调整配置项取值，对比不同设置下的字段提取一致性，确定符合业务要求的取值区间。
