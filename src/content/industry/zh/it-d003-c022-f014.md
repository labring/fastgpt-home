# 信创替代适配的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
本品类的数据围绕信创替代适配场景生成，典型来源包括企业现有IT系统清单、官方发布的国产软硬件兼容目录、项目测试环境记录与厂商公开资料。日常产出的文档包含适配清单、兼容性测试报告、迁移方案与问题台账，数据更新节奏以单个项目周期或季度为单位，文档字段多包含软硬件型号、兼容版本、测试结果、风险等级等，无统一固定单位，随具体文档类型调整。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类的数据分散且项目专属，要求模型接入环节支持多源异构数据的导入适配；非固定的更新节奏，需配置可手动或按项目节点触发的刷新机制；多样的文档类型，需模型兼容清单、报告、台账等不同格式的内容解析；无统一字段标准，需支持灵活的字段映射与自定义规则。同时信创替代适配场景的合规审查需求，要求模型接入时可配置安全校验参数，适配国产化软硬件的特定调用协议，避免跨环境兼容问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | `8000–12000 token` | 适配信创替代适配场景下多份适配文档、测试报告的拼接需求，避免超出模型上下文窗口限制 |
| `maxTokens` | `2000–4000 token` | 平衡合规审查结果的输出长度与响应效率，满足项目级文档的完整审查需求 |
| `temperature` | `0.1–0.3` | 保障合规审查输出的严谨性，降低内容随机性，符合信创场景的合规校验要求 |
| `AIPROXY_API_ENDPOINT` | `填写AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions路径，不得配置为单模型服务地址` | 为FastGPT v4.17.0+版本必需的AI Proxy服务端环境变量，用于指定AI Proxy服务访问地址 |
| `AIPROXY_API_TOKEN` | `填写与AI Proxy服务端配置一致的管理员Token，不能为空` | 为FastGPT v4.17.0+版本必需的AI Proxy服务端环境变量，用于AI Proxy服务鉴权 |

## 容易做错的三处
- 现象：工作流中模型厂商图标无法加载，界面显示空白占位。原因：未配置国产化大模型的专属图标资源路径，或FastGPT版本与国产化模型的适配资源未同步更新。
- 现象：调用模型节点返回500 Gateway forwarding error because service is disconnected。原因：未正确配置`AIPROXY_API_ENDPOINT`为AI Proxy服务根地址且无法访问，或`AIPROXY_API_TOKEN`配置错误或未配置，或AI Proxy服务未正常运行
- 现象：使用封装的MCP协议调用模型时，提示仅支持stdio进程。原因：未按照信创环境的部署要求配置模型调用的进程类型，误使用了非适配的传输协议。

## 怎么确认配好了
- 测试导入单份适配清单文档，查看模型返回的审查结果是否覆盖文档核心内容。
- 调用模型节点执行一次合规校验，确认返回状态码无连接类报错。
- 检查`AIPROXY_API_TOKEN`是否与AI Proxy服务端配置的管理员Token一致且非空
- 查看工作流中模型节点的图标是否正常显示，无加载失败提示。
