# 信息化预算与项目组合管理的安全与合规材料审查：文档解析与分块

## 这个品类的数据长什么样
该品类的核心数据来自财务系统、项目管理系统、合同台账及业务部门需求。日常处理的文档包括年度预算表、项目立项书、项目组合看板、投资复盘报告，文档多包含预算科目、项目编号、优先级、金额等结构化字段，部分报告附带非结构化说明内容。数据更新节奏以月、季或年为周期，不同来源的文档字段格式存在细微差异。

## 这些特征在「文档解析与分块」这一环带来什么约束
多来源的文档格式差异会要求解析逻辑适配不同的表格结构，避免结构化字段丢失。混合结构化数据与非结构化说明的文档，需要灵活调整分块边界，确保预算科目、项目优先级等关键信息不被拆分。批量的月度/季度/年度更新数据，需要匹配稳定的解析超时与文件大小限制，避免批量任务中断。文档字段的细微差异，需要自定义分块规则，防止跨文档的字段混淆，同时满足安全合规审查对关键元数据保留的要求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 800–1200 字符 | 适配该品类文档中结构化字段与非结构化说明的混合长度，避免关键预算信息被拆分 |
| `chunkSplitter` | 按表格优先分块 | 匹配该品类文档多含结构化预算表格、项目看板的特征，保留表格完整性 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配批量导入的年度预算汇总文件、大型跨部门项目组合看板的大小需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 满足多文档批量解析的耗时要求，避免大型投资复盘报告解析中断 |
| `customPdfParse` | 开启 | 适配从项目管理系统导出的带格式PDF文档，保留原有排版与字段结构 |
| `chunkSettingMode` | 手动配置 | 适配不同来源文档的格式差异，灵活调整分块规则以满足合规审查要求 |

## 容易做错的三处
- 现象：上传飞书多维文档或Excel文件后解析结果为空或字段缺失。原因：未开启对应第三方知识库的表格解析开关，未适配该品类文档中结构化预算表格的解析规则。
- 现象：上传大型PDF格式的年度预算文件时触发请求错误。原因：未调整`UPLOAD_FILE_MAX_SIZE`或`PARSE_FILE_TIMEOUT_SECONDS`的配置，超出系统默认限制导致解析任务中断。
- 现象：解析后的分块内容丢失项目编号、预算金额等关键合规审查所需字段。原因：未设置`chunkSplitter`为按表格优先分块，导致结构化表格被错误拆分，关键信息分散在多个分块中。

## 怎么确认配好了
- 上传单份小型项目立项书，检查解析结果是否保留完整的项目编号、优先级等合规审查所需字段。
- 上传批量的月度预算汇总文件，验证解析任务是否在预设的超时时间内完成。
- 开启`customPdfParse`后，上传从项目管理系统导出的带格式PDF文档，核对解析后的排版与原文档是否一致。
- 调整`chunkSize`后，检查分块内容是否未拆分连续的预算科目说明段落。
