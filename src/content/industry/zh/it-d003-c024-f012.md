# 信息流广告创意测试的安全与合规材料审查：文档解析与分块

## 这个品类的数据长什么样
该品类的核心数据来自广告平台、素材库、用户互动数据与转化数据，更新频率多为日或周。日常处理的文档包含创意脚本、素材测试表、投放数据报告、迭代清单四类，其中创意脚本包含画面描述、投放文案、合规提示字段，素材测试表包含测试批次、素材ID、点击率统计字段，投放数据报告包含曝光量、转化量、成本数据，迭代清单包含创意调整记录与合规检查项。

## 这些特征在「文档解析与分块」这一环带来什么约束
四类文档的结构差异要求解析适配不同格式，创意脚本的段落层级、素材测试表的表格关联、投放报告的长文本结构均需保留完整。日/周级的更新频率要求解析流程具备足够的稳定性，避免批量文件处理中断。广告相关的字段与合规提示内容需避免被错误拆分，否则可能导致合规审查遗漏或创意关联信息断裂。同时，大体积的批量投放报告与素材合集需要适配合理的解析阈值，保障处理效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `chunkSize` | 800–1200 字符 | 适配创意脚本、投放报告的单段内容长度，避免拆分跨字段的广告创意文案与合规提示 |
| `chunkSplitter` | 按段落+标题分割 | 匹配创意脚本的画面、文案、投放说明的层级结构，保留素材测试表的表头与数据行关联 |
| `customPdfParse` | 开启 | 适配广告素材测试表的复杂表格结构，保留单元格的对应关系，避免数据错位导致合规审查偏差 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 匹配日更投放报告的解析时长，避免大体积文件解析中断 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 容纳批量的创意脚本与素材测试表合集，满足周更迭代清单的上传需求 |

## 容易做错的三处
- 上传PDF后无解析进度提示，搜索测试返回空结果。原因是未开启`customPdfParse`配置，复杂表格类的素材测试表无法被正确解析，导致嵌入内容缺失。
- 部分PDF文件解析后内容为空。原因是PDF包含加密图层或非标准字体，未触发自定义解析模式，导致文本提取失败。
- 搜索结果出现跨测试批次的内容混杂。原因是`chunkSize`设置过小，将同批次的测试数据拆分到多个块中，导致上下文关联丢失。

## 怎么确认配好了
- 上传单份创意脚本PDF，查看FastGPT v4.17.0解析后的文本预览，确认画面描述、文案内容的段落结构完整。
- 上传包含表格的素材测试表，检查解析结果中是否保留表头与对应数据行的关联。
- 上传100MB左右的投放数据报告，等待解析完成后验证无超时报错。
- 触发搜索测试，输入测试批次相关关键词，确认返回结果包含对应文档的准确内容。
