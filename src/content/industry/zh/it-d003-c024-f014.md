# 信息流广告创意测试的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自广告平台后台、内部素材库、用户互动数据与转化数据。日常产出的文档包括创意脚本、素材测试表、投放数据报告、迭代清单。数据更新节奏多为日度或周度，随投放迭代调整。数据字段包含创意素材类型、变量组合、投放时段、转化指标等，关联创意测试的变量组合与投放效果的对应关系。

## 这些特征在「模型接入与配置这一环带来什么约束
该品类数据来源分散且更新频繁，需通过配置`maxContext`限制总上下文长度，避免混入无关投放数据。日常文档结构多样，需配置`quoteMaxToken`限制引用内容的token长度，适配不同文档的格式与内容规模。数据关联创意变量与转化效果，需调整`temperature`控制输出稳定性，避免因数据更新导致的结果波动。出错后果直接影响投放效果，需配置`toolChoice`限定工具调用范围，确保合规审查的准确性。同时需开启`vision`配置，覆盖图片、视频素材的合规审查，适配信息流广告的多类型素材。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配多源投放数据与创意文档的总长度，避免截断有效测试数据 |
| `maxTokens` | 2000–3000 token | 控制单轮合规审查的输出长度，避免超出模型负载 |
| `quoteMaxToken` | 1500–2000 token | 限制引用单份素材脚本或测试表的内容长度，确保引用合规且不溢出上下文 |
| `temperature` | 0.2–0.4 | 平衡合规审查的灵活性与稳定性，适配高置信度的合规判断 |
| `vision` | 开启 | 覆盖图片、视频素材的合规审查，适配信息流广告的多类型创意素材 |
| `AIPROXY_API_ENDPOINT` | AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions路径，不得填写VLLM/Ollama/Xinference等单模型地址 | 为App/Admin服务端的环境变量，指向AI Proxy服务根地址，确保服务能正常连接AI Proxy依赖 |
| `AIPROXY_API_TOKEN` | AI Proxy服务端配置的管理员Token，与服务端配置一致且不能为空，不得为应用API Key、模型供应商密钥或按应用签发的Token | 为App/Admin服务端的环境变量，用于AI Proxy服务身份校验，确保服务能正常调用AI Proxy |

## 容易做错的三处
- 配置`AIPROXY_API_ENDPOINT`时填写错误地址，触发404 page not found报错，可排查是否填写了VLLM/Ollama/Xinference等单模型地址或附加了/v1、/chat/completions等路径。
- 设置`temperature`取值超过0.5，导致模型识别合规规则不灵活，原因是温度过高导致输出随机性过强，无法稳定识别合规细节。
- 未配置`quoteMaxToken`限制引用素材内容，导致token计算超出模型负载，触发请求失败，原因是未限制引用文档的token占用，超出模型上下文上限。

## 怎么确认配好了
- 检查App/Admin服务端的环境变量配置，确认`AIPROXY_API_ENDPOINT`（AI Proxy服务根地址）与`AIPROXY_API_TOKEN`（AI Proxy管理员Token）已正确配置且非空，服务启动校验无失败。
- 上传一份创意脚本与素材测试表，查看模型输出的合规审查结果是否覆盖了文案与素材的合规点。
- 调整`temperature`至0.3左右，对比两次审查结果的稳定性，确认符合预期。
- 上传一张图片素材，确认`vision`配置开启，模型能识别图片的合规性。
