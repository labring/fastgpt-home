# 内容版权与授权管理的安全与合规材料审查：文档解析与分块

## 这个品类的数据长什么样
本品类的核心数据来自合同系统、版权登记信息、内容库与投诉邮箱，日常处理的文档包含授权合同、版权台账、下架通知及侵权投诉材料。数据更新以每单或月度为节奏，文档结构多包含权利主体、授权范围、有效期限、侵权情况等字段，无统一固定格式，部分材料为扫描件或多页混合文档。

## 这些特征在「文档解析与分块」这一环带来什么约束
不同来源的文档格式差异大，导致解析时需适配多类文件类型；授权合同等长文档需精准拆分授权范围相关段落，避免分块割裂权利边界；侵权投诉材料多为零散文本，需按投诉主体、侵权内容分类分块；扫描件类材料需额外处理图像识别环节；按单更新的数据要求分块结果可快速关联对应业务单据，避免跨单内容混淆。

以下配置适用于FastGPT v4.17.0版本。
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `chunkSize` | 800–1200 字符 | 适配授权合同、版权台账等常规文档的段落长度，避免单块内容过多影响检索 |
| `chunkSplitter` | 按段落+语义，针对扫描件文档额外启用OCR处理（耗时约20秒/页） | 适配多类文档的自然分段，避免割裂授权范围等核心业务内容，同时覆盖扫描件材料的解析需求 |
| `customPdfParse` | 启用 | 适配扫描版授权合同、多页混合的投诉材料，提升解析完整性 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 兼容单批次批量上传的版权台账、下架通知包 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 适配长文本侵权投诉材料的解析耗时，避免中途超时中断 |
| `chunkSettingMode` | 手动配置 | 针对不同类型的版权文档调整分块规则，满足业务场景需求 |

## 容易做错的三处
- 现象：通过创建文件集合API上传的文件与平台直接上传的文件分块结果不一致，分块数量存在偏差。原因：两种上传方式默认启用的`chunkSplitter`参数配置存在差异，API上传未手动指定分块规则时使用通用默认值，平台上传则适配了版权文档的默认分段逻辑。
- 现象：配置自定义URL链接调用解析工具后，无解析结果返回且无报错提示。原因：未确认自定义链接指向的文档格式受平台解析支持范围覆盖，或链接权限限制导致平台无法获取文件内容。
- 现象：启用文档解析节点后，模型无法读取上传的授权合同或投诉材料。原因：`UPLOAD_FILE_MAX_SIZE`配置值小于实际上传文件的大小，或`PARSE_FILE_TIMEOUT_SECONDS`设置过短导致解析未完成即被终止。

## 怎么确认配好了
- 上传单份典型文档（如标准授权合同），查看解析后的分块列表，核对分块是否覆盖了核心的权利主体、授权范围字段。
- 对比API上传与平台上传同一份文档的分块结果，确认分块规则配置是否符合预期。
- 测试自定义URL链接的解析流程，检查是否能正常获取并解析目标文档内容。
- 查看解析任务的日志，确认解析耗时未超过配置的`PARSE_FILE_TIMEOUT_SECONDS`阈值，文件大小未超出`UPLOAD_FILE_MAX_SIZE`限制。
