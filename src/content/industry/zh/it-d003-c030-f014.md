# 内部网络与WiFi运维的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自交换机控制台、无线控制器、监控系统及用户报障渠道。日常产出的文档包含网络拓扑图、变更单、故障记录与无线覆盖巡检表。数据更新节奏为每日更新或随网络变更即时同步。文档字段包含端口编号、VLAN标识、无线信号强度参数、巡检周期与故障排查步骤等，部分为非结构化文字记录，无统一标准化格式。

## 这些特征在「模型接入与配置」这一环带来什么约束
非结构化的故障记录与巡检表要求模型适配多格式输入，需限制上下文长度避免冗余。数据随变更同步的特性要求模型接入配置支持动态更新数据源，避免使用过期的网络拓扑与故障信息。端口、VLAN等精准字段的核查需求，要求模型调用时需固定参数精度，不宜放宽匹配阈值。本地部署的模型需适配内部网络环境，无法依赖公网接口，需配置本地接入端点与令牌验证。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `AIPROXY_API_ENDPOINT` | 内部网络可访问的AI Proxy服务根地址，如 `http://internal-aiproxy:3000` | 为AI Proxy服务的必填环境变量，指定服务访问根地址，不得附加 `/v1` 等路径后缀，非单模型部署地址 |
| `AIPROXY_API_TOKEN` | 与AI Proxy服务端配置一致的管理员Token | 为AI Proxy服务的必填环境变量，用于验证AI Proxy服务访问权限，非模型供应商密钥或应用API Key |
| `maxContext` | 8000–12000 token | 匹配网络拓扑图、故障记录等多文档的总长度需求，避免截断关键配置信息 |
| `temperature` | 0.1–0.3 | 保障端口、VLAN等精准字段的核查结果一致性，降低随机误差 |
| `toolChoice` | auto | 允许模型根据合规审查需求自动调用工具，适配动态变化的网络变更场景 |
| `maxTokens` | 2000–3000 token | 限制单轮生成的合规审查结果长度，避免输出冗余信息 |

## 容易做错的三处
- 配置`AIPROXY_API_ENDPOINT`时使用公网地址，导致内部网络无法访问AI Proxy服务，界面显示连接超时错误。原因是未使用内网可访问的AI Proxy服务根地址，违反内部网络访问限制。
- 未正确配置`AIPROXY_API_TOKEN`，系统启动校验失败或运行时提示未授权访问。原因是未配置或配置了与AI Proxy服务端不一致的管理员Token，非模型生成的令牌。
- 添加知识库后触发报错，仅在本地部署模型时出现。原因是未调整`maxContext`参数适配知识库文档的总长度，超出模型支持的上下文上限，导致请求失败。

## 怎么确认配好了
FastGPT v4.17.0版本下，可通过以下动作核对配置是否生效：
- 访问配置的`AIPROXY_API_ENDPOINT`地址，验证内部网络可正常访问AI Proxy服务根地址，确认网络连通性。
- 验证App/Admin服务启动时未报环境变量缺失或校验失败错误，确认`AIPROXY_API_TOKEN`配置有效。
- 上传一份网络故障记录作为测试知识库，发起合规审查请求，确认无超时或报错，返回结构化的核查结果。
- 调整`temperature`参数至0.2，发起两次相同的审查请求，确认结果一致，验证参数配置生效。
