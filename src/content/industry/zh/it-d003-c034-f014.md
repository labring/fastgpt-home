# 办公系统流程配置的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来源于企业OA系统、组织架构库、内部制度文件及用户反馈。日常产出的文档包含流程配置单、审批节点表、表单字段说明与变更记录。数据更新随流程变更触发，通常每月至少一次。数据字段包含流程节点标识、审批权限范围、表单校验规则、节点执行时限说明等，无固定统一的标准化格式，随企业内部管理要求调整。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散且格式不统一，要求模型接入时需支持多源异构文档的解析适配，难以依赖固定输入模板。更新随流程变更触发，需配置动态数据同步机制，避免模型使用过期的流程配置信息。审批节点与权限字段涉及企业内部权限规则，要求模型调用时需严格遵循数据隔离要求，防止敏感权限信息泄露。流程变更记录需纳入上下文窗口，确保模型生成的配置建议与历史调整逻辑保持一致，适配安全合规审查的校验需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配流程配置单、审批节点表等多文档的上下文长度，避免截断关键审批规则 |
| `maxTokens` | 2000–3000 token | 满足合规审查时对长文本审批规则的完整解析需求 |
| `temperature` | 0.1–0.3 | 降低配置建议的随机性，确保审批规则配置的一致性与合规性 |
| `toolChoice` | auto | 自动触发工具调用以读取流程配置文档，适配多源数据的校验需求 |
| `AIPROXY_API_ENDPOINT` | AI Proxy服务的根地址，例如 http://aiproxy:3000，不得附加 /v1 或 /chat/completions 路径，不得为单模型服务地址 | 为AI Proxy服务的根地址，需与部署的AI Proxy服务端地址一致，且为App/Admin服务端环境变量，不得在工作流全局变量、应用API请求头或普通模型管理页面填写，满足企业内部数据隔离的安全合规要求，避免外部接口调用风险 |
| `AIPROXY_API_TOKEN` | 与部署的AI Proxy服务端配置一致的管理员Token，不能为空 | 为AI Proxy服务的管理员Token，需与AI Proxy服务端配置的Token完全一致且非空，且为App/Admin服务端环境变量，不得在工作流全局变量、应用API请求头或普通模型管理页面填写，符合权限管控要求 |

## 容易做错的三处
- 现象：调用MCP工具后模型上下文被打断，回答内容不连贯。原因：未正确配置`maxContext`参数，工具调用时未保留原有流程配置的上下文窗口，导致关键审批规则信息丢失。
- 现象：模型调用响应超时，生成内容卡顿或不完整。原因：未设置合理的`maxTokens`取值，或未配置动态数据同步机制，导致模型需要加载过多过期的流程配置文档。
- 现象：重排模型无法正常生效，返回结果不符合合规审查优先级要求。原因：未确认FastGPT v4.17.0版本对Qwen3-Reranker-8B的适配支持，或重排参数配置未匹配模型输入要求。

## 怎么确认配好了
- 发起一次流程配置单的合规校验请求，检查模型返回的配置建议是否包含当前系统内的审批节点信息。
- 触发MCP工具调用流程变更记录，确认模型上下文未被截断，保留了完整的历史配置逻辑。
- 查看模型调用日志，确认鉴权令牌与API端点配置正确，无外部接口调用的异常报错。
- 测试重排模型的调用，调整参数以匹配实际校验需求，确认返回的文档排序符合合规审查的优先级要求。
