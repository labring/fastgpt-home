# 变更管理与发布窗口的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源于变更管理系统、CI流水线、监控数据与业务日历。更新频率为周度或每一次变更触发。核心文档包含变更申请、风险评估表、上线窗口计划与回退方案，字段包含变更唯一标识、执行时段、风险等级、回退触发条件等，时间类字段以小时或天为单位，风险等级字段以低、中、高为取值。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构数据的接入要求配置兼容不同系统的API端点，需适配变更管理系统的结构化数据与CI流水线的非结构化日志文本。非固定更新频率要求上下文长度配置可灵活调整，避免因单次审查的数据量波动触发token超限。多样的文档结构要求模型支持多格式输入解析，字段的标准化程度差异要求配置合适的温度参数以保证风险评级的稳定性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `maxContext` | 8000–12000 token | 变更管理相关文档的总token量通常处于该区间，可完整加载单批次审查所需的全部材料 |
| `maxTokens` | 2000–3000 token | 生成合规审查结论的长度需求覆盖风险评级、窗口适配性分析与回退建议的完整输出 |
| `temperature` | 0.1–0.3 | 需稳定的风险评级与合规判断结果，避免因随机性导致审查结论偏差 |
| `AIPROXY_API_ENDPOINT` | 填写AI Proxy服务的根地址，如 http://aiproxy:3000 | 该地址为AI Proxy服务的根地址，不得附加/v1或模型接口路径，需与AI Proxy服务端配置一致 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的管理员Token，不能为空 | 该Token为AI Proxy的管理员鉴权凭证，非模型服务商密钥或应用API Key |

## 容易做错的三处
- 检查服务端环境变量`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置：未正确配置会导致模型接入异常；排查时需确认`AIPROXY_API_ENDPOINT`为AI Proxy服务根地址且未附加接口路径，`AIPROXY_API_TOKEN`为有效管理员Token且非空
- 排查模型输出为空的情况：可检查`maxTokens`参数配置是否合理，避免因参数值过小导致生成内容被截断
- 无法修改预设模型的名称，原因是使用了固定绑定的第三方模型接入模板，未开启自定义模型名称的编辑权限。

## 怎么确认配好了
- 检查服务端环境变量`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置值，确认`AIPROXY_API_ENDPOINT`为AI Proxy服务根地址且未附加接口路径，`AIPROXY_API_TOKEN`为有效管理员Token且非空；验证App/Admin服务启动无校验失败报错
- 上传一份完整的变更申请与风险评估文档，验证模型可正确读取文档内容并生成合规审查结果。
- 设置`temperature`为0.2后，多次运行同一审查任务，确认输出结果的差异处于可接受范围。
- 查看App/Admin服务端与AI Proxy服务端的日志，确认无连接超时、认证失败或参数格式错误的报错记录。
