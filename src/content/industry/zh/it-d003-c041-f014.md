# 图像标注项目的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据通常来自标注平台的图片样本、预设类别字典、抽检结果与标注团队的日常产出。日常关联文档包括标注规范、框选样例、质检报告与返工清单，更新节奏按日或每批任务更新。数据核心围绕视觉目标的位置、类别信息展开，不同于文本标注项目，需处理边界框、遮挡状态等视觉特征字段，无额外量化统计数值。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据来源分散于标注平台、本地图片样本库与抽检结果，要求模型接入需适配多源输入的读取逻辑。数据更新节奏为日或每批任务，需支持动态加载的类别字典与最新样本。视觉类数据的处理需求，要求接入的模型需支持视觉模态，同时需配置适配视觉任务的上下文与token限制。日常关联的结构化文档如质检报告、返工清单，需模型能处理结构化字段的读取与校验，进一步约束了模型的上下文窗口与工具调用配置。

## 配置怎么定
以下配置项适配FastGPT v4.17.0版本的模型接入流程：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `vision` | 开启（设为true） | 该品类需处理图片样本的视觉特征，需调用支持视觉模态的模型 |
| `maxContext` | 8000–12000 token | 需承载标注规范、框选样例、质检报告等多份文档的上下文，避免截断关键规则 |
| `maxTokens` | 2000–3000 token | 用于生成标注校验结果或返工建议，满足长文本输出需求 |
| `quoteMaxToken` | 1500 token | 限制引用的标注文档片段长度，避免冗余信息干扰模型判断 |
| `temperature` | 0.1–0.3 | 需保持标注规则的一致性，降低随机输出概率 |
| `AIPROXY_API_ENDPOINT` | AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions等路径，不得填写单模型服务地址 | 该变量为App/Admin服务端必需配置的环境变量，需与AI Proxy服务端部署配置一致 |

## 容易做错的三处
- 现象：部署后出现身份校验失败或请求参数不匹配报错。原因：未正确配置服务端环境变量`AIPROXY_API_TOKEN`，其值需与AI Proxy服务端配置的管理员Token一致且非空；或上游模型渠道配置未开放视觉模型调用权限。
- 现象：提交图片样本后模型无视觉识别结果。原因：未开启`vision`配置项，或接入的模型未声明支持视觉模态。
- 现象：校验标注结果时出现关键规则被截断。原因：`maxContext`取值过小，导致标注规范、类别字典等上下文文档未完整加载。

## 怎么确认配好了
- 上传单张带标注样例的图片，发起合规校验请求，检查是否返回基于视觉特征的标注合规性判断。
- 导入一份完整的标注规范文档，查看模型调用日志中是否完整加载了文档内容，无截断提示。
- 配置`temperature`参数后，多次发起相同的校验请求，确认输出结果的一致性符合预期。
- 检查代理服务的调用日志，确认模型请求已正常发起且无身份校验失败记录。
