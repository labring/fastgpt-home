# 安全事件应急响应的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的核心数据来自SIEM、EDR、防火墙日志与主机镜像，更新节奏为实时或每事件触发。日常产出的文档包括应急响应报告、取证记录、处置方案与通报材料，各文档包含事件时间戳、受影响资产标识、攻击路径描述、处置操作记录等固定字段，字段随事件类型动态调整，无统一固定单位。本文基于FastGPT v4.17.0版本编写。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据来源分散且更新节奏为实时或每事件触发，要求模型接入环节需适配多源异构日志格式，避免格式解析失败。事件触发的更新模式意味着需支持短周期批量数据处理，不宜设置过长的上下文等待窗口。日常文档包含敏感字段与动态变化的事件专属字段，需在模型调用时配置内容脱敏规则，同时支持灵活的上下文提取逻辑，适配不同事件的字段差异。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填写AI Proxy服务的根地址，例如 http://aiproxy:3000，不得附加 /v1 或 /chat/completions 路径 | 作为AI Proxy必需依赖的App/Admin服务端环境变量，指定AI Proxy服务接入根地址，不得为单模型服务地址 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的非空管理员Token | 作为AI Proxy必需依赖的App/Admin服务端环境变量，与AI Proxy服务端配置的管理员Token保持一致且不能为空，与模型供应商权限无关 |
| `maxContext` | 8000–12000 token | 适配单事件多源日志的上下文长度，避免截断关键证据信息 |
| `temperature` | 0.1–0.3 | 确保模型输出的处置方案与取证逻辑严谨，减少主观偏差 |
| `toolChoice` | auto | 允许模型自主选择是否调用工具处理日志解析，适配动态字段的提取需求 |
| `maxTokens` | 2000–3000 token | 限制单条处置建议的输出长度，符合通报材料的篇幅规范 |

## 容易做错的三处
- 现象为调用时返回`403 该令牌无权使用模型`，可排查项：检查应用API Key、模型供应商密钥等鉴权配置是否正确，AI Proxy管理员Token与模型访问权限无关。
- 现象为模型输出的处置建议超出通报材料的篇幅限制，原因是未配置`maxTokens`参数或取值过大，未限制单条输出长度。
- 现象为多源异构日志无法被正确解析，原因是未适配数据来源的格式，且未开启灵活的上下文提取配置，导致动态字段无法被识别。

## 怎么确认配好了
- 调用测试接口，输入单条SIEM日志与取证记录，检查是否返回合规的处置建议，无权限报错。
- 查看模型输出的内容长度，确认符合预设的输出限制要求。
- 导入多源异构日志样本，检查模型是否能正确提取攻击路径与受影响资产信息。
- 核对`AIPROXY_API_TOKEN`是否与AI Proxy服务端配置的管理员Token一致且非空。
