# 安全培训与钓鱼演练的安全与合规材料审查：权限与数据隔离

## 这个品类的数据长什么样
该品类的核心数据来自员工通讯录、邮件网关、内部培训平台及用户点击统计系统。日常产出的文档包含培训课件、钓鱼演练方案、钓鱼邮件模板、演练结果报告四类。数据更新频率通常为季度或年度，部分单次演练的结果报告需根据活动周期更新。文档字段包含演练人群范围、模板变量、点击转化率、合规校验标记等，无统一固定单位，随文档类型调整。

## 这些特征在「权限与数据隔离」这一环带来什么约束
该品类的数据特征对权限与数据隔离带来多重约束。员工通讯录数据涉及人员隐私，需通过`teamId`参数绑定团队边界，确保不同团队仅能访问本团队的人员信息，避免跨团队数据泄露。钓鱼邮件模板与演练方案属于敏感安全资料，需隔离不同服务商或内训团队的专属内容，防止未授权调用。演练结果报告包含合规校验结果，需绑定对应演练活动的权限，确保仅参与复盘的人员可查看。低更新频率下需维持权限配置的稳定性，避免因配置变更导致数据访问异常。

## 配置怎么定
本页面配置说明适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `teamId` | 绑定当前工作流所属团队的唯一标识 | 隔离不同团队的演练数据、培训课件与演练报告，避免跨团队访问 |
| `tmbId` | 绑定钓鱼邮件模板所属团队的唯一标识 | 隔离不同服务商或内训团队的专属模板，防止未授权调用 |
| 全局变量隔离规则 | 按使用者ID隔离同名变量，变量缓存时长`5 分钟`，按实测标定 | 确保不同使用者的同名全局变量互不干扰，匹配实际业务场景 |
| 团队数据存储配额 | `10 GB`以内，按团队规模调整 | 适配不同团队的演练数据存储需求，避免资源浪费 |
| 权限校验超时时间 | `20–40 秒`，按实测标定 | 快速响应权限校验请求，避免影响钓鱼演练的执行流程 |
| 敏感文档访问日志保留时长 | `180 天` | 满足合规审计的日志留存要求，便于后续回溯校验 |

## 容易做错的三处
- 现象为不同使用者调用同名全局变量时获取到非预期值，原因是未配置按使用者ID隔离的全局变量规则，导致变量作用域未按使用者划分。
- 现象为尝试访问其他团队的钓鱼邮件模板时返回“没有权限操作此对话记录”，原因是未绑定`teamId`参数，导致权限校验未正确匹配团队边界，无法识别访问者所属团队。
- 现象为演练结果报告的审计日志缺失，原因是未配置敏感文档访问日志的留存规则，导致合规校验无有效回溯证据。

## 怎么确认配好了
- 发起跨团队的钓鱼模板访问请求，确认返回权限校验失败提示，验证`teamId`与`tmbId`绑定的隔离配置生效。
- 创建同名全局变量，使用不同使用者ID发起调用，确认获取到各自独立的变量值，验证全局变量隔离规则配置正确。
- 查看团队数据存储目录，确认仅包含当前团队的演练数据与文档，验证团队数据存储配额配置生效。
- 触发多次权限校验请求，确认响应时长符合业务需求，验证权限校验超时时间配置合理。
