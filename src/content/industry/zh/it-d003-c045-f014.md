# 安全培训与钓鱼演练的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的日常文档包含培训课件、演练方案、钓鱼邮件模板、演练结果报告，数据来源包括员工通讯录、邮件网关、内部培训平台与用户点击统计系统。数据更新频率通常为季度或年度，单份文档包含人群标签、模板内容、统计结果等字段，无统一固定单位，需结合具体业务场景匹配。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散导致接入时需兼容多系统接口格式，更新频率较低意味着无需高频同步数据，但需配置稳定的批量处理逻辑。钓鱼邮件模板与演练报告的非结构化内容较多，要求模型支持长文本处理与多模态输入。人群筛选环节依赖员工通讯录字段，需确保模型能准确识别结构化字段并完成匹配，避免因字段解析错误导致演练人群偏差。同时，合规审查要求保留完整处理痕迹，需配置可溯源的日志记录参数。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配钓鱼邮件模板与演练报告的长文本内容，避免上下文截断导致审查不完整 |
| `maxTokens` | 2000–3000 token | 满足合规审查结果输出的长度需求，同时控制单轮推理成本 |
| `temperature` | 0.1–0.3 | 降低输出随机性，确保合规审查结果的一致性与准确性 |
| `AIPROXY_API_ENDPOINT` | 填写AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions等路径 | 为App/Admin服务端必需的环境变量，适配私有化部署网络环境，确保AI Proxy代理链路连通 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的管理员Token，不得为空 | 为App/Admin服务端必需的环境变量，保障AI Proxy代理调用的身份验证安全，避免未授权访问 |

## 容易做错的三处
- 现象：App/Admin服务启动失败或OneApi页面返回502状态码。排查项：检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`是否已作为服务端环境变量正确配置，且`AIPROXY_API_ENDPOINT`为AI Proxy服务根地址、`AIPROXY_API_TOKEN`非空且与服务端配置一致。
- 现象：新增自定义模型提供商后，钓鱼邮件模板审查无有效结果。排查项：检查模型渠道配置的上游模型地址、供应商凭证是否正确，检查模型是否支持长文本处理，检查`maxContext`参数配置是否适配待处理的长文本内容。
- 现象：接入DeepSeek系列模型后，输出无思考过程内容。排查项：检查模型渠道配置的模型参数（如`toolChoice`）是否正确设置，检查模型是否支持结构化思考环节输出。

## 怎么确认配好了
- 检查App/Admin服务启动日志，确认无`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`缺失的启动校验报错。
- 上传一份标准钓鱼邮件模板，触发合规审查任务，确认输出结果包含完整的合规性分析与风险提示内容。
- 查看模型调用日志，确认AI Proxy代理链路无身份验证失败或链路超时记录。
- 调整`temperature`参数至0.2，连续触发3次同一模板的审查，确认输出结果的核心内容一致性符合预期。
