# 客户培训与使用手册的安全与合规材料审查：引用来源与溯源

## 这个品类的数据长什么样
该品类的核心数据包括培训课件、用户手册、培训签到表与问题答疑清单，数据来源为产品帮助中心、客户组织架构、培训录屏与工单系统。更新节奏为每单或每产品版本触发，文档结构通常包含角色权限说明、操作步骤演示、常见问题解答三类字段，部分录屏类文档附带时长与播放进度字段，整体数据格式兼具结构化文本与非结构化音视频转写内容。

## 这些特征在「引用来源与溯源」这一环带来什么约束
该品类的数据来源分散且包含文本、录屏转写等多种格式，更新频率随客户订单或产品版本变动，要求溯源环节必须绑定对应版本与适用角色，避免引用过期内容。文档结构差异大，既有结构化的操作步骤清单，也有非结构化的答疑记录，需适配不同格式的片段提取。工单系统的实时问题数据要求溯源链路支持快速关联最新的答疑内容，同时需保证培训材料的引用与对应客户角色匹配，防止出现权限说明错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 相似度阈值 | 0.75–0.85 | 适配该品类结构化与非结构化混合的文档特征，平衡召回精度与覆盖范围 |
| 单次搜索上限 | 前3–5条 | 匹配培训材料单条内容聚焦的特点，防止引入过多冗余的无关片段 |
| 重排 | 开启 | 优化该品类中相似操作步骤文档的排序准确性，提升溯源精准度 |
| `quoteMaxToken` | 1000–1500 token | 适配培训课件与用户手册的单段内容长度，保证引用片段完整且不超出上下文限制 |
| `responseData` | 开启来源字段 | 绑定文档版本与适用角色，满足合规溯源的版本校验与角色匹配需求 |
| `detail` | 开启详细溯源 | 展示文档来源的具体位置，便于培训讲师与客户成功经理核对内容正确性 |

## 容易做错的三处
- 开启重排后出现引用为空的情况。原因：该品类的部分短片段答疑记录被重排阈值过滤，未保留有效引用片段。
- 引用内容超时未返回。原因：未针对该品类的长文本培训课件调整`quoteMaxToken`参数，导致系统等待超出合理范围。
- 无法自定义引用模板与提示词。原因：使用的FastGPT版本低于v4.17.0，高级配置功能未开放。

## 怎么确认配好了
- 上传一份标注了版本号的用户手册，触发引用溯源，检查返回结果是否绑定了对应产品版本字段。
- 搜索操作步骤相关的问题，确认开启重排后返回的引用片段排序符合逻辑，无明显错位。
- 查看单条引用的详情，确认展示了文档的具体位置与更新时间，可直接追溯原始材料。
- 测试短片段的答疑内容搜索，确认不会出现无有效引用的情况，召回结果符合预期。
