# 客户数据导入迁移的安全与合规材料审查：文档解析与分块

## 这个品类的数据长什么样
本品类的数据主要来自客户历史业务系统、CSV或Excel导入模板、数据库导出文件，以及产品导入日志。日常处理的文档包括数据映射模板、迁移执行方案、字段对应表、迁移验证报告。数据更新节奏随项目单而定，通常不定期产生。数据包含业务字段、单位标识、映射关系等内容，结构随客户原有系统格式差异较大，部分包含多列表格、内嵌图片的说明文档。

## 这些特征在「文档解析与分块」这一环带来什么约束
客户数据导入迁移的文档多包含结构化字段映射、表格类业务数据，部分带有内嵌图片的说明文档。数据来源多样导致文档格式不统一，需适配CSV、Excel、PDF等多种格式。不定期的更新节奏要求解析流程具备灵活适配能力，避免因文档结构变化导致解析失败。字段映射的准确性直接影响后续数据导入的合规性，文档分块需保留字段关联信息，防止拆分后丢失映射关系。同时，需避免因分块过大导致后续检索失效，或分块过小增加冗余处理成本，保障解析效率与合规审查的准确性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配字段映射表、迁移方案这类包含结构化文本的文档长度，避免拆分后丢失字段关联，保障后续数据映射的准确性与合规性 |
| `chunkSplitter` | 按段落+表头拆分 | 适配多列表格、字段映射表的结构，保留表格列与内容的对应关系，防止字段错位引发合规风险 |
| `customPdfParse` | 开启图片内嵌解析 | 适配包含截图说明的迁移文档，可提取文档内图片与对应文本内容，避免敏感图片信息遗漏，符合合规审查要求 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 兼容数据库导出的大体积日志文件与多页PDF迁移方案，同时限制文件上限以降低传输过程中的数据泄露风险 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 避免大体积导入日志因解析超时导致任务失败，适配批量数据的处理时长，保障解析流程的稳定性与合规性 |

## 容易做错的三处
- 现象：多列表格解析后字段错位，结果条数与原表格列数不符。原因：未配置适配多列结构的分块规则，默认分块逻辑按行拆分导致列关联丢失，引发字段映射错误。
- 现象：上传PDF后图片未被提取，解析结果仅包含纯文本。原因：未开启`customPdfParse`的图片内嵌解析配置，仅提取文档内文本内容，导致图片相关的合规审查材料缺失。
- 现象：导入日志解析任务超时，界面显示超时报错。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`至适配大体积日志的取值，默认时长不足以完成批量数据解析，导致任务中断。

## 怎么确认配好了
- 上传一份包含多列表格的字段映射表，核对解析后的文本是否保留了表格列与内容的对应关系。
- 上传包含内嵌图片的迁移方案文档，确认解析结果中包含图片的关联文本与图片标识。
- 上传单份符合常规体积的导入日志文件，验证解析任务可正常完成无超时报错。
- 调整`chunkSize`至不同取值区间，核对分块后的文本片段是否未丢失核心字段映射信息。
