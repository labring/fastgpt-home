# 工单受理与问题分级的安全与合规材料审查：文档解析与分块

## 这个品类的数据长什么样
这个品类的核心数据来自工单系统、聊天记录、产品日志、客户合同SLA，更新频率为日级或实时。日常处理的文档包括客户工单、问题分级表、处理记录、服务报告，其中工单包含客户标识、问题描述、响应时限等字段，分级表为结构化的问题类型映射表，处理记录多为短文本交互片段，服务报告则包含周期内的工单汇总数据。

## 这些特征在「文档解析与分块」这一环带来什么约束
数据的实时更新要求解析环节支持增量同步与低延迟处理，避免阻塞工单流转。结构化的问题分级表与非结构化的工单描述、处理记录并存，要求分块规则同时适配结构化字段提取与自然文本语义保留。客户合同SLA等合规文档可能包含加密格式，解析环节需兼容非标准PDF格式，且不能因解析失败导致合规材料无法归档。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配工单问题描述、处理记录的常规文本长度，避免分块割裂问题上下文与处理逻辑 |
| `chunkSplitter` | 按段落+语义 | 匹配工单文档的自然分段习惯，保留问题与对应处理步骤的关联关系 |
| `customPdfParse` | 启用 | 用于解析客户上传的合同SLA、加密工单附件等PDF文档，还原结构化字段与复杂格式内容 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 匹配工单系统的实时响应时限要求，避免解析超时导致工单流转阻塞 |
| `UPLOAD_FILE_MAX_SIZE` | 100 MB | 适配客服团队常用的工单附件大小范围，避免大文件解析失败 |
| `chunkSettingMode` | 手动配置 | 针对问题分级表这类结构化文档，可单独调整分块规则以保留字段关联性 |

## 容易做错的三处
- 现象：本地部署环境无法正常解析复杂公式，界面返回解析失败提示。原因：未启用`customPdfParse`配置，或使用的解析引擎版本与FastGPT v4.17.0不兼容。
- 现象：知识库里的PDF文档点击分块预览时提示无法读取文件内容。原因：`UPLOAD_FILE_MAX_SIZE`配置值小于上传的PDF文件大小，或文件为加密格式未开启对应解析权限。
- 现象：飞书知识库无法同步PPT和PDF文档。原因：未配置`customPdfParse`且未开启对应文档类型的解析支持，或同步任务超时未自动重试。

## 怎么确认配好了
- 上传测试用的加密PDF、PPT文档，查看平台解析日志是否显示正常解析状态。
- 提交包含复杂数学公式的工单附件，确认分块结果完整保留公式结构与排版。
- 上传100 MB以内的测试文件，确认解析任务在600秒内完成且无超时报错。
- 查看飞书知识库的同步日志，确认PPT、PDF文档的同步状态为已完成。
