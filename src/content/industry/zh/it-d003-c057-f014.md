# 工单受理与问题分级的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据主要来自工单系统、聊天记录、产品日志与客户合同SLA文件。日常处理的文档包括客户提交的工单文本、标准化问题分级表、历史处理记录与服务报告。数据更新节奏分为实时与日更两类：实时数据包含新提交的工单与在线聊天内容，日更数据则为当日汇总的处理记录与服务报告。数据字段涵盖工单标识、问题描述、分级标签、关联SLA条款、处理人信息等，适配半结构化与非结构化混合输入。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据特征对模型接入与配置带来多重约束。实时工单与聊天内容要求调用链路支持低延迟响应，避免超时影响工单处理时效；包含SLA条款的合规数据要求模型输出严格匹配原文，避免偏差或篡改；混合半结构化与非结构化的输入格式，要求模型具备灵活的文本理解能力；兼具实时与日更的更新节奏，需模型支持动态上下文加载，同时平衡上下文长度与token消耗。此外，安全合规审查需保留调用日志与引用记录，配置时需兼顾可追溯性与调用效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配工单与聊天记录的上下文长度，避免截断关键SLA或客户信息 |
| `maxTokens` | 1500–2000 token | 满足单次问题分级与合规审查的输出长度需求 |
| `temperature` | 0.1–0.3 | 保障安全合规审查的输出一致性，降低主观偏差风险 |
| `AIPROXY_API_ENDPOINT` | AI Proxy 服务的根地址，例如 http://aiproxy:3000（不得附加 /v1 或 /chat/completions，不得使用单模型服务地址） | 配置 AI Proxy 服务的访问地址，为 App/Admin 服务端必需环境变量 |
| `AIPROXY_API_TOKEN` | AI Proxy 管理员 Token，需与 AI Proxy 服务端配置一致且非空 | 配置 AI Proxy 服务的访问鉴权凭证，为 App/Admin 服务端必需环境变量 |
| `vision` | 开启 | 支持识别工单中包含的截图类合规材料，适配多模态输入需求 |

## 容易做错的三处
- 现象：提交模型调用后提示connection error。原因：App/Admin 服务端未正确配置`AIPROXY_API_ENDPOINT`（AI Proxy 服务根地址），或`AIPROXY_API_TOKEN`（AI Proxy 管理员 Token）配置错误，导致无法连通 AI Proxy 服务。
- 现象：在模型提供商页面新增渠道时，提示getModifierState不是一个函数。原因：前端页面渲染异常，需刷新页面或重新进入模型配置模块后重试。
- 现象：模型调用显示欠费，但API密钥对应账户仍有可用余额。原因：未正确关联API密钥的计费账户，或配置的调用额度限制被触发。

## 怎么确认配好了
- 检查 App/Admin 服务端的环境变量配置，确认`AIPROXY_API_ENDPOINT`（AI Proxy 服务根地址）与`AIPROXY_API_TOKEN`（AI Proxy 管理员 Token）配置正确且非空。
- 上传一条包含标准问题描述与SLA条款的测试工单，发起模型调用，检查返回的问题分级结果符合预设规则，且无连接错误或参数超限提示。
- 上传一条包含截图附件的测试工单，确认模型能识别图片内容，并在返回结果中关联说明。
- 查看模型调用日志，确认每次调用的token消耗处于`maxContext`与`maxTokens`的配置范围内，无异常溢出。
