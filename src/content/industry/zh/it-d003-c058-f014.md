# 广告合规留痕的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
广告合规留痕的合规材料数据来源包括广告平台后台、客户资质文件、合同系统及监管公开规则。数据更新节奏随广告活动推进或月度周期变动，无统一的批量更新周期。日常处理的文档包含结构化的广告审查表、扫描件形式的资质附件、时序化的投放记录、带整改要求的通知文件。数据字段包含广告唯一标识、投放时段、资质编号、合规状态、整改时限等，无统一固定格式模板，需适配多类型文档结构。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散要求模型接入支持多数据源的定向拉取，需适配广告平台开放接口、客户文件存储路径等不同接入方式。更新节奏随活动变动，要求配置支持按需触发数据拉取，适配临时新增的广告活动数据。文档结构多样，需模型具备解析结构化表格、图片附件及纯文本的能力，避免遗漏关键字段。字段的合规属性要求输出结果需严格匹配数据字段定义，不得随意篡改或遗漏核心信息。

## 配置怎么定
本页配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 合规材料通常包含多份文档，需保留足够的上下文以完整加载全部审查数据 |
| `maxTokens` | 2000–3000 token | 合规审查结果需涵盖资质核验、投放合规性判断等内容，需足够的输出篇幅 |
| `quoteMaxToken` | 1000–1500 token | 限制引用的合规材料内容长度，避免超出模型处理上限 |
| `temperature` | 0.1–0.3 | 需生成稳定、符合合规要求的输出结果，避免随机性过高 |
| `toolChoice` | auto | 需自动调用对应工具拉取分散的合规数据源，无需手动指定工具 |
| `AIPROXY_API_ENDPOINT` | AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions等路径，不得填写单模型服务地址 | 该变量为App/Admin服务端环境变量，用于配置与AI Proxy服务的通信端点 |
| `AIPROXY_API_TOKEN` | 与AI Proxy服务端配置一致的管理员Token，不能为空，不得使用应用API Key、模型供应商密钥等其他凭证 | 该变量为App/Admin服务端环境变量，用于AI Proxy服务的身份鉴权 |

## 容易做错的三处
- 现象：生成的合规审查结果中包含`<think></think>`标签，部分场景下标签内无有效内容。原因：接入的模型默认输出思考环节内容，未配置对应过滤规则。
- 现象：测试时无法拉取到投放记录或资质附件，后台显示接口报错。原因：`AIPROXY_API_ENDPOINT`配置错误、`AIPROXY_API_TOKEN`配置错误或未配置，或AI Proxy服务不可达，或数据源接口配置错误。
- 现象：合规审查结果出现字段缺失或信息不完整。原因：`maxContext`取值不足，无法完整加载全部合规材料内容。

## 怎么确认配好了
- 发起一次单条广告活动的合规材料同步请求，检查模型是否能正确提取广告ID、投放时段等核心字段。
- 查看接口调用日志，确认`AIPROXY_API_TOKEN`验证通过，无异常报错返回。
- 生成合规审查结果，检查是否未包含`<think></think>`标签内容。
- 调整`temperature`取值范围，验证输出结果的稳定性符合预期。
