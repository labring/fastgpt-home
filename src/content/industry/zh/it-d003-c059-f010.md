# 广告素材审核的安全与合规材料审查：引用来源与溯源

## 这个品类的数据长什么样
该品类的数据以广告素材、落地页截图、审核意见、修改记录为核心文档载体，数据来源覆盖广告投放平台、落地页服务器、商品资质备案库及广告法合规条款库。数据更新频率为日级或实时，单条素材关联字段包含素材唯一标识、投放渠道、文案内容、落地页URL、审核节点及违规判定依据，所有数据均围绕合规审查的核心需求组织，无冗余的非关联字段。

## 这些特征在「引用来源与溯源」这一环带来什么约束
广告素材审核的引用溯源需匹配多源异构数据，广告平台的素材数据更新实时性强，需支持即时拉取最新投放内容，避免审核结果滞后于实际投放状态。落地页URL的一致性核对需溯源到原始落地页服务器，依赖缓存的静态数据会导致核对结果失真。审核意见与修改记录的溯源需绑定唯一素材ID，确保每一条合规判定都能关联到原始素材与资质文件，避免跨素材的溯源混淆。同时，广告法条款库的静态内容需定期同步，确保溯源依据的合规性，且需严格限定溯源范围，防止无关数据干扰审核流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `quoteMaxToken` | `800–1200 token` | 单条广告素材文案+落地页摘要的总长度通常在该区间，避免截断溯源所需的关键信息 |
| `responseData` | `仅返回合规判定相关字段` | 广告素材审核仅需溯源合规相关的素材、资质与条款数据，减少无效信息的加载与展示 |
| `detail` | `开启溯源链接跳转` | 审核员需直接跳转至原始素材或落地页完成现场核对，提升审核效率与准确性 |
| 溯源数据源范围 | `广告平台、落地页、商品资质库` | 该品类的核心数据来源为三类，覆盖所有合规审查所需的原始材料 |
| 数据同步频率 | `实时同步+日全量补更` | 在FastGPT v4.17.0版本中，该配置项的设置可通过后台「数据源同步」页面完成，实时更新适配投放中的素材审核，日全量补更覆盖遗漏的历史素材与资质文件 |
| 溯源失败重试次数 | `2次` | 避免频繁重试导致的平台接口限流，同时保障基础的溯源成功率 |

## 容易做错的三处
- 现象：查看聊天回答的知识库引用时出现404 Not Found报错。原因：溯源配置中未正确绑定落地页的原始URL，导致引用链接指向失效的缓存地址，无法跳转至原始落地页。
- 现象：调用工作流工具后，回答中强制显示知识库搜索的input和response引用内容。原因：未关闭非必要的溯源字段输出，导致冗余的中间步骤被带入最终的审核结果展示中。
- 现象：代码运行插件引用第三方库时，无法关联到广告素材的合规资质依据。原因：溯源范围未配置商品资质库，导致第三方库调用未绑定对应的合规资质文件，无法完成合规校验。

## 怎么确认配好了
- 上传一条测试广告素材，触发合规审核流程，查看返回结果中是否包含可跳转的原始素材与落地页URL链接。
- 关闭非必要的溯源字段输出，发起审核请求，确认最终回答中仅显示合规判定结果，无冗余的搜索步骤引用内容。
- 模拟素材更新场景，修改已上传的广告素材文案，验证实时同步的审核结果是否匹配最新的素材内容与资质文件。
- 查看系统日志，确认溯源请求的重试次数不超过配置的2次，无频繁的接口限流报错记录。
