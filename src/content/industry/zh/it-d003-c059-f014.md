# 广告素材审核的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据来源包括广告平台、落地页、商品资质与广告法条款。日常处理的文档包含广告素材文案、落地页截图、审核意见、修改记录。数据更新频率为日级或实时，每条素材对应独立的审核任务，字段涵盖素材类型、投放渠道、违规类型标签、整改要求等，无统一固定单位，随单条素材的属性动态变化。

## 这些特征在「模型接入与配置」这一环带来什么约束
广告素材审核的数据多源且支持日级或实时更新，要求模型调用适配高并发实时请求，无法依赖批量离线处理流程。素材包含文案、图片、视频等多种形式，需同时支持文本与视觉内容的审核，因此需配置视觉识别能力。每条素材的审核需关联多份关联文档，需保留足够的上下文信息，避免截断关键关联内容。同时审核结果直接影响广告投放权限，需保证判定的一致性，避免随机化输出。

以下配置项基于FastGPT v4.17.0版本制定：
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 广告素材审核需关联素材、落地页、商品资质等多份文档，需保留足够上下文以覆盖全部关联信息 |
| `maxTokens` | 2000–3000 token | 需输出完整的违规点标注与整改建议，避免截断关键审核结论 |
| `vision` | 开启 | 需处理落地页截图、素材图片或视频素材，识别视觉类违规内容 |
| `temperature` | 0.1–0.3 | 需保持审核结论的一致性，避免随机生成违规判定 |
| `AIPROXY_API_ENDPOINT` | AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions路径，不得使用VLLM/Ollama/Xinference等单模型地址 | 为App/Admin服务端必需配置的环境变量，适配高并发实时调用需求 |
| `AIPROXY_API_TOKEN` | 与AI Proxy服务端配置一致的管理员Token，且不能为空，不得使用应用API Key、模型供应商密钥、按应用签发的token或按请求估算的token数 | 为App/Admin服务端必需配置的环境变量，与AI Proxy服务端配置保持一致 |

## 容易做错的三处
- 测试渠道时返回400状态码。排查项：检查App/Admin服务端配置的AIPROXY_API_ENDPOINT是否为AI Proxy服务的根有效地址，未附加/v1等路径；检查AIPROXY_API_TOKEN是否与AI Proxy服务端配置一致且非空。
- 审核结果出现截断，违规点标注不完整。原因是`maxTokens`设置过小，无法承载完整的审核结论输出。
- 图片类素材的违规内容未被识别。原因是未开启`vision`配置，无法处理视觉类素材的审核任务。

## 怎么确认配好了
- 上传单条包含文本与图片的广告素材，触发审核流程，检查是否生成完整的违规点标注与整改建议。
- 查看模型调用日志，确认`maxContext`与`maxTokens`的实际取值与配置一致。
- 更换不同违规类型的素材，验证审核结论的一致性，无随机化判定结果。
- 上传纯图片类素材，确认视觉违规内容被正确识别与标注。
