# 投放效果优化的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
本页面基于FastGPT v4.17.0版本编写。本品类关联的文档主要包含广告投放日报周报、每日调价记录、素材效果测试表、投放优化复盘报告。数据来源覆盖广告平台后台数据、用户归因系统、CRM客户线索库、落地页访问数据。数据更新节奏多为每日同步或实时推送，单份文档字段包含投放时段、消耗金额、线索量、素材点击率等，无统一固定格式，部分字段随广告平台接口调整存在细微差异。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散且格式不统一，要求模型接入时需兼容多源异构数据的解析逻辑，避免因字段差异导致的识别失效。实时或每日更新的数据需要模型配置支持高频调用，需限制单次请求的上下文长度以规避超时风险。不同文档的字段差异要求配置阶段预设多套字段映射规则，适配广告投放、线索归因等不同场景的材料审查需求。合规审查需关联投放数据与素材内容，模型接入需同时支持文本解析与结构化数据匹配，因此需提前配置多模态或结构化数据处理的相关参数。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 适配多源投放文档的上下文长度，平衡合规审查的完整性与请求响应速度 |
| `maxTokens` | `2000–3000 token` | 限制单次审查输出的合规性判定结果长度，避免超出常规阅读与处理阈值 |
| `quoteMaxToken` | `1500 token` | 限定引用原始文档片段的最大长度，确保审查依据清晰可追溯 |
| `temperature` | `0.1–0.3` | 降低输出随机性，保证合规审查结果的一致性，适配标准化的材料校验需求 |
| `AIPROXY_API_ENDPOINT` | AI Proxy 服务的根地址，例如 `http://aiproxy:3000`，不得附加 `/v1` 或 `/chat/completions` 路径 | 作为 App/Admin 服务端环境变量，配置 AI Proxy 服务的访问路由，规避跨区域访问的延迟或拦截问题 |
| `AIPROXY_API_TOKEN` | 与 AI Proxy 服务端配置一致的管理员 Token，不能为空 | 作为 App/Admin 服务端环境变量，完成与 AI Proxy 服务的身份验证，保障请求的合法性与安全性 |

## 容易做错的三处
- 文本理解模型列表为空，无法选择可用模型。原因是未正确配置 App/Admin 服务端环境变量 `AIPROXY_API_ENDPOINT` 与 `AIPROXY_API_TOKEN`，或 AI Proxy 服务不可用，导致平台无法拉取模型列表。
- 审查任务频繁触发超时报错，返回状态码504。原因是`maxContext`设置过大，结合实时数据的高频调用需求，超出了模型接口的响应时限。
- 合规审查结果遗漏部分素材测试表中的违规字段。原因是未预设针对素材测试表的字段映射规则，模型无法识别非标准化的素材属性字段。

## 怎么确认配好了
- 检查 App/Admin 服务端配置的环境变量 `AIPROXY_API_ENDPOINT` 与 `AIPROXY_API_TOKEN`，发起基础连通性测试，确认返回正常的模型列表。
- 导入一份典型的投放日报文档，触发合规审查任务，查看返回结果的上下文引用片段长度是否符合`quoteMaxToken`的配置值。
- 调整`temperature`参数至0.2，连续发起两次相同的审查任务，核对两次结果的一致性，确认参数生效。
- 导入包含结构化数据的调价记录文档，验证模型是否能正确提取消耗金额、投放时段等字段，确认多源数据适配配置生效。
