# 投放计划搭建的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
典型文档包含投放计划全文、定向人群标签列表、预算排期表、转化追踪配置字段，数据来源为广告平台接口、用户画像数据集、内部预算表、归因工具日志，更新节奏为每日同步或单次活动启动时全量更新，字段多为枚举类定向标签、数值型预算、布尔型转化开关，单份文档长度差异较大，无统一固定格式规范。

## 这些特征在「模型接入与配置」这一环带来什么约束
投放计划搭建的合规审查数据来源分散，要求模型接入时支持多源数据的统一解析与整合；文档长度差异大，需适配动态上下文长度配置，避免关键合规项被截断；更新节奏灵活，需支持实时或定时的数据源同步配置，保障审查数据的时效性；合规审查需匹配广告平台的合规校验逻辑，需配置工具调用规则联动合规校验接口，确保审查结果符合平台要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配投放计划文档长度差异，避免上下文截断导致合规项遗漏 |
| `maxTokens` | 2000–3000 token | 控制合规审查结果输出长度，匹配广告平台接口的返回限制 |
| `quoteMaxToken` | 1500 token | 限定引用的原始文档片段长度，确保合规审查依据清晰可追溯 |
| `toolChoice` | auto | 自动触发合规校验工具调用，适配投放计划中多类合规项的校验需求 |
| `temperature` | 0.1–0.3 | 降低输出随机性，确保合规审查结果符合广告平台的固定规则 |
| `AIPROXY_API_TOKEN` | 与AI Proxy服务端配置的管理员Token一致且非空 | 为App/Admin服务端部署的环境变量，用于服务端与AI Proxy服务的身份验证，不得在模型配置页面填写 |

## 容易做错的三处
- 现象为合规审查时未触发重排模型，返回结果未按合规优先级排序；原因是未配置`quoteMaxToken`或`maxContext`参数，导致上下文过长触发截断，重排模型未被调用。
- 现象为默认调用的模型与配置不符，合规审查结果不符合预期；原因是未在全局配置与应用配置中同步设置默认模型参数。
- 现象为模型输出合规思考内容后未返回正式审查结论；原因是`maxTokens`参数设置过低，导致输出被提前截断。

## 怎么确认配好了
- 登录FastGPT v4.17.0后台，进入对应应用的模型配置页面，核对已设置的`maxContext`、`maxTokens`等参数与配置表中的建议值匹配。
- 上传一份包含完整定向设置、预算排期的投放计划文档，触发合规审查，检查返回结果未出现上下文截断提示。
- 模拟API调用请求，查看返回的日志信息，确认`toolChoice`参数触发了合规校验工具的调用。
- 修改`temperature`参数为0.5，对比两次审查结果的差异，确认输出随机性符合业务需求。
