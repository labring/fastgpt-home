# 投标文件编制的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自招标公告、招标文件、企业资质库与供应商报价，更新频率为每单对应一次。日常处理的文档包括投标文件、资格证明、商务偏离表、技术偏离表，文档结构严格匹配招标方给定的格式要求，包含资质核验项、条款响应项、报价明细等字段，内容需精准对应招标条款，避免出现偏差。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据特征对模型接入与配置带来多重约束。多源且按单更新的数据，要求配置需支持快速接入不同来源的招标公告、招标文件、企业资质库与供应商报价数据。严格匹配招标格式的文档结构，要求配置需保留格式对齐的处理能力，确保生成内容符合招标方的排版与条目要求。内容精准对应招标条款的要求，需限制模型生成的偏离范围，避免出现与招标要求不符的表述。严重的废标风险，要求配置需提升内容校验的优先级，同时保障调用稳定性。

## 配置怎么定
本文档基于FastGPT v4.17.0版本编写。以下为针对该场景的配置建议：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 投标文件及关联文档的总内容量较大，需覆盖单项目全量招标与响应内容 |
| `maxTokens` | `2000–3000 token` | 单份偏离表或资质核验内容的生成长度需匹配招标条款的响应要求，避免截断关键信息 |
| `quoteMaxToken` | `500 token` | 需限制引用的招标条款内容长度，确保响应内容聚焦于条款匹配 |
| `temperature` | `0.1–0.3` | 需保障内容的准确性与合规性，降低生成内容的随机性，避免出现不符合招标要求的表述 |
| `AIPROXY_API_ENDPOINT` | AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions，不得配置为单模型地址 | 为AI Proxy服务的访问根地址，保障模型调用的网络连通性，适配企业内部网络策略 |
| `AIPROXY_API_TOKEN` | 与AI Proxy服务端配置一致的管理员Token，且不能为空，不得使用应用API Key、模型供应商密钥或按应用签发的Token | 为AI Proxy服务的身份验证凭证，保障模型调用的身份验证安全性，避免未授权访问 |

## 容易做错的三处
- 现象为工作流的AI模型选项下拉框为空，无法选择可用模型。排查项为检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`是否已作为App/Admin服务端环境变量正确配置，配置错误或未配置会导致无法正常拉取模型列表；未配置必填变量会触发启动校验失败。
- 现象为平台提示“模型流响应为空，请检查模型流输出是否正常”。原因是`maxTokens`设置过小，导致模型生成内容被截断为空，或模型调用超时未返回有效内容。
- 现象为知识库页面可查看所有内容，但对话时模型提示知识库为空。原因是`maxContext`设置过小，无法加载迁移后的知识库全量内容，或知识库的嵌入配置未同步更新。

## 怎么确认配好了
- 核对`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的服务端环境变量配置，确保`AIPROXY_API_ENDPOINT`为AI Proxy服务的根地址，`AIPROXY_API_TOKEN`与AI Proxy服务端配置的管理员Token一致且非空。
- 发起单条招标条款的匹配测试，确认模型可返回对应格式的响应内容，无空返回或报错。
- 查看工作流的AI模型选择界面，确认已接入的模型列表正常加载。
- 导入测试用的资格证明与偏离表文档，触发合规校验流程，检查生成内容是否符合招标格式要求。
