# 搜索广告关键词管理的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自搜索广告后台、搜索词报告、竞价排名数据与落地页数据。日常处理的标准化文档包含关键词清单、否词表、出价记录及搜索词报告，字段覆盖关键词文本、匹配类型、出价金额、搜索量、转化数据等，单位包含字符、元、次等。数据更新频率通常为日度或周度，不同广告账户的同步节奏存在差异，部分大型账户会按小时增量同步部分数据。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据特征会带来三类明确约束：一是多来源的结构化数据格式不统一，不同广告平台导出的关键词、否词等文件存在字段顺序、编码差异，模型接入需适配多格式的批量数据导入；二是日度或周度的更新节奏，要求配置定时同步任务，平衡数据时效性与模型调用的资源消耗；三是数据包含品牌词、出价策略等敏感信息，合规审查环节需限制模型上下文的敏感内容泄露，同时适配批量数据处理的token上限，避免超出模型调用限额。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 搜索广告批量审查的上下文通常包含多组关键词与关联报告内容，该区间可覆盖常规批量任务的上下文需求 |
| `maxTokens` | 2000–3000 token | 单条合规审查的回复需覆盖关键词合规性判断与优化建议，该区间可保证输出完整且无冗余 |
| `toolChoice` | auto | 需根据输入数据自动选择是否调用合规检查工具，适配批量关键词审查的灵活需求 |
| `temperature` | 0.1–0.3 | 合规审查需保持判断的一致性，较低温度可减少主观偏差，保证审查标准统一 |
| `AIPROXY_API_ENDPOINT` | AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions等子路径 | 该变量为App/Admin服务端必需环境变量，用于指定AI Proxy服务的访问地址，不属于单模型服务地址或本地广告数据存储路径 |
| `quoteMaxToken` | 500 token/条 | 每条关键词的合规审查需引用对应搜索词报告内容，该长度可覆盖单条数据的引用需求 |

## 容易做错的三处
- 现象：调用后仅返回单条相似度最高的结果，未覆盖全部待审查关键词。可排查项：检查`maxTokens`配置是否适配当前批量数据的上下文长度需求。
- 现象：多模态的搜索词报告图片无法被正确识别，纯文本关键词审查任务错误调用了视觉模型。可排查项：检查是否按数据类型分别配置了模型调用规则，是否区分了多模态与纯文本任务的模型绑定逻辑。
- 现象：toolChoice功能触发异常，无法自动调用合规检查工具。可排查项：检查`toolChoice`配置是否为auto，以及绑定的模型是否支持工具调用功能。

## 怎么确认配好了
- 上传单组100条以内的关键词清单，检查模型是否生成完整的合规审查结果，无截断或缺失内容。
- 分别上传纯文本关键词文件与带图片的搜索词报告，确认模型仅对带图片的任务调用视觉能力，符合预期。
- 查看工具调用日志，确认`toolChoice`触发的合规检查工具调用次数与待审查关键词数量匹配。
- 配置定时同步任务，检查是否按预设的日度或周度节奏自动拉取新的广告数据并执行审查。
