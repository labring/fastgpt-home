# 数据脱敏处理的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自数据库、数据字典、脱敏工具及访问审批系统，更新节奏为每批任务或每个项目一次。日常关联文档包含脱敏方案、字段映射表、脱敏验证报告与审批记录，数据字段涵盖敏感信息类型、映射规则、验证结果及审批状态，无固定单位，随项目配置灵活调整，数据体量随项目规模波动。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据来源分散且按项目更新，要求模型接入需适配多源数据格式，避免硬编码适配单一数据源。日常关联的文档结构包含字段映射等配置项，要求模型需支持自定义字段识别与映射规则解析。敏感字段识别、脱敏规则配置及可用性验证环节耗时占比高，要求模型接入需提供轻量化的规则调试入口，同时验证环节需对接脱敏工具输出结果，确保配置生效。审批记录需同步至模型配置日志以保证合规溯源，因此模型接入需支持关联审批状态字段，实现全流程可追溯。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `maxContext` | 8000–12000 token | 适配脱敏方案中多字段映射的上下文需求，避免截断关键规则信息 |
| `maxTokens` | 2000–3000 token | 匹配脱敏验证报告的输出长度，确保完整返回验证结果 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写AI Proxy服务根地址，例如 http://aiproxy:3000 | 为App/Admin服务端环境变量，适配本地或云端部署的访问路径，保证AI Proxy服务调用可达，请勿附加 /v1 或 /chat/completions，非VLLM/Ollama/Xinference等单模型地址 |
| `AIPROXY_API_TOKEN` | 与AI Proxy服务端配置一致的非空字符串 | 为App/Admin服务端环境变量，是AI Proxy管理员Token，非应用API Key、模型供应商密钥或按应用签发的token |
| `temperature` | 0.1–0.3 | 降低规则解析的随机性，保证字段映射与脱敏规则配置的一致性 |
| `toolChoice` | auto | 自动选择适配的脱敏规则校验工具，无需手动指定 |
| `quoteMaxToken` | 500 token | 限制引用字段映射表的长度，避免冗余信息干扰配置解析 |

## 容易做错的三处
- 现象为模型渠道配置中无法找到火山方舟等新增厂商的选项，原因是未在FastGPT v4.17.0的渠道管理页面开启自定义厂商接入权限。
- 现象为本地部署版本上传文档时无图片索引模型选项，原因是该功能依赖的扩展模块未随基础包一同部署，需手动安装对应插件。
- 现象为知识库思考模型返回乱码结果，原因是配置的`temperature`参数超出合理区间，或模型接入时未正确设置`maxContext`参数导致上下文截断，或未正确配置`AIPROXY_API_ENDPOINT`、`AIPROXY_API_TOKEN`服务端环境变量导致启动校验失败，无法正常调用模型，替换非思考模型后恢复正常。

## 怎么确认配好了
- 查看渠道管理页面的新增厂商列表，确认目标厂商已添加至配置项中。
- 上传一批测试脱敏文档，检查字段识别结果与预设的字段映射表是否一致。
- 运行脱敏验证任务，查看输出结果是否包含完整的验证报告内容。
- 检查服务端环境变量配置，确认`AIPROXY_API_ENDPOINT`、`AIPROXY_API_TOKEN`已正确设置。
- 检查模型调用日志，确认请求参数与配置项的取值完全匹配。
