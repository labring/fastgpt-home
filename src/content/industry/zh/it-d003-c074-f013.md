# 文本标注项目的安全与合规材料审查：权限与数据隔离

## 这个品类的数据长什么样
文本标注项目的数据主要来自客户提供的语料、内部标注平台产出的标注结果、自定义词表以及质检抽样结果。日常流转的文档包括标注规范、样本包、质检报告与问题反馈表。数据更新频率通常为每日或按标注批次更新，涉及的字段包含文本内容、标注标签、质检结果、标注人ID与时间戳等，整体围绕语义实体、意图分类等文本类标注需求生成，区别于图像标注项目对视觉元素的关注。

## 这些特征在「权限与数据隔离」这一环带来什么约束
客户语料属于敏感业务数据，按批次更新的特性要求隔离规则需适配批量数据的权限校验。标注规范、质检报告等文档涉及团队内部的操作标准与质量要求，需限制非授权人员访问。文本标注的字段包含标注人信息与质检结果，需确保数据流转过程中仅对应角色可修改或查看对应字段。同时，标注团队与NLP算法团队的职责边界要求，数据隔离需区分标注权限、质检权限与算法调用权限，避免跨角色越权访问标注样本与结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `teamId` | 绑定标注项目专属团队ID | 确保仅项目内成员可访问对应标注数据，隔离跨项目的敏感语料 |
| `tmbId` | 绑定标注模板专属模板ID | 限制仅配置该模板的角色可修改标注规范，避免非授权变更标注规则 |
| 角色权限组 | 分为标注员、质检员、算法工程师三类 | 匹配标注团队的职责边界，仅质检员可查看质检报告，算法工程师仅可调用脱敏后的样本数据 |
| 数据访问范围 | 按标注批次划分隔离单元 | 适配按批次更新的数据特性，仅参与对应批次的人员可访问该批次样本 |
| 日志留存周期 | 按实测标定（通常30–90天） | 满足合规审查的日志追溯需求，同时避免无效存储占用 |
| 敏感字段脱敏 | 对客户标识、原始语料等字段做脱敏处理 | 保护客户业务数据的敏感信息，符合合规审查要求 |
| 单次样本访问上限 | 不超过100条 | 限制单次请求的样本量，避免批量敏感数据泄露 |

## 容易做错的三处
- 现象：团队管理员发送成员邀请后，受邀成员未收到任何权限通知。原因：未开启团队权限通知开关，导致隔离规则无法同步到受邀成员，无法正常加入项目。
- 现象：跨项目的标注员尝试访问其他标注批次的样本包，返回403权限不足错误。原因：未正确绑定`teamId`参数，导致权限校验未匹配到对应项目的授权范围。
- 现象：算法工程师调用标注样本时，获取到未脱敏的客户原始联系方式字段。原因：未配置敏感字段脱敏规则，导致合规审查环节遗漏敏感信息保护。

## 怎么确认配好了
- 登录FastGPT v4.17.0的项目管理后台，进入对应文本标注项目的权限设置页面，确认`teamId`与`tmbId`已正确绑定当前项目。
- 邀请测试成员加入项目，查看是否收到权限申请通知，验证通知开关是否正常生效。
- 使用非授权角色的账号尝试访问标注规范文档，确认无法查看或修改该文档。
- 触发一次标注样本的访问请求，查看系统日志是否包含对应权限校验的记录与脱敏后的样本数据。
