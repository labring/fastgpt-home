# 机房巡检与环境监控的安全与合规材料审查：权限与数据隔离

## 这个品类的数据长什么样
该品类的核心数据来自动环监控、门禁系统、UPS监控、视频巡检四类数据源，更新频率为日级或实时。日常产出的文档包括巡检表、温湿度记录、告警记录、值班日志，字段包含设备ID、温湿度数值（单位℃）、电压值（单位V）、告警时间戳、门禁通行记录、巡检人员签名等，单条记录的文本长度从数十字符到数百字符不等。

## 这些特征在「权限与数据隔离」这一环带来什么约束
实时更新的告警与温湿度数据要求权限校验需匹配更新节奏，避免延迟导致未授权访问。多源异构的数据来源需要按机房区域绑定权限，防止跨机房数据泄露。多样的文档类型需按岗位角色划分访问范围，比如值班日志仅对当班运维可见，告警汇总记录可对监控中心开放。跨团队的机房资产隔离要求严格匹配`teamId`与数据归属，否则可能导致设备状态信息泄露，引发设备宕机或客户SLA受损的风险。此外，巡检记录包含人员签名等敏感信息，需进一步限制非授权人员的查看范围，避免内部信息泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `teamId` | 与机房资产绑定的团队标识 | 匹配数据来源的机房归属，确保数据仅对授权团队可见 |
| `tmbId` | 绑定角色权限的模板ID | 区分运维、管理员、监控岗的不同访问权限范围 |
| 实时数据校验间隔 | 60秒 | 匹配巡检数据的实时更新节奏，及时拦截未授权访问 |
| 单请求文档返回上限 | 前20条 | 限制单次返回的巡检记录数量，避免敏感数据批量泄露 |
| 团队数据存储配额 | 1000 MB | 对应单团队的告警、温湿度记录存储上限，防止资源滥用 |

## 容易做错的三处
- 无法打开团队管理页面，提示权限不足。原因：未将当前账号绑定至对应机房的`teamId`，无团队管理权限。
- 无法查看团队内成员的模型使用情况。原因：未配置`tmbId`对应的管理员权限模板，仅开放了基础巡检权限。
- 跨团队应用调用知识库查询无相关内容。原因：应用绑定的`teamId`与知识库所属团队不一致，数据隔离拦截了跨团队请求。

## 怎么确认配好了
- 登录FastGPT v4.17.0，进入团队管理页面，确认当前账号已关联目标机房的`teamId`。
- 切换至非授权团队账号，尝试访问目标机房的巡检数据，确认无法查看。
- 提交一条模拟告警记录，确认仅授权团队的账号可检索到该记录。
- 查看实时数据校验日志，确认每60秒触发一次权限校验，无异常报错。
