# 机房巡检与环境监控的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据主要来自动环监控、门禁系统、UPS监控与视频巡检设备，更新节奏为实时或每日归档。日常文档包含结构化的巡检表、温湿度记录、告警记录与值班日志，字段包含监测时间、环境温度、相对湿度、UPS输入电压、告警等级、设备位置与巡检人员信息，单位涵盖℃、%RH、V等设备监测常用单位，数据格式以表格与短文本为主，部分包含视频帧数据。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源包含实时设备采集的结构化数值、告警日志与视频帧，因此模型接入需同时支持文本与视觉模态，需启用视觉识别能力。数据更新频率为实时或每日，调用频率需匹配采集节奏，避免过度请求导致资源占用过高。文档多为固定格式的巡检表与告警记录，字段数量较多，需限制单轮输入输出长度避免上下文溢出。安全合规审查要求过滤敏感设备标识与位置信息，需在配置中限定输出范围，防止敏感数据泄露。

## 配置怎么定
本页面的配置说明基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `vision` | 开启（设为true） | 数据来源包含视频巡检的帧数据，需支持视觉内容识别与分析 |
| `maxTokens` | 800–1200 token | 巡检表、告警记录的字段数量较多，需限制单轮输入输出长度避免内容溢出 |
| `maxContext` | 3000–5000 token | 需保留近期的告警记录与巡检日志作为上下文，同时控制上下文加载延迟 |
| `temperature` | 0.1–0.3 | 安全合规审查需输出稳定的判断结果，避免随机性导致的合规偏差 |
| `AIPROXY_API_ENDPOINT` | 配置为AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions等路径 | 作为App/Admin服务端必需的环境变量，指定AI Proxy服务的访问地址，非单模型地址。 |
| `AIPROXY_API_TOKEN` | 配置为与AI Proxy服务端配置一致的管理员Token，不得为空 | 作为App/Admin服务端必需的环境变量，用于AI Proxy服务的身份验证，非应用API Key或模型供应商密钥。 |

## 容易做错的三处
- 现象：调用模型时出现接口报错，返回状态码401或字段为空。原因：未正确配置服务端环境变量`AIPROXY_API_TOKEN`或`AIPROXY_API_ENDPOINT`，身份验证失败，与跨平台接入报错的常见场景一致。
- 现象：单轮调用耗时超过10秒，出现超时提示。原因：`maxContext`设置过大，上下文加载耗时超过接口默认超时阈值，导致请求中断。
- 现象：模型未识别视频巡检帧内容，仅返回文本提示。原因：未开启`vision`参数，模型未启用视觉模态能力，无法处理图像类输入数据。

## 怎么确认配好了
- 检查服务端配置的`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`环境变量值，发起测试调用，验证接口连通性正常。
- 上传一条包含视频帧的巡检记录，发起调用，验证模型同时输出文本分析结果与视觉识别结论，确认`vision`参数生效。
- 设置`maxTokens`为1000 token，输入一条完整的告警记录，验证输出内容未出现截断或格式混乱。
- 调整`temperature`至0.2，连续发起3次相同输入的调用，确认输出结果差异较小，符合稳定审查的需求。
