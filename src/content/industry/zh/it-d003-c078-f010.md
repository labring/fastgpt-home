# 机柜上架与布线的安全与合规材料审查：引用来源与溯源

## 这个品类的数据长什么样
这个品类的典型使用主体为IDC运维工程师与网络工程师，日常处理的文档包含上架申请、机柜布线图、端口标签表、施工记录。数据来源为DCIM系统、资产管理系统、网络拓扑图与客户工单，更新节奏为每单或每日更新。文档字段包含机位编号、线缆规格、端口标识、施工日期等，对应单位为U（机架单位）、米、端口号等，仅围绕物理设备的物理接入信息展开。

## 这些特征在「引用来源与溯源」这一环带来什么约束
由于数据围绕单次施工的物理接入信息，且随施工单动态更新，引用溯源需精准匹配当前工单的关联文档，避免混入历史机柜的无关数据。同时，文档类型多为结构化表格与拓扑图，需确保检索时能区分布线图的端口对应关系与施工记录的验收状态，避免引用错误的资产字段。此外，数据来源分散在多个系统，需保证溯源时能关联到原始系统的条目，不能仅依赖知识库切块的摘要内容。

## 配置怎么定
以下为FastGPT v4.17.0版本下的配置项说明：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `quoteMaxToken` | 1200–1800 token | 匹配机柜布线图、端口标签表这类单份文档的常规切块长度，避免截断关键的机位与端口对应信息 |
| `responseData` | 返回引用源文件名与存储路径 | 符合运维工程师快速定位原始施工文档的需求，避免冗余内容干扰 |
| `detail` | 开启 | 用于展示引用源的字段细节，比如端口标签表中的端口号与机位编号，确保溯源信息可直接核对 |
| 单次召回上限 | 前3条 | 匹配单份施工单的关联文档数量，避免引入无关的历史机柜数据 |
| 引用展示开关 | 随检索结果自动启用 | 便于运维工程师直接查看引用的原始文档信息，无需额外手动配置 |

## 容易做错的三处
- 出现`quote type error`报错：现象为知识库引用环节弹出格式错误提示，原因是传入的引用源参数未匹配机柜上架类文档的结构化字段格式，未正确关联端口标签表或布线图的特定字段。
- 引用内容超出配置上限：现象为检索到的切块内容超过`quoteMaxToken`的设置值，原因是知识库切块大小未与`quoteMaxToken`的取值匹配，导致内容截断异常。
- 无法展示引用文件地址：现象为回复中未出现原始文档的路径信息，原因是未开启`responseData`配置项，或配置为仅返回文本内容，未配置源地址返回。

## 怎么确认配好了
- 上传一份机柜布线图与端口标签表到知识库，发起包含具体机位编号的查询，查看返回结果是否附带引用源文件名与存储路径。
- 调整`quoteMaxToken`为1000 token，检索长内容的施工记录，确认返回的引用内容未超过该token阈值。
- 触发一次上架申请相关的查询，检查是否出现`quote type error`报错，确认参数格式配置正确。
- 查看配置界面的`detail`开关状态，确认引用源的字段细节是否在回复中展示。
