# 游戏客户端性能优化的安全与合规材料审查：权限与数据隔离

## 这个品类的数据长什么样
该品类的数据主要来自引擎Profiler导出的帧率、资源占用日志，真机测试采集的加载耗时、卡顿时长记录，崩溃平台的异常堆栈，以及版本迭代中的性能测试报告、机型适配清单、优化记录、崩溃分析报告。部分记录还包含测试设备的硬件配置信息，数据更新频率为每日或每版本迭代周期，单条记录包含机型型号、系统版本、帧率数值、资源加载耗时、异常触发场景等字段，无统一固定格式，随测试场景动态调整。

## 这些特征在「权限与数据隔离」这一环带来什么约束
该品类的数据涉及项目级性能机密与测试环境资源，按来源与使用场景通常需划分不同权限边界。多来源的动态数据需绑定对应项目的`teamId`与`tmbId`，避免跨项目调用测试日志。高频更新的测试记录与优化文档，通常需按版本迭代周期设置数据留存与隔离规则，防止旧版本敏感配置泄露。不同机型适配清单关联发行区域，通常需限制仅对应区域的团队成员可访问，避免合规风险。跨团队的性能测试数据若未做隔离，可能导致项目机密泄露或合规审核不通过。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 团队权限绑定 | 绑定`teamId`与项目性能数据标签 | 匹配数据来源的项目归属，避免跨项目访问 |
| 成员权限粒度 | 按测试角色分配权限（性能测试/引擎开发/运维） | 匹配团队分工的操作范围，限制非必要访问 |
| 免登录链接限制 | 单团队版应用最多创建100个免登录链接 | 适配性能测试场景的临时访问需求，避免资源滥用 |
| 数据过期时间 | 设置为7天 | 适配每日更新的测试数据留存周期，减少敏感数据留存 |
| 权限校验触发 | 基于`teamId`校验接口请求 | 确保所有数据调用符合项目隔离规则，符合FastGPT v4.17.0版本的权限校验逻辑 |

## 容易做错的三处
- 现象：提示“没有权限操作此对话记录”，原因：未将当前用户的`teamId`绑定至对应性能测试项目的权限组，导致无法访问专属测试日志。
- 现象：免登录链接创建数量超出预设限制，原因：未调整团队版应用的免登录链接上限配置，默认值为10个，未适配大规模测试场景需求。
- 现象：跨团队成员可查看其他项目的性能报告，原因：未启用`teamId`级别的数据隔离校验，导致权限边界失效。

## 怎么确认配好了
- 登录对应团队后台，检查`teamId`绑定的权限组是否包含当前项目的性能数据标签。
- 创建免登录链接，验证创建数量是否符合预设配置，无超出限制的提示。
- 切换至非授权团队账号，尝试访问目标项目的性能测试报告，确认无法正常加载。
- 提交接口请求，校验`teamId`参数是否随请求同步传递，确保权限校验生效。
