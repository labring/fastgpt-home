# 游戏客户端性能优化的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据主要来自引擎Profiler、崩溃平台、真机测试及帧率采集工具，日常产出性能测试报告、机型适配清单、优化记录、崩溃分析报告四类文档。数据更新频率为每日或每版本发布周期，字段包含帧率数值、包体大小、资源加载时长、机型型号、崩溃日志堆栈等，单位多为帧率（fps）、兆字节（MB）、毫秒（ms）。数据以结构化性能指标和非结构化日志为主，不同机型的测试数据差异较大，需针对单份文档开展合规与性能审查。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据特征对模型接入与配置带来多维度约束。首先，数据来源包含结构化性能指标和非结构化日志，要求模型支持混合格式的输入解析；其次，每日或每版本的更新频率，意味着模型需适配快速迭代的文档内容，避免上下文缓存过载。其次，核心审查维度聚焦帧率、包体和资源加载，配置需优先匹配这些游戏客户端特有的性能指标。最后，出错会导致卡顿、闪退甚至商店差评，要求审查结果具备较高严谨性，需严格控制生成内容的偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `maxContext` | `10000–15000 token` | 适配单份完整性能测试报告的上下文长度需求，避免截断关键性能数据 |
| `maxTokens` | `4000–6000 token` | 平衡单轮审查的输出长度与处理耗时，适配游戏客户端性能数据的分析需求 |
| `toolChoice` | `auto` | 允许模型自主判断是否调用性能分析工具，适配不同场景的审查需求 |
| `temperature` | `0.2–0.4` | 降低生成结果的随机性，保障合规审查的严谨性，避免偏离实际性能数据 |
| `AIPROXY_API_ENDPOINT` | `填写AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions等路径，不得作为VLLM/Ollama/Xinference等单模型地址` | 适配FastGPT v4.17.0及以上版本的服务端环境变量要求，确保AI Proxy调用链路正常 |
| `AIPROXY_API_TOKEN` | `填写与AI Proxy服务端配置一致的非空管理员Token，不得为应用API Key、模型供应商密钥等` | 为App/Admin服务端必需环境变量，保障AI Proxy调用的身份认证安全，避免未授权访问 |

## 容易做错的三处
- 现象：模型返回的合规审查结果仅覆盖部分性能指标，未提及包体或资源加载问题。原因：未正确配置`maxContext`，导致上下文被截断，无法读取完整的机型适配清单和优化记录内容。
- 现象：调用模型时出现超时报错。原因：未合理设置`maxTokens`，导致模型处理超长的帧率数据或崩溃日志时耗时过长，超出链路超时阈值。
- 现象：模型无法识别截图类机型适配文档的合规问题。原因：未开启`vision`参数，无法处理图像格式的输入内容，导致审查遗漏。

## 怎么确认配好了
- 上传一份包含帧率、包体、资源加载数据的完整性能测试报告，检查模型返回的审查结果是否覆盖所有核心指标。
- 模拟低端机测试数据输入，观察模型处理耗时是否符合业务预期，无明显超时情况。
- 查看FastGPT服务端启动日志，确认`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`环境变量已正确配置，无认证或链路报错。
- 调整`temperature`参数至0.1和0.5，对比生成结果的一致性，验证参数配置对严谨性的影响。
