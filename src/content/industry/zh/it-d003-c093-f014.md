# 用户增长与留存运营的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自用户行为日志、推送系统、实验平台与CRM系统，更新频率多为日度或周度。日常产出的文档包含增长实验方案、用户分层表、触达文案、留存分析报告，数据字段包含用户分层标签、触达文案内容、实验分组参数、留存率指标、渠道投放数据等，单份文档的字段数量随分析维度变化，无统一固定的单条数据长度。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据来源分散且格式多样，包含结构化的用户分层表、实验数据，与非结构化的触达文案、分析报告，要求模型接入配置适配多类型输入。更新频率多为日度或周度，需要模型调用的响应速度匹配业务迭代节奏，避免延迟影响实验排期。同时触达文案的合规审查存在严格要求，配置需保障敏感内容识别的准确性，且需适配多维度的用户分层数据字段，避免截断关键分析信息。

## 配置怎么定
本文基于FastGPT v4.17.0版本编写，配置项及建议如下：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配多维度用户分层数据与实验报告的字段组合，避免截断关键分析信息 |
| `maxTokens` | 2000–3000 token | 覆盖触达文案的合规审查与实验归因分析的输出需求，匹配业务分析的内容长度 |
| `quoteMaxToken` | 1500 token | 限定引用的用户行为日志与CRM数据的长度，避免无关信息干扰审查结果 |
| `temperature` | 0.1–0.3 | 保障合规审查的结果一致性，减少敏感内容识别的随机性偏差 |
| `AIPROXY_API_ENDPOINT` | AI Proxy 服务的根地址，例如 http://aiproxy:3000，不得附加 /v1 或 /chat/completions 路径，不得填写VLLM/Ollama/Xinference等单模型地址 | 该变量为FastGPT App/Admin服务端必需环境变量，用于指定AI Proxy服务根地址 |
| `AIPROXY_API_TOKEN` | 与AI Proxy服务端配置一致的非空管理员Token | 该变量为FastGPT App/Admin服务端必需环境变量，用于AI Proxy服务身份验证 |

## 容易做错的三处
- 调用模型时返回422错误，可排查项：`AIPROXY_API_TOKEN`是否为与AI Proxy服务端配置一致的有效管理员Token；`maxContext`是否超出模型支持的最大上下文长度。
- 配置外部模型API后界面仅显示默认模型列表，可排查项：FastGPT App/Admin服务端是否已正确配置`AIPROXY_API_ENDPOINT`（AI Proxy服务根地址）与`AIPROXY_API_TOKEN`（AI Proxy管理员Token）；`AIPROXY_API_ENDPOINT`是否未附加多余路径，未填写单模型地址。
- 工作流调用指定模型时出现超时，可排查项：`maxTokens`设置是否超出模型支持的最大输出token限制；AI Proxy服务网络连通性是否正常。

## 怎么确认配好了
- 确认FastGPT App/Admin服务端启动校验通过，未提示`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`缺失的错误。
- 调用测试接口，输入一段合规的触达文案，查看返回结果是否正常返回合规审查结论，无报错信息。
- 上传一份用户分层表与实验报告，验证模型是否能完整读取并识别其中的敏感内容，无信息截断。
- 查看API调用日志，确认AI Proxy服务调用请求已成功发送并返回有效响应。
