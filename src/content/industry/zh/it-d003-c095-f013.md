# 监控告警配置的安全与合规材料审查：权限与数据隔离

## 这个品类的数据长什么样
本品类的典型维护主体为运维工程师、SRE团队与平台工程团队，数据主要来源于Prometheus、Zabbix、云监控、应用日志及CMDB系统。日常维护的文档包括监控指标清单、告警规则、值班手册与告警变更记录。监控指标清单包含指标名称、关联资源标识与阈值范围；告警规则包含触发条件、生效时段与通知对象；告警变更记录包含变更时间、操作人与修改内容。数据更新频率为每日同步基础指标，每次告警规则或资源配置变更后即时更新。

## 这些特征在「权限与数据隔离」这一环带来什么约束
本品类的数据覆盖多类监控资源与业务运行细节，不同团队的监控指标、告警规则属于专属业务数据，需严格隔离。数据来源包含CMDB的资源归属信息，需按团队标识绑定资源与权限，避免跨团队访问非授权数据。高频更新与即时变更的特性，要求权限配置支持实时生效，确保变更后权限立即生效。告警通知与变更记录包含操作人、通知对象等敏感信息，需绑定团队标识进行权限校验，防止非授权人员查看或修改。告警阈值设定、噪声清理等核心操作的权限需绑定团队，避免非授权调整影响业务监控效果。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 团队资源绑定 | 按`teamId`关联监控资源与团队，取值为对应团队的唯一标识 | 匹配监控数据的资源归属，实现跨团队数据隔离 |
| 告警模板隔离 | 为每个团队生成专属告警模板，绑定`tmbId` | 确保不同团队的告警规则不被跨团队访问 |
| 变更操作权限 | 仅允许团队管理员修改本团队告警配置，取值为团队管理员角色 | 防止非授权人员篡改告警规则 |
| 告警通知间隔 | 取值为`300 秒` | 避免同一告警重复打扰值班人员，同时确保告警及时触达 |
| 告警历史保留 | 取值为`30 天` | 符合合规数据留存要求，同时控制存储成本 |
| 日志访问过滤 | 按`teamId`过滤可查询的应用日志，取值为对应团队关联的资源ID范围 | 保护团队应用运行数据的隐私性 |

## 容易做错的三处
- 工作流中添加自定义监控告警配置插件后，无输入输出参数显示且无报错日志。原因是未正确绑定插件的`teamId`与团队权限，导致参数渲染权限不足。
- 跨团队查看告警配置时可访问其他团队的监控指标数据。原因是未按`teamId`配置资源隔离规则，导致权限过滤失效。
- 告警变更记录中出现非本团队的操作日志。原因是未绑定操作人的`tmbId`与团队标识，导致权限校验缺失。

## 怎么确认配好了
- 切换不同团队的登录账号，验证仅可查看本团队关联的监控指标与告警规则
- 尝试提交其他团队的告警配置修改请求，确认操作被权限系统拦截
- 触发测试告警，确认通知仅发送至本团队绑定的通知链路
- 查看告警变更记录，确认仅显示本团队的操作日志与变更内容
