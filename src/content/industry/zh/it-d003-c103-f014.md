# 美术资产生产管理的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
通常包含美术PM、原画师、3D美术、外包管理人员日常产生的文档，包括美术需求单、资产规格、外包反馈表、验收记录。数据来源包括美术资产库、项目管理系统、引擎资源、外包交付包，更新频率为日或周。文档字段包含资产唯一标识、规格参数、交付时间、验收状态、外包方信息等，部分文档附带美术资源预览图或交付包文件，不同来源的数据结构存在差异。

## 这些特征在「模型接入与配置」这一环带来什么约束
美术资产生产管理的数据特征对模型接入与配置环节带来多项约束。首先，多源异构的数据格式要求模型支持适配不同来源的文档解析，需配置适配性参数。其次，日/周级别的更新频率要求模型上下文能够及时同步最新的资产信息，避免使用过期数据。再者，文档字段的多样性需要模型能够精准识别不同字段的关联关系，确保合规审查的准确性。最后，最耗时的规格确认、外包返修沟通、引擎导入检查环节，要求模型优先处理此类场景的召回与生成，优化审查效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配美术资产相关文档的长文本内容，避免截断关键的资产规格、验收要求等信息 |
| `maxTokens` | 2000–3000 token | 满足生成合规审查报告、外包返修说明等内容的长度需求 |
| `temperature` | 0.2–0.4 | 保持合规审查的严谨性，避免生成不符合资产规格的内容 |
| `vision` | 开启 | 支持对美术资产预览图、外包交付包截图的合规性检查 |
| `AIPROXY_API_TOKEN` | 配置与AI Proxy服务端一致的非空管理员Token | 作为App/Admin服务端的环境变量，用于AI Proxy服务身份验证，不得作为应用API调用凭证 |
| `AIPROXY_API_ENDPOINT` | 配置AI Proxy服务的根地址，例如http://aiproxy:3000 | 作为App/Admin服务端的环境变量，用于指向AI Proxy服务地址，不得附加/v1或模型服务路径 |

## 容易做错的三处
- 界面右上角无创建模型标识：现象为登录系统后未看到模型创建的入口按钮，原因是未开启对应权限或部署版本未支持模型自建功能，需检查FastGPT v4.17.0的权限配置。
- 模型响应速度不理想且硬盘消耗过高：现象为调用模型时响应缓慢，系统硬盘IO占用率偏高。排查项：检查`maxContext`和`maxTokens`参数配置是否符合业务需求，确认系统硬盘IO负载与模型调用情况匹配。
- 本地Docker部署可访问但OneApi无法连接：现象为本地Docker环境下模型调用正常，但通过OneApi转发的请求无法成功，排查项：检查`AIPROXY_API_ENDPOINT`是否配置为AI Proxy服务根地址，或网络策略是否限制跨服务访问。

## 怎么确认配好了
- 检查App/Admin服务端的环境变量配置，确认`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`已正确配置且非空。
- 发起一次针对美术需求单的合规审查测试，验证模型是否能正确提取资产规格字段并生成合规性说明。
- 查看系统日志，确认无模型调用超时或参数解析错误的记录，根据实际调用情况调整参数取值。
- 验证App/Admin服务启动时无环境变量缺失相关的校验错误，确认模型调用链路正常。
