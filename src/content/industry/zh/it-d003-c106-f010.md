# 语音标注与转写的安全与合规材料审查：引用来源与溯源

## 这个品类的数据长什么样
该品类的数据主要来自音频文件、标注平台、专有词表与抽检样本。日常关联文档包含转写规范、音频交付清单、质检报告、说话人标注表，数据按日或每批任务更新。数据字段涵盖音频时长、结构化转写文本、说话人标识、标注人员ID、质检结果，单位包含秒、字符、条等，核心围绕音频转写的结构化输出与全流程标注信息。

## 这些特征在「引用来源与溯源」这一环带来什么约束
音频类数据的非文本属性决定了引用溯源需绑定原始音频片段与转写文本的对应关系，需明确标注环节的来源节点。按日或每批更新的数据要求溯源信息需匹配任务批次，避免跨批次混淆。多文档关联的场景需要溯源时区分不同文档类型的引用权重，专有词表的引用需绑定专属来源标识。同时，噪声片段判断、说话人区分的标注结果需在溯源中保留修正痕迹，确保合规审查时可追溯标注流程的每一步。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 相似度阈值 | 0.75–0.85 | 匹配语音转写文本的语义特征，过滤噪声片段的误匹配结果 |
| 引用上限 | 前10条 | 适配单批次语音标注任务的文档体量，避免上下文溢出 |
| 重排开关 | 开启 | 优化语音转写文本的排序逻辑，提升相关片段的召回率 |
| `quoteMaxToken` | 1200–1500 字符 | 匹配语音转写文本的平均长度，确保完整引用关键片段 |
| `detail` | 开启 | 展示完整的标注流程与文档关联信息，满足合规审查要求 |
| 最大上下文 | 按实测标定 | 适配多文档关联的合规审查场景，避免超出模型处理上限 |

## 容易做错的三处
- 开启重排后出现检索结果为空或引用片段缺失。原因是未同步调整相似度阈值，重排机制过滤了原本处于阈值边缘的有效语音转写片段。
- 无法在开源版V4.8.22中配置自定义引用模板与提示词。原因是该功能仅在FastGPT v4.17.0及以上版本开放，旧版本仅支持基础参数调整。
- 设置的引用上限超出合理范围导致上下文加载失败。原因是未结合语音标注任务的文档体量配置参数，超出模型的上下文处理上限。

## 怎么确认配好了
- 上传单批次语音标注测试数据，触发合规审查流程，查看引用溯源模块是否显示原始音频链接、转写文本片段与标注文档的对应关系。
- 调整相似度阈值与重排开关，验证检索结果的数量是否符合预期，无明显空结果或冗余片段。
- 检查`quoteMaxToken`与`detail`参数配置，确认引用片段的长度匹配语音转写文本的平均字符量，且完整展示标注节点信息。
- 检查`responseData`参数是否开启，确保溯源接口返回完整的来源文档信息。
- 查看版本信息，确认当前运行的FastGPT版本为v4.17.0及以上，确保自定义配置功能可用。
