# 语音标注与转写的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据主要来自原始音频文件、标注平台产出的中间结果、行业专用词表以及抽检样本。日常配套文档包含转写规范、音频交付清单、质检报告与说话人标注表。数据更新按日或按项目批次进行，单批次数据体量随项目规模浮动。数据字段包含音频时长、说话人标识、转写文本片段、质检评分等，部分字段需匹配行业专有术语规范。

## 这些特征在「模型接入与配置」这一环带来什么约束
音频文件的非结构化特性要求模型需支持多模态输入适配，专有词表的存在要求配置中需加入术语对齐规则。按日或批次更新的数据需要适配动态配置刷新机制，避免模型使用过时的术语库。说话人标注表的结构化要求需模型能准确识别并区分不同说话人，对应配置需调整上下文关联逻辑。噪声片段的判断需求要求模型具备音频预处理相关的辅助能力，配置中需预留对应工具调用的接入空间。转写返工与交付延期的风险则要求配置需设置合理的超时与重试机制，保障任务执行稳定性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxTokens` | 8000–12000 | 匹配语音转写文本的平均长度，避免截断关键专有术语与说话人标注信息 |
| `temperature` | 0.2–0.4 | 降低随机生成概率，保障转写结果与专有词表的一致性，符合安全合规的固定格式要求 |
| `AIPROXY_API_ENDPOINT` | 按部署节点实际地址填写，为AI Proxy服务根地址，勿附加`/v1`等路径 | 为App/Admin服务端必需环境变量，适配语音标注场景的内网或专线访问需求，保障数据传输安全 |
| `maxContext` | 10 条会话记录 | 匹配单批次音频转写的上下文关联需求，避免跨批次数据混淆 |
| 单次任务超时阈值 | 600 秒 | 适配长音频文件的转写处理时长，避免因任务超时导致交付延期 |
| `AIPROXY_API_TOKEN` | 与AI Proxy服务端配置一致的非空管理员Token | 为App/Admin服务端必需环境变量，与`AIPROXY_API_ENDPOINT`配合使用 |

## 容易做错的三处
- 模型接入后检测失败，界面显示状态码400或无匹配模型。排查项：检查App/Admin服务端环境变量`AIPROXY_API_ENDPOINT`、`AIPROXY_API_TOKEN`是否配置正确且非空，符合v4.17.0及以上版本的启动校验要求。
- 同名但密钥不同的多个模型无法同时启用。原因是未在配置中区分模型标识字段，仅使用模型名称作为唯一识别依据，导致配置冲突。
- 转写结果中专有术语出现随机替换。原因是`temperature`参数设置过高，导致模型生成结果偏离预设的专有词表规范，不符合合规审查的固定格式要求。

## 怎么确认配好了
- 登录FastGPT v4.17.0后台，进入模型接入页面，检查已配置的模型列表中是否包含目标模型；检查App/Admin服务端环境变量`AIPROXY_API_ENDPOINT`、`AIPROXY_API_TOKEN`是否配置正确且非空，与服务部署值一致。
- 上传一条包含专有术语与多说话人的测试音频文件，发起转写任务，查看任务执行日志中是否有超时报错，确认`maxTokens`与单次任务超时阈值的配置是否正常生效。
- 查看转写结果中的专有术语与说话人标注是否符合预设规范，核对`temperature`参数的配置是否符合预期的生成稳定性要求。
- 配置多个同名不同密钥的模型，测试调用时是否能按指定密钥区分不同模型实例，确认配置的唯一性标识是否正确。
