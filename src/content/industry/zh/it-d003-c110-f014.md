# 运维外包驻场服务的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据通常来自客户ITSM系统、运维监控平台、内部资产清单与值班记录。日常产出的文档包含驻场日报、服务台工单、巡检报告与SLA月报，数据更新节奏以日度和月度为主。单份文档包含驻场人员标识、工单编号、巡检项名称、服务响应时段、资产编号等字段，不同文档的字段覆盖范围与更新频率存在差异。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据分散来源与多更新节奏，要求模型接入环节支持多源API对接与差异化的同步频率配置。不同文档的字段差异，需要模型能够适配非标准化的文本输入格式。驻场服务涉及客户内部资产与工单数据，对模型调用的合规性要求更高，需限制模型的推理模式与数据输出范围。月度SLA月报等长文本文档的处理，需要配置足够的上下文窗口与令牌限额，避免截断关键信息。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的逻辑制定。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配驻场日报、巡检报告等单份文档的长度需求，避免长文本截断 |
| `maxTokens` | 2000–3000 token | 满足合规材料审查的输出长度，覆盖工单总结、SLA统计等场景 |
| `toolChoice` | none | 限制模型仅进行文本生成，避免触发工具调用，符合驻场场景下的合规审查需求 |
| `temperature` | 0.1–0.3 | 降低输出随机性，确保合规审查结果的一致性与准确性 |
| `AIPROXY_API_ENDPOINT` | 填写AI Proxy服务的根地址，例如 http://aiproxy:3000，不得附加 /v1 或 /chat/completions | 为FastGPT App/Admin服务端必需环境变量，用于连接AI Proxy服务 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的非空管理员Token | 为FastGPT App/Admin服务端必需环境变量，用于AI Proxy服务鉴权 |

## 容易做错的三处
- 现象：模型输出包含推理模式相关内容，无法限制仅使用文本生成模式。原因：未正确配置`toolChoice`参数，或参数取值未匹配目标模型支持的模式。
- 现象：配置阿里云模型接入时提示拒绝访问，使用其他平台接入无此问题。原因：上游模型渠道配置（如阿里云模型的供应商凭证、接口地址）错误，未适配阿里云的接口访问规则。
- 现象：添加同名的嵌入模型配置后，原有配置被自动覆盖，无法保留多版本配置。原因：未为不同模型配置添加唯一标识，导致同名配置项被覆盖。

## 怎么确认配好了
- 上传单份驻场日报文档，触发模型审查，查看输出内容是否符合合规要求，调整参数至输出符合预期。
- 测试接入多类数据源的文档，确认来自ITSM系统、监控平台的内容均可被正常读取与处理。
- 检查接口访问日志，确认无拒绝访问或超时报错，验证`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置有效。
- 尝试添加带有唯一标识的多个模型配置，确认同名配置不会被自动覆盖，确保多模型调用的稳定性。
