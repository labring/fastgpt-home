# 配置管理与CMDB维护的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的日常文档包含配置项清单、服务关系拓扑、变更记录、资产盘点表四类核心文件。数据来源涵盖CMDB系统、云资源清单、自动发现工具与采购台账，更新频率为每日或每周。字段包含配置项唯一标识、资产类型、关联依赖项、变更时间、所属环境等，单位涵盖台、个、天等基础资产计量与时间单位，数据结构以结构化表格与链路拓扑文本为主。

## 这些特征在「模型接入与配置」这一环带来什么约束
多数据源的混合输入要求模型接入配置适配不同格式的资产数据，需确保上下文窗口能覆盖全量合规审查所需的配置项与变更信息。日/周级别的更新频率要求配置匹配数据刷新节奏，避免使用过期的资产数据进行合规校验。结构化的依赖关系字段则要求配置支持自动工具调用，以完成配置项间的依赖合规性检查，同时需平衡严谨性与响应速度，避免过度宽松的参数导致审查结果不符合要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配CMDB配置项清单、关系拓扑等多文档的总长度，覆盖日/周更新的全量合规审查数据 |
| `maxTokens` | 2000–3000 token | 限制模型输出的合规审查报告长度，避免超出平台或模型的输出上限 |
| `temperature` | 0.1–0.3 | 平衡合规审查的严谨性与响应速度，避免生成不符合合规要求的内容 |
| `toolChoice` | auto | 自动调用工具校验配置项间的依赖关系，适配CMDB的拓扑结构合规审查 |
| `AIPROXY_API_ENDPOINT` | http://aiproxy:3000（替换为实际AI Proxy服务根地址） | AI Proxy 服务的根地址，不得附加 /v1 或其他API路径后缀，非单模型服务地址 |
| `quoteMaxToken` | 1500 token | 确保引用的配置项变更记录、资产盘点数据完整，不截断关键合规信息 |

本配置说明基于FastGPT v4.17.0版本。

## 容易做错的三处
- 调用时返回`model response empty`报错。排查项：检查服务端是否已配置`AIPROXY_API_ENDPOINT`（AI Proxy服务根地址）与非空`AIPROXY_API_TOKEN`（AI Proxy管理员Token），未配置会导致启动校验失败或代理转发异常。
- 合规审查结果中未包含配置项关系拓扑的相关校验内容。原因是未开启`toolChoice`自动工具调用，或`maxContext`设置过小，无法完整加载拓扑数据。
- 多模型接入时出现单节点过载无法响应。原因是未配置代理的负载均衡逻辑，仅使用单一模型节点处理请求，未适配多数据源的并发调用需求。

## 怎么确认配好了
- 发起测试调用，输入一份CMDB配置项清单，确认返回的合规审查结果包含配置项的合规性校验内容。
- 核对服务端环境变量`AIPROXY_API_ENDPOINT`（AI Proxy服务根地址）与非空`AIPROXY_API_TOKEN`（AI Proxy管理员Token）的配置，验证代理可正常转发请求并获取模型响应。
- 上传一份CMDB变更记录文档，验证模型是否能正确关联配置项与变更审批状态，生成完整的合规审查报告。
- 调整`maxContext`参数，确认大模型能完整加载多份CMDB文档的内容，无关键信息截断情况。
