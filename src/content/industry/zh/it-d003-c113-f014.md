# 集成测试与接口测试的安全与合规材料审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源于接口管理平台、测试环境日志、数据库、消息队列，更新频率为日或每版本。日常产出的文档包含接口测试用例、联调问题单、环境说明、测试报告，其中接口测试用例包含接口地址、请求方法、参数列表、预期响应，联调问题单包含错误码、报错信息、调用链路，测试报告包含整体通过率、异常统计等字段。数据结构相对固定，且会随接口迭代或测试版本更新发生变化。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散且格式各异，要求模型接入配置支持多格式的输入解析，适配不同来源的日志、用例文档。更新频率较高，要求配置的参数校验逻辑能快速适配新增的接口字段，避免因字段变更导致模型解析失效。日常文档的结构固定，要求模型的prompt配置能匹配固定的文档字段，确保从测试用例、联调问题单中提取的信息准确。出错后果直接影响联调进度，要求配置中加入超时、重试机制，降低因模型调用异常导致的联调延期风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填写AI Proxy服务的根地址，例如http://aiproxy:3000，无多余空格，不要附加/v1或/chat/completions等路径，不得使用VLLM/Ollama/Xinference等单模型地址，不得在工作流全局变量、应用API请求头或普通模型管理页面填写以替代服务部署配置 | 用于指定AI Proxy服务的根地址，确保请求能正确路由到AI Proxy服务 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的管理员Token，不能为空，不得使用应用API Key、模型供应商密钥等其他类型的凭证，不得在工作流全局变量、应用API请求头或普通模型管理页面填写以替代服务部署配置 | 用于AI Proxy服务的身份验证，确保请求合法性 |
| `maxContext` | 8000–12000 token | 适配接口测试用例、联调问题单的整体上下文长度，避免内容截断导致解析不全 |
| `maxTokens` | 2000–4000 token | 满足接口参数校验、链路问题定位的结果输出长度需求 |
| `temperature` | 0.1–0.3 | 降低模型生成结果的随机性，确保接口参数校验逻辑的准确性 |
| `toolChoice` | auto | 让模型自动选择是否调用接口校验工具，适配不同的测试场景 |

## 容易做错的三处
- 现象：新增的第三方模型未出现在可用列表中，调用时提示找不到渠道。排查项：检查服务端`AIPROXY_API_ENDPOINT`、`AIPROXY_API_TOKEN`环境变量是否配置正确，参数是否包含多余的换行、空格字符，未配置必填变量将导致启动校验失败
- 现象：在对话模块可选择自定义模型，但在文本提取环节的模型列表中无法看到该模型。排查项：检查上游模型渠道参数配置是否正确，服务端`AIPROXY_API_ENDPOINT`、`AIPROXY_API_TOKEN`环境变量是否配置无误
- 现象：模型调用返回的校验结果与实际接口参数不符，出现参数误判。排查项：检查`temperature`参数取值是否过高，当前取值是否超出建议范围

## 怎么确认配好了
- 在FastGPT v4.17.0的模型管理页面，查看已添加的模型是否出现在可用模型列表中。
- 上传一条标准的接口测试用例文档，触发模型调用，检查返回结果是否包含接口参数校验、链路问题定位的相关内容。
- 模拟联调问题单的输入，确认模型能正确提取其中的错误码、接口地址等关键信息。
- 查看测试环境的日志，确认模型调用的请求参数与配置的`maxContext`、`maxTokens`等参数一致。
