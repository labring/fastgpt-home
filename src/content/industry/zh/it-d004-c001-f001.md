# CDN与边缘加速配置的客户技术支持与售前答疑：HTTP 接口与外部系统

## 这个品类的数据长什么样
通常的数据源包括CDN控制台、DNS解析记录、公网访问日志、节点监控告警；日常产出的文档包括域名接入单、缓存规则配置表、刷新预热操作记录、故障分析报告；数据更新频率为每日或随配置变更实时更新；数据字段包含域名、缓存规则ID、节点IP、访问状态码、缓存命中率等，仅按业务场景结构化存储，无固定统一的统计口径。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
由于数据来源依赖CDN开放API拉取，HTTP接口需要适配CDN官方的鉴权规则与参数格式；数据更新频率为日或实时变更，接口的轮询间隔需匹配该节奏，避免数据过时或产生冗余请求；日常业务文档的字段要求接口返回结构化的业务数据，需包含域名、缓存规则等核心字段；面向公网内容分发的特性要求接口需适配跨域访问与公网网络环境的稳定性要求，同时需处理节点故障、缓存错乱等异常场景的错误反馈。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | CDN控制台生成的API鉴权令牌 | 符合CDN开放API的官方鉴权要求 |
| `variables` | 包含目标域名、缓存规则ID、告警阈值的键值对 | 匹配日常业务文档的核心字段要求 |
| `responseData` | 包含访问状态码、节点IP、缓存命中情况的结构化数据 | 对齐故障分析报告的输出标准 |
| 接口轮询间隔 | 300–600 秒 | 匹配CDN数据的日/实时更新频率 |
| 鉴权方式 | CDN官方的签名鉴权 | 保障接口调用的安全性 |
| 数据时间范围 | 仅返回近24小时的访问日志 | 符合日常运维的查询习惯 |

## 容易做错的三处
- 工作流调试时出现接口鉴权失败报错，返回401状态码，原因是误将AI Proxy管理员Token作为CDN接口的鉴权参数。
- 调用接口后返回数据为空，原因是未在`variables`中配置正确的目标域名或缓存规则ID。
- 接口请求返回超时错误，原因是轮询间隔设置过短，超出CDN控制台API的限流阈值。

## 怎么确认配好了
- 调用CDN开放API拉取近1小时的访问日志，检查返回的`responseData`包含预期的业务字段。
- 查看FastGPT工作流日志，确认`Authorization`鉴权参数被正确携带且返回200状态码。
- 核对`variables`中配置的域名与实际接入的CDN域名完全一致。
- 模拟触发缓存规则变更，检查接口是否能同步拉取最新的规则配置数据。
