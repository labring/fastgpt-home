# 云主机交付与资源开通的客户技术支持与售前答疑：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据主要来自云管理平台、订单系统、IAM权限系统与计费系统。日常流转的文档包括资源开通单、实例配置表、账号权限单与交付确认单。数据更新节奏为每单实时同步，单条数据包含实例ID、计算规格、网络安全组配置、权限绑定范围、交付状态等字段，单位多为核心数、GB、秒级时间戳，无聚合统计类批量数据。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多源数据来源要求HTTP接口需对接云管理平台、订单系统等多个独立端点，需兼容不同系统的鉴权格式。实时更新节奏要求接口超时阈值需适配单条资源的创建周期，避免超时中断未完成的交付流程。文档字段的多样性要求请求体需覆盖计算规格、安全组配置、权限绑定等核心参数，且需支持按单条订单维度拉取数据。同时，该品类仅聚焦计算资源交付，接口无需兼容网络负载均衡类的扩展配置。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本编写。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | 携带Bearer Token的鉴权格式 | 适配云管理平台的标准API鉴权规则 |
| 接口超时时间 | 600–900 秒 | 覆盖单台云主机从创建到交付的平均耗时 |
| 请求批次大小 | 1–3 单/次 | 避免单次拉取过多订单数据导致接口负载过高 |
| `variables` | 绑定实例ID、订单号作为全局变量 | 实现跨系统数据的关联传递 |
| `responseData` | 仅返回实例状态、交付时间字段 | 减少无效数据传输，适配售前答疑的快速查询需求 |
| 代理配置 | 1080–1088 端口，按实测标定的用户名与密码 | 适配内网部署场景的网络访问需求 |

## 容易做错的三处
- 现象：接口请求返回403鉴权失败或无法连通外部云系统。原因：仅配置了代理IP与端口，未填写代理所需的用户名与密码，无法通过内网环境的代理鉴权。
- 现象：调用接口后返回`Data too long`类报错。原因：未限制`responseData`返回的字段长度，导致超长参数写入本地存储时触发数据库限制。
- 现象：跨设备使用免登录链接时无法加载接口关联的资源数据。原因：未在接口配置中绑定`variables`中的订单号参数，导致不同设备的请求无法匹配对应资源上下文。

## 怎么确认配好了
- 发起单条云主机资源开通的模拟请求，核对`responseData`返回的字段是否包含预期的实例ID与交付状态。
- 配置代理参数后，从内网环境调用外部云管理平台接口，确认可以正常连通并拉取数据。
- 调整接口超时阈值，模拟长耗时的资源创建流程，确认接口不会提前中断请求。
- 检查`Authorization`鉴权参数的格式，确认符合对接系统的鉴权规则，无格式错误。
