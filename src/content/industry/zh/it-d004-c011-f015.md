# 云主机交付与资源开通的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据主要来自云管理平台、订单系统、IAM权限系统与计费系统，日常文档包含资源开通单、实例配置表、账号权限单、交付确认单。单条数据关联单台云主机实例，包含实例规格、部署区域、网络配置、权限绑定信息与交付状态字段，更新节奏为每单实时同步，单次交付流程的数据量随实例数量线性增长。

## 这些特征在「知识库检索与召回」这一环带来什么约束
由于该品类数据按交付单实时更新，知识库需支持增量同步订单、权限与计费数据，避免检索到过期信息。单条交付数据包含实例规格、区域、权限等强关联字段，检索时需优先匹配用户提问中的实例ID或区域关键词，缩小召回范围。同时，交付流程中的规格核对、安全组配置环节依赖高频复用的配置文档，需确保这些文档被优先召回，减少人工核对耗时。此外，不同交付单的数据结构高度统一，检索时可通过固定字段快速定位相关文档，无需泛化搜索全量知识库。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的知识库检索模块设置：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配该品类中实例规格、区域这类强相关字段的精准度要求，避免召回无关的云网络配置文档 |
| `limit` | 前8条 | 该品类单次交付流程的关联文档数量通常不超过7条，保留冗余量确保覆盖所有必要配置 |
| `searchMode` | semantic | 匹配用户提问中的实例ID、规格关键词，相比关键词匹配更适合处理自然语言的售前咨询 |
| `usingReRank` | 开启 | 交付配置中的安全组、权限规则存在语义相近的条目，重排可提升高相关文档的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可将用户提问中的实例规格自动扩展为匹配的配置文档关键词，降低检索漏检概率 |
| `collectionIds` | 绑定云主机交付专属知识库集合 | 避免召回其他品类（如云网络）的配置文档，缩小检索范围 |

## 容易做错的三处
- 现象：检索时无法正确引用实例规格变量，原因：未在检索配置中开启变量映射功能，导致提问中的变量未被正确替换为文档中的字段值。
- 现象：csv格式的交付确认单导入后无法被检索到，原因：未使用模板导入功能直接上传csv，导致文档字段未被正确映射，无法生成有效向量化结果。
- 现象：检索时无法加载历史交付单的向量化结果，原因：未正确配置知识库的向量存储关联路径，导致系统无法读取已生成的向量化数据。

## 怎么确认配好了
- 上传一份测试用的资源开通单文档，在测试界面输入包含实例ID的提问，核对检索结果是否包含该文档。
- 调整`similarity`阈值为0.7，再调整为0.9，观察检索结果条数变化，确认阈值设置符合业务需求。
- 开启`usingReRank`后，输入包含安全组配置的提问，核对高相关文档的排序是否提前。
- 查看知识库集合绑定情况，确认仅绑定了云主机交付专属的数据集，无其他品类的集合混入。
