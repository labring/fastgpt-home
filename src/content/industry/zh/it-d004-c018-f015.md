# 企业软件许可证管理的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据由软件资产管理系统、采购系统、终端扫描结果及厂商授权文件生成，日常文档包含许可证台账、软件使用清单、采购合同与合规审计报告。数据更新周期为月或季度，字段包含软件名称、授权数量、授权类型、安装终端数、续费到期日等，单位多为台、套、天，需严格匹配软件授权与实际安装使用的对应关系，核心围绕软件授权合规性展开。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散且更新周期较长，检索时需优先匹配最新的月度或季度更新的台账数据，避免调用过期信息引发合规风险。字段包含多维度的授权与安装对应关系，单一关键词召回易出现匹配偏差，需同时关联软件名称、授权编号、终端信息等多个字段。文档类型多样，需支持跨文档关联检索，例如将采购合同中的授权条款与台账的实际使用情况结合，且需规避非合规数据的召回，保障检索结果符合审计要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 匹配许可证台账的精准字段，避免低相似度的无关授权信息混入 |
| `limit` | `前 6–10 条` | 覆盖单条咨询可能涉及的多款软件授权，同时控制上下文长度 |
| `searchMode` | `keyword + semantic` | 兼顾关键词匹配授权编号、语义匹配咨询场景的合规需求 |
| `usingReRank` | `开启` | 对召回结果按合规相关性重新排序，优先展示高优先级的授权与使用数据 |
| `datasetSearchUsingExtensionQuery` | `关闭` | 避免扩展查询引入非本品类的无关IT资产数据 |
| `collectionIds` | `指定许可证管理专属知识库ID` | 限定检索范围，仅调用本品类的台账、合同等合规文档 |

本配置基于FastGPT v4.17.0版本。

## 容易做错的三处
- 现象：调用知识库检索时提示“当前分组 default 下对于模型 gpt-4o-mini 无可用渠道”，原因：未将许可证管理专属知识库绑定至对应模型的渠道分组，或分组配置未关联正确的API密钥。
- 现象：检索结果包含季度前的过期许可证数据，原因：未配置按更新时间过滤召回结果，或数据源未同步最新的月度或季度更新数据。
- 现象：检索结果中混入IT资产盘点的无关设备数据，原因：未限定`collectionIds`为专属知识库ID，导致跨品类的非授权管理数据被召回。

## 怎么确认配好了
- 检索包含“2024年第三季度许可证台账”的咨询，确认召回结果仅包含本品类的文档，无其他IT资产类数据。
- 调整`similarity`参数，验证召回结果的匹配度符合预设区间，无低相关性的冗余内容。
- 检查`limit`参数，确认单次召回的结果条数符合预设值，避免上下文过长超出模型限制。
- 模拟续费到期提醒类咨询，确认召回的授权到期日数据与最新台账一致。
