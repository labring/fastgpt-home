# 信息流广告创意测试的客户技术支持与售前答疑：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据主要来自广告平台API、内部素材库、用户互动数据与投放转化数据，更新节奏多为日度或周度。日常关联文档包括创意脚本、素材测试表、投放数据报告与迭代清单，数据字段包含素材类型、文案内容、投放时段、点击率、转化成本等，单位涵盖次、元、小时等，数据体量随测试规模动态调整，不同测试任务的数据结构存在细微差异。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
数据来源分散且涉及多类外部系统，需要HTTP接口适配不同平台的鉴权格式与数据返回结构，避免因接口不兼容导致同步失败。更新节奏的差异要求接口配置灵活的触发间隔，日度数据需设置每日同步任务，周度数据可调整为每周触发。日常文档结构多样，接口需支持传入匹配不同文档的参数，确保创意脚本、素材测试表等数据可正确传递。数据体量动态变化，需配置合理的批量请求阈值与超时时间，避免单次请求过载或超时中断。

## 配置怎么定
以下配置适用于 FastGPT v4.17.0 版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `Authorization` | `Bearer {FastGPT API密钥}` | 符合HTTP接口鉴权标准，适配外部广告平台与系统的鉴权要求 |
| `variables` | `{"素材类型": "视频/图片", "投放时段": "每日9-21点"}` | 传递创意测试的核心变量，匹配素材测试表的字段结构 |
| `responseData` | `仅返回素材ID、点击率、转化成本` | 过滤冗余数据，适配投放数据报告的提取需求，减少接口传输负载 |
| 批量请求阈值 | 单次最多50条 | 匹配广告平台API的批量调用限制，避免触发限流机制 |
| 请求超时时间 | 300 秒 | 适配日度批量数据拉取的耗时需求，避免中途中断同步任务 |

## 容易做错的三处
- 调用批量添加数据接口后未返回数据ID，无法与本地系统完成映射。原因：未正确配置`responseData`参数，未指定返回数据ID字段。
- 接口请求频繁触发超时，大量素材数据同步失败。原因：请求超时时间设置过短，未适配日度批量数据拉取的实际耗时。
- 鉴权失败，无法连接外部广告平台接口。原因：`Authorization`参数格式错误，未添加Bearer前缀或密钥配置有误。

## 怎么确认配好了
- 调用测试接口，检查返回的`responseData`是否包含预期的业务字段，确认参数配置与创意测试需求匹配。
- 发起单次小批量请求，验证鉴权参数`Authorization`有效，接口可正常返回测试数据。
- 设置定时触发任务，检查数据同步频率与业务更新节奏（日度/周度）是否符合预期配置。
- 模拟大流量请求，确认接口负载阈值设置合理，未触发限流或超时规则。
