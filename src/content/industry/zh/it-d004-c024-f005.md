# 信息流广告创意测试的客户技术支持与售前答疑：多轮对话与提示词

## 这个品类的数据长什么样
信息流广告创意测试的相关数据通常来自广告投放平台、素材库、用户互动数据与转化数据，更新频率多为日度或周度。日常产出的文档包含创意脚本、素材测试表、投放数据报告与迭代清单，核心字段涵盖创意变量组合、素材疲劳度评分、点击量、转化成本与合规状态。该品类的核心工作环节中，创意变量设计、素材疲劳判断与测试结论归纳较为耗时，异常情况可能导致点击率下降、投放成本升高或素材违规。与搜索广告品类不同，其核心对比维度为图片、视频与文案的组合效果。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
品类的数据来源分散且更新节奏固定，要求多轮对话流程需逐步引导用户提供对应文档的专属字段，避免遗漏关键信息。日常文档的固定结构，要求提示词预设标准化的字段提取规则，适配创意脚本、素材测试表等固定格式的内容输入。核心耗时环节的归纳工作，需要多轮对话逐步拆解测试结论，避免一次性输出过载的信息。异常后果的严重性，要求对话流程中加入合规性检查的前置提示，提前规避素材违规风险。同时，跨周的测试迭代需要对话上下文保留更长周期的历史信息，匹配周度数据的更新节奏。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chatId` | 绑定广告账户唯一标识 | 确保每个信息流优化师的对话历史与专属投放账户关联，FastGPT v4.17.0支持该配置 |
| `messages` | 保留前20条对话上下文 | 覆盖单次测试周期内的变量调整与数据反馈，避免上下文过长导致推理延迟 |
| `variables` | 注入素材测试表字段、投放数据周期 | 自动填充品类专属文档的固定字段，减少手动输入的操作成本 |
| 历史对话保留时长 | 7 天 | 匹配周度投放数据的更新周期，确保跨周测试的上下文连贯 |
| 单轮回复最大 token | 1500 token | 适配创意测试结论归纳的内容长度，避免截断关键信息 |

## 容易做错的三处
- 现象：未绑定`chatId`时，不同优化师的对话历史混合显示。原因：未将对话标识与广告优化师的专属账户关联，导致上下文隔离失效。
- 现象：工作流中多个<AI对话>节点的回复全部出现在最终对话中。原因：未为每个工作流节点配置独立的上下文隔离规则，导致多轮节点的输出未做截断或隔离。
- 现象：搭建工作流时，问题分类节点仅支持单次提问，无法实现多轮问答与反问。原因：提示词未预设针对品类专属文档的反问逻辑，未配置多轮对话的上下文延续规则。

## 怎么确认配好了
- 输入测试用的广告账户标识，发起第一条对话，更换浏览器或设备后重新发起，确认对话历史未丢失。
- 配置`variables`后，在对话中触发提示词，检查是否自动注入了预设的素材测试表字段与投放数据周期。
- 发起多轮测试，调整创意变量并提交测试数据，确认对话上下文保留了之前的变量信息与反馈内容。
- 触发工作流中的<AI对话>节点，检查仅当前节点的回复出现在最终对话中，无冗余历史节点输出。
