# 内容审核规则运营的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
内容审核规则运营的日常文档包含审核规则、处置指南、申诉记录、质检报告，数据来源为内容审核后台、用户举报、法规政策、样本库。文档结构包含规则编号、适用场景、处置阈值、申诉流程等字段，更新频率为每日同步或随政策法规变更触发更新，需支持按规则类型、场景关键词快速定位检索。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据更新频率高且随政策变更触发，要求检索链路支持近实时的知识库同步，避免使用过期规则。文档包含明确的规则编号与场景字段，需支持多维度的精准匹配，兼顾语义与关键词检索。审核场景的出错后果直接关联合规风险，要求召回结果的匹配精度需维持在较高区间，避免误召回无关规则或遗漏关键条款。数据覆盖多类审核场景，需限定检索范围至专属数据集，防止跨业务数据干扰检索结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 审核规则需高匹配度，避免误判合规或违规场景 |
| `limit` | `前8–12条` | 覆盖常见审核场景的同时，控制上下文长度避免冗余 |
| `searchMode` | `语义匹配+关键词混合` | 适配审核规则既有语义场景又有明确关键词的结构 |
| `usingReRank` | `开启` | 提升复杂规则组合的召回准确性，降低误召回概率 |
| `datasetSearchUsingExtensionQuery` | `开启` | 优化用户问题到审核规则术语的匹配精度 |
| `collectionIds` | `指定审核规则专属数据集ID` | 隔离业务数据，避免申诉记录、质检报告等无关内容干扰检索 |

## 容易做错的三处
- 调试预览阶段检索正常，嵌入自有页面后无法触发知识库搜索，返回空结果或非预期内容。排查项：确认应用API请求使用应用专属API Key鉴权，未将AI Proxy管理员Token用作请求鉴权参数。
- 导入Markdown格式的审核规则文档后无法被检索到，或检索结果未匹配到规则内容。原因是未提取文档中的规则编号、适用场景作为检索字段，未配置文档分块的关键词映射。
- 检索结果返回条数与配置的`limit`不符，超出或少于预设数量。原因是未正确指定`collectionIds`，检索范围覆盖了多个数据集，导致结果条数超出预期。

## 怎么确认配好了
- 检查FastGPT v4.17.0版本的服务端环境变量，确认已配置`AIPROXY_API_ENDPOINT`（AI Proxy服务的根地址，不得附加`/v1`或其他路径后缀）和非空的`AIPROXY_API_TOKEN`（与AI Proxy服务端配置一致的管理员Token）。
- 触发一次测试检索，核对返回结果的匹配分值是否落在配置的`similarity`区间内。
- 查看检索结果的数据集来源，确认仅包含`collectionIds`指定的审核规则专属数据集。
- 验证开启`usingReRank`后，复杂规则组合的检索结果排序是否符合预期。
