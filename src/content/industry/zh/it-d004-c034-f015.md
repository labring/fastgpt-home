# 办公系统流程配置的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
办公系统流程配置的相关数据通常来自企业OA系统、组织架构目录、内部制度文件与用户反馈工单。日常维护的文档包括流程配置单、审批节点表、表单字段说明、流程变更记录。数据更新随业务流程变更触发，平均每月至少一次。文档多为结构化表格与文本结合的形式，包含审批路径、权限范围、字段校验规则等核心字段，无统一固定单位，部分配置项以节点数、权限组为标识。

## 这些特征在「知识库检索与召回」这一环带来什么约束
办公系统流程配置的数据特征对检索召回带来多重约束。跨多源的数据来源要求检索覆盖OA系统、制度文件、用户反馈等多个数据集，避免召回范围缺失。结构化的表格与文本混合文档，需要适配字段级匹配，确保审批节点、权限规则等精准内容被召回。按月更新的节奏要求知识库同步周期匹配业务变更频率，防止召回过时的流程配置内容。用户反馈类的场景化数据，需要支持结合具体报错关键词的定向检索，提升匹配效率。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本编写。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.65–0.75 | 办公系统流程配置的配置项多为精准规则，过低阈值会引入无关审批节点配置，过高阈值可能遗漏有效内容，按实测标定适配场景 |
| `limit` | 前8–12条 | 单条流程配置内容篇幅适中，过多召回会超出上下文窗口，过少无法覆盖完整审批路径，按业务场景调整 |
| `searchMode` | hybrid | 兼顾关键词匹配与语义召回，适配结构化配置单与场景化用户反馈的混合检索需求 |
| `usingReRank` | 开启 | 流程配置的权限、节点等内容语义相近，重排可提升高相关结果的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可基于用户提问自动补充流程相关的关键词，比如将“审批卡住”扩展为“审批节点配置 权限异常” |
| `collectionIds` | 按业务流程分组指定 | 区分不同业务线的流程配置数据集，避免召回无关系统的配置内容 |

## 容易做错的三处
- 现象：设置较低`similarity`与最大`limit`后，召回结果条数未随参数调整增长，维持固定数值。原因：部分数据集设置了固定召回上限，或系统对单数据集的召回条数做了隐性限制，未同步开放全部召回额度。
- 现象：知识库中显示的结构化表格内容，在最终输出结果中未展示表格格式。原因：检索召回时未开启结构化内容的格式保留配置，或流程配置类文档的表格块未被正确识别为结构化数据。
- 现象：无法按不同业务知识库分别输出对应内容。原因：未通过`collectionIds`指定对应数据集，或检索逻辑未绑定业务分组与知识库的映射关系。

## 怎么确认配好了
- 提交包含审批节点、权限配置的测试提问，核对召回结果的条数是否符合`limit`设置的区间。
- 检查召回结果的相似度分值，确认是否落在`similarity`设置的范围内。
- 上传测试用的流程配置表格文档，验证输出结果是否保留表格格式。
- 切换不同业务分组的`collectionIds`，核对召回结果是否仅来自指定数据集。
