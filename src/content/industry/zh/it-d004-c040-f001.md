# 售前技术方案的客户技术支持与售前答疑：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类属于IT服务外包与系统集成下的售前技术方案，服务电子、互联网、IT领域的客户技术支持与售前答疑场景。数据主要来自客户访谈、招标文件、厂商产品资料及历史项目方案，更新频率为每单或每周。日常产出的文档包括技术方案书、客户需求调研表、报价清单、演示脚本，文档结构通常包含技术路线说明、实施边界界定、资源配置清单、报价明细等字段，无统一强制单位，字段随客户需求及项目类型调整。典型使用主体为系统集成商售前顾问、解决方案架构师与销售团队，最耗时环节集中在需求澄清、方案边界设计与报价配置核对，出错后果包括投标失分、承诺超范围或项目亏损，与投标文件编制的差异在于前者优先明确技术路线与实施边界。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据来源分散且随项目动态更新，因此HTTP接口需支持按需拉取不同来源的文档片段，且需兼容多格式输入。由于更新频率为每单或每周，接口需支持短周期增量同步，避免全量拉取占用过多资源。日常文档包含技术路线、实施边界等核心字段，接口参数需精准匹配这些字段的传递，避免字段缺失导致方案内容偏差。出错后果较为严重，因此接口需包含完整的错误捕获与重试机制，防止因调用失败导致方案编制中断。此外，主体人员需频繁核对方案细节，接口响应时长需适配长周期校验的业务需求，避免因超时中断核心流程。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer ${API_KEY}` | 符合FastGPT官方接口认证规范，保障调用安全，适配多项目权限隔离需求 |
| `variables` | 按项目需求传入客户名称、技术参数等自定义变量，取值区间为10-20个/次请求 | 匹配售前技术方案单份文档的核心参数数量，避免参数过载导致接口报错 |
| `responseData` | 仅返回技术路线、实施边界、报价明细字段 | 聚焦售前技术方案的核心输出内容，减少冗余数据处理与传输成本 |
| 超时时间 | 600秒 | 匹配售前方案编制的长周期校验需求，避免因超时中断配置核对流程 |
| 重试次数 | 3次 | 平衡接口调用成功率与资源消耗，适配多源数据拉取的不稳定场景 |

## 容易做错的三处
- 现象：调用对话接口时传入图片URL，返回结果为空或提示参数无效。原因：未正确配置`variables`参数的图片字段校验规则，或传入的URL未满足接口格式要求。
- 现象：调用知识库目录创建接口时，返回401状态码。原因：未正确设置`Authorization`参数，或API密钥权限不足，无法访问对应资源。
- 现象：将HTTP请求获取的JSON数据传入另一个HTTP请求时，字段中出现大量转义反斜杠。原因：未对`responseData`返回的JSON数据进行转义处理，导致二次请求时格式异常。

## 怎么确认配好了
- 调用`Authorization`认证接口，返回200状态码，确认认证配置有效。
- 传入预设的`variables`参数，检查接口返回结果是否包含对应自定义字段，验证参数传递逻辑正常。
- 传入测试用的JSON数据，检查`responseData`返回的字段是否符合预设筛选规则，确认数据过滤配置生效。
- 模拟长周期请求，确认接口未触发超时中断，验证超时配置适配业务场景。
