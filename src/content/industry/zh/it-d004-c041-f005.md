# 图像标注项目的客户技术支持与售前答疑：多轮对话与提示词

## 这个品类的数据长什么样
图像标注项目的数据主要来源于标注平台上传的图片样本、预设的类别字典、标注过程产生的框选记录，以及后续的质检报告与返工清单。数据更新节奏为每日更新或按标注批次更新，每批标注任务对应独立的数据集合。日常流转的文档包含统一标注规范、标准框选样例、单次任务质检结果，以及标注返工的明细清单。数据字段包含视觉目标的边界框坐标、类别标签、抽检判定结果等，无额外统一单位要求，仅按标注任务的具体规则匹配字段格式。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
图像标注项目的数据特征对多轮对话与提示词配置带来多项约束。首先，数据包含视觉类的图片样本与边界框坐标，提示词需明确区分视觉目标描述与文本标注规则，避免混淆两类信息。其次，日常文档包含标注规范、质检报告等结构化内容，多轮对话需支持关联指定批次的标注文档，避免跨批次数据干扰当前任务。另外，数据按日或按批次更新，对话上下文需限制单轮会话的有效数据范围，防止加载过期的返工清单或旧版标注规范。同时，字段包含边界框坐标等非文本内容，提示词需明确指定输出格式，确保标注结果符合团队的统一要求。

## 配置怎么定
以下配置适配FastGPT v4.17.0版本，针对图像标注项目的客户技术支持与售前答疑场景优化。

| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| 最大上下文长度 | 8000–12000 字符 | 图像标注项目的文档包含标注规范、框选样例等长文本，需保留足够的上下文信息确保规则匹配 |
| `variables` | 绑定标注批次ID、类别字典字段 | 图像标注项目的数据按批次更新，通过变量绑定批次信息可精准关联对应批次的标注文档 |
| `messages` | 限制单轮会话历史保留前10条对话 | 避免过多历史对话干扰当前标注任务的提示词匹配 |
| 问题优化 | 开启 | 标注相关的技术问题通常表述模糊，优化后可提升规则匹配的准确性 |
| `chatId` | 按标注任务ID生成唯一会话ID | 区分不同标注团队的会话数据，避免跨任务的上下文混淆 |
| 单次搜索上限 | 前3条 | 标注相关的文档通常集中在少数几个规范或样例中，过多搜索结果会干扰提示词的精准性 |

## 容易做错的三处
- 现象：模型输出语言与预设prompt要求不符，例如预设英文回答指令但仅返回中文内容。原因：未在提示词中明确绑定知识库的语言属性，或`variables`未配置语言变量覆盖默认模型输出规则。
- 现象：上传标注图片样本后，解析环节返回报错。原因：未在`messages`中配置文件解析的触发规则，或配置的上下文长度不足以容纳图片解析后的元数据。
- 现象：对话详情页无法查看应用内部的交互记录。原因：未开启会话日志存储配置，或`chatId`未正确关联到当前会话的日志索引。

## 怎么确认配好了
- 发起包含标注规范关键词的对话，核对模型返回的内容是否匹配预设的标注规则。
- 上传单张标注图片样本，检查解析环节是否正常返回图片元数据。
- 生成新的`chatId`发起会话，确认会话详情页可查看完整的交互日志。
- 配置英文提示词后发起对话，核对模型输出语言是否符合预设要求。
