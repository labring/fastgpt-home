# 图像标注项目的客户技术支持与售前答疑：重排与混合检索

## 这个品类的数据长什么样
图像标注项目的数据主要来自标注平台产出的图片样本、类别字典、抽检结果与返工清单。日常维护的文档包含标注规范、框选样例、质检报告、返工清单四类，字段涵盖目标类别、边界框坐标、抽检判定结果、返工要求等。数据更新以日度或单批次标注任务为节奏，随标注进度同步更新。数据围绕视觉目标的位置与类别展开，区别于文本标注的语义内容处理，核心聚焦于图像内实体的空间定位与类别识别。

## 这些特征在「重排与混合检索」这一环带来什么约束
图像标注数据混合了视觉特征与文本元数据，要求混合检索同时兼容向量嵌入的视觉特征与文本字段，避免单一检索模式的局限性。按日或单批次更新的数据，需要适配高频索引刷新的检索延迟约束，避免因索引更新导致的检索结果不一致。标注规范、返工清单等文档的字段差异较大，需针对性配置检索匹配的权重，确保关键信息如边界框坐标、返工要求能被优先匹配。视觉目标的边界框坐标等结构化数据，需与文本描述结合检索，避免遗漏位置相关的关键标注信息。质检报告的抽检结果关联标注质量，检索时需优先匹配高可信度的历史数据，降低返工风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 重排开关 | 开启 | 图像标注数据混合视觉与文本特征，重排可过滤低相关性召回结果，提升标注相关检索的精准度 |
| 相似度阈值 | 0.72–0.85 | 适配混合视觉特征与文本元数据的相似度计算区间，避免误匹配边界框坐标与无关内容 |
| 单次返回上限 | 前 10–15 条 | 匹配单批次标注任务的样本量范围，控制检索结果的处理耗时 |
| 接口超时时间 | 300–600 秒 | 适配重排模型的加载与推理时长，避免超时导致的检索失败 |
| 检索模式 | 混合检索 | 兼容图片样本的视觉嵌入与标注文档的文本元数据，实现跨类型内容的混合检索 |
| 重排模型版本 | 适配FastGPT v4.17.0的兼容版本 | 避免因版本不匹配导致的重排请求错误 |

## 容易做错的三处
- 现象：开启重排开关后，在线召回测试无重排结果。原因：未在知识库索引环节同步开启重排关联配置，或重排模型的部署路径未正确绑定。
- 现象：本地重排模型请求返回错误。原因：配置的重排模型版本与FastGPT兼容要求不匹配，或模型加载时的内存配额不足。
- 现象：调用ollama重排模型时显示Invalid URL (POST /v1/rerank)。原因：未正确配置重排模型的API端点路径，或第三方API转发规则未覆盖重排接口。

## 怎么确认配好了
- 进入知识库的检索测试页面，输入与标注规范、返工清单相关的查询词，查看返回结果的排序是否优先匹配高相关的框选样例或质检报告。
- 检查重排模型的连接状态，确认界面显示的模型状态为正常运行，无连接超时或认证失败提示。
- 调整相似度阈值的区间，验证检索结果的匹配数量随阈值变化符合预期。
- 查看检索日志，确认重排接口的调用请求与返回数据包含视觉特征与文本字段的混合匹配结果。
