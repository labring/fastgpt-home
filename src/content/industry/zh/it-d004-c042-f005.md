# 备份恢复与灾备演练的客户技术支持与售前答疑：多轮对话与提示词

## 这个品类的数据长什么样
本品类的核心数据来自备份系统、数据库日志、对象存储及灾备平台，日常产出备份策略、恢复演练报告、灾备切换预案、数据校验记录四类文档。数据更新频率分为日、月、季三级，恢复演练报告按单次演练更新，数据校验记录每日生成。数据关联跨系统资源，需核对恢复点、演练脚本执行状态、数据一致性校验结果，核心主体为运维团队、数据库管理员及业务连续性负责人，聚焦跨系统的可恢复能力验证。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
本品类的数据特征对多轮对话与提示词配置带来明确约束。跨系统的数据来源要求对话需统一不同平台的术语表述，避免因备份系统与灾备平台的术语差异导致理解偏差。不同更新频率的文档需区分上下文时效性，需配置上下文过滤规则，避免调用过期的备份策略或旧版演练预案。核心环节涉及多步骤验证，对话需支持分步回溯确认，例如从恢复点确认到脚本执行再到数据校验的连贯引导。出错后果直接影响业务连续性，提示词需包含数据一致性校验的前置逻辑，确保回复基于最新生成的校验记录。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 最大上下文长度 | 8000–12000 token | 本品类单份核心文档最长约10000字符，对应token数约8000-12000，基于FastGPT v4.17.0版本的token计算规则，避免上下文过载 |
| 上下文保留轮次 | 前20轮有效会话 | 灾备演练的咨询常涉及步骤回溯，过多轮次会干扰当前请求的逻辑判断 |
| 变量绑定 | 绑定备份系统、灾备平台的环境变量 | 需调用对应系统的实时数据，确保回复基于最新的备份状态与校验结果，需配置`variables`参数关联系统接口 |
| 输入长度校验 | 15000字符以内 | 客户咨询的单次输入通常不超过12000字符，设置合理阈值拦截超限请求 |
| 单次文档召回上限 | 前6条 | 本品类的数据校验记录的关联条目通常不超过6条，过多召回会干扰对话逻辑 |
| 多模态输入配置 | 开启jpg格式支持 | 适配客户上传的备份拓扑图、演练报告截图等输入内容 |
| 引用标识配置 | 开启文档关联标识 | 便于客户追溯回复依据的备份策略或数据校验记录 |

## 容易做错的三处
- 对话请求返回结果无cite引用id，现象是调用对话接口后，返回的`messages`字段中未附带关联文档的引用标识，无法追溯依据的备份策略或校验记录。原因是未开启引用标识配置，未绑定`variables`变量关联文档元数据与对话回复的逻辑。
- 输入超过上限触发未拦截报错，现象是对话节点返回输入长度超限的系统报错，未按配置拦截超限请求。原因是未设置输入长度校验规则，或阈值设置不合理超出AI模型的输入上限。
- 无法接入jpg文件作为对话输入，现象是上传jpg格式的备份拓扑图后，对话模块无法解析图片内容，回复未涉及图片相关信息。原因是未开启多模态输入配置，未配置jpg格式的图片转文本预处理步骤。

## 怎么确认配好了
- 发起包含“查询最新备份策略”的对话，检查回复是否附带对应文档的引用标识，确认引用配置生效。
- 构造超过15000字符的输入文本，检查是否触发输入长度拦截提示，确认校验规则生效。
- 上传jpg格式的灾备演练拓扑图，发起包含“描述该拓扑图内容”的对话，检查回复是否能正确解析图片信息。
- 发起新的对话并结束后，检查是否能正常删除该对话的`chatId`对应的会话记录，确认会话管理功能正常。
