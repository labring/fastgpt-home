# 安全产品规则运营的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
该品类的核心数据来自WAF、IDS、防火墙设备与威胁情报平台，日常运维与业务文档包括规则变更单、拦截日志、误报分析报告、策略回滚记录。文档字段通常包含规则编号、触发特征、生效时间、误报率、关联攻击类型等专业技术内容，更新节奏为每日批量更新或随安全事件实时更新，单次更新的数据量随安全事件规模波动。

## 这些特征在「知识库检索与召回」这一环带来什么约束
由于该品类的数据来源分散且更新频率较高，知识库检索需支持多源异构数据的统一解析与实时增量同步，确保召回内容的时效性。文档多为专业技术类内容，检索需精准匹配技术关键词，避免泛化召回无关的通用安全文档。高频查询场景集中在误报分析与策略回滚，召回结果需优先关联当前客户的实际拦截场景，同时需控制召回结果的数量，防止超出大模型上下文窗口。另外，安全策略变更频繁，检索链路需快速同步最新规则数据，避免影响客户技术支持的响应效率。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配：

| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `similarity` | 0.75–0.85 | 匹配安全产品规则的专业术语，避免召回无关的通用安全文档，同时保证召回结果的相关性 |
| `limit` | 前8条 | 安全产品规则文档的字段数量较多，过多结果会超出大模型上下文窗口，同时覆盖常见的误报、策略变更场景 |
| `searchMode` | 语义检索 | 适配技术类文档的语义匹配，相比关键词检索更能识别相近的攻击特征与规则描述 |
| `usingReRank` | 开启 | 对召回的初始结果进行重排序，优先返回与客户当前拦截日志关联度更高的规则内容 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展售前答疑类问题的检索词，比如将“WAF拦截规则”扩展为“Web应用防火墙防护策略”，覆盖更多相关文档 |
| `collectionIds` | 指定专属安全规则数据集ID | 隔离不同品类的知识库，确保检索范围仅覆盖安全产品规则运营相关的文档，避免混入其他品类的内容 |

## 容易做错的三处
- 检索结果包含知识库文档，但大模型回答精简，未返回具体条款内容。原因是未开启`datasetSearchUsingExtensionQuery`，且未设置足够的`limit`参数，导致关键条款未被召回。
- 知识库搜索速度缓慢，响应时长超出预期。原因是未限制`limit`参数的合理取值，或未开启`usingReRank`，导致系统加载过多无关的安全日志与规则数据。
- 同一问题的召回结果条数与内容每次不一致。原因是`similarity`阈值设置区间过大，或未固定`collectionIds`导致检索范围包含多个未隔离的数据集。

## 怎么确认配好了
- 查看检索日志，确认召回结果的`similarity`分值落在0.75–0.85区间内。
- 测试售前答疑场景的检索，确认返回结果包含规则变更单、误报分析的具体条款内容。
- 检查知识库同步状态，确认最新的规则变更数据已被索引并可被检索到。
- 模拟高并发检索场景，确认搜索响应时间符合预期，无明显延迟。
