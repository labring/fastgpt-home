# 安全培训与钓鱼演练的客户技术支持与售前答疑：多轮对话与提示词

本文适配FastGPT v4.17.0版本，以下配置均基于该版本的界面与接口规则。

## 这个品类的数据长什么样
该品类的核心文档包含培训课件、钓鱼邮件模板、演练方案与演练结果报告，数据来源通常为员工通讯录、企业邮件网关、内部培训平台及用户点击统计数据。数据更新频率多为季度或年度，文档结构包含人群标签、邮件内容模板、演练流程、结果统计字段，无统一强制格式，需适配企业现有安全运营台账。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
数据来源分散且格式不统一，要求多轮对话需支持跨数据源的字段提取，提示词需适配不同文档的结构差异。更新频率较低，提示词需支持历史演练数据的复用与增量更新。演练人群筛选、模板设计等耗时环节依赖多轮对话的参数传递，需明确对话流程中的变量传递规则。结果复盘环节需关联点击统计数据，提示词需支持多维度结果的聚合展示约束。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chatId` | 绑定演练场景唯一标识 | 区分不同钓鱼演练的对话上下文，避免跨场景数据混淆 |
| `messages` | 按演练阶段拆分对话轮次 | 适配培训课件、模板、报告的分段调用需求，符合多轮答疑的流程逻辑 |
| `variables` | 传入员工部门、演练批次参数 | 实现人群筛选的精准匹配，适配不同部门的安全培训需求 |
| 模型选择 | 文本理解用通用嵌入模型，对话用大语言模型 | 适配品类文档的结构化与非结构化处理需求，提升答疑准确性 |
| 单次召回上限 | 前 3 条 | 控制返回的历史演练数据量，避免冗余信息干扰当前答疑 |
| 超时阈值 | 60 秒 | 适配跨数据源调用的延迟情况，保障售前与技术支持的响应效率 |
| 最大上下文长度 | 800–1200 字符 | 容纳单份演练方案与模板的核心内容，避免上下文溢出 |

## 容易做错的三处
- 现象：调用知识库关联接口后返回空结果，未匹配到演练相关文档。原因：未通过`variables`传入演练场景的专属知识库ID，导致对话无法定位对应品类的文档数据。
- 现象：多轮对话中模型混淆不同批次的钓鱼邮件模板内容。原因：未绑定`chatId`区分场景上下文，导致不同演练的对话数据互相干扰。
- 现象：调用API创建智能体时返回未定义的接口错误。原因：未使用FastGPT官方提供的智能体创建接口，误用通用对话接口参数。

## 怎么确认配好了
- 发起测试对话，输入“查看本次钓鱼演练的邮件模板”，核对返回内容是否包含当前绑定场景的专属模板内容。
- 调用`variables`传入测试部门参数，发起“筛选对应部门的培训人群”类提问，核对返回结果是否仅包含对应部门的员工信息。
- 查看对话日志，确认`chatId`与当前演练场景的唯一标识一致，无跨场景的上下文残留。
- 模拟延迟请求场景，确认系统在60秒内返回响应或明确的超时提示。
