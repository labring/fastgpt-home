# 安全培训与钓鱼演练的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
该品类的典型主体为安全运营团队、企业内训部门及外部安全服务商。日常产生的文档包含培训课件、钓鱼演练方案、钓鱼邮件模板、演练结果报告四类。数据来源涵盖员工通讯录、企业邮件网关、内部培训平台及用户点击统计数据。文档更新频率通常为季度或年度，核心耗时环节集中在演练人群筛选、邮件模板设计与结果复盘。出错后可能引发员工泄密风险、审计缺项或整改无有效证据。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的文档类型多样且关联场景明确，要求检索召回需精准匹配演练场景、人群标签等关键词，避免无关内容干扰。数据更新频率较低，无需频繁增量同步，但需保证召回结果与当前培训计划的适配性。多来源的数据存在格式差异，要求检索支持跨文档类型的统一匹配逻辑。此外，核心耗时环节的痛点要求检索可快速召回过往复用的模板与方案，因此需支持按场景标签快速筛选结果，减少人工筛选成本。

## 配置怎么定
FastGPT v4.17.0版本下，可通过以下配置项适配该品类的检索需求：
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `similarity` | 0.75–0.85 | 平衡钓鱼邮件模板、演练方案的相关性匹配，避免过低返回无关文档，过高遗漏适配场景的内容 |
| `limit` | 3–5条 | 适配单场景检索需求，避免过多结果增加售前与技术支持人员的筛选成本 |
| `searchMode` | 全文检索 | 支持从培训课件、邮件模板、演练报告中召回关键词匹配内容，覆盖多类型文档 |
| `usingReRank` | 开启 | 对初始召回的结果按相关性重排，提升演练方案与邮件模板的精准度 |
| `collectionIds` | 指定专属数据集ID | 确保仅检索该品类的培训课件、演练方案等文档，避免混入其他品类的内容 |
| `datasetSearchUsingExtensionQuery` | 关闭 | 因该品类文档更新频率较低，无需额外扩展查询词，避免引入无关内容 |

## 容易做错的三处
- 现象：检索返回结果仅1条，无法满足多演练方案对比需求。原因：将`limit`参数设置为1，未适配该品类多文档复用的业务场景。
- 现象：检索接口响应缓慢，耗时超出合理范围。原因：未根据品类文档体积调整检索参数，或开启`usingReRank`后未限制初始召回条数，导致计算资源占用过高。
- 现象：检索结果混入安全基线检查类文档。原因：未通过`collectionIds`指定专属数据集，导致检索范围覆盖了其他品类的文档集合。

## 怎么确认配好了
- 提交包含钓鱼邮件关键词的查询，检查返回结果是否包含对应的演练方案或邮件模板文档。
- 查看检索结果的条数，确认是否符合预设的`limit`参数取值范围。
- 调整`similarity`参数的取值，观察返回结果的相关性变化，验证阈值设置符合业务需求。
- 检查数据集关联配置，确认仅包含该品类的培训课件、演练方案等文档，无跨品类内容混入。
