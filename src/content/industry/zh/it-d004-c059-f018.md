# 广告素材审核的客户技术支持与售前答疑：重排与混合检索

## 这个品类的数据长什么样
本品类数据主要来自广告平台、落地页、商品资质及广告法条款，更新频率为日级或实时。日常处理的文档包含广告素材、落地页截图、审核意见与修改记录，核心字段包括素材唯一标识、违规类型标注、审核状态、修改时间戳，单条素材文档长度跨度较大，从数十字符的文案素材到数百像素的落地页截图文件不等。

## 这些特征在「重排与混合检索」这一环带来什么约束
广告素材的多源异构特性要求混合检索需兼容文本、图片元数据两类数据，因此需要配置适配多模态的检索模式。素材更新频率为日级或实时，需确保检索链路支持实时同步的索引更新，避免召回过期素材。单条素材文档长度跨度较大，重排环节需适配不同长度的输入，避免因上下文溢出导致检索失效。审核关联的合规文档需严格匹配最新版本，重排结果需优先关联当前生效的广告法条款内容，确保召回内容符合合规要求。

## 配置怎么定
以下配置项适用于FastGPT v4.17.0版本。

| 配置项         | 建议取法           | 这样取的依据 |
| ----------------|--------------------|------------------------------------------------------------------------------ |
| 相似度阈值     | 0.75–0.85          | 适配广告素材合规检索的严格性，平衡召回精度与覆盖范围 |
| 单次搜索上限   | 前8–12条           | 控制单次检索返回结果数量，避免重排环节计算过载 |
| 检索模式       | 混合检索           | 兼容广告素材文本、落地页元数据等多源数据 |
| 启用重排       | 开启               | 针对广告素材审核的高合规要求，优化召回结果的相关性排序 |
| 重排召回上限   | 前5–7条            | 聚焦高优先级的合规匹配结果，减少无效校验 |

## 容易做错的三处
- 在线召回测试时未显示重排结果，原因是未在知识库索引环节开启重排关联配置，或未在检索环节启用重排功能。
- 重排模型连接报错显示Invalid URL (POST /v1/rerank)，原因是重排模型的API地址配置错误，或第三方API转发服务的重排接口路径与FastGPT要求的格式不匹配。
- 本地重排模型请求失败，原因是本地模型的端口未开放，或配置的重排模型参数与FastGPT支持的模型格式不兼容。

## 怎么确认配好了
- 进入FastGPT的检索配置页面，确认启用重排功能的开关处于开启状态。
- 提交一条广告素材相关的测试查询，查看检索结果列表中是否包含重排得分字段。
- 检查重排模型的API配置信息，确认地址、密钥等参数与部署的模型服务一致。
- 触发一次完整的知识库索引，确认索引过程中重排模块未抛出异常日志。
