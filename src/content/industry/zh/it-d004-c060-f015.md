# 广告账户开户审核的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据主要来自广告平台后台、国家企业信用信息公示系统、客户提交的开户申请材料、行业准入规则文档。日常处理的文档包含开户申请单、营业执照扫描件、行业资质证明、开户审核记录等。数据更新频率为每日或随每一笔开户申请同步更新，文档字段包含主体名称、所属行业类目、资质有效期、审核状态等，部分为结构化表单，部分为非结构化扫描件。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据分散于多个系统与客户提交材料中，要求知识库检索需支持跨数据源关联召回，覆盖广告平台规则、资质核验标准等多类内容。混合的结构化与非结构化文档，要求检索模块适配不同格式的文本与扫描件解析结果。数据随开户申请实时更新，要求召回的知识库索引需保持与业务同步的更新频率。字段聚焦于主体资质与行业准入，检索需精准匹配相关字段，避免无关结果干扰审核判断。

## 配置怎么定
本文基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配广告账户开户相关的资质与规则文本，该区间可过滤低相关结果，保留核心审核依据 |
| `limit` | 前10条 | 控制单次召回的结果数量，适配审核人员快速查看的场景，避免过多信息干扰判断 |
| `searchMode` | semantic | 采用语义检索模式，适配非结构化的资质文档与规则文本，提升跨语义匹配的准确性 |
| `usingReRank` | 开启 | 对召回结果进行重排序，优先展示与开户资质核验强相关的内容，降低误判风险 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展查询词，补充行业准入相关的同义词与规则表述，覆盖更多潜在审核依据 |
| `collectionIds` | 对应广告账户开户审核知识库的集合ID | 限定检索范围仅为该品类专属的数据集，避免无关知识库内容干扰审核流程 |

## 容易做错的三处
- 现象：调用知识库API时返回鉴权失败或无权限访问结果。原因：未使用专属的广告账户开户审核知识库鉴权KEY，误用通用KEY导致权限范围不匹配。
- 现象：本地部署的FastGPT中，知识库搜索模块的召回结果条数无法调整。原因：未正确配置`limit`参数，或误操作其他无关设置项，导致参数无法生效。
- 现象：导入修改后的知识库CSV文件时提示格式错误。原因：未按照FastGPT对应版本的CSV模板调整字段顺序与格式，导致系统无法识别开户审核相关的文档元数据。

## 怎么确认配好了
- 执行典型的开户审核相关查询，比如“游戏行业开户需要哪些资质”，核对返回结果的相关性与数量，调整`similarity`与`limit`参数至匹配业务需求。
- 查看知识库检索日志，确认仅从指定的`collectionIds`集合中召回数据，无无关知识库内容被返回。
- 对比开启与关闭`usingReRank`后的结果排序，确认重排功能正常生效，优先展示核心审核依据。
- 使用专属鉴权KEY发起测试调用，确认可正常获取开户审核相关的知识库内容，无权限报错。
