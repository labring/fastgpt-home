# 投放计划搭建的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据通常来自广告平台后台、用户画像库、预算排期表、归因分析工具。日常产出的文档包含投放计划文档、定向设置配置表、预算排期表、转化追踪配置文件。数据更新频率为每日或对应广告活动启动时。文档字段包含定向人群包标识、预算金额（单位元）、转化事件类型、投放时段等，单位多为元、人次、事件标识等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据特征会对知识库检索与召回带来多重约束。数据来源分散且格式不统一，跨广告平台、用户画像库的字段映射需在检索时自动对齐。文档包含表格、配置文件、纯文本等多种格式，需适配不同内容的分块规则。数据更新频率灵活，部分随广告活动实时变动，召回需优先关联最新更新的数据集。投放相关数据的准确性直接影响后续投放效果，检索结果的置信度要求高于通用问答场景。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 投放计划数据的字段匹配精度要求较高，该区间可过滤低相关结果，避免错误配置影响投放 |
| `limit` | 前6条 | 投放相关文档的单条内容较长，限制召回条数避免上下文过长导致超时 |
| `searchMode` | vector_search | 适配投放计划的结构化数据，向量搜索可精准匹配定向、预算等字段的语义关联 |
| `usingReRank` | 开启 | 对召回结果做二次排序，提升高相关投放配置文档的展示优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 针对投放问题自动生成扩展查询词，覆盖不同表述的定向设置、预算配置等内容 |
| `collectionIds` | 按投放业务分组配置 | 区分不同广告账户、活动的知识库集合，避免跨业务的无关数据被召回 |

## 容易做错的三处
- 现象：知识库召回结果准确率偏低，无法匹配精准的投放配置字段。原因：`similarity`阈值设置过低，过滤了部分高相关的结构化文档，或未开启`usingReRank`导致低相关结果优先返回。
- 现象：知识库请求返回`request entity too large`报错，或上传190MB的投放计划文档时出现`offset is out of bounds`报错。原因：未调整系统级的请求大小限制，或未针对大体积文档调整分块逻辑，导致单次请求超出上限或分块索引越界。
- 现象：开启知识库关联后，问答响应速度明显变慢。原因：召回的`limit`条数过多，或未按业务分组配置`collectionIds`，导致检索跨多个无关数据集，增加了检索耗时。

## 怎么确认配好了
- 输入一条典型的投放配置问题，核对召回结果的`similarity`得分是否符合预设区间，确认过滤了无关内容。
- 上传一份大体积的投放计划文档，检查是否能正常完成索引，无报错提示。
- 对比开启和未开启知识库关联的问答响应时长，确认耗时在可接受范围内。
- 查看召回结果的来源数据集，确认仅包含当前业务分组下的投放相关文档，无跨业务的无关数据。
