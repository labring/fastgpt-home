# 数据库云服务运维的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
数据库云服务运维的业务数据主要来自云数据库控制台、慢日志、监控指标、工单系统四类来源，更新频率为每日或每完成一次实例变更。日常产出的文档包含实例变更单、备份恢复记录、性能诊断报告、参数调整记录，字段包含实例ID、备份时间戳、慢SQL耗时（毫秒）、参数调整前后值等，部分文档关联多租户租户标识与云服务边界配置。

## 这些特征在「知识库检索与召回」这一环带来什么约束
业务数据的多来源特性要求检索需覆盖不同格式的文档，包括结构化的监控指标与非结构化的慢SQL分析文本。实例ID、租户标识等字段的强业务关联性，要求检索需支持按元数据过滤，避免跨租户或跨实例的无关结果返回。高频变更的更新节奏要求索引需实时同步，确保检索结果包含最新的参数调整与备份记录。慢SQL定位、备份恢复演练等核心耗时环节，要求召回结果需精准匹配业务场景，避免冗余信息干扰。

## 配置怎么定
本章节配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `similarity` | 0.75–0.85 | 匹配数据库运维场景的精准检索需求，过滤低相关的监控指标与备份记录 |
| `limit` | 前8条 | 平衡上下文长度与信息覆盖，适配实例变更、备份恢复等多类业务文档的召回 |
| `searchMode` | 语义检索 | 适配慢SQL分析、参数风险评估这类非结构化文本的语义匹配需求 |
| `usingReRank` | 开启 | 对初始召回结果二次排序，优化慢SQL、性能诊断类结果的展示优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 优化售前答疑场景的用户问题，将口语化提问转化为匹配业务文档的检索词 |
| `collectionIds` | 绑定云数据库运维专属集合 | 仅检索该品类的知识库内容，避免混入其他业务板块的文档 |

## 容易做错的三处
- 现象：检索结果包含非目标租户的数据库实例文档，或未过滤出指定实例的内容。原因：未正确配置`collectionIds`绑定专属业务集合，或未按租户、实例ID等元数据字段设置过滤规则。
- 现象：开启支持联网的AI模型后，应用仅检索知识库内容，无法补充最新云服务公告信息。原因：知识库检索优先级未调整，或未正确启用跨源检索配置，导致联网功能被知识库检索覆盖。
- 现象：基于集合标签的检索无法返回预期结果，或标签功能失效。原因：未在知识库集合中正确添加实例ID、租户ID等业务标签，或标签过滤逻辑配置错误。

## 怎么确认配好了
- 提交包含具体实例ID的测试问题，核对返回结果是否仅包含该实例的相关文档。
- 开启`usingReRank`后，查看检索结果的排序是否符合业务相关性，比如慢SQL问题优先返回性能诊断报告。
- 切换为不相关的非数据库运维问题，确认检索结果未混入其他品类的知识库内容。
- 测试开启联网功能的场景，确认当知识库无对应内容时，应用会触发联网检索。
