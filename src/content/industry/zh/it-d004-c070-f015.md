# 数据清洗与质检的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据来源包含原始数据集、ETL日志、标注平台、抽样结果。数据更新频率为日度或每批次交付周期。日常产出的文档包含清洗规则、质检抽样表、异常数据清单、交付报告。清洗规则包含规则标识、生效范围、匹配字段；质检抽样表包含样本总量、不合格样本占比字段；异常数据清单包含数据唯一标识、异常类型、处理状态；交付报告包含批次编号、整体质检结论。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源的多样性要求检索同时覆盖结构化规则文档与非结构化日志、报告内容，需适配不同格式的知识库内容召回。高频更新的特性要求检索链路支持增量同步，避免因数据滞后导致的规则调用错误。业务场景聚焦精准匹配规则与异常处理方案，需过滤低相关性的召回结果，保障数据处理的准确性。业务主体的查询需求多围绕规则配置、异常排查，检索需优先匹配业务术语与字段标识，提升查询效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 数据清洗规则与异常清单的匹配需要精准匹配业务术语，避免低相似度的无关规则被召回 |
| `limit` | `前8–12条` | 单次需要召回的清洗规则、异常处理文档数量适配质检员的批量查看需求，避免过多结果干扰判断 |
| `searchMode` | `精确匹配优先` | 数据清洗与质检的业务查询多为精准匹配规则ID、异常类型，精确匹配可减少无关召回结果 |
| `usingReRank` | `开启` | 异常数据清单和ETL日志的文本内容较长，重排可过滤低相关性的召回结果，提升精准度 |
| `datasetSearchUsingExtensionQuery` | `开启` | 数据清洗规则多有关联字段，扩展查询可覆盖同义词或相近的业务表述，适配工程师的模糊查询需求 |
| `collectionIds` | `仅绑定清洗规则、质检抽样表、异常数据清单、交付报告对应的集合` | 缩小检索范围，避免无关知识库内容干扰，提升检索效率 |

## 容易做错的三处
-  知识库检索响应超时，界面显示`504 Gateway Timeout`状态码。原因：未针对数据清洗与质检的高频更新数据集调整检索参数，导致milvus在GPU上的索引负载过高。
-  新建知识库目录后直接弹出报错弹窗，界面显示provider相关异常提示。原因：未正确配置`collectionIds`，绑定了不存在或权限不足的知识库集合，导致检索链路无法正常调用。
-  检索结果条数与设置的`limit`不符，返回结果超出或少于预期数量。原因：未正确调整`similarity`阈值，阈值过低则纳入过多无关结果，阈值过高则过滤了有效匹配内容。

## 怎么确认配好了
以下核对动作基于FastGPT v4.17.0版本的界面与参数逻辑。
-  检索指定的清洗规则文档，核对返回结果是否包含目标规则标识，确认`similarity`阈值适配业务匹配需求。
-  查看连续多次检索的响应时长，结合实际业务负载调整`limit`和`usingReRank`的配置。
-  测试新建知识库目录与新增文件夹操作，确认`collectionIds`的绑定配置无异常，无provider相关报错。
-  检索异常数据清单，核对返回结果的相关性排序，确认`usingReRank`功能生效。
