# 游戏内容合规自查的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据来源于游戏研发过程中的游戏文本、美术资源、剧情脚本，以及监管公开的合规要求。日常维护的文档包括内容自查表、敏感内容修改记录、用户协议、合规评审纪要。文档结构包含版本标识、检查条目、审核状态、关联资源ID等字段。数据更新随游戏版本迭代或活动上线触发，每次更新覆盖当次版本或活动的全部合规相关内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束
游戏内容合规自查的数据包含文本、美术资源等多类型内容，要求检索召回环节支持跨类型内容的关联匹配。数据随版本或活动高频更新，要求知识库同步机制适配增量更新与全量更新切换，避免检索到过期内容。文档包含自查表、评审纪要等结构化与非结构化内容，多级目录与字段差异要求检索链路支持按文档类型过滤召回结果。合规场景对内容准确性要求极高，召回结果需覆盖全部关联的合规依据与历史修改记录，支撑售前答疑与技术支持的精准性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 过滤低关联的检索结果，避免无关合规条目干扰答疑 |
| `limit` | `前8–12条` | 覆盖单版本自查的核心检查项，同时控制上下文总长度 |
| `searchMode` | 向量检索+关键词混合 | 兼顾语义匹配与关键词精准命中，适配结构化合规文档的字段检索 |
| `usingReRank` | 开启，重排前5条结果 | 二次排序召回结果，提升高合规相关性内容的展示优先级 |
| `datasetSearchUsingExtensionQuery` | 开启，关联内置合规词库 | 自动扩展合规相关同义词与监管术语，覆盖用户模糊提问场景 |
| `collectionIds` | 绑定当前版本的合规知识库集合，大小不超过1000 MB | 限定检索范围，避免召回非当前版本的过期合规数据 |

## 容易做错的三处
- 现象：调用知识库content接口返回格式不支持错误，直接访问链接可正常下载docx文件。原因：未配置知识库支持docx格式的文档解析，或上传的docx文件包含加密内容。
- 现象：飞书文档多级目录中的内容无法全部召回，文档内的doc附件与图片无检索结果。原因：未开启知识库的飞书文档多级目录同步开关，且未配置图片与doc附件的解析支持。
- 现象：无法实现用户选择是否跳过知识库检索的交互逻辑。原因：未在工作流中配置条件分支变量，未绑定检索开关与用户输入选项。

## 怎么确认配好了
- 登录FastGPT v4.17.0版本的知识库管理后台，进入对应合规知识库的检索配置页面，确认`similarity`、`limit`等配置项的取值与预设值一致。
- 上传一份测试用的游戏剧情脚本与自查表，发起检索请求，验证召回结果包含对应检查项与剧情内容。
- 触发一次版本更新的知识库同步任务，验证过期文档被自动排除在检索结果外。
- 配置用户选择变量的工作流，测试切换检索开关时，是否正确触发或跳过知识库检索环节。
