# 游戏客户端性能优化的客户技术支持与售前答疑：重排与混合检索

## 这个品类的数据长什么样
这个品类的数据通常来自引擎Profiler、崩溃分析平台、真机测试集群与帧率采集工具。日常产出的文档包括性能测试报告、机型适配清单、优化迭代记录与崩溃根因分析报告。数据更新节奏为每日同步或每版本发布前全量更新，核心字段包含帧率数值、资源加载耗时、崩溃堆栈信息与机型适配标记，字段与单位随测试场景动态调整，无固定统一格式。

## 这些特征在「重排与混合检索」这一环带来什么约束
该品类的数据特征会对重排与混合检索环节带来多重约束。首先，数据来源覆盖结构化的帧率数据、非结构化的崩溃分析报告与机型适配清单，混合检索需要支持多源异构数据的统一召回，避免遗漏关键信息。其次，数据更新节奏为每日或每版本同步，检索系统需支持增量同步机制，确保技术支持调用的是最新的优化记录与测试结果。另外，核心字段无固定统一格式，重排环节需要可配置的字段权重规则，例如针对帧率数值的相关性权重可单独调整。同时，技术支持场景的查询多指向特定机型的性能问题，检索需优先召回同机型的适配数据，提升匹配精度。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，适配游戏客户端性能优化的技术支持场景：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 重排开关 | 开启 | 针对游戏客户端性能问题的精准匹配需求，过滤低相关性的历史优化记录 |
| 单次召回上限 | 前20条 | 适配该品类每日更新的多源数据量，避免过多冗余数据进入重排环节 |
| 检索模式 | 混合检索 | 同时召回结构化帧率数据与非结构化崩溃分析报告，覆盖全量业务文档 |
| 相似度阈值 | 0.75–0.85 | 过滤与当前问题无关的机型适配记录，保留高相关的优化方案 |
| 重排召回条数 | 前5条 | 符合技术支持场景下快速定位问题的需求，避免过多信息干扰判断 |
| 数据同步周期 | 每日 | 适配该品类每日更新的数据节奏，确保检索使用最新的优化记录 |

## 容易做错的三处
- 现象：对话详情中重排相关字段为空或显示未配置状态，原因：未在系统配置中开启重排开关，或配置参数未正确同步到服务节点，对应常见的重排配置异常问题。
- 现象：检索结果仅返回单条最高相似度内容，原因：重排召回条数配置为1，未适配技术支持场景下多方案参考的需求。
- 现象：重排环节未按预期过滤低相关数据，原因：相似度阈值设置过高或过低，未匹配该品类的文档字段特征。

## 怎么确认配好了
- 进入FastGPT的知识库配置页面，确认重排开关处于开启状态，检索模式设置为混合检索。
- 发起一条测试查询，例如“某机型帧率卡顿如何优化”，查看检索结果的召回条数是否符合配置的单次召回上限。
- 查看对话详情中的检索日志，确认重排环节已执行，且结果按相关性排序。
- 调整相似度阈值后发起测试，确认检索结果的相关性发生对应变化。
