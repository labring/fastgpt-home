# 移动端开发的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
移动端开发的客户技术支持与售前答疑相关数据，主要来自iOS工程师、Android工程师、跨端开发团队的日常产出与平台后台。日常文档包括端版本发布单、机型适配清单、崩溃分析报告、应用商店审核资料等。数据来源覆盖代码仓库、应用商店后台、崩溃监控平台、机型覆盖统计平台。更新频率为每日同步或每版本发布时更新。文档结构按机型、版本号分类，包含结构化字段如机型版本、权限配置项，以及非结构化内容如崩溃堆栈、审核材料说明。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散且更新频繁，要求知识库需支持多平台定时同步，避免检索到过时的版本信息。文档按机型与版本分类，检索时需结合当前会话的机型参数过滤结果，避免返回不匹配的适配内容。结构化与非结构化内容混合的文档，要求检索模式兼顾关键词与向量匹配，覆盖不同类型的技术内容。应用商店资料的更新周期与版本发布同步，知识库的更新频率需匹配版本发布节奏，确保售前答疑时的资料时效性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 移动端开发文档多技术细节，需过滤低匹配度的无关适配内容 |
| `limit` | 前8条 | 移动端适配项数量较多，过多检索结果会超出上下文窗口限制 |
| `searchMode` | 向量+关键词混合检索 | 兼顾结构化的机型参数与非结构化的崩溃日志文本，提升召回精准度 |
| `usingReRank` | 开启 | 移动端文档存在大量相似术语，重排可筛选出最贴合当前问题的结果 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充开发者常用术语的扩展查询，覆盖跨端开发的同义词与缩写场景 |
| `collectionIds` | 移动端开发专属知识库ID | 限定检索范围，避免混入其他品类的文档干扰 |

## 容易做错的三处
- 现象：上传大于500MB的适配清单文档时，FastGPT v4.17.0界面显示timeout但后台上传完成。原因：未调整大文件上传的超时阈值，默认超时时长不足以覆盖大文档的解析与上传流程。
- 现象：导入崩溃分析报告后，知识库显示已就绪但无检索结果。原因：未开启结构化数据的字段映射，未将崩溃日志ID、机型版本等字段纳入检索索引。
- 现象：用户连续提问两个不同机型的适配问题时，第二次检索仍沿用第一次的知识库集合。原因：未配置会话上下文的知识库切换逻辑，默认保留首次选定的知识库ID。

## 怎么确认配好了
- 上传一份包含指定机型适配要求的测试文档，发起包含该机型名称的查询，核对检索结果是否命中该文档的对应段落。
- 调整`similarity`参数，验证低阈值下是否会召回无关的开发文档，高阈值下是否会过滤有效内容。
- 上传大于1GB的崩溃分析报告，检查上传进度是否正常，无界面timeout提示。
- 发起连续两个不同机型的适配问题，核对第二次检索是否切换至对应机型的知识库集合。
