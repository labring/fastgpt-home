# 美术资产生产管理的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
美术资产生产管理的核心数据来自美术资产库、项目管理系统、引擎资源包、外包交付包。日常流转的文档包括美术需求单、资产规格表、外包反馈记录表、验收确认单，文档字段包含资产唯一标识、面数/分辨率等规格参数、交付时间、外包方信息、验收状态等。数据更新频率多为每日或每周，单次文档体量从数KB到数十MB不等，部分3D资产资源包体积较大。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源数据的混合来源要求检索需支持跨系统关联召回，避免割裂的资产信息。日/周级的更新节奏要求知识库同步任务需匹配数据更新周期，避免检索到过期的资产规格或验收记录。文档字段包含大量专业参数与状态标识，要求检索需精准匹配规格关键词与状态条件，否则易返回不匹配的资源内容。单次检索若返回过多长文档，会超出上下文窗口限制，影响后续生成环节的准确性。资源不匹配或版本缺失会直接影响项目进度，因此检索结果的相关性需达到较高标准。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 美术资产规格参数多且专业，该区间可过滤低匹配度的无关结果，避免错配资源 |
| `limit` | `前8条` | 单条美术资产文档长度较长，限制返回条数可控制上下文总长度，避免超出模型限制 |
| `searchMode` | `向量+关键词混合检索` | 兼顾资产ID、文件名等精确匹配需求与规格参数的语义匹配需求 |
| `usingReRank` | `开启` | 外包反馈、验收记录等长文本的语义相关性需通过重排优化排序，提升核心结果的优先级 |
| `datasetSearchUsingExtensionQuery` | `开启` | 美术需求单的表述可能存在口语化或缩写，扩展查询可覆盖同义表述，提升召回覆盖率 |
| `collectionIds` | `指定美术资产库、项目管理系统对应的集合ID` | 限定检索范围仅覆盖美术资产相关数据源，避免混入非目标内容 |

## 容易做错的三处
- 触发知识库请求频次限制，现象为返回429状态码，原因是未根据美术资产数据的更新节奏配置合理的请求限流规则，或未调整批量检索的并发参数。
- 无法检索飞书知识库中的美术资产数据，现象为返回空结果，原因是未正确配置飞书数据源的同步权限，或未将飞书知识库关联到指定的美术资产检索集合。
- 生成静态链接知识库时出现`Validation failed: name: Path `name` is required.`报错，现象为提交任务后立即失败，原因是未正确填写静态链接对应的资源名称字段，或链接指向的资源元数据缺失。

## 怎么确认配好了
- 发起包含具体美术资产规格关键词的查询，核对返回结果的匹配度是否符合预设的`similarity`阈值。
- 查看检索结果的来源集合标识，确认仅包含美术资产库、项目管理系统等指定数据源的内容。
- 测试包含同义表述的查询，确认`datasetSearchUsingExtensionQuery`功能正常生效，可召回未使用原关键词的相关文档。
- 开启`usingReRank`后，核对排序结果是否将最相关的资产规格或验收记录排在前列。
- 发起批量测试查询，确认未触发频次限制，验证限流配置的合理性。
