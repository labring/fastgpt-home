# 落地页转化优化的客户技术支持与售前答疑：知识库检索与召回

## 这个品类的数据长什么样
本品类的核心数据来自落地页访问日志、热力图、表单提交数据及广告来源参数，日常关联文档包含落地页方案、埋点需求文档、AB测试报告与表单字段清单。数据更新频率为每周或单次活动周期（约 7–14 天），最耗时的处理环节为页面路径分析、表单阻塞排查与实验结果判断，异常会导致线索流失、数据无法归因或广告成本上升。

## 这些特征在「知识库检索与召回」这一环带来什么约束
落地页转化优化的数据源多为用户行为类信息，关联文档包含结构化的埋点字段、AB测试结论与活动规则，需支持针对业务字段的精准召回。数据更新频率为周度或单次活动周期，检索需适配临时更新的活动文档，避免召回过期内容。页面路径分析等耗时环节依赖细粒度的访问数据，需召回匹配用户访问节点的精准文档，同时需控制检索耗时以支撑售前答疑的实时性。此外，表单字段清单等文档的结构化特征，要求检索需区分业务字段与通用说明，避免无关内容混入结果，影响答疑准确性。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本适配。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 语义匹配度 | 匹配落地页相关的专业术语与业务字段，避免召回无关的通用文档 |
| `limit` | 前 3–5 条检索结果 | 适配落地页转化优化的短平快答疑需求，控制上下文长度 |
| `usingReRank` | 开启重排功能 | 区分AB测试报告、表单字段等不同类型的业务文档，提升召回精准度 |
| `datasetSearchUsingExtensionQuery` | 开启问题扩展检索 | 自动扩展用户的售前问题，匹配落地页方案中的隐藏规则 |
| `collectionIds` | 指定专属知识库ID | 隔离业务数据，避免召回其他品类的文档 |
| `searchMode` | hybrid 检索模式 | 结合关键词与语义检索，适配落地页相关的结构化与非结构化文档 |

## 容易做错的三处
- 现象：对话中无法复述上传的落地页Excel表单字段清单内容，返回无法读取文件的提示。原因：未开启针对结构化文件的扩展检索配置，或知识库未正确解析Excel的单元格字段。
- 现象：检索结果包含过期的AB测试报告，无法匹配当前活动的规则。原因：未设置按活动周期过滤文档的检索条件，或数据更新未同步至知识库。
- 现象：检索返回过多无关的通用技术文档，无法定位到落地页专属的埋点需求。原因：`similarity`阈值设置过低，或未指定专属知识库的`collectionIds`。

## 怎么确认配好了
- 上传一份最新的落地页方案文档，发起包含“落地页表单字段”的查询，核对检索结果是否包含该文档的内容。
- 导入一份过期的AB测试报告，发起包含“当前活动测试结果”的查询，核对检索结果是否优先召回最新文档。
- 上传一份Excel格式的表单字段清单，发起包含“提取第十行内容”的查询，核对是否能正确返回对应字段信息。
- 发起包含“页面路径分析方法”的查询，核对检索结果是否仅包含落地页转化优化专属的文档，无其他品类的无关内容。
