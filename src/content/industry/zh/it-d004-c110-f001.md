# 运维外包驻场服务的客户技术支持与售前答疑：HTTP 接口与外部系统

## 这个品类的数据长什么样
通常，运维外包驻场服务的核心数据来自客户ITSM系统、现场监控平台、企业资产清单与驻场人员值班记录。日常产出的文档包含驻场日报、服务台工单、巡检报告与SLA月报，数据更新以日度为主，部分月度统计类文档按月更新。该品类的核心工作环节中，现场工单处理、巡检记录整理与SLA统计汇总为耗时占比较高的内容，数据字段多包含工单编号、巡检项、服务响应时长、驻场人员排班信息与设备状态标识等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据来源分散且包含工单、巡检报告等多类型内容，部分文档还会附带驻场现场拍摄的设备图片与巡检视频，这要求HTTP接口需支持多格式数据传递与多租户鉴权隔离，避免不同客户的服务数据被混淆。数据更新的日度与月度节奏差异，会影响接口调用的频率设置，高频调用需适配低延迟响应，低频批量统计接口则需调整超时阈值。此外，现场工单处理与巡检记录整理环节产生的单批次数据量较大，接口需具备处理批量请求的能力，同时需兼容相对链接转绝对链接的需求，避免外部系统无法正常读取驻场现场上传的文件，影响客户技术支持与售前答疑的效率。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | 按客户租户生成专属密钥，禁止使用通用KEY | 该品类数据涉及客户ITSM等敏感系统，通用密钥会增加数据泄露风险 |
| `variables` | 传入驻场工单编号、巡检报告ID等业务标识 | 便于外部系统关联对应服务记录，匹配运维外包驻场服务的文档字段结构 |
| `responseData` | 仅返回工单处理状态、文件上传结果等核心字段 | 减少无效数据传输，适配该品类高频调用的场景需求 |
| 文件上传大小限制 | 100–500 MB，按实测标定 | 驻场现场上传的设备图片、巡检视频等文件通常不超过该区间 |
| 接口超时时间 | 600–1200 秒 | 该品类的批量SLA统计、大型工单处理可能需要较长执行时间 |
| 单次请求工单数量上限 | 前200条，按实测标定 | 适配该品类日常批量处理工单的规模 |

## 容易做错的三处
- 现象：调用知识库API时返回403 Forbidden错误，或接口返回无权限访问数据。原因：使用通用鉴权密钥，未按客户租户生成专属密钥，不符合多客户数据隔离的要求。
- 现象：外部系统无法读取上传的图片或视频文件，返回文件不存在或路径错误。原因：未开启相对链接自动转换功能，驻场现场生成的相对链接无法被外部系统正常解析。
- 现象：批量处理工单或巡检数据时，接口返回超时错误，执行时间超过1200秒。原因：接口超时阈值设置过短，未适配该品类批量数据处理的耗时特征。

## 怎么确认配好了
- 发起单次鉴权请求，检查返回的状态码是否为200 OK，确认鉴权密钥的配置符合当前租户的权限要求。
- 上传一张驻场现场拍摄的测试图片，检查外部系统是否能正常读取文件内容，确认相对链接转换功能生效。
- 发起批量数据请求，监控接口执行时长，调整超时阈值至满足当前业务的耗时需求。
- 调用接口获取返回结果，检查返回的字段是否包含业务所需的核心信息，确认`responseData`的配置符合预期。
