# 专题活动运营的技术文档与接口问答：文档解析与分块

本文适配FastGPT v4.17.0版本的文档解析与分块模块。

## 这个品类的数据长什么样
该品类的数据主要来自内容库、活动后台、流量数据与用户反馈。日常处理的文档包含活动方案、资源位排期表、活动页面文案、复盘报告等，文档字段包含活动唯一标识、资源位位置、执行时间、参与指标等。数据更新节奏以周为周期，节假日前后会有临时更新，部分核心文档会在活动上线前完成最终定稿。

## 这些特征在「文档解析与分块」这一环带来什么约束
活动类文档存在明确的时间节点与资源绑定关系，分块时需避免割裂活动流程与资源位关联信息。结构化的排期表与方案文档包含固定字段，解析需保留字段的原始格式与关联关系。高频更新的文档要求解析流程适配快速迭代，同时活动复盘报告包含非结构化的用户反馈片段，需适配混合格式的内容拆分。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 活动文档多包含流程描述与结构化字段，该区间可保留单块内容的逻辑完整性 |
| `chunkSplitter` | 按段落+标题拆分 | 活动文档存在明确的章节划分，按标题与段落拆分可匹配活动的逻辑节点 |
| `customPdfParse` | 开启 | 活动方案多以PDF格式提交，开启后可保留原始排版与表格结构 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 活动复盘报告可能包含多页素材与数据附件，该上限可覆盖常规活动文档的大小需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 大型活动文档解析需足够时间完成格式转换与内容拆分，避免中途超时 |
| `chunkSettingMode` | 手动配置 | 活动文档格式差异较大，手动配置可灵活调整分块规则适配不同类型文档 |

## 容易做错的三处
- 上传语雀公开链接解析时提示不支持的数据源类型，原因是未确认链接为公开可访问且符合平台解析的格式要求，仅支持公开分享的语雀文档链接，私有链接无法完成解析。
- 调用HTTP工具时参数解析正常但未执行请求，原因是未正确配置工具的触发条件或权限设置，部分场景下需确认请求的目标地址是否在允许的范围内。
- 解析PDF文档后内嵌图片未被正确提取，原因是未开启自定义PDF解析的图片提取开关，默认解析模式可能仅提取文本内容，忽略内嵌图片资源。

## 怎么确认配好了
- 上传一份典型的活动方案PDF，查看解析后的文本块是否保留了原文档的标题与段落结构，核对单块文本的字符长度是否符合`chunkSize`的配置区间。
- 提交合规的语雀公开文档链接，确认解析任务状态显示为完成，且返回的内容包含原文档的全部文本与图片信息。
- 测试配置完成的HTTP工具，查看工具调用日志是否显示参数正确传递，且请求执行状态符合预期。
- 调整`PARSE_FILE_TIMEOUT_SECONDS`为较短数值，上传大型活动文档，确认是否会触发超时报错，验证超时配置的有效性。
