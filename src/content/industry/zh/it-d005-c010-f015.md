# 事件响应与故障处理的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据来源包括监控告警、日志平台、APM工具与用户反馈，核心文档涵盖故障工单、事件时间线、应急预案、故障通报。数据更新频率为实时或每次事件发生后，字段包含故障ID、影响服务范围、发生时间、止损操作步骤、关联告警规则等，部分结构化数据带有时间戳、服务名称等标准化单位，非结构化文档以自然语言记录处理流程与复盘内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据实时更新的特性要求检索环节支持增量同步的数据集，避免召回过期的故障处理记录；文档结构包含结构化工单与非结构化预案，要求检索支持多格式内容的混合召回，兼顾关键词匹配与语义理解；高频更新的特点要求召回结果的时效性匹配事件响应窗口，不能延迟返回；字段关联故障ID、影响服务等信息，要求检索支持按特定字段精准筛选，缩小召回范围以提升决策效率。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配故障相关文档的核心语义，过滤掉与当前问题关联度较低的内容 |
| `limit` | 前3–5条 | 控制单次召回结果数量，适配事件响应的快速决策场景，避免信息过载 |
| `searchMode` | hybrid | 结合关键词与语义检索，适配结构化工单与非结构化预案的混合数据特征 |
| `usingReRank` | 开启 | 对召回结果重排，优先返回与当前故障场景最匹配的预案或工单步骤 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户问题生成扩展查询，覆盖故障场景下的隐含需求，比如关联的监控告警规则 |
| `collectionIds` | 按故障场景绑定的数据集ID | 限定检索范围在当前事件关联的知识库集合，排除无关数据集内容 |

## 容易做错的三处
- 现象：单次召回的结果条数与设置的`limit`参数不符。原因：未正确绑定`collectionIds`限定检索范围，或未校准`limit`的取值适配数据集容量。
- 现象：AI回答包含知识库以外的内容。原因：未启用仅检索知识库内容的配置，导致模型调用外部生成逻辑。
- 现象：检索结果中出现大量重复的故障处理步骤。原因：未设置合理的分块重复率过滤，导致相似分块被多次召回。

## 怎么确认配好了
- 提交与当前故障场景相关的测试问题，核对返回结果的条数是否与`limit`的设置一致。
- 检查AI回答的内容是否全部来自绑定的知识库集合，无外部无关内容。
- 查看检索接口的返回结果，确认格式符合JSON规范，无未转义的特殊字符。
- 模拟更新故障工单后提交相关问题，确认检索结果包含最新的事件记录。
