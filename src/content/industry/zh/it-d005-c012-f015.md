# 云网络与负载均衡配置的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据主要来自云平台控制台导出的VPC规划文档、安全组规则配置、负载均衡配置文件、网络拓扑图与运维变更单。数据更新节奏随单次配置调整触发，每完成一次变更即生成新的版本或条目。文档结构以结构化配置项为主，包含网段范围、端口映射、健康检查阈值、后端服务器组ID等字段，字段多带有明确单位，如C类网段、秒、百分比等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
由于数据更新频率随运维变更实时触发，检索需优先匹配最新的配置条目，避免返回过时的规则。结构化的配置字段要求检索需支持精准匹配字段名称与取值，兼顾模糊匹配描述性文本。单条配置文档内容较长且关联多组参数，需限制召回结果的数量以避免超出上下文窗口。同时，数据按项目或变更单划分，需支持限定检索范围，排除无关的配置内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 该品类的配置项多为标准化数值，该区间可平衡精准匹配与召回覆盖范围 |
| `limit` | `前8–12条` | 单条负载均衡配置文档内容较长，过多召回会导致上下文溢出，影响模型生成结果 |
| `searchMode` | `semantic + keyword` | 该品类同时存在结构化配置字段与描述性文本，混合模式可兼顾精准匹配与语义关联 |
| `usingReRank` | `开启` | 该品类存在大量相似命名的配置项，重排可提升高相关性结果的展示优先级 |
| `datasetSearchUsingExtensionQuery` | `开启` | 该品类的配置常关联变更单、拓扑图等辅助文档，扩展查询可覆盖关联数据 |
| `collectionIds` | `指定目标项目的集合ID` | 该品类的数据按项目或变更单划分，限定集合可排除无关的配置内容 |

## 容易做错的三处
- 现象为点击知识库新建按钮后弹出配置错误提示，可验证排查项为未在App/Admin服务端正确配置`AIPROXY_API_ENDPOINT`（AI Proxy 服务的根地址，不得附加 /v1 或 /chat/completions 等路径，非单模型服务地址）与`AIPROXY_API_TOKEN`（AI Proxy 管理员 Token，需与服务端配置一致且非空，非应用API Key、模型供应商密钥等）环境变量，该配置缺失会触发启动校验失败。
- 现象为搜索结果包含非目标项目的负载均衡配置内容，原因是未通过`collectionIds`参数限定检索的目标知识库集合范围。
- 现象为上传的MD格式文档中图片路径无法正确加载，原因是未配置知识库的资源路径映射规则，导致检索时无法关联图片资源。

## 怎么确认配好了
- 检查App/Admin服务端的环境变量配置，确认`AIPROXY_API_ENDPOINT`（AI Proxy 服务的根地址，不得附加 /v1 或 /chat/completions 等路径，非单模型服务地址）与`AIPROXY_API_TOKEN`（AI Proxy 管理员 Token，需与服务端配置一致且非空，非应用API Key、模型供应商密钥等）已正确填写且非空，该要求适用于FastGPT v4.17.0及以上版本。
- 发起针对负载均衡配置的检索测试，验证返回结果的数量符合`limit`参数的设定范围。
- 测试传入`collectionIds`参数，确认检索结果仅包含指定集合的配置内容。
- 开启`usingReRank`与`datasetSearchUsingExtensionQuery`后，对比检索结果的相关性变化。
