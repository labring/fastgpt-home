# 企业软件许可证管理的技术文档与接口问答：文档解析与分块

## 这个品类的数据长什么样
本品类的数据主要来自软件资产管理系统、采购系统、终端扫描结果及厂商授权文件，日常处理的文档包括许可证台账、软件使用清单、采购合同与合规审计报告。数据更新频率为月度或季度，文档结构多包含授权编号、软件名称、授权数量、使用终端数、到期时间等字段，单位涉及台、套、个等，需匹配厂商授权的标准计量方式。

## 这些特征在「文档解析与分块」这一环带来什么约束
许可证台账的字段关联性强，授权数量与使用终端数需严格对应，解析时需保留字段间的关联关系，避免分块割裂关键信息。采购合同与合规审计报告多为长文本且包含合规条款，分块需兼顾上下文完整性，防止拆分后无法识别授权范围。月度更新的台账数据需适配批量解析的效率要求，超时或分块过大可能导致数据同步延迟。终端扫描的软件使用清单格式不统一，需适配多格式解析的灵活性，同时保证授权状态字段的准确提取。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `chunkSize` | 800–1200 字符 | 适配许可证台账的字段密度与长文本合同的上下文完整性，避免拆分关键授权关联信息 |
| `chunkSplitter` | 按语义分块 | 适配合规审计报告与采购合同的条款结构，保留上下文逻辑 |
| `customPdfParse` | 开启高精度模式 | 针对厂商授权文件的PDF格式，提取嵌入的授权编号与盖章信息，避免OCR误差 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配批量上传的季度更新合规审计报告，避免单次上传超限 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 适配长文本合规审计报告的解析时长，防止中途超时中断 |
| `chunkSettingMode` | 手动配置 | 针对不同类型的许可证管理文档，灵活调整分块参数，适配台账与合同的差异化需求 |

## 容易做错的三处
- 上传许可证台账PDF后搜索无结果，界面显示解析错误。原因是未开启`customPdfParse`高精度模式，导致嵌入的授权编号字段未被正确提取。
- 升级后无法找到对应解析功能。原因是FastGPT v4.17.0版本默认关闭了旧版解析插件，需在`customPdfParse`配置中切换至适配的解析引擎。
- 解析大型合规审计报告时触发OCR Error。原因是未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，长文本解析超时导致OCR流程中断。

## 怎么确认配好了
- 上传单份许可证台账PDF，查看解析后的文本中是否包含授权编号、软件名称等核心字段，确认字段完整性。
- 上传批量季度更新的软件使用清单，检查解析任务的完成状态，确认未出现超时报错。
- 触发搜索测试，输入授权数量核对相关的问题，查看返回结果是否包含分块后的关联信息，确认上下文未被割裂。
- 调整`chunkSize`参数至区间边界值，验证解析后的分块数量是否符合预期，确认配置生效。
