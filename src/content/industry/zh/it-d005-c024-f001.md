# 信息流广告创意测试的技术文档与接口问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的核心数据来自广告投放平台、内部素材库、用户互动与转化数据，更新节奏通常为日度或周度。日常产出的文档包括创意脚本、素材测试表、投放数据报告与迭代清单，字段包含创意素材类型、变量组合、投放时段、转化指标等，单位多为次、元、字符、秒。数据围绕图文、视频类创意的测试变量展开，需同步多源数据以完成疲劳判断与效果归纳，整体数据结构随测试迭代动态调整，与搜索广告的关键词管理数据结构存在明显差异。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多源数据来源要求接口需适配不同广告平台的鉴权规则，避免因鉴权配置错误导致数据拉取失败。日度或周度的更新节奏要求接口调用频次需匹配数据更新周期，防止过度调用触发平台限流。多样的文档结构需要通过接口参数传递不同类型的测试变量，确保创意脚本、测试变量等信息可被准确识别。素材违规的风险要求接口返回内容需包含合规校验字段，以便快速定位违规素材。

## 配置怎么定
本文基于 FastGPT v4.17.0 版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer Token` 格式，携带广告平台分配的有效令牌 | 适配多广告平台的鉴权规则，确保接口可正常拉取投放数据 |
| `variables` | 传递10–50个创意变量组合，包含素材类型、文案变体、投放定向参数 | 匹配品类内测试变量的数量范围，确保接口可处理批量测试需求 |
| `responseData` | 指定返回点击率、转化成本、合规状态字段 | 过滤非必要数据，聚焦创意测试的核心指标 |
| 调用频次限制 | 100 次/天 | 匹配日度数据更新节奏，避免触发广告平台限流 |
| 超时设置 | 60 秒 | 适配广告平台接口的平均响应时长，防止测试任务中断 |
| 批量参数上限 | 单次传递不超过20组测试变量 | 平衡接口负载与测试效率，避免参数过长导致请求失败 |

## 容易做错的三处
- 调用语音素材上传接口返回400错误，`responseData`字段为空。未在`variables`中指定语音素材的格式与存储路径参数，导致接口无法识别上传请求。
- 导入工作流模板后界面显示成功，但工作流无任何节点。未在`Authorization`中配置对应广告平台的鉴权令牌，导致模板依赖的外部资源未正确拉取。
- 调用接口后未返回文本嵌入的状态查询入口。未通过`responseData`指定返回嵌入任务的状态查询字段，导致结果未包含对应信息。

## 怎么确认配好了
- 调用鉴权接口，返回有效令牌后验证`Authorization`头的格式与令牌内容正确。
- 向接口传递一组测试变量组合，检查`variables`字段的格式符合预设要求。
- 发起一次测试请求，查看`responseData`返回字段是否包含核心投放指标与合规校验结果。
- 模拟日度调用频次，确认接口未触发限流提示，且返回数据完整。
