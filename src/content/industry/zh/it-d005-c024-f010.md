# 信息流广告创意测试的技术文档与接口问答：引用来源与溯源

## 这个品类的数据长什么样
信息流广告创意测试的日常文档包含创意脚本、素材测试表、投放数据报告与迭代清单。数据来源覆盖广告平台接口、内部素材库、用户互动数据与转化数据，更新频率分为日更与周更两类。文档字段包含素材ID、文案内容、投放时段、点击率、转化成本、测试组号等，不同文档的结构差异明显，创意脚本侧重变量组合，测试表侧重量化测试结果，投放报告侧重整体投放表现。

## 这些特征在「引用来源与溯源」这一环带来什么约束
多源数据与差异化文档结构要求溯源系统需关联不同类型的文档标识，避免混淆创意脚本与投放数据的来源。日/周级别的更新频率要求知识库定期增量同步，确保溯源内容与最新测试结果一致。创意变量设计与疲劳判断的高耗时环节，要求溯源能快速定位到对应文档片段，减少重复查找成本。素材违规与成本升高的出错后果，要求溯源结果必须精准匹配提问主题，避免返回无关内容影响决策。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | 匹配信息流创意文案与测试数据的总长度，避免截断溯源所需的关键信息 |
| `responseData` | 仅返回文档标题、片段文本、来源路径 | 适配创意团队快速定位素材文档的工作需求 |
| `detail` | 开启 | 保留完整的文档溯源字段，便于排查素材疲劳判断的具体依据 |
| 单次搜索上限 | 前5条 | 过滤冗余的历史测试数据，聚焦当前核心创意测试的关联内容 |
| 文档分块重叠长度 | 50–80 字符 | 保留创意脚本与测试表的上下文关联，避免溯源时丢失变量组合信息 |
| 召回匹配阈值 | 按实测标定 | 过滤非创意相关的投放数据，精准匹配信息流广告创意测试的主题 |

## 容易做错的三处
- 知识库返回与提问无关的内容。原因是未设置合理的召回匹配阈值，导致召回了非创意相关的投放数据或通用文档。
- 溯源信息缺失文档来源路径。原因是未正确配置`responseData`的返回字段，仅返回了文本片段未关联来源标识。
- 溯源内容被截断无法完整匹配创意变量。原因是`quoteMaxToken`取值过小，截断了测试表中的转化成本或测试组号等关键字段。

## 怎么确认配好了
- 发起包含具体创意变量的提问，检查返回结果是否关联到对应的创意脚本或测试表文档。
- 查看回答下方的溯源模块，确认包含文档标题、来源路径与片段文本的完整信息。
- 测试提问与创意测试无关的内容，检查是否无匹配结果返回。
- 在FastGPT v4.17.0版本中，确认`detail`参数处于开启状态，确保溯源字段完整。
