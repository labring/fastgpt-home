# 办公系统流程配置的技术文档与接口问答：向量模型与索引

## 这个品类的数据长什么样
该品类的数据主要来自企业OA系统、组织架构库、内部制度文件及用户反馈工单。日常处理的文档包含流程配置单、审批节点表、表单字段说明与变更记录。数据更新无固定周期，随业务流程变更随时触发，平均每月至少更新一次。数据结构多为结构化表格与短文本说明，包含审批节点权限、字段校验规则、流转路径等核心配置信息。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据特征对向量模型与索引环节带来三点约束。首先，结构化表格与短文本为主的文档结构，要求分块策略需兼顾单块内容完整性与语义关联性，避免拆分审批节点的层级关联。其次，随业务变更的高频更新特性，要求索引更新策略支持增量同步，避免全量重建带来的性能损耗。最后，核心配置信息多为权限、规则类语义，要求向量模型需具备精准的语义匹配能力，同时需限制分块长度以适配模型的上下文窗口限制。

以下配置适配FastGPT v4.17.0版本：
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配流程配置单、审批节点表的单条内容长度，避免分块过碎或丢失关键规则 |
| 重叠长度 | 100–200 字符 | 保留审批节点间的流转逻辑关联，防止跨块上下文断裂 |
| 相似度阈值 | 0.75–0.85 | 匹配审批规则、字段说明的语义相似度，过滤低相关性召回结果 |
| 单次搜索上限 | 前 10 条 | 覆盖常见的流程配置查询场景，平衡召回效率与结果数量 |
| maxToken | 8192 | 适配主流开源嵌入模型的上下文窗口，避免截断关键配置信息 |
| defaultToken | 1000 | 适配嵌入模型的默认上下文填充需求，优化短文本的向量生成效果 |

## 容易做错的三处
- 现象：新增Qwen/Qwen3-Embedding-8B嵌入模型配置时，原有同名配置被自动覆盖。原因：系统默认以模型名称作为唯一配置标识，未提供分组或重命名管理功能。
- 现象：导入Excel格式的审批节点表后，生成向量时提示内容过长。原因：未针对结构化表格数据调整分块长度，默认分块参数未适配表格单块的最大容量。
- 现象：查询审批权限规则时，召回结果包含大量不相关的表单字段说明。原因：相似度阈值设置过低，导致低语义匹配的内容被误召回。

## 怎么确认配好了
- 导入单份流程配置单，检查生成的分块数量与预期一致，无内容截断或过度拆分的情况。
- 提交包含审批节点名称的查询，核对召回结果的语义相关性，确认符合预设的相似度阈值区间。
- 尝试新增同名嵌入模型配置，确认系统提示重复配置或保留原有配置，无自动覆盖行为。
- 上传Excel格式的审批节点表，验证分块后的数据长度未超出向量模型支持的最大范围。
