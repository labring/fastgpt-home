# 后端服务开发的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
这个品类的数据主要来自代码仓库、API网关日志、数据库、配置中心，更新频率多为每日或每版本发布周期。日常使用的文档包括接口设计文档、数据库变更单、代码评审记录、服务发布说明，数据多包含接口路径、请求参数、返回格式、变更生效时间、评审意见等字段，无统一固定的单位，部分字段关联版本号或环境标识。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散且类型多样，要求检索配置需支持多数据源的统一适配，避免出现跨来源的匹配偏差。更新频率较高，需配置增量同步机制确保索引与源数据的时效性，防止检索返回过时的接口或变更内容。字段关联版本与环境标识，检索时需加入对应维度的过滤条件，避免跨版本调用错误接口或读取非当前环境的配置数据。同时，后端场景的核心耗时环节聚焦接口契约确认与异常排查，要求检索结果需精准匹配接口参数、事务边界等关键内容，减少无效信息干扰。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 适配后端接口文档的精准匹配需求，过滤低相关的非接口类内容 |
| `limit` | 前10条 | 平衡检索结果的全面性与系统资源占用，适配后端团队批量查看接口信息的场景 |
| `searchMode` | hybrid | 结合关键词与语义检索，覆盖接口路径、参数描述、变更记录等不同类型的检索需求 |
| `usingReRank` | 开启 | 对初步检索结果进行重排序，提升高相关接口文档、变更单的展示优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展检索词，补充接口关联的日志、评审记录等延伸内容 |
| `collectionIds` | 按业务环境指定 | 限定检索范围在当前环境的知识库集合，避免跨环境的无效检索 |

## 容易做错的三处
- 现象：强制关闭知识库检索开关后，返回结果仍包含非配置范围内的文档片段。原因：未正确指定`collectionIds`参数，导致检索范围未被限定，默认检索了全量知识库内容。
- 现象：检索结果未结合当前会话的接口版本上下文，返回过时的数据库变更单或发布说明。原因：未开启`datasetSearchUsingExtensionQuery`，或未将上下文的版本信息作为检索过滤条件。
- 现象：在FastGPT v4.17.0之前的版本中，执行批量检索时出现页面崩溃或请求超时。原因：`limit`参数设置过高，或`similarity`阈值过低，导致返回结果数量超出系统处理上限。

## 怎么确认配好了
- 查看检索日志，确认返回结果的关联集合与配置的`collectionIds`一致，验证范围限定生效。
- 输入包含接口路径、版本号的检索词，检查返回结果的相关性是否符合预期，验证`similarity`与`searchMode`配置生效。
- 执行批量检索操作，确认系统未出现异常报错或资源占用过高的情况，验证`limit`与`usingReRank`的配置合理。
- 关闭知识库检索开关，确认返回结果中无配置外的文档片段，验证检索范围限定逻辑生效。
