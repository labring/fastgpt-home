# 售前技术方案的技术文档与接口问答：文档解析与分块

## 这个品类的数据长什么样
该品类的数据主要来自客户访谈、招标文件、厂商产品资料及历史项目方案。日常处理的文档包含技术方案书、客户需求调研表、报价清单、演示脚本四类，结构差异明显，既有结构化的报价明细，也有大段的技术路线描述。数据更新以每单或每周为频率，单份售前项目文档可能包含多类格式的附件。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的文档来源多样且结构差异大，要求文档解析环节需适配不同格式的附件，避免丢失结构化信息。更新频率较高的特性要求解析流程具备快速响应能力，适配单周或单项目的迭代需求。售前文档直接关联投标与项目边界，分块环节需精准保留技术路线、实施边界等核心内容，避免因分块断裂导致关键信息丢失。同时，单份文档体积可能较大，需适配较大文件的上传与解析流程，避免因文件超限导致任务失败。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 售前技术方案多为技术段落，该长度可覆盖完整技术逻辑且避免跨块拆分 |
| `chunkSplitter` | 按段落+语义分块 | 文档包含结构化报价清单与大段技术描述，语义分块可保留上下文连贯性 |
| `customPdfParse` | 启用 | 售前文档多为格式复杂的扫描件或多格式合集，自定义解析可保留公式、表格结构 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 大型招标文件或多页方案书解析耗时较长，避免超时中断任务 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 单份售前方案合集可能包含多份文档，需适配较大文件上传需求 |
| `chunkSettingMode` | 手动配置 | 不同类型售前文档的分块需求差异明显，手动配置可精准适配各类场景 |

## 容易做错的三处
- 现象：调用关联大模型时无法调起文件解析工具，原因：未在知识库配置中启用`customPdfParse`且未正确关联解析服务
- 现象：本地部署版本无法解析复杂公式，线上版本可正常返回，原因：未使用FastGPT v4.17.0及以上版本的公式解析适配逻辑，旧版本对复杂LaTeX公式的分块支持不足
- 现象：docker部署解析镜像时启动失败，原因：未正确挂载GPU驱动目录或未指定符合要求的镜像版本参数，导致解析服务无法正常运行

## 怎么确认配好了
- 上传一份包含技术方案书、报价清单的合集文档，查看解析后的分块结果是否保留了各类文档的结构与核心内容
- 测试上传单份500 MB以内的文档，确认上传与解析流程无超时或文件超限报错
- 在对话中调用关联的知识库，验证是否能准确提取方案中的技术路线与实施边界描述
- 查看后台任务日志，确认解析任务的耗时未超过配置的`PARSE_FILE_TIMEOUT_SECONDS`阈值
