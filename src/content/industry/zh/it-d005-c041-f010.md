# 图像标注项目的技术文档与接口问答：引用来源与溯源

## 这个品类的数据长什么样
这个品类的数据主要来自标注平台存储的图片样本、类别字典、标注过程产生的框选样例、质检报告与返工清单。数据更新节奏通常为每日或按标注批次更新，单条数据包含视觉目标的边界框坐标、类别标签、标注与质检人员标识、抽检结果等字段。日常依托的文档包括统一标注规范、样例参考文件，用于对齐标注标准与返工要求。

## 这些特征在「引用来源与溯源」这一环带来什么约束
图像标注项目的视觉类数据与文档特征，会对引用溯源环节带来多重约束。首先，图片样本与框选样例的关联需要精准匹配视觉内容，无法仅通过文本关键词检索完成溯源，需同时关联图片ID与标注批次信息。其次，按批次更新的数据要求溯源时绑定对应批次的标注规范与质检结果，避免跨批次引用失效。另外，返工清单与质检报告的字段包含大量状态类标识，需在溯源时保留字段完整性，确保AI回答可匹配到具体的返工判定依据，支撑标注质量的可追溯性。

## 配置怎么定
本页面适配FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 字符 | 匹配图像标注文档与数据的单条内容长度，避免截断关键的边界框坐标与类别信息 |
| `responseData` | 仅返回关联文档ID与原始链接 | 适配标注团队需要快速跳转至原始标注记录的需求，避免冗余内容干扰 |
| `detail` | high | 保留标注数据的完整字段，确保溯源时可获取边界框坐标、抽检结果等关键信息 |
| 单次搜索上限 | 前 3 条 | 限制返回的标注批次文档数量，避免过多数据超出上下文窗口 |
| 上下文窗口阈值 | 4000 字符 | 适配图像标注数据的字段长度，确保所有关联信息可完整传入大模型 |

## 容易做错的三处
- 现象：AI回答中未显示原始标注文档的链接，仅展示文本摘要。原因：未正确配置`responseData`参数，未开启原始链接返回功能。
- 现象：检索结果包含跨批次的标注数据，导致标注规范引用错误。原因：未绑定标注批次ID作为检索过滤条件，未限制单次搜索的批次范围。
- 现象：AI回答截断了边界框坐标等关键视觉信息。原因：`quoteMaxToken`取值过小，无法容纳完整的标注数据字段。

## 怎么确认配好了
- 发起包含边界框坐标关键词的测试提问，核对AI回答中是否返回对应文档的原始链接。
- 提交指定标注批次的测试请求，确认检索结果仅包含该批次的标注规范与质检报告。
- 查看大模型上下文窗口日志，确认传入的标注数据字段未被截断。
- 调整配置项后，重复测试提问，验证返回结果的字段完整性与链接准确性。
