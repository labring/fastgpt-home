# 图像标注项目的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
图像标注项目的日常数据来源包含图片样本、标注平台操作日志、类别字典与抽检结果，更新频率为日或每批。日常文档包括标注规范、框选样例、质检报告与返工清单，其中标注规范包含类别定义与边界框绘制规则，框选样例附带样本ID与坐标参数，质检报告记录抽检通过率与返工率，返工清单标注问题点位与整改要求。数据多为结构化的视觉关联内容，无纯文本泛化内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束
图像标注项目的数据特征对检索召回环节带来明确约束。首先，高频更新的数据源要求检索链路支持快速增量同步，避免数据滞后影响标注与质检流程。其次，数据包含边界框坐标、样本ID等结构化业务字段，要求检索配置需支持精准匹配特定字段，过滤无关的跨项目内容。第三，专业的标注规则、视觉框选样例等文档，要求召回结果需与边界框定、遮挡样本判定等细分场景强相关，提升检索针对性，降低返工风险。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本，具体参数设置如下：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配标注规范、框选样例这类专业文档，该区间可过滤低相关结果，避免无效召回干扰标注流程 |
| `limit` | 前3–5条 | 图像标注文档单篇内容聚焦特定场景，少量结果即可覆盖标注、质检的核心需求 |
| `searchMode` | `vector` | 适配带坐标、视觉描述的结构化文档，向量检索可精准关联视觉相关的标注规则 |
| `usingReRank` | 开启 | 针对遮挡样本判定、边界框定这类细分场景，重排可提升高相关文档的排序权重 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充标注术语的扩展查询，匹配类别字典、返工清单中的专业术语关联 |
| `collectionIds` | 绑定标注团队专属知识库集合 | 隔离不同项目的标注数据，避免跨项目的无关内容干扰检索 |

## 容易做错的三处
- 现象：API调用工作流返回空值，原因：未在`collectionIds`中绑定标注项目专属的知识库集合，或使用了v4.8.10以下的FastGPT版本。
- 现象：检索时出现`quote type error`报错，原因：传入的检索变量未匹配文档中结构化字段的格式要求，如边界框坐标的数值类型未正确传递。
- 现象：检索结果未包含通过外部搜索获取的标注相关内容，原因：未将外部搜索结果同步至专属知识库集合，或未开启`datasetSearchUsingExtensionQuery`关联外部查询内容。

## 怎么确认配好了
- 检查`collectionIds`是否绑定了标注项目专属的知识库集合，确认无跨项目的无关数据被纳入检索范围。
- 发起测试检索，输入“遮挡样本边界框判定规则”，查看返回结果是否包含标注规范或框选样例相关文档。
- 开启`usingReRank`后，对比重排前后的结果排序，确认高相关的遮挡样本处理内容排序靠前。
- 传入带坐标格式的变量发起检索，确认无`quote type error`报错，返回结果匹配变量对应的业务场景。
