# 备份恢复与灾备演练的技术文档与接口问答：引用来源与溯源

## 这个品类的数据长什么样
本品类数据主要来自备份系统、数据库日志、对象存储及灾备平台，日常产出备份策略、恢复演练报告、灾备切换预案、数据校验记录四类文档。数据更新频率涵盖日、月、季，文档字段包含备份路径、恢复点标识、校验哈希值、演练执行时间等，单位多为时间戳、字节数、百分比（校验通过率），且需关联跨系统的备份链路信息，区别于单数据库实例的运维数据。

## 这些特征在「引用来源与溯源」这一环带来什么约束
本品类跨系统的数据来源，要求引用溯源环节需关联备份系统、数据库日志、对象存储及灾备平台的唯一标识，避免混淆不同节点的备份记录；多更新频率的文档需匹配对应数据的更新周期，确保引用的是当前生效的备份策略或最新校验结果；数据校验记录的哈希值字段需作为溯源核心锚点，保障恢复结果的一致性核验可追溯；演练报告需覆盖脚本执行、恢复点确认等核心环节的关联关系，确保溯源链路完整，且需支持跨系统的链路追溯逻辑。

## 配置怎么定
本文档适配FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 最大引用上下文 | 前800–1200字符 | 匹配本品类备份策略、校验记录的单文档平均长度，避免截断核心字段 |
| 单次搜索上限 | 前5条 | 对应灾备演练的核心关联节点数量，覆盖主要备份链路的溯源需求 |
| 引用来源展示开关 | 开启 | 需向运维人员展示备份系统、对象存储的具体来源路径，满足合规核验要求 |
| `quoteMaxToken` | 600 token | 适配本品类多字段关联的溯源内容长度，保障完整展示校验哈希值、恢复点标识等关键信息 |
| 溯源锚点字段 | 恢复点标识、校验哈希值 | 匹配本品类文档的核心唯一标识字段，确保溯源结果准确对应具体备份实例 |

## 容易做错的三处
- 现象：输入关于灾备恢复的提问后，返回与备份恢复与灾备演练无关的内容。原因：未配置本品类专属的溯源锚点字段，导致搜索匹配到非灾备相关的文档，未过滤无关数据源的内容。
- 现象：引用来源展示为空或未显示备份系统、对象存储的具体路径。原因：关闭了引用来源展示开关，未开启跨平台来源的展示配置，无法关联多数据源的溯源信息。
- 现象：溯源结果关联了错误的恢复点或校验记录。原因：未使用恢复点标识、校验哈希值作为核心锚点，混淆了不同更新周期的备份数据，导致溯源链路混乱。

## 怎么确认配好了
- 发起一次针对恢复演练报告的测试提问，核对返回结果中是否包含本品类专属的文档类型。
- 查看引用来源模块，确认是否展示了备份系统、对象存储的对应路径信息。
- 验证溯源锚点的匹配逻辑，输入已知恢复点标识的关键词，核对返回结果是否仅关联对应备份实例的记录。
- 调整`quoteMaxToken`的取值，确认长文档的核心字段（如校验哈希值）未被截断。
