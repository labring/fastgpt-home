# 安全培训与钓鱼演练的技术文档与接口问答：文档解析与分块

## 这个品类的数据长什么样
该品类的典型数据来自安全运营、内训团队及外部安全服务商，日常文档包含培训课件、演练方案、钓鱼邮件模板、演练结果报告四类。数据来源涵盖员工通讯录、邮件网关、内部培训平台及用户点击统计系统，更新频率多为季度或年度。文档结构包含结构化的演练步骤、非结构化的邮件文本、统计类的结果字段，无固定统一的单位格式，部分文档内嵌示例图片或表格。

## 这些特征在「文档解析与分块」这一环带来什么约束
四类文档的差异要求解析工具兼容多种格式，培训课件与演练报告多为pdf或导出的markdown格式，需保留内嵌图片与排版结构；钓鱼邮件模板需完整保留文本上下文，避免拆分破坏话术逻辑。数据来源包含网页链接（如语雀公开文档），需支持无权限限制的网页解析。低更新频率意味着解析流程需稳定可靠，避免因单次解析失败影响批量任务。统计类数据的字段无统一格式，需保留原始文本结构以支持后续问答。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的参数逻辑。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 800–1200 字符 | 品类文档多为培训课件、演练报告，单块内容需覆盖完整操作步骤或模板片段，避免拆分关键信息 |
| `chunkSplitter` | markdown | 日常文档多为pdf转markdown或语雀网页解析结果，按markdown分块可保留标题、列表等结构 |
| `customPdfParse` | 开启 | 培训课件多为pdf格式，开启后可提取内嵌图片与保留原有排版 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 大型批量演练报告解析耗时较长，避免因超时导致解析失败 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 部分批量培训课件包体积较大，需适配大文件上传需求 |
| `chunkSettingMode` | manual | 需针对不同文档类型（邮件模板、演练报告）调整分块规则，适配场景化需求 |

## 容易做错的三处
- 现象：上传pdf培训课件后解析结果无内嵌图片，或图片无法被大模型调用。原因：未开启`customPdfParse`配置，默认解析流程未提取内嵌图片的二进制数据。
- 现象：输入语雀公开分享链接后提示无法解析。原因：未确认链接为完全公开可访问状态，或未开启网页解析适配功能。
- 现象：上传钓鱼邮件模板后，解析结果出现内容截断或上下文断裂。原因：`chunkSize`设置过小，将完整的邮件模板内容拆分为多个独立块，丢失前后文关联逻辑。

## 怎么确认配好了
- 上传一份测试用的pdf培训课件，检查解析结果是否保留所有内嵌图片与原有排版。
- 输入一条测试用的公开网页链接，确认解析任务状态为成功且提取的内容完整无缺失。
- 调整`chunkSize`至不同区间，上传一份钓鱼邮件模板文档，检查是否未出现内容截断情况。
- 上传一个超过常规单文件体积的演练报告，确认解析任务未触发超时错误。
