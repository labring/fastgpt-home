# 客户培训与使用手册的技术文档与接口问答：向量模型与索引

## 这个品类的数据长什么样
该品类的数据主要来自产品帮助中心、客户组织架构、培训录屏与工单系统，日常文档包含培训课件、用户手册、培训签到表、问题答疑清单。数据更新频率为每单或每版本，文档结构多为分步操作说明、权限配置说明、常见问题条目，部分录屏类数据需先转写为文本再处理。字段包含操作步骤编号、权限角色名称、问题分类标签，无统一固定单位，部分字段需结合客户业务场景补充。

## 这些特征在「向量模型与索引」这一环带来什么约束
数据来源分散导致文本格式多样，需适配纯文本、转写文本两类输入，索引时需统一预处理规则。更新频率频繁要求索引流程支持增量更新，避免全量重建耗时过长，影响培训文档的及时同步。文档以分步说明、权限条目为主，内容颗粒度差异大，需匹配合适的分块规则避免语义割裂，防止切断操作步骤的前后关联。工单系统的问答数据多为短文本，需单独调整分块参数适配短内容的向量化需求。客户组织架构数据涉及权限角色，需保留字段关联信息，避免索引时丢失权限相关的语义关联。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配该品类分步操作、权限说明类文档的语义完整性，避免单块内容过碎或过长 |
| 重叠长度 | 100–200 字符 | 覆盖分步操作的前后衔接语义，防止分块切断操作步骤的关联逻辑 |
| 相似度阈值 | 0.72–0.85 | 匹配该品类问答的精准性需求，过滤低相关的权限说明或操作步骤内容 |
| 单次搜索上限 | 前 5 条 | 控制返回结果的信息量，避免过多操作步骤干扰用户查询 |
| `maxToken` | 4096 token | 适配大模型上下文窗口限制，确保整合的文档内容不会超出模型处理范围 |
| `defaultToken` | 256 token | 用于控制单条召回内容的输出长度，适配短问答类的问题答疑清单数据 |

## 容易做错的三处
- 现象：调用多模态向量模型时出现调用失败报错，返回不支持指定模型的提示。原因：未在系统配置中添加对应多模态模型的接入密钥与接口地址，仅配置了通用文本向量模型。
- 现象：索引完成后搜索结果条数与预期不符，部分工单问答数据未被召回。原因：未针对短文本类的问题答疑清单调整分块参数，导致短内容被过滤或未正确分块入库。
- 现象：使用关联查询工具时无法关联客户组织架构的权限字段。原因：索引时未保留字段关联信息，仅对纯文本内容进行向量化，丢失了角色与权限的语义关联。

## 怎么确认配好了
- 上传单份用户手册文档，触发手动索引，查看索引日志中的分块数量，确认分块长度与重叠长度的配置生效，本核对流程基于FastGPT v4.17.0版本。
- 发起一条包含操作步骤的查询，核对返回结果的相关性，确认相似度阈值的配置符合业务需求。
- 测试调用多模态向量模型的接入接口，查看返回结果是否包含对应特征的向量数据，确认模型配置正确。
- 导入客户组织架构的权限数据，使用关联查询工具，确认返回结果包含角色与权限的关联信息。
