# 容量规划与资源扩缩容的技术文档与接口问答：文档解析与分块

## 这个品类的数据长什么样
该品类的数据来源包括云账单、监控系统、业务预测工具、压测报告。更新频率多为周度或月度。典型文档包含容量规划报告、扩容申请单、资源利用率报表、预算测算表，结构多混合结构化表格、数值指标与文本分析内容。字段通常包含资源类型、使用量、预测峰值、预算额度等，对应单位涉及计算核心、存储容量、货币金额等。

## 这些特征在「文档解析与分块」这一环带来什么约束
数据来源的混合性要求解析环节需同时适配结构化报表与非结构化分析内容，避免遗漏关键指标。周度或月度的更新频率意味着无需高频解析，分块无需考虑实时同步需求。文档内的数值与关联说明常分散在连续段落中，分块需保留逻辑关联，避免拆分包含完整资源分析的内容。特定字段与单位的存在要求解析后的数据需保留原始格式，避免单位与数值分离。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `chunkSize` | 800–1200 字符 | 容量规划文档多含数值与文本混合内容，该长度可保留单组资源预测的完整信息，避免拆分关键指标 |
| `chunkSplitter` | 按段落+语义拆分 | 文档包含结构化报表与非结构化分析内容，语义拆分可保留逻辑关联 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 大型压测报告与月度云账单报表解析耗时较长，该范围可覆盖常规解析需求，避免中途中断 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 月度云账单汇总文件可能体积较大，该上限可覆盖常规批量上传需求 |
| `customPdfParse` | 启用 | 容量规划文档多含自定义表格与图表，自定义解析可适配非标准格式 |
| `chunkSettingMode` | 手动配置 | 不同类型的容量规划文档结构差异较大，手动配置可精准适配业务需求 |

## 容易做错的三处
- 现象：调用文档解析相关API时，图片参数传递错误导致解析失败或结果为空。原因：未参照官方接口文档正确配置图片参数的格式与传递方式。
- 现象：解析后的分块内容出现关键资源指标被拆分的情况。原因：`chunkSize`设置值过小，切断了包含完整分析内容的文本段落。
- 现象：批量上传大型容量规划报表时触发超时错误。原因：`PARSE_FILE_TIMEOUT_SECONDS`的配置值低于实际解析所需的时长。

## 怎么确认配好了
- 针对FastGPT v4.17.0版本，上传一份典型的月度容量规划报告，查看解析后的分块列表，确认每个分块包含完整的资源分析或预测内容。
- 调用文档解析接口，检查返回的分块数据中是否包含文档内的核心字段，如资源类型、使用量、预测峰值等。
- 上传单份体积接近`UPLOAD_FILE_MAX_SIZE`配置值的测试文件，确认解析过程未触发上传限制或超时错误。
- 启用`customPdfParse`配置后，上传包含自定义表格的扩容申请文档，确认解析后的表格结构未出现错乱。
