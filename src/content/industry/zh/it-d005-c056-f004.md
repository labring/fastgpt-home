# 对象存储与备份服务的技术文档与接口问答：向量模型与索引

## 这个品类的数据长什么样
该品类的数据主要来自对象存储控制台、备份系统、访问日志与客户策略表，日常生成的文档包括存储桶配置细则、备份策略配置、恢复操作记录、生命周期规则文档。数据更新频率为每日更新或随策略变更实时更新，字段包含存储桶权限、备份任务状态、恢复耗时、生命周期触发条件等，部分字段以字符串、布尔值或时间戳形式存在，无统一固定的单位标准。

## 这些特征在「向量模型与索引」这一环带来什么约束
数据来源分散且更新节奏不一致，要求向量索引支持多源数据的增量同步更新，避免全量重建带来的性能损耗。不同类型文档结构差异较大，存储桶配置、备份策略等文本长度与格式各不相同，向量切分需适配多样的文本片段长度。恢复记录与访问日志包含敏感权限字段，向量处理时需规避敏感信息泄露风险。每日或实时的更新频率要求索引具备快速更新能力，保障检索数据的时效性。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本，适配对象存储与备份服务的各类业务文档场景：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 相似度阈值 | 0.75–0.85 | 适配存储桶配置、备份策略等文本的语义匹配精度，过滤低关联结果 |
| 分块长度 | 800–1200 字符 | 匹配日常文档的段落长度，减少跨块语义断裂 |
| 重叠长度 | 100–150 字符 | 保留块间语义衔接，避免关键配置项被拆分到不同块中 |
| `defaultToken` | 8192 | 适配多数向量模型的输入上限，满足多数备份策略文档的处理需求 |
| `maxToken` | 16384 | 覆盖最长的恢复记录或生命周期规则文档，避免截断关键信息 |
| 单次召回上限 | 前 10 条 | 控制检索返回量，适配运维人员的快速查询场景 |

## 容易做错的三处
- 现象：检索结果中出现大量与目标文档无关的备份日志片段，相似度分数普遍超出预设范围。原因：未设置合理的相似度阈值，导致低关联文本被误判为高匹配结果。
- 现象：辅助的权限策略日志未被纳入索引范围，检索时无法获取相关配置信息。原因：未将辅助数据源添加至索引同步列表，仅同步了核心存储桶配置文档。
- 现象：上传本地向量化后的备份数据至服务器后，检索无匹配结果。原因：本地与服务器使用的向量模型输入格式不一致，导致向量嵌入无法匹配索引规则。

## 怎么确认配好了
- 上传单篇存储桶配置文档，发起检索请求，核对返回结果的相似度分数是否符合预设阈值范围。
- 模拟备份策略变更操作，查看索引更新状态，确认增量同步机制正常生效。
- 导入一组多源数据，验证不同类型文档的向量切分与嵌入结果符合预期。
- 调用接口测试检索功能，确认返回结果条数与单次召回上限配置一致。
