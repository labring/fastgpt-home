# 广告素材审核的技术文档与接口问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
本品类核心数据包括广告素材文案、落地页截图、审核意见与修改记录，数据来源覆盖广告投放平台、落地页服务器、商品资质系统与广告法合规条款库。数据更新频率为日级或实时，实时更新的素材需随投放计划同步拉取。文档结构包含素材唯一标识、文案内容、图片二进制流、审核状态、违规点明细等字段，单位多为字符、像素、时间戳，无复杂嵌套层级。单条素材数据量通常在数百KB至数MB之间，需支持多格式文件与结构化文本混合传输。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多源数据来源要求接口支持跨广告平台、落地页服务器等系统拉取数据，或接收外部系统推送的批量素材文件。实时或日级的数据更新节奏，要求接口具备增量同步能力，避免全量拉取占用过多系统资源。多格式混合的文档结构，要求接口同时支持结构化文本与二进制文件流的传输。单条素材数据量较大的特点，要求接口设置合理的超时阈值与分片上传备选方案。高风险的出错后果，要求接口返回明确的状态码与详细错误信息，便于快速定位问题。同时，素材审核需绑定唯一投放标识，要求接口支持传入业务上下文参数，确保审核结果与对应素材准确绑定。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 授权方式 | 使用`Authorization`头携带Bearer token | 符合FastGPT v4.17.0的安全认证规范，避免明文传输密钥 |
| API请求超时时间 | 600秒 | 适配单条素材审核的完整处理时长，避免因审核流程较长触发超时中断 |
| 请求体格式 | multipart/form-data | 支持同时上传多张广告素材图片与结构化审核参数，符合多文件传输需求 |
| 响应数据格式 | 配置`responseData`为JSON结构 | 便于外部系统解析审核结果、违规点明细与任务状态 |
| 业务上下文参数 | 通过`variables`传入广告素材ID与投放计划标识 | 确保审核结果与对应广告投放素材绑定，便于后续合规溯源与数据关联 |
| 单次请求最大文件数 | 前5张 | 平衡传输效率与接口负载，避免单请求文件过多导致超时 |

## 容易做错的三处
- 现象：调用接口上传多张广告素材图片时返回400 Bad Request错误。原因：未正确配置multipart/form-data请求头，或未将图片文件作为独立表单字段提交。
- 现象：通过Langchain对接FastGPT应用时无法获取流式审核响应。原因：未启用FastGPT的流式输出配置，或未按Server-Sent Events格式处理接口返回的响应流。
- 现象：调用数据集集合创建接口时返回字段缺失错误。原因：未通过`variables`传入广告素材关联的业务参数，或参数格式不符合接口要求。

## 怎么确认配好了
- 调用接口上传单张广告素材图片，检查返回状态码为200且`responseData`中包含审核任务ID。
- 配置`Authorization`头后调用接口，检查无401 Unauthorized未授权错误。
- 启用流式响应配置后，通过外部工具对接接口，检查能逐段接收审核结果片段。
- 上传落地页截图后，检查接口返回的违规点标注字段不为空，且包含对应素材的审核明细。
