# 广告素材审核的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的核心数据包含广告素材文案、落地页截图、历史审核意见、商品资质文件及广告法合规条款。数据来自广告投放平台、落地页后台、商品资质系统与公开合规文档，更新频率为日级或实时。单条数据结构包含素材唯一标识、投放渠道、审核状态、违规类型字段，无统一固定单位，随来源文档格式适配。日常由广告审核员、代理商优化师、品牌合规人员使用，用于逐条核对投放内容的合规性。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散且格式多样，要求检索环节支持多类型文档解析与跨源关联，避免遗漏跨平台合规依据与历史审核案例。实时或日级更新的数据需要配套同步机制，保障知识库内容与最新合规条款、投放素材保持一致，否则会出现审核依据滞后的问题。单条数据无统一固定单位，需保留原始字段信息用于精准匹配违规场景。逐条核对的使用场景要求召回结果需按违规风险优先级排序，避免无关内容干扰审核判断。出错后果直接关联广告投放风险，要求检索结果的溯源信息完整，且召回范围需覆盖全部合规依据与历史审核记录。

## 配置怎么定
本文配置基于 FastGPT v4.17.0 版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 广告素材审核需平衡合规判定准确性与检索效率，阈值过低会引入无关违规判定，过高则遗漏潜在合规风险点 |
| `limit` | 前 6–10 条 | 单次审核需覆盖核心合规依据与历史案例，过多会增加上下文处理负荷，过少则无法覆盖全部潜在风险 |
| `searchMode` | `vector+keyword` | 广告合规内容既有语义关联的合规条款，也有精准匹配的资质字段，混合模式可兼顾语义召回与关键词精准匹配 |
| `usingReRank` | 开启 | 需按违规风险优先级排序召回结果，帮助审核人员快速定位高风险内容，提升审核效率 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可通过扩展用户的审核查询语句，将“落地页合规”扩展为“落地页一致性、广告法落地页条款”等，提升召回精准度 |
| `collectionIds` | 绑定广告素材审核专属知识库的集合 ID | 隔离不同业务场景的知识库数据，避免无关内容干扰检索结果，保障审核依据的针对性 |

## 容易做错的三处
- 现象：调用知识库检索接口返回结果条数不足预期，原因：未正确指定`collectionIds`参数，导致检索范围覆盖了非广告素材审核专属的无关知识库内容。
- 现象：多轮审核对话后检索准确率下降，重开新对话后恢复正常，原因：未开启`datasetSearchUsingExtensionQuery`且未配置上下文过滤，冗余的历史审核上下文干扰了当前查询的语义匹配。
- 现象：更换嵌入模型后，原有导入的知识库无法匹配新的检索需求，原因：未触发原有知识库的重新索引流程，仍使用旧模型生成的向量进行检索。

## 怎么确认配好了
- 查看检索配置面板，确认`collectionIds`参数绑定了广告素材审核专属的知识库集合，无无关集合被纳入检索范围。
- 发起测试查询，验证检索结果是否按违规风险优先级排序，确认`usingReRank`功能已生效。
- 更换嵌入模型后，触发原有知识库的重新索引流程，验证新模型的向量是否被应用到现有数据。
- 发起多轮测试对话，确认检索准确率未随对话轮次增加出现明显下降，确认`datasetSearchUsingExtensionQuery`功能已生效。
