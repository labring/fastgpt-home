# 广告账户开户审核的技术文档与接口问答：文档解析与分块

## 这个品类的数据长什么样
该品类的核心数据来自广告平台后台、国家企业信用信息公示系统、客户提交的开户申请材料与行业准入规则。日常处理的文档包含开户申请表单、营业执照扫描件、行业资质证明、开户审核记录等。文档结构兼具结构化字段（如统一社会信用代码、申请日期）与非结构化文本（如审核意见、资质说明），更新频率为每日或随每一笔开户申请触发，数据格式因来源不同存在差异。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的文档类型多样且格式差异大，要求解析环节适配结构化表单与非结构化文件的混合输入。高频更新的特性要求解析流程具备足够效率，避免延迟影响开户审核进度。关键字段如统一社会信用代码、行业资质编号需完整保留，分块时不能拆分跨字段的关联信息，否则会导致后续资质核验环节出错，引发开户失败。多来源的数据格式不一致，需要针对性配置解析规则，确保不同格式的文件都能提取有效信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `chunkSize` | `800–1200 字符` | 该品类的文档包含短字段与段落文本，该区间可平衡字段完整性与检索效率，避免拆分关键资质信息 |
| `customPdfParse` | `启用` | 该品类的资质文件多为带公章的PDF，启用自定义解析可保留公章区域的文本与排版，避免关键信息丢失 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300 秒` | 该品类单次提交的批量文件量较大，该时长可覆盖多数文件的解析流程，避免因超时导致审核中断，该配置适配FastGPT v4.17.0版本的超时逻辑 |
| `chunkSplitter` | `按段落+语义分块` | 该品类的审核记录多为连贯的段落式文本，按语义分块可保留审核逻辑的完整性，提升后续问答的准确性 |
| `UPLOAD_FILE_MAX_SIZE` | `100 MB` | 该品类的批量资质文件单批次提交上限通常不超过该值，可避免上传失败影响开户流程 |
| `chunkSettingMode` | `手动配置` | 该品类的文档格式差异较大，手动配置可适配不同来源的文件解析需求，避免默认配置的适配性不足 |

## 容易做错的三处
- 上传CSV文件升级版本后报错，现象为返回`400 Bad Request`，原因是版本升级后`chunkSettingMode`的默认值变更，未适配原配置的分块规则。
- 尝试接入minerU文档解析失败，现象为解析后文本为空，原因是未开启`customPdfParse`并配置对应解析适配器，导致系统使用默认解析流程。
- 调用创建文件集合接口指定PDF解析参数无效，现象为接口返回结果仍使用默认解析，原因是未在请求参数中正确传递`customPdfParse`的启用值，导致配置未生效。

## 怎么确认配好了
- 上传单份带公章的资质PDF，查看解析后的文本是否保留公章区域的关键信息，确认`customPdfParse`配置生效。
- 提交批量CSV格式的开户申请表单，查看解析耗时是否在`PARSE_FILE_TIMEOUT_SECONDS`范围内，确认超时配置合理。
- 调用创建文件集合接口，检查返回的配置参数中是否包含指定的`chunkSize`与`chunkSplitter`值，确认API配置传递正确。
- 测试直传原始文件到大模型节点，查看节点输入内容是否为原始文件的二进制流，确认跳过了系统默认的解析流程。
