# 广告账户开户审核的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据包含开户申请表单、营业执照、行业资质证明、开户审核记录四类核心内容，数据来源覆盖广告平台后台、国家企业信用信息公示系统、客户提交的电子/纸质材料、行业准入规则文本。数据更新随单次开户申请触发，或每日同步后台规则与公示系统信息。文档结构差异明显，包含结构化字段（如主体名称、统一社会信用代码）、非结构化资质文本与规则条目，每个申请对应独立的关联数据集合。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源要求检索链路支持跨数据源的召回适配，确保能同时匹配结构化字段与非结构化文本。按申请或日更的更新节奏要求知识库支持增量同步配置，避免全量更新带来的性能损耗。文档结构的差异要求检索兼顾精确匹配与语义召回，确保资质字段与规则文本都能被精准命中。单次申请关联的专属数据集合要求检索限定范围，避免混入其他审核流程的冗余数据，影响核验效率。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定：
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `similarity` | `0.75–0.85` | 该品类需要精准匹配资质与规则文本，避免低相关的审核历史干扰结果 |
| `limit` | `前6–10条` | 单次开户审核的相关材料与规则条目有限，过多结果会超出上下文窗口 |
| `searchMode` | 混合检索 | 数据包含结构化字段与非结构化规则，混合模式可兼顾精确匹配与语义召回 |
| `usingReRank` | 开启 | 需要对召回结果排序优化，突出高优先级的行业准入规则与核心资质字段 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可将用户的审核查询自动扩展为关联的资质核验关键词，提升召回覆盖率 |
| `collectionIds` | 开户审核专属知识库集合ID | 限定检索范围在专属数据集，避免混入其他品类的审核数据 |

## 容易做错的三处
- 现象：调用知识库检索接口后返回空结果或非相关内容。原因：未通过`collectionIds`限定检索范围，导致检索覆盖了无关的知识库集合。
- 现象：添加专属知识库时持续返回报错提示。原因：未按照开户审核数据的格式上传结构化资质与规则文本，或批量同步时触发了接口调用频率限制。
- 现象：对话中无法返回知识库内的图片URL内容。原因：未在检索配置中开启多模态召回适配，或图片URL未正确绑定至对应知识库条目。

## 怎么确认配好了
- 上传单条测试用的营业执照文本与行业准入规则条目，调用检索接口，核对返回结果的相关性是否符合预期。
- 进入FastGPT知识库配置界面，确认`collectionIds`已绑定至广告账户开户审核专属数据集，无无关集合混入。
- 提交包含长文本的审核查询，检查是否自动触发查询扩展，且召回结果未超出合理条数范围。
- 上传绑定图片URL的资质材料条目，发起对话测试，确认可正常返回对应的URL内容。
