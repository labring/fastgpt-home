# 投放效果优化的技术文档与接口问答：文档解析与分块

本文基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
通常，投放效果优化相关的数据来源包括广告平台曝光点击数据、归因系统转化数据、CRM线索数据、落地页访问数据。日常处理的文档包含每日投放日报、周度复盘报告、实时调价记录、素材A/B测试数据表。数据更新频率多为日级或实时，文档结构多为结构化表格与非结构化段落混合，字段包含曝光量、点击量、转化成本、预算额度等，单位涉及元、次、百分比等。

## 这些特征在「文档解析与分块」这一环带来什么约束
广告类文档的结构化特征要求分块不能破坏表格列与行的关联，否则会导致后续问答无法匹配指标与对应数值。实时或日级更新的数据需要快速解析，过长的解析超时会影响投放调整效率。多来源的混合文档（表格+段落）需要适配不同的分块规则，通用分块可能拆分跨类型内容。批量上传的日报与测试表体积较大，需要放宽上传限制，同时避免因文件过大触发解析错误。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | `800–1200 字符` | 适配广告类文档的字段长度，避免拆分跨表格行的关联数据 |
| `chunkSplitter` | 按表格列+段落混合 | 适配日常文档中结构化表格与非结构化复盘内容混合的特征 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 满足批量上传日报、素材测试表的体积需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `600 秒` | 适配实时更新数据的批量解析耗时需求 |
| `customPdfParse` | 启用 | 适配素材测试表等PDF格式文档的结构化表格提取 |
| `chunkSettingMode` | 手动配置 | 允许针对不同文档类型调整分块规则，避免通用分块破坏数据关联 |

## 容易做错的三处
- 现象：上传CSV格式的调价记录或测试表后，仅显示第一列与第二列数据。原因：未开启结构化表格解析模式，默认分块逻辑仅提取纯文本内容，未识别表格列字段的关联关系。
- 现象：docker模式部署后上传文件触发413请求实体过大报错。原因：未调整`UPLOAD_FILE_MAX_SIZE`参数，系统默认限制小于上传文件的实际体积。
- 现象：自定义pdf-maker解析器无法正常提取PDF文档中的表格数据。原因：未在系统配置中正确设置解析器密钥，或未启用`customPdfParse`开关。

## 怎么确认配好了
- 上传单份体积不超过1000 MB的PDF格式素材测试表，检查解析结果是否包含所有列字段与对应数值。
- 提交批量结构化表格文件，等待解析完成，确认无超时报错提示。
- 查看分块后的文本片段，确认每个片段未拆分跨表格行的关联数据。
- 进入系统配置页，确认`customPdfParse`开关处于启用状态。
