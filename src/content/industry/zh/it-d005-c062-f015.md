# 投放效果优化的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据主要来自广告平台后台、归因分析系统、CRM线索库与落地页数据采集工具。日常处理的文档包含广告投放日报周报、单次调价操作记录、素材A/B测试结果表、投放效果优化复盘笔记，字段多包含曝光量、点击量、转化成本、预算额度等投放相关指标。数据更新节奏以日级为主，核心实时调整类数据如单次竞价记录、落地页实时转化数据为实时更新。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源要求知识库支持跨系统数据的统一索引与召回，避免出现数据孤岛。日级与实时混合的更新节奏，要求检索环节支持增量同步与实时数据的快速召回，保障结果时效性。文档类型涵盖结构化表格与非结构化笔记，需适配不同的分块与检索匹配逻辑，确保调价记录、复盘笔记等不同格式的内容都能被精准召回。投放相关指标的字段差异，要求检索时可指定特定字段作为召回依据，避免无关数据干扰。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 适配投放数据的字段密度与召回精准度需求，避免召回过多无关的历史调价记录或低相关复盘内容 |
| `limit` | 前10条 | 控制单次召回的结果数量，适配广告优化师快速浏览的使用习惯，避免结果过载 |
| `usingReRank` | 开启 | 针对多源异构的投放数据，通过重排提升高相关内容的排序优先级，解决初始召回结果混杂的问题 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户的投放问题自动扩展查询词，补充如“转化成本”“预算调配”等行业术语，提升召回覆盖度 |
| `collectionIds` | 按业务域指定 | 限定检索范围在广告投放效果优化专属的知识库集合中，避免召回其他品类的文档数据 |
| `searchMode` | 混合检索 | 适配结构化的调价记录与非结构化的复盘文档，兼顾精确匹配与语义匹配 |

## 容易做错的三处
- 开启`usingReRank`后检索返回结果为空。现象为执行检索后无有效内容片段展示，原因是重排的相关性阈值设置过高，过滤掉了初始召回的全部有效内容。
- 本地搭建的知识库无法创建超过指定数目的库。现象为界面弹出创建失败提示，原因是未调整默认的知识库存储配额（默认配额为1000 MB），不足以承载多源投放数据的索引。
- 检索结果包含非投放优化相关的文档内容。现象为召回结果中出现无关的运营文档或技术手册，原因是未通过`collectionIds`限定检索的知识库集合，导致召回了其他业务域的数据。

## 怎么确认配好了
- 上传一份历史调价记录文档，执行包含“调价”“转化成本”关键词的检索，核对召回结果是否包含该文档的相关片段。
- 开启`usingReRank`后，对比开启前后的检索结果排序，确认高相关内容的优先级得到提升。
- 查看知识库管理界面，确认已通过`collectionIds`指定了投放优化专属的知识库集合。
- 测试实时更新的落地页转化数据，确认检索结果可包含最新的实时数据片段。
