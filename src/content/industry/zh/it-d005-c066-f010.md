# 搜索广告关键词管理的技术文档与接口问答：引用来源与溯源

## 这个品类的数据长什么样
搜索广告关键词管理的核心数据包含关键词清单、否词表、出价记录、搜索词报告四类文档，数据来源为搜索广告后台、搜索词报告、竞价排名数据与落地页数据。数据更新频率分为日更与周更两类，其中出价记录、搜索词报告为日更，关键词清单与否词表通常为周更。文档字段包含关键词文本、匹配模式、单次出价、点击量、转化数等，单位涵盖元/次、次、个等，不同来源的数据字段存在明显差异，例如搜索词报告包含用户实际搜索词，而否词表仅包含需屏蔽的关键词文本。

## 这些特征在「引用来源与溯源」这一环带来什么约束
搜索广告关键词管理的数据来源分散且字段差异明显，引用溯源需精准匹配对应数据源的文档类型与字段，否则会出现溯源混淆的问题。不同更新频率的数据要求溯源标注明确的更新周期，避免使用者误用过期数据。同时，文档字段包含多维度业务信息，引用时需完整展示相关字段以支撑关键词优化决策，若仅展示摘要则无法完成精准校验。此外，该品类的问答场景聚焦于关键词相关的操作，引用内容需与问题强相关，不应混入无关文档的内容，否则会干扰优化师的判断。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| 最大引用token数（`quoteMaxToken`） | 800–1200 token | 搜索广告相关文档单条记录的文本长度集中在100-300字符，800-1200token可覆盖3-4条完整记录，避免截断关键业务字段 |
| 引用数据返回开关（`responseData`） | 开启 | 搜索广告关键词管理的溯源需绑定原始数据的具体字段，如关键词、出价、点击量，仅返回摘要无法完成精准校验 |
| 引用详情展示模式（`detail`） | 完整字段 | 关键词清单、否词表等文档包含多维度业务字段，完整展示可让使用者快速核对数据来源与内容匹配度 |
| 数据源分类绑定规则 | 按文档类型分类绑定 | 数据来源包含搜索广告后台、搜索词报告等不同类型，分类绑定可避免溯源混淆 |
| 单次召回引用上限 | 前5条 | 搜索词报告单页通常包含5-10条数据，前5条可覆盖核心关键词的优化需求 |

## 容易做错的三处
- 现象：回答底部自动附加所有引用文件的列表，与搜索广告关键词管理的问答场景不匹配。原因：未关闭非必要的引用汇总开关，默认开启了全量引用展示，导致无关文档内容被一并列出。
- 现象：引用内容被截断，无法展示完整的出价记录或否词表条目。原因：`quoteMaxToken`取值过小，超出单条或多条记录的token占用量，导致关键业务字段被截断。
- 现象：引用来源未标注对应文档的更新时间，导致使用者无法判断数据时效性。原因：未配置引用详情中的更新时间字段展示，或未同步数据源的更新时间信息。

## 怎么确认配好了
- 输入一条与关键词出价调整相关的问题，检查回答中引用的内容是否包含出价、匹配模式等专属字段，无无关文档的内容。
- 查看引用区域的来源标识，确认仅包含搜索广告后台、搜索词报告等指定类型的数据源，未混入其他无关知识库内容。
- 调整`quoteMaxToken`的取值，验证引用内容的截断情况是否符合预期，确保核心业务字段未被截断。
- 检查引用区域是否标注了对应文档的更新时间与类型，确保溯源信息完整可追溯。
