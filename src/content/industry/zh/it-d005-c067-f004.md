# 数据安全分类分级的技术文档与接口问答：向量模型与索引

## 这个品类的数据长什么样
该品类的数据主要来自数据资产盘点、数据库元数据、业务系统说明与法规文件，日常文档包含数据目录、分类分级规则、重要数据识别表、评审纪要。数据更新频率为季度或对应业务系统变更时触发，文档以结构化表格与段落混合为主要结构，字段包含数据资产标识、敏感等级、合规标签、所属业务域，无统一固定单位，随文档类型灵活调整。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类数据来源包含结构化元数据与非结构化法规文档，混合格式要求向量索引需支持跨结构文本分块。季度或业务变更的更新频率，决定索引无需高频增量同步，仅需在触发更新时执行全量或增量刷新。文档以表格与段落混合为主，分块操作需保留数据资产标识、敏感等级等核心字段的关联关系，避免拆分破坏业务逻辑。字段多为分类标签类内容，向量检索需精准匹配合规标签与敏感等级，对召回结果的相关性要求更高。同时针对数十万条规模的索引数据，需适配批量处理的资源消耗限制，避免索引任务超时。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的向量模型与索引功能设定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配数据目录、评审纪要等混合文档的段落长度，避免拆分破坏核心字段关联 |
| 重叠长度 | 50–100 字符 | 保留跨分块的分类分级规则上下文，确保敏感等级标签的检索连贯性 |
| `maxToken` | 4096 token | 匹配法规文件等长文本的处理上限，避免截断关键合规条款 |
| 相似度阈值 | 0.75–0.85 | 精准匹配分类标签与敏感等级，避免召回无关数据资产条目 |
| 单次搜索上限 | 前 10 条 | 适配数据治理团队的常规检索需求，平衡召回效率与结果相关性 |
| `defaultToken` | 按实测标定 | 适配本地部署的PGSQL向量库资源限制，避免内存占用过高 |

## 容易做错的三处
- 现象：知识库完成全量索引后搜索结果条数远低于预期，或返回与检索关键词不匹配的数据资产条目。原因：未根据该品类的分类标签字段调整相似度阈值，阈值设置过高或过低导致召回偏差。
- 现象：分块后数据目录的资产标识、所属业务域等核心字段被拆分至不同分块，无法关联检索。原因：分块长度设置过小，破坏了结构化表格中核心字段的完整关联。
- 现象：增量更新时索引未及时同步业务系统变更后的分类分级规则，或更新任务超时。原因：未按照季度或业务变更的更新节奏配置索引触发时机，且`maxToken`设置未适配长文本合规文件的处理需求，导致任务资源占用过高。

## 怎么确认配好了
- 选取5条典型分类分级规则文档与数据目录条目，执行检索测试，核对返回结果是否包含匹配的敏感等级与合规标签。
- 查看向量索引的分块日志，确认结构化表格的核心字段未被拆分至不同分块。
- 触发一次业务系统变更后的索引更新任务，核对任务完成状态与资源占用情况。
- 调整相似度阈值区间，验证召回结果的相关性是否匹配该品类的检索精度要求。
