# 数据库云服务运维的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据主要来自云数据库控制台、慢日志、监控指标与工单系统。日常产出的文档包含实例变更单、备份恢复记录、性能诊断报告、参数调整记录，单份文档通常包含实例ID、操作时间、变更内容、执行结果等字段，部分监控指标带有固定单位如毫秒、百分比。数据更新频率为每日或每次配置变更后同步，以结构化日志、半结构化工单文档为主要存储形式。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源要求检索环节适配不同格式的文档，需同时支持结构化日志的关键词匹配与半结构化工单的语义召回。按变更触发的更新频率要求召回逻辑优先获取最近更新的文档，避免使用过期的实例配置信息。文档中包含实例ID、租户标识等敏感字段，检索时需关联租户权限进行数据隔离，防止跨租户数据泄露。专业度较高的慢日志、性能报告类文档，需要更高的语义匹配阈值以过滤低相关性结果，同时需覆盖运维领域的专业术语变体。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配慢日志、性能报告这类高专业度文档，该区间可平衡召回覆盖率与精准度，过滤低相关性结果 |
| `limit` | 前8–12条 | 单实例关联的运维文档通常在10条以内，该取值可覆盖全量关联内容且不超出上下文窗口限制 |
| `searchMode` | hybrid | 适配结构化日志与半结构化工单的混合数据特征，结合关键词检索与语义检索提升召回效果 |
| `usingReRank` | 开启 | 针对参数调整记录、变更单这类字段密集的文档，重排可提升高相关内容的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展运维类问题的检索词，如将「慢SQL」扩展为「慢查询日志分析」，覆盖专业术语变体 |
| `collectionIds` | 按租户实例分组配置 | 隔离不同客户的云数据库数据，符合多租户运维的安全隔离要求 |

## 容易做错的三处
- 现象：调大`limit`参数后，大模型输出未引用任何召回内容。原因：超出上下文窗口总长度，导致召回的文档片段无法完整传入模型，或重排后高相关内容被低优先级条目挤占。
- 现象：知识库查询可返回结果，但模型无法输出内容。原因：未开启`usingReRank`或`searchMode`配置错误，导致召回的文档格式异常，无法被模型正确解析。
- 现象：本地部署后回答精准度不足。原因：未针对慢日志、性能报告这类专业文档调整`similarity`阈值，或未开启`datasetSearchUsingExtensionQuery`，无法覆盖运维领域的专业术语变体。

## 怎么确认配好了
- 登录FastGPT v4.17.0的知识库管理界面，查看对应数据集的`searchMode`配置是否为hybrid，确认与预设配置一致。
- 输入测试问题如「查询当前实例的慢日志分析结果」，检查召回结果中是否包含最近3天的慢日志文档，且`similarity`阈值匹配预期区间。
- 调整`limit`为前10条，验证返回的引用内容数量符合预期，无上下文溢出的提示。
- 开启`datasetSearchUsingExtensionQuery`后，输入「调整实例的连接数参数」，确认召回结果包含对应的参数调整记录文档。
