# 数据库运维的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的核心使用者为DBA、数据平台运维及后端团队，日常处理的文档包含数据库变更单、慢SQL报告、备份记录、权限申请单。数据来源主要为数据库监控系统、审计日志、SQL执行计划文件、内部工单系统。数据更新频率为每日或每次数据库变更触发。文档结构多包含实例标识、时间戳、操作类型等字段，其中慢SQL报告附带执行时长（毫秒）、扫描行数（行）等量化指标，变更单标注影响实例数量（台）。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源覆盖结构化监控日志、半结构化工单与执行计划，要求检索同时支持关键词匹配与语义关联，避免遗漏关键执行细节。更新频率随变更触发，要求召回环节支持增量同步，无需全量重建知识库。文档与具体数据库实例强绑定，检索需按实例ID过滤范围，防止跨实例的无关内容干扰。慢查询定位、变更审核为核心耗时场景，要求召回结果精准匹配业务关键词，减少无效信息的上下文占用。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的知识库检索逻辑：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.7–0.85` | 匹配数据库运维文档的精准度，过滤语义偏差较大的冗余结果 |
| `limit` | `前10–15条` | 适配慢SQL报告、变更单等单场景文档数量，避免过多结果增加上下文处理负担 |
| `searchMode` | `语义+关键词混合` | 同时匹配SQL关键词与业务语义，满足慢查询定位、变更审核的双重检索需求 |
| `usingReRank` | `开启` | 对初始召回结果二次排序，过滤重复或关联度较低的备份记录、权限申请单 |
| `datasetSearchUsingExtensionQuery` | `开启` | 扩展检索范围至关联工单、监控日志，比如关联变更单的权限申请记录 |
| `collectionIds` | `绑定当前运维实例的知识库ID` | 限定检索范围仅覆盖当前负责的数据库实例文档，避免跨实例干扰 |

## 容易做错的三处
- 检索结果为空，现象为调用知识库文件列表接口时返回空数组，原因是未正确配置`collectionIds`，导致未限定检索的知识库范围。
- 知识库原文链接无法访问，现象为点击检索结果的原文链接返回404错误，原因是未同步更新nginx代理规则，导致下载链接的路径与实际存储路径不一致。
- 检索结果冗余过多，现象为慢查询定位时返回大量不相关的备份记录，原因是`similarity`阈值设置低于0.7，匹配了语义相近但业务无关的文档。

## 怎么确认配好了
- 输入慢SQL的核心关键词，执行检索，检查返回结果是否包含慢SQL报告、SQL执行计划等相关文档。
- 调用知识库文件列表接口时传入指定的`collectionIds`，确认返回结果仅包含绑定实例的知识库文件，未出现其他实例的内容。
- 开启`usingReRank`后，对比初始召回结果与重排后的结果条数，确认冗余内容被有效过滤。
- 提交一次小型数据库变更，等待知识库增量更新完成后，检索新生成的变更单关键词，确认新文档可被正常召回。
