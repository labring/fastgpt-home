# 数据脱敏处理的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据主要来自企业数据库、数据字典、脱敏工具输出结果以及访问审批系统，按每批项目或单次任务更新。日常产出的文档包含脱敏方案、字段映射表、脱敏验证报告与审批记录，文档结构多以结构化字段为主，包含敏感字段标识、脱敏规则编码、验证结果、审批状态等字段，无统一固定单位，具体字段单位随项目需求调整。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据按项目批次更新，导致知识库检索需严格限定数据集范围，避免跨项目的敏感数据被召回。结构化字段占比高的文档，需支持按字段精准匹配，仅全文检索无法适配结构化字段的语义查询需求。脱敏相关文档涉及合规内容，检索结果需兼顾精准性与安全性，同时需快速定位特定项目的脱敏配置记录，提升检索针对性。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本适配。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.72–0.85` | 适配脱敏文档的结构化字段匹配，平衡精准度与召回覆盖率 |
| `limit` | `前 8–12 条` | 单批次项目的脱敏文档数量通常有限，避免返回过多冗余结果 |
| `searchMode` | `vector` | 针对结构化规则类内容，向量检索比全文检索更适配语义匹配需求 |
| `usingReRank` | `开启` | 脱敏文档的合规性与准确性要求高，重排可提升结果相关性排序精度 |
| `datasetSearchUsingExtensionQuery` | `关闭` | 脱敏配置类文档无需扩展查询，避免引入无关项目的脱敏规则 |
| `collectionIds` | 按项目绑定的数据集ID填写 | 限定检索范围仅为当前项目的脱敏相关数据集，避免跨项目数据干扰 |

## 容易做错的三处
- 现象：检索结果包含非当前项目的脱敏文档与审批记录。原因：未正确绑定`collectionIds`参数，未限定检索的数据集范围，导致召回跨项目的敏感数据，违反合规要求。
- 现象：检索返回的脱敏规则匹配度偏差过大，要么遗漏关键配置要么混入无关内容。原因：`similarity`取值未适配结构化脱敏文档的语义特征，取值区间不符合项目实际需求。
- 现象：检索时无法正确匹配脱敏方案中的变量配置参数。原因：未正确配置检索模式或匹配规则，导致无法精准定位变量赋值相关的文档内容，对应技术文档与接口问答场景中的变量引用配置需求。

## 怎么确认配好了
- 查看FastGPT检索配置面板，确认`collectionIds`已绑定当前项目的脱敏数据集ID，无额外无关数据集被选中。
- 执行测试检索，输入脱敏方案的关键词，检查返回结果是否仅包含当前项目的相关文档，无跨项目数据混入。
- 调整`similarity`取值区间，对比不同取值下的检索结果相关性，选择符合项目合规验证需求的配置。
- 开启`usingReRank`后，验证检索结果的排序是否符合相关性优先级，确保关键脱敏规则排在前列。
