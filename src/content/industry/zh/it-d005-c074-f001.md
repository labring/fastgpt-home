# 文本标注项目的技术文档与接口问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
文本标注项目的数据主要来自客户提供的语料、自有标注平台产出的标注样本、行业通用词表以及质检抽样结果。日常产出的文档包括标注规范、样本包、质检报告和问题反馈表。数据更新以日度或单批次标注任务为节奏，单批次样本量随客户需求浮动。数据字段包含原始文本内容、实体标注位置、意图标签、置信度分值，部分质检报告还会包含仲裁记录与一致性抽检结果。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
文本标注项目的数据特征对HTTP接口与外部系统环节带来多维度约束。首先，数据包含客户敏感语料，接口传输需优先使用加密协议，避免明文泄露风险。其次，数据更新节奏波动较大，接口需支持按需触发批量拉取或增量同步，适配日度或单批次的更新需求。再者，标注规范与质检报告的字段结构随客户需求灵活调整，接口需支持自定义字段映射，避免硬编码适配。另外，文本标注关注语义边界与实体细节，接口返回的标注结果需保留精确的字符位置信息，无法简化为通用分类标签。最后，单批次样本量可能较大，接口需支持分页拉取，避免单次请求过载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| 接口协议 | 优先使用HTTPS | 适配标注语料的敏感传输需求，避免明文泄露 |
| `Authorization` | 携带Bearer令牌格式的访问密钥 | 符合接口鉴权标准，保障外部调用安全 |
| `variables` | 配置标注任务ID、样本批次号等自定义参数 | 适配单批次标注数据的拉取与匹配需求 |
| `responseData` | 保留实体位置、置信度、仲裁记录等核心字段 | 匹配文本标注项目的数据字段要求 |
| 超时阈值 | 设置为30-60秒 | 适配单批次样本的处理时长，避免短超时导致任务中断 |
| 分页拉取上限 | 单次拉取100-200条样本 | 平衡接口负载与传输效率，避免单次请求过载 |

## 容易做错的三处
- 现象：自定义插件调用外部标注接口时触发报错，或无法正常拉取客户语料。原因：未将接口协议从HTTP升级为HTTPS，导致敏感语料传输被拦截，或鉴权参数配置错误。
- 现象：HTTP编排节点的output字段为空，未在对话结果中展示。原因：未在`responseData`中配置需要返回的标注结果字段，或未开启节点的输出权限（FastGPT v4.17.0）。
- 现象：定时拉取标注数据时出现请求超时，或仅拉取到部分样本。原因：超时阈值设置低于实际处理时长，或单次拉取的样本数量超出接口承载上限。

## 怎么确认配好了
- 发起测试接口请求，检查返回的`responseData`是否包含实体位置、置信度等文本标注项目所需的核心字段。
- 查看接口鉴权日志，确认`Authorization`参数被正确携带并通过鉴权验证。
- 测试定时拉取或批量拉取功能，确认接口返回的样本数量与配置的分页上限匹配。
- 发起HTTPS请求，确认接口可以正常响应，无传输安全相关的告警信息。
