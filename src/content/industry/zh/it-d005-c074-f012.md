# 文本标注项目的技术文档与接口问答：文档解析与分块

## 这个品类的数据长什么样
文本标注项目的日常文档包含标注规范、样本包、质检报告与问题反馈表。数据来源包括客户提供的语料、标注平台导出的标注结果、自定义词表以及质检抽样的结果。数据更新频率为每日或按标注批次更新，单份文档多为层级化结构，包含实体标注位置、标签类别、质检得分、问题反馈描述等字段，无统一强制格式，部分文档会附带手写批注或格式变体。

## 这些特征在「文档解析与分块」这一环带来什么约束
标注文档的层级化结构要求解析与分块需保留标题与对应内容的关联，避免拆分破坏语义边界；批量更新的样本包需支持多文档并行解析，适配不同格式的样本文件；质检报告与问题反馈表的固定表头与关联内容需作为整体分块，避免拆分导致的逻辑断裂；由于出错后会引发模型训练偏差、返工或交付延期，解析环节需确保关键标注规则与样本信息无丢失，同时适配不同来源文档的格式差异。

## 配置怎么定
以下配置适用于FastGPT v4.17.0及以上版本：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 800–1200 字符 | 文本标注项目的文档多为带语义关联的标注规则与样本，该长度可保留单条标注逻辑的完整性 |
| `chunkSplitter` | 按段落+标题拆分 | 标注文档多有层级标题与段落化的规则说明，避免拆分破坏语义边界 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 批量样本包文件体积较大，需预留足够解析时间 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 标注项目的样本包可能包含多份文档合集，需适配批量上传需求 |
| `customPdfParse` | 关闭OCR模式 | 文本标注项目的文档多为可编辑文本，无需额外OCR处理，避免冗余解析 |
| `chunkSettingMode` | 手动配置 | 标注项目的文档格式差异较大，需自定义分块规则适配不同文档类型 |

## 容易做错的三处
- 排查项：启用PDF增强功能后，解析结果包含冗余OCR文本且无原图，需检查自定义PDF解析的OCR开关配置。
- 排查项：解析Excel文档时无法获取sheet名称，需检查是否配置了适配表格多页签的解析规则。
- 排查项：导入PPT或DOC文档时解析无效果，需检查是否正确启用了对应文档格式的解析插件。

## 怎么确认配好了
- 检查App/Admin服务端的环境变量配置，确认已正确设置`AIPROXY_API_ENDPOINT`（AI Proxy服务的根地址，例如 http://aiproxy:3000，不得附加 /v1 或 /chat/completions，不得配置为VLLM/Ollama/Xinference等单模型地址）与`AIPROXY_API_TOKEN`（AI Proxy管理员Token，与AI Proxy服务端配置一致且不能为空，不得使用应用API Key、模型供应商密钥、按应用签发的token或按请求估算的token数替代），无空值或错误地址。
- 上传单份标注规范文档，查看解析结果的分块是否保留了标题与对应段落的关联，无强制拆分语义单元。
- 上传Excel样本包，验证解析结果是否包含所有sheet的名称与对应表格内容。
- 上传非PDF格式文档，确认解析结果可正常生成分块文本，无格式丢失。
