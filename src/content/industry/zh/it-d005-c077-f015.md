# 机房巡检与环境监控的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
本品类数据主要来自动环监控、门禁系统、UPS监控与视频巡检设备。日常产出的文档包含巡检表、温湿度记录、告警记录、值班日志，字段多包含设备ID、巡检点位、温湿度数值、告警等级、时间戳，温湿度以℃、%RH为单位。数据更新节奏为实时或每日，由运维人员或监控系统直接录入或同步。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源要求检索系统支持跨设备、跨文档类型的混合召回，需适配结构化字段（如设备ID、时间戳）与非结构化文本的混合匹配。实时更新的温湿度、告警数据要求召回结果需优先覆盖最新数据，避免使用过期向量。巡检表、值班日志的半结构化特征，需要检索同时支持语义匹配与精确字段匹配，确保运维能快速定位特定点位的巡检结果。告警记录的高时效性要求，需支持按时间范围过滤召回结果，避免冗余的历史数据干扰判断。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配告警、温湿度这类强相关内容，避免召回无关的巡检记录 |
| `limit` | 前10条 | 适配运维人员单次查看的信息量，避免过多结果干扰核心告警的定位 |
| `searchMode` | hybrid | 兼顾结构化字段匹配与语义召回，适配巡检表、告警记录的混合数据结构 |
| `usingReRank` | 开启 | 对召回结果按相关性重新排序，优先展示高优先级的告警与最新巡检结果 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展查询词，补充设备型号、巡检点位等运维常用术语，提升召回精准度 |
| `collectionIds` | 按机房分组配置 | 限定检索范围为目标机房的数据集，避免跨机房数据干扰运维判断 |

## 容易做错的三处
- 现象：导入温湿度记录的Markdown文件时提示格式错误。原因：未将巡检表的结构化字段（如设备ID、温湿度数值）按规范的Markdown表格格式排版，导致系统解析失败。
- 现象：调试预览时召回结果正常，但嵌入自有页面后无法搜索。原因：未正确配置`collectionIds`参数，未限定检索范围为目标机房的数据集，导致跨机房数据范围冲突。
- 现象：知识库内的告警记录配图无法正常展示，云环境下报错率较高。原因：未将图片资源上传至关联的云存储桶，或未开启图片元数据的索引配置，导致向量检索无法关联图片内容。

## 怎么确认配好了
- 手动输入一条已知的告警记录关键词，核对召回结果是否包含该记录，且排序符合预期。
- 查看检索日志，确认`searchMode`为hybrid模式，且`similarity`值落在预设的0.75–0.85区间内。
- 测试按时间范围过滤查询，确认仅召回指定时间段内的告警与巡检数据。
- 检查数据集的更新日志，确认实时同步的动环监控数据已被正确索引。
