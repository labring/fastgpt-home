# 游戏运营活动配置的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的日常文档包含活动方案、奖励配置表、上线检查单、活动复盘材料，数据来源为运营后台、玩家分群数据、付费统计数据与活动运行日志。数据更新频率通常为周度或节假日活动前临时调整，文档结构包含活动ID、时间范围、奖励数值与单位、触发条件等字段，奖励配置表需明确道具类型、发放数量等具体参数，活动日志则记录每一次配置的执行与异常情况。

## 这些特征在「知识库检索与召回」这一环带来什么约束
活动配置类数据的结构化程度高，包含数值型奖励参数与时间类约束字段，要求检索时精准匹配字段与单位，避免模糊匹配引发的错误配置召回。数据更新频率随活动节奏波动，需支持增量同步与临时更新，确保活动前的配置文档始终处于最新状态。奖励发放错误会引发玩家投诉与收入波动，要求召回结果的置信度需匹配业务风险等级。多源数据的格式差异，要求检索环节兼容运营后台导出的表格格式与日志类结构化文本。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，具体参数设置如下：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配活动配置的结构化字段，平衡精准度与召回覆盖范围，避免低相关结果混入 |
| `limit` | 前10条 | 控制单次召回的文档数量，适配运营场景的短上下文交互需求 |
| `searchMode` | 精准匹配 | 针对结构化的配置表与检查单，优先匹配字段关键词，提升匹配准确性 |
| `usingReRank` | 开启 | 对召回结果重新排序，提升高价值奖励配置文档的优先级，降低错误配置的曝光 |
| `datasetSearchUsingExtensionQuery` | 关闭 | 活动配置的问题通常明确，无需额外扩展查询词避免干扰核心匹配逻辑 |
| `collectionIds` | 活动配置专属集合ID | 限定检索范围，排除无关的游戏研发、美术资源等文档，提升检索效率 |

## 容易做错的三处
- 现象：检索返回结果条数远低于预期，或无匹配的活动配置文档。原因：未正确设置`collectionIds`限定检索范围，导致检索覆盖了非活动配置类的文档。
- 现象：对话中无法输出知识库中存储的图片链接内容。原因：未开启知识库图片解析功能，或图片URL未被正确生成向量嵌入，导致无法关联展示。
- 现象：输入过长的活动规则描述时，检索召回耗时显著增加。原因：未对查询文本做合理截断，或未配置`limit`参数限制召回数量，导致冗余计算量上升。

## 怎么确认配好了
- 执行测试查询，输入常见的活动配置问题，核对返回结果是否包含活动方案、奖励配置表等目标文档，验证检索范围是否正确。
- 检查检索结果的排序，确认高优先级的奖励配置文档出现在靠前位置，验证`usingReRank`的配置效果是否符合预期。
- 导入一份测试用的活动配置PPT，确认图片与文字均被正确纳入知识库，验证解析配置是否生效。
- 调整`similarity`参数区间，测试不同阈值下的召回结果，确认匹配精度符合业务风险要求。
