# 监控告警配置的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据来自Prometheus、Zabbix、云监控、应用日志、CMDB等运维数据源，日常生成监控指标清单、告警规则、值班手册、告警变更记录四类文档。监控指标清单包含指标名、采集周期（单位秒）、阈值范围；告警规则包含触发条件、通知对象、生效时段；告警变更记录包含变更时间、变更内容、经办人等字段。数据更新频率为每日或每完成一次告警配置变更后。

## 这些特征在「知识库检索与召回」这一环带来什么约束
告警配置类数据的多来源特性，要求检索时需匹配不同数据源的字段格式，避免跨源文档的误召回；更新频率的不确定性，要求知识库需配置按需或定时同步机制，确保召回数据与最新配置一致；文档类型的多样性，需按文档类别设置检索权重，优先召回告警规则与指标清单；字段的明确单位与阈值要求，需在检索时自动匹配单位信息，防止因单位不符导致的无效召回。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.7–0.85` | 告警配置的字段精度要求较高，需过滤低匹配度的无关运维文档 |
| `limit` | `前8–12条` | 告警配置的关联文档数量适中，过多会超出上下文窗口上限 |
| `searchMode` | `vector` | 告警配置的文本结构规整，语义检索的匹配精度优于关键词检索 |
| `usingReRank` | `开启` | 需进一步过滤检索结果中的噪声告警规则，降低误报干扰 |
| `datasetSearchUsingExtensionQuery` | `开启` | 告警配置包含较多专业运维术语，扩展查询可提升召回覆盖度 |
| `collectionIds` | `绑定告警配置专属知识库集合` | 隔离业务数据，避免无关文档干扰告警配置的精准检索 |

## 容易做错的三处
- 现象：调用知识库检索接口后，返回结果未包含关联文件的标识或路径。原因：未开启`datasetSearchUsingExtensionQuery`参数，或未配置知识库集合的文件元数据同步。
- 现象：语义检索得分超出常规0~1区间，出现数千分的数值。原因：未正确适配嵌入模型的归一化逻辑，或错误使用了非标准化的相似度计算方式。
- 现象：配置searchXNG检索引擎后，部分场景下无法检索到告警配置相关文档。原因：未配置searchXNG的数据源过滤规则，或未同步最新的告警配置文档到检索引擎。

## 怎么确认配好了
- 调用FastGPT v4.17.0的知识库检索API，传入告警配置相关的查询文本，检查返回结果是否包含预期的告警规则、指标清单等文档。
- 查看检索结果的`similarity`字段，确认得分处于合理区间，无异常高值或低值。
- 验证`usingReRank`参数生效后，检索结果中的噪声文档占比明显降低。
- 检查`collectionIds`参数配置，确认仅绑定了告警配置专属的知识库集合，无无关业务集合混入。
