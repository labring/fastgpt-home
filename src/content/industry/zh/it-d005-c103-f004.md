# 美术资产生产管理的技术文档与接口问答：向量模型与索引

## 这个品类的数据长什么样
美术资产生产管理的日常文档包含美术需求单、资产规格、外包反馈表、验收记录四类，其中美术需求单包含需求编号、资产类型、交付时间等字段，资产规格包含面数、纹理分辨率、格式等参数。数据来源涵盖美术资产库、项目管理系统、引擎资源文件、外包交付包，包含结构化字段数据与非结构化的文件内容。数据更新频率分为日更与周更，每日上传新的外包交付包与验收记录，每周同步更新项目需求与资产规格参数。

## 这些特征在「向量模型与索引」这一环带来什么约束
美术资产生产管理的数据来源多样，包含结构化的项目字段、长文本类的需求与反馈文档，以及大体积的3D资产交付包，不同数据的格式与长度差异显著。数据更新频率分为日度小批量与周度全量两种，要求索引支持增量同步与全量重建两种模式。数据关联到具体的资产ID与项目节点，索引需要保留字段级的关联信息，避免召回不匹配的资产规格或外包记录。同时，高频的规格确认与外包返修沟通需求，要求向量检索具备快速定位精准内容的能力，避免冗余检索带来的性能消耗。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配美术需求单、资产规格文档的平均内容长度，避免分割后丢失参数关联 |
| 重叠长度 | 50–100 字符 | 保留跨块的上下文信息，确保连续的资产规格参数不被割裂 |
| 相似度阈值 | 0.75–0.85 | 区分匹配的资产规格与相似但不匹配的参数，降低误召回概率 |
| 单次搜索上限 | 前8条 | 适配外包返修沟通的检索场景，返回精准的历史反馈与验收记录 |
| `defaultToken` | 4096 token | 适配3D资产交付包的文本描述与引擎资源的参数说明长度 |
| 最大上下文 | 3500 字符 | 整合多条相关的验收记录与需求单内容，满足完整的规格确认需求 |

## 容易做错的三处
- 现象：知识库磁盘占用超出预期，包含原文件、分割块、嵌入向量之外的额外占用。原因：未对3D资产交付包的二进制文件进行预处理，导致嵌入向量生成时额外缓存了未压缩的资源数据。
- 现象：检索结果返回不相关的资产规格文档，比如角色资产的规格匹配到场景资产。原因：未在索引中保留资产类型字段的关联信息，导致向量召回未过滤类型差异。
- 现象：配置索引模型后检索响应超时，单次返回结果条数远超需求。原因：未设置合理的单次搜索上限，导致系统加载过多的历史外包反馈记录与验收文档。

## 怎么确认配好了
- 查看知识库的磁盘占用统计，核对原文件、分割块、嵌入向量的占比，确认未出现额外的未预期占用。
- 输入一条针对性的美术规格查询，检查检索结果的资产类型与查询需求一致，确认索引的字段过滤生效。
- 模拟高频检索场景，查看系统响应时间，确认未出现超时情况。
- 检查FastGPT v4.17.0的索引模型配置页面，确认已完成对应渠道与参数的绑定。
