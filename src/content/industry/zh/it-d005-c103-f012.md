# 美术资产生产管理的技术文档与接口问答：文档解析与分块

## 这个品类的数据长什么样
该品类的日常文档通常包含美术需求单、资产规格表、外包反馈记录、验收文档等类型，数据来源为美术资产库、项目管理系统、引擎资源目录及外包交付包，更新频率多为日度或周度。文档多包含结构化字段如资源ID、面数、分辨率、版本号，字段单位多为像素、三角面数、文件格式等，部分文档还会包含图文结合的参考说明内容，部分外包交付包会打包多份关联文件。

## 这些特征在「文档解析与分块」这一环带来什么约束
结构化表格占比高的文档要求分块需保留字段关联完整性，避免拆分跨规格项或需求条目；图文结合的文档需保留原图元与文本的对应关系，防止仅提取OCR文本丢失视觉参考信息；批量交付的多文件场景要求解析配置适配较大的单文件及批量上传上限；高频更新的文档需要分块逻辑匹配快速检索的需求，避免过细或过粗的分块导致关联信息断裂；此外，外包交付包的多文件打包场景要求解析配置支持批量文件处理，避免因单文件限制导致交付包解析失败。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，具体如下：
| 配置项|建议取法|这样取的依据 |
| ---|---|--- |
| `chunkSize`|800–1200 字符|适配美术规格表的字段密度，避免拆分跨规格项 |
| `chunkSplitter`|按标题+段落拆分|匹配美术需求单的层级结构，保留需求与参考图的关联 |
| `customPdfParse`|开启|保留外包交付包PDF中的内嵌表格与矢量图元，避免强制OCR导致的信息丢失 |
| `UPLOAD_FILE_MAX_SIZE`|1000 MB|适配外包交付包的批量文件上限 |
| `PARSE_FILE_TIMEOUT_SECONDS`|600 秒|应对大型资产规格文档的解析耗时 |
| `chunkSettingMode`|手动配置|针对美术资产文档的特殊结构调整分块规则 |

## 容易做错的三处
- 现象：导入PPT或DOC文档勾选PDF增强后无解析效果，任务状态显示解析完成但无有效文本内容，原因：PDF增强功能仅适配PDF格式文档，未针对Office类文件启用对应解析规则，导致文档未被正确识别。
- 现象：Excel解析结果未包含Sheet名称，仅展示默认Sheet的内容，原因：默认分块配置未提取表格页签信息，未开启多Sheet识别逻辑，导致页签名称未被纳入解析范围。
- 现象：图文结合的操作手册解析后丢失原图仅保留OCR文本，原因：未开启`customPdfParse`配置，强制触发通用OCR模式，无法保留原图元。

## 怎么确认配好了
- 上传单份包含标题层级的美术需求单PDF，检查解析结果是否保留标题与对应段落的关联，未出现跨标题拆分的情况。
- 上传包含多个Sheet的Excel资产规格表，确认解析结果包含各Sheet的名称与对应数据，未遗漏页签内容。
- 上传内嵌矢量图的外包交付包PDF，检查结果中是否保留原图元，未出现仅生成OCR文本的情况。
- 上传100MB以内的外包交付包，确认解析任务在600秒内完成，未出现超时报错提示。
