# 落地页转化优化的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
本品类的核心数据来自落地页访问日志、热力图、表单提交数据及广告来源参数。日常产出的文档包括落地页方案、埋点需求文档、AB测试报告与表单字段清单。数据更新频率为周度或单次活动周期内。文档结构多包含结构化字段（如表单字段名、广告渠道参数）与非结构化分析内容（如页面路径分析结论），字段无统一固定单位，需结合具体活动场景匹配。

## 这些特征在「知识库检索与召回」这一环带来什么约束
落地页转化优化的数据来源多为活动级的实时或准实时数据，要求检索召回需支持按活动时间范围过滤，避免跨活动的无关数据干扰。文档包含大量结构化字段与非结构化分析内容，需同时支持语义匹配与关键词精准匹配，确保召回埋点字段、表单规则等细节内容。周度或活动级的更新频率意味着知识库需支持增量更新，且检索结果需贴合当前活动的专属配置，不能泛化到历史活动。此外，排查类场景对结果时效性要求较高，需避免过长的检索等待时间。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 匹配落地页相关文档的语义相似度区间，避免召回无关的历史活动文档 |
| `limit` | `前10–15条` | 落地页转化优化的排查文档总量有限，过多结果会超出上下文长度，影响后续处理 |
| `searchMode` | 向量搜索+关键词混合 | 兼顾语义匹配与关键词精准匹配，可同时召回埋点字段、广告参数等结构化内容 |
| `usingReRank` | 开启 | 落地页文档包含大量细节字段，重排可提升高相关结果的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可补充当前活动的广告来源参数、活动时间等上下文，提升检索精准度 |
| `collectionIds` | 绑定当前活动的专属数据集ID | 避免召回其他活动的无关文档，确保检索结果贴合当前业务场景 |

## 容易做错的三处
- 现象：上传落地页相关的.txt或.csv文件时，出现`fail to create post presigned url`报错。原因：未正确配置知识库关联的存储桶权限，或未绑定当前活动的数据集ID。
- 现象：检索时召回了非当前活动的落地页文档。原因：未指定`collectionIds`参数，或绑定了错误的数据集ID，导致检索范围覆盖了无关知识库。
- 现象：导入.csv格式的广告来源参数文件时，提示`datasetId is required for S3 files`。原因：未在配置中指定关联的数据集ID，导致S3存储的文件无法匹配到对应知识库。

## 怎么确认配好了
- 上传测试用的落地页方案文档，检查上传过程中无预设url相关报错，确认文件成功导入知识库。
- 输入具体的排查类问题，如「表单字段缺失排查」，检查召回结果是否包含当前活动的表单字段清单文档。
- 进入FastGPT v4.17.0的知识库配置面板，确认`usingReRank`、`datasetSearchUsingExtensionQuery`等参数已按设定开启。
- 导入测试用的.csv格式广告来源参数数据，检查是否能正常导入，无datasetId相关报错。
