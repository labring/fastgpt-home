# 集成测试与接口测试的技术文档与接口问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
这个品类的核心数据由测试工程师、测试开发团队及接口平台维护人员产出，日常文档包含接口测试用例、联调问题单、环境说明、测试报告。数据来源涵盖接口管理平台、测试环境日志、数据库、消息队列，更新频率为每日或每版本迭代时更新。数据字段包含接口地址、请求方法、参数名、参数类型、预期响应码、实际响应内容等，单位涉及字符、毫秒、调用次数等，无固定统一的格式模板，需适配不同测试场景的需求。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据来源分散且更新频繁，要求HTTP接口问答系统能同时接入多源数据以覆盖接口文档、测试日志、链路信息等内容。日常文档的字段无统一模板，要求问答系统支持灵活提取自定义字段作为检索与回答依据。最耗时的依赖服务准备与参数核对环节，要求系统能快速定位接口参数、响应结果及链路异常，因此需配置合理的上下文刷新与检索规则，避免因数据滞后或冗余影响测试效率。同时，数据更新频率较高，要求配置项支持定期同步最新的接口文档与测试环境信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `Authorization` | 格式为`Bearer {app_api_key}`的鉴权串 | 符合FastGPT应用API的鉴权规则，用于合法调用接口服务 |
| `variables` | 填入测试环境域名、`300 秒`超时阈值等自定义参数 | 适配不同测试环境的接口调用与响应等待需求 |
| `responseData` | 提取返回结果中的`code`、`message`字段作为校验目标 | 聚焦接口测试的核心验证逻辑 |
| AIPROXY_API_ENDPOINT | 填写`http://aiproxy:3000`格式的根地址，不附加子路径 | 为AI Proxy服务的根地址，不附加/v1或/chat/completions等子路径、非VLLM/Ollama/Xinference等单模型地址，符合FastGPT v4.17.0+的服务环境变量配置要求 |
| AIPROXY_API_TOKEN | 填写与AI Proxy服务端配置一致的非空字符串 | 为AI Proxy管理员Token，与服务端配置一致且非空，满足服务启动的必填校验项要求 |

## 容易做错的三处
- 现象：接口调用返回401未授权错误，控制台日志显示鉴权字段格式异常。排查项：检查是否误将AI Proxy管理员Token填入`Authorization`请求头，未使用应用API Key。
- 现象：问答系统重复返回相同的联调问题解决方案，无法区分不同版本的测试用例。原因：未在`variables`中配置版本标识参数，导致上下文未区分不同迭代周期的接口文档。
- 现象：FastGPT服务启动失败，控制台提示环境变量缺失。排查项：检查是否未在App/Admin服务端配置必填的`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`，或误将其填入工作流全局变量、应用API请求头，未配置为服务端环境变量。

## 怎么确认配好了
- 检查FastGPT App/Admin服务端的环境变量配置，确认`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`已正确配置且非空。
- 发起一条测试接口调用请求，验证`Authorization`请求头格式为`Bearer {app_api_key}`，能正常获取接口响应数据。
- 触发一次接口测试问答，确认`responseData`能正确提取到预期的`code`和`message`字段。
- 重启FastGPT服务，确认无环境变量缺失的启动校验报错。
