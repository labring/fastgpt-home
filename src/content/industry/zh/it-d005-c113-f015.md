# 集成测试与接口测试的技术文档与接口问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据主要来自接口管理平台、测试环境日志、数据库与消息队列，日常文档包含接口测试用例、联调问题单、环境说明与测试报告。数据更新节奏为每日或每版本发布周期，文档结构多包含接口路径、请求参数、响应格式、测试步骤与结果字段，部分日志类数据包含时间戳、调用链路与错误码信息，无统一强制格式但需覆盖测试链路核心信息。

## 这些特征在「知识库检索与召回」这一环带来什么约束
接口测试相关数据更新频率为每日或每版本，知识库检索需支持增量召回机制，避免全量扫描占用资源。文档包含接口路径、调用链路、错误码等结构化字段，检索时需优先匹配跨模块交互相关的关键词，保障链路问题定位效率。多源数据混合存储，需针对接口管理平台文档、测试日志等不同来源设置差异化召回权重。测试用例与联调问题单存在强关联，需支持同组关联数据的绑定召回，避免单条信息割裂影响问题排查。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配接口测试场景下的精准参数与链路关键词，避免召回无关的通用测试文档 |
| `limit` | 前10条 | 覆盖单轮测试排查所需的关联用例、日志与问题单，避免结果过多干扰定位 |
| `searchMode` | hybrid | 结合关键词匹配与语义召回，适配接口路径、参数名等结构化字段与自然语言问题的混合检索需求 |
| `usingReRank` | 开启 | 对初始召回结果进行重排序，优先返回与接口调用链路、错误排查直接相关的文档 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户问题扩展检索词，覆盖同义词、接口别名等场景，提升跨模块交互内容的召回率 |
| `collectionIds` | 按业务场景指定 | 限定检索范围为接口测试用例、联调问题单等专属集合，避免混入其他品类的文档 |

## 容易做错的三处
- 现象：上传包含章节标题、链接、简介的分组文档后，检索时单组数据被拆分为独立条目，无法匹配到完整的一组信息。原因：未正确配置关联召回的绑定参数，未将同组数据关联至同一集合或未启用分组召回逻辑。
- 现象：调用知识库接口创建纯文本集合或训练订单时，返回参数错误或功能未生效。原因：未指定合法的`trainingType`选项，或错误使用了未支持的参数配置。
- 现象：高并发场景下，接口测试相关的知识库检索请求出现超时或结果条数不足。原因：未根据并发规模调整检索参数，或`similarity`阈值设置不合理导致检索耗时过长。

## 怎么确认配好了
- 上传一组包含章节标题、链接、简介的测试数据，检索时确认可返回完整的单组信息，验证关联召回配置生效。
- 调用知识库接口创建纯文本集合，传入不同的`trainingType`选项，确认接口返回正常且功能符合预期。
- 模拟高并发请求，观察检索响应时间与结果完整性，调整`similarity`与`limit`配置至符合业务需求的阈值。
- 查看检索日志，确认仅召回指定`collectionIds`范围内的文档，避免混入无关数据。
