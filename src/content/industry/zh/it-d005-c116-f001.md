# 项目文档移交归档的技术文档与接口问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
本品类的数据来自项目文档库、配置清单、会议纪要、测试报告，更新节奏为项目各阶段结束或整体项目交付时。日常产出的文档包括竣工文档、配置手册、培训记录、验收证书，核心字段包含项目唯一标识、文档版本号、移交归档日期、接收方单位信息、电子签章状态，字段格式多为标准项目编号、日期文本、字符型内容。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
本品类的数据更新节奏随项目阶段波动，单次接口请求需适配多批次文档提交，因此接口需支持分段批量上传。文档包含项目编号、版本号、签章状态等校验字段，接口需校验必填参数完整性，避免无效归档。数据来源分散，需通过外部系统同步多类文档元数据，因此接口需兼容不同格式的结构化文本。归档后的数据需留存可追溯标识，接口需返回唯一归档编号用于后续运维查询。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| 服务端环境变量`AIPROXY_API_TOKEN` | 需配置与AI Proxy服务端一致的非空管理员Token | 符合FastGPT v4.17.0+的AI Proxy依赖要求 |
| 单次请求文档数量 | 前10条 | 避免单次请求过载，适配项目文档单次移交的合理体量 |
| `variables` | 绑定项目编号、文档版本号 | 匹配本品类文档的核心校验字段，确保元数据准确 |
| 超时时间 | 600秒 | 大型项目文档移交需足够的处理时长，避免中途中断 |
| `responseData` | 提取归档编号、校验状态 | 获取可追溯的归档结果，用于后续运维核对 |
| 单份文档大小限制 | 1000 MB | 适配通用文件上传的合理阈值，避免传输失败 |

## 容易做错的三处
- 现象：接口返回401未授权错误，或提示鉴权参数缺失。原因：服务端未正确配置非空`AIPROXY_API_TOKEN`（AI Proxy管理员Token，需与AI Proxy服务端配置一致），或未正确配置应用API鉴权参数。
- 现象：工作流中HTTP请求的body参数无法绑定文档元数据。原因：未正确使用`variables`绑定项目专属字段，导致参数无法自动填充到请求体中。
- 现象：接口返回归档校验失败。原因：未校验必填字段完整性，未包含项目编号、文档版本号等本品类核心字段。

## 怎么确认配好了
- 发送单份测试文档的请求，查看接口返回的`responseData`是否包含预期的归档编号与校验状态。
- 检查App/Admin服务端是否已正确配置非空`AIPROXY_API_TOKEN`和`AIPROXY_API_ENDPOINT`（AI Proxy服务根地址，无需附加路径后缀）。
- 触发工作流HTTP节点，确认`variables`绑定的项目元数据自动填充到请求body中。
- 上传多批次测试文档，确认接口支持分段批量提交，无请求中断问题。
