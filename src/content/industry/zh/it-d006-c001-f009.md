# CDN与边缘加速配置的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
该品类的数据通常来自CDN控制台、DNS解析记录、公网访问日志与边缘节点监控告警。日常产出的文档包括域名接入单、缓存规则配置单、刷新预热操作记录、故障根因分析报告。数据更新节奏一般为每日同步或随配置变更实时更新，字段包含域名接入状态、缓存命中率、边缘节点延迟、错误码分布等，通常按对应CDN厂商的控制台规范记录，无统一强制的外部字段要求。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据特征会对工具调用与插件配置带来多重约束。多源数据来源要求插件需支持对接CDN控制台、DNS解析、访问日志等多类API，需提前配置对应数据源的访问权限。数据更新节奏的差异，需要为不同数据类型设置差异化的轮询间隔，避免过度调用接口或延迟获取最新状态。日常文档的多样结构，要求插件需适配域名接入单、缓存规则等不同格式的输入与输出，需预设字段映射规则。运维场景的高频操作需求，需简化工具调用的参数配置流程，减少重复输入。基于FastGPT v4.17.0的工具调用框架，需额外兼容厂商特定的API鉴权方式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 自动匹配当前场景所需的CDN相关工具，减少手动选择的操作成本 |
| `functionCall` | `[{"name":"fetch_cdn_access_log","parameters":{"time_range":"24h"}}]` | 明确指定调用获取访问日志的工具，精准拉取对应时间范围的日志数据 |
| 数据轮询间隔 | `300 秒` 至 `86400 秒` | 匹配数据更新节奏，实时监控数据用短间隔，日更报告类数据用长间隔 |
| 文档字段映射规则 | 按实测标定 | 适配不同CDN厂商的文档字段差异，避免解析域名接入单、缓存规则等文档失败 |
| 工具调用超时阈值 | `15 秒` | 边缘节点响应通常较快，该阈值可平衡等待时长与调用成功率 |

## 容易做错的三处
- 现象：工具调用的模型选择环节无法读取预设的环境变量参数。原因：未在插件配置中开启环境变量调用权限，导致工具无法获取CDN厂商的API密钥等敏感配置。
- 现象：调用CDN访问日志拉取工具时返回格式错误，包含`$schema`字段的异常提示。原因：在工具调用参数中误添加了非预期的`$schema`字段，不符合FastGPT的工具调用格式规范。
- 现象：配置MCP接入后无法正常拉取CDN节点数据。原因：未正确配置MCP的连接参数，或未为MCP工具添加CDN相关的权限范围。

## 怎么确认配好了
- 手动触发一次预设的CDN工具调用，检查返回结果是否包含目标域名的缓存规则或访问日志信息。
- 查看插件运行日志，确认无环境变量读取失败或格式错误的提示。
- 验证MCP接入的连接状态，确认可以正常拉取边缘节点的监控数据。
- 调整数据轮询间隔后，核对工具拉取数据的时间间隔是否符合预期的数据源更新节奏。
