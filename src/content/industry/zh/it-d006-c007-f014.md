# SLA与服务报告的测试用例与缺陷分析：模型接入与配置

## 这个品类的数据长什么样
本品类数据来自监控系统、工单系统、合同文本与客户沟通记录，更新周期为月或季度。日常产出文档包含SLA条款、月度服务报告、可用性统计报表与客户复盘纪要，数据字段包含服务周期内的指标达标情况、异常事件记录、合同约定的服务阈值，无固定统一的单位，随具体服务项匹配对应计量标准。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据来源要求配置支持多格式数据解析的模型接入规则，月/季的更新节奏决定了模型调用可按周期触发汇总任务，无需高频运行。文档包含结构化条款与非结构化纪要，需配置适配混合文本的解析参数。SLA指标计算与异常归因依赖精准的逻辑对齐，需限制模型生成的随机性，同时保障上下文覆盖完整的周期数据，避免因信息缺失导致计算偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `AIPROXY_API_ENDPOINT` | 填写AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions等路径 | 作为App/Admin服务端的环境变量，配置AI Proxy服务的统一接入路径，避免跨系统配置冲突 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的管理员Token，且不能为空 | 作为App/Admin服务端的环境变量，保障AI Proxy服务调用的身份验证，符合SLA数据的敏感访问要求 |
| `temperature` | 0.1–0.3 | 降低生成随机性，保障SLA指标计算与归因结果的一致性 |
| `maxContext` | 8000–12000 token | 覆盖月度服务报告的全量上下文内容，确保模型能关联完整的周期数据 |
| `maxTokens` | 2000–3000 字符 | 适配SLA报告的单段输出长度，避免超出下游文档处理的格式限制 |
| `toolChoice` | auto | 允许模型按需调用工具处理结构化数据，提升SLA指标计算的准确性 |

## 容易做错的三处
- 界面提示“当前分组default下对于模型gpt-4o-mini无可用渠道”，原因是未在对应模型分组中配置该模型的接入凭证，或未将模型渠道绑定至default分组。
- 模型调用返回结果为空或格式异常，原因是未根据SLA报告的文档结构调整`maxContext`与`maxTokens`参数，导致上下文超出限制被截断。
- 生成的SLA指标计算结果与实际不符，原因是将`temperature`设置过高，导致模型生成的归因逻辑出现随机偏差。

## 怎么确认配好了
本文档适用于FastGPT v4.17.0版本。
- 调用测试接口，检查模型返回的内容是否包含SLA指标的基础计算逻辑，核对返回结果的格式是否匹配下游文档的导入要求。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置未出现格式错误，调用状态码为200。
- 调整`temperature`参数后，对比两次生成的SLA归因结果，确认结果的一致性符合业务预期。
- 导入一份月度服务报告的样本数据，验证模型是否能正确关联合同中的SLA条款与实际服务记录。
