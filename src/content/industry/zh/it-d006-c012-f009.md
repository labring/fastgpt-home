# 云网络与负载均衡配置的测试用例与缺陷分析：工具调用与插件
本文档适用于FastGPT v4.17.0版本。

## 这个品类的数据长什么样
该品类的数据主要来自云平台控制台导出的VPC规划文档、安全组规则配置、负载均衡监听器配置，以及客户提供的网络拓扑图、流量监控报表。日常产出的文档包含网段规划表、访问规则清单、健康检查配置项、变更审批单。数据更新随每一次网络变更触发，字段包含网段掩码、端口范围、协议类型、健康检查间隔等，无统一固定周期，仅随业务调整同步更新。不同于云主机交付类数据，该品类数据聚焦网络连通与流量分配的配置细节。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据结构存在较强的场景特异性，依赖云平台原生的结构化配置字段，工具调用需适配网段掩码、端口范围、健康检查间隔等非通用参数。数据更新随单次网络变更触发，无固定周期，工具调用需支持实时拉取最新配置，避免使用过期的历史数据生成测试用例。同时，缺陷分析环节需关联流量监控数据，工具调用需整合多源数据的关联查询能力，确保测试用例覆盖的配置项与实际部署状态一致。此外，该品类的出错后果直接影响业务访问，工具调用需内置配置校验逻辑，提前识别潜在的访问不通或流量转发错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配云网络配置的多参数校验场景，自动匹配可用工具 |
| `functionCall` | `["describeVPCConfig", "listSecurityGroups", "checkLBListeners"]` | 覆盖该品类核心的VPC、安全组、负载均衡配置校验需求 |
| 工具调用超时时间 | 300 秒 | 云平台配置拉取通常耗时100-200秒，预留足够的网络请求缓冲 |
| 工具结果缓存时长 | 15 分钟 | 云网络变更频率较低，缓存可减少重复调用云平台API的次数 |
| 单次工具调用返回条目上限 | 前20条 | 符合云平台API的默认返回条目限制，避免结果过载 |
| 触发工具调用的关键词 | 负载均衡、安全组、VPC、网络拓扑 | 匹配该品类的核心业务术语，精准触发工具调用 |

## 容易做错的三处
- 现象：工具调用执行后无返回结果，后台显示调用失败提示。原因：未正确配置`functionCall`参数的工具列表，或未开启工具调用开关，导致大模型无法触发对应云网络配置的拉取流程。
- 现象：生成的测试用例中包含“引用标记：［1］”字样。原因：工具调用返回的知识库关联文档数据未做格式清洗，直接将原始引用标记拼接至输出内容中。
- 现象：用户输入指定关键词后，未触发自定义接口回复，直接返回默认回答。原因：未配置关键词触发工具调用的规则，或自定义接口的调用参数未与工具调用流程绑定。

## 怎么确认配好了
- 发起包含“VPC配置校验”的测试提问，查看是否自动触发对应工具调用，核对返回结果是否包含VPC网段、安全组规则等信息。
- 查看工具调用日志，确认`toolChoice`参数的取值与配置一致，工具调用超时时间的设置未触发超时报错。
- 输入包含预设关键词的提问，验证是否触发自定义接口或对应工具调用流程，确认无默认回答返回。
- 生成测试用例后，检查输出内容是否无多余的引用标记字样，确认格式清洗规则已生效。
