# 企业软件许可证管理的测试用例与缺陷分析：工作流编排

## 这个品类的数据长什么样
企业软件许可证管理的数据来源于软件资产管理系统、采购系统、终端扫描工具及厂商授权文件。日常产出的核心文档包括许可证台账、软件使用清单、采购合同与合规审计报告。数据更新频率为月或季，与台账更新、合规审计周期匹配。核心字段包含许可证编号、授权数量、终端安装数、到期日等，需匹配授权与实际使用的安装数量，区别于通用IT资产盘点仅统计硬件或软件安装情况。

## 这些特征在「工作流编排」这一环带来什么约束
多源数据接入的需求要求工作流支持不同格式的文件解析与跨系统数据拉取节点，避免手动整理数据的重复操作。数据更新周期为月或季，因此工作流需配置匹配的定时触发规则，无需频繁手动启动。核心字段的唯一性与关联性要求工作流内的`variables`需绑定准确的字段参数，确保授权数量核对、超装识别等环节的逻辑正确。文档类型多样，需针对台账、合同、扫描报告分别配置对应的解析规则，适配不同的字段提取逻辑。FastGPT v4.17.0版本的工作流节点可适配上述配置需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 定时触发周期 | 按业务更新频率，月/季 | 匹配许可证台账、合规审计报告的更新节奏 |
| 文件解析节点 | 开启全量字段提取 | 覆盖许可证编号、授权数量、到期日等核心业务字段 |
| `variables` | 绑定许可证编号、授权数量、终端安装数 | 用于工作流内节点间的参数传递与比对逻辑 |
| 节点超时设置 | 600 秒 | 解析大型厂商授权文件或跨系统拉取数据需要充足处理时间 |
| 异常告警触发 | 超装数量>0、到期日<30天 | 匹配最耗时的超装识别与续费到期提醒业务环节 |
| `nodeId` | 绑定文件上传、数据比对节点ID | 配置节点间的触发依赖与参数流转 |

## 容易做错的三处
- 现象：上传厂商授权文件时提示Load file error，界面显示文件解析失败。原因：未配置对应格式的文件解析节点，或`variables`未正确绑定文件上传节点的输出参数。
- 现象：本地部署环境中上传许可证台账后，工作流解析节点无执行日志。原因：未开启工作流的自动触发开关，或节点间的触发依赖配置错误。
- 现象：代码运行节点执行授权数量核对逻辑失败，无法输出比对结果。原因：未在代码节点中正确引用`variables`绑定的字段参数，或未匹配对应的数据格式。

## 怎么确认配好了
- 上传一份测试用的厂商授权文件，查看FastGPT v4.17.0版本的工作流执行日志，确认文件解析节点成功提取核心字段。
- 手动触发一次工作流，核对数据比对节点的输出结果，确认超装识别逻辑正常运行。
- 配置定时触发任务，等待匹配的更新周期后，查看工作流的执行记录，确认自动触发生效。
- 模拟超装场景，验证异常告警节点是否按预期触发提示。
