# 信息流广告创意测试的测试用例与缺陷分析：工具调用与插件

本文档基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
该品类的核心数据来源于信息流广告平台、素材库、用户互动数据与转化数据，更新频率多为日度或周度。日常使用的文档包括创意脚本、素材测试表、投放数据报告与迭代清单，其中素材测试表包含创意类型、变量组合、投放时段、互动指标与违规标识等字段，投放数据报告则记录核心业务指标，整体数据围绕创意组合的测试效果展开。

## 这些特征在「工具调用与插件」这一环带来什么约束
日常文档以结构化测试表与报告为核心，要求工具调用需精准读取对应字段，避免无效数据拉取。数据来源分散且更新节奏固定，需配置触发式或定时式的工具调用逻辑，匹配数据更新周期。创意变量设计、疲劳判断与结论归纳为最耗时环节，工具调用需自动生成多组测试用例、对比素材互动数据判断疲劳度，同时集成违规检测逻辑，规避业务风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工具调用触发时机 | 按素材测试表更新完成触发 | 日常测试流程以素材测试表为核心载体，更新后需立即启动用例生成与分析 |
| `toolChoice` | `auto` | 适配不同类型的创意测试工具调用需求，自动选择合规的函数调用逻辑 |
| 最大并发调用数 | 前 10 条 | 匹配信息流广告平台的常规调用限额，避免触发频率限制 |
| 结果输出格式 | 结构化 JSON 格式 | 便于传递给下一个AI对话模块，直接提取点击率、转化成本等业务字段 |
| 超时时间 | 600 秒 | 覆盖素材拉取、数据汇总的常规耗时，避免因数据量波动导致调用中断 |
| 违规检测阈值 | 按实测标定 | 适配不同信息流平台的合规规则，避免误判或漏判违规素材 |

## 容易做错的三处
- 现象：调用OpenRouter API时返回请求地址无效的报错，原因是未使用官方推荐的请求端点，错误填写了通用API地址。
- 现象：并发调用工具时频繁触发429状态码，原因是未限制并发数，超出第三方接口或广告平台的调用频率限制。
- 现象：对话日志中未记录chatId参数的关联信息，原因是未在工具调用请求中正确传递chatId字段，或未开启对话参数的日志采集配置。

## 怎么确认配好了
- 提交一份已完成编辑的素材测试表，触发工具调用，检查工具调用日志中是否显示正确的请求地址与参数。
- 模拟多轮并发调用，查看是否触发频率限制报错，确认并发数配置符合对应接口的限额要求。
- 触发工具调用后，查看下一个AI对话模块的上下文窗口，确认是否包含工具返回的结构化业务数据。
- 查看对话日志，确认chatId参数被正确记录并关联到当前调用任务。
