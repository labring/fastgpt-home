# 信息流广告创意测试的测试用例与缺陷分析：引用来源与溯源

## 这个品类的数据长什么样
信息流广告创意测试的核心数据来自广告投放平台、内部素材存储库、用户交互日志、转化统计系统。日常工作文档包含创意脚本、素材测试表、投放数据报告、迭代清单，文档结构多为表格搭配文本备注，核心字段包含创意组合标识、测试周期、互动指标、转化指标。数据更新节奏按日或周更新，不同测试批次的素材变量、测试结果会分别归档至对应文档条目。

## 这些特征在「引用来源与溯源」这一环带来什么约束
由于数据来源分散，需关联广告平台、素材库、转化系统的多源信息，溯源环节需精准匹配到单个创意组合，采用针对素材单元的匹配方式。日常文档以表格为主，溯源需定位到具体的脚本行或测试表条目，对应文档内的单个条目。数据按日或周更新，需定期刷新引用源以保证信息时效性。创意变量为图片、视频、文案的组合，溯源需绑定到具体的素材单元，避免跨批次的错误关联。出错后会导致点击率下降、成本升高，因此溯源的准确性直接影响测试结论的可信度。

## 配置怎么定
FastGPT v4.17.0 下的配置项参考如下：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `quoteMaxToken` | `800–1200 token` | 匹配信息流创意文案与素材描述的总长度，避免截断关键溯源信息 |
| `responseData` | 包含素材ID、投放批次号、测试条目编号 | 关联到创意测试表与投放报告的具体条目，实现精准溯源 |
| `detail` | 开启 | 展示完整的素材来源与测试背景信息，满足优化师的溯源需求 |
| 最大上下文窗口 | `前3–5轮对话` | 信息流创意测试的讨论通常集中在近几轮的变量调整与结果分析，覆盖必要的上下文范围 |
| 引用源刷新频率 | `每12–24小时1次` | 匹配投放数据的日更新节奏，保证引用信息的时效性 |
| 关联文档范围 | 创意脚本、素材测试表 | 覆盖日常工作的核心文档类型，避免无关文档被纳入溯源范围 |

## 容易做错的三处
- 免登录分享链接访问应用时，引用原文功能显示无法查看。原因是未开启分享页的引用源权限配置，或配置项未同步到分享链路。
- 知识库回答末尾未显示引用段落。原因是`detail`参数未开启，或配置的`responseData`未包含必要的文档标识字段。
- 连续追问时无法关联上下文，后续问题出现答非所问的情况。原因是最大上下文窗口配置过小，或未开启多轮对话的上下文绑定逻辑。

## 怎么确认配好了
- 上传一份创意测试表与创意脚本，发起测试用例相关提问，查看回答末尾是否显示关联的文档条目。
- 生成免登录分享链接，访问后点击引用标识，确认可跳转至对应文档的对应位置。
- 发起连续3轮的测试优化提问，确认回答会关联前两轮的测试讨论内容。
- 调整`quoteMaxToken`参数后，查看回答的引用源长度是否符合配置的token范围。
