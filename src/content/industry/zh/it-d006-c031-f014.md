# 创作者入驻与认证的测试用例与缺陷分析：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据主要围绕创作者准入与身份核验产生。日常文档包含入驻申请单、身份资质扫描件、认证审核流转记录、合作框架协议等。数据来源覆盖创作者后台提交的账号信息、企业信用信息公示渠道获取的主体资质、账号历史行为数据、合同系统存储的合作条款文件。数据更新节奏随申请流程触发，单次申请全流程更新频次为每日或每完成一个审核节点。数据字段包含申请唯一标识、创作者账号ID、资质类型、审核状态、关联协议编号等，无统一固定的批量统计维度。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源数据接入的需求要求模型配置支持适配不同格式的输入，来自创作者后台的结构化账号数据、企业信用信息的公示文本、账号历史的行为日志，需要分别适配不同的字段拆分与编码规则。随申请节点触发的更新节奏，要求模型调用支持按需触发，需配置符合单次请求处理时效的参数。针对资质核验、风险判断的核心任务，需要调整模型的输出格式与置信度阈值，适配身份实体抽取、违规文本分类的业务需求。数据字段的非标准化特征，要求配置支持自定义字段映射的参数，避免因字段差异导致的模型输入异常。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| AIPROXY_API_ENDPOINT | 填写AI Proxy服务的根地址，例如 http://aiproxy:3000，不得附加 /v1 或 /chat/completions 等路径 | 该变量为FastGPT服务端配置的AI Proxy通信端点，非单模型服务地址 |
| AIPROXY_API_TOKEN | 填写与AI Proxy服务端配置一致的非空管理员Token | 该变量为FastGPT服务端配置的AI Proxy鉴权凭证，非模型服务商密钥或应用API Key |
| maxTokens | 8000–12000 token | 覆盖入驻申请、资质材料、审核记录的综合文本长度，避免输入内容被截断 |
| temperature | 0.2–0.4 | 降低资质核验时的随机输出，提升身份判断的一致性 |
| maxContext | 10 条历史审核记录 | 匹配日常审核流转的上下文长度，避免冗余数据占用模型上下文资源 |
| toolChoice | auto | 支持按需调用实体抽取工具，适配多字段的身份核验需求 |

## 容易做错的三处
- 点击启用指定嵌入模型后点击测试，返回404 status code（no body）。可排查项：确认FastGPT服务端已正确配置AIPROXY_API_ENDPOINT（AI Proxy服务根地址）与非空AIPROXY_API_TOKEN，且AI Proxy服务正常运行。
- 商业版部署后，渠道模型列表仅显示重排模型。可排查项：确认FastGPT服务端已正确配置AIPROXY_API_ENDPOINT与非空AIPROXY_API_TOKEN，服务启动校验通过。
- 重置oneapi的用户名和密码后，模型调用持续失败。可排查项：确认FastGPT服务端的AIPROXY_API_TOKEN环境变量未被意外修改，且与AI Proxy服务端配置一致。

## 怎么确认配好了
- 进入模型配置测试页面，输入创作者入驻申请的示例文本，点击测试调用，确认返回结果无报错且包含预期的资质核验字段。
- 查看渠道模型列表，确认目标语言模型已显示在可用列表中，可正常选择调用。
- 配置完成后提交一条测试入驻申请，触发模型调用，查看审核记录中的模型输出是否符合身份核验的业务逻辑。
- 调整temperature参数后，多次调用同一测试文本，确认输出结果的一致性符合业务要求。
