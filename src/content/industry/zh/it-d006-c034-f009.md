# 办公系统流程配置的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
这个品类的数据通常来自企业内部OA系统、组织架构目录、现行制度文件以及一线业务用户反馈。日常产出的文档包含流程配置单、审批节点表、表单字段说明和变更记录。流程配置单记录审批节点顺序、触发条件与权限绑定规则；审批节点表标注各节点的负责人与流转要求；变更记录保留配置修改的时间与操作人信息。数据更新节奏随流程配置变更触发，每月平均有多次调整。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据来源要求工具调用需支持对接OA、组织架构等多个接口，避免单一数据源导致的配置校验不完整。数据更新随变更触发，工具需支持实时拉取最新配置数据，避免使用过期缓存导致的测试用例失效。文档结构包含审批节点、权限字段等细分项，工具调用的参数需匹配这些字段的命名规则，否则会出现解析失败。测试验证环节耗时较长，工具需支持批量生成测试用例的能力，减少手动梳理的工作量。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配办公流程配置的多步骤工具调用场景，自动调度对应工具完成配置校验、用例生成等任务 |
| `functionCall` | `enabled` | 支持结构化解析流程配置单、审批节点表中的字段数据，便于自动生成标准化测试用例 |
| 工具调用超时阈值 | `300 秒` | 办公流程配置数据体量适中，300秒可覆盖多源OA数据拉取、权限校验的常规耗时 |
| 批量测试用例生成上限 | `前 20 条` | 匹配日常审批节点表的常规条目数量，避免生成冗余测试数据 |
| 流响应开关 | 开启 | 支持实时返回测试用例生成和缺陷排查的进度，便于实时监控配置校验过程 |
| 数据缓存时长 | `1 天` | 匹配流程配置的更新频率，避免使用过期的审批节点和表单字段数据 |

## 容易做错的三处
- 现象：工具激活状态显示为临时，无法持续拉取流程配置数据。原因：未配置持久化鉴权参数，仅启用了临时会话模式。
- 现象：调用工具生成测试用例时返回超时错误。原因：工具调用超时阈值设置过短，未适配多源OA数据拉取的耗时。
- 现象：基于知识库创建的应用无法检索最新流程配置数据。原因：未配置工具调用的实时数据拉取规则，仅使用了静态知识库缓存。

## 怎么确认配好了
- 手动触发工具调用，检查是否能拉取最新的审批节点表、表单字段说明等数据。
- 查看工具调用日志，确认`toolChoice`参数自动调度的任务与当前流程配置的校验需求匹配。
- 生成批量测试用例，检查用例是否包含审批规则、权限配置等核心字段。
- 开启流响应开关，验证是否能实时收到测试用例生成的进度反馈。
