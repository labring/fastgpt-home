# 办公系统流程配置的测试用例与缺陷分析：模型接入与配置

## 这个品类的数据长什么样
该品类的数据通常来自企业OA系统、组织架构库、内部制度文件及一线用户反馈。日常维护的文档包括流程配置单、审批节点表、表单字段说明与流程变更记录。数据更新随业务流程变更触发，无固定周期但平均每月至少一次。数据字段包含审批节点权限、表单校验规则、流转路径配置等，无统一固定单位，随具体流程配置需求调整。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散且随流程变更频繁更新，要求模型接入时支持快速对接多源异构文档，避免因配置滞后导致测试用例失效。流程配置单、审批节点表等文档结构差异大，需模型适配非标准化的文本解析，确保测试用例生成时能准确识别节点权限与流转逻辑。测试验证环节依赖实时数据校验，模型配置需支持低延迟的上下文调用，否则会拉长测试周期。另外，流程配置出错会直接影响业务运行，模型配置需强化结果校验逻辑，减少权限错误或审批路径偏差的概率。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 办公系统流程配置相关文档通常包含完整审批链路与节点细节，需覆盖足够上下文以准确解析配置逻辑 |
| `maxTokens` | 2000–3000 token | 测试用例与缺陷分析结果需包含详细的节点权限、流转路径说明，需足够输出长度承载完整内容 |
| `temperature` | 0.2–0.4 | 需保证配置解析的一致性，避免因随机偏差导致测试用例与实际流程不符 |
| `vision` | 开启 | 流程配置单可能包含流程示意图、权限分配图等视觉素材，需支持图片理解以完整提取配置信息 |
| `AIPROXY_API_ENDPOINT` | AI Proxy 服务的根地址，例如 http://aiproxy:3000（不得附加 /v1 或 /chat/completions 等路径，不得使用单模型地址） | 该变量为 App/Admin 服务端必需环境变量，不得在工作流全局变量、应用 API 请求头或普通模型管理页面填写 |
| `AIPROXY_API_TOKEN` | 与 AI Proxy 服务端配置一致的非空管理员 Token | 该变量为 App/Admin 服务端必需环境变量，不得在工作流全局变量、应用 API 请求头或普通模型管理页面填写，且不得作为应用 API 鉴权密钥 |

## 容易做错的三处
- 现象：使用渠道链接生成测试用例时，界面提示“undefined”is not valid json。原因：未正确设置`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`这两个服务端环境变量，导致 App/Admin 服务启动校验失败或接口调用返回无效格式的响应。
- 现象：上传流程配置示意图后，模型无法提取其中的配置信息。原因：未开启`vision`配置项，或本地部署环境未加载图片理解模型依赖。
- 现象：尝试接入claude系列模型时，调用失败提示地域限制。原因：未适配模型接入的地域配置，或接口地址未指向支持对应模型的服务节点。

## 怎么确认配好了
- 调用模型接口解析单份完整的流程配置单，检查返回结果是否覆盖所有审批节点与权限配置，确认上下文长度配置合理。
- 上传包含流程示意图的配置文档，检查模型是否能正确识别并提取其中的配置细节，验证`vision`配置生效。
- 发起测试用例生成请求，观察返回结果的格式是否符合测试用例的标准结构，确认输出长度与温度系数配置适配当前需求。
- 检查服务端环境变量配置，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`已正确设置且格式合法，调用状态码正常。
