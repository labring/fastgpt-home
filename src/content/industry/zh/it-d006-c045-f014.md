# 安全培训与钓鱼演练的测试用例与缺陷分析：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自员工通讯录、邮件网关、内部培训平台与用户点击统计系统。日常产出的文档包含培训课件、钓鱼演练方案、标准化邮件模板与演练结果报告。数据更新节奏多为季度或年度，核心字段涵盖演练人群范围、邮件触达记录、员工点击反馈与整改结果。数据围绕人员安全意识培训与钓鱼演练全流程生成，覆盖从方案设计到结果复盘的全环节，无统一固定格式，需适配多类型文档结构。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散的特点要求模型接入环节支持多源字段的标准化映射，避免因字段格式不统一导致的解析错误。文档类型多样，涵盖培训课件、邮件模板与结果报告，需要模型适配不同结构的文本处理逻辑。更新频率较低的特性，使得模型无需高频同步训练数据，但需支持季度级的文档内容变更适配。同时，演练人群筛选与模板设计为最耗时环节，模型接入需配置足够的上下文处理能力与超时阈值，以支撑大规模员工数据的批量处理与个性化内容生成。

## 配置怎么定
本页面配置说明基于FastGPT v4.17.0版本

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxTokens` | 8000–12000 token | 钓鱼邮件模板、演练方案与结果报告通常包含多段场景描述与规则，需足够的token支持完整内容生成 |
| `temperature` | 0.6–0.8 | 平衡内容的规范性与灵活性，确保生成的培训内容符合安全要求同时具备场景适配性 |
| `AIPROXY_API_ENDPOINT` | AI Proxy服务的根地址，例如 http://aiproxy:3000 | 为App/Admin服务端环境变量，需配置AI Proxy服务的根地址，不得附加 /v1 或 /chat/completions 等路径，非单模型地址 |
| `AIPROXY_API_TOKEN` | 与AI Proxy服务端配置一致且非空 | 为App/Admin服务端环境变量，为AI Proxy管理员Token，与AI Proxy服务端配置一致且不能为空，非应用API Key、模型供应商密钥等 |
| `maxContext` | 500–700 秒 | 处理大规模员工通讯录数据与点击统计时，预留足够的任务执行时间 |
| `toolChoice` | auto | 自动调用适配的工具完成人群筛选与数据汇总，简化配置复杂度 |

## 容易做错的三处
- 现象：生成的钓鱼邮件模板出现员工姓名、部门等字段为空。原因：未配置合理的`maxContext`超时阈值，批量处理员工数据时任务中途中断，字段映射未完成。
- 现象：上传演练场景的截图至模型处理环节时直接报错。原因：未开启`vision`配置项，或传入的图片格式不符合模型支持的规范。
- 现象：并发测试时超过设定阈值后出现无应答情况。原因：未根据`maxTokens`的取值调整并发上限，或未正确配置`AIPROXY_API_ENDPOINT`、`AIPROXY_API_TOKEN`环境变量导致服务连接异常。

## 怎么确认配好了
- 提交批量员工数据测试，检查生成的邮件模板是否正确填充所有预设字段，确认字段映射逻辑生效。
- 上传一张合规格式的测试图片，验证`vision`配置项是否正常触发视觉处理流程，无报错返回。
- 调整`temperature`参数至不同区间，对比生成的邮件模板内容，确认参数调整对输出效果的影响符合预期。
- 模拟多并发请求，观察接口返回状态，确认请求未因配置限制出现无应答情况。
