# 安全监控与SOC值守的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
本品类的数据来源于SIEM、EDR、NDR及第三方威胁情报源，更新节奏分为实时与日更两类。日常关联文档包括告警处置单、值班记录、威胁情报通报、安全运营日报周报，各文档字段包含告警ID、攻击类型、处置状态、响应时长等，其中告警处置单需关联具体攻击溯源字段，值班记录需记录实时研判进度与派单状态。

## 这些特征在「工具调用与插件」这一环带来什么约束
实时更新的告警数据要求工具调用需支持低延迟触发，避免因响应超时错过关键处置窗口。多源异构数据来源要求插件需适配不同API格式，同时需支持批量拉取SIEM/EDR的告警条目。日更的威胁情报与周报数据需支持定时触发调用，避免重复拉取全量数据占用资源。告警研判环节的高耗时特性，要求工具调用需支持上下文留存，关联历史值班记录与处置单，减少分析师重复查询操作。

## 配置怎么定
本配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | auto 模式，按告警优先级触发 | 适配SOC值守的实时告警研判需求，自动选择匹配的安全工具 |
| 工具调用超时阈值 | 300 秒 | 实时告警处置需快速响应，超过阈值需触发人工介入流程 |
| 插件批量调用上限 | 前 10 条告警 | 避免单次调用过载，适配SIEM批量告警的常规处理节奏 |
| `functionCall` | 强制指定安全工具集合 | 确保调用的工具均为SOC场景下的合规安全工具，避免非授权调用 |
| 定时触发配置 | 每 1 小时拉取日更威胁情报 | 适配日更类情报的更新频率，减少不必要的资源消耗 |
| 上下文留存时长 | 24 小时 | 关联当日值班记录与告警处置单，保障研判操作的连贯性 |

## 容易做错的三处
- 现象：工具调用同时触发2个及以上安全工具时，出现告警处置单字段不匹配。原因：未配置批量调用的参数校验规则，导致不同工具返回的数据格式冲突。
- 现象：获取当前时间插件调用失败，返回状态码400。原因：未在插件配置中绑定SOC场景的时间格式要求，导致返回值无法适配告警研判的时间戳字段。
- 现象：工具调用准确性低，误报排除环节耗时过长。原因：未限定工具调用的目标数据源范围，导致插件拉取了无关的SIEM日志条目。

## 怎么确认配好了
- 执行单次实时告警调用，检查工具返回的字段是否与告警处置单的预设字段一致。
- 触发批量调用测试，确认返回的告警条目数量符合配置的上限要求。
- 配置定时任务，检查是否按设定的时间间隔拉取威胁情报数据。
- 模拟调用失败场景，确认是否触发预设的人工升级告警流程。
