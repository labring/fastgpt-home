# 客户培训与使用手册的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
通常，该品类的数据来源包括产品帮助中心、客户组织架构、培训录屏、工单系统，更新频率为每单或每版本。日常产出的文档包含培训课件、用户手册、培训签到表、问题答疑清单，文档结构覆盖标准化操作说明、非标准化培训素材、用户反馈记录三类。数据字段包含操作步骤、权限配置、答疑关键词、培训签到状态等，无统一固定的单位要求，需根据文档类型灵活适配。该品类的核心使用主体为客户成功经理、培训讲师与产品运营，日常最耗时的环节为角色权限讲解、操作步骤演示与课后问题整理，若处理不当会导致客户不会使用产品、上线转化降低、工单数量激增。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据来源分散且更新频繁，要求工具调用与插件需支持实时拉取最新版的用户手册与工单数据，适配不同版本的文档格式，避免测试用例基于旧版内容生成。文档结构多样的特点，要求插件需具备多格式解析能力，可同时处理标准化用户手册与非标准化培训课件，覆盖不同类型的培训素材。数据字段覆盖操作步骤、权限配置等核心内容，要求工具调用需精准提取对应字段，避免冗余信息干扰缺陷分析与测试用例设计。同时，该品类的核心耗时环节与出错后果，要求工具调用需优先聚焦角色权限与操作步骤的解析，减少无关内容的召回，提升分析效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配不同培训文档的自动工具调用需求，无需手动指定调用类型 |
| `functionCall` | `enabled` | 支持提取用户手册中的操作步骤与权限配置作为函数调用参数 |
| 工具调用超时时间 | `300–600 秒` | 培训课件与用户手册多为长文本，需预留足够的解析与调用时间 |
| 单次调用最大token数 | `8000–12000 token` | 用户手册的单章节内容通常在该范围内，避免超出模型上下文限制 |
| 召回文档数量上限 | `前 8 条` | 培训答疑清单的常见问题数量有限，避免冗余数据干扰测试用例生成 |
| 文档解析优先级 | 先用户手册后培训课件 | 用户手册为标准操作文档，优先级高于非标准化的培训课件 |

## 容易做错的三处
- 现象为调用文档解析工具返回400状态码且无响应体，原因是未配置工具调用的前置预校验步骤，未按文档要求先触发预请求。
- 现象为函数调用提取的操作步骤与最新用户手册不符，原因是未设置版本匹配的召回规则，调用了旧版培训课件内容。
- 现象为工具调用返回的结果条数超出预期，原因是未限制单次召回的文档数量，导致冗余数据干扰缺陷分析。

## 怎么确认配好了
- 上传FastGPT v4.17.0版本的最新用户手册，触发工具调用，核对提取的操作步骤与文档原文一致。
- 导入单条培训答疑问题，验证工具调用后返回的匹配内容来自对应文档类型。
- 查看工具调用日志，确认无400状态码及无响应体的报错记录。
- 开启`functionCall`参数，验证函数调用能正确映射用户手册中的权限配置内容。
