# 客户培训与使用手册的测试用例与缺陷分析：模型接入与配置

## 这个品类的数据长什么样
该品类的日常文档包含培训课件、用户手册、培训签到表、问题答疑清单，典型使用主体为客户成功经理、培训讲师与产品运营。数据主要来源于产品帮助中心、客户组织架构、培训录屏与工单系统，更新频率为每单或每版本一次。文档结构覆盖操作步骤说明、权限配置指引、常见问题解答等类型，字段包含操作节点、权限角色、答疑场景等，无统一固定单位，随文档类型动态调整。

## 这些特征在「模型接入与配置」这一环带来什么约束
由于数据来源包含录屏文本、工单记录、帮助中心文章等多种格式，模型需适配不同长度与结构的输入内容；更新频率较高的特性要求配置需支持快速同步最新培训内容，避免模型使用过时的文档信息。同时，文档聚焦操作步骤与权限讲解，对生成内容的准确性要求较高，若配置不当易导致生成内容偏离实际培训标准，引发客户使用障碍与工单激增。此外，多类型文档的混合输入，要求模型接入配置需兼顾不同文档的特征适配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | `4000–8000 token` | 培训课件与用户手册的单段参考内容通常较长，需覆盖足够的原始文档信息以保证生成准确性 |
| `maxTokens` | `1000–1500 token` | 操作步骤类的回复不宜过长，需控制在用户可快速阅读的范围内 |
| `temperature` | `0.3–0.5` | 需保证生成内容严格匹配培训文档的准确表述，避免过度发散 |
| `toolChoice` | `auto` | 可自动调用工具整理工单与答疑清单，适配该品类的课后问题整理环节 |
| `AIPROXY_API_ENDPOINT` | 按实际部署的AI Proxy服务根地址填写，例如http://aiproxy:3000，请勿附加/v1或/chat/completions | 为App/Admin服务端必需的环境变量，是AI Proxy服务的访问根地址 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的管理员Token，不能为空 | 为App/Admin服务端必需的环境变量，用于AI Proxy服务的访问鉴权 |

## 容易做错的三处
- 现象：同一模型在FastGPT网页调试与外部接入场景下返回结果不一致。排查项：检查网页调试与外部调用的`maxContext`参数配置是否统一。
- 现象：添加模型后测试不通过，弹出配置缺失报错。排查项：检查App/Admin服务端是否已配置必填的`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`，且AI Proxy服务根地址格式符合要求。
- 现象：生成的操作步骤与培训课件内容不符，出现额外无关表述。排查项：检查`temperature`参数设置是否超出`0.3–0.5`的合理区间。

## 怎么确认配好了
- 进入FastGPT v4.17.0的模型测试页面，输入典型的操作类问题，核对返回内容是否准确引用了培训课件中的步骤说明。
- 调用外部接入接口，使用同一测试问题发起请求，对比网页调试的返回结果，确认配置参数完全一致。
- 查看模型运行日志，确认无`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`相关的认证失败或地址错误提示。
- 调整`temperature`参数至合理区间，观察生成内容的发散程度，确认符合该品类对准确性的要求。
