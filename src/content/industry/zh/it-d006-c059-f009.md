# 广告素材审核的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
这个品类的数据主要来自广告平台、落地页、商品资质及广告法条款，更新频率为日级或实时。日常处理的文档包括广告素材文件、落地页截图、审核意见表单、素材修改记录。数据字段包含素材唯一标识、违规类型标签、审核状态、修改时间戳等，无统一固定单位，随不同来源的素材格式调整。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源实时的数据来源要求工具调用需适配广告平台、落地页、商品资质等不同接口的拉取逻辑，且需支持低延迟响应以匹配实时更新的审核节奏。多样的文档类型要求插件需兼容广告素材文本、落地页截图、审核意见表单等不同格式的输入解析。逐条审核的业务场景限制了工具调用的批量规模，避免单次请求资源占用过高。同时，出错后果直接关联广告账户风险，要求工具调用需增加参数校验与失败重试机制，减少误判或漏审。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `"auto"` 或指定合规校验工具名称 | 适配广告素材审核的多工具协同需求，灵活调用不同类型的审核插件 |
| 单次请求素材上限 | `前 10 条` | 匹配逐条审核的业务节奏，避免单次请求资源占用过高或超时 |
| 失败重试次数 | `2–3 次` | 对冲第三方接口的临时波动，减少审核流程中断 |
| 超时时间 | `600 秒` | 覆盖落地页拉取、截图OCR解析等耗时较长的环节 |
| 结果校验开关 | 开启 | 确保工具返回的违规点与广告法条款匹配，降低误判或漏审风险 |
| `functionCall` | 按审核规则配置函数参数 | 精准触发落地页一致性比对、资质校验等专用工具函数 |

## 容易做错的三处
- 出现`connect ECONNREFUSED`报错，原因是插件配置的第三方审核工具地址未正确映射，或容器网络策略限制了端口访问。
- 基于Ollama部署的Qwen2.5模型无法触发工具调用，原因是未在模型配置中开启工具调用权限，或工作流中未正确绑定工具节点与模型输出。
- 自定义渠道配置Jina rerank服务调用失败，原因是未正确配置自定义渠道的请求头与接口地址，或未匹配服务的鉴权规则。

## 怎么确认配好了
- 提交单条测试素材，查看FastGPT v4.17.0的工具调用日志，确认请求参数与配置项一致。
- 模拟第三方接口临时异常，验证失败重试机制是否按配置触发。
- 对比工具返回结果与人工审核意见，确认结果校验开关是否生效。
- 查看插件监控面板，确认请求成功率符合业务预期阈值。
