# 广告素材审核的测试用例与缺陷分析：模型接入与配置

## 这个品类的数据长什么样
本品类的核心数据来自广告投放平台、落地页服务器、商品资质库及广告法合规条款库。日常处理的文档包括单条广告素材文件、落地页截图、逐次生成的审核意见与修改记录。数据更新频率为日级或实时，随投放计划、素材修改或合规条款更新同步变动。单条待审核数据包含素材文本、视觉元素、关联商品信息、审核历史字段，按单条素材、单页截图、单条审核意见分别记录，无统一固定单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类的数据特征对模型接入与配置带来多重约束。首先，数据来源分散且支持实时更新，要求接入配置需适配多数据源并行拉取，同时支持增量数据的实时校验逻辑。其次，待审核内容包含文本素材、落地页截图两类格式，需配置支持多模态处理的模型参数。单条待审核数据的总内容量覆盖素材文本、商品资质信息及历史审核记录，需限制模型的上下文与token消耗。同时，审核环节需逐条匹配合规条款，需配置稳定的调用参数以适配高频校验场景，避免因配置不当导致处理延迟或结果偏差。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的参数逻辑：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配单条广告素材、落地页截图及历史审核记录的总内容量，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 匹配单条审核结果的输出长度需求，平衡合规校验的详细程度与处理效率 |
| `vision` | 开启 | 适配落地页截图的视觉元素校验需求，识别图片中的违规文字、版式问题 |
| `temperature` | 0.1–0.3 | 降低审核结果的随机性，确保合规判断的一致性 |
| `AIPROXY_API_ENDPOINT`（服务端环境变量） | 填写AI Proxy服务的实际根地址，示例为http://aiproxy:3000，不得附加/v1或/chat/completions路径，不得使用单模型地址 | 适配广告素材审核的实时调用需求，确保模型响应及时性 |
| `AIPROXY_API_TOKEN`（服务端环境变量） | 填写与AI Proxy服务端配置一致的管理员Token，不得为空 | 保障AI Proxy服务调用的鉴权安全，避免未授权访问 |

## 容易做错的三处
- 现象：上传落地页截图后模型解析失败，返回`invalid file format`报错。排查项：检查`vision`配置项是否开启。
- 现象：启用重排模型后，最终输入大模型的结果仅包含单条最高相似度的匹配内容。排查项：检查`quoteMaxToken`参数配置是否正确。
- 现象：模型调用超时，返回`504 Gateway Timeout`状态码。排查项：检查`maxContext`参数设置，或检查AI Proxy服务运行状态。

## 怎么确认配好了
- 上传一条包含文本和图片的广告素材，检查模型是否能同时解析文本内容与图片中的违规元素。
- 发起多条实时审核请求，确认接口调用的响应时长符合业务需求，无频繁超时情况。
- 启用重排模型后，查看传入大模型的上下文内容数量，确认符合预设的校验范围。
- 核对`AIPROXY_API_TOKEN`与`AIPROXY_API_ENDPOINT`的服务端环境变量配置值，确保与部署的AI Proxy服务一致。
