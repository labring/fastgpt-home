# 投放效果优化的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
该品类的数据主要来自广告平台后台、归因分析系统、CRM线索库与落地页数据终端，更新节奏多为日级或实时。日常关联文档包含投放日报周报、每日调价记录、素材AB测试表与优化复盘台账，数据字段包含曝光量、点击量、转化成本、有效线索数等，单位涵盖次、元、条等，单条数据绑定具体广告计划、素材与投放时段。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据来源分散且格式多样，要求工具调用环节需支持对接多类数据源插件，适配不同接口的权限与返回格式。实时或日级的更新节奏，要求插件调用的触发频率需匹配业务调整周期，避免冗余调用或数据滞后。日常文档结构差异大，工具调用需兼容文本、表格类不同格式的输入解析。字段与单位的特异性，要求插件输出需完成标准化字段映射，确保不同来源的数据可统一用于测试用例与缺陷分析。

## 配置怎么定
FastGPT v4.17.0 版本下，以下配置项可直接在工作流插件模块中设置：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工具调用触发时机 | 按广告数据更新节点触发 | 匹配业务日级/实时更新节奏，避免无效调用 |
| `toolChoice` | 自动模式 | 适配多工具联动场景，自动选择对应数据源插件 |
| 插件超时阈值 | 60-120秒 | 覆盖广告平台接口常规响应时长，避免因网络波动中断流程 |
| 输出字段映射规则 | 按业务台账字段匹配 | 对齐日报、调价记录的标准字段，简化后续分析 |
| `functionCall` | 开启强制参数校验 | 确保插件输入的曝光量、转化成本等字段格式合规，减少解析错误 |
| 插件调用重试次数 | 2-3次 | 应对广告平台接口临时波动，降低单次调用失败概率 |

## 容易做错的三处
- 现象：调用文档解析工具时返回读取异常报错。原因：未适配素材测试表的表格格式，插件无法识别自定义字段或合并单元格结构。
- 现象：通过API调用工作流时，文本拼接的变量未出现在返回结果中。原因：未配置标准化字段映射规则，变量字段格式不符合插件调用要求，导致解析丢失。
- 现象：批量调用插件时出现流程中断。原因：未设置合理的重试次数与超时阈值，无法应对广告平台接口的临时波动。

## 怎么确认配好了
- 手动触发一次工具调用，核对返回结果的字段与业务台账的标准字段是否对齐。
- 调用API接口，验证拼接后的文本是否包含预设变量内容。
- 模拟多轮调用，观察插件调用的成功率与流程稳定性，调整配置至符合业务需求。
- 查看工具调用日志，确认触发时机与业务数据更新节点匹配。
