# 投标文件编制的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
这个品类的数据围绕单次投标任务生成，日常文档包含投标文件、资格证明、商务偏离表、技术偏离表，数据来源为招标公告、招标文件、企业资质库与供应商报价，更新节奏随单任务完成而终止。文档需严格匹配招标方格式要求，包含资格响应条款、报价明细、资质扫描件对应字段，无通用固定结构，需随每轮招标公告调整内容与字段顺序。

## 这些特征在「工具调用与插件」这一环带来什么约束
每单任务的数据源与格式要求均不固定，要求工具调用需支持动态拉取最新招标公告与招标文件内容，适配单次任务的定制化需求。文档需严格匹配招标方格式，插件需支持对商务偏离表、技术偏离表的字段完整性与格式合规性校验。出错后果直接关联废标、保证金损失，工具调用需嵌入缺陷分析环节，对条款响应、资质核对结果做实时校验。单次任务的差异化需求，要求插件配置支持随单调整参数，无需全局固定设置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `toolChoice` | `auto` | 适配FastGPT v4.17.0的工具调用逻辑，支持自动选择资质核对、格式校验类工具 |
| 函数调用触发时机 | 每完成1000字符的文档生成后 | 匹配投标文件的分段编写节奏，避免单次调用内容过长导致超时 |
| 格式校验插件调用范围 | 前3条核心偏离表条目 | 优先校验商务与技术的重点响应条款，符合投标文件的评审优先级 |
| 工具调用超时阈值 | 600秒 | 覆盖从拉取招标公告到完成资质核对的平均耗时，按实测标定 |
| `functionCall` | 开启强制校验模式 | 确保工具调用结果直接纳入缺陷分析环节，避免未校验内容进入最终文档 |

## 容易做错的三处
- 现象：调用企业资质库工具时返回401状态码，原因：未正确配置工具鉴权参数，未绑定对应数据源的合法访问凭证。
- 现象：生成的技术偏离表字段为空，原因：未开启`functionCall`强制校验模式，工具调用结果未被正确捕获并写入文档对应字段。
- 现象：插件调用触发超时告警，原因：单次调用拉取了全量招标公告内容，未按分段拉取配置，导致耗时超出预设阈值。

## 怎么确认配好了
- 发起单次小型投标文档生成任务，查看工具调用日志中是否包含资质核对、格式校验的执行记录。
- 手动输入一条不符合招标格式的偏离表条目，验证插件是否触发缺陷告警。
- 检查工具鉴权配置项是否绑定了对应数据源的访问凭证，确认无空值或无效密钥。
- 调整单次调用内容长度为500字符，验证工具调用耗时是否在预设的600秒范围内。
