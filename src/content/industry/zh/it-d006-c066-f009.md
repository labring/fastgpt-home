# 搜索广告关键词管理的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
该品类的核心数据来自搜索广告后台、搜索词报告、竞价排名数据与落地页数据，更新频率多为每日或每周。日常产出的标准化文档包含关键词清单、否词表、出价记录与搜索词报告，各文档包含关键词文本、匹配模式、单次出价金额、点击量、转化成本等固定字段，单位统一为人民币元、次、字符等基础单位，无额外非预设自定义字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据来源分散，需对接多类广告后台接口，工具调用环节需支持多独立端点的配置，避免单一接口故障影响整体关键词管理流程。日常文档字段标准化程度高但覆盖维度多，工具调用需明确指定需提取的字段范围，防止返回冗余数据占用上下文。数据更新频率较高，工具调用需适配每日或每周的批量处理节奏，同时需配置实时监控机制，及时捕捉无效点击、转化成本异常等问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| 工具调用模式 | 按`functionCall`配置 | 适配搜索广告数据的结构化提取需求，避免自由格式输出导致的字段混乱 |
| 工具调用触发时机 | 每日定时触发 | 匹配搜索广告后台数据的日更节奏，确保处理最新的关键词与出价数据 |
| 单次工具调用超时时间 | 600秒 | 适配多广告接口的并行请求耗时，避免因接口延迟导致任务失败 |
| 工具返回结果条数上限 | 前20条 | 匹配单批次关键词管理的合理处理规模，防止返回数据过多占用上下文 |
| 错误重试次数 | 3次 | 应对广告接口临时波动的场景，减少因短暂网络问题导致的任务中断 |
| MCP服务代理端点 | 按广告后台API完整路径与鉴权参数配置 | 确保工具调用能正确对接搜索广告后台的数据源 |

## 容易做错的三处
- 谷歌搜索插件返回结果为空，原因是未正确绑定搜索广告关键词的上下文参数，导致工具调用时未传入正确的搜索词范围。
- MCP服务代理端点配置不生效，原因是未填写完整的API路径与鉴权参数，导致无法正常对接搜索广告后台接口。
- 工具调用触发后无响应，原因是未启用`toolChoice`参数的强制调用模式，导致大模型未触发工具调用流程。

## 怎么确认配好了
- 手动触发一次工具调用，检查返回结果是否包含正确的关键词清单、出价记录等预设字段。
- 查看FastGPT v4.17.0的工具调用日志，确认`functionCall`参数已被正确启用，无格式错误。
- 配置定时触发任务，等待一个更新周期后，检查是否自动拉取最新的搜索词报告数据。
- 使用Qwen2.5-14B模型测试工具调用，确认模型能正确触发结构化工具调用流程。
- 模拟接口错误场景，确认错误重试机制已按配置触发，任务未直接中断。
