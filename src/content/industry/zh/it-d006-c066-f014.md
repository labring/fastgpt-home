# 搜索广告关键词管理的测试用例与缺陷分析：模型接入与配置

本文基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
典型主体为SEM优化师、代理商运营、品牌市场人员，日常处理的文档包含关键词清单、否词表、出价记录、搜索词报告。数据主要来源于搜索广告后台、搜索词报告、竞价排名数据及落地页数据，更新频率多为日度或周度。文档结构固定，包含关键词文本、匹配类型、出价金额、搜索量等字段，单位涵盖人民币、次、字符等。与其他广告品类不同，该品类围绕用户主动搜索词开展工作，核心环节耗时集中在关键词扩展、否词筛选及出价匹配调整。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的多源、固定结构数据要求模型接入时需适配多种文档格式，避免出现字段不匹配的错误。日/周级的更新频率意味着模型上下文需支持批量历史数据导入，不宜设置过短的上下文长度。核心环节的高耗时特性要求模型调用需具备自动化工具能力，减少人工干预。同时，出错后果直接影响广告投放效果，需配置完善的日志采集与失败重试机制，且模型输出需严格匹配广告投放的合规性要求，避免生成违规关键词或出价建议。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配关键词清单、否词表、搜索词报告等多文档的批量上下文输入 |
| `maxTokens` | 2000–3000 token | 满足否词筛选、出价建议、关键词扩展的长文本输出需求 |
| `temperature` | 0.2–0.4 | 保证关键词判断、否词筛选的输出一致性，避免生成无关或违规内容 |
| `toolChoice` | auto | 自动调用工具完成关键词匹配、数据查询等任务，提升处理效率 |
| `AIPROXY_API_ENDPOINT` | 填写AI Proxy服务的根地址，例如`http://aiproxy:3000`，请勿附加`/v1`或模型服务地址路径 | 为App/Admin服务端必需的环境变量，指定AI Proxy服务访问地址 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的管理员Token，不能为空 | 为App/Admin服务端必需的环境变量，用于AI Proxy服务身份验证 |

## 容易做错的三处
- 现象：agent执行详情页显示模型响应完成原因含“链接断开”。排查项：检查App/Admin服务端是否正确设置了`AIPROXY_API_ENDPOINT`（AI Proxy服务的根地址）和`AIPROXY_API_TOKEN`（AI Proxy管理员Token），未配置或配置错误会导致服务启动校验失败或模型调用链路中断、权限验证失败。
- 现象：模型提供商管理页面未展示调用日志。原因：未开启接口日志采集开关，或日志存储配置未正确绑定至当前部署环境。
- 现象：自定义部署的模型在agent环节无法正常运行，但知识库搜索测试可正常使用。原因：未在agent配置中启用该模型的工具调用权限，或模型输入格式与该品类的关键词数据结构不匹配。

## 怎么确认配好了
- 执行单次关键词扩展测试，核对模型输出的关键词是否符合当前品类的搜索词特征，与输入的关键词清单字段匹配。
- 查看模型提供商管理页面的调用日志模块，确认有最新的接口调用记录生成。
- 模拟一次否词筛选任务，核对模型输出的结果是否与本地否词表的字段规则一致。
- 检查agent执行详情页的响应状态码，确认返回正常状态码，无异常报错提示。
