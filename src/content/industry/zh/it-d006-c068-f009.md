# 数据库云服务运维的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
数据库云服务运维的核心数据来自云数据库控制台、慢日志、监控指标与工单系统。日常产出的文档包括实例变更单、备份恢复记录、性能诊断报告、参数调整记录，数据字段包含实例ID、慢SQL耗时、备份文件大小、工单状态等，单位涵盖毫秒、GB、天等。数据更新频率为每日或随实例变更触发，不同来源的数据更新节奏存在差异，慢日志与监控指标实时或近实时更新，工单与变更记录则随操作完成同步更新。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据来源要求工具调用需对接多个不同的API接口，插件需兼容不同接口的鉴权、参数格式与返回结构。数据更新节奏的差异要求插件的轮询间隔需匹配对应数据源的更新频率，避免因轮询过频触发接口限流，或过慢导致数据滞后。文档字段的特异性要求工具调用需指定提取特定字段，例如仅返回慢SQL的耗时与执行计划。多租户服务边界则要求插件需集成租户权限校验逻辑，防止工具调用越权访问其他租户的数据库资源。

## 配置怎么定
以下配置适用于 FastGPT v4.17.0 版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `toolChoice` | 设为`auto` | 适配测试用例与缺陷分析的多样化场景，让模型自主选择匹配的运维工具 |
| 工具超时时间 | 设为`300-600 秒` | 匹配云数据库API的常规响应延迟范围，避免因超时中断慢SQL定位或备份恢复演练流程 |
| `functionCall` | 开启严格模式 | 确保工具调用的参数格式符合云数据库API的校验规则，减少格式错误导致的调用失败 |
| 单次工具调用返回条数 | 设为`前10条` | 适配慢日志、监控指标的批量数据返回上限，避免返回过多数据导致上下文过载 |
| 租户权限校验 | 开启 | 匹配数据库云服务运维的多租户边界要求，防止越权访问其他租户的数据库实例 |

## 容易做错的三处
- 工具调用返回的图片URL无法直接在界面展示，原因是未配置工具返回内容的渲染规则，未将URL字段标记为可渲染资源。
- 调用本地创建的MCP服务失败，原因是未在FastGPT插件配置中添加本地服务的访问白名单，或未正确配置服务的监听端口与通信协议。
- 开启工具调用后模型未输出思维过程，原因是未保留思维链输出的配置项，或工具调用的强制模式覆盖了思维过程生成逻辑。

## 怎么确认配好了
- 发起一次慢SQL定位的测试调用，检查返回结果是否包含实例ID、慢SQL耗时等预期字段，且字段格式符合云数据库API的定义。
- 查看插件配置的租户权限校验开关状态，确认多租户隔离规则已生效，无法访问其他租户的数据库实例数据。
- 触发工具调用流程，检查界面是否正常展示返回的图片URL对应的资源，或返回的文本内容符合预期格式。
- 查看工具调用的日志，确认每次调用的超时时间符合配置的`300-600 秒`范围，未出现频繁超时错误。
