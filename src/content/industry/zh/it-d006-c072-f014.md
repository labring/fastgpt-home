# 数据采集任务设计的测试用例与缺陷分析：模型接入与配置

## 这个品类的数据长什么样
该品类的数据围绕数据采集任务全流程生成，来源包括客户明确的采集需求、公开合规数据源、自研采集工具沉淀的样本库，以及现场采集的原始数据。日常产出的文档包含采集方案、样本规格说明、授权合规文件与任务排期表，更新频率按单项目或每周迭代。数据字段通常包含样本范围、采集字段、格式要求、授权期限等，无统一强制单位，需匹配客户需求与采集工具的输出格式要求。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据存在来源分散、字段随客户需求动态调整、合规性要求明确的特征，对模型接入与配置带来多重约束。首先，动态变化的样本字段要求模型支持灵活的参数适配，避免固定模板导致的采集偏差；其次，合规性相关的授权信息需要模型准确识别并校验，需配置足够的上下文长度承载合规文档内容；最后，分散的数据源需要模型适配不同接口的调用规则，需明确配置接口端点与验证参数，防止因数据源不兼容导致采集任务中断。本文基于FastGPT v4.17.0版本编写。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 承载采集方案、样本规格等多份文档的上下文内容，避免因上下文溢出丢失关键合规与字段信息 |
| `maxTokens` | 2000 token | 适配采集任务的单次结果输出长度，确保字段描述与合规说明完整传递 |
| `temperature` | 0.3–0.5 | 降低生成随机性，保证采集字段与格式要求的输出一致性，避免因参数波动导致的采集偏差 |
| `AIPROXY_API_ENDPOINT` | http://127.0.0.1:8080 | AI Proxy服务的根地址，为FastGPT App/Admin服务端必需的环境变量，不得附加/v1或模型接口路径 |
| `AIPROXY_API_TOKEN` | 与AI Proxy服务端配置一致的非空管理员Token | 为FastGPT App/Admin服务端必需的环境变量，用于AI Proxy服务的身份验证 |
| `vision` | 关闭 | 该品类数据以文本类采集方案、字段说明为主，无需视觉模型能力，减少不必要的资源消耗 |

## 容易做错的三处
- 现象：配置OneAPI对接本地Ollama模型时，接口测试返回超时错误，主机端口访问与容器服务运行均正常。排查项：误将`AIPROXY_API_ENDPOINT`配置为Ollama等单模型服务地址（含/v1路径），或混淆了模型渠道配置与AI Proxy服务环境变量。
- 现象：引用text-embedding-3-large作为索引模型时，数据采集任务执行过程中持续卡滞无响应。原因：未配置`maxContext`的合理取值，或取值超出模型支持的上下文上限，导致模型加载索引数据时资源耗尽。
- 现象：将代码块输出的有效String类result传入大模型后，系统返回Question is empty报错，且result本身存在有效内容。原因：未在模型接入配置中适配工具调用的输入格式要求，导致模型无法正确解析传入的非标准文本内容，误判请求为空。

## 怎么确认配好了
- 执行FastGPT服务启动校验，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置可正常连通AI Proxy服务，无权限或路由错误。
- 调整`maxContext`与`maxTokens`的取值，模拟采集任务的最大上下文需求，验证模型可正常加载并处理相关文档内容。
- 配置测试采集任务，传入预设的样本字段与合规说明，确认模型输出的采集规则与预设要求一致，无格式偏差。
- 检查`temperature`的取值，通过多次测试验证生成结果的一致性，确认符合采集任务的格式要求。
