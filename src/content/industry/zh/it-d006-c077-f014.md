# 机房巡检与环境监控的测试用例与缺陷分析：模型接入与配置

## 这个品类的数据长什么样
机房巡检与环境监控的数据来源包括动环监控系统、门禁系统、UPS监控设备与视频巡检摄像头。数据更新节奏分为实时与日级，实时数据包含即时告警、温湿度读数，日级数据包含完整巡检表、值班日志与归档告警记录。日常文档以结构化表格为主，包含设备ID、温湿度值（单位为℃与%RH）、告警等级、巡检时间戳等字段，同时配套非结构化的视频巡检画面文件。数据的使用者为IDC值班运维与设施工程师，核心用于连续运行状态的监控与异常处置。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据同时包含结构化日志与非结构化视频画面，因此模型接入需同时支持文本推理与视觉分析能力。实时或日级的更新节奏要求上下文窗口配置需适配短周期增量数据的处理，避免冗余历史数据占用过多资源。多字段的结构化文档要求明确模型的输入字段映射规则，防止解析时出现字段混淆或单位识别错误。异常处置的高时效性要求模型调用的延迟需匹配运维响应的时效标准，同时需配置失败重试机制以应对网络波动。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配机房巡检的实时告警与历史记录的上下文长度，避免截断关键运维数据 |
| `vision` | 开启 | 支持解析视频巡检画面的异常状态，覆盖非结构化数据的推理需求 |
| `toolChoice` | auto | 自动选择合适的工具处理结构化日志与非结构化视频，适配多类型数据源 |
| `temperature` | 0.2–0.4 | 降低随机输出，确保告警分析的结果准确稳定，匹配运维场景的严谨性要求 |
| `quoteMaxToken` | 1000 token | 保留关键引用片段的长度，避免冗余引用占用上下文窗口 |
| `AIPROXY_API_ENDPOINT` | 填写AI Proxy服务的根地址（如http://aiproxy:3000，不得附加/v1或/chat/completions等路径） | 为FastGPT App/Admin服务配置的环境变量，用于连接AI Proxy服务，确保服务启动与模型调用连通性 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的非空管理员Token | 为FastGPT App/Admin服务配置的环境变量，用于AI Proxy服务的身份验证，防止未授权访问 |
| `maxTokens` | 2000 token | 限制单轮模型输出长度，避免冗长分析影响运维响应效率 |

## 容易做错的三处
- 模型调用失败，后台提示连接超时或服务启动校验失败。排查项：未正确配置服务端环境变量`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`，或机房网络限制了该代理地址的访问权限。
- 模型输出的告警分析结果与实际巡检数据不符，字段解析混乱。原因是未明确`toolChoice`的调用规则，导致模型未按指定字段映射处理结构化巡检日志。
- 视频巡检画面无法被模型正确解析。原因是未开启`vision`参数，或未配置支持视觉推理的模型接口。

## 怎么确认配好了
- 访问配置的`AIPROXY_API_ENDPOINT`地址，验证接口连通性。
- 上传一条结构化的温湿度告警记录与一段视频巡检画面，发起模型调用，检查输出是否包含对应告警的分析与画面异常点标注。
- 查看模型调用日志，确认`maxContext`与`maxTokens`的参数值与配置一致，无异常截断。
- 模拟异常场景触发，检查模型输出的告警等级与实际数据匹配度，确认`temperature`参数的生效效果。
