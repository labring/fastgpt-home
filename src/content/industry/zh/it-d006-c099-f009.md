# 移动端开发的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
移动端开发的测试用例与缺陷分析数据，主要来自代码仓库提交记录、应用商店后台审核进度、崩溃监控平台告警日志、机型覆盖统计报表。日常关联文档包含端版本发布单、多机型适配清单、崩溃根因分析报告、应用商店上架资料。数据更新节奏为每日同步或每版本发布周期更新，字段涵盖机型型号、系统版本、崩溃堆栈、测试用例执行结果、审核状态等，随不同数据源类型调整对应字段格式与单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
移动端开发的测试数据多源分散，工具调用需适配代码仓库、应用商店后台、崩溃监控平台等不同接口的鉴权与数据格式要求。数据按日或版本周期更新，工具需支持定时触发或版本节点触发的调用逻辑，避免重复拉取无效数据。日常关联文档包含机型适配清单、发布单等，插件需自动关联对应文档字段，自动生成对应机型的测试用例。同时需处理应用商店审核状态、机型系统差异等移动端特有场景，确保工具调用结果匹配业务流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配多数据源接口的自动调用需求，符合FastGPT v4.17.0版本的工具调用规范 |
| `functionCall` | 按实测标定 | 支持结构化输出测试用例与缺陷分析结果，适配崩溃日志、适配清单等结构化文档处理 |
| 循环调用触发条件 | 按版本发布节点或每日 0 点 | 匹配数据按版本或日更新的节奏，避免无效重复调用 |
| 接口超时阈值 | 30–60 秒 | 适配应用商店后台、崩溃监控平台的接口响应周期，避免超时中断 |
| 文件识别格式过滤 | 仅允许 .xlsx、.log、.plist 格式 | 匹配移动端开发日常文档的常见格式，过滤无效上传文件 |
| 测试用例生成上限 | 前 20 条机型记录 | 适配单版本适配清单的典型机型数量，避免生成冗余用例 |

## 容易做错的三处
- 现象：调用多模态插件处理移动端崩溃日志截图时，返回结果缺失机型系统信息。原因：未在插件配置中指定提取移动端特有字段的规则，导致插件无法识别日志中的机型、系统版本参数。
- 现象：工作流循环调用应用商店后台接口时，触发接口限流报错。原因：未设置循环调用的间隔时长，连续发起请求超出平台接口调用限制。
- 现象：上传.xlsx格式的适配清单后，无法触发AI对话生成测试用例。原因：未配置文件识别格式过滤规则，或过滤规则未包含.xlsx格式，导致文件被拦截未进入处理流程。

## 怎么确认配好了
- 手动触发一次工具调用，查看返回结果是否包含机型、系统版本、崩溃堆栈等移动端开发测试所需的核心字段，确认字段提取规则匹配业务需求。
- 启动定时触发的工作流，检查是否在设定的版本节点或每日指定时间自动拉取应用商店后台的审核状态数据，确认触发逻辑生效。
- 上传.xlsx格式的适配清单文件，查看是否能正常进入AI处理流程，确认文件格式过滤规则配置正确。
- 发起两次间隔10秒的循环调用请求，检查是否触发接口限流，确认超时阈值与间隔设置符合平台接口调用要求。
