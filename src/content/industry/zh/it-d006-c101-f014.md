# 续费健康度管理的测试用例与缺陷分析：模型接入与配置

本文档基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
这个品类的数据主要来自CRM系统、产品使用数据、工单统计台账与合同管理台账。日常处理的文档包括客户健康度报告、续费预测表、风险客户清单与客户沟通纪要。数据更新节奏通常为周度或月度，单份文档包含客户标识、合同周期节点、近周期使用频次、工单响应情况、历史沟通记录等字段，无统一固定单位，随文档类型调整。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据的周度或月度更新节奏要求模型接入配置需适配批量任务调度，避免高频重复调用产生额外成本。多类型文档的混合输入需求，要求配置支持结构化表格与非结构化文本的兼容解析。分散的数据来源需要统一的接入接口配置，确保多台账数据的同步读取。字段无统一单位的特征，要求模型配置支持多维度数值的标准化解析，降低后续数据解读的人工成本。风险客户清单的时效性要求，需限制单轮模型调用的最大响应时长，避免延迟影响续费动作跟进。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | `8000–12000 token` | 适配多份客户文档的上下文整合需求，覆盖合同台账、沟通纪要等多源数据的总长度 |
| `maxTokens` | `2000 token` | 控制单轮输出长度，避免续费分析结果过长导致可读性下降 |
| `temperature` | `0.2–0.4` | 降低随机生成概率，确保风险客户归类的一致性 |
| `AIPROXY_API_ENDPOINT` | 填写AI Proxy服务根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions路径，不得填写VLLM/Ollama/Xinference等单模型地址 | 为AI Proxy服务根地址环境变量，适配企业内部数据隔离的接入要求，确保敏感客户数据不泄露 |
| `AIPROXY_API_TOKEN` | 填写与AI Proxy服务端配置一致的管理员Token，不得为空 | 为AI Proxy管理员Token环境变量，限制接口调用权限，避免未授权访问 |
| `toolChoice` | `auto` | 自动选择合适的工具处理结构化表格与文本数据，适配多类型文档的解析需求 |

## 容易做错的三处
- 现象为调用相关接口返回403状态码，界面显示鉴权失败。排查项：检查服务端是否正确配置`AIPROXY_API_ENDPOINT`（AI Proxy服务根地址）与`AIPROXY_API_TOKEN`（AI Proxy管理员Token），未配置必填变量会导致启动校验失败。
- 现象为生成的续费建议中出现敏感内容，未被拦截。原因是未开启模型自带的敏感词过滤配置，或未对接企业内部敏感词校验工具。
- 现象为解析多列excel文档时，字段错位，结果条数与预期不符。原因是未配置适配结构化表格的解析参数，默认文本解析无法识别列结构。

## 怎么确认配好了
- 提交批量测试任务，选取10份风险客户清单样本，核对模型输出的风险归类结果与人工标注是否一致。
- 检查服务端部署配置，确认`AIPROXY_API_ENDPOINT`（AI Proxy服务根地址）与`AIPROXY_API_TOKEN`（AI Proxy管理员Token）已正确设置且非空，无格式错误。
- 调整`temperature`参数，对比不同取值下的输出稳定性，确认归类结果无明显波动。
- 上传混合类型的测试文档，确认模型可同时解析表格与文本内容，无字段错位问题。
