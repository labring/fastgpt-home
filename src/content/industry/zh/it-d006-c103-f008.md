# 美术资产生产管理的测试用例与缺陷分析：工作流编排

## 这个品类的数据长什么样
这个品类的数据主要来自美术资产库、项目管理系统、引擎资源包及外包交付文件。日常关联文档包含美术需求单、资产规格表、外包反馈表与验收记录，字段涵盖资产唯一标识、面数、分辨率、交付时效、验收状态等，单位涉及像素、三角面数、MB等。数据更新以日或周为周期，单次交付包的资源体量差异较大，从单张纹理贴图到批量3D模型文件不等。

## 这些特征在「工作流编排」这一环带来什么约束
美术资产生产管理的数据特征对工作流编排带来明确约束。多源异构的关联文档与资源包，要求工作流中配置跨系统数据拉取与格式转换节点，适配不同来源的数据格式。日/周级的更新节奏，需要工作流支持定时触发与手动触发两种模式，兼顾周期性校验与临时验收需求。资源体量差异大的特点，要求工作流节点支持动态调整处理阈值，适配单文件与批量资源的校验场景。此外，外包交付文件的非标准化特性，需要在编排中加入前置校验节点，过滤不符合格式要求的交付内容。同时，美术资产的验收记录需与项目管理系统的任务进度绑定，因此工作流中需配置数据同步节点，确保测试结果同步更新至项目管理系统。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本

| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| 触发模式 | 定时触发+手动触发双模式 | 适配日/周级的数据更新节奏，兼顾临时校验需求 |
| `variables` 配置 | 包含资产面数阈值、分辨率标准、验收规则集 | 统一管理多类美术资产的校验标准，适配美术需求单与资产规格表的字段差异 |
| `nodeId` 配置 | 绑定跨系统拉取节点、格式校验节点、缺陷标记节点 | 精准定位工作流中的关键环节，便于后续故障排查与流程调整 |
| 批量处理上限 | 800–1200 个资源文件/次 | 适配外包交付包的资源体量差异，避免节点资源过载 |
| 超时阈值 | 600 秒 | 适配大体积3D模型的校验时长，防止任务异常中断 |
| 异常重试次数 | 2–3 次 | 应对临时网络波动或格式解析故障，减少人工干预 |

## 容易做错的三处
- 现象：本地部署的工作流配置界面，节点多时页面输入文字出现卡顿。原因：未对界面节点进行分页渲染配置，大量DOM节点同时加载占用主线程资源。
- 现象：代码节点执行时返回axioserror报错。原因：未在`variables`中配置合规的接口请求地址与超时阈值，导致请求无法正常完成。
- 现象：调用指定工作流时返回参数校验失败。原因：工作流ID未使用24位十六进制字符，不符合FastGPT的接口参数格式要求。

## 怎么确认配好了
- 手动触发一个小型测试工作流，检查是否能正常拉取美术资产库的测试数据并完成格式校验。
- 查看工作流的日志面板，确认`nodeId`绑定的节点均正常执行，无报错信息。
- 调用工作流接口时，传入符合24位十六进制格式的工作流ID与有效API密钥，确认接口返回正常结果。
- 调整批量处理上限为500个资源文件，测试批量交付包的校验流程是否正常运行。
