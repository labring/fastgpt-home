# 美术资产生产管理的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
该品类的数据主要来自美术资产库、项目管理系统、引擎资源包与外包交付包。日常关联文档包含美术需求单、资产规格表、外包反馈表与验收记录，字段涵盖资产唯一标识、分辨率、三角面数、交付周期、验收状态等。数据更新频率以日或周为单位，单次更新量随项目阶段波动，核心数据围绕美术资源的交付标准与质量校验展开。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于数据分散在多个系统与交付包中，工具调用需适配多源数据接入插件，确保能拉取统一格式的资产规格与验收记录。日常关联文档的字段存在差异，工具调用的参数需匹配不同文档的字段映射规则，避免校验失败。外包交付包的文件结构不固定，插件需支持自定义解析规则以适配不同外包方的交付格式。同时，高频次的日/周更新要求工具调用具备实时触发能力，适配项目进度变化。本页面内容基于FastGPT v4.17.0版本的官方文档编写。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配美术资产测试用例的自动生成需求，无需手动指定工具类型 |
| `functionCall` | 开启参数强制校验 | 确保工具调用时必传资产ID、规格参数等核心字段，避免无效调用 |
| 工具调用前用户确认 | 绑定资产规格校验节点 | 避免在参数不符合美术资产标准时触发插件执行 |
| 插件超时阈值 | `300 秒` | 适配美术资产包解析、引擎资源检查的常规耗时，避免提前终止流程 |
| 单次工具调用触发频率 | `每 10 分钟` | 适配美术资产生产的日常更新节奏，避免过于频繁的调用占用资源 |
| 上下文窗口长度 | `800–1200 字符` | 适配美术需求单、资产规格表的常规字段长度，避免截断关键校验信息 |

## 容易做错的三处
- 工具调用后中间步骤的AI回复无法隐藏，原因是未正确配置工具调用的结果展示规则，误将中间执行结果设为强制展示。
- 插件执行时提示核心参数缺失，原因是未开启`functionCall`的强制参数校验，导致未传递资产ID、规格参数等必填字段。
- 工具调用频繁出现超时报错，原因是将插件超时阈值设置为低于实际耗时的数值，未适配美术资产包解析的常规运行时长。

## 怎么确认配好了
- 启动FastGPT服务，检查服务端日志无AI Proxy相关的启动校验失败报错，确认`AIPROXY_API_ENDPOINT`（AI Proxy服务的根地址，不得附加/v1等路径，非单模型地址）与`AIPROXY_API_TOKEN`（AI Proxy管理员Token，与服务端配置一致且非空）已按官方要求配置。
- 新建美术资产测试用例工作流，触发工具调用，查看是否按照配置的`toolChoice`自动调用对应工具，或按照`functionCall`规则完成参数校验。
- 模拟不符合资产规格的参数调用工具，确认是否触发预设的校验拦截或用户确认流程。
- 等待插件执行完成，检查执行时长是否在配置的超时阈值范围内，未出现提前终止的情况。
