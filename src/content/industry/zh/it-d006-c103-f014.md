# 美术资产生产管理的测试用例与缺陷分析：模型接入与配置

## 这个品类的数据长什么样
美术资产生产管理的典型参与主体包括美术PM、原画师、3D美术与外包管理人员，日常产生的文档包含美术需求单、资产规格表、外包反馈表与验收记录。数据主要来自美术资产库、项目管理系统、引擎资源包及外包交付包，更新频率多为日度或周度。核心字段包括资源ID、版本号、规格参数、外包状态与验收结果，该品类聚焦角色、场景与特效类资源的交付管理，区别于关卡内容制作，最耗时的环节为规格确认、外包返修沟通与引擎导入检查，出错后易引发资源不匹配、性能超标或版本缺素材等问题。

## 这些特征在「模型接入与配置」这一环带来什么约束
美术资产生产管理的多源数据来源，要求模型接入配置需适配不同格式的资产文档与外包反馈数据，需合理设置上下文窗口以容纳多份关联文档。日度或周度的更新节奏，要求`maxContext`的取值需匹配数据更新周期，避免引入过期的无效信息。核心字段的特殊性，要求配置需支持针对资源ID、规格参数等字段的精准提取与校验，同时需平衡模型的严谨性与灵活性，以应对外包返修、引擎导入等不同场景的缺陷分析需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | `7-14 天` | 匹配美术资产数据日/周的更新节奏，避免冗余旧数据干扰缺陷分析 |
| `temperature` | `0.2-0.4` | 美术资产校验需严谨，降低随机生成的模糊判断，提升缺陷识别的准确性 |
| `maxTokens` | `8000-12000 token` | 需处理美术需求单、资产规格、外包反馈等多份文档的拼接，确保完整上下文输入 |
| `quoteMaxToken` | `2000-3000 token` | 优先引用核心的资产规格与验收记录，作为缺陷分析的关键依据 |
| `toolChoice` | `auto` | 自动适配资产校验、外包沟通记录整理等不同任务的工具调用需求 |
| `AIPROXY_API_TOKEN` | 为 AI Proxy 服务端环境变量，需与 AI Proxy 服务端配置一致且不能为空 | 该变量为 AI Proxy 管理员 Token，是 App/Admin 服务端必需的部署配置，不是应用调用凭证或用户维度密钥 |

## 容易做错的三处
- 现象：在FastGPT界面添加模型配置后，无法看到已配置的模型选项，重启服务后仍未恢复。原因：未将模型配置文件放置在FastGPT v4.17.0指定的模型接入目录，或配置文件格式不符合平台校验规则。
- 现象：运行模型测试时返回报错“[] is too short - 'messages'”。原因：未在模型调用配置中填充必要的上下文消息字段，或测试输入为空的消息数组。
- 现象：配置多用户鉴权后，出现跨账号的对话记录共享。原因：未正确隔离不同用户的应用调用凭证，或未配置正确的应用 API 鉴权参数。

## 怎么确认配好了
- 进入FastGPT的模型管理界面，确认已配置的模型出现在可用模型列表中。
- 提交包含美术资产规格字段的测试文本，运行模型测试，确认无“messages”相关的报错信息。
- 验证应用侧的用户鉴权配置，确保不同测试账号的调用凭证隔离有效，对话记录不会在账号间共享。
- 查看模型调用日志，确认`maxContext`、`temperature`等配置参数的取值与预设配置一致。
