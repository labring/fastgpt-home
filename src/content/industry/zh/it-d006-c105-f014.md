# 许可证合规与版权声明的测试用例与缺陷分析：模型接入与配置

## 这个品类的数据长什么样
本品类的数据主要来自代码仓库、依赖清单、许可证文本与贡献记录。日常维护的文档包含LICENSE文件、NOTICE文件、依赖许可证清单与版权声明。数据更新频率为每版本发布或每次依赖项变更时更新。文档字段包含许可证类型、版权持有者名称、依赖项名称、版本号与授权范围，无额外统计类字段，仅用于合规校验与版权声明生成。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散在代码仓库与依赖清单中，模型接入时需要配置跨多数据源的拉取权限与路径。更新频率随版本与依赖变更，模型需支持增量同步，避免重复处理旧数据，提升处理效率。文档结构固定为四类文件，模型需要识别不同文件的字段规则，比如LICENSE文件需提取授权条款，NOTICE文件需整理版权声明内容。字段无额外统计维度，模型处理时无需额外聚合统计，只需按字段匹配合规规则。

以下配置适用于FastGPT v4.17.0版本。
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | AI Proxy服务的根地址，例如http://aiproxy:3000，不得附加/v1或/chat/completions路径，不得指向VLLM/Ollama/Xinference等单模型服务地址 | 为App/Admin服务端必需的环境变量，用于对接AI Proxy服务 |
| `AIPROXY_API_TOKEN` | AI Proxy服务的管理员Token，需与AI Proxy服务端配置的Token一致且不能为空 | 为App/Admin服务端必需的环境变量，用于AI Proxy服务鉴权 |
| `maxContext` | 8000–12000 token | 适配多文档拼接后的上下文长度，避免截断关键合规条款 |
| `maxTokens` | 4000 token | 限制单次模型输出的长度，确保合规结论简洁明确 |
| `temperature` | 0.1–0.3 | 保持合规判断的一致性，避免生成模糊的合规结论 |
| `quoteMaxToken` | 2000 token | 限制引用的许可证文本长度，确保输出引用内容清晰 |

## 容易做错的三处
- 排查项：检查`maxContext`参数取值是否适配当前处理的多文档拼接后的上下文长度
- 排查项：检查模型渠道配置是否正确，确保可正常获取贡献记录相关数据
- 排查项：检查`AIPROXY_API_ENDPOINT`是否为AI Proxy服务的正确根地址，未附加/v1或/chat/completions等额外路径

## 怎么确认配好了
- 检查App/Admin服务端启动日志，确认无AIPROXY_API_ENDPOINT或AIPROXY_API_TOKEN相关的启动校验失败提示
- 上传单份LICENSE文件与NOTICE文件，核对模型输出的合规结论与文件内容一致。
- 触发一次增量同步任务，确认仅最近更新的依赖项被重新处理。
- 调整`temperature`参数至0.2，验证输出的合规结论与之前的结果保持一致。
