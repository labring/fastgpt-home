# 质保期缺陷响应的测试用例与缺陷分析：表单与交互

本文档适用于FastGPT v4.17.0版本，针对质保期缺陷响应的测试用例与缺陷分析中的表单与交互环节进行说明。

## 这个品类的数据长什么样
这个品类的数据来自客户提交的质保工单、系统运行日志、合同约定的质保条款、软件版本发布记录。日常产出的文档包括质保工单、缺陷确认单、修复记录、客户确认单，字段包含工单编号、缺陷发生场景、责任边界判定结果、修复方案、客户确认状态。数据更新频率为每日或随每单流转，无固定统计口径，仅按实际业务流转更新。

## 这些特征在「表单与交互」这一环带来什么约束
这些特征带来的约束：数据来源分散，需要表单支持接收外部系统/后续节点传递的多源字段数据，或支持手动录入，减少手动录入误差。数据更新随单流转，需要表单支持提交时校验必填字段完整性，避免责任边界判定、修复方案的字段未完成时无法提交。日常文档包含多类单据，需要表单支持接收外部业务系统传递的关联文档字段数据，由外部逻辑限定可受理的缺陷范围。最耗时的环节需通过外部工作流分支配置实现责任方选择、客户确认的分步提交，确保流程可追溯。责任方选择、客户确认的业务逻辑由外部系统另行实现，FastGPT表单节点仅负责收集输入信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 表单输入节点 `formInput` | 测试示例：从质保期缺陷响应字段中选 3 个作为必填输入，实际字段按任务确定 | 该节点收集用户输入；缺必填项时需排查交互状态，避免后续节点无法获得完整输入 |
| 用户选择节点 `userSelect` | 测试示例：设置 2 个业务选项，逐项检查对应分支 | 该节点处理用户选择；质保期缺陷响应相关记录的查询、筛选需由后续接口或外部系统实现 |
| 提交后字段传递 | 测试示例：准备 10 条质保期缺陷响应输入样本，覆盖完整填写、缺必填项和取消操作 | 对照输入与节点输出，核对后续节点是否收到对应字段；结果阈值按实际任务确定 |
| 外部实施项：表单提交校验 | 需由外部系统另行实现；触发时机设为必填字段全部完成 | 确保流程不遗漏关键环节 |
| 外部实施项：超时自动保存 | 需由外部系统另行实现；由外部会话管理系统实现，建议取300秒作为待实测起点 | 避免长时间未操作丢失录入内容 |
| 外部实施项：客户确认单选框 | 需由外部系统另行实现；可选值由外部系统提供，节点等待用户选择 | 匹配客户确认单的字段要求 |

## 容易做错的三处
- 现象：工作流中表单节点无法被其他分支调用，触发后无法跳转至该节点。核对动作：检查工作流分支配置是否正确关联表单节点，确认节点发布状态为已启用。
- 现象：配置外部输入引导逻辑并指定外部词库地址后，调试预览时出现格式报错。核对动作：检查外部词库地址是否可正常访问，确认词库文件格式符合外部系统要求。
- 现象：引用质保工单的关联字段时出现quote type error报错。核对动作：检查变量引用格式是否符合FastGPT官方文档要求，确认参数类型与目标字段匹配。

## 怎么确认配好了
- 执行单条质保工单的流程测试，录入对应字段，确认表单可正常提交。
- 调用已配置的其他工作流分支，确认可跳转至该表单节点，验证分支关联正常。
- 配置外部输入引导逻辑，在调试预览中输入内容，确认无格式报错。
- 引用合同质保条款的关联变量，确认无quote type error报错，验证变量引用正常。
