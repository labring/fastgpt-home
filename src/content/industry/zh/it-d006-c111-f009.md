# 配置管理与CMDB维护的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
本品类的数据围绕IT服务组件的配置与关联关系生成，日常维护文档包括配置项清单、服务组件关系拓扑、变更记录、资产盘点表。数据来源包括企业自有CMDB系统、云资源清单、自动化资产发现工具、采购台账。数据更新频率为每日或每周，核心字段包含配置项唯一标识、组件类型、依赖关系、变更时间戳，无统一量化单位，字段随资产类别调整。日常工作中，配置项采集、跨组件关系核对、变更后同步更新为最耗时环节，数据偏差会直接影响故障定位与影响范围分析，与通用IT资产盘点的核心差异在于关注服务组件间的依赖关系。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于数据来源分散且更新节奏不同，工具调用需适配多源数据拉取的时序要求，需明确指定不同数据源的拉取周期。配置项与关系拓扑的字段结构复杂且随资产类别调整，工具调用需预设字段映射规则，避免因字段名不匹配导致数据解析失败。变更记录的实时性要求较高，批量执行工具需支持按变更时间戳筛选待处理条目。同时，数据偏差会直接影响分析结果，工具调用需内置校验逻辑，对账实不符的配置项标记异常。相较于通用IT资产盘点场景，本品类需额外处理服务组件间的依赖关系，插件需支持拓扑关系的递归拉取与验证。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配多源数据拉取的动态调用需求，无需手动指定固定工具 |
| 批量执行并发数 | `2–4 个` | 适配CMDB与云资源接口的调用限制，避免触发限流 |
| 参数优先级规则 | 先取工作流变量，再取插件默认值 | 匹配运维场景中动态配置的更新需求，支持临时调整参数 |
| 数据校验开关 | 开启 | 避免账实不符的配置项进入后续分析流程，降低出错风险 |
| 超时设置 | `600 秒` | 适配多源数据拉取的耗时需求，避免因单次调用过长导致工作流中断 |
| `functionCall` | 开启批量模式 | 支持同时拉取多个配置项的关联数据，提升处理效率 |

## 容易做错的三处
- 工作流调用CMDB数据拉取工具时返回参数不匹配报错，表现为接口返回字段为空或格式错误，原因是未按配置项清单的字段名映射工具入参，导致解析失败。
- 插件未按预设优先级获取参数值，表现为未读取到指定工作流变量时未自动使用默认值，直接抛出参数缺失错误，原因是未开启参数优先级校验配置。
- 批量执行工具返回的结果条数与预期不符，表现为结果条数少于或多于待处理条目数，原因是未设置正确的变更时间戳筛选条件，导致拉取了超出范围的历史数据。

## 怎么确认配好了
- 触发一次单条配置项的工具调用，查看返回结果的字段是否与配置项清单的字段完全匹配。
- 手动删除已配置的工作流变量，确认插件是否自动使用预设的默认参数值，未抛出参数缺失错误。
- 提交批量执行任务，查看任务日志中是否标记了账实不符的配置项异常，未出现异常报错。
- 等待超过`600 秒`的超时设置时长后，确认工作流未因调用超时中断，且返回了完整的数据集。
