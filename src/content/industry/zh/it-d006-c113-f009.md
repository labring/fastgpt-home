# 集成测试与接口测试的测试用例与缺陷分析：工具调用与插件

## 这个品类的数据长什么样
本品类的数据主要来自接口管理平台、测试环境日志、数据库与消息队列，更新频率为每日或每版本发布后。日常文档包含接口测试用例、联调问题单、环境说明与测试报告，其中接口测试用例包含接口地址、请求参数、预期响应字段；联调问题单记录请求状态码、报错堆栈与链路ID；测试报告随单条用例的执行结果同步更新。数据结构固定，字段包含请求标识、响应结果、环境标识等，用于跨模块交互的验证与缺陷定位。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类的数据多源且更新节奏明确，要求工具调用插件需适配多数据源的拉取权限配置，确保能同时访问接口管理平台与测试日志数据。数据结构固定且包含链路标识，插件需支持按接口请求ID匹配对应日志与问题单，避免跨用例的无效关联。高频更新的特性要求插件支持增量同步，减少全量拉取带来的资源消耗。同时，面向测试工程师与团队的使用场景，插件需支持批量用例的工具调用，适配日常的批量测试与缺陷排查工作。FastGPT v4.17.0的插件框架需针对这些约束调整数据源配置与调用逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` 或 指定缺陷分析工具名 | 适配集成测试中多工具调用的场景，支持自动选择或固定调用用于缺陷定位的工具 |
| `functionCall` | `enabled` | 启用函数调用以解析接口测试用例中的参数与响应数据，实现自动化缺陷匹配 |
| 插件数据源路径 | 按接口管理平台、测试日志的实际部署路径配置 | 匹配本品类的数据来源，确保插件拉取正确的测试数据 |
| 定时拉取间隔 | `1 天` 或 每版本发布后触发 | 适配本品类数据的日/版本级更新频率，避免无效拉取 |
| 缺陷匹配结果上限 | `前 3 条` | 定位联调问题单中的常见链路错误，过滤不相关的日志数据 |
| 外部工具代理 | 按国内访问环境配置代理参数 | 适配国内使用场景，解决外部工具访问受限的问题 |

## 容易做错的三处
- 调用`toolChoice`时返回未授权错误，原因是未配置测试环境的接口平台鉴权参数，导致插件无法访问数据源。
- 插件返回的缺陷结果条数超出预期，原因是未设置合理的匹配结果上限，拉取了过多不相关的测试日志。
- 无法调用指定的外部搜索工具，原因是未配置适配国内环境的代理参数，导致工具访问失败。

## 怎么确认配好了
- 执行单条接口测试用例，查看插件是否自动拉取对应环境的测试日志与问题单数据。
- 检查`toolChoice`参数的配置是否匹配当前使用的工具类型，确认工具调用流程正常。
- 触发一次定时拉取任务，查看是否按配置的间隔同步了最新的测试数据。
- 模拟联调报错场景，确认插件是否能定位到对应的缺陷日志与问题单。
