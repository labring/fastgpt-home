# 项目实施计划管理的测试用例与缺陷分析：模型接入与配置

## 这个品类的数据长什么样
该品类的数据通常由项目经理、实施经理及PMO维护，日常文档包含项目计划、里程碑清单、周报、风险问题清单。数据来源包括合同、工作分解结构（WBS）、客户日程及企业项目管理系统。数据更新节奏为每周或每完成一个里程碑时同步，文档字段包含任务标识、责任人、截止时间、进度占比、风险等级及应对措施等，无固定统一格式但核心围绕项目进度与风险展开。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据分散于多个独立系统，模型接入需适配多源异构数据的格式兼容要求。固定的周/里程碑更新节奏，要求配置匹配更新周期的上下文同步参数。文档结构无统一规范，不同文档的内容长度差异较大，需调整上下文长度参数以完整承载有效信息。风险问题清单的动态变化，要求模型生成结果保持稳定的逻辑一致性，避免因参数波动导致分析结果偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配项目计划、风险清单等多文档的总长度，避免因上下文溢出丢失关键项目信息 |
| `maxTokens` | 2000–3000 token | 满足测试用例拆解、缺陷分析的输出长度需求，避免生成结果截断 |
| `temperature` | 0.3–0.5 | 控制风险问题分析的稳定性，适配项目进度跟踪的严谨性要求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写，为AI Proxy服务的根地址，例如http://aiproxy:3000，不要附加/v1或/chat/completions等路径，不是单模型地址 | 确保App/Admin服务能正确连接AI Proxy服务，该变量为App/Admin服务端环境变量，不得在工作流全局变量、应用API请求头或普通模型管理页面配置 |
| `AIPROXY_API_TOKEN` | 与AI Proxy服务端配置一致的管理员Token，不能为空 | 完成App/Admin服务与AI Proxy服务的身份验证，确保访问权限合规，该变量为App/Admin服务端环境变量，不得在工作流全局变量、应用API请求头或普通模型管理页面配置 |
| `toolChoice` | auto | 允许模型自动选择是否调用工具处理测试用例与缺陷数据，适配动态分析需求 |

## 容易做错的三处
- 调用模型时返回403状态码，提示令牌无权使用模型。可验证排查项：检查App/Admin服务是否已正确配置AIPROXY_API_ENDPOINT和AIPROXY_API_TOKEN环境变量；检查AIPROXY_API_ENDPOINT是否为AI Proxy服务的根地址，未附加额外路径；检查AIPROXY_API_TOKEN是否与AI Proxy服务端配置的管理员Token一致且非空。
- 模型生成的测试用例拆解结果出现逻辑偏差，且多次运行结果差异较大。可验证排查项：检查`temperature`参数设置是否超出0.3–0.5的建议区间，参数取值是否过高。
- 模型无法完整解析项目计划中的任务信息。可验证排查项：检查`maxContext`参数设置是否小于8000 token的建议区间下限，参数取值是否过小。

## 怎么确认配好了
- 在FastGPT v4.17.0的模型测试页面，输入项目计划的片段文本，验证模型能否正确提取任务责任人与截止时间。
- 提交风险问题清单的样本数据，检查模型生成的分析结果是否符合项目进度跟踪的严谨性要求。
- 验证App/Admin服务是否已正确加载AIPROXY_API_ENDPOINT和AIPROXY_API_TOKEN环境变量，检查服务启动日志是否存在校验通过提示；或通过AI Proxy服务端日志确认存在来自App/Admin服务的合法请求。
- 调整`maxContext`参数为不同区间，测试不同长度的项目文档能否被完整解析。
