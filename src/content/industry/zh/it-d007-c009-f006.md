# 个人信息保护合规的线上故障排查与复盘：定时任务与自动化

## 这个品类的数据长什么样
本品类的数据主要来自业务系统、App权限清单、隐私政策、用户请求记录，更新频率为季度或每产品版本变更时。日常处理的文档包括个人信息清单、处理规则、影响评估报告、用户授权文本，文档结构包含结构化表格与分段文本，字段包含可识别自然人的信息标识、处理场景、合法性依据、存储周期等，无统一固定单位，随文档类型调整。

## 这些特征在「定时任务与自动化」这一环带来什么约束
由于本品类数据更新随产品版本变更触发或按季度执行，定时任务需支持手动触发与变更事件联动的自定义调度，同时兼容固定周期调度以适配季度巡检需求。文档类型多样，自动化处理需适配结构化表格与分段文本的混合输入，需针对个人信息清单的行级数据做精准提取。数据涉及可识别自然人的信息，定时任务的执行权限需严格限定，执行日志需加密留存，避免信息泄露。单次处理的数据量随业务增长逐步提升，需合理规划资源占用，避免处理超时。

## 配置怎么定
本文档基于FastGPT v4.17.0版本的功能编写。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 调度触发方式 | 支持变更事件触发+固定周期双模式，固定周期设为720小时 | 适配季度更新与临时产品变更的调度需求，覆盖常规巡检与紧急合规检查场景 |
| 数据提取粒度 | 按文档类型适配：个人信息清单取每行，处理规则取每段 | 匹配日常文档的结构化与非结构化特征，避免分段混乱 |
| 执行资源阈值 | 单次处理内存上限设为1000 MB，超时时间设为600秒 | 适配合规文档的平均数据量，避免因资源不足导致任务失败 |
| 权限管控范围 | 仅开放给隐私合规团队角色，执行日志加密存储 | 符合个人信息保护的合规要求，避免敏感数据泄露 |
| 异常告警触发 | 任务失败后10分钟内推送告警至指定渠道 | 及时响应故障，避免合规风险扩大 |
| 数据清洗规则 | 过滤空字段与重复的自然人标识条目 | 提升后续处理的准确性，减少无效数据 |

## 容易做错的三处
- 现象：导入多列excel格式的个人信息清单后，自动分段结果混乱，单条自然人信息被拆分至多个分段。原因：未针对结构化表格文档配置按行提取的规则，使用了通用的自动分段逻辑。
- 现象：定时任务执行后，合规数据未同步至知识库，且无明确报错提示。原因：未设置超时时间或阈值设置过高，导致任务执行超时后被强制终止，未返回有效报错信息。
- 现象：本地部署版本的定时任务无法加载配置的隐私政策数据源，提示环境变量未配置。原因：未按要求配置FastGPT的数据源访问环境变量，导致任务无法读取加密的合规文档。

## 怎么确认配好了
- 手动触发一次调度任务，核对任务日志中是否包含所有配置的触发规则与资源阈值。
- 导入一份测试用的个人信息清单文档，核对分段结果是否按预设规则拆分。
- 检查权限配置页面，确认仅隐私合规团队角色可访问该定时任务的执行入口。
- 模拟一次任务超时场景，核对是否在预设时间内收到告警通知。
