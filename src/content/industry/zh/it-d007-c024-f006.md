# 信息流广告创意测试的线上故障排查与复盘：定时任务与自动化

## 这个品类的数据长什么样
通常信息流广告创意测试的相关数据来自广告投放平台、内部素材库、用户互动数据与转化数据，更新节奏以日或周为周期。日常产出的文档包含创意脚本、素材测试表、投放数据报告与迭代清单，字段覆盖创意变量组合、素材疲劳度标记、点击率、转化成本等，不同文档间需关联素材ID与投放计划ID进行匹配。

## 这些特征在「定时任务与自动化」这一环带来什么约束
数据来源分散且需跨文档关联，要求定时任务需同时拉取多类数据源并完成字段匹配。更新周期的日/周特性，要求定时任务的触发频率需与数据更新节奏对齐，避免重复拉取或遗漏周期数据。创意测试的出错后果直接影响投放效果，要求自动化流程需设置明确的异常触发条件与告警规则，同时需适配素材库、投放数据的批量处理耗时。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 定时触发周期 | 1天 / 7天 | 匹配投放数据、素材更新的日/周更新节奏 |
| 数据源拉取范围 | 前7天的广告平台数据 | 覆盖完整测试周期的有效样本量 |
| 失败重试次数 | 3次 | 规避单次网络波动或接口临时异常导致的任务中断 |
| 异常告警阈值 | 点击率下降10%（按实测标定） | 及时识别创意疲劳或素材违规引发的投放异常 |
| 任务执行超时时间 | 1800秒 | 适配多数据源拉取与AI创意识别的整体耗时 |

## 容易做错的三处
- 任务无自动触发，仅能手动启动。原因是未配置FastGPT v4.17.0的定时任务触发器，依赖人工触发流程。
- 图片识别结果未同步到素材测试表。原因是未配置素材自动上传到知识库的触发规则，仅支持手动上传本地文件。
- 任务执行后测试表字段为空。原因是未配置素材ID与投放计划ID的关联规则，导致拉取的数据无法匹配现有测试清单。

## 怎么确认配好了
- 查看FastGPT v4.17.0的任务管理面板，确认目标定时任务状态为已启用。
- 手动触发一次测试任务，检查是否自动拉取指定周期内的广告平台数据与素材库文件。
- 模拟一次临时断网场景，检查是否触发预设的失败重试与告警通知。
- 核对生成的迭代清单，确认自动归纳的测试结论与创意变量字段完整。
