# 关卡内容制作的线上故障排查与复盘：部署与升级

## 这个品类的数据长什么样
该品类的核心数据来自关卡编辑器、美术资源库、玩家测试数据与缺陷系统。日常产出的文档包含关卡设计稿、资源需求表、测试反馈单与版本提交记录，字段涵盖关卡ID、路径节点坐标、道具摆放位置、反馈等级、版本号与修改记录。数据更新以周或单次版本迭代为节奏，单次提交的关卡资源包与测试数据体量随关卡复杂度波动。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据多源且随版本迭代高频更新，部署环节需兼容关卡编辑器、美术资源库等多类数据源的接入，同时需支持版本提交记录与部署版本的绑定关联。单次关卡资源包与测试数据的体量波动，要求部署配置预留足够的存储与带宽余量。高频的版本更新需求，要求升级流程支持快速回滚与增量部署，避免中断关卡编辑与线上测试。此外，测试反馈与缺陷系统的对接需求，需提前配置外部系统的连接参数。

## 配置怎么定
本页面适配FastGPT v4.17.0版本，以下配置项基于该版本的部署规范制定：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `200–300 个连接` | 匹配关卡内容制作团队多源数据并发访问的峰值需求，适配周级版本更新的并发压力 |
| `MONGODB_URI` | `mongodb://username:password@host:port/database?authSource=admin` | 存储关卡设计稿、版本提交记录等非结构化数据，支持多文档类型的灵活存储 |
| `REDIS_URL` | `redis://:password@host:port/0` | 缓存实时关卡编辑状态与测试反馈单，降低核心数据库的并发访问压力 |
| `STORAGE_S3_ENDPOINT` | 按实测标定 | 适配美术资源库的存储路径，匹配关卡资源包的上传与下载带宽需求 |
| `FILE_TOKEN_KEY` | `32位随机字符串` | 保障关卡资源上传接口的访问安全，防止未授权的资源提交 |
| `FE_DOMAIN` | `https://your-custom-domain.com` | 绑定关卡编辑器的前端访问地址，统一前端资源的加载与跳转路径 |

## 容易做错的三处
- 现象：上传大体积关卡资源包或测试数据PDF时，进度接近完成时出现“偏移量超出范围”报错。原因：未正确配置文件上传的分块参数或存储会话有效期，导致大文件上传时分块校验不匹配或会话超时。
- 现象：docker本地部署时无法拉取指定镜像，出现拉取超时或镜像找不到报错。原因：未配置正确的镜像仓库访问地址，或未开通部署环境的外网访问权限。
- 现象：部署完成后后台管理界面未显示【文本加工】模块，无法配置关卡内容的文本清洗或格式化规则。原因：未在启动参数中加载对应插件，或未使用正确的`ROOT_KEY`权限登录后台导致功能隐藏。

## 怎么确认配好了
- 执行镜像拉取测试，验证配置的镜像仓库地址可正常访问并拉取所需镜像。
- 上传小体积测试文件，确认文件上传流程无报错，资源可正常存入配置的存储路径。
- 使用`ROOT_KEY`权限登录后台，确认【文本加工】模块已在功能列表中显示。
- 查看实时监控日志，确认数据库与缓存服务的连接状态正常，无异常断开。
