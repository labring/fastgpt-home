# 创作者入驻与认证的线上故障排查与复盘：部署与升级

## 这个品类的数据长什么样
创作者入驻与认证环节的数据主要来自创作者后台、企业信用信息系统、账号历史库与合同管理系统。日常处理的文档包含入驻申请表单、身份资质扫描件、认证审核记录、合作协议等。数据更新频率为每日或随每一笔申请触发，字段涵盖身份标识、资质编号、审核状态、合同条款等，无统一固定的统计口径，仅按申请流程流转。

## 这些特征在「部署与升级」这一环带来什么约束
FastGPT v4.17.0版本起，该品类的数据来源分散且更新实时性要求高，需保障多系统间的稳定连接，因此部署时需合理配置数据库与缓存的连接参数。文档结构包含非结构化的资质文件与结构化的审核记录，对存储服务的兼容性与读写性能有明确要求。由于出错后果直接关联账号准入可信度，部署与升级环节需严格校验必填配置项，避免因参数缺失导致流程中断。同时，需确保AI Proxy相关配置与模型渠道配置分离，防止混淆鉴权信息引发安全风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `MONGODB_URI` | `mongodb://username:password@host:27017/fastgpt?authSource=admin` | 存储创作者资质、审核记录等结构化业务数据，需正确配置认证信息与目标数据库 |
| `REDIS_URL` | `redis://:redispassword@host:6379/0` | 缓存账号风险判断结果、会话临时数据，保障高频申请场景下的响应速度 |
| `DB_MAX_LINK` | `50–100 个连接` | 匹配创作者入驻申请的并发处理规模，避免连接池耗尽导致服务中断 |
| `STORAGE_S3_ENDPOINT` | 按实际存储服务商地址填写，例如 `https://oss-cn-beijing.aliyuncs.com` | 存储创作者上传的资质文件等非结构化数据，需匹配存储服务的访问端点 |
| `FILE_TOKEN_KEY` | 随机生成的32位以上字符串 | 签署文件上传的鉴权凭证，防止未授权用户访问敏感资质材料 |
| `ROOT_KEY` | 强随机生成的64位字符串 | 管理后台最高权限操作的鉴权密钥，保障配置修改的安全性 |

## 容易做错的三处
- 现象：FastGPT服务启动时抛出校验失败报错，提示缺少`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`。原因：未在App/Admin服务端配置这两个必填环境变量，其中`AIPROXY_API_ENDPOINT`为AI Proxy服务的根地址，`AIPROXY_API_TOKEN`为AI Proxy管理员Token，或误将二者填入模型管理页面、工作流全局变量或应用API请求头中替代服务部署配置。
- 现象：上传创作者资质文件时返回存储连接超时错误。原因：`STORAGE_S3_ENDPOINT`配置错误，或未正确配置存储服务的访问密钥与权限。
- 现象：服务器出现读写资源耗尽，每日固定时段出现卡顿。原因：`DB_MAX_LINK`设置值过小，未匹配创作者入驻申请的并发峰值，导致数据库连接池耗尽。

## 怎么确认配好了
- 启动FastGPT的App/Admin服务，查看启动日志，确认无数据库、存储服务、AI Proxy相关的启动失败报错。
- 调用创作者入驻相关的测试接口，提交模拟申请，确认文件上传、资质核验流程可正常完成并生成审核记录。
- 查看Redis与MongoDB的监控指标，确认连接数稳定在配置范围内，无频繁断开重连或连接溢出情况。
- 登录管理后台，使用`ROOT_KEY`对应的权限执行配置修改操作，确认操作可正常生效。
