# 售前技术方案的线上故障排查与复盘：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据主要来自客户访谈、招标文件、厂商产品资料与历史项目方案，更新节奏为每单或每周。日常产出的文档包含技术方案书、客户需求调研表、报价清单与演示脚本，文档结构通常以需求澄清项、技术路线、实施边界、成本核算为核心模块，字段涵盖接口调用范围、权限配置要求、批量执行节点设计等，无统一固定的单位标准，需结合具体客户场景调整。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
由于该品类的数据来源分散且更新频率较高，HTTP接口需要支持动态调整`variables`参数以适配不同客户的需求边界。文档中包含的权限配置要求，要求接口需通过`Authorization`字段校验调用合法性。同时，因单份方案需匹配特定客户的实际场景，批量执行节点的配置需预留灵活调整空间，避免因固定参数导致方案与实际需求不符。另外，方案需留存完整调用日志用于复盘，接口的`responseData`需完整记录返回结果与错误信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| Basic Auth 账号密码配置 | 从客户需求调研表提取对应凭据，按实测标定 | 该品类数据来自客户需求调研表，需匹配客户提供的接口访问权限 |
| 获取对话记录列表接口偏移量 | 取值区间为0至1000条 | 适配客户需求的分页起始位置，符合售前方案的查询范围要求 |
| 批量执行节点循环次数 | 取值区间为1至500次 | 匹配客户的实际业务规模，避免超出接口调用限额 |
| HTTP接口调用超时时间 | 取值区间为300至900秒 | 适配客户的业务响应要求，避免超时导致方案无法落地 |
| `Authorization` 字段配置 | 绑定方案对应的客户权限标识，取值为`Basic {base64编码的账号密码}` | 需通过接口校验合法调用，符合售前方案的权限边界要求 |
| `responseData` 日志存储 | 保留完整返回结果与错误信息，存储时长为7天 | 该品类数据更新频率为每周，需留存日志用于方案复盘与需求澄清 |

## 容易做错的三处
- 现象：调用获取对话记录列表接口后，返回结果中无法区分用户提问与对应AI回复，部分关联字段为空。原因：未按照售前技术方案中约定的字段映射规则配置`responseData`提取逻辑，导致数据关联关系丢失。
- 现象：在FastGPT v4.17.0中配置批量执行节点循环调用大模型，在线调试可完整执行流程，但通过API调用时仅完成部分循环任务。原因：未调整`variables`中的批量任务并发参数，API调用的并发限制与在线调试环境不一致，导致任务提前终止。
- 现象：配置Basic Auth的HTTP模块后，接口调用返回401未授权错误。原因：未从客户需求调研表提取正确的账号密码，直接使用通用凭据，未匹配客户提供的接口访问权限。

## 怎么确认配好了
- 调用获取对话记录列表接口，检查返回结果中是否包含用户提问与AI回复的关联字段，关联关系是否与售前技术方案中的约定一致。
- 查看`Authorization`字段的配置是否与客户提供的权限凭据匹配，可通过接口调试工具发起单次调用验证合法性。
- 配置批量执行节点后，通过API调用发起与客户业务规模匹配的测试任务，检查任务执行是否完整，无中途中断情况。
- 查看`responseData`日志是否完整记录了接口调用的返回结果与错误信息，符合方案中要求的复盘留存标准。
