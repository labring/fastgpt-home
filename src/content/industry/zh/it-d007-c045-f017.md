# 安全培训与钓鱼演练的线上故障排查与复盘：部署与升级

## 这个品类的数据长什么样
该品类的日常文档包含培训课件、演练方案、钓鱼邮件模板、演练结果报告，数据来源通常为员工通讯录、邮件网关、培训平台与点击统计数据，更新频率多为季度或年度。最耗时的环节集中在演练人群筛选、邮件模板设计与结果复盘，一旦出错可能引发员工泄密风险、审计缺项或整改无证据。与安全基线检查类服务不同，该品类聚焦人员安全意识与行为的培训演练。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据来源包含员工通讯录、邮件网关等企业内部系统，部署时需适配不同的身份鉴权与数据同步规则，避免权限泄露。演练结果报告与模板的存储需匹配企业现有文档管理的合规要求，升级时需保证历史数据的兼容性。人群筛选与复盘环节依赖精准的字段匹配，部署阶段需提前配置对应的数据映射规则，避免后续演练数据错位。季度或年度的更新节奏要求部署后的升级流程轻量化，减少业务中断时间。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MONGODB_URI` | 私有网络内专属集群连接串，配置访问白名单 | 存储演练模板、报告等敏感业务数据，符合FastGPT v4.17.0版本的敏感数据存储规范 |
| `REDIS_URL` | 单实例内存不低于 2048 MB 的专属缓存服务 | 缓存演练人群筛选的临时数据与点击统计结果，降低数据库压力 |
| `FILE_TOKEN_KEY` | 随机生成的 32 位以上字符串 | 加密钓鱼邮件模板与演练报告的访问令牌，防止未授权下载 |
| `STORAGE_S3_ENDPOINT` | 企业自有对象存储服务的接入地址 | 适配企业现有文档存储合规要求，统一数据管理路径 |
| `DB_MAX_LINK` | 100–200 条连接数 | 平衡演练数据查询的并发需求与数据库资源占用 |
| `FE_DOMAIN` | 企业内部域名或专属二级域名 | 隔离外部访问，保证培训演练平台的内部使用属性 |

## 容易做错的三处
- 升级版本后点击演练报告详情显示`Invalid dataset file key`报错，原因是升级过程中未同步更新`FILE_TOKEN_KEY`的配置值，导致原有文件令牌校验失败。
- 部署社区版时出现数据库连接超时，原因是未配置`DB_MAX_LINK`的合理取值，并发请求超出数据库连接上限。
- 未正确配置非商业版API密钥的时长与使用次数限制，原因是未在对应配置项中启用校验规则，导致密钥滥用风险。

## 怎么确认配好了
- 执行自带的数据库连通性测试脚本，验证`MONGODB_URI`与`REDIS_URL`的连通性，确认无访问权限或连接超时问题。
- 上传一份测试钓鱼邮件模板，通过`FILE_TOKEN_KEY`生成访问链接，验证链接可正常打开且无未授权访问异常。
- 查看前端页面加载状态，确认`FE_DOMAIN`配置与实际访问地址一致，无跨域或域名解析错误。
- 模拟一次小型演练人群筛选操作，验证数据映射规则生效，筛选结果与员工通讯录数据匹配。
