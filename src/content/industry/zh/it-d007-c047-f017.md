# 安全漏洞披露处理的线上故障排查与复盘：部署与升级

## 这个品类的数据长什么样
本品类的数据来自私密漏洞报告、代码仓库、CVE编号机构及官方发布渠道，更新节奏为单次漏洞事件触发一次。核心文档包含安全公告、漏洞报告、修复补丁与CVE申请材料，字段涵盖漏洞编号、影响范围、修复版本、披露时间、受影响组件等，无固定批量更新周期，仅随漏洞发现与处置流程推进更新。

## 这些特征在「部署与升级」这一环带来什么约束
本品类的数据随单次漏洞事件生成，包含私密漏洞报告与公开安全文档的混合内容，部署环节需隔离敏感漏洞信息与公开访问资源，防止未授权访问。因更新仅随漏洞处置流程触发，升级过程需保障漏洞响应流程不中断，且需兼容不同版本的补丁文档解析逻辑。同时，数据来源涉及多类外部机构接口，部署时需配置稳定的外部访问权限，避免因接口波动导致漏洞信息同步失败。

## 配置怎么定
以下配置项适用于FastGPT v4.17.0版本，需严格遵循官方环境变量规范：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MONGODB_URI` | `mongodb://user:pass@host:27017/fastgpt?replicaSet=rs0` | 本品类需存储漏洞报告、补丁元数据等结构化数据，副本集配置保障数据持久化与高可用 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 用于缓存漏洞公告、临时会话数据，单库配置满足轻量缓存需求 |
| `DB_MAX_LINK` | `200 个` | 本品类数据访问随漏洞事件波动，200个连接可平衡资源占用与并发响应能力 |
| `STORAGE_S3_ENDPOINT` | 按对象存储服务商提供的根地址填写 | 用于存储补丁文件、漏洞报告附件等非结构化数据，需匹配存储服务的访问端点 |
| `ROOT_KEY` | `32 位随机字符串` | 用于生成敏感操作的鉴权令牌，保障漏洞处置后台的访问安全 |
| AI Proxy 服务根地址 | `http://aiproxy:3000` | 官方要求为AI Proxy服务的根地址，不可附加路径后缀，保障服务正常调用 |
| AI Proxy 管理员 Token | `32 位随机字符串` | 需与AI Proxy服务端配置一致，不能为空，用于服务端鉴权 |

## 容易做错的三处
- 现象为MongoDB启动校验失败，提示副本集未配置，原因是未按要求在`MONGODB_URI`中添加副本集参数，导致数据存储校验不通过。
- 现象为知识库训练后数据处理为空，原因是未正确配置`DB_MAX_LINK`的连接数，导致数据库连接耗尽无法写入训练数据。
- 现象为容器化部署后向量索引结果异常，所有得分一致，原因是未正确配置`REDIS_URL`的连接参数，导致向量检索的中间缓存被错误覆盖。

## 怎么确认配好了
- 启动FastGPT服务端，检查启动日志是否无必填环境变量缺失的报错提示。
- 上传测试用的补丁文件，验证存储服务可正常完成文件写入与读取。
- 提交一条模拟漏洞报告，确认数据可正常写入数据库并可被查询。
- 查看服务连接状态，确认Redis、MongoDB的连接无超时或拒绝报错。
