# 安全监控与SOC值守的线上故障排查与复盘：数据库与运维

## 这个品类的数据长什么样
本品类的数据主要来自SIEM、EDR、NDR及外部威胁情报源，更新节奏分为实时告警推送与日度情报同步两类。日常产出的文档包含告警处置单、值班记录、威胁情报通报、日报周报，数据字段涵盖告警唯一标识、源IP地址、威胁类型、研判结果、处置状态、派单时间等，无自定义聚合统计字段，单条数据体量较小但单日数据量随告警触发频次波动。

## 这些特征在「数据库与运维」这一环带来什么约束
实时告警的高频写入要求数据库连接池支持高并发短连接复用，避免连接耗尽；日度情报同步的批量写入需要配置批量提交阈值，防止单次写入超时。多类异构数据源的接入要求数据库支持灵活的字段扩展，无需频繁修改表结构适配不同格式的告警与情报数据。告警处置单等文档的全生命周期留存需要配置数据归档策略，区分热数据与冷数据存储，同时保障历史数据可快速检索。实时研判的低延迟需求要求数据库配置读写分离节点，避免主库读写压力过载影响告警响应速度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://soc-admin:secure123@mongo-host:27017/soc_db?authSource=admin` | 适配docker部署的MongoDB实例，支持账号密码与认证源配置，兼容FastGPT v4.17.0的数据库连接逻辑 |
| `PG_URL` | `postgresql://soc-user:pass456@pg-host:5432/soc_ops?sslmode=require` | 保障数据库连接的加密传输，适配安全场景下的数据合规存储要求 |
| `DB_MAX_LINK` | `60–100 个` | 匹配SOC值守场景下的实时告警并发写入需求，避免连接池耗尽导致的告警丢失 |
| `REDIS_URL` | `redis://:redis-pass@redis-host:6379/1` | 缓存高频查询的告警研判规则与值班记录，降低主数据库的读写压力 |
| 批量写入阈值 | `150–250 条/次` | 适配日度威胁情报同步的批量写入场景，平衡单次写入效率与超时风险 |

## 容易做错的三处
- 现象：执行版本升级后无法登录平台，返回`500 Internal Server Error`。原因：修改MongoDB配置文件时误调整了`MONGODB_URI`的认证源或连接地址参数，导致数据库连接验证失败。
- 现象：批量导入日度威胁情报时出现写入超时错误。原因：未配置合理的批量写入阈值，单次写入数据量超过数据库的承载上限。
- 现象：实时告警出现大量重复推送记录。原因：未配置Redis缓存告警去重规则，导致重复的告警请求反复写入数据库，造成数据冗余。

## 怎么确认配好了
- 执行`mongo --uri $MONGODB_URI`命令，验证MongoDB数据库连接是否正常，根据连接结果调整配置参数。
- 提交测试告警数据，查看数据库写入日志，确认数据是否按预期格式存储到对应库表中。
- 查看Redis服务连接状态，确认缓存服务是否正常响应，验证告警去重规则是否生效。
- 模拟日度批量情报导入操作，检查写入耗时是否符合业务预期，按需调整批量写入阈值。
