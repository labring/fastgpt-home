# 客户培训与使用手册的线上故障排查与复盘：对话日志与审计

## 这个品类的数据长什么样
该品类的数据通常来自产品帮助中心、客户组织架构、培训录屏与工单系统，更新节奏为每单或每版本更新。日常文档包含培训课件、用户手册、培训签到表与问题答疑清单，数据字段涵盖培训主题、参与人员ID、操作步骤截图、工单反馈编号、答疑记录时间戳，单位多为人次、分钟、字符数，文档结构按培训批次与客户分组归档。该品类关注首轮使用能力建立，与续费健康度管理类品类的核心差异在于聚焦首次使用的操作指导与问题解答。

## 这些特征在「对话日志与审计」这一环带来什么约束
该品类的数据特征对对话日志与审计环节带来多重约束。数据来源分散覆盖产品帮助中心、培训录屏、工单系统，要求审计工具需对接多入口采集完整交互数据；更新频率为每单或每版本，需支持按培训批次、客户版本关联日志；文档按培训分组归档，要求日志按角色、操作步骤分类存储；字段包含答疑记录与权限讲解内容，需保留完整交互链路，覆盖角色权限讲解、操作步骤演示等最耗时环节的操作痕迹，避免遗漏导致课后问题整理困难与后续工单激增。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `chatId` | 绑定培训批次关联的会话ID | 该品类数据按培训批次归档，`chatId`可关联单批次内的所有用户交互日志，便于按批次审计 |
| `responseChatItemId` | 关联用户提问与客服响应的唯一ID | 需完整记录答疑环节的提问与响应链路，`responseChatItemId`可精准定位单条交互的完整流程 |
| `detail` | `true` | 该品类需保留操作步骤演示、权限讲解的完整细节，全量日志可覆盖角色权限讲解环节的操作痕迹 |
| 日志存储周期 | 180–365 天 | 培训数据需保留至下一个版本更新，满足后续复盘与工单追溯需求 |
| 审计筛选维度 | 按角色、培训批次、操作步骤分类 | 该品类文档按培训分组归档，按维度筛选可快速定位课后问题整理的异常点 |
| 实时同步开关 | 开启，按实测标定 | 更新频率为每单或每版本，实时同步可确保最新培训数据与日志关联 |

## 容易做错的三处
- 现象：会话界面显示图片上传成功，但交互按钮持续处于禁用状态，日志中仅记录上传请求无后续响应字段。原因：未开启`detail`全量日志采集，无法捕获图片解析环节的异常节点，导致无法定位按钮禁用的根因。
- 现象：无法检索到指定培训批次的用户问答记录，筛选后结果为空。原因：未绑定`chatId`与培训批次关联关系，日志未按批次归档，导致筛选维度缺失。
- 现象：知识库搜索节点返回结果与历史上下文无关，指代消除失败。原因：未配置按`responseChatItemId`关联历史交互，未保留完整会话链路，导致上下文丢失。

## 怎么确认配好了
- 登录FastGPT后台，查看会话日志列表，确认可按培训批次、用户角色筛选日志。
- 触发一次培训答疑交互，检查日志中是否包含`chatId`、`responseChatItemId`字段与全量`detail`内容。
- 模拟工单提交场景，确认日志可关联工单编号与答疑记录。
- 验证日志存储周期配置，确认可按业务需求调整保留时长。
