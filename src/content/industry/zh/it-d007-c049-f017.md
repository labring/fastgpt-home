# 客户培训与使用手册的线上故障排查与复盘：部署与升级

## 这个品类的数据长什么样
通常，该品类的核心数据来自产品帮助中心、客户组织架构、培训录屏、工单系统。日常产出的文档包括培训课件、用户手册、培训签到表、问题答疑清单。数据更新频率为每单或每版本，最耗时的环节集中在角色权限讲解、操作步骤演示、课后问题整理。文档结构通常包含受众分层、操作步骤、常见问题模块，字段涵盖文档版本、更新时间、关联客户标识、受众群体标签等，无固定强制单位要求。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据来源分散且更新频繁，部署环节需支持快速对接多源文档同步工具，避免因文档更新导致部署后内容不一致。由于文档包含角色权限相关内容，部署时需预设权限配置模板，适配不同培训受众的访问范围，比如普通客户、管理员等不同角色的权限差异。由于更新频率为每单或每版本，升级环节需兼容旧版文档结构，避免升级后原有培训资料无法正常加载，同时保留客户的历史培训记录。同时，由于核心数据关联客户标识，部署时需配置独立的存储与访问权限，防止不同客户的培训数据混淆，保障数据安全。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:27017/training_db?authSource=admin` | 持久化存储培训课件、工单记录等核心品类数据 |
| `REDIS_URL` | `redis://:your_redis_password@host:6379/0` | 缓存培训录屏访问令牌、用户会话与检索缓存 |
| `FE_DOMAIN` | `https://your-training-platform.com` | 绑定培训手册的官方访问域名，确保前端资源正常加载 |
| `ROOT_KEY` | `随机生成的32位以上无特殊字符字符串` | 配置系统最高权限管理入口，用于培训内容的批量更新 |
| `DB_MAX_LINK` | `10–20 条` | 限制数据库连接数，适配培训文档的日常并发访问需求 |
| `STORAGE_S3_ENDPOINT` | `按实测标定` | 适配培训录屏、课件等大文件的存储与访问需求 |

## 容易做错的三处
- 执行docker-compose up后启动失败，报错提示数据库连接超时。原因是未正确配置`MONGODB_URI`或`PG_URL`的访问权限，或数据库服务未正常启动。
- 培训手册页面无法加载，前端显示404错误。原因是`FE_DOMAIN`配置的域名未绑定到部署服务器的公网IP，或前端资源打包路径错误。
- 上传的培训课件无法被检索，或培训录屏无法正常播放。原因是未配置`STORAGE_S3_ENDPOINT`导致文件存储路径错误，或存储服务的访问权限未开放。

## 怎么确认配好了
- 执行docker-compose config命令，检查所有配置项的格式是否符合FastGPT v4.17.0的规范，无语法错误。
- 访问`FE_DOMAIN`对应的域名，确认培训手册首页可以正常加载，无空白或报错提示。
- 使用`ROOT_KEY`调用系统内置的权限验证接口，验证最高权限配置是否生效，可正常执行批量文档更新操作。
- 上传一份10MB以内的测试培训课件，确认文件可以正常上传并存储，且可通过检索功能正常找到。
