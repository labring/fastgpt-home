# 客户开通与租户初始化的线上故障排查与复盘：部署与升级

## 这个品类的数据长什么样
该品类的数据通常关联客户开通与租户初始化全流程，日常文档包括开通申请单、租户配置表、管理员账号清单、交付确认单。数据来源覆盖CRM系统、合同订单库、身份管理平台与FastGPT产品后台，更新节奏按单或每日更新。核心字段包含客户唯一标识、租户编码、权限配置范围、开通状态与验收节点，仅随交付动作同步流转，无固定统计口径。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据随单流转且依赖多系统同步，部署时需确保各系统间的身份标识对齐，避免租户编码冲突。每日更新的节奏要求升级操作需在低峰期执行，防止影响正在进行的开通流程。多文档协同的场景下，部署配置需支持批量导入租户配置表字段，减少手动录入误差。同时，验收节点绑定开通结果，部署失败将直接导致交付验收受阻，需提前配置回滚预案。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:27017/fastgpt?authSource=admin` | 适配租户数据隔离存储需求，确保不同租户的配置与开通记录独立存储 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 用于缓存租户权限校验数据，建议设置超时时间为300秒 |
| `STORAGE_S3_ENDPOINT` | `http://minio.example.com:9000` | 对应租户初始化所需的文件存储地址，支持内网或公网部署，需匹配FastGPT v4.17.0的存储适配逻辑 |
| `ROOT_KEY` | `自定义随机32位字符串` | 用于管理员后台的权限校验，避免默认密钥导致的权限泄露风险 |
| `FE_DOMAIN` | `https://your-fastgpt-domain.com` | 配置前端访问域名，确保租户登录回调地址与配置一致 |

## 容易做错的三处
- 现象为调用第三方大模型接口时返回403错误，或接口配置项显示为空。原因是本地部署时未正确配置第三方API的环境变量，导致密钥与接口地址未正确加载。
- 现象为租户初始化时文件上传失败，控制台显示连接超时错误。原因是升级后存储配置强制要求端点公网可访问，未针对内网环境配置反向代理或内网穿透。
- 现象为插件系统无法加载第三方接口配置，系统提示缺少API入口参数。原因是docker compose部署文件中未添加相关环境变量，导致系统无法识别第三方API配置。

## 怎么确认配好了
- 登录FastGPT管理员后台，进入租户管理页面，确认已导入的租户配置字段与本地交付的租户配置表一致。
- 提交一条测试租户开通申请，查看系统生成的开通状态与验收节点是否正常流转，无报错提示。
- 调用存储接口上传测试文件至配置的`STORAGE_S3_ENDPOINT`地址，确认文件可正常读取与下载。
- 检查部署环境变量，确认`MONGODB_URI`、`REDIS_URL`与`FE_DOMAIN`等核心配置项的取值与实际部署环境匹配。
