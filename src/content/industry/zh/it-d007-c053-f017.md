# 客户需求池管理的线上故障排查与复盘：部署与升级

## 这个品类的数据长什么样
这个品类的数据通常来自工单系统、客户访谈记录、CRM系统与产品路线图，日常以需求池清单、需求评估表、客户反馈记录、版本规划说明为载体。数据更新频率为周度或随产品版本迭代，核心字段包含客户标识、需求优先级、归并标记、版本关联项，最常处理的重复需求归并环节会产生大量关联校验数据。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据多源分散且需定期更新，要求部署环节支持灵活的外部接口对接，避免硬编码限制数据源扩展。字段包含客户标识、优先级等关联项，需在部署时配置数据校验规则，防止不同来源的字段格式冲突。周度或版本级的更新频率，要求升级环节支持增量数据迁移，避免全量替换导致的业务中断。同时，客户反馈的实时接入需求，要求部署时配置稳定的端口与域名绑定规则，保障外部请求的正常流转。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:port/dbname?authSource=admin` | 存储需求池清单、客户反馈记录的核心业务数据，需配置正确的认证与库名参数 |
| `REDIS_URL` | `redis://:password@host:port/0` | 缓存高频访问的需求优先级、归并标记数据，建议设置连接超时为`30 秒` |
| `FE_DOMAIN` | `https://your-fastgpt-domain.com` | 绑定前端访问域名，保障企业微信等外部渠道的回调请求正常跨域 |
| `DB_MAX_LINK` | `10–20` | 适配周度批量需求归并与评估的并发请求，避免连接池耗尽 |
| `STORAGE_S3_ENDPOINT` | 按实测标定 | 存储版本规划说明等文档附件，需匹配云服务商的终端节点地址 |
| `ROOT_KEY` | 自定义长度不低于16 字符的复杂字符串 | 配置系统管理员的最高权限密钥，保障需求池管理的后台操作安全 |

## 容易做错的三处
- 现象：前端页面无法访问，返回404或连接超时。原因：未正确配置`FE_DOMAIN`参数，导致前端域名与后端服务的绑定不匹配，跨域请求被拦截。
- 现象：调用外接模型时返回connection refused。原因：未正确配置`PG_URL`或`REDIS_URL`的主机端口参数，导致模型服务与需求池管理的关联链路不通，请求无法正常转发。
- 现象：批量需求归并时出现重复数据残留。原因：`DB_MAX_LINK`配置过低，导致并发处理时连接池不足，部分归并操作未完成提交，数据一致性被破坏。

## 怎么确认配好了
- 登录FastGPT v4.17.0版本的后台数据源配置页面，查看`MONGODB_URI`与`REDIS_URL`的参数与部署时填写的内容是否一致。
- 发起一条测试客户反馈提交，查看后端日志是否有正常的请求接收与存储记录，无报错提示。
- 访问配置的`FE_DOMAIN`地址，确认前端页面可以正常加载，且能正常提交测试需求。
- 执行一次批量需求归并的模拟操作，查看数据校验规则是否生效，无格式冲突的报错。
