# 广告账户开户审核的线上故障排查与复盘：部署与升级

## 这个品类的数据长什么样
该品类的数据通常来自广告平台后台、国家企业信用信息公示系统、客户提交的材料以及行业准入规则。日常关联文档包括开户申请单、营业执照扫描件、行业资质证明、开户审核记录等。数据更新节奏通常为每申请一次或每日更新，字段涵盖主体名称、资质编号、审核状态、提交时间等，无固定统一的标准化格式，部分字段需跨数据源关联核验。

## 这些特征在「部署与升级」这一环带来什么约束
多数据源的依赖要求部署时需配置稳定的跨系统访问权限，避免因权限不足导致资质核验失败。非结构化的文档存储需求，要求选用适配灵活字段的存储方案，升级时需兼容旧版审核记录的字段结构。高频的实时核验与更新节奏，要求缓存服务能支撑高频查询，避免重复调用外部接口导致延迟。审核结果直接关联开户流程，部署与升级环节需配置完善的失败重试与告警机制，防止因配置错误导致开户失败或违规投放。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `MONGODB_URI` | `mongodb://[用户名]:[密码]@[主机]:[端口]/fastgpt?authSource=admin` | 该品类需存储灵活的资质材料与审核记录，MongoDB适配非结构化文档的存储与查询 |
| `DB_MAX_LINK` | `20–30 个连接` | 单审核任务的数据库连接需求稳定，该取值可避免连接池耗尽，适配日常并发量 |
| `REDIS_URL` | `redis://:[密码]@[主机]:[端口]/0` | 需缓存高频查询的行业准入规则与主体核验结果，降低重复调用外部接口的开销 |
| `STORAGE_S3_ENDPOINT` | `https://s3.[区域].服务商域名` | 需存储客户提交的高清资质扫描件，适配大文件的上传与下载需求 |
| `FILE_TOKEN_KEY` | `32 位随机字符串` | 需生成安全的文件访问令牌，防止未授权下载客户提交的敏感资质材料 |
| `PG_URL` | `postgresql://[用户名]:[密码]@[主机]:[端口]/fastgpt` | 可作为MongoDB的替代存储方案，用于存储结构化的审核流程日志 |
| `ROOT_KEY` | 按部署环境生成强随机字符串 | 需管控平台的最高权限操作，避免未授权的审核流程修改或数据篡改 |

## 容易做错的三处
- 现象为审核流程报错「连接超时」，状态码504，原因是未针对多数据源配置合理的`DB_MAX_LINK`，导致数据库连接池耗尽，无法及时响应资质核验请求。
- 现象为客户提交的资质材料无法正常存储，界面显示「文件上传失败」，原因是未正确配置`STORAGE_S3_ENDPOINT`，导致存储服务地址错误，无法完成大文件上传。
- 现象为审核记录字段缺失，比如资质编号为空，原因是部署时未校验`MONGODB_URI`的读写权限，导致无法写入完整的审核数据字段。

## 怎么确认配好了
- 执行版本查询命令，确认当前运行的FastGPT版本为v4.17.0，核对部署包与官方发布版本一致。
- 提交一条测试开户申请，查看数据库中是否生成完整的审核记录，验证`MONGODB_URI`的读写权限正常。
- 上传一张测试资质扫描件，查看是否能正常存储并生成访问链接，验证`STORAGE_S3_ENDPOINT`配置正确。
- 查看连接池监控指标，确认当前数据库连接数未超过配置的`DB_MAX_LINK`阈值，验证连接池配置生效。
