# 投放计划搭建的线上故障排查与复盘：部署与升级

## 这个品类的数据长什么样
投放计划搭建类的日常文档包含投放计划模板、人群定向配置表、预算排期表、转化追踪配置项。数据主要来自广告平台API、用户画像标签库、线下预算审批表、归因分析工具。数据更新节奏通常为每日同步或单次活动启动时全量更新，字段包含定向人群包ID、预算阈值、转化事件编码等，无统一标准化单位，部分字段需匹配广告平台的枚举值格式。

## 这些特征在「部署与升级」这一环带来什么约束
由于投放计划搭建的数据来自多个异构来源，部署时需配置多源数据对接的参数，且需内置枚举值校验逻辑，避免数据格式不匹配导致的配置失效。数据更新频率为日或活动级，升级时需保证数据同步任务的稳定性，防止中断后投放计划无法生效。最耗时的人群定向、预算分配、转化事件校验环节，要求部署环节内置字段合法性校验，减少人工排查成本。出错后果可能导致预算浪费或投放无法启动，升级前需配置快速回滚参数，确保故障时可快速恢复服务。FastGPT v4.17.0版本新增了多源数据同步的重试机制，适配该品类的更新节奏。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `MONGODB_URI` | `mongodb://[username]:[password]@host:port/dbname?authSource=admin` | 投放计划的定向人群包、历史配置数据需持久化存储，需匹配广告平台返回的枚举值格式 |
| `REDIS_URL` | `redis://:password@host:port/0` | 需缓存实时的预算校验结果、定向人群包的临时数据，缓存过期时间建议设为3600秒 |
| `PG_URL` | `postgresql://username:password@host:port/dbname` | 需存储预算排期的历史版本、归因数据的关联记录，支持多租户的权限隔离 |
| `DB_MAX_LINK` | `100–150` | 投放计划搭建的并发请求量通常在百级以内，避免连接池耗尽影响服务稳定性 |
| `ROOT_KEY` | `随机生成的32位以上字符串` | 用于对接广告平台API的签名校验，防止未授权的配置修改 |
| `FE_DOMAIN` | `https://your-deploy-domain.com` | 配置前端服务的访问域名，用于跨域请求的校验与回调地址的设置 |

## 容易做错的三处
- 现象：调用广告平台API时返回401未授权错误，无法加载定向人群包数据。原因：未正确配置`ROOT_KEY`或`MONGODB_URI`中的认证参数，导致签名校验失败。
- 现象：通过Sealos部署的OneAPI调用大模型时，无法触发function call工具，投放计划的转化事件校验失败。原因：未在`FE_DOMAIN`配置中添加Sealos部署的API网关地址，导致跨域请求被拦截，工具调用的参数无法正确传递。
- 现象：Docker构建镜像时提示依赖包拉取失败，无法启动本地调试环境。原因：未指定正确的依赖源镜像，或本地网络无法访问官方包管理仓库，导致构建过程中断。

## 怎么确认配好了
- 执行`docker ps`命令，确认所有依赖服务（MongoDB、Redis、PostgreSQL）的容器均处于运行状态。
- 调用配置的广告平台API接口，验证`MONGODB_URI`中存储的定向人群包数据可正常读取并匹配枚举值。
- 修改一条投放计划的预算配置，观察`REDIS_URL`的缓存是否在设定的过期时间内同步更新。
- 执行升级回滚脚本，验证`ROOT_KEY`的权限校验逻辑可正常拦截未授权的配置修改。
