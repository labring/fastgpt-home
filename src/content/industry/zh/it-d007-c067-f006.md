# 数据安全分类分级的线上故障排查与复盘：定时任务与自动化

## 这个品类的数据长什么样
FastGPT v4.17.0及以上版本支持本场景的配置。本品类的数据主要来自数据资产盘点、数据库元数据、业务系统说明与法规文件。日常维护的文档包括数据目录、分类分级规则、重要数据识别表与评审纪要。数据更新频率为季度周期或对应业务系统变更时触发。数据字段包含资产编号、数据分类标签、敏感级别、所属业务域，无统一固定的单位体系，部分字段需结合业务场景补充说明。

## 这些特征在「定时任务与自动化」这一环带来什么约束
数据来源分散且多为跨系统文件，导致定时任务需适配多源数据拉取逻辑，避免单一数据源拉取失败影响整体流程。数据更新节奏不固定，任务调度需支持固定周期触发与系统变更触发结合的模式，无需高频执行浪费资源。日常文档结构多样，包含结构化的识别表与非结构化的评审纪要，自动化处理需兼容多格式解析逻辑，避免单一解析规则导致内容丢失。数据字段无统一单位，自动化校验规则需支持动态适配字段格式，无需硬编码单位匹配逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 任务触发模式 | 固定周期+系统变更触发 | 匹配数据季度更新与系统变更的实际节奏 |
| 单次数据拉取上限 | 1000 MB | 适配数据库元数据与资产盘点文件的常规大小 |
| 任务超时阈值 | 1800 秒 | 覆盖多源数据拉取与多格式解析的耗时需求 |
| 自动化校验匹配度 | 85%-95% | 适配分类分级规则的评审精度要求 |
| 失败重试次数 | 3 次 | 平衡任务稳定性与系统资源消耗 |
| 日志留存时长 | 30 天 | 满足合规复盘的日志查阅需求 |

## 容易做错的三处
- 现象：Excel格式的重要数据识别表导入后，多行内容被合并为单条记录。原因：未配置自定义行级拆分规则，默认解析逻辑按单元格换行合并内容，未适配Excel单条记录对应一行的导入要求。
- 现象：API调用自动化工作流后返回空值。原因：未在任务配置中绑定对应的数据资产盘点数据源，导致任务无法拉取有效输入数据。
- 现象：定时任务执行过程中触发超时终止。原因：任务触发周期设置过短，在多源数据拉取时未预留足够耗时，超出预设的超时阈值。

## 怎么确认配好了
- 手动触发一次定时任务，查看任务日志中是否拉取到配置的数据源文件列表。
- 导入Excel格式的重要数据识别表，核对解析后每条记录对应一行原始Excel内容。
- 核对任务配置的超时阈值，确保其覆盖多源数据拉取与解析的实际耗时。
- 模拟系统变更触发任务，确认任务可自动启动并完成全流程执行。
