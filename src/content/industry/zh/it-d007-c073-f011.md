# 数据集交付与版本管理的线上故障排查与复盘：数据库与运维

## 这个品类的数据长什么样
通常，该品类的数据由数据项目经理、数据工程师、客户算法团队维护，日常文档包括数据集说明、版本记录、交付清单、验收报告。数据来源涵盖对象存储、数据仓库、标注平台及客户验收反馈，更新频率随每批次或每个版本推进。数据字段通常包含数据集标识、版本号、来源路径、样本数量、验收状态等，单位多为条、GB、天等，核心聚焦交付包的完整性与版本可追溯性，区别于侧重数据清洗的同类服务。本内容适配FastGPT v4.17.0版本。

## 这些特征在「数据库与运维」这一环带来什么约束
该品类的数据多源分散、更新频率随版本波动，且核心文档需结构化存储与快速查询，因此对数据库运维提出多重约束。多数据源接入需求要求配置兼容不同存储类型的连接参数；版本号、样本差异等核心元数据需持久化存储，避免丢失导致训练不可复现；交付完整性核对需支持复杂条件查询，对数据库索引优化提出要求；频繁的版本更新与交付操作，需限制并发连接数避免服务过载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:27017/fastgpt_dataset` | 用于存储非结构化的版本记录、交付清单，适配多源数据的灵活存储 |
| `PG_URL` | `postgresql://user:pass@host:5432/fastgpt_metadata` | 存储结构化的数据集说明、验收报告字段，支持复杂条件查询 |
| `DB_MAX_LINK` | `20–30 个` | 避免数据库连接耗尽，适配多批次数据集交付的并发请求 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 缓存高频访问的版本元数据，降低数据库查询压力 |
| 缓存过期时间 | `300 秒` | 减少高频访问的版本元数据的数据库查询次数 |
| 数据集导出粒度 | 按业务分类维度 | 适配多类型知识库的拆分导出需求，满足精细化交付要求 |

## 容易做错的三处
- 现象：导出数据集时仅能选择知识库维度，无法按业务分类或数据类型拆分。原因：未配置按业务维度的导出粒度参数，默认仅开放知识库级粒度。
- 现象：本地部署时数据库连接报错，提示无法解析主机名或权限不足。原因：未正确填写`PG_URL`或`MONGODB_URI`中的主机地址，或未将服务IP加入数据库白名单。
- 现象：执行多行SQL语句时返回语法错误。原因：未启用数据库连接插件的多行查询支持，默认仅允许单条语句执行。

## 怎么确认配好了
- 登录数据库管理面板，检查是否存在数据集版本记录、交付清单等对应表结构，字段与日常文档结构一致。
- 发起一次小规模数据集导出测试，验证导出粒度是否符合业务分类配置，导出文件完整性与交付清单匹配。
- 执行两条及以上的SQL语句测试，确认无语法报错，语句可正常执行完成。
- 查看数据库连接监控面板，确认当前活跃连接数未超过`DB_MAX_LINK`的配置值。
