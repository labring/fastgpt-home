# 文本标注项目的线上故障排查与复盘：部署与升级

## 这个品类的数据长什么样
文本标注项目的数据主要来自客户提供的语料、自有标注平台产出的标注结果、行业通用词表以及质检抽样结果。日常产出的文档包括标注规范、样本包、质检报告和问题反馈表。数据更新节奏通常为每日或按标注批次推进，核心字段包含标注文本、实体标签、意图分类结果、质检评分等，整体聚焦语义边界、实体与意图的标注逻辑。

## 这些特征在「部署与升级」这一环带来什么约束
文本标注项目的数据特征会对部署与升级环节带来明确约束。多源且高频更新的数据，要求部署时适配多渠道数据接入配置，升级时需保障数据同步的一致性。日常文档的固定结构，需在部署阶段预设对应文档的存储与解析路径。按日或按批次的更新节奏，要求部署后的服务支持实时或批量数据加载，升级过程不能中断核心标注与质检流程。围绕语义、实体与意图的标注字段，需在部署时配置标签校验规则，升级时兼容旧版格式避免标注中断，同时预留日志与回滚机制应对故障。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:27017/fastgpt_text_label` | 存储标注文本、标签结果与质检数据，需绑定专属业务数据库 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 缓存高频访问的标注规范、词表与临时标注任务数据，使用默认0号数据库 |
| `DB_MAX_LINK` | `200–300 个连接` | 适配多标注团队并发的数据库连接需求，避免连接耗尽导致的任务中断 |
| `STORAGE_S3_ENDPOINT` | 按对象存储服务商的内网地址填写 | 存储样本包、质检报告等大体积文档，内网地址可降低传输延迟 |
| `FE_DOMAIN` | 部署服务的公网域名 | 用于生成标注任务的访问链接与文件预览地址，适配前端页面的跨域需求 |

## 容易做错的三处
- 现象：升级后第三方API配置丢失，界面显示配置项为空。原因：未将第三方标注接口的配置信息写入持久化存储目录，升级容器时挂载目录未正确绑定，导致配置随容器销毁丢失。
- 现象：Docker部署后无法找到`packages/plugins/register`文件，系统插件配置界面加载失败。原因：部署时未正确复制插件注册目录到容器镜像中，或挂载的本地目录权限不足导致文件无法读取。
- 现象：工作流节点较多时，页面输入文字出现卡顿。原因：前端未对标注文本的实时校验做防抖处理，同时未限制节点渲染的批量更新频率，导致大量DOM重排引发卡顿。

## 怎么确认配好了
- 查看服务启动日志，确认数据库、缓存服务的初始化日志无报错，根据实际并发需求调整连接数配置。
- 上传测试样本包，验证存储服务能否正常接收并生成访问链接，确认存储配置的有效性。
- 进入系统插件配置界面，尝试保存第三方API配置，确认配置信息可正常持久化不丢失。
- 打开标注工作流页面，添加多个测试节点并输入文本，观察页面响应状态，按需调整前端渲染的相关参数。
