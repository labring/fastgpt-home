# 美术资产生产管理的线上故障排查与复盘：定时任务与自动化

## 这个品类的数据长什么样
这个品类的数据主要来自美术资产库、项目管理系统、引擎资源包、外包交付包。日常产出的文档包含美术需求单、资产规格表、外包反馈表、验收记录，字段包含资产唯一标识、版本号、交付时间、规格参数、验收状态等。数据更新频率通常为每日或每周，单次资产包体量从几十MB到数GB不等。

## 这些特征在「定时任务与自动化」这一环带来什么约束
多源数据来源要求任务需支持跨系统拉取并统一格式，避免数据割裂；日/周级别的更新频率要求任务调度需匹配业务节奏，避免过度占用系统资源；不同类型文档的字段差异，要求按文档类型配置差异化的校验规则；资产包体量较大的特点，要求分块处理时需控制单次处理的资源消耗，防止性能超标或任务超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 任务触发周期 | 每日凌晨2点，或按项目更新节奏设定 | 匹配美术资产日/周级别的更新频率，避免频繁拉取占用系统资源 |
| 数据源拉取范围 | 仅当前项目组关联的美术资产库、项目管理系统数据 | 过滤无关数据，降低任务处理量 |
| 数据块分块大小 | `800–1200 字符` | 适配Excel源数据的单行列内容长度，避免分块过大导致资源消耗过高 |
| 资源匹配校验阈值 | `资源匹配度≥95%` | 匹配资产规格的严格要求，防止资源不匹配问题 |
| 失败重试配置 | 重试2次，间隔`600 秒` | 应对临时网络波动或系统负载过高导致的任务失败 |
| 告警触发条件 | 连续2次任务失败 | 及时通知相关人员处理异常 |
*注：本配置适用于FastGPT v4.17.0版本*

## 容易做错的三处
- 现象：定时任务执行后，知识库未同步更新内容，再次打开对应对话时，历史回复内容为空。原因：未配置任务结果的持久化存储，或未绑定对话记录保存动作。
- 现象：Excel格式的资产规格表处理时任务超时。原因：数据块分块大小设置超过`1500 字符`，超出系统单次处理的资源上限。
- 现象：外包交付的资源包上传后未触发自动化校验。原因：仅配置了固定时间触发任务，未配置按资源包后缀触发的规则。

## 怎么确认配好了
- 手动触发一次定时任务，查看任务日志中是否有对应数据源的拉取、处理记录。
- 上传一份测试用的美术需求单文档，确认任务执行后生成对应的校验结果并同步至知识库。
- 模拟一次任务失败场景，比如断开临时数据源连接，查看是否触发预设的告警通知。
- 检查知识库中拆分后的资产规格内容，确认符合预设的分块大小要求。
