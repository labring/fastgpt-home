# 集成测试与接口测试的线上故障排查与复盘：数据库与运维

## 这个品类的数据长什么样
该品类的数据主要来自接口管理平台、测试环境日志、数据库与消息队列，更新频率为每日或每版本发布时。日常产出的文档包括接口测试用例、联调问题单、测试环境说明文档与测试报告，数据字段包含接口请求参数、响应状态码、链路调用耗时、依赖服务健康状态等，无统一固定单位，随具体接口与测试场景变化。数据由测试工程师、测试开发团队与接口平台维护人员共同维护，用于验证跨模块交互的正确性。本页适配FastGPT v4.17.0版本。

## 这些特征在「数据库与运维」这一环带来什么约束
该品类的数据来源分散且更新频繁，要求数据库与运维环节需适配多类型数据源的连接配置，同时保障测试环境与生产环境的数据库隔离，避免测试数据污染生产环境。跨模块交互的测试验证需频繁读写数据库与消息队列，连接池参数需匹配高频调用的负载需求，防止依赖服务准备环节出现连接耗尽。日常文档的动态字段结构要求运维配置支持灵活的参数映射，且需留存完整的配置变更记录，便于故障复盘时追溯链路。测试场景的多样性也要求运维环节可快速切换不同数据库的连接配置，适配不同的测试需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MONGODB_URI` | `mongodb://fastgpt_test:TestPass123@host:27017/fastgpt_test?authSource=admin` | 适配MongoDB的专属测试用户认证，隔离测试与生产环境的数据 |
| `PG_URL` | `postgresql://test_user:TestPass456@host:5432/fastgpt_test?sslmode=disable` | 适配PostgreSQL的测试环境连接，支持结构化测试数据的存储与查询 |
| `DB_MAX_LINK` | `20–50 个` | 匹配每日/每版本的高频测试调用量，避免连接耗尽导致测试中断 |
| `REDIS_URL` | `redis://:RedisPass789@host:6379/1` | 用于缓存接口测试的中间结果，降低数据库的重复读写压力 |
| 数据库连接超时阈值 | `30 秒` | 匹配依赖服务准备环节的耗时上限，避免测试用例因等待过久失败 |
| 测试日志留存周期 | `7 天` | 满足联调问题单与故障复盘的日志追溯需求 |

## 容易做错的三处
- 配置`MONGODB_URI`时复用生产环境的root用户权限，未创建专属测试用户，导致测试数据污染生产环境，出现`Authentication failed`或权限不足报错。
- 未正确配置`DB_MAX_LINK`参数，设置值过低，高频测试调用时出现连接耗尽，返回`400 status code (no body)`报错。
- 本地开发环境未修改`MONGODB_URI`指向本地Mongo实例，仍使用远程生产环境地址，导致`pnpm dev`时出现数据库连接超时，无响应内容。

## 怎么确认配好了
- 登录MongoDB实例，执行`show users`命令，验证专属测试用户已创建并拥有对应测试数据库的读写权限。
- 运行预设的集成测试脚本，观察所有接口调用的响应状态码均为200，无连接超时或权限报错。
- 查看数据库连接池监控面板，确认当前活跃连接数未超过`DB_MAX_LINK`的配置值。
- 检查测试日志目录，确认近7天的接口测试日志已正常生成并可通过接口ID、请求参数等关键词检索。
