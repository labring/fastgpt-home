# 集成测试与接口测试的线上故障排查与复盘：部署与升级

## 这个品类的数据长什么样
这个品类的数据主要来自接口管理平台的用例参数、测试环境的请求响应日志、关联业务数据库的调用记录、消息队列的链路通知。日常关联文档包括接口测试用例的参数配置、联调问题单的异常记录、环境说明的依赖项清单、测试报告的通过率数据。数据更新频率为每日同步测试执行数据，每版本迭代时更新接口链路映射与依赖服务配置。字段包含接口地址、请求头、响应码、调用耗时、依赖服务状态，无额外非标准统计字段。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据特征对部署与升级环节带来具体约束。因数据来源涉及多类平台与日志，部署时需提前配置各数据源的连接参数，确保接口管理平台、测试日志库的连通性。因更新频率随版本与每日执行变化，升级时需保留历史接口映射配置，避免因版本更新丢失联调链路数据。因日常文档依赖环境说明与依赖清单，部署前需校验配置项与环境说明的一致性，防止依赖服务配置错位。因字段固定为接口地址、响应码等，升级时无需额外调整数据解析逻辑，仅需适配数据源连接协议变更。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `MONGODB_URI` | `mongodb://testuser:testpass@db-host:27017/fastgpt_integration` | 存储接口测试的请求响应日志与联调问题记录 |
| `REDIS_URL` | `redis://:redispass@redis-host:6379/1` | 缓存接口调用频次、联调状态与临时测试数据 |
| `DB_MAX_LINK` | `20–30 个` | 适配每日集成测试的并发连接数，避免连接耗尽 |
| `STORAGE_S3_ENDPOINT` | `https://s3-cn-beijing.aliyuncs.com` | 存储测试报告、接口用例附件与链路分析文件 |
| `FE_DOMAIN` | `https://integration-test.example.com` | 配置联调环境的前端访问域名，用于接口回调与结果展示 |

## 容易做错的三处
- 现象：线上部署后接口测试日志丢失，无法回溯联调问题。原因：未正确配置`MONGODB_URI`参数，或连接字符串中未指定正确的数据库名称与读写权限。
- 现象：执行批量集成测试时出现连接超时报错，状态码504。原因：`DB_MAX_LINK`取值过低，无法支撑并发的接口调用请求。
- 现象：升级后无法查看当前部署的FastGPT版本。原因：未保留版本信息的存储配置，或`FILE_TOKEN_KEY`参数配置错误导致版本文件无法读取。

## 怎么确认配好了
- 执行一条基础接口测试用例，检查测试报告是否生成并存储在指定的对象存储路径。
- 查看测试环境的日志平台，确认接口请求与响应数据已同步到配置的数据库中。
- 调用版本查询接口，确认当前部署的FastGPT v4.17.0版本信息正常返回。
- 检查Redis缓存中是否存在最近一次联调测试的状态标记，确认连接正常。
