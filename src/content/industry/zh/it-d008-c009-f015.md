# 个人信息保护合规的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据主要来自隐私合规团队、安全咨询及法务部门的日常工作文档，包括个人信息清单、处理规则、影响评估报告、用户授权文本等。数据来源涵盖业务系统、App权限清单、隐私政策及用户请求记录，更新频率为季度周期或每次产品功能变更时。文档包含结构化表格类内容与非结构化合规报告类内容，字段多围绕自然人信息识别、处理合法性展开，无额外非合规业务字段。

## 这些特征在「知识库检索与召回」这一环带来什么约束
由于数据包含结构化表格与非结构化合规文本，检索需同时支持两类文档的解析与匹配。更新频率的周期性要求知识库需定期同步最新版本的合规文档，避免使用过时的处理规则或授权文本。文档字段聚焦个人信息相关内容，检索范围需严格限定在合规知识库内，防止无关业务数据混入结果。同时，合规内容的准确性要求极高，召回结果需与用户工单的合规查询高度匹配，避免误导运维人员的工单处理。

## 配置怎么定
本页面的配置逻辑适配FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `similarity` | 0.75-0.85 | 合规内容需较高相关性，避免无关文档干扰工单的合规判断 |
| `limit` | 前6-8条 | 内部工单问答需快速获取合规依据，过多结果会超出上下文长度限制 |
| `searchMode` | hybrid | 同时适配结构化表格（如个人信息清单）与非结构化合规文本的检索需求 |
| `usingReRank` | 开启 | 重排可提升高相关合规文档的排序优先级，确保关键依据优先展示 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户工单问题扩展检索词，覆盖更多关联的合规文档内容 |
| `collectionIds` | 指定合规知识库专属ID | 限定检索范围仅覆盖个人信息保护合规相关文档，避免混入非合规数据 |

## 容易做错的三处
- 现象：对话中要求复述上传的xlsx格式个人信息清单内容时，返回无法读取该文件。原因：未开启`datasetSearchUsingExtensionQuery`，且未配置表格文件的检索解析规则，仅默认支持文本类文档的读取。
- 现象：检索结果包含非合规类的业务知识库内容，无法精准匹配个人信息保护相关文档。原因：未指定`collectionIds`，检索范围覆盖了其他业务知识库，导致结果混杂，不符合合规数据隔离要求。
- 现象：检索返回的结果相关性过低，或遗漏关键合规依据。原因：`similarity`阈值设置不当，未结合合规文档的文本特征进行实测标定，导致匹配精度不足。

## 怎么确认配好了
- 上传一份测试用的个人信息清单xlsx文件，发起包含“查看该文件第十行内容”的工单，检查是否能返回对应表格行的完整内容。
- 查看检索日志，确认仅匹配到指定合规知识库的文档，无其他非合规知识库的结果返回。
- 调整`similarity`阈值，验证不同阈值下的检索结果相关性变化，确认符合合规内容的精度要求。
- 开启`usingReRank`后，对比重排前后的结果排序，确认高相关合规文档被优先展示。
