# 云主机交付与资源开通的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
这个品类的日常文档包括资源开通单、实例配置表、账号权限单、交付确认单，核心字段包含实例规格、网络配置、权限范围、计费规则等。数据来源为云管理平台、订单系统、IAM权限系统与计费系统，更新节奏为每单实时同步。典型处理主体为云服务运营、云平台运维与客户支持团队，工单处理中最耗时的环节为规格核对、网络安全组配置校验与交付通知确认，错误将直接导致客户部署失败、资源配置错误或计费争议。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源数据同步的特性要求知识库检索需兼容不同系统的字段格式，避免出现字段不匹配导致的召回失败。实时更新的节奏则要求检索链路支持增量数据的快速同步，确保最新的资源配置与工单信息可被及时召回。工单文档的结构化特征，要求检索需精准匹配字段，否则易返回无关的非结构化内容。高风险的出错后果，则要求检索结果需具备较高的准确率，避免因错误的配置参考引发业务问题。同时，有限的处理时间窗口要求检索链路需控制返回结果的数量与处理时长，保障工单处理效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.78–0.82 | 匹配云主机规格、权限等精确字段，过滤低相关召回结果，适配FastGPT v4.17.0版本的检索逻辑 |
| `limit` | 前6条 | 控制单次召回的文档数量，适配工单处理的上下文长度，避免信息过载 |
| `searchMode` | `vector+keyword` | 兼顾语义匹配与精确字段匹配，满足规格核对、权限校验的核心需求 |
| `usingReRank` | 开启 | 对召回结果二次排序，提升高相关文档的展示优先级，优化检索体验 |
| `datasetSearchUsingExtensionQuery` | 开启 | 将工单问题扩展为相关检索词，覆盖更多匹配场景，比如将“云主机开通”扩展为“ECS实例配置” |
| `collectionIds` | 绑定专属云主机交付知识库集合 | 限定检索范围，避免召回无关的网络、负载均衡类文档 |

## 容易做错的三处
- 调用关联知识库接口后返回空检索结果，原因是未正确配置`collectionIds`参数，或未绑定专属云主机交付的知识库集合。
- 检索结果包含大量无关的网络配置或负载均衡类文档，原因是未限定`collectionIds`的检索范围，导致召回其他品类的知识库内容。
- 工单提交后检索链路出现延迟，原因是未设置合理的`limit`参数，召回过多文档导致处理时长超出业务允许的窗口。

## 怎么确认配好了
- 使用FastGPT v4.17.0版本的控制台提交测试工单，检索云主机规格、权限配置等典型问题，查看返回结果是否包含对应品类的专属文档。
- 查看检索日志，确认`similarity`阈值生效，召回结果的匹配度符合预设标准。
- 检查应用配置页面，确认`collectionIds`已绑定正确的云主机交付知识库集合。
- 提交一条新的资源开通单，验证新增的配置文档可被正常检索召回。
