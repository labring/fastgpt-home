# 企业软件许可证管理的运维值班与内部工单问答：权限与数据隔离

## 这个品类的数据长什么样
本品类的数据来自软件资产管理系统、采购系统、终端扫描结果及厂商授权文件，日常维护许可证台账、软件使用清单、采购合同、合规审计报告四类文档。数据更新频率为月或季度，单条数据包含许可证编号、授权数量、绑定终端数、到期日期等字段，字段单位包含台、个、自然日等，不同来源的数据对应不同的业务管理职责边界。

## 这些特征在「权限与数据隔离」这一环带来什么约束
本品类的数据来源分散且包含合规敏感信息，不同来源的数据对应不同的权限边界，需严格区分IT资产管理员、采购、法务合规等角色的访问范围。月度或季度的更新节奏要求权限配置无需频繁调整，但需保证变更后的数据隔离规则即时生效。许可证台账、合规审计报告等文档涉及企业合规风险，仅允许对应角色查看自身负责模块的内容。运维值班与工单问答场景中，处理人员仅可调用与当前工单关联的业务线数据，避免跨部门数据泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `teamId` 隔离维度 | 按业务线划分 | 本品类数据按业务线对应不同的软件采购与管理主体，匹配业务线权限边界 |
| `tmbId` 成员权限绑定 | 按角色分组配置 | 区分IT资产管理员、采购、法务合规三类角色的访问范围，符合日常职责分工 |
| 权限校验超时时间 | 600 秒 | 避免工单处理时权限校验阻塞，适配运维值班的实时响应需求 |
| 单次调用数据条数上限 | 前20条 | 适配许可证台账的单页展示量，避免一次性加载过多敏感数据 |
| 权限缓存有效期 | 7 天 | 适配本品类月度/季度的更新节奏，避免频繁同步权限数据 |
| 敏感文档过滤规则 | 仅展示当前`teamId`下的许可证台账与使用清单 | 合规审计报告仅开放给法务角色，避免非授权访问 |
| 工单上下文隔离 | 仅保留当前会话关联的`teamId`数据 | 防止跨业务线的敏感数据在工单问答中泄露 |

## 容易做错的三处
- 现象：调用`teamId`相关接口后返回的团队数据未正确存储，导致权限校验失败。原因：未将`teamId`与业务线数据进行绑定，接口返回数据未同步到权限隔离模块。
- 现象：知识库回答末尾显示“没有权限操作此对话记录”，且无法取消引用。原因：未配置针对工单上下文的`teamId`隔离规则，导致跨业务线的会话数据被误关联。
- 现象：团队管理页面无法正常打开。原因：未开启`teamId`对应的权限管理模块，或角色未被分配访问团队管理页面的权限。

## 怎么确认配好了
- 登录FastGPT v4.17.0，进入团队管理页面，确认已按业务线划分`teamId`分组。
- 发起一条对应业务线的运维工单，调用`teamId`相关接口，验证返回数据仅包含当前业务线的许可证信息。
- 切换非法务角色的账号，尝试访问合规审计报告，确认页面提示无权限。
- 发起跨业务线的工单测试，验证会话上下文未加载其他业务线的敏感数据。
