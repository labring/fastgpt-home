# 信创替代适配的运维值班与内部工单问答：部署与升级

## 这个品类的数据长什么样
该品类的数据主要来自企业现有IT系统清单、国产软硬件官方目录、项目测试环境与厂商公开资料。日常产出的文档包含适配清单、兼容性测试报告、迁移方案与问题台账，字段通常包含软硬件型号、适配状态、兼容版本、测试结果与风险等级。数据更新频率为每项目或每季度，随国产化软硬件版本迭代、存量系统盘点结果动态调整。

## 这些特征在「部署与升级」这一环带来什么约束
数据来源分散且需适配多类国产软硬件，要求部署阶段需提前配置多源数据导入规则，避免手动录入的误差。数据更新节奏随项目进度调整，升级阶段需同步适配最新的国产软硬件版本，需预留兼容性验证的时间窗口。存量系统盘点环节耗时较长，部署前需预加载适配清单以减少重复校验。信创场景的业务中断风险较高，升级阶段需采用灰度发布策略，避免全量切换导致的业务不可用。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的部署规范。
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `DB_MAX_LINK` | `20–30 条` | 适配场景下运维工单与适配文档的数据量波动较大，需匹配数据库连接池的合理上限 |
| `REDIS_URL` | `本地 Redis 实例地址，端口 6379` | 内部工单问答需缓存会话记录与适配规则，本地部署可降低内网访问延迟 |
| `STORAGE_S3_ENDPOINT` | `国产对象存储服务地址，如 192.168.1.100:9000` | 信创场景需规避海外存储依赖，适配国产合规的对象存储服务 |
| `FE_DOMAIN` | `企业内部域名，如 internal.oa.com` | 部署于企业内网，需匹配内部访问的统一域名规则 |
| `FILE_TOKEN_KEY` | `按实测标定的 32 位随机字符串` | 保障适配文档的上传、解析与存储权限安全 |
| `ROOT_KEY` | `仅用于初始化配置的一次性密钥，部署后禁用` | 严格管控信创场景下的系统最高操作权限 |

## 容易做错的三处
- 现象：上传的适配文档中部分表格无法正常分块，界面显示解析失败提示。原因：未启用信创适配的文档解析规则，默认解析逻辑未兼容国产办公软件生成的特殊表格格式。
- 现象：调用知识库接口时触发最大重试次数报错，日志显示`Reached the max retries`。原因：未根据信创场景的内网网络波动调整`DB_MAX_LINK`参数，连接池耗尽导致重试超限。
- 现象：本地修改配置后通过Docker重新部署，服务无法加载适配规则。原因：未将本地修改的配置文件挂载到Docker容器的对应目录，导致部署后配置未生效。

## 怎么确认配好了
- 登录前端界面，访问`FE_DOMAIN`配置的内部域名，确认能正常加载运维值班与内部工单问答的页面。
- 执行数据库连接测试，查看连接数未超出`DB_MAX_LINK`配置的取值区间，无连接超时或断开的报错。
- 上传一份含表格的适配文档，确认分块成功且无解析错误，可正常生成知识库条目。
- 重启服务后，检查`REDIS_URL`配置的缓存实例能正常写入会话数据，无缓存写入失败的日志。
