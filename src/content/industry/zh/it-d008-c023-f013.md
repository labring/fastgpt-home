# 信息化预算与项目组合管理的运维值班与内部工单问答：权限与数据隔离

## 这个品类的数据长什么样
该品类的数据主要来自财务系统、项目管理系统、合同台账与业务部门需求，日常产出年度预算表、项目立项书、项目组合看板、投资复盘报告等文档。数据更新节奏多为月、季或年度，核心字段包含项目编号、预算金额、立项时间、收益预估等，单位涉及万元、人天、项目周期（月）等，数据结构围绕项目全生命周期与预算分配展开，无统一标准化格式，多由各业务系统导出后整理。

## 这些特征在「权限与数据隔离」这一环带来什么约束
数据来源分散覆盖多个业务系统，不同部门持有不同权限范围的数据，要求隔离规则需按部门与角色划分明确的访问边界。数据更新频率较低但单次数据量可能较大，需避免频繁变更权限配置导致的权限混乱。文档结构非标准化，需针对不同文档类型配置字段级权限，防止敏感的投资复盘报告、预算表等被未授权成员访问。同时，跨团队的运维工单与智能体调用需严格隔离，避免不同项目组的预算数据泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `teamId` | 绑定对应业务部门的专属teamId | 区分不同业务部门的项目与预算数据访问范围 |
| `tmbId` | 按角色分配tmbId组，如财务BP组、PMO组 | 限定不同角色的操作权限，仅允许对应组修改授权数据 |
| 团队数据范围 | 关联财务系统、项目管理系统的指定数据源 | 匹配该品类多系统来源的数据隔离需求 |
| 单次查询上限 | 前5条 | 限制单轮查询返回的数据条数，避免跨团队数据泄露 |
| 上下文隔离时长 | 600 秒 | 限制跨团队上下文的保留时间，避免数据泄露 |
| 权限校验规则 | 按文档类型配置字段级权限 | 适配该品类非标准化的文档结构 |
| 接口调用权限 | 仅允许团队管理员配置 | 避免非授权人员修改隔离规则 |

## 容易做错的三处
- 现象：跨团队应用调用知识库时返回无相关内容。原因：未配置`teamId`与知识库的绑定关系，导致跨团队数据无法被正确隔离。
- 现象：非授权成员可查看团队内的模型使用记录。原因：未按角色分配`tmbId`组，导致权限校验未生效。
- 现象：成员可创建未授权的智能体。原因：未配置接口调用权限仅允许管理员操作，导致非授权人员修改权限规则。

## 怎么确认配好了
- 登录FastGPT v4.17.0后台，切换至对应团队，检查`teamId`绑定的数据源是否与实际业务部门的系统一致。
- 使用非授权成员账号尝试访问团队内的年度预算表或投资复盘报告，确认无法查看或操作对应内容。
- 测试跨团队的智能体调用知识库功能，确认返回无相关内容或弹出权限不足的提示。
- 检查成员权限组配置，确认仅团队管理员可修改权限隔离相关的设置项。
