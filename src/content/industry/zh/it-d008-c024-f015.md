# 信息流广告创意测试的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据主要来自广告投放平台、内部素材库、用户互动数据与转化数据。日常产出的文档包含创意脚本、素材测试表、投放数据报告、迭代清单，更新频率多为每日或每周。数据字段围绕创意素材类型、投放时段、转化链路、测试变量组合展开，单位涵盖曝光量、点击量、成本阈值等。数据围绕信息流广告的创意组合测试全流程生成，服务于创意优化与投放效果复盘。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据分散多源、更新节奏不一，要求知识库检索与召回环节支持多源数据对接与增量更新。多样的文档类型需要适配不同结构的内容解析，确保创意脚本、测试表等不同格式的内容均可被有效召回。数据字段围绕创意组合、转化效果展开，要求检索精准匹配变量组合与投放指标，避免无关结果干扰运维与工单处理。高频的创意测试与复盘需求，也要求召回链路具备低延迟特性，支撑实时的创意疲劳判断与测试结论归纳。

## 配置怎么定
以下配置项均基于FastGPT v4.17.0版本的官方支持清单：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配信息流创意测试的精准检索需求，过滤低相关的历史测试数据 |
| `limit` | 前8条 | 覆盖单次创意测试的变量组合场景，避免过多冗余结果占用上下文 |
| `searchMode` | hybrid | 结合关键词与语义检索，适配创意脚本、投放数据报告等多类型文档的召回 |
| `usingReRank` | 开启 | 对召回结果二次排序，修正语义匹配偏差，提升高转化创意素材的召回优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展工单或测试问题的查询词，覆盖创意变量的同义词与行业术语 |
| `collectionIds` | 按业务分组绑定 | 仅检索创意测试相关的知识库集合，排除无关的内部行政文档，缩小召回范围 |

## 容易做错的三处
-  出现`invalid configuration parameter name "hnsw.iterative_scan"`报错。原因是误用了官方支持清单外的非标准配置参数，未使用FastGPT允许的检索配置项。
-  知识库检索结果包含无关的内部行政文档。原因是未正确配置`collectionIds`，未限定仅检索创意测试相关的知识库集合。
-  模型输出时出现多余空格或字母大写错误。原因是未开启`usingReRank`或`datasetSearchUsingExtensionQuery`，导致检索结果的格式未被正确适配，或扩展查询词引入了格式偏差。

## 怎么确认配好了
-  上传创意脚本、素材测试表等品类专属文档，执行测试查询，核对检索结果是否仅包含目标集合内的内容。
-  调整`similarity`参数区间，验证检索结果的相关性是否符合创意测试的业务需求，按需调整阈值。
-  触发一次内部工单查询，检查是否自动扩展了行业相关的查询词，确认`datasetSearchUsingExtensionQuery`生效。
-  查看系统日志，确认未出现未授权的配置参数报错，验证所有使用的配置项均在官方支持清单内。
