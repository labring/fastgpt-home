# 信息流广告创意测试的运维值班与内部工单问答：重排与混合检索

## 这个品类的数据长什么样
该品类的数据主要来自广告投放平台、内部素材库、用户互动数据与转化数据，更新节奏多为日度或周度。日常产出的文档包含创意脚本、素材测试表、投放数据报告、迭代清单，字段涵盖素材类型、创意组合、投放时段、点击率、转化成本、测试结论等，单位涉及曝光量、点击量、转化量等指标。

## 这些特征在「重排与混合检索」这一环带来什么约束
该品类的数据分散于多个来源，混合检索需同时关联广告平台投放数据、素材库文件与用户互动记录，需配置跨源检索逻辑。日度或周度的更新节奏要求检索索引需定期同步，避免检索到过期的素材测试结果。文档字段包含创意组合、投放效果指标，重排环节需优先基于转化成本、点击率等业务相关字段排序，结合文本相似度辅助优化排序结果。创意测试的高时效性要求，需限制单次检索返回的有效结果数量，同时过滤存在违规风险的素材相关内容，防止影响投放效果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `usingReRank` | 开启 | 信息流创意测试需基于投放效果字段排序，重排可提升结果相关性，适配FastGPT v4.17.0的内置重排模型调用逻辑 |
| `similarity` | 0.65–0.75 | 过滤低相关的创意脚本与测试表，避免干扰有效检索结果，适配业务文档的文本特征 |
| `limit` | 前8–12条 | 创意测试的有效组合数量有限，过多结果会增加筛选成本，符合运维值班的快速定位需求 |
| `searchMode` | 混合检索 | 需同时检索素材库、投放数据与用户互动数据，覆盖全量业务文档 |
| 重排模型匹配字段 | 点击率、转化成本 | 匹配图片、视频、文案组合的业务特征，优先基于业务核心指标排序，贴合信息流创意测试的核心对比维度 |

## 容易做错的三处
- 现象：应用内开启重排模型后无检索结果，知识库单独测试时结果正常。原因：未配置跨源检索的关联字段，仅在知识库测试时加载了单源数据，应用调用时未正确关联广告平台与素材库数据。
- 现象：重排后返回的结果包含违规素材相关内容。原因：未在重排环节加入违规关键词过滤逻辑，导致低质量或违规创意组合被优先排序，可能引发投放风险。
- 现象：单次检索返回结果超出预期数量，导致运维值班时无法快速定位有效测试结论。原因：未限制`limit`参数的取值范围，返回了冗余的无效结果。

## 怎么确认配好了
- 进入FastGPT应用配置页，确认`usingReRank`开关处于开启状态。
- 模拟运维值班场景，输入“上周高转化创意组合”关键词，核对检索结果包含素材测试表与投放数据报告内容。
- 调整`similarity`参数取值，验证检索结果的相关性是否符合业务预期。
- 查看检索日志，确认`searchMode`为混合检索模式，同时调用了多源数据接口。
