# 内容审核规则运营的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自内容审核后台、用户举报渠道、公开法规政策、标注样本库四类来源。日常维护的文档包括审核规则条目、处置操作指南、申诉复核记录、质检复盘报告。数据更新随政策变更触发或每日同步，文档字段包含规则编号、生效时段、违规判定标准、样本标注标签等，基础单位为规则条目、记录条数与字符数。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源且高频更新的数据要求检索链路支持近实时同步，确保返回的规则与记录为当前生效版本。多样的文档结构需要适配不同长度的文本块，避免截断关键规则的生效条件或判定逻辑。字段中的生效时段要求检索时增加时间范围过滤，排除过期规则。样本库的标注数据需要精准匹配语义关联，避免误召回不相关的旧版样本，同时需覆盖规则的同义词与行业变体表述，提升疑难样本判定时的检索覆盖率。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 适配审核规则的精准匹配需求，过滤低相关的冗余结果，同时覆盖语义相近的规则表述 |
| `limit` | 前10条 | 控制返回结果数量，适配运维值班时快速查阅的场景，避免信息过载 |
| `searchMode` | semantic | 针对审核规则的逻辑关联，匹配规则解释与疑难样本的上下文关联，不局限于关键词匹配 |
| `usingReRank` | 开启 | 对初始召回结果进行重排序，优先返回高置信度的审核规则与处置指南 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户问题扩展相关关键词，覆盖审核规则的同义词与行业变体表述 |
| `collectionIds` | 按审核规则库、申诉记录库分别配置 | 精准定位该品类专属的知识库集合，避免混入其他品类的无关数据 |

## 容易做错的三处
- 现象：语义检索时，知识库里带有指定关键词的知识块未被召回。原因：未开启`datasetSearchUsingExtensionQuery`，或`similarity`阈值设置过高，过滤掉了语义匹配但关键词弱关联的规则条目。
- 现象：使用严格问答模板时，检索到知识库内的图片地址类内容，系统提示未找到答案。原因：严格问答模板仅支持文本型知识库内容，未配置图片内容的适配解析规则。
- 现象：API调用返回知识库检索失败，提示知识库id无效。原因：`collectionIds`参数配置错误，未使用该品类专属知识库的集合ID，或全局变量未正确绑定对应知识库。

## 怎么确认配好了
- 发起包含审核规则关键词的测试查询，核对返回结果是否包含当前生效的规则条目。
- 调整`similarity`阈值，观察召回结果的相关度变化，确认阈值适配业务需求。
- 调用API接口传入指定`collectionIds`，检查返回结果是否仅包含该品类的知识库内容。
- 切换严格问答模板与其他模板，验证图片地址类内容的检索结果是否符合预期。
