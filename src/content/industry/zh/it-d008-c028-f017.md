# 内容推荐运营的运维值班与内部工单问答：部署与升级

## 这个品类的数据长什么样
这个品类的数据通常来自内容标签库、用户行为日志、线上实验平台与推荐后台。日常产出的文档包含推荐策略记录、内容池清单、实验报告与运营复盘。数据更新节奏以日或周为单位，核心字段包括内容分类标签、用户交互指标、实验分组标识与推荐曝光量，需结合具体运营场景调整统计维度，无固定统一的口径。

## 这些特征在「部署与升级」这一环带来什么约束
内容推荐运营的数据来源分散且更新频繁，要求部署环节需适配多数据源的接入配置，避免因存储容量不足导致内容池同步中断。日常文档包含结构化策略记录与非结构化实验报告，部署时需配置兼容混合格式的解析参数。数据关联核心运营指标，升级环节需保证服务无感知切换，避免停机引发推荐策略中断。同时，运维值班与工单问答需实时关联数据状态，部署后需快速完成链路验证，确保异常排查响应及时。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本，适配内容推荐运营的业务场景：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150 个连接` | 适配内容池每日新增的大量数据连接请求，避免连接池耗尽影响内容同步 |
| `MONGODB_URI` | `mongodb://mongo:27017/fastgpt` | 存储内容标签、实验报告等非结构化数据的标准容器地址 |
| `REDIS_URL` | `redis://redis:6379/0` | 缓存用户行为日志与推荐策略缓存，降低数据库高频查询压力 |
| `FE_DOMAIN` | `https://internal-ops.your-domain.com` | 配置运维值班与内部工单问答的前端访问地址，确保通知可正常触达运营人员 |
| `FILE_TOKEN_KEY` | `32位随机字符串` | 加密内容池清单等敏感文档的访问令牌，防止未授权访问核心运营数据 |
| `AIPROXY_API_ENDPOINT` | `http://aiproxy:3000` | AI Proxy 服务的根地址，用于对接AI Proxy依赖服务 |
| `AIPROXY_API_TOKEN` | `与AI Proxy服务端配置一致的非空字符串` | AI Proxy 管理员 Token，用于App/Admin服务对接AI Proxy的鉴权 |

## 容易做错的三处
- 现象：使用docker-compose启动服务后启动失败，日志提示环境变量缺失。原因：未配置必填的`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`环境变量，未重建容器加载新配置，导致启动校验失败。
- 现象：离线部署后调用接口报错，提示无法找到cl100k.tiktoken文件。原因：未配置本地分词模型依赖，服务默认尝试从外网拉取文件，不符合离线部署的场景要求。
- 现象：内部工单问答无法响应推荐策略相关查询。原因：将AI Proxy管理员Token误填为应用API Key，导致接口鉴权失败，无法访问知识库中的内容池与实验报告数据。

## 怎么确认配好了
- 执行`docker logs fastgpt-app`查看启动日志，确认无环境变量缺失或鉴权失败的报错信息。
- 调用内部运维接口，传入合法的`AIPROXY_API_TOKEN`，验证工单问答模块可正常返回内容池清单相关数据。
- 访问配置的`FE_DOMAIN`地址，确认运维值班面板可正常加载并显示服务运行状态。
- 测试离线部署场景下的分词功能，确认无需外网连接即可正常加载本地依赖文件。
