# 办公系统流程配置的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的核心数据来自企业OA系统、组织架构库、内部制度文件及用户反馈工单。日常产出的文档包括流程配置单、审批节点表、表单字段说明与变更记录。数据更新随流程变更触发，常规更新频率为每月一次。数据结构以审批路径、权限规则、表单字段为核心字段，无统一固定单位，随具体配置项调整变化。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据分散于多个内部系统与文档，要求检索环节支持跨源关联召回，避免割裂的知识库结果。流程配置类文档以结构化规则为主，检索需精准匹配审批节点、权限字段与表单配置，模糊匹配易导致错误结果。数据更新随流程变更触发，常规每月更新，要求知识库同步机制适配非固定周期的增量更新。出错后果直接影响业务审批，因此检索召回的准确率需优先保障，避免返回无关的配置规则引发审批异常。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的知识库检索逻辑。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配办公流程配置的结构化规则，避免过低导致无关结果，过高遗漏有效配置 |
| `limit` | 前 8 条 | 覆盖常见审批节点与权限组合的配置项，避免返回过多冗余数据影响排查 |
| `searchMode` | 精准匹配 | 适配流程配置的结构化字段，优先匹配审批规则、节点名称等精确内容 |
| `usingReRank` | 开启 | 对召回结果按相关性重排，优化审批规则类内容的展示顺序 |
| `datasetSearchUsingExtensionQuery` | 开启 | 关联组织架构数据，补充用户所属部门对应的审批权限配置 |

## 容易做错的三处
- 现象为知识库检索耗时超过40秒，返回结果延迟明显。原因是未针对结构化的流程配置数据调整召回参数，同时跨源检索未优化关联逻辑。
- 现象为导入CSV格式的QA数据时，Q字段长度超过限制无法提交。原因是未调整知识库的单条文本长度阈值，默认限制与流程配置单的长文本不匹配。
- 现象为检索结果未包含最新的流程变更记录。原因是未配置按变更触发的增量同步机制，仍使用固定周期的全量更新。

## 怎么确认配好了
- 发起模拟运维工单，检索指定审批节点的配置内容，核对返回结果是否包含对应审批规则与权限说明。
- 触发一次流程变更后的知识库同步任务，验证新增的配置单是否能被精准检索到。
- 调整检索参数后，对比前后的返回结果条数与耗时，确认参数调整生效。
- 检查跨源关联的组织架构数据，确认检索结果中包含当前用户所属部门对应的审批权限配置。
