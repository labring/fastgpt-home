# 售前技术方案的运维值班与内部工单问答：权限与数据隔离

## 这个品类的数据长什么样
该品类的数据主要来自客户访谈、招标文件、厂商产品资料及历史项目方案，日常产出技术方案书、客户需求调研表、报价清单、演示脚本四类核心文档。数据更新以单项目为周期，每完成一轮需求澄清或报价调整即更新一次，单次更新覆盖单项目下的全量关联文档。文档结构按项目维度组织，包含项目编号、客户名称、技术路线、报价明细等字段，部分文档关联内部运维工单的进度节点，用于值班人员跟进售前项目的落地准备。

## 这些特征在「权限与数据隔离」这一环带来什么约束
由于该品类的数据按单项目组织且关联内部运维工单，需严格按项目与团队划分权限边界，避免跨项目的售前方案、报价等敏感信息泄露。因数据更新频率为每单/周，权限配置需支持动态调整，随项目文档的更新同步更新权限范围。不同售前角色的信息访问需求存在差异，需区分字段级权限，例如销售仅可查看报价清单，技术顾问可访问完整技术方案。此外，免登陆演示链接的场景下，需限制链接绑定的项目范围，防止非授权人员访问特定项目的机密文档。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `teamId` | 绑定当前售前项目的团队ID | 按项目团队隔离数据，确保仅授权团队成员可访问对应项目的售前文档 |
| 免登陆链接绑定范围 | 仅关联当前项目的文档ID | 限制免登陆链接只能访问对应项目的售前方案，避免跨项目数据泄露 |
| 角色权限分组 | 按售前角色配置字段权限，销售仅可见报价清单 | 区分不同售前角色的信息访问边界，匹配日常工作的信息查看需求 |
| `tmbId` | 绑定内部运维工单的团队标识 | 关联运维值班的工单权限，确保值班人员仅能访问对应工单的关联售前文档 |
| 免登陆链接数量上限 | 团队版默认10个，可调整至100个 | 匹配不同售前项目的演示需求，支持按需调整链接创建数量 |
| 权限过期时间 | 7天 | 适配售前演示的临时访问需求，避免长期有效链接带来的信息安全风险 |

## 容易做错的三处
- 现象：界面提示“没有权限操作此对话记录”，原因：未将当前操作用户的`teamId`绑定到对应售前项目的团队ID，导致权限校验逻辑未匹配到授权范围。
- 现象：免登陆链接无法访问指定的售前文档，且提示链接数量超限，原因：未按项目订阅套餐的配置调整免登陆链接数量，或链接未绑定当前项目的文档ID。
- 现象：跨项目的售前方案被非授权团队成员访问，原因：未按项目维度配置`teamId`绑定规则，导致团队权限覆盖范围超出当前售前项目的边界。

## 怎么确认配好了
- 登录FastGPT v4.17.0后台的权限管理页面，查看`teamId`绑定的项目列表，确认当前售前项目的团队ID已正确关联到对应角色。
- 创建一条免登陆链接，测试仅能访问当前项目的售前文档，无法打开其他项目的技术方案或报价清单。
- 切换至销售角色的测试账号，确认仅能查看报价清单字段，无法访问技术方案书的详细技术路线内容。
- 查看免登陆链接的管理界面，确认可根据需要调整链接数量至套餐允许的上限值。
