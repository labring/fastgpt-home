# 备份恢复与灾备演练的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据来源包括备份系统、数据库日志、对象存储、灾备平台。日常文档涵盖备份策略、恢复演练报告、灾备切换预案、数据校验记录，包含备份任务ID、恢复点目标、演练执行时间、数据一致性校验结果等字段。数据更新节奏分为日、月、季三类，其中备份任务日志按日更新，演练报告按月归档，长期校验记录按季留存。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源数据来源要求检索需覆盖不同格式与存储位置的文档，需配置跨源同步规则；不同更新频率要求分批次设置同步任务，避免全量同步占用资源。文档包含结构化的任务字段与非结构化的预案文本，需兼顾关键词与语义检索的适配性。表格、图片较多的文档存在一定占比，需优化分块逻辑以保留结构化信息。最耗时的恢复点确认、演练脚本执行等环节的内容需被精准召回，因此检索阈值需严格匹配业务场景的相关性要求。

## 配置怎么定
本文基于 FastGPT v4.17.0 版本编写，以下为适配本品类的配置方案：
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `similarity` | 0.75–0.85 | 过滤低相关性内容，确保召回的文档与备份恢复、灾备演练强相关 |
| `limit` | 前3–5条 | 控制返回结果数量，适配运维值班时快速浏览多份参考文档的需求 |
| `searchMode` | hybrid | 结合关键词与语义检索，覆盖备份策略中的任务编号、演练报告中的校验结果等混合内容 |
| `usingReRank` | 开启 | 对初始召回结果重排序，提升恢复点确认、数据一致性核验相关内容的优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动优化工单问题，扩展匹配备份策略、灾备预案的相关查询词 |
| `collectionIds` | 绑定备份恢复专属知识库集合 | 限定检索范围，避免混入其他运维类文档，提升精准度 |

## 容易做错的三处
- 现象：仅返回1条知识库匹配结果。原因：`limit`参数被设置为1，未适配备份恢复场景下需要多份参考文档的需求。
- 现象：导入的Word文档中表格、图片内容识别效果差。原因：未针对结构化文档调整分块规则，默认分块逻辑未保留表格、图片的结构化信息。
- 现象：无法在对话过程中手动选择目标知识库。原因：未配置多知识库绑定的工作流节点，仅锁定了单一备份恢复知识库集合。

## 怎么确认配好了
- 发起包含“恢复演练步骤”的测试查询，检查返回结果的条数是否符合`limit`参数的设置。
- 上传一份包含表格的备份策略文档，检索后查看召回内容是否包含表格的结构化信息。
- 配置多知识库绑定逻辑后，发起测试查询，确认界面可展示知识库选择下拉框并支持手动切换。
- 查看检索日志，确认召回结果的相似度得分在`similarity`参数设置的区间内。
