# 安全培训与钓鱼演练的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的核心数据来自员工通讯录、邮件网关、内部培训平台与用户点击统计系统。日常产出的文档包含标准化培训课件、钓鱼演练执行方案、批量钓鱼邮件模板、演练结果复盘报告。数据更新节奏多为季度或年度，文档结构多为带固定字段的汇报类、模板类文件，部分模板类文档存在固定格式的参数占位项，用于适配不同演练场景的个性化配置。

## 这些特征在「知识库检索与召回」这一环带来什么约束
由于数据来源分散且包含跨系统的员工属性、邮件行为数据，知识库召回需支持跨数据集关联查询，避免仅检索单类文档导致的信息缺失。文档类型涵盖模板类与复盘报告类，部分模板存在固定占位符，需配置检索时忽略无意义占位符的匹配逻辑，避免过滤有效模板内容。季度级的更新频率意味着无需高频增量同步，但需支持按演练场景、培训周期做精准过滤。演练人群筛选依赖员工通讯录字段，检索环节需关联人员部门、岗位等属性维度，缩小召回范围以提升查询效率。

以下配置基于FastGPT v4.17.0版本。
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 适配钓鱼邮件模板的文本相似度匹配，避免误匹配占位符或低相关的培训课件 |
| `limit` | 前8条 | 兼顾演练方案与复盘报告的召回数量，覆盖单次运维值班的查询需求 |
| `searchMode` | hybrid | 结合关键词与语义检索，适配模板类文档的固定字段与语义化查询 |
| `usingReRank` | 开启 | 提升钓鱼邮件模板与演练结果报告的排序精准度，过滤无关的培训课件 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展员工通讯录与点击统计的关联查询，支持演练人群筛选的检索需求 |
| `collectionIds` | 按场景绑定对应数据集 | 区分培训课件、演练方案、邮件模板的数据集，避免跨品类文档干扰召回 |

## 容易做错的三处
- 检索返回结果条数不足且包含大量无关文档，页面显示结果与查询主题匹配度低。原因：未通过`collectionIds`限定检索范围，召回了其他业务线的非安全培训类数据集文档。
- 查询钓鱼邮件模板优化建议时，系统无法关联员工通讯录数据，无法完成人群筛选相关的检索。原因：未开启`datasetSearchUsingExtensionQuery`，未配置跨数据集的关联查询逻辑。
- 上传Excel格式的演练结果报告后，检索效果不佳，无法提取表格内的结构化数据。原因：未针对表格结构化数据配置合理的分块规则，直接按整表上传导致语义分割不清晰，向量匹配精度不足。

## 怎么确认配好了
- 执行针对钓鱼邮件模板的查询，核对返回结果是否仅包含预设的安全培训类数据集文档。
- 触发包含员工岗位信息的查询，确认召回结果是否关联了对应部门的演练方案。
- 调整`similarity`阈值，验证召回结果的关联度是否符合业务场景的匹配要求。
- 上传包含图片的测试文档，确认检索时是否正确提取图片内的文字内容。
