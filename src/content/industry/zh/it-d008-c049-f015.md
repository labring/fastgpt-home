# 客户培训与使用手册的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
本品类数据主要来自产品帮助中心、客户组织架构、培训录屏与工单系统。日常文档包含培训课件、用户手册、培训签到表与问题答疑清单。数据更新节奏为每单或每版本迭代。文档结构多包含角色权限说明、操作步骤拆解、常见问题条目，部分文档带有表格与图片素材，字段涵盖培训主题、操作节点、权限范围与工单关联标识。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散且更新频率随业务迭代波动，需适配多格式文档的召回逻辑。培训课件与用户手册多包含长文本操作步骤，需优化分块规则避免语义割裂。带表格图片的文档识别效果易受格式影响，需针对性调整召回匹配规则。工单系统关联的答疑清单需按工单优先级关联检索，同时需区分内部运维与客户侧的权限字段，避免跨角色信息泄露。通常需兼顾内部运维值班场景与客户培训场景的检索需求，确保返回内容符合对应角色的访问权限。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的知识库检索与召回逻辑制定。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 适配带操作步骤的长文本匹配，避免低相关结果混入 |
| `limit` | 前6–8条 | 匹配培训课件与用户手册的单页内容量，控制上下文长度 |
| `searchMode` | hybrid | 兼顾关键词匹配与语义召回，适配多格式文档的混合检索需求 |
| `usingReRank` | 开启 | 优化带表格图片的文档召回排序，提升高相关内容的展示优先级 |
| `datasetSearchUsingExtensionQuery` | 关闭 | 避免生成非知识库内的AI问题，贴合品类的固定答疑清单需求 |
| `collectionIds` | 按培训场景分组配置 | 区分内部运维与客户培训的知识库权限，匹配业务数据的分组逻辑 |

## 容易做错的三处
- 导入的带表格图片的文档检索结果缺失或匹配度低，原因是未开启`usingReRank`或未调整匹配规则适配格式差异。
- 检索时推荐的关联问题未命中知识库内的答疑清单，原因是开启了`datasetSearchUsingExtensionQuery`生成扩展问题，偏离了固定答疑的需求。
- 对话中无法实时切换对应场景的知识库，原因是未配置`collectionIds`的动态绑定逻辑，仅固定绑定单一场景的知识库集合。

## 怎么确认配好了
- 上传带表格图片的培训文档，发起包含操作步骤的查询，核对返回结果是否包含文档内的具体操作内容与表格信息。
- 发起包含角色权限说明的查询，核对返回结果是否仅包含对应权限范围内的文档内容，无跨角色信息泄露。
- 测试切换不同培训场景的知识库分组，核对检索结果是否匹配当前选择的`collectionIds`对应知识库。
- 查看检索推荐的关联问题，核对是否均来自知识库内的答疑清单条目，无AI生成的无关问题。
