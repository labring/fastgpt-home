# 广告素材审核的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
广告素材审核的核心数据来自广告投放平台、落地页资源、商品资质文件及通用广告法合规条款。日常处理的文档包含单条广告素材文案、落地页截图、历史审核意见、素材修改记录等。数据更新频率为日级或实时，随广告投放计划调整或合规条款更新同步变化。单条审核任务关联的文档类型多样，需覆盖投放内容、合规依据、历史处理结果三类核心信息。本场景适配 FastGPT v4.17.0 版本。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源数据来源要求检索系统支持跨格式文档的统一索引，避免因文档类型差异导致合规条款或审核记录召回缺失。实时/日级更新要求知识库支持增量同步，确保最新的合规条款与素材修改记录可被快速检索。文档类型多样的特征要求检索逻辑兼顾语义关联与精确关键词匹配，既要识别违规文案的语义意图，也要匹配具体的合规条款或审核意见中的修改要求。高风险的出错后果要求检索结果具备较高置信度，需严格限制无关内容的召回比例，避免误导审核决策。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 广告素材审核需精准匹配合规条款与违规内容，该区间可过滤低相关度的无关结果 |
| `limit` | `前8条` | 单条审核任务的上下文长度需控制在合理范围，避免超出模型处理上限 |
| `searchMode` | 语义检索+关键词混合 | 兼顾广告文案的语义意图匹配与合规条款的精确关键词匹配需求 |
| `usingReRank` | 开启 | 对初始召回结果做二次排序，优先展示与违规点标注、合规依据直接相关的内容 |
| `datasetSearchUsingExtensionQuery` | 开启 | 将审核员的提问扩展为合规相关的查询词，提升历史审核记录的召回精准度 |
| `collectionIds` | 绑定广告素材审核专属集合ID | 隔离不同业务场景的知识库，避免跨品类的审核数据干扰检索结果 |

## 容易做错的三处
- 误将非专属集合ID填入`collectionIds`配置项，现象是检索结果中混入开户审核或其他业务的文档内容，原因是未按业务场景隔离知识库集合。
- 未配置`similarity`阈值或阈值设置过低，现象是与广告合规无关的提问仍触发知识库检索并返回相关结果，原因是未设置最低相关度限制过滤无关内容。
- 未启用`datasetSearchUsingExtensionQuery`且未调整内容优先级规则，现象是历史审核意见中的修改记录等辅助数据未被优先召回，原因是未扩展查询范围覆盖辅助文档的关联信息。

## 怎么确认配好了
- 上传广告素材、审核意见等专属文档，检查是否自动归入配置的专属集合，确认`collectionIds`绑定正确。
- 输入与广告合规无关的测试问题，验证是否触发预设的非知识库回复，确认`similarity`相关限制配置生效。
- 输入包含违规关键词的审核问题，检查召回结果是否优先展示合规条款与历史审核记录，确认`usingReRank`与检索模式配置生效。
- 查看检索返回的结果条数，确认符合`limit`配置的数量要求，验证检索上限设置正确。
