# 广告素材审核的运维值班与内部工单问答：部署与升级

## 这个品类的数据长什么样
本品类的数据核心为广告素材审核相关文档，来源包括广告投放平台、落地页存储服务、商品资质备案系统及公开合规条款。日常流转的文档包含待审核广告素材文件、落地页截图、审核人员出具的整改意见、素材修改迭代记录。数据更新节奏为日更或实时同步，单条审核数据包含素材标识、违规类型标注、审核时间戳、关联投放账户等字段，无额外自定义统计字段。

## 这些特征在「部署与升级」这一环带来什么约束
广告素材审核的实时/日更数据特性要求部署时需适配高频读写的存储配置，避免因存储吞吐量不足导致审核工单积压，进而影响投放合规进度。多来源的异构数据（文件、文本、结构化字段）要求部署时配置兼容多类型存储的参数，确保不同格式的审核数据可正常写入与读取。审核数据关联投放账户与合规条款的特性，要求升级过程中需保留历史审核关联关系，避免因版本升级导致历史工单数据丢失或关联断裂，引发广告投放违规风险。同时，实时更新的审核数据要求升级窗口需避开业务高峰时段，减少对日常审核流程的影响。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MONGODB_URI` | `mongodb://username:password@mongodb:27017/fastgpt?authSource=admin` | 适配广告素材审核的多工单、多文档存储需求，确保高并发读写稳定性 |
| `REDIS_URL` | `redis://:redis_password@redis:6379/0` | 用于缓存高频访问的合规条款与审核规则，降低数据库查询压力 |
| `DB_MAX_LINK` | `200–300` | 匹配广告素材审核场景下的并发工单处理需求，避免连接池耗尽导致请求超时 |
| `FE_DOMAIN` | `https://your-fastgpt-domain.com` | 用于生成审核工单的访问链接与回调地址，确保内部运维人员可正常访问工单页面 |
| `STORAGE_S3_ENDPOINT` | `http://s3-endpoint:9000` | 用于存储落地页截图、广告素材文件等二进制数据，适配多类型审核附件的存储需求 |

## 容易做错的三处
- 现象：部署后启动校验失败，提示缺少`AIPROXY_API_ENDPOINT`（AI Proxy服务的根地址，不得附加/v1等路径，非单模型地址）或`AIPROXY_API_TOKEN`（AI Proxy管理员Token，与AI Proxy服务端配置一致且不能为空，非应用API Key、模型供应商密钥等）配置。原因：未在App/Admin服务端的环境变量中配置这两个必填项，或误将其填写在工作流全局变量、模型管理页面、应用API请求头中替代服务部署配置。
- 现象：Linux服务器部署时镜像拉取失败，提示网络超时或镜像不存在。原因：未配置正确的容器镜像仓库地址，或服务器未开通访问官方镜像源的权限。
- 现象：升级到FastGPT v4.17.0后，导入插件时提示internal server error。原因：升级过程中未正确迁移数据库索引或缓存配置，导致插件加载时无法读取必要的元数据。

## 怎么确认配好了
- 检查App/Admin服务端部署配置的环境变量，确认`AIPROXY_API_ENDPOINT`（AI Proxy服务的根地址，不得附加/v1等路径，非单模型地址）和`AIPROXY_API_TOKEN`（AI Proxy管理员Token，与AI Proxy服务端配置一致且不能为空，非应用API Key、模型供应商密钥等）已正确配置且非空。
- 执行服务启动校验脚本，检查数据库、Redis、AI Proxy的连通性是否正常。
- 提交一条测试广告素材审核工单，确认工单可正常创建、存储与查询。
- 查看服务日志，确认无配置项缺失或连接超时的报错信息。
