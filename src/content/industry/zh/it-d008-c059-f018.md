# 广告素材审核的运维值班与内部工单问答：重排与混合检索

## 这个品类的数据长什么样
广告素材审核场景的数据来源包括广告平台投放素材、落地页截图、商品资质文件、广告法合规条款，更新频率为日级或实时。日常处理的文档包含单条广告素材内容、落地页校验记录、审核人员出具的违规整改意见、历史工单修改记录。数据字段覆盖素材文案、落地页合规性标记、违规点描述、整改要求等，无统一固定的单位体系，需根据不同来源文档适配解析规则。

## 这些特征在「重排与混合检索」这一环带来什么约束
多源异构的数据来源要求混合检索需适配不同格式的文档内容，确保广告平台素材、合规条款、历史工单等数据均可被有效召回。实时或日级的更新节奏要求检索与重排流程需具备较低的延迟，避免影响运维值班人员的实时审核效率。逐条审核的业务模式要求重排环节优先关联与当前素材违规风险直接相关的内容，减少无关信息的干扰。同时，出错后果的严重性要求检索与重排的结果需具备较高的精准度，避免遗漏关键合规依据或引入误导性内容。运维值班与工单问答的场景还要求检索结果需快速关联历史审核记录与合规条款，缩短问题排查时长。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 重排开关 | 开启 | 广告素材审核需精准匹配违规相关内容，重排可提升结果相关性 |
| 相似度阈值 | 0.75–0.80 | 过滤低相关的非违规内容，避免干扰审核判断 |
| 单次召回上限 | 前10条 | 平衡检索效率与召回覆盖范围，适配单条素材审核的信息需求 |
| 检索模式 | 混合检索 | 需整合广告平台素材数据、广告法合规条款、历史审核工单等多源数据 |
| 重排模型显存释放 | 检索完成后自动卸载 | 避免检索后重排模型持续占用显存，缓解运维服务器压力，适配FastGPT v4.17.0版本的显存管理规则 |
| 问题优化开关 | 开启 | 优化用户工单的检索意图，提升多源数据的匹配精准度 |

## 容易做错的三处
- 现象：重排模型在检索完成后持续占用服务器显存，未自动释放。原因：未配置检索完成后自动卸载重排模型的规则，导致显存资源被长期占用。
- 现象：开启问题优化与结果重排后，审核工单响应时长超过30秒。原因：单次召回上限设置过高，或重排模型选型未适配轻量化部署，导致处理延迟超出业务要求。
- 现象：在线召回测试时未显示重排后的结果，配置项显示已开启重排。原因：未将混合检索模式与重排功能绑定，或未在知识库索引阶段同步开启重排关联配置。

## 怎么确认配好了
- 查看服务器显存监控面板，确认检索完成后重排模型的显存占用是否自动释放。
- 发起单条广告素材的审核工单测试，核对响应时长是否符合业务预期阈值。
- 在线召回测试中，对比开启与关闭重排后的结果排序，确认重排逻辑已生效。
- 检查知识库索引配置页面，确认混合检索模式与重排功能已同步开启。
