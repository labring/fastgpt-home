# 广告账户开户审核的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的核心数据来自广告平台后台、国家企业信用信息公示系统、客户提交的申请材料与行业准入规则。日常处理的文档包含开户申请单、企业营业执照扫描件、对应行业的经营资质文件、历史开户审核记录。数据更新节奏为每日批量同步或随单提交即时更新，文档多为结构化表单与非结构化图文混合格式，字段包含主体名称、统一社会信用代码、投放行业类目、审核节点状态等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散且格式混合，要求检索环节同时支持结构化字段匹配与非结构化图文语义召回。随单提交的即时更新需求，要求召回链路支持低延迟的增量同步。多份资质文件的关联核验需求，要求召回结果按申请单维度聚合，返回关联的全套材料。审核记录的历史数据占比高，要求召回时优先匹配最新的准入规则与历史合规案例。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.72–0.80 | 匹配资质类文档的语义相似度阈值，平衡常规审核场景的精准度与召回率 |
| `limit` | 前8条 | 限制单次召回的文档数量，适配单开户申请的关联材料总量 |
| `searchMode` | hybrid | 混合检索模式，兼顾结构化字段匹配与非结构化语义召回 |
| `usingReRank` | 开启，重排后取前5条 | 对召回结果重排，优先返回与审核规则强相关的文档 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于原问题扩展查询词，补充行业准入相关的潜在匹配项 |
| `collectionIds` | 指定审核专属数据集ID | 限定检索范围，排除非关联的业务文档 |

## 容易做错的三处
- 现象：上传营业执照、开户申请等文件时提示上传失败，部分场景返回400状态码。原因：未配置数据集允许的上传文件格式与单文件大小阈值，或文件包含不支持的编码格式。
- 现象：提问行业准入规则时，召回的文档内容输出不全，核心审核条款缺失。原因：未启用分段增强处理，或分段长度设置不合理导致长文档被截断后丢失关键信息。
- 现象：批量处理开户申请时，检索响应超时，服务器硬盘IO占用持续偏高。原因：未限定检索的数据集范围，召回了大量非关联的历史审核记录，或未开启重排环节导致冗余结果过多。

## 怎么确认配好了
- 上传一份测试用的营业执照与开户申请单，确认文件可正常上传并存入指定数据集。
- 输入模拟的审核问题，检查召回结果的数量是否符合预设的`limit`取值，相似度是否落在0.72–0.80区间内。
- 开启重排功能后，核对召回结果的排序是否优先返回与当前审核场景强相关的文档。
- 查看数据集的配置页面，确认`collectionIds`已绑定当前审核专属的数据集，未包含无关业务文档。
