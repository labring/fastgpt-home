# 投放效果优化的运维值班与内部工单问答：部署与升级

## 这个品类的数据长什么样
该品类的数据主要来自广告平台接口、归因系统、CRM线索库与落地页统计工具。数据更新节奏分为实时（如实时曝光、点击数据）与日更（如单日转化、获客成本报表）。日常产出的文档包含投放日报周报、关键词调价记录、素材A/B测试表、优化效果复盘报告，字段包含曝光量、点击量、转化数、预算额度、素材点击率等，单位涉及次、元、%等。

## 这些特征在「部署与升级」这一环带来什么约束
多数据源接入需求要求部署时配置稳定的跨系统连接参数，保障广告平台、归因系统等数据源的正常拉取。实时数据的更新节奏要求部署时调整向量索引的刷新阈值，避免数据滞后影响优化判断。日常文档包含表格类的调价记录、素材测试表，需适配多格式文件的解析配置，保障知识库训练的完整性。运维值班与工单场景需配置权限隔离规则，区分优化师、分析师等不同角色的访问范围，升级过程需保障实时数据链路不中断，防止投放调整出现延迟。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MONGODB_URI` | `mongodb://username:password@host:port/dbname?authSource=admin` | 存储投放历史数据、工单记录与知识库文档，需保障高可用连接 |
| `REDIS_URL` | `redis://:password@host:port/0` | 缓存实时投放数据、会话上下文与工单状态，建议设置超时时间为300秒 |
| `STORAGE_S3_ENDPOINT` | 按本地对象存储服务地址填写，如`http://192.168.1.100:9000` | 存储素材文件、报表文档等知识库上传资源，适配多格式文件的读取需求 |
| `FILE_TOKEN_KEY` | 随机生成的32位字符串 | 加密文件上传的校验令牌，防止未授权的知识库文件提交 |
| `ROOT_KEY` | 自定义复杂字符串 | 配置系统最高权限访问密钥，用于运维场景的后台操作与工单审核 |
| `FE_DOMAIN` | 部署服务的公网或内网域名，如`http://fastgpt.example.com` | 配置前端访问地址，保障内部工单与知识库的正常跳转 |

## 容易做错的三处
- 上传知识库文件后数据处理为空。原因是未正确配置`STORAGE_S3_ENDPOINT`或本地存储路径权限不足，导致文件解析时无法读取上传的素材测试表、调价记录等文档。
- 本地运行向量索引正常，Docker打包镜像后向量得分一致。原因是未同步配置`REDIS_URL`与`MONGODB_URI`的环境变量，导致容器内无法读取缓存的实时投放数据，向量计算依赖的数据源缺失。
- 调用本地大模型后首次回答正常，后续含多轮上下文的对话报错。原因是未调整`REDIS_URL`的会话超时配置，默认超时时间过短导致上下文缓存被提前清除，无法加载历史对话与投放数据。

## 怎么确认配好了
- 执行知识库文件上传测试，上传一份调价记录表格，查看数据处理进度是否在120秒内完成并生成向量索引。
- 启动多轮对话测试，输入连续3条包含不同投放指标的问题，确认会话上下文可正常加载且回答关联对应数据。
- 检查`REDIS_URL`的连接状态，通过运维工具查看缓存的会话数量与过期时间是否符合配置要求。
- 验证工单系统的权限隔离，使用不同角色的密钥尝试访问敏感的预算调整工单，确认无权限的角色无法查看对应内容。
