# 投放效果优化的运维值班与内部工单问答：重排与混合检索

## 这个品类的数据长什么样
这个品类的数据主要来自广告平台后台、归因分析系统、CRM线索库与落地页数据采集模块。日常处理的文档包含每日投放效果日报、周度预算复盘报告、单次素材的调价记录、多轮素材测试对比表以及优化策略复盘笔记。数据更新节奏多为日级批量同步，核心投放指标的实时数据会按分钟级推送。文档字段包含曝光量、点击量、转化数、单次获客成本、素材点击率等，单位多为次、元、百分比。

## 这些特征在「重排与混合检索」这一环带来什么约束
该品类的数据来源分散且类型多样，混合检索需要同时召回广告平台后台数据、归因分析记录与内部业务文档，因此需要明确不同数据源的召回优先级。数据更新节奏包含日级批量同步与分钟级实时推送两类，检索范围需支持按时间区间筛选，避免引入过期的历史数据。日常文档的结构差异较大，从简短的单次调价记录到长篇的周度复盘报告均有覆盖，重排模型需要适配不同长度的输入内容。核心投放指标的异常定位需要快速匹配高相关内容，因此检索结果的排序逻辑需优先关联投放效果相关的字段，提升异常指标定位的准确性。

## 配置怎么定
本文档基于FastGPT v4.17.0版本编写，以下配置项均基于官方指定参数设置：
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `usingReRank` | 开启，对输入文本长度≥800字符的检索请求自动触发 | 适配该品类长短不一的文档类型，避免短文本调用重排模型浪费资源，长文本则通过重排提升排序精准度 |
| `similarity` | 取值区间为0.65–0.80 | 匹配该品类核心投放指标的语义相关性，避免召回无关的历史记录或低相关的素材测试数据 |
| `limit` | 前10条召回结果 | 控制单次检索返回的结果数量，适配运维值班与工单问答的快速定位需求，避免过多结果干扰异常指标排查 |
| `searchMode` | 混合召回模式，整合广告平台数据与内部业务文档 | 适配该品类多源数据的检索需求，覆盖广告平台实时数据与内部复盘笔记等不同类型的内容 |

## 容易做错的三处
- 现象：自定义重排模型的API地址填写无误，但检索后返回的结果未经过重排，排序与初始召回结果一致。原因：未开启`usingReRank`配置项，或触发重排的文本长度阈值设置过高，未匹配当前检索内容的实际长度。
- 现象：使用Qwen3-Reranker-8B模型时，界面显示模型加载成功，但检索时返回重排结果为false。原因：未在模型配置中正确映射模型的输入输出格式，导致FastGPT无法解析重排后的结果。
- 现象：检索包含多页文档的长内容时，重排模型未被调用，仅返回初始召回的前N条结果。原因：未针对长文本场景配置重排触发规则，FastGPT默认仅对短文本触发重排。

## 怎么确认配好了
- 查看FastGPT的检索日志，确认重排模型的调用记录，检查是否有成功的请求与响应。
- 手动输入包含投放指标的查询词，对比开启与关闭重排功能后的检索结果排序差异。
- 调整检索内容的长度，验证当文本长度达到设定阈值时，重排模型是否被触发。
- 检查自定义重排模型的API配置，确认请求地址与参数格式与模型部署要求一致。
