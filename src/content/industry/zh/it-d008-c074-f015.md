# 文本标注项目的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
文本标注项目的日常文档包含标注规范、样本包、质检报告与问题反馈表，数据主要来自客户提供的语料、内部标注平台产出内容、专用词表以及质检抽样结果。数据更新频率多为每日或每批标注任务完成后，核心文档围绕语义边界、实体识别与意图分类展开，字段涵盖标注标签、样本内容、质检评分与问题记录，整体围绕标注全流程的标准化与质量管控要求生成。

## 这些特征在「知识库检索与召回」这一环带来什么约束
标注规范、样本包等文档结构差异较大，既有结构化的质检报告字段，也有非结构化的样本文本，要求检索需适配混合格式内容；数据按批或日更新，需支持增量召回逻辑以匹配最新标注结果；标签边界解释、疑难样本相关的查询占比高，需优先召回语义匹配度高的标注规则与历史仲裁案例；出错后果直接关联模型训练与交付进度，要求检索结果的准确性需严格匹配标注团队的业务逻辑，避免召回无关内容干扰值班人员决策。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 适配文本标注场景下语义边界、实体识别的精准匹配需求，避免召回低相关的非标注类文档 |
| `limit` | 前6条 | 适配运维值班与工单问答的快速决策场景，控制单次返回结果的信息量 |
| `searchMode` | 语义优先 | 优先匹配标注规范、样本内容的语义关联，不局限于关键词匹配 |
| `usingReRank` | 开启 | 对初始召回结果进行二次排序，提升疑难样本仲裁、一致性抽检相关内容的展示优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展标注相关的同义词与行业术语，覆盖专用词表中的边缘术语 |
| `collectionIds` | 指定当前标注项目的专属数据集ID | 隔离不同标注团队的文档，避免检索结果混入无关项目的标注数据 |

## 容易做错的三处
- 现象：调试预览阶段知识库检索结果正常，部署到自有页面后无法触发检索。原因：页面集成时未正确指定标注项目专属的`collectionIds`，导致检索指向了错误的数据集。
- 现象：云版知识库中上传的标注样本相关图片无法正常加载。原因：导入的Markdown文件或文档中使用了内部私有网络的图片链接，未配置符合平台要求的公开访问权限，导致检索时无法正常拉取资源。
- 现象：检索标签边界解释相关的工单问题时，召回结果覆盖不全。原因：未开启`datasetSearchUsingExtensionQuery`，无法自动扩展标注专业术语的同义词，导致部分语义相似的文档未被召回。

## 怎么确认配好了
- 登录FastGPT v4.17.0后台，进入标注项目专属数据集页面，手动发起检索测试，核对返回结果是否包含标注规范、样本包等目标文档。
- 模拟运维值班场景，输入包含“标签边界”“疑难样本”的查询语句，检查召回结果的排序是否符合业务优先级。
- 部署测试页面，发起检索请求，核对返回结果的数量是否与配置的`limit`参数匹配。
- 检查集成代码中是否正确绑定了当前标注项目的`collectionIds`，避免跨项目数据混淆。
