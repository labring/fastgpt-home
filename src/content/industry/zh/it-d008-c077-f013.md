# 机房巡检与环境监控的运维值班与内部工单问答：权限与数据隔离

## 这个品类的数据长什么样
这个品类的日常数据包含巡检表、温湿度记录、告警记录、值班日志四类，数据来源为动环监控系统、门禁系统、UPS监控设备与视频巡检工具。数据更新节奏分为实时与按日两类，实时数据如告警信息、温湿度数值由采集设备直接推送，值班日志与巡检表按每日交接班周期更新。数据字段包含设备ID、温湿度数值（单位为℃与%RH）、告警等级、设备物理位置、值班人员ID与时间戳，不同来源的数据字段存在明确的分类边界。

## 这些特征在「权限与数据隔离」这一环带来什么约束
多源异构的数据来源要求权限隔离需匹配不同系统的归属范围，避免跨系统越权访问。实时更新的告警与温湿度数据需要权限配置即时生效，否则可能导致异常未被对应团队及时处理。巡检记录与值班日志包含敏感的物理位置与人员信息，需按负责区域与班次进行细粒度权限管控。内部工单需关联对应机房的运维团队，确保工单仅在负责该区域的人员间流转。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `teamId`绑定规则 | 按机房区域分配唯一`teamId`，如A机房组、B机房组 | 匹配巡检数据按区域分类存储的特征，确保不同区域的运维团队仅访问对应数据 |
| `tmbId`权限分组 | 按值班班次分配`tmbId`，如早班组、晚班组 | 适配值班日志按班次分类的特征，确保不同班次的人员仅访问对应班次的日志 |
| 数据字段过滤 | 仅开放温湿度（℃）、告警等级、设备ID字段 | 符合巡检记录的敏感字段管控需求，隐藏设备物理位置等非必要信息 |
| 实时数据源权限 | 与动环监控、UPS监控的数据源绑定`teamId` | 适配实时数据的更新特性，确保权限配置即时生效 |
| 工单权限关联 | 绑定值班日志的`tmbId`与对应运维班组 | 确保内部工单仅对负责对应机房与班次的人员可见 |
| 权限生效时效 | 不超过600秒 | 适配实时告警数据的处理节奏，避免权限滞后导致的异常未及时响应 |

## 容易做错的三处
- 现象：配置`teamId`绑定数据源后，部分巡检数据无法被对应团队访问；原因：未将动环监控、UPS监控的数据源与`teamId`正确关联，导致权限映射失效。
- 现象：添加自定义数据源后，工作流中无法显示对应巡检数据的输入参数；原因：未配置`teamId`与数据源的绑定关系，权限校验不通过导致参数未加载。
- 现象：跨班次的运维人员能查看其他班次的值班日志；原因：未按`tmbId`分配班次权限，导致权限分组混乱。

## 怎么确认配好了
- 登录对应`teamId`的账号，检查是否仅能查看负责机房的温湿度、告警记录，无法访问其他区域的数据。
- 登录对应`tmbId`的账号，检查是否仅能查看对应班次的值班日志，无法访问其他班次的记录。
- 触发一条测试告警，确认仅负责对应机房与班次的运维人员能收到内部工单通知。
- 修改权限配置后，等待不超过600秒的生效时效，验证数据访问权限是否按预期更新。
- 查看FastGPT v4.17.0的数据源绑定日志，确认`teamId`与`tmbId`和动环监控、门禁系统的关联关系正常。
