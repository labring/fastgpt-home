# 机柜上架与布线的运维值班与内部工单问答：部署与升级

## 这个品类的数据长什么样
该品类的典型使用主体为IDC运维工程师、网络工程师与设备实施人员，日常涉及的文档包括上架申请、机柜布线图、端口标签表、施工记录。数据主要来源于DCIM系统、资产系统、网络拓扑与客户工单，更新频率为每单或每日。字段通常包含U位编号、线缆长度（米）、端口标识、施工时间等，不同文档的结构差异明显，结构化工单与非结构化图纸需分别处理。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据来源分散且包含异构系统，部署时需配置多数据源连接参数，确保稳定拉取机位、端口等核心数据；由于文档类型多样，需适配结构化工单与非结构化图纸的解析与存储，因此需要配置文件访问与存储相关参数；由于更新频率较高，需合理设置数据库连接池大小，避免连接耗尽影响工单同步；由于出错后果可能导致端口接错、客户开通延期，升级时需开启配置校验逻辑，防止参数错误引发业务异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 10–20 个 | 适配机柜上架工单的每日更新量，避免数据库连接耗尽 |
| `MONGODB_URI` | DCIM系统的只读连接地址 | 用于拉取机柜拓扑与机位数据，确保只读权限避免误操作 |
| `PG_URL` | 资产系统的工单数据库只读地址 | 存储与同步上架申请、施工记录等结构化数据 |
| `REDIS_URL` | 本地部署的Redis实例地址，端口使用默认6379 | 缓存端口标签表、布线图解析结果，降低重复拉取开销 |
| `FILE_TOKEN_KEY` | 按实测生成的32位随机字符串 | 用于签署机柜布线图、端口标签表等文件的访问令牌，保障文件访问安全 |
| `STORAGE_S3_ENDPOINT` | 内部对象存储的VPC内网接入地址 | 实现机柜相关文档的安全存储与快速读取 |

## 容易做错的三处
- 现象：调用本地部署的文本解析模型时无返回结果，工作流节点显示「运行超时」；原因：未调整`DB_MAX_LINK`参数适配本地模型的并发请求限制，导致数据库连接被模型调用耗尽。
- 现象：上传机柜布线图后无法正常解析，界面显示「文件令牌无效」；原因：未正确配置`FILE_TOKEN_KEY`，导致文件访问权限校验失败。
- 现象：升级到FastGPT v4.17.0后，端口标签表的同步任务无法触发；原因：未更新`REDIS_URL`关联的缓存配置，导致旧版本的缓存逻辑与新版本的增量同步规则冲突。

## 怎么确认配好了
- 运行内置的数据源连通性校验工具，确认`PG_URL`、`MONGODB_URI`配置的系统可以正常拉取机位编号、端口标签等核心数据。
- 上传一张测试用的机柜布线图，确认文件可以正常加载，无「令牌无效」类报错。
- 提交一条模拟的上架申请工单，确认工单可以正常同步至系统内，无超时或连接失败日志。
- 查看系统监控面板，确认数据库连接数未超过`DB_MAX_LINK`设置的阈值，无异常断开情况。
