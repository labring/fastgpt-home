# 用户验收测试支持的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来源于需求规格文档、测试环境配置记录、客户业务样例素材与缺陷系统工单。日常产出的文档包含UAT用例、验收问题单、验收报告及签字确认单。数据更新节奏按项目阶段或软件版本推进，不同业务分类的文档结构存在差异，部分文档包含业务场景描述、测试步骤、问题复现步骤、验收结论等字段，仅随业务场景适配内容格式，无统一固定的单位要求。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据按业务分类存储且来源分散，要求检索环节支持按分类维度筛选召回结果，避免无关文档干扰。按阶段/版本更新的数据规模较大，需适配批量导入与增量更新逻辑，避免单次操作超时。文档包含长文本测试步骤与问题细节，需合理控制分块逻辑，确保检索时语义完整。不同文档的字段侧重差异明显，检索时需兼顾业务场景与具体问题的匹配度，提升召回精准度。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，适配用户验收测试支持场景的知识库检索与召回需求。

| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `similarity` | 0.75–0.85 | 适配UAT用例与验收问题单的语义匹配精度，过滤低相关的文档内容 |
| `limit` | 前10条 | 控制单次召回结果数量，适配运维值班与工单问答的快速响应场景 |
| `searchMode` | hybrid | 结合关键词与语义检索，覆盖固定测试步骤与模糊问题描述的匹配需求 |
| `usingReRank` | 开启 | 对初始召回结果进行重排序，提升验收问题与缺陷工单的匹配精准度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动优化用户提问的扩展查询，适配客户业务样例中的场景化表述 |
| `collectionIds` | 按项目分类指定 | 限定检索范围，避免跨分类的无关文档干扰，适配按阶段筛选的需求 |

## 容易做错的三处
- 批量导入大量文档时触发maxLength报错，原因是未拆分导入任务至合理单次数量，未适配知识库的单次上传限制。
- 语雀公开链接导入知识库失败，原因是未确认链接为可直接解析的公开数据源格式，未适配非标准网页内容的解析规则。
- 检索结果包含跨项目的无关文档，原因是未指定`collectionIds`限定检索范围，导致召回了非当前阶段的文档内容。

## 怎么确认配好了
- 上传单份UAT用例文档，检查导入状态是否正常，确认无格式解析报错。
- 输入模拟验收问题，查看检索结果的匹配分值是否在预设区间内，验证召回精度。
- 调用检索API，检查返回结果的数量是否符合设定的`limit`值，验证数量控制效果。
- 查看知识库分类配置，确认检索范围仅包含当前项目的`collectionIds`，验证分类筛选效果。
