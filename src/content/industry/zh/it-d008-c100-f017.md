# 等级保护测评咨询的运维值班与内部工单问答：部署与升级

## 这个品类的数据长什么样
等级保护测评咨询的业务数据围绕等保测评全流程产生，日常文档包含定级报告、差距分析报告、整改方案、测评报告四类核心文件。数据主要来自测评工具采集的系统配置、访谈记录整理的业务流程、资产清单梳理的设备信息，以及安全设备日志留存的访问与操作记录。数据更新以单个测评项目为周期，项目周期内完成定级、差距核对、整改、测评全流程后更新，单次项目周期内无高频数据变动。

## 这些特征在「部署与升级」这一环带来什么约束
等级保护测评咨询的业务特征对部署与升级环节提出明确约束。多源异构的数据来源需要适配多格式文档解析与存储，部署时需配置兼容非结构化报告与结构化日志的存储与检索组件。以项目为周期的更新节奏要求升级过程中保留历史项目数据，避免数据丢失影响后续测评复盘。核心文档的高合规性要求，需在升级后验证数据访问权限与加密配置符合内部管控规则，防止敏感测评信息泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30 个` | 等级保护测评咨询的业务数据以项目为周期存储，单项目数据量适中，该取值可平衡连接数与资源占用 |
| `MONGODB_URI` | 按测评项目数据量标定，`mongodb://user:pass@host:port/dbname?authSource=admin` | 需存储多份测评报告、日志等非结构化数据，需配置带权限验证的MongoDB连接，适配多项目数据隔离 |
| `REDIS_URL` | `redis://:password@host:6379/0`，内存配额设为`2000 MB` | 用于缓存高频检索的控制项匹配结果，2000 MB可覆盖单项目周期内的全量检索缓存需求 |
| `FE_DOMAIN` | 机构内部域名，如`http://sec-assess.internal` | 限定内部工单与问答系统的访问范围，符合等保测评的内部访问管控要求 |
| `FILE_TOKEN_KEY` | 按实测生成随机32位字符串 | 用于加密上传的测评报告附件，避免敏感文档泄露 |

## 容易做错的三处
- 执行FastGPT v4.17.0版本升级脚本时出现`curl --location`相关报错，现象为脚本执行中断，返回连接超时或权限拒绝。原因是未配置内部网络代理，或数据库连接凭证未正确写入升级脚本配置文件。
- 使用`docker build`构建镜像时出现checksum校验失败，现象为构建过程中提示文件校验不匹配，构建终止。原因是本地缓存的依赖包版本与官方源不一致，或网络中断导致依赖下载不完整。
- 多用户权限管控失效，现象为非授权用户可查看其他项目的测评报告。原因是未正确配置用户权限隔离参数，或未开启内部数据访问权限校验。

## 怎么确认配好了
- 执行`docker ps`命令，确认FastGPT相关容器正常运行，无异常退出状态。
- 访问`FE_DOMAIN`配置的内部域名，验证页面可正常加载，且能提交内部工单与检索测评相关文档。
- 执行`redis-cli info stats`命令，确认Redis连接数处于`DB_MAX_LINK`配置的合理区间内。
- 上传一份测试版定级报告，验证附件可正常存储与检索，无加密或权限报错。
