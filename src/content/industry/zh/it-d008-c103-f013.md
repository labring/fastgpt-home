# 美术资产生产管理的运维值班与内部工单问答：权限与数据隔离

## 这个品类的数据长什么样
该品类的数据主要来自美术资产库、项目管理系统、引擎资源包及外包交付包。日常产出的文档包含美术需求单、资产规格表、外包反馈表与验收记录，字段涵盖资产唯一标识、版本号、外包方权限标识、验收状态、面数、纹理分辨率等。数据更新频率多为日级或周级，部分紧急外包交付包会按单次任务更新。

## 这些特征在「权限与数据隔离」这一环带来什么约束
美术资产生产管理涉及项目核心视觉资源，且存在内部团队与外包协作的场景，不同角色（美术PM、原画师、3D美术、外包管理人员）的资源访问范围需严格区分。资产规格、验收记录等文档包含项目敏感参数，需限制非授权角色查看。日/周级更新的批量资产数据若未做权限隔离，易出现跨项目资源误用。外包交付包的权限需绑定对应项目，避免跨项目访问未授权的外包素材。

## 配置怎么定
以下配置适用于 FastGPT v4.17.0
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 团队权限绑定 | 绑定项目专属`teamId` | 美术资产按项目分组，避免跨项目资源访问 |
| 资产可见范围 | 限定为当前项目关联`tmbId` | 匹配美术资产的项目归属逻辑，隔离跨项目数据 |
| 免登陆链接有效期 | 设为 `24 小时` | 适配外包协作的临时访问需求，避免链接长期泄露 |
| 对话上下文隔离 | 按`teamId`划分边界 | 内部工单问答需隔离不同项目的运维沟通内容 |
| 资源返回条数限制 | 前 10 条 | 控制单次查询返回的资产数据量，降低敏感信息泄露风险 |
| 数据更新权限 | 仅开放给美术PM角色 | 匹配美术资产的更新审批流程，避免非授权修改 |

## 容易做错的三处
- 现象：非项目成员尝试访问指定美术资产时，界面返回“无权限访问”但实际已配置团队权限。原因：未将资产与`teamId`绑定，权限校验未关联项目分组规则。
- 现象：免登陆链接未做有效期限定，外部人员可长期访问未授权的外包交付包。原因：未配置`tmbId`绑定的访问范围，导致链接可访问全量资产数据。
- 现象：内部运维工单中出现其他项目的美术资产规格参数。原因：未按`teamId`划分对话上下文，导致不同项目的工单问答内容未做隔离。

## 怎么确认配好了
- 使用非项目成员的账号登录平台，尝试访问指定项目的美术资产，确认无法查看对应资源。
- 创建免登陆链接，设置有效期为`24 小时`，验证链接在有效期外无法访问目标资源。
- 发起内部运维工单，查询指定项目的资产信息，确认对话中仅返回当前`teamId`关联的资产数据。
- 尝试修改非当前项目的资产配置，确认操作被系统拦截。
