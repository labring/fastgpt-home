# 美术资产生产管理的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据主要来自美术资产库、项目管理系统、引擎资源目录及外包交付包。日常文档包含美术需求单、资产规格表、外包反馈表、验收记录，文档字段含资源编号、规格参数、交付时间、验收状态等，部分文件附带分辨率、面数、格式等单位化参数。数据更新频率通常为每日或每周，单次交付包可能随外包进度临时更新。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散导致检索需跨多系统对接，需配置跨源召回规则；文档含单位化参数（如面数、分辨率），需支持带单位的精准匹配；更新频率较高，需定期同步增量数据避免召回过时内容；外包交付包格式多样，需兼容多类型文件解析。内部工单多围绕规格确认、返修沟通，检索需优先召回同项目、同角色的历史记录，需按业务场景限定召回范围。

## 配置怎么定
本文基于FastGPT v4.17.0版本的配置逻辑，具体配置项及建议如下：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 匹配美术资产规格的精准度需求，避免召回无关的资源参数 |
| `limit` | `前 8–12 条` | 单次检索需覆盖单项目的典型资产条目，平衡上下文长度与召回覆盖度 |
| `searchMode` | `vector + keyword` | 兼顾语义匹配资产规格与关键词匹配资源编号、项目名称 |
| `usingReRank` | `开启` | 对召回的资产条目按相关性二次排序，修正单一向量召回的偏差 |
| `datasetSearchUsingExtensionQuery` | `开启` | 自动扩展工单问题的同义表述，覆盖美术领域的专业术语如「面数」「UV展开」 |
| `collectionIds` | `按项目分组配置` | 限定检索范围仅为当前项目的美术资产库，避免跨项目无关数据干扰 |

## 容易做错的三处
- 现象：检索结果出现非当前项目的美术资产条目，部分字段为空。原因：未配置`collectionIds`限定检索集合，导致跨项目数据被召回。
- 现象：检索返回的资产规格与工单问题的单位不匹配，如要求面数单位为「千面」却召回「面」的结果。原因：未开启`datasetSearchUsingExtensionQuery`，未对单位参数做扩展匹配。
- 现象：知识库召回的外包反馈表缺失最新的返修记录。原因：未按日/周更新频率配置增量同步任务，导致数据未及时更新。

## 怎么确认配好了
- 提交一条包含具体资源编号和规格参数的内部工单，核对检索结果是否优先返回同编号的资产文档。
- 调整`similarity`参数的取值区间，验证检索结果的相关性是否随参数变化符合预期。
- 上传一份最新的外包交付包，触发增量同步后检索相关工单，确认召回结果包含最新的验收记录。
- 切换`searchMode`的配置，对比向量召回与混合召回的结果差异，确认符合业务场景的匹配逻辑。
