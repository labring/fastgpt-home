# 落地页转化优化的运维值班与内部工单问答：知识库检索与召回

## 这个品类的数据长什么样
落地页转化优化的日常文档包含落地页方案、埋点需求、AB测试报告、表单字段清单四类核心内容。数据来源主要为落地页访问日志、热力图数据、表单提交数据、广告来源参数。数据更新频率为每周或单次活动周期内。字段包含页面访问路径、停留时长、表单提交状态、广告渠道标识等，内容结构随具体活动灵活调整，无固定统一格式。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源分散的数据来源要求检索需覆盖落地页方案、埋点需求、AB测试报告、表单字段清单四类核心文档，避免单一检索模式遗漏关键业务信息。周度或单次活动周期的更新节奏要求知识库同步频率匹配业务节奏，避免召回过时的旧数据。文档结构灵活且无固定统一格式，要求检索需兼顾关键词匹配与语义理解，适配不同类型的业务问题。字段分散且随活动调整，要求检索配置需支持按业务分组关联知识库，避免跨品类数据干扰。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配落地页相关的业务关键词，过滤低相关性的通用运维文档 |
| `limit` | 前8条 | 适配单轮运维值班问答场景，控制上下文长度不超出模型处理上限 |
| `searchMode` | hybrid | 结合关键词与语义检索，覆盖埋点需求、AB测试报告等不同类型文档 |
| `usingReRank` | 开启 | 对召回结果二次排序，优先匹配表单字段、广告归因等核心业务内容 |
| `datasetSearchUsingExtensionQuery` | 开启 | 优化用户问题的扩展表述，匹配落地页方案中的细节内容 |
| `collectionIds` | 按业务分组配置 | 仅关联落地页转化优化专属的知识库集合，避免跨品类数据干扰 |

## 容易做错的三处
- 现象：调用`/api/v1/chat/completions`接口时，指定appId后未召回对应知识库内容。原因：未通过`collectionIds`配置关联目标知识库集合，或配置的集合ID与实际上传文档的集合不匹配。
- 现象：检索结果包含大量无关的通用运维文档，未命中落地页相关内容。原因：`similarity`阈值设置过低，召回了超出业务范围的非核心文档。
- 现象：单轮问答返回的上下文过长，超出模型处理上限导致报错。原因：`limit`参数设置过大，未控制召回结果的条数。

## 怎么确认配好了
- 调用FastGPT提供的应用关联知识库校验接口，检查指定appId下绑定的知识库集合ID与配置的`collectionIds`是否一致。
- 输入落地页路径、表单字段等业务关键词，验证检索结果是否优先返回落地页方案、AB测试报告类文档。
- 调整`similarity`阈值，观察召回结果的相关性变化，确认阈值符合业务需求。
- 开启`usingReRank`后，对比重排前后的结果排序，确认重排逻辑生效。
