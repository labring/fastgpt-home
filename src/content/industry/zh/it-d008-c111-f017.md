# 配置管理与CMDB维护的运维值班与内部工单问答：部署与升级

## 这个品类的数据长什么样
本品类数据来源于企业CMDB系统、云资源自动发现工具、硬件采购台账与ITSM变更记录。数据以配置项清单、服务依赖拓扑图、变更操作日志、资产盘点表为核心载体，包含配置项唯一标识、所属业务域、关联组件、更新时间、责任人等字段。数据更新频率按日或周执行，单次更新覆盖新增、下线或变更的资产与依赖关系。

## 这些特征在「部署与升级」这一环带来什么约束
本品类数据来源分散且需定期同步，部署时需配置多类数据源的连接参数，确保与CMDB、云资源清单等系统的网络连通性。数据更新频率存在日/周差异，需在部署阶段配置定时同步任务的触发间隔，适配不同业务的更新节奏。配置项依赖关系的校验逻辑需在部署时预加载基础拓扑数据，避免启动后出现依赖校验失败。同时，由于数据量随资产规模增长，需合理配置数据库连接池参数，保障查询与同步的稳定性。FastGPT v4.17.0及以上版本必须配置AI Proxy相关环境变量，作为系统基础依赖。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://mongo:27017/fastgpt_cmdb` | 存储CMDB配置项、拓扑关系与变更记录的数据库连接地址，需指定专属数据库名称隔离业务数据 |
| `REDIS_URL` | `redis://redis:6379/0` | 缓存高频查询的配置项信息与同步任务状态，降低数据库查询压力 |
| `DB_MAX_LINK` | `20–30` | 适配CMDB数据的并发查询与批量同步需求，避免连接数过多导致数据库负载过高 |
| `FE_DOMAIN` | `http://internal-fastgpt:3001` | 配置内部运维前端的访问域名，用于配置变更工单的推送与页面跳转 |
| `ROOT_KEY` | `自定义复杂随机字符串` | 作为系统内部鉴权的根密钥，保障配置同步与工单接口的安全性 |
| `STORAGE_S3_ENDPOINT` | `http://internal-minio:9000` | 存储CMDB变更日志与资产快照的对象存储地址，适配内部私有存储部署场景 |

## 容易做错的三处
- 启动App/Admin服务时弹出必填参数缺失报错，排查项：检查是否在服务端环境变量中配置了`AIPROXY_API_ENDPOINT`（AI Proxy服务的根地址）与非空的`AIPROXY_API_TOKEN`（AI Proxy管理员Token，与AI Proxy服务端配置一致且不能为空）。
- 嵌入模型调用失败，检索结果条数为0，排查项：检查`AIPROXY_API_ENDPOINT`（AI Proxy服务的根地址）是否配置为AI Proxy服务的根地址，不得配置为VLLM/Ollama/Xinference等单模型地址。
- 批量同步CMDB配置项时出现数据库连接耗尽报错，原因是`DB_MAX_LINK`取值过低，未适配批量数据处理的并发需求。

## 怎么确认配好了
- 执行App/Admin服务的启动校验流程，确认`AIPROXY_API_ENDPOINT`（AI Proxy服务的根地址）与`AIPROXY_API_TOKEN`（AI Proxy管理员Token，与AI Proxy服务端配置一致且不能为空）的配置通过校验。
- 发起一次CMDB配置项的手动同步任务，查看任务日志中无数据库连接或数据源连通性相关报错。
- 访问内部运维前端域名，确认可以正常加载配置项清单与服务依赖拓扑图。
- 调用配置变更工单接口，确认可以正常生成并推送相关运维工单。
