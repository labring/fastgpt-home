# SLA与服务报告的需求与设计文档起草：文档解析与分块
本文档适配FastGPT v4.17.0版本的文档解析与分块功能。

## 这个品类的数据长什么样
本品类的数据来自监控系统、工单系统、正式服务合同及客户沟通记录，更新周期为月度或季度。日常处理的文档包含标准化SLA条款文本、月度服务汇总报告、系统可用性统计报表、客户服务复盘纪要。文档字段包含服务周期范围、服务可用性约定、异常事件记录、客户诉求分类及对应处理结果，单位多为自然时间单位、事件计数单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
SLA与服务报告的文档结构差异显著，标准化条款为长文本连贯结构，月度报告则包含表格、数值统计与段落描述混合内容。数据来源分散导致解析前需整合多系统导出的异构文件，更新频率要求解析流程需适配批量月度归档文件的批量处理。文档中的SLA指标字段需精准提取，分块时需避免割裂条款与对应数值的关联，同时需兼容不同格式的统计报表解析，对分块规则的灵活性要求较高。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配SLA条款与服务报告中长段落与表格嵌套的内容长度，避免割裂关键指标关联 |
| `chunkSplitter` | 按段落+语义分割 | 适配混合文本结构，保留SLA条款的完整语义单元与报告中的统计段落 |
| `customPdfParse` | 启用 | 适配月度服务报告中的表格与数值统计内容，提升异构文档解析准确率 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 兼容季度汇总的多文档打包上传场景，满足批量归档文件的处理需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 适配多系统整合后的大型统计报表解析，避免因内容复杂导致超时失败 |
| `chunkSettingMode` | 手动配置 | 针对不同类型的SLA文档与服务报告，灵活调整分块规则与阈值 |

## 容易做错的三处
- 上传PDF后显示解析失败，界面返回超时状态码。原因是未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，大型月度服务报告的解析时长超出默认阈值。
- 分块结果割裂SLA条款与对应赔付条款。原因是`chunkSplitter`配置为按固定字符分割，未保留语义关联单元。
- 批量上传月度报告时部分文件未被解析。原因是`UPLOAD_FILE_MAX_SIZE`设置过小，超出季度汇总文件的实际大小。

## 怎么确认配好了
- 上传单份标准SLA条款文档，检查分块结果是否保留完整的单条SLA条款内容，无中途割裂情况。
- 上传包含表格的月度服务报告，查看解析后的文本是否保留表格内的数值与对应说明段落的关联。
- 上传1000 MB以内的打包归档文件，确认所有文件均被识别并完成解析流程。
- 调整`PARSE_FILE_TIMEOUT_SECONDS`至600秒，上传大型统计报表，验证解析过程无超时报错。
