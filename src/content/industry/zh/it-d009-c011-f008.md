# 云主机交付与资源开通的需求与设计文档起草：工作流编排

## 这个品类的数据长什么样
通常，该品类的数据来源于云管理平台、订单系统、IAM权限系统与计费系统。日常产出的文档包括资源开通单、实例配置表、账号权限单与交付确认单，核心字段包含实例规格（vCPU核数、内存大小）、安全组ID、子网信息、订单编号、权限范围与交付时间，单位涉及核、GB、秒等。数据更新节奏为每单或实时，每提交一次资源开通请求即生成或更新对应数据。

## 这些特征在「工作流编排」这一环带来什么约束
多源数据的接入要求工作流支持从不同系统拉取并统一格式，避免因数据格式差异导致的校验失败。实时或单实例的更新节奏要求工作流支持事件触发或单实例启动模式，适配单次资源交付的独立流程。多类型业务文档的存在要求工作流通过变量映射匹配不同文档的字段，减少手动录入的误差。核心字段的单位与格式要求需在编排时加入校验环节，规避规格错配、权限错误等问题，同时针对最耗时的规格核对、安全组配置环节标准化流程，提升编排效率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 映射为实例规格、安全组ID、订单号、权限范围 | 匹配云主机交付的核心业务字段，确保工作流读取准确的业务数据 |
| `nodeId` | 1001、1002、1003、1004 | 规范工作流节点标识，便于排查校验失败与执行日志问题 |
| 触发条件 | 按资源开通单提交事件触发 | 匹配业务流程的发起节点，实现实时响应新的交付需求 |
| 数据校验规则 | 校验vCPU核数为正整数、内存大小为1024 MB-65536 MB区间 | 符合FastGPT v4.17.0版本的工作流配置规范，同时匹配云主机常规配置范围 |
| 通知延迟配置 | 延迟300秒发送交付确认通知 | 预留云主机初始化的缓冲时间，确保通知时资源已就绪 |

## 容易做错的三处
- 现象：工作流启动时提示“工作流校验失败，请检查是否缺失、缺值，连线是否正常”，原因：未正确配置`variables`映射云主机业务字段，或`nodeId`存在重复标识。
- 现象：App/Admin服务启动校验失败，或AI Proxy相关调用报错，提示鉴权失败或地址不可达，原因：未在服务端正确配置AIPROXY_API_ENDPOINT和AIPROXY_API_TOKEN环境变量，或使用了非AI Proxy管理员的鉴权凭证。
- 现象：工作流中固定操作无法复用，原因：未将常用节点（如规格核对、权限配置）保存为可复用模板，或未正确关联`nodeId`实现节点调用。

## 怎么确认配好了
- 检查服务端部署配置中是否已配置AIPROXY_API_ENDPOINT（AI Proxy服务根地址，例如http://aiproxy:3000，不得附加/v1等路径，非单模型服务地址）和AIPROXY_API_TOKEN（与AI Proxy服务端配置一致的非空管理员Token，不得使用应用API Key、模型供应商密钥等其他凭证），且两个变量均非空。
- 运行工作流的测试节点，查看是否能正确拉取云管理平台的实例配置数据，无格式报错或字段缺失提示。
- 手动触发一次模拟的资源开通单提交事件，确认工作流按预设顺序执行所有配置节点，无中断或异常跳转。
- 核对`variables`映射的字段与实际业务文档的字段是否完全一致，无遗漏或错配情况。
