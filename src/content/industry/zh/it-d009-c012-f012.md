# 云网络与负载均衡配置的需求与设计文档起草：文档解析与分块

## 这个品类的数据长什么样
该品类的日常文档包含VPC规划、安全组规则、负载均衡配置、变更单等，数据来源为云平台控制台导出的配置文件、网络拓扑图、流量监控报表及客户架构图。文档按变更单、配置项章节结构化，包含网段范围、端口映射、健康检查阈值、后端服务器组等字段，单位多为C类网段、毫秒、台等，更新频率随每一次配置变更完成。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的结构化章节文档要求分块需保留章节标题以维持上下文关联，频繁的变更更新要求解析流程需适配快速迭代的文档内容。网段、端口等字段的精确性要求分块不能割裂单个关键配置项，同时，来自云平台的导出文件可能存在格式兼容性问题，需适配非标准的文档结构。单份变更单文档长度不一，部分大型拓扑文档内容较多，需灵活调整分块参数以避免过细或过粗的分块结果，影响后续检索精度。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 800–1200 字符 | 适配云网络配置文档的章节长度，避免割裂单个配置项 |
| `chunkSplitter` | 按标题+段落拆分 | 保留文档的章节层级，提升检索时的上下文准确性 |
| `customPdfParse` | 开启 | 适配云平台导出的PDF格式配置文件，还原表格与章节结构 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 容纳单份批量变更的配置文档，适配大型网络拓扑文件 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 避免大型文档解析超时，适配复杂变更单的处理时长 |
| `chunkSettingMode` | 手动模式 | 针对不同类型的网络文档灵活调整分块参数，适配多样化的配置格式 |

## 容易做错的三处
- 现象：服务器环境上传文件后解析节点返回404错误，本地环境正常。原因：未配置服务器端文件上传的静态资源访问路径，导致解析节点无法获取上传的文档文件。
- 现象：使用Qwen3-14B部署时无法从PDF解析结果提取响应字段，使用Qwen2.5-14B可正常提取。原因：未开启`customPdfParse`优化解析结构，导致大模型无法识别结构化的配置内容。
- 现象：RAG检索结果仅返回正文内容，未包含章节标题信息。原因：分块配置未保留标题层级，仅拆分了段落内容，导致上下文关联丢失。

## 怎么确认配好了
- 上传一份标准的负载均衡配置docx文档，查看解析后的分块结果是否包含章节标题与对应配置段落。
- 上传一份100 MB左右的变更单文档，确认解析过程未触发超时错误，解析状态显示为完成。
- 调整`chunkSize`参数为不同区间，对比分块后的内容长度，验证参数生效。
- 上传云平台导出的PDF格式配置文件，查看表格与章节结构是否完整还原。
