# 供应商与设备到货管理的需求与设计文档起草：工作流编排

## 这个品类的数据长什么样
该品类的数据主要来自ERP系统、供应商发货单、物流追踪信息与设备厂商后台。日常产出的文档包含采购订单、到货验收单、序列号清单与发票资料，其中采购订单包含供应商编号、设备型号、采购数量、约定到货日期等字段，序列号清单则记录设备唯一标识与对应采购项的关联关系。数据更新以单订单为周期，部分批量采购项目按周同步。

## 这些特征在「工作流编排」这一环带来什么约束
数据来源分散导致工作流需对接多类外部数据源节点，需配置对应输入规则适配不同格式的发货单与物流信息。跨文档的字段关联要求绑定`variables`实现采购订单、序列号清单与验收单的字段联动，避免手动录入误差。数据更新周期随订单灵活变动，需设置按单订单提交触发的启动规则，部分批量项目需适配周级同步逻辑。设备序列号的唯一性要求，需在流程中加入校验环节拦截重复或错配的标识信息，防止出现设备错配或账实不符问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `variables` | 绑定采购订单ID、设备SN码、项目编号三类核心字段 | 匹配该品类跨文档的字段关联需求，实现多文档数据联动 |
| 触发节点设置 | 按单订单提交触发，支持周级批量任务触发 | 适配该品类每单或每周的更新频率，匹配业务执行节奏 |
| 输入节点配置 | 对接ERP、供应商发货单、物流信息三类数据源，设置字段映射规则 | 覆盖该品类全量数据来源，减少手动录入步骤 |
| 校验节点配置 | 添加序列号唯一性校验、型号匹配校验，超时阈值设为600秒 | 规避设备错配、账实不符的风险，控制单节点执行时长 |
| 输出节点配置 | 生成采购订单附件、到货验收单模板，支持导出为不超过500 MB的PDF文档 | 匹配该品类日常文档的输出需求，便于存档与内部流转 |

## 容易做错的三处
- 工作流运行报错显示Cannot convert undefined or null to object，原因是未配置`variables`绑定核心字段，导致流程中调用的字段为空值。
- AI对话节点输出直接展示在页面，无法通过后续组件拼接后指定输出，原因是未关闭AI节点的自动输出开关，未配置`nodeId`关联后续文本拼接节点。
- 工作流中历史记录无法作为跨节点变量调用，原因是未在`variables`中绑定历史记录节点的输出字段，导致无法传递数据。

## 怎么确认配好了
- 提交测试订单，检查工作流是否自动触发并拉取对应ERP、发货单与物流信息数据。
- 输入模拟的重复序列号，检查校验节点是否拦截异常数据并返回明确提示。
- 配置AI对话节点后关闭自动输出开关，运行流程后检查是否仅在文本拼接组件完成后输出结果。
- 查看FastGPT v4.17.0版本的流程日志，确认`variables`绑定的字段均有有效取值，无空值报错。
