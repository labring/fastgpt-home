# 内容版权与授权管理的需求与设计文档起草：工作流编排

## 这个品类的数据长什么样
本品类的数据来源包含合同系统、版权登记信息、内容库与投诉邮箱。日常产出的文档包括授权合同、版权台账、下架通知与侵权投诉材料，核心字段涵盖授权范围、授权期限、侵权主体、投诉时间及下架原因等。数据更新以单订单或月度为周期，不同来源的数据格式存在差异，合同系统多为结构化字段，投诉邮箱则多为非结构化文本。

## 这些特征在「工作流编排」这一环带来什么约束
数据来源分散的特征要求工作流编排需支持对接多类异构数据源，需配置数据源绑定规则以统一数据格式。按单或月度的更新频率，要求工作流支持按单触发或定时触发机制，避免无效执行。核心文档字段多且结构差异大，需配置字段映射规则，将不同来源的数据统一映射到工作流的`variables`中。由于出错后果严重，工作流需增加前置校验环节，对授权范围、到期时间等核心字段进行合法性校验，同时配置异常处理流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `variables` | 包含授权范围（800-1200字符）、授权期限、侵权主体3个核心字段 | 匹配品类核心文档的字段结构，适配FastGPT v4.17.0的变量绑定规则 |
| 节点触发条件 | 按`variables`更新触发 | 贴合按单/月的更新频率，仅在数据变更时执行工作流 |
| `nodeId` | 绑定合同系统、版权登记信息的数据源节点ID | 对接品类指定的核心数据源，确保数据来源准确 |
| 工具调用超时 | 600秒 | 覆盖合同审核、侵权材料整理的常规耗时需求 |
| 报错处理规则 | 捕获400状态码、`empty`返回值 | 覆盖常见的工具调用异常场景，匹配用户反馈的问题类型 |
| 输出字段映射 | 将图片URL绑定到渲染节点，支持最多5条侵权投诉材料的批量渲染 | 实现工作流结果的可视化渲染，避免仅返回纯文本链接 |

## 容易做错的三处
- 工作流调用图表工具后渲染为空：现象为图表节点输出无内容，前端展示空白。原因是未在`variables`中配置图片URL的字段映射，导致工具返回的结果未正确绑定到输出节点。
- 工作流返回400错误：现象为节点执行失败，界面展示400状态码报错。原因是未正确配置`variables`中的授权范围字段，导致请求参数缺失，无法完成合法校验。
- AI对话节点返回`empty`未触发异常处理：现象为节点执行成功但无输出，直接跳过后续流程。原因是未设置针对`empty`返回值的异常处理规则，未触发预设的报错提醒与重试机制。

## 怎么确认配好了
- 检查`variables`配置是否包含授权范围、授权期限、侵权主体三个核心字段，且字段格式匹配品类文档的要求。
- 验证`nodeId`是否正确绑定了合同系统、版权登记信息的数据源节点，确保数据来源准确无误。
- 触发一次单订单的工作流，确认是否按配置的触发条件执行，且核心字段已正确映射。
- 模拟400状态码或`empty`返回值，确认是否触发预设的报错处理规则，生成对应的异常提醒。
