# 备份恢复与灾备演练的需求与设计文档起草：工作流编排

## 这个品类的数据长什么样
这个品类的数据主要来自备份系统、数据库日志、对象存储、灾备平台，日常产出备份策略、恢复演练报告、灾备切换预案、数据校验记录四类文档。数据更新频率分为日、月、季三类，核心字段包含恢复点目标、恢复时间目标、备份路径、校验结果等，文档结构需覆盖演练流程、参数配置、异常处理等内容。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的数据来源分散、文档结构差异大且更新节奏不同，会对工作流编排带来多重约束。首先需适配多数据源接入，确保能同步备份系统、灾备平台的实时数据；其次需根据文档更新频率配置对应触发规则，避免高频任务占用过多资源；同时需针对不同文档类型预设字段映射规则，确保恢复点目标、校验结果等核心字段能准确流转；另外因出错后果严重，需在工作流中嵌入异常校验节点，拦截不符合规范的文档内容，保障业务连续性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| 全局变量`variables` | 映射恢复点目标、校验结果等核心字段 | 适配该品类多文档的字段结构，确保数据准确流转 |
| 工作流触发规则 | 按日/月/季周期配置 | 匹配该品类数据的更新频率，避免无效执行 |
| 异常校验节点 | 配置数据一致性校验阈值为99.9%，单次校验时长不超过300秒 | 确保恢复数据的准确性，控制校验耗时 |
| 节点ID`nodeId` | 按灾备演练流程顺序分配 | 确保工作流节点执行顺序与标准灾备流程一致 |
| AI对话模块文件链接 | 绑定备份策略、恢复演练报告文档 | 为AI对话提供品类专属的参考数据 |
| 变量传递规则 | 限定传递核心业务字段 | 减少无效数据流转，提升工作流运行效率 |

## 容易做错的三处
- 工作流中配置的表单输入字段无法在对话界面显示，交互内容为空。原因是未将表单字段绑定到全局变量`variables`，导致数据未正确流转到对话模块。
- AI对话模块配置的文件链接无法加载参考文档。原因是绑定的文档路径未匹配备份系统、灾备平台的实际存储路径，导致文件无法被读取。
- 工作流触发后未按预期执行演练流程。原因是节点ID`nodeId`分配顺序与标准灾备流程不符，导致节点执行顺序错乱。

## 怎么确认配好了
- 触发一次测试工作流，检查对话界面是否显示预设的表单输入字段。
- 查看AI对话模块的参考文档列表，确认已绑定备份策略、恢复演练报告等品类专属文档。
- 导出工作流执行日志，核对节点执行顺序与灾备演练流程的预设顺序一致。
- 提交一份模拟的演练报告数据，检查全局变量是否正确捕获核心字段如恢复点目标。
