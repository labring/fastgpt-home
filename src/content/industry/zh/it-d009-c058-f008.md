# 广告合规留痕的需求与设计文档起草：工作流编排

## 这个品类的数据长什么样
本品类数据主要来自广告平台后台、客户资质文件、合同系统及监管公开规则。日常产出的核心文档包括广告审查表、资质附件、投放记录与整改通知。数据更新节奏随单次广告活动或自然月度推进，单条数据包含投放主体、合规审核编号、资质有效期、投放时段、整改记录等字段，无统一固定的单条数据体量上限，随广告活动规模浮动。

## 这些特征在「工作流编排」这一环带来什么约束
数据来源分散导致工作流需对接多系统接口，需配置跨源数据拉取节点适配不同数据源的格式要求。文档类型多样要求工作流支持多格式输入适配，需包含文本解析、附件提取子节点处理资质附件等非结构化数据。更新频率随活动波动，需支持按需触发与定时触发两种模式，避免无效执行。合规留痕的强证据属性要求工作流全程可追溯，需绑定`variables`记录每一步操作节点的执行状态与结果，同时绑定`nodeId`标记节点身份，便于后续审计。单条数据体量随活动规模浮动，需预留足够的上下文处理空间，避免触发上下文溢出报错。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 单次搜索上限 | 前3-5条 | 投放记录单条数据的合规条目数通常在3-5条，匹配单活动的合规检查范围 |
| 最大上下文 | 8000-12000 token | 广告审查表与整改通知的文本长度波动较大，预留足够空间容纳多文档拼接 |
| 变量存储 | 开启全链路记录 | 合规留痕需留存每一步执行结果，绑定`variables`和`nodeId`节点记录执行状态与节点身份 |
| 触发模式 | 按需触发+定时触发 | 数据更新随活动与月度波动，按需触发适配临时活动，定时触发适配月度归档 |
| 附件解析规则 | 按文件格式自动适配 | 数据包含资质附件等多格式文件，自动适配解析规则覆盖常见合规文档格式 |

## 容易做错的三处
- 工作流仅支持单节点调用，无法在主Bot中嵌套多工作流。现象为尝试在Bot配置面板的节点库中搜索子工作流节点时无匹配选项，原因是未开启工作流嵌套权限，或未将目标工作流设置为可被外部调用的公共节点。
- 导入他人JSON工作流后文本加工模块缺失。现象为导入的工作流配置中存在文本加工节点，但本地编辑器的节点库中无法找到该模块，原因是本地FastGPT版本低于v4.17.0，该模块在v4.17.0及以上版本中新增。
- 工作流导出失败或导出内容不完整。现象为点击导出JSON按钮后无下载响应，或导出的JSON文件缺少部分节点的配置参数，原因是工作流中存在未保存的草稿节点，或节点配置包含未授权的外部引用链接。

## 怎么确认配好了
- 触发工作流后，查看`variables`节点记录的执行日志，确认所有跨源数据拉取节点均成功获取对应文档，无报错信息。
- 运行工作流并输入单条广告活动数据，检查输出结果包含广告审查表、投放记录等所有要求的文档片段，字段完整。
- 尝试在主Bot的节点库中添加该工作流节点，确认可正常选择并配置调用参数，无异常提示。
- 导出工作流为JSON文件，解压后检查文件包含所有配置节点与参数，无缺失内容，可正常重新导入。
