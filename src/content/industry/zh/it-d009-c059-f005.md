# 广告素材审核的需求与设计文档起草：多轮对话与提示词

## 这个品类的数据长什么样
该品类的数据主要来自广告投放平台、落地页资源、商品资质文件与广告法合规条款。日常处理的文档包含单条广告素材内容、落地页截图、审核人员输出的修改意见与素材迭代记录。数据更新节奏为日更或实时同步，无固定统计周期，文档字段包含素材文案、落地页URL、违规类型标注、修改时限要求等，无统一标准化单位，需按单次审核任务匹配对应字段。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
广告素材审核的数据来源分散且实时更新，要求多轮对话需支持实时拉取最新的广告平台合规规则与素材状态。日常处理的文档包含非结构化的素材文案、落地页截图，提示词需适配多模态输入的解析逻辑。审核任务需逐条处理单条素材，多轮对话需限制上下文关联范围，避免跨任务干扰。同时，审核意见与修改记录需作为对话历史留存，需绑定当前审核任务的专属参数，确保每轮对话的上下文精准匹配当前审核项。

以下配置基于FastGPT v4.17.0版本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chatId` | 绑定当前审核任务的唯一ID | 确保多轮对话上下文仅关联单条素材审核任务，避免跨任务数据混淆 |
| `messages` | 保留最近15–20轮对话 | 覆盖素材修改、意见反馈的完整流程，同时控制上下文占用资源 |
| `variables` | 传入素材文案、落地页URL、合规条款版本 | 为提示词提供当前审核的专属参数，适配实时更新的合规规则 |
| 单次搜索上限 | 前3条 | 匹配单条素材审核的轻量化需求，避免冗余信息干扰 |
| 最大上下文 | 8000–12000 token | 按实测标定，适配广告素材审核的文档长度与历史对话 |
| 对话超时 | 600秒 | 按实测标定，适配单条素材审核的处理时长 |

## 容易做错的三处
- 现象：前端页面同时展示多个审核任务的对话内容，无法精准关联当前处理的素材。原因：未将`chatId`绑定为当前审核任务的唯一标识，导致多任务上下文混杂。
- 现象：提示词未按要求识别落地页一致性或文案违规问题，审核结果不符合预期。原因：未在`variables`中传入落地页URL或合规条款版本参数，提示词无法获取对应校验数据。
- 现象：发布后的对话界面仅显示LaTeX原始代码，调试预览阶段可正常渲染。原因：未配置前端对话模块的格式渲染规则，导致发布后未启用LaTeX解析。

## 怎么确认配好了
- 提交一条测试审核任务，查看对话上下文是否仅包含当前素材的修改记录与审核意见，无其他任务的历史内容。
- 传入测试素材、落地页URL与合规条款版本，触发多轮对话，确认提示词能正确调用对应参数进行审核。
- 插入包含LaTeX格式的审核意见，在发布后的对话界面查看是否正常渲染，无原始代码残留。
- 发起多次测试对话，确认系统会话流程可正常推进，无持续卡顿或超时情况。
