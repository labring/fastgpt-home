# 广告素材审核的需求与设计文档起草：工作流编排

## 这个品类的数据长什么样
广告素材审核的核心数据来自广告投放平台、落地页资源、商品资质文件及广告法合规条款。日常产出的文档包含待审核广告素材、落地页截图、人工审核意见、整改修改记录。数据更新频率为日更或实时，随投放计划调整或违规判定结果即时更新。数据字段包含素材唯一标识、投放渠道类型、文案内容、落地页URL、违规类型标记、整改要求等，无统一固定单位，字段随投放场景与合规要求动态调整。

## 这些特征在「工作流编排」这一环带来什么约束
广告素材审核的数据来源分散且更新节奏灵活，要求工作流需支持多数据源并行拉取节点，确保实时或日更的素材与合规条款同步更新。逐条审核的业务逻辑要求工作流配置循环处理节点，适配单条素材的全流程校验。文档类型多样且字段动态调整，需支持变量动态绑定与字段映射，避免硬编码导致的适配失效。出错后果直接关联广告投放权限，工作流需配置前置校验与异常拦截环节，减少人工干预失误的概率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 循环体结束条件 | 检测到`variables`中违规标记字段存在时触发 | 匹配广告素材审核的违规判定逻辑，自动终止无效循环 |
| 单次处理素材条数 | 前20条 | 适配单批次审核的服务器资源负载，避免节点超时 |
| 超时阈值 | 600秒 | 覆盖多数据源拉取、文案检查与落地页核对的平均耗时 |
| 变量引用格式 | {{}} 格式兼容模式 | 适配FastGPT v4.17.0的变量引用规则，修复旧版本兼容问题 |
| `nodeId`绑定 | 绑定审核结果存储节点 | 确保循环处理后的所有审核结果准确归集至指定存储位置 |
| 单次校验字符上限 | 800–1200 字符 | 匹配单条广告素材文案的常规长度，避免节点处理过载 |

## 容易做错的三处
- 循环体执行后未自动终止，日志显示`variables`中违规标记字段未被正确识别，原因是循环体条件未绑定正确的`variables`字段，未匹配广告素材的违规判定逻辑。
- HTTP节点调用广告平台接口时，变量解析为空，原因是未开启{{}}格式的变量兼容设置，使用旧的/模式取变量导致解析失败。
- 工作流触发后无审核结果产出，`nodeId`绑定的存储节点未写入任何数据，原因是循环体未正确配置输出变量映射，导致处理后的结果未传递至存储节点。

## 怎么确认配好了
- 提交单条包含明确违规标记的测试素材，查看工作流各节点状态是否全部成功，循环体是否自动终止。
- 触发批量审核任务，检查`nodeId`绑定的存储节点，确认所有审核结果均已正确写入。
- 模拟高负载场景，提交20条以上的测试素材，确认节点未触发超时报错。
- 调整变量引用格式为旧版/模式，验证是否出现变量解析失败的情况，确认兼容设置生效。
