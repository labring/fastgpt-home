# 投放计划搭建的需求与设计文档起草：文档解析与分块

## 这个品类的数据长什么样
投放计划搭建的核心数据来自广告平台、用户画像库、预算排期表、归因工具。日常产出的文档包含投放计划、定向设置、预算排期、转化追踪配置四类，按单次投放活动为单位组织，包含定向人群包标识、预算金额、转化事件名称、投放时段等字段，更新频率为每日或每次投放活动更新时同步。

## 这些特征在「文档解析与分块」这一环带来什么约束
投放计划文档按单次活动组织的结构，要求分块不能跨活动拆分，否则会丢失单个投放的完整配置逻辑。来自多数据源的混合字段，要求解析环节需保留不同类型字段的关联关系，避免拆分后定向与预算配置脱节。高频更新的特性要求解析流程需具备合理的超时容错，避免因更新频繁导致解析中断。结构化的表格与嵌套配置，要求解析环节需适配合并单元格、嵌套字段等非标准格式，否则会出现字段识别缺失的问题。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的参数逻辑制定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配投放计划文档的单活动配置长度，避免拆分后丢失定向与预算的关联关系 |
| `chunkSplitter` | 按段落+关键词锚定 | 投放计划文档包含结构化段落与配置项，按段落拆分保留配置上下文，关键词锚定定向、预算等核心字段 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 投放计划文档常包含多活动配置，解析耗时较长，避免因超时中断解析流程 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 支持批量导入多活动的投放计划文档，适配代理商运营的批量作业需求 |
| `customPdfParse` | 开启 | 投放计划多为导出的PDF格式，开启自定义解析可保留表格与字段结构，避免OCR识别丢失配置项 |
| `chunkSettingMode` | 手动配置 | 适配不同投放活动的文档结构差异，手动调整分块参数以匹配不同文档的字段关联逻辑 |

## 容易做错的三处
- 现象：上传包含合并单元格的投放计划Excel文档时，解析后出现字段为空的报错。原因：未开启结构化文件解析适配，默认解析无法识别嵌套的配置字段，导致关联数据丢失。
- 现象：文档解析后分块数量过多，后续向量化环节耗时过长。原因：`chunkSize`设置过小，将单条定向配置拆分为多个独立块，增加了向量化计算的总工作量。
- 现象：非文档类的文本提问触发了文档解析流程。原因：未正确配置`chunkSettingMode`，将通用提问误绑定至文档解析环节，导致资源占用异常。

## 怎么确认配好了
- 上传一份标准投放计划Excel文档，查看解析后的分块预览，确认每个投放活动的定向、预算、转化配置未被拆分至不同块。
- 上传单份100 MB以内的投放计划PDF文档，等待解析完成，确认未触发超时报错。
- 测试非文档类的文本提问，确认未进入文档解析流程，仅在上传文档时触发解析动作。
- 查看上传文件大小限制，确认可上传符合业务需求的批量文档，未触发拦截提示。
