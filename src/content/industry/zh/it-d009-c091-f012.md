# 玩家客服与舆情处理的需求与设计文档起草：文档解析与分块

## 这个品类的数据长什么样
典型主体为游戏客服、社区运营与发行运营，日常处理的文档包括玩家工单、补偿申请、舆情日报与处理话术。数据来源涵盖客服系统工单、社区论坛评论、应用商店评分、游戏内日志，更新节奏多为日更或实时。文档结构多为半结构化或短文本，包含账号ID、问题描述、提交时间、反馈分类、补偿类型等字段，无统一固定格式，部分补偿申请与舆情日报采用Excel、PDF格式存储。

## 这些特征在「文档解析与分块」这一环带来什么约束
品类的多来源、非统一格式的文档特征，要求解析环节需兼容Excel、PDF、短文本等多种格式。实时/日更的更新节奏，要求解析流程具备足够的响应速度，避免延迟影响后续处理。文档中包含账号、补偿申请单号等关键敏感字段，分块时需避免拆分跨字段的关联内容，否则会导致后续核验与判断出错。同时，部分文档存在多sheet的Excel格式，解析时需支持读取不同标签页的内容，否则会遗漏部分补偿申请数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---|---|--- |
| `chunkSize` | 800–1200 字符 | 适配玩家工单、舆情评论的单块内容长度，避免拆分账号、补偿类型等关键字段 |
| `chunkSplitter` | 按段落+标题拆分 | 匹配舆情日报、处理话术的结构化排版，保留上下文关联 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 60–120 秒 | 适配实时/日更的文档处理节奏，避免大体积Excel解析超时 |
| `UPLOAD_FILE_MAX_SIZE` | 100 MB | 兼容批量导入的舆情日报压缩包、多sheet补偿申请Excel |
| `customPdfParse` | 开启 | 优化PDF格式的舆情日报解析，保留表格与标题层级 |
| `chunkSettingMode` | 手动配置 | 针对不同文档类型（工单/舆情/话术）调整分块规则，适配品类专属文档结构 |

## 容易做错的三处
- 上传Excel文件后仅加载默认sheet，无法读取其他标签页的内容。原因是未配置适配多sheet文档的解析规则，未启用对应格式的全sheet读取功能。
- 导入PPT、DOC文档时勾选PDF增强后无解析效果。原因是PDF增强功能仅针对PDF格式文档生效，未切换对应文档类型的解析模式。
- 外部调用时无法同时获取知识库调用参数与流式返回的完整结果。原因是未配置通用解析逻辑绑定返回字段，未正确处理流式数据的分段拼接。

## 怎么确认配好了
- 上传包含多个sheet的补偿申请Excel，检查解析结果是否包含所有sheet的内容与对应名称。
- 分别上传PPT、DOC、PDF格式的舆情日报，确认PDF格式可正常解析且保留表格结构。
- 调用FastGPT v4.17.0的外部接口测试解析流程，确认返回结果包含知识库调用参数与流式返回的完整内容。
- 调整`chunkSize`参数后上传短文本玩家工单，检查分块结果是否未拆分账号ID等关键字段。
