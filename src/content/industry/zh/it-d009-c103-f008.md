# 美术资产生产管理的需求与设计文档起草：工作流编排

## 这个品类的数据长什么样
该品类的数据主要来自美术资产库、项目管理系统、引擎资源包及外包交付包。日常产出的文档包含美术需求单、资产规格表、外包反馈表与验收记录，字段涵盖资产唯一标识、三角面数、像素分辨率、交付时限、验收状态等，单位涉及像素、三角面数、MB、天等。数据更新频率多为每日或每周，由美术团队、外包方及项目管理人员同步维护。不同于关卡内容制作，该品类聚焦角色、场景及特效类资产的交付管理。

## 这些特征在「工作流编排」这一环带来什么约束
多源数据来源要求工作流需支持对接多个系统的字段提取，避免手动录入误差。固定的文档结构与字段要求工作流的`variables`配置需精准匹配各文档的必填项，否则会导致流程中断。日/周级别的更新频率要求工作流触发规则需支持按周期或事件触发，适配不同的同步节奏。最耗时的规格确认与外包返修环节，要求工作流需内置审批、循环节点以减少重复沟通，而出错后果如资源不匹配、性能超标，则要求流程需加入规格校验环节，提前拦截异常数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 关联美术需求单、资产规格表的字段，提取资产ID、三角面数、交付时限（默认`30天`） | 匹配日常文档的字段结构，确保流程流转时可获取准确数据 |
| `nodeId` | 绑定验收记录的状态变更节点，设置为验收通过/不通过触发 | 适配数据更新的事件触发逻辑，无需手动启动流程 |
| 循环触发配置 | 按`7天`周期触发外包返修检查 | 匹配数据周更频率，及时跟进未完成的返修任务 |
| 规格校验规则 | 匹配引擎资源的三角面数阈值`10000面`、文件大小阈值`500 MB` | 提前拦截不符合规格的资产，避免后续性能超标 |
| 知识库关联配置 | 绑定美术资产库的对应项目分类 | 快速调取历史资产数据，辅助需求与设计文档起草 |

## 容易做错的三处
- 现象：调用工作流API时返回404错误，无法触发流程。原因：未正确配置`nodeId`对应的触发节点，未在FastGPT v4.17.0平台内生成对应接口凭证。
- 现象：工作流无法循环执行外包返修沟通流程，提交多次返修请求后未自动终止。原因：未开启循环编排配置，未设置明确的循环终止条件，如连续3次验收通过。
- 现象：全局变量中的美术资产库选择无法随项目动态赋值。原因：未将`variables`配置关联到项目管理系统的项目ID字段，导致变量无法自动匹配对应项目的资产库。

## 怎么确认配好了
- 检查`variables`配置是否覆盖了美术需求单、资产规格表的所有必填字段，可通过预览节点查看变量提取结果是否完整。
- 触发一次测试工作流，验证验收状态变更后是否按预期触发后续节点，确认事件触发逻辑生效。
- 测试循环编排节点，提交3次以内的返修请求，验证是否在满足验收通过的条件后自动停止循环。
- 查看平台生成的API文档，确认`nodeId`对应的触发接口已生成，可通过工具调用验证接口返回正常。
