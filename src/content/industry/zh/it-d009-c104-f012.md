# 落地页转化优化的需求与设计文档起草：文档解析与分块

## 这个品类的数据长什么样
落地页转化优化的日常文档包含落地页方案、埋点需求清单、AB测试报告、表单字段配置表。数据来源为落地页访问日志、热力图数据、表单提交记录、广告来源参数。更新频率按周或单次活动周期调整。文档结构混合结构化字段清单与非结构化分析描述，字段包含页面停留时长、表单提交次数、广告渠道标识等，无固定统一的统计数值格式。

## 这些特征在「文档解析与分块」这一环带来什么约束
落地页转化优化的文档混合结构化字段与非结构化分析内容，要求分块时保留字段与对应分析的上下文关联，避免拆分埋点清单的单条字段或AB测试报告的实验分组数据。按周或活动周期更新的文档，需要分块规则适配频繁迭代的内容，避免因固定分块长度导致更新内容被割裂。多来源的混合文档格式，要求解析工具兼容不同文档类型的结构特征，无法使用通用的按字符一刀切的分块逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配落地页方案、埋点清单的单章节长度，保留字段与分析内容的关联上下文 |
| `chunkSplitter` | 按文档结构拆分 | 适配AB测试报告、表单字段清单的结构化格式，避免拆分单条埋点字段的关联信息 |
| `customPdfParse` | 开启 | 解决PDF上传后内嵌图片无法查看的问题，保留文档内的热力图、实验结果图表元素 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配活动周期内累积的落地页日志与报告文档的上传需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 避免大型AB测试报告解析超时，保证完整解析所有实验数据与分析内容 |
| `chunkSettingMode` | 手动配置 | 针对落地页转化优化的专属文档类型，自定义分块规则适配混合结构的文档 |

## 容易做错的三处
- 上传docx、excel文档后知识库回答准确率低，现象为解析后字段缺失或关联断裂，原因是未按文档结构配置分块规则，将结构化的埋点清单拆分为无关联的零散片段。
- PDF上传后无法查看内嵌图片，现象为解析后文档内的热力图、图表元素丢失，原因是未开启`customPdfParse`配置项。
- 大型活动报告解析超时，现象为返回超时报错或解析任务失败，原因是未将`PARSE_FILE_TIMEOUT_SECONDS`调整至适配大型文档的取值。

## 怎么确认配好了
- 上传一份测试用的落地页方案文档，检查解析后的分块是否保留了埋点字段与对应方案描述的关联。
- 上传带内嵌图表的PDF文档，确认解析后可正常查看所有图片元素。
- 上传1000 MB以内的大型AB测试报告，确认解析过程无超时报错。
- 进入FastGPT v4.17.0的配置页面，确认`chunkSettingMode`设为手动配置且`chunkSize`处于800–1200字符区间。
