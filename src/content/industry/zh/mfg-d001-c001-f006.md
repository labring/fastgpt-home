# PCB制造的供应商与过程质量审核：引用来源与溯源

## 这个品类的数据长什么样
该品类的数据主体为印制电路板工厂的工程、生产、品质与实验室人员。日常文档包含工程制作指示、Gerber解析记录、钻孔和层压参数、药水分析报告、AOI报告、电测报告、切片报告。数据来源涵盖客户Gerber文件、钻带、BOM清单，CAM文件，设备运行参数，槽液化验结果，AOI、电测与实验室检测数据。数据按每生产批、每班或连续采集的节奏更新生成，覆盖从客户资料转换到成品检测的全流程环节。

## 这些特征在「引用来源与溯源」这一环带来什么约束
PCB制造的多批次、高频更新数据特征，要求引用溯源需精准匹配单生产批的对应文档，避免跨批次数据混淆。不同文档的字段差异显著，如层压参数含压力、温度单位，切片报告含孔径偏差数值，需在溯源时保留原始字段与单位。连续采集的实时数据与批量生成的报告数据并存，需区分数据的采集时间戳与生成节点，确保引用的是对应审核环节的最新有效数据。同时，引用错误的核心文档可能导致整批板报废，需严格绑定数据来源与审核环节的对应关系。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | `8000–12000 token` | PCB制造的审核文档包含多份专业参数报告，需容纳足够的引用内容以覆盖全流程审核信息 |
| `responseData` | 开启并绑定原始文档ID | 需保留数据来源的唯一标识，便于精准溯源到对应生产批的具体文档 |
| `detail` | 完整输出 | 审核需覆盖钻孔、层压、检测等多环节的细节数据，完整输出可确保信息全面无遗漏 |
| 相似度阈值 | `0.75–0.85` | PCB文档的专业术语多，该区间可平衡召回精度与覆盖范围，避免遗漏关键参数 |
| 单次搜索上限 | 前6条 | 单生产批的审核相关文档数量有限，过多引用会超出上下文承载限制 |
| 重排 | 开启 | PCB文档的相关性判断需结合专业语义，重排可优化检索结果的排序准确性 |

## 容易做错的三处
- 现象为开启重排功能后，检索结果为空或引用片段消失。原因是相似度阈值设置过低，过滤掉了原本符合要求的PCB专业文档片段。
- 现象为引用请求超时，无法返回审核所需的参数报告内容。原因是`quoteMaxToken`设置过小，或上下文加载未适配长文档的加载需求。
- 现象为无法自定义引用提示词或模板，仅能调整基础参数。原因是使用的FastGPT版本低于v4.17.0，需升级到对应版本后使用高级配置功能。

## 怎么确认配好了
- 上传单生产批的典型文档，发起审核查询，核对返回结果中是否包含对应文档的原始标识与字段内容。
- 调整重排功能的启用状态，对比检索结果的排序与召回数量，确认重排功能正常生效。
- 查看系统版本标识，确认当前使用FastGPT v4.17.0及以上版本，确保高级配置功能可用。
- 模拟跨批次的文档检索，确认返回结果仅关联当前审核的生产批数据，无跨批次数据混淆。
