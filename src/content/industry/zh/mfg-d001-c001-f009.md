# PCB制造的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
本品类数据来自印制电路板工厂的工程、生产、品质与实验室部门，包含工程制作指示、Gerber解析记录、钻孔和层压参数、药水分析、AOI报告、电测报告、切片报告等文档。数据来源覆盖客户Gerber/钻带/BOM、CAM、设备参数、槽液化验、AOI、电测和实验室数据，更新频率为每生产批、每班、连续采集，部分检测数据如AOI报告为实时生成。数据包含文本参数、CAD格式文件与图像类检测结果，字段覆盖工艺参数值、缺陷坐标、浓度指标等专业制造业内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源混合的数据类型要求模型接入需支持文本与图像的多模态处理，适配AOI报告、切片报告的图像解析需求。高频更新的生产数据要求单次处理的上下文长度需匹配单生产批的数据总量，避免因上下文溢出导致处理失败。专业的制造业字段与文档格式要求模型需具备行业术语理解能力，同时质量审核出错会导致整批板报废或高额索赔，需严格控制模型输出的准确性，因此需降低模型的随机性参数，避免错误判定。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `vision` | 开启（适配多模态模型） | PCB制造场景包含AOI报告、切片报告等图像类检测数据，需开启视觉理解能力解析图像缺陷内容 |
| `temperature` | 0.1–0.3 | 过程质量审核需严格匹配检测数据与工艺参数，低温度可降低模型幻觉概率，避免错误判定缺陷类型 |
| `maxTokens` | 8000–12000 token | 单生产批的工艺参数、检测报告总长度较大，需适配长上下文处理需求，可按实际数据量按实测标定调整 |
| `quoteMaxToken` | 1500–2000 token | 限制单份引用文档的长度，避免AOI报告、Gerber解析记录等单份文件过长占用过多上下文资源 |
| `AIPROXY_API_ENDPOINT` | 填写企业内部模型代理地址 | 适配制造业数据保密要求，对接自有或合规的第三方大模型服务 |
| `AIPROXY_API_TOKEN` | 填写企业分配的访问密钥 | 保障模型调用的安全性，防止未授权访问企业生产与检测数据 |

## 容易做错的三处
- 尝试调用前端嵌入页面时无法加载，原因是FastGPT v4.17.0版本仅支持API调用模式，需通过API对接自有系统开发前端界面。
- 模型配置测试通过但应用中无法正常使用，原因是应用未关联已配置的模型参数，或`AIPROXY_API_TOKEN`、`AIPROXY_API_ENDPOINT`配置有误，导致模型调用失败。
- 图像类检测数据无法被正确解析，原因是未开启`vision`参数，或未接入支持多模态能力的模型，无法读取AOI报告、切片报告的图像内容。

## 怎么确认配好了
- 传入单生产批的工艺参数与AOI报告图片，调用模型测试接口，验证模型是否能正确识别缺陷类型与位置。
- 检查`AIPROXY_API_TOKEN`与`AIPROXY_API_ENDPOINT`的配置，发起模拟调用请求，确认网络连通性与访问权限正常。
- 调整`temperature`参数至0.1和0.3，对比两次模型输出的缺陷判定结果，确认结果一致性符合质量审核要求。
- 同时传入Gerber解析记录与电测报告，验证模型能否整合两类数据完成完整的质量审核流程。
