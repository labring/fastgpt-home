# SMT贴片与电子组装的供应商与过程质量审核：部署与升级

## 这个品类的数据长什么样
该品类的数据包含BOM与坐标文件、换线表、钢网与炉温记录、首件确认报告、SPI/AOI检测报告、维修记录与追溯标签等。数据来源涵盖客户提供的BOM、Gerber与坐标文件，工厂MES系统、锡膏与元件批次台账、贴片机、SPI/AOI检测设备及回流焊炉温记录。数据更新频率为每工单、每次换线及实时，字段包含料号、位号、元件批次、炉温曲线参数、坐标位置等，部分检测报告与钢网文件采用二进制格式存储。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据来源分散且更新频率高，需对接多类设备与系统接口，部署时需配置多数据源的适配规则。数据包含元件批次、炉温等敏感信息，需保障内网部署的安全性，避免公网泄露。复杂的文档结构要求系统支持多格式文件的解析与元数据提取，升级时需兼容旧版本导出的字段格式。高频更新的数据会带来数据库与缓存的负载压力，需合理配置连接参数避免过载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `10–30 条` | 匹配SMT工单的单次搜索数据量，避免内网带宽过载与查询超时 |
| `MONGODB_URI` | `绑定内网专用网段的实例地址` | 存储元件批次、追溯标签等敏感数据，需内网部署保障信息安全 |
| `REDIS_URL` | `配置持久化缓存参数` | 应对实时更新的工单与检测数据，高频读取需求通过缓存降低数据库压力 |
| `FILE_TOKEN_KEY` | `与企业文件服务器对齐的密钥` | 对接钢网、炉温记录等二进制文件，统一密钥保障文件访问权限 |
| `STORAGE_S3_ENDPOINT` | `企业自建对象存储的内网端点` | 存储大量SPI/AOI报告等文件，内网端点避免公网传输延迟与安全风险 |

## 容易做错的三处
- 导入旧版本导出的知识库数据时触发训练报错，原因是旧版本导出的字段与FastGPT v4.17.0的CSV模板必填字段不匹配，未按要求调整BOM、坐标文件对应的元数据字段。
- 知识库搜索返回结果条数与预期不符，原因是未正确设置`DB_MAX_LINK`参数，取值超出内网网络承载能力或未匹配实际数据量。
- 模型调用出现超时错误，原因是未针对SMT实时数据的高频请求配置合理的缓存策略，导致数据库连接池耗尽。

## 怎么确认配好了
- 上传测试用的BOM与坐标文件，检查系统能否正确解析料号、位号字段，确认文件处理配置生效。
- 发起模拟工单的搜索请求，检查返回结果条数与`DB_MAX_LINK`的配置值一致。
- 查看内网数据库与缓存的连接日志，确认`MONGODB_URI`与`REDIS_URL`的配置无连接超时或权限错误。
- 导入旧版本格式的知识库数据，检查是否触发字段校验相关的报错，确认模板适配配置正确。
