# 光伏电池片制造的供应商与过程质量审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
通常晶硅电池片制造的供应商与过程质量审核相关数据，来源包括硅片来料记录、车间MES系统、扩散炉/镀膜/印刷设备日志、EL与IV测试结果、实验室检测报告。日常文档涵盖工艺卡、扩散与镀膜参数、印刷烧结记录、EL检测图、IV分档数据、良率报告。数据更新节奏按每批来料、每片检测结果、每日汇总执行，字段包含工艺参数值、缺陷类型、电性能指标、批次追溯码等。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
多源异构的数据来源要求接口兼容不同格式的请求与响应，适配设备日志、测试报告等不同类型的数据同步。高频率的更新节奏（每批、每片、每日）要求接口具备低延迟与高并发处理能力，避免数据积压。EL检测图等图片类数据的存在，要求接口支持二进制或多部分表单数据传输。批次追溯的核心需求，要求接口必须携带唯一业务标识参数，确保数据与对应批次精准绑定。同时，缺陷识别与分档的准确性要求，需接口返回完整的校验字段，避免关键信息缺失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {企业专属API密钥}` | 光伏电池片生产数据属于车间敏感数据，需通过标准Bearer令牌鉴权，防止未授权访问 |
| `variables` | `{"batchId": "string", "testType": "EL/IV"}` | 匹配批次追溯与多类型检测的业务需求，传递核心业务标识参数 |
| `responseData` | `include defectInfo, ivScore, batchTrace` | 仅返回审核所需核心字段，减少数据传输量，适配高频率数据同步场景 |
| 文件传输格式 | `multipart/form-data`，单文件最大 100 MB | EL检测图单张通常不超过50 MB，按实测标定最大上传阈值 |
| 失败重试次数 | 3 次 | 适配设备偶发断连的场景，避免单次请求失败导致数据丢失 |
| 流式返回开关 | `true / false` | 实时审核场景使用流式返回，批量同步场景使用非流式 |

## 容易做错的三处
- 现象：调用接口返回401 Unauthorized状态码，无法正常建立连接。原因：未正确配置`Authorization`参数，未携带企业专属API密钥或密钥格式不符合Bearer令牌规范。
- 现象：将`stream`参数设置为true时，仅收到部分分段数据，无法获取完整审核结果。原因：未按流式响应的逐段拼接逻辑处理，未等待最后一个`data: [DONE]`标记结束。
- 现象：上传EL检测图后接口返回参数格式错误。原因：未使用`multipart/form-data`格式传输图片，误将图片二进制数据转为Base64字符串放入JSON请求体。

## 怎么确认配好了
- 使用FastGPT v4.17.0版本的工作流API，携带正确的`Authorization`参数发起测试请求，确认返回状态码为200 OK。
- 开启流式返回开关，逐段接收响应数据，确认能完整拼接出包含缺陷信息、电性能指标的最终审核结果。
- 上传测试用EL检测图，使用`multipart/form-data`格式提交，确认接口能正确解析并返回对应检测字段。
- 配置批量同步任务，检查接口返回的`responseData`字段是否包含预设的批次追溯码、工艺参数等核心业务信息。
