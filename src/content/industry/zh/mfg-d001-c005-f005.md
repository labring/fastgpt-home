# 光伏电池片制造的供应商与过程质量审核：工具调用与插件

## 这个品类的数据长什么样
该品类的数据通常来自硅片来料台账、生产MES系统、扩散炉/镀膜设备/印刷机的运行日志、EL与IV测试设备输出、实验室品质检测数据。数据更新节奏覆盖每生产批次、每片成品检测、每日汇总环节。日常文档包含工艺卡、扩散和镀膜参数配置表、印刷烧结工序记录、EL缺陷检测图、IV性能分档数据、批次良率报告，核心字段包含转换效率值、隐裂等级、色差参数、烧结温度区间等，单位多为百分比、瓦、像素级缺陷标识。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的片级、批次级高频数据特征，要求工具调用支持多源异构数据的定向拉取，包括结构化的工艺参数、非结构化的EL检测图与IV测试报告。高频更新节奏要求工具触发逻辑匹配生产节点，避免拉取过期的未完成工序数据。多维度的核心字段需求，要求插件配置需支持自定义字段映射，将工具返回的原始数据对应到光伏电池片制造的专属指标。同时，工序连续且微结构敏感的特点，要求工具调用需关联上下游工序数据，避免孤立分析导致的偏差。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | 自动 | 适配多工具并行调用的场景，匹配光伏制造多工序审核的多源数据需求 |
| 工作流/API 函数调用配置 | 开启 | 支持结构化返回工艺参数与检测数据，便于后续质量分析与追溯 |
| 工具触发时机 | 按生产批次完成后 | 匹配该品类按批次汇总数据的更新节奏，避免拉取未完成的工序数据 |
| 字段映射规则 | 关联转换效率、隐裂等级、良率字段 | 对应该品类核心业务审核指标，确保返回数据贴合业务场景 |
| 单次调用数据量 | 100–500 条 | 适配批次级数据的批量拉取，避免接口过载或数据解析超时 |
| 超时阈值 | 300–600 秒 | 匹配设备日志与EL/IV检测报告的生成周期，适配长耗时的非结构化数据解析 |

## 容易做错的三处
- 接口调用返回514状态码。原因是未配置对应光伏电池片制造场景的数据权限，工具无法定向拉取EL检测图或IV分档数据。
- 无法找到联网插件的替代API调用入口。原因是未开启自定义API配置项，仅绑定了默认的模型调用接口。
- 工作流中通过API传入的变量无法触发知识库搜索节点。原因是未将传入变量的格式匹配为知识库支持的批次号或硅片ID字段。

## 怎么确认配好了
- 发起一次模拟生产批次的API调用，检查返回数据是否包含转换效率、隐裂等级等核心业务字段。
- 查看工具调用日志，确认`toolChoice`参数生效，自动匹配了所需的多工具调用逻辑。
- 测试变量引用功能，传入预设的硅片ID，检查知识库搜索节点是否返回对应批次的工艺卡数据。
- 模拟长耗时的EL检测图解析请求，验证超时阈值配置是否生效，未触发超时报错。
