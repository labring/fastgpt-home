# 光伏电池片制造的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
该品类的数据通常来自硅片来料台账、生产MES系统、扩散炉/镀膜设备/印刷机的运行日志、EL与IV测试报告、实验室质检记录。数据更新节奏覆盖每批次生产、每片产品检测结果、每日汇总统计。日常文档包含工艺卡、扩散与镀膜参数表、印刷烧结工序记录、EL缺陷检测图、IV性能分档数据、良率汇总记录。数据字段包含批次编号、工艺参数值、缺陷类型标识、电性能测试数值等，随对应检测项匹配不同的数值单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
由于该品类包含视觉类的EL检测图与多源结构化参数数据，模型接入时需适配视觉推理与多模态数据处理的配置要求。高频次的片级与批次数据更新，要求上下文窗口配置可容纳单批次完整文档量，避免截断关键工艺与质检信息。多来源的异构数据格式，需要明确工具调用的触发规则，适配不同数据的解析逻辑。同时，片级精细数据的处理需求，要求模型的输出精度与上下文召回的精准度匹配，避免冗余或缺失关键字段，FastGPT v4.17.0版本的配置逻辑可更好适配这类多源数据的整合。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `vision` | 开启 | 该品类包含EL检测图等视觉类质检文档，需模型支持图像解析 |
| `maxContext` | 8000–12000 token | 单批次生产的工艺与质检文档总量通常覆盖多份参数表与检测记录，需完整容纳上下文信息，适配FastGPT v4.17.0的上下文窗口逻辑 |
| `maxTokens` | 2000–3000 token | 单条审核结论的输出需覆盖工艺参数分析与缺陷判定，避免输出截断 |
| `toolChoice` | auto | 需根据用户查询自动选择调用结构化参数查询或视觉数据解析工具 |
| `temperature` | 0.2–0.4 | 审核类任务需保持输出的一致性与精准度，避免过度随机化 |
| `AIPROXY_API_TOKEN` | 填写对应大模型的访问密钥 | 需通过合法密钥完成模型调用的身份验证，保障访问安全 |

## 容易做错的三处
- 现象为迁移知识库后，后台知识库页面可显示所有文字内容，但发起对话时模型返回知识库为空。原因是未正确配置上下文召回的关联规则，导致对话时未触发对应知识库的检索逻辑。
- 现象为调用MCP工具时，使用对应大模型返回400状态码，不调用工具时可正常使用模型。原因是MCP工具调用的参数格式与大模型的接口要求不匹配，未正确适配工具调用的请求结构。
- 现象为新建问题分类节点，使用初始化的默认AI模型时，运行或保存发布报错，切换AI模型后报错消失。原因是初始化模型的接口权限或参数配置未适配问题分类节点的输入输出格式，需重新匹配模型能力。

## 怎么确认配好了
- 上传单份EL检测图与对应工艺参数文档，发起包含视觉数据解析的查询，核对模型是否能正确识别图像中的缺陷信息。
- 发起针对单批次生产数据的查询，核对模型返回的内容是否包含知识库中对应批次的完整参数与检测记录。
- 配置MCP工具调用后，发起需要调用工具的查询，核对工具返回的结构化数据是否被正确整合到模型输出中。
- 查看模型调用的日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置未出现格式错误或权限异常，核对FastGPT v4.17.0的版本是否与当前部署环境一致。
