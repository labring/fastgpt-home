# 光伏组件封装的供应商与过程质量审核：知识库检索与召回

## 这个品类的数据长什么样
光伏组件封装环节的数据来自电池片分档台账、玻璃胶膜背板批次记录、车间MES系统、串焊与层压生产设备、EL/IV测试仪。数据更新节奏为每块组件生成一套测试记录，每批原材料生成批次溯源文档。日常文档包含工艺排版图、材料批次台账、层压温度压力时间记录、EL隐裂图像、IV功率测试报告、绝缘耐压记录、成品包装清单。字段包含电池片电流档位、层压工艺参数、隐裂坐标、功率值、绝缘电阻值等，对应单位为安培、摄氏度、帕斯卡、瓦、兆欧。

## 这些特征在「知识库检索与召回」这一环带来什么约束
高频次的单组件/单批次更新要求检索系统支持增量召回，避免全量索引重建的延迟。多类型文档混合存在，需要同时适配图文类EL图与数值类测试报告的检索逻辑。专业字段如电池片电流档位、层压工艺参数要求检索匹配精度，需过滤非相关的通用文档。跨环节的数据关联需要召回串焊、层压、测试等不同环节的关联文档，要求检索范围可按业务模块隔离。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 匹配电池片电流档位、层压工艺参数等专业字段的精准度要求 |
| `limit` | `前10条` | 单批次材料或单块组件的关联文档量适中，避免上下文溢出 |
| `searchMode` | `mixedRecall` | 同时处理图文类EL隐裂图像与数值类IV测试报告的检索需求 |
| `usingReRank` | `开启` | 过滤EL图检索中的非隐裂相关结果，提升专业判读的召回准确性 |
| `datasetSearchUsingExtensionQuery` | `开启` | 补充电池片分档的关联批次信息，完善材料溯源的检索覆盖 |
| `collectionIds` | `按串焊/层压/测试模块绑定的ID集合` | 隔离不同生产环节的文档，避免跨模块的无效召回 |

## 容易做错的三处
- 出现`Query read timeout`报错，原因是未针对大体积EL图或IV报告调整检索超时配置，导致数据加载超时。
- 传入知识库ID后无搜索结果，原因是未正确配置`collectionIds`参数，或检索范围未覆盖对应生产环节的文档库。
- 调用apiCollection接口返回`Invalid URL, code: 500`，原因是上传的文档路径包含未转义的特殊字符，或未匹配光伏组件封装文档的格式要求。

## 怎么确认配好了
- 检索「电池片电流档位」关键词，确认返回结果包含对应批次的材料溯源文档。
- 触发EL图检索，确认重排后的结果优先展示隐裂判读相关的专业文档。
- 查看FastGPT v4.17.0的检索日志，确认`similarity`参数的取值生效，召回结果符合预设阈值。
- 验证外部传入`collectionIds`后，仅返回对应业务模块的文档内容，无跨模块的无效结果。
