# 冲压与板材成形的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
冲压与板材成形场景的典型主体为汽车覆盖件、家电钣金、五金件企业的冲压车间。日常产生的文档包括冲压作业指导书、材料利用率表、模具点检表、首末件记录、尺寸检验报告、换模记录。数据来源涵盖钢卷标签与质保书、冲床和送料机实时数据、模具管理系统、MES系统、三坐标或检具检测数据。数据更新频率为每卷料、每批生产物料、每次换模操作时更新。

## 这些特征在「模型接入与配置」这一环带来什么约束
冲压与板材成形的业务数据更新频率高且批次差异显著，每卷钢卷、每批生产物料、每次换模操作均会产生新的业务数据，要求模型上下文配置需适配批量短周期更新的多份文档片段。多源异构的数据来源意味着模型需处理不同格式的结构化与非结构化数据，配置时需考虑对不同数据源的适配性。同时，供应商与过程质量审核场景对结果准确性要求极高，参数调整需兼顾响应速度与内容可信度，避免因配置不当导致审核结果偏差。此外，跨系统的数据交互需确保配置的网络连通性与权限合理性，适配私有化部署的本地调用需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配每卷料、每次换模产生的多份文档总长度，确保覆盖单次审核所需的全部关联数据 |
| `maxTokens` | 2000–3000 token | 满足质量审核类问题的回答长度需求，避免超出模型输出上限 |
| `quoteMaxToken` | 4000 token | 限制模型引用的文档片段总长度，防止模型生成超出实际文档范围的伪造引用ID |
| `temperature` | 0.1–0.3 | 降低回答随机性，提升质量审核结果的一致性与准确性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写内网或公网地址，例如 `https://volc-private-llm.example.com/v1` | 适配火山云私有化部署的大模型接入，确保docker容器可正常访问目标地址 |
| `AIPROXY_API_TOKEN` | 填写私有化模型的访问密钥 | 完成模型身份验证，保障接入安全性 |

## 容易做错的三处
- 现象：模型生成的质量审核回答中出现未在上传文档中出现的伪造引用ID。原因：未正确配置`quoteMaxToken`参数，导致模型无法准确匹配现有文档片段，生成超出实际文档范围的引用内容。
- 现象：连续发起的会话无法保留上下文关联信息。原因：未在FastGPT v4.17.0的会话配置中启用上下文关联，导致会话ID未被正确传递与绑定。
- 现象：docker本地部署的FastGPT无法连接火山云私有化大模型。原因：未配置正确的`AIPROXY_API_ENDPOINT`内网地址，或容器未开放对应端口的网络访问权限。

## 怎么确认配好了
- 上传一份冲压作业指导书与模具点检表，发起“核对本次换模的压边力参数”的测试请求，检查返回结果是否包含文档中明确提及的参数内容。
- 发起两次连续的质量审核会话，查看FastGPT后台日志，确认会话ID被正确记录并关联两次请求的上下文。
- 在docker容器中执行模型连接测试命令，检查日志是否显示模型连接成功的提示信息。
- 调整`temperature`参数至0.2，发起三次相同的审核请求，检查三次返回结果的差异是否符合预期的低随机性。
