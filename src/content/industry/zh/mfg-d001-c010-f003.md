# 医疗器械装配与洁净生产的供应商与过程质量审核：多轮对话与提示词

## 这个品类的数据长什么样
本品类的数据来源包括设计历史文件、器件与材料批次数据、MES系统、洁净环境监测设备、灭菌设备及检验校准系统。更新节奏为每批或每台产品更新一次，洁净区环境监测按既定计划定期更新。日常文档涵盖生产工艺规程、批生产记录、洁净区运行记录、灭菌批记录、检验报告、软件版本记录、不良事件与追溯资料，字段包含批次号、灭菌温度（℃）、灭菌时长（分钟）、洁净区温湿度、材料唯一标识编号、软件版本号等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
本品类的数据多且按批次、周期更新，要求多轮对话必须绑定单批次会话上下文，避免跨批次数据混淆。文档字段多且包含高风险参数，提示词需精准限定提取特定字段，防止无关数据干扰审核。数据来源涉及生产与环境监测设备，对话需支持实时拉取最新的批记录与环境数据，确保审核依据的时效性。此外，医疗器械的追溯要求需对话保留完整的审核上下文，便于后续验证。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 最大上下文长度 | 8000–12000 字符 | 匹配单批生产记录的文档长度，避免截断关键灭菌、洁净数据 |
| 会话绑定规则 | 按`chatId`限定单批次会话 | 确保对话仅关联当前审核批次的文件，避免跨批次数据混淆 |
| 变量绑定规则 | 绑定`variables`为当前批次号与洁净区编号 | 自动拉取对应批次的批生产记录与环境监测数据 |
| 多模态识别开关 | 开启，限定仅识别JPG/PNG格式 | 适配洁净区监控图片、灭菌记录扫描件的审核需求 |
| 会话超时时间 | 600 秒 | 适配单批次审核的完整流程时长，避免中途中断 |
| 引用文件展示 | 按需开启 | 符合医疗器械追溯要求，仅在需要验证时展示引用源 |

## 容易做错的三处
- 现象：多轮对话中调用提示词时，无法获取当前会话的历史上下文内容。原因：未正确配置`chatId`绑定当前会话，导致提示词无法关联已提交的审核记录与`messages`历史对话内容。
- 现象：开启多模态图片识别后，上传洁净区监控图片或灭菌记录扫描件时，回复提示无法提供图片内容。原因：多模态识别开关未开启，或提示词未明确允许处理图片格式的输入。
- 现象：对话回复底部强制展示引用的批生产记录文件，无法按需隐藏。原因：引用文件展示开关配置为全局开启，未根据审核节点的要求调整为按需开启。

## 怎么确认配好了
- 提交单批次的批生产记录与洁净区监测数据，检查对话是否仅返回该批次的相关内容，无跨批次数据混入。
- 上传符合要求的JPG或PNG格式的图片，检查对话是否能正确识别并关联图片中的关键信息，如灭菌参数、温湿度记录。
- 发起多轮对话，后续提问无需重复提交批次信息，检查对话是否能基于之前的审核上下文进行响应。
- 调整引用文件展示开关的配置，检查回复底部是否不再强制展示引用文件，或按需展示。
