# 半导体封装测试的供应商与过程质量审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据覆盖封装全流程的过程与结果记录，日常文档包含封装流程卡、键合与塑封参数、晶圆来料图、测试程序版本、良率报告、失效分析报告。数据来源于晶圆测试图、生产执行系统（MES）、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格要求，更新频率覆盖每生产批次、每颗芯片测试、每日汇总环节，字段包含批次号、测试bin值、参数阈值、失效类型等，无统一固定长度，随检测项目动态调整。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据更新频率覆盖批次、单颗测试与每日汇总，高频且多粒度的调用需求要求接口设置合理的超时与重试机制；多源异构的数据来源与多样的文档字段，要求接口支持自定义字段映射与动态参数结构；严格的批次管控要求，接口需绑定唯一批次标识作为必传参数，避免跨批次数据混淆。同时，失效分析报告等文档体积存在差异，接口需适配合理的数据传输大小，防止单次请求过载。

## 配置怎么定
本章节的配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {封装厂专属API密钥}` | 用于对接外部MES、ATE测试机等系统的身份校验，符合工业级接口的安全规范 |
| `variables` | `{"batchNo": "必传", "testBinValue": "可选", "deviceSn": "可选"}` | 适配半导体封装测试的批次、测试结果、设备标识等核心业务字段需求 |
| `responseData` | `提取返回结果的根节点字段` | 适配不同外部系统返回的数据结构，便于后续同步至良率报告或流程卡系统 |
| 请求超时时间 | `300–600 秒` | 适配工业设备数据传输的延迟特性，避免因设备响应缓慢导致请求中断 |
| 请求重试次数 | `3 次` | 避免因临时网络波动重复触发生产环节的校验操作 |
| 单次请求最大数据量 | `50 MB` | 适配封装流程卡、失效分析报告等文档的传输需求，防止请求过载 |

## 容易做错的三处
- 现象：接口返回`401 Unauthorized`状态码，且无法同步外部系统的批次数据。原因：未正确配置`Authorization`参数，或使用了过期的API密钥，未匹配对应系统的身份校验规则。
- 现象：调用接口后，良率报告中出现跨生产批次的测试数据。原因：未在`variables`中必传batchNo字段，导致接口无法区分不同批次的数据，引发数据错位。
- 现象：接口请求长时间无响应，最终触发超时错误。原因：未设置合理的请求超时时间，或未针对ATE测试机的慢响应场景调整参数，导致工业设备的数据传输未完成即被中断。

## 怎么确认配好了
- 调用测试接口，检查返回的`responseData`字段是否包含与测试批次匹配的有效数据。
- 查看接口日志，确认每次请求都携带了正确的`Authorization`参数，无身份校验失败记录。
- 模拟多批次数据调用，检查接口是否能正确区分不同batchNo的请求，无数据混淆情况。
- 调整请求超时时间，验证在工业设备正常响应的范围内，接口不会触发超时错误。
