# 半导体封装测试的供应商与过程质量审核：工具调用与插件

## 这个品类的数据长什么样
该品类的数据主要来自晶圆测试图、生产执行系统（MES）、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格文档。日常维护的文档包括封装流程卡、键合与塑封参数表、晶圆来料图、测试程序版本文件、良率报告及失效分析报告。数据更新频率覆盖每批物料、每颗芯片测试及每日汇总，字段包含芯片批次号、测试bin分布、设备参数阈值等，需适配多源异构的数据结构。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源异构的数据来源要求工具调用插件需支持对接工业设备API、MES接口及文档解析工具，适配不同的通信协议与数据格式。高频更新的特性要求工具调用的上下文长度需严格限制，避免因数据量过大导致模型上下文溢出。多样化的文档类型与字段要求工具参数需覆盖芯片批次号、测试程序版本、良率指标等特定字段，确保审核时能精准提取所需信息。同时，需支持晶圆图与实物批次的对齐操作，匹配来料信息与测试结果的关联关系。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 最大上下文长度 | 8000–12000 token | 单批次封装测试数据量较大，避免超出模型承载范围导致截断 |
| 工具调用重试次数 | 2–3 次 | 工业设备调用可能出现临时网络波动，减少无效流程中断 |
| 工具调用超时时间 | 30–60 秒 | 键合机、ATE测试机等设备响应需要一定时长，过长会阻塞整体审核流程 |
| 工作流/API 工具选择配置 | auto | 自动选择适配当前任务的工具，无需手动指定调用对象 |
| 工作流/API 函数调用配置 | strict | 严格校验工具调用的参数格式，确保符合封装测试文档的字段要求 |
| 插件数据格式校验 | 开启 | 对齐晶圆来料图、测试程序版本等结构化数据的字段规范 |

## 容易做错的三处
- 工具调用时出现上下文溢出报错，日志显示内容长度超限。原因是未限制最大上下文长度，单批次封装测试的良率报告、失效分析报告等数据量较大，超出模型承载范围。
- 工具调用解析失败，返回Tool call Parser相关报错。原因是推理模型返回的内容使用think标签包装后放入content字段，不符合预设的工具调用格式要求。
- 配置MCP server后出现转发错误，返回长错误代码。原因是未正确配置aiproxy的密钥转发规则，导致模型请求无法正常转发至目标服务。

## 怎么确认配好了
- 提交单批次封装测试的模拟数据，检查工具调用是否能自动触发对应的数据提取或设备查询动作。
- 查看工具调用日志，确认参数格式符合预设的封装测试文档字段要求，无解析报错。
- 测试工具调用的超时和重试逻辑，模拟临时网络波动，检查是否能按配置完成重试并返回有效结果。
- 对比配置的上下文长度与单批次数据的实际大小，确认未出现超出限制的情况。
