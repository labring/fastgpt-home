# 半导体封装测试的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据来源包含晶圆测试图、MES系统、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格书；更新节奏按生产批次、单颗测试结果、每日汇总；日常文档涵盖封装流程卡、键合与塑封参数表、晶圆来料图、测试程序版本文件、良率分析报告、失效分析报告；数据字段包含批次标识、参数阈值、测试bin码、良率值等，涉及封装温度、压力、测试电压电流等单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据更新频率高且粒度细，要求模型接入时支持实时拉取最新批次的测试数据与关联参数，避免使用过期上下文；多类型文档混合存在，要求配置的模型兼容结构化参数表、可视化晶圆图、文本报告的解析；设备与系统来源多样，要求接入配置支持多端点API适配；批次关联要求严格，要求配置时明确上下文的批次标识字段关联规则，避免数据错位影响审核准确性。

## 配置怎么定
以下配置项基于FastGPT v4.17.0版本设置。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `AIPROXY_API_ENDPOINT` | 从企业MES系统或ATE测试机的官方接口文档获取对应端点 | 该参数用于指定模型调用的目标服务地址，需匹配设备或系统的API规范，适配半导体封装测试的多源数据接入需求 |
| `AIPROXY_API_TOKEN` | 从企业内部API网关获取专属访问令牌 | 该参数用于身份验证，需符合设备与系统的安全接入要求，避免未授权访问生产数据 |
| `maxContext` | 8000–12000 token | 该品类的批次数据关联信息较多，需容纳多份测试报告、参数表的上下文内容，适配多源数据的审核需求 |
| `maxTokens` | 2000–3000 token | 单批次的失效分析与良率分析输出要求明确，需控制生成内容的长度避免冗余，符合审核文档的格式规范 |
| `vision` | 启用 | 需解析晶圆来料图、X-ray检测图像等可视化数据，适配封装测试的视觉校验与失效分析需求 |
| `temperature` | 0.2–0.4 | 参数配置与质量审核需严谨，避免生成不确定的分析结果，保障审核结论的一致性 |

## 容易做错的三处
- 现象：调用模型时返回401未授权状态码，或接口无法正常拉取测试数据。原因：未正确获取`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的有效值，误用了非官方端点或过期的访问凭证。
- 现象：模型无法解析晶圆来料图、X-ray检测图像等可视化数据，输出内容仅包含文本描述。原因：未启用`vision`配置项，导致模型未开启视觉解析能力。
- 现象：使用第三方部署的大模型时，GPU使用率持续偏低且CPU单核占用达到100%。原因：接入配置未绑定GPU设备标识，导致模型默认以CPU模式运行，未充分利用硬件资源。

## 怎么确认配好了
- 执行一次模型调用测试，上传指定批次的封装参数与测试数据，验证是否能正常拉取并生成审核内容，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置有效。
- 上传一份晶圆来料图至模型输入，验证是否能正确解析图像中的晶圆分区与标识信息，确认`vision`配置项生效。
- 调整`temperature`参数至不同区间，观察模型生成的分析报告的严谨性，确认参数取值符合业务审核的精度要求。
- 查看模型运行日志，确认上下文加载的批次标识与实际生产批次一致，验证`maxContext`的配置适配了多源数据关联需求。
