# 半导体封装测试的供应商与过程质量审核：知识库检索与召回

## 这个品类的数据长什么样
该品类数据来自晶圆测试图、MES系统、键合与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格文件。日常文档包含封装流程卡、键合与塑封参数表、晶圆来料图、测试程序版本文件、良率报告、失效分析报告。数据按生产批次、单颗测试结果及每日频次更新，文档包含明确的批次号、参数值、测试bin码、失效类型等字段，部分图纸类文档附带坐标与尺寸单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
晶圆来料图与实物批次的强关联要求检索需绑定批次号字段，避免跨批次匹配错误；高频更新的单颗测试数据、每日良率报告需检索链路支持实时增量同步；多源数据包含结构化参数表与非结构化图纸，需兼容两种文档格式的检索逻辑；键合与塑封参数的精准匹配要求检索召回结果需按参数精度排序，防止错用工艺参数导致生产异常。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的知识库检索功能。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配封装参数与测试程序的精准度要求，避免低匹配度的错误参数召回 |
| `limit` | 前10条 | 控制单次召回结果数量，适配单批次工艺参数与测试数据的检索量 |
| `searchMode` | `mixedRecall` | 兼容结构化参数表与非结构化图纸类文档的检索需求 |
| `usingReRank` | 开启 | 对召回结果按批次号与参数精度二次排序，优化匹配精准度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展批次号相关的检索词，提升晶圆来料图与实物批次的匹配效率 |
| `collectionIds` | 按生产批次分组的知识库集合 | 限定检索范围，避免跨批次文档的无效召回 |

## 容易做错的三处
- 调试预览阶段检索结果正常，嵌入自有页面后无检索结果或返回空列表。原因是页面未正确携带知识库授权的上下文参数，或跨域配置未覆盖FastGPT的检索接口域名。
- 检索结果中嵌入的晶圆测试图、X-ray检测图无法正常加载，界面显示图片加载失败。原因是知识库未配置图片资源的外链访问权限，或图片存储路径未绑定到知识库的资源白名单。
- 检索结果中出现非当前生产批次的工艺参数文档，无法精准匹配当前批次的生产需求。原因是未配置`collectionIds`限定检索的知识库集合，导致跨批次文档被召回。

## 怎么确认配好了
- 上传单批次的封装流程卡与对应晶圆来料图，发起检索，核对返回结果的范围是否限定在当前批次的文档集合内。
- 上传一条新增的良率报告文档，发起检索，核对结果是否包含该新增文档。
- 进入知识库检索配置面板，确认所有预设的开关状态与参数值与预设配置一致。
- 在自有页面嵌入检索组件后，执行检索并查看网络请求日志，确认接口调用参数与配置项匹配。
