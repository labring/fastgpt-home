# 半导体晶圆制造的供应商与过程质量审核：引用来源与溯源

## 这个品类的数据长什么样
半导体晶圆制造场景下，数据主要来自MES系统、设备FDC模块、缺陷检测与量测设备、晶圆图文件、工艺配方库与实验数据集。日常文档包含工艺流程卡、批次运行记录、设备配方、SPC控制图、异常处置单、缺陷图谱与良率报告。数据更新节奏覆盖每批晶圆流转、实时参数上报与每日汇总统计，字段包含工艺参数、缺陷坐标、良率数值与批次标识，单位涉及纳米级尺寸、时间戳与批次编号。

## 这些特征在「引用来源与溯源」这一环带来什么约束
该品类的多源异构数据、分层更新节奏与精密工艺参数特征，对引用溯源环节带来多重约束。首先，纳米级参数与跨工序耦合的工艺逻辑，要求溯源时需精准匹配批次标识与对应工艺节点，避免参数漂移误判。其次，实时设备数据与每日汇总报告并存的更新节奏，需要支持动态索引与历史数据回溯。此外，多样的文档格式与字段结构，要求溯源模块可适配结构化参数表、可视化晶圆图与文本类处置记录的关联调用，确保引用来源可完整映射到原始生产数据。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `quoteMaxToken` | 1500–2000 token | 容纳完整的晶圆批次运行记录、缺陷图谱与工艺参数内容，避免引用来源被截断 |
| `responseData` | 开启 | 保留原始生产数据的批次标识与字段信息，确保溯源可追溯到具体生产环节 |
| `detail` | 开启 | 展示引用来源的具体工艺节点与更新时间，匹配晶圆制造的跨工序审核逻辑 |
| 分块长度 | 800–1200 字符 | 适配结构化工艺文档与可视化晶圆图的分块要求 |
| 重叠长度 | 100–200 字符 | 覆盖连续的设备参数漂移记录，防止分块切断关键关联信息 |
| 相似度阈值 | 0.75–0.85 | 精准匹配纳米级工艺参数与批次信息，避免误关联不同晶圆批的数据 |

## 容易做错的三处
- 生成的回答未关联原始生产文档的具体批次与参数，引用来源字段为空。未开启`responseData`配置，导致系统未抓取原始数据的标识信息。
- 问答响应超时，服务长时间无返回。`quoteMaxToken`设置过大，超出系统处理上限，同时未调整对应上下文加载阈值。
- 匹配到错误的晶圆批次数据，审核结论出现偏差。相似度阈值设置过低，导致非目标批次的参数被误关联。

## 怎么确认配好了
- 发起针对某一批次晶圆的质量审核查询，查看回答末尾的引用来源模块，确认包含批次标识与对应文档类型。
- 检查引用来源的内容长度，确认未出现截断情况，与原始文档的对应片段一致。
- 调整相似度阈值后重新发起查询，观察匹配结果的数量变化，验证阈值配置生效。
- 查看系统日志，确认引用来源的参数字段已被正确提取并展示。
