# 半导体晶圆制造的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
半导体晶圆制造的审核数据来源包括MES系统、设备FDC采集终端、缺陷检测量测设备、工艺配方库等。数据更新节奏覆盖每批晶圆生成、实时设备参数同步、每日良率报表汇总。日常文档包含工艺流程卡、批次运行记录、设备配方、SPC控制图、异常处置单、缺陷图谱、良率分析报告，字段包含晶圆唯一标识、工序纳米级参数、设备运行时长、缺陷坐标等，单位涵盖纳米、小时等，批次标识采用字符串格式。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据的高实时性要求模型接入时支持实时拉取设备FDC数据，避免审核依赖过期信息；多源异构的文档类型包含图像类缺陷图谱与数值类工艺参数，要求配置适配多模态数据的处理能力；按批次更新的数据体量较大，需合理限制上下文与输出token的上限，避免资源占用过高；跨模块的良率归因需要关联多工序数据，要求配置足够大的上下文窗口保留完整关联信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 匹配晶圆制造多工序的跨模块关联需求，避免截断关键归因信息 |
| `maxTokens` | 4000–6000 token | 适配单批次晶圆数据的常规长度，防止输出内容超出模型上限 |
| `vision` | 开启 | 用于处理缺陷图谱、晶圆图、SPC图等图像类文档，提取缺陷空间分布特征 |
| `temperature` | 0.1–0.3 | 保证工艺参数判读与缺陷判定的结果一致性，减少随机偏差 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写实际接入地址 | 适配aiproxy的模型调用链路，确保跨数据源的请求转发正常 |
| `AIPROXY_API_TOKEN` | 按实测标定的密钥 | 保障模型调用的权限安全，避免未授权访问 |

## 容易做错的三处
- 现象：配置后模型仅检索知识库内容，无法调用联网工具补充最新设备数据。原因：未根据实时数据需求调整工具调用配置，误关闭了工具调用能力。
- 现象：升级FastGPT v4.17.0后导入工艺配方CSV文件时触发格式报错。原因：未适配新版本的CSV字段解析规则，原有批次编号、工艺参数的字段格式未匹配更新后的索引逻辑。
- 现象：调用配置的模型后，返回的审核结果未覆盖全部缺陷图谱信息。原因：未调整`quoteMaxToken`参数，导致检索到的知识库片段被过度截断，无法承载完整的缺陷空间分布数据。

## 怎么确认配好了
- 上传一张缺陷晶圆图触发审核任务，检查模型是否能提取图像中的缺陷位置与类型，确认`vision`配置生效。
- 导入单批次晶圆的完整工艺数据，查看索引完成后的上下文预览，确认`maxContext`与`maxTokens`的取值未截断关键关联信息。
- 填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`后发起测试调用，检查是否能正常返回模型响应，无权限或连接错误。
- 调整`temperature`参数至0.2，多次触发同一审核任务，确认结果差异在可接受范围内，验证配置稳定性。
