# 半导体晶圆制造的供应商与过程质量审核：部署与升级

## 这个品类的数据长什么样
半导体晶圆制造的供应商与过程质量审核数据，通常来自MES系统、设备FDC模块、缺陷检测与量测设备、晶圆图文件、工艺配方库与实验数据集。数据更新节奏涵盖每批晶圆生成时、设备运行实时同步、每日批量汇总。日常处理的文档包含工艺流程卡、批次运行记录、设备配方参数、SPC统计图表、异常处置单、缺陷图谱与良率报告，字段包含批次标识、工艺参数值、缺陷位置坐标与设备运行时长，单位涵盖纳米、小时等纳米级与工业常用单位。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据多源异构且更新节奏差异大，部署时需适配多系统对接与实时同步的配置要求。纳米级工艺参数与大体积晶圆图文件，要求存储配置预留足够的带宽与存储空间。每批晶圆的批次数据量随工艺复杂度提升，需调整数据库连接池参数以避免连接溢出。升级过程中需保留历史批次运行记录与缺陷图谱的兼容逻辑，避免中断正在执行的晶圆生产流程。同时，有限的返工窗口要求部署与升级操作需在非生产窗口完成，需配置离线升级预案。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `80–120 个连接` | 适配每批晶圆的批次数据与实时设备数据的并发访问需求，该区间可覆盖多数晶圆厂的同步场景 |
| `REDIS_URL` | `redis://default:自定义密码@redis主机:6379/1` | 缓存实时设备FDC数据与审核会话信息，使用数据库1隔离业务数据 |
| `STORAGE_S3_ENDPOINT` | `对应企业对象存储的访问端点` | 存储大体积晶圆图、缺陷图谱与工艺文档，适配多源文件的上传与读取 |
| FE_DOMAIN | `wafer-quality-audit.企业域名` | 配置二级域名区分服务，解决docker部署的二级域名访问问题 |
| `PG_URL` | `postgresql://用户名:密码@数据库主机:5432/fastgpt_wafer?sslmode=require` | 存储结构化的良率报告与异常处置单，保障敏感工艺数据的传输安全 |

## 容易做错的三处
- 现象：docker部署后无法通过配置的二级域名访问服务，日志提示404或无法解析域名。原因：未正确配置`FE_DOMAIN`参数，或未在域名解析服务商处将二级域名指向部署服务器的公网IP。
- 现象：升级到新版本后容器启动失败，提示依赖包缺失或配置项不兼容。原因：未保留原有`REDIS_URL`与`PG_URL`的配置信息，或升级过程中未停止正在运行的批次数据同步任务，导致配置文件被覆盖。
- 现象：知识库分割后的文本块包含过长的纳米级工艺参数，或多个分段合并后仍未达到合理长度。原因：未针对晶圆制造文档的字段特性调整分块规则，直接沿用通用文档的分块配置，未匹配该品类文档的实际长度特征。

## 怎么确认配好了
- 访问配置的二级域名，检查服务登录页面是否正常加载，验证`FE_DOMAIN`配置生效。
- 连接配置的`PG_URL`与`REDIS_URL`，执行基础的读写测试，确认数据库与缓存服务连接正常。
- 上传一份晶圆工艺流程卡与缺陷图谱，检查文件是否能正常存储与读取，验证`STORAGE_S3_ENDPOINT`配置生效。
- 查看数据库连接池状态，确认当前连接数未超过`DB_MAX_LINK`的设定值，验证并发访问配置合理。
