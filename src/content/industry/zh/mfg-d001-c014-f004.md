# 印染与后整理的供应商与过程质量审核：工作流编排

## 这个品类的数据长什么样
该品类数据来源于客户色样、配方库、染化料批次记录、染缸控制系统、测色仪、定形机及环保监测设备。日常生成的文档包含染色配方、称化料台账、染缸运行曲线、打样确认单、色差检测报告、定形工艺单、污水排放记录。数据按每缸、每批或每班的生产节奏更新，字段涵盖染缸温度、化料配比、色差值、排污量等，以结构化表单或时序曲线形式存储。

## 这些特征在「工作流编排」这一环带来什么约束
多源异构的数据来源与非标准化文档格式，要求工作流配置多节点的数据拉取与格式转换环节，适配设备采集时序数据、纸质台账扫描件及在线表单的不同接入方式。高频次的缸级、批级数据更新，要求工作流触发节点适配生产节拍触发规则，匹配实际生产节奏。专业参数如色差值、染缸升温曲线的校验需求，需在工作流中嵌入参数校验环节，确保输入数据符合染整工艺标准。严重的出错后果要求工作流配置异常分支，对异常数据触发对应处理流程。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 绑定染缸编号、化料批次、色样编号三类核心变量 | 匹配染整生产的缸级、批级数据关联需求，确保工作流节点调用对应批次的配方与检测数据 |
| 触发规则 | 按生产节拍触发，支持单缸、单批或每班触发 | 适配该品类按缸、按批更新数据的频率，匹配实际生产节奏 |
| 参数校验节点 | 配置色差值ΔE阈值、染缸温度偏差范围、排污量上限校验 | 覆盖染整工艺的核心参数校验需求，提前拦截不合格数据 |
| `nodeId` | 为数据拉取、格式转换、异常分支分别配置唯一nodeId | 便于工作流调试与异常定位，快速定位对应环节的执行状态 |
| 异常分支配置 | 为整缸报废、排放超标、参数异常三类场景配置告警与回滚节点 | 匹配该品类出错后的严重后果，及时触发对应处理流程 |
| 工具调用延迟阈值 | 300–600 秒 | 适配染缸曲线、测色数据的上传延迟，避免工具调用超时 |

## 容易做错的三处
- 调用图表工具生成染缸温度曲线后，问答界面返回空结果。未在工作流中配置图片URL的渲染绑定节点，仅返回原始接口返回值未做格式转换。
- 选择工具节点执行化料配比校验时返回400错误。未对输入的化料参数做格式校验，传入了不符合染整工艺单位的数值，触发接口参数校验失败。
- AI对话节点返回empty或报错后，工作流直接终止无后续处理。未配置异常分支处理逻辑，未对空结果或报错场景设置跳转节点。

## 怎么确认配好了
- 执行一次模拟缸级生产的工作流，检查各节点的变量绑定是否正确匹配预设的染缸编号与配方数据。
- 触发异常参数场景，验证异常分支是否跳转至对应告警与处理节点。
- 调用图表工具生成色差值曲线，确认问答界面可正常渲染生成的图片内容。
- 查看工作流日志，确认各节点的`nodeId`与配置的唯一标识一致，无重复或缺失。
