# 印染与后整理的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
本品类数据主要来自客户色样、配方库、染化料批次记录、染缸控制数据、测色仪读数、定形机参数与环保监测台账。数据更新频率为每缸、每批或每班，单批次文档包含染色配方、称化料记录、染缸曲线、打样确认单、色差报告、定形工艺单等内容，字段涵盖物理参数如温度、投料量、色差ΔE值，以及定性描述如色花、手感、缩水率等。

## 这些特征在「模型接入与配置」这一环带来什么约束
高频次的缸级/批级数据更新要求模型上下文窗口适配单批次文档量，避免冗余信息干扰审核逻辑；多模态的色样、色差报告等图片类数据，要求模型支持视觉解析能力；混合了结构化物理参数与非结构化描述的文档，要求模型同时适配文本与数值解析；质量审核的严谨性要求模型输出具备一致性，减少随机偏差。此外，污水台账等合规类数据的审核，要求模型输出格式稳定，便于后续校验。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配单缸/单批相关文档的总token量，避免上下文过载 |
| `vision` | 开启 | 需处理客户色样、色差报告等图片类审核数据 |
| `temperature` | 0.2–0.4 | 保证质量审核的输出一致性，降低主观偏差 |
| `maxTokens` | 1500–2000 token | 适配单缸审核报告的标准输出长度 |
| `AIPROXY_API_ENDPOINT` | 填写代理服务的实际访问地址，如`https://api.local:11434/v1` | 指向模型部署的正确服务路径 |
| `AIPROXY_API_TOKEN` | 填写代理分配的鉴权密钥 | 完成模型接入的身份验证 |

## 容易做错的三处
- 现象：模型渠道配置界面中无法找到火山方舟的新增厂商选项，无法完成第三方厂商接入。原因：未在FastGPT的模型管理模块开启第三方厂商接入开关，或未配置对应厂商的代理路由。
- 现象：接入通义千问QWEN2.5-VL-7B-instruct多模态模型后，上传色样或色差报告图片无解析结果。原因：未开启`vision`配置项，或模型调用时未携带图片解析的必要参数。
- 现象：通过ai proxy添加本地ollama模型时返回404错误。原因：`AIPROXY_API_ENDPOINT`填写的地址未指向ollama的实际服务端口，或代理服务未正常启动。

## 怎么确认配好了
- 进入FastGPT v4.17.0的模型渠道管理页面，查看已配置的模型列表，确认目标模型或厂商已成功添加。
- 上传单张客户色样图片，触发模型分析任务，检查是否返回与颜色、色差相关的有效解析结果。
- 提交单缸的染缸曲线与配方文档，检查模型输出的审核结果格式符合预设的结构化要求。
- 查看模型调用日志，确认`maxContext`、`temperature`等配置参数的取值与预设配置一致。
