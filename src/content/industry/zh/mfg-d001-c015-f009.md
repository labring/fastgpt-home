# 原料药与医药中间体生产的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
本品类数据来自原料药企业合成、精制、质量与注册支持部门的注册工艺文档、原料批次记录、DCS系统、LIMS系统、色谱数据系统及QMS。日常文档包含批生产记录、物料平衡表、反应与精制记录、清洁记录、杂质谱报告、偏差与变更文件。数据更新以每生产批次、每工艺步骤为节奏，字段包含反应参数、杂质含量、溶剂残留量、批次编号等，单位对应化学检测常用的摩尔比、ppm等。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类多源异构的数据来源要求模型接入时适配不同系统的输出格式，避免数据解析错误。高频次的批次级更新要求配置适配批量数据处理的上下文承载能力，防止因上下文溢出导致的任务中断。专业化学文档的结构与术语要求模型配置支持领域文本的精准理解，同时需适配杂质谱、工艺路线等专属业务逻辑的解析需求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配批生产记录、杂质谱报告等长文档的完整上下文加载，避免专业化学内容被截断 |
| `temperature` | 0.1–0.3 | 降低随机输出，保证杂质评估、工艺合规判断等任务的结果一致性 |
| `quoteMaxToken` | 2000 token | 匹配本品类单份专业文档的核心片段长度，确保召回的杂质谱、反应记录等内容完整 |
| 工作流/API 工具选择配置 | auto | 自动选择工具适配多源数据的检索与解析需求，适配供应商审核中的多文档交叉验证 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配大模型调用的专属接口路径，确保模型接入的连通性 |
| `AIPROXY_API_TOKEN` | 按授权凭证填写 | 完成模型接入的身份验证，保障调用权限合规 |

## 容易做错的三处
- 配置`maxContext`参数时取值过小，搜索测试时返回「上下文溢出」报错，原因是未适配本品类长文档的加载需求，导致专业化学内容被截断无法完成检索。
- 未正确填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，调用大模型时返回401或404状态码，原因是身份验证或接口路径配置错误，无法连通目标大模型。
- 开启`vision`参数后未配置对应视觉输入的处理规则，导致上传杂质谱扫描件时返回空结果，原因是未适配本品类色谱图、扫描文档的视觉解析需求。

## 怎么确认配好了
- 上传单份批生产记录文档，检查模型能否正确提取反应参数、批次信息等核心字段，验证上下文加载配置是否生效。
- 发起供应商资质相关的检索请求，检查返回结果的召回条数与匹配度，验证`quoteMaxToken`与检索配置是否适配业务需求。
- 调用大模型完成杂质谱合规性判断，检查输出结果的一致性，验证`temperature`参数的取值是否符合业务要求。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的调用状态均为成功，验证接入权限配置是否正确。
