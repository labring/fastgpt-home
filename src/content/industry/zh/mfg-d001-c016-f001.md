# 变压器与高压电器制造的供应商与过程质量审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的日常文档包含绕制与器身装配记录、真空干燥记录、绝缘油报告、局放和耐压试验报告、铭牌参数表。数据来源为设计BOM、硅钢片和绝缘材料数据、真空与干燥设备、油化验、试验站。数据更新频率为每台设备、每批材料一次，单台设备的完整审核数据包含绝缘结构参数、局放数值、耐压值、铭牌额定电压（单位kV）等专属字段。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
因为该品类的每台设备、每批材料均有唯一标识且数据需单台追溯，因此接口请求必须携带批次号、设备序列号等标识参数。多类型的审核文档要求接口支持多格式数据拉取，同时由于绝缘击穿、电网现场故障等出错后果严重，接口需配置合理的超时与重试机制。此外，单台设备的试验数据精度要求高，接口返回的原始数据不能被随意截断或修改，需保留业务字段的原始含义。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {第三方系统API密钥}` | 供应商与试验设备的外部接口通常采用Bearer令牌鉴权，符合工业系统的安全访问规范 |
| `variables` | `{"batchId": "实际批次号", "deviceSerial": "设备序列号"}` | 变压器制造的每台设备、每批材料均有唯一标识，用于接口精准匹配对应批次的审核数据 |
| `responseData` | `保留原始字段，不做重命名` | 绝缘油报告、局放试验报告的字段具有固定业务含义，重命名会导致后续审核环节无法匹配 |
| 单次请求超时时间 | `600 秒` | 高压试验报告的生成流程耗时较长，避免提前超时中断数据拉取 |
| 流式返回分片间隔 | `按实测标定` | 不同批次的试验数据量存在差异，需匹配前端展示的节奏需求 |

## 容易做错的三处
- 现象：对话API流式输出后，外部链接点击仅覆盖当前页面无法跳转。原因：未在`responseData`中配置正确的跳转协议字段，导致前端无法识别外部链接的跳转规则。
- 现象：对话日志详情与实际回答内容不一致。原因：未在`variables`中绑定正确的设备批次ID，导致每次请求调用的是缓存的旧数据。
- 现象：API调用返回速度固定为4秒每次无法调整。原因：未根据试验报告的数据量调整接口的返回分片配置，默认的分片间隔未适配变压器制造的单批次数据规模。

## 怎么确认配好了
- 调用测试接口，检查返回的`responseData`中是否包含绝缘油含水量、局放数值等品类专属字段，字段名称与外部系统的文档一致。
- 发起携带`variables`中批次ID的请求，核对返回数据是否与对应批次的试验记录匹配。
- 开启流式输出测试，观察前端链接的跳转行为是否符合业务需求，调整配置项直到符合预期。
- 查看FastGPT v4.17.0的对话日志，确认日志内容与实际接口返回的内容一致。
