# 变压器与高压电器制造的供应商与过程质量审核：多轮对话与提示词

## 这个品类的数据长什么样
本品类数据来源于设计BOM、硅钢片与绝缘材料采购数据、真空干燥设备日志、绝缘油化验报告、高压试验站记录。数据按单台产品或每批原材料更新，单台产品关联的文档包含绕制与器身装配记录、真空干燥记录、绝缘油报告、局放与耐压试验报告、铭牌参数表。文档字段包含绝缘结构参数、洁净度检测项、引线连接信息、分接位置数据、高压试验数值等，部分字段带有专用检测单位。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
单台产品关联多份专属文档，要求对话上下文需精准匹配当前批次或单台产品的参数，避免跨批次数据混淆。高频的高压试验、绝缘检测数据字段多且专业，提示词需明确限定检索范围为当前任务对应的单台文档，防止无关数据干扰分析。数据更新频率随单台产品生产推进，对话过程中需支持动态加载最新的试验记录，同时需限制上下文长度，避免旧批次数据占用过多token。此外，绝缘与高压试验的专业术语较多，提示词需固定术语释义规则，减少分析过程中的歧义。

## 配置怎么定
基于FastGPT v4.17.0版本，针对本品类的多轮对话与提示词配置建议如下：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 最大上下文 | 前20条历史对话+当前任务文档 | 匹配单台产品的文档量与常规对话轮次，避免上下文溢出 |
| 单次搜索上限 | 前3条匹配文档 | 单台产品关联文档数量有限，过多结果会干扰专业分析 |
| 问题优化 | 开启 | 适配绝缘、高压试验相关的专业术语，自动补全隐含的检测条件 |
| 知识库关联数量 | 按单台产品的专属文档组配置 | 避免跨批次的无关知识库混入当前任务 |
| 上下文超时时间 | 120秒 | 匹配高压试验数据的加载与分析节奏，避免长文档解析超时 |
| 会话绑定 | 按`chatId`绑定单台产品 | 确保`messages`历史记录仅关联当前产品的对话数据，`variables`存储专属铭牌参数 |

## 容易做错的三处
- 调试预览正常但正式环境报错，提示知识库无法加载。原因是正式环境的知识库路径配置与本地部署的路径不一致，未同步关联的单台产品文档组。
- 对话中输入的json格式试验报告超出字符限制，无法解析。原因是未调整上下文的字符上限配置，默认限制与变压器长文本试验报告不匹配。
- 关联过多知识库导致分析结果偏差。原因是未按单台产品分组关联知识库，混入了其他批次的绝缘油或耐压试验数据。

## 怎么确认配好了
- 导入单台变压器的全部关联文档，检查关联知识库的数量是否与该产品的文档清单一致。
- 发起包含局放异常分析的对话，查看返回结果是否仅包含当前批次的试验数据与装配记录。
- 输入长文本的绝缘油报告，确认对话可正常解析且无字符溢出报错。
- 查看会话绑定的`chatId`是否与当前产品的编号一致，确保`messages`历史记录未混入其他批次数据。
