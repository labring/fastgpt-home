# 基础化工连续生产的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据覆盖多类源头：DCS/SIS系统采集实时工艺参数，在线分析仪、LIMS系统输出化验与质检数据，设备状态、能源计量、原料储罐同步设备运行与物料存储信息。日常文档包含操作规程、工艺指标卡、DCS趋势图、化验报告、联锁旁路记录、特殊作业票、班报。数据更新节奏涵盖实时、每班、每日，字段多带明确单位，如温度（℃）、压力（MPa）、物料储量（t）。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据来源与差异化更新节奏，要求模型接入时需适配不同时效的输入，避免将实时工艺数据与每日班报按同一规则处理。多样的文档类型覆盖结构化指标、趋势图文本、审批类单据，需要配置支持跨类型文档的检索与解析。实时工艺参数与联锁记录的强时效性，要求模型调用的整体延迟需匹配生产节奏。数据字段多带专业单位，配置需支持对单位一致性的校验，避免计算时出现单位不匹配的问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 需容纳多份DCS趋势、联锁记录与化验报告的组合上下文，避免关键工艺信息被截断 |
| `maxTokens` | 2000–3000 token | 供应商审核与质量核对的回复需覆盖多组指标对比，过长的输出会超出生产场景的响应需求 |
| `quoteMaxToken` | 1500–2000 字符 | 需完整引用工艺指标卡与联锁旁路记录的关键条款，避免截断重要合规内容 |
| `temperature` | 0.1–0.3 | 质量审核需稳定的结果一致性，避免随机波动导致的指标判断偏差 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写对应地址 | 将模型请求路由至适配的代理节点，保障数据传输安全与延迟可控 |
| `AIPROXY_API_TOKEN` | 按平台分配的密钥填写 | 实现模型调用的身份验证，防止未授权访问 |

*注：本页面基于FastGPT v4.17.0版本配置规范*

## 容易做错的三处
- 现象：模型输出的物料总量计算结果与实际储罐数据不符，字段为空或数值偏差。原因：未配置对数据单位一致性的校验，将不同单位的参数直接相加，或未正确处理实时数据与历史班报的时间范围匹配。
- 现象：模型调用返回身份验证相关的报错。原因：未正确填写`AIPROXY_API_TOKEN`，或密钥权限未配置为允许访问供应商审核相关的模型接口。
- 现象：检索返回的文档条数不足，无法覆盖关键工艺指标。原因：未调整`maxContext`参数适配多文档组合，或未配置问题优化环节扩展检索范围，导致指代不明确的查询无法召回有效文档。

## 怎么确认配好了
- 上传单份工艺指标卡与DCS趋势图，触发一次质量审核请求，核对返回结果是否完整引用了文档中的关键参数。
- 导入一组包含不同单位的工艺数据，触发计算请求，核对返回结果是否标注了统一的输出单位。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置项匹配部署环境，无身份验证报错。
- 模拟包含指代模糊的查询，如“核对近期的原料质量”，核对系统是否通过问题优化扩展了查询范围，召回对应时段的班报与化验报告。
