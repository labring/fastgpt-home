# 塑料注塑成型的供应商与过程质量审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
数据来源包括树脂批次物性表、注塑机运行参数、模温机监测数据、车间MES系统、尺寸与外观检测设备。数据更新节点为每批次原料进厂、每次换模换料、每班巡检结束。日常文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验报告、生产巡检表、换料清机记录。字段包含树脂水分含量、模腔温度（℃）、充填时长（s）、模具编号、生产批次号等，数据结构随文档类型不同存在差异。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
高频且节点明确的数据更新要求接口支持按生产节点触发调用，避免无效的重复请求。多源异构的数据格式要求接口支持灵活的字段筛选与格式解析，适配注塑机、模温机、MES等不同系统的返回结构差异。批量的质检与工艺数据要求接口支持分页或批量拉取，降低单请求的数据传输量。严格的质量管控要求接口具备异常重试与告警能力，应对车间网络波动或设备离线导致的请求失败。同时，生产数据的敏感性要求接口鉴权配置需符合车间工业网络的安全规范，避免未授权访问。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 鉴权方式 | `Authorization`头携带Bearer令牌 | 符合工业设备接口的通用鉴权规范，适配注塑车间的设备接入安全要求 |
| 请求超时时间 | 30–60秒 | 覆盖注塑工艺参数拉取、单批次质检数据同步的平均耗时 |
| 返回字段筛选 | 仅指定业务所需字段 | 减少数据传输量，适配车间有限的网络带宽 |
| `variables`参数绑定 | 绑定生产批次号、模具编号变量 | 精准拉取对应生产场景的原料、工艺与质检数据 |
| `responseData`解析规则 | 按JSON数组格式解析 | 适配多数车间MES系统返回的批量数据结构 |
| 重试机制 | 失败后重试2次，间隔5秒 | 应对车间网络波动导致的临时请求中断 |

## 容易做错的三处
- 现象：调用外部接口时界面显示504超时状态码。原因：未根据注塑数据的拉取量调整超时时间，默认超时时长不足以覆盖批量质检数据的传输耗时。
- 现象：接口返回字段与预期不符，出现冗余数据。原因：未配置返回字段筛选规则，直接拉取了全量的设备日志数据，超出业务所需范围。
- 现象：curl调用接口响应迅速，但在FastGPT内调用时延迟明显。原因：未配置接口的本地缓存规则，重复拉取相同的注塑工艺卡数据占用请求资源，同时未调整请求并发数，导致车间高频请求出现排队。

## 怎么确认配好了
- 执行本地curl命令，携带`Authorization`头调用目标接口，确认返回字段与配置的筛选规则一致。
- 在FastGPT的测试面板中，绑定生产批次号与模具编号变量发起接口调用，确认返回数据包含该批次对应的原料干燥记录。
- 模拟10次高频调用，观察接口响应时长未出现明显波动，确认重试与并发配置生效。
- 查看FastGPT v4.17.0的系统日志，确认接口请求的鉴权参数`Authorization`被正确携带，无解析错误。
