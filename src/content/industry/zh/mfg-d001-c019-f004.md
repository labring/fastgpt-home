# 塑料注塑成型的供应商与过程质量审核：工作流编排
本页面适配FastGPT v4.17.0

## 这个品类的数据长什么样
该品类的数据来源包括树脂批次与物性表、注塑机参数、模温机数据、MES系统记录、尺寸与外观检测结果。日常文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验表、巡检表、换料清机记录。数据更新频率为每生产批次、每次换模换料操作、每班交接班时更新，文档字段包含树脂批次号、模温设定值、注塑压力参数、冷却时长等，单位涵盖℃、MPa、秒等。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的数据更新频次高且触发场景分散，要求工作流支持按生产批次、换模操作、交接班节点触发。多源异构的数据结构要求工作流支持`variables`配置自定义字段映射，适配树脂批次号、模温参数等特定字段。批量生产时的高频数据提交，要求工作流节点设置合理的并发阈值，避免单节点过载。同时，质检数据与工艺参数的关联校验，需要工作流串联不同数据源的节点，确保审核逻辑的连贯性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 触发方式 | 按生产批次、换模操作、交接班节点触发 | 匹配该品类数据的更新节奏 |
| `variables` 配置 | 映射树脂批次号、模温设定值、冷却时长字段 | 适配注塑工艺的特定数据字段 |
| 并发上限 | 20–30 并发/节点 | 适配单节点硬件承载能力 |
| 节点超时时间 | 600 秒 | 覆盖单次注塑工艺的完整周期 |
| JSON输入框变量绑定 | 启用变量选择模式 | 支持多字段组合的审核参数录入 |

## 容易做错的三处
- 工作流通过API访问时返回参数错误。原因是未在`variables`中配置API请求所需的注塑批次号、模温参数等必填字段，导致请求体缺失必要参数。
- 单节点在高并发场景下出现进程崩溃。原因是未设置合理的并发上限，超过4c16g单节点的承载阈值，导致资源耗尽。
- JSON输入框无法选择变量。原因是未启用JSON输入框的变量绑定开关，仅支持静态JSON录入，无法动态关联工作流中的数据源字段。

## 怎么确认配好了
- 手动触发一次工作流，检查是否拉取到对应批次的注塑工艺卡、原料干燥记录等文档。
- 调整并发参数后，使用模拟流量测试节点承载能力，确认单节点运行稳定。
- 配置JSON输入框后，尝试选择工作流中的`variables`字段，确认变量可正常绑定。
- 调用API接口，检查返回结果是否包含预设的审核校验逻辑输出。
