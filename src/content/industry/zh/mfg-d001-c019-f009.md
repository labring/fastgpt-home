# 塑料注塑成型的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来自树脂批次与物性表、注塑机参数、模温机、生产执行系统（MES）及尺寸外观检测设备。日常留存的文档包括注塑工艺卡、原料干燥记录、模具履历、首件检验表、巡检记录、换料清机记录。数据更新节奏为每生产批次、每次换模换料、每班巡检后更新，字段包含工艺参数、原料批次号、模具编号、检验尺寸与外观结果等，部分为设备直连导出的结构化数据，部分为纸质转电子的非结构化文档。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类多源异构的数据特征，要求模型接入时需适配结构化设备参数、半结构化检验记录、非结构化纸质转档文档的混合输入。高频更新的生产数据，要求配置时限制上下文窗口规模，避免冗余旧数据干扰当前审核逻辑。注塑相关的专业字段如充填保压参数、模温、回料比例，要求配置的模型需具备注塑行业术语的识别能力。同时，单次生产批次的审核数据量集中，需适配批量数据的快速解析需求。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本，具体配置项及依据如下：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 该品类单批次审核数据包含注塑工艺卡、巡检记录、模具履历等，总token量集中在该区间，避免上下文溢出影响解析 |
| `temperature` | `0.1–0.3` | 供应商与过程质量审核需稳定一致的参数判断，该温度区间可减少随机波动导致的审核结果偏差 |
| `vision` | 启用 | 该品类审核需解析注塑件外观缺陷图片、模具照片等视觉类文档，适配图片解析需求 |
| `maxTokens` | `2000–3000 token` | 单条审核结论的输出长度需控制在该区间，确保结果清晰完整，适配业务审核的信息密度 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写专属节点 | 保障模型接口调用的合规性，规避跨区域访问限制 |
| `AIPROXY_API_TOKEN` | 按分配的专属密钥填写 | 保障接口调用的身份合法性，防止未授权访问 |

## 容易做错的三处
- 现象：配置`vision`参数后仍无法解析上传的图片或PDF内嵌图片，审核结果未包含图片相关内容。原因：未正确开启视觉模型的关联配置，或上传的图片格式未被支持（如非JPG/PNG格式）。
- 现象：调用模型时返回403状态码，接口调用失败。原因：`AIPROXY_API_TOKEN`配置错误或密钥过期，未按部署要求填写专属接口密钥。
- 现象：批量导入多批次注塑数据时，解析结果出现字段缺失或错位。原因：`maxContext`取值过小，无法容纳单批次完整的多文档数据，导致截断丢失字段信息。

## 怎么确认配好了
- 上传单份注塑工艺卡与配套的外观缺陷图片，验证模型是否能正确识别图片中的缺陷标注与工艺参数文本。
- 发起一次批量审核测试，查看接口返回的结果是否完整包含所有上传文档的关键信息，无字段缺失或错位。
- 核对`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置内容，确保与分配的专属接口信息一致。
- 调整`temperature`参数至不同区间，对比两次审核结论的差异，确认输出稳定性符合业务审核要求。
