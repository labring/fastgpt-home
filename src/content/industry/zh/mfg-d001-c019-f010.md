# 塑料注塑成型的供应商与过程质量审核：知识库检索与召回

## 这个品类的数据长什么样
该品类数据来自树脂批次物性表、注塑机运行参数、模温机采集数据、生产MES系统、尺寸与外观检测报告。日常文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验表、巡检表、换料清机记录。数据更新节奏为每生产批次、每次换模换料、每班结束。文档字段包含充填压力（单位兆帕）、保压时长（单位秒）、模温（单位摄氏度）、干燥温度、模次累计数等，不同文档的字段关联度高，需跨文档匹配验证生产过程的一致性。

## 这些特征在「知识库检索与召回」这一环带来什么约束
高频更新的生产数据要求检索系统支持近实时的增量索引，避免召回过时的旧数据。多类型文档的混合存储要求检索模型适配不同格式的语义匹配，比如巡检表的缺陷描述与工艺卡的调整方法需精准关联。带特定单位的字段要求检索时匹配单位信息，避免召回模温、压力单位不符的无效结果。跨数据源的字段关联要求检索系统支持跨文档的信息整合，比如将原料干燥记录与注塑工艺卡的参数绑定。此外，注塑缺陷相关的检索需精准匹配工艺调整逻辑，不能泛化召回无关内容。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配注塑工艺参数、缺陷描述的精准度要求，避免召回无关的模具履历或原料记录 |
| `limit` | 前8条 | 覆盖单次供应商审核或过程质量排查所需的工艺、原料、检测数据量，避免上下文超出模型处理上限 |
| `searchMode` | 语义检索 | 适配多格式文档的语义匹配，比如将巡检表的「飞边缺陷」与工艺卡的「模具间隙调整」关联召回 |
| `usingReRank` | 开启 | 对初始召回结果二次排序，过滤掉模温、压力单位不匹配的无效结果 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展原料物性表、注塑机参数的相关查询词，比如补充「缩水缺陷对应工艺调整」的关联查询 |

## 容易做错的三处
- 搜索时出现模型相关报错，界面返回「模型调用超时」或日志显示「embedding请求失败」。原因是未针对注塑数据的高频更新配置增量同步，导致知识库索引过大触发模型资源过载。
- 检索结果包含无关的工艺文档，比如出现交联固化相关内容。原因是未开启品类专属的检索过滤，未区分注塑与其他品类的文档特征。
- 检索结果缺少当前批次的原料干燥记录，返回的是3天前的旧数据。原因是未配置按更新时间排序的召回规则，未启用增量同步的实时更新机制。

## 怎么确认配好了
- 上传1份注塑工艺卡和原料干燥记录，发起「缩水缺陷调整方法」的查询，核对召回结果包含对应工艺参数。
- 查看知识库的增量同步日志，确认每批换料后10分钟内完成索引更新。
- 测试检索时输入带单位的查询词「模温60摄氏度的注塑工艺」，核对召回结果的模温字段匹配该单位。
- 进入FastGPT知识库配置面板，确认`usingReRank`和`datasetSearchUsingExtensionQuery`处于开启状态。
