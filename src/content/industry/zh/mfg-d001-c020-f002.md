# 安全环保与特殊作业管理的供应商与过程质量审核：向量模型与索引

## 这个品类的数据长什么样
本品类数据来自化工、冶金、机械等制造企业EHS部门与生产检维修团队，涵盖风险辨识记录、动火/受限空间/吊装等作业票、环境监测记录、危废台账、事故与隐患整改报告等文档。数据来源包括行业法规标准、在线环保监测系统、气体检测仪、人员资质档案、设备隔离清单及监管平台。更新节奏随作业触发、实时或按监测要求执行，定期完成检查与台账更新。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类数据来源覆盖结构化档案、实时监测流与非结构化作业文档，要求向量索引支持多类型数据的混合检索。高频率更新需求要求索引支持增量同步，避免全量重索引的耗时。强合规属性的文档（如作业票、整改报告）要求向量召回的精准匹配，需限制低置信度结果返回。作业相关文档包含作业类型、人员资质、监测数值等多维度字段，索引需保留字段级关联以支撑精准过滤。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配作业票、监测记录等单篇文档的平均长度，避免单块内容割裂业务逻辑 |
| 重叠长度 | 100–150 字符 | 弥补分块导致的上下文断裂，保障作业流程类文本的语义连贯性 |
| 相似度阈值 | 0.75–0.85 | 匹配本品类强合规的检索需求，过滤低置信度的非相关风险记录 |
| 单次搜索上限 | 前 10 条 | 限制返回结果数量，避免冗余信息干扰作业前风险辨识 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| `defaultToken` | 按代表性样本文档实测设置 | `defaultToken` 是直接文本分块使用的默认 token 数，请用本品类代表性原文实测调整；参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不表示向量维度、嵌入模型输入上限或检索/LLM 上下文。 |

## 容易做错的三处
- 现象：手动插入的作业票文档生成默认索引后，数小时后索引自动消失。原因：未开启增量索引的持久化存储配置，导致临时缓存的索引数据被自动清理。
- 现象：配置嵌入模型API后测试返回404状态码。原因：未正确填写模型调用的完整接口路径，或未在平台权限中开放对应API访问权限。
- 现象：更换嵌入模型后，未对现有知识库文档执行批量重嵌入，导致多语言文档召回率下降。原因：未触发现有知识库的全量重索引流程，旧嵌入向量未被替换。

## 怎么确认配好了
- 上传单篇作业票文档，检查向量生成日志中是否显示正确的嵌入模型调用信息。
- 执行风险记录的检索测试，核对返回结果的数量与配置的单次搜索上限一致。
- 新增一篇危废台账文档，等待更新完成后验证索引是否正常保留。
- 调整相似度阈值后，测试检索结果的过滤效果是否符合业务需求。
