# 安全环保与特殊作业管理的供应商与过程质量审核：工作流编排

## 这个品类的数据长什么样
本品类的数据来源包括法规标准、在线环保监测设备、气体检测仪、人员资质档案、设备隔离清单及监管平台。日常文档涵盖风险辨识记录、动火/受限空间/吊装等作业票、现场监测记录、危废台账、排放监测报表、事故与隐患整改报告。数据更新节奏为每次作业完成即更新、实时或按监测要求更新、定期检查更新。文档字段包含作业类型、作业时间、监护人资质编号、气体检测值、危废类别、产生量等，部分字段带有专属单位，如气体检测值的ppm或%LEL。

## 这些特征在「工作流编排」这一环带来什么约束
数据来源分散且更新节奏差异大，要求工作流支持多触发方式，适配单次作业、实时监测、定期检查等不同更新场景。文档字段多带有专属校验规则，需在工作流中配置字段校验节点，确保资质、检测值等数据符合要求。高风险特性要求工作流设置强制审批与异常上报分支，避免未合规的作业执行。跨部门协作需求则要求配置节点权限，限定不同角色的操作范围。

## 配置怎么定
本文档适配FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| 触发方式 | 按作业节点事件触发，或按`variables`传入的作业ID触发 | 匹配作业的单次/实时更新特性，避免无效轮询 |
| 节点超时时间 | 600秒 | 适配气体检测、资质核验等现场操作的合理耗时 |
| 变量绑定规则 | 按作业文档字段名直接绑定`variables` | 简化作业数据流转，减少格式转换错误 |
| 异常分支配置 | 当检测值超出阈值时跳转至审批节点 | 匹配安全环保场景的高风险否决要求 |
| 节点ID标识 | 按作业类型配置唯一`nodeId` | 便于调试和日志追踪，区分不同作业场景的工作流 |
| 权限配置 | 仅EHS部门可修改审批节点状态 | 符合作业管理的权限管控要求 |

## 容易做错的三处
- 现象：代码执行节点运行后返回执行失败日志，或节点状态置为异常。原因：未通过`variables`传入作业所需的现场设备接口密钥、检测阈值等参数，或节点超时时间设置不符合现场操作耗时。
- 现象：http请求节点的body参数为空，或未正确加载作业相关数据。原因：未将作业票、监测记录中的字段与`variables`绑定，未在请求配置中正确引用变量名。
- 现象：工作流无法区分上传的图片与其他格式文件，导致后续校验节点触发错误。原因：未配置文件类型校验逻辑，未通过`variables`提取文件后缀名进行分支跳转。

## 怎么确认配好了
- 触发测试：手动提交一份模拟作业票，检查工作流是否按配置的触发规则启动对应节点。
- 变量校验：在工作流调试面板中查看`variables`是否正确加载了作业相关字段，确认http请求body的变量引用格式正确。
- 异常分支验证：模拟触发高风险场景（如气体检测值超标），检查工作流是否跳转至预设的审批或上报节点。
- 权限验证：使用非EHS部门账号尝试修改审批节点状态，确认权限配置生效。
