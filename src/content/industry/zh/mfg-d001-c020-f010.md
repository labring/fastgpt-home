# 安全环保与特殊作业管理的供应商与过程质量审核：知识库检索与召回

## 这个品类的数据长什么样
该品类数据来自制造企业EHS部门与检维修团队的日常工作产出及外部监管源，包含风险辨识清单、动火/受限空间/吊装作业票、在线环保监测记录、危废台账、排放监测数据、事故与隐患整改报告等。数据来源覆盖法规标准、在线环保监测设备、气体检测仪、人员资质档案、设备隔离清单及监管平台。更新节奏随作业开展实时生成，或按监测周期、定期检查要求更新。文档结构多为结构化表单与非结构化文本，包含作业类型、监测数值、资质编号、整改时限等字段，无统一固定格式。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类数据的多源异构特性，要求检索召回需适配结构化表单、实时监测数值、非结构化文本等多种数据格式，避免遗漏关键字段。高频更新的特性要求检索链路支持增量同步，确保召回结果匹配最新作业要求与监测数据。作业前风险辨识、资质核验等核心环节对信息时效性要求高，需优先召回近周期内更新的内容。出错后果的严重性要求检索结果需覆盖全部必要合规项，避免因信息缺失导致审核失误。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 该品类需精准匹配合规要求与作业风险，该区间可过滤低相关结果，同时保留足够的关联信息 |
| `limit` | `前8–12条` | 作业审核需覆盖多维度合规项，过多结果会增加审核负担，过少则可能遗漏关键信息 |
| `searchMode` | 语义检索+关键词检索 | 该品类数据包含结构化字段与非结构化文本，混合检索可同时匹配关键词与语义关联内容 |
| `usingReRank` | 开启 | 多源数据的相关性差异较大，重排可过滤低质量召回结果，提升核心合规信息的优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 作业相关术语存在多表述方式，扩展查询可覆盖更多同义词与行业常用表述 |
| `collectionIds` | 绑定对应安全环保作业管理知识库集合 | 精准限定检索范围，避免跨品类数据干扰审核结果 |

## 容易做错的三处
- 检索结果中混入产品质检相关文档，未匹配当前品类的安全环保作业要求。原因是未通过`collectionIds`限定检索范围，调用了跨品类的知识库集合。
- 作业前风险辨识的检索结果条数不足，无法覆盖全部合规项。原因是`similarity`阈值设置过高，过滤掉了部分关联度符合要求的历史作业记录与风险清单。
- 调用知识库检索节点时返回“text index required for $text qu”类报错。原因是升级FastGPT版本后未重新生成对应知识库的向量索引，或新增文档后未触发索引更新。

## 怎么确认配好了
- 检查检索配置的`collectionIds`是否仅绑定当前安全环保作业管理的知识库集合，确认无跨品类数据混入。
- 发起一次模拟作业风险辨识的检索请求，核对返回结果的文档类型是否覆盖作业票、风险清单等品类内数据。
- 验证检索结果的排序是否符合业务优先级，确认`usingReRank`的配置是否生效。
- 测试新增一份作业票文档后，检索是否能召回该文档，确认增量更新与索引重建流程正常。
