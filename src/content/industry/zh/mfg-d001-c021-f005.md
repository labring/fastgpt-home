# 家具与木制品制造的供应商与过程质量审核：工具调用与插件

## 这个品类的数据长什么样
这个品类的典型主体为板式家具、实木家具、定制家居及木门企业。日常产生的文档包含拆单图、开料清单、封边与钻孔程序、涂装工艺文件、五金物料清单、试装及包装记录。数据主要来自订单设计系统、板材与木材批次台账、数控开料钻孔设备、ERP/MES系统及含水率检测设备。数据更新节奏随订单、每日或每批材料变动，涉及个性化定制的板件参数、工艺要求及物料信息。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的个性化定制属性带来多文档关联查询需求，工具调用需支持跨拆单图、开料清单等多类型文档的实体关系检索。高频更新的板材批次、工艺参数数据，要求插件配置适配实时或近实时的数据同步逻辑。板件尺寸、孔位等高精度参数的核对需求，要求工具调用返回结果需匹配精准的字段与单位。定制订单的板件数量较多，单次工具调用需限制返回结果的条数，避免上下文过载影响生产流程。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配该品类多场景工具调用需求，支持自动匹配生产参数核对、文档关联查询等不同任务 |
| `functionCall` | 按实测标定 | 适配定制订单的个性化参数需求，支持灵活绑定拆单图、开料清单等多类文档 |
| 单次搜索上限 | 前10条 | 匹配该品类单订单板件数量较多的特征，避免过多结果导致上下文过载 |
| 最大上下文 | 8000–12000 token | 适配多文档关联查询的内容长度需求，覆盖拆单图、工艺文件等多类数据 |
| 问题优化 | 开启 | 优化针对生产参数、物料清单的查询表述，提升工具调用的匹配精度 |
| 响应超时 | 600秒 | 适配生产环节的实时性要求，避免过长等待影响车间流程 |

## 容易做错的三处
- 调用工具时返回结果条数与预期不符，现象为返回结果不足或过多。原因是未根据单订单板件数量调整单次搜索上限配置，导致上下文过载或检索不充分。
- 工具调用提示知识库id无效，现象为界面弹出“未找到指定知识库”的报错。原因是未在API请求中正确绑定对应拆单图、开料清单的知识库id，或全局变量配置未同步更新。
- 工作流调用工具后无返回数据，现象为工作流节点状态显示超时。原因是未将响应超时配置调整至符合生产环节的合理时长，导致生产数据查询未完成即触发超时。

## 怎么确认配好了
- 发起针对板件尺寸参数的工具调用请求，核对返回结果是否包含拆单图、开料清单中的对应字段与单位。
- 检查API请求参数，确认已正确绑定目标知识库的id，或全局变量配置与实际知识库路径一致。
- 运行测试工作流，验证工具调用的响应时长是否符合生产环节的预期，无异常超时提示。
- 调整`toolChoice`配置为`auto`，发起多场景查询，确认工具可自动匹配生产参数核对、文档关联等不同任务。
