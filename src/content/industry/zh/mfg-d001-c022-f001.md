# 家用电器整机制造的供应商与过程质量审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
数据来源涵盖ERP、MES系统，零部件批次台账，拧紧与制冷剂充注设备、安规测试仪、性能实验室数据，以及售后故障记录。日常文档包含配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告、返修记录。数据更新按单台产品、每班生产批次或抽检计划执行，字段覆盖物料编码、测试电压、充注量、故障类型等，需匹配生产环节的标准化文档结构。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
家电整机制造的高频、多维度生产数据要求接口支持高并发调用与灵活的字段映射。单台产品的实时数据与批量生产的批次数据需分别适配不同的请求频率，混线生产的多型号产品需传递唯一标识以区分数据归属。安规测试、性能抽检等环节的数据耗时较长，需适配合理的超时设置，避免因请求中断导致生产流程停滞。同时，数据需严格匹配装配作业书、BOM等文档的字段规则，确保外部系统返回的数据可直接用于质量审核环节。

## 配置怎么定
本文基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `Authorization` | Basic Auth格式，传入预设的服务账号密钥 | 对接ERP、MES等内部生产系统的安全认证要求 |
| `variables` | 绑定10-50个自定义字段，涵盖产品型号、零部件批次号、抽检批次 | 匹配家电整机制造多维度的质量审核数据需求 |
| `responseData` | 过滤返回安规测试结果、充注量、返修记录等核心字段，单次返回数据量不超过2000 KB | 减少传输负载，适配高频生产数据同步场景 |
| 接口超时时间 | 60-120 秒 | 适配安规测试、性能实验室数据拉取的耗时需求 |
| 批量请求并发数 | 前5 条并行请求 | 避免超过车间生产设备的接口调用上限 |
| 字段映射规则 | 按装配作业书的字段名对齐外部系统返回字段 | 匹配家电整机制造的标准化生产文档结构 |

## 容易做错的三处
- 现象：调用“获取对话记录列表”接口后，无法区分AI回复与用户提问。原因：未在`responseData`中配置对话角色标识字段，导致返回数据未标记提问与回复的对应关系。
- 现象：配置Basic Auth的Http模块时，认证失败。原因：未按`Basic Auth`标准格式编码账号密码，导致外部系统无法识别认证信息。
- 现象：批量执行节点在线调试正常，通过API调用时无法完成全部流程。原因：未在`variables`中配置批量请求限流参数，导致API调用时触发外部系统的并发限制。

## 怎么确认配好了
- 调用测试接口，查看`responseData`返回的字段是否包含产品型号、批次号等核心业务字段，核对字段名是否与装配作业书一致。
- 模拟批量请求，检查接口返回的状态码是否为200，且返回数据条数与预期的批量请求数量匹配。
- 检查`Authorization`配置的密钥是否与外部系统预设的服务账号一致，可通过单次调用测试认证结果。
- 运行完整工作流，查看对话日志中的运行数据是否包含外部系统返回的安规测试、充注记录等内容，确认数据不为空。
