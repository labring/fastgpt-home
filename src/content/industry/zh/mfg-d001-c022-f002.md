# 家用电器整机制造的供应商与过程质量审核：向量模型与索引

## 这个品类的数据长什么样
该品类数据涵盖空调、冰箱、洗衣机及小家电生产企业的业务文档，包括配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告与返修记录。数据来源包含ERP/MES系统、零部件批次台账、拧紧与充注设备日志、安规测试仪数据、性能实验室报告及售后故障档案。数据更新频率按单台产品、每班作业或抽检计划执行，单条记录包含零部件编号、工艺参数、测试结果、批次信息等字段，部分字段带有明确单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的多源异构数据、高频更新节奏与强工艺关联性，对向量模型与索引环节带来多重约束。多源数据格式差异大，需适配结构化台账与非结构化文档的统一嵌入处理。高频更新要求索引支持增量同步，避免全量重建占用过多资源。单台产品的细分数据需避免跨型号混同，索引需按产品型号、生产批次做维度隔离，防止检索时混入不匹配的工艺参数。安规、性能类测试数据的强合规性要求，需确保向量嵌入时保留字段级关联，避免丢失关键校验信息。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配装配作业书、测试报告的单段内容长度，避免跨工艺逻辑拆分 |
| 重叠长度 | 100–150 字符 | 保留相邻工艺步骤的上下文关联，防止装配流程的逻辑断裂 |
| maxToken | 4096 token | 匹配家电测试报告的单页内容最大长度，确保完整嵌入测试参数 |
| defaultToken | 512 token | 适配短字段如零部件编号、批次号的嵌入需求，减少冗余计算 |
| 相似度阈值 | 按实测标定 | 需结合安规测试、工艺参数的匹配精度调整，避免错配同型号不同批次数据 |
| 单次搜索上限 | 前 10 条 | 控制检索结果规模，适配多型号混线装配时的快速校验场景 |

## 容易做错的三处
- 升级版本后导入同配置的CSV文件出现分块报错，界面提示“字段解析失败：存在未闭合的换行符”。原因是新版本对CSV的字段解析规则调整，未兼容旧版中包含换行符的工艺参数字段。
- 知识库索引任务长时间卡在90%进度，未生成完整索引文件。原因是未开启增量索引模式，全量同步高频更新的售后故障数据时，单次任务超时未完成。
- 检索结果中混入不同型号家电的装配作业书，导致审核时出现错装风险。原因是未按产品型号设置索引的维度过滤规则，未隔离不同批次的工艺数据。

## 怎么确认配好了
- 上传单份家电配置BOM文档，检查分块后的片段是否完整保留零部件编号与装配顺序信息，调整分块与重叠长度至符合业务需求。
- 导入包含不同型号参数的测试数据，执行检索测试，验证结果是否仅返回目标型号的相关内容，确认维度过滤规则生效。
- 提交批量的返修记录数据进行索引，检查任务进度是否能在合理时间内完成，调整增量同步参数避免超时。
- 查看向量嵌入日志，确认结构化字段如扭矩、充注量的单位信息被完整保留在嵌入向量中，无字段丢失。
