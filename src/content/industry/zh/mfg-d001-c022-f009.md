# 家用电器整机制造的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
该品类数据涵盖空调、冰箱、洗衣机及小家电生产相关的配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告与返修记录。数据来源包括ERP/MES系统、零部件批次台账、拧紧与充注设备日志、安规测试仪、性能实验室数据及售后故障档案。更新节奏按单台产品、每班作业或抽检计划执行，单条数据包含零部件型号、工艺参数、测试结果、批次编号等字段，字段数量与长度随文档类型变化。

## 这些特征在「模型接入与配置」这一环带来什么约束
多型号混线装配的业务特征要求模型需支持多批次、多型号异构文档的快速识别，因此模型接入需适配不同格式的数据源兼容。高频更新的实时工艺与测试数据要求上下文窗口需适配短时高频的内容同步，避免因上下文溢出导致审核失效。安规与性能测试的强合规性要求，需模型能精准匹配文档中的特定字段，如制冷剂充注量、绝缘电阻值等，因此模型配置需优先保障字段召回精度。内网部署的场景限制了外部接口调用，需配置本地模型接入参数，同时需适配数据库连接异常的容错机制。

## 配置怎么定
本配置基于FastGPT v4.17.0版本制定，具体如下：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配多批次混线装配的多文档上下文需求，覆盖单次审核所需的BOM、工艺与测试数据 |
| `maxTokens` | 2000–3000 token | 控制单条审核结果的输出长度，适配安规、性能异常的结构化判断需求 |
| `quoteMaxToken` | 1500–2000 字符 | 限制引用文档的总长度，避免因过长引用导致模型推理超时 |
| `temperature` | 0.1–0.3 | 降低随机性，保障安规与性能判断的一致性，符合合规审核的严谨性要求 |
| `AIPROXY_API_ENDPOINT` | 内网部署的FastGPT代理地址 | 适配内网环境下的模型调用，避免外部网络限制 |
| `AIPROXY_API_TOKEN` | 按内网认证规则生成的令牌 | 保障内网模型调用的访问权限安全 |

## 容易做错的三处
- 现象为模型调用返回数据库连接拒绝错误，日志显示端口无响应；原因是未在配置中指定内网MySQL的正确地址与端口，导致无法拉取供应商台账数据。
- 现象为审核结果出现多型号混装的误判；原因是`maxContext`设置过小，未覆盖当前批次的全部BOM与工艺文档，导致模型无法区分不同零部件的型号要求。
- 现象为安规测试结果的字段匹配为空；原因是`quoteMaxToken`设置过大，模型无法精准定位文档中的特定测试参数，导致合规判断失效。

## 怎么确认配好了
- 调用测试接口，输入单台家电的BOM与安规测试数据，核对返回的审核结果是否包含对应字段的匹配内容。
- 查看系统日志，确认模型调用的数据库连接无超时或拒绝报错，验证内网环境下的接口连通性。
- 导入多型号混线的测试文档，核对模型是否能正确区分不同批次的零部件与工艺要求。
- 调整`temperature`参数后，对比两次审核结果的一致性，确认合规判断的稳定性。
