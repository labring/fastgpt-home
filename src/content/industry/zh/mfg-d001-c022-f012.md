# 家用电器整机制造的供应商与过程质量审核：部署与升级

## 这个品类的数据长什么样
家用电器整机制造的供应商与过程质量审核涉及的业务文档包含配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告、返修记录。数据来源涵盖ERP/MES系统、零部件批次台账、拧紧和充注设备、安规测试仪、性能实验室设备以及售后故障数据库。数据更新按单台产品、每班生产批次或抽检计划执行，字段包含零部件型号、工艺参数、测试结果、返修原因等核心信息。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的大批量混线装配特性，要求部署的检索系统支持多型号文档的精准区分，避免错装相关的检索偏差。多源工业设备与实时系统的数据来源，要求配置适配内网隔离的网络策略，减少公网传输延迟与安全风险。高频次的数据更新节奏，要求升级过程采用滚动更新模式，避免中断生产环节的实时数据接入。敏感的安规与售后数据，要求配置严格的访问权限校验规则，保障数据合规性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30 个连接` | 适配多班次生产的质检数据并发写入与检索需求，避免数据库连接耗尽 |
| `MONGODB_URI` | `副本集地址，包含认证信息` | 保障零部件批次、返修记录等敏感数据的访问安全，支持故障自动切换 |
| `STORAGE_S3_ENDPOINT` | `企业内网对象存储域名` | 减少公网传输延迟，适配大批量制冷剂充注记录、安规测试视频的存储需求 |
| `REDIS_URL` | `本地Redis实例，6379 端口` | 缓存高频查询的装配作业书内容，提升检索响应速度 |
| `FILE_TOKEN_KEY` | `32 位自定义加密密钥` | 为内嵌到生产看板的文档生成合法访问令牌，避免权限报错 |
| `ROOT_KEY` | `仅内部运维人员知晓的密钥` | 限制后台管理接口的访问权限，防止未授权的配置修改 |

## 容易做错的三处
- 现象：升级到FastGPT v4.9.3后，提交零部件批次关键词的检索请求，返回结果为空。原因：未重新索引新增的BOM与装配作业书字段，导致向量库未收录最新的质检文档。
- 现象：将FastGPT语音识别功能内嵌到生产看板网页时，提示permission denied。原因：未配置`FILE_TOKEN_KEY`生成访问权限校验规则，导致跨域请求被生产环境的网关拦截。
- 现象：执行docker打包启动FastGPT容器后，提示数据库连接超时。原因：`MONGODB_URI`未配置正确的内网访问地址，未适配生产环境的网络隔离策略。

## 怎么确认配好了
- 执行`docker ps`命令，确认FastGPT v4.17.0版本的所有相关容器处于运行状态，无异常退出。
- 提交一条包含特定型号空调装配作业书关键词的检索请求，验证返回结果匹配家电整机制造的业务文档。
- 上传一份新的制冷剂充注记录，确认文件存储路径符合`STORAGE_S3_ENDPOINT`的配置要求。
- 测试内嵌到测试网页的语音识别功能，确认无权限报错提示。
