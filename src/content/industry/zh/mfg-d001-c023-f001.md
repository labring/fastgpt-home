# 工业仪器仪表制造与校准的供应商与过程质量审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
本品类数据主要来自设计文件、标准器与环境监测设备、校准软件、实验室信息系统及客户量程要求。日常文档包含装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录，每台设备每次校准后更新。数据字段包含设备编号、校准日期、标准器参数、环境温湿度、多点测量值、误差计算结果、溯源链编号，单位涵盖帕斯卡、摄氏度、毫安等计量专用单位，每份校准记录关联唯一计量证书编号。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
本品类的校准记录与计量证书是核心交付物，需通过HTTP接口同步至外部系统或供应商审核平台。每台设备每次校准生成独立数据，接口需支持单次单设备或小批量数据提交。数据字段包含大量计量专用参数，接口需严格匹配字段格式与单位。审核溯源链、环境条件等环节需接口支持批量校验数据完整性，错误提交会直接导致计量审核不通过。校准数据更新频率高，接口需适配高频小批量提交场景，避免数据积压。

## 配置怎么定
本配置适用于FastGPT v4.17.0。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 请求头配置 | 固定`Authorization`参数携带Bearer令牌，有效期`7200 秒` | 匹配计量数据的权限校验要求，避免未授权访问 |
| 变量映射 | 将校准数据字段映射为`variables`中的标准化键名 | 适配外部系统的字段接收规则 |
| 响应数据处理 | 校验`responseData`中的计量证书编号字段完整性 | 确保返回的提交结果可追溯 |
| 提交批次大小 | 单次提交`1–3 台设备`的校准数据 | 适配每台设备每次校准的独立数据更新节奏 |
| 超时时间 | 设置为`60 秒` | 避免因校准数据量大导致接口请求超时 |
| 重试策略 | 仅在状态码为`500`或`502`时重试 | 避免重复提交导致的校准数据重复 |

## 容易做错的三处
- 配置`Authorization`时使用过期的Bearer令牌，返回状态码`401 Unauthorized`，原因是未定期更新权限凭证。
- 未按校准数据的独立更新节奏设置提交批次，单次提交超过3台设备的数据，导致接口超时，返回状态码`504 Gateway Timeout`。
- 未正确配置外部系统的连接地址，导致接口请求失败，返回状态码`500 Internal Server Error`，类似社区中部署时外部系统连接配置错误的常见问题。

## 怎么确认配好了
- 提交单台设备的校准数据，检查`responseData`中是否返回正确的计量证书编号。
- 查看接口日志，确认`Authorization`参数被正确携带在请求头中。
- 模拟提交缺少计量证书编号的异常数据，确认接口返回明确的错误提示。
- 批量提交3台设备的校准数据，确认接口未出现超时错误。
