# 工业仪器仪表制造与校准的供应商与过程质量审核：向量模型与索引

## 这个品类的数据长什么样
本品类数据来自流量、压力、温度、分析仪器制造商及计量实验室，涵盖装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录。数据取自设计文件、标准器监测数据、校准软件、实验室信息系统及客户量程要求，更新频率为每台每次校准，字段包含量程单位（如Pa、℃、ppm）、校准日期、溯源编号、误差计算值等，部分文档含结构化数值与图表文本。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类数据更新频率高且单条数据关联单台设备的全校准流程，向量分块时需保留溯源编号、量程等关键元数据避免信息断裂；误差曲线、计量证书包含结构化数值与图表文本，需适配长文本与结构化字段的向量映射逻辑；每台设备的校准记录独立更新，索引需支持增量同步以避免全量重建的耗时；数据溯源要求严格，检索结果需关联原始文档的字段信息，因此索引需保留文档元数据与向量的关联关系。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配校准规程、原始记录等长文本的语义完整性，避免关键字段被截断 |
| 重叠长度 | 50–100 字符 | 保留相邻分块的语义关联，适配误差曲线等连续数值文本的连贯性 |
| `maxToken` | 4096 token | 匹配通用嵌入模型的输入上限，适配校准证书等含多字段的文本长度 |
| 相似度阈值 | 0.75–0.85 | 过滤低匹配度的非校准类文档，确保检索结果关联仪器校准核心流程 |
| 单次搜索上限 | 前10条 | 控制检索结果数量，避免上下文过载影响审核判断 |
| `defaultToken` | 按实测标定 | 适配不同校准记录的平均token长度，优化索引构建效率 |

## 容易做错的三处
- 升级版本后检索无结果，界面显示知识库索引状态异常。原因是未同步更新索引的元数据关联规则，FastGPT v4.17.0版本对字段匹配的校验逻辑调整，原有配置未适配校准记录的溯源编号字段格式。
- 导入csv格式的校准记录时报错，提示分块失败。原因是csv文件包含未转义的特殊字符（如误差曲线中的±符号），未提前做文本清洗，导致分块时触发格式校验失败。
- 检索结果未关联原始校准证书的溯源信息。原因是索引配置未开启元数据保留选项，仅存储了文本向量未关联文档字段，无法在检索结果中展示溯源编号等关键审核信息。

## 怎么确认配好了
- 上传单份校准规程文档，执行分块测试，检查分块结果是否保留了溯源编号、量程等关键字段。
- 触发增量索引同步，验证更新后的校准记录是否能被正常检索到，无全量重建耗时过长的问题。
- 输入检索词（如“压力校准误差计算”），检查检索结果是否关联对应文档的元数据字段。
- 调整相似度阈值，验证检索结果的匹配度是否符合审核所需的精度要求。
