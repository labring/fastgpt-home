# 工业仪器仪表制造与校准的供应商与过程质量审核：多轮对话与提示词

## 这个品类的数据长什么样
本品类数据来自流量、压力、温度、分析仪器制造商及计量实验室，涵盖装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录等日常文档。数据来源包括设计文件、标准器和环境监测数据、校准软件、实验室信息系统及客户量程要求，更新频率为每台设备每次校准后更新。文档包含计量证书编号、误差值、校准日期、标准器信息等固定字段，单位多为计量标准单位，单台设备的校准相关文档总长度相对固定。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
本品类的数据更新频率高且绑定单台设备，因此多轮对话需要通过`chatId`绑定唯一设备标识，确保上下文关联对应设备的校准记录。日常文档包含误差曲线、计量证书等专业内容，提示词需要明确指定提取核心计量字段，避免引入无关的装配调试内容。数据来源分散且需审核溯源链，多轮对话的`messages`需要保留历史审核记录，确保每一轮的提问都基于之前的校准信息。此外，校准文档的字段与单位有严格规范，引用模板需要匹配量程、标准器等关键维度，避免引用不相关的文档内容。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，具体如下：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 单次搜索上限 | 前3条 | 校准相关文档数量有限，过多会引入无关误差 |
| 最大上下文长度 | 1200–1800 字符 | 适配单台设备的校准记录与误差曲线总长度 |
| 引用内容模板 | 保留计量证书编号、误差值、校准日期字段 | 匹配品类文档的核心交付物字段 |
| 引用模板提示词 | 优先匹配被测件量程与校准标准器信息 | 贴合仪器校准的核心匹配维度 |
| `chatId` | 绑定单台设备的唯一标识 | 确保多轮对话上下文关联对应设备的校准数据 |
| `variables` | 绑定单台设备的量程、校准标准器参数 | 传递专属校准维度信息 |
| `messages` | 保留最近5轮对话内容 | 支持多轮审核的上下文追溯 |
| 并发请求限制 | 20 次/分钟 | 适配实验室系统的接口调用频率上限 |

## 容易做错的三处
- 现象：API调用时返回的结果缺少误差曲线字段，在线对话则完整包含。原因：API调用时未正确配置`messages`保留历史上下文，导致未关联对应设备的误差曲线文档。
- 现象：引用内容包含大量无关的装配调试单内容，未匹配校准相关文档。原因：未设置引用模板提示词的匹配维度，未限定仅匹配量程、标准器相关的文档。
- 现象：工作流中AI回复注释触发后，stream回复提前终止。原因：误将注释触发时机理解为回复过程中，未按配置在stream回复完毕后触发。

## 怎么确认配好了
- 发起单台设备的校准审核对话，检查返回结果包含计量证书编号、误差值等核心字段。
- 调用API并设置`chatId`为固定设备标识，发起两轮对话，验证上下文保留历史审核记录。
- 对比在线对话与API调用的返回结果，确认字段一致性。
- 发起多轮并发请求，验证未超过配置的并发限制。
