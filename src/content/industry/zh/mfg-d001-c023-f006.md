# 工业仪器仪表制造与校准的供应商与过程质量审核：引用来源与溯源

本配置项均适配FastGPT v4.17.0版本的界面逻辑。

## 这个品类的数据长什么样
数据来源包括设计文件、标准器和环境监测数据、校准软件输出、实验室信息系统及客户量程要求，更新频率为每台设备每次校准后。日常文档涵盖装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录，字段包含被测件编号、校准日期、标准器编号、误差值、量程范围、计量证书编号，单位多为国际标准计量单位。

## 这些特征在「引用来源与溯源」这一环带来什么约束
高频率的单次校准文档生成，要求溯源系统能快速定位单台设备的最新校准记录；文档包含计量证书编号、标准器编号等唯一标识，需要精准匹配溯源链以确保审核有效性；专业计量字段与单位要求检索时保留关联信息，避免溯源信息失真；原始校准记录、误差曲线等非结构化内容需精准召回，防止遗漏关键误差数据影响审核结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 相似度阈值 | 0.75–0.85 | 匹配计量证书、校准记录等专业文档的精准度要求 |
| `quoteMaxToken` | 8000–12000 token | 容纳单台设备完整校准记录与误差曲线的内容长度 |
| 单次召回条数 | 前6条 | 覆盖校准规程、计量证书、调试单等多份关联文档的需求 |
| `detail` | 完整 | 保留原始记录中的标准器编号、校准日期等关键溯源字段 |
| 最大上下文窗口 | 16000–20000 字符 | 承载多台设备批量审核时的关联数据 |

## 容易做错的三处
- 配置`quoteMaxToken`取值过小，导致召回的校准记录被截断，界面显示引用内容不完整，无法查看完整误差曲线与计量证书编号。原因是未考虑单台设备校准文档的总长度需求。
- 直接在提示词中硬编码知识库ID，调用时返回固定结果，无法根据审核的被测件自动匹配对应校准数据。原因是未使用变量绑定逻辑实现动态知识库召回，触发配置报错。
- 未设置合理的相似度阈值，导致召回大量不相关的通用校准规程，无法精准定位当前被测件的专属记录。原因是未针对专业计量文档的字段特征调整匹配规则。

## 怎么确认配好了
- 输入单台被测件的专属编号，核对召回的文档是否包含该编号对应的校准记录、计量证书与误差曲线。
- 查看引用内容的完整度，确认未出现字段截断或信息缺失的情况。
- 调整相似度阈值，验证召回结果的精准度是否符合专业文档的匹配要求。
- 测试变量绑定逻辑，确认输入不同被测件编号时，召回的文档自动切换为对应设备的数据。
