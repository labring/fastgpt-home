# 工业仪器仪表制造与校准的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
本品类的数据来自设计文件、标准器与环境监测数据、校准软件、实验室信息系统及客户量程要求。单台仪器每次校准后会生成装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录等文档，字段包含溯源编号、量程范围、误差值（单位为Pa、℃、kPa等）、校准日期与环境参数。数据更新频率为每台每次校准，单份文档的长度随校准点数与误差曲线复杂度变化。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类的校准记录与计量证书是核心交付物，数据需严格溯源且不能出现偏差。多类型文档混合的特征要求模型能同时处理结构化字段与非结构化图表数据；按单台每次校准更新的节奏，要求上下文需限定在单次校准的全流程材料内，避免跨批次数据混淆。最耗时的审核环节涉及多点误差计算与溯源链验证，需要模型能自动调用工具获取分散在不同系统中的数据，同时保证输出内容与原始记录完全匹配，不能生成无依据的内容。此外，测量偏差传递风险要求配置需严格控制模型的生成自由度，避免无关内容干扰审核结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 覆盖单台仪器单次校准的全部文档内容，包括校准记录、误差曲线与计量证书 |
| `quoteMaxToken` | 2000–3000 token per quote | 完整保留计量证书的溯源信息与误差曲线的关键数据，避免截断核心审核依据 |
| 工作流/API 工具选择配置 | auto | 自动调用工具查询实验室信息系统中的校准记录与标准器数据，适配多系统协同的审核流程 |
| `temperature` | 0.1–0.3 | 控制模型生成内容的严谨性，避免出现与原始校准数据不符的偏差内容 |
| `AIPROXY_API_ENDPOINT` | 按部署的代理服务填写 | 安全转发大模型请求，避免直接暴露接口密钥 |
| `AIPROXY_API_TOKEN` | 按FastGPT v4.17.0的配置规则生成 | 完成接口身份验证，确保请求合法有效 |

## 容易做错的三处
- 现象：模型输出未引用原始校准记录，直接生成通用审核结论。原因：未配置`quoteMaxToken`或取值过小，导致无法加载完整的校准数据，触发模型直接生成内容的行为。
- 现象：无法查看校准记录对应的数据库表结构。原因：未在配置中开启数据表映射工具，或未导入实验室信息系统的表定义文件，导致无法识别校准数据的字段与关联关系。
- 现象：部分浏览器中无法正常加载模型配置页面或问答界面。原因：未适配FastGPT支持的浏览器版本，或浏览器的隐私拦截规则阻止了接口请求，导致配置无法正常保存或问答无法发起。

## 怎么确认配好了
- 发起一次模拟供应商审核请求，检查模型是否自动调用工具获取对应仪器的校准记录与计量证书数据。
- 查看输出内容的引用标记，确认所有核心审核依据都来自原始校准文档，无生成的无依据内容。
- 验证本地大模型服务的连接状态，确认接口请求能正常返回符合校准数据格式的响应。
- 切换不同浏览器打开配置页面，确认页面加载与接口请求无拦截或报错，适配目标使用的浏览器版本。
