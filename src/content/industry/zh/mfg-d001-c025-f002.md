# 工装夹具与检具制造的供应商与过程质量审核：向量模型与索引

## 这个品类的数据长什么样
工装夹具与检具制造的业务数据来自汽车、航空、机械装配企业的工装部门及专用工装供应商，日常文档包含工装需求书、定位基准方案、夹具图、检具操作书、验收报告、校准记录、变更履历。数据来源覆盖产品数模与GD&T参数、工艺路线、三坐标检测数据、现场试用反馈、计量系统数据。更新节奏按项目交付、产品变更、定期校准执行，文档包含专业工程术语、几何公差参数、计量数值与操作步骤，单份文档的文本长度跨度较大。

## 这些特征在「向量模型与索引」这一环带来什么约束
品类数据包含专业工程术语、多类型文档格式与跨度较大的文本长度，要求向量模型适配工业场景的术语语义。按项目与变更的更新节奏，要求索引支持增量更新与版本化管理，避免全量重建带来的耗时问题。工程图、校准记录等文档的专业内容易被分块截断，需要合理设置分块与重叠参数。多模态数据的嵌入需求，要求配置适配多模态输入的模型参数，避免出现格式不兼容的报错。同时，该品类的审核场景对检索精度要求较高，错误的索引配置可能导致装夹偏差、检具误判等严重后果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxToken` | 8192 | 适配工装夹具文档中包含的工程图文本、GD&T参数与校准记录的总token长度 |
| `defaultToken` | 4096 | 满足多模态Embedding处理夹具图文本描述与三坐标数据的嵌入需求 |
| 分块长度 | 800–1200 字符 | 匹配夹具图说明、验收报告的单段文本长度，避免专业术语被拆分 |
| 重叠长度 | 100–150 字符 | 保留跨分块的专业术语上下文，防止分块截断导致语义丢失 |
| 相似度阈值 | 0.72–0.85 | 适配工业文档的专业术语匹配精度，过滤低相关性的历史数据 |
| 单次搜索上限 | 前 10 条 | 聚焦最相关的历史验收、校准记录，满足审核场景的精准检索需求 |

## 容易做错的三处
- 现象：接入多模态Embedding模型时返回Invalid参数报错。原因：未适配工装夹具文档中的GD&T术语、工程图文本的token格式，未在FastGPT v4.17.0中启用工业文档嵌入优化。
- 现象：升级新版本后voyage索引无法使用，返回400状态码无响应体。原因：未更新索引的配置参数以适配新版本的向量协议，未重新生成历史数据的嵌入向量。
- 现象：重建知识库索引后，历史校准记录无法被正确检索。原因：分块重叠长度设置过小，导致专业术语被截断后无法匹配查询。

## 怎么确认配好了
- 上传一份典型的工装夹具验收报告，检查生成的嵌入向量是否包含GD&T参数、校准日期等核心字段。
- 发起一次针对历史变更履历的检索，确认返回结果的相似度符合预设的阈值区间。
- 执行一次向量库迁移测试，验证旧版本数据可以正常加载到新的索引结构中。
- 调用多模态Embedding接口上传一张夹具图的文本描述，确认返回的嵌入向量无报错且格式正确。
