# 工装夹具与检具制造的供应商与过程质量审核：文档解析与分块

本文档基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
工装夹具与检具制造的日常文档包含工装需求书、定位基准方案、夹具图、检具操作书、验收报告、校准记录、变更履历。数据来源包括产品数模与GD&T、工艺路线、三坐标数据、现场试用反馈、计量系统。更新按项目推进、随产品变更触发、按周期完成校准更新。文档包含结构化测量数值、形位公差参数、校准周期等专属字段，部分文档如夹具图为CAD导出的PDF格式，结构与通用办公文档差异较大。

## 这些特征在「文档解析与分块」这一环带来什么约束
品类文档的结构差异较大，CAD图纸类PDF与技术文档、校准记录的格式逻辑不同，需针对性的解析规则。结构化的三坐标数据、GD&T参数需完整保留字段完整性，不能被随意拆分。按项目与变更的更新节奏，要求分块需关联项目元数据，避免跨项目内容混合。大型工装CAD图纸的解析耗时较长，需适配更长的解析时长阈值，防止中途失败。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配工装需求书、验收报告的常规段落长度，同时容纳三坐标测量数据的分段内容，避免拆分关键技术参数 |
| `chunkSplitter` | 自定义分隔符（章节标题、换行符） | 适配变更履历、检具操作书的结构化分段需求，避免拆分GD&T技术参数与定位基准描述 |
| `customPdfParse` | 开启 | 针对夹具CAD图纸的非标准PDF格式，适配图层与专业技术文本的提取逻辑，提升解析完整性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 应对大型工装CAD图纸PDF的解析耗时，避免因默认时长不足导致解析失败 |
| `chunkSettingMode` | 手动配置 | 针对校准记录、变更履历等不同文档类型，调整分块参数以适配细分场景的内容结构 |

## 容易做错的三处
- 上传大型工装CAD图纸PDF后显示解析失败，日志返回超时错误。原因是未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认时长不足以完成大型图纸的文本与图层提取。
- 配置自定义解析后处理逻辑时未匹配品类文档结构，导致GD&T参数、校准记录字段被错误拆分。原因是未启用`customPdfParse`并配置针对性的文档识别规则。
- 知识库召回结果包含不相关的旧版变更履历内容。原因是未按项目关联元数据配置分块，导致跨项目的文档内容被混合分块。

## 怎么确认配好了
- 上传单份100MB以内的工装夹具图PDF，检查解析状态是否在设定的`PARSE_FILE_TIMEOUT_SECONDS`内完成，无超时报错。
- 导入一份包含GD&T参数的工装需求书文档，检查分块结果是否保留了完整的形位公差描述，未被错误拆分。
- 启用`customPdfParse`后，验证检具操作书的步骤文本是否被正确提取，无缺失或乱码内容。
- 上传多份同项目的文档，检查分块结果是否保留了项目关联的元数据，未出现跨项目内容混合的情况。
