# 有色金属冶炼与电解的供应商与过程质量审核：工作流编排

## 这个品类的数据长什么样
该品类的核心数据来源包括精矿与辅料分析报告、DCS系统采集的设备运行数据、电解槽电压电流监测数据、化验室检测结果、能源与环保监测系统。数据更新频率覆盖每批原料、每炉或每槽的实时同步。日常业务文档包含配料单、熔炼记录、电解槽况记录、化验报告、阳极阴极质量记录、环保台账，文档内包含原料成分参数、设备运行指标、检测数值等专用字段，对应业务场景的专属单位。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的数据来源分散且更新节奏差异大，导致工作流需要适配多数据源的串联调用，需合理设置节点触发顺序与间隔。业务文档包含大量专用字段，要求工作流的变量提取节点需精准匹配专属字段路径。数据异常会直接影响金属回收率与产品质量，因此工作流需配置失败重试与异常告警环节。同时，该品类对电解槽群管理与杂质控制要求较高，工作流需加入针对性的校验与核算节点，确保流程符合业务逻辑。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 绑定精矿品位、槽电压、阳极质量等业务字段 | 匹配该品类核心审核与监测参数 |
| `nodeId` | 按业务环节命名（如“熔炼记录提取”“槽况校验”） | 便于工作流排查与维护 |
| 数据库连接超时 | 600秒 | 该品类数据查询可能涉及多炉次历史数据，需较长超时时间 |
| JSONPath变量配置 | 按实测标定匹配业务字段路径 | 适配该品类文档的半结构化格式与专用字段 |
| 问题分类节点背景知识 | 填写配料单、熔炼记录的典型字段与审核逻辑 | 提升分类节点对专属场景的匹配精度 |
| 工作流导出设置 | 选择JSON格式并勾选权限开关 | 便于工作流的备份与跨环境部署 |

## 容易做错的三处
- 现象：HTTP请求节点运行后下游节点接收的变量为空。原因：未正确配置JSONPath提取规则，未匹配到该品类业务数据的专属字段路径。
- 现象：工作流运行时弹出数据库连接失败报错，提示Failed to connect to相关内容。原因：未配置正确的数据库实例地址与端口，或网络策略限制了访问目标数据库。
- 现象：问题分类节点无法准确匹配审核场景类型。原因：背景知识未填写该品类专属的审核文档示例与字段说明。

## 怎么确认配好了
- 运行单步测试节点，检查`variables`中提取的业务参数是否与源数据一致。
- 发起模拟的数据库连接请求，确认连接状态正常。
- 提交一批模拟的审核文档，检查问题分类节点的匹配结果是否符合预期。
- 尝试导出工作流配置，确认导出操作可正常完成并生成有效文件。
