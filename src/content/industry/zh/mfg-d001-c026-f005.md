# 有色金属冶炼与电解的供应商与过程质量审核：工具调用与插件

## 这个品类的数据长什么样
有色金属冶炼与电解的业务数据来源包括精矿与辅料分析报告、DCS系统数据、电解槽电压电流监测数据、化验室检测结果、能源与环保监测台账。数据更新频率覆盖每批原料、每炉熔炼或每槽电解作业，部分槽况、能耗数据为实时更新。日常审核涉及的文档包含配料单、熔炼记录、电解槽况记录、化验报告、阳极阴极质量记录、环保台账，字段包含精矿品位、槽电压、电流强度、元素含量、排放限值等，各文档有固定的单位与格式要求。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源异构的数据来源要求工具调用需支持对接不同类型的外部接口，包括工业控制系统、化验室系统、环保监测系统等。实时与批量更新的数据节奏，要求插件调用需适配短周期数据拉取与多批次数据处理，避免因超时或延迟影响审核流程。固定字段格式的业务文档，要求工具返回的结构化数据需与预设字段匹配，否则无法完成成分平衡、槽况分析等审核计算。同时，审核环节出错会导致金属回收率下降、产品不合格等后果，要求工具调用需配置重试与异常捕获机制，降低流程中断风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配供应商资质审核、过程质量审核等多类场景，自动选择匹配的工具 |
| `functionCall` | `enabled` | 支持调用外部数据源插件获取实时冶炼、化验数据 |
| 单次插件调用超时 | 600 秒 | 覆盖精矿分析、槽况监测等数据的获取时长，避免中断审核流程 |
| 插件调用重试次数 | 2 次 | 应对DCS、化验室接口临时波动，降低审核失败概率 |
| 单次召回插件数量 | 前3条 | 聚焦核心审核所需的数据源，避免冗余数据干扰分析 |
| 插件返回数据解析规则 | 按预设字段映射 | 匹配配料单、电解槽况记录的固定字段格式，确保审核数据准确 |

## 容易做错的三处
- 现象：调用工具返回的文本为无格式整段内容，前端解析后可读性差。原因：未启用`functionCall`的结构化输出配置，未为插件配置字段映射规则，导致返回内容未按业务文档格式整理。
- 现象：前端转发工具调用流数据时出现断开，页面数据固定无法恢复。原因：未配置插件调用的超时重连逻辑，或未处理流中断后的会话恢复，导致中间服务转发后无法续接数据。
- 现象：Docker部署的FastGPT中创建系统插件时，无法找到`packages/plugins/register`文件。原因：FastGPT v4.17.0版本已调整插件注册路径至`data/plugins`目录，需按官方指引修改配置路径。

## 怎么确认配好了
- 发起一次供应商资质审核的工具调用，检查返回结果是否包含预设的精矿成分、槽况等字段，字段格式与业务文档一致。
- 模拟接口超时场景，确认工具调用会触发重试机制，且重试次数符合配置项设置。
- 查看插件调用日志，确认所有配置的数据源接口均能正常拉取数据，无权限或连接错误。
- 测试指定工作流调用，确认传入对应参数后能触发审核流程，返回预期的结构化结果。
