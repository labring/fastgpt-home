# 模具设计制造的供应商与过程质量审核：向量模型与索引

## 这个品类的数据长什么样
该品类的核心数据来自客户产品模型、模流或成形仿真文件、CAD/CAM导出图纸、机加工与测量记录、试模样件数据。日常产出的文档包括模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历。数据更新按单个项目推进，每次试模或改模后都会生成新的版本文件。数据字段包含模具编号、零件尺寸公差、加工参数、试模缺陷记录、改模次数等，部分文件包含结构化参数与非结构化文本内容。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据按项目迭代更新，且包含结构化参数与非结构化设计内容，要求索引需支持按项目维度关联多版本数据，适配单次试模或改模后的增量同步。零件尺寸公差、加工参数等结构化字段需与非文本内容关联检索，索引需同时支持元数据与向量文本的联合匹配。不同项目的模具数据关联性较弱，需避免跨项目的无关召回结果，因此索引的召回范围需支持按项目维度过滤。大量的工程图纸与仿真文件的向量转换，需适配非结构化文本的分段规则，避免丢失关键设计细节。

## 配置怎么定
本文适配FastGPT v4.17.0版本，以下为具体配置建议：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配模具设计文档中包含的零件尺寸、加工工艺等连续文本内容，避免拆分关键设计段落 |
| 重叠长度 | 50–100 字符 | 保留相邻分块的关联细节，防止截断试模缺陷描述、改模关联信息 |
| `defaultToken` | 4096 | 匹配多数模具设计文档的单页文本长度上限，适配向量模型的输入限制 |
| `maxToken` | 8192 | 支持整合多份关联文档（如DFM报告与试模报告）的上下文内容，满足审核时的多文档关联检索需求 |
| 相似度阈值 | 0.72–0.85 按实测标定 | 过滤低匹配度的无关模具项目数据，避免跨项目召回干扰审核流程 |
| 单次搜索上限 | 前 8 条 | 控制召回结果数量，适配模具审核时需聚焦核心问题的检索场景 |

## 容易做错的三处
- 现象：导入的模具设计文档生成的dataset.csv仅包含index字段，无content字段内容。原因：未正确配置分块长度与文本提取规则，导致非结构化文档的文本内容未被完整提取并写入目标字段。
- 现象：Docker部署环境中集成向量模型后，检索结果为空或出现超时报错。原因：未配置正确的模型访问端口与网络策略，导致FastGPT容器无法连通向量模型服务，或`defaultToken`设置超出模型输入限制引发超时。
- 现象：检索结果包含跨项目的无关模具数据，无法精准匹配当前审核项目。原因：未开启按项目维度的索引过滤配置，导致召回范围覆盖所有历史项目数据，干扰当前审核流程。

## 怎么确认配好了
- 查看知识库导入日志，确认所有模具设计文档的content字段均被正确提取并写入向量数据库。
- 提交包含模具编号、试模缺陷关键词的检索请求，核对召回结果是否仅包含当前审核项目的关联文档。
- 调整分块长度与重叠长度参数，验证不同配置下的向量转换结果是否保留关键设计细节。
- 检查向量模型的访问日志，确认FastGPT容器可正常连通模型服务，无超时或报错记录。
