# 模具设计制造的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
该品类的日常文档包含模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历。数据主要来自客户产品模型、模流或成形仿真、CAD/CAM、机加工与测量数据、试模样件。数据更新按项目推进，每次试模或改模后都会同步更新，不同项目的文档结构、字段存在差异，部分文档包含模腔数、脱模斜度、材料牌号、加工精度要求等细分字段。

## 这些特征在「模型接入与配置」这一环带来什么约束
日常文档类型多样且结构不统一，要求模型接入时需支持多格式文档解析与字段提取适配。数据更新频率随项目迭代，需配置支持增量同步的接入逻辑，避免全量重复加载。不同项目的细分字段差异较大，需预留自定义字段映射的配置空间。试模与改模产生的实时数据需快速接入，对模型响应的实时性有一定要求。模具相关数据涉及生产工装的精度要求，模型输出的审核结果需具备较高的准确性，因此对上下文长度、token限制等参数的配置需匹配业务场景。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 匹配模具设计文档的平均长度，确保审核时可完整加载DFM报告、零件图相关的上下文信息 |
| `maxTokens` | 4000–6000 token | 限制单次回复的输出长度，避免因过长内容影响审核效率，适配过程质量审核的短平快需求 |
| `quoteMaxToken` | 2000–3000 token | 限定引用文档的总token数，确保检索到的试模报告、加工工艺卡等内容可完整纳入审核逻辑 |
| `temperature` | 0.2–0.4 | 降低输出的随机性，保证模具精度、脱模可行性等审核结论的一致性 |
| `AIPROXY_API_ENDPOINT` | 按业务部署的代理地址 | 适配企业内部网络环境，确保模型调用的稳定性与数据安全性 |
| `AIPROXY_API_TOKEN` | 按实测标定 | 匹配代理服务的鉴权要求，保障接入的合法性 |

## 容易做错的三处
- 现象：升级FastGPT v4.17.0后，相同知识库与嵌入模型的检索时间明显增加，对话响应耗时超10秒。原因：未根据模具设计文档的长度调整`maxContext`参数，导致每次调用加载过多冗余上下文数据。
- 现象：尝试接入企微机器人时无法完成配置，未找到官方支持的替代方案。原因：未通过工作流模块配置自定义API接入渠道，仅使用官方内置的接入模板。
- 现象：将工作流发布为个人微信渠道后，仅支持单人扫码使用，无法实现多人协同访问。原因：未将工作流的访问权限配置为团队共享模式，仅开放了个人临时访问链接。

## 怎么确认配好了
- 上传一份完整的模具设计任务书与试模报告，测试模型能否正确提取关键审核项，核对输出内容是否覆盖文档核心信息。
- 模拟多次试模改模的场景，触发数据同步流程，确认新上传的改模通知可被模型正常检索与引用。
- 调整`temperature`参数后，对比两次相同审核请求的输出结果，确认结果一致性符合业务要求。
- 调用测试接口验证`AIPROXY_API_TOKEN`与`AIPROXY_API_ENDPOINT`的配置有效性，确认无鉴权或连接报错。
