# 模具设计制造的供应商与过程质量审核：部署与升级

## 这个品类的数据长什么样
该品类数据通常来自客户产品模型、模流或成形仿真文件、CAD/CAM源文件、机加工与测量记录、试模样件检测数据。日常产出的文档包含模具设计任务书、DFM报告、零件工程图、加工工艺卡、试模报告、改模通知、模具履历表。数据更新按单个项目推进，每次试模或改模后同步更新，文档包含明确的零件尺寸、模具结构参数、加工公差、试模缺陷记录等字段，无统一固定单位，随项目需求调整。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的多源异构工程文件、按项目高频更新的特性，对部署与升级环节带来具体约束。首先，需兼容CAD、模流仿真等非标准格式文件的存储与解析，因此部署时需配置适配的存储服务参数。其次，单次项目数据量随试模改模迭代增长，需合理配置数据库连接参数保障读写性能。此外，跨供应商的协作审核需求，要求部署时配置权限管理相关参数，避免未授权访问项目文档。升级环节则需保障历史模具履历、试模报告等核心数据的完整迁移，防止项目数据丢失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://user:pass@host:27017/fastgpt?authSource=admin` | 存储模具项目的试模报告、改模记录等结构化数据，需指定专属数据库实例保障数据隔离 |
| `REDIS_URL` | `redis://:pass@host:6379/0` | 缓存高频访问的模具零件图、DFM报告预览数据，降低数据库读写压力，按实测标定 |
| `STORAGE_S3_ENDPOINT` | `http://minio.host:9000` | 存储CAD源文件、模流仿真文件等大体积工程文件，需适配自建对象存储服务地址 |
| `DB_MAX_LINK` | `50–80` | 单项目多成员协作审核时，数据库连接数需覆盖并发访问需求，避免连接耗尽 |
| `FE_DOMAIN` | `https://audit.mold-manufacture.com` | 配置前端访问域名，保障团队成员通过指定地址访问审核流程，避免跨域问题 |
| `ROOT_KEY` | 自定义高强度随机字符串 | 管理平台最高权限，用于配置团队成员的审核权限与项目访问范围 |

## 容易做错的三处
- 现象：使用docker-compose部署后，所有模型调用返回报错，容器日志显示数据库连接超时。原因：未根据模具项目的并发访问需求调整`DB_MAX_LINK`参数，导致数据库连接池耗尽，无法处理审核流程的请求。
- 现象：升级至FastGPT v4.17.0版本后，原有供应商审核示例流程无法正常运行，提示流程节点缺失。原因：升级时未同步更新`PG_URL`指向的关系型数据库结构，导致示例流程依赖的审核记录表未完成迁移。
- 现象：团队成员无法创建独立的模具审核项目，提示无权限访问部署的程序。原因：未正确配置`ROOT_KEY`生成的权限令牌，未给协作成员分配对应项目的访问范围，导致权限校验失败。

## 怎么确认配好了
- 访问配置的`FE_DOMAIN`地址，确认前端页面可以正常加载，无跨域或访问报错。
- 上传一份模具零件图文件，确认可以正常存储并生成预览，验证`STORAGE_S3_ENDPOINT`配置生效。
- 发起一次供应商审核流程，提交试模报告数据，确认数据库可以正常写入并检索数据，验证`MONGODB_URI`与`DB_MAX_LINK`配置符合并发需求。
- 使用`ROOT_KEY`生成的权限令牌，邀请测试成员访问项目，确认权限校验逻辑正常生效。
