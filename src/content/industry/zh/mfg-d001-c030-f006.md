# 橡胶混炼与制品硫化的供应商与过程质量审核：引用来源与溯源

## 这个品类的数据长什么样
本品类数据主要来自配方系统、原材料批次台账、密炼机、门尼粘度仪、流变仪、硫化机及实验室检测设备。日常文档包含配方单、称量记录、混炼曲线、胶料快检报告、硫化工艺卡、模具使用记录、成品性能报告等，每个文档绑定唯一批次标识，更新频率为每车原材料批次、每批胶料混炼、每模次硫化操作。数据字段包含投料比例、混炼温度、时长、硫化压力、温度曲线等，单位涵盖摄氏度、分钟、兆帕等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
本品类的批次绑定、高频更新与多源数据特征，对引用溯源带来多重约束。首先，每批次数据需精准关联唯一标识，避免跨批次混淆，确保溯源结果指向正确的混炼与硫化环节。其次，多源异构文档（如曲线类、表格类、文本类）需统一适配引用格式，保证不同类型的工艺记录均可被正确溯源。再者，高频更新的实时数据要求溯源系统支持快速加载最新批次的文档，同时需保留原始记录不可篡改的特性，匹配生产过程的质量管控要求。最后，出错后果严重的特性要求溯源结果必须具备可追溯性，确保审核时可快速定位原始数据来源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 最大上下文token数 | 8000–12000 token | 适配混炼曲线、工艺卡等多文档的批量引用需求 |
| 返回引用数据开关 | 开启 | 确保系统加载并展示本地知识库中的原始生产文档 |
| `detail` | 显示原始文档的全部内容 | 满足过程质量审核的全字段溯源要求 |
| 单次召回结果数 | 前6条 | 覆盖单批次下的混炼、硫化、检测等多环节记录 |
| `quoteMaxToken` | 1500 token | 限制单条引用内容的长度，避免上下文溢出 |
| `responseData` | 返回完整元数据与原始内容 | 用于严格溯源的合规场景 |
| 重排配置 | 按匹配度降序 | 优先展示与当前审核问题最相关的工艺记录 |

## 容易做错的三处
- 现象：回答中未包含本地知识库的生产文档内容，仅展示通用回复，引用列表显示正确但正文无对应内容。原因：未开启返回引用数据开关，系统未加载本地存储的配方单、混炼曲线等文档。
- 现象：溯源结果仅显示部分字段，无法查看完整的投料比例或硫化参数。原因：`detail`配置设置为仅展示基础字段，未开启完整内容展示。
- 现象：召回结果排序混乱，无关的旧批次记录优先展示。原因：未启用按匹配度降序的重排配置，导致召回结果未按相关性排序。

## 怎么确认配好了
- 发起针对某一特定批次橡胶混炼的审核请求，检查回答中是否包含关联的原始文档引用标识或链接。
- 查看每条引用的详情内容，确认是否包含配方单的投料比例、混炼曲线的温度曲线等完整字段。
- 验证单次召回结果的数量是否符合设定的前6条，且排序按匹配度从高到低排列。
- 测试超长篇度的查询，确认`quoteMaxToken`限制生效，单条引用内容未超出设定的1500 token长度。
