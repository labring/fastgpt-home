# 橡胶混炼与制品硫化的供应商与过程质量审核：模型接入与配置

本文基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
该品类的日常文档包含配方单、称量记录、混炼曲线、胶料快检、硫化工艺卡、模具记录、成品性能报告。数据来源覆盖配方系统、原材料批次台账、密炼机、门尼粘度仪、流变仪、硫化机及实验室检测设备。数据更新频率为每车原材料批次、每批混炼胶料、每模次硫化制品，单条记录包含配方比例、工艺温度、时长、批次编号、检测数值等字段，单位涵盖摄氏度、分钟、千克、邵氏硬度等。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的高频次、多源异构数据特征，对模型接入与配置带来多重约束。多批次的实时更新数据要求上下文长度需匹配数据量，避免截断关键审核依据；图像类文档（如混炼曲线、硫化工艺卡）要求模型支持视觉识别能力；内网部署的模型与FastGPT服务器需在同一网络环境，无法依赖外网公开API；多字段的精准校验需求要求模型输出稳定，不宜过度随机。此外，单任务的响应时长需匹配生产节奏，避免延迟影响现场审核。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 覆盖多批次混炼、硫化的历史记录与当前审核数据，避免上下文截断 |
| `maxTokens` | `2000–3000 token` | 适配单批次审核的参数校验、偏差判断需求，控制响应时长匹配生产节奏 |
| `temperature` | `0.1–0.3` | 保障质量审核的判断稳定性，降低随机输出对审核结果的影响 |
| `vision` | 开启 | 支持识别混炼曲线、硫化工艺卡等图像类文档中的参数与记录 |
| `AIPROXY_API_ENDPOINT` | 内网部署的DeepSeek API地址 | 适配FastGPT服务器与模型均在内网的网络环境，无法访问外网资源 |
| `toolChoice` | `auto` | 自动调用工具提取多源数据中的质量参数，无需手动指定调用逻辑 |

## 容易做错的三处
-  配置`AIPROXY_API_ENDPOINT`为外网公开地址，调用时返回连接超时错误。原因是FastGPT服务器处于内网环境，无法访问外网资源。
-  设置`maxTokens`为`5000 token`，审核任务频繁出现响应截断。原因是该品类单批次审核需覆盖的字段与历史数据较多，超出预设的token上限。
-  未开启`vision`参数，无法识别混炼曲线图像中的温度波动记录，导致审核结果遗漏工艺偏差。

## 怎么确认配好了
-  上传一份混炼曲线图像文档，触发审核任务，查看是否能准确提取图像中的温度、时间等核心参数。
-  提交包含多批次混炼与硫化数据的审核请求，查看响应内容未出现上下文截断提示。
-  在内网环境下直接调用配置的API地址，返回正常的模型响应，验证鉴权令牌有效。
-  调整`temperature`参数为`0.5`，对比两次同类型审核的结果差异，确认参数配置生效。
