# 橡胶混炼与制品硫化的供应商与过程质量审核：部署与升级

## 这个品类的数据长什么样
这个品类的核心数据来自配方系统、原材料批次记录、密炼机、门尼和流变仪、硫化机、实验室检测设备。日常文档包含配方单、称量记录、混炼曲线、胶料快检报告、硫化工艺卡、模具使用记录、成品性能报告。数据更新频率为每车胶、每批原料、每模次生产操作，单条数据包含投料量（千克）、混炼温度（摄氏度）、硫化时间（秒）、成品拉伸强度（兆帕）等字段，格式覆盖结构化表格、时序曲线、文本记录三类。

## 这些特征在「部署与升级」这一环带来什么约束
高频次的单条数据更新要求数据库连接池配置适配高并发写入，避免连接耗尽导致的服务中断。多源异构的数据来源需要统一的存储与权限管理，确保不同设备上传的混炼曲线、实验室报告可以被统一检索。每模次的更新节奏要求缓存配置适配高频读取的工艺参数，降低底层数据库的访问压力。同时，配方单、性能报告等敏感文档需要配置访问权限控制，防止核心工艺数据泄露。部署时还需考虑arm架构设备的兼容性，适配软路由等边缘部署场景的资源限制。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150` | 适配每车胶、每模次的高频数据写入，避免数据库连接池耗尽 |
| `MONGODB_URI` | `mongodb://[用户名]:[密码]@[主机]:27017/fastgpt?authSource=admin` | 存储配方单、性能报告等结构化文档，适配多源数据的持久化存储 |
| `REDIS_URL` | `redis://:[密码]@[主机]:6379/0` | 缓存高频读取的混炼曲线、硫化工艺卡，降低数据库的重复查询压力 |
| `STORAGE_S3_ENDPOINT` | `按本地对象存储地址填写` | 统一存储密炼机上传的混炼曲线、模具记录等二进制文件，简化文件管理 |
| `FILE_TOKEN_KEY` | `随机生成的32位字符串` | 保护上传的配方单、性能报告等敏感文档的访问权限，防止未授权访问 |
| `FE_DOMAIN` | `http://[本机IP]:3000`（本地部署）或绑定的正式域名 | 配置前端访问地址，确保前端页面可以正常加载与资源调用 |

## 容易做错的三处
- 现象：部署后前端页面无法打开，端口检测显示通但页面加载失败。原因：`FE_DOMAIN`配置未绑定正确的本机IP或端口，导致前端资源路径错误，无法加载页面资源。
- 现象：外接vllm模型时，oneapi提示connection refused。原因：`MONGODB_URI`或`REDIS_URL`配置错误，导致FastGPT服务无法正常初始化，或端口映射未正确配置，阻断了模型服务的连接请求。
- 现象：docker部署时下载的yml文件仅包含一行404内容。原因：部署文件下载链接失效或网络中断，导致文件未完整下载，需重新获取官方部署文件。

## 怎么确认配好了
- 执行`docker ps`命令，确认FastGPT相关的所有容器均处于运行状态。
- 访问`FE_DOMAIN`配置的地址，确认前端页面可以正常加载，无资源加载失败提示。
- 连接`MONGODB_URI`配置的数据库，验证是否可以写入测试用的配方单数据，确认存储正常。
- 调用FastGPT内置的模型测试接口，确认外接的向量模型、语言模型api可以正常连通并返回结果。
