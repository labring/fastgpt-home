# 汽车零部件批量制造的供应商与过程质量审核：向量模型与索引
本文适用于FastGPT v4.17.0版本。

## 这个品类的数据长什么样
本品类的典型主体为汽车制动、转向、底盘、内外饰及动力系统供应商。日常产生的文档包含控制计划、过程流程图、作业指导书、首件与巡检记录、SPC报表、PPAP资料及8D报告。数据来源涵盖客户图纸与特殊特性清单、ERP/MES系统、量检具数据、设备过程参数及供应商质保书。数据更新频率为每批生产、每班产出同步更新，部分设备参数与巡检记录持续采集。字段包含特殊特性编号、工序参数阈值、不合格品率、根因分析结论等，部分文档附带单位标注，如扭矩值、压力参数。

## 这些特征在「向量模型与索引」这一环带来什么约束
多源异构的数据格式差异显著，既有结构化的SPC报表、巡检记录，也有非标准化的工艺文档与报告，要求索引支持混合格式的解析与向量化。高频的批量更新数据会带来持续的索引刷新压力，需适配增量索引模式，以匹配生产节奏。汽车零部件的特殊特性关联强，向量检索需精准匹配工艺参数与客户要求，避免泛化匹配无关内容。部分文档附带合规性标注，索引需保留字段级关联，避免检索时丢失关键合规信息。持续采集的实时设备数据要求索引的更新延迟控制在合理范围，适配生产现场的快速响应需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配本品类单份工艺文档的典型段落长度，避免切割关键工艺参数与特殊特性关联内容 |
| 重叠长度 | 100–150 字符 | 保留跨块的工艺参数上下文，防止检索时丢失连续的工序要求 |
| 相似度阈值 | 按实测标定 | 需匹配本品类对特殊特性匹配的精准度要求，避免误匹配非关联的工艺文档 |
| 单次搜索上限 | 前 8 条 | 平衡检索效率与召回覆盖率，适配批量审核时的多文档关联需求 |
| `maxToken` | 4096 token | 适配本品类批量审核时的多文档合并上下文长度，满足8D报告、PPAP资料的长文本解析 |
| `defaultToken` | 按当前向量模型支持上限配置 | 适配不同向量模型的输入长度限制，避免文本截断导致关键信息丢失 |

## 容易做错的三处
- 现象：Excel格式的SPC报表上传后，向量化完成但索引显示为空。原因：未配置结构化数据解析规则，导致报表中的数值字段与文本字段未正确关联，无法生成有效向量。
- 现象：知识库上传后状态持续显示「索引中」超过600秒。原因：未开启增量索引模式，全量索引处理高频更新的批量生产数据时耗时过长，超出系统默认超时限制。
- 现象：检索结果中出现不相关的PPAP资料，相似度匹配不符合预期。原因：相似度阈值设置过低，导致低关联度的文档被召回，无法精准匹配当前审核的工序参数。

## 怎么确认配好了
- 上传一份典型的作业指导书文档，检查向量生成日志，确认`maxToken`未触发截断提示。
- 提交一份包含特殊特性的SPC报表，核对检索结果是否包含关联的控制计划文档，验证字段关联是否生效。
- 模拟批量上传多份8D报告，查看索引进度，确认增量索引模式下的更新延迟符合生产节奏要求。
- 调整相似度阈值后进行检索测试，验证召回结果的关联度是否符合当前审核的精度要求。
