# 热处理的供应商与过程质量审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
本品类数据来自材料牌号档案、客户技术要求文档、温控仪表、炉温均匀性检测设备、硬度计、金相分析仪及车间MES系统。数据按每炉次、每批实时更新，日常产出热处理工艺卡、装炉布局图、炉温曲线记录、硬度与金相检测报告、设备点检表、异常处置单等文档。数据字段包含炉温设定值与实测值（单位℃）、保温时长（单位小时）、硬度检测值（单位HV）、金相组织评级等，单条数据体量较小但批次间差异明显。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
本品类按炉次、批次更新的数据特征，要求HTTP接口需支持按炉号、批次号作为精准查询参数，避免全量拉取导致的数据冗余。多字段带特定单位的要求，使得接口请求需携带材料牌号、检测项类型等限定参数，返回结果需严格匹配预设的单位格式。多样的日常文档类型，要求接口兼容结构化时序数据（如炉温曲线）与非结构化文档的传输格式。异常处置单的实时同步需求，要求接口具备低延迟回调能力，避免质量审核滞后。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | 携带热处理车间MES系统的Bearer令牌 | 用于接口身份校验，避免未授权访问 |
| `variables` | 绑定炉号、批次号作为查询变量 | 精准匹配单炉次的检测数据 |
| `responseData` | 提取炉温、硬度值、金相评级字段 | 仅返回质量审核所需的核心数据 |
| 超时时间 | 600秒 | 适配炉温曲线等时序数据的完整传输 |
| 重试次数 | 3次 | 应对车间网络波动导致的接口调用失败 |

## 容易做错的三处
- 现象为接口调用返回401 Unauthorized状态码，界面显示无效的令牌。原因是未正确绑定热处理车间MES系统的Bearer令牌，或令牌已过期未更新。
- 现象为接口返回的质量数据字段缺失单位信息，如硬度值未标注HV。原因是未在`responseData`配置中指定字段的单位映射规则，导致解析后数据格式不符合审核要求。
- 现象为接口拉取的数据包含多炉次的冗余信息，无法精准匹配当前审核批次。原因是未在`variables`中绑定炉号、批次号作为查询参数，仅使用时间范围拉取数据。

## 怎么确认配好了
- 调用配置好的HTTP接口，传入测试用的炉号与批次号，核对返回数据是否包含预设的核心字段。
- 检查接口返回的响应头，确认`Authorization`校验通过，无401类报错。
- 查看接口调用日志，确认仅返回当前批次的热处理数据，无冗余多炉次信息。
- 模拟异常场景，如令牌过期，确认接口返回对应错误提示，符合预期。
