# 焊接结构件制造的供应商与过程质量审核：引用来源与溯源

## 这个品类的数据长什么样
焊接结构件制造的业务数据来源包括设计图纸、材料质保书、焊接设备参数、焊材库台账、无损检测系统、人员资质台账。数据更新节奏为每条焊缝、每批焊材或每班频次。日常产生的文档包括焊接工艺评定、焊接工艺规程、焊材领用记录、焊工资格记录、焊缝检验报告、返修单，字段涵盖焊缝编号、焊材批号、焊工资质编号、无损检测结果等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
该品类的数据特征对引用溯源环节带来多重约束。首先，数据按单条焊缝、每批焊材或每班更新，需精准匹配对应生产批次的关联文档内容，避免跨批次引用无关内容。其次，日常文档涵盖工艺、资质、检测三类，需按文档类型过滤召回，确保仅调用与当前审核项相关的焊接工艺评定、焊工资格记录等。此外，质量审核依赖焊工资质、焊材批号等刚性字段，溯源环节需准确提取原始文档的对应字段，为后续核验提供明确依据。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 单次搜索上限 | 前6–10条 | 单批次焊接结构件的关联文档通常不超过8类，召回6到10条可覆盖全部核心审核内容 |
| `quoteMaxToken` | 1000–1600 token | 单条焊缝的审核关联内容总长度通常在800 token以内，预留合理冗余避免截断关键信息 |
| `responseData` | 开启 | 需返回原始文档的焊缝编号、焊材批号、焊工资质编号等字段，用于精准溯源 |
| `detail` | 完整 | 需保留原始文档的完整内容片段，便于核对无损检测结果、焊接工艺参数 |
| 重排 | 开启 | 按相关性排序召回结果，确保最相关的焊接工艺评定、焊缝检验报告优先展示 |
| 最大上下文 | 按实测标定 | 结合单次搜索上限与`quoteMaxToken`取值，适配当前使用的模型上下文限制 |

## 容易做错的三处
- 现象：配置`quoteMaxToken`为2000后，生成的回答内容超出3000 token。原因：焊接结构件的关联文档单篇长度较长，且召回的文档数量过多，累加后的总token超出模型上下文限制，导致回答被截断或触发token超限报错。
- 现象：引用知识库时的提示词仍为中文，无法生成符合要求的英文审核报告。原因：未将系统提示词中的中文指令替换为适配场景的英文表述，未针对焊接专业术语调整提示词格式。
- 现象：生成的审核回答未引用知识库中排名第一的焊缝检验报告。原因：未开启重排配置，或单次搜索上限设置过低，导致核心文档未被纳入召回范围，或相似度阈值设置过严，过滤掉了高相关内容。

## 怎么确认配好了
- 查看生成回答的引用来源模块，确认包含焊缝编号、焊材批号等对应字段，且字段与当前审核的生产批次一致。
- 检查回答的token消耗情况，确认未超出当前模型的上下文限制，且`quoteMaxToken`的取值适配当前内容长度。
- 验证召回的文档类型，确认仅包含与当前审核项相关的焊接工艺评定、焊工资格记录等目标文档。
- 对比召回结果的排序顺序，确认最相关的审核文档优先展示，符合业务优先级需求。
