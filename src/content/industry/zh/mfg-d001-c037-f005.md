# 生产计划与车间排程的供应商与过程质量审核：工具调用与插件

## 这个品类的数据长什么样
该品类的典型主体为制造企业PMC、计划、车间调度和物控部门，日常处理的文档包含销售订单、主生产计划、物料需求计划、周日排产表、工单、缺料清单、交期变更单。数据来源覆盖ERP订单与库存、BOM和工艺路线、设备产能、人员班次、在制品和供应商到货，更新频率分为每日、每周、订单或异常发生时三类，核心字段包含订单号、工序编码、设备ID、产能阈值、物料编码与交期要求。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于该品类的数据来源分散且更新节奏随订单、异常实时变动，工具调用需要适配多数据源的实时拉取逻辑，避免因数据滞后导致排程偏差。同时，核心文档包含多维度的约束条件，工具调用的参数需精准匹配工单、产能、物料等专属字段，无法泛化调用通用数据。此外，排程调整直接影响交期与在制品状态，插件调用需配套异常处理机制，应对数据拉取失败或排程计算异常的场景。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ------ | -------- | ------------ |
| 工作流/API 工具选择配置 | `auto` | 适配排程场景下的自动工具匹配需求，无需手动指定工具类型 |
| 工具调用超时时间 | 600 秒 | 排程数据处理涉及多维度资源约束计算，需预留足够的执行时长 |
| 单次调用数据上限 | 前 20 条工单数据 | 避免单次拉取过多数据导致系统过载，同时覆盖单次排程的核心业务需求 |
| 异常重试次数 | 3 次 | 应对临时网络波动或数据源短暂不可用的场景，降低调用失败概率 |
| 工作流/API 函数调用配置 | 强制绑定排程相关工具 | 确保调用仅针对生产计划与车间排程的专属工具，避免触发无关功能模块 |

## 容易做错的三处
- 调用工具返回401状态码，原因是未正确配置工具调用的身份验证参数，导致身份校验失败。
- 插件调用后未返回有效排程结果，原因是未指定匹配工单、物料需求计划的字段过滤规则，导致工具拉取到无关的非生产类数据。
- 工具调用触发频率过高，原因是未设置调用频率限制，匹配了频繁更新的排程数据触发逻辑，引发系统请求拦截。

## 怎么确认配好了
- 模拟提交一条新的销售订单，查看系统是否自动触发排程相关的工具调用。
- 检查工具调用日志，确认返回结果包含工单、物料需求计划、设备产能等该品类专属数据字段。
- 模拟触发一次缺料清单更新的异常场景，查看插件是否正确执行排程重算逻辑。
- 发起一次测试API调用，确认返回结果无身份验证类错误，符合FastGPT v4.17.0的接口规范。
