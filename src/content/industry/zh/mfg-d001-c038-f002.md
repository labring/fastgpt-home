# 生物制品与无菌生产的供应商与过程质量审核：向量模型与索引

本文基于FastGPT v4.17.0版本编写，以下配置项均适配该版本的界面逻辑。

## 这个品类的数据长什么样
该品类数据来自细胞库与种子批、过程分析系统、洁净区监测记录、MES、LIMS及设备完整性测试结果。日常文档包含细胞库或种子批记录、培养纯化记录、无菌灌装记录、环境监测数据、培养基模拟灌装报告、无菌检验结果及批放行资料。数据更新节奏分为每批生产后、实时监测触发、按固定监测计划更新，文档字段包含批次编号、操作参数、环境温湿度、检验结果、设备运行状态等，部分记录需关联无菌边界、人员物料路径信息。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据分散且更新节奏差异显著，需支持多源异构数据的增量索引与实时同步。文档兼具结构化参数记录与半结构化检验报告，需适配不同字段的向量提取规则，避免无关内容干扰匹配精度。单批次生产对应独立数据集，需按批次维度隔离索引，确保审核时仅调用对应批次的关联数据。无菌过程记录对数据一致性要求极高，索引需保证查询结果的时效性，避免因数据滞后引发质量判断偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配该品类文档中结构化参数与半结构化报告的混合长度，避免单块内容割裂关键逻辑 |
| 重叠长度 | 100–150 字符 | 保留跨块的关键参数关联，确保批次编号、无菌边界描述等信息不会被分块截断 |
| 相似度阈值 | 0.75–0.85 | 匹配该品类对数据一致性的严格要求，过滤低相关性的历史记录，避免误匹配 |
| 单次搜索上限 | 前 10 条 | 控制审核时的返回数据量，确保审核人员可快速定位关键记录，同时覆盖多来源的关联数据 |
| `maxToken` | 4000 token | 适配批放行资料等长文档的向量索引，避免因token超限导致索引失败 |
| `defaultToken` | 2000 token | 用于常规过程记录的索引，平衡内容完整性与检索效率 |

## 容易做错的三处
- 现象：索引生成时出现token超限报错，日志显示内容超出上限。原因：未针对长文档调整`maxToken`配置，沿用默认值导致长记录无法完成索引。
- 现象：检索结果包含跨批次的无关数据，或无法找到指定批次的记录。原因：未按批次维度隔离索引，导致不同批次的数据集混合，匹配逻辑混乱。
- 现象：尝试引入关系型关联检索或接入非通用向量模型时，出现检索结果异常或调用报错。原因：未适配品类的异构数据结构与模型调用规则，沿用扁平化实体索引或通用模型逻辑，无法满足定制化需求。

## 怎么确认配好了
- 上传单批次的典型文档，检查索引生成状态是否正常，无报错提示。
- 输入与批次编号、无菌边界相关的检索词，核对返回结果是否仅包含对应批次的关联记录，无跨批次的无关数据。
- 调整相似度阈值的取值范围，验证检索结果的数量是否随阈值变化符合预期。
- 测试多源数据同步，确认实时更新的洁净区监测记录可在索引中及时被检索到。
