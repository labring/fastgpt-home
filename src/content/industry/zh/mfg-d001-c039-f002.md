# 电机与发电机制造的供应商与过程质量审核：向量模型与索引

## 这个品类的数据长什么样
本品类数据来自电机厂、电力装备企业的绕线、绝缘、总装与试验部门，涵盖绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试报告、型式与出厂试验报告等文档。数据来源于电磁设计数据、铜线和绝缘材料批次记录、绕线设备、平衡机、电气试验台数据及ERP/MES系统，更新频率为每台产品、每批次物料或每次型式变更时生成新数据。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类数据包含结构化的批次编号、电磁参数、试验数值，以及半结构化的工艺步骤记录，更新频率高且单条数据体量小但整体数据量增长快。多源数据的字段单位差异较大，如匝数、温升、耐压值分别对应不同计量标准，需要向量模型适配混合字段的语义与数值关联。增量更新需求频繁，需支持按批次或设备ID快速同步新数据。同时，核心审核场景需精准匹配绕组工艺、试验结果与异常分析的关联，对索引的召回精度有较高要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配绕组工艺卡、试验报告的单页内容长度，避免块内语义断裂 |
| 重叠长度 | 100–150 字符 | 保留跨块的工艺步骤、试验数据关联，防止关键信息被拆分 |
| 相似度阈值 | 0.75–0.85 | 匹配电机制造中精密的工艺参数与异常结果关联，过滤低相关检索结果 |
| `maxToken` | 8192 token | 适配型式试验报告的长文本内容，确保完整加载试验数据与工艺说明 |
| 单次搜索上限 | 前 8 条 | 覆盖核心审核场景的关联数据量，避免冗余信息干扰审核判断 |
| `defaultToken` | 按实测标定 | 适配本地或私有部署的向量模型资源占用，平衡检索速度与召回效果 |

## 容易做错的三处
- 现象：知识库上传后显示未索引，向量数据库无对应数据条目。原因：未按每批次物料或设备ID设置增量同步触发规则，导致新生成的试验报告未被自动纳入索引。
- 现象：界面提示m3e无可用频道，无法生成向量嵌入。原因：未在FastGPT v4.17.0的私有模型配置页添加m3e的部署地址与密钥，或频道配额已耗尽。
- 现象：重复发起相同的工艺参数检索请求时，系统响应延迟较高。原因：未配置缓存优化机制，每次请求均直接访问向量数据库，未复用已检索到的结果。

## 怎么确认配好了
- 上传一份最新的绕组工艺卡，查看知识库索引状态页，确认条目已生成且关联对应批次编号。
- 输入“绕组匝数核对”的检索词，检查返回结果中是否包含动平衡报告、耐压试验数据的关联条目，验证召回逻辑匹配审核场景。
- 查看向量模型的运行指标，确认`defaultToken`的配置适配当前部署的资源限制。
- 发起两次相同的检索请求，对比响应时间，验证缓存机制是否按配置生效。
