# 电机与发电机制造的供应商与过程质量审核：工具调用与插件

## 这个品类的数据长什么样
电机与发电机制造的供应商与过程质量审核核心数据，来自电磁设计数据库、铜线与绝缘材料批次台账、绕线设备、平衡机、电气试验台，以及ERP与MES系统。日常产出文档包括绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试报告、型式与出厂试验报告。数据更新频率为每台电机或每批物料，每次型式变更时同步更新。核心需核对字段包括绕组匝数、绝缘体系参数、动平衡值、温升与耐压测试结果，同时需兼顾电磁与旋转机械平衡的双重约束。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据来源覆盖设备、系统与纸质文档，要求工具调用需对接多类数据源，同时需支持批量参数校验。数据更新频率高且单次变更影响范围广，工具调用需适配实时或近实时的数据源拉取需求。核心文档字段多且存在专业约束，工具调用需支持多参数的分步收集与严格格式匹配。此外，高压与温升试验的特殊数据要求工具调用需保留上下文关联，避免因参数拆分导致的逻辑断裂。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | auto | 适配电机制造场景下多参数、多步骤的工具调用需求，自动触发参数补充与数据拉取 |
| 单次工具调用超时 | 600 秒 | 覆盖耐压试验、动平衡分析等耗时较长的电机专属检测环节 |
| 工作流/API 函数调用配置 | strict | 严格匹配绕组工艺卡、试验报告的固定字段格式，避免参数错位 |
| 多参数补充触发 | 工作流节点拦截 | 分步收集铜线批次、绕线设备编号等电机制造专属必填字段 |
| 工具结果缓存时长 | 3600 秒 | 匹配批次数据每批更新的频率，避免重复拉取历史试验数据 |
| 上下文保留条数 | 前 8 条 | 平衡上下文完整性与调用速度，避免过载影响响应效率 |

## 容易做错的三处
- 现象：调用MCP工具时模型上下文被打断，输出与当前电机审核无关的内容，历史绕组参数未被保留。原因：未将`toolChoice`配置为auto，强制触发工具调用时直接中断上下文流转，未保留绕组工艺卡的历史参数关联。
- 现象：多参数MCP调用时必填字段为空，工具调用失败。原因：未通过工作流节点设置参数补充环节，未收集铜线批次、绝缘材料型号等电机制造场景的专属必填参数。
- 现象：工具调用后模型回答延迟超过阈值，响应缓慢。原因：未限制单次工具调用的结果返回条数，或缓存时长设置过长，导致大量历史试验数据被重复加载。

## 怎么确认配好了
- 导入一份完整的绕组工艺卡与动平衡报告，触发工具调用，检查是否自动提取匝数、绝缘厚度等核心字段。
- 模拟缺少铜线批次参数的审核请求，检查是否触发参数补充环节或工作流拦截节点。
- 连续发起3次同批次电机的试验数据查询，检查响应时间是否保持稳定。
- 查看FastGPT v4.17.0的工具调用日志，确认`functionCall`配置为strict模式，返回结果匹配试验报告的字段格式。
