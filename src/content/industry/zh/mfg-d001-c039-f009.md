# 电机与发电机制造的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
本品类数据来自电磁设计文档、铜线与绝缘材料批次台账、绕线设备运行日志、平衡机采集数据、电气试验台测试结果及ERP/MES系统记录。日常生成绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试报告、型式与出厂试验报告等文档，字段包含绕组匝数、浸漆工艺参数、不平衡量、耐压值、温升数据等。数据更新频率为每台产品或每批次物料，每次产品型式变更时同步更新。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类数据的批次关联特性要求模型接入时需配置批次维度的上下文隔离，避免跨批次物料的审核结果混淆；工程类文档多为带单位的数值字段，需在模型配置中指定数值解析的格式规则；高频更新的特性要求配置`maxContext`时限制单批次数据的上下文长度，防止上下文溢出；不同文档类型的字段差异，需在接入环节明确字段映射的对应关系，确保模型能准确识别审核所需的核心参数。

## 配置怎么定
本配置基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单批次电机绕组工艺、试验报告的总文本长度，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 满足审核报告的详细输出需求，覆盖绕组匝数核对、绝缘参数校验等全流程分析 |
| `quoteMaxToken` | 1500–2000 token | 限定引用的文档片段长度，确保仅提取与当前审核项相关的核心数据 |
| `temperature` | 0.1–0.3 | 保持审核逻辑的一致性，避免工程参数判断出现随机偏差 |
| `AIPROXY_API_ENDPOINT` | 按平台实际部署地址填写 | 适配模型接入的代理配置，确保请求路由正确 |
| `AIPROXY_API_TOKEN` | 按平台分配的有效令牌填写 | 完成身份验证，保障接口调用权限 |

## 容易做错的三处
- 现象：模型测试时报错提示接口认证失败或“无可用模型”。原因：未在配置中正确填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或代理地址与令牌不匹配。
- 现象：知识库查询结果出现跨批次数据关联，比如将A批次的绕组数据用于B批次的审核。原因：未配置批次维度的上下文隔离规则，导致上下文缓存了多批次的文档数据。
- 现象：审核结果出现数值判断偏差，比如绕组匝数核对错误或绝缘参数判定异常。原因：`temperature`取值过高，导致模型对工程数值的判断出现随机波动。

## 怎么确认配好了
- 调用模型测试接口，输入单批次电机的绕组工艺卡片段，检查接口返回无认证错误或参数解析错误。
- 上传单批次的试验报告文档，确认知识库能正确解析并关联对应批次的元数据，无跨批次数据混入。
- 调整`temperature`参数后，多次输入同一审核场景，检查结果的一致性符合预期。
- 查看上下文日志，确认仅加载当前审核批次的相关文档片段，无无关数据被纳入上下文。
