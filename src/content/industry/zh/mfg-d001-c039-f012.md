# 电机与发电机制造的供应商与过程质量审核：部署与升级

## 这个品类的数据长什么样
本品类数据来自电磁设计数据库、铜线与绝缘材料批次台账、绕线设备、动平衡机、电气试验台及ERP/MES系统。日常文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试记录、型式与出厂试验报告，字段涵盖绕组匝数、浸漆烘干参数、振动幅值、温升数值、效率指标等，更新频率为每台成品、每批次物料或每次产品型式变更时触发。

## 这些特征在「部署与升级」这一环带来什么约束
本品类的数据来源分散覆盖设计、物料、生产设备与管理系统，部署时需配置跨系统的数据同步链路。单台或单批次产品的更新频率高，需启用增量数据抓取机制以避免全量同步的性能损耗。专业文档字段多且带专属单位，需预设对应的数据解析规则以保障字段提取准确性。高压试验与温升数据的精度要求较高，需适配大容量、高稳定性的存储配置，避免数据写入丢失或延迟。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 100–200 并发连接 | 适配多生产设备数据同步的并发需求，避免数据库连接池溢出 |
| `MONGODB_URI` | 本地部署使用`mongodb://localhost:27017/motor_audit`；云部署使用对应云服务商MongoDB实例连接串 | 存储绕组工艺卡、耐压试验报告等非结构化与半结构化数据，适配高频小数据写入 |
| `REDIS_URL` | `redis://:自定义高强度密码@部署地址:6379/0` | 缓存物料批次信息与工艺参数，降低重复查询数据库的延迟 |
| `STORAGE_S3_ENDPOINT` | 本地部署使用`http://localhost:9000`；云部署使用对应云服务商对象存储端点 | 存储大型型式试验报告与绝缘处理记录，保障大文件上传与下载稳定性 |
| `FE_DOMAIN` | 部署服务器绑定的公网域名或静态IP | 配置webhook回调的合法域名，确保跨域请求正常发起 |
| `ROOT_KEY` | 自定义高强度随机字符串 | 配置管理员权限访问密钥，保障部署环境的操作安全 |

## 容易做错的三处
- 现象：配置多表格格式的webhook时触发权限限制提示。原因：未根据批量数据同步的需求完成对应版本升级，无法处理多表格并行提交的请求。
- 现象：本地部署reranker模型后，在模型渠道配置中返回连接超时报错。原因：未正确填写自定义请求地址，或未开放容器端口映射导致外部无法访问reranker服务。
- 现象：阿里云部署的知识库响应延迟较高。原因：未配置增量同步机制，每次查询都触发全量数据检索，或数据库连接数设置过低导致并发请求阻塞。

## 怎么确认配好了
- 执行数据库连接测试，验证`MONGODB_URI`与`REDIS_URL`的配置可正常建立连接，连接数不超过预设的`DB_MAX_LINK`阈值。
- 上传一份绕组工艺卡与耐压试验报告，验证文件可正常存储至配置的`STORAGE_S3_ENDPOINT`对应存储路径。
- 发起一次多表格格式的webhook请求，验证数据可正常同步至系统，回调请求可通过`FE_DOMAIN`的域名校验。
- 启动本地部署的reranker模型，验证自定义请求地址可正常返回重排结果，无连接异常报错。
