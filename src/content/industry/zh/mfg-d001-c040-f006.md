# 电池PACK与储能系统集成的供应商与过程质量审核：引用来源与溯源

## 这个品类的数据长什么样
本品类数据来源于电芯分容系统、车间MES系统、焊接与扭矩采集设备、BMS软件版本库、EOL试验台。日常文档包含电芯配组规则、BOM清单、焊接扭矩记录、BMS刷写日志、绝缘耐压报告、EOL测试报告、系统配置清单。数据更新频率为单台PACK或储能柜产出即更新，每次BMS软件版本变更同步更新。数据字段包含电芯分容参数、焊接扭矩值、绝缘测试电压、BMS版本号、系统配置参数，按实际采集内容结构化存储。

## 这些特征在「引用来源与溯源」这一环带来什么约束
本品类的数据特征对引用溯源环节带来多项约束。首先，数据按单台PACK或储能柜产出、单次软件变更更新，需绑定唯一序列号或批次号进行引用，避免跨批次混淆。其次，数据来源覆盖工业设备、MES系统、测试台等多类系统，需支持跨数据源的关联溯源，例如将焊接扭矩记录与对应BOM的紧固件信息绑定。再者，日常文档包含多类型测试报告，引用时需匹配测试项与对应产出批次，确保溯源信息准确。另外，BMS版本变更带来的数据更新，需在引用时同步关联版本标识，避免使用过期配置数据。

## 配置怎么定
本页配置基于FastGPT v4.17.0版本，具体配置项如下：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 相似度阈值 | 0.75–0.85 | 本品类数据包含精密扭矩、绝缘参数等强相关字段，阈值过低会引入无关数据，过高则无法召回有效记录 |
| 单次搜索上限 | 前8条 | 单台PACK的关联数据量有限，过多召回会超出上下文窗口，影响检索效率 |
| `quoteMaxToken` | 1200–1500 token | 本品类文档包含多组测试数据与配置参数，需足够token存储完整溯源信息 |
| `responseData` | 仅返回绑定批次的关联数据 | 需确保引用数据与当前审核批次严格绑定，避免跨批次引用错误 |
| `detail` | 返回完整来源路径与时间戳 | 过程质量审核需追溯数据采集时间、来源设备，确保合规性 |
| 引用模板 | 按「批次号+来源设备+采集时间」格式拼接 | 本品类需按批次溯源，该格式可快速定位对应生产记录 |

## 容易做错的三处
- 现象：引用结果中出现非当前批次的生产记录。原因：未配置批次号绑定的检索规则，导致召回跨批次的无关数据。
- 现象：表单节点引用变量无法获取对应批次数据。原因：未将批次号作为检索的前置过滤条件，变量绑定的检索范围未覆盖当前审核单。
- 现象：引用的BMS配置参数与实际批次不符。原因：未关联BMS软件版本字段进行检索，使用了过期的版本数据，导致审核结果错误。

## 怎么确认配好了
- 输入单台PACK的批次号，检索关联的焊接扭矩记录，核对返回结果是否仅包含该批次的数据。
- 查看引用内容的来源路径与时间戳，确认是否包含对应设备的采集信息与测试时间。
- 触发一次EOL测试的模拟审核，检查返回的引用数据是否匹配当前使用的BMS软件版本。
- 调整相似度阈值的测试值，确认检索结果的相关性符合业务要求，无过多无关数据。
