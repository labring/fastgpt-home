# 电池PACK与储能系统集成的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
该品类的核心数据来自电芯分容数据、工厂MES系统、焊接设备、扭矩工具、BMS软件版本记录及EOL试验台。日常产出的文档包含电芯配组规则、整机BOM清单、焊接与扭矩操作记录、BMS刷写日志、绝缘耐压报告、EOL测试数据及系统配置清单。数据更新频率为每生产一个电池包或储能柜更新一次，每次BMS软件版本变更也会触发数据更新。数据字段包含电芯分容参数、焊接扭矩值、BMS版本号、绝缘测试电压等，无统一跨厂商格式。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的多源异构数据格式差异大，不同设备导出的日志字段不统一，要求模型接入时需支持灵活的字段映射配置。单次生产的文档体量较小但更新频繁，需限制单轮上下文长度避免冗余。BMS刷写记录、EOL测试数据属于强关联业务数据，需确保模型调用时能准确关联对应批次的生产信息。多模态数据如绝缘耐压报告的扫描件、焊接过程截图片段，要求模型接入配置需支持多模态向量模型的接入。同时，生产数据的实时性要求较高，需合理设置请求超时与重试机制。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 匹配单批次生产数据的总字符量，避免截断核心配组与测试信息 |
| `vision` | 开启 | 支持解析绝缘耐压报告扫描件、焊接过程截图等多模态业务文档 |
| `temperature` | 0.2–0.4 | 确保审核逻辑的一致性，避免生成不符合配组规则的判断结果 |
| `maxTokens` | 2000–3000 token | 限制单次审核结果的输出长度，避免冗余信息干扰审核判断 |
| `AIPROXY_API_ENDPOINT` | 按部署的代理服务实际地址填写 | 适配本地或云端部署的代理服务，确保模型请求正常路由 |
| `AIPROXY_API_TOKEN` | 与代理服务配置的密钥一致 | 完成身份验证，避免请求被拦截或拒绝 |

## 容易做错的三处
- 尝试接入多模态向量模型时返回格式错误，无法解析绝缘耐压报告扫描件。原因是未开启`vision`参数，未配置多模态模型的接入路径。
- 配置代理服务后请求返回404 body not found错误。原因是`AIPROXY_API_ENDPOINT`填写错误，或代理服务未正确映射模型调用路径。
- 审核结果与实际配组规则偏差较大，生成不符合要求的判断。原因是`temperature`参数设置过高，导致模型生成随机化的判断逻辑。

## 怎么确认配好了
- 上传一份绝缘耐压报告扫描件，检查模型是否能正确提取报告中的测试电压、合格判定结果等信息。
- 调用模型审核单批次生产数据，检查返回结果中是否关联了对应批次的BOM清单与配组规则。
- 模拟多次请求，检查是否出现超时或404错误，确认代理服务与模型接口的连通性正常。
- 调整`temperature`参数至0.3左右，审核同一份数据两次，检查结果是否保持一致。
