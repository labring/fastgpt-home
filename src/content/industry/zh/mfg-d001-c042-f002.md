# 石油炼制的供应商与过程质量审核：向量模型与索引

## 这个品类的数据长什么样
该品类的数据来自DCS/APC、LIMS、罐区计量、原油评价、设备管理系统与能源系统。日常文档包含操作规程、生产方案、物料平衡、馏出口质量报告、联锁台账、交接班记录、变更管理文件，字段涉及馏程、密度、ppm浓度、班次编号、装置负荷数值、原油蜡含量等。数据更新节奏覆盖实时、每班与每日，由生产运行、工艺、调度、设备与化验部门日常维护。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据特征对向量模型与索引环节带来多重约束。异构数据源产生的文本格式差异显著，既有结构化化验数据也有数千字符的长文本工艺文档，需适配差异化分块策略；多更新节奏覆盖实时、每班与每日，要求索引支持实时增量、每日全量等多种刷新模式；原料与产品质量数据的特征差异显著，相似度阈值需结合工艺场景调整，避免误判相似内容；多装置耦合的业务逻辑要求向量召回需覆盖关联数据，单次召回上限需适配业务覆盖范围。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配炼油类长文本工艺文档的平均长度，避免单块token数量超出模型限制 |
| 重叠长度 | 100–150 字符 | 保留相邻分块的上下文信息，防止长文本工艺描述被拆分后丢失关联逻辑 |
| 相似度阈值 | 0.72–0.85 | 匹配炼油工艺数据的特征区分度，避免将不同原料性质或产品质量数据误判为相似 |
| 单次搜索上限 | 前 10 条 | 覆盖多装置耦合的业务关联数据，满足供应商审核与过程质量排查的信息需求 |
| `maxToken` | 4096 token | 适配FastGPT v4.17.0的模型输入上限，兼容炼油类长文档的向量计算需求 |
| `defaultToken` | 按实测标定 | 针对不同类型文档的token密度差异调整，优化向量计算的一致性 |

## 容易做错的三处
- 向量计算得分异常，相似内容的分数差异极小，原因是未结合炼油工艺数据的特征调整相似度阈值，沿用通用场景的默认参数。
- 上传PDF格式的炼油操作规程后，向量化耗时远超预期，原因是分块长度设置超出适配炼油长文本的合理区间，导致单块token数量过高，延长计算耗时。
- 导入十万条包含化验数据的CSV文件后，向量后数据量减少数千条，原因是部分数据包含未转义的特殊单位符号（如ppm、℃），导致向量化流程中断未被记录。

## 怎么确认配好了
- 随机抽取3份不同类型的炼油文档（如操作规程、馏出口质量报告、交接班记录），执行向量分块测试，确认分块结果符合预设的长度区间。
- 导入100条包含特殊单位符号的测试数据，检查向量后数据量与源数据一致，无异常丢失。
- 触发一次批量向量化任务，监控任务耗时，确认符合预设的合理范围。
- 输入工艺相关的查询（如“原油蜡含量对馏分收率的影响”），检查返回的相似文档的相似度分值符合预设阈值区间。
