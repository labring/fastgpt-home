# 石油炼制的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源包括DCS/APC控制系统、LIMS实验室信息管理系统、罐区计量系统、原油评价数据库、设备管理系统与能源管理系统。数据更新节奏涵盖实时、每班、每日三类。日常文档包含操作规程、生产方案、物料平衡报表、馏出口质量报告、联锁台账、交接班记录、变更管理文件，各文档对应装置参数、物料组分、质量指标、设备状态等字段，单位涉及温度、压力、馏程、流量等工业常用计量标准。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类多源异构数据的实时、每班、每日更新节奏，要求模型接入需支持增量同步与批量拉取的混合调度逻辑。多样的专业文档与工业字段，要求配置需适配炼油专属术语的向量召回规则，避免语义匹配偏差。多套连续装置的物流耦合特性，要求上下文窗口需覆盖跨装置的关联数据，确保分析逻辑连贯。实时工艺数据的高时效性要求，需限制模型响应的最大等待时长，同时区分不同数据源的调用优先级。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 覆盖跨装置物料平衡、交接班记录等多文档的关联上下文，适配炼油业务的长逻辑分析 |
| `maxTokens` | 4000 token | 匹配馏出口质量报告、原油评价数据的单批次输出长度，避免截断专业分析内容 |
| `temperature` | 0.3–0.6 | 平衡工艺分析的严谨性与灵活性，避免生成不符合炼油操作规程的异常结论 |
| `AIPROXY_API_ENDPOINT` | 部署节点内网API地址 | 适配FastGPT v4.17.0的内部网络隔离部署要求，确保数据传输安全 |
| `toolChoice` | auto | 自动匹配供应商审核、质量异常处置所需的工具调用逻辑，适配多环节业务场景 |
| `quoteMaxToken` | 1500 token | 限制引用文档的长度，确保召回内容聚焦于当前审核的装置与物料范围 |

## 容易做错的三处
- 现象为对话提示无流响应，curl调用模型可正常返回内容。原因是未正确配置`AIPROXY_API_ENDPOINT`的流响应开关，或FastGPT版本未适配大模型的SSE协议。
- 现象为模型响应为空，日志显示字段异常。原因是接入的第三方模型未正确映射炼油业务所需的专业字段，或`maxContext`配置超出模型支持上限。
- 现象为升级版本后模型调用异常。原因是未同步更新模型接入的代理配置，或旧版本的上下文参数与新版本规则不兼容。

## 怎么确认配好了
- 执行curl命令调用配置的模型接口，核对返回内容是否包含炼油工艺相关的专业术语与数据格式。
- 导入一份真实的馏出口质量报告文档，测试向量召回的结果是否匹配文档中的质量指标字段。
- 开启模型对话的流响应开关，观察界面是否逐步返回分析内容，确认SSE协议适配正常。
- 调整`temperature`参数的取值区间，验证不同取值下的分析结果是否符合炼油业务的严谨性要求。
