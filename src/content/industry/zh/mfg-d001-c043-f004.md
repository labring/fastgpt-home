# 精细化工间歇合成的供应商与过程质量审核：工作流编排

## 这个品类的数据长什么样
该品类数据覆盖涂料、树脂、助剂、农化中间体及专用化学品生产主体。日常文档包含批生产指令、投料复核单、反应过程记录、清场记录、检验报告、偏差与变更单。数据来源于配方与工艺库、原料批次、反应釜DCS、称量系统、LIMS、仓储系统，按每批生产或每个关键步骤更新。数据字段包含原料批次号、反应釜温度参数、投料量、清场确认标识等，部分字段涉及配方保密内容，需严格管控访问权限。

## 这些特征在「工作流编排」这一环带来什么约束
多品种按批次切换的生产模式，要求工作流按单批生产任务触发，节点配置需匹配对应批次的配方与工艺参数。多源数据接入需求，要求工作流集成多个工具节点，分别从反应釜DCS、称量系统、LIMS获取实时数据。按每批更新的数据特征，要求工作流节点的变量不使用跨批次缓存数据，确保每批审核的准确性。投料复核、反应终点判断、清场确认等耗时环节，要求工作流配置条件分支，按关键步骤的执行结果触发后续节点。配方保密要求，要求工作流中涉及配方的`variables`仅对授权节点开放访问权限。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 绑定工作流全局token变量至工具入参 | 适配传递全局参数的业务需求，符合FastGPT v4.17.0版本的全局变量使用规范 |
| 工具自动调用触发 | 按节点执行结果自动触发 | 适配多步骤审核的条件判断逻辑，无需手动干预每一步执行 |
| 钉钉webhook | 配置审核结果推送地址与触发条件 | 实现偏差单、检验报告等结果的同步通知，覆盖业务协作需求 |
| 节点超时设置 | 300–600秒 | 覆盖反应过程数据采集、LIMS查询等操作的平均耗时区间，按实测标定 |
| `nodeId` | 绑定至对应批次的工艺节点 | 确保每个步骤的节点参数匹配当前生产批次的工艺要求 |
| 变量访问范围 | 仅授权审核节点可访问 | 保护配方保密数据的安全，避免敏感信息泄露 |

## 容易做错的三处
- 现象：工作流运行时无法获取`variables`中的全局token，工具调用返回参数为空。原因：未将全局变量正确绑定至工具入参配置，未启用全局变量传递开关。
- 现象：工作流无法自动选择调用工具，始终按固定流程执行。原因：未配置节点执行结果的触发规则，未启用工具自动调用模式。
- 现象：钉钉webhook推送无有效内容或推送失败。原因：未配置正确的审核结果触发条件，未将对应节点的输出数据绑定至推送内容。

## 怎么确认配好了
- 运行测试批次的工作流，查看工具调用的入参详情，确认全局token变量已正确传递至对应工具。
- 模拟节点执行结果不符合预设条件，查看工作流是否自动触发对应分支或调用工具，确认自动调用逻辑生效。
- 配置测试钉钉webhook地址，触发审核节点完成后查看推送内容，确认审核结果数据已正确同步。
- 检查`variables`的访问权限配置，确认非授权节点无法查看敏感配方相关的变量内容，确认权限控制生效。
