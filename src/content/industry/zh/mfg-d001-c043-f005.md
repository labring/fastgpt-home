# 精细化工间歇合成的供应商与过程质量审核：工具调用与插件

## 这个品类的数据长什么样
该品类数据来自配方与工艺库、原料批次台账、反应釜DCS系统、称量记录系统、LIMS实验室信息管理系统及仓储系统。数据按每生产批次、每个关键工艺步骤更新，包含批生产指令、投料复核单、反应过程记录、清场记录、成品检验报告、偏差与变更单等文档，字段涵盖原料批次号、反应温度、投料量、清场验证结果等，单位涉及千克、摄氏度、小时等，且因多品种间歇切换，需区分不同批次的配方与清洗记录。

## 这些特征在「工具调用与插件」这一环带来什么约束
多品种、按批次切换的生产模式，要求工具调用需绑定当前生产批次的上下文，仅调用对应批次的原料、反应及清场数据。数据更新频率高且粒度细，工具调用的触发需匹配工艺节点，避免提前或滞后调用导致数据不全。配方保密属性要求工具调用的文档访问权限需按角色限定，仅开放审核环节所需的非涉密字段。交叉污染防控需求，要求工具调用需自动关联前一批次的清场验证结果，完成合规校验。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `"auto"` | 自动匹配当前审核环节所需的工具，适配多步骤的审核流程 |
| 工具触发节点 | 按投料完成、反应温度稳定900秒、清场验证完成三个节点触发 | 匹配该品类每批次的关键工艺步骤，确保调用数据完整 |
| 上下文窗口限制 | 仅包含当前批次的12000字符以内的文档数据 | 避免跨批次数据干扰，控制上下文长度符合系统承载要求 |
| 工具调用超时时间 | 600秒 | 适配该品类反应步骤的周期，预留足够的工具调用与数据获取时间 |
| 文档访问权限范围 | 仅开放当前批次的投料、检验、清场字段 | 满足配方保密需求，限制非必要数据的访问范围 |

## 容易做错的三处
- 现象：工具调用后返回响应为空，日志显示无匹配数据。原因：未限定上下文仅包含当前批次的文档，调用了跨批次的历史数据，导致工具无法识别当前审核的参数。
- 现象：工作流中无法读取自定义的环境变量，导致工具调用失败。原因：未在系统配置中开启工作流的环境变量调用权限，或未正确使用变量引用格式。
- 现象：调用特定模型时应用测试正常，但通过API调用返回错误。原因：未在API请求中正确传递当前批次的上下文参数，或未配置模型的API密钥环境变量。

## 怎么确认配好了
- 触发当前批次的投料复核节点，检查工具是否自动调用对应的数据查询工具，返回当前批次的原料批次信息。
- 查看系统日志，确认工具调用的上下文仅包含当前批次的文档，未包含其他批次的数据。
- 调用API测试接口，传递当前批次的参数，检查是否能正常返回工具调用结果，无字段缺失或超时错误。
- 在工作流中添加打印环境变量的节点，运行后确认能正确读取自定义配置的参数。
