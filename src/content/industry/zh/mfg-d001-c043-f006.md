# 精细化工间歇合成的供应商与过程质量审核：引用来源与溯源

## 这个品类的数据长什么样
本品类覆盖涂料、树脂、助剂、农化中间体及专用化学品生产企业，日常文档包含批生产指令、投料复核单、反应过程记录、清场记录、检验报告、偏差与变更单。数据来源涵盖配方与工艺库、原料批次记录、反应釜DCS数据、称量系统数据、LIMS系统、仓储系统。数据更新频率为每批生产及每个关键工艺步骤。文档字段包含唯一批次标识、投料量（千克/升）、反应温度（摄氏度）、时间戳等，多为结构化表格或半结构化日志文本。

## 这些特征在「引用来源与溯源」这一环带来什么约束
本品类多品种按批次切换生产，每批数据独立更新，要求引用溯源需绑定唯一批次标识，关联分散在配方库、DCS、LIMS等多系统的同批次数据，确保引用来源的一致性。多步骤的工艺记录要求溯源需按工艺节点精准匹配对应文档片段，避免跨批次、跨步骤的无效引用。偏差与变更单的存在要求引用溯源需关联变更前后的版本记录，确保引用内容匹配当前有效版本。文档的结构化特征要求引用溯源需识别字段与单位，避免格式不匹配的引用错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | 匹配本品类单批次工艺文档的平均长度，确保覆盖投料、反应、清场等关键步骤的完整引用内容 |
| `responseData` | 仅返回关联批次与工艺步骤的条目 | 本品类生产数据按批次与步骤绑定，需精准匹配对应批次的文档，避免跨批次无效引用 |
| `detail` | 展示文档的完整字段与来源路径，字符长度不超过500 字符 | 本品类文档包含批次号、投料量、反应温度等字段，需明确溯源的具体字段与来源节点 |
| 上下文召回上限 | 前6条 | 本品类关键步骤的关联文档数量有限，召回过多会导致上下文冗余，降低溯源准确性 |
| 引用校验开关 | 开启 | 本品类需确保引用内容与来源严格对应，避免无依据的生成内容，符合生产合规要求 |

## 容易做错的三处
- 现象：界面下拉菜单仅支持单个变量选择，无法同时引用多个投料批次的文档。原因：默认配置限制了单轮引用的变量数量，未适配本品类多批次、多步骤关联溯源的需求。
- 现象：调用时返回`quote type error`报错。原因：输入的引用变量格式未匹配本品类文档的字段结构，例如未携带唯一批次标识、投料量等必填字段，不符合系统预设的引用格式要求。
- 现象：回复中未展示知识库引用的来源地址与文档类型。原因：未开启引用来源展示的配置开关，或配置的`quoteMaxToken`参数取值过小，导致来源信息被截断。

## 怎么确认配好了
本核对基于FastGPT v4.17.0版本的功能逻辑。
- 发起包含指定批次号与工艺步骤的质量审核问题，检查回复中是否关联了对应批次的投料复核单、反应过程记录等文档。
- 查看回复中引用内容的长度，确认覆盖单批次工艺文档的核心信息，匹配`quoteMaxToken`的配置取值。
- 检查报错日志，确认未出现`quote type error`报错，验证引用变量格式符合本品类文档的字段要求。
- 检查回复中是否展示了文档的批次号、时间戳等溯源信息，确认引用来源的完整性。
