# 精细化工间歇合成的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
本品类数据来自涂料、树脂、助剂、农化中间体等企业的配方与工艺库、原料批次台账、反应釜DCS系统、称量系统、LIMS实验室管理系统及仓储系统。日常文档包含批生产指令、投料复核单、反应过程记录、清场记录、检验报告、偏差与变更单，各文档字段含批次号、投料量、反应温度、残留检测值等，单位涵盖千克、摄氏度、ppm等。数据更新频率为每生产批次或每个关键工艺步骤触发一次。

## 这些特征在「模型接入与配置」这一环带来什么约束
由于本品类按批次切换生产且数据随工艺步骤更新，模型接入时需适配多批次上下文隔离，避免不同生产批次的信息混淆。分散的多源数据要求配置支持多格式文档解析，适配不同系统导出的文档结构差异。配方与工艺的保密性要求配置加入敏感信息过滤规则，防止核心技术数据泄露。频繁的投料复核、反应判断、清洗确认等高频调用场景，需限制单次响应的token消耗以保证生产节奏不受影响。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | `8000–12000 token` | 适配单批次生产相关的多文档上下文，避免超出模型窗口限制 |
| `maxTokens` | `2000–3000 token` | 控制单次响应长度，满足投料复核、反应判断等场景的文本输出需求 |
| `quoteMaxToken` | `1500 token` | 限制引用文档的token占比，保证模型响应的核心内容占比 |
| `toolChoice` | `auto` | 自动选择是否调用工具，适配多步骤审核中需要调用知识库或系统数据的场景 |
| `temperature` | `0.2–0.4` | 降低随机性，保证质量审核结果的一致性与准确性 |
| `AIPROXY_API_TOKEN` | 按企业权限配置 | 绑定对应模型的访问权限，符合配方数据的保密要求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配企业内部的代理访问配置，保证数据传输的安全性 |

## 容易做错的三处
- 现象：使用知识库时提示“无可匹配内容”，但已在系统中配置text-embedding-ada-002模型。原因：未将原料批次、LIMS数据对应的文档正确关联至对应批次的上下文，或模型调用时未绑定正确的知识库源。
- 现象：上传文档时使用r1模型，查询时使用qwen14B模型，出现查询结果与上传内容不匹配的情况。原因：不同模型的嵌入向量空间不一致，导致知识库召回的内容与上传文档的语义关联失效。
- 现象：使用deepseek模型进行文本提取时，身份证字段返回空值。原因：模型对证件文本的格式识别阈值设置不合理，未适配精细化工场景下的文档排版特征。

## 怎么确认配好了
- 登录FastGPT v4.17.0平台，上传单批次的投料复核单、反应记录等文档，验证知识库召回的内容与上传文档的字段匹配度，调整相关配置至召回结果符合业务需求。
- 发起投料复核的模型调用，验证响应结果包含所需的投料量、批次号等核心字段，调整`temperature`配置至结果稳定性符合要求。
- 测试敏感信息过滤功能，确认配方、原料批次等保密数据未被泄露至外部，验证`AIPROXY_API_TOKEN`的权限配置生效。
- 模拟多批次切换的场景，验证模型上下文能够正确隔离不同批次的生产数据，避免跨批次的信息干扰。
