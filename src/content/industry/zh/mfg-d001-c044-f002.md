# 纸浆造纸的供应商与过程质量审核：向量模型与索引

## 这个品类的数据长什么样
纸浆造纸场景的核心数据来自木浆废纸批次、DCS/QCS系统、纸机在线测量设备、实验室、能源和水处理系统，属于高速连续幅材生产的业务数据。日常文档包含配浆单、打浆记录、纸机运行记录、在线质量曲线、实验室报告、断纸与换品记录，字段涵盖浆料配比、打浆度、克重、水分、厚度等，更新节奏覆盖实时、每班、每卷三个层级。

## 这些特征在「向量模型与索引」这一环带来什么约束
实时、每班、多批次的更新节奏要求索引支持增量更新与批量重建，避免全量重新导入的冗余操作。多类型文档的混合输入，需要向量模型同时适配结构化字段与半结构化时序数据，`maxToken`需覆盖长时序纸机运行记录的长度。单批次数据量较大的特点，要求索引召回效率匹配业务查询的响应要求，同时需保留跨块的流程关联信息，防止分块破坏配浆、抄纸的连续业务逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配配浆单、打浆记录等单文档的平均长度，避免单块内容截断关键业务参数 |
| 重叠长度 | 50–80 字符 | 保留打浆到抄纸的跨块关联信息，适配在线质量曲线的连续时序特征 |
| `maxToken` | 8192 token | 适配长时序纸机运行记录的最大长度，防止模型截断核心运行数据 |
| `defaultToken` | 按所选模型标注的最大限制 | 匹配embedding模型的token上限，避免触发模型参数不兼容报错 |
| 相似度阈值 | 按实测标定 | 适配纸浆造纸场景的质量偏差特征，区分正常生产数据与异常问题记录 |
| 单次搜索上限 | 前10条 | 平衡召回效率与检索覆盖范围，满足快速定位质量问题的业务需求 |

## 容易做错的三处
- 现象：更换embedding模型后，已导入的知识库无法直接复用，需重新生成索引。原因：向量索引与embedding模型的输出维度强绑定，不同模型生成的向量特征不兼容，未配置FastGPT v4.17.0的增量索引更新流程。
- 现象：知识库搜索结果排序不符合预期，未按相似度优先级展示。原因：未开启重排配置，或重排模型未适配纸浆造纸场景的质量特征字段，导致排序逻辑偏离业务需求。
- 现象：语义检索分数很高，但返回的结果与实际质量问题不匹配，更换embedding模型后仍未改善。原因：分块长度设置过大，导致关键质量参数被截断，向量特征无法准确匹配查询意图。

## 怎么确认配好了
- 导入单份完整的纸机运行记录文档，检查FastGPT v4.17.0的向量生成日志无token截断、模型报错提示。
- 发起“查找当前批次浆料配比异常的记录”查询，核对返回结果的分块信息与原始文档的业务逻辑匹配。
- 更换embedding模型后，触发批量索引重建，验证索引生成进度正常无异常中断。
- 查看搜索结果排序，确认与质量偏差的关联程度符合业务预期，无明显排序混乱问题。
