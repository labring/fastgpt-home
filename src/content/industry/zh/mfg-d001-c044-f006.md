# 纸浆造纸的供应商与过程质量审核：引用来源与溯源

## 这个品类的数据长什么样
纸浆造纸的生产与质量数据来源涵盖木浆废纸批次台账、DCS/QCS控制系统数据、纸机在线测量数据、实验室检测报告、能源与水处理系统记录。数据更新节奏覆盖实时（如纸机在线质量曲线）、每班（如打浆记录）、每卷（如断纸与换品记录）。日常文档包含配浆单、打浆记录、纸机运行日志、在线质量曲线图表、实验室理化检测报告、断纸与换品台账，字段包含批次号、克重、水分、厚度、浆料配比等，单位涵盖吨、平方米、百分比、克/平方米等。生产为高速连续幅材模式，单条运行记录与质量曲线的内容长度较长。

## 这些特征在「引用来源与溯源」这一环带来什么约束
纸浆造纸的生产数据多为实时或批次绑定的结构化与半结构化内容，对溯源的精准性要求较高。首先，不同文档的更新节奏差异要求溯源系统需匹配数据的时间戳与生产批次，避免将非当前生产周期的记录混入审核溯源结果。其次，高速幅材生产的断纸、换品记录与当前生产批次强关联，溯源需绑定具体卷号与批次号，避免泛化匹配关键词带来的误差。此外，在线质量曲线、运行日志等内容长度较长，溯源需保留完整的原始字段与片段，不能仅展示摘要。同时，实验室报告与DCS数据的字段差异较大，需精准匹配对应数据源的元数据，确保审核时可追溯具体检测项与测量值。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | 纸浆造纸的在线质量曲线、纸机运行记录等文档单条长度较长，需足够token保留完整的批次号、检测值等核心溯源字段 |
| `responseData` | 仅返回关联文档元数据与内容片段 | 需精准展示配浆单、打浆记录等具体来源的元信息，支撑供应商与过程质量审核的溯源验证 |
| `detail` | 开启 | 需展示原始文档的具体字段如浆料配比、克重检测值，确保审核人员可核对原始数据与生成结论的一致性 |
| 相似度阈值 | `0.7–0.9` | 纸浆造纸的生产数据字段精准度要求高，需过滤与当前审核无关的历史记录，仅保留与当前审核批次强关联的文档 |
| 单次召回上限 | 前6条 | 生产类文档批次较多，过多召回会超出上下文窗口，且质量审核仅需核心的配浆、打浆、质量检测三类数据 |

## 容易做错的三处
- 现象为设置最低相关度阈值为1后，响应仍包含大量非当前批次的断纸记录。原因是未将溯源召回的文档与当前审核的生产批次绑定，仅基于关键词匹配召回，未过滤历史数据。
- 现象为溯源内容被截断，无法显示完整的配浆单批次号与浆料配比。原因是`quoteMaxToken`设置过小，未适配长文档的token占用上限。
- 现象为响应中未显示任何来源文档的元数据与链接。原因是未开启`responseData`配置，仅返回生成的审核结论，未关联原始数据源。

## 怎么确认配好了
- 提交一个针对特定生产批次的质量审核请求，查看响应中是否包含对应批次的配浆单、打浆记录的元数据与内容片段。
- 调整`quoteMaxToken`的取值，验证响应中溯源内容的长度是否随配置变化，确认参数生效。
- 测试一个与当前生产批次无关的查询，确认召回结果的相似度符合预设阈值，无无关内容混入。
- 检查FastGPT v4.17.0的版本标识是否出现在溯源日志或响应底部，确认当前使用的版本支持对应配置。
