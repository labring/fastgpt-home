# 纺纱与织造的供应商与过程质量审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
通常涵盖棉纺、化纤纺、机织与针织生产企业的业务数据。日常文档包含配棉配料单、工艺上机单、设备运转记录、纱线与坯布检验单据、疵点台账。数据来源于原纤维检验报告、ERP系统、纺机织机实时采集数据、条干仪、验布机输出结果与订单规格文件。更新节奏随每批原料、每班生产、每匹布产出同步更新。字段包含纤维指标参数、工艺参数、设备运行参数、检验数值与疵点类型，单位涵盖重量、长度、强度等物理计量单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据更新频率高、来源分散且字段类型多样，对HTTP接口的调用频率与数据兼容性提出约束。高频的生产与检验数据同步需求，要求接口支持每秒数次的并发请求，避免数据同步延迟。多来源的数据格式差异，要求接口的`variables`参数支持灵活的字段映射，`responseData`可适配结构化检验数值与非结构化单据内容。设备头数多带来的单批次数据量较大，要求接口支持合理的批量请求参数配置。分散的内部系统对接需求，要求接口权限配置可适配不同业务系统的鉴权规则。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | 携带企业内部系统的Bearer令牌，有效期设为7200秒 | 适配内部ERP与检验设备的鉴权规则，避免频繁刷新令牌导致的接口调用失败 |
| `variables` | 传入纤维品级、工艺捻度、疵点类型等字段，单次请求字段数不超过20个 | 匹配配棉单、工艺上机单的结构化数据结构，避免字段过多导致解析异常 |
| `responseData` | 按检验批次返回纱线强力、坯布疵点数量的结构化数组 | 适配供应商审核的批量数据统计需求，便于后续入库与分析 |
| 单次请求超时时间 | 30–60秒 | 适配设备数据采集的响应周期，避免因设备延迟导致的请求中断 |
| 并发请求上限 | 按实测标定 | 匹配纺机织机的并发数据上传能力，避免超出系统负载阈值 |

## 容易做错的三处
- 现象：调用接口后知识库与应用未自动关联，返回关联字段为空。原因：未在`variables`中传入知识库ID与应用绑定的关联参数，导致系统无法识别绑定关系。
- 现象：接口调用返回401状态码，鉴权失败。原因：`Authorization`参数未正确携带有效令牌，或令牌有效期超出预设的7200秒限制。
- 现象：批量请求后返回结果条数与预期不符。原因：未限制单次请求的字段数或数据量，超出接口解析上限导致部分数据被丢弃。

## 怎么确认配好了
- 发起一次测试请求，传入配棉配料单的典型字段，检查`responseData`是否返回符合预期的结构化检验结果。
- 调用鉴权接口获取令牌，验证`Authorization`参数可正常通过系统鉴权，无401状态码返回。
- 发起批量请求，核对返回结果的字段完整性与请求参数的一致性，确认无字段丢失或解析异常。
- 调整超时时间参数，模拟设备延迟场景，确认请求可在预设周期内完成响应。
