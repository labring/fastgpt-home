# 计量器具与实验室管理的供应商与过程质量审核：向量模型与索引

## 这个品类的数据长什么样
本品类数据来自企业计量室、CNAS体系实验室的计量管理系统、LIMS平台、外部校准机构证书及环境监测数据。日常文档包含量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账与偏离处置文件。数据更新节奏按校准周期、单次试验结果或异常事件触发，单条文档包含器具编号、量程、精度等级、测量值、不确定度、校准日期等带明确单位的字段。

## 这些特征在「向量模型与索引」这一环带来什么约束
多源异构的数据来源要求索引支持跨系统文档的关联检索；按校准周期、异常事件触发的非批量更新模式，要求索引支持增量更新以避免全量计算耗时；带明确单位与溯源字段的文档结构，要求分块时保留字段关联，避免拆分破坏溯源链；高置信度的质量审核需求，要求向量检索结果的匹配精度需严格匹配业务场景，不能出现无关结果。同时，校准证书与试验记录的长文本特性，要求向量模型的上下文窗口需适配单条文档的长度需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配校准证书、试验原始记录的单条内容长度，避免拆分破坏器具编号、校准日期等溯源字段的关联 |
| 重叠长度 | 50–100 字符 | 保留分块间的上下文关联，确保校准周期、期间核查的连续信息不被截断 |
| `maxToken` | 8192 | 适配多数公开向量模型的上下文窗口上限，满足长文本校准证书的完整向量化需求 |
| 相似度阈值 | 按实测标定 | 本品类对检索置信度要求较高，需结合实际质量审核的检索结果调整匹配精度 |
| 单次搜索上限 | 前 10 条 | 覆盖多份关联文档的检索需求，确保溯源失准器具影响的产品范围时可获取完整关联记录 |
| `defaultToken` | 4096 | 适配单条检索结果的合理展示长度，满足质量审核人员的文档查阅需求 |

## 容易做错的三处
- 现象：导入数据后状态持续显示为创建索引中，耗时数小时。原因：未针对校准证书、试验记录这类长文本调整分块配置，单块内容过长导致向量计算资源占用过高。
- 现象：向量计算得分异常，分数偏大且多条结果得分一致。原因：分块时未保留器具编号、校准日期等元数据字段，导致相似检索匹配了无关的长文本内容，无法准确关联溯源信息。
- 现象：向量化处理速度过慢，无法满足批量校准数据的更新需求。原因：未配置增量索引模式，每次全量索引所有历史数据，重复计算已完成向量化的旧文档。

## 怎么确认配好了
- 查看FastGPT v4.17.0的索引创建日志，确认单条分块长度符合预设的分块配置，无异常拆分的溯源字段。
- 检索已知的器具编号，确认返回结果包含关联的校准证书、期间核查记录与试验原始记录，且排序符合业务关联逻辑。
- 导入批量校准数据，验证索引创建耗时符合预设的时间区间，无持续卡顿或异常终止。
- 调整相似度阈值，验证检索结果的匹配精度符合质量审核的置信度要求。
