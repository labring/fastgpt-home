# 计量器具与实验室管理的供应商与过程质量审核：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自企业计量室、CNAS体系实验室的日常产出，包含量具台账、校准计划、校准证书、期间核查记录、标准物质台账、偏离处置单等文档。数据来源覆盖计量管理系统、外部校准机构证书、LIMS系统与环境监测设备。更新节奏按校准周期、单次试验结果或异常情况触发，字段包含量具唯一编号、校准日期、测量不确定度、溯源标准器编号与使用状态，单位涉及毫米、牛顿、摄氏度等计量专业单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
本品类数据的溯源关联属性，要求检索需精准匹配多文档间的关联关系，仅匹配单个关键词无法满足需求。混合结构化台账与非结构化证书的文档格式，要求检索支持多类型内容召回。非固定的更新频率，要求检索系统支持增量索引以避免全量重建的资源消耗。专业字段如测量不确定度的语义匹配需求，对检索的语义一致性要求更高。溯源场景下需同时召回多份关联文档，对单次召回的结果条数有明确约束。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配计量专业术语与关联字段，过滤低相关结果 |
| `limit` | 前10条 | 覆盖溯源所需的多文档关联，控制单轮检索上下文长度 |
| `searchMode` | 语义检索 | 适配测量不确定度、溯源编号等专业语义字段的匹配 |
| `usingReRank` | 开启 | 对召回结果按专业相关性重排，提升校准证书等核心文档的排序 |
| `datasetSearchUsingExtensionQuery` | 开启 | 召回量具台账、校准证书中的扩展关联字段 |
| `collectionIds` | 计量器具、校准证书专属数据集ID | 限定检索范围，避免混入其他品类的无关文档 |
*注：本配置适用于FastGPT v4.17.0版本*

## 容易做错的三处
- 现象：知识库搜索无结果，界面显示空结果列表。原因：升级FastGPT v4.9到v4.10后，原数据集关联配置被重置，未重新指定`collectionIds`为计量器具相关数据集。
- 现象：检索报错`invalid configuration parameter name "hnsw.max_scan_tuples"`。原因：误用了非官方支持的索引参数，未使用FastGPT指定的配置项。
- 现象：召回结果未包含校准证书的测量不确定度字段。原因：未开启`datasetSearchUsingExtensionQuery`，仅召回了基础文本内容。

## 怎么确认配好了
- 进入FastGPT应用配置页面，确认已关联计量器具、校准证书专属数据集。
- 输入专业检索词，比如「2024年3月校准的外径千分尺」，验证召回结果包含对应量具的台账与校准证书。
- 查看应用运行日志，确认无`invalid configuration parameter name`类报错。
- 检索溯源相关关键词，验证召回结果包含多份关联文档，符合溯源需求。
