# 通用机械设备装配的供应商与过程质量审核：多轮对话与提示词

## 这个品类的数据长什么样
通用机械设备装配场景的核心数据来自泵、阀、压缩机、减速机、机床及非标设备制造商的全流程业务。日常文档覆盖装配工艺卡、BOM、扭矩记录、间隙调整记录、试运行报告、出厂检验单、装箱清单。数据来源包含PLM/ERP系统、零件检验数据、装配工具采集终端、试验台、MES系统及客户技术协议。数据更新随单台设备或每订单执行，每完成一次装配环节或订单交付，对应文档即完成更新。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
该品类的数据分散在多个系统且随单台设备独立更新，导致多轮对话需要逐步调取不同来源的文档，避免一次性加载过多内容超出上下文限制。文档包含扭矩值、间隙参数、同轴度要求等带明确单位的特定字段，提示词需要明确引导提取对应字段进行核对。单台设备的审核流程覆盖多个装配环节，多轮对话需要按工序分步推进，避免跨环节的信息干扰当前判断。同时，每订单的BOM和装配记录唯一，对话上下文需要绑定当前订单标识，确保信息关联准确。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，适配通用机械设备装配的审核场景。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chatId` | 与设备出厂编号或订单号绑定的唯一标识 | 每台设备对应唯一审核流程，确保对话记录可精准追溯 |
| `messages` | 保留最近10轮对话，超出自动截断最早轮次 | 该品类的审核对话聚焦当前装配环节，过多历史内容会干扰当前判断 |
| `variables` | 自动同步ERP中的当前订单BOM编号、装配工序编号 | 确保对话上下文关联当前批次的专属文档，避免跨订单混淆 |
| 单次召回上限 | 前6条 | 该品类的文档按工序分类，前6条即可覆盖当前审核环节的参考内容 |
| 最大上下文长度 | 8000–12000 字符 | 单台设备的装配文档总长度通常在此区间，避免超出模型token限制 |
| 对话记录保存时长 | 180 天 | 行业内通常需要留存装配审核记录至设备交付后半年，满足追溯需求 |

## 容易做错的三处
- 现象：执行长文本审核任务时，界面显示任务正常完成但抛出`The value of "offset" is out of range`报错。原因：未针对该品类的长文档（如完整装配工艺卡）设置合理的分块参数，导致分块时偏移量超出文档实际长度。
- 现象：对话中无法调取指定订单的BOM文档。原因：未正确配置`variables`绑定当前订单的BOM标识，导致知识库搜索无法匹配对应专属文档。
- 现象：跨班组登录后可查看非负责工序的装配文档。原因：未按装配工序配置知识库权限，导致权限范围覆盖了非当前负责的文档库。

## 怎么确认配好了
- 发起一次针对单台减速机装配的审核对话，检查`chatId`是否与该设备的出厂编号绑定，确保对话记录可精准追溯。
- 输入查询「核对当前批次的BOM齐套情况」，确认返回的文档包含当前订单的BOM内容，验证`messages`和`variables`配置生效。
- 尝试调用超出配置长度的文档进行测试，观察是否触发上下文截断提示，验证最大上下文长度配置合理。
- 切换不同的测试账号，检查是否只能访问对应工序的装配文档，验证知识库权限配置正确。
