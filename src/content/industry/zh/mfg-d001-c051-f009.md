# 金属切削加工的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
金属切削加工场景的数据来源于产品图纸与三维模型、CAPP/CAM系统、机床采集终端、刀具管理系统、MES系统及量检具数据。日常文档包含工艺路线、工序卡、刀具清单、数控程序、首件检验记录、巡检表及量具校准记录，字段涵盖工序号、刀具编号、数控程序段、检验尺寸数值、校准周期等。数据更新频率随工单执行、抽检环节及刀具更换动作触发，无固定周期，单条数据长度跨度较大，从简短的尺寸数值到数百行的数控程序不等。

## 这些特征在「模型接入与配置」这一环带来什么约束
多异构数据源的接入要求统一的格式解析规则，需适配数控程序的G代码语法、量检具的数值输出格式等不同结构的数据。高频更新的数据源要求上下文窗口能够快速加载最新的工序、刀具及检验数据，避免因上下文过期导致审核偏差。精密尺寸数值与工艺参数的高准确性要求，限制了模型输出的随机性，同时需支持长文本片段的引用与解析。场景依赖工装、刀具与基准转换的关联逻辑，要求模型配置能够关联多文档的跨字段信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 金属切削加工的工艺文档、检验记录单条长度较长，需承载多工序关联的上下文信息，足够的窗口可避免关键内容截断 |
| `temperature` | 0.1–0.3 | 质量审核需严格匹配工艺参数与检验结果，低温度可降低输出随机性，提升数值解析与规则匹配的准确性 |
| `quoteMaxToken` | 2000–3000 字符 | 需引用数控程序段、量具校准记录等长文本片段，确保引用内容完整覆盖审核所需的细节 |
| 工作流/API 工具选择配置 | auto | 审核过程需调用知识库查询工序要求、刀具参数，自动调用工具可提升流程效率 |
| `AIPROXY_API_ENDPOINT` | `http://192.168.xxx.xxx:8080`（本地代理地址） | 适配车间内网的数据采集节点，减少跨网段传输延迟，保障数据流转稳定 |
| `AIPROXY_API_TOKEN` | 按实测标定 | 需匹配代理服务的身份校验规则，避免未授权访问导致的调用失败 |

## 容易做错的三处
- 现象：调用模型时提示流响应为空，接口返回401或超时状态码。原因：未正确配置`AIPROXY_API_TOKEN`，或`AIPROXY_API_ENDPOINT`指向错误的内网节点。
- 现象：系统日志显示实际调用的模型与应用配置的模型不一致。原因：未区分应用全局模型与知识库参数优化模型的配置项，导致两者绑定了不同的模型。
- 现象：审核过程中无法完整加载数控程序或工序卡内容。原因：`maxContext`取值过小，无法承载长文本的工艺文档，导致上下文截断。

## 怎么确认配好了
- 登录FastGPT v4.17.0的管理后台，进入对应应用的模型配置页面，核对`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的取值与代理服务配置一致。
- 提交一条包含数控程序片段的测试请求，查看日志中返回的上下文长度是否符合`maxContext`的配置值，无截断现象。
- 发起质量审核测试，确认调用的模型与应用配置的模型一致，无跨配置项的模型混用。
- 触发一次刀具更换场景的审核请求，验证模型是否能正确关联刀具清单与工序卡的关联数据。
