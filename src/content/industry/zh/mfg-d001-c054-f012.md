# 钣金下料折弯的供应商与过程质量审核：部署与升级

## 这个品类的数据长什么样
该品类的数据主要来自CAD/CAM软件、订单BOM系统、板材库存台账、激光切割机与折弯机设备日志、车间MES系统。日常生成的文档包括三维件展开图、数控下料程序、折弯工艺卡、套料图、首件检验记录、工序流转卡。数据更新随订单交付、每日库存盘点、每次生产换型同步。文档字段包含折弯补偿系数、孔位坐标、板材规格、折弯顺序、工序流转节点等，部分文档关联板材材质与厚度参数。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据多源异构且更新频繁，部署时需适配CAD/CAM导出格式、MES接口协议等多种数据接入方式，提前配置对应解析规则。高频次的订单、换型数据更新，要求部署的服务具备稳定的低延迟读写能力，升级时需优化数据库连接池参数。多类型工艺文档包含折弯系数、孔位坐标等专业工程字段，部署时需配置支持工程属性的向量索引。多品种小批量带来的文档体量波动，要求部署的存储资源具备弹性适配能力，避免因数据量突增引发服务卡顿。此外，核心工艺数据的跨模块关联，要求部署时确保数据链路的一致性，避免同步延迟导致的工序错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `10–15 个` | 适配该品类多源设备（激光切割机、折弯机、MES）的并发读写需求，支撑车间生产数据的实时交互 |
| `MONGODB_URI` | `mongodb://username:password@host:27017/fastgpt?authSource=admin` | 存储工艺文档、工序流转记录等非结构化数据，需配置带权限验证的连接地址，适配FastGPT v4.17.0版本的数据存储规范 |
| `PG_URL` | `postgresql://username:password@host:5432/fastgpt` | 存储订单BOM、板材库存等结构化业务数据，适配关系型数据的复杂查询需求 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 缓存高频访问的折弯系数、套料规则等数据，降低数据库的重复读写压力 |
| `STORAGE_S3_ENDPOINT` | `按本地对象存储地址填写，如 http://192.168.1.100:9000` | 存储展开图、数控程序等大体积工程文件，适配私有云或本地存储的部署场景 |
| `FILE_TOKEN_KEY` | `按实测标定的随机字符串` | 生成工程文件的访问令牌，保障工艺文档下载的安全性 |

## 容易做错的三处
- 容器持续重启且前端无法访问，现象为FastGPT v4.17.0版本的容器日志提示MongoDB连接认证失败或超时，原因是未正确配置`MONGODB_URI`中的用户名、密码或数据库名称，导致服务无法初始化核心数据存储。
- 工程文档解析失败，现象为上传的钣金展开图或套料图无法生成向量索引，原因是未配置适配CAD格式的解析适配器，导致折弯系数、孔位坐标等专业字段无法被正确提取。
- 服务响应缓慢，现象为查询折弯工艺卡时出现超时，原因是`DB_MAX_LINK`取值过低，无法满足多台设备并发提交生产数据的读写需求。

## 怎么确认配好了
- 登录FastGPT后台的系统设置页面，检查`MONGODB_URI`、`PG_URL`等数据库连接配置的格式与参数是否与本地部署的数据库一致。
- 上传一份标准钣金展开图文档，验证是否能成功解析并生成对应的向量索引，确认文件存储与解析链路正常。
- 启动多个模拟并发请求，观察服务的运行状态，确认`DB_MAX_LINK`的取值能支撑并发访问需求。
- 查看容器的实时日志输出，确认无数据库连接失败、认证错误等报错信息。
