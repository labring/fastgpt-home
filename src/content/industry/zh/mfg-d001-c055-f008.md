# 铸造（砂型、精密、压铸）的供应商与过程质量审核：文档解析与分块

## 这个品类的数据长什么样
该品类的数据来源包括ERP物料主数据、熔炼炉与测温仪、光谱仪、MES炉次记录、模具管理系统、客户图纸与技术条件。日常文档包含铸造工艺卡、配料单、炉次记录、模具履历、首件检验记录、材质报告、不合格品评审单，字段涵盖合金配料比例、熔炼温度、浇注参数、缺陷类型、炉次号、模次号等，单位涉及摄氏度、炉次编号等。数据更新频率为每炉次、每批、每日，单份文档结构固定，字段顺序统一。

## 这些特征在「文档解析与分块」这一环带来什么约束
文档结构固定但字段多为结构化内容，分块时需保留单炉次、单批次的完整字段组合，不能拆分同一炉次的配料比例、温度参数等关键信息。数据更新频率为每炉次、每批、每日，分块需适配高频更新的炉次记录，避免块内包含跨批次内容混淆。数据来自多系统，文档格式存在差异，需自定义分隔符适配不同文档的结构边界。关键数据的准确性直接影响质量审核结果，分块不能将不同炉次、不同批次的内容合并，否则会导致后续召回时无法精准匹配审核需求。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配铸造类文档的单炉次或单批次内容长度，保留完整的配料、温度等字段组合 |
| `chunkSplitter` | 自定义分隔符，按行或炉次号分隔 | 适配Excel、PDF文档的结构化行内容，避免跨行、跨炉次合并内容 |
| `customPdfParse` | 开启 | 准确提取铸造工艺卡、材质报告中的表格内容，保留字段边界 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 适配多份炉次记录、模具履历等较大的文档解析时长，避免超时中断 |
| `chunkSettingMode` | 手动模式 | 针对不同文档类型自定义分隔符，适配多来源的结构化数据 |

## 容易做错的三处
- 现象：上传Excel格式的配料单、炉次记录时，多行单条记录被合并为一个`chunk`。原因：未将`chunkSplitter`配置为按行或炉次号分隔，默认按段落拆分，无法识别Excel的行边界。
- 现象：部分材质报告、炉次记录的`chunk`无法被召回。原因：`chunkSize`设置不符合文档内容长度，导致关键的合金成分、温度参数被拆分到多个块，或未设置自定义分隔符匹配炉次号作为边界。
- 现象：多PDF格式的工艺卡、模具履历上传后，无法按文档逐一提取信息。原因：未配置按文档维度拆分，默认合并所有上传文档的内容，无法区分单份文档的内容。

## 怎么确认配好了
- 上传单份Excel格式的配料单，检查拆分后的`chunk`数量与原Excel行一一对应。
- 上传多份PDF格式的工艺卡、材质报告，检查每个`chunk`对应单份文档的内容，无跨文档合并。
- 查看解析后的`chunk`内容，确认炉次号、合金配料比例等关键字段未被截断。
- 输入包含合金配料比例、熔炼温度等审核关键词，确认能召回对应的`chunk`。
