# 铸造（砂型、精密、压铸）的供应商与过程质量审核：模型接入与配置

## 这个品类的数据长什么样
这个品类的日常数据涵盖铸造工艺卡、配料单、炉次记录、模具履历、首件检验记录、材质报告等，数据来源包括ERP物料主数据、熔炼炉与测温仪、光谱仪、MES炉次记录、模具管理系统及客户图纸。数据更新频率为每炉次、每批或每日，其中炉次记录、配料单随生产节奏实时更新，模具履历与材质报告按批次归档。文档结构包含结构化字段与非结构化文本，字段涉及合金成分占比、浇注温度、炉次号、模次、缺陷类型等，单位涵盖百分比、摄氏度、千克。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源、高频更新的铸造数据要求模型接入需适配实时同步与批量处理的需求，结构化的配料单、炉次记录需保持字段完整性，避免分块时断裂。跨系统关联的数据（如炉次与模具履历）需要足够的上下文窗口承载关联信息，同时质量审核的判读结果需保持一致性，不宜引入过多随机性。此外，部分场景需处理光谱仪、探伤仪生成的图片数据，需适配图像识别的配置要求，内部网络环境下的模型调用需解决代理与权限问题。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 承载炉次、模具、配料单的关联数据，避免截断跨文档的质量审核关联信息 |
| `maxTokens` | 2000 token | 控制单轮回复长度，适配结构化的缺陷判定与比例核对输出格式 |
| `quoteMaxToken` | 3000 token | 保留足够的原文片段，确保合金配料比例、温度参数的核对结果可追溯 |
| `temperature` | 0.1–0.3 | 降低输出随机性，保证成分判定、缺陷归类的结果一致性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配内部网络访问限制，解决外部模型连接不通的问题 |
| `AIPROXY_API_TOKEN` | 按授权密钥填写 | 保障模型调用的权限合法性，避免权限报错 |

## 容易做错的三处
- 现象：上传结构化excel配料单后，自动分块结果将单条炉次记录拆分为多个片段，无法完整匹配对应字段。原因：未针对excel数据设置按行分块，使用默认自动分段逻辑导致字段断裂。
- 现象：模型调用返回连接超时或`403 Forbidden`错误，无法完成质量审核任务。原因：未正确配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或内部代理网络未放行对应访问路径。
- 现象：上传光谱仪拍摄的气孔缺陷图片后，模型未识别图像中的缺陷特征，返回无相关判定结果。原因：未开启`vision`配置，或未按照要求的格式传递图片参数。

## 怎么确认配好了
- 上传单份炉次记录excel，检查分块结果是否完整保留每行的炉次号、合金成分、浇注温度等核心字段。
- 发起一次合金配料比例核对的测试请求，查看返回结果是否引用了原文片段且无关键信息截断。
- 调用模型接口上传标准铸造缺陷图片，确认返回的判定结果包含对应缺陷的特征描述。
- 检查模型调用日志，确认无权限报错或连接超时记录，验证代理配置的有效性。
