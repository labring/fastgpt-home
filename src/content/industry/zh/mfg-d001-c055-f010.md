# 铸造（砂型、精密、压铸）的供应商与过程质量审核：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自铸造厂、压铸车间及质量部门的日常业务文档，包括铸造工艺卡、合金配料单、炉次记录、模具履历、首件检验记录、材质报告及不合格品评审单。数据来源覆盖ERP物料主数据、熔炼炉测温仪、光谱仪、MES炉次记录、模具管理系统与客户技术图纸。更新节奏按炉次、批次或每日执行，单条数据包含合金成分、浇注温度、模次、缺陷类型等字段，单位涉及温度、重量、百分比等专业铸造参数。

## 这些特征在「知识库检索与召回」这一环带来什么约束
本品类的数据特征对检索召回带来多重约束。多源异构数据覆盖设备采集、系统记录与业务文档，需适配不同格式的索引构建规则。高频更新节奏要求检索链路支持增量同步，避免全量重建占用过多资源。单条数据包含专业铸造字段且关联紧密，如炉次对应配料比例、浇注温度与缺陷类型，检索需支持多字段关联召回。不同文档的单位存在差异，需在预处理阶段完成格式统一，防止匹配偏差。过程质量审核需追溯缺陷与炉次、模次的关联，检索需精准召回历史关联记录。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 铸造数据专业度高，需过滤低匹配度的无关文档，该区间可平衡召回覆盖率与准确率 |
| `limit` | `前8–12条` | 单炉次相关文档数量有限，过多结果会超出上下文窗口，过少可能遗漏关键关联记录 |
| `searchMode` | `mixedRecall` | 需同时匹配专业术语关键词与语义关联内容，适配铸造工艺的专业表述 |
| `usingReRank` | 开启 | 多源数据易出现语义相似但无关的结果，重排可提升精准度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可通过扩展问题覆盖铸造专业术语的同义表述，如将“回炉料”匹配“旧料配比” |
| `collectionIds` | 绑定铸造工艺、炉次记录、质量评审专属集合 | 隔离非铸造类数据，避免无关内容干扰检索结果 |

## 容易做错的三处
- 现象：检索结果中混入大量非铸造类文档，准确率偏低。原因：未配置`collectionIds`绑定专属知识库集合，导致检索范围覆盖无关数据。
- 现象：合并多个铸造相关数据集后出现重复的炉次或模次记录。原因：未设置基于炉号、模次字段的去重规则，导致索引合并时未过滤重复条目。
- 现象：无法导出分段好的铸造知识库内容用于本地迁移。原因：直接复制服务器原始文件未保留分段元数据，或未使用官方导出流程导出结构化的知识库片段。

## 怎么确认配好了
- 手动输入一条炉次记录的核心参数，核对检索结果是否优先返回同炉次的关联文档。
- 检查检索配置中是否绑定了专属的铸造知识库集合，确认无关数据未被纳入检索范围。
- 验证合并数据集后的去重逻辑，确认重复的炉次、模次记录已被过滤。
- 测试接入外部铸造技术网站的检索功能，确认页面内容可被正常召回。
