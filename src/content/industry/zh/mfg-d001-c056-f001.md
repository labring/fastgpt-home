# 锂离子电芯制造的供应商与过程质量审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
本品类数据来源包括原材料批次台账、生产MES系统、浆料与涂布检测设备、车间露点监测装置、化成分容柜及实验室测试设备。日常文档涵盖配料记录、涂布辊压参数日志、卷绕/叠片操作记录、注液台账、化成分容数据、OCV与安全测试报告。数据更新节奏为每批次、单只电芯维度实时同步，字段包含批次号、检测值、设备编号、时间戳等，单位涉及电压、电阻、露点温度、浆料固含量等电化学与工业参数。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
本品类数据的实时更新、多源异构、专用参数特征，对HTTP接口环节带来多重约束。多源数据来自生产设备、实验室等不同系统，需通过统一的`Authorization`参数完成鉴权，避免跨系统数据泄露。实时同步的单条数据量小但频次高，接口需适配高并发请求，避免数据积压。电化学专用参数的原始格式需完整保留，`responseData`不应擅自转换单位或截断字段。审核流程需关联多批次文档，接口需支持按批次号、电芯ID批量查询，确保关联数据的完整性。

## 配置怎么定
以下配置适用于 FastGPT v4.17.0

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {自定义密钥}` | 适配多源外部系统的统一鉴权需求，避免未授权访问生产与检测数据 |
| 超时时间 | `30–60 秒` | 适配实时数据上报与审核查询的响应需求，避免长耗时任务阻塞接口队列 |
| `responseData` | 保留原始字段与单位，不做格式转换 | 本品类电化学参数需严格匹配原始检测值，字段缺失或转换会影响审核准确性 |
| `variables` | 绑定批次号、电芯ID为动态参数 | 支持按单批次或单电芯维度查询对应文档，适配审核流程的精准定位需求 |
| 单次搜索上限 | `前 10 条` | 单批次关联文档数量通常在10条以内，避免冗余数据占用接口带宽 |
| 鉴权缓存时长 | `15 分钟` | 平衡鉴权安全性与接口响应速度，适配高频设备上报的鉴权需求 |

## 容易做错的三处
- 现象：接口调用返回504超时状态码，或请求无响应。原因：未根据本品类实时数据上报的高频特性调整超时时间，默认超时时长过短，无法覆盖多源数据的查询与拼接流程。
- 现象：接口返回的`responseData`中电化学参数单位缺失或被转换。原因：未配置`responseData`保留原始格式，擅自转换参数单位或截断字段，导致审核依据的检测数据失真。
- 现象：数据库查询请求仅部分成功返回数据，或完全无法匹配对应检测记录。原因：未通过`variables`绑定批次号、电芯ID作为动态查询参数，固定参数导致查询范围无法匹配本品类按批次、单电芯更新的数据结构，同时并发请求未做限流导致数据库资源耗尽。

## 怎么确认配好了
- 调用配置后的接口，传入已知的批次号，检查`responseData`中是否包含该批次对应的配料、涂布等原始文档字段，且单位未被修改。
- 发起10次以上并发请求，确认接口未出现超时或500系列错误，调整超时时间至符合业务需求的区间。
- 传入`variables`绑定的动态参数，验证接口返回的文档数量与该批次实际关联的文档数量一致。
- 检查`Authorization`参数的配置，使用未授权的密钥调用接口，确认返回401未授权状态码，确保鉴权生效。
