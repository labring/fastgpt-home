# 锂离子电芯制造的供应商与过程质量审核：向量模型与索引

## 这个品类的数据长什么样
该品类数据覆盖动力、储能、消费电池企业极片、装配、化成与品质部门的全流程记录，包含配料记录、涂布辊压参数、卷绕或叠片记录、注液记录、化成分容数据、OCV与安全测试报告。数据来源涵盖原材料批次台账、MES系统、浆料与涂布检测数据、露点监测记录、化成分容柜实时数据及实验室测试报告。更新节奏按生产批次、单只电芯及实时指标三类推进，单条数据包含批次号、参数值、检测时间、检测结果等字段，部分参数带单位如涂布面密度g/㎡、露点温度℃。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类数据的多源实时性与批次级更新要求，要求向量索引需支持高频增量写入，避免全量重建带来的性能损耗。多类型文档的字段差异（如浆料配比的数值项、安全报告的文本项），要求向量模型需适配混合模态数据的编码，同时索引需支持按批次号、检测时间等字段的元数据过滤。单只电芯的细粒度数据会带来索引体积膨胀，需控制单条向量的维度与存储开销，同时需保证化成分容曲线这类时序数据的向量编码能保留时序特征，避免一致性校验时丢失关键信息。

## 配置怎么定
本文基于FastGPT v4.17.0版本的配置逻辑编写，具体配置项如下：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配配料记录、涂布参数等单条文档的长度，避免单块数据跨关键信息边界 |
| 重叠长度 | 50–100 字符 | 保留涂布辊压参数的前后关联信息，防止分块切断连续的工艺参数序列 |
| 相似度阈值 | 按实测标定 | 需匹配电芯检测数据的离散程度，避免误匹配不同批次的浆料配比记录 |
| 单次搜索上限 | 前10条 | 控制召回结果的数量，适配批次级审核的批量数据处理需求 |
| `defaultToken` | 4096 | 适配化成分容数据的长文本向量编码需求，保证完整的曲线数据被正确编码 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |

## 容易做错的三处
- 接入腾讯混元向量模型时渠道配置错误，表现为界面提示「模型渠道未启用」，原因是未在FastGPT系统设置中先完成第三方向量模型的密钥绑定与渠道激活。
- Ollama部署的BGE-M3向量模型接入失败，表现为检索时返回空结果或报错「模型连接超时」，原因是未将向量模型的API端口开放至FastGPT部署网络，且未在配置中填写正确的本地访问地址。
- 启用索引模型后未配置元数据过滤，表现为检索结果包含跨批次的电芯数据，原因是未绑定批次号、检测时间等元数据字段，导致索引无法按生产批次进行精准召回。

## 怎么确认配好了
- 上传一条典型的涂布辊压参数文档，检查向量生成任务的状态显示为「已完成」，无报错日志。
- 发起针对某批次浆料配比的检索，核对召回结果的元数据中包含该批次号，且结果条数符合单次搜索上限的配置。
- 查看向量索引的存储占用，确认未出现异常膨胀，符合单批次数据的索引规模预期。
- 测试长文本的化成分容曲线检索，确认完整的曲线数据被正确编码，未出现截断报错。
