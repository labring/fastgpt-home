# 锂离子电芯制造的供应商与过程质量审核：工作流编排

## 这个品类的数据长什么样
锂离子电芯制造的核心数据来自原材料批次台账、生产MES系统、浆料与涂布检测设备、车间露点监测装置、化成分容柜及实验室测试设备。日常归档的生产文档包含配料记录、涂布辊压参数表、卷绕/叠片工序日志、注液台账、化成分容数据、OCV与安全测试报告。数据更新频率覆盖每批物料、单只电芯的细粒度维度，部分检测参数如车间露点、涂布面密度为实时上传。字段包含浆料固含量、涂布面密度、卷绕张力、露点温度、化成分容曲线参数、电芯内阻等专业生产参数。

## 这些特征在「工作流编排」这一环带来什么约束
多源异构的实时/批量数据要求工作流支持多节点并行接入不同数据源，且需适配单批次、单电芯的细粒度数据校验。专业字段多且精度要求高，工作流的变量定义需严格匹配生产文档的字段名与单位，避免参数不匹配导致的校验失败。高频更新的数据会触发工作流的频繁触发，需配置节点触发规则以避免重复执行。电化学体系对环境参数敏感，工作流需嵌入异常校验环节，对露点异常、面密度偏差等情况触发中断流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 全局变量配置 | 按生产文档定义`variables`为配料批次、涂布面密度、露点温度 | 匹配锂离子电芯制造的核心生产与检测字段 |
| 节点ID绑定 | 为涂布检测、化成分容等核心节点绑定`nodeId` | 精准关联数据源与对应工作流步骤 |
| 上下文保留轮次 | 前序AI节点保留1轮，后续校验节点保留3轮 | 适配不同环节的信息需求，避免冗余数据占用资源 |
| 变量更新规则 | 支持空值覆盖更新 | 处理检测数据缺失的异常场景 |
| 外部参数传递 | 开启URL参数绑定全局变量 | 接收外部传入的批次号等查询参数 |
| 节点超时设置 | 600秒 | 适配化成分容等长耗时环节的数据获取 |

## 容易做错的三处
- 尝试通过变量更新将前一个AI模型的输出置为空值但未生效，现象为目标字段始终保留旧值，原因是未开启变量覆盖开关，或更新规则未匹配`variables`的作用域。
- 外部URL传递参数后工作流未读取到传入值，现象为全局变量字段显示为空，原因是未正确配置URL参数与`variables`的映射关系。
- 同一ID多次访问工作流时，前序节点的上下文数据未重置，现象为对话结果包含历史冗余信息，原因是未在节点触发时清空上下文缓存。

## 怎么确认配好了
- 提交测试批次的生产参数，检查全局变量是否正确加载配料批次、涂布面密度、露点温度等核心字段。
- 触发涂布检测节点运行，查看绑定`nodeId`的数据源是否正常同步最新检测数据。
- 传入包含批次号的URL参数，验证`variables`是否正确接收传入值。
- 使用FastGPT v4.17.0版本的平台进行测试，多次触发同一工作流，检查上下文轮次是否按配置重置。
