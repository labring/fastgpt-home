# 锂离子电芯制造的供应商与过程质量审核：文档解析与分块

## 这个品类的数据长什么样
本品类的主体为动力、储能及消费锂离子电芯制造企业的极片、装配、化成与品质部门。日常文档涵盖配料记录、涂布辊压参数、卷绕或叠片记录、注液记录、化成分容数据、OCV与安全测试报告。数据来源于原材料批次台账、MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室数据，更新频率为每批、每只电芯或实时。文档多包含数值型字段与对应专业单位，如涂布厚度、露点温度、内阻参数等。

## 这些特征在「文档解析与分块」这一环带来什么约束
高频实时的更新节奏要求解析环节具备低延迟处理能力，避免延迟影响过程质量审核的时效性。多源异构的文档类型，包含结构化表格与非结构化测试报告，需要兼容不同格式的解析规则。单条记录的字段关联性强，如涂布参数与后续化成分容数据存在因果关联，分块需保留相邻字段的上下文关联，避免拆分后破坏数据逻辑。电化学体系对数据精度要求严格，解析过程需保留字段与对应单位的绑定关系，防止丢失关键信息。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 800–1200 字符 | 锂离子电芯制造的单条工序记录包含多组关联参数，该字符区间可完整保留一组工序的完整数据，避免拆分丢失上下文关联 |
| `chunkSplitter` | 按表格行+段落边界混合分块 | 日常文档包含结构化表格与非结构化段落，混合分块可兼顾两类文档的解析完整性 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 60–120 秒 | 实时更新的生产数据与批量检测报告需在合理时间内完成解析，该区间可适配高频任务的时效性要求 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 支持单批次原材料台账或批量化成分容数据的上传，覆盖企业日常批量审核的文档体积需求 |
| `customPdfParse` | 启用结构化解析模式 | OCV与安全测试报告多为表格化结构化文档，启用该模式可精准提取字段与对应单位的绑定关系 |
| `chunkSettingMode` | 手动配置 | 锂离子电芯制造的文档结构差异显著，手动配置可针对不同类型文档灵活调整分块规则 |

## 容易做错的三处
- 上传XLSX格式的多行表格文档后，解析结果中部分字段为空。未针对结构化表格配置针对性分块规则，导致多行表格被错误拆分，丢失字段关联关系。
- 解析PDF文档时出现“the argument ‘windows-1252’ is invalid encoding”报错。未配置适配的编码解析规则，文档中包含非UTF-8编码的字符导致解析失败。
- 批量上传多份大体积文档时，解析任务中途失败。未调整`PARSE_FILE_TIMEOUT_SECONDS`参数至合理区间，批量文档解析耗时超出默认阈值。

## 怎么确认配好了
- 上传单份典型文档（如涂布辊压参数表），核对解析后的分块数量与字段完整性，调整`chunkSize`至符合业务需求的取值。
- 上传多格式混合文档包，验证不同类型文档的解析结果是否保留字段与单位的绑定关系，确认`customPdfParse`配置生效。
- 批量上传预设体积的文档，检查解析任务的完成状态，调整`UPLOAD_FILE_MAX_SIZE`与`PARSE_FILE_TIMEOUT_SECONDS`参数适配批量处理需求。
- 检查系统环境变量配置，确认文件解析相关的自定义接口配置正确，适配企业内部数据来源的访问需求。
