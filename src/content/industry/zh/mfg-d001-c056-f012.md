# 锂离子电芯制造的供应商与过程质量审核：部署与升级

## 这个品类的数据长什么样
锂离子电芯制造的供应商与过程审核数据，来自原材料批次记录、MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室测试数据。日常文档包含配料记录、涂布辊压参数、卷绕或叠片记录、注液记录、化成分容数据、OCV与安全测试报告。数据按每批电芯、单只电芯实时更新，字段包含批次号、参数数值、检测时间、合格判定，单位涉及重量、厚度、电压、湿度等电化学相关指标。

## 这些特征在「部署与升级」这一环带来什么约束
该品类数据的实时性与批次强关联特性，要求部署时需适配高频小批量数据写入的存储配置。多源异构数据（设备直连、实验室报表、MES导出）需要统一的格式解析规则，升级时需兼容旧版设备对接协议。电芯数据对水分、洁净度等敏感指标的高精度要求，需配置足够的字段存储精度与校验逻辑。化成分容的长周期数据需支持按批次关联查询，部署时需规划合理的索引策略，避免升级后查询延迟。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:27017/fastgpt?authSource=admin` | 适配多源异构的批次化电芯数据存储，支持高并发写入 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 缓存实时检测数据与批次索引，降低高频查询延迟 |
| `DB_MAX_LINK` | `200–300` | 匹配每批次电芯检测数据的并发写入量，避免连接耗尽 |
| `STORAGE_S3_ENDPOINT` | 按企业内部对象存储实际地址填写 | 存储大容量的化成分容历史数据与测试报告 |
| `ROOT_KEY` | 随机生成32位字符串 | 保障系统内部接口调用的权限安全 |
| `FILE_TOKEN_KEY` | 与内部存储服务密钥保持一致 | 验证上传的检测报表文件合法性 |

## 容易做错的三处
- 启动容器后无法正常发起对话，界面提示未配置有效密钥。原因是未正确设置`ROOT_KEY`或`FILE_TOKEN_KEY`，导致系统内部权限校验失败。
- 执行`docker run --gpus all -itd -p 7231:7231`安装marker_images:v0.1时出现报错。原因是未在部署脚本中添加对应挂载参数，或宿主机未正确配置GPU驱动适配。
- 升级至FastGPT v4.17.0后，使用URL创建知识库报错，后台日志显示cannot fetch internal url。原因是未配置`FE_DOMAIN`为合法的内部访问地址，导致系统无法解析内部资源路径。

## 怎么确认配好了
- 登录系统后台，查看存储连接状态面板，确认`MONGODB_URI`与`REDIS_URL`的连接测试返回成功。
- 上传一份涂布辊压参数的测试文档，验证文件上传与解析流程无报错，且提取的字段符合电芯数据的格式规范。
- 发起一次单批次电芯数据的关联查询，确认查询流程无超时报错，返回结果与原始数据一致。
- 检查系统后台日志，无内部URL抓取失败的报错信息，确认`FE_DOMAIN`配置符合内部访问规则。
