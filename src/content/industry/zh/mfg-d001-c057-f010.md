# 锻造与模锻的供应商与过程质量审核：知识库检索与召回

## 这个品类的数据长什么样
本品类数据主要来自原材料质保书、加热炉系统、压力机采集数据、MES系统、无损检测仪及客户锻件图。日常生成的文档包含锻造工艺规程、下料卡、加热炉记录、锻造过程卡、模具寿命记录、热处理委托单、超声检测报告。数据更新以每件锻件、每批次或每炉次为节奏，包含炉批号、锻造比、纤维方向、检测缺陷类型等字段，部分来自工业系统的结构化数据，部分为纸质或电子格式的非结构化内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散且格式不统一，结构化工业系统数据与非结构化文档混合，要求检索系统支持多源数据适配。更新频率高且按批次绑定，需支持按炉批号、锻件批次快速定位关联文档。单批次数据关联多类文档，检索时需匹配锻件工艺、检测结果、生产记录的关联关系，避免召回无关内容。部分来自工业系统的实时数据，需保障检索响应速度匹配生产节奏，同时需准确识别锻造比、纤维方向等专业字段，确保召回内容贴合业务需求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配锻造专业术语与批次字段，避免召回无关的通用工艺文档 |
| `limit` | 前6条 | 覆盖单批次锻件关联的多类文档，同时控制上下文总长度 |
| `searchMode` | `mixedRecall` | 兼顾结构化的炉批号、批次号数据与非结构化的工艺规程、检测报告内容 |
| `usingReRank` | 开启 | 对召回结果按业务相关性重排，优先匹配锻造比、纤维方向等核心字段 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于原问题扩展批次、炉号相关检索词，提升召回精准度 |

## 容易做错的三处
- 现象：检索结果为空或仅返回少量无关文档。原因：未针对锻造专业字段配置`similarity`阈值，或未开启`datasetSearchUsingExtensionQuery`扩展批次检索词，无法匹配炉批号、锻件图等核心标识。
- 现象：私有化部署场景下，API调用`limit`参数设置超过6时无响应或返回错误。原因：未调整系统默认的单次检索上限配置，默认限制与单批次文档数量匹配，超出后触发参数校验失败。
- 现象：导入大于1 MB的热处理委托单或超声检测报告时失败。原因：未调整系统支持的单文件大小阈值，锻造类文档常包含大量检测数据，默认阈值无法覆盖。

## 怎么确认配好了
- 上传单批次锻件的下料卡、加热炉记录与超声检测报告，发起包含炉批号的检索，核对召回结果包含全部上传文档。
- 调用API设置`limit`为8，验证返回结果条数符合预期，无参数报错。
- 导入单份2.5 MB的超声检测报告，确认导入成功且可正常检索。
- 发起包含“纤维方向”的检索，核对召回结果优先返回匹配该字段的工艺规程文档。
