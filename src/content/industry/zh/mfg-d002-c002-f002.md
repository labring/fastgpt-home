# SMT贴片与电子组装的工艺文件与异常报告起草：向量模型与索引

本页适用于FastGPT v4.17.0版本。

## 这个品类的数据长什么样
SMT贴片与电子组装的日常数据包含BOM与坐标文件、换线表、钢网与炉温记录、首件确认报告、SPI/AOI检测报告、维修记录与追溯标签。数据来源包括客户提供的BOM、Gerber文件、生产MES系统、贴片机、SPI/AOI设备与回流焊炉温采集设备。数据更新频率为每工单、每次换线触发更新，实时采集的炉温与缺陷数据为实时更新。文档包含结构化字段如料号、位号、元件批次、坐标参数，以及非结构化的缺陷描述与维修记录，字段附带毫米、摄氏度等对应单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据更新频率高且实时性强，要求索引支持增量更新以避免全量重建带来的性能损耗。文档类型涵盖结构化与非结构化内容，切片时需保留料号、坐标等关键字段的完整性，避免语义断裂。多字段附带电子制造领域的专业术语与单位，向量模型需适配这类专业语义识别，确保检索结果的准确性。同时单工单数据量波动较大，索引的资源占用需匹配生产节奏，避免影响生产系统的正常运行。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配SMT文档的单段工艺描述长度，避免切片破坏料号、坐标等关键信息 |
| 重叠长度 | 100–150 字符 | 保留跨切片的关键关联信息，比如换线前后的工艺衔接内容 |
| 相似度阈值 | 0.75–0.85 | 区分工艺文件与异常报告的专业语义，避免误匹配非相关的缺陷记录 |
| `defaultToken` | 8192 | 适配长文档如完整BOM表的嵌入处理，符合行业文档的常规长度 |
| `maxToken` | 16384 | 支持批量嵌入多工单的工艺数据，避免截断关键内容 |
| 向量模型渠道 | 电子制造领域专用嵌入模型 | 适配SMT行业的专业术语与数据格式，提升嵌入与检索的准确性 |

## 容易做错的三处
- 现象：检索结果出现非对应工单的工艺文件。原因：未按工单ID关联索引分片，导致跨工单数据被误召回。
- 现象：嵌入任务触发超时报错。原因：未调整`maxToken`参数，长文档如完整钢网配置表被截断后嵌入失败，触发超时。
- 现象：异常报告的缺陷类型匹配准确率偏低。原因：未设置合理的相似度阈值，将语义相近但属于不同工序的缺陷记录混淆。

## 怎么确认配好了
- 上传单份工单的BOM与SPI报告，检索对应工艺参数，核对返回结果的工单编号是否匹配。
- 查看知识库磁盘占用，确认原文件、分割块与嵌入向量的存储占比符合预期。
- 测试增量更新一份换线表，验证索引是否自动刷新并能检索到最新内容。
- 调整相似度阈值，对比不同阈值下的检索结果，选择符合业务需求的取值。
