# SMT贴片与电子组装的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
SMT贴片与电子组装场景的数据来自客户提供的BOM、Gerber文件、元件坐标表，以及MES系统、贴片机、SPI/AOI检测设备、回流焊炉温记录仪的实时或工单级数据。日常文档包含换线表、首件确认报告、维修记录与追溯标签，字段涵盖料号、位号、元件批次、温度曲线参数、缺陷位置与类型等，更新频率为每工单、每次换线实时同步。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的实时工单数据要求模型接入需支持结构化文档解析与实时数据调用，频繁的工单级更新意味着上下文需严格限定在当前工单范围内，避免跨工单数据干扰。字段密集的工艺与异常文档要求模型输出需精准匹配料号、位号等特定字段，同时需适配不同设备导出的文档格式差异，确保数据提取的一致性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单工单的工艺文件、异常报告总数据量，避免超出模型上下文窗口限制 |
| `maxTokens` | 2000–3000 token | 满足完整工艺文件起草与异常分析报告的输出长度需求，防止结果截断 |
| `temperature` | 0.2–0.4 | 保持工艺描述与缺陷分析的准确性，降低主观偏差对结果的影响 |
| `toolChoice` | auto | 自动调用文档解析工具，提取BOM、坐标文件等结构化数据中的关键字段 |
| `AIPROXY_API_ENDPOINT` | http://localhost:8080/v1 或对应云服务商接入地址 | 适配SMT场景的低延迟数据处理需求，保障实时工单处理的响应速度 |
| `AIPROXY_API_TOKEN` | 平台生成的专属接入令牌 | 保障模型接入权限安全，防止未授权调用影响生产数据 |

## 容易做错的三处
- 本地部署14B模型后，添加工单数据调用异常报告起草功能报错，返回500状态码或「上下文溢出」提示，原因是未调整`maxContext`参数适配本地模型的上下文窗口限制。
- 系统模型下拉列表无已配置的本地模型选项，无法选中目标模型，原因是未正确配置`AIPROXY_API_TOKEN`或接入地址格式不符合要求。
- 工艺文件起草结果缺失料号、位号等关键字段，原因是未开启`toolChoice`自动解析功能，导致结构化文档中的核心数据未被提取。

## 怎么确认配好了
- 上传单工单的BOM与SPI报告文件，调用起草功能，检查输出结果是否包含对应料号、缺陷类型等字段。
- 查看FastGPT v4.17.0的模型接入日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的请求状态码为200。
- 调整`temperature`参数值，对比两次输出结果，确认参数调整对结果的影响符合预期。
- 测试跨工单的上下文隔离，上传不同工单的数据后调用功能，检查输出未包含其他工单的冗余数据。
