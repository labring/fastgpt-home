# 乳制品加工的工艺文件与异常报告起草：引用来源与溯源

## 这个品类的数据长什么样
该品类覆盖液态奶、酸奶、奶粉及乳配料加工全流程，日常文档包含原奶验收记录、标准化配料单、巴氏/UHT热处理记录、CIP清洗记录、灌装记录、留样与微检报告。数据来源涵盖奶源检测设备、生产MES系统、均质与热处理在线传感器、CIP系统及LIMS实验室管理平台，更新节奏按单奶罐、生产批次实时同步，文档字段包含检测数值、设备参数、时间戳、批次编号，单位多为摄氏度、升、菌落总数cfu/mL等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
由于数据按单罐、批次实时更新，引用溯源需绑定唯一批次编号与时间戳，避免跨批次数据混淆。多源异构数据来自设备、系统与实验室，需明确各来源的字段映射规则，确保引用时可精准匹配原数据节点。实时更新的温流量、热处理参数需支持秒级溯源，无法依赖静态分块缓存。同时，乳制品易腐特性要求溯源结果需关联留样与微检报告，验证异常判定的合规性，不能脱离原始检测记录。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | 匹配单批次乳制品文档的平均长度，确保完整引用原奶验收、热处理记录的核心内容 |
| `responseData` | 开启 | 允许返回原始文档的字段与溯源链接，匹配乳制品加工需验证批次参数的业务需求 |
| `detail` | 开启 | 展开引用来源的具体字段，如原奶的抗生素检测值、CIP清洗的温度时长 |
| 最大上下文 | 前10轮对话 | 覆盖从原奶验收到灌装的完整工艺链路，确保多轮工艺判定的上下文连贯 |
| 单次搜索上限 | 前6条 | 匹配单批次生产的关联文档数量，避免冗余数据干扰异常报告起草 |
| 重排 | 按实测标定 | 根据不同生产批次的文档结构调整排序规则，优先匹配当前工艺环节的核心数据 |

## 容易做错的三处
- 现象：生成工艺文件或异常报告时仅返回引用链接，无正文内容。原因：未开启`responseData`配置，仅返回了溯源索引未加载原始文档内容。
- 现象：免登录分享链接访问应用时，引用查看功能无法正常显示。原因：FastGPT v4.17.0版本中，免登录分享的溯源权限未同步开启，需在应用配置中单独勾选溯源显示开关。
- 现象：多轮对话中无法关联前序批次的原奶验收或配料数据。原因：未配置最大上下文覆盖多轮工艺链路，仅调用了当前单轮的搜索结果。

## 怎么确认配好了
- 生成单批次原奶验收的工艺文件，检查返回结果中是否包含原始文档的字段内容与溯源链接。
- 模拟多轮工艺讨论，确认后续生成的异常报告可关联前序的配料、热处理记录。
- 生成异常报告后，点击引用链接，验证是否可跳转至对应原始文档的详情页面。
- 测试免登录分享链接，确认引用查看功能可正常加载原始数据。
