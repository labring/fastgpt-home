# 光伏电池片制造的工艺文件与异常报告起草：HTTP 接口与外部系统

## 这个品类的数据长什么样
通常晶硅电池片制造的工艺与异常相关数据，来自硅片来料台账、车间MES系统、扩散炉/镀膜设备/印刷机的运行日志、EL与IV测试设备的检测结果，以及实验室品质分析数据。日常产出的文档包含工艺卡、扩散与镀膜参数表、印刷烧结过程记录、EL缺陷检测图、IV性能分档数据、批次良率报告。数据更新节奏随生产节点变化，每批次物料对应一份工艺文件，每片电池片的EL、IV检测结果实时上传，每日汇总生成全车间良率与异常汇总报告。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多源异构的数据来源要求接口支持跨系统的参数拉取与格式转换，不同设备与系统的时间戳、字段命名存在差异，需在接口配置中统一数据映射规则。高频更新节奏要求接口支持批量拉取与实时回调，避免因轮询延迟导致工艺参数同步不及时。多样的文档类型需要接口兼容结构化参数表、非结构化检测图与数值报告的上传与解析，同时需适配光伏工艺参数的高精度校验要求，避免因字段精度不足影响工艺窗口控制。

## 配置怎么定
本页面配置说明基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | Bearer {生产环境专属密钥} | 遵循HTTP接口鉴权标准，隔离生产与测试环境的数据访问 |
| `variables` | 绑定批次号、设备SN参数 | 精准拉取对应光伏电池片批次的工艺与检测数据 |
| `responseData` | 按字段映射为扩散温度、IV效率值 | 统一多源异构数据的输出格式，适配异常报告的自动生成 |
| 接口超时阈值 | 900 秒 | 适配多源数据合并与解析的耗时，避免高频生产场景下的接口中断 |
| 批量拉取上限 | 前 15 条 | 匹配每日汇总的生产数据规模，避免接口资源占用过高 |
| 数据校验精度 | 保留 0.1 单位 | 符合光伏工艺参数的管控要求，避免精度误差影响工艺窗口 |

## 容易做错的三处
-  调用接口返回401未授权错误，排查发现未正确配置`Authorization`参数或关联的环境变量。原因是未遵循FastGPT的鉴权规范，导致接口无法通过身份校验。
-  拉取数据后返回字段为空，排查发现`variables`中绑定的批次号参数与车间MES系统的命名规则不匹配。原因是未结合光伏生产的批次管控逻辑配置参数，导致无法精准匹配目标生产数据。
-  上传工艺文件后接口返回解析失败，排查发现未配置对应文档类型的解析规则。原因是未适配光伏电池片制造的多样文档格式，无法正确识别工艺卡、EL检测图等文件内容。

## 怎么确认配好了
-  在FastGPT v4.17.0的后台接口配置页面，填写并保存`Authorization`参数，调用接口后检查返回状态码为200。
-  提交绑定有效批次号的请求，确认`responseData`返回的字段与MES系统中对应批次的扩散温度、IV效率值一致。
-  上传一份印刷烧结记录文件至接口，检查接口返回的解析结果包含预设的工艺参数字段。
-  连续调用接口5次，验证未出现超时或鉴权失败的情况，确认限流与超时配置生效。
