# 光伏电池片制造的工艺文件与异常报告起草：知识库检索与召回

## 这个品类的数据长什么样
通常来自硅片来料记录、生产MES系统、扩散炉/镀膜设备/印刷机的运行数据、EL与IV测试结果、实验室分析数据。更新节奏按生产批次、单片检测结果实时更新，每日汇总生产与品质数据。日常文档包含工艺卡、扩散和镀膜参数表、印刷烧结记录、EL检测图、IV分档数据、良率报告，包含批次号、工艺参数值、检测结果、分档等级等字段，单位涉及电压、电流、转换效率百分比等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源要求检索模块支持跨系统数据的关联召回；高频更新的生产与检测数据，需要适配实时或准实时的检索刷新机制；多样的文档类型（结构化参数表、可视化检测图、文本报告），需要兼容不同格式的内容解析与向量建模；单批次生产的强关联性，要求检索时优先召回同批次关联的工艺与检测数据，保障异常追溯的准确性；工艺参数的高精度要求，使得检索的匹配精度需要适配细分的数值范围。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配光伏工艺参数的高精度要求，避免召回无关的批次数据 |
| `limit` | 前8条 | 平衡检索效率与召回覆盖，保障异常报告起草的上下文充足 |
| `searchMode` | `mixedRecall` | 结合语义与关键词匹配，适配结构化参数表与非结构化检测报告的混合检索 |
| `usingReRank` | 开启 | 对初始召回结果重排，优先匹配异常现象对应的核心工艺参数 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展光伏专业术语的同义词，适配行业专属表述 |
| `collectionIds` | 按生产、设备、品质部门绑定的专属知识库集合 | 隔离不同部门的文档，避免跨部门检索干扰 |

## 容易做错的三处
- 现象：调用知识库检索时返回404状态码。原因：未正确绑定指定知识库集合，或未在对应FastGPT版本下执行初始化脚本。
- 现象：检索结果为空或无匹配的工艺参数。原因：未开启`datasetSearchUsingExtensionQuery`，无法识别光伏专业术语的同义词扩展。
- 现象：检索返回的结果条数超出预期。原因：未正确设置`limit`参数，或配置了超出服务器资源承载的召回上限。

## 怎么确认配好了
- 查看知识库检索的系统日志，确认返回结果包含目标部门的工艺与检测文档。
- 模拟异常场景的检索，验证结果是否优先召回同批次的关联生产数据。
- 调整`similarity`参数，通过多组测试确认匹配精度适配工艺参数的检索需求。
- 确认当前部署的FastGPT版本为v4.17.0，与知识库配置的兼容要求一致。
