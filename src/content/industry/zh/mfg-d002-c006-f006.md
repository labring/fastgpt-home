# 光伏组件封装的工艺文件与异常报告起草：引用来源与溯源

## 这个品类的数据长什么样
光伏组件封装环节的数据来自电池片分档系统、玻璃胶膜背板批次台账、工厂MES系统、串焊与层压生产设备、EL隐裂检测仪及IV功率测试仪。日常产出的文档包含排版图、材料批次记录、层压工艺参数记录、EL缺陷图、IV测试报告、绝缘耐压检测记录、成品包装清单。数据更新节奏为每一块组件对应一套测试记录，每批次原材料生成对应批次台账，字段包含材料型号、生产批次、设备运行参数、检测数值、操作人员标识等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
光伏组件封装的多源数据特征，为引用溯源环节带来多重约束。数据分散于生产设备、检测仪器与管理系统，需精准匹配电池片分档、材料批次、生产参数的时间戳与关联字段，确保溯源时不会跨批次混淆数据，避免因数据错位导致后续功率不达标、层压脱层等质量问题。单组件对应高频更新的测试记录，需限定引用的时间范围，避免调用过期的批次台账。日常文档包含图像类EL缺陷图与数值类IV测试报告，需支持不同格式数据源的关联引用，保证异常报告起草时可同时调取可视化缺陷记录与量化检测数据。

## 配置怎么定
本页面适用FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | 光伏组件封装的工艺文件与异常报告需引用多组检测数据、批次记录，该token范围可覆盖单份完整检测报告的引用需求，避免截断关键信息。 |
| `responseData` | 返回关联文档元数据 | 需在异常报告中体现引用的材料批次、测试报告来源，开启该配置可将文档的批次号、检测时间等元数据同步至输出内容。 |
| `detail` | 开启 | 工艺文件与异常报告需详细关联EL图、IV测试数据等细节内容，开启后可召回更精准的细分数据源。 |
| 单次搜索上限 | 前6条 | 单份异常报告需关联的数据源通常不超过5组，前6条可覆盖全部关联需求，避免冗余信息干扰。 |
| 响应超时时间 | 300 秒 | 光伏组件封装的数据源多部署于工厂内网，300秒可覆盖多源数据的召回与关联耗时，避免中途超时。 |
| 文档分块大小 | 1000–1500 字符 | 单份光伏组件检测报告的文本长度通常处于该区间，分块后可保证数据完整，避免截断关键参数。 |

## 容易做错的三处
- 正式输出的异常报告中未显示引用的文档来源，仅调试页面可见。原因：未正确开启`responseData`配置，或配置项未关联至输出模板的引用展示模块。
- 引用的数据源条数超出预期，无法限制为固定条数。原因：未按业务需求配置单次搜索上限，或误将分数阈值作为条数限制条件。
- 引用的EL图数据无法正常关联至工艺文件。原因：未开启`detail`配置，或数据源的关联字段未正确匹配，导致无法召回图像类检测记录。

## 怎么确认配好了
- 进入调试界面，输入光伏组件异常报告起草的需求，查看输出内容中是否包含引用的文档元数据，如材料批次号、检测报告编号。
- 调整`quoteMaxToken`的取值，观察输出内容的引用长度变化，确认配置生效。
- 测试调用不同类型的数据源，如EL图与IV测试报告，确认两种格式的数据均可被正常引用。
- 切换至正式发布的聊天界面，验证引用信息是否与调试界面一致。
