# 光伏组件封装的工艺文件与异常报告起草：知识库检索与召回

## 这个品类的数据长什么样
该品类数据来自电池片分档系统、玻璃胶膜背板批次台账、MES生产管理系统、串焊与层压设备日志、EL/IV测试仪输出文件。日常文档包含排版图、材料批次记录、层压工艺记录、EL隐裂图、IV测试报告、绝缘耐压记录、包装清单。数据按每块组件、每批材料实时更新，单份文档包含批次号、电流档位、工艺参数、测试数值等字段，部分图文类文档需关联对应批次的生产记录。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的高频实时更新数据，要求知识库检索需匹配生产节奏，避免召回过期的材料批次或工艺参数。多类型文档并存的场景，要求检索支持图文、数值报表、设备日志的跨模态匹配，精准关联EL隐裂图与对应层压工艺记录。固定字段如批次号、电流档位的存在，要求检索需基于特定字段精准匹配，减少无关结果的干扰。生产环节与测试数据的强绑定关系，要求召回结果需同时关联串焊、层压等工序与IV测试数值，确保起草的异常报告逻辑连贯。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配批次号、电流档位等精准字段，过滤低相关的召回结果 |
| `limit` | 前8–12条 | 单批次关联文档数量有限，过多结果会超出上下文承载上限 |
| `usingReRank` | 开启 | 区分图文类EL图与数值类测试报告的相关性，优先召回匹配异常关键词的内容 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充光伏封装专业术语，如串焊温度、层压气泡阈值，提升检索精准度 |
| `searchMode` | 精准匹配 | 基于批次号、设备编号等字段定向检索，避免全文模糊匹配的干扰 |

## 容易做错的三处
- 上传飞书关联知识库文档时出现“Request failed with status code 400”报错。原因是未正确配置飞书开放平台的应用权限，或上传的文档包含系统未授权访问的字段，导致接口调用触发参数错误。
- 自定义分块长度时设置不合理的数值。原因是未结合光伏封装文档的图文混合特征，若分块长度过短会拆分EL隐裂图与对应工艺参数，过长则导致上下文冗余，影响检索精度。
- 检索返回的结果包含大量非当前批次的文档。原因是未设置`limit`参数的合理取值，或未开启精准匹配模式，召回了过多无关的历史批次数据。

## 怎么确认配好了
- 上传一份当前批次的层压工艺记录与EL隐裂图，发起检索请求，核对召回结果是否包含关联的材料批次台账。
- 触发异常报告起草的模拟请求，查看检索返回的文档数量，确认符合`limit`参数设置的取值范围。
- 检查检索结果的相关性，确认低匹配度的无关文档已被`similarity`阈值过滤。
- 验证飞书知识库的文档导入流程，确认无400报错出现，确保文档已成功同步至知识库。
