# 光伏组件封装的工艺文件与异常报告起草：部署与升级

## 这个品类的数据长什么样
光伏组件封装环节的数据来源于电池片分档、玻璃胶膜背板批次台账、生产MES系统、串焊与层压设备、EL缺陷检测仪、IV功率测试仪。数据更新频率为每块组件、每批材料生成一次，日常需处理的文档包括排版图、材料批次记录、层压工艺记录、EL缺陷图像、IV测试报告、绝缘耐压记录、成品包装清单。数据字段包含电池片电流档位、层压温度与时间、EL隐裂位置坐标、IV功率值、绝缘电阻值等，对应单位包括摄氏度、秒、瓦、兆欧等。

## 这些特征在「部署与升级」这一环带来什么约束
高频次的单组件、单批次数据更新，要求部署时配置足够的数据库连接池与缓存资源，避免读写阻塞影响生产节奏。多类型的文档与图像数据，要求适配不同格式的文件解析与存储方案，需对接企业内部的对象存储服务。字段的特定单位与业务含义，要求配置字段映射规则时匹配光伏封装的行业标准，不能直接使用通用映射逻辑。升级环节需预留与现有生产设备、MES系统的对接兼容性，避免因配置变更导致生产数据同步中断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30 个连接` | 适配高频读写的组件数据、测试报告等业务场景，避免连接池耗尽 |
| `MONGODB_URI` | `mongodb://<user>:<pass>@<host>:<port>/<dbname>?authSource=admin` | 存储批量的EL缺陷图像、IV测试报告等非结构化文档 |
| `REDIS_URL` | `redis://:<password>@<host>:<port>/0` | 缓存实时的材料批次、电池片分档数据，缩短字段映射的查询耗时 |
| `STORAGE_S3_ENDPOINT` | `按企业内部对象存储服务地址填写` | 存储工艺文件、测试记录等批量文件，降低本地存储压力 |
| `FILE_TOKEN_KEY` | `随机生成的32位字符串` | 保护文件上传接口，防止未授权的文件提交 |
| `ROOT_KEY` | `按部署环境配置的专属密钥` | 初始化FastGPT v4.17.0平台的管理员权限，保障后台配置安全 |

## 容易做错的三处
- 现象：部署后控制台出现`TypeError: Cannot read properties of undefined`报错，原因是未正确配置`FILE_TOKEN_KEY`，导致文件解析时令牌校验失败。
- 现象：对接one API时登录报用户名密码错误，原因是未将`REDIS_URL`配置为与one API共享的缓存实例，导致会话存储异常。
- 现象：使用docker compose部署时返回`Error response from daemon`报错，原因是未为`MONGODB_URI`配置正确的数据库访问权限，导致数据库连接失败。

## 怎么确认配好了
- 执行`docker ps`命令，查看所有FastGPT相关容器均处于运行状态，无异常退出记录。
- 上传一份层压工艺记录PDF文件，验证解析后可提取电池片电流档位、层压温度与时间等核心业务字段。
- 调用文件上传接口，验证返回的令牌可通过`FILE_TOKEN_KEY`的校验规则，无权限报错。
- 查看数据库连接日志，确认当前数据库连接数未超过`DB_MAX_LINK`的配置上限，无连接耗尽告警。
