# 化妆品生产的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
化妆品生产的工艺与异常数据主要来自注册或备案配方、原料安全资料、称量与乳化设备、ERP/MES系统、实验室检测记录及包材版本信息。日常文档包含配方工艺单、称量投料记录、乳化或灌装记录、清场清洁记录、半成品与成品检验报告、标签审核文件。数据更新节奏为每批生产或每次换线触发，文档字段包含限用物质含量、工艺温度参数、批号、包材规格等，所有数据均随对应生产批次动态更新。

## 这些特征在「模型接入与配置」这一环带来什么约束
化妆品生产的工艺与异常数据随每批生产或换线动态更新，要求模型接入配置需支持实时关联最新的备案配方、生产记录等数据，避免使用过期信息。文档包含限用物质含量、标签宣称等强合规字段，要求配置优先召回准确的备案数据源，降低生成内容的合规风险。单批生产的文档总量适中但字段针对性强，需控制上下文长度以避免无关数据干扰生成结果。同时，出错后果涉及下架召回等合规风险，要求配置强化参数稳定性，减少生成错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 需容纳单批生产的全量工艺文档与备案数据，避免截断关键的限用物质、配方合规信息 |
| `maxTokens` | 3500–4500 token | 控制单份工艺文件或异常报告的生成长度，匹配化妆品生产文档的常规篇幅 |
| `quoteMaxToken` | 1800–2200 token | 限定召回知识库内容的总长度，优先保留备案配方、原料安全资料等核心合规数据 |
| `temperature` | 0.1–0.3 | 降低生成随机性，确保工艺参数、批号、合规字段等内容的准确性 |
| `toolChoice` | auto | 自动触发知识库检索，适配每批生产的动态数据更新需求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配本地或私有云部署的API地址，确保生产数据不出域 |
| `AIPROXY_API_TOKEN` | 按实测标定 | 保证接口调用的安全性，避免未授权访问 |

## 容易做错的三处
-  索引模型配置错误，表现为调用时返回401状态码或空结果，原因是未正确填写`AIPROXY_API_TOKEN`或`AIPROXY_API_ENDPOINT`参数，或参数格式不符合部署要求。
-  知识库为空时工作流仍触发检索，表现为生成结果中出现无关的通用问答内容，原因是未配置空知识库的跳过检索逻辑，导致模型调用通用能力生成非生产相关内容。
-  版本升级后模型调用失败，表现为返回超时或参数校验失败提示，原因是沿用了FastGPT v4.17.0之前版本的非标准配置，未适配新版本的参数校验规则。

## 怎么确认配好了
-  提交单批化妆品生产的配方工艺单，核对生成的工艺文件是否包含备案的限用物质信息与正确的工艺参数。
-  模拟知识库为空的场景，触发异常报告起草工作流，确认未返回无关的检索结果。
-  查看接口调用日志，确认`maxContext`、`temperature`等配置参数的实际调用值与预设值一致。
-  测试标签审核相关的文档生成，确认生成内容符合化妆品标签的合规要求。
