# 化学药制剂生产的工艺文件与异常报告起草：HTTP 接口与外部系统

## 这个品类的数据长什么样
化学药制剂生产的相关数据来源包括经批准处方工艺、MES电子批记录、设备与环境监测系统、LIMS系统及质量管理系统。数据更新频率为每生产批次、每个关键工艺步骤执行时，以及按固定监测计划更新。日常文档包含主生产文件、批生产记录、批包装记录、清场记录、检验记录、偏差/CAPA/变更文件及批放行审核表，核心字段涵盖物料批次号、工艺参数值、检验结果、偏差描述与整改措施等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
化学药制剂生产的多系统数据来源、批次级更新频率及GMP合规要求，为HTTP接口与外部系统集成带来多项约束。需对接MES、LIMS、质量管理系统等多个数据源，接口字段需严格匹配各系统的输出格式，避免数据不匹配导致的文档生成错误。批次级的更新频率要求接口支持可变入参，适配不同生产批次的物料、工艺参数与检验数据。GMP下文件与操作同步的要求，需保证接口调用与生产环节实时联动，同时需支持异常数据的实时回传，确保偏差与整改记录可完整追溯。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 请求超时时间 | 300–600 秒 | 适配多系统数据拉取的延迟，避免因生产环节等待超时中断流程 |
| 可变入参配置 | 支持批次号、物料批次、工艺参数三类字段 | 匹配每批生产的动态数据需求，适配不同生产批次的参数差异 |
| `Authorization` | 按系统权限生成临时令牌 | 保证接口调用的权限合规，符合GMP下的操作追溯要求 |
| 响应数据校验规则 | 校验必选字段完整性 | 确保拉取的MES、LIMS数据包含批记录所需的核心信息 |
| 响应提取方式 | 按实测标定 | 适配FastGPT v4.17.0及以上版本的响应格式，避免提取逻辑不兼容 |
| 触发时机配置 | 按生产步骤完成信号触发 | 匹配GMP下文件与操作同步的要求，确保文档生成与生产进度一致 |

## 容易做错的三处
- 现象：调用集成外部系统的工作流接口时返回空值。原因：未正确配置`variables`入参，未传递生产批次号等核心动态参数，导致外部系统无法返回对应数据。
- 现象：HTTP请求返回的结构化数据或异常记录无法正常提取。原因：未适配FastGPT版本更新后的返回值提取规则，如v4.8.12-beta及以上版本的响应提取逻辑变更，导致无法匹配预设的提取路径。
- 现象：接口调用时无法传入动态调整的入参。原因：未在工作流配置中开启动态入参绑定，导致入参固定无法适配不同生产批次的物料与工艺数据。

## 怎么确认配好了
- 发起模拟调用，传入测试批次的物料批次号，核对接口返回的字段是否包含批生产记录所需的核心信息。
- 检查`Authorization`令牌的生成逻辑，确认仅授权用户可触发接口调用，且调用记录可追溯。
- 触发模拟生产步骤完成信号，确认工作流自动调用接口并生成对应工艺文件或异常报告。
- 模拟异常数据回传，确认偏差记录可正确同步至质量管理系统的接口中。
