# 半导体封装测试的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
半导体封装测试的日常文档包含封装流程卡、键合与塑封参数、晶圆来料图、测试程序版本、良率报告、失效分析报告。数据来源包括晶圆测试图、MES系统、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格。数据更新频率为每批晶圆、每颗测试结果、每日汇总。文档字段涵盖批次号、参数阈值、bin码、失效类型等，涉及电压、电流、封装厚度等专业单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据多源异构且更新频率高，要求模型接入环节适配不同设备与系统的输出格式，避免格式不兼容导致的解析失败。文档包含大量专业工艺参数与失效编码，配置时需预留自定义字段映射的空间，确保模型能准确识别专业术语。细粒度的更新节奏（每批、每颗测试、每日）要求控制模型上下文长度，避免冗余数据占用过多token配额。同时，工艺文件与异常报告的关联分析需求，要求配置环节支持多文档关联调用，需合理设置模型调用的参数。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配该品类单批次工艺文件与异常报告的总长度，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 控制单轮起草输出的长度，匹配工艺文档的常规撰写需求 |
| `quoteMaxToken` | 1500–2000 字符 | 保留足够的源文档片段用于对齐晶圆测试图与测试结果，避免上下文过载 |
| `temperature` | 0.3–0.5 | 保障工艺参数与失效描述的准确性，降低随机输出的概率 |
| `AIPROXY_API_ENDPOINT` | 供应商提供的专属接入地址 | 适配多源设备与系统的数据格式转换，解决跨数据源接入的问题 |
| `AIPROXY_API_TOKEN` | 绑定的专属访问令牌 | 保障模型接入的安全性与权限可控性 |

## 容易做错的三处
- 现象：界面弹出「当前分组 default 下对于模型 qwq:latest 无可用渠道」的报错。原因：未在模型渠道配置中绑定对应模型的接入权限，或`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置错误，无法拉取有效渠道列表。
- 现象：模型调用返回的工艺文件片段缺失专业参数字段。原因：`quoteMaxToken`设置过小，未保留足够的源文档片段用于提取封装参数与测试bin码。
- 现象：ollama部署的本地模型无法正常调用，端口500被占用。原因：未关闭占用该端口的其他服务，或未在FastGPT配置中正确指定本地模型的接入地址，导致连接失败。

## 怎么确认配好了
- 进入FastGPT v4.17.0的模型渠道管理页面，验证`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置与供应商提供的信息一致。
- 发起一次测试调用，使用封装流程卡与良率报告作为输入，检查返回的工艺文件片段是否包含该品类特有的专业字段与参数。
- 查看模型调用日志，确认`maxContext`与`maxTokens`的参数未触发上下文溢出或输出截断的报错。
- 针对本地部署的模型，检查端口占用情况，确认接入地址与端口配置与部署环境匹配。
