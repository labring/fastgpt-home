# 半导体晶圆制造的工艺文件与异常报告起草：工具调用与插件

## 这个品类的数据长什么样
半导体晶圆制造的工艺与异常数据主要来自MES系统、设备FDC监控模块、缺陷检测与量测设备、晶圆图文件、工艺配方库及实验数据。日常产出的文档包含工艺流程卡、批次运行记录、设备配方、SPC控制图、异常处置单、缺陷图谱、良率报告等，字段包含晶圆批次号、工艺参数（温度、压强等，单位为摄氏度、帕斯卡）、缺陷坐标、良率数值等。数据更新节奏分为每批晶圆、实时及每日三类，覆盖从工序执行到批次收尾的全流程。

## 这些特征在「工具调用与插件」这一环带来什么约束
晶圆制造的数据来源分散且格式各异，要求工具调用插件支持多数据源的关联拉取与格式转换；数据更新节奏覆盖实时到批次级，要求工具触发时机匹配不同数据的更新周期，避免延迟或冗余拉取；工艺链长且参数耦合度高，要求工具调用需覆盖数百道工序的参数整理与跨模块归因，同时需控制调用时长以适配有限的返工窗口；工艺报告面向一线制造人员，要求工具输出简化技术细节，仅保留核心结论。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | 强制调用指定工具集 | 适配晶圆制造多工序关联的工艺文件生成，避免模型自主选择工具遗漏关键环节 |
| `functionCall` | 启用结构化函数调用 | 适配结构化的工艺参数提取与异常归因，确保输出格式符合工艺报告要求 |
| 最大工具调用次数 | 8–12次 | 覆盖数百道工序的参数整理与异常归因，避免调用不足无法完成全流程报告 |
| 超时阈值 | 600–900秒 | 匹配实时设备数据拉取与SPC图分析的耗时，适配每批晶圆的处理节奏 |
| 上下文窗口大小 | 8000–12000 token | 适配多份工艺文档与异常数据的整合，避免上下文溢出 |
| 工具输出展示 | 隐藏工具输入与响应内容 | 简化最终报告的可读性，符合工艺人员的阅读习惯 |
| 数据源绑定规则 | 绑定当前晶圆批次的MES与设备数据 | 确保工艺文件与异常报告的数据源匹配当前批次，避免跨批次数据混淆 |

## 容易做错的三处
- 工具调用超时，耗时超过600秒但仅返回部分异常数据。原因是未限制数据源范围，拉取了全量历史晶圆批次的工艺数据，超出平台处理上限。
- 配置数据库连接插件后触发报错。原因是未绑定晶圆制造专属的MES或设备数据源表，字段匹配不符合工艺参数的格式要求。
- 工具调用输出展示了完整的工具输入与响应内容。原因是未开启输出过滤配置，导致报告中混入过多技术细节，不符合工艺人员的阅读习惯。

## 怎么确认配好了
- 触发一次单批次晶圆的工艺文件生成，检查工具调用日志是否仅关联当前批次的数据源。
- 运行异常报告起草任务，查看工具调用的耗时是否处于预设的600–900秒范围内。
- 查看最终生成的报告，确认工具调用的输入与响应内容未被展示。
- 测试触发多工序关联的异常归因任务，检查工具调用次数是否在8–12次的预设范围内。
