# 半导体晶圆制造的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自MES系统、设备FDC模块、缺陷检测与量测设备、晶圆图文件、工艺配方库与实验数据集。日常文档包含工艺流程卡、批次运行记录、设备配方、SPC控制图、异常处置单、缺陷图谱与良率报告。数据更新以每批晶圆为基础周期，同时伴随实时参数采集与每日汇总统计，字段多包含纳米级工艺参数、批次标识、缺陷空间坐标与良率占比等。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类多源、高频更新的数据集，要求模型接入环节需适配短周期、高并发的参数调用需求。纳米级工艺参数与空间分布类字段的专业属性，要求配置环节需适配模型的专业术语识别能力。批次级与实时更新的数据体量，要求上下文管理需限制单轮输入的总token量，避免超出模型承载上限。同时异常报告的严谨性要求，需严格控制模型的随机输出幅度，避免生成不符合工艺规范的内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 适配单批次晶圆的多源文档总长度，避免截断关键工艺参数与缺陷数据 |
| `maxTokens` | `2000–3000 token` | 限制单轮输出的异常报告或工艺文件长度，确保符合工厂文档的排版规范 |
| `temperature` | `0.1–0.3` | 降低随机输出幅度，保障工艺描述与异常判读的严谨性，匹配晶圆制造的高合规要求 |
| 工作流/API 工具选择配置 | `auto` | 允许模型自主选择是否调用工具处理实时设备参数，适配动态更新的工艺数据 |
| `vision` | `enabled` | 适配晶圆图等视觉类文档的缺陷识别需求，处理缺陷图谱与SPC图的判读任务 |
| `AIPROXY_API_ENDPOINT` | 对应部署模型的接入地址 | 适配云上或本地私有化部署的模型渠道，确保数据传输路径合规 |
| `AIPROXY_API_TOKEN` | 与部署模型一致的鉴权密钥 | 保障模型接入的权限合法性，避免测试时出现权限报错 |

*注：本文档基于FastGPT v4.17.0版本编写*

## 容易做错的三处
- 现象：配置后模型仍输出思考过程内容。原因：未在模型渠道配置中关闭思考过程输出开关，或模型本身默认携带思考过程输出。
- 现象：在FastGPT中测试OneAPI接入的本地DeepSeek8B时出现权限报错。原因：FastGPT的`AIPROXY_API_TOKEN`配置与OneAPI生成的鉴权密钥不匹配，或未开放对应端口的出站权限。
- 现象：上传晶圆图文件后模型无法识别缺陷分布。原因：未开启`vision`配置项，或上传的晶圆图格式不符合模型支持的规范。

## 怎么确认配好了
- 核对`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置，在FastGPT的模型测试页面发起单次调用，查看返回结果是否包含鉴权成功的日志。
- 调整`temperature`至0.1，发起3次相同的异常报告生成请求，核对输出内容的一致性，确认随机输出幅度符合预期。
- 上传一份单批次晶圆的工艺文档与缺陷图谱，测试`maxContext`配置下的输入是否被正常接收，未出现截断提示。
- 检查`toolChoice`的配置，发起包含设备参数的查询请求，确认模型是否按配置自主选择调用工具或直接生成内容。
