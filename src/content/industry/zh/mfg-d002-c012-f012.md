# 半导体晶圆制造的工艺文件与异常报告起草：部署与升级

## 这个品类的数据长什么样
该品类的数据主要来自工厂MES系统、设备FDC监控模块、缺陷检测与量测设备、晶圆图数据库、工艺配方库与实验数据集。日常产出的文档包含工艺流程卡、批次运行记录、设备配方、SPC控制图、异常处置单、缺陷图谱与良率报告。数据更新按生产批次触发，设备参数实时采集，汇总类报表每日更新，字段包含晶圆唯一标识、工序纳米级参数、批次良率、缺陷空间分布坐标等。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据多源异构且更新频率跨度大，部署时需适配MES、设备FDC等不同数据源的接入协议，同时支持自定义字段解析以适配纳米级工艺参数、缺陷坐标等特殊字段。生产过程中数据连续性要求高，升级环节需支持增量更新，避免中断正在运行的晶圆批次数据流转。异常报告生成需匹配生产节拍，部署时需限制并发连接数与响应延迟，防止影响产线正常运行。此外，大量高维度工艺与缺陷数据需适配专用的存储配置，避免基础存储资源不足。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 100–150 条 | 适配多源数据接入与高并发的工艺数据查询需求，避免数据库连接耗尽 |
| `MONGODB_URI` | 带认证信息的专属集群连接串 | 存储晶圆缺陷图谱、批次运行记录等非结构化高维度数据，需专用集群保障读写性能 |
| `PG_URL` | 关联业务数据库的只读实例地址 | 存储工艺流程卡、良率报告等结构化业务数据，只读实例避免写入冲突 |
| `REDIS_URL` | 本地缓存集群连接地址 | 缓存实时采集的设备FDC参数与临时生成的异常报告草稿，降低重复查询延迟 |
| `STORAGE_S3_ENDPOINT` | 企业专属对象存储节点地址 | 存储晶圆图、工艺配方库等大体积文件，满足批量数据存储需求 |
| `ROOT_KEY` | 随机生成的32位字符串 | 保障系统内部接口调用的权限安全，防止未授权访问工艺数据配置 |

## 容易做错的三处
- 现象：接入企业内部通讯工具后出现接口调用失败，日志返回403状态码。原因：未配置`FILE_TOKEN_KEY`，导致请求签名验证不通过，触发平台安全拦截。
- 现象：跨版本升级后，历史晶圆批次数据无法正常加载。原因：未执行中间版本的升级脚本，直接覆盖部署导致数据结构不兼容。
- 现象：配置本地大模型服务后，无法正常生成异常报告。原因：未正确配置模型服务地址，强制绑定公开接口导致本地网络访问受限。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`DB_MAX_LINK`配置的连接数可稳定维持在设定区间内。
- 上传一张晶圆图文件，验证`STORAGE_S3_ENDPOINT`配置的存储节点可正常完成上传与下载操作。
- 触发一条异常报告生成任务，核对`REDIS_URL`配置的缓存节点是否缓存了临时生成的草稿数据。
- 登录系统后台查看权限日志，确认`ROOT_KEY`配置的校验规则未拦截合法的内部接口调用。
