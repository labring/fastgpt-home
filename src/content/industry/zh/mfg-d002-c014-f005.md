# 印染与后整理的工艺文件与异常报告起草：工具调用与插件

## 这个品类的数据长什么样
该品类的数据来自客户色样、配方库、染化料批次记录、染缸控制系统、测色仪、定形机及环保监测设备。日常文档包含染色配方、称化料记录、染缸温度曲线、打样确认单、色差报告、定形工艺单与污水台账。数据按每缸、每批或每班更新，单批次数据包含批次号、染化料参数、工艺曲线、检测数值与排放指标，字段单位涵盖℃、g/L、mg/L等专业工业单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据的高频更新要求工具调用需匹配生产批次节奏，避免拉取过期数据。多类型文档结构需要插件支持解析表格、曲线、文本等不同格式的业务文件。专业字段与单位要求工具调用时需完成参数校验，防止生成内容出现单位错误或字段缺失。严重的出错后果要求配置失败重试与异常上报逻辑，确保异常数据能及时触发报告生成。同时，跨设备的数据来源需要插件完成统一格式转换，保障生成内容的一致性。

## 配置怎么定
本配置方案适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` | 自动匹配染整工艺相关的工具调用逻辑 |
| 工作流/API 函数调用配置 | `enabled` | 支持调用专业工具生成工艺文件与异常报告 |
| 工具调用超时时间 | `600 秒` | 适配染缸升温、加料等工艺的处理周期 |
| 单次工具调用返回条数 | `前3条` | 避免过多历史批次数据干扰当前生成 |
| 插件数据拉取触发条件 | 按当前生产批次触发 | 匹配每缸、每批的数据更新节奏，需通过MCP工具集对接生产设备数据源 |
| 异常结果校验阈值 | 按实测标定 | 适配不同订单的色差、排放等合格标准 |

## 容易做错的三处
- 现象：工具返回的工艺文件缺少染化料批次字段。原因：未配置插件拉取染化料批次库的数据源，导致生成内容缺失核心业务字段。
- 现象：调用工具后出现超时报错。原因：设置的超时时间短于染缸工艺的实际处理周期，无法完成完整的参数拉取与计算。
- 现象：工具无法拉取染缸设备的实时数据。原因：未正确将本地运行的MCP服务添加到工具集中，导致数据源连接失败。

## 怎么确认配好了
- 触发一次模拟单缸生产的测试调用，检查返回的工艺文件包含染色配方、称化料记录等核心文档字段。
- 查看工具调用日志，确认`functionCall`和`toolChoice`的配置被正确应用。
- 模拟色差超标的场景，检查是否触发异常报告生成逻辑。
- 检查MCP工具集的连接状态，确认生产设备数据可以正常拉取。
