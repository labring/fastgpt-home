# 原料药与医药中间体生产的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
原料药与医药中间体生产的核心数据来自注册工艺文档、原料批次台账、DCS控制系统、称量系统、LIMS实验室信息管理系统、色谱数据系统与QMS质量管理系统。数据更新以每生产批次、每工艺步骤为触发节点。日常文档包含批生产记录、物料平衡台账、反应与精制记录、清洁验证记录、杂质谱报告、偏差与变更文件，字段涵盖反应温度、收率比值、杂质含量、溶剂残留量等，部分字段带有行业专属计量标识。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据来源要求接入环节需支持对接多个异构系统的API，避免形成数据孤岛。高频次的批次级更新要求配置需适配快速的数据拉取与处理节奏，避免延迟影响工艺文件与异常报告的起草效率。复杂的文档结构与专属字段单位，要求模型需能准确识别并映射特定工艺字段，需提前配置字段对应规则。同时，合规性要求下的敏感数据管控，需限制模型的上下文范围，避免无关数据泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单批次多步骤工艺文档的总数据量，避免截断核心工艺参数 |
| `maxTokens` | 3500–4500 token | 平衡异常报告的内容完整性与生成响应速度 |
| `temperature` | 0.2–0.4 | 保证工艺描述与数据引用的严谨性，减少无关发散内容 |
| `toolChoice` | auto | 允许模型按需调用数据检索工具，补充缺失的批次关联数据 |
| `AIPROXY_API_ENDPOINT` | 企业私有部署的代理地址 | 适配私有化部署的网络隔离要求，保障数据传输安全 |
| `AIPROXY_API_TOKEN` | 与代理服务绑定的专属密钥 | 实现细粒度的访问权限控制，避免未授权的数据访问 |

## 容易做错的三处
- 现象：升级FastGPT v4.17.0后，对接ONEAPI的模型无法连接，界面返回连接失败提示。原因：未更新ONEAPI的代理端点配置，或绑定的令牌权限未同步更新。
- 现象：新增模型配置后，FastGPT界面无法显示该配置项，重启服务后仍未恢复。原因：配置文件未正确放置在系统指定加载目录，或部署包未完成全量更新。
- 现象：生成的异常报告中缺少批次收率数据。原因：`maxContext`取值过小，截断了批生产记录中的收率字段信息。

## 怎么确认配好了
- 在系统设置界面验证`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置是否与私有部署的代理服务一致。
- 上传单批次的批生产记录样本，测试模型能否完整提取文档中的核心工艺字段。
- 生成异常报告草稿，核对生成内容是否包含了来自LIMS、DCS的关联数据。
- 调整`maxContext`的取值范围，确保覆盖当前批次的所有核心工艺数据。
