# 变压器与高压电器制造的工艺文件与异常报告起草：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类数据来自设计BOM、硅钢片与绝缘材料库存数据、真空干燥设备、油化验报告、试验站高压试验记录。日常需生成的文档包含绕制与器身装配记录、真空干燥记录、绝缘油检测报告、局放与耐压试验报告、铭牌参数表。数据更新以单台产品或每批原材料为单位，每个环节的检测与装配数据需实时同步至工艺与异常报告流程。字段包含绝缘距离参数、含水量检测值、试验电压等级等，单位多为毫米、百分比、千伏。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的多源分散数据来源，要求HTTP接口支持跨设备与系统的数据拉取与整合。单台产品的全流程数据需绑定唯一编码，接口请求需携带该编码以关联完整工艺链信息。高频次的单台或单批更新节奏，要求接口响应时长匹配生产环节的等待阈值。专用字段如绝缘距离、局放数值的单位与格式，需在接口配置中提前定义映射规则，避免数据解析错误。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {生产系统API密钥}` | 该品类的试验与装配数据属于生产敏感信息，需通过标准Bearer令牌鉴权，避免未授权访问 |
| `variables` | `{"deviceCode": "${external.deviceId}", "testCategory": "highVoltageWithstand"}` | 绑定单台产品的唯一编码与对应试验类型，匹配数据更新的单台/批规则 |
| `responseData` | `{"insulationDistance": "mm", "moistureContent": "%", "partialDischarge": "pC"}` | 统一接口返回字段的单位，匹配该品类专用参数的格式要求 |
| 接口超时时间 | `600 秒` | 匹配高压试验等长耗时环节的生产节拍，避免因超时中断数据同步 |
| 请求重试次数 | `前 3 次` | 应对车间网络波动导致的接口调用失败，保障数据同步成功率 |

## 容易做错的三处
- 现象：调用HTTP接口后，客户端断开连接时，异常报告数据未写入工艺数据库。原因：未配置接口的持久化回调逻辑，仅在请求完成后写入数据，导致中途中断的数据丢失。
- 现象：接口返回的绝缘油含水量字段为空。原因：未在`variables`中配置对应数据源的字段映射，导致外部系统的原始数据无法正确解析。
- 现象：调用接口后返回状态码401。原因：未正确设置`Authorization`参数，使用了过期或无权限的API密钥。

## 怎么确认配好了
- 发起单台变压器的模拟接口请求，核对`responseData`返回的字段单位与该品类的专用参数格式是否一致。
- 检查`Authorization`参数是否携带有效鉴权信息，模拟未授权请求，确认返回状态码符合预期。
- 模拟车间网络波动场景，验证请求重试逻辑是否触发，确认数据同步成功率达标。
- 绑定唯一设备编码发起请求，核对接口返回的数据是否与对应单台产品的工艺记录关联。
