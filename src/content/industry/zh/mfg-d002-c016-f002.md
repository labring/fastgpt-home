# 变压器与高压电器制造的工艺文件与异常报告起草：向量模型与索引

## 这个品类的数据长什么样
这个品类的日常文档包含绕制与器身装配记录、真空干燥记录、绝缘油报告、局放和耐压试验报告、铭牌参数表。数据来源为设计BOM、硅钢片和绝缘材料数据、真空与干燥设备、油化验结果、试验站测试数据。数据更新频率为每台设备或每批材料更新一次，每份文档包含绝缘含水量（ppm）、局放峰值（pC）、试验电压（kV）等专业字段，且需绑定对应设备的唯一追溯ID，支持单台全生命周期的工艺与试验数据关联。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的专业数据特征对向量索引环节带来三点约束：第一，单台设备需绑定唯一追溯ID，索引需支持按设备ID分组检索，避免跨设备数据混淆；第二，文档包含绝缘含水量、局放峰值等带专业单位的字段，分块时需保留字段完整性，不能拆分跨专业参数的上下文；第三，数据按每台或每批更新，需支持增量索引与全量重索引的灵活切换，适配工艺迭代与试验更新的频率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 匹配绝缘油报告、局放试验报告的单页内容长度，保留专业字段完整性 |
| 重叠长度 | 50–80 字符 | 避免跨绝缘距离、含水量等专业参数的上下文被拆分 |
| `defaultToken` | 4096 | 适配单份工艺文件的基础内容长度，符合FastGPT v4.17.0的基础配置标准 |
| `maxToken` | 8192 | 支持单台设备全批次工艺与试验数据的完整索引 |
| 相似度阈值 | 0.75–0.85 | 区分正常与异常局放数据，匹配高压电器的精度要求 |
| 单次搜索上限 | 前3条 | 聚焦核心试验数据，避免冗余信息干扰异常分析 |

## 容易做错的三处
- 现象：调用知识库接口生成索引后返回状态码400，提示embedding模型不匹配。原因：未针对高压电器的专业字段调整模型，误使用通用embedding模型，无法适配绝缘、试验等专业数据的语义特征。
- 现象：更换embedding模型后，已导入的知识库检索结果异常。原因：未对已导入的知识库重新创建向量索引，仅更新了新导入数据的向量，导致新旧数据的向量空间不一致。
- 现象：批量导入工艺文件后，索引任务触发超时。原因：分块长度设置过大，单块内容超出`maxToken`限制，导致索引任务无法正常完成。

## 怎么确认配好了
- 查看向量索引的分块日志，确认每个分块的长度处于设定的800–1200字符区间内。
- 调用知识库搜索接口，输入局放异常相关的关键词，检查返回结果包含绝缘含水量、试验电压等专业字段。
- 导入一批新的工艺文件，触发增量索引，确认旧数据与新数据的检索结果均正常返回。
- 查看索引任务的耗时日志，确认单次索引任务未超过预设的合理阈值。
