# 变压器与高压电器制造的工艺文件与异常报告起草：工作流编排

## 这个品类的数据长什么样
本品类数据来源于设计BOM、硅钢片与绝缘材料库存数据、真空干燥设备日志、绝缘油化验报告、高压试验站局放与耐压测试记录。文档包含绕制与器身装配记录、真空干燥记录、绝缘油检测报告、局放和耐压试验报告、产品铭牌参数表。数据按每台产品、每批原材料更新，字段包含额定电压、绝缘距离、含水量、局放峰值等，单位涵盖kV、mm、ppm、pC。

## 这些特征在「工作流编排」这一环带来什么约束
本品类数据来源分散，覆盖设计、生产、检测全流程节点，工作流编排需对接多类异构数据源。单台产品数据具有唯一性，工作流需绑定产品唯一标识实现全链路数据溯源。文档字段包含特定计量参数，工作流变量需严格匹配对应字段名与单位。高压试验异常会引发严重生产与安全后果，工作流需配置异常触发分支，自动生成异常报告并流转至审核环节。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `variables` | 包含产品ID、绝缘油含水量阈值（20ppm）、局放异常阈值（10pC） | 匹配本品类文档的核心字段与校验规则 |
| 触发节点 | 按产品批次上传完成触发 | 匹配每批原材料的更新节奏 |
| `nodeId` | 绑定高压试验数据获取节点ID | 精准对接试验站的局放与耐压测试数据源 |
| 超时设置 | 600秒 | 适配高压试验数据的采集时长 |
| 文件上传参数 | 支持多类型文档上传，上限按实测标定 | 覆盖绝缘油报告、装配记录等多种文档格式 |
| 异常分支配置 | 当局放值超过阈值时触发 | 对应本品类的高风险出错场景 |

## 容易做错的三处
- 工作流在运行预览页面正常运行，聊天页面无输出。原因是工作流未配置共享节点的权限绑定，或未在`variables`中传入聊天会话所需的产品标识参数。
- 工作流中HTTP请求配置form-data类型时，无法正确发送检测报告文件。原因是未将文件参数绑定为工作流内的文档节点，或未指定匹配文档类型的MIME格式。
- 上传工艺文件提示Load file error。原因是工作流节点未适配绝缘油报告、耐压试验报告的格式，或文件大小超出节点配置的限制。

## 怎么确认配好了
- 打开工作流的运行预览页面，传入预设的产品ID与检测数据，验证各节点是否按预设顺序执行。
- 配置form-data类型的HTTP请求节点，上传一份小型绝缘油报告文件，验证请求是否能正常发送并返回预期结果。
- 触发异常分支，输入超过阈值的局放数值，验证是否自动跳转至异常报告生成节点。
- 查看工作流的日志面板，确认`variables`中的参数已正确传递至各关联节点。
