# 变压器与高压电器制造的工艺文件与异常报告起草：工具调用与插件

## 这个品类的数据长什么样
这个品类的日常文档包含绕制与器身装配记录、真空干燥记录、绝缘油报告、局放和耐压试验报告、铭牌参数表。数据来源涵盖设计BOM、硅钢片和绝缘材料采购数据、真空与干燥设备运行数据、油化验报告、试验站高压试验数据。数据更新以单台产品、每批材料为节奏，每份文档包含绝缘含水量、局放数值、耐压值、分接位置等专业字段，单位涉及ppm、pC、kV等，需实现单台产品全流程数据追溯。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据来源分散且专业，工具调用需对接多类异构数据源接口，包括设备传感器数据、试验站API等。单台产品的全流程追溯要求工具调用时绑定唯一产品标识，避免数据混淆。专业字段的准确性直接关联产品质量，工具调用需准确提取对应字段并校验格式。高频更新的特性要求工具调用支持实时拉取最新数据，不宜依赖过期缓存。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` | 自动匹配变压器工艺文件起草所需的工具，适配多源数据调用需求 |
| 工作流/API 函数调用配置 | `enabled` | 强制触发工具调用，确保工艺文件和异常报告生成时调用对应试验数据接口 |
| 工具调用超时时间 | 600 秒 | 高压试验数据拉取、绝缘油报告解析通常需要较长处理时长 |
| 多源数据拉取条数 | 前 5 条 | 单台变压器的关联数据量有限，避免冗余信息干扰生成 |
| 工具结果校验开关 | 开启 | 校验绝缘参数、试验数据的合法性，规避严重质量风险 |

## 容易做错的三处
- 调用第三方大模型时返回`{"object":"error","message":"Only allowed now"}`，原因是未在系统配置中开放第三方模型调用权限，仅允许使用平台内置模型。
- HTTP工具调用时参数解析正常，但工具未实际执行，返回空结果或状态码异常，原因是未配置工具的请求头认证信息，或请求地址未匹配企业内部接口的访问权限。
- 生成的异常报告中缺失绝缘参数字段或单位错误，原因是未开启工具结果校验开关，未对提取的试验数据进行格式校验。

## 怎么确认配好了
- 发起模拟单台变压器的工艺文件生成请求，核对工具调用日志是否拉取了对应设计BOM、试验站数据。
- 触发局放异常报告生成请求，检查工具调用结果中是否包含绝缘含水量、局放数值等必填字段。
- 测试调用第三方大模型，确认无权限类报错返回。
- 模拟输入错误的试验参数，检查是否触发工具结果校验拦截。
