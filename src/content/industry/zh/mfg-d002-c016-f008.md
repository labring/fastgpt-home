# 变压器与高压电器制造的工艺文件与异常报告起草：文档解析与分块

## 这个品类的数据长什么样
这个品类的文档主要包括绕制与器身装配记录、真空干燥记录、绝缘油报告、局放和耐压试验报告、铭牌参数表。数据来源为设计BOM、硅钢片和绝缘材料数据、真空与干燥设备采集数据、油化验结果、试验站测试数据。文档按单台产品或每批材料更新，包含绝缘含水量、局放幅值、耐压等级、引线连接位置等字段，单位多为ppm、pC、kV、mm等。

## 这些特征在「文档解析与分块」这一环带来什么约束
单台产品的文档需精准追溯对应批次的材料与试验数据，因此解析时需保留字段间的关联关系，不能随意拆分跨关联字段的内容。绝缘油报告、试验报告包含高敏感的绝缘参数，解析过程需确保数据不被外泄。文档中存在大量表格类数据，如试验数据表格、铭牌参数表，分块时需避免拆分表格的完整行或列，否则会导致参数对应关系错乱。每台产品的文档更新频率独立，分块需适配单文档的小批量解析场景，避免过度消耗系统资源。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配该品类文档中试验报告、装配记录的单段参数描述长度，避免拆分完整的试验数据组 |
| `chunkSplitter` | 按段落+表格边界分割 | 匹配该品类文档中存在大量结构化表格与连贯工艺描述的特征，保留表格完整性 |
| `customPdfParse` | 启用 | 针对绝缘油报告、耐压试验报告中的复杂排版，使用自定义解析规则提取结构化字段 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 适配单台产品全批次文档的总大小上限，避免因文件过大导致解析中断 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 预留足够时间处理包含多组试验数据的长文档，避免超时失败 |
| `chunkSettingMode` | 手动配置 | 针对单台产品的个性化文档结构，手动调整分块规则以匹配字段关联关系 |

## 容易做错的三处
- 上传的试验报告PDF表格出现错位，解析后字段对应关系混乱。原因是未启用`chunkSplitter`的表格边界分割规则，直接按字符分块导致表格行被拆分。
- 文档解析失败，界面显示解析超时状态。原因是未调整`PARSE_FILE_TIMEOUT_SECONDS`至适配长文档的取值，单台产品的完整试验报告解析耗时超出默认阈值。
- 上传的铭牌参数表解析后字段为空。原因是未启用`customPdfParse`，默认解析规则无法识别铭牌中的紧凑排版参数。

## 怎么确认配好了
- 上传一份典型的绝缘油报告PDF，检查解析后的文本是否保留了完整的试验数据表格，无行或列拆分。
- 上传一份包含多组试验数据的长文档，等待解析完成后确认未触发超时报错。
- 手动调整`chunkSize`参数，上传同一份文档对比分块结果，确认分块未拆分关键参数关联的段落。
- 查看解析日志，确认未出现文件内容外泄相关的异常记录，验证解析过程为本地化处理。
