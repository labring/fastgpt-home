# 变压器与高压电器制造的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
该品类数据来源于设计BOM、硅钢片与绝缘材料采购数据、真空干燥设备日志、绝缘油化验报告、高压试验站记录。文档包含绕制与器身装配记录、真空干燥记录、绝缘油检测报告、局放与耐压试验报告、产品铭牌参数表。数据按单台产品或每批材料更新，字段包含绝缘电阻值（单位MΩ）、局部放电量（单位pC）、试验日期、批次号、引线连接位置等，需匹配产品专属的绝缘距离与洁净度要求。

## 这些特征在「模型接入与配置」这一环带来什么约束
单台产品专属的文档与按批更新的数据，要求模型上下文需匹配单台产品的全量试验、装配与材料数据，避免跨批次数据混淆。绝缘参数的高精度单位要求，需模型能准确识别并保留MΩ、pC等专业单位，避免单位转换错误。高频的试验异常报告起草需求，要求模型调用响应速度适配试验流程的时间窗口，且能关联对应批次的材料数据。此外，产品全生命周期追溯要求，模型生成的文档需绑定唯一批次号与铭牌参数，配置时需确保数据关联逻辑的准确性。

以下配置基于FastGPT v4.17.0版本编写：
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单台产品的全量试验、装配与材料数据，避免截断关键绝缘参数 |
| `maxTokens` | 3000–4000 token | 满足单份工艺文件或异常报告的生成长度需求，适配试验报告的详细描述 |
| `quoteMaxToken` | 1500–2000 token | 优先引用绝缘油报告、局放试验报告中的核心数据，确保引用内容完整 |
| `temperature` | 0.2–0.4 | 降低生成随机性，保证试验数据与参数的准确性，符合制造场景的严谨要求 |
| `AIPROXY_API_ENDPOINT` | 按接入的模型服务商提供的端点填写 | 适配OneAPI或Ollama的代理配置，确保模型调用链路正常 |
| `AIPROXY_API_TOKEN` | 从服务商获取的专属令牌 | 验证模型调用权限，避免无权限访问或超额调用 |

## 容易做错的三处
- 现象：调用模型时提示「当前分组 default 下对于模型 whisper-1 无可用渠道」，日志显示请求失败。原因：未在模型分组中配置Whisper相关模型，或使用了Ollama未收录的模型，未通过OneAPI补充接入支持的模型。
- 现象：TTS模型配置后生成结果无对应音色，或配置项无效。原因：未按模型要求填写`voices`参数，未匹配模型支持的音色列表，导致参数解析失败。
- 现象：夜间出现大量未授权的模型调用请求，账户余额快速消耗。原因：未配置API令牌的访问权限限制，或令牌泄露，未设置调用频率与时段限制，导致恶意或误调用。

## 怎么确认配好了
- 发起单台变压器的工艺文件生成测试，核对生成内容中是否包含绝缘电阻、局放量等核心参数，且单位准确。
- 查看模型调用日志，确认请求使用的配置项与实际填写的一致，无参数缺失或错误。
- 测试异常报告起草场景，输入局放异常的试验数据，核对生成内容是否关联对应批次的材料数据。
- 验证API调用的权限限制，模拟非授权请求，确认会被拦截，避免超额调用。
