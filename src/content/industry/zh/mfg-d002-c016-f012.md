# 变压器与高压电器制造的工艺文件与异常报告起草：部署与升级

## 这个品类的数据长什么样
数据来源包括设计BOM、硅钢片与绝缘材料采购数据、真空干燥设备运行记录、油化验报告、高压试验站的局放与耐压测试结果。更新按单台产品批次或每批材料执行。日常文档包含绕制与器身装配记录、真空干燥记录、绝缘油检测报告、局放与耐压试验报告、铭牌参数表，字段涵盖绝缘结构参数、引线连接信息、分接位置、试验数值等，无统一批量格式，单台文档体量差异较大。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据特征对部署与升级环节带来三项核心约束。其一，单台产品或每批材料的独立更新节奏，要求部署时支持增量同步机制，避免全量重复处理历史数据，降低存储与计算负载。其二，多来源异构数据（设备运行日志、油化验报告、高压试验数据），要求配置适配多格式解析的索引规则，确保不同类型文档的字段统一映射。其三，单台文档体量差异大且核心字段聚焦绝缘与高压试验参数，需要调整向量存储的分片阈值，避免单条数据过大导致索引异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 120–180 个连接 | 适配单台产品多文档并发读取的场景，避免数据库连接池耗尽 |
| `MONGODB_URI` | 指向绝缘试验与油化验数据的专属数据库实例 | 分离核心业务数据与通用知识库数据，提升检索效率与数据安全性 |
| `REDIS_URL` | 配置为本地部署的 redis 服务地址，缓存过期时间设为 1800–3600 秒 | 缓存高频查询的绝缘参数与试验数据，降低重复读取数据库的负载 |
| `ROOT_KEY` | 生成符合企业安全规范的随机密钥 | 保障管理员权限的安全性，避免未授权访问部署后的系统 |
| `STORAGE_S3_ENDPOINT` | 指向企业内部工业数据存储节点 | 适配多源异构文档的统一存储需求，确保数据访问的稳定性 |

## 容易做错的三处
- 现象：升级到FastGPT v4.17.0后，知识库可检索到匹配的试验报告，但大模型无法输出完整的工艺起草内容。原因：升级后未重新生成并配置`FILE_TOKEN_KEY`参数，导致文档解析后的访问令牌验证失败，模型无法拉取完整的上下文数据。
- 现象：docker部署后，3000端口页面无法加载，3001端口可正常访问。原因：未正确配置`FE_DOMAIN`的端口映射参数，前端主服务的端口绑定未暴露到宿主机3000端口，导致外部访问失败。
- 现象：在Linux环境通过docker部署后，修改容器内的配置文件后，指定参数未生效。原因：未通过挂载外部配置卷的方式修改参数，直接修改容器内文件会在容器重启后被重置，或未重启容器加载新的配置内容。

## 怎么确认配好了
- 执行数据库连接测试，验证`DB_MAX_LINK`配置的连接数可支撑当前业务的并发读取需求，确认连接池无耗尽情况。
- 上传一份单台变压器的绝缘试验报告，验证`STORAGE_S3_ENDPOINT`配置的存储节点可正常存储与读取文档，无访问报错。
- 重启部署服务后，使用`ROOT_KEY`对应的管理员账号登录系统，验证权限验证流程正常，无报错提示。
- 触发一次增量同步任务，确认`REDIS_URL`配置的缓存服务可正常缓存高频查询的试验参数数据，无缓存失效日志。
