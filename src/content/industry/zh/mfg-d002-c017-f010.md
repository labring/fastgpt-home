# 喷涂与涂装的工艺文件与异常报告起草：知识库检索与召回

## 这个品类的数据长什么样
本品类数据覆盖汽车、家电、工程机械、金属家具等涂装线场景，日常文档包含涂装工艺卡、涂料批次单、调漆记录、膜厚色差报告、烘炉曲线、缺陷返修单、VOCs台账。数据来源包括涂料供应商TDS/SDS文件、喷房与烘炉实时采集数据、色差仪、膜厚仪、环境监测设备及MES系统，更新频率随每批涂料投放、每班生产进度及设备连续采集数据动态调整，文档字段包含工艺参数、批次编号、检测数值、时间戳等，部分字段附带单位，如膜厚μm、色差ΔE、烘炉温度℃。

## 这些特征在「知识库检索与召回」这一环带来什么约束
涂装场景的文档类型多样且参数精度要求高，需精准匹配工艺窗口与缺陷对应关系，因此检索需区分不同文档类型的权重。实时采集的设备数据更新频率高，需支持增量召回以避免使用过时的生产参数。文档中大量带单位的检测数值，要求检索需匹配参数单位与数值范围，避免跨单位混淆导致的无效召回。异常报告起草需关联多源数据，检索需支持跨文档关联召回，同时需控制返回结果数量以适配起草场景的上下文长度限制。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，具体配置项及依据如下：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 匹配涂装工艺参数与缺陷报告的精准度要求，避免低相关结果混入 |
| `limit` | `前8–12条` | 适配工艺文件与异常报告的上下文长度，控制单轮检索返回的文档量 |
| `searchMode` | `keyword + semantic` | 兼顾涂装文档中的关键词参数（如膜厚μm）与语义关联的缺陷分析需求 |
| `usingReRank` | `开启` | 对返回的初始结果按相关性二次排序，提升缺陷返修相关文档的召回优先级 |
| `datasetSearchUsingExtensionQuery` | `开启` | 自动扩展检索词，覆盖涂料批次单、烘炉曲线等多类型文档的关联字段 |
| `collectionIds` | `按涂装场景专属数据集配置` | 限定检索范围仅覆盖本品类的工艺、检测与台账文档，避免无关数据干扰 |

## 容易做错的三处
- 检索时提示「当前分组 default 下对于模型 gpt-4o-mini 无可用渠道」，原因是未为涂装场景专属数据集配置专属检索分组，或分组未绑定对应模型渠道。
- 知识库内的图片链接在AI回复中显示为「input an image」，原因是未开启文档图片的外链生成配置，或检索时未携带图片关联的元数据参数。
- 检索结果未匹配到对应烘炉曲线数据，原因是未开启`datasetSearchUsingExtensionQuery`，导致无法关联烘炉温度与固化参数的扩展检索词。

## 怎么确认配好了
- 上传一条涂装工艺卡与烘炉曲线文档，执行检索测试，检查返回结果是否包含对应文档且相关性符合预期。
- 查看检索日志，确认`usingReRank`是否生效，返回结果的排序是否按相关性从高到低排列。
- 测试带单位的参数检索（如「膜厚15μm」），检查是否能匹配到对应膜厚色差报告文档。
- 检查专属数据集的`collectionIds`配置，确认检索范围仅包含本品类的文档，无无关数据集混入。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
