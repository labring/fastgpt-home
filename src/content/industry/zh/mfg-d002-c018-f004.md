# 基础化工连续生产的工艺文件与异常报告起草：工作流编排

## 这个品类的数据长什么样
数据来源包括DCS/SIS系统、在线分析仪、LIMS实验室管理系统、设备状态监测模块、能源计量系统与原料储罐液位监测模块。日常文档涵盖操作规程、工艺指标卡、DCS趋势图、化验报告、联锁旁路记录、特殊作业票与班报。数据更新节奏分为实时、每班、每日三类。字段包含反应釜温度（℃）、系统压力（MPa）、物料进料流量（m³/h）、联锁编号、作业票编号等，部分文档需匹配固定格式的单位与校验规则。

## 这些特征在「工作流编排」这一环带来什么约束
实时更新的DCS与在线分析仪数据要求工作流节点触发频率匹配数据采样间隔，避免延迟或冗余处理。多类型、多更新节奏的文档需要分类绑定到工作流变量，防止数据混淆。强联锁控制的特性要求工作流优先校验关键报警与旁路记录，一旦异常立即触发中断流程。连续生产的稳态维持需求要求工作流支持无人工干预的自动循环执行，且需配置失败后的自动恢复机制。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 表单输入节点触发方式 | 仅内部调用 | 适配基础化工连续生产无现场弹窗的运行场景，避免嵌套工作流时出现交互阻塞 |
| `variables`绑定规则 | 绑定DCS测点、工艺指标与作业票字段 | 匹配品类数据来源的结构化字段，确保工作流调用数据的准确性 |
| 工作流超时时间 | 300秒 | 覆盖DCS数据拉取、化验报告查询的平均耗时，避免因数据延迟导致运行失败 |
| 节点重试次数 | 2次 | 应对临时的系统网络波动，保障关键校验节点的执行成功率 |
| `nodeId`指定节点 | 联锁校验节点ID | 优先处理强联锁相关的异常校验，确保生产安全相关环节的执行优先级 |
| 上下文调用上限 | 前10条 | 匹配品类日常文档的单次处理规模，避免过多数据占用运行资源 |

## 容易做错的三处
- 嵌套在父工作流中运行时，表单输入节点弹出对话框，父工作流无法自动推进。原因是表单输入节点的触发方式默认设置为「外部调用弹窗」，未适配嵌套工作流的无交互运行场景。
- 调用自定义Python代码函数时返回执行失败提示，无法获取预期的工艺计算结果。原因是未将Python代码节点配置为可被外部工作流调用的公开节点，且未在`variables`中绑定函数所需的实时工艺参数。
- 尝试通过前端直接调用工作流时返回权限错误，无法获取工作流的执行结果。原因是未使用工作流的唯一`nodeId`或绑定的应用密钥进行鉴权调用，直接调用未配置公开权限的工作流。

## 怎么确认配好了
- 触发嵌套工作流，确认表单输入节点无弹窗弹出，工作流自动完成所有节点的执行并生成结果。
- 调用自定义Python代码节点，传入`variables`中绑定的工艺参数，确认代码正常执行并返回符合要求的计算结果。
- 查看工作流运行日志，确认超时时间内完成所有节点的执行，无超时报错或关键节点执行失败的记录。
- 核对`nodeId`的配置，确认联锁校验节点被正确指定，且该节点的重试规则已生效。
