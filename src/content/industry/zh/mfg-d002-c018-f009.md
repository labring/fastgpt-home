# 基础化工连续生产的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据主要来自DCS/SIS系统、在线分析仪、LIMS实验室管理系统、设备状态监测装置、能源计量系统及原料储罐数据。日常文档涵盖操作规程、工艺指标卡、DCS趋势图、化验报告、联锁旁路记录、特殊作业票、班报。数据更新节奏分为实时、每班、每日三类，文档字段包含工艺控制参数、报警阈值、化验结果、作业许可信息等，单位涉及压力、温度、流量、物料浓度等工业常用计量标准。

## 这些特征在「模型接入与配置」这一环带来什么约束
由于数据更新存在实时、每班、每日的差异，模型接入时需区分不同数据源的调用频率，避免过度调用实时接口导致资源占用过高。日常文档类型多样、结构差异明显，配置环节需适配不同文档的提取逻辑，确保联锁参数、报警阈值等关键字段被完整识别。多系统联动的数据来源要求配置时明确各数据源的权限与接口格式，防止跨系统数据同步异常。异常报告起草需快速调用最新报警数据，需调整上下文相关参数以覆盖关键时间窗口的信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 覆盖单班次的工艺数据与异常记录，确保上下文包含足够的过程信息 |
| `maxTokens` | 4000 token | 限制单份异常报告的生成长度，避免超出化工文档的常规输出篇幅 |
| `quoteMaxToken` | 1500 token | 优先提取工艺指标卡、联锁记录等核心文档片段，确保引用内容的准确性 |
| `temperature` | 0.2–0.4 | 降低生成随机性，保证工艺参数与报警处置流程的表述符合行业规范 |
| `AIPROXY_API_ENDPOINT` | 按部署节点的内网地址填写 | 适配企业内部多系统联动的网络环境，保障数据传输安全 |
| `AIPROXY_API_TOKEN` | 绑定专属调用密钥 | 限制非授权访问，符合工业场景的数据安全要求 |

## 容易做错的三处
- 现象：本地测试生成结果正常，但外部发布渠道无法调用生成内容，返回403状态码。原因：未正确配置`AIPROXY_API_ENDPOINT`的访问白名单，内网部署节点未开放对应端口供外部调用。
- 现象：升级到FastGPT v4.17.0后，模型调用频繁超时，生成结果被截断。原因：`maxTokens`参数设置超出新版系统的默认限制，未根据化工文档的常规篇幅调整取值区间。
- 现象：生成的异常报告未包含联锁旁路记录的关键信息。原因：`quoteMaxToken`参数设置过小，未覆盖该类文档的字段长度，导致核心数据未被成功召回。

## 怎么确认配好了
- 检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置值，确保与部署环境的实际参数一致。
- 发起一次模拟调用，输入包含工艺指标卡与报警记录的测试文本，核对生成结果是否包含核心字段。
- 调整`temperature`参数的取值区间，对比不同配置下的生成内容，确认符合行业表述规范。
- 查看系统日志，确认模型调用过程中无超时或权限报错信息。
