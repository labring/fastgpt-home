# 塑料注塑成型的工艺文件与异常报告起草：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的日常文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验、巡检表、换料清机记录。数据来自树脂批次物性表、注塑机运行参数、模温机数据、车间MES系统、尺寸与外观检测设备。数据更新频率为每生产批次、每次换模换料、每班结束。文档字段包含特定单位参数，如干燥温度为摄氏度、充填压力为兆帕、冷却时间为秒，异常报告需关联批次号、模具编号与缺陷类型。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
由于数据来源覆盖多类车间设备与系统，接口需支持多数据源的拉取与整合。高频更新的业务场景要求接口具备低延迟特性，避免因数据滞后影响工艺文件与异常报告的生成。文档字段的特定单位与业务关联逻辑，要求请求参数需匹配对应字段名与格式。同时，异常报告需关联模具履历、树脂批次等数据，接口需支持按批次号、模具编号等条件查询。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {车间系统API密钥}` | 符合HTTP接口鉴权标准，适配注塑车间系统的身份验证规则，在FastGPT v4.17.0的HTTP节点中可直接配置请求头 |
| `variables` | `{"batchNo": "PXXXXXXXXX", "moldId": "M001", "defectType": "short shot"}` | 携带注塑批次号、模具编号、缺陷类型等业务字段，匹配异常报告起草的查询条件，实现数据精准拉取 |
| 接口超时时间 | `30–60 秒` | 适配注塑设备数据拉取的延迟范围，避免因车间网络波动导致请求失败 |
| `responseData` | `提取工艺参数、检测结果、批次关联字段` | 仅返回工艺文件与异常报告所需的核心数据，减少网络传输开销，提升生成效率 |
| 批量请求上限 | `前 20 条` | 匹配每班巡检表的单次提交数量，避免接口过载影响车间系统运行 |

## 容易做错的三处
- 现象：调用接口返回`401 Unauthorized`，返回的`responseData`为空。原因：未正确配置`Authorization`参数，未携带车间系统要求的鉴权凭证。
- 现象：接口返回`504 Gateway Timeout`，生成的异常报告缺少部分工艺参数。原因：超时时间设置过短，未适配注塑设备拉取数据的实际延迟。
- 现象：HTTP节点返回BLOB对象后，用户无法在对话框中点击下载。原因：未配置正确的响应格式，未将二进制流转换为可下载的文件链接。

## 怎么确认配好了
- 在FastGPT v4.17.0的HTTP节点中发起测试调用，查看返回的`responseData`是否包含注塑工艺卡的核心参数，如充填压力、保压时间。
- 检查`Authorization`参数的格式是否符合Bearer鉴权规则，无拼写或格式错误。
- 模拟换模换料场景，触发接口调用，确认返回数据的更新频率符合每批、每次换模的要求。
- 验证异常报告生成时，是否能自动关联树脂批次的物性表与检测结果数据。
