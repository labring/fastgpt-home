# 家用电器整机制造的工艺文件与异常报告起草：向量模型与索引

## 这个品类的数据长什么样
本品类数据覆盖空调、冰箱、洗衣机及小家电生产企业的日常生产与售后文档，包含配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告与返修记录。数据来源涵盖ERP/MES系统、零部件批次数据、拧紧与充注设备、安规测试仪、性能实验室及售后故障数据，更新节奏为单台设备级、班组级或按抽检计划执行。文档结构包含固定字段如部件型号、工艺参数、测试结果与返修原因，部分文档附带设备采集的原始数值与批次标识。

## 这些特征在「向量模型与索引」这一环带来什么约束
混线装配的生产模式带来多型号文档共存的业务场景，要求索引具备精准的型号区分能力，避免跨型号的工艺文件被错误匹配；高频的单台/班组级数据更新，要求索引支持增量更新逻辑，减少全量重建的资源消耗；安规、性能抽检等强合规类文档包含结构化数值与非结构化文本，要求向量模型适配混合输入格式；售后返修记录与前端工艺文件的关联需求，要求索引支持跨文档的关联检索，同时控制单批次索引规模以保障检索速度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配装配作业书、测试报告等单页文档的语义完整性，避免跨段落语义断裂 |
| 重叠长度 | 50–80 字符 | 保留相邻分块的语义衔接，适配工艺文件中连续的参数说明段落 |
| 相似度阈值 | 0.72–0.85 | 按实测标定 | 匹配多型号混线场景下的文档区分度，避免不同型号的相似工艺参数被误匹配 |
| 单次搜索上限 | 前 10 条 | 控制检索结果规模，适配工艺文件检索时的快速定位需求 |
| maxToken | 4096 | 适配安规测试报告等长文档的向量生成，避免内容截断导致语义丢失 |
| defaultToken | 1024 | 适配返修记录等短文档的向量生成，平衡生成效率与语义完整性 |

## 容易做错的三处
- 向量模型配置后出现报错，无法生成有效索引。原因是未针对结构化工艺参数调整输入格式，导致模型无法正确解析数值类字段。
- 检索结果条数与预期不符，仅返回少量或无匹配结果。原因是相似度阈值设置过高，过滤掉了符合工艺参数匹配的有效结果。
- 本地部署版本的PDF增强解析功能无法正常触发。原因是未确认FastGPT v4.17.0版本的本地非商业版权限，未正确配置解析依赖。

## 怎么确认配好了
- 上传单份装配作业书，检查分块后的文本片段是否覆盖完整的工艺步骤，无明显语义截断。
- 输入包含特定部件型号的检索词，核对检索结果的文档类型与型号是否匹配，确认相似度阈值的过滤效果符合预期。
- 上传多份不同型号的工艺文档，验证检索结果是否仅返回对应型号的相关内容，无跨型号误匹配。
- 查看向量生成日志，确认`maxToken`与`defaultToken`的配置被正确应用，无参数冲突报错。
