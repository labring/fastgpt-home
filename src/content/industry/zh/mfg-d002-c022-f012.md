# 家用电器整机制造的工艺文件与异常报告起草：部署与升级

## 这个品类的数据长什么样
该品类的日常文档包括配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告、返修记录。数据来源于ERP/MES系统、零部件批次台账、拧紧与充注设备、安规测试仪、性能实验室数据及售后故障记录。数据更新节奏为单台产品级、班组级及按抽检计划执行，文档关联具体生产批次、工艺参数与测试结果。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据来源分散且覆盖生产设备、实验室、售后系统等多类终端，部署时需配置多源数据同步适配链路，兼容不同协议的设备数据接入。高频细粒度的更新节奏要求部署的数据库连接池参数适配小批量高频写入场景，避免连接耗尽。多样的文档类型与单台/班组级的更新逻辑，升级时需新增型号关联的文档路由规则，防止多型号混线时的文档错配。同时，面向消费者的产品属性要求异常报告的字段校验严格，部署时需配置必填字段校验逻辑。本页面基于FastGPT v4.17.0版本编写。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150 个连接` | 适配高频小批量的生产数据写入场景，避免数据库连接耗尽 |
| `REDIS_URL` | `redis://:自定义密码@内网IP:6379/0` | 存储临时工艺文档解析缓存与会话数据，适配家电生产的高频访问需求 |
| `STORAGE_S3_ENDPOINT` | `企业内网对象存储节点地址` | 存储大容量的安规测试报告与返修记录，降低公网传输延迟 |
| `FE_DOMAIN` | `https://企业内网工艺平台域名` | 适配企业内网访问场景，避免生产相关数据公网暴露 |
| `FILE_TOKEN_KEY` | `按实测标定` | 生成工艺文档的访问令牌，适配不同型号产品的文档权限控制 |
| `ROOT_KEY` | `企业专属随机字符串` | 保障平台后台配置的权限安全，防止未授权访问 |

## 容易做错的三处
- 现象：Docker部署后前端访问地址无法切换为HTTPS，浏览器提示不安全连接。原因：未正确配置`FE_DOMAIN`参数为HTTPS格式，且未将SSL证书挂载到容器的前端服务目录。
- 现象：添加Qwen3模型到配置后启动报错，提示模型仅支持流模式。原因：未在模型配置中开启流式传输开关，使用非流模式调用该模型。
- 现象：多源数据同步时出现字段为空的异常，导致工艺文件生成失败。原因：未配置`REDIS_URL`对应的缓存过期时间，导致临时同步的零部件批次数据丢失。

## 怎么确认配好了
- 访问配置的`FE_DOMAIN`地址，确认前端页面可正常加载并展示工艺文档与异常报告模板。
- 触发一次多源数据同步任务，确认来自ERP/MES、安规测试仪等系统的数据均可正常拉取并存储。
- 调用大语言模型生成一份模拟的返修异常报告，确认输出内容包含预设的工艺文档字段。
- 查看数据库连接池的监控数据，确认当前连接数未达到配置的上限值。
