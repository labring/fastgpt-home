# 工业仪器仪表制造与校准的工艺文件与异常报告起草：向量模型与索引

## 这个品类的数据长什么样
本品类数据来自流量、压力、温度、分析仪器制造商及计量实验室，日常文档包含装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录。数据来源涵盖设计文件、标准器监测数据、校准软件输出、实验室信息系统及客户量程要求，更新频率为每台每次校准，文档包含量程、误差值、校准日期、溯源编号等明确字段与对应物理单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类数据更新频率高且单条数据关联单台设备校准全流程，索引环节需支持增量更新以避免全量重建耗时。文档包含结构化表单、曲线数据说明与专业技术文本，向量模型需适配多类型内容的特征提取。字段包含溯源编号、误差值等关键标识，分块时需保留字段关联以确保检索准确性。同时校准结果直接关联客户生产，检索召回的精准度需满足计量审核要求，需严格控制召回结果的匹配精度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配校准规程、误差曲线说明等文档的自然分段，避免破坏溯源编号等关键字段的关联 |
| 重叠长度 | 100–200 字符 | 保留相邻分块的字段关联，防止跨块的校准记录信息断裂 |
| 相似度阈值 | 0.75–0.85 | 匹配校准记录、计量证书的专业文本特征，过滤低相关性结果以满足计量审核要求 |
| 单次搜索上限 | 前 8 条 | 平衡检索效率与召回完整性，适配单台设备校准数据的体量 |
| maxToken | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| defaultToken | 按代表性样本文档实测设置 | `defaultToken` 是直接文本分块使用的默认 token 数，请用本品类代表性原文实测调整；参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不表示向量维度、嵌入模型输入上限或检索/LLM 上下文。 |

## 容易做错的三处
- 现象：检索时同时调用多个知识库，无法优先使用指定知识库的索引，结果包含无关的通用设备文档。原因：未在向量模型配置中绑定知识库与对应索引规则，未开启知识库优先级开关。
- 现象：检索过程中返回60秒超时报错，界面显示任务中断。原因：未配置增量索引更新，全量重建校准记录索引耗时过长，超过系统默认超时限制。
- 现象：批量为集合添加索引的请求返回参数错误，无有效索引生成。原因：未按照接口要求携带集合ID、分块数据及仪器溯源编号等关联字段，未匹配品类数据的专属字段格式。

## 怎么确认配好了
- 进入向量模型配置页面，检查知识库优先级开关是否开启，确认指定知识库的索引规则已绑定。
- 发起单台仪器校准记录的检索测试，查看返回结果的响应时间，无60秒中断提示。
- 提交批量添加索引的测试请求，查看返回结果是否包含有效索引ID，无参数错误提示。
- 检索异常报告相关内容，确认返回结果仅包含目标知识库的文档，无跨知识库的无关内容。
