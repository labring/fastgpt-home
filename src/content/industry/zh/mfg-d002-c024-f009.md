# 工艺变更与工程变更的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
本品类的数据由制造企业变更管理团队产生，涵盖ECN/ECR、变更评估表、图纸与BOM版本、工艺验证报告、切换计划、库存处置单等文档。数据来源包括PLM、ERP、MES系统、供应商资料、验证试验记录及客户特殊要求，更新随每次变更不定期触发。文档包含设计/物料/工艺关联字段、版本号、验证状态、审批节点等，无统一固定单位，随对应业务环节调整。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类的数据特征对模型接入配置带来多重约束。数据来源覆盖多业务系统，格式包含结构化字段与半结构化文档，要求配置需支持多源数据的格式适配与字段映射。更新随变更不定期触发，单次数据量波动明显，需预设可灵活调整的上下文参数上限，避免处理超时。文档包含版本号、验证状态等关键业务字段，模型输出需精准关联对应字段，需调整参数控制输出的精准性。同时，变更出错后果严重，需配置溯源绑定功能，确保输出内容可关联原始文档来源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 本品类单次变更涉及的文档总长度波动大，覆盖多系统导出的内容，需适配不同数据量 |
| `temperature` | `0.1–0.3` | 需保证输出的工艺文件、异常报告内容精准匹配业务字段，避免冗余或偏差 |
| `quoteMaxToken` | `2000–3000 token` | 需保留足够的原始文档引用细节，满足变更验证的溯源要求 |
| `AIPROXY_API_ENDPOINT` | `http://{本地IP}:{端口}/v1/chat/completions` | 适配本地大模型接入需求，解决跨网络访问限制 |
| `AIPROXY_API_TOKEN` | 代理平台分配的令牌值 | 验证接入身份合法性 |
| `toolChoice` | `auto` | 自动调用文档解析工具，适配多源数据的不同格式 |

## 容易做错的三处
- 现象为调用时返回连接错误，状态码500或请求超时。原因是未正确填写`AIPROXY_API_ENDPOINT`的本地地址，或未开放对应端口的网络访问权限。
- 现象为生成的工艺文件未关联原始文档引用，引用字段为空。原因是未开启`quoteMaxToken`参数的绑定配置，或参数取值过小导致无法保留引用细节。
- 现象为生成的变更报告内容偏差较大，包含无关业务字段。原因是`temperature`参数取值过高，导致模型输出偏离业务字段要求。

## 怎么确认配好了
- 在FastGPT v4.17.0版本中，填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`后，运行连接测试，确认返回正常的模型响应。
- 上传一份ECN文档与工艺验证报告，触发起草流程，检查生成的内容是否包含文档中的版本号、验证状态等关键字段。
- 查看生成结果的引用模块，确认已关联原始文档的片段内容，且引用细节完整。
- 调整`temperature`参数至0.2，再次生成变更报告，对比两次输出的差异，确认参数配置生效。
