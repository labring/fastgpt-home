# 工艺变更与工程变更的工艺文件与异常报告起草：知识库检索与召回

## 这个品类的数据长什么样
本品类数据由制造企业研发、工艺、质量、生产、采购团队协同产生，日常文档包含ECN/ECR表单、变更评估报告、图纸与BOM版本文件、工艺验证报告、生产切换计划、库存处置单及客户批准文件。数据来源覆盖PLM、ERP、MES系统、供应商资料、验证试验记录与客户特殊要求，更新随每次变更不定期触发，单份文档包含变更原因、影响范围、版本信息、验证结果等字段，无统一固定单位，字段与单位随文档类型差异调整。

## 这些特征在「知识库检索与召回」这一环带来什么约束
本品类数据跨多系统来源且更新无固定周期，要求知识库检索需支持跨源数据关联召回；文档类型多样且包含专业技术字段与关联信息，需适配模糊匹配与多维度关键词召回；每次变更触发的文档更新无规律，需支持增量同步机制以保证数据时效性；变更场景需快速定位连锁影响关联的BOM、工艺验证报告等文件，要求召回结果需覆盖跨文档的关联信息。

## 配置怎么定
本文档基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 本品类文档包含专业技术字段与关联信息，该区间可过滤无关结果同时保留核心关联内容 |
| `limit` | `前8–12条` | 变更场景需覆盖多维度关联文档，该数量可平衡上下文长度与信息完整性 |
| `searchMode` | `mixedRecall` | 兼顾关键词匹配变更相关术语与向量召回语义关联的跨系统文档 |
| `usingReRank` | `开启` | 本品类文档关联关系复杂，重排可提升高关联结果的排序优先级 |
| `datasetSearchUsingExtensionQuery` | `开启` | 可扩展检索范围，覆盖变更场景下的隐含关联术语，如工艺变更对应的物料替代信息 |
| `collectionIds` | `绑定对应变更管理相关的知识库集合` | 精准限定检索范围，避免无关文档干扰召回结果 |

## 容易做错的三处
- 调用FastGPT知识库接口时返回`Error: write EPROT`或`Query read timeout`报错。原因：未正确配置接口超时参数，或跨系统调用时未处理HTTPS证书校验问题。
- 外部传入知识库ID后无搜索结果返回。原因：未将目标文档集合绑定至指定`collectionIds`参数，或检索配置的`similarity`阈值过高过滤了有效结果。
- 召回结果未覆盖跨系统关联的BOM或工艺验证文档。原因：未开启`datasetSearchUsingExtensionQuery`配置，仅检索了单一知识库集合内的文档。

## 怎么确认配好了
- 调用知识库检索接口，传入变更场景的测试关键词，核对返回结果的文档类型是否包含ECN/ECR、BOM版本文件等本品类核心文档。
- 查看接口返回的结果条数，确认与配置的`limit`参数取值范围匹配。
- 检查返回结果的相似度分值，确认处于预设的`similarity`区间内。
- 验证开启`usingReRank`后，高关联度的变更关联文档是否排在结果前列。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
