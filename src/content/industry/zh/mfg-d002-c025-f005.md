# 工装夹具与检具制造的工艺文件与异常报告起草：工具调用与插件

## 这个品类的数据长什么样
该品类的数据来自产品数模与GD&T、工艺路线、三坐标测量数据、现场试用反馈及计量系统。日常文档包含工装需求书、定位基准方案、夹具图、检具操作书、验收报告、校准记录与变更履历。文档字段含GD&T公差标注、微米级测量值、校准日期、偏差值等，更新节奏随项目推进、产品变更或定期校准执行。

## 这些特征在「工具调用与插件」这一环带来什么约束
品类数据来源分散且格式各异，需插件对接计量系统、三坐标设备等数据源，工具调用需适配多格式数据解析。文档长度跨度大，短则数页需求书，长则数十页夹具图，工具调用需支持可变长度上下文处理。更新节奏随项目与变更触发，工具需支持按需拉取最新校准记录与变更履历，避免使用过期数据。同时，工具调用结果需关联GD&T公差与测量值，确保工艺文件与异常报告的准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配不同插件调用场景，自动匹配工具能力 |
| `functionCall` | `enabled` | 强制启用显式函数调用，确保工具调用流程可控 |
| 工具调用超时时间 | `300 秒` | 三坐标数据拉取、校准记录解析通常需较长处理时长 |
| 单次工具调用返回条目上限 | `前 10 条` | 工装夹具文档条目较多，避免上下文过载 |
| 上下文预留比例 | `20%` | 保留足够空间处理插件返回的测量数据与公差信息 |
| 插件请求重试次数 | `3 次` | 应对计量系统临时连接中断的情况 |

## 容易做错的三处
- 现象：调用插件时返回`unAuthChat`报错，原因是未正确配置插件的访问密钥，或接口地址填写存在拼写错误。
- 现象：处理长文档如大型夹具图时，工具生成的异常报告关键信息缺失，原因是未调整上下文窗口设置，导致核心GD&T公差数据被截断。
- 现象：无法找到定时执行工具的配置入口，原因是未在插件管理页面启用定时任务模块，或使用的FastGPT版本未支持该功能。

## 怎么确认配好了
- 在FastGPT v4.17.0的插件测试页面输入工装需求书示例，触发工具调用，查看是否返回定位基准方案的解析结果。
- 检查插件配置页面的访问密钥与接口地址，触发测试调用后无权限报错或连接超时提示。
- 上传包含三坐标测量数据的检具操作书，验证工具调用后生成的异常报告是否包含微米级测量偏差值。
- 进入定时任务配置页面，创建按项目变更触发的插件执行任务，确认任务列表中显示对应配置项。
