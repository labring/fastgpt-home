# 工装夹具与检具制造的工艺文件与异常报告起草：知识库检索与召回

## 这个品类的数据长什么样
该品类的日常文档包含工装需求书、定位基准方案、夹具图、检具操作书、验收报告、校准记录、变更履历，数据来源为产品数模与GD&T、工艺路线、三坐标数据、现场试用反馈、计量系统。文档包含定位基准参数、装配尺寸公差、校准周期、变更版本号等字段，单位涵盖毫米、弧度、校准周期按项目节点。数据更新频率按项目推进、每次产品变更触发，以及定期校准更新，单份文档的技术参数精度要求高。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据特征对检索召回带来多重约束：多类型混合文档（图纸、报告、校准记录）要求检索支持按文档类型过滤，避免无关结果干扰；高精度技术参数（如GD&T公差、三坐标坐标值）的存在，要求检索兼顾语义匹配与精确字段匹配，防止低精度结果引发装夹偏差；按项目与变更的高频更新，要求知识库支持增量同步与版本回溯检索，确保召回结果为最新有效版本；现场反馈与计量数据的时效性要求，需优先召回最新校准与变更后的文档。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 该品类文档包含高精度公差参数，需过滤低匹配度的无关结果，避免装夹方案偏差 |
| `limit` | 前6条 | 工装夹具的工艺依赖多份关联文档（如夹具图+校准记录+变更履历），6条可覆盖核心关联数据且不超出上下文长度 |
| `searchMode` | `mixedRecall` | 该品类既有语义类的定位方案描述，又有精确数值类的GD&T参数，混合检索可兼顾语义与精确匹配 |
| `usingReRank` | 开启 | 多文档混合场景下，重排可提升高精度参数匹配结果的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 该品类文档包含专业术语（如GD&T、三坐标检测），扩展查询可覆盖术语变体与同义词 |
| `collectionIds` | 按文档类型分组的集合ID | 该品类文档分为图纸类、报告类、校准类，按集合过滤可缩小检索范围，提升召回效率 |

## 容易做错的三处
- 现象：离线环境下知识库上传文件后长时间处于转圈圈状态，联网后恢复正常。原因：FastGPT v4.17.0默认依赖外部资源拉取索引依赖，离线环境无法完成初始化校验。
- 现象：使用bge-m3、bge-large等语义模型检索时无法命中目标文档，全文检索可正常返回结果。原因：未开启`datasetSearchUsingExtensionQuery`，专业术语未做扩展匹配，且`similarity`阈值设置过高，过滤了精准匹配的低语义相似度结果。
- 现象：检索结果中混杂非当前项目的工装文档，无法精准匹配当前工序的定位基准方案。原因：未配置`collectionIds`过滤指定项目的文档集合，召回范围覆盖了全量知识库数据。

## 怎么确认配好了
- 查看检索结果的文档类型占比，确认是否符合当前工序的文档需求，调整`similarity`阈值至匹配度符合业务精度要求。
- 测试离线环境下的知识库上传与检索流程，确认无长时间加载状态，验证离线依赖配置是否正确。
- 输入包含专业术语（如GD&T、三坐标）的查询词，确认召回结果包含对应参数的文档，验证`datasetSearchUsingExtensionQuery`是否生效。
- 对比全文检索与语义检索的结果条数，确认`limit`配置的召回条数符合上下文长度限制。
