# 有色金属冶炼与电解的工艺文件与异常报告起草：向量模型与索引

## 这个品类的数据长什么样
通常覆盖铜、铝、铅锌等冶炼企业的熔炼、电解、化验与调度部门。日常文档包含配料单、熔炼记录、电解槽况记录、化验报告、阳极阴极质量记录、环保台账。数据来源包括精矿与辅料分析、DCS系统、槽电压电流监测、化验室检测、能源与环保监测设备。更新节奏随原料批次、炉次或电解槽运行实时调整，部分核心指标如槽电压、电流为秒级更新，配料单、化验报告随单生成。文档字段包含专业单位，如槽电压（mV）、电流强度（A）、金属品位（%）、杂质含量（ppm）等。

## 这些特征在「向量模型与索引」这一环带来什么约束
高频实时的更新要求索引支持增量构建与快速刷新，避免全量重建消耗过多资源。多字段、带专业单位的文档结构要求分块时保留字段上下文，防止截断关键信息导致向量表征偏差。跨部门文档的关联需求要求索引支持跨类型文档召回，例如将配料单与电解槽况记录关联匹配。不同于钢铁冶炼的铁碳体系，本品类需重点关注杂质成分与电解槽群的关联数据，因此向量模型需适配工业冶炼场景的专业术语，提升对杂质含量、金属回收率等表述的识别精度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配冶炼文档的单段字段长度，避免截断包含配料比例、槽况参数的关键内容 |
| 重叠长度 | 100–150 字符 | 保留相邻分块的上下文关联，防止专业术语被分块割裂 |
| 相似度阈值 | 0.72–0.85 | 按实测标定，过滤低相关性的非专业文档，保留与冶炼工艺强相关的召回结果 |
| 单次搜索上限 | 前 8–12 条 | 平衡召回覆盖范围与后续推理的上下文长度，适配多文档关联的工艺查询 |
| 最大上下文 | 4000–6000 token | 符合`maxToken`参数设置要求，容纳多份冶炼文档的向量内容与查询文本 |
| 默认token数 | 2000–3000 token | 适配`defaultToken`参数，用于基础召回的上下文填充，控制单次调用成本 |

## 容易做错的三处
- 现象：Embedding模型连不通OneAPI，报错提示接口认证失败或请求超时。原因：未将向量模型的输入格式调整为适配冶炼专业文档的字段结构，或未正确配置OneAPI的端点映射规则。
- 现象：开启Rerank模型后，在线召回测试无生效排序变化。原因：未将重排模型的输入调整为包含专业字段的完整文档片段，或相似度阈值设置超出适配区间，导致重排模型未触发有效计算。
- 现象：索引构建完成后，部分化验数据的向量表征缺失。原因：分块长度设置过短，截断了包含杂质含量、金属品位等关键字段的文档片段，导致对应内容未被完整向量化。

## 怎么确认配好了
- 查看FastGPT v4.17.0的索引构建日志，确认分块长度、重叠长度等配置项的取值与设置一致。
- 输入一条工艺相关查询，例如「某批次铝锭电解槽的电压异常原因」，验证召回结果包含电解槽况记录、熔炼记录等目标文档。
- 开启重排功能后，核对召回结果的排序与专业相关性匹配，确认重排模型已生效。
- 检查向量模型的调用日志，确认无认证错误或超时报错，确保模型调用链路正常。
