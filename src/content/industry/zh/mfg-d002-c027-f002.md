# 服装裁剪与缝制的工艺文件与异常报告起草：向量模型与索引

## 这个品类的数据长什么样
该品类的数据主要来自服装OEM/ODM工厂、品牌供应链及裁剪缝制车间，日常留存工艺单、CAD样板、排料图、裁剪单、首件封样、工序质量表、包装配码单等文档。数据来源覆盖订单与尺码表、CAD设计文件、面辅料检验记录、吊挂系统生产数据、验针机检测结果及客户封样件。数据更新频率随每订单、每款、每批变动，单款文档包含明确的尺码参数、面料规格、工序要求等字段，裁片相关数据带有不可逆的生产属性，无通用批量复用的固定格式。本文基于 FastGPT v4.17.0 版本的配置规范。

## 这些特征在「向量模型与索引」这一环带来什么约束
品类内款式多、季节性强的特点，要求向量索引支持高频新增文档的快速增量更新；裁片数据不可逆且人工工序密集，意味着索引需保留工序拆解的细节信息，避免截断关键工艺描述；多来源数据格式差异大，需适配CAD文件、表格、质检记录等非结构化与半结构化数据的嵌入；按订单、款、批更新的节奏，要求索引支持按批次维度的分组管理，避免全量重建的耗时。同时，包装配码单、工序质量表等文档的字段关联性强，需确保向量嵌入能捕捉字段间的对应关系，避免搜索时出现跨款的无效匹配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配工艺单、工序质量表等文档的单段工艺描述长度，避免截断关键工序要求 |
| 重叠长度 | 100–200 字符 | 保留相邻分块的工艺关联信息，避免裁片配套要求的上下文断裂 |
| 相似度阈值 | 0.75–0.85 | 过滤服装品类中相似面料、工序描述的无效匹配，确保召回结果与工艺需求强相关 |
| 单次搜索上限 | 前 10 条 | 匹配车间单次工艺查询的信息量级，避免返回过多无关排料图或历史订单数据 |
| `defaultToken` | 4096 | 适配CAD样板、排料图等带长文本参数的文档嵌入，覆盖完整的尺寸与排版信息 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |

## 容易做错的三处
- 现象：索引同步完成后，工艺单、排料图等文档在搜索时无返回结果。原因：未按订单批次配置增量索引规则，全量索引仅同步了历史批次数据，新订单的文档未被纳入索引范围。
- 现象：拆分长文档时，最后一个分块无法完成索引，界面显示分块校验失败。原因：未配置空分块跳过规则，最后一组文本长度不足分块阈值，导致系统尝试嵌入无有效内容的分块。
- 现象：搜索工艺查询时，返回结果的相关性偏低，出现非目标款式的工艺描述。原因：相似度阈值设置不符合品类需求，未过滤相似但不匹配的面料、工序数据，或未按款号维度配置索引分组。

## 怎么确认配好了
- 上传单款完整的工艺单与排料图，检查索引同步状态是否显示完成，确认文档字段是否完整提取。
- 输入目标工序的查询词，查看召回结果的数量与相关性，调整相关配置至符合业务需求的区间。
- 上传新批次的订单文档，验证增量索引是否自动同步，无需手动触发全量重建。
- 拆分长文档后，检查最后一个分块是否被正常嵌入，确认无校验失败的提示。
