# 模具设计制造的工艺文件与异常报告起草：工具调用与插件

## 这个品类的数据长什么样
通常，模具设计制造的业务数据来源于客户产品模型、模流/成形仿真文件、CAD/CAM图纸、机加工与测量记录、试模样件数据。数据更新按项目节点推进，每次试模或改模后都会生成新的文档与记录。日常文档包含模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历，字段包含模具编号、零件材料、型腔数、脱模角度、缩水率等，单位多为毫米、兆帕、小时等。

## 这些特征在「工具调用与插件」这一环带来什么约束
多来源的异构数据要求工具调用需兼容不同格式的解析，避免因数据格式不匹配导致调用失败。按项目与试模节点的高频更新，要求工具调用可动态触发，适配临时生成的异常报告与工艺文件。复杂的文档字段结构，要求工具调用需精准匹配预设字段，确保写入的工艺文件数据符合企业标准化要求。同时，模具延期、制件缺陷等出错后果，要求工具调用需具备失败重试与结果校验能力，保障业务流程稳定。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | 设为`auto` | 适配模具设计场景下的多工具自动调度，无需手动指定调用项，适配多来源数据的处理需求 |
| 工作流/API 函数调用配置 | 开启强制模式 | 确保工具调用返回结构化结果，便于精准提取模具字段并写入标准化工艺文件 |
| 文件上传超时阈值 | 300–600 秒 | 适配CAD图纸、试模报告等大尺寸文件的上传与解析流程，FastGPT v4.17.0版本支持自定义该参数 |
| 工具调用重试次数 | 2–3 次 | 应对试模数据同步时的网络波动或临时接口异常，降低调用失败概率 |
| 上下文窗口大小 | 8000–12000 token | 容纳完整的模具项目文档与历史迭代记录，确保工具调用可获取足够的上下文信息 |

## 容易做错的三处
- 调用飞书多维表格接口返回400错误，字段为空。原因：未匹配模具文档中的标准化字段（如模具编号、型腔数），导致接口校验失败。
- 调用MySQL工具获取试模数据后，大模型回答未引用原始数据片段。原因：未开启`functionCall`的结构化返回配置，无法提取并保留数据库原文片段。
- 上传CAD文件后长时间未显示索引完成状态。原因：未设置合理的超时阈值，或未适配大尺寸图纸的解析队列，导致任务积压。

## 怎么确认配好了
- 触发一次基于试模报告的工具调用，检查返回结果是否包含预设的模具标准化字段。
- 调用飞书多维表格接口，提交模拟的模具工艺数据，确认接口返回成功状态码。
- 上传一份小型CAD图纸，等待后查看文件索引状态，确认解析完成。
- 调用MySQL工具获取试模数据，检查输出结果是否保留原始数据的完整片段。
