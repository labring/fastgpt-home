# 模具设计制造的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据来自客户产品模型、模流或成形仿真文件、CAD/CAM导出图纸、机加工与测量数据、试模样件检测记录。通常生成的业务文档包含模具设计任务书、DFM报告、零件加工工艺卡、试模报告、改模通知、模具履历表，字段通常包含模具编号、零件材质、脱模角度、缩水率、试模缺陷类型等。数据更新按单个项目推进，每次试模或改模后同步更新。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据来源多样，包含结构化的CAD图纸、数值型仿真文件与非结构化的试模报告，需要配置适配多格式输入的模型接入规则。数据更新随项目迭代频率较高，需支持动态加载最新的试模与改模数据，避免使用过期文档生成工艺文件。工程专用术语较多，需确保模型上下文窗口足够容纳专业词汇与长文本内容，同时避免上下文溢出导致解析失败。单份模具项目文档内容较长，需合理限制模型处理的输入输出长度，保障生成效率与准确性。

## 配置怎么定
本页面配置说明基于FastGPT v4.17.0版本，具体配置项如下：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 模具相关文档单份长度可达数千字符，需容纳完整的试模报告与设计图纸解析内容，按实测标定 |
| `maxTokens` | 2000–3000 token | 工艺文件与异常报告的起草需输出完整的工艺卡或缺陷整改方案，输出长度需覆盖完整内容 |
| `quoteMaxToken` | 1500 token | 需关联引用试模数据、CAD图纸标注等参考内容，限制引用片段的总长度避免上下文溢出 |
| `temperature` | 0.2–0.4 | 工程文档需保持严谨性，降低随机性以确保工艺参数、缺陷描述的准确性 |
| `AIPROXY_API_ENDPOINT` | 与所选用大模型匹配的官方接口地址 | 适配模具工程领域常用的大模型接口，确保专业术语解析准确性 |
| `AIPROXY_API_TOKEN` | 平台分配的专属接口密钥 | 保障接口调用的安全性，避免未授权访问 |

## 容易做错的三处
- 配置`AIPROXY_API_ENDPOINT`时填写错误的接口地址，导致调用时返回连接超时或出现“Cannot read p”类报错，原因是未匹配大模型官方的标准接口路径。
- 未限制`maxContext`参数导致上下文过长，模型处理时卡滞无响应，原因是未结合模具文档的实际长度调整上下文窗口。
- 将未经过格式校验的工艺数据字符串传入模型，触发“Question is empty”报错，原因是输入内容残留空字段或无效字符。

## 怎么确认配好了
- 调用FastGPT内置的接口测试工具，输入一份简化的试模缺陷报告文本，检查是否能正常返回结构化的整改建议，无超时或报错信息。
- 查看`maxContext`参数的配置值，确认其取值与当前导入的模具文档平均长度匹配，无明显上下文溢出风险。
- 多次输入相同的试模缺陷描述，检查输出的工艺参数与缺陷整改方案的一致性，符合工程文档的严谨性要求。
- 验证`AIPROXY_API_TOKEN`的配置内容，确认未包含多余空格或错误字符，避免鉴权失败导致调用中断。
