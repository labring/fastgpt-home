# 模具设计制造的工艺文件与异常报告起草：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据主要来自注塑、冲压、压铸模具企业及制造企业模具中心，包含模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历等文档。数据来源覆盖客户产品模型、模流/成形仿真文件、CAD/CAM输出文件、机加工与测量数据、试模样件记录。数据按单个项目更新，每次试模或改模后同步更新对应文档，每份文档绑定专属模具编号、零件图号，包含脱模角度、加工公差、试模缺陷类型等字段。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据特征为检索召回环节带来三项核心约束。第一，每份文档绑定专属模具编号与零件图号，检索需精准匹配对应标识，避免召回跨项目的无关数据。第二，数据包含模流仿真、CAD图纸、加工测量记录等多类型文件，检索需支持多格式解析，且需关联试模、改模的时序记录，避免召回过时的工艺参数或缺陷报告。第三，数据更新随试模、改模动态触发，检索需支持增量同步，确保召回的是最新版本的工艺文件与异常记录。同时，文档包含脱模角度、加工公差等专业数值字段，检索需支持按数值范围匹配，不局限于关键词匹配。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配模具工艺参数的专业术语与数值范围，避免召回关联度过低的试模报告 |
| `limit` | 前 8 条 | 单项目下的工艺文档与异常报告数量通常有限，限制召回条数避免上下文过载 |
| `searchMode` | `embedding` | 支持专业术语与数值范围的语义匹配，适配模具设计的专业检索需求 |
| `usingReRank` | 开启 | 对召回的结果按与模具ID、零件图号的匹配度重排，提升精准度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展检索词，补充模具编号、零件图号等专属标识的检索维度 |
| `collectionIds` | 按项目绑定的知识库集合ID | 限定检索范围仅为当前项目的模具文档，避免跨项目干扰 |

## 容易做错的三处
- 现象为检索结果仅返回单条匹配内容，无法展示符合要求的多条工艺文件。原因是未正确配置`limit`参数，或误将参数取值设置为1，导致仅召回单条结果。
- 现象为模流仿真、CAD图纸等非文本文件无法被检索召回。原因是未启用对应格式的文档解析能力，导致非文本类工艺数据无法生成嵌入向量。
- 现象为检索结果混入其他项目的无关模具文档，无法精准匹配当前项目的模具编号。原因是未配置`collectionIds`限定检索的知识库集合，导致跨项目数据被召回。

## 怎么确认配好了
- 检索指定模具编号的工艺文档，核对召回结果是否仅包含该模具的关联文件，确认`collectionIds`配置生效。
- 输入包含专业参数（如脱模角度、加工公差）的检索词，核对召回结果是否匹配对应参数范围，确认`similarity`与`searchMode`配置合理。
- 上传最新的改模通知，等待同步完成后检索该改模事件的关键词，核对召回结果是否包含更新后的文档，确认增量同步配置生效。
- 测试非文本格式的仿真文件检索，核对是否能正常召回并解析对应内容，确认多格式解析配置完成。
