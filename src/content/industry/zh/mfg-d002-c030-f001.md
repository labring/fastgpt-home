# 橡胶混炼与制品硫化的工艺文件与异常报告起草：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的典型主体为轮胎、密封件、胶管和橡胶制品企业。日常业务文档包含配方单、称量记录、混炼曲线、胶料快检记录、硫化工艺卡、模具使用记录、成品性能报告。数据来源覆盖配方管理系统、原材料批次台账、密炼机、门尼粘度仪、流变仪、硫化机及实验室检测设备。数据更新频率为每车原材料批次、每批混炼胶料、每模次硫化制品，单条数据包含胶种名称、投料重量、工艺参数、检测结果等字段，单位涵盖千克、摄氏度、分钟、兆帕等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据高频次、多源异构的特征，对HTTP接口与外部系统集成带来多重约束。首先，每车原材料批次、每批混炼胶料、每模次硫化制品的高频更新需求，要求接口支持短周期、批量的同步调用，避免数据滞后影响生产节拍。其次，数据来源覆盖多类设备与系统，不同来源的字段格式存在差异，要求接口支持自定义参数映射，适配各类设备的输出格式。第三，核心业务文档如混炼曲线、硫化工艺卡的字段专业性强，要求接口返回的数据需精准匹配业务字段，减少无效数据传输。最后，异常报告的生成需匹配生产异常的响应时效，要求接口具备低时延的处理能力。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | Bearer {自定义API密钥} | 符合FastGPT v4.17.0的接口鉴权规范，保障调用合法性 |
| `variables` | `{"scene": "rubber_mixing_sulfurization", "max_records": 10}` | 标记当前调用属于橡胶混炼与硫化场景，限制单次拉取数据量为10条，适配小批量同步节奏 |
| `responseData` | `["recipe", "mixing_curve", "sulfur_process_card", "abnormal_report"]` | 匹配该品类的核心业务文档，过滤无关数据，减少传输开销 |
| 重试间隔 | 30秒 | 应对生产环境偶发的网络波动，保障数据同步可靠性 |
| 单次调用频率上限 | 60次/分钟 | 适配每模次的高频更新需求，避免触发平台限流 |

## 容易做错的三处
- 现象：调用`/api/v1/chat/completions`接口时，配置appId后无法关联知识库上传的配方单或硫化工艺卡。原因：未在`variables`中配置场景过滤参数，导致接口检索全量知识库内容，或未将该品类的业务文档上传至关联的知识库数据集。
- 现象：接口返回514状态码。原因：调用频率超过FastGPT平台的接口限流阈值，未适配该品类每模次的高频数据更新需求，未设置合理的单次调用数据量与调用间隔。
- 现象：拉取的异常报告字段为空或格式不匹配。原因：未在`responseData`中配置异常报告的对应字段，或未将外部系统的异常字段映射至FastGPT要求的格式，导致数据无法正确解析。

## 怎么确认配好了
- 调用测试接口，检查返回的`responseData`是否包含配方单、混炼曲线、硫化工艺卡等核心字段，验证数据过滤配置生效。
- 模拟高频次调用，连续1分钟内发起10次请求，确认接口返回200状态码，无514或鉴权失败报错，验证限流与重试配置生效。
- 查看知识库关联日志，确认已上传的该品类业务文档被正确检索到，验证appId与知识库的关联配置生效。
- 手动修改`variables`中的场景参数，验证接口返回的文档范围随参数变化，验证自定义变量配置生效。
