# 橡胶混炼与制品硫化的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
该品类的日常文档包含配方单、称量记录、混炼曲线、胶料快检、硫化工艺卡、模具记录、成品性能报告，数据来源覆盖配方系统、原材料批次管理、密炼机、门尼与流变仪、硫化机及实验室检测设备。数据更新频率为每车胶、每批原料或每模次制品生成一次，单批次数据包含投料配比、工艺参数、检测结果等结构化字段，字段单位随文档类型变化，如混炼曲线包含温度、转速、时长参数，硫化工艺卡包含压力、温度、固化时长参数。

## 这些特征在「模型接入与配置」这一环带来什么约束
高频次的单批次数据更新要求模型接入时适配小批量、高频率的文档索引与召回流程，避免因批量处理延迟影响生产节奏。多源异构的设备数据与实验室检测数据并存，要求配置时需明确不同数据源的字段映射规则，确保模型能整合跨系统的关联数据。结构化字段多且业务关联性强（如混炼曲线对应同批次硫化工艺卡），要求配置时需保留上下文关联的参数设置，避免拆分关联数据导致生成内容逻辑断裂。同时，工艺与异常报告需保持严谨性，要求配置时需约束模型的生成灵活性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 该品类单批次关联文档（混炼曲线+硫化工艺卡+检测报告）总token数通常处于该区间，可覆盖完整工艺链路的上下文信息 |
| `temperature` | `0.2–0.4` | 工艺文件与异常报告需保持严谨性，该参数区间可降低生成内容的随机性，避免偏离实际生产参数 |
| `quoteMaxToken` | `1500–2000 字符` | 需保留单批次关键工艺参数的完整引用，该区间可避免截断核心生产数据 |
| `toolChoice` | `auto` | 可根据输入内容自动选择是否调用检索工具获取最新批次的关联数据，适配高频更新的业务场景 |
| `AIPROXY_API_ENDPOINT` | 本地部署模型的专属API地址 | 适配该品类企业常部署本地模型保障生产数据安全的需求 |
| `AIPROXY_API_TOKEN` | 按企业内部安全规则生成的访问密钥 | 保障模型调用的权限安全性，避免未授权访问生产数据 |

## 容易做错的三处
- 现象：本地部署embedding-2或m3e向量模型后，配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`时持续显示索引中，无进度更新。原因：未将模型的API响应格式适配FastGPT的向量检索要求，导致平台无法正确解析返回的向量数据。
- 现象：接入本地部署的deepseek-r1模型后，生成的报告中包含`<think></think>`标签内容。原因：未在模型配置中关闭原生思考过程输出，或未配置符合FastGPT要求的标签替换规则。
- 现象：配置语音识别与重排模型后，生成的工艺文件出现字段缺失或数值异常。原因：未针对该品类的结构化文档字段（如混炼温度、硫化时长）配置模型的输出格式约束，导致模型生成内容不符合业务字段要求。

## 怎么确认配好了
- 上传单批次的混炼曲线与硫化工艺卡，触发模型生成工艺文件，检查生成内容是否包含对应批次的关键工艺参数。
- 模拟异常场景（如欠硫、过硫情况），输入对应批次的检测数据，检查模型是否能正确生成异常报告并关联历史批次的关联数据。
- 查看FastGPT v4.17.0的模型调用日志，确认`maxContext`、`temperature`等配置参数的实际生效值与预设值一致。
- 测试本地部署模型的API调用，确认返回格式符合FastGPT的接入要求，无格式错误或字段缺失。
