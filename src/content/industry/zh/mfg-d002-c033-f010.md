# 汽车零部件批量制造的工艺文件与异常报告起草：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据来源于客户图纸与特殊特性清单、ERP、MES系统、量检具、设备过程参数、供应商质保书。日常文档包含控制计划、过程流程图、作业指导书、首件与巡检记录、SPC报表、PPAP资料、8D报告。数据更新频率为每批、每班及持续采集，文档包含专属业务字段如特殊特性编号、工序参数阈值、批次号等，结构覆盖流程类、记录类、报告类多种类型。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源要求检索逻辑支持跨知识库关联召回，适配不同系统导出的文档格式。高频更新的节奏要求召回机制支持增量同步，避免重复处理全量数据。多样的文档类型与专属业务字段，要求检索规则兼顾语义匹配与精准字段匹配，确保召回内容与汽车零部件制造的专业场景强相关。批量制造的业务特性要求控制检索返回的上下文长度，避免超出处理上限，同时需关联合规类文档以满足整车客户的质量体系约束。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，具体参数设置如下：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 适配汽车零部件专业术语与专属字段的匹配精度，过滤无关的通用工艺内容 |
| `limit` | 前8条 | 控制单轮检索返回的上下文长度，适配批量制造场景下的多文档关联处理 |
| `searchMode` | `mixedRecall` | 结合语义匹配与关键词匹配，覆盖特殊特性编号、设备参数等精准业务字段 |
| `usingReRank` | 开启 | 对召回结果按业务相关性重排，优先返回首件记录、PPAP资料等核心制造文档 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户查询自动扩展关联的合规校验、专家解读类知识库内容 |
| `collectionIds` | 按工艺、异常、合规三类分组配置 | 区分不同业务域的文档集合，实现定向精准检索 |

## 容易做错的三处
- 检索结果返回大量无关的通用机械加工文档，原因是未配置`similarity`阈值或取值过低，未匹配汽车零部件专属的特殊特性字段。
- 大文档上传后无法优先处理小文档，且无手动控制的暂停/恢复功能，原因是未启用知识库上传队列的优先级调度逻辑，未对接文档分段的异步处理配置。
- 检索结果中业务字段为空或单位不匹配，原因是未针对汽车零部件的ppm、工序参数等专属字段配置精准检索规则，未关联对应集合的元数据校验。

## 怎么确认配好了
- 输入包含特定特殊特性编号的查询，核对检索结果是否优先返回对应控制计划、PPAP资料等文档。
- 上传单份大文档与多份小文档，查看上传队列是否优先处理小文档，且支持暂停与恢复操作。
- 查看检索返回结果的元数据，确认是否关联了正确的`collectionIds`分组集合。
- 触发异常报告起草相关查询，核对是否自动召回8D报告、SPC报表等关联业务文档。
