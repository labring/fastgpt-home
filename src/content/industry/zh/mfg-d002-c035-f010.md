# 热处理的工艺文件与异常报告起草：知识库检索与召回

## 这个品类的数据长什么样
热处理场景的数据来源包括材料牌号标准、客户技术条件文件、温控仪表实时数据、炉温均匀性测试报告、硬度计与金相设备检测结果、车间MES系统日志。数据更新频率为每炉次或每生产批次，单批次数据包含热处理工艺卡、装炉布置图、炉温时间曲线、硬度与金相分析报告、设备点检表、异常处置单等文档。文档字段包含炉温（单位℃）、保温时间（单位小时）、材料牌号、硬度值（单位HV或HRC）、金相组织等级、装炉位置编号等，部分文档包含可视化图表与表格数据。

## 这些特征在「知识库检索与召回」这一环带来什么约束
由于数据按炉次更新且增量频繁，检索环节需支持快速增量召回，避免全量扫描带来的性能损耗。多类型文档混合存在，包含纯文本、表格与可视化图表，需适配多模态内容的检索与召回。专业字段如金相组织等级、炉温曲线参数等要求检索匹配精度较高，避免召回无关的非热处理类文档。单炉次关联文档数量有限，但单文档内容密度较高，需控制召回结果的上下文窗口大小，避免超出模型处理上限。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 热处理数据专业度高，需较高相似度阈值过滤无关结果，避免非目标工艺的文档被召回 |
| `limit` | `前8–12条` | 单炉次相关文档数量通常在5-10份，召回过多会超出大模型上下文窗口，影响回答准确性 |
| `searchMode` | `fullTextRecall` | 场景包含炉温曲线、装炉图等非纯文本内容，全文检索可覆盖图文混排的专业文档 |
| `usingReRank` | 开启 | 专业术语较多，重排环节可优化检索结果的相关性排序，提升异常报告与工艺文件的匹配精度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 材料牌号、客户技术条件等术语存在同义词或简称，扩展查询可提升跨术语匹配的召回率 |
| `collectionIds` | 绑定热处理专属知识库集合 | 隔离其他生产品类的知识库数据，避免召回无关的机械加工、表面处理类文档 |
*注：本配置基于FastGPT v4.17.0版本*

## 容易做错的三处
- 现象：检索Excel文件时返回的匹配数据少于源文件，例如无法召回标注国外使用地的条目，原因：未开启`datasetSearchUsingExtensionQuery`，且分块时未保留完整的跨行列数据关联，导致专业字段匹配失效。
- 现象：调用自有系统的HTTPS接口时提示`Error: write EPROT`，原因：未配置正确的接口超时参数，或未处理HTTPS双向认证，无法稳定建立与知识库的连接。
- 现象：知识库中上传的工艺卡图片无法在回答中显示，或重复文件未被自动清理，原因：未开启多模态检索配置，或未启用重复文件校验功能，未绑定专属集合或未设置按文件内容哈希值去重的规则。

## 怎么确认配好了
- 输入单炉次的典型工艺参数，执行检索测试，核对召回的文档类型与字段是否匹配当前业务需求。
- 上传测试用的Excel文件与图片文件，验证检索结果中可正确关联对应附件内容，确认多模态与表格数据的召回有效性。
- 调用接口验证返回结果条数与源文件匹配度，调整`similarity`与`limit`参数至符合业务要求。
- 检查接口调用日志，确认无`Error: write EPROT`类报错，且超时参数适配当前检索负载。
