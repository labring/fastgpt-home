# 焊接结构件制造的工艺文件与异常报告起草：引用来源与溯源

## 这个品类的数据长什么样
焊接结构件制造的日常文档包含焊接工艺评定、焊接工艺规程、焊材领用记录、焊工资格记录、焊缝检验报告、返修单。数据来源涵盖设计图纸、材料质保书、焊接设备参数、焊材库、无损检测系统、人员资质台账。数据更新以每条焊缝或每批、每班为节奏，单条文档包含焊缝编号、焊材批号、焊工证号、检测数值等固定字段，单位涉及毫米、兆帕、小时等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
该品类的数据更新频率高且关联维度多，需精准匹配焊缝编号、焊材批号、焊工证号等核心字段完成溯源，否则会导致工艺文件错误或异常报告失效。多源分散的数据来源要求溯源环节需跨系统关联提取信息，无法仅依赖单一知识库来源。文档中的刚性资质文件需严格对应人员与物料的有效期限，溯源环节需同步验证文档的更新时间与合规状态。单条焊缝的关联文档数量有限，需避免冗余检索干扰核心内容的呈现。

## 配置怎么定
本页面配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | 焊接结构件的工艺文件单条内容较长，需保留足够上下文用于精准溯源 |
| `responseData` | 开启原文片段提取 | 需返回焊材批号、焊工证号等精确字段，用于合规核验 |
| 单次搜索上限 | 前6条 | 每批焊缝的关联数据通常不超过6类，过多会干扰核心内容呈现 |
| `detail` | 开启详细溯源 | 需标注文档来源系统、更新时间，满足特种设备验收的合规要求 |
| 查看来源权限 | 按业务场景配置 | 部分内部资质文档需隐藏敏感信息，部分需公开溯源依据 |

## 容易做错的三处
- 现象：调用后仅返回文档引用链接，无对应工艺内容。原因：未开启`responseData`配置，仅返回元数据未提取原文片段。
- 现象：所有文档均显示查看来源原文，无法隐藏敏感的焊工资质信息。原因：未按业务场景细分配置查看权限，统一开启了可见度开关。
- 现象：部分焊缝的返修单未被检索到，无法完成溯源。原因：知识库分块时未保留焊缝编号字段，导致检索匹配失败。

## 怎么确认配好了
- 输入包含特定焊缝编号的查询，核对返回结果中是否包含对应焊材领用记录的原文片段。
- 切换查看来源权限，确认敏感文档的引用内容是否被隐藏，非敏感文档可正常显示。
- 测试批量检索多份关联文档，确认返回的溯源结果数量符合预设的单次搜索上限。
- 查看系统日志，确认`detail`配置开启后显示了文档来源系统与更新时间。
