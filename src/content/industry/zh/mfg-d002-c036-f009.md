# 焊接结构件制造的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
焊接结构件制造的业务数据来源包括设计图纸、材料质保书、焊接设备参数、焊材库台账、无损检测系统记录与人员资质台账。日常生成的文档包含焊接工艺评定、焊接工艺规程、焊材领用记录、焊工资格记录、焊缝检验报告与返修单。数据更新频率为每条焊缝或每批、每班，文档字段包含母材牌号、焊材型号、焊缝位置、检测缺陷类型、返修次数等，无统一跨企业的固定单位格式，随企业现有台账调整。

## 这些特征在「模型接入与配置」这一环带来什么约束
焊接结构件制造的数据特征对模型接入与配置带来多重约束。多源异构的数据来源要求配置兼容多类文档格式的读取逻辑，适配设计图纸、台账、检测记录等不同类型的输入。高频更新的业务数据需适配小批量高频查询的上下文处理，避免因上下文溢出导致的生成异常。无统一字段格式的文档要求配置支持非结构化数据的解析，无需强制标准化输入即可完成内容提取。此外，焊缝检验与返修单的强关联需求，需配置上下文关联与联动逻辑，确保报告起草时能自动关联对应焊缝的资质与检测数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配焊接结构件多文档关联的上下文需求，避免因上下文不足丢失焊缝、焊材、资质的关联信息，适配FastGPT v4.17.0的上下文处理逻辑 |
| `temperature` | 0.2–0.4 | 焊接工艺与报告需严格匹配资质要求，较低温度可提升输出的规范性与一致性，避免生成不符合规范的内容 |
| `vision` | 开启 | 需识别设计图纸中的焊缝位置、焊材标注等视觉信息，支持图像类数据源的解析与内容提取 |
| `AIPROXY_API_ENDPOINT` | 按部署的代理地址填写 | 适配本地部署FastGPT的模型调用链路，确保请求能正确转发至目标模型服务 |
| `AIPROXY_API_TOKEN` | 填写代理服务分配的验证令牌 | 保障模型调用的身份合法性，防止未授权访问与请求拦截 |
| `quoteMaxToken` | 2000–3000 token | 限制引用文档的最大长度，避免生成时因引用内容过多导致上下文溢出，优化生成效率 |

## 容易做错的三处
- 现象：对话时无法输出知识库中的图片内容，界面显示图片占位符为空或报错「无法加载图像」。原因：未开启`vision`配置项，或未将图片资源正确映射为可访问的URL地址，导致模型无法获取图像数据。
- 现象：上传Word格式的焊接工艺文档后，模型识别内容为空，返回「未检测到有效文本」。原因：未配置支持Word文档解析的预处理模块，或上传的文档存在加密、格式损坏问题，导致FastGPT无法提取文本内容。
- 现象：调用模型生成报告时出现超时错误，状态码为504或提示「请求超时」。原因：`maxContext`配置值过小，导致模型需要处理的上下文内容过多，超出模型服务的响应时限，或代理配置的超时阈值设置过低。

## 怎么确认配好了
- 上传一张焊接结构件的设计图纸图片至知识库，发起包含「提取图中焊缝位置」的查询，确认模型能正确返回图像中的标注信息。
- 上传一份Word格式的焊材领用记录，发起查询要求提取记录中的焊材型号与领用数量，确认模型能返回非空的解析结果。
- 配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`后，发起一次模型调用，检查代理服务日志中是否有成功的请求响应，无报错信息。
- 调整`temperature`至0.3，生成一份焊缝检验报告，核对输出内容是否符合焊接工艺的刚性约束，无明显违规表述。
