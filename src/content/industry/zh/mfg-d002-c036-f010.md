# 焊接结构件制造的工艺文件与异常报告起草：知识库检索与召回

## 这个品类的数据长什么样
焊接结构件制造的核心数据覆盖钢结构、压力容器、工程机械及轨道车辆结构件企业的全流程文档，包括焊接工艺评定、焊接工艺规程、焊材领用记录、焊工资格记录、焊缝检验报告、返修单。数据来源涵盖设计图纸、材料质保书、焊接设备参数、焊材库、无损检测系统、人员资质台账。数据更新随每条焊缝、每批物料或每班生产节奏触发，单条文档包含工艺参数、资质编号、检测结果等明确字段，无冗余模糊项。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类数据多来自异构系统，且更新频率随生产节点触发，要求检索环节支持实时增量同步。文档包含焊工资质编号、工艺评定编号、焊缝检测参数等刚性约束字段，检索需精准匹配字段，采用字段定向匹配逻辑。单条数据关联度强，检索结果需覆盖工艺、资质、检测多维度信息，避免单一维度召回导致的工艺与资质不匹配问题。同时，数据失效会直接引发结构失效风险，要求召回结果的置信度需匹配业务刚性约束。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 焊接结构件的工艺参数、资质编号需精准匹配，该区间可过滤无关结果同时保留有效匹配项 |
| `limit` | `前6条` | 单批次生产涉及的工艺、资质、检测数据量集中，6条结果可覆盖核心关联信息且不超出上下文窗口 |
| `searchMode` | `fullTextRecall` | 查询示例侧重标识符或专业术语；请用代表性数据实测该模式，不将其视为产品默认值。 |
| `usingReRank` | `开启` | 多源异构数据的语义相似度需二次校准，提升结果排序准确性 |
| `datasetSearchUsingExtensionQuery` | `开启` | 可将工艺问题扩展为关联的资质、检测查询，覆盖全流程数据 |
| `collectionIds` | `绑定焊接结构件专属数据集` | 隔离其他品类数据，避免无关文档干扰检索结果 |

## 容易做错的三处
- 现象：调用知识库生成时返回Validation failed: name: Path `name` is required. 报错。原因：未为焊接结构件专属数据集配置必填的名称元数据字段，或导入的文档未携带对应标识信息。
- 现象：查看聊天回答的知识库引用时出现报错。原因：检索结果的文档元数据未完整保留，或`usingReRank`配置开启后丢失了原始文档的关联标识。
- 现象：检索结果未覆盖焊材领用记录等焊材库数据。原因：未将焊材库对应的数据集集合添加到`collectionIds`配置中，导致检索范围受限。

## 怎么确认配好了
- 提交一条包含焊工资质编号的查询，核对检索结果是否包含对应的焊工资格记录、焊接工艺评定文档。
- 触发一次增量同步，确认焊材库、无损检测系统的新数据是否在预设同步周期内完成检索覆盖。
- 查看检索日志，确认`similarity`、`limit`等配置项的实际取值与预设一致。
- 测试按需隐藏知识库引用的操作，确认回答中可根据需求调整引用展示状态。
