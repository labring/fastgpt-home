# 生物制品与无菌生产的工艺文件与异常报告起草：部署与升级

## 这个品类的数据长什么样
本品类的核心数据来自细胞库与种子批、过程分析、洁净区监测、MES、LIMS、设备完整性测试。日常文档包含细胞库或种子批记录、培养纯化记录、无菌灌装记录、环境监测、培养基模拟灌装、无菌检验、批放行资料，包含批次号、培养温度（℃）、洁净区沉降菌浓度（cfu/㎡）、设备运行时长（小时）等固定字段。数据更新频率分为每批、实时、按监测计划三类，部分实时监测数据的更新间隔不超过15分钟。

## 这些特征在「部署与升级」这一环带来什么约束
多源分散的数据来源要求部署阶段支持对接多系统接口，避免数据同步中断影响生产文档的完整性。不同更新节奏的数据需要适配增量同步与批量导入两种模式，升级阶段需兼容旧版数据结构，防止跳级升级导致历史记录无法检索。复杂的文档字段与严格的合规要求，要求配置阶段完成自定义字段映射，同时保障数据访问权限仅对授权人员开放，避免敏感生产数据泄露。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150 条/分钟` | 适配MES、LIMS等多数据源的并发请求，避免连接池耗尽导致数据同步失败 |
| `MONGODB_URI` | 指向存储无菌生产记录的专用MongoDB集群 | 隔离业务数据与通用数据，保障生产文档的访问权限与稳定性 |
| `REDIS_URL` | 配置为本地缓存节点，过期时间设为30分钟 | 缓存实时洁净区监测数据，减少重复查询LIMS的网络开销 |
| `STORAGE_S3_ENDPOINT` | 对接企业合规的对象存储服务端点 | 存储培养基模拟灌装、无菌检验的原始扫描件，符合数据留存要求 |
| `FILE_TOKEN_KEY` | 配置为与企业IAM系统联动的密钥 | 保障工艺文件与异常报告的上传、下载权限仅开放给授权生产人员 |

## 容易做错的三处
- 直接跳级升级到FastGPT v4.17.0后，旧版工艺文件的索引无法正常检索。未按版本迭代的兼容步骤升级，跳过了中间版本的数据库结构迁移，导致历史数据无法被正确解析。
- 在openEuler arm64系统部署时，`MONGODB_URI`连接失败。未使用适配arm64架构的MongoDB镜像，导致数据库驱动与系统架构不兼容，无法建立有效连接。
- 调用接口创建文本集合时返回403状态码。未正确配置`FILE_TOKEN_KEY`，导致文档上传的权限校验不通过，接口请求被拦截。

## 怎么确认配好了
- 执行数据库连通性测试脚本，验证`MONGODB_URI`与`REDIS_URL`的连接状态，确认并发连接数不超过`DB_MAX_LINK`的配置值。
- 上传一份培养基模拟灌装记录的扫描件，验证`STORAGE_S3_ENDPOINT`的存储与读取功能正常，文件可正常预览。
- 发起一次实时洁净区监测数据的检索请求，确认返回结果的延迟符合预设阈值，无超时报错。
- 调用指定接口创建文本集合，验证返回结果包含有效的文档ID，无权限相关的报错信息。
