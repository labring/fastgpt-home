# 电机与发电机制造的工艺文件与异常报告起草：工具调用与插件

## 这个品类的数据长什么样
本品类数据来自电机厂绕线、绝缘、总装与试验部门，日常文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试记录、型式与出厂试验报告。数据来源于电磁设计数据、铜线和绝缘材料批次信息、绕线设备、平衡机、电气试验台及ERP/MES系统，更新频率为每台或每批产品、每次型式变更时触发。文档包含绕组匝数、接线方式、浸漆参数、试验电压、温升数据等字段，部分需匹配设备运行日志与物料批次信息。

## 这些特征在「工具调用与插件」这一环带来什么约束
品类数据的多源属性要求工具调用需兼容设备日志、ERP数据与文档文本的格式对齐，避免跨系统字段不匹配。单台/单批的高频更新要求插件调用需支持实时拉取最新批次物料与试验数据，无法依赖静态缓存。文档字段的专业性（如耐压绝缘测试的电压单位、动平衡的不平衡量参数）要求工具调用需匹配特定字段映射，避免通用插件的字段适配偏差。型式变更触发的更新要求插件支持动态调整调用逻辑，适配新的工艺参数与试验标准。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工作流/API 工具选择配置 | 自动选择匹配的工具 | 适配电机制造场景下多源数据的调用需求，自动匹配工艺卡、试验数据与异常分析工具 |
| 工作流/API 函数调用配置 | 启用强制工具调用 | 确保异常报告起草时必须调用试验数据与工艺参数工具，避免生成无依据的内容 |
| 分块长度 | 800–1200 字符 | 适配绕组工艺卡、试验报告等长文档的字段完整性，避免拆分专业术语 |
| 单次工具调用上限 | 前 3 条 | 匹配单台电机的试验数据与工艺参数数量，避免冗余调用占用资源 |
| 工具调用超时时间 | 60 秒 | 适配电气试验台、平衡机等设备的数据拉取延迟，避免超时中断关键流程 |
| 上下文窗口大小 | 4000  token | 容纳多份试验报告与工艺卡的核心内容，支持异常报告起草时的全量数据参考 |

## 容易做错的三处
- 调用插件时返回 AxiosError 404 报错，原因是未将插件的目标接口地址配置为企业内部设备或MES系统的实际域名，误使用了示例域名。
- BI图表插件返回的字段为空，原因是未配置匹配电机试验数据的字段映射规则，通用插件无法识别耐压电压、动平衡值等专业字段。
- 工具调用超时，原因是设置的超时时间过短，未适配电气试验台等设备的数据拉取延迟，导致未完成数据拉取即终止调用。

## 怎么确认配好了
基于 FastGPT v4.17.0 版本，可通过以下动作核对配置：
- 上传一份绕组工艺卡与动平衡报告，发起“生成本次产品的异常报告”提问，核对工具调用返回的设备数据与上传文档的字段是否匹配。
- 查看插件调用日志，确认接口请求的域名与企业内部设备系统的实际地址一致，无示例域名残留。
- 模拟一次异常场景，发起调用请求，确认工具调用的耗时未超过配置的超时时间，无超时报错。
- 测试多次工具调用，确认未超过单次调用上限的限制，无调用被拦截的提示。
