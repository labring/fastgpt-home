# 电池PACK与储能系统集成的工艺文件与异常报告起草：HTTP 接口与外部系统

## 这个品类的数据长什么样
本品类的核心数据来自电芯分容设备、生产MES系统、焊接扭矩工具、BMS软件、EOL试验台等。日常生成的文档包含配组规则、BOM清单、焊接扭矩记录、BMS刷写日志、绝缘耐压报告、EOL测试数据、系统配置清单。数据更新频率为每完成一个电池包或储能柜的生产即更新一次，每次BMS软件版本变更也会触发数据更新。字段包含电芯容量（单位Ah）、内阻（单位mΩ）、焊接扭矩（单位N·m）、绝缘电阻（单位MΩ）、BMS版本号、充放电电压（单位V）等，单份工艺文件数据量约为800–1200字符。本页面基于FastGPT v4.17.0版本编写。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
本品类的数据来源分散且更新频率高，要求HTTP接口支持多设备数据的批量拉取与实时同步。多字段的业务需求要求接口需支持指定返回字段，避免冗余数据传输。严重的出错后果要求接口需配置鉴权与重试机制，防止异常数据流入工艺文件与异常报告。内网部署场景下，部分设备无法直接访问互联网，要求接口支持带用户名密码的HTTP代理配置，适配内网访问需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {fastgpt_api_token}` | 符合HTTP接口鉴权标准，适配多厂商外部系统对接 |
| `variables` | `{"product_type": "pack", "report_scope": "eol"}` | 传递品类专属的业务参数，区分不同类型的工艺文件与异常报告 |
| `responseData` | `include:["torque_value","insulation_resistance","bms_version","related_docs"]` | 仅返回工艺文件与异常报告所需的核心字段，减少数据传输量，同时支持返回关联的知识库文档信息 |
| 请求超时时间 | 300 秒 | 适配焊接、EOL测试等环节的数据采集延迟，避免接口中断 |
| HTTP代理配置 | 代理地址+端口+用户名密码 | 适配内网部署场景下的互联网访问需求，解决内网服务器无法直接访问外部数据的问题 |

## 容易做错的三处
- 现象：接口返回`Data too long for column 'models'`报错，原因：未限制`variables`或自定义字段的长度，导致传入的BOM明细或电芯参数超出数据库字段存储上限。
- 现象：免登录链接跨设备访问时无法加载工艺文件，原因：未配置接口的跨域白名单，导致外部设备无法通过链接调用FastGPT的接口获取数据。
- 现象：接口返回的`responseData`字段为空，原因：未指定需要返回的业务字段，导致接口未匹配到工艺文件所需的电芯、测试数据。

## 怎么确认配好了
- 调用测试接口，检查`Authorization`鉴权头是否被正确携带，返回状态码为200。
- 传入预设的`variables`参数，检查接口返回的`responseData`是否包含品类专属的业务字段。
- 在内网代理环境下测试接口调用，确认可以正常访问外部数据来源，无连接超时报错。
- 模拟异常场景触发接口，检查是否能正确生成异常报告所需的字段数据。
