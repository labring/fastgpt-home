# 电池PACK与储能系统集成的工艺文件与异常报告起草：多轮对话与提示词

## 这个品类的数据长什么样
该品类的核心数据覆盖动力电池包、储能柜及BMS系统的全流程生产与测试环节。日常文档包含配组规则、BOM清单、焊接扭矩记录、BMS刷写记录、绝缘耐压报告、EOL测试数据、系统配置清单。数据来源包括电芯分容数据库、工厂MES系统、焊接设备日志、扭矩工具记录、BMS软件版本库、EOL试验台数据。数据更新频率为每生产一包或一台储能柜更新一次，每次BMS软件版本变更同步更新。各文档字段需按对应环节匹配专属单位，如扭矩值以牛米计、测试电压以伏特计。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
品类的多源数据来源要求对话系统需关联多个独立数据源的变量，避免单数据源的信息缺失。高频更新频率要求多轮对话需实时调用最新的生产与测试数据，确保工艺文件与异常报告的时效性。多字段、专属单位的文档结构要求提示词需明确指定字段范围与匹配规则，减少参数混淆。单包/单柜的专属数据特征要求每轮对话绑定唯一的工单标识，确保生成内容与对应产品完全匹配。热管理失效、BMS配置错误等严重后果要求多轮对话需加入参数校验环节，确保高压连接、绝缘测试等关键数据的准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chatId` | 绑定当前生产工单的唯一标识 | 关联单包或单柜的专属BOM、焊接记录、EOL测试数据，避免跨工单的信息混淆 |
| `messages` | 保留前15–20轮对话内容 | 覆盖配组规则、焊接参数、BMS配置等全流程历史信息 |
| `variables` | 导入「电芯分容数据」「焊接扭矩记录」「EOL测试数据」三个指定集合 | 直接调用品类核心的生产与测试数据源，减少手动录入 |
| 最大上下文长度 | 8000–12000 字符 | 适配多环节文档的总长度，避免关键信息被截断 |
| 问题优化开关 | 开启 | 简化专业工艺术语的表述，适配现场工程师的输入习惯 |
| 变量引用温度 | 0.2–0.4 | 保证工艺参数与异常描述的准确性，降低主观偏差 |

## 容易做错的三处
- 配置数据库连接插件后弹出报错提示，日志显示数据源连接超时。原因是未将工厂MES系统、EOL试验台的通信端口添加至FastGPT的出站访问白名单。
- 变量引用模式下温度设置按钮消失，无法调整参数。原因是FastGPT v4.17.0及之前版本中，变量引用模式默认锁定温度参数，需通过自定义提示词指定温度参数。
- 点击对话复制按钮后，生成的Markdown内容无回车换行，粘贴后格式混乱。原因是未开启对话内容的自动换行渲染开关，或未正确配置Markdown格式的换行符。

## 怎么确认配好了
- 输入已知的电芯分容参数，检查对话是否能调用绑定的`variables`数据生成对应的配组规则，确认数据源关联正常。
- 查看会话绑定的`chatId`是否与当前生产工单的唯一标识一致，确认会话上下文与对应产品的匹配性。
- 测试复制对话内容，检查生成的Markdown格式是否包含正确的换行符，确保粘贴后排版正常。
- 调整自定义提示词中的温度参数，检查生成的异常报告是否保持了准确的专业术语表述，无主观化偏差。
