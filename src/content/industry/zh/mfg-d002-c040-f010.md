# 电池PACK与储能系统集成的工艺文件与异常报告起草：知识库检索与召回

## 这个品类的数据长什么样
该品类的核心文档涵盖配组规则、BOM清单、焊接与扭矩记录、BMS刷写记录、绝缘耐压报告、EOL测试报告、系统配置清单。数据来源于电芯分容系统、车间MES系统、焊接设备、扭矩工具、BMS软件版本库、EOL试验台。数据更新以单台电池包或储能柜为最小单位，每次软件版本变更时同步更新，文档字段包含电芯参数、扭矩值、测试电压、软件版本号等，单位涵盖毫安时、牛米、伏特等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据特征对知识库检索召回带来多重约束。多源分散的数据来源要求检索链路支持对接不同系统导出的文档，需配置跨数据源的知识库集合。高频小批量更新模式要求优先启用增量解析功能，避免全量重扫带来的资源浪费。文档包含专业工程参数与单位，检索时需保留字段精确匹配能力，避免模糊匹配导致的参数错位。单台设备绑定的专属记录，要求召回结果可按设备序列号或批次筛选，确保起草工艺文件或异常报告时调用的是对应批次的合规数据。

以下配置基于FastGPT v4.17.0版本。
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 该品类文档多为专业工程内容，需较高相似度阈值避免无关配组规则、测试记录混入检索结果 |
| `limit` | 前8条 | 兼顾工艺文件与异常报告的全面性与可读性，过多结果会增加上下文整理负担 |
| `searchMode` | 精确匹配 | 文档包含带单位的专业工程参数，精确匹配可避免参数错位导致的工艺错误 |
| `usingReRank` | 开启 | 多源知识库召回的结果存在相关性差异，重排可提升核心文档的展示优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 工艺起草需关联配组规则与对应批次测试记录，扩展查询可补充关联上下文 |
| `collectionIds` | 对应电池PACK与储能系统集成的知识库集合ID | 该品类文档分散在多个知识库中，指定集合ID可避免召回无关品类的内容 |

## 容易做错的三处
- 现象：检索结果未按预设标签筛选，混入了电芯制造类文档。原因：未在检索环节配置标签筛选逻辑，或录入文档时未添加电池PACK专属的分类标签。
- 现象：知识库召回结果条数与配置的`limit`不符，出现过多或过少的结果。原因：未正确设置`limit`参数，或知识库中有效文档数量不足导致召回结果未达预期。
- 现象：主动推送的文档无法被检索到。原因：未完成推送文档的解析切片流程，或未将文档关联到指定的`collectionIds`集合中。

## 怎么确认配好了
- 上传一条该品类的专属测试文档，添加预设分类标签，发起检索并核对是否仅召回带对应标签的内容。
- 检查知识库管理界面，确认主动推送的文档已完成解析切片并关联到指定的知识库集合。
- 调整`similarity`参数，验证检索结果的相关性是否随参数变化符合预期。
- 发起工艺文件起草的模拟调用，核对召回的文档是否包含配组规则、BOM清单等该品类专属内容。
