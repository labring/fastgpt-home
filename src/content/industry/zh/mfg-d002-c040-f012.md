# 电池PACK与储能系统集成的工艺文件与异常报告起草：部署与升级

## 这个品类的数据长什么样
该品类的日常文档包含配组规则、BOM清单、焊接与扭矩记录、BMS刷写记录、绝缘耐压报告、EOL测试结果、系统配置清单。数据来源为电芯分容数据、MES系统、焊接设备、扭矩工具、BMS软件版本记录、EOL试验台。数据更新节奏为每生产一个电池包或储能柜即生成对应记录，同时在每次BMS软件版本变更时同步更新关联文档，数据字段涵盖电芯参数、设备运行参数、测试结果、软件版本等核心生产信息。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据来源覆盖生产设备、测试系统与软件记录，多源异构数据的接入需求提升了部署阶段的接口适配复杂度。高频次的更新节奏要求部署时配置支持单份小体量文档的快速索引，避免批量任务的资源占用过载。多样的文档类型与专属字段，需要在部署阶段预设对应的数据解析与校验规则，确保后续起草的工艺文件与异常报告字段合规。同时，生产数据直接关联系统运行安全，部署时需配置数据校验环节，防止错误参数流入后续流程。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配该品类的生产场景：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `PG_URL` | `postgresql://username:password@host:5432/pack_manufacture` | 该品类的生产数据多存储于PostgreSQL数据库，需匹配专属业务库的连接地址 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 用于缓存高频访问的电芯分容、BMS配置等数据，默认0号库可隔离业务缓存与其他服务 |
| `DB_MAX_LINK` | `20–30 个` | 该品类单批次生产数据量适中，20-30个连接可平衡资源占用与并发索引需求，按实测标定可调整 |
| `STORAGE_S3_ENDPOINT` | `http://minio.example.com:9000` | 该品类的测试报告、BOM等文档多存储于对象存储服务，需匹配对应存储节点的访问地址 |
| `FE_DOMAIN` | `https://pack-manufacture.example.com` | 用于配置平台前端访问域名，匹配该品类的业务系统域名规则 |
| `FILE_TOKEN_KEY` | `随机生成的 32 位字符串` | 用于加密文档访问令牌，保障生产文档的访问安全，避免未授权访问 |

## 容易做错的三处
- 知识库索引任务中断，日志显示「文件读取失败」。原因：未配置`STORAGE_S3_ENDPOINT`或配置错误，无法访问存储的焊接记录、EOL测试报告等文档。
- 数据库连接超时，索引任务无法完成。原因：未调整`DB_MAX_LINK`至适配该品类数据量的取值，连接池耗尽无法处理并发索引请求。
- 嵌入模型调用返回异常，无法生成文档向量。原因：未正确配置`REDIS_URL`，导致缓存的模型调用参数丢失，触发服务校验失败。

## 怎么确认配好了
- 执行单份电芯分容数据的索引任务，确认任务状态为成功，可根据该品类的文档数量调整索引并发数。
- 访问前端域名`FE_DOMAIN`，确认可正常登录平台并查看已上传的BOM清单、绝缘耐压报告等文档。
- 调用数据库连接测试接口，确认数据库连接池的可用连接数符合预设的`DB_MAX_LINK`取值。
- 上传一份带专属字段的文档（如焊接扭矩记录），确认解析后字段完整，可正常用于工艺文件起草。
