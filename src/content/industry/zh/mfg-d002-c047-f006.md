# 计量器具与实验室管理的工艺文件与异常报告起草：引用来源与溯源

## 这个品类的数据长什么样
该品类数据来自企业计量室、CNAS体系实验室的日常业务文档，包含量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账及偏离处置文件。数据来源涵盖企业内部计量管理系统、外部校准机构证书、标准器、LIMS系统与环境监测数据，更新节奏随校准周期、单次试验完成或异常事件触发。文档包含器具编号、测量值、不确定度、校准日期等字段，单位随测量对象覆盖各类计量场景。

## 这些特征在「引用来源与溯源」这一环带来什么约束
该品类的溯源需求需关联多源业务数据，因此需支持跨知识库的精准匹配。数据更新无固定周期，需配置增量索引机制以保证溯源信息的时效性。文档包含高精度测量数据与不确定度字段，对引用内容的准确性要求极高，需过滤无关检索结果。异常报告与工艺文件需留存完整溯源链，因此需限制引用条数与单条引用长度，避免上下文过载影响生成质量。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 最大上下文 | 8000–12000 token | 计量类文档包含校准证书、原始记录等长文本，需完整加载溯源链关联数据 |
| 知识库最大引用 | 前6条 | 单份校准证书关联多台计量器具，控制引用条数避免上下文过载 |
| 最大响应tokens | 2000–3000 token | 异常报告起草需完整呈现溯源信息，避免截断关键内容 |
| `quoteMaxToken` | 1500 字符 | 限制单条引用的显示长度，适配计量文档的字段排版要求 |
| `responseData` | 开启溯源字段 | 自动关联计量管理系统的器具编号、校准日期等核心溯源字段 |

## 容易做错的三处
- 界面显示红色错误提示，引用内容无法正常加载。原因：未配置多数据源关联，或知识库最大引用取值超出系统允许范围。
- 生成的异常报告缺少校准证书溯源信息。原因：最大上下文取值过小，未加载完整的溯源链关联数据。
- 响应结果中引用标记过多干扰阅读。原因：未调整`quoteMaxToken`参数，或知识库最大引用取值过高。

## 怎么确认配好了
- 导入一份校准证书作为测试数据，发起异常报告起草请求，核对返回结果中是否包含器具编号、校准日期等溯源字段。
- 查看FastGPT v4.17.0的知识库索引日志，确认计量类文档已按校准周期完成增量更新。
- 调整`quoteMaxToken`参数后，检查单条引用的显示长度是否符合预期排版要求。
- 测试多知识库关联场景，确认同时调用计量管理系统与LIMS系统的数据时无冲突。
