# 计量器具与实验室管理的工艺文件与异常报告起草：知识库检索与召回

## 这个品类的数据长什么样
该品类数据来自企业计量室、CNAS体系实验室的计量管理系统、LIMS平台、外部校准机构证书及标准器数据。日常文档包含量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账、偏离处置记录等，字段包含器具唯一编号、校准日期、测量值、测量不确定度、溯源链关联信息等，单位涵盖毫米、牛顿、百分比、毫克每升等计量专用单位。数据更新按校准周期、每次试验或异常情况触发，无固定批量更新节奏。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据来源分散且格式多样，需对接多类数据源，召回时需统一识别不同文档的核心计量字段。文档包含高精度数值与严格溯源信息，要求检索结果与原始数据匹配度满足计量置信度要求。更新节奏无固定周期，需支持增量召回以避免重复处理已完成校准的器具数据。工艺文件与异常报告需关联特定器具的全周期计量数据，检索时需优先匹配强关联字段，否则会导致工艺参数错误或异常判定无效。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75-0.85 | 计量数据需保证置信度，避免召回低匹配度的非对应校准记录 |
| `limit` | 前5条 | 控制单轮召回的文档数量，避免过多历史记录干扰起草工作 |
| `searchMode` | `fullTextRecall` | 查询示例侧重标识符或专业术语；请用代表性数据实测该模式，不将其视为产品默认值。 |
| `usingReRank` | 开启 | 对召回结果按溯源链完整性、测量不确定度精度重新排序，提升关键信息可见性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动补充器具溯源相关的上下文关键词，强化跨文档的关联召回 |
| `collectionIds` | 指定计量器具专属集合ID | 隔离业务数据，避免召回其他品类的文档干扰 |

本配置基于FastGPT v4.17.0版本的参数逻辑。

## 容易做错的三处
- 上传校准证书类PDF后无解析完成提示，搜索测试结果为空。原因是未开启批量解析的状态通知，且未将文档导入指定的计量器具专属集合。
- 异常报告起草时未调用知识库内容，生成的内容与实际计量数据不符。原因是`similarity`阈值设置过高，导致无符合要求的召回结果。
- 工作流中提取知识库信息为空。原因是文档分块时未覆盖校准证书的溯源链字段，导致关键关联信息未被向量化。

## 怎么确认配好了
- 上传单份校准证书后，查看平台解析状态，确认无格式报错且解析字段包含器具编号、测量值、溯源链信息等核心内容。
- 发起搜索测试，输入指定器具的唯一编号，验证是否召回对应台账、校准计划、历史校准证书等文档。
- 调整`similarity`阈值至0.8，发起异常报告起草测试，确认结果中包含校准证书的测量不确定度信息。
- 查看工作流日志，确认知识库召回步骤返回的文档数量符合`limit`配置的取值。
