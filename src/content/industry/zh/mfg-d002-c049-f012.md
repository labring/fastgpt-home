# 过程质量与成品放行的工艺文件与异常报告起草：部署与升级

## 这个品类的数据长什么样
这个品类的数据来自MES系统、生产检测设备、实验室系统、工艺参数库、客户质量标准与历史缺陷库。日常生成的文档包含控制计划、巡检记录、SPC报表、成品检验报告、不合格品评审单、放行单与质量月报。数据更新节奏为每生产批次、每班持续采集，部分历史数据按需同步。文档字段包含批次标识、检验参数阈值、缺陷类型、评审意见与放行标识，对应单位涵盖生产件数、检验时长、不合格等级等生产检验场景的标准单位。

## 这些特征在「部署与升级」这一环带来什么约束
多数据源与实时更新的特性要求部署时需配置多类型存储连接，支撑批量数据写入与高频查询。多格式文档的接入需要适配不同解析规则，避免格式解析失败。数据字段的复杂性要求向量入库时需准确映射业务字段，确保检索精度。同时，涉及成品放行的核心数据需保证一致性，部署升级过程中需避免配置变更导致数据同步中断，影响生产流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–200 条/分钟` | 适配每批、每班的批量数据写入节奏，避免数据库连接池耗尽 |
| `MONGODB_URI` | `对应生产质量数据库的专属连接串` | 存储SPC报表、不合格品评审单等非结构化文档与历史缺陷库 |
| `REDIS_URL` | `本地Redis实例的内网访问地址` | 缓存实时巡检记录与放行单的查询结果，降低主数据库的查询压力 |
| `STORAGE_S3_ENDPOINT` | `企业内部对象存储的接入端点` | 存储成品检验报告、控制计划等大体积文档，适配批量存储需求 |
| `FE_DOMAIN` | `部署服务的公网或内网域名` | 生成工艺文件下载链接时匹配正确的访问路径，避免链接失效 |
| `FILE_TOKEN_KEY` | `随机生成的32位加密字符串` | 加密知识库原文下载链接，防止未授权访问核心质量文档 |

本页配置适用于FastGPT v4.17.0版本。

## 容易做错的三处
- 知识库原文下载链接无法正常访问，返回403或404错误：未正确配置`FE_DOMAIN`与nginx代理规则，导致生成的下载链接与实际访问路径不匹配。
- 容器重启后质量数据的同步任务中断：未将`MONGODB_URI`、`REDIS_URL`等核心配置写入持久化环境变量，仅在启动时临时传入，重启后配置丢失。
- 批量导入不合格品评审记录时出现连接超时：未根据数据写入频率调整`DB_MAX_LINK`的取值，连接池无法支撑批量写入请求。

## 怎么确认配好了
- 访问配置的`FE_DOMAIN`对应的下载链接，验证工艺文件与异常报告的原文可以正常下载。
- 进入部署容器执行环境变量查询命令，确认`MONGODB_URI`、`REDIS_URL`等配置参数已正确加载。
- 提交一条测试用的巡检记录，等待1分钟后查询对应存储，确认数据已成功写入。
- 生成异常报告的预览链接，验证加密参数`FILE_TOKEN_KEY`未被篡改，链接可正常访问。
