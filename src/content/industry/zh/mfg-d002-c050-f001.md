# 通用机械设备装配的工艺文件与异常报告起草：HTTP 接口与外部系统

## 这个品类的数据长什么样
通用机械设备装配场景的数据主要来自PLM、ERP、零件检验系统、装配工具采集终端、试验台、MES及客户技术协议。日常文档包含装配工艺卡、BOM、扭矩记录、间隙调整记录、试运行报告、出厂检验单与装箱清单，数据按每台设备或每订单更新。文档字段包含设备型号、部件编号、扭矩值、间隙参数、试验结果等，单位涵盖牛米、毫米、帕斯卡等，部分字段需匹配客户技术协议的定制要求。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
通用机械设备装配的数据按单台或单订单更新的特性，要求HTTP接口支持单次请求携带单订单或单设备的全量文档数据，避免跨订单数据混淆。多类来源的异构数据，要求接口支持不同格式的请求体与响应体适配，需提前统一字段映射规则。定制化的客户技术协议字段，要求接口预留动态变量配置空间，适配不同客户的字段要求。装配过程的实时数据（如扭矩、间隙）需低延迟同步，要求接口超时设置匹配现场采集节奏，避免数据丢失或不完整。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {平台分配的API密钥}` | 符合HTTP接口鉴权规范，保障外部系统调用的合法性 |
| `variables` | `{"orderId": "请求路径提取", "deviceModel": "动态匹配"}` | 适配单订单、单设备的动态数据拉取，匹配按订单更新的业务节奏 |
| `responseData` | `仅保留装配工艺卡、扭矩记录、间隙调整字段` | 过滤冗余数据，降低接口传输与解析的负载 |
| 接口超时设置 | `30–60 秒` | 匹配装配现场数据采集的平均耗时，避免网络延迟导致请求中断 |
| 请求内容类型 | `application/json` | 适配PLM、MES等系统的结构化数据输出格式，简化字段映射流程 |
| 单请求数据上限 | `1000 MB以内` | 适配单订单或单设备的全量文档数据规模，避免请求过载 |

## 容易做错的三处
- 调用接口返回401未授权错误，原因：未正确配置`Authorization`参数，或密钥格式不符合接口鉴权要求。
- 接口返回的`responseData`字段为空，原因：未指定需要提取的业务字段，或请求参数未匹配文档的更新周期（如请求单订单数据时未携带正确的订单标识）。
- 表单无法通过API同步到外部平台，原因：未在接口配置中开启`variables`动态参数映射，导致无法传递表单的定制化字段。

## 怎么确认配好了
- 调用测试接口，检查返回的`responseData`是否包含预设的核心业务字段，如装配工艺卡、扭矩记录等。
- 模拟单订单请求，验证`variables`参数是否能正确提取动态标识，避免跨订单数据混淆。
- 查看接口鉴权日志，确认`Authorization`参数的格式符合要求，无鉴权失败记录。
- 模拟数据延迟场景，验证接口超时设置是否适配现场采集节奏，无频繁超时报错。
