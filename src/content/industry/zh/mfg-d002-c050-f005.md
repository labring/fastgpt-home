# 通用机械设备装配的工艺文件与异常报告起草：工具调用与插件

## 这个品类的数据长什么样
通用机械设备装配的日常文档包含装配工艺卡、多层BOM、扭矩记录、间隙调整记录、试运行报告、出厂检验单、装箱清单。数据来源通常为PLM/ERP系统、零件检验数据、装配工具采集终端、试验台、MES系统及客户技术协议。数据更新节奏为每台设备或每订单一次，包含设备型号、订单号、装配日期、扭矩值（单位N·m）、间隙值（单位mm）、同轴度公差（单位μm）等字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
这些数据特征对工具调用与插件环节带来多重约束：多源异构的数据来源要求插件支持对接不同系统的接口，需适配PLM、MES等不同格式的返回数据；单台/单订单的更新节奏要求每次调用工具时需精准拉取对应批次的最新数据，避免调用过期内容；多层BOM的嵌套结构要求插件具备嵌套数据解析能力，确保能逐层核对物料齐套情况；特定单位的字段要求插件内置单位校验逻辑，防止因单位不匹配导致的工艺文件错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配多数据源插件的自动调用逻辑，无需手动指定每个插件 |
| 单次搜索上限 | 前8条 | 匹配装配工艺卡单页的典型内容长度，避免冗余数据干扰 |
| 超时时间 | 300秒 | 适配跨PLM和MES系统的接口响应周期，防止因网络延迟导致调用失败 |
| `functionCall` | 开启 | 支持调用外部MCP插件解析多层BOM与扭矩记录数据 |
| 上下文窗口上限 | 16000 token | 适配完整装配工艺卡的长文本解析需求 |

以上配置均适用于FastGPT v4.17.0版本。

## 容易做错的三处
- 调用API返回403无权限错误：原因是未在FastGPT平台配置对应API密钥的访问范围，未绑定所需插件的调用权限。
- 工作流调用MCP插件时显示未找到服务：原因是未先在插件管理模块注册MCP服务，直接在工作流中调用插件节点。
- 工具调用超时报错：原因是未设置合理的超时时间，未适配跨系统接口的响应延迟，导致调用过程中断。

## 怎么确认配好了
- 传入测试订单号调用API，检查返回的BOM数据是否与对应PLM系统中的该订单物料清单一致。
- 在工作流中添加MCP插件节点，选择已注册的装配数据解析插件，运行测试节点，检查是否能返回间隙调整记录的解析结果。
- 配置超时时间后，模拟跨系统调用，检查是否在设定时间内返回有效结果。
- 检查`functionCall`开关是否开启，确认插件调用的参数格式符合装配工艺文件的解析要求。
