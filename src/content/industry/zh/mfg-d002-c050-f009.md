# 通用机械设备装配的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
通用机械设备装配场景的数据主要来自PLM/ERP系统、零件检验数据、装配工具采集终端、试验台、MES系统及客户技术协议。日常产出的文档包含装配工艺卡、BOM清单、扭矩记录、间隙调整记录、试运行报告、出厂检验单与装箱清单。数据更新节奏为每台设备或每订单一次，文档字段包含标准化的装配参数、检验结果与交付信息，单位多涉及牛米、毫米、微米等精密计量单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据来源分散且包含多系统采集的精密计量数据，要求模型接入配置支持多数据源的统一对接，避免数据同步延迟。文档更新频率为单台或单订单级，需适配高频的内容变更，因此上下文窗口配置需支持动态调整以容纳最新的装配与检验记录。文档类型多样，涵盖步骤式工艺卡与清单式BOM，要求配置兼容多格式的文本解析规则，同时精密参数的核对需限制token用量以保证内容准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配单台设备装配相关的多文档总长度，覆盖工艺卡、BOM与检验记录的完整内容，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 限制单轮起草的文档输出长度，保证工艺文件与异常报告符合装配场景的规范格式 |
| `quoteMaxToken` | 1500 token | 限定引用源数据的最大长度，确保扭矩值、间隙参数等精密数据的引用准确且不冗余 |
| `temperature` | 0.2–0.4 | 降低生成内容的随机性，保证装配参数与检验结果的一致性，符合场景的严谨要求 |
| `AIPROXY_API_ENDPOINT` | 按企业内部代理地址填写 | 适配企业内部网络环境，解决无网络状态下的接入问题 |
| 工作流/API 工具选择配置 | auto | 自动选择工具调用，适配多数据源的参数核对与文档拼接需求 |

## 容易做错的三处
- 启动模型接入容器时出现无网络报错，或提示无法获取API资源。原因：未配置适配企业内部网络的代理地址，或容器部署环境未开通对外访问权限。
- 生成的异常报告或工艺文件中混入大量无意义的标点符号。原因：未调整`temperature`参数至合理区间，导致生成内容出现冗余格式错误，或未配置上下文过滤规则清理无效标记。
- 配置API密钥后无法正常调用模型。原因：未正确填写`AIPROXY_API_TOKEN`参数，或密钥权限未覆盖当前场景的接口调用范围。

## 怎么确认配好了
本文基于FastGPT v4.17.0版本的配置逻辑进行验证，可通过以下动作确认配置生效：
- 执行单台设备的工艺文件起草测试，核对生成内容是否包含装配工艺卡、BOM清单的核心参数。
- 触发异常报告生成流程，检查输出内容是否无冗余标点或格式错误。
- 查看容器运行日志，确认无API调用失败或网络连接异常的报错信息。
- 测试多数据源同步功能，确认PLM/ERP与MES的装配数据能正确导入上下文窗口。
