# 金属切削加工的工艺文件与异常报告起草：工具调用与插件

本文档的配置示例适用于FastGPT v4.17.0。

## 这个品类的数据长什么样
本品类的典型数据来自机加工厂、精密零部件厂的生产环节，涵盖工艺路线、工序卡、刀具清单、数控程序、首件检验记录、巡检表与量具校准记录等文档。数据来源包括产品图纸与三维模型、CAPP/CAM系统、机床采集终端、刀具管理系统、MES系统与量检具数据。数据更新频率随工单、单件产品、抽检批次或刀具更换触发，不同文档的字段与单位存在差异，例如工序卡标注装夹基准参数，单位为毫米；刀具清单记录刀具寿命，单位为分钟；数控程序包含进给速度参数，单位为转每分钟。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类的数据来源分散且更新频率随生产节点触发，要求工具调用需支持多数据源的实时拉取与异构格式适配。不同文档的字段与单位存在差异，需工具具备结构化解析能力，将分散数据转换为统一的工艺或异常报告格式。工艺编制与异常处理是本品类最耗时的环节，需工具调用关联工序、刀具、机床的实时数据，辅助完成基准选择、程序验证与异常根因分析。出错后果直接关联工件报废或机床停机，要求工具调用的结果需经过格式校验，避免因参数错误导致后续生产异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配多工具调用场景，自动匹配工艺文件生成、异常报告起草所需的工具 |
| `functionCall` | `enabled` | 强制触发结构化输出，保证工艺参数、异常数据的格式符合工序卡、数控程序的字段要求 |
| 工具调用数据源配置 | 对接机床采集、MES、刀具管理系统接口 | 覆盖工艺文件生成所需的实时刀具寿命、工序进度与机床状态数据 |
| 上下文窗口大小 | 8000–12000 token | 容纳完整的工艺路线、数控程序与异常日志数据，避免关键信息截断 |
| 超时阈值 | 300 秒 | 适配机床数据拉取、工艺程序验证的常规耗时场景，避免因等待超时中断调用 |
| 异常触发规则 | 按刀具更换、尺寸偏差超差触发 | 匹配本品类数据更新的生产场景，减少无效工具调用 |

## 容易做错的三处
- 调用工具时返回`{"code":514,"statusText":"unAuthApiKey"}`，原因是未正确配置工具调用的API密钥权限，未绑定对应机床或MES系统的合法密钥。
- 工具调用完成后全局变量未更新，原因是未开启工具调用后的变量同步开关，导致生成的工艺参数未写入上下文变量池。
- 调用日志提示获取数据异常，原因是未配置正确的数据源接口地址，或数据源接口的响应格式与工具预设的解析规则不匹配。

## 怎么确认配好了
- 测试调用工艺文件生成工具，验证是否能拉取对应工单的刀具清单与工序卡数据。
- 提交异常报告起草请求，查看返回结果是否包含标准化的异常类型、尺寸偏差值与处理建议。
- 查看工具调用日志，确认所有API请求均返回200状态码，无`unAuthApiKey`或数据获取失败报错。
- 验证全局变量是否能在工具调用后自动更新为生成的工艺参数值。
