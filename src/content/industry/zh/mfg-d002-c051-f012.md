# 金属切削加工的工艺文件与异常报告起草：部署与升级

## 这个品类的数据长什么样
金属切削加工的业务数据来自产品图纸与三维模型、CAPP/CAM系统、机床采集终端、刀具管理系统、MES系统与量检具设备。日常产出的文档包含工艺路线、工序卡、刀具清单、数控程序、首件检验记录、巡检表与量具校准记录，核心字段包含刀具寿命、切削参数、尺寸偏差、装夹基准等。数据更新频率随工单、单件产品、抽检批次或刀具更换动作触发，无固定周期但更新频次与生产节奏强绑定。

## 这些特征在「部署与升级」这一环带来什么约束
金属切削加工的多源数据对接需求，要求部署环节需适配多系统的接口接入，需配置专用存储与缓存资源。高频更新的工艺文件与异常报告需稳定的数据库连接池，避免因并发写入导致资源耗尽。不同类型的工艺文档格式差异较大，需适配数控程序、三维模型等非结构化文件的解析与存储。车间内网部署的场景下，需限制外部网络访问，同时保证内部系统的连通性，对网络配置的精准度要求较高。

## 配置怎么定
以下配置适用于 FastGPT v4.17.0
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 10–20 个 | 金属切削加工的工艺文件与异常报告数据随工单批量写入，限制数据库连接数可避免服务器资源耗尽 |
| `MONGODB_URI` | 内网可访问的实例地址 | 存储工序卡、巡检记录等非结构化业务数据，适配多来源的批量存储需求 |
| `REDIS_URL` | 本地部署的单机实例地址 | 缓存高频访问的刀具清单、基准方案数据，适配高更新频率的业务场景 |
| `STORAGE_S3_ENDPOINT` | 内网对象存储的接入地址 | 存储数控程序、三维模型等大体积工艺文件，满足大文件的存储与读取需求 |
| `FILE_TOKEN_KEY` | 随机生成的32位字符串 | 加密工艺文件的访问令牌，避免未授权的文件访问 |
| `FE_DOMAIN` | 部署节点的内网域名 | 适配车间内网的访问场景，配置前端页面的访问地址 |

## 容易做错的三处
- 现象为Docker容器内的FastGPT实例无法访问内网存储或外部工具，报错显示连接超时或404状态码，原因是容器网络模式未配置为桥接或未映射对应端口，未正确设置`STORAGE_S3_ENDPOINT`的内网访问地址。
- 现象为代码运行插件执行时返回AxiosError 404，原因是插件配置的接口地址未指向本地部署的服务，或未在`FE_DOMAIN`中配置正确的内网访问域名。
- 现象为内网部署的aiproxy无法连接外部模型服务，报错显示连接超时，原因是未配置内网代理规则或未将代理地址指向本地部署的模型服务。

## 怎么确认配好了
- 登录FastGPT后台的存储配置页面，上传一段数控程序文件，确认文件可正常存储并下载至本地。
- 上传一份工序卡文档，执行解析测试，确认可提取出刀具编号、切削参数等预设字段。
- 启动代码运行插件，调用本地部署的工具接口，确认返回结果无404或超时报错。
- 配置高级编排流程，输入测试工单问题，运行流程后确认判断器后的AI节点可获取到初始提问内容。
