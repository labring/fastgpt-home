# 钣金下料折弯的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
这个品类的日常数据主要来自CAD/CAM软件、订单BOM、板材库存系统、激光切割机、折弯机与MES系统。日常文档包含钣金展开图、数控下料程序、折弯工艺卡、套料图、首件记录、工序流转卡，核心字段包括折弯补偿量、板材厚度、孔位尺寸、下料规格、折弯顺序等，单位多为毫米、平方米、千克。数据更新随订单生成、每日库存盘点或生产换型触发，每次换型时需同步更新折弯系数与套料方案。

## 这些特征在「模型接入与配置」这一环带来什么约束
钣金下料折弯的多品种小批量特性，要求模型接入配置支持灵活的上下文调用与动态参数适配；图纸驱动的业务模式，要求配置中开启视觉解析能力以读取CAD图纸与工艺卡内容；数据更新频率高的特点，要求模型能快速关联最新的订单BOM与库存数据；核心耗时环节集中在展开计算与套料管理，要求配置允许模型调用专用工具完成复杂计算；出错后果涉及板材浪费与装配误差，要求配置强化结果校验逻辑，避免生成错误的工艺参数。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 钣金展开图、工艺卡等文档内容较长，需完整保留上下文以准确提取参数 |
| `temperature` | 0.2–0.4 | 工艺文件与异常报告需保持严谨性，避免生成随意或偏离标准的内容 |
| `vision` | 开启 | 需解析CAD图纸、套料图等视觉类文档，提取图形尺寸与折弯参数 |
| 工作流/API 工具选择配置 | auto | 可自动调用工具完成折弯系数计算、套料规划等复杂业务逻辑 |
| `AIPROXY_API_ENDPOINT` | 填写企业私有化部署的代理地址 | 保障生产数据不泄露，符合企业数据安全要求 |
| `AIPROXY_API_TOKEN` | 填写企业专属的访问密钥 | 验证模型服务的访问权限，防止未授权调用 |

## 容易做错的三处
- 现象：添加模型后测试不通过，返回连接超时或401报错。原因：未正确配置`AIPROXY_API_TOKEN`或`AIPROXY_API_ENDPOINT`参数，导致无法连通目标模型服务。
- 现象：生成的工艺文件出现乱码或格式混乱。原因：未开启`vision`配置，无法正确解析DOC文档中的表格内容或CAD图纸的矢量图形信息。
- 现象：上传展开图或折弯工艺卡后无解析结果。原因：未将`maxContext`设置为足够大的取值，导致上传的文档内容被截断，无法完整读取图纸中的核心参数。

## 怎么确认配好了
- 手动上传一张标准钣金展开图，检查模型是否能正确提取板材厚度、折弯系数等核心字段。
- 运行异常报告起草测试，确认模型能自动关联预设的订单BOM与板材库存数据，生成符合业务逻辑的报告内容。
- 查看模型调用日志，确认`toolChoice`配置生效，自动触发了展开计算或套料分析相关的工具调用。
- 测试上传不同格式的文档，包括图片格式的套料图与DOC格式的工艺卡，确认`vision`配置可正常识别各类文档内容。
