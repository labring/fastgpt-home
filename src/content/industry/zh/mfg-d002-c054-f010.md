# 钣金下料折弯的工艺文件与异常报告起草：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据主要来自CAD/CAM软件、订单BOM、板材库存系统、激光切割机与折弯机设备日志、MES生产执行系统。日常文档包含零件展开图、数控下料程序、折弯工艺卡、套料图、首件检验记录、工序流转卡。数据更新随每笔订单、每日生产排班或每次工艺换型触发，文档字段包含折弯补偿系数、板材厚度、孔位公差、下料尺寸等，单位多为毫米、千克。

## 这些特征在「知识库检索与召回」这一环带来什么约束
由于数据来源分散在多类工业设备与管理系统，跨源整合的召回逻辑需适配不同格式的原始数据；高频更新要求检索链路支持增量同步，避免全量刷新带来的性能损耗；工程类文档多为非结构化的图纸与程序文本，需调整文本切分与向量匹配规则以适配专业术语；专用字段如折弯系数、套料参数的检索，需限定匹配范围以避免无关结果干扰；多品种小批量的生产模式导致知识库条目庞杂，需控制单次召回的结果数量，防止上下文溢出影响生成质量。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 钣金下料折弯的工程参数匹配精度要求较高，过低会引入无关套料或折弯参数，过高会遗漏有效补偿值数据，适配FastGPT v4.17.0的向量匹配逻辑 |
| `limit` | `前 6 条` | 多品种小批量场景下知识库条目较多，限制结果数量可避免上下文溢出，同时覆盖常用的工艺参数与异常处理方案 |
| `searchMode` | `mixedRecall` | 工程文档同时包含结构化参数与非结构化文本描述，混合检索可同时匹配关键词如「折弯干涉」与向量语义特征 |
| `usingReRank` | `开启` | 工程类文档的语义相似度易受图纸编号、设备型号等无关字段干扰，重排可过滤低相关性结果，提升精准度 |
| `datasetSearchUsingExtensionQuery` | `开启` | 工艺起草与异常报告的提问常包含省略的工程术语，扩展查询可补充如「折弯系数」「套料余料」等隐含关键词，提升召回覆盖 |
| `collectionIds` | `绑定钣金下料折弯专属知识库集合` | 隔离其他品类的知识库数据，避免召回非相关的冲压或焊接工艺文档，缩小检索范围 |

## 容易做错的三处
- 现象：检索结果中混入冲压工艺的折弯参数文档，导致后续工艺参数匹配错误，原因：未配置`collectionIds`限定专属知识库集合，导致跨品类数据被召回。
- 现象：手动上传的套料图文档无法被检索到，原因：未针对CAD图纸格式配置专属文本解析规则，且未开启`datasetSearchUsingExtensionQuery`，导致向量嵌入失败。
- 现象：手动插入的自定义索引条目在数小时后消失，原因：未配置增量同步触发规则，全量同步时覆盖了手动插入的非自动生成索引，对应通用知识库索引异常的典型问题。

## 怎么确认配好了
- 上传一份钣金折弯工艺卡至绑定的专属知识库集合，发起包含「折弯补偿系数」的检索，验证召回结果仅来自该集合，无其他品类文档混入。
- 输入包含「折弯干涉」的查询词，验证召回结果包含对应的异常处理方案与套料调整参数，且结果排序符合语义相关性。
- 调整`similarity`阈值后观察检索结果的数量变化，确认阈值生效。
- 手动插入一份自定义工序流转卡，等待1小时后再次检索，验证文档未被自动清除。
