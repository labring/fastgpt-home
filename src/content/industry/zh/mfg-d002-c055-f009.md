# 铸造（砂型、精密、压铸）的工艺文件与异常报告起草：模型接入与配置

## 这个品类的数据长什么样
铸造（砂型、精密、压铸）场景的数据覆盖工艺卡、配料单、炉次记录、模具履历、首件检验记录、材质报告、不合格品评审单等文档。数据来源包括ERP物料主数据、熔炼炉与测温仪、光谱仪、MES炉次记录、模具管理系统、客户图纸与技术条件。数据更新节奏为每炉次、每批或每日，字段包含合金配料比例、熔炼温度、浇注参数、缺陷类型、炉次与模次编号等，部分字段带有明确的单位标识。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据更新频率为每炉次、每批或每日，且需关联炉次、模次等唯一标识，同时包含带单位的合金比例、温度等数值字段。这要求模型接入配置需适配高频更新的源数据，确保生成内容能及时匹配最新记录。同时，工艺文件与异常报告的严谨性要求高，需避免虚构参数，因此配置需限制模型的自由生成空间。此外，单份任务需覆盖多份关联文档，上下文配置需足够容纳这些数据。FastGPT v4.17.0的默认参数无法直接适配该场景的需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 铸造场景需覆盖炉次记录、材质报告、模具履历等多份关联文档，该取值可容纳完整的关联数据 |
| `quoteMaxToken` | 1500–2000 token | 需完整引用炉次记录、材质报告中的关键字段，该取值可覆盖单份源文档的核心内容 |
| `temperature` | 0.1–0.3 | 工艺文件与异常报告需严谨准确，较低的温度可限制模型虚构参数的概率 |
| `AIPROXY_API_ENDPOINT` | 填写私有化部署节点的本地API地址 | 适配内网部署的访问需求，确保数据传输的安全性 |
| `toolChoice` | auto | 自动调用检索工具获取最新的炉次、模具等数据，满足高频更新的要求 |
| `maxTokens` | 4000–6000 token | 单篇工艺文件或异常报告的生成长度需符合企业文档规范，该取值可覆盖常规输出需求 |

## 容易做错的三处
- 现象为调大`quoteMaxToken`至2000以上后，生成的工艺文件未显示任何引用来源，原因是参数设置超出`maxContext`的总上限，导致检索到的源数据无法被正确纳入上下文。
- 现象为返回401未授权错误，无法发起生成请求，原因是`AIPROXY_API_TOKEN`配置了错误的访问密钥，未与部署节点的凭证匹配。
- 现象为生成的异常报告中出现未匹配的合金配料比例，原因是`temperature`设置高于0.3，模型生成了超出实际工艺范围的虚构内容。

## 怎么确认配好了
- 上传一份炉次记录与材质报告的样本数据，发起工艺文件起草请求，检查返回结果中是否包含引用的源数据字段。
- 配置`AIPROXY_API_TOKEN`后发起测试请求，检查返回状态码为200且无未授权报错。
- 设置`temperature`为0.2后生成异常报告，检查结果中未出现虚构的合金配料比例或参数。
- 调整`maxContext`至10000 token，上传多份关联文档，检查生成内容覆盖了所有必要的关联数据。
