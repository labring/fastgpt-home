# 锂离子电芯制造的工艺文件与异常报告起草：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的日常文档包含配料记录、涂布辊压参数、卷绕或叠片记录、注液记录、化成分容数据、OCV与安全测试报告。数据来源涵盖原材料批次台账、MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室测试数据。数据更新频率为每批、每只电芯实时同步，字段包含批次号、检测参数值、时间戳等，部分参数带有特定单位，如辊隙、温度、毫安时等。文档结构按生产工序分层，每个工序对应独立的数据条目，便于按批次回溯与分析。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据来源分散且更新实时，要求HTTP接口支持多源数据拉取与高频次调用。文档字段多且带有特定单位，接口请求参数需严格匹配上游系统的字段命名与格式，避免数据错位。电化学生产对数据准确性要求极高，异常报告需实时同步至管理系统，接口需具备低延迟特性。每批次电芯对应大量细分数据，接口需支持批量数据传输，同时需过滤冗余内容以提升传输效率。此外，异常报告需关联特定批次的全流程数据，接口返回结构需适配结构化存储需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 请求超时时间 | 60-120秒 | 适配化成分容柜的实时数据上报延迟，避免请求过早中断，本配置适用于FastGPT v4.17.0 |
| 数据编码方式 | UTF-8 | 匹配MES系统与实验室设备的通用编码格式，防止文本乱码 |
| 批量请求阈值 | 50条/次 | 适配每批次电芯的文档数量，平衡接口负载与传输效率 |
| 字段映射规则 | 按电芯批次号、检测参数名匹配 | 对应工艺文件的固定字段结构，确保数据正确写入工艺文档模板 |
| 重试触发条件 | 状态码≥500或超时 | 适配工业设备的临时网络波动，保障异常报告同步成功率 |
| `Authorization`参数配置 | Bearer {自定义服务密钥} | 用于验证外部系统与FastGPT的身份，避免未授权访问 |

## 容易做错的三处
- 现象：通过API发起应用管理类请求时返回权限错误。原因：未正确配置`Authorization`参数，或绑定的密钥未开放应用管理的操作权限。
- 现象：上传工艺文件文本时出现乱码，无论通过网页、本地文件还是API传参。原因：未统一配置数据编码为UTF-8，与上游设备的编码格式不匹配。
- 现象：工作流循环调用HTTP接口后未按预期生成异常报告。原因：未正确设置`variables`参数绑定电芯批次号，导致接口无法获取对应批次的工艺数据。

## 怎么确认配好了
- 发起单次HTTP接口请求，检查返回的`responseData`是否包含预期的工艺文档字段，无冗余内容。
- 上传一条包含特殊字符的工艺文本，确认返回的数据集内容无乱码。
- 触发工作流循环调用HTTP接口，观察接口状态码均在正常范围内，无连续超时或报错。
- 使用配置的密钥发起应用管理请求，确认可以正常执行对应操作。
