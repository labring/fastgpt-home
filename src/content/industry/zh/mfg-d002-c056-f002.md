# 锂离子电芯制造的工艺文件与异常报告起草：向量模型与索引

## 这个品类的数据长什么样
该品类的数据来自原材料批次台账、车间MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室测试设备。日常文档包含配料记录、涂布辊压参数、卷绕/叠片记录、注液记录、化成分容数据、OCV与安全测试报告，字段涵盖工艺参数、检测值与批次标识，单位对应各环节工艺规范，如涂布面密度为g/㎡、露点为℃。数据更新频率为每批、每只电芯或实时，单批次文档量随电芯生产规模增长。

## 这些特征在「向量模型与索引」这一环带来什么约束
锂离子电芯制造的数据按批次关联且更新频繁，要求索引支持增量更新与批次维度的快速召回。文档包含结构化参数与非结构化测试报告，需兼顾分块时的参数完整性与文本连贯性。电化学体系对参数一致性要求极高，检索需优先匹配同批次、同工序的关联数据，避免低关联结果干扰异常判断。同时，长文本的化成分容曲线报告需适配向量模型的长度限制，防止关键数据被截断。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配单批次工艺记录的段落长度，避免拆分关键参数组 |
| 重叠长度 | 100–150 字符 | 保留跨块的工艺参数关联，防止分块切断辊压与涂布的联动数据 |
| 相似度阈值 | 0.75–0.85 | 匹配电芯制造对参数一致性的严格要求，过滤低关联的异常报告 |
| 单次搜索上限 | 前10条 | 限制召回范围，聚焦同批次或同工序的相关文档 |
| `maxToken` | 4096 token | 适配长文本的化成分容曲线报告，避免截断关键数据 |
| `defaultToken` | 按实测标定 | 适配不同环节的文档长度，覆盖配料到测试的全流程数据 |

## 容易做错的三处
- 现象：创建训练订单时返回“参数不完整”报错，原因：未将电芯批次号作为必填元数据传入训练接口，无法按批次关联关联文档
- 现象：图片向量化后检索结果无法匹配对应工艺参数，原因：未开启图片OCR与结构化文本的绑定索引，仅提取图片文本而未关联工艺字段
- 现象：选择目标Embedding模型时无选项，原因：未在oneAPI配置中更新模型列表，未添加对应模型的接口密钥与地址

## 怎么确认配好了
- 上传单批次的配料记录与异常报告，检查训练订单生成后是否自动关联批次元数据
- 上传包含工艺参数的图片，检索时验证是否能同时返回图片OCR文本与对应结构化参数文档
- 在模型配置页面确认目标Embedding模型已显示在可选列表中，且接口连通性正常
- 发起异常报告检索，检查召回结果的相似度阈值是否符合预设区间，无低关联结果
