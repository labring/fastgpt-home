# 锻造与模锻的工艺文件与异常报告起草：工具调用与插件

## 这个品类的数据长什么样
锻造与模锻的日常文档包含锻造工艺规程、下料卡、加热炉记录、锻造过程卡、模具寿命记录、热处理委托单、超声检测报告。数据来源为原材料质保书、加热炉系统、压力机采集数据、MES、无损检测仪。数据更新频率为每件锻件或每批锻件、每炉次。文档字段包含锻件批号、加热温度（℃）、保压时间（秒）、模具编号、缺陷类型等，各字段需匹配对应业务场景的单位与格式要求。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散且需实时拉取最新炉次与批次数据，要求插件支持对接多类系统接口。高频更新的业务特性要求工具调用需适配小批量、实时性的拉取逻辑，避免冗余数据加载。多字段与单位的标准化需求，要求插件需完成字段映射与格式校验，确保生成的工艺文件与异常报告符合行业规范。严重的出错后果要求工具调用需配置失败重试与异常拦截机制，防止错误数据流入生产环节。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` | 适配锻造工艺文档起草的多工具调用场景，自动选择匹配的插件完成数据拉取与格式转换 |
| 工作流/API 函数调用配置 | `enabled` | 支持插件生成标准化的异常报告字段，匹配超声检测报告与锻造过程卡的必填项 |
| 工具调用超时时间 | `120–180 秒` | 锻造数据拉取涉及多系统接口交互，该时长可覆盖多数常规接口的响应周期 |
| 批量数据拉取上限 | `前 10 条` | 每炉次锻件的关联检测数据量有限，该上限可避免上下文过载影响模型处理 |
| 参数校验开关 | 启用 | 校验加热温度、保压时间等字段的单位与取值范围，符合锻造工艺的技术要求 |

## 容易做错的三处
- 现象：调试模式下工具调用正常，运行模式下触发接口报错。原因：运行模式未配置生产环境的系统接口访问权限，仅调试模式使用本地测试地址完成调用。
- 现象：调用文档解析插件时出现连接失败报错。原因：部署的docker容器未映射插件服务的对应端口，或内网防火墙阻断了插件与FastGPT服务的通信链路。
- 现象：工作流运行时出现gpt-4o-mini调用报错日志。原因：未配置工具调用的上下文截断规则，导致加载的锻造数据超出模型支持的token上限触发报错。

## 怎么确认配好了
- 手动触发工具调用，拉取单炉次的加热炉记录数据，核对返回字段与锻造工艺规程的要求一致。
- 模拟锻件异常场景触发插件生成异常报告，检查报告包含锻件批号、缺陷类型、处理建议等必填项。
- 查看FastGPT v4.17.0的运行日志，确认工具调用的请求参数与配置项匹配，无未授权的接口访问记录。
- 批量拉取3炉次的锻件检测数据，确认插件返回的结果条数符合配置的批量上限要求。
