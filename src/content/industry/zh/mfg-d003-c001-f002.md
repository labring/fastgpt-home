# PCB制造的工艺规程与技术标准问答：向量模型与索引

## 这个品类的数据长什么样
印制电路板工厂的工程、生产、品质与实验室部门产生的日常文档，包含工程制作指示、Gerber解析记录、钻孔和层压参数、药水分析、AOI报告、电测报告、切片报告。数据来源包括客户提供的Gerber文件、钻带、BOM，以及CAM系统、生产设备参数、槽液化验结果、AOI与电测设备数据、实验室检测记录。数据更新频率为每生产批、每班或连续采集，单份文档包含具体工艺参数与检测数值，结构随文档类型差异较大。

## 这些特征在「向量模型与索引」这一环带来什么约束
多源异构的数据来源与格式差异，要求索引系统支持跨类型文档的语义关联，避免因格式不兼容丢失关键参数。高频更新的生产数据需要适配增量索引机制，确保新增的钻孔、层压参数能被及时纳入检索范围。单份文档包含的具体数值与连续工艺步骤，要求向量模型能捕捉参数间的关联逻辑，避免切割破坏工艺上下文。出错后果严重的业务属性，要求索引召回的准确率需满足工艺校验的严格要求，避免召回无关数据导致错误判断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配PCB工艺文档的语义长度，匹配`defaultToken`的默认设置，避免过长分块丢失参数关联 |
| `defaultToken` | 1024 token | 承载单段分块的语义内容，覆盖多数工艺文档的单段信息 |
| 重叠长度 | 150–200 字符 | 保留相邻分块的参数关联，避免切割钻孔、层压等连续工艺步骤 |
| 相似度阈值 | 0.75–0.85，按实测标定 | 区分工艺参数的细微差异，避免召回无关的槽液化验或质检报告 |
| 单次搜索上限 | 前8条 | 覆盖PCB工艺问题涉及的多环节关联文档，避免召回过多冗余数据 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |

## 容易做错的三处
- 出现503错误，提示default分组下text-embedding-v3无可用渠道，原因：未配置对应embedding模型的渠道分组，或分组的调用配额耗尽。
- 无法通过检索结果页直接调整索引参数，需进入知识库内容页修改配置，原因：误将检索调试入口与知识库配置入口混淆，FastGPT v4.17.0中检索调试仅支持预览召回结果。
- 召回结果包含大量无关的AOI报告，原因：相似度阈值设置过低，未区分工艺规程与质检报告的语义差异，导致召回精度不足。

## 怎么确认配好了
- 上传单份钻孔参数文档，检查分块后是否保留连续的工艺步骤，无明显的参数切割情况。
- 发起包含具体工艺参数的查询，比如“层压温度异常会导致什么问题”，检查召回结果包含对应的层压参数文档。
- 查看索引更新日志，确认每生产批的新增数据能被自动增量索引，无更新延迟情况。
- 验证embedding模型的调用状态，无503类报错，确保模型渠道配置正常。
