# PCB制造的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
PCB制造的工艺规程与技术标准相关数据，来源涵盖客户提供的Gerber文件、钻带、BOM清单，以及CAM生成的工程资料、生产设备参数、槽液化验记录、AOI检测报告、电测报告与切片分析报告。数据更新随生产批推进、每班产出或设备连续采集完成，日常文档包含工程制作指示、各工序参数记录与质检报告，包含钻孔转速、层压温度、药水浓度、缺陷坐标、导通阻值等具体字段与对应单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
PCB制造的多源异构数据特征，对模型接入与配置带来多重约束。数据涵盖二进制工程文件、结构化工艺参数表与非结构化质检报告，要求配置支持多模态数据解析与跨文档关联。高频率的批次级更新，需要适配实时或近实时的上下文同步逻辑，避免不同生产批次的工艺数据混淆。单批次数据规模随PCB层数增加而扩大，需限制单次接入的上下文总量，防止模型推理超时。同时，工艺参数与质检结果的强字段关联性，要求配置优先保障上下文引用的精准匹配。

## 配置怎么定
FastGPT v4.17.0版本下，以下配置项可针对性适配PCB制造场景：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `AIPROXY_API_TOKEN` | 应用特定key | PCB制造的工艺数据包含生产核心参数，使用应用特定key可限制访问范围，符合数据安全要求 |
| `maxContext` | 8000–12000 token | 单批次PCB工艺数据规模较大，需容纳多份关联文档的上下文，避免关键参数被截断 |
| `quoteMaxToken` | 1500–2000 token | 需保障每条引用的工艺参数或质检记录完整展示，避免截断关键数值 |
| `temperature` | 0.1–0.3 | 工艺规程与技术标准问答需严格匹配既定参数，不宜使用过高随机性 |
| `vision` | 开启 | 需处理Gerber解析记录、AOI报告等含图表的文档，支持视觉解析可提升信息提取精度 |
| `maxTokens` | 2000–3000 token | 回答需覆盖完整的工艺步骤或异常排查方案，避免输出截断 |

## 容易做错的三处
- 调用接口时返回403权限错误，原因：误将通用key用于PCB工艺数据问答场景，未使用应用特定key限制访问范围，不符合数据安全要求。
- 知识库无法解析Gerber或AOI报告中的图表内容，原因：未开启`vision`配置项，未启用多模态数据处理能力，无法提取图表中的关键信息。
- 模型返回的工艺参数与实际文档不符，引用片段不完整，原因：未合理配置`maxContext`与`quoteMaxToken`，导致上下文总量超限或引用片段被截断。

## 怎么确认配好了
- 传入单批次PCB工艺数据的样本调用测试接口，检查返回结果是否包含正确的工艺参数与对应文档引用来源。
- 上传含图表的Gerber解析报告或AOI检测报告，验证模型能否正确识别并提取其中的关键数值，确认多模态配置生效。
- 查看接口调用日志，确认使用的是配置的`AIPROXY_API_TOKEN`，无权限报错或参数异常提示。
- 调整`temperature`参数后，检查回答的细节变化是否符合预期，确认配置参数生效。
