# PCB制造的工艺规程与技术标准问答：知识库检索与召回

## 这个品类的数据长什么样
这个品类的数据来自印制电路板工厂的工程、生产、品质与实验室环节，涵盖工程制作指示、Gerber解析记录、钻孔和层压参数、药水分析、AOI报告、电测报告、切片报告。数据来源包含客户Gerber、钻带、BOM文件，CAM输出文件，设备运行参数，槽液化验结果，以及AOI、电测和实验室检测数据。更新频率为每生产批、每班或连续采集，文档包含结构化参数字段与非结构化报告内容，例如钻孔参数含主轴转速、进给速率，层压参数含压力、温度等明确单位的字段。

## 这些特征在「知识库检索与召回」这一环带来什么约束
PCB制造的多源分散数据、高频更新节奏与混合文档类型，对检索召回带来多重约束。多源数据需关联客户资料与生产环节数据，要求检索支持跨集合关联；高频更新要求召回逻辑适配增量同步，避免全量检索的延迟；混合文档类型（结构化参数表、非结构化报告）要求检索模式兼顾语义与关键词匹配；工艺异常的误判会导致整批报废，要求召回结果具备明确溯源能力，确保内容来自指定的工艺文档集合。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配PCB工艺参数的精度要求，避免召回无关的层压参数到钻孔工艺问答场景 |
| `limit` | 前6条 | 单批次生产数据量较大，限制召回条数避免上下文过载，同时覆盖核心工艺环节的参考信息 |
| `searchMode` | `mixedRecall` | 适配Gerber、CAM等结构化与非结构化混合文档的检索，兼顾语义理解与关键词精准匹配 |
| `usingReRank` | 开启 | 区分AOI报告中的切片异常与常规工艺偏差，优化召回结果的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充客户BOM、钻带的关联字段检索，覆盖工程资料转换环节的常见问题 |
| `collectionIds` | 按生产车间绑定专属集合 | 区分不同产线的工艺参数与检测数据，避免跨车间数据混淆导致的检索错误 |

## 容易做错的三处
- 现象：检索结果未附带知识库来源标识，无法验证内容是否来自上传的工艺文档。原因：未开启FastGPT的知识库溯源配置，未在输出中绑定文档集合的来源信息。
- 现象：服务日志出现TRACE请求相关的异常或安全告警。原因：未禁用FastGPT内置的TRACE请求支持，暴露了HTTP协议实现的测试接口风险。
- 现象：无法召回最新上传的钻孔参数或AOI报告数据。原因：未配置按生产批触发的增量同步规则，仍使用固定周期的全量同步，无法匹配PCB数据的高频更新节奏。

## 怎么确认配好了
- 发起包含钻孔转速关键词的检索，检查结果是否附带上传文档的来源集合名称。
- 查看FastGPT v4.17.0的HTTP服务配置项，确认TRACE请求已被禁用。
- 上传一份新的层压参数文档，发起对应工艺的检索，确认新文档内容被正常召回。
- 检查检索请求的配置，确认仅调用绑定了PCB工艺文档的专属集合，未混入无关数据集。
