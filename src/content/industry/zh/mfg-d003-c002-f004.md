# SMT贴片与电子组装的工艺规程与技术标准问答：工作流编排

## 这个品类的数据长什么样
SMT贴片与电子组装的业务数据主要来自客户提供的BOM、Gerber文件、贴装坐标，以及工厂MES系统、贴片机、SPI/AOI检测设备、回流焊炉温记录等。日常文档包含BOM与坐标文件、换线表、钢网与炉温记录、首件确认报告、SPI/AOI检测报告、维修记录与追溯标签。数据更新频率为每工单、每次换线时实时更新，字段包含料号、位号、元件批次、炉温参数等，单位多为毫米、摄氏度等。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的数据实时性强且更新频繁，要求工作流支持动态调用最新的工单数据与设备记录，避免使用过期的工艺参数。多类型的业务文档需要工作流适配不同格式的知识库导入与检索，确保覆盖换线表、炉温记录等细分文档。频繁的换线操作要求工作流可快速切换对应工单的知识库，减少配置冗余。同时，错料、虚焊等出错后果严重，工作流需增加参数校验环节，确保检索结果与当前工单的料号、位号匹配。

## 配置怎么定
本文档基于FastGPT v4.17.0编写。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 动态知识库指定 | 绑定`variables`中的工单ID变量 | 匹配每工单实时更新的知识库需求，适配不同工单对应不同工艺文档的场景 |
| 上下文保留时长 | 600 秒 | 适配多轮工艺问答的会话周期，避免上下文过期导致问答中断 |
| 单次搜索上限 | 前 5 条 | 平衡检索效率与结果覆盖，符合SMT工艺参数的少量精准匹配需求 |
| 最大上下文长度 | 800–1200 字符 | 适配工艺文档的单段内容长度，避免冗余信息干扰大模型推理 |
| 节点输出控制 | 关闭会话输出开关 | 确保AI对话节点的执行结果仅写入工作流变量，不混入用户可见的对话流 |
| 变量作用范围 | 全局`variables` | 确保多轮会话间的工单参数、元件批次等信息可跨节点传递 |
| 知识库导入上限 | 1000 MB | 适配单份SMT工艺文档包的大小，避免导入失败 |

## 容易做错的三处
- 现象：动态指定知识库时引用变量列表为空，无法选择对应工单的知识库。原因：未在工作流的`variables`配置中提前定义工单ID关联的知识库变量，导致节点无法识别可选参数。
- 现象：AI对话节点的执行结果被强制输出到会话返回内容中。原因：未关闭节点的「会话输出」开关，默认将节点执行结果混入用户可见的对话流。
- 现象：多轮会话后工艺参数出现错位，无法匹配当前工单。原因：未设置上下文保留时长，导致旧工单的变量被保留，干扰当前问答逻辑。

## 怎么确认配好了
- 上传测试用的SMT换线表与炉温记录，绑定测试工单ID，触发工作流，检查动态知识库是否自动关联对应文档。
- 发起多轮工艺问答，检查`variables`定义的工单参数是否在各节点间正常传递，未出现丢失或错位。
- 运行AI对话节点，确认执行结果仅写入工作流变量，未出现在最终会话返回内容中。
- 模拟两次换线操作，检查工作流是否可快速切换对应知识库，未出现配置冲突或检索错误。
