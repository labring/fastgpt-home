# SMT贴片与电子组装的工艺规程与技术标准问答：工具调用与插件

## 这个品类的数据长什么样
该品类的数据主要来自客户提供的BOM、Gerber文件、元件坐标表，以及工厂MES系统、贴片机、SPI/AOI检测设备、回流焊炉温记录仪等设备数据。日常维护的文档包含换线表、钢网参数记录、首件确认报告、锡膏与元件批次台账、维修记录与追溯标签。数据更新随工单流转、换线操作实时生效，单次工单内的工艺参数、元件信息会随生产环节逐步同步更新。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据分散且实时更新的特征，要求工具调用需支持对接多类异构数据源，包括客户上传的结构化文件与生产设备的实时数据流，避免仅依赖静态文档。文档包含结构化参数如炉温曲线、元件坐标，与非结构化检测报告，工具需同时支持字段值读取与文本解析。数据随工单与换线实时更新，需限制工具调用的上下文范围，防止加载过期工单数据。同时，工艺错误会引发批量失效，工具调用需附带参数校验逻辑，提前拦截错料、虚焊相关的异常配置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配SMT工单的动态工艺需求，自动匹配对应功能插件 |
| 插件调用触发规则 | 按用户提问触发，单次对话限1次 | 避免重复调用占用资源，符合工单单次处理的业务逻辑 |
| 上下文窗口大小 | 8000–12000 token | 适配BOM、换线表、炉温记录等多文档的内容长度，按实测标定 |
| 插件参数校验开关 | 开启 | 提前校验元件位号、炉温参数等字段的合法性，规避生产风险 |
| 数据源同步间隔 | 30秒 | 匹配实时生产数据的更新节奏，保证调用数据的时效性 |
| 插件返回结果筛选 | 前3条匹配结果 | 聚焦核心工艺参数，避免冗余信息干扰问答流程 |

## 容易做错的三处
- 现象：调用自定义插件时无法找到机械臂控制或工艺校验相关功能，或提示插件配置无效。原因：未绑定SMT场景专属的插件资源库，或未上传适配电子组装流程的插件配置文件。
- 现象：工具调用后返回报错，提示工具消息需紧跟前置调用。原因：对话流程中未按顺序编排`functionCall`与tool消息，或上下文窗口溢出导致前置调用记录丢失。
- 现象：部署自定义代码插件时提示依赖库缺失，代码模块无法正常加载。原因：未在平台的插件运行环境中安装对应Python依赖包，或依赖包版本与生产环境不匹配。

## 怎么确认配好了
- 发起测试提问，输入「当前工单的钢网参数是什么」，核对插件是否调用对应数据源并返回正确内容。
- 模拟触发异常参数提问，如输入「使用过期批次的锡膏」，核对插件是否触发参数校验逻辑并返回提示。
- 调用API接口发起相同提问，核对返回结果与在线对话的一致性，调整API调用参数匹配在线配置。
- 查看FastGPT v4.17.0的插件运行日志，确认数据源同步间隔符合设定值，无异常报错信息。
