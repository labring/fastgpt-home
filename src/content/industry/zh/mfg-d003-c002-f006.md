# SMT贴片与电子组装的工艺规程与技术标准问答：引用来源与溯源

## 这个品类的数据长什么样
SMT贴片与电子组装的业务数据来自客户BOM、Gerber文件、坐标文件、MES系统、贴片机、SPI/AOI检测设备、回流焊炉温记录等。日常文档包含BOM与坐标文件、换线表、钢网与炉温记录、首件确认报告、SPI/AOI报告、维修记录、追溯标签。数据更新频率为每工单、每次换线、实时，字段包含料号、位号、元件批次、炉温参数、坐标位置等，单位涉及毫米、摄氏度等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
SMT工单数据实时更新，引用溯源需匹配最新的工单、换线记录，避免使用过期数据。文档类型多样且关联字段复杂，需精准区分不同文档的引用范围，避免混淆料号、位号等关键参数。数据更新频率高，溯源环节需快速关联实时生成的记录。出错后果严重，溯源需准确指向具体工单环节，不能生成虚假引用。同时，该品类与PCB制造品类差异明显，溯源需限定在贴装、焊点、炉温等SMT专属数据，不能混入相邻品类的基板制造数据。

## 配置怎么定
本配置基于FastGPT v4.17.0版本下的设置，具体如下：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | 匹配SMT单工单文档的长度，保留足够的关键参数，避免截断核心溯源数据 |
| `responseData` | 关联工单ID、换线记录、SPI/AOI报告 | 对应SMT核心业务文档，确保溯源指向具体工单环节 |
| `detail` | 前3条匹配源的完整字段 | 覆盖料号、位号、炉温数据，满足工艺溯源的详细需求 |
| 单次搜索上限 | 前6条 | 匹配SMT工单的核心文档数量，避免过多冗余数据 |
| 最大上下文 | 6000–8000字符 | 覆盖单工单的所有关联数据，确保上下文完整 |

## 容易做错的三处
- 现象为输出内容中包含“引用标记：［1］”字样，原因是未配置响应数据的标记过滤规则，导致原始引用标记未被剥离。
- 现象为生成的回答伪造了引用ID，原因是未绑定具体工单或换线记录作为溯源源，导致大模型生成虚假引用。
- 现象为溯源结果中出现PCB基板制造相关数据，原因是未限定溯源范围为SMT贴片与电子组装的专属文档，混入了相邻品类的数据。

## 怎么确认配好了
- 发起包含料号、位号相关的工艺问题，检查回答中出现的引用标记是否对应工单ID、换线记录等SMT专属文档标识。
- 查看FastGPT v4.17.0版本下的日志，确认`quoteMaxToken`的取值符合配置，未出现关键参数被截断的情况。
- 验证生成的关联文档，检查是否自动关闭了引用标记的输出，未出现冗余的引用信息。
- 发起包含炉温参数相关的问题，检查溯源结果是否仅包含SMT专属的炉温记录、钢网数据，未混入相邻品类的内容。
