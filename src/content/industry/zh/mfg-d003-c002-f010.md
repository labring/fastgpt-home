# SMT贴片与电子组装的工艺规程与技术标准问答：知识库检索与召回

## 这个品类的数据长什么样
SMT贴片与电子组装的工艺数据来源包括客户提供的BOM、Gerber、坐标文件，以及MES系统、贴片机、SPI/AOI检测设备、回流焊炉温采集设备的实时采集数据。数据更新频率为每工单、每次换线、实时。日常生成的文档涵盖BOM与坐标文件、换线表、钢网与炉温记录、首件确认报告、SPI/AOI检测报告、维修记录、追溯标签，字段包含料号、位号、元件批次、坐标偏移量、炉温曲线参数等，单位涉及毫米、摄氏度、批次编号等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
实时高频更新的工艺数据要求知识库支持增量同步与快速切换，适配换线频繁的业务场景。多类结构化与半结构化文档并存，要求检索优先匹配料号、位号等精确字段，避免召回无关内容。错料、虚焊等严重出错后果，要求召回结果具备较高准确率。工单数量较多，需控制单次召回的知识库条目数量，避免上下文溢出影响大模型回答质量。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配SMT工艺文档的精准度要求，避免召回无关的元件参数或炉温数据 |
| `limit` | 前6条 | 控制单次召回的知识库条目数量，适配PCB组装工艺文档的单页上下文长度 |
| `searchMode` | 精准匹配 | 优先匹配料号、位号等精确字段，符合工艺规程的检索习惯 |
| `usingReRank` | 开启 | 对召回结果重排，修正关键词匹配的偏差，提升焊点缺陷分析类问题的召回准确性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 扩展查询词，补充元件替代料、换线步骤等关联术语，覆盖工艺问答的常见延伸需求 |
| `collectionIds` | 按工单绑定的数据集ID配置 | 关联当前工单对应的钢网、炉温记录等专属文档，避免跨工单数据干扰 |

## 容易做错的三处
- 仅第一个问题能触发知识库引用，后续问题无召回结果。原因是工作流未配置上下文传递，未将历史对话的关键词带入检索环节。
- 导入中英文对照知识库后，大模型未读取对应中文内容。原因是未开启针对中文语料的分词优化，或检索时未匹配中文关键词的向量特征。
- 全局变量datasetid无法在知识库检索节点引用。原因是未将全局变量映射到检索节点的数据集ID参数，或变量作用域未覆盖当前工作流节点。

## 怎么确认配好了
- 输入工艺相关问题，检查检索节点返回的知识库条目数量是否符合配置的`limit`取值。
- 查看检索日志，确认召回结果的`similarity`得分处于配置区间内。
- 绑定测试用数据集，输入包含特定料号的问题，验证是否召回对应BOM或换线表内容。
- 开启重排功能后，对比重排前后的召回结果顺序，确认结果排序更符合业务逻辑。
