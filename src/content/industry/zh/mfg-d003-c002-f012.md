# SMT贴片与电子组装的工艺规程与技术标准问答：部署与升级

## 这个品类的数据长什么样
该品类的数据来自客户提供的BOM、Gerber文件、贴装坐标，以及MES系统、锡膏与元件批次台账、贴片机运行数据、SPI/AOI检测报告、回流焊炉温记录等。日常维护的文档包含换线表、钢网参数、首件确认单、维修追溯标签等。数据更新频率随工单执行、换线操作实时触发，不同文档的字段覆盖料号、位号、元件规格、焊接温度、检测结果等，无统一固定格式，需适配多源异构的工业文档结构。

## 这些特征在「部署与升级」这一环带来什么约束
多源异构的工业文档结构差异大，部署时需配置适配多格式的文档解析模块，升级时需保留旧解析规则以兼容历史工单数据。实时更新的特性要求部署的向量数据库与知识库同步链路支持低延迟写入，避免影响工艺问答的实时性。按工单和换线触发的更新，需支持按生产批次隔离知识库版本，防止不同工单的工艺数据混淆。同时，数据来源包含工业设备日志，部署时需配置内网访问权限以保障数据安全。

## 配置怎么定
本页面适配FastGPT v4.17.0版本，以下为该场景下的标准配置项：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `REDIS_URL` | `redis://:自定义复杂密码@内网服务器IP:6379/0` | 缓存工艺问答的上下文与临时搜索结果，内网部署保障缓存数据安全 |
| `MONGODB_URI` | `mongodb://用户名:自定义复杂密码@内网服务器IP:27017/fastgpt?authSource=admin` | 存储多源异构的工艺文档与知识库版本，支持按工单粒度的快速索引 |
| `DB_MAX_LINK` | 150–200 | 限制数据库并发连接数，适配工业场景下的多工单并发问答请求 |
| `STORAGE_S3_ENDPOINT` | `http://内网MinIO服务地址:9000` | 存储钢网参数、炉温记录等大体积工业文档，内网访问避免数据泄露 |
| 知识库同步间隔 | 10–30 秒 | 适配实时更新的工单与换线数据，降低问答数据的延迟 |
| `ROOT_KEY` | 32位以上随机字符串 | 保障FastGPT后台配置的访问权限，防止未授权修改工艺问答的知识库与模型 |

## 容易做错的三处
- 现象：FastGPT内调用模型接口响应缓慢，日志显示接口调用延迟超过30秒，直接curl调用该接口响应正常。原因：未将FastGPT的模型调用链路配置为内网访问，公网请求存在网络抖动，且未调整超时阈值适配工业场景的实时要求。
- 现象：本地部署FastGPT后，登录界面无注册入口，无法创建普通用户账号。原因：未开启FastGPT的本地注册配置项，默认仅开放管理员账号登录，未适配工业场景下的多用户权限需求。
- 现象：知识库搜索返回结果与当前工单的工艺要求不匹配，召回条数不符合预期。原因：未按工单粒度隔离知识库版本，不同工单的工艺数据混淆，且未配置按文档类型的召回过滤规则。

## 怎么确认配好了
- 执行内网环境下的模型接口调用测试，核对响应延迟符合业务要求，确认`REDIS_URL`与`MONGODB_URI`的配置可正常连接。
- 登录FastGPT后台，验证`ROOT_KEY`配置可限制未授权访问，确认管理员账号可正常创建与管理工艺知识库。
- 上传一份钢网记录文档，触发知识库同步，验证文档解析与索引流程正常，确认`STORAGE_S3_ENDPOINT`可正常存储工业文档。
- 发起一条针对当前工单的工艺标准问答请求，核对返回结果与当前工单的工艺数据匹配，确认知识库同步间隔配置符合业务实时性要求。
