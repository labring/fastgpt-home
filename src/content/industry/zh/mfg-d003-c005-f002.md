# 光伏电池片制造的工艺规程与技术标准问答：向量模型与索引

## 这个品类的数据长什么样
晶硅电池片企业的工艺、设备、品质与生产部门日常产生的文档，包含工艺卡、扩散和镀膜参数、印刷烧结记录、EL检测图、IV分档数据、良率报告。数据来自硅片来料、MES系统、扩散炉/镀膜设备/印刷机、EL与IV测试设备、实验室数据。更新频率为每批生产、每片检测产出数据、每日汇总。文档字段包含工艺参数数值、检测结果、批次编号、设备编号等，部分文档附带图像与量化指标。

## 这些特征在「向量模型与索引」这一环带来什么约束
数据来源分散且更新频率不一，需适配多格式数据源的接入与增量更新；单批次生产产生的参数与检测数据量随规模扩大而增长，需支持高效的索引扩容；文档包含结构化数值参数与非结构化图像类内容，需区分两类数据的向量提取逻辑；工艺参数的精度要求较高，向量编码需保留细微数值差异以保障检索匹配的准确性；批次与设备编号的关联检索需求，需在索引元数据中保留对应字段用于精准过滤。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配工艺卡、参数表等文档的段落长度，避免拆分破坏工艺参数组的关联完整性 |
| 重叠长度 | 100–200 字符 | 保留相邻分块的工艺步骤衔接信息，防止跨块的工序逻辑被割裂 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| 相似度阈值 | 0.75–0.85 按实测标定 | 区分同工序不同参数的细微差异，避免出现误匹配或漏匹配有效工艺文档 |
| 单次搜索上限 | 前 8 条 | 覆盖单批次生产涉及的多类工艺文档，避免检索结果过多超出上下文承载限制 |
| `defaultToken` | 按代表性样本文档实测设置 | `defaultToken` 是直接文本分块使用的默认 token 数，请用本品类代表性原文实测调整；参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不表示向量维度、嵌入模型输入上限或检索/LLM 上下文。 |

## 容易做错的三处
- 检索结果条数与设置的单次搜索上限不符，原因是未开启增量索引的自动同步开关，导致新上传的批次数据未被纳入当前索引库。
- 大语言模型未使用检索到的文档内容作答，原因是检索到的分块内容未达到预设相似度阈值，或`maxToken`设置过小导致检索结果被截断后无法完整传递至大语言模型。
- 向量编码后出现工艺参数匹配偏差过大，原因是分块长度设置过小，将完整的工艺参数组拆分为多个不关联的分块，导致检索时无法匹配完整的工艺要求。

## 怎么确认配好了
- 在FastGPT v4.17.0版本中上传单份标准工艺卡文档，检查分块预览是否保留完整的参数组与工序描述。
- 输入已知工艺参数的查询词，核对检索结果的相似度得分是否落在预设的0.75–0.85区间内。
- 验证增量索引功能，上传新的批次检测数据后，确认新数据可被检索命中。
- 查看系统日志，确认向量编码过程未出现超时或格式报错。
