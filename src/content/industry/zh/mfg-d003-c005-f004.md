# 光伏电池片制造的工艺规程与技术标准问答：工作流编排

## 这个品类的数据长什么样
该品类的数据主要来自晶硅电池片企业的工艺、设备、品质与生产部门，涵盖工艺卡、扩散和镀膜参数、印刷烧结记录、EL检测图、IV分档数据、良率报告等文档。数据来源包括硅片来料台账、MES系统、扩散炉/镀膜设备/印刷机运行数据、EL与IV测试结果、实验室检测记录，更新节奏覆盖每批次生产、每片检测结果以及每日汇总。文档包含工艺参数、检测指标、分档结果等字段，单位涉及温度、电流、转换效率等专业参数。

## 这些特征在「工作流编排」这一环带来什么约束
光伏电池片制造的数据更新频率高且颗粒度细，每片检测数据需实时同步，因此工作流需支持高频触发与小批量数据处理。多类型文档混合调用要求工作流能区分工艺参数类、检测类数据的检索逻辑，避免跨类型数据混淆。按批次、每日的更新节奏，要求工作流能关联对应周期的数据源，确保检索的工艺规程与当前生产批次匹配。片级检测数据的敏感性要求工作流的`variables`绑定生产批次ID，防止数据串用，同时需限制非授权节点访问原始检测数据。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本逻辑制定：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 变量绑定 | 绑定生产批次ID与`variables`字段 | 确保工作流仅检索对应批次的工艺规程与检测数据，避免跨批次数据混淆 |
| 知识库关联 | 关联工艺卡、参数台账专属知识库 | 匹配光伏电池片制造的专业文档类型，缩小检索范围 |
| 工具调用分流 | 按文档类型划分知识库与MCP调用路径 | 区分工艺参数查询与设备运行数据查询的调用逻辑 |
| 表单输入节点 | 默认值取全局生产批次变量 | 减少手动输入频次，适配高频生产场景 |
| 超时阈值 | 600 秒 | 覆盖多设备数据拉取与多文档检索的耗时需求 |
| 节点权限配置 | 按部门划分`nodeId`访问范围 | 限制工艺、设备、品质部门仅访问对应权限的工作流节点 |

## 容易做错的三处
- 现象：工作流节点无法添加HTTP响应的入参变量，表单字段为空。原因：未在`variables`配置中声明入参的绑定规则，导致系统无法识别传入的参数字段。
- 现象：点击工作流导出按钮后无文件生成，界面提示参数错误。原因：未配置工作流的`nodeId`关联路径，导出逻辑无法定位完整的节点配置。
- 现象：表单输入节点的默认值无法读取全局生产批次变量，显示为空。原因：未将全局变量正确绑定到表单节点的`variables`配置中，导致无法获取系统上下文值。

## 怎么确认配好了
- 触发一次工作流，检查返回结果是否仅包含当前生产批次对应的工艺规程与检测数据。
- 提交表单输入，确认默认值是否自动加载全局生产批次变量，无需手动输入。
- 测试不同类型的查询请求，确认是否按配置分流至知识库或MCP调用节点。
- 导出工作流配置文件，检查文件是否包含所有节点的完整配置信息。
