# 光伏电池片制造的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
通常覆盖晶硅电池片企业工艺、设备、品质与生产部门的日常文档，包括工艺卡、扩散和镀膜参数、印刷烧结记录、EL检测图、IV分档数据、良率报告等。数据来源涵盖硅片来料、MES系统、扩散炉/镀膜设备/印刷机、EL与IV测试设备、实验室数据。更新节奏按每批物料、每片检测结果、每日生产报表进行。文档包含工序参数、检测数值、分档标准等字段，部分数据带有特定单位，如扩散温度的摄氏度、转换效率的百分比等。

## 这些特征在「模型接入与配置」这一环带来什么约束
由于数据来源分散且更新频率不一，模型接入需兼容多格式的工艺文档与检测数据，避免因格式不匹配导致召回失败。工序参数与检测结果的准确性直接影响生产质量，要求模型召回的内容需完整且无歧义，因此配置需兼顾上下文长度与回答严谨性。片级检测数据量较大，需合理控制召回的文档数量与长度，防止超出模型处理上限。同时，不同工序的参数窗口需精准关联，配置需支持按业务场景定向召回对应文档。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配光伏工艺文档的整体长度，避免截断关键工序参数与检测记录 |
| `temperature` | 0.1–0.3 | 工艺标准问答需保持严谨，较低的温度值可减少模糊或偏离标准的输出 |
| `quoteMaxToken` | 2000–3000 字符 | 完整召回EL检测图描述、IV分档数据等单份文档的核心内容 |
| `maxTokens` | 4000–6000 token | 满足工艺问题回答的长度需求，覆盖参数解释、工序说明等内容 |
| `AIPROXY_API_ENDPOINT` | 按所选模型供应商的官方接入地址填写 | 建立模型调用的基础网络连接，确保请求可正常送达 |
| `AIPROXY_API_TOKEN` | 按供应商分配的密钥填写 | 完成模型调用的身份验证，保障接口访问权限 |

## 容易做错的三处
- 现象为知识库可查询到数据，但传递给大模型后无输出，原因是未正确配置`maxContext`参数，导致召回的工艺文档超出上下文上限被截断，无法参与模型推理。
- 现象为启用索引模型后无法正常调用，原因是未正确填写`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`，或参数中包含多余空格、格式错误。
- 现象为升级到FastGPT v4.17.0后离线配置重排模型失败，原因是未加载对应版本的重排模型依赖包，或离线部署时未正确配置模型文件路径。

## 怎么确认配好了
- 调用测试接口验证`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的有效性，确认无身份验证或网络访问错误。
- 上传单份光伏工艺卡文档，触发工艺参数相关的问答测试，查看返回结果是否包含完整的工序要求与标准数值。
- 测试包含EL检测、IV分档的查询需求，确认返回的引用文档数量与长度符合`quoteMaxToken`的配置限制。
- 查看系统运行日志，确认无模型调用超时、参数格式错误等报错信息，验证配置的稳定性。
