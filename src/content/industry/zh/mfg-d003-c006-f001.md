# 光伏组件封装的工艺规程与技术标准问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
光伏组件封装环节的主体为串焊、层压、装框、测试部门，日常产生的文档包含排版图、材料批次记录、层压工艺记录、EL图、IV测试报告、绝缘耐压记录、包装清单。数据来源覆盖电池片分档系统、玻璃胶膜背板批次台账、MES系统、串焊与层压设备、EL/IV测试仪。数据按每块组件、每批材料更新，单组件关联多条关联记录，字段包含电池片电流档位、层压工艺参数、测试结果等，不同来源数据格式存在差异。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据按单组件、单批次更新，且来源分散、格式存在差异，对接口配置带来多重约束。高频率的单组件数据更新要求接口支持小批量、高并发请求，避免单次传输过载。多源数据的格式差异需要统一的鉴权与字段映射规则，确保不同设备与系统的数据可被正确读取。非结构化的EL图、IV测试报告需要接口支持二进制或路径数据的拉取，同时需通过参数绑定精准匹配对应组件的工艺文档，避免问答结果与实际生产数据脱节。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {企业内部系统统一API密钥}` | 对接MES、测试设备等多源外部系统，实现统一的访问鉴权 |
| `variables` | 绑定组件批次号、测试时间戳变量 | 精准匹配对应组件的工艺规程与测试数据，避免跨批次混淆 |
| `responseData` | 仅返回工艺参数、测试结果、关联批次字段 | 减少无效数据传输，降低接口带宽消耗 |
| 接口超时时间 | 300秒 | 等待EL/IV测试仪返回测试数据的耗时通常较长，避免请求提前中断 |
| 单次请求最大条目 | 前20条 | 单组件关联的历史数据量有限，限制返回条数提升查询效率 |
| 失败重试次数 | 2次 | 避免重复请求加重外部设备与系统的负载，同时覆盖临时网络波动 |

## 容易做错的三处
- 现象：接口返回的IV测试报告功率字段为空，原因：未在`responseData`中配置包含功率参数的字段映射，导致测试数据未被正确拉取，可能引发工艺问答结果与实际生产参数不符。
- 现象：请求返回403鉴权失败状态码，原因：未正确配置`Authorization`参数，使用了过期或无权限的API密钥，无法访问外部生产系统。
- 现象：问答结果匹配了错误的层压温度参数，原因：未通过`variables`绑定组件批次号参数，导致系统调用了其他批次的工艺记录，可能引发层压脱层、功率不达标等生产问题。

## 怎么确认配好了
- 调用测试接口，检查返回的`responseData`是否包含预设的工艺参数与测试结果字段。
- 传入已知的组件批次号，验证`variables`绑定的参数是否正确传递到外部系统。
- 配置`Authorization`参数后，发起无权限的测试请求，确认鉴权机制生效。
- 模拟临时网络中断场景，检查失败重试机制是否按配置触发。
