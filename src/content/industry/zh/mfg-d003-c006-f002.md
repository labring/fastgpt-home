# 光伏组件封装的工艺规程与技术标准问答：向量模型与索引

## 这个品类的数据长什么样
光伏组件封装环节的数据来自电池片分档系统、玻璃胶膜背板批次台账、车间MES系统、串焊与层压设备日志、EL/IV测试仪及绝缘耐压测试记录。日常生成的文档包含排版图、材料批次记录、层压工艺参数表、EL缺陷图、IV功率测试报告、绝缘耐压记录与包装清单。每条数据关联对应组件的唯一标识，包含批次号、测试数值、设备编号与生成时间戳，更新频率为每块组件或每批材料一次。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据粒度细且更新频率高，每块组件或每批材料即生成新数据，要求索引支持增量更新以避免全量重建的耗时。文档类型包含文本参数表、可视化测试图与结构化测试记录，不同类型数据的向量编码逻辑需适配，避免混合编码导致的语义偏差。数据关联组件唯一标识与批次信息，检索时需优先匹配关联字段，因此索引需保留字段级元数据以支撑精准召回。同时，工艺参数匹配的准确性直接影响生产质量，索引的召回精度需满足业务校验要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配层压工艺记录、IV测试报告的常规文本长度，避免单块包含跨批次的无关数据 |
| 重叠长度 | 100–150 字符 | 保留同组件不同分块的上下文关联，避免切断批次号、设备编号等关键元数据 |
| 相似度阈值 | 0.75–0.85 | 匹配电池片电流档位的精度要求，过滤低关联度的历史工艺记录 |
| `maxToken` | 4096 token | 适配EL图描述与测试参数的总编码长度，避免截断关键测试信息 |
| `defaultToken` | 256 token | 用于单条短字段的向量编码，如包装清单的批次号、设备编号等字段 |
| 重排 | 开启，前3条 | 优先召回与工艺问题最相关的测试记录，适配EL隐裂判读、功率匹配的高频检索场景 |

本配置基于FastGPT v4.17.0版本。

## 容易做错的三处
- 现象：Docker内网部署时集成索引模型失败，日志提示连接超时。原因：未将索引模型服务端口映射至宿主机内网网段，导致FastGPT实例无法访问模型服务。
- 现象：导出的知识库dataset.csv仅包含index字段，无content字段。原因：导入文档时未开启文本提取开关，仅存储了文档元数据未提取正文内容。
- 现象：使用bge-large模型时，长文本导入后未按预期分段生成向量。原因：未调整分块长度参数，默认分段逻辑与长工艺记录的结构不匹配，导致分段失效。

## 怎么确认配好了
- 执行增量导入单份层压工艺记录，查看索引更新日志，确认仅新增对应批次的数据，无全量重建提示。
- 发起电池片电流档位匹配的检索请求，核对返回结果的关联字段与查询条件的匹配度，调整相似度阈值至符合业务要求的区间。
- 导出知识库的dataset.csv，检查是否同时包含index与content字段，确认文本提取开关已正确配置。
- 查看GPU资源占用情况，确认多张显卡均被调度用于索引构建与向量编码，无闲置资源。
