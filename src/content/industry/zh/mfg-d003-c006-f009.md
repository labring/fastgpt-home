# 光伏组件封装的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
光伏组件封装环节的数据来自电池片分档系统、玻璃胶膜背板批次台账、车间MES系统、串焊与层压设备日志、EL/IV测试仪输出文件。日常留存的文档包含排版图、材料批次记录、层压工艺记录、EL隐裂图、IV测试报告、绝缘耐压记录、包装清单。数据更新节奏为每块组件生成对应测试记录，每批原材料同步更新批次台账，单份文档包含材料型号、工艺参数、测试数值等字段，部分EL图为图像格式，需关联对应组件的批次信息。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类数据包含结构化工艺记录与图像类测试文件，模型接入需同时支持文本与图像解析，适配多模态输入。数据更新频率高，单批次组件的工艺与测试数据需在短时间内完成索引，需限制上下文长度避免冗余信息干扰。部分字段需关联电池片分档结果与层压参数，模型调用时需确保上下文包含对应批次的完整材料与设备日志，避免参数匹配错误。同时需适配车间本地部署的网络环境，需配置本地API端点与访问令牌。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配单批次组件的完整工艺与测试数据，避免超出模型上下文上限 |
| `vision` | 开启 | 需解析EL隐裂图、包装清单配图等图像类文档 |
| `quoteMaxToken` | 1500–2000 token | 保留足够的工艺参数细节，支撑问答时的参数匹配 |
| `temperature` | 0.1–0.3 | 降低泛化偏差，确保工艺参数与标准的匹配准确性 |
| `AIPROXY_API_ENDPOINT` | 车间本地部署的FastGPT代理地址 | 适配车间内网访问限制，避免外部网络延迟 |
| `AIPROXY_API_TOKEN` | 车间专属访问令牌 | 限制非授权访问，保障生产数据安全 |

## 容易做错的三处
- 现象：模型无法解析EL图、包装清单配图等图像文件，返回无法识别图像内容的报错。原因：未开启`vision`配置项，未启用多模态解析能力。
- 现象：知识库内无直接匹配的工艺条款时，模型直接拒绝回答，无法进行泛化推理。原因：未合理配置`maxContext`与`temperature`，导致上下文截断或参数偏差过大，无法关联相似工艺参数。
- 现象：本地部署版本无法调用指定模型，返回403权限错误。原因：未正确配置`AIPROXY_API_TOKEN`，或使用了非车间专属的访问令牌。

## 怎么确认配好了
- 上传单份EL图与对应层压工艺记录，发起工艺合规性问答，确认模型能正确识别图像中的隐裂位置并关联层压参数。
- 输入未在知识库中直接收录的电池片分档匹配问题，确认模型能基于已有批次数据进行合理推导。
- 检查模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置被正确加载，无访问报错。
- 调整`temperature`参数后发起测试，确认回答的严谨性随参数变化符合预期。
