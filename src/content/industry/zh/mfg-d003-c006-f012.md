# 光伏组件封装的工艺规程与技术标准问答：部署与升级

## 这个品类的数据长什么样
光伏组件封装场景的数据来源涵盖电池片分档记录、玻璃胶膜背板批次台账、车间MES系统、串焊与层压设备运行日志、EL/IV测试仪测试报告等。数据更新频率为每块组件、每批材料同步生成，日常文档包含排版图、材料批次记录、层压工艺参数记录、EL缺陷图、IV功率测试报告、绝缘耐压记录、包装清单等。单份文档包含电池片电流档位、层压温度时长、隐裂位置坐标、功率数值等字段，单位涵盖摄氏度、秒、瓦、兆帕等。

## 这些特征在「部署与升级」这一环带来什么约束
该场景的高频更新多源数据要求部署环节需支持实时向量同步与多格式文档解析，需兼容设备日志、测试报告、台账等不同类型的数据源。数据关联精度直接影响工艺问答的准确性，部署时需保障数据库与缓存服务的稳定性。此外，场景内出错后果关联客户索赔与生产损失，部署后需预留验证环节，升级时需保障历史问答库的兼容性，避免影响车间日常运维。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150` | 适配光伏组件封装场景的多源数据并发访问需求，避免连接池耗尽导致服务中断 |
| `MONGODB_URI` | 厂区专属云或本地集群的连接串 | 用于存储高频更新的组件批次与测试数据，保障读写性能与数据安全性 |
| `REDIS_URL` | 本地缓存实例，缓存时长`3600 秒` | 减少重复查询MES与设备数据的开销，提升问答响应速度 |
| `FE_DOMAIN` | 厂区内网域名或固定内网IP | 保障串焊、层压、测试等部门的内部访问稳定性 |
| `STORAGE_S3_ENDPOINT` | 厂区自建对象存储接入地址 | 存储EL图、IV测试报告等大体积文档，降低跨网络传输延迟 |

## 容易做错的三处
- 现象为vllm接入oneapi时返回connection refused。原因是`MONGODB_URI`或`REDIS_URL`配置错误，导致模型服务无法完成依赖组件的初始化校验。
- 现象为容器运行正常但前端页面无法打开。原因是`FE_DOMAIN`未配置为正确的内网访问地址，或端口映射规则未正确映射至应用端口。
- 现象为docker部署时下载的yml文件仅显示404内容。原因是拉取镜像时未配置加速源，导致官方镜像文件拉取失败，仅返回错误页面。
