# 化妆品生产的工艺规程与技术标准问答：向量模型与索引

## 这个品类的数据长什么样
本品类数据覆盖护肤、洗护、彩妆及特殊化妆品生产企业的全流程文档，包含配方工艺单、称量投料记录、乳化灌装记录、清场清洁记录、半成品成品检验报告、标签审核文件。数据来源涵盖注册备案配方、原料安全资料、生产设备日志、ERP/MES系统、实验室检测结果及包材版本档案，更新节奏随生产批次与换线操作实时触发，文档包含原料名称、投料量、工艺参数、备案编号等核心字段。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类数据的多源异构性、高频更新特性与合规性要求，对向量模型与索引环节形成多重约束。多源文档包含结构化记录、半结构化工艺文件与非结构化检测报告，需适配不同文本结构的分块规则；每批生产与换线触发的实时更新，要求索引支持增量同步，避免全量重建的资源消耗；备案配方与生产数据的合规匹配需求，要求召回结果具备较高精准度，需严格控制无关数据的混入；不同文档的长度跨度大，短记录与长工艺单并存，需灵活调整分块参数以保留核心信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配化妆品生产场景下长短不一的文档，兼顾工艺单的完整度与投料记录的精准分块 |
| 重叠长度 | 100–150 字符 | 避免乳化、灌装等连续工艺步骤被分块截断，保证工艺流程的信息连贯性 |
| `maxToken` | 4096 token | 适配多数主流embedding模型的上下文上限，覆盖单批生产记录的总文本长度 |
| `defaultToken` | 2048 token | 设置默认问答上下文长度，满足基础工艺问答的信息调用需求 |
| 相似度阈值 | 0.72–0.85 | 匹配化妆品配方与备案数据的高精准要求，过滤低相关性的生产记录 |
| 单次搜索上限 | 前 6 条 | 平衡召回覆盖范围与结果可读性，避免过多冗余信息干扰工艺复核 |

## 容易做错的三处
- 现象：索引任务始终显示无数据，无法检索到生产记录。原因：未将配方、投料记录等数据源按生产批次建立关联，导致分块后无有效可索引的文本片段。
- 现象：搜索返回结果相关性极低，出现无关包材版本或历史批次的记录。原因：相似度阈值设置过低，未匹配化妆品合规数据的高精准匹配要求，混入大量无关内容。
- 现象：最后一组文档无法完成索引流程。原因：单批完整生产记录的`maxToken`超过配置上限，导致分块拆分失败，无法生成有效向量数据。

## 怎么确认配好了
- 上传单份完整的配方工艺单，查看分块预览界面，确认乳化温度、投料量等核心工艺参数未被截断。
- 触发一次增量索引任务，查看FastGPT v4.17.0的任务日志，确认对应批次的生产记录已成功入库。
- 输入“本次生产的限用物质是否符合备案要求”，检索返回结果，确认关联了对应批次的原料安全资料与检验记录。
- 调整相似度阈值至0.78，验证搜索结果的召回数量是否符合生产复核的实际需求。
