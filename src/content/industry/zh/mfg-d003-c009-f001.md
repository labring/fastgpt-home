# 化学药制剂生产的工艺规程与技术标准问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
化学药制剂生产的相关数据主体为生产、质量保证、质量控制、仓储部门，日常文档涵盖主生产文件、批生产记录、批包装记录、清场记录、检验记录、偏差/CAPA/变更、批放行审核表。数据来源包括经批准处方工艺、物料批次、MES/电子批记录、设备与环境监测、LIMS、质量管理系统，更新频率为每批、每个关键步骤、按监测计划。数据字段包含批次号、物料信息、工艺参数、检验结果等，需严格匹配合规要求。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
化学药制剂生产的数据来源分散，涉及多个独立系统，接口需适配不同系统的数据格式与权限规则。数据更新频率高且与生产批次强绑定，接口触发时机需匹配单批生产的关键步骤，确保问答内容实时准确。受合规要求约束，接口需严格验证访问身份，且返回的文档需具备可追溯性。单批次生产数据量较大，接口需限制返回内容的规模，避免负载过高影响生产环节的响应速度。

## 配置怎么定
本文基于 FastGPT v4.17.0 版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | Bearer {经加密的合规访问令牌} | 工艺规程与批记录属于受监管数据，需通过该参数完成严格身份验证，符合合规数据安全要求 |
| `variables` | 绑定批次号、物料批次、检验结果字段 | 需精准匹配单批次生产的关联参数，确保问答返回的工艺与标准内容与当前批次一致 |
| `responseData` | 包含文档标题、生效版本、关联批记录编号 | 便于生产与质量部门快速定位合规文档，满足可追溯要求 |
| 单次返回文档条数 | 前5条 | 化学药制剂生产的批记录与工艺文档单批次数据量较大，限制返回条数可降低接口负载，同时满足快速查阅需求 |
| 超时阈值 | 600 秒 | 对接多系统（MES、LIMS、质量管理系统）时，数据拉取耗时较长，需预留足够时间完成数据同步 |
| 上下文窗口大小 | 8000–12000 token | 按实测标定，需覆盖单批工艺规程与关联检验记录的完整内容 |

## 容易做错的三处
- 现象：调用接口时返回`Api response error: undefined`，原因：未正确配置`variables`参数传递批次号等关联字段，导致系统无法匹配对应工艺与批记录数据。
- 现象：创建文件集合的API接口未指定PDF解析配置，无法正确解析工艺规程PDF文档，返回空的文档片段，原因：未在接口配置中绑定对应解析规则，导致默认解析逻辑无法适配化学药制剂生产的PDF文档格式。
- 现象：调用代理服务时使用错误端口，导致无法连接LLM服务，原因：未按对接系统要求配置正确的服务端口，混淆了不同代理服务的端口规则。

## 怎么确认配好了
- 调用接口传入已知合规批次号的`variables`参数，检查`responseData`是否返回对应批次的工艺规程与批记录关联内容。
- 配置`Authorization`参数后，使用无效令牌发起请求，确认返回身份验证失败的错误提示。
- 发起创建文件集合的请求，指定PDF解析相关配置，检查接口返回的文档解析状态是否正常。
- 发起接口请求后，监控响应时长，确认未超过预设的超时阈值。
