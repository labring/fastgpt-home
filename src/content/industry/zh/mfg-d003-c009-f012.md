# 化学药制剂生产的工艺规程与技术标准问答：部署与升级

## 这个品类的数据长什么样
该品类的数据来源包括经批准处方工艺、MES电子批记录、设备与环境监测数据、LIMS系统及质量管理系统。日常文档涵盖主生产文件、批生产记录、清场记录、检验记录、偏差CAPA变更文件、批放行审核表。数据更新随每批生产、关键工艺步骤执行及监测计划推进，文档字段包含物料批次号、工艺参数、检验结果、偏差记录等，单位涉及重量、温度、时间、批次编号等。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据关联多套生产与质量管理系统，部署时需配置跨系统的数据拉取权限，确保数据来源的合规性。高频次的按批、按步骤更新要求存储与检索组件支持稳定的并发写入与查询。GMP下数据完整性要求严格，部署时需配置可靠的持久化存储，避免数据丢失。复杂的文档结构与专属字段要求检索配置匹配业务文档的层级与字段规则，避免检索结果偏离工艺与标准内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 10–15 并发连接 | 匹配多系统高频数据拉取的并发需求，避免连接耗尽影响检索效率 |
| `REDIS_URL` | 本地部署实例，内存配置 8 GB 以上 | 支撑高频次的会话缓存与检索结果缓存，适配批记录快速查询需求 |
| `STORAGE_S3_ENDPOINT` | 合规云存储端点或本地持久化存储地址 | 满足GMP下数据持久化与可追溯要求，保障生产记录存储安全 |
| `PG_URL` | 关联企业质量管理系统的只读数据库地址 | 拉取经批准的工艺规程与标准数据，避免写入操作干扰生产系统运行 |
| `ROOT_KEY` | 配置为内网访问专属密钥 | 限制管理后台访问范围至生产与质量部门内网，符合数据访问合规要求 |

## 容易做错的三处
- 现象：升级FastGPT v4.17.0版本后，自建的工艺规程问答应用配置全部丢失。原因：升级过程未挂载持久化数据库存储卷，导致应用元数据被覆盖清除。
- 现象：工具调用配置界面中无代码运行工具的连线配置选项。原因：未正确配置`ROOT_KEY`权限，或未启用代码运行工具的配套依赖服务。
- 现象：检索批生产记录时出现超时错误，无法获取完整工艺参数。原因：`REDIS_URL`关联的缓存实例内存配置不足，无法支撑高频次的检索结果缓存与查询。

## 怎么确认配好了
- 登录FastGPT管理后台，查看数据库连接状态面板，确认`DB_MAX_LINK`配置的并发连接数符合业务拉取需求。
- 发起一条测试查询，输入工艺规程相关问题，验证检索结果包含主生产文件、批记录等指定类型的文档内容。
- 执行一次版本升级操作，验证自建应用配置未被清除，确认存储卷挂载配置正确。
- 检查工具调用配置界面，确认代码运行工具的连线选项已显示，验证`ROOT_KEY`权限配置生效。
