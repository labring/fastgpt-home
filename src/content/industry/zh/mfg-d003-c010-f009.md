# 医疗器械装配与洁净生产的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
该品类的日常文档包含生产工艺规程、批生产记录、洁净区记录、灭菌批记录、检验报告、软件版本记录、不良事件与追溯资料。数据来源涵盖设计历史文件、器件与材料批次台账、MES系统、洁净环境监测设备、灭菌设备、检验校准系统。数据更新频率为每批产品或每台设备生产完成后更新，洁净环境数据按监测计划定期更新。文档字段包含唯一器械标识、灭菌参数、洁净区温湿度、材料批次号等受控字段，格式多为结构化表格与长文本结合。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据来源分散且受控性强，需适配多系统数据的接入格式，同时需支持按批次或监测周期的增量更新。文档包含大量专业受控字段，模型需准确识别并关联字段与工艺要求，避免匹配偏差。数据更新频率高，需配置灵活的索引刷新规则，确保检索内容与最新生产记录一致。此外，问答结果直接关联生产合规性，需严格控制模型生成内容的准确性，避免因参数配置不当导致错误引用或遗漏关键标准。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，针对该品类的业务特征制定：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 该品类文档多为长文本的工艺规程与批记录，需容纳足够上下文以关联多段工艺要求 |
| `maxTokens` | 4000–6000 token | 回答需覆盖完整工艺步骤与标准细节，避免截断关键合规内容 |
| `quoteMaxToken` | 2000–3000 token | 需引用受控文档的原文片段，保留完整字段信息以确保合规性 |
| `temperature` | 0.1–0.3 | 工艺问答需严格匹配标准要求，避免生成偏离规范的内容 |
| 工作流/API 工具选择配置 | auto | 需根据问题类型自动调用文档检索工具，适配不同工艺与标准查询场景 |
| `AIPROXY_API_ENDPOINT` | 企业内部代理或本地服务地址 | 适配本地部署的索引模型或云服务地址，例如本地docker部署的M3E服务地址，同时适配企业内网环境，避免生产数据外泄 |
| `AIPROXY_API_TOKEN` | 企业专属鉴权令牌 | 控制访问权限，符合医疗器械生产的合规要求 |

## 容易做错的三处
- 现象：classify模块配置时无法选择目标AI模型，但发布后的工作流可正常调用。原因：未在全局模型列表中完成接入配置，仅在工作流内临时引用未生效。
- 现象：发起工艺问答请求时出现超时错误，日志显示请求时长超出预设范围。原因：未适配长文档检索后的请求耗时，未合理配置上下文参数导致模型加载数据过久。
- 现象：使用qwen3模型调用工具时，生成冗余推理内容，无法强制限制仅使用工具调用模式。原因：未正确配置`toolChoice`参数为指定模式，或未在系统提示中明确约束调用规则。

## 怎么确认配好了
- 上传单份灭菌批记录至索引库，测试检索匹配度，确认符合预设的关联规则。
- 发起工艺规程相关问题，检查返回结果引用的文档片段长度，与`quoteMaxToken`配置一致。
- 模拟批量请求，验证`maxContext`未触发上下文溢出错误，确保长文档查询正常。
- 检查鉴权配置，确认仅授权用户可访问模型接入页面，符合合规要求。
