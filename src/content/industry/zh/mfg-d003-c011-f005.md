# 半导体封装测试的工艺规程与技术标准问答：工具调用与插件

## 这个品类的数据长什么样
该品类的数据主要来自晶圆测试图、制造执行系统（MES）、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格要求。日常文档包含封装流程卡、键合与塑封参数表、晶圆来料图、测试程序版本文件、良率报告、失效分析报告。数据更新频率为每生产批次、每颗芯片测试后及每日更新，文档字段包含设备参数阈值、测试bin码、失效类型标识等，单位涵盖牛、摄氏度、毫秒等专业工业参数单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散且更新频次高，工具调用需对接多类设备接口与MES系统，需适配不同格式的文档解析。不同文档的字段差异显著，比如晶圆来料图的坐标字段与测试程序的bin码字段格式不同，插件需支持自定义字段映射。每批更新的数据量随生产批次波动，需配置动态上下文长度适配。失效分析报告包含大量专业术语，工具调用需支持行业术语的精准召回，避免歧义。同时，逐颗测试的细粒度数据要求插件处理时需控制上下文规模，避免溢出。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 问题优化 | 开启并指定封装测试行业术语优先 | 适配该品类的专业术语体系，提升文档召回匹配度 |
| 单次搜索上限 | 前 8 条 | 覆盖该品类多字段文档的核心信息，按实测标定 |
| 最大上下文 | 8000–12000 字符 | 适配单批次生产文档与测试报告的总长度，避免上下文溢出 |
| 工作流/API 工具选择配置 | 自动 | 允许模型自主选择适配的工具，覆盖流程查询、参数调用等多类需求 |
| 流式输出过滤 | 开启，配置工艺违规关键词规则 | 过滤不符合生产要求的参数输出，对应场景的合规性需求 |
| 文档解析插件 | 选用支持结构化字段提取的PDF解析插件 | 适配封装流程卡、良率报告等带结构化字段的文档 |

## 容易做错的三处
- 现象：流式输出时出现未过滤的违规工艺参数，输出内容不符合生产规范。原因：未配置流式输出过滤规则，或规则未覆盖该品类的专有违规关键词。
- 现象：调用PDF解析插件时无法提取晶圆来料图的坐标字段，解析结果为空。原因：选用的解析插件未适配半导体封装测试文档的结构化字段格式，未针对晶圆图坐标做专门适配。
- 现象：使用开源版FastGPT作为商业后端服务时触发授权限制报错。原因：未明确开源版用于商业场景的授权要求，直接部署未合规的插件。

## 怎么确认配好了
- 提交包含晶圆来料图坐标查询的测试问题，核对工具调用日志中是否触发了对应的文档解析插件。
- 配置流式输出过滤规则后，输入包含违规工艺参数的测试问题，确认输出内容已被过滤。
- 上传单批次的封装流程卡与测试程序版本文件，核对召回的文档条数符合单次搜索上限的设置。
- 将`toolChoice`配置为自动，输入查询键合参数的问题，确认模型自动触发了适配的工具调用。
