# 半导体封装测试的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
半导体封装测试的数据涵盖封装流程卡、键合与塑封工艺参数、晶圆来料图、测试程序版本、良率报告、失效分析报告等。数据来源包括晶圆测试图、MES生产系统、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格要求。数据更新频率为每生产批次、每颗芯片测试后及每日更新，文档包含批次号、工艺阈值、测试bin值、失效类型等固定字段，单位涵盖电压、电流、时间、温度等工业标准单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
由于该品类数据来源覆盖多设备实时采集与高频次更新，模型接入需支持多源数据的实时同步校验；不同文档的字段差异较大，需配置适配的上下文裁剪规则以避免关键工艺参数被截断；每批、每颗的精细化更新要求模型上下文长度适配小批量数据处理，避免冗余加载；失效分析报告与良率报告的结构化程度不同，需调整参数适配非标准化文本的召回与问答逻辑。同时，部分封测厂需内网部署，模型接入需支持私有地址配置，保障数据安全。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配封装流程卡、测试程序版本、良率报告等多文档拼接的上下文长度，避免截断关键工艺参数 |
| `maxTokens` | 2000–3000 token | 匹配单条工艺问答的输出长度需求，确保覆盖完整参数说明与操作步骤 |
| `quoteMaxToken` | 1500 token | 限制单段召回文档的长度，适配晶圆来料图、失效分析报告的结构化片段长度 |
| `temperature` | 0.1–0.3 | 降低随机生成概率，确保工艺参数与标准问答的准确性，避免出现不符合行业规范的输出 |
| `vision` | 开启 | 适配晶圆测试图、X-ray检测图像的视觉问答需求，帮助对齐实物批次与图纸数据 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配本地或云端大模型的接入地址，满足封测厂内网部署的安全要求 |

## 容易做错的三处
- 调用本地大模型时返回版本不兼容报错，原因是未安装模型指定版本的依赖库，直接使用了官方最新版。
- 配置模型接入地址时出现接口连通失败，原因是误用旧版OneAPI服务地址，未使用FastGPT v4.17.0支持的代理地址格式。
- 召回的工艺文档片段过长导致上下文溢出，原因是未设置合理的`quoteMaxToken`参数，未限制单段召回文档的长度。

## 怎么确认配好了
- 上传单份封装流程卡，发起工艺参数查询，检查返回结果是否包含准确的键合温度、塑封压力等核心工艺参数。
- 上传晶圆测试图，发起视觉问答，检查模型是否能正确识别测试bin值与对应失效类型。
- 提交多批次的良率报告，发起批次对齐查询，检查模型是否能正确关联批次号与对应测试数据。
- 查看系统调用日志，确认大模型调用的`maxContext`参数已正确传递，无上下文截断报错。
