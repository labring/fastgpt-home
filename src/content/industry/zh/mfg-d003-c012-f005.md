# 半导体晶圆制造的工艺规程与技术标准问答：工具调用与插件

## 这个品类的数据长什么样
该品类的数据来自晶圆厂的MES系统、设备FDC模块、缺陷检测与量测设备、工艺配方库、实验数据库等。日常文档包含工艺流程卡、批次运行记录、设备配方、SPC图、异常处置单、缺陷图谱、良率报告，字段涵盖工序编号、工艺参数阈值、缺陷空间坐标、良率数值等，单位包含纳米、摄氏度、批次编号等。数据更新节奏为每批晶圆生成后同步、实时采集设备运行参数、每日汇总批次与良率数据。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于数据来源分散且更新节奏存在差异，工具调用需适配多源数据的实时拉取与批量同步，需支持解析结构化配方文件、SPC图表、晶圆位图等非标准格式文档。超长工艺链与纳米级参数要求工具调用的参数精度需匹配微米级阈值，同时需支持跨工序的关联查询。有限返工窗口要求工具调用的响应延迟需控制在合理区间，避免影响生产调度。此外，异常处置单与缺陷图谱的关联查询需工具支持语义匹配与空间坐标关联，这对插件的上下文整合能力提出要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 自动匹配工具，支持手动指定工具 | 适配工艺参数查询、异常根因分析、良率归因等不同场景，自动模式可减少人工配置成本 |
| 文件读取插件 | 支持解析PDF、CSV、PNG格式，单文件上限1000 MB | 覆盖工艺流程卡、批次运行记录、晶圆缺陷图谱等核心文档类型 |
| `functionCall` | 开启强制函数调用，入参需包含工序ID与批次号 | 精准关联晶圆批次数据，避免泛化查询导致结果偏离生产场景 |
| API调用超时 | 设置为600秒 | 适配设备FDC实时数据拉取、跨工序数据汇总的延迟需求 |
| 单次工具调用返回条数 | 前10条 | 覆盖跨工序的关联数据量，避免结果过载影响推理效率 |
| HTTP插件导入 | 填写HTTPS接口地址，配置Bearer令牌认证 | 对接MES等内部生产系统，保障数据传输的安全性 |

本文基于FastGPT v4.17.0版本的配置逻辑编写。

## 容易做错的三处
- 现象：调用`toolChoice`时返回模型不支持的错误，界面提示「无效的工具选择参数」。原因：未确认当前使用模型是否兼容`toolChoice`功能，部分开源模型需额外配置工具调用适配文件。
- 现象：导入HTTP插件时提示「接口格式错误」，无法完成配置，或发布应用后调用API无返回结果。原因：未使用HTTPS协议填写接口地址，或未正确配置认证令牌、内网IP白名单，导致接口校验或访问被拦截。
- 现象：应用调用工具后直接返回原始结果，未将其作为上下文喂给大模型。原因：未关闭应用的直接输出开关，或未配置工具调用结果的上下文拼接逻辑，导致工具返回数据未参与大模型推理。

## 怎么确认配好了
- 发起包含具体工序ID与批次号的查询，检查工具是否正确拉取对应批次的运行记录与工艺参数。
- 上传晶圆缺陷图谱PNG文件，确认插件可解析图片中的缺陷坐标与类型信息。
- 调用API接口，检查返回结果是否包含工具拉取的生产数据，且未直接暴露原始接口字段。
- 测试`functionCall`在异常查询场景下的自动匹配，确认是否调用异常处置单查询工具。
