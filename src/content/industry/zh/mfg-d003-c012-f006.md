# 半导体晶圆制造的工艺规程与技术标准问答：引用来源与溯源

## 这个品类的数据长什么样
半导体晶圆制造场景的业务数据覆盖多类工艺相关文档，包括工艺流程卡、批次运行记录、设备配方、SPC图、异常处置单、缺陷图谱、良率报告。数据主要来自MES系统、设备FDC模块、缺陷检测与量测设备、晶圆图文件、工艺配方库及实验数据。更新节奏随晶圆批次推进、设备运行状态实时同步，部分批量报告按每日频率更新，字段包含纳米级工艺参数、批次编号、缺陷坐标等，单位涵盖微米、瓦特等半导体工艺专用计量标准。

## 这些特征在「引用来源与溯源」这一环带来什么约束
多源异构的数据来源要求溯源环节需关联不同系统的唯一标识，避免跨源数据混淆。超长工艺链与复杂返工路径的特性，需要溯源结果精准匹配对应工序的文档片段，防止溯源偏移。纳米级工艺参数与洁净室环境的耦合特性，要求溯源数据的时间戳与批次信息严格对齐，否则会导致工艺判断偏差。实时更新的批次数据需要溯源接口支持低延迟查询，避免因数据滞后影响问答准确性。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本调整。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 字符 | 晶圆制造工艺文档包含长段参数与工序描述，该区间可覆盖单工序核心溯源内容 |
| `responseData` | 开启 | 需返回引用片段的批次编号、设备FDC参数等专属字段，支撑精准溯源 |
| `detail` | 开启 | 需展示引用片段的原始存储路径，匹配MES系统、设备日志的文档目录结构 |
| 单次召回引用数 | 前 3–5 条 | 单晶圆批次工序可达数百道，限制召回条数可避免上下文过载，同时覆盖核心归因依据 |
| 引用匹配阈值 | 0.75–0.85 | 半导体工艺参数精度要求高，该阈值可过滤低相关的非目标工序文档 |

## 容易做错的三处
- 搜索匹配到多条相关文档，但仅返回1条引用内容。未正确配置`quoteMaxToken`参数，或单次召回引用数设置过低，导致有效溯源片段被截断。
- 调用引用溯源接口后返回字段缺失报错。未开启`responseData`参数，未返回原始引用的批次编号、设备参数等必填字段，无法支撑完整溯源。
- 引用溯源结果未匹配到对应晶圆批次的工艺数据。未对齐引用片段的时间戳与批次标识，导致溯源偏移到非目标工序的文档。

## 怎么确认配好了
- 上传单份晶圆工艺流程卡，发起工艺参数相关问答，检查返回结果中引用片段的字符数是否符合预设区间。
- 查看问答结果的引用源列表，确认包含批次编号、设备FDC参数等专属业务字段。
- 调整单次召回引用数为前5条，发起跨工序良率归因问答，检查返回的引用条数匹配设置值。
- 模拟异常处置场景，检查引用结果的存储路径与MES系统的文档目录结构一致。
