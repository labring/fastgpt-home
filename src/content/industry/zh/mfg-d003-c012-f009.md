# 半导体晶圆制造的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据主要来自MES系统、设备FDC模块、缺陷检测与量测设备、工艺配方库及实验数据集。数据更新节奏覆盖每批晶圆产出、实时设备状态同步与每日汇总统计。日常文档包含工艺流程卡、批次运行记录、设备配方、SPC图表、异常处置单、缺陷图谱与良率相关记录，字段涵盖纳米级工艺参数、设备运行数值、缺陷空间坐标、批次标识与配方参数，单位包含纳米、毫秒等高精度计量标识。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据特征对模型接入与配置带来多重约束。首先，数百道工序与复杂返工路径的工艺数据，要求模型上下文窗口需适配长文本召回；其次，纳米级参数、缺陷空间分布等高精度字段，要求模型能精准匹配细分参数与异常场景；实时更新的设备与批次数据，要求向量检索链路支持高频同步；同时，洁净室环境下的隐性缺陷风险，要求模型输出需严格关联原始文档来源，避免无依据推断。另外，有限的返工窗口要求模型响应时长需适配产线节奏，不宜过长。

## 配置怎么定
以下配置说明基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配数百道工序的长工艺文档上下文，避免截断核心工艺参数 |
| `maxTokens` | 4000 token | 控制单轮回答长度，确保产线人员可快速读取，同时覆盖完整异常处置方案 |
| `quoteMaxToken` | 2000 token | 限制单段引用文档的长度，聚焦核心工艺步骤与参数，避免冗余信息干扰 |
| `temperature` | 0.2–0.4 | 降低随机输出，确保工艺规程回答的一致性与准确性，适配标准化生产要求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写专属节点 | 确保模型调用链路的稳定性，适配晶圆厂内部网络安全要求 |
| `AIPROXY_API_TOKEN` | 绑定专属服务账号的令牌 | 限制访问权限，符合洁净室生产环境的数据安全规范 |

## 容易做错的三处
- 现象：更新版本后模型输出长度过短，无法覆盖完整工艺处置步骤。原因：`maxTokens`或`maxContext`配置被意外调低，或默认参数被新版本覆盖。
- 现象：切换向量模型后界面显示无进度，且无法恢复原有配置。原因：未先清空现有向量库缓存，或配置保存链路出现异常，导致配置未生效。
- 现象：部署容器内模型文件缺失，无法正常加载问答模型。原因：镜像构建时未将离线模型包纳入打包流程，或挂载路径配置错误导致模型未正确加载。

## 怎么确认配好了
- 发起包含单道核心工艺参数的测试查询，核对模型输出是否关联原始文档的引用来源。
- 调整`temperature`参数后发起多轮相同查询，验证输出结果的一致性是否符合预期。
- 上传一份新增的工艺配方文档，触发向量索引更新，验证检索链路是否能正常召回新数据。
- 检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置，发起测试调用，确认无连接报错。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
