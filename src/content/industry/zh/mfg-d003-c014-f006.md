# 印染与后整理的工艺规程与技术标准问答：引用来源与溯源

## 这个品类的数据长什么样
本品类的数据来自客户色样、配方库、染化料批次记录、染缸控制数据、测色仪输出、定形机运行参数与环保监测台账。更新节奏为每缸、每批或每班一次，数据时效性强。日常文档包含染色配方、称化料记录、染缸温度曲线、打样确认单、色差报告、定形工艺单与污水台账，字段包含单位为摄氏度的温度值、单位为千克的加料量、6位编码的批次号等专属参数，不同文档的核心字段差异明显。

## 这些特征在「引用来源与溯源」这一环带来什么约束
每缸每批的高频更新要求溯源信息必须绑定唯一批次标识，避免跨批次的工艺参数混淆。多类型文档的差异化字段需要溯源功能支持按文档类型展示对应元数据，比如染缸曲线需展示温度区间，污水台账需展示排放数值。专属单位的字段要求引用时保留原始单位，防止工艺参数解读偏差。频繁更新的数据需要溯源功能支持指向最新版本的文档，确保回答基于当前有效工艺标准。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 相似度阈值 | 0.7–0.8 | 印染工艺参数精度要求高，需过滤低相关的非目标批次数据 |
| 单次搜索上限 | 前8条 | 单缸工艺相关文档条目有限，过多结果会干扰AI上下文理解 |
| `quoteMaxToken` | 1500–2000 token | 染缸曲线、配方文档的单段内容较长，需容纳完整参数片段 |
| `responseData` | 携带文档元数据 | 需展示批次号、更新时间等关键溯源信息 |
| `detail` | 开启完整字段返回 | 色差报告、定形工艺单需展示具体数值与对应单位 |

## 容易做错的三处
- 现象：知识库搜索无法匹配目标染缸的专属批次数据，结果显示无关缸次的工艺参数。原因：相似度阈值设置过低，过滤了精准匹配的批次字段内容。
- 现象：AI回答未展示任何引用来源信息，无法追溯工艺数据的原始文档。原因：未开启`responseData`配置，未关联文档的元数据字段。
- 现象：引用的染缸曲线内容被截断，缺失关键的升温节点参数。原因：`quoteMaxToken`设置过小，无法容纳完整的曲线数据片段。

## 怎么确认配好了
- 上传一份测试用的染色配方文档，发起对应工艺问题查询，检查返回结果是否包含文档中的批次号与加料量数值。
- 查看AI回答的引用区域，确认是否展示了文档名称、更新时间等元数据信息。
- 调整`quoteMaxToken`参数，验证长文本片段是否能完整出现在引用内容中。
- 模拟低相似度的模糊查询，确认结果被正确过滤，无无关的非目标缸次数据混入。
