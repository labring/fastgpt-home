# 变压器与高压电器制造的工艺规程与技术标准问答：多轮对话与提示词

## 这个品类的数据长什么样
该品类的数据来自设计BOM、硅钢片与绝缘材料采购数据、真空干燥设备运行日志、油化验报告、试验站局放及耐压试验记录、产品铭牌参数表。数据更新随每台成品、每批原材料的完成同步。日常文档包含绕制与器身装配记录、真空干燥流程记录、绝缘油性能报告、局放与耐压试验报告、产品铭牌参数表。核心字段包含绝缘距离、含水量、试验电压值，产品以单台为单位进行全生命周期追溯。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
单台追溯的属性要求对话需绑定`chatId`保留每台产品的专属上下文，通过`messages`参数传递历史交互内容，确保上下文连贯。高频的试验报告、绝缘参数查询，需要提示词明确限定仅调用变压器与高压电器制造的工艺文档，防止引入无关品类的工艺内容。每台/每批的更新频率要求对话可触发知识库的实时检索，确保返回的试验数据为当前批次最新结果。复杂的局放异常分析需要多轮对话逐步拆解参数，提示词需引导工程师补充具体的试验点位、电压等级信息，避免泛泛回答。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 单次搜索上限 | 前8条 | 匹配该品类单台产品的核心试验与装配文档数量，避免冗余信息干扰 |
| 最大上下文 | 12000 token | 适配多轮对话中需保留的单台产品全流程参数，确保上下文完整 |
| 问题优化 | 开启 | 辅助将工程师的口语化提问转化为符合工艺文档检索的规范表述 |
| 重排 | 开启 | 优先展示与绝缘参数、高压试验相关的高匹配度文档 |
| 变量`variables` | 绑定当前产品批次号 | 限定检索范围为对应批次的材料与试验数据 |
| 会话`chatId` | 随每台产品生成唯一值 | 确保每台产品的对话上下文独立，不与其他批次混淆 |

## 容易做错的三处
- 现象为迁移知识库后，对话界面提示知识库为空，但知识库管理页面可查看所有文档内容。原因是对话绑定的知识库关联配置未同步更新，或对话上下文缓存保留了旧的知识库关联信息。
- 现象为FastGPT v4.9.14版本下，多轮对话并发请求超出预期数量后出现报错。原因是未针对该版本配置合理的并发上限阈值，未限制单节点的对话并发数。
- 现象为stream设置为false与true时返回结果差异显著。原因是未在提示词中明确限定返回格式与内容范围，导致不同流式配置触发的检索逻辑不一致。

## 怎么确认配好了
- 发起单台产品的工艺查询，核对返回文档是否包含该产品对应的绝缘油报告、耐压试验记录。
- 切换stream与非stream模式，验证两次返回的结果范围与格式一致。
- 查看对话的`chatId`参数，确认每台产品的对话会话独立，无上下文混淆。
- 在FastGPT v4.17.0版本下，查看对话配置的知识库绑定状态，确认已关联正确的变压器与高压电器制造工艺文档库。
