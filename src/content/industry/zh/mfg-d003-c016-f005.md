# 变压器与高压电器制造的工艺规程与技术标准问答：工具调用与插件

## 这个品类的数据长什么样
该品类数据主要来自设计BOM、硅钢片与绝缘材料台账、真空干燥设备日志、油化验报告、试验站局放与耐压试验记录，以及单台产品的绕制装配、铭牌参数等文档。数据按每台产品或每批原材料更新，文档包含结构化参数（如绝缘厚度、试验电压值）与非结构化记录，字段需匹配设备型号、批次号、试验日期等专属标识，单位涵盖毫米、千伏、微库仑等行业专用单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
单台产品的专属追溯数据要求工具调用需绑定对应设备型号、批次号的上下文，避免跨产品数据混淆。高频更新的真空干燥、局放试验记录需适配实时或近实时同步逻辑，防止数据滞后影响问答准确性。绝缘厚度、试验电压等核心参数的字段校验需匹配行业专用单位与格式，避免非结构化文本解析偏差。批量导入数据时需区分单台追溯与批次台账的存储逻辑，确保检索时能精准定位目标文档。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | 自动 | 适配工艺问答的专业场景，自动触发对应工具 |
| 工作流/API 函数调用配置 | 开启 | 强制使用结构化工具调用，避免非结构化解析偏差 |
| 单次召回上限 | 前10条 | 匹配单台产品相关文档的平均数量，避免冗余数据干扰 |
| 上下文窗口大小 | 1200–1500 字符 | 适配单台产品核心工艺文档的长度，确保关键参数完整加载 |
| 超时时间 | 600 秒 | 适配FastGPT v4.17.0版本下跨数据源调取的默认耗时上限 |
| 字段映射规则 | 按实测标定 | 需匹配CSV或结构化文档的专属列名，确保数据读取准确 |

## 容易做错的三处
- 调用工具后返回结果为空，但预览插件时可获取到目标内容。原因是未正确配置`functionCall`的上下文绑定逻辑，未将当前产品的批次号、型号参数传入工具请求头。
- 上传CSV格式的工艺文档后，检索结果与界面生成的数据集不一致。原因是未指定CSV文件的字段映射规则，工具调用时默认读取的列与业务所需的绝缘参数、试验数据不匹配。
- 使用chunk模式调用pushdata API上传数据后，界面一直显示索引中状态。原因是未设置正确的批次数据拆分阈值，导致单批次数据量过大，超出系统默认的索引处理上限。

## 怎么确认配好了
- 发起单台变压器的工艺规程问答，核对工具调用返回的文档是否包含该产品专属的绝缘油报告、局放试验数据。
- 上传一批次绝缘材料数据，通过工具调用检索，确认返回的字段与预设的业务参数完全匹配。
- 模拟插件预览与正式调用的流程，对比两者返回的内容是否一致，验证上下文绑定逻辑是否生效。
- 查看FastGPT v4.17.0版本的系统索引日志，确认chunk模式上传的批次数据在合理时间范围内完成索引。
