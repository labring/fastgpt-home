# 变压器与高压电器制造的工艺规程与技术标准问答：引用来源与溯源

## 这个品类的数据长什么样
该品类的数据来源于设计BOM、硅钢片与绝缘材料采购数据、真空干燥设备日志、绝缘油化验报告、高压试验站记录。数据按单台产品或每批材料更新，对应文档包含绕制与器身装配记录、真空干燥记录、绝缘油检测报告、局放与耐压试验报告、产品铭牌参数表。核心字段包含绝缘距离、含水量、局部放电数值、耐压等级，单位多为毫米、皮库仑、千伏等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
单台产品追溯的核心需求，要求引用溯源需绑定具体产品批次与序列号，避免跨产品的文档混淆。多类型试验文档的字段差异，要求检索时需匹配对应文档的字段类型，如局部放电数据仅关联高压试验类记录。按单台或每批材料的更新节奏，需确保引用的数据源为最新批次的检测与装配记录，避免使用过期数据。绝缘结构与洁净度相关参数的严谨性要求，溯源时需明确引用来源的生成时间与试验环境，保障问答内容的准确性。

以下配置基于 FastGPT v4.17.0 版本。
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 相似度阈值 | 0.75–0.85 | 匹配变压器试验报告与装配记录的文本特征，过滤低相关的非工艺类文档 |
| 单次搜索上限 | 前8条 | 单台产品的核心工艺文档数量集中，过多引用会分散回答重点 |
| `quoteMaxToken` | 1200–1500 token | 适配绝缘油报告、耐压试验报告的文本长度，确保完整引用关键参数与结论 |
| 引用显示规则 | 显示来源文档类型与生成时间 | 符合单台产品追溯的需求，明确溯源的时间与文档类别 |
| `detail` | 开启完整字段展示 | 高压试验数据需明确局部放电数值、试验环境等细节，保障问答内容的严谨性 |
| `responseData` | 仅返回已关联产品批次的数据源 | 避免跨批次文档被错误引用，匹配该品类的单台追溯要求 |

## 容易做错的三处
- 现象：对话中返回了未添加到本地知识库的引用文档，原因：未配置数据源的权限绑定规则，导致检索范围超出预设的本地知识库范围。
- 现象：引用条数超出业务预期的上限，原因：未设置单次搜索上限的参数，或相似度阈值设置过低，召回了大量低相关的冗余文档。
- 现象：无法关闭对话中的引用展示区域，原因：未正确配置引用显示开关的默认状态，或后台配置未同步到前端渲染逻辑。

## 怎么确认配好了
- 发起一条针对具体产品批次的工艺问题，核对返回的引用来源是否均属于该批次的试验、装配文档。
- 调整相似度阈值与单次搜索上限后，发起测试问题，核对返回的引用条数符合预设范围。
- 检查引用展示区域是否显示来源文档的类型、生成时间等关键信息，确认`detail`配置生效。
- 尝试修改引用显示规则的配置，刷新对话后核对展示状态是否同步更新。
