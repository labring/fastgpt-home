# 变压器与高压电器制造的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
变压器与高压电器制造的核心数据来源于设计BOM、硅钢片与绝缘材料台账、真空干燥设备运行日志、绝缘油化验报告、高压试验站记录与单台产品铭牌参数表。日常文档包含绕制与器身装配记录、真空干燥流程记录、绝缘油检测报告、局放与耐压试验报告、产品铭牌参数表。数据更新节奏为每台产品或每批原材料批次更新，单台产品需全链路追溯绝缘结构、洁净度、引线连接等环节的全量记录。

## 这些特征在「模型接入与配置」这一环带来什么约束
单台产品的全量追溯数据要求模型能关联多源异构文档，需限制上下文总长度避免超出模型承载上限。每台/每批的更新频率要求配置支持增量数据同步，避免重复加载全量历史数据，降低资源占用。绝缘油、局放试验等专业字段的单位与数值精度要求模型能准确识别专业术语与数值范围，需配置合适的上下文匹配规则。高压试验异常分析的场景要求工具调用能快速关联试验报告数据，需明确工具触发的优先级与关联范围。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的逻辑制定：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配单台产品的多源文档总长度，避免超出模型上下文限制 |
| `temperature` | 0.1–0.3 | 保持专业问答的严谨性，减少无关发散内容 |
| `toolChoice` | auto | 自动触发工具调用以关联试验报告、装配记录等专业数据源 |
| `quoteMaxToken` | 2000 token | 限制引用文档的长度，确保模型聚焦核心试验参数与工艺要求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写专属节点 | 确保模型请求能正确路由到指定的部署实例 |
| `maxTokens` | 4000–6000 token | 限制单次回答的输出长度，避免超出硬件显存或平台响应限制 |

## 容易做错的三处
- 现象：新建AI对话时，工具调用的默认模型未出现在可选列表中，或发起对话后返回模型调用失败提示。原因：未在`AIPROXY_API_ENDPOINT`配置正确的模型部署节点，导致平台无法拉取可用模型列表。
- 现象：在知识库中测试搜索正常，但发起AI对话时无法调用重排模型，返回空的关联结果。原因：未在模型接入配置中绑定重排模型的`AIPROXY_API_TOKEN`，或重排模型的部署节点未正确关联至当前工作区。
- 现象：使用4070ti部署16b模型时，单条工艺问答的响应时长超过5分钟，且显存占用率持续处于高位。原因：`maxContext`配置值过大，超出部署硬件的显存限制，导致模型加载上下文耗时过长。

## 怎么确认配好了
- 在平台的模型管理页面查看已接入的模型列表，确认目标模型与版本已正常显示。
- 发起一条包含绝缘油密度或耐压值查询的测试对话，验证工具调用能正确关联并返回试验报告中的对应数据。
- 输入一条局放异常分析的查询，检查模型返回的内容是否包含合规的工艺规程引用。
- 查看模型调用日志，确认`maxContext`、`temperature`等配置参数已按设定值生效。
