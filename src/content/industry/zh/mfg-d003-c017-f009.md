# 喷涂与涂装的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
喷涂与涂装场景的业务数据涵盖涂装工艺卡、涂料批次单、调漆记录、膜厚色差报告、烘炉曲线、缺陷返修单、VOCs台账等多类文档。数据来源包括涂料供应商TDS/SDS文件、喷房与烘炉实时采集数据、色差仪、膜厚仪、环境监测设备及MES系统。数据更新频率随批次涂料、每班生产及连续采集节奏变化，字段包含膜厚、色差ΔE、烘炉温度、VOCs浓度等带明确单位的工艺参数，文档结构差异较大，既有标准化表格也有自由文本记录。

## 这些特征在「模型接入与配置」这一环带来什么约束
多类型文档与高频更新的特征要求模型接入配置需兼顾长上下文承载与实时数据适配。带明确单位的工艺参数需精准匹配，因此模型调用的参数稳定性要求较高。不同文档的字段权重差异大，如烘炉曲线与膜厚报告对工艺问答的优先级不同，需配置合理的召回与引用规则。VOCs台账涉及合规性内容，要求模型返回的引用片段准确对应原始文档，避免参数偏差。同时，本地部署与云端接入的路径差异，需适配不同的API端点配置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 承载涂装工艺卡、烘炉曲线等长文档的上下文，避免截断关键工艺参数 |
| `maxTokens` | 4000 token | 适配单条工艺问答的输出长度，完整返回膜厚控制、色差修正等细节内容 |
| `temperature` | 0.1–0.3 | 保证工艺标准问答的准确性，避免生成不符合涂装规范的非标准内容 |
| 工作流/API 工具选择配置 | auto | 允许模型按需调用工具，匹配前处理、喷涂窗口的复杂匹配需求 |
| `quoteMaxToken` | 2000 token | 限制引用文档片段的长度，确保召回的涂装数据清晰聚焦核心问题 |
| `AIPROXY_API_TOKEN` | 按实际部署的模型密钥填写 | 验证模型接入的身份权限，确保调用链路正常 |

## 容易做错的三处
- 上传涂装工艺卡、调漆记录等文档时解析失败。原因：未针对喷涂类文档的多字段格式配置正确的解析规则，导致文档结构识别异常。
- 工作流调用模型时出现与gpt-4o-mini相关的调用报错日志。原因：误将非gpt系列模型配置为依赖gpt-4o-mini的工具节点，未匹配实际接入的模型类型。
- 无法接入xinference部署的模型。原因：未正确填写`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`参数，或未配置模型的访问权限。

## 怎么确认配好了
- 上传单份涂装工艺卡文档，验证模型能正确召回其中的喷涂参数与固化要求。
- 发起一条涉及VOCs台账的合规问题，检查模型返回的结果是否包含正确的文档引用片段。
- 查看FastGPT v4.17.0的模型调用日志，确认`maxContext`和`maxTokens`参数未触发截断报错。
- 测试重排序功能，验证召回的文档片段按涂装工艺的优先级排序。
