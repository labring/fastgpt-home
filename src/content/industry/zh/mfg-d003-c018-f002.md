# 基础化工连续生产的工艺规程与技术标准问答：向量模型与索引

## 这个品类的数据长什么样
该品类的典型主体为氯碱、合成氨、甲醇、纯碱等基础化工企业，日常文档涵盖操作规程、工艺指标卡、DCS趋势、化验报告、联锁旁路记录、特殊作业票、班报。数据来源包含DCS/SIS系统、在线分析仪、LIMS系统、设备状态监测、能源计量平台、原料储罐监测系统。数据更新节奏分为实时（如DCS趋势）、每班（如班报）、每日（如化验报告）三类。文档兼具结构化字段（如工艺指标卡的温度、压力设定值与实测值，单位为℃、MPa、m³/h）与非结构化文本（如特殊作业票的操作步骤）。该品类为大宗连续生产，危险介质与强联锁控制突出，不同于石油炼制的原油多组分分馏网络。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据多源异构且更新频率差异显著，要求索引系统支持增量更新与多源数据适配；文档包含高敏感的强联锁参数与实时时序数据，出错后果为有毒可燃物泄漏、装置停车或产品污染，因此对召回结果的置信度要求更高；不同文档类型的长度差异明显，从短文本的工艺指标卡到长时序的DCS趋势文件，需要灵活的分块策略；部分数据（如联锁旁路记录）需严格匹配特定字段，对向量召回的精准度提出了额外约束。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配工艺规程的段落长度与DCS趋势的时序块长度，避免单块内容过载 |
| 重叠长度 | 100–150 字符 | 避免工艺指标卡的关键联锁参数被分块截断，保障召回完整性 |
| 相似度阈值 | 0.85–0.90 | 匹配基础化工强联锁场景的高置信度召回要求，过滤低相关性结果 |
| 单次搜索上限 | 前6条 | 覆盖班组报告、联锁旁路记录等多文档的召回范围，满足现场问答的信息需求 |
| maxToken | 4000 | 适配基础化工文档的总长度需求，符合`maxToken`参数的通用规范 |
| 超时设置 | 600 秒 | 适配DCS趋势等大体积数据的索引处理时长，避免任务中途中断 |

## 容易做错的三处
- 现象：索引任务长期处于运行中无进度，或返回503状态码。原因：未适配基础化工实时更新的DCS数据，未配置增量更新触发规则，导致大体积数据反复加载占用系统资源。
- 现象：embedding模型调用成功但问答无匹配结果。原因：相似度阈值设置过低，将无关的工艺参数数据误判为匹配项，或分块长度过长截断了关键联锁参数。
- 现象：对话模型可正常运行但向量索引任务无进度。原因：未单独配置embedding模型的API信息，仅绑定了对话模型的密钥，导致向量索引环节无法调用对应模型。

## 怎么确认配好了
- 查看FastGPT v4.17.0的索引任务日志，确认无超时报错、连接失败记录，且分块后的文档数量与源文档数量匹配。
- 手动输入工艺指标或联锁相关的问题，验证召回结果包含对应的DCS趋势、工艺指标卡或联锁旁路记录内容。
- 测试增量索引功能，上传新生成的班报数据，确认索引任务在设定的更新周期内完成。
- 检查embedding模型的调用日志，确认API请求参数正确，无格式错误或权限问题。
