# 基础化工连续生产的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
本品类数据来源包括DCS/SIS系统、在线分析仪、LIMS实验室管理系统、设备状态监测模块、能源计量装置与原料储罐数据接口。更新节奏涵盖实时、每班、每日三类。日常文档包含操作规程、工艺指标卡、DCS趋势图、化验报告、联锁旁路记录、特殊作业票与班报。数据字段多带工业标准单位，如压力MPa、温度℃、流量t/h、浓度mg/L等，部分联锁参数含触发阈值与动作延时字段。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类数据的多来源与高频更新特性，要求模型接入时适配不同更新节奏的上下文窗口，避免因`maxContext`设置过小丢失实时工艺数据。文档类型包含带专业单位的工艺指标、联锁参数与作业票，需通过`quoteMaxToken`控制引用长度，确保关键参数的完整提取。强联锁与报警数据的严谨性要求高，需调整`temperature`参数降低随机性，保证工艺问答的准确性。同时，实时DCS数据与班报的长文本特性，需要合理配置`maxTokens`避免生成截断关键处置步骤。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配DCS趋势、班报等长文档的上下文拼接，避免丢失关键工艺序列数据 |
| `maxTokens` | 2000–3000 token | 保证联锁处置、作业隔离等长步骤的完整生成，避免截断关键操作指引 |
| `quoteMaxToken` | 1000–1500 字符 | 保留工艺指标卡、化验报告的完整参数与单位，确保问答引用的准确性 |
| `temperature` | 0.1–0.3 | 降低生成随机性，匹配基础化工工艺的严谨性要求，避免出现不符合规范的处置方案 |
| `toolChoice` | auto | 自动触发工具调用，检索DCS/SIS数据、联锁记录等实时文档，适配稳态维持与报警核对的高频需求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配企业内部网络的API访问路径，确保模型调用的稳定性 |

## 容易做错的三处
- 现象：调用模型时返回`400 Bad Request`，提示不支持工具调用。原因：未针对基础化工场景配置`toolChoice`为auto，或选用了不支持工具调用的模型，无法完成联锁记录、作业票的检索调用。
- 现象：OneApi页面无法正常加载。原因：部署时未正确配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或网络策略限制了内部API的访问路径，导致依赖服务无法连通。
- 现象：无法在界面中新增默认模型提供商选项。原因：未通过官方指定的配置方式导入提供商信息，直接修改代码需提交PR才能生效，未按规范操作导致配置无法加载。

## 怎么确认配好了
- 发起包含工艺联锁参数的查询，核对返回结果是否包含完整的触发阈值与处置步骤，确认上下文与引用参数的配置覆盖了所需文档长度。
- 触发工具调用请求，检查是否自动检索了DCS趋势、化验报告等对应数据源的内容，确认工具调用配置生效。
- 查看模型生成的输出内容，核对是否保留了工艺参数的单位信息，确认引用长度配置合理。
- 验证内部API的访问路径，确认模型提供商的配置可正常连通服务，无访问报错。
