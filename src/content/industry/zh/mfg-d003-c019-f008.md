# 塑料注塑成型的工艺规程与技术标准问答：文档解析与分块

## 这个品类的数据长什么样
该品类的核心数据来自树脂批次物性表、注塑机运行参数、模温机记录、生产MES系统、尺寸与外观检测报告。日常文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验表、巡检表、换料清机记录，包含注塑压力、保压时长、模温、原料含水率、回料比例等字段，单位涵盖MPa、秒、℃、%等。数据更新频率为每生产批次、每次换模换料、每班生产周期更新一次。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的文档兼具结构化表格与半结构化段落特征，且更新频率高、时效性强，要求解析与分块需精准匹配生产场景逻辑。批量上传的模具履历、巡检表集合体积较大，需支持大文件分片解析；不同批次的文档存在字段差异，需避免跨批次的无关数据被合并分块；工艺卡中的充填保压冷却窗口等关键参数，需保证拆分时不被截断，否则影响后续问答准确性。同时，原料干燥与回料比例等关联参数需保留上下文关联，不能拆分至独立块中。

## 配置怎么定
以下配置适用于FastGPT v4.17.0
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 匹配注塑工艺卡中单段工艺参数的长度，避免拆分跨充填保压冷却窗口的关键描述 |
| `chunkSplitter` | 按段落+自定义分隔符 | 适配注塑文档中「工艺参数」「干燥记录」「模具履历」等固定标题结构，保留参数上下文关联 |
| `customPdfParse` | 开启 | 识别注塑文档中的结构化表格与固定表头，提取「原料含水率」「回料比例」等专用字段 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配批量上传的模具履历、巡检表集合的常规体积 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 覆盖批量大文件解析的常规耗时，避免中途超时中断 |
| `chunkSettingMode` | 手动模式 | 针对注塑文档的特定字段调整分块规则，确保关键参数不被拆分 |

## 容易做错的三处
- 现象：上传大批量文档中途出现中断，重启服务后无法继续解析。原因：未设置合理的`UPLOAD_FILE_MAX_SIZE`与`PARSE_FILE_TIMEOUT_SECONDS`，批量文件超出存储限制或解析耗时超出阈值触发中断。
- 现象：解析后的文档可查看，但模型回答未引用文档内的工艺参数内容。原因：`chunkSplitter`未按文档结构拆分，导致充填保压冷却窗口、原料干燥参数等关键内容被拆分至不同分块，无法关联上下文。
- 现象：对话框上传文件后无解析进度提示，后台无报错信息。原因：未开启`customPdfParse`，通用PDF解析无法识别注塑文档中的结构化表格与专用字段，导致解析静默失败。

## 怎么确认配好了
- 上传单份注塑工艺卡，查看解析后的文本是否保留「充填压力」「保压时间」「模温」等专用字段。
- 上传批量换料清机记录集合，检查解析任务是否在600秒内完成，无中断或超时提示。
- 检索「某批次原料含水率」相关问题，确认返回结果包含对应分块的完整参数与上下文。
- 调整`chunkSize`至600字符与1500字符区间，验证拆分后的段落未跨关键工艺窗口的描述。
