# 塑料注塑成型的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源包括树脂批次物性表、注塑机运行参数、模温机数据、MES系统记录、首件检验表、换料清机记录与模具履历。日常文档包含注塑工艺卡、原料干燥台账、巡检表单等，字段涵盖料温、保压压力、冷却时长、原料含水率等，单位多为摄氏度、兆帕、秒。数据更新随生产批次、换模换料操作与每班巡检触发，无固定周期，每次生产动作触发对应文档更新。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据多源分散且更新触发无固定周期，随生产批次、换模换料与每班巡检实时更新，导致模型接入需支持实时拉取不同生产节点的文档。单份工艺文档长度较长，需适配长文本分段处理逻辑。文档字段涵盖多种工程单位，需模型能准确识别并关联对应参数。不同生产环节的文档字段差异显著，需配置灵活的字段映射规则，避免参数匹配错误。同时，工艺问答需关联多份文档进行交叉验证，模型上下文容量需满足多文档同时加载的需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 注塑工艺文档单份长度多在千字符级别，需容纳多份工艺卡与巡检记录的上下文，避免问答过程中丢失关键信息 |
| `maxTokens` | 4000 token | 匹配单次问答返回的工艺参数解释与问题分析长度，避免超出模型输出限制导致结果截断 |
| `toolChoice` | auto | 支持自动调用内置工具处理长文本切割与多源数据关联，适配工艺问答的多步骤分析需求 |
| `AIPROXY_API_ENDPOINT` | 按部署的模型网关地址填写 | 适配企业内部部署的模型服务地址，确保请求能正常路由到目标模型 |
| `AIPROXY_API_TOKEN` | 按网关分配的密钥填写 | 完成请求身份验证，确保模型接入的安全性与合法性 |
| `temperature` | 0.2–0.4 | 保持工艺参数回答的准确性，避免生成不符合注塑规范的非标准参数 |

## 容易做错的三处
- 现象：调用HTTP API获取工艺文档后，返回长文本被截断或触发上下文溢出报错。原因：未配置长文本自动分段逻辑，直接将完整文档传入模型，超出`maxContext`设置的上限。
- 现象：配置`toolChoice`为false后，无法触发内置的文本切割与多段发送功能。原因：错误关闭了自动工具选择开关，导致无法调用系统内置的文本处理工具。
- 现象：创建知识库时无法选择通过容器启动并接入网关的本地ChatGLM2模型。原因：未在系统配置中正确录入模型的接入地址与密钥，或模型版本与FastGPT v4.17.0兼容不匹配。

## 怎么确认配好了
- 发起测试请求，传入一份典型的注塑工艺卡文本，检查模型能否正确返回工艺参数解释，验证上下文加载正常。
- 配置`toolChoice`为auto，发起包含长文本的测试请求，检查系统是否自动触发文本分段工具，验证工具调用逻辑生效。
- 核对`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置值，发起模型连通性测试，检查请求能否正常返回响应。
- 调整`temperature`的取值，发起多次测试请求，检查回答的一致性是否符合工艺参数的准确性要求。
