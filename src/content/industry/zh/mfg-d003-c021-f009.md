# 家具与木制品制造的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
该品类的日常文档包含拆单图、开料清单、封边与钻孔程序、涂装工艺、五金清单、试装与包装记录。数据来源为订单设计系统、板材和木材批次数据、数控开料与钻孔设备、ERP/MES系统、含水率检测结果。数据更新节奏随订单、每日生产批次、材料批次变动。文档字段包含板件尺寸参数、材料含水率、五金型号规格、涂装工艺参数等，部分文档关联具体生产批次与订单编号。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据来源分散且关联生产全流程，模型接入时需确保不同来源的工艺文档与对应生产批次、订单精准绑定，避免跨订单数据混淆。文档包含数控程序、开料清单等结构化与半结构化内容，配置需适配多格式数据源的解析逻辑。数据更新频率随订单、生产批次变动，需支持按需同步或定时更新机制，防止调用过时的工艺参数。定制订单驱动的板件数量多，模型上下文长度需适配多文档召回的场景，同时避免冗余信息干扰问答准确性。

## 配置怎么定
本内容基于FastGPT v4.17.0版本的配置逻辑编写。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配多板件工艺文档的召回量，避免上下文溢出影响问答逻辑 |
| `maxTokens` | 2000–3000 token | 控制单轮问答输出长度，确保工艺参数与要求的完整展示 |
| `quoteMaxToken` | 1500 字符 | 限制召回文档的引用长度，聚焦核心工艺要求与参数 |
| `temperature` | 0.2–0.4 | 降低回答随机性，保证工艺参数与生产要求的回答准确性 |
| `AIPROXY_API_ENDPOINT` | 部署FastGPT的本地或内网地址 | 适配家具制造企业内网部署的场景，保障生产数据安全 |
| `AIPROXY_API_TOKEN` | 企业专属鉴权令牌 | 限制接口访问权限，防止未授权调用生产相关数据 |

## 容易做错的三处
- 出现`do_request_failed`报错，Post请求失败。原因是未正确配置`AIPROXY_API_ENDPOINT`为内网可访问地址，或`AIPROXY_API_TOKEN`鉴权校验不通过。
- 问答返回的工艺参数与实际生产批次不符。原因是未按订单或生产批次绑定召回数据源，导致调用了过时的文档数据。
- 单轮问答输出过长，超出生产现场终端的展示限制。原因是未合理设置`maxTokens`参数，导致返回内容冗余且无关信息较多。

## 怎么确认配好了
- 调用测试接口发起工艺参数查询，核对返回内容与目标数据源的匹配度，确认召回的文档属于当前查询的订单或生产批次。
- 查看接口调用日志，确认请求的鉴权信息与配置的`AIPROXY_API_TOKEN`一致，无鉴权失败记录。
- 模拟不同场景的查询请求，包括拆单要求、涂装工艺等，确认返回内容符合该品类的工艺规范。
- 测试上下文长度较大的查询场景，确认模型未出现上下文溢出导致的异常报错。
