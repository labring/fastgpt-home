# 家用电器整机制造的工艺规程与技术标准问答：向量模型与索引

## 这个品类的数据长什么样
本品类的日常文档包含配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告、返修记录。数据来源于ERP/MES系统、零部件批次台账、拧紧与充注设备日志、安规测试仪数据、性能实验室测试结果、售后故障反馈库。数据更新频率为单台产品对应记录实时生成，班组级文档按班次更新，抽检类报告按既定计划生成。文档字段包含零部件编号、工艺参数、测试数值、批次标识、时间戳等，部分文档带有物理单位，如制冷剂充注量单位为克，拧紧扭矩单位为牛米。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类的数据特征对向量模型与索引环节带来多重约束。多源异构的数据来源，包括设备日志、系统台账、测试报告等，要求统一嵌入规则，避免不同来源的同类型字段出现语义偏差。高频实时更新的单台产品记录与低频抽检报告混合存储，需要设置分层索引策略，区分实时查询与批量召回的优先级。文档携带精准工艺参数与物理单位，向量建模需保留字段语义细节，防止单位与参数混淆导致检索偏差。多型号混线装配的场景下，索引需支持按产品型号快速过滤，避免跨型号工艺文档误匹配。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本，其中 `defaultToken` 与 `maxToken` 的取值需适配本品类的长文本文档特征。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 本品类文档包含长段工艺步骤与测试数据，该长度可保留完整语义单元，避免切割工艺逻辑 |
| 重叠长度 | 100–150 字符 | 工艺规程存在连续步骤关联，重叠分块可保留上下文连贯性，防止检索时丢失步骤衔接信息 |
| 相似度阈值 | 0.75–0.85 | 需区分同型号不同批次的工艺参数差异，避免低匹配度的无关文档被召回 |
| `defaultToken` | 8192 | 适配本品类长文本文档的嵌入需求，确保完整工艺参数与测试结果可被正确向量化 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| 单次搜索上限 | 前 8 条 | 混线装配场景下需快速定位对应型号的工艺文档，过多结果会增加现场判断成本 |

## 容易做错的三处
- 现象：知识库新建数据索引后长时间显示「索引中」状态，无进度更新。原因：未适配本品类高频实时更新的单台产品记录，索引刷新触发频率设置过高，导致系统资源被占用。
- 现象：自定义索引配置后检索结果无匹配内容，或匹配结果与工艺问题无关。原因：未针对本品类携带物理单位的工艺参数设置语义映射，导致向量嵌入时丢失单位与参数的关联信息。
- 现象：接入自定义向量数据库后无法加载现有数据。原因：未按照FastGPT要求的向量存储格式转换本品类的批次编号、拧紧扭矩、制冷剂充注量等字段，导致数据库无法识别字段语义。

## 怎么确认配好了
- 上传单台家电产品的装配作业书与测试报告，发起工艺相关检索，查看返回结果是否包含对应型号的工艺内容。
- 查看FastGPT的索引任务日志，确认本品类的多源数据均已完成向量化与索引创建。
- 输入包含物理单位的工艺查询，如「冰箱的电气安全测试标准」，核对检索结果是否匹配对应文档的信息。
- 测试不同分块配置下的检索结果连贯性，确认工艺步骤未被过度切割。
