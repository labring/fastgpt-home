# 工业仪器仪表制造与校准的工艺规程与技术标准问答：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自流量、压力、温度类仪器制造商与计量实验室，日常文档包含装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录。数据来源于设计文件、标准器监测数据、校准软件、实验室信息系统及客户量程要求，更新频率为每台仪器每次校准后更新。文档包含量程、误差值、校准日期、溯源编号等专业字段，单位涵盖帕斯卡、立方米每小时、摄氏度等计量专用单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
品类数据的高频更新要求检索系统支持单台/单批次文档的增量更新，避免全量重建知识库。多类型文档包含表格、曲线与长文本，要求检索系统适配非结构化专业文本的分块与匹配逻辑。数据来源分散且字段统一要求高，需通过元数据绑定仪器类型与校准周期，缩小检索范围。校准记录作为核心交付物，要求检索召回的内容具备可溯源性，避免引入非官方文档。专业术语密集，要求检索匹配精准度高于通用场景，减少偏差传递风险。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.82–0.88` | 适配校准规程的专业术语匹配，避免误召回非相关误差曲线或计量证书 |
| `limit` | `前6条` | 单仪器分类下的文档量适中，限制召回条数避免上下文溢出 |
| `searchMode` | `精确匹配优先` | 工艺规程与校准标准需精准匹配专业术语，避免模糊召回非目标内容 |
| `usingReRank` | `开启` | 校准记录与误差曲线的语义相似度需二次校验，提升精准匹配度 |
| `datasetSearchUsingExtensionQuery` | `关闭` | 专业术语无需扩展查询，避免引入非标准表述干扰检索结果 |
| `collectionIds` | `按仪器类型绑定对应集合` | 按流量、压力、温度仪器分类存储文档，缩小单次检索范围 |

## 容易做错的三处
- 检索返回超时，界面提示“检索超时”或返回`504`状态码。原因是未按仪器类型绑定`collectionIds`，检索范围覆盖全量知识库，导致耗时超出阈值。
- 导入的长校准规程出现分段异常，部分长段落被强制截断或合并超出预期长度。原因是未适配校准规程的长表格与误差曲线文本的分块逻辑，未按专业文档的自然分段处理。
- 检索结果未返回预设问答对的原文答复，出现非目标内容。原因是未正确配置`similarity`阈值，召回了非目标文档，或未开启精准匹配模式。

## 怎么确认配好了
- 导入单台仪器的校准规程文档，检索对应工艺关键词，检查召回结果的条数与相似度符合配置参数。
- 触发检索操作，观察界面响应时间，确认未出现超时报错或异常状态码。
- 导入预设的问答对文档，检索对应问题，检查返回内容为预设答复的原文内容。
- 查看知识库分块日志，确认长文档的分段处理符合专业文档的自然分段逻辑。
