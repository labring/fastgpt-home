# 有色金属冶炼与电解的工艺规程与技术标准问答：工具调用与插件

## 这个品类的数据长什么样
该品类的数据来源涵盖精矿与辅料分析报告、生产DCS系统、电解槽电压电流监测数据、化验室检测结果、能源与环保监测台账。数据更新节奏随生产节点变动，每批原料、每炉熔炼或每槽电解环节实时更新。日常产出的文档包含配料单、熔炼记录、电解槽况记录、化验报告、阳极阴极质量记录与环保台账，字段多包含精矿品位、槽电压、电流强度、杂质含量等，单位涉及百分比、毫伏、安培、克每吨等。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据实时性强、更新节点分散，工具调用需支持低延迟响应，避免因等待超时影响生产调度节奏。日常文档字段专业且类型多样，插件需精准匹配配料单、电解槽况记录等特定文档的字段格式，不依赖通用字段映射。数据来源覆盖多系统，工具调用需支持对接DCS、化验室系统等多类数据源，同时需动态拉取最新的生产数据，不依赖静态缓存文件。关键数据涉及金属回收率与环保指标，工具提取的字段需严格对齐原始台账的单位与精度要求。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配工艺问答中动态调用工具的需求，无需手动指定具体工具 |
| 单次工具调用超时时间 | 300 秒 | 匹配生产环节的响应等待窗口，避免因数据拉取延迟导致问答中断 |
| 工具返回字段过滤 | 保留精矿品位、槽电压、杂质含量等核心字段 | 匹配该品类文档的核心业务字段，减少无效信息干扰 |
| `functionCall` | 按实测标定 | 适配专业工艺术语的函数调用格式，避免参数解析错误 |
| 插件数据源刷新频率 | 每10分钟 / 实时触发 | 对应生产数据的更新节奏，保障问答使用的是最新生产数据 |

## 容易做错的三处
- 调用接口将`stream`参数设为`true`后无法获取完整最终结果，原因是未配置流式数据的聚合逻辑，导致分段返回的内容未被合并。
- 私有部署环境导入插件时提示`internal server error`，原因是部署版本与插件依赖的环境配置不匹配，或本地缓存未清理。
- 使用SSE协议封装的MCP插件无法被正常识别，原因是平台仅支持stdio进程类型的插件，未完成协议适配的配置调整。

## 怎么确认配好了
- 发起包含工艺参数查询的测试请求，核对返回结果中是否包含预设的核心业务字段。
- 查看插件运行日志，确认工具调用的响应时间符合预设的等待窗口要求。
- 导入插件后执行连通性测试，确认无异常报错提示。
- 配置流式调用后，验证是否能完整接收并聚合所有分段返回的结果数据。
