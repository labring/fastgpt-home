# 汽车零部件批量制造的工艺规程与技术标准问答：工作流编排

## 这个品类的数据长什么样
该品类数据主要来自客户图纸与特殊特性清单、ERP/MES系统、量检具数据、设备过程参数及供应商质保书。日常生产相关文档包含控制计划、过程流程图、作业指导书、首件与巡检记录、SPC报表、PPAP资料、8D报告。数据更新节奏为每批生产、每班巡检及持续采集设备参数，文档字段包含零件编号、工序参数、质量特性值、异常记录等，单位多采用毫米、牛米、百分比等行业通用计量标准。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的数据分散且更新节奏频繁，工作流编排需适配多数据源的实时同步调用，避免因数据滞后导致工艺问答出现偏差。日常文档类型多样，工作流需预设不同文档的解析规则，分别从控制计划提取工序要求、从8D报告提取异常根因。受整车客户质量体系约束，工作流需配置严格的权限校验节点，仅允许绑定了`nodeId`权限标记的环节访问涉密质量文档。批量生产的实时性要求，工作流需支持高频触发，处理来自MES的实时异常数据与巡检记录。

## 配置怎么定
以下配置参考FastGPT v4.17.0版本的工作流编排功能。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` 定义 | 绑定零件编号、批次号为必填变量 | 适配批量生产的场景化工艺问答需求 |
| 分块长度 | 1000 字符 | 适配汽车零部件工艺文档的标准段落长度 |
| 全局变量传递 | 启用跨节点调用 | 支持token等参数在MCP工具间流转 |
| 超时设置 | 600 秒 | 适配多文档检索与解析的处理时长 |
| `nodeId` 权限标记 | 为涉密文档节点绑定专属ID | 适配整车客户的质量体系权限约束，实现涉密文档的访问控制 |
| 知识库关联 | 关联3–5个专属知识库 | 适配该品类的文档存储规模 |

## 容易做错的三处
-  工作流执行后返回结果条数不符预期，现象为检索到的文档数量少于配置值。原因是未正确配置知识库关联数量，或关联的知识库未同步最新的工艺文档。
-  全局变量无法在后续节点调用，现象为下游模块读取到的变量字段为空。原因是未启用全局变量的跨节点传递配置，或变量定义时未勾选全局作用域。
-  MCP工具调用失败，现象为返回认证错误或参数缺失。原因是未将工作流中的token全局变量正确绑定到MCP工具的请求参数中，导致工具无法获取合法认证信息。

## 怎么确认配好了
-  触发测试问答，输入包含零件编号、批次号的问题，核对工作流是否自动提取对应`variables`变量。
-  手动触发工作流，检查各节点的日志是否显示全局变量已正确传递至下游模块。
-  调用MCP工具，核对工具请求参数中是否包含工作流传入的认证信息。
-  调整知识库关联数量，验证检索结果的数量是否符合配置预期。
