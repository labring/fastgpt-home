# 汽车零部件批量制造的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来自客户图纸、特殊特性清单、ERP/MES系统、量检具、设备过程参数及供应商质保书。日常文档包含控制计划、过程流程图、作业指导书、首件与巡检记录、SPC报表、PPAP资料与8D报告。数据随生产批次、班次持续更新，包含批次号、公差值、设备运行参数、检验结果等明确字段与单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类数据更新频率高且随生产批次实时变动，要求模型接入环节支持增量同步与高频批量调用。多类型的工艺与质检文档结构差异较大，需配置适配多格式的解析规则以完整提取核心字段。受整车客户质量体系约束，问答结果需严格匹配官方文档内容，同时需避免因配置不当导致批量不良相关的错误输出，保障生产一致性。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配多份工艺文档与质检记录的上下文长度，避免截断关键的特殊特性与公差要求 |
| `maxTokens` | 4000 token | 控制单轮问答输出长度，确保批量生产场景下的响应效率，避免超出API调用限额 |
| `quoteMaxToken` | 2000 token | 限制引用的文档片段长度，聚焦核心的控制计划、作业指导书内容，减少无关信息干扰 |
| `temperature` | 0.1–0.3 | 降低随机性，确保工艺规程与技术标准的回答严格匹配官方文档内容，符合汽车零部件制造的质量一致性要求 |
| `vision` | 开启 | 支持识别并引用知识库中的图片内容，适配包含工艺示意图的文档场景 |
| `AIPROXY_API_TOKEN` | 绑定专属服务账号 | 隔离不同生产场景的API调用权限，避免因权限问题导致的调用中断 |

## 容易做错的三处
- 现象：大模型调用提示欠费，但后台API余额仍有剩余。原因：未正确绑定`AIPROXY_API_TOKEN`，导致调用被代理服务误判为未授权欠费。
- 现象：工作流运行报错，提示模型配置正确但执行失败。原因：未设置合理的`maxContext`参数，长文档上下文被截断后触发模型调用异常。
- 现象：问答结果未展示知识库中的图片内容。原因：未启用`vision`配置，且未在系统提示词中明确要求关联图片引用。

## 怎么确认配好了
- 执行单轮工艺规程问答测试，核对返回内容是否包含指定的特殊特性与公差值，确认`maxContext`与`maxTokens`配置未截断关键信息。
- 模拟批量调用场景，检查API调用日志的响应时长与成功率，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置有效。
- 上传包含图片的工艺文档，发起相关问答，确认图片内容被正确识别与引用，验证`vision`配置生效。
- 调整`temperature`参数至不同区间，对比问答结果的一致性，确认配置符合质量一致性要求。
