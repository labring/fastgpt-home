# 生物制品与无菌生产的工艺规程与技术标准问答：工作流编排

## 这个品类的数据长什么样
本品类的数据涵盖细胞库与种子批记录、培养纯化记录、无菌灌装记录、环境监测数据、培养基模拟灌装结果、无菌检验报告及批放行资料。数据来源包括细胞库管理系统、过程分析设备、洁净区监测系统、MES、LIMS及设备完整性测试工具。更新节奏按每批生产、实时监测数据上传及固定监测计划执行。单份文档包含批次标识、操作时间、关键工艺参数、检验结果、操作人员信息等字段，参数常带℃、CFU/mL、小时等专用单位。

## 这些特征在「工作流编排」这一环带来什么约束
本品类数据来源分散，涉及多套系统与设备，工作流编排需整合跨源数据拉取节点，确保覆盖所有必要的过程与检验数据。不同于化学制剂品类，本品类无法通过成品抽检覆盖所有风险，需依赖全流程数据的校验。不同数据的更新节奏差异较大，实时监测数据需配置触发式拉取，批级数据则需按生产批次触发同步。文档字段包含专用工艺参数与单位，工作流需内置参数格式校验环节，避免不符合规范的数值进入问答逻辑。由于出错后果涉及患者安全与批次报废，工作流需增加异常分支处理与告警配置。FastGPT v4.17.0版本的工作流节点可适配这类多源、多节奏的数据处理需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `variables` | 包含批次号、洁净区等级、工艺阶段三类核心参数 | 匹配本品类数据的核心标识字段，支撑跨源数据拉取与精准问答 |
| 重试次数 | 3 次 | 应对单次工具调用的临时网络波动，符合医药生产场景的稳定性要求 |
| 超时时间 | 600 秒 | 覆盖复杂的跨系统数据拉取与工艺参数校验流程 |
| 参数校验规则 | 匹配文档字段的单位与取值区间 | 确保进入问答逻辑的工艺参数符合无菌生产规范 |
| `nodeId` | 绑定工具调用节点与异常告警节点 | 实现工作流分支的精准跳转与异常通知 |
| 最大上下文长度 | 800–1200 字符 | 适配单批次生产文档的核心内容长度，避免上下文溢出 |
| 文件上传大小限制 | 1000 MB | 适配本品类批放行资料的单文件最大体积 |

## 容易做错的三处
- 工具调用节点返回结果为空或格式异常。原因是未配置`variables`绑定批次号参数，导致工作流无法拉取对应批次的工艺文档数据。
- 工作流优化环节无法加载历史对话记录。原因是未开启工作流的上下文持久化配置，导致会话状态无法跨节点留存。
- 嵌入业务系统后身份校验失败。原因是未在工作流的HTTP请求节点中配置业务系统的身份令牌传递逻辑，导致FastGPT平台无法验证调用方权限。

## 怎么确认配好了
- 触发一次模拟生产批次的工作流，检查`variables`参数是否正确传入批次号与工艺阶段信息。
- 模拟工具调用节点的异常返回，确认工作流是否跳转至重试或告警分支。
- 嵌入业务系统发起调用，验证身份令牌是否随HTTP请求正确传递至FastGPT平台。
- 查看FastGPT v4.17.0版本的工作流运行日志，确认上下文长度未超出配置阈值且参数校验环节未过滤有效数据。
