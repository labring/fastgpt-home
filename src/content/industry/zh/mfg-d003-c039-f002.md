# 电机与发电机制造的工艺规程与技术标准问答：向量模型与索引

## 这个品类的数据长什么样
本品类数据来自电机与发电机制造企业的绕线、绝缘、总装与试验部门，日常文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试记录、型式与出厂试验报告。数据来源涵盖电磁设计数据、铜线与绝缘材料批次信息、绕线设备、平衡机、电气试验台数据及ERP/MES系统数据。数据更新频率为每台产品或每批次生产完成时更新，每次产品型式变更后同步更新全部关联文档。文档包含明确的工艺参数、测试数值、批次标识与变更记录字段，单位涵盖匝数、温度、压力、功率等细分品类专属指标。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类数据的高频小批量更新、多类型测试文档混合、专属工艺参数字段等特征，对向量模型与索引环节带来多重约束。首先，每台或每批产品的文档独立关联批次信息，需在分块时保留批次标识与工艺节点的上下文关联，避免检索时跨批次混淆不同产品的工艺要求。其次，文档包含大量带专属单位的数值型参数，向量模型需适配结构化与非结构化混合的文本内容，确保语义检索时能准确匹配工艺参数与异常场景。另外，高频更新的特性要求索引支持增量同步，避免全量重建带来的耗时问题，同时需保证检索结果与最新的工艺变更、测试数据保持一致。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配绕组工艺卡、测试报告的单段落长度，避免关键工艺步骤的语义割裂 |
| 重叠长度 | 100–150 字符 | 保留跨分块的绕组接线、绝缘处理流程上下文，防止关键信息被截断 |
| 相似度阈值 | 0.72–0.85 按实测标定 | 匹配本品类工艺参数与异常场景的语义匹配精度，避免误匹配不同批次的工艺要求 |
| 单次搜索上限 | 前 6 条 | 控制检索结果的信息量，适配工艺问答的单场景查询需求 |
| `maxToken` | 4096 token | 适配FastGPT v4.17.0的模型输入上限，确保完整加载关联的工艺文档与测试数据 |
| `defaultToken` | 256 token | 补充基础工艺术语的向量化上下文，提升低频工艺场景的检索匹配度 |

## 容易做错的三处
- 现象：向量索引创建完成后，PG数据库仅存储向量数据，无法关联原始文档的批次与工艺参数内容。原因：未开启原始文档持久化的配置项，仅同步了向量化后的结果，导致检索时无法回溯原始工艺文档的完整信息。
- 现象：使用bge-m3向量模型时，语义检索返回的相似度分值异常偏高，或搜索测试直接报错。原因：未针对本品类的专属数值型参数调整相似度阈值，或分块长度设置超出模型支持范围，导致语义匹配逻辑失效。
- 现象：在部署的FastGPT实例中，知识库建索引步骤长时间无响应，任务进度停滞。原因：未配置分批同步的索引规则，全量导入多批次的电机测试报告时，单次任务占用过多系统资源导致超时。

## 怎么确认配好了
- 登录关联的PG数据库，查看知识库对应数据表，确认同时存在原始文档文本字段与向量字段，验证存储配置生效。
- 输入绕组匝数核对、绝缘处理步骤查询等专属场景的问题，检索返回结果的相似度分值落在预设阈值区间内，验证参数配置匹配。
- 导入单批次的绝缘处理记录文档，执行增量索引同步，确认任务在合理时长内完成，验证更新配置适配高频小批量更新需求。
- 调用FastGPT的检索接口，查看返回结果的条数符合单次搜索上限的设置，验证检索规则生效。
