# 电机与发电机制造的工艺规程与技术标准问答：多轮对话与提示词

## 这个品类的数据长什么样
该品类数据来自电机厂、电力装备企业的绕线、绝缘、总装与试验部门，包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试记录、型式与出厂试验报告等文档。数据字段涵盖绕组匝数、铜线规格、绝缘材料批次、试验电压、温升数值等，单位包含匝数、毫米、伏特、摄氏度等。数据更新频率为每台或每批产品产出，以及每次产品型式变更时同步更新，数据来源覆盖电磁设计数据、原材料批次记录、生产设备运行日志与ERP/MES系统。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
该品类的工艺与测试数据需匹配单台或单批产品的专属参数，多轮对话需保留每台产品的绕组匝数、绝缘批次等上下文信息，避免跨批次数据混淆。文档包含电磁、绝缘、机械平衡多维度专业内容，提示词需明确限定检索范围为对应部门的专属文档，防止混入其他品类的工艺数据。数据更新频率高且变更频繁，需在对话中触发实时关联最新的型式变更记录，同时需限制单次对话上下文长度，避免加载过多旧批次数据导致响应延迟。用户通常会针对单台产品发起多轮参数核对，对话流程需适配从工艺参数查询到异常分析的完整场景。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 相似度阈值 | 0.75–0.85 | 该品类工艺文档字段多且专业，需过滤低匹配度的无关数据，保留高相关的绕组、试验类文档，适配FastGPT v4.17.0的检索逻辑 |
| 单次搜索上限 | 前6条 | 电机制造工艺文档包含多维度关联内容，6条结果可覆盖绕组、绝缘、试验的核心信息，避免结果冗余 |
| 上下文保留长度 | 前12轮对话 | 单台电机的工艺问答通常涉及多轮参数核对，12轮可覆盖从绕组匝数到耐压试验的完整流程，避免上下文溢出 |
| `variables`配置 | 绑定产品批次ID与试验类型 | 该品类数据按批次与产品类型更新，通过变量限定检索范围，精准匹配当前对话的产品参数 |
| `chatId`绑定 | 绑定单台/单批产品的唯一标识 | 多轮对话需关联专属工艺数据，`chatId`可确保对话上下文与特定产品绑定，避免跨产品数据混淆 |
| `messages`历史管理 | 保留最近2000 token的对话内容 | 电机工艺问答的上下文包含专业术语与参数，2000 token可覆盖完整的多轮追问流程，同时控制响应加载速度 |

## 容易做错的三处
- 现象：升级到FastGPT v4.17.0后，对话窗口报错，上传文件和文本数据集失败，仅模版导入功能可正常上传。原因：升级后接口路由逻辑未适配非模版类文件的上传路径，导致请求未正确匹配目标数据集接口。
- 现象：无法通过提示词指定特定数据集进行搜索，检索结果包含全平台的工艺文档。原因：未通过`variables`配置绑定目标数据集的专属标识，提示词未限定检索范围为电机制造专属的工艺文档。
- 现象：对话开场白仅预设单个引导问题，无法提供多个可选的初始查询方向。原因：未在`messages`初始参数中配置多组预设问题，未启用多轮对话的开场白变量设置。

## 怎么确认配好了
- 上传一份绕组工艺卡文件，发起检索请求，核对返回结果仅包含该文档的相关内容，无无关的其他品类文档。
- 发起两轮以上的参数追问，核对对话上下文保留了前一轮的绕组匝数或绝缘批次信息，未出现上下文丢失的情况。
- 查看对话开场白，确认显示多个预设的引导问题，覆盖绕组参数查询、试验标准核对等核心场景。
- 上传一份动平衡报告文件，确认上传成功且可正常发起检索，无接口报错或数据丢失的情况。
