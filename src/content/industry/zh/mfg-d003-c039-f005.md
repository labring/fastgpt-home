# 电机与发电机制造的工艺规程与技术标准问答：工具调用与插件

## 这个品类的数据长什么样
电机与发电机制造的工艺规程与技术标准数据，来自绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试记录、型式与出厂试验报告等文档，数据来源涵盖电磁设计数据、铜线和绝缘材料批次信息、绕线设备参数、平衡机运行记录、电气试验台结果以及ERP/MES系统数据。数据更新频率为每台产品或每批次生产完成更新，每次产品型式变更时同步更新。文档字段包含绕组匝数、接线方式、浸漆烘干参数、振动测试值、温升数据、耐压试验结果等，附带对应批次的材料编号与设备运行记录。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据按批次与型式变更更新，工具调用需精准匹配当前生产批次的文档，避免调用过时的工艺参数。文档包含结构化的试验数据与非结构化的工艺说明，工具需同时支持结构化字段提取与网页内容读取。由于出错后果直接关联产品质量与安全，工具调用的结果需关联原始数据来源，便于溯源。同时，跨部门的文档关联需求要求工具可调用多个数据源的插件，实现绕组、绝缘、试验环节的数据联动。

## 配置怎么定
以下配置适配FastGPT v4.17.0版本：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 单次搜索上限 | 前6–10条 | 该品类的工艺与试验文档数量较多，限定返回数量避免上下文溢出 |
| 重排 | 开启 | 需将最匹配当前生产批次的工艺参数、试验数据排在检索结果前列 |
| `toolChoice` | auto | 自动适配结构化字段提取与非结构化网页内容读取的调用需求 |
| `functionCall` | 开启 | 强制模型调用工具提取绕组匝数、耐压值等结构化文档字段 |
| 最大上下文 | 8000–12000 token | 承载多组试验数据、工艺说明与批次信息的完整上下文 |
| 超时设置 | 300–600 秒 | 适配试验报告与大型工艺文档的加载时长，避免调用中断 |

## 容易做错的三处
- 现象：调用搜索插件后仅返回网页标题与摘要，无法读取完整网页内容。原因：未开启网页内容提取的插件配置，仅调用了基础搜索工具。
- 现象：在HTTP插件中调用第三方API返回502状态码，相同API在APIFOX中可正常调用。原因：未配置正确的请求头参数或超时设置，导致网关转发失败。
- 现象：工具配置中仅能看到少量可选模型，无法选择全量可用模型。原因：未在系统设置中配置对应的模型密钥与接入地址，导致模型列表未加载完整。

## 怎么确认配好了
- 发起一次绕组匝数查询的测试请求，确认返回结果中包含对应批次的工艺卡内容与原始数据链接。
- 配置HTTP插件调用内部试验数据API，发起测试请求并验证返回的502状态码是否消失，确认请求参数正确。
- 进入模型配置页面，确认所有已接入的模型均显示在工具调用的可选列表中。
- 确认`functionCall`配置已开启，发起包含结构化字段的查询，确认模型返回的结果中包含提取的字段值。
