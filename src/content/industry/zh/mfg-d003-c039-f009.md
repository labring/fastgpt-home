# 电机与发电机制造的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据来自电机厂、电力装备企业的绕线、绝缘、总装与试验部门的业务系统与设备，包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试记录、型式与出厂试验报告等文档。数据来源于电磁设计数据、铜线和绝缘材料批次信息、绕线设备、平衡机、电气试验台及ERP/MES系统，更新节奏为每台产品或每批物料生产完成时更新，每次产品型式变更后同步更新，文档包含设备参数、批次信息、试验数值等结构化与非结构化字段。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据多源分散，包含设备直采数据、ERP/MES业务数据与专业试验报告，要求模型接入配置支持多格式数据源的统一解析。高频更新节奏（每台/每批生产、每次型式变更）要求配置适配增量同步的触发逻辑与更新频率。文档包含绕组匝数、绝缘体系参数、振动测试数值等专业字段，需要配置适配电机制造专业术语的召回规则，同时需支持多文档间的关联检索，避免孤立召回导致的工艺与试验数据脱节。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配电机制造工艺文档与试验报告的长文本上下文需求，避免截断关键的绕组匝数、绝缘参数等核心信息 |
| `maxTokens` | 4000–6000 token | 限制单轮回答的输出长度，确保工艺步骤、试验结果等专业内容完整且不冗余，适配工程人员的阅读习惯 |
| `quoteMaxToken` | 1500–2000 token | 限定召回的参考文档总长度，优先保留绕组工艺卡、动平衡报告等核心文档片段，避免无关内容干扰回答 |
| `temperature` | 0.1–0.3 | 降低回答的随机性，确保工艺规程、技术标准的回答符合官方文档的严谨性，避免出现与电机制造规范不符的错误内容 |
| `AIPROXY_API_ENDPOINT` | 按部署的代理服务实际地址填写 | 适配多源模型接入的统一代理配置，便于统一管理电机制造场景下的模型调用权限与流量 |
| `AIPROXY_API_TOKEN` | 按代理服务生成的专属令牌填写 | 保障模型调用的安全性，避免未授权访问导致的敏感工艺数据泄露 |

## 容易做错的三处
-  现象：调用模型时返回404状态码，无法正常获取回答结果。原因：未正确填写`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`，或代理服务未对接适配电机制造场景的模型接口。
-  现象：召回的参考文档仅包含零散的试验数据，未关联对应的绕组工艺卡内容。原因：未配置支持多文档关联检索的规则，导致无法将同一批次产品的工艺与试验数据绑定。
-  现象：回答内容出现与电机制造规范不符的错误参数，如绝缘厚度取值偏差。原因：`temperature`配置值过高，导致模型生成的内容偏离官方工艺规程与技术标准。

## 怎么确认配好了
-  上传一份绕组工艺卡与动平衡报告，发起「该批次产品的绕组匝数是否符合工艺要求」的提问，核对召回的参考文档是否包含对应文档片段。
-  发起包含专业术语的提问，如「定子绕组的绝缘处理步骤」，核对回答内容是否匹配官方工艺规程的严谨表述，无明显错误。
-  查看模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置已被正确读取，无连接超时或权限报错。
-  发起多文档关联提问，如「结合绝缘处理记录与耐压试验报告，分析该产品的绝缘性能」，核对召回内容是否同时包含两类文档的相关片段。
