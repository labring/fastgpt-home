# 电池PACK与储能系统集成的工艺规程与技术标准问答：向量模型与索引

## 这个品类的数据长什么样
本品类的核心数据来自动力电池包、储能柜及BMS系统制造商的生产与测试环节，日常文档包含配组规则、BOM清单、焊接与扭矩记录、BMS刷写记录、绝缘耐压报告、EOL测试报告、系统配置清单。数据来源覆盖电芯分容数据、MES系统、焊接设备、扭矩工具、BMS软件版本及EOL试验台，更新频率为每生产一包或一台储能柜、每次BMS软件版本变更时新增或更新数据，单条文档包含具体工艺参数、测试数值与版本标识。

## 这些特征在「向量模型与索引」这一环带来什么约束
多源异构的数据来源导致文档格式差异较大，既有结构化的BOM与测试报告，也有非结构化的工艺规程文本，要求索引系统支持混合格式的嵌入与检索。高频更新的特性要求索引支持增量更新，避免每次全量扫描数十万条数据导致效率低下。文档中的专业参数如扭矩值、电芯分容档位、绝缘耐压数值，需要向量模型准确捕捉语义关联，同时更新频率高也意味着嵌入模型需适配快速生成的需求。此外，工艺问答的准确性直接影响生产安全，检索结果的精度需严格匹配业务场景的标准，避免召回无关的设备原始日志或错误配置信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配配组规则、焊接记录等文档的段落长度，避免将带专业单位的工艺参数拆分为多个分块 |
| 重叠长度 | 100–200 字符 | 保留跨分块的工艺关联信息，例如焊接步骤与后续扭矩校验的衔接内容 |
| 相似度阈值 | 0.75–0.85 | 过滤低匹配度的非工艺文档，避免召回无关的设备原始日志或测试冗余数据 |
| 单次搜索上限 | 前 10 条 | 控制返回结果的信息量，适配工艺问答的短上下文需求，避免超出模型处理能力 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| `defaultToken` | 用代表性工艺文档样本实测校准 | 这是直接文本切分使用的默认 token 数；请抽查样本文档的分块结果。它不表示向量维度或 LLM 上下文。参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx) |

## 容易做错的三处
- 搜索返回结果包含大量无关的设备原始日志，未匹配到目标工艺规程。原因是未设置合理的相似度阈值，将低匹配度的非标准文档纳入召回范围。
- 知识库索引完成后单次搜索耗时超过10秒，检索效率低下。原因是未启用增量索引模式，每次查询都全量扫描数十万条生产数据，导致响应缓慢。
- 嵌入后的文本丢失专业参数关联，例如电芯配组规则的前后档位信息被拆分。原因是分块长度设置过短，将跨段落的工艺逻辑拆分为独立分块，破坏语义完整性。

## 怎么确认配好了
- 随机抽取10条工艺关键词，例如「电芯配组规则」「焊接扭矩要求」，执行检索，核对返回结果的文档类型是否属于目标工艺文档。
- 查看索引任务的运行日志，确认增量更新仅处理了新增的电芯分容数据或BMS版本变更文件，未重复索引旧数据。
- 测试调整相似度阈值前后的召回结果，对比匹配度差异，确认阈值设置符合业务场景的精度需求。
- 按所选嵌入模型/服务输入上限核对`maxToken`，并抽查`defaultToken`产生的分块。检索文本和对话上下文应另按所选 LLM 文档中的限制预算。
