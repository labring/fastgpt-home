# 电池PACK与储能系统集成的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
该品类的核心数据来源于电芯分容设备、生产MES系统、焊接与扭矩工具、BMS软件版本库及EOL试验台。日常留存的文档包含电芯配组规则、BOM清单、焊接扭矩记录、BMS刷写日志、绝缘耐压报告、EOL测试报告与系统配置清单。数据更新频率为每生产一组电池包或储能柜同步一次，伴随BMS软件版本变更时同步更新。文档结构以标准化的工序记录、参数台账与测试报告为主，包含电芯型号、扭矩值、测试电压、软件版本号等明确字段。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散且绑定具体生产单元，要求模型接入时需支持多源数据的上下文关联；单组产品的文档量不大但更新频繁，需配置适配高频更新的上下文同步机制；文档包含大量带单位的工程参数，需模型具备精准的参数匹配与校验能力；EOL测试报告与BMS刷写记录属于强关联的工序数据，配置时需保证跨文档的检索关联性。工艺规程与技术标准问答需要准确匹配工序要求，因此模型的上下文窗口需适配单组产品的完整工序数据量。FastGPT v4.17.0版本的配置界面已支持上述场景的参数调整。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | `http://localhost:11434/v1`（本地部署）或厂商提供的API地址 | 适配本地ollama或第三方模型的接入路径，匹配品类常用的本地部署模型场景 |
| `AIPROXY_API_TOKEN` | 空字符串（本地ollama）或厂商分配的令牌 | 适配不同模型部署的认证要求，本地部署无需额外令牌 |
| `maxContext` | 8000–12000 token | 适配单组电池包的完整工序文档与关联测试数据量，避免截断关键参数 |
| `maxTokens` | 2000–3000 token | 保证单次问答的回复能覆盖完整的工艺步骤或参数校验结果 |
| `vision` | 开启 | 支持解析绝缘耐压报告、EOL测试报告中的图表数据 |
| `temperature` | 0.2–0.4 | 降低随机性，保证工艺参数与标准的匹配结果准确一致 |

## 容易做错的三处
- 现象：调用本地ollama部署的deepseek-r1模型时，回复内容中<think>标签内为空或无有效内容。原因：未正确配置`AIPROXY_API_ENDPOINT`指向ollama的v1接口路径，或未关闭模型的强制上下文截断设置。
- 现象：上传绝缘耐压报告、EOL测试报告等图片或PDF文件时，平台返回上传失败提示。原因：未开启`vision`配置项，或上传的文件格式未被FastGPT v4.17.0版本支持。
- 现象：发起需要工具调用的工艺问答时，模型未触发对应工具，仅返回文本回复。原因：未将`toolChoice`配置为auto，或本地部署的模型未正确开放工具调用能力。

## 怎么确认配好了
1. 发起一条针对特定型号电芯配组规则的问答，核对模型返回的结果是否与文档中的配组规则完全一致。
2. 上传一张绝缘耐压报告的图片，确认模型能正确识别报告中的测试数值与结论。
3. 发起需要调用工具的问答，如核对某规格电池包的扭矩要求，确认模型能触发对应工具并返回正确校验结果。
4. 查看FastGPT平台的模型接入日志，确认接口调用的状态码为200，无认证或超时错误。
