# 电镀与化学表面处理的工艺规程与技术标准问答：知识库检索与召回

## 这个品类的数据长什么样
本品类的主体为电镀厂、电子连接器与五金件表面处理车间，日常文档包含槽液分析记录、工艺参数卡、挂具记录、膜厚与附着力报告、危废台账、废水监测记录。数据来源涵盖客户表面处理规范、槽液化验结果、整流器运行数据、在线水质监测记录与危废管理台账，更新频率为每槽次、每班或按固定监测周期。文档多为结构化表格，字段包含槽号、槽温（℃）、电流密度（A/dm²）、金属离子浓度（g/L）、处理时间（min）等带明确单位的参数项。

## 这些特征在「知识库检索与召回」这一环带来什么约束
结构化表格占比高且带专属单位的文档特征，要求检索链路支持结构化数据匹配与单位识别，避免因单位不匹配导致召回失败。高频更新的数据要求召回链路支持增量同步，确保检索结果为最新的工艺参数与监测记录。多样的文档类型需要适配多格式导入与分块规则，保证完整的工艺信息不被拆分。严重的出错后果要求召回结果具备较高的置信度，需过滤低相关性的冗余数据，避免错误的工艺参数被调用。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本，针对电镀与化学表面处理的工艺数据特征定制：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 电镀工艺参数对阈值敏感度高，过低会引入无关槽液数据，过高会遗漏匹配的合格参数 |
| `limit` | `前6条` | 单工艺查询通常涉及多组关联参数（如槽温、电流、处理时间），6条结果可覆盖完整的工艺组合信息 |
| `searchMode` | `mixedRecall` | 兼顾结构化字段的关键词匹配与语义向量召回，适配工艺参数卡的结构化特征 |
| `usingReRank` | `开启` | 电镀工艺的参数组合关联性强，重排可过滤低相关性的槽液记录，提升召回准确性 |
| `datasetSearchUsingExtensionQuery` | `开启` | 可扩展用户查询的场景表述，例如将“挂镀电流”匹配为“挂具挂镀时的电流密度”，适配车间现场的口语化查询 |
| `collectionIds` | `绑定对应电镀车间的专属知识库集合` | 隔离不同车间的工艺数据，避免跨车间的参数混淆与错误召回 |

## 容易做错的三处
- 现象：表格数据无法被正确召回，返回空结果或无关文本。原因：未针对结构化表格开启多向量支持，未配置适配表格数据的索引模式。
- 现象：API调用返回字段为空或400状态码。原因：未正确指定`collectionIds`参数，或传入了不存在的知识库集合ID。
- 现象：分块后完整的工艺参数卡被拆分为不相关的片段。原因：未设置合理的最大段落深度与分块大小，导致跨参数组的错误拆分。

## 怎么确认配好了
- 上传一份真实的槽液分析记录表格，发起包含“槽液pH值”的查询，核对召回结果是否包含对应字段的数值内容。
- 调用知识库检索API，传入指定的`collectionIds`参数，核对返回结果是否仅包含绑定集合内的文档数据。
- 开启`usingReRank`后，对比开启前后的召回结果排序，确认高相关性的工艺参数记录排在前列。
- 发起包含口语化表述的查询，例如“挂镀时的电流密度”，核对是否能召回对应的工艺参数卡内容。
