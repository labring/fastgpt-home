# 石油炼制的工艺规程与技术标准问答：工具调用与插件

## 这个品类的数据长什么样
石油炼制场景的工艺规程与技术标准问答数据，涵盖操作规程、生产方案、物料平衡、馏出口质量报告、联锁台账、交接班记录、变更管理文件等日常文档。数据来源包括DCS/APC系统、LIMS实验室管理系统、罐区计量系统、原油评价数据库、设备管理系统与能源管理系统。数据更新节奏覆盖实时、每班、每日三个层级，文档包含馏程温度、物料流量、罐区液位、设备联锁值等带明确单位的字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源异构的数据来源要求工具调用需适配不同系统的接口格式，避免出现格式不兼容导致的调用失败。实时更新的DCS/APC数据要求工具调用具备低延迟能力，需设置合理的超时阈值以匹配数据返回节奏。每班、每日更新的台账类文档，需在工具调用时限定数据检索的时间范围，避免引入过期信息影响工艺判断。多套耦合装置的物料平衡数据，要求工具调用能关联多节点的日志与报表，需支持多参数联合查询。带明确单位的字段需工具在调用时自动匹配单位格式，防止计算或展示时出现单位混乱。

## 配置怎么定
以下配置项适配FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` | 允许模型自主选择适配炼油场景的工具，覆盖多源数据检索需求 |
| 单次工具调用返回条数 | 前3条 | 避免超出上下文窗口，同时覆盖核心工艺参数 |
| 工具调用超时时间 | 600秒 | 适配DCS/APC系统的实时数据查询延迟 |
| 上下文窗口保留时长 | 每班更新周期内 | 匹配交接班记录、联锁台账的每班更新节奏 |
| `functionCall`参数校验 | 开启单位匹配规则 | 适配炼油数据中馏程温度、罐区液位等带单位的字段 |
| 工具调用最大上下文长度 | 8000 token | 适配炼油场景多文档联合检索的需求 |

## 容易做错的三处
- 调用接口返回流数据后未按单位格式解析，导致展示的馏出口质量数据出现单位缺失或混乱。原因是未开启工具调用的字段单位匹配校验，直接使用原始接口返回的数值。
- 工具调用输出内容未过滤，直接展示在对话结果中，导致工艺人员无法快速获取核心问答结论。原因是未配置隐藏工具调用原始日志的开关，未设置仅输出AI整理后的结论。
- 未限定数据检索的时间范围，导致检索到过期的交接班记录或变更管理文件，影响工艺判断的准确性。原因是未绑定数据更新的时间维度参数，工具调用默认检索全量历史数据。

## 怎么确认配好了
- 发起包含原油评价参数的查询，核对工具调用返回的数据来源是否包含原油评价数据库，且字段带有正确的单位。
- 模拟工艺波动场景发起查询，检查工具调用的超时时间是否符合预设的600秒阈值，未出现超时报错。
- 发起多装置关联的物料平衡查询，确认工具调用返回的结果条数为前3条，未超出上下文窗口限制。
- 查看对话界面，确认仅展示AI整理后的工艺结论，未显示工具调用的原始请求与响应日志。
