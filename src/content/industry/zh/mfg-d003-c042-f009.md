# 石油炼制的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
石油炼制工艺规程与技术标准问答的核心文档包括操作规程、生产方案、物料平衡、馏出口质量报告、联锁台账、交接班记录、变更管理文件。数据来源覆盖DCS/APC、LIMS、罐区计量、原油评价、设备管理系统、能源系统，更新节奏涵盖实时、每班、每日。字段包含工艺温度、压力、流量、原油馏程、产品质量指标等，附带对应工程单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构且更新频率差异大的炼化数据，要求模型接入时适配实时、每班、每日的不同更新节奏，避免调用过期的工艺参数。文档包含多装置联动的复杂逻辑，要求上下文窗口足够容纳召回的多段文档片段，确保问答时覆盖完整工艺约束。炼化数据涉及生产安全与合规要求，模型调用需保障数据不泄露，因此配置需优先使用内部部署的模型端点。工艺参数的严谨性要求极高，模型生成内容需严格匹配现有规程，避免随意调整参数。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 石油炼制工艺文档包含多装置联动的复杂逻辑，需要足够上下文容纳召回的多段文档片段与用户问题 |
| `temperature` | 0.1–0.3 | 工艺规程问答需严格匹配现有标准，避免生成非规范的工艺参数，保障生产操作安全性 |
| `AIPROXY_API_ENDPOINT` | 企业内部部署的大模型API地址 | 炼化数据涉及生产安全与合规要求，使用内部端点可保障数据不泄露 |
| `AIPROXY_API_TOKEN` | 企业内部模型的专属访问令牌 | 限制非授权访问，保障模型调用安全 |
| `quoteMaxToken` | 1500–2000 token | 引用的工艺文档片段需完整覆盖关键操作要求，避免截断核心内容 |
| `maxTokens` | 2000–3000 token | 问答回复需包含具体工艺步骤与参数，不宜过长影响阅读 |

## 容易做错的三处
- 现象：点击模型测试提示请求错误，curl测试接口返回401或连接超时。原因：未正确配置`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`，或参数中包含多余空格、换行符。
- 现象：知识库查询到的内容未被大模型整理输出，回复仅返回空值或原始文档片段。原因：`maxContext`设置过小，无法容纳召回的文档片段与用户问题，导致模型无法完成上下文整合。
- 现象：生成的工艺建议参数与规程不符，出现明显偏差。原因：`temperature`设置过高，模型生成内容偏离现有标准，或未启用内部模型端点导致调用外部非合规模型。

- 发起涉及多装置联动的工艺问题，确认回复包含多段文档的关联逻辑，无上下文截断问题。
