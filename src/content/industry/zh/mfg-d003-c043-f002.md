# 精细化工间歇合成的工艺规程与技术标准问答：向量模型与索引

## 这个品类的数据长什么样
该品类典型主体为涂料、树脂、助剂、农化中间体和专用化学品企业，日常产生的文档包括批生产指令、投料复核单、反应过程记录、清场记录、检验报告、偏差与变更单。数据来源涵盖配方与工艺库、原料批次信息、反应釜DCS系统、称量系统、LIMS系统、仓储系统。数据更新频率为每批生产或每个关键工艺步骤一次，字段包含投料量、反应温度、批次号、清场验证结果等，单位多为千克、升、摄氏度。

## 这些特征在「向量模型与索引」这一环带来什么约束
由于该品类需按批次切换生产且数据按每批或关键步骤更新，向量索引需支持增量更新以适配高频小批量数据写入。日常文档多为单步骤或单批次的短文本，且包含专业工艺术语、单位明确的参数，向量模型需适配工业工艺类专业语义，需合理设置`defaultToken`与`maxToken`参数。同时，检索需关联批次号、工艺步骤等字段，索引需支持多维度过滤，避免跨批次或错误工艺步骤的结果干扰。此外，部分文档涉及配方保密内容，索引需严格控制访问权限，仅允许授权访问。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配该品类单批次工艺文档的平均长度，避免拆分关键工艺参数 |
| 重叠长度 | 100–150 字符 | 保留相邻工艺步骤的关联语义，防止分块切断投料顺序等连贯逻辑 |
| 相似度阈值 | 0.75–0.85 | 过滤低匹配度的非工艺类结果，适配专业术语的语义匹配精度 |
| `defaultToken` | 4096 token | 适配工艺问答的上下文长度需求，覆盖多步骤工艺的关联信息 |
| `maxToken` | 8192 token | 支持长文档的完整嵌入与检索，应对包含多环节的复杂工艺查询 |
| 单次搜索上限 | 前 5 条 | 控制返回结果的数量，避免冗余信息干扰工艺判断 |

本配置基于FastGPT v4.17.0版本的功能设计。

## 容易做错的三处
- 刷新页面后弹出“检测到没有可用的索引模型”报错，此前agent测试可正常回答。未将当前索引绑定至对应问答agent，或索引的向量模型配置未同步至生产环境。
- 通过API调用知识库检索时，返回结果的分块与界面设置不符。未在API请求中正确传递分块配置参数，或参数命名不符合FastGPT的接口要求。
- 升级FastGPT版本后，原有向量库数据无法被新索引识别，检索返回空结果。未执行向量库格式转换，新旧版本的向量嵌入维度或存储结构存在差异。

## 怎么确认配好了
- 查看索引管理页面的向量模型配置项，确认已选择适配工业工艺语义的模型，且配置与当前问答场景匹配。
- 发起一条模拟工艺查询，核对返回结果的分块长度、重叠长度与预设配置一致。
- 检查API调用日志，确认请求参数已正确传递，无参数缺失或格式错误。
- 验证增量更新功能，上传一条新的工艺文档，确认索引可自动同步新数据并返回对应检索结果。
