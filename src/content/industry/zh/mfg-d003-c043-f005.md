# 精细化工间歇合成的工艺规程与技术标准问答：工具调用与插件

## 这个品类的数据长什么样
该品类数据来自配方与工艺库、原料批次台账、反应釜DCS系统、称量记录系统、LIMS实验室信息管理系统及仓储系统。日常文档包含批生产指令、投料复核单、反应过程记录、清场记录、检验报告、偏差与变更单，每份文档绑定唯一批次号，字段包含投料量（单位kg、L）、反应温度（℃）、停留时间（小时）、清场验证编号等。数据更新频率为每批生产完成或每个关键工艺步骤执行后同步。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类多批次、多步骤切换的生产特征，要求工具调用需支持按批次号精准筛选分散在多系统的工艺数据，避免跨批次数据混淆。数据更新频率高且绑定唯一批次，工具调用需配置实时拉取逻辑，确保返回最新的投料、反应及清场记录。配方保密与交叉污染防控要求，插件需内置权限校验规则，仅允许调用授权范围内的工艺文档。该品类常用的工业反应釜多模态监控图片，需适配通用格式与分辨率限制，避免格式不兼容导致的调用报错。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 允许模型根据用户问题自动选择匹配的工艺数据工具，适配多场景提问 |
| `functionCall` | `strict: true` | 强制模型按照预设的工具参数格式返回调用指令，减少无效或格式错误的调用请求 |
| 多数据源对接超时阈值 | `300 秒` | 工业现场系统响应存在一定延迟，该阈值可平衡调用成功率与流程阻塞风险 |
| 批次数据筛选规则 | 按生产批次号精准匹配 | 该品类工艺数据按批次组织，精准匹配可避免跨批次的无效数据混入问答结果 |
| 多模态图片调用格式限制 | JPEG/PNG，分辨率不超过 2048×2048 像素 | 适配工业反应釜监控图片的通用格式与分辨率，减少invalid image类报错 |
| 单次工具调用返回数据条数 | 前 10 条 | 该品类单批次工艺文档字段较多，限制条数可避免上下文溢出影响问答效果 |

## 容易做错的三处
- 调用多模态工艺监控图片时返回400 invalid image报错。原因是未配置适配工业场景的图片格式与分辨率限制，上传的图片不符合调用要求。
- 配置数据链接工具的SQL语句后无法正常返回数据。原因是未遵循该品类按批次号筛选的字段规则，SQL语句未绑定唯一批次参数，导致返回数据与当前问答不匹配。
- 非工具调用模式下未引用预设的网络搜索节点内容。原因是未开启工具调用的强制触发配置，模型未被要求调用搜索插件补充工艺标准数据。

## 怎么确认配好了
- 提交包含特定生产批次号与工艺监控图片的测试问题，检查工具调用是否返回对应批次的投料、反应记录及图片解析结果。
- 编写符合批次筛选规则的SQL语句，测试数据链接工具是否能返回准确的单批次工艺数据。
- 切换至非工具调用模式，提交需引用公开工艺标准的问题，检查模型是否未主动调用搜索节点。
- 确认当前使用的FastGPT版本为v4.17.0，确保配置项兼容系统要求。
- 检查插件权限规则是否已生效，仅授权用户可调用敏感工艺数据工具。
