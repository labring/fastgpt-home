# 精细化工间歇合成的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源于配方与工艺库、原料批次台账、反应釜DCS系统、称量记录系统、LIMS实验室管理系统及仓储系统。文档包含批生产指令、投料复核单、反应过程记录、清场记录、检验报告、偏差与变更单。数据按每批生产或每个关键工艺步骤更新，单份文档包含投料量、反应温度、压力、批次号、清场验证编号等带明确单位的字段，且涉及配方保密内容，数据结构随产品品类调整。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据按每批或关键工艺步骤更新，且结构随产品品类调整，同时包含带明确单位的工艺参数与敏感配方内容。这要求模型接入配置需适配动态变化的文档字段，准确识别带单位的工艺参数，避免参数匹配错误。高频短周期的更新节奏，要求配置适配短间隔的索引更新逻辑，避免索引延迟影响问答时效性。敏感配方内容则要求配置时严格限制模型的外部数据调用范围，防止信息泄露。

## 配置怎么定
本配置基于FastGPT v4.17.0版本制定，具体参数与建议如下：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单批次工艺文档的总长度，避免上下文溢出导致问答中断 |
| `maxTokens` | 2000–3000 token | 满足工艺问答的详细回复需求，覆盖多步骤复核的信息输出 |
| `quoteMaxToken` | 1500–2000 token | 匹配单份工艺文档的核心片段长度，确保引用内容完整且符合文档规范 |
| `temperature` | 0.1–0.3 | 降低随机输出，保证工艺参数与标准的一致性，避免工艺步骤描述偏差 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写内网或映射后的访问地址 | 适配内网部署的场景，确保模型调用链路稳定，适配精细化工企业的网络安全要求 |
| `AIPROXY_API_TOKEN` | 由模型服务商提供的有效令牌 | 完成模型接入的身份验证，确保调用权限合法，防止未授权访问 |

## 容易做错的三处
- 上传3MB的工艺文档PDF后触发报错，界面显示模型调用失败。原因是未正确配置`AIPROXY_API_TOKEN`，令牌无效导致模型服务无法完成请求验证。
- 知识库索引进度持续停滞，docker部署环境下接入通用大模型时尤为明显。原因是未适配该品类按批次更新的数据节奏，索引触发逻辑未匹配短周期更新需求，导致重复扫描旧数据。
- 配置模型时提示接入点错误。原因是`AIPROXY_API_ENDPOINT`填写的地址未包含正确的API路径后缀，与模型服务商的接口规范不匹配。

## 怎么确认配好了
- 上传单份典型工艺文档，触发模型问答请求，检查返回结果是否包含文档内的带单位工艺参数。
- 查看知识库索引日志，确认在数据更新后，索引任务能在预设周期内完成构建。
- 测试内网映射后的模型访问链路，确认FastGPT能正常调用模型接口并返回有效回复。
- 验证敏感配方相关的问答请求，确认模型未返回未授权的配方细节。
