# 纸浆造纸的工艺规程与技术标准问答：引用来源与溯源

## 这个品类的数据长什么样
纸浆造纸的工艺与质量数据来源包括木浆废纸批次档案、DCS/QCS系统、纸机在线测量设备、实验室检测报告、能源与水处理系统记录。数据更新节奏覆盖实时（在线质量曲线）、每班（打浆与配浆记录）、每卷（断纸与换品记录）。日常文档包含配浆单、打浆台账、纸机运行日志、在线质量曲线、实验室化验报告、断纸台账，字段包含浆料配比、打浆度、纸幅克重、水分含量等，对应单位为%、°SR、g/㎡、%等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
纸浆造纸的多维度、分时段更新的数据特征，要求溯源环节必须匹配数据的时效性与场景关联性。实时在线质量曲线需优先召回最新采集的内容，每班/每卷的文档需关联对应生产批次，避免跨批次数据混淆。多类型文档（表格类质量曲线、文本类运行日志）的格式差异，要求溯源模块适配不同结构的内容召回与展示。工艺调整依赖精准的参数匹配，溯源需保留字段的原始单位，防止因单位不一致导致的工艺判断错误。高速连续生产的特性，要求关联文档的召回需覆盖从备料到成品的全流程数据，避免单一文档的片面性。

## 配置怎么定
本配置适用于FastGPT v4.17.0。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 单次搜索上限 | 前3-5条 | 纸浆造纸的核心工艺文档集中在配浆、打浆、质量检测三类，过多召回会超出上下文承载限制 |
| `quoteMaxToken` | 1200-1800 token | 单份打浆记录或在线质量曲线的文本长度通常在该区间，需完整引用以支撑参数核对 |
| 最大上下文 | 4000-6000 字符 | 需容纳配浆单、打浆记录、质量报告等多份关联文档的完整内容，覆盖工艺问答的上下文需求 |
| `responseData` | 开启文档元数据返回 | 需标注溯源文档的生产批次、采集时间，匹配纸浆造纸数据的分批次更新节奏 |
| `detail` | 开启完整内容溯源 | 工艺问答需核对具体参数如打浆度°SR、克重g/㎡，仅文档标题不足以支撑准确判断 |
| 重排 | 按时间倒序 | 纸浆造纸的工艺调整依赖最新的运行记录与断纸台账，最新数据优先级更高 |

## 容易做错的三处
- 测试环节提示配置错误，强行忽略后可正常运行。原因：未正确绑定对应纸浆造纸的知识库分组，测试时未加载预设的配浆单、运行记录数据集。
- 问答仅返回1条引用文档，提示知识库引用(1条)。原因：单次搜索上限配置过低，未覆盖配浆、打浆、质量检测的关联文档集合。
- 调用时知识库选项为空，无法直接选定预设数据集。原因：未开启知识库的自动加载配置，需手动指定数据源分组。

## 怎么确认配好了
- 发起工艺调整类提问，核对返回结果中引用的文档是否包含当前生产批次的配浆单、打浆记录。
- 查看引用溯源模块，确认每条引用都标注了文档来源、采集时间与对应参数单位。
- 模拟断纸场景提问，验证是否召回了同批次的断纸与换品记录。
- 调整提问关键词，确认可召回多份关联文档，引用条数符合预设配置。
