# 纺纱与织造的工艺规程与技术标准问答：工作流编排

## 这个品类的数据长什么样
该品类数据主要来自棉纺、化纤纺、机织与针织企业的日常业务文档与设备采集内容。日常文档包含配棉或配料单、工艺上机单、设备运转记录、纱线检验单、坯布检验单、布面疵点记录。数据来源覆盖原纤维检验报告、ERP系统、纺机与织机实时数据、条干仪检测结果、验布机采集数据、订单规格参数。数据更新随每批原料、每班作业、每匹布产出同步调整。

## 这些特征在「工作流编排」这一环带来什么约束
由于数据随每批原料、每班、每匹布更新，工作流需支持按批次关联对应文档，避免跨批次数据混淆。设备采集的条干、疵点数据为结构化数值，需在工作流中配置字段映射规则，将原始设备数据匹配至工艺问答的标准字段。配棉配料单、工艺上机单存在批次级的专用参数，工作流需支持变量绑定对应批次的文档片段。多设备多批次的数据量较大，工作流需限制单次召回的文档范围，避免上下文过载影响问答准确性。不同工序的工艺参数单位存在差异，比如捻度用捻/米、组织参数用经纱密度/纬纱密度，工作流需统一参数单位转换逻辑，确保问答输出的参数符合生产要求。

## 配置怎么定
本配置项适配FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 绑定当前作业批次的配棉单、工艺上机单子集 | 纺纱织造数据按批次更新，需限定变量匹配范围避免跨批次数据干扰 |
| 问题分类节点模型 | 使用初始化的通用工艺分类模型 | 默认模型适配该品类工艺问题的分类逻辑，切换模型需重新校准 |
| AI对话组件回复触发时机 | 等待stream回复完毕后执行后续动作 | 工艺问答需完整返回参数后再触发注释或存储逻辑 |
| 知识库选择范围 | 仅勾选纺纱织造工艺库、设备运转记录库 | 该品类专属数据仅分布在两类文档中，无需调用全量知识库 |
| 单次搜索上限 | 前8条 | 该品类单批次文档量适中，8条可覆盖核心工艺参数与疵点记录 |
| `nodeId` | 绑定问题分类节点的唯一标识 | 需精准关联后续AI对话节点的输入源，避免节点混淆 |

## 容易做错的三处
- 现象：配置`variables`时无可选变量值，无法绑定对应批次的工艺文档。原因：未先创建文档分片节点输出批次关联变量，或未在工作流中配置变量来源的数据源映射。
- 现象：问题分类节点的模型选项为空，无法选择可用模型。原因：未在平台全局配置中添加可用AI模型，或未为当前工作流开启模型权限。
- 现象：使用初始化AI模型的问题分类节点运行时报错，切换模型后恢复正常。原因：初始化模型未完成默认分类规则的校准，首次运行时缺少分类阈值的预设配置。

## 怎么确认配好了
- 手动触发工作流，输入纺纱或织造工艺相关问题，检查返回结果是否仅包含当前作业批次的工艺文档内容。
- 运行问题分类节点，确认模型选项正常显示，分类结果符合工艺问题的类别划分。
- 触发AI对话组件的回复流程，等待回复完毕后检查注释逻辑是否正常触发。
- 检查`variables`的绑定配置，确认可选变量列表包含当前批次的配棉单、工艺上机单等文档。
