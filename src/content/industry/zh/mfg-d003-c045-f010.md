# 纺纱与织造的工艺规程与技术标准问答：知识库检索与召回

## 这个品类的数据长什么样
典型主体为棉纺、化纤纺、机织和针织企业，日常文档通常包含配棉单、工艺上机单、设备运转记录、纱线检验记录、坯布检验记录、疵点记录。数据来源涵盖原纤维检验报告、ERP系统、纺机与织机实时数据、条干仪检测结果、验布机输出数据。数据更新频率随生产节奏变动，每批原料、每班生产、每匹布完成后均会生成新的文档或更新原有记录。文档字段包含纤维类型、上机张力参数、纱支规格、捻度数值、经密密度、疵点类型等，部分字段带有专业单位，如捻度单位为捻每米，经密单位为根每厘米。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据结构要求检索召回环节同时适配结构化的ERP参数文档与非结构化的检验、记录类文本，避免单一检索模式的局限性。高频更新的生产数据要求召回结果优先返回最新批次的文档，避免使用过时的配棉或工艺参数。专业字段的存在要求检索匹配需聚焦纺织行业专属术语，减少泛化召回的无关内容。不同文档的业务场景差异明显，配棉单与疵点处理文档的检索需求不同，需按业务模块划分召回范围，避免跨场景的无效结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.80 | 匹配纺纱织造的专业术语精度，避免召回无关的疵点记录或设备参数 |
| `limit` | 前8条 | 覆盖单批原料对应的多份工艺文档，同时控制上下文长度符合FastGPT v4.17.0版本的上下文限制 |
| `searchMode` | 语义检索+关键词混合 | 适配结构化的ERP数据和非结构化的检验记录，兼顾参数匹配与文本语义理解 |
| `usingReRank` | 开启 | 过滤召回结果中的低相关疵点描述，提升精准度，适配疵点处理类问答场景 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展配棉、捻度等专业术语的同义词，提升专业场景下的召回覆盖范围 |
| `collectionIds` | 按业务模块划分的集合ID | 区分配棉文档、工艺上机文档、检验记录集合，避免跨模块的无效召回 |

## 容易做错的三处
- 现象：开启`usingReRank`后检索结果为空。原因：将`similarity`阈值设置过高，导致初始召回的候选集不足，重排后无有效结果。
- 现象：检索结果仅包含单类文档，无法覆盖全流程工艺需求。原因：未配置`collectionIds`参数，未按业务模块划分召回范围，仅召回了默认集合的文档。
- 现象：检索结果包含过时的工艺参数。原因：未启用按更新时间排序的召回规则，未优先返回最新批次的生产文档。

## 怎么确认配好了
- 输入“配棉单的纤维搭配要求”，检查召回结果包含配棉相关文档，且优先返回近7天更新的内容。
- 开启`usingReRank`后，输入“纱线强力不合格的处理方法”，确认召回结果中无无关的染整工艺文档。
- 调整`similarity`阈值，验证当阈值降低时召回结果增多，阈值升高时结果更精准。
- 查看检索日志，确认`searchMode`为语义检索+关键词混合模式，同时匹配参数关键词与文本语义。
