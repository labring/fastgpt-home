# 计量器具与实验室管理的工艺规程与技术标准问答：向量模型与索引

## 这个品类的数据长什么样
本品类数据覆盖企业计量室、CNAS认证实验室等主体的日常业务文档，包括量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账、偏离处置单。数据来源涵盖企业计量管理系统、LIMS系统、外部校准机构证书、标准器参数及环境监测数据，更新节奏随校准周期、单次试验完成或异常情况触发。文档字段包含器具唯一标识、校准有效期、测量数值、溯源标准器编号、不确定度参数等，单位随测量类型匹配。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类的数据来源分散且更新无固定批量，要求索引支持多源数据的增量同步与实时接入；文档包含校准证书、试验原始记录等带精确测量参数的内容，分块操作不能破坏单份文档的逻辑完整性，需避免拆分表头与测量结果。同时，数据需保留溯源链相关的元数据，索引需支持字段级关联召回，确保查询时能关联到器具的全周期校准记录。此外，部分文档存在长文本结构，索引需适配较长的单份文档内容，避免截断关键溯源信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配校准证书、试验记录的单页内容长度，避免拆分关键测量信息 |
| 重叠长度 | 100–150 字符 | 保留分块间的溯源关联字段，防止截断校准周期等关键内容 |
| 相似度阈值 | 0.75–0.85 | 匹配计量参数的精确性要求，过滤低相关性的非测量类文档 |
| 单次搜索上限 | 前8条 | 覆盖单次查询所需的关联校准记录与溯源链信息 |
| `defaultToken` | 4096 | 适配标准校准证书的长文本内容，保证完整召回元数据 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |

## 容易做错的三处
- 本地部署时无法自动索引文档中的图片：原因是未开启FastGPT v4.17.0的图片OCR解析开关，且未配置本地OCR插件支持计量证书内的校准图表识别。
- Embedding模型无法连接OneAPI，返回连接超时报错：原因是本地部署环境未正确配置OneAPI的接口地址与访问密钥，或网络策略限制了模型调用的出站请求。
- 开启Rerank模型后在线召回测试无生效结果：原因是未在知识库索引配置中同步开启重排功能，或重排模型的调用参数与索引分块设置不匹配。

## 怎么确认配好了
- 上传一份标准校准证书样本，检查索引生成的分块内容，确认未拆分证书的表头与测量结果部分。
- 发起包含「校准有效期」的查询，验证召回结果包含关联的量具台账与校准计划文档。
- 查看FastGPT的索引日志，确认Embedding模型调用成功且无报错信息。
- 开启重排功能后，对比开启前后的召回结果排序，确认高相关的校准结果优先级得到提升。
