# 计量器具与实验室管理的工艺规程与技术标准问答：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自企业计量室、CNAS体系实验室的日常文档，包含量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账、偏离处置文件。数据来源涵盖计量管理系统、外部校准机构证书、标准器、LIMS系统、环境监测设备。更新节奏随校准周期、单次试验结果、异常事件触发。文档字段包含器具编号、精度等级、校准有效期、测量值、不确定度、溯源编号等，部分文档附带物理单位，如毫米、毫克、帕斯卡等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源要求检索系统支持跨系统文档的统一字段映射，避免因格式差异导致召回失败。非固定的更新节奏需要检索模块支持增量同步，按校准周期、异常事件触发更新，保障召回数据的时效性。带精度、不确定度的结构化字段，要求检索需兼顾语义匹配与关键词精准匹配，避免遗漏关键参数。溯源链关联需求则要求召回结果可关联到对应量具的台账、校准证书、试验记录等全链路文档，仅召回单条记录无法满足溯源需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 校准证书、溯源记录等需要高精准匹配的文档，阈值过低会引入无关的计量数据，过高会遗漏有效关联项 |
| `limit` | 前8条 | 兼顾单条校准证书的细节与关联的期间核查、试验记录，避免上下文过长超出模型处理上限 |
| `searchMode` | semantic+keyword | 兼顾语义匹配工艺规程与关键词匹配量具编号、校准日期等结构化字段，提升检索精准度 |
| `usingReRank` | 开启 | 对召回的条目按相关性重新排序，解决语义召回可能混杂低关联的器具台账问题 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展计量术语的同义表达，如将“校准有效期”扩展为“有效期截止日期、校准到期时间”，适配不同提问方式 |
| `collectionIds` | `["metrology_001", "lims_002"]` | 限定检索范围仅覆盖计量器具与实验室管理类知识库，避免混入其他品类的无关文档 |

## 容易做错的三处
- 现象为API调用嵌套知识库助手的工作流时返回空值，原因是未正确配置`collectionIds`限定检索范围，或`similarity`阈值设置过高，未召回有效文档。
- 现象为知识库变量引用时触发`quote type error`报错，原因是传入的参数格式不符合要求，未遵循`limit`、`similarity`等配置项的规范传递方式。
- 现象为输出结果无法隐藏知识库引用片段，原因是未在工作流输出配置中关闭引用展示选项，或未正确过滤检索结果的引用字段。

## 怎么确认配好了
- 检查FastGPT v4.17.0版本工作流配置中`collectionIds`是否仅包含计量器具与实验室管理类知识库的ID列表，确保检索范围正确。
- 提交测试问题，如“外径千分尺的校准流程与不确定度要求”，核对召回结果是否包含校准计划、校准证书、期间核查记录等对应文档。
- 验证知识库变量引用时无格式报错，确认传入的参数符合`similarity`、`limit`等配置项的格式要求。
- 测试关闭引用展示功能，确认最终输出结果不包含知识库引用的来源片段。
