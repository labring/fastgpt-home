# 设备点检与预防维修的工艺规程与技术标准问答：部署与升级
本文适配FastGPT v4.17.0版本，针对制造领域设备点检与预防维修的工艺规程与技术标准问答场景的部署与升级环节提供配置指引。

## 这个品类的数据长什么样
该品类的数据涵盖制造企业设备部、维修班组及公用工程部门的生产资产相关文档，包括设备台账、点检表、保养计划、维修工单、故障分析、备件清单及特种设备检验记录。数据来源包括EAM/CMMS系统、设备传感数据、操作员点检记录、维修历史、备件库存信息与法定检验文件。更新节奏覆盖每班、日/周/月周期及故障发生时的即时更新，文档包含设备编号、点检点位、标准参数、故障现象等固定字段与对应单位。

## 这些特征在「部署与升级」这一环带来什么约束
该品类多源异构的数据来源要求部署时配置多系统对接适配，避免数据同步中断影响问答时效性。高频更新节奏需要匹配向量数据库的增量刷新参数，确保点检、故障数据能及时纳入检索范围。多样的文档类型需要预设格式解析规则，适配设备台账的结构化字段与检验记录的非结构化文本。法定检验相关文档的合规性要求，需在部署时开启数据溯源存储，保留完整版本记录。维修工单的实时性需求，需调整实时检索的索引优先级，避免非核心数据占用过多系统资源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | 连接EAM/CMMS同步库的专属URI，配置读写权限隔离 | 该品类数据需从多业务系统同步，专属URI避免权限冲突 |
| `REDIS_URL` | 配置为本地部署的Redis实例，设置`300 秒`连接超时 | 高频更新的点检与故障数据需缓存检索结果，超时适配实时性要求 |
| `FE_DOMAIN` | 填写企业内网访问域名，绑定车间终端的访问IP段 | 限制访问范围，符合制造企业内网部署的安全要求 |
| `DB_MAX_LINK` | 设置为`20–30`条并发连接 | 匹配设备台账、维修工单等多文档的批量同步需求 |
| `FILE_TOKEN_KEY` | 生成`32 位`随机密钥，设置文件访问有效期`7 天` | 保护备件清单、检验记录等敏感文档的访问权限 |
| `STORAGE_S3_ENDPOINT` | 填写企业自建对象存储的内网端点 | 存储大体积文档，避免公网传输延迟 |

## 容易做错的三处
- 部署后访问前端出现`{"code":500,"statusText":"","message":"URI malformed"}`报错，原因是`MONGODB_URI`或`REDIS_URL`配置的连接字符串包含非法字符或未正确转义特殊符号。
- 容器启动后无法访问前端页面，原因是`FE_DOMAIN`配置的域名未绑定内网DNS，或容器端口映射未开放对应内网端口。
- 未按设备文档的更新节奏配置数据同步任务，导致检索结果滞后于实际点检、维修状态，原因是未将同步周期与每班、日更的更新频率匹配。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`MONGODB_URI`与`REDIS_URL`的连接有效性，确认无连接超时或权限拒绝报错。
- 上传一份设备点检表样本，检查格式解析是否能提取点检点位、标准值等核心字段，验证文档预处理配置生效。
- 查看向量数据库的索引更新日志，确认近24小时内的维修工单、故障分析数据已完成增量同步。
- 访问内网绑定的`FE_DOMAIN`，确认能正常加载问答界面并触发检索请求，验证前端部署配置正确。
