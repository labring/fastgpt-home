# 通用机械设备装配的工艺规程与技术标准问答：向量模型与索引

## 这个品类的数据长什么样
通用机械设备装配品类的核心主体为泵、阀、压缩机、减速机、机床及非标设备制造商。日常文档包含装配工艺卡、BOM、扭矩记录、间隙调整记录、试运行报告、出厂检验单、装箱清单。数据主要来自PLM/ERP系统、零件检验数据、装配工具采集设备、试验台、MES系统及客户技术协议，更新频率为每台设备或每订单一次。文档字段包含工序号、扭矩值（单位N·m）、间隙值（单位mm）、物料编码、温升（单位℃）等结构化与半结构化内容。

## 这些特征在「向量模型与索引」这一环带来什么约束
多源异构的数据来源要求索引系统支持混合格式文档的统一处理，避免因格式差异导致的向量生成偏差。高频小批量的更新节奏需要适配增量索引机制，确保单台设备的装配文档可快速完成索引同步。文档中包含大量带精确单位的工艺参数，要求向量模型兼顾语义关联与数值匹配精度，防止因单位缺失导致检索错误。多层级BOM与工序文档的结构特征，需要索引保留节点间的层级关联，避免检索时丢失跨工序的上下文信息，同时需合理设置`maxToken`以容纳长文档上下文。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配装配工艺卡、BOM等文档的单段语义完整性，避免拆分破坏工序或参数关联 |
| 重叠长度 | 50–80 字符 | 保留相邻块的工序衔接信息，防止跨块检索时丢失步骤关联 |
| 相似度阈值 | 0.72–0.85 | 适配工艺参数的精确匹配需求，过滤低相关性的非标准文档片段 |
| 单次搜索上限 | 前 8 条 | 覆盖多工序装配的完整步骤，避免遗漏关键调整环节 |
| `maxToken` | 4000–6000 token | 容纳多层BOM和完整工艺规程的上下文，支持长文档的完整检索匹配 |
| `defaultToken` | 2000 token | 适配单段工艺文档的基础上下文长度，保障基础语义召回 |

## 容易做错的三处
- 点击启用豆包Doubao-embedding-large索引模型，填写自定义请求地址和apikey后测试直接报错。原因是未正确配置向量模型的请求头参数，或自定义地址未指向合规的向量服务端点。
- 知识库中表格数据未开启多向量支持，导致扭矩、间隙等数值字段无法被正确检索。原因是未针对结构化表格数据启用多向量拆分配置，仅对整体文本块生成向量。
- 单次搜索上限设置过低，导致检索结果仅返回前3条，无法覆盖完整装配工序的所有环节。原因是未结合该品类多工序、多参数的业务特征调整搜索上限阈值。

## 怎么确认配好了
- 进入FastGPT v4.17.0的知识库向量模型配置页，确认已选择Doubao-embedding-large模型并填写正确的自定义请求地址与apikey，执行测试连接无报错。
- 上传一份包含BOM表格和装配工艺卡的测试文档，查看分块预览结果，确认相邻块存在重叠字符，工序未被强制拆分。
- 发起工艺参数检索测试，输入“减速机装配扭矩要求”，确认返回结果包含正确的扭矩数值与对应工序，结果条数符合配置的单次搜索上限。
- 提交一份测试装配文档，查看索引队列状态显示为已完成，确认增量索引更新正常。
