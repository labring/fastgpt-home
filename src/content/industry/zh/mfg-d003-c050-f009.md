# 通用机械设备装配的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
通用机械设备装配的日常文档包含装配工艺卡、BOM、扭矩记录、间隙调整记录、试运行报告、出厂检验单、装箱清单等，数据来源涵盖PLM/ERP系统、零件检验数据、装配工具采集终端、试验台、MES系统及客户技术协议。数据更新随单台设备或订单完成节奏变动，字段包含带单位的量化参数，如扭矩值（牛米）、间隙（毫米）、同轴度（微米）等，不同订单的文档结构与字段存在差异。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源分散的数据来源要求配置支持跨系统的数据关联与统一解析；随单台设备变动的更新节奏，要求上下文窗口适配单批次文档规模，避免加载冗余或不相关数据；带单位的结构化字段与多样的文档类型，要求配置保留原始字段格式，保证参数问答的准确性；装配环节对实时性有明确要求，要求配置合理的响应阈值，避免影响现场调试进度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配单台设备的装配工艺卡、BOM、检验记录等关联文档总长度，避免上下文溢出导致问答中断 |
| `temperature` | 0.1–0.3 | 工艺与标准问答需严谨，降低随机性以保证答案匹配技术文档的固定内容 |
| `quoteMaxToken` | 1500 token | 保留足够长度的原始文档片段，用于验证工艺步骤、参数的合规性与准确性 |
| `AIPROXY_API_ENDPOINT` | 按部署的大模型服务地址填写 | 对接本地或线上大模型的接入地址，适配不同部署场景的需求 |
| `AIPROXY_API_TOKEN` | 由部署平台生成的专属令牌 | 完成接口鉴权，保障数据调用的安全性 |
| `toolChoice` | none | 该场景以文本问答为主，无需调用工具，避免引入不必要的逻辑分支 |

## 容易做错的三处
- 现象：调用本地大模型时返回参数不匹配报错，状态码400。原因：未区分本地大模型与线上API的参数格式，直接复用线上调用的配置逻辑。
- 现象：上传包含扭矩、间隙参数的装配文档后，模型无法准确提取量化数值。原因：未设置合理的`maxContext`参数，导致文档关键片段被截断，丢失参数信息。
- 现象：问答结果中出现无关的零件加工内容。原因：未限制上下文范围，引入了非装配场景的文档数据，导致模型生成偏离主题的回答。

## 怎么确认配好了
- 上传单台设备的完整装配文档，验证模型能准确返回装配步骤的参数要求，如指定扭矩值、间隙调整范围。
- 调用测试接口，传入模拟的工艺问题，检查返回结果是否包含原始文档的引用片段，确认数据关联正常。
- 查看FastGPT v4.17.0的接口调用日志，确认鉴权令牌与API地址配置正确，无401或403类鉴权报错。
- 调整`temperature`参数后，验证同一问题的回答结果无明显随机变化，符合工艺问答的严谨性要求。
