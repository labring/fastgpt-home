# 通用机械设备装配的工艺规程与技术标准问答：部署与升级

## 这个品类的数据长什么样
通用机械设备装配场景的业务数据主要来自PLM、ERP、MES系统，以及装配工具采集的扭矩记录、间隙调整记录，还有出厂检验单、装箱清单等。日常文档包含装配工艺卡、多层级BOM、试运行报告等，字段含部件编号、扭矩值、同轴度参数、间隙公差等，单位多为毫米、牛米、转每分钟。数据更新随每台设备装配、每个订单交付同步进行，单次更新覆盖单台设备的全流程装配记录。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的多源混合、按单更新的业务特征，对部署与升级环节带来多重约束。多源格式的文档需要部署时配置兼容结构化BOM、扭矩记录与非结构化工艺卡的接入规则；按台/订单的高频更新要求升级时需支持增量同步且不中断现有问答服务；专业字段的固定单位要求配置时保留原始字段映射，避免单位转换导致检索偏差；同时需预留校验接口，确保核心工艺参数检索结果匹配现场装配要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `50–80` | 适配单台设备装配产生的单订单数据量，避免连接池耗尽 |
| `MONGODB_URI` | 指向PLM同步后的工艺文档数据库 | 存储装配工艺卡、试运行报告等非结构化业务文档 |
| `PG_URL` | 指向结构化参数存储库 | 存储扭矩记录、间隙调整记录等带单位的结构化数据 |
| `REDIS_URL` | 配置为本地缓存节点 | 加速高频检索的工艺参数查询，降低数据库压力 |
| `ROOT_KEY` | 按部署环境生成随机字符串 | 保障后台配置的访问权限安全，符合企业内部部署规范 |
| `FE_DOMAIN` | 配置为企业内部访问域名 | 适配内部工程师的访问路径，避免跨域访问问题 |

## 容易做错的三处
- 现象：升级到FastGPT v4.17.0新版本后，知识库检索可返回结果，但模型无法输出最终内容。原因：未配置`REDIS_URL`的缓存过期时间，导致检索结果在模型调用前被清空。
- 现象：Docker部署后，3000端口页面无法访问，3001端口可正常打开。原因：部署脚本未正确映射前端服务的3000端口，或防火墙规则限制了3000端口的外部访问。
- 现象：修改Docker容器内的FastGPT配置文件后，OpenAI密钥或root密码未生效。原因：未重启容器加载新配置，或修改的配置文件路径与容器内挂载路径不一致。

## 怎么确认配好了
- 执行数据库连接测试，验证`MONGODB_URI`与`PG_URL`指向的存储库可正常读写装配相关文档。
- 发起单台设备的工艺规程检索请求，确认返回结果包含对应BOM、扭矩记录等核心字段。
- 重启部署服务后，检查前端页面可正常加载，且`FE_DOMAIN`配置的访问路径无跨域报错。
- 触发增量同步任务，验证新上传的装配记录可被检索系统正常识别。
