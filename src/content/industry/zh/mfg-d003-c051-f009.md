# 金属切削加工的工艺规程与技术标准问答：模型接入与配置
FastGPT v4.17.0

## 这个品类的数据长什么样
金属切削加工的业务数据来源包括产品图纸与三维模型、CAPP/CAM系统、机床采集终端、刀具管理系统、MES系统及量检具数据。日常业务文档包含工艺路线、工序卡、刀具清单、数控程序、首件检验记录、巡检表、量具校准记录。数据更新随工单执行、单件加工、抽检环节或刀具更换触发，文档字段涵盖切削参数、尺寸公差、刀具寿命、装夹基准等，单位包含转速、进给量、表面粗糙度参数等。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据来源分散且关联工单、刀具、加工环节等多维度，接入时需确保多源数据的上下文关联逻辑匹配生产流程。高频更新的工单与刀具数据要求配置支持按工单、刀具更换等事件触发的同步规则，避免知识库与生产实际脱节。文档类型多样，包含数控程序代码、公差数值、工艺参数等结构化与半结构化内容，配置时需适配不同文档的解析规则，确保关键字段被准确提取。数据关联的工艺环节直接影响问答准确性，需约束模型调用时的上下文范围，避免无关数据干扰输出。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配工艺文档的多段关联内容，覆盖工序卡、数控程序、刀具清单的关联信息，避免截断关键工艺参数 |
| `maxTokens` | 2000–3000 token | 覆盖完整工艺规程的问答输出需求，确保装夹方案、切削步骤等关键内容完整输出 |
| `temperature` | 0.1–0.3 | 确保工艺参数、公差数值等结构化内容的输出准确性，减少无关发散内容 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 匹配FastGPT的代理接入地址，保障模型调用链路正常 |
| `AIPROXY_API_TOKEN` | 按平台分配的密钥填写 | 完成模型调用的身份验证，保障接入安全 |
| `toolChoice` | auto | 按需启用工具调用，适配工艺方案验证、参数校验等多步骤查询需求 |

## 容易做错的三处
- 现象：同一知识库、提示词与模型，在线对话与API调用返回结果差异显著。原因：未统一配置`maxContext`与`temperature`参数，或API调用时未正确传递上下文参数。
- 现象：使用指定模型时，仅输出思考内容，无正文回答。原因：`maxTokens`配置值过小，截断了正文输出部分，或提示词未明确要求输出正文内容。
- 现象：进入工作台编辑页面报错提示未配置语言模型，或工作流的AI模型选项为空。原因：未正确填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或模型未在平台后台完成注册与启用。

## 怎么确认配好了
- 检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的填写内容，确保与平台分配的信息一致。
- 发起测试调用，验证模型是否能正确返回工艺参数、公差要求等相关问答内容，调整参数至符合业务需求的区间。
- 对比在线对话与API调用的返回结果，确认`maxContext`与`maxTokens`的配置覆盖了关键文档内容。
- 检查工作流配置页面，确认AI模型选项已显示可用的部署模型。
