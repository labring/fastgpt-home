# 钣金下料折弯的工艺规程与技术标准问答：工具调用与插件

## 这个品类的数据长什么样
该品类数据主要来自CAD/CAM软件、订单BOM系统、板材库存台账、激光切割机与折弯机设备及MES系统。日常文档包含零件展开图、数控下料程序、折弯工艺卡、套料图、首件记录与工序流转卡。数据更新随每笔订单、每日生产及每次设备换型调整，文档字段多包含板材规格、折弯系数、下料尺寸、工序流转节点等，单位以毫米、平方米、千克、工时为主。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据分散于多系统且更新频率高，要求工具调用插件支持实时同步订单BOM、设备参数与库存数据。日常文档包含CAD展开图与工艺卡文本，需适配CAD格式与工艺文本的专用插件解析折弯系数、下料尺寸等关键参数，避免格式解析错误。多品种小批量的生产模式，要求工具调用需限定召回范围为当前订单关联的工艺文档，防止无关数据干扰问答准确性。同时，工艺问答结果直接影响生产质量，插件需增加参数校验环节，避免因错误参数导致板材浪费或装配偏差。

## 配置怎么定
本页面配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工具调用模式 | `toolChoice` 设置为 `auto` | 适配多场景工艺问答，自动选择合适工具执行参数校验与数据查询 |
| 单次召回文档条数 | 前3–5条 | 避免过多召回导致上下文过载，符合多品种小批量的窄范围数据需求 |
| 插件超时阈值 | 600秒 | 适配CAD文件解析与设备数据拉取的耗时需求，防止因慢操作导致流程中断 |
| 文档召回范围 | 当前订单关联工艺文档 | 限定数据来源，避免无关套料图或历史工艺卡干扰当前问答 |
| 函数调用格式校验 | `functionCall` 开启强制校验 | 确保工具调用参数符合钣金工艺的字段规范，比如折弯系数的取值要求 |

## 容易做错的三处
- 现象：工具调用时持续报slow operation日志，MongoDB响应延迟过高。原因：未限定文档召回范围，导致每次调用拉取全量工艺文档，超出系统处理能力。
- 现象：配置工具调用后问答效果偏差大，同等级模型表现不如预期。原因：未对工具调用的参数做钣金工艺专属校验，比如折弯系数取值未结合板材厚度与材质，导致生成的工艺参数不符合实际需求。
- 现象：自定义变量更新插件无法实现计数器自增。原因：插件未配置为接收当前变量值作为输入，仅支持固定值更新，无法读取并累加现有数值。

## 怎么确认配好了
- 发起工艺问答测试，输入“当前订单的折弯工艺卡参数”，核对工具调用是否仅召回当前订单关联的文档。
- 触发工具调用，查看FastGPT系统日志，确认无异常延迟提示，且`toolChoice`自动选择对应工具的记录正常。
- 调用变量更新插件，手动传入测试数值，确认插件可正确接收并更新变量值。
- 验证专用工具调用，检查请求参数与目标服务要求一致，确认返回结果符合预期格式。
