# 钣金下料折弯的工艺规程与技术标准问答：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据通常来自CAD/CAM软件、订单BOM、板材库存系统、激光切割机与折弯机设备日志、MES生产管理系统。日常文档包含零件展开图、数控下料程序、折弯工艺卡、套料图、首件检验记录、工序流转卡。数据字段包含折弯补偿系数、板材厚度、孔位公差、折弯角度等，单位多为毫米、度、平方米。更新节奏随订单生成、每日库存盘点、每次生产换型同步调整。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的多源异构数据来自设备、软件与管理系统，格式差异较大，要求模型接入时适配多种非结构化工程文档。高频更新的订单、换型数据，需要配置支持动态调整上下文长度的参数。专业字段如折弯系数、孔位公差需要模型具备行业术语理解能力，避免解析偏差。多品种小批量的业务模式，要求配置兼顾单订单数据的快速调用与批量任务的资源分配。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，适配钣金下料折弯场景的工艺问答需求：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配钣金工艺多文档拼接的上下文需求，覆盖展开图、工艺卡、套料图等内容 |
| `maxTokens` | 2000–3000 token | 满足工艺问答的详细回复长度，包含折弯系数计算、套料建议等专业内容 |
| `temperature` | 0.1–0.3 | 保持工艺标准回答的准确性，避免专业参数出现随机偏差 |
| `vision` | 开启 | 支持解析嵌入PDF的展开图、折弯示意图等视觉类工艺文档 |
| `AIPROXY_API_ENDPOINT` | 按本地部署环境填写专属API地址 | 适配本地大模型的调用路径，确保数据传输符合部署要求 |
| `AIPROXY_API_TOKEN` | 按实测生成的安全密钥 | 保障本地模型调用的身份验证合规性 |

## 容易做错的三处
- 上传包含展开图的工艺PDF后，界面显示解析超时或请求失败，重启服务器无改善。原因：未调整`maxContext`参数适配长文档，本地模型内存分配不足导致请求中断。
- 发起折弯系数计算的问答后，返回结果与行业通用标准偏差较大。原因：`temperature`取值过高，导致专业工艺参数生成出现随机波动。
- 将图片嵌入PDF上传后，解析结果未包含图片对应的工艺内容。原因：未开启`vision`配置项，模型无法处理视觉类工艺文档。

## 怎么确认配好了
- 上传单份折弯工艺卡PDF，包含嵌入的展开图与工序说明，检查解析结果是否覆盖核心工艺参数。
- 发起包含折弯补偿系数计算的问答，核对返回内容是否符合行业通用工艺逻辑。
- 查看本地模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置无错误，请求无异常中断。
- 测试多文档拼接的上下文问答，确认模型能关联不同工序的工艺参数与要求。
