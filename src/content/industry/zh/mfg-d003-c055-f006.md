# 铸造（砂型、精密、压铸）的工艺规程与技术标准问答：引用来源与溯源

## 这个品类的数据长什么样
铸造（砂型、精密、压铸）的日常文档包含铸造工艺卡、配料单、炉次记录、模具履历、首件检验记录、材质报告、不合格品评审单。数据来源包括ERP物料主数据、熔炼炉与测温仪、光谱仪、MES炉次记录、模具管理系统、客户图纸与技术条件。数据按每炉次、每批、每日更新，每份文档关联唯一炉次号、模次号或批次号，字段包含合金配料比例数值、熔炼温度、浇注参数、缺陷类型等，随文档类型呈现差异化结构。

## 这些特征在「引用来源与溯源」这一环带来什么约束
该品类的数据按炉次、批次高频更新，溯源需精准关联到单炉次或单批次，因此引用的切片必须携带唯一标识字段，避免跨批次混淆。多类型文档的字段结构差异较大，需在溯源时区分文档来源类型，确保引用内容与查询问题匹配。高频更新的数据要求引用的数据源为最新版本，需配置实时同步机制，避免引用过期数据。出错后果可能导致整炉或整批报废，或引发客户索赔，因此引用的精准度直接决定工艺判断的可靠性，需严格控制引用内容的范围与准确性。

## 配置怎么定
以下配置适用于FastGPT v4.17.0。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `quoteMaxToken` | 1200–1800 token | 匹配铸造工艺文档的单切片常规长度，避免引用内容超出回复承载上限 |
| `responseData` | 开启 | 满足工艺人员对溯源依据的查看需求 |
| `detail` | 开启 | 展示文档的唯一标识与来源类型，便于精准追溯炉次、模次信息 |
| 单次召回条数 | 前3–5条 | 控制回复信息量，避免冗余内容干扰工艺判断 |
| 文档同步频率 | 每小时同步一次 | 匹配该品类的高频更新节奏，确保引用数据为最新版本 |

## 容易做错的三处
- 控制台返回`quote type error`报错。原因是引用的变量格式未符合系统要求，例如未正确指定引用源的唯一标识字段。
- 回复中始终携带知识库引用链接无法隐藏。原因是未正确配置`responseData`的开关状态，导致引用内容强制展示。
- 当知识库切块大小设置为5000token，`quoteMaxToken`设为1500时，仍召回超出长度的切片内容。原因是切块大小与引用上限未匹配，未对召回的切片进行长度截断处理。

## 怎么确认配好了
- 发起包含合金配料比例、熔炼温度的查询，检查回复中是否携带炉次号、模次号等唯一标识。
- 测试隐藏引用功能，确认回复中不再显示知识库引用的地址或来源信息。
- 调整`quoteMaxToken`的取值，验证返回的引用内容长度是否符合设置的阈值。
- 查看系统日志，确认未出现`quote type error`类的报错信息。
