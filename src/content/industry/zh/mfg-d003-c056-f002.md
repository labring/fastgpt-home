# 锂离子电芯制造的工艺规程与技术标准问答：向量模型与索引

## 这个品类的数据长什么样
主体为动力、储能和消费电池企业的极片、装配、化成与品质部门。日常文档包含配料记录、涂布辊压参数、卷绕或叠片记录、注液记录、化成分容数据、OCV与安全测试报告。数据来源包括原材料批次记录、MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室数据。更新频率为每批、每只电芯对应的数据实时更新，单条记录包含具体参数值与批次关联信息。

## 这些特征在「向量模型与索引」这一环带来什么约束
锂离子电芯制造的数据按批次与单只电芯实时更新，要求索引支持增量更新以避免全量重建的资源消耗。数据包含结构化参数与非结构化测试报告两类，需兼顾两类内容的向量召回精度。单条数据的参数关联性强，如涂布辊压参数与后续卷绕工序存在直接关联，chunk拆分需保留参数的完整关联。电化学体系对水分、洁净度等参数敏感，相关数据的向量匹配需具备较高置信度，避免召回无关记录。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| 分块长度 | 800–1200 字符 | 锂离子电芯工艺文档的单条工序记录长度大多在此区间，避免拆分破坏参数与工序的关联 |
| `maxToken` | 8192 token | 适配bce-embedding-v1模型的最大支持token数，匹配分块长度的向量生成需求 |
| `defaultToken` | 0.65–0.75 | 工艺参数匹配需较高置信度，该区间可过滤低相关性的非目标工序记录 |
| 单次搜索上限 | 前8条 | 覆盖涂布、卷绕、化成等关联工序的记录，保证问答上下文的完整性 |
| 最大上下文 | 4000–6000 字符 | 适配工艺问答的多工序关联需求，避免上下文超出模型处理上限 |
| 重排 | 开启 | 对召回结果按相关性排序，提升关键工艺参数的展示优先级 |

## 容易做错的三处
- 现象为通过chunk模式调用pushdata api上传工艺数据后，FastGPT界面持续显示「索引中」状态，无进度更新。原因为未正确配置`defaultToken`的访问权限，或分块长度超出了`maxToken`的限制，导致索引任务无法完成。
- 现象为调用bce-embedding-v1模型时，返回报错文案为「该令牌无权使用模型」。原因为未在FastGPT中绑定该模型的专属访问密钥，使用了未授权的密钥发起调用。
- 现象为发起工艺规程问答时，召回结果缺少关联工序的参数记录。原因为分块长度设置过大，导致关键参数被拆分到不同chunk中，无法被精准召回。

## 怎么确认配好了
- 查看FastGPT v4.17.0的模型管理页面，确认bce-embedding-v1已添加且`defaultToken`配置正确。
- 上传一条测试用的涂布辊压参数记录，查看索引任务的执行日志，确认无token超限或权限报错。
- 发起一条工艺问答，比如“涂布辊压的面密度参数范围是多少”，核对召回结果是否包含对应工序的文档片段。
- 调整相似度阈值，测试不同阈值下的召回结果，确认符合业务所需的置信度要求。
