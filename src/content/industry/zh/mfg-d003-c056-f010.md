# 锂离子电芯制造的工艺规程与技术标准问答：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自原材料批次台账、车间MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室测试报告。日常文档包含配料记录、涂布辊压参数表、卷绕/叠片作业单、注液台账、化成分容数据、OCV与安全测试报告。数据更新节奏为每生产批次、单只电芯生产节点实时同步，文档字段包含浆料固含量、涂布面密度、辊压厚度、露点温度、充放电电流等，对应单位为g/㎡、μm、℃、A等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类数据的实时性与批次绑定特性，要求知识库检索需精准匹配生产批次与对应工艺参数，避免跨批次参数误用引发质量问题。多源异构的文档格式，要求检索需兼容结构化表格与非结构化文本，同时需按文档类型过滤无关内容。高敏感的电化学生产要求，检索结果需严格关联原始数据来源，防止参数偏差引发内短路、鼓胀等安全风险。高频更新的单电芯数据，要求召回结果需限定在当前生产批次的有效文档范围内，避免调用过期数据。

## 配置怎么定
本配置方案基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配锂离子电芯工艺参数的精度要求，避免低相似度的无关参数混入召回结果 |
| `limit` | 前8条 | 覆盖单批次工艺的核心参数项，同时控制上下文长度适配模型输入限制 |
| `searchMode` | `mixedRecall` | 兼顾结构化参数的精准匹配与非结构化文档的语义召回，适配多源文档格式 |
| `usingReRank` | 开启 | 对召回结果二次排序，修正矢量检索的语义偏差，强化工艺参数的强关联性匹配 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展工艺问题的同义表述，比如将「涂布面密度」匹配为「涂布厚度均匀性」相关文档 |
| `collectionIds` | 绑定当前生产车间的工艺知识库集合 | 限定检索范围仅为当前批次所属车间的文档，避免跨车间数据混淆 |

## 容易做错的三处
- 检索结果未展示对应文档的原材料批次、检测设备编号等溯源元数据。原因：未配置检索结果的元数据展示规则，未将文档的核心溯源字段纳入召回返回范围。
- 检索结果中图片无法正常加载或显示。原因：未开启知识库的图片解析与外链托管配置，直接引用本地图片路径导致无法访问。
- 检索召回结果包含过期的化成分容数据。原因：未按生产批次筛选召回集合，导致调用了非当前批次的历史工艺文档。

## 怎么确认配好了
- 上传一份当前批次的涂布辊压参数文档，发起「涂布面密度参数」的检索，核对返回结果是否仅包含该文档及同车间同类型文档。
- 发起包含专业术语的检索，比如「卷绕对齐度异常处理」，核对是否自动扩展匹配到相关的叠片作业文档。
- 查看检索结果的展示项，确认是否包含文档的批次编号、检测设备编号等溯源元数据。
- 上传一张涂布工序的露点监测截图，发起「露点控制要求」的检索，核对图片是否正常展示在结果中。
