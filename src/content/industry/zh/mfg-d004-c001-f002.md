# PCB制造的技术文档交叉审查：向量模型与索引

## 这个品类的数据长什么样
该品类的数据来源包括客户交付的Gerber文件、钻带、BOM清单，以及工厂内部CAM系统、生产设备参数、槽液化验记录、AOI检测报告、电测数据与实验室切片报告。日常生成的文档涵盖工程制作指示、Gerber解析记录、钻孔与层压参数表、药水分析台账等。数据更新频率随生产批次、班次变动，部分设备数据为连续采集，单份文档包含明确的参数字段与单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
多样的数据源与文档格式要求向量模型能够适配结构化参数文本与专业技术描述的嵌入需求。高频更新的生产数据要求索引支持增量刷新与批量处理，避免因全量重建索引占用过多资源。单份文档包含的专业参数与关联关系，要求向量嵌入过程保留字段间的语义关联，避免参数拆分导致的语义丢失。生产批次与数据的强绑定关系，要求索引支持按生产批次分组检索，提升跨文档关联的精准度。

## 配置怎么定
使用本页配置时，请确保当前使用FastGPT v4.17.0版本。
部分嵌入模型的`defaultToken`参数需与模型实际上下文窗口匹配，可通过模型官方文档确认取值。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | PCB文档包含长参数表与专业技术描述，过长会破坏语义关联完整性，过短会割裂参数间的关联关系 |
| 重叠长度 | 100–200 字符 | 避免跨块的连续参数或技术描述被拆分，保留上下文语义 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| 相似度阈值 | 0.72–0.85 | 平衡检索的精准度与召回率，适配PCB专业文档的参数匹配需求 |
| 单次搜索上限 | 前 8 条 | 减少候选文档数量，避免后续重排环节产生不必要的耗时 |
| 重排 | 启用 | 过滤低关联的检索结果，提升最终匹配的专业文档相关性 |

## 容易做错的三处
- 界面显示“无可用的向量模型渠道”，原因是未在FastGPT系统中正确配置对应嵌入模型的API密钥与接入地址，或未将模型绑定至default分组。
- 向量嵌入任务超时，原因是分块长度设置过大，超出模型`maxToken`限制，导致单块嵌入耗时过长。
- 检索后重排环节耗时过长，原因是单次搜索上限设置过高，同时启用了重排功能，导致大量候选文档进入重排流程。

## 怎么确认配好了
- 进入FastGPT的模型管理页面，查看嵌入模型的接入状态，确认显示正常在线。
- 上传单份典型的PCB工程制作指示文档，触发向量嵌入任务，查看任务日志无报错信息。
- 输入测试查询，如“层压参数异常排查”，查看检索结果包含对应的层压参数文档。
- 调整相似度阈值或分块参数后，验证检索结果的关联度变化符合预期。
