# PCB制造的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
PCB制造场景的数据来源包括客户Gerber、钻带、BOM文件，CAM工程文件，设备运行参数、槽液化验记录、AOI检测报告、电测报告与实验室切片报告。数据更新频率为每生产批、每班或连续采集。日常文档涵盖工程制作指示、Gerber解析记录、钻孔和层压参数、药水分析报告等，字段包含孔径、铜厚、层数、偏移量、合格率等，单位多为毫米、盎司、百分比等。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据格式要求模型接入时需适配二进制、结构化表格、文本报告等多种文档类型，需配置对应格式的解析规则。高频更新的数据节奏要求检索与索引环节需匹配生产节拍，避免索引滞后导致检索结果失效。复杂的文档结构与长文本内容需要更大的上下文窗口，确保模型能覆盖完整的工艺链路与异常记录。同时，审查结果直接关联生产报废与索赔风险，要求模型调用的严谨性与一致性，需严格控制生成参数的随机性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | PCB制造文档包含多层Gerber参数、多份测试报告，长上下文可覆盖完整工艺链路 |
| `maxTokens` | 2000–3000 token | 交叉审查需输出完整异常分析，避免截断关键结论 |
| `quoteMaxToken` | 1500–2000 字符 | 需引用完整的钻孔参数、AOI异常记录作为审查依据 |
| `temperature` | 0.1–0.3 | 技术审查需严谨，降低随机性，确保结论一致 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写对应地址 | 适配本地或云端模型接入需求 |
| `AIPROXY_API_TOKEN` | 按授权生成的密钥 | 保障模型调用的安全性 |

## 容易做错的三处
- 现象：知识库检索响应超时，日志显示检索耗时超出预设阈值。原因：未针对PCB制造的高频更新数据配置合适的索引刷新频率，导致大量未索引的生产数据参与实时检索。
- 现象：尝试接入蒸馏版DeepSeek模型时返回认证失败。原因：未将`AIPROXY_API_ENDPOINT`配置为蒸馏模型专属接入地址，仍使用通用大模型的接入端点。
- 现象：上传Gerber或AOI报告后解析结果为空，无明显异常日志。原因：未开启对应文档格式的解析插件，或未将文档类型关联至对应的解析规则。

## 怎么确认配好了
- 执行单份PCB工艺文档的检索测试，核对返回的引用内容是否覆盖文档核心参数，调整`quoteMaxToken`至覆盖完整引用片段。
- 上传多份不同格式的PCB文档（Gerber、AOI报告、槽液化验记录），验证解析结果是否包含对应字段，确认格式解析规则已正确配置。
- 触发模型调用测试，核对返回的审查结论是否符合工艺逻辑，调整`temperature`至符合审查严谨性要求。
- 查看API调用日志，确认`AIPROXY_API_ENDPOINT`和`AIPROXY_API_TOKEN`的配置未出现拼写错误，无认证失败记录。
