# SMT贴片与电子组装的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
SMT贴片与电子组装的日常技术文档包含BOM与坐标文件、换线表、钢网与炉温记录、首件确认报告、SPI/AOI检测报告、维修记录与追溯标签。数据来源覆盖客户提供的BOM、Gerber与坐标文件，以及MES系统、锡膏与元件批次台账、贴片机、SPI/AOI设备、回流焊炉温数据。数据更新频率为每工单、每次换线及实时，文档字段包含料号、位号、元件规格、炉温曲线参数、缺陷标记等，不同来源文档的字段命名与单位存在差异。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的文档结构要求模型接入配置需支持文本与图像混合数据的解析适配；实时与高频更新的数据要求模型调用链路具备低延迟特性，需合理设置上下文与输出长度参数。字段命名与单位的差异要求配置中开启模型的格式校准能力，保证跨文档的信息比对准确性。不同文档的核心校验目标，如料号核对、缺陷分析，需对应调整模型的温度参数，平衡精度与效率。不同模型渠道的接入配置需匹配SMT场景的业务需求，比如启用图像解析功能处理AOI报告的图像内容。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 覆盖BOM、换线表、炉温记录等多文档拼接后的上下文长度，避免关键信息截断 |
| `maxTokens` | 2000–3000 token | 满足料号核对、缺陷分析、参数比对等任务的输出长度需求 |
| `temperature` | 0.1–0.3 | 保证料号、位号等精确匹配任务的结果一致性，降低随机偏差 |
| `vision` | 开启 | 支持SPI/AOI报告中的缺陷图像解析，完成图像与文本数据的交叉审查 |
| `AIPROXY_API_ENDPOINT` | 按部署服务商提供的专属地址 | 适配不同模型渠道的接入路径，避免因地址错误导致调用失败 |
| `AIPROXY_API_TOKEN` | 绑定对应模型的专属密钥 | 确保模型调用的权限合法性，防止因密钥错误或权限不足无法访问 |

## 容易做错的三处
- 现象：文本内容提取模块的模型选择列表中仅展示GPT系列选项，已接入的GLM模型未显示。原因：仅在AI对话模块完成了模型接入配置，未在文本提取模块中同步关联对应模型的适配规则。
- 现象：调用AWS Claude3模型时提示「找不到渠道」。原因：未正确配置`AIPROXY_API_ENDPOINT`为对应AWS区域的专属接入地址，或绑定的`AIPROXY_API_TOKEN`未获得Claude3模型的调用权限。
- 现象：模型返回的交叉审查结果遗漏元件批次与炉温参数。原因：`maxContext`取值过低，未覆盖完整的BOM与炉温记录的上下文内容，导致关键信息被截断。

## 怎么确认配好了
- 上传一份测试用的BOM文件与SPI检测报告，触发交叉审查任务，检查模型是否能正确识别料号、位号与检测缺陷的对应关系。
- 进入FastGPT v4.17.0的模型管理界面，确认已接入的所有模型均显示在文本提取、AI对话等模块的选择列表中，验证`AIPROXY_API_TOKEN`的有效性。
- 调整`temperature`参数至0.2，提交3组重复的测试样本，检查返回的审查结果是否保持一致。
- 上传一张AOI缺陷图像，确认模型能正常解析图像中的缺陷标记，并关联对应文档的文本信息完成审查。
