# 乳制品加工的技术文档交叉审查：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自奶源检测、MES系统、均质与热处理设备、在线温流量采集模块、CIP系统、LIMS实验室管理平台。日常文档包含原奶验收记录、标准化配料单、巴氏或UHT热处理记录、CIP清洗记录、灌装记录、留样与微检报告，字段涵盖原奶菌落总数、配料比例、热处理温度与时长、CIP循环参数等，单位涵盖cfu/mL、%、℃、秒、MPa等。数据更新节奏为每奶罐、每批实时同步，单批次数据关联多环节生产流程。

## 这些特征在「知识库检索与召回」这一环带来什么约束
实时高频的批次数据更新要求检索链路支持低延迟召回，避免因数据滞后导致合规审查失效。多源异构的数据格式，包含结构化报表、设备原始日志、实验室报告，要求检索模型适配混合字段的语义匹配，不能仅依赖纯文本关键词匹配。单批次生产关联多环节文档，要求检索支持跨文档关联召回，避免割裂原奶验收到灌装的全链路审查逻辑。原料易腐且出错后果严重，要求检索结果的关联度匹配业务风险等级，优先召回高优先级的合规校验文档。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本编写，适配该版本的知识库管理与检索逻辑。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配乳制品加工文档的专业术语密度，过滤低关联度的非生产类文档 |
| `limit` | 前8条 | 覆盖单批次生产关联的多环节文档数量，避免召回冗余数据 |
| `searchMode` | `mixedRecall` | 结合关键词匹配与语义检索，适配结构化报表与设备日志的混合检索需求 |
| `usingReRank` | 开启 | 对召回结果二次排序，优先返回与原奶验收、热处理环节强相关的文档 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展行业专业术语查询，比如将「UHT」扩展为「超高温瞬时灭菌」，适配行业术语习惯 |
| `collectionIds` | 按生产批次绑定对应数据集 | 隔离不同奶罐/批次的文档数据，避免跨批次检索干扰审查逻辑 |

## 容易做错的三处
- 导出的知识库文件体积仅几百KB，未覆盖全量生产文档。原因是未按生产批次全量同步原奶验收、微检报告等全链路文档，仅上传了部分环节的文件。
- 导入的markdown文档无法显示本地图片。原因是未配置本地图片资源的关联路径，仅导入了文本内容，未同步上传图片文件至知识库存储目录。
- 检索精度不足，无法快速定位合规校验所需的热处理参数。原因是未开启`usingReRank`配置，且`similarity`阈值设置过低，导致召回大量低关联度的非生产文档。

## 怎么确认配好了
- 执行单批次原奶的交叉审查检索，核对召回结果包含原奶验收记录、对应批次的热处理记录与CIP清洗记录。
- 上传包含本地图片链接的markdown文档，检索该文档时确认图片可正常加载显示。
- 触发知识库全量训练任务，查看训练日志显示覆盖全量数据集的文档数量，无遗漏提示。
- 导出知识库文件，核对文件体积与全量文档的总存储容量匹配，无明显偏小情况。
