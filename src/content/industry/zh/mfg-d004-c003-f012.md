# 乳制品加工的技术文档交叉审查：部署与升级

## 这个品类的数据长什么样
典型主体为液态奶、酸奶、奶粉及乳配料企业，日常文档涵盖原奶验收记录、标准化配料单、巴氏或UHT热处理记录、CIP清洗记录、灌装记录、留样与微检报告。数据来源覆盖奶源检测设备、MES系统、均质与热处理设备、在线温流量采集系统、CIP系统及LIMS实验室管理系统。数据更新频率为每奶罐、每批或实时，字段包含原奶抗生素与理化指标、热处理时间温度参数、无菌灌装校验数据等，附带对应检测单位与设备编号。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的高频实时更新要求部署时适配高并发的数据读写，避免因连接耗尽导致文档同步中断。多源异构的数据来源需要配置多类型存储连接，适配结构化的理化指标数据与非结构化的检测报告。文档字段包含专业生产参数，部署时需确保数据映射的准确性，避免交叉审查时出现字段缺失或单位错误。同时，出错后果涉及整罐原奶拒收或大范围召回，部署环节需配置完善的失败重试与告警机制，保障审查流程的稳定性。

## 配置怎么定
本页面适配FastGPT v4.17.0开源版。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `20–30 个连接` | 适配每奶罐实时写入的并发量，避免数据库连接耗尽 |
| `MONGODB_URI` | `mongodb://<db-user>:<db-pass>@<host>:27017/fastgpt_dairy?authSource=admin` | 对接LIMS系统与留样微检报告的非结构化存储，支持高频读写 |
| `PG_URL` | `postgresql://<pg-user>:<pg-pass>@<host>:5432/fastgpt_dairy?sslmode=disable` | 存储标准化配料单、CIP记录等关系型生产数据 |
| `REDIS_URL` | `redis://:<redis-pass>@<host>:6379/0` | 缓存实时温流量、设备状态数据，降低核心数据库压力 |
| `FE_DOMAIN` | 企业内部nginx代理后的域名 | 修复知识库原文链接的代理跳转问题，确保内部访问正常 |
| `FILE_TOKEN_KEY` | 32位随机字符串 | 加密知识库文件下载token，防止未授权访问生产文档 |
| `ROOT_KEY` | 复杂度不低于12位的随机字符串 | 验证管理后台最高权限，保障部署配置的安全性 |

## 容易做错的三处
- 现象：docker部署启动后弹出数据库认证失败报错，日志显示连接被拒绝。原因：未正确修改`MONGODB_URI`与`PG_URL`中的数据库密码参数，沿用了默认初始密码。
- 现象：nginx代理配置完成后，知识库原文链接无法正常跳转，访问返回404状态码。原因：未配置`FE_DOMAIN`为nginx代理后的内部域名，链接指向容器默认内网地址，无法被外部访问。
- 现象：本地部署完成后，管理后台无团队邀请功能入口，页面提示功能未启用。原因：未设置`ROOT_KEY`并通过系统设置开启团队模块，开源版默认未激活该功能。

## 怎么确认配好了
- 登录FastGPT管理后台的数据源管理页面，分别测试`MONGODB_URI`、`PG_URL`、`REDIS_URL`的连接状态，确认全部显示连接正常。
- 上传一份标准化配料单文档生成知识库，点击文档详情中的原文链接，确认跳转至预设的内部访问地址，无404报错。
- 使用`ROOT_KEY`进入系统设置页面，确认团队功能开关已开启，页面显示团队邀请相关配置项。
- 批量导入5个批次的CIP记录，观察后台监控的数据库连接数未超过`DB_MAX_LINK`的设定值，无连接超时日志输出。
