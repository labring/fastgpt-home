# 光伏电池片制造的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
数据来源涵盖硅片来料检测、生产MES系统、扩散炉/镀膜设备/印刷机的实时运行数据、EL与IV测试设备的片级检测结果、实验室理化分析记录。更新节奏按生产批次、单片检测结果、每日汇总更新。日常文档包含工艺卡、扩散与镀膜参数表、印刷烧结工序记录、EL缺陷检测图、IV性能分档数据、良率汇总报告，文档字段包含蚀刻深度、方块电阻、镀膜厚度、缺陷坐标、电性能参数等，部分文档包含可视化图像与数值绑定的关联数据。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的多源片级数据、批次级文档与可视化图像并存的特征，要求模型接入需支持多模态输入与长上下文处理，单批次关联文档的总长度可能超出通用上下文限制，需合理配置上下文参数。内网部署的生产数据无法对外暴露，要求模型API需在内网环境可访问，无法依赖公网模型渠道。专业工艺参数与可视化缺陷的关联分析，要求向量模型适配电子制造领域的专业术语，召回结果需覆盖多维度的关联文档。生产环节的出错影响直接关联产品性能，要求模型调用的稳定性与失败排查机制需适配内网环境的网络限制。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 单批次光伏电池片的关联文档总token数通常覆盖该区间，避免截断关键工艺关联信息 |
| `vision` | 开启 | 需处理EL检测图、IV测试可视化数据，实现图像与数值参数的交叉审查 |
| `temperature` | 0.1–0.3 | 工艺审查需严谨，避免生成偏离实际参数的推断结果 |
| `AIPROXY_API_ENDPOINT` | 内网部署模型的本地API地址 | 生产数据在内网环境，需使用内网可访问的模型API，避免数据泄露 |
| `toolChoice` | auto | 需自动判断是否调用工具补充文档数据，适配多源文档的交叉校验 |
| `quoteMaxToken` | 1500 token | 单份核心工艺文档的token占比，确保召回的引用内容足够支撑审查逻辑 |

## 容易做错的三处
- 现象为模型渠道调用时报错`error`，调用日志显示获取数据异常。原因是未配置内网可访问的API端点，仍尝试调用公网模型渠道，导致内网服务器无法连通目标接口。
- 现象为向量模型召回的结果无法覆盖专业工艺参数。原因是使用了未适配电子制造领域的向量模型，无法准确匹配光伏电池片制造的专业字段与术语。
- 现象为API响应未返回思维链相关内容，仅展示最终审查结论。原因是未开启思维链输出的相关配置，或所选模型渠道未支持思维链内容的返回格式。

## 怎么确认配好了
基于FastGPT v4.17.0版本，可通过以下动作核对配置是否完成：
- 在内网环境下发起一次模型调用测试，查看接口返回是否正常，无连接超时或权限报错。
- 导入单批次的光伏电池片关联文档，检查模型是否能正确识别图像与数值参数的关联关系。
- 查看调用日志，确认模型调用的参数与配置项一致，无参数遗漏或错误赋值。
- 触发一次异常调用场景，检查失败处理流程是否能正常记录日志并提示排查方向。
