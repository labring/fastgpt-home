# 光伏组件封装的技术文档交叉审查：引用来源与溯源

## 这个品类的数据长什么样
光伏组件封装环节的数据来源包括电池片分档台账、玻璃胶膜背板批次记录、MES生产管理系统、串焊与层压设备运行日志、EL缺陷检测仪与IV功率测试仪输出文件。数据更新节奏为每块组件生成专属文档，每批材料同步批次溯源记录。日常文档涵盖排版布局图、材料批次表、层压工艺参数记录、EL隐裂标注图、IV功率测试报告、绝缘耐压检测记录、成品包装清单。核心字段包含电池片电流档位、层压温度与保温时长、EL隐裂位置与面积、IV测试功率值、绝缘电阻数值，单位涵盖安培、摄氏度、秒、瓦特、兆欧等。

## 这些特征在「引用来源与溯源」这一环带来什么约束
每块组件的文档独立且更新频繁，要求溯源系统精准匹配到单组件的全量关联文档，避免跨组件的错误关联。文档类型包含图文、表格与测试数据，要求溯源支持多格式内容的召回与展示。核心字段多且带有明确业务单位，要求检索时精准匹配字段关键词，避免无关记录被召回。合规审查需要追溯材料批次与测试设备的关联信息，要求溯源结果包含文档的原始生成路径与设备编号。相较于电池片制造环节，该品类更关注封装后的层压质量与功率分档，因此溯源需聚焦封装环节的文档，仅覆盖光伏组件封装的专属文档库。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | 适配光伏封装文档的单条记录长度，避免截断层压温度、EL隐裂面积等关键参数 |
| `responseData` | 仅返回批次记录、EL图标注、IV测试数值 | 聚焦业务核心字段，减少无关的排版图内容干扰检索结果 |
| `detail` | 开启完整溯源 | 展示文档的原始上传路径、生成时间、测试设备编号，满足合规审查需求 |
| 单次召回上限 | 前6条 | 匹配单组件的关联文档数量，避免加载过多冗余的同批次材料记录 |
| 上下文窗口 | 14000–16000 token | 容纳单组件的多份关联文档，比如材料批次表、层压记录、EL图与IV报告 |

## 容易做错的三处
- 现象：工作流中引用文档检索插件后运行报错，输入框显示“参数格式错误”，原因是未按平台预设区间设置引用上限，误填了不在合法范围内的数值。
- 现象：检索结果返回大量无关的电池片制造文档，未聚焦封装环节内容，原因是未配置关键词过滤规则，未限定检索范围为光伏组件封装的专属文档库。
- 现象：返回的EL图关联描述文本被截断，无法查看完整的隐裂标注信息，原因是未调整`quoteMaxToken`的取值，导致token配额不足，截断了关键内容。

## 怎么确认配好了
- 在FastGPT v4.17.0环境下，上传一份包含单组件批次记录、EL图、IV测试报告的完整文档包，运行检索任务，核对返回结果仅包含该组件的核心业务文档。
- 查看检索结果的溯源详情，确认展示了文档的上传路径、生成时间与测试设备编号。
- 调整`quoteMaxToken`的取值，验证返回的EL图描述文本未出现截断情况。
- 模拟多组件文档的检索场景，确认不会出现上下文溢出的报错提示。
