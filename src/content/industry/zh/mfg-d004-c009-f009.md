# 化学药制剂生产的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
该品类的日常文档包含主生产文件、批生产记录、批包装记录、清场记录、检验记录、偏差/CAPA/变更及批放行审核表。数据来源为经批准的处方工艺、物料批次、MES/电子批记录、设备与环境监测数据、LIMS及质量管理系统。数据更新随每批生产、关键工艺步骤及监测计划执行，核心字段包含物料批号、工艺参数、检验结果、偏差描述及放行状态，单位涉及质量、体积、温度等医药生产标准单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的文档与生产操作强绑定且需符合合规要求，模型接入需支持结构化与半结构化文档的精准匹配。数据随每批生产动态更新，需配置支持动态拉取最新批次数据的接口。核心合规字段的校验要求模型输出关联原始数据来源，需开启上下文引用配置。批放行决策依赖多源数据汇总，需模型支持跨文档关联分析，同时需保证调用延迟适配实时审核节奏，避免影响生产节拍。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 该品类文档多为多源批记录汇总，需容纳完整的批次数据上下文，避免截断关键合规信息 |
| `temperature` | 0.1–0.3 | 技术文档交叉审查需严格遵循既定规则，低温度可保证输出的一致性与合规性 |
| `quoteMaxToken` | 2000 字符 | 需保留足够的原始文档片段用于合规追溯，匹配批记录的单页平均长度 |
| 工作流/API 工具选择配置 | auto | 需模型自主判断是否调用文档检索工具完成交叉校验，适配多源数据的关联分析需求 |
| `AIPROXY_API_ENDPOINT` | 按本地部署的模型网关地址填写 | 适配企业本地部署的模型调用需求，保障生产数据不出域符合合规要求 |
| `AIPROXY_API_TOKEN` | 按网关生成的专属令牌填写 | 限制未授权的模型调用，保障生产数据的访问安全 |

## 容易做错的三处
- 现象：模型调用返回connection refused错误，界面显示模型连接失败。原因：未正确配置`AIPROXY_API_ENDPOINT`为本地部署的模型网关地址，或网关服务未正常启动、端口未开放，无法建立有效连接。
- 现象：生成的交叉审查报告缺少关联的原始文档片段。原因：未配置`quoteMaxToken`参数或取值过小，导致模型无法提取并返回关联的原始文档内容。
- 现象：单批次文档审核耗时过长，触发平台超时限制。原因：`maxContext`参数设置过大，超出模型支持的上下文窗口上限，导致模型处理延迟增加。

## 怎么确认配好了
- 手动触发单批次文档的交叉审查任务，查看模型调用日志，确认请求地址与`AIPROXY_API_ENDPOINT`配置一致。
- 审查结果生成后，检查是否包含关联的原始文档片段，确认`quoteMaxToken`参数配置符合当前文档的引用需求。
- 批量提交3-5个不同批次的文档进行审核，确认任务无连接失败或超时报错，根据实际运行节奏调整参数。
- 查看模型输出的结果一致性，确认`temperature`取值符合合规审查的严谨性要求。
