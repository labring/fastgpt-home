# 化学药制剂生产的技术文档交叉审查：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据来源于经批准处方工艺、物料批次、MES/电子批记录、设备与环境监测系统、LIMS及质量管理系统。日常文档包含主生产文件、批生产记录、清场记录、检验记录、偏差/CAPA/变更文档及批放行审核表，每批生产、每个关键工艺步骤及按监测计划完成更新。文档字段包含物料批号、工艺参数值、检测结果、偏差描述等，对应单位涉及质量、温度、时长等生产相关计量标准。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的按批、按步骤更新的数据特征，要求检索需绑定当前生产批次的物料批号与工艺参数，避免调用过期或不匹配的历史数据。多类型合规文档的结构差异，要求检索需支持按文档类别筛选目标字段，确保匹配的内容与当前审查环节（如投料复核、偏差汇总）对应。高频更新的特性要求知识库同步频率匹配生产节奏，同时需限制检索范围仅包含已完成质量放行的文档，符合GMP合规要求，若检索匹配错误，将直接影响批记录审核与放行判断，带来合规风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 适配化学药制剂生产文档的字段精度要求，过滤低匹配度的无关历史数据 |
| `limit` | `前 6–10 条` | 覆盖当前批次的物料、工艺、偏差等多维度审查需求，避免过多结果增加审核负担 |
| `searchMode` | `mixedRecall` | 兼顾语义匹配与精准字段匹配，适配多类型合规文档的检索需求 |
| `usingReRank` | `开启` | 对初步检索结果按相关性排序，确保最贴合当前审查环节的文档优先展示 |
| `datasetSearchUsingExtensionQuery` | `开启` | 自动扩展审查相关的关键词，覆盖偏差处理、批放行等关联文档 |
| `collectionIds` | `绑定当前生产批次对应的知识库集合` | 限定检索范围仅包含当前项目的合规文档，避免跨批次数据干扰 |

## 容易做错的三处
- API调用嵌套知识库助手的工作流时返回空值。原因：未使用FastGPT v4.17.0及以上版本，或未在工作流中正确配置`collectionIds`参数绑定当前生产批次的知识库集合。
- 知识库变量引用时出现quote type error报错。原因：传入的检索变量格式不符合系统要求，未遵循预设的参数结构，或变量中包含未处理的特殊符号。
- 检索结果未覆盖当前批次的偏差或放行相关文档。原因：未开启`datasetSearchUsingExtensionQuery`参数，导致无法自动扩展关联关键词，遗漏相关审查内容。

## 怎么确认配好了
- 查看工作流的知识库检索节点，确认`collectionIds`参数绑定了当前生产批次对应的知识库集合。
- 执行一次模拟检索，核对返回结果的匹配度是否符合当前审查环节的精度要求，调整`similarity`阈值至合适区间。
- 触发API调用工作流，确认返回结果不为空，且包含当前批次的相关文档内容。
- 检查检索结果的排序，确认`usingReRank`参数已生效，最相关的文档优先展示。
