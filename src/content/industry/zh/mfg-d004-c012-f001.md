# 半导体晶圆制造的技术文档交叉审查：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据主要来自晶圆厂的MES系统、设备FDC采集模块、缺陷检测与量测设备、工艺配方库与实验数据库。日常文档包含工艺流程卡、批次运行记录、设备配方、SPC控制图、异常处置单、缺陷图谱与良率报告。数据更新节奏随晶圆批次推进，关键工艺参数实时采集，批量记录与报告每日生成。文档字段包含晶圆批次号、工艺参数（单位含纳米、瓦特等）、缺陷空间坐标、设备运行时长与良率占比等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据分散在多个异构外部系统，HTTP接口对接需同时覆盖实时采集的设备参数、批量生成的批次记录与静态工艺文档，因此需适配不同接口的鉴权规则与数据格式。晶圆批次的强关联属性要求接口参数必须携带唯一批次标识，避免数据混淆。多类型文档的混合调用，需支持结构化参数与非结构化文件的同步传输。同时，数据异常会直接导致晶圆报废，接口需内置幂等处理与失败重试机制，避免重复提交或漏传数据引发生产事故。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `Authorization` | 携带Bearer格式的静态令牌 | 符合工业系统API的通用鉴权要求，避免明文传输密钥 |
| 超时阈值 | 60–180 秒 | 覆盖实时参数拉取、大尺寸晶圆图传输与批量记录查询的耗时 |
| 文件上传上限 | 1000 MB | 适配晶圆图与缺陷图谱的单文件尺寸要求 |
| `responseData` | 提取根节点下的结构化业务字段 | 统一不同外部系统的返回格式，降低下游数据解析成本 |
| 批量拉取上限 | 前15条批次运行记录 | 控制单次请求的数据量，避免触发接口限流 |
| `variables` | 预设晶圆批次号、工艺节点等核心参数 | 简化接口调用时的参数传递，确保数据关联准确性 |

## 容易做错的三处
- 调用接口返回`message: Invalid URL, code: 500`，原因是未正确配置外部系统的API根路径，或携带的参数未匹配目标接口的路由规则。
- 接口调用提示`Multimodal file size is`截断报错，原因是未设置合理的文件传输大小限制，晶圆缺陷图谱的单张文件尺寸超出接口允许的上传上限。
- 副本集模式下MongoDB Change Streams断连无法重连，原因是未配置自动重连参数，主节点漂移后未触发连接重置逻辑，导致数据流中断。

## 怎么确认配好了
- 调用测试接口拉取单条批次记录，核对`responseData`字段是否提取到预期的晶圆批次号与工艺参数。
- 配置`Authorization`鉴权后，调用无权限的测试接口，确认返回正确的鉴权失败状态码。
- 提交大尺寸晶圆图文件，验证接口是否能正常接收并返回有效响应。
- 调整`variables`参数，确认接口调用时自动带入预设的业务变量。
