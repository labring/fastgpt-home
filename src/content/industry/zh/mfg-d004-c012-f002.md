# 半导体晶圆制造的技术文档交叉审查：向量模型与索引

## 这个品类的数据长什么样
该品类的数据主要来自晶圆厂的MES系统、设备FDC模块、缺陷检测与量测设备、工艺配方库及实验数据集。日常生成的文档包含工艺流程卡、批次运行记录、设备配方、SPC时序图、异常处置单、缺陷图谱与良率报告。数据更新节奏覆盖每批晶圆流转、实时设备参数上报与每日工艺台账同步，文档包含结构化数值字段、可视化晶圆点位图与长时序运行记录，字段涉及晶圆批次标识、工艺参数、设备编号与缺陷位置坐标。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据特征对向量模型与索引环节带来多重约束。多更新节奏的数据源要求支持增量索引与实时参数同步，避免全量重建带来的性能损耗。包含可视化晶圆图、SPC时序图的文档，需要适配非纯文本内容的向量化处理，确保图表内的参数关联关系被正确捕捉。纳米级精度的工艺参数与跨工序的文档关联，要求向量模型具备细粒度语义识别能力，索引需支持多维度字段召回以匹配跨模块的审查需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 匹配晶圆制造文档中工艺流程卡、设备配方的单段有效信息长度，避免跨工序语义断裂 |
| 重叠长度 | 100–150 字符 | 覆盖跨块的工艺参数关联，防止分块切断SPC图的时序逻辑 |
| 相似度阈值 | 0.72–0.85 | 适配纳米级参数的细微差异识别，过滤无关的工艺文档干扰 |
| 单次搜索上限 | 前 10 条 | 匹配单批次晶圆审查的关联文档数量，避免冗余召回拖慢审查效率 |
| `maxToken` | 4096 token | 适配长时序的批次运行记录，确保完整嵌入审查上下文 |
| `defaultToken` | 按实测标定 | 适配不同向量模型的输入长度限制，兼容各类公开与商用索引模型接入渠道 |

## 容易做错的三处
- 现象：向量模型接入后提示无可用渠道，或分组default下无法加载模型。原因：未在模型供应商配置页勾选索引模型启用开关，或未将模型绑定至对应使用分组。
- 现象：ollama部署的BGE-M3模型无法生成向量，日志显示超时或向量维度不匹配。原因：未正确配置向量模型的端口与访问路径，或输入文本长度超出模型`maxToken`限制。
- 现象：交叉审查召回结果与预期不符，包含大量无关的非工艺类文档。原因：相似度阈值设置过低，或分块长度未匹配文档结构，导致语义碎片干扰召回逻辑。

## 怎么确认配好了
- 进入FastGPT v4.17.0的模型管理页面，确认索引模型已启用且绑定至当前使用的业务分组。
- 上传一份典型的晶圆缺陷图谱，触发向量生成流程，查看生成日志确认无维度错误或超时报错。
- 输入一条跨工序的工艺审查问题，验证召回结果包含对应的工艺流程卡与异常处置单。
- 上传一份新的批次运行记录，测试增量索引同步功能，确认新数据可被正常召回与检索。
