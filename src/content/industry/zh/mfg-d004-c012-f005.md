# 半导体晶圆制造的技术文档交叉审查：工具调用与插件

## 这个品类的数据长什么样
通常半导体晶圆制造的技术文档涵盖工艺流程卡、批次运行记录、设备配方、SPC图、异常处置单、缺陷图谱、良率报告。数据来源包括MES系统、设备FDC、缺陷检测与量测设备、晶圆图、工艺配方库、实验数据。更新节奏随每批晶圆生产、实时设备参数采集、每日报表生成而变化。文档字段包含晶圆批次号、纳米级工艺参数、缺陷空间坐标、良率数值等，部分文档包含可视化图表与结构化数值。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源且实时更新的数据要求工具调用支持跨系统拉取，需适配MES、设备FDC等不同数据源的接口格式。纳米级参数与可视化图表的文档结构，要求工具具备非结构化文本与图像的解析能力。单批晶圆关联的工序文档数量较多，且返工窗口有限，要求工具调用的延迟控制在合理范围，同时避免冗余数据干扰审查结果。跨模块的良率归因需要关联多批次数据，要求工具支持批量数据查询与关联校验。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配多类型工艺文档的交叉审查调用需求，自动匹配不同数据源的工具 |
| `functionCall` | 开启 | 支持结构化调用设备参数、良率数据等专用查询工具，提升审查准确性 |
| 单次工具调用返回上限 | 前6–10 条 | 单批晶圆关联的工艺文档数量有限，避免冗余数据干扰交叉审查逻辑 |
| 工具调用超时时间 | 90–150 秒 | 需拉取多源实时设备数据与缺陷图谱，预留足够的接口响应时间 |
| 结果格式校验开关 | 开启 | 避免非结构化搜索结果或数组格式数据无法参与交叉审查流程 |

## 容易做错的三处
- 现象：工具调用并发超出限制，出现503状态码或请求被丢弃。原因：未根据单批晶圆的生产节奏调整并发配置，未设置匹配实时数据拉取的并发队列上限。
- 现象：调用MCP工具时出现图片显示不全的报错，无法加载缺陷图谱的可视化内容。原因：未配置支持图像解析的工具插件，或未正确传递图片的路径与格式参数。
- 现象：谷歌搜索返回的array<object>格式结果无法参与交叉审查，字段为空或格式报错。原因：未开启结果格式校验开关，未配置格式化工具处理结构化数组数据。

- 基于FastGPT v4.17.0版本，提交单批晶圆的工艺交叉审查请求，查看工具调用日志中的返回条数是否符合配置的上限要求。
- 模拟多批次并行的审查请求，确认无503状态码或请求丢弃的报错，并发配置符合生产节奏。
- 导入指定的嵌入模型，测试嵌入包含纳米级工艺参数的配方文档，确认无适配报错。
- 模拟谷歌搜索返回array<object>格式的测试数据，提交审查请求，确认结果可正常解析并参与交叉审查。
- 调用MCP工具加载缺陷图谱的可视化内容，确认图片完整显示无报错。
