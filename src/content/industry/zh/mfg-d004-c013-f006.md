# 印刷与包装加工的技术文档交叉审查：引用来源与溯源

## 这个品类的数据长什么样
这个品类的日常文档包含印前文件、拼版单、印刷工艺单、油墨配色记录、首件签样、条码检测、模切与复合记录。数据来源包括客户稿件、色彩管理系统、印刷机运行数据、油墨与基材批次记录、分光仪检测数据、条码检测仪读数。数据更新频率为每订单、每批或每次换版。文档字段包含文件版本号、CMYK色值、模切位置参数、油墨批次号、色差值ΔE、条码校验位等，部分字段带有单位，如色差值以ΔE为单位，印刷速度以米/分钟为单位。

## 这些特征在「引用来源与溯源」这一环带来什么约束
该品类的数据更新频率高且关联具体生产批次，要求引用溯源需精准绑定订单、批次或换版节点，避免跨批次引用失效。多源数据并存的特征，要求溯源环节区分不同来源的文档与检测数据，防止将印刷机运行数据与油墨配色记录混淆。文档包含版本号、色差值、条码校验位等带单位的字段，要求引用时需携带对应字段作为验证依据，仅引用文本无法支撑合规审核。印版错误会高速复制的特性，要求溯源结果可快速定位到具体版次与生产环节，缩短错误排查周期。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 字符 | 匹配单份印刷工艺单或拼版单的平均内容长度，完整覆盖核心审核信息 |
| `responseData` | 限定返回近 7 天的批次数据 | 贴合该品类按生产批次溯源的需求，避免跨周期数据干扰 |
| `detail` | 开启全字段展示 | 保留色差值ΔE、条码校验位等带单位的字段，支撑交叉审核的验证 |
| 单次召回上限 | 前 5 条 | 匹配单订单的核心文档数量，避免冗余结果稀释审核重点 |
| 来源标记开关 | 开启 | 明确标注色彩管理系统、印刷机数据等不同来源的引用内容 |

## 容易做错的三处
- 现象：引用结果中未包含油墨批次号字段，字段为空。原因：未开启`detail`配置项，仅返回了基础文本内容，未携带带单位的专属字段。
- 现象：知识库搜索时无法选择订单号变量作为检索条件，无可选值。原因：未将订单变量配置为节点输出参数，或未在检索配置中绑定对应变量源。
- 现象：引用内容超出审核范围，包含前一批次的拼版单数据。原因：未限定`responseData`的返回范围，导致跨批次数据被召回。

## 怎么确认配好了
- 上传一份测试用的油墨配色记录，检查引用结果中是否包含油墨批次号与色差值ΔE字段。
- 在检索配置中绑定订单号变量，触发检索后确认可选值列表包含测试订单的编号。
- 调整`quoteMaxToken`的取值，验证引用内容的长度是否随配置变化。
- 确认当前使用的FastGPT版本为v4.17.0，确保配置项的功能正常生效。
