# 印染与后整理的技术文档交叉审查：工作流编排

## 这个品类的数据长什么样
该品类的数据来自客户色样、配方库、染化料批次、染缸控制系统、测色仪、定形机与环保监测设备。日常生成的文档包含染色配方、称化料记录、染缸曲线、打样确认单、色差报告、定形工艺单与污水台账。数据更新频率为每缸、每批或每班，其中染色配方包含染料比例、助剂添加量等数值字段，染缸曲线记录每分钟的温度与压力参数，污水台账记录排放浓度与时长，字段与单位贴合湿化学加工的工艺要求。

## 这些特征在「工作流编排」这一环带来什么约束
高频次的批次数据更新要求工作流按生产节点触发，避免冗余执行。多源异构的数据格式需要工作流统一解析仪器导出的结构化数据与手工填写的文档扫描件。染缸曲线与色差报告的交叉校验需要实时拉取对应批次的关联数据，不宜延迟处理。湿化学加工的批次关联性要求工作流绑定染缸、染化料的批次维度，避免跨批次数据混淆。同时，环保监测数据的合规性校验需要与生产文档实时比对，确保数据同步。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，适配印染与后整理场景的工作流编排需求。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 全局变量 | 绑定染缸批次号、染化料批次号 | 匹配业务数据的关联维度，通过`variables`参数配置对应字段 |
| 数据库连接节点 | 填写对应端口号，按实测标定 | 适配染缸控制系统的专属端口配置 |
| 文件上传节点 | 允许上传JPG/PNG格式文件，单文件上限100 MB | 适配色样、色差报告的文件类型与大小限制 |
| 工具调用节点 | 选用qwen3.5-plus模型，并发请求上限前3条 | 降低请求超限报错概率 |
| 节点超时设置 | 600秒 | 适配染缸曲线的拉取与跨文档比对时长 |
| 节点ID配置 | 绑定对应数据库、工具调用节点的`nodeId` | 确保工作流节点的执行顺序与关联关系正确 |
| 工作流触发规则 | 按每班/每批生产任务触发 | 匹配数据更新的频率与生产节奏 |

## 容易做错的三处
- 数据库连接节点无法输入端口号，现象为界面端口输入框置灰或无响应，原因是未在`variables`中预先配置端口参数，或节点绑定的数据源未开放端口访问权限。
- 工具调用节点频繁返回429状态码，现象为日志中显示Request rate increased too quickly，原因是并发请求数量超过模型限流阈值，未设置合理的并发上限。
- 工作流无法触发文件上传功能，现象为上传按钮未显示或上传后无响应，原因是未开启节点的文件上传权限配置，或允许上传的文件类型未包含测试所需的图片格式。

## 怎么确认配好了
- 测试数据库连接节点，查看返回的染缸数据是否包含预设的批次关联字段，确认`variables`参数配置生效。
- 触发文件上传节点，上传测试用色样图片，确认节点可正常接收并解析文件内容。
- 模拟单批次生产任务触发工作流，查看工具调用节点的请求日志，确认未出现429报错。
- 检查全局变量的绑定值，确认与当前生产批次的染化料、染缸参数一致。
