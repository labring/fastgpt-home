# 变压器与高压电器制造的技术文档交叉审查：HTTP 接口与外部系统

## 这个品类的数据长什么样
变压器与高压电器制造的技术文档包括绕制与器身装配记录、真空干燥记录、绝缘油报告、局放和耐压试验报告、铭牌参数表。数据来源涵盖设计BOM、硅钢片和绝缘材料库存数据、真空与干燥设备运行数据、油化验结果、试验站测试数据。数据按每台产品、每批原材料更新，需关联唯一序列号实现单台追溯，核心字段包含绝缘间隙参数、微库仑级局放数值、摄氏度级干燥温度等，采用行业通用的专业计量单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的文档类型覆盖结构化报表与非结构化测试照片，且需绑定单台产品的唯一序列号，要求接口支持按序列号精准查询。数据更新频率随产品批次动态变动，接口需适配批量请求场景。核心数据来自多类工业设备与管理系统，需兼容不同系统的鉴权机制与数据格式。绝缘油报告、耐压试验照片等非结构化数据的传输，要求接口支持多类型文件上传与格式校验。单台追溯的需求也要求接口返回数据必须绑定唯一序列号，避免跨产品数据混淆。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本的接口模块设计：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | Bearer {企业内部统一鉴权令牌} | 匹配输配电设备企业的内部系统鉴权规范 |
| `variables` | 传入`{"serialNumber":"","materialBatch":""}` | 适配单台产品与批次材料的查询需求 |
| `responseData` | 仅返回`reportType,serialNumber,testResult`字段 | 减少无效数据传输，聚焦技术文档审查的核心信息 |
| 超时时间 | 600 秒 | 覆盖高压试验报告生成的常规耗时区间 |
| 单次请求最大文档数 | 前 3 条 | 匹配每批原材料对应的文档数量上限 |
| 重试策略 | 按实测标定 | 适配工业设备接口的不稳定响应特性 |

## 容易做错的三处
- 出现`400 Bad Request`报错，提示“unsupported media type”。原因是未在接口配置中指定绝缘油报告、耐压试验照片的允许格式范围，导致多模态调用失败。
- 接口调用后返回空`responseData`字段。原因是未正确映射变压器铭牌参数表的字段名，无法从外部系统提取有效审查数据。
- 接口调用触发全局超时后未执行重试。原因是未设置适配试验设备响应时长的超时阈值，直接终止请求流程。

## 怎么确认配好了
- 调用测试接口，传入单台变压器的有效序列号，检查返回的`responseData`是否包含预期的报告类型与序列号字段。
- 查看系统鉴权日志，确认`Authorization`头被正确携带并通过企业内部系统校验。
- 模拟批量文档请求，检查接口返回的文档数量是否符合配置的单次请求上限。
- 触发模拟超时场景，确认系统按照配置的重试策略执行重试操作。
