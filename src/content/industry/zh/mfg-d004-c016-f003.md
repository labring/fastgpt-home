# 变压器与高压电器制造的技术文档交叉审查：多轮对话与提示词

## 这个品类的数据长什么样
本品类的数据来源为设计BOM、硅钢片与绝缘材料台账、真空干燥设备日志、绝缘油化验报告、高压试验站记录。数据按单台产品或批次材料更新，日常文档包括绕制与器身装配记录、真空干燥记录、绝缘油报告、局放和耐压试验报告、铭牌参数表。单台产品文档包含绝缘结构参数、引线连接位置、分接开关档位、试验数据等字段，部分字段带有行业通用单位。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
数据按单台或批次更新的特性要求多轮对话需绑定对应产品ID或批次标识，避免跨产品数据混淆。多类文档的字段差异需要提示词明确区分不同文档类型的校验逻辑，比如绝缘油报告需核对性能参数，试验报告需匹配试验数据范围。单台产品的追溯需求要求对话上下文需保留单台产品的全部关联文档信息，避免上下文截断导致校验不完整。高压试验数据的专业性需要提示词限定校验范围为行业通用工艺要求，避免超出文档内容的无效推导。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 最大上下文长度 | 8000–12000 token | 适配FastGPT v4.17.0的上下文上限，匹配单台产品多份关联文档的总字符量，避免上下文截断 |
| `messages` 字段长度限制 | 每轮不超过 1800 字符 | 匹配单份专业文档的典型长度，保证单轮校验的完整性 |
| `variables` 绑定参数 | 绑定产品ID、批次号 | 对应数据按单台/批次更新的特性，实现数据精准关联 |
| `chatId` 绑定规则 | 绑定单台产品唯一标识 | 避免跨产品对话的上下文混淆，保障追溯准确性 |
| 单次召回文档上限 | 前5条 | 匹配单台产品的关联文档数量，避免冗余信息干扰 |
| 问题优化开关 | 开启 | 针对专业试验数据的校验需求，优化提问的精准性 |

## 容易做错的三处
- 调用删除对话记录的接口后返回成功，但`chatId`对应的对话仍保留。原因是未正确绑定目标对话的`chatId`参数，系统无法匹配到对应会话。
- 上传或读取绝缘油报告、耐压试验报告后，解析结果为空或报错。原因是未针对专业工程文档设置适配的解析逻辑，导致无法识别行业专属字段。
- 开启问题优化功能后，未生成与文档内容匹配的校验问题。原因是提示词未明确限定校验范围为变压器与高压电器的工艺参数，或未适配专业文档的提问逻辑，导致未生成有效校验问题。

## 怎么确认配好了
- 发起绑定产品ID的多轮对话，核对`variables`参数是否携带对应产品的标识信息，确认数据关联正确。
- 上传或读取飞书在线文档格式的试验报告，检查解析结果是否包含文档内的核心字段，确认数据源适配品类文档结构。
- 测试删除指定`chatId`的对话，确认接口返回与实际会话状态一致，确认会话绑定规则生效。
- 开启问题优化功能后发起校验提问，检查生成的回复是否围绕绝缘参数、试验数据等品类专属内容，确认提示词配置符合需求。
