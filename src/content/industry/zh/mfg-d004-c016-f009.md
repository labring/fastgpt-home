# 变压器与高压电器制造的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
本品类数据来源为设计BOM、硅钢片与绝缘材料台账、真空干燥设备日志、绝缘油化验报告、高压试验站记录。文档按生产批次或单台产品生成，包含绕制与器身装配记录、真空干燥记录、绝缘油检测报告、局放与耐压试验报告、铭牌参数表。数据更新随每台产品或每批原材料完成同步，字段包含绝缘距离、含水量、局放峰值、分接位置等，单位涵盖毫米、百分比、皮库仑。

## 这些特征在「模型接入与配置」这一环带来什么约束
单台产品全流程数据的追溯需求，要求模型接入时需绑定单台产品的专属数据集，避免跨批次数据混淆。多类型结构化与半结构化文档并存，需配置适配不同字段格式的模型调用规则。高频次的单台/批次数据更新，要求配置的索引与召回逻辑可快速同步最新数据。向量模型的匹配需聚焦单台产品的核心指标，避免无关数据干扰。核心指标如绝缘距离、局放值的校验精度直接关联产品安全，需约束模型输出的置信度与一致性，避免错误判定。

本配置指南适用于FastGPT v4.17.0版本。
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 企业专属代理地址 | 适配企业内部网络环境，避免公网访问限制 |
| `AIPROXY_API_TOKEN` | 企业分配的专属密钥 | 保障接口调用权限安全，防止未授权访问 |
| `maxContext` | 8000–12000 token | 适配单台产品多份文档的总内容长度，避免截断关键校验信息 |
| `temperature` | 0.1–0.3 | 降低随机输出概率，保障绝缘参数校验的一致性与准确性 |
| `quoteMaxToken` | 2000–3000 token | 限制召回文档的引用长度，聚焦单台产品的核心试验与装配数据，适配向量模型的匹配精度要求 |
| `toolChoice` | auto | 允许模型自动选择是否调用工具完成参数校验，适配多类型文档的交叉核对需求 |

## 容易做错的三处
- 调用返回404状态码，原因是`AIPROXY_API_ENDPOINT`配置为无效地址，或`AIPROXY_API_TOKEN`未正确配置。
- 校验任务返回500内部错误，原因是`maxContext`取值超出模型支持的上下文上限，导致上下文溢出。
- 召回的文档与当前校验产品不匹配，原因是未绑定单台产品专属数据集，导致跨批次数据混入。

## 怎么确认配好了
- 调用测试接口，检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置是否与预设值一致，确认接入通道正常。
- 上传单台变压器的全套文档，触发交叉审查任务，核对召回的文档是否仅包含该台产品的相关数据，无跨批次数据混入。
- 查看模型输出的校验结果，确认参数匹配逻辑符合业务规则，无明显的随机偏差。
- 模拟多次数据更新操作，检查索引同步是否及时，无数据延迟或遗漏。
