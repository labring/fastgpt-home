# 变压器与高压电器制造的技术文档交叉审查：部署与升级

## 这个品类的数据长什么样
本品类数据来自设计BOM、硅钢片与绝缘材料采购数据、真空干燥设备日志、绝缘油化验报告、高压试验站记录，以及单台产品的绕制装配、真空干燥、铭牌参数等文档。数据按每台产品或每批原材料更新，文档包含明确的物理参数字段，如绝缘厚度（单位为mm）、干燥温度（单位为℃）、试验电压（单位为kV），每份文档绑定唯一产品序列号，需关联多环节的交叉校验数据以完成审查。

## 这些特征在「部署与升级」这一环带来什么约束
单台产品按批次更新的数据特征，要求部署环节配置支持低延迟的小批量数据写入，避免批量索引任务占用过多资源；多类型文档的跨环节关联需求，需在部署时预置字段匹配规则，适配绝缘油报告、试验记录等不同文档的字段结构；唯一产品序列号作为核心关联标识，需配置固定的字段校验逻辑，防止数据绑定错误；高精度物理参数的存储需求，要求部署时预留足够的存储空间与内存资源，适配大数值字段的解析与索引。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://fastgpt:xxxx@localhost:27017/fastgpt?authSource=admin` | 适配多环节文档的关联存储，支持按产品序列号快速查询交叉校验数据 |
| `REDIS_URL` | `redis://:xxxx@localhost:6379/1` | 缓存高频读取的绝缘参数与试验结果，降低数据库并发压力 |
| `DB_MAX_LINK` | `25 个` | 适配每台产品的多文档高频更新场景，避免连接池资源耗尽 |
| `FE_DOMAIN` | `https://transformer-manufacture.example.com` | 配置合规的访问域名，满足工业场景的安全访问要求 |
| `STORAGE_S3_ENDPOINT` | `http://192.168.1.100:9000` | 存储大体积的绝缘油化验报告、耐压试验记录等文件，适配品类的文档存储需求 |

## 容易做错的三处
-  现象：部署后服务器磁盘空间快速耗尽，通过docker volume ls命令可发现大量未清理的临时解析文件。原因：未配置定期清理任务，品类的大体积高压试验报告解析会产生大量临时缓存数据。
-  现象：前端页面无法通过自定义域名访问，浏览器返回不安全连接提示。原因：未正确配置`FE_DOMAIN`与SSL证书的绑定关系，未将容器内部端口映射到443端口。
-  现象：索引构建失败，控制台返回未找到指定嵌入模型的报错。原因：未使用FastGPT v4.17.0支持的官方嵌入模型标识，错误配置了非标准的模型名称参数。

## 怎么确认配好了
-  执行数据库连接测试命令，验证`MONGODB_URI`与`REDIS_URL`的配置是否可正常建立连接。
-  上传一份绝缘油报告文档，检查是否能正常存储到指定的对象存储路径，验证`STORAGE_S3_ENDPOINT`的配置有效性。
-  发起一次小批量的文档索引任务，查看数据库连接数是否在`DB_MAX_LINK`的配置范围内。
-  访问配置的`FE_DOMAIN`，验证前端页面可正常加载且无安全证书报错。
