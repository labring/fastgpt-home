# 喷涂与涂装的技术文档交叉审查：向量模型与索引

## 这个品类的数据长什么样
这个品类的数据来自涂料供应商TDS/SDS、喷房与烘炉运行数据、色差仪、膜厚仪、环境监测设备及MES系统。日常文档包含涂装工艺卡、涂料批次单、调漆记录、膜厚色差报告、烘炉曲线、缺陷返修单、VOCs台账。数据更新频率随每批涂料、每班生产及连续采集的设备数据调整，文档多包含工艺参数、批次标识、检测数值、环境记录等字段，无统一固定格式，随生产批次与检测项变化。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类多源、高频更新的文档特征，对向量模型与索引环节带来多重约束。多类型文档混合存在，包含纯文本工艺说明、结构化检测数据、时间序列运行曲线，需适配不同内容长度的分块规则，避免关键参数被截断。高频更新的批次数据与连续采集的设备数据，会快速积累大量增量内容，需支持增量索引以避免全量重建的资源消耗。同时，工艺参数与外观缺陷、固化效果的关联分析需求，要求索引保留跨文档的关联特征，提升匹配精度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配涂装工艺卡、调漆记录等文档的平均内容长度，避免单块包含跨工序无关信息 |
| 重叠长度 | 100–200 字符 | 保留相邻分块的工艺关联信息，避免匹配时割裂调漆黏度与喷涂参数的关联 |
| 相似度阈值 | 0.75–0.85 | 匹配涂装工艺与缺陷报告的关联特征，过滤低相关性的非工艺类文档 |
| 单次召回上限 | 前 10 条 | 控制单次检索返回的文档数量，适配喷涂工序的多参数匹配需求 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| `defaultToken` | 200 token | 用于短文档的标准化分块，适配涂料批次单、VOCs台账等短内容文档 |

## 容易做错的三处
- 现象：服务器因大量文件上传崩溃重启后，知识库状态卡在「未就绪」，无自动索引触发，界面显示索引进度为空。原因：未开启增量索引的自动恢复配置，全量索引任务因重启中断后未自动续接，短文件的批量上传未触发断点续传。
- 现象：升级FastGPT v4.17.0后，原有已创建索引的知识库无法返回检索结果，搜索结果为空。原因：版本更新后向量模型的嵌入维度发生变更，原有索引的向量特征与新模型不匹配，未触发自动重索引。
- 现象：索引任务超时，界面显示「索引失败」报错。原因：未调整`defaultToken`与`maxToken`的取值，长文档如烘炉曲线的分块拼接超出系统限制，导致索引任务超时。

## 怎么确认配好了
- 上传单份典型文档（如涂装工艺卡）至FastGPT v4.17.0平台，查看分块预览界面，确认分块长度符合预设取值，无关键内容截断。
- 触发一次增量索引任务，等待任务完成后查看索引统计面板，确认已索引的文档数量与上传数量一致。
- 输入工艺相关的检索词，查看返回结果的数量与相关性，调整相似度阈值至符合业务需求的区间。
- 重启FastGPT服务后，查看知识库状态，确认自动恢复索引任务正常启动，无需手动触发。
