# 基础化工连续生产的技术文档交叉审查：多轮对话与提示词

## 这个品类的数据长什么样
基础化工连续生产的日常文档包含操作规程、工艺指标卡、DCS趋势、化验报告、联锁旁路记录、特殊作业票、班报。数据来源为DCS/SIS系统、在线分析仪、LIMS系统、设备状态监测、能源计量装置、原料储罐传感器。数据更新频率涵盖实时、每班、每日。文档字段包含工艺温度（℃）、压力（MPa）、联锁动作阈值、班次编号、化验结果数值等，部分文档附带标准化单位标识。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
该品类的数据来源分散且更新节奏差异大，实时类数据需在多轮对话中限制`messages`的历史长度，避免历史消息过载。文档字段存在专业单位与固定格式，提示词需明确要求匹配对应单位与字段结构，防止输出偏差。多类文档需按更新频率分类调用，提示词需限定会话仅使用当前班次或实时的文档数据。此外，强联锁相关文档的审查需保留历史对话的上下文关联，需通过`chatId`绑定对话历史。本配置适用于FastGPT v4.17.0版本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 匹配工艺指标卡、DCS趋势单页的内容长度，避免块内专业信息割裂 |
| 单次召回上限 | 前6条 | 覆盖当班班报、化验报告、联锁记录的典型数量，避免冗余信息干扰 |
| 最大上下文窗口 | 4000 token | 限制多轮对话的历史消息长度，适配基础化工文档的单次交互信息量 |
| `variables` | 预设为「基础化工连续生产技术文档审查」 | 明确提示词的应用场景，过滤无关知识库内容 |
| `chatId` | 绑定会话唯一标识 | 保留多轮对话的历史联锁、工艺参数上下文，避免会话中断后信息丢失 |
| 输入引导开关 | 开启 | 辅助提炼现场工程师的口语化提问，匹配基础化工场景的专业问题类型 |

## 容易做错的三处
- 现象：对话界面无法复述上传的工艺指标xlsx文件内容，返回无法读取的提示。原因：未针对基础化工xlsx文档（含工艺温度、压力、联锁阈值字段）配置专属解析规则，默认解析逻辑无法识别专业字段结构。
- 现象：开启输入引导并配置词库后，对话界面未显示预设的专业提问。原因：输入引导的配置未绑定当前场景的`variables`参数，或词库未覆盖基础化工的典型提问关键词。
- 现象：多轮对话中模型输出的联锁旁路记录与当前当班数据不符。原因：未在提示词中限定仅调用当前会话关联的实时或当班文档，错误调用了历史会话的旧数据。

## 怎么确认配好了
- 上传一份包含工艺温度（℃）、压力（MPa）的xlsx工艺指标文档，发起提问“请复述这份文档的核心指标”，确认模型能返回对应字段及单位。
- 开启输入引导后，刷新对话界面，确认显示的预设问题包含“联锁旁路检查”“DCS趋势核对”等基础化工场景关键词。
- 发起两轮连续提问，第一轮询问当班班报内容，第二轮询问该班的联锁状态，确认模型能关联两轮的上下文给出对应结果。
- 查看知识库配置，确认`variables`参数已设置为“基础化工连续生产技术文档审查场景”，无无关场景的配置残留。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
