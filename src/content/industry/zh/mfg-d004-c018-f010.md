# 基础化工连续生产的技术文档交叉审查：知识库检索与召回

## 这个品类的数据长什么样
本品类数据主体为氯碱、合成氨、甲醇、纯碱等基础化工企业的生产相关文档。日常文档涵盖操作规程、工艺指标卡、DCS趋势、化验报告、联锁旁路记录、特殊作业票、班报。数据来源包括DCS/SIS系统、在线分析仪、LIMS系统、设备状态监测、能源计量系统、原料储罐数据。更新节奏分为实时（如DCS趋势）、每班（如班报）、每日（如化验报告）。文档包含明确的工艺参数字段，如温度单位为℃、压力单位为MPa、流量单位为m³/h，时序类文档带时间戳，表格类文档含固定表头与数值行。

## 这些特征在「知识库检索与召回」这一环带来什么约束
本品类的多源异构数据、差异化更新节奏与高风险业务属性，对检索召回环节形成多重约束。实时更新的DCS趋势与班报数据，需配置增量同步机制以保证知识库内容与生产现场一致。多类型文档覆盖结构化表格、时序数据与非结构化文本，需适配混合检索模式以覆盖不同格式的内容。强联锁相关文档的召回精度直接关联生产安全，需设置较高的匹配阈值过滤低相关性结果。按生产单元划分的文档体系，要求检索范围限定在对应车间或工艺线，避免跨单元的无关内容干扰审查。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 基础化工文档包含强联锁参数，需过滤低匹配度结果，避免误召回无关工艺内容 |
| `limit` | 前8条 | 单批次召回量适配班报、工艺卡的短文本特征，避免上下文过长影响审查效率 |
| `searchMode` | hybrid | 支持结构化数据（DCS趋势、化验报告）与非结构化文本的混合检索，覆盖多类型文档 |
| `usingReRank` | 开启 | 针对联锁旁路记录等高风险文档，通过重排提升关键内容的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于工艺术语扩展查询，覆盖DCS/SIS中的专业缩写，比如“PV”对应“过程变量” |
| `collectionIds` | 按车间/工艺线划分 | 匹配基础化工按生产单元划分的文档体系，缩小检索范围，提升召回精度 |

本配置适用于FastGPT v4.17.0版本。

## 容易做错的三处
- 上传工艺指标卡文件后检索结果为空。原因是未将对应文档添加至指定`collectionIds`集合，导致检索范围未覆盖目标文档。
- 调用知识库添加内容接口返回403状态码。原因是未配置内网访问的反向代理权限，导致接口调用被拦截。
- 表格数据（如化验报告）检索时仅返回表头，无具体数值。原因是未开启表格多向量支持，无法拆分表格单元格内容进行召回。

## 怎么确认配好了
- 上传一份对应车间的联锁旁路记录，验证检索结果包含关键联锁编号与处置步骤。
- 进入FastGPT知识库设置页面，确认表格多向量支持功能已开启。
- 访问内网`https://域名:3000`，验证可正常上传文件并调用知识库添加接口。
- 查看数据库存储日志，确认训练后的文档已写入对应租户的知识库表。
