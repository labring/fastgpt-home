# 塑料注塑成型的技术文档交叉审查：工作流编排

## 这个品类的数据长什么样
塑料注塑成型的业务数据来源包括树脂批次物性表、注塑机参数、模温机、MES系统、尺寸与外观检测设备。日常文档涵盖注塑工艺卡、原料干燥记录、模具履历、首件检验表、巡检表、换料清机记录。数据更新频率为每生产批次、每次换模换料、每班一次。文档字段包含干燥温度（℃）、充填压力（bar）、冷却时长（秒）、模腔数、模次（模）等，各文档绑定对应生产环节的唯一标识，数据格式覆盖PDF、Excel、CSV及结构化导出文件。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的数据特征对工作流编排带来多重约束。首先，数据更新频率高且绑定生产节点，要求工作流触发时机需匹配换模、换料或定时拉取的节奏，避免无效执行。其次，文档类型与格式多样，要求工作流支持多格式文件的导入与解析，适配不同来源的业务数据。再者，字段带有明确的单位与业务含义，要求工作流的`variables`配置需统一字段校验规则，避免参数混乱。最后，出错会导致批量不良或安全问题，要求工作流需配置失败重试与异常告警节点，保障审查流程的可靠性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 触发时机 | 按换模/换料事件触发，或每8小时批量扫描 | 匹配数据每批次、换模换料、每班的更新频率 |
| 变量配置（`variables`） | 绑定干燥温度（℃）、充填压力（bar）、冷却时长（秒）等字段 | 适配品类文档的固定字段与单位规则 |
| 节点超时设置 | 600秒 | 覆盖设备数据同步与多文档解析的平均耗时 |
| 多变量更新聚合 | 按`nodeId`绑定统一AI回复节点 | 实现多环节审查结果的汇总输出 |
| 文件上传配置 | 支持本地文件导入与链接引用 | 适配本地部署与云端数据来源的场景 |

## 容易做错的三处
- 现象：工作流中无法找到已配置的账号模型。原因：未在工作流的模型节点中选择对应绑定的账号模型，或未完成FastGPT v4.17.0版本适配的模型同步。
- 现象：HTTP请求节点接收文件后，后台接口返回解析失败。原因：未将文件内容转换为JSON格式的POST请求体，或未正确配置请求头的Content-Type。
- 现象：多个变量更新节点的结果无法汇总到单个AI回复。原因：未将各变量更新节点的`nodeId`绑定到同一个聚合输出节点，导致流程分支未统一。

## 怎么确认配好了
- 手动触发一次换模事件对应的工作流，检查是否能拉取对应模具履历、注塑工艺卡等关联文档数据。
- 打开工作流的模型节点配置面板，确认已配置的账号模型正常显示并可选中，验证模型调用无报错。
- 上传本地注塑工艺卡文件至HTTP请求节点，检查后台接口是否能正确接收并解析请求体内容。
- 查看多变量更新节点的输出日志，确认所有环节的字段数据都能汇总到绑定的AI回复节点。
