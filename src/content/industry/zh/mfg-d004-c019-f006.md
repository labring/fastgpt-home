# 塑料注塑成型的技术文档交叉审查：引用来源与溯源

## 这个品类的数据长什么样
该品类的日常文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验、巡检表、换料清机记录。数据来源涵盖树脂批次和物性表、注塑机参数、模温机、MES系统、尺寸和外观检测结果。数据更新频率为每批生产、每次换模换料、每班巡检后更新。单份文档包含专属字段，如工艺卡标注充填保压冷却窗口参数，干燥记录记录原料干燥温度与时长，模具履历标注模次与维护时间。

## 这些特征在「引用来源与溯源」这一环带来什么约束
由于数据按生产批次、换模换料节点更新，溯源环节需精准绑定生产批次与对应文档，避免跨批次数据混淆。多类文档的专属字段差异较大，需配置匹配规则关联同批次的工艺、干燥、模具等数据。出错后果涉及批量尺寸外观不良、模具损伤或混料安全问题，因此溯源需确保引用数据的准确性与时效性。同时，材料含水与模温敏感的特性，要求干燥记录与注塑机参数的引用必须精准对应，否则会直接影响生产结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配注塑工艺卡、原料干燥记录的单段内容长度 |
| 重叠长度 | 100–150 字符 | 避免跨换模批次的内容割裂，确保同批次文档的上下文连贯 |
| 单次搜索上限 | 前5条 | 匹配同批次的多类文档，如工艺卡、巡检表与模具履历 |
| `quoteMaxToken` | 1200 token | 限制单条引用的内容长度，防止输出冗余信息 |
| `responseData` | 开启 | 保留引用文档的原始元数据，便于关联生产批次与时间 |
| `detail` | 开启 | 展示引用文档的具体字段，如树脂牌号、模温参数等专属信息 |

## 容易做错的三处
- 对话界面底部展示冗余的引用文件列表，原因是未关闭「自动展示引用来源」的配置项，导致非必要的文档被列出。
- 引用内容缺失原料干燥的关键参数，原因是未将原料干燥记录纳入关联的知识库集合，或分块长度设置过小导致干燥记录的内容被截断。
- 搜索结果仅匹配到模具履历而未关联注塑机参数，原因是未配置按生产批次的时间范围过滤规则，导致跨批次的数据被召回。

## 怎么确认配好了
- 在FastGPT v4.17.0环境中，上传单批次的注塑工艺卡、原料干燥记录和模具履历，发起工艺合规性提问，查看引用列表是否仅包含该批次的文档。
- 点击引用列表的展开按钮，确认是否显示树脂牌号、模温参数、生产时间等专属字段。
- 调整`quoteMaxToken`的取值，验证单条引用的内容长度是否发生对应变化。
- 发起涉及混料风险的提问，确认引用的树脂物性表数据与当前生产批次的原料牌号一致。
