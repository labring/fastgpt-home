# 塑料注塑成型的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来自树脂批次物性表、注塑机运行参数、模温机数据、MES系统、尺寸外观检测记录，以及注塑工艺卡、原料干燥记录、模具履历、首件检验表、巡检表、换料清机记录。数据更新随每批生产、每次换模换料、每班作业触发，文档多为带固定字段的表单格式，字段包含树脂牌号、干燥温度、保压时长、模温、尺寸公差等，对应单位为摄氏度、秒、兆帕、毫米等。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的多源高频更新数据，要求模型接入需支持多格式文档的批量同步，避免因数据更新滞后导致审查结果偏差。表单类文档的固定字段结构，要求配置需适配结构化数据的精准提取，避免非结构化解析的误差。单批次数据关联紧密的特性，要求上下文配置需保留批次内的全量关联信息，同时需控制单轮处理的负载，防止因数据量过大导致超时。此外，安全与质量相关的审查需求，要求配置需锁定高置信度的数据源关联规则。本文基于FastGPT v4.17.0版本的配置逻辑展开说明。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 匹配单批次注塑生产关联的多文档总长度，避免截断批次内的关键关联信息 |
| `maxTokens` | 4000–6000 token | 适配单轮审查的输出需求，覆盖工艺参数校验、缺陷分析的完整结论生成 |
| `temperature` | 0.1–0.3 | 降低随机输出，保证缺陷判定、参数合规性审查的结果一致性 |
| `AIPROXY_API_TOKEN` | 平台分配的专属密钥 | 确保接入权限的安全性，避免未授权访问影响生产数据审查 |
| `quoteMaxToken` | 1500–2000 token | 限定召回的文档片段长度，聚焦单批次内的核心工艺与检测数据 |
| 工作流/API 工具选择配置 | auto | 允许模型自动选择是否调用文档检索工具，适配多源数据的交叉校验需求 |

## 容易做错的三处
- 现象：对话窗口上传的注塑工艺文档未被纳入审查分析，输出结果未引用上传文件内容。原因：未配置`maxContext`参数覆盖上传文档的上下文长度，导致系统自动截断或忽略新增上传数据。
- 现象：部署70B大模型后，审查响应时长超过30秒，部分批次数据处理超时。原因：未调整`maxContext`与`maxTokens`参数适配大模型的负载，或未限定召回的文档数量导致输入token过载。
- 现象：通过iframe嵌入的审查页面在小程序环境中无法正常显示，弹出域名校验相关提示。原因：未使用平台支持的小程序适配接入逻辑，仍采用通用iframe嵌入方案。

## 怎么确认配好了
- 上传单批次的注塑工艺卡与检测记录，触发审查任务，核对输出结果是否包含上传文档中的具体参数与检测数据。
- 查看平台的token使用日志，确认输入token数未超过配置的`maxContext`与`maxTokens`阈值。
- 测试不同更新频率的文档上传，确认系统能自动同步最新的换料清机记录与模具履历数据。
- 模拟单批次全量数据的审查场景，核对响应时长是否符合业务场景的要求。
