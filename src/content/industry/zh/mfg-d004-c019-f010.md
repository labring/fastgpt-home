# 塑料注塑成型的技术文档交叉审查：知识库检索与召回

本文适配FastGPT v4.17.0版本。

## 这个品类的数据长什么样
该品类的日常文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验、巡检表、换料清机记录。数据来源包括树脂批次物性表、注塑机参数、模温机、MES系统、尺寸与外观检测数据。文档按生产批次、换模换料事件、每班更新，字段包含工艺参数（如充填保压冷却窗口时长、模温）、原料含水率、模具使用次数等，带有明确的工程单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
由于数据按生产批次、换模换料事件实时更新，知识库检索需支持按批次、模具ID过滤召回范围，避免跨批次无效数据干扰。文档包含带工程单位的工艺参数，召回时需匹配参数单位与查询条件的一致性，防止参数混淆。高频更新的巡检、换料记录要求检索链路支持增量同步，避免召回过期数据。同时，注塑工艺的故障分析需快速召回关联的模具、原料数据，对检索时延有明确要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配注塑工艺参数的精准度要求，避免低相关的故障分析数据混入 |
| `limit` | 前6条 | 控制单轮召回的文档数量，适配注塑工艺卡、模具履历等单文档内容较长的场景 |
| `searchMode` | `embedding` | 优先匹配工艺参数、设备参数的语义关联，支持跨文档的故障关联检索 |
| `usingReRank` | 开启 | 对召回结果按相关性重排，优化缩水、短射等注塑故障的检索排序 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展查询词，补充注塑工艺相关的同义词，如将“缩水”关联“收缩痕”“尺寸偏差” |
| `collectionIds` | 按模具/批次绑定的数据集ID | 限定检索范围为当前生产批次关联的知识库，避免跨批次数据干扰 |

## 容易做错的三处
- 现象：知识库检索能返回匹配结果，但传递给大模型后无有效输出。原因：未配置`datasetSearchUsingExtensionQuery`导致召回的文档格式不符合大模型上下文要求，或`limit`取值过高导致上下文溢出。
- 现象：创建知识库目录时传入父级ID，仍显示在根目录下。原因：未在`collectionIds`配置中绑定对应父级目录的数据集ID，或父级ID格式不符合FastGPT要求。
- 现象：单文档知识库检索耗时超过10秒。原因：未开启`usingReRank`导致召回结果过多，或`similarity`阈值设置过低导致召回大量无关文档。

## 怎么确认配好了
- 检索特定注塑工艺参数，查看召回结果是否仅包含当前生产批次的文档，验证`collectionIds`配置生效。
- 输入“缩水”查询，查看召回结果是否包含关联的原料干燥记录、模温数据，验证`datasetSearchUsingExtensionQuery`生效。
- 查看检索返回的结果数量是否与`limit`配置一致，验证参数配置准确。
- 测试跨模具ID的检索，确认仅召回对应模具的知识库数据，验证过滤逻辑正确。
