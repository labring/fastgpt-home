# 塑料注塑成型的技术文档交叉审查：部署与升级

## 这个品类的数据长什么样
本品类的核心数据覆盖注塑全流程文档与生产实时数据。日常文档包括注塑工艺卡、原料干燥记录、模具履历、首件检验表、巡检表、换料清机记录，单份文档包含工艺参数、原料批次、模具编号、检测结果等字段。数据来源涵盖树脂批次物性表、注塑机运行参数、模温机数据、生产执行系统（MES）及尺寸外观检测结果。数据更新随每生产批次、换模换料操作及每班巡检触发，无固定周期但与生产节奏强绑定。

## 这些特征在「部署与升级」这一环带来什么约束
本品类的生产数据与文档强绑定生产节奏，且多源异构，包含注塑机参数、模温数据等实时生产指标与工艺卡、模具履历等静态文档，部署时需适配多系统数据对接的兼容性要求。因数据更新随每生产批次、换模换料及每班巡检触发，存储配置需预留扩容空间以应对突发数据增量。升级过程需避免中断实时数据同步，否则可能导致生产环节文档缺失。同时，因数据出错会引发批量不良、模具损伤甚至安全问题，部署时需配置容错机制，确保异常数据不被直接导入审查流程。本页面基于FastGPT v4.17.0版本编写。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://fastgpt:password@mongodb:27017/fastgpt?authSource=admin` | 适配多源生产数据的存储需求，支持大吞吐量的文档读写 |
| `REDIS_URL` | `redis://:password@redis:6379/0` | 缓存高频访问的工艺参数与模具履历，降低数据库负载 |
| `STORAGE_S3_ENDPOINT` | `http://192.168.1.200:9000` | 对接本地存储介质作为文档存储载体，适配私有化部署场景 |
| `FE_DOMAIN` | `http://192.168.1.100:3000` 或 `https://your-frp-domain.com` | 适配私有化部署的访问路径，支持公网穿透后的正常访问 |
| `FILE_TOKEN_KEY` | `随机生成的32位字符串` | 保障文档上传与访问的安全性，避免未授权访问生产文档 |

## 容易做错的三处
- 配置`STORAGE_S3_ENDPOINT`时填写错误的存储端口，例如误将飞牛NAS的9000端口写成80，导致文档上传失败，返回404状态码。原因是未核对本地存储的实际服务端口，直接使用通用默认值。
- 升级时未同步更新docker-compose文件中的`REDIS_URL`环境变量，导致缓存的工艺参数过期，审查结果出现旧数据。原因是忽略了缓存配置与生产数据的绑定关系。
- 未将`FE_DOMAIN`配置为FRP穿透后的公网域名，导致外部访问时静态资源加载失败，界面无法正常展示审查结果。原因是混淆了内网访问地址与公网穿透地址。

## 怎么确认配好了
- 执行docker compose up命令后，查看容器运行日志，确认`MONGODB_URI`、`REDIS_URL`等配置项无连接报错。
- 上传一份注塑工艺卡文档，验证文档可以正常存储并在审查流程中被正常索引。
- 通过配置的内网或公网访问地址访问平台，确认界面可以正常加载且文档预览功能无异常。
- 触发一次模拟的文档交叉审查，确认返回的结果包含对应生产数据的相关字段。
