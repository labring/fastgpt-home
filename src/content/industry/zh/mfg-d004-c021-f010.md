# 家具与木制品制造的技术文档交叉审查：知识库检索与召回

## 这个品类的数据长什么样
该品类主体为板式家具、实木家具、定制家居和木门企业，日常技术文档包含拆单图、开料清单、封边与钻孔程序、涂装工艺文件、五金清单、试装与包装记录。数据来源覆盖订单设计系统、板材与木材批次台账、数控生产设备、ERP/MES系统、板材含水率检测设备。数据更新按订单生成即时同步、每日同步批次生产数据、每批材料检测后更新含水率信息。文档字段包含板件尺寸、孔位坐标、板材规格、五金型号、工艺参数等，字段单位多为毫米、立方米、件等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源要求检索需支持跨业务集合的精准筛选，避免混入无关系统的文档。高频更新节奏要求召回机制适配增量同步逻辑，确保最新的板材批次、订单拆单数据可被快速检索。多类型文档混合的结构，包括结构化清单与非结构化工艺说明，要求检索配置兼顾不同格式的文本与元数据匹配。定制化订单驱动的业务模式，要求检索可关联订单维度的元数据，精准定位对应订单的生产文档。板件尺寸、孔位等高精度字段的匹配需求，要求检索的相似度阈值需设置在合理区间，避免低相关结果干扰审查流程。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配板件尺寸、孔位坐标等高精度字段，过滤低相关的检索结果 |
| `limit` | 前10条 | 覆盖单定制订单的板件数量，避免检索结果过载影响审查效率 |
| `searchMode` | 混合检索 | 适配文本类工艺文档与拆单图关联的元数据文本，兼顾结构化与非结构化内容 |
| `usingReRank` | 开启 | 对检索结果进行重排，优先展示与板件尺寸、五金匹配度更高的文档 |
| `collectionIds` | 按业务模块分组配置 | 区分拆单数据、工艺文档、ERP台账等集合，缩小检索范围 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充订单号、板材批次号等元数据查询，关联跨系统的关联文档 |

## 容易做错的三处
- 搜索返回结果包含非目标业务模块的文档，比如涂装工艺文档混入拆单数据。原因是未通过`collectionIds`参数指定需要检索的集合范围，导致检索覆盖了无关的知识库集合。
- 检索结果仅返回文本摘要，无法获取原始文档的完整链接。原因是未开启`datasetSearchUsingExtensionQuery`配置，或未关联原始文档的元数据链接信息。
- 上传的MD格式技术文档中图片路径无法正确加载，界面显示图片占位符或报错。原因是未将本地图片文件同步上传至知识库存储目录，或引用路径未适配知识库的文件存储规则。

## 怎么确认配好了
- 执行测试检索，输入板件尺寸关键词，检查返回结果是否仅包含目标业务集合的文档。
- 选择一条检索结果，点击链接验证是否能跳转至原始文档页面，确认完整内容可被访问。
- 上传包含本地图片的MD测试文档，检查图片是否正常加载显示，无占位符或报错。
- 调整`similarity`参数值后重新检索，观察结果条数与相关性的变化是否符合预期。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
