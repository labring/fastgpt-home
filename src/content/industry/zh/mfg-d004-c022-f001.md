# 家用电器整机制造的技术文档交叉审查：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据来源涵盖ERP/MES系统、零部件批次台账、拧紧与充注设备、安规测试仪、性能实验室数据及售后故障记录。日常文档包含配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告与返修记录。数据按单台产品、每班生产批次或抽检计划更新，字段包含零部件批次号、拧紧扭矩值、制冷剂充注量、测试电压、故障编码等，附带对应物理单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
单台/每班的高频小批量数据更新，要求HTTP接口支持高并发低延迟的请求处理，避免阻塞生产环节。多类型文档的差异化字段结构，要求接口支持动态接收不同业务字段，适配BOM、测试报告等不同文档的参数格式。多设备与系统的数据来源，要求接口兼容标准化的认证与数据格式转换，确保跨系统数据同步的一致性。混线装配的场景要求接口传递精准的产品型号与批次标识，避免不同型号文档交叉混淆。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `Authorization` | `Bearer {FastGPT 分配的 API 密钥}` | 遵循FastGPT官方API认证标准，确保接口调用的合法性 |
| `variables` | `{"product_model": "", "batch_no": "", "collection_id": ""}` | 传递家电整机的型号、批次号与目标集合ID，精准匹配对应技术文档 |
| `responseData` | `返回匹配文档列表与合规校验标记` | 精简返回内容，适配生产系统的低延迟处理需求，避免冗余数据占用带宽 |
| 单次请求最大数据量 | `50 条/次` | 适配单台/每班的小批量数据上传场景，避免请求过载 |
| 回调地址超时时间 | `30 秒` | 匹配生产设备的响应等待周期，防止回调失败导致生产中断 |

## 容易做错的三处
- 调用API上传技术文档至指定集合后，集合列表中未出现对应文档。原因：请求参数未正确传递目标集合的标识信息，导致文档被分配至默认集合或未完成绑定。
- 接收回调的系统日志显示返回数据中缺失AI审查的思考过程内容。原因：初始API请求未配置对应参数启用思考过程输出，FastGPT仅返回最终审查结果。
- 调用API删除集合内的文档数据时返回403状态码。原因：`Authorization`参数未正确携带有效密钥，或密钥权限未配置为可执行删除操作。

## 怎么确认配好了
- 调用测试接口上传一份标准家电装配作业书，查看知识库对应集合是否成功收录该文档。
- 发起模拟审查请求，检查返回的`responseData`中是否包含预期的文档匹配结果与校验标记，匹配规则可根据实际业务需求设定。
- 配置回调地址后，触发一次模拟生产数据上传，查看回调接口是否收到完整的请求响应数据，响应字段可根据业务场景调整。
- 更换不同的API密钥进行调用测试，确认`Authorization`参数的认证逻辑正常生效，权限范围可按需配置。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
