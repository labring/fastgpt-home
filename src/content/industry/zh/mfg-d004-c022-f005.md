# 家用电器整机制造的技术文档交叉审查：工具调用与插件

## 这个品类的数据长什么样
该品类的日常文档包含配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告及返修记录。数据来源覆盖ERP/MES系统、零部件批次台账、拧紧与充注设备日志、安规测试仪数据、性能实验室检测结果及售后故障档案。数据更新节奏按单台产品、每班生产批次或抽检计划执行，单条数据包含零部件型号、工艺参数、检测结果、批次编号等字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类多型号混线装配的业务场景，要求工具调用需精准匹配单台产品的专属BOM与工艺参数，避免跨批次数据混淆。高频更新的设备日志、抽检报告与返修记录，要求工具调用支持实时拉取最新数据源，避免使用过期文档。多来源的数据需要插件统一对接ERP/MES、检测设备及售后档案，且需校验字段一致性，确保交叉审查的准确性。同时，跨文档关联安规、性能与返修数据的需求，要求工具调用通过`toolChoice`指定专属工具集，支持多文档并行检索与字段匹配。

## 配置怎么定
以下配置适配FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | 指定家电制造文档审查专属工具集 | 该品类需调用多类设备与文档数据，指定工具集避免无关调用干扰审查流程 |
| 工作流/API 函数调用配置 | 强制按预设参数触发 | 混线生产需严格匹配单台产品的工艺参数，避免自由调用导致的参数混乱 |
| 工具调用超时时间 | 300–600 秒 | 多数据源拉取需覆盖设备日志、ERP数据，耗时较长，按实测标定调整 |
| 单次工具调用返回条数 | 前8条 | 单台产品的关联文档数量集中在5-10条范围内，过多会增加上下文负担 |
| 插件触发规则 | 按产品批次ID触发 | 混线生产需按批次隔离数据，避免跨批次数据混同 |

## 容易做错的三处
- 现象：工具调用返回结果包含非当前批次的零部件数据，批次编号或工艺参数不符。原因：未配置按产品批次ID触发的插件规则，导致跨批次数据混同，引发混线错装风险。
- 现象：流程编排中工具调用节点后无终止标记，持续触发后续工具调用导致超时。原因：未在流程末尾添加工具调用终止节点，系统按编排逻辑循环调用工具，超出预设耗时阈值。
- 现象：自定义卡片无法在界面展示，调用插件后无返回内容。原因：插件未配置正确的数据源接口权限，或未绑定到工具调用节点，导致数据无法正常传递。

## 怎么确认配好了
- 上传单台家电的BOM与装配作业书，触发工具调用，核对返回结果仅包含当前批次的文档数据。
- 查看流程编排节点，确认工具调用节点后已添加终止标记，无循环调用风险。
- 启用自定义卡片插件，触发工具调用后确认界面展示预设的文档审查卡片。
- 测试超时场景，确认工具调用在300–600秒内完成返回，无长时间挂起。
