# 工业仪器仪表制造与校准的技术文档交叉审查：文档解析与分块

## 这个品类的数据长什么样
本品类的典型主体为流量、压力、温度类仪器制造商及计量实验室，日常文档包含装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录。数据来源涵盖设计文件、标准器监测数据、校准软件、实验室信息系统及客户量程要求，更新频率为每台仪器每次校准。文档包含结构化表格、计量数值、溯源编号及可视化误差曲线，字段多附带专用单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
文档包含结构化表格与可视化误差曲线，要求解析环节准确拆分表格并保留图文关联；更新频率高且批量导入场景多，需适配快速解析与批量处理逻辑；字段含特定计量单位与溯源编号，分块需保留上下文关联避免破坏数据溯源逻辑；同时需兼容PDF、Excel、DOC等多种文档格式，需分别适配不同格式的解析规则，避免丢失sheet页或图片原图。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配包含计量单位、溯源编号的短字段与长校准规程文本，避免拆分破坏误差曲线描述的上下文关联 |
| `chunkSplitter` | 按段落+表头分隔 | 适配原始校准记录的结构化分段，保留Excel表格的sheet页名称关联 |
| `customPdfParse` | 开启 | 保留PDF格式校准证书、误差曲线中的原图内容，避免OCR解析后丢失图片 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 适配批量导入含10万条数据的Excel原始记录，避免解析超时中断 |
| `chunkSettingMode` | 按文档类型定制 | 针对计量证书、误差曲线PDF分别调整分块规则，适配不同文档结构 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配批量导入多份校准记录文档，避免因文件大小限制无法上传 |

## 容易做错的三处
- 现象：上传PDF格式的误差曲线文档后，解析结果仅包含OCR识别的文本，无原始误差曲线图片。原因：未开启`customPdfParse`配置，默认解析模式会剥离原图仅保留文本内容。
- 现象：Excel格式的原始校准记录导入后，无法读取sheet页名称，仅加载第一个sheet的数据。原因：未配置`chunkSplitter`按表头分隔，未启用sheet页关联解析规则。
- 现象：导入DOC格式的校准规程并勾选PDF增强后，解析结果无变化。原因：PDF增强配置仅对PDF格式文档生效，未适配DOC文档的解析逻辑。

## 怎么确认配好了
- 上传单份PDF格式的误差曲线文档，检查解析结果是否包含原图预览。
- 上传包含多个sheet页的Excel原始校准记录，检查解析结果是否显示对应sheet页的名称。
- 上传DOC格式的校准规程文档，确认勾选PDF增强后解析逻辑是否适配文档结构。
- 导入含10万条数据的Excel文档，检查解析过程是否未触发超时报错。
