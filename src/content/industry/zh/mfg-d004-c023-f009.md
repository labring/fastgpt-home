# 工业仪器仪表制造与校准的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
本品类数据来源于设计文件、标准器与环境监测数据、校准软件、实验室信息系统及客户量程要求。日常生成的文档包含装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录，每台设备每次校准后数据即更新。数据字段包含设备量程、误差计算值、校准日期、计量证书编号等，单位多为物理量标准单位，如帕斯卡、摄氏度、百分比等。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类数据的高频更新特性要求模型接入配置支持增量同步与快速索引更新；多类型文档（含数值曲线、证书文本）的混合结构，要求配置适配非结构化与半结构化数据的分块与解析逻辑；校准记录作为核心交付物的属性，要求配置严格控制召回文档的溯源准确性与引用范围；数据来源包含本地校准软件与实验室系统，要求配置支持本地部署模型的对接参数设置，同时适配不同数据源的格式差异。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 本品类文档包含误差曲线、校准记录等长文本，需足够上下文支撑交叉审查逻辑 |
| `quoteMaxToken` | 2000–3000 token | 校准证书、原始记录等核心交付物文档需完整引用，避免截断关键溯源信息 |
| `temperature` | 0.1–0.3 | 技术文档交叉审查需保持严谨输出，降低随机性偏差 |
| `AIPROXY_API_ENDPOINT` | 按本地部署模型路径填写，如`http://localhost:11434/api` | 适配本地部署的大模型对接需求，匹配本品类常用的本地部署方案 |
| `AIPROXY_API_TOKEN` | 留空或填写本地模型认证令牌 | 多数本地部署大模型无需额外认证令牌，避免配置错误导致连接失败 |
| `maxTokens` | 4000–6000 token | 控制单轮审查结果的输出长度，适配大模型的上下文窗口限制 |

## 容易做错的三处
- 现象：在线召回测试时未显示重排后的结果，配置项中已开启Rerank且索引时启用。原因：未在应用的模型接入配置中关联重排模型，或重排模型的对接参数未正确填写。
- 现象：设置`maxContext`为3000以上时，上下文未发送至大模型。原因：超出FastGPT v4.17.0版本的默认上下文窗口上限，或配置的大模型实际支持的最大上下文小于设置值。
- 现象：对话过程中频繁出现Request Time报错。原因：本地部署的大模型或FastGPT服务的超时参数设置过短，未适配本品类大量文档召回后的处理耗时。

## 怎么确认配好了
- 进入FastGPT的模型接入配置页面，核对`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的填写内容与本地部署模型的实际参数一致。
- 发起一次技术文档交叉审查的测试请求，查看返回结果中引用的文档是否包含校准证书、误差曲线等本品类核心文档。
- 检查应用的上下文预览模块，确认召回的文档数量与`maxContext`的设置逻辑匹配。
- 模拟多轮审查对话，观察是否出现请求超时报错，调整相关参数以适配实际处理耗时。
