# 工业仪器仪表制造与校准的技术文档交叉审查：部署与升级

## 这个品类的数据长什么样
本品类的数据来源于设计文件、标准器和环境监测数据、校准软件、实验室信息系统及客户量程要求。日常生成的文档包括装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录。数据更新频率为每台设备每次校准触发，单条数据包含量程范围、误差计算值、校准日期、标准器编号、溯源链编号等字段，单位涵盖Pa、℃、mL/min等计量专用单位，部分文档为带可视化曲线的结构化文件。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据按单台设备每次校准更新，需支持增量导入与批量历史数据迁移，且需保证不同批次校准记录的字段一致性。因数据包含误差曲线、计量证书等大体积文件，存储配置需适配大文件上传与读取。同时，校准记录为可溯源的关键交付物，需对不同权限角色的文档访问与修改操作做细粒度控制。多实验室同时开展校准的场景下，需支撑较高的并发检索与数据库连接请求，避免因资源不足导致审查流程卡顿。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150` | 适配多台设备同时发起校准文档交叉审查的并发连接需求，避免数据库连接池耗尽 |
| `STORAGE_S3_ENDPOINT` | 按内部对象存储实际访问地址填写 | 用于存储校准记录、误差曲线、计量证书等大体积文档，保障大文件上传与读取稳定 |
| `REDIS_URL` | 带访问密码的专用Redis实例地址 | 缓存校准文档的元数据与向量检索结果，提升批量审查时的响应速度 |
| `FILE_TOKEN_KEY` | 32位随机生成的字符串 | 保护校准文档的下载权限，防止未授权人员获取计量证书等敏感交付物 |
| `FE_DOMAIN` | 部署环境的前端访问域名 | 统一配置知识库管理界面的访问入口，确保文档导入与索引操作的路径正确 |

## 容易做错的三处
- 现象：导入CSV格式的原始校准记录后出现中文乱码。原因：未指定文件的GBK或UTF-8编码格式，或导入时系统编码与文件编码不匹配。
- 现象：升级FastGPT v4.10后，原知识库中的校准记录无法检索到结果。原因：向量索引格式发生版本变更，未重新生成原有知识库的索引或迁移数据库索引数据。
- 现象：批量导入历史校准记录时出现数据库超时错误。原因：`DB_MAX_LINK`配置值过低，无法支撑批量导入时的并发数据库请求。

## 怎么确认配好了
- 上传一份包含中文校准信息的CSV测试文件，检查导入后中文内容显示正常，无乱码或字符缺失。
- 执行一次批量导入历史校准记录的操作，等待索引生成完成后，检索指定校准日期的记录，确认检索结果与导入数据匹配。
- 查看数据库连接池状态，确认并发连接数未达到`DB_MAX_LINK`配置的上限值。
- 访问`FE_DOMAIN`配置的前端地址，进入知识库管理界面，检查大文件上传与索引生成功能可正常触发。

本配置适用于FastGPT v4.17.0版本。
