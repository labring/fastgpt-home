# 模具设计制造的技术文档交叉审查：引用来源与溯源

## 这个品类的数据长什么样
模具设计制造的日常文档包含模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知与模具履历，数据来源涵盖客户产品模型、模流或成形仿真结果、CAD/CAM文件、机加工与测量数据、试模样件检测记录。数据更新按项目推进，每次试模或改模后都会生成新的版本，单份文档包含模具编号、零件公差、缺陷描述、加工参数等字段，单位涉及毫米、兆帕、小时等工程常用单位。

## 这些特征在「引用来源与溯源」这一环带来什么约束
文档类型多样且按项目迭代，要求溯源功能需精准绑定当前模具项目的最新版本数据，避免跨项目数据混淆。多来源的数据需要统一关联规则，确保引用的试模报告、改模通知等文档能匹配对应的设计任务书。单份文档内容较长，需保证引用的片段完整覆盖关键信息，同时避免引入无关数据干扰审查逻辑。出错后需快速定位引用来源，因此溯源信息需包含文档类型、生成时间与所属项目等元数据。

## 配置怎么定
本配置规则适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | 模具设计相关文档单段内容较长，需覆盖完整的DFM报告或试模缺陷描述 |
| `responseData` | 完整元数据 | 需记录引用文档的类型、生成时间与所属项目，便于后续问题追溯 |
| `detail` | 启用 | 模具项目需追溯到具体试模报告或改模通知，满足工程审查的溯源要求 |
| 项目关联规则 | 按项目ID绑定 | 数据按项目迭代更新，确保引用的是当前模具项目的最新版本 |
| 单次召回上限 | 前3条 | 避免过多无关数据干扰审查逻辑，聚焦核心的试模与改模记录 |

## 容易做错的三处
- 现象为引用的数据源唯一标识字段为空，原因是未配置项目与文档的绑定规则，无法关联查询到的文件与当前模具项目。
- 现象为设置变量引用模式后温度参数配置按钮消失，原因是部分界面入口在变量引用模式下默认折叠高级配置项，需展开后调整。
- 现象为引用结果混入非当前项目的模具数据，原因是未开启数据源的项目过滤开关，导致跨项目的文档被错误召回。

## 怎么确认配好了
- 上传一份测试用的试模报告与改模通知，发起审查请求，查看返回结果是否附带文档的生成时间与所属项目信息。
- 切换至变量引用模式，检查是否可展开高级配置项并调整温度参数。
- 输入包含特定模具编号的查询，确认返回的引用数据仅包含对应项目的文档。
- 查看引用日志，确认每条引用结果都绑定了唯一的数据源ID与项目标识。
