# 模具设计制造的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
该品类的典型主体为注塑、冲压、压铸模具企业及制造企业模具中心，日常产生的文档包括模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历。数据来源涵盖客户产品模型、模流或成形仿真文件、CAD/CAM输出文件、机加工与测量数据、试模样件相关记录，更新节奏按项目推进，每次试模或改模均会触发数据更新。文档包含结构化文本与二维/三维图纸，字段涉及模腔参数、成形公差、材料收缩率等专业内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
模具设计制造场景的数据混合了结构化文本与二维/三维图纸，要求模型接入配置支持多模态内容处理；数据更新随项目迭代频繁，需配置足够的上下文长度以覆盖单项目全量审查文档；专业字段与几何参数的交叉校验需要模型具备精准的行业理解能力，参数取值需兼顾严谨性与处理效率；多源数据的协同审查需要稳定的API接入链路，确保不同格式的文档均可被正确读取与分析。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配模具项目全流程文档的长上下文需求，避免截断关键审查信息 |
| `vision` | 开启 | 支持零件图、DFM报告等图纸类文档的交叉审查，识别几何与公差细节 |
| `temperature` | 0.2–0.4 | 保证审查结果的一致性，避免冗余发散，符合模具设计的严谨性要求 |
| `AIPROXY_API_ENDPOINT` | 填写公网可访问的部署地址，如`https://your-fastgpt-instance.com/api/v1` | 适配第三方模型接入的跨域访问要求，解决地址校验失败问题 |
| `maxTokens` | 2000–3000 token | 控制单轮审查的输出长度，确保结果聚焦于脱模、缩水等核心审查点 |
| `AIPROXY_API_TOKEN` | 填写对应模型平台的授权密钥 | 完成模型接入的身份验证，确保调用权限正常 |

## 容易做错的三处
- 现象：第三方模型接入时提示消息接收地址校验失败。原因：未配置公网可访问的`AIPROXY_API_ENDPOINT`，或未按提示禁用无效SSL证书校验。
- 现象：开启思维链功能后审查结果出现冗余发散。原因：`temperature`参数取值过高，超出模具设计审查所需的严谨性范围。
- 现象：自定义模型接入后无法正常触发审查。原因：未正确填写`AIPROXY_API_TOKEN`参数，或选择了未适配的模型类型。

## 怎么确认配好了
- 测试调用已配置的模型，查看接口返回状态码为200，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置正确。
- 上传一份模具零件图与配套DFM报告，触发交叉审查，查看是否返回图纸相关的几何与公差分析内容，确认`vision`参数开启生效。
- 设置`maxContext`为8000 token，上传多段长文档，查看审查过程未出现上下文截断提示，确认参数配置合理。
- 调整`temperature`至0.3，多次调用同一审查任务，查看结果差异在可接受范围内，确认参数取值符合场景需求。
