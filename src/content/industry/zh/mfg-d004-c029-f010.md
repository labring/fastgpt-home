# 模具设计制造的技术文档交叉审查：知识库检索与召回

## 这个品类的数据长什么样
这个品类的日常文档包含模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历。数据来源包括客户产品模型、模流或成形仿真文件、CAD/CAM源文件、机加工与测量数据、试模样件检测记录。数据更新按单个项目推进，每次试模或改模后同步更新。文档多包含模具编号、材料牌号、加工公差、试模批次等专属字段，部分图纸类文档附带矢量图形与标注参数。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的多类型、高更新频率与专属字段特征，对检索召回环节带来多重约束。多格式混合文档（含矢量图纸、仿真文件）要求检索链路支持跨格式解析与召回；按项目的更新节奏，需要通过标签隔离不同项目的知识库数据，避免跨项目检索干扰；专属字段如模具编号、加工公差，要求检索支持字段级过滤，精准匹配业务需求；长文档占比高，需适配长文本分块规则，避免关键工艺参数被截断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.85 | 模具设计的工艺参数匹配精度直接影响试模结果，该相似度区间可过滤通用制造文档的干扰，保留与当前项目模具规格、材料匹配的结果 |
| `limit` | 前8条 | 单项目知识库的核心文档数量有限，8条可覆盖试模报告、工艺卡、图纸等关键交叉审查所需的全部资料 |
| `searchMode` | `fullTextRecall` | 模具设计的交叉审查需关联多维度信息，全文检索可覆盖图纸标注、工艺步骤、试模缺陷记录等分散内容 |
| `usingReRank` | 开启 | 长文档分块后可能出现语义分散，重排可修正初始检索的语义偏差，提升试模缺陷对应改模方案的匹配精度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 模具术语多为行业专属，开启问题优化可将用户的审查问题扩展为包含专业术语的检索词 |
| `collectionIds` | 按当前项目标签指定 | 避免跨项目数据干扰，仅召回当前模具项目对应的知识库集合，确保交叉审查的数据源精准 |

## 容易做错的三处
- 现象：知识库中嵌入的图片（如试模样件照片、CAD标注图）在检索后无法正常加载显示。原因：未开启多格式文档的扩展解析配置，或上传的图片格式未被FastGPT v4.17.0版本支持，导致解析时丢失图片关联信息。
- 现象：检索返回的结果包含跨项目的模具文档，导致交叉审查时混淆不同批次的改模记录。原因：未通过`collectionIds`指定当前项目的知识库集合，检索范围覆盖了全量知识库数据。
- 现象：长文档的关键参数（如加工公差）未被召回，导致交叉审查遗漏关键信息。原因：分块逻辑未适配长图纸文档，将带参数的完整标注截断为不完整片段，导致语义丢失。

## 怎么确认配好了
- 上传一份标注有专属模具编号的试模报告，检索该模具编号，核对返回结果是否仅包含当前项目的文档。
- 上传一份含矢量图纸的文档，检索“脱模角度”等专业术语，核对结果中是否包含图纸标注的参数信息。
- 开启`usingReRank`后，检索“缩水缺陷改模方案”，核对重排后的结果是否优先匹配试模报告中的对应记录。
- 检查知识库集合的标签配置，确认仅当前项目的文档被纳入检索范围，无跨项目数据混入。
