# 生产计划与车间排程的技术文档交叉审查：工具调用与插件
FastGPT v4.17.0 适用版本

## 这个品类的数据长什么样
本品类服务于制造企业PMC、计划、车间调度和物控部门，日常处理销售订单、主生产计划、物料需求计划、周日排产表、工单、缺料清单、交期变更单等文档。数据来源包括ERP订单与库存、BOM和工艺路线、设备产能、人员班次、在制品和供应商到货，更新频率为每日、每周，或随订单、异常情况触发，包含订单号、物料编码、产能工时、班次人数等特定业务字段与对应单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
多类型结构化文档的混合输入，要求插件支持不同格式的字段映射与解析；高频且随异常触发的更新节奏，要求工具调用的触发时机与数据更新同步；特定业务字段的精准识别需求，要求插件适配生产计划的专业术语与单位；数据量级随订单波动的特征，要求工具调用的负载适配能力匹配业务变化，避免冗余加载或调用失败。需通过`toolChoice`配置适配多工具调用，覆盖不同业务文档的解析需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工作流/API 工具选择配置 | 自动适配多工具 | 适配销售订单、排程表等多类型业务文档的解析需求，匹配本品类的数据多样性特征 |
| 工作流/API 函数调用配置 | 按文档更新时机触发 | 匹配每日、异常触发的数据更新节奏，确保工具调用与数据同步 |
| 分块长度 | 1000–1500 字符 | 适配业务文档的段落长度，提升解析准确率 |
| 单次搜索上限 | 前10条 | 匹配车间排程的常规工单数量，避免加载冗余业务数据 |
| 最大上下文 | 8000–12000 token | 适配包含BOM、工艺路线的长文档解析，覆盖完整业务信息 |
| 调用超时阈值 | 600 秒 | 适配生产计划数据的同步延迟，避免长时间等待异常数据 |

## 容易做错的三处
- 出现模型渠道报错、调用日志显示获取数据异常：原因是未按本品类数据的更新节奏配置工具触发时机，导致调用时读取了未同步的ERP或排程数据。
- 文本提取工具返回`400 Invalid JSON payload received. Unknown name`报错：原因是未针对生产计划的专用字段（如物料编码、产能工时）配置正确的字段映射，导致插件生成的请求参数包含未定义字段。
- 升级PgVector插件后出现排程数据召回异常：原因是未适配本品类数据的字段结构，插件的向量库索引未同步更新业务文档的字段格式。

## 怎么确认配好了
- 查看工具调用日志，确认触发时机与销售订单、排程表的更新时间匹配。
- 提交测试文档（如工单、缺料清单），检查工具提取的业务字段与文档内容一致。
- 触发异常场景（如模拟插单），确认工具调用能自动适配新的业务数据。
- 查看插件运行状态，确认向量库或工具的负载符合当前业务数据的量级。
