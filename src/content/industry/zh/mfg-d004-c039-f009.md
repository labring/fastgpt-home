# 电机与发电机制造的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
这个品类的日常文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试报告、型式与出厂试验报告。数据来源涵盖电磁设计数据、铜线和绝缘材料批次记录、绕线设备、平衡机、电气试验台输出数据，以及ERP、MES系统的生产与质检数据。数据更新频率为每台电机或每批生产任务更新一次，每次型式变更时同步更新全部关联文档。文档包含绕组匝数、绝缘厚度、试验电压、温升数值等专业字段，单位多为匝数、毫米、千伏、摄氏度等行业标准单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的文档多来自生产设备与管理系统，数据更新频率高且关联紧密，要求模型接入配置支持高频增量数据的快速加载与校验。文档包含绕组匝数、绝缘参数等专业字段，需模型准确识别并交叉核对，因此配置需限制上下文与输出长度，避免截断关键信息。同时，该品类同时受电磁、绝缘与旋转机械平衡约束，技术文档需跨类别交叉审查，配置需支持多文档关联检索。此外，数据出错会导致绕组烧毁、绝缘击穿等严重后果，因此配置需降低模型输出的随机性，保障校验结果的一致性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的界面与参数逻辑制定。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配电机制造文档的长上下文需求，涵盖绕组工艺、试验报告等多份关联文档 |
| `maxTokens` | 2000–3000 token | 满足专业术语与试验数据的完整输出，避免截断关键校验结果 |
| `quoteMaxToken` | 1500 token | 限制引用文档的片段长度，确保交叉审查时能精准匹配绕组匝数、绝缘参数等字段 |
| `temperature` | 0.1–0.3 | 降低随机输出，保证专业参数核对的一致性，避免篡改文档字段格式 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写本地或云端端点 | 适配电机厂常用的本地部署大模型或公有云模型调用需求 |
| `AIPROXY_API_TOKEN` | 按实际授权密钥填写 | 保障模型调用的安全性，避免未授权访问 |

## 容易做错的三处
- 界面显示`请求错误`，本地重排模型配置失败。原因是未正确填写`AIPROXY_API_ENDPOINT`指向本地部署的大模型端点，或未配置正确的`AIPROXY_API_TOKEN`。
- 并发上升时模型回答延迟显著升高，且伴随数据库查询写入超时。原因是未限制`maxContext`的合理范围，导致每次请求加载过多电机试验报告数据，加重系统负载。
- 模型输出时出现多余空格、字母大写篡改。原因是`temperature`取值过高，或未在提示词中明确要求保留原始文档的字段格式与大小写规则。

## 怎么确认配好了
- 上传单份绕组工艺卡与对应耐压试验报告，发起交叉审查任务，检查返回结果是否准确匹配绕组匝数、试验电压等字段。
- 发起多批次并发测试请求，观察接口响应时长与系统日志，确认无持续超时报错。
- 调用本地部署的大模型，检查返回的文档排序与校验结果是否符合专业逻辑，无异常格式篡改。
- 验证`AIPROXY_API_TOKEN`的有效性，在高并发场景下无未授权访问相关报错。
