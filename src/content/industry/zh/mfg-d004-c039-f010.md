# 电机与发电机制造的技术文档交叉审查：知识库检索与召回

## 这个品类的数据长什么样
电机与发电机制造的技术文档涵盖绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试报告、型式与出厂试验报告等。数据来源包括电磁设计数据、铜线和绝缘材料批次记录、绕线设备、平衡机、电气试验台的运行数据，以及ERP/MES系统的生产批次信息。数据更新频率为每台或每批产出一次，每次产品型式变更时同步更新。文档字段包含绕组匝数、绝缘等级、试验电压、转子转速、效率值等，对应单位为匝、kV、r/min、%等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的文档按单台或单批生产批次关联，且包含大量专业数值字段，要求检索结果需精准匹配批次信息与具体参数。频繁的更新节奏要求知识库同步机制需适配实时或近实时的文档更新，避免检索到过期数据。业务中需同时核对电磁、绝缘、机械平衡三类文档，检索需支持跨这三类文档的关联召回。专业字段的语义与通用文本差异较大，需避免低相关的非专业文档混入检索结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 需精准匹配绕组匝数、绝缘等级这类专业字段，过滤低相关的通用文档 |
| `limit` | 前8条 | 单台电机关联的有效文档数量有限，过多会超出上下文窗口限制 |
| `searchMode` | `vector` | 适配专业文档的语义与字段匹配需求，结合向量检索实现精准召回 |
| `usingReRank` | 开启 | 过滤语义相近但参数不符的结果，例如匝数数值不匹配的工艺卡 |
| `datasetSearchUsingExtensionQuery` | 开启 | 将用户的审查问题扩展为关联批次、参数的查询，覆盖更多相关文档 |
| `collectionIds` | 指定绕组工艺、绝缘处理、试验报告对应的知识库集合ID | 避免检索到行政、财务等无关文档，聚焦业务核心数据 |

本配置适用于FastGPT v4.17.0及以上版本。

## 容易做错的三处
- 调用API触发嵌套知识库助手的工作流后返回空值，原因是使用了v4.8.10及更早版本，知识库上下文在API调用链中未正确传递。
- 界面提示`quote type error`报错，原因是传入的检索参数格式不符合要求，例如未按数组格式传递`collectionIds`的值。
- 经外部搜索模块获取的信息无法融入审查结果，原因是未将搜索结果同步至指定的业务知识库集合，或未配置跨源检索的关联规则。

## 怎么确认配好了
- 输入针对特定批次电机绕组匝数核对的专业问题，核对检索结果是否包含匹配的绕组工艺卡文档。
- 查看API调用返回的检索结果条数，确认不超过`limit`的设定值。
- 运行工作流，确认无`quote type error`类报错，且返回内容不为空。
- 测试开启或关闭`usingReRank`功能，观察检索结果的相关性变化是否符合预期。
