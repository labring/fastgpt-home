# 电池PACK与储能系统集成的技术文档交叉审查：向量模型与索引

本文适配FastGPT v4.17.0版本。

## 这个品类的数据长什么样
该品类的日常文档包含配组规则、BOM清单、焊接与扭矩记录、BMS刷写记录、绝缘耐压报告、EOL测试数据、系统配置清单。数据来源为电芯分容数据、MES系统、焊接设备、扭矩工具、BMS软件版本记录、EOL试验台。更新节奏为每生产一包动力电池或一台储能柜触发一次，伴随BMS软件版本变更同步更新。文档字段包含电芯容量、内阻、物料编码、扭矩值、测试电压、软件版本号等，部分字段带有明确单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据按单包/单柜高频更新，且包含结构化测试数据与非结构化规则文档，要求向量索引支持小批量实时更新，避免全量重建索引的耗时。不同文档类型差异显著，配组规则类文档篇幅较长，焊接记录类文档多为短条目，需适配分块策略区分处理。结构化字段带有明确单位，向量模型需准确识别并编码带单位的数值文本，避免语义混淆。多源数据关联紧密，索引需支持按电芯编码、BMS版本号等字段关联不同文档的向量数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配配组规则、BOM等长文档的语义完整性，避免跨块截断关键条款 |
| 重叠长度 | 50–80 字符 | 覆盖跨块文档的关联信息，防止配组规则的关键内容被分割 |
| `maxToken` | 4096 token | 匹配储能系统集成文档的平均长度，确保完整加载单块文档的语义信息 |
| `defaultToken` | 1024 token | 适配短条目类的焊接、扭矩记录文档，优化索引构建效率 |
| 相似度阈值 | 按实测标定 | 需结合绝缘测试、BMS配置的匹配精度调整，确保交叉审查的准确性 |
| 单次召回上限 | 前 8 条 | 覆盖单包产品的关联文档数量，避免遗漏关键测试记录 |

## 容易做错的三处
- 现象：页面仅支持选择一种向量模型，但业务中存在多模型适配需求，或本地与服务器模型不一致。原因：未提前统一向量模型的嵌入维度与文本预处理规则，导致不同模型生成的向量无法兼容。
- 现象：单个文件长时间处于索引中，无法完成构建。原因：未针对短条目文档调整分块策略，或单文件包含超过索引上限的内容量，导致索引进程阻塞。
- 现象：上传的多组数据无法正确关联到对应向量。原因：未按文档的关联字段（如电芯编码、BMS版本号）配置索引关联规则，导致向量与业务数据脱节。

## 怎么确认配好了
- 上传单份焊接扭矩记录文档，查看索引完成状态，确认耗时符合预期。
- 输入配组规则相关的查询，核对返回的关联文档数量与业务逻辑匹配。
- 更换向量模型后，验证同一份文档生成的向量余弦相似度变化符合预期。
- 上传多份关联文档（如同一电芯的分容数据与配组规则），确认索引能正确关联两类文档。
