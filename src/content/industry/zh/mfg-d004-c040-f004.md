# 电池PACK与储能系统集成的技术文档交叉审查：工作流编排

## 这个品类的数据长什么样
该品类的日常文档包含配组规则、BOM清单、焊接与扭矩记录、BMS刷写记录、绝缘耐压报告、EOL测试报告、系统配置清单。数据来源包括电芯分容数据、MES系统、焊接设备、扭矩工具、BMS软件版本记录、EOL试验台数据。数据更新频率为每台电池包或储能柜产出一次，或每次BMS软件版本变更时更新。文档字段包含电芯内阻、装配扭矩、耐压值、软件版本等，对应单位为毫欧、牛米、千伏、版本标识等。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的数据多源分散且单批次数据独立，要求工作流支持多源数据节点的串联整合，避免跨批次数据混淆。文档字段存在特定参数与单位，要求工作流配置校验规则，确保输入数据格式匹配。高频更新的单包数据要求工作流按单台设备触发执行，避免批量数据干扰审查结果。跨文档交叉审查的需求，要求工作流包含多文档输入与内容比对节点，同时需适配长文档处理的资源消耗，避免执行超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables`校验规则 | 匹配电芯内阻、扭矩值、耐压值的数值范围与单位 | 该品类文档包含特定参数与单位，需通过`variables`配置过滤格式错误的输入数据 |
| 单次执行超时时间 | 600–900 秒 | 单份EOL测试报告与关联文档的交叉审查需较长处理时长，适配业务实际执行周期 |
| `nodeId`绑定配置 | 绑定多文档输入节点与模型调用节点的`nodeId` | 确保工作流节点间的数据流转正确，避免跨节点数据丢失 |
| `variables`上下文配置 | 按文档总长度调整输入参数 | 该品类文档总长度差异较大，需通过`variables`适配不同批次的输入数据 |
| 多文档输入节点 | 同时导入配组规则、BOM、EOL测试报告三类文档 | 交叉审查需比对多类核心文档的一致性，覆盖该品类核心审查环节 |
| 触发方式 | 按单台设备的文档上传事件触发 | 该品类数据按单包/单柜更新，按单设备触发可避免数据混淆 |
| 模型选择节点 | 绑定已启用的企业级大模型 | FastGPT v4.17.0版本中，需确保模型在账号配置页启用后，在工作流节点中可见 |

## 容易做错的三处
- 现象：工作流执行超过120秒后触发超时终止。原因：未针对该品类多文档交叉审查的处理时长调整超时参数，沿用默认的短超时配置。
- 现象：工作流节点中无法找到已在账号配置页启用的模型。原因：未在对应工作流空间中同步模型配置，或使用的FastGPT版本与模型启用流程存在兼容差异。
- 现象：上传的技术文档无法被正确提取字段内容。原因：未配置`variables`校验规则匹配该品类文档的参数格式与单位，导致大模型无法识别有效审查信息。

## 怎么确认配好了
- 上传单台电池包的全套核心文档，触发工作流执行，检查节点运行日志是否包含所有导入文档的处理记录。
- 查看工作流的超时配置项，确认其取值覆盖该品类文档的常规处理时长，匹配业务实际执行周期。
- 进入账号模型配置页，确认目标模型处于启用状态，再返回工作流节点查看模型选择列表是否包含该模型。
- 提交测试数据，检查`variables`校验规则是否过滤了格式不符合要求的字段内容，确保仅有效参数进入审查环节。
