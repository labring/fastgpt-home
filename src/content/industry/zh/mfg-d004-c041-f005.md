# 电镀与化学表面处理的技术文档交叉审查：工具调用与插件

## 这个品类的数据长什么样
本品类数据主要来自客户表面处理规范、槽液化验结果、整流器运行数据、在线水质监测记录与危废管理台账。日常生成的文档包含槽液分析记录、工艺参数卡、挂具使用记录、膜厚与附着力报告、危废台账及废水监测记录。数据更新节奏为每槽次、每班或按固定监测要求，文档字段包含槽液浓度、作业温度、电流参数、膜厚数值、排放指标等，对应单位多为g/L、℃、A、μm、mg/L。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类的数据更新频率高、类型多样且字段带有专属单位，对工具调用与插件带来多重约束。高频更新的槽液、水质数据要求工具需支持实时拉取最新的在线监测与化验数据，避免依赖过期离线文档。多类文档的字段差异（如膜厚的μm单位、槽液浓度的g/L单位）要求插件需适配不同文档的格式解析规则，确保参数匹配准确。跨文档关联需求（如槽液成分与废水排放的对应关系）要求工具调用需支持跨数据源的信息整合，同时需校验参数合法性以规避批量生产风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配本品类多类型文档的交叉审查需求，自动匹配对应工具 |
| `functionCall` | `启用并限定为槽液分析、水质监测类工具` | 聚焦本品类核心业务数据，避免无关工具调用 |
| 多模态系统插件启用 | 开启并绑定文档解析工具 | 用于识别带图表的膜厚报告、工艺参数卡等文档 |
| MCP功能开启 | 开启并配置触发条件为文档上传完成后 | 自动触发跨文档的合规与参数校验 |
| 文件上传识别接口配置 | 支持xlsx、pdf格式，单文件上限800 MB | 覆盖本品类常用的报表与报告类文档 |
| 工具调用超时设置 | `600 秒` | 适配FastGPT v4.17.0版本的工具调用规则，匹配本品类复杂文档的解析与数据拉取耗时 |
| 单次工具调用返回条数 | 前5条 | 匹配单批次生产的核心文档数量 |

## 容易做错的三处
- 接口调用返回`aiPointsNotEnough`报错。原因是工具调用时未限定本品类专属的槽液分析、水质监测类工具，触发了超出配额的无关数据请求。
- xlsx格式的槽液分析记录无法完成AI对话。原因是未配置适配表格类文档的解析规则，或文件大小超出接口设置的上限。
- 多模态系统插件未正确识别膜厚报告中的参数。原因是未绑定针对带图表文档的解析工具，或未开启多模态插件的启用开关。

## 怎么确认配好了
- 上传一份本品类的xlsx格式槽液分析记录，检查工具是否自动调用槽液分析类工具。
- 触发跨文档审查流程，确认是否自动拉取对应批次的危废台账与废水监测记录。
- 查看工具调用日志，确认返回的结果条数符合配置的单次调用上限。
- 测试多模态文档上传，确认插件是否能识别报告中的膜厚数值与图表数据。
