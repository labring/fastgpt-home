# 石油炼制的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来自DCS/APC控制系统、LIMS实验室管理系统、罐区计量系统、原油评价报告、设备管理系统与能源管理系统。日常文档包含操作规程、生产方案、物料平衡报表、馏出口质量报告、联锁台账、交接班记录、变更管理文件。数据更新节奏覆盖实时、每班、每日，文档字段多包含工艺参数、物料量、质量指标等，单位涉及温度、压力、质量吨数、体积立方米等。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构数据的实时、每班、每日更新节奏，要求模型接入时适配不同频率的文档分片与索引更新，避免索引滞后或资源浪费。文档类型多样且包含联锁逻辑、物料平衡公式等专业内容，需要配置足够的上下文长度以覆盖长文本审查，防止截断关键工艺逻辑。多装置通过物流与能源网络耦合的业务特性，要求模型能关联跨装置的文档数据，需合理调整工具调用的范围限制。不同来源的工业系统数据格式存在差异，需确保接入时的格式兼容与权限配置合规，保障数据读取的准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配石油炼制长文档审查需求，覆盖多装置耦合的跨文档关联内容，符合FastGPT v4.17.0的上下文配置规范 |
| `maxTokens` | 4000–6000 token | 平衡单轮审查的输出长度与响应速度，适配工艺参数校验、物料平衡核对等场景的内容长度 |
| `quoteMaxToken` | 1500–2000 token | 保留足够的原文引用片段，用于交叉验证联锁条件、质量指标等核心内容 |
| 工作流/API 工具选择配置 | auto | 自动适配多文档关联审查的工具调用逻辑，覆盖跨装置数据校验、变更管理文件关联等场景 |
| `temperature` | 0.1–0.3 | 降低模型输出的随机性，确保专业审查结果的一致性，符合工业场景的严谨性要求 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写专属节点 | 适配企业内部网络的访问限制，确保数据传输的安全性与稳定性 |
| `AIPROXY_API_TOKEN` | 按权限分配专属密钥 | 管控模型接入的访问权限，防止未授权调用与数据泄露 |

## 容易做错的三处
- 现象：模型服务频繁自动中断，日志显示连接超时或401状态码。原因：`AIPROXY_API_TOKEN`未按权限更新，或`AIPROXY_API_ENDPOINT`指向了已下线的代理节点。
- 现象：添加重排序配置后，检索结果顺序无变化。原因：`quoteMaxToken`取值过小，仅保留了少量原文片段，重排序模型无法获取足够的上下文信息完成顺序调整。
- 现象：本地部署的内容提取模块无法正常运行，而官网在线版本可正常执行。原因：`maxContext`配置未匹配文档长度，或`toolChoice`未设置为auto，导致提取逻辑未触发。

## 怎么确认配好了
- 发起单篇长文档（如完整装置操作规程）的交叉审查，检查输出是否覆盖了跨文档的关联内容，未出现关键文本截断。
- 配置重排序模型后，输入包含多组质量指标的查询，核对检索结果的顺序是否随查询逻辑调整。
- 查看模型调用日志，确认`AIPROXY_API_TOKEN`和`AIPROXY_API_ENDPOINT`的配置无格式错误，无频繁的连接报错。
- 测试内容提取功能，输入包含工艺参数的文档片段，确认提取的字段与原文匹配，无缺失或错误。
