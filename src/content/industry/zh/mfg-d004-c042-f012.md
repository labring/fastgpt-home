# 石油炼制的技术文档交叉审查：部署与升级

## 这个品类的数据长什么样
石油炼制的技术文档覆盖操作规程、生产方案、物料平衡表、馏出口质量报告、联锁台账、交接班记录与变更管理文件。数据来源包括DCS/APC系统、LIMS实验室管理系统、罐区计量系统、原油评价数据库、设备管理系统与能源管理系统。数据更新节奏覆盖实时（工艺参数）、每班（交接班记录）、每日（物料平衡与质量报告）。文档字段包含装置编号、物料流量、馏程温度、罐区液位、设备联锁值等，带标准工业单位。

## 这些特征在「部署与升级」这一环带来什么约束
多套连续装置通过物流与氢气网络耦合的架构，要求文档交叉审查需覆盖跨装置关联数据，部署时需支持多源异构数据的统一接入。实时与多频次更新的文档体系，要求部署环节配置适配高频同步的存储与检索参数，避免数据延迟。多部门共用的文档管理需求，要求升级时需保留权限隔离配置，防止跨部门数据泄露。炼油文档的标准化工业字段与单位，要求部署时需配置字段映射规则，避免检索时出现单位不匹配的错误。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MONGODB_URI` | `mongodb://username:password@host:27017/fastgpt?authSource=admin` | 适配炼油企业海量工艺与质量文档的存储需求，支持多源数据的读写操作 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 缓存高频访问的装置参数与交接班记录，降低实时数据检索的延迟 |
| `STORAGE_S3_ENDPOINT` | 企业内部对象存储专属端点 | 存储原油评价报告、联锁台账等大体积文档，适配工业数据的长期归档需求 |
| 单次召回文档上限 | 前10条 | 匹配炼油文档多装置关联的检索场景，避免过多冗余数据干扰交叉审查 |
| 文档分块长度 | 800–1200 字符 | 适配炼油操作规程、物料平衡表的长文本结构，保留完整工艺逻辑单元 |
| 上下文窗口 | 6000 token | 覆盖跨装置的物流与氢气网络关联分析所需的文本长度 |

## 容易做错的三处
- 导入炼油工艺文档时报500错误，原因是未配置`FILE_TOKEN_KEY`导致文件上传校验失败。
- 前端页面无法正常访问，原因是`FE_DOMAIN`配置的外部访问地址与容器映射端口不匹配，导致网关转发失败。
- 跨装置文档检索结果为空，原因是未配置`DB_MAX_LINK`限制文档关联深度，导致检索时跳过了跨装置的关联文档。

## 怎么确认配好了
- 执行文件上传测试，上传一份馏出口质量报告，确认无报错且文档成功存入指定存储系统。
- 访问`FE_DOMAIN`配置的外部访问地址，确认前端页面正常加载且能完成系统登录。
- 发起跨装置关联检索，确认返回的文档包含不同装置的操作规程与物料平衡数据。
- 查看`REDIS_URL`对应的缓存监控指标，确认高频访问的工艺参数缓存命中率符合预期。
