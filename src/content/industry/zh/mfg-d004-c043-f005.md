# 精细化工间歇合成的技术文档交叉审查：工具调用与插件

本页面配置基于FastGPT v4.17.0版本。

## 这个品类的数据长什么样
本品类的数据来自配方与工艺库、原料批次台账、反应釜DCS系统、称量系统、LIMS实验室管理系统及仓储系统。数据更新频率为每生产批次、每个关键工艺步骤触发。日常关联文档包括批生产指令、投料复核单、反应过程记录、清场记录、检验报告、偏差与变更单，文档字段包含投料量、反应温度、批次编号、清洗验证结果等，单位涵盖千克、升、摄氏度、批次编号等。

## 这些特征在「工具调用与插件」这一环带来什么约束
多批次、多步骤的更新节奏要求工具调用需绑定单批次上下文，避免跨批次数据混淆。多类型文档的复核需求要求插件需支持批量拉取不同系统的结构化数据，适配批生产指令、投料复核单等多类文档的字段格式。数据来源分散的特点要求插件配置跨系统数据拉取的权限映射，同时配方保密的业务要求需限制工具调用的输出内容。间歇合成的步骤切换逻辑要求工具调用需支持条件触发，仅在当前工艺步骤完成后启动下一轮审查流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | auto | 适配多类型文档的动态工具调用需求 |
| 工作流/API 函数调用配置 | 仅调用预设插件 | 适配固定工艺步骤的审查流程 |
| 批量执行节点循环上限 | 10 次 | 匹配间歇合成典型工艺步骤数量 |
| 敏感信息隐藏开关 | 开启，隐藏配方参数 | 符合配方保密的业务要求 |
| 接口超时阈值 | 600 秒 | 适配反应釜DCS数据拉取的延迟场景 |
| 单批次数据拉取上限 | 500 MB | 适配仓储系统的文档存储限制 |
| 单次工具调用token上限 | 8000 token | 适配大模型的上下文限制 |
| 上下文关联标识 | 批次编号 | 避免跨批次数据混淆 |

## 容易做错的三处
- 现象为工具调用输出中未显示工具的input和response字段。原因是未开启工具详情显示开关，或错误配置了敏感信息隐藏规则导致核心字段被隐藏。
- 现象为批量执行节点在线调试可完成全流程，通过API调用时无法执行完毕。原因是API调用未配置批量节点的循环超时阈值，或未绑定批次编号作为上下文标识导致循环无法正常终止。
- 现象为接口调用工作流后，对话日志中的运行数据字段为空，或自定义插件运行后输出下载地址持续跳动延迟返回结果。原因是未开启工具调用的日志记录开关，或插件未配置同步调用模式、超时阈值设置不合理导致数据返回延迟。

## 怎么确认配好了
- 发起单批次的测试调用，检查工具调用输出是否包含对应批次的投料复核单、反应过程记录等核心数据
- 查看对话日志，确认运行数据字段已填充对应批次的系统拉取结果
- 验证批量执行节点的循环次数是否匹配当前测试批次的工艺步骤数
- 检查敏感信息隐藏配置是否仅隐藏配方、原料批次等保密字段，未影响必要的审查字段
