# 纺纱与织造的技术文档交叉审查：工具调用与插件

## 这个品类的数据长什么样
该品类的日常文档包含配棉或配料单、工艺上机单、设备运转记录、纱线检验、坯布检验、疵点记录。数据来源涵盖原纤维检验报告、企业ERP系统、纺机与织机实时数据、条干仪、验布机采集结果以及订单规格要求。数据更新节奏随生产节点变动：每批原料对应更新配棉配料单，每班更新设备运转与工艺执行记录，每匹布对应生成检验与疵点记录。文档字段包含纤维原料规格、混配参数、工艺参数、检验指标等，部分参数带有明确计量单位，如捻度以捻/米为单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据特征对工具调用与插件环节带来多重约束。多源异构的数据来源要求插件适配不同系统的接口格式，实现原纤维检验数据、ERP配料信息、设备实时参数的统一拉取。不同节点的差异化更新节奏，需要工具调用按生产批次、班次、匹次配置触发规则，避免无效调用或遗漏关键数据。文档字段带有特定计量单位，插件需内置参数校验逻辑，确保捻度、纤维强度等跨文档比对的单位一致性。连续生产带来的疵点传播特性，要求工具调用支持跨匹布的疵点记录关联查询，实现交叉审查的完整性。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工具调用触发规则 | 按生产批次、班次、匹次分别触发 | 匹配该品类数据按批、按班、按匹更新的节奏，避免无效调用 |
| 工作流/API 工具选择配置 | auto | 自动选择适配当前审查任务的工具，覆盖多源数据拉取与关联查询需求 |
| 工作流/API 函数调用配置 | enabled | 开启自定义函数调用，支持多源数据的关联查询与参数校验 |
| 参数校验开关 | 开启 | 适配文档字段带特定计量单位的特征，确保跨文档比对的参数一致性 |
| 关联文档召回上限 | 前10条 | 覆盖单匹布关联前序多匹疵点记录的需求，按实测标定召回条数 |
| 工具调用重试次数 | 3次 | 应对纺机数据接口偶发波动的场景，降低调用失败概率 |
| 最大上下文长度 | 8000 token | 适配单批生产相关文档的总长度，满足交叉审查的信息完整性要求 |

## 容易做错的三处
- 导入品类专属文档时返回500状态码。原因：未适配该品类文档的多字段混合结构，插件未正确解析纤维规格、混配参数等非通用字段。
- 调用自定义大模型时返回仅允许官方模型的报错信息。原因：未完成自定义模型调用的权限配置流程，插件未正确映射模型调用参数。
- 使用联网工具拉取纺机实时数据时未返回预期引用内容。原因：未配置对应数据源的接口访问权限，或触发规则未匹配实时数据的更新节点。

## 怎么确认配好了
- 触发一次按批次的工具调用，核对返回的文档是否包含该批次对应的配棉单、工艺上机单等全部关联文档。
- 开启参数校验开关，输入带不同计量单位的工艺参数，核对插件是否能识别并提示单位不一致的问题。
- 调用自定义模型接口，核对是否能正常返回模型生成的交叉审查结果，无权限报错。
- 触发关联召回操作，核对返回的关联文档数量是否符合预设的召回上限规则。
