# 肉制品与屠宰加工的技术文档交叉审查：HTTP 接口与外部系统

## 这个品类的数据长什么样
本品类数据来源于动物检疫信息、供应商批次、生产追溯、温度采集、金属检测及实验室检验。日常文档包含检疫证明、屠宰与分割记录、配料腌制记录、热加工记录、冷链温度记录、微生物检验报告。数据按每批、每班更新，连续温控数据实时同步。字段包含批次编号、检疫标识、温度数值（单位℃）、检测时间、微生物指标值等，部分数据需绑定对应生产环节的唯一标识。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
本品类数据按生产批次、班次更新，连续温控数据需实时同步，要求HTTP接口支持高频短间隔的批量数据拉取。多类文档需绑定唯一生产批次标识，接口需传递批次编号作为关联校验参数。数据包含检疫编号、温度值、微生物指标等特定格式字段，接口需支持自定义字段映射以匹配本地系统数据结构。部分数据涉及生物安全校验，接口需配置身份验证参数以保障数据传输合法性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | 固定前缀加企业专属密钥，格式为`Bearer {企业API密钥}` | 匹配外部系统的身份校验要求，保障接口访问合法性 |
| `variables` | 配置为`["批次编号", "检疫标识", "温度阈值"]` | 匹配本品类文档的核心关联字段，实现跨文档的批次关联校验 |
| `responseData` | 仅返回`["检疫证明编号", "批次温度记录", "微生物检验结果"]` | 过滤无关字段，降低接口传输负载，匹配交叉审查的核心数据需求 |
| 请求超时时间 | 600 秒 | 适配连续温控数据的实时同步需求，避免高频请求触发超时 |
| 批量请求上限 | 前 20 条 | 匹配每班/每批的数据量规模，避免接口过载 |

## 容易做错的三处
- 现象：调用关联接口后返回数据库相关报错。原因：未正确映射字段格式，导致外部系统数据库无法解析传入的参数。
- 现象：接口调用返回未授权错误。原因：未正确配置`Authorization`参数，或密钥格式不符合外部系统要求。
- 现象：模型调用返回配置异常。原因：未在正确位置配置外部系统接口地址，或未添加`/v1`路径后缀。

## 怎么确认配好了
- 发起单批次数据的接口请求，检查返回字段是否包含预设的核心业务字段。
- 模拟高频请求，验证接口是否能稳定返回数据且未触发超时限制。
- 核对接口传输的批次编号与本地生产系统的批次编号是否一致。
- 检查接口地址是否添加了正确的路径后缀，未返回路径错误。
