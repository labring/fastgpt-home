# 计量器具与实验室管理的技术文档交叉审查：引用来源与溯源

## 这个品类的数据长什么样
该品类数据来自企业计量室、CNAS体系实验室的日常业务文档，包括量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账与偏离处置文件。数据来源覆盖内部计量管理系统、外部校准机构证书、标准器数据、LIMS系统与环境监测记录。更新节奏随校准周期、单次试验完成或异常事件触发，无固定周期。文档字段包含明确的计量相关单位，如不确定度值（μm、mg等）、溯源等级、校准有效期，结构以单份器具或试验为核心单元，关联多维度溯源信息。

## 这些特征在「引用来源与溯源」这一环带来什么约束
数据来源分散且跨系统，要求引用溯源环节支持跨数据源召回与关联，避免仅检索单一系统的文档。更新无固定周期，需支持按需触发增量更新，确保溯源链始终关联最新的校准、核查数据。文档包含专业计量字段与单位，引用时需保留字段完整性，不能截断关键的不确定度、溯源等级信息。单份业务文档关联多维度关联项，如校准证书关联对应量具台账与期间核查记录，要求检索时自动匹配关联关系，避免溯源链断裂。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | 覆盖单份校准证书、试验原始记录的典型文本长度，避免截断溯源相关的关键内容 |
| `responseData` | 返回完整原始字段 | 保留器具编号、校准有效期、不确定度值等计量核心业务字段，支撑溯源审查 |
| `detail` | 开启详细溯源关联 | 自动匹配跨文档的关联关系，如校准证书与对应量具台账、期间核查记录的绑定 |
| 单次搜索上限 | 前6条 | 匹配单份校准证书关联的业务文档数量，避免冗余召回非关联内容 |
| 知识库容量阈值 | `1000–2000 MB` | 适配单实验室的计量文档集合规模，避免超出系统存储上限 |
| 检索超时 | `600 秒` | 等待跨系统检索的合理时长，避免因超时中断溯源流程 |

本配置适用于 FastGPT v4.17.0 版本

## 容易做错的三处
- 现象：检索到关联文档后仅返回引用标记，无对应业务内容。原因：未开启`responseData`配置，仅召回了文档索引未拉取原始文本内容。
- 现象：工作流中引用插件后运行报错，提示上下文超限。原因：`quoteMaxToken`取值过小，截断了校准证书中包含溯源链的关键文本段落。
- 现象：溯源关联结果遗漏期间核查记录。原因：未配置跨数据源检索，仅检索了单一计量系统的文档，未关联外部校准机构的证书数据。

## 怎么确认配好了
- 上传单份校准证书与对应的量具台账，发起技术文档交叉审查请求，核对返回结果中是否包含器具编号、校准有效期、不确定度值等完整业务字段。
- 触发异常更新场景，比如修改某量具的校准有效期，核对系统是否自动拉取更新后的文档并重新关联到溯源链中。
- 查看检索日志，确认召回的文档数量符合预设的单次搜索上限，无冗余或遗漏的关联业务记录。
- 输入包含长文本的不确定度说明内容，核对返回的审查结果未丢失关键的溯源相关信息。
