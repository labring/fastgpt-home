# 计量器具与实验室管理的技术文档交叉审查：文档解析与分块

## 这个品类的数据长什么样
本品类的主体为企业计量室、质量实验室、CNAS体系实验室，日常产生的文档包括量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账、偏离处置单等。数据来源涵盖企业内部计量管理系统、外部校准机构出具的证书、标准器数据、LIMS系统、环境监测记录。更新节奏随校准周期、单次试验结果或异常事件触发，无固定批量更新周期。文档多为结构化格式，包含溯源编号、测量值、不确定度、校准日期等专业字段，附带mm、mg、℃等计量专用单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
本品类的多源异构数据、非固定更新节奏与专业结构化字段，对文档解析与分块带来多重约束。多来源数据包含PDF证书、系统导出的结构化表格、内嵌图像的docx记录，要求解析工具支持多格式适配与图像文本提取。非固定更新节奏意味着需灵活调整分块参数，适配从几行的量具台账到数十页的批量校准证书。专业字段如溯源链信息、测量不确定度需保留完整上下文，避免拆分时破坏计量数据的溯源性与可信度。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 800–1200 字符 | 适配校准证书、试验记录等带专业字段的长文本，避免拆分溯源编号、不确定度等关键信息 |
| `chunkSplitter` | markdown | 保留文档原有的表格、标题层级，适配量具台账的结构化格式 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 应对外部校准证书PDF的复杂排版解析耗时 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 支持批量上传同周期内的多份校准证书文件 |
| `customPdfParse` | 开启 | 提取PDF格式校准证书中的可编辑文本，避免图像转文字的识别误差 |
| `chunkSettingMode` | 手动配置 | 针对不同文档类型（台账、证书、记录）调整分块参数，适配专业字段的上下文完整性 |

## 容易做错的三处
- 现象：上传含内嵌校准图像的docx文件后，解析结果中图像关联文本为空，日志返回`Invalid image file`报错。原因：未开启`customPdfParse`配置，或未启用内嵌图像的文本提取功能，导致图像内容无法被正确解析。
- 现象：批量上传同周期校准证书时，日志持续报`slow operation xxxxms`，解析任务超时终止。原因：`PARSE_FILE_TIMEOUT_SECONDS`设置值低于批量解析多份PDF证书的实际耗时，未覆盖长文本解析的时间需求。
- 现象：Markdown格式的量具台账解析后，表格列内容被截断，无法完整显示溯源编号与对应校准值。原因：`chunkSize`设置过小，拆分时破坏了表格行的完整结构，导致专业字段被拆分到不同分块中。

## 怎么确认配好了
- 上传一份标准格式的校准证书PDF，检查解析结果中的标题层级、表格内容、溯源编号等关键信息是否完整，无截断或缺失。
- 上传批量的量具台账docx文件，查看解析任务的执行状态，确认无超时报错或异常日志。
- 开启`customPdfParse`配置后，上传含内嵌图像的试验记录文档，确认图像附带的文本注释被正确提取至解析结果中。
- 调整`chunkSize`参数后，对比不同取值下的分块结果，确保专业字段如测量不确定度未被拆分至不同分块内。
