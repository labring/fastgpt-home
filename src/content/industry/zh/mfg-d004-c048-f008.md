# 设备点检与预防维修的技术文档交叉审查：文档解析与分块

## 这个品类的数据长什么样
该品类的数据覆盖制造企业设备部、维修班组及公用工程部门的日常生产支持文档，包括设备台账、点检表、保养计划、维修工单、故障分析、备件清单、特种设备检验记录。数据来源包括EAM/CMMS系统、设备传感数据、操作员点检记录、维修历史、备件库存及法定检验信息，更新频率覆盖每班、日/周/月及故障发生时。文档包含设备编号、点检项、参数阈值、备件型号、检验日期等字段，部分内容带有毫米、帕斯卡、运行小时数等专用单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的文档兼具结构化表格、半结构化工单与自由文本分析报告的混合形态，部分文档还包含内嵌图片的传感数据或检验记录，对解析与分块提出多重约束。高频更新的点检表与维修工单需要快速完成解析，避免影响班组日常巡检效率；带专用单位的参数字段需保留上下文关联，防止拆分后丢失参数与阈值的对应关系；故障发生时的紧急文档解析需求，要求配置具备低延迟的批量处理能力；法定检验记录需完整保留全部内容，不能因分块规则导致关键信息断裂。

## 配置怎么定
本配置项适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配该品类混合形态的文档，保留点检项、参数阈值与备件信息的关联 |
| `chunkSplitter` | 按文档类型自动适配 | 兼顾结构化点检表的表格拆分与自由文本故障分析的语义分块 |
| `customPdfParse` | 启用 | 处理包含内嵌图片的设备传感数据PDF与特种设备检验记录PDF，提取图片内文本 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 120 秒 | 匹配大型EAM系统导出的批量文档解析耗时，避免超时失败 |
| `chunkSettingMode` | 手动配置 | 针对点检表的结构化数据调整分块边界，防止切断单条点检记录的完整信息 |

## 容易做错的三处
- 现象：上传包含内嵌图片的设备点检PDF后，解析结果未包含图片内的文本内容。原因：未启用`customPdfParse`配置，默认解析仅提取PDF原生文本，未处理内嵌图片。
- 现象：提问备件清单的型号与对应更换周期时，答案仅返回部分字段。原因：`chunkSize`设置过小，拆分时切断了备件型号与更换周期的上下文关联。
- 现象：批量上传10份以上的EAM导出excel文档时，解析任务返回超时错误。原因：`PARSE_FILE_TIMEOUT_SECONDS`设置低于批量文档的实际解析耗时。

## 怎么确认配好了
- 上传包含内嵌图片的特种设备检验记录PDF，检查解析结果是否包含图片内的检验日期与合格判定字段。
- 上传结构化点检表excel，验证分块结果是否保留单条点检项的设备编号、点检内容与参数阈值的完整组合。
- 上传单份10MB左右的EAM导出文档，检查解析任务是否在120秒内完成并返回有效内容。
- 调整`chunkSize`至1000字符，提问相邻的设备运行参数与点检频率，验证返回结果包含完整的关联信息。
