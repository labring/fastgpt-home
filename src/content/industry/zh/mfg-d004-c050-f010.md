# 通用机械设备装配的技术文档交叉审查：知识库检索与召回

## 这个品类的数据长什么样
通用机械设备装配的业务数据主要来自PLM/ERP、零件检验数据、装配工具采集系统、试验台、MES及客户技术协议。日常生成的文档包含装配工艺卡、多层级BOM、扭矩记录、间隙调整记录、试运行报告、出厂检验单与装箱清单，数据更新频率为每台设备或每订单一次。文档字段包含物料编码、扭矩值（N·m）、间隙值（mm）、使用地等结构化字段，以及装配示意图、试验曲线等非结构化内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类多订单、按台更新的数据特征，要求知识库检索需支持按订单或设备ID的定向召回；多层级BOM与多类型文档的组合，需要检索同时适配结构化表格、数值型记录与图文混排文档；专业术语的多样性（如减速机与齿轮箱的同义表述），要求检索具备术语扩展能力；频繁的单台更新则要求召回支持增量同步，避免全量重建的延迟。此外，扭矩、间隙等数值型字段的精准匹配需求，需区别于通用语义检索，增加数值范围筛选的约束。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 适配扭矩、间隙等数值型字段的精准匹配，过滤低相关的语义结果 |
| `limit` | 前10条 | 适配单台设备的关联文档数量，避免上下文过载影响审查效率 |
| `searchMode` | `fullTextRecall` | 使用全文检索召回文本内容；字段、元数据、批次和文档类型条件需另行配置过滤，不能由该模式保证。 |
| `usingReRank` | 开启 | 对初始召回结果进行二次排序，优化多模态文档（如装配示意图）的匹配精度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展专业术语关联，如将「减速机」关联至「传动机构」「齿轮箱」，适配装配场景的术语多样性 |

## 容易做错的三处
- 检索时返回结果中不包含上传的装配示意图图片，仅显示文本标注：原因是未开启多模态检索配置，或未将图片嵌入带专业标注的文档中。
- 检索「使用地为国外」的Excel BOM数据时，返回的有效结果条数远少于源文件中的匹配条目：原因是未配置结构化数据的字段筛选规则，或检索时未指定「使用地」字段的匹配条件。
- 调用自定义系统的HTTPS接口时返回Error: write EPROT错误：原因是未正确配置HTTPS双向认证，或请求超时阈值设置不符合FastGPT v4.17.0的默认规则。

## 怎么确认配好了
- 上传一份包含装配示意图、BOM表格和扭矩记录的测试文档，发起检索「泵的装配工艺要求」，确认结果中包含图片预览和表格片段。
- 导入一份包含「使用地」字段的Excel BOM文档，发起检索「使用地为欧盟的装配清单」，核对返回结果的条数与源文件中匹配条目一致。
- 使用FastGPT v4.17.0的API调试工具，调用知识库检索接口，确认返回的`similarity`值在0.75–0.85区间内，且结果条数符合`limit`设置。
- 发起包含专业术语的检索，如「减速机同轴度调整记录」，确认结果自动关联了相关的齿轮箱文档，验证`datasetSearchUsingExtensionQuery`配置生效。
