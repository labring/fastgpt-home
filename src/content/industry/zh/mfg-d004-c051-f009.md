# 金属切削加工的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
金属切削加工的技术文档包含工艺路线、工序卡、刀具清单、数控程序、首件检验记录、巡检表、量具校准记录等。数据来源包括产品图纸与三维模型、CAPP/CAM系统、机床采集数据、刀具管理系统、MES及量检具数据。更新随工单、单件加工、抽检或刀具更换触发，单份文档包含工序编号、刀具型号、切削参数、检验尺寸、校准周期等字段，单位涵盖毫米、转每分钟、牛米等加工专用单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的多源异构数据、高频更新特性及专业字段要求，对模型接入配置带来多重约束。多源数据包含结构化参数与非结构化代码文档，需配置适配混合格式的模型调用逻辑；高频更新要求配置支持快速同步的接口参数；专业字段与单位需模型具备加工领域术语识别能力，避免参数解析错误；数控程序等长文本文档，需调整模型的上下文承载参数，确保完整读取内容。FastGPT v4.17.0版本的配置界面可针对性调整相关参数以适配这些约束。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配数控程序、工艺路线等长文档的完整读取，覆盖多源加工文档的总上下文长度 |
| `maxTokens` | 2000–3000 token | 满足专业切削参数、尺寸要求的审查结果输出长度，避免截断关键加工内容 |
| `quoteMaxToken` | 1500 token | 限定引用的单份文档片段长度，适配工序卡、巡检表等单文档的核心字段提取需求 |
| `temperature` | 0.2–0.4 | 降低随机输出偏差，确保加工参数、尺寸要求的审查结果准确一致 |
| `AIPROXY_API_ENDPOINT` | 按平台提供的专属地址填写 | 适配多源加工数据的跨域调用需求，确保接口请求稳定 |
| `AIPROXY_API_TOKEN` | 按平台生成的密钥填写 | 保障接口访问的权限安全，避免未授权调用 |

## 容易做错的三处
- 现象：在第三方接口测试工具中验证模型调用正常，但在FastGPT中新建模型节点后测试返回报错，报错文案包含「权限不足」或「接口地址无效」。原因：未正确配置`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`的权限范围，FastGPT的接口校验规则与第三方工具存在差异。
- 现象：技术文档交叉审查的响应时长超过30秒，页面出现加载超时提示。原因：未合理设置`maxContext`参数，引入过多冗余文档片段，导致模型处理的上下文负载过高。
- 现象：审查结果中出现切削参数单位错误或引用的刀具型号与文档不符，例如将「φ10mm」识别为「φ10cm」。原因：未将`temperature`参数设置在合理区间，导致模型输出出现随机偏差，未适配加工领域的专业字段校验需求。

## 怎么确认配好了
- 调用模型接口测试，输入一段包含切削参数的数控程序文本，检查返回结果是否包含完整的工序参数校验内容。
- 上传一份刀具清单文档，验证模型引用的片段长度是否符合预设的`quoteMaxToken`范围。
- 调整`temperature`参数后，多次输入相同的工艺审查请求，确认输出结果的一致性符合业务要求。
- 模拟高频更新场景，上传新的巡检表文档，检查模型是否能正确读取最新的检验数据。
