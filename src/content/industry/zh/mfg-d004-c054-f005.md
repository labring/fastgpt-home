# 钣金下料折弯的技术文档交叉审查：工具调用与插件

## 这个品类的数据长什么样
钣金下料折弯的日常文档包含展开图、数控下料程序、折弯工艺卡、套料图、首件记录、工序流转卡。数据来源为CAD/CAM软件、订单BOM、板材库存系统、激光切割机、折弯机及MES系统。数据更新频率为每订单、每日或每次换型。核心字段包含板材厚度（单位mm）、折弯系数、下料尺寸（单位mm）、折弯角度（单位°）等，不同订单的文档结构和字段存在一定差异。

## 这些特征在「工具调用与插件」这一环带来什么约束
由于该品类多品种小批量、图纸驱动的特征，每次审查的文档集合随订单变化，工具调用需支持动态加载不同订单的数据源。文档类型多样且包含CAD格式文件，插件需适配不同格式的解析与调用。核心审查环节依赖折弯系数计算、套料核对、折弯顺序校验等外部工具，因此工具调用需具备灵活的触发与执行逻辑。数据来自多系统，插件需完成跨系统的数据格式转换与同步，避免因格式不匹配导致审查失败。同时高频更新的数据要求工具调用具备近实时的响应能力。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配多订单、多文档的交叉审查场景，自动选择匹配的工具完成审查 |
| `functionCall` | 启用 | 支持调用折弯系数计算器、套料核对工具等外部插件完成核心审查操作 |
| 单次工具调用条数 | 前3条 | 钣金下料折弯的核心审查数据集中在前几份核心文档，过多会增加上下文负担 |
| 工具调用超时时间 | 60-120秒 | 对接数控设备、CAD工具的响应通常在该区间，过长会导致流程卡顿 |
| 上下文保留长度 | 800-1200字符 | 单份钣金工艺卡的核心审查内容约为该范围，过长会干扰工具调用精度 |

## 容易做错的三处
- 现象：尝试无工具建立文档交叉审查的链接时，系统提示配置错误。原因：未启用`functionCall`参数，或未配置对应工具的调用权限，无法完成无工具的跨文档关联。
- 现象：输出内容中包含“引用标记：［1］”字样。原因：未关闭知识库引用标记的输出开关，或工具调用时未过滤文档引用标识。
- 现象：用户输入指定关键词后未触发自定义接口调用。原因：未在插件配置中设置关键词触发规则，或规则配置错误导致拦截逻辑未生效。
