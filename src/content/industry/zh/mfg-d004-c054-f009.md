# 钣金下料折弯的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
钣金下料折弯场景的核心数据来自CAD/CAM软件、订单BOM系统、板材库存台账、激光切割机与折弯机设备日志、车间MES系统。日常产生的文档包含三维件展开图、数控下料程序、折弯工艺卡、套料图、首件检验记录、工序流转卡。数据更新频率随订单交付、每日生产排班、机型换型调整。文档字段包含板材厚度、折弯补偿值、下料尺寸、折弯角度、工序流转单号，单位多为毫米、角度、千克。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类多品种小批量的生产模式，要求模型接入支持多文档批量解析与实时更新。不同格式的工艺文档与CAD图纸混合输入，要求配置适配视觉与文本混合的解析能力。高频次的订单与换型数据更新，要求模型上下文能够快速加载最新的工艺参数。特定的折弯补偿、下料尺寸等字段，要求模型能够精准识别行业专属术语与单位，避免通用解析的偏差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 适配多份套料图、折弯工艺卡的长文本加载需求，避免上下文截断导致参数遗漏 |
| `temperature` | `0.1–0.3` | 降低随机输出概率，保障折弯补偿值、下料尺寸等工艺参数的精准匹配 |
| `vision` | 开启 | 用于解析三维件展开图中的折弯标注、孔位信息，匹配文本类工艺文档的交叉审查需求 |
| `maxTokens` | `2000–3000 token` | 适配单份工艺卡或套料图的审查结果输出长度，避免结果被强制截断 |
| `AIPROXY_API_ENDPOINT` | 填写对应大模型服务商的官方接入端点 | 完成模型的基础网络连通配置，保障请求正常发送 |
| `AIPROXY_API_TOKEN` | 填写服务商分配的专属密钥 | 完成模型的身份验证，确保接入权限有效 |

## 容易做错的三处
- 模型测试报错「[] is too short - 'messages'」：现象为调用模型测试时返回指定报错文案，原因是未配置初始对话消息或消息数组为空，未满足模型输入的最小格式要求。
- 新增模型配置后界面无法显示：现象为完成配置填写并提交后，模型列表中无新增条目，重启FastGPT服务后仍未加载，原因是未正确填写`AIPROXY_API_TOKEN`或`AIPROXY_API_ENDPOINT`的必填字段，导致配置校验失败未入库。
- 模型审查结果遗漏工艺参数：现象为输出的交叉审查报告中未包含折弯补偿值或套料余量信息，原因是`maxContext`设置值过小，加载的文档上下文不足，无法覆盖全部待审查的工艺数据。

## 怎么确认配好了
以下核对动作基于FastGPT v4.17.0版本。
- 检查`AIPROXY_API_TOKEN`与`AIPROXY_API_ENDPOINT`的填写内容，可通过调用基础模型接口测试连通性，验证配置是否生效。
- 开启`vision`配置后，上传一张钣金展开图，验证模型是否能识别图中的折弯角度、孔位标注等视觉信息，确认视觉解析功能正常。
- 设置`temperature`为`0.2`，输入一段包含折弯补偿值的工艺卡文本，验证输出结果是否保持参数的一致性，确认温度参数配置符合需求。
- 导入3份以上不同类型的钣金文档，验证`maxContext`是否能容纳所有加载的文档内容，无明显的上下文截断提示。
