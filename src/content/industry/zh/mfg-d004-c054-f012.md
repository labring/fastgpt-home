# 钣金下料折弯的技术文档交叉审查：部署与升级

## 这个品类的数据长什么样
这个品类的日常文档包含三维件展开图、数控下料程序、折弯工艺卡、套料图、首件记录与工序流转卡，数据多来自CAD/CAM软件、订单BOM系统、板材库存台账、激光切割机与折弯机设备日志，以及车间MES系统。数据更新随订单生成、每日库存盘点或生产换型触发，文档字段包含板材厚度、折弯系数、下料尺寸、折弯角度等，单位多为毫米、度，部分工艺卡附带数控代码片段。

## 这些特征在「部署与升级」这一环带来什么约束
多类型异构的生产文档需要适配不同格式的解析逻辑，部署时需配置兼容CAD图纸、数控代码与文本工艺卡的解析规则。高频更新的生产数据要求数据库支持高并发写入，因此需调整连接池参数以匹配车间的并发访问量。多源数据的跨系统关联需求，要求数据库配置支持跨表查询，同时需适配不同系统的数据格式差异。此外，多品种小批量的生产模式，要求知识库支持动态添加文档分类，无需固定绑定产品模板，避免频繁调整部署配置。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配，具体如下：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://fastgpt:securepass@mongodb.internal:27017/fastgpt_prod?authSource=admin` | 适配多源异构生产文档的存储与检索，支持高频小批量数据写入 |
| `REDIS_URL` | `redis://:redispass@redis.internal:6379/1` | 缓存高频检索的折弯系数、套料规则数据，降低核心数据库的负载 |
| `STORAGE_S3_ENDPOINT` | `http://minio.internal:9000` | 存储数控下料程序、展开图等大体积文件，适配每日新增的生产文档 |
| `DB_MAX_LINK` | `200–300 个连接` | 匹配车间设备与订单的并发访问量，避免数据库连接耗尽导致的服务中断 |
| `FE_DOMAIN` | `https://钣金工艺审查.your-domain.com` | 配置前端访问域名，确保文档上传与检索的跨域请求正常完成 |
| `FILE_TOKEN_KEY` | `随机生成的32位十六进制字符串` | 保障上传的工艺卡、套料图等文件的访问权限安全，防止未授权访问 |

## 容易做错的三处
- 现象：工作流中调用数据库连接无输出，界面显示工具调用超时。原因：未将`MONGODB_URI`或`PG_URL`配置为车间内网可访问的地址，导致FastGPT无法连接MES或板材库存数据库。
- 现象：上传折弯工艺卡后无响应，无法生成检索索引。原因：未配置`STORAGE_S3_ENDPOINT`对应的存储桶读写权限，导致文件上传后无法被解析服务读取。
- 现象：本地部署的大模型无法响应文档提问。原因：未正确设置`ROOT_KEY`的模型调用密钥，或`REDIS_URL`的缓存配置未适配大模型的上下文缓存需求，导致模型无法获取上传的文档数据。

## 怎么确认配好了
- 访问`FE_DOMAIN`的文档上传页面，上传一张折弯工艺卡，确认文件能正常保存并显示在知识库的分类列表中。
- 在FastGPT的测试对话界面，输入“查询当前板材库存”，确认能返回对应数据库的查询结果，无连接报错或超时提示。
- 触发一次生产换型的文档批量上传，检查数据库连接数监控指标，确认连接数未超过`DB_MAX_LINK`的配置上限。
- 调用本地部署的大模型，输入“总结这份下料程序的折弯顺序”，确认模型能基于上传的文档生成有效回答，无空响应或错误提示。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
