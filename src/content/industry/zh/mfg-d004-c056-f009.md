# 锂离子电芯制造的技术文档交叉审查：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据来自原材料批次台账、生产MES系统、浆料与涂布检测设备、车间露点监测装置、化成分容柜及实验室检测系统。日常生成的文档包含配料记录、涂布辊压参数台账、卷绕或叠片操作记录、注液参数日志、化成分容数据报表、OCV与安全测试报告。数据更新节奏为单批次、单电芯维度实时更新，文档字段包含浆料配比参数、涂布面密度数值、辊压间隙数值、露点温度数值、化成分容电压数值、内阻检测数值等。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据特征对模型接入与配置带来多重约束。实时更新的单批次、单电芯维度数据，要求模型上下文长度不能过大，否则会导致处理延迟，无法匹配生产实时性需求。多设备来源的异构数据格式，要求配置时加入数据格式校验规则，避免接入不规范的生产日志。细粒度的专业生产字段，要求模型能精准匹配对应参数，需配置合理的上下文召回规则，防止跨批次数据混淆。高频更新的数据还要求配置适配的上下文刷新机制，确保模型调用时使用最新的生产文档数据。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 企业内部FastGPT代理接口地址 | 适配锂离子电芯制造场景的内部生产数据访问权限，确保数据传输安全 |
| `maxContext` | 8000–12000 token | 匹配单批次生产相关文档的总token规模，避免上下文溢出导致调用失败 |
| `maxTokens` | 2000–3000 token | 覆盖专业生产参数交叉审查的完整输出长度，满足多维度文档对比需求 |
| `quoteMaxToken` | 1500 token | 限定单份核心生产文档的引用长度，确保审查内容聚焦且不超出模型处理上限 |
| `temperature` | 0.1–0.3 | 保持生产参数审查的严谨性，避免生成不符合工艺规范的非标准结果 |
| `toolChoice` | none | 该场景仅需文档交叉审查，无需调用外部工具 |

## 容易做错的三处
- 现象：调用第三方大模型后，输出仍包含`<think>`包裹的思考内容。原因：未正确配置模型的思考输出开关，或开关配置未同步至代理接口。
- 现象：接入内部生产数据接口后，提示无授权访问。原因：未将生产数据来源的IP地址添加至FastGPT代理的访问白名单，或`AIPROXY_API_TOKEN`配置错误。
- 现象：模型返回的交叉审查结果中，未正确关联对应生产文档的参数。原因：`maxContext`取值过小，导致核心生产文档未被完整纳入上下文，无法完成参数匹配。

## 怎么确认配好了
- 调用测试接口，输入单批次生产文档的交叉审查需求，检查输出是否包含`<think>`标签，确认思考输出开关配置符合预期。
- 查看模型调用日志，确认`AIPROXY_API_TOKEN`的验证状态为通过，检查接口地址是否与企业内部部署的FastGPT代理地址一致。
- 输入包含特定生产参数的查询，核对模型返回的引用内容是否包含对应批次的生产文档，确认上下文召回范围符合配置要求。
- 调整`temperature`参数后，观察输出结果的一致性，确认参数取值适配场景的严谨性需求。
