# 锂离子电芯制造的技术文档交叉审查：部署与升级

## 这个品类的数据长什么样
该品类的数据来自原材料批次台账、生产MES系统、浆料与涂布检测设备、车间露点监测装置、化成分容柜、实验室测试设备。日常文档包含配料记录、涂布辊压参数台账、卷绕或叠片工序记录、注液操作记录、化成分容数据报表、OCV与安全测试报告。数据更新节奏为每生产批次、单只电芯维度实时同步，部分检测指标随工序完成即时更新。文档字段包含物料批次号、工艺参数数值、检测结果、时间戳，部分参数带有专属工艺单位，如涂布面密度、内阻、露点温度等。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据来源分散，包含生产设备、检测装置、管理系统等多类异构数据源，部署阶段需配置适配不同数据协议的连接参数，确保全链路数据接入。实时与批次级更新并存的节奏，要求部署时合理划分同步任务优先级，避免高频小数据同步占用过多集群资源。文档字段多且带有专属工艺单位，升级时需保留原有字段映射规则，避免交叉审查时出现参数匹配偏差。同时，因数据异常会直接引发电芯内短路、鼓胀或热失控等安全问题，部署与升级环节需内置强制校验逻辑，确保接入数据的格式与合规性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `DB_MAX_LINK` | 100–200 条 | 适配多数据源并发连接需求，避免因连接数超限导致数据同步中断 |
| `MONGODB_URI` | 包含认证信息的集群连接地址，端口默认27017 | 存储批量生成的工序记录、化成分容历史数据与安全测试报告，需支持高并发读写与海量数据存储 |
| `REDIS_URL` | 带密码的单节点或集群连接地址 | 缓存实时检测数据与临时校验结果，降低重复查询开销 |
| `STORAGE_S3_ENDPOINT` | 企业内部对象存储的访问端点 | 存储大体积的测试报告与原始检测数据，适配批量文档存储需求 |
| `FILE_TOKEN_KEY` | 随机生成的32位字符串 | 加密文件访问令牌，防止未授权访问敏感工艺文档 |
| `ROOT_KEY` | 按企业内部权限规则配置的密钥 | 管理系统级权限配置，确保仅授权运维人员可修改审查规则 |

## 容易做错的三处
- 现象：执行`docker run --gpus all -itd -p 7231:7231`命令安装`marker_images:v0.1`时出现依赖报错。原因：未在部署环境中提前配置CUDA运行时环境，导致GPU镜像无法正常加载。
- 现象：升级FastGPT至v4.9.0后，通过URL创建知识库时持续报错，后台日志显示`cannot fetch internal url`。原因：未配置`FE_DOMAIN`参数为内部服务的合法访问地址，导致系统无法解析内部资源路径。
- 现象：部署后无法找到文件加工插件，无法执行技术文档解析。原因：未在启动命令中挂载对应插件的镜像卷，或插件版本与当前FastGPT版本不匹配。

## 怎么确认配好了
- 使用FastGPT v4.17.0版本的后台管理界面，进入系统设置页面，检查已配置的连接参数是否与预设值一致。
- 执行`docker ps`命令，确认`marker_images`容器处于运行状态，端口7231正常监听。
- 登录FastGPT后台，进入知识库配置页面，输入内部工艺文档的URL，测试能否正常拉取并解析。
- 查看后台日志，确认数据同步任务无连接超时或权限报错，字段映射规则正常生效。
- 上传一份测试用的配料记录文档，触发交叉审查校验，确认结果符合预设规则。
