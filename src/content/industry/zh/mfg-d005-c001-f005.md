# PCB制造的投标文稿与报价编制：工具调用与插件

## 这个品类的数据长什么样
本品类数据来自客户提供的Gerber文件、钻带、BOM清单，结合工厂CAM系统、生产设备参数、槽液化验记录、AOI检测报告、电测数据与实验室切片报告。数据更新随生产批、每班频次产生，部分参数由设备连续采集生成。日常文档包含工程制作指示、Gerber解析记录、钻孔与层压参数表、药水分析台账、AOI缺陷报告、电测合格证明、切片失效分析报告，字段包含孔径规格、层压温度、槽液浓度、缺陷点位坐标等。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类的数据分散于多系统与多格式来源，工具调用需适配Gerber解析、CAM数据拉取等专用接口格式，避免通用插件无法识别专用字段。数据更新频次高且部分为实时采集，工具需支持按生产批或班次触发数据同步，避免使用过期参数生成报价。文档包含结构化参数表与非结构化检测报告，工具调用需区分结构化字段提取与全文检索的不同逻辑，适配不同内容的处理规则。工具调用失败会直接影响投标文稿准确性或报价合理性，需增加前置校验环节。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| :--- | :--- | :--- |
| `toolChoice` | `auto` | 自动匹配适合当前任务的工具，适配多类型数据源与文档格式 |
| `functionCall` | 开启强制函数调用 | 确保结构化生产参数的准确提取，避免非结构化报告内容干扰报价计算 |
| 工具调用超时时间 | 300–600 秒 | 数据拉取涉及多系统接口，需预留足够的响应与处理时间 |
| 数据源白名单 | 仅添加工厂CAM、AOI、槽液化验系统的合法API地址 | 防止调用非授权数据源引入错误或敏感数据 |
| 异常参数校验规则 | 当提取字段超出行业合理区间时触发告警 | PCB制造参数存在固定合理范围，可快速识别异常数据 |
| 默认工具调用模型 | 选择支持工具调用能力的大模型 | 确保工具调用的逻辑正常执行 |

## 容易做错的三处
- 现象：工具调用返回的钻孔参数为空，生成的投标文稿遗漏孔位精度要求。原因：未配置数据源白名单，调用了非授权的CAM系统接口，导致参数提取失败。
- 现象：工具调用超时，返回状态码504。原因：设置的超时时间短于多系统数据拉取的总耗时，未预留足够的响应时间。
- 现象：工具调用时无法识别上传的Gerber文件，返回格式错误提示。原因：未配置文件上传的工作流API适配规则，未指定支持的PCB专用文件格式。

## 怎么确认配好了
- 登录FastGPT v4.17.0的工具配置页面，检查`toolChoice`是否设置为`auto`。
- 进入函数调用设置界面，确认`functionCall`强制调用模式已开启。
- 模拟调用测试接口，传入测试用的Gerber文件与CAM数据，检查返回的结构化参数是否完整。
- 配置异常校验规则，输入超出合理区间的测试参数，确认是否触发告警。
- 检查工具调用返回的语料是否附带数据源标识，确认追溯功能已开启。
- 进入默认模型设置界面，确认已选择支持工具调用能力的大模型。
