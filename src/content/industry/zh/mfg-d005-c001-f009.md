# PCB制造的投标文稿与报价编制：模型接入与配置

## 这个品类的数据长什么样
该品类数据来源为客户提供的Gerber文件、钻带、BOM清单，以及工厂内部CAM系统、生产设备参数、槽液化验记录、AOI检测报告、电测报告与实验室切片报告。数据更新随生产批次、班组班次连续采集，单次生产批对应完整的工程制作指示、钻孔层压参数、药水分析台账等文档。文档包含图层编号、孔径尺寸、槽液浓度、检测缺陷类型等字段，单位涵盖毫米、兆帕、百分比等工业标准单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据来源要求接入配置支持解析二进制格式的Gerber文件、专有CAM字段的结构化数据，无法仅依赖通用文本处理逻辑。高频连续更新的生产数据，要求上下文窗口配置适配实时同步的业务状态，避免因上下文过期导致报价偏差。投标文稿需绑定客户专属的工程参数，需自动调用对应数据源工具提取字段，工具调用逻辑需与业务环节强绑定。同时，报价错误可能引发整批报废或高额索赔，需限制生成的随机性，避免参数失真。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本编写
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配多源生产数据的上下文长度，覆盖单次生产批的完整工程与检测数据 |
| `maxTokens` | 4000 token | 限制单次报价与文稿生成的输出长度，避免冗余内容导致投标文件格式混乱 |
| `quoteMaxToken` | 1500 token | 单独限定报价明细的生成长度，确保每项报价参数清晰合规 |
| 工作流/API 工具选择配置 | auto | 自动触发工具调用，提取客户Gerber参数、CAM钻孔数据等业务字段 |
| `temperature` | 0.2–0.4 | 降低生成随机性，确保报价参数与实际生产数据严格匹配，避免错误取值 |
| `AIPROXY_API_ENDPOINT` | 按工厂专属代理地址填写 | 适配内部网络环境，确保数据传输的安全性与稳定性 |
| `AIPROXY_API_TOKEN` | 按专属密钥配置 | 保障接口调用的权限安全，防止未授权访问 |

## 容易做错的三处
- 接口日志显示非工作时段持续发起调用，账户余额快速消耗。原因是未配置访问时段与IP白名单，公开的API密钥被未授权第三方调用。
- 生成的投标文稿中出现与当前生产批次不匹配的钻孔参数。原因是`maxContext`配置过小，未加载最新的CAM设备参数，导致上下文缺失。
- 生成的报价明细字段单位混乱，混用毫米与英寸。原因是未在工具调用逻辑中配置单位标准化转换，直接提取原始数据未做统一处理。

## 怎么确认配好了
- 提交测试用的客户Gerber文件与BOM清单，核对生成的工程参数是否与原始数据一致。
- 模拟非工作时段发起接口调用，检查是否触发访问限制，确认时段配置生效。
- 生成单批次的投标报价与文稿，检查输出长度是否符合预设的生成限制。
- 查看接口调用日志，确认工具调用自动触发并正确提取了CAM、槽液化验等数据字段。
