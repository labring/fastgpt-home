# 乳制品加工的投标文稿与报价编制：向量模型与索引

## 这个品类的数据长什么样
乳制品加工的日常文档包含原奶验收记录、标准化配料单、巴氏或UHT热处理记录、CIP清洗记录、灌装记录、留样与微检报告。数据来源涵盖奶源检测系统、生产MES系统、均质与热处理设备、在线温度流量监控系统、CIP系统及LIMS实验室管理系统。数据更新节奏为每奶罐、每生产批次实时同步，单份文档包含批次编号、检测数值、工艺参数等结构化字段，部分字段带有专业单位，如菌落总数单位CFU/mL、抗生素残留量单位μg/kg。

## 这些特征在「向量模型与索引」这一环带来什么约束
乳制品加工的数据更新频率高且按奶罐、生产批次实时同步，要求索引支持增量更新，避免全量重建占用过多系统资源。多类型结构化文档包含专业检测与工艺参数，如原奶抗生素残留量、热处理温度时间等，要求向量模型适配专业术语的语义识别，避免丢失核心指标关联。单份文档的结构化字段与专业单位较多，要求分块时保留上下文关联，防止跨分块的生产流程逻辑被割裂。数据关联紧密，原奶验收结果直接影响后续配料与热处理环节，要求索引支持跨文档的关联检索，确保检索结果覆盖完整业务链路，避免遗漏关键决策依据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配乳制品加工单份检测、生产记录的长度，避免破坏专业术语的语义完整性 |
| `maxToken` | 8192 token | 匹配主流开源嵌入模型的上下文窗口上限，防止长文档被截断 |
| 分块重叠长度 | 100–150 字符 | 保留相邻分块的上下文关联，避免跨分块的生产流程逻辑被割裂 |
| 相似度阈值 | 0.72–0.80 | 适配乳制品专业数据的特征相似度分布，平衡召回精度与无关结果过滤 |
| `defaultToken` | 4096 token | 适配单批次核心文档的平均长度，满足基础检索的上下文需求 |
| 单次召回上限 | 前 6 条 | 控制检索结果的上下文负荷，避免超出模型处理能力 |

## 容易做错的三处
- 现象：配置同名嵌入模型后，原有配置被覆盖。原因：FastGPT v4.17.0 版本中同一模型名称仅支持唯一配置项，未按业务场景区分模型别名导致配置冲突。
- 现象：检索结果仅返回少量条目或为空。原因：相似度阈值设置过高，未匹配到符合乳制品专业特征的关联文档，或分块长度过长导致语义被截断。
- 现象：长检测记录的向量检索结果出现关键指标丢失。原因：未设置合理的`maxToken`参数，导致长文档被截断，丢失原奶抗生素、理化指标等核心字段。

## 怎么确认配好了
- 上传单份原奶验收记录，执行检索测试，查看返回结果的分块是否保留了批次号、抗生素检测值等核心字段。
- 配置多个同类型模型并设置不同别名，验证新增配置未覆盖原有设置。
- 调整相似度阈值，对比不同阈值下的检索结果数量，确认符合业务预期的召回范围。
- 上传多份按批次关联的生产文档，验证增量索引更新后可检索到跨批次的关联记录。
