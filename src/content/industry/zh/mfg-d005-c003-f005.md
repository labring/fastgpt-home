# 乳制品加工的投标文稿与报价编制：工具调用与插件

## 这个品类的数据长什么样
该品类的数据涵盖原奶验收记录、标准化配料单、巴氏或UHT热处理记录、CIP清洗记录、灌装记录、留样与微检报告。数据来源包括奶源检测设备、生产MES系统、均质与热处理在线监测装置、实时温度流量采集系统、CIP管控平台及LIMS实验室管理系统。数据更新以单奶罐、单生产批次为单位，部分在线监测数据实时同步，核心指标随生产流程推进逐步完善。文档字段包含原料批次号、检测数值、工艺参数、设备编号、留样编号等，部分参数需匹配法定检测单位出具的权威格式。

## 这些特征在「工具调用与插件」这一环带来什么约束
乳制品加工的生产数据与批次强绑定，工具调用需精准关联对应批次的文档与实时参数，无法使用通用批次模板。实时在线数据的高频更新要求工具调用具备低延迟响应能力，避免调用过时数据生成投标内容。多源异构数据的整合需求要求插件需兼容不同系统的接口格式，适配原奶验收、热处理、灌装等环节的不同数据结构。投标文稿需匹配官方认可的检测报告格式，工具调用需严格遵循预设字段顺序与单位，避免因格式不符导致投标文件无效。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` | 自动适配多环节工具调用逻辑，无需手动指定工具类型 |
| 工作流/API 函数调用配置 | `["原奶指标校验", "热处理参数验证", "投标文档填充"]` | 绑定乳制品加工专属业务工具函数，精准调用对应生产环节数据 |
| 工具调用开关 | 开启 | 需整合多系统生产数据生成投标内容，开启后支持跨数据源调用 |
| 知识库召回上限 | `0 条` | 投标内容需基于实测生产数据，不使用知识库通用内容 |
| 超时阈值 | `300 秒` | 需等待多设备实时数据返回，预留充足的接口响应时间 |
| 响应内容过滤 | 仅保留工具调用结果 | 避免无关对话引用干扰投标文稿的严谨性 |

## 容易做错的三处
- 现象：调用工作流时返回`401 Unauthorized`错误，或提示API Key无效。原因：使用全局通用API Key直接调用工作流，未使用对应应用的专属API Key。
- 现象：工作流调用后返回空的生产数据字段，无法匹配对应批次的原奶验收记录。原因：未为每个生产批次生成唯一的工作流实例标识，导致数据关联错位。
- 现象：生成的投标文稿中混入了知识库通用内容或无关的对话引用片段。原因：未正确配置响应内容过滤规则，导致工具调用结果被额外的对话内容污染。

## 怎么确认配好了
- 调用测试工作流，检查返回的响应中仅包含工具调用生成的生产数据内容，无额外对话引用片段。
- 验证API Key权限，确认调用时返回`200 OK`状态码，无权限相关报错。
- 生成单批次的投标文稿片段，核对字段与单位与对应生产批次的文档完全匹配。
- 查看工作流运行日志，确认每个工具调用均关联了正确的生产批次数据。
