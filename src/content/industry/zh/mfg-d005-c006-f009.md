# 光伏组件封装的投标文稿与报价编制：模型接入与配置

## 这个品类的数据长什么样
光伏组件封装品类的数据来源于电池片分档系统、玻璃胶膜背板批次台账、车间MES系统、串焊与层压生产设备、EL缺陷检测仪及IV功率测试仪。数据按每块组件、每批材料实时更新，日常文档包含排版图、材料批次记录、层压工艺记录、EL缺陷图、IV测试报告、绝缘耐压记录、成品包装清单。数据字段包含电池片电流档位、层压温度压力参数、EL隐裂位置、功率值、绝缘耐压值等，覆盖光伏组件封装的生产全流程节点。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据更新频率高且单条体量小，要求模型接入时适配高频小批量的查询请求，避免上下文溢出。文档包含图像类的EL缺陷图，要求模型支持视觉识别能力以解析缺陷信息。数据字段聚焦生产工艺与测试结果，配置时需确保模型能准确关联电池片电流档位、层压参数与报价系数。同时投标文稿需匹配材料批次与功率分档，需限制上下文长度以避免无关数据干扰报价计算。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 字符 | 适配光伏组件封装的多文档拼接需求，避免超出模型上下文限额 |
| `maxTokens` | 2000–3000 token | 匹配投标文稿与报价编制的输出长度，确保覆盖完整的报价明细与技术说明 |
| `quoteMaxToken` | 1500 字符 | 限制引用的生产文档长度，聚焦与当前投标批次相关的材料与工艺数据 |
| `vision` | 开启 | 用于解析EL缺陷图、IV测试报告图表，提取隐裂与功率异常信息 |
| `temperature` | 0.2–0.4 | 降低输出随机性，确保报价与工艺参数的一致性 |
| `AIPROXY_API_ENDPOINT` | 按部署规则填写 | 适配FastGPT v4.17.0的代理调用标准 |
| `AIPROXY_API_TOKEN` | 按获取的密钥填写 | 完成模型调用的身份验证 |

## 容易做错的三处
- 现象：模型配置的`AIPROXY_API_ENDPOINT`地址测试时返回连接失败。原因：未填写正确的代理地址，或未开放对应端口的访问权限。
- 现象：模型调用后返回的投标文稿未包含EL缺陷相关内容。原因：未开启`vision`配置项，无法解析EL缺陷图等图像文档。
- 现象：同一工作流ID多次调用时，前一次的对话内容干扰当前报价计算。原因：未配置正确的上下文保留轮次，导致冗余历史数据被带入模型。

## 怎么确认配好了
- 上传测试用EL缺陷图与IV测试报告，检查模型是否能准确提取隐裂位置与功率数值。
- 输入模拟的投标批次参数，验证模型输出的报价明细是否关联对应材料批次与电池片电流档位。
- 调用两次同一工作流ID，检查第二次调用的上下文是否仅包含本次请求的内容。
- 测试配置的`AIPROXY_API_ENDPOINT`地址，确认可正常发起模型调用请求。
