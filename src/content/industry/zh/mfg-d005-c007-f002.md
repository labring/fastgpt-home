# 冲压与板材成形的投标文稿与报价编制：向量模型与索引

## 这个品类的数据长什么样
该品类的数据来自汽车覆盖件、家电钣金、五金件企业的冲压车间日常生产文档与生产设备采集数据，涵盖冲压作业指导书、材料利用率表、模具点检表、首末件记录、尺寸检验报告、换模记录等固定格式文档，以及钢卷标签与质保书、冲床和送料机实时数据、模具管理系统、MES系统、三坐标或检具检测数据。数据更新节奏为每卷料、每批物料或每次换模时同步更新，文档包含标准化字段，如模具编号、材料牌号、料厚、加工节拍、检验尺寸偏差值等，无额外自定义非标准字段。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据多源分散且更新频率高，会对向量模型与索引环节带来三项核心约束。其一，多系统采集的异构数据需统一嵌入格式，避免不同来源的字段偏差影响向量一致性；其二，每卷料、每批物料或每次换模的高频更新，要求索引支持增量更新，避免全量重建耗时过长，保障投标前的数据时效性；其三，包含表格、记录等多类型文档，需适配不同结构的切分规则，避免关键加工参数被拆分丢失。另外，投标报价需关联模具、材料、检验数据，索引需保留字段关联关系，保障召回内容的业务关联性，需通过`defaultToken`与`maxToken`调整嵌入与上下文的长度限制。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配冲压作业指导书、材料利用率表的单块内容长度，避免关键参数跨块拆分 |
| 重叠长度 | 50–100 字符 | 保障换模记录、尺寸检验报告的上下文连贯性，防止关键工序描述被截断 |
| 相似度阈值 | 0.75–0.85 | 匹配冲压加工参数的语义相似度，过滤无关的模具点检记录，提升召回精准度 |
| 单次搜索上限 | 前 10 条 | 覆盖投标所需的多维度数据，同时避免过多冗余内容干扰报价核算 |
| `defaultToken` | 按代表性样本文档实测设置 | `defaultToken` 是直接文本分块使用的默认 token 数，请用本品类代表性原文实测调整；参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不表示向量维度、嵌入模型输入上限或检索/LLM 上下文。 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |

## 容易做错的三处
- 接入自定义向量模型时返回401状态码。原因是未正确配置向量模型的API密钥与请求地址，或使用了过期的密钥信息。
- 自定义文档切分后，知识库自动删除重复文档块导致索引顺序错乱。原因是默认开启了文档去重开关，未针对冲压生产记录的批次性重复内容关闭该配置。
- 配置向量模型后，搜索请求被误路由至大语言模型接口。原因是未在渠道配置中明确指定该渠道为向量嵌入专用，未关闭默认的大语言模型路由规则。

## 怎么确认配好了
- 上传一份典型的冲压作业指导书，检查向量嵌入后的分块结果，确认关键参数未被跨块拆分。
- 模拟发起一次投标报价相关的搜索请求，核对返回结果的文档类型与字段匹配度，调整相似度阈值至符合业务需求的范围。
- 提交增量数据更新任务，检查索引更新耗时与增量同步效果，确认未触发全量重建流程。
- 查看向量模型调用日志，确认请求地址与密钥配置正确，无路由至大语言模型的异常记录。
