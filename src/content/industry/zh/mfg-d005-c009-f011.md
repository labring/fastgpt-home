# 化学药制剂生产的投标文稿与报价编制：表单与交互

## 这个品类的数据长什么样
化学药制剂生产的数据来源包括经批准处方工艺、MES/电子批记录、LIMS、质量管理系统。日常文档涵盖主生产文件、批生产记录、批包装记录、检验记录、偏差/CAPA/变更记录等，字段包含物料批次号、称量值、工艺温度、偏差编号等，单位包括mg、L、℃、min等。数据更新频率为每批生产、每个关键工艺步骤，以及按固定监测计划执行。

## 这些特征在「表单与交互」这一环带来什么约束
多系统来源的数据要求表单支持跨源变量引用，避免手动录入的重复错误。按批更新的特性要求表单绑定批次维度的动态字段，确保每次投标引用的是当前批次的最新数据。GMP合规要求下，表单交互需保留审核留痕节点，且仅允许引用经质量放行的数据。严格的字段单位要求需要表单内置单位校验规则，防止格式不符的内容进入投标文稿。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 表单输入框配置 | 绑定`formInput`变量，启用单位校验规则 | 化学药制剂数据需匹配mg、L、℃等固定单位，避免格式错误 |
| 用户选择组件 | 预设`userSelect`批次号选项组 | 数据来自MES系统的已批准批次清单，减少手动输入失误 |
| 变量引用校验 | 开启严格格式校验，仅允许引用GMP放行字段 | 防止引用未审核的偏差或工艺数据，符合合规要求 |
| 上下文长度限制 | 800–1200 字符 | 适配单批次批记录的文档长度，保障模型处理效率 |
| 超时设置 | 600 秒 | 适配跨LIMS、质量管理系统的数据拉取耗时 |
| 表单提交触发 | 需经两级审核节点 | 匹配批放行审核的GMP流程，确保数据合规 |

## 容易做错的三处
- 提交投标文稿时弹出`quote type error`报错弹窗，原因是未按要求使用`formInput`或`userSelect`格式引用变量，混入了未校验的自定义字段。
- 配置自定义渠道后调用失败，返回`500`状态码，原因是未在FastGPT v4.17.0版本的渠道配置中正确填写授权密钥与接口地址。
- BI图表渲染后无数据，title或轴字段为空，原因是未绑定对应`formInput`的数据源字段，或字段格式不符合绘图要求。

## 怎么确认配好了
- 提交测试表单，检查是否触发单位校验报错，验证`formInput`绑定的字段是否正确返回对应数据。
- 选择`userSelect`的批次选项，确认下拉选项与MES系统的已批准批次清单一致。
- 触发变量引用操作，检查是否弹出`quote type error`报错，验证严格格式校验规则生效。
- 配置自定义渠道后，发起测试调用，确认返回结果正常，无`500`状态码报错。
