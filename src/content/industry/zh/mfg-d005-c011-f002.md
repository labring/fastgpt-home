# 半导体封装测试的投标文稿与报价编制：向量模型与索引

## 这个品类的数据长什么样
该品类的日常文档包含封装流程卡、键合与塑封参数、晶圆来料图、测试程序版本、良率报告、失效分析报告。数据来源包括晶圆测试图、MES系统、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格要求。数据更新频率为每生产批次、每颗芯片测试环节及每日更新，字段包含晶圆编号、测试电压电流参数、良率分级标识等，单位涉及伏特、毫安。

## 这些特征在「向量模型与索引」这一环带来什么约束
多源异构的数据类型与更新节奏，要求索引系统适配结构化参数文档与非结构化报告的混合处理。高频更新的生产数据需要增量索引同步策略，避免全量重建带来的计算资源消耗。专业字段的单位与标识需要在分块时保留上下文关联，防止语义割裂影响召回精度。投标报价编制需对齐客户规格与内部生产参数，因此索引召回需优先匹配客户指定的测试程序与良率标准，召回与业务需求强相关的文档片段。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配封装流程卡、良率报告的单段文本长度，避免单块token超出模型上限 |
| 重叠长度 | 100–200 字符 | 保留相邻分块的上下文关联，防止晶圆来料图的批次信息被截断 |
| 相似度阈值 | 0.72–0.85 | 区分专业参数与通用描述，匹配封测场景的语义相似度分布 |
| 单次搜索上限 | 前 8 条 | 覆盖ATE测试机的单批次测试参数条目，避免召回冗余数据 |
| `maxToken` | 8192 | 适配Qwen/Qwen3-Embedding-8B的输入长度限制，匹配长文本分块需求 |
| `defaultToken` | 1024 | 作为默认分块的基准token数，平衡召回精度与计算效率 |

## 容易做错的三处
- 现象：配置多个同名嵌入模型后，仅最后一个生效，界面展示的模型配置与实际调用的模型不一致。原因：系统以模型名称作为唯一识别标识，同名配置会覆盖此前的设置，未启用多模型分组管理功能。
- 现象：导入包含10000+行的Excel源数据后，单条召回数据块包含完整表头与整行业务内容，出现字段冗余与语义混淆。原因：未调整分块长度与重叠长度参数，默认分块尺寸过大，未针对Excel结构化数据做分块优化。
- 现象：长文本失效分析报告生成向量时触发截断报错，或召回结果缺失后半段关键内容。原因：未配置`maxToken`适配模型的输入长度上限，直接使用默认参数导致长文本被强制截断，未匹配封测场景的长文档处理需求。

## 怎么确认配好了
- 进入FastGPT v4.17.0的模型配置页面，检查嵌入模型的名称与调用路径是否与预设一致，确认无同名模型覆盖情况。
- 上传单份封装流程卡与长文本失效分析报告，预览分块结果，确认分块长度与重叠长度符合预设参数。
- 导入测试用Excel源数据，查看分块预览界面，确认单块数据未包含冗余表头或整行业务内容。
- 发起模拟召回测试，输入测试程序版本关键词，检查召回结果的条数与相似度是否符合单次搜索上限设置。
