# 半导体晶圆制造的投标文稿与报价编制：多轮对话与提示词

## 这个品类的数据长什么样
半导体晶圆制造的业务数据来源包括MES系统、设备FDC模块、缺陷检测与量测设备、晶圆图文件、工艺配方库与实验数据集。数据更新节奏随晶圆批次生成实时同步，日常工艺参数每日刷新，异常处置记录随事件触发更新。日常文档涵盖工艺流程卡、批次运行日志、设备配方参数、SPC统计图表、异常处置单、缺陷图谱与良率分析文档，字段包含晶圆批次标识、工艺步骤参数、设备运行参数、缺陷空间坐标与批次加工状态。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
该品类的超长工艺链与高频更新特征，要求多轮对话需绑定特定晶圆批次的上下文，通过`chatId`维持会话连贯性，避免跨批次数据混淆。实时生成的设备参数与异常记录，要求对话上下文需限定在当前会话的`messages`数组范围内，同时通过`variables`传入当前晶圆批次的专属标识，防止冗余数据干扰结果生成。纳米级参数耦合与跨模块归因需求，使得提示词需明确指定调用对应工序的工艺文档与批次运行记录，同时需限制单次召回的文档数量，避免参数过载。有限的返工窗口要求对话响应需快速定位关键异常，不宜加载过多非关联数据。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，具体参数设置如下：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 会话ID绑定 | 绑定当前晶圆批次的`chatId` | 避免跨批次会话数据混淆，维持单批次对话连贯性 |
| 上下文窗口大小 | 8000–12000 token | 适配单批次晶圆的工艺文档与运行记录长度，防止上下文溢出 |
| 单次召回文档数 | 前3–5条 | 聚焦当前工序的核心参数与异常记录，避免冗余数据干扰 |
| 提示词模板配置 | 限定调用工艺配方库与批次日志 | 明确指定检索范围为晶圆制造专属的工艺与批次数据 |
| 结果格式控制 | 禁用Markdown语法 | 适配投标文稿的标准化输出格式，避免格式混乱 |
| 会话超时设置 | 600 秒 | 匹配单批次报价编制的常规工作周期，防止会话中断 |

## 容易做错的三处
- 现象：发起新对话时无法延续之前的晶圆批次信息，需重新输入批次标识与工艺参数。原因：未绑定`chatId`参数，每次会话生成独立的对话标识，未关联当前批次的历史数据。
- 现象：AI生成的报价内容仅显示在侧边弹窗，主对话区域无直接输出内容。原因：未配置结果直接输出到对话流的设置项，仅启用了侧边预览模式。
- 现象：AI返回的投标文稿包含Markdown标题、列表或分隔符，不符合投标文档的排版要求。原因：未配置结果格式控制的禁用Markdown选项，提示词未明确限制输出格式。

## 怎么确认配好了
- 发起针对已知晶圆批次的测试对话，核对会话过程中是否自动关联之前输入的批次参数，无重新输入需求。
- 生成报价内容后，检查主对话区域是否直接显示结果，无侧边弹窗跳转。
- 查看AI返回的文稿内容，确认无Markdown格式的标题、列表或分隔符。
- 测试会话持续时长超过预设阈值，核对是否触发超时中断提示。
