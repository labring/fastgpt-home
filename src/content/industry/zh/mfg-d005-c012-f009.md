# 半导体晶圆制造的投标文稿与报价编制：模型接入与配置

## 这个品类的数据长什么样
半导体晶圆制造的日常文档包含工艺流程卡、批次运行记录、设备配方、SPC图、异常处置单、缺陷图谱、良率报告等。数据来源覆盖MES系统、设备FDC模块、缺陷检测与量测设备、晶圆图文件、工艺配方库与实验数据集。数据更新节奏涵盖每批晶圆生成、实时同步与每日归档，不同文档的字段与单位存在差异，例如包含纳米级线宽、批次良率、设备运行时长等参数。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据来源要求配置兼容不同格式的接入节点，适配MES导出的结构化表格、设备FDC的时序数据、晶圆图的可视化文件等。差异化的更新节奏需要匹配不同的同步周期，避免实时数据延迟或历史数据过期。多样的文档类型与纳米级参数要求配置足够的上下文长度，防止关键工艺信息被截断，同时需要适配不同解析规则，确保SPC图、缺陷图谱等可视化内容可被正确读取。

## 配置怎么定
FastGPT v4.17.0 版本下的配置项如下：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配晶圆制造多工序文档的长上下文需求，避免截断关键工艺参数 |
| `maxTokens` | 4000–6000 token | 平衡报价计算的精度与响应速度，适配复杂良率归因分析 |
| `quoteMaxToken` | 1500–2000 token | 确保引用的SPC图、缺陷图谱等附件内容完整，不影响判读 |
| `temperature` | 0.2–0.4 | 保证投标文稿的参数严谨性，减少随机偏差 |
| `AIPROXY_API_ENDPOINT` | 按本地部署模型的实际地址填写 | 适配本地部署QWQ-32B等模型的接入需求 |
| `AIPROXY_API_TOKEN` | 按模型部署生成的密钥填写 | 完成模型身份验证，保障接入安全 |

## 容易做错的三处
- 上传晶圆批次运行记录、缺陷图谱等附件后，模型无响应，简单应用与工作流应用均无效果。原因是未正确配置`maxContext`参数，长文档被截断后模型无法读取完整内容。
- 模型仅返回1个知识库匹配文本块，无法综合输出多工序的良率归因结果。原因是未合理设置`quoteMaxToken`参数，限制了召回内容的数量与长度。
- 配置文档解析节点后，模型无法读取SPC图、晶圆图等可视化附件。原因是未启用`vision`参数，未开启图像解析能力。

## 怎么确认配好了
- 上传单份晶圆工艺流程卡，检查模型是否能正确提取工序参数与良率数据，核对上下文长度是否符合配置预期。
- 发起包含多份附件的测试请求，确认模型能召回并引用符合配置要求的知识库文本块，验证内容完整性。
- 查看模型接入日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置正确，无连接报错或身份验证失败提示。
- 调整`temperature`参数后，验证生成的投标文稿参数一致性，确认偏差符合业务需求。
