# 半导体晶圆制造的投标文稿与报价编制：表单与交互

## 这个品类的数据长什么样
半导体晶圆制造的投标相关数据，通常来自MES系统、设备FDC模块、缺陷检测与量测设备、晶圆图文件、工艺配方库及实验数据集。数据更新节奏覆盖每批晶圆流转、实时参数采集与每日汇总。日常关联文档包含工艺流程卡、批次运行记录、设备配方、SPC控制图、异常处置单、缺陷图谱与良率报告，字段多涉及工艺参数、批次编号、良率数据与设备运行状态等。

## 这些特征在「表单与交互」这一环带来什么约束
该品类的多源高频更新数据，要求表单与交互环节支持实时拉取最新批次的工艺、良率数据，避免使用过期信息编制报价。多类型文档的字段格式差异，要求表单支持自定义字段映射与单位转换配置。超长工艺链与返工窗口有限的特点，要求选择类交互组件支持层级化筛选，快速定位对应工序与模块数据。同时，因数据错误会导致晶圆批报废等严重后果，表单需添加必填项校验与数据来源溯源标记，确保编制内容可追溯。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定，适配半导体晶圆制造场景的特有数据与业务需求。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 表单字段映射规则 | 按MES、设备FDC等数据源的字段名一对一绑定 | 匹配不同系统导出的标准化数据格式 |
| `userSelect` 组件层级结构 | 按工序-模块-设备的三级配置 | 适配超长工艺链的层级化数据筛选需求 |
| `formInput` 数据拉取时效 | 15–30 分钟 | 平衡数据实时性与系统负载 |
| 表单校验触发时机 | 提交前全量校验 | 避免无效数据进入报价编制流程 |
| 下拉选项数据源 | 绑定实时更新的工艺配方库 | 确保报价使用最新的设备与工艺参数 |

## 容易做错的三处
- `userSelect` 组件下拉列表为空，无法选择对应工艺模块。原因是未绑定实时更新的工艺配方库数据源，或数据源更新频率配置超出预设阈值。
- 表单提交后返回非预期的引用内容，即使未开启引用开关。原因是全局变量未正确配置动态赋值规则，导致遗留的上下文数据被带入编制流程。
- 表单字段校验不通过却未弹出明确提示。原因是未针对纳米级参数、批次编号等特有字段配置自定义校验规则，仅使用通用校验逻辑。

## 怎么确认配好了
- 打开`userSelect`组件的配置界面，确认下拉选项包含预设的工序、模块与设备三级层级结构。
- 触发`formInput`组件的数据拉取动作，检查拉取的字段与MES、设备FDC等数据源的实际字段完全匹配。
- 提交包含异常参数的测试表单，确认系统弹出对应字段的校验提示。
- 关闭引用开关后提交表单，确认返回内容未包含未授权的外部文档内容。
