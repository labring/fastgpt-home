# 印染与后整理的投标文稿与报价编制：工具调用与插件

## 这个品类的数据长什么样
该品类的核心数据来自客户色样、配方库、染化料批次记录、染缸控制参数、测色仪数据、定形机工艺参数及环保监测台账。数据更新频率为每缸、每批或每班，单次更新内容包含染色配方、称化料记录、染缸曲线、打样确认单、色差报告、定形工艺单、污水台账等文档。文档多包含结构化字段，如染料配比（g/L）、升温速率（℃/min）、保温时长（h）等，部分为时序格式的染缸运行曲线数据。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类数据的高频更新特性要求工具调用需支持实时拉取最新批次的染化料、染缸参数；结构化与时序混合的文档格式，要求插件需适配半结构化字段解析与时序数据提取；多源设备与现场记录的数据来源，要求工具调用可对接不同格式的数据源；颜色与工艺参数的精准匹配要求，需确保工具调用返回的内容无字段歧义，避免因数据错误导致投标偏差。

## 配置怎么定
本文基于 FastGPT v4.17.0 版本编写，以下配置项可直接在平台界面或配置文件中调整：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配染色配方、染缸曲线等半结构化文档的语义拆分，避免核心字段被截断 |
| 相似度阈值 | 0.75–0.85 | 匹配客户色样、历史配方库的精准度，过滤无关的非染整类业务数据 |
| 单次工具调用上限 | 前 3 条 | 控制单轮报价生成的数据源范围，防止上下文过载影响输出逻辑 |
| 工作流/API 工具选择配置 | 固定为 `functionCall` | 统一工具调用的触发规则，确保输出格式符合投标文稿的结构化要求 |
| 工作流/API 函数调用配置 | 强制启用 | 用于投标文稿中精准调用染色配方、染缸参数等业务数据，避免生成非预设内容 |
| 工具调用超时时间 | 600 秒 | 适配染整文档的批量解析与多数据源拉取，避免长时间等待导致流程中断 |

## 容易做错的三处
- 工具调用返回结果为空，原因是未配置对应染化料批次的数据源映射，导致无法拉取所需的业务数据。
- 插件处理染色配方文档时出现解析失败，原因是未将Doc2x插件的解析规则适配染整行业的结构化字段格式。
- 调用知识库时未返回关联的染缸曲线文件，原因是未配置工具调用的文件溯源参数。

## 怎么确认配好了
- 上传一份染色配方文档，触发工具调用，检查返回结果包含染料配比、升温参数等核心业务字段。
- 发起模拟投标请求，检查工具调用仅返回预设的染整业务数据，无冗余的非相关内容。
- 查看知识库溯源日志，确认调用时关联的染缸曲线、色差报告等文件被正确识别并关联。
- 调整单次工具调用上限为2，检查返回的数据源条数符合预设的数量要求。
