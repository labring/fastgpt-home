# 原料药与医药中间体生产的投标文稿与报价编制：表单与交互

## 这个品类的数据长什么样
本品类数据来自注册工艺文档、原料批次台账、DCS控制系统、称量系统、LIMS实验室信息管理系统、色谱数据系统与QMS质量管理系统，更新频率为每生产批次、每工艺步骤。日常文档包含批生产记录、物料平衡台账、反应与精制过程记录、清洁验证记录、杂质谱报告、偏差与变更申请文件。数据字段包含工艺步骤编号、反应温度、反应时长、收率数值、杂质含量、溶剂残留量、批次标识与供应商信息，单位涵盖摄氏度、小时、mg/g、ppm等。

## 这些特征在「表单与交互」这一环带来什么约束
多源跨系统的数据来源要求表单支持实时数据源绑定，避免静态录入的误差与滞后性。每批次的高频更新要求表单字段可随生产进度动态刷新，适配多步骤工艺的连续数据采集。多类专业文档的关联需求，要求表单支持嵌套分组与多文件上传，匹配批生产记录、杂质谱报告等不同格式的文档提交。合规性相关的偏差与变更字段，需强制关联审批节点，确保数据可追溯。投标文稿需复用生产数据，要求表单字段可直接映射至报价单与投标文档模板，减少重复操作。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 绑定LIMS系统API，自动填充对应批次的收率与杂质数据 | 减少手动录入误差，适配每批次的实时数据更新要求 |
| `userSelect` | 预设工艺步骤选项，按生产批次动态加载关联物料 | 适配多步骤生产的动态选项需求，避免选择错误 |
| 文件上传限制 | 单文件最大100 MB，支持PDF、CSV与色谱数据文件格式 | 匹配日常文档的大小与格式类型，适配杂质谱报告上传 |
| 表单校验规则 | 数值字段仅允许输入合法数值，必填字段包含批次号与工艺步骤编号 | 确保投标数据准确完整，符合合规性要求 |
| HTTP请求超时 | 超时阈值按实测标定 | 适配色谱数据文件解析的时长需求，避免请求中断 |
| 流程触发配置 | 表单提交完成后自动触发预设Python脚本 | 衔接生产数据与报价编制环节，提升编制效率 |

## 容易做错的三处
- 现象：输入框未显示文件上传按钮，提交表单时无法关联批生产记录。原因：未开启`formInput`的文件上传配置项，或未绑定对应存储路径的访问权限。
- 现象：用户选择模块的选项无法随生产批次动态更新，出现旧批次的物料选项。原因：未配置`userSelect`的动态数据源绑定，未关联批次台账的实时更新接口。
- 现象：调用Python脚本后无解析结果返回，表单字段为空。原因：未将表单上传的色谱数据文件正确传递至脚本接口，或脚本未适配色谱数据的格式解析。

## 怎么确认配好了
- 打开FastGPT v4.17.0的表单配置页面，检查`formInput`模块是否已绑定LIMS系统的API接口，确认输入框区域显示文件上传按钮。
- 测试`userSelect`模块，切换不同生产批次的标识，确认关联的物料选项自动更新。
- 上传一份标准格式的杂质谱报告文件，检查表单是否接收文件并显示元数据，确认提交后生成脚本执行日志。
- 填写非法数值或缺失必填的批次号字段，确认表单弹出对应校验提示。
