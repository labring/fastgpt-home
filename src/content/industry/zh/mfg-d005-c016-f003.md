# 变压器与高压电器制造的投标文稿与报价编制：多轮对话与提示词

## 这个品类的数据长什么样
该品类的数据围绕单台变压器与高压电器产品生成，日常文档包含绕制与器身装配记录、真空干燥记录、绝缘油报告、局放和耐压试验报告、铭牌参数表。数据来源为设计BOM、硅钢片与绝缘材料数据、真空与干燥设备记录、油化验结果、试验站检测报告，更新频率为每台产品或每批原材料批次更新一次，文档字段涵盖产品结构参数、试验检测数值、材料规格信息。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
该品类的数据特征为单台/批次更新、专业试验类文档占比高，为多轮对话与提示词环节带来多重约束。需绑定单台产品的专属参数与试验数据，避免上下文混淆，因此`chatId`需关联产品编号或批次号。提示词需适配专业电气术语，同时限定输出格式为投标文稿与报价的规范文本，避免使用非必要格式。需保留每轮对话中的产品参数记忆，确保后续提问可直接调用对应批次的绝缘油数据、试验报告内容，同时需加入参数校验逻辑，避免出现绝缘参数与试验结果不符的情况。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chatId` | 绑定产品唯一编号 | 确保对话上下文关联对应单台产品的专属数据，避免跨产品参数混淆 |
| `messages` | 保留前20轮对话内容 | 覆盖单台产品从参数确认到报价调整的全流程对话记忆 |
| `variables` | 传入产品BOM与试验报告ID | 供对话节点直接调用对应批次的绝缘油、耐压试验数据 |
| 输出格式限制 | 仅使用纯文本，禁用Markdown语法 | 匹配投标文稿的正式排版要求，避免格式混乱 |
| 单次召回上限 | 前3条匹配文档 | 聚焦最相关的试验报告与BOM数据，减少无关信息干扰 |
| 最大响应长度 | 1500–2000 token | 覆盖单台产品的报价与投标文稿核心内容，避免截断关键参数 |

## 容易做错的三处
- 输出结果仍包含Markdown语法。原因是提示词未明确限定禁用非纯文本格式，或格式校验规则未生效。
- 多轮对话上下文混乱，出现跨产品的参数混淆。原因是未通过`chatId`绑定单台产品的唯一标识，导致不同产品的对话上下文被共享。
- 工作流分支无法正确跳出，始终重复进入问题分类节点。原因是对话节点的返回值未配置为直接输出结果，未设置分支跳转的终止条件。

## 怎么确认配好了
- 发起测试对话，输入某台变压器的产品编号，核对输出内容是否仅包含该产品的试验数据与报价信息，无其他产品的参数。
- 检查输出结果，确认未出现Markdown格式的标题、列表等元素，仅包含纯文本内容。
- 触发工作流测试，验证对话节点返回结果后，工作流直接进入结束环节，未重复进入问题分类节点。
- 发布应用后，尝试直接发起对话，确认无需点击交互按钮即可进入问答环节。
