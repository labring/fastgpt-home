# 喷涂与涂装的投标文稿与报价编制：表单与交互
本文基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
本品类数据围绕汽车、家电、工程机械、金属家具涂装线产生，日常文档包含涂装工艺卡、涂料批次单、调漆记录、膜厚色差报告、烘炉曲线、缺陷返修单、VOCs台账。数据取自涂料供应商TDS/SDS、喷房与烘炉运行数据、色差仪、膜厚仪、环境监测设备及MES系统，更新节奏为每批涂料批次、每班生产周期及连续实时采集。

## 这些特征在「表单与交互」这一环带来什么约束
数据来源分散且包含仪器采集的数值型参数、纸质或电子文档的工艺记录，要求表单支持多格式数据导入与字段映射。高频率更新的特性要求交互环节实时关联最新批次的涂料参数、生产数据，避免使用过期信息。数据关联的合规性与质量风险，要求表单内置基础校验规则，拦截不符合涂装工艺要求的参数录入。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `formInput` | 绑定预设的涂装工艺参数模板 | 快速生成投标文稿的标准化工艺模块 |
| `userSelect` | 限定当前生产批次的涂料型号与供应商 | 确保投标数据使用最新可用的物料参数 |
| 数据导入触发时机 | 上传涂料批次单后自动填充关联字段 | 减少手动录入的重复操作 |
| 单次导入数据上限 | 前 5 条 | 匹配单批次涂料的常规检测项数量 |
| 字段字符限制 | 800–1200 字符 | 匹配投标文稿中工艺说明的标准篇幅 |
| 超时设置 | 600 秒 | 匹配单批次涂装投标数据的平均处理时长 |

## 容易做错的三处
- 现象：表单导入涂料TDS/SDS文档后部分字段为空。原因：未配置`formInput`的字段映射规则，无法识别文档中的参数标签。
- 现象：提交投标表单后出现超时报错。原因：超时设置取值小于单批次涂装数据的处理时长，导致数据加载中断。
- 现象：无法选择当前生产批次的涂料参数。原因：`userSelect`的数据源未关联最新的MES系统涂料批次数据，仅调用了历史缓存参数。

## 怎么确认配好了
1. 上传一份涂料批次单，核对表单是否自动填充预设的关联字段。
2. 尝试录入不符合涂装工艺要求的参数值，确认是否触发对应校验提示。
3. 切换可选的涂料型号，核对`userSelect`的可选列表是否同步更新。
4. 提交包含完整参数的表单，确认数据是否成功同步至目标文档模板。
