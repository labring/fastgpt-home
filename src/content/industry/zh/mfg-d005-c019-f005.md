# 塑料注塑成型的投标文稿与报价编制：工具调用与插件

## 这个品类的数据长什么样
塑料注塑成型场景的业务数据主要来自树脂批次物性表、注塑机运行参数、模温机日志、MES系统、尺寸与外观检测记录。日常关联文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验表、巡检表、换料清机记录。数据更新节奏为每生产批次、每次换模换料、每班一次，单份文档包含模温、充填时间、保压压力、原料含水率、回料比例等专用字段，单位涵盖摄氏度、秒、兆帕等工业常用标准单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据更新频率高且依赖多源工业设备接口，工具调用需实时拉取最新的注塑参数与生产记录，否则投标报价与文稿将出现数据过时问题。专用字段与工业单位要求插件调用时需严格匹配参数格式，避免因单位转换或字段缺失导致报价偏差，例如回料比例、原料含水率等参数的准确传递。多份关联文档的批量调用需限定单次请求范围，防止接口过载。同时，投标文稿需关联模具履历与首件检验数据，工具调用需精准定位对应文档片段，避免无关信息干扰生成结果。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | auto | 适配多工具并行调用场景，覆盖注塑参数拉取、文档检索等需求 |
| 工作流/API 函数调用配置 | 启用 | 强制大模型使用预设插件，确保调用格式符合工业接口规范 |
| 插件请求超时时间 | 300 秒 | 适配注塑设备数据拉取的典型耗时，避免因等待超时中断调用 |
| 插件重试次数 | 2 次 | 应对工业设备通信偶发中断的场景，减少调用失败率 |
| 单次检索文档数 | 前10条 | 覆盖核心关联文档范围，避免检索结果过多干扰生成 |
| 工具调用参数校验 | 启用 | 校验原料含水率、模温等专用字段的合法性，防止无效参数传入 |

## 容易做错的三处
- 插件调用返回字段为空：现象为生成的投标文稿中原料干燥参数缺失，查看工具调用日志发现返回的接口数据字段为空。原因是未在插件配置中正确绑定树脂批次号作为查询参数，导致无法拉取对应原料的干燥记录。
- 大模型调用提示欠费：现象为界面弹出API欠费提示，但后台显示账户余额充足。原因是未在插件配置中正确关联预设的API密钥，导致调用走了默认计费通道。
- 工具调用结果条数不足：现象为生成的文稿未包含最新的换料清机记录。原因是未配置正确的文档检索范围，仅检索了注塑工艺卡而未覆盖换料清机记录等关联文档。

## 怎么确认配好了
- 触发一次工具调用，核对返回的注塑工艺参数与本地存储的最新工艺卡内容是否一致。
- 模拟插件调用失败场景，检查是否触发预设的重试机制并在重试成功后正常返回结果。
- 查看工具调用日志，确认所有配置的参数均被正确传入，包括树脂批次号、模具编号等专用字段。
- 生成一份测试投标文稿，核对其中引用的模具履历数据与MES系统导出的历史记录是否匹配。
