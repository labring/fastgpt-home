# 安全环保与特殊作业管理的投标文稿与报价编制：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自法规标准、在线环保监测设备、气体检测仪、作业人员资质档案、设备隔离清单及监管平台。日常文档包含风险辨识记录、动火/受限空间/吊装等作业票、环境监测日志、危废台账、排放监测报表、事故与隐患整改报告。数据更新随单次作业完成实时提交，或按监测周期、定期检查要求同步。文档字段包含作业时间、气体浓度值、资质有效期、隔离设备编号等，单位涵盖ppm、立方米、天等专业计量标识。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源要求检索覆盖不同格式与类型的文档，避免遗漏合规性内容。实时或高频更新的数据需要知识库支持增量同步，确保投标文稿引用的内容与现场最新状态一致。专业字段与单位要求检索匹配精准的术语，不能出现语义偏差。高风险的业务属性要求召回结果具备高置信度，避免因错误引用导致合规风险。投标文稿的篇幅限制要求检索结果需控制数量，防止上下文溢出。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配安全环保专业术语的精准度要求，避免低相关内容混入投标文稿 |
| `limit` | 前8条 | 覆盖作业票、资质、法规等多类文档，同时控制上下文长度符合FastGPT v4.17.0的处理上限 |
| `searchMode` | 语义搜索 | 适配专业术语的语义匹配，识别作业场景的关联内容 |
| `usingReRank` | 开启 | 对召回结果二次排序，过滤低置信度的合规性内容，降低投标出错概率 |
| `datasetSearchUsingExtensionQuery` | 开启 | 扩展检索范围，关联法规标准与现场监测数据的关联内容，提升检索全面性 |
| `collectionIds` | 按EHS业务标签筛选 | 仅导入风险辨识、作业票、危废台账等专属数据集，避免无关数据干扰检索结果 |

## 容易做错的三处
- 检索结果包含非EHS业务的文档，原因是未配置`collectionIds`筛选规则，混入了其他品类的知识库内容。
- 对话中无法展示知识库内的图片链接，原因是未开启图片外链的上下文传递配置，或图片链接未绑定到对应业务文档字段。
- 导入PPT格式的知识库仅显示文字无图片，原因是未开启PPT图片提取配置，或图片解析流程未正确关联到FastGPT服务。

## 怎么确认配好了
- 发起包含EHS作业场景的测试查询，核对检索结果仅包含风险辨识、作业票等专属业务文档。
- 上传包含图片的PPT文档到知识库，确认导入后可提取图片链接并在对话中正常展示。
- 调整`similarity`阈值，观察检索结果的相关度变化，确认阈值符合业务精准度要求。
- 触发检索引用合并功能，核对重复的文档条目被自动合并，减少上下文冗余。
