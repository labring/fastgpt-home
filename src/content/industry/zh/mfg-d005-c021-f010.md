# 家具与木制品制造的投标文稿与报价编制：知识库检索与召回

## 这个品类的数据长什么样
该品类数据主要来自订单设计系统、板材与木材批次台账、数控开料钻孔设备、ERP/MES系统及含水率检测设备。日常文档包含拆单图、开料清单、封边钻孔程序、涂装工艺说明、五金物料清单、试装与包装记录，既有结构化的表格数据，也有带尺寸标注的图纸类文档。数据更新随订单生成、每日生产同步、每批材料到货完成，字段包含板件尺寸、材料批次号、工艺参数、五金型号等，单位涉及毫米、千克、立方米等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据特征为检索召回环节带来多重约束。定制订单驱动的生产模式导致单订单数据关联性强，检索需精准匹配板件尺寸、材料批次等专属参数，避免跨订单数据混淆。多类型文档并存的结构，要求检索同时适配结构化表格数据与非结构化工艺文档，需调整分块规则适配不同格式的数据长度。高频更新的数据源要求定期同步知识库，确保检索结果使用最新的板材参数、开料数据等信息。板件数量多且参数细分度高，需控制单条召回数据的颗粒度，避免信息过载影响报价与文稿编制效率。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.72–0.85 | 匹配板件尺寸、五金型号等精准业务字段，覆盖常规检索的精度需求，可按实测标定调整 |
| `limit` | 前6–8条 | 适配单份投标文稿需引用的多类细分数据，避免过多结果占用上下文空间 |
| `searchMode` | `mixedRecall` | 同时适配结构化开料清单、五金清单与非结构化拆单图、工艺文档，覆盖品类多类型文档特征 |
| `usingReRank` | 开启 | 对召回结果按相关性重排序，提升细分参数如板材含水率、封边工艺的匹配精度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 针对投标场景的专业术语扩展查询，优化对拆单、涂装等细分领域内容的召回效果 |
| `collectionIds` | 按业务模块绑定对应数据集 | 区分拆单数据、五金清单、工艺文档等知识库集合，避免跨模块数据干扰检索结果 |

## 容易做错的三处
- 现象：检索结果返回后，大模型输出内容中包含「引用标记：［1］」字样。原因：未关闭知识库引用标记的自动拼接配置，或检索时未过滤冗余的元数据信息。
- 现象：单条召回数据块过大，导致检索颗粒度不足。原因：未针对品类的Excel开料清单、五金清单等结构化数据调整分块规则，沿用通用分块参数导致数据块包含过多行内容。
- 现象：检索结果遗漏特定批次的板材参数。原因：未定期同步更新知识库的板材批次数据，或绑定的数据集未包含最新的ERP/MES同步数据。

## 怎么确认配好了
- 上传单份开料清单与五金清单的结构化数据，执行检索测试，核对召回结果的字段是否与源数据一致。
- 触发一次模拟投标文稿编制的查询，检查大模型输出内容中是否出现未预期的引用标记字样。
- 手动修改一条测试用的板材批次数据，同步更新知识库后执行检索，确认召回结果包含最新修改的内容。
- 调整`similarity`参数区间，对比不同取值下的检索结果数量与相关性，确认匹配精度符合业务需求。
