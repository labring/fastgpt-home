# 工业仪器仪表制造与校准的投标文稿与报价编制：多轮对话与提示词

## 这个品类的数据长什么样
本品类数据来源于设计文件、标准器监测数据、校准软件输出、实验室信息系统及客户量程要求。单台设备每次校准即更新专属数据，日常文档包含装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录。数据字段包含被测量程、误差计算值、溯源编号、环境温湿度、校准日期，对应单位涵盖帕斯卡、摄氏度、ppm等专业测量单位。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
单台设备每次校准即更新专属数据，多轮对话需精准关联对应设备的历史校准记录，避免跨设备数据混淆。日常文档类型多样且字段专业，提示词需明确区分校准记录、投标报价相关字段，防止提取错误的溯源信息或单位。投标文稿需整合多台设备的校准数据，多轮对话需逐步引导用户提供设备清单、量程要求等信息，避免一次性输入过载导致关键信息遗漏。

## 配置怎么定
本文档基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chatId` | 绑定单台设备的唯一校准编号 | 确保多轮对话上下文仅关联当前投标设备的校准数据，防止跨设备混淆 |
| `messages` | 保留前20条对话历史与关联知识库条目 | 本品类数据关联单台设备的多份校准记录，需保留足够上下文以区分不同设备的投标参数 |
| `variables` | 绑定设备ID、校准日期、量程范围字段 | 精准传递专业字段信息，适配投标文稿的正式格式要求 |
| 单次搜索上限 | 前 8 条召回结果 | 单台设备的校准记录通常不超过10份，过多召回会引入无关数据，干扰投标文稿编制 |
| 响应token上限 | 1500–2500 token | 投标文稿需包含多段校准数据与报价细节，足够的token可保证内容完整覆盖计量证书、误差分析等内容 |
| 问题优化 | 开启，按实测标定 | 校准数据字段专业，优化提示词可简化专业术语表述，适配投标文稿的正式格式 |

## 容易做错的三处
- 现象：调试预览界面对话触发报错，提示「未找到匹配的校准数据」。原因：未通过`variables`绑定设备唯一标识，导致系统无法调取对应校准数据。
- 现象：特定问题的最大响应token自动变为200，回复内容过短。原因：未全局设置响应token上限，或未针对专业校准数据场景单独调整token阈值，系统触发默认限制。
- 现象：检索结果包含无关设备的校准记录，与当前投标项不匹配。原因：未通过`chatId`绑定单台设备的唯一编号，导致上下文关联了多台设备的历史数据。

## 怎么确认配好了
- 输入单台设备的校准编号，核对对话上下文仅展示该设备的校准记录与相关参数。
- 触发专业术语转换，核对提示词优化后的表述符合投标文稿的正式格式要求。
- 提交包含多台设备的投标需求，核对系统仅召回对应设备的校准数据，无跨设备混淆。
- 测试复杂校准数据的提取，核对响应token未触发默认限制，内容完整覆盖投标所需字段。
