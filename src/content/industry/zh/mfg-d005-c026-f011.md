# 有色金属冶炼与电解的投标文稿与报价编制：表单与交互

## 这个品类的数据长什么样
该品类的日常文档包含配料单、熔炼记录、电解槽况记录、化验报告、阳极阴极质量记录、环保台账。数据来源涵盖精矿与辅料分析、DCS系统、槽电压电流监测、化验室检测、能源与环保监测设备。数据更新频率随原料批次、单炉或单槽作业、实时工况变化。字段包含原料批次号、炉槽编号、成分参数、电流电压数值、排放指标等，无统一固定格式，多按生产环节分类存储。

## 这些特征在「表单与交互」这一环带来什么约束
该品类的数据来源分散且更新节奏不一，要求表单需支持多源数据的快速调用与校验；文档类型多样且字段无统一格式，要求交互需适配多类型文件的上传与字段映射；业务环节涉及炉况、成分核算等敏感参数，错误录入会引发生产风险，要求表单需配置严格的校验规则；同时投标报价需依次确认原料、炉况、化验结果等多层数据，要求交互需按业务流程分层触发。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` 校验规则 | 绑定业务字段的必填与范围校验 | 依据是该品类数据涉及炉况、成分参数，错误会引发生产风险 |
| 用户选择层级 | 按原料-炉况-化验结果分层触发 | 依据是投标报价需依次确认各环节数据 |
| 文件上传 | 支持默认全部通用格式 | 依据是日常文档包含配料单、化验报告等多类型文件 |
| 表单提交超时 | 600 秒 | 依据是复杂金属平衡核算需要充足处理时间 |
| 知识库文件夹选择 | 绑定冶炼业务专属分类文件夹 | 依据是该品类知识库按生产环节分类，便于快速检索 |

## 容易做错的三处
- 表单提交后出现字段为空的报错，原因是未配置`formInput`的必填校验规则，导致未采集的业务参数未被拦截。
- 文件上传时无法识别工业表格格式，原因是未开启默认全格式支持，仅开放了通用文档格式，无法适配配料单的CSV格式。
- 多层用户选择出现重复提问，原因是未按业务流程分层配置用户选择的触发逻辑，导致重复请求相同环节的数据。

## 怎么确认配好了
- 使用FastGPT v4.17.0版本的表单编辑器，进入文件夹选择弹窗，确认仅显示冶炼业务专属的分类文件夹。
- 上传一份CSV格式的配料单，确认表单可以自动提取原料批次、成分参数等字段。
- 故意留空`formInput`配置的必填字段，如原料批次号，确认会弹出对应校验提示。
- 触发多层用户选择流程，依次选择原料批次、炉号，确认仅在完成上一步选择后才会加载下一层选项。
