# 模具设计制造的投标文稿与报价编制：工具调用与插件

## 这个品类的数据长什么样
该品类的数据来自客户产品模型、模流或成形仿真结果、CAD/CAM文件、机加工与测量数据、试模样件。日常产生的文档包含模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历。数据更新按项目节点触发，每次试模或改模后都会同步更新。数据字段包含模具型腔数、材料牌号、加工公差、试模次数、工时定额等，多数采用毫米、兆帕、小时等通用工业单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据类型包含结构化文档、大体积CAD文件、仿真分析结果，对工具调用的文件解析能力提出要求。数据更新频率随试模、改模动作动态调整，要求插件能够实时拉取最新的项目数据，避免使用过期的工艺参数或工时数据。专业字段较多且存在工业单位规范，工具调用需精准匹配投标文稿所需的特定字段，无法通过泛化提取获取完整报价依据。同时，模具项目的延期风险要求工具调用流程具备快速反馈能力，确保报价编制的时效性。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本制定。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | 指定自定义工具 | 投标文稿需调用模具设计制造专属的成本核算、工艺参数查询工具，适配该品类的专业数据需求 |
| 工作流/API 函数调用配置 | 强制触发工具调用 | 需从CAD文件、仿真报告中提取型腔数、材料用量等核心报价字段，确保数据准确匹配投标要求 |
| 工具调用超时时间 | 1200 秒 | 模具CAD文件、仿真报告加载耗时较长，需预留足够时间完成数据解析与提取 |
| 工具返回字段过滤 | 仅保留模具材料、加工工时、试模次数 | 投标文稿仅需核心报价相关字段，避免冗余信息干扰AI生成内容 |
| 上下文窗口大小 | 8000–12000 token | 需完整加载零件图、DFM报告等文档内容，确保工具调用时能获取完整的项目上下文 |
| 工具调用重试次数 | 3次 | 应对模具数据加载时的临时网络波动 |
| 文件上传大小限制 | 1000 MB | 适配大型CAD装配文件的上传需求 |

## 容易做错的三处
- 现象：平台界面未显示工具调用日志。原因：未开启全局的工具调用日志开关，或配置的自定义工具未启用日志上报功能。
- 现象：生成的投标文稿缺少模具加工公差字段。原因：未在`functionCall`中指定提取该字段的规则，导致工具未返回对应数据。
- 现象：上传的CAD文件无法同步到工具调用参数中。原因：未配置文件类型的工具入参映射，导致上传的项目文件未被正确绑定到报价计算工具。

## 怎么确认配好了
- 发起一次模拟投标报价请求，检查工具调用是否触发并返回模具相关的成本、工时数据。
- 查看平台的工具调用日志面板，确认每次调用都有完整的请求和返回记录。
- 上传一份测试用的CAD零件图，验证工具是否能正确提取型腔数、加工公差等字段。
- 检查AI生成的投标文稿中是否标注了数据来源，如“数据来自本次上传的零件图”。
