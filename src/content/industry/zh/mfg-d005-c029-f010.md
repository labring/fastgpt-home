# 模具设计制造的投标文稿与报价编制：知识库检索与召回

## 这个品类的数据长什么样
模具设计制造的日常文档包含模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历。数据来源包括客户产品模型、模流或成形仿真结果、CAD/CAM文件、机加工与测量数据、试模样件信息。数据更新按项目推进，每次试模或改模后同步更新。文档包含工艺参数、部件尺寸、材料标识、缺陷记录等字段，单位包含毫米、材料牌号、加工工时等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
模具设计制造的多类型文档混合，既有结构化工艺参数又有非结构化的试模描述，要求检索召回需兼顾语义匹配与关键词匹配。数据按项目与试模改模更新，需优先召回最新版本的文档片段，避免使用过时的改模通知或试模报告。投标场景需关联项目特定的模具类型，需通过项目元数据过滤召回结果，防止无关项目的模具数据混入。此外，文档包含精密尺寸与工艺参数，需控制召回结果的精准度，避免低匹配度的无关片段干扰报价与文稿编制。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 模具数据包含精密工艺参数，该区间可平衡召回覆盖率与精准度，过滤低匹配度的无关片段 |
| `limit` | 前8条 | 投标文稿需覆盖多维度的工艺、试模数据，8条可提供足够上下文且不超出常规上下文窗口限制 |
| `searchMode` | hybrid | 兼顾语义匹配与关键词匹配，适配模具文档中既有工艺描述又有明确参数编号的内容 |
| `usingReRank` | 开启 | 多召回结果中，按与当前投标项目的相关性重排，避免低相关的旧试模报告优先返回 |
| `datasetSearchUsingExtensionQuery` | 开启 | 投标问题常包含项目特定的模具类型描述，扩展查询可覆盖更多相关文档片段 |
| `collectionIds` | 按项目绑定的知识库集合ID | 隔离不同投标项目的模具数据，避免召回无关项目的文档 |

## 容易做错的三处
- 召回结果未附带对应文档文件名，无法快速定位原始参考资料。原因是未配置检索参数返回文档元数据，未开启文件名关联的召回开关。
- API调用返回的回答未包含知识库匹配内容。原因是未在对话应用中绑定对应模具项目的知识库集合，或请求参数未指定正确的`collectionIds`。
- 检索测试界面无法直接编辑索引参数。原因是FastGPT v4.17.0版本中该编辑按钮已调整至知识库内容管理页面，需进入对应文档列表完成索引调试。

## 怎么确认配好了
- 发起检索测试，检查返回结果是否附带文档文件名与所属项目信息。
- 调用API接口时传入指定的`collectionIds`，验证返回结果是否包含模具工艺卡、试模报告等对应文档片段。
- 调整`similarity`阈值，观察召回结果的精准度变化，确认阈值符合业务需求。
- 开启`usingReRank`后，验证返回结果的排序是否优先匹配当前投标项目的最新试模数据。
