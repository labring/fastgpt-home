# 热处理的投标文稿与报价编制：表单与交互

## 这个品类的数据长什么样
热处理相关数据来源于材料牌号库、客户技术要求、炉温控仪表、炉温均匀性测试报告、硬度计与金相检测设备数据，以及车间MES系统。数据更新频率为每炉次、每批工件。日常产生的文档包含热处理工艺卡、装炉布局图、实时炉温曲线、硬度与金相分析报告、设备点检表、异常处置单。核心字段包括材料牌号、加热温度、保温时长、冷却方式、硬度值，配套单位为摄氏度、小时、HRC等行业通用标准。

## 这些特征在「表单与交互」这一环带来什么约束
每炉次的高频更新要求表单支持单炉次快速录入与多炉次批量提交，避免重复操作带来的误差。多源数据来源决定表单需要支持对接设备与系统的字段映射，减少手动输入的错误概率。多样的支撑文档要求表单具备附件上传与关联功能，将工艺卡、炉温曲线等文件与对应投标条目绑定，确保投标文稿的支撑材料完整。专业字段与固定单位的存在，要求表单预设单位选项与合理范围校验，降低信息错误率。严重的出错后果要求表单设置必填项与异常校验，确保投标文稿的核心信息完整准确，避免因参数错误导致后续生产不合格。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 单炉次表单录入 | `formInput` 启用快速录入模式 | 适配每炉次的高频数据更新需求，提升录入效率 |
| 材料牌号选择 | `userSelect` 关联预设材料牌号库 | 快速调用标准化数据，避免手动输入的牌号错误 |
| 单位预设 | 加热温度用摄氏度，保温时间用小时，硬度用HRC | 符合行业通用字段单位，减少手动输入误差 |
| 表单输入校验 | 加热温度范围800-1200摄氏度，保温时间0.5-8小时 | 匹配多数热处理设备的运行参数区间，避免不合理参数录入 |
| 附件上传配置 | 支持上传工艺卡、炉温曲线等文件，单文件上限1000 MB | 匹配投标文稿所需的支撑材料要求，适配常见文档大小 |
| 表单提交校验 | 标记工艺参数、检测结果为必填项 | 确保投标文稿的核心信息完整，避免遗漏关键内容 |

## 容易做错的三处
- 配置知识库变量引用时未明确关联热处理专属数据字段，导致搜索结果仅返回通用文档，无法调取炉温曲线、硬度报告等投标支撑材料。原因是未按要求配置变量引用的参数范围，仅指定了通用文档分类，未匹配热处理品类的专属数据字段。
- 表单提交后出现「必填字段未填写」的报错文案。原因是未设置工艺参数、检测结果为必填项，导致投标文稿缺失核心信息。
- 上传炉温曲线文件时触发「文件大小超出限制」的报错。原因是未配置上传文件大小上限，上传的文件超出系统默认限制。

## 怎么确认配好了
- 手动录入一条热处理工艺参数，检查加热温度、保温时间等字段是否自动匹配预设单位。
- 上传一份符合格式的炉温曲线文件，确认附件上传功能正常且自动关联到当前表单条目。
- 尝试提交未填写加热温度或硬度值的表单，确认触发对应报错提示。
- 配置知识库变量引用，搜索热处理工艺卡关键词，确认能调取对应品类的专属文档数据。
