# 电机与发电机制造的投标文稿与报价编制：HTTP 接口与外部系统

## 这个品类的数据长什么样
这个品类的数据来自电磁设计数据、铜线和绝缘材料批次记录、绕线设备、平衡机、电气试验台输出，以及ERP/MES系统。日常生成的文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试记录、型式与出厂试验报告。数据更新节奏为每台产品或每批次产品完成后更新，每次产品型式变更时同步更新。数据字段包含绕组匝数、绝缘材料批次号、动平衡精度值、试验电压值等，对应不同环节有专属单位标识。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据来源分散在多类设备与业务系统，且更新节奏为单次或批次级，因此HTTP接口需要支持按需触发的单台/批量数据拉取，适配不同投标项目的定制化数据需求。日常文档包含多类专属字段与单位，接口需要支持自定义字段映射规则，避免跨系统的单位转换错误。每次产品型式变更会触发数据更新，接口需兼容动态参数拉取，无需每次变更都重新配置接口规则。同时，投标文稿与报价编制需要关联试验数据，接口需返回结构化的合规数据格式，支撑后续文档生成环节。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer ${企业专属API密钥}` | 适配多租户的接口鉴权需求，避免未授权访问内部业务系统 |
| `variables` | `{"batchId": "当前投标批次号", "productType": "指定电机型号"}` | 传递批次与型号参数，精准拉取对应产品的试验数据与工艺记录 |
| `responseData` | 仅返回试验报告、工艺卡的结构化字段 | 过滤冗余数据，提升接口响应效率，适配投标文稿的精准数据调用 |
| 接口超时时间 | `600 秒` | 部分试验数据生成需要较长时间，避免提前超时中断请求 |
| 字段映射规则 | 按实测标定的单位转换规则 | 适配该品类专属的匝数、电压、平衡精度等单位，确保数据准确性 |

## 容易做错的三处
- 现象：接口调用返回`self-signed certificate`报错，SSL握手失败。原因：未配置信任内部设备或系统的自定义SSL证书，直接调用HTTPS接口。
- 现象：`responseData`返回字段为空，无法获取对应试验数据。原因：未正确传递`variables`参数中的批次号或型号，接口无法匹配到对应数据。
- 现象：接口请求提前中断，返回超时错误。原因：超时时间设置过短，未适配该品类试验数据生成的耗时需求。

## 怎么确认配好了
- 调用配置后的接口，检查返回状态码为200，且`Authorization`鉴权校验通过。
- 查看`responseData`返回的字段，确认包含绕组匝数、动平衡精度等该品类专属数据字段。
- 传递不同的`variables`参数，确认接口能返回对应批次或型号的试验数据。
- 测试调用内部HTTPS接口，确认无SSL相关报错，证书信任配置生效。
