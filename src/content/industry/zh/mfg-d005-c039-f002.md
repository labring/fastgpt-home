# 电机与发电机制造的投标文稿与报价编制：向量模型与索引

## 这个品类的数据长什么样
本品类的核心数据来自电磁设计系统、铜线与绝缘材料批次台账、绕线设备、平衡机、电气试验台，以及ERP/MES系统。日常产出的文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试记录、型式与出厂试验报告。数据更新频率为每台电机或每批产品生成一次，每次产品型式变更时同步更新。文档包含匝数、绝缘等级、试验电压、温升数值等专用工业字段，无通用办公文档的标准化格式框架。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类的数据更新频率高且单批次数据关联紧密，要求索引支持增量更新与批量关联检索。专用工业字段的术语体系与通用文档差异较大，向量模型需适配电磁、绝缘、机械平衡的专业词汇。不同文档的格式不统一，分块策略需兼顾单段内容的完整性与跨文档的参数关联。数据关联错误会直接导致投标文稿引用错误的工艺参数，引发后续生产或运行事故，因此检索的准确性要求高于通用场景。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配绕组工艺卡、试验报告的单段专业内容长度 |
| 重叠长度 | 100–150 字符 | 保留跨分块的绕组匝数、绝缘参数关联信息 |
| 相似度阈值 | 0.75–0.85 | 过滤低匹配度的非相关试验数据，保障检索准确性 |
| 单次搜索上限 | 前 8 条 | 覆盖单台电机的全流程试验记录与工艺文档 |
| `maxToken` | 4096 token | 适配工业文档的长段落上下文，避免截断核心参数 |
| `defaultToken` | 按实测标定 | 适配不同批次材料的专用术语向量匹配 |

## 容易做错的三处
- 现象：检索结果出现不相关的绝缘处理记录，导致投标文稿引用错误的绝缘参数。原因：相似度阈值设置过低，未过滤低匹配度的跨批次数据，引发专业参数混淆。
- 现象：索引任务长时间处于等待状态，后台日志显示分块超时。原因：分块长度设置过大，超出系统单块处理的承载上限，未结合电机文档的单段内容长度调整。
- 现象：向量检索返回的结果字段为空，无法提取绕组匝数信息。原因：未针对绕组工艺卡的专用字段配置索引映射，导致专业参数未被正确向量化。

## 怎么确认配好了
- 上传单份完整的绕组工艺卡，检查分块后的文本是否保留完整的匝数、绝缘等级等核心字段。
- 发起包含同一文档块多字段的检索请求，确认系统会按字段优先级返回匹配度最高的专业参数结果。
- 查看索引任务日志，确认单份文档的处理时长符合预期，无持续超时报错。
- 在FastGPT v4.17.0的索引管理界面，确认向量模型已正确绑定阿里-emb3，且索引字段包含专用工业参数。
