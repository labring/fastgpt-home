# 电机与发电机制造的投标文稿与报价编制：工具调用与插件
本页面基于FastGPT v4.17.0版本配置。

## 这个品类的数据长什么样
本品类数据来自电磁设计数据库、铜线与绝缘材料批次台账、绕线设备运行日志、平衡机检测记录、电气试验台报告，以及ERP/MES系统。数据更新节奏为每台成品或每批投产批次更新，每次产品型式变更时同步更新。日常产出文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试记录、型式与出厂试验报告，核心字段包含绕组匝数、绝缘层厚度、动平衡剩余不平衡量、试验电压、额定功率，对应单位为匝、毫米、克·厘米、千伏、千瓦。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类的数据按单台或单批次更新，且包含多维度的工艺、检测与生产参数，工具调用与插件需匹配这一特征。需绑定对应批次的物料、设备运行与试验数据，避免跨批次参数混用导致投标文稿出错。核心字段带有专属单位，插件需配置单位校验逻辑，防止匝数与绝缘厚度等不同类型字段混淆。产品型式变更会触发数据同步更新，工具调用需关联最新的型式版本，确保投标文稿使用的参数与当前生产标准一致。投标需汇总多台/多批次数据，插件需支持批量拉取多源系统的结构化数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工作流/API 工具选择配置 | 固定为`auto` | 需自动匹配绕组工艺、绝缘检测、试验报告等多类结构化数据的调用，自动模式可适配多源异构数据结构 |
| 工具调用触发规则 | 按投标批次分组触发 | 本品类数据按单台或单批次更新，分组触发可避免跨批次参数混用 |
| 单次调用数据条数上限 | 12 条批次数据 | 匹配单份投标文件的常规覆盖范围，避免单次调用资源过载 |
| 字段单位校验 | 启用字段单位匹配 | 本品类核心字段带有专属单位，可防止匝数、绝缘厚度等不同类型字段混淆 |
| 超时阈值 | 300 秒 | 适配单批次数据拉取的常规响应时长，避免调用超时中断 |
| 工作流/API 函数调用配置 | 开启强制参数校验 | 确保投标文稿引用的参数与ERP/MES系统的批次数据完全匹配 |
| 上下文窗口上限 | 7000–9000 token | 适配多份试验报告与工艺卡的文本长度，满足投标文稿的内容拼接需求 |

## 容易做错的三处
- 工具调用返回参数为空，界面显示调用失败。原因是未绑定对应批次的ERP/MES数据，导致插件无法拉取绕组匝数、动平衡剩余不平衡量等核心投标所需参数。
- 调用日志中未显示完整的request body内容，无法排查参数传递异常。原因是未开启调试模式下的请求日志存储，导致无法追溯完整调用细节。
- 内置的DuckDuckGo搜索插件无法正常返回国内电机原材料的报价信息。原因是插件未适配国内网络环境，无法正常拉取公开报价数据源。

## 怎么确认配好了
- 发起一次测试调用，查看返回的参数是否包含当前选定批次的绕组匝数、动平衡剩余不平衡量等核心字段。
- 检查调试日志，确认完整的request body已被记录，可追溯调用的参数传递过程。
- 测试搜索插件，确认可拉取与本品类相关的原材料报价数据，且返回结果符合国内网络环境的访问要求。
- 验证`toolChoice`的自动模式是否能自动匹配多类结构化数据，无需手动指定调用的函数类型。
