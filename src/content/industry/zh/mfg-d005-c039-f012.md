# 电机与发电机制造的投标文稿与报价编制：部署与升级

## 这个品类的数据长什么样
该品类的数据来自电磁设计系统、铜线与绝缘材料批次台账、绕线设备运行日志、平衡机检测记录、电气试验台报告，以及ERP与MES生产管理系统。日常生成的业务文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试记录、型式与出厂试验报告。数据按每台电机、每批产品或每次型式变更更新，核心字段包含绕组匝数、接线方式、浸漆烘干参数、振动与温升测试值、效率与耐压指标。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据按单台、批次或型式变更更新，且包含大量专业测试参数与工艺记录，部署时需适配多源异构数据的接入与解析。升级过程中需保证原有索引不丢失，同时兼容新增的型式变更相关字段。由于核心业务文档包含绕组匝数、耐压测试等强关联字段，部署时需配置精准的字段映射规则，避免检索时出现字段错位。频繁的批次级更新要求部署的存储与查询组件具备低延迟增量更新能力，防止全量重索引带来的业务中断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150 个连接` | 适配多批次数据同时接入的并发请求，避免数据库连接耗尽 |
| `MONGODB_URI` | 指向SSD存储挂载的专用MongoDB实例，配置读写分离 | 存储大量非结构化的试验报告与工艺文档，读写分离提升查询性能 |
| `PG_URL` | 连接部署在企业级SSD的PostgreSQL实例 | 存储结构化的批次数据、绕组参数与ERP同步字段，保障事务一致性 |
| `REDIS_URL` | 配置为单实例内存上限`8 GB` | 缓存高频访问的试验参数与检索结果，降低数据库查询压力 |
| `STORAGE_S3_ENDPOINT` | 指向企业内部对象存储服务地址 | 存储原始试验数据与文档备份，适配企业现有存储架构 |

## 容易做错的三处
- 现象：升级到FastGPT v4.17.0后，原有电机试验报告检索不到内容，界面返回“未找到匹配文档”提示。原因：未执行增量索引更新，仅完成程序升级，未同步更新批次数据的向量索引。
- 现象：docker容器启动失败，控制台返回`500 Internal Server Error`，日志显示数据库连接超时。原因：`MONGODB_URI`配置的实例地址未开放对外端口，或docker-compose.yml中未正确配置容器与数据库的网络互通。
- 现象：上传绝缘处理记录时出现文件解析失败，界面提示“权限不足”。原因：未配置`FILE_TOKEN_KEY`导致的文件权限校验失败，无法读取原始文档内容。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`DB_MAX_LINK`配置的连接数可正常并发接入，无连接超时报错。
- 上传一份绕组工艺卡文档，验证解析后可正确提取绕组匝数、接线方式等核心字段，无字段缺失。
- 触发一次增量索引任务，验证新上传的试验报告可被正常检索，检索结果包含正确的批次与参数信息。
- 查看Redis监控面板，确认缓存命中率稳定，无大量重复查询导致的资源过载。
