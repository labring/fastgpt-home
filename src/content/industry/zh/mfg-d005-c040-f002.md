# 电池PACK与储能系统集成的投标文稿与报价编制：向量模型与索引

## 这个品类的数据长什么样
本品类的核心数据来自电芯分容设备、MES系统、焊接扭矩工具、BMS软件及EOL试验台，日常文档包含电芯配组规则、单台产品BOM、焊接与扭矩记录、BMS刷写日志、绝缘耐压报告、EOL测试报告及系统配置清单。数据更新频率为每生产一台PACK或储能柜同步一次，每次BMS软件版本变更也会触发数据更新，单份文档包含电芯型号、配组参数、扭矩值、测试阈值等明确字段，无额外冗余统计项。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类的数据分散且更新粒度细，单份文档包含大量带单位的工程参数，需确保向量建模保留参数与上下文的绑定关系，避免语义割裂。投标场景需快速召回同类型产品的历史文稿与报价数据，索引需支持跨文档的参数匹配召回，不能仅依赖纯文本匹配。高频更新的单台产品数据要求索引支持增量更新，避免全量重建带来的处理延迟，同时需适配多源异构数据的统一向量化格式。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配单份工程文档的语义完整性，避免拆分后参数上下文断裂 |
| 重叠长度 | 100–150 字符 | 保留相邻块的参数关联信息，防止跨块语义丢失 |
| `defaultToken` | 4096 | 适配FastGPT v4.17.0版本的token限制，覆盖BMS配置清单、EOL测试报告的长文本向量化需求 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| 相似度阈值 | 按实测标定 | 适配工程参数的语义匹配精度，需结合历史投标数据调整 |
| 单次召回上限 | 前10条 | 控制召回结果的冗余度，避免无效信息干扰报价编制 |

## 容易做错的三处
- 向量相似度计算结果超出常规区间（如10000+），原因是未正确配置相似度阈值的归一化规则，误用了非0-1区间的评分体系。
- 知识库导入数据集后长期处于索引中状态，原因是未适配本品类多源异构数据的格式，未提前统一工程参数的字段命名规则，导致索引解析失败。
- 无法找到指定的embedding模型的可用频道，原因是未在平台配置页添加模型接入密钥，或未开通模型的调用权限。

## 怎么确认配好了
- 上传一份典型的BMS配置清单文档，检查分块后的语义完整性，确认无参数被拆分到无关块中。
- 输入一条投标相关的查询（如“某型号电芯的配组规则”），核对召回结果的相关性，调整相似度阈值至符合业务需求的区间。
- 导入一份更新后的焊接扭矩记录，检查索引是否自动完成增量更新，无需全量重建。
- 查看平台的模型配置页，确认无可用频道提示消失，模型调用状态正常。
