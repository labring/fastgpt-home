# 石油炼制的投标文稿与报价编制：模型接入与配置

## 这个品类的数据长什么样
石油炼制的投标与报价相关数据，来源于DCS/APC控制系统、LIMS化验系统、罐区计量系统、原油评价报告、设备管理系统及能源管理系统。日常支撑文档包含操作规程、生产方案、物料平衡表、馏出口质量报告、联锁台账、交接班记录与变更管理文件。数据更新节奏涵盖实时、每班及每日，字段包含原油性质参数、装置负荷指标、产品质量标准等，需适配多源异构的非统一格式数据接入。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据来源要求模型接入层支持跨系统数据的统一解析与格式适配，避免出现字段不匹配或数据丢失。不同更新频率的数据源，需要配置分层的上下文加载规则，实时数据需优先加载以保障报价的时效性，每班及每日的批量数据需支持批量导入。投标文稿与报价涉及的工艺参数多且专业，要求模型上下文能覆盖完整的业务文档片段，同时需限制无关数据的干扰，避免生成内容偏离炼油业务场景。此外，数据的严谨性要求模型调用需保障权限安全，防止敏感工艺数据泄露。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | `8000–12000 token` | 覆盖炼油业务多源文档的完整上下文，避免工艺数据截断 |
| `maxTokens` | `2000–3000 token` | 适配投标文稿与报价的常规输出长度，满足专业内容的完整输出 |
| `quoteMaxToken` | `500–800 token` | 限定引用的工艺数据片段长度，保障引用内容的精准性 |
| `temperature` | `0.2–0.4` | 降低生成随机性，保障投标文稿与报价的严谨性与专业性 |
| 工作流/API 工具选择配置 | `auto` | 支持自动调用工具处理多源异构数据，适配qwen3系列模型的调用逻辑 |
| `AIPROXY_API_ENDPOINT` | 企业专属代理地址 | 保障数据传输的安全性与调用权限的可控性 |
| `AIPROXY_API_TOKEN` | 企业专属访问令牌 | 验证调用权限，防止未授权访问敏感业务数据 |

## 容易做错的三处
- 调用接口返回401未授权错误，原因是`AIPROXY_API_TOKEN`配置错误，未填写有效专属令牌或令牌过期。
- 生成的投标文稿中缺少关键工艺参数，原因是`maxContext`设置过小，无法加载完整的原油评价或装置运行数据。
- 调用失败后无法查看详细日志，原因是未开启API调用日志的留存配置，无法定位OneAPI调用的具体异常环节。

## 怎么确认配好了
- 测试调用`AIPROXY_API_ENDPOINT`对应的接口，验证`AIPROXY_API_TOKEN`的有效性，检查返回状态码是否正常。
- 导入一段完整的炼油工艺文档，验证`maxContext`的设置是否能完整加载文档内容，无截断或丢失。
- 生成一段包含工艺参数的报价片段，检查`maxTokens`和`quoteMaxToken`的设置是否符合输出长度要求，无提前截断。
- 调整`temperature`参数，验证生成内容的严谨性是否符合炼油业务的专业要求，无过度发散的内容。
