# 精细化工间歇合成的投标文稿与报价编制：模型接入与配置

## 这个品类的数据长什么样
精细化工间歇合成的业务数据来自配方与工艺库、原料批次、反应釜DCS、称量系统、LIMS、仓储系统。日常文档包含批生产指令、投料复核单、反应过程记录、清场记录、检验报告、偏差与变更单，每个字段对应投料质量、反应温度、反应时长、检验结果等参数，单位涉及千克、升、摄氏度、小时等。数据更新频率为每批生产或每个关键步骤，随批次切换与工艺调整实时更新，且涉及配方保密内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据按批次与关键步骤更新，且包含敏感的配方与工艺信息，要求模型接入配置需支持按批次关联上下文，同时限制敏感数据的泄露范围。多品种、多步骤的生产模式要求配置可灵活切换工具调用逻辑，适配不同批次的投料与报价规则。多源数据来源要求配置统一的接口适配规则，避免不同系统的数据格式差异导致模型输入异常。实时更新的数据需要配置合理的上下文长度，保证模型能获取最新的生产与库存信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 匹配单批次精细化工合成的全流程文档长度，覆盖投料、反应、检验等环节的上下文信息 |
| `maxTokens` | 2000–3000 token | 保证投标文稿与报价的生成内容完整，包含工艺参数、原料成本核算、交付周期等细节 |
| `quoteMaxToken` | 1500 token | 限制引用的业务文档长度，避免引入无关的历史批次数据，聚焦当前投标项目的需求 |
| 工作流/API 工具选择配置 | auto | 自动触发投料复核、成本核算、工艺校验等工具调用，适配多步骤的投标编制逻辑 |
| `temperature` | 0.3–0.5 | 平衡报价的严谨性与灵活性，避免出现不符合工艺规范或成本核算错误的内容 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写内网代理地址 | 对接企业内部的模型代理服务，适配内网部署的安全要求，避免敏感数据外流 |
| `AIPROXY_API_TOKEN` | 按实际分配的密钥填写 | 保证模型接入的身份验证安全，符合配方保密的合规要求 |

## 容易做错的三处
- 现象：平台页面无可用模型列表显示，仅完成了`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置。原因：未在FastGPT v4.17.0的部署配置中完成模型代理的白名单绑定，或代理服务与FastGPT部署的网络不通。
- 现象：模型映射配置保存后未生效，调用时未触发预设的业务工具。原因：`toolChoice`参数未设置为auto，或未将对应工具与精细化工的工艺文档库完成关联绑定。
- 现象：调用模型返回连接报错或格式异常，使用阿里云百炼或Ollama镜像时均出现问题。原因：`AIPROXY_API_ENDPOINT`填写的地址未包含正确的路径后缀，或`AIPROXY_API_TOKEN`的权限未覆盖对应模型的调用范围。

## 怎么确认配好了
- 进入FastGPT v4.17.0的模型管理页面，查看已配置的代理模型是否正常显示，点击测试按钮查看是否返回正常的基础响应内容。
- 上传单批次的投料复核单与工艺文档，调用模型生成投标文稿片段，检查是否包含正确的工艺参数与原料成本信息。
- 将`toolChoice`设置为auto后，触发包含多步骤逻辑的测试请求，确认模型自动调用了对应的工具校验模块。
- 查看系统运行日志，确认模型调用的请求头中携带了正确的`AIPROXY_API_TOKEN`，无身份验证失败的报错记录。
