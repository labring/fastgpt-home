# 纸浆造纸的投标文稿与报价编制：知识库检索与召回

本页面的配置方案适用于FastGPT v4.17.0版本。

## 这个品类的数据长什么样
这个品类的数据源涵盖木浆废纸批次档案、DCS/QCS生产控制系统、纸机在线测量设备、实验室检测报告、能源与水处理系统日志。文档类型包含配浆单、打浆记录、纸机运行台账、在线质量曲线、断纸与换品记录，字段包含浆料配比、打浆度（°SR）、纸克重（g/㎡）、水分占比（%）、纸病类型等。数据更新节奏分为实时（纸机运行参数）、每班（班组生产报表）、每卷（单卷纸质量档案），无固定批量更新周期。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据的多频率更新要求知识库支持增量同步，避免全量更新占用过多计算资源。结构化字段与数值型参数的占比高，要求检索支持结构化匹配与数值范围查询，不能仅依赖关键词模糊匹配。单卷纸的生产数据关联紧密，投标报价需匹配同纸种、同生产批次的历史数据，因此检索需支持按纸种、批次字段过滤。多类型文档混合存储，需区分配浆参数、质量曲线、业务台账等不同文档类型，避免召回结果交叉干扰。高速连续幅材生产模式下，单卷纸的参数连续性强，检索需避免召回跨批次的无效数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.80 | 匹配纸浆造纸的结构化数值字段与业务关键词，区间按实测标定，避免召回无关的历史配浆数据 |
| `limit` | 前6条 | 纸浆造纸生产数据关联紧密，单次召回过多会超出模型上下文限制，6条可覆盖单卷纸的典型配浆、运行参数 |
| `searchMode` | `vector+keyword` | 兼顾配浆单、质量曲线的数值特征与投标文稿中的业务关键词（如「120g/m²白卡纸」），提升召回精准度 |
| `usingReRank` | 开启 | 针对多类型文档的混合特征，重排可过滤掉相似度达标但业务不匹配的结果，比如将同纸种的有效数据排在前列 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展投标需求的关键词，比如将「高松厚度配浆」扩展为对应浆料配比、打浆度的业务术语，匹配历史文档 |
| `collectionIds` | 绑定纸浆造纸投标知识库的专属集合ID | 避免检索到其他品类的知识库数据，确保召回结果仅来自本行业务文档 |

## 容易做错的三处
- 导入外部网页链接后检索不到对应内容，提示无匹配结果。未处理网页登录限制，FastGPT无法抓取需授权的页面内容，导致知识库导入数据缺失。
- 调用知识库时提示「未选择知识库」，但调试预览时可正常召回结果。生产环境的知识库集合ID配置未同步到API调用参数，或环境变量未正确绑定对应知识库集合。
- 检索结果条数远低于预期，且包含大量无关的非纸浆造纸业务数据。未配置`collectionIds`限定专属知识库集合，或`similarity`阈值设置过低，召回了低匹配度的其他品类文档。

## 怎么确认配好了
- 上传单条纸机运行记录文档，触发检索，检查返回结果是否包含该文档的关键字段（如打浆度、纸机车速）。
- 设置`similarity`阈值为0.75，输入测试查询「150g/m²涂布白纸板配浆方案」，核对召回结果的纸种匹配度是否符合预期。
- 开启`usingReRank`后，对比开启前后的召回结果排序，确认高匹配度的业务文档排在前列。
- 检查知识库更新日志，确认实时上传的配浆单、换品记录可在10分钟内同步到检索库。
