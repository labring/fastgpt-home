# 肉制品与屠宰加工的投标文稿与报价编制：表单与交互

## 这个品类的数据长什么样
该品类的数据涵盖检疫证明、屠宰与分割记录、配料腌制记录、热加工记录、冷链温度记录、微生物检验报告等。数据来源包括动物检疫信息、供应商批次台账、生产追溯系统、温度采集设备、金属检测设备与实验室检测结果。更新节奏按生产批次、每班产出更新，冷链温度需连续采集更新。字段包含批次编号、检疫合格编号、原料溯源码、加工温度值、检测指标数值等，部分字段需匹配对应检疫与生产环节的关联关系。

## 这些特征在「表单与交互」这一环带来什么约束
该品类的数据关联要求强，批次与检疫信息需一一对应，因此表单需设计字段联动逻辑，确保选择生产批次时自动匹配对应检疫编号。生熟分区管控要求表单区分生肉与熟制品的填报分类，避免交叉污染相关字段混淆。连续采集的冷链温度数据量较大，表单需支持批量导入或分段录入，减少手动输入工作量。数据更新频率高，表单需对接实时生产数据接口，避免使用过时的手工录入信息。同时，微生物检验结果需与生产环节参数绑定，表单需添加关联校验规则，防止参数不匹配的情况提交。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 字段联动规则 | 配置批次编号与检疫编号自动匹配，生熟制品分类隔离 | 匹配品类的批次关联与生熟管控要求 |
| 批量导入上限 | 单次导入不超过300–500条温度记录 | 适配每班连续采集的温控数据量 |
| 单次输入上限 | 单字段输入不超过1200字符 | 适配投标文稿的单字段录入规范 |
| `formInput` | 设置为必填，绑定溯源码与检验结果字段 | 确保核心业务数据完整录入 |
| `userSelect` | 配置生熟制品分类选择项 | 区分生肉与熟制品的填报分类 |
| 超时阈值 | 设置为600秒 | 适配生产设备数据接口的常规响应时长 |

## 容易做错的三处
- 其他工作流分支无法跳转至该表单节点，系统弹出“节点链路不支持跨分支复用”提示。原因：未开启表单节点的全局复用配置，导致节点仅能在当前分支内调用。
- 开启输入引导并配置自定义词库后，调试预览界面弹出“quote type error”报错。原因：自定义词库的引用格式未匹配FastGPT的变量调用规则，词库内容未按要求包裹标识。
- 提交表单后出现“批次与检疫信息不匹配”的提示，但手动核对数据无误。原因：表单联动规则未绑定正确的生产批次数据源，导致自动匹配逻辑出错。

## 怎么确认配好了
- 调用表单节点的调试功能，输入模拟的生产批次编号，确认自动匹配的检疫编号与预设数据一致。
- 导入批量温控数据，确认导入条数不超过设定的上限，且数据字段无格式错误。
- 尝试从其他工作流分支跳转至该表单节点，确认跳转成功且无链路报错。
- 输入不符合关联规则的测试数据，确认系统弹出对应的校验提示。
