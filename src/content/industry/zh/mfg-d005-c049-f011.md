# 过程质量与成品放行的投标文稿与报价编制：表单与交互

## 这个品类的数据长什么样
本品类数据来源包括MES系统、在线检测设备、实验室检测记录、工艺参数台账、客户质量标准及历史缺陷库。数据更新节奏为每生产批次、每班实时采集，或按检验节点持续同步。日常文档包含控制计划、巡检记录表、SPC统计报表、成品检验报告、不合格品评审单、放行审批单及质量月报，核心字段含检验项编号、检验结果数值、批次标识、设备编码、缺陷类型编码及放行权限标记，无固定百分比类统计字段。

## 这些特征在「表单与交互」这一环带来什么约束
多源数据接入要求表单支持跨系统字段自动映射，避免重复录入。高频更新节奏要求表单内置实时校验规则，拦截不符合检验逻辑的输入。多样的文档类型要求表单提供模板切换功能，适配控制计划、检验报告等不同场景的字段布局。特定编码类字段需预设可选值，降低手动输入错误率。放行环节的权限约束要求表单集成角色校验，仅允许对应权限用户提交或修改审批状态。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 配置检验项编号、合格件数、缺陷项数为必填字段，数值范围限定为非负整数 | 匹配品类核心业务字段的合法性要求，贴合业务逻辑 |
| `userSelect` | 预设合格、不合格、待评审3个固定选项 | 对应成品放行的标准判定规则，减少手动输入错误 |
| 模板切换设置 | 提供控制计划、检验报告、放行单3种预设模板 | 适配品类内多文档类型的投标与报价编制需求 |
| 实时校验配置 | 开启字段合法性校验，超时阈值设为10秒 | 匹配高频更新的数据校验要求，避免长时间等待 |
| 权限绑定配置 | 关联质量工程师、放行审批员两类角色 | 符合放行环节的权限管控规则，防止越权操作 |

## 容易做错的三处
- 调用API访问发布后的表单交互时无提示弹窗。原因是未在工作流配置中开启`formInput`或`userSelect`的前端渲染开关，仅配置了后端数据存储。
- 表单字段未按预设选项填充，出现自定义非法值。原因是未启用`userSelect`的固定选项限制，允许自由输入导致不符合业务编码规则。
- 表单提交后未触发校验报错，导致不合格数据流入后续环节。原因是未开启实时校验开关，仅依赖后端校验延迟拦截。

## 怎么确认配好了
- 打开工作流编辑页面，查看`formInput`和`userSelect`组件是否已绑定品类核心业务字段。
- 测试提交表单，验证是否弹出预设的判定选项弹窗，无自定义输入入口。
- 模拟无权限角色访问表单，确认无法修改或提交字段内容。
- 输入非合法数值（如负的合格件数），验证是否弹出实时校验提示。
