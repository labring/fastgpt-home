# 过程质量与成品放行的投标文稿与报价编制：部署与升级

## 这个品类的数据长什么样
本品类的数据来自制造企业的MES系统、在线检测设备、实验室系统、工艺参数库、客户质量标准及历史缺陷库，用于支撑投标文稿与报价编制中的质量承诺、检验方案等内容。数据按生产批次、班组周期持续采集，覆盖在制品到成品的全流程质量相关文档，包括控制计划、巡检记录、SPC报表、成品检验报告、不合格品评审单、放行单及质量月报。数据字段包含检验项参数、缺陷类型、判定结果、放行权限标识等，严格贴合业务实际采集的内容，无额外冗余字段。

## 这些特征在「部署与升级」这一环带来什么约束
本品类多源数据的接入需求，要求部署环节需提前配置跨系统数据同步的适配规则，保障投标文稿编制所需的质量数据准确同步。高频更新的生产批次数据，会对数据库连接稳定性提出要求，升级时需验证`DB_MAX_LINK`等参数的适配性，避免影响报价编制的实时数据调用。多样的质量文档结构，需要在部署阶段预设文档解析模板，避免升级后出现解析异常，影响投标文稿的内容生成。涉及放行权限的敏感数据，需同步配置存储加密与访问控制规则，保障数据合规性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `DB_MAX_LINK` | `20–30 个连接` | 适配每班、每批高频的数据采集请求，避免连接池耗尽导致的业务中断 |
| `MONGODB_URI` | 指向企业内部MongoDB实例，配置访问白名单 | 存储大量非结构化的检验报告、SPC报表等质量文档，支撑投标文稿的内容提取 |
| `REDIS_URL` | 配置为本地缓存实例，设置`600 秒`过期时间 | 缓存高频查询的客户标准、历史缺陷数据，降低数据库负载，保障报价编制效率 |
| `STORAGE_S3_ENDPOINT` | 指向企业内部对象存储地址 | 存储巡检记录、成品检验报告等大体积质量文档，适配投标资料的归档需求 |
| `FILE_TOKEN_KEY` | 按企业密钥规范生成`32 位随机字符串` | 保障上传的质量文档的访问权限，仅授权指定团队用于投标文稿编制 |
| `ROOT_KEY` | 按企业内部安全策略生成 | 保障平台管理权限的安全性，仅授权质量工程团队配置相关业务规则 |

## 容易做错的三处
- 现象：调用批量质量数据处理接口时，前端页面无响应或返回`504 Gateway Timeout`报错。原因：未调整`DB_MAX_LINK`参数，导致数据库连接池耗尽，请求超时。
- 现象：查看会话日志时，部分质量文档的解析结果为空或字段缺失。原因：未预设对应控制计划、检验报告的文档解析模板，升级后解析规则不匹配业务文档结构。
- 现象：升级到FastGPT v4.17.0后，无法正常调用外部质量数据接口。原因：沿用了旧版本的One API相关配置，未切换为适配新版本的代理配置。

## 怎么确认配好了
- 访问平台管理界面，查看数据库连接配置项的连通性提示，确认无异常报错。
- 上传一份典型的SPC报表文档，验证解析后能提取出控制限、采样数据等核心字段，用于投标文稿的质量方案生成。
- 发起单批次的质量数据同步任务，观察系统无连接超时类报错，保障数据同步的稳定性。
- 检查会话日志模块，确认能正常记录质量相关的会话操作及返回结果，便于后续排查业务问题。
