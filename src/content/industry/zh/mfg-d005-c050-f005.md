# 通用机械设备装配的投标文稿与报价编制：工具调用与插件

## 这个品类的数据长什么样
通常，通用机械设备装配品类的核心数据来自PLM、ERP、零件检验数据、装配工具采集系统、试验台、MES及客户技术协议。日常文档包含多层级BOM、装配工艺卡、扭矩记录、间隙调整记录、试运行报告、出厂检验单与装箱清单。数据更新频率为每台设备或每订单一次，不同订单的装配参数、检验记录存在显著差异。

## 这些特征在「工具调用与插件」这一环带来什么约束
多层级BOM与分散的数据源（PLM、MES、试验台等）要求工具调用需支持跨系统数据拉取与层级解析，确保投标文稿中的BOM数据准确完整。按订单更新的装配数据，要求插件调用需实时同步最新的检验、调试记录，避免使用过期参数生成报价与投标内容。多品种定制装配的特性，要求工具调用需适配不同机型的专属参数规则，需针对每类设备调整调用逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | 自动触发 | 适配投标文稿生成时自动调用装配相关数据的场景 |
| `functionCall` | 启用 | 用于调用BOM、扭矩记录等结构化数据源接口 |
| 单次调用文档上限 | 前10条 | 避免单次上下文过载，确保工具调用响应速度 |
| 插件超时时间 | 120秒 | 适配多数据源拉取的延迟情况，避免任务中断 |
| 结果校验阈值 | 85%以上匹配度 | 确保投标数据与实际装配参数的一致性 |
| 文件解析格式 | 按上传文件自动识别 | 适配不同类型的装配文档格式，如BOM表格、工艺卡PDF等 |

## 容易做错的三处
- 调用指定接口返回500错误：调用`/api/core/dataset/update`时返回500状态码，浏览器可正常访问但API调用失败。原因：未在工作流中配置对应数据集的访问权限，导致接口鉴权不通过。
- 语义检索工具返回连接错误：调用语义检索和全文检索工具时返回“Connection error”，无法获取装配文档内容。原因：未配置插件的数据源地址白名单，或网络策略限制了跨域访问。
- Doc2x工具调用异常：FastGPT v4.9.1版本中调用Doc2x工具时返回文件读取错误，报错包含异常“result”字段。原因：未指定Doc2x工具的文件解析编码参数，或上传的装配文档格式超出工具支持范围。

## 怎么确认配好了
- 在FastGPT v4.17.0版本中触发投标文稿生成工作流，检查工具是否自动拉取最新的BOM、装配工艺卡等数据。
- 手动调用配置的插件接口，查看返回结果是否包含指定的装配参数字段，如扭矩值、间隙参数等。
- 模拟数据源断开场景，检查工具是否返回对应错误提示，无异常中断。
- 查看工作流日志，确认`toolChoice`和`functionCall`的调用参数符合配置要求。
