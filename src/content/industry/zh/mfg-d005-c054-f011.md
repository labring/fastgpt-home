# 钣金下料折弯的投标文稿与报价编制：表单与交互

## 这个品类的数据长什么样
钣金下料折弯的业务数据主要来自CAD/CAM软件、订单BOM、板材库存系统、激光切割机与折弯机设备、MES系统。日常产出的文档包含展开图、数控下料程序、折弯工艺卡、套料图、首件记录、工序流转卡。数据更新节奏随订单生成、每日库存盘点、每次生产换型调整。核心字段包含折弯补偿量、板材厚度、展开尺寸、套料利用率，单位多为毫米、千克、平方米。

## 这些特征在「表单与交互」这一环带来什么约束
由于该品类以多品种小批量生产为主，表单需要灵活适配不同规格的钣金工件参数。数据来源依赖CAD/CAM导出的图纸参数，因此表单需支持导入标准化的图纸数据文件。数据更新频率较高，表单需实时或定时同步板材库存、设备产能等动态数据。核心字段的校验直接影响后续生产质量，表单需对折弯补偿量、展开尺寸等关键字段设置必填与数值范围校验，避免孔位错位、板材浪费等问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 表单字段分组 | 按图纸类型、板材参数、工序数据分块 | 适配多品种小批量的不同业务场景 |
| 默认折弯系数预设 | 按常见碳钢材质设为1.6-2.0毫米 | 匹配钣金下料折弯的通用工艺参数 |
| `userSelect` 触发时机 | 当表单提交前校验通过后触发 | 避免无效工具调用 |
| 数据同步间隔 | 每5分钟同步一次板材库存数据 | 匹配板材库存的更新频率 |
| `formInput` 格式限制 | 仅允许上传CAD导出的CSV格式参数文件 | 对齐数据来源的文档格式 |
| 表单校验规则 | 对展开尺寸、折弯补偿量设为必填且数值大于0 | 规避孔位错位、板材浪费风险 |

## 容易做错的三处
- 现象为提交投标报价表单后，系统未生成对应报价数据，原因是未配置`userSelect`的触发条件，导致智能体无法自主判断是否调用参数校验工具。
- 现象为导入的钣金展开图参数缺失或解析错误，原因是未对`formInput`设置格式校验，非标准CAD导出文件无法被正确识别。
- 现象为语音输入的投标需求未转化为可编辑文本，原因是未绑定语音转写模块与表单输入字段，导致语音内容无法同步至交互流程。

## 怎么确认配好了
- 上传一份标准钣金CAD导出的CSV格式参数文件，检查表单是否自动填充对应字段。
- 提交包含异常参数（如负的折弯补偿量）的表单，检查是否触发校验提示。
- 触发`userSelect`逻辑，检查智能体是否自主调用参数校验工具。
- 等待5分钟，检查板材库存数据是否在表单中同步更新。
