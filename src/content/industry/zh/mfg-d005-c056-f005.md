# 锂离子电芯制造的投标文稿与报价编制：工具调用与插件

## 这个品类的数据长什么样
该品类数据来源包括原材料批次台账、生产MES系统、浆料与涂布检测设备、车间露点监测装置、化成分容柜及实验室测试设备。日常生成的文档包含配料记录、涂布辊压参数、卷绕或叠片记录、注液记录、化成分容数据、OCV与安全测试报告。数据更新节奏为每生产批次、每只电芯实时同步，电化学体系对水分、洁净度与批次一致性要求极高，后段化成分容环节数据生成周期较长。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散且实时性要求高，工具调用需对接多类异构数据源，需适配不同设备的协议格式。单批次与单电芯数据粒度细，单次调用需处理的字段数量多，需限定单次调用的返回规模与存储上限。电化学体系的敏感性要求调用结果的字段精度匹配生产参数的单位规范，比如浆料固含量、辊压厚度需对应精确的计量标准。化成分容数据的长周期特性，需插件支持历史数据的批量拉取与关联查询，避免重复调用低效接口。同时投标文稿需按生产环节依次填充数据，工具调用需遵循生产流程的顺序逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | 固定为`auto` | 适配多源异构数据源的调用场景，自动匹配对应生产数据的工具 |
| 单次工具调用返回条数 | 前6–10 条 | 匹配单批次电芯生产数据的字段规模，避免返回内容过载 |
| 工具调用超时阈值 | 90–150 秒 | 适配化成分容数据的长周期查询需求，避免超时中断 |
| 单批次数据拉取上限 | 400–600 MB | 匹配单批次电芯生产数据的存储规模，避免内存过载 |
| 工作流/API 函数调用配置 | 开启参数校验 | 确保调用返回的浆料固含量、辊压厚度等数据符合锂电生产的单位规范 |
| 多工具调用顺序 | 按生产流程排序 | 匹配投标文稿需按配料、涂布、装配等环节依次填充数据的要求 |

## 容易做错的三处
- 现象：LLM在一次提问中未按指定顺序调用MCP工具，返回结果顺序混乱。原因：未配置多工具调用的执行顺序规则，或未绑定生产流程的依赖逻辑。
- 现象：FastGPT启动失败，日志显示MCP服务连接超时或协议不匹配。原因：未更新FastGPT配置中的MCP服务地址与端口，或升级后未重启相关服务进程。
- 现象：工具调用返回的字段为空或单位错误，无法填充到投标文稿中。原因：未开启`functionCall`的参数校验模式，未绑定锂电生产数据的专用字段映射规则。

## 怎么确认配好了
- 测试调用单类生产数据工具，检查返回结果的字段与单位是否匹配锂电生产的规范，确认`functionCall`的校验功能生效。
- 发起包含多类数据的测试提问，检查工具调用是否按生产流程顺序执行，确认多工具顺序配置正确。
- 模拟升级MCP服务后重启FastGPT v4.17.0，检查服务日志无连接报错，确认MCP服务的配置匹配当前版本。
- 查看工具调用的返回条数与拉取数据大小，确认不超过预设的单次调用上限，确认返回规模符合配置要求。
