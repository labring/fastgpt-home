# 锂离子电芯制造的投标文稿与报价编制：文档解析与分块

## 这个品类的数据长什么样
该品类的数据来源包括原材料批次记录、生产MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室检测数据。数据更新节奏为每批电芯、单只电芯维度实时更新。日常文档包含配料记录、涂布辊压参数、卷绕或叠片记录、注液记录、化成分容数据、OCV与安全测试报告，文档类型混合结构化表格、时序曲线与纯工艺文本，字段包含物料批次号、工艺参数值、检测结果、时间戳与单位标识。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的高频实时更新数据与多维度批次关联文档，要求文档解析与分块需保留数据的批次关联性，避免割裂同批次的工艺参数与检测结果。混合了结构化表格、时序曲线与纯文本的文档类型，需要同时适配表格字段提取与非结构化文本的分块逻辑。单份文档体量跨度大，从数行的配料记录到数十页的化成分容报告，分块需适配不同长度的输入。数据精度要求高，分块时需保留完整的参数单位与时间戳信息，避免丢失关键工艺细节。

以下配置均基于FastGPT v4.17.0版本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | `800–1200 字符` | 该品类文档包含混合的表格数据与工艺参数文本，该区间可平衡单块信息完整性与检索效率 |
| `chunkSplitter` | 按段落+表格拆分 | 日常文档包含结构化表格与工艺说明段落，按此拆分可保留表格内字段的完整性 |
| `customPdfParse` | 启用 | 该品类的PDF文档多包含嵌入式表格与时序曲线，启用自定义解析可提升表格字段提取准确率 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `300–600 秒` | 单份化成分容报告可能包含大量时序数据，需预留足够解析时间 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 批量上传的批次文档集合可能达到较大体量，该上限可覆盖多数生产批次的文档需求 |
| `chunkSettingMode` | 手动配置 | 该品类文档结构差异大，手动配置可灵活调整分块规则适配不同文档类型 |

## 容易做错的三处
- 现象：上传化成分容报告后，界面显示解析超时错误，或耗时超过预设阈值后请求失败。原因：未针对该品类的长时序文档调整`PARSE_FILE_TIMEOUT_SECONDS`参数，使用通用短超时配置无法完成大体积文档解析。
- 现象：上传包含涂布辊压参数的表格文档后，知识库中仅保留文本内容，表格字段数据丢失。原因：未启用`customPdfParse`配置，默认解析引擎无法准确提取锂电制造专用的结构化表格字段，导致数据被过滤。
- 现象：检索同批次的工艺数据时，无法关联到对应的注液参数，分块结果将完整的批次工艺组拆分到不同块中。原因：`chunkSize`设置过小，破坏了同批次数据的关联性。

## 怎么确认配好了
- 上传一份典型的配料记录PDF，检查解析后的文本是否保留了所有表格字段与参数单位。
- 上传一份长时序的化成分容报告，核对解析耗时是否符合预设的`PARSE_FILE_TIMEOUT_SECONDS`范围，未出现超时错误。
- 检索同批次的工艺数据，确认关联的参数块未被拆分，可在单次检索中获取完整的批次信息。
- 上传一份批量的批次文档集合，确认上传文件大小未触发`UPLOAD_FILE_MAX_SIZE`的限制。
