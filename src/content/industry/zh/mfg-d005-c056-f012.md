# 锂离子电芯制造的投标文稿与报价编制：部署与升级

## 这个品类的数据长什么样
锂离子电芯制造的日常文档包含配料记录、涂布辊压参数、卷绕或叠片记录、注液记录、化成分容数据、OCV与安全测试报告。数据来源于原材料批次台账、生产MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室检测数据。数据更新以每生产批次、每只电芯为单位实时同步，字段包含批次编号、检测数值、采集时间、关联设备编号等，单位涉及电压、容量、露点温度等电化学专用计量标准。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据特征对部署与升级环节带来多重约束。多源异构的数据来源要求部署时适配多类设备的对接协议，升级时需兼容新增的化成分容柜、露点监测装置的数据接入。高实时性的更新节奏要求知识库的增量同步频率匹配生产批次周期，避免索引数据滞后于生产进度。电化学专用的字段与单位需要在配置时保留原始格式，不能随意调整计量标准，确保投标文稿中的参数准确可追溯。同时生产数据涉及安全合规，部署时需配置分级权限，防止敏感检测数据未授权访问。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://fastgpt:securepass@mongodb1:27017,mongodb2:27017/fastgpt_lithium?replicaSet=rs-lithium` | 该品类数据量大且实时更新，副本集配置可保障读写稳定性与数据持久化 |
| `REDIS_URL` | `redis://:redispass@redis-cache:6379/1` | 高实时性的生产数据检索需要缓存结果，1号数据库可隔离业务缓存与其他系统缓存 |
| `STORAGE_S3_ENDPOINT` | `http://local-storage:9000` | 生产文档多为检测报告与参数记录，本地对象存储可保障数据读取速度与权限可控 |
| 知识库单次召回上限 | 前 6–10 条 | 投标文稿需要关联多维度的批次数据，适量召回结果可覆盖核心参数与检测记录 |
| 文档分块长度 | 900–1300 字符 | 文档包含长参数序列与测试报告，该区间可保留参数关联逻辑，避免关键信息被截断 |
| `FE_DOMAIN` | `https://lithium-manu.fastgpt.site` | 该域名用于绑定官网访问地址，保障部署后的访问路径合规 |

## 容易做错的三处
- 现象：新建知识库上传文档时，界面无图片索引模型的可选选项。原因：本地部署未配置`FILE_TOKEN_KEY`与关联的图片处理服务，导致图片索引功能未启用。
- 现象：Docker部署完成后，访问配置的域名无响应，浏览器显示连接超时或502错误。原因：未正确映射容器端口或`FE_DOMAIN`配置与实际访问域名不一致，导致请求无法正确路由。
- 现象：每次打开新的对话窗口，均会弹出版本更新说明弹窗。原因：未在配置文件中关闭版本更新提示开关，导致每次会话都触发弹窗。

## 怎么确认配好了
- 访问配置的`FE_DOMAIN`地址，确认页面正常加载，无502、404或连接超时类报错。
- 上传一份包含涂布辊压参数的生产文档，执行批次编号的检索操作，确认返回的结果包含匹配的文档内容。
- 查看数据库连接日志，确认`MONGODB_URI`与`REDIS_URL`配置的服务已成功建立稳定连接。
- 关闭版本更新提示开关后重启服务，确认新对话不再弹出版本更新说明。
