# SMT贴片与电子组装的检验与过程记录审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据来源为客户BOM、Gerber坐标文件、MES系统、贴片机、SPI/AOI检测设备及回流焊炉温记录。日常文档包含换线表、钢网与炉温记录、首件确认单、SPI/AOI缺陷报告、维修记录与追溯标签。数据更新频率为每工单、每次换线时触发，部分检测数据实时同步。字段包含料号、位号、元件批次、焊接温度、检测缺陷类型等，需匹配对应设备输出的原生格式。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据实时性要求高，部分SPI/AOI检测数据需实时同步至审核流程，HTTP接口需支持高频请求并设置合理超时阈值。多类型业务文档的字段结构差异显著，接口请求需适配BOM、检测报告、炉温记录等不同格式，需通过`variables`参数传递字段映射规则。每次换线或工单创建时触发数据更新，接口需支持按工单ID、换线编号精准触发调用，减少无效请求。追溯标签与维修记录需绑定唯一工单标识，接口返回数据需包含可溯源的唯一标识字段。

本文档适配FastGPT v4.17.0版本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 接口超时时间 | 60-120秒 | 适配实时检测数据同步与工单批量处理的响应需求 |
| 身份校验配置 | 按外部系统预设密钥填写 | 保障FastGPT与生产设备、MES系统的安全对接 |
| 请求参数传递 | 绑定工单ID、文档类型标识 | 适配多类型业务文档的字段匹配需求 |
| 响应数据提取 | 提取缺陷结果、校验状态、唯一追溯码 | 便于后续业务系统对接与数据留存 |
| 重试触发规则 | 3次，按实测标定 | 应对外部设备临时离线或网络波动 |
| 数据格式适配 | 按对应设备输出格式调整 | 兼容BOM、SPI报告、炉温记录等多类型数据 |

## 容易做错的三处
- `variables`参数传递的字段映射错误，导致`responseData`为空。原因是未匹配SMT文档的特有字段，如位号、元件批次等。
- 接口超时时间设置过短，出现504状态码报错。原因是未考虑SPI/AOI报告的批量数据处理耗时。
- 未按工单触发接口调用，导致重复提交换线数据。原因是未绑定唯一工单ID作为请求标识。

## 怎么确认配好了
- 调用测试接口，传入模拟工单ID与对应文档数据，检查响应是否返回预期的`responseData`字段。
- 模拟设备离线或网络波动，检查接口是否按配置的重试规则触发重传。
- 对比外部系统传入的字段与FastGPT接收的字段，确认映射关系正确。
- 查看接口调用日志，确认每次请求均绑定唯一工单标识，无重复调用。
