# 乳制品加工的检验与过程记录审核：多轮对话与提示词

## 这个品类的数据长什么样
乳制品加工的检验与过程记录数据来自奶源检测、MES系统、均质和热处理设备、在线温流量采集模块、CIP系统、LIMS实验室管理系统。数据更新按奶罐、生产批次触发，部分在线参数实时同步。日常文档包含原奶验收记录、标准化配料单、巴氏或UHT热处理记录、CIP清洗记录、灌装记录、留样与微生物检测报告，字段覆盖理化指标、设备运行参数、检测结果，单位随指标类型区分，如温度用℃、时间用秒、菌落数用CFU/mL。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
数据的高频更新要求对话需实时调用最新批次的业务记录，避免使用过期数据。结构化的多字段文档需要提示词明确指定提取规则，确保精准定位原奶抗生素指标、热处理时间温度等核心审核项。按奶罐/批次的更新逻辑要求会话通过`chatId`绑定唯一标识，区分不同生产批次的上下文，避免跨批次数据混淆。易腐原料的属性要求审核响应及时，多轮对话需支持快速回溯历史交互内容，完成连续环节的验证。

## 配置怎么定
本页面配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chatId` | 绑定当前生产批次的唯一编码 | 区分不同奶罐或批次的会话上下文，避免跨批次数据混淆 |
| `messages` | 按单批次归档历史交互内容 | 保留单批次审核的完整对话链，支持多轮回溯验证各环节 |
| `variables` | 绑定当前批次的原奶验收、热处理记录ID | 自动拉取对应批次的业务数据，减少手动输入操作 |
| 单次召回结果数 | 前3条 | 乳制品审核需快速定位核心指标，过多结果会干扰判断 |
| 上下文窗口长度 | 8000–12000 token | 覆盖单批次全流程记录的关键字段，满足多轮审核的信息需求 |
| 超时阈值 | 60秒 | 匹配乳制品生产的实时响应要求，避免延迟影响生产节奏 |
| 文件存储上限 | 1000 MB | 适配单批次生产记录的存储规模 |

## 容易做错的三处
- 现象：对话时提示知识库为空，但知识库页面可查看所有内容。原因：未将当前批次的业务文档绑定到会话的`variables`参数，导致系统无法定位对应批次的审核数据。
- 现象：Xlsx格式的生产记录无法被AI对话识别。原因：未在提示词中指定提取Xlsx文件中原奶验收、热处理环节的字段规则，或未按批次拆分上传文件。
- 现象：对话接口无法传递图片URL，即使使用外网可访问地址也失败。原因：未使用平台支持的内部存储地址，直接使用外网URL触发了访问限制。

## 怎么确认配好了
- 发起针对当前生产批次的检验审核对话，检查对话中自动带出的原奶验收、热处理记录字段是否匹配对应批次的业务数据。
- 切换不同批次的会话，确认`chatId`绑定的批次编码更新后，对话上下文和调用的业务数据同步更新。
- 上传单批次的Xlsx生产记录，发起对话后检查是否能正确提取抗生素指标、热处理时间等核心审核字段。
- 测试对话接口的图片URL传递，确认使用平台支持的存储地址后可正常调用。
