# 乳制品加工的检验与过程记录审核：引用来源与溯源

## 这个品类的数据长什么样
该品类主体为液态奶、酸奶、奶粉及乳配料加工企业，日常文档涵盖原奶验收记录、标准化配料单、巴氏/UHT灭菌记录、CIP清洗记录、灌装记录、留样与微生物检验报告。数据来源覆盖奶源检测、生产MES系统、均质热处理设备、在线温流量监测、CIP系统及LIMS实验室管理系统，更新节奏按单奶罐、生产批次实时同步，字段包含抗生素理化指标、热处理温时参数、无菌灌装与清洗验证数据，单位涉及摄氏度、秒、菌落计数单位等。

## 这些特征在『引用来源与溯源』这一环带来什么约束
该品类的实时批次化更新要求溯源系统精准绑定单奶罐、生产批次的唯一标识，避免跨批次数据混淆。多源异构数据来源需要统一关联批次ID，确保引用的原奶检测、设备运行、实验室检验数据属于同一生产链路。易腐原料的特性要求溯源响应不出现延迟，否则可能引发合规风险。全流程连续的生产链路无法像固态烘焙那样逐批隔离，要求引用的每一条来源数据都能完整覆盖从收奶到灌装的完整环节，不能出现数据断档。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `quoteMaxToken` | 800–1200 token | 匹配单批次生产记录的平均字符长度，避免截断批次ID、抗生素检测值等核心溯源字段 |
| `responseData` | 仅返回匹配当前批次的文档 | 规避跨批次数据混淆，符合乳制品加工溯源的精准绑定要求 |
| `detail` | 开启完整字段展示 | 完整呈现热处理时间、在线温度、微生物检测结果等关键审核依据 |
| 单次搜索上限 | 前5–7条 | 覆盖单批次关联的原奶验收、CIP清洗、灌装等多类文档 |
| 相似度阈值 | 0.72–0.80 | 过滤非当前批次的历史数据，精准匹配提问中的批次关键词 |
| 最大上下文 | 1500–2000 token | 承载单批次全链路的关联数据，确保审核时可调用完整生产记录 |

## 容易做错的三处
- 现象：提问与当前生产批次无关时，仍返回其他批次的文档。原因：未绑定批次唯一标识作为强制检索条件，仅依赖语义匹配导致跨批次数据被召回。
- 现象：引用的设备运行数据未关联对应生产批次，无法验证热处理参数的合规性。原因：未配置按批次ID关联多源数据的检索规则，单独匹配设备参数导致数据链路断裂。
- 现象：中文提问未召回知识库内的英文行业标准文档，无法获取英文参考来源。原因：未配置开启英文数据源召回的规则，或未在检索逻辑中兼容中英文混合的业务需求。

## 怎么确认配好了
- 发起单批次生产的模拟提问，核对返回的文档是否全部关联该批次的唯一标识，无无关批次的数据。
- 检查检索结果的字段展示，确认所有需要的生产参数均完整呈现，无字段截断。
- 验证中英文提问分别召回对应语言的业务文档，确保数据源限定规则生效。
