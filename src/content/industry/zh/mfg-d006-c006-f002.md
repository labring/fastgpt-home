# 光伏组件封装的检验与过程记录审核：向量模型与索引

## 这个品类的数据长什么样
光伏组件封装的检验与过程记录数据，来自串焊、层压、装框、测试部门的多类业务载体。日常文档包含排版图、材料批次记录、层压工艺记录、EL隐裂图像、IV测试报告、绝缘耐压记录、包装清单。数据来源覆盖电池片分档结果、玻璃胶膜背板批次台账、MES系统、串焊与层压设备日志、EL/IV测试仪输出。数据更新节奏为每块组件生成专属测试记录，每批原材料生成批次台账，单份记录包含材料批次号、工艺参数、测试数值、图像文件等字段。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据更新频率高且单条体量分散，要求向量索引支持增量更新以适配批量组件的审核场景。数据同时包含结构化文本（工艺记录、测试报告）与非结构化图像（EL图），要求向量模型兼顾两类数据的嵌入适配。匹配电池片电流档位是核心耗时环节，要求向量召回的精度需满足工艺参数的公差匹配要求，避免误判或漏判。多源数据的格式差异，要求索引层统一数据的嵌入与存储格式，降低后续检索的匹配成本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配EL图文本标注、层压工艺记录的单段内容长度，避免块内关键信息割裂，基于FastGPT v4.17.0的分块逻辑优化 |
| 重叠长度 | 100–150 字符 | 覆盖串焊、层压等工艺步骤的衔接内容，防止跨块的工艺关联信息丢失 |
| `maxToken` | 8192 token | 适配IV测试报告的结构化文本长度，满足主流多模态嵌入模型的单样本token限额要求 |
| 相似度阈值 | 0.75–0.85 | 匹配电池片电流档位的精度要求，可结合实际组件的公差范围调整标定 |
| 单次搜索上限 | 前10条 | 平衡批量组件审核的召回效率与结果覆盖，避免冗余结果过多影响审核效率 |
| 重排 | 开启 | 优化高相似度结果的排序逻辑，优先匹配层压气泡、隐裂判读的关键参考记录 |

## 容易做错的三处
- 现象：上传EL隐裂图像后，向量嵌入任务返回空结果或格式错误。原因：未配置多模态向量模型，仅使用了纯文本嵌入模型，无法适配图像数据的嵌入要求。
- 现象：调用上传文件API返回成功，但后续检索无匹配结果。原因：未等待FastGPT v4.17.0的增量索引异步完成，直接发起检索请求，此时索引尚未同步完成。
- 现象：匹配电池片电流档位时召回结果偏差过大，出现误匹配。原因：相似度阈值设置未结合光伏组件的电流公差范围，过高会过滤有效匹配结果，过低则引入大量无关记录。

## 怎么确认配好了
- 上传单份层压工艺记录，查看系统嵌入任务日志，确认无异常报错，生成的向量数据可正常存储。
- 发起电池片电流档位匹配的检索请求，核对返回结果的相关性符合预设的匹配逻辑，可调整相似度阈值进行验证。
- 调用FastGPT v4.17.0提供的文件状态查询接口，确认上传文件的原始数据与索引均完成后，再发起正式检索。
- 统计批量测试数据的token消耗，确认`defaultToken`与`maxToken`的配置未超出所选嵌入模型的限额要求。
