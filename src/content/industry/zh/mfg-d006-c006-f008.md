# 光伏组件封装的检验与过程记录审核：文档解析与分块

## 这个品类的数据长什么样
光伏组件封装环节的数据来源包括电池片分档记录、玻璃胶膜背板批次台账、生产MES系统、串焊与层压设备日志、EL缺陷检测仪与IV功率测试仪输出。数据更新频率为每块组件生成专属测试报告与工艺记录，每批原材料生成批次台账。日常文档包含排版图、材料批次记录、层压工艺记录、EL缺陷图像、IV测试报告、绝缘耐压记录、包装清单，字段涵盖批次编号、电流档位、工艺参数、测试数值与设备编号，单位涉及安培、瓦特、兆帕等专业生产参数。

## 这些特征在「文档解析与分块」这一环带来什么约束
多类型文档并存的特征要求解析与分块需适配结构化表格、非结构化PDF与图像格式，避免单一拆分逻辑导致字段关联丢失。高频更新的单组件/单批次数据，要求分块大小需控制在合理区间，避免跨批次或跨环节内容混叠，影响检索精准度。多列结构化表格与带元数据的图像文档，要求分块时需保留字段间的绑定关系，例如同一批次的材料信息需与对应层压工艺记录绑定，EL缺陷图像需与IV测试报告关联。同时，不同文档的字段重叠度较低，需避免通用分块逻辑导致的上下文断裂，影响后续的检验审核匹配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配光伏组件相关文档的字段密度，保证单块内容包含完整的单批次或单组件的关联数据，同时兼顾检索效率 |
| `chunkSplitter` | 按段落与表格行拆分 | 适配多列Excel材料批次记录、层压工艺表格等结构化文档，保留字段间的绑定关系，避免多列数据被截断 |
| `customPdfParse` | 启用 | 支持解析EL缺陷图像关联的PDF测试报告，提取其中的测试数值与元数据，适配非结构化文档的解析需求 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 适配大型EL缺陷图像与批量测试报告的解析时长，避免因超时导致解析任务失败 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 适配大型EL缺陷图像与批量测试报告的上传需求，避免因文件过大导致上传失败 |
| `chunkSettingMode` | 手动配置 | 针对光伏组件封装的特定文档类型调整分块规则，适配多格式文档的解析与分块需求 |

## 容易做错的三处
- 现象：上传多列Excel材料批次记录后，检索时仅能匹配前两列内容。原因：未调整`chunkSplitter`配置以适配多列表格，默认分块逻辑仅识别前两列数据。
- 现象：调用条件判断组件处理解析出的boolean类型合格参数时，参数变为空值。原因：文档解析时未保留参数的原始数据类型关联，分块时丢失了参数与对应测试报告的上下文绑定。
- 现象：启用PDF增强解析时无法正常调用mineru API，解析任务失败。原因：未配置mineru API的关联参数，`customPdfParse`启用后未绑定对应解析接口。

## 怎么确认配好了
本核对流程适配FastGPT v4.17.0版本。
- 上传一份光伏组件的材料批次Excel表格，检查解析后的内容是否包含所有列的字段信息。
- 上传一份EL缺陷图像关联的PDF测试报告，查看解析任务是否在`PARSE_FILE_TIMEOUT_SECONDS`配置的时长内完成。
- 查看分块预览界面，确认单块内容未跨越多组批次或测试数据，符合`chunkSize`的配置区间。
- 启用`customPdfParse`后，检查解析结果中是否包含EL缺陷图像的关联元数据与测试数值。
