# 光伏组件封装的检验与过程记录审核：部署与升级

## 这个品类的数据长什么样
光伏组件封装的检验与过程记录审核涉及的数据来源包括电池片分档系统、玻璃胶膜背板批次台账、工厂MES系统、串焊与层压生产设备、EL/IV测试仪等。数据更新频率为每块组件生成一次测试记录、每批材料生成一次批次台账，日常文档包含排版图、材料批次记录、层压工艺记录、EL缺陷图、IV功率测试报告、绝缘耐压记录、包装清单等。数据字段包含电池片电流档位、层压温度与时长、EL隐裂位置与面积、IV测试功率值等，对应单位为安培、摄氏度、秒、瓦、兆欧等。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据特征对部署与升级带来多重约束：多源异构的数据来源要求部署时适配不同系统的对接协议，需提前配置数据导入的预处理规则；高频次的更新节奏要求数据库连接池、缓存服务的配置适配高频写入与查询，避免性能瓶颈；多样化的文档类型要求文件存储服务适配图纸、测试报告等不同格式的大体积文件存储；核心耗时环节的精准处理要求向量检索服务适配长文本与图像类数据的解析需求，升级时需同步更新对应解析配置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 100–200 | 适配每块组件高频写入的数据库连接需求，避免连接耗尽导致服务中断 |
| `MONGODB_URI` | 指向挂载光伏组件业务数据的副本集地址 | 存储批量的EL图、IV测试报告等非结构化数据，副本集部署保障数据高可用 |
| `REDIS_URL` | 配置为本地缓存实例地址，设置键过期时间1800秒 | 缓存高频查询的电池片电流档位匹配规则，降低后端数据库的查询压力 |
| `STORAGE_S3_ENDPOINT` | 指向企业对象存储服务的接入地址 | 存储排版图、包装清单等大体积文档，适配多类型文件的存储与检索需求 |
| `ROOT_KEY` | 按企业内部权限规范生成随机32位字符串 | 配置管理员访问权限，保障部署后的系统访问安全 |
| `FE_DOMAIN` | 填写服务器公网IP或企业内网域名 | 配置前端访问地址，适配串焊、层压、测试等部门的内部访问场景 |

## 容易做错的三处
- 启动容器后无法访问前端页面，返回502或超时错误。原因是未正确配置`FE_DOMAIN`为服务器公网IP或域名，且未开放3000端口的入站访问规则。
- 上传EL图或IV测试报告后，知识库中无法检索到对应文件。原因是未正确配置`STORAGE_S3_ENDPOINT`指向可用的对象存储服务，导致文件无法正常存储。
- 调用外部AI渠道时无返回结果，接口报错401或请求超时。原因是未正确配置渠道的密钥参数，或使用了过期的镜像，未重新拉取适配FastGPT v4.17.0的最新版本。

## 怎么确认配好了
- 执行`docker ps`命令，确认FastGPT容器及依赖的MongoDB、Redis容器均处于运行状态。
- 访问配置的`FE_DOMAIN`地址，验证前端页面可正常加载并完成管理员登录。
- 上传一份小型光伏组件EL图测试文件，验证文件可正常上传并在知识库中检索到对应条目。
- 批量导入10条模拟的组件测试数据，观察数据库连接池的监控指标，确认连接数未出现耗尽告警。
