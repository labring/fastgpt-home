# 冲压与板材成形的检验与过程记录审核：工具调用与插件

## 这个品类的数据长什么样
该品类的数据主要来自钢卷标签与质保书、冲床和送料机运行数据、模具管理系统、MES系统、三坐标测量或检具检测数据。日常生成的文档包含冲压作业指导书、材料利用率表、模具点检表、首末件记录、尺寸检验报告、换模记录。数据更新随每卷料、每批生产任务、每次换模操作触发，字段覆盖材料牌号、模具编号、冲压工艺参数、检验尺寸偏差值等，单位包含毫米、兆帕、件次等。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据更新频率高且随生产批次、换模操作触发，工具调用需支持实时拉取最新批次的生产与检验数据，避免使用过期的材料参数或模具状态。多源异构的数据来源要求插件兼容不同格式的结构化与半结构化文档，适配模具管理系统API、三坐标导出的CSV报告等格式。冲压检验涉及尺寸偏差、开裂起皱等多类异常，工具调用需支持关联多文档字段交叉校验，例如结合换模记录与首末件检验数据判断工艺稳定性。批量生产场景下，工具调用需控制单次处理的数据量，避免超时或资源过载。

## 配置怎么定
本配置基于FastGPT v4.17.0版本的界面与参数规则制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配冲压检验与过程记录审核的多类场景需求，无需手动指定调用工具 |
| 工具调用超时设置 | `120–180 秒` | 冲压车间数据拉取涉及多系统接口，该区间可覆盖多数跨系统数据同步时长，按实测标定后可优化 |
| 插件数据源适配规则 | 支持CSV、JSON格式与模具管理系统API | 覆盖该品类常用的三坐标报告、换模记录导出格式与车间系统接口 |
| 多文档关联校验开关 | 开启 | 可结合换模记录与首末件检验数据，校验工艺稳定性，符合该品类的审核需求 |
| 单次调用数据量上限 | `500–800 条` | 匹配批量生产的单批次数据规模，避免单次调用过载 |

## 容易做错的三处
- 调用时返回AggregateError Code:ETIMEDOUT。原因是未适配冲压车间多系统接口的同步延迟，设置的超时时长不足以覆盖跨系统数据拉取。
- 部署MCP后无法正常调用冲压车间系统数据。原因是未配置适配该品类数据源的MCP权限与接口规则，未导入钢卷标签、换模记录的对应字段映射。
- `functionCall`参数设置为强制指定工具，导致无法自动匹配冲压检验与记录审核的多类场景需求。原因是未根据场景调整`toolChoice`配置，限制了工具自动选择能力。

## 怎么确认配好了
- 提交模拟的换模记录与首末件检验数据，查看工具是否自动拉取对应批次的材料利用率表进行校验。
- 触发已部署的MCP插件，提交钢卷标签与模具点检表数据，查看是否能正常拉取对应系统的信息。
- 等待调用完成，确认未出现ETIMEDOUT类超时报错，检查超时设置是否符合实际拉取时长。
- 查看插件日志，确认已适配CSV、JSON格式与车间系统API接口。
