# 冲压与板材成形的检验与过程记录审核：部署与升级

## 这个品类的数据长什么样
本品类数据来源包括钢卷标签与质保书、冲床和送料机运行数据、模具管理系统、MES系统、三坐标或检具检验数据。日常文档包含冲压作业指导书、材料利用率表、模具点检表、首末件记录、尺寸检验报告、换模记录。数据更新节奏为每卷料、每批物料或每次换模时触发，文档字段包含物料牌号、冲压压力、模具编号、检验尺寸、换模时间等，对应单位为毫米、兆帕、小时等。

## 这些特征在「部署与升级」这一环带来什么约束
本品类多源异构的数据来源与高频更新节奏，要求部署时需适配多系统数据接入的连接配置，避免因数据源不稳定导致同步中断。频繁的卷料、批次及换模更新，需要支持增量同步机制，减少全量同步的资源占用。多样的业务文档与差异化字段，要求升级时需保留原有文档解析规则的兼容配置，避免因版本更新导致历史数据解析失效。检验数据与生产参数的强关联需求，需在部署阶段完成数据链路的打通配置，确保审核环节可调用完整关联信息。

## 配置怎么定
本配置项说明适配FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://admin:securepass@mongodb-host:27017/fastgpt?authSource=admin` | 适配冲压车间多源生产数据的存储需求，支持高频读写操作 |
| `REDIS_URL` | `redis://:redispass@redis-host:6379/1` | 用于缓存高频访问的模具点检、首末件记录数据，降低数据库负载 |
| `STORAGE_S3_ENDPOINT` | `https://s3-internal.company-domain.com` | 存储尺寸检验报告、换模记录等大体积业务文档 |
| `DB_MAX_LINK` | `20–30` | 匹配冲压车间数据更新的并发量，避免连接池耗尽导致同步失败 |
| `FILE_TOKEN_KEY` | `随机生成的32位加密字符串` | 用于生成业务文档的安全访问链接，防止未授权访问 |

## 容易做错的三处
- 现象：升级后前端页面显示的版本号与实际部署版本不符，知识库列表无法正常加载。原因：升级过程中未清理前端静态资源缓存，旧版本资源仍被调用。
- 现象：调用检验数据审核工具时返回模型流响应为空。原因：部署时未正确配置`REDIS_URL`，导致缓存的上下文数据无法正常读取，工具调用链路中断。
- 现象：批量导入换模记录时出现数据库连接超时错误。原因：未调整`DB_MAX_LINK`配置，并发导入请求超过数据库连接池上限，无法建立新连接。

## 怎么确认配好了
- 执行容器日志查看命令，确认`MONGODB_URI`与`REDIS_URL`配置可正常建立连接，无报错日志。
- 上传一份冲压作业指导书，验证解析后的文档可在知识库中正常检索与查看，确认`STORAGE_S3_ENDPOINT`与`FILE_TOKEN_KEY`配置有效。
- 模拟一次换模数据的增量同步操作，查看数据是否正常写入数据库，确认`DB_MAX_LINK`配置匹配并发需求。
- 访问配置的`FE_DOMAIN`对应的前端页面，验证系统版本号与部署包版本一致，确认前端资源已正确更新。
