# 医疗器械装配与洁净生产的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源于设计历史文件、器件与材料批次记录、MES系统、洁净环境监测设备、灭菌设备、检验校准系统。日常文档涵盖生产工艺规程、批生产记录、洁净区运行记录、灭菌批记录、检验报告、软件版本记录、不良事件与追溯资料。数据更新按每批或每台产品执行，洁净环境监测数据按既定计划更新。文档包含批次号、唯一器械标识、洁净环境参数、灭菌时长、检验结果等字段，部分内容以结构化表格形式存在。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源分散的数据来源要求接入配置需支持跨系统数据拉取与整合，避免单一数据源的信息缺失。高频更新的批记录与环境数据，要求配置适配近实时的知识库同步逻辑，确保审核结果基于最新数据。多样的文档格式与结构化字段，要求模型上下文处理配置可兼容文本与表格类内容，准确提取关键参数。同时，该品类审核出错会引发严重合规风险，因此配置需强化结果溯源与合规判定的准确性，避免模糊输出。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 该品类审核需关联多份批记录、灭菌与检验报告，需容纳完整的关联上下文 |
| `maxTokens` | 2000–3000 token | 检验与过程审核需输出详细合规判定与溯源说明，需足够的输出长度 |
| `quoteMaxToken` | 1500–2000 token | 需精准引用灭菌批记录、洁净区记录等核心溯源文档片段，确保审核结果可追溯 |
| `temperature` | 0.1–0.3 | 审核场景需稳定合规的判定结果，降低输出随机性，避免不合规判定 |
| `AIPROXY_API_ENDPOINT` | 部署节点专属接入地址 | 该品类数据涉及合规追溯，需使用受控的接入地址，避免未授权访问 |
| `AIPROXY_API_TOKEN` | 绑定专属权限的令牌 | 严格控制模型调用权限，符合医疗器械数据的安全合规要求 |

## 容易做错的三处
- 现象：调用70B级大模型后响应超时，界面显示请求耗时超过60秒。原因：未针对大模型负载调整`maxContext`参数，加载过多跨批次关联数据导致推理资源占用过高。
- 现象：iframe嵌入的审核页面在小程序中无法加载，控制台提示域名校验失败。原因：未配置适配小程序的安全域名规则，或未使用符合小程序嵌入要求的接入方式。
- 现象：模型输出的审核结果未关联具体文档片段。原因：未正确配置`quoteMaxToken`参数，导致无法提取足够长度的溯源文档内容用于引用。

## 怎么确认配好了
- 发起单批次产品的检验审核请求，核对输出结果中是否包含对应批记录、灭菌参数的精准引用片段。
- 查看FastGPT v4.17.0的模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置无格式错误，无401或403报错。
- 调整`temperature`参数至0.2，发起3次重复审核请求，核对结果的一致性符合预期。
- 导入单份洁净区监测记录，验证模型能否正确识别参数是否符合既定工艺要求。
