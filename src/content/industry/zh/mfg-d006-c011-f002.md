# 半导体封装测试的检验与过程记录审核：向量模型与索引

## 这个品类的数据长什么样
该品类的日常文档包含封装流程卡、键合与塑封参数、晶圆来料图、测试程序版本、良率报告、失效分析报告。数据来源涵盖晶圆测试图、MES系统、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格要求。数据更新节奏为每生产批次、每颗芯片测试节点及每日更新，单份文档包含设备参数阈值、测试bin值、晶圆坐标映射等字段，部分图纸类文档含像素级坐标信息，单位涵盖电压、时间、芯片尺寸参数等。

## 这些特征在「向量模型与索引」这一环带来什么约束
晶圆来料图的像素级坐标信息要求分块时保留关联完整性，避免拆分跨坐标的映射字段，否则会丢失晶圆批次与实物的对应关系。多源数据的格式差异要求索引构建时统一字段映射规则，确保不同设备日志、测试报告的向量编码逻辑一致。高频更新的单颗测试数据需支持增量索引，减少全量重建的计算开销。不同文档类型的长度跨度大，从短文本的测试程序版本到数千字符的失效分析报告，需适配灵活的分块与编码策略。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配封装流程卡、失效分析报告的混合文本长度，避免拆分跨参数关联的内容 |
| 重叠长度 | 50–80 字符 | 保留晶圆来料图的坐标关联信息，防止分块边界丢失关键映射关系 |
| `defaultToken` | 1024 | 匹配多数商用与开源embedding模型的输入token上限，适配测试程序版本等短文本的编码需求 |
| 相似度阈值 | 按实测标定 | 需结合良率报告的失效关联特征调整，避免误匹配不同批次的测试数据 |
| 单次搜索上限 | 前20条 | 覆盖ATE测试机的单批次测试数据量，确保召回足够的关联记录 |
| `maxToken` | 4096 | 适配失效分析报告的长文本编码需求，匹配主流embedding模型的最大输入限制 |

## 容易做错的三处
- 更换embedding模型后直接使用原有知识库搜索，出现检索结果偏差或无匹配内容。原因是旧索引基于原模型的向量空间生成，未同步更新向量映射规则。
- 配置`defaultToken`超出所选embedding模型的输入上限，出现模型调用报错，返回undefined model或参数不匹配提示。原因是未对齐模型的token限制，未按所选模型调整参数。
- 检索结果仅按相似度排序，未匹配业务场景的优先级逻辑，出现低关联但高相似度的结果干扰审核。原因是未配置重排环节或未绑定业务字段权重规则。

## 怎么确认配好了
- 导入单份封装流程卡，检查分块后的文本片段是否保留完整的键合参数与批次关联信息，无跨关键字段的拆分。
- 在FastGPT v4.17.0版本中，更换embedding模型后触发全量索引重建，验证知识库内所有文档的向量更新完成，无失败状态的条目。
- 输入测试bin分布查询，核对检索结果的召回条数符合单次搜索上限的配置，且排序逻辑符合业务审核的优先级。
- 调用测试接口，检查`defaultToken`与`maxToken`的参数匹配所选embedding模型的输入要求，无参数超限报错。
