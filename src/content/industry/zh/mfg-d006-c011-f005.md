# 半导体封装测试的检验与过程记录审核：工具调用与插件

## 这个品类的数据长什么样
该品类数据覆盖封装全流程相关记录，日常文档包含封装流程卡、键合与塑封参数表、晶圆来料图、测试程序版本文件、良率报告及失效分析报告。数据来源包括晶圆测试图、工厂MES系统、键合与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格要求。数据更新频率按生产批次、单颗芯片测试结果及每日汇总节奏更新，单条记录包含批次号、参数阈值、测试bin值、失效类型等字段，结构随检测项调整，无统一固定长度。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类多源异构的数据特征，要求工具调用插件需适配MES系统、ATE测试机、X-ray检测设备等不同数据源的接口格式。高频更新的业务节奏，要求插件支持按生产批次、单颗测试结果触发数据拉取，避免数据滞后。多样的文档类型，需要插件可解析结构化参数表、可视化晶圆图、文本形式的失效分析报告，适配不同字段提取需求。关联晶圆图与实物批次的核心流程，要求插件可通过批次号建立跨数据源的关联映射，减少人工对齐成本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` | 适配多数据源的插件调用需求，自动匹配对应工具处理不同类型的业务数据 |
| 工作流/API 函数调用配置 | 按生产批次触发 | 该品类数据按生产批次更新，按批次触发可保证数据完整性，避免单颗数据重复调用 |
| 插件超时阈值 | 300–600 秒 | ATE测试机与MES系统的数据拉取需跨设备交互，超时阈值需覆盖设备响应的正常耗时范围，按实测标定 |
| 数据拉取条数上限 | 前 200 条 | 单批次生产的测试数据量通常在百级范围，上限设为200条可覆盖常规批次规模，避免无效数据过载 |
| 插件结果输出格式 | 结构化JSON | 需将模型输出转化为可导入良率报告的格式，结构化JSON可直接对接工厂文档系统，无需二次转换 |
| 跨域访问权限 | 允许 192.168.1.0/24 网段 | 封测厂内部设备与系统部署在内网，仅允许内网IP发起请求可保障数据安全 |

## 容易做错的三处
- 现象：数据库查询插件返回空结果，状态码为404。原因：未配置工厂内网IP的跨域访问权限，导致插件无法从MES系统拉取封装流程卡数据。
- 现象：模型输出的文档转换结果缺失键合参数字段。原因：未明确`functionCall`的触发规则，导致插件未提取封装流程卡中的键合温度、压力等核心字段。
- 现象：插件调用超时，返回504状态码。原因：拉取的ATE测试数据条数超过配置上限，导致数据处理耗时超出阈值。

## 怎么确认配好了
- 发起模拟生产批次的插件调用，检查是否能拉取对应批次的晶圆来料图与ATE测试数据。
- 查看插件调用日志，确认`toolChoice`自动匹配了对应数据源的插件，未出现调用失败的报错。
- 导出插件处理后的结果，检查是否包含封装流程卡、良率报告所需的全部字段，格式符合工厂文档系统的导入要求。
- 在FastGPT v4.17.0的插件管理页面，确认跨域访问的IP段已配置为工厂内网网段。
