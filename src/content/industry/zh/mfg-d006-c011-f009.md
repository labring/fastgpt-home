# 半导体封装测试的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自晶圆测试图、MES系统、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格文档。日常需处理的文档包含封装流程卡、键合与塑封参数表、晶圆来料图、测试程序版本文件、良率报告及失效分析报告。数据更新频率覆盖每批生产、单颗芯片测试及每日汇总，字段包含批次标识、测试bin值、键合拉力参数、塑封温度、良率数据等，需适配多源异构的输入格式。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据来源要求模型接入需兼容不同格式的输入内容，需支持多模态数据解析以处理晶圆图、扫描图像等非文本文件。高频更新的生产数据要求上下文窗口需适配动态变化的单批次数据量，避免截断关键信息。严格的业务出错后果要求模型输出需保持严谨，不宜过度发散。同时，需关联批次标识与对应测试、失效数据，因此配置需确保上下文能完整承载批次关联的全量信息。

## 配置怎么定
本配置规范基于FastGPT v4.17.0版本，具体配置项及建议如下：

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `vision` | 开启，启用多模态解析能力 | 该品类需处理晶圆来料图、X-ray扫描图像等非文本检验数据 |
| `maxContext` | 8000–12000 token | 适配单批次封装流程卡、测试数据及关联文档的总字符量 |
| `temperature` | 0.1–0.3 | 检验审核需严格匹配参数与文档内容，避免输出发散 |
| `AIPROXY_API_ENDPOINT` | 按部署的本地代理地址填写 | 适配私有部署或本地Ollama模型的调用需求 |
| `quoteMaxToken` | 2000 token | 确保完整引用测试程序版本、良率报告等核心文档片段 |
| 工作流/API 工具选择配置 | auto | 自动调用文档解析工具处理多源异构的生产数据 |

## 容易做错的三处
- 新增模型厂商时未找到火山方舟选项，原因是未在平台的厂商配置列表中手动添加第三方厂商接入渠道。
- 配置通义千问QWEN2.5-VL-7B-instruct后图片分析无结果，原因是未开启`vision`配置项，或未上传符合格式的图像文件。
- 通过AI proxy添加本地Ollama模型时返回404错误，原因是代理地址配置错误或本地模型未正常启动。

## 怎么确认配好了
- 进入模型渠道配置页面，确认已添加目标厂商或本地代理地址。
- 上传单张晶圆测试图，触发多模态解析，检查是否能提取晶圆批次标识。
- 提交一批封装流程卡数据，查看模型返回的审核结果是否包含对应业务字段。
- 调整`temperature`参数后提交测试，确认输出结果的严谨性变化符合业务需求。
