# 半导体封装测试的检验与过程记录审核：知识库检索与召回

## 这个品类的数据长什么样
该品类的日常文档包含封装流程卡、键合与塑封参数、晶圆来料图、测试程序版本、良率相关报告、失效分析报告。数据来源覆盖晶圆测试图、MES系统、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格文件。数据更新频率按每批、单颗测试结果、每日周期更新。文档包含参数数值、批次编号、测试bin码、失效位置等字段，部分文档附带可视化图表，单位涵盖电压、电流、时间等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源带来字段对齐需求，需匹配批次编号、测试bin码等关联字段，确保检索结果与当前生产批次绑定。高频更新节奏要求检索链路支持快速同步最新数据，避免调用过期的封装参数或测试程序。可视化类文档（如晶圆来料图）需适配非文本内容的解析，保障图表关联的参数信息可被召回。多文档绑定的业务场景（如封装流程与ATE测试程序版本关联）要求检索支持跨文档关联召回，防止出现参数与程序不匹配的问题。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配半导体封装测试的参数精度需求，避免召回与批次无关的低匹配度文档 |
| `limit` | 前8条 | 覆盖单批次生产涉及的多类文档（流程卡、测试程序、良率报告等），避免结果过多超出上下文限制 |
| `searchMode` | 全文检索 | 适配多源异构数据的关联匹配，支持跨字段检索批次编号与测试bin码等核心业务字段 |
| `usingReRank` | 开启 | 优化检索结果的排序精度，优先召回与当前生产场景最相关的参数与报告 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展检索关键词，覆盖封装流程卡、ATE测试程序等多类文档的专业术语 |
| `collectionIds` | 按生产场景绑定的集合ID | 限定检索范围至当前批次对应的文档集合，避免召回无关的历史批次数据 |

## 容易做错的三处
- 现象：导入的晶圆来料图、X-ray检测图等可视化文档在检索结果中无法正常展示。原因：未开启知识库的非文本内容解析配置，或导入文档时未正确关联图片与对应参数文件的元数据。
- 现象：调用知识库检索耗时超过15秒，界面返回结果延迟。原因：未通过`collectionIds`限定检索范围至当前生产批次的文档集合，检索覆盖了过多历史批次数据，导致召回计算量过大。
- 现象：检索结果中出现与当前生产批次无关的测试程序版本文档。原因：未设置`similarity`阈值或阈值设置不合理，召回了匹配度不足的低相关文档。

## 怎么确认配好了
- 手动导入单份封装流程卡文档，执行针对性关键词检索，核对结果是否包含该文档。
- 上传带可视化图表的晶圆来料图，检索对应批次编号，核对图表是否可正常加载展示。
- 查看系统检索日志，确认检索范围仅覆盖当前生产场景绑定的文档集合，未涉及无关历史数据。
- 执行批量检索测试，核对返回结果的排序是否符合业务场景的优先级要求。
