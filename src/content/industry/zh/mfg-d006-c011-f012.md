# 半导体封装测试的检验与过程记录审核：部署与升级

## 这个品类的数据长什么样
该品类的数据来源包含晶圆测试图、MES系统、键合与塑封设备日志、ATE测试机数据、X-ray/SAM检测结果及客户规格文档。日常生成的文档包括封装流程卡、键合与塑封参数表、晶圆来料图、测试程序版本文件、良率报告与失效分析报告。数据更新频率为每生产批次、每颗芯片测试后及每日更新，字段包含批次标识、测试bin分布、设备参数阈值、失效类型等，无统一固定单位，随文档类型变化。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的多源异构数据特征要求部署环节支持对接设备日志、MES系统及检测设备的API或文件导入，需配置多数据源兼容的存储与索引规则。高频更新的特性要求存储层配置足够的并发处理能力，避免数据写入延迟。多样的文档类型与细粒度字段要求索引模型适配结构化参数表、非结构化检测图档等多种格式，升级环节需兼容旧版文档解析规则与新业务字段的映射关系。批次级与单颗级的数据粒度要求元数据关联配置精准，避免批次混淆或数据错位。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | 100–150 连接数 | 适配多源数据高频写入的并发需求，避免连接池耗尽 |
| `MONGODB_URI` | 指向封装测试业务专属的副本集地址 | 隔离业务数据与其他系统，保障细粒度测试数据的读写稳定性 |
| `REDIS_URL` | 配置本地高可用Redis集群地址 | 支撑高频的批次元数据缓存与用户会话管理，适配每日更新的频率 |
| `FE_DOMAIN` | 绑定封测厂专属的二级域名 | 适配内部访问权限控制与证书配置需求 |
| `FILE_TOKEN_KEY` | 使用32位随机生成的加密密钥 | 保障封装流程卡等敏感文档的下载权限安全 |
| `ROOT_KEY` | 配置为16位以上的强随机字符串 | 避免默认root账号密码重置的异常问题 |

## 容易做错的三处
- 访问前端页面返回500错误，日志显示`URI malformed`。原因是`FE_DOMAIN`配置未包含正确的协议前缀，或`MONGODB_URI`中存在非法字符。
- 容器启动后前端页面无法访问。原因是`REDIS_URL`配置指向了不可达的地址，或`DB_MAX_LINK`设置过低导致连接池无法初始化。
- 系统每日自动重置root账号密码。原因是`ROOT_KEY`配置未正确设置，或部署脚本中残留了默认的密码重置逻辑，未替换为自定义密钥。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`MONGODB_URI`与`DB_MAX_LINK`配置的连接数可正常建立。
- 访问`FE_DOMAIN`绑定的地址，确认前端页面可正常加载且无500错误。
- 修改root账号密码后，重启容器并等待24小时，确认密码未被自动重置。
- 上传一份封装流程卡文档，验证`FILE_TOKEN_KEY`可正常生成合法的下载令牌。
