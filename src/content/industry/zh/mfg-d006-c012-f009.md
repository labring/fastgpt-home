# 半导体晶圆制造的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
半导体晶圆制造的检验与过程记录数据，通常来自MES系统、设备FDC模块、缺陷检测与量测设备、晶圆图文件、工艺配方库与实验数据集。数据更新节奏覆盖每批晶圆流转、实时设备参数采集与每日良率汇总。日常文档包含工艺流程卡、批次运行记录、设备配方、SPC控制图、异常处置单、缺陷图谱与良率报告，字段包含纳米级工艺参数、晶圆批次标识、缺陷空间坐标与良率占比等。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据多源分散且更新频率差异大，要求模型接入环节适配多格式数据的统一解析，避免格式不兼容导致的解析失败。超长工艺链与复杂返工路径带来的长序列文档，需要配置足够的上下文容纳量，防止关键工序记录被截断。纳米级参数与空间分布缺陷的判读需求，要求开启视觉相关配置以支持晶圆图、SPC图的内容解析。同时，高风险的出错后果要求配置严格的输出校验规则，避免错误的审核结论。本配置基于FastGPT v4.17.0版本的标准逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单批次晶圆的完整工艺记录与关联文档，避免关键工序信息被截断 |
| `maxTokens` | 4000–6000 token | 控制单轮审核输出的长度，确保缺陷归因与审核结论的可读性 |
| `quoteMaxToken` | 1500–2000 token | 限制引用的原始文档片段长度，聚焦与当前审核项相关的工艺参数与记录 |
| `vision` | 开启 | 支持对晶圆图、SPC控制图、缺陷图谱的视觉内容解析，适配纳米级缺陷与参数分布的判读需求 |
| `temperature` | 0.1–0.3 | 降低输出随机性，确保审核结论的一致性与严谨性，适配高风险的制造场景 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写专属接口地址 | 适配多源数据接入的代理配置，确保内部系统数据的安全传输 |

## 容易做错的三处
-  配置`temperature`为0后，审核结论仍出现非必要的思考过程。原因是未正确关联禁用思考输出的配置项，或模型本身的默认输出逻辑未被覆盖。
-  接入本地模型或代理接口后出现未捕获异常，且无法查看完整报错详情。原因是未在部署脚本中开启详细日志输出，或代理接口的权限配置有误导致数据传输中断。
-  开启`vision`配置后无法解析晶圆图文件。原因是未指定适配的图像格式白名单，或图像分辨率超出模型支持的范围。

## 怎么确认配好了
-  上传单批次晶圆的工艺记录与缺陷图谱，触发审核流程，检查输出内容是否包含完整的工序参数与缺陷分析。
-  查看模型调用日志，确认`maxContext`、`maxTokens`等参数的实际取值与配置一致，无异常截断。
-  测试禁用思考输出的配置，确认返回结果中无额外的思考片段。
-  接入内部代理接口后，执行一次数据拉取测试，确认无权限或连接超时报错。
