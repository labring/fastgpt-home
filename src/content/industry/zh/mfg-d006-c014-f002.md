# 印染与后整理的检验与过程记录审核：向量模型与索引

## 这个品类的数据长什么样
本品类数据主要来自染整厂染色、定形、实验室及质量部门，包含染色配方、称化料记录、染缸运行曲线、打样确认单、色差报告、定形工艺单、污水台账等文档。数据来源覆盖客户色样、配方库、染化料批次台账、染缸控制系统、测色仪、定形机运行数据及环保监测记录。更新节奏以每缸、每批或每班为单位，单份文档包含配方参数、批次编号、工艺曲线、检测数值等字段，部分数据带有温度、浓度、时间等单位标识。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类高频次、批次化的数据更新节奏，要求向量索引支持增量同步，避免全量重建占用生产资源。文档同时包含结构化参数与非结构化曲线文本，需要分块规则适配不同内容类型，确保关键信息不被截断。字段附带温度、浓度、时间等单位标识，分块时需保留完整参数组合，防止向量匹配时丢失关键关联信息。单缸/单批数据的独立属性，要求索引能够按批次维度进行分组检索，提升匹配精准度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配染色配方、染缸曲线等不同长度的文档内容，避免单块信息过载或过碎 |
| 重叠长度 | 100–200 字符 | 保留相邻分块的关键参数关联，防止染缸曲线的分段断点丢失上下文 |
| `maxToken` | 4096 token | 适配主流嵌入模型的输入长度限制，兼容Qwen/Qwen3-Embedding-8B等本地模型 |
| 相似度阈值 | 0.72–0.85 区间 | 匹配色差报告、工艺单等对精度要求较高的业务场景，过滤低相关性的批次数据 |
| 单次搜索上限 | 前 8 条 | 覆盖单缸生产涉及的多份关联文档，避免遗漏关键配方或检测记录 |
| `defaultToken` | 按实测标定 | 适配FastGPT v4.17.0版本本地部署的M3E模型的默认参数，确保嵌入向量的一致性 |

## 容易做错的三处
- 现象：本地部署的M3E模型在FastGPT中配置后，再次添加同名嵌入模型时原有配置被覆盖。原因：未在模型配置页区分本地部署模型的唯一标识，直接使用模型名称作为配置键导致冲突。
- 现象：配置Qwen/Qwen3-Embedding-8B作为嵌入与重排模型时，系统仅识别一个模型实例。原因：未为重排任务单独配置模型标识，复用了嵌入模型的名称导致配置被覆盖。
- 现象：导入10000+行的Excel源数据后，知识库分块过大导致检索匹配精度不足。原因：未调整分块长度配置，沿用默认参数导致单块包含过多行数据，丢失单条记录的关键信息。

## 怎么确认配好了
- 上传单份染色配方文档，执行分块预览，确认分块长度符合预设区间且无关键参数截断。
- 配置本地嵌入模型后，测试生成一条染缸曲线的嵌入向量，核对向量生成结果与模型输出一致。
- 导入小批量Excel测试数据，执行检索测试，确认返回结果的数量与单次搜索上限配置匹配。
- 调整相似度阈值后，输入色差报告关键词，核对检索结果的相关性符合业务预期。
