# 印染与后整理的检验与过程记录审核：工作流编排

## 这个品类的数据长什么样
该品类数据主要来自客户色样、配方库、染化料批次台账、染缸控制系统、测色仪、定形机及环保监测设备。日常生成的文档包含染色配方、称化料记录、染缸运行曲线、打样确认、色差报告、定形工艺单、污水排放台账。数据更新以每缸、每批或每班为节奏，单份文档包含物料批次号、工艺参数、检测数值、时间戳等字段，部分参数带有浓度、温度、时间等单位。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的高频小批量、多节点校验需求，要求工作流需适配多源异构数据的接入。按批次更新的数据需要工作流绑定对应生产批次的变量，避免跨缸数据混淆。湿化学加工的实时性要求，需确保工作流节点间的数据流转延迟符合染缸工艺窗口。多部门协同的文档校验需求，要求工作流支持跨角色节点的权限隔离与数据流转。同时，环保监测数据的实时校验，需要工作流内置合规性判断节点，匹配实时采集的参数阈值。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 按生产批次创建独立变量组 | 匹配每缸、每批的数据更新节奏，避免跨批次数据混淆 |
| 知识库文件集合筛选 | 按染整工艺类型指定目标文件 | 仅检索染色配方、定形工艺单等品类专属文档，缩小搜索范围 |
| AI对话组件温度参数 | 设为0.6–0.8 | 平衡工艺判断的严谨性与灵活性，适配复杂配方调整场景 |
| 单节点超时设置 | 300秒 | 匹配染缸升温、保温等工艺的常规时长，避免流程中断 |
| 知识库ID配置 | 从平台知识库管理界面复制对应ID | 直接绑定品类专属的染整工艺知识库，确保数据准确性 |
| `nodeId` | 按部门角色绑定对应节点ID | 隔离实验室、质量部、生产岗的节点权限，避免越权操作 |

## 容易做错的三处
- 工作流运行时报错「输入字段为空」，且全局变量在节点间调试时未传递有效值。原因是未按生产批次绑定`variables`参数，导致跨缸数据未隔离，后续节点无法读取对应批次的变量数据。
- AI对话组件调用大模型时，无法找到温度参数设置入口。原因是未切换至自定义参数配置模式，直接使用默认调用方式，未开放温度设置选项。
- 知识库搜索节点返回结果包含无关文档，未仅检索指定文件集合。原因是未配置文件筛选规则，默认检索整个知识库的全部文档，未匹配染整品类的专属文件范围。

## 怎么确认配好了
- 触发模拟生产批次的测试流程，检查各节点间的`variables`参数是否正确传递，无空值报错。
- 进入AI对话组件配置界面，确认存在温度参数设置入口，可手动调整参数值。
- 运行知识库搜索节点，验证仅返回指定的染整工艺相关文件，无无关文档混入。
- 查看节点运行日志，确认单节点运行时长未超过预设阈值，无流程中断情况。
