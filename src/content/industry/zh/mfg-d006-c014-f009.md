# 印染与后整理的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来自染整厂染色、定形、实验室与质量部门的日常业务产出，包含染色配方、称化料记录、染缸运行曲线、打样确认单、色差报告、定形工艺单、污水台账等文档。数据来源覆盖客户色样、配方库、染化料批次记录、染缸控制系统、测色仪、定形机参数、环保监测数据，更新节奏为每缸、每批、每班生成对应记录，单条记录包含工艺参数、批次信息、检测结果等字段，部分数据带物理单位如温度、浓度、批次编号。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类高频更新的小批量业务数据，要求模型接入配置需适配短周期数据的实时处理需求，避免上下文溢出导致任务中断。多类型业务文档与设备直连数据的混合输入，要求配置支持多模态数据的解析与关联。单条记录包含专业工艺参数与物理单位，需确保模型能正确识别字段含义与单位规范。频繁的批次更新要求配置项需支持快速迭代调整，同时保障审核结果的一致性，避免因参数波动导致整缸返修或报废等严重后果。在FastGPT v4.17.0版本中，相关配置逻辑已针对该品类的业务特性做了优化适配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 该品类单缸工艺记录与关联文档的总长度通常在该区间内，避免上下文溢出导致审核中断 |
| `maxTokens` | 2000–3000 token | 检验与审核结果需覆盖工艺合规性、色差判断等核心内容，该取值可保障输出完整且不冗余 |
| `temperature` | 0.1–0.3 | 该品类审核需保持专业判断的一致性，避免因参数过高导致结果波动 |
| `vision` | 启用 | 该品类包含色差报告、打样照片等视觉类文档，需支持图像解析以辅助审核 |
| `AIPROXY_API_ENDPOINT` | 部署FastGPT的专属API端点地址 | 该品类数据需在安全可控的环境内处理，避免外部传输风险 |
| `quoteMaxToken` | 1500–2000 token | 需限制引用的原始文档长度，确保审核逻辑聚焦于核心工艺参数 |

## 容易做错的三处
- 现象为FastGPT后台模型管理页面无可用模型渠道选项，测试模型时返回配置错误提示。原因是未正确填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`参数，导致平台无法建立与模型服务的连接。
- 现象为模型审核任务超时或返回截断结果，日志显示上下文长度超限。原因是`maxContext`取值低于单缸工艺记录与关联文档的总内容长度，导致模型无法加载全部待审核数据。
- 现象为审核结果出现乱码、格式混乱的引用片段，或图像类文档无法被解析。原因是未启用`vision`参数，或`quoteMaxToken`取值不合理，导致模型无法正确处理视觉输入或格式化引用内容。

## 怎么确认配好了
- 登录FastGPT后台，进入模型接入配置页面，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`参数已正确填写。
- 发起单缸工艺记录的审核测试，检查任务是否能正常启动并返回完整结果，无上下文超限报错。
- 上传色差报告图像与染缸曲线文档，检查模型是否能正确解析图像内容并关联文本参数。
- 查看审核结果的引用片段，确认格式清晰无乱码，引用长度符合业务需求。
