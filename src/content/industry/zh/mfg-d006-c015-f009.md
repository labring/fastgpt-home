# 原料药与医药中间体生产的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
原料药与医药中间体生产的检验与过程记录审核涉及的数据来源覆盖注册工艺文档、原料批次台账、DCS生产控制系统、称量系统、LIMS实验室信息管理系统、色谱数据系统与QMS质量管理系统。数据更新随每生产批次完成、每工艺步骤结束触发，频率为单批每步骤一次。日常文档包含批生产记录、物料平衡台账、反应与精制过程记录、清洁验证记录、杂质谱报告、偏差与变更申请文件，数据字段包括批次标识、工艺参数值、检测结果数值、文件编号与变更单号，部分文档为结构化表格与非结构化文本混合格式。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据来源要求配置环节需实现不同系统数据格式的统一映射，避免字段错位导致审核偏差。批次级高频更新的特性要求模型上下文窗口不宜过大，否则会增加单批次审核的处理延迟。结构化与非结构化混合的文档结构，需要配置适配混合格式的解析规则，确保模型能准确提取核心审核信息。合规相关的审核需求，要求模型调用链路具备可溯源的权限配置，防止未授权的敏感工艺与质量数据泄露。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配单批次生产记录与关联质量文档的总长度，避免截断核心审核数据 |
| `maxTokens` | 2000–3000 token | 满足审核结果输出的详细程度，覆盖杂质分析、收率核算等多维度结论 |
| `quoteMaxToken` | 1500 token | 限定引用源数据的长度，确保审核依据的准确性与可读性 |
| `temperature` | 0.1–0.3 | 降低随机输出，保证审核结论的一致性，适配合规性要求 |
| `AIPROXY_API_ENDPOINT` | 部署的FastGPT代理服务外部访问地址 | 实现模型调用的统一路由与权限管控 |
| `AIPROXY_API_TOKEN` | 绑定应用的专属访问密钥 | 限制未授权的模型调用，符合数据安全要求 |

## 容易做错的三处
- 将代码块输出的String类result直接传入大模型时出现“Question is empty”报错，原因是未对result中的换行、转义符等特殊字符进行处理，导致模型接口解析失败。
- 配置`AIPROXY_API_ENDPOINT`时填写容器内部端口地址，即便主机本地可访问容器端口，代理服务仍无法连通，最终触发超时错误。
- 创建索引模型后未关联对应语言模型配置，导致审核任务无法调用大模型完成推理，出现模型缺失的异常状态。

## 怎么确认配好了
- 调用模型测试接口，传入单批次的批生产记录文本，检查返回结果是否包含杂质分析、收率核算等对应审核维度的结论，无明显内容截断或缺失。
- 查看模型调用日志，确认`AIPROXY_API_TOKEN`验证通过，无权限相关报错信息。
- 调整`temperature`参数至不同区间，对比两次输出结果的一致性，验证参数配置已生效。
- 测试多源数据接入场景，传入来自LIMS与DCS的混合数据，检查模型是否能正确识别并关联对应字段。
