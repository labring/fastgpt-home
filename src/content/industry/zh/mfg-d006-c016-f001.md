# 变压器与高压电器制造的检验与过程记录审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类数据来自设计BOM、硅钢片与绝缘材料库存数据、真空干燥设备运行日志、油化验报告、试验站高压试验记录。日常生成绕制与器身装配记录、真空干燥记录、绝缘油报告、局放和耐压试验报告、铭牌参数表。单台产品的检验记录通常包含数十个字段，每批材料的记录则按批次汇总参数。数据按单台产品或每批材料更新，包含绝缘电阻、局放阈值、干燥温度、引线连接位置等字段，字段附带对应工程单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
单台或每批更新的特性要求接口支持按产品ID或批次号精准拉取数据，避免全量同步占用过多系统资源。多类型异构文档（绕制记录、试验报告、设备日志等）要求接口适配不同格式的结构化数据返回，需提前约定统一的字段映射规则。带工程单位的字段要求接口传输时保留单位信息，避免数据解析时出现偏差。高压试验数据的敏感性要求接口鉴权严格，需通过`Authorization`参数完成身份校验。高频的单台数据更新要求接口支持低延迟响应，适配实时同步需求，避免因数据延迟导致检验流程卡顿。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本适配。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | 固定前缀加企业专属密钥，例如 `Bearer sk-xxxxxx` | 适配高压试验数据的敏感鉴权要求，避免未授权访问 |
| 超时时间 | 600 秒 | 适配大型变压器试验数据的完整返回周期 |
| `responseData` | 仅返回检验与审核所需字段，例如绝缘电阻、局放值、干燥温度 | 减少无效数据传输，降低接口负载 |
| `variables` | 传入单台产品的批次号作为查询参数 | 精准拉取对应批次的检验记录数据 |
| 字段映射规则 | 按产品ID、试验类型分组映射字段 | 适配多类型异构文档的统一解析需求 |
| 数据格式校验 | 开启字段单位校验 | 保留工程单位信息，避免数据解析偏差 |

## 容易做错的三处
- 现象：接口返回`responseData`字段为空，原因：未在配置中指定需要返回的检验记录字段，导致接口返回的冗余数据未被正确识别。
- 现象：请求返回401未授权错误，原因：未正确配置`Authorization`参数，或密钥格式不符合鉴权规则。
- 现象：无法通过API直接与发布的应用通信，原因：未正确配置`variables`参数传入应用所需的产品ID或批次号，或未匹配接口调用的基础格式。

## 怎么确认配好了
- 调用测试接口，查看返回的`responseData`是否包含预设的检验字段，确认字段映射正确。
- 提交带密钥的请求，确认返回状态码为200，无401类鉴权错误。
- 传入指定的产品批次号，确认返回的数据仅对应该批次的检验记录，无冗余数据。
- 查看接口响应时长，确认符合预设的超时阈值，无超时报错。
