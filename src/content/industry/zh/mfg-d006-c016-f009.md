# 变压器与高压电器制造的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来自设计BOM、硅钢片与绝缘材料采购数据、真空干燥设备日志、油化验报告、试验站高压试验记录等。日常文档包含绕制与器身装配记录、真空干燥记录、绝缘油报告、局放与耐压试验报告、铭牌参数表，单台产品对应一套专属的文档集合。数据更新频率为每台产品或每批材料一次，字段包含绝缘含水量、局放数值、耐压等级等专业参数，需按单台进行全流程追溯管理。

## 这些特征在「模型接入与配置」这一环带来什么约束
单台产品对应专属文档集合的特征，要求模型接入时需支持按单台或批次划分知识库边界，避免跨产品数据混淆。多来源的文档格式差异，要求配置适配结构化试验报告、半结构化装配记录等不同类型文本。高频更新的特性，要求配置支持快速增量同步机制，适配每台或每批材料的更新节奏。绝缘参数、局放数值等专业字段的存在，要求配置启用精准的召回与引用逻辑，确保审核时的信息准确性，避免无关内容干扰判断。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配单台产品的长文档集合，避免截断绝缘试验记录、油化验报告等核心内容 |
| `maxTokens` | 2000–3000 token | 控制单轮审核回答的输出长度，确保清晰呈现引线核对、耐压试验结果等审核要点 |
| `quoteMaxToken` | 1200–1500 token | 限制引用文档的总长度，优先保留绝缘参数、局放数值等关键业务数据 |
| `temperature` | 0.1–0.3 | 降低回答随机性，保障检验审核结果的一致性与准确性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写实际接入地址 | 适配模型调用的网络路径要求 |
| `AIPROXY_API_TOKEN` | 按分配的密钥填写 | 完成模型接入的身份验证 |

## 容易做错的三处
- 现象：知识库检索耗时超过30秒，页面返回超时提示。原因：未针对单台产品的文档集合调整`maxContext`参数，导致模型加载过多无关文档。
- 现象：网页调试与外部接入的审核结果存在差异。原因：未统一配置`temperature`等生成参数，导致不同环境下的生成逻辑不一致。
- 现象：模型调用返回未授权或渠道配置错误提示。原因：`AIPROXY_API_TOKEN`填写错误，或`AIPROXY_API_ENDPOINT`地址与部署环境不匹配。

## 怎么确认配好了
- 上传单台产品的典型文档集合，执行检索测试，核对召回结果是否包含绝缘油报告、耐压试验记录等核心业务文档。
- 调整`temperature`参数后，多次执行同一审核问题，确认回答内容的一致性符合业务预期。
- 查看模型调用日志，核对`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置是否与部署环境一致。
- 模拟单台产品的文档更新操作，确认同步流程可正常完成且耗时符合业务节奏。
