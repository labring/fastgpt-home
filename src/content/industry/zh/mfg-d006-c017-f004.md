# 喷涂与涂装的检验与过程记录审核：工作流编排

## 这个品类的数据长什么样
本文基于FastGPT v4.17.0版本的工作流编排功能进行说明。喷涂与涂装场景的核心数据来自涂料供应商TDS/SDS、喷房与烘炉实时采集数据、色差仪/膜厚仪检测结果、环境监测数据及MES系统。日常文档包含涂装工艺卡、涂料批次单、调漆记录、膜厚色差报告、烘炉曲线、缺陷返修单、VOCs台账。数据更新节奏为每批涂料对应批次单更新、每班生成调漆与返修记录、烘炉与环境数据连续采集。文档字段包含涂料批次号、膜厚数值（单位μm）、色差ΔE值、烘炉温度曲线节点、VOCs浓度（单位mg/m³）等。

## 这些特征在「工作流编排」这一环带来什么约束
多源异构的数据来源要求工作流需整合结构化仪器数据、半结构化检测报告与非结构化工艺文档，需配置统一的字段映射规则。不同更新节奏的数据源需对应不同的节点触发时机，连续采集的实时烘炉与环境数据需绑定实时触发节点，批次类的涂料单与工艺卡需绑定批次完成事件。文档字段的专业性要求工作流需提取特定单位的数值用于校验，避免无效字段干扰审核逻辑。出错后果的严重性要求工作流需加入多层校验环节，提前拦截不符合工艺要求的流程，避免批量返修或合规风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配涂装工艺卡、调漆记录等长文本文档，完整保留工艺参数与批次信息 |
| 重叠长度 | 100–150 字符 | 避免长文档拆分后丢失前后关联的膜厚、烘炉温度等关键字段 |
| 相似度阈值 | 0.75–0.85 | 用于匹配涂料批次单与现场检测数据，过滤低匹配度的无效关联 |
| 单次召回上限 | 前 8 条 | 匹配喷涂工序的多维度检测数据，避免冗余信息干扰审核逻辑 |
| 变量绑定 | 按`variables`绑定批次号、膜厚数值、VOCs浓度 | 关联`variables`中定义的现场采集字段，实现自动校验 |
| 节点超时时间 | 300 秒 | 适配烘炉曲线、色差报告等大文件的解析与匹配流程 |

## 容易做错的三处
- 现象为上传涂装工艺卡或检测报告时提示Load file error，原因为未按批次绑定`variables`中的涂料批次号，导致文件关联校验失败。
- 现象为工作流中文件解析节点无执行日志，原因为未配置按批次完成的节点启动规则，导致非触发时段的文件未被处理。
- 现象为代码运行节点无法执行自定义校验逻辑，原因为未明确指定需校验的专业字段，导致代码无法读取对应数据。

## 怎么确认配好了
- 上传单份涂装工艺卡，查看工作流节点的输入输出是否包含预设的字段信息。
- 模拟提交一批涂料的检测数据，检查相似度匹配节点是否返回符合设定规则的关联文档。
- 上传烘炉曲线文件，确认解析节点是否在设定超时时间内完成解析。
- 触发一次完整工作流，检查最终输出是否包含预设的审核校验项。
