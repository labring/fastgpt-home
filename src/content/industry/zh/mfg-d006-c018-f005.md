# 基础化工连续生产的检验与过程记录审核：工具调用与插件

## 这个品类的数据长什么样
基础化工连续生产品类的日常数据来源包括DCS/SIS系统、在线分析仪、LIMS实验室管理系统、设备状态监测模块、能源计量系统与原料储罐监测模块。数据更新节奏分为实时、每班、每日三类，对应不同类型的业务文档。典型文档包含操作规程、工艺指标卡、DCS趋势图、化验报告、联锁旁路记录、特殊作业票与班组日报，字段与单位包含工艺温度（℃）、系统压力（MPa）、物料流量（m³/h）、物料浓度（%）与联锁阈值（固定量程）等。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据来源分散且更新节奏差异大，要求工具调用插件需适配多类型数据源的API格式，避免因数据格式不兼容导致校验失败。强联锁控制的业务特性要求工具调用需具备严格的权限校验与结果校验逻辑，防止误操作引发装置异常。多文档类型的场景要求插件可识别不同文档的专属字段，例如联锁旁路记录需匹配联锁ID与生效时间字段，确保审核数据的准确性。实时数据的高频更新要求工具调用的响应延迟需控制在合理区间，保障检验审核的时效性，启用`functionCall`可适配复杂的工艺数据校验逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配多类型工具调用需求，自动匹配检验与审核相关插件 |
| `functionCall` | `enabled` | 启用自定义函数调用，适配复杂的工艺数据校验逻辑 |
| 单次工具调用上限 | 前3次 | 避免循环调用导致资源占用过高，符合化工流程的稳态控制逻辑 |
| 工具调用超时 | 60秒 | 适配实时工艺数据的响应要求，避免因等待过长影响审核流程 |
| 知识库引用变量 | 工作流入参变量 | 支持动态切换对应工艺的知识库，适配不同生产单元的审核需求 |
| 工具调用结果校验 | 开启 | 校验返回数据的字段完整性与单位一致性，符合化工数据的规范要求 |

## 容易做错的三处
- 现象：调用外部API时返回报错信息，无法获取工艺数据。原因：未在插件清单中添加对应数据源的API配置，无法识别调用目标。
- 现象：工具调用重复执行，日志显示多次触发同一插件节点。原因：未在工作流末尾配置工具调用终止节点，导致流程循环触发调用。
- 现象：知识库搜索节点无法加载传入的变量值，搜索结果为空。原因：未将工作流入参正确绑定到知识库选择字段，导致变量未传递至节点配置中。

## 怎么确认配好了
- 触发测试工作流，查看FastGPT v4.17.0的工具调用日志，确认调用的插件与配置项一致。
- 传入测试变量，检查知识库搜索节点是否加载对应工艺的知识库，验证变量传递生效。
- 模拟工具调用超时场景，确认触发预设的超时处理逻辑，验证超时配置生效。
- 连续运行3次以上测试流程，确认未出现重复执行的情况，验证终止配置生效。
