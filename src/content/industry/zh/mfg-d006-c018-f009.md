# 基础化工连续生产的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类数据来自DCS/SIS系统、在线分析仪、LIMS实验室管理系统、设备状态监测模块、能源计量节点与原料储罐传感器。日常文档包含操作规程、工艺指标卡、DCS趋势图、化验报告、联锁旁路记录、特殊作业票与班报。数据更新节奏分为实时（如工艺参数、联锁状态）、每班（如班报、作业记录）、每日（如能耗汇总、储罐库存）。文档字段包含带单位的工艺指标、联锁触发条件、化验结果数值与作业审批状态。

## 这些特征在「模型接入与配置」这一环带来什么约束
实时更新的工艺数据要求模型上下文窗口能适配高频增量同步，避免上下文溢出。多源异构数据包含时序图、结构化记录与文本表单，要求配置支持多模态接入与结构化解析。每班/每日的批量文档需要配置合理的检索逻辑，适配不同更新周期的文档召回。带单位的工艺字段要求模型能准确识别并关联单位，避免参数校验错误。联锁旁路记录等合规性文档需要配置高置信度的匹配规则，确保审核结果符合生产规范。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配基础化工连续生产的多源实时工艺数据与历史记录，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 满足长文档审核与多参数核对的输出需求，适配班报、联锁记录等长文本 |
| `temperature` | 0.1–0.3 | 降低审核结果的随机性，确保工艺参数核对、联锁状态判断的一致性 |
| `AIPROXY_API_ENDPOINT` | 按平台提供的专属地址填写 | 适配企业内部网络与接口权限要求，保障数据传输安全 |
| `AIPROXY_API_TOKEN` | 按授权文档生成的专属令牌 | 完成接口身份验证，符合基础化工企业的权限管控要求 |

## 容易做错的三处
- 现象：接口返回429状态码，并发请求时触发调用限制。原因：未根据实时工艺数据的更新节奏配置合理的请求间隔，未设置请求队列限流规则。
- 现象：无法通过SK/AK方式完成国内模型的接口授权。原因：仍沿用旧版渠道添加流程，未适配平台最新的授权配置逻辑。
- 现象：接入Qwen3系列模型时，自定义参数无法在指定界面生效。原因：未在FastGPT v4.17.0的模型配置面板中正确填写适配参数，混淆了基础参数与扩展参数的填写位置。

## 怎么确认配好了
- 提交单条工艺记录审核请求，检查接口返回状态码是否正常，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置有效。
- 导入一批包含工艺参数、联锁记录的测试文档，核对模型输出的审核结果是否覆盖了文档中的关键字段。
- 发起多并发测试请求，验证接口调用频率限制规则是否生效，避免触发第三方接口的限流机制。
- 调整`temperature`参数值，观察模型输出结果的一致性变化，确认参数配置对生成逻辑的影响符合预期。
