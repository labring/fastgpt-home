# 基础化工连续生产的检验与过程记录审核：知识库检索与召回

## 这个品类的数据长什么样
该品类数据来自DCS/SIS系统、在线分析仪、LIMS系统、设备状态监测模块、能源计量系统与原料储罐台账。日常文档包含操作规程、工艺指标卡、带时间戳的DCS趋势图、化验报告、联锁旁路记录、特殊作业票与班报。数据更新节奏覆盖实时（如DCS趋势、在线分析仪数值）、每班（如班报、特殊作业票）与每日（如月度化验汇总）。文档字段包含工艺参数（如反应温度、压力，单位为℃、MPa）、设备编号、联锁逻辑、采样时间与合格判定结果，结构覆盖结构化数值报表与非结构化文本记录。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据类型要求检索系统同时支持结构化字段匹配与全文检索，避免遗漏工艺参数、联锁编号等关键专业信息。不同更新频率的文档需要区分时效性，实时数据需优先召回最新版本，过期的旧操作规程需被过滤。检验与审核场景需精准匹配多份关联文档，单次召回的内容需覆盖工艺要求、实时数据与历史记录，避免召回无关的非工艺类文档。同时，错误的召回结果可能引发生产事故，需严格控制低匹配度的无关内容进入上下文。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 基础化工工艺参数阈值明确，该区间可过滤低匹配度的无关文档，避免误召回旧的错误工艺指标 |
| `limit` | 前6条 | 检验审核需核对多份关联文档，该数量可覆盖工艺指标卡、DCS趋势、联锁记录等核心内容，且不超出上下文窗口限制 |
| `usingReRank` | 开启 | 可对初始召回结果按专业相关性重新排序，优先返回联锁记录、工艺要求等关键审核依据 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可对用户的检验审核问题做扩展拆解，匹配关联的多份文档，避免仅召回单条孤立内容 |
| `searchMode` | 全文+结构化字段检索 | 适配该品类的异构数据结构，同时匹配文本内容与工艺参数、设备编号等结构化字段 |

## 容易做错的三处
- 现象：检索结果仅返回单条引用链接，无对应回答内容。原因：未开启`datasetSearchUsingExtensionQuery`，未对用户的检验审核问题做扩展拆解，无法匹配到关联的多份工艺文档与记录。
- 现象：导入的docx、excel文档中，工艺参数、联锁编号等结构化字段无法被正确召回。原因：未配置匹配结构化字段的检索模式，仅依赖全文检索无法精准匹配专业字段内容。
- 现象：导入飞书文档后，部分图片附带的文字说明无法被检索到。原因：未开启图片文本提取功能，或未对飞书文档的嵌套格式做适配处理，导致部分内容未被正确索引。

## 怎么确认配好了
- 上传一份测试用的工艺指标卡与DCS趋势文档，在FastGPT v4.17.0环境下发起“核对当前反应釜压力是否符合工艺要求”的测试问题，检查召回结果是否包含对应文档的阈值与实时数值。
- 查看知识库索引日志，确认导入的所有文档类型（docx、excel、飞书文档）均已生成索引条目，无格式报错。
- 调整`similarity`参数的取值，测试不同阈值下的召回结果数量，确认过滤效果符合专业场景的需求。
- 开启`usingReRank`后，测试同一问题的召回结果排序是否更贴合审核优先级，优先返回联锁记录与工艺要求类文档。
