# 塑料注塑成型的检验与过程记录审核：HTTP 接口与外部系统
本文适用于 FastGPT v4.17.0 版本。

## 这个品类的数据长什么样
该品类的数据涵盖注塑工艺卡、原料干燥记录、模具履历、首件检验、巡检表、换料清机记录等文档，数据来源包括树脂批次与物性表、注塑机参数、模温机、MES系统、尺寸与外观检测设备。数据更新频率为每生产批次、每次换模换料、每班结束时更新，字段包含批次号、模具编号、原料含水率、工艺温度与压力参数、检验结果等，单位涉及摄氏度、兆帕、秒等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据强绑定生产批次与模具，且更新频率为每批次、换模换料及每班更新，因此HTTP接口需支持按唯一标识拉取对应批次的业务数据，避免跨批次数据混淆。不同数据源的字段格式存在差异，接口需兼容异构系统的返回结构，需配置灵活的字段映射规则。同时，注塑工艺参数的采集存在固定周期，接口超时设置需适配该周期，避免因超时中断数据拉取流程。此外，检验与审核流程需依赖准确的业务字段，接口需支持基础数据校验，确保字段符合注塑业务的定义。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer ${绑定的外部系统API密钥}` | 符合HTTP接口标准认证格式，适配注塑机、MES等系统的鉴权要求 |
| `variables` | `{"batchId": "", "moldSerial": ""}` | 绑定注塑批次与模具编号，匹配业务数据的关联规则，便于按批次拉取检验记录 |
| `responseData` | `$.records[*]` | 适配多数注塑设备返回的检验数据嵌套结构，提取有效字段用于审核流程 |
| 请求超时设置 | `30–60 秒` | 适配注塑工艺参数的采集周期，避免因网络延迟导致数据拉取中断 |
| 字段映射规则 | 按实测标定 | 不同注塑设备返回的字段名称存在差异，需匹配本地业务文档的字段定义 |

## 容易做错的三处
- 现象：外部系统返回消息接收地址校验失败提示。原因：未将接口部署在公网可访问的环境，或未正确配置SSL证书校验选项。
- 现象：接口调用返回空的检验记录列表。原因：未通过`variables`传入正确的批次号或模具编号，无法匹配对应业务数据。
- 现象：接口返回403 Forbidden状态码。原因：未正确配置`Authorization`参数，或使用了过期的外部系统API密钥。

## 怎么确认配好了
- 调用配置好的HTTP接口，查看返回的`responseData`是否包含预期的注塑检验记录字段。
- 传入测试用的批次号与模具编号，验证接口是否能返回对应批次的业务数据。
- 检查`Authorization`参数格式是否符合标准Bearer令牌规范，确认鉴权通过。
- 模拟外部系统触发回调，验证接口是否能正常接收并处理数据。
