# 塑料注塑成型的检验与过程记录审核：工具调用与插件

## 这个品类的数据长什么样
该品类的数据涵盖树脂批次物性表、注塑机运行参数、模温机监测数据、MES系统生产记录、尺寸与外观检测结果。日常文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验表、巡检记录表、换料清机记录。数据更新随每生产批次、每次换模换料、每班作业触发，字段包含注塑机螺杆转速（单位转/分钟）、模腔温度（单位℃）、充填保压时长（单位秒）、原料批次编号、模具循环次数等。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据更新随生产批次、换模换料、每班作业触发，且来源分散覆盖设备、系统、检测结果，文档字段包含特定行业参数与单位。工具调用需绑定生产事件触发逻辑，确保在对应节点自动执行检验与记录审核任务，此时可通过`toolChoice`配置自动选择适配的工具。多数据源对接需求要求插件支持适配注塑机、模温机、MES等不同类型的系统接口，参数解析需匹配螺杆转速、模腔温度等行业标准字段。单次处理的数据量需限制在单批次或单班次范围内，避免因数据集过大导致调用超时。检验结果需同步至生产系统，确保异常记录可被及时追溯。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 触发时机 | 按生产事件触发（换模、换料、每班作业结束） | 匹配该品类数据的更新节奏 |
| 工作流/API 工具选择配置 | `auto` | 自动选择适配注塑检验场景的工具 |
| 工作流/API 函数调用配置 | 批量调用模式，单次处理上限为50条记录 | 适配单批次生产的检验数据量 |
| 数据源适配 | 绑定注塑机、模温机、MES的专用接口 | 覆盖该品类的全量数据来源 |
| 参数校验阈值 | 模温偏差±5℃、充填时长偏差±2秒 | 匹配注塑工艺卡的额定参数要求 |
| 超时设置 | 600秒 | 适配单批次数据处理的典型时长 |

## 容易做错的三处
- 现象：调用API时，对话日志中出现未预期的非检验类标题内容。原因：未在工具调用配置中过滤无关文档片段，导致非目标内容被带入上下文。
- 现象：调用工具时偶发超时报错。原因：单次调用处理的数据集超过配置上限，未按生产批次拆分任务。
- 现象：工具调用返回的检验结果无法匹配注塑行业字段格式。原因：未配置行业专用的参数解析规则，导致字段与生产系统不兼容。

## 怎么确认配好了
- 触发一次换模事件，检查工具是否自动启动并调用对应数据源。
- 查看工具调用日志，确认返回的参数符合注塑工艺的额定区间。
- 验证检验结果是否同步至预设的生产系统台账。
- 模拟异常参数输入，检查工具是否触发异常告警逻辑。
