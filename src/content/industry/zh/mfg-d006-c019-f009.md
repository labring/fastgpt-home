# 塑料注塑成型的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类的数据涵盖注塑工艺卡、原料干燥记录、模具履历、首件检验、巡检表、换料清机记录等结构化文档，数据来源包括树脂批次物性表、注塑机参数、模温机、MES系统、尺寸与外观检测设备。数据更新频率为每生产批次、每次换模换料、每班交接班时更新，单份文档包含模具编号、原料型号、模温、注塑压力、保压时长、原料干燥参数等工业参数，参数带有明确的工业单位标识。

## 这些特征在「模型接入与配置」这一环带来什么约束
多来源的分散数据要求接入配置支持跨系统的文档同步与解析，适配不同格式的工业记录。高频更新的特性要求配置支持近实时的文档拉取与处理，避免数据滞后影响检验审核效率。多样的文档类型与带单位的工业参数，要求配置适配结构化文档的字段识别，确保模型能准确读取关键参数。严重的批量不良、模具损伤或混料风险，要求配置降低模型输出的随机性，保证检验与审核结果的一致性与准确性。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配注塑工艺记录的长文本上下文需求，避免截断关键工艺参数与历史检验数据 |
| `maxTokens` | 2000–3000 token | 满足检验结果分析的输出长度，覆盖缺陷类型判定与整改参数建议 |
| `temperature` | 0.2–0.4 | 降低模型输出的随机性，保证工业参数判断与缺陷判定的一致性 |
| `vision` | 开启 | 适配外观缺陷检测的图像输入需求，识别飞边、短射、翘曲等外观问题 |
| `AIPROXY_API_ENDPOINT` | 按接入模型的实际部署地址填写 | 匹配第三方大模型的调用路径，确保请求能正确送达目标模型 |
| `AIPROXY_API_TOKEN` | 按平台分配的密钥填写 | 完成大模型调用的身份验证，防止未授权访问 |

## 容易做错的三处
- 现象：批量执行节点通过API调用时无法完成全部循环，在线调试可正常运行。原因：API调用时未配置足够长的超时参数，或未启用批量节点的异步回调机制，导致请求超时中断。
- 现象：调用视觉模型时无法识别注塑件外观图像。原因：未开启`vision`配置项，或未传入符合要求的图像格式数据，导致模型无法解析视觉输入。
- 现象：无法查询到大模型调用的requestid。原因：未开启平台的日志记录配置，或日志存储路径未正确配置，导致requestid未被捕获并存储。

## 怎么确认配好了
- 核对`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的填写内容，与第三方大模型平台的配置信息保持一致。
- 发起单次测试调用，查看返回结果中包含requestid字段，确认日志已正常记录调用信息。
- 上传注塑件外观图像与对应工艺记录，验证模型能正确输出缺陷分析与参数调整建议。
- 启动批量执行节点的测试流程，确认在线调试与API调用均能完成全部循环步骤。
