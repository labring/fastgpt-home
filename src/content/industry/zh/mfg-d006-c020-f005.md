# 安全环保与特殊作业管理的检验与过程记录审核：工具调用与插件

## 这个品类的数据长什么样
该品类的数据涵盖化工、冶金等制造企业EHS部门及检维修团队的安全环保与作业管理文档，包括风险辨识清单、动火/受限空间/吊装作业票、在线监测记录、危废台账、排放监测报表、事故与隐患整改报告。数据来源包括行业法规标准、在线环保监测设备、气体检测仪、人员资质档案、设备隔离清单及监管平台。数据更新随单次作业完成、实时监测周期或定期检查推进，文档字段包含作业起止时间（精确到分钟）、气体浓度值（ppm）、人员资质编号、隔离设备标识等，需匹配作业合规校验的必要要求。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据来源分散且格式差异大，工具调用需同时对接在线监测设备、人员资质档案、监管平台等多类数据源，需配置适配多格式数据解析的插件。单次作业的实时数据与定期巡检的批量数据更新节奏不同，工具触发需匹配作业流程节点，避免重复调用或遗漏关键环节。文档字段需覆盖合规校验的必要项，工具调用需提取并验证作业时间、气体浓度、人员资质等字段，且需适配不同作业类型的文档结构，确保校验逻辑覆盖全部合规要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配不同作业场景下的自动选择工具，覆盖风险辨识、资质核验等多类任务 |
| `functionCall` | 开启 | 确保模型严格按照预设工具参数调用，避免生成不符合合规要求的非结构化结果 |
| 工具调用超时时间 | 600 秒 | 匹配气体监测数据上传、资质数据库查询的平均响应时长 |
| 单轮工具调用重试次数 | 2 次 | 平衡接口调用成功率与作业流程的响应速度 |
| 多源数据合并规则 | 按作业票编号关联 | 匹配该品类文档的唯一标识字段，确保数据整合的准确性 |

*注：本页面配置适用于 FastGPT v4.17.0*

## 容易做错的三处
- 调用在线监测接口时返回 400 status code (no body)，原因是未按照接口文档要求携带作业类型与作业票编号作为请求参数，接口无法定位对应监测数据。
- 配置`functionCall`时未绑定该品类专属的合规校验工具，导致大模型生成的函数调用未覆盖人员资质、设备隔离等关键校验项，出现调用效果差的问题。
- 未设置工具调用的异常校验逻辑，导致工具返回的危废台账数据与在线监测数据不一致时未触发告警。

## 怎么确认配好了
- 发起一次模拟动火作业的工具调用流程，核对工具是否自动调用气体检测仪接口、人员资质数据库接口与作业票校验插件。
- 查看工具调用日志，确认返回结果包含作业时间、气体浓度、人员资质等必填字段，且格式符合文档要求。
- 模拟临时网络波动导致接口请求失败的场景，核对是否触发预设的重试机制。
- 对比工具返回的合规校验结果与手动校验的结果，确认逻辑匹配。
