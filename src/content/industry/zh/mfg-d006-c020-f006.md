# 安全环保与特殊作业管理的检验与过程记录审核：引用来源与溯源

## 这个品类的数据长什么样
本品类数据来自化工、冶金、机械、轻工等制造企业的EHS部门与生产检维修团队，涵盖风险辨识文档、动火/受限空间/吊装等作业票、危废台账、排放监测记录、人员资质文件、设备隔离清单等。数据来源包含公开法规标准、在线环保监测系统、气体检测仪、人员资质数据库、设备管理平台与监管端接口。更新节奏覆盖每次作业完成即时更新、监测数据实时推送、资质与合规文档定期校验。单份文档包含作业编号、监测数值、资质有效期、隔离状态等字段，单位涉及合规计量相关的标准单位。

## 这些特征在「引用来源与溯源」这一环带来什么约束
多源异构的数据来源要求溯源系统支持跨本地文档、硬件接口、在线平台的统一关联，避免出现来源混淆。高频更新的特性要求溯源结果必须匹配最新的作业与监测数据，无法依赖静态缓存。文档字段的专业性与合规性要求溯源需精准映射原始字段，不能遗漏作业票编号、监测阈值等关键合规信息。同时，该品类的高风险属性要求溯源结果具备可追溯性，需完整保留原始数据的来源标识与校验信息，确保审核环节可验证。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | `800–1200 token` | 作业票与监测记录的典型文本长度，确保覆盖核心审核信息 |
| `responseData` | 保留原始字段映射 | 需完整展示作业编号、监测值等合规字段，满足溯源审核要求 |
| `detail` | 开启精准召回 | 该品类需匹配高置信度的合规文档，避免无关内容干扰审核 |
| 单次召回条数 | 前8–12条 | 作业审核需关联核心的3-5份文档，避免过多冗余信息 |
| 多源数据召回开关 | 开启 | 数据来源包含在线平台、硬件接口与本地文档，需统一纳入溯源范围 |
| 溯源信息展示层级 | 显示来源路径与校验时间 | 高风险场景需完整展示数据的合规校验痕迹 |

## 容易做错的三处
- 现象：调用查询时无法设置300左右的引用上限，仅可选100或900的固定档位。原因：未通过`quoteMaxToken`参数自定义调整，直接使用了界面固定档位配置。
- 现象：检索结果未包含在线环保监测平台的实时数据。原因：未开启多源数据召回开关，仅召回了本地存储的静态文档。
- 现象：溯源结果中缺失气体检测仪的检测时间字段。原因：未配置`responseData`的原始字段保留规则，仅返回了摘要化的文本内容。

## 怎么确认配好了
- 发起包含特定作业票编号的查询，检查返回结果是否关联了对应的风险辨识文档与作业许可记录。
- 查看溯源模块，确认是否显示了原始数据的来源路径与校验时间信息。
- 调整`quoteMaxToken`参数后，验证返回的引用文本长度是否符合预期的合规文档范围。
- 在FastGPT v4.17.0版本中导入实时监测数据，确认检索结果是否包含最新的监测数值与更新时间。
