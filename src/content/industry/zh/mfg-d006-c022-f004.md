# 家用电器整机制造的检验与过程记录审核：工作流编排
本文基于FastGPT v4.17.0版本进行配置说明。

## 这个品类的数据长什么样
家用电器整机制造的检验与过程记录审核涉及多源数据，数据来源包括ERP/MES系统、零部件批次台账、拧紧与充注设备、安规测试仪、性能实验室设备及售后故障数据库。数据更新频率分为每台产品对应一次的充注、测试记录，每班产出的批量抽检报告，以及按固定计划生成的返修记录。日常文档涵盖配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告与返修记录，字段包含物料编码、扭矩参数、充注量、绝缘电阻值等，对应单位为牛米、克、兆欧等。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的多源、高频更新与混线生产特征，对工作流编排带来多重约束。首先，大批量混线装配要求工作流支持按产品型号、生产批次过滤知识库内容，避免不同型号的BOM与作业书混淆。其次，充注与安规测试记录可通过已配置的集成接入工作流，例如由 HTTP 请求节点调用工厂系统开放的 API。数据能否自动提供，取决于外部接口及其对接；若没有可用 API 或集成，仍需通过现有上传或录入流程提供记录。应在目标部署中核验鉴权、字段映射与更新时序。此外，多类型文档的混合检索要求工作流配置适配不同文档的字段提取规则，便于审核人员获取对应工序的检测参数。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 相似度阈值 | 0.75–0.85 | 家用电器整机检验文档专业度高，需精准匹配工序与检测项，避免混线型号干扰 |
| 单次搜索上限 | 前8条 | 混线生产下同型号文档较多，需控制返回量避免上下文过载 |
| 引用内容模板 | `{{docTitle}} \| {{fieldName}}:{{fieldValue}}` | 需清晰展示检测项对应参数，便于审核人员快速定位异常 |
| 引用模板提示词 | 基于以下检测数据完成审核：{{recall}} | 明确告知AI需结合检索到的文档内容进行审核判断 |
| `variables` | 设置为当前生产批次号、产品型号 | 精准过滤对应批次的BOM与作业书，避免跨型号数据混淆 |
| `nodeId` | 标识用于安规测试与充注记录的工作流节点 | 用节点 ID 跟踪相关工作流步骤；数据访问仍取决于已配置的数据源集成 |

## 容易做错的三处
- 免登录链接中自定义变量未生效，界面显示字段为空。原因：未在工作流启动配置中绑定免登录链接的变量参数，导致变量未传递到节点中。
- 知识库搜索节点鉴权不生效，非授权用户可访问私有检验文档。原因：未在工作流权限配置中绑定对应生产部门的角色权限，导致鉴权规则未生效。
- AI对话节点返回的审核结果未引用指定文档内容。原因：混淆了引用内容模板与引用模板提示词的配置位置，导致检索到的内容未正确代入提示词中。

## 怎么确认配好了
- 启动工作流并传入指定生产批次的参数，检查检索到的文档是否仅包含对应型号的BOM与作业书，确认`variables`配置生效。
- 触发已配置的数据集成，并将返回的检测数据与来源系统记录核对；确认工作流节点和字段映射正确。若通过外部 API 或导入接入，也应检查相应访问日志与更新记录。
- 查看AI对话节点的输出，确认检索到的文档内容已按预设模板展示，且提示词中正确引入了检索结果。
- 切换非授权角色访问工作流，确认无法检索到私有检验文档，确认鉴权配置生效。
