# 家用电器整机制造的检验与过程记录审核：引用来源与溯源

## 这个品类的数据长什么样
该品类数据覆盖空调、冰箱、洗衣机及小家电生产全流程，日常文档包含配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告与返修记录。数据来源涵盖ERP/MES系统、零部件批次台账、拧紧与充注设备日志、安规测试仪数据、性能实验室检测结果及售后故障记录。更新节奏按单台产品、每班生产批次或抽检计划执行，单条数据包含产品型号、生产批次、工艺参数、检测结果与关联设备编号等字段。

## 这些特征在「引用来源与溯源」这一环带来什么约束
单台产品的高频更新数据要求溯源时快速定位对应批次与工艺节点，避免混线错装时引用错误型号的工艺数据。多类型文档的混合检索需区分配置BOM、安规测试报告等不同文档类型，匹配业务场景。按抽检计划更新的静态检测数据与实时工艺日志需配置差异化检索规则，确保异常抽检结果优先被召回。面向消费者的产品特性要求溯源数据需包含明确的批次、参数与合规信息，支撑售后与合规溯源需求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `quoteMaxToken` | 800–1200 token | 适配家电整机制造的单批次工艺记录与检测报告长度，避免上下文过载 |
| `responseData` | 带元数据的完整片段 | 强制返回文档的批次、型号与生成时间，支撑合规溯源需求 |
| `detail` | 开启 | 展示完整的文档内容与关联字段，便于审核人员核对工艺参数 |
| 相似度阈值 | 0.6–0.7 | 匹配家电制造的工艺文档与检测报告的语义相似度，过滤低相关数据 |
| 单次搜索上限 | 前5条 | 覆盖单台产品的多类型关联文档，同时减少冗余信息干扰 |

## 容易做错的三处
- 现象：上传100个5kb的家电工艺文档后，约一半显示训练异常，检索时无法召回对应内容。原因：未按家电文档的类型（如制冷剂充注记录、安规测试报告）设置分块规则，导致分块后元数据丢失。
- 现象：设置相似度阈值为0.4后，检索结果混入大量不相关的混线装配数据，无法定位目标检测报告。原因：阈值设置过低，未过滤家电制造场景下语义相似但业务无关的文档片段。
- 现象：将`quoteMaxToken`设置为20000 token后，AI回答中出现大量冗余的非目标文档内容，无法快速定位关键工艺参数。原因：引用上限设置过大，导致系统加载过多无关上下文，干扰检索精准度。

## 怎么确认配好了
- 上传单台家电的装配作业书与安规测试报告，发起检索，核对返回结果是否包含对应文档的批次与型号元数据。
- 调整相似度阈值至业务场景下的合理区间，发起多次检索，确认结果条数与相关性符合预期。
- 设置`quoteMaxToken`为对应文档长度的区间，验证AI回答中引用的文档片段长度符合配置要求。
- 上传多批次的工艺文档，检索目标批次的内容，确认召回结果未混入其他批次的无关数据。
