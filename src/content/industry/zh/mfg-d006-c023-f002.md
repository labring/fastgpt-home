# 工业仪器仪表制造与校准的检验与过程记录审核：向量模型与索引

## 这个品类的数据长什么样
本品类数据来自设计文件、标准器与环境监测数据、校准软件、实验室信息系统及客户量程要求。日常文档包含装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录，单台设备每次校准即生成新数据。数据包含结构化的校准参数、误差计算结果，以及非结构化的曲线说明文本，字段包含量程、误差值、计量证书编号、校准日期等，单位涵盖压力、温度、流量等物理量单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类的数据来源分散且更新频繁，每次校准即生成新数据，对索引的增量更新能力提出要求。数据包含结构化的校准参数、误差计算结果与非结构化的曲线说明，单条数据长度差异显著，需适配不同长度的文本分块。数据包含物理量单位、计量证书编号等专业术语，向量模型需适配工业计量领域的专业语义，确保召回结果准确匹配校准场景需求。同时，校准记录为关键交付物，索引需支持关联检索溯源链相关文件，避免遗漏审核所需的关键信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 本品类校准记录、误差说明文本长度多在此区间，避免分块破坏专业术语完整性 |
| 重叠长度 | 100–150 字符 | 校准规程中的关键步骤多为连续表述，重叠分块可保留上下文关联 |
| 相似度阈值 | 0.75–0.85 | 过滤低匹配度的非相关校准文件，确保审核所需的溯源信息准确召回 |
| 单次搜索上限 | 前 8 条 | 本品类审核需覆盖多维度校准数据，少量条目即可覆盖主要关联信息 |
| `defaultToken` | 按校准记录样本设置直接分块的默认 token 数 | 该字段表示分块 token 数，不是嵌入模型标识；应结合样本验证分块效果 |
| `maxToken` | 按所选嵌入模型/服务支持的最大 token 数设置 | 该上限取决于模型和部署，不假设固定版本默认值 |

## 容易做错的三处
- 现象为向量模型调用失败或界面提示「无可用渠道」。可能原因包括模型/渠道、服务地址或凭证配置问题；`defaultToken`不是模型或渠道标识，需结合完整日志定位。
- 现象为知识库搜索耗时超过预设阈值，单次召回结果条数不足。原因是分块长度设置过大，导致单条向量数据过长，索引检索效率降低，且未设置合理的单次搜索上限。
- 现象为向量召回结果包含大量不相关的误差曲线文本。原因是相似度阈值设置过低，未过滤低匹配度的非目标文档，导致审核时需要额外筛选无效信息。

## 怎么确认配好了
- 检查所选向量模型的标识、渠道、服务地址与凭证；若使用自定义模型配置，确认`defaultToken`用于直接分块 token 数，且`maxToken`不超过模型/服务支持上限。
- 导入单份原始校准记录，查看分块后的文本片段与设置的分块长度、重叠长度匹配。
- 发起包含计量证书编号的检索请求，核对召回结果包含关联的校准规程与误差分析文档。
- 执行增量索引更新测试，确认新生成的校准数据可被正常检索，无需触发全量索引重建。
