# 工业仪器仪表制造与校准的检验与过程记录审核：多轮对话与提示词

## 这个品类的数据长什么样
本品类数据来自流量、压力、温度、分析仪器制造商及计量实验室，涵盖装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录等文档。数据来源于设计文件、标准器与环境监测数据、校准软件、实验室信息系统及客户量程要求，更新频率为每台设备每次校准。文档字段包含被测件编号、校准环境参数、误差计算值、溯源链编号等，单位涵盖Pa、℃、ppm等测量相关标准单位。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
每台设备每次校准的高频更新特性，要求对话上下文需精准绑定单台设备的单次校准流程，避免跨设备数据混淆。多类型结构化文档的混合输入，需要提示词明确指定优先读取计量证书、误差曲线等核心审核字段。溯源链、环境条件等审核环节的强关联性，要求多轮对话需保留每一步的审核节点记录，确保后续回溯时可追溯完整流程。不同文档的字段单位差异，需要提示词统一单位转换规则，避免跨文档计算误差。

## 配置怎么定
本配置基于 FastGPT v4.17.0 版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 上下文窗口大小 | 前 15–25 条历史消息 | 适配单台设备单次校准的审核步骤数量，避免冗余数据干扰 |
| `variables` 绑定规则 | 绑定被测件编号、校准环境参数变量 | 对应本品类文档的核心字段，精准关联单台设备校准流程 |
| `messages` 上下文过滤 | 仅保留当前校准批次的对话内容 | 符合本品类按批次管理校准数据的更新频率要求 |
| 提示词模板变量 | 嵌入`{{平台的当前日期}}` | 满足校准证书落款时间的固定格式要求，适配交付规范 |
| `chatId` 绑定规则 | 绑定单台设备单次校准的唯一标识 | 避免跨设备对话数据混淆，确保审核溯源完整 |
| 单次对话最大时长 | 600 秒 | 适配校准审核的单轮操作时长，避免超时中断 |

## 容易做错的三处
- 现象：对话历史未保存，重新打开后回复内容为空。原因：未绑定`chatId`参数或配置中未开启历史记录存储，导致对话上下文未持久化。
- 现象：提示词中使用`{{平台的当前日期}}`变量未正确生成落款时间。原因：变量未正确嵌入提示词模板，或模板中存在格式冲突导致变量解析失败。
- 现象：工作流中前一个AI对话的回复被带入最终输出结果。原因：未配置上下文过滤规则，导致历史消息未被截断，多轮对话的冗余内容被一并返回。

## 怎么确认配好了
- 发起单台设备的校准审核对话，查看上下文窗口中仅显示当前批次的历史消息。
- 在提示词中插入`{{平台的当前日期}}`变量，生成测试内容，确认落款时间与系统当前日期一致。
- 复制当前对话的`chatId`，重新打开对话页面，确认历史消息与之前的内容一致。
- 配置工作流多轮对话，测试仅输出最后一轮的审核结果，确认前一轮内容未被带入。
