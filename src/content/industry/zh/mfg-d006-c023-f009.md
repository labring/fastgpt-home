# 工业仪器仪表制造与校准的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类的典型主体为流量、压力、温度、分析仪器制造商及计量实验室。日常产生的文档包括装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录。数据来源涵盖设计文件、标准器和环境监测数据、校准软件、实验室信息系统、客户量程要求，更新频率为每台设备每次校准更新一次。每份校准相关文档包含被测件编号、校准点参数、环境条件记录、多点测量值、误差计算结果、溯源链信息等字段，单位对应仪器测量类型，如温度校准记录使用℃，压力校准记录使用kPa。

## 这些特征在「模型接入与配置」这一环带来什么约束
首先，数据来源分散在多套系统与工具中，要求模型接入配置支持多源数据导入与统一解析，避免手动整理带来的误差。其次，单台设备每次校准生成的文档存在结构混合特征，既有结构化的校准参数字段，也有非结构化的误差曲线描述与证书文本，要求配置适配混合格式的文档解析。再者，校准记录的溯源链信息与误差计算结果是审核核心，需确保配置不会截断关键内容，同时过滤无关的历史记录。另外，更新频率为单次单台，要求配置支持单次批量处理单台设备的校准文档，适配小批量高频的业务场景。最后，计量审核的严谨性要求模型输出的审核结果具备一致性，需限制输出的随机性。

## 配置怎么定
FastGPT v4.17.0版本中，以下配置项可直接在模型接入页面进行设置：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 单台设备的完整校准记录、误差曲线、计量证书等文档的总token数通常处于该区间，避免截断关键的溯源链与误差计算信息 |
| `maxTokens` | 2000–3000 token | 用于生成审核结论或提取结构化字段的输出长度，覆盖完整的误差分析与审核意见 |
| `quoteMaxToken` | 1500–2000 token | 限定引用的原始记录片段长度，确保仅提取与审核相关的校准数据与环境条件，避免混入无关内容 |
| 工作流/API 工具选择配置 | auto | 自动选择合适的工具提取结构化字段，适配校准记录中混合的结构化参数与非结构化文本 |
| `temperature` | 0.1–0.3 | 降低输出随机性，确保审核结果的一致性，符合计量审核的严谨要求 |
| `AIPROXY_API_ENDPOINT` | 按实际部署的代理地址填写 | 适配国内或海外的模型调用链路，规避跨区域访问限制 |

## 容易做错的三处
- 现象：通过API调用模型接入配置的工作流时，未收到用户输入或选择的提示信息。原因：未在工作流中正确配置交互节点的输出参数，或未在API调用时指定正确的会话上下文参数。
- 现象：配置`AIPROXY_API_ENDPOINT`时输入错误的端口号，仍能正常访问模型服务。原因：代理服务未对端点合法性进行校验，或存在冗余的默认回退链路，导致错误配置未触发拦截。
- 现象：语义检索返回的相关结果条数过多或分数过高，无法筛选出有效校准记录。原因：未配置合理的上下文过滤规则，导致检索时未限定与校准审核相关的文档片段，混入了无关的历史记录。

## 怎么确认配好了
- 上传单台设备的完整校准记录文档，触发模型接入配置的测试流程，核对输出的审核结果是否包含所有关键字段，调整配置项以匹配预期的提取范围。
- 调用API接口发送测试请求，检查返回结果是否包含预期的交互提示或结构化提取内容，验证参数配置的有效性。
- 修改`AIPROXY_API_ENDPOINT`为无效地址，触发调用并检查是否返回对应错误提示，验证安全配置的有效性。
- 调整`temperature`参数的取值，观察输出结果的随机性变化，确认参数生效后恢复至合理区间。
