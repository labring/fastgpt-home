# 服装裁剪与缝制的检验与过程记录审核：工具调用与插件

## 这个品类的数据长什么样
服装裁剪与缝制品类的日常文档包含工艺单、CAD样板、排料图、裁剪单、首件封样、工序质量表、包装配码单等。数据来源涵盖订单与尺码表、CAD设计文件、面辅料检验记录、车间吊挂系统数据、验针机检测结果及客户封样标准。数据更新以每订单、每款、每批为节奏，不同文档对应专属字段，比如工艺单包含工序要求与公差范围，包装配码单关联订单尺码配比与装箱规则，裁片数据无修改空间，需严格匹配原始版型要求。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据按订单、款式、批次更新，工具调用需绑定单次任务的专属订单上下文，避免跨批次数据混淆。裁片不可逆且字段关联紧密，插件需严格校验输入字段与对应工艺单、排料图的匹配性，防止参数偏差。多源数据来自车间设备与客户封样，插件需适配非标准化的设备导出格式，同时支持客户封样标准的实时调用。款式多且季节性强，工具调用需支持快速切换不同款的工艺规则与样板数据，减少重复配置流程。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 函数调用配置 | 开启 | 支持多工具并行调用，适配工序质量校验、裁片核对、包装配比检查等多环节需求 |
| 工具调用超时时间 | 120–180 秒 | 适配车间吊挂系统、验针机等设备的数据上传与工艺单检索的平均耗时，避免因设备延迟导致调用失败 |
| 输入字段校验规则 | 绑定对应订单的工艺单字段 | 确保裁片尺寸、面料批次等输入与工艺要求匹配，防止批量偏差 |
| 插件数据格式适配 | 支持CSV、JSON格式导入 | 适配吊挂系统、验针机导出的标准化设备数据格式 |
| 工作流/API 工具选择配置 | 限制为指定工具集合 | 仅开放与当前订单相关的检验工具，避免无关工具调用干扰流程 |
| 工具调用重试次数 | 2次 | 应对临时网络波动导致的调用失败，减少人工干预成本 |

## 容易做错的三处
- 调用工具时返回404状态码，原因是未正确配置工具的API地址与权限白名单，或工具依赖的服务未正常启动。
- 深度思考工具无法在聊天界面正常加载，原因是未在插件管理中开启对应工具的全局调用权限，或未绑定到当前应用的工具列表。
- BI图表插件返回的地址未替换为自定义域名，原因是未在插件配置的输出参数中修改返回地址的占位符，或未保存配置后发布应用。

## 怎么确认配好了
- 上传一份测试订单的工艺单与裁片数据，触发工具调用，检查是否返回与工艺要求匹配的校验结果。
- 查看插件日志，确认工具调用的超时时间、字段校验规则均已生效，无异常报错信息。
- 切换不同款式的订单数据，检查工具是否能自动适配对应款的工艺规则与样板数据。
- 测试BI图表插件的返回地址，确认已替换为自定义的有效域名。
