# 模具设计制造的检验与过程记录审核：HTTP 接口与外部系统

## 这个品类的数据长什么样
通常该类业务主体的日常文档包含模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历等。数据来源于客户产品模型、模流或成形仿真文件、CAD/CAM导出数据、机加工与测量记录、试模样件检测结果，更新节奏随单个模具项目推进，每次试模或改模后同步更新。数据包含设计参数、加工精度、试模缺陷记录等字段，无统一固定单位，随具体项目文档的要求调整。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
数据来源包含非结构化图纸、结构化检测记录等多类型内容，接口需兼容多格式的输入输出。更新无固定周期且随项目迭代，接口需支持按需触发，适配单次项目的增量数据同步。文档字段随项目灵活变化，接口参数需支持自定义映射，无需每次调整核心逻辑。数据体量随模具复杂度波动，接口需支持动态调整请求负载，避免传输超时。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 单次请求超时时间 | 600–1200 秒 | 适配模具项目文档的大小与传输耗时，避免大尺寸图纸传输中断 |
| `Authorization` | 按项目生成专属令牌 | 隔离不同模具项目的接口调用权限，防止数据越权访问 |
| `variables` | 绑定项目专属的文档字段映射规则 | 适配不同模具项目的自定义字段需求，无需每次调整接口逻辑 |
| 请求重试次数 | 3 次 | 抵消临时网络波动对接口调用的影响，保障试模数据的及时同步 |
| `responseData` | 仅返回校验通过的检验记录字段 | 过滤无效数据，减少外部系统的存储与处理压力 |
| 接口传输协议 | 强制启用HTTPS | 符合工业生产系统的安全规范，避免明文传输风险 |

## 容易做错的三处
- 接口调用返回401未授权错误，原因是未为每个模具项目配置专属的`Authorization`令牌，混用全局令牌导致权限校验失败。
- 外部系统接收的`responseData`字段缺失，原因是未配置响应数据过滤规则，返回了未校验的原始文档内容，超出外部系统的字段解析范围。
- 接口调用无法正常发起，原因是未启用HTTPS加密传输，仅使用默认的HTTP协议，无法通过工业生产系统的安全校验。

## 怎么确认配好了
- 提交单份试模报告的接口请求，确认`Authorization`校验通过，返回的`responseData`包含预期的检验记录字段。
- 上传符合项目标准格式的模具设计文档，确认接口能正确解析并返回校验结果。
- 切换至HTTPS协议发起调用，确认外部系统可正常接收加密后的接口响应。
- 模拟临时网络中断的场景，确认接口重试机制按配置触发，恢复后能正常完成调用。
