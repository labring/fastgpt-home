# 橡胶混炼与制品硫化的检验与过程记录审核：工作流编排

## 这个品类的数据长什么样
该品类数据来源于配方系统、原材料批次台账、密炼机、门尼粘度仪、流变仪、硫化机及实验室检测设备。日常文档包含配方单、称量记录、混炼曲线、胶料快检报告、硫化工艺卡、模具使用记录、成品性能报告。数据更新频率为每车胶料批次、每批原材料投料、每模次硫化流程完成时更新。数据字段包含混炼温度（摄氏度）、硫化时间（分钟）、门尼粘度值、批次编号等，不同来源数据格式差异较大，设备输出多为结构化日志，实验室报告多为半结构化文档。本页配置基于FastGPT v4.17.0版本。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的高频率更新要求工作流需按实时触发逻辑配置，避免定时轮询导致的数据延迟或遗漏。多源异构数据的接入需要工作流支持不同格式的解析节点，适配密炼机日志、实验室报告等不同文档类型。严重的出错后果要求工作流必须在投料、混炼、硫化三个核心环节前置校验节点，拦截配方错误、温度偏差等风险。同时，每模次的硫化数据需要单独关联对应批次的混炼记录，工作流需支持`variables`的批次绑定逻辑，避免数据串扰。此外，跨环节的节点联动需要明确`nodeId`的关联规则，确保各工序的校验结果能正确流转至下一环节。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `variables`映射规则 | 按批次编号绑定对应混炼、硫化数据 | 每车胶料对应唯一批次，需确保数据关联准确无串扰 |
| `nodeId`关联配置 | 按混炼→硫化→检验的工序顺序绑定节点ID | 核心工序需按流程串联，避免链路混乱导致校验失效 |
| 工作流触发时机 | 每车胶完成混炼后、每模次硫化完成后 | 匹配数据更新频率，确保校验实时覆盖每一批次与每一模次 |
| 校验节点阈值 | 混炼温度偏差±5摄氏度，硫化时间偏差±2分钟 | 贴合行业通用工艺参数范围，拦截不合格参数输入 |
| 失败重试次数 | 2–3 次 | 应对设备临时波动导致的校验失败，避免误触发告警 |
| 组件复制权限 | 开启`variables`批量导出功能 | 支持快速复用校验节点配置，提升多工作流编辑效率 |

## 容易做错的三处
- 现象：工具调用节点返回Invalid JSON: Bad control character错误，原因是未对混炼曲线、硫化工艺卡中的换行符、特殊符号做转义处理，导致JSON格式校验失败。
- 现象：选中工作流组件后无法拖拽复制或移动，原因是未开启工作流编辑页的`variables`批量编辑开关，导致组件属性无法被正常复制或移动。
- 现象：工作流节点间无法添加连接线，界面无连接圆圈出现，原因是未正确配置`nodeId`的关联规则，导致节点间的触发链路被系统阻断。

## 怎么确认配好了
- 导入一份真实的混炼曲线文档，触发工作流，检查校验节点是否正确提取配方编号、混炼温度等核心字段。
- 模拟一组超出阈值的硫化工艺数据，检查工作流是否触发失败告警节点并生成异常记录。
- 复制一个已配置的校验节点，粘贴到另一个工作流分支，检查组件的`variables`映射规则是否完整保留。
- 打开工具调用节点的高级设置，确认`nodeId`参数已正确配置，可正常查看关联节点信息。
