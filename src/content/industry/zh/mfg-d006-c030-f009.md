# 橡胶混炼与制品硫化的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源包括配方系统、原材料批次台账、密炼机运行日志、门尼粘度仪、流变仪、硫化机参数记录及实验室成品性能报告。更新节奏为每车原料批次、每批混炼胶料、每模次硫化制品。日常文档包含配方单（含投料比例与顺序）、称量记录、混炼曲线、胶料快检报告、硫化工艺卡、模具台账及成品性能检测单，字段多包含批次号、重量、温度、时间等，单位多为千克、摄氏度、分钟。

## 这些特征在「模型接入与配置」这一环带来什么约束
高频小批量的更新节奏要求模型能够快速处理单条或少量批次的审核任务，避免上下文堆积过长导致的处理延迟。多源异构的数据格式要求配置适配结构化的设备日志与半结构化的工艺文档，需明确字段提取的优先级。固定的单位与字段规则要求模型对工业参数的识别具备严谨性，避免单位或数值偏差。同时，单次审核的数据量不大但时效性强，需限制上下文长度以保证处理效率，避免资源浪费。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配混炼曲线、硫化工艺卡、称量记录等多文档拼接的上下文长度，避免截断关键工艺参数 |
| `maxTokens` | 2000 token | 匹配单条检验记录的审核输出长度，确保完整呈现偏差分析与整改建议 |
| `temperature` | 0.1–0.3 | 降低随机偏差，保证工艺参数审核的一致性，符合工业生产的严谨要求 |
| 工作流/API 工具选择配置 | `"auto"` | 让模型自主选择是否调用工具处理结构化工艺数据，适配多源文档的审核需求 |
| `AIPROXY_API_ENDPOINT` | `http://{本地模型IP}:{端口}/v1` | 对接本地部署的工业专用大模型或通用大模型的代理服务，适配企业内部部署场景 |
| `AIPROXY_API_TOKEN` | 按模型服务提供的密钥填写 | 完成代理服务的身份验证，确保请求合法有效 |

## 容易做错的三处
- 修改config.json后模型列表未更新，容器内查看/app/data/config目录配置未同步。原因：未重启FastGPT容器加载新配置，或配置文件路径填写错误。
- 模型流响应为空，审核结果无有效内容。原因：`AIPROXY_API_ENDPOINT`配置错误，或模型服务未正常返回流式数据，无法适配工业数据的格式要求。
- 审核结果出现参数单位偏差，如将“摄氏度”识别为“华氏度”。原因：`temperature`参数设置过高，导致模型对工业参数的严谨性判断不足，未匹配该品类的字段特征。

## 怎么确认配好了
- 登录FastGPT v4.17.0后台，进入模型管理页面，查看已配置的模型是否出现在可用列表中。
- 上传一条单批次的混炼记录与硫化工艺卡，发起审核测试，查看是否返回完整的审核结果与参数偏差分析。
- 进入FastGPT容器内部，查看/app/data/config目录下的配置文件，确认修改后的参数已同步更新。
- 测试流式响应功能，查看审核过程中是否有分段的结果返回，无空响应或长时间卡顿情况。
