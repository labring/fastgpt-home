# 汽车零部件批量制造的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
本品类的数据来自客户图纸与特殊特性清单、ERP/MES系统、量检具采集数据、设备过程参数、供应商质保书。日常文档包含控制计划、过程流程图、作业指导书、首件与巡检记录、SPC报表、PPAP资料、8D报告。数据更新节奏为每批、每班或持续采集，字段包含批次标识、检验结果数值、工艺参数阈值、客户特殊特性指标，单位随对应检测项而定。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类的数据来源分散且格式多样，包含结构化工艺参数、非结构化质量文档，需模型同时适配两类数据的解析规则。数据更新频率高，需配置支持增量同步的接入方式，避免重复处理历史数据。客户特殊特性需严格匹配，模型输出需关联对应文档片段，确保审核结果可追溯。同时，因出错后果涉及批量不良、客户停线，接入环节需预留异常拦截节点，防止错误配置导致无效审核。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配批量制造场景下多文档拼接的上下文需求，覆盖控制计划、SPC报表等核心文档的总长度 |
| `maxTokens` | 2000–3000 token | 限制单轮审核输出长度，确保结果符合质量体系文档的格式要求，避免过长内容无法匹配客户审核规则 |
| `quoteMaxToken` | 1500 token | 限定引用源文档的片段长度，确保引用内容准确对应工序参数或检验记录，避免冗余片段干扰审核判断 |
| `temperature` | 0.1–0.3 | 降低随机输出概率，确保审核结果严格匹配客户特殊特性与工艺要求，避免出现不符合质量规范的判断 |
| `AIPROXY_API_ENDPOINT` | 按企业部署环境填写对应地址 | 适配企业内部网络环境，确保模型调用链路符合汽车零部件行业的信息安全要求 |
| `AIPROXY_API_TOKEN` | 绑定专属权限的令牌 | 限制仅授权的审核流程可调用模型，防止未授权访问导致的质量数据泄露 |

## 容易做错的三处
- 现象：调用模型时返回`该令牌无权使用模型：text-embedding-3-large`报错。原因：未为`AIPROXY_API_TOKEN`绑定对应模型的使用权限，或令牌配置错误。
- 现象：审核任务超时，返回连接失败状态。原因：`AIPROXY_API_ENDPOINT`配置为外部公开地址，未适配企业内部网络的访问限制，导致链路中断。
- 现象：输出的审核结果未关联源文档片段。原因：`quoteMaxToken`配置值过小，导致无法提取足够的源文档内容用于引用，或未配置关联引用的开关。

## 怎么确认配好了
本核对流程基于FastGPT v4.17.0版本。
- 检查`AIPROXY_API_TOKEN`的权限配置，确认绑定的模型与当前使用的审核任务匹配。
- 提交单批次的检验记录与工艺文档，验证输出结果的上下文长度未超过`maxContext`的配置值。
- 查看审核结果的引用片段，确认`quoteMaxToken`的配置值适配源文档的片段提取需求。
- 运行测试任务，确认输出结果的随机性符合`temperature`的配置区间，无偏离工艺要求的判断。
