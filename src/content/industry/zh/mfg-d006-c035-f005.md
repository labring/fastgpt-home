# 热处理的检验与过程记录审核：工具调用与插件

## 这个品类的数据长什么样
热处理场景的数据来自材料牌号档案、客户技术条件、温控仪表、炉温均匀性测试设备、硬度计、金相分析仪与生产制造执行系统。数据按每炉次、每批更新，核心文档包含热处理工艺卡、装炉图、炉温曲线、硬度与金相报告、设备点检表、异常处置单。字段包含炉号、零件批次号、加热温度（单位为摄氏度）、保温时长、冷却速率、硬度值（单位为HRC或HV）等，部分文档为图表格式，需插件支持多类型数据解析。

## 这些特征在「工具调用与插件」这一环带来什么约束
每炉次每批的更新节奏要求工具调用需按批次触发，避免无区分的批量调用导致数据混乱。多源异构的数据来源与混合格式文档，要求插件需支持结构化参数校验与非结构化图表解析。固定的字段单位要求工具调用时需对温度、硬度等指标做格式与单位校验，防止无效数据流入。严重的出错后果要求插件调用后需输出校验结果，便于后续异常处置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 自动匹配适配热处理检验的专用插件，减少手动配置成本 |
| `functionCall` | `enabled` | 支持结构化工艺参数的精准调用，适配字段校验需求 |
| 单次调用文档上限 | `1-3 份/次` | 避免单批次数据过载导致请求超时 |
| 超时时间 | `240 秒` | 适配炉温曲线、硬度报告的拉取与解析耗时 |
| 触发时机 | 按炉次批次触发 | 匹配热处理每炉次、每批的更新频率 |
| 参数校验开关 | 开启 | 校验温度、硬度等指标的单位与格式合规性 |

## 容易做错的三处
- 现象：调用钉钉机器人插件时返回未授权报错，原因：未在FastGPT插件配置中绑定正确的机器人密钥与会话权限。
- 现象：长文档（如完整炉温曲线）调用校验工具时结果异常，原因：未针对长文档配置合理的分段规则，导致上下文溢出导致校验偏差。
- 现象：定时执行的检验工具未在列表中显示，原因：未开启定时任务的插件权限开关，或未配置触发的时间周期规则。

## 怎么确认配好了
- 发起单炉次的检验请求，查看插件是否正确拉取对应炉号的工艺卡与炉温曲线数据。
- 触发工具调用后，检查返回结果中是否包含硬度、金相报告的校验字段，且单位符合业务要求。
- 模拟温度超出工艺范围的异常场景，确认插件是否触发异常处置提示。
- 查看FastGPT v4.17.0的插件调用日志，确认超时时间、调用次数符合配置的取值。
