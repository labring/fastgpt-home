# 热处理的检验与过程记录审核：部署与升级

## 这个品类的数据长什么样
该品类的数据覆盖热处理全流程的多类型文档，包括热处理工艺卡、装炉图、炉温曲线、硬度与金相报告、设备点检表、异常处置单。数据来源涵盖材料牌号、客户技术条件、温控仪表、炉温均匀性测试设备、硬度计与金相设备，以及车间MES系统。数据更新频率为每炉次、每批，单炉次产生的文档包含炉温（℃）、保温时间（小时）、硬度值（HV）、金相组织等级等带明确单位的字段，不同文档的结构差异明显，部分为结构化仪表数据，部分为非结构化报告与图像。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据高频更新、多源异构且关联严格的工艺参数，要求部署环节适配高并发小批量写入需求，同时支持多格式文件的存储与检索。由于部分热处理车间部署离线服务器，升级环节需兼容离线运行环境，避免依赖公网资源。数据字段与单位的特异性要求配置环节支持自定义元数据映射，确保检验与审核流程能准确匹配业务字段。同时，检验结果直接关联产品性能，部署后需配置数据校验规则，避免错误数据流入审核流程。

## 配置怎么定
以下配置适配FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150 个` | 适配每炉次多文档并发写入与查询的需求，避免数据库连接超限 |
| `REDIS_URL` | `redis://:自定义密码@内网IP:6379/0` | 缓存会话数据与临时检验文档，适配批量处理的节奏 |
| `STORAGE_S3_ENDPOINT` | `内网MinIO地址或公网OSS端点` | 存储炉温曲线、金相报告等多格式大文件，适配离线或云端部署场景 |
| `FE_DOMAIN` | `热处理车间内部域名或备案公网域名` | 配置HTTPS访问路径，适配本地或远程运维需求 |
| `MONGODB_URI` | `mongodb://用户名:密码@内网IP:27017/fastgpt?authSource=admin` | 存储检验记录与审核日志，支持高频写入与查询 |
| `FILE_TOKEN_KEY` | `随机生成的32位字符串` | 加密文件访问令牌，保障检验文档的访问安全 |

## 容易做错的三处
- 访问FastGPT界面提示证书不安全，无法建立HTTPS连接。原因是未将mkcert生成的证书挂载到对应服务容器，未将证书路径与`FE_DOMAIN`的配置关联。
- 离线服务器部署时AI proxy报错`get tiktoken dial tcp lookup`。原因是离线环境未配置本地tokenizer缓存，或未指定离线模型路径，导致程序尝试联网获取资源失败。
- 阿里云部署后提交审核流程无响应，返回状态码500。原因是`MONGODB_URI`或`REDIS_URL`中的权限配置错误，未开放对应端口的内网访问权限。

## 怎么确认配好了
- 登录FastGPT后台的系统监控页面，查看数据库连接数，确认未触发`DB_MAX_LINK`配置的连接超限告警。
- 上传一份热处理炉温曲线PDF文件，验证文件可正常存储与预览，确认`STORAGE_S3_ENDPOINT`配置生效。
- 发起一次单炉次的检验记录审核流程，查看会话日志，确认`REDIS_URL`的缓存读写无异常。
- 访问`FE_DOMAIN`对应的访问地址，确认浏览器提示HTTPS连接安全，无证书警告。
