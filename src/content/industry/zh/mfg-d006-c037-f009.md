# 生产计划与车间排程的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源涵盖ERP订单与库存、BOM、工艺路线、设备产能、人员班次、在制品及供应商到货信息。日常处理的文档包含销售订单、主生产计划、物料需求计划、周日排产表、工单、缺料清单、交期变更单，各文档包含订单号、物料编码、产能数值、班次时长、工单数量等字段，单位涉及件、小时、天等。数据更新频率包含每日、每周，以及订单或异常发生时的实时更新。

## 这些特征在「模型接入与配置」这一环带来什么约束
多来源、多更新节奏的数据要求模型接入时需适配不同的同步频率，避免因数据滞后导致审核结果偏差。多样的文档结构与字段类型，要求配置需支持识别不同格式的业务字段，例如数值型的产能数据与文本型的交期说明。高频的异常更新（如插单、缺料）要求配置具备快速响应能力，同时需控制上下文长度以避免冗余数据干扰审核逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 该品类需覆盖至少3天的排程数据与关联订单，此范围可完整承载核心审核上下文 |
| `maxTokens` | 4000–6000 token | 需生成完整的排程调整建议与审核结论，此范围可平衡输出长度与内容完整性 |
| `quoteMaxToken` | 2000–3000 token | 需引用工单、缺料清单等核心文档片段，此范围可保留足够的原文细节 |
| `toolChoice` | auto | 需根据审核场景自动选择调用工具或直接生成结果，适配排程调整、缺料审核等不同任务 |
| `temperature` | 0.2–0.4 | 审核场景需保持结果严谨，此取值区间可避免泛化偏差，确保审核结论符合业务规则 |
| `AIPROXY_API_ENDPOINT` | 平台提供的专属代理端点 | 保障模型调用的稳定性与安全性，适配国内与国际模型渠道的接入需求 |
| `AIPROXY_API_TOKEN` | 与端点绑定的专属密钥 | 验证调用身份，防止未授权的模型访问 |

## 容易做错的三处
- 现象：调用指定模型时返回授权错误，无法正常完成审核任务。原因：未正确配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或使用了不匹配的代理渠道。
- 现象：知识库内无对应排程数据时，模型直接拒绝生成推理结果。原因：未调整上下文配置或未开启合理的泛化逻辑，误将搜索匹配设为强制依赖。
- 现象：调用工具处理排程调整时返回超时错误。原因：未设置合理的`maxTokens`限制，导致工具调用耗时过长超出系统阈值。

## 怎么确认配好了
- 确认当前使用的FastGPT版本为v4.17.0，确保配置项与界面匹配。
- 提交测试用的工单与缺料清单数据，检查模型返回的审核结果是否包含对应文档的引用片段。
- 模拟插单或设备故障场景，验证模型是否能基于实时更新的产能与库存数据生成调整后的审核建议。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的请求状态码为200，无授权或连接错误。
