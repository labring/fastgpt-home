# 生物制品与无菌生产的检验与过程记录审核：多轮对话与提示词

## 这个品类的数据长什么样
生物制品与无菌生产的检验与过程记录数据来源包括细胞库与种子批、过程分析、洁净区监测、MES、LIMS、设备完整性测试。数据更新节奏分为每批、实时、按监测计划三类，对应不同的业务文档类型。日常文档包含细胞库或种子批记录、培养纯化记录、无菌灌装记录、环境监测、培养基模拟灌装、无菌检验、批放行资料，各文档包含批次标识、培养温度、沉降菌菌落数、灌装时间戳等专属字段，单位涵盖摄氏度、菌落形成单位/皿、秒等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
该品类的数据来源分散且覆盖多系统，多轮对话需要逐步调取不同模块的记录，避免一次性加载过多无关数据。不同更新频率的要求意味着对话上下文需要动态同步最新的实时监测数据与当批的静态记录。复杂的文档结构与专属字段要求提示词必须精准指定可调用的文档范围与字段规则，防止模型混淆不同批次的内容。同时，无菌生产的严格风险要求对话输出必须严格基于给定的业务文档，不得生成无依据的审核结论。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chatId` | 绑定当前生产批次的唯一标识 | 确保多轮对话上下文始终关联同一批次的所有检验与过程记录，避免跨批次数据混淆 |
| `messages` | 保留近3轮对话与前20000字符的历史数据 | 覆盖单批生产从培养到放行的完整过程记录，防止关键审核信息被截断 |
| `variables` | 引入当前批次的LIMS预设数据快照 | 让模型直接调用已归档的批次专属数据，减少重复的系统查询操作 |
| 最大响应token数 | 按实测标定，不超过8192 token | 适配长文本的检验与放行记录审核需求，避免关键字段被截断 |
| 上下文召回上限 | 前6条匹配的过程文档 | 聚焦当前批次的核心审核依据，避免无关历史数据干扰模型判断 |

## 容易做错的三处
-  配置变量引用时未找到设置按钮，无法调整模型温度参数。原因是未在对话组件的变量绑定面板中开启高级参数配置入口，基础模式下无温度调整选项。
-  单轮对话回传耗时超过600秒，但模型调用分组仅显示1分组。原因是对话上下文绑定了过多跨批次的历史数据，导致模型加载的文档量超出单次处理阈值，触发队列排队。
-  配置数据库连接插件后调用报错，且无法限定搜索指定集合。原因是未将LIMS或MES的数据库访问权限配置为仅允许读取当前批次的限定数据，且未在提示词中约束插件仅调取指定集合的记录。

## 怎么确认配好了
-  发起测试对话，输入“调取当前批次的无菌灌装记录”，核对返回结果中仅包含当前绑定`chatId`对应的批次数据。
-  调整变量引用的参数，确认可以在对话中直接调用预设的LIMS字段值，无需手动输入批次标识。
-  触发数据库连接插件，检查返回的记录集合仅包含指定的洁净区监测或过程分析数据，匹配知识库搜索指定集合的要求。
-  查看对话耗时日志，确认单轮响应耗时符合预设的安全范围，无长时间排队情况。
