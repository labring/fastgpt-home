# 生物制品与无菌生产的检验与过程记录审核：知识库检索与召回

本页面基于FastGPT v4.17.0版本编写，针对生物制品与无菌生产的检验与过程记录审核场景，梳理知识库检索与召回的配置、约束与落地要点。

## 这个品类的数据长什么样
本品类的核心数据涵盖细胞库与种子批记录、培养纯化记录、无菌灌装记录、环境监测数据、培养基模拟灌装结果、无菌检验报告及批放行资料。数据来源包括细胞库与种子批系统、过程分析设备、洁净区监测系统、MES、LIMS及设备完整性测试工具。更新节奏分为三类：每批生成的批记录、实时上传的洁净区监测与过程参数、按固定监测计划更新的设备完整性数据。文档包含结构化字段，如批次号、培养温度（℃）、灌装时间、沉降菌浓度（cfu/㎡），以及非结构化的过程描述文本。

## 这些特征在「知识库检索与召回」这一环带来什么约束
本品类的数据特征对检索召回环节带来多重约束。多源异构的数据来源要求检索系统同时支持结构化字段匹配与非结构化文本语义检索，覆盖不同类型的审核需求。实时与按批次的混合更新节奏，需要系统支持增量索引与全量索引结合，确保新生成的批记录与实时监测数据能快速被检索到。文档的高风险属性，要求召回结果需具备高精准度，避免无关数据干扰审核流程。同时，批记录的隔离性要求检索范围需限定在对应生产批次的数据集内，防止跨批次数据混淆。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，适配生物制品与无菌生产的审核场景需求。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配无菌生产过程参数的精准性要求，避免误召回无关批记录 |
| `limit` | 前8条 | 平衡上下文长度与信息完整性，适配批放行审核的多维度数据需求 |
| `searchMode` | `mixedRecall` | 同时支持结构化字段匹配与非结构化文本语义检索，覆盖不同类型的审核文档 |
| `usingReRank` | 开启 | 对初始召回结果重排序，提升高风险过程记录的召回优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展审核相关的专业术语，覆盖“无菌边界”“培养基模拟灌装”等场景表述 |
| `collectionIds` | 按生产批次绑定的数据集ID | 限定检索范围，避免跨批次数据干扰，符合批记录隔离要求 |

## 容易做错的三处
- 现象：使用`bge-m3`向量模型时，语义检索得分异常偏高，导致召回大量无关的历史批记录。原因：未针对生物制品专业文本调整匹配阈值，或未启用专业领域的文本预处理流程。
- 现象：知识库内的工艺流程图、洁净区布局图无法正常显示，审核时无法直观查看相关内容。原因：未正确配置图片资源的上传格式与外链托管规则，导致检索时无法关联图片资源。
- 现象：检索请求返回结果条数不足，无法覆盖审核所需的全部过程数据。原因：未正确设置`limit`参数，或未将相关数据集加入`collectionIds`范围，导致检索范围受限。

## 怎么确认配好了
- 上传一批模拟的细胞库记录与无菌检验报告，执行检索操作，验证召回结果包含对应批次的关键参数与过程描述。
- 查看系统检索日志，确认`usingReRank`功能生效，高置信度的过程记录排在检索结果前列。
- 测试增量更新功能，上传新的培养基模拟灌装记录，验证检索结果实时包含新增的数据内容。
- 检查权限配置，确认不同审核角色只能检索对应`collectionIds`绑定的生产批次数据集。
