# 电机与发电机制造的检验与过程记录审核：向量模型与索引

## 这个品类的数据长什么样
本品类的日常文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试报告、型式与出厂试验报告。数据来源涵盖电磁设计数据、铜线和绝缘材料批次信息、绕线设备、平衡机、电气试验台及ERP/MES系统。数据更新频率为每台或每批产品产出一次，每次型式变更也会触发新的数据生成。文档包含工艺参数、试验数值、批次标识等字段，字段单位随类型对应调整。

## 这些特征在「向量模型与索引」这一环带来什么约束
多类型文档与混合字段的特征，要求向量模型同时支持文本与数值类数据的嵌入，避免单一模型无法覆盖全量业务数据。高频率的批次化更新，要求索引系统支持增量更新与批次关联管理，减少全量索引的资源消耗。检验环节对异常数据的识别精度要求高，要求相似度阈值需结合业务场景实测标定，避免误匹配或漏检。跨环节的文档关联需求，要求分块时保留上下文关联，避免拆分关键工艺与试验数据的对应关系。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 匹配绕组工艺卡、试验报告的单段有效信息长度，避免跨关键字段拆分 |
| 重叠长度 | 100–150 字符 | 保留绕组匝数、接线方式等跨块关联的工艺信息，提升检索匹配度 |
| `maxToken` | 8192 token | 适配FastGPT v4.17.0的多模态向量模型输入上限，覆盖耐压测试报告的长文本内容 |
| 相似度阈值 | 0.72–0.80 | 贴合电机制造检验的高置信度要求，避免误匹配异常试验数据 |
| 单次搜索上限 | 前 8 条 | 覆盖试验报告的多维度关联特征，提供足够的参考分析样本 |
| 最大上下文 | 30000 字符 | 满足整合多份型式试验报告的完整分析需求 |

## 容易做错的三处
- 现象：界面提示向量模型调用失败，返回状态码400。原因：未正确区分通用文本向量与多模态向量的配置参数，误用通用文本向量处理包含试验数值的文档。
- 现象：检索结果为空或条数远低于预期。原因：分块长度设置过大，导致绕组匝数、耐压值等关键参数被截断，无法形成有效匹配特征。
- 现象：索引更新耗时超出预期。原因：未开启增量索引模式，每次更新都处理全批次的电机制造数据，占用过多计算资源。

## 怎么确认配好了
- 上传一份包含绕组工艺卡与耐压测试报告的混合文档，查看分块预览界面是否保留了完整的匝数、绝缘电阻值等关键字段。
- 输入「绕组匝数核对」的检索词，查看返回结果的相似度评分是否处于预设的阈值区间内。
- 提交一份新的动平衡报告，检查索引任务是否在10分钟内完成数据更新。
- 验证向量模型的调用日志，确认返回的向量维度与所选模型的标准参数一致。
