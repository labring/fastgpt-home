# 电机与发电机制造的检验与过程记录审核：工作流编排

## 这个品类的数据长什么样
电机与发电机制造的检验与过程记录数据来源包括电磁设计数据、铜线和绝缘材料批次信息、绕线设备运行数据、平衡机检测数据、电气试验台测试结果，以及ERP/MES系统的生产工单数据。数据更新频率为每台或每批产品一次，每次型式变更时同步更新。日常文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试报告、型式与出厂试验报告，核心字段包括绕组匝数、绝缘等级、振动幅值、温升数值、试验电压等。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的多源异构数据来源要求工作流需支持对接多类设备接口与系统数据源，避免数据孤岛。按批次或单台更新的节奏，要求工作流支持按生产工单触发，适配批量与单件生产场景。核心文档的多字段校验需求，要求工作流内置字段完整性校验规则，确保绕组匝数、绝缘参数等关键信息无缺失。同时，高压与温升试验的异常结果需快速触发分支处理，且需解决检验记录审核中的指代消除问题，避免模糊表述导致的结果偏差。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `variables` | 绑定批次号、设备ID、试验编号 | 电机制造每台/每批有唯一标识，需跨节点传递避免混淆 |
| 问题优化 | 启用，关联历史3轮会话记录 | 解决检验记录审核中的指代消除问题，解析模糊表述 |
| 节点触发规则 | 按`nodeId`绑定的试验节点完成状态触发 | 适配绕线、绝缘、试验等工序的顺序执行逻辑 |
| 上下文窗口 | 前2000 token | 覆盖绕组工艺卡、试验报告等多字段的校验需求 |
| 重试阈值 | 3次 | 应对设备数据临时异常的场景，减少误判 |
| 超时设置 | 600秒 | 适配高压、温升试验的较长耗时场景 |

## 容易做错的三处
- 现象：工作流最终输出包含中间AI对话节点的结果。原因：未配置中间节点的输出隐藏规则，导致节点结果被纳入全局输出链路。
- 现象：知识库搜索返回无关结果，无法解决指代消除问题。原因：未启用问题优化配置，未关联历史会话记录，导致模糊表述无法被正确解析。
- 现象：工作流启动失败，提示缺少必要参数。原因：未提前配置`variables`全局变量，导致跨节点传递的批次号、设备ID等字段为空。

## 怎么确认配好了
- 触发单台电机的检验工作流，检查全局变量是否自动绑定了对应批次号、设备ID与试验编号。
- 输入指代模糊的问题，例如“这个绕组的匝数是否符合要求”，确认系统能关联历史会话中的绕组信息并返回正确校验结果。
- 暂停中间AI对话节点后触发工作流，确认最终输出内容不包含中间节点的对话结果。
- 模拟设备数据临时异常的场景，确认工作流触发重试机制，达到重试阈值后触发异常处理分支。
