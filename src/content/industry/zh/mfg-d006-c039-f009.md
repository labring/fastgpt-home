# 电机与发电机制造的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类数据来自电磁设计数据库、铜线与绝缘材料批次台账、绕线机/平衡机/电气试验台的实时采集数据，以及ERP/MES系统的生产工单。数据更新频率为每台成品或每批次工件，每次产品型式变更时同步更新。日常文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试报告、型式与出厂试验报告，字段包含绕组匝数、绝缘层厚度、动平衡余量、试验电压值，附带设备编号、生产批次号与试验日期。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的多源异构数据与高频更新特性，要求模型接入环节需适配多格式文档解析与字段识别。绕组匝数、耐压值等强校验字段存在严格数值范围，需模型能精准匹配文档字段与业务规则。每台/每批次的独立数据特征，要求上下文窗口需支持单批次文档的完整加载，同时需控制单轮推理的资源占用，避免因多源数据叠加导致显存溢出。此外，高压试验数值的精度要求，需模型具备稳定的数值提取与校验能力，适配不同硬件资源的部署场景。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单批次电机试验报告与工艺卡的总文本长度，避免截断核心校验字段 |
| `maxTokens` | 2000–3000 token | 控制单轮推理输出长度，适配绕组校验、异常分析的结果输出需求 |
| `quoteMaxToken` | 1500–2000 字符 | 限定引用文档的单段长度，确保关键数据如耐压值、动平衡数值完整被模型读取 |
| `temperature` | 0.1–0.3 | 降低随机输出概率，保障绕组匝数、绝缘参数等校验结果的一致性 |
| `AIPROXY_API_ENDPOINT` | 按部署集群的实际接入地址填写 | 适配多显卡部署的API转发配置，实现显存资源的合理分配 |
| `toolChoice` | auto | 允许模型自动选择校验工具，适配多类型文档的字段提取与异常分析需求 |

## 容易做错的三处
- 现象：rerank模型运行后显存占用持续攀升直至溢出，显存资源未被自动释放。原因：未配置显存自动回收策略，且未限制rerank模型的并发调用数量。
- 现象：工作流内的文本提取节点无法选择可用模型，下拉菜单为空。原因：未在系统配置中绑定对应文本提取模型的API密钥与接入地址，或模型类型与节点要求不匹配。
- 现象：Ollama挂载的模型输出结果与知识库内容无关，或多显卡部署时第二张显卡未被调用。原因：未正确配置模型的上下文窗口参数，导致关键文档内容被截断，或未启用多显卡调度的API转发逻辑。

## 怎么确认配好了
- 登录FastGPT v4.17.0后台，核对模型接入的API密钥与接入地址配置，确保与部署环境参数匹配。
- 上传单份电机耐压测试报告，触发模型校验流程，检查输出结果是否包含完整的字段提取与校验结论。
- 启动多批次数据并行推理任务，监控显卡资源占用情况，确认显存占用控制在合理区间内。
- 测试Ollama挂载模型的交互流程，确认输出结果与上传的电机生产文档存在逻辑关联。
