# 电机与发电机制造的检验与过程记录审核：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自电磁设计数据库、铜线与绝缘材料批次台账、绕线设备运行日志、平衡机检测数据、电气试验台报告及ERP/MES系统。日常产出文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试记录、型式与出厂试验报告。数据按每台电机、每批生产批次更新，每次产品型式变更后同步更新。文档字段包含绕组匝数、绝缘层厚度、试验电压值、温升数值等，对应单位为匝、毫米、千伏、摄氏度。

## 这些特征在「知识库检索与召回」这一环带来什么约束
由于数据按单台/单批生产更新且随型式变更同步刷新，知识库召回需优先匹配最新批次的物料、设备与试验数据，避免使用过期工艺或测试参数。品类文档涵盖工艺卡、试验报告等多类型专业文档，且包含电磁、绝缘、机械平衡三类专业字段，检索需支持跨文档类型的精准字段匹配。同时，数据来源覆盖设备日志与管理系统，不同来源的字段格式存在差异，召回前需完成统一的字段标准化处理，确保检索结果可直接用于审核环节。审核环节对结果准确性要求极高，误召回的低相关文档可能导致检验出错，引发绕组烧毁、绝缘击穿等问题。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配电机制造专业术语的精准度要求，过滤低相关的通用工艺内容 |
| `limit` | 前10条 | 覆盖绕组匝数、绝缘参数、试验数据等多维度审核所需的参考文档 |
| `searchMode` | `fullTextRecall` | 查询示例侧重标识符或专业术语；请用代表性数据实测该模式，不将其视为产品默认值。 |
| `usingReRank` | 开启 | 对召回的试验报告、工艺卡结果按审核场景重新排序，优先展示动平衡、耐压测试相关内容 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充专业术语扩展，比如将“绕组匝数”扩展为“线圈匝数”“定子绕组匝数”，覆盖不同表述的文档 |
| `collectionIds` | 按生产部门绑定对应知识库 | 区分绕线、绝缘、试验等部门的专属文档，避免跨部门数据混淆 |

## 容易做错的三处
- 出现Query read timeout报错。原因是未针对电机制造的长文档（如型式试验报告）调整检索超时设置，导致大体积文档加载超时。
- 传入知识库ID后无搜索结果。原因是绑定的`collectionIds`配置未关联对应绕线、试验部门的知识库，或`searchMode`设置为模糊匹配导致专业字段无法命中。
- 调用apiCollection接口返回Invalid URL, code: 500。原因是知识库文件上传时未使用正确的接口路径，或上传的文档格式无法被解析，导致接口调用失败。

## 怎么确认配好了
- 检索绕组匝数相关内容，核对召回结果是否包含最新批次的铜线绝缘材料参数。
- 触发知识库检索后，查看返回结果的排序是否优先展示动平衡、耐压测试相关的试验报告。
- 调用外部接口传入正确的`collectionIds`，验证是否能获取到对应部门的文档数据。
- 模拟超时场景，确认检索请求在合理时长内返回结果，无Query read timeout报错。
