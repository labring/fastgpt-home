# 电池PACK与储能系统集成的检验与过程记录审核：工作流编排

## 这个品类的数据长什么样
动力电池包、储能柜和BMS系统制造商的日常数据涵盖配组规则、BOM、焊接和扭矩记录、BMS刷写记录、绝缘耐压报告、EOL测试、系统配置清单。数据来源包括电芯分容数据、MES系统、焊接设备、扭矩工具、BMS软件版本记录、EOL试验台。数据更新频率为每包或每柜生成一次，每次BMS软件版本变更时同步更新。数据字段包含电芯档级、额定容量、扭矩值、刷写版本号、绝缘耐压值等，部分字段带有对应物理单位，如扭矩值以N·m为单位。

## 这些特征在「工作流编排」这一环带来什么约束
FastGPT v4.17.0版本支持多源数据节点的绑定与`variables`规则配置，可适配品类数据的整合需求。品类数据来源分散且更新频率高，要求工作流需配置多源数据拉取节点，按`variables`定义的字段映射规则整合不同数据源的信息。日常文档类型多且字段结构差异大，要求工作流需按文档类型分别配置`variables`提取模板，确保关键词变量精准提取。出错后果涉及系统安全与停机风险，要求工作流需添加关键字段校验节点，对绝缘耐压值、BMS配置参数等核心数据进行合法性校验，失败时触发告警。单批次数据的处理时效需匹配更新频率，要求工作流单次执行时长控制在300秒以内。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables`配置 | 按文档类型分模板：配组规则提取电芯档级、额定容量；扭矩记录提取扭矩值（20–50 N·m）、拧紧时长（5–10秒）；BMS刷写记录提取版本号、刷写结果 | 匹配品类日常文档的字段结构，精准提取关键词变量 |
| `nodeId`绑定 | 按数据源类型绑定对应`nodeId`：焊接设备节点绑定专属`nodeId`、MES系统节点绑定专属`nodeId` | 确保工作流能精准拉取对应数据源的最新数据 |
| 工具调用触发条件 | 按关键字段校验结果触发，仅当绝缘耐压值≥1000V、扭矩值符合20–50 N·m范围时调用MCP工具 | 避免无效工具调用，降低出错风险 |
| 全局变量传递配置 | 传递工作流生成的token至MCP工具节点，设置传递范围为当前工作流实例 | 解决全局变量跨模块使用的问题，适配工具调用需求 |
| 自动校验节点配置 | 对每包/每柜的EOL测试结果、BMS配置参数设置校验规则，失败时触发告警 | 符合品类数据更新频率，确保每批次数据的合法性 |

## 容易做错的三处
- 现象：提取的变量字段为空，比如配组规则中的电芯档级未被正确识别，或扭矩记录的扭矩值未被提取。原因：未按品类文档的字段结构配置`variables`提取规则，仅使用通用模板匹配。
- 现象：MCP工具节点无法获取工作流中的全局变量token。原因：全局变量传递范围未设置为当前工作流实例，导致变量仅在全局生效无法跨模块传递。
- 现象：工作流未按规则触发工具调用，直接执行所有预设节点。原因：未配置工具调用的触发逻辑，未绑定校验节点的输出结果作为触发依据。

## 怎么确认配好了
- 上传单批次PACK的配组规则、扭矩记录文档，运行工作流，核对提取的`variables`是否与文档中的对应字段一致。
- 触发工作流并生成全局变量token，查看MCP工具节点是否成功接收该token，确认传递配置生效。
- 模拟关键字段校验失败的场景，查看工作流是否触发告警，确认校验节点配置生效。
- 调整工具调用触发条件，验证仅在符合规则时才调用工具，确认触发逻辑正确。
