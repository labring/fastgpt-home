# 精细化工间歇合成的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类的业务数据来自配方与工艺库、原料批次台账、反应釜DCS系统、称量记录系统、LIMS实验室管理系统与仓储系统。数据按每批生产、每个关键工艺步骤更新，涵盖批生产指令、投料复核单、反应过程记录、清场记录、检验报告、偏差与变更单等文档。单份文档包含投料量、反应温度、时长、清场检查项、偏差描述等字段，字段多关联具体批次与设备编号，单位涉及千克、升、摄氏度、小时等。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类多批次、多步骤的文档结构，要求模型接入时需适配较长的上下文长度，避免截断关键工艺与检验数据。多源异构的数据来源，要求配置环节需兼容不同系统导出的文档格式，统一字段映射规则。高更新频率要求配置的模型服务具备稳定的响应速度，避免因数据同步延迟导致审核滞后。专业字段与特定单位的存在，要求配置时需选择适配精细化工专业术语的模型，减少字段识别误差。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单批次多步骤文档的总长度，避免截断关键工艺与检验数据 |
| `maxTokens` | 2000–3000 token | 控制单轮审核的输出长度，确保偏差判断与合规提示完整 |
| `quoteMaxToken` | 1500 token | 限定引用源文档的最大长度，保证审核依据清晰且不冗余 |
| `temperature` | 0.1–0.3 | 降低输出随机性，确保专业判断的一致性，符合工业审核的严谨要求 |
| `AIPROXY_API_ENDPOINT` | 填写本地部署的Xinference reranker模型接口地址 | 适配本地部署的模型服务，满足数据隐私与响应速度需求 |
| `AIPROXY_API_TOKEN` | 填写本地部署模型的安全凭证 | 完成模型服务的身份验证，避免未授权访问 |

本配置指南基于FastGPT v4.17.0版本编写。

## 容易做错的三处
- 现象：本地通过docker-compose部署的reranker模型，在FastGPT平台中未显示可用模型列表。原因：未正确配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或接口地址未开放跨域访问权限。
- 现象：配置了v2版本模型并在FastGPT中选择对应名称，但实际调用的仍是v1版本模型。原因：模型接口地址指向了旧版本服务，或凭证绑定的模型版本未更新。
- 现象：调用reranker模型时返回401未授权错误。原因：未正确补全Bearer前缀的安全凭证，或凭证已过期失效。

## 怎么确认配好了
- 测试接入本地部署的模型服务，查看平台返回的模型列表是否包含目标reranker模型，核对接口地址与凭证是否匹配配置项。
- 上传单份典型的投料复核单与反应过程记录，触发审核流程，检查输出结果是否引用了正确的源文档片段。
- 调整`temperature`参数值，观察两次审核输出的偏差判断结果是否保持一致，验证参数配置生效。
- 模拟高频率提交多批次文档，检查模型服务的响应时长是否符合预期，确认无超时报错。
