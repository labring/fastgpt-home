# 纸浆造纸的检验与过程记录审核：向量模型与索引

本页面适配 FastGPT v4.17.0 版本

## 这个品类的数据长什么样
该品类的数据主要来自木浆废纸批次台账、DCS与QCS控制系统、纸机在线测量设备、实验室检测系统、能源与水处理系统。日常生成的文档包括配浆单、打浆记录、纸机运行记录、在线质量曲线、实验室报告、断纸与换品记录。数据更新节奏覆盖实时、每班、每卷三个维度，单条记录包含浆料组分、打浆参数、纸机运行参数、质量检测指标、异常事件标识等字段，部分关联数据带有时间戳与批次编号字段。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据特征对向量模型与索引环节带来多重约束。异构数据源产生的结构化参数、曲线类时序数据与文本记录，要求索引支持混合类型向量的统一存储与检索。多更新节奏的并发写入需求，需要索引的增量更新机制适配实时、每班、每卷的不同写入频率。单卷纸对应的全流程记录数据量较大，需结合模型输入限制调整分块逻辑，避免向量维度超限。同时，断纸、换品等低频异常记录的高召回需求，要求索引保留批次、时间戳等元数据字段用于精准过滤。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配纸机运行记录与实验室报告的单段文本长度，避免分块过碎或过长 |
| 重叠长度 | 100–150 字符 | 保留跨分块的上下文关联，适配打浆记录的连续流程描述 |
| 相似度阈值 | 0.75–0.85 | 匹配纸浆质量指标的波动范围，避免误匹配或漏检合格批次 |
| 单次搜索上限 | 前10条 | 覆盖单卷纸的全流程异常排查需求，控制检索开销 |
| `defaultToken` | 2000 token | 适配在线质量曲线的时序文本解析长度，符合主流嵌入模型的输入限制 |
| 最大上下文 | 4000–6000 字符 | 保留完整的配浆与打浆流程信息，支撑审核环节的关联分析 |

## 容易做错的三处
- 界面显示索引任务长期处于「索引中」状态，无进度更新，重启服务后仍无法进入就绪状态。原因：未针对纸浆造纸的实时、多频次数据更新配置增量索引规则，重复执行全量索引导致系统资源被占用。
- 数据集内的索引条目数量随时间自动增加，出现多组重复的同批次记录索引。原因：未绑定数据更新的批次触发条件，误将实时数据流按固定周期全量导入，生成重复索引。
- 配置向量模型后，原有的语言模型配置项消失，无法搭建完整的问答审核链路。原因：未区分向量模型与语言模型的独立配置逻辑，在索引配置环节错误覆盖了语言模型的关联参数。

## 怎么确认配好了
- 查看索引任务的进度日志，确认增量索引的触发频率与数据更新的实时、每班、每卷节奏匹配。
- 随机抽取不同更新周期的记录样本，验证检索结果可关联到对应批次的配浆、打浆与质量检测文档。
- 检查向量模型与语言模型的配置项均未被覆盖，可正常调用关联链路。
- 导入单条低频异常记录，确认索引能在合理时间内完成新增条目加载并支持精准检索。
