# 纸浆造纸的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
数据来源包括木浆废纸批次台账、DCS/QCS控制系统、纸机在线测量设备、实验室检测系统、能源与水处理系统。更新节奏分实时（纸机运行参数）、每班（配浆与打浆记录）、每卷（断纸与换品台账）。文档包含配浆单、打浆日志、纸机运行记录、在线质量曲线、实验室报告、断纸换品台账，字段涵盖浆料配比份数、打浆度、克重、水分含量、断纸时长等，格式差异较大。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据来源要求接入环节适配不同系统的字段格式与输出结构，避免解析失败。实时更新的纸机运行参数要求模型调用的响应延迟匹配生产节拍，无法承受过长的响应等待。不同时间粒度的文档（实时参数、每班记录、每卷台账）需要划分独立的上下文分组，避免跨粒度数据干扰。非结构化的在线质量曲线需要适配视觉处理能力，以识别曲线异常点。高频更新的数据会快速填充上下文窗口，需要合理限制上下文长度防止溢出。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配纸浆造纸多源异构的历史数据上下文，覆盖单班生产记录与实时参数的关联分析 |
| `maxTokens` | 4000–6000 token | 匹配单卷质量审核的文本与曲线分析需求，避免超出模型输出上限 |
| `vision` | 启用 | 用于解析在线质量曲线、实验室报告的图表内容，识别异常波动 |
| `temperature` | 0.2–0.4 | 保持审核结果的一致性，避免因参数波动导致的质量判定偏差 |
| `AIPROXY_API_ENDPOINT` | 指向企业内部大模型网关地址 | 适配生产数据不出厂的安全要求，保障敏感生产信息不泄露 |
| `AIPROXY_API_TOKEN` | 按企业身份认证规则生成 | 保障模型调用的访问权限安全，防止未授权接入 |

## 容易做错的三处
- 现象：模型调用返回`context length exceeded`报错，界面显示上下文溢出提示。原因：未根据纸浆造纸的高频生产数据调整`maxContext`参数，导致历史运行记录快速填充上下文窗口。
- 现象：配置`vision`后仍无法解析在线质量曲线，日志显示图像解析失败。原因：未上传符合模型输入格式的曲线图片，或未开启对应模型的视觉推理能力。
- 现象：FastGPT接入OneAPI后出现间歇性响应超时，控制台显示`request timeout`日志。原因：未匹配纸机实时数据的响应延迟要求，`maxTokens`设置过高导致模型推理耗时过长。

## 怎么确认配好了
- 导入单卷断纸换品台账与对应时段的纸机运行数据，触发审核任务，检查输出结果是否包含浆料配比、断纸时长的关联分析。
- 上传一条在线质量曲线图片，启用视觉分析，检查是否能识别曲线的异常波动点。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置无误，无身份验证失败报错。
- 连续运行10分钟的实时数据审核任务，检查响应时长是否匹配生产节拍，无持续超时情况。
