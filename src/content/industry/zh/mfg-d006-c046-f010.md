# 肉制品与屠宰加工的检验与过程记录审核：知识库检索与召回

## 这个品类的数据长什么样
这个品类的典型数据来源包括动物检疫信息、供应商批次、生产追溯、温度采集、金属检测、实验室检测结果。日常文档包含检疫证明、屠宰与分割记录、配料腌制记录、热加工记录、冷链温度记录、微生物检验报告。数据更新节奏为每批、每班更新，连续温控数据每15 分钟更新一次。文档字段包含批次标识、温度数值、检测指标、检疫编号等，其中温度数值以摄氏度为单位，微生物检测指标以菌落形成单位为单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
品类数据按批次与生产时段更新，要求检索需限定批次与时间范围，避免召回跨批次的无关记录。多类型的专业文档需要按文档类型拆分存储，检索时需限定专属文档集合，防止混入行政类无关内容。连续温控与微生物检测的专业字段与单位，要求检索需匹配专业术语，避免低匹配度的内容被召回。数据关联着合规风险，检索结果的准确性直接影响审核效率与合规性，应严格过滤无关内容。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的参数逻辑。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.78–0.82` | 肉制品检验相关文档包含专业术语与严格合规要求，需过滤低匹配度的无关内容 |
| `limit` | `前5条` | 单批次生产的检验与过程记录总量有限，限制召回条数可减少token占用，提升检索效率 |
| `usingReRank` | 开启 | 品类数据存在批次、温度、检测结果等多字段关联，重排可提升高相关结果的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 用户提问可能省略批次号等元数据，扩展查询可补充关联字段，提升匹配精度 |
| `collectionIds` | 绑定检疫记录、生产记录、冷链记录专属集合 | 品类数据按文档类型拆分存储，限定集合可排除无关的企业行政文档 |

## 容易做错的三处
- 现象：检索结果包含跨批次的冷链温度记录，无法过滤无关内容。原因：未配置`collectionIds`限定专属文档集合，或未启用元数据过滤逻辑。
- 现象：知识库检索为空后触发联网搜索，但返回与检验审核无关的闲聊内容。原因：未设置基于知识库匹配结果的触发条件，或触发逻辑未绑定品类专属的业务关键词。
- 现象：AI回复中强制显示知识库引用标记，无法关闭。原因：未在检索配置中关闭引用展示开关，或未配置仅在匹配成功时展示引用的逻辑。

## 怎么确认配好了
- 上传单批次的检验记录与检疫证明，发起对应批次的审核提问，核对召回结果仅包含该批次的相关文档。
- 调整`similarity`参数的取值，验证低匹配度的无关内容是否被过滤。
- 发起无明确批次信息的提问，验证`datasetSearchUsingExtensionQuery`是否自动补充批次相关的检索条件。
- 触发知识库检索为空的场景，验证是否按配置触发后续的联网搜索或过滤逻辑。
