# 计量器具与实验室管理的检验与过程记录审核：向量模型与索引

## 这个品类的数据长什么样
本品类的数据主要来自企业计量室、CNAS体系实验室的计量管理系统、LIMS平台、外部校准机构证书、标准器及环境监测设备。日常文档包含量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账与偏离处置文件。数据更新按校准周期、单次试验或异常事件触发，包含器具编号、测量值、不确定度、校准日期、溯源链信息等字段，部分文档附带毫米、帕斯卡等明确单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类的数据兼具结构化台账与半结构化证书文本，更新频率差异大，且包含严格的溯源与测量精度要求。分块时需避免拆分溯源链、器具编号等关联字段，否则会影响向量召回的语义连贯性。批量数据的更新需支持增量索引，避免全量重建带来的资源消耗。同时，数据的严谨性要求向量匹配需过滤低置信度结果，防止错误的溯源或校准结果关联。部分短文本如期间核查记录与长文本如完整校准证书并存，需适配不同长度的分块参数，确保索引构建效率与召回准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配校准证书、试验原始记录的单块语义完整性，避免拆分溯源链与关键测量字段 |
| 重叠长度 | 100–150 字符 | 保留跨块的器具编号、校准日期等关联信息，确保溯源上下文的连贯性 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| 相似度阈值 | 0.75–0.85 | 满足计量数据的严谨性要求，过滤低置信度的匹配结果，避免误判关联 |
| `defaultToken` | 按实测标定 | 不同向量模型的token计算规则存在差异，需结合实际文档长度调整参数 |
| 单次搜索上限 | 前 5 条 | 聚焦最相关的校准记录与溯源信息，避免冗余数据干扰审核流程 |

## 容易做错的三处
- 导入数据后状态长期显示创建索引中。现象：数据集导入校准证书、量具台账等文件后，界面状态持续为创建索引中，无进度更新。原因：未调整分块长度适配长文本校准报告，导致向量计算超时。
- 向量计算得分异常。现象：不同计量记录的向量得分完全一致且数值超出合理区间。原因：未设置合理的相似度阈值，或分块时破坏了测量不确定度、器具编号等关键字段的语义关联。
- 向量化任务执行缓慢。现象：批量导入期间核查记录后，向量化耗时远超预期。原因：未调整分块参数适配短文本的批量处理，或未限制单次搜索的返回条数，导致索引构建资源占用过高。

## 怎么确认配好了
- 在FastGPT v4.17.0的数据集管理页面查看向量计算日志，核对`maxToken`的实际使用值是否符合文档长度要求。
- 随机抽取校准证书、量具台账等不同类型的文档，手动检查分块后的内容，确认溯源链、器具编号等关键信息未被拆分。
- 输入溯源查询语句，如“查找编号为XXX的量具的校准记录”，核对返回结果的相关性，调整相似度阈值至符合业务严谨性要求。
- 查看索引构建的进度日志，确认批量数据的更新任务在合理时间内完成，无持续超时报错。
