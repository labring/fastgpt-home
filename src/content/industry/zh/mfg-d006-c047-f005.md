# 计量器具与实验室管理的检验与过程记录审核：工具调用与插件

## 这个品类的数据长什么样
本品类数据覆盖企业计量室、CNAS体系实验室等主体，日常文档包含量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账及偏离处置文件。数据来源包括内部计量管理系统、外部校准机构证书、标准器、LIMS系统与环境监测设备。数据更新按校准周期、单次试验结果或异常事件触发，文档字段包含器具编号、校准有效期、测量不确定度、溯源编号等，附带长度、质量等物理量单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散且涉及多类系统与外部机构，工具调用需支持对接多源接口，需配置独立的权限校验规则适配不同数据源的访问要求。数据更新无固定周期，工具调用需支持按校准事件、试验完成或异常告警触发，适配非固定更新节奏。文档字段含物理量单位与溯源编号，工具入参需校验字段格式与单位合规性，避免因参数错误导致审核结果无效。溯源链维护需关联多份历史记录，工具调用需支持批量拉取关联数据，避免单次调用遗漏关联信息。

## 配置怎么定
本配置适用于 FastGPT v4.17.0。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | auto | 适配多工具调用场景，自动匹配计量器具数据拉取、校准证书校验等需求 |
| `functionCall` | enabled | 支持结构化输出检验审核结果，便于后续溯源链整理 |
| 工具调用超时时间 | 300 秒 | 校准证书拉取、溯源数据查询通常不超过该时长，避免长时间阻塞流程 |
| 多源数据并发数 | 前 3 条 | 避免同时调用过多外部接口触发限流，适配多数计量系统的调用限制 |
| 单次调用最大字符数 | 1000 字符 | 校准证书的文本内容通常不超过该长度，便于AI处理结构化信息 |
| 批量调用阈值 | 50 条 | 单次批量拉取期间核查记录的合理上限，避免单次数据量过大 |

## 容易做错的三处
- 现象：调用apiCollection接口时返回Invalid URL, code: 500。原因：未正确配置外部校准机构证书接口的完整访问路径，或接口未对调用方开放访问权限。
- 现象：工具调用节点仅输出工具执行日志，未生成AI整理后的检验审核结论。原因：未开启`functionCall`参数的启用配置，导致AI未将工具结果转化为结构化审核内容。
- 现象：上传校准证书扫描件等多模态文件时返回参数错误。原因：多模态文件尺寸超出平台支持的上限，或文件格式未被识别为合规的检验文档类型。

## 怎么确认配好了
- 发起一次模拟调用，检查是否能拉取指定计量器具的校准证书数据，核对返回字段包含溯源编号、测量不确定度等核心内容。
- 触发异常事件模拟，检查工具调用是否能按配置规则拉取相关期间核查记录与偏离处置文件。
- 查看工具调用日志，确认参数校验开关已生效，未出现字段格式或单位不匹配的报错。
- 验证多源数据拉取逻辑，确认同时调用计量管理系统与LIMS接口时，未出现并发限流导致的调用失败。
