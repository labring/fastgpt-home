# 计量器具与实验室管理的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来自企业计量室、CNAS体系实验室的计量管理系统、外部校准机构证书、LIMS系统与环境监测设备。日常生成量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账、偏离处置文档。数据更新按校准周期、单次试验完成或异常情况触发，文档包含器具编号、校准有效期、测量不确定度、溯源链编号等字段，部分字段带明确单位，如校准有效期以天为单位，不确定度以百分比或ppm为单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据分散于多套系统与外部证书，模型接入需支持多源数据的批量拉取与格式对齐，因此配置时需考虑适配不同数据源的接口格式。数据更新无固定周期，单次任务可能涉及多份不同更新节奏的文档，需合理限制上下文长度以避免冗余信息干扰。文档包含带单位的测量数值与溯源标识，模型需准确识别单位关联的数值逻辑，因此需调整参数以提升数值类字段的识别精度。同时，校准结果与溯源链需高可信度输出，需限制工具调用的范围以避免无关信息混入。

## 配置怎么定
本页面适配FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配多份校准证书与溯源记录的上下文长度，避免关键审核信息被截断 |
| `maxTokens` | 2000–3000 token | 满足校准结果审核、溯源链梳理的输出长度需求，确保输出内容完整 |
| `quoteMaxToken` | 1500–2000 token | 限定引用的原始文档片段长度，确保仅提取与审核相关的校准数据与溯源信息 |
| `toolChoice` | auto | 自动选择是否调用工具处理溯源查询与数据校验，适配多源数据的复杂处理需求 |
| `temperature` | 0.1–0.3 | 降低输出随机性，确保校准结果与溯源信息的表述准确一致，符合体系审核要求 |
| `AIPROXY_API_ENDPOINT` | 按平台提供的专属地址填写 | 适配计量数据的隐私传输要求，确保接口调用的安全性与合规性 |

## 容易做错的三处
- 现象：FastGPT界面中新增模型配置后无法查看，重启服务后仍未显示。原因：未正确填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的必填参数，导致配置未被系统持久化存储。
- 现象：模型测试时返回`[] is too short - 'messages'`报错。原因：初始上下文消息未填充有效内容，或`maxContext`参数设置过小导致可用上下文长度不足。
- 现象：多用户对接时出现对话与记录共享的情况。原因：未为每个用户生成独立的密钥，直接复用公共密钥进行接口调用。

## 怎么确认配好了
- 进入模型配置页面，查看`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`字段是否已正确填写，无空值。
- 发起一次模型测试请求，确认无`[] is too short - 'messages'`类报错，输出内容包含校准数据审核的相关逻辑。
- 配置多源数据对接的触发规则，测试拉取计量管理系统与LIMS系统的文档片段，确认格式对齐无误。
- 调整`temperature`参数后，观察输出内容的随机性变化，确认参数生效。
