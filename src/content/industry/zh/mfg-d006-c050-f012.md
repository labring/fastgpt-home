# 通用机械设备装配的检验与过程记录审核：部署与升级

## 这个品类的数据长什么样
这个品类的日常文档包含装配工艺卡、BOM、扭矩记录、间隙调整记录、试运行报告、出厂检验单、装箱清单。数据主要来自PLM/ERP系统、零件检验数据、装配工具采集终端、试验台、MES系统及客户技术协议。数据更新以单台设备或单订单为单位，每份文档包含明确的数值类字段，如扭矩值（单位N·m）、间隙值（单位mm）、同轴度（单位μm），以及标准化的审批流程节点信息。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据以单台/单订单为更新单元，且包含大量结构化数值字段与标准化流程节点，部署时需适配多源异构数据的接入格式。升级过程中需保留历史装配记录的关联关系，避免因版本迭代导致BOM与检验记录的映射断裂。同时，由于数据来源涉及车间现场的采集终端与试验台，部署时需预留适配工业协议的接口配置空间，确保不同设备的数据可正常同步至系统中。另外，单订单数据的独立性要求系统支持按订单维度的权限隔离，避免跨订单数据混淆。

## 配置怎么定
针对FastGPT v4.17.0版本的部署与升级，以下配置项需结合品类特征合理配置：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `DB_MAX_LINK` | `20–30 个连接` | 适配单订单多份文档的并发查询需求，避免数据库连接耗尽 |
| `MONGODB_URI` | 按实际部署的MongoDB实例地址填写，附加认证参数 | 存储大量非结构化的装配记录与试验报告，需支持高并发写入 |
| `PG_URL` | 按实际部署的PostgreSQL实例地址填写，配置连接池参数 | 存储结构化的BOM、扭矩记录等数据，支持复杂关联查询 |
| `REDIS_URL` | 配置为本地缓存实例地址，设置过期时间为`3600 秒` | 缓存高频访问的装配工艺卡数据，降低数据库查询压力 |
| `FILE_TOKEN_KEY` | 随机生成32位字符串 | 用于生成文件访问令牌，保障装配记录等敏感文档的访问安全 |
| `STORAGE_S3_ENDPOINT` | 按部署的对象存储服务地址填写 | 存储装配过程中的试验视频、装箱清单扫描件等最大`1000 MB`的大文件 |

## 容易做错的三处
- 现象：FastGPT镜像拉取超时或失败。原因：未配置国内镜像加速源，或服务器网络无法访问官方镜像仓库。
- 现象：导入插件时提示`internal server error`。原因：插件配置的数据源连接参数与实际部署的`PG_URL`或`MONGODB_URI`不匹配，或插件依赖的文件权限未正确配置。
- 现象：无法找到对应版本的docker-compose.yml配置文件。原因：未正确获取FastGPT历史版本的官方配置文件，或配置文件中的参数与当前部署环境不匹配。

## 怎么确认配好了
- 执行`docker ps`命令，确认所有FastGPT相关容器处于运行状态。
- 访问`FE_DOMAIN`配置的域名，登录系统后尝试导入一份BOM文档，验证上传与解析流程正常。
- 调用系统接口查询单订单的装配记录，确认返回的数据字段与PLM/ERP导出的字段一致。
- 重启FastGPT服务后，验证管理员权限仍可正常使用。
