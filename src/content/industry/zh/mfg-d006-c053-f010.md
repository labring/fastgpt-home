# 钢铁冶炼与连铸的检验与过程记录审核：知识库检索与召回

## 这个品类的数据长什么样
本品类的核心数据来自铁水与废钢台账、L2过程控制系统、化验室检测结果、MES生产系统、能源介质与设备状态监测模块。日常生成的文档包括炉次计划、配料单、转炉冶炼记录、成分报告、连铸工艺记录、板坯判定单，包含炉次标识、碳含量、出钢温度、拉速等字段，附带对应检测与工艺单位。数据更新频率按炉次生成冶炼记录，实时同步过程控制数据，每班汇总调度与质量审核类文档。

## 这些特征在「知识库检索与召回」这一环带来什么约束
实时与炉次级的更新节奏要求知识库检索需支持按炉次标识、生产时段快速过滤召回结果，避免混入无关历史数据。多源异构的文档结构，包含结构化参数与半结构化记录，要求检索模式适配字段级匹配与全文检索结合的逻辑。数据与生产强绑定，出错后果关联炉次降级或连铸中断，要求召回结果的相关性阈值需严格匹配业务场景。炉次与浇次的强耦合特性，要求检索召回需支持按生产链路关联查询，覆盖从炼钢到连铸的全流程关联数据。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，适配钢铁冶炼与连铸场景的专业数据特征。

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `similarity` | `0.75–0.85` | 钢铁冶炼专业术语密集，需过滤低相关性结果，避免误召回非对应炉次的记录 |
| `limit` | `前8条` | 单炉次关联的有效文档数量有限，过多召回会超出上下文窗口，影响审核效率 |
| `searchMode` | `全文+字段匹配` | 文档包含结构化参数与半结构化工艺记录，需兼顾关键词匹配与属性过滤 |
| `usingReRank` | 开启 | 多源异构数据的语义相似度需二次校准，提升专业术语匹配的准确性 |
| `datasetSearchUsingExtensionQuery` | 按实测标定 | 冶炼场景的专业问句需优化扩展，避免遗漏关联工艺参数 |
| `collectionIds` | 绑定炼铁、炼钢、连铸、质量审核专属数据集 | 需隔离非本品类的知识库内容，确保召回结果精准匹配业务范围 |

## 容易做错的三处
- 现象：创建知识库或通过静态链接生成数据集时返回Validation failed: name: Path `name` is required.报错。原因：未填写知识库基础配置中的名称字段，或静态链接生成流程中未正确指定关联集合的必填信息。
- 现象：回答内容中强制显示知识库搜索的input与response引用内容，无法仅展示审核结论。原因：未关闭回答中的引用展示开关，或工作流调用时未配置隐藏工具输出的对应参数。
- 现象：召回结果包含大量非当前炉次的历史数据，干扰审核判断。原因：未配置按炉次标识或生产时段过滤召回结果的逻辑，或`limit`参数设置过大导致无关数据被召回。

## 怎么确认配好了
- 执行单炉次的检验审核查询，检查返回结果是否仅包含对应炉次的相关文档，无无关历史数据混入。
- 触发工作流调用或直接知识库检索，查看回答内容，确认是否按需显示或隐藏知识库搜索的引用模块。
- 尝试创建知识库与静态链接数据集，确认无必填字段缺失的报错信息。
- 调整`similarity`参数的取值区间，验证召回结果的相关性是否符合业务审核的要求。
