# 钣金下料折弯的检验与过程记录审核：向量模型与索引

## 这个品类的数据长什么样
钣金下料折弯场景的核心数据来自CAD/CAM软件、订单BOM系统、板材库存台账、激光切割机、折弯机及MES系统。日常文档包含展开图、数控下料程序、折弯工艺卡、套料图、首件记录、工序流转卡。数据更新频率为每订单、每日或每次生产换型，文档字段包含折弯补偿参数、孔位坐标、板材规格、工序编号等，常用单位为毫米、平方米、小时。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类多品种小批量的生产模式带来高频数据更新需求，要求索引支持增量更新与快速重建。文档多为参数化的工艺与图纸内容，切分需保留关键参数块，避免拆分折弯系数、孔位关联信息。多源异构的数据格式要求索引兼容不同解析规则，同时因加工出错后果严重，向量匹配需保证高召回率，避免漏检关键工艺参数。

## 配置怎么定
本配置适用于 FastGPT v4.17.0。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配展开图、工艺卡的参数块长度，避免拆分折弯系数等关键工艺参数 |
| 重叠长度 | 50–80 字符 | 保留相邻块的折弯顺序、孔位关联信息，防止语义断裂影响检索准确性 |
| 相似度阈值 | 0.75–0.85 | 匹配钣金加工的公差范围，平衡误判与漏检风险 |
| `defaultToken` | 1024 | 适配折弯工艺卡的单块文本token上限，保证完整解析折弯步骤 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| 单次召回条数 | 前6条 | 覆盖多品种小批量的高频检索需求，避免遗漏同工序的历史记录 |

## 容易做错的三处
- 索引进度卡在「索引中」状态无进展。原因是单份套料图或完整展开图文件过大，未配置分块参数导致向量生成超时。
- 本地生成的向量无法在服务器端正常检索。原因是本地与服务器使用了不同的向量模型，嵌入维度不匹配导致相似度计算偏差。
- 问答时未按预设知识库优先级返回结果。原因是未配置知识库优先级规则，系统默认按索引时间排序检索结果。

## 怎么确认配好了
- 上传单份折弯工艺卡，查看分块后的文本是否保留完整的折弯系数、工序顺序信息。
- 调用向量生成接口，验证返回的嵌入维度与配置的模型维度匹配，且`defaultToken`与`maxToken`符合所选模型的限制。
- 上传多份同类型文档，检查索引进度是否在合理时间内完成，无卡顿。
- 配置知识库优先级后发起测试问答，确认优先返回指定知识库的检索结果。
