# 钣金下料折弯的检验与过程记录审核：模型接入与配置

## 这个品类的数据长什么样
该品类数据主要来自CAD/CAM软件、订单BOM、板材库存系统、激光切割机与折弯机设备日志及MES系统。日常文档包含三维件展开图、数控下料程序、折弯工艺卡、套料图、首件检验记录、工序流转卡，字段包含板材厚度、折弯系数、孔位坐标、工序编号等，单位多为毫米、千克、小时。数据更新随每笔订单、每日生产排班及每次设备换型触发，覆盖从订单下达至工序完成的全流程节点。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的多品种小批量、图纸驱动特性，要求模型接入时需适配多格式图纸解析与动态数据关联。高频更新的订单与换型数据，要求配置需支持快速同步增量数据，避免上下文冗余。多类型文档的字段差异，要求配置需明确不同数据源的字段映射规则，防止数据解析错位。设备采集的实时日志与静态工艺卡结合的需求，要求配置需区分结构化与非结构化数据的处理逻辑，保障审核结果的准确性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `vision` | 开启 | 该品类核心依赖图纸、工艺卡等图片类文档审核，需支持视觉解析能力 |
| `maxContext` | `8000–12000 token` | 覆盖单订单多工序的流转记录与工艺参数，避免上下文截断丢失关键信息 |
| `maxTokens` | `4000 token` | 适配单批次下料折弯的全量审核内容长度，平衡输出精度与响应速度 |
| `temperature` | `0.2–0.4` | 保障审核逻辑的一致性，避免因参数波动导致折弯顺序判断偏差 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写对应节点 | 适配国内或跨境的模型调用链路，保障接口连通性 |
| `AIPROXY_API_TOKEN` | 绑定专属调用密钥 | 限制访问权限，防止未授权调用影响生产数据安全 |

## 容易做错的三处
- 开启`vision`后仍无法解析图纸图片，原因是未在数据源配置中勾选图片解析开关，仅开启模型端视觉参数未生效。
- 配置`maxContext`为6后仍无多轮对话记忆，原因是未同时配置对应会话缓存规则，仅修改模型上下文参数未关联会话存储逻辑。
- 调用模型代理接口测试通义千问失败，原因是未正确填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或接口未开放对应模型调用权限。

## 怎么确认配好了
- 上传单份折弯工艺卡与下料程序，验证模型能否正确提取板材厚度、折弯系数等核心字段，核对提取结果与文档内容是否一致。
- 发起两轮关联的审核请求，验证模型能否基于上一轮的工序记录完成当前工序的误差核对，确认上下文关联生效。
- 调用内置测试接口提交配置参数，验证接口返回状态为正常，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置正确。
- 模拟设备换型后的数据同步，验证配置能否自动加载新的工艺参数，确认增量数据同步逻辑生效。
