# 铸造（砂型、精密、压铸）的检验与过程记录审核：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据来自ERP物料主数据、熔炼炉与测温仪、光谱仪、MES炉次记录、模具管理系统及客户图纸。日常文档包含铸造工艺卡、配料单、炉次记录、模具履历、首件检验记录、材质报告与不合格品评审单。更新按炉次、批次或每日执行，单份文档包含合金元素含量、炉温、浇注时间、模具使用次数、不合格类型等结构化字段与对应数值、单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
高频更新的生产数据要求检索召回覆盖最新炉次、批次记录，避免引用过期参数。结构化字段多且关联紧密，如炉次号对应配料单、炉温记录、材质报告，需按关联字段精准召回关联文档。单份文档包含明确数值与单位，检索需保留字段语义，避免混淆不同参数的单位表述。生产规模扩大后，召回结果过多会超出上下文长度限制，需严格控制召回范围与条数。

以下配置基于FastGPT v4.17.0版本。
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 铸造检验参数需较高语义匹配度，过滤低相关的历史生产记录 |
| `limit` | `前3–5条` | 单炉次关联的检验与过程文档通常不超过5份，避免超出上下文长度 |
| `searchMode` | `keyword + semantic` | 兼顾结构化字段（如炉次号、模次号）的精准匹配与参数语义的召回 |
| `usingReRank` | `开启` | 对召回结果按业务相关性重排，优先返回匹配炉次、模次的文档 |
| `datasetSearchUsingExtensionQuery` | `开启` | 扩展查询覆盖同义词，如将「回炉料」匹配「旧料」「回收料」 |
| `collectionIds` | `按生产部门指定的知识库集合` | 仅召回铸造检验相关的文档，排除无关的行政或非生产类文档 |

## 容易做错的三处
- 现象：配置完成后点击测试提示错误，但引用文档后可正常运行。原因：测试接口未正确加载模型与知识库的关联配置，运行时的上下文参数覆盖了测试阶段的异常配置。
- 现象：工作台知识库简单应用中每次仅返回1条引用文档。原因：`limit`参数被误设为`1`，未根据铸造关联文档的数量调整召回上限。
- 现象：导入指定JSON知识库后，工作流中知识库选项为空。原因：未指定`collectionIds`参数，或集合ID配置错误，无法匹配到导入的知识库集合。

## 怎么确认配好了
- 触发包含炉次号或检验参数的查询，查看返回的引用文档数量是否符合设定的`limit`范围。
- 输入包含特定炉次号的查询词，确认召回的文档包含对应炉次的配料单、炉温记录等关联内容。
- 测试高相似度的非目标查询词，确认`similarity`阈值过滤了低相关的文档。
- 检查工作流中知识库选项是否自动加载指定的集合，无需手动选择。
