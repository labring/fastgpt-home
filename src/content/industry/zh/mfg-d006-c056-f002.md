# 锂离子电芯制造的检验与过程记录审核：向量模型与索引

## 这个品类的数据长什么样
该品类数据来自原材料批次台账、车间MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室测试设备。日常文档包含配料记录、涂布辊压参数、卷绕或叠片工序记录、注液台账、化成分容数据、OCV与安全测试报告。数据更新节奏为每批次、单只电芯维度实时更新，且对水分含量、洁净度、批次一致性要求极高，后段化成分容环节数据生成周期较长。

## 这些特征在「向量模型与索引」这一环带来什么约束
实时且高频的单电芯/批次数据会带来索引更新压力，需适配增量索引以降低全量重建的负载。多维度的工艺参数与测试数据字段复杂，需支持细粒度分块以保留参数单位与工序关联逻辑。电化学体系对异常值敏感，需确保向量嵌入时保留关键阈值信息，避免模糊化处理。长周期的化成分容数据会拉长单条文档长度，需合理控制分块边界以保留数据关联性。同时，数据量随产能扩张快速增长，需适配可横向扩展的索引结构。

## 配置怎么定
可通过`defaultToken`配置默认嵌入Token长度，通过`maxToken`限制单条文档的最大Token数，本文适配FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配单电芯工艺记录的字段密度，避免拆分后丢失参数关联 |
| 重叠长度 | 100–150 字符 | 保留跨分块的工艺参数上下文，防止分块边界切断关键逻辑 |
| 相似度阈值 | 0.72–0.85 | 匹配电芯工艺数据的特征相似度区间，过滤低关联的异常匹配 |
| 单次搜索上限 | 前8条 | 适配批次数据的多参数关联查询，控制返回结果的冗余度 |
| 最大上下文Token数 | 4096 token | 适配化成分容数据的长文本长度，确保完整嵌入关键曲线信息 |
| 问题优化 | 按实测标定 | 适配不同工艺场景的查询意图，避免通用优化破坏专业字段语义 |

## 容易做错的三处
- 现象：知识库搜索响应超时，日志显示向量检索耗时超过60秒。原因：未配置增量索引，全量重建索引时处理了每批次的实时数据，导致索引加载压力过大。
- 现象：部分工艺参数查询结果为空，返回无匹配内容。原因：分块长度设置过小，拆分时切断了参数与对应测试结果的关联逻辑，导致向量嵌入丢失关键关联信息。
- 现象：使用shaw/dmeta-embedding-zh模型时，检索结果的异常值占比过高。原因：未针对电化学数据的敏感阈值做预处理，向量嵌入时模糊了水分、内阻等关键参数的权重。

## 怎么确认配好了
- 手动导入单批次的配料记录与化成分容数据，检查分块后的文档是否保留完整的参数单位与关联字段。
- 配置增量索引后，提交实时生成的电芯测试数据，确认索引能在5分钟内完成更新。
- 选择shaw/dmeta-embedding-zh模型，查询已知的异常工艺参数，检查检索结果的匹配度是否符合预设阈值。
- 查看系统索引监控面板，确认单次搜索的返回条数不超过预设的单次搜索上限。
