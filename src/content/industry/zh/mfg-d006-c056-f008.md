# 锂离子电芯制造的检验与过程记录审核：文档解析与分块

## 这个品类的数据长什么样
锂离子电芯制造的检验与过程记录数据，来源覆盖原材料批次台账、生产执行系统（MES）、浆料与涂布在线检测设备、车间露点监测系统、化成分容柜及实验室测试报告。文档包含配料配比参数、涂布辊压工艺记录、卷绕叠片工序台账、注液量数据、化成分容曲线、OCV与安全测试结果等，更新节奏按生产批次、单只电芯实时产生，单批次文档随生产规模呈现多页结构化表格与时序曲线结合的特征。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的高频实时更新、混合格式文档特征，对解析与分块环节带来多重约束。多页结构化表格与时序曲线结合的文档，需保留字段间的关联关系，避免拆分跨工序的参数组；实时产生的单批次大体积文档，需适配足够的解析时长与文件上传上限；电化学工艺对参数精度要求高，分块时需避免破坏单工序的完整数据上下文，否则会影响后续审核环节的信息完整性。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | `800–1200 字符` | 锂离子电芯文档包含多字段参数与短时序数据，该区间可保留单工序参数组的完整上下文，避免拆分跨关联参数的内容 |
| `chunkSplitter` | `按段落+表格行拆分` | 文档混合结构化表格（配料、检测记录）与段落说明（工艺要求），需保留表格行内字段完整性与段落逻辑 |
| `PARSE_FILE_TIMEOUT_SECONDS` | `120–180 秒` | 单批次多页文档解析需足够时间加载完整内容，避免高频更新的大文件超时中断 |
| `UPLOAD_FILE_MAX_SIZE` | `1000 MB` | 大型生产批次的多页汇总文档可能达到较大体积，需适配批量文档上传需求 |
| `customPdfParse` | `启用结构化解析模式` | 文档包含时序曲线与表格数据，结构化解析可保留字段关联关系，提升分块准确性 |
| `chunkSettingMode` | `手动配置` | 需针对电芯制造文档的混合格式调整分块规则，避免通用模式拆分关键参数组 |

## 容易做错的三处
- 现象：调用解析工具处理数百页的生产汇总PDF时报错，小页数文档可正常解析。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`参数，默认超时阈值不足以完成多页文档的完整加载与解析。
- 现象：本地部署的PDF解析工具启动后，页面抛出Cannot read properties of undefined报错。原因：未启用适配结构化文档的解析模式，或解析配置未匹配锂离子电芯文档的混合格式（表格+时序曲线）。
- 现象：分块结果出现大量重复内容，或召回的文件数与预期不符。原因：未针对电芯文档的字段关联性调整分块规则，错误设置了通用的分块重叠比例，或未匹配文档的批次更新节奏配置召回参数。

## 怎么确认配好了
- 上传单批次50页以上的电芯生产文档，查看解析进度是否在`PARSE_FILE_TIMEOUT_SECONDS`设定的时间内完成，无超时报错。
- 随机抽取分块结果，检查表格行与时序曲线的关联字段是否未被拆分，保留完整的工序参数组。
- 调整分块参数后，对比不同`chunkSize`取值下的分块数量，确认符合文档的结构逻辑，无跨参数拆分的情况。
- 在FastGPT v4.17.0版本中，确认`customPdfParse`配置项已启用结构化解析模式，适配混合格式文档的解析需求。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
