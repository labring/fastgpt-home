# 锂离子电芯制造的检验与过程记录审核：模型接入与配置

本文适配FastGPT v4.17.0版本的模型接入与配置流程。

## 这个品类的数据长什么样
该品类的数据来自原材料批次台账、车间MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室测试报告。日常文档包含配料记录、涂布辊压参数、卷绕/叠片记录、注液记录、化成分容数据、OCV与安全测试报告。数据更新节奏为每批电芯、每只单体电芯实时同步，部分关键参数如露点、浆料配比需高频采集。电化学体系对水分、洁净度与批次一致性要求极高，后段化成分容环节需留存长周期曲线数据。

## 这些特征在「模型接入与配置」这一环带来什么约束
由于数据来源分散且包含结构化参数与非结构化报告，模型接入需适配多源数据的关联读取；高频实时更新的批次数据要求配置支持按生产批次过滤历史信息，避免跨批次数据混淆；长周期化成分容曲线数据体积较大，需限制单轮调用的上下文与输出token总量，防止响应超时；水分、洁净度等敏感参数的精准识别，需开启视觉适配能力以读取带图表的测试报告；不同环节的文档格式差异明显，需配置对应解析规则确保各类文件均可被正确处理。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 单批次数据包含多份检测报告与参数记录，需保留足够上下文以关联批次内所有关联数据 |
| `maxTokens` | 4000–6000 token | 化成分容曲线的长文本解析需足够输出空间，避免截断关键测试结论 |
| `vision` | 开启 | OCV与安全测试报告包含数值表格与趋势图表，视觉识别可准确提取图表中的核心数据 |
| `temperature` | 0.1–0.3 | 检验与审核场景需高一致性的结论，避免随机偏差影响判断准确性 |
| `AIPROXY_API_ENDPOINT` | 部署所在局域网的代理访问地址 | 本地部署场景下需通过代理访问合规模型服务，确保生产数据不出厂 |
| `quoteMaxToken` | 1500 token | 需引用单份检测报告的核心内容，避免引入过多冗余数据干扰模型判断 |

## 容易做错的三处
- 现象：本地部署场景下，知识库中转换为URL的图片无法在对话中被模型输出。原因：未开启`vision`配置项，或代理配置未开放内部图片资源的访问权限。
- 现象：上传Word文档后模型识别结果为空。原因：未配置适配Office文档的解析规则，或文档内包含加密内容、复杂嵌套格式超出默认解析范围。
- 现象：单批次数据量较大时模型响应超时。原因：`maxContext`或`maxTokens`配置取值过大，超出模型服务的负载阈值，或未限制单轮调用的数据源数量。

## 怎么确认配好了
- 上传单份配料记录与化成分容报告，核对模型是否能准确提取关键参数如涂布面密度、化成分容容量。
- 发起包含多批次数据的查询，核对模型是否能正确关联对应批次的检测结果，无跨批次数据混淆。
- 检查代理配置项的连通性，确认模型服务可正常访问内部MES系统与检测设备数据。
- 上传包含图表的OCV测试报告，核对模型是否能输出图表中的核心数值与测试结论。
