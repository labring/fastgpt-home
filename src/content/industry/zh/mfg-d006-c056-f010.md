# 锂离子电芯制造的检验与过程记录审核：知识库检索与召回

## 这个品类的数据长什么样
锂离子电芯制造的检验与过程记录数据，来源包括原材料批次台账、车间MES系统、浆料与涂布检测设备、车间露点监测系统、化成分容柜采集数据、实验室OCV与安全测试报告。数据更新节奏为每批次电芯生成配料、涂布等记录，单只电芯的化成分容数据实时上传，实验室报告随测试完成同步更新。文档结构包含批次号、参数值、测试时间、设备编号等字段，单位涵盖微米、毫安时、摄氏度等专业工业计量标准，与普通电子装配的装配记录差异明显，核心聚焦电化学工艺相关的参数与安全指标。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据更新频率高且单条记录粒度细，要求检索召回环节支持实时或准实时的增量同步，避免召回过期数据。多字段的专业文档结构，要求检索需精准匹配批次号、工艺参数等关键字段，避免泛化检索返回无关内容。单批次累积的检测记录数量较多，若不限制召回条数，会导致上下文token超出模型承载上限，影响回答效率。电化学工艺的专业术语需要专属匹配逻辑，普通检索模式难以覆盖专业场景的召回精度。

## 配置怎么定
FastGPT v4.17.0 版本下的配置建议如下：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.72-0.80 | 匹配电芯制造的专业工艺参数与记录，过滤低相关的通用文档 |
| `limit` | 前6条 | 控制上下文token消耗，避免超出模型承载上限 |
| `usingReRank` | 开启 | 对多批次的检测记录进行排序，优先召回关键工艺参数与安全指标 |
| `datasetSearchUsingExtensionQuery` | 开启 | 扩展专业术语的查询范围，例如将“面密度”关联到涂布工序的检测记录 |
| `collectionIds` | 绑定专属电芯制造知识库集合 | 隔离其他品类的文档，避免召回无关的装配或消费电子数据 |
| `searchMode` | `mixedRecall` | 查询示例结合了领域术语与自然语言语境；请用代表性数据比较验证，不将其视为产品默认值。 |

## 容易做错的三处
- 对话发起后未自动调用知识库，直接输出通用回答：未在工作流中配置检索节点的默认触发逻辑，或未将检索节点绑定到对话的起始环节。
- 检索结果超出设定的token上限，回答冗长且卡顿：单次搜索上限设置过高，例如设置为2000条记录，导致召回数据量过大，超出模型上下文限制。
- 检索结果直接显示在界面中，与后续AI回答重复输出：工作流中同时保留了检索节点的直接输出配置，未将检索结果仅作为上下文传入AI回答节点。

## 怎么确认配好了
- 上传一批电芯涂布与化成分容的历史记录，发起查询“本次批次的涂布辊压参数”，核对召回结果的条数与相似度是否符合配置的阈值与上限要求。
- 查看工作流的节点链路，确认检索节点仅作为上下文传入AI回答节点，未配置直接输出，避免重复结果。
- 检查知识库的集合绑定，确认仅包含锂离子电芯制造的相关文档，无其他品类的无关数据混入。
- 发起包含多个专业术语的查询，例如“某批次电芯的露点异常记录”，核对检索结果是否优先召回相关的工艺与检测数据。
