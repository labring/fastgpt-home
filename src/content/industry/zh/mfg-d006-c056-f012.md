# 锂离子电芯制造的检验与过程记录审核：部署与升级

## 这个品类的数据长什么样
该品类的数据来自原材料批次台账、生产MES系统、浆料与涂布检测设备、车间露点监测装置、化成分容柜及实验室测试系统。日常文档涵盖配料记录、涂布辊压参数台账、卷绕/叠片工序记录、注液操作日志、化成分容数据报表、OCV与安全测试报告。数据更新节奏为每生产批次、每只电芯实时同步，字段包含工序编号、工艺参数值、环境监测数值、测试结果及批次关联标识，未包含额外统计类百分比数据。

## 这些特征在「部署与升级」这一环带来什么约束
由于该品类数据更新频率高且单批次数据量随电芯生产数量增长，部署时需适配高频写入的存储配置，避免出现连接阻塞。多源异构的生产数据需统一接入格式，升级环节需兼容原有设备的协议接口，防止中断实时数据采集链路。同时，电化学生产对数据准确性要求极高，部署时需配置数据校验规则，确保检测数值与工艺标准的偏差可被及时识别。此外，单条记录字段多且关联紧密，需预留足够的上下文存储资源，防止查询时出现数据截断或关联信息丢失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150 个连接` | 适配高频实时写入的生产数据，避免连接池耗尽导致请求失败 |
| `MONGODB_URI` | 指向存储工序记录与测试报告的专属数据库实例 | 该品类数据需按批次与电芯维度归档，专属实例可隔离业务数据与其他业务库 |
| `REDIS_URL` | 配置为本地缓存节点，缓存时长设为`300 秒` | 用于临时存储实时露点、辊压参数等高频读取的生产数据，降低数据库查询压力 |
| `STORAGE_S3_ENDPOINT` | 绑定企业内部对象存储服务的访问地址，单文件最大限制设为`1000 MB` | 用于存储大容量的化成分容数据与测试报告文件，满足大体积数据存储需求 |
| `FILE_TOKEN_KEY` | 按企业内部密钥管理规范生成32位随机字符串 | 用于校验上传的工序记录文件的合法性，防止非法文件接入系统 |
| `PG_URL` | 指向存储工艺参数基准值的关系型数据库 | 用于对比实时检测数据与工艺标准的偏差，实现快速合规校验 |

## 容易做错的三处
- 现象：部署后查询检验记录时返回结果不完整，或推理输出长度不足无法覆盖完整检验报告内容。原因：未正确配置`DB_MAX_LINK`参数，连接池上限过低导致部分数据请求被拒绝，或升级后未调整上下文存储配置适配大容量检验数据。
- 现象：上传化成分容数据或测试报告时提示请求失败，且重启服务器后仍无法恢复。原因：`STORAGE_S3_ENDPOINT`配置错误，或`REDIS_URL`对应的缓存节点出现故障，导致对象存储服务无法正常写入大容量测试文件。
- 现象：配置MCP服务时，参数类型被固定为字符串无法修改。原因：未按FastGPT v4.17.0官方部署文档启用自定义参数类型开关，或部署版本未适配该功能。

## 怎么确认配好了
- 登录FastGPT后台的数据库连接管理页面，验证`MONGODB_URI`与`PG_URL`配置的实例可正常建立连接。
- 上传一条模拟的注液记录文件，检查文件是否能正常存储并在文档列表中正常显示。
- 发起一次批量检验记录查询请求，确认返回的结果条数未超过`DB_MAX_LINK`配置的连接池上限。
- 查看系统实时日志，确认`REDIS_URL`对应的缓存节点无连接超时或读写失败报错。
