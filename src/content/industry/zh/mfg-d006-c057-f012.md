# 锻造与模锻的检验与过程记录审核：部署与升级

## 这个品类的数据长什么样
这个品类的数据主要来自原材料质保书、加热炉系统、压力机采集数据、MES系统、无损检测仪及客户锻件图。日常关联文档包含锻造工艺规程、下料卡、加热炉记录、锻造过程卡、模具寿命记录、热处理委托单、超声检测报告。数据更新以每件、每批或每炉次为节奏，核心字段包含炉批号、锻造比、纤维方向、检测缺陷类型及对应参数，单位涉及温度、压力、尺寸公差等工艺参数。

## 这些特征在「部署与升级」这一环带来什么约束
高频次的单批/单炉次数据更新，要求部署时配置支持实时或准实时的数据同步链路，避免延迟引发审核滞后。多源异构的数据来源，需要提前配置对应的数据接入适配规则，确保不同系统的字段格式统一。批量文档的结构化存储需求，要求知识库索引适配多字段关联检索。升级过程中需保留历史炉批号、锻造比等核心关联数据，避免批次追溯链路断裂。同时，因缺陷检出直接关联锻件报废风险，部署时需预留足够的检索响应资源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 数据库连接池配置 | 通过 `DB_MAX_LINK` 设为 20–30 个连接 | 适配多源数据高频写入，避免连接耗尽 |
| 对象存储端点配置 | 通过 `STORAGE_S3_ENDPOINT` 填写对应云服务商节点，单文件上限设为 1000 MB | 适配批量超声检测报告的大文件存储需求 |
| 缓存服务地址配置 | 通过 `REDIS_URL` 填写自建或托管服务地址 | 加速炉批号、批次数据的快速校验检索 |
| 关系型数据库连接 | 通过 `PG_URL` 或 `MONGODB_URI` 选择对应数据源 | 适配结构化锻造参数的存储与关联检索 |
| 知识库导入校验 | 开启自动格式校验 | 避免格式错误导致的训练数据报错 |
| 单次检索召回上限 | 召回前 20 条结果 | 平衡检索效率与完整召回的需求 |
| 文件访问密钥配置 | 自定义 `FILE_TOKEN_KEY` 为随机字符串 | 保障敏感工艺文档的访问安全 |

## 容易做错的三处
- 导入改造后的知识库数据时报错，提示CSV格式不兼容。原因：未严格按照FastGPT v4.17.0的官方模板调整字段，保留了旧版本的冗余字段。
- 无法查看当前部署的FastGPT版本。原因：未在系统设置页面开启版本查看权限，或未配置`ROOT_KEY`进行管理员身份验证。
- 知识库搜索模块的引用上限无法调节。原因：未通过对应配置项调整检索配额，或缓存服务未正常同步配置，导致配额无法生效。

## 怎么确认配好了
- 执行一次单炉次数据的批量导入，查看导入日志无格式报错，确认导入校验配置生效。
- 发起针对某锻件批次的检索请求，查看返回结果条数符合预设的召回上限，确认检索配置正常。
- 访问存储的超声检测报告文件，验证文件访问权限正常，确认密钥配置有效。
- 查看系统状态页面，确认数据库连接池、缓存服务的运行指标稳定，确认基础服务配置无误。
