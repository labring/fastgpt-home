# 饮料与瓶装水的检验与过程记录审核：部署与升级

## 这个品类的数据长什么样
该品类的数据主要来自水源与原料检测、配方系统、在线糖度酸度监测、灌装设备、视觉检测及LIMS系统。日常文档包含配方单、水处理记录、调配记录、杀菌或无菌灌装记录、包材检验与成品检验表单。数据更新频率为每批、每班或连续采集，字段涵盖原料检测值、配方参数、设备运行参数、检验结果与产品批号等，部分参数带有明确单位，如糖度百分比、灌装液位毫米值。

## 这些特征在「部署与升级」这一环带来什么约束
该品类高频连续采集的设备数据与批次级文档，要求部署环节支持高并发数据写入与低延迟查询。多源异构的数据来源，需要配置兼容多类型数据源的存储与接入链路，避免数据同步中断。产品切换频繁的特性，要求升级环节支持快速切换不同批次的知识库数据集，避免跨批次数据混淆。关键检验环节的记录需严格溯源，因此部署时需确保数据存储的不可篡改配置，同时需适配该品类特有的字段格式与单位规则，避免数据解析错误。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `200–300` | 适配每批连续采集的高频数据连接需求，避免连接池耗尽 |
| `MONGODB_URI` | 指向LIMS系统对接的专用数据库实例 | 存储批次级检验记录与配方数据，与业务数据隔离 |
| `REDIS_URL` | 配置为本地缓存服务地址，缓存有效期`300 秒` | 缓存高频查询的在线监测数据，降低数据库访问压力 |
| `STORAGE_S3_ENDPOINT` | 指向企业合规的对象存储服务端点 | 存储大体积的设备运行日志与检验原始图片，确保数据可溯源 |
| `FILE_TOKEN_KEY` | 按企业内部密钥规范生成随机字符串 | 加密存储的检验文档访问令牌，避免未授权访问 |

## 容易做错的三处
- 现象为创建知识库时无法选择本地部署的模型，提示模型未配置或地址无效。原因是未通过`FE_DOMAIN`配置本地模型服务的访问域名，或未将第三方API接入的配置正确同步到FastGPT的服务配置中，导致FastGPT无法发现本地部署的模型实例。
- 现象为批量导入检验记录时出现连接超时错误，日志显示连接池耗尽。原因是`DB_MAX_LINK`配置值过低，无法支撑高频的批量数据写入请求。
- 现象为存储的检验图片无法正常加载，返回403权限错误。原因是`STORAGE_S3_ENDPOINT`配置的存储端点未开放文档读取权限，导致FastGPT无法访问存储的原始检验数据。

## 怎么确认配好了
- 执行批量导入单批次水处理记录的测试，查看数据库连接数监控指标，确认未超过`DB_MAX_LINK`配置的阈值，验证连接池配置生效。
- 访问配置的`STORAGE_S3_ENDPOINT`存储端点，上传并读取测试文档，确认存储链路正常，可正常读写检验相关文件。
- 发起本地模型的测试调用，检查`FE_DOMAIN`配置的本地服务地址可正常访问，确认模型接入链路正常。
- 生成检验记录的访问令牌，使用`FILE_TOKEN_KEY`生成的密钥验证令牌有效性，确认加密配置生效。
