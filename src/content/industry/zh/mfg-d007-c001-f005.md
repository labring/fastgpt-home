# PCB制造的生产台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
PCB制造的生产台账数据来自客户交付的Gerber文件、钻带、BOM清单，以及CAM系统、生产设备参数、槽液化验记录、AOI检测报告、电测报告与实验室切片报告。数据更新节奏为每生产批次、每班或连续采集，单批次台账包含工程制作指示、钻孔层压参数、药水分析结果、缺陷检测记录等内容，字段涵盖图层编号、孔径尺寸、设备运行参数、缺陷坐标与数量等，无统一固定的字段顺序与格式，随生产环节不同有所调整。

## 这些特征在「工具调用与插件」这一环带来什么约束
PCB制造的生产台账数据来源分散、格式不统一，工具调用需适配多源异构数据的拉取与解析，无法依赖单一格式的输入。数据更新节奏差异明显，部分参数需实时采集，部分按生产批次同步，工具调用的触发时机需匹配生产环节的节奏。单批次台账数据量随PCB层数与检测项增加而扩大，工具调用的单次数据处理规模需适配该特征。同时台账需关联多环节的工程、检测与设备数据，工具调用需支持跨数据源的参数联动，仅处理单一环节文档无法满足汇总需求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` | 适配多源异构数据的解析需求，自动匹配对应工具处理不同格式的台账数据 |
| 工作流/API 函数调用配置 | `enabled` | 强制启用工具调用，完成跨数据源的生产数据汇总与格式转换 |
| 单次工具调用数据拉取上限 | 前10条生产环节记录 | 单批次PCB的生产环节记录数量可控，过多拉取会增加解析与传输负担 |
| 工具调用超时阈值 | 120 秒 | 多源数据拉取与解析需合理时长，超时会导致台账生成流程中断 |
| 结果输出格式 | Markdown 格式 | 生产台账需清晰的层级结构，Markdown格式便于后续报告生成与分发 |
| 上下文窗口长度 | 8000 token | 多环节的台账数据内容较多，足够的上下文窗口可保留完整的关联信息 |

## 容易做错的三处
- 调用API调试时返回报错提示「工具调用参数非法」，原因是未按PCB生产台账的多源数据格式配置工具入参，导致工具无法识别分散的数据源字段。
- 前端接收的文本流为无格式的纯文本，无法生成清晰的台账报告，原因是未配置结果输出为Markdown格式，工具返回的结构化数据未做格式转换。
- 中间服务转发后出现流数据断开，前端页面数据固定，原因是未设置工具调用的超时重试机制，当多源数据拉取超时后未触发重试，导致流程中断。

## 怎么确认配好了
- 触发一次单批次PCB的台账生成流程，查看工具调用日志是否显示正确的数据源拉取记录。
- 查看工具调用返回的结果，确认格式为Markdown，包含层级化的生产环节数据。
- 模拟中间服务转发场景，测试流数据传输是否稳定，无无故断开情况。
- 调整工具调用的拉取上限，验证返回的生产环节记录数量符合预期设置。
