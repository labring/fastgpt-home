# PCB制造的生产台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
本品类数据来自客户提供的Gerber文件、钻带、BOM，以及CAM系统、生产设备参数、槽液化验结果、AOI检测报告、电测报告与实验室切片报告。数据更新按生产批次、每班频次或连续采集生成，日常文档包含工程制作指示、钻孔层压参数记录、药水分析台账等。数据字段涵盖图形层信息、孔位参数、药水浓度、检测缺陷类型与结果等，无统一固定的字段顺序与格式，随生产环节动态生成。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类数据多源异构且格式不统一，模型接入需适配多类异构文档的解析，需配置足够的上下文窗口容纳批量生产数据。数据按生产批或连续更新，单次处理数据量较大，需控制接口调用频次避免触发QPS限制。专业字段如孔铜厚度、层压压力等需准确识别，模型输出需保持稳定格式以适配台账汇总逻辑，同时需兼容不同厂商设备导出的原始数据格式。

## 配置怎么定
当前适配FastGPT v4.17.0版本的模型接入配置逻辑如下：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配多源PCB生产文档的批量上下文，容纳单次生产批的全部台账与检测数据 |
| `maxTokens` | 4000–6000 token | 限制单轮输出长度，避免生成过长的汇总报告导致解析失败 |
| `temperature` | 0.2–0.4 | 降低随机输出概率，保障专业术语与台账格式的稳定性 |
| `toolChoice` | auto | 自动选择调用工具处理结构化数据提取，适配多类生产文档的字段抽取 |
| `AIPROXY_API_ENDPOINT` | 按服务商提供的专属地址填写 | 确保接口调用指向正确的模型服务节点 |
| `AIPROXY_API_TOKEN` | 按服务商生成的密钥填写 | 完成接口调用的身份验证，保障访问权限 |

## 容易做错的三处
- 接口调用频繁触发QPS限制报错。原因是未根据生产数据的批量更新节奏调整调用频次，单次处理数据量超出接口承载范围。
- 大模型输出的Markdown格式不稳定，出现标题层级混乱或代码块格式错误。原因是temperature参数设置过高，导致输出随机性过强，未适配台账的固定格式要求。
- 无法调用指定第三方模型，提示密钥验证失败。原因是`AIPROXY_API_TOKEN`配置错误，或未完成第三方模型的密钥绑定验证。

## 怎么确认配好了
- 发起单次测试数据的调用，确认接口返回状态码正常。
- 检查模型输出的台账字段与原始生产文档的字段对应，无遗漏或错误。
- 连续发起多次调用，确认输出格式保持稳定，无明显随机性偏差。
- 核对接口密钥与端点的配置信息与服务商提供的内容一致。
