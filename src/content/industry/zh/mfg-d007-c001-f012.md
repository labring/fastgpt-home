# PCB制造的生产台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
PCB制造的生产台账数据来源包含客户提供的Gerber文件、钻带、BOM清单，以及CAM生成的工程制作指示、钻孔和层压参数，还有槽液化验、AOI报告、电测报告、切片报告等实验室与设备采集数据。数据按生产批、每班或连续采集更新，覆盖工程、生产、品质、实验室等多岗位的业务文档，字段包含钻孔孔径、层压温度、槽液浓度等专业参数，格式涵盖结构化表格与非结构化报告。

## 这些特征在「部署与升级」这一环带来什么约束
PCB制造的多源异构台账数据，要求部署时需支持多格式文件解析与结构化存储，需配置`STORAGE_S3_ENDPOINT`存储原始Gerber、AOI等附件。高频次的生产批更新会带来并发写入压力，需调整数据库连接池参数避免连接耗尽。多工序关联的台账需缓存元数据以提升查询效率，需配置`REDIS_URL`搭建稳定缓存服务。台账字段包含专业单位参数，部署时需配置结构化数据库存储字段校验规则，避免数据格式错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:27017/pcb_prod?authSource=admin` | 存储多工序关联的结构化台账数据，需指定业务库与认证源 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 缓存高频访问的生产批台账元数据，减少数据库查询压力 |
| `STORAGE_S3_ENDPOINT` | `http://s3-cn-south-1.example.com` | 存储Gerber文件、AOI报告等原始台账附件，需匹配对象存储服务地址 |
| `DB_MAX_LINK` | `200 个` | 应对每班连续采集的高频数据库写入请求，避免连接耗尽 |
| `PG_URL` | `postgresql://username:password@host:5432/pcb_measure?sslmode=require` | 存储槽液化验、电测等带单位的结构化测量数据，需支持事务性更新 |
| `ROOT_KEY` | `按实测标定` | 开启插件加载权限，确保文件加工等功能插件可正常注册 |

## 容易做错的三处
- 现象：执行docker启动marker_images容器时返回端口占用或镜像拉取失败，原因：未提前开放7231端口或镜像仓库权限配置错误。
- 现象：升级FastGPT v4.17.0后，通过URL导入Gerber格式台账文件时报错，后台日志提示cannot fetch internal url，原因：未配置`FE_DOMAIN`为工厂内网可访问的服务域名，导致内部URL校验失败。
- 现象：后台插件列表中无法找到文件加工插件，原因：部署时未挂载对应插件目录或未配置`ROOT_KEY`开启插件权限，导致插件加载失败。

## 怎么确认配好了
- 执行数据库连接测试命令，验证`MONGODB_URI`与`PG_URL`配置的连接有效性，确认可读写对应业务库。
- 启动Redis服务并执行ping命令，验证`REDIS_URL`配置的缓存服务可正常连通。
- 上传一份测试用Gerber文件，通过台账导入功能验证`STORAGE_S3_ENDPOINT`配置的存储服务可正常接收与读取文件。
- 重启FastGPT服务后查看后台日志，确认无数据库连接超时、插件加载失败相关报错。
