# SMT贴片与电子组装的生产台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
SMT贴片与电子组装的生产数据来源包括MES系统、贴片机、SPI/AOI检测设备、回流焊炉温记录仪等。日常文档涵盖BOM与坐标文件、换线表、钢网与炉温记录、首件确认单、SPI/AOI检测报告、维修记录、追溯标签等，字段包含料号、位号、元件批次、炉温参数、检测缺陷项等，单位涉及毫米、摄氏度、批次号等。数据更新频率为每工单、每次换线实时同步，部分检测数据随检测完成即时更新。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据来源分散且更新实时，要求模型接入需适配多格式文档的解析需求，包括结构化表格与图像类检测报告。多工单的高频更新会导致上下文规模快速扩张，需严格控制传入模型的上下文长度，避免超出模型承载上限。同时，台账数据的准确性直接关联生产防错与追溯，要求模型生成的字段需严格匹配预设的料号、位号等业务字段，不能出现字段缺失或错误映射的情况。此外，本地与线上大模型的参数适配差异，也需要针对SMT场景的文档规模进行针对性调整。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配单工单多文档拼接的上下文需求，避免因上下文溢出导致调用失败 |
| `maxTokens` | 4000 token | 控制单轮台账报告的生成长度，符合生产文档的常规输出规模 |
| `temperature` | 0.1–0.3 | 降低随机生成概率，保障台账中料号、位号等关键业务字段的准确性 |
| `vision` | 开启 | 用于解析SPI/AOI检测报告的图像数据，提取焊点缺陷、元件偏移等可视化信息 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配本地或线上大模型的接入路径，确保接口调用可达 |
| `AIPROXY_API_TOKEN` | 按平台分配值填写 | 保障模型接口调用的身份验证安全 |

## 容易做错的三处
- 现象：本地大模型调用时返回`400 Bad Request`报错。原因：未针对本地大模型调整`maxContext`参数，传入的上下文长度超出模型支持的最大上下文阈值。
- 现象：生成的台账中SPI/AOI检测的缺陷数据字段为空。原因：未开启`vision`参数，无法解析检测报告的图像内容，导致关键业务信息丢失。
- 现象：调用接口后长时间无响应并触发超时。原因：未正确配置`AIPROXY_API_ENDPOINT`，指向了错误的模型服务地址，导致请求无法正常建立连接。

## 怎么确认配好了
- 上传一份测试用的SMT工单BOM与SPI检测报告，触发台账生成流程，检查是否能正确提取料号、位号、元件批次等核心字段。
- 查看FastGPT v4.17.0的接口调用日志，确认`AIPROXY_API_TOKEN`验证通过，无401权限报错。
- 调整`temperature`参数至0.2与0.3，对比两次生成的台账内容，确认差异在业务可接受范围内。
- 上传多张不同类型的SPI/AOI图像报告，检查模型是否能正确识别图像中的缺陷数据并写入对应台账字段。
