# 乳制品加工的生产台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
该品类的数据覆盖液态奶、酸奶、奶粉及乳配料生产全流程，日常文档包含原奶验收记录、标准化配料单、巴氏或UHT热处理记录、CIP清洗记录、灌装记录、留样与微检报告。数据来源涵盖奶源检测、生产MES系统、均质与热处理设备、在线温流量采集模块、CIP系统、LIMS实验室管理系统，更新节奏为每奶罐、每生产批次实时同步。单份文档包含批次编号、检测数值、设备参数等字段，数值单位包含mg/kg、g/100g、℃、秒、CFU/mL等。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据特征对工具调用与插件环节带来多重约束。多源异构的数据来源要求配置多工具的鉴权与数据拉取规则，分别对接奶源检测、MES、设备及LIMS系统。强批次绑定的更新节奏要求工具调用时必须以生产批次编号作为核心过滤条件，避免跨批次数据混入。字段单位不统一的文档结构，要求工具调用后自动完成单位转换与字段标准化，确保汇总数据的一致性。实时更新的特性要求工具调用的响应时效匹配生产节拍，避免数据滞后影响台账生成。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工具调用触发条件 | 按生产批次编号触发 | 匹配该品类批次强绑定的数据特征，避免跨批次数据混入 |
| 多工具并行调用上限 | 前3个工具 | 平衡数据拉取效率与系统负载，适配多源数据对接场景 |
| 字段标准化规则 | 统一转换为℃、秒、mg/kg、CFU/mL等标准单位 | 适配品类内多源文档的单位差异 |
| `toolChoice` | auto | 允许模型自主选择匹配业务场景的工具完成数据拉取与汇总 |
| `functionCall` | 仅在明确需要指定工具时启用 | 避免模型误调用非必要工具，简化调用逻辑 |
| 响应超时阈值 | 600秒 | 匹配实时生产的响应时效要求，避免数据滞后影响台账生成 |
| 结果过滤规则 | 仅保留当前批次关联字段 | 确保生成的台账仅对应目标生产批次 |

本文档适用于FastGPT v4.17.0版本。

## 容易做错的三处
- 调用日志显示获取数据异常、模型渠道返回error。原因：未配置按生产批次编号触发工具调用，导致拉取跨批次的冗余数据，超出接口数据返回限制。
- 文本提取工具返回400 Invalid JSON payload received. Unknown name报错。原因：工具调用时传入了未在接口文档中定义的自定义字段，例如直接传入了品类特有的字段但未在工具参数中声明。
- 升级PgVector插件后无法正常拉取设备数据。原因：未更新插件的数据源鉴权配置，导致与原有CIP系统、MES系统的对接权限失效。

## 怎么确认配好了
- 手动输入某生产批次编号，触发工具调用，核对返回的数据是否仅包含该批次的相关记录。
- 查看工具调用日志，确认所有调用的工具均为预先配置的多源对接工具，且无未声明的字段传入。
- 检查PgVector插件版本，确认已更新至适配当前FastGPT版本的最新版本，且鉴权配置正确。
- 模拟实时数据更新，触发台账生成，核对响应时长是否符合预设的时效要求。
