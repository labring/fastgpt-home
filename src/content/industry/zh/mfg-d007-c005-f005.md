# 光伏电池片制造的生产台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
光伏电池片制造的生产台账数据来源覆盖硅片来料入库、车间MES系统、扩散炉/镀膜设备/印刷机的实时运行数据、EL与IV测试的片级检测结果，以及实验室抽检数据。数据更新节奏包含每批次生产记录、每片电池的检测数据，以及每日汇总的车间运行数据。常见文档类型包括工艺卡、扩散与镀膜参数表、印刷烧结工序记录、EL缺陷检测图、IV分档数据表、良率分析报告，字段包含工艺温度、镀膜厚度、栅线宽度、缺陷坐标、转换效率、分档等级等，对应单位多为摄氏度、微米、瓦、等级标识。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源异构的数据来源要求工具调用需适配不同类型的数据源插件，包括结构化参数拉取、图像解析、数值计算工具。高频的更新节奏要求工具调用需匹配实时或准实时的数据拉取频率，避免引入延迟或过期数据。多样的文档类型需要工具支持跨格式解析，例如将EL检测图的缺陷坐标转换为结构化字段，或将IV测试的原始数据转换为转换效率数值。片级的细粒度数据会增加单次工具调用返回的信息量，需要限制工具调用的输出规模，防止超出模型上下文窗口。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工具调用模式 | `auto`（由模型自主选择工具） | 适配多类型工具调用需求，覆盖工艺参数拉取、缺陷检测、数据汇总等场景 |
| 单次工具调用上限 | `10–15 次` | 匹配光伏电池片生产的多工序台账拉取需求，避免单次调用返回过多数据 |
| 上下文窗口限制 | `8192–16384 token` | 适配光伏台账的多字段、多批次数据汇总需求，覆盖常见大模型的上下文容量 |
| 工具调用超时时间 | `300 秒` | 适配设备数据拉取的延迟情况，避免因设备响应慢导致调用失败 |
| 数据源缓存周期 | `24 小时` | 匹配每日汇总的生产台账更新节奏，减少重复拉取设备数据的开销 |

## 容易做错的三处
- 现象：生成的生产台账缺少扩散炉或镀膜设备的参数字段，对应字段为空。原因：未正确配置对应设备数据源的MCP服务代理地址，未完成工具绑定。
- 现象：工具调用触发失败，返回400状态码或“未匹配可用工具”提示。原因：未设置合理的工具调用模式，或未启用所需的插件服务。
- 现象：生成报告时出现上下文截断或“上下文长度不足”的报错。原因：未限制单次工具调用的返回条目数，导致累计数据超出模型上下文窗口。

## 怎么确认配好了
- 提交包含“拉取批次号为P20240520的扩散炉工艺参数”的请求，验证工具能否成功拉取对应数据并填入台账。
- 提交包含“解析EL检测图中的隐裂缺陷”的请求，确认工具能触发图像解析插件并返回结构化缺陷坐标。
- 查看工具调用日志，确认单次调用的返回条目数未超出设定的单次工具调用上限。
- 提交包含3个批次以上的生产数据汇总请求，验证上下文窗口限制未触发溢出报错。
