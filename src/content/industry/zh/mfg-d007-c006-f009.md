# 光伏组件封装的生产台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
光伏组件封装环节的数据来源包括电池片分档系统、玻璃胶膜背板批次台账、车间MES系统、串焊与层压设备采集数据、EL/IV测试仪输出报告。数据更新节奏为每块组件生成对应唯一的台账记录，每批原材料同步更新批次信息。日常文档包含排版图、材料批次记录、层压工艺参数记录、EL缺陷图、IV测试报告、绝缘耐压检测记录、成品包装清单，字段涵盖组件编号、电池片电流档位、层压温度时长、隐裂位置等级、功率值、耐压数值等。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据更新频率高且单条体量小，要求模型接入配置需适配实时小批量数据处理，避免上下文溢出。多类型文档并存，包含结构化参数记录与图像类EL缺陷图，需配置支持视觉识别的模型能力。专业字段如电池片电流档位、层压工艺参数需模型准确识别匹配，配置时需确保模型对电子制造专业术语的理解精度。数据来源分散且字段标准化程度不一，需在配置中明确数据映射规则，减少后续汇总误差。

## 配置怎么定
本文基于FastGPT v4.17.0版本的配置逻辑编写。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单批次组件台账的多文档拼接，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 匹配单份报告生成的输出长度，覆盖所有字段汇总需求 |
| `vision` | 开启 | 支持EL缺陷图、IV测试报告图像的内容识别，匹配品类内图像类文档处理需求 |
| `temperature` | 0.1–0.3 | 降低输出随机性，确保专业参数汇总的准确性 |
| `AIPROXY_API_ENDPOINT` | http://{内网部署IP}:8001/v1 | 适配内网部署场景，确保数据传输安全 |
| `AIPROXY_API_TOKEN` | 部署生成的访问密钥 | 验证模型调用权限，防止未授权访问 |

## 容易做错的三处
- 现象：部署rerank模型后，FastGPT平台未显示对应模型选项。原因：未在系统配置文件中正确添加rerank模型的接入配置，或部署地址未加入允许访问的白名单。
- 现象：配置模型为v2版本后，实际调用仍使用v1版本。原因：平台选择的模型名称与配置文件中注册的模型名称不一致，或配置文件未正确重载生效。
- 现象：内网部署模型后，服务进程反复重启。原因：内网环境下未配置正确的网络访问权限，导致模型依赖的外部资源无法加载，或启动参数中内存分配不足。

## 怎么确认配好了
- 进入FastGPT的模型管理页面，查看已接入的模型列表，确认目标模型已正常显示。
- 发起一次模拟调用，输入包含EL图参数与层压记录的测试数据，检查输出结果是否包含对应字段的准确汇总。
- 查看平台日志，确认模型调用请求的参数与配置项一致，无参数缺失或错误。
- 测试内网环境下的模型调用连通性，确认请求能正常到达部署地址并返回有效结果。
