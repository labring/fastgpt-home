# 光伏组件封装的生产台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据来源包括电池片分档系统、玻璃胶膜背板批次台账、车间MES系统、串焊与层压生产设备、EL/IV测试仪。数据更新节奏为每块组件产出同步更新，每批原材料入库即生成批次记录。日常文档涵盖排版图、材料批次记录、层压工艺参数记录、EL缺陷图、IV功率测试报告、绝缘耐压记录、成品包装清单。数据字段包含电池片电流档位、层压温度与保温时长、EL隐裂坐标、IV测试功率值等，对应单位为安培、摄氏度、秒、瓦。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据特征对检索召回环节带来多重约束。高频实时更新的单组件数据要求检索响应速度匹配车间生产节拍，避免拖慢台账汇总流程。多类型异构文档并存，包括图文混合的EL缺陷图、数值型测试报告与纯文本工艺记录，需要适配不同模态的召回匹配规则。批次级原材料数据与单组件生产数据的关联检索，要求明确数据关联维度，避免召回结果错位。强关联字段如电池片电流档位、层压工艺参数的精准匹配需求，要求检索模式支持精确匹配与语义召回结合的策略。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配电池片电流档位、层压参数等强关联字段，避免召回低相关的工艺记录 |
| `limit` | 前8条 | 覆盖单组件对应的层压、串焊、测试环节的至少3类文档，同时控制上下文长度 |
| `searchMode` | hybrid | 结合语义召回与精确匹配，适配异构文档的检索需求，兼顾EL图与文本记录的召回效果 |
| `usingReRank` | 开启 | 对初始召回结果重排，优先匹配EL隐裂判读、IV功率测试这类核心业务字段的关联度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展批次材料与单组件数据的关联查询，解决跨维度数据检索的遗漏问题 |
| `collectionIds` | 绑定串焊、层压、测试环节的知识库集合 | 精准限定检索范围，避免混入其他品类的文档数据 |

## 容易做错的三处
- 现象为调用API同步知识库集合时返回身份验证不通过的报错。原因未配置知识库绑定的API密钥权限，或密钥已过期失效。
- 现象为点击知识库新增文件夹后弹出provider相关报错。原因未正确关联对应生产文档的知识库数据源，或数据源配置格式不符合要求。
- 现象为检索EL图与IV测试报告的组合数据时超时，单次检索耗时超过10秒。原因未开启重排功能或未限定检索集合范围，导致召回过多无关文档占用计算资源。

## 怎么确认配好了
- 上传单批次电池片批次记录与单组件EL图，执行检索，核对召回结果包含对应环节的工艺参数文档。
- 查看检索日志，确认返回的召回结果数量符合`limit`配置的取值范围。
- 测试API调用同步知识库集合，确认返回状态码为200且无身份验证报错。
- 模拟高频检索场景，核对单次检索耗时符合车间生产节拍要求，具体阈值按实测标定。
