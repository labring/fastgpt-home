# 光伏组件封装的生产台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
光伏组件封装的生产台账数据来源包括电池片分档记录、玻璃胶膜背板批次档案、工厂MES系统、串焊与层压设备日志、EL测试仪与IV功率测试仪输出、绝缘耐压测试记录等。数据更新节奏为每块组件生成一次，每批原材料同步更新批次信息。日常归档文档包含排版图、材料批次记录、层压工艺参数记录、EL缺陷图像、IV测试报告、绝缘耐压记录、包装出货清单等。数据字段包含组件唯一编号、电池片电流档位、层压温度与时间、EL隐裂位置坐标、IV测试功率值、绝缘耐压数值等，单位涵盖摄氏度、秒、瓦特、兆帕等专业工业单位。

## 这些特征在「部署与升级」这一环带来什么约束
光伏组件封装的生产台账数据来源分散、更新频率高且文档类型多样，对FastGPT的部署与升级带来多重约束。多数据源对接需要配置多个数据连接参数，避免字段映射错误；高更新频率要求缓存与数据库连接数适配并发写入需求，防止连接耗尽；多类型文档存储需要适配图像、表格、日志等多种格式，需配置兼容的存储后端；专业工业字段的关联分析需要准确的字段匹配规则，避免台账汇总时数据错位。此外，光伏组件封装需关联电池片档位与功率分档结果，部署时需额外配置字段关联逻辑，确保报告生成的准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `REDIS_URL` | `redis://:自定义密码@redis服务地址:6379/0` | 光伏组件台账数据更新频繁，需低延迟缓存会话与临时索引，6379为Redis默认端口，数据库0用于隔离业务数据 |
| `MONGODB_URI` | `mongodb://用户名:自定义密码@mongodb服务地址:27017/fastgpt?authSource=admin` | 存储EL图、IV测试报告等非结构化文档，MongoDB适配多格式文件存储需求 |
| `STORAGE_S3_ENDPOINT` | `http://minio服务地址:9000` | 存储批量生产文档，9000为MinIO默认端口，适配小文件批量上传场景 |
| `DB_MAX_LINK` | `50–80 个` | 多设备数据同时写入，避免数据库连接耗尽，具体数值按实测场景标定 |
| `ROOT_KEY` | `32位随机十六进制字符串` | 替代默认密钥，防止Root账号密码被自动重置，提升管理员账号安全性 |
| `FILE_TOKEN_KEY` | `16位随机字符串` | 生成文件访问令牌，防止未授权访问生产文档与测试图像 |

## 容易做错的三处
- 现象：部署时Redis镜像拉取失败或容器启动失败。原因：未正确填写`REDIS_URL`中的访问密码或端口，或使用了与FastGPT v4.17.0不兼容的Redis镜像版本。
- 现象：登录系统后返回`{"code":500,"statusText":"","message":"URI malformed`报错。原因：`FE_DOMAIN`配置未添加协议前缀（如未写入http://），或域名格式存在非法字符，导致前端回调URI解析失败。
- 现象：Root账号密码每隔一天自动重置为123456。原因：未修改默认`ROOT_KEY`配置，FastGPT部分旧版本存在默认密钥下的密码重置机制，未自定义密钥导致配置被覆盖。

## 怎么确认配好了
- 执行`docker-compose ps`命令，确认Redis、MongoDB等依赖服务的容器状态均为Up。
- 访问`FE_DOMAIN`配置的访问地址，使用Root账号尝试登录，验证无500报错出现。
- 上传一份EL测试图像或IV测试报告文件，确认文件能正常上传并在文档管理列表中显示。
- 查看数据库连接日志，确认当前连接数未超过`DB_MAX_LINK`配置的阈值，无连接耗尽告警。
