# 冲压与板材成形的生产台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
该品类的数据主要来自钢卷标签与质保书、冲床和送料机运行数据、模具管理系统、MES系统、三坐标或检具检验数据。日常产生的文档包含冲压作业指导书、材料利用率表、模具点检表、首末件记录、尺寸检验报告、换模记录。数据更新频率为每卷料、每批生产或每次换模时更新，字段包含材料规格、冲压参数、模具状态、检验结果等，无统一固定格式，随生产批次与换模操作动态变化。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据来源分散且更新频率高，部署时需适配多源异构数据的接入配置，预留多数据接口的适配空间。日常生产文档无固定格式，部署时需配置灵活的文档解析规则，适配不同类型的生产台账字段。换模与批次更新频繁，升级时需保证数据同步的实时性，避免因升级中断导致生产数据丢失。依赖模具与设备的运行数据，部署环节需验证与现有车间设备系统的兼容性，确保数据采集链路稳定，避免因配置不兼容导致数据采集异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `DB_MAX_LINK` | `100–200 个并发连接` | 适配多源生产数据的并发读取需求，避免数据库连接耗尽，支撑高频更新的生产台账查询 |
| `MONGODB_URI` | `存储生产台账的 MongoDB 集群地址` | 存储非结构化的生产文档与动态变化的生产记录，适配品类多样的台账数据格式 |
| `PG_URL` | `存储结构化生产参数的 PostgreSQL 数据库地址` | 存储钢卷规格、冲压参数等结构化数据，便于快速查询与统计分析 |
| `REDIS_URL` | `本地 Redis 服务地址，端口默认 6379` | 缓存高频读取的生产台账数据，降低数据库压力，适配实时更新的生产数据场景 |
| `STORAGE_S3_ENDPOINT` | `车间本地对象存储服务地址` | 存储批量上传的生产文档，确保数据本地化存储符合车间数据安全要求 |
| `FILE_TOKEN_KEY` | `与车间文件系统一致的加密密钥` | 验证文件上传请求的合法性，防止未授权的生产文档上传，保障车间数据安全 |

## 容易做错的三处
- 现象：工作流中配置文件上传节点后，解析文件地址时返回权限错误或空结果。原因：未正确配置`FILE_TOKEN_KEY`，导致无法验证本地文件系统的访问权限，无法读取上传的生产文档。
- 现象：外部平台调用聊天接口时响应超时，耗时超出预期。原因：未合理配置`DB_MAX_LINK`，并发连接数不足，导致多源生产数据查询堆积，接口响应延迟。
- 现象：本地编译部署FastGPT v4.17.0时出现依赖包加载失败。原因：未使用适配当前版本的依赖包版本，或未正确配置`FE_DOMAIN`导致静态资源加载异常。

## 怎么确认配好了
- 执行数据库连接测试，验证`MONGODB_URI`与`PG_URL`配置的数据库可正常读写对应类型的生产数据。
- 上传一份冲压作业指导书文档，通过文档解析节点验证可正常读取文档内容，确认`STORAGE_S3_ENDPOINT`与`FILE_TOKEN_KEY`配置生效。
- 调用外部聊天接口，验证响应符合预期，确认`FE_DOMAIN`与`REDIS_URL`配置适配内网访问场景。
- 模拟一次换模后的生产数据上传，验证数据可正常同步至数据库，确认`DB_MAX_LINK`配置的并发连接数满足当前生产场景的需求。
