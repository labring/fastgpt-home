# 化妆品生产的生产台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
化妆品生产的数据来自注册备案配方、原料安全资料、称量乳化设备、ERP/MES系统、实验室检测记录与包材版本台账。日常文档包含配方工艺单、称量投料记录、乳化灌装记录、清场清洁记录、半成品与成品检验报告、标签审核表。数据更新随每批生产或换线触发，字段包含生产批号、原料名称与用量、限用物质含量、乳化温度、均质时长、包材版本号等，单位涉及摄氏度、千克、分钟等。

## 这些特征在「模型接入与配置」这一环带来什么约束
化妆品生产的批次化高频更新数据，要求模型接入时支持按生产批次同步数据源，避免静态知识库的信息滞后。多类型专业文档与专属字段，要求配置适配配方工艺、检验记录等格式的解析规则，确保专业字段如限用物质含量、生产批号可被准确识别。因出错后果涉及合规与召回风险，需配置严格的结果校验逻辑，同时需关联备案数据源，确保生产数据与备案信息的一致性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 需容纳单批次多份文档的内容，避免截断关键备案与生产数据 |
| `maxTokens` | 4000–6000 token | 满足台账汇总与合规报告的输出长度，覆盖所有批次细节与校验说明 |
| `quoteMaxToken` | 1500–2000 token | 确保引用的原料备案、检验记录等片段完整，不丢失专业信息 |
| `temperature` | 0.1–0.3 | 降低输出随机性，保证合规报告的表述严谨，避免配方数据偏差 |
| `AIPROXY_API_ENDPOINT` | 按平台部署节点填写 | 适配本地或云部署的访问路径，确保数据传输稳定 |
| `AIPROXY_API_TOKEN` | 按权限分配的专属密钥 | 保障接口调用的安全性，避免未授权访问生产数据 |

## 容易做错的三处
- 现象：新建知识库后无法调用图片理解模型处理工艺单扫描件。原因：未在配置中开启`vision`参数，或本地部署未加载对应视觉模型依赖。
- 现象：知识库搜索后仅返回匹配内容，未对未匹配的合规问题进行推理。原因：未正确配置模型的推理触发逻辑，误将搜索匹配结果作为唯一输出依据。
- 现象：接口调用返回401状态码，无法完成台账同步。原因：`AIPROXY_API_TOKEN`配置错误，或密钥权限未覆盖生产数据源的访问范围。

## 怎么确认配好了
- 上传单批次的配方工艺单与备案配方，核对模型输出的原料对比结果是否包含限用物质校验内容。
- 调用接口同步近一次换线的生产记录，检查返回的台账数据是否包含所有必填字段与对应单位。
- 查看接口日志，确认`maxContext`参数未触发内容截断，输出内容完整覆盖上传文档。
- 测试未在知识库内的合规校验问题，确认模型可基于现有规则进行合理推理。
