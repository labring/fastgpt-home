# 医疗器械装配与洁净生产的生产台账汇总与报告生成：向量模型与索引

## 这个品类的数据长什么样
本品类的核心数据来自一次性耗材、植介入器械、诊断设备及有源器械制造商的生产全流程。日常文档包含生产工艺规程、批生产记录、洁净区记录、灭菌批记录、检验报告、软件版本记录及不良事件与追溯资料。数据来源覆盖设计历史文件、器件与材料批次台账、MES系统、洁净环境监测设备、灭菌设备、检验和校准系统。数据更新以每批或每台产品为周期，同时按环境监测计划定期同步洁净区相关记录。文档字段包含唯一标识、批次号、时间戳、检测数值等生产相关属性。

## 这些特征在「向量模型与索引」这一环带来什么约束
多源异构的数据来源导致文档格式、字段结构存在差异，要求向量模型具备适配非结构化与半结构化数据的能力。按批次或周期的更新频率，要求索引支持增量更新逻辑，避免全量重建带来的资源消耗。文档中包含的唯一标识、追溯信息等高敏感字段，要求索引过程保留元数据关联，确保后续报告生成可追溯数据来源。高风险的生产场景要求召回结果具备较高置信度，需调整索引的召回规则以过滤低相关内容。洁净生产相关的环境监测数据包含时间序列属性，分块策略需保留上下文关联，避免破坏数据的时间逻辑。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，适配本品类的生产台账汇总与报告生成场景：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| maxToken | 8192 token | 适配批生产记录、灭菌批记录等长文档内容，覆盖完整生产批次的信息范围 |
| defaultToken | 2048 token | 用于日常台账片段的向量生成，平衡召回精度与计算资源开销 |
| 分块长度 | 800–1200 字符 | 匹配洁净区记录、检验报告的单页内容长度，避免跨批次信息的错误拼接 |
| 重叠长度 | 100–200 字符 | 保留批次间的关键关联信息，防止分块破坏追溯逻辑 |
| 相似度阈值 | 0.75–0.85 | 适配高风险生产场景的召回精度，过滤非生产类的低相关文档 |
| 单次搜索上限 | 前 8 条 | 控制召回结果的数量，避免冗余数据干扰生产台账的汇总与报告生成 |

## 容易做错的三处
- 知识库上传后无索引条目，界面显示索引任务停滞。原因是未正确配置m3e embedding模型的可用频道，未完成模型与知识库的绑定流程。
- 部署后向量数据库连接失败，启动时报错提示无法找到指定服务。原因是仅启动了MongoDB和向量数据库镜像，未同步启动sandbox容器用于本地模型运行与数据处理。
- 重复提交相同查询导致系统响应延迟。原因是未启用缓存优化机制，未配置重复查询的缓存规则，导致每次请求都触发向量数据库的检索流程。

## 怎么确认配好了
- 上传单份批生产记录文档，查看索引任务的运行日志，确认向量生成进度正常完成，无报错信息。
- 输入与洁净区环境监测相关的查询词，核对召回结果的文档类型与来源，确认匹配预期的数据源范围。
- 测试重复提交相同的生产台账查询，确认首次查询后后续请求的响应时间显著缩短，验证缓存机制生效。
- 进入向量模型配置页面，检查m3e模型的可用频道状态，确认无未授权的模型调用报错。
