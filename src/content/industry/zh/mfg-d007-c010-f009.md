# 医疗器械装配与洁净生产的生产台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
本品类数据来源于设计历史文件、器件与材料批次、MES系统、洁净环境监测设备、灭菌设备、检验和校准系统。日常文档包含生产工艺规程、批生产记录、洁净区记录、灭菌批记录、检验报告、软件版本记录、不良事件与追溯资料。数据更新频率为每批或每台产品，或按洁净环境监测计划执行。数据字段包含器械唯一标识、材料批次号、洁净环境参数、灭菌参数、检验结果等，附带日期、批次编号等单位化标识。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类的多源分散数据来源要求模型接入需支持跨系统数据聚合，避免手动整理的额外成本。按批次或计划的更新频率，要求模型上下文窗口需适配单批次全量台账数据的长度，防止因上下文不足导致信息遗漏。专属字段如器械唯一标识、灭菌参数等，要求配置时需明确指定数据提取规则，避免生成内容偏离生产合规要求。同时，不良事件与追溯资料的强关联需求，要求需保留原始数据引用片段，防止出现无法追溯的生成结果。

## 配置怎么定
本配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 本品类单批次台账包含多份关联文档，需容纳全量输入数据 |
| `maxTokens` | `2000–3000 token` | 保障汇总报告的完整输出，避免关键内容被截断 |
| `quoteMaxToken` | `1500 token` | 保留足够长度的原始台账引用片段，满足追溯要求 |
| `temperature` | `0.1–0.3` | 降低生成内容的随机性，适配医疗器械生产的高精度要求 |
| `AIPROXY_API_ENDPOINT` | 按部署的代理服务地址填写 | 解决平台内置模型列表无法覆盖小众或自研模型的问题 |
| `AIPROXY_API_TOKEN` | 按代理服务生成的密钥填写 | 保障接口调用的身份验证安全 |

## 容易做错的三处
- 现象为部分小众或自研模型无法在平台内置列表中选择，调用时返回接口未配置错误。原因是未通过代理服务配置自定义模型接入地址，直接依赖平台默认模型库。
- 现象为接口调用频繁超时，日志返回连接重置或请求超时状态码。原因是未合理设置`maxContext`与`maxTokens`参数，单次请求数据量超出代理服务的限制阈值。
- 现象为生成的报告缺少医疗器械唯一标识、灭菌批记录编号等专属字段，对应字段为空。原因是未在配置中明确指定需提取的专属数据字段，或`quoteMaxToken`设置过小导致引用片段被截断。

## 怎么确认配好了
- 输入单批次医疗器械的完整台账数据，调用生成接口，检查返回的报告是否包含所有要求的专属业务字段。
- 查看代理服务的运行日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置无误，无401、404或500类报错。
- 调整`temperature`参数为0.1后，多次生成同一份台账的报告，检查结果的一致性是否符合生产数据的严谨性要求。
- 测试超大数据量的台账输入，确认`maxContext`与`maxTokens`参数设置后，请求未出现超时或内容截断问题。
