# 半导体封装测试的生产台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
本品类的数据覆盖封装全流程，来源包括晶圆测试图、MES系统、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格文档。日常文档包含封装流程卡、键合与塑封参数表、晶圆来料图、测试程序版本文件、良率报告与失效分析报告。数据更新频率为每生产批次、每颗芯片测试及每日一次，字段涵盖批次号、键合功率、塑封压力、测试bin码、晶圆坐标等，无统一固定格式，需适配多源异构数据特征。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源异构的数据来源要求插件需支持对接多个不同API端点，且需配置统一的字段映射规则，避免不同设备与系统的数据格式不兼容。高更新频率要求工具调用需支持定时触发与事件触发两种模式，分别适配每日汇总与单批次生产完成后的实时台账更新。多样的文档类型要求插件可处理表格、文本、图像类输入，适配晶圆来料图等非结构化数据。严重的质量出错后果要求工具调用需配置失败重试与告警机制，避免因数据异常导致混批、错程序等问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| 工作流/API 工具选择配置 | `auto` | 适配多类型插件调用，自动选择合适的工具执行逻辑，覆盖不同数据源的调用需求 |
| 工作流/API 函数调用配置 | `{"name":"get_production_data","parameters":{"batch_id":"${var_batch_id}"}}` | 明确指定调用生产数据获取插件，绑定工作流传入的批次变量，确保调用目标精准 |
| 插件触发时机 | 每日凌晨2点 + 每批次生产完成后10分钟内 | 匹配品类数据每日、每批次的更新频率，保证台账数据的实时性 |
| 参数 fallback 规则 | 优先使用工作流传入变量，变量缺失时使用插件预设默认值 | 适配动态参数传递场景，避免因变量缺失导致调用失败 |
| 超时设置 | 300秒 | 覆盖多设备数据拉取的平均耗时，避免长时间阻塞工作流 |
| 重试次数 | 2次 | 应对临时网络波动或设备短暂离线，减少无效调用次数 |

## 容易做错的三处
- 现象：调用ATE测试机数据插件时返回跨域错误，状态码403。原因：未在FastGPT插件配置中添加对应设备API的跨域白名单。
- 现象：工作流中调用生产台账生成插件后，部分字段为空。原因：未正确配置参数 fallback 规则，工作流传入的变量缺失且未启用插件默认值。
- 现象：插件调用超时，工作流标记为失败。原因：超时设置时长短于多设备数据拉取的总耗时，未匹配品类数据来源多、拉取步骤多的特征。

## 怎么确认配好了
- 手动触发一次插件调用，查看返回结果是否包含封装流程卡、测试bin分布等品类专属字段。
- 检查插件配置中的跨域白名单，确认已添加所有对接设备与系统的API域名。
- 模拟变量缺失场景，验证插件是否自动使用预设默认值完成调用。
- 查看FastGPT v4.17.0版本的工作流日志，确认插件调用的触发时机与数据更新频率匹配。
