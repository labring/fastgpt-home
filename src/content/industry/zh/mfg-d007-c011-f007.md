# 半导体封装测试的生产台账汇总与报告生成：数据库与运维

## 这个品类的数据长什么样
该品类的数据来源包含晶圆测试图、MES系统、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格文档。数据更新节奏分为每批、每颗测试、每日三类，日常文档涵盖封装流程卡、键合与塑封参数、晶圆来料图、测试程序版本、良率报告、失效分析报告。数据字段包含批次号、晶圆ID、键合温度、塑封压力、测试bin码、良率数值等，单位涉及摄氏度、帕斯卡、秒等。

## 这些特征在「数据库与运维」这一环带来什么约束
多源异构的数据来源要求数据库支持结构化与非结构化数据混合存储，同时需建立统一的字段映射规则，对齐不同设备与系统的批次标识。高频更新节奏带来高并发写入需求，需配置足够的数据库连接资源避免写入阻塞。多样的文档类型要求数据库支持关联查询，以完成晶圆图与实物批次的匹配校验。数据一致性要求严格，任何字段偏差都可能引发生产异常，需配置基础的数据校验约束。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `MONGODB_URI` | `mongodb://fastgpt_seal:自定义密码@数据库主机:27017/seal_test_db?authSource=admin` | 存储ATE测试原始数据、晶圆来料图元数据等非结构化业务数据，绑定专属数据库权限避免越权访问 |
| `PG_URL` | `postgresql://fastgpt_ledger:自定义密码@数据库主机:5432/production_ledger?sslmode=require` | 存储结构化生产台账数据，支持批次与测试数据的关联查询，适配复杂统计逻辑 |
| `DB_MAX_LINK` | `20–30 个连接` | 适配每批测试的并发写入请求，避免连接耗尽导致的写入失败 |
| `REDIS_URL` | `redis://:自定义密码@缓存主机:6379/0` | 缓存高频访问的测试程序版本、晶圆图索引，降低数据库的重复查询负载 |

## 容易做错的三处
- 现象为MongoDB连接报错`Authentication failed`，原因是未创建fastgpt专属数据库用户，直接使用root用户连接触发权限校验失败。
- 现象为调用MySQL工具时返回400 status code (no body)，原因是数据库连接字符串配置错误，或数据库未开放对应端口的外部访问权限。
- 现象为数据库写入延迟过高，导致台账数据与实际生产批次出现偏差，原因是`DB_MAX_LINK`取值过低，无法支撑高并发的设备数据写入请求。

## 怎么确认配好了
- 执行MongoDB连接命令，使用`MONGODB_URI`配置的用户登录数据库，验证可以正常读写测试数据集合。
- 登录FastGPT v4.17.0后台的数据库配置页面，测试`PG_URL`的连通性，确认可以正常插入结构化台账数据。
- 查看Redis监控面板，确认`REDIS_URL`对应的缓存命中情况符合业务访问频率。
- 模拟单次批量设备数据写入，检查数据库连接数未超过`DB_MAX_LINK`的配置值。
