# 半导体封装测试的生产台账汇总与报告生成：模型接入与配置
本文基于FastGPT v4.17.0版本编写

## 这个品类的数据长什么样
该品类数据来源包括晶圆测试图、MES系统、键合与塑封设备日志、ATE测试机数据、X-ray/SAM检测报告及客户规格书。日常文档涵盖封装流程卡、键合塑封参数表、晶圆来料图、测试程序版本文件、良率报告与失效分析报告。数据更新节奏为每生产批次、每颗芯片测试完成及每日汇总。字段包含晶圆编号、批次号、键合压力、测试电压、bin码等，对应单位为毫米、牛、伏特等。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类高频细粒度的更新节奏，要求模型接入配置适配增量数据同步的频率，避免上下文溢出。多样的数据类型包含结构化参数、图像检测结果与文本报告，需要配置支持多模态处理的参数以兼容不同格式输入。字段附带专属单位的特征，要求模型调用时需准确匹配字段与单位的对应关系，避免解析错误。分散的数据来源需要统一的接入配置，确保各设备与系统的日志可被正常拉取与解析。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配该品类多批次、多字段的台账数据汇总需求，避免上下文溢出 |
| `maxTokens` | 4000 token | 满足单份良率报告与失效分析报告的完整生成需求 |
| `vision` | 开启 | 用于解析晶圆来料图、X-ray/SAM检测图像等多模态数据 |
| `temperature` | 0.2–0.4 | 保证台账汇总的准确性，避免生成结果出现偏差 |
| `AIPROXY_API_ENDPOINT` | 按实际部署的代理地址填写 | 适配分散的数据来源与跨设备接入需求 |
| `AIPROXY_API_TOKEN` | 按分配的专属令牌填写 | 确保接入的安全性与权限控制 |

## 容易做错的三处
- 现象：调用模型时返回不支持多模态输入的报错。原因：未开启`vision`配置项，或接入的模型未适配多模态能力。
- 现象：配置代理后返回404 body not found报错。原因：`AIPROXY_API_ENDPOINT`填写错误，或与其他代理服务的配置冲突。
- 现象：生成的台账中出现字段单位与实际不符的情况。原因：未针对该品类的专属字段（如键合压力、测试电压）配置单位匹配逻辑，导致模型解析偏差。

## 怎么确认配好了
- 上传一份晶圆来料图与对应批次的MES数据，验证模型可正常解析图像内容并提取相关字段。
- 发起一次台账汇总请求，检查返回结果的上下文长度未超出配置的范围。
- 查看代理服务的运行日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的调用无异常。
- 测试多组不同类型的输入数据，验证模型生成的报告字段与实际业务规则匹配准确。
