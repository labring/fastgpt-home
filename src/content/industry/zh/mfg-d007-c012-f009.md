# 半导体晶圆制造的生产台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
半导体晶圆制造的生产台账数据来源涵盖MES系统、设备FDC模块、缺陷检测与量测设备、晶圆图文件、工艺配方库与实验数据集。数据更新节奏分为每批晶圆流转触发、设备参数实时上报、每日汇总统计三类。日常文档包含工艺流程卡、批次运行记录、设备配方、SPC分析图、异常处置单、缺陷图谱与良率报告，字段包含纳米级工艺参数、批次唯一标识、设备运行时长与跨工序关联节点信息。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据源格式差异，要求接入配置兼容结构化数据库表、半结构化设备日志与非结构化晶圆图文件。不同更新节奏的台账数据，需要配置差异化的增量同步触发规则，避免重复同步或遗漏实时数据。纳米级高精度参数与跨工序的层级关联字段，要求模型能够识别并保留数据的精度与关联关系，避免解析失真。超长工艺链带来的长上下文需求，要求配置足够的上下文容纳量，避免截断关键工序与异常处置信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 晶圆制造台账包含多工序、跨设备的关联数据，需容纳完整批次运行记录与工艺参数，避免关键信息被截断 |
| `maxTokens` | `2000–3000 token` | 单份报告生成的输出长度需覆盖良率分析、异常处置总结与改进建议，确保输出内容完整 |
| `quoteMaxToken` | `1500–2000 token` | 需召回足够的工艺配方、SPC图关联数据作为引用依据，同时控制总上下文长度，避免模型过载 |
| `temperature` | `0.1–0.3` | 台账汇总与报告生成需保持数据准确性，避免生成偏离原始记录的内容 |
| `AIPROXY_API_ENDPOINT` | 按平台提供的专属接入地址填写 | 确保模型调用请求路由正确，降低跨区域访问延迟 |
| `AIPROXY_API_TOKEN` | 按平台分配的专属密钥填写 | 验证调用身份，保障数据传输与模型调用的安全性 |

## 容易做错的三处
- 现象：切换模型后任务无进度且无法回退至原配置，原因：未正确配置模型切换后的上下文重置规则，残留的旧模型调度参数导致任务无法正常推进。
- 现象：生成的报告中缺失晶圆缺陷图谱的关联分析内容，原因：未开启`vision`参数，无法识别并解析嵌入台账中的晶圆图数据。
- 现象：大模型调用偶尔返回空响应，原因：`maxContext`设置过高导致模型上下文溢出，或`AIPROXY_API_TOKEN`配置过期导致鉴权失败。

## 怎么确认配好了
- 使用FastGPT v4.17.0自带的模型调试工具，输入单批次晶圆的台账关键词，核对返回内容是否包含对应工序、设备参数的准确引用。
- 检查模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置无格式错误，无鉴权失败或请求超时日志。
- 调整`temperature`参数至0.2，生成同一份台账的两次报告，核对核心数据的一致性，确认未出现随机偏差。
- 测试多源数据接入场景，验证MES系统与设备FDC的台账数据能否被正确召回并关联展示。
