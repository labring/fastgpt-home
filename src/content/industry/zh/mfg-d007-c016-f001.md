# 变压器与高压电器制造的生产台账汇总与报告生成：HTTP 接口与外部系统

## 这个品类的数据长什么样
变压器与高压电器制造的生产台账数据来源包括设计BOM、硅钢片和绝缘材料库存数据、真空干燥设备运行记录、油化验报告、高压试验站的局放与耐压试验数据。数据更新频率为每台设备出厂前完成一次，每批次原材料入库时同步更新。日常生成的台账文档包含绕制与器身装配记录、真空干燥记录、绝缘油检测报告、局放和耐压试验报告、设备铭牌参数表，字段包含绝缘含水量、局放数值、耐压等级、额定电压等，对应单位为ppm、pC、kV、kV等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据来源分散，覆盖工业设备、化验报告与试验记录，要求HTTP接口支持多数据源的结构化与非结构化数据拉取。单台设备的台账更新频率高且需精准匹配设备ID，接口需支持按批次或设备序列号查询的参数设计。文档包含大体积试验报告，接口需适配文件传输或文件URL返回的格式。数据涉及绝缘性能等核心参数，接口鉴权与数据校验要求严格，避免敏感数据泄露或错误调用。本配置方案适配FastGPT v4.17.0版本的接口功能。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| API鉴权方式 | `Bearer ${企业专属API密钥}` | 该品类生产数据涉及绝缘性能等核心参数，需严格鉴权控制访问权限 |
| 请求变量配置 | `{"batchId": "必填", "deviceSerial": "可选", "reportScope": "all"}` | 适配按批次或单台设备查询台账的业务需求，明确参数必填项减少无效调用 |
| 响应数据过滤 | 仅返回设备标识、绝缘参数、试验结果、文档关联字段，单字段长度不超过1000 字符 | 减少冗余数据传输，控制单接口返回体积，提升生产台账汇总的处理效率 |
| 接口超时时间 | 300 秒 | 适配单份高压试验报告生成的耗时需求，避免正常请求被强制中断 |
| 重试次数 | 2 次 | 应对工业现场网络波动的常见场景，降低单次请求失败的概率 |
| 大文件传输方式 | 返回文件下载URL | 适配绝缘油报告、试验记录等大体积文档的传输需求，减少接口负载 |

## 容易做错的三处
- 现象：调用接口返回401 Unauthorized状态码，原因是`Authorization`参数未配置为有效鉴权密钥，或密钥未绑定对应数据访问权限。
- 现象：接口返回的`responseData`字段缺失局放试验数值，原因是请求时未在`variables`中指定试验报告类型，系统未拉取对应结构化数据。
- 现象：批量拉取多台设备台账时出现超时，原因是未根据该品类单份报告的体积调整超时配置，使用了默认的短超时时长。

## 怎么确认配好了
- 调用接口并传入测试用的有效设备批次ID，检查返回的`responseData`是否包含预设的绝缘参数与试验结果字段。
- 验证`Authorization`参数配置正确，调用接口后无401类鉴权报错。
- 传入不同的`variables`参数组合，确认接口能返回对应范围的生产台账数据。
- 模拟短时间网络波动，重试接口调用，确认配置的重试机制正常生效。
