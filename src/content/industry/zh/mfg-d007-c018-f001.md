# 基础化工连续生产的生产台账汇总与报告生成：HTTP 接口与外部系统

## 这个品类的数据长什么样
基础化工连续生产品类的台账数据来源包括DCS/SIS系统、在线分析仪、LIMS系统、设备状态监测、能源计量装置、原料储罐传感器。数据更新节奏分为实时（工艺参数）、每班（班报、联锁旁路记录）、每日（汇总报表）。日常文档涵盖操作规程、工艺指标卡、DCS趋势图、化验报告、特殊作业票、联锁旁路记录、班报。数据字段包含工艺参数实时值、累计流量、设备运行状态、化验指标数值，单位多为Nm³/h、MPa、wt%等工业标准单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的多源异构数据与差异化更新频率，要求HTTP接口需适配多端点调用与定时触发逻辑。实时工艺数据需高频调用接口，每班、每日的汇总文档需按固定周期触发请求。多数据来源对应多接口鉴权与参数适配需求，需绑定设备、班次等维度变量。文档类型多样，需过滤非台账类数据，同时保障强联锁相关参数的传输准确性，避免因参数错误引发生产风险。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {化工系统专属API_KEY}` | 符合工业外部系统的鉴权规范，保障接口调用合法性 |
| `variables` | `{"device_id": "氯碱装置T01", "time_range": "8h"}` | 匹配基础化工台账的设备维度与时间窗口，精准提取对应生产数据 |
| `responseData` | `["dcs_trend", "lab_report", "shift_report"]` | 过滤并提取该品类核心台账文档，减少无效数据传输 |
| 重试策略 | 3次，间隔60秒 | 应对网络波动与MongoDB副本集主节点切换导致的调用失败 |
| 定时触发周期 | 15分钟（实时数据）、8小时（班报）、24小时（日报） | 匹配该品类数据的实际更新频率，避免无效调用 |

## 容易做错的三处
- 调用接口返回`400 InternalError.Algo.InvalidParameter: Multimodal file size is`报错，原因是未对DCS趋势图、化验报告等大尺寸附件做大小限制，导致参数超限。
- 接口调用持续失败，日志显示MongoDB连接超时，原因是未配置MongoDB Change Streams的重连机制，主节点漂移后无法自动恢复连接。
- HTTP请求体中业务数值字段为空，原因是未在`variables`中正确绑定设备运行参数、化验指标等台账数值，导致参数未传递到请求中。

## 怎么确认配好了
- 发起单次测试调用，检查请求头中`Authorization`字段格式符合`Bearer {API_KEY}`规范。
- 查看请求体内容，确认`variables`中绑定的设备ID、时间范围与生产台账维度一致。
- 验证`responseData`返回的内容包含DCS趋势、化验报告、班报等预期的基础化工台账文档。
- 模拟MongoDB主节点切换场景，确认接口调用能自动重试并恢复正常连接。
