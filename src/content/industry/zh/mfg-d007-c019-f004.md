# 塑料注塑成型的生产台账汇总与报告生成：工作流编排

## 这个品类的数据长什么样
这个品类的数据覆盖注塑件、汽车内饰、家电及医疗塑件生产全流程。日常文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验表、巡检记录表、换料清机记录。数据来源涵盖树脂批次与物性表、注塑机运行参数、模温机数据、MES系统、尺寸及外观检测结果。数据更新随每批次生产、每次换模换料、每班作业触发，单份文档包含树脂批次号、模温设定值、保压时长、检测公差等核心字段。

## 这些特征在「工作流编排」这一环带来什么约束
由于数据随批次、换模换料、每班更新，工作流需支持按触发节点动态拉取对应批次的专属文档。多源数据格式差异较大，需在编排中配置统一的格式转换步骤，适配不同设备导出的参数文件。模具履历、原料干燥记录等文档关联紧密，工作流需支持跨节点的变量关联调用，确保不同环节的数据联动。生产数据对时效性要求较高，工作流需设置合理的超时阈值，避免因数据未及时同步导致任务中断。同时，注塑成型的出错后果直接关联批量不良或安全问题，工作流需配置失败重试与异常告警环节，确保数据准确性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 全局变量设置 | 按生产批次绑定`variables` | 适配每批次动态更新的树脂批次、模温参数等数据 |
| 工作流触发节点 | 按换模换料事件触发 | 匹配该品类数据随换模换料更新的节奏 |
| 知识库检索范围 | 绑定对应模具的历史文档 | 缩小检索范围，提升结果准确性 |
| 超时阈值 | 600秒 | 覆盖多源数据拉取与格式转换的平均耗时 |
| 失败重试次数 | 2次 | 避免单次数据同步异常导致任务中断 |
| 节点ID配置 | `nodeId`关联模具履历节点 | 实现跨节点的文档关联调用 |

## 容易做错的三处
- 现象：工作流中AI对话模块返回空结果，或提示无法找到相关文档。原因：未正确配置文件链接指向注塑工艺卡、模具履历等专属文档，或用户问题未限定注塑成型相关场景。
- 现象：全局变量赋值时无法正确选择目标知识库，返回参数格式错误。原因：未按要求使用`variables`绑定知识库ID，或输入的知识库标识格式不符合系统要求。
- 现象：工作流执行超时，或任务状态一直处于运行中。原因：未设置合理的超时阈值，或未配置失败重试机制，导致单节点异常时任务无法自动恢复。

## 怎么确认配好了
本文基于FastGPT v4.17.0版本编写。
- 触发一次模拟换模换料事件，检查工作流是否自动拉取对应批次的原料干燥记录与注塑工艺卡。
- 查看全局变量列表，确认`variables`中已绑定当前生产批次的相关参数。
- 调用知识库检索节点，验证返回结果仅包含当前模具的历史文档与当前批次的生产数据。
- 模拟单次数据同步异常，检查工作流是否触发失败重试与异常告警。
