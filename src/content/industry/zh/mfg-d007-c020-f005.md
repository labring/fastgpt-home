# 安全环保与特殊作业管理的生产台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
本品类数据来自法规标准库、在线环保监测设备、气体检测仪、人员资质档案、设备隔离清单及监管平台。日常文档涵盖风险辨识记录、动火/受限空间/吊装等作业票、环境监测记录、危废台账、排放监测数据、事故与隐患整改报告。数据更新随单次作业完成、实时监测结果或定期检查节奏推进，字段涵盖作业类型、作业时段、人员资质编号、监测数值、整改闭环状态等，部分数值带有明确单位，如危废产生量以吨计、排放浓度以mg/m³计。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类数据来源分散，覆盖多类独立系统与设备，工具调用需适配不同数据源的接口格式与权限规则。数据更新节奏差异明显，实时监测数据需高频调用接口，作业类台账需在作业完成后即时触发同步，定期检查数据则按固定周期拉取。文档结构与字段格式多样，部分文档含带单位的数值字段，工具调用时需保留字段单位以保证台账汇总的准确性。同时因业务否决权高，调用结果的正确性需严格校验，失败场景需配置明确的重试与告警逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | 按业务场景指定 | 适配本品类多数据源的工具调用需求，避免自动调用无关的非安全环保类工具 |
| `functionCall` | 强制指定工具列表 | 保证仅调用合规的安全环保与特殊作业管理类工具，符合业务高准确性要求 |
| 工具调用超时设置 | 300–600 秒 | 兼顾实时监测数据的即时响应与批量台账拉取的稳定性 |
| 检索结果条数上限 | 前8条 | 匹配本品类单场景文档数量集中的特征，减少无效信息干扰 |
| 工具调用失败重试次数 | 2次 | 应对临时网络波动或接口抖动，避免单次调用失败直接终止流程 |
| 字段格式校验开关 | 开启 | 保留带单位的业务字段，保证台账汇总的统计准确性 |

## 容易做错的三处
- 调用`/api/core/dataset/update`返回500错误，但浏览器端可正常访问接口。原因是未配置接口调用的身份验证参数，浏览器端自动携带的会话信息在API调用中未正确传递。
- 语义检索工具返回「Connection error」。原因是未正确配置工具调用的网络代理或目标数据源的访问权限，导致无法建立稳定连接。
- 调用Doc2x工具时读取文件失败，返回读取异常报错。原因是未指定正确的文件读取路径或未授予工具访问对应台账文件的权限，导致无法获取作业票或监测记录文件。

## 怎么确认配好了
- 在FastGPT v4.17.0版本的后台配置界面中，发起单次作业台账的工具调用请求，核对返回结果是否包含作业票、监测记录等本品类要求的文档字段。
- 模拟临时网络中断场景，验证工具调用是否按配置的重试次数执行重试，并在重试失败后触发告警。
- 导入带单位的测试数据，确认汇总后的台账保留了原始字段的单位信息，未出现数值与单位分离的情况。
- 检查`functionCall`配置项是否锁定了指定的工具列表，避免调用非合规工具。
