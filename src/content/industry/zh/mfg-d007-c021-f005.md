# 家具与木制品制造的生产台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
该品类典型主体为板式家具、实木家具、定制家居和木门企业。日常生产相关文档包含拆单图、开料清单、封边与钻孔程序、涂装工艺文件、五金清单、试装与包装记录。数据来源覆盖订单设计系统、板材和木材批次台账、数控开料与钻孔设备、ERP/MES系统、含水率检测设备。数据更新随单、每日或按材料批次触发，字段包含板件尺寸、材料批次号、工艺参数、五金规格、安装点位信息，对应单位为毫米、批次编号、百分比等。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据多源异构，包含结构化的ERP台账、数控设备输出的CSV文件、非结构化的拆单图纸与工艺文档，工具调用需适配多种数据格式与对接协议。定制订单驱动的生产模式导致单批次板件数量多，工具批量调用需限制单次处理条目数，避免超时。数据更新频率高，工具拉取数据的触发时机需匹配生产节拍，确保台账与生产进度同步。部分文档如拆单图包含复杂的尺寸标注与点位信息，需调用专用解析工具提取结构化字段，否则无法完成台账汇总。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` 或指定 `["pull_erp", "parse_cutlist", "compile_report"]` | 适配多工具串联的台账汇总流程，自动调度工具或明确执行顺序 |
| 问题优化 | 按实测标定 | 适配拆单图、工艺文档的复杂文本，优化后的查询更易被工具准确解析 |
| 单次工具调用上限 | 前20条 | 匹配单批次定制订单的板件数量规模，避免单次调用资源过载 |
| 超时阈值 | 600秒 | 匹配数控设备与ERP系统的常规数据拉取响应时长 |
| 工作流/API 函数调用配置 | 启用 | 强制工具返回结构化台账字段，确保报告生成的格式一致性 |
| 上下文窗口长度 | 8000–12000 token | 容纳多份开料清单、涂装工艺文档的完整内容，避免截断关键生产信息 |

## 容易做错的三处
- 现象：调用飞书多维表格的HTTP工具时返回403状态码或写入字段为空。原因：未正确配置飞书应用的文档编辑权限，或未在工具参数中传入符合要求的环境变量密钥。
- 现象：`functionCall`启用后，工具返回的结构化数据格式与预设模板不匹配。原因：未在工具定义中明确指定台账字段的名称与数据类型，导致输出格式不一致。
- 现象：批量拉取ERP数据时出现超时错误。原因：单次工具调用上限设置过高，超出FastGPT节点的资源限制，未匹配定制订单的板件数量特征。

## 怎么确认配好了
- 触发一次单订单的台账生成流程，检查工具调用日志中是否按预期拉起了ERP拉取、文档解析、报告生成三个环节。
- 查看工具返回的结构化数据，确认包含板件尺寸、材料批次、工艺参数等该品类特有的字段。
- 调用测试用的飞书多维表格接口，验证写入的台账数据是否与生成的报告内容一致。
- 调整单次调用上限参数，观察工具调用的耗时变化，确保符合生产节拍要求。
