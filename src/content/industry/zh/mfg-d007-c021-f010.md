# 家具与木制品制造的生产台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
该品类数据通常来自订单设计系统、板材与木材批次台账、数控开料钻孔设备、ERP/MES系统及含水率检测设备。日常文档包含拆单图、开料清单、封边与钻孔程序、涂装工艺规范、五金物料清单、试装及包装记录。数据更新随订单生成、每日生产进度或每批材料进场完成，字段包含板件尺寸、板材批次号、含水率数值、加工时间、五金规格等，对应单位为毫米、批次编号、百分比、时间戳、型号标识。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类定制订单驱动的特性导致板件数量多、参数个性化强，检索需精准匹配板件编号、板材批次号等唯一标识，避免泛化匹配导致的错配。多类型文档并存的情况要求检索环节兼容图纸、程序文本、清单表格等不同格式的内容解析。高频更新节奏要求知识库同步机制匹配每订单、每日或每批的更新频率，防止数据滞后影响台账汇总准确性。板件尺寸、含水率等核心参数直接影响生产结果，检索需优先召回与当前生产任务强相关的内容，减少无关结果干扰。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配该品类板件参数、批次号等精准字段的需求，避免过低导致无关召回，过高遗漏有效内容 |
| `limit` | 前8条 | 该品类单订单板件数量较多，单次召回足够覆盖核心生产参数，同时控制上下文长度 |
| `searchMode` | `mixedRecall` | 对拆单图与工艺文本使用语义/向量和全文混合召回；精确尺寸或批次筛选需单独配置 |
| `usingReRank` | 开启 | 针对定制化参数多的场景，重排可优化高相关结果的排序，减少误判 |
| `datasetSearchUsingExtensionQuery` | 开启 | 配合工作流中的问题优化步骤，扩展检索关键词，覆盖板件编号、五金规格等细分字段 |
| `collectionIds` | 绑定当前订单关联的知识库集合 | 精准限定检索范围，避免跨订单数据干扰，适配定制订单的独立数据需求 |

## 容易做错的三处
- 导入开料清单、拆单图等文档后，数据集状态长期显示索引中，未进入就绪状态。原因：未配置匹配该品类多格式文档的解析触发规则，或知识库同步频率未匹配每订单/每批的更新节奏。
- 切换向量模型后，检索返回相似度值为10000+，无法设置有效过滤阈值。原因：未明确该模型的相似度取值区间，直接套用通用0-1区间的过滤规则，未调整为对应模型的有效范围。
- 工作流执行至知识库搜索环节后提前结束，无法进入AI对话步骤。原因：检索召回的内容超出上下文长度限制，或未开启`datasetSearchUsingExtensionQuery`导致关键词匹配失败，工作流触发异常终止。

## 怎么确认配好了
- 导入一批对应订单的开料清单与拆单图，等待同步完成后，查看知识库解析状态是否显示就绪。
- 输入包含板件尺寸、板材批次号的测试查询，核对检索结果的排序与相关性，调整`similarity`与`usingReRank`配置至符合预期的召回效果。
- 触发工作流执行测试，确认流程从问题优化、知识库搜索到AI对话的全环节正常完成，无中途终止情况。
- 查看检索返回的结果条数，确认匹配`limit`的配置要求，无过多或过少的召回内容。
