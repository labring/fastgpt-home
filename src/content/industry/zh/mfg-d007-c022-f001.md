# 家用电器整机制造的生产台账汇总与报告生成：HTTP 接口与外部系统

## 这个品类的数据长什么样
家用电器整机制造的生产台账数据涵盖配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检结果及返修记录。数据来源包括ERP/MES系统、零部件批次台账、拧紧与充注设备、安规测试仪、性能实验室数据及售后故障记录。数据更新节奏按单台产品、每班生产批次或抽检计划执行，单台设备的充注、测试记录实时生成，批量抽检报告按周期汇总，返修记录随售后反馈同步更新。字段包含产品型号、批次号、工艺参数、测试结果、返修原因等，部分工艺数据需匹配专用单位，如制冷剂充注量为克，拧紧扭矩为牛米。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
家用电器整机制造的多源异构数据来源，要求HTTP接口需兼容工业设备的非标准HTTP请求格式与ERP/MES的标准接口协议。按单台、每班、抽检计划的差异化更新节奏，需接口支持增量同步与批量拉取两种模式，适配不同数据量的传输需求。涉及制冷剂充注、电气安全测试等敏感工艺数据，接口需通过`Authorization`参数完成权限校验，保障数据传输安全。不同业务文档的字段差异明显，如充注记录需浮点型数值字段，返修记录需文本备注字段，接口需支持自定义字段映射，避免格式不兼容导致同步失败。

## 配置怎么定
以下配置基于FastGPT v4.17.0。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `Authorization` | 携带 Bearer 令牌，有效期设置为 3600 秒 | 适配工业系统的权限校验周期，避免频繁刷新令牌影响同步效率 |
| `responseData` | 仅返回业务核心字段，过滤冗余元数据 | 减少接口传输流量，适配大批量台账数据的同步需求 |
| 单次请求最大数据条数 | 前 500 条 | 避免单请求数据量过大导致超时，符合工业设备的接口带宽限制 |
| 接口超时时间 | 600 秒 | 适配安规测试、性能实验室等耗时较长的报告拉取场景 |
| `variables` | 绑定产品型号、批次号作为查询变量 | 精准拉取对应型号的生产台账数据，避免混线数据干扰 |
| 字段映射规则 | 按业务文档定义匹配字段名与类型 | 适配不同文档的字段差异，确保数据同步准确 |

## 容易做错的三处
- 现象：调用接口时返回“Request failed with status code 400”。原因：未正确配置`Authorization`参数，或请求字段未匹配业务文档的必填项，如缺少产品批次号字段。
- 现象：接口调用频繁卡顿或超时。原因：未配置合理的单次请求数据条数，或未启用请求重试机制，无法应对网络波动。
- 现象：日志中出现“getaddrinfo EAI_AGAIN”报错。原因：未配置稳定的代理节点，或代理节点的域名解析出现故障，无法正常连接目标系统。

## 怎么确认配好了
- 发起单条数据的接口请求，核对返回的`responseData`是否包含业务文档要求的核心字段，字段类型与单位匹配。
- 调用批量拉取接口，检查传输的数据量与配置的单次请求最大数据条数一致。
- 模拟网络波动，验证接口是否能在配置的超时时间内完成请求，或触发预设的重试机制。
- 检查`Authorization`参数的有效性，确认无权限相关的报错信息。
