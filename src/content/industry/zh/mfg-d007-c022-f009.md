# 家用电器整机制造的生产台账汇总与报告生成：模型接入与配置

本页面基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
家用电器整机制造的生产台账数据来源包括ERP、MES系统，零部件批次记录，拧紧与制冷剂充注设备日志，电气安全测试、性能抽检报告，以及售后返修记录。数据更新节奏为单台产品对应一次工序台账，班组每日汇总抽检与返修数据，按固定计划生成性能测试报告。日常文档包含配置BOM、装配作业指导书、工艺参数记录等，字段涵盖零部件批次号、拧紧扭矩值、制冷剂充注量、安规测试电压、返修原因等，各字段均绑定对应业务场景的单位与校验规则。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的台账数据更新频率高且类型多样，要求模型接入配置需支持多格式文本的快速解析，避免因数据同步延迟导致汇总报告滞后。单台产品的关联文档较多，需控制上下文窗口的合理范围，防止混线生产的不同型号数据互相干扰。专业字段如制冷剂充注量、安规测试参数需模型准确识别，因此配置需保证模型对工业专业术语的理解精度，同时需适配企业内部网络隔离要求，避免核心生产数据外泄。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单批次多工序台账的关联分析，避免超出模型上下文窗口导致数据截断 |
| `maxTokens` | 2000–3000 token | 匹配单份生产报告的输出长度，覆盖安规、性能、返修等多维度汇总内容 |
| `quoteMaxToken` | 1500–2000 字符 | 保留台账原文核心片段，确保零部件批次、充注量等关键业务字段不被截断 |
| `temperature` | 0.1–0.3 | 保证专业术语与业务字段的生成准确性，减少无关内容的随机生成 |
| `AIPROXY_API_ENDPOINT` | 按企业部署环境填写本地或专属云端接口地址 | 适配内部网络隔离要求，避免生产数据通过公共接口传输 |
| `AIPROXY_API_TOKEN` | 按权限分配的专属访问密钥 | 限制接口访问范围，防止未授权调用引发的数据安全风险 |

## 容易做错的三处
- 出现`{"object":"error","message":"Only allowed now"}`报错，原因是未配置符合企业内部权限要求的`AIPROXY_API_TOKEN`或接口地址，无法通过模型接入校验。
- 本地部署的vllm服务无法在oneapi中添加，报connection refused错误，原因是未开放vllm服务的监听端口，或企业内部网络策略阻断了跨服务的访问链路。
- 生成的台账报告缺失零部件批次号或制冷剂充注量字段，原因是`quoteMaxToken`取值过小，截断了台账原文中的核心业务字段，导致模型无法提取关键信息。

## 怎么确认配好了
- 调用测试接口传入单台空调的装配作业书与电气安全测试记录，检查模型返回的汇总内容是否包含所有要求的业务字段。
- 查看模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置未触发权限校验失败提示。
- 调整`temperature`参数至0.1与0.3区间，对比两次生成的报告内容，确认专业术语与业务字段的一致性。
- 提交批量台账的汇总请求，检查是否出现上下文溢出相关的错误提示，验证`maxContext`配置的合理性。
