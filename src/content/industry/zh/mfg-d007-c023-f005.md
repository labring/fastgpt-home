# 工业仪器仪表制造与校准的生产台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
该品类的核心数据来自流量、压力、温度、分析仪器制造商及计量实验室的日常业务流程。日常文档包含装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录。数据来源涵盖设计文件、标准器和环境监测数据、校准软件、实验室信息系统及客户量程要求。数据更新频率为每台设备每次校准触发一次，每份校准记录包含被测件编号、校准日期、标准器编号、环境温度（℃）、压力（kPa）、误差值、校准结果、证书编号等固定字段，部分文档包含非结构化的误差曲线图像与计量证书PDF。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据来源分散且更新频次独立，要求工具调用支持单台设备单次校准的精准触发，避免批量调用产生的冗余数据。核心文档包含非结构化的误差曲线与计量证书，工具调用需适配多类型文件的解析规则，保留字段的原始单位与溯源信息。最耗时的校准环节涉及建立标准器与被测件连接、多点采集误差数据、审核溯源链与证书信息，工具调用需优先覆盖这些环节的自动化处理，减少人工干预的概率。此外，数据的合规性要求严格，工具调用需确保所有字段的完整性与可溯源性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工具调用触发时机 | 按单台校准完成后触发 | 匹配该品类每台每次校准的更新频率，避免无效调用 |
| 文件解析规则 | 优先解析原始校准记录、误差曲线格式 | 覆盖该品类核心业务文档类型，符合日常数据来源 |
| 上下文保留长度 | 8000–12000 token | 适配校准规程、计量证书等长文本的完整读取需求，按实测标定 |
| 单次工具调用超时时间 | 120 秒 | 覆盖建立标准器连接、多点采集误差数据的最长耗时环节 |
| `functionCall` | 启用 | 支持调用自定义工具对接实验室信息系统、校准软件等外部数据源 |
| `toolChoice` | 手动指定 | 针对溯源链审核环节，指定专用工具校验计量证书的合规性 |

## 容易做错的三处
- 现象为通过API调用台账汇总流程时返回核心字段缺失，但在应用配置的测试界面运行正常；原因是API请求未正确携带单台校准设备的唯一标识参数，导致工具调用无法匹配对应数据源。
- 现象为调用校准相关工具时返回模型加载失败；原因是升级FastGPT v4.17.0后未更新工具依赖的模型配置路径，导致本地部署的模型无法被正确寻址。
- 现象为解析校准记录文件时耗时过长；原因是未配置针对该品类文档的专用解析规则，工具调用默认解析所有文件类型，额外处理了非业务相关的冗余内容。

## 怎么确认配好了
- 触发一次单台校准完成后的工具调用，检查返回结果是否包含被测件编号、校准日期、误差值等核心业务字段。
- 查看工具调用日志，确认已对接的外部数据源返回的数据格式与配置预期一致，未丢失单位或溯源信息。
- 模拟溯源链审核环节，调用专用工具校验计量证书信息，确认工具能正确读取证书中的溯源编号与标准器关联关系。
- 在Linux部署环境中测试本地模型调用，确认工具能正常加载并处理校准相关的文本与图像数据。
