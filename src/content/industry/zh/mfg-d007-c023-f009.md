# 工业仪器仪表制造与校准的生产台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
本品类的数据围绕单台仪器的校准与生产全流程产生，来源包括设计文件、标准器与环境监测数据、校准软件导出内容、实验室信息系统记录、客户量程要求。数据更新频率为每台仪器每次校准后更新。日常文档包含装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录，字段涵盖仪器型号、校准日期、测量误差值、环境温湿度、标准器编号、证书编号等，单位涉及帕斯卡、摄氏度、毫安等计量相关标准单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类数据单次校准产生的文档包含曲线、证书等多类型内容，且更新频率为每台每次校准后更新，模型接入时需适配多模态输入与频繁的上下文刷新。数据字段多为计量相关专业内容，需保证模型对专业术语的识别准确性，同时需严格控制输入token总量避免超出模型上限。由于校准记录为关键交付物，模型调用的权限校验需严格匹配溯源要求，且需处理多来源数据的格式对齐问题，避免因数据结构不一致导致的配置异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配本品类单次校准产生的多文档上下文总量，避免截断关键计量数据 |
| `maxTokens` | 4000 token | 控制单轮输出的报告长度，符合计量证书与校准报告的常规篇幅要求 |
| `quoteMaxToken` | 1500 token | 限制引用的原始校准记录、误差曲线等文档的token占比，保证模型输出逻辑清晰 |
| `vision` | 开启 | 支持识别误差曲线、计量证书的图像内容，适配本品类多模态数据输入需求 |
| `temperature` | 0.2–0.4 | 降低输出随机性，保证计量相关数值与结论的准确性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配本地或云端的模型调用地址，保证数据传输合规 |
| `AIPROXY_API_TOKEN` | 绑定对应模型权限的令牌 | 匹配模型权限管理工具配置的令牌权限，避免调用失败 |

## 容易做错的三处
- 调用时返回`403 该令牌无权使用模型`报错，原因是配置的`AIPROXY_API_TOKEN`未在对应模型权限管理工具中添加目标模型权限，或令牌的访问范围未覆盖当前场景所需的模型。
- 生成的校准报告未符合预设的篇幅要求，原因是未正确设置`maxTokens`参数，导致模型输出超出预期长度，或提示词中的字数限制未与模型输出参数对齐。
- 无法正确解析误差曲线的图像内容，原因是未开启`vision`配置项，或上传的图像格式不符合模型支持的规范，导致图像识别失败。

## 怎么确认配好了
- 在FastGPT v4.17.0的模型测试界面输入单份校准记录，查看返回的响应状态码是否为200，无权限类报错。
- 上传误差曲线图像，确认模型能正确提取图像中的数值与标注信息，验证`vision`配置生效。
- 配置`maxTokens`为预设值后，生成一份模拟校准报告，核对输出内容的长度符合设定范围。
- 切换至不同的校准场景文档，确认模型调用时能正常加载并处理对应上下文内容，验证`maxContext`配置合理。
