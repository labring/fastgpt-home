# 工艺变更与工程变更的生产台账汇总与报告生成：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据来自PLM、ERP、MES、供应商资料、验证试验记录及客户特殊要求文件。日常产出的文档包含ECN/ECR表单、变更评估报告、图纸与BOM版本记录、工艺验证报告、生产切换计划、库存处置单及客户批准文件。数据更新无固定周期，每次工艺或工程变更触发更新，由跨部门变更管理团队维护，字段包含变更编号、版本号、影响范围、验证状态、切换节点等，无统一固定单位，随关联文档类型调整。

## 这些特征在「HTTP接口与外部系统」这一环带来什么约束
多源数据来源要求接口需兼容不同外部系统的返回格式，需支持解析PLM的结构化BOM数据、ERP的库存信息及MES的生产进度数据。非固定更新周期要求接口需支持按需触发拉取，适配变更触发的临时数据同步需求。多样的文档类型要求接口返回的`responseData`需兼容多种字段结构，无需强制统一字段模板。同时，变更数据的版本关联性要求接口需携带版本校验参数，确保同步的是当前有效版本的台账信息，避免新旧版本混用风险。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 单次请求数据量上限 | 1000–1500 条 | 适配ECN/ECR表单的单次批量同步规模，避免请求超时 |
| 超时阈值 | 600 秒 | 适配多源跨系统数据拉取的耗时需求，保障数据完整拉取 |
| 请求体最大体积 | 1000 MB | 适配大型图纸附件的同步需求，避免请求被截断 |
| `Authorization` 认证配置 | `Bearer {FastGPT v4.17.0 生成的API密钥}` | 符合FastGPT v4.17.0版本的HTTP接口认证规范，保障对接权限安全 |
| `responseData` 字段过滤规则 | 仅保留已完成验证的变更台账数据 | 过滤无效数据，降低外部系统存储与处理压力 |
| `variables` 绑定参数配置 | 变更编号、版本号、影响范围 | 精准匹配变更台账的核心查询维度，支持定向拉取目标变更数据 |

## 容易做错的三处
- 调用接口返回503状态码，提示当前分组无可用资源。原因：未在接口配置中绑定对应变更数据拉取的服务分组，导致请求无法匹配可用对接资源。
- 接口返回的台账数据包含旧版本变更记录。原因：未配置`responseData`的版本过滤规则，同步了未切换到有效版本的旧数据。
- 跨系统对接后外部系统接收的变更文档不完整。原因：单次请求数据量上限设置过小，未适配批量同步的ECN/ECR表单规模，导致数据截断。

## 怎么确认配好了
- 调用测试接口，检查返回的`responseData`中仅包含已验证通过的变更台账数据，核对字段与关联文档结构匹配。
- 模拟一次变更触发的数据同步，确认接口返回状态码为200，无权限或超时类报错。
- 核对`Authorization`配置的密钥与FastGPT平台生成的对接密钥一致，验证权限校验生效。
- 调整`variables`绑定的查询维度参数，确认可精准筛选目标变更的台账数据。
