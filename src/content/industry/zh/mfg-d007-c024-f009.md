# 工艺变更与工程变更的生产台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
本品类数据来自PLM、ERP、MES、供应商资料、验证试验及客户特殊要求，更新节奏为每次工艺或工程变更触发，无固定周期。日常文档包含ECN/ECR表单、变更评估报告、图纸与BOM版本记录、工艺验证报告、生产切换计划、库存处置单及客户批准文件，核心字段含变更编号、版本号、涉改物料清单、审批节点状态，部分文档附带结构化参数与非结构化图纸内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类数据来源分散且包含结构化表单与非结构化图纸，要求模型接入环节支持多源数据解析，适配不同系统导出的文档格式。变更触发无固定周期，可能出现突发的批量变更请求，需适配高并发接入场景，避免因并发超限触发异常。文档包含客户批准文件等合规性内容，要求配置环节可锁定敏感字段的解析规则，防止信息遗漏或篡改。同时，变更关联的连锁影响识别需依赖长上下文关联，对模型上下文长度提出明确要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `vision` | 开启 | 本品类包含非结构化图纸、验证报告等视觉类文档，需启用视觉解析能力 |
| `maxContext` | 8000–12000 token | 变更关联的多源文档需长上下文关联，覆盖ECN、BOM、客户要求等全量关联内容 |
| `maxTokens` | 2000–3000 token | 台账汇总与报告生成需输出完整的变更影响分析，避免截断关键结论 |
| `temperature` | 0.2–0.4 | 变更相关内容需保持严谨性，降低随机性输出 |
| `AIPROXY_API_ENDPOINT` | 按部署服务商提供的地址填写 | 适配多源数据接入的代理配置，确保跨系统数据同步稳定 |
| `AIPROXY_API_TOKEN` | 按实测标定的密钥长度配置 | 保障接口访问权限安全，避免密钥泄露或无效调用 |

## 容易做错的三处
- 现象：视觉解析功能仅在商业版本菜单中显示，无法在开源部署环境中启用。原因：未针对开源版本配置`vision`参数的兼容项，或部署包未包含开源视觉模型适配文件。
- 现象：并发调用超过5个时返回429状态码，请求被拦截。原因：未配置接口并发限制规则，未结合变更业务的突发调用特性调整阈值。
- 现象：自定义添加的大模型无法正常调用，系统提示连接超时。原因：`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`参数填写错误，或网络策略限制了接口访问。

## 怎么确认配好了
本页面配置基于FastGPT v4.17.0版本。
- 导入一份ECN变更文档与关联BOM文件，触发台账汇总任务，检查是否能正确提取变更编号、涉改物料等核心字段。
- 发起2次以上并发的报告生成请求，检查是否触发429异常，确认并发限制配置生效。
- 查看模型调用日志，确认`vision`参数已启用，视觉类文档的解析结果包含图纸关键标注信息。
- 测试自定义大模型接口调用，检查是否能正常返回变更影响分析内容，无连接报错。
