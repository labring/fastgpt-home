# 工装夹具与检具制造的生产台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
该品类的数据主要来自产品数模与GD&T、工艺路线、三坐标测量数据、现场试用反馈及计量系统。日常产生的文档包括工装需求书、定位基准方案、夹具图、检具操作书、验收报告、校准记录与变更履历。数据更新节奏按单个项目推进、每次产品设计变更触发，以及定期校准周期更新。数据字段包含基准参数、夹紧方案、干涉验证结果、校准值、变更记录等，单位涉及毫米、牛顿、微米等精密计量单位。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的精密计量类数据与结构化工程文档混合的特征，要求部署环节需支持多源异构数据接入。按单个项目、产品设计变更及定期校准触发的非周期性更新，要求部署的同步机制支持按需触发，适配临时变更与校准任务的即时数据提交。多字段包含毫米、牛顿、微米等精密计量单位的特征，要求数据存储与解析环节支持自定义单位映射与格式校验。大量工程图纸、校准记录的存储需求，要求配置足够的存储空间与适配CAD格式文件的解析模块。同时，数据关联的工艺路线与三坐标测量数据需与现有生产系统对接，部署时需预留标准化接口适配空间。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:port/database?authSource=admin` | 适配多源工程文档与计量数据的结构化存储需求，支持事务性数据更新 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 缓存高频访问的工装图纸元数据与校准记录，降低数据库查询压力 |
| `STORAGE_S3_ENDPOINT` | `https://s3-cn-beijing.volces.com`（或本地存储节点地址） | 适配大量工程图纸、三坐标数据的批量存储与快速读取需求 |
| `FILE_TOKEN_KEY` | 按实测标定 | 用于加密工装文档的访问令牌，避免未授权访问精密工程数据 |
| `DB_MAX_LINK` | `100–150` | 适配多项目并行的台账数据并发访问，避免连接池耗尽 |
| `FE_DOMAIN` | `https://your-fastgpt-domain.com` | 配置前端访问域名，确保工装文档预览与报告生成的链路正常 |

## 容易做错的三处
- 现象：升级至FastGPT v4.17.0后，离线配置重排模型时弹出配置失败提示，后台日志显示模型加载超时。原因：未将离线模型文件放置在指定的本地模型存储目录，或目录权限未配置为可读写。
- 现象：启用关联知识库功能后无法加载本地文档，界面显示「资源不可用」。原因：未配置`STORAGE_S3_ENDPOINT`指向本地存储节点，或本地文件路径未在部署配置中映射。
- 现象：本地部署完成后，尝试通过SSO对接企业认证系统时，无法完成登录跳转，界面显示认证失败。原因：未在部署配置中正确配置`FE_DOMAIN`与后端回调地址，导致SSO令牌校验不通过。

## 怎么确认配好了
- 执行数据库连接测试，确认`MONGODB_URI`与`REDIS_URL`配置的地址、端口与认证信息可正常连通。
- 上传一份工装夹具图纸文件，验证`STORAGE_S3_ENDPOINT`配置的存储节点可正常接收并返回文件访问链接。
- 发起一次台账汇总任务，检查生成的报告中是否包含校准记录、变更履历等品类专属数据字段。
- 测试SSO对接流程，确认`FE_DOMAIN`配置的前端地址与SSO回调地址一致，完成认证跳转。
- 尝试离线加载重排模型，确认模型加载无超时报错，符合本地部署的配置要求。
