# 有色金属冶炼与电解的生产台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
该品类数据来源包括精矿与辅料分析报告、DCS系统采集的生产参数、电解槽电压电流数据、化验室检测结果、能源与环保监测系统。日常文档涵盖配料单、熔炼记录、电解槽况记录、化验报告、阳极阴极质量记录、环保台账。数据更新节奏随生产流程推进，每批原料、每炉或每槽生成对应记录，关键生产参数实时同步。文档字段包含原料批次标识、配料添加量、炉温、槽电压、电流强度、检测成分数值、能源消耗数值，单位涉及千克、摄氏度、伏特、安培、立方米等。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据分散且更新频率不均，多源数据与多格式文档需同时处理，因此模型接入时需配置适配多数据源的调用规则，确保不同类型台账的完整读取。文档字段无统一标准化格式，模型需具备非结构化数据的解析能力，因此需调整上下文窗口参数以容纳多份文档的完整内容。实时生产参数与批量记录混合，要求模型调用适配不同延迟的请求，需设置合理的调用约束。同时，该品类需平衡原料成分与杂质控制，模型输入需包含多维度生产数据，因此需配置足够的上下文长度以承载完整的生产台账信息，保障核算与分析的准确性。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配多份生产台账的完整内容，涵盖配料单、熔炼记录等多文档的汇总信息 |
| `maxTokens` | 2000–3000 token | 保证生产报告的完整生成，覆盖金属平衡核算、槽况分析等核心内容 |
| `temperature` | 0.3–0.5 | 降低生成随机性，确保生产数据与核算结果的准确性，匹配工业场景的严谨要求 |
| `AIPROXY_API_ENDPOINT` | 按部署的OneAPI地址填写 | 适配多模型接入的代理配置，解决跨服务连接的常见问题 |
| `AIPROXY_API_TOKEN` | 填写部署生成的认证密钥 | 完成模型接入的身份验证，保障接口调用的安全性 |
| 工作流/API 工具选择配置 | auto | 允许模型自动选择是否调用工具，适配生产台账汇总时的多数据整合需求 |

## 容易做错的三处
- 现象：Embedding模型调用时返回OneAPI连接报错，状态码为502或连接超时。原因：未正确配置`AIPROXY_API_ENDPOINT`的代理地址，或认证密钥`AIPROXY_API_TOKEN`无效，导致模型代理链路中断。
- 现象：生成的生产报告中出现与实际台账不符的虚构数据。原因：`temperature`参数取值过高，模型生成内容的随机性超出工业场景的严谨要求，未结合实际生产数据进行约束。
- 现象：模型无法解析多份分散的生产文档内容。原因：`maxContext`参数设置过小，无法容纳多份台账的完整信息，导致关键数据被截断丢失。

## 怎么确认配好了
- 调用测试接口，输入单份熔炼记录与配料单，检查模型是否能正确提取关键生产参数，确认`maxContext`的长度适配输入内容。
- 调整`temperature`参数至设定区间，生成3次测试报告，对比输出内容的一致性，验证参数对生成随机性的约束效果。
- 验证代理配置的有效性，使用`AIPROXY_API_TOKEN`发起模型调用请求，确认返回结果无认证相关报错。
- 测试多源数据输入，同时上传电解槽况记录与环保台账，检查模型是否能完整整合两类文档的信息，确认配置的上下文窗口可承载全部输入内容。
