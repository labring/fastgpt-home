# 服装裁剪与缝制的生产台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
该品类的数据通常来自订单与尺码表、CAD样板、面辅料检验记录、吊挂系统数据、验针机检测结果及客户封样文件。日常涉及的文档包含工艺单、样板、排料图、裁剪单、首件封样、工序质量表、包装配码单。数据更新以每订单、每款、每批为节奏，单款裁片不可逆且工序多依赖人工，数据字段多包含尺码、面料批次、工序质检结果、包装配比等，无统一的跨厂标准格式。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的高频按批次更新数据，要求部署时支持动态加载单订单/单款的数据集，避免全量索引的耗时。多类型非标准化文档（CAD样板、工序质检表等），要求部署配置适配多格式解析，尤其是结构化表格与矢量图形的提取。裁片不可逆的业务特性，要求台账数据的溯源字段完整且不可篡改，需配置严格的数据存储校验。季节性强、款式迭代快的特点，要求升级环节不中断正在运行的台账生成任务，且支持快速切换业务数据集。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150` | 该品类单批订单关联多份文档，数据库连接数需适配批量数据读取，适配FastGPT v4.17.0版本的连接池规则 |
| `REDIS_URL` | `本地6379端口，按实测标定` | 高频台账生成需要缓存排料图、工序数据，本地部署可降低跨节点传输延迟 |
| `STORAGE_S3_ENDPOINT` | `内网存储节点地址，如http://192.168.1.100:9000` | 该品类的CAD样板、裁片图等文件体积较大，内网存储可降低上传下载耗时 |
| `ROOT_KEY` | `32位随机字符串` | 管理后台的权限控制需强密钥，避免非授权访问台账配置与业务数据 |
| `FILE_TOKEN_KEY` | `与本地存储服务一致的签名密钥` | 需校验上传的工艺单、包装配码单等文件的合法性，防止恶意文件导入数据集 |

## 容易做错的三处
- 现象：本地Docker部署后，其他应用无法调用FastGPT API。原因：未配置`FE_DOMAIN`为本地公网或内网可访问地址，导致跨域请求被拦截。
- 现象：导入面料检验、工序质量表等数据集后，长时间处于索引中状态。原因：未调整`DB_MAX_LINK`适配批量文档解析，数据库连接池耗尽导致索引阻塞。
- 现象：部署本地rerank模型后，调用接口返回认证失败。原因：未将`FILE_TOKEN_KEY`替换为rerank服务的安全凭证密钥，导致Bearer令牌校验不通过。

## 怎么确认配好了
- 执行本地API调用测试，传入订单台账的查询指令，确认返回结果包含正确的工序、尺码、包装配比字段。
- 查看数据库连接日志，确认`DB_MAX_LINK`配置的连接数未被持续占满，无连接超时报错。
- 上传一份CAD样板文件至数据集，确认解析后提取的裁片数量、尺码信息与原文档一致。
- 尝试通过非授权IP访问管理后台，确认`ROOT_KEY`配置生效，无法直接登录系统。
