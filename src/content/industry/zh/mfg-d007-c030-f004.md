# 橡胶混炼与制品硫化的生产台账汇总与报告生成：工作流编排

## 这个品类的数据长什么样
橡胶混炼与制品硫化的生产数据来源于配方系统、原材料批次台账、密炼机、门尼粘度仪、流变仪、硫化机及实验室检测设备。日常生产文档包含配方单、称量记录、混炼曲线、胶料快检报告、硫化工艺卡、模具使用记录、成品性能检测报告。数据更新节奏为每车原材料批次、每批胶料、每模次硫化制品同步更新，字段包含批次标识、工艺参数、检测结果等，无固定统一格式，随生产节点动态生成。

## 这些特征在「工作流编排」这一环带来什么约束
高频的生产数据更新要求工作流支持按单批次触发的灵活调度，避免无效的重复采集。多源异构的数据来源需要工作流配置多个独立的数据源节点，适配不同设备与系统的接入方式。多样的生产文档类型要求工作流支持多种格式的文件上传与解析，确保各类台账信息均可纳入汇总范围。不可逆的工艺特性要求工作流对台账数据设置锁定机制，防止后续环节修改已生成的历史记录。同时，严重的出错后果需要工作流配置校验与重试环节，降低数据偏差导致的报废风险。

## 配置怎么定
以下配置适用于 FastGPT v4.17.0 版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 数据源节点触发时机 | 按单批次生产完成后触发 | 匹配每车胶、每批的更新节奏，避免重复采集无效数据 |
| 全局变量绑定 | `variables` 绑定批次号、原材料批次 | 统一传递跨节点的核心标识，避免不同批次的数据错位 |
| 文件上传节点大小限制 | 单次上传不超过 100 MB | 适配混炼曲线、性能报告等文档的常规存储大小 |
| 工具调用节点重试次数 | 3 次 | 应对设备数据采集的临时波动，降低单次调用失败的影响 |
| 节点链路校验 | 按`nodeId`匹配预设工艺顺序 | 确保混炼、硫化、检测等环节按生产逻辑依次执行 |
| 调用超时阈值 | 600 秒 | 适配密炼机、硫化机的数据采集和报告生成的常规耗时 |

## 容易做错的三处
- 数据库连接节点无法输入端口号：现象为界面端口输入框置灰不可用，原因是未勾选对应数据源的高级配置选项，仅在接入密炼机、硫化机的专属数据库时需手动启用该配置。
- 无法找到文件上传入口：现象为工作流中无文件上传节点选项，原因是未在系统配置中开启文件上传功能，需先启用后才可在工作流中添加对应节点。
- 工具调用节点触发429 Request rate increased too quickly报错：现象为节点运行失败返回对应状态码，原因是未配置合理的调用频率限制，高频采集混炼、硫化数据导致请求速率超出模型限额。

## 怎么确认配好了
- 手动触发一次单批次的工作流，检查各数据源节点是否正确拉取对应批次的称量记录、混炼曲线等文档。
- 查看工具调用节点的运行日志，确认未出现429类报错，且返回结果符合混炼工艺的参数范围。
- 验证全局变量是否在跨节点传递正常，可通过打印`variables`参数的内容确认批次标识与实际生产批次一致。
- 检查最终生成的报告，确认包含配方单、成品性能报告等该品类生产台账的所有必填文档内容。
