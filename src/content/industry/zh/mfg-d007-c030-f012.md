# 橡胶混炼与制品硫化的生产台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
本品类的生产数据来自配方系统、原材料批次台账、密炼机、门尼流变仪、硫化机及实验室检测设备。日常生成的文档包含配方单、称量记录、混炼曲线、胶料快检报告、硫化工艺卡、模具使用记录、成品性能报告，数据字段包含原材料批次号、混炼温度、硫化时长、成品拉伸强度等，单位涵盖摄氏度、分钟、MPa等。数据更新频率为每车胶、每批原料、每模次制品生成一次，单条数据体量从数十KB到数MB不等，整体数据量随生产规模线性增长。

## 这些特征在「部署与升级」这一环带来什么约束
高频次的单条数据更新要求部署时配置支持高并发读写的存储连接，避免数据同步延迟影响台账的实时性。多源异构的数据来源需要预设数据映射规则，确保不同设备的日志格式统一后接入台账系统，减少后续解析与汇总的工作量。多样的文档类型需要适配不同格式的文件解析，避免配方单、混炼曲线等格式差异导致的解析失败。同时，该品类数据出错会引发制品报废或性能不合格，部署时需配置权限控制机制，防止非授权修改台账内容，升级时需保留历史数据的不可篡改特性，确保生产追溯的准确性。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本，针对橡胶混炼与制品硫化的生产台账汇总与报告生成场景优化。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://admin:securepass@192.168.1.10:27017,192.168.1.11:27017/fastgpt_manufacture?authSource=admin` | 该品类数据更新频繁，集群模式的`MONGODB_URI`可支持高并发的台账读写与索引构建 |
| `REDIS_URL` | `redis://:redispass@cache-host:6379/0?maxmemory-policy=allkeys-lru&maxmemory=1000 MB` | 缓存高频访问的混炼曲线、胶料快检报告，1000 MB的内存配置可满足单批次生产数据的缓存需求 |
| `STORAGE_S3_ENDPOINT` | `http://s3-cn-north-1.example.com` | 存储批量上传的混炼曲线PDF、成品性能报告等大体积文档，适配多文件并发存储需求 |
| `FILE_TOKEN_KEY` | `32位随机字符串` | 保护上传的配方单、工艺卡等敏感文档，防止未授权访问与篡改 |
| `FE_DOMAIN` | `https://manufacture-doc.example.com` | 配置前端访问域名，用于生成台账汇总报告的分享链接与前端页面加载 |
| `ROOT_KEY` | `64位随机密钥` | 配置系统管理员权限，确保只有授权人员可修改台账汇总与报告生成的配置规则 |
| `DB_MAX_LINK` | 20 | 配置数据库连接池大小，20的取值可满足该品类高频数据读写的并发需求 |

## 容易做错的三处
- 上传混炼曲线PDF或配方单后返回`400 Bad Request`报错，文件解析失败。原因是未配置`FILE_TOKEN_KEY`，导致文件上传权限校验未通过，无法将文件同步至`STORAGE_S3_ENDPOINT`对应的存储服务。
- 部署完成后新用户无法完成注册，界面提示“注册接口未启用”。原因是开源版部署时未开启用户注册相关的配置开关，未正确配置系统权限相关参数。
- 知识库检索时无法匹配到指定批次的称量记录，检索结果条数远少于实际台账数量。原因是`DB_MAX_LINK`设置过小，数据库连接池耗尽，导致部分批次数据未被同步至知识库索引。

## 怎么确认配好了
- 访问`FE_DOMAIN`对应的前端地址，确认可以正常加载台账汇总页面，无加载失败或资源404报错。
- 上传一份真实的混炼曲线PDF文件，确认解析后可以正确提取混炼温度、时长等字段，无解析为空或乱码情况。
- 执行一次台账生成任务，确认生成的报告包含配方单、称量记录、硫化工艺卡的对应字段，数据与源文档一致。
- 查看`REDIS_URL`的连接日志，确认无连续的连接超时或认证失败报错，缓存服务运行正常。
- 检查`MONGODB_URI`的数据库连接日志，确认无连接失败或认证报错，台账数据同步正常。
