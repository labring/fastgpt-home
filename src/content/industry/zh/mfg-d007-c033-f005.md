# 汽车零部件批量制造的生产台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
本品类数据来自制动、转向等汽车零部件供应商的多类业务载体，日常文档包含控制计划、过程流程图、作业指导书、首件与巡检记录、SPC报表、PPAP资料、8D报告。数据来源涵盖客户图纸和特殊特性清单、ERP/MES系统、量检具数据、设备过程参数及供应商质保书。数据更新频率为每批、每班及持续采集，字段包含批次号、检验尺寸（mm）、扭矩参数（N·m）、检验时间、异常记录等，需严格匹配客户特殊特性要求。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类的数据特征对工具调用与插件环节带来多重约束。多源异构数据需调用不同插件分别拉取ERP/MES的生产数据、量检具的检验数据及客户图纸的特殊特性要求，需适配不同数据源的API格式。高频更新的特性要求工具调用需绑定产线的实时数据触发逻辑，避免滞后。文档类型多样，需配置多格式解析插件以处理控制计划、SPC报表等不同结构的文件。同时，需严格遵循客户质量体系约束，确保台账字段与客户特殊特性完全匹配，不得随意调整字段名称或格式。

## 配置怎么定
本配置基于FastGPT v4.17.0版本制定。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` | 适配多类型工具的自动调用需求，无需手动指定单个插件 |
| 工作流/API 函数调用配置 | `enabled` | 启用函数调用能力，支持跨插件汇总多源生产台账数据 |
| 工具调用触发时机 | 每批次生产完成后 | 匹配本品类每批更新的数据频率，确保台账数据实时对应当期生产 |
| 知识库绑定范围 | 绑定当前产线专属知识库 | 遵循客户质量体系的强约束要求，实现数据隔离与精准匹配 |
| API调用超时时间 | `120 秒` | 适配跨ERP、MES及量检具系统拉取数据的平均耗时，避免调用中断 |

## 容易做错的三处
- 现象：调用API时提示“知识库id未找到”错误，返回状态码404。原因：未将对应产线的知识库id配置为全局变量，或传入的参数格式不符合系统要求。
- 现象：生成的生产台账缺失客户特殊特性相关字段，结果为空或字段不完整。原因：未在工具调用配置中指定关联客户图纸和特殊特性清单的数据源，导致无法拉取对应字段。
- 现象：工具调用超时，任务状态显示为失败。原因：未设置合理的超时时间，且同时调用多个跨系统插件，超出系统默认等待时长。

## 怎么确认配好了
- 触发一次工具调用，检查返回的生产台账数据是否包含控制计划、巡检记录、SPC报表等指定文档的核心字段。
- 查看API调用日志，确认传入的知识库id与全局变量配置一致，无格式错误。
- 模拟产线异常数据触发工具调用，验证是否自动调用根因分析相关插件生成对应报告。
- 检查`toolChoice`参数设置，确认工具调用流程自动匹配所需的数据源插件，无需手动干预。
