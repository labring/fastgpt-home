# 汽车零部件批量制造的生产台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来源涵盖客户图纸、特殊特性清单、ERP/MES系统、量检具数据、设备过程参数及供应商质保书。日常生产关联文档包含控制计划、过程流程图、作业指导书、首件与巡检记录、SPC报表、PPAP资料及8D报告。数据更新频率为每批、每班及持续采集，字段包含批次编号、工序参数、检测数值、不合格项记录及客户特殊特性要求，单位涵盖毫米、牛顿、百万分比等工业常用计量标准。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源分散的数据来源要求模型接入需支持对接不同格式的结构化与非结构化文档，避免数据解析遗漏。高频更新的生产数据要求模型调用具备低延迟特性，适配实时汇总需求。多样的文档类型需要配置适配多格式解析的工具链，保障台账内容完整提取。同时，受整车客户强质量约束，模型输出的报告需严格匹配客户特定格式与字段要求，避免出现内容偏差或格式错误。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 汽车零部件生产台账包含多批次的SPC报表、PPAP资料等文档，单批次文档总量较大，需覆盖完整批次上下文以提取全部关键信息 |
| `maxTokens` | 2000–3000 token | 生产台账汇总报告需包含工序参数、检测结果汇总及异常分析，输出长度需匹配常规工业报告的篇幅要求 |
| `temperature` | 0.1–0.3 | 报告需严格匹配客户特殊特性要求，降低生成内容的随机性，避免偏离业务规范 |
| 工作流/API 工具选择配置 | `auto` | 需自动调用文档解析工具处理控制计划、作业指导书等多类型生产文档，无需手动指定工具 |
| `AIPROXY_API_ENDPOINT` | 私有化部署的模型服务地址 | 需对接内部重排索引模型，保障生产数据不出企业内网，符合汽车行业数据安全要求 |
| `AIPROXY_API_TOKEN` | 与私有化模型绑定的访问令牌 | 限制未授权访问，保障生产台账数据的访问安全，符合整车客户的质量体系约束 |

## 容易做错的三处
- 调用私有化重排索引模型返回405错误，原因是未正确配置`AIPROXY_API_ENDPOINT`的请求路径，或未开启模型支持的HTTP请求方法。
- 接入OpenAI-API-Compatible模型时返回405错误，原因是未匹配模型支持的请求格式，或令牌权限不足。
- 生成的报告缺失客户特殊特性字段，原因是`maxContext`设置过小，未覆盖客户特殊特性清单的完整内容，导致模型无法提取关键业务信息。

## 怎么确认配好了
- 测试调用模型接口，验证返回状态码为200，无405、401等错误提示。
- 上传单批次完整生产台账文档，检查模型提取的字段包含批次号、工序参数、检测结果及客户特殊特性要求等核心内容。
- 调整`temperature`参数至0.2与0.3，对比两次生成的报告，确认输出内容符合业务规范且无明显偏差。
- 发起2–3个并发测试请求，验证模型服务的响应稳定性，无超时或限流问题。
