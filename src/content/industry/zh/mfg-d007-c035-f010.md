# 热处理的生产台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自材料牌号标准、客户技术要求、温控仪表、炉温均匀性测试设备、硬度计与金相检测设备、生产执行系统。数据按每炉次、每批更新，日常文档包含热处理工艺卡、装炉布局图、实时炉温曲线、硬度与金相检测报告、设备点检表、异常处置单。数据字段包含炉温区间（单位℃）、装炉重量（单位kg）、硬度值（单位HV或HRC）、保温时长（单位分钟）等，文档多为结构化表格与时序曲线文件。

## 这些特征在「知识库检索与召回」这一环带来什么约束
本品类的数据特征对知识库检索与召回带来多重约束。多源设备与生产系统生成的文档包含结构化表格、时序曲线与纯文本，要求检索链路兼容多格式的向量建模与关联召回。数据按每炉次、每批高频更新，要求召回流程支持低延迟的增量同步，避免因数据滞后导致检索结果不符当前生产要求。字段带有专属行业单位，检索时需匹配单位关联的工艺条件，避免跨单位的无效匹配。不同文档间存在强关联，如装炉布局对应炉温曲线、工艺卡对应硬度检测报告，召回需支持跨文档的上下文关联，确保检索结果的完整性。

以下配置基于FastGPT v4.17.0版本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.6–0.7 | 匹配热处理工艺的精准参数要求，过滤低相关性的通用工艺文档 |
| `limit` | 前6–10条 | 单炉次关联的台账文档数量有限，控制召回条数避免上下文冗余 |
| `searchMode` | 全文检索 | 适配多格式文档的关联检索，覆盖装炉图、炉温曲线等跨类型数据 |
| `usingReRank` | 开启 | 对初始召回结果按工艺相关性重排，修正初始检索的排序偏差 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户问题扩展工艺相关关键词，如将「淬火要求」扩展为冷却速度、保温时长 |
| `collectionIds` | 按产线/车间指定 | 限定检索范围至当前产线的热处理知识库，排除无关产线的历史数据 |

## 容易做错的三处
- 现象：检索时返回大量无关的通用热处理工艺文档，无法定位目标炉次的台账数据。原因：`similarity`阈值设置过低，未匹配热处理工艺的精准参数要求，导致低相关性内容被召回。
- 现象：知识库中重复上传同一份炉温曲线文件后，检索结果出现重复条目。原因：未启用文档去重配置，或去重规则未匹配热处理文档的专属唯一标识（如炉号、工艺编号）。
- 现象：检索装炉布局要求时，仅召回装炉图文档，未关联对应的炉温曲线与硬度报告。原因：未开启扩展检索或重排功能，无法建立跨文档的工艺关联。

## 怎么确认配好了
- 上传单份热处理工艺卡与炉温曲线，发起针对该炉次的检索，核对召回结果是否包含目标文档。
- 调整`similarity`阈值，对比不同阈值下的召回结果，确认符合当前产线的参数匹配精度要求。
- 开启重排与扩展检索功能，发起跨文档关联的检索请求，确认召回结果包含关联的多类文档。
- 查看知识库的同步日志，确认高频更新的炉次数据已完成增量同步，无滞后情况。
