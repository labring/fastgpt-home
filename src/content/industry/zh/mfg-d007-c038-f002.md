# 生物制品与无菌生产的生产台账汇总与报告生成：向量模型与索引

## 这个品类的数据长什么样
该品类主体为疫苗、抗体、血液制品及无菌注射剂生产企业，日常数据涵盖细胞库与种子批记录、培养纯化记录、无菌灌装记录、洁净区环境监测数据、培养基模拟灌装结果、无菌检验报告及批放行资料。数据来源覆盖细胞库管理系统、过程分析仪器、洁净区监测设备、MES生产执行系统、LIMS实验室信息管理系统及设备完整性测试工具。数据更新节奏包含按生产批次、实时监测及固定周期计划三类，单条记录包含批次编号、操作时间、工艺参数值、检测结果及操作人信息等字段，部分文档包含多维度结构化表格与非结构化描述文本。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据来源分散且格式混杂，包含结构化表格、仪器导出的原始数据及非结构化过程描述，要求索引系统支持多源异构数据的统一分块与元数据绑定。数据与生产批次强绑定，分块过程需保留批次编号作为核心关联元数据，避免跨批次的检索混淆。数据更新频率差异大，实时监测数据需支持增量索引，而批放行资料需支持全量重新索引。同时，数据异常可能引发严重安全风险，需确保向量化与索引过程无异常chunk生成，避免低质量向量影响检索结果。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配该品类单条过程记录的平均文本长度，避免拆分关键工艺参数的上下文 |
| 分块重叠长度 | 100–150 字符 | 保留跨分块的批次编号、关键操作节点信息，确保检索时的上下文连贯性 |
| `defaultToken` | 4096 | 适配主流开源嵌入模型的输入token上限，匹配该品类大部分记录的文本长度 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| 单次搜索上限 | 前5条 | 匹配批放行报告需关联的核心过程记录数量，过滤冗余检索结果 |
| 相似度阈值 | 0.75–0.85 按实测标定 | 过滤低匹配度的非相关过程记录，确保检索结果与目标生产批次强关联 |

## 容易做错的三处
- 上传10M以上的批放行资料时，生成超过1000个chunk后出现向量化异常，反复重试后部分恢复。原因是分块时未绑定批次元数据，导致部分chunk的上下文关联断裂，触发嵌入模型的格式校验失败。
- 多文件批量上传导致服务器崩溃重启后，知识库状态卡在“未就绪”且无自动恢复动作。原因是未配置批量索引的状态持久化机制，仅支持单文件手动触发索引，未关联上传任务的执行记录。
- 更新FastGPT v4.17.0版本后，原有索引的知识库无法返回检索结果。原因是版本升级后嵌入模型的向量维度发生变更，原有索引的向量库未做维度适配，导致匹配逻辑失效。

## 怎么确认配好了
- 上传单份细胞库种子批记录文档，查看分块后的元数据是否包含批次编号、操作时间字段，验证分块逻辑是否正确绑定业务标识。
- 发起针对某一生产批次的放行报告检索请求，核对返回结果的数量是否符合预设的单次搜索上限，且相似度分值处于设定区间内。
- 重启服务器后，查看知识库列表的状态是否自动变为“就绪”，无需手动触发索引操作即可正常检索。
- 调用嵌入模型接口，上传一段培养纯化记录的文本片段，验证向量输出无异常报错，确认向量化流程正常。
