# 生物制品与无菌生产的生产台账汇总与报告生成：多轮对话与提示词

## 这个品类的数据长什么样
生物制品与无菌生产领域涵盖疫苗、抗体、血液制品及无菌注射剂企业，其生产台账数据来源包括细胞库与种子批记录、培养纯化记录、无菌灌装记录、洁净区环境监测数据、培养基模拟灌装结果、无菌检验报告及批放行资料，数据采集自细胞库管理系统、过程分析平台、洁净区监测系统、MES、LIMS及设备完整性测试工具。数据更新节奏分为每批生产完成更新、实时监测数据推送及按固定监测计划更新，单批台账包含批次编号、培养温度与时长、沉降菌检测值、灌装环境参数、检验结果等结构化字段，部分记录附带采样时间、操作人员编号等非结构化备注信息。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
多源异构的数据来源要求对话系统需支持跨系统数据的关联整合，避免因数据分散导致的汇总偏差。不同更新频率的数据集需要对话环节区分实时监测数据与批后归档数据的调用逻辑，确保报告生成的时效性与准确性。单批台账包含多类专业字段与非结构化备注，提示词需明确指定字段提取规则与格式要求，避免生成的报告缺失关键无菌保证参数。同时，该品类的出错后果直接关联患者安全，对话环节需增加数据校验逻辑，确保汇总的台账数据符合无菌生产的合规要求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 最大上下文 | 8000–12000 字符 | 适配单批完整生产台账的总字符量，避免截断批放行的关键校验数据 |
| 单次对话召回条数 | 前 3 条 | 聚焦单批核心生产记录，避免多知识库数据叠加导致的信息过载 |
| 变量预设 | 按批号筛选 | 匹配生产台账按批管理的业务逻辑，减少无效数据的召回与处理，对应`variables`参数配置 |
| 对话历史保留时长 | 7 天 | 对应批生产的常规追溯周期，符合无菌生产的记录保存规范，基于`messages`上下文管理逻辑 |
| 输入文件大小限制 | 1000 MB | 适配大型细胞库记录的上传需求，避免单批完整台账无法导入 |
| 对话ID绑定 | 按单批生产任务 | 绑定专属`chatId`，确保单批对话的上下文不与其他批次混淆 |

## 容易做错的三处
- 现象：对话输入的json格式台账文件返回字符超限报错。原因：未调整最大上下文配置，默认限制未适配生物制品台账的长文档输入。
- 现象：关联多个知识库后返回的结果条数不足或无匹配内容。原因：未设置合理的单次召回条数，多源数据叠加超出系统处理上限。
- 现象：国际版正式对话环境出现知识库关联报错，预览环境无异常。原因：正式环境与预览环境的知识库配置未同步，或跨区域数据同步存在延迟。

## 怎么确认配好了
- 上传单批完整的生产台账json文件，检查对话界面未出现字符超限或文件格式错误提示。
- 关联指定的细胞库、MES、LIMS知识库，发起带批号的查询，确认返回的记录字段符合业务要求。
- 切换到正式对话环境，验证与预览环境的知识库关联状态一致，无配置差异提示。
- 在对话设置中开启默认问题预设，确认发起新对话时自动加载预设的批号查询提示。
