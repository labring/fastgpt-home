# 生物制品与无菌生产的生产台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
本品类数据来自细胞库与种子批、过程分析系统、洁净区监测设备、MES、LIMS及设备完整性测试工具。日常文档包含细胞库或种子批记录、培养纯化记录、无菌灌装记录、环境监测数据、培养基模拟灌装结果、无菌检验报告及批放行资料。数据更新节奏分为每批生成、实时上传及按监测计划定期更新。单份台账文档包含批次号、操作时间、工艺参数、环境指标、检验结果等字段，单位涵盖摄氏度、菌落形成单位、件/分钟等专业生产参数单位。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类多源数据接入需求要求工具调用支持对接多个异构系统接口，需配置灵活的工具组调用规则。不同更新频率的数据源需要适配动态触发机制，既支持实时拉取洁净区监测数据，也支持按生产批次触发全量台账汇总。专业且多样的台账字段要求工具调用返回结构化内容，避免无格式的自然语言文本，确保后续报告生成符合合规要求。同时，数据异常或拉取失败可能引发严重生产风险，需配置完善的失败处理与校验机制。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 按触发场景动态选择 | 适配实时洁净区监测数据拉取、生产批次台账汇总的不同需求 |
| `functionCall` | 定义生物制品专属台账字段的结构化输出 | 确保返回内容包含批次号、工艺参数、环境指标等合规字段 |
| 工具调用超时时间 | 600 秒 | 覆盖多系统数据拉取的完整流程，避免因数据量较大导致超时中断 |
| 失败重试策略 | 最多3次重试，间隔120秒 | 应对临时的系统接口波动，降低数据拉取失败风险 |
| 工具返回格式 | Markdown 带专业字段标注 | 让前端解析后呈现清晰的结构化报告，提升可读性 |
| 工作流绑定 | 绑定预设的生产台账汇总工作流 | 确保调用后直接生成符合生物制品合规要求的报告 |

## 容易做错的三处
- 现象：调用API返回的文本流解析后为无格式整段文本，无法区分专业参数字段。原因：未配置`functionCall`要求结构化输出，仅返回自然语言描述，未适配生物制品台账的专业字段展示需求。
- 现象：中间服务转发后流数据传输中断，页面数据固定无更新。原因：未配置超时重试机制，多系统数据拉取超时后未重新发起调用，导致流传输中断。
- 现象：调用指定工作流时返回必填参数缺失错误。原因：未按品类数据特征定义`functionCall`的必填字段，未包含批次号、环境监测数据等核心台账项。

## 怎么确认配好了
- 发起单批次生产台账拉取测试，检查返回结果是否包含细胞库记录、无菌灌装参数等品类专属字段。
- 模拟流数据传输中断场景，验证是否触发失败重试机制并重新拉取完整数据。
- 查看工具调用日志，确认`toolChoice`根据触发场景自动匹配了对应的数据源接口。
- 导出生成的报告，确认格式符合Markdown规范且专业字段带有明确标注。
