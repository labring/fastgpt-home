# 生物制品与无菌生产的生产台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
本品类数据主要来自细胞库与种子批、过程分析系统、洁净区监测设备、MES、LIMS及设备完整性测试工具。日常文档包含细胞库或种子批记录、培养纯化记录、无菌灌装记录、环境监测数据、培养基模拟灌装报告、无菌检验结果及批放行资料。数据更新节奏为每生产批次同步、按监测计划实时更新，字段包含批次标识、过程参数值、监测时间、检验结论等，部分参数需匹配行业通用的物理或生物单位。

## 这些特征在「部署与升级」这一环带来什么约束
本品类的数据特征对部署与升级环节带来多重约束。多源异构的数据来源要求部署阶段配置适配不同系统接口的对接参数，避免数据同步中断。差异化的更新节奏，包括实时监测数据与批次级归档数据，需要分别配置低延迟缓存与批量导入的存储参数。多样的文档格式与专属字段要求升级时兼容新增的无菌生产记录模板，确保台账解析的完整性。同时，数据关联的合规性要求部署环节配置审计日志与权限管控的存储规则，匹配行业数据安全要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `STORAGE_S3_ENDPOINT` | 填写本地MinIO的内网访问地址，如 `http://192.168.1.100:9000` | 适配生物制品生产企业常见的内网部署场景，避免公网访问的硬性要求 |
| `REDIS_URL` | 配置为内网Redis实例地址，连接超时设为 `30 秒` | 保障实时洁净区监测数据的缓存读取效率，适配高频更新的同步需求 |
| `DB_MAX_LINK` | 设置为 `20–30 个连接` | 匹配多源数据对接的并发连接需求，避免因连接数不足导致台账同步中断 |
| `MONGODB_URI` | 填写内网MongoDB的访问地址，开启副本集模式 | 存储批次级归档的生产台账数据，保障数据持久化与容灾能力 |
| `FILE_TOKEN_KEY` | 配置为随机生成的32位字符串 | 加密台账文件的访问令牌，避免未授权访问敏感生产记录 |
| `ROOT_KEY` | 保留默认或配置为强随机字符串 | 管控系统管理员权限，保障部署后的基础安全配置 |

## 容易做错的三处
- 界面显示台账同步失败，日志返回连接超时错误。原因是未配置内网地址的`STORAGE_S3_ENDPOINT`，错误使用公网访问地址导致内网环境下无法连接存储服务。
- 系统插件加载失败，提示未找到指定API对接配置。原因是未在部署配置中正确添加对应接口的参数，导致无法拉取跨系统的生产台账数据。
- 生成的报告缺失无菌检验的关键字段。原因是未配置`DB_MAX_LINK`的合理取值，导致多源数据同步时部分字段未完整拉取。

## 怎么确认配好了
- 使用FastGPT v4.17.0版本的部署脚本执行内网存储服务的连通性测试，访问`STORAGE_S3_ENDPOINT`配置的地址，验证可正常上传与下载台账文件。
- 导入一批模拟的细胞库记录，检查数据同步后的字段完整性与更新时间准确性。
- 调用系统管理员接口，验证`ROOT_KEY`配置的权限管控规则生效。
- 查看Redis连接日志，确认实时监测数据的缓存读取延迟符合预期。
