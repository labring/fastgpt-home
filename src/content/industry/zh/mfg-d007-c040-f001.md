# 电池PACK与储能系统集成的生产台账汇总与报告生成：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的生产台账数据来源包括电芯分容数据、MES系统、焊接设备、扭矩工具、BMS软件版本记录、EOL试验台测试数据。数据更新频率为每完成一个电池包或储能柜的生产即更新一次，每次BMS软件版本变更时同步更新对应台账。日常文档包含配组规则、BOM清单、焊接与扭矩操作记录、BMS刷写记录、绝缘耐压报告、EOL测试结果、系统配置清单。数据字段涵盖电芯容量、内阻、焊接扭矩值、BMS版本号、绝缘电阻值等，对应单位为Ah、mΩ、N·m、V等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据来源分散且更新节奏差异化，要求HTTP接口支持多数据源并行拉取，同时适配按需触发与定时拉取两种模式。多类型文档与字段要求接口请求参数需精准匹配台账的核心字段，避免冗余数据传输。生产出错后果严重的特性，要求接口需具备鉴权校验、数据格式校验与失败重试机制，防止错误数据流入汇总流程。此外，单包/单柜的更新粒度要求接口支持按单个生产单元触发数据拉取，避免全量拉取带来的资源浪费。

## 配置怎么定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer ${token}` | 符合HTTP接口鉴权标准，适配FastGPT v4.17.0的接口调用规则 |
| `variables` | `{"deviceTypes": ["welding", "torque", "eol", "bms"], "updateTrigger": ["perPackage", "versionChange"]}` | 匹配该品类的数据来源与更新频率，精准限定接口拉取的数据源范围 |
| `responseData` | `include: ["cellCapacity", "torqueValue", "insulationResistance", "bmsVersion"], exclude: ["rawSensorRaw"]` | 仅返回台账汇总所需的核心字段，减少接口传输开销 |
| 接口超时时间 | `300 秒` | 该品类单包台账数据量适中，300秒可覆盖多设备数据拉取的完整流程 |
| 请求重试次数 | `3 次` | 应对设备临时离线或网络波动，符合生产场景的稳定性要求 |
| 数据格式校验规则 | 按实测标定 | 匹配该品类的字段格式要求，例如扭矩值需处于0-1000 N·m区间 |

## 容易做错的三处
- 现象：调用接口返回`该令牌无权使用指定服务`报错，日志中包含request id标识。原因：未将FastGPT的调用令牌配置为适配外部系统（如MES、EOL试验台）的鉴权规则，错误使用了通用鉴权凭证。
- 现象：接口返回的`responseData`字段缺少扭矩记录或BMS版本信息。原因：未在`variables`参数中正确指定需要拉取的数据源类型，导致接口仅获取了部分台账数据。
- 现象：接口调用后频繁触发重试失败，最终返回连接超时。原因：未设置合理的重试间隔，导致外部生产设备被重复请求过载。

## 怎么确认配好了
- 调用测试接口，检查返回的`responseData`包含配组规则、扭矩记录、绝缘耐压报告等核心业务字段，字段格式符合预设要求。
- 模拟一次电芯配组操作或BMS版本变更，验证接口能在预设的更新频率内拉取到最新的台账数据。
- 调用接口时使用无效鉴权凭证，确认返回对应鉴权报错，验证`Authorization`配置生效。
- 查看FastGPT的接口调用日志，确认`variables`参数中的数据源配置与实际生产流程匹配。
