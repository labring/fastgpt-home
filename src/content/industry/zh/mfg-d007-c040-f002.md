# 电池PACK与储能系统集成的生产台账汇总与报告生成：向量模型与索引

## 这个品类的数据长什么样
典型主体为动力电池包、储能柜和BMS系统制造商，日常文档包含配组规则、BOM、焊接和扭矩记录、BMS刷写记录、绝缘耐压报告、EOL测试记录、系统配置清单。数据来源涵盖电芯分容数据、MES系统、焊接设备、扭矩工具、BMS软件版本记录、EOL试验台。数据更新频率为每包或每柜生成一次台账，每次BMS软件版本变更时同步更新相关记录。文档包含结构化字段（如电芯内阻、扭矩值、测试电压）与非结构化文本（如测试报告、配置说明），字段单位涵盖Ah、Nm、V等专业电子制造单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的台账数据按单包/单柜独立更新，且更新频率随生产节拍波动，要求索引支持增量更新以避免全量重建的额外耗时。文档类型兼具结构化字段与非结构化文本，要求向量模型能够兼顾结构化数值与自然语言文本的语义匹配。单包台账包含多维度的生产参数，关联数据量较大，需控制向量生成与索引的单次处理规模，避免超出硬件资源上限。同时，生产台账的准确性直接影响系统安全，要求向量召回的精准度需满足业务合规要求，不可出现关键参数的误匹配。

## 配置怎么定
本页配置基于FastGPT v4.17.0版本的界面与参数逻辑。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 覆盖该品类既有短结构化BOM记录、又有长文本EOL报告的文档长度范围，避免过度拆分导致语义断裂 |
| 重叠长度 | 100–150 字符 | 保留跨块的关键生产规则、配组参数等连续信息，防止关键内容被拆分丢失 |
| 相似度阈值 | 0.75–0.85 | 匹配该品类对电芯参数、焊接记录等关键台账项的精准匹配需求，过滤低相关性的召回结果 |
| 单次搜索上限 | 前 10 条 | 生产台账的关联项多为有限批次的同类型记录，过多结果会增加汇总报告的生成耗时 |
| maxToken | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| defaultToken | 按实测标定 | 匹配当前使用的embedding模型的默认token限制，避免输入内容被强制截断 |

## 容易做错的三处
- 界面提示“无可用渠道”或日志返回“该令牌无权使用模型”，原因是未直接配置embedding模型的接入参数，依赖one API中转且渠道配置错误。
- 知识库搜索耗时超过 30 秒，原因是未按单包/单柜的更新频率设置索引增量更新，全量索引重建频率过高，或分块长度过大导致向量生成耗时增加。
- 汇总报告中出现不匹配的电芯配组记录，原因是相似度阈值设置过低，召回了大量无关的历史台账数据，导致汇总结果混乱。

## 怎么确认配好了
- 手动上传一份典型的BMS刷写记录文档，检查向量生成过程无报错，确认模型接入配置正常。
- 输入业务场景化查询，如“某批次储能柜的绝缘耐压测试结果”，核对召回结果的条数与内容是否符合预期，调整相似度阈值至匹配业务需求的范围。
- 查看索引刷新日志，确认仅在新生成PACK台账或BMS版本变更时触发更新，无无效的全量刷新操作。
- 测试输入包含多段生产台账的上下文，确认`maxToken`参数未超出限制，无内容被截断的提示。
