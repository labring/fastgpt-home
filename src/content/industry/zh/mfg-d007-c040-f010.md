# 电池PACK与储能系统集成的生产台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
本品类的生产数据来源包括电芯分容数据、MES系统、焊接设备、扭矩工具、BMS软件版本记录及EOL试验台数据。日常文档涵盖配组规则、BOM清单、焊接与扭矩记录、BMS刷写记录、绝缘耐压报告、EOL测试报告及系统配置清单。数据更新节奏为每生产一包动力电池或一台储能柜更新一次，每次BMS软件版本变更时同步更新对应文档。文档字段包含电芯容量、内阻、物料编码、扭矩值、BMS版本号等，部分字段带有明确单位，如扭矩值单位为N·m。

## 这些特征在「知识库检索与召回」这一环带来什么约束
本品类的数据更新频率高且单批次数据体量小，要求检索系统支持增量更新与精准匹配，避免冗余数据占用上下文。多类型文档并存的结构，要求检索模式同时适配结构化台账字段与非结构化工艺规则。数据字段带有明确单位与业务专属含义，要求检索过程保留字段精度，避免模糊匹配导致的错误关联。此外，生产环节出错后果严重，要求召回结果的相关性与准确性满足业务合规要求，不得混入无关品类的生产数据。

## 配置怎么定
本配置基于FastGPT v4.17.0版本制定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配配组规则、焊接参数这类高精度业务文档，过滤低匹配度的无关数据 |
| `limit` | 单次召回前8条 | 单包生产台账关联的文档数量有限，避免上下文过长导致生成延迟 |
| `searchMode` | `mixedRecall` | 同时覆盖结构化台账字段与非结构化工艺规则，适配多类型业务文档 |
| `usingReRank` | 开启 | 对召回结果二次排序，提升BMS配置、绝缘测试这类关键文档的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展工艺规则类查询的同义表述，覆盖不同业务文档的表述差异 |
| `collectionIds` | 绑定本品类专属知识库集合 | 隔离其他品类的生产数据，避免检索结果混入无关内容 |

## 容易做错的三处
-  检索响应超时，单次调用耗时超过30秒。原因是未限制`limit`参数的取值，召回了过量的历史台账数据，导致上下文长度超出处理阈值。
-  检索结果遗漏BMS刷写记录类文档。原因是未开启`datasetSearchUsingExtensionQuery`，无法匹配工艺文档的同义表述，导致规则类查询无法命中对应业务记录。
-  检索结果混入电芯制造环节的文档。原因是未配置`collectionIds`绑定专属知识库集合，导致跨品类数据干扰检索结果的准确性。

## 怎么确认配好了
-  上传单包储能系统的生产台账与对应工艺文档，发起检索请求，核对返回结果是否包含该包的焊接扭矩记录、BMS版本信息等专属数据。
-  调整`similarity`参数至0.8，发起配组规则相关查询，确认返回结果的匹配度符合预期，无低相关性的无关内容。
-  查看系统检索日志，确认每次召回的文档数量不超过设定的`limit`取值，无异常超时记录。
-  切换至其他品类的知识库集合，发起本品类的业务查询，确认当前检索仅返回本品类的专属文档数据。
