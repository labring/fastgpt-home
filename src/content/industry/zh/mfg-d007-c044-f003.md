# 纸浆造纸的生产台账汇总与报告生成：多轮对话与提示词

## 这个品类的数据长什么样
纸浆造纸的生产台账数据来源包括木浆废纸批次档案、DCS与QCS系统数据、纸机在线测量记录、实验室检测报告、能源与水处理系统日志。日常文档涵盖配浆单、打浆操作记录、纸机运行日志、在线质量曲线、断纸与换品台账等。数据更新节奏分为实时、每班周期、每卷纸生产周期三类。字段包含浆料配比参数、纸机运行转速、克重、厚度、断纸时长等，对应单位为千克、转每分钟、克每平方米、毫米等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
纸浆造纸的台账数据来源分散且类型多样，多轮对话需统一调用不同系统的数据源，提示词需明确区分配浆单、在线质量曲线等不同文档的解析规则。数据更新节奏覆盖实时到周期级，对话中需支持按时间粒度筛选数据，避免查询过时的台账内容。单卷纸生产的台账数据量较大，多轮对话需限制上下文与检索结果数量，防止检索耗时过长。同时生产存在固定的全局参数，需支持持久化存储全局变量，避免重复配置。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 对话会话标识配置 | 绑定`chatId` | 绑定会话标识可确保多轮对话的上下文与检索结果关联正确，基于FastGPT v4.17.0版本适配 |
| 最大上下文长度 | 8000–12000 字符 | 纸浆造纸台账包含多类文档，较长上下文可保留完整的历史对话与多份台账摘要，避免关键参数丢失 |
| 变量存储规则 | 全局持久化`variables` | 纸浆造纸生产存在固定的纸机幅宽、浆料标准配比等全局参数，持久化存储可避免重复配置 |
| 历史对话引用开关 | 开启 | 多轮对话中需关联断纸、换品等历史台账，开启后可自动调用`messages`中的历史内容 |
| 检索触发条件 | 每次对话触发 | 纸浆造纸数据实时更新，每次对话强制检索可确保获取最新的在线质量曲线与运行记录 |
| 单次返回结果数 | 前8条 | 纸浆造纸单类台账数据量较大，过多结果会增加检索耗时，前8条可覆盖主要查询需求 |

## 容易做错的三处
- 对话仅部分触发知识库检索：现象为部分查询未返回台账数据，原因是未设置每次对话强制检索，仅在关键词匹配时触发检索。
- 全局变量无法持久保存：现象为每次重启对话后，预设的纸机幅宽、浆料标准等参数丢失，原因是未开启`variables`的全局持久化存储。
- 多轮对话后检索耗时过长：现象为对话轮次增加后，知识库检索耗时超过60秒，新窗口则恢复正常，原因是未限制最大上下文长度或单次返回结果数，导致每次检索加载过多历史对话与冗余数据。

## 怎么确认配好了
- 发起包含“今日纸机运行数据”的查询，核对返回结果是否包含最新的DCS系统日志与在线质量曲线。
- 预设全局变量如“纸机幅宽”，重启对话后核对变量是否仍保留预设值。
- 发起多轮连续查询，核对检索耗时是否稳定在合理区间，无明显波动。
- 发起包含历史关键词的查询，核对返回结果是否关联之前查询过的断纸与换品记录。
