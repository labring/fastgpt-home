# 纺纱与织造的生产台账汇总与报告生成：向量模型与索引

## 这个品类的数据长什么样
通常棉纺、化纤纺、机织和针织企业的生产台账数据，日常文档包含配棉或配料单、工艺上机单、设备运转记录、纱线检验、坯布检验、疵点记录等。数据来源涵盖原纤维检验报告、ERP系统、纺机与织机实时数据、条干仪、验布机采集数据及订单规格文件。数据更新节奏随每批原料、每班生产、每匹布产出同步更新，单份文档包含纤维指标、配料比例、工艺参数、设备运行参数、检验结果、疵点类型等字段，部分字段带有专属单位，如捻度单位为捻/米、条干均匀度单位为CV%。

## 这些特征在「向量模型与索引」这一环带来什么约束
通常该品类的数据多源异构且更新频繁，不同文档的字段结构差异显著，配棉单与疵点记录的核心信息维度完全不同，导致向量分块时需匹配文档类型调整分块逻辑，避免拆分关键工艺参数或检验结果。高频更新的生产数据要求索引支持增量同步，避免因全量重建索引占用过多生产系统资源。同时，纺织专业术语较多，如捻度、条干CV%、疵点类型等，向量模型需准确捕捉这类术语的语义关联，否则可能导致检索结果偏离生产台账的核心需求。另外，单批生产对应的台账数据关联性强，索引需支持按生产批次、设备编号等维度进行分组检索，提升汇总报告的生成效率。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 该品类的工艺单、检验记录单份核心内容长度多在该区间，可完整保留单份文档的专业语义 |
| 重叠长度 | 100–150 字符 | 生产台账的配料比例、工艺参数为连续字段，重叠分块可避免关键信息被拆分 |
| 相似度阈值 | 0.72–0.85 | 该品类专业术语较多，该区间可过滤低相关性结果，同时保留同工艺的关联结果，具体按实测标定 |
| 单次搜索上限 | 前 8 条 | 生产台账汇总需覆盖多类文档，该数量可兼顾召回覆盖率与检索效率 |
| `maxToken` | 3500–4500 token | 生产台账汇总需整合多份文档信息，该区间可覆盖典型场景的上下文需求 |
| `defaultToken` | 1000 token | 单份台账文档的向量嵌入长度适配该取值，避免嵌入时截断核心内容 |

## 容易做错的三处
- 现象：上传配棉单后返回处理成功，但检索时无法找到对应文档内容。原因：未开启增量索引同步，或分块长度设置超出向量模型的最大输入限制，导致文档被截断。
- 现象：调用文件上传API后无法获取索引完成状态，导致生产台账汇总流程阻塞。原因：未对接FastGPT的文件处理状态回调接口，或未正确配置索引完成的校验逻辑。
- 现象：检索疵点记录时返回大量与生产台账无关的内容，汇总报告出现冗余信息。原因：相似度阈值设置过低，未过滤低相关性的检索结果，未按生产批次进行分组检索。

## 怎么确认配好了
- 上传一份已知核心内容的配棉单，等待处理完成后，通过检索接口输入配棉比例关键词，核对返回结果中是否包含该文档的核心信息。
- 调用文件上传API，监听返回的回调参数，确认索引完成状态字段是否被正确标记。
- 更换向量模型后，重新生成现有文档的向量嵌入，检索同一份工艺单，对比更换前后的检索结果相关性差异。
- 输入疵点类型关键词，核对返回结果的相似度是否符合预设的阈值区间，避免出现过多无关内容。
