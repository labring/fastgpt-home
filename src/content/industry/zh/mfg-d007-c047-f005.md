# 计量器具与实验室管理的生产台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
本品类的数据覆盖企业计量室、CNAS体系实验室等主体的计量相关文档，包含量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账及偏离处置文件。数据来源涵盖企业内部计量管理系统、外部校准机构证书、标准器数据、LIMS系统及环境监测记录。数据更新按校准周期、单次试验完成或异常事件触发，单条记录包含器具编号、校准日期、有效期、测量不确定度、使用范围等字段，部分字段需匹配法定计量溯源要求。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类的数据特征对工具调用与插件环节带来明确约束：多源异构的数据来源要求插件需兼容计量管理系统、LIMS、外部校准证书等不同格式的输入，需支持结构化字段提取与非结构化证书文本解析。数据按校准周期、试验或异常更新的节奏，要求工具调用需同时支持定时拉取与实时触发两种模式，保障数据时效性。字段需匹配计量溯源要求，工具输出的台账汇总需包含器具编号、校准有效期、不确定度等强制字段，不可遗漏或篡改核心计量信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工作流/API 工具选择配置 | 指定自定义函数 | 限制工具调用范围，仅执行计量台账、校准证书相关的自定义工具 |
| 工作流/API 函数调用配置 | 仅调用计量数据解析、溯源校验类函数 | 避免调用无关工具，保障输出符合计量溯源与CNAS体系要求 |
| 单次工具调用数据量上限 | 前100条记录 | 匹配计量台账的常规批量处理规模，避免系统过载 |
| 超时阈值 | 300秒 | 适配校准证书解析、多源数据拼接的复杂处理时长 |
| 文本提取最大长度 | 800–1200字符 | 适配校准证书、试验原始记录的常规文本长度 |
| 触发模式 | 定时拉取+实时触发双模式 | 适配按校准周期、单次试验、异常事件的不同数据更新节奏 |

## 容易做错的三处
- 现象：调用文本提取工具时返回400 Invalid JSON payload received. Unknown name错误。原因：未严格按照计量文档的字段结构封装请求参数，额外传入了非预期的自定义字段。
- 现象：通过API调用配置好的工作流时，无法获取上下文关联数据。原因：未在请求参数中正确携带上下文标识，或触发模式未配置为支持上下文传递。
- 现象：调用工作流API时，无法明确`model`参数的作用范围。原因：未在工作流配置中绑定对应计量数据处理的任务模型，导致参数逻辑模糊。

## 怎么确认配好了
- 传入标准量具台账的样本数据发起调用，核对返回结果的字段与预设的计量文档字段清单匹配。
- 配置定时触发任务，验证系统能按预设的更新节奏自动拉取数据并生成汇总内容。
- 传入包含非合规字段的测试数据，确认工具调用会触发合规校验流程。
- 调用API并携带上下文标识，核对返回结果能关联对应历史计量记录的上下文信息。
