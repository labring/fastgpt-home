# 过程质量与成品放行的生产台账汇总与报告生成：工作流编排

## 这个品类的数据长什么样
本品类数据覆盖制造企业IPQC、FQC、质量工程及实验室的全流程质检相关内容，日常文档包含控制计划、巡检记录、SPC报表、成品检验报告、不合格品评审、放行单、质量月报。数据来源包括MES系统、在线检测设备、实验室仪器、工艺参数库、客户标准及历史缺陷库，更新频率为每生产批次、每班或持续采集。数据字段包含生产批次标识、检验项实测值、合格判定结果、不合格处置记录、放行审批状态，字段单位匹配对应检测项的实际计量要求。

## 这些特征在「工作流编排」这一环带来什么约束
数据来源分散且类型多样，要求工作流需配置多节点适配不同数据源的接入格式，避免数据采集遗漏。更新频率与生产批次强绑定，要求工作流需支持按批次触发或定时触发的调度模式，匹配业务数据生成节奏。日常文档包含多类质检专业格式，要求工作流的文档解析节点需覆盖多种文件类型的解析规则。核心耗时环节包括将标准转化为可执行检验项、识别趋势异常并隔离影响范围、组织不合格评审与放行审核，要求工作流需内置标准匹配、异常分支判断及审批流转的标准化节点，减少人工重复操作。同时，异常未处理会引发批量不良等后果，要求工作流需配置异常阻断与告警节点，确保不合格品管控到位。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 触发方式 | 按生产批次触发，或按每班定时触发 | 匹配数据每批、每班的更新节奏，确保台账生成与业务同步 |
| `variables` 映射规则 | 绑定生产批次号、检验项参数、合格阈值为全局变量 | 统一调用多数据源的标准字段，避免重复配置与字段不一致问题 |
| `nodeId` 配置 | 为异常识别、评审流转节点分配唯一`nodeId` | 便于工作流调试与异常定位，支持多分支流转的精准控制 |
| 文档解析节点 | 适配控制计划、SPC报表等多格式解析 | 覆盖本品类全量日常文档的采集需求，确保数据完整 |
| 单节点超时设置 | 300–600 秒 | 匹配质检数据采集、评审流程的实际耗时，避免因超时中断任务 |
| 外部MCP插件接入 | 开启插件授权通道，绑定检测设备触发节点 | 支持直接接入在线检测设备数据，减少手动录入工作量 |

## 容易做错的三处
- 现象：工作流调用后仍返回知识库搜索结果，原因：未在工作流节点中关闭知识库检索开关，或未配置仅调用工具的执行模式。
- 现象：异常识别节点未触发阻断流程，原因：未配置异常判定后的分支跳转逻辑，导致不合格品未被及时隔离，引发批量不良风险。
- 现象：工作流中问题分类识别准确率偏低，原因：未针对质检场景的专业术语优化提示词，或未选用适配工业质检语义特征的模型配置。

## 怎么确认配好了
- 手动触发对应生产批次的工作流，检查是否自动拉取对应批次的MES数据与检测设备记录。
- 模拟不合格判定结果，确认工作流是否自动跳转至评审流转节点并触发审批流程。
- 查看工作流运行日志，确认所有`variables`参数均已正确绑定对应数据源的字段值。
- 测试外部MCP插件接入，确认检测设备的实时数据可正常同步至工作流节点。
