# 通用机械设备装配的生产台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
通用机械设备装配场景的生产台账数据，通常来自PLM/ERP系统、零件检验记录、装配工具采集数据、试验台数据、MES系统及客户技术协议。日常需归集的文档包括装配工艺卡、多层BOM、扭矩与间隙调整记录、试运行报告、出厂检验单与装箱清单。数据更新节奏为单台设备或每订单触发，字段包含设备型号、装配工序参数、检验数值、客户验收要求等，单位涵盖扭矩值（N·m）、间隙（mm）、压力（MPa）等，随装配环节推进逐步补充完整。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据多源分散、按单台/订单更新且含精准数值字段，为部署与升级带来多重约束。需对接PLM、ERP、MES等多系统接口，配置跨系统字段映射规则，确保数据准确同步。增量更新的特性要求系统优化同步逻辑，避免全量拉取占用过多存储与计算资源。带单位的工艺与检验数据，需配置统一的数值解析与格式校验规则，确保台账汇总的一致性。自定义客户技术协议字段，需支持灵活扩展，升级时需兼容旧版本自定义结构，避免历史数据失效。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `10–15` | 适配多系统并发的台账数据拉取请求，避免数据库连接耗尽 |
| `REDIS_URL` | `redis://:自定义密码@部署主机:6379/0` | 缓存装配工序的临时数据与订单关联关系，降低重复查询数据库的开销 |
| `STORAGE_S3_ENDPOINT` | `按企业自建对象存储服务地址填写` | 存储装配工艺卡、检验报告等附件，确保多节点部署下的附件访问一致性 |
| `PG_URL` | `postgresql://用户名:密码@数据库地址:5432/装配台账库` | 存储结构化的台账数据，适配多字段关联的汇总查询需求 |
| 数据同步触发规则 | 按订单完成节点触发 | 匹配单台设备装配的更新节奏，避免无效的全量同步 |
| `FILE_TOKEN_KEY` | `按企业内部安全规范生成随机字符串` | 保障台账附件的下载权限验证安全，防止未授权访问 |

## 容易做错的三处
- 调用台账汇总接口返回`code500 Cannot read p`，原因是未正确配置`REDIS_URL`的连接参数，导致缓存数据读取失败。
- 上传装配相关的图片或文档后，系统无法加载附件，原因是未配置`STORAGE_S3_ENDPOINT`或存储路径权限不足，导致附件无法正常读取。
- 调用外部模型接口返回400错误，原因是`DB_MAX_LINK`设置过高导致数据库连接池耗尽，接口响应异常。

## 怎么确认配好了
- 执行`curl`命令调用台账同步接口，检查返回状态码为200，且返回数据包含装配工艺卡、BOM等核心字段。
- 登录FastGPT后台，查看`REDIS_URL`的连接状态，确认显示正常连接。
- 上传一份装配检验报告附件，检查系统能否正常加载并关联到对应订单台账。
- 查看数据库连接池监控，确认当前连接数未超过`DB_MAX_LINK`的设置值。
