# 金属切削加工的生产台账汇总与报告生成：模型接入与配置

本页面基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
本品类数据来源包括产品图纸与三维模型、CAPP/CAM系统、机床采集终端、刀具管理系统、MES系统及量检具数据。日常产生的文档包含工艺路线、工序卡、刀具清单、数控程序、首件检验记录、巡检表、量具校准记录。数据更新随每工单、每件工件或抽检、刀具更换动作触发，字段包含刀具寿命、工序尺寸偏差、机床运行时长等，对应单位为分钟、毫米、小时。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据格式（含静态图纸、数控程序文本、动态采集表格）要求模型接入支持多模态输入，需配置对应视觉处理参数。高频更新的工单级数据要求上下文窗口适配单次任务的全量关联文档，避免截断关键工艺与检验信息。特定行业专属字段（如刀具磨损量、工序尺寸偏差）要求模型生成时精准匹配行业定义，需调整生成参数平衡准确性与灵活性。离线部署场景下需配置本地API端点，无需依赖外部中转服务。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `vision` | 开启（`true`） | 需处理产品图纸、数控程序截图等视觉类文档，支持多模态输入 |
| `maxContext` | `8000–12000 token` | 适配单工单多源文档的上下文长度，避免截断关键工艺与检验数据 |
| `maxTokens` | `2000–3000 token` | 控制单份台账报告的生成长度，匹配工序卡、巡检记录的汇总需求 |
| `quoteMaxToken` | `1000–1500 token` | 限制引用文档的单段长度，避免冗余内容干扰台账汇总 |
| `temperature` | `0.2–0.4` | 降低生成随机性，确保刀具寿命、工序尺寸等行业专属字段的输出准确性 |
| `toolChoice` | `auto` | 自动判断是否调用工具处理实时机床数据或刀具寿命计算，适配多环节台账汇总 |
| `AIPROXY_API_ENDPOINT` | 本地部署的FastGPT API地址 | 适配离线部署场景，无需依赖外部中转服务 |
| `AIPROXY_API_TOKEN` | 对应部署环境的访问密钥 | 用于身份验证，确保API调用权限合法 |

## 容易做错的三处
- 模型测试时返回「请求错误」，离线部署场景下无法连通模型服务。原因：未正确填写`AIPROXY_API_ENDPOINT`为本地部署地址，或未配置有效的`AIPROXY_API_TOKEN`，导致身份验证失败。
- 导入工艺图纸与数控程序后，模型未识别相关内容且无有效输出。原因：未开启`vision`参数，未配置多模态输入支持，无法处理非文本类行业文档。
- 生成的台账缺失刀具寿命、工序尺寸等关键参数，或字段单位错误。原因：`temperature`取值过高，导致生成结果偏离行业标准字段定义与单位规范。

## 怎么确认配好了
- 执行模型测试功能，检查返回结果是否包含工艺路线、刀具参数等金属切削行业专属字段。
- 导入单份工单的多源文档（如工序卡、巡检表、刀具清单），验证生成的台账是否完整覆盖所有关联数据。
- 调整`temperature`参数后对比生成结果，确认字段准确性随参数调整符合预期。
- 查看API调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置未触发权限或连通错误。
