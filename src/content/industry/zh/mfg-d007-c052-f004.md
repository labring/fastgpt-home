# 钢材轧制与精整的生产台账汇总与报告生成：工作流编排

## 这个品类的数据长什么样
钢材轧制与精整的生产数据来源于板坯或钢坯批次、加热炉、轧机自动控制系统、在线测厚测宽设备、表面检测装置与MES系统。日常生成的文档包含轧制计划、加热制度、轧制规程、板形厚度记录、表面质量报告、质保书。数据更新频率为每卷或每支实时更新，核心字段包括卷号、加热温度、轧制速度、厚度偏差、表面缺陷等级，对应单位分别为批次标识、摄氏度、米每秒、毫米、缺陷等级。

## 这些特征在「工作流编排」这一环带来什么约束
多源异构的实时数据要求工作流需串联多个节点完成跨系统数据拉取，避免数据延迟导致台账归集错误。按卷或每支的精准更新节奏，要求工作流需绑定卷号作为核心全局变量，实现单批次生产数据的独立归集与汇总。多样的文档格式与字段结构，要求工作流需配置格式转换节点，统一不同来源文档的输出格式。丰富的核心生产字段，要求工作流需增加参数校验环节，过滤缺失或异常的数据，防止后续报告生成出现错误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 变量设置 | 绑定卷号、批次ID作为全局`variables` | 匹配每卷或每支的实时数据更新逻辑，避免跨批次数据混淆 |
| 节点校验规则 | 检查`nodeId`对应节点的必填字段填充率 | 确保轧制温度、厚度偏差等核心生产数据无缺失 |
| 数据拉取间隔 | 10–30 秒 | 适配在线检测设备的实时数据更新频率 |
| 特殊字符处理 | 自动转义双引号、换行符 | 适配质保书、表面质量报告中的特殊格式内容 |
| 基准测试触发 | 按实测标定 | 用于开展模型对比与消融实验 |
| 超时阈值 | 600 秒 | 适配多数据源联合拉取的耗时要求 |

## 容易做错的三处
- 现象：工作流调试校验失败，提示请检查节点是否正确填值以及连线是否正常。原因：未将卷号等核心`variables`绑定到对应节点的输入参数，导致节点无有效数据触发。
- 现象：工作流生成的报告中出现格式错乱或乱码。原因：未配置特殊字符处理规则，未对质保书、表面检测记录中的双引号、换行符做转义处理。
- 现象：基准测试运行无结果或结果条数不符合预期。原因：未明确测试触发的数据集范围，未限定对比实验的参数边界。

## 怎么确认配好了
- 手动触发工作流，输入已知卷号的测试数据，核对节点输出的台账字段是否与MES系统中的记录一致。
- 导入包含双引号、换行符的模拟表面质量报告，检查生成的报告是否无格式错乱问题。
- 运行基准测试，对比不同配置下的台账汇总结果，确认测试数据集的覆盖范围符合业务需求。
- 查看FastGPT v4.17.0版本的工作流运行日志，确认`nodeId`对应的节点均正常完成数据拉取与校验，无超时报错。
