# 钣金下料折弯的生产台账汇总与报告生成：向量模型与索引

## 这个品类的数据长什么样
该品类数据主要来自CAD/CAM软件、订单BOM系统、板材库存台账、激光切割机与折弯机设备日志、MES生产管理系统。日常产生的文档包含三维件展开图、数控下料程序、折弯工艺卡、套料图、首件检验记录、工序流转卡，单份文档包含板材规格、折弯系数、下料尺寸、工序编号、流转状态等字段，单位涵盖毫米、平方米、千克、件数。数据更新随每笔订单、每日生产排班、每次产线换型触发，无固定批量更新周期。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据特征对向量模型与索引环节带来多重约束。首先，文档包含工程图纸、工艺参数、流转记录等多类型内容，要求索引支持结构化字段与非结构化文本的联合语义编码；其次，数据随订单、排班和换型频繁变化，应结合当前版本实际报告的处理状态与任务日志确认从提交到可检索的耗时，不能仅凭更新频率推断存在可配置的增量索引开关，也不能假定每次更新都会全量重建；再者，单份文档包含折弯系数、下料尺寸等专业工程参数，向量模型需具备工程领域语义理解能力，确保参数关联的检索准确性。

## 配置怎么定
以下配置适配FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 匹配折弯工艺卡、套料图等文档的单段工程文本长度，避免语义割裂 |
| 重叠长度 | 50–80 字符 | 保留折弯系数、下料尺寸等关键参数的跨块关联信息 |
| 相似度阈值 | 0.72–0.85 | 过滤低匹配度的非相关生产记录，确保检索结果贴合台账汇总需求 |
| 单次搜索上限 | 前 10 条 | 控制检索结果规模，适配生产台账的批量汇总处理逻辑 |
| `maxToken` | 4096 | 适配工程文本与参数的总长度，避免截断关键工艺信息 |
| 重排 | 按实测标定 | 针对钣金领域的专业术语优化重排逻辑，提升核心参数的检索优先级 |

## 容易做错的三处
- 新建知识库时未见图片索引选项：先核对当前 FastGPT 版本与版本套餐。v4.17.2 的[数据集 OpenAPI](https://doc.fastgpt.cn/zh-CN/openapi/dataset)将`imageIndex`标注为商业版支持；若使用商业版仍缺少该选项，再核对对应配置、发行包和接口版本，不应先归因于未安装多模态插件或未开启某个开关。
- 检索结果中混入大量非当前订单的工艺卡数据。原因：相似度阈值设置偏低，未有效过滤不匹配的生产记录。
- 产线换型后新增或更新的工艺卡迟迟无法检索。排查：查看本次任务实际报告的处理状态与日志；任务完成后用该批次特有字段验证检索，并根据日志定位延迟环节，不要直接归因于未配置增量索引或每次全量重建。

## 怎么确认配好了
- 上传一份折弯工艺卡与套料图的混合文档，检查索引解析后的字段是否包含板材规格、折弯系数等关键生产参数。
- 在测试数据中提交一份带唯一字段的新增工艺卡，查看该任务实际报告的处理状态与日志；任务完成后以该字段检索，确认新内容可检索。若耗时异常，依据日志定位环节，不预设存在某个增量索引开关或每次更新都会全量重建。
- 发起包含“折弯顺序”“余料管理”的检索请求，核对返回结果的相关性是否符合业务预期。
- 确认配置项中的分块长度、重叠长度等参数已根据文档类型完成适配，无明显的语义割裂问题。
- 若需要图像索引，先核验当前版本/套餐的`imageIndex`支持；v4.17.2 的 OpenAPI 将其限定为商业版。若部署支持该能力，在测试数据中提交含独特可辨识内容的图像，查看任务实际状态与日志，并在处理完成后按该部署支持的检索方式确认图像内容可检索；需配置的开关或调用的 API 以当前部署文档为准。
