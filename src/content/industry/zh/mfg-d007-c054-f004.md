# 钣金下料折弯的生产台账汇总与报告生成：工作流编排

## 这个品类的数据长什么样
钣金下料折弯的生产数据通常来自CAD/CAM软件、订单BOM、板材库存系统、激光切割机与折弯机设备日志、MES系统。日常关联文档包括展开图、数控下料程序、折弯工艺卡、套料图、首件记录、工序流转卡。数据更新节奏随订单交付、每日生产、设备换型调整，包含板材厚度、折弯补偿系数、展开尺寸、下料数量、工位流转时长等字段，单位多为毫米、千克、小时。

## 这些特征在「工作流编排」这一环带来什么约束
多品种小批量的业务模式要求工作流支持动态适配不同订单的BOM与工艺参数，因此需通过`variables`绑定多源动态字段。多类数据源的接入需明确数据校验节点，避免格式不匹配的文档进入流程。高频更新的生产数据要求工作流触发时机与订单提交、设备换型同步，不宜设置过长的固定周期。展开图计算、套料规划等耗时环节需单独拆分节点，便于单独配置超时与重试策略，减少整体流程的阻塞风险。

## 配置怎么定
本文基于FastGPT v4.17.0版本编写。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 绑定订单BOM、板材库存、设备日志的动态字段集 | 适配多品种小批量的订单参数差异 |
| 触发节点规则 | 按订单提交、换型完成触发，间隔不低于300秒 | 匹配生产数据的更新节奏，避免重复执行 |
| 节点超时阈值 | 单节点超时设置为1200秒 | 覆盖展开图计算、套料规划的常规耗时 |
| `nodeId`映射 | 绑定下料、折弯、台账生成的节点ID | 确保工作流按生产工序顺序执行 |
| 知识库调用开关 | 仅工艺查询环节开启，关闭自动引用 | 避免冗余的搜索日志混入最终报告 |
| 输出格式配置 | 支持HTML、PDF两种格式，默认输出HTML | 匹配生产台账的日常查看与存档需求 |

## 容易做错的三处
- 工作流执行到指定HTML输出节点后无报错但直接跳过进入下一分支。原因是未将`variables`中绑定的HTML内容字段正确映射到输出节点的参数位，导致节点无法识别输出内容。
- 工作流运行整体超时。原因是未拆分长耗时的展开图计算、套料规划节点，且未设置合理的单节点超时阈值，导致单个环节阻塞后拖慢整体流程。
- 工具调用生成的生产报告中附带了知识库搜索的input和response字段。原因是未关闭工作流节点的自动引用配置，导致系统将搜索过程的日志写入最终输出内容。

## 怎么确认配好了
- 触发模拟订单的工作流，检查输出节点是否生成包含展开尺寸、下料数量、折弯参数的标准生产台账内容。
- 查看工作流运行日志，确认`variables`绑定的字段均正确从CAD/CAM、MES等数据源获取，无缺失或格式错误。
- 测试设备换型后的触发动作，确认工作流按预设规则启动，未出现重复执行或延迟的情况。
- 调用工具生成报告，检查输出内容中无冗余的知识库搜索相关字段，仅保留生产台账的核心信息。
