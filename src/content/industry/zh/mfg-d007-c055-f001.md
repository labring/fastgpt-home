# 铸造（砂型、精密、压铸）的生产台账汇总与报告生成：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的生产数据包含铸造工艺卡、配料单、炉次记录、模具履历、首件检验记录、材质报告、不合格品评审单等文档。数据来源覆盖ERP物料主数据、熔炼炉与测温仪、光谱仪、MES炉次记录、模具管理系统、客户图纸与技术条件。更新节奏按每炉次、每批或每日执行，字段包含合金配料比例、熔炼温度、浇注参数、模具模次、缺陷类型等，单位涉及摄氏度、千克、ppm等。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
多源且分散的数据来源，导致HTTP接口需适配不同设备、系统的异构输出格式与字段命名，增加参数校验的复杂度。高频更新节奏（每炉次、每批或每日）要求接口响应延迟控制在合理范围，避免生产台账数据积压。多类型字段与不合格品评审单等附带文档的传输需求，要求接口支持结构化参数与文件流传输。跨部门的自定义字段映射需求，需接口预留灵活的字段适配配置项。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {企业自定义令牌}` | 符合多数外部生产系统的OAuth2认证格式，保障接口访问安全 |
| `variables` | `{"炉次ID": "${input.炉次号}", "熔炼温度": "${data.测温仪数据}"}` | 将生产系统的实时字段映射为接口请求变量，适配多源数据拼接需求 |
| `responseData` | `{"台账ID": "id", "生成状态": "status"}` | 按铸造台账的核心字段提取返回结果，便于后续系统解析与调用 |
| 接口超时时间 | `30–60 秒` | 适配熔炼炉等设备的数据采集延迟，避免高频请求触发超时，适配FastGPT v4.17.0的工作流节点配置逻辑 |
| 请求重试次数 | `前 2 次` | 平衡接口稳定性与资源消耗，应对短暂的网络波动 |
| 附件传输开关 | 按实测标定 | 根据是否需要传输炉次记录的扫描件、光谱仪检测报告等附件调整配置 |

## 容易做错的三处
- 现象：调用接口后返回状态码401，认证失败。原因：未正确配置`Authorization`参数的令牌格式，或令牌权限未覆盖目标生产系统接口。
- 现象：工作流中知识库检索结果传入HTTP接口后，AI对话无法正确关联生产台账。原因：未按`responseData`要求配置返回字段的映射规则，导致AI无法获取台账的关键标识信息。
- 现象：重启FastGPT服务后，配置的`Authorization`令牌丢失，接口认证失败。原因：未将认证信息保存至全局配置，仅存储在临时会话中，服务重启后配置失效。

## 怎么确认配好了
- 手动触发一次接口请求，查看返回结果的字段是否与`responseData`配置的映射规则一致。
- 检查`Authorization`参数的格式是否符合目标系统的认证要求，可通过模拟请求工具验证认证通过状态。
- 模拟按生产节奏发起的高频请求，确认接口响应延迟符合业务需求，无持续超时情况。
- 重启FastGPT服务后，检查`Authorization`等配置项是否仍保留，未出现丢失情况。
