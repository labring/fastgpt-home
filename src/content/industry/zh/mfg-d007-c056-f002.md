# 锂离子电芯制造的生产台账汇总与报告生成：向量模型与索引

## 这个品类的数据长什么样
该品类数据来自动力、储能及消费电池企业的极片、装配、化成与品质部门，日常文档包含配料记录、涂布辊压参数、卷绕/叠片记录、注液记录、化成分容数据、OCV与安全测试报告。数据来源覆盖原材料批次、MES系统、浆料与涂布检测、露点监测、化成分容柜及实验室数据，更新频率为每批、每只电芯级别，部分监测数据实时更新。电化学体系对水分、洁净度与批次一致性要求极高，后段化成分容环节耗时较长。

## 这些特征在「向量模型与索引」这一环带来什么约束
数据更新频率高且粒度细，需支持高频增量索引与单条数据快速更新，避免全量重建带来的性能损耗。多源异构数据格式差异大，需适配结构化参数与非结构化报告的统一向量化处理。批次关联的强关联性要求索引保留数据间的批次归属关系，避免跨批次数据混淆。电化学相关参数的精度要求高，向量模型需能捕捉细微参数差异，同时需限制长文本冗余信息的嵌入，避免向量维度冗余。实时监测数据的索引延迟需匹配生产节拍，确保台账汇总的时效性。部分场景需引入批次间的关联关系，需额外配置实体关联索引逻辑以满足台账的关联汇总需求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 匹配单份台账记录的平均长度，避免单块包含跨批次数据 |
| 重叠长度 | 50–80 字符 | 保留批次关联信息的连续性，防止块间数据断裂 |
| 相似度阈值 | 0.75–0.85 | 区分同批次与跨批次的参数差异，避免误关联 |
| 单次搜索上限 | 前 20 条 | 覆盖单批次的核心检测数据量，避免冗余结果干扰汇总 |
| `maxToken` | 8000  | 容纳多份检测报告与参数记录的拼接长度，适配长文本向量化 |
| 问题优化 | 按实测标定 | 适配电化学参数的语义理解需求，优化查询向量与文档向量的匹配精度 |

## 容易做错的三处
- 现象：尝试将多模态向量模型与文本向量模型混用，界面提示不支持跨模型索引。原因：未开启多模型混合索引配置，未确认平台对多模态与文本向量的兼容设置。
- 现象：调用向量模型时返回报错「模型不支持当前调用格式」，状态码为400。原因：未针对多模态向量模型调整调用参数，混用了文本向量的调用模板。
- 现象：增量索引时出现字段为空的报错，部分台账记录无法被索引。原因：未适配电化学检测数据中的空值字段，未配置空值跳过规则。

## 怎么确认配好了
- 上传单份批次台账记录，检查索引生成的向量维度与配置的`defaultToken`设置是否匹配。
- 发起针对单批次参数的查询，核对返回结果的条数是否符合单次搜索上限的配置。
- 导入多源异构数据，检查结构化参数与非结构化报告是否均被正确向量化并索引。
- 触发增量索引任务，确认新增的实时监测数据可被快速纳入索引库。
