# 锂离子电芯制造的生产台账汇总与报告生成：工具调用与插件

## 这个品类的数据长什么样
该品类的数据来自原材料批次台账、车间MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室测试设备。日常生成的文档包括配料记录、涂布辊压参数日志、卷绕/叠片工序记录、注液台账、化成分容数据、OCV与安全测试报告。数据更新节奏覆盖单批次、单只电芯维度，部分参数如车间露点、涂布面密度为实时更新，单条记录包含工序编号、设备编号、参数实测值、操作人员标识与时间戳。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源数据接入需求要求插件支持对接MES系统、专用检测设备API及实验室数据接口，需兼容不同的请求协议与返回格式。实时更新的参数如车间露点、涂布面密度需要工具调用具备短间隔触发能力，需合理配置调用频率与超时阈值。单批次、单只电芯的高频数据生成的台账，要求工具调用支持按工序、批次维度进行数据筛选与聚合，避免冗余数据导入。电化学体系对数据一致性要求严格，工具调用返回的参数需包含完整的字段校验逻辑，防止异常值或空字段影响后续报告生成。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配多源数据的自动触发逻辑，覆盖不同工序的台账数据调用需求 |
| 工具调用超时时间 | 30 秒 | 匹配实时参数的更新间隔，避免长等待导致的流程阻塞 |
| 单次调用返回最大条数 | 前 200 条 | 适配单批次电芯的台账数据量，避免上下文溢出 |
| 数据聚合维度 | 按生产批次分组 | 匹配锂离子电芯制造的台账汇总逻辑，便于生成批次级报告 |
| `functionCall` | 启用 | 强制大模型按预设工具调用格式返回结果，确保参数解析准确性 |
| 字段校验阈值 | 按实测标定 | 适配不同工序的参数范围要求，避免异常数据进入报告 |

## 容易做错的三处
- 现象：MCP服务调用失败，日志显示「请求超时」或「响应格式错误」。原因：未配置符合实时参数更新节奏的超时时间，或插件未适配专用检测设备的非标准API返回格式。
- 现象：无法将HTTP响应的入参变量添加到工具调用流程中。原因：未将响应字段与台账模板的预设字段做映射绑定，或入参变量的命名未匹配工具定义的参数名。
- 现象：大模型未触发工具调用，仅直接生成文本报告。原因：`toolChoice`配置为`none`，或未在系统提示词中明确要求工具调用的触发条件。

## 怎么确认配好了
- 触发一次工具调用，检查返回的台账数据是否包含配料记录、涂布参数等预设的品类专属字段。
- 查看工具调用日志，确认超时时间设置匹配30秒的配置，无频繁超时报错。
- 在FastGPT v4.17.0的工作流编辑界面中，确认工具节点已绑定对应的数据源插件。
- 测试单批次数据的聚合逻辑，确认返回结果按生产批次分组展示。
