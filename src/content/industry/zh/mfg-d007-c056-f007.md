# 锂离子电芯制造的生产台账汇总与报告生成：数据库与运维

## 这个品类的数据长什么样
锂离子电芯制造的生产台账数据来自原材料批次、MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室检测系统。日常记录包含配料记录、涂布辊压参数、卷绕或叠片记录、注液记录、化成分容数据、OCV与安全测试报告。数据按生产工序分层更新，更新节奏涵盖每批电芯、单只电芯及实时检测。字段包含批次号、设备编号、检测时间、参数数值等，单位涉及质量、电压、时间、面积等维度，各工序数据需跨环节关联用于一致性校验。

## 这些特征在「数据库与运维」这一环带来什么约束
多源且高频的更新节奏要求数据库支持高并发写入与批量查询，避免数据延迟或丢失。多工序关联的业务逻辑需要数据库具备跨表/集合的关联查询能力，同时需严格的字段校验机制，防止浆料固含量、面密度等专业参数的脏数据流入。电化学生产的安全属性要求数据库配置权限隔离，限制敏感检测数据的访问范围。此外，单批次数据量随生产规模增长，需合理规划存储与索引策略，避免汇总查询耗时过长。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://admin:${pwd}@192.168.1.100:27017/lithium_ledger?authSource=admin` | 适配非结构化的化成分容、安全测试数据存储，支持权限验证与分布式部署 |
| `PG_URL` | `postgresql://postgres:${pwd}@192.168.1.101:5432/prod_ledger` | 存储结构化的配料、辊压、注液等台账数据，支持复杂跨工序关联查询 |
| `DB_MAX_LINK` | `150–250 个` | 匹配每批次多工序的并发写入与查询请求，避免数据库连接池耗尽 |
| `REDIS_URL` | `redis://default:${pwd}@192.168.1.102:6379/0` | 缓存高频访问的设备参数、批次基准值，降低数据库的重复查询负载 |
| 数据库联合索引配置 | 按批次号、工序ID、检测时间创建联合索引 | 加速跨工序的台账汇总查询，匹配数据按工序分层的更新逻辑 |

## 容易做错的三处
- 现象：使用MongoDB Compass连接FastGPT绑定的MongoDB时返回认证失败或连接超时。原因：未在`MONGODB_URI`中配置正确的认证源参数，或未开放数据库所在服务器的端口访问权限。
- 现象：跨工序的生产台账汇总结果为空或字段缺失。原因：未按批次号、工序ID创建联合索引，导致关联查询无法匹配对应工序的记录数据。
- 现象：数据库写入请求频繁超时。原因：`DB_MAX_LINK`取值低于当前并发写入的请求量，连接池耗尽无法分配新的数据库连接。

## 怎么确认配好了
- 执行命令行连接配置的`MONGODB_URI`，验证能否成功登录并查询化成分容数据集合。
- 运行FastGPT内置的text2Sql测试工具，输入「查询指定批次的涂布辊压参数」，验证能否返回对应结构化台账数据。
- 查看数据库连接池监控面板，确认当前活跃连接数未超过`DB_MAX_LINK`的配置值。
- 向测试批次写入一条完整的配料记录，验证能否在对应数据库集合中查询到全部配置字段。
