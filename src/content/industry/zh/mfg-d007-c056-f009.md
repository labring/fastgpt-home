# 锂离子电芯制造的生产台账汇总与报告生成：模型接入与配置

## 这个品类的数据长什么样
该品类的数据来自原材料批次台账、车间MES系统、浆料与涂布检测设备、车间露点监测系统、化成分容柜及实验室测试设备。日常生成的文档包括配料记录、涂布辊压参数表、卷绕或叠片工序记录、注液台账、化成分容数据报表、OCV与安全测试报告。数据更新节奏为每生产批次、每只电芯同步更新，部分关键参数如车间露点、涂布面密度为实时更新。文档字段包含物料批次号、工序参数值、检测结果、操作人员编号、检测时间等，部分参数带有专属单位，如涂布面密度单位为g/㎡，化成分容电压单位为V。

## 这些特征在「模型接入与配置」这一环带来什么约束
由于数据来源分散且更新频率存在差异，模型接入环节需支持多源异构数据的批量拉取与格式对齐，避免因数据时序不匹配导致的台账汇总错误。由于日常文档包含大量带专属单位的工序参数与检测结果，配置时需保留原始字段与单位信息，防止参数语义丢失影响报告可读性。由于电化学生产对数据一致性要求极高，模型调用需限制上下文长度，避免引入无关历史数据干扰汇总逻辑。实时更新的车间参数需配置短间隔的同步触发机制，确保报告生成时使用最新的工序与检测数据。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，适配锂离子电芯制造场景的台账汇总与报告生成需求：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 锂离子电芯制造台账数据字段多且关联紧密，需保留足够上下文以关联跨工序数据 |
| `maxTokens` | 4000 token | 单份报告生成需控制输出长度，避免超出模型处理上限导致内容截断 |
| `temperature` | 0.1–0.3 | 台账汇总与报告生成需保持参数表述的一致性，降低随机输出风险 |
| `quoteMaxToken` | 1500 token | 提取台账关联文档时，限制单条引用的长度，避免冗余内容干扰汇总逻辑 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写专属接口地址 | 确保模型请求定向到指定的代理服务，保障数据传输安全 |
| `AIPROXY_API_TOKEN` | 与部署环境绑定的专属密钥 | 验证请求合法性，防止未授权访问 |

## 容易做错的三处
- 现象：上传配料记录的Word文档后，模型识别结果为空。原因：未开启FastGPT内置的Word文档解析插件，或文档中嵌入的非标准格式表格无法被自动识别。
- 现象：调用模型生成报告时，输出结果中携带大量#、*等标点符号。原因：未配置合适的输出格式过滤规则，导致模型生成的Markdown格式未被正确转换为标准报告格式。
- 现象：接入外部模型API时，请求返回认证失败。原因：`AIPROXY_API_TOKEN`配置错误，或密钥与部署的代理服务不匹配。

## 怎么确认配好了
- 上传一份标准的涂布辊压参数Word文档，核对解析后的字段是否包含涂布面密度、辊压温度等预设字段。
- 发起一次台账汇总请求，核对输出结果中是否保留了原始参数的单位信息，无多余的格式标点。
- 配置`AIPROXY_API_TOKEN`后，发起一次模型测试请求，确认返回的响应状态码无认证相关错误。
- 调整`maxContext`参数区间，核对不同批次数据的关联逻辑是否正常，无上下文截断导致的信息缺失。
