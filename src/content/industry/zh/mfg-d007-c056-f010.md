# 锂离子电芯制造的生产台账汇总与报告生成：知识库检索与召回

## 这个品类的数据长什么样
锂离子电芯制造的生产台账数据来自原材料批次台账、MES系统、浆料与涂布检测设备、露点监测终端、化成分容柜及实验室测试系统。日常生成的文档包含配料记录、涂布辊压参数、卷绕或叠片记录、注液记录、化成分容数据、OCV与安全测试报告等，字段涵盖批次编号、工艺参数、检测数值、测试结果等。数据更新节奏为单批次电芯生产时实时同步，单只电芯完成对应工序后生成专属记录，无固定批量更新周期。

## 这些特征在「知识库检索与召回」这一环带来什么约束
由于数据更新频率为每批、每只电芯实时生成，检索环节需支持高频增量同步的数据集更新，避免索引滞后导致召回过时的生产记录。多类型工序文档包含结构化数值参数与非结构化测试报告，需按工序模块拆分检索单元，确保跨工序台账关联时的精准匹配。电化学体系对水分、批次一致性要求极高，检索需优先召回与当前生产批次匹配的原材料、环境参数记录，避免因参数偏差引发质量风险。同时多源数据的字段格式存在差异，需在检索前统一标准化处理，确保召回结果的字段可直接用于台账汇总与报告生成。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的知识库检索功能。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 锂离子电芯生产参数对精度要求高，需过滤低匹配度的无关台账记录，确保召回结果与当前工序的参数匹配度达标 |
| `limit` | `前8–12条` | 单批次生产台账的关联参数数量有限，过多召回会增加上下文冗余，过少则可能遗漏关键工序记录 |
| `searchMode` | `vector` | 生产台账包含大量结构化数值参数与工序记录，向量检索可精准匹配语义与数值关联的内容，优于关键词模糊匹配 |
| `usingReRank` | `开启` | 多源台账的语义相似度易受字段格式干扰，重排环节可进一步筛选与当前生产场景最相关的记录 |
| `datasetSearchUsingExtensionQuery` | `开启` | 生产场景的检索需求常隐含工序关联逻辑，扩展查询可补充当前工序的上下游关联参数，完善台账汇总的完整性 |
| `collectionIds` | `按工序分组的数据集ID列表` | 按涂布、卷绕、化成等工序拆分数据集，可精准限定检索范围，避免跨工序无关记录的干扰 |

## 容易做错的三处
- 现象：检索请求长时间无响应，控制台返回`504 Gateway Timeout`状态码。原因：未针对高频实时更新的生产台账配置增量同步，全量索引重建耗时过长导致检索超时。
- 现象：知识库内的`chunk ID`无法被选中复制。原因：FastGPT界面的`chunk ID`元素未设置可选中的文本属性，未针对台账类知识库的批量操作需求优化交互。
- 现象：检索生成的台账报告参数与实际生产记录不符。原因：未配置`usingReRank`或`similarity`阈值设置过低，召回了低匹配度的非当前批次台账记录。

## 怎么确认配好了
- 查看数据集的更新日志，确认近24小时内的实时生产台账已完成增量同步，无失败记录。
- 发起一条针对当前生产工序的检索请求，核对召回结果的数量与配置的`limit`取值一致。
- 手动复制任意`chunk ID`，确认可正常选中并粘贴至外部文本编辑器。
- 调整`similarity`阈值至0.7，检索后确认低匹配度的无关记录已被过滤。
