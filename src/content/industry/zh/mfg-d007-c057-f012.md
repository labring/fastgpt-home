# 锻造与模锻的生产台账汇总与报告生成：部署与升级

## 这个品类的数据长什么样
该品类的数据覆盖锻造全流程，来源包括原材料质保书、加热炉系统、压力机采集数据、MES系统、无损检测仪及客户锻件图。日常文档包含锻造工艺规程、下料卡、加热炉记录、锻造过程卡、模具寿命记录、热处理委托单、超声检测报告。数据更新按每件、每批或每炉次触发，单条数据包含锻件批次号、材料炉批号、加热温度区间、压力参数、模具磨损值、检测结果等字段，单位涵盖摄氏度、兆帕、小时、毫米等。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据按单炉次、单批次高频更新，部署环节需适配高并发小批量数据写入，需预留足够的数据库连接资源。日常文档类型多样且字段差异大，升级时需兼容多格式文件解析，避免因新增文档类型触发解析异常。数据关联需匹配锻件批次与材料炉批，部署时需配置跨系统数据关联规则，确保台账关联准确性。同时，因出错后果涉及锻件报废与服役安全，部署后需保留完整数据溯源链路，升级时不得删减关键字段的存储逻辑。本文档基于FastGPT v4.17.0版本编写。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `15–25 个连接` | 适配单炉次/单批次高频数据写入的并发需求，避免数据库连接耗尽 |
| `MONGODB_URI` | 指向部署在厂区内网的MongoDB实例 | 存储高频更新的锻造过程数据，保障数据读写延迟低于500毫秒 |
| `REDIS_URL` | 配置为本地缓存实例，缓存有效期`3600 秒` | 缓存常用的锻件工艺参数与模具寿命数据，降低重复查询压力 |
| `STORAGE_S3_ENDPOINT` | 厂区内部对象存储服务地址 | 存储超声检测报告、热处理委托单等大体积文档，统一管理文件权限 |
| `ROOT_KEY` | 按厂区内部权限规则生成 | 管控系统最高权限，避免非授权用户修改台账配置与数据 |

## 容易做错的三处
- 现象：数据库连接超时报错，状态码504。原因：未根据单炉次高频写入调整`DB_MAX_LINK`配置，导致连接池耗尽无法响应新请求。
- 现象：锻件批次与材料炉批关联字段为空。原因：未配置跨系统数据关联规则，直接读取原始采集数据未做批次匹配。
- 现象：大体积超声检测报告无法上传。原因：未配置`STORAGE_S3_ENDPOINT`指向内部对象存储，使用默认临时存储导致文件大小超限。

## 怎么确认配好了
- 执行单炉次数据批量写入测试，查看数据库连接数监控，确认连接数未超过`DB_MAX_LINK`配置值。
- 上传一份超声检测报告，通过系统文件管理模块验证文件可正常存储与读取，确认`STORAGE_S3_ENDPOINT`配置生效。
- 随机选取一批锻件数据，验证锻件批次与材料炉批的关联关系可正常生成，确认跨系统数据关联逻辑正常。
- 使用`ROOT_KEY`权限测试系统配置修改功能，确认非授权用户无法访问该操作入口。
