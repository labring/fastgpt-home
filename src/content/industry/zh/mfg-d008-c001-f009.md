# PCB制造的设备点检与维修问答：模型接入与配置

本页面适配FastGPT v4.17.0版本。

## 这个品类的数据长什么样
本品类数据来自印制电路板工厂的工程、生产、品质与实验室团队，日常文档包含工程制作指示、Gerber解析记录、钻孔和层压参数、药水分析报告、AOI检测报告、电测报告、切片报告。数据来源涵盖客户提供的Gerber文件、钻带、BOM清单，以及CAM文件、设备运行参数、槽液化验结果、AOI与电测数据、实验室检测记录。数据更新节奏为每生产批次、每班更新，部分设备数据连续采集。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类数据来源多样且格式不统一，涵盖工程文档、设备参数、检测报告等多类非结构化内容，要求模型接入配置需适配多源文档的上下文拼接。数据更新频率高且部分为连续采集，配置需匹配数据更新节奏，避免上下文窗口无法容纳最新批次数据。专业字段如钻孔层压参数、槽液化验指标较多，配置需兼顾专业问答的严谨性，同时支持多文档关联查询，确保输出结果可溯源至对应业务文档。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填写部署地址加 `/v1` 后缀 | PCB制造的设备数据接口多为标准API格式，添加`/v1`可适配多数模型接入规范 |
| `AIPROXY_API_TOKEN` | 填写平台分配的专属密钥 | 需验证调用权限，避免未授权访问业务数据 |
| `temperature` | `0.2–0.4` | 设备点检维修问答需严谨准确，避免生成无关内容 |
| `maxContext` | `8000–12000 token` | 需容纳多份生产批次文档、检测报告的关联内容，覆盖单次查询的上下文需求 |
| `quoteMaxToken` | `2000–3000 字符` | 需完整提取钻孔参数、AOI异常记录等关键业务片段，确保问答溯源准确 |
| `toolChoice` | `auto` | 需根据查询自动选择是否调用文档检索工具，适配多源数据查询需求 |

## 容易做错的三处
- 现象：配置Ollama渠道时测试返回status code 404。原因：未在API地址末尾添加`/v1`后缀，导致接口路径不匹配。
- 现象：FastGPT v4.8.20及以上版本中修改OneAPI配置无生效。原因：未在平台页面的模型配置模块更新参数，仍依赖docker compose中的静态配置文件。
- 现象：上传业务文档后大模型提示null未上传，但文件可正常下载。原因：文档解析时未正确关联文件元数据，导致模型调用时无法读取上传文件的标识信息。

## 怎么确认配好了
- 调用模型测试接口，输入设备点检相关的专业问题，检查返回结果是否包含对应业务文档的溯源信息。
- 查看平台日志，确认API请求的地址包含正确的`/v1`后缀，无路径错误。
- 上传一份测试用的钻孔参数文档，触发模型问答，检查是否能正确提取文档中的关键参数内容。
- 调整`temperature`参数后重新测试，观察返回结果的严谨性变化，确认参数生效。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
