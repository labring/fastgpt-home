# SMT贴片与电子组装的设备点检与维修问答：模型接入与配置

## 这个品类的数据长什么样
SMT贴片与电子组装的业务数据包含多类文档与实时采集信息。日常文档包括BOM与坐标文件、换线表、钢网与炉温记录、首件确认单、SPI/AOI报告、维修记录、追溯标签。数据来源涵盖客户交付的BOM、Gerber文件、坐标数据，以及MES系统、锡膏与元件批次信息、贴片机、SPI/AOI检测设备、回流焊炉温数据。数据更新频率为每工单、每次换线及实时采集，字段包含料号、位号、替代料、炉温曲线参数、缺陷类型等专业信息。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据实时更新且按工单聚合，要求模型上下文窗口需适配单工单内多份文档的总长度，避免上下文溢出导致调用失败。数据混合了坐标、炉温曲线等结构化数值信息，SPI/AOI缺陷图片等视觉类数据，以及维修记录类文本数据，要求模型接入时需支持多模态输入，适配不同类型的业务数据格式。专业字段如料号、位号、缺陷类型需保持术语准确性，要求模型生成时需控制随机偏差。不同工单的数据结构差异较大，需灵活调整模型输出长度以匹配不同场景的问答需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配单工单包含的BOM、换线表、SPI报告等多份文档的总长度，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 控制维修问答的回复长度，确保包含缺陷分析、维修步骤等完整信息 |
| `vision` | 开启 | 支持处理SPI/AOI的缺陷图片、钢网照片等视觉类点检数据，匹配业务中的图片分析需求 |
| `temperature` | 0.3–0.5 | 降低随机生成概率，保证料号、位号等专业术语的准确性 |
| `AIPROXY_API_ENDPOINT` | 按部署的大模型服务地址填写 | 对接智谱、千问2等模型的官方服务端点，适配多渠道模型接入 |
| `AIPROXY_API_TOKEN` | 从对应模型平台获取的密钥 | 完成模型身份验证，确保接口调用权限正常 |

## 容易做错的三处
- 现象：在OneAPI渠道添加智普、千问2模型后，创建知识库与应用时无对应模型选项。原因：`AIPROXY_API_ENDPOINT`或`AIPROXY_API_TOKEN`配置错误，未正确对接渠道的接口地址与密钥。
- 现象：离线接入重排模型时提示rerank error，日志包含detail字段为空或格式异常。原因：未选用适配电子组装行业文本特征的重排模型，或模型部署路径配置不符合FastGPT v4.17.0的加载要求。
- 现象：测试视觉模型时上传的SPI/AOI缺陷图片显示正常，但交互按钮无响应，日志显示接口调用超时。原因：`maxContext`配置超出模型支持的窗口上限，导致模型处理多模态输入时超时。

## 怎么确认配好了
- 进入FastGPT v4.17.0的模型渠道管理页面，确认已添加的智普、千问2等模型正常显示在可选模型列表中。
- 上传单份SMT工单的SPI缺陷图片，触发视觉模型测试，确认交互按钮可正常触发接口调用，无卡顿或无响应情况。
- 输入包含料号、位号的维修问题，查看模型回复内容，确认专业术语无明显错误，回复长度符合预期。
- 检查接口调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的配置无格式错误，无401或404类报错。
