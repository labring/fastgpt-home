# SMT贴片与电子组装的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
SMT贴片与电子组装的生产数据来源包括客户提供的BOM、Gerber、坐标文件，以及MES系统、锡膏与元件批次台账、贴片机、SPI/AOI检测设备、回流焊炉温记录等。数据更新节奏为每工单、每次换线实时同步，涵盖BOM与坐标表、换线表、钢网与炉温记录、首件确认报告、SPI/AOI检测报告、维修记录、追溯标签等文档。文档字段包含料号、位号、元件批次、炉温曲线参数、坐标值等，单位涉及毫米、摄氏度、批次编号等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据实时性要求高，检索需适配频繁更新的工单与换线数据，避免召回过时的钢网或炉温记录。多类型文档混合存在，包括结构化表格、非结构化文本与图片格式的检测报告，要求检索同时支持关键词匹配与语义理解。字段精准度要求高，料号、位号等核心字段的匹配误差会直接导致生产失误，需限制无关召回结果。此外，按生产单元隔离数据的需求，要求检索范围限定在对应车间的数据集内，避免跨工单数据干扰。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.72–0.85` | SMT生产核心字段如料号、位号需较高匹配精度，避免无关召回干扰维修与点检决策 |
| `limit` | `前5条` | 单工单相关的文档数量通常不超过5个，限制结果条数可降低上下文负载 |
| `usingReRank` | 开启 | 多源召回的混合数据需通过重排优化排序结果，提升SPI/AOI报告、维修记录等文档的匹配准确性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充工单关联的换线、炉温等上下文信息，提升检索召回率，适配设备点检的多维度查询 |
| `collectionIds` | 绑定对应车间的贴片机、炉温、维修数据集 | 按生产单元隔离数据，避免跨车间工单的无关数据被召回，保障检索精准性 |
| `searchMode` | `semantic + keyword hybrid` | 同时匹配文本关键词与语义，适配BOM表格、维修记录等多类型文档的检索需求 |

## 容易做错的三处
- 现象：使用严格问答模板发起检索时，若知识库包含图片格式的钢网记录或首件确认图，会返回「未找到答案」。原因：严格问答模板默认仅处理纯文本检索结果，未配置图片内容的解析适配，无法提取图片中的参数信息。
- 现象：API调用时传入知识库ID参数后提示无效ID。原因：未绑定对应SMT车间的`collectionIds`配置，或传入的数据集ID未在当前工作流的授权范围内。
- 现象：上传100MB以上的PDF格式维修记录或炉温报告时，上传进度到90%后提示「偏移量超出范围」。原因：未调整大文件分块上传的缓冲区参数，或网络波动导致分片上传中断，引发文件解析异常。

## 怎么确认配好了
- 上传单份BOM文件，发起料号检索，核对返回结果包含对应BOM中的元件位号与批次信息。
- 发起换线相关的设备点检问题，检查召回结果包含对应换线的钢网参数、元件替换规则等内容。
- 调用API接口，验证返回结果的`similarity`分值在配置的区间内，且结果条数不超过配置的`limit`值。
- 上传大体积PDF文件，确认上传进度完成且无偏移量报错，可正常检索文件内的炉温曲线数据。
