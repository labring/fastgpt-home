# 乳制品加工的设备点检与维修问答：多轮对话与提示词

## 这个品类的数据长什么样
该品类数据覆盖液态奶、酸奶、奶粉及乳配料的生产全流程，日常文档包含原奶验收记录、标准化配料单、巴氏或UHT热处理记录、CIP清洗记录、灌装操作记录、留样与微生物检测报告。数据来源于奶源检测设备、生产MES系统、均质与热处理设备、在线温度流量传感器、CIP系统及LIMS实验室管理系统，更新节奏为每奶罐、每批生产节点实时同步，字段包含原奶抗生素与理化指标、热处理时间温度参数、无菌灌装校验数据等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
乳制品加工的实时性与批次绑定的数据特征，要求多轮对话需关联对应生产批次的上下文，避免跨批次数据混淆。高频实时的温度流量、CIP清洗参数需在对话中快速调用，提示词需限定单次调用的字段范围，防止上下文过载。原奶验收、微检报告的结构化数据需明确关联对话中的设备编号或批次号，多轮对话需保留`chatId`绑定当前会话的批次上下文，确保每轮提问都能匹配对应生产环节的历史数据。同时，易腐原料的应急处理需求要求对话响应需匹配实时更新的CIP记录，提示词需预设设备点检的标准化流程步骤，约束回答仅基于当前批次的有效数据。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chatId` | 绑定当前生产批次编号 | 确保多轮对话上下文绑定对应批次的生产数据，避免跨批次数据混淆 |
| `messages` 上下文整理 | 按生产环节分组排序历史对话 | 确保多轮对话的历史上下文逻辑清晰，便于快速匹配当前问题 |
| 上下文窗口长度 | 800–1200 字符 | 匹配单批次生产记录的平均长度，覆盖关键点检与维修的核心参数，防止上下文过载 |
| `variables` 绑定字段 | 原奶抗生素指标、热处理时间温度、CIP校验结果 | 限定调用的数据源范围，仅使用当前会话关联的批次有效数据 |
| 响应超时 | 600秒 | 匹配乳制品加工设备点检的平均响应等待时长，避免超时中断会话 |
| 历史对话保留条数 | 20条 | 覆盖单批次生产的典型对话轮次，避免过多历史数据占用上下文 |
| 回答格式控制 | 禁用Markdown语法 | 适配设备运维人员的快速阅读需求，避免格式干扰 |
| 会话复用设置 | 保持当前会话不新建 | 支持连续多轮设备点检提问，符合现场连续排查的操作习惯 |

## 容易做错的三处
- 现象：对话结果仅在侧边弹窗展示，主对话框无可见输出。原因：未配置直接输出到主对话框的规则，仅启用了侧边预览模式。
- 现象：每发起一次提问就自动新建独立会话窗口。原因：未绑定`chatId`维持当前会话，且开启了会话自动新建的默认设置。
- 现象：回答内容自动使用Markdown语法排版。原因：未关闭默认的Markdown渲染开关，未指定纯文本输出格式。

## 怎么确认配好了
- 发起针对当前生产批次的设备点检提问，检查主对话框是否直接展示回答结果，确认输出位置配置正确。
- 连续发起3次针对同一批次的设备维修提问，检查是否始终在同一个会话窗口内完成，确认会话绑定与复用配置生效。
- 查看回答内容，确认未出现Markdown格式的标题、列表等元素，确认格式控制配置正确。
- 调用`variables`绑定的字段，检查回答是否仅引用当前批次的生产数据，确认数据源绑定配置生效。
