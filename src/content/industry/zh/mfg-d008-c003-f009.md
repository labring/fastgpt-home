# 乳制品加工的设备点检与维修问答：模型接入与配置

## 这个品类的数据长什么样
该品类数据覆盖液态奶、酸奶、奶粉及乳配料生产全流程，来源包括奶源检测、MES系统、均质与热处理设备、在线温度流量监测、CIP清洗系统、LIMS实验室管理系统。日常文档包含原奶验收记录、标准化配料单、巴氏或UHT热处理记录、CIP清洗记录、灌装记录、留样与微检报告。数据更新节奏为每奶罐、每批或实时，核心字段包含原奶抗生素与理化指标、热处理时间温度参数、无菌灌装状态等，字段单位涵盖℃、秒、菌落总数cfu/mL等。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的高频实时数据、多源异构字段与高风险业务后果，对模型接入配置带来多重约束。实时更新的设备与生产数据要求限制上下文长度，避免推理延迟影响现场点检的响应速度。多源字段的格式差异要求配置时明确映射规则，确保检索到的生产参数与维修文档的字段匹配度。单批次独立数据的场景，要求配置上下文隔离逻辑，防止跨批次数据干扰当前批次的故障判定。高风险业务后果要求检索结果的召回精度匹配业务需求，避免错误的维修建议引发生产异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配乳制品加工多文档拼接的上下文需求，避免因上下文溢出丢失批次关键生产参数 |
| `temperature` | 0.1–0.3 | 降低随机输出，确保维修建议与生产参数的一致性，匹配高风险业务的严谨性要求 |
| `vision` | 开启 | 支持识别设备仪表盘读数、CIP管路照片等视觉化点检数据，适配现场巡检场景 |
| 工作流/API 工具选择配置 | auto | 自动调用检索工具获取实时生产数据，无需手动触发，适配快速点检的响应需求 |
| `AIPROXY_API_ENDPOINT` | 按部署区域填写专属端点 | 适配国内或跨境部署的API调用需求，确保数据传输稳定 |
| `AIPROXY_API_TOKEN` | 绑定专属服务密钥 | 确保API调用权限可控，防止未授权访问生产相关数据 |

## 容易做错的三处
- 现象：界面右上角无创建模型标识，无法接入本地或第三方模型。原因：未切换至对应工作空间的管理员权限分组，或FastGPT版本低于v4.17.0，该功能在v4.17.0及以上版本开放。
- 现象：配置`AIPROXY_API_ENDPOINT`后提示无可用渠道。原因：未在对应分组中配置API密钥的访问权限，或密钥绑定的服务未覆盖当前调用区域。
- 现象：模型无法识别设备图片上传请求。原因：未开启`vision`配置项，或接入的基础模型未开放视觉理解能力，需确认模型本身支持视觉输入。

## 怎么确认配好了
- 进入模型配置页面，检查`maxContext`、`temperature`等参数的取值与预设配置一致。
- 上传一份乳制品加工的设备维修文档与实时生产数据，发起测试提问，确认返回结果包含对应字段的匹配内容。
- 尝试上传设备仪表盘照片，确认模型可识别并解读图片中的参数信息。
- 调用API接口发起请求，确认返回结果的token数与`maxTokens`设置的上限匹配，无异常报错。
