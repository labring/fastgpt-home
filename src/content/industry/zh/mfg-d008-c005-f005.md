# 光伏电池片制造的设备点检与维修问答：工具调用与插件

## 这个品类的数据长什么样
晶硅电池片制造企业的工艺、设备、品质与生产部门为核心使用主体，日常文档包含工艺卡、扩散和镀膜参数、印刷烧结记录、EL检测图、IV分档数据、良率报告。数据来源覆盖硅片来料、MES系统、扩散炉/镀膜设备/印刷机等生产设备、EL与IV测试设备及实验室检测数据，更新频率涵盖每批、每片检测、每日三个层级。核心工作涉及控制制绒、扩散、钝化和电极工艺窗口，识别隐裂、色差与效率损失，按电性能分档追溯。

## 这些特征在「工具调用与插件」这一环带来什么约束
数据来源分散且更新频率不均，要求工具调用需支持多源数据的实时拉取与关联，避免因数据断层影响点检结果准确性。多类型文档并存的特点，要求插件需同时适配结构化参数查询与非结构化图片、文本的解析，覆盖工艺参数校验、缺陷识别等场景。高频更新的片级数据与工艺窗口控制需求，要求工具调用需精准匹配当前设备的上下文信息，避免冗余数据干扰判断。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` 或指定设备参数查询工具 | 适配设备点检的精准调用需求，避免模型调用无关工具 |
| `functionCall` | 启用 | 支持触发参数校验、日志提取等预设工具，匹配光伏设备维修的场景需求 |
| 最大上下文长度 | 8000–12000 token | 容纳单批次的工艺卡、EL检测图文本描述与IV分档数据，避免截断关键信息 |
| 单次工具调用超时 | 300 秒 | 适配EL检测图分析、设备日志拉取的耗时场景，按实测标定 |
| 召回结果数量 | 前3–5条 | 聚焦当前设备的历史点检记录与工艺参数，避免冗余信息干扰 |

## 容易做错的三处
- 调用仅支持stream模式的大模型时，返回「获取数据异常」「error」类日志。原因是未在模型渠道配置中开启stream模式适配，导致同步调用与模型接口不兼容。
- 升级PgVector插件时出现配置冲突报错。原因是升级前未暂停关联知识库的索引任务，引发文件占用与数据同步冲突。
- 文本提取工具返回`400 Invalid JSON payload received. Unknown name`报错。原因是传入的EL检测图文本描述或设备日志存在未转义的特殊字符，不符合JSON格式要求。

## 怎么确认配好了
- 发起设备点检相关的查询，查看工具调用日志中是否正确触发预设的参数查询、日志提取工具。
- 测试调用仅支持stream模式的大模型，确认返回的流式结果无中断且无数据异常报错。
- 触发文本提取工具，检查返回结果的JSON格式是否符合要求，无未知字段报错。
- 查看PgVector插件的版本信息，确认已升级至目标版本，且关联的知识库索引任务正常运行。
