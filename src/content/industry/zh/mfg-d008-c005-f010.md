# 光伏电池片制造的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
光伏电池片制造的业务数据主要来自硅片来料、生产MES系统、扩散炉/镀膜设备/印刷机等产线终端、EL与IV测试设备、实验室检测数据。日常文档包含工艺卡、扩散和镀膜参数、印刷烧结记录、EL检测图像、IV分档数据、良率分析报告。数据按每批次生产、单片检测结果、每日更新，核心字段含工艺窗口参数、电性能转换效率、隐裂等级、分档结果等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的高频实时更新、混合文档结构与工艺精度要求，对检索召回带来多重约束。单片级检测数据的实时更新要求检索链路支持增量同步；工艺参数、图像、数值混合的文档结构，要求检索模型同时适配多类型内容；工序连续且工艺窗口敏感的业务特点，要求召回结果需关联前后工序信息，避免孤立匹配导致的错误决策。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.82 | 匹配光伏工艺参数的精度区间，过滤低相关结果 |
| `limit` | 前6–8条 | 平衡上下文长度与召回覆盖度 |
| `searchMode` | hybrid | 适配混合文本、数值、图像类文档的检索 |
| `usingReRank` | true | 开启重排优化，提升高相关结果排序优先级 |
| `datasetSearchUsingExtensionQuery` | true | 开启问题扩展，适配工艺类问题语义延伸 |
| `collectionIds` | 设备点检专属知识库集合ID | 限定检索范围，避免跨品类文档干扰 |

## 容易做错的三处
- 分块长度设置为3000字符时出现内容丢失，原因是未预留重叠字符，导致长工艺文档被截断拆分时丢失关键参数
- 向量化任务报错显示速率超限，原因是未调整线程数，并发请求超出接口限制
- 检索结果包含非设备点检内容，原因是未指定`collectionIds`限定专属知识库集合

## 怎么确认配好了
- 发起测试提问如“扩散炉炉温异常如何点检”，核对返回结果是否为知识库原文答复，无AI生成内容
- 查看向量化任务日志，确认无速率超限报错
- 测试分块操作，确认无内容丢失情况
- 发起批量检索，确认响应时间符合业务延迟要求
