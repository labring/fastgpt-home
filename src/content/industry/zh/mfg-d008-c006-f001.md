# 光伏组件封装的设备点检与维修问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
光伏组件封装场景的数据来自电池片分档系统、玻璃胶膜背板批次台账、工厂MES系统、串焊与层压设备、EL/IV测试仪与绝缘耐压设备。日常文档包含排版图、材料批次记录、层压工艺记录、EL缺陷图、IV测试报告、绝缘耐压记录与包装清单。数据按每块组件、每批材料更新，字段包含电池片电流档位、层压温度与压力、组件功率、隐裂坐标等，对应不同设备与业务环节的记录格式。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
数据按单组件或单批次高频更新，要求接口支持小批量、低延迟的请求处理，需设置合理的超时阈值以适配传输耗时。多源异构的数据来源（设备、MES、测试报告）要求接口支持不同格式的请求与响应解析，需明确字段映射规则以保证数据匹配准确性。设备点检与维修问答需关联实时设备状态与历史工艺记录，接口需支持按组件ID或批次号精准查询。不同文档类型的非结构化数据需单独处理，接口需区分结构化参数与文件上传路径。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {OneAPI分配的密钥}` | 匹配外部系统的鉴权要求，避免鉴权失败报错 |
| `variables` | 绑定组件ID、材料批次号为请求变量 | 精准匹配单组件或单批次的业务数据 |
| `responseData` | 提取设备运行参数、测试结果字段 | 快速获取点检与维修所需的核心信息 |
| 请求超时阈值 | 600秒 | 适配EL图、IV报告等非结构化数据的传输与解析耗时 |
| 工具调用配置 | 开启functionCall并绑定设备维修知识库 | 支持自动匹配维修问答的知识库内容 |
| 模型接入路径 | 填写本地部署ChatGLM2的OneAPI接口地址 | 适配本地模型的调用需求 |

## 容易做错的三处
- 现象：调用接口返回401状态码，使用Postman调用同一密钥可正常访问。原因：FastGPT配置的`Authorization`参数格式错误，未添加Bearer前缀或密钥输入有误。
- 现象：创建知识库时无法选择本地部署的ChatGLM2模型。原因：未在config.json中正确配置模型接入路径与权限，未重启服务加载更新后的配置。
- 现象：内容提取节点无法调用自建模型接口。原因：未在工具配置中正确开启functionCall参数，导致节点不支持自定义模型接口调用。

## 怎么确认配好了
- 执行接口鉴权测试，确认返回状态码为200，验证`Authorization`配置生效。
- 输入测试组件ID与批次号，核对接口返回数据是否包含预设的业务字段。
- 触发工具调用流程，确认节点能自动关联绑定的设备维修知识库内容，生成对应问答结果。
- 检查系统配置文件，确认模型接入参数与本地部署服务的参数一致，验证模型加载正常。
