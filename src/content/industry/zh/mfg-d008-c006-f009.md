# 光伏组件封装的设备点检与维修问答：模型接入与配置

## 这个品类的数据长什么样
本品类的数据覆盖串焊、层压、装框、测试全流程环节。数据来源包括电池片分档记录、玻璃胶膜背板批次台账、生产MES系统、串焊与层压设备运行日志、EL/IV测试仪输出文件。数据更新随单块组件生产完成触发，每批材料同步更新溯源信息。日常文档包含排版图、材料批次记录、层压工艺参数记录、EL缺陷图、IV功率测试报告、绝缘耐压记录、成品包装清单，包含电池片电流档位、层压温度与压力参数、EL隐裂坐标、IV功率值等专属字段。

## 这些特征在「模型接入与配置」这一环带来什么约束
单组件绑定多类文档且更新频繁的特征，要求模型接入时需限定上下文范围，避免冗余数据拖慢检索速度。专属字段如电池片电流档位、EL隐裂坐标需要模型精准匹配业务术语，需配置对应参数限定召回文档的来源范围。图像类EL图的判读需求，要求开启视觉处理能力。不同环节的设备日志与测试报告结构差异较大，需调整参数适配混合检索的负载，避免单次检索耗时过长。同时，商用场景需平衡检索精度与响应速度，避免因召回过多文档导致超时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `vision` | 开启 | 需处理EL缺陷图等图像类点检文档 |
| `maxContext` | 8000–12000 token | 匹配单组件全流程文档的总长度，避免超出模型上下文上限 |
| `quoteMaxToken` | 2000–3000 token | 限定召回文档的总长度，平衡检索精度与响应速度 |
| `temperature` | 0.3–0.5 | 保持维修建议的准确性，避免生成无关内容 |
| `AIPROXY_API_ENDPOINT` | 填写厂商提供的API地址 | 接入第三方大模型的必要配置 |
| `AIPROXY_API_TOKEN` | 填写厂商分配的访问密钥 | 完成大模型接入的身份验证 |

## 容易做错的三处
- 混合检索响应耗时超过10秒。原因是未限制`quoteMaxToken`的取值，召回了过多冗余文档，超出模型处理负载。
- 模型无法识别EL缺陷图内容。原因是未开启`vision`配置项，导致无法解析图像类点检文档。
- 工具调用返回结果中出现多余的0字段。原因是未对齐业务文档的专属字段格式，模型错误拼接了无关的溯源数据。

## 怎么确认配好了
- 使用FastGPT v4.17.0版本，上传单块组件的EL图与测试报告，验证模型能否正确识别隐裂位置与功率值。
- 发起混合检索请求，查看单次响应耗时是否符合业务场景的要求。
- 配置`vision`后，上传EL图像，验证模型能否输出对应的点检结论。
- 检查API配置项的填写内容，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`无误。
