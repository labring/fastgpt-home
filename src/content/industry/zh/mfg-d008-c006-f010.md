# 光伏组件封装的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
光伏组件封装的设备点检与维修问答所关联的数据，来自串焊、层压、装框、测试部门的日常文档与业务系统。日常文档包含排版图、材料批次记录、层压工艺记录、EL图、IV测试报告、绝缘耐压记录、包装清单。数据来源涵盖电池片分档、玻璃胶膜背板批次、MES系统、串焊与层压设备、EL/IV测试仪。数据更新频率为每块组件、每批材料，字段包含材料批次号、设备参数、测试数值、工艺参数等，单位涉及功率、温度、压力等专业工业单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据特征对检索召回带来多重约束。首先，数据更新频率高且单条数据关联度强，要求检索系统支持实时同步批次数据与设备日志，避免召回过时或不匹配的内容。其次，文档类型涵盖文本、图纸、测试报告，要求检索系统支持多模态内容的召回与展示，确保EL图、IV测试报告等可视化文档可被正确加载。此外，字段专业性强且出错后果严重，要求检索匹配需精准对应电池片电流档位、层压温度等关键参数，避免低匹配度的无关条目混入，影响点检与维修决策。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 光伏组件封装的关键参数匹配精度要求高，该阈值可过滤低相关的工艺记录与测试报告，确保召回结果的相关性 |
| `limit` | 前8条 | 单块组件关联的工艺、测试文档数量有限，过多召回内容会超出对话上下文窗口，影响维修问答的可读性 |
| `searchMode` | `mixedRecall` | 兼顾工艺文档的文本关键词匹配与EL图、IV测试数据的向量匹配，覆盖多类型业务文档的检索需求 |
| `usingReRank` | 开启 | EL隐裂判读、功率匹配等场景需要高置信度的召回结果，重排可进一步过滤低相关条目，提升决策准确性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 设备点检问题常需要关联材料批次、设备运行参数，扩展查询可补充上下文信息，提升检索的全面性 |
| `collectionIds` | 绑定光伏组件封装设备点检专属数据集 | 隔离其他品类的业务文档，避免召回无关的半导体制造、电池片生产类内容，确保检索范围精准 |

## 容易做错的三处
- 现象：检索结果中无法加载排版图、EL图，页面显示图片缺失。原因：未配置知识库图片存储路径与业务文档路径的映射规则，导致召回时无法定位图片资源。
- 现象：Excel格式的材料批次记录、IV测试报告导入失败，返回导入失败提示。原因：未按品类文档的字段顺序整理数据，未统一功率、温度等单位的格式，导致解析异常。
- 现象：调用对话接口后，返回结果中未携带关联的知识库标识信息。原因：未开启检索溯源配置，未启用`datasetSearchUsingExtensionQuery`附带溯源参数，导致接口未返回相关标识。

## 怎么确认配好了
以下核对动作基于FastGPT v4.17.0版本。
- 上传一份光伏组件的EL图和IV测试报告，执行设备点检相关查询，检查是否能召回对应文档并正确加载图片资源。
- 导入整理好字段与单位的Excel批次记录，检查导入状态是否成功，无解析报错提示。
- 发起电池片电流档位匹配的查询，检查返回结果中是否包含关联的知识库专属数据集信息。
- 调整`similarity`阈值为0.8，检索层压气泡控制相关问题，检查召回结果的匹配度是否符合业务预期。
