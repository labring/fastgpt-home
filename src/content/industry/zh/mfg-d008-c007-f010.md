# 冲压与板材成形的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
这个品类的数据来自钢卷标签与质保书、冲床和送料机运行数据、模具管理系统、MES系统、三坐标或检具检测报告。日常文档包含冲压作业指导书、材料利用率表、模具点检表、首末件记录、尺寸检验报告、换模记录。数据更新节奏随每卷钢料、每批生产任务、每次模具更换触发，文档多为表格化记录，字段包含模具编号、材料牌号、压边力数值、换模时间等，单位多为毫米、千牛、小时等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据分散且更新频率高，随每卷钢料、每批任务、每次换模触发更新，要求检索环节支持增量同步与事件触发的知识库刷新。文档多为表格化记录，包含模具编号、材料牌号、压边力数值等专业参数，需适配结构化数据的精准匹配，避免字段歧义。高频生产场景下，检索需支撑高并发调用，同时保留单位与数值的关联匹配逻辑，确保维修与点检问答的准确性。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 该品类参数精度要求高，需过滤低匹配度的非专业内容 |
| `limit` | `前8–12条` | 冲压场景需覆盖模具、材料、操作多维度的参考数据，避免单条信息不足 |
| `searchMode` | `vector+keyword` | 文档含结构化表格与纯文本操作步骤，混合检索可兼顾语义与关键词匹配 |
| `usingReRank` | 开启 | 多源召回结果需按相关性重排序，提升专业内容的展示优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 维修问答常需关联换模记录与点检数据，扩展查询可覆盖关联文档 |
| `collectionIds` | 绑定冲压车间专属知识库集合 | 隔离其他品类数据，避免无关内容干扰检索 |

## 容易做错的三处
- 检索时显示匹配到文档，但最终回答仅返回引用链接，未生成具体解答。原因：未开启`datasetSearchUsingExtensionQuery`，未关联相关文档补充上下文，导致模型无法基于召回内容生成完整回答。
- 导入docx、excel格式的文档后，检索准确率偏低。原因：未针对结构化表格内容优化检索配置，仅使用纯文本向量检索无法匹配表格内的专业参数。
- 检索结果条数与设置的`limit`不符，出现过多或过少的结果。原因：未正确配置`similarity`阈值，阈值过高过滤有效结果，阈值过低混入无关内容。

## 怎么确认配好了
- 发起包含模具编号、压边力等专业参数的查询，核对召回结果是否覆盖冲压车间专属文档。
- 调整`similarity`取值，观察召回结果的相关性变化，确认阈值适配当前场景的精度需求。
- 测试包含换模与点检关联信息的查询，确认`datasetSearchUsingExtensionQuery`功能生效，召回关联文档。
- 查看检索调用日志，确认返回结果条数符合`limit`的设置范围。
