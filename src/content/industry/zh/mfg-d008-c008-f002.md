# 化妆品生产的设备点检与维修问答：向量模型与索引

## 这个品类的数据长什么样
化妆品生产设备点检与维修问答的知识库数据，主要来自注册备案配方、原料安全资料、称量与乳化灌装设备日志、ERP/MES系统、实验室检验记录、包材版本文件。日常文档包含配方工艺单、称量投料记录、清场清洁记录、半成品检验报告、标签审核文件等。数据更新频率为每批生产或每次换线，文档字段包含限用物质含量、设备运行参数、生产批号、产品宣称内容等，单位涉及摄氏度、千克、毫升等专业生产参数。

## 这些特征在「向量模型与索引」这一环带来什么约束
化妆品生产的业务数据特征，对向量模型与索引环节带来三点约束。首先，数据按生产批次与换线高频更新，要求索引支持增量更新与快速同步，避免全量重建带来的任务延迟。其次，文档包含合规性强的备案配方、标签内容，以及专业的设备运行参数，要求向量模型能准确捕捉专业术语与合规相关的语义关联。最后，单份文档长度差异较大，从短的清场记录到长的完整工艺单，要求索引分块逻辑适配不同长度的业务文档，避免语义割裂或关键信息丢失。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配化妆品生产中配方工艺单、设备日志的常见长度，避免单块过长超出嵌入限制 |
| 重叠长度 | 100–200 字符 | 保留相邻块的语义关联，防止跨块的设备点检逻辑被分割丢失 |
| 相似度阈值 | 0.7–0.85 | 过滤低相关性的非点检类文档，精准匹配设备维修相关的语义请求 |
| 单次搜索上限 | 前 5 条 | 控制返回结果的数量，适配设备点检场景下的快速查询需求 |
| `maxToken` | 16384 | 适配长文本嵌入需求，覆盖完整的大型配方工艺单或设备日志 |
| `defaultToken` | 8192 | 匹配基础嵌入模型的默认token上限，平衡性能与资源占用 |

## 容易做错的三处
- 现象：知识库上传后长期处于索引中状态。原因：未配置增量索引触发规则，且单次处理的文档批次超出系统预设缓存阈值，导致索引任务堆积。
- 现象：设置分块长度为3000字符时出现文本块丢失。原因：未匹配嵌入模型的`maxToken`限制，长文本块超出token上限，嵌入失败后被系统自动跳过。
- 现象：搜索结果中混入大量无关的原料备案内容。原因：相似度阈值设置过低，召回了语义相似但不属于设备点检范畴的文档。

- 在FastGPT v4.17.0版本中，上传单份1000字符的设备点检记录，等待索引完成后查看分块预览，确认块数与预期一致。
- 发起模拟设备点检的问题搜索，查看返回结果的相似度得分，确认落在预设的0.7–0.85区间内。
- 批量上传3份换线后的清场记录，确认索引状态能在预设时间内完成更新（按实测标定）。
- 上传完整的大型配方工艺单，查看嵌入日志，确认无文本截断报错，验证`maxToken`配置生效。
