# 化妆品生产的设备点检与维修问答：模型接入与配置

## 这个品类的数据长什么样
该品类数据来自注册备案配方、原料安全资料、称量乳化等生产设备、ERP/MES系统、实验室记录与包材版本信息。日常文档包含配方工艺单、称量投料记录、乳化或灌装记录、清场清洁记录、半成品与成品检验报告及标签审核文件。数据更新随每批生产、每次换线触发，核心字段包含原料配比、生产参数、批号、备案编号与包材信息。

## 这些特征在「模型接入与配置」这一环带来什么约束
由于数据随每批生产快速更新，模型上下文需适配批次级数据的动态加载；多来源的结构化与半结构化文档混合，需适配不同格式的文本拆分与召回逻辑；备案编号、原料限用物质等强合规字段要求模型召回的上下文必须精准匹配业务规则；单次生产流程涉及多设备参数与批次信息，需限制单轮交互的token消耗，避免接口超时或结果溢出。同时，化妆品生产的合规性要求，模型输出需关联备案数据，因此需固定关联数据源的权限范围，防止调用未授权的生产文档。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 适配每批生产的多文档上下文，覆盖配方、生产记录与备案信息的关联查询 |
| `maxTokens` | `2000–3000 token` | 限制单轮回复长度，匹配设备点检问答的简洁性要求，避免接口超时 |
| `quoteMaxToken` | `3000–4000 token` | 限定召回的上下文总token数，确保仅调用与当前点检问题相关的批次生产数据 |
| `temperature` | `0.1–0.3` | 降低生成随机性，保证设备维修步骤与合规参数的准确性，匹配生产场景的严谨性 |
| `toolChoice` | `auto` | 允许模型自动选择是否调用工具处理设备点检的参数查询，适配多类型维修场景 |
| `AIPROXY_API_TOKEN` | 按平台分配的专属密钥填写 | 确保接口调用的权限合规，匹配化妆品生产场景的数据访问要求 |

## 容易做错的三处
- 调用接口返回403权限错误，原因是未正确配置`AIPROXY_API_TOKEN`，或使用了未适配生产场景权限的接入密钥。
- 模型召回的上下文仅包含旧批次生产数据，无法匹配当前点检的换线参数，原因是未按批次更新频率调整`maxContext`的上下文刷新规则。
- 部分厂商的最新模型无法在配置界面中选中，原因是未在接入配置中补充对应模型的接口映射规则，导致平台未加载该类模型的可选列表。

## 怎么确认配好了
- 发起一次设备点检的模拟查询，核对返回结果中是否包含当前批次的备案配方信息，确认上下文召回范围符合配置要求。
- 查看接口调用日志，确认单轮回复的token数未超出`maxTokens`的设定值，验证回复长度的合规性。
- 检查模型接入的密钥与端点配置，确认接口调用无权限报错，验证接入链路的有效性。
- 触发一次换线场景的查询，核对召回的生产数据是否为最新批次，确认更新频率适配配置规则。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
