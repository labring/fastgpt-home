# 化学药制剂生产的设备点检与维修问答：工具调用与插件

## 这个品类的数据长什么样
化学药制剂生产的设备点检与维修相关数据，来源包括经批准处方工艺、物料批次、MES/电子批记录、设备与环境监测系统、LIMS及质量管理系统。数据更新按生产批次、关键工艺步骤及监测计划执行，涵盖主生产文件、批生产记录、批包装记录、清场记录、检验记录、偏差/CAPA/变更文件及批放行审核表。数据字段包含设备运行时长、振动值、温度、投料量、生产批次号等，对应单位为小时、mm/s、℃、kg、编号格式。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据来源分散且需严格匹配GMP合规要求，因此工具调用需支持对接多系统异构接口，保障数据溯源性。数据按生产批次更新，工具触发需绑定当前生产批次参数，避免跨批次数据混淆。文档结构复杂且字段要求精准，工具调用需支持指定字段提取，避免冗余数据干扰问答结果。设备点检与维修的异常处理直接关联批次放行，工具调用失败需触发明确告警，防止延误生产或合规风险。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，可通过`toolChoice`和`functionCall`参数配置工具调用逻辑。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` | 自动匹配设备点检与维修场景下的工具调用需求，无需手动指定函数 |
| 工作流/API 函数调用配置 | 启用 | 支持调用外部设备接口获取点检数据，符合GMP下的数据溯源要求 |
| 钉钉Webhook推送配置 | 触发条件为异常生成后10秒内 | 及时将点检异常推送给运维人员，保障生产响应时效 |
| 多模态视觉分析参数 | 按实测标定 | 适配设备点检照片的1024×768像素规格，保障Qwen2.5-vl的解析精度 |
| API调用重试次数 | 3次 | 应对网络波动导致的调用失败，保障设备数据获取稳定性 |
| 上下文窗口大小 | 8000 token | 容纳完整的批记录与设备历史数据，支持精准的点检维修问答 |

## 容易做错的三处
- 现象为调用多模态视觉模型时返回「Failed to fetch」或图片解析失败报错，原因是未配置适配内网设备图片存储路径的下载权限，导致无法拉取点检照片。
- 现象为钉钉Webhook推送无响应或消息内容与当前生产批次不匹配，原因是未绑定生产批次参数触发推送，导致数据关联错误。
- 现象为工具调用返回字段为空或格式不符合要求，原因是未指定精准的数据源字段提取规则，导致从MES或LIMS拉取的设备数据不符合点检维修问答的需求。

## 怎么确认配好了
- 发起一次模拟的设备点检问答，验证工具是否自动调用对应数据源接口获取设备运行数据。
- 触发一次设备异常告警，检查钉钉Webhook是否在指定时间内推送正确的异常信息。
- 上传一张符合1024×768像素规格的设备点检照片，验证多模态模型是否能正确解析并返回维修建议。
- 查看工具调用日志，确认每次调用的参数和返回结果都符合预设的配置规则。
