# 化学药制剂生产的设备点检与维修问答：模型接入与配置

## 这个品类的数据长什么样
化学药制剂生产场景的数据来自经批准的处方工艺、MES/电子批记录、设备与环境监测系统、LIMS及质量管理系统。日常文档包含主生产文件、批生产记录、批包装记录、清场记录、检验记录、偏差/CAPA/变更文件及批放行审核表。数据随每批生产、每个关键工艺步骤及既定监测计划更新，字段涵盖物料批次、工艺参数、检验结果、设备运行状态等，需严格遵循GMP下的文件同步要求。

## 这些特征在「模型接入与配置」这一环带来什么约束
数据需严格匹配GMP下的同步要求，因此模型接入时需确保输入数据的批次关联性与审批状态可追溯。多源数据（MES、LIMS等）的格式差异，要求配置环节需统一数据字段映射规则。批记录的逐批更新要求，需适配高频次的数据同步与上下文管理。设备点检与维修问答需关联具体批次的设备参数，因此模型需精准绑定对应生产批次的上下文信息，避免跨批次数据混淆。同时，数据完整性要求需限制模型输出的引用范围，确保仅使用经批准的合规数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配批记录的长文本上下文需求，避免截断关键工艺与设备参数 |
| `maxTokens` | 2000–3000 token | 平衡设备点检问答的回答长度与响应速度，符合GMP下的审核响应节奏 |
| `toolChoice` | auto | 允许模型自主选择是否调用设备点检知识库工具，适配多场景问答需求 |
| `temperature` | 0.1–0.3 | 保持回答的严谨性，避免生成不符合GMP规范的非标准化操作指引 |
| `AIPROXY_API_ENDPOINT` | 按云服务厂商提供的专属接入地址配置 | 适配模型调用链路，确保数据传输符合合规要求 |
| `quoteMaxToken` | 1500 token | 限制引用的文档片段长度，确保仅提取与当前点检问题直接相关的合规数据 |

## 容易做错的三处
- 现象：可用模型列表为空，无法选择目标模型。原因：未正确配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，导致平台无法拉取厂商模型列表。
- 现象：工作流中代码运行结果传入AI模型时提示`chat:ai_input_is_e`报错。原因：未将代码执行的结果变量正确映射到模型输入的上下文字段，导致输入格式不符合平台要求。
- 现象：模型测试成功但无法开启或关闭设备点检问答应用。原因：工具调用配置被限制，模型无法触发知识库查询或状态切换逻辑。

## 怎么确认配好了
- 在FastGPT v4.17.0版本的平台中，进入模型接入配置页面，检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的填写是否与厂商提供的信息一致，点击测试连接按钮确认返回正常。
- 配置`maxContext`与`quoteMaxToken`参数后，上传单份批记录文档，验证模型可完整提取其中的设备运行参数与点检要求。
- 开启工具调用开关，设置`toolChoice`为auto，发起设备点检相关的测试问题，确认模型可调用绑定的知识库并返回合规内容。
- 模拟多批次数据输入，验证模型不会混淆不同批次的设备参数与工艺要求。
