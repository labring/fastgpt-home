# 半导体封装测试的设备点检与维修问答：工具调用与插件

## 这个品类的数据长什么样
该品类的业务数据覆盖封装全流程，日常文档包含封装流程卡、键合与塑封参数、晶圆来料图、测试程序版本、良率报告及失效分析报告。数据来源于晶圆测试图、生产执行系统（MES）、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格要求，更新节奏覆盖每批生产、单颗芯片测试及每日运维统计，字段包含设备编号、测试bin码、失效类型、参数阈值等，单位随文档类型动态调整。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据来源分散，覆盖设备、生产系统、检测设备及客户需求文档，工具调用需支持多源异构数据的拉取与解析。数据更新频率覆盖单颗测试、批次生产及每日运维，工具调用需适配高频更新的数据源，避免使用过期的设备参数或测试程序。不同文档的字段结构差异显著，例如晶圆来料图包含坐标参数，良率报告包含统计维度，插件需针对不同文档类型配置专属的字段映射规则。同时，设备参数错误会直接导致生产失效，工具调用需加入参数合法性校验环节，确保调用的测试程序版本、设备阈值与当前批次匹配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | `auto` | 适配多源异构数据的灵活调用需求，无需手动指定工具类型 |
| `functionCall` | `启用` | 支持结构化参数传递，可校验设备编号、测试程序版本等字段合法性 |
| 问题优化 | 按实测标定 | 适配高频更新的生产数据，优化问题与业务文档的匹配精度 |
| 最大上下文 | 8000 token | 容纳晶圆来料图、失效分析报告等长文本内容 |
| 单次工具调用上限 | 前6条 | 避免单次调用返回过多数据导致上下文溢出 |
| 工具调用重试次数 | 3 次 | 适配设备接口偶尔波动的场景，保障数据拉取成功率 |
| 知识库引用阈值 | 按实测标定 | 适配不同批次的良率报告与检测数据的匹配需求 |

## 容易做错的三处
- 现象：工具调用配置时返回字段格式错误，提示包含`$schema`的字段无效。原因：在工具输入参数中错误添加了以美元符号开头的schema字段，不符合FastGPT的参数校验规则。
- 现象：无法正常调用第三方设备接口，提示连接失败或无权限。原因：未正确配置MCP接入通道，未绑定设备的IP地址与端口映射，导致插件无法获取设备实时数据。
- 现象：知识库引用结果不符合预期，或无法切换向量模型。原因：未在系统配置中正确设置向量模型的调用参数，导致检索环节无法触发向量模型调用，或参数配置错误导致模型切换失败。

## 怎么确认配好了
本核对流程基于FastGPT v4.17.0版本。
- 进入工具调用配置页面，查看`toolChoice`与`functionCall`的配置状态，确认与预设值一致。
- 发起模拟设备点检查询，检查是否能正确拉取对应设备的参数与历史维修记录，验证多源数据调用功能正常。
- 提交测试程序版本匹配查询，检查工具是否能校验参数合法性，确认结构化调用规则生效。
- 查看知识库引用配置，确认向量模型的切换路径已配置，可通过调整检索参数验证匹配逻辑。
