# 半导体封装测试的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的核心数据来自晶圆测试图、生产执行系统（MES）、键合与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格文件。日常留存的文档包含封装流程卡、键合与塑封工艺参数表、晶圆来料批次图、测试程序版本清单、良率分析报告、失效物理分析报告。数据更新节奏随生产批次、单颗芯片测试结果及每日设备运行状态调整，单条记录包含晶圆编号、测试bin值、设备运行时长、工艺参数阈值等字段，字段规范随文档类型灵活调整，无统一固定格式。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据分散来自多类生产与检测设备，且更新频率随生产批次、单颗测试结果动态调整，对知识库检索召回带来多重约束。多源异构的文档类型，包含可视化晶圆图、工艺参数表、测试报告等，要求检索适配非结构化与半结构化数据的解析逻辑。字段无统一固定规范，需支持灵活关键词匹配，不依赖固定字段检索，避免遗漏关键关联信息。同时，检索结果的准确性直接影响生产合规性，需严格控制召回精度，防止错误匹配导致混批、工艺参数误用等严重生产问题。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 半导体封装测试工艺参数与晶圆批次匹配需要较高精度，该区间可过滤低相关结果，避免混批风险 |
| `limit` | 前10–15条 | 单批次生产关联的文档数量有限，该区间可覆盖所需的工艺参数、设备日志与测试数据，避免上下文过载 |
| `searchMode` | 向量检索+关键词混合 | 适配多源异构文档，既匹配语义关联的工艺参数，又可精准检索晶圆编号等固定标识字段 |
| `usingReRank` | 开启 | 针对失效分析报告与良率数据这类高价值文档，重排可提升Top3结果的精准度，减少人工排查成本 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充设备点检相关的衍生问题，匹配用户实际提问习惯，覆盖更多业务场景 |
| `collectionIds` | 按生产数据集、设备数据集、测试数据集分别配置 | 按数据来源分类管理，可精准召回对应环节的文档，避免跨类数据干扰 |

## 容易做错的三处
- 现象：知识库召回的内容未正确填充至System prompt的<Reference>标签内，返回结果无关联文档引用。原因：未开启知识库检索结果的上下文拼接配置，或配置中未指定引用标签的格式。
- 现象：无法导出知识库里的文件名清单，界面无对应导出选项。原因：未开启数据集的文件元数据存储开关，或未在系统设置中启用元数据导出权限。
- 现象：检索结果条数远低于预期，或匹配不到对应设备的点检记录。原因：`similarity`阈值设置过高，过滤了部分弱相关但实际匹配的设备日志，或`searchMode`仅配置为向量检索，未启用关键词匹配以检索固定编号字段。

## 怎么确认配好了
- 发起包含晶圆编号的设备点检提问，核对返回结果中是否包含对应批次的封装流程卡与测试程序文档。
- 查看聊天界面的<Reference>标签，确认召回的文档内容与提问的业务场景匹配。
- 检查数据集的元数据列表，确认可查看所有上传文件的文件名与上传时间。
- 调整`similarity`阈值，验证不同阈值下召回结果的数量变化是否符合业务需求。
