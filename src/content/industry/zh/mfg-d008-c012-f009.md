# 半导体晶圆制造的设备点检与维修问答：模型接入与配置

## 这个品类的数据长什么样
半导体晶圆制造的业务数据来源包括MES系统、设备FDC监控数据、缺陷检测与量测设备、晶圆图、工艺配方库、实验数据。数据更新节奏为每批晶圆、实时、每日，日常文档涵盖工艺流程卡、批次运行记录、设备配方、SPC图、异常处置单、缺陷图谱、良率报告。数据字段包含纳米级工艺参数、批次编号、运行时长、缺陷坐标等，部分文档为可视化的晶圆缺陷图像。

## 这些特征在「模型接入与配置」这一环带来什么约束
晶圆制造数据的纳米级参数、多工序关联特性要求模型上下文需精准匹配单批次业务范围，避免冗余数据干扰；实时与高频更新的设备数据要求模型调用适配短响应时长，防止影响产线节拍；多源异构的文档类型包含可视化缺陷图谱，要求模型支持视觉数据解析；超长工艺链与有限返工窗口要求模型输出兼顾准确性与时效性，避免出现上下文溢出或超时问题。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `vision` | 开启 | 需处理缺陷图谱、晶圆图等视觉类点检与异常数据 |
| `maxContext` | 8000–12000 token | 适配单批次晶圆的多工序关联数据量，避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 满足维修方案、点检结果的详细输出要求 |
| `quoteMaxToken` | 1500–2000 token | 限定召回的业务文档总token，减少无效数据占用 |
| `temperature` | 0.2–0.4 | 降低输出随机性，保证点检判断、维修方案的一致性 |
| 工作流/API 工具选择配置 | auto | 允许模型自主选择是否调用参数判读等工具 |
| `AIPROXY_API_TOKEN` | 按接入平台分配的密钥填写 | 完成模型接入的身份验证 |
| `AIPROXY_API_ENDPOINT` | 按接入模型的官方地址填写 | 适配跨平台模型调用的路由要求 |

## 容易做错的三处
- 模型接入后无法解析晶圆缺陷图谱：现象为界面显示图片解析失败日志，原因是未开启`vision`配置项，未适配视觉类数据的接入要求。
- token消耗统计与实际不符：现象为后台token统计数值异常偏高或偏低，原因是未正确配置`quoteMaxToken`，导致冗余召回数据被重复计入消耗。
- 接入第三方模型后返回401错误：现象为请求被拒绝，原因是`AIPROXY_API_TOKEN`填写错误，或接口地址与模型不匹配。

## 怎么确认配好了
- 上传一张晶圆缺陷图谱，触发模型问答，验证模型能否正确识别缺陷类型与位置，确认`vision`配置生效。
- 导入单批次晶圆的运行记录，输入点检异常相关问题，检查返回结果是否关联了对应的工艺配方与SPC数据，确认上下文配置生效。
- 查看FastGPT v4.17.0的模型调用日志，核对token消耗数值与`maxContext`、`quoteMaxToken`的设置匹配，确认参数配置正确。
- 输入包含参数判读需求的点检问题，验证模型是否自动完成参数漂移分析，确认`toolChoice`配置生效。
