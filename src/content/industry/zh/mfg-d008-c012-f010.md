# 半导体晶圆制造的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的业务数据来自晶圆厂的MES系统、设备FDC模块、缺陷检测与量测设备、晶圆图库、工艺配方库与实验数据平台。日常文档包含工艺流程卡、批次运行记录、设备配方、SPC图、异常处置单、缺陷图谱与良率报告。数据更新频率覆盖每批晶圆、实时与每日，字段包含晶圆ID、工序号、参数阈值、缺陷空间坐标等，单位涉及纳米、帕斯卡、批次编号等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
超长工艺链带来的多工序文档体量，要求检索需控制召回结果数量，避免超出上下文窗口。多来源异构数据（文本配方、数值SPC图、晶圆图等）要求检索模式需兼顾语义与关键词匹配。高频率更新要求索引支持增量同步，保障数据时效性。纳米级参数耦合的业务特性，要求召回结果需具备较高匹配精度，避免引入无关工序数据。跨模块良率归因的业务需求，要求检索可关联多业务集合的数据源。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75-0.85 | 匹配纳米级工艺参数与异常描述，避免误召回无关工序数据 |
| `limit` | 前8-12条 | 单批次晶圆工序覆盖范围广，过多结果会超出上下文窗口，过少无法覆盖关联异常 |
| `searchMode` | `mixedRecall` | 兼顾文本配方的语义匹配与SPC图、缺陷图谱的关键词匹配 |
| `usingReRank` | 开启 | 多来源异构数据下，重排可提升高相关结果的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 设备点检问题常隐含参数漂移与配方变更，扩展查询可关联隐含业务关联数据 |
| `collectionIds` | 按业务模块分组配置 | 精准关联设备FDC、良率报告、工艺配方等对应数据源，支持跨模块归因 |

## 容易做错的三处
- 现象：导出的知识库数据集csv文件仅包含index字段，无content字段。原因：未勾选导出时包含原文内容的选项，或自定义索引配置时未关联正确的数据源表字段。
- 现象：知识库导入文档时页数持续刷新，无法选择目标页面。原因：导入文档包含未被解析的嵌套格式元素，或单次导入的文档总量超出系统临时缓存阈值，导致页面渲染阻塞。
- 现象：离线环境下上传知识库文件后状态持续转圈，联网后恢复正常。原因：系统初始化阶段需访问外部资源完成依赖校验，离线状态下无法完成校验流程，导致上传流程阻塞。

## 怎么确认配好了
- 执行针对设备参数漂移的查询，核对返回结果的相似度分值是否落在预设的0.75-0.85区间内。
- 查看索引构建日志，确认MES记录、设备FDC数据、缺陷图谱等多来源数据已被正确关联到对应业务集合。
- 导出测试数据集，确认content字段已完整包含原文内容，无字段缺失情况。
- 断开网络后上传小型测试文档，确认上传流程可正常完成，无持续转圈阻塞现象。
