# 半导体晶圆制造的设备点检与维修问答：表单与交互

## 这个品类的数据长什么样
晶圆制造的设备点检与维修问答相关数据，通常来自晶圆厂MES系统、设备FDC采集模块、缺陷检测与量测设备、晶圆图数据库、工艺配方库及实验数据。日常涉及的文档包含工艺流程卡、批次运行记录、设备运行配方、SPC控制图、异常处置单、缺陷图谱与良率报告。数据更新节奏按每批晶圆批次、实时采集或每日同步，覆盖数百道工序的参数与记录。字段包含纳米级工艺参数、批次编号、设备运行时长等，单位涉及微米、小时、批次等专属标识。

## 这些特征在「表单与交互」这一环带来什么约束
该品类的数据多源且更新频率差异大，要求表单需支持多数据源的自动关联与实时同步，避免手动录入的误差。海量工序与复杂文档结构，要求表单需按工艺模块分组展示字段，降低录入与检索的认知成本。纳米级参数与批次绑定的特性，要求表单需预设专属字段校验规则，确保参数精度与批次关联的正确性。实时采集的设备数据需快速响应，要求交互流程轻量化，减少不必要的等待环节。超长工艺链与有限返工窗口，要求问答交互需快速定位异常类型，避免流程延误。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 按设备FDC、MES字段映射，单条输入长度800–1200字符 | 该品类的设备参数、工艺记录多为半结构化数据，限定输入长度可避免数据溢出与格式混乱 |
| `userSelect` | 按工序分组预设10–15个点检项选项 | 晶圆制造工序超百道，分组选择可降低录入与检索的成本 |
| 超时设置 | 600秒 | 实时采集的设备数据需及时同步，合理的超时时长可保障流程连续性 |
| 数据源关联开关 | 开启 | 需关联MES批次记录、晶圆图数据，自动填充已知参数减少手动输入 |
| 异常标签库 | 导入现有缺陷图谱、异常处置单模板 | 该品类异常类型需匹配工艺标准，预定义标签可统一录入格式 |

## 容易做错的三处
- 配置第三方模型端点后，界面未展示填入的baseURL对应的模型。原因是未在`formInput`中配置模型接入的同步校验逻辑，导致端点信息未正确加载到选择列表。
- 提交点检表单时出现字段为空的报错。原因是未针对晶圆制造的专属字段（如晶圆批次号、设备FDC参数阈值）设置必填校验，导致遗漏必填项提交。
- 维修问答返回的异常处置结果与当前工序不匹配。原因是未按工艺模块配置`userSelect`的分组筛选，导致检索范围覆盖了无关工序的冗余数据。

## 怎么确认配好了
- 进入FastGPT v4.17.0的表单配置页面，检查`formInput`的字段映射是否覆盖了MES、设备FDC的核心参数。
- 模拟提交点检表单，验证必填字段校验是否触发正确，多源数据是否自动填充。
- 调用配置的第三方模型端点，检查返回结果的格式是否符合`formInput`预设的输入规范。
- 选择`userSelect`的分组选项，验证检索结果是否仅包含对应工序的异常记录。
