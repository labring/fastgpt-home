# 印刷与包装加工的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自彩印、标签、纸箱、软包装及药包材企业的生产全流程，日常文档包含印前文件、拼版单、印刷工艺单、油墨配色记录、首件签样、条码检测及模切与复合记录。数据来源覆盖客户稿件、色彩管理系统、印刷机运行数据、油墨与基材批次档案、分光仪及条码检测仪的检测结果，更新频率为每订单、每批或每次换版时触发，单份文档包含版本号、色彩参数、批次编号、检测结果等字段。

## 这些特征在「知识库检索与召回」这一环带来什么约束
由于数据按订单、批次或换版高频更新，知识库需支持实时同步新生成的工艺单、检测记录等文档，避免检索结果与当前生产批次脱节。文档包含版本号、色彩参数、批次编号等细分专业字段，检索时需精准匹配对应字段，避免混同不同批次的油墨配比或模切参数。单份文档结构差异小但字段专业性强，需避免召回无关的跨品类文档，同时需适配印前文件、检测报告等不同格式的数据源，确保检索覆盖全类型业务文档。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，适配印刷与包装加工的设备点检与维修问答场景：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配印刷工艺单、油墨参数等专业字段，过滤低相关的旧版文档，适配专业内容的检索精度 |
| `limit` | 前8条 | 单批次生产相关文档数量有限，控制召回条数避免上下文过载，符合印刷包装单批次业务的文档规模 |
| `searchMode` | `embedding` | 适配专业字段的语义检索，精准匹配色彩参数、批次编号等细分业务内容 |
| `usingReRank` | 开启 | 对召回的结果按业务相关性重排，优先返回首件签样、模切记录等核心点检维修参考文档 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展点检维修相关的问题表述，比如将「套准异常」关联到对应印刷工艺参数，提升检索覆盖范围 |
| `collectionIds` | 按生产车间/产品线分组 | 区分不同品类的印刷文档，避免跨车间的无关数据被召回，缩小检索范围提升精准度 |

## 容易做错的三处
- 现象：传入知识库id变量时触发参数格式错误提示，或检索结果为空。原因：未将变量绑定至知识库检索节点的`collectionIds`配置项，或变量格式不符合系统要求。
- 现象：针对单篇PDF文档发起定向提问时，无法精准匹配目标文档。原因：未通过`collectionIds`限定目标文档所属的知识库集合，导致检索范围覆盖全库，混同其他批次的文档。
- 现象：工作流中知识库搜索节点执行后未触发预设的空结果处理分支，直接进入后续异常流程。原因：未在节点配置中添加空结果分支，或未正确绑定对应异常处理节点。

## 怎么确认配好了
- 上传单份印刷工艺单至指定知识库集合，发起包含对应批次参数的提问，核对检索结果是否包含目标文档。
- 调整`similarity`阈值，验证检索结果的相关性是否符合业务要求，确认阈值设置的合理性。
- 触发工作流中的知识库搜索节点，模拟空检索场景，确认是否触发预设的异常处理逻辑。
- 绑定知识库id变量至检索节点，发起测试对话，验证变量是否正常生效并返回对应结果。
