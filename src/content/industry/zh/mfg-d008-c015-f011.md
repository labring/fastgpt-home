# 原料药与医药中间体生产的设备点检与维修问答：表单与交互

## 这个品类的数据长什么样
该品类的数据来源包含注册工艺文档、原料批次台账、DCS控制系统、称量系统、LIMS实验室信息管理系统、色谱数据系统与QMS质量管理系统。数据更新节奏为每生产批次、每工艺步骤触发。日常文档涵盖批生产记录、物料平衡台账、反应与精制过程记录、清洁验证记录、杂质谱分析报告、偏差与变更管控文件。数据字段包含批次标识、工艺参数值、物料称量数据、杂质浓度、收率核算值等，对应标识单位为批次号、摄氏度、千克、mg/L、核算单位。

## 这些特征在「表单与交互」这一环带来什么约束
多系统来源的数据要求表单支持跨源数据拉取与字段预设，避免重复录入。高频更新节奏要求表单支持快速提交与实时校验，确保每步骤数据及时归档。多类文档与字段要求表单按业务模块拆分，降低填写复杂度。数据关联批次与设备的属性，要求表单强制关联对应标识字段，保障可追溯性。合规相关的管控要求，要求表单操作全程留痕，便于后续审计。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 允许关联LIMS与色谱数据系统的字段预设值 | 该品类数据分散在多套系统中，通过该配置可减少人工录入误差，提升数据准确性 |
| `userSelect` | 预设设备型号、点检项分类选项，选项数量不超过20个 | 原料药生产设备品类相对固定，可减少输入错误与格式不一致问题 |
| 表单分块配置 | 按点检、维修、异常上报分3个区块，每个区块不超过10个字段 | 日常文档按业务模块分类，分块可降低填写复杂度，提升准确率 |
| 必填项校验规则 | 批次号、设备编号字段为必填，校验格式为大写字母加6位数字 | 数据需关联批次与设备，确保每笔记录可追溯至对应生产环节 |
| 提交触发配置 | 填写完成后自动同步至QMS系统，同步延迟不超过60秒 | 数据更新频率为每工艺步骤，需及时归档至质量管理系统 |
| 上下文加载配置 | 加载当前批次关联的3条历史点检与维修记录 | 维修与点检工作需参考同批次过往数据，保障决策一致性 |

## 容易做错的三处
- 现象为表单无法加载跨系统的预设字段，提交后无对应数据填充。原因是未配置`formInput`的数据源关联权限，导致无法拉取LIMS或色谱数据系统的对应数据。
- 现象为用户选择点检项时无匹配选项，且无法手动输入补充内容。原因是未开启`userSelect`的自定义输入开关，且预设选项未覆盖原料药生产的小众设备点检场景。
- 现象为高级编排中工具调用无法选择对应维修知识库工具，返回空结果。原因是未在FastGPT v4.17.0的工具配置中绑定该品类专属的文档库，导致模型无法识别可用的行业知识库工具。

## 怎么确认配好了
- 提交测试批次的点检表单，检查是否自动拉取对应批次的DCS参数到表单预设字段。
- 点击点检项下拉菜单，确认列表包含原料药生产常用的设备点检内容，且可自定义补充选项。
- 提交未填写批次号的表单，检查系统是否弹出格式错误提示。
- 提交完整表单后，检查QMS系统是否在60秒内同步收到对应记录。
