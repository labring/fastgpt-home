# 变压器与高压电器制造的设备点检与维修问答：部署与升级

## 这个品类的数据长什么样
该品类的业务数据源自设计BOM、硅钢片与绝缘材料台账、真空干燥设备运行日志、绝缘油化验报告、高压试验站原始记录及产品铭牌参数表。数据按单台成品或每批原材料更新，对应文档包含绕制与器身装配流程记录、真空干燥工艺参数台账、绝缘油击穿电压与含水量报告、局放和耐压试验原始数据、产品铭牌参数表。数据字段包含绝缘距离、干燥温度、试验电压、分接位置等专属参数，无通用批量装配类数据的标准化批次字段。

## 这些特征在「部署与升级」这一环带来什么约束
单台产品全生命周期追溯的属性，要求问答系统需支持按设备ID关联多源异构的业务数据，部署时需配置专属的数据关联逻辑。多类型非结构化试验文档的混合格式，要求系统需兼容PDF、CSV、日志文件等多种解析插件，升级时需保障新增解析能力不影响原有业务流程。高频更新的绝缘油、干燥设备实时数据，要求存储配置需支持低延迟读写与实时同步，避免数据滞后导致问答结果偏差。高压试验的局放异常数据需关联原始试验日志，部署时需确保知识库索引覆盖高维度的试验参数字段，无法兼容通用装配类的简化索引逻辑。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `REDIS_URL` | `redis://:自定义密码@内网缓存IP:6379/0` | 该品类数据需高频读写缓存设备关联关系与试验参数，内网部署可保障低延迟，数据库索引0用于隔离业务缓存 |
| `FILE_TOKEN_KEY` | `32位随机十六进制字符串` | 需为每份设备专属文档生成唯一访问令牌，防止未授权访问绝缘油报告等敏感业务数据 |
| `STORAGE_S3_ENDPOINT` | `内网对象存储端点:9000` | 单台产品关联多份试验文档，内网存储可保障批量文档上传下载的稳定性，适配高频数据更新需求 |
| `DB_MAX_LINK` | `20–30` | 需同时处理多台设备的点检查询请求，该取值可平衡并发负载与数据库性能 |
| `PG_URL` | `postgresql://用户名:自定义密码@内网数据库IP:5432/fastgpt` | 需存储设备BOM与试验数据的关联关系，PostgreSQL可保障结构化数据的查询准确性 |

## 容易做错的三处
- 现象：升级FastGPT至v4.17.0后，点击知识库的绝缘油报告详情，显示“Invalid dataset file key ”。原因：升级过程中未同步更新`FILE_TOKEN_KEY`的配置值，导致原有文档令牌校验失败。
- 现象：运行绝缘油报告或耐压试验记录的解析任务时，出现Node.js版本不兼容报错。原因：未将sandbox镜像的Node版本升级至20.20.0，导致部分专用解析插件无法正常加载。
- 现象：调用qwen3-max模型生成点检问答结果时，返回404状态码且无响应体。原因：使用v4.11.0版本部署，该版本未适配qwen3-max模型的接口规范。

## 怎么确认配好了
- 登录FastGPT后台管理界面，检查`REDIS_URL`的配置项，确认连接地址与端口与内网缓存服务一致。
- 上传一份单台变压器的绝缘油报告文档，生成访问链接，验证链接携带的令牌可正常访问文档内容。
- 发起单台设备的点检问答请求，确认系统可返回对应设备的绕制记录、真空干燥参数与高压试验数据。
- 查看存储服务的监控指标，确认文档上传下载的并发请求符合业务峰值需求。
