# 喷涂与涂装的设备点检与维修问答：工具调用与插件

## 这个品类的数据长什么样
该品类数据覆盖汽车、家电、工程机械、金属家具涂装线场景，日常文档包含涂装工艺卡、涂料批次单、调漆记录、膜厚色差报告、烘炉曲线、缺陷返修单、VOCs台账。数据来源包括涂料供应商TDS/SDS文件、喷房与烘炉实时采集数据、色差仪、膜厚仪读数、环境监测记录及MES系统数据。更新节奏随每批涂料批次、每班作业及连续设备运行同步更新，文档字段包含工艺参数、物料批号、检测数值、设备运行曲线、缺陷类型等，部分文档需匹配行业通用单位，如膜厚单位微米、烘炉温度单位摄氏度。

## 这些特征在「工具调用与插件」这一环带来什么约束
涂装品类的多源异构数据结构要求工具调用需适配不同文档格式，如结构化的涂料TDS/SDS文件、时序化的烘炉运行曲线。多频次更新要求工具调用支持实时拉取MES、设备传感器的最新数据，避免使用过期的涂料黏度或烘炉温度参数。多类型检测数据需工具调用时关联对应批次的物料信息，确保维修问答的匹配精度。VOCs台账的合规性要求工具调用需同步校验相关数据字段，确保输出符合业务规范。同时，需启用`functionCall`以支持结构化参数传递，适配涂装工艺的固定字段格式。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` | 适配涂装场景下多工具并行或按需调用的需求，无需手动指定单个工具 |
| 工具调用超时时间 | 600 秒 | 匹配涂装设备数据拉取、工艺参数校验的常规耗时区间 |
| 单次工具调用返回条数 | 前3-5条 | 避免冗余数据干扰涂装维修问答的核心判断 |
| 工作流/API 函数调用配置 | `enabled` | 支持结构化参数传递，适配涂装工艺卡、涂料批次单的固定字段格式 |
| 工具调用上下文缓存时长 | 120 分钟 | 覆盖单班作业的连贯维修流程需求 |

## 容易做错的三处
- 现象：调用工具时返回`400 InternalError.Algo.InvalidParameter: The tool`报错。原因：未按涂装品类的固定字段格式传递参数，例如未携带涂料批次号或膜厚检测数值字段。
- 现象：无法通过插件读取涂装场景的图片数据。原因：未适配涂装类图片（如色差报告、烘炉曲线截图）的解码格式，或未配置支持图像解析的工具链。
- 现象：线上创建的插件无法在流程中调用。原因：未将插件关联至对应工具调用节点，或未保存插件配置后发布到生产环境。

## 怎么确认配好了
- 发起包含涂装设备参数查询的测试请求，检查工具调用是否返回对应批次的涂料黏度、烘炉温度数据。
- 触发包含结构化参数的工具调用，检查返回结果是否符合涂装工艺的固定字段格式。
- 上传涂装类图片文件，验证工具调用是否能正确解析图片中的检测数值。
- 发布插件配置后，在流程编辑界面中确认插件已被列为可选调用工具。
