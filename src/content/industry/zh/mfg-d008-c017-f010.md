# 喷涂与涂装的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
喷涂与涂装场景的业务数据来源包括涂料供应商TDS/SDS文件、喷房与烘炉实时运行数据、色差仪与膜厚仪检测报告、环境监测记录及MES系统工单。数据更新节奏覆盖每批涂料批次、每班工艺调整及连续采集的设备运行参数。文档类型包含涂装工艺卡、涂料批次单、调漆记录、膜厚色差报告、烘炉温度曲线、缺陷返修单与VOCs台账，字段包含工艺参数值、检测结果、批次标识与设备编号，部分专业字段带有行业标准单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源且高频更新的数据要求检索链路支持近实时的文档同步，避免召回过时的工艺参数或设备记录。多样的文档类型与专业字段需要检索逻辑兼顾语义匹配与关键词精准匹配，确保膜厚、烘炉温度、色差ΔE等专业术语能被正确识别。不同批次的涂装数据关联性强，召回结果需覆盖同一工艺窗口下的关联文档，避免拆分的参数信息无法形成完整解决方案。同时，涂装场景的出错后果直接关联批量返修与合规风险，检索结果的精准度要求高于通用场景，需严格过滤不相关的非涂装类数据。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 喷涂行业专业参数匹配需要较高相似度阈值，过滤低相关的通用设备文档 |
| `limit` | `8–12条` | 涂装设备点检问题涉及多环节工艺参数，需要足够召回量覆盖完整的工艺窗口 |
| `searchMode` | `mixedRecall` | 兼顾专业术语的语义匹配与关键词的精准匹配，适配涂装场景的多类型文档 |
| `usingReRank` | 开启 | 涂装场景下参数关联度高，重排可以过滤冗余结果，提升高相关文档的排名 |
| `datasetSearchUsingExtensionQuery` | 开启 | 涂装问题常涉及工艺参数的关联信息，扩展查询可以覆盖相关批次、设备的关联数据 |
| `collectionIds` | 绑定涂装设备点检专属数据集 | 隔离其他品类的知识库内容，避免召回不相关的非涂装类文档 |

## 容易做错的三处
- 现象：全文检索与语义检索均无法召回指定的涂料批次单或烘炉曲线文档，返回大量不相关的通用设备文档。原因：未通过`collectionIds`绑定专属数据集，导致检索范围覆盖了无关品类的知识库内容。
- 现象：配置了`usingReRank`但在线召回测试时未生效。原因：未在知识库索引环节开启重排开关，或重排模型未适配涂装专业文本的语义匹配逻辑。
- 现象：设置了较大的`limit`参数后，大模型无法接收上下文内容。原因：未调整知识库上下文总长度限制，超出大模型的输入token上限，导致上下文被截断或丢弃。

## 怎么确认配好了
- 上传一份专属的涂装工艺卡文档，执行针对性检索，确认能召回该文档且无无关结果。
- 开启`usingReRank`后，对比开启前后的召回结果排序，确认高相关文档的排名发生合理变化。
- 调整`limit`参数至测试值，查看大模型输入上下文的日志，确认内容完整未被截断。
- 测试包含专业术语的查询，比如「膜厚不合格的返修流程」，确认召回的文档包含对应的缺陷返修单内容。
