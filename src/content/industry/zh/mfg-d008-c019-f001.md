# 塑料注塑成型的设备点检与维修问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
本品类数据来自树脂批次与物性表、注塑机参数、模温机、生产执行系统（MES）及尺寸外观检测设备。日常文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验表、巡检表、换料清机记录。数据更新随每批生产、每次换模换料、每班巡检完成，字段涵盖树脂批次号、注塑机压力/温度参数、模温数值、巡检项合格状态等，适配不同生产场景的动态调整需求。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
本品类的数据高频更新、多源异构且字段随生产场景动态调整，对HTTP接口与外部系统对接带来多重约束。多源数据需通过接口统一拉取，要求`Authorization`配置支持多来源的鉴权规则。高频更新要求接口响应延迟控制在合理区间，避免影响生产节奏。动态字段需求要求`responseData`支持灵活的字段映射，适配不同生产批次的文档结构。跨系统对接需兼容注塑机、模温机、MES等不同设备的输出格式，减少数据转换成本。

## 配置怎么定
以下配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `Authorization` | `Bearer ${临时token}，有效期不超过72小时` | 适配注塑设备与生产执行系统的鉴权规范，降低长期token的安全隐患 |
| `variables` | 包含树脂批次号、注塑机压力阈值、模温区间等字段，按生产批次动态更新 | 匹配本品类文档的动态字段结构，支撑设备点检与维修问答的精准匹配 |
| `responseData` | 返回前10条匹配的注塑工艺卡、巡检记录或模具履历 | 覆盖单次生产场景下的核心参考数据，避免冗余信息干扰问答 |
| 接口超时时间 | 60秒 | 适配注塑设备数据拉取的常规延迟范围，避免超时中断生产相关的问答流程 |
| 数据同步频率 | 每10分钟一次 | 匹配本品类每班、每批的更新节奏，平衡实时性与系统负载 |

## 容易做错的三处
- 现象：调用外部设备接口时返回`401 Unauthorized`报错。原因：未正确配置`Authorization`参数，使用了过期或无对应生产设备访问权限的鉴权信息。
- 现象：调用注塑机参数拉取接口时返回`404 Not Found`。原因：接口路径未匹配目标设备的实际部署地址，或未在`variables`中配置正确的注塑机ID。
- 现象：调用数据更新接口时返回`500 Internal Server Error`。原因：`responseData`未正确映射本品类的动态字段结构，导致接口无法解析返回的注塑工艺或巡检记录数据。

## 怎么确认配好了
- 调用配置好的HTTP接口，检查鉴权参数是否能正常通过，返回对应生产场景的设备与文档数据。
- 验证`variables`中的字段是否随生产批次、换模换料操作动态更新，匹配当前生产的文档结构。
- 确认`responseData`返回的内容包含当前生产所需的注塑工艺卡、巡检记录等核心参考数据。
- 测试接口的响应时间是否符合生产场景的延迟要求，调整超时时间至合理区间。
