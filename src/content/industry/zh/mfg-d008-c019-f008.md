# 塑料注塑成型的设备点检与维修问答：文档解析与分块

## 这个品类的数据长什么样
该品类的数据来自树脂批次物性表、注塑机参数、模温机、MES系统及尺寸外观检测结果，日常文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验表、巡检表、换料清机记录。数据更新随每批生产、每次换模换料及每班作业触发，文档包含充填保压冷却窗口参数、原料干燥与回料比例、缺陷分析记录等字段，单位涵盖温度、压力、时间、比例值等。

## 这些特征在「文档解析与分块」这一环带来什么约束
文档类型覆盖结构化表格与非结构化分析文本，且更新频率高，需适配多格式内容的精准解析；字段包含多组关联物理参数，分块需保留参数间的上下文关联，避免拆分后语义断裂；不同文档结构差异显著，需支持自定义解析规则适配不同文档类型；大型打包文档上传需求多，需放宽上传与解析的阈值限制。

## 配置怎么定
本章节配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配注塑文档中参数组与缺陷分析的语义单元长度，避免拆分参数关联 |
| `chunkSplitter` | 按段落+语义边界 | 匹配工艺卡、巡检表的结构化段落与非结构化缺陷分析的自然语义 |
| `customPdfParse` | 启用结构化解析 | 适配注塑文档中表格化的工艺参数、模具履历等结构化内容，保留字段关联 |
| `UPLOAD_FILE_MAX_SIZE` | 500 MB | 覆盖单批次完整模具履历、多份工艺卡打包上传的场景 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300 秒 | 适配大型注塑工艺文档、多页巡检表的解析耗时，避免超时失败 |
| `chunkSettingMode` | 手动配置 | 针对不同文档类型（工艺卡/巡检记录）调整分块规则，适配差异化内容结构 |

## 容易做错的三处
- 现象：上传注塑工艺PDF后解析结果字段为空。原因：未启用`customPdfParse`配置，默认通用解析无法识别注塑文档中的表格化参数字段。
- 现象：解析Excel格式的原料干燥记录时返回超时错误。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`至适配值，大型Excel台账解析耗时超出默认阈值。
- 现象：分块后相邻的充填保压参数与冷却窗口参数被拆分到不同块中。原因：`chunkSize`设置过小，导致语义关联的参数组被强制拆分。

## 怎么确认配好了
- 上传一份标准注塑工艺卡PDF，查看解析结果中是否保留了充填压力、保压时间等参数的完整关联。
- 上传单份100页以上的巡检表文档，确认解析进度未触发超时报错。
- 上传Excel格式的原料干燥记录，查看解析结果中是否包含批次号、干燥温度、时长等字段。
- 调整`chunkSize`至不同区间，对比分块结果，确认参数组未被强制拆分。
