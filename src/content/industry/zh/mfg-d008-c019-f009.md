# 塑料注塑成型的设备点检与维修问答：模型接入与配置

## 这个品类的数据长什么样
本品类的核心数据包含树脂批次物性表、注塑机运行参数、模温机温控记录、MES系统生产数据、首件检验记录、换料清机记录与模具履历。数据更新节奏为每批生产完成、每次换模换料操作后、每班巡检结束后更新。日常文档包含结构化的注塑工艺卡、带含水率字段的原料干燥记录、按周期维护的模具档案。字段包含以摄氏度为单位的模温、以兆帕为单位的注塑压力、字符串格式的原料批次号。

## 这些特征在「模型接入与配置」这一环带来什么约束
高频更新的生产数据要求模型上下文能够适配频繁刷新的文档内容，避免因上下文截断丢失关键生产参数。多类型文档的关联需求要求模型能够联动注塑工艺卡、模具履历与实时运行数据，输出针对性的点检与维修建议。注塑专用的参数单位与术语要求模型能够准确识别并标准化输出，避免因格式或术语错误导致操作失误。严重的出错后果要求模型输出的维修方案与参数建议具备较高稳定性，减少随机误差。

## 配置怎么定
以下配置项基于FastGPT v4.17.0版本的界面与参数规则制定。

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配多类型注塑文档的上下文关联，避免截断工艺参数与模具履历内容 |
| `maxTokens` | 2000–3000 token | 满足设备点检维修问答的长回复需求，包含故障分析与完整解决方案 |
| `temperature` | 0.2–0.4 | 降低输出随机性，保证注塑专用术语与参数单位的一致性 |
| 工作流/API 工具选择配置 | auto | 允许模型自主调用工具查询实时注塑机参数与模具维护记录 |
| `AIPROXY_API_ENDPOINT` | 按平台提供的专属地址填写 | 适配国内或海外模型调用的网络环境要求 |
| `AIPROXY_API_TOKEN` | 绑定对应模型的有效密钥 | 确保接口调用权限合法有效 |

## 容易做错的三处
- 接口调用返回429状态码，提示QPS超限。原因是未根据注塑生产的批量调用节奏调整QPS阈值，高频触发平台调用限制。
- 模型输出的维修步骤未使用标准Markdown格式，参数单位标注错误。原因是未配置适配注塑专用术语的提示词，或`temperature`取值过高导致输出随机性过强。
- 配置`AIPROXY_API_TOKEN`后无法调用指定模型，界面显示模型列表与官方渠道不符。原因是未绑定对应模型的专属密钥，或未在平台配置中开启目标模型权限。

## 怎么确认配好了
- 提交一条包含注塑机压力参数的点检查询，核对返回结果中参数单位与本地文档一致。
- 连续发起3次同类型查询，检查返回格式稳定符合预设的Markdown结构。
- 查看平台接口调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的匹配性无报错。
- 触发换模换料后的场景查询，验证模型能关联模具履历与当前注塑参数。
