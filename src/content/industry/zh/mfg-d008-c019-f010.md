# 塑料注塑成型的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
塑料注塑成型的设备点检与维修相关数据，来源涵盖树脂批次物性表、注塑机运行参数、模温机数据、生产执行系统（MES）记录、产品尺寸与外观检测结果。日常文档包含注塑工艺卡、原料干燥记录、模具履历、首件检验报告、班组巡检表、换料清机记录。数据更新随生产批次、换模换料操作及班组班次触发，无固定周期，但单次更新内容均关联当前生产环节。文档兼具结构化参数表与非结构化操作记录，字段包含温度、压力、时间等工艺参数，单位涵盖摄氏度、兆帕、秒等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据更新频繁且关联当前生产环节，要求检索需支持实时或近实时的数据源同步能力，避免召回过时的工艺参数。文档兼具结构化参数与非结构化记录，检索需同时适配关键词匹配与语义理解，确保能从工艺卡的参数表和巡检表的口语化描述中召回有效内容。数据字段包含多单位的工艺参数，检索需支持单位补全与匹配，避免因单位缺失导致的召回失败。设备故障后果严重，要求检索结果的置信度需维持在较高水平，减少误召回无关文档的概率。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 注塑成型的故障描述（如缩水、飞边）语义相似度要求较高，该区间可过滤低关联结果，同时保留有效匹配项 |
| `limit` | `前6条` | 单批次注塑的故障关联数据量有限，过多结果会超出上下文窗口，影响大模型回答的准确性 |
| `usingReRank` | 开启 | 注塑工艺参数的语义关联复杂，重排可过滤表面相似但参数不匹配的结果，提升召回精准度 |
| `searchMode` | 语义检索 | 点检人员的提问常为口语化表述（如“模温太高怎么办”），语义检索比关键词匹配更适配此类场景 |
| `datasetSearchUsingExtensionQuery` | 开启 | 点检人员的提问常省略参数单位（如只说“模温过高”），扩展查询可补全常见单位，提升匹配成功率 |
| `collectionIds` | 绑定注塑成型专属知识库集合 | 需限定检索范围至本品类的设备文档，避免混入其他品类的冗余数据，确保召回内容与当前生产场景匹配 |

## 容易做错的三处
- 现象为知识库解析文件时日志报slow operation xxxxms，原因是未针对注塑成型的大尺寸工艺卡（单份可超数千字符）设置合理分块参数，导致分块处理超时。
- 现象为返回报错文案“insufficient_quota 当前分组上游负载已饱和”，原因是未设置合理的`limit`参数，单次检索请求携带过多上下文数据，触发上游负载限制。
- 现象为部分巡检表文件未生成问答对，原因是未开启`datasetSearchUsingExtensionQuery`，导致文件中的非标字段（如回料比例）无法被正确识别为检索关键词，导致分块失败。

## 怎么确认配好了
- 上传一份注塑机参数文档与模温机记录，检索“模温过高怎么调整”，核对返回结果是否包含模温机的参数调整范围与注塑机的对应工艺要求。
- 查看FastGPT v4.17.0的知识库解析日志，确认无slow operation相关报错，验证分块与检索参数设置生效。
- 发起多次不同表述的点检提问（如“缩水怎么修复”“产品收缩怎么办”），核对返回结果的`similarity`分值是否处于预设的0.75–0.85区间内。
- 检查检索结果的来源标签，确认仅来自注塑成型专属的知识库集合，无其他品类文档混入。
