# 家用电器整机制造的设备点检与维修问答：工作流编排

本配置基于FastGPT v4.17.0版本，适配家用电器整机制造的设备点检与维修问答工作流需求。

## 这个品类的数据长什么样
家用电器整机制造的设备点检与维修问答相关数据，主要来源于ERP/MES系统、零部件批次台账、拧紧与制冷剂充注设备日志、安规测试仪、性能实验室检测报告及售后故障返修记录。日常支撑文档包含配置BOM、装配作业指导书、制冷剂充注记录、电气安全测试报告、性能抽检报告及返修台账。数据更新频率覆盖单台产品级、班组级及抽检计划级，每个文档对应具体生产批次或单台成品的专属参数。

## 这些特征在「工作流编排」这一环带来什么约束
该品类的多批次混线装配、多维度工艺数据关联及高风险出错后果，对工作流编排提出明确约束。单台产品的专属数据需通过`variables`传递，避免跨批次参数混淆；多数据源的实时读取需适配不同更新节奏，防止节点执行顺序错误；安规与售后数据的关联查询，要求工作流支持跨系统数据联动；批量混线生产场景下，需限制单工作流的并行执行实例数量，避免服务器资源过载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 全局变量绑定 | 绑定`variables`为单台产品的BOM编号、批次号 | 适配单台产品专属数据的传递需求，避免混线装配时的参数混淆 |
| 数据库连接超时 | 600秒 | 适配制冷剂充注记录、安规测试报告等长周期数据的读取需求 |
| 节点执行顺序 | 按`nodeId`升序排列 | 确保拧紧充注、安规测试等前置工艺节点完成后，再执行维修问答逻辑 |
| 单次召回条数 | 前5条 | 适配维修问答的知识库检索需求，避免过多冗余数据干扰核心逻辑 |
| 节点重试次数 | 3次，按实测标定 | 适配工艺数据读取的异常恢复需求 |
| 插件导出权限 | 仅开放给指定工作流组 | 防止核心工艺文档被非授权导出，符合生产数据安全要求 |
| 全局token传递 | 配置为应用级全局变量 | 满足跨节点的身份验证与数据访问需求 |

## 容易做错的三处
- 工作流中的单独插件导出时提示权限不足，原因是未配置插件导出的权限范围，仅开放给指定工作流组的设置未生效。
- 数据库连接插件执行耗时过长，原因是未设置合理的超时阈值，且未按`nodeId`调整节点执行顺序，导致重复读取同批次的工艺数据。
- classify模块在编辑阶段无法选择模型，发布后可正常使用，原因是编辑阶段未绑定对应模型的全局变量，发布时自动同步了应用级的模型配置。

## 怎么确认配好了
- 触发测试工作流，检查`variables`是否正确传递了预设的单台产品BOM编号与批次号。
- 运行数据库连接节点，确认读取安规测试报告的耗时符合预设阈值。
- 尝试导出工作流中的工艺文档插件，确认仅授权用户可执行该操作。
- 发布工作流后，输入不同型号的产品参数，确认classify模块触发对应维修知识库的逻辑正常。
