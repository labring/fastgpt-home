# 家用电器整机制造的设备点检与维修问答：模型接入与配置

## 这个品类的数据长什么样
该品类的数据覆盖空调、冰箱、洗衣机及小家电整机生产全流程，日常文档包含配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告与返修记录。数据来源涵盖ERP/MES系统、零部件批次台账、拧紧与充注设备日志、安规测试仪数据、性能实验室检测结果及售后故障档案。数据更新节奏按单台产品、每班作业及抽检计划执行，字段包含设备编号、工艺参数、检测结果、批次信息与故障类型。

## 这些特征在「模型接入与配置」这一环带来什么约束
多型号混线装配的特性要求模型能快速区分不同产品的工艺参数与安规要求，需精准匹配对应文档片段。多源异构数据来源意味着接入时需兼容不同格式的日志与报告，需配置适配多类型数据源的读取规则。按单台、每班、抽检的更新节奏，要求模型上下文窗口能及时加载最新批次的工艺与检测数据，避免调用过时信息。直接面向消费者的属性要求模型输出的维修指导需符合安规要求，需严格关联对应文档中的安全条款，避免生成不符合合规要求的内容。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配多型号混线装配的文档拼接需求，容纳多批次的工艺与检测数据 |
| `maxTokens` | 4000 token | 控制单轮问答的输出长度，确保维修指导信息简洁且覆盖核心要点 |
| `temperature` | 0.2–0.4 | 降低输出随机性，确保安规与工艺参数的表述准确一致，符合企业文档要求 |
| `quoteMaxToken` | 2000–3000 token | 精准提取单条工艺文档的关键信息，避免冗余内容干扰故障判断 |
| `AIPROXY_API_ENDPOINT` | 企业内部大模型部署地址 | 适配数据隔离需求，避免敏感工艺与售后数据外泄 |
| `AIPROXY_API_TOKEN` | 企业专属访问令牌 | 保障内部大模型调用的安全性，防止未授权访问 |

## 容易做错的三处
- 现象：调用模型时返回500状态码，提示地址无效。原因：未正确配置`AIPROXY_API_ENDPOINT`为本地大模型实际部署地址，误填为默认公共地址或第三方平台地址。
- 现象：模型输出的维修指导包含错误的安规参数或工艺要求。原因：`temperature`取值过高，导致模型生成不符合企业文档的随机参数，偏离实际生产要求。
- 现象：无法在系统界面选择已通过openapi配置的模型。原因：未正确配置`AIPROXY_API_TOKEN`，导致平台无法拉取已接入的模型列表，或令牌权限不足。

## 怎么确认配好了
- 调用模型测试接口，传入一条家电设备的故障描述，检查返回结果是否关联到本地配置的工艺文档片段。
- 查看模型接入日志，确认`maxContext`、`maxTokens`等参数值与配置一致，无被系统默认值覆盖的情况。
- 在系统模型选择界面，确认已通过openapi配置的大模型已正常显示，可正常选中调用。
- 模拟多型号混线的点检场景，传入不同型号的BOM编号，检查模型是否能匹配对应型号的装配与维修文档。
