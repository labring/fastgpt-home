# 家用电器整机制造的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的日常文档包含配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告、返修记录。数据来源包括ERP、MES系统，零部件批次数据，拧紧、充注设备日志，安规测试仪、性能实验室检测数据，以及售后故障记录。数据更新节奏按单台设备、每班作业、抽检计划执行，文档字段包含物料编码、作业工位、检测参数、故障编码等，部分文档带计量单位，如制冷剂充注量的千克。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类多型号混线装配的特征，要求知识库检索需精准匹配设备型号与工位场景，避免混线错装。高频更新的单台、每班数据，要求检索环节支持实时同步最新的充注记录、返修数据。多类型文档共存，包括结构化的BOM、检测报告与非结构化的作业指导书，需要适配不同的召回规则。安规相关文档的风险属性，要求检索优先召回高置信度的合规数据，防止漏电、泄漏等风险。售后故障数据与生产数据的关联，要求检索可跨数据源召回关联记录，支撑综合异常判断。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 家用电器整机制造的文档包含大量型号参数与工艺细节，需过滤低匹配度的无关文档，避免混线检索干扰 |
| `limit` | `前6–8条` | 单台设备的点检与维修涉及多环节文档，适量召回可覆盖装配、检测、返修全流程，同时控制上下文长度 |
| `searchMode` | 向量检索+关键词混合 | 兼顾结构化的BOM、检测参数的关键词匹配与非结构化作业书的语义检索，适配多类型文档 |
| `usingReRank` | 开启 | 多型号文档易出现语义相似但场景不符的结果，重排可提升高相关文档的排序优先级，适配混线生产的精准需求 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可基于用户提问自动扩展点检、维修相关的关键词，如补充故障代码、工位号，匹配生产系统中的结构化数据 |
| `collectionIds` | 绑定生产相关数据集ID | 仅召回该品类的BOM、作业书、检测报告等专属文档，排除无关知识库内容，避免检索干扰 |

## 容易做错的三处
- 现象：知识库检索返回结果为空或字段缺失。原因：未绑定对应品类的`collectionIds`，检索范围覆盖了无关数据集，无法匹配家用电器整机制造的专属文档。
- 现象：检索结果中混有其他品类的设备文档。原因：未设置合理的`similarity`阈值，或未开启`usingReRank`，导致低相关的相似文档被优先召回，引发混线错装风险。
- 现象：无法召回结构化的BOM或检测报告数据。原因：未开启`datasetSearchUsingExtensionQuery`，或未配置`searchMode`为混合检索模式，仅依赖纯语义检索无法匹配结构化字段。

## 怎么确认配好了
- 执行单台家电设备的点检提问，核对返回结果是否包含对应型号的BOM、装配作业书，确认`collectionIds`绑定正确。
- 调整`similarity`参数，验证返回结果的匹配度是否符合生产场景的精度要求，确认阈值设置合理。
- 上传测试用的制冷剂充注记录文件，执行相关提问，验证是否能召回结构化字段内容，确认`searchMode`与`datasetSearchUsingExtensionQuery`配置生效。
- 开启`usingReRank`后对比检索结果排序，确认高相关文档的排序优先级得到提升。
