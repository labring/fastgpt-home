# 家用电器整机制造的设备点检与维修问答：表单与交互

## 这个品类的数据长什么样
本品类数据来源于家电整机制造的ERP、MES系统，以及拧紧设备、制冷剂充注设备、安规测试仪、性能实验室设备，还有售后故障数据。日常文档包含配置BOM、装配作业书、制冷剂充注记录、电气安全测试报告、性能抽检报告、返修记录。数据更新节奏按单台产品、每班作业或抽检计划执行，覆盖零部件批次、工艺参数、检测结果与售后异常信息。

## 这些特征在「表单与交互」这一环带来什么约束
单台产品的高频更新数据要求表单交互支持实时关联零部件批次与工艺参数，避免错装或参数不符。多型号混线生产的场景需要表单交互组件支持动态匹配当前产线型号，适配不同产品的点检项差异。覆盖安规测试、性能检测、售后返修多类文档的需求，要求表单可调用多源异构数据，确保问答内容的准确性。返修记录与抽检数据的关联需求，需要交互环节支持跨文档字段联动，辅助维修人员快速定位异常原因。直接面向消费者的产品属性，要求表单输出的异常判断需符合通用消费端认知，避免专业术语过度堆砌。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 开启附件上传功能，限制单文件≤100 MB，支持批量上传≤5张，兼容JPG/PNG格式 | 适配家电点检与维修场景的现场照片、测试记录采集需求，符合FastGPT v4.17.0的组件配置规则 |
| `userSelect` | 绑定ERP/MES的产线型号、零部件批次数据源，选项更新频率设为每班一次 | 匹配混线生产的型号切换节奏，确保交互选项与当前产线一致，避免错装 |
| 语音输入支持 | 开启中文普通话识别功能，响应超时设为30秒 | 适配现场维修人员不便手动输入的场景，提升交互效率 |
| HTTP请求触发规则 | 绑定表单提交事件触发，超时阈值设为600秒 | 确保等待设备测试数据返回后完成问答解析，适配家电制造的工艺检测周期 |
| 动态选项更新 | 按产线工位触发更新，更新延迟≤2秒 | 满足混线生产时快速切换点检项的需求，减少等待时间 |

## 容易做错的三处
- 现象为聊天功能的输入框未显示上传文件按钮，原因是未开启`formInput`组件的附件上传配置，未匹配点检场景的照片采集需求。
- 现象为用户选择模块的选项无法随当前产线型号动态调整，原因是未将`userSelect`绑定实时更新的产线型号数据源，选项更新频率未适配每班的产线切换节奏。
- 现象为通过HTTP请求调用Python脚本时，上传的图片未被正确解析，接口返回空值或格式错误，原因是未在请求中正确携带图片二进制数据，未配置表单字段与脚本接口的参数映射规则。

## 怎么确认配好了
- 打开聊天界面的输入框，确认存在附件上传按钮，尝试上传一张JPG格式的测试照片，验证上传流程可正常完成且无报错提示。
- 切换模拟产线型号，检查`userSelect`模块的选项是否同步更新，验证动态绑定逻辑生效。
- 发起语音输入测试，等待30秒内确认生成对应的文字内容，验证语音转文字功能正常运行。
- 配置模拟HTTP请求，上传测试图片并调用预设脚本，确认接口返回解析后的文本结果，验证数据流转正常。
