# 工业仪器仪表制造与校准的设备点检与维修问答：多轮对话与提示词

## 这个品类的数据长什么样
本品类数据来自流量、压力、温度、分析仪器制造商及计量实验室，日常文档包含装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录。数据来源于设计文件、标准器与环境监测数据、校准软件、实验室信息系统及客户量程要求，更新频率为每台设备每次校准后更新。文档结构按校准流程拆分，包含计量溯源链、误差计算值、量程参数等字段，单位多为国际标准计量单位，如帕斯卡、摄氏度、百分比误差等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
本品类的校准记录为核心交付物且按单台单次更新，多轮对话需绑定设备序列号、校准批次等唯一标识，避免上下文混淆。文档包含误差曲线、计量证书等带溯源要求的内容，提示词需明确要求引用经校准的标准器数据与溯源链信息，不可脱离计量规范。数据更新频率高，对话上下文需限制有效时长，防止调用过期的校准记录。同时，设备点检与维修问答需关联装配调试单的步骤，提示词需区分点检项、维修步骤的检索优先级。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 对话历史调用参数 | 调用`messages`的前8轮内容，按实测标定 | 本品类数据更新频繁，调用有限轮次的对话历史可避免加载过期的校准记录 |
| 上下文绑定变量 | 引入`variables`中的设备序列号、校准批次字段 | 本品类数据按单台校准更新，绑定唯一标识可避免不同设备的校准记录混淆 |
| 会话关联参数 | 绑定`chatId`到当前设备的点检维修流程 | 可将对话会话与特定设备绑定，确保多轮对话的上下文一致性 |
| 图片识别开关 | 开启，按实测标定 | 设备点检场景常需上传仪表读数照片、误差曲线截图，开启后可识别图片中的计量数值与标注 |
| 引用文件展示开关 | 关闭 | 设备点检与维修问答需聚焦当前问题，展示冗余引用文件会干扰对话可读性 |
| 对话轮次上限 | 20轮以内，按实测标定 | 本品类问题多围绕单台设备的单次校准或维修，过长轮次的上下文易偏离当前问题 |

## 容易做错的三处
- 现象：开启图片识别功能后，上传仪表读数照片或误差曲线截图，系统回复无法识别图片内容。原因：未在提示词中明确要求模型识别图片中的计量数值与标注，或未正确配置图片上传的节点参数。
- 现象：对话回复中自动附加引用的校准记录、误差曲线文件列表，无法隐藏。原因：未关闭对话回复的引用文件展示开关，或配置时误保留了引用展示的默认设置。
- 现象：多轮对话超过设定轮次后，系统截断早期的设备序列号与校准批次信息，导致后续问答无法关联正确的校准记录。原因：未正确设置最大上下文窗口或对话轮次上限，导致有效上下文被覆盖。

## 怎么确认配好了
- 上传单台设备的校准证书图片，触发对话，核对回复是否识别图片中的计量数值与溯源链信息。
- 发起包含设备序列号的多轮对话，核对后续回复是否始终关联该设备的校准记录。
- 发起包含引用文件的查询，核对回复是否未附加冗余的引用文件列表。
- 发起超过设定轮次的对话，核对系统是否保留有效上下文且未截断关键的设备标识信息。
