# 工业仪器仪表制造与校准的设备点检与维修问答：工作流编排

## 这个品类的数据长什么样
本品类的典型主体为流量、压力、温度、分析仪器制造商及计量实验室。日常产生的文档包含装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录，数据来源涵盖设计文件、标准器和环境监测数据、校准软件、实验室信息系统及客户量程要求。数据按每台设备、每次校准更新，文档包含校准值、误差值、溯源编号、环境温湿度等字段，单位对应测量参数的法定计量要求。

## 这些特征在「工作流编排」这一环带来什么约束
品类数据按单台设备单次校准更新的特性，要求工作流必须精准绑定单设备的专属校准记录，避免跨设备数据混淆。日常文档类型多样且关联紧密，工作流需支持同时关联装配调试单、校准规程等多类文档作为问答依据。最耗时的建立标准器连接、多点误差计算、审核溯源链环节，要求工作流设置前置校验节点，减少无效运行次数。本品类的校准记录等同关键交付物，出错将导致测量偏差传递、证书无效或计量审核不通过，因此工作流需配置失败回滚与全链路日志记录，确保异常可追溯。

## 配置怎么定
在配置工作流前，需确保使用FastGPT v4.17.0版本，以获得稳定的工作流编排功能。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工作流变量 | 绑定单台设备的校准记录ID、量程范围 | 匹配品类数据按每台每次校准更新的特性，精准关联单设备业务数据 |
| 触发节点条件 | 按`variables`中的校准完成状态触发 | 确保工作流仅在有效校准数据生成后启动，避免无效运行 |
| 文档关联规则 | 关联装配调试单、校准规程、计量证书三类文档 | 覆盖品类日常点检与维修所需的全部业务文档类型 |
| 超时设置 | 600秒 | 覆盖建立标准器连接、多点误差计算的典型耗时场景 |
| 失败处理策略 | 触发日志上报并回滚至前置校验节点 | 规避错误数据传递导致的计量审核不通过等严重后果 |
| 节点标识绑定 | 绑定`nodeId`为校准审核节点的唯一标识 | 确保工作流跳转时精准指向审核环节，避免路径错误 |

## 容易做错的三处
- 现象：创建工作流模板后进入编辑界面出现加载失败。原因：未正确绑定品类专属的校准文档数据源，导致系统无法加载对应元数据。
- 现象：本地部署后打开工作流报错，提示Cannot read properties of undefined (reading 'incl'。原因：`variables`配置中遗漏了仪器型号的必填字段，系统无法识别关联的校准记录。
- 现象：引用自定义插件后执行代码运行节点出现输入报错。原因：未按品类数据的字段格式配置插件入参，未匹配误差曲线、计量证书的字段结构。

## 怎么确认配好了
- 触发工作流后，检查是否仅在校准记录生成后启动运行。
- 查看工作流日志，确认所有关联的文档类型均被正确加载。
- 模拟异常场景，验证失败处理节点是否正常触发日志上报与回滚。
- 核对`nodeId`配置，确认审核环节的跳转路径与业务流程一致。
