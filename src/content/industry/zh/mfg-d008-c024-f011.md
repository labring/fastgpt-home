# 工艺变更与工程变更的设备点检与维修问答：表单与交互

## 这个品类的数据长什么样
该品类的数据由制造企业变更管理团队生成，涵盖ECN/ECR表单、变更评估报告、图纸与BOM版本记录、工艺验证报告、生产切换计划、库存处置单及客户批准文件。数据来源包括PLM、ERP、MES系统、供应商资料、验证试验结果与客户特殊要求，更新随每次变更不定期触发，核心数据需关联多系统的版本信息与审批状态。

## 这些特征在「表单与交互」这一环带来什么约束
该品类的数据特征对表单交互带来多重约束。跨多系统的数据来源要求表单支持关联调用外部文档与版本信息，避免手动输入错误。不定期的更新节奏需要表单动态加载最新的ECN/ECR、图纸版本等数据，防止使用过期版本。多角色参与的变更流程要求表单的`userSelect`组件支持按角色配置可见选项，同时校验必填的审批文件与切换点字段。此外，复杂的连锁影响识别需求，需要表单预设关联字段以简化信息录入。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` 最大字符数 | 800–1200 字符 | 适配ECN/ECR表单的变更描述、工艺调整说明等长文本录入需求 |
| `userSelect` 选项加载方式 | 按变更类型动态拉取 | 匹配不同工艺变更场景下的审批角色、关联文档类型差异 |
| 输入框上传按钮 | 启用 | 支持上传工艺验证报告、客户批准文件等附件 |
| 上下文窗口大小 | 1500–2000 token | 适配多系统关联数据的问答交互需求 |
| 动态选项更新间隔 | 按实测标定 | 适配PLM、ERP系统的版本更新节奏，避免加载过期数据 |

## 容易做错的三处
- 现象：对话交互中无法实时调用关联的PLM知识库文档，原因：未配置`userSelect`组件绑定外部知识库的动态拉取逻辑，仅使用固定预设的选项列表。
- 现象：聊天输入框未显示上传文件按钮，原因：未启用表单的附件上传配置，或错误限制了可上传文件的类型与大小阈值。
- 现象：用户选择模块的选项无法随变更类型动态调整，原因：未将`userSelect`组件与当前变更的工艺分类绑定，未触发对应场景的选项更新。

## 怎么确认配好了
- 发起一条工艺变更的测试问答，验证输入框可正常上传工艺验证报告类附件。
- 选择不同的变更类型，确认`userSelect`组件加载的审批角色、关联文档选项发生对应变化。
- 输入长文本的变更描述，验证`formInput`组件的字符限制符合预设的800–1200字符范围。
- 等待PLM系统更新某份图纸版本，确认表单加载的图纸版本为最新状态。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
