# 工装夹具与检具制造的设备点检与维修问答：向量模型与索引

## 这个品类的数据长什么样
该品类的数据主要来自汽车、航空、机械装配企业工装部门及专用工装供应商的业务产出，包含工装需求书、定位基准方案、夹具图、检具操作书、验收报告、校准记录、变更履历等文档。数据来源覆盖产品数模与GD&T、工艺路线、三坐标数据、现场试用反馈及计量系统，更新按项目推进，伴随每次产品变更触发，同时需配合定期校准动作完成更新，单份文档多包含几何参数、校准周期、变更节点等明确字段。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据混合了非结构化文本、结构化数值报告与工程图纸描述，不同文档的字段差异明显，对向量模型的适配性提出要求。按项目与变更驱动的更新节奏，要求索引支持增量更新以避免重复处理全量数据。三坐标数据、校准记录等包含高精度几何参数的内容，需要向量模型能准确捕捉数值关联关系，同时索引需支持按变更节点筛选召回范围，确保维修问答时调用的是最新有效数据。

## 配置怎么定
本配置方案适用于FastGPT v4.17.0版本，具体配置项如下：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 该品类文档包含工程图纸描述、数值校准记录与文本变更履历，该区间可平衡单块信息完整性与向量模型的计算负载 |
| 重叠长度 | 100–150 字符 | 定位基准方案、变更履历等文档存在连续关联内容，重叠设置可避免关键关联信息被截断 |
| 相似度阈值 | 0.75–0.85 | 需过滤低匹配度的过时校准记录与非目标工装方案，确保召回内容与当前点检维修需求的匹配度 |
| 重排开关 | 开启 | 设备点检与维修问答需优先匹配故障相关的校准、验收记录，重排可提升高相关内容的排序优先级 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| `defaultToken` | 按实测标定 | 适配该品类混合结构化与非结构化数据的向量模型输入要求，需结合实际召回效果调整 |

## 容易做错的三处
- 现象为开启Rerank模型后，在线召回测试返回的结果排序未发生变化，原因是未在知识库索引配置中同步开启重排关联的召回开关，或重排模型的调用密钥未正确绑定至对应服务。
- 现象为Embedding模型调用OneAPI时返回连接超时或403权限报错，原因是未针对该品类的结构化数值数据调整Embedding模型的输入格式，或OneAPI的接口配置未匹配所选Embedding模型的调用协议。
- 现象为索引召回结果中包含过期的校准记录或变更前的工装方案，原因是未配置按变更节点筛选的增量更新规则，全量索引未过滤已失效的历史数据。

## 怎么确认配好了
- 进入FastGPT的知识库管理页面，查看已完成的索引任务运行日志，确认分块长度、重叠长度与配置项中的设置一致。
- 发起典型设备点检问题的在线召回测试，核对召回结果的排序与匹配度，确认重排开关已生效。
- 检查向量模型的调用日志，确认`defaultToken`参数的实际取值与配置一致，无异常报错信息。
- 查看索引更新记录，确认仅在产品变更或定期校准节点触发增量更新，未重复处理全量历史数据。
