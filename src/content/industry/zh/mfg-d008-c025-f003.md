# 工装夹具与检具制造的设备点检与维修问答：多轮对话与提示词

## 这个品类的数据长什么样
本品类数据来源于产品数模与GD&T、工艺路线、三坐标测量数据、现场试用反馈及计量系统。日常文档包含工装需求书、定位基准方案、夹具图、检具操作书、验收报告、校准记录与变更履历。数据更新按项目节点、每次产品变更或定期校准执行，字段包含基准参数、公差值、校准日期、变更编号等，单位涉及毫米、微米、校准周期等。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
产品数模与GD&T包含高精度几何参数，多轮对话需保留基准关联信息，提示词需明确引用公差字段以避免装夹偏差。变更履历需关联对话上下文，防止遗漏版本差异导致的工装失效。三坐标数据与现场反馈需作为检索依据，要求对话能回溯不同阶段的点检记录。检具操作书的步骤需按顺序关联，多轮对话需支持分段验证操作逻辑，降低检具误判风险。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 最大上下文长度 | 8000–12000 token | 本品类文档包含夹具图、三坐标数据等长文本，需覆盖完整项目关联信息 |
| 单次召回条数 | 前6条 | 工装数据按项目分类，过多召回会引入无关变更记录，降低回答精准度 |
| `variables` | 绑定项目编号、校准日期变量 | 本品类数据需按项目和校准周期筛选，提升检索精准度 |
| `messages`上下文窗口 | 最近20轮对话 | 点检与维修需回溯前序操作记录，避免重复提问或遗漏关键信息 |
| 问题优化 | 按实测标定 | 不同项目的工装术语存在差异，需适配行业专属表述 |
| 重排排序 | 按文档关联度排序 | 本品类数据包含基准、公差等强关联字段，需优先召回匹配定位逻辑的内容 |

## 容易做错的三处
- 现象：调大上下文引用上限后，大模型输出未包含任何检索到的工装文档内容，仅返回通用回答。原因：未通过`variables`绑定项目编号、校准日期等筛选条件，召回的文档与当前对话的工装场景不匹配。
- 现象：检索返回的结果附带知识库段落的id字段，干扰专业术语的识别与回答准确性。原因：未配置`messages`过滤非业务字段，导致冗余的id信息被带入对话上下文。
- 现象：对话框无法显示检具校准相关的图片附件。原因：未开启多模态对话的图片解析配置，未关联图片与对应夹具图的基准信息。

## 怎么确认配好了
- 发起包含项目编号的点检提问，核对召回的文档是否仅包含该项目的工装数据。
- 查看大模型输出的上下文引用，确认未包含冗余的段落id字段。
- 上传检具校准图片，验证对话框是否能正常解析并关联对应夹具的基准信息。
- 发起多轮维修提问，核对上下文是否保留前序对话的关键参数，无需重复提问。
