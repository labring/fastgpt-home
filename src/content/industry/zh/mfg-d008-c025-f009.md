# 工装夹具与检具制造的设备点检与维修问答：模型接入与配置

## 这个品类的数据长什么样
本品类数据来自产品数模与GD&T、工艺路线、三坐标数据、现场试用反馈及计量系统，日常文档包含工装需求书、定位基准方案、夹具图、检具操作书、验收报告、校准记录与变更履历。数据更新按项目节点、每次产品变更及定期校准节奏执行，服务于汽车、航空、机械装配企业的工装部门与专用工装供应商。

## 这些特征在「模型接入与配置」这一环带来什么约束
本品类的专业文档包含GD&T参数、三坐标测量数值等结构化与非结构化内容，模型接入时需适配多类型数据的解析。按项目与变更的更新节奏，要求配置支持灵活触发知识库同步的逻辑。设备点检与维修问答需关联夹具图、校准记录等精准文档，模型上下文长度需覆盖单项目全量相关文档内容，避免关键信息截断。同时，计量系统的高精度数据要求模型输出需匹配专业术语与数值精度，避免出现偏差。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的逻辑制定，适配工装夹具与检具制造场景的专属需求。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 覆盖单项目工装文档、校准记录、变更履历的总长度，避免关键点检维修信息截断 |
| `maxTokens` | 2000–3000 token | 适配设备点检维修问答的详细回复需求，匹配专业文档的解析长度 |
| `quoteMaxToken` | 1500–2000 字符 | 限定引用的工装夹具文档片段长度，确保引用内容精准且不冗余 |
| `vision` | 开启 | 支持解析夹具图、检具操作书等图片类文档，匹配品类内图片类业务数据 |
| `temperature` | 0.1–0.3 | 降低随机性，保证点检维修问答的专业术语与数值精度一致性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配FastGPT的代理接入逻辑，确保模型调用链路稳定 |

## 容易做错的三处
- 现象：配置`vision`参数后仍无法解析夹具图JPG文件，返回空的图片解析结果。原因：未开启对应模型的视觉能力开关，或未上传符合格式的高清工装图纸文件。
- 现象：配置函数调用工具后，模型生成的调用参数与GD&T、三坐标数据不匹配，调用失败。原因：`temperature`参数设置过高，导致模型输出随机性超出专业场景要求，或未在上下文内注入品类专属的GD&T字段说明。
- 现象：尝试接入第三方大模型时，接口调用返回权限报错。原因：未正确填写`AIPROXY_API_TOKEN`参数，或代理端点配置未适配专属接入路径。

## 怎么确认配好了
- 上传单份工装夹具JPG图纸，发起包含图纸细节的提问，核对模型是否能正确解析图纸中的定位基准信息。
- 输入包含GD&T参数的点检问题，核对模型生成的工具调用参数是否匹配品类文档的字段格式。
- 触发知识库更新操作，核对最新的校准记录、变更履历是否能被模型召回用于问答。
- 发起多次模型调用，核对接口返回无权限、超时等异常状态。
