# 模具设计制造的设备点检与维修问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据主要来自客户产品模型、模流或成形仿真、CAD/CAM软件、机加工与测量数据、试模样件。日常文档包含模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历。数据按单个项目更新，每次试模或改模后同步更新。数据字段包含模具编号、型腔数量、材料牌号、加工精度要求等，单位多为毫米、兆帕等工业常用标准单位。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的数据分散在CAD/CAM、试模系统、客户产品管理系统等多个工具中，HTTP接口需要支持跨系统数据拉取，适配不同格式的文档字段。数据按单个项目按需更新，接口需支持携带项目专属参数触发数据同步，避免无效请求。模具数据关联量产节点，接口需配置超时与失败重试机制，防止请求中断影响后续改模流程。接口需通过`Authorization`请求头完成身份校验，确保仅授权人员可访问模具设计与维修相关数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ------ | -------- | ----------- |
| `Authorization` | `Bearer {项目专属token}` 格式 | 符合工业系统通用的API身份校验规范，适配模具数据的保密要求 |
| `variables` | 传递模具编号、试模批次、项目ID | 该品类数据按单个项目更新，需精准匹配对应项目的文档与数据 |
| `responseData` | 提取点检记录、维修日志、模具履历字段 | 该品类的核心接口需求为获取结构化的设备状态与维修信息 |
| 超时设置 | `30–60 秒` | 模具数据关联量产节点，需平衡请求稳定性与业务响应效率 |
| 重试次数 | `2–3 次` | 避免单次网络波动导致的接口调用失败，保障数据同步连续性 |
| 历史上下文携带 | 前`3 条`设备点检记录 | 维修问答需参考近期设备状态，提升回答准确性 |

## 容易做错的三处
- 现象：对话请求接口返回结果中无cite引用id字段。原因：未在接口配置中关联模具设计制造场景的专属知识库文档ID，导致无法生成对应引用标识。
- 现象：接口调用返回401未授权错误。原因：`Authorization`参数未使用`Bearer`前缀格式，或token过期未及时更新。
- 现象：接口拉取的数据与当前项目不匹配。原因：`variables`参数未传递模具编号或项目ID，导致系统返回错误的模具点检与维修数据。

## 怎么确认配好了
使用FastGPT v4.17.0版本进行以下核对：
- 调用接口后检查`responseData`中是否包含模具点检、维修相关的结构化字段，字段匹配度按项目需求标定。
- 验证`Authorization`参数格式正确，调用后返回200状态码，无未授权报错。
- 传入指定项目的`variables`参数，确认返回的数据与该项目的模具文档一致。
- 模拟网络波动，检查接口是否触发重试机制，未出现连续调用失败。
