# 模具设计制造的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
通常这类主体的日常文档包含模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历；数据来自客户产品模型、模流或成形仿真、CAD/CAM、机加工与测量数据、试模样件；更新按项目推进，每次试模或改模后同步更新。文档包含结构化字段与非结构化文本，部分文件带有尺寸、工时等量化参数。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的文档包含结构化工艺卡、非结构化试模报告与CAD图纸，且按项目按需更新。混合格式的数据要求检索需适配不同类型文档的召回逻辑，避免图纸类文本被过度截断。按项目更新的特性要求检索环节支持增量同步，无需每次全量重建知识库。此外，业务核心环节依赖试模缺陷、改模记录等时序数据，检索需优先召回关联度高的项目级文档片段。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 适配模具类文档的结构化与非结构化混合特征，平衡召回精度与覆盖范围 |
| `limit` | 前8条 | 匹配单项目下的文档体量，避免上下文过载影响检索准确性 |
| `searchMode` | `mixedRecall` | 结合关键词与语义检索，适配零件图、工艺卡等不同格式的文档 |
| `usingReRank` | 开启 | 对召回结果重排，优先返回与试模缺陷、改模需求相关的高关联片段 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于原问题扩展检索词，覆盖模具设计术语、试模缺陷的同义表述 |
| `collectionIds` | 按项目绑定的集合ID | 隔离不同项目的模具文档，避免跨项目召回干扰 |

## 容易做错的三处
- 现象：上传知识库文件时出现格式报错。原因：未区分结构化工艺卡、非结构化试模报告与CAD图纸的上传规则，混合上传未做格式适配。
- 现象：使用`[{datasetId: xxx}]`格式的变量引用无法生效。原因：未遵循FastGPT v4.17.0的变量引用规范，或未在调用链路中绑定对应数据集的访问权限。
- 现象：知识库上传后持续显示索引中状态。原因：单批次上传的模具文档总量过大，未按项目拆分上传，导致索引进程超时。

## 怎么确认配好了
- 上传单份模具设计任务书与试模报告，检查索引进度是否在合理时间内完成。
- 输入“试模时出现缩水缺陷如何处理”的问题，验证检索结果是否召回对应试模报告与改模通知的相关片段。
- 配置变量引用后发起调用，检查返回结果是否包含绑定数据集内的文档内容。
- 上传模具零件图至知识库，发起关联问题检索，确认结果中可显示对应图片。
