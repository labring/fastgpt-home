# 模具设计制造的设备点检与维修问答：表单与交互

## 这个品类的数据长什么样
该品类的核心数据来自客户产品模型、模流或成形仿真文件、CAD/CAM图纸、机加工与测量记录、试模样件数据。日常文档包含模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历。数据更新按项目节点触发，每次试模或改模后同步更新，核心字段包含模具编号、型腔数量、材料牌号、缺陷类型、设备型号等，无固定统一格式模板，随项目需求动态调整。本页面基于FastGPT v4.17.0版本进行配置说明。

## 这些特征在「表单与交互」这一环带来什么约束
由于数据按项目动态更新且格式不固定，表单需支持关联多版本的项目文档，避免使用固化的字段结构。由于核心数据包含CAD、仿真等大体积文件，表单需适配多格式附件上传，且限制单文件与总上传大小。由于该品类业务环节涉及设计、制造、试模多角色协作，表单需区分不同角色的可见与可编辑字段，仅允许对应权限的人员修改特定内容。由于出错后果直接影响量产节点，表单需添加必填字段校验与异常输入提示，减少无效问答请求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | `{模具编号: "", 缺陷类型: "", 设备型号: ""}` | 匹配模具品类的核心业务字段，减少用户重复输入成本 |
| `userSelect` | `["注塑模具", "冲压模具", "压铸模具"]` | 覆盖该品类常见的模具类型，缩小问答的业务范围，提升回复精度 |
| 附件上传限制 | 单次最多5个，单文件最大200 MB | 匹配CAD/模流仿真文件的常规存储大小，避免占用过多存储空间 |
| 上下文召回条数 | 前3条 | 该品类单项目关联文档量适中，过多召回内容会干扰模型对核心问题的判断 |
| 超时阈值 | 600秒 | 复杂模具数据解析与维修方案生成需要较长处理时间，避免提前触发超时报错 |
| 自定义提示词 | 按实测标定 | 需结合企业内部模具维修文档与业务流程调整，适配特定场景的问答逻辑 |

## 容易做错的三处
- 现象：调用指定模型时触发400报错，仅在输入特定短句时出现。原因：`formInput`字段未配置输入长度限制，或未过滤非法字符，触发FastGPT v4.17.0的模型接口参数校验失败。
- 现象：语音输入功能无法正常触发，或识别结果与用户输入偏差较大。原因：未将语音识别模型与FastGPT的`userSelect`输入字段正确绑定，未配置语音输入的触发权限。
- 现象：无法区分用户输入是否包含图片，统一调用基础问答模型。原因：未在`formInput`中添加多模态输入的校验规则，未配置图片识别的前置判断逻辑。

## 怎么确认配好了
- 输入预设的模具编号与缺陷类型，检查`formInput`字段是否自动填充对应项目的关联文档链接。
- 点击`userSelect`下拉框，确认包含注塑模具、冲压模具、压铸模具三个预设选项。
- 上传大小为150 MB的CAD格式文件，检查是否允许上传且无报错提示。
- 分别输入带图片和不带图片的维修问题，确认不带图片时直接调用目标模型，带图片时触发多模态处理流程。
