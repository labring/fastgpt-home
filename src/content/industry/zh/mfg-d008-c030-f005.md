# 橡胶混炼与制品硫化的设备点检与维修问答：工具调用与插件

## 这个品类的数据长什么样
本品类的数据主要来自配方系统、原材料批次记录、密炼机、门尼粘度仪、流变仪、硫化机及实验室检测设备。日常生成的文档包含配方单、称量记录、混炼曲线、胶料快检报告、硫化工艺卡、模具使用记录、成品性能报告。数据更新频率为每车胶料、每批原材料、每模次制品各生成一次，字段包含胶料批次号、混炼温度、硫化时间、模具编号、成品性能参数等，单位涵盖摄氏度、秒、批次标识等。

## 这些特征在「工具调用与插件」这一环带来什么约束
本品类的数据更新频率高、来源分散且格式多样，要求工具调用需支持实时拉取最新的混炼、硫化参数，避免使用过期的历史数据。多类型的业务文档需要插件适配不同的数据解析逻辑，例如从表格格式的配方单提取投料参数，从时序格式的混炼曲线读取温度变化。工业设备数据源的API接口通常有严格的访问权限与响应延迟限制，需配置适配工业场景的请求超时与重试规则。此外，设备点检与维修的出错后果直接关联制品报废或早期失效，工具调用的失败处理需具备快速告警与流程回滚能力。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，通过配置`toolChoice`自动选择工具、启用`functionCall`实现第三方接口调用，具体参数如下：
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工作流/API 工具选择配置 | `auto` | 适配不同点检场景自动选择对应工具，无需手动切换 |
| 工作流/API 函数调用配置 | 启用 | 支持调用工业设备API、配方系统接口获取实时业务数据 |
| 全局变量初始值 | 按业务文档预设字段填充 | 匹配配方单、称量记录的固定字段格式，避免参数不匹配 |
| HTTP请求超时时间 | 30–60 秒 | 适配工业设备API的常规响应延迟区间 |
| 工具调用重试次数 | 2 次 | 应对工业网络波动导致的临时请求失败 |
| 工具调用返回数据上限 | 前10条 | 适配单批次胶料的点检数据量，避免返回冗余信息 |
| 最大上下文长度 | 8000–12000 token | 适配混炼曲线、硫化工艺卡等多文档的内容长度 |
| Cookie持久化配置 | 启用 | 适配需要身份验证的设备API接口，正确捕获Set-Cookie字段 |

## 容易做错的三处
- 现象：全局变量设置初始值后，工具调用时对应字段为空。原因：未在工作流启动节点配置变量初始化步骤，或初始值未匹配业务文档的字段命名规则。
- 现象：发起点检提问后，工作流直接进入工具调用步骤并返回报错。原因：未配置前置参数校验逻辑，请求携带了无效的胶料批次号或设备ID。
- 现象：HTTP请求模块无法解析响应中的Set-Cookie字段，代码执行模块调用API失败。原因：未启用HTTP请求的Cookie持久化配置，或代码执行模块未正确封装API身份验证参数。

## 怎么确认配好了
- 触发工作流，检查全局变量是否正确加载了预设的胶料批次号、硫化工艺参数等字段值。
- 发起模拟点检请求，确认工具调用能正确返回密炼机的混炼曲线或硫化机的实时运行数据。
- 模拟网络波动场景，触发工具调用失败，确认流程自动执行预设的重试机制。
- 查看HTTP请求响应日志，确认Set-Cookie字段被正确捕获并用于后续接口的身份验证。
