# 橡胶混炼与制品硫化的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
该品类数据主要来自轮胎、密封件、胶管等橡胶制品企业的配方系统、原材料批次台账、密炼机、门尼黏度仪、硫化机及实验室检测设备。日常文档包含配方单、称量投料记录、混炼工艺曲线、胶料快检报告、硫化工艺卡、模具使用记录、成品性能检测报告。数据更新频率为每车原材料批次、每批混炼胶料、每模次硫化制品对应更新一次，单份文档包含设备编号、批次号、工艺参数、检测数值等字段，无统一标准化格式。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的高频更新、多类型文档及强关联标识特征，对知识库检索召回带来多重约束。高频的批次级更新要求检索链路支持快速增量同步，避免召回过时的工艺参数。多类型文档包含结构化参数、工艺曲线与检测报告，需兼顾关键词匹配与语义召回的适配性。单份文档绑定设备编号、批次号等唯一标识，检索需支持按设备或批次维度过滤。同时，工艺参数错误会引发批量报废，需严格控制召回结果的相关性，避免匹配到不匹配当前工况的混炼或硫化数据。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，适配橡胶混炼与制品硫化的设备点检与维修问答场景：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配橡胶工艺参数的精准度要求，避免召回不相关的混炼或硫化数据 |
| `limit` | 前3–5条 | 控制单轮检索返回的结果数量，适配设备点检场景下的快速查阅需求 |
| `usingReRank` | 开启 | 对初始召回结果进行重排序，提升结构化工艺参数的匹配精度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 对用户问题进行语义扩展，覆盖设备点检中常见的模糊表述 |
| `searchMode` | `mixedRecall` | 兼顾工艺参数的精准匹配与自然语言点检问题的理解 |
| `collectionIds` | 按设备分组绑定对应知识库 | 精准匹配当前点检设备对应的混炼、硫化工艺文档，缩小检索范围 |

## 容易做错的三处
- 现象：检索结果被自动归类到兜底分类，未匹配到对应设备的工艺文档。原因：未按`collectionIds`绑定对应设备的专属知识库，仅基于当前问题文本进行分类，未关联设备编号、批次号等上下文信息。
- 现象：检索结果显示无匹配内容，但知识库中已存储对应设备的点检相关文档。原因：`similarity`阈值设置过高，或未开启`datasetSearchUsingExtensionQuery`，无法覆盖用户的模糊点检表述。
- 现象：docx格式的称量记录、硫化工艺卡检索结果与当前工况不匹配，准确率较低。原因：未开启`usingReRank`功能，初始召回的结果未按语义相关性排序，结构化的工艺参数未被优先匹配。

## 怎么确认配好了
- 输入当前点检设备的典型问题，核对检索结果是否仅返回该设备绑定知识库中的文档。
- 调整`similarity`阈值，验证不同阈值下召回结果的数量变化是否符合场景需求。
- 开启`usingReRank`后，对比重排前后的结果排序，确认结构化工艺参数的匹配优先级提升。
- 输入模糊表述的点检问题，验证`datasetSearchUsingExtensionQuery`是否能扩展语义并召回相关文档。
