# 水泥熟料与粉磨的设备点检与维修问答：表单与交互

## 这个品类的数据长什么样
该品类数据来自在线成分分析、DCS系统、化验室、窑磨设备、原燃料台账与能源计量装置。数据更新节奏分为实时、每班、每日三类。日常文档包含生料配料方案、窑操作记录、化验报告、质量控制通知单、设备巡检记录与能源报表。数据字段涵盖原燃料成分、窑炉热工参数、熟料矿物组成、水泥强度指标等，需匹配工业现场的标准化计量格式。

## 这些特征在「表单与交互」这一环带来什么约束
数据来源分散且更新节奏差异大，要求表单需支持多数据源的字段联动录入，避免重复填写不同时段的巡检与化验数据。文档类型多样，表单需适配不同文档的字段结构，例如生料配料方案的参数与设备巡检记录的字段需分别配置。工业现场的计量单位需严格匹配，表单需内置标准化单位选项，防止录入错误。实时数据的录入需支持快速提交，避免延迟导致的参数偏差，每班与每日的汇总数据则需支持批量导入与校验。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `formInput` | 配置原燃料成分、窑炉热工参数等字段，绑定计量单位 | 匹配品类日常文档的标准化字段与单位 |
| `formInput` | 配置批量巡检记录的导入字段 | 适配每班汇总的数据规模 |
| `userSelect` | 预设回转窑结皮、磨辊磨损等维修点检选项 | 适配该品类高频维修场景 |
| `userSelect` | 预设数据更新频率选项，如实时、每班、每日 | 匹配数据的更新节奏 |
| 批量提交上限 | 50条/次 | 匹配每班巡检记录的汇总规模，避免数据处理过载 |
| 输入引导词库 | 导入生料配料方案、化验报告的专业术语 | 匹配品类专属的业务文档内容 |
| 上下文窗口 | 8000–12000 token | 适配多份巡检、化验与能源报表的内容长度 |

本配置基于FastGPT v4.17.0版本。

## 容易做错的三处
- 配置输入引导与专业词库后，对话界面未显示预设的点检与维修问题。未将水泥熟料与粉磨品类的生料配料、窑操作术语导入词库，或引导词未绑定该品类的业务场景。
- 免登录页面的语音输入出现发送不显示或长按时长停留在00:00的情况。未适配工业现场的网络延迟场景，或输入组件的超时阈值未匹配现场的网络环境。
- 批量提交巡检记录时，超过设定上限后未触发提示，导致部分数据未被保存。未配置`formInput`的批量提交校验规则，或上限取值未匹配每班巡检记录的汇总规模。

## 怎么确认配好了
- 打开表单配置页面，核对录入字段是否包含生料配料、窑炉巡检、化验结果等品类专属字段。
- 模拟提交批量巡检数据，检查是否触发符合现场规模的提交上限提示。
- 启用输入引导功能，验证对话界面是否显示回转窑结皮、磨辊磨损等品类高频问题选项。
- 测试语音输入功能，确认在模拟工业现场网络延迟的场景下，输入内容可正常显示与提交。
