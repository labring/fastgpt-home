# 烘焙与方便食品的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
该品类主体为面包糕点、饼干、方便面与速冻面点工厂，日常运维与生产文档包含配方与投料单、生产记录、烘烤或蒸煮曲线、金属检测记录、清洁消毒记录、出厂检验报告。数据来源覆盖原辅料合格证明、ERP/MES系统、称量系统、烤炉或油炸线设备、实验室检测结果与食品追溯台账。数据更新频率按生产批次、班组班次与自然日循环，核心耗时环节集中于配方与过敏原物料复核、醒发/烘烤/油炸窗口控制、异物与包装保质期核对。

## 这些特征在「知识库检索与召回」这一环带来什么约束
配方数量多且产线换型频繁，要求检索召回能够快速匹配最新的单批次生产参数与清洁记录，避免过期或不匹配的文档被召回。过敏原与清洁切换的高优先级需求，要求检索结果能够精准区分不同产线的专属文档，减少跨产线信息干扰。多来源的混合数据（结构化参数与非结构化文本），要求检索模式兼顾语义理解与关键词匹配，覆盖曲线数值、投料清单等不同格式的内容。高频更新的特性要求知识库索引能够快速同步每班每批的最新数据，避免检索结果滞后于实际生产状态。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.72–0.78 | 匹配过敏原标识、设备参数等高精度需求场景，按实测标定 |
| `limit` | 前8条 | 覆盖多批次生产记录、多产线清洁记录的检索需求，避免遗漏关键信息 |
| `searchMode` | `mixedRecall` | 适配配方文本、烘烤曲线数值的混合检索场景 |
| `usingReRank` | 开启 | 对检索结果重新排序，优化过敏原物料、异物控制记录的召回优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 扩展问题边界，匹配生产记录中的醒发窗口、投料参数等内容 |
| `collectionIds` | 按产线分组配置 | 区分不同烘焙、油炸产线的知识库集合，精准召回对应产线的点检维修文档 |

## 容易做错的三处
- 现象：知识库导出文件仅几百KB，内容不全面。原因：未选择全量数据集导出，仅导出了部分分组集合的文档。
- 现象：检索结果中无法显示本地图片链接的文档内容。原因：未将本地图片上传至可公开访问的在线图床并替换原链接，知识库仅支持在线可加载的图片资源。
- 现象：检索精度不足，过敏原物料匹配出现错误。原因：`similarity`阈值设置过低，导致低相关结果被召回，或未按产线分组配置`collectionIds`导致跨产线文档干扰。

## 怎么确认配好了
- 上传一份测试用的烘烤曲线文档，发起包含“烘烤温度”的检索，确认结果包含该文档的关键参数。
- 触发全量知识库重新训练，等待训练完成后查看数据集状态，确认所有文档均被成功索引。
- 发起包含已知过敏原物料名称的检索，检查结果的排序是否符合业务优先级。
- 导出指定分组的数据集，核对导出文件的内容与原始文档数量，确认导出范围符合预期。
