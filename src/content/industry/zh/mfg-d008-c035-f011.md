# 热处理的设备点检与维修问答：表单与交互

## 这个品类的数据长什么样
本品类数据来自材料牌号手册、客户技术条件、温控仪表、炉温均匀性测试设备、硬度计与金相检测设备、车间MES系统。数据更新随每炉次、每批生产节奏完成。日常文档包含热处理工艺卡、装炉图、炉温曲线（单位为℃）、硬度与金相报告、设备点检表、异常处置单。文档字段包含加热温度、保温时长、装炉工位编号、检测硬度值（HV或HRC）、炉温偏差值等，结构随生产批次动态调整。

## 这些特征在「表单与交互」这一环带来什么约束
本品类的数据更新随每炉次、每批生产节奏动态完成，要求表单支持单次单批次的参数录入，不宜复用固定不变的通用模板。日常文档类型多样且字段差异明显，表单需要支持多类型字段组合，包含数值型、枚举型、关联型等字段。数据来源包含设备自动采集与人工检测两类，表单需要区分自动同步字段与人工填报字段，避免数据冲突。异常处置环节需关联点检记录与工艺数据，表单需支持快速关联已有知识库条目，减少重复录入。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `formInput` | 按炉次批次创建字段组，包含加热段温度、保温时长、装炉工位等子字段 | 本品类数据按每炉次更新，分组后便于单批次参数的集中录入与校验 |
| `userSelect` | 预设12种异常类型选项，包含炉温偏差、装炉错位、硬度不合格等 | 日常异常处置单的异常类型固定，预设选项可减少人工输入误差 |
| 分块长度 | 800–1200字符 | 热处理工艺卡、炉温曲线的单段有效内容长度符合该区间，避免分块丢失关键上下文 |
| 单次搜索上限 | 前6条 | 本品类知识库条目按批次分类，前6条可覆盖单炉次关联的工艺、检测与点检数据 |
| 表单必填校验 | 开启温度范围（室温至1200℃）、时长区间（10–120分钟）校验 | 热处理参数存在固定合规区间，校验可提前规避无效录入 |

## 容易做错的三处
- 现象：配置自定义表单字段后调用问答接口返回字段为空。原因：未按炉次批次配置`formInput`的字段组，系统无法识别单批次参数的关联关系。
- 现象：导入多列Excel格式的设备点检表后，自动分段结果混乱，字段关联断裂。原因：未指定按单条点检记录作为分段单元，系统默认按段落拆分导致数据碎片化。
- 现象：开启`userSelect`预设异常选项后，部分现场异常无法被正确匹配。原因：预设选项未覆盖淬火冷却速率异常、炉体密封失效等常见场景，导致问答召回结果不符合需求。

## 怎么确认配好了
- 录入单炉次的完整参数，检查表单字段是否按批次分组展示，无遗漏的必填项。
- 导入单份热处理工艺卡，查看自动分块后的内容是否保留完整的加热、保温、冷却参数段。
- 提交异常报修请求，检查`userSelect`的预设选项是否包含现场常见的异常类型，可正常选中提交。
- 发起设备点检相关的问答，检查召回的知识库条目是否优先关联当前录入的炉次参数。
