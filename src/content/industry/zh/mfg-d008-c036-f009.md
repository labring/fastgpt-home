# 焊接结构件制造的设备点检与维修问答：模型接入与配置

## 这个品类的数据长什么样
焊接结构件制造品类的数据主要来自设计图纸、材料质保书、焊接设备参数、焊材库、无损检测系统及人员资质台账。日常留存的文档包含焊接工艺评定、焊接工艺规程、焊材领用记录、焊工资格记录、焊缝检验报告、返修单等。数据更新节奏为每条焊缝、每批物料或每班作业完成后更新，文档字段随单条业务记录匹配实际参数，无统一固定单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据分散于多个业务系统，需配置多源数据接入适配不同接口格式，确保从焊材库、无损检测系统等渠道同步完整业务数据。高频更新节奏要求配置项适配实时或近实时的上下文同步，避免因上下文滞后影响点检结果的准确性。多类型文档与非统一字段结构，需限制单条引用内容的token占用，同时需配置工具调用规则，确保模型输出符合焊工资质、工艺评定的刚性约束。FastGPT v4.17.0版本的配置逻辑可适配该场景下的多源数据与高频更新需求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `AIPROXY_API_ENDPOINT` | 填写企业内部模型网关或合规第三方模型接口地址 | 适配焊接结构件制造场景下的私有模型或合规调用需求 |
| `AIPROXY_API_TOKEN` | 填写对应接口的有效认证令牌 | 确保模型调用的身份校验符合企业合规要求 |
| `maxContext` | 8000–12000 token | 适配高频更新的焊缝、焊材等业务上下文，避免上下文溢出 |
| `quoteMaxToken` | 1500–2000 token | 限制单条引用文档的token占用，适配多类型业务文档的长度差异 |
| `toolChoice` | 设为强制调用合规校验工具 | 确保模型调用焊工资质核验、工艺评定匹配等工具，符合品类刚性约束 |
| `temperature` | 0.2–0.4 | 降低输出随机性，确保点检与维修建议的一致性与合规性 |

## 容易做错的三处
- 现象：接入钉钉渠道时提示「消息接收地址校验失败」，日志显示公网访问超时或SSL证书校验不通过。原因：未配置公网可访问的FastGPT服务地址，或未按提示调整SSL证书校验设置。
- 现象：配置DeepSeek R1模型时，思维链开关无法在Web渠道启用。原因：当前FastGPT版本中Web渠道暂不支持思维链功能的独立配置，需通过API渠道启用该功能。
- 现象：本地部署后索引模型下拉框无法选择非默认列表的模型提供商。原因：未在系统配置文件中添加对应模型提供商的接口配置，导致下拉选项未加载。

## 怎么确认配好了
- 调用模型接口，检查返回结果中是否包含焊接工艺、焊工资质的合规校验内容，核对`toolChoice`的配置是否生效。
- 上传单条焊缝检验报告，查看上下文引用的token占用是否符合配置的`quoteMaxToken`范围，调整取值至合理区间。
- 测试公网地址的可访问性，确认钉钉等渠道的消息接收地址校验通过，验证`AIPROXY_API_ENDPOINT`的配置正确性。
- 查看系统日志，确认模型调用的认证令牌`AIPROXY_API_TOKEN`未过期，接口调用无报错。
