# 生物制品与无菌生产的设备点检与维修问答：文档解析与分块

## 这个品类的数据长什么样
该品类数据主体来自疫苗、抗体、血液制品及无菌注射剂生产企业，日常文档包含细胞库或种子批记录、培养纯化记录、无菌灌装记录、环境监测数据、培养基模拟灌装结果、无菌检验报告及批放行资料。数据来源覆盖细胞库与种子批系统、过程分析平台、洁净区监测系统、MES、LIMS及设备完整性测试工具，更新节奏涵盖每批生产同步更新、实时监测数据推送及按月度/季度监测计划更新。文档字段包含批次号、设备运行时长、洁净区沉降菌数值、培养基批号等，部分文档内嵌设备铭牌、培养皿照片等非文本内容。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的文档类型多样且包含非文本内容，需同时处理结构化批记录与非结构化监测照片，因此解析环节需兼顾文本提取与内嵌图片的完整传递。实时更新的监测数据要求解析流程具备低延迟特性，避免数据滞后影响点检与维修响应。不同生产批次的文档需严格按批次边界拆分，防止跨批次内容混淆引发的合规风险。此外，文档字段包含专业生产参数，分块时需保留参数与对应设备、批次的关联，避免拆分后丢失关键上下文。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的规则制定：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 匹配生物制品批记录的单段专业内容长度，避免拆分关键参数与设备关联信息 |
| `chunkSplitter` | 按标题+段落拆分 | 保留文档层级结构，区分不同设备、不同生产批次的点检与维修记录 |
| `customPdfParse` | 启用内嵌图片提取 | 适配包含培养皿照片、设备铭牌、洁净区监测图像的PDF文档，确保图片可被大模型读取 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 应对长批次记录、月度汇总监测报告的解析耗时，避免大型文档解析中断 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 支持批量上传月度环境监测汇总文件、多批次批记录合集 |
| `chunkSettingMode` | 手动配置 | 针对不同文档类型（如批记录、实时监测数据）调整分块规则，适配业务场景 |

## 容易做错的三处
- 现象：解析PDF文档后内嵌图片无法被大模型读取或丢失。原因：未启用`customPdfParse`配置，未开启内嵌图片提取功能。
- 现象：上传语雀公开分享链接后提示解析失败。原因：链接未设置为公开可访问权限，或链接指向需登录的私有页面，不符合数据源要求。
- 现象：长批次生产记录解析超时或被截断。原因：未调整`PARSE_FILE_TIMEOUT_SECONDS`至适配长文档的取值，导致解析任务提前终止。

## 怎么确认配好了
- 上传一份包含内嵌培养皿照片的无菌灌装记录PDF，检查解析结果中是否包含图片的关联描述或可访问的图片资源。
- 上传一条公开可访问的语雀设备点检知识库链接，确认解析任务无报错并生成完整的知识库条目。
- 上传一份100页的月度环境监测汇总文件，检查解析耗时未超过设定的`PARSE_FILE_TIMEOUT_SECONDS`阈值。
- 拆分一段包含设备运行参数与点检记录的长文本，确认分块结果保留了参数与对应设备编号的关联关系。
