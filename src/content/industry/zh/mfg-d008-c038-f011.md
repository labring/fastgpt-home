# 生物制品与无菌生产的设备点检与维修问答：表单与交互

## 这个品类的数据长什么样
这个品类的典型主体为疫苗、抗体、血液制品和无菌注射剂企业，日常文档包含细胞库或种子批记录、培养纯化记录、无菌灌装记录、环境监测数据、培养基模拟灌装结果、无菌检验报告、批放行资料。数据来源覆盖细胞库与种子批、过程分析系统、洁净区监测设备、MES、LIMS、设备完整性测试工具。数据更新节奏包含每批生产同步、实时监测推送、按固定监测计划更新，字段包含灭菌温度（℃）、设备运行时长（分钟）、洁净区沉降菌菌落数（cfu/皿）等，随生产环节动态调整。

## 这些特征在「表单与交互」这一环带来什么约束
品类数据来源分散且格式不统一，要求表单与交互支持多数据源关联调取，避免重复录入。数据更新节奏包含实时与批量两种，交互流程需支持按需刷新实时数据、按生产批次批量提交记录。日常文档结构复杂、字段较多，需支持条件跳转与层级化选择，匹配设备点检与维修的问题树逻辑。无菌生产的合规性要求与严重出错后果，要求表单必须包含严格的必填校验与操作留痕，防止关键参数遗漏。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 用户选择组件 | 按设备类型、点检项层级配置嵌套`userSelect`组件，支持级联联动 | 品类数据存在明确的层级结构，匹配设备点检的问题树逻辑 |
| 表单条件跳转规则 | 按点检项的风险等级配置显示逻辑，高风险项强制前置 | 无菌生产中高风险参数需优先确认，降低出错概率 |
| 文件上传格式配置 | 允许上传PDF、CSV、TXT、XLSX格式，默认全选可调整 | 覆盖日常文档的全部格式类型，适配MCP服务对接需求 |
| 表单必填项校验 | 对灭菌温度、洁净区菌落数等关键字段设置校验 | 避免关键参数遗漏引发严重生产风险 |
| 上下文保留时长 | 1200秒 | 适配单批生产的完整周期，保证交互过程的上下文连贯性 |
| 操作日志记录 | 开启全流程操作留痕 | 满足合规性要求，便于追溯点检与维修过程 |

## 容易做错的三处
- 现象：多层`userSelect`组件无法联动下级选项，下级选项始终为空。原因：未配置`userSelect`的级联触发规则，未绑定上级选择的参数值到下级组件。
- 现象：文件上传仅支持少量格式，无法对接MCP服务。原因：未将文件上传格式配置为全量可选，未同步更新MCP支持的格式映射。
- 现象：调用外部模型时报空错误，或代码运行节点无法选择知识库引用。原因：未在表单中配置对应参数的`formInput`绑定，或未正确关联系统变量与知识库ID。

## 怎么确认配好了
- 触发多层`userSelect`组件，验证下级选项随上级选择的内容联动更新。
- 上传不同格式的文件，验证符合配置的格式要求，且可正常提交。
- 清空表单中的关键字段，验证触发必填校验提示，阻止表单提交。
- 调用外部模型或代码节点，验证参数已正确传递到对应环节。
