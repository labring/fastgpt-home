# 电机与发电机制造的设备点检与维修问答：模型接入与配置

## 这个品类的数据长什么样
该品类数据来自电机厂、电力装备企业的绕线、绝缘、总装与试验部门，涵盖绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试记录、型式与出厂试验报告等文档。数据来源于电磁设计数据、铜线和绝缘材料批次信息、绕线设备、平衡机、电气试验台及ERP/MES系统，更新频率为每台产品、每批次生产或每次型式变更时更新。核心字段包含绕组匝数、接线方式、浸漆烘干参数、振动与温升测试值、效率及耐压试验结果等，伴随生产全流程同步产生。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类数据的高频更新特性要求模型接入配置适配实时或近实时的数据同步，避免检索到过期的绕组、绝缘或试验数据。多类型文档并存的特征，要求配置中适配不同文档的结构解析规则，确保绕组匝数、耐压值等核心字段被准确提取。同时，数据涉及电磁、绝缘、机械平衡等跨领域专业内容，需选用适配工业技术文本的嵌入模型，保障语义检索的准确性。此外，设备点检与维修问答的出错后果直接关联整机质量，配置需强化检索结果的溯源能力，关联原始生产与测试数据。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配电机制造文档的长文本长度，涵盖绕组工艺、试验报告等多份关联文档的上下文 |
| `maxTokens` | 4000 token | 控制单轮问答的输出长度，避免超出维修指导类内容的合理篇幅，适配设备点检的快速响应需求 |
| `quoteMaxToken` | 2000 字符 | 限定检索引用的原始文档片段长度，确保核心的绕组匝数、耐压数据等关键信息被完整提取且不冗余 |
| `temperature` | 0.3–0.5 | 降低输出的随机性，保障维修指导内容的准确性，符合工业场景对严谨性的要求 |
| `AIPROXY_API_ENDPOINT` | 按部署实例填写专属接口地址 | 适配企业内部的模型代理部署，确保数据传输的安全性与可控性 |
| 工作流/API 工具选择配置 | auto | 自动触发工具调用，用于调取绕组参数查询、试验数据比对等专用功能，适配点检维修的多步骤需求 |

## 容易做错的三处
- 现象：在渠道管理中添加指定模型后，创建知识库或应用时无法选择该模型。原因：未正确配置`AIPROXY_API_TOKEN`的权限范围，导致代理接口未返回对应模型的列表信息。
- 现象：离线接入重排模型时，系统返回`rerank error`报错。原因：未匹配重排模型与嵌入模型的向量维度，或模型文件存放路径包含非ASCII字符，导致加载失败。
- 现象：上传电机绕组或振动图像用于视觉点检时，图片上传成功但提交按钮无法触发。原因：`vision`配置项未启用，或前端上传组件的回调逻辑未正确绑定模型调用接口，导致状态未更新。

## 怎么确认配好了
- 执行模型连通性测试，检查接口返回的模型列表是否包含已配置的目标模型，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置有效。
- 导入一份绕组工艺卡与耐压试验报告，测试检索功能，确认检索结果能准确匹配文档中的核心字段，验证`maxContext`与`quoteMaxToken`的配置符合业务需求。
- 设置`temperature`为0.3，发起一条绕组匝数核对的测试问答，检查输出内容的严谨性，确认参数对生成逻辑的影响符合预期。
- 启用视觉模型配置，上传一张电机定子绕组的图像，触发点检问答流程，确认按钮状态正常且能正常调用视觉分析能力。
