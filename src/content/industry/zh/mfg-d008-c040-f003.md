# 电池PACK与储能系统集成的设备点检与维修问答：多轮对话与提示词

## 这个品类的数据长什么样
该品类数据来源包括电芯分容数据、工厂MES系统、焊接设备日志、扭矩工具记录、BMS软件版本文件、EOL试验台测试数据。数据更新节奏为每台电池包或储能柜生成一次，每次BMS软件版本变更时同步更新。日常文档包含配组规则、BOM清单、焊接与扭矩作业记录、BMS刷写日志、绝缘耐压报告、EOL测试报告、系统配置清单。数据字段涵盖电芯容量、扭矩值、测试电压、软件版本号等，无统一跨设备标准化单位。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
该品类的数据特征对多轮对话与提示词环节带来多重约束。首先，单台设备对应专属数据，多轮对话需通过`chatId`绑定单台电池包或储能柜的全量历史记录，避免跨设备数据混淆。其次，文档类型多样且字段分散，提示词需明确指定检索的文档类型范围，例如仅调用配组规则或对应设备的BMS刷写日志。再者，数据更新频率高且来源分散，提示词需限定检索与当前设备匹配的最新版本数据，同时多轮对话需保留设备的BMS版本、测试参数等上下文，确保问答基于当前设备的最新配置。另外，设备故障后果严重，多轮对话需在每轮验证输入参数的合规性，例如扭矩值是否符合对应机型的配组要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chatId` | 绑定单台设备的唯一设备编码 | 确保多轮对话关联对应设备的专属历史数据，避免跨设备混淆 |
| `messages` | 保留当前设备的3轮历史对话与最新输入 | 控制上下文长度，适配单台设备的有限历史数据量 |
| `variables` | 传入当前设备的BMS版本、电芯型号、测试日期 | 让提示词精准匹配对应设备的专属配置文档，明确引用模板的调用范围 |
| 问题优化 | 开启并设置为仅针对设备维修场景优化 | 适配该品类的专业维修问答需求 |
| 最大上下文 | 8000 token | 覆盖单台设备的核心文档与历史对话内容，按实测标定 |
| 单次召回上限 | 前6条匹配文档 | 匹配该品类多类型文档的检索需求，避免冗余数据干扰 |

本配置基于FastGPT v4.17.0版本。

## 容易做错的三处
- 调用对话接口时指定知识库标签未生效，现象是返回结果包含无关文档，原因是未在`variables`中传入对应标签参数。
- 配置提示词后调用接口返回400状态码，现象是接口返回参数校验失败提示，原因是提示词模板中未正确绑定`variables`对应的设备专属字段，例如未引用BMS版本参数。
- 多轮对话中上下文丢失，现象是后续对话无法调用之前的设备测试数据，原因是未正确传递`chatId`导致会话绑定失效。

## 怎么确认配好了
- 发起测试对话，输入单台设备的型号，检查返回结果中是否包含对应设备的专属文档内容。
- 查看接口返回的`messages`字段，确认包含最近3轮的历史对话记录。
- 传入预设的`variables`参数，检查提示词是否正确调用对应设备的配置信息。
- 重复发起3次以上同设备的对话，确认`chatId`绑定的会话数据未丢失。
