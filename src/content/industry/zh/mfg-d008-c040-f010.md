# 电池PACK与储能系统集成的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的核心数据来源于电芯分容设备、MES系统、焊接扭矩工具、BMS软件、EOL试验台等生产与测试环节。日常维护与生产文档包含配组规则、BOM清单、焊接与扭矩记录、BMS刷写日志、绝缘耐压报告、EOL测试报告、系统配置清单。数据更新频率为每台电池包或储能柜产出一次，每次BMS软件版本变更时同步更新。文档字段包含电芯容量、内阻、物料编码、扭矩值、刷写版本号等专业参数，需按生产环节分类存储，无统一的通用存储格式。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的生产与维护数据更新频率高且单条数据关联具体设备单元，要求检索召回环节支持增量同步与精准匹配单台设备的专属配置。配组规则、BMS配置等核心文档直接关联设备安全运行，要求检索结果需优先匹配专业技术文档，避免无关内容干扰。多来源的异构数据格式要求预处理环节需按文档类型做结构化转换，确保检索时可准确匹配故障现象与对应处理流程。此外，绝缘失效、BMS配置错误等出错后果严重，要求检索召回的准确率需满足现场维修的可靠性标准。

## 配置怎么定
本配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 电池PACK与储能系统的专业参数匹配精度要求高，过低会引入无关文档，过高会导致有效召回结果不足 |
| `limit` | 前8条 | 单台设备点检的相关文档数量有限，过多会增加上下文长度，影响响应速度 |
| `usingReRank` | 开启 | 该品类文档涉及电气、热管理、软件配置等多维度专业内容，重排可在平衡响应速度的前提下提升高相关结果的排序优先级 |
| `searchMode` | 语义匹配优先 | 设备维修问答需匹配故障现象与对应处理流程，仅通过关键词匹配难以覆盖专业场景 |
| `datasetSearchUsingExtensionQuery` | 开启 | 现场点检人员的提问可能包含口语化描述，扩展查询可覆盖更多专业术语变体 |
| `collectionIds` | 绑定当前项目的配组规则、BMS文档等专属集合 | 避免召回无关品类的知识库内容，确保检索结果贴合该品类的业务场景 |

## 容易做错的三处
- 现象：调用API同步知识库集合时返回身份验证失败。原因：未使用绑定目标知识库集合的专属API密钥，或密钥未被授予集合读写权限。
- 现象：绑定谷歌搜索API时提示操作失败。原因：未完成谷歌搜索结算账户的实名认证流程，或调用频次超出当前套餐的限额。
- 现象：设备点检问答的检索响应速度过慢。原因：单次召回的文档数量过多，或`similarity`阈值设置过低导致召回了大量无关文档，增加了处理耗时。

## 怎么确认配好了
- 执行一条模拟现场点检的提问，例如“某型号储能柜绝缘报警如何排查”，检查返回结果是否包含该品类专属的绝缘耐压报告、BMS配置文档，可通过调整`similarity`配置匹配业务需求。
- 调用API测试知识库集合同步流程，确认返回状态码为200且集合内文档数量与源生产数据一致。
- 测试绑定谷歌搜索API的流程，确认可正常调用并返回该品类设备维修的参考内容。
- 测试不同提问的响应速度，确认符合业务场景的实时性要求，可通过调整`limit`配置优化。
