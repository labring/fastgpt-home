# 石油炼制的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
石油炼制场景的业务数据覆盖炼油企业生产运行、工艺、设备等部门，日常文档包含操作规程、生产方案、物料平衡、馏出口质量报告、联锁台账、交接班记录、变更管理文件。数据来源包括DCS/APC系统、LIMS系统、罐区计量系统、原油评价报告、设备管理系统、能源管理系统。数据更新节奏分为实时（DCS时序数据）、每班（交接班记录）、每日（物料平衡与质量报告）。文档字段包含装置编号、操作压力（MPa）、温度（℃）、设备序列号、运行时长（小时）等标准化单位字段，部分长文档存在多章节嵌套结构。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源导致检索需兼容时序数据、静态台账、报告类文档等不同格式，需针对性配置分块与召回规则。不同更新频率要求支持增量更新与全量更新结合的同步策略，避免数据滞后或冗余。炼油场景的文档存在多装置耦合的关联逻辑，检索时需优先召回同装置、同工艺段的相关条目，同时需控制召回结果的上下文长度，避免超出LLM处理限额。此外，该场景的异常后果严重，需确保召回结果的精准度，避免无关条目干扰决策。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | 0.75–0.85 | 匹配炼油设备点检的故障描述与标准化知识库条目，过滤无关的非炼油设备数据 |
| `limit` | 前8条 | 适配多装置耦合的业务场景，控制召回结果的总字符数，符合FastGPT v4.17.0的上下文限额要求 |
| `searchMode` | `fullTextRecall` | 适配长文档如生产方案、物料平衡的检索需求，覆盖跨章节的关联工艺内容 |
| `usingReRank` | 开启 | 对多源异构的召回结果做二次排序，提升精准匹配炼油工艺问题的概率 |
| `datasetSearchUsingExtensionQuery` | 开启 | 对设备点检的口语化提问做语义优化，匹配标准化的操作规程与维修记录 |
| `collectionIds` | 按炼油专属知识库ID配置 | 隔离其他品类的知识库数据，避免召回无关内容，实现精准的知识库范围限定 |

## 容易做错的三处
- 配置`collectionIds`时误引入其他品类的知识库ID，导致召回非炼油设备的维修条目，出现搜索结果偏离炼油场景的现象。原因是未按炼油专属集合配置参数，导致跨品类数据混杂。
- 未开启`datasetSearchUsingExtensionQuery`，使用口语化的点检提问（如“加氢装置换热器漏了怎么修”）时，无法匹配标准化的维修规程，出现检索结果为空的现象。原因是未对口语化提问做语义扩展优化。
- 未调整`similarity`阈值，阈值过低时召回大量冗余的交接班记录，阈值过高时无法召回匹配的故障维修条目，出现结果条数异常的现象。原因是未结合炼油场景的文档特征标定阈值。

## 怎么确认配好了
- 发起设备点检相关提问，检查召回结果仅包含炼油设备的操作规程、维修记录，无其他品类的内容。
- 查看FastGPT的检索日志，确认`similarity`、`usingReRank`等配置参数被正确调用，参数取值符合预设规则。
- 上传一条新的炼油设备变更管理文件，触发增量更新后，检索该文件的关键词，确认能正常召回对应条目。
- 测试口语化的维修提问，确认能匹配到对应的标准化文档条目，验证语义扩展优化生效。
