# 精细化工间歇合成的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
本品类数据来自涂料、树脂、农化中间体等专用化学品企业的配方与工艺库、原料批次记录、反应釜DCS系统、称量系统、LIMS实验室管理系统及仓储系统。日常文档包含批生产指令、投料复核单、反应过程记录、清场记录、检验报告、偏差与变更单，每个生产批次及关键工艺步骤都会更新数据。数据字段包含批次号、投料量、反应温度、清场确认记录等，单位涉及千克、摄氏度、小时等，且因多品种切换生产，需关联对应批次的清洗验证记录。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多品种按批次切换的生产模式，要求检索需精准匹配当前生产批次的工艺参数与清洗验证记录，避免交叉污染风险。按批更新的高频数据，要求检索需支持实时关联最新的批次记录、偏差与变更单信息。文档包含敏感配方与工艺细节，要求检索需严格限定授权访问范围，同时需按文档类型分类召回对应场景的内容。设备点检与维修需求覆盖反应釜、称量设备等多类硬件，需支持按设备型号、工艺步骤定向检索，且关联历史维修与点检记录。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本，针对精细化工间歇合成场景定制：

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 匹配精细化工工艺参数的精度要求，避免召回无关的非当前批次记录 |
| `limit` | `前 8–12 条` | 覆盖多文档类型的检索需求，同时控制上下文长度避免超出模型限制 |
| `searchMode` | `semantic + keyword` | 兼顾工艺参数的语义匹配与批次号、设备编号的精准关键词匹配 |
| `usingReRank` | `开启` | 对召回结果按相关性重排序，提升维修与点检场景的精准度 |
| `datasetSearchUsingExtensionQuery` | `开启` | 扩展检索范围，关联批次相关的清场、偏差记录 |
| `collectionIds` | `按生产车间/设备类型分组配置` | 限定检索范围，避免召回其他车间或设备的无关文档 |

## 容易做错的三处
- 检索结果返回的文档跳转链接点击后返回报错信息“Only support .txt, .m”。原因是导入知识库的文档包含非支持的格式，且未在检索配置中过滤非授权文档类型。
- 自定义分块长度配置后，检索召回的内容出现截断或冗余。原因是未结合本品类文档的字段长度（如投料复核单包含多组数值记录）设置合理的分块区间，导致分块不符合工艺文档的语义完整性。
- 导入知识库时出现“Request failed with status code 400”报错。原因是未按批次关联的文档结构配置导入模板，导致字段格式与系统要求不匹配，或扩展查询参数配置异常。

## 怎么确认配好了
- 输入当前生产批次的设备点检或维修问题，核对召回结果是否包含对应批次的清场记录、维修历史及工艺参数文档。
- 查看检索结果的相关性得分，确认`similarity`参数的取值符合当前场景的精度要求。
- 测试导入不同类型的工艺文档，确认检索配置是否正确限定了召回的文档范围。
- 触发检索后，检查返回结果的条数是否符合配置的`limit`参数要求。
