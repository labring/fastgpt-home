# 肉制品与屠宰加工的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的核心数据包括动物检疫证明、屠宰与分割记录、配料腌制记录、热加工记录、冷链温度记录、微生物检验报告，以及设备点检与维修相关的生产台账。数据来源涵盖动物检疫信息、供应商批次台账、生产追溯系统、实时温度采集设备、金属检测结果、实验室检验数据。更新节奏按生产批次、每班作业更新，冷链温度数据为连续采集更新。文档包含批次号、检疫编号、温度阈值、检验指标等字段，格式兼具结构化台账与非结构化记录。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类数据涉及生物安全与生产合规要求，检索结果需严格匹配对应批次与检疫状态，避免无关或错误信息干扰设备点检与维修决策。高频更新的冷链温度与实时检测数据，要求检索环节支持增量召回与时效性过滤，防止调用陈旧数据。多样的文档格式与多来源数据，需要检索系统适配结构化与非结构化内容的统一召回逻辑。设备点检维修问答需关联生产批次与检疫信息，检索范围需限定在对应生产环节的设备数据范围内，避免跨场景混淆。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 该品类需严格匹配设备点检与生产批次的关联信息，避免低相关结果混入问答场景 |
| `limit` | `前6–8条` | 兼顾召回信息量与响应速度，过多结果会增加上下文处理耗时，影响设备维修问答的流畅性 |
| `searchMode` | `混合检索` | 该品类数据兼具结构化台账与非结构化记录，混合检索可覆盖不同格式的设备点检手册与生产数据 |
| `usingReRank` | `开启` | 通过重排过滤冗余结果，提升设备维修相关问答的精准度，避免无关文档干扰决策 |
| `datasetSearchUsingExtensionQuery` | `开启` | 可通过扩展问题优化检索词，匹配设备点检手册与生产记录中的隐含关联信息 |
| `collectionIds` | `指定设备点检维修数据集ID` | 限定检索范围至对应品类的专属知识库，避免无关的检疫或检验数据干扰 |

## 容易做错的三处
- 现象：知识库检索时弹出“无可匹配结果”报错，或检索结果与设备点检问题无关。原因：未限定`collectionIds`至专属数据集，检索范围覆盖了无关的检疫或检验文档。
- 现象：部分PDF文档无法被识别，检索时无对应内容。原因：未按品类文档格式调整解析规则，或PDF包含加密内容、非标准字体导致解析失败。
- 现象：检索响应延迟，或上下文处理超时。原因：未设置合理的`limit`取值，召回过多结果导致系统处理压力过大。

## 怎么确认配好了
- 上传品类专属的设备点检记录与生产文档，验证`collectionIds`仅指向该数据集，检索时仅返回对应文档的内容。
- 输入设备点检相关问题，检查返回结果的`similarity`分值是否在预设区间内，且结果与问题高度相关。
- 开启`usingReRank`后，对比开启前后的检索结果排序，确认重排后结果的相关性提升。
- 测试高频更新的冷链温度数据检索，验证是否能召回最新的采集记录，无陈旧数据干扰。
