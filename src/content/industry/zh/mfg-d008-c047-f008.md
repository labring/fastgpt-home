# 计量器具与实验室管理的设备点检与维修问答：文档解析与分块

## 这个品类的数据长什么样
这个品类的数据来自企业计量管理系统、外部校准机构证书、标准器数据、LIMS平台及环境监测记录。日常文档包含量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账、偏离处置文件等，部分数据来自语雀分享页、飞书文件夹内的Excel文件与多维文档。文档包含器具标识、校准日期、测量结果、不确定度、溯源编号等固定字段，单位随测量参数变化，如长度、质量、不确定度单位等。数据更新按校准周期、每次试验或异常情况触发，更新节奏不固定。

## 这些特征在「文档解析与分块」这一环带来什么约束
该品类的文档类型多样，包含结构化台账、半结构化校准证书、非结构化试验记录及多格式外部文件，要求分块逻辑适配不同内容结构。文档中的溯源编号、校准结果等关键信息需保留上下文关联，避免拆分跨关键字段的内容，否则会破坏数据的可信性。外部来源的文档格式不统一，如校准证书的页眉页脚包含溯源信息，需要自定义解析规则提取。数据更新频率随校准周期变化，单次批量解析的文件数量较多，需考虑解析超时与文件大小限制。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，适配计量器具与实验室管理的文档特征。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chunkSize` | 800–1200 字符 | 适配校准证书、试验记录的单页内容长度，避免拆分关键溯源字段 |
| `chunkSplitter` | 按段落+标题拆分 | 适配结构化台账和半结构化证书的层级结构，保留字段上下文关联 |
| `customPdfParse` | 开启 | 校准证书多为标准化PDF，开启后可提取页眉页脚的溯源编号等关键信息 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 300–600 秒 | 适配大型年度校准台账批量解析的耗时需求 |
| `UPLOAD_FILE_MAX_SIZE` | 1000 MB | 支持导入多份年度校准计划、批量校准证书文件 |
| `chunkSettingMode` | 手动配置 | 针对品类特有的文档结构，自定义分块规则适配不同类型的计量文档 |

## 容易做错的三处
- 现象：导入语雀公开分享链接后提示解析失败，返回「不支持的数据源类型」。原因：未确认语雀链接为公开可访问状态，且未适配语雀网页的解析结构。
- 现象：调用HTTP工具时参数解析正常，但工具未执行，返回空结果。原因：未配置对应工具的调用权限，或参数中包含品类特有的溯源编号格式未被正确转义。
- 现象：导入飞书多维文档后，解析结果中字段为空或格式混乱。原因：未开启飞书文档的企业共享权限，或分块配置未适配多维表格的列结构。

## 怎么确认配好了
- 上传一份标准校准证书PDF，查看解析后的分块内容，确认溯源编号、校准日期等关键字段未被拆分。
- 导入语雀公开分享的计量器具台账链接，验证解析结果包含台账的表格内容与字段信息。
- 上传一份500MB以内的校准计划Excel文件，检查解析耗时是否在配置的`PARSE_FILE_TIMEOUT_SECONDS`范围内。
- 开启自定义PDF解析规则后，重新上传校准证书，验证页眉页脚的溯源信息被正确提取。
