# 计量器具与实验室管理的设备点检与维修问答：部署与升级

## 这个品类的数据长什么样
该品类数据主要来自计量管理系统、外部校准机构证书、标准器、LIMS系统及环境监测设备。日常生成量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账、偏离处置单等文档。数据更新按校准周期、单次试验结果或异常情况触发。文档包含器具编号、校准有效期、测量不确定度、溯源链编号等字段，单位涵盖日期、百分比、物理量单位等，需严格匹配计量溯源要求。

## 这些特征在「部署与升级」这一环带来什么约束
该品类多源异构的数据来源、周期性更新的特征及溯源相关的字段要求，对部署与升级环节带来多重约束。需提前配置兼容多数据源的数据库与存储连接，适配计量管理系统、LIMS等不同系统的数据格式。增量同步配置需匹配校准周期与异常触发规则，避免全量索引占用过多资源。升级过程中需保留原有文档的字段映射规则，防止溯源链编号、测量不确定度等关键字段丢失或格式错乱。同时需预设结构化文档的字段匹配模板，确保校准证书等文档的解析一致性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:port/dbname?authSource=admin` | 适配计量器具台账、校准记录等结构化数据的存储需求，支持多文档类型的索引与查询 |
| `STORAGE_S3_ENDPOINT` | `https://s3-cn-beijing.volces.com`（或对应自建存储地址） | 用于存储校准证书、试验原始记录等大体积文档，匹配多源数据的存储格式要求 |
| `REDIS_URL` | `redis://:password@host:port/0` | 缓存校准周期、溯源链状态等高频查询数据，降低数据库负载 |
| `FE_DOMAIN` | `https://your-fastgpt-domain.com` | 配置前端访问地址，确保语音功能可正常调用，避免HTTP环境下的功能限制 |
| `DB_MAX_LINK` | `20–30 个` | 适配多源数据同步时的并发连接需求，避免数据库连接耗尽 |

## 容易做错的三处
- 现象：前端访问时语音功能无法触发，控制台报跨域或协议不支持错误。原因：未将`FE_DOMAIN`配置为HTTPS地址，仍使用HTTP根地址部署，导致浏览器限制非安全环境下的语音API调用。
- 现象：升级新版本后，尝试导入老版本的工作流应用失败，界面提示“应用格式不兼容”。原因：未在升级前导出包含计量器具专属字段映射的应用配置，或升级后未保留原有数据库的字段索引规则，导致应用依赖的数据结构无法匹配。
- 现象：知识库持续处于索引状态，日志显示字段解析超时。原因：未配置合理的`DB_MAX_LINK`参数，多源数据同步时并发连接耗尽，导致索引任务无法正常完成。

## 怎么确认配好了
- 访问配置的`FE_DOMAIN`地址，验证前端页面可正常加载，且语音功能可正常唤起。
- 执行一次多源数据同步任务，查看数据库连接数未超过`DB_MAX_LINK`的配置值，无连接超时报错。
- 尝试导入老版本的工作流应用包，确认应用可正常加载且包含计量器具台账的关联字段。
- 查看知识库索引任务日志，确认无持续的字段解析超时或连接失败记录，索引任务可正常完成。
