# 过程质量与成品放行的设备点检与维修问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
本品类的数据来源包括制造执行系统（MES）、在线检测设备、实验室检测结果、工艺参数库、客户质量标准及历史缺陷记录。数据更新节奏按生产批次、班组周期持续采集，日常产出的文档包含控制计划、巡检记录、SPC统计报表、成品检验报告、不合格品评审单、成品放行单及质量月报。数据字段包含检验项参数、检测数值、判定结果、批次编号、缺陷类型及整改记录，部分字段需匹配工艺公差范围与客户验收标准。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
本品类的数据来源分散且更新节奏差异明显，接口需适配多系统的鉴权规则与数据格式，避免硬编码适配单一数据源。日常文档类型多样且字段结构不统一，接口需支持动态字段映射，适配控制计划、检验报告等不同文档的参数传递。成品放行相关数据需严格的权限校验，接口需绑定角色级别的访问控制，防止未授权数据篡改。数据更新覆盖批次到实时采集，接口需配置合理的轮询间隔与超时阈值，避免重复拉取或遗漏关键批次数据。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer {系统分配的API密钥}` | 符合多数外部系统的鉴权规范，适配MES、检测设备的接口要求 |
| `variables` | `{"batchNo": "{{batch_no}}", "inspectResult": "{{inspect_result}}"}` | 匹配本品类的批次、检验结果核心字段，实现动态参数传递 |
| `responseData` | `仅提取status、message、data字段` | 过滤冗余数据，适配本品类的质量数据校验逻辑 |
| 批量提交阈值 | `10-20条/请求` | 适配本品类每班的巡检记录批量处理需求，避免接口过载 |
| 接口超时时间 | `30-60秒` | 适配实验室检测数据的采集延迟，防止超时中断数据同步 |

## 容易做错的三处
- 现象：HTTP请求携带的JSON数据在传递至外部系统时出现大量反斜杠转义字符。原因：未对请求体进行正确的序列化处理，直接拼接原始JSON字符串导致格式异常。
- 现象：调用接口时返回401未授权错误。原因：未正确配置`Authorization`参数，或使用了过期的API密钥，无法通过外部系统的鉴权校验。
- 现象：接口返回的文件相对路径附带额外token参数，无法被Flask服务正常解析。原因：未在接口配置中剥离路径中的鉴权token，直接传递完整路径导致外部系统无法识别有效文件地址。

## 怎么确认配好了
- 调用测试接口，检查`responseData`是否仅返回预期的核心字段，无冗余数据。
- 提交包含本品类标准字段的测试数据，确认外部系统能正确解析`variables`传递的参数。
- 验证`Authorization`参数配置正确，调用接口后返回200状态码且无鉴权报错。
- 模拟批量提交巡检记录，确认接口未出现过载报错，数据同步正常。
