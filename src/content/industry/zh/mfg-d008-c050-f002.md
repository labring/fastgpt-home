# 通用机械设备装配的设备点检与维修问答：向量模型与索引

## 这个品类的数据长什么样
通用机械设备装配品类的数据多来自PLM/ERP、零件检验数据、装配工具采集系统、试验台、MES及客户技术协议，更新节奏为每台设备或每订单一次。日常文档包含装配工艺卡、BOM清单、扭矩记录、间隙调整记录、试运行报告、出厂检验单与装箱清单，数据字段多包含具体数值类参数，如扭矩值、间隙尺寸、同轴度指标，附带明确的单位标注。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据按单台或订单更新，且包含大量带单位的工艺参数与步骤类文本，对向量模型与索引环节带来多重约束。首先，单台/单订单的增量数据需适配快速索引更新，避免全量重索引的耗时；其次，带单位的数值参数需在分块时保留关联上下文，避免拆分后丢失参数与单位的绑定关系；最后，文档类型多样且结构差异大，需确保索引能兼容结构化参数与非结构化工艺文本的混合嵌入。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配装配工艺卡与BOM的单段文本长度，避免拆分后丢失工艺步骤的上下文关联 |
| 重叠长度 | 100–150 字符 | 保留相邻分块的参数与步骤衔接信息，防止间隙调整记录等带连续数值的文本被割裂 |
| 相似度阈值 | 0.72–0.80 | 过滤低匹配度的检索结果，适配设备点检中对参数精度的要求 |
| 最大上下文 | 6000 字符 | 匹配通用机械设备装配场景下的工艺问答所需的上下文长度，避免超出模型输入限制 |
| `defaultToken` | 按实测标定 | 适配不同embedding模型的token上限，兼容扭矩、间隙等带单位的数值类文本的嵌入 |
| `maxToken` | 8192 | 匹配主流开源embedding模型的最大token限制，确保装配工艺类长文本可完整嵌入 |

## 容易做错的三处
- 现象：手动插入知识库的默认索引数小时后自动消失。原因：未配置增量索引的持久化存储，或索引刷新周期设置与数据更新频率不匹配，导致临时索引被自动清理。
- 现象：接入qwen3-embedding-8b后，文件状态持续显示“索引中”。原因：所选embedding模型的接口超时设置未适配大模型加载耗时，或模型版本与FastGPT v4.17.0的兼容配置未完成。
- 现象：检索结果中出现参数与单位分离的不匹配内容。原因：分块长度设置过短，导致带单位的数值参数被拆分至不同分块，嵌入后丢失关联关系。

## 怎么确认配好了
- 上传一份包含扭矩记录与间隙调整记录的测试文档，检查索引完成后检索“如何调整减速机间隙”，查看返回结果是否包含对应参数与步骤。
- 上传一份新的订单文档，触发增量索引，检查索引状态是否在合理时间内完成，未出现持续“索引中”的情况。
- 更换embedding模型后，执行批量重嵌入操作，检查原有文档的检索召回率是否符合预期。
- 查看索引存储目录，确认索引文件未被自动清理，持久化配置生效。
