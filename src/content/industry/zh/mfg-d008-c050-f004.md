# 通用机械设备装配的设备点检与维修问答：工作流编排

## 这个品类的数据长什么样
通用机械设备装配的日常文档包含装配工艺卡、BOM、扭矩记录、间隙调整记录、试运行报告、出厂检验单、装箱清单。数据来源包括PLM/ERP、零件检验数据、装配工具采集、试验台、MES、客户技术协议，更新节奏为每台设备或每订单一次。文档字段包含设备型号、订单号、扭矩值（单位N·m）、间隙值（单位mm）、同轴度公差（单位μm）等，核心围绕部件配合与装配调试结果。

## 这些特征在「工作流编排」这一环带来什么约束
由于该品类采用多品种按订单装配模式，数据随每台设备个性化更新，工作流需绑定`variables`参数以适配不同订单的BOM与工艺要求。核对多层BOM与实物齐套、调整间隙同轴度等环节耗时较长，工作流需预留足够执行时长。装配文档体量随订单复杂度变化，需支持动态调整文件解析与数据调用的节点配置，同时需覆盖漏装错装、性能超限等异常场景的闭环处理逻辑。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的工作流逻辑制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `variables` | 绑定订单号、扭矩阈值、间隙公差范围 | 适配每台设备的个性化装配参数与工艺要求 |
| `nodeId` | 指定BOM校验、间隙调试节点的唯一标识 | 快速定位工作流中的异常执行环节 |
| 单次执行超时时间 | 600–1200秒 | 覆盖核对多层BOM、调试装配参数的常规耗时 |
| 表单触发规则 | 仅当所有必填字段填写完成后启动 | 避免未完成输入就触发工作流执行 |
| 文件上传节点限制 | 单文件不超过100 MB | 匹配装配工艺卡、BOM等文档的常规体量 |
| 外部搜索工具调用配置 | 绑定专用搜索节点，调用前8条结果 | 用于检索设备维修相关的公开参考内容，聚焦核心信息 |

## 容易做错的三处
- 工作流执行超时，返回执行超时报错，原因是未针对装配BOM核对、间隙调试的长耗时环节调整超时设置，导致执行时长超出预设阈值。
- 调用带文件上传的工作流API时返回文件解析失败，原因是未配置文件上传节点的允许格式与大小限制，无法接收装配文档类的大体积文件。
- 未限制外部搜索工具的结果调用上限，返回过多冗余搜索结果，原因是未设置仅调用前8条核心匹配内容的规则。

## 怎么确认配好了
- 触发测试工作流，输入模拟订单参数，核对`variables`是否加载对应订单的BOM与工艺数据。
- 上传一份标准装配工艺卡，确认文件上传节点正常接收并返回有效解析内容。
- 留空表单必填字段，验证工作流无法启动，确认触发规则生效。
- 触发外部搜索节点，输入通用设备维修问题，确认返回有效参考结果。
