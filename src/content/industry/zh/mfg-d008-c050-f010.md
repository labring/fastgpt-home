# 通用机械设备装配的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
通用机械设备装配品类的业务数据主要来自PLM、ERP、零件检验数据、装配工具采集、试验台、MES及客户技术协议。日常文档包含装配工艺卡、BOM表、扭矩记录、间隙调整记录、试运行报告、出厂检验单与装箱清单。数据更新随单台设备或每笔订单触发，文档结构多包含物料编码、扭矩数值、间隙参数、检验结果等字段，单位涵盖毫米、牛·米、小时等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类数据随单台设备或订单更新，知识库需支持按订单或设备维度关联数据，避免跨单数据混淆。文档类型多样且字段差异大，检索需适配不同文档的字段格式，比如BOM的物料编码与扭矩记录的数值字段需分别匹配查询逻辑。数据更新频率高，召回结果需实时关联最新的装配、检验记录，同时需控制检索范围，避免冗余数据干扰。此外，多品种按订单装配的特性，要求检索结果需区分不同订单的专属配置，确保召回内容与当前装配任务匹配。

以下配置基于FastGPT v4.17.0版本。
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.85 | 适配扭矩、间隙等数值类字段的匹配精度，避免召回无关的装配文档 |
| `limit` | 前6条 | 匹配单台设备的多类型文档数量，避免上下文过长超出模型处理上限 |
| `searchMode` | `embedding` | 适配多类型文档的混合检索，覆盖工艺卡、BOM、检验记录等不同格式内容 |
| `usingReRank` | 开启 | 对召回结果二次排序，过滤因字段差异导致的低相关召回项 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展查询词，补充订单号、设备型号等专属字段的检索维度 |
| `collectionIds` | 按订单关联的文档集合ID | 限定检索范围仅为当前订单的装配数据，避免跨单数据干扰 |

## 容易做错的三处
- 现象：检索后返回0条结果，或界面提示“无匹配内容”。原因：未将当前订单的文档集合ID填入`collectionIds`，导致检索范围超出目标订单的装配数据。
- 现象：召回结果包含其他订单的扭矩记录或间隙调整数据。原因：未开启`datasetSearchUsingExtensionQuery`，未对查询词补充订单号、设备型号等专属标识，导致跨单数据被召回。
- 现象：检索结果的相关性波动大，部分低匹配度的文档被优先召回。原因：未开启`usingReRank`，仅依赖初始语义检索的结果，未对召回结果进行二次排序过滤。

## 怎么确认配好了
- 查看知识库的集合绑定配置，确认`collectionIds`已关联当前订单对应的装配文档集合。
- 发起测试检索，检查返回结果的数量是否符合`limit`的设置要求。
- 验证检索结果的相关性，确认相似度符合预设的`similarity`区间。
- 检查重排功能是否开启，确认召回结果的排序逻辑符合业务需求。
