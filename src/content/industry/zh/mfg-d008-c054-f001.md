# 钣金下料折弯的设备点检与维修问答：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的核心数据来自CAD/CAM软件、订单BOM、板材库存系统、激光切割机与折弯机设备日志、MES生产系统。日常产出展开图、数控下料程序、折弯工艺卡、套料图、首件记录、工序流转卡等文档。数据更新随订单生成、每日盘点、每次生产换型触发，包含折弯系数、板材规格、下料尺寸、折弯角度等字段，单位随生产场景灵活调整。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类多品种小批量的生产模式，要求接口适配高频动态请求，支持不同订单的差异化参数传递。多源数据来源需要接口兼容不同系统的数据格式，完成CAD程序、工艺卡、设备日志的跨系统同步。频繁的更新节奏需要接口配置合理的超时与重试机制，避免因生产中断导致数据同步失败。同时，因参数错误会引发整张板材浪费，接口需增加数据校验环节，确保传入的折弯系数、下料尺寸等参数符合生产要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `Authorization` | `Bearer ${自定义对接密钥}` | 符合FastGPT v4.17.0版本的工业API安全认证规范，避免未授权访问 |
| `variables` | `{"orderNo": "", "sheetSpec": "", "bendCoeff": ""}` | 匹配钣金下料折弯的核心生产参数，实现动态适配不同订单的工艺要求 |
| `responseData` | `仅返回工艺匹配内容与设备点检日志` | 过滤无关数据，压缩接口响应载荷，提升调用效率 |
| 单次搜索上限 | 前6条 | 该品类单批次生产关联的工艺文档数量适中，过多会增加检索耗时 |
| 最大上下文 | 1000–1400 字符 | 匹配折弯工艺卡、展开图的核心内容长度区间，避免上下文溢出 |
| 超时时间 | 240 秒 | 适配数控下料程序解析、套料计算的常规耗时，按实测标定 |

## 容易做错的三处
- 现象：部分生产相关问题在调试页面可匹配到知识库结果，但通过API调用时无匹配内容。原因：API请求未携带与调试页面一致的知识库授权参数，或未正确配置上下文关联的订单变量。
- 现象：上传至API知识库的dir1目录下的b.md文件，在界面中显示为上层目录文件。原因：接口返回的`responseData`中未正确传递目录层级的嵌套结构，导致知识库解析路径异常。
- 现象：调用接口时出现SSL连接异常或认证失败报错。原因：未在compose.yml中正确挂载SSL证书文件，或未设置合法的`Authorization`认证参数。

## 怎么确认配好了
- 发起携带`variables`参数的测试请求，检查返回的`responseData`是否包含当前订单对应的折弯工艺内容。
- 查看知识库目录结构，确认上传的dir1目录下的文件显示路径正确，无层级错位。
- 调用接口并传入错误的`Authorization`参数，验证是否返回认证失败的提示，确认安全配置生效。
- 模拟生产换型后的参数变更，发起新的请求，确认接口可动态适配新的`variables`参数。
