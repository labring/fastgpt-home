# 钣金下料折弯的设备点检与维修问答：向量模型与索引

## 这个品类的数据长什么样
该品类的业务数据主要来自机柜机箱、通风设备、电气柜、非标设备制造商的生产与设备管理流程。日常留存有展开图、数控下料程序、折弯工艺卡、套料图、首件记录、工序流转卡及设备点检台账，数据来源覆盖CAD/CAM工具、订单BOM、板材库存系统、激光切割机、折弯机及MES系统。数据更新随每笔订单、每日生产及每次设备换型同步调整，整体呈现多品种小批量、图纸驱动的特征，核心生产环节聚焦三维件展开、折弯系数补偿、套料余料管理及折弯顺序核对。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的多源异构数据特征、高频更新节奏与图纸驱动的生产逻辑，对向量模型与索引环节形成多重约束。不同格式的文档（图纸导出文本、数控程序、工艺卡、点检台账）需适配差异化的分块规则，避免破坏工艺参数的上下文关联。数据随订单、生产及换型高频更新，要求索引支持增量更新与快速同步，避免出现数据滞后。图纸驱动的业务逻辑使得工艺类文档包含折弯角度、板材厚度等结构化字段，向量模型需适配半结构化内容的语义匹配。核心生产环节出错后果严重，要求检索的召回精度与上下文完整性达标，避免断章取义导致的错误匹配。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| 分块长度 | 800–1200 字符 | 适配该品类的半结构化工艺卡、数控程序文本，保留折弯系数、下料参数等完整上下文 |
| 重叠长度 | 100–150 字符 | 保留相邻工序的衔接信息，避免折弯顺序描述的上下文断裂 |
| `maxToken` | 4096 token | 适配长文本输入需求，承载展开图导出的完整工艺信息 |
| 相似度阈值 | 按实测标定 | 匹配该品类高容错风险的业务场景，平衡召回准确率与漏检率 |
| 单次搜索上限 | 前 6 条 | 覆盖同类型设备的常见点检维修问题，避免结果冗余 |
| `defaultToken` | 2048 token | 适配设备点检问答的常规输入长度，完整承载故障描述与关联参数 |

## 容易做错的三处
- 现象：上传文档后显示分8段，就绪后变为13段，出现重复索引条目。原因：该品类数据随订单、换型高频更新，增量索引未正确过滤已处理的文档元数据，导致同一份文件被重复分块入库。
- 现象：已添加的ollama qwen2.5、bge-m3模型出现在可用模型列表，但创建知识库时文本理解模型下拉框无对应选项。原因：未将模型绑定至向量索引的专属调用通道，或模型的接口连通性校验未通过。
- 现象：仅可单文件调整向量模型训练参数后重新上传，无法批量触发全量或增量重训练。原因：未配置适配该品类高频更新节奏的批量重训练任务规则，系统默认仅支持单文件触发。

- 发起一次设备故障描述的检索测试，确认召回结果的数量与单次搜索上限的配置匹配。
- 触发增量索引更新任务，验证高频更新的文档可按预设节奏完成同步。
