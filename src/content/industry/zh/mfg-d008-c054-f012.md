# 钣金下料折弯的设备点检与维修问答：部署与升级

## 这个品类的数据长什么样
钣金下料折弯品类的业务数据主要来自CAD/CAM软件、订单BOM系统、板材库存台账、激光切割机、折弯机设备及车间MES系统。日常产生的文档包括零件展开图、数控下料程序、折弯工艺卡、套料图、首件检验记录、工序流转卡。数据更新节奏随订单交付、每日生产排班、每次设备换型调整，核心字段包含板材厚度、折弯系数、下料尺寸、折弯顺序、余料规格等，无固定统一的统计口径，随生产批次动态变化。

本文基于FastGPT v4.17.0版本编写。

## 这些特征在「部署与升级」这一环带来什么约束
由于数据来源分散在多个生产系统，部署时需配置多数据源的连接参数，确保不同类型的业务文档能同步接入知识库。因数据更新频率高，每订单、换型即产生新数据，需预留足够的存储容量与连接池资源，避免知识库同步延迟。品类文档多为工程图纸与工艺文本，部署时需适配非结构化文件的解析规则，确保展开图、套料图等内容能被正确提取。此外，多品种小批量的生产模式要求问答系统的召回逻辑能灵活适配不同机型的参数，部署时需预留配置调整的空间，避免硬编码限制业务扩展。品类的生产出错后果直接关联整张板材的物料浪费，部署时需确保问答系统的配置符合生产安全要求，避免因配置错误导致无效的点检与维修指引。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://fastgpt:pass@your-host:27017/fastgpt?authSource=admin` | 对接订单BOM、工序流转卡等结构化业务数据，存储问答的历史交互记录 |
| `PG_URL` | `postgresql://fastgpt:pass@your-host:5432/fastgpt` | 存储数控下料程序、折弯工艺卡的文本解析结果，支持按工艺编号快速检索 |
| `REDIS_URL` | `redis://:fastgpt-redis@your-host:6379/0` | 缓存高频点检问答的召回结果，降低数据库的并发访问压力 |
| `DB_MAX_LINK` | `20–30` | 适配车间多工位同时发起点检请求的并发场景，避免数据库连接池耗尽 |
| `FILE_TOKEN_KEY` | `随机生成的32位字符串` | 保护上传的展开图、套料图等生产文件的访问权限，防止未授权下载 |
| `STORAGE_S3_ENDPOINT` | `按企业自建对象存储地址填写，如https://oss.example.com:8080` | 存储大量的工程图纸与工艺文档，预留1000 MB以上的存储空间避免容量不足 |
| `ROOT_KEY` | `按企业内部权限规则生成的复杂密钥` | 管理系统的最高权限配置，仅授权运维人员使用，防止未授权的系统修改 |

## 容易做错的三处
- 现象：线上环境导入套料图、展开图后内容乱码，本地部署则无异常。原因：线上环境未正确配置`STORAGE_S3_ENDPOINT`导致文件读取时编码解析异常，或`FILE_TOKEN_KEY`配置不一致导致文件传输损坏。
- 现象：调用设备点检问答接口时无法编辑请求body内容。原因：`FE_DOMAIN`配置错误，导致前端跨域限制拦截了body编辑操作。
- 现象：输入十几个字的点检问题时，回答先一次性返回完整结果再切换为流式输出。原因：`DB_MAX_LINK`配置不合理，导致数据库连接池波动，召回逻辑未按预期触发分步输出。

## 怎么确认配好了
- 访问`FE_DOMAIN`配置的域名，检查前端页面能否正常加载并显示设备点检问答的入口，无加载失败或跨域报错。
- 上传一张测试用的折弯工艺卡，检查文件能否正常解析并存储到`STORAGE_S3_ENDPOINT`对应的存储服务中，无乱码或上传失败提示。
- 使用`ROOT_KEY`登录系统后台，检查`MONGODB_URI`和`PG_URL`的连接状态是否显示正常，无连接超时或认证失败提示。
- 发起一个简单的点检问题请求，检查响应的body内容能否正常编辑，无字段缺失或乱码情况。
