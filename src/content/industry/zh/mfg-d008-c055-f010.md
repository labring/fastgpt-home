# 铸造（砂型、精密、压铸）的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据来源包括ERP物料主数据、熔炼炉与测温仪、光谱仪、MES炉次记录、模具管理系统及客户图纸技术文件。日常文档涵盖铸造工艺卡、配料单、炉次记录、模具履历、首件检验记录、材质报告与不合格品评审单。数据更新节奏为每炉次、每批或每日，字段包含炉次编号、熔炼温度、浇注时长、模具使用次数、缺陷类型代码、材质检测数值，单位涉及摄氏度、分钟、次等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据更新频率高，且按炉次、批次绑定关联字段，要求知识库检索召回需支持按炉次编号、模具编号等精准字段匹配，避免召回无关批次的历史数据。多类型文档并存的特点，要求检索适配结构化配料单、非结构化工艺卡等不同格式的数据，确保不同来源的内容均可被有效召回。数据体量随生产节奏动态增长，需限制单次召回的结果条数，避免上下文超出模型处理上限，同时支持增量同步更新的炉次记录与模具履历数据。此外，业务中需精准核对合金配料与回炉料比例、追溯缺陷对应的炉次与模次，要求检索结果需具备强关联的上下文关联能力，不能仅返回孤立的文档片段。

## 配置怎么定

召回模式需用代表性查询实测选择；品类、批次或实体范围应另行配置过滤，召回模式本身不负责约束这些边界。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 该品类需精准匹配炉次、配料比例等核心业务字段，阈值过低会引入无关批次数据，过高则无法召回相近缺陷的维修方案。 |
| `limit` | `前8–12条` | 铸造相关文档单条内容较长，过多召回会超出上下文限制，过少则无法覆盖完整的维修与点检流程。 |
| `usingReRank` | `开启` | 该品类数据关联度要求高，重排可过滤低相关度的召回结果，提升维修方案与点检问题的匹配精度。 |
| `datasetSearchUsingExtensionQuery` | `开启` | 可将用户的点检问题（如“某炉次缩孔如何处理”）扩展为包含炉次、材质参数的查询词，提升召回精准度。 |
| `collectionIds` | `绑定铸造设备点检与维修专属数据集` | 隔离其他品类的知识库数据，避免召回无关的锻造、机加工文档，确保检索范围贴合业务场景。 |

*注：本页面配置基于FastGPT v4.17.0版本*

## 容易做错的三处
- 现象：调用API引用私人知识库时返回空结果或权限报错。原因：未正确配置`collectionIds`参数，未将目标数据集加入允许调用的集合列表。
- 现象：对话页面或知识库页面出现崩溃。原因：未限制`limit`参数的取值，单次召回过多文档导致上下文溢出，触发平台内存限制。
- 现象：新建数据索引后无法检索到对应炉次的配料单。原因：未开启`datasetSearchUsingExtensionQuery`，无法将用户问题中的炉次号自动关联到索引字段，导致检索匹配失败。

## 怎么确认配好了
- 执行单炉次点检问题的检索，核对召回结果是否仅包含对应炉次的配料、熔炼参数等数据。
- 查看检索返回的结果条数，确认符合`limit`参数的设定区间。
- 调用API测试私人知识库的引用，确认返回结果包含预期的维修方案与点检文档。
- 检查重排功能的生效情况，确认高相关度的文档排在检索结果前列。
