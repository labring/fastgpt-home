# 锂离子电芯制造的设备点检与维修问答：部署与升级

## 这个品类的数据长什么样
锂离子电芯制造的设备点检与维修问答所依托的数据，来源涵盖原材料批次记录、车间MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室测试设备。数据更新频率覆盖每批电芯、单只电芯的实时生成节奏，日常业务文档包含配料记录、涂布辊压参数表、卷绕或叠片台账、注液记录、化成分容数据、OCV与安全测试报告。数据字段包含浆料配比、辊压厚度、环境露点值、内阻参数等专业电化学指标，且对水分含量、洁净度的记录精度要求极高。

## 这些特征在「部署与升级」这一环带来什么约束
该品类的数据多源分散、更新频率高且字段专业性强，对部署与升级环节带来多重约束。多源数据需要适配不同接入协议的存储配置，避免数据同步延迟；高频实时数据请求需要优化数据库连接池与缓存配置，防止服务过载；专业字段的识别需要预设匹配规则，确保问答系统能准确提取电芯制造相关的业务信息；同时，电化学体系对数据一致性要求高，部署时需配置严格的权限校验，防止非授权访问敏感测试数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://<管理员账号>:<密码>@<数据库地址>:<端口>/fastgpt?authSource=admin` | 适配多源实时的电芯制造数据存储，支持高并发读写需求 |
| `REDIS_URL` | `redis://:<密码>@<缓存地址>:<端口>/0` | 缓存实时露点监测、化成分容柜数据，降低核心数据库的访问压力 |
| `STORAGE_S3_ENDPOINT` | `按企业自有对象存储服务的接入地址填写` | 存储涂布辊压图像、OCV安全测试报告等大体积业务文档 |
| `DB_MAX_LINK` | `180–250 个连接` | 匹配每批次电芯产生的高频数据请求，避免数据库连接池耗尽 |
| `FILE_TOKEN_KEY` | `随机生成的32位无特殊字符字符串` | 保护上传的点检记录、配料文档的访问安全性 |
| `FE_DOMAIN` | `企业内部部署的前端访问域名` | 限定问答系统的前端访问来源，保障内部数据安全 |

## 容易做错的三处
- 现象：部署v2版本的marker组件后，日志显示ocr error。原因：未配置适配锂离子电芯制造文档的图像预处理参数，无法准确识别涂布辊压参数表、OCV安全测试报告中的专业字段与格式。
- 现象：新部署的环境启动后提示配置缺失报错。原因：未正确填写`MONGODB_URI`或`REDIS_URL`的连接信息，导致系统无法初始化核心数据存储与缓存模块。
- 现象：FastGPT v4.17.0版本新建知识库时无图片理解模型选项。原因：未在系统配置中启用图像识别插件开关，或未部署对应模型的依赖包。

## 怎么确认配好了
- 执行系统内置的健康检查脚本，确认`MONGODB_URI`、`REDIS_URL`等核心配置项的连接状态正常。
- 上传一份涂布辊压参数记录文档，验证问答系统能否正确提取浆料配比、辊压厚度等字段信息。
- 发起一条设备点检相关的查询，确认系统能返回匹配的配料记录、化成分容数据等业务内容。
- 检查前端访问域名`FE_DOMAIN`的配置，确认内部授权人员可正常访问问答系统界面。
