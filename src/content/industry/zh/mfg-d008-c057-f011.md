# 锻造与模锻的设备点检与维修问答：表单与交互

## 这个品类的数据长什么样
该品类数据来源包括原材料质保书、加热炉系统、压力机采集数据、MES系统、无损检测仪及客户锻件图。日常文档涵盖锻造工艺规程、下料卡、加热炉记录、锻造过程卡、模具寿命记录、热处理委托单、超声检测报告。数据更新以单件、每批或每炉次为节奏，字段包含锻件批次号、炉批号、模具磨损量（mm）、检测缺陷类型、工艺参数值（℃、MPa）等，对应单位随文档类型有所区分。

## 这些特征在「表单与交互」这一环带来什么约束
数据按单件、每批或每炉次更新的节奏，要求表单支持单次单批次数据录入，避免批量冗余操作。多类文档来源带来的字段差异，要求表单具备灵活的自定义字段配置能力，适配下料卡、加热炉记录等不同场景的参数录入。批次号与炉批号的强关联特性，要求表单内置关联校验逻辑，防止锻件批次与材料炉号错配，避免后续生产环节出现报废等问题。同时，不同设备点检场景的参数类型差异，需要表单支持文本、数值、枚举等多类型输入组件。

## 配置怎么定
以下配置基于 FastGPT v4.17.0 版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 表单字段分组 | 按点检场景拆分：加热炉点检组、压力机点检组、模具点检组 | 适配锻造与模锻多类日常文档的分类逻辑，简化录入流程 |
| `formInput` 输入组件类型 | 按字段属性匹配：数值型用数字输入框、枚举型用下拉选择框 | 适配不同参数的录入格式，降低输入错误率 |
| `userSelect` 知识库绑定规则 | 按数据来源分类绑定：原材料数据绑定原材料质保书知识库、加热数据绑定加热炉记录知识库 | 匹配数据来源与知识库的对应关系，提升召回精准度 |
| 单次录入条目上限 | 10 条/次 | 匹配每炉次或每批次的常规点检数据量，避免单次录入过载 |
| 批次关联校验 | 开启炉批号与锻件批次号联动校验 | 匹配锻件批次与材料炉号的强关联特性，防止数据错配 |
| 结果展示字段 | 显示缺陷类型、模具磨损量、工艺参数值 | 贴合设备点检与维修的核心关注内容，缩短信息获取路径 |

## 容易做错的三处
- 现象：在设备点检问答场景中，输入加热炉参数后召回了模具磨损的相关结果。原因：未按数据来源配置`userSelect`知识库绑定规则，错误将所有点检数据绑定到同一知识库。
- 现象：表单录入模具磨损量数值时出现输入限制报错。原因：未为数值型字段配置`formInput`对应的数字输入组件，误用了文本输入框。
- 现象：提交表单后批次号与炉批号不匹配的条目未被拦截。原因：未开启批次关联校验逻辑，未配置联动校验规则。

## 怎么确认配好了
- 进入表单配置界面，核对字段分组是否匹配加热炉点检、压力机点检、模具点检等场景，确认分组逻辑合理。
- 针对每个表单字段，检查输入组件类型是否与字段属性匹配，确认数值型参数使用数字输入组件。
- 查看知识库绑定配置，确认不同来源的点检数据已绑定到对应知识库。
- 提交测试数据，验证批次号与炉批号的关联校验是否正常触发。
