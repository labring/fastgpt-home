# 预拌混凝土生产的设备点检与维修问答：知识库检索与召回

## 这个品类的数据长什么样
预拌混凝土生产场景的数据来自工程订单、砂石水泥外加剂检验记录、骨料含水率测定数据、搅拌站控制系统日志、试验室试验报告。日常文档包含配合比通知单、开盘鉴定表、生产运输单、原材料检验报告、试块强度记录等，单份文档包含物料配比参数、含水率数值、搅拌时间、运输里程、浇筑部位等字段，单位涵盖千克、立方米、百分比、小时等。数据更新频率为每车生产批次、每批原料进场、每日试验室检测周期。

## 这些特征在「知识库检索与召回」这一环带来什么约束
数据更新频率高且粒度细，要求知识库检索需支持准实时召回最新的含水率、配比数据，避免使用过期参数。多源异构数据来自控制系统、试验室等不同系统，需统一字段映射规则，确保检索时能匹配设备点检、维修相关的关联信息。单份文档包含专业工程参数，检索时需精准匹配设备型号、维修工序对应的文档片段，避免无关内容干扰。试块强度报告等滞后性数据需单独设置召回权重，确保维修或点检时能关联历史强度异常记录。

## 配置怎么定
本配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.80 | 匹配专业工程参数的精准度要求，避免召回无关的通用维修文档 |
| `limit` | 前8条 | 覆盖单车生产的多维度参数，同时控制上下文长度 |
| `searchMode` | `mixedRecall` | 结合关键词与语义检索，适配专业术语与结构化参数的匹配 |
| `usingReRank` | 开启 | 对召回结果按相关性排序，筛选出与设备点检、维修直接相关的内容 |
| `datasetSearchUsingExtensionQuery` | 开启 | 扩展问题语义，补充混凝土生产相关的专业术语，提升召回覆盖度 |
| `collectionIds` | 绑定搅拌站设备库、试验文档库 | 限定检索范围，避免混入其他品类的维修数据 |

## 容易做错的三处
- 现象：AI对话中返回的答案未引用知识库内容，检索日志显示召回结果为空。原因：未正确绑定对应品类的`collectionIds`，检索范围覆盖了无关数据集。
- 现象：检索结果返回大量通用机械维修文档，无法匹配混凝土设备的专业参数。原因：`similarity`阈值设置过低，召回了低相关性内容。
- 现象：测试提问后回答延迟超过12秒，界面显示加载超时。原因：`limit`取值过高，导致召回的文档片段过多，超出模型上下文承载上限。

## 怎么确认配好了
- 进入FastGPT知识库管理页面，检查绑定的`collectionIds`是否包含搅拌站设备库、试验文档库。
- 输入测试问题“搅拌站主机轴承异响的维修方案”，查看检索结果是否优先返回对应设备的维修文档。
- 查看检索日志，确认`similarity`阈值范围内的召回结果数量符合预期，无过多无关内容。
- 上传最新的骨料含水率检测数据，模拟实时更新场景，验证检索时能否召回该最新数据。
