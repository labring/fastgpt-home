# PCB制造的质量问题追溯与不良分析：模型接入与配置

## 这个品类的数据长什么样
PCB制造的质量追溯数据来源包括客户Gerber文件、钻带、BOM清单、CAM解析记录、钻孔与层压设备参数、槽液化验结果、AOI检测报告、电测数据及切片分析报告。数据按生产批次、每班或连续采集更新，文档包含工程制作指示、工艺参数记录、检测报告等，核心字段涵盖图形层数、孔位坐标、蚀刻补偿值、导通测试结果等，部分文档需关联多批次生产记录以形成完整的质量追溯链。

## 这些特征在「模型接入与配置」这一环带来什么约束
PCB制造的多源、高频更新的专业数据，要求模型接入需支持长上下文处理以关联多批次生产记录。多样的文档类型（从纯参数表格到图文检测报告）要求配置适配多模态输入的参数。专业术语密集的字段（如蚀刻补偿、孔铜异常）要求模型配置匹配行业术语的prompt模板。高频采集的数据更新节奏，要求配置的上下文刷新参数适配实时或批次级的数据同步。部分检测报告存在长文本内容，需配置合理的文本切割规则以适配模型输入长度限制，避免调用失败。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本，适配国内部署的大模型接入场景。
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `maxContext` | 8000–12000 token | 适配多批次生产记录的关联查询，覆盖单批次完整工艺与检测数据 |
| `temperature` | 0.2–0.4 | 降低随机性，保证质量追溯结果的一致性，匹配专业分析的严谨性要求 |
| 工作流/API 工具选择配置 | auto | 允许模型自主选择工具，适配多源数据的关联分析需求 |
| `AIPROXY_API_ENDPOINT` | 按自建模型的部署地址填写，如`http://192.168.1.100:3000/v1` | 适配国内部署的模型，替代OpenAI官方端点，支持OneAPI接入的国内模型 |
| `AIPROXY_API_TOKEN` | 自建模型的访问密钥 | 用于身份验证，适配国内模型的接入要求 |
| `quoteMaxToken` | 1500–2000 token | 限制单条引用的文本长度，避免超出模型输入限制，适配AOI、电测报告的长文本内容 |

## 容易做错的三处
- 界面创建知识库时无法选择本地部署的ChatGLM2模型，提示未找到可用模型。原因是未在FastGPT配置文件中正确填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或OneAPI接入的模型未正确映射到FastGPT的模型列表。
- HTTP API返回的长检测报告无法分批次传入模型，出现输入长度超限报错。原因是未配置合理的文本切割规则，未将长文本按固定长度分段后逐段提交。
- 模型调用时工具无法触发，返回结果未包含预期的参数查询。原因是误将`toolChoice`参数设为false，或未在配置中开启函数调用支持。

## 怎么确认配好了
- 进入模型管理页面，查看已配置的模型列表，确认目标国内模型已正常显示，可点击测试调用验证连通性。
- 上传单份AOI检测报告的长文本内容，测试模型是否能正确提取异常点并关联对应批次的工艺参数，观察返回结果的完整性。
- 配置文本切割规则后，导入一份超过模型输入限制的长文档，验证系统是否自动分段并逐段处理，无长度超限报错。
- 查看模型调用日志，确认`maxContext`、`temperature`等参数的实际取值与配置一致，无默认参数覆盖的情况。
