# SMT贴片与电子组装的质量问题追溯与不良分析：工具调用与插件

## 这个品类的数据长什么样
SMT贴片与电子组装的质量追溯数据主要来自客户提供的BOM与坐标文件、换线表、钢网记录，以及MES系统、贴片机、SPI/AOI检测设备、回流焊炉温记录、追溯标签与维修档案。数据更新频率为每工单、每次换线触发更新，部分检测数据为实时同步。单工单数据包含料号、位号、替代料、元件批次号、贴装坐标、缺陷类型、温度曲线等字段，坐标单位为毫米，炉温单位为摄氏度，批次号为字符串格式。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据分散在多系统与设备中，工具调用需要对接多个数据源插件，才能完成全流程的质量数据拉取。数据更新频率短且实时性要求高，工具调用需支持短周期触发，避免因数据滞后导致追溯结果不准确。文档字段存在明确的格式与单位要求，工具调用的参数提取环节需匹配料号、坐标等特定字段，无法泛化处理。同时，质量追溯的核心环节为核对料号与缺陷数据，工具调用需自动完成多文档的字段比对，减少人工操作耗时。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 适配SMT多数据源插件的自动调用需求，FastGPT v4.17.0版本支持该参数的全功能配置 |
| `functionCall` | 开启强制参数校验 | 确保提取的料号、坐标等字段符合SMT文档的格式与单位要求 |
| 单次工具调用超时时间 | 60–120秒 | 覆盖从MES、SPI/AOI设备拉取单工单数据的平均耗时 |
| 工具调用返回结果上限 | 前10条 | 匹配单工单的缺陷记录与数据条目数量，避免冗余信息干扰分析 |
| 用户输入确认开关 | 开启 | 匹配SMT工单的质量审核流程，避免误调用插件执行批量操作 |
| 上下文窗口大小 | 8000–12000 token | 容纳BOM、炉温记录等多文档的完整内容，支持跨文档比对分析 |

## 容易做错的三处
- 现象：工具调用返回的料号、坐标字段为空。原因：未开启`functionCall`的强制参数校验，提取的字段未匹配SMT文档的格式要求。
- 现象：工具调用触发超时报错（状态码504）。原因：设置的超时时间过短，未覆盖多设备拉取数据的总耗时。
- 现象：插件执行后未弹出用户输入确认弹窗。原因：未开启用户输入确认开关，直接执行了插件调用，不符合SMT工单的审核流程要求。

## 怎么确认配好了
- 上传一份测试用的BOM文件与SPI检测报告，触发工具调用，检查返回结果是否包含料号、位号、缺陷坐标等预期字段。
- 模拟单次工具调用，查看系统返回的耗时是否在设定的超时时间范围内，确认无超时报错。
- 触发插件调用流程，检查是否弹出用户输入确认弹窗，确认审核环节已生效。
- 测试多插件依次调用场景，检查是否能依次拉取MES系统与贴片机的数据，返回完整的工单追溯信息。
