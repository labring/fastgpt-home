# 乳制品加工的质量问题追溯与不良分析：多轮对话与提示词

## 这个品类的数据长什么样
乳制品加工的数据覆盖原奶验收、生产全流程与留样检测环节，来源包括奶源检测设备、生产MES系统、均质与热处理设备、在线温流量采集模块、CIP清洗系统、LIMS实验室管理系统。数据更新节奏为每奶罐、每批实时同步，日常文档包含原奶验收记录、标准化配料单、巴氏或UHT热处理记录、CIP清洗记录、灌装操作记录、留样与微生物检测报告，字段包含抗生素残留数值、热处理温度与时长、CIP清洗参数、菌落检测结果等，带明确物理单位。

## 这些特征在「多轮对话与提示词」这一环带来什么约束
乳制品加工的实时性、批次强关联特性，要求多轮对话需绑定`chatId`锁定单批次生产数据，避免跨批次混淆。数据更新频率高且字段带单位，提示词需要求AI严格匹配文档字段与单位，禁止模糊表述。液态原料易腐的特性要求对话响应不能过长，需限制上下文长度，避免因历史数据冗余导致检索偏差。多源数据分散在不同系统，提示词需明确指定检索范围为对应批次的全流程文档，防止跨环节数据混用。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `chatId` | 绑定当前生产批次的唯一标识 | 确保多轮对话仅检索该批次的原奶、生产与检测数据，避免跨批次混淆 |
| `messages` | 保留前10条对话上下文 | 乳制品加工数据更新快，过长上下文易引入无关批次信息，10条可平衡上下文完整性与检索精度 |
| 单次搜索上限 | 前8条匹配结果 | 单批次生产文档数量有限，过多结果会增加AI处理负担 |
| 问题优化 | 按实测标定 | 需适配原奶、热处理、CIP等不同环节的专业术语，避免检索偏差 |
| 最大上下文 | 1200–1500 字符 | 液态乳制品生产流程短，单批次文档总字符量可控，该区间可覆盖核心检索数据且避免冗余 |
| `variables` | 传入当前批次的生产时间范围 | 辅助知识库检索精准定位对应批次的文档，提升召回准确性 |

## 容易做错的三处
- 现象：调用对话接口时，检索到知识库图片地址后返回「未找到答案」。原因：未在提示词中明确指定仅检索文本类文档，或配置中未过滤非文本检索结果。
- 现象：短时间内连续发送两个对话请求，后发起的请求未得到及时响应。原因：未配置对话中断机制，前一个请求的会话未释放，导致新请求排队等待。
- 现象：尝试修改或删除对话记录时返回「没有权限操作此对话记录」。原因：未在`variables`中传入当前会话的归属用户或批次标识，导致权限校验失败。

## 怎么确认配好了
- 发起单批次原奶抗生素检测的多轮对话，核对返回结果仅包含该批次的原奶验收与微检文档数据。
- 连续发送两个不同批次的查询请求，核对后发起的请求可快速得到响应，无排队等待情况。
- 尝试操作不属于当前会话的对话记录，核对是否返回权限错误，确认权限校验逻辑生效。
- 检索包含「巴氏杀菌温度」的专业问题，核对返回结果匹配对应批次的热处理记录参数与单位。
