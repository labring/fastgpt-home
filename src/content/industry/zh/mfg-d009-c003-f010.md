# 乳制品加工的质量问题追溯与不良分析：知识库检索与召回

## 这个品类的数据长什么样
乳制品加工的业务数据覆盖液态奶、酸奶、奶粉及乳配料生产全流程，日常文档包括原奶验收记录、标准化配料单、巴氏或UHT热处理记录、CIP清洗记录、灌装记录、留样与微检报告。数据来源涵盖奶源检测系统、MES生产系统、均质及热处理设备、在线温度流量监测、CIP系统、LIMS实验室管理系统。数据更新频率为每奶罐、每批实时同步，字段包含原奶抗生素/理化指标、热处理时间温度、CIP清洗参数等，且为液态生物原料，需按批次严格隔离追溯。

## 这些特征在「知识库检索与召回」这一环带来什么约束
乳制品加工的实时批次化数据特征，要求知识库检索必须支持按生产批次精准过滤，避免跨批次数据干扰。多类型文档的混合存储，要求检索同时覆盖结构化字段（如原奶指标数值）和非结构化流程描述（如CIP操作步骤）。数据更新频率高，要求检索索引能快速同步最新的原奶验收、微检报告等文档。液态原料易腐且需严格隔离的特性，要求检索结果必须精准绑定当前批次，不能混入其他批次的异常数据，同时需快速响应以支撑现场不良分析的时效性需求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `similarity` | 0.75–0.85 | 匹配原奶验收记录的抗生素、理化指标等结构化字段，兼顾精准度和召回覆盖 |
| `limit` | 前8条 | 每批乳制品生产对应的关联文档通常不超过8份，避免冗余信息干扰不良分析 |
| `searchMode` | vector + keyword | 同时匹配文本关键词（如“巴氏杀菌温度”）和向量语义（如合规清洗流程），适配多类型业务文档 |
| `usingReRank` | 开启 | 对召回的文档按业务相关性重排，优先匹配热处理时间、CIP流程等关键分析字段 |
| `datasetSearchUsingExtensionQuery` | 开启 | 扩展检索范围，覆盖留样微检报告的批次关联数据，提升追溯准确性 |
| `collectionIds` | 按生产批次绑定的知识库集合 | 精准限定检索范围，避免跨批次数据干扰当前批次的不良分析 |

## 容易做错的三处
- 现象：检索结果未显示docx格式文档中的内嵌图片。原因：未开启知识库的图片识别配置，未将图片解析器绑定到对应知识库集合。
- 现象：检索返回的关联文档条数远低于预期。原因：`similarity`阈值设置过高，或`limit`取值偏小，未覆盖当前批次的全部必要业务文档。
- 现象：无法调用maker工具完成图片解析。原因：未在知识库配置中开启maker工具关联，未正确配置图片解析器的调用权限。

## 怎么确认配好了
- 上传一份带内嵌图片的原奶验收记录docx文档到目标知识库，发起检索关键词“原奶抗生素检测结果”，确认结果中包含文档内的图片内容。
- 查看知识库配置页面，确认`usingReRank`、`datasetSearchUsingExtensionQuery`处于开启状态，`similarity`阈值设置在0.75–0.85区间。
- 发起针对特定生产批次的检索，确认返回结果仅包含该批次对应的CIP记录、灌装记录等文档，无跨批次数据混入。
- 测试检索响应时长，确认符合现场不良分析的实时性要求，调整相关配置以优化响应速度。
