# 光伏电池片制造的质量问题追溯与不良分析：工具调用与插件

## 这个品类的数据长什么样
光伏电池片制造的生产数据来源涵盖硅片来料检测记录、车间MES系统、扩散炉/镀膜设备/印刷机的运行参数、EL缺陷检测图、IV电性能测试数据及实验室良率报告。数据更新节奏分为每片级检测、每批次同步、每日汇总三类，文档结构包含结构化的工艺参数表、非结构化的可视化检测图，字段包含批次唯一标识、片号、扩散温度、镀膜厚度、转换效率、隐裂坐标等。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源异构的数据结构要求工具调用需同时支持结构化参数拉取与非结构化图片解析；片级、批次级的高频更新节奏，要求工具触发需绑定批次号与片号作为唯一标识，避免跨批次数据混淆；跨部门协同的追溯需求，要求插件可同步调用工艺、设备、品质三类数据源的接口；实时缺陷识别的场景，需支持异常触发与固定定时的调用逻辑，适配不同质量监控的节奏要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工具调用触发时机 | 按批次号+片号触发，或每10分钟定时拉取 | 匹配光伏电池片的片级追溯与每日汇总的生产节奏 |
| `toolChoice` | 自动选择（auto） | 适配多类型数据源的插件调用，无需手动指定工具函数 |
| 插件超时时间 | 600 秒 | 覆盖设备数据拉取、EL检测图OCR解析的平均耗时 |
| 参数传入规则 | 从工作流变量获取批次号、片号，缺失则使用默认空值 | 适配生产数据的实时传入与异常场景 |
| 结果返回条数 | 前 10 条 | 匹配单批次的追溯数据量，避免上下文溢出 |
| 结果缓存时长 | 24 小时 | 匹配每日良率报告的更新汇总节奏，避免重复拉取历史数据 |

本文基于FastGPT v4.17.0版本配置。

## 容易做错的三处
- 跨域配置错误，现象为浏览器调用插件API返回403或CORS相关报错，原因是未在FastGPT的插件配置中添加企业生产系统的内网或公网域名白名单。
- `functionCall`参数配置不当，现象为插件无法正确解析EL检测图的隐裂坐标，原因是未指定调用的工具函数为图片OCR与缺陷识别模块。
- 参数 fallback 逻辑缺失，现象为当MES系统数据未同步时插件返回空字段，原因是未配置从默认值或备用数据源获取参数的逻辑。

## 怎么确认配好了
- 传入测试用的批次号与片号，触发工具调用，检查是否拉取到对应批次的扩散参数、EL检测图与IV测试数据。
- 查看FastGPT的插件调用日志，确认`toolChoice`参数已正确设置为自动适配多工具。
- 模拟MES数据未同步的场景，检查插件是否返回默认占位值或触发备用数据源获取数据。
- 验证跨域配置，使用企业内网浏览器调用插件接口，确认无CORS相关报错。
