# 光伏电池片制造的质量问题追溯与不良分析：知识库检索与召回

## 这个品类的数据长什么样
光伏电池片制造的业务数据来源包括硅片来料记录、生产MES系统、扩散炉/镀膜设备/印刷机的运行参数、EL与IV测试结果、实验室工艺文档。数据更新节奏为每生产批次同步、单硅片检测实时更新、每日汇总良率报告。日常文档包含工艺卡、扩散与镀膜参数表、印刷烧结记录、EL检测图、IV分档数据、良率分析报告，字段涵盖工艺温度、沉积时间、电性能转换效率、缺陷类型等，单位涉及摄氏度、秒、瓦等。本页面的配置参考FastGPT v4.17.0版本的功能逻辑。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据兼具结构化参数与非结构化检测图文，且更新频率覆盖批次、单硅片、日度多个维度，要求检索系统同时支持精准字段匹配与全文内容召回。跨工序的工艺关联需求，需要检索系统能够打通制绒、扩散、钝化、印刷等环节的历史数据。单批次数据量较大，需限制召回结果的范围以避免上下文溢出，同时需按设备、批次等维度进行数据隔离，防止无关数据干扰召回精度。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 匹配工艺参数与缺陷记录的精准度需求，过滤低相关性的召回结果 |
| `limit` | 前8条 | 覆盖单批次光伏电池片的典型工艺关联条目，控制上下文长度 |
| `searchMode` | `mixedRecall` | 兼顾结构化参数字段与非结构化EL检测图、良率报告的内容匹配 |
| `usingReRank` | 开启 | 优化召回结果的排序逻辑，提升与当前查询的相关性 |
| `datasetSearchUsingExtensionQuery` | 开启 | 补充批次号、设备型号等上下文信息，优化检索关键词的召回精度 |
| `collectionIds` | 按业务分组配置 | 隔离硅片来料、设备运行、检测数据等不同类别的知识库数据 |

## 容易做错的三处
- 导入知识库数据时触发训练报错，现象为界面弹出格式错误提示，原因是混用了旧版本导出的csv模板与当前版本的字段结构，未完成格式适配。
- 重排功能在大模型对话中无法生效，现象为API调用返回的结果未按相关性排序，仅在知识库测试页面可正常使用，原因是未在大模型配置中关联启用`usingReRank`参数，仅单独配置了知识库检索的重排选项。
- 知识库搜索的引用上限无法调整，现象为返回结果条数固定且不符合业务需求，原因是未正确配置`limit`参数的取值，或误将其与其他召回参数混淆。

## 怎么确认配好了
- 上传单条扩散炉温度参数记录，执行检索后查看召回结果是否包含关联的EL检测缺陷数据。
- 调用API检索指定设备的历史工艺数据，确认返回结果的条数与配置的`limit`取值一致。
- 测试添加批次号作为检索关键词，验证召回结果是否仅包含对应批次的知识库数据。
- 开启`usingReRank`参数后，对比检索前后的结果排序，确认相关性更高的条目排在前列。
