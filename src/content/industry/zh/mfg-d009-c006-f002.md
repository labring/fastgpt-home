# 光伏组件封装的质量问题追溯与不良分析：向量模型与索引

## 这个品类的数据长什么样
光伏组件封装环节的数据来自电池片分档、玻璃胶膜背板批次、MES系统、串焊与层压设备、EL/IV测试仪、绝缘耐压测试设备。日常文档包含排版图、材料批次记录、层压工艺记录、EL缺陷图、IV测试报告、绝缘耐压记录、包装清单。数据更新频率为每块组件产出一次，每批材料入库一次。数据字段包含电池片电流档位、层压温度压力参数、EL隐裂位置、IV测试功率值、绝缘耐压数值等，覆盖工艺与测试全流程。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据类型覆盖结构化工艺参数、非结构化测试报告与图像配套文本，且更新频率极高，每块组件对应独立的业务数据单元。不同于电池片制造的半导体表面工艺，该品类更关注层压工艺与功率分档的关联，因此索引需重点关联层压参数与IV测试结果。这要求向量索引需支持按业务单元拆分数据，避免跨批次或跨组件的数据混合。同时，数据字段多为精度敏感的数值与批次标识，嵌入与召回环节需保证匹配精度，不能丢失关键的批次关联信息。此外，数据来源分散在多套设备与系统中，向量索引需兼容多格式数据源的接入，确保不同类型的文档都能被正确嵌入与检索。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| 分块长度 | 800–1200 字符 | 适配光伏组件工艺记录、EL图配套文本的典型长度，避免跨业务单元拆分 |
| 重叠长度 | 100–150 字符 | 保证工艺参数与测试数据的连续性，防止关键关联信息断裂 |
| 相似度阈值 | 0.75–0.85 | 匹配电池片电流档位、层压参数的精度需求，过滤无关召回结果 |
| 单次搜索上限 | 前 10 条 | 对应单批组件的关联数据规模，避免冗余召回影响检索效率 |
| `maxToken` | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| `defaultToken` | 1500 token | 匹配单条工艺记录的典型长度，保证嵌入模型的处理效果 |

## 容易做错的三处
- 现象是调用嵌入模型接口返回404错误，原因是未正确配置嵌入模型的API端点与密钥，或使用了不被支持的模型标识。
- 现象是在无GPU的硬件环境中无法加载向量模型服务，原因是未选用适配CPU运行的轻量嵌入模型，或未正确配置CPU运行的相关参数。
- 现象是向量索引召回的关联数据与目标组件不匹配，原因是分块时未按单块组件的完整业务数据单元拆分，导致不同批次的工艺记录被混合到同一索引块中。

## 怎么确认配好了
- 查看嵌入模型的调用日志，确认每次请求都能返回合法的向量数据，无报错状态码。
- 手动输入单块组件的典型工艺参数或测试数据，核对召回的关联文档是否属于同一业务环节与批次。
- 调整相似度阈值，验证召回结果的匹配精度是否符合预设的业务标准。
- 检查索引的更新配置，确认其刷新频率与组件的产出更新节奏保持一致。
