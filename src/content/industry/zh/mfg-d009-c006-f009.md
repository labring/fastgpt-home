# 光伏组件封装的质量问题追溯与不良分析：模型接入与配置

## 这个品类的数据长什么样
光伏组件封装的质量追溯数据来源包括电池片分档记录、玻璃胶膜背板批次台账、车间MES系统、串焊与层压设备日志、EL缺陷检测图、IV功率测试报告、绝缘耐压记录与成品包装清单。数据更新频率为每块组件生成独立关联数据集，每批次材料同步更新批次台账。单份数据集包含结构化工艺参数、非结构化图像与文本报告，字段涵盖电池片电流档位、层压温度时间、隐裂坐标、功率数值等，需跨源关联匹配。

## 这些特征在「模型接入与配置」这一环带来什么约束
跨源异构的多格式数据要求模型接入需支持多模态输入，适配EL图等图像类文档解析。单块组件的数据集更新频率高，需限制上下文窗口大小以避免处理延迟过高，影响实时追溯效率。结构化字段的精准匹配需求要求模型输出需具备较高确定性，同时需适配企业内部网络隔离环境，保证敏感生产数据传输安全。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `vision` | 开启 | 光伏组件封装数据包含EL缺陷图、IV测试曲线等图像类文档，需模型支持图像解析以完成缺陷定位 |
| `maxContext` | 8000–12000 token | 单块组件关联的批次记录、设备日志、测试报告总token量适中，该区间可覆盖全量关联数据且避免上下文溢出 |
| `maxTokens` | 2000–3000 token | 单次不良分析的输出需覆盖缺陷定位、原因追溯、整改建议，该区间可保证输出完整性 |
| `temperature` | 0.1–0.3 | 质量追溯需精准匹配工艺参数与缺陷关联，较低温度可减少输出随机性，提升结论可信度 |
| `AIPROXY_API_ENDPOINT` | 填写FastGPT部署的企业内部代理接口地址 | 适配车间网络隔离环境，保证敏感生产数据传输安全 |
| `AIPROXY_API_TOKEN` | 填写企业专属代理鉴权令牌 | 用于接口身份验证，限制未授权访问模型服务 |

## 容易做错的三处
- 现象：第三方代理平台配置后，FastGPT界面无渠道选项，或测试请求报错401未授权。原因：未正确填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或代理接口未适配FastGPT的调用格式。
- 现象：EL图或DOC文档上传后无法触发分析，或解析结果出现乱码。原因：未开启`vision`配置，模型无法处理图像或非标准格式的文本文档。
- 现象：模型输出的思考过程引用片段排版混乱，或出现冗余无关内容。原因：未合理设置`maxContext`与`quoteMaxToken`，导致上下文窗口过大，引入过多非关联数据。

## 怎么确认配好了
- 在FastGPT v4.17.0版本中，上传单份EL缺陷图与对应批次的工艺记录，发起不良分析测试请求，检查模型是否能正确识别隐裂位置并关联对应电池片批次参数。
- 查看模型输出的思考过程片段，确认引用内容与当前分析任务相关，排版无混乱或冗余。
- 查看接口调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置无格式错误，无连接超时或鉴权失败报错。
- 调整`temperature`参数至0.2与0.3，对比两次输出的缺陷匹配结果，确认参数调整对输出确定性的影响符合预期。
