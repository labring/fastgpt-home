# 化学药制剂生产的质量问题追溯与不良分析：模型接入与配置

## 这个品类的数据长什么样
化学药制剂生产的业务数据来自经批准的处方工艺、物料批次台账、MES系统、电子批记录、设备与环境监测数据、LIMS实验室管理系统、质量管理系统。日常关联文档包括主生产文件、批生产记录、批包装记录、清场记录、检验记录、偏差与CAPA文件、变更记录、批放行审核表。数据更新节奏为每生产批次一次、关键工艺步骤触发更新，同时按固定监测计划更新设备环境监测数据。数据字段包含物料批号、工艺参数值、检验结果、偏差描述、放行状态等，无额外非生产类附加字段。

## 这些特征在「模型接入与配置」这一环带来什么约束
化学药制剂生产的批次关联数据结构固定且覆盖多类文档，要求模型接入时配置足够的上下文长度以容纳单批完整文档。多系统来源的数据格式存在差异，要求配置的模型支持多源数据的统一解析。按批次和关键步骤更新的数据需要快速响应生产环节的操作窗口，要求模型调用的响应时长适配业务节奏。GMP合规要求下的数据需可追溯，因此配置时需开启支持引用溯源的相关参数。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配单批完整文档的总token长度，避免截断关键批记录内容 |
| `temperature` | 0.1–0.3 | 确保分析结果的严谨性，符合数据一致性要求 |
| `quoteMaxToken` | 2000 字符 | 限定单条引用文档的长度，避免上下文过载 |
| `vision` | 开启 | 支持解析批记录中的设备参数截图、称量记录图片等非文本数据 |
| `AIPROXY_API_ENDPOINT` | 按部署的大模型服务填写 | 适配国内大模型的接入地址，满足合规要求 |
| `AIPROXY_API_TOKEN` | 按授权密钥填写 | 完成模型调用的身份验证，保障数据访问安全 |

## 容易做错的三处
- 现象为界面下拉列表中无通义千问等国内大模型选项，原因是未配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或未在平台中添加对应大模型的接入映射。
- 现象为调用模型返回参数不兼容或格式错误提示，原因是未根据批记录的文本长度调整`maxContext`的取值，或未开启`vision`参数适配图片类生产数据。
- 现象为导入OneAPI地址和密钥后无法触发模型调用，原因是未将OneAPI的接入地址正确填入`AIPROXY_API_ENDPOINT`配置项，或密钥未绑定目标模型的调用权限。

## 怎么确认配好了
以下核对动作适配FastGPT v4.17.0版本。
- 检查`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的填写是否与部署的大模型服务一致，可通过平台自带的测试接口验证连通性。
- 测试输入单批批记录的文本片段，查看模型返回的分析结果是否包含对应字段的解析内容。
- 开启`vision`参数后，上传一张设备参数截图，验证模型是否能正确识别图片中的文本信息。
- 配置`maxContext`为8000 token后，输入超过该长度的文本，查看模型是否正常截断或提示上下文溢出。
