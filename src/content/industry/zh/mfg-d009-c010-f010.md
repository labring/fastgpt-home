# 医疗器械装配与洁净生产的质量问题追溯与不良分析：知识库检索与召回

## 这个品类的数据长什么样
该品类数据涵盖一次性耗材、植介入器械、诊断设备及有源器械的生产全流程文档，包括生产工艺规程、批生产记录、洁净区环境记录、灭菌批记录、检验报告、软件版本记录与不良事件追溯资料。数据来源覆盖设计历史文件、器件与材料批次台账、MES系统、洁净环境监测设备、灭菌设备及检验校准系统，更新节奏为每生产批次或单台设备完成后更新，同时按固定环境监测计划同步更新洁净区相关数据，数据包含批次号、唯一器械标识、环境监测参数、检验结果等结构化字段与非结构化文档内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的多源混合数据结构与强关联属性，对知识库检索召回带来明确约束。需支持按批次号、唯一器械标识等精准字段过滤召回结果，避免匹配到无关生产批次的数据。混合结构化台账与非结构化文档的数据源，需适配不同格式的召回规则，确保两类数据均可被有效检索。按批次或固定环境监测计划更新的数据，需支持增量同步机制，避免全量检索时重复加载过期数据。不良事件追溯资料需与对应生产批次强绑定，检索时需自动关联召回该批次的全链路生产与检验文档，保障追溯过程的完整性与准确性。

## 配置怎么定
FastGPT v4.17.0版本适配以下配置：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 匹配医疗器械批次、唯一标识等强关联字段，过滤低置信度结果，保障追溯准确性 |
| `limit` | `前10条` | 覆盖单批次生产相关的多类文档，同时控制上下文长度，避免超出业务响应阈值 |
| `searchMode` | `混合检索` | 适配结构化台账与非结构化文档混合的数据源，兼顾精准字段匹配与语义关联召回 |
| `usingReRank` | `开启` | 提升不良事件追溯资料与生产批次的关联排序准确性，适配高风险场景的检索需求 |
| `datasetSearchUsingExtensionQuery` | `开启` | 自动扩展批次号、唯一器械标识等字段的检索词，覆盖多源关联的生产与检验数据 |
| `collectionIds` | `指定洁净生产与质量追溯专属数据集ID` | 隔离其他品类数据，避免检索到无关文档，缩小检索范围提升效率 |

## 容易做错的三处
- 现象为通过API上传含中文名称的知识库文件时，返回乱码文件名或文件解析失败。原因是未在API请求头中正确配置字符编码参数，导致中文文件名无法被正确解析。
- 现象为知识库检索结果条数与预期不符，仅返回少量关联文档。原因是未正确设置`limit`参数取值，或未开启`datasetSearchUsingExtensionQuery`导致未覆盖关联字段检索。
- 现象为单次检索耗时过长，对话响应延迟。原因是未开启`usingReRank`且未限制`limit`参数取值，导致加载过多无关文档进入上下文，增加处理负担。

## 怎么确认配好了
- 上传含中文名称的测试文件至指定数据集，确认文件名在知识库列表中正常显示无乱码。
- 输入已知批次号或唯一器械标识作为检索词，核对返回结果包含对应批次的生产记录、检验报告等关联文档。
- 执行多次检索操作，查看响应耗时，调整`limit`或`usingReRank`配置，优化检索速度。
- 检查检索结果的数据集范围，确认未召回非该品类的无关文档。
