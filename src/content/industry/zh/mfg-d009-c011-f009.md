# 半导体封装测试的质量问题追溯与不良分析：模型接入与配置

## 这个品类的数据长什么样
该品类的数据涵盖封装流程卡、键合与塑封参数、晶圆来料图、测试程序版本、良率报告、失效分析报告等文档，数据来源包括晶圆测试图、MES系统、键合机与塑封设备、ATE测试机、X-ray/SAM检测设备及客户规格要求。数据更新频率为每生产批次、每颗芯片测试节点及每日更新，字段包含批次号、测试bin值、键合温度、塑封压力、失效类型等，无统一固定单位，随设备参数与检测项变化。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类多源异构的数据源与高频更新节奏，要求模型接入配置需适配多文档拼接与实时数据调用。批次号、测试bin值等无统一单位的字段，要求配置中需支持模型识别带单位的设备参数并关联对应检测记录。高频的单颗测试与每日更新数据，要求模型调用的响应时长匹配生产节拍，避免延迟影响产线流程。同时，需对齐晶圆图与实物批次的关联要求，配置需确保知识库召回能精准匹配批次关联的全链路文档。本页配置基于FastGPT v4.17.0版本。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | 8000–12000 token | 适配封装流程卡、失效分析报告等多文档拼接的上下文长度需求 |
| `maxTokens` | 4000 token | 匹配单颗芯片测试数据与失效分析的输出长度限制 |
| `quoteMaxToken` | 2000 token | 确保召回的晶圆测试图、ATE测试记录等文档片段不超出上下文配额 |
| `temperature` | 0.2–0.4 | 降低输出随机性，保证质量追溯分析的结论一致性 |
| `AIPROXY_API_ENDPOINT` | 按部署节点实际地址填写 | 适配企业内部网络的代理访问配置 |
| `AIPROXY_API_TOKEN` | 按授权凭证填写 | 完成模型渠道的身份验证 |

## 容易做错的三处
- 现象：调用模型时返回代理连接超时错误，状态码502。原因：未正确配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或代理节点未开放对应端口。
- 现象：模型返回内容中包含完整的prompt思考过程片段。原因：未按要求关闭模型的内部思考输出开关，导致冗余内容混入返回结果。
- 现象：模型渠道调用时出现随机失败，无固定报错信息。原因：未配置合理的负载均衡规则，导致单节点过载无法响应请求。

## 怎么确认配好了
- 填写`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`后，发起一次测试调用，确认返回正常的质量追溯分析结果，未出现报错。
- 上传一份封装流程卡与对应批次的测试数据，验证模型召回的文档片段数量符合配置要求。
- 设置`temperature`为0.3后，两次调用同一测试prompt，确认输出结果的差异在可接受范围内。
- 配置`maxContext`后，拼接多份长文档发起调用，确认未出现上下文溢出报错。
