# 半导体晶圆制造的质量问题追溯与不良分析：HTTP 接口与外部系统

## 这个品类的数据长什么样
该品类的数据来源包括晶圆厂MES系统、设备FDC采集模块、缺陷检测与量测设备、工艺配方库与实验数据库。日常文档涵盖工艺流程卡、批次运行记录、设备配方、SPC控制图、异常处置单、缺陷图谱与良率报告。数据更新节奏覆盖每批晶圆流转节点、实时设备参数上报、每日汇总统计。字段包含晶圆批次标识、工艺节点参数、缺陷空间坐标、设备运行时序数据，单位涉及纳米、埃、毫秒等精密计量尺度。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
该品类的多源异构数据、高频更新与精密计量特征，对HTTP接口提出多重约束。多源对接需求要求接口支持跨系统身份校验，需配置安全的鉴权规则。精密字段与大体积文件类数据（如晶圆图、缺陷图谱）要求接口支持二进制流与结构化参数混合传输，避免数据截断。多更新节奏并存的场景，要求接口同时适配单次批量请求与实时回调模式，需支持按业务维度筛选数据。跨工序追溯的需求要求接口返回完整的关联数据链路，需规范返回字段的覆盖范围。

## 配置怎么定
本配置适用于FastGPT v4.17.0版本。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 鉴权配置 | 启用Bearer Token鉴权，`Authorization`参数填写有效期12 小时的令牌 | 适配晶圆厂跨系统对接的安全要求，避免令牌泄露风险 |
| 请求参数配置 | 通过`variables`绑定晶圆批次号、设备ID为核心筛选条件，单次请求参数不超过20 个 | 匹配晶圆制造数据按批次与设备组织的特征，减少冗余数据传输 |
| 响应数据配置 | 配置`responseData`返回完整关联字段，包含异常处置单、缺陷图谱的标识 | 满足质量追溯的跨环节关联查询需求 |
| 超时时间 | 600 秒 | 适配晶圆批次数据的复杂查询处理时长 |
| 文件传输上限 | 1000 MB | 适配晶圆图、缺陷图谱等大体积文件的传输需求 |
| 重试次数 | 3 次 | 降低实时设备数据上报时的网络波动影响 |

## 容易做错的三处
- 现象：调用HTTP接口上传markdown格式的晶圆工艺文档时返回400状态码，文件字段为空。原因：未正确配置请求头的Content-Type为application/markdown，或未通过`variables`参数绑定文件流与业务标识。
- 现象：批量调用接口同步多台设备的FDC数据时，返回数据库执行错误，提示多行语句不支持。原因：未关闭接口调用的单行查询限制，导致批量SQL语句被拦截。
- 现象：调用质量追溯接口时，返回的结果未包含关联文档的引用标识，无法展示来源信息。原因：未在`responseData`中配置返回异常处置单、缺陷图谱的关联字段。

## 怎么确认配好了
- 携带配置的鉴权参数调用接口，返回200状态码则鉴权配置正常。
- 上传单份晶圆缺陷图谱文件，检查接口返回的文件ID与业务标识匹配，无格式截断或数据丢失。
- 发起批量设备数据查询请求，检查返回结果条数与预设的筛选条件一致，无冗余或缺失字段。
- 调用质量追溯接口，检查返回结果中包含关联文档的标识信息，可用于后续引用来源展示。
