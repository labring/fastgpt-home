# 半导体晶圆制造的质量问题追溯与不良分析：向量模型与索引

## 这个品类的数据长什么样
半导体晶圆制造的质量追溯数据来源包括MES系统、设备FDC数据、缺陷检测与量测设备输出、晶圆图、工艺配方库与实验数据。日常文档涵盖工艺流程卡、批次运行记录、设备配方、SPC图、异常处置单、缺陷图谱与良率报告。数据更新频率为每批晶圆、实时或每日，字段包含纳米级工艺参数、晶圆批次号、缺陷坐标与设备运行参数，文档长度差异较大。

## 这些特征在「向量模型与索引」这一环带来什么约束
超长的工艺链与多源异构数据特征，要求向量模型支持跨工序、跨设备的语义关联检索；实时与高频更新的数据，需要适配增量索引机制以避免全量重建的性能损耗；纳米级工艺参数与缺陷空间分布的精细分析，要求分块粒度足够小以保留局部特征；有限的返工窗口则要求检索延迟控制在合理范围，支撑快速决策。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 匹配晶圆工艺卡单段工序的描述长度，避免跨工序语义断裂 |
| 重叠长度 | 150–200 字符 | 覆盖工序间的衔接参数，防止分块丢失关联逻辑 |
| `maxToken` | 8192 token | 适配多源文档拼接后的总长度，兼容工艺配方库的长文本 |
| `defaultToken` | 2048 token | 适配单条异常处置单的文本长度，满足基础语义召回 |
| 相似度阈值 | 按实测标定 | 匹配缺陷图谱的特征匹配精度需求 |
| 单次搜索上限 | 前 10 条 | 平衡召回效率与跨工序归因的信息完整性 |

## 容易做错的三处
- 配置豆包嵌入模型API时返回404错误，原因是未正确填写平台分配的专属API域名，导致请求路由错误。
- 批量重新嵌入知识库后召回率无改善，原因是未针对晶圆数据的纳米级参数调整分块长度，导致语义分块失效。
- 手动插入的知识库条目对应的索引数小时后消失，原因是未开启增量索引的持久化存储，导致临时索引被自动清理。

## 怎么确认配好了
- 导入单份晶圆缺陷图谱文档，检查分块后的文本片段是否覆盖完整的缺陷描述与对应工序信息。
- 发起包含工艺参数与缺陷类型的查询，确认返回的搜索结果包含跨设备、跨工序的关联数据。
- 查看FastGPT v4.17.0的系统日志，确认嵌入请求的状态码均为200，无超时或路由错误。
- 手动触发一次批量重嵌入任务，检查知识库的向量索引更新进度条是否正常推进。
