# 半导体晶圆制造的质量问题追溯与不良分析：模型接入与配置

## 这个品类的数据长什么样
这个品类的数据来源包括晶圆厂MES系统、设备FDC监控模块、缺陷检测与量测设备、工艺配方库与实验数据集。日常文档涵盖工艺流程卡、批次运行记录、设备配方参数、SPC控制图、异常处置单、晶圆缺陷图谱与良率报告。数据更新节奏随每批晶圆流转、设备实时采集与每日汇总同步。数据字段包含纳米级工艺参数、晶圆批次ID、缺陷空间坐标、设备运行时长与配方调整记录，单位涵盖纳米、帕斯卡、安培等精密计量值。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的多源异构、高频更新与精密计量特征，对模型接入配置带来多重约束。多源数据需配置对应的数据接入适配器，适配MES、FDC等不同系统的接口格式。高频更新的数据要求模型上下文窗口可灵活调整，避免因上下文溢出丢失关键批次信息。纳米级参数与复杂空间缺陷数据，需配置合适的token分配规则，确保关键信息不被截断。跨工序的质量归因需要开启工具调用功能，支持关联不同模块的历史数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `maxContext` | `8000–12000 token` | 适配多批次晶圆的历史运行记录与缺陷数据的上下文长度，避免关键工艺信息溢出 |
| `maxTokens` | `4000 token` | 控制单次分析的输出长度，确保纳米级参数与缺陷分布的详细判读结果完整输出 |
| `quoteMaxToken` | `1500 token` | 限制引用的原始数据片段长度，优先保留批次ID、缺陷坐标等核心溯源字段 |
| `toolChoice` | `auto` | 支持自动触发跨系统数据调用，完成跨工序良率归因与参数漂移分析 |
| `temperature` | `0.2–0.4` | 降低结果随机性，确保质量追溯的结论与工艺数据的一致性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配晶圆厂本地部署的大模型服务地址，确保数据不出洁净室网络边界 |

## 容易做错的三处
- 模型对话返回结果末尾出现未预期的格式符号。原因是未关闭内置的追溯展示规则配置，导致系统自动追加了标记字符。
- 本地部署的模型无法正常接入系统。原因是未正确配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`，或网络策略限制了本地服务器的访问权限。
- 跨工序数据关联分析结果缺失。原因是未开启`toolChoice`配置，导致模型无法调用所需的多源数据接口，无法完成跨模块的良率归因。

## 怎么确认配好了
- 使用FastGPT v4.17.0版本的系统管理界面，查看所有配置的数据源均能正常拉取对应批次的工艺与缺陷数据。
- 发起一次单批次晶圆的质量分析请求，核对返回结果的上下文长度未超出`maxContext`设置的范围。
- 触发跨工序关联分析，确认系统能自动调用`toolChoice`配置的工具接口，返回完整的归因步骤。
- 调整`temperature`参数后发起多次测试，确认结果的一致性符合业务预期。
