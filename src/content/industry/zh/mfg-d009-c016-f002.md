# 变压器与高压电器制造的质量问题追溯与不良分析：向量模型与索引

## 这个品类的数据长什么样
典型主体为输配电设备、开关柜和变压器厂，日常产生的文档包括绕制与器身装配记录、真空干燥记录、绝缘油报告、局放和耐压试验报告、铭牌参数表。数据来源涵盖设计BOM、硅钢片与绝缘材料采购数据、真空与干燥设备运行数据、油化验报告、高压试验站测试数据。数据按单台产品或每批原材料更新，字段包含绝缘电阻、局放值、含水量等专业参数，附带明确的单位标识，单条记录的文本长度跨度较大，从简短的铭牌参数到数页的试验分析报告不等。

## 这些特征在「向量模型与索引」这一环带来什么约束
单台或每批的更新频率要求索引支持增量更新，避免全量重建带来的性能损耗。专业参数与长文本的组合，要求向量模型具备专业术语的语义理解能力，同时分块策略需兼顾长文本的完整性与嵌入效率。单台产品的追溯需求意味着索引需支持按产品批次、序列号等字段进行精准过滤，避免跨产品的无效召回。绝缘与高压试验数据的高敏感性，要求索引的权限控制与数据隔离符合生产场景的安全要求。

## 配置怎么定
本配置基于 FastGPT v4.17.0 版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 分块长度 | 800–1200 字符 | 适配绝缘油报告、耐压试验报告的单段文本长度，避免专业术语被过度拆分 |
| 重叠长度 | 50–80 字符 | 保留跨分块的专业术语关联，防止局放、绝缘等核心术语被拆分至不同块中 |
| 相似度阈值 | 0.72–0.85 | 匹配变压器制造场景下的专业术语语义相似度，避免误召回或漏召回 |
| 单次搜索上限 | 前8条 | 适配单台产品的关联数据量，平衡召回精度与查询延迟 |
| `maxToken` | 8192 token | 适配主流嵌入模型的最大上下文长度，支持完整的耐压试验分析报告嵌入 |
| `defaultToken` | 2048 token | 匹配常规嵌入任务的token消耗上限，避免单次嵌入任务超出资源限制 |

## 容易做错的三处
- 界面提示“没有可用的渠道，当前分组 default 下”，原因是未将索引模型添加至默认分组的可用模型列表中，导致调用时无法匹配到配置的向量模型。
- 向量嵌入任务超时，原因是单块文本长度超过`maxToken`设置的限制，未按配置的分块长度进行截断或拆分，导致模型无法完成嵌入。
- 召回结果包含非目标批次的产品数据，原因是未配置按产品序列号、批次号的过滤规则，导致索引召回范围未限定在当前追溯的单台产品内。

## 怎么确认配好了
- 上传一份完整的耐压试验报告，查看嵌入任务的日志，确认token消耗未超过`maxToken`的设置值。
- 输入包含专业术语的查询语句，如“某台变压器的局放异常原因”，检查召回结果的条数是否符合单次搜索上限的配置。
- 进入模型管理页面，确认索引模型已添加至默认分组，且接入状态显示正常。
- 手动拆分一段长试验记录，验证分块后的文本拼接后核心专业术语未被错误拆分。
