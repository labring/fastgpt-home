# 变压器与高压电器制造的质量问题追溯与不良分析：工作流编排

## 这个品类的数据长什么样
本品类数据来源为设计BOM、硅钢片与绝缘材料台账、真空干燥设备日志、绝缘油化验报告、高压试验站局放与耐压记录。数据按单台产品或每批原材料更新，配套文档包含绕制与器身装配记录、真空干燥记录、绝缘油检测报告、局放耐压试验报告、铭牌参数表。核心字段包含绝缘层厚度、含水量（单位ppm）、局放幅值（单位pC）、耐压试验电压（单位kV），单台产品关联的文档条目可达十余项。

## 这些特征在「工作流编排」这一环带来什么约束
单台产品关联多源异构文档的特征，要求工作流需通过`nodeId`绑定对应产品的唯一标识，避免跨批次数据混淆。按单台/每批更新的节奏，需配置触发节点按生产批次或完工节点自动启动流程。核心字段的高精度要求，需在工作流中嵌入参数校验环节，验证绝缘含水量、局放幅值等字段的取值范围。多文档关联的场景下，需通过`variables`传递不同文档的字段值，避免上下文过载导致流程卡顿。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 触发方式 | 按生产完工节点自动触发 | 匹配产品按单台更新的业务节奏，避免手动触发遗漏批次 |
| `variables` | 绑定单台产品的`nodeId`与核心试验字段 | 实现跨节点的单台数据传递，避免数据混淆 |
| 节点超时时间 | 600秒 | 适配高压试验报告上传、局放数据解析的耗时需求 |
| 知识库关联范围 | 前8条文档 | 覆盖单台产品全量追溯所需的核心文档，避免上下文过载 |
| 错误重试次数 | 2次 | 平衡流程稳定性与执行效率，适配设备日志偶发读取失败的场景 |
| 单台数据过滤 | 按铭牌序列号匹配 | 精准定位对应产品的全量追溯数据，避免跨单台数据干扰 |

## 容易做错的三处
- 工具调用节点运行后输出冗余AI回复，现象为节点日志中出现非预期的自然语言回复，原因是未关闭节点的自动回复配置，导致工具调用后额外生成了回答。
- 代码执行节点的输出无法传递至指定回复节点，现象为指定回复节点的日志中无代码执行的返回字段，原因是未通过`variables`配置项绑定代码节点的输出变量作为后续节点的输入。
- 环境变量配置失效导致minio存储的试验数据无法读取，现象为节点运行时报存储连接错误，原因是未按FastGPT v4.17.0版本的更新要求调整环境变量命名规则，导致minio连接参数无法被正确识别。

## 怎么确认配好了
- 手动触发一条对应生产批次的工作流，检查节点日志中是否仅传递了单台产品的`nodeId`与核心试验字段，无冗余内容。
- 运行代码执行节点后，查看`variables`配置的变量是否正确携带了代码返回的局放幅值、耐压值等数据。
- 执行知识库检索节点，检查返回结果是否包含对应批次的绝缘油报告、真空干燥记录等文档。
- 模拟代码执行节点的异常退出，检查工作流是否按配置的重试次数执行了自动重试。
