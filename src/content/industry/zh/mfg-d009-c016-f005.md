# 变压器与高压电器制造的质量问题追溯与不良分析：工具调用与插件

## 这个品类的数据长什么样
该品类的数据来源包括设计BOM、硅钢片与绝缘材料台账、真空干燥设备日志、绝缘油化验报告、局放与耐压试验记录、产品铭牌参数表。数据按单台产品或每批原材料更新，文档包含绕制装配工序单、干燥工艺记录、绝缘性能检测表等，核心字段含绝缘含水量、局部放电量、耐压试验电压值，对应单位为ppm、pC、kV。

## 这些特征在「工具调用与插件」这一环带来什么约束
单台产品的全链路数据关联需求，要求工具调用需精准绑定单台变压器的设计BOM、试验记录等多源文档，避免跨批次数据混淆。核心检测字段的单位与精度要求，需工具在调用外部数据接口时自动对齐字段格式。高频的单台更新节奏，要求插件配置适配短周期数据拉取，同时需校验绝缘油含水量、局放值等核心字段的完整性，防止缺失关键检测数据导致分析失效。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `toolChoice` | `auto` | 允许系统根据质量分析查询自动匹配工具调用或直接生成分析结论 |
| `functionCall` | 开启强制参数校验 | 确保调用外部接口时仅传递单台产品的有效字段，避免跨批次数据混入 |
| 工具调用超时时间 | 600秒 | 适配绝缘油化验、局放试验等需等待设备返回结果的长周期检测数据拉取 |
| 单工具调用返回结果条数 | 前3条 | 聚焦单台产品的核心试验记录，减少无关数据对分析的干扰 |
| 插件数据格式对齐 | 按实测标定 | 适配绝缘含水量（ppm）、局部放电量（pC）、耐压试验电压（kV）等品类专属字段的单位与精度 |
| 上下文绑定规则 | 单台产品ID | 确保所有工具调用仅关联当前查询的单台变压器数据，避免多产品数据混淆 |

## 容易做错的三处
- 现象：自定义代码调用插件时返回AggregateError Code:ETIMEDOUT。原因：未适配绝缘油化验、局放试验等长周期检测数据的拉取时长，默认超时设置过短导致请求中断。
- 现象：工具调用返回的试验数据与当前产品不匹配，出现跨批次的记录。原因：未配置单台产品ID绑定的上下文规则，导致调用时混入其他批次的检测数据。
- 现象：核心字段如局部放电量为空，分析结果无有效参考。原因：未开启插件的字段完整性校验，未过滤缺失关键检测数据的记录。

## 怎么确认配好了
- 使用FastGPT v4.17.0版本的平台界面，发起单台变压器的质量追溯查询，验证工具调用仅返回该产品的试验记录与装配文档。
- 模拟长周期数据拉取，确认工具调用超时时间符合品类的检测数据返回节奏。
- 触发插件调用，检查返回数据的字段单位与品类专属参数是否对齐。
- 查看工具调用日志，确认`functionCall`模式下仅传递当前产品的有效参数，无冗余字段。
