# 变压器与高压电器制造的质量问题追溯与不良分析：模型接入与配置

## 这个品类的数据长什么样
本品类数据来源于设计BOM、硅钢片与绝缘材料采购数据、真空干燥设备日志、绝缘油化验报告、局放与耐压试验站记录、产品铭牌参数表。数据更新节奏为每台产品对应一套专属记录，每批次原材料同步更新对应台账。日常文档包含绕制与器身装配流程单、真空干燥工艺记录、绝缘油理化指标报告、高压试验原始数据、产品铭牌参数表，字段包含绝缘含水量、局放幅值、耐压击穿电压、分接开关位置等，无通用批量装配类数据的标准化批量字段。

## 这些特征在「模型接入与配置」这一环带来什么约束
由于本品类数据为单台产品专属的多源异构文档，模型接入时需限制上下文仅匹配当前批次或单台产品的关联数据，避免跨产品数据干扰分析结果。由于包含绝缘含水量、局放幅值等精密数值型字段，配置需支持数值阈值比对与异常值识别逻辑，确保分析的准确性。由于数据来源于设备日志、试验报告等非标准化文档，需配置适配多格式文本的提取规则，确保字段准确提取。由于单台产品数据更新频率高，需确保模型调用时可实时拉取最新的试验与装配记录，避免使用过期数据进行追溯分析。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的模型接入逻辑制定。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 单台产品的关联文档总长度通常在数千token区间，需覆盖绕制记录、试验报告等全量关联数据，避免截断关键追溯信息 |
| `maxTokens` | 4000 token | 用于生成不良分析结论与追溯报告，平衡输出长度与内容完整性，适配单台产品的分析需求 |
| `quoteMaxToken` | 2000 token | 限定模型引用的单份文档片段长度，确保仅提取与当前不良问题相关的核心段落，避免冗余内容干扰分析 |
| `toolChoice` | auto | 允许模型自主选择是否调用工具，适配多源数据的检索与提取需求，提升追溯准确性 |
| `temperature` | 0.2–0.4 | 降低随机输出概率，确保分析结论与试验数据、装配记录的一致性，避免主观偏差 |
| `AIPROXY_API_ENDPOINT` | 按服务商提供的专属端点填写 | 适配模型调用的网络路径要求，确保请求可正常送达目标模型服务 |
| `AIPROXY_API_TOKEN` | 按账号生成的专属令牌填写 | 完成模型调用的身份验证，确保请求的合法性与安全性 |

## 容易做错的三处
- 现象：调用Bedrock系列模型时出现software.amazon.awssdk.services.bedrockruntime.model报错。原因：未正确配置`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`的对应关系，导致身份验证失败或请求路径错误。
- 现象：配置`vision`参数后，仍无法从绝缘油报告的扫描件中提取含水量数值。原因：未针对高压试验报告的扫描件配置专用的OCR预处理规则，导致图像文本提取不完整。
- 现象：使用部分模型时，工作流文本提取组件返回空字段。原因：模型`temperature`设置过高，导致输出格式偏离预设的结构化提取要求，无法匹配组件的字段解析规则。

## 怎么确认配好了
- 发起一次针对单台变压器的模拟追溯请求，检查返回结果中是否包含该产品的绕制记录、试验报告等关联文档片段，确认上下文配置可覆盖所需数据。
- 输入已知局放异常的试验数据，检查模型输出的分析结论是否与数据匹配，确认温度参数与工具调用配置符合预期。
- 查看模型调用日志，确认请求的API端点与令牌与配置项一致，无身份验证相关错误。
- 上传一份绝缘油报告的扫描件，检查文本提取结果是否包含核心业务字段，确认视觉配置与预处理规则生效。
