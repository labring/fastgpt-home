# 喷涂与涂装的质量问题追溯与不良分析：知识库检索与召回

## 这个品类的数据长什么样
喷涂与涂装场景的业务数据覆盖汽车、家电、工程机械等涂装线的全流程文档与采集数据。日常文档包括涂装工艺卡、涂料批次单、调漆记录、膜厚色差报告、烘炉曲线、缺陷返修单、VOCs台账。数据来源涵盖涂料供应商TDS/SDS文件、喷房与烘炉实时采集数据、色差仪与膜厚仪检测结果、环境监测数据、MES系统工单。数据更新节奏为每批涂料更新批次单、每班更新调漆与工艺执行记录、连续采集烘炉与环境监测数据。文档字段包含涂料批号、膜厚值、色差参数、烘炉温度曲线参数、VOCs实时浓度等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据结构要求检索支持跨文档类型的关联匹配，例如将涂料批次单的黏度参数与烘炉曲线的温度参数结合分析缺陷。高频更新的数据源需要配置增量召回机制，避免全量检索占用过多资源。涂装缺陷的分析需匹配前处理、喷涂、固化全窗口的参数，导致检索范围较广，需平衡召回数量与精准度。不同文档的字段差异要求检索规则适配工艺参数、检测数据、台账记录的不同格式，同时需优先匹配涂层外观与固化相关的核心指标，与其他金属加工品类形成区分。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 涂装缺陷匹配需较高置信度，避免低相关的工艺或设备数据混入结果 |
| `limit` | 前8条 | 覆盖涂装全流程的批次、设备、检测等多维度数据，避免结果冗余 |
| `searchMode` | `fullTextRecall` | 适配涂装工艺卡、烘炉曲线等长文本的参数匹配需求 |
| `usingReRank` | 开启 | 重排可优化多维度参数的关联排序，提升缺陷与工艺的匹配精准度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 基于用户问题扩展工艺、缺陷相关的关键词，覆盖更多潜在匹配文档 |
| `collectionIds` | 按涂装工艺、缺陷分析分别配置集合ID | 区分不同类型的业务文档，避免跨品类数据干扰检索结果 |

## 容易做错的三处
- 现象：调用知识库检索后返回`Validation failed: name: Path `name` is required.`报错。原因：未补全涂装类文档的必填字段，例如涂料批次单的批号、烘炉曲线的设备ID等信息未在导入时配置。
- 现象：使用网页静态链接生成知识库时失败。原因：涂装类文档的烘炉曲线、膜厚报告多包含图表与结构化数据，未配置正确的抓取规则导致字段解析失败。
- 现象：回答中强制显示知识库搜索的input和response引用内容。原因：未在工作流配置中关闭引用展示开关，或未在检索设置中禁用引用输出功能。

## 怎么确认配好了
FastGPT v4.17.0版本下，可通过以下可执行动作核对配置：
- 导入一批涂装工艺卡与涂料批次单，执行缺陷分析相关的检索测试，查看返回结果是否包含对应批次的黏度、膜厚等核心参数。
- 查看检索日志，确认`similarity`阈值生效，返回结果的相似度分值处于设定的0.75–0.85区间内。
- 测试工作流调用场景，验证是否可按需隐藏或显示知识库引用内容，符合业务展示需求。
- 提交新的调漆记录与烘炉数据，确认增量更新功能生效，检索结果可及时包含最新的业务数据。
