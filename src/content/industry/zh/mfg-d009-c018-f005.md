# 基础化工连续生产的质量问题追溯与不良分析：工具调用与插件
本文适配 FastGPT v4.17.0 版本。

## 这个品类的数据长什么样
基础化工连续生产的核心数据来自DCS/SIS控制系统、在线分析仪、LIMS实验室管理系统、设备状态监测模块、能源计量系统与原料储罐传感器。日常文档涵盖操作规程、工艺指标卡、DCS趋势图、化验报告、联锁旁路记录、特殊作业票与班报。数据更新节奏包含实时、每班与每日，字段多带专属单位，如反应釜压力的MPa、物料温度的℃、储罐液位的m³等。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源异构的数据来源要求工具调用需适配不同协议的数据源接口，避免因格式不兼容导致拉取失败。实时类数据的高频更新要求工具调用的触发间隔匹配生产节奏，避免过长或过短。多样的文档类型需要插件预置对应解析规则，适配工艺指标卡的表格结构、DCS趋势图的时序数据格式等。强联锁相关的记录调用需额外校验权限，防止敏感数据泄露。大宗连续生产的物料流转数据量大，单次工具调用的返回量需控制，避免接口过载。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 工作流/API 工具选择配置 | `auto` | 自动适配多工具调用逻辑，兼容不同数据源的调用需求 |
| 单次工具调用数据条数上限 | 前 500 条 | 匹配基础化工连续生产的单批次数据规模，避免接口传输过载 |
| 工具调用超时时间 | 30–60 秒 | 适配实时数据拉取与历史工艺数据查询的响应节奏，按实测标定 |
| `functionCall` 参数校验 | 开启 | 拦截无效格式的调用请求，规避JSON payload格式报错 |
| 文档解析规则适配 | 预置化工专属解析模板 | 适配工艺指标卡、DCS趋势图、联锁旁路记录等特有文档结构 |
| 上下文更新触发时机 | 按每班作业周期 | 匹配基础化工生产的班组作业节奏，确保上下文数据时效性 |

## 容易做错的三处
- 现象为文本提取工具返回400 Invalid JSON payload received. Unknown name报错，原因是未开启`functionCall`参数校验开关，传入了不符合格式的调用参数。
- 现象为调用工作流API时无法获取预设的上下文数据，原因是未将上下文更新触发时机配置为匹配班组作业的周期节点，导致上下文未按生产节奏同步更新。
- 现象为工具调用返回的结果字段缺失或单位异常，原因是未启用化工专属文档解析模板，无法适配工艺指标卡、DCS趋势图的特有字段与单位格式。

## 怎么确认配好了
- 发起单条模拟调用，检查返回结果的JSON格式合规，确认`functionCall`参数校验已开启。
- 查看工具调用的执行日志，确认触发时机与班组作业周期对齐，验证上下文更新配置正确。
- 上传一份DCS趋势图文档，检查解析后的时序数据与字段单位是否匹配生产实际，确认化工专属解析模板生效。
- 发起批量数据调用，确认返回结果的条数未超出预设上限，验证单次调用数据量配置合理。
