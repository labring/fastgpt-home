# 塑料注塑成型的质量问题追溯与不良分析：工具调用与插件

## 这个品类的数据长什么样
这个品类的数据主要来自树脂批次物性档案、注塑机运行参数、模温机日志、车间MES系统、首件检验与巡检表单，以及换料清机记录。日常归档文档包含注塑工艺卡、原料干燥台账、模具履历表。数据更新节点为每批次生产、每次换模换料操作，以及每班生产结束时。数据字段涵盖原料批次标识、设备运行参数、检验结果数值等，未使用额外统计类量化百分比标注。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据更新节点分散且频次密集，工具调用需适配多时间范围的跨源数据拉取，避免单次调用仅覆盖单类生产文档。多类型数据源的存在要求插件支持联动调取原料档案、设备参数与检验结果，支撑不良分析的多维度关联。生产节点触发的工具调用需求，需绑定生产事件触发时机，确保调用时机与生产流程匹配。同时，不良分析需关联多维度历史数据，工具调用的上下文需支持加载多字段的关联数据集，保障分析维度完整。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| ------ | -------- | ----------- |
| `toolChoice` | 自动模式 | 适配自由识别工具的需求，匹配自动选择工具处理生产问题的场景 |
| `functionCall` | 启用参数格式校验 | 保障调用的接口参数符合注塑数据的字段规范，避免无效请求 |
| 工具调用触发时机 | 绑定生产事件节点（换模、换料、每班结束） | 匹配该品类数据更新与生产流程的节点要求，保障数据实时性 |
| 单次调用返回数据条数 | 前8条 | 覆盖多源数据的核心字段，避免上下文过载影响分析效率 |
| 调用超时阈值 | 600秒 | 适配注塑工艺参数调取的实际延迟范围，可按实测标定调整 |
| 结果输出过滤 | 仅保留工具调用内部字段 | 控制工具获取的知识不输出给终端用户，匹配知识隐藏需求 |

## 容易做错的三处
- 现象：工具调用返回的原料数据字段为空。原因：未绑定对应生产事件触发调用，拉取的原料档案未关联当前批次的树脂标识。
- 现象：工具调用被定时器持续触发，产生无效的生产数据拉取请求。原因：未绑定生产事件触发，误将定时任务作为调用触发条件。
- 现象：工具调用获取的原始文档内容被直接输出给终端用户。原因：未开启结果输出过滤配置，未设置仅保留内部字段的规则。

## 怎么确认配好了
- 触发一次换模事件，检查工具调用是否自动拉取对应模具的履历数据。
- 发起不良分析请求，确认`toolChoice`自动匹配了原料、设备、检验三类工具。
- 查看工具调用的返回结果，确认仅保留内部字段，未向测试用户输出原始文档内容。
- 模拟超出600秒的延迟场景，确认调用触发超时校验逻辑。
