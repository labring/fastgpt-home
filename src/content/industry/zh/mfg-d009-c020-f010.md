# 安全环保与特殊作业管理的质量问题追溯与不良分析：知识库检索与召回

## 这个品类的数据长什么样
本品类数据主体为化工、冶金、机械、轻工等制造企业EHS部门与生产检维修团队，日常文档涵盖风险辨识记录、动火/受限空间/吊装等作业票、在线监测记录、危废台账、排放监测数据、事故与隐患整改报告。数据来源包括法规标准库、在线环保监测设备、气体检测仪、人员资质档案、设备隔离清单、监管平台。更新节奏覆盖每次作业完成后、实时监测数据生成时，以及定期合规检查更新。文档字段包含作业类型、审批人、隔离点编号、危废产生量、监测数值等，对应单位涉及立方米、千克、人次、ppm等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
多源异构的数据来源（在线监测设备、纸质作业票、监管平台数据等）要求检索系统支持混合格式内容的召回；高频更新节奏（每次作业完成、实时监测生成、定期合规检查）要求配置精准的同步机制，避免检索结果滞后于现场合规状态；多样的文档类型与专属字段（如隔离点编号、危废产生量）要求检索逻辑兼顾结构化字段匹配与非语义文本召回；同时，该品类涉及人身安全、合规处罚与环境责任，需严格限定检索范围至本部门合规文档，避免无关数据干扰决策有效性。

## 配置怎么定
FastGPT v4.17.0 版本下，可通过以下配置项完成该场景的知识库检索与召回设置：

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 该品类数据涉及安全合规，需较高匹配精度，避免召回无关的作业票或监测记录 |
| `limit` | 前8条 | 单次召回过多会超出上下文窗口，且EHS关键合规信息多集中在前几条结果 |
| `searchMode` | `mixedRecall` | 文档包含结构化字段（如设备隔离清单编号）和非结构化文本（如风险辨识报告），混合模式可兼顾精准匹配与语义召回 |
| `usingReRank` | 开启 | 该品类合规要求高，重排可过滤低相关性结果，提升关键隐患、作业许可信息的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | EHS场景常需关联法规、资质要求，扩展查询可补充检索相关的合规文档内容 |
| `collectionIds` | 绑定专属EHS作业票、危废台账等数据集ID | 需限定检索范围至本部门的合规文档，避免召回其他品类的生产数据 |

## 容易做错的三处
- 现象：创建知识库时无法选择表格数据集，原因：未将表格数据集上传至专属的EHS合规数据集集合，或未开启表格数据集的检索权限。
- 现象：知识库检索结果未同步更新最新作业票或监测记录，原因：未配置增量同步触发规则，仅使用全量同步导致更新延迟，无法匹配实时生成的合规文档。
- 现象：搜索卡片中引用作业类型、隔离点编号等变量后返回空结果，原因：未将变量对应的字段配置为检索扩展字段，导致变量无法关联到对应文档内容。

## 怎么确认配好了
- 检查知识库绑定的`collectionIds`是否仅包含EHS相关的作业票、危废台账、监测记录等数据集ID，未混入其他品类的生产数据。
- 发起一次针对受限空间作业许可的检索，确认召回结果包含最新的作业票模板、风险辨识要求与人员资质标准。
- 测试变量引用隔离点编号字段，确认检索结果能过滤出对应隔离点的合规作业要求。
- 触发一次增量同步，等待10分钟（按实测标定）后检索最新上传的危废台账，确认内容已同步至检索结果中。
