# 家具与木制品制造的质量问题追溯与不良分析：知识库检索与召回

## 这个品类的数据长什么样
一般家具与木制品制造的核心数据来自订单设计系统、板材和木材批次台账、数控开料与钻孔设备日志、ERP/MES系统以及含水率检测记录。日常产出的文档包含个性化拆单图、开料清单、封边与钻孔程序、涂装工艺规范、五金配件清单、试装与包装记录。数据更新节奏按单、按日或按材料批次执行，每份文档包含板件尺寸、纹理色号、孔位参数、五金型号等专属字段，无通用标准BOM的固定字段结构。

## 这些特征在「知识库检索与召回」这一环带来什么约束
个性化订单驱动的板件数量多、尺寸参数分散，导致检索需匹配多维度板件属性；按单、按日或按材料批次的高频更新节奏，要求检索链路支持实时同步最新板材批次与工艺参数；拆单图、数控程序等非结构化文档与五金清单、开料清单等结构化文档并存，需适配混合检索模式；定制化场景下无通用固定BOM，需避免通用检索逻辑的冗余召回，聚焦当前订单的专属参数与批次信息。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本适配。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.72–0.80 | 匹配板件尺寸、孔位等高精度参数，避免召回无关板件数据 |
| `limit` | 前8条 | 单订单板件数量通常不超过50，限制召回条数避免上下文过载 |
| `searchMode` | `mixedRecall` | 适配结构化参数与非结构化文档的混合检索需求 |
| `usingReRank` | 开启 | 对召回结果按订单关联度重排，优化定制化场景的检索精度 |
| `datasetSearchUsingExtensionQuery` | 开启 | 自动扩展检索词，覆盖拆单术语、涂装工艺等行业专属表述 |
| `collectionIds` | 按订单绑定的知识库集合 | 仅召回当前订单关联的工艺、板材、五金数据，避免跨单干扰 |

## 容易做错的三处
- 现象：检索返回大量跨订单的板件数据，无法精准匹配当前定制订单的专属参数。原因：未通过`collectionIds`限定检索的知识库集合，召回范围覆盖全量历史数据。
- 现象：调用FastGPT对话接口时，无法指定仅检索当前订单关联的知识库。原因：未在API请求中配置正确的知识库集合参数，导致检索范围未限定。
- 现象：导入需要登录权限的网页版涂装工艺文档时，知识库导入任务失败。原因：未配置网页抓取的登录校验跳过逻辑，无法正常获取文档内容。

## 怎么确认配好了
- 导入当前订单的拆单图与开料清单，执行检索后核对返回结果的板件参数是否与当前订单匹配。
- 调用对话接口传入指定知识库的参数，确认返回结果仅包含该知识库内的文档内容。
- 导入需要登录权限的网页文档，检查知识库导入任务的执行状态是否正常。
- 开启重排功能后，核对召回结果的排序是否优先匹配当前订单的专属工艺与材料参数。
