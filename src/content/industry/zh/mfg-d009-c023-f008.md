# 工业仪器仪表制造与校准的质量问题追溯与不良分析：文档解析与分块

## 这个品类的数据长什么样
数据来源包括设计文件、标准器和环境监测数据、校准软件输出、实验室信息系统及客户量程要求；日常文档涵盖装配调试单、校准规程、原始校准记录、误差曲线、计量证书、软件版本记录；更新频率为每台仪器每次校准后生成新文档；文档多为带固定字段的表单或嵌入坐标曲线的PDF，字段包含仪器编号、校准日期、标准器编号、误差值、合格判定及对应计量单位。

## 这些特征在「文档解析与分块」这一环带来什么约束
本品类的文档多为单台仪器单次校准生成的结构化表单或带误差曲线的PDF，且需严格保留溯源链信息，因此文档解析分块需适配两类核心文档结构：带固定字段的计量表单与带坐标数据的误差曲线。由于文档更新频率为每台每次校准，单文档体量较小但生成频次高，解析需兼顾单文档处理效率与字段完整性。同时，文档中包含带计量单位的校准值、标准器编号等关键溯源字段，分块时需避免拆分跨字段的关联信息，否则会导致后续质量追溯时无法匹配对应校准数据。另外，不同来源的文档格式差异较大，需通过自定义配置适配不同导出格式的解析逻辑。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配本品类带固定字段的表单与误差曲线关联文本的长度，避免拆分关键溯源字段 |
| `chunkSplitter` | 按语义分块 | 基于校准文档的结构化特征，保留字段与曲线说明的语义完整性 |
| `customPdfParse` | 开启 | 针对本品类PDF中嵌入的误差曲线图表与表单字段，启用自定义解析以保留原始排版与字段映射 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 600 秒 | 适配误差曲线PDF的解析耗时，避免因复杂图表渲染导致解析超时 |
| `chunkSettingMode` | 手动配置 | 针对不同来源的校准文档（如校准软件导出、LIS生成），可灵活调整分块规则，满足个性化解析需求 |

## 容易做错的三处
- 现象：PDF解析任务突然报错，返回解析失败状态码。原因：未正确启用`customPdfParse`，或近期配置变更导致doc2x解析引擎无法适配本品类的误差曲线PDF格式。
- 现象：上传的校准文档未按预期传入大模型，仅返回默认解析的纯文本内容。原因：未关闭系统默认的通用文本解析流程，导致文档被提前拆分，无法直接传入大模型。
- 现象：分块后的文本块丢失误差曲线的关联说明文本。原因：`chunkSize`取值过小，拆分了曲线说明与坐标数据的关联段落，破坏了信息完整性。

## 怎么确认配好了
- 上传一份标准计量证书PDF，查看解析后文本是否保留了仪器编号、校准日期、误差值等核心字段，无字段丢失或错位。
- 查看解析任务的日志信息，确认未触发`PARSE_FILE_TIMEOUT_SECONDS`对应的超时报错，解析耗时符合预期。
- 测试分块后的文本块，确认同一校准记录的合格判定与误差值未被拆分至不同块，保留关联信息。
- 上传一份带误差曲线的PDF文档，确认解析结果包含图表说明与对应坐标数据，无内容缺失。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
