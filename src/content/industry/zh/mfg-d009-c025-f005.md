# 工装夹具与检具制造的质量问题追溯与不良分析：工具调用与插件

## 这个品类的数据长什么样
该品类的数据围绕工装与检具全生命周期生成，来源包括产品数模与GD&T规范、工艺路线文件、三坐标测量数据、现场试用反馈及计量系统记录。日常产出的文档包含工装需求书、定位基准方案、夹具设计图、检具操作指导书、验收报告、校准记录与变更履历。数据更新节奏匹配项目推进、产品变更节点与定期校准周期，单份数据关联多环节流程，字段包含基准公差、夹紧力参数、校准周期等专属标识。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类的数据关联多环节且结构复杂，要求工具调用需适配多源异构数据接入，包括三坐标测量数据、GD&T规范文档与变更履历。非结构化的工装图纸、检具操作书需专用解析插件适配机械制图格式，无法依赖通用文档处理工具。数据更新无固定周期，工具调用需支持动态拉取最新校准记录与变更信息，避免使用过期数据。单份数据关联的流程节点多，工具调用需关联多插件完成基准转换、干涉验证等环节，且需保留调用链路日志用于问题追溯。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` | 需自动选择适配工装专业场景的工具，避免强制调用不相关插件 |
| 工作流/API 函数调用配置 | `enabled` | 需启用函数调用以对接三坐标数据查询、校准记录拉取等专用插件 |
| 工具调用超时时间 | `120–180 秒` | 工装数据解析需处理图纸与数模，耗时较长，按实测标定调整区间 |
| 插件调用重试次数 | `2 次` | 工装数据来源分散，网络波动或接口临时异常可通过重试恢复 |
| 上下文最大token数 | `8000–12000 token` | 需承载GD&T规范、夹具图解析结果与变更履历，避免截断关键信息 |
| 工具调用日志存储 | 开启全链路记录 | 需留存调用链路用于质量问题追溯，符合工装制造的流程管控要求 |

## 容易做错的三处
- 现象：调用`functionCall`插件后返回空结果，未获取到对应工装项目的校准记录。原因：未配置插件与企业计量系统的对接权限，或插件数据源未关联当前项目的变更履历。
- 现象：生成的质量分析结果未匹配GD&T公差要求，效果弱于直接使用大模型处理。原因：未设置`toolChoice`为自动适配模式，强制调用通用工具导致专业机械字段识别缺失。
- 现象：免登录应用调用MCP Server时无法获取用户标识，无法关联用户的工装项目数据。原因：未在应用配置中开启用户标识透传功能，免登录模式下默认未传递用户关联参数。

## 怎么确认配好了
- 在FastGPT v4.17.0的应用调试页面触发工具调用，查看全链路日志是否包含插件调用、数据拉取的完整步骤。
- 上传一份工装夹具设计图，验证工具调用后是否返回符合行业规范的定位夹紧方案解析结果。
- 模拟插件调用失败的场景，确认系统是否触发预设的重试机制，并记录失败原因与重试次数。
- 配置免登录应用后，通过MCP Server接口发起请求，确认接口可获取到用户关联的项目标识信息。
