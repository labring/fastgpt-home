# 工装夹具与检具制造的质量问题追溯与不良分析：模型接入与配置

## 这个品类的数据长什么样
工装夹具与检具制造的业务数据涵盖工装需求书、定位基准方案、夹具图、检具操作书、验收报告、校准记录、变更履历等文档。数据来源包括产品数模与GD&T、工艺路线、三坐标测量数据、现场试用反馈、企业计量系统。数据更新按项目推进、每次产品变更触发、定期校准执行，单份项目文档包含GD&T公差值、三坐标测量偏差、校准周期等字段，单位多为毫米、微米、天等工程通用单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
该品类的数据兼具结构化工程参数与半结构化文档内容，且更新无固定周期，因此模型接入需适配多格式数据解析与触发式知识库同步。同时，数据涉及装夹偏差、检具误判等敏感工程信息，需严格控制上下文与输出长度以避免信息泄露或关键内容截断。此外，质量追溯需关联多维度历史数据，要求模型能够精准召回校准记录、变更履历等关联文档，对上下文窗口与引用长度提出明确要求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 工装夹具文档多含长段工程图纸说明与公差数据，需保留足够上下文关联基准与偏差信息 |
| `maxTokens` | 2000–3000 token | 单条不良分析回答需覆盖定位偏差、校准记录等多维度数据，避免截断关键信息 |
| `quoteMaxToken` | 1500–2000 字符 | 需完整引用夹具图尺寸、三坐标测量原始数据作为追溯依据 |
| `temperature` | 0.1–0.3 | 质量分析需严谨，降低随机输出以保证公差判断、追溯路径的准确性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写专属接口地址 | 适配企业内部计量系统与工程数据的跨域调用需求 |
| `AIPROXY_API_TOKEN` | 按企业权限生成专属密钥 | 保障工装与检具的敏感工程数据传输安全 |

## 容易做错的三处
- 检索结果中出现GD&T公差公式无法正常渲染，原因是未配置适配工程公式的解析逻辑，仅使用通用文本处理流程。
- 本地部署时相同质量追溯问题返回结果不一致，原因是未固定`temperature`参数取值，导致每次推理的随机输出偏差超出可接受范围。
- 重排模型未按偏差优先级排序检索结果，原因是未启用关联工程数据的重排配置，或未指定适配公差数值的重排规则。

## 怎么确认配好了
- 上传一份工装夹具图文档，验证GD&T公差值、三坐标测量原始数据可被正确提取并作为引用内容。
- 提交一条不良分析问题，检查返回结果中关联的校准记录、变更履历等文档的完整性。
- 固定`temperature`参数为0.2，连续提交3次相同问题，确认返回结果的一致性。
- 配置`AIPROXY_API_TOKEN`后，测试跨系统调用计量数据的接口连通性。
