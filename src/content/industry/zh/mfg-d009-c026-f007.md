# 有色金属冶炼与电解的质量问题追溯与不良分析：数据库与运维

## 这个品类的数据长什么样
该品类的数据通常来自精矿与辅料分析、DCS系统、槽电压电流监测、化验室检测、能源与环保监测设备。日常文档包含配料单、熔炼记录、电解槽况记录、化验报告、阳极阴极质量记录、环保台账。数据更新节奏覆盖每批原料、每炉或每槽级，部分设备参数实时更新。数据字段包含原料成分指标、设备运行参数、检测结果、环保监测值，涵盖生产全流程多维度信息。

## 这些特征在「数据库与运维」这一环带来什么约束
多源混合的更新节奏，包含实时设备参数与批次级生产记录，要求数据库兼顾高并发写入与批量查询的处理能力。异构的文档结构，涵盖结构化检测报表与非结构化日志，需要兼容结构化存储与文档型存储的混合部署。高频的单条参数更新与批量化验数据导入，要求配置合理的数据库连接上限避免资源耗尽。跨部门的质量溯源需要关联多维度数据，要求数据库支持高效的跨表关联查询。环保相关数据的留存需求，要求配套完善的数据备份与权限管控机制。

## 配置怎么定
本页内容基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://user:pass@host:27017/fastgpt_elecsmelt?authSource=admin` | 存储非结构化的熔炼日志、槽况记录等异构文档，适配多源数据的灵活存储 |
| `PG_URL` | `postgresql://user:pass@host:5432/fastgpt_quality?sslmode=require` | 存储结构化的配料单、化验报告、质量台账等数据，支持复杂跨表关联查询 |
| `DB_MAX_LINK` | `200–300 个连接` | 匹配实时设备参数与批量化验数据的并发写入需求，避免连接耗尽 |
| `REDIS_URL` | `redis://:pass@host:6379/0` | 缓存高频查询的槽电压电流实时数据，降低数据库直接访问压力 |

## 容易做错的三处
- 现象：安装数据库连接插件时提示服务器内部错误。原因：未正确配置`MONGODB_URI`或`PG_URL`的访问权限，或网络策略限制了数据库端口的出站连接。
- 现象：新版本启动失败，日志中出现MongoDB连接报错。原因：`DB_MAX_LINK`设置过高超出服务器资源上限，或`MONGODB_URI`的认证参数配置错误。
- 现象：知识库导出时无法定位目标数据。原因：未按照生产数据的租户与表结构配置存储路径，混淆了结构化与非结构化数据的存储库。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`MONGODB_URI`、`PG_URL`和`REDIS_URL`的连通性，确认无认证或网络报错。
- 导入一批模拟的电解槽况记录与化验报告，检查数据写入与跨表关联查询的响应速度，根据实际业务负载调整`DB_MAX_LINK`的取值。
- 查看系统运行日志，确认无数据库连接耗尽或超时报错，根据生产高峰时段的并发量优化连接数配置。
- 导出指定批次的生产数据，核对导出内容与数据库中存储的字段、结构是否匹配，确认存储路径与租户配置正确。
