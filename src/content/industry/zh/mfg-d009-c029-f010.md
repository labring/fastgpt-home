# 模具设计制造的质量问题追溯与不良分析：知识库检索与召回

## 这个品类的数据长什么样
该品类的核心数据来自注塑、冲压、压铸模具企业及制造企业模具中心，日常留存模具设计任务书、DFM报告、零件图、加工工艺卡、试模报告、改模通知、模具履历等文档。数据来源包含客户产品模型、模流/成形仿真文件、CAD/CAM源文件、机加工与测量数据、试模样件相关记录，更新节奏随项目推进、每次试模或改模触发。文档多包含几何参数、工艺要求、缺陷记录等字段，格式随项目需求灵活调整，无统一固定模板。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的专业文档包含几何参数、工艺要求、缺陷记录等细分字段，且格式随项目灵活调整，要求检索需精准匹配专业术语与项目专属信息。多源异构的数据来源带来格式不统一的问题，需适配CAD文件、仿真报告、测量记录等不同类型内容进行召回。按项目、试模或改模的更新节奏，知识库需支持快速同步最新的改模记录与试模缺陷数据，避免检索到过时内容。同时，质量追溯需关联多环节数据，检索需覆盖设计、加工、试模全链路的关联信息。

## 配置怎么定
本配置方案适配FastGPT v4.17.0
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 匹配模具专业术语与项目专属信息的精度要求，避免召回无关的通用模具文档 |
| `limit` | `前 6–8 条` | 覆盖试模报告、改模通知、工艺卡等多类关联文档的数量需求，避免单次召回过载 |
| `searchMode` | `mixedRecall` | 适配专业术语与几何参数的混合检索需求，兼顾精准度与召回范围 |
| `usingReRank` | `开启` | 对召回结果按相关性重新排序，优化多文档关联检索的结果顺序 |
| `datasetSearchUsingExtensionQuery` | `开启` | 扩展检索范围，覆盖试模缺陷与改模记录的关联内容 |
| `collectionIds` | `按项目绑定专属知识库集合` | 隔离不同项目的模具数据，避免跨项目无关文档被召回 |

## 容易做错的三处
- 现象：上传模具设计任务书、DFM报告等文档时，界面返回“Request failed with status code 400”报错。原因：未适配模具专业文档的格式要求，或上传文件大小超出知识库单次上传阈值。
- 现象：检索质量问题相关内容时，仅返回单一份零件图，无法关联对应试模报告的缺陷记录与改模通知。原因：未配置跨文档关联召回，或`searchMode`仅设置为单一检索模式。
- 现象：检索结果中出现超过3个月未更新的旧改模记录。原因：未按项目试模、改模的节奏刷新知识库绑定的集合，或未启用增量同步配置。

## 怎么确认配好了
- 输入一条模具试模缺陷的专业问题，核对召回结果是否包含对应项目的试模报告、改模通知等关联文档。
- 上传一份最新的改模通知，触发知识库同步后，检索该改模的相关内容，确认结果包含最新记录。
- 调整任一检索配置项后，对比前后召回结果的相关性与数量，确认配置生效。
- 检查知识库绑定的集合是否按项目进行隔离，避免跨项目的无关文档被召回。
