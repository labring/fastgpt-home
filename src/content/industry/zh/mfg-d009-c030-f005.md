# 橡胶混炼与制品硫化的质量问题追溯与不良分析：工具调用与插件

本文档基于FastGPT v4.17.0版本编写。

## 这个品类的数据长什么样
该品类的业务数据主要来自配方系统、原材料批次台账、密炼机、门尼与流变仪、硫化机及实验室检测设备。日常文档包含配方单、称量记录、混炼曲线、胶料快检报告、硫化工艺卡、模具使用记录、成品性能报告。数据更新频率为每车胶料、每批原材料、每模次制品生成对应记录。单条记录包含胶种配比（单位：phr）、工艺参数（温度/时间/压力）、设备编号、批次号、检测数值等字段。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类高频次的多源数据更新，要求工具调用需支持毫秒级响应与高频触发，避免因等待延迟干扰实时生产流程。多类型的工艺与检测文档，要求插件需适配混炼曲线数值提取、工艺参数结构化解析等不同数据格式。全链路追溯需求则要求工具调用可关联原材料批次、设备运行记录、成品检测结果等多源数据，实现不良问题的正向与反向溯源。同时，不可逆的硫化加工特性，要求工具调用需拉取完整的历史流程数据，无法依赖单次实时数据完成不良分析。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工具调用开关 | 开启 | 用于启用工具调用能力，实现配方数据查询、工艺参数校验等生产相关功能 |
| 单次工具调用超时时间 | 30–60 秒 | 匹配每模次的生产间隔，避免超时中断正在进行的生产流程 |
| 工具结果拼接方式 | 按调用顺序拼接 | 保证追溯数据的时间线一致性，便于不良分析的全流程还原 |
| `toolChoice` | auto | 适配多源数据查询需求，自动选择合适的工具完成数据拉取与结构化解析 |
| 插件输入参数校验 | 开启必填字段校验 | 避免因缺失批次号、设备编号等关键参数导致工具调用失败 |
| 最大工具调用次数 | 3 次 | 限制单次对话的工具调用轮次，防止生产流程被过度占用 |

## 容易做错的三处
- 现象：工具调用完成后，对话框内未显示结果，重新进入会话后才加载出部分结果。原因：未配置工具结果的实时推送逻辑，导致结果仅在会话重建时同步。
- 现象：使用代码运行插件编写脚本时，无法从返回的JSON数据中提取指定元素，且无Python代码运行支持。原因：插件内置的代码运行环境仅预装了JS依赖，未配置Python运行时，且未开放JSON路径解析的快捷配置。
- 现象：调用基础图表插件时，输入正确的工艺数据参数后，返回结果为“none”。原因：未按要求传入符合格式的数值数组，或参数中缺少图表类型、坐标轴单位等必填配置项。

## 怎么确认配好了
- 发起包含原材料批次查询的测试对话，核对工具是否能拉取对应批次的称量记录与混炼数据。
- 触发工具调用后，等待30秒内查看对话框是否实时显示工具返回结果，无需重新进入会话。
- 配置`toolChoice`为auto后，发起跨数据源的查询请求，核对工具是否自动选择合适的插件完成数据解析。
- 输入带必填参数的工具调用请求，核对插件是否会拦截缺失关键信息的调用请求。
