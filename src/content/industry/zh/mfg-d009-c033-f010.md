# 汽车零部件批量制造的质量问题追溯与不良分析：知识库检索与召回

本文基于FastGPT v4.17.0版本编写

## 这个品类的数据长什么样
该品类数据来自客户图纸、特殊特性清单、ERP/MES系统、量检具、设备过程参数及供应商质保书，日常文档包含控制计划、过程流程图、作业指导书、首件与巡检记录、SPC报表、PPAP资料与8D报告。数据按生产批次、班次持续采集更新，部分文档关联具体工序编号、设备编号与批次号，字段包含特殊特性参数、过程能力指标、异常处置记录等，单份文档字数跨度较大。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据多源且实时性要求高，需支持对接多类系统的实时数据接入。文档类型多样，结构差异显著，部分文档包含结构化参数与非结构化描述，检索需兼顾语义匹配与精准字段匹配。单份文档跨度大且关联生产批次信息，检索需关联工序、设备、批次等维度的精准过滤，同时适配不同文档的分块与召回逻辑。高频更新的特性要求检索链路支持增量同步，避免全量重建带来的资源消耗。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 汽车零部件质量文档多包含精准参数，需过滤低相关结果，避免混入非目标工序的异常记录 |
| `limit` | 前8条 | 批量制造场景下需覆盖多工序、多批次的关联记录，过多结果会超出上下文窗口，过少则遗漏关键根因信息 |
| `searchMode` | vector+keyword | 该品类文档同时包含结构化参数与非结构化描述，混合检索可兼顾语义匹配与精准字段匹配 |
| `usingReRank` | 开启 | 批量制造的异常分析需精准匹配根因关联的8D报告、SPC报表，重排可提升高相关结果的排序优先级 |
| `datasetSearchUsingExtensionQuery` | 开启 | 该品类需关联特殊特性、工序编号等字段，扩展查询可补充检索相关的上下游文档 |
| `collectionIds` | 按生产批次绑定对应数据集 | 该品类数据按批次更新，绑定数据集可精准召回对应批次的生产文档，避免跨批次干扰 |

## 容易做错的三处
- 现象：检索结果未包含长文档的核心段落，或返回结果为空。原因：未适配长文档的分块逻辑，直接按固定长度分块后，长文档的关键片段因超出向量模型支持的长度限制被丢弃，导致召回失败。
- 现象：知识库更新后无法同步最新的批次记录，需手动重新上传全量文档。原因：未配置增量更新触发规则，仅支持全量上传，无法实现单个文档的局部内容更新，无法适配该品类高频的批次级更新需求。
- 现象：AI对话输出耗时超过预设阈值。原因：未开启`usingReRank`重排功能，或`limit`取值过高，导致召回的结果过多，超出上下文窗口后需额外处理，拖慢输出速度。

## 怎么确认配好了
- 上传一份典型的8D报告与SPC报表，执行异常检索后核对结果是否包含对应文档的关键段落。
- 模拟单次异常检索，查看返回结果的条数是否符合预设的`limit`取值范围。
- 提交局部修改后的作业指导书，验证知识库是否自动同步更新内容，无需全量重新上传。
- 查看检索与对话的整体耗时，确认输出速度符合业务场景的响应要求，可通过调整`similarity`阈值或`limit`取值优化。
