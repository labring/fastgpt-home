# 焊接结构件制造的质量问题追溯与不良分析：工具调用与插件

## 这个品类的数据长什么样
焊接结构件制造的质量追溯与不良分析数据，覆盖焊接工艺评定、焊接工艺规程、焊材领用记录、焊工资格记录、焊缝检验报告、返修单等文档。数据来源包括设计图纸、材料质保书、焊接设备参数、焊材库管理系统、无损检测系统、人员资质台账。数据更新频率为每条焊缝或每批、每班，每条记录包含焊缝编号、焊接参数、检测结果、焊工资质等字段，字段单位随具体文档类型调整。

## 这些特征在「工具调用与插件」这一环带来什么约束
品类数据的多文档关联特性，要求工具调用需支持跨数据源拼接，例如关联焊材领用记录与焊缝检验报告。数据更新频率高，要求插件需适配实时或近实时的数据调取，避免使用过期的焊工资质或焊材信息。刚性的资质与工艺约束，要求工具调用需严格匹配预设的合规规则，无法灵活调整过滤条件。无损检测数据的非结构化特性，要求插件需具备解析特定格式检测报告的能力，提取裂纹、未熔合等缺陷信息。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工作流/API 工具选择配置 | `auto` | 自动选择适配焊接结构件业务的工具，无需手动指定调用类型 |
| 工作流/API 函数调用配置 | `enabled` | 启用函数调用能力，用于调取焊接台账、检测报告解析等专属业务插件 |
| 工具调用超时时间 | `300-600 秒` | 适配多份焊接文档的解析与跨数据源查询耗时 |
| 单次工具调用次数上限 | `前 8 条` | 匹配单批次焊缝或单份返修单的关联数据量，避免请求过载 |
| 插件数据源过滤规则 | 仅匹配焊接工艺、无损检测、资质台账类文档 | 限定插件调用范围，避免无关数据干扰分析结果 |
| 上下文窗口长度 | `8000-12000 token` | 承载多份焊接文档的完整上下文，适配FastGPT v4.17.0版本的上下文管理规则 |

## 容易做错的三处
- marker-pdf调用出现请求错误，提示连接失败。原因是部署在Docker Desktop中时，未将插件容器端口映射至宿主机，导致FastGPT无法访问本地部署的marker-pdf服务。
- 工作流运行时出现gpt-4o-mini调用报错日志。原因是未在FastGPT平台配置区正确填写对应模型的API密钥或区域参数，导致调用链路中断。
- 知识库问答对提取任务卡在训练中，无调用日志生成。原因是未配置对应的数据解析插件，无法提取问答对的字段信息，导致任务停滞。

## 怎么确认配好了
- 发起一次模拟焊缝不良分析的查询，查看工具调用日志是否有对应焊接数据源的调取记录。
- 上传一份焊缝检验报告至marker-pdf插件，查看解析结果是否包含焊缝编号、无损检测结果等核心字段。
- 发起一次包含多份焊接文档的查询，确认未出现超时报错，工具调用流程正常完成。
- 查看FastGPT平台的配置日志，确认`toolChoice`和`functionCall`的参数被正确加载。
