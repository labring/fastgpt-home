# 焊接结构件制造的质量问题追溯与不良分析：部署与升级

## 这个品类的数据长什么样
焊接结构件制造的业务数据涵盖焊接工艺评定、焊接工艺规程、焊材领用记录、焊工资格记录、焊缝检验报告、返修单等标准化文档。数据来源包括设计图纸、材料质保书、焊接设备参数、焊材库管理系统、无损检测系统、人员资质台账。数据更新以每条焊缝、每批焊材或每班作业为节奏，单条数据关联母材材质、焊接电流电压、检测图像、操作人员资质等多维度字段，无统一固定单位，随业务环节动态匹配对应参数。

## 这些特征在「部署与升级」这一环带来什么约束
该品类高频、多源且关联度高的数据特征，对部署环节带来多重约束。首先，焊缝级的高频数据更新要求数据库连接池配置适配高频读写，避免连接耗尽影响业务连续性。其次，多源异构数据接入需求，需要配置多数据源连接参数，兼容设备接口、台账系统的不同格式。再者，单条焊缝数据关联多维度字段，向量存储的容量配置需匹配变长内容的存储需求。最后，追溯需求要求留存全流程历史数据，需明确数据留存周期与清理策略，适配业务合规性要求。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | `mongodb://username:password@host:27017/fastgpt_welding?authSource=admin` | 适配多源焊接业务数据的存储需求，指定专属数据库名隔离业务数据 |
| `REDIS_URL` | `redis://:password@host:6379/0` | 用于缓存高频查询的焊工资质、焊材库存信息，降低数据库负载 |
| `DB_MAX_LINK` | `20–30` | 匹配焊缝级高频读写的并发需求，避免连接池资源耗尽 |
| `FE_DOMAIN` | `http://192.168.1.100:3000` 或对应局域网域名 | 允许局域网内生产现场设备访问控制台，适配现场部署场景 |
| `FILE_TOKEN_KEY` | 随机生成的32位字符串 | 用于加密文件上传令牌，防止未授权访问焊接工艺文档等敏感文件 |
| `STORAGE_S3_ENDPOINT` | `http://minio-host:9000` | 用于存储无损检测图像、返修单等大文件，适配焊接业务的非结构化数据存储 |

本配置适用于FastGPT v4.17.0版本。

## 容易做错的三处
- 现象：修改管理员密码后服务无法启动，或控制台登录提示权限异常。原因：未正确同步环境变量配置，重启服务时未加载更新后的权限参数。
- 现象：局域网内设备输入部署机器的对外IP无法访问控制台，仅容器内部IP可正常访问。原因：`FE_DOMAIN`配置仅绑定了容器内部IP，未设置为局域网对外可访问的地址。
- 现象：通过Nginx配置二级目录后，页面加载失败或接口请求返回404错误。原因：仅修改了前端框架的BasePath配置，未同步更新`FE_DOMAIN`中的路径前缀，导致资源请求路径不匹配。

## 怎么确认配好了
- 执行对应部署方式的状态检查命令，确认所有FastGPT相关进程处于运行状态。
- 访问`FE_DOMAIN`配置的地址，登录控制台后进入数据连接测试页面，确认数据库、Redis连接状态正常。
- 上传一份焊接工艺规程文档，触发向量生成与存储流程，确认文件上传与索引生成无报错。
- 模拟发起焊缝追溯查询请求，验证返回结果包含母材信息、焊接参数、检测记录等关联字段。
