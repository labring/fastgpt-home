# 生物制品与无菌生产的质量问题追溯与不良分析：模型接入与配置

## 这个品类的数据长什么样
该品类的数据主要来自细胞库与种子批记录、培养纯化记录、无菌灌装记录、洁净区环境监测数据、培养基模拟灌装结果、无菌检验报告及批放行资料。数据来源覆盖细胞库管理、生产过程分析、洁净区监控、生产执行系统（MES）、实验室信息管理系统（LIMS）及设备完整性测试结果，更新节奏涵盖每批生产周期、实时监测数据及固定周期的计划监测内容，字段包含批次编号、培养温度、洁净区沉降菌数、无菌检验结果等，随记录类型变化无统一固定单位。

## 这些特征在「模型接入与配置」这一环带来什么约束
多源异构的数据来源要求模型接入需支持跨系统数据的统一解析，适配MES、LIMS等不同系统的字段格式。实时与按批次的更新节奏，要求配置需支持动态调整上下文刷新频率，匹配生产过程的实时监控与批记录的批量处理需求。字段无统一单位的特征，要求模型需兼容带单位的数值、文本混合的记录内容，避免因单位不匹配导致解析失败。同时，该品类的质量问题后果严重，配置需包含严格的参数校验与失败告警机制，防止错误配置引发数据处理异常。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `maxContext` | 8000–12000 token | 适配该品类单批生产记录的平均文本长度，覆盖多源关联数据的上下文需求 |
| `maxTokens` | 2000–3000 token | 满足不良分析报告的输出长度，确保涵盖完整的追溯逻辑与结论 |
| `quoteMaxToken` | 1500 token | 限制引用的原始记录长度，避免过长引用干扰模型分析逻辑 |
| `toolChoice` | auto | 允许模型自主选择是否调用工具处理多源数据，适配复杂的追溯分析场景 |
| `temperature` | 0.2–0.4 | 降低生成结果的随机性，确保质量追溯结论的严谨性与一致性 |
| `AIPROXY_API_ENDPOINT` | 按部署环境填写 | 适配本地或云端的大模型接入路径，满足生产环境的网络隔离要求 |
| `AIPROXY_API_TOKEN` | 按实际接入密钥填写 | 保障大模型调用的身份验证安全，符合医药生产的数据安全规范 |

## 容易做错的三处
- 现象：调用本地大模型时返回状态码400参数不兼容报错。原因：直接沿用线上API的`temperature`默认取值，未适配本地大模型的参数范围要求。
- 现象：导入LIMS数据后，模型分析结果中部分字段为空。原因：未适配该品类数据无统一单位的特征，未配置字段解析规则，导致部分带单位的数值无法被正确识别。
- 现象：提交不良分析请求后，模型未关联多源生产数据，仅返回泛泛的结论。原因：错误将`toolChoice`设置为固定值，限制了模型自主调用关联数据工具的能力。

## 怎么确认配好了
- 导入单批生产的完整记录，检查模型能否正确关联细胞库、培养过程、检验结果等多源数据。
- 提交模拟不良分析请求，核对输出结果的严谨性与字段匹配度。
- 查看大模型调用日志，确认`AIPROXY_API_ENDPOINT`与`AIPROXY_API_TOKEN`配置正确，无认证报错。
- 调整`temperature`参数，验证生成结果的随机性是否符合业务要求。
- 确认当前使用的FastGPT版本为v4.17.0，确保配置项兼容。
