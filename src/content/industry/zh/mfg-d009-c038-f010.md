# 生物制品与无菌生产的质量问题追溯与不良分析：知识库检索与召回

## 这个品类的数据长什么样
本品类的数据来自细胞库与种子批、过程分析系统、洁净区监测数据、MES、LIMS及设备完整性测试结果。日常文档包含细胞库或种子批记录、培养纯化记录、无菌灌装记录、环境监测报告、培养基模拟灌装记录、无菌检验报告与批放行资料。数据更新节奏为每批生产周期、实时监测触发或按固定监测计划执行。单份文档多包含批次编号、工艺参数、检验数值、操作人员记录等字段，部分参数需匹配法定计量单位，如温度以摄氏度计、菌落数以CFU/皿计。

## 这些特征在「知识库检索与召回」这一环带来什么约束
本品类数据的多源异构特性要求检索需兼容结构化工艺记录、非结构化检验报告等多种格式，每批或实时更新的数据需保证索引时效性，避免召回过期信息。生产批次的强关联性要求检索结果需精准匹配目标生产批的所有关联文档，防止跨批次数据混淆。单份文档包含的工艺参数、检验数值需严格匹配法定单位与字段定义，检索召回的内容需可直接用于质量问题溯源，不能出现字段缺失或单位错误。同时，质量问题关联的后果严重，要求检索召回的信息需具备高可信度，避免无关或错误信息干扰分析。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定，适配本品类的质量追溯与不良分析需求。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 本品类需精准匹配工艺参数与批次信息，避免低相似度的无关文档干扰溯源分析 |
| `limit` | `前8–12条` | 单批生产关联的文档数量有限，召回过多会增加上下文处理负担，过少则可能遗漏关键溯源信息 |
| `searchMode` | `vector` | 本品类需基于工艺参数、检验数值等语义内容检索，向量搜索更适配非结构化文档的语义匹配需求 |
| `usingReRank` | 开启 | 多源异构数据的语义相似度可能存在偏差，重排可提升关键信息的排序优先级，适配质量追溯的精准性要求 |
| `datasetSearchUsingExtensionQuery` | 开启 | 可通过扩展问题优化检索范围，覆盖生产批关联的所有潜在文档，避免遗漏跨系统的溯源信息 |
| `collectionIds` | 绑定本品类专属知识库集合 | 隔离其他品类的文档，确保检索结果仅包含本企业生物制品与无菌生产的相关记录，提升溯源效率 |

## 容易做错的三处
- Excel文件导入知识库后，自动拆分结果为多行合并为一条，无法实现一行一条的条目拆分。未正确配置自定义分隔符，或未指定按行作为拆分依据，导致系统默认的分块规则未匹配Excel的行结构。
- 基于QA拆分的文件集合检索速度较慢，无法满足实时追溯的需求。未针对本品类的批次关联文档优化`limit`与`usingReRank`配置，或未绑定专属知识库集合导致检索范围过大。
- 上传文件到知识库时出现`upstream connect error or disconnect/reset before head`报错。知识库服务与文件存储服务的连接超时，或大体积工艺文档超出单次上传默认限制，导致连接中断。

## 怎么确认配好了
- 检索测试时，输入某生产批的批次编号，核对召回结果是否仅包含该批次的关联文档，无跨批次的无关内容。
- 输入工艺参数关键词，核对召回结果的排序是否符合业务优先级，关键文档是否位于前列。
- 检查知识库集合的绑定配置，确认仅包含本品类的细胞库记录、检验报告等专属文档。
- 上传Excel测试文件，核对自动拆分结果是否按行生成独立条目，符合自定义分隔符的配置要求。
