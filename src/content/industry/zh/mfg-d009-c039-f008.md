# 电机与发电机制造的质量问题追溯与不良分析：文档解析与分块

## 这个品类的数据长什么样
该品类数据来自电机厂绕线、绝缘、总装与试验部门的日常业务产出，包括绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试报告、型式与出厂试验报告。数据来源涵盖电磁设计数据、铜线和绝缘材料批次、绕线设备、平衡机、电气试验台及ERP/MES系统，更新频率为每台/每批产出或每次型式变更时。数据字段包含工艺参数、测试数值、批次信息、设备编号等，带有明确的单位标注，如匝数、兆欧级绝缘电阻值、振动幅值等。

## 这些特征在「文档解析与分块」这一环带来什么约束
绕组工艺卡、试验报告等文档的字段多为带单位的工艺/测试参数，且批次信息与设备编号需精准关联，因此分块需保留字段关联性，避免拆分破坏参数组。不同文档的格式差异较大，既有结构化表格也有纯文本段落，需适配多格式解析。每台/每批的文档更新频率高且关联具体批次，解析后需保留批次与文档的绑定关系，避免分块后丢失溯源信息。同时，耐压、温升等测试数据的数值精度要求高，分块时需确保关键数值不被拆分到不同块中，影响后续质量分析的上下文完整性。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本的官方规则：
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `chunkSize` | 800–1200 字符 | 适配绕组工艺卡、试验报告中带单位的参数组长度，避免拆分关键工艺或测试数据块 |
| `chunkSplitter` | 按段落+表头拆分 | 适配结构化表格与纯文本混合的文档格式，保留工艺参数与说明的关联性 |
| `customPdfParse` | 启用 | 准确提取PDF格式的试验报告中的表格与字段，避免文本错位 |
| `PARSE_FILE_TIMEOUT_SECONDS` | 120 秒 | 适配单份大型型式试验报告的解析时长，避免超时中断 |
| `chunkSettingMode` | 手动模式 | 针对不同文档类型（工艺卡、试验报告）单独调整分块规则，确保批次信息与参数绑定 |
| `UPLOAD_FILE_MAX_SIZE` | 100 MB | 适配单份大型型式试验报告的上传限制，避免解析前上传失败 |

## 容易做错的三处
- 知识库分块展示出现未渲染的Markdown标记，原因是未启用`customPdfParse`导致结构化表格解析异常，保留了原始排版标记。
- 传入链接后无法解析文档内容，原因是未配置`PARSE_FILE_TIMEOUT_SECONDS`的合理取值，或链接指向的文档超出`UPLOAD_FILE_MAX_SIZE`限制。
- 分块列表中无法复制chunk ID，原因是前端渲染逻辑未绑定分块ID的复制事件，未针对批量导出的分块数据做ID展示优化。

## 怎么确认配好了
- 上传一份绕组工艺卡PDF，检查解析后的分块是否保留了完整的工艺参数组，未拆分关键数值与单位。
- 上传一份带表格的型式试验报告，确认解析后的文本未出现排版错位或原始Markdown标记残留。
- 传入外部文档链接，验证解析任务在预设超时时间内完成，未出现超时中断。
- 查看分块列表，确认每个分块的ID可被选中复制，无展示异常。

文中的配置项名称与取值区间需以所用版本的实际界面与文档为准。
