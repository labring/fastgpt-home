# 电机与发电机制造的质量问题追溯与不良分析：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据来自电磁设计文档、铜线与绝缘材料批次记录、绕线设备日志、平衡机运行数据、电气试验台测试结果，以及ERP/MES系统的生产与物料数据。日常生成的文档包含绕组工艺卡、绝缘处理记录、动平衡报告、耐压绝缘测试报告、型式与出厂试验报告。数据更新节奏为每台产品或每批次生产完成更新，每次产品型式变更时同步更新关联文档，文档字段包含绕组匝数、浸漆烘干参数、振动幅值、温升数值、耐压等级等，带有明确的工艺参数与测试单位。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据按单台或单批次更新，且包含大量专业工艺与测试参数，在知识库检索与召回环节带来多重约束。首先，检索需关联生产批次、设备编号等标识，才能精准定位对应产品的工艺与测试数据；其次，专业字段如绕组匝数、耐压等级需精准匹配，避免无关结果干扰分析；多来源数据格式存在差异，需统一分块规则以保证召回一致性；高频更新的生产与测试数据，要求索引更新节奏匹配生产节拍，防止数据滞后；同时，不良分析需同时召回工艺参数与测试结果，单次召回的内容范围需覆盖关联文档类型。

## 配置怎么定
本配置基于FastGPT v4.17.0版本，具体配置项及依据如下：

| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `similarity` | `0.75–0.85` | 该品类需精准匹配绕组匝数、耐压等级等专业参数，避免低相关结果干扰不良分析 |
| `limit` | `前10条` | 单次召回需覆盖同批次的工艺卡、试验报告等多类文档，同时控制上下文长度 |
| 分块长度 | `800–1200 字符` | 适配绕组工艺卡、试验报告等文档的段落长度，避免关键参数被拆分 |
| 分块重叠长度 | `120 字符` | 保证绕组匝数、浸漆参数等跨段落的专业内容可被完整召回 |
| `usingReRank` | `开启` | 专业数据的语义相似度判断易受参数单位干扰，重排可提升结果相关性 |
| `datasetSearchUsingExtensionQuery` | `开启` | 可通过扩展工艺、测试相关的同义词，提升专业内容的召回率 |
| `collectionIds` | `绑定电机制造专属文档集合ID` | 仅召回该品类的工艺、测试与生产数据，避免混入无关知识库内容 |

## 容易做错的三处
- 现象：上传文档后，知识库数据集的索引状态长时间停留在「索引中」，无进度更新。原因：未匹配该品类高频更新的生产数据节奏，设置的索引触发频率与生产更新频率不匹配，或单批次导入的文档数量超出系统单次处理上限。
- 现象：更换嵌入模型后，检索结果的相似度分值达到10000+，无法通过阈值过滤无关结果。原因：未重新校准`similarity`阈值，新模型的相似度分值区间与原模型不一致，导致阈值设置无法生效。
- 现象：上传文档后，知识库无对应索引条目，后台日志显示无可用频道。原因：未在系统中配置对应嵌入模型的可用频道，导致文档无法完成向量化处理。

## 怎么确认配好了
- 上传单份该品类的绕组工艺卡，等待索引完成后，检索预设的专业关键词，核对召回结果的相关性是否符合分析需求。
- 检索同批次产品的动平衡报告，核对召回结果是否包含该批次的所有关联文档类型，数量是否符合单次搜索上限设置。
- 更换嵌入模型后，重新调整相似度阈值，通过检索已知正确的工艺参数，验证阈值可有效过滤无关结果。
- 查看知识库后台的索引日志，确认该品类的文档已完成向量化处理，无报错信息。
