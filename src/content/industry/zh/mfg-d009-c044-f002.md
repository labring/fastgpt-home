# 纸浆造纸的质量问题追溯与不良分析：向量模型与索引

## 这个品类的数据长什么样
该品类的数据来源包括木浆废纸批次台账、DCS/QCS生产控制系统、纸机在线测量设备、实验室检测系统、能源与水处理系统。日常生成的文档包含配浆单、打浆记录、纸机运行记录、在线质量曲线、实验室报告、断纸与换品记录。数据更新节奏覆盖实时、每班、每卷三个维度，字段包含浆料批次号、打浆浓度、纸机车速、克重、水分、厚度等，对应单位通常为g/㎡、%、mm、m/min等。

## 这些特征在「向量模型与索引」这一环带来什么约束
该品类的数据混合了结构化台账、半结构化运行日志与非结构化曲线、报告，且更新节奏差异大，要求索引同时支持批量全量更新与近实时增量同步。高速连续幅材生产带来的横纵向多测点数据，要求索引能够关联时序与空间维度的字段信息。多类型文档的解析结果需要统一的分块规则，避免因字段单位差异（如g/㎡、%）导致的向量嵌入偏差。同时，质量追溯需快速定位历史数据，要求检索延迟控制在可接受范围内，避免影响生产排障效率。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本制定。

| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配配浆单、打浆记录等文本的平均长度，避免分块过碎丢失上下文或过长导致嵌入偏差 |
| 重叠长度 | 100–150 字符 | 覆盖跨分块的生产流程关联信息，比如打浆过程的连续参数变化 |
| `maxToken` | 4096 token | 适配主流大模型的上下文窗口限制，避免截断关键的纸机运行参数 |
| 相似度阈值 | 0.75–0.85 | 过滤低相关性的历史记录，匹配生产数据的时序一致性特征 |
| 单次搜索上限 | 前 10 条 | 兼顾检索效率与数据完整性，覆盖单卷纸的主要生产环节记录 |
| `defaultToken` | 2048 token | 配置基础上下文的默认长度，适配实验室报告的摘要检索需求 |

## 容易做错的三处
- 现象：无法通过One API完成向量模型的配置，界面返回API调用失败提示。原因：未正确配置One API的代理地址与密钥绑定，导致模型调用链路中断。
- 现象：检索返回的结果条数远低于预期，无法定位到指定批次的断纸记录。原因：未针对浆料批次、纸卷编号设置索引过滤规则，导致召回了跨批次的无关数据。
- 现象：嵌入后的向量相似度计算结果偏差过大，无法区分不同克重的纸页数据。原因：未对数值型字段（如克重、水分）做归一化处理，导致单位与数值范围差异影响向量嵌入效果。

## 怎么确认配好了
- 上传单份配浆单文档，检查分块后的文本片段长度是否符合预设的分块规则，无过度截断或冗余拆分的情况。
- 发起针对特定纸卷批次的检索请求，核对返回结果是否包含该批次的关联记录，且数量符合单次搜索上限的配置。
- 调用向量嵌入接口处理长文本的在线质量曲线解析结果，确认任务可正常完成，无超时或截断报错。
- 调整相似度阈值的配置，观察检索结果的相关性变化，确认阈值设置适配当前业务的匹配精度需求。
