# 纸浆造纸的质量问题追溯与不良分析：知识库检索与召回

## 这个品类的数据长什么样
纸浆造纸的业务数据来源包括木浆废纸批次档案、DCS/QCS系统、纸机在线测量设备、实验室检测系统、能源与水处理系统。日常产出的文档涵盖配浆单、打浆记录、纸机运行日志、在线质量曲线、实验室检测报告、断纸与换品记录。数据更新节奏覆盖实时（在线质量数据）、每班（运行日志）、每卷（断纸与换品记录）。文档包含浆料配比、打浆度、克重、水分、厚度等专业字段，单位涉及g/㎡、%、mm、吨等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
实时性数据占比高，要求知识库的增量更新频率匹配每班、每卷的业务节奏，避免召回过时的批次数据。多类型结构化与半结构化文档并存，需支持按字段（如批次号、纸卷编号）过滤检索，缩小无效结果范围。高速连续幅材生产的质量问题涉及配浆、打浆、纸机运行多环节关联，召回结果需覆盖全链条文档，避免遗漏关键关联项。专业术语较多（如打浆度、叩解度），需支持语义扩展查询，覆盖同义词与行业专属表述。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| `similarity` | `0.75–0.85` | 纸浆造纸的质量参数关联性强，阈值过低会引入无关的水处理或能源记录，过高会遗漏关键的配浆、打浆匹配项 |
| `limit` | `前8–12条` | 高速生产的质量问题涉及多环节关联数据，足够的召回条数可覆盖配浆、打浆、纸机运行的全链条记录 |
| `searchMode` | `mixedRecall` | 查询示例结合了领域术语与自然语言语境；请用代表性数据比较验证，不将其视为产品默认值。 |
| `usingReRank` | `开启` | 在线质量曲线、实验室报告等多类型文档的语义相似度需二次校准，提升不良分析的匹配精准度 |
| `datasetSearchUsingExtensionQuery` | `开启` | 配浆单、打浆记录的专业术语较多，通过扩展查询可覆盖同义词（如打浆度与叩解度），扩大检索召回范围 |
| `collectionIds` | `绑定制浆、抄纸、质量检测三类专属知识库集合` | 不同部门的文档分类清晰，按业务部门绑定可缩小检索范围，降低无关结果占比 |

## 容易做错的三处
- 现象：检索结果仅返回少量单条文档，无法覆盖配浆、纸机运行的全链条关联数据。原因：`limit`参数取值过低，未覆盖多环节的关联记录需求。
- 现象：回答中引用的知识库条目未按批次关联，出现跨批次的无效参考内容。原因：未配置`searchMode`为批次关联模式，未绑定`collectionIds`到对应批次集合。
- 现象：大模型未引用知识库内容，直接生成通用回答。原因：未开启`datasetSearchUsingExtensionQuery`导致专业术语匹配失败，或`similarity`阈值设置过高，过滤了所有有效召回结果。

## 怎么确认配好了
- 上传单份指定批次的配浆单与断纸记录，执行“某批次纸卷出现克重偏差”的查询，核对召回结果包含对应批次的配浆参数与断纸时间记录。
- 调整`similarity`参数至0.75，查看检索结果的语义匹配度，确认无明显无关的水处理记录混入。
- 开启`usingReRank`后，对比开启前后的检索结果排序，确认高相关性的实验室报告被前置展示。
- 查看FastGPT v4.17.0的知识库配置面板，确认`collectionIds`已绑定对应业务部门的知识库集合。
