# 计量器具与实验室管理的质量问题追溯与不良分析：向量模型与索引

## 这个品类的数据长什么样
本品类数据来自计量管理系统、LIMS、外部校准机构证书、标准器及环境监测设备。日常文档包含量具台账、校准计划、校准证书、期间核查记录、试验原始记录、标准物质台账与偏离处置文件。数据更新按校准周期、单次试验结果或异常事件触发，字段包含器具编号、校准有效期、测量不确定度、合格判定项，部分字段带mm、N等计量专用单位。

## 这些特征在「向量模型与索引」这一环带来什么约束
本品类数据的半结构化属性与专业计量术语，要求向量模型适配量具、不确定度、溯源链等专用语义，避免专业字段的语义偏差。非固定更新频率要求索引支持增量同步，仅处理新增或修改的校准证书、台账记录，无需全量重建。跨文档关联的溯源需求，需索引保留文档间的关联字段，支持按器具编号、校准周期串联检索相关记录。高可信度要求下，索引的召回逻辑需优先匹配计量相关的精准字段，减少无关结果返回。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| --- | --- | --- |
| 分块长度 | 800–1200 字符 | 适配校准证书、试验记录的单页内容长度，避免语义断裂 |
| 重叠长度 | 100–150 字符 | 保留跨分块的计量术语关联，比如不确定度描述跨分块的部分 |
| 相似度阈值 | 0.75–0.85 | 匹配计量数据的严谨性，过滤低相关的非计量类内容 |
| 单次搜索上限 | 前 10 条 | 控制召回结果的数量，避免冗余信息干扰溯源分析 |
| maxToken | 按所选嵌入模型/服务支持的最大输入 token 数设置 | `maxToken` 表示所选嵌入模型/服务支持的最大输入 token 数；请按模型或服务配置核对，参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不是检索/LLM 上下文，也不是 FastGPT 全局固定上限。 |
| defaultToken | 按代表性样本文档实测设置 | `defaultToken` 是直接文本分块使用的默认 token 数，请用本品类代表性原文实测调整；参见 [FastGPT v4.17.2 模型字段说明](https://github.com/labring/FastGPT/blob/v4.17.2/document/content/self-host/config/model/intro.mdx)。它不表示向量维度、嵌入模型输入上限或检索/LLM 上下文。 |

## 容易做错的三处
- 现象：向量索引任务长时间无进度，后台日志显示扫描耗时过长。原因：未针对计量文档的非固定更新节奏配置增量索引，触发了全量重建流程。
- 现象：搜索计量器具溯源问题时，返回大量与校准、测量无关的冗余内容。原因：相似度阈值设置低于合理区间，召回了不相关的非计量类文档。
- 现象：导入导出应用后，原有知识库的向量关联关系丢失。原因：仅导出了应用配置文件，未同步导出对应的向量索引元数据。

## 怎么确认配好了
- 查看向量索引的任务日志，确认仅处理了新增或修改的计量文档，未触发全量重建流程。
- 输入一条计量溯源相关的测试问题，核对返回结果是否包含器具编号、校准日期等计量专属字段。
- 检查配置项的取值是否匹配当前计量文档库的规模与内容长度。
- 验证导入导出应用后，向量索引的关联关系未发生异常。
