# 金属切削加工的质量问题追溯与不良分析：知识库检索与召回

## 这个品类的数据长什么样
本品类数据覆盖机加工全流程，来源包括产品图纸与三维模型、CAPP/CAM系统、机床采集数据、刀具管理系统、MES系统及量检具记录。日常文档包含工艺路线、工序卡、刀具清单、数控程序、首件检验记录、巡检表与量具校准记录。数据更新随每工单、每件工件或抽检、刀具更换触发，文档字段含工序编号、切削参数、刀具寿命、检验公差值与校准周期等，单位涵盖转速、进给量、寿命小时、公差微米等。

## 这些特征在「知识库检索与召回」这一环带来什么约束
本品类的数据分散且更新触发条件多样，要求知识库检索需支持按工单ID、工序编号、刀具编号等多维度精准过滤，避免召回不相关的历史数据。文档包含结构化参数与非结构化数控程序文本，需适配不同内容的召回权重配置，确保工艺参数、检验记录与程序代码均可被有效检索。数据更新随工单、抽检或刀具更换触发，需保证检索结果实时关联最新的工序调整、刀具寿命与校准记录，避免使用过期文档。字段单位多样，需在检索匹配中统一参数识别逻辑，避免因单位差异导致召回失败。

以下配置基于FastGPT v4.17.0版本。
## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | 0.75–0.85 | 匹配金属切削加工的工艺参数、检验记录等结构化内容的精度要求，避免召回低相关的历史数据 |
| `limit` | 前10条 | 覆盖单工序可能关联的刀具、检验、程序等多类文档，避免结果过多超出上下文长度 |
| `searchMode` | 混合检索 | 兼顾结构化字段匹配与全文语义检索，适配工艺路线、数控程序等多样文档类型 |
| `usingReRank` | 开启 | 提升高相关文档的排序优先级，尤其针对刀具磨损、尺寸漂移等需要精准匹配的不良分析场景 |
| `datasetSearchUsingExtensionQuery` | 按实测标定 | 适配金属切削加工的专业术语，优化检索词的扩展逻辑，提升召回精准度 |
| `collectionIds` | 绑定当前车间/工单的数据集ID | 缩小检索范围，避免召回其他车间的不相关工艺文档 |

## 容易做错的三处
- 现象：检索时返回的文档条数固定为默认值，无法通过配置修改上限。原因：未启用高级配置模式，仅使用了基础配置的默认`limit`取值。
- 现象：在知识库测试界面可正常启用重排功能，但通过API调用大模型生成回答时，重排结果未生效。原因：API调用时未同步开启`usingReRank`配置项，仅在测试界面完成了设置。
- 现象：检索结果中出现多份内容完全一致的工序卡或数控程序。原因：未开启数据集的文件去重开关，或导入时未按工单ID过滤重复上传的文档。

## 怎么确认配好了
- 进入知识库检索配置界面，检查`similarity`、`limit`、`usingReRank`等配置项的取值是否与预设一致。
- 上传一份测试用的工序卡与刀具清单，执行检索，确认返回的文档条数不超过`limit`的设置值。
- 开启重排功能后，检索「刀具磨损导致尺寸漂移」的问题，确认高相关文档的排序优先级高于低相关内容。
- 导入两份内容完全一致的工艺路线文档，执行检索，确认仅返回一条结果，验证去重配置生效。
