# 钣金下料折弯的质量问题追溯与不良分析：工具调用与插件

## 这个品类的数据长什么样
钣金下料折弯场景面向机柜机箱、通风设备、电气柜、非标设备等金属成形制造商，核心数据来自CAD/CAM软件、订单BOM系统、板材库存台账、激光切割机与折弯机设备日志、车间MES系统。日常产出的文档包括零件展开图、数控下料程序、折弯工艺卡、套料图、首件检验记录、工序流转卡。数据更新节奏随订单执行、每日库存盘点、每次工艺换型调整，字段包含折弯补偿量、孔位坐标、切割路径参数、板材利用率、尺寸偏差值等，无统一固定格式，需适配多类数据源结构。本页面基于FastGPT v4.17.0版本编写。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源异构的数据来源要求工具调用需支持对接不同类型的系统接口，适配CAD文件、工艺表格等多格式文档解析。高频更新节奏要求工具调用需实时拉取最新的订单数据与设备日志，避免使用过期的折弯系数或套料方案。多品种小批量的业务模式要求工具可动态匹配不同零件的展开参数与折弯顺序，无需固定模板。同时，不良分析需精准校验尺寸偏差，工具调用的结果准确性直接影响后续装配与板材利用率，需严格校验返回数据的字段完整性。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| 工具调用开关 | 开启 | 启用外部工具对接钣金下料折弯的多源数据源 |
| 工具调用超时时间 | 300–600 秒 | 适配数控下料程序、CAD展开图的解析与数据拉取耗时 |
| 单次工具调用返回条数 | 前 3 条 | 匹配单订单少批量的钣金零件数据量，避免冗余信息干扰 |
| `toolChoice` | auto | 让模型自主选择适配钣金场景的专用工具 |
| `functionCall` | 启用 | 支持结构化调用折弯系数查询、尺寸偏差校验等专用工具 |
| 工具数据源绑定 | 绑定CAD/CAM、MES、板材库存接口 | 匹配该品类的核心数据来源路径 |

## 容易做错的三处
- 现象：调用`api/v1/chat/completions`时出现跨域报错，状态码显示403 Forbidden。原因：未在FastGPT后台配置跨域白名单，未允许外部前端域名访问接口。
- 现象：启动工具调用流程时提示缺少MCP server依赖。原因：未按要求部署MCP服务作为工具调用的中间节点，无法完成外部数据源的请求转发。
- 现象：调用不良分析流程图时返回“chat：llm—model—response-empty”。原因：工具调用未正确拉取指定零件的折弯工艺卡或展开图数据，导致模型无有效上下文生成回复。

## 怎么确认配好了
- 发起一次测试调用，输入指定订单号，查看工具是否能拉取对应零件的折弯工艺卡与展开图数据。
- 检查后台配置的`toolChoice`与`functionCall`参数是否处于启用状态，无异常报错日志。
- 配置前端测试域名，发起跨域请求，确认接口可正常返回响应内容。
- 模拟一次不良分析场景，输入已知尺寸偏差的零件数据，查看工具是否返回对应的偏差原因与整改建议。
