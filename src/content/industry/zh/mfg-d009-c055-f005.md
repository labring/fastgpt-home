# 铸造（砂型、精密、压铸）的质量问题追溯与不良分析：工具调用与插件

## 这个品类的数据长什么样
该品类的数据主要来自ERP物料主数据、熔炼炉测温设备、光谱分析仪、MES生产系统、模具管理系统及客户技术图纸。日常留存文档包含铸造工艺卡、合金配料单、炉次运行记录、模具履历表、首件检验记录、材质报告与不合格品评审单。数据更新节奏为每炉次、每生产批次或每日，核心字段包含炉次编号、合金成分参数、浇注温度、模次信息与回炉料配比参数。

## 这些特征在「工具调用与插件」这一环带来什么约束
多源异构的数据来源要求工具调用需配置多个跨系统插件，每个插件需匹配对应数据源的鉴权与接口格式。高频更新的炉次、批次数据要求工具触发时机绑定生产节点，避免冗余调用。核心字段的特定格式要求工具调用的参数校验规则适配铸造行业的炉次编号、温度参数等格式。批量核对合金配料、追溯缺陷关联炉次与模次的需求，要求工具支持代码运行插件完成多数据比对与关联查询。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
|---|---|---|
| `toolChoice` | `auto` 或指定代码运行、联网搜索插件 | 匹配不同质量追溯场景的工具调用需求，比如批量配料比对使用代码运行，外部标准查询使用联网搜索 |
| `functionCall` | 开启 | 强制模型按结构化格式调用工具，确保返回结果可被解析用于缺陷追溯与数据关联 |
| 工具调用超时时间 | `120–180 秒` | 适配熔炼、光谱分析等设备数据返回的平均耗时区间，避免单工具调用超时终止整体流程 |
| 单次工具调用返回条数 | `前 8 条` | 覆盖单炉次关联的模具、配料、检验等核心数据量，避免冗余信息干扰分析 |
| 插件鉴权配置 | 按数据源类型预设参数 | 匹配ERP、MES、模具管理系统等不同系统的接口鉴权规则，确保数据拉取成功 |
| 代码运行环境 | Python 3.10 环境 | 适配铸造行业数据比对常用的数据分析库，提升批量处理效率 |

## 容易做错的三处
- 现象：工具调用配置界面无法选择代码运行插件，无连线配置区域。原因：未在系统设置中启用代码运行工具权限，或当前版本未适配该插件的连线逻辑。
- 现象：调用联网搜索插件后返回空结果。原因：未配置联网插件的必要参数，或检索关键词未匹配铸造行业质量追溯文档的格式规范。
- 现象：工具调用返回的字段无法关联炉次与缺陷类型。原因：未针对铸造行业的炉次编号、温度参数等配置工具调用的参数校验规则，导致数据拉取格式错误。

## 怎么确认配好了
- 进入工具调用配置界面，确认`toolChoice`选项包含代码运行、联网搜索等所需插件。
- 触发一次测试调用，输入模拟炉次编号，检查是否能拉取对应配料单、炉次记录等关联数据。
- 查看工具调用日志，确认每个插件的返回结果格式符合预设的铸造行业字段要求。
- 在FastGPT v4.17.0版本中，验证代码运行插件的连线配置区域正常显示，可拖拽连接至对应节点。
