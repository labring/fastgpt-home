# 锂离子电芯制造的质量问题追溯与不良分析：数据库与运维

## 这个品类的数据长什么样
该品类数据涵盖配料批次台账、涂布辊压参数记录、卷绕或叠片操作日志、注液台账、化成分容曲线、OCV与安全测试报告等。数据来源包括原材料批次台账、生产MES系统、浆料与涂布检测设备、车间露点监测装置、化成分容柜及实验室测试仪器。数据更新频率覆盖单批物料、单只电芯维度，部分参数如车间露点、化成分容实时曲线为毫秒级更新。单条记录包含批次号、时间戳、设备编号、检测数值、操作人员编号等字段，单位涉及毫安时、帕斯卡、摄氏度等电化学与工业检测标准单位。

## 这些特征在「数据库与运维」这一环带来什么约束
该品类的数据特征对数据库与运维环节带来多重约束。多源异构的数据接入需要适配不同协议的生产设备与测试系统，实时数据需支持低延迟写入能力。单只电芯的全链路追溯需按批次、个体关联存储，对数据库的关联查询性能要求较高。高更新频率会带来持续的写入压力，需合理分配连接资源避免服务阻塞。电化学检测的高精度数值需保留足够精度字段，不宜过度压缩导致数据失真。同时，数据需保留全生命周期链路，不可随意删除或修改历史记录，需配置不可变存储策略，区别于普通电子装配的轻量数据存储要求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本编写。
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `MONGODB_URI` | 格式为`mongodb://[用户名]:[密码]@[主机]:[端口]/[数据库名]?authSource=admin` | 适配多源异构的生产设备与测试数据存储，支持高并发写入与跨批次关联查询 |
| `PG_URL` | 格式为`postgresql://[用户名]:[密码]@[主机]:[端口]/[数据库名]` | 用于存储结构化的批次台账、测试报告元数据，支持复杂条件的追溯查询 |
| `DB_MAX_LINK` | `200–300` | 匹配单批电芯生产的并发写入请求，避免连接耗尽导致的服务中断，按实测标定 |
| `REDIS_URL` | 格式为`redis://[密码]@[主机]:[端口]/[数据库索引]` | 用于缓存实时露点、化成分容的临时数据，降低主数据库的直接查询压力 |

## 容易做错的三处
- 连接Mongo数据库时出现认证失败报错，返回状态码401。原因是未正确配置`MONGODB_URI`中的authSource参数，未匹配生产数据库的认证源。
- 本地部署时请求外部服务接口超时，返回状态码504。原因是未配置合理的请求超时阈值，未适配外部设备与系统的网络延迟。
- 数据库连接池耗尽，出现`too many connections`报错。原因是未设置合理的`DB_MAX_LINK`参数，未匹配生产环境的并发写入请求量。

## 怎么确认配好了
- 执行数据库连接测试脚本，验证`MONGODB_URI`与`PG_URL`能否正常建立连接，查看返回的连接状态是否正常。
- 模拟单批电芯的实时数据写入请求，观察`DB_MAX_LINK`的连接使用情况，确认连接数未达到上限阈值。
- 发起外部服务接口请求，验证请求能否正常返回数据，确认超时阈值适配外部服务的响应速度。
- 查看Redis缓存的实时监测数据，确认缓存写入与读取流程正常运行。
