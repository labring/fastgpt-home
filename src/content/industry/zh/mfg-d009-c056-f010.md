# 锂离子电芯制造的质量问题追溯与不良分析：知识库检索与召回

## 这个品类的数据长什么样
该品类的数据覆盖动力、储能、消费电池企业极片、装配、化成与品质部门的全流程记录，日常文档包含配料记录、涂布辊压参数、卷绕或叠片记录、注液记录、化成分容数据、OCV与安全测试报告。数据来源涵盖原材料批次、MES系统、浆料与涂布检测设备、露点监测装置、化成分容柜及实验室数据，更新频率为每批、每只电芯级别，部分参数实时同步。电化学体系对水分、洁净度与批次一致性要求极高，后段化成分容环节需留存长时间运行曲线数据。

## 这些特征在「知识库检索与召回」这一环带来什么约束
该品类的数据特征对检索召回环节带来多重约束：按单批、单电芯实时更新的属性，要求检索系统快速匹配最新批次的工艺参数与历史不良记录；多类型专业文档包含浆料配比、涂布辊压参数、露点值等高精度字段，需模型精准识别专业术语与单位关联；长周期化成分容曲线数据体量较大，需限制单次召回的内容长度与条数，避免超出上下文窗口；电化学体系对水分、洁净度与批次一致性的强关联要求，需检索优先匹配同批次的环境与工艺数据。

## 配置怎么定
| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `similarity` | `0.75–0.85` | 匹配浆料、涂布等专业参数的精度要求，兼顾召回完整性与相关性 |
| `limit` | `前8–12条` | 平衡单批次数据体量与上下文窗口占用，避免检索结果过载 |
| `searchMode` | `语义+关键词混合检索` | 适配专业术语与数值参数的双重匹配需求，提升不良分析的精准度 |
| `usingReRank` | `开启` | 对召回的多批次数据进行二次排序，优先匹配同批次的工艺与不良关联记录 |
| `datasetSearchUsingExtensionQuery` | `开启` | 扩展检索范围，关联原材料批次与化成环节的测试数据，覆盖全链路追溯需求 |
| `collectionIds` | `按生产批次绑定对应数据集ID` | 限定检索范围仅覆盖当前批次的工艺与检测数据，减少无关结果干扰 |

## 容易做错的三处
- 调用知识库API时使用通用鉴权KEY，导致检索范围超出当前生产批次的允许数据，出现跨批次无关结果。原因是通用KEY未绑定指定的`collectionIds`，未限定检索的数据集范围。
- 导入知识库数据时出现训练报错，现象为系统提示格式不兼容。原因是未按照FastGPT v4.17.0的csv模板调整字段结构，或混入了非本品类的非标准文档内容。
- 知识库检索返回结果条数远低于设定值，现象为仅返回少量结果。原因是未正确配置`limit`参数，或本地部署时未调整检索模块的引用上限限制，导致提前截断检索结果。

## 怎么确认配好了
- 核对`collectionIds`参数是否绑定了当前生产批次对应的数据集ID，确保检索范围仅覆盖目标批次的工艺与检测数据。
- 验证`similarity`参数的取值区间是否符合本品类专业参数的匹配精度要求，可通过检索已知不良批次的工艺数据核对召回结果的相关性。
- 测试检索长周期化成分容曲线数据，确认单次召回的内容长度与条数未超出上下文窗口限制，避免出现内容截断。
- 检查`usingReRank`和`datasetSearchUsingExtensionQuery`是否开启，可通过检索关联的原材料批次与化成数据，确认结果是否覆盖全链路追溯需求。
