# 锂离子电芯制造的质量问题追溯与不良分析：部署与升级

## 这个品类的数据长什么样
本品类数据来源于原材料批次台账、生产MES系统、浆料与涂布检测设备、车间露点监测装置、化成分容柜及实验室测试报告。日常文档包含配料记录、涂布辊压参数台账、卷绕/叠片工序记录、注液操作日志、化成分容数据报表、OCV与安全测试报告。数据更新节奏为每批次、单只电芯维度实时同步，字段包含批次号、工艺参数值、检测结果、环境指标等，单位涵盖重量百分比、毫米、毫伏、秒、毫安时等。

## 这些特征在「部署与升级」这一环带来什么约束
锂离子电芯制造的数据多源且实时性强，包含精密工艺参数、环境监测指标与单只电芯测试数据，部署时需预留适配多源接入的资源。数据更新频率覆盖批次、单只与实时，需配置支持高并发查询与批量导入的参数。化成分容环节数据体量较大，需合理设置数据库连接上限。电化学体系对数据准确性要求高，配置需匹配数据字段与更新节奏，避免同步异常。同时，生产数据涉及工艺细节，部署需满足本地存储与访问隔离的要求。

## 配置怎么定
本页面适配FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `DB_MAX_LINK` | `100–150 个连接` | 适配多工序数据同步与实时查询的并发需求，匹配电芯制造多环节数据交互的场景 |
| `MONGODB_URI` | 指向存储工序记录、化成分容数据的专用MongoDB实例 | 用于存储非结构化的工艺日志与实时检测数据，支持灵活的字段扩展 |
| `REDIS_URL` | 配置为本地缓存实例，内存配额设为`8 GB` | 缓存高频查询的露点监测、配料参数数据，降低数据库查询压力 |
| `STORAGE_S3_ENDPOINT` | 指向企业内部对象存储服务的内网地址 | 存储OCV测试报告、安全检测文档等大体积文件，避免公网传输延迟 |
| `FE_DOMAIN` | 填写企业内网访问的域名或IP:端口 | 适配生产车间内网访问的场景，避免公网暴露内部系统 |
| `ROOT_KEY` | 由部署团队随机生成的32位字符串 | 用于配置文件的签名验证，保障部署权限的安全性 |

## 容易做错的三处
- 现象：docker部署后3000端口页面无法访问，3001端口可正常打开。原因：未正确配置`FE_DOMAIN`指向内网访问地址，或前端容器端口映射参数设置错误。
- 现象：升级新版本后，知识库可查询到匹配内容，但模型无法输出最终结果。原因：配置文件中`REDIS_URL`未正确更新，导致上下文缓存失效，模型无法获取完整检索结果。
- 现象：私有部署环境出现未捕获异常。原因：配置文件中`MONGODB_URI`或`PG_URL`的连接参数包含非法字符，或数据库权限未开放至部署服务器。

## 怎么确认配好了
- 执行`docker ps`命令，确认前端、数据库、缓存相关容器均处于运行状态，端口映射参数与配置文件一致。
- 导入一批测试用的涂布辊压参数数据，通过系统查询接口验证数据同步成功，字段匹配配置的映射规则。
- 访问配置的`FE_DOMAIN`地址，登录系统后发起单条电芯数据的追溯查询，确认检索结果与原始数据一致。
- 修改配置文件中的`ROOT_KEY`后重启服务，验证非授权访问无法进入系统后台，确认权限配置生效。
