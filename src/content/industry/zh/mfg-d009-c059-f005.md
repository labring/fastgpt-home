# 预拌混凝土生产的质量问题追溯与不良分析：工具调用与插件

## 这个品类的数据长什么样
该品类数据来自工程订单、砂石水泥外加剂检验、含水率测定、搅拌站控制系统及工程项目试验室。日常文档包含配合比通知单、开盘鉴定、生产运输单、原材料检验记录、试块台账与强度报告。数据更新按每车生产批次、每批原料进场、每日试验室检测的节奏更新。数据字段涵盖原料含水率、配合比参数、坍落度指标、试块强度值，单位包含千克、立方米、毫米、兆帕。

## 这些特征在「工具调用与插件」这一环带来什么约束
该品类数据更新频率高且颗粒度细，工具调用需支持实时拉取最新的含水率、生产单数据，避免使用过期的静态文档。多类文档格式混杂，插件需适配不同结构的试验记录与生产单据，需配置统一的字段映射规则。单次调用需处理多源数据聚合，工具参数需支持按批次、按原料类型筛选数据，避免返回冗余信息。试块强度报告需滞后验证，工具调用需支持跨时间范围的历史数据回溯，匹配质量追溯的时间跨度要求。

## 配置怎么定
以下配置基于FastGPT v4.17.0版本。

| 配置项 | 建议取法 | 这样取的依据 |
| ---- | ---- | ---- |
| `toolChoice` | 按实测标定 | 适配预拌混凝土场景下的多类工具调用需求，支持原料检验、试块强度回溯等功能 |
| 工具调用超时时间 | 60–120 秒 | 适配多源生产与试验数据的聚合耗时，避免因数据拉取延迟导致调用中断 |
| 文档筛选规则 | 按生产批次匹配 | 匹配预拌混凝土按车、按批的更新节奏，精准关联当前批次的配合比与检验数据 |
| `functionCall` | 启用字段合法性校验 | 验证含水率、坍落度、强度值等核心字段的格式与取值范围，过滤无效调用请求 |
| 插件数据源绑定 | 绑定搅拌站控制系统、试验室检测接口 | 拉取实时更新的生产数据与试验记录，确保追溯数据的时效性 |
| 结果返回上限 | 前 3–5 条 | 聚焦当前批次的关联数据，避免返回冗余的历史信息干扰分析 |

## 容易做错的三处
- 现象：调用BI图表插件时返回固定地址`api.example.com`，无法替换为企业内部接口地址。原因：未在插件配置中更新目标接口地址，直接沿用了默认占位配置。
- 现象：通过`/api/core/dataset/update`接口发起调用时返回500错误，浏览器访问该接口却可正常使用。原因：未配置API调用的身份验证参数，服务端拒绝了无权限的外部调用请求。
- 现象：工作流中调用外部模型时无法实现流式输出，结果仅在调用结束后一次性返回。原因：未启用`functionCall`的流式返回配置，或未设置正确的输出格式适配流式数据传输。

## 怎么确认配好了
- 发起一次针对当前生产批次的工具调用，验证返回的数据包含配合比、原料含水率与试块强度记录，确认数据源绑定正确。
- 触发字段合法性校验，输入超出合理范围的坍落度数值，确认调用被拦截并返回错误提示，确认校验配置生效。
- 查看插件调用日志，确认接口地址与企业内部系统一致，验证目标地址配置正确。
- 启动流式输出测试，确认外部模型调用时逐段返回分析结果，验证流式配置生效。
