# B2B平台撮合交易的商品资料与选型问答：向量模型与索引

## 这个品类的数据长什么样

在B2B平台撮合交易的商品资料与选型问答中，本页说明FastGPT的向量模型与索引如何衔接资料。不同索引命中的品名能否回到带有使用限制的同一条原数据？所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

自拟询报价单把商品写成工业用温度传感器，并注明仅供室内设备配套。索引检查不能停在是否出现了传感器这个词，还应回查该索引指向的完整原数据。一个数据块可关联多个索引，可以为测试提出品名问法与使用场景问法，再查看它们各自命中哪条原文。检查记录需要保留室内条件是否随引用返回，商品适用性的最终判断仍需对应规格依据，不能从命中分数直接推出。

## 配置怎么定

| 核对项 | 本题输入或条件 | 检查目标 |
| --- | --- | --- |
| 向量模型 | 关联库采用相同向量模型 | 实际模型与该资料的输入类型 |
| 原数据与索引 | 同一数据块可对应多条索引 | 品名问法和场景问法各自的原文 |
| 索引内容 | 保留室内说明与户外说明的来源身份 | 没有合成未获支持的适用结论 |
| 图片索引 | 图片来源先核实际入库处理 | 转为文字的核提取结果；图片检索路径再核描述或图片向量。 |
| 版本与结果复核 | 模型或索引变更后复用同组问题 | 工作温度依据与仍缺的条件 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 索引只留传感器品名、遗漏室内限制时，对照索引文本、原数据和引用，定位条件在哪一环丢失，不能由命中分数推出户外适用。

- 户外控制箱说明与当前室内询报价混用时，核两份资料的型号、版本和索引目标，先确认是否同一商品。

- 温度范围问题仅取回品名却得到具体数值时，追查规格原文。补充图片已接收不证明数值已被读取，还需核实际文字或图片处理结果。

## 怎么确认配好了

询报价单没有工作温度范围，命中商品名也不能提供这项规格依据。若补充说明只以图片提供，应先核实际入库路径：已经转为文字的，对照原件检查提取结果；采用图片检索的，核相应描述或图片向量，再用温度范围问题回查来源。接收文件、形成可检索内容和规格数值有原文支持，应分别记录。仍未提供的条件继续列为缺项，不从相似度或图片接收状态推定规格完整。
