# B2B平台撮合交易的商品资料与选型问答：引用来源与溯源

## 这个品类的数据长什么样

在B2B平台撮合交易的商品资料与选型问答中，本页说明FastGPT的引用来源与溯源如何衔接资料。旋接说明支持连接方式，灰色展示件尚不能定义供货颜色。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

自拟选型资料分为两份：接口说明写“主机使用旋接连接，附件另列”，样品观察表只记“展示件为灰色”。问题同时问连接方式与常规供货颜色时，前半句可以回指接口说明，后半句尚缺供货清单。FastGPT的引用内容需要保留两份材料各自的原文范围；把样品颜色接到接口段落后面，会让读者误以为同一份规格文件已经确认两个条件。这里还应区分可观察的灰色展示件与可采购的配置：观察表没有列颜色可选范围，也未说明附件与展示件的关系，因此不能以展示照片的同框对象扩大供货清单。需要取得写明供货对象的文字再核。

## 配置怎么定

| 本题核对项 | 材料条件 | 取证动作 |
| --- | --- | --- |
| 连接方式 | 接口说明中的结构句 | 逐字回指旋接关系。 |
| 颜色身份 | 展示件观察与供货标准分开 | 补核正式供货颜色资料。 |
| 片段内容 | 引用数组含有结构句 | 核回答实际收到的文字。 |
| 附件条件 | 附件另列 | 保留范围限定及来源。 |
| 空引用排查 | 本次未附结构片段 | 查检索范围及片段传递。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

核对引用时，应把回答中的每个属性单独落到对应片段。常见错误是引用标题含“规格”的观察表，却从标题推导正式供货属性；另一个风险是引用数组确有内容，但传给回答的文字只有附件说明，连接结构那一句没有进入其中。前者要补查文件身份与适用范围，后者要检查实际传入片段，不能凭引用数量判断依据充分。第三处是颜色问题没有带回任何引用，便直接写成不存在供货颜色资料。此时应回查本次范围及片段传递记录，区分未传入与文件确实未取得，不能用空数组给供货资料下存在性结论。

## 怎么确认配好了

建议分别提出“如何连接”“灰色是否为供货标准”“附件是否随主机提供”三个问题，再记录答案、实际引用文字与待补材料。验收时，连接结论应能逐字回到结构说明，颜色只表述为样品观察，附件条件应保持另列。引用为空时继续追查本次检索范围与片段传递；空数组本身不能证明供货清单从未存在，也不能补出未写明的规格。
