# B2B平台撮合交易的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

在B2B平台撮合交易的商品资料与选型问答中，本页说明FastGPT的模型接入与配置如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「模型接入与配置」这一环带来什么约束

B2B选型练习可把询报价中的文字分成采购方提出的定制需求、供应方给出的型号及另附规格指向，再配企业认证资料核主体。接入要检查这些主语和关系是否随原句送达，不能只找产品词。采购方希望按某条件定制，不说明供应方已有相应成品；型号出现也不代表规格附件已经取得。回答应分别指出它在解释哪一方的话、依据哪份文件。某项要求是否能满足，需要实际技术条件，经营范围和一段定制意向都不能替代这项比对。

## 配置怎么定

| 接入或实施核对项 | B2B选型材料 | 检查目标 |
| --- | --- | --- |
| 实际输入 | 询报价型号与认证主体文字 | 哪份原文及哪些条件送达 |
| 资料职责 | 主体身份与规格说明分开 | 不由认证资料推定产品性能 |
| 范围差异 | 经营范围与产品类别各有出处 | 模型不裁定资质或适用性 |
| 规格缺项 | 定制需求尚无技术附件 | 补充后同题回查新增条件 |
| 输入路径 | 本例只验证文字 | 图片或工具能力另按需要测 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `AI Proxy依赖` | 按实际版本核服务、渠道与应用。 |
| `AIPROXY_API_ENDPOINT` | 使用AI Proxy服务根地址。 |
| `AIPROXY_API_TOKEN` | 管理员Token非空且与服务端一致。 |
| `模型能力` | 按实际输入路径验证所需能力。 |
| `应用参数` | 接口同名字段未必覆盖应用设置。 |

## 容易做错的三处

- 询报价规格没有进入请求，却声称已读产品条件：保留资料清单与实际输入，沿选择和传入路径定位，不以服务响应替代送达。

- 经营范围与产品类别不同，被回答写成资质不合格或已具交付能力：并列两处原文与结论，另取相应业务证明，模型选择不能裁定资质。

- 原文只有采购定制需求，回答却补出确定技术规格：逐句回查尺寸或能力的出处，缺证据仍列待补，补附件后同题核新增引用。

## 怎么确认配好了

询报价单只有定制需求而没有技术规格说明时，应保留这项缺证据状态。模型参数无法提供未知规格，输出提到的尺寸、能力或交付条件需要各自出处。补充适用的规格附件后，用相同问题和设置复测，记录新原文是否送达、回答采用了哪段条件。当前文字输入不证明图片或工具路径已经验证；能力测试应按实际资料形式分别安排。
