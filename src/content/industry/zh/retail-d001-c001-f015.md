# B2B平台撮合交易的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在B2B平台撮合交易的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

B2B选型检索可另拟一段询报价说明：“阀体采用标准接口；密封材料需按用途另行确认。”问接口形式与问材料是否适用，实际需要的证据不同。先用接口原词找出对应句子，再用包含用途限制的完整问法比较语义、全文和混合检索。返回阀体名称并不能回答密封材料问题，引用也需保留“另行确认”，不能把一个商品描述扩成全部使用条件已经核定。

## 配置怎么定

| 文档项或实施核对 | 本题材料与条件 | 取证动作 |
| --- | --- | --- |
| 检索范围（实施核对） | 询报价与样品记录分别作为来源 | 展示记录不能代替材料说明。 |
| 搜索模式（语义/全文/混合） | 接口原词与包含用途的完整问题 | 比较三种模式实际取回的原句。 |
| 引用token上限 | 用途限制需随接口说明保留 | 检查“另行确认”是否被裁剪。 |
| 最低相关度 | 语义检索或重排时核过滤行为 | 高分不等于用途适用性已核。 |
| 问题优化 | 追问“这款是否可用” | 核优化问题没有新增许可或用途。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

再提供一份自拟样品记录，只写“已展示接口样式”，可用于检查相近术语会不会盖过真正的用途限制。两份资料分别保留身份，核候选属于询报价还是样品展示，再看回答是否把“展示过”写成“适用性已验证”。引用上限按token控制，不能只数片段；若截掉用途这一侧的条件，需回到原文记录遗漏位置，并用相同问题复核。

## 怎么确认配好了

密封材料说明尚未提供时，先明确当前输入只有接口描述和样品记录。问题优化可帮助处理指代，但不能替代缺少的材料依据，尤其不能把“这款是否可用”扩写成原资料没有的应用许可。取得对应说明后再测试同题，分别查看新增原文进入候选和引用的情况；最低相关度只在语义或重排条件下检查，不据分数认定实际用途适用。
