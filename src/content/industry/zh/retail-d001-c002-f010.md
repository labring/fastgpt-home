# MCN机构达人管理的商品资料与选型问答：引用来源与溯源

## 这个品类的数据长什么样

在MCN机构达人管理的商品资料与选型问答中，本页说明FastGPT的引用来源与溯源如何衔接资料。活动确认范围与待确认培训练习有不同证据身份。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

为MCN商品问答自拟一份活动范围确认单和一份主播培训提纲。确认单仅允许介绍杯盖开合与收纳方式，培训提纲另有“可演示倒置”的练习句，旁注写待品牌确认。有人询问能否对外宣称密封性能时，两份材料的身份决定引用边界：培训例句能解释排练内容，尚不能证明该性能已经获得确认。需要把旁注随例句一起保留，避免引用只留下积极表述。杯盖能开合与倒置时是否密封是不同属性。确认了操作介绍范围，并没有同时确认倒置测试的条件、观察方式或对外说法。引用范围确认单时，应让这项属性缺口保持可见，不能靠培训练习补齐。

## 配置怎么定

| 本题核对项 | 材料条件 | 取证动作 |
| --- | --- | --- |
| 允许范围 | 确认单列两项介绍内容 | 追溯范围原句。 |
| 练习旁注 | 倒置演示待确认 | 核引用是否带上旁注。 |
| 版本关系 | 培训修改时间较新 | 找明确替代或确认依据。 |
| 执行问题 | 排期只记已安排 | 补查实际执行材料。 |
| 引用覆盖 | 现有片段均来自培训提纲 | 登记确认单是否真正传入。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

这里容易发生两种误读：把培训文档的新修改时间当成活动范围已更新，或把排期表里的“已安排”当成演示已实际完成。前一项应核是否存在正式替代关系及确认材料，后一项要找实际执行记录。FastGPT显示来源名称只能帮助定位，不能替材料完成这些判断。引用数组若只包含培训提纲，即使有多条片段，也没有补上品牌确认的缺口。

## 怎么确认配好了

验收可分别问“本次允许介绍什么”“倒置练习是否已确认”“演示是否实际发生”。回答应将允许范围落到确认单，将练习状态连同待确认旁注回指培训提纲，将执行问题保留为待核。抽查引用时对照原文与实际传入内容，确认没有截掉限制条件。没有引用的回答要追查范围和传递路径，不把它改写成对活动结果的肯定或否定结论。
