# MCN机构达人管理的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在MCN机构达人管理的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

MCN商品资料可以另拟一段培训记录：“演示样品为试用装；直播赠品另见账号排期附注。”解析时应保留演示样品与赠品的不同角色，不能把试用装直接写为直播将赠送的商品。先对照这两个分句与解析结果，再用“演示的是什么”和“赠品是什么”分别检索，核返回内容是否只支持其中一问，而没有提供另一问所需附注。演示样品和赠品两个词应随各自分句保留，避免章节标题被移除后混在一起。是否取到排期附注，应以实际原数据为据，不能由培训内容相关就推定已有。可另设一个失败输出样例：“赠品为试用装”。若解析文本这样合并两句，原文只把试用装写为演示样品；应并列保存原句、解析片段和检索返回位置，定位角色合并发生在哪一步，赠品本身仍需回到实际排期核对。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或条件 | 回查线索 |
| --- | --- | --- |
| 解析角色 | 演示样品与直播赠品 | 不能把试用装改写为赠品。 |
| 分段完整性 | 护肤品范围与设备配件排除 | 保留“不包含”及其对象。 |
| 原数据与索引 | 培训记录与达人合同独立 | 搜索摘要不能拼接推广安排。 |
| 样本检索 | 分别问演示物和赠品 | 注明当前哪一问有原文支持。 |
| 更新后复核 | 缺账号排期附注 | 补入后核解析及索引状态。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

自拟达人合同还可写“推广范围为护肤品，不包含设备配件”，用于检查否定条件是否与范围词同在。若分块只留下设备配件这一名词，不能把检索命中解释成合同允许推广它。原数据与索引应分别查看，保留合同和培训记录各自身份；两份材料即使都涉及直播，也不能被拼成一段没有来源的商品推广安排。另一种问题是分段只留下“设备配件”，没有取回同句的“不包含”。这时须回查原数据的完整范围句，并比较被引用的分块与索引，辨别条件已在解析中丢失，还是原文完整但检索没有取到；不能只凭名词命中恢复推广范围。

## 怎么确认配好了

账号排期附注未提供时，赠品问题缺少直接材料，应记录需要补充的来源，不由解析器或模型填入商品名。取得对应附注后，核其解析文字、训练或索引状态，再用原问题复测。若附注确实在原文中而输出没有，应保留遗漏位置及同题结果，区分材料缺失、解析遗漏与召回未取到三个环节，不能把上传成功当作赠品依据已到位。
