# MCN机构达人管理的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在MCN机构达人管理的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

这道选型题首先要找的是签约合同列出的商品品类。自拟材料已经写出允许推广的类型，测试可分别用条款中的品类名称和自然问句发起检索，比较返回片段是否包含完整范围。全文、语义与混合模式都应使用同一份合同作对照，记录各自找到的原文；一次命中某个商品词，尚不足以回答该词前后的限制。若还关联账号排期资料，应先核资料库使用的向量模型，再检查排期内容有没有挤掉合同依据。

## 配置怎么定

| 核对项 | 本题取法与条件 | 验收线索 |
| --- | --- | --- |
| 关联的知识库 | 拟议合同与账号排期；多库需同向量模型 | 记录实际采用的资料范围 |
| 搜索模式 | 同合同对照语义、全文、混合模式 | 允许品类条款是否随美妆字样返回 |
| 引用上限 | 按token计，用长条款选择取值 | 合同限制与数码排期两处均保留 |
| 最低相关度 | 范围0–1；仅语义或重排时生效 | 标注品类依据及无关佣金条款 |
| 问题优化 | 比较改写前后的完整问题 | 品类范围未被扩大成型号许可 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

- 合同只允许美妆，引用却只剩商品名时，对照完整条款和实际引用，查限制是否被裁掉。

- 数码直播排期被答成合同允许范围时，分别保存合同与排期出处；安排了某类商品不说明合同已经调整。

- 只有佣金条款却回答具体型号已获准时，核实际候选与型号问题的关系，并检查优化是否新增了原文没有的商品主体。

## 怎么确认配好了

另一份测试合同只有佣金比例，没有具体型号的推广要求。继续查询型号限制时，即使召回了佣金条款，也需要检查它与提问的关系，不能据相关片段推断某型号已经获准。验收记录应列出缺少的型号要求、实际召回内容与回答所作表述。补充对应材料后再重复同题，并检查问题优化是否沿用了正确商品主体；资料补齐和搜索参数调整分别记录，才能说明答案依据发生了什么变化。
