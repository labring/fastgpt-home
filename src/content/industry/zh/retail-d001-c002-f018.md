# MCN机构达人管理的商品资料与选型问答：重排与混合检索

## 这个品类的数据长什么样

在MCN机构达人管理的商品资料与选型问答中，本页说明FastGPT的重排与混合检索如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「重排与混合检索」这一环带来什么约束

达人商品问答的候选应落到合同允许推广的品类条款。自拟签约合同列出商品类型时，可用“允许推广哪些商品”和条款中的品类原词组成一组测试，记录召回内容是否确有范围及限制。重排要接收完整问题，避免把培训记录或其他相近业务文字排到前面后，就省略真正决定阅读范围的合同句子。这里核的是文字覆盖，未执行合同或排期审批。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或适用条件 | 回查与验收线索 |
| --- | --- | --- |
| 融合候选 | 合同的美妆范围与排期表的数码直播 | 确认两种商品品类表述各有出处。 |
| 完整问题 | 达人允许推广的品类与实际排期文字 | 不能只问直播内容而丢掉合同范围。 |
| 最低相关度 | 按语义或重排条件检查过滤 | 核合同限制是否在筛选后消失。 |
| 引用token上限 | 范围条款及其限制需一并引用 | 美妆限定不能缩写成无条件商品推广。 |
| 缺资料复测 | 佣金条款未提供具体型号推广要求 | 取得型号资料后核新增条款的引用。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `混合检索` | 向量与全文结果通过RRF融合。 |
| `结果重排` | 按完整问题对候选再次排序。 |
| `最低相关度` | 过滤仅在语义或重排时生效。 |
| `引用上限` | 按token裁剪引用内容。 |
| `问题优化` | 比较优化前后主体与限制。 |

## 容易做错的三处

自拟合同限定美妆，账号排期却安排数码直播，两份文字需要并列查看。检查候选里是否都有对应达人及品类说明，再对照排序结果有无漏掉合同限制。不能只采用更贴近“数码直播”问法的排期片段，就把合同也解释为允许数码。若引用token上限裁掉了限制，先记录被删去的位置，调整后复测同一问题，保留双方出处。合同限制与排期安排应分别回指所属材料，验收要能解释每段在回答中承担的角色。单独引用直播安排时，仍需保留合同范围这一待核条件。

## 怎么确认配好了

仅写佣金结算方式的合同无法为具体型号的推广要求提供直接条款。这个缺项要在测试记录中单列，不能靠提高某个合同片段的排名获得型号限制。补充适用的商品推广资料后，再看新增条款是否进入候选并被正确引用；同时核对原问与优化后问题，防止“商品型号”被扩展成原材料没有的推广许可结论。
