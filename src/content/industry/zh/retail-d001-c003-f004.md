# Shopify独立站订单履约的商品资料与选型问答：向量模型与索引

## 这个品类的数据长什么样

在Shopify独立站订单履约的商品资料与选型问答中，本页说明FastGPT的向量模型与索引如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

独立站商品索引可用新拟订单说明：“磨砂杯，单杯装；礼盒需另购。”围绕款式和包装分别设计搜索文字时，都要回到这段原数据。款式问题能读到磨砂，包装问题需保留单杯装与礼盒另购的关系；不能因两个入口指向同一商品，就把另购项当成订单已包含的组成部分。索引文字和原文含义应分别检查。

## 配置怎么定

| 核对项（含实施核对） | 具体原数据或索引 | 验收线索 |
| --- | --- | --- |
| 向量模型 | 订单与规格库若关联同一检索节点 | 核该节点关联库使用相同向量模型。 |
| 原数据与索引 | 单杯装及礼盒另购的订单原句 | 索引不能变成已含礼盒。 |
| 索引内容 | 款式与包装两种问法 | 分别查看命中的原数据。 |
| 图片路径 | 容量仅在待取得规格图中 | 按实际文字或图片路径检查对应输出。 |
| 变更复测 | 固定款式、包装、容量问题 | 比对引用变化，不单看分数。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是入口写“带礼盒的磨砂杯”，原订单仍写礼盒另购。应逐词对照索引与订单，保留另购条件，不能由包装问法增加已包含属性。第二处是入口名称正确，却指向另一订单的包装原文；应核索引所指原数据的订单身份，不能只看磨砂杯名称相同。第三处是把另购条件直接回答为本单已购买或未购买。应查对应订单的实际选购记录；条件说明、数据映射与购买结果各需依据，索引命中不完成成交事实核验。核订单身份时还要看礼盒条件属于当前杯款还是另一笔交易；名称相同不代表包装选择相同。核选购结果时，应读取本单具体条目，不能把可选说明再次当作成交凭证。即使入口已经指向正确订单，也仍要区分原文只介绍选项，还是实际列了已选礼盒。

## 怎么确认配好了

杯子容量若只在尚未提供的规格图中说明，增加款式索引不能补出容量值。取得对应材料后，先查实际按文字还是图片处理；前者逐字核提取结果，后者才核图片描述或向量，并用容量问法追到对应来源。模型或索引调整前后保留同一组商品问题，分别记录哪些原数据被引用、哪些属性仍没有依据；不能由相似分数升高推定全部商品参数均已覆盖。还需排查索引回指错误对象：若本订单的包装问题取回另一条订单或规格记录，名称相近也不是本题证据。应对照提问所指订单、索引目标及返回来源的身份和版本，先解决映射问题，再检查容量或包装文字是否满足当前问题。
