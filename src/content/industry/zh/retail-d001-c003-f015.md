# Shopify独立站订单履约的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在Shopify独立站订单履约的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

独立站商品问答可用新拟订单文字：“短柄雨伞，收纳袋另列。”检索时应区分伞的款式与订单组成，不能只命中收纳袋一词就回答已经随附。先用短柄雨伞和收纳袋两种原词分别查看候选，再用“本订单包含哪些物品”的完整问题比较搜索模式。需要核对的是原文写了什么，以及“另列”的指向是否已有对应清单。

## 配置怎么定

| 文档项或实施核对 | 本题材料与条件 | 取证动作 |
| --- | --- | --- |
| 检索范围（实施核对） | 订单详情、标签和待补清单 | 标签大类不提供随附物明细。 |
| 搜索模式（语义/全文/混合） | 款式词与订单组成问题 | 逐模式核原句及来源身份。 |
| 引用token上限 | “收纳袋另列”的限定 | 不能只保留收纳袋名词。 |
| 最低相关度 | 语义或重排下核最低相关度 | 过滤后仍需查看组成证据。 |
| 问题优化 | 追问是否包括袋子 | 保持当前订单，不借入其他款式。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

另拟一张发货标签，只写“伞具”，它能帮助识别包裹内容的大类，却没有说明收纳袋是否属于本次订单。应保留标签与订单详情各自身份，检查相近商品词是否把订单中的组成限制挤出引用。即使返回多条片段，也需逐条核是否有包含物清单；token上限裁掉“另列”时，简短答复可能失去关键条件，应以原文位置作复核依据。

## 怎么确认配好了

若组成清单尚未提供，当前无法从标签补出随附物。用“袋子也包括吗”作追问时，核问题优化是否仍指向这份订单，没有把前一轮的其他款式带入。补入真实对应清单后，重复相同问题检查新增引用，并将来源补齐和参数变化分别记录。最低相关度按实际生效条件核验；商品名称相关并不表示订单所有组成信息都已经找到。
