# Temu半托管卖家运营的商品资料与选型问答：向量模型与索引

## 这个品类的数据长什么样

在Temu半托管卖家运营的商品资料与选型问答中，本页说明FastGPT的向量模型与索引如何衔接资料。朝向说明只描述摆放，不能被索引扩成双面材质。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

Temu商品索引自拟原文“展示时磨砂面朝外；背面材质见规格页”，另一份摆放图注写“可转向”。问是否两面都是磨砂材质时，原文只有一面的朝向和一个未读来源。可转向说的是展示动作，不能补出背面属性。入口可以覆盖朝向或材质问法，但要分别指回能支持它的文字，不能因为两条都出现面或转向，就把摆放说明概括成双面磨砂商品。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 朝向关系 | 磨砂面朝外 | 回指展示动作。 |
| 背面属性 | 另见规格页 | 保留待读原文。 |
| 入口增义 | 双面磨砂 | 核双面是否有依据。 |
| 目标类型 | 图注只写可转向 | 不当材质说明。 |
| 新增采用 | 规格页补入后的实际引用 | 核原数据与入口目标。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是拟议入口写双面磨砂，却只指向朝外句，应逐词检查新增的双面属性。第二处是背面问题回到摆放图注，应读所指原数据的内容类型，确认它回答的是动作还是材质。第三处是补入规格页后仍引用旧摆放文字，应核新原数据、入口目标与实际返回，不能只看规格文件已上传。三项分别查索引增义、目标适用和更新后采用，当前没有背面依据时不替它补成相同或不同材质。

## 怎么确认配好了

验收分别问展示朝向、背面依据和是否双面磨砂，保留每个问题对应的入口、原句与引用。朝外与可转向可以各自得到说明，背面属性仍待规格。新规格取得后先核适用商品，再用同题比较新增内容，分开记录资料加入与检索设置变化。若同一原数据有多个入口，数量不代表已经覆盖背面；入口词语再完整，也不能代替原文中尚未出现的材料描述。
