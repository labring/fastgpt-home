# Temu半托管卖家运营的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在Temu半托管卖家运营的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

Temu半托管的检索样例可另拟商品申报：“组合A含主体和接头；外包装图另供。”商品组成与包装外观需要不同来源，先用主体、接头这些原词检查候选，再以组合内容的完整问题比较语义、全文和混合搜索。原文能够支持两项组成，但并未说明外包装尺寸；不能因为组合名称已经命中就把待提供图片里的信息也当成已知。

## 配置怎么定

| 文档项或实施核对 | 本题材料与条件 | 取证动作 |
| --- | --- | --- |
| 检索范围（实施核对） | 申报组成、库存记录与缺失包装图 | 三类来源不可互相替代。 |
| 搜索模式（语义/全文/混合） | 主体、接头与组合内容问法 | 查看申报原句是否被取回。 |
| 引用token上限 | 组成与“外包装图另供” | 裁剪后仍需保留资料指向。 |
| 最低相关度 | 语义检索或重排下检查过滤 | 在库片段不构成包装依据。 |
| 问题优化 | 组合A的连续追问 | 不能扩写未给尺寸或换成其他组合。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |

| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

自拟海外库存表若只写“组合A在库”，提供的是库存记录说法，不能补成主体、接头各自的规格表。查询商品组成时，应检查库存片段是否因名称相同被取回，而申报中的组成原句反而未进入引用。两份资料分别留身份，核长片段是否挤掉所问的组成条件。库存存在与商品属性齐全是不同检查，回答不能将它们压成一个结论。

## 怎么确认配好了

外包装图尚未提供时，应明确缺少能说明包装外观的资料；搜索参数不能从“在库”或“组合”推算尺寸。补入对应文字说明或实际图片资料后，核新增内容是否具备可检索的来源，再问同题检查引用。问题优化前后还需保持组合A这一对象；最低相关度仅在语义或结果重排时生效，不能用过滤后的剩余结果表示包装资料已经齐全。
