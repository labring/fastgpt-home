# TikTok Shop美国店运营的商品资料与选型问答：工作流编排

## 这个品类的数据长什么样

在TikTok Shop美国店运营的商品资料与选型问答中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

商品Listing可以提供选型问题的阅读起点，但页面描述与商品的验证依据应在输入中分开。自拟记录可写“Listing列出外观与用途描述，尚未取得对应材质说明”，让表单收集已提供原句及本次要回答的属性问题。核对提交后的传值，检查页面中的宣传描述有没有被改写成已经核实的技术参数，缺少的属性是否仍被保留。

## 配置怎么定

| 核对步骤 | 本题自拟输入 | 应核对的实际结果 |
| --- | --- | --- |
| 描述与依据 | Listing原句及缺少的材质说明 | 宣传文字没有变成已验证参数 |
| 传值检查 | 当前属性问题与已提供页面描述 | 回答步骤收到同一问题及出处 |
| 材料选择 | 查原始商品说明或读退货记录 | 来源身份和适用范围保持可回查 |
| 补说明或图像内容 | 尚未提供的产品依据 | 另验读取路径，再复测属性问题 |
| 页面更新 | 审核意见及真实Listing更新记录 | 生成答复与实际发布分别登记 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

如果另有Return Grading材料或退货反馈，应先确定其对应商品和记录范围，再决定是否补充给当前选型问题。人员可选择回查商品原始说明，或查看该份退货材料能支持的具体内容，分别验证分支连接。退货状态描述不能自动代表全部商品的共同属性，一次选择也不能证明Listing已经修改或商品已符合某项适用条件。 例如，自拟Listing把材质说明留空，而后续回答仍声称已核过材质，就应排查那句话取自哪份提交材料。检查问题中是否夹带了未经证实的描述，以及接收步骤有没有把提问内容当作商品依据；确认来源后，重新运行材质尚缺的同一道问题。

## 怎么确认配好了

对仍未提供的商品说明，应明确资料来源和接收步骤；取得后重复同一属性问题，检查新原文是否真正进入回答。若材料只有图片，图片转成可供阅读内容的处理方式需要另行落实，表单不会自行解析或核实图片。选型结论进入对外页面或售后系统前，还需相应审核及真实更新记录，不能以生成文字代替发布完成。
