# 一般贸易出口报关的商品资料与选型问答：工作流编排

## 这个品类的数据长什么样

在一般贸易出口报关的商品资料与选型问答中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

出口报关材料中的商品名称和装箱描述，可以用于确认单据怎么记载商品，不能直接充当某项用途的完整规格。自拟输入可分别列出商业发票的品名原句、装箱单的包装描述和待问的使用条件，交由表单收集后传向阅读步骤。检查这几段内容是否保持独立来源，避免把运输包装描述写成商品材质、性能或适用性的确定结论。

## 配置怎么定

| 核对步骤 | 本题自拟输入 | 应核对的实际结果 |
| --- | --- | --- |
| 单据范围 | 发票品名及装箱描述原句 | 运输或交易文字没有变为完整规格 |
| 表单接收 | 原文出处及被询问的使用条件 | 后续步骤保留每段来源 |
| 阅读选择 | 补制造方规格或只查看单据 | 两条路径收到不同且有依据的内容 |
| 新增规格 | 制造方材料与固定属性问题 | 答案采用新增依据并保留未知 |
| 外部写入 | 贸易或采购系统的实际操作记录 | 选型答复与业务完成分别确认 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

当采购方问得比单据更细，例如需要制造方对型号用途的说明，流程应先判断实际收集了哪些依据，再安排人员选择补规格资料或只查看单据描述。各选项都要核对真实接收值及后续去向，不能让继续查看单据的路径填入尚未提供的技术信息。报关材料之间的文字一致，也不能代替商品验收、归类判断或供应商资格确认。 装箱资料还可能使用箱数，选型问题却问商品本身的组成。若流程把箱数直接解释成产品套装构成，就出现阅读对象不一致。应回看数量所在表头和原句，确认传给下一步的是包装信息；另行补商品构成说明后，再检查答复是否真正改用新依据。

## 怎么确认配好了

验收时可固定原属性问题，逐段比对表单提交、后续输入和最后回答，确认报价或装箱文字没有越过其材料范围。取得制造方资料后再复测，保留新增出处与仍缺的条件。若还需向贸易或采购系统写入选型结果，应另核业务权限、操作契约和实际记录，不能把资料问答完成解释为报关、采购或产品审核已经结束。
