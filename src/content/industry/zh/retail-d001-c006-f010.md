# 一般贸易出口报关的商品资料与选型问答：引用来源与溯源

## 这个品类的数据长什么样

在一般贸易出口报关的商品资料与选型问答中，本页说明FastGPT的引用来源与溯源如何衔接资料。合同指向交付附件时，还需读取附件中的工具条目。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

出口选型资料可自拟为商业发票条目“支架组件”、装箱说明“立柱与底座分袋”，以及合同内“交付清单见附件”的指向句。问题问整套是否含安装工具时，前两份能说明已列的组件与包装方式，合同指向句只能提示还需查附件。引用它不能代替读取附件内容，分袋也不能证明工具另装或随套附送。回答要把已见条目与缺少的清单正文分开。

## 配置怎么定

| 本题核对项 | 材料条件 | 取证动作 |
| --- | --- | --- |
| 组件名称 | 发票列支架组件 | 核条目与本批对象。 |
| 包装方式 | 立柱与底座分袋 | 限于说明装袋关系。 |
| 附件指向 | 合同提到交付清单 | 取得所指正文再核。 |
| 批次身份 | 装箱说明可能属于别批 | 对照来源适用对象。 |
| 工具结论 | 现有正文未列工具范围 | 补附件并核实际引用。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

两种失误值得单独查：来源表中出现合同链接，但实际引用数组没有交付清单；或引用了另一批次的装箱说明，却沿用本批组件结论。前者属于内容覆盖缺口，应核链接指向及实际传入文字；后者要核批次和适用对象。FastGPT的来源追溯能辅助定位这些差异，不能把同名文件自动视为同一交付范围，更不能从未见工具条目直接认定工具必定不包含。若工具问题只能定位到附件名称而无法看到条目，应停在清单正文缺失；若工具属于另一批次，回答与本批身份会不一致。补证时先排查合同附件对应关系，再按本批对象逐项读取工具条目，不能用组件发票替代工具清单。

## 怎么确认配好了

建议以组件名称、分袋方式、工具是否列明三个问题核对回答。验收保留发票与装箱说明各自能支持的句子，对工具问题注明待补附件原文；取得附件后再检查它是否真正进入引用内容，并与合同指向关系对照。空引用需检查本次资料范围与片段传递。仅有附件名称或可访问链接时，应继续核正文，不能把可定位等同于已取得证明。
