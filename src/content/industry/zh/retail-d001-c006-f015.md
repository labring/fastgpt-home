# 一般贸易出口报关的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在一般贸易出口报关的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

出口商品检索可用新拟商业发票文字：“展示架组件，拆卸状态交付。”这段能够描述商品称谓和交付形态，不能单凭展示架三个字就答成已装配成品。先用组件、拆卸这些原词检查候选，再以“单据写明什么交付形态”的问题比较三种检索模式，核两项限定是否仍与商品相连；此处不进行编码归类，也不从检索结果作报关决定。

## 配置怎么定

| 文档项或实施核对 | 本题材料与条件 | 取证动作 |
| --- | --- | --- |
| 检索范围（实施核对） | 总体形态与包装子项分别核对 | 两份单据不自动组成装配清单。 |
| 搜索模式（语义/全文/混合） | 组件、拆卸及完整交付形态问题 | 比较各模式取回的限定文字。 |
| 引用token上限 | 拆卸状态需与展示架关联 | 裁剪不能只留商品名称。 |
| 最低相关度 | 语义检索或重排时核过滤 | 得分不构成单据归类结论。 |
| 问题优化 | 连续追问交付形式 | 保留组件对象，不补成已装配状态。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

另一份自拟装箱单把“配件袋”单列，可用于检查资料描述的层次。发票描述总体形态，装箱单列包装内的子项，二者不必然互相否定，也不能拼成没有出处的完整组装清单。分别保留原文和文件身份，核被取回的是商品说明还是包装条目。引用token上限若只留下展示架名称而删掉拆卸状态，应记录遗漏位置并重新检查。

## 怎么确认配好了

组件尺寸和具体工艺说明没有提供，展示架与配件袋名称都不能补出这些参数。补齐对应技术资料前，查询应明确列出缺少的来源，不将其扩展成既定规格；补充后用原问题复测，核新增原文与引用。问题优化需保留组件和拆卸这两个条件，最低相关度按生效场景检查，不能用得分或返回条数代替对单据实际描述范围的核对。
