# 一般贸易出口报关的商品资料与选型问答：重排与混合检索

## 这个品类的数据长什么样

在一般贸易出口报关的商品资料与选型问答中，本页说明FastGPT的重排与混合检索如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「重排与混合检索」这一环带来什么约束

出口商品名称比对的样例，商业发票附页写的是“电子元器件”，问题却要求与采购订单核对。候选中先要确认是否真的提供了采购订单；发票文字与问题接近，不能代替订单这一侧。已有两份材料时，再用完整的名称比对问题观察重排，把每个候选所属的文件记录下来。仅取回一张发票，最多能回查其写明的名称。采购订单只是当前核对所需的另一份资料，不是已经存在的知识库字段。取得订单后，需要确认其原文真正进入候选，不能只在提问中写出“订单”二字。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或适用条件 | 回查与验收线索 |
| --- | --- | --- |
| 融合候选 | 发票电子元器件与待取得的采购订单 | 订单未提供时不能声称两边已经比对。 |
| 完整问题 | 商品名称是否与订单原文对应 | 核重排输入是否实际具备订单文字。 |
| 最低相关度 | 仅在语义或重排条件下核参数 | 空候选还需排查资料范围。 |
| 引用token上限 | 发票和合同的两处定性价格表述 | 保留双方出处，不由排名定价。 |
| 缺资料复测 | 发票未附详细技术规格 | 补充规格后核型号要求的实际出处。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `混合检索` | 向量与全文结果通过RRF融合。 |
| `结果重排` | 按完整问题对候选再次排序。 |
| `最低相关度` | 过滤仅在语义或重排时生效。 |
| `引用上限` | 按token裁剪引用内容。 |
| `问题优化` | 比较优化前后主体与限制。 |

## 容易做错的三处

总价样例分别使用“甲类价格”和“乙类价格”作为自拟文字，不涉及真实报价。排序测试应保留商业发票与合同的两处表述，检查有没有将其中一处移到前面后就遗漏另一处。金额或价格说明是否可比较，还要核相同交易、版本及计算范围。RRF融合和后续重排都不承担业务定价判断，结果应回到实际原文，由对应责任人核对。

## 怎么确认配好了

详细技术规格不在现有发票附页中，型号要求就缺少可供匹配的依据。可检查那些看似相关的候选是否仅重复商品名称，再取得所需规格文件复测原问题。保存新增来源进入候选及引用的记录，核对长规格条件是否被token上限裁掉。过滤行为按语义或重排条件查看，不能由发票片段的得分推定商品已满足型号要求。
