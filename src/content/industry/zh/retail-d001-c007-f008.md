# 一般贸易进口报关的商品资料与选型问答：工作流编排

## 这个品类的数据长什么样

在一般贸易进口报关的商品资料与选型问答中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

进口资料中的商品描述，首先服务于这组单据的阅读核对。自拟测试可以给出提单中的包装表述和发票中的品名，同时注明尚无制造方使用说明。表单接收这两处原句及具体选型问题后，检查下一步是否仍能区分包装方式、交易名称与商品用途。资料里没有写明的性能不能由流程补出，到港或进口记录也不能单独证明商品适合某项生产条件。

## 配置怎么定

| 核对步骤 | 本题自拟输入 | 应核对的实际结果 |
| --- | --- | --- |
| 三类文字区分 | 包装描述、交易品名、待核用途 | 输入没有把三者混为同一属性 |
| 资料身份 | 提单及发票对应的商品范围 | 后续步骤收到可回查原句 |
| 人工路径 | 核型号、补制造方文档或暂缓 | 各选项与实际接收步骤对应 |
| 新说明复测 | 制造方依据及原选型问题 | 引用真实新增内容并保留未知条件 |
| 外部处理 | 查询、采购或入库的实际记录 | 文字核对与业务执行分开验收 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

当不同材料使用不同名称，应先确认是否指向同一批商品，再考虑补充商品说明或继续阅读原文。可让资料负责人选择核型号对应关系、查看制造方文档或暂缓回答，分别验证连接分支与收到的内容。名称经过人工确认后，也只解决本次资料对应问题；不能把这次选择扩展为商品归类、质量或用途已经获得全面确认。 一项可复现的阅读失败，是把提单上的唛头当作制造方型号，继而回答型号适配问题。应展示唛头所在原文及厂家说明的缺口，比较提交前后字段含义；在确有型号资料进入前，下一步只解释提单标识，不让错误的商品身份继续传递。

## 怎么确认配好了

验收应保留原选型问题、两份材料身份以及所需制造方依据。补充资料后，逐项检查表单提交与回答输入，确认新增说明确实被引用，仍未知的条件没有被猜测。需要外部查询时，按实际服务契约另接接口并核权限与返回；需要采购或入库处理时，继续检查相应业务记录，不能由文字核对流程完成推定这些动作已发生。
