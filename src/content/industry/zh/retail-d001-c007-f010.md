# 一般贸易进口报关的商品资料与选型问答：引用来源与溯源

## 这个品类的数据长什么样

在一般贸易进口报关的商品资料与选型问答中，本页说明FastGPT的引用来源与溯源如何衔接资料。散装接头的货物条目与木箱包装各有自己的主语。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

进口商品问答自拟两份普通文字材料：商业发票将货物列为散装接头，装箱单写外装木箱；技术规格正文尚未提供。用户追问“是不是整机、是否木制”时，要先分清货物形态和运输包装。木箱这个来源只支持外包装，散装接头条目支持所列货物名称，两者都不应被扩成整机配置或接头材质。引用应精确到条目和对象，避免标题相近造成属性挪用。散装还需要结合所问范围阅读：它描述本条所列接头，并不说明木箱内所有货物的组装程度。若问题改为整批是否含整机，应取得覆盖整批的货物清单，不能将单一条目的证据扩大到其他未读条目。

## 配置怎么定

| 本题核对项 | 材料条件 | 取证动作 |
| --- | --- | --- |
| 货物对象 | 发票列散装接头 | 保留条目身份。 |
| 包装对象 | 木箱修饰外包装 | 核句子主语及范围。 |
| 材质依据 | 接头组成未见规格 | 登记待补技术文字。 |
| 行级错配 | 链接正确但片段可能不同 | 逐行对照引用与提问对象。 |
| 总成范围 | 尚未核其他同运清单 | 不从单行推断全批构成。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

一种常见错误是引用装箱单的木箱句回答产品材质，另一种是来源链接指向正确文件，实际传入段落却来自另一行货物。前者需重新核句子主语，后者需对照被引用条目与本题货物身份。来源可打开并不解决行级错配；引用数组非空也不能补足技术规格缺口。仅凭本组发票还无法判断是否另有总成或其他同运货物，应明确保留待核范围。

## 怎么确认配好了

验收可以先问“外包装是什么”，再问“接头材质有什么依据”，检查回答是否分别指回装箱句与缺失的规格资料。对于是否整机，要引用本组所列散装接头，同时说明尚未核其他货物或总成清单。抽查实际引用文字，保留条目身份与原文限定。若没有引用，先追查本次检索和传递过程，不把该运行状态直接改写成货物性质的否定判断。
