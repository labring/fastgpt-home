# 一般贸易进口报关的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在一般贸易进口报关的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。包装层级中的内衬与货物材料需要保留不同主语。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

进口商品资料自拟两栏：货物栏写金属接头，包装栏写纸质内衬，表后说明“内衬仅用于固定”。问接头是什么材料时，应保留金属修饰接头、纸质修饰内衬的关系。解析若按阅读顺序串成金属接头纸质内衬，短块可能只剩纸质而丢主语。分段前先核原栏位及解析词序，不能从同箱材料推定商品组成，也不能补写内衬的其他性能。

## 配置怎么定

| 原文或分块核对项 | 具体材料关系 | 取证动作 |
| --- | --- | --- |
| 货物属性 | 金属修饰接头 | 核主语与材料配对。 |
| 包装属性 | 纸质修饰内衬 | 不迁给货物。 |
| 用途注记 | 内衬仅用于固定 | 核注记不离对象。 |
| 全批范围 | 两栏不覆盖全部部件 | 不补整批组成。 |
| 补技术页 | 适用对象及处理状态 | 复测错误归栏是否仍在。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

一种失败是包装栏被归到货物规格，回答称接头为纸质；另一处风险是仅用于固定注记被拆离，内衬被文案写成接头功能件。应核对象名称、栏级身份及用途条件，分别定位属性转移与范围扩大。原数据与索引需区分，纸质入口可能指包装，不能因搜到该词就回答货物材质。现有两栏也没有覆盖所有部件，不能由金属接头推出整批全部为金属。

## 怎么确认配好了

验收分别用接头、内衬、仅用于固定检索，再问“纸质描述的是哪一项”，检查返回块主语是否明确。答案应逐项对应货物与包装，不把装箱资料扩成完整材质清单。若补技术页，核适用货物及实际处理、索引后复测；上传成功不能证明错误归栏已从结果清除。保留原表和每块对照，检查更新后回答是否仍把包装用途迁给商品。
