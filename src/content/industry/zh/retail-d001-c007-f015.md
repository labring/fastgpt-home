# 一般贸易进口报关的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在一般贸易进口报关的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

进口商品问答可以新拟发票说明：“测试样机，不附零售包装。”检索需要把样机对象和包装排除同时取回，不能只找到零售包装几个字就回答有包装。先用原文词组检查候选，再用“这份发票描述什么包装范围”比较语义、全文与混合检索。样机称谓只是一段资料文字，既不证明实际用途，也不能扩成准入或豁免结论。

## 配置怎么定

| 文档项或实施核对 | 本题材料与条件 | 取证动作 |
| --- | --- | --- |
| 检索范围（实施核对） | 发票与运输包装条目分别核对 | 缓冲箱不提供零售包装内容。 |
| 搜索模式（语义/全文/混合） | 原文排除及完整包装问题 | 比较三种模式实际取回的句子。 |
| 引用token上限 | 不附零售包装的限定 | 检查否定词是否在裁剪中遗漏。 |
| 最低相关度 | 语义或重排时核过滤 | 空结果仍需排查来源与召回。 |
| 问题优化 | 设备接口的后续问题 | 不补写未提供的接口类型。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

另拟装箱单记“缓冲箱”，描述的是运输包装。若查询把它当成零售包装，问题是两种资料角色被混用，应并列保存发票句子、装箱条目与本次引用。还需检查“不附”是否在引用裁剪中遗漏：只剩包装名词时，答复可能失去排除条件。多条命中也要查看是否重复同一运输记录，没有提供销售包装的实际依据。

## 怎么确认配好了

继续询问某设备接口是否兼容时，当前样机名称和缓冲箱都无法支持该属性。若优化问题加入原文没有的接口类型，就改变了本题的取证范围，应保留改写前后的问题核对。取得对应规格后再用同题查新增引用，最低相关度只在语义或重排条件下生效。空结果还需排查资料范围与召回，不能据此认定规格不存在或商品不兼容。
