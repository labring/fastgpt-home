# 一般贸易进口报关的商品资料与选型问答：重排与混合检索

## 这个品类的数据长什么样

在一般贸易进口报关的商品资料与选型问答中，本页说明FastGPT的重排与混合检索如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「重排与混合检索」这一环带来什么约束

进口商品基本信息样例中，商业发票明确写了“标准型深蓝色商品”。可先标出型号和颜色所在原句，再检查融合候选是否把这两项保持在同一商品上下文里。完整问题应保留所查商品，重排时观察其他相似型号文字是否排到前面，最终答复则回查发票的实际描述；无需从该句扩展商品性能或准入结论。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或适用条件 | 回查与验收线索 |
| --- | --- | --- |
| 融合候选 | 标准型深蓝色商品的完整描述 | 型号与颜色需对应同一商品。 |
| 完整问题 | 商业发票一百件与装箱单九十九件 | 候选需保留总件数及两份资料身份。 |
| 最低相关度 | 语义检索或重排时检查过滤 | 过滤后仍要核单位和批次范围。 |
| 引用token上限 | 数量原句及“总件数”含义 | 不得静默将两个数统一。 |
| 缺资料复测 | 商业发票没有市场准入依据 | 另补适用来源，再核新增引用。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `混合检索` | 向量与全文结果通过RRF融合。 |
| `结果重排` | 按完整问题对候选再次排序。 |
| `最低相关度` | 过滤仅在语义或重排时生效。 |
| `引用上限` | 按token裁剪引用内容。 |
| `问题优化` | 比较优化前后主体与限制。 |

## 容易做错的三处

一百件与九十九件分别来自自拟商业发票和装箱单。数量核对需同时看到两张材料的商品及总件数，不能只展示与提问字面更接近的一方。保存候选顺序和出处，再检查引用是否保留了“总件数”的含义；两份记录是否同批次、同版本仍须另外确认。数值不同可提出核对要求，不能由排序直接认定短装或报关错误。数量差异的记录应保留各自原句和单位，避免把九十九自动改写成一百。即使最后只展示简短答复，仍应能回查两处实际取回的数量文字。

## 怎么确认配好了

特定市场准入标准并未包含在现有发票中，商品名称、颜色和数量都不能代替准入依据。可用这道缺资料问题观察重排结果是否把一般商品描述误作合规证明。取得对应的标准及适用资料后，重复原问题并检查新增证据是否被引用；最低相关度仅按其生效场景验证，不能把相关候选的排位或得分写成已准入的事实。
