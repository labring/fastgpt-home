# 亚马逊FBA备货运营的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在亚马逊FBA备货运营的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。平铺包装要求与展开展示状态分节，保持不同形态场景。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

FBA商品资料自拟结构页“折叠收纳筐可展开”，包装节写“入仓保持平铺”，展示节写“展示时撑开”，末注“以上为状态说明，不列包装附送物”。选型问能否展开与包装包含什么是两个问题。解析应保留节标题和末注，不能把展示状态当作实际发货形态，也不能从撑开动作推定随附支撑配件。原文只说明状态，没有提供附送清单。

## 配置怎么定

| 原文或分块核对项 | 具体材料关系 | 取证动作 |
| --- | --- | --- |
| 节标题 | 结构、包装、展示 | 核场景归属。 |
| 状态条件 | 入仓平铺、展示撑开 | 不判为同场景冲突。 |
| 附送边界 | 状态说明不是清单 | 核末注随相关块。 |
| 分问检索 | 展开、入仓、包含物 | 核各问题返回依据。 |
| 节级更新 | 包装新版与展示版本 | 核实际处理和引用。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

常见错误是平铺与撑开被放进无标题块，回答宣称资料互相矛盾；另一种失败是末注单独切出，使状态说明被当成包装组成。应核原节归属、场景词和分块条件，区分主体相同但用途不同的两种说明。索引可提供展开与入仓入口，仍需回读各自原数据，不由关键词同时出现推定包含件。资料身份和版本也要保留，以免新包装节与旧展示节混在一起。

## 怎么确认配好了

验收分别问能否展开、入仓采用何种状态、是否列附送物，核返回块是否支持对应目标。答案应保留可展开、入仓平铺和清单缺项，不将三项合成一个包装承诺。更新包装节后核实际处理与索引状态，复用原问题检查引用版本；上传新版不能证明旧节已停止引用。保留原文解析对照，确认场景和末注没有在更新时再次脱离对象。
