# 亚马逊FBA备货运营的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在亚马逊FBA备货运营的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

FBA商品检索可另拟入仓计划：“可折叠收纳盒，按扁平形态入仓。”问商品名称与交付形态时，都需保留这段文字的对象和条件。先用折叠、扁平标注所需候选，再比较完整问题在各模式下取回哪份原文。收纳盒名称命中，并不提供组装后的尺寸，也不证明实际入仓完成；本题只核自拟计划写明的内容。

## 配置怎么定

| 文档项或实施核对 | 本题材料与条件 | 取证动作 |
| --- | --- | --- |
| 检索范围（实施核对） | 入仓计划与箱唛附注分开 | 区分交付形态与展示语境。 |
| 搜索模式（语义/全文/混合） | 折叠、扁平与完整形态问题 | 核每种模式取回的限定。 |
| 引用token上限 | 扁平入仓条件 | 定位候选遗漏或引用裁剪。 |
| 最低相关度 | 语义或重排下核相关度 | 名称相近不提供尺寸依据。 |
| 问题优化 | 连续追问入仓形态 | 不换成组装成品问题。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

另拟箱唛普通文字附注“组装后示意”，没有提供真实图片。若答复据此说计划要求组装后交付，就是将展示语境误读成交付形态，应核计划与箱唛各自出处。还可排查引用是否只剩收纳盒或示意短词，遗漏扁平入仓这一条件。保存完整句子和返回片段，判断条件未进候选，还是在token裁剪时丢失，再决定需要调整的环节。

## 怎么确认配好了

折叠尺寸未提供时，扁平这一称谓不能换算成长宽。若输出出现具体尺寸，应查其引用是否来自其他商品，不能因名称接近就采信。取得对应规格后再用同题复测，并保留新增来源和参数调整的独立记录。问题优化应保持入仓形态，不将追问换成组装成品；最低相关度按语义或重排条件核验，相关得分不等于已经取得尺寸依据。
