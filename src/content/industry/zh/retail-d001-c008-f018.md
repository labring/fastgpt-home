# 亚马逊FBA备货运营的商品资料与选型问答：重排与混合检索

## 这个品类的数据长什么样

在亚马逊FBA备货运营的商品资料与选型问答中，本页说明FastGPT的重排与混合检索如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「重排与混合检索」这一环带来什么约束

FBA入仓计划的自拟附页列出智能手环、一百件和小型，能提供的是本次备货文字。标注商品名称、数量及尺寸的原文后，可比较融合候选和重排结果是否仍将它们对应到同一条备货说明。问法包含尺寸时，检查数量片段是否挤掉尺寸描述；最终引用需保留原句，而不能把“小型”扩写成没有来源的具体长宽。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或适用条件 | 回查与验收线索 |
| --- | --- | --- |
| 融合候选 | 智能手环、一百件、小型的备货文字 | 三个属性应保持对应关系。 |
| 完整问题 | 电子产品类别与易碎品处理提示 | 检查回答是否保留两种资料角色。 |
| 最低相关度 | 按语义或重排的实际条件核过滤 | 箱唛缺失时先查召回。 |
| 引用token上限 | 类别与处理说明各自原句 | 不能只保留无法识别来源的短词。 |
| 缺资料复测 | 尚未提供特殊包装说明 | 易碎提示不能补出包装材料和层数。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `混合检索` | 向量与全文结果通过RRF融合。 |
| `结果重排` | 按完整问题对候选再次排序。 |
| `最低相关度` | 过滤仅在语义或重排时生效。 |
| `引用上限` | 按token裁剪引用内容。 |
| `问题优化` | 比较优化前后主体与限制。 |

## 容易做错的三处

入仓计划写“电子产品”，箱唛写“易碎品”，这两个描述可以同时成立，不能先当作互相否定的证据。排序核对应分清商品类别与处理提示，让两边原文分别可回查。候选缺少箱唛时，先核是否召回了该材料；两边都已进入后，再看重排有没有把处理提示误写成商品类别，或因引用裁剪只留下无法辨明来源的短词。

## 怎么确认配好了

特殊包装要求没有出现在现有智能手环计划中，“易碎品”字样也不能自行生成完整包装规则。验收可检查回答是否擅自给出具体材料或包装层数，并向实际资料来源补齐相关说明。补充前后使用同一包装问题，分别保留候选、排序与引用，确认新增要求确实来自对应来源；检索或重排得分不能代替对包装要求的原文核对。包装说明缺失与箱唛存在应分别记录，不把处理提示当成已提供完整操作规程。新增资料若只覆盖部分要求，答复也需保持其实际范围。
