# 亚马逊FBM自发货运营的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在亚马逊FBM自发货运营的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。左右适配关系表需要保留行与脚注，不能只返回方向词。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

FBM商品资料自拟适配表，两行分别写左侧支架配左接头、右侧支架配右接头，脚注“左右以正视主机为准”。用户问右边该选哪件时，解析必须保留支架与接头配对，也要保留观察方向。若只取到右字而丢脚注，提问中的右边可能与资料方向不同。分块检查应先核原表行和脚注适用范围，不能按日常方向理解替换文件给定的参照。

## 配置怎么定

| 原文或分块核对项 | 具体材料关系 | 取证动作 |
| --- | --- | --- |
| 行配对 | 左配左、右配右 | 核解析没有错列。 |
| 方向参照 | 正视主机 | 核脚注随适配关系。 |
| 问法差异 | 右边未说明视角 | 保留参照待核。 |
| 型号缺项 | 未提供具体主机 | 不扩到全部型号。 |
| 改表复测 | 新旧行关系和索引 | 比较同题配对引用。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

一种失败是按列解析让左支架配到右接头，另一处风险是脚注单独成块，回答对右边直接给物件却不核参照。应对照原行、解析顺序和每块主体，分别定位配对错误与方向条件缺失。检索索引可以包含左右问法，但原数据仍要给出完整适配关系；入口名不能确认实际观察视角。没有主机身份资料时，也不能把某一表的方向套到所有型号。

## 怎么确认配好了

验收分别用左接头、右支架和“按什么视角判断右边”的问题检索，再核完整选件问题是否带方向条件。答案应保留正视主机这一参照，不能只用左右二字。表格更新后核实际处理及索引版本，以同题比较配对是否改变。上传成功不证明旧错行已清除；保留原表和返回块对照。若补入具体主机资料，再核适用对象，不把正确解析等同实际安装已验证。
