# 亚马逊FBM自发货运营的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在亚马逊FBM自发货运营的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

FBM检索可新拟拣货说明：“左侧配件，安装工具不包含。”物品与工具问题要分别回查位置和排除文字，不能只命中工具名词就认为随货。先用左侧配件与完整包含问题测试搜索模式，核所选来源是否确有该句。左侧是自拟物品描述，不是软件配置，也不能扩成所有装配位置都可通用的说法。

## 配置怎么定

| 文档项或实施核对 | 本题材料与条件 | 取证动作 |
| --- | --- | --- |
| 检索范围（实施核对） | 拣货说明与确认单分别核对 | 配件包不是逐项工具清单。 |
| 搜索模式（语义/全文/混合） | 左侧原词与包含工具问法 | 核是否取回实际排除句。 |
| 引用token上限 | 安装工具不包含 | 不能在引用中丢掉否定。 |
| 最低相关度 | 语义检索或重排下核过滤 | 高相关不代表位置通用。 |
| 问题优化 | 追问右侧能否安装 | 检查优化有无改变位置条件。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

另一份自拟发货确认单仅写“配件包”，没有工具清单。若答复由包这个词推导套件齐全，就是缺少组成依据，应保留该候选和拣货原句作对照。另查token裁剪是否删掉不包含的限制，避免多条重复配件包记录掩盖排除项。两份来源分别保留身份；实际发货是否有工具仍需对应记录，不能由检索中的大类名称确认。还可将错误输出“工具齐全”与原句对照，检查返回是否只有配件包标签，或引用删掉了排除句。保存源句、候选与答案，分别定位条件未被召回和生成时无依据扩写两种问题。

## 怎么确认配好了

追问右侧能否安装时，现有左侧说明没有给出兼容范围。若优化将左、右改成可互换，就引入了未经提供的条件，需对照完整原问与改写文字。取得真实适配资料后，用同题核新增候选与引用，并分开记录补资料和调参数。最低相关度只按生效条件检查；名称相似、片段靠前或回答更长，都不能填补右侧适配依据的缺口。
