# 亚马逊FBM自发货运营的商品资料与选型问答：重排与混合检索

## 这个品类的数据长什么样

在亚马逊FBM自发货运营的商品资料与选型问答中，本页说明FastGPT的重排与混合检索如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「重排与混合检索」这一环带来什么约束

FBM拣货单样例写了森林绿和三人加大款，问颜色、尺寸时应回到户外露营帐篷对应的原句。可分别用属性原词和包含商品名称的完整问题检查候选，再看重排是否仍保留这种对应关系。这里读取的是自拟拣货文字，“三人”不能被扩成未经提供的承重或使用效果，尺寸表述也不应脱离该商品进入其他款式的答案。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或适用条件 | 回查与验收线索 |
| --- | --- | --- |
| 融合候选 | 露营帐篷的森林绿及三人加大款 | 保留商品、颜色、尺寸的关联。 |
| 完整问题 | 咖啡机X-零零一与X-零零二 | 型号标识不能按近义词合并。 |
| 最低相关度 | 语义或重排下检查该过滤条件 | 两侧候选都存在后再解释次序。 |
| 引用token上限 | 型号及其所属文件身份 | 回查是否漏掉另一型号。 |
| 缺资料复测 | 拣货单没有手表续航信息 | 不得从其他款式借入时长。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `混合检索` | 向量与全文结果通过RRF融合。 |
| `结果重排` | 按完整问题对候选再次排序。 |
| `最低相关度` | 过滤仅在语义或重排时生效。 |
| `引用上限` | 按token裁剪引用内容。 |
| `问题优化` | 比较优化前后主体与限制。 |

## 容易做错的三处

便携咖啡机在拣货单和发货确认单中分别记为X-零零一与X-零零二。重排前先查两个型号所在片段是否都已召回，之后查看最终引用有没有只保留其中一个。不同标识不能由模型当成可以互换的近义词；还需核两份材料的订单身份和版本，才能解释这个差异。排序模型可调整已有候选的次序，不负责判定真实错发。型号原词应随各自文件身份保留，不能在回答中自动统一标识。需要补充的关联材料也应明示，以便将单据文字差异与实际发货判断分开处理。

## 怎么确认配好了

智能手表的续航资料未包含在现有拣货附页中，可用这道问题检查回答是否从其他商品借入时长。缺少续航说明时，即使一个手表名称片段排在前面，仍没有相应属性依据。取得对应规格后再问同题，核对新片段是否进入候选、是否通过实际过滤条件、是否在引用中完整保留；不将型号相似或得分变化当成续航已获验证。
