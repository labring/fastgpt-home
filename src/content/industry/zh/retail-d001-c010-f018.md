# 京东POP第三方店铺运营的商品资料与选型问答：重排与混合检索

## 这个品类的数据长什么样

在京东POP第三方店铺运营的商品资料与选型问答中，本页说明FastGPT的重排与混合检索如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「重排与混合检索」这一环带来什么约束

京东POP的电子配件样例，要核的是商品信息表“主要功能”栏写明的数据传输与充电。候选检查应能定位这处内容，完整问题也需包含功能诉求，不能只搜索电子配件这一宽泛类别。比较重排前后两项功能有没有被分离或漏掉，再回查最终引用；“充电”这一描述不包含尚未提供的协议、功率或适配设备清单。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或适用条件 | 回查与验收线索 |
| --- | --- | --- |
| 融合候选 | 主要功能中的数据传输与充电 | 确认两项功能都关联同一配件。 |
| 完整问题 | 两份附页分别记白色与黑色 | 保留商品与颜色来源，不自行统一。 |
| 最低相关度 | 参数在语义检索或重排时生效 | 过滤结果仍需核资料版本。 |
| 引用token上限 | 功能说明和颜色限定原句 | 不能只留电子配件这一宽泛类别。 |
| 缺资料复测 | 没有是否含电池的明确文字 | 存在与不存在都不能无依据补写。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `混合检索` | 向量与全文结果通过RRF融合。 |
| `结果重排` | 按完整问题对候选再次排序。 |
| `最低相关度` | 过滤仅在语义或重排时生效。 |
| `引用上限` | 按token裁剪引用内容。 |
| `问题优化` | 比较优化前后主体与限制。 |

## 容易做错的三处

同款商品的白色和黑色分别出现在两份自拟附页中。颜色核对需要两处来源同时可见，不能只因一种颜色与问题更接近就忽略另一份。检查候选是否具有相同商品及对应版本，再观察排序和token裁剪怎样影响原句。颜色记载不同是待核事项，是否属于不同规格或旧版本仍需资料确认，不由重排次序决定。

## 怎么确认配好了

是否含电池在附页里没有明确说明，不能从“电子配件”或“充电”两个词推导答案。可检查高排位结果究竟提供了电池信息，还是仅复述功能字段。补充该商品的对应说明后再测试，记录新增证据从召回到引用的路径。最低相关度只在语义检索或结果重排时生效，调整阈值也不能让没有写明的电池属性成为已有事实。未说明是否含电池也不能被写为“不含电池”。这道缺项问题的验收应明确检查两种无依据补写，既不默认存在，也不默认不存在。
