# 仅退款争议处理的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在仅退款争议处理的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。申请中描述与商品规格来源的身份应随片段保留。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

仅退款商品问答自拟申请摘录“买家描述瓶盖松动”，商品规格页写“旋合式瓶盖”，未提供该件检测。问此商品是否普遍有松盖问题时，两份文字分别描述个体反馈与结构类型。解析应保留买家描述与规格身份，不能把反馈词放进规格块，或从旋合结构推定每件都没有问题。分块前先核来源与对象范围，避免将个案陈述扩成全款性能。旋合式还没有描述松紧程度，不能据结构词反驳该次反馈。要核单件状态需相应检测，要核普遍表现则需覆盖该结论范围的资料；两种缺项应分开记录，不因同用瓶盖一词就合并证据。

## 配置怎么定

| 原文或分块核对项 | 具体材料关系 | 取证动作 |
| --- | --- | --- |
| 反馈身份 | 买家描述 | 核陈述来源未裁掉。 |
| 规格对象 | 旋合式结构 | 不当作该件检测。 |
| 范围差异 | 单件与全款 | 核结论未扩大。 |
| 证据缺口 | 缺检测及全款依据 | 分别保留待核。 |
| 补检更新 | 检测对象与引用版本 | 核处理及同题返回。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

一种失败是买家描述被截为瓶盖松动，回答将其当作产品已确认缺陷；另一处风险是规格页与申请被解析成同一文档，结构说明被误作对该件的检测结论。应对照文档身份、陈述主语与实际块，区分来源丢失和证据类型混用。索引命中松动词也不能说明主张属实，命中旋合式也不能排除松动。没有检测材料时，不替产品或责任作肯定结论。

## 怎么确认配好了

验收分别问买家说了什么、规格写什么、是否有该件检测或全款依据，核返回块有不同覆盖。答案应保留反馈身份与结构描述，其他结论明确缺项。补检测记录后核适用商品与实际处理、索引状态再复测，不能仅上传就认定反馈已证实或被否定。保留原文与引用版本，防止旧个案被新检测对象替换，或单件结果继续扩到全部商品。
