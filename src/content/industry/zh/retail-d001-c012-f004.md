# 仓内拣货复核打包的商品资料与选型问答：向量模型与索引

## 这个品类的数据长什么样

在仓内拣货复核打包的商品资料与选型问答中，本页说明FastGPT的向量模型与索引如何衔接资料。仓区标签、周转容器与商品名称不能被组合成规格。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

仓内商品索引自拟标签“青区周转筐”，商品清单另写“磨砂瓶”，移位备注写“随货位更新标签”。问瓶子是什么颜色时，青区是仓区称呼，筐是周转容器，清单没有颜色属性。入口若写青色磨砂瓶，会把地点词迁到商品。应分别保留位置、容器与单品的原数据，不能因为标签与商品在同处出现就认定颜色或固定规格，更不能从移位行为补出商品变化。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 地点名称 | 青区 | 不转成颜色。 |
| 容器身份 | 周转筐 | 不与瓶子合并。 |
| 商品内容 | 磨砂瓶无颜色 | 保留规格缺项。 |
| 旧位置入口 | 移位后仍可被搜到 | 核实际目标适用。 |
| 标签更新 | 位置与单品身份分别核 | 比较原文及引用。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是青区被索引成青色瓶，应核地点名和商品属性的原文角色。第二处是瓶子问法指向周转筐标签，应查目标原数据是否属于容器。第三处是移位后旧位置入口仍被回答当商品身份，应核更新标签、索引目标及实际引用。三项分别查词义角色、物理对象和更新对应，不从仓区简称推定材质颜色，也不把索引仍可命中理解为旧位置仍适用。

## 怎么确认配好了

验收分别问货位标签叫什么、周转物是什么、商品清单列何物，核入口及引用保留对象。颜色问题应明确清单未写，不从青区给出答案。移位资料补入后检查实际原数据与索引状态，用同题看位置来源是否更新；文件上传不能证明旧入口已处理。一个商品即使对应多个位置检索入口，也不表示商品规格随位置改变，应逐项回到真实被指向的原句。
