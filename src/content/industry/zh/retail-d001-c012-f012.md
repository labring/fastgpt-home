# 仓内拣货复核打包的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在仓内拣货复核打包的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。相似简称的缓冲垫与支撑垫需要保留物料身份。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

仓内商品资料自拟物料表，缓冲垫简称软垫，用途是包装防磕；支撑垫简称底垫，用途是成品底部支撑。拣货备注写“核对应物料名称后取件”。问底部配什么时，应区分包装物料和成品部件，不能因为都带垫字而替换。解析要保留全称、简称和用途配对，分块若只剩简称，会让自然问题难以判断对象。备注也没有授权任意相似物料互换。

## 配置怎么定

| 原文或分块核对项 | 具体材料关系 | 取证动作 |
| --- | --- | --- |
| 物料全称 | 缓冲垫与支撑垫 | 核实体不同。 |
| 简称配对 | 软垫与底垫各有全称 | 核解析对应。 |
| 用途身份 | 包装与成品支撑 | 不按相似词互换。 |
| 前置备注 | 取件前核名称 | 核条件随相关块。 |
| 改名复测 | 旧简称与新物料索引 | 核处理及目标原文。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

常见错误是把软垫用途接到底垫行，支撑部件变成包装材料；另一种失败是核物料名称条件被拆离，回答按相似词直接给出替换建议。应核原表行、解析配对与实际块，区分实体混并和前置动作丢失。索引可用简称帮助检索，仍须回指完整原数据，不由简称命中推定适配。当前资料没有规格尺寸或替代规则，不能补写两垫可通用。

## 怎么确认配好了

验收用全称、简称和“成品底部支撑用哪项”的问题检索，核每个返回块同时提供身份与用途。答案应明确支撑垫与包装缓冲垫不同，并保留取件前核名称。新增物料或改简称后，检查实际处理及索引状态再复测同题，尤其核旧简称是否仍错误指向新物料。上传成功不能证明配对已更新；保留原表与块对照，不能把检索通过写成实际拣货已验证。
