# 仓内拣货复核打包的商品资料与选型问答：重排与混合检索

## 这个品类的数据长什么样

在仓内拣货复核打包的商品资料与选型问答中，本页说明FastGPT的重排与混合检索如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「重排与混合检索」这一环带来什么约束

仓内问答的自拟拣货单，把商品写为轻便型家用吸尘器，主要功能为吸尘。这一描述适合核对单据上写的功能，不能延伸成实际清洁效果测试。先找出名称及功能对应的候选，再把商品与功能放在完整问题中检查重排。若另一款商品的长描述靠前，应逐条回查出处，观察目标商品原句是否仍进入最终引用。轻便型是样例中的描述词，没有提供可比较的实际重量。若问题进一步询问重量或搬运条件，需要另外取得对应资料，不能由排序靠前的名称说明补出数值。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或适用条件 | 回查与验收线索 |
| --- | --- | --- |
| 融合候选 | 轻便型家用吸尘器及吸尘功能 | 回查目标商品的功能原句。 |
| 完整问题 | 扫地机器人与手持吸尘器的描述 | 保留两种商品称谓及材料身份。 |
| 最低相关度 | 仅按语义或重排条件查看 | 排序前缺失的复核记录应先查召回。 |
| 引用token上限 | 商品称谓与功能对应关系 | 不能让长描述挤掉另一来源。 |
| 缺资料复测 | 材质、尺寸及适用场景未提供 | 轻便描述不等于已有重量参数。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `混合检索` | 向量与全文结果通过RRF融合。 |
| `结果重排` | 按完整问题对候选再次排序。 |
| `最低相关度` | 过滤仅在语义或重排时生效。 |
| `引用上限` | 按token裁剪引用内容。 |
| `问题优化` | 比较优化前后主体与限制。 |

## 容易做错的三处

扫地机器人和手持吸尘器分别来自拣货单与复核记录，两种商品描述应被分开保留。检查双方是否在候选中，再核材料关联和版本，不能由词义相近就当作同一规格。重排没有取回缺失材料的能力；只有一边时先查召回，两边都存在再看顺序及引用裁剪，记录最后答复是否遗漏了需要复核的另一种描述。

## 怎么确认配好了

名称与数量不能回答材质、具体尺寸或适用场景，现有拣货附页也没有提供这些项目。可分别用这些属性问题观察候选是否只是泛泛提到吸尘器，回答有无超出原文。补充对应商品说明后再复测，核新增条件是否完整进入引用。这里的验收是属性来源可回查，不能因排序靠前或过滤后仍有结果，就认定商品适用于某一使用场景。
