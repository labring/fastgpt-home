# 便利店加盟门店督导的商品资料与选型问答：向量模型与索引

## 这个品类的数据长什么样

在便利店加盟门店督导的商品资料与选型问答中，本页说明FastGPT的向量模型与索引如何衔接资料。货架价签夹与食品名称中的夹字指向不同对象。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

便利店商品索引自拟器材清单“货架价签夹”，食品简报列“夹心点心”，巡店需求写“补夹子”。这里的简称没有明确采购对象，两个来源都含夹字也不能归成同一商品。入口应保留器材或食品的完整名称，并能回到对应原数据；问夹子有什么规格时，食品简报没有器材信息，不能因文字相近就供给规格，更不能把补货需求当作已确定选型。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 物料类别 | 器材与食品不同 | 核全文名称。 |
| 简称对象 | 补夹子尚不明确 | 核需求所指。 |
| 规格覆盖 | 器材清单仅名称 | 不补尺寸及适配。 |
| 业务状态 | 需求不等于采购完成 | 查选型及记录。 |
| 入口更新 | 新明细与旧食品目标 | 比实际原文引用。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是夹子入口指向夹心食品，应核目标物料类别与全文名称。第二处是器材索引补出尺寸或适配货架，而原文只有名称，应查实际规格来源。第三处是巡店需求被写成已采购价签夹，应核选型及采购记录。三项分别查对象类别、属性覆盖和业务动作，不用一个简称代替确认。若补入新规格仍只回食品段，应记录实际入口目标，不能靠重复查询证明已修正。

## 怎么确认配好了

验收分别问器材名、食品名和补夹子所指对象，再检查自然规格问题返回哪份原文。当前可区分两类名称，但具体器材规格与需求身份还待核，不补数值。新增对照或清单后检查实际处理与索引，再用同题看引用变化。多个入口可为完整器材名提供不同问法，但每个仍应指向器材原数据；命中相同汉字不表示语义或物理对象已经对应。
