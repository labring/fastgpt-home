# 便利店加盟门店督导的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在便利店加盟门店督导的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。货架位置示例与可售规格清单分源，不能从示例补商品范围。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

便利店商品资料自拟陈列示例“上层摆小包装”，示例标题注明仅示位置；另有清单指向“可售规格见本期商品册”，商品册未提供。问是否销售小包装与大包装时，上层小包装只能说明示例画法，不能证明本期可售规格。解析需保留示例身份与转引来源，分块不应把位置句归为商品册正文，更不能从未见大包装推定不售该规格。

## 配置怎么定

| 原文或分块核对项 | 具体材料关系 | 取证动作 |
| --- | --- | --- |
| 示例身份 | 仅示位置 | 核标题限制保留。 |
| 画面对象 | 上层小包装 | 不当作在售清单。 |
| 转引来源 | 本期商品册未提供 | 保留所需正文缺项。 |
| 规格问法 | 大小包装与本期范围 | 核回答不扩大示例。 |
| 补册复测 | 期间、处理和索引 | 比较实际新引用。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

一种失败是仅示位置被独立切走，小包装被回答当成已确认在售；另一处风险是商品册指向和示例合并为一个块，让读者误以为清单已经列明。应核标题、文档身份与实际块的内容边界，区分限制丢失和来源替代。索引可覆盖包装规格问法，但仍需回到真实规格原文。没有商品册时，多个示例命中也不会自动组成在售清单，不能以数量增加代替资料补齐。

## 怎么确认配好了

验收用上层、小包装、可售规格原词和“本期有哪些规格”的问题检索，核返回块是否明确示例与转引。答案可以说明位置示意所用包装，但本期规格仍需商品册。取得商品册后核适用期间、实际处理与索引状态，再用同题复测新来源是否进入引用。上传成功不证明期间已匹配或旧示例已停止代替清单；保留原文解析对照，检查回答有没有继续扩大示例范围。
