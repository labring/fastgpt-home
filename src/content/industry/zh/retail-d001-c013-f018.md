# 便利店加盟门店督导的商品资料与选型问答：重排与混合检索

## 这个品类的数据长什么样

在便利店加盟门店督导的商品资料与选型问答中，本页说明FastGPT的重排与混合检索如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「重排与混合检索」这一环带来什么约束

巡店表中的“货架第二层”和“促销标签已张贴”记录的是现场陈列文字，不是商品性能。可用商品A与这两项记录标注所需候选，再检查重排是否仍能分别回答位置和标签状态。返回片段应带着所指商品，不能将其他商品的陈列标准当作本次巡店已发生的事实。材料为自拟测试，未核实真实门店的摆放或活动执行。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或适用条件 | 回查与验收线索 |
| --- | --- | --- |
| 融合候选 | 第二层货架及促销标签记录 | 检查两项是否对应商品A。 |
| 完整问题 | 巡店十件与标准十二件 | 分别保留记录值和规定值。 |
| 最低相关度 | 按语义或重排条件核过滤 | 标准值命中不代表现场数量已核实。 |
| 引用token上限 | 陈列位置、数量及来源角色 | 不能把标准文字改成现场记录。 |
| 缺资料复测 | 巡店表没有新品标识 | 促销标签不能替代新品依据。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `混合检索` | 向量与全文结果通过RRF融合。 |
| `结果重排` | 按完整问题对候选再次排序。 |
| `最低相关度` | 过滤仅在语义或重排时生效。 |
| `引用上限` | 按token裁剪引用内容。 |
| `问题优化` | 比较优化前后主体与限制。 |

## 容易做错的三处

商品B在巡店表写十件，陈列标准写十二件，分别描述记录值与规定值。排序检查应保留两种角色，而不能仅选一段数字作为统一答案。先核候选是否同时包含商品及数量原句，再查两份资料是否同一标准版本和适用范围。两处数值可提出核对点，是否构成现场执行问题还需相应业务确认，不能由重排直接作结。巡店记录与陈列标准各自的资料角色，应随引用保留；不能把标准值当成现场实测值。是否需要整改也要依据实际适用要求，不能仅从候选中的两个数字推出。

## 怎么确认配好了

新品属性没有在现有巡店表中明示，位置和促销标签都不能补出这个结论。可用“是否新品”作缺资料问题，检查回答有无借用活动文字推断上市状态。补充明确标识或对应商品资料后，再看新依据进入候选、重排和引用的情况；改变最低相关度时需按语义或重排的实际条件检查，不将分数当作新品身份的证明。
