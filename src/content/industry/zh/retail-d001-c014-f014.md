# 便利店鲜食订货的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样
便利店鲜食订货围绕短保质期商品高频补货，资料来自POS销售、总部订货系统、门店库存与冷链温控记录。日常文档包括鲜食订货单、报损单、临期处理表与温度记录。这些材料按日或按班次更新，订货决策依赖当日可售数量与到期时间。商品资料与选型问答需要在这些材料范围内回答规格、保质期与订货条件，接入模型时须让回答只依据已上传的文档内容。

## 这些特征在「模型接入与配置」这一环带来什么约束
FastGPT 借助 AI Proxy 连接模型提供商。App 与 Admin 服务必须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺少任一项会启动校验失败。AIPROXY_API_ENDPOINT 填服务根地址，不附加 /v1。系统至少需要一个语言模型和一个索引模型才能正常使用。模型 ID 全局唯一，模型映射把 FastGPT 请求的模型映射到上游实际模型。模型能力按应用所需输入核对，多模态、工具调用分别验证。应用参数在应用或节点配置中设置，不能假设兼容对话接口的同名字段会覆盖编排。

假设演练样本：某门店 2026 年 9 月 23 日鲜食订货单记录“饭团类当日 14:00 前可订，次日 06:00 到店，保质期 48 小时”。温度记录显示当日 08:00 冷藏柜 4 摄氏度。拟核对句：“该门店当日 14:00 后仍可追加饭团订单。”此句与订货单原文的截止时点不一致，属于待核实项。

## 配置怎么定
| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 填写 AI Proxy 服务根地址 | 与官方要求一致，不附加 /v1；核对是否含路径后缀 |
| AIPROXY_API_TOKEN | 填写与服务端一致的非空 Token | 比较 App 与服务端配置是否一致，空值即校验失败 |
| 语言模型 | 启用一个已测试的语言模型 | 对照模型测试结果，确认对话请求返回成功 |
| 索引模型 | 启用一个已测试的索引模型 | 对照模型测试结果，确认索引请求返回成功 |
| 模型映射 | 按渠道填写映射关系 | 比较 FastGPT 请求模型 ID 与上游实际模型 ID 是否对应 |
| 模型探测间隔 | 本次假设设为 30 分钟 | 官方支持 5～60 分钟整数；与自身告警响应需求比较后取值 |

## 容易做错的三处
1. 把 AIPROXY_API_ENDPOINT 写成完整模型请求地址并附加 /v1。检查输入：环境变量值；比较对象：官方要求的不附加 /v1 根地址；观察结果：值含 /v1 或 /chat/completions 即不符。
2. 用应用 API Key 代替 AIPROXY_API_TOKEN。检查输入：Token 字段来源；比较对象：AI Proxy 管理员 Token；观察结果：来源为应用 Key 即不符。
3. 将拟核对句“当日 14:00 后仍可追加饭团订单”直接作为答案。检查输入：订货单原文与拟核对句；比较对象：原文截止时点 14:00；观察结果：拟句与原文时点不一致，须标记待核实。

## 怎么确认配好了
1. 输入假设样本订货单原文与拟核对句，比较原文“14:00 前可订”与拟句“14:00 后仍可追加”，若两者时点互斥则判定拟句未获支持，记录证据缺口。
2. 输入 AIPROXY_API_ENDPOINT 实际值，比较是否附加 /v1 或 /chat/completions，若含后缀则判定不符，保留原值待改。
3. 输入模型探测配置的间隔值，比较是否落在 5～60 分钟整数范围，若超出范围则判定不符并记录实际取值。
