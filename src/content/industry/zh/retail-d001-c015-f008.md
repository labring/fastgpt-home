# 信用证审单交单的商品资料与选型问答：工作流编排

## 这个品类的数据长什么样

在信用证审单交单的商品资料与选型问答中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

信用证及配套单据可以帮助定位交易中怎样描述商品，但选型提问还需明确具体想知道什么。可用自拟文本同时给出信用证的品名段、商业发票的商品描述，以及“尚无制造方用途说明”的记录。表单收集后，先比较后续步骤实际收到的三项内容，防止把单据名称的一致改写成商品性能一致，或将付款条件中的描述直接扩展为产品适用性结论。

## 配置怎么定

| 核对步骤 | 本题自拟输入 | 应核对的实际结果 |
| --- | --- | --- |
| 问题定位 | 品名段、发票描述及待问用途 | 交易文字没有被扩写为性能依据 |
| 提交接收 | 已给两处原文，制造方说明尚缺 | 后续步骤保留三项内容的区别 |
| 型号路径 | 核单据或补制造方型号说明 | 实际接收方与所选来源一致 |
| 路径错接 | 请求补说明仍到旧回答步骤 | 检查连接并重测选择及传入值 |
| 业务结果 | 交单或采购系统实际操作凭证 | 与商品阅读和对话结束分开验收 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

若提问涉及型号差异，流程可让资料负责人选择核对各份单据的原文，或补充制造方的型号说明，再分别验证接收路径。继续读交易单据只能回答其实际记载，不能补出另一条路径所需的技术依据。若选了补说明却仍进入原有回答步骤，应检查选择记录和连接；在来源未到位前，不以分支执行完成推定商品匹配已经确认。 另一种错配是制造方说明已经补齐，后续输入却仍停留在旧的发票描述，造成新增依据丢失。可把两次提交的资料清单并列，逐项查看实际传入内容，再追到回答引用的位置；修好传值后复测，不能仅凭上传动作认定新资料已参与选型解释。

## 怎么确认配好了

复测时保留原问题、材料版本和新增说明，核查回答是否仍能区分银行单证阅读与商品资料阅读。制造方说明没有提供的条件应保持未知，不由提单或保险材料替代。若还需更新交单材料、采购资料或外部业务记录，需另外核实实际操作接口、授权及结果；问答流程结束不能证明银行已接受材料，也不能作为商品验收凭证。
