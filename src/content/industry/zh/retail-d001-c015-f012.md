# 信用证审单交单的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在信用证审单交单的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。交易商品清单中的续页表头、缩写和附件限制需正确分块。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

审单背景的商品阅读可拟清单首行“支架主体”，续页行“附件：紧固片”，页下注“图示工具不随件”。缩写说明把紧固片简记为片。问题是商品是否附带安装工具。解析要将续页附件接回当前商品，同时保留图示工具排除；不能因工具出现在图注就加成供货组成，也不能把紧固片缩写读成任意片状附件。本页不设置真实单证要求，只核自拟商品表和图注的结构与回指。

## 配置怎么定

| 材料核对项 | 本题具体条件 | 实施取证 |
| --- | --- | --- |
| 续页表头 | 附件归支架 | 核页序行关系。 |
| 工具排除 | 图示不随件 | 随商品保留。 |
| 缩写范围 | 片仅指紧固片 | 不跨商品沿用。 |
| 解析缺文 | 先核原结构 | 索引不补漏句。 |
| 更新采用 | 当前清单引用 | 核训练与版本。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

第一处是续页附件脱离首行商品，应对页序、表头及解析行归属，明确它属于哪个主体。第二处是图示工具排除被分到无对象片段，应核图注与商品说明的连接，保留不随件限定。第三处是片的缩写在另一商品段落被沿用，应核缩写解释范围及块身份，不把同字当同一部件。三项分别查续页关系、排除条件和术语范围，不由分块大小或索引名称决定实际商品组成。

## 怎么确认配好了

验收分别问主体、紧固片和图示工具是否列入，保存原文、解析文本、分块及引用原句。调整后用部件全称、缩写和自然问法分别检索，核返回对象而不保证每种问法同样命中。若排除句未解析，先补结构再谈索引。更新清单后核训练与引用版本，上传成功不表示已采用。本练习不执行交单或确定审单结论，也不证明现实装箱包含哪些物品。
