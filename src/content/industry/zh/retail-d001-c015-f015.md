# 信用证审单交单的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在信用证审单交单的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

信用证材料的商品检索可新拟商业发票：“维修备件套件，不含测试工具。”检索需要同时取得备件对象及排除文字，不能只匹配工具名词就回答工具已经包含。先用备件、测试工具分别检查原文候选，再比较完整组成问题在各模式下的取回范围。这里核单据文字，没有形成银行接受、拒绝或单证符合性的判断。

## 配置怎么定

| 文档项或实施核对 | 本题材料与条件 | 取证动作 |
| --- | --- | --- |
| 检索范围（实施核对） | 发票组成、宽泛名称与清单指向 | 三种来源不互相填补明细。 |
| 搜索模式（语义/全文/混合） | 备件原词及完整组成问题 | 核实际取回的排除条件。 |
| 引用token上限 | 不含测试工具 | 区分候选遗漏和引用裁剪。 |
| 最低相关度 | 语义或重排时核过滤 | 得分不形成单证符合结论。 |
| 问题优化 | 追问具体工具范围 | 不得将排除改成已有清单。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

另拟保险单以“维修器材”作宽泛描述，信用证附注则写“商品明细见清单”。若回答把维修器材当成逐项清单，就越过了该来源范围，应并列保存三份原句及实际引用。token裁剪还可能遗漏发票里的“不含”，需回查完整句子，区分候选本来未覆盖与引用阶段丢掉限制。宽泛名称相近，不代表三份材料已经说明相同组成。

## 怎么确认配好了

商品明细清单与规格参数未提供时，应把这两项缺口分别记录，不能从维修用途推导具体型号。追问有哪些工具时，核优化问题有没有把不含工具改为确认工具清单，保留改写前后文本。取得对应资料后再以原题检查新增引用；最低相关度在语义或重排条件下核验，候选得分和数量都不能补成单据本身没有的详细要求。
