# 加盟商培训与开业辅导的商品资料与选型问答：向量模型与索引

## 这个品类的数据长什么样

在加盟商培训与开业辅导的商品资料与选型问答中，本页说明FastGPT的向量模型与索引如何衔接资料。贴放演练标签与门店商品标签需要保留用途边界。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

加盟培训商品原文自拟“标签仅供贴放演练，不用于门店商品”，开业资料另写“正式标签另见物料册”。问能否用课堂标签替代门店标签时，原文已经区分练习与正式来源，不能由外观相近改成通用。入口可覆盖课堂用途与正式物料问法，但应各自指向对应原数据；把课堂可用概括成门店可用，会丢掉最重要的对象限制。尚未提供正式物料册，也不能自行补其规格。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 练习用途 | 仅供贴放演练 | 保留使用范围。 |
| 排除对象 | 不用于门店商品 | 核索引未删条件。 |
| 正式来源 | 物料册另见 | 不拿课堂段代替。 |
| 新旧身份 | 名称相近未必同款 | 核文档和实际引用。 |
| 扫描路径 | 实际处理方式待核 | 按输出核原文。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是演练入口删除不用于门店，应核索引与完整用途句。第二处是正式标签问题仍指课堂材料，应查入口目标的角色和范围。第三处是正式册补入后，新旧标签名称被回答合成同款，应核各自文档身份与实际引用，不只看词语相同。三项分别查条件保留、目标适用和对象区分，不用培训记录替商品标准，也不把拿到正式册写成已经完成换标。

## 怎么确认配好了

验收分别问课堂标签用途、门店标签出处、二者是否有替代依据，核返回句保留演练与不用于条件。现有资料可以说明用途区分，具体正式标签仍待物料册。补入后核适用门店、实际处理与索引状态，再比较同题引用。多个入口若都指练习段，应明确它们没有提供正式规格。若原文来自扫描件，先查实际文字或图片处理方式，不默认已经走图片向量或文字提取。
