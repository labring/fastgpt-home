# 加盟商培训与开业辅导的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在加盟商培训与开业辅导的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。辅导器材说明中的示范动作、产品属性和侧栏提示需要分清。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

开业辅导器材可拟演示台说明“桌板可拆，底架不折叠”，正文示范“收纳时先移走台面道具”，侧栏“照片折叠架为另一款”。问题是当前演示台是否可折叠收纳。解析时需保留桌板与底架各自属性，也需识别移道具是动作、折叠架属于侧栏另款。若分块只把可拆和折叠架放在一起，就可能拼成原文未有的折叠能力；演示动作同样不能补产品结构。

## 配置怎么定

| 材料核对项 | 本题具体条件 | 实施取证 |
| --- | --- | --- |
| 组件属性 | 桌板可拆底架不折 | 核主体否定。 |
| 侧栏身份 | 折叠架另款 | 不并本款。 |
| 示范受词 | 移走的是道具 | 不扩拆台步骤。 |
| 分块回指 | 每段可追商品 | 保留来源关系。 |
| 实际能力 | 未作实物操作 | 不承诺可折叠。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

第一处是底架不折叠被拆离演示台，应对句内主体和解析文本，核否定是否仍约束底架。第二处是侧栏另一款被并入正文，应查版面关系、商品身份及块来源，不用照片称呼覆盖本款。第三处是移走道具被摘要为拆台步骤，应核动作受词及原句，不把教学示范扩成结构操作。三项分别查否定关系、侧栏归属和动作对象，不以段落相邻推同一产品能力。

## 怎么确认配好了

验收分别问桌板、底架和台面道具的说明，再问侧栏属于哪款，保留原文到引用的映射。分块调整后用可拆、折叠与自然收纳问法对实际返回，不保证特定措辞准确召回。若否定本就漏解析，先定位原结构。更新款式说明后复核训练与索引状态，不能看上传即宣称更新。本练习不做实物拆装或教学实测，也不保证真实演示台能按某流程收纳。
