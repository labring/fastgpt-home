# 加盟商培训与开业辅导的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在加盟商培训与开业辅导的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

加盟培训商品问答可另拟SOP文字：“演示饮品使用示范杯，正式出品容器见开业物料清单。”问演示用什么杯和顾客取得什么容器，需要的来源不同。先用示范杯与正式容器分别查看候选，再用完整问题比较检索模式。SOP可以说明示范用途，却没有列出现实出品杯型；不能因为两个问题都与饮品有关就合并成同一答案。

## 配置怎么定

| 文档项或实施核对 | 本题材料与条件 | 取证动作 |
| --- | --- | --- |
| 检索范围（实施核对） | 演示SOP、培训附注与物料清单 | 示范杯不能直接认定为正式容器。 |
| 搜索模式（语义/全文/混合） | 两种用途分别形成完整问题 | 查看各模式实际支持的范围。 |
| 引用token上限 | 正式容器见清单的指向 | 不能裁剪成只有杯型描述。 |
| 最低相关度 | 语义或重排下核相关度 | 培训命中不表示物料齐备。 |
| 问题优化 | 追问示范杯是否用于出品 | 保持用途，不补写规格。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

另拟培训签到附注“已展示带图案杯”，它只记录了一项展示说法。若回答据此确认正式销售采用该杯，就是把培训记录替代了物料清单，应并列保存原句与返回来源。还需排查引用token上限有无删掉正式容器另见清单的指向，避免只留下杯子描述。演示和正式出品的资料角色应分别保留，不能由排序较前选择一种作为统一配置。第三处是签到附注中的已展示被扩写成学员已经掌握正式出品操作。应核实际培训评估或操作记录，区分展示事件与能力验证；杯具在场或有人签到都没有提供这项结论。

## 怎么确认配好了

开业物料清单未提供时，实际容器规格仍需补充资料，不能从示范杯图案推断容量或材质。追问这款杯是否用于出品，应核优化是否保持当前用途，没有将展示对象扩成销售组成。取得对应清单后，再用原题核新引用，并将来源更新与检索设置变化分开记录；最低相关度只按生效条件检查，培训内容相关不代表出品物料已经核齐。
