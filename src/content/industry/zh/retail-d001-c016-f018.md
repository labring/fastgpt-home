# 加盟商培训与开业辅导的商品资料与选型问答：重排与混合检索

## 这个品类的数据长什么样

在加盟商培训与开业辅导的商品资料与选型问答中，本页说明FastGPT的重排与混合检索如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「重排与混合检索」这一环带来什么约束

加盟培训的商品问答样例，在SOP附页列出特调咖啡及咖啡豆、牛奶、糖浆。候选应把饮品名称和这组成分保持在一起，再用完整商品问题检查重排。这里核对的是手册写明的内容，不能由成分文字推导尚未提供的配比、营养或效果。若制作步骤也进入候选，需观察长步骤有没有挤掉本题所问的成分原句，最终引用仍要回到对应手册。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或适用条件 | 回查与验收线索 |
| --- | --- | --- |
| 融合候选 | 特调咖啡及咖啡豆、牛奶、糖浆 | 成分应与所指饮品对应。 |
| 完整问题 | SOP季节限定与签到附注常态供应 | 保留规则文字和附注的不同角色。 |
| 最低相关度 | 仅在语义或重排时核该参数 | 排名不能确定哪个版本现行。 |
| 引用token上限 | 成分或供应限制的完整原句 | 制作步骤不应挤掉所问成分。 |
| 缺资料复测 | 新品选型和目标顾客资料未提供 | 培训记录不能补出商品受众定位。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `混合检索` | 向量与全文结果通过RRF融合。 |
| `结果重排` | 按完整问题对候选再次排序。 |
| `最低相关度` | 过滤仅在语义或重排时生效。 |
| `引用上限` | 按token裁剪引用内容。 |
| `问题优化` | 比较优化前后主体与限制。 |

## 容易做错的三处

SOP写季节限定，培训签到表附注写常态供应，涉及规则资料和附注两类来源。排序测试先确认两处文字都已召回，再核它们是否针对同一商品、期间和版本。不能由签到表更贴近提问就自动修改SOP的适用范围，也不能只凭两处措辞认定实际经营安排。记录重排及引用裁剪后是否仍能看到双方限定，供后续资料核对使用。签到附注中的供应说法应与SOP中的规则文字分列，核对前不自动统一版本。即使一份材料更新较晚，也需要实际版本依据，不能凭排序或文件名称判断现行口径。

## 怎么确认配好了

新品缺少详细选型参数和目标顾客说明，培训记录的存在不能提供这些商品依据。可检查“适合哪些顾客”的回答有没有借用其他饮品的描述，再补入对应的新品资料复测。候选是否新增、重排后是否保留以及最后引用是否可回查，需分别记录；最低相关度只按实际生效条件验证，不能将一个相关片段的高分当成受众定位已经确认。
