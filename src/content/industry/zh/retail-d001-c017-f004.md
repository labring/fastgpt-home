# 加盟费与保证金结算的商品资料与选型问答：向量模型与索引

## 这个品类的数据长什么样

在加盟费与保证金结算的商品资料与选型问答中，本页说明FastGPT的向量模型与索引如何衔接资料。空白胸牌套的物件属性与另约印字服务分开索引。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

加盟结算关联商品资料自拟用品领取说明“空白胸牌套，印字另约”，服务备注“可登记门店名称”。问领取物是否已经带店名时，物件说明给空白状态，服务备注只说可登记，没有印制结果。入口若写带门店名胸牌，会把另约服务写成已完成属性。应区分胸牌套、登记内容与印字动作，不能因都在同份开业资料里就拼成已定制商品，也不涉及任何金额。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 物件状态 | 空白胸牌套 | 不写已印店名。 |
| 服务动作 | 可登记门店名 | 不当印制完成。 |
| 另约条件 | 印字另约 | 保留未给结果。 |
| 本店对应 | 别店成品可能混入 | 核门店物件身份。 |
| 更新映射 | 本店记录补入后 | 查原数据及实际引用。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是空白被索引成已印名，应对照用品原句与新增属性。第二处是店名问题回到登记备注，应核目标是收集信息还是实际印制。第三处是另一门店的成品记录被用于本店，应查门店对象和物件身份。三项分别核状态改写、动作类型和对象关联，不能用一个门店名或索引命中替代结果证据；即使已登记，也不自动说明另约已完成。

## 怎么确认配好了

验收分别问领取物初始状态、服务备注允许做什么、是否有本店印制依据，核每项引用。已有材料应保留空白、可登记与另约，带名成品仍需记录，不补实际交付。补入本店记录后核原数据及索引映射，再以同题比较返回；上传成功不证明旧入口已改。若多个入口指登记段，它们仍只提供登记动作，不能靠数量变成多份印字完成证明。
