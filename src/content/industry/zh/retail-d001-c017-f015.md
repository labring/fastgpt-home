# 加盟费与保证金结算的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在加盟费与保证金结算的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。服务品目和设备资料指向能被命中，但设备主体仍需供货清单正文。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

加盟结算资料里的选型提问，首先要判断查到的是服务项目还是设备明细。自拟发票写“品目为加盟服务项；设备另见供货清单”，付款计划附注写“设备事项单列”。这里有两次指向设备资料的关系，却没有设备条目本身。用设备名称作为查询目标时，候选可能仍来自发票和附注；应逐一指出它们实际提供的是项目身份与资料指向，不能把同一指向重复出现当成配置已被列明。

## 配置怎么定

| 本题检索对象 | 具体文字关系 | 检查所得 |
| --- | --- | --- |
| 服务项目 | 发票品目为加盟服务项 | 确认这项所指的已知对象。 |
| 资料指向 | 设备另见供货清单 | 定位所需正文，不补设备名。 |
| 范围委托 | 付款附注将设备事项单列 | 两个指向不构成配置条目。 |
| 改写与裁剪 | 哪台设备追问及另见条件 | 定位实体新增或条件丢失阶段。 |
| 补清单复测 | 核同一服务项目适用关系 | 逐条追设备主体、配置与除外条件。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

如果问“这项里面是哪台设备”，这项在已知文字中首先指服务品目。问题优化若直接补出机器名称，会改变提问对象；检索到类似设备词也不能证明其来自本项供货范围。另一个失败情形是片段只留下设备二字，另见清单与单列被裁掉，回答因此把设备写成服务已经包含。应同时核原问题、优化文字、完整候选与实际引用，定位实体是在改写、取回还是回答阶段增加的。

## 怎么确认配好了

验收不只看是否命中设备关键词，可用三个结果对象核对：发票能够证明何种项目，付款附注把事项交给哪份资料，现有正文能否列出任何设备及其配置。前两项可以各自回指，第三项应保持缺少清单正文。若后续取得实际供货清单，再核其是否适用于同一服务项目，逐条查设备主体、配置与除外条件，并追踪它是否进入候选和引用。旧资料仍可用于说明项目身份，不能由新旧片段相邻就推定已经付款或交付。
