# 区域经销商库存补货的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在区域经销商库存补货的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。经销商品表的型号栏、通用说明和局部例外不能跨行错接。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

经销商品阅读可拟两款陈列架：窄架行“带侧钩”，宽架行“侧钩另选”，表外通用说明“配件按对应行”。当前问宽架是否附侧钩。解析要保留型号列与配件列，分块不能把窄架的带钩拷到宽架。通用说明本身也没有列具体配件，需要回到行。这里的宽窄仅为自拟商品标签，不是软件参数或真实规格，不能从同系列或表格相邻推两款配置完全相同。

## 配置怎么定

| 材料核对项 | 本题具体条件 | 实施取证 |
| --- | --- | --- |
| 型号列 | 宽窄架分开 | 核解析行对应。 |
| 选配词 | 宽架另选 | 保留同一行。 |
| 通用转引 | 按对应行 | 实际读宽架行。 |
| 更新目标 | 宽架当前配置 | 核训练与引用。 |
| 现实适用 | 没有安装或库存证据 | 不补执行结论。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

第一处是型号列解析丢失后带侧钩无对象，应对原表、解析及原数据块，恢复行对应。第二处是另选被分离后宽架看似已含，应核状态词与同一行，不能从空白片段补配置。第三处是通用说明被当完整商品答案，应查实际引用是否包含宽架行，不以配件按对应行代替读取该行。三项分别查型号、选择状态和转引覆盖，不用索引数量或相同系列名替商品依据。

## 怎么确认配好了

验收分别问两款配置和通用说明指向什么，保存原始行、解析文本、块身份及实际引用。分块调整后用宽架、侧钩和自然包含问题测试，不承诺某模式必然召回。更新宽架行后核训练与索引状态，再同题查当前原文；上传成功不自动更新引用。本练习不下补货单、不测实物承重或附件安装，也不证明现实库存和供货确认，实际采用仍需对应材料。
