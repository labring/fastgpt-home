# 区域经销商库存补货的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在区域经销商库存补货的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

区域经销商商品检索可另拟补货申请：“短版货架，加固件清单另附。”货架版本与配套件需要分别核对，先用短版及加固件这些原词检查候选，再比较包含问题在三种模式下取回的依据。原文写的是清单另附，没有实际列明配件。名称相关只能指出需要哪份材料，不能把短版改写成配件已经完整配置的货架组合。

## 配置怎么定

| 文档项或实施核对 | 本题材料与条件 | 取证动作 |
| --- | --- | --- |
| 检索范围（实施核对） | 申请版本与出库大类分开 | 组合名称不提供配件明细。 |
| 搜索模式（语义/全文/混合） | 短版、加固件及完整包含问题 | 比较各模式实际来源。 |
| 引用token上限 | 清单另附的限定 | 检查条件在候选或引用何处遗漏。 |
| 最低相关度 | 语义或重排条件下核相关度 | 高相关不证明适配。 |
| 问题优化 | 追问这些件适用哪一版本 | 不补出未知配件型号。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

另拟出库单只写“货架组合”，可用于排查大类名称替代明细的问题。若答复据此列出加固件，就应回查是否真的有清单进入输入；单据中组合一词不提供所有组成项。另查引用token上限是否裁掉另附条件，保存申请原句、出库条目及实际返回。两个来源同被取回，也不能说明出库对象与所问版本已经完成对应。

## 怎么确认配好了

加固件清单和具体适配说明未提供时，追问这些件能否用于短版仍缺证据。核问题优化是否把未知配件扩成指定型号，不能从货架组合借入规格。取得对应资料后，用原题比较新增候选及引用，并记录资料与参数各自变化。最低相关度按实际生效条件检查，片段靠前不表示适配性已被验证，实际结构或安装要求仍需相应专业材料支持。
