# 区域经销商库存补货的商品资料与选型问答：重排与混合检索

## 这个品类的数据长什么样

在区域经销商库存补货的商品资料与选型问答中，本页说明FastGPT的重排与混合检索如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「重排与混合检索」这一环带来什么约束

区域补货的自拟申请，用“中等”描述建议补货量，用“标准箱装”描述包装规格。检索与重排要保留这种定性表述，不能擅自换算成具体件数或箱数。先检查所问型号对应的两处文字是否进入候选，再看完整问题下的排序是否仍能同时支持补货量和包装回答。实际订货数量还需对应业务依据，不能从该样例的词义推算。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或适用条件 | 回查与验收线索 |
| --- | --- | --- |
| 融合候选 | 中等补货量及标准箱装 | 保持定性文字，不自行换算件数。 |
| 完整问题 | 充足与低位的库存状态范围 | 核商品、时间和统计口径是否相同。 |
| 最低相关度 | 语义检索或重排时核过滤行为 | 状态词高分不构成库存核对结果。 |
| 引用token上限 | 状态与其条件需对应保留 | 不得把低位当成数值计算补货量。 |
| 缺资料复测 | 缺保质期与近期销售条件依据 | 补资料后再核其对本题的支持。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `混合检索` | 向量与全文结果通过RRF融合。 |
| `结果重排` | 按完整问题对候选再次排序。 |
| `最低相关度` | 过滤仅在语义或重排时生效。 |
| `引用上限` | 按token裁剪引用内容。 |
| `问题优化` | 比较优化前后主体与限制。 |

## 容易做错的三处

申请中的充足与周转表中的低位，需要先核状态所指的商品、时间和统计范围。两种词并不总是在同一口径下比较，不能看到不同就认定库存记录错误。把双方原文与身份分别保存在候选核对中，再观察重排有没有只留下更贴近问题的一侧。若一方未召回，先查范围；两边均在时，再核排序及引用是否保留可比性条件。库存状态词也不能直接换算成建议采购数量。若问题转向订货决策，应另核数量和适用条件的依据，不能把“低位”作为模型自行计算补货量的输入事实。

## 怎么确认配好了

保质期未提供时，现有补货申请无法说明该型号是否满足近期销售所需条件，销售要求本身也要有依据。可以检查回答有没有从“库存充足”推断商品仍在适售范围，或补写具体日期。补充对应资料后重复原问题，分别核新增候选、过滤行为及最终引用；调整重排不能创造保质期记录，也不能替代对具体销售条件的核对。
