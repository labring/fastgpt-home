# 原产地证书申办的商品资料与选型问答：向量模型与索引

## 这个品类的数据长什么样

在原产地证书申办的商品资料与选型问答中，本页说明FastGPT的向量模型与索引如何衔接资料。品名、组装地点与本批来源指向不能组合成原产地属性。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

原产地资料中的商品索引自拟品名“组装组件”、说明“终装地点见另页”和申请附注“本批来源待核”。问商品是否在某地制造时，品名不提供地点，终装另页尚未读，来源也待核。入口若写本地制造组件，就增加原数据未给的属性。应保留品名、工序地点和本批来源三个对象，不把组装一词等同完整制造过程，也不由地点空缺作相反结论。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 品名信息 | 组装组件 | 不添加产地。 |
| 工序地点 | 终装地点另见 | 核工序与货物。 |
| 本批状态 | 来源待核 | 保留待确认。 |
| 跨批目标 | 另一批地点页 | 核对象及适用。 |
| 确认采用 | 新来源与旧申请入口 | 查实际引用版本。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是组件名称被索引成已确认产地，应查对应货物来源原文。第二处是地点问题指向另一批终装页，应核货物、批次与工序身份。第三处是来源确认补入后，入口仍只引用待核申请，应核新原数据、索引目标与实际采用。三项分别查属性新增、适用对象和更新映射，不以文件标题或相似地名完成核定，也不由这些段落作出证或合规判断。

## 怎么确认配好了

验收分别问品名说明什么、终装页是否取得、本批来源确认到了哪步，核引用来源与限定。当前可以列明组件称呼和待核范围，制造地点仍需适用资料，不补国家或地区。新资料取得后检查实际处理与索引状态，再用同题看引用是否采用确认原文。多个入口若仍指申请附注，不能当作多份来源证明；检索定位完成也不代表业务核查已经完成。
