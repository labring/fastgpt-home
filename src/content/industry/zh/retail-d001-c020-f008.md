# 原产地证书申办的商品资料与选型问答：工作流编排

## 这个品类的数据长什么样

在原产地证书申办的商品资料与选型问答中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

原产地证申请中的产地表述与商品本身的材质、用途说明，应作为不同阅读对象。自拟测试可给出申请附页的产地原句，同时注明只有商业发票品名，没有制造方的成分说明。表单提交后，检查后续步骤是否仍按各自出处使用这些内容，不能将“材料中记载某产地”扩写为商品具备某种性能，或将申请表述当作已经取得正式签发结果。

## 配置怎么定

| 核对步骤 | 本题自拟输入 | 应核对的实际结果 |
| --- | --- | --- |
| 对象分开 | 产地原句、发票品名、缺少成分说明 | 产地表述没有被扩展为商品性能 |
| 传值来源 | 申请文字及本次属性问题 | 后续步骤仍能回到各自原文 |
| 资料路径 | 补生产说明、核申请或暂缓 | 所选路径提供其实际具备的依据 |
| 接收缺项 | 选补资料但尚未收到新来源 | 检查接收值并维持缺项状态 |
| 业务提交 | 证书申请的实际操作与签发记录 | 与资料阅读和交互状态分别核对 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

客户若追问某种商品属性，流程可让资料负责人选择补生产说明、核申请文字或暂缓回答，并逐项验证路径。应先查本次问题需要的证据，不能让查看申请的分支替代获取商品说明。选了补资料却未收到新来源时，应回查实际接收值并保留缺项；人员作出的选项选择不负责确认原产资格，也不对商品品质作出判定。 当自拟生产说明只提到组装地点，而问题要求商品材料构成时，两者并非同一依据。若答复由地点推断组成，应排查引用落在哪句原文，分别转交生产工序说明与材料清单的补充需求；补回的资料也须逐项看内容，不能因文件名称像成本资料就直接采用。

## 怎么确认配好了

取得补充后，用同一属性问题对照新增原文、提交记录和最终引用，确认结论没有跨越来源实际支持的范围。生产资料中的说明若仍不足，应记录还需哪项依据及提供者。需要修改或提交证书申请时，应由实际业务流程另核操作权限与真实结果；知识问答或表单继续执行，不证明证书已签发、商品已获认可或客户清关已经完成。
