# 原产地证书申办的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在原产地证书申办的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。原产商品页的标题范围、生产陈述和运输侧注应保持独立。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

原产商品资料可拟标题“本页为支架外壳”、正文“在松桥厂完成喷涂”和侧注“整机由东岸仓发运”。问题是整机是否都在松桥厂生产。解析需保留外壳标题与喷涂工序，不将侧注整机和正文工厂拼成全机生产事实。运输地点也不解释生产工序。材料没有其他组件的生产记录，本页不引入真实原产规则，只核不同版面位置的文字范围，不能因标题短而在分块时丢失它的对象限制。

## 配置怎么定

| 材料核对项 | 本题具体条件 | 实施取证 |
| --- | --- | --- |
| 标题范围 | 仅支架外壳 | 随喷涂句保留。 |
| 工序限定 | 喷涂 | 不扩全机制造。 |
| 侧注行动 | 整机发运 | 不并生产链。 |
| 组件来源 | 另页组装说明 | 核对象版本。 |
| 现实判断 | 生产链仍缺 | 不作资格结论。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

第一处是支架外壳标题被拆离喷涂句，应对标题层级、解析段落与块，核工厂陈述实际修饰什么。第二处是整机发运侧注并入生产描述，应查版面来源与动作词，不从发运推生产。第三处是另一页整机组装说明被同名块采用，应核商品、组件及版本，不能用整机词覆盖外壳范围。三项分别查标题、侧注和来源身份，不以相关片段共现补完整生产链。

## 怎么确认配好了

验收分别问本页对象、所述工序、整机侧注行动，保存原文布局到解析文字和引用的对应。用外壳、喷涂及整机生产自然问法复测，核当前分块能支持哪项，不保证特定词精准命中。补入组件资料后先核本品身份及版本，再查训练与引用是否采用。当前缺生产链就列待补，不反推声明虚假。测试不判断原产资格或执行申办，也不证明真实工厂与运输事件已经被核实。
