# 原产地证书申办的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在原产地证书申办的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

原产地证申办材料的商品检索可另拟商业发票：“木制装饰组件。”装箱单再写“未组装交付，底座单列”，用于核对单据描述的形态。先用组件、未组装和底座这些原词检查候选，再用完整商品组成问题比较搜索模式。单据文字可以提供阅读线索，但不能因名称接近就认定是完整成品，也没有在本例中完成商品归类或原产地判定。

## 配置怎么定

| 文档项或实施核对 | 本题材料与条件 | 取证动作 |
| --- | --- | --- |
| 检索范围（实施核对） | 商品形态与地点信息分别核对 | 装运地点不补成生产地点。 |
| 搜索模式（语义/全文/混合） | 组件、未组装与组成问题 | 查看各模式实际原句。 |
| 引用token上限 | 单列与生产地未填 | 保留组成和缺项状态。 |
| 最低相关度 | 语义或重排条件下核过滤 | 候选相关不决定证书条件。 |
| 问题优化 | 追问哪里生产 | 核优化没有以装运地补未知地点。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

另拟申请附注“装运地为港口甲，生产地未填”，可用于排查来源字段混用。若回答将装运地点写成生产地点，应并列保存附注及返回文字，定位多出的说法来自哪里。引用token上限也需保留未填这一状态，不能只剩地点词。发票商品名称、装箱形态与申请地点各有用途，候选共同出现不表示它们能互相补齐同一属性。第三处是把生产地未填解释成已经否定某地生产。应核是否另有对应货物的产地说明，区分本栏空缺与来源作出的否定；装运地字段和商品名称都不能代替该证明。

## 怎么确认配好了

生产来源说明及完整商品规格尚未提供，应分别保留两项证据缺口。追问这件哪里生产时，核优化有没有把装运地当作已知生产地；没有原文支持的新增地点不能采用。取得对应资料后，再用原问题检查新增引用和候选，分开记录补资料与调参数。最低相关度只按其生效条件检查，不由得分推定商品属性或证书申办条件已核实。
