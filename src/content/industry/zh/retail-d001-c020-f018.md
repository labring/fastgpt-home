# 原产地证书申办的商品资料与选型问答：重排与混合检索

## 这个品类的数据长什么样

在原产地证书申办的商品资料与选型问答中，本页说明FastGPT的重排与混合检索如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「重排与混合检索」这一环带来什么约束

原产地证申办的商品问答，可用自拟商业发票中的精选咖啡豆及一千公斤作为名称和数量阅读样例。先标注这两项对应的原句，核候选有没有把商品与计量单位分开，再观察重排是否仍能回答完整问题。商品名称和数量不包含原产地判定依据，也不能由发票被检索到就确认证书申办条件；阅读记录应保留名称、数量及其对应位置。还要区分商品描述与证明来源，不因咖啡豆名称出现就推断其生产地点。若问题转向原产地，应取得相应资料后另行核对，保持当前问答的证据范围。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或适用条件 | 回查与验收线索 |
| --- | --- | --- |
| 融合候选 | 咖啡豆名称及一千公斤数量 | 商品描述不提供生产地点依据。 |
| 完整问题 | 两份单据总净重九百五十与九百八十公斤 | 核商品、单位和版本后再比较。 |
| 最低相关度 | 仅在语义或重排时核其生效 | 相关度不决定应采纳的净重。 |
| 引用token上限 | 重量数值和总净重口径 | 防止只留数字而丢掉计量含义。 |
| 缺资料复测 | 缺少保质期与存储条件 | 补对应来源，不生成保存建议。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `混合检索` | 向量与全文结果通过RRF融合。 |
| `结果重排` | 按完整问题对候选再次排序。 |
| `最低相关度` | 过滤仅在语义或重排时生效。 |
| `引用上限` | 按token裁剪引用内容。 |
| `问题优化` | 比较优化前后主体与限制。 |

## 容易做错的三处

商业发票与装箱单分别写九百五十公斤、九百八十公斤的总净重，排序检查应保留两种数值及其文件身份。先核商品、单位和版本是否可比较，再看引用中是否保留“总净重”，并区分其他重量口径。两个候选同时出现不代表差异已解释，排位靠前也不能决定应采纳的重量；需回到相应原始记录继续核对。

## 怎么确认配好了

保质期和存储条件未出现在现有发票附页中，应把这两项作为仍需取得的资料。可检查相关候选是否只是其他商品的通用说明，输出有无无出处的日期或保存建议。取得对应资料后再问原问题，记录新来源进入候选及引用的情况。重排和最低相关度只在各自条件下检查返回内容，不承担商品存储适用性或原产地资格认定。
