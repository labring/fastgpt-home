# 品牌会员私域运营的商品资料与选型问答：工作流编排

## 这个品类的数据长什么样

在品牌会员私域运营的商品资料与选型问答中，本页说明FastGPT的工作流编排如何衔接资料。会员商品问答保留权益适用、商品差异与信息版本，选择分支不授予会员权益。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

假设会员页说明权益仅适用指定系列，商品卡只列材质未列尺寸，旧群消息属于另一活动。先收商品、所问权益及来源，让人员选择核选型信息或补适用依据，再检查下游收到的原句。收集会员问题不证明用户符合资格，用户选择也不是会员数据库查询结果。

## 配置怎么定

| 会员选型编排 | 自拟限定 | 核验动作 |
| --- | --- | --- |
| 权益系列 | 指定范围 | 不扩全部商品 |
| 商品尺寸 | 卡片未给 | 不推适配 |
| 历史消息 | 另一活动 | 核版本时效 |
| 选择路径 | 规格或权益 | 看实际原句 |
| 权益发放 | 业务接口另核 | 资格及权限 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

系列限定被扩大所有商品时，对权益范围；未列尺寸却答适配时，查尺寸依据；旧活动消息套当前权益时，对活动版本。三处分别核范围、规格缺口和时效，纸面问答不提供真实资格认证或购买结果。

## 怎么确认配好了

验收两条路径的回答逐句追来源，尺寸缺证时继续待补。新增尺寸只补选型信息，权益资格仍另核；旧消息留在对照区。权益发放、会员身份校验及订单变更需要独立业务接口和权限，编排链把收集的信息传递到位，不代替这些业务决定。 选型表将材质已给与尺寸缺席分列，权益原句紧邻适用系列，便于复查每项依据。

| 材料背景 | 适用范围 |
| --- | --- |
| 文档类型 | 会员标签表、触达计划、优惠券规则、隐私授权记录 |
| 候选来源 | CRM系统、企微、POS消费记录、小程序行为数据 |
