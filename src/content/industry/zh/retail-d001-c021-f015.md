# 品牌会员私域运营的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

在品牌会员私域运营的商品资料与选型问答中，本页说明FastGPT的知识库检索与召回如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

会员私域商品问答可新拟优惠券规则附注：“会员礼包含试用装；正装需另选。”检索时要把礼包组成与选购项分开，先用试用装、正装这些原词检查候选，再以礼包含什么的完整问题比较搜索模式。会员这一名称只说明自拟资料的场景，不提供真实人员数据；商品关键词命中也不能把另选的正装写成礼包已经包含。

## 配置怎么定

| 文档项或实施核对 | 本题材料与条件 | 取证动作 |
| --- | --- | --- |
| 检索范围（实施核对） | 礼包规则与营销展示文字分开 | 展示物不能替换礼包组成。 |
| 搜索模式（语义/全文/混合） | 试用装原词与完整包含问题 | 比较各模式的实际支持。 |
| 引用token上限 | 正装另选及不表示配置 | 核否定和选配条件没有被裁掉。 |
| 最低相关度 | 语义或重排时核过滤 | 相关结果不提供试用装规格。 |
| 问题优化 | 追问这份礼包的规格 | 不将正装属性带入试用装。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

另拟触达计划写“正装展示图，不表示礼包配置”，这段普通文字描述营销展示，不提供实际图片内容。若答复用展示物取代礼包组成，就误用了来源，应保存规则附注、计划文字及实际引用作对照。还需排查token裁剪是否遗漏不表示或另选这些条件，避免只保留正装名词。触达计划与商品规则不同，不能因同时被召回就拼成新的礼包清单。第三处是把某次触达计划中的正装展示延用为所有会员活动的配置。应核计划适用活动和期间，再与本次礼包规则对应；一次展示既不覆盖其他活动，也不能补成本次清单。

## 怎么确认配好了

试用装的具体规格未提供，优惠券规则和展示文字都不能补出容量或材质。追问这份多大时，应并排检查原问与优化问题，核是否误将正装规格带入试用装。取得对应商品说明后，再用同题检查新增引用，并记录资料更新与检索参数的独立变化。最低相关度只在语义或重排条件下生效，片段得分不能证明全部礼包属性已齐，也不能据此推断任何真实会员的购买或授权情况。
