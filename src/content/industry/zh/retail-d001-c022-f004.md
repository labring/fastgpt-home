# 品牌全渠道库存调拨的商品资料与选型问答：向量模型与索引

## 这个品类的数据长什么样

在品牌全渠道库存调拨的商品资料与选型问答中，本页说明FastGPT的向量模型与索引如何衔接资料。渠道简称与直营规格的对象对应需要明确关系。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

全渠道商品索引自拟渠道表“轻便款”，直营规格页写“折叠式支架”，调拨备注“按渠道简称查询”。问轻便款是否可折时，简称提供查找方式，技术页提供某支架结构，本组没有两者对应。入口若把轻便直接改成折叠，会将营销称呼当技术属性。应保留渠道、规格与调拨用途的原数据身份，不能由常见词义推定同一商品，也不把按简称查询写成已经完成实体校对。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 渠道称呼 | 轻便款 | 不直接解释可折。 |
| 技术对象 | 直营折叠式支架 | 核所属单品。 |
| 查找用途 | 按简称查询 | 不当实体校对完成。 |
| 跨渠道目标 | 同名可能属别渠道 | 核渠道及对象。 |
| 新增映射 | 关系表与旧入口 | 比实际引用是否采用。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是轻便入口新增可折，应核本渠道商品是否有该规格原文。第二处是渠道入口指向另一渠道同名物品，应查目标所属渠道及单品身份。第三处是对应表补入后，旧入口仍指原先猜测目标，应核新关系、索引映射与实际引用。三项分别核属性来源、渠道对象和更新采用，不以简称、同一品牌或查询成功证明两个原数据指同一实体。

## 怎么确认配好了

验收分别问渠道如何称呼、直营页描述什么、有没有明确对应，核引用保留来源。可以说明两份文字各自内容，轻便款结构仍待关系确认。对应表取得后先核适用期间与单品，再查实际处理和索引，以同题看是否真正采用。一个原数据可对应多个入口，并不允许不同渠道资料被自动合成一款；每个查找入口仍需回到已核的具体对象。
