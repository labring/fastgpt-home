# 品牌奥莱折扣运营的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

在品牌奥莱折扣运营的商品资料与选型问答中，本页说明FastGPT的模型接入与配置如何衔接资料。核清货清单对款式、季节与库存的支持范围，补齐选型需要的商品属性资料。所用场景为自拟文字测试。

## 这些特征在「模型接入与配置」这一环带来什么约束

自拟清货附页可列款号、季节标识和门店现货说明，供选型问答识别候选商品。模型接入应核三项是否连同款号关系一起进入请求；库存文字不说明材质、尺码适合度或质量。若回答从“过季”推断商品存在缺陷，应保存清单原句与新增判断排查支持范围。清货目的与商品状况是不同事项，调用有结果不能证明选型所需属性已经取得。

## 配置怎么定

| 接入核对项 | 奥莱候选商品材料 | 验证线索 |
| --- | --- | --- |
| 候选识别 | 款号、季节与门店现货说明 | 关联关系实际送达 |
| 属性边界 | 库存不说明尺码材质或质量 | 无据判断回查原句 |
| 名称映射 | 系列名与具体款号另核 | 缺来源与传入遗漏分开 |
| 范围串用 | 季节及门店不得无据混合 | 保存请求与具体返回 |
| 补齐属性 | 新尺码材质资料同题复核 | 图片及业务批准另外核验 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `AI Proxy依赖` | 按实际版本核服务、渠道与应用。 |
| `AIPROXY_API_ENDPOINT` | 使用AI Proxy服务根地址。 |
| `AIPROXY_API_TOKEN` | 管理员Token非空且与服务端一致。 |
| `模型能力` | 按实际输入路径验证所需能力。 |
| `应用参数` | 接口同名字段未必覆盖应用设置。 |

## 容易做错的三处

- 款号与现货说明的关系在输入中丢失：对照清单和实际请求查传递，不能用出现同一商品词就认定候选款已正确识别。

- 系列名与具体款号被直接合并，或季节门店串用：保留两份身份与返回，补实际映射后再核，不由相似名称或参数裁定同款。

- 过季清货被解释成缺陷或适合某尺码：回查质量及属性依据，库存背景不提供这些条件；缺商品资料时保留选型限制。

## 怎么确认配好了

验收可以分别问候选款、对应门店及缺少的属性，记录答案采用哪项现货说明、哪些仍待补资料。尺码和材质来源补齐后，以同题和相同设置核输入及条件，不能让旧清单覆盖新说明。图片中的颜色或细节需要另验相应输入，当前文字核对不代表图片读取。审批、价格与购买条件也须另据适用材料确认，选型回答不自动完成业务批准。
