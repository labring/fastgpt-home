# 品牌经销商订货会的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

订货会面向线下经销商预订，不直接管理平台店铺。主要数据来源为订货会系统、历史销售、经销商库存与财务授信，日常文档包括订货手册、订货合同、样品清单与授信审批。商品资料与选型问答要回答的是某款商品在某个订货季是否可订、对应哪份手册条款、样品清单里是否列明该型号。资料更新频率为季、年，模型接入与配置只需保证这些文档进入知识库后，问答请求能按已启用的语言模型与索引模型完成检索与生成。

## 这些特征在「模型接入与配置」这一环带来什么约束

从 V4.17.0 起，AI Proxy 为必需依赖。App 与复用 App/Service 配置的 Admin 服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空的 `AIPROXY_API_TOKEN`；缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。系统至少需要一个语言模型和一个索引模型才能正常使用。模型渠道配置中的代理地址填写 `BaseUrl`，不要填完整模型请求地址。模型映射把 FastGPT 请求的模型映射到上游实际模型，例如 `gpt-4o-test` 映射为 `gpt-4o`。检索库与向量模型的关系属于知识库侧配置，不随本页的模型接入改变。

## 配置怎么定

假设演练样本：某品牌渠道部在 2026 年秋季订货会前，将《2026 秋季订货手册》第 3 章、样品清单 A 表与一份授信审批单导入知识库，用于商品资料与选型问答。手册第 3 章写明「A 型保温杯本季可订，起订量 500 件」。样品清单 A 表列出 A 型保温杯，状态栏为「已到样」。授信审批单载明某经销商申请额度 80 万元，审批栏为空。待判定拟稿句为「A 型保温杯本季可订，该经销商已获 80 万元授信」。该句前半部分有手册原文支持，后半部分只有申请金额、审批栏为空，属于未获支持。

| 配置项 | 本次假设起点 | 选择理由与比较方法 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填写 AI Proxy 服务根地址，不附加 `/v1` | 与文档要求一致，比较是否含多余路径 |
| `AIPROXY_API_TOKEN` | 填写与服务端一致的非空管理员 Token | 与文档要求一致，比较是否为空 |
| 语言模型 | 启用一个语言模型 | 系统至少需要一个语言模型，比较启用状态 |
| 索引模型 | 启用一个索引模型 | 系统至少需要一个索引模型，比较启用状态 |
| 模型映射 | 将请求模型映射到上游实际模型 | 按渠道配置填写，比较映射前后模型 ID |
| 模型探测 | 按需开启自动探测，间隔设为本次假设起点 30 分钟 | 文档支持 5～60 分钟整数，比较探测记录 |

## 容易做错的三处

1. 把 `AIPROXY_API_ENDPOINT` 填成带 `/v1` 或 `/chat/completions` 的完整请求地址。输入为环境变量值，比较对象为文档所述根地址格式，观察结果是启动校验是否通过。
2. 把授信审批单的申请金额当作已获授信写入拟稿句。输入为审批栏为空的审批单原文，比较对象为拟稿句中「已获 80 万元授信」的表述，观察结果是该表述缺少审批完成的证据。
3. 用检索结果或表单填写代替授权执行。输入为知识库检索返回的手册条款，比较对象为拟稿句是否据此声称可订，观察结果是检索只提供文本依据，不构成订货授权。

## 怎么确认配好了

1. 输入假设样本中的手册原文「A 型保温杯本季可订，起订量 500 件」与拟稿句前半部分，比较两者主体、对象、期间是否一致，观察结果是该部分获得原文支持。
2. 输入假设样本中的授信审批单原文与拟稿句后半部分，比较审批栏状态与「已获 80 万元授信」的表述，观察结果是审批栏为空，该部分属于未获支持，需记录证据缺口。
3. 输入假设样本中的样品清单 A 表与拟稿句，比较样品状态栏「已到样」与拟稿句是否声称可订，观察结果是样品到样与可订属于不同事实，不能互相替代。
