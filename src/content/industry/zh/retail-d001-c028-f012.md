# 品牌自播直播间运营的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在品牌自播直播间运营的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。直播商品卡的原话引用、脚本建议和规格字段不能混作同类正文。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

品牌自播商品阅读可拟规格字段“杯盖需旋紧”，脚本建议“可演示单手拿起”和引用区“有人问能否倒置”。当前问题是商品是否可以倒置使用。解析需保留规格、建议及观众问句三种身份，问过能否不说明可以，拿起演示也不等于倒置能力。分块如果丢引号或栏目，会把问题当肯定属性。此处全为自拟文字，没有真实密封性能或实验数据，不可从杯盖需旋紧外推任何使用效果。

## 配置怎么定

| 材料核对项 | 本题具体条件 | 实施取证 |
| --- | --- | --- |
| 问句身份 | 观众能否倒置 | 不当肯定属性。 |
| 脚本用途 | 单手拿起演示 | 不扩规格。 |
| 条件主体 | 旋紧杯盖 | 解析保持连接。 |
| 栏目边界 | 规格建议引用分开 | 核块归属。 |
| 现实效果 | 没有物理试验 | 不承诺性能。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

第一处是观众问句丢能否后变成倒置陈述，应对引用区、句式和解析结果，保留疑问身份。第二处是脚本单手拿起被扩成规格，应查栏目用途及实际商品依据，不用演示计划补能力。第三处是旋紧条件被拆离杯盖，应核动作与主体连接，不能把条件无对象化或推广整杯效果。三项分别查引述、内容类型和条件，不以同页出现动作词就确认真实物理表现。

## 怎么确认配好了

验收分别问规格实际要求什么、脚本计划什么、观众提出什么，把答案回指各自栏目。调整分块后用旋紧、单手与自然倒置问法核实际引用，检查问句仍是问句，不承诺某问法必然召回。卡片更新后核训练和原数据版本，上传成功不说明新条件已采用。缺实测继续列待核，本练习不直播或测试倒置，不保证安全性能，也不把自拟观众问题当真实用户反馈。
