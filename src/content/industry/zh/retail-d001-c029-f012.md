# 售后维修与补寄的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在售后维修与补寄的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。补寄清单中的父部件、括注用途和排除配件需要按层级保留。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

维修补寄商品阅读可拟树形清单：外盖下列“装饰片（只作遮饰）”，卡扣下列“弹簧另配”；页尾说明“示意图中的整盖并非本清单全部供应”。问题是是否含整盖及弹簧。解析需保留父部件与子项，括注只约束装饰片，另配约束弹簧；图中的完整外观也不扩大供货范围。分块后若仅留下外盖、卡扣等上级名称，不能直接认定这些总成已在供应清单内。

## 配置怎么定

| 材料核对项 | 本题具体条件 | 实施取证 |
| --- | --- | --- |
| 父子层级 | 分组名与实供子项 | 逐项对原树。 |
| 括注用途 | 装饰片只遮饰 | 保留局部范围。 |
| 配件状态 | 弹簧另配 | 连接卡扣分支。 |
| 图示范围 | 整盖超出清单 | 不补组成。 |
| 实际引用 | 子项与条件同返 | 核更新版本。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

第一处是树形父节点变成实供条目，应对原层级、解析列表与块身份，核哪些只是分组名称。第二处是弹簧另配被拆离卡扣，应保留部件及状态的连接，不让缺少限定的弹簧词成为随附证明。第三处是图示整盖被用来补供应组成，应查页尾说明及示意用途，不能以完整图注替清单。三项分别查层级、选配状态和展示范围，不由块中多次出现总成名推商品齐套。

## 怎么确认配好了

验收分别问实供子项、弹簧状态和整盖图注，保存原树、解析文本、块与实际引用的对应。调整后用装饰片、弹簧及自然整套问题复测，查看是否仍带括注和另配。若父子关系没解析，先修该关系，多个索引不能生成缺失层级。清单更新后核训练及实际引用版本。本练习不创建补寄单、不做实物装配，也不保证现实备件适配或已经发出；当前缺整套确认仍应留待核。
