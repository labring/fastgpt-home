# 商超供应商进场结算的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

在商超供应商进场结算的商品资料与选型问答中，本页说明FastGPT的文档解析与分块如何衔接资料。供应商商品表的计量对象、包装附注和门店另行工作需要分清。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

商超供应商商品阅读可拟表头“商品主体”，行内写“单只玻璃杯”；包装栏“外箱成组”，脚注“门店标签另印，不随货”。问题是商品是否按整组且附印好标签供应。解析要保留单只修饰商品、成组修饰外箱，标签另印是门店工作。不能将横向栏目读成单一规格句，或从外箱分组推销售单位已经变化。文字没有本次交易数量与验收结果，不应由表格格式补这些业务事实。

## 配置怎么定

| 材料核对项 | 本题具体条件 | 实施取证 |
| --- | --- | --- |
| 计量对象 | 商品单只 | 不并外箱成组。 |
| 包装栏目 | 外箱层级 | 核解析列。 |
| 脚注工作 | 门店另印标签 | 不当随附成品。 |
| 旧页身份 | 印标包装另源 | 核版本与对象。 |
| 真实交易 | 数量结果未给 | 不补执行事实。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

第一处是商品与包装两列串接，应对表头、解析列和块来源，核单只与成组各修饰什么。第二处是标签不随货脚注被切离，应查其商品与门店归属，不把另印写成已经附带。第三处是旧印标包装页进入当前商品问题，应核版本、标识对象与实际引用，不靠同杯名合并。三项分别查列关系、脚注行动和来源身份，不由多个相关片段推成套或完成印制。

## 怎么确认配好了

验收分别问商品单位、外箱组织和标签由谁处理，保留原表到解析与引用的映射。调整分块后用单只杯、成组箱及自然随附问题复测，查看是否仍能区分层级。若脚注没解析，先补原文字句，不用索引关键词代替。新包装页加入后核本款、训练与实际引用，上传不证明采用。本练习不决定真实采购数量，不执行印标或验收，也不证明货物已按某种包装交付。
