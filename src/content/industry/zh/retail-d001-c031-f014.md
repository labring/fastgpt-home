# 商超塑料袋与一次性用品报告的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

该品类围绕一次性塑料制品报告与环保监管展开，主要数据来源包括商务部报告系统、POS塑料袋销售、采购系统和门店台账。日常文档为塑料袋采购台账、销售凭证、半年报告和自律承诺。商品资料与选型问答要处理的问题，是把台账、凭证、报告、承诺这些材料中的字段与状态讲清楚，供运营人员核对。

材料里的关键字段通常是主体名称、制品规格、采购或销售数量、对应期间、凭证状态。这些字段决定一条问答是否有依据。模型接入与配置环节需要让问答能够引用这些材料，同时不把材料中未载明的状态当作已确认事实。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入依赖 AI Proxy。App 与 Admin 服务都必须设置 AIPROXY_API_ENDPOINT 和非空的 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。AIPROXY_API_ENDPOINT 填写 AI Proxy 服务根地址，不附加 /v1。AIPROXY_API_TOKEN 必须与服务端配置一致且不能为空。

系统至少需要一个语言模型和一个索引模型才能正常使用。模型类型包括语言模型、索引模型、重排模型、语音合成和语音识别。模型 ID 是接口请求 Body 中 model 字段的值，全局唯一。模型名用于展示，可以自定义。

模型状态探测仅针对已启用的系统模型，探测请求首次失败后最多自动重试 3 次，单轮最多尝试 4 次，4 次全部失败才判定为异常。该机制用于观察模型可用性，不改变材料本身的授权状态。

检索与相关度负责找到文本，不负责权限或实体隔离。检索库同向量模型的要求限于该库内部，不能扩展为外部系统也要同模型。跨不同向量模型的库不可共同关联，需要先核标识并排除不符合者。

## 配置怎么定

以下配置项围绕本页主任务，即商品资料与选型问答中的模型接入与配置。表内数值若为假设试验起点，已注明理由。

| 配置项 | 本次假设试验起点 | 说明与比较方法 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设填 `http://aiproxy:3000` | 选此值因文档示例使用该形式且不附加 /v1；与文档要求比较，确认无 /v1 后缀 |
| AIPROXY_API_TOKEN | 假设填非空字符串 | 与 AI Proxy 服务端配置比较，确认一致且非空 |
| 语言模型 | 假设启用一个语言模型 | 与系统至少一个语言模型的要求比较 |
| 索引模型 | 假设启用一个索引模型 | 与系统至少一个索引模型的要求比较 |
| 模型状态探测间隔 | 假设填 30 分钟 | 文档支持 5～60 分钟整数；选 30 作为中间值，与允许范围比较 |
| 告警 Webhook 地址 | 假设填一个 HTTP 地址 | 与文档支持 HTTP/HTTPS 的要求比较，确认可点击测试 |

## 容易做错的三处

1. 把 AIPROXY_API_ENDPOINT 填成完整模型请求地址。文档要求填根地址，不附加 /v1。检查时输入该配置值，比较是否含 /v1 或 /chat/completions，出现即不符。

2. 用应用 API Key 代替 AIPROXY_API_TOKEN。文档要求管理员 Token 且与服务端一致。检查时输入该 Token，与 AI Proxy 服务端配置比较，不一致或为空即不符。

3. 把检索结果当作授权凭证。检索只返回文本，不判定材料是否已批准或已报送。检查时输入一条询问某台账是否已报送的问答，比较回答是否声称已报送；材料未载明报送状态时，回答声称已报送即不符。

## 怎么确认配好了

假设演练样本。材料原文两句：某门店塑料袋采购台账载明，2026 年上半年采购规格为 30cm×50cm 塑料袋共 12000 个，供应商为某包装厂，台账状态为已登记。该门店半年报告载明，同期销售凭证合计 11500 个，报告状态为待报送。拟判定句：该门店 2026 年上半年塑料袋已报送半年报告。

1. 输入上述材料原文与拟判定句，比较拟判定句中的报送状态与材料中报告状态字段。材料载明待报送，拟判定句称已报送，两者在同一主体、同一期间、同一字段上取值互斥，判定为矛盾。

2. 输入上述材料原文与一条询问该门店采购数量的问答，比较回答中的数量与台账载明的 12000 个。回答给出 12000 个且注明来源为台账，判定为有依据；回答给出其他数量或未注明来源，判定为未获支持。

3. 输入一条询问该门店销售凭证数量的问答，比较回答是否引用了销售凭证材料。材料载明 11500 个，回答引用该数字并注明凭证，判定为有依据；回答未引用凭证或给出未载明数字，判定为待核实。

以上三项均为纸面核对，未实际执行。材料未载明的字段保持未知，待报送状态不表示已报送，台账已登记不表示已批准。
