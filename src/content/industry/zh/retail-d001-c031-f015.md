# 商超塑料袋与一次性用品报告的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

该品类围绕一次性塑料制品报告与环保监管展开，资料主体是塑料袋采购台账、销售凭证、半年报告与自律承诺。采购台账与销售凭证通常按日产生，半年报告按半年度归集，自律承诺在特定节点形成文本。这些材料共同支撑商品资料与选型问答：问的是某类塑料袋的采购规格、销售记录、报告口径与承诺范围。

检索与召回面对的是上述材料的文本化内容。采购台账记录供应商、规格、数量与日期；销售凭证记录交易与商品对应关系；半年报告汇总使用量与回收情况；自律承诺记录主体与承诺事项。这些字段是否齐全、是否同一期间、是否同一主体，直接决定问答能否得到可核对的答案。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。不同向量模型的库不可共同关联，需先核标识并排除不符合者，不执行跨模型检索来比较漏召回。搜索模式按测试问题在语义检索、全文检索与混合检索之间比较，不预设一种模式适合全部资料。引用上限以 token 为单位，用长短不同的实际资料测试内容是否完整，再调整上限。最低相关度仅在语义检索或使用结果重排时生效，先标注相关与无关样本再调阈值。问题优化用于指代消除和问题扩展，比较原问题与优化后问题，核对主体是否被改错。

引用内容以数组输出，长度可以为 0，未搜索到内容时输出链路仍走通。检索是召回候选内容的过程，不承担权限或实体隔离。表单收集值，业务核对、审批、数据库写入与外部同步需要各自的下游实现。RRF 是混合结果融合过程，不写成开启开关。图片检索须有相应图像输入及模型能力，重排须具备模型且按设置启用。

假设演练样本：供核对的材料原文为三句。第一句：“2024年上半年，某商超门店采购一次性塑料袋共计十二万只，供应商为甲包装厂，规格为可降解材质。”第二句：“同期该门店塑料袋销售凭证显示，收费塑料袋销售数量为十万只。”第三句：“该门店已签署自律承诺，承诺内容为减少不可降解塑料袋使用。”一条待判定的拟稿句为：“该门店2024年上半年一次性塑料袋采购量与销售量一致，且已完成回收情况报送。”

## 配置怎么定

| 配置或核对项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| 关联知识库 | 仅关联使用同一向量模型的库 | 先核向量模型标识，排除不同模型的库 |
| 搜索模式 | 语义检索与全文检索分别测试 | 与混合检索结果比较，观察同一问题的候选差异 |
| 引用上限 | 起点设为覆盖最长台账片段的 token 值 | 与较短销售凭证片段比较，检查内容是否被截断 |
| 最低相关度 | 起点设为中间值 | 与标注的相关、无关样本比较，观察过滤变化 |
| 问题优化 | 对含指代的问题开启测试 | 与未优化问题比较，核对主体是否被改错 |
| 结果重排 | 在具备重排模型时按设置启用 | 与未重排候选比较，观察排序变化 |

## 容易做错的三处

1. 将不同向量模型的知识库共同关联。输入为两个向量模型标识不同的库，比较其向量模型标识，观察是否被排除。若标识不一致仍被关联，则配置有误。
2. 将最低相关度当作权限或实体过滤。输入为标注的相关与无关样本，比较过滤前后候选，观察无关样本是否因阈值被排除。若把阈值当作业务隔离手段，则理解有误。
3. 将检索或表单当作授权执行。输入为待审核的交接请求，比较请求状态与授权状态，观察是否被当作已批准。待审核不证明缺少操作权限，也不等于已批准。

## 怎么确认配好了

1. 针对假设原文第一句与第二句，输入问题“该门店2024年上半年塑料袋采购量与销售量分别是多少”，比较召回内容是否同时包含采购数量与销售数量，观察引用内容是否完整。若仅召回其中一句，则需检查引用上限与分块。
2. 针对拟稿句“采购量与销售量一致，且已完成回收情况报送”，输入该句作为核对请求，比较原文中采购量、销售量与回收报送三者是否同主体、同期间、同字段。原文未载明回收报送，该部分为未获支持，需记录证据缺口。
3. 针对空结果承接，输入明确的纸面输入空数组，比较下游设计是否按引用内容长度为 0 走通输出链路，观察是否出现中断。不声称虚构规则检索一定返回空数组。
