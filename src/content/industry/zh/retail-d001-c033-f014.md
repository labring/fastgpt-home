# 外汇收结汇与贸易名录的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

外汇收结汇与贸易名录场景的资料围绕外汇资金与贸易背景真实性展开，不审全套信用证单据。日常材料包括收汇水单、贸易合同、发票与外汇业务登记资料，数据来源涉及国家外汇管理局政策、银行网银、企业财务账与海关出口数据。资料更新以每单和每月为主，从业主体为外贸财务、银行客户经理与外汇专员。这些特征决定了商品资料与选型问答的语料必须能承载收汇主体、金额、币种与贸易背景的对应关系，模型接入与配置需要按此核对输入材料与输出边界。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入依赖 AI Proxy。App 与 Admin 服务都必须设置 AIPROXY_API_ENDPOINT 和非空的 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。AIPROXY_API_ENDPOINT 填写 AI Proxy 服务根地址，不附加 /v1。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。系统至少需要一个语言模型和一个索引模型才能正常使用。模型 ID 是接口请求 Body 中 model 字段的值，全局唯一；模型名仅用于展示。模型能力按应用所需输入分别核对，多模态、工具调用与思考配置分别验证。应用参数在应用或节点配置中设置，不能假设兼容对话接口的同名字段会覆盖编排。

假设演练样本：某外贸企业提供三句材料原文供核对。第一句为“2026年3月10日，我司收到境外买方A公司支付的货款美元120,000.00，收汇水单编号HX-2026-0310-07，对应合同号HT-2026-018。”第二句为“合同HT-2026-018约定付款方式为电汇，货物为不锈钢管件，发票号FP-2026-0311。”第三句为“上述水单与合同、发票的收汇主体、金额、币种一致。”待判定的拟稿句为：“该笔收汇已完成结汇并取得外汇业务登记凭证。”判定所需材料为收汇水单、贸易合同与发票，结汇完成与登记凭证的证明材料未提供，该拟稿句属于未获支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 填写 AI Proxy 服务根地址，不附加 /v1 | 与官方要求比较，缺少则启动校验失败 |
| AIPROXY_API_TOKEN | 填写与服务端一致的非空管理员 Token | 与官方要求比较，不能以应用 API Key 代替 |
| 语言模型 | 至少启用一个语言模型 | 与系统要求比较，缺少则无法正常使用 |
| 索引模型 | 至少启用一个索引模型 | 与系统要求比较，缺少则无法正常使用 |
| 模型 ID | 与渠道中模型字段一致 | 与官方说明比较，全局唯一且用于请求 Body |
| 模型能力 | 按应用所需输入分别核对 | 与官方说明比较，多模态与工具调用分别验证 |

## 容易做错的三处

1. 将 AIPROXY_API_ENDPOINT 写成完整模型请求地址并附加 /v1。输入为配置值，比较对象为官方要求的根地址，可观察结果为启动校验是否通过。
2. 用应用 API Key 代替 AIPROXY_API_TOKEN。输入为 Token 值，比较对象为服务端管理员 Token，可观察结果为启动校验是否通过。
3. 把待判定的拟稿句当作已成立事实。输入为样本三句原文与拟稿句，比较对象为结汇完成与登记凭证材料，可观察结果为材料是否载明该状态。

## 怎么确认配好了

1. 输入样本第一句与第二句原文，比较收汇主体、金额、币种与合同号是否一致，一致时满足核对条件，不一致时记录差异。
2. 输入样本第三句与拟稿句，比较结汇完成与登记凭证是否在材料中载明，未载明时记录为未获支持，不判定为已完成。
3. 输入 AIPROXY_API_ENDPOINT 与 AIPROXY_API_TOKEN 配置值，比较是否符合官方要求，两项均符合时启动校验通过，任一项缺失时记录为未通过。
