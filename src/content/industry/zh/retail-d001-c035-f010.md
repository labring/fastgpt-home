# 外贸退运与索赔的商品资料与选型问答：引用来源与溯源

## 这个品类的数据长什么样

退运索赔处理出口后的逆向物流与责任认定，主要材料来自客户邮件、质检报告、海关系统与保险公司理赔系统，日常文档包括退运协议、索赔函、质量报告与退运报关单。每案不定期更新，资料时效直接影响引用是否可用。商品资料与选型问答在这一环节要求回答能逐条回到原文档，检索输出以引用数组形式呈现，长度允许为零。资料版本与知识库标识需要先行核对，相同向量模型的知识库才可共同关联。

## 这些特征在「引用来源与溯源」这一环带来什么约束

检索节点输出引用内容，空数组也走通链路，下游承接需要按数组处理。相似度得分只反映相关度，不承担权限或实体隔离。混合检索经 RRF 融合多路结果，结果重排按设置启用，图片检索需要相应图像输入与模型能力。以下为假设演练样本。

假设演练样本：供核对的材料原文为「2025年3月10日，编号TN-2025-031的退运协议载明：买方于2025年2月20日签收批次B2401，因外观尺寸超差申请整批退运，退运原因待质检报告确认。质检报告QR-2025-118状态为待审核。」待判定拟稿句为「该批次退运原因已确认为质量不合格，索赔函可直接提交。」判断所需主体、对象、状态与有效范围已在原文出现，质检报告处于待审核状态，退运原因未获确认。

## 配置怎么定

| 配置或核对项 | 本页相关设置 | 核对方式 |
| --- | --- | --- |
| 关联的知识库 | 选择一个或多个相同向量模型的知识库 | 核对已选库标识与资料版本，排除不同向量模型者 |
| 搜索模式 | 语义检索、全文检索、混合检索可选 | 按问题类型选择，编号类问题可用全文或混合 |
| 引用上限 | 每次搜索最多引用的 tokens 数量 | 本次假设试验起点设为 3000 tokens，理由为样本材料较短，与默认展示值比较后调整 |
| 最低相关度 | 0-1 数值，仅在语义检索或结果重排时生效 | 本次假设试验起点设为 0.3，与检索结果得分比较 |
| 结果重排 | 需具备重排模型并按设置启用 | 检查模型可用性与启用状态 |
| 引用内容输出 | 数组格式，长度可为 0 | 用纸面输入 `[]` 核对下游承接设计 |

## 容易做错的三处

1. 把待审核质检报告当作已确认结论。输入为样本原文与拟稿句，比较「待审核」与「已确认质量不合格」，出现拟稿句即判定未获支持。
2. 把相似度得分当作权限过滤。输入为最低相关度设置与检索结果，比较得分与授权范围，得分高不表示记录已获授权。
3. 把不同向量模型的知识库共同关联。输入为已选库标识，比较向量模型标识，出现不一致即排除该库并记录。

## 怎么确认配好了

1. 输入样本原文与拟稿句，比较退运原因字段状态，拟稿句被标为未获支持且保留证据缺口，视为符合。
2. 输入纸面 `[]` 作为引用输出，比较下游节点是否继续执行，链路走通且不报错，视为符合。
3. 输入已选知识库标识清单，比较各库向量模型标识，全部一致方可关联，出现不一致即排除并记录实际观察，视为符合。
