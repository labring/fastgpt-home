# 天猫旗舰店日常运营的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

天猫旗舰店的商品资料与选型问答，主要核对材料是商品发布页、品牌授权书、发货承诺记录与售后工单。这些材料按日、按单更新，日常最耗时的环节集中在类目资质校验、48小时发货承诺维护与延迟发货赔付处理。对模型接入与配置而言，材料本身带有明确的授权边界：品牌授权书限定可售商品范围，发货承诺记录限定履约时限，售后工单限定处理状态。模型只能在这些材料已载明的事实内组织问答，检索命中的片段不构成售卖授权或赔付确认。资料更新频率本身不改变接入配置，本页不据此推导批量同步或交易触发机制。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入依赖 AI Proxy。App 与 Admin 侧需设置 AIPROXY_API_ENDPOINT 与非空 AIPROXY_API_TOKEN，端点填写服务根地址，不附加 /v1。系统至少需要一个语言模型和一个索引模型。模型 ID 是请求体中 model 字段的值，全局唯一；模型名仅用于展示。渠道测试、模型测试与模型状态探测分别对应渠道连通、单模型可用与周期性健康检查，三者不互相替代。模型状态探测仅覆盖已启用模型，首次失败后最多重试 3 次，4 次全部失败才判定异常。检索用于找出与问题相关的文本块，相关度得分不承担主体、类目或授权过滤职责。跨不同向量模型的库不可共同关联，核对时先比对模型标识，排除标识不一致的库，再记录实际观察。

## 配置怎么定

以下为假设演练样本，用于说明配置核对方式，不代表任何真实店铺或真实测试。

样本材料原文（假设）：某天猫旗舰店商品发布页载明“本店为A品牌旗舰店，在售商品以页面SKU为准”；品牌授权书载明“授权期限2026年1月1日至2026年12月31日，授权范围限A品牌家用电器类目”；发货承诺记录载明“付款后48小时内发出”。待判定拟稿句：“本店A品牌全部商品均可在2026年12月31日前下单并保证48小时发货。”

| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设填 `http://aiproxy:3000` | 文档要求根地址，与附加 /v1 的写法比较 |
| AIPROXY_API_TOKEN | 假设填非空管理员 Token | 文档要求非空且与服务端一致，与应用 API Key 比较 |
| 语言模型 | 假设启用一个语言模型 | 满足系统最低要求，与未启用状态比较 |
| 索引模型 | 假设启用一个索引模型 | 满足系统最低要求，与未启用状态比较 |
| 模型状态探测间隔 | 假设填 15 分钟 | 文档允许 5～60 分钟整数，与范围外取值比较 |
| 模型测试 | 假设对渠道执行模型测试 | 核对渠道连通，与未执行测试的状态比较 |

## 容易做错的三处

1. 把检索命中的商品片段当作售卖授权。输入是拟稿句与检索结果，比较对象是品牌授权书载明的类目与期限，观察结果是拟稿句是否超出授权范围。
2. 把模型测试通过当作业务授权完成。输入是渠道测试结果，比较对象是商品发布页与授权书，观察结果是测试通过是否被用来支撑可售结论。
3. 把待审核的售后工单当作已处理完成。输入是工单状态字段，比较对象是工单是否载明处理完成，观察结果是拟稿句是否把待审核写成已解决。

## 怎么确认配好了

1. 输入假设样本中的三句材料原文与拟稿句，比较拟稿句“全部商品”与授权书“限A品牌家用电器类目”，观察拟稿句是否收窄到授权类目与期限内；未收窄即不满足。
2. 输入假设样本中的发货承诺记录“付款后48小时内发出”，比较拟稿句“保证48小时发货”，观察两者是否为同一承诺表述；拟稿句加入记录未载明的保证语气即不满足。
3. 输入假设样本中的售后工单状态，比较工单是否载明处理完成，观察拟稿句是否把未载明完成状态的工单写成已完成；未载明即记录为待核实。检索空结果可用明确的纸面输入 `[]` 核对下游设计，不表示虚构规则检索一定返回空。
