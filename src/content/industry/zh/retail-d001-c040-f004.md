# 客服咨询知识库维护的商品资料与选型问答：向量模型与索引

## 这个品类的数据长什么样

商品资料与选型问答的资料来自客服系统、商品详情页、售后问题统计与质检抽查，日常处理 FAQ 条目、话术模板、商品参数表和升级工单。资料更新按周或按月推进，汇总高频问题、改写标准答复、同步新品参数是主要耗时环节。知识库维护属于前置问答资料整理，不直接审批退款，出错表现为答非所问、投诉升级或客服培训失败。

商品参数表常含型号、编号与专有名词，选型问答则依赖自然语言描述使用场景。向量模型与索引这一环需要同时面对两类输入：精确编号适合全文检索路径，场景描述适合语义检索路径。资料原文的完整性、长度与多样性直接影响召回质量，检索词质量与数据质量需要一起核对。

## 这些特征在「向量模型与索引」这一环带来什么约束

关联检索的知识库须使用相同向量模型，先核对实际模型与输入类型。一个原数据块可以关联多个索引，索引与原文内容分别核对。索引内容应完整且聚焦，检索覆盖范围与索引长度需结合样本权衡，为同一数据块增加多组索引可提高命中机会，也会扩大向量数量。

图片检索还取决于入库时是否生成图片描述索引或图片向量索引，查询端上传图片不足以让图片被检索到。文档给出的检索流程包含问题优化、语义检索、全文检索、混合检索、RRF 融合、ReRank 二次排序、相似度过滤与引用上限裁剪，这些路径按输入内容与搜索参数组合，不表示每次请求全部执行。引用上限以 tokens 为单位，最低相关度仅在语义检索或使用结果重排时生效，且是过滤阈值，不是最终排序规则。语义召回与相关度不承担权限或实体隔离功能，检索本身不构成授权。

假设演练样本：某客服知识库运营整理一份商品参数表，原文为“型号 X200 无线吸尘器，额定功率 120W，续航 40 分钟，适用于 60 平方米以内户型。滤网型号 F-200，建议每三个月更换。”待判定拟稿句为“X200 续航 40 分钟，适合大户型使用。”核对范围限于上述原文与拟稿句，不涉及真实客户或真实公司。

## 配置怎么定

下表围绕上述样本列出与本功能、主任务相关的已说明设置或实施核对项。数值仅作为本次假设试验起点，用于与样本实际字段比较，不表示官方默认值。

| 配置项 | 本页设定或核对内容 | 与样本的关系 |
| --- | --- | --- |
| 向量模型 | 核对关联知识库是否使用相同向量模型 | 样本所在库与其他库模型标识一致才可共同关联 |
| 索引内容 | 为参数表建立完整且聚焦的索引文本 | 索引须覆盖型号、功率、续航、适用面积等字段 |
| 多向量映射 | 一个原数据块可关联多个索引 | 参数表较长时可拆分多组索引，分别核对原文 |
| 搜索模式 | 语义检索、全文检索或混合检索 | 型号与滤网编号适合全文检索，场景描述适合语义检索 |
| 引用上限 | 以 tokens 为单位的引用内容上限 | 本次假设试验起点设为 2000 tokens，与样本参数表长度比较后调整 |
| 最低相关度 | 0 至 1 数值，仅在语义检索或结果重排时生效 | 本次假设试验起点设为 0.3，与样本召回结果比较后调整 |

引用上限与最低相关度的假设起点需说明选择理由：样本参数表约数百字，2000 tokens 可容纳多段引用；0.3 用于观察过滤前后候选差异。两者均为本次试验起点，不是官方默认值。

## 容易做错的三处

1. 将查询端上传图片当作图片已被检索到。错误输入为仅上传一张商品图片并期望命中知识库图片；比较对象是入库时是否生成图片描述索引或图片向量索引；可观察结果是引用内容为空或仅返回文本片段。文档说明图片能否被检索到取决于入库时是否建立对应索引。
2. 将最低相关度当作权限或实体过滤器。错误输入为设置最低相关度后期望排除其他业务线的资料；比较对象是召回结果是否仍包含无关业务内容；可观察结果是无关内容仍出现在候选中。文档说明最低相关度是过滤阈值，不承担权限隔离。
3. 将不同向量模型的知识库共同关联。错误输入为选择两个模型标识不同的知识库；比较对象是节点要求相同向量模型；可观察结果是配置核对阶段即可发现标识不一致，应排除不符合者并记录，不执行跨模型检索来比较漏召回。

## 怎么确认配好了

1. 针对假设样本原文与拟稿句，输入拟稿句“X200 续航 40 分钟，适合大户型使用。”，比较拟稿句与原文中“适用于 60 平方米以内户型”这一字段。原文未支持“大户型”，可观察结果为拟稿句未获原文支持，需改写或补充依据。
2. 针对样本参数表中的型号与滤网编号，输入“F-200 滤网更换周期”，比较全文检索路径是否命中“建议每三个月更换”。可观察结果为引用内容包含该句时满足条件；若未命中，记录该次观察，不推断必然原因。
3. 针对空结果承接，使用明确的纸面输入 `[]` 核对下游设计，比较下游节点是否按引用内容长度为 0 继续执行。文档说明即使没有搜索到内容，输出链路也会走通。可观察结果为下游未因空数组中断时满足条件；不声称虚构规则检索一定返回 `[]`。
