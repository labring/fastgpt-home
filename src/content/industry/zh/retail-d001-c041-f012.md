# 平台促销报名与价格管理的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

促销报名场景的核心资料是活动报名表、促销价审批单、库存锁定表和活动复盘表。这四类文档共同承载价格、库存与活动节奏，宣传用语审查不属于本页任务。报名表与审批单里同一商品的价格字段往往同时出现多个取值：报名价、活动价、最低到手价，三者分属不同字段，只有在同一字段出现互斥取值时才能判定为矛盾。库存锁定表记录锁定数量与锁定范围，复盘表记录活动结束后的实际结果。资料按周或每场活动更新，更新后需核对实际训练与索引状态，上传成功不等于检索已更新。从业主体包括平台活动运营、品牌销售计划和财务BP，检索得到的候选内容只用于回答，不构成报名、审批或库存锁定授权。

## 这些特征在「文档解析与分块」这一环带来什么约束

价格字段与库存字段常以表格、条件说明和附注形式出现，分块时若把条件句与所约束的价格拆开，检索到的片段会缺失生效范围。FastGPT 的知识库由库、集合和数据组成，最小搜索单位是库，集合仅用于分类管理，与搜索效果无关。向量存储在 PostgresSQL 的 vector 字段，索引为 HNSW，MongoDB 的 dataset.datas 表保存原数据并提供 indexes 字段记录向量 ID，一组数据可对应多个向量。检索时先召回向量，再按向量 ID 回 MongoDB 寻找原数据，命中同一组原数据则合并，向量得分取最高得分。语义检索依赖向量距离，全文检索依赖关键词命中，混合检索通过 RRF 融合两路结果，重排用 ReRank 模型对候选文本二次排序并给出 0-1 得分。最低相关度仅过滤阈值，在语义检索或启用结果重排时生效，它不承担权限或实体隔离功能。检索库与向量模型需同源关联，跨不同向量模型的库不可共同关联，此时只核标识并排除不符合者，记录实际观察，不推断运行结果。

## 配置怎么定

下表围绕本页样本，列出官方已说明的设置或实施核对项。数值为本次假设试验起点，用于与样本检索现象比较，并非官方默认值。

| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| 搜索模式 | 混合检索 | 样本含编号类字段与自然语言问法，需同时考察语义召回与全文命中，与单独语义检索的返回集合比较 |
| 最低相关度 | 0.3 | 起点用于观察低分片段是否被过滤，与 0.5 的返回条数和内容范围比较 |
| 引用上限 | 按 tokens 计，起点 2000 | 混合库中 chunk 长度差异大，用 tokens 控制引用量，与 1000 时的引用完整度比较 |
| 问题优化 | 关闭 | 样本问题主体明确，避免额外模型调用增加耗时，与开启后的耗时和召回差异比较 |
| 结果重排 | 启用 | 候选较多时用 ReRank 得分二次排序，与不启用时的排序位置比较 |
| 索引核对 | 核对 indexes 字段与原数据对应关系 | 确认入库时是否生成有效索引，与仅查看上传状态的判断方式比较 |

## 容易做错的三处

1. 把报名价、活动价、最低到手价三个不同字段的取值当作同一字段的矛盾。检查方式：输入样本原文，比较三个字段名称与其各自取值，观察是否存在同字段互斥取值；字段不同则记录为未获支持。
2. 把上传成功当作检索已更新。检查方式：输入更新后的资料与一条术语检索词，比较检索返回内容与更新后原文，观察返回是否仍为旧版本；未训练或索引未更新时记录缺口。
3. 把语义检索或最低相关度当作权限过滤。检查方式：输入一条涉及未授权范围的检索词，比较返回候选与访问权限清单，观察返回内容是否包含无权访问的记录；检索本身不执行授权判定，需另接系统实现。

## 怎么确认配好了

以下验证使用假设演练样本。样本原文为：「活动编号 A-2025-0317，商品甲，报名价 199 元，活动价 189 元，最低到手价 179 元，价格有效范围 2025-03-17 至 2025-03-20。库存锁定数量 500 件，锁定范围仅限华东仓。」待判定拟稿句为：「商品甲本次活动最低到手价 179 元，有效期至 2025-03-20。」该句主体、对象与字段均取自原文，判定为在原文范围内获支持，但有效期表述将价格有效范围收窄为单一截止日，需与原文起止范围比较后记录差异。

1. 输入样本原文与拟稿句，比较拟稿句中的价格字段名称、取值与原文对应字段，观察三者是否同主体、同期间、同一字段；字段一致且取值相同则满足条件，字段被替换或期间被改写则记录未获支持。
2. 输入一条纸面空结果 [] 与下游引用拼接设计，比较空结果进入引用环节后的输出，观察下游是否按空集合处理；输出为空或明确提示无引用则满足条件，输出其他内容则记录缺口。
3. 输入跨库标识清单，比较各库绑定的向量模型标识，观察是否存在同源关联；标识一致则记录可关联，标识不一致则排除并记录实际观察，不执行跨模型检索比较漏召回。
