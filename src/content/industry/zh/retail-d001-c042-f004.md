# 平台商品标题与详情合规的商品资料与选型问答：向量模型与索引

## 这个品类的数据长什么样
平台商品标题与详情合规处理宣传真实性与资质展示，不处理包裹交付。主要材料包括商品标题表、详情页素材、广告禁词清单、质检报告，来源为平台规则中心、广告法合规清单、品牌素材库与质检机构报告。日常最耗时的环节是核查极限词、比对实物参数、替换违规素材，出错后果为商品下架、投诉举报与行政处罚风险。资料更新频率为周与每次上新。这些材料在商品资料与选型问答中需要被检索、引用并交给人工核对，因此向量模型与索引的配置直接影响引用内容能否覆盖标题、素材、禁词与报告四类文档。

## 这些特征在「向量模型与索引」这一环带来什么约束
知识库搜索由库、集合与数据三部分组成，最小搜索单位是库，集合仅用于分类管理。FastGPT 采用 PostgresSQL 的 PG Vector 插件作为向量检索器，索引为 HNSW，MongoDB 用于其他数据存取。dataset.datas 表存储向量原数据，indexes 字段记录对应的向量 ID，一组数据可以对应多个向量。检索时先召回向量，再按向量 ID 去 MongoDB 寻找原数据，同一组原数据被多路命中则合并，向量得分取最高分。关联检索的知识库须使用相同向量模型，先核实际模型与输入类型。索引内容要求完整且聚焦，检索覆盖与索引长度需结合样本权衡。图片检索还取决于入库时是否生成图片描述或图片向量，不能只看查询端。混合检索通过 RRF 合并语义与全文结果，结果重排使用 ReRank 模型二次排序，最低相关度仅在语义检索或使用结果重排时生效。检索与相似度不承担权限或实体隔离功能。

假设演练样本：某平台店铺运营人员提交一份商品资料核对请求，材料原文为三句。第一句：“商品标题为‘家用静音破壁机 大容量’。”第二句：“详情页素材标注‘全网最低价，绝对静音’。”第三句：“广告禁词清单列明‘最低价’‘绝对’属于禁用表述，质检报告编号 QC-2024-0871 显示噪音实测 78 分贝。”待判定拟稿句为：“该商品标题与详情页素材均符合平台合规要求，可直接上架。”请求状态为待合规审核，尚未获得任何签署或批准。

## 配置怎么定
配置围绕上述样本，只列官方已说明的设置或实施核对项。数值为本次假设试验起点，用于与样本内实际值比较，不作为官方默认值。

| 配置项 | 本次假设起点 | 选择理由与比较对象 |
| --- | --- | --- |
| 关联知识库 | 商品标题表、详情页素材、广告禁词清单、质检报告四个库 | 四类材料均属本任务检索范围，须确认使用相同向量模型 |
| 搜索模式 | 混合检索 | 禁词与报告编号属精确查询，标题与素材属语义查询，用 RRF 合并两路结果 |
| 最低相关度 | 假设起点 0.35 | 与样本中禁词命中片段的语义得分比较，低于该值的结果不进入引用 |
| 引用上限 | 假设起点 2000 tokens | 样本四类材料片段合计长度约在此范围，与返回引用总长度比较 |
| 结果重排 | 启用 ReRank | 候选片段来自四个库，用重排得分二次排序后按得分过滤 |
| 问题优化 | 启用 | 拟稿句含指代与合规判断意图，先做指代消除与问题扩展再检索 |

## 容易做错的三处
1. 把向量相似度当作合规判定依据。错误表现：检索到“绝对静音”片段后直接输出“符合要求”。输入为上述禁词清单原文与拟稿句，比较对象为禁词清单中“绝对”是否属于禁用表述，观察结果为检索片段与拟稿句是否同时出现该词。相似度分数不承担合规判断，需人工比对禁词清单。
2. 跨不同向量模型的库共同关联。错误表现：将使用不同向量模型的知识库一并选入同一次检索。输入为四个库的模型标识，比较对象为各库声明的向量模型是否一致，观察结果为标识不一致的库被排除并记录，不执行跨模型检索比较。
3. 把待审核请求当作已批准。错误表现：拟稿句处于待合规审核状态，却输出“可直接上架”。输入为请求状态字段与拟稿句，比较对象为是否存在签署或批准记录，观察结果为仅有待审核状态时判定为未获支持，保留证据缺口。

## 怎么确认配好了
1. 输入上述假设样本的材料原文三句与拟稿句，比较对象为禁词清单中“最低价”“绝对”的禁用表述与拟稿句中对应词，观察结果为检索引用同时覆盖禁词清单片段与详情页素材片段，且不输出合规结论。预期为引用内容完整呈现，合规判定留给人工。
2. 输入四个库的模型标识，比较对象为各库声明的向量模型是否一致，观察结果为标识一致的库进入检索，标识不一致的库被排除并记录。预期为不执行跨模型检索比较，不据此推断漏召回或冗余。
3. 输入请求状态字段，比较对象为是否存在签署、批准或合同生效记录，观察结果为仅有待审核状态时判定为未获支持。预期为不补造授权或生效条款，明确保留证据缺口。若检索返回空结果，可用明确的纸面输入 [] 核对下游设计，不声称虚构规则检索一定返回空数组。
