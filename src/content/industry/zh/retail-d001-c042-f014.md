# 平台商品标题与详情合规的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样
平台商品标题与详情合规处理宣传真实性和资质展示，不涉及包裹交付。主要数据来源是平台规则中心、广告法合规清单、品牌素材库和质检机构报告，日常文档包括商品标题表、详情页素材、广告禁词清单和质检报告。资料更新频率为周和每次上新，本页不据此推导批量同步或交易触发机制。本任务中，商品资料与选型问答需要把标题表、素材、禁词清单和质检报告作为知识来源接入，由模型按检索结果回答运营人员关于某项表述是否可用的提问。模型接入与配置决定这些文档能否被正确索引、检索和引用。

## 这些特征在「模型接入与配置」这一环带来什么约束
从 V4.17.0 起，AI Proxy 为必需依赖，App 和复用 App/Service 配置的 Admin 服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空的 `AIPROXY_API_TOKEN`。`AIPROXY_API_ENDPOINT` 填写 AI Proxy 服务根地址，不附加 `/v1`；`AIPROXY_API_TOKEN` 为管理员 Token，不能以应用 API Key 代替。系统至少需要一个语言模型和一个索引模型才能正常使用。索引模型负责对文本块建立索引供相关文本检索，语言模型负责对话回答。模型能力按应用所需输入核对，多模态、工具调用及思考配置分别验证。应用参数在应用或节点配置中设置，不能假设兼容对话接口的同名字段会覆盖编排。

假设演练样本：某次内部演练使用一份虚构的《商品标题表》片段，原文为“商品编号 A-001，标题拟用‘全网最低价’，详情页素材引用质检报告 Q-2026-001，广告禁词清单版本为 V3。”另有一条待判定拟稿句：“A-001 标题可使用‘全网最低价’，因质检报告 Q-2026-001 已确认价格优势。”该拟稿句将质检报告与价格表述建立关联，需核对禁词清单 V3 是否收录“最低价”以及质检报告 Q-2026-001 是否覆盖价格结论。

## 配置怎么定
以下配置项与实施核对项围绕本页样本，数值为本次假设试验起点并说明比较对象。

| 配置项 | 本次假设起点 | 说明与比较方法 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | `http://aiproxy:3000` | 假设起点，因文档示例使用该形式；与是否误加 `/v1` 的写法比较，确认根地址。 |
| `AIPROXY_API_TOKEN` | 非空管理员 Token | 文档要求非空且与服务端一致；与应用 API Key 比较，确认未混用。 |
| 索引模型 | 启用一个索引模型 | 文档要求至少一个索引模型；与语言模型数量比较，确认两类均存在。 |
| 语言模型 | 启用一个语言模型 | 文档要求至少一个语言模型；与索引模型比较，确认两类均存在。 |
| `VECTOR_MAX_PROCESS` | `10` | 文档默认值；与 `QA_MAX_PROCESS` 等队列并发比较，确认解析队列可支撑文档量。 |
| 模型能力核对 | 按需勾选 vision、toolChoice | 文档列出字段；与样本是否含图片或工具调用比较，确认能力匹配。 |

## 容易做错的三处
1. 把 `AIPROXY_API_ENDPOINT` 写成带 `/v1` 或 `/chat/completions` 的完整请求地址。检查时输入该变量值与文档要求比较，出现附加路径即不满足。
2. 用应用 API Key 填入 `AIPROXY_API_TOKEN`。检查时输入该变量值与“管理员 Token”字段说明比较，出现应用 Key 特征即不满足。
3. 只启用语言模型而未启用索引模型。检查时输入已启用模型列表与“至少一个语言模型和一个索引模型”要求比较，缺少索引模型即不满足。

## 怎么确认配好了
1. 输入假设样本原文与拟稿句，比较检索结果是否引用禁词清单 V3 和质检报告 Q-2026-001 的对应字段。若检索结果未返回禁词清单中“最低价”条目，或未返回质检报告覆盖范围说明，则记录为证据缺口，不判定拟稿句可用。
2. 输入 `AIPROXY_API_ENDPOINT` 变量值与文档示例比较。若该值以 `/v1` 结尾，则不满足根地址要求；若为纯根地址，则通过该项检查。
3. 输入已启用模型列表与“至少一个语言模型和一个索引模型”要求比较。若两类模型均存在，则通过；若缺少任一类，则记录为未满足。

检索与相关度不承担权限或实体隔离，检索库同向量模型要求不扩展至外部系统。空结果以纸面输入 `[]` 核对下游设计，不声称虚构规则检索必然返回空。跨不同向量模型的库先核标识并排除不符者，不执行跨模型检索比较漏召回。待审核不证明缺少操作权限，报价有效期不表示供货期限。
