# 平台商品标题与详情合规的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

标题详情合规处理宣传真实性和资质展示，不处理包裹交付。主要材料来自平台规则中心、广告法合规清单、品牌素材库、质检机构报告，日常文档包括商品标题表、详情页素材、广告禁词清单、质检报告。最耗时的环节是核查极限词、比对实物参数、替换违规素材。资料更新频率为周和每次上新，本页功能不依赖同步节奏，故不展开。这些材料决定检索库应以文本语义为主，编号、型号、检测项目名称需要精确命中。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库，跨向量模型的库不可共同关联。向量搜索采用 topk 召回，语义检索依赖向量距离，全文检索依赖关键词命中，混合检索通过 RRF 融合两路结果。引用上限以 token 为单位，最低相关度仅在语义检索或使用结果重排时生效。问题优化用于指代消除和问题扩展，会额外调用模型。图片检索需要图像输入与相应模型能力，重排需要模型并按设置启用，两者属于可选路径，不代表每次请求全部执行。检索结果不承担权限或实体隔离职责。

假设演练样本。材料原文一：某型号电饭煲详情页标注“额定容量 3L，额定功率 500W”。材料原文二：广告禁词清单载明“绝对化用语不得用于商品标题”。材料原文三：质检报告载明“样品名称：电饭煲，检测项目：输入功率，结论：合格”。待判定拟稿句：“该电饭煲标题使用‘全网最省电’表述，详情页参数与质检报告一致，可提交上架审核。”判定要点：拟稿句的主体为同一商品，字段为标题用语与详情参数；禁词清单针对标题，报告针对输入功率，两者字段不同，不能互相支持或否定。上架审核是否获批属于待核实状态，检索命中不构成授权。

## 配置怎么定

| 配置项 | 本页取值或核对项 | 依据与说明 |
| --- | --- | --- |
| 关联知识库 | 选择同一向量模型的标题详情合规库 | 节点要求相同向量模型，跨模型先核标识并排除 |
| 搜索模式 | 按测试问题分别比较语义、全文、混合 | 编号型号类问题用全文或混合，自然语言问法用语义或混合 |
| 引用上限 | 假设试验起点 3000 tokens | 该值仅为本次纸面比较起点，与 1500 和 6000 对比内容完整性后调整 |
| 最低相关度 | 先标注相关与无关样本再设阈值 | 仅在语义检索或结果重排时生效 |
| 问题优化 | 多轮追问、短问题场景开启 | 核对优化后问题主体是否被改错 |
| 重排 | 具备模型且按设置启用时使用 | 重排得分 0-1，可据此过滤 |

## 容易做错的三处

1. 把检索命中当作上架授权。输入拟稿句后系统返回禁词清单条目，比较动作是核对返回内容是否包含授权结论，观察结果是仅返回规则文本、无审批状态，此时上架审核仍为待核实。
2. 跨向量模型强行关联。输入两个不同向量模型的知识库标识，比较动作是核对模型标识是否一致，观察结果是标识不符即排除，不执行跨模型检索来比较漏召回。
3. 用不同字段互相否定。输入详情页功率参数与质检报告输入功率结论，比较动作是核对主体、期间、字段是否同一，观察结果是字段不同，只能记录为未获支持，不判定为矛盾。

## 怎么确认配好了

1. 输入材料原文一与拟稿句，比较详情页参数与拟稿句所述参数是否同主体同字段，观察结果为参数一致时该部分获支持，标题用语部分仍回到禁词清单单独核对。
2. 输入材料原文二，比较标题用语是否落入禁词清单范围，观察结果为命中绝对化用语时该表述未获支持，未命中时记录为待核实，不推断可上架。
3. 输入空引用数组，比较下游节点是否按长度为 0 的引用链路继续执行，观察结果为链路走通即符合文档描述，不声称虚构规则检索必然返回空数组。
