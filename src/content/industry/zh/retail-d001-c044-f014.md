# 平台广告投放与站内流量的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

平台广告投放与站内流量品类中，投放专员与代运营投手日常处理的文档包括投放计划、关键词报表、人群包说明与转化归因表，数据来源涉及巨量千川、京东快车、阿里妈妈及店铺成交数据。这些材料按日或按小时更新，选型问答需要围绕这些文档做模型接入与配置。该品类按流量和转化实时调价，审核环节相对薄弱，配置错误会直接体现为广告费浪费与ROI失真。模型接入与配置的任务是让问答系统能正确读取并回答商品资料与选型问题，不构造无依据的业务功能。

## 这些特征在「模型接入与配置」这一环带来什么约束

FastGPT v4.17.2 中，AI Proxy 为必需依赖，App 与 Admin 服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空的 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。模型渠道配置中，代理地址填写 `BaseUrl`，不填完整的模型请求地址。模型 ID 是接口请求 Body 中 `model` 字段的值，全局唯一。模型状态探测仅针对已启用的系统模型，探测失败后最多自动重试 3 次，只有 4 次尝试全部失败才判定为异常。检索与相关度不负责权限或实体隔离，跨不同向量模型的库不可共同关联。

## 配置怎么定

以下配置项围绕本页样本的核对需求列出，均为官方文档已说明的设置或实施核对项。

| 配置项 | 设置或核对内容 | 与本页样本的关系 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填写 AI Proxy 服务根地址，不附加 `/v1` | 样本问答请求须经 AI Proxy 转发至模型 |
| `AIPROXY_API_TOKEN` | 填写与服务端一致的非空管理员 Token | 不能用应用 API Key 代替 |
| 模型渠道代理地址 | 填写 `BaseUrl`，不填完整模型请求地址 | 样本中投放计划相关问答依赖该渠道 |
| 模型 ID 与模型映射 | 模型 ID 全局唯一，映射将 FastGPT 请求的模型映射到上游实际模型 | 样本中商品资料问答请求的 `model` 字段须与配置一致 |
| 模型状态探测 | 仅针对已启用模型，失败后最多重试 3 次，4 次全失败判定异常 | 样本中渠道可用性核对应参考探测状态 |
| 向量库全文检索 | Milvus 走 BM25，其他向量库走 MongoDB `$text` | 样本中商品资料检索路径取决于向量库类型 |

假设演练样本：某投放专员在 2026 年 10 月 12 日交接一份关键词报表，报表原文为“计划 A 在 10 月 11 日消耗 3200 元，转化 48 单，ROI 为 2.1；计划 B 同日消耗 1800 元，转化 12 单，ROI 为 0.9”。待判定的拟稿句为“计划 B 的 ROI 低于计划 A，建议暂停计划 B”。该请求处于待审核状态，尚未获得投放主管的批准。

## 容易做错的三处

1. 将 `AIPROXY_API_ENDPOINT` 填写为包含 `/v1` 或 `/chat/completions` 的完整请求地址。核对输入为环境变量配置值，比较对象为文档所述“服务根地址，不要附加 `/v1`”，若配置值包含 `/v1` 则不符合要求。
2. 将模型状态探测的重试机制理解为单次失败即判定异常。核对输入为探测配置与探测结果记录，比较对象为文档所述“首次失败后最多自动重试 3 次，4 次全部失败才判定异常”，若在仅 1 次失败后即标记异常则不符合要求。
3. 将检索相关度分数当作权限或实体过滤依据。核对输入为检索请求与返回结果，比较对象为文档所述检索与相关度不负责权限或实体隔离，若依据相似度分数排除未授权记录则不符合要求。

## 怎么确认配好了

1. 核对 `AIPROXY_API_ENDPOINT` 与 `AIPROXY_API_TOKEN` 是否均已设置且非空。输入为环境变量配置值，比较对象为文档所述两项均为必填且缺少任一项会导致启动校验失败，若两项均存在且 Token 非空则满足条件。
2. 核对模型渠道的代理地址是否填写为 `BaseUrl` 且不包含完整请求路径。输入为渠道配置中的代理地址字段，比较对象为文档所述“填写 `BaseUrl`，注意是否需要增加 `/v1`”，若地址为根地址形式则满足条件。
3. 核对样本中拟稿句“计划 B 的 ROI 低于计划 A”是否与报表原文一致。输入为拟稿句与报表原文，比较对象为原文中计划 B 的 ROI 为 0.9、计划 A 的 ROI 为 2.1，若 0.9 小于 2.1 则数值比较成立；拟稿句中“建议暂停计划 B”属于业务建议，该请求处于待审核状态，不构成已批准或已执行的暂停操作。
