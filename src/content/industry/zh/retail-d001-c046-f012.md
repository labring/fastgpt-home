# 平台类目资质准入的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

平台类目资质准入发生在店铺上架或入驻之前，核心材料是主体资质与授权链。日常处理的文档包括营业执照、商标注册证、品牌授权链和行业许可证。这些材料来自平台招商页面、国家企业信用信息公示系统、商标局数据和许可证系统，更新不定期，每次入驻时重新收集。资质准入的出错后果是入驻驳回、类目无法发布或保证金占用，因此文档解析与分块的质量直接影响后续检索能否定位到正确的资质条款。

## 这些特征在「文档解析与分块」这一环带来什么约束

资质文档的结构差异明显：营业执照包含统一社会信用代码与经营范围，商标注册证包含注册号与核定使用商品类别，品牌授权链包含授权方、被授权方、授权期限与授权范围，行业许可证包含许可项目与有效期。分块时需要保留这些字段与所约束内容之间的完整关系，避免将授权期限与授权范围拆到不同段落。

假设演练样本：某份品牌授权链文件原文为“授权方甲，被授权方乙，授权期限自二〇二四年一月一日起至二〇二五年十二月三十一日止。授权范围限于第25类服装商品。本授权未经授权方书面同意不得转授权。”待判定拟稿句为“乙可在第25类服装商品上转授权给丙。”核对时比较原文“不得转授权”与拟稿句“可转授权”，两者在同一授权范围与同一期限内对同一字段给出互斥取值。

## 配置怎么定

| 配置项 | 本页相关设置或核对项 | 与样本的关系 |
| --- | --- | --- |
| 分段方式 | 按资质文档的字段结构分段，保持授权方、被授权方、期限、范围同段 | 样本中授权期限与范围需同段保留 |
| 索引数量 | 同一组数据可对应多个索引，indexes 字段记录向量 ID 数组 | 样本可对授权范围单独建索引 |
| 引用上限 | 每次搜索最多引用 n 个 tokens 的内容 | 本次假设试验起点设为 2000 tokens，因样本授权链全文约 1500 字，需留余量；与 1000 tokens 比较观察是否截断 |
| 最低相关度 | 0-1 数值，仅在语义检索或结果重排时生效 | 本次假设试验起点设为 0.3，与 0.5 比较观察召回变化 |
| 搜索模式 | 语义检索、全文检索或混合检索，混合检索经 RRF 融合 | 样本中“第25类”属编号类查询，适合全文或混合检索 |
| 问题优化 | 检索前进行指代消除与问题扩展 | 样本问题若含“该授权”需开启以补全主体 |

## 容易做错的三处

1. 将授权期限与授权范围拆到不同分块，检索时只召回期限段而遗漏范围段，导致拟稿句核对时缺少完整约束条件。检查方式：输入样本原文，比较解析后的分块是否包含授权方、被授权方、期限、范围四项，观察四项是否出现在同一数据组。
2. 将上传成功当作检索已更新，资料变更后未核对实际训练与索引状态。检查方式：输入变更后的授权链文本，比较检索结果是否返回新文本，观察返回内容与上传内容是否一致。
3. 将检索结果当作授权执行依据，拟稿句“可转授权”被直接采信。检查方式：输入拟稿句与原文，比较原文“不得转授权”与拟稿句“可转授权”在同一字段上的取值，观察两者是否互斥。

## 怎么确认配好了

1. 输入样本原文与拟稿句，比较原文“不得转授权”与拟稿句“可转授权”，观察是否识别为同一授权范围、同一期限内的互斥取值。若分块后两项约束未同段保留，则无法完成该比较。
2. 输入样本中的“第25类”编号，分别使用全文检索与语义检索，比较两种模式下返回的候选内容，观察全文检索是否命中含“第25类”的分块。若返回结果为空，记录空结果并核对下游设计，不推断原因。
3. 输入一份未载明授权期限的授权链文本，比较检索结果是否包含期限字段，观察返回内容是否缺少该字段。缺少时记录为未获支持，不判定为否定或冲突。
