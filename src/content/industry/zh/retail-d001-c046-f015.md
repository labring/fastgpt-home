# 平台类目资质准入的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

平台类目资质准入发生在商品上架或店铺入驻之前，核心材料是营业执照、商标注册证、品牌授权链与行业许可证。这些材料通常由招商运营、店铺入驻专员或品牌方渠道经理收集，来源包括平台招商页面、国家企业信用信息公示系统、商标局数据与许可证系统。资料更新不定期，每次入驻时重新提交。

对知识库检索与召回而言，这批材料的共同特点是：主体名称、证件编号、有效期限、授权层级与经营范围字段密集，问答往往围绕“某主体是否持有某证件”“某授权链是否覆盖某类目”展开。检索结果需要能定位到具体材料原文，供人工核对，检索本身不判定资质是否成立。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库，跨不同向量模型的库不可共同关联。检索是整个库级别的搜索，集合只用于分类管理，与搜索效果无关。一次检索会按输入内容和搜索参数组合问题优化、语义检索、全文检索或混合检索、图片检索与重排，最终经相似度过滤和引用上限裁剪得到引用内容。引用内容以数组输出，长度可以为 0，没有搜索到内容时输出链路仍走通。

语义检索依赖向量距离，全文检索依赖关键词命中，混合检索通过 RRF 融合两路结果。RRF 是结果融合过程，不是可开启的独立开关。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值，不承担权限或实体隔离功能。检索到某条材料，不代表该材料对应的资质已获批准或授权已生效。

假设演练样本：知识库中一份材料原文为：“授权方：甲品牌管理有限公司；被授权方：乙商贸有限公司；授权品牌：星野；授权类目：家用电器；授权期限：2025年1月1日至2025年12月31日。”另一份营业执照原文为：“名称：乙商贸有限公司；统一社会信用代码：91XXXXXXXXXXXXXX；经营范围：家用电器销售。”一条待判定拟稿句为：“乙商贸有限公司已获得星野品牌家用电器类目授权，授权有效期至2025年12月31日。”核对时比较拟稿句的主体、品牌、类目、期限与授权材料原文是否一致，营业执照仅支持主体存在与经营范围，不证明授权关系。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联存放资质材料原文的同一向量模型库 | 先核对各库向量模型标识，排除标识不同者，再决定关联范围 |
| 搜索模式 | 先用混合检索 | 材料含证件编号与自然语言描述，比较语义、全文、混合三种模式对同一测试问题的召回内容 |
| 引用上限 | 设为能容纳一份完整授权链的token量 | 用长短不同的实际材料测试引用内容是否被截断，再调整上限 |
| 最低相关度 | 先取一个中间值，标注相关与无关样本后调整 | 该值仅在语义检索或结果重排时生效，比较不同取值下无关片段是否被滤除 |
| 问题优化 | 多轮追问场景开启，单轮明确问题关闭 | 比较原问题与优化后问题，核对主体、品牌、类目是否被改错 |
| 结果重排 | 具备重排模型且候选较多时启用 | 重排得分可用于过滤，比较重排前后排序与最低相关度的配合效果 |

## 容易做错的三处

1. 把检索命中当成授权成立。输入“乙商贸有限公司 星野 授权”，检索返回授权材料原文，这只说明材料被召回，不说明授权已签署或生效。检查时比较拟稿句与材料原文的主体、品牌、类目、期限字段是否同期间同字段一致，材料未载明的签署状态应记为待核实。
2. 跨向量模型关联知识库。把使用不同向量模型的两个库同时关联，违反节点对相同向量模型的要求。检查时先读取各库向量模型标识，排除标识不同者，记录实际观察，不推断关联后的运行结果。
3. 用最低相关度代替权限过滤。最低相关度是相似度过滤阈值，不区分业务主体或授权范围。检查时确认检索范围本身已限定在有权访问的库内，缺失访问权时记录证据缺口。

## 怎么确认配好了

1. 输入假设样本中的拟稿句与两份材料原文，比较拟稿句的授权期限字段与授权材料原文的“2025年1月1日至2025年12月31日”是否一致。若拟稿句写“有效期至2025年12月31日”，与原文期限终点一致，但原文未载明签署或生效状态，该部分仍属未获支持；若拟稿句写“长期有效”，与原文明确期限矛盾，判定为不一致。
2. 输入一条仅含主体名称的短问题，观察引用内容数组。若返回长度大于 0 且内容指向该主体相关材料，说明召回可用；若返回空数组，按文档所述空结果链路走通处理，将该空结果作为下游设计的纸面输入核对，不声称某规则检索必然返回空。
3. 输入一条含证件编号的精确查询，比较全文检索与语义检索的召回内容。若编号类问题在全文检索下命中材料原文，说明该模式适配精确查询；若两种模式召回内容不同，记录差异并核对问题优化是否改动了编号主体，不保证首条命中或全部召回。
