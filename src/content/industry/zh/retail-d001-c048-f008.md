# 快递面单与揽收交接的商品资料与选型问答：工作流编排

## 这个品类的数据长什么样

在快递面单与揽收交接的商品资料与选型问答中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

面单和交接资料可以回答包裹怎样被描述、准备交给哪类处理方，却不等于商品使用说明。自拟附页可写“包裹描述为玻璃器皿，并有易碎提示，未附商品型号和用途资料”。表单接收时应保留这几项文字，检查下游有没有把运输提示当成已验证的包装性能，或者把托寄物名称直接扩展成商品规格；能读到提示与能确认商品适用性是不同检查。

## 配置怎么定

| 核对步骤 | 本题自拟输入 | 应核对的实际结果 |
| --- | --- | --- |
| 可读范围 | 托寄物描述、易碎提示及缺少型号说明 | 运输提示没有被扩展成商品规格 |
| 传值核对 | 附页原句及当前选型问题 | 下游保留各项文字的用途区别 |
| 补充路径 | 托寄物说明、包装资料或交接咨询 | 每条分支收到对应的实际依据 |
| 图像读取 | 面单或附页只有扫描图片 | 另核转换实现后再查接收文本 |
| 承运业务 | 改面单、换服务或揽收的实际记录 | 与信息传递及商品阅读分别验收 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

选型提问若涉及所需保护或商品用途，应先明确需要商品方还是运输方补充依据，再设计对应人员选择。分别验证取得托寄物说明、查看实际包装资料和交接咨询的路径，记录每条分支真正收到什么。选项只是阅读安排，不能由一次选择认定运输方案已经获批，也不能在缺少制造方说明时给出确定的商品使用建议。 包装说明若只引用旧版承运要求，当前商品问题又涉及新使用条件，就需排查两者适用对象。并列保留旧要求和本次提问，向资料负责人索取相应说明；不要把“存在一份规范”写成当前商品包装已经通过确认，也不能借分支继续执行绕开这一缺口。

## 怎么确认配好了

取得新增资料后，用相同问题复核面单文字、补充内容与最终答复的关系。若只有扫描图片，读取成文字的处理能力要另外落实，不能归给表单本身。需要修改面单、变更运输服务或提交揽收安排时，应另验外部接口与实际业务记录；字段传到后续步骤，只说明信息交付到位，不证明承运方已接受包裹或服务已经完成。
