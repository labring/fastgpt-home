# 批发市场档口交易的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

批发市场档口交易的商品资料散落在进货单、手写销售单、摊位租赁合同和货款收据中。档口老板与采购商现场议价后开单，商品名称、规格、数量和价格常以手写形式记录，同一商品在不同单据上可能出现简称或别名。商品资料与选型问答需要从这些材料中提取可核对的字段，再依据模型能力回答采购商关于规格、库存和替代品的询问。数据按日和每单更新，资料更新频率本身不触发任何自动同步动作。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入依赖 AI Proxy 服务。App 与复用 App/Service 配置的 Admin 服务都必须设置 AIPROXY_API_ENDPOINT 和非空的 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。AIPROXY_API_ENDPOINT 填写 AI Proxy 服务根地址，不附加 /v1。系统至少需要一个语言模型和一个索引模型才能正常使用。模型配置中的模型 ID 是接口请求 Body 中 model 字段的值，全局唯一；模型名仅用于展示。商品资料问答若涉及图片识别，需要所选语言模型具备 vision 能力，此项按应用所需输入核对，不能假设默认开启。

假设演练样本：某档口一张手写销售单载明“螺纹钢 HRB400 直径12mm，数量3吨，单价3850元，当日有效”，另一张摊位租赁合同载明“摊位A-17，租期2026年1月1日至2026年12月31日”。待判定的拟稿句为“该档口可长期供应螺纹钢HRB400直径12mm，价格以3850元为准”。核对对象是销售单的当日有效范围与拟稿句的长期供应表述。

## 配置怎么定

以下配置项围绕本页商品资料与选型问答任务，均为官方已说明的设置或实施核对项。数值若出现，均为本次假设试验起点，并注明选择理由与比较对象。

| 配置项 | 本页假设起点 | 理由与比较方法 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设填写内部 AI Proxy 根地址，不含 /v1 | 与官方要求“不附加 /v1”比较，确认路径结尾无 /v1 |
| AIPROXY_API_TOKEN | 假设填写非空管理员 Token | 与服务端配置比较，确认一致且非空 |
| 语言模型 vision 能力 | 假设按需启用 | 与商品资料是否含图片输入比较，无图片输入时不强制 |
| 索引模型 | 假设至少启用一个 | 与官方“至少一个索引模型”要求比较 |
| 模型 ID | 假设与渠道中模型字段一致 | 与渠道配置的模型字段比较，确认全局唯一 |
| 模型探测间隔 | 假设设为 10 分钟 | 与官方 5～60 分钟整数范围比较，仅为本次试验起点 |

模型探测仅针对已启用的系统模型，未启用模型不参与探测也不产生历史记录。探测请求首次失败后最多自动重试 3 次，4 次全部失败才判定异常。告警 Webhook 在状态边沿变化时推送，持续异常不重复推送。

## 容易做错的三处

1. 将手写销售单上“当日有效”的报价当作长期供货承诺。销售单只载明当日有效范围，拟稿句若写“长期供应”则超出该范围，属于未获支持。
2. 将 AIPROXY_API_ENDPOINT 填写为完整模型请求地址并附加 /v1。官方要求填写根地址且不附加 /v1，附加后与根地址填写要求不符，实际请求路径和响应需测试。
3. 将摊位租赁合同的租期当作商品供应期限。租赁合同的对象是摊位，商品资料问答的对象是商品，两者主体与对象不同，不能互相替代。

## 怎么确认配好了

1. 输入假设销售单原文“螺纹钢 HRB400 直径12mm，数量3吨，单价3850元，当日有效”与拟稿句“该档口可长期供应螺纹钢HRB400直径12mm，价格以3850元为准”。分别核价格有效范围与供货承诺。原文可支持3850元的当日报价，未给销售单具体日期或长期供货承诺；不能仅改成“当日供货”就判支持。长期价格及供货主张均待核。
2. 输入 AIPROXY_API_ENDPOINT 的假设填写值，比较其结尾是否含 /v1。若结尾含 /v1，则与官方要求不符；若结尾为根地址，则满足条件。AIPROXY_API_TOKEN 需比较是否非空且与服务端一致。
3. 输入假设摊位租赁合同原文“摊位A-17，租期2026年1月1日至2026年12月31日”与商品供应询问。比较合同对象“摊位”与询问对象“商品”。对象不同，合同租期不能作为商品供应期限的证据，记录为待核实，保留证据缺口。
