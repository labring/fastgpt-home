# 拼多多低价活动店铺运营的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

拼多多低价活动店铺运营围绕低价资源位、活动库存和退款率波动展开，数据来源包括拼多多商家后台、活动资源位数据、ERP库存、物流签收数据。日常文档为活动报名表、商品成本测算表、售后退款单、平台站内信。这些材料直接决定商品资料与选型问答的语料范围：活动报名表承载活动价与报名状态，成本测算表承载成本与毛利口径，退款单承载售后波动。资料给出更新频率为日、每场活动，本页不据此推出批量同步或实时触发机制。

## 这些特征在「模型接入与配置」这一环带来什么约束

从 V4.17.0 起，AI Proxy 为必需依赖，App 与复用 App/Service 配置的 Admin 都须设置 `AIPROXY_API_ENDPOINT` 和非空 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两项。系统至少需要一个语言模型和一个索引模型才能正常使用。模型 ID 是请求 Body 中 `model` 字段的值，全局唯一；模型映射把 FastGPT 请求的模型映射到上游实际模型。渠道优先级范围 1～100，数值越大越容易被优先选中。模型状态探测仅针对已启用系统模型，首次失败后最多自动重试 3 次，单轮最多尝试 4 次，全部失败才判定异常。

假设演练样本：某拼多多活动店铺运营人员提交一份商品资料与选型问答的接入核对请求。供核对材料原文为：“活动报名表（2026年3月场次）载明商品A报名活动价为19.9元，报名状态为已提交待平台审核。商品成本测算表载明商品A单件成本16.5元，毛利口径含平台佣金与物流费。售后退款单（2026年3月1日至3月7日）记录商品A退款2单，原因均为尺码不符。”待判定的拟稿句为：“商品A在2026年3月场次已通过审核，可按19.9元上架销售。”该句涉及审核状态与上架授权，材料仅显示“已提交待平台审核”。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填写 AI Proxy 服务根地址，例如 `http://aiproxy:3000` | 文档要求不附加 `/v1`；与含 `/v1` 的写法比较 |
| `AIPROXY_API_TOKEN` | 填写与服务端一致的非空管理员 Token | 文档要求非空且一致；与应用 API Key 比较 |
| 语言模型与索引模型 | 各启用至少一个 | 文档要求系统至少各一个；与未启用状态比较 |
| 模型映射 | 将 FastGPT 模型 ID 映射到上游实际模型 | 文档给出 `gpt-4o-test` 映射到 `gpt-4o` 的示例；与未映射比较 |
| 渠道优先级 | 本次假设试验起点设为 50 | 文档范围 1～100，数值越大越优先；与另一渠道数值比较 |
| 模型状态探测间隔 | 本次假设试验起点设为 10 分钟 | 文档支持 5～60 分钟整数；与 5 或 60 比较 |

检索与知识库相关度不承担权限或实体隔离职责，检索库同向量模型要求不扩展到外部系统。空结果可承接纸面输入 `[]` 核对下游设计，不声称虚构规则检索一定返回 `[]`。跨不同向量模型的库不可共同关联，先核标识并排除不符合者。

## 容易做错的三处

1. 把“已提交待平台审核”当作审核通过。输入为材料原文“报名状态为已提交待平台审核”，比较对象为拟稿句“已通过审核”。可观察结果为：材料未载明审核通过，该拟稿句未获支持，属待核实。
2. 用应用 API Key 代替 `AIPROXY_API_TOKEN`。输入为文档要求“非空管理员 Token，必须与服务端配置一致”。比较对象为应用 API Key。可观察结果为：两者用途不同，替代不满足文档条件。
3. 把模型状态探测重试次数理解为单次请求重试。输入为文档“首次失败后最多自动重试 3 次，单轮最多尝试 4 次”。比较对象为“单次请求重试 3 次”。可观察结果为：文档描述的是单轮探测的总尝试次数，两者口径不同。

## 怎么确认配好了

1. 针对拟稿句“商品A在2026年3月场次已通过审核，可按19.9元上架销售”，输入为材料原文“已提交待平台审核”。比较同一主体、同一场次、同一报名状态字段。满足条件为：材料明确载明审核通过；当前材料未载明，判定为未获支持、待核实。
2. 针对接入核对请求，输入为 `AIPROXY_API_ENDPOINT` 与 `AIPROXY_API_TOKEN` 两项配置。比较文档要求“根地址不附加 `/v1`”与“非空且一致”。满足条件为：两项均按文档填写；缺少任一项时启动校验失败。
3. 针对商品资料检索，输入为活动报名表、成本测算表、退款单文本。比较返回结果与查询主体、场次、字段是否一致。满足条件为：返回内容与输入材料同主体同期间；空结果时记录缺口，不判定为否定。检索为观察动作，不构成授权或审批。
