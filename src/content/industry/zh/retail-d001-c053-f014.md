# 渠道应收账款催收的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

渠道应收催收发生在赊销后，关注授信和现金回收。品牌财务、销售内勤与经销商核应收账龄表、催款函、授信协议及发货冻结通知，资料来自财务系统、银行回单、订单和销售合同。选型问答需保留主体、期间、金额及授信范围。模型用于读取材料并生成待核答案；自动写回或冻结发货的实施与授权须另核。

## 这些特征在「模型接入与配置」这一环带来什么约束

按官方文档，FastGPT 借助 AI Proxy 连接模型提供商。从 V4.17.0 起 AI Proxy 为必需依赖，App 与复用 App/Service 配置的 Admin 都必须设置 AIPROXY_API_ENDPOINT 和非空的 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两项。

系统至少需要一个语言模型和一个索引模型才能正常使用。语言模型字段包含 maxContext、maxResponse、quoteMaxToken、maxTemperature、vision、toolChoice、functionCall 等；索引模型字段包含 defaultToken 与 maxToken。这些字段在模型配置中定义，应用或节点参数在编排中设置，不能假设对话接口的同名字段会覆盖编排。检索与相关度不承担权限或实体隔离职责，检索结果是否可交给某位使用者，取决于业务侧的授权判断。

假设演练样本：某品牌财务人员提交一份《授信协议》摘录，原文为“经销商甲，授信额度八十万元，账期六十天，协议自二〇二五年三月一日起生效”；同时提交一份《应收账龄表》摘录，原文为“经销商甲，截至二〇二五年六月三十日，逾期金额十二万元，账龄九十天以上”。待判定拟稿句为“经销商甲当前逾期金额为十二万元”。该样本仅用于纸面核对，不代表任何真实客户或已发生的业务。

## 配置怎么定

下表为本次假设演练的核对项，数值仅为本次试验起点，用于与文档说明或实际观测值比较，不作为官方默认值。

| 核对项 | 本次假设起点 | 核对方式与依据 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设填写 AI Proxy 服务根地址 | 对照文档，地址不附加 `/v1`；与启动校验结果比较 |
| AIPROXY_API_TOKEN | 假设填写与服务端一致的非空 Token | 与 AI Proxy 管理员 Token 比较，确认非空且一致 |
| 语言模型 | 假设启用一个支持文本对话的模型 | 对照模型配置中的 maxContext 与 maxResponse，确认满足问答长度 |
| 索引模型 | 假设启用一个索引模型 | 对照 defaultToken 与 maxToken，确认与待检索文档切分方式匹配 |
| 模型测试 | 假设在渠道测试中对已配置模型发起一轮测试 | 观察测试结果与请求时长，未通过时记录为待排查 |
| 检索范围 | 假设限定在含授信协议与账龄表的资料集 | 核对返回片段是否来自该范围，缺失时记录为证据缺口 |

## 容易做错的三处

1. 把 AIPROXY_API_TOKEN 当作可省略项。文档说明该项为必填且不能为空，缺少会导致启动校验失败。核对时输入为环境变量配置，比较对象为文档中的必填说明，观测结果为启动校验是否通过。
2. 用应用 API Key 代替 AI Proxy 管理员 Token。文档说明两者用途不同，核对时输入为实际填入的凭证，比较对象为 AI Proxy 服务端配置，观测结果为模型调用是否成功。
3. 把检索命中的片段直接当作已核实事实。样本中账龄表只载明截至二〇二五年六月三十日的逾期金额，拟稿句若写成当前逾期，需核对是否另有更新材料。输入为拟稿句与两份原文，比较对象为期间与字段，观测结果为是否同主体同期间同字段。

## 怎么确认配好了

- 验证一：核对 AIPROXY_API_ENDPOINT 与 AIPROXY_API_TOKEN。输入为本次假设演练中填写的地址与 Token，比较对象为文档中“根地址不附加 `/v1`”与“非空且与服务端一致”的说明，观测结果为启动校验是否通过、模型测试是否返回结果。未通过时记录为待排查，不推断具体失败原因。

- 验证二：核对拟稿句“经销商甲当前逾期金额为十二万元”。输入为该句与账龄表原文“截至二〇二五年六月三十日，逾期金额十二万元”，比较对象为主体、期间与字段，观测结果为账龄表支持“截至该日逾期十二万元”，对“当前”是否成立需另有材料，缺失时记录为证据缺口。

- 验证三：输入两份摘录，核主体是否均为经销商甲，再分别核协议生效日与账龄表截至日；同主体不能消除期间差异。若涉及多个库共同检索，另核其向量模型一致。实际引用待测，不保证首条命中或全部召回。
