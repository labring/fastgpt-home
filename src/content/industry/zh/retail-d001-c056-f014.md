# 生产企业免抵退税的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样
生产企业免抵退税把内销税额抵减与退税合并计算，这一特征决定了商品资料与选型问答必须同时面对申报明细表、出口合同、销售明细账与出口报关单四类材料。四类材料的字段口径并不一致：申报明细表按免抵退口径记录出口销售额与不得免征和抵扣税额，销售明细账按会计口径记录收入与成本，报关单提供离岸价与商品编码，出口合同提供成交方式与数量约定。模型接入与配置要处理的，是让问答在引用这些材料时保持口径可追溯，不把会计口径的金额直接当作免抵退计税依据。资料更新频率为月，本页不涉及由此推导的批量或实时同步机制。

## 这些特征在「模型接入与配置」这一环带来什么约束
模型接入依赖 AI Proxy，App 与复用 App/Service 配置的 Admin 服务都必须设置 AIPROXY_API_ENDPOINT 和非空的 AIPROXY_API_TOKEN，缺少任一项会启动校验失败。AIPROXY_API_ENDPOINT 填服务根地址，不附加 /v1。模型能力按应用所需输入分别核对，多模态、工具调用与思考配置各自验证。检索结果的相关度分数不承担权限或实体隔离职责，检索动作本身不构成授权。跨不同向量模型的库不可共同关联，只能先核标识并排除不符合者。

假设演练样本：某出口生产企业 2026 年 3 月免抵退税申报明细表载明“出口销售额 1,200,000 元，不得免征和抵扣税额 24,000 元”，销售明细账同期载明“主营业务收入 1,180,000 元”，出口合同约定“FOB 上海，数量 5,000 件，装运期 2026 年 3 月”。拟判定句为“该企业 3 月出口销售额为 1,180,000 元”。判定需比较同一期间、同一字段的取值，明细表与明细账口径不同，不能直接认定矛盾。

## 配置怎么定
下表仅列与本页主任务相关的官方已说明设置或实施核对项，数值为本次假设试验起点，用于与文档说明的范围或相邻配置比较，不代表官方默认值。

| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 填写 AI Proxy 服务根地址 | 文档要求不附加 /v1，与带路径写法比较 |
| AIPROXY_API_TOKEN | 填写与服务端一致的非空 Token | 文档要求不能为空，与应用 API Key 比较 |
| 模型能力核对 | 按问答所需输入逐项核对 | 多模态、工具调用分别验证，与内置模型说明比较 |
| 检索库向量模型标识 | 记录各库所用向量模型 | 跨模型库不可共同关联，与同模型库比较 |
| 探测间隔 | 假设起点 30 分钟 | 文档范围为 5～60 分钟整数，与边界值比较 |
| 重试判定 | 假设起点为单轮最多 4 次尝试 | 文档说明首次失败后最多重试 3 次，与尝试次数比较 |

## 容易做错的三处
1. 把销售明细账的会计口径金额直接当作免抵退出口销售额。输入为明细账金额，比较对象为申报明细表同一期间同一字段，两者口径不同，直接等同会掩盖口径差异。
2. 用相关度分数排除不相关业务或未授权记录。输入为检索返回的分数，比较对象为权限判定依据，分数不承担权限或实体隔离职责。
3. 把不同向量模型的库直接共同关联。输入为两个库的向量模型标识，比较对象为标识是否一致，标识不同时只能排除不符合者并记录观察。

## 怎么确认配好了
1. 针对假设样本的拟判定句，输入明细表原文与明细账原文，比较同一期间同一字段的取值与口径说明。只有两处对同一字段给出明确互斥取值，才构成矛盾；口径不同或只有相关阶段证据，记为未获支持或待核实。
2. 针对检索库配置，输入各库向量模型标识，比较标识是否一致。标识一致才可共同关联；标识不一致时排除不符合者，不执行跨模型检索来比较漏召回，空结果以明确的纸面输入核对下游设计。
3. 针对模型接入，输入 AIPROXY_API_ENDPOINT 与 AIPROXY_API_TOKEN 的配置值，比较端点是否为根地址、Token 是否非空且与服务端一致。两项均满足才通过启动校验；任一缺失时启动校验失败，属于需补齐配置的失败分支。
