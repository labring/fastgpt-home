# 生鲜水果门店采购的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

生鲜水果门店采购依赖批发市场行情与供应商报价，采购单、验收单、农残检测报告、损耗记录按日或按批更新。商品资料与选型问答需要把这些文档中的品名、等级、产地、批次与验收状态整理成可检索的条目，供采购与门店生鲜主管在询价比价、等级验收、损耗控制时调用。文档中的主体、对象、有效范围与状态字段决定检索结果能否支撑选型判断。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入与配置决定商品资料与选型问答能否按文档内容作答。语言模型与索引模型为系统运行所需；语言模型处理文本对话，索引模型对文本块建立索引用于相关文本检索。AI Proxy 为必需依赖，App 与 Admin 均须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败；旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。AIPROXY_API_ENDPOINT 填写服务根地址，不附加 /v1。模型能力按应用所需输入核对，多模态、工具调用与思考配置分别验证。检索结果的相关度分数不承担权限或实体过滤职责，检索动作本身不构成授权。

假设演练样本：某门店采购组提交一份纸质材料供核对，原文为“本批次红富士苹果由甲档口于4月12日报价，等级为一级，报价有效期至4月15日；当日验收单记录到货80箱，农残检测报告编号待补”。另有一条待判定拟稿句：“甲档口已承诺本批次供货至4月30日。”材料仅载明报价有效期至4月15日，未载明供货期限，拟稿句中的供货承诺未获支持。

## 配置怎么定

围绕上述样本，配置与核对项如下表。数值为本次假设试验起点，选取理由与比较对象一并列出。

| 配置或核对项 | 本次假设试验起点 | 选取理由与比较方法 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设填写服务根地址，不带 /v1 | 文档要求根地址；与含 /v1 的写法比较，确认启动校验通过 |
| AIPROXY_API_TOKEN | 假设填写非空管理员 Token | 文档要求非空且与服务端一致；与空值比较，确认校验失败分支 |
| 语言模型 | 假设启用一个已启用系统模型 | 文档要求至少一个语言模型；与未启用状态比较，确认问答可用 |
| 索引模型 | 假设启用一个已启用系统模型 | 文档要求至少一个索引模型；与未启用状态比较，确认检索可用 |
| 模型能力核对 | 假设按文本输入核对 | 文档要求按应用所需输入核对；与图片输入场景比较，确认能力差异 |
| 检索范围核对 | 假设限定在已导入的采购文档库 | 文档说明检索不承担授权；与未导入文档比较，确认结果边界 |

## 容易做错的三处

1. 把报价有效期当作供货期限。样本中报价有效期至4月15日，拟稿句称供货至4月30日，两者字段不同，供货承诺未获支持。
2. 把待补的检测报告编号当作已具备。样本写明编号待补，该字段处于缺失状态，不能据此判定检测已完成。
3. 把检索命中当作授权执行。检索返回文档片段仅表示内容相关，采购审批与供货确认需另接系统实现，检索动作不构成授权。

## 怎么确认配好了

1. 输入样本原文与拟稿句，比较报价有效期字段与拟稿句中的供货期限字段，若两者主体、期间、字段一致且取值互斥才判为矛盾；本例字段不同，应记录为未获支持。
2. 输入样本中“农残检测报告编号待补”一句，比较编号字段是否有值，若为空则记录为证据缺口，不判定检测状态。
3. 输入一条仅含相关阶段证据的请求，比较请求中的授权状态与检索结果，若检索返回片段但无审批记录，则记录为待核实，不判定授权已完成。
