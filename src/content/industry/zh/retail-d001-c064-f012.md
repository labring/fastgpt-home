# 直播选品与样品质检的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

选品质检发生在开播之前，判断的是商品能否上播、是否适合直播展示。这个判断依赖四类材料：样品评估表、质检报告、供应商资质、禁售清单。材料来源分散，供应商提供资料、检测机构出具报告、平台负面目录与历史退货率各自独立，更新节奏按周或按品推进。选品经理、供应链BD、质检专员在同一批材料上协作，任何一处解析偏差都可能带来退货、虚假宣传认定或平台处罚。

这些材料进入知识库时，最需要保留的是可回指原文的文档身份与版本，以及条件、说明与所约束内容之间的完整关系。样品评估表里的适用批次、质检报告里的检测项目与结论、供应商资质里的有效期、禁售清单里的类目范围，一旦在分块时被拆开，检索到的片段就会失去判断所需的限定条件。

## 这些特征在「文档解析与分块」这一环带来什么约束

FastGPT 的知识库由库、集合和数据三部分组成，最小搜索单位是库，集合仅作分类管理。MongoDB 的 `dataset.datas` 表存储向量原数据，`indexes` 字段记录对应的向量 ID，一组数据可以对应多个向量。PostgresSQL 的 `vector` 字段存储向量，检索时先召回向量，再按向量 ID 回 MongoDB 找原数据，命中同一组原数据则合并，向量得分取最高分。

这些结构意味着分块要同时照顾两件事：一组数据内部的语义完整，以及多组索引对同一组原数据的覆盖。样品评估表、质检报告、供应商资质、禁售清单四类材料的结构差异明显，分段时按各自结构检查段落，避免把条件句与它约束的结论拆到不同数据里。语义检索依赖向量距离，全文检索依赖关键词命中，混合检索经 RRF 融合两路结果，Rerank 再做二次排序。编号、型号、专有名词适合全文或混合检索，自然语言问法适合语义或混合检索。

假设演练样本：某批次样品评估表原文为“样品名称：折叠电煮锅；送样批次：B2405；评估结论：外观与功能符合上播要求，待质检报告归档后确认。”一条待判定拟稿句为“该批次已确认可上播。”供核对的供应商资质原文为“资质名称：食品接触材料检测报告；覆盖对象：折叠电煮锅系列；有效期至：2025年12月31日。”交接请求为“请确认该批次可上播并同步至选品清单。”此处主体为B2405批次，对象为折叠电煮锅，状态为待质检报告归档后确认，授权边界为评估结论尚未转为可上播确认。

## 配置怎么定

| 配置或核对项 | 本页相关取值或做法 | 依据与说明 |
| --- | --- | --- |
| 搜索模式 | 语义检索、全文检索、混合检索按问题类型选择 | 官方文档说明三种模式并存，混合检索经 RRF 融合 |
| 引用上限 | 以 tokens 计，不采用 top k | 官方文档说明混合知识库下 chunk 长度差距大 |
| 最低相关度 | 0-1 数值，仅在语义检索或结果重排时生效 | 官方文档说明其为过滤阈值，不是排序规则 |
| 分段核对 | 按样品评估表、质检报告、资质、禁售清单各自结构检查 | 官方文档说明分段完整与单一可提高精度 |
| 索引核对 | 确认一组原数据对应的多组向量已建立 | 官方文档说明 indexes 为数组，可对应多个向量 |
| 更新后复核 | 资料变更后核对实际训练与索引状态 | 上传成功不等于检索已更新，需人工核对 |

本次假设试验起点：将最低相关度设为0.3，理由是样本问题为自然语言问法，需保留一定召回范围；比较对象为同一批材料在0.3与0.5两个取值下的返回内容差异，观察是否出现条件句与结论被拆离的片段。

## 容易做错的三处

1. 把“待质检报告归档后确认”的评估结论当作已确认可上播。输入是样本原文与拟稿句，比较的是拟稿句是否超出原文状态，可观察结果是拟稿句把待确认写成已确认。
2. 把检索命中当作授权执行。输入是交接请求“请确认该批次可上播并同步至选品清单”，比较的是请求是否附有已完成的确认动作，可观察结果是请求本身不构成确认或同步授权。
3. 把上传成功当作索引已更新。输入是资料变更记录与检索结果，比较的是变更后检索是否返回新内容，可观察结果是上传记录存在而检索仍返回旧片段。

## 怎么确认配好了

1. 输入样本原文与拟稿句，比较拟稿句是否保留“待质检报告归档后确认”这一状态，只有拟稿句不超出原文状态才满足条件。
2. 输入交接请求，比较请求中是否载明确认动作与同步授权，只有请求被明确标注为待审核且未执行同步才满足条件。
3. 输入资料变更记录，比较变更后检索返回内容与变更前内容，只有检索返回内容与变更后材料一致才满足条件。

空结果承接可用明确的纸面输入 `[]` 核对下游设计，不能声称虚构规则检索一定返回 `[]`。跨不同向量模型的库不可共同关联，需先核标识并排除不符合者，记录实际观察。图片检索须有相应图像输入及模型能力，重排须具备模型且按设置启用。检索与相似度不负责权限或实体隔离，业务确认、审批、数据库写入与外部同步需另接系统实现。
