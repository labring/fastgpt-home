# 直播选品与样品质检的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

在直播选品与样品质检的商品资料与选型问答中，本页说明FastGPT的模型接入与配置如何衔接资料。选品回答分别核样品结论、资质主体及禁售范围，接入不产生准售判断。所用场景为自拟文字测试。

## 这些特征在「模型接入与配置」这一环带来什么约束

假设样品评估表只记手感观察，质检报告对应另一规格，供应商资质文件提供主体信息，禁售清单适用范围尚待核。选品问答应检查模型实际收到每份文本及其对应对象，不将手感意见写成安全合格或可售保证。这里没有真实检测指标或平台准售结果；模型可以整理缺项，不能用文件多或返回快代替样品与报告一致性。

## 配置怎么定

| 样品选型证据 | 假设范围 | 需查限制 |
| --- | --- | --- |
| 评估 | 手感观察 | 不称安全合格 |
| 检测 | 另一规格报告 | 核样品对应 |
| 资质 | 供应商主体 | 不证商品性能 |
| 禁售 | 市场待核 | 不扩全部渠道 |
| 补料 | 同规格报告 | 仅更新有据部分 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `AI Proxy依赖` | 按实际版本核服务、渠道与应用。 |
| `AIPROXY_API_ENDPOINT` | 使用AI Proxy服务根地址。 |
| `AIPROXY_API_TOKEN` | 管理员Token非空且与服务端一致。 |
| `模型能力` | 按实际输入路径验证所需能力。 |
| `应用参数` | 接口同名字段未必覆盖应用设置。 |

## 容易做错的三处

- 报告规格字段未进入输入而回答本样品已合格时，核报告页与实际请求，定位对象信息遗漏。

- 供应商资质被用来证明商品性能时，对主体证明用途和产品检测依据，企业资料不能代替样品结论。

- 禁售清单的适用市场丢失而判断全部渠道可售时，对清单范围与拟销对象，缺对应规则应保留待核。

## 怎么确认配好了

固定样品表与报告，分别问观察、检测和准售各由何资料支持；补同规格报告后只更新相关判断。接入模型和参数比较需保留相同材料与问题，实际收到内容和引用逐项核。图片质检单的读取另测，不给准确率或安全认证承诺。真实选品还需负责人员核检测、渠道规定与使用授权，本题不执行上架。
