# 短视频挂车分销运营的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

短视频挂车分销以内容长期曝光和商品链接转化为主，不依赖实时讲解。日常材料包括短视频脚本、挂车商品清单、佣金计划和违规反馈，更新频率为日或周。商品资料与选型问答需要把脚本中的商品指向、清单里的商品状态、佣金计划的有效范围放在同一视图内核对。资料分散在精选联盟、播放数据、成交数据和平台规则中，问答系统接入模型时，必须承认这些来源的记录状态各自独立。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入依赖 AI Proxy。App 与 Admin 必须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺少任一项启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。系统至少需要一个语言模型和一个索引模型。模型 ID 是请求 Body 中 model 字段的值，全局唯一；模型映射把 FastGPT 请求的模型映射到上游实际模型。渠道优先级范围 1～100，数值越大越容易被优先选中。模型探测仅针对已启用的系统模型，首次失败后最多重试 3 次，4 次全部失败才判定异常。检索负责召回文本，不承担权限或实体隔离；跨不同向量模型的库不可共同关联，只能核对标识并排除不符合者。

## 配置怎么定

以下假设演练样本用于说明核对方式，不表示实际测试或部署。假设材料原文：某短视频脚本第 3 段写“挂车商品为 A 款保温杯，佣金比例 12%”；同期挂车商品清单记录“A 款保温杯，状态：待审核，生效日期：2026-03-01”；佣金计划表记录“A 款保温杯，佣金比例 12%，有效期至 2026-03-31”。待判定拟稿句：“A 款保温杯已通过审核并可按 12% 佣金挂车。”该句把待审核写成已通过，把佣金比例的有效期写成无期限。

| 配置项 | 本页相关取值或核对项 | 说明 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设起点 `http://aiproxy:3000`，不附加 `/v1` | 填写 AI Proxy 根地址，与文档示例比较 |
| AIPROXY_API_TOKEN | 假设起点为与服务端一致的非空值 | 不能用应用 API Key 代替 |
| 语言模型与索引模型 | 各至少启用一个 | 系统正常使用的最低条件 |
| 模型 ID 与模型映射 | 核对 `model` 字段全局唯一 | 映射示例 `gpt-4o-test` 到 `gpt-4o` |
| 渠道优先级 | 假设起点 50，与 1～100 范围比较 | 数值越大越优先 |
| 模型探测 | 仅针对已启用模型，重试上限 3 次 | 4 次失败才判异常 |

## 容易做错的三处

1. 把待审核状态当作已通过。清单记录“状态：待审核”，拟稿句写“已通过审核”，两者同主体、同字段、取值互斥，构成矛盾。
2. 把佣金比例的有效期当作无期限。佣金计划表记录“有效期至 2026-03-31”，拟稿句未载明期限，属于未获支持。
3. 把检索召回当作授权。检索返回 A 款保温杯的文本，不表示该商品已通过审核或可挂车，授权状态需另查清单字段。

## 怎么确认配好了

1. 输入假设材料原文与拟稿句，比较“状态”字段取值。清单为“待审核”，拟稿句为“已通过审核”，两者互斥，判定为矛盾。
2. 输入佣金计划表记录与拟稿句，比较“有效期”字段。计划表载明“有效期至 2026-03-31”，拟稿句未载明，判定为未获支持，保留证据缺口。
3. 输入空结果 `[]` 与下游设计，核对空结果承接方式。若下游未定义空结果处理，记录为缺口；不声称虚构规则检索一定返回 `[]`。
