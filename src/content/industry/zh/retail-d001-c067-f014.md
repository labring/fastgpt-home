# 社区团购团长运营的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

团长运营管理社区节点与佣金，不直接做冷链质检。资料来自团购后台、团长社群、订单明细与售后记录，包括团长协议、佣金表、提货清单及社群公告，按日、每团更新。商品资料问答须保留来源、日期及团次，分别核商品、供货范围和提货安排。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入依赖 AI Proxy。自 V4.17.0 起，App 与复用 App/Service 配置的 Admin 服务必须设置 `AIPROXY_API_ENDPOINT` 与非空 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败。`AIPROXY_API_ENDPOINT` 填服务根地址，不附加 `/v1`。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两项。

系统至少需要一个语言模型和一个索引模型才能正常使用。语言模型处理文本对话，索引模型对文本块建立索引用于检索。选型问答若涉及图片资料，需要模型具备图片输入能力；工具调用与提取按所选模式核能力，提取还需核文档所列提示词模式。这些能力按应用所需输入逐项核对，不能由模型名称推断。

检索是取回相关文本块的过程，不承担权限或实体隔离。同一向量模型下的库才可共同关联；跨不同向量模型的库先核对标识，排除不符合者，不执行跨模型检索来比较漏召回。重排模型存在且按设置启用时才参与重排，图片检索需要相应图像输入与模型能力，这些是可选路径，不代表每次请求全部执行。

## 配置怎么定

以下为假设演练样本，用于说明核对方式，不表示任何真实部署或测试已经发生。

材料原文（假设）：某社区团购平台《团长协议》第 3 条载明“团长可在授权团次内转发平台提供的商品资料”。《佣金表》2026 年 3 月版列明“叶菜类按提货金额 5% 计佣”。《社群公告》2026 年 3 月 18 日载明“本团本周仅供应 A 类商品，B 类商品暂停接单”。

待判定拟稿句（假设）：“团长可转发全部商品资料，B 类商品照常接单。”

下表为本页纸面配置检查。

| 配置项 | 本次假设起点 | 选择理由与比较方法 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 假设填 `http://aiproxy:3000` | 文档要求根地址且不附加 `/v1`；与是否含 `/v1` 的写法比较 |
| `AIPROXY_API_TOKEN` | 假设填非空管理员 Token | 文档要求非空且与服务端一致；核管理员Token来源及服务端一致性，应用Key用途另核 |
| 语言模型 | 假设启用一个语言模型 | 文档要求至少一个；与“未启用任何语言模型”状态比较 |
| 索引模型 | 假设启用一个索引模型 | 文档要求至少一个；与“未启用任何索引模型”状态比较 |
| 模型能力 | 假设按问答所需输入核对 | 文档要求按输入核对；与仅凭模型名称推断比较 |
| 知识库文件解析并发 | 假设 `DATASET_PARSE_MAX_PROCESS=10` | 文档默认值 10，作为本次起点；与队列实际积压情况比较 |

## 容易做错的三处

1. 把 `AIPROXY_API_ENDPOINT` 写成含 `/v1` 的完整请求地址。输入为假设填写的地址字符串，比较对象是文档要求“不附加 `/v1`”，可观察结果是该字符串是否以 `/v1` 结尾。
2. 用应用 API Key 充当 `AIPROXY_API_TOKEN`。输入为假设填入的 Token 值，比较对象是文档要求“管理员 Token 且与服务端一致”，可观察结果是该值是否与 AI Proxy 服务端配置相同。
3. 由模型名称推断其具备图片输入或工具调用能力。输入为假设的模型名称与问答所需输入类型，比较对象是文档要求“按应用所需输入核对模型能力”，可观察结果是模型配置中对应能力字段的取值。

## 怎么确认配好了

以下验证使用前述假设样本，只说明应比较什么与预期现象，不表示已经实测。

1. 输入假设拟稿句“团长可转发全部商品资料，B 类商品照常接单”，比较对象是《团长协议》第 3 条的授权范围与《社群公告》2026 年 3 月 18 日的供应范围。同一期间、同一字段出现互斥取值时，可判定为矛盾；拟稿句超出协议授权范围或与公告供应范围不一致，即为未获支持。
2. 输入假设的 `AIPROXY_API_ENDPOINT` 字符串，比较对象是文档“不附加 `/v1`”的要求。可观察结果是该字符串是否以 `/v1` 结尾；若结尾含 `/v1`，则与文档要求不符。
3. 输入假设的 `DATASET_PARSE_MAX_PROCESS=10`，比较对象是文档列出的默认值 10。可观察结果是本次起点与默认值是否一致；若不一致，需记录该差异及选择理由，不能视为官方默认。

若检索返回空结果，可用明确的纸面输入 `[]` 核对下游设计如何处理空引用，不据此推断某条虚构规则一定返回空。模型状态探测的告警 Webhook 与重试机制属于文档已说明能力，本页不声称已配置或已触发。
