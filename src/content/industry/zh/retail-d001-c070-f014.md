# 跨境商品合规与标签的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

跨境商品合规与标签场景的资料在上架和进口前产生，核心是产品安全与标签证据。主要来源包括平台政策中心、检测机构报告、目的国法规库和供应商资料，日常文档为产品测试报告、英文标签、MSDS 和平台禁售清单。这些资料不定期更新，每次上新都需要重新核对。资料中主体、对象、状态和有效范围往往分散在不同文档里，选型问答需要把产品、目的国、报告结论和标签字段对应起来，不能只凭相似文本推断合规结论。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入与配置解决的是让语言模型和索引模型能够被问答流程调用。FastGPT 借助 AI Proxy 连接模型提供商，App 和 Admin 必须设置 AIPROXY_API_ENDPOINT 和非空的 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。模型 ID 是请求 Body 中 model 字段的值，全局唯一；模型名仅用于展示。模型渠道决定协议类型和上游地址，模型映射把 FastGPT 请求的模型名映射到上游实际模型。系统至少需要一个语言模型和一个索引模型才能正常使用。检索结果只表示文本相关，不表示记录已获授权或属于某类业务实体，权限和实体隔离需要另行核对。

假设演练样本：某跨境卖家计划向德国上架一款儿童水杯，材料为一份检测报告摘录，原文为「报告编号 HYP-2026-0417，样品为 350ml 儿童水杯，检测项目为邻苯二甲酸酯，结论为符合限值要求，报告签发日期 2026 年 3 月 10 日，有效期至 2027 年 3 月 9 日」。另有一份英文标签草稿，待判定句为「本产品符合德国儿童饮水器具安全要求」。交接请求为「请确认该报告能否支持上述标签句，并说明还需要哪些材料」。该样本中报告只覆盖邻苯二甲酸酯一项，标签句未限定检测项目，两者主体相同但字段范围不一致，属于未获支持。

## 配置怎么定

下表只列与本页任务相关的官方已说明设置或实施核对项。数值列为本次假设试验起点，用于纸面比较，不作为官方默认值。

| 配置项 | 本次假设起点 | 核对方式 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 填写 AI Proxy 服务根地址，不附加 /v1 | 与部署文档示例比较，确认无路径后缀 |
| AIPROXY_API_TOKEN | 填写与服务端一致的非空管理员 Token | 与应用 API Key 区分，确认非空 |
| 语言模型 | 启用一个已测试通过的语言模型 | 在模型测试页发起测试，观察返回结果 |
| 索引模型 | 启用一个已测试通过的索引模型 | 在模型测试页发起测试，观察返回结果 |
| 模型映射 | 将 gpt-4o-test 映射到 gpt-4o | 与渠道配置中的映射 JSON 比较 |
| 模型探测间隔 | 假设设为 30 分钟 | 与 5～60 分钟整数范围比较 |

## 容易做错的三处

1. 把 AIPROXY_API_TOKEN 填成应用 API Key。输入为应用侧生成的 Key，比较对象为 AI Proxy 管理员 Token，可观察结果为启动校验失败或调用被拒。
2. 把模型映射写成模型别名。输入为展示用名称，比较对象为渠道中配置的模型 ID，可观察结果为请求上游时 model 字段与预期不符。
3. 把检索相似度当成权限过滤。输入为一条相似度较高的记录，比较对象为该记录是否在授权范围内，可观察结果为记录被召回但无权使用。

## 怎么确认配好了

- 验证一：输入假设样本中的报告原文和待判定标签句，比较报告检测项目与标签句覆盖范围，只有标签句明确限定为邻苯二甲酸酯且报告在有效期内，才满足支持条件；当前样本不满足。

- 验证二：输入交接请求「请确认该报告能否支持上述标签句」，比较请求是否要求给出未覆盖项目的补充材料，只有回复明确列出缺失的检测项目或法规依据，才满足条件。

- 验证三：输入空结果承接场景，假设检索返回空数组 []，比较下游设计是否按空结果处理，只有下游不生成合规结论并提示补充材料，才满足条件。以上均为纸面核对，未实际执行。
