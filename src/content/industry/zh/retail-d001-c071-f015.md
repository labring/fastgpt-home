# 跨境平台结算与汇兑的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

跨境平台结算与汇兑的资料围绕已成交订单的资金归集展开，与支付风控关注的欺诈拒付属于不同环节。本页处理的材料包括平台结算单、汇率表、服务费发票与收款对账表，更新频率为周或月。这些材料在商品资料与选型问答中承担两类用途：一是作为选型依据，说明某类结算资料在特定平台、币种与账期下的字段构成；二是作为核对依据，供运营在交接时判断某份材料是否覆盖所需对象与期间。

商品资料与选型问答的检索对象是资料文本本身，检索结果用于回答“哪类结算单包含哪些字段”“某币种汇率表覆盖哪个区间”等问题。检索环节不判断材料真伪，不执行对账，也不产生授权效果。

## 这些特征在「知识库检索与召回」这一环带来什么约束

结算资料的编号、账期、币种代码属于精确查询对象，适合全文检索或混合检索；对字段含义的自然语言提问适合语义检索。知识库搜索节点可关联一个或多个使用相同向量模型的知识库，跨不同向量模型的知识库不可共同关联。引用上限以 token 为单位，长短差异大的结算单与对账表需要分别观察引用内容是否完整。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值，不构成排序规则，也不承担权限或实体隔离功能。问题优化用于指代消除和问题扩展，需核对优化后的问题是否改动了主体或期间。检索输出为数组，长度可以为 0，空结果链路仍会走通。

假设演练样本：供核对的材料原文为“2024年3月平台结算单（样本编号S-2403），覆盖币种USD，账期2024-03-01至2024-03-31，含订单扣费明细与服务费合计”。待判定的拟稿句为“该结算单已确认2024年3月全部服务费金额并完成收款”。该拟稿句涉及收款状态，材料原文未载明收款事实，属未获支持。

## 配置怎么定

| 配置项 | 本页假设起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 选入结算单库与汇率表库 | 两库使用相同向量模型；逐一核对模型标识，排除不一致者 |
| 搜索模式 | 混合检索 | 样本含编号与自然语言字段；与单独语义、单独全文的结果对照 |
| 引用上限 | 假设起点 3000 token | 以样本S-2403完整字段为参照，比较截断处是否丢失服务费合计 |
| 最低相关度 | 假设起点 0.4 | 先标注相关与无关样本，再比较阈值调整后的引用集合变化 |
| 问题优化 | 对多轮追问开启 | 比较原问题与优化后问题，核对主体与期间是否被改动 |
| 结果重排 | 候选较多时启用 | 需具备重排模型并按设置启用；比较重排得分与向量得分差异 |

以上数值为本次假设试验起点，不属官方默认值。RRF 为混合检索结果融合过程，不作为独立开关配置。

## 容易做错的三处

1. 将最低相关度当作权限或实体过滤。输入为样本S-2403的检索请求，比较返回引用是否含其他币种或未授权账期记录，若出现此类记录，说明相关度设置未承担隔离功能，需另接权限实现。
2. 将检索命中当作业务确认。输入为拟稿句“已完成收款”，比较材料原文是否载明收款状态，原文未载明时该判定为未获支持，不得记为已收款。
3. 将不同向量模型的知识库强行共同关联。输入为结算单库与汇率表库的模型标识，比较两者是否一致，不一致时排除该库，不执行跨模型检索。

## 怎么确认配好了

1. 输入样本S-2403的完整原文与拟稿句，比较拟稿句所述收款事实是否在原文中出现，原文未载明时记录为未获支持，不得判定为已完成收款。
2. 输入样本S-2403的检索请求，比较引用内容是否包含服务费合计字段，若引用上限截断导致该字段缺失，调整上限后重新观察，不保证首条命中。
3. 输入一条纸面空结果[]，核对下游设计是否按数组长度0处理，不声称虚构规则检索一定返回空数组。
