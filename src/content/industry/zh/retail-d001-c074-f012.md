# 跨境退货翻新与二次销售的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

跨境退货翻新与二次销售处理逆向物流和商品状态，与海外仓头程补货属于不同业务。主要数据来自海外仓WMS、TikTok退货中心、Amazon退货报告和商品质检照片，日常文档包括退货质检表、翻新记录、报废单和二次上架清单。最耗时的环节是判断退货等级、安排翻新包装、决定报废或重售。这些文档常以单件或小批次出现，同一商品可能同时存在质检结论、翻新工序记录和二次上架状态，分段时需保留主体、对象、状态与有效范围。

## 这些特征在「文档解析与分块」这一环带来什么约束

文档解析与分块需按退货质检表、翻新记录、报废单、二次上架清单各自的结构切分。质检表中的等级判定条件与对应商品状态应处于同一数据块，避免条件与结论被拆离。翻新记录中的工序、包装状态与二次上架清单中的可售状态需分别保留索引。FastGPT 中一组数据可对应多个向量索引，检索时先召回向量，再按向量 ID 去 MongoDB `dataset.datas` 寻找原数据，同一组原数据取最高得分合并。混合检索通过 RRF 融合语义与全文结果，结果重排依赖 ReRank 模型，两者均需相应设置与模型能力。

假设演练样本：某海外仓质检记录原文为“退货单号 RT-2041，商品为折叠桌，外观划痕，功能测试正常，质检等级 B，可安排翻新包装后二次上架。”待判定拟稿句为“RT-2041 折叠桌已批准报废。”该拟稿句与原文在商品状态字段上取值不同，原文为可翻新后二次上架，拟稿句为已批准报废，两者在同一字段上互斥，属于未获支持的表述。

## 配置怎么定

| 配置项 | 本页相关设置或核对项 | 与样本的关系 |
| --- | --- | --- |
| 搜索模式 | 语义检索、全文检索或混合检索 | 用“折叠桌”“RT-2041”分别检索，核对召回内容 |
| 结果重排 | 需具备 ReRank 模型并按设置启用 | 候选较多时核对重排得分与过滤 |
| 引用上限 | 按 tokens 控制引用内容量 | 核对质检条件与结论是否同块返回 |
| 最低相关度 | 0-1 数值，仅在语义检索或结果重排时生效 | 核对过滤后是否仍包含该样本原文 |
| 问题优化 | 指代消除与问题扩展，检索前增加模型调用 | 连续追问“这批怎么处理”时核对补全结果 |
| 索引状态 | 核对实际训练与索引状态 | 资料变更后不能将上传成功当作检索已更新 |

本次假设试验起点可设最低相关度为 0.5，选择理由是该值处于 0-1 区间中段，便于观察过滤前后差异，并与未设阈值时的召回结果比较。该值仅为本次纸面核对起点，不是官方默认值。

## 容易做错的三处

1. 将质检等级与二次上架状态拆到不同数据块，检索时只召回等级而丢失可售状态。检查方式：输入“RT-2041 折叠桌 质检等级”，比较返回内容是否同时包含等级 B 与可翻新后二次上架，若仅返回等级则分段不完整。
2. 将拟稿句“已批准报废”当作原文事实。检查方式：输入“RT-2041 折叠桌 报废”，比较返回原文中是否存在报废批准字段，原文仅有质检等级与翻新安排，该拟稿句未获支持。
3. 将检索结果当作授权执行。检查方式：输入“RT-2041 执行报废”，比较系统是否返回任何报废执行记录或审批状态，检索仅返回文档内容，不构成报废操作授权。

## 怎么确认配好了

1. 输入“RT-2041 折叠桌 质检等级 B”，比较返回内容是否包含原文中外观划痕、功能正常、等级 B 及翻新后二次上架，若返回内容缺少可售状态则分段需调整。
2. 输入“RT-2041 折叠桌 已批准报废”，比较返回内容是否出现报废批准字段，原文未载明该字段，预期为未获支持，需记录证据缺口。
3. 输入“折叠桌 二次上架”，比较返回内容是否命中二次上架清单中的可售状态，若返回空结果，可用纸面输入 `[]` 核对下游对空引用的处理设计，不能声称虚构规则检索一定返回空数组。

检索或表单不构成授权执行，待审核不证明缺少操作权限。跨不同向量模型的库不可共同关联，需先核对标识并排除不符合者，不执行跨模型检索来比较漏召回。
