# 达人专场带货合作的商品资料与选型问答：知识库检索与召回

## 这个品类的数据长什么样

达人专场带货合作的核心是外部达人履约与佣金结算。商品资料与选型问答要处理的材料包括达人合作协议、佣金设置单、样品寄送单、直播战报，这些材料由品牌商务、MCN机构、达人经纪分别维护，更新节奏为每场或每周。资料分散在精选联盟、巨量星图、达人历史数据和店铺成交明细中，同一款商品的佣金比例、坑位费、寄样状态、历史带货表现可能出现在多份材料里。检索环节需要把商品规格、佣金条件、合作阶段三类信息放在同一知识库中供问答调用，检索结果只呈现材料内容，不构成佣金确认、授权或结算依据。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的库，跨不同向量模型的库不可共同关联，应先核对向量模型标识并排除不符合者。搜索模式分为语义检索、全文检索和混合检索，混合检索通过 RRF 融合多路结果，RRF 是融合过程，不是可开启的独立开关。引用上限以 token 为单位控制每次搜索引用的内容量，最低相关度仅在语义检索或使用结果重排时生效。问题优化用于指代消除和问题扩展，会额外调用模型。图片检索需要图像输入及相应模型能力，重排需要具备模型并按设置启用，这些路径并非每次请求都会执行。检索输出为数组，长度可以为 0，空结果链路仍会走通。相似度得分不承担权限或实体隔离功能，检索本身不构成授权。

## 配置怎么定

以下配置围绕本页假设演练样本设定。样本材料原文为：“2025年3月样品寄送单载明，达人A于3月10日收到样品X两件，寄样用途为专场选品测试。同期佣金设置单载明，商品X在达人A专场的佣金比例为百分之十五，该比例适用于3月15日至3月31日。”待判定拟稿句为：“达人A已确认商品X的佣金比例并完成专场合作。”该拟稿句涉及合作是否达成，材料仅显示寄样与佣金比例区间，未载明达人确认或合作签署。

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 商品资料库与合作协议库各一个 | 两库向量模型标识一致才可共同关联，逐一核对标识 |
| 搜索模式 | 混合检索 | 佣金比例含数字与专有名词，与语义召回比较命中差异 |
| 引用上限 | 以较长材料完整呈现为起点 | 用长短不同的实际材料测试内容是否被截断，再调整 |
| 最低相关度 | 先标注相关与无关样本再设值 | 仅在语义检索或重排生效，比较过滤前后结果 |
| 问题优化 | 多轮追问场景启用 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 具备模型时按设置启用 | 比较重排前后排序，确认候选是否足够 |

## 容易做错的三处

1. 把检索命中当作合作确认。输入拟稿句“达人A已确认商品X的佣金比例并完成专场合作”，比较材料原文，原文只载明寄样与佣金比例区间，未载明达人确认或签署，该拟稿句未获支持。
2. 把跨向量模型的库强行共同关联。输入两个库的向量模型标识，比较是否一致，标识不一致时应排除，不执行跨模型检索来比较漏召回。
3. 把最低相关度当作权限或实体过滤。输入无关业务问题，比较返回结果，相关度阈值不排除未授权记录，检索不承担授权判断。

## 怎么确认配好了

1. 输入拟稿句“达人A已确认商品X的佣金比例并完成专场合作”，比较材料原文中寄样日期、佣金比例区间与有效期间，若原文未载明达人确认或合作签署，判定为未获支持，保留证据缺口。
2. 输入两个待关联知识库的向量模型标识，比较两者是否一致，标识一致方可共同关联，标识不一致时记录并排除，不推断运行结果。
3. 输入一条明确纸面空结果承接场景，核对下游设计是否接受长度为 0 的引用数组，空结果链路走通即满足条件，不声称虚构规则检索一定返回空数组。
