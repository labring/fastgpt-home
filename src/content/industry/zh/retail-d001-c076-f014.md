# 达人佣金结算与扣佣的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

在达人佣金结算与扣佣的商品资料与选型问答中，本页说明FastGPT的模型接入与配置如何衔接资料。让佣金问答分别读取约定、争议说明与结算意见，核谁提出扣佣及哪些尚未确认。所用场景为自拟文字测试。

## 这些特征在「模型接入与配置」这一环带来什么约束

自拟佣金选型材料可由合作约定、运营备注与达人回信组成。约定只说退单事项另核，运营备注提出本场存在待核订单，达人回信要求逐单说明；当前没有双方确认的扣佣清单。选择接入模型时，可用这三段文字核它实际收到哪些资料，能否分清约定条件、内部主张和对方请求。回答应按订单证据解释待核范围，不能从“另核”直接给出扣佣结论。这里比较的是阅读这类文本的输入与输出，不为任何模型宣称核算能力或准确率。

## 配置怎么定

| 佣金阅读核对 | 自拟材料 | 保留的证据 |
| --- | --- | --- |
| 条件 | 退单另核约定 | 不扩大成扣佣决定 |
| 内部主张 | 本场订单待核 | 作者及场次 |
| 对方请求 | 逐单说明回信 | 请求实际传入 |
| 清单对象 | 别场与本场分开 | 订单及约定版本 |
| 输入形式 | 文字与图片附件 | 各路径分别复测 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `AI Proxy依赖` | 按实际版本核服务、渠道与应用。 |
| `AIPROXY_API_ENDPOINT` | 使用AI Proxy服务根地址。 |
| `AIPROXY_API_TOKEN` | 管理员Token非空且与服务端一致。 |
| `模型能力` | 按实际输入路径验证所需能力。 |
| `应用参数` | 接口同名字段未必覆盖应用设置。 |

## 容易做错的三处

- 服务已有返回而达人回信未进入请求时，保留三份资料清单和实际输入，定位选择或传入遗漏；缺少对方请求会使争议范围无法复核。

- 内部待核备注被写成达人已认可扣佣时，对照作者、动词和回信，检查认可结论从哪份原文增加。

- 另一场结算清单被用来确定本场扣佣时，核场次、订单及约定版本，未给对应明细仍保持待核。

## 怎么确认配好了

验收先只给合作约定，再加入运营备注，最后加入达人回信，分别问谁作了何种表述、当前能核哪批订单。记录各次原文送达与采用句，补齐材料后只应改变被支持的部分。若改用图片形式的结算附件，另测该实际输入路径，文字练习结果不能覆盖图片读取。连接服务所用凭证只解决模型通道条件；真实结算资料的读取范围和业务确认仍需单独安排，本页不处理扣款或回写账单。
