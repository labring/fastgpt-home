# 进出口许可证件办理的商品资料与选型问答：文档解析与分块

## 这个品类的数据长什么样

许可证件办理发生在申报之前，决定货物能否合法进出口，这一时序位置使文档解析与分块的准确性直接关联后续通关。主要数据来源包括商务主管部门系统、海关商品编码、供应商资料与客户用途说明；日常处理的文档为自动进口许可证、两用物项许可证、合同、产品说明。这些材料篇幅差异大，许可证含证件编号与监管条件，合同含主体与标的，产品说明含用途与技术参数。

数据更新频率为不定期、每票，资料变更后需重新核对实际训练与索引状态，上传成功不能直接视为检索已更新。最耗时的环节是判断监管证件、准备用途说明、跟进审批状态，这些环节依赖对原文结构与条件的完整保留。

## 这些特征在「文档解析与分块」这一环带来什么约束

解析需先核对原文结构，保留能回指原文的文档身份与版本。分段按具体资料结构进行，条件、说明与所约束的内容不能被拆离。原数据与检索索引需区分，同一组原数据可对应多个索引，一组数据可对应多个向量。检索时先召回向量，再按向量 ID 去 MongoDB 寻找原数据，对应同一组则合并，向量得分取最高得分。

语义检索依赖向量距离，全文检索依赖关键词命中，混合检索通过 RRF 融合两路结果。RRF 是融合过程，不是可开启的开关。最低相关度仅在语义检索或使用结果重排时生效，是过滤阈值，不是排序规则。引用上限按 tokens 控制，不采用 top k。问题优化在检索前增加一次模型调用，用于指代消除与问题扩展，会提升连续对话效果并增加耗时。图片检索需要图像输入与相应模型能力，重排需要模型且按设置启用，两者都不是每次请求必然执行。

检索或表单收集值不构成授权；业务核验、审批、数据库写入与外部同步需要各自的下游实现。跨不同向量模型的库不可共同关联，只能核对标识并排除不符合者。

## 配置怎么定

以下围绕假设演练样本列出与本功能、主任务相关的官方已说明设置或实施核对项。

假设演练样本：某外贸合规岗准备一份自动进口许可证材料，原文为“许可证编号：AUTO-2024-0731；商品名称：数控机床；监管条件：需自动进口许可证；持证主体：某机械进出口有限公司；有效期至2024年12月31日。”另有一条待判定拟稿句：“该许可证已覆盖本次数控机床进口，可在申报前直接使用。”样本标注为假设演练，不指向真实主体或证件。

| 配置项 | 官方已说明依据 | 本样本取值与理由 |
| --- | --- | --- |
| 搜索模式 | 语义检索、全文检索、混合检索三种 | 选混合检索，编号与自然语言问法并存 |
| 引用上限 | 按 tokens 控制，非 top k | 假设起点 3000 tokens，因许可证与合同片段较长，与默认值比较后调整 |
| 最低相关度 | 0-1 数值，仅语义检索或重排时生效 | 假设起点 0.4，与检索结果观察值比较 |
| 结果重排 | ReRank 生成 0-1 得分，可按得分过滤 | 启用，用于候选较多时二次排序 |
| 问题优化 | 检索前指代消除与问题扩展 | 开启，样本含多轮追问可能 |
| 数据与索引核对 | 原数据与索引区分，同组可多索引 | 每票资料变更后核对训练与索引状态 |

## 容易做错的三处

1. 把上传成功当作检索已更新。输入为样本许可证上传动作，比较对象为实际训练与索引状态，观察结果是检索能否命中该证件编号；上传成功与索引生效是两件事。
2. 把最低相关度当作权限或实体过滤。输入为最低相关度设置值，比较对象为返回内容是否属于目标证件，观察结果是无关证件是否被排除；相似度设置不承担授权或实体隔离功能。
3. 把待审核状态当作已获授权。输入为样本拟稿句“可在申报前直接使用”，比较对象为原文是否载明授权或生效条款，观察结果是原文未载明该内容；待审核不证明缺少权限，也不等于已批准。

## 怎么确认配好了

1. 输入样本许可证原文与拟稿句，比较原文是否含“可在申报前直接使用”的授权表述，观察结果为原文仅载明编号、商品、监管条件、主体与有效期，未载明该授权；满足条件为拟稿句被标记为未获支持。
2. 输入证件编号“AUTO-2024-0731”执行全文检索，比较返回片段是否保留编号与监管条件在同一分段，观察结果为编号与条件未被拆离；满足条件为分段可回指原文。
3. 输入空结果纸面输入[]，比较下游设计对空引用的处理，观察结果为系统按空引用输出；满足条件为不将空结果解释为证件不存在。以上均为纸面核对，不声称已实测。
