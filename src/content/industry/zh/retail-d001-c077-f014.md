# 进出口许可证件办理的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

许可证办理发生在申报之前，决定该批货物能否合法进出口。日常要处理的文档包括自动进口许可证、两用物项许可证、合同和产品说明。这些文档来自商务主管部门系统、海关商品编码、供应商资料和客户用途说明，更新不定期，每票业务单独处理。

商品资料与选型问答需要把这些文档整理成可检索的知识，再通过模型回答商品归类、证件选型等问题。模型接入与配置决定问答能否正常运行。系统至少需要一个语言模型和一个索引模型才能使用。AI Proxy 为必需依赖，App 和复用 App/Service 配置的 Admin 服务都必须设置 AIPROXY_API_ENDPOINT 和非空的 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。

## 这些特征在「模型接入与配置」这一环带来什么约束

许可证文档涉及商品名称、规格、用途和监管条件，问答需要准确引用原文。模型配置中的 maxContext、maxResponse、quoteMaxToken 决定单次请求能容纳的上下文和回复长度。索引模型的 defaultToken 和 maxToken 影响文本分割和向量化。

模型渠道配置需要填写渠道名、协议类型、模型、模型映射、代理地址和 API 密钥。代理地址填写 BaseUrl，不填完整请求地址。模型测试可以检查渠道是否有效。模型状态探测仅针对已启用的系统模型，探测请求首次失败后最多重试 3 次，4 次全部失败才判定异常。

假设演练样本：某外贸合规人员整理了一份商品资料，原文为「商品名称：不锈钢法兰；规格：DN50 PN16；用途：用于化工管道连接；监管条件：需自动进口许可证」。待判定拟稿句为「该商品需要办理两用物项许可证」。此样本仅用于说明核对方法，不涉及真实客户或实际业务。

## 配置怎么定

配置围绕商品资料与选型问答任务，只列与本功能相关的设置或核对项。

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | `http://aiproxy:3000` | 文档要求填写服务根地址，不附加 `/v1`；与文档示例比较格式 |
| AIPROXY_API_TOKEN | 非空字符串 | 文档要求非空且与服务端一致；核对是否为空 |
| 语言模型 maxContext | 125000 | 文档字段说明中的示例值；与商品资料实际 token 量比较 |
| 语言模型 quoteMaxToken | 120000 | 文档字段说明中的示例值；与 maxContext 比较，需小于等于 |
| 索引模型 defaultToken | 512 | 文档字段说明中的示例值；与文本分割设置比较 |
| 索引模型 maxToken | 3000 | 文档字段说明中的示例值；与 defaultToken 比较，需大于 |

模型 ID 全局唯一，模型名可自定义。模型渠道优先级范围 1～100，数值越大越优先。渠道测试输出每个模型的测试结果和请求时长。

## 容易做错的三处

1. 把 AIPROXY_API_ENDPOINT 填成完整请求地址。文档要求填写服务根地址，不附加 `/v1` 或 `/chat/completions`。检查输入值是否以 `/v1` 结尾，若是则需去掉。

2. 把 quoteMaxToken 设置得大于 maxContext。文档字段说明中 quoteMaxToken 为 120000，maxContext 为 125000。检查两者数值，quoteMaxToken 应小于等于 maxContext。

3. 用应用 API Key 代替 AIPROXY_API_TOKEN。文档要求 AIPROXY_API_TOKEN 为 AI Proxy 管理员 Token，必须与服务端配置一致且不能为空。检查 Token 是否为空，是否与服务端配置一致。

## 怎么确认配好了

1. 核对 AIPROXY_API_ENDPOINT 输入值。输入假设样本中的 `http://aiproxy:3000`，比较该值是否以 `/v1` 结尾。若不以 `/v1` 结尾，符合文档要求；若以 `/v1` 结尾，需修改。

2. 核对 quoteMaxToken 与 maxContext 的大小关系。输入假设样本中的 quoteMaxToken 120000 和 maxContext 125000，比较两者数值。若 quoteMaxToken 小于等于 maxContext，符合文档字段说明；若大于，需调整。

3. 核对 AIPROXY_API_TOKEN 是否非空且与服务端一致。输入假设样本中的非空字符串，比较该值是否为空、是否与服务端配置相同。若非空且一致，符合文档要求；若为空或不一致，需修改。

模型状态探测可观察模型健康状态，但探测结果不替代配置核对。检索结果不负责权限或实体隔离，相关度分数不是权限过滤器。空结果可用明确的纸面输入 `[]` 核对下游设计，不能声称虚构规则检索一定返回空数组。
