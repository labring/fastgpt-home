# 连锁门店价格与陈列稽核的商品资料与选型问答：模型接入与配置

## 这个品类的数据长什么样

价格与陈列稽核发生在日常经营期，重点是标准持续执行。巡店照片、价签清单、陈列标准、整改通知构成主要文档集合，更新频率为周或月。商品资料与选型问答要求从这些材料中提取商品名称、规格、价签状态与陈列位置，再回答选型或整改问题。

模型接入与配置在此处的直接约束是：问答质量取决于所接入模型能否读图、能否稳定处理中文价签文本，以及索引模型能否把商品资料切分为可检索片段。FastGPT 借助 AI Proxy 连接模型提供商，系统至少需要一个语言模型和一个索引模型才能正常使用。语音识别模型仅生效一个，本任务不涉及。

## 这些特征在「模型接入与配置」这一环带来什么约束

从 V4.17.0 起，AI Proxy 为必需依赖。App 和复用 App/Service 配置的 Admin 服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空的 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。

模型能力按应用所需输入核对。使用照片时核视觉能力；价签文本提取按实际模式核工具能力，两项工具能力均不支持时文档还给出提示词模式。`vision`、`toolChoice`、`functionCall` 在模型配置中分别声明，不能假设同名对话接口字段会覆盖编排。

索引模型决定商品资料能否被检索。`defaultToken` 是文本分割时使用的 token 值，`maxToken` 是最大 token。两者是索引模型字段，按实际模型与分块核对，不能由向量库名称推定取值。

模型探测仅针对已启用的系统模型。未启用模型不参与探测。探测首次失败后最多自动重试 3 次，4 次全部失败才判定异常。

## 配置怎么定

以下为假设演练样本。材料原文：某连锁品牌运营部 2026 年 3 月《巡店照片归档说明》载明“价签照片须含商品正面与价签同框，拍摄日期在巡店当日”。另一份《价签清单》表头为“门店编号、商品名称、规格、标价、生效日期”。待判定拟稿句：“该门店 3 月 12 日价签照片显示标价 9.9 元，与清单生效日期一致，可确认价格执行正确。”

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填写 AI Proxy 服务根地址，不附加 `/v1` | 与文档示例格式比较，确认无多余路径 |
| `AIPROXY_API_TOKEN` | 填写与服务端一致的非空管理员 Token | 核管理员Token来源及服务端一致性，应用Key用途另核 |
| 语言模型 `vision` | 设为 `true` | 与巡店照片输入需求比较，确认支持图片 |
| 语言模型 `toolChoice` | 设为 `true` | 与价签字段提取需求比较，确认支持工具选择 |
| 索引模型 `defaultToken` | 本次假设试验起点 512 | 与商品资料片段长度比较，观察切分是否完整 |
| 模型探测间隔 | 本次假设试验起点 30 分钟 | 与 5～60 分钟可配范围比较，确认在区间内 |

## 容易做错的三处

1. 把 `AIPROXY_API_ENDPOINT` 写成完整模型请求地址并附加 `/v1`。文档要求填写服务根地址。检查方式：读取该变量值，与“根地址、无 `/v1`”比较，出现 `/v1` 即不满足。
2. 把应用 API Key 填入 `AIPROXY_API_TOKEN`。文档要求管理员 Token 且非空。检查方式：比对所填值与服务端管理员 Token，不一致或为空即不满足。
3. 把旧探测历史当作未启用期间的新探测。按文档，未启用模型不参与探测；核启用状态及记录时间，只检查未启用期间是否产生新记录，不能因存在旧历史直接判错。

## 怎么确认配好了

1. 输入假设样本中的拟稿句与两份材料原文。比较拟稿句所称“价格执行正确”与材料实际载明内容。材料只说明照片须含商品与价签同框、清单含生效日期，未载明该门店该日实际标价与清单一致。预期现象：拟稿句的结论未获材料支持，应标记为待核实。

2. 待取得实际巡店照片后，核所选模型的 `vision` 声明及上游图片支持，再按相同图片测试实际输入与结果。只有归档说明不能证明照片已处理；声明值也不能替代实际调用验证。

3. 输入价签清单文本与索引模型 `defaultToken` 设定值。比较切分后片段是否覆盖完整商品行。预期现象：片段截断导致规格或标价缺失时，需调整该值后重新核对。检索结果为空时，可用明确的纸面输入 `[]` 核对下游设计，不声称虚构规则必然返回空。

模型探测告警仅在状态边沿变化时推送，持续异常不重复推送。检索不承担授权职能，相似度设置不排除未授权记录。
