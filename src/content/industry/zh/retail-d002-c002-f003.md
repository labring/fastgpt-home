# MCN机构达人管理的订单履约与售后答疑：分享与嵌入

## 这个品类的数据长什么样

在MCN机构达人管理的订单履约与售后答疑中，本页说明FastGPT的分享与嵌入如何衔接资料。向达人开放对应处理摘要时核其他账号资料，区分通知、申诉与实际结果。所用场景为自拟文字测试。

## 这些特征在「分享与嵌入」这一环带来什么约束

自拟服务入口拟给某达人一份待补材料摘要，不拟开放其他达人合同或内部审核记录。先用完整链接在接收环境核可读原文，再问别账号情况检查边界。若他人条款或处理信息被回答改写，应保存完整返回查授权；同属机构不说明共享有依据。入口标识可以定位对话，但不验证真实达人身份，也不说明接收者拥有全部长期账号资料的访问权。

## 配置怎么定

| 服务分享核对项 | 达人处理摘要 | 验收动作 |
| --- | --- | --- |
| 本账号范围 | 待补材料与当前事项 | 接收环境实际原文 |
| 受限来源 | 他人合同及内部审核排除 | 完整返回与拒绝范围 |
| 阶段区别 | 通知、申诉及恢复结果分开 | 不由跟进推撤销处置 |
| 跨设备 | 手机到电脑的账号及前问 | 缺对象补原问来源 |
| 执行分工 | 答复不申诉或改平台状态 | 另核结果及身份限制 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `免登录窗口` | 复制生成的完整分享链接。 |
| `过期时间与QPM` | QPM指每用户每分钟访问上限。 |
| `积分上限` | 按入口及版本核用量与费用条件。 |
| `身份验证` | 第三方认证受商业版范围限制。 |
| `对话记录边界` | 匿名标识依赖同设备、同浏览器。 |

## 容易做错的三处

- 本账号入口读出他人合同或审核记录：保存实际段落及完整返回查资源授权，同机构不说明跨达人资料已获准共享。

- 手机通知追问转到电脑却缺账号和前问：核实际历史，补当前原文，不预设匿名会话跨设备；借另一账号结果时保留错指证据。

- 通知、申诉提交或已跟进被写成账号恢复：回查正式结果及实际输入，结果未取得与取得未传入分开查，不能用摘要代替撤销处置。

## 怎么确认配好了

验收用本账号摘要、他人合同和内部记录分别做读取与拒绝测试，记录所见原句及当前版本的限制。需要外部达人身份验证时，另验商业版能力与接口返回，不从链接识别账号持有人。答复可以整理待补步骤，不提交申诉或修改平台状态，合作责任和恢复结果须回到实际通知与责任人确认。分享对话结束不等于账号问题已解决，保留未知状态。
