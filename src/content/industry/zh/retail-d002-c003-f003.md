# Shopify独立站订单履约的订单履约与售后答疑：分享与嵌入

## 这个品类的数据长什么样

在Shopify独立站订单履约的订单履约与售后答疑中，本页说明FastGPT的分享与嵌入如何衔接资料。分享独立站订单进度时核单据范围，区分标签创建、承运事件与退款结果。所用场景为自拟文字测试。

## 这些特征在「分享与嵌入」这一环带来什么约束

自拟售后入口拟开放本单进度摘要，不开放完整买家地址、支付附页和其他订单。通过渠道完整链接先问包裹进度，再请求限制资料，保存接收环境实际原文。若回答转述他单退款或地址，应查资源范围，不能因页面没有附件就判已隔离。链接只给入口位置，不验证买家身份，也不说明持有人应能读全部履约及支付资料，拟开放范围需实际测试。

## 配置怎么定

| 分享入口核对项 | 独立站进度来源 | 验收证据 |
| --- | --- | --- |
| 本单摘要 | 不含完整地址及支付附页 | 接收环境实际原文 |
| 限制测试 | 他单退款及地址不开放 | 完整返回及拒绝 |
| 事件区别 | 标签创建不证明交付 | 物流原句与答复 |
| 手机承接 | 订单和前问是否带入 | 缺对象补原材料 |
| 处理状态 | 缺事件与传入遗漏分开 | 另查系统结果及入口限制 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `免登录窗口` | 复制生成的完整分享链接。 |
| `过期时间与QPM` | QPM指每用户每分钟访问上限。 |
| `积分上限` | 按入口及版本核用量与费用条件。 |
| `身份验证` | 第三方认证受商业版范围限制。 |
| `对话记录边界` | 匿名标识依赖同设备、同浏览器。 |

## 容易做错的三处

- 本单摘要转述他单地址或支付资料：保存完整返回与所用资源，附件不显示不能证明未暴露，完整链接也不认证买家身份。

- 电脑标签追问到手机后缺订单指代：核手机历史及前问，补本单原文；匿名记录不自动跨设备，不能猜包裹对象。

- 标签创建被写成揽收或已送达：并列标签与承运事件，查该句来源；事件已有未传入则查送达，未取得则补源，不从对话结束判履约。

## 怎么确认配好了

验收对本单摘要、别单及受限支付来源分别做读拒测试，再核适用版本的期限、每用户访问及用量条件。需要身份验证时另验商业版能力与返回。结果记录应区分输入漏了已有事件与事件原文尚未取得；两者都不靠延长链接期限解决。分享可以整理待补信息，不买标签、不退款或同步履约。已送达、已退款等状态仍从实际系统记录确认，不能由结束对话代替。
