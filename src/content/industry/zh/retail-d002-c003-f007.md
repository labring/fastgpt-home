# Shopify独立站订单履约的订单履约与售后答疑：对话日志与审计

## 这个品类的数据长什么样
Shopify独立站由商家自行配置支付、运费和履约服务，不由平台统一自动退货。这一差别使订单详情、运费模板、发货标签、退款记录分散在Shopify Admin、支付网关、承运商系统与库存地点数据中，每单与每日都在更新。对话日志与审计要处理的正是这些材料与对话记录之间的对应关系：订单号、退款记录、发货标签状态需要与具体会话的chatId、dataId对齐，才能判断某次答疑发生在哪个履约阶段。数据来源分散意味着日志本身不会自动包含订单状态，核对时需要把业务材料原文与接口返回字段并列查看。

## 这些特征在「对话日志与审计」这一环带来什么约束
日志存在不等于完成合规审计。对账、留存与合规要求由完整业务方案另行落实，本页只处理对话记录的读取、核对与交接判断。检索与相似度分数不承担权限或实体隔离职责，score与similarity只反映召回排序，不能用来排除无关商家或未授权记录。对话接口的detail参数决定是否返回中间值，未设置detail时responseData不出现，字段含义需以接口实际返回为准，未返回的业务数据不能推定已完整留存。测试模式与正式调用的身份字段可能不同，两者需分别核对输入、历史与返回内容。

假设演练样本：材料原文为“订单#SHP-2041，2024年10月13日创建，退款记录状态为‘申请中’，发货标签已购买未交运”。一条待判定的交接请求为“请确认该订单已完成退款并终止履约”。判定所需主体是订单#SHP-2041，对象是退款记录与发货标签，状态分别是申请中与已购买未交运，有效范围是2024年10月13日。退款记录处于申请中，未显示完成；发货标签已购买未交运，未显示终止。该交接请求中的“已完成退款”“终止履约”均未获材料支持，属于待核实，不能按完成处理。授权边界为：仅可读取该订单对应会话的对话记录，不得据此写入退款或取消标签。

## 配置怎么定
配置围绕该样本的读取与核对展开，只列官方已说明的设置或实施核对项。数值为本次假设试验起点，用于与接口实际返回值比较，不作为官方默认值。

| 配置项 | 本次假设起点 | 选择理由与比较对象 |
| --- | --- | --- |
| detail | true | 需要responseData中的模块运行详情，与detail=false时无responseData比较 |
| stream | false | 便于一次取得完整choices与responseData，与stream=true的event分片比较 |
| chatId | 样本订单对应会话ID | 用于按会话取历史，与另一订单的chatId比较以确认未混算 |
| source | api | 获取通过API创建的会话，与页面会话来源比较 |
| pageSize | 10 | 假设起点，用于分页取对话列表，与total值比较确认是否取全 |
| loadCustomFeedbacks | true | 读取自定义反馈，与不传该参数时反馈字段缺失比较 |

chatId需自行确保唯一且长度小于250。responseChatItemId在当前chatId下需唯一。variables用于替换模块输入框中的[key]。authProxy代理身份仍需具备目标应用和会话权限。交互节点返回的interactive只含type与params，内部运行态字段不返回。

## 容易做错的三处
1. 把申请中的退款记录当作已完成退款。输入为样本材料原文与交接请求，比较退款记录状态字段与“已完成”表述，可观察结果是材料只显示申请中，判定应为待核实。
2. 把已购买未交运的发货标签当作已终止履约。输入为发货标签状态与请求中的“终止履约”，比较两者，可观察结果是标签未显示取消或终止，判定应为未获支持。
3. 用similarity或score排除其他订单记录。输入为召回列表中的score值与订单号，比较score与订单归属，可观察结果是score不携带订单或权限信息，不能据此排除无关记录。

## 怎么确认配好了
1. 取样本材料原文与交接请求，输入detail=true、stream=false的对话请求，比较返回的responseData中是否出现对应模块运行详情，出现即满足读取条件，未出现则记录字段缺口。
2. 取chatId与订单号，比较该会话对话列表中的dataId与业务材料中的订单#SHP-2041，两者对应即满足同主体核对，不对应则记录会话与订单未对齐。
3. 取退款记录状态“申请中”与拟稿句“已完成退款”，比较状态字段取值，材料未载明完成即判定待核实，不因请求措辞而改写状态。空结果承接可用明确的纸面输入[]核对下游设计，不声称虚构规则检索一定返回[]。跨不同向量模型的库不可共同关联，先核标识并排除不符合者。
