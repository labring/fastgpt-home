# 加盟商培训与开业辅导的订单履约与售后答疑：分享与嵌入

## 这个品类的数据长什么样

在加盟商培训与开业辅导的订单履约与售后答疑中，本页说明FastGPT的分享与嵌入如何衔接资料。分享门店整改进度时保留本轮检查范围，不以签到、照片或入口状态认定完成。所用场景为自拟文字测试。

## 这些特征在「分享与嵌入」这一环带来什么约束

拟分享的门店进度可只列待补现场说明与已收到的整改文字，不放其他门店照片和总部内部检查意见。先用完整链接读接收环境原句，核门店及检查日期，再请求限制来源测试边界。课堂口令或入口访问不能验证店长真实身份，所需身份条件按商业版实际能力另验。进度材料来自哪次检查须保留，链接有效也不说明旧照片能代表门店当前现场。

## 配置怎么定

| 整改进度分享 | 门店检查来源 | 检查动作 |
| --- | --- | --- |
| 公开范围 | 本轮缺项和已收文字 | 门店日期及原句 |
| 限制来源 | 他店照片与内部意见 | 完整回答和拒绝 |
| 设备承接 | 整改问题对应哪次检查 | 历史及补问 |
| 阶段区别 | 收到材料不等复核通过 | 真实复核及责任确认 |
| 处理执行 | 分享不登记考勤或关闭 | 业务权限及回执 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `免登录窗口` | 复制生成的完整分享链接。 |
| `过期时间与QPM` | QPM指每用户每分钟访问上限。 |
| `积分上限` | 按入口及版本核用量与费用条件。 |
| `身份验证` | 第三方认证受商业版范围限制。 |
| `对话记录边界` | 匿名标识依赖同设备、同浏览器。 |

## 容易做错的三处

- 本店摘要返回他店照片或内部检查意见：保存来源说明及完整回答查授权，同一督导管理不意味着可以跨店公开。

- 电脑问检查缺项、手机问“整改完成了吗”无门店和前题：核实际历史补检查对象，匿名标识不自动跨设备，不借最近门店回答。

- 收到签到或照片被写成整改已核实完成：另取本轮实际复核依据和责任确认，材料送达与检查通过是不同阶段。

## 怎么确认配好了

验收对本轮进度、他店照片和内部意见做读拒测试，保留实际原句与版本。新整改文字已取得却未入本轮输入，和现场复核尚未发生要分开；延长分享期限不能补执行。换设备测试缺对象追问，核是否要求补材料。分享只解释已有记录，不提交整改、登记考勤或关闭检查；正式处理仍靠业务权限、执行记录及真实回执，不由对话结束确认。
