# 商超供应商进场结算的订单履约与售后答疑：知识库检索与召回

## 这个品类的数据长什么样

在商超供应商进场结算的订单履约与售后答疑中，本页说明FastGPT的知识库检索与召回如何衔接资料。供应商售后中的外箱标识、内袋商品码和实物对应需要分开检索。所用场景为自拟文字测试。

## 这些特征在「知识库检索与召回」这一环带来什么约束

商超供应商售后可拟问询“包装码与商品描述不同，是发错货吗”，标签说明“外箱为组包标识”，内袋页“商品码另附”。当前没有内袋页正文或本批实物检查。检索需保留外箱与商品两个层级，组包标识不能直接与商品名称当同类字段比较，也不能由代码不同就判错发。用外箱标识、商品码及整题核候选，当前只能说明需要哪份对应资料，不补现实货物身份。

## 配置怎么定

| 材料核对项 | 本题具体条件 | 实施取证 |
| --- | --- | --- |
| 字段层级 | 外箱组包标识 | 不当商品本体。 |
| 内袋来源 | 另附未读 | 不补正文。 |
| 问题推断 | 不同不证错误 | 核优化强度。 |
| 适用批次 | 本商品本批 | 核实际引用。 |
| 实物缺项 | 没有本批检查 | 不判真实错发。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `搜索模式` | 支持语义、全文与混合模式。 |
| `引用上限` | 引用上限按token计。 |
| `最低相关度` | 范围0–1，仅语义或重排时生效。 |
| `问题优化` | 用于指代消除与问题扩展。 |

## 容易做错的三处

第一处是外箱说明被用来直接证明内物正确，应核候选覆盖的包装层级，标签用途不代实物。第二处是优化把不同写成商品不合格，应对前后问题强度，未核关系不构成已证错误。第三处是另一商品的内袋码页被本批采用，应核商品、批次及原文身份。三项分别查证据范围、问题推断和来源对应，不用相似标识、高分或文件齐名确定本批是否发错。

## 怎么确认配好了

验收分别问外箱码作用、内袋依据是否提供、实物观察还缺什么，展开真实引用。语义、全文和混合检索以同题比字段，token预算保留组包及另附限定。新内袋页加入后核本商品和批次，再查是否实际送给回答，不能从上传成功判已核对。本练习不验货、不改编码或结算，不认定真实错发或质量问题；缺页时继续待核，也不由未返回推内袋没有商品码。
