# 外汇收结汇与贸易名录的订单履约与售后答疑：HTTP 接口与外部系统

## 这个品类的数据长什么样

本页只处理外汇收结汇与贸易名录场景下订单履约与售后答疑环节的 HTTP 接口与外部系统对接。该品类与信用证审单的差别在于，收结汇关注外汇资金和贸易背景真实性，不审全套信用证单据。日常材料包括收汇水单、贸易合同、发票、外汇业务登记资料，数据来源涉及国家外汇管理局政策、银行网银、企业财务账和海关出口数据。这些材料在订单履约与售后答疑中要经由 HTTP 接口传给外部系统时，接口只负责传输和解析字段，贸易背景真实性核验、名录分类判定和资金入账确认属于下游业务实现，接口调用本身不构成授权。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向对应地址发送请求，实际操作与 Postman、ApiFox 这类工具接近。Params 为路径请求参数，GET 请求中用得居多；Body 为请求体，POST/PUT 请求中用得居多；Headers 为请求头，用于传递特殊信息。三类数据均可通过 `{{}}` 引用变量，URL 也可引用变量，变量来自全局变量、系统变量和前方节点输出。返回值配置不代表接口返回值，而是通过 JSON path 语法提取接口响应的值；输出类型选字符串时，会将对应 key 的值转成 json 字符串输出。对话接口使用 APIKey 鉴权，调用 `chat/completions` 时推荐在请求体传入 `body.appId`，appId 优先级为 `body.appId`、`<apiKey>-<appId>`、apikey 关联的 appId。传入的 `model`、`temperature` 等字段无效，由编排决定。交互节点返回的 `interactive` 只含 `type` 和 `params`，`entryNodeIds`、`memoryEdges`、`nodeOutputs`、`nodeResponseId` 等内部运行态字段不返回。表单收集值，业务核验、审批、数据库写入和外部同步需要各自的下游实现。

## 配置怎么定

假设演练样本：某外贸企业财务人员提交一份收汇水单核对请求，材料原文为“收汇水单显示付款方为 ABC TRADING，金额 USD 50,000，收款方为某出口企业，申报单号尾号 4821；贸易合同编号 HT-2024-031，合同金额 USD 50,000，签署日期 2024 年 3 月 10 日”。待判定拟稿句为“该笔收汇已核对贸易背景真实性，可办理结汇”。此样本仅用于纸面核对，不代表任何实际业务动作已完成。

| 配置项 | 本次假设试验起点 | 选取理由与比较方法 |
| --- | --- | --- |
| 请求地址与方法 | 按外部接口文档填写，地址引用变量 | 与外部接口契约逐字比对，核对方法为人工查阅文档 |
| Params 与 Headers | 鉴权凭证经安全配置注入 | 与接口文档要求比对，不写入公开样例 |
| Body 结构 | 按外部接口契约组织 JSON | 逐字段核对键名与值类型，与文档示例比对 |
| 变量引用 | 引用前方节点输出或全局变量 | 逐项核对实际传入值，与节点输出比对 |
| 返回值提取 | 按 JSON path 配置 key | 与接口响应结构比对，核对待提取字段路径 |
| 调试身份字段 | chatId 与 responseChatItemId 测试模式下不存在 | 核对运行模式，不将调试空值当作业务故障 |

## 容易做错的三处

1. 将接口返回值配置当作接口本身返回值。返回值配置是通过 JSON path 提取响应值的规则，输入为接口原始响应，比较对象为配置的 key 路径，可观察结果为提取出的值是否与响应中对应字段一致。
2. 在测试模式下将 chatId 或 responseChatItemId 缺失判定为业务故障。输入为测试模式请求，比较对象为文档说明的测试模式字段不存在，可观察结果为请求是否按文档预期运行。
3. 将表单提交或接口调用当作授权执行。输入为拟稿句或交接请求，比较对象为材料原文中的主体、对象、状态与有效范围，可观察结果为拟稿句是否超出原文支持范围。上述样本中，原文只显示收汇水单与合同金额一致，未载明贸易背景真实性核验结论，拟稿句超出原文支持范围。

## 怎么确认配好了

1. 输入上述假设样本原文与拟稿句，比较拟稿句是否与原文主体、金额、单号一致，观察结果为拟稿句包含原文未载明的核验结论，判定为未获支持。
2. 输入一条请求体含 `body.appId` 的调用，比较 appId 优先级规则，观察结果为接口按 `body.appId` 取值，与文档说明一致。
3. 输入一条测试模式请求，比较 chatId 与 responseChatItemId 是否存在，观察结果为测试模式下两字段不存在，符合文档说明，不作为业务故障判定。以上均为纸面核对，未实际发起调用，实际结果需在有访问权的目标范围内观察。
