# 外贸出口退税申报的订单履约与售后答疑：分享与嵌入

## 这个品类的数据长什么样

出口退税申报在货物出口后做税务凭证匹配，主要数据来自电子税务局、出口退税申报系统、海关电子信息与财务账，日常文档包括出口退免税申报表、出口报关单、进货发票与收汇凭证。退税延迟、不得退税与税务风险是出错后果，因此订单履约与售后答疑中的分享与嵌入环节，核心在于核对外部协作方可查看的材料范围和授权状态。链接或检索结果不能充当业务授权凭证。更新频率为月或每批，本页不涉及批量同步或实时触发机制。

## 这些特征在「分享与嵌入」这一环带来什么约束

免登录窗口从发布渠道创建并复制系统生成的完整链接，链接标识仅用于访问，不能当成业务授权。身份验证受商业版范围限制，按官方接口返回成功状态与 uid；uid 为不含 "|"、"/"、"\\" 字符且不超过 255 字节长度的字符串，否则返回 Invalid UID。匿名本地标识依赖同一设备同一浏览器，跨设备记录需另行设计身份与会话管理。检索不是授权，相关度分数不承担权限或实体隔离功能。

假设演练样本：某外贸企业财务人员拟将一份出口退税申报材料分享给外部协作方核对。供核对的材料原文为：“出口报关单号 2024XXXX，出口日期 2024 年 3 月 15 日，商品名称钢制紧固件，数量 5000 件，申报状态为已申报未退税。”拟稿句为：“该报关单已完成退税，请协作方按已退税状态归档。”待判定请求为：将该分享链接的 authToken 设置为外部协作方编号，并允许其查看引用全文。

## 配置怎么定

| 配置项 | 本页对应设置或核对项 | 说明 |
| --- | --- | --- |
| 名称 | 仅用于记录展示 | 按官方说明填写，不承载业务授权含义 |
| 过期时间 | 按使用范围设置并核实际版本 | 超过该时间链接无法使用 |
| QPM | 每个用户每分钟最大访问次数 | 按官方说明设置，不推断默认值 |
| 积分上限 | 核对分享入口的用量限制及费用归属 | 部分参数受版本限制 |
| 身份验证 | 填写 POST 根地址，返回 success 与 uid | 受商业版范围限制 |
| 查看引用全文 | 按官方说明配置 | 与查看引用片段、下载来源原文并列 |

## 容易做错的三处

1. 把链接标识当成业务授权。输入为分享链接与 authToken，比较对象是身份验证接口返回的 success 与 uid，若 success 不为 true 仍继续操作，则授权状态未成立。
2. 把申报状态写成已完成退税。输入为材料原文中的“已申报未退税”，比较拟稿句中的“已完成退税”，两者在同一字段上取值不同，构成矛盾。
3. 把检索相关度当成权限过滤。输入为相似度分数，比较对象是访问范围，分数高低不改变某条记录是否属于当前协作方可见范围。

## 怎么确认配好了

1. 针对假设样本的拟稿句，输入材料原文与拟稿句，比较“已申报未退税”与“已完成退税”是否同字段互斥，出现取值不一致即判定拟稿句未获支持。
2. 针对 authToken 请求，输入外部协作方编号作为 authToken，比较身份验证接口返回的 success 是否为 true、uid 是否符合格式，success 不为 true 时记录为未通过。
3. 针对查看引用全文配置，输入该分享链接的引用查看设置，比较配置值与实际展示行为是否一致，若配置为关闭而仍展示全文，记录为待核实差异。缺失证据保持缺失，待审核不证明缺少操作权限。
