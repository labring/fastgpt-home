# 平台促销报名与价格管理的订单履约与售后答疑：引用来源与溯源

## 这个品类的数据长什么样

平台促销报名与价格管理围绕活动报名表、促销价审批单、库存锁定表、活动复盘表展开，核心数据是价格、库存和活动节奏。日常需要核算最低到手价、锁定活动库存、同步多平台价格。这些材料在订单履约与售后答疑环节被反复引用，引用来源与溯源要求回答中的价格、库存、活动状态能对应到具体文档原文。

## 这些特征在「引用来源与溯源」这一环带来什么约束

知识库搜索节点可关联一个或多个相同向量模型的知识库，引用内容以数组输出，长度允许为零。空数组意味着搜索链路走通但未命中内容，不表示工作流报错终止。最低相关度仅在语义检索或结果重排时生效，属于过滤阈值，不承担权限或实体隔离功能。检索本身不构成授权，表单收集值不等于审批或执行。

假设演练样本：材料原文为“2025年3月1日促销价审批单（编号 C-0301）载明：A 商品活动价 89 元，审批状态为待财务复核，有效期至 2025年3月7日。同日库存锁定表载明：A 商品锁定 200 件，锁定状态为已提交，未标注释放条件。”待判定拟稿句为：“A 商品活动价 89 元已获财务批准，库存 200 件已锁定可售。”该拟稿句将待复核写成已批准，将已提交写成已锁定可售，属于把未完成状态当作完成状态引用。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 促销审批与库存锁定资料库 | 核对已选库是否使用相同向量模型，不同向量模型的库不共同关联 |
| 搜索模式 | 混合检索 | 与语义检索单独使用比较，观察编号类查询是否命中原文 |
| 引用上限 | 本次假设起点 3000 tokens | 与默认引用上限比较，观察长审批单是否被截断 |
| 最低相关度 | 本次假设起点 0.3 | 与 0.5 比较，观察低相关片段是否进入引用数组 |
| 结果重排 | 启用 | 与不启用比较，观察候选较多时排序是否变化 |
| 引用内容输出 | 承接至回答节点 | 核对回答逐条对应引用原文，空数组时检查下游设计 |

## 容易做错的三处

1. 把待财务复核写成已获财务批准。输入为审批单原文“待财务复核”，比较拟稿句“已获财务批准”，观察结果是两者状态字段不一致。
2. 把库存锁定表的“已提交”写成“已锁定可售”。输入为锁定表原文，比较拟稿句，观察结果是锁定状态被改写。
3. 把报价有效期当作供货期限。输入为“有效期至 2025年3月7日”，比较拟稿句“可售”，观察结果是有效期与供货期限属于不同字段。

## 怎么确认配好了

1. 输入假设样本中的审批单原文与拟稿句，比较审批状态字段，拟稿句出现“已获财务批准”而原文为“待财务复核”时判定为未获支持。
2. 输入库存锁定表原文与拟稿句，比较锁定状态字段，拟稿句出现“已锁定可售”而原文为“已提交”时判定为状态改写。
3. 输入报价有效期原文与拟稿句，比较有效期字段与供货字段，拟稿句将有效期当作供货期限时判定为字段混用。
