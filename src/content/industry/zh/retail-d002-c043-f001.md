# 平台多店铺矩阵管理的订单履约与售后答疑：HTTP 接口与外部系统

## 这个品类的数据长什么样

平台多店铺矩阵管理涉及各平台商家后台、ERP 渠道价、品牌防伪系统与经销商报表等来源，从业主体包括品牌电商负责人、渠道运营与经销商电商团队。与单店广告投放相比，这一品类更关注跨店授权和价格秩序。资料给出的更新频率为日与月，本页仅在订单履约与售后答疑环节处理由外部系统传入或向外部系统发出的 HTTP 请求，不推导批量同步、全量同步或交易触发机制。日常文档为店铺授权清单、价格管控表、窜货投诉单与月度销售报表；这些文档在接口环节的作用是提供请求参数与核对依据，检索或表单本身不构成授权。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向对应地址发送请求，Params 用于路径请求参数，Body 用于请求体，Headers 用于请求头，三者均可通过 `{{}}` 引用变量，URL 也可引用变量。变量来自全局变量、系统变量与前方节点输出。系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories，其中 chatId 与 responseChatItemId 在测试模式下不存在，不能把调试空值当成业务故障。返回值配置用于解析接口响应，按 JSON path 提取，输出类型选字符串时会把对应 key 的值转成 json 字符串。

对话接口使用 APIKey 鉴权，调用 `chat/completions` 时推荐在请求体传入 `body.appId`，也支持 `Authorization: Bearer <apiKey>-<appId>`。appId 优先级为 `body.appId`、`<apiKey>-<appId>`、apikey 关联的 appId。传入的 `model`、`temperature` 等字段无效，由编排决定。`detail=true` 时返回中间值，`stream` 模式下通过 event 区分。插件调用默认 detail 模式，无需 chatId 与 messages，通过 variables 传输入，通过 `pluginOutput` 取输出。交互节点返回的 `interactive` 只含 type 与 params，内部运行态字段不返回。

假设演练样本：某品牌电商负责人持有《店铺授权清单》原文两条——“授权店铺：A 店、B 店；授权事项：订单查询与售后登记；授权有效期：2025 年 1 月 1 日至 2025 年 12 月 31 日。”待判定的交接请求拟稿句为：“请通过 HTTP 接口向外部售后系统提交 C 店订单退款登记。”判定所需材料为上述清单原文与该拟稿句，C 店未在授权范围内，该请求处于未获授权状态，不执行提交。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 与什么值比较 |
| --- | --- | --- |
| 请求地址 | 外部售后系统文档给出的地址，可引用变量 | 与外部接口文档列出的地址逐字符比较 |
| 请求方法 | 按外部接口文档选择 | 与方法字段声明比较 |
| Headers 鉴权 | 通过安全配置注入，不写入公开样例 | 与密钥使用规范比较 |
| Body 结构 | 按外部接口契约填写 JSON | 与契约字段逐项比较 |
| 返回值解析 | 按 JSON path 配置 key | 与响应示例结构比较 |
| appId 来源 | 请求体 `body.appId` | 与优先级规则比较 |

上述起点为本次纸面核对所选，用于与外部接口文档和密钥规范对照，不作为官方默认值。配置仅覆盖本页任务所需的请求构造与解析，不涉及数据库内部实现。

## 容易做错的三处

1. 把测试模式下不存在的 chatId 或 responseChatItemId 空值当作业务故障。检查方式：输入测试模式请求，比较返回中这两个字段是否存在，观察是否出现空值报错。
2. 将检索结果或表单提交当成授权执行。检查方式：输入上述假设清单原文与拟稿句，比较 C 店是否在授权范围内，观察拟稿句是否被标记为未获授权。
3. 在 Body 中引用字符串变量时漏加双引号，导致解析结果与预期类型不符。检查方式：输入含字符串与数字的变量组，比较最终解析的字段类型，观察字符串是否被当作裸值。

## 怎么确认配好了

1. 输入上述假设清单原文与拟稿句，比较 C 店与授权店铺列表，若 C 店不在列表内且拟稿句被标记为未获授权，则满足条件；若清单未载明 C 店，则记录为未获支持。
2. 输入一条按外部接口文档构造的请求，比较请求地址、方法与 Headers 鉴权是否与文档一致，观察返回值解析的 key 是否与响应示例结构对应。
3. 输入测试模式请求，比较 chatId 与 responseChatItemId 是否不存在，观察是否被误判为业务故障；若返回中无这两个字段，记录为符合文档说明。

以上为纸面核对，未实际执行请求、提交或部署。相似度与检索结果不承担权限或实体隔离职责，检索不构成授权。缺失字段保持未知，待审核状态不表示缺少操作权限。
