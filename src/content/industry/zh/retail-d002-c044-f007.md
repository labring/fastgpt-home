# 平台广告投放与站内流量的订单履约与售后答疑：对话日志与审计

## 这个品类的数据长什么样

广告投放按流量与转化实时调价，订单履约与售后答疑的对话因此分散在多个来源：巨量千川、京东快车、阿里妈妈带来的成交数据，以及店铺自身的履约记录。同一笔订单的咨询可能先在投放落地页产生，再转到站内客服，对话日志需要按 chatId 归并，不能把不同入口的会话混算。投放数据更新到日或小时级，但对话日志与审计环节本身不因此改变取数方式，按需拉取即可。

## 这些特征在「对话日志与审计」这一环带来什么约束

对话身份以 chatId 为准。官方文档说明，chatId 为 `非空字符串` 时使用该 ID 进行对话，自动从数据库取会话，并以 messages 数组最后一个内容作为用户问题，其余 message 被忽略；不传入 chatId 时完全不使用上下文功能。核对目标对话与业务记录时，须先确认 chatId 唯一且长度小于 250。

运行详情需要按官方契约设置 `detail=true`，非 stream 模式下结果保存在 `responseData`，其中包含 moduleName、moduleType、runningTime、tokens、quoteList、completeMessages 等字段。未返回的业务数据不能推定已完整留存。日志存在不等于完成合规审计，对账、留存与合规要求由完整业务方案另行落实。

假设演练样本：某投放专员在 2025 年 3 月 10 日核对一笔站内订单的售后答疑。供核对的材料原文为：「订单 A-20250310-07 的买家在 chatId `usdAP1GbzSGu` 下询问退款进度，客服回复『已提交审核』。该会话由 API 创建，source 为 api。」一条待判定的拟稿句为：「该订单退款已完成。」核对对象是 chatId `usdAP1GbzSGu` 下的对话记录与订单 A-20250310-07 的履约状态。授权边界为：仅核对，不执行退款或修改订单状态。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| chatId | `usdAP1GbzSGu` | 取自样本材料，长度小于 250；与订单号 A-20250310-07 逐字比对，确认同一会话 |
| detail | true | 需要 responseData 中的 moduleName、tokens 等字段；与 detail=false 的返回结构对比，确认字段存在 |
| stream | false | 便于直接读取 responseData；与 stream=true 的 event 区分方式对比 |
| source | api | 样本会话由 API 创建；与页面会话的 source 取值对比，排除非 API 来源 |
| loadCustomFeedbacks | true | 需要读取自定义反馈；与不传该参数时的返回对比，确认 customFeedbacks 字段 |
| pageSize | 10 | 本次假设试验起点，覆盖样本对话；与 total 字段比较，确认未遗漏记录 |

## 容易做错的三处

1. 把 chatId 为空的请求当作同一会话。官方文档说明不传入 chatId 时完全不使用上下文功能，完全通过 messages 构建上下文。若把这类请求与 `usdAP1GbzSGu` 的会话合并统计，对话身份即被混淆。核对时须逐条检查 chatId 是否非空且一致。
2. 把 responseData 中未出现的字段当作已留存。官方文档说明不同模块的响应值可能有差异，建议先 log 自行查看最新值。若样本中 responseData 未返回某业务字段，不能推定该数据已完整留存。核对时须以实际返回的字段名为准。
3. 把「已提交审核」当作退款完成。样本材料中客服回复为「已提交审核」，拟稿句为「该订单退款已完成」。审核中与已完成是同一字段的不同取值，二者互斥。核对时须比较订单状态字段的实际取值，未载明完成时间或完成凭证时，判定为待核实。

## 怎么确认配好了

1. 输入：样本材料中的 chatId `usdAP1GbzSGu` 与订单号 A-20250310-07。比较：对话记录中的 chatId 与订单记录中的 chatId 是否逐字一致，且长度小于 250。观察：两者一致时满足条件；出现不一致或 chatId 为空时，记录为身份未确认。
2. 输入：detail=true、stream=false 的请求与样本对话。比较：responseData 中实际返回的 moduleName、moduleType、tokens 等字段与预期核对清单。观察：字段存在且可读取时满足条件；字段缺失时记录为未返回，不推定已留存。
3. 输入：拟稿句「该订单退款已完成」与订单 A-20250310-07 的状态字段。比较：状态字段的实际取值与「已完成」是否一致。观察：状态字段明确为已完成时满足条件；状态为「已提交审核」或未载明时，判定为未获支持，保留证据缺口。
