# 平台广告投放与站内流量的订单履约与售后答疑：知识库检索与召回

## 这个品类的数据长什么样

广告投放按流量和转化实时调价，文档围绕投放计划、关键词报表、人群包说明与转化归因表展开，更新频率为日或小时。订单履约与售后答疑场景中，检索请求常涉及某笔订单对应的投放来源、退款进度或关键词承诺，这些内容散落在不同文档里，需要按主体、对象与状态精确召回。知识库搜索节点可关联一个或多个使用相同向量模型的知识库，跨模型的知识库不能共同关联。检索环节只负责找到引用内容，不判断授权状态，也不执行退款或修改投放计划。

## 这些特征在「知识库检索与召回」这一环带来什么约束

一次检索会组合语义召回、全文召回、图片描述或图片向量召回、问题优化与重排，再经相似度过滤和引用上限裁剪。搜索模式按测试问题比较，不预设一种模式适合全部资料。引用上限以 token 为单位，最低相关度仅在语义检索或使用结果重排时生效。问题优化用于指代消除和问题扩展，会增加一次模型调用。检索结果以数组输出，长度可以为 0，空结果链路仍走通。检索库同向量模型要求只针对知识库关联，不扩展到外部系统。相似度分数不承担权限或实体隔离功能。

假设演练样本：材料原文为“订单 A-2291 于 2025 年 3 月 12 日提交退款申请，当前状态为待审核；该订单来自关键词计划 K-08，计划归属账户 Z-14。”待判定拟稿句为“订单 A-2291 的退款已完成，投放来源为关键词计划 K-08。”核对时比较主体、对象、状态与日期：原文状态为待审核，拟稿句写已完成，属于同字段互斥取值矛盾；投放来源与原文一致。待审核不表示退款已执行，也不表示缺少操作权限。

## 配置怎么定

| 配置项 | 本次假设起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 仅关联使用同一向量模型的投放文档库 | 先核向量模型标识，排除不同模型库，不执行跨模型检索 |
| 搜索模式 | 先用混合检索 | 关键词编号与自然语言问题并存，与纯语义、纯全文结果比较 |
| 引用上限 | 本次假设起点 2000 token | 用长短不同资料测试内容完整性，与更小值比较是否截断 |
| 最低相关度 | 本次假设起点 0.3 | 先标注相关与无关样本，再与更高阈值比较过滤效果 |
| 问题优化 | 多轮追问和短问题开启 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 候选较多时启用 | 重排得分按 0-1 过滤，与仅用向量得分比较排序 |

## 容易做错的三处

1. 把待审核状态写成已完成。输入为材料原文“当前状态为待审核”，比较同一订单同一字段的取值，拟稿句写“已完成”即矛盾。可执行检查：抽取状态字段，与原文逐字比对，状态不同即标记待核实。
2. 把检索命中当作授权执行。输入为检索返回的退款说明，比较该说明是否载明审批或执行完成，未载明则记录缺口，不写成已退款。可执行检查：检查引用内容是否含授权或执行字段，缺失时保留待核实。
3. 跨向量模型关联知识库。输入为两个知识库的向量模型标识，比较两者是否一致，不一致则排除，不继续比较漏召回。可执行检查：读取模型标识字段，相同才允许共同关联。

## 怎么确认配好了

1. 针对假设样本拟稿句，输入“订单 A-2291 的退款已完成，投放来源为关键词计划 K-08”，比较原文状态“待审核”与拟稿“已完成”，出现同字段互斥取值即判定矛盾，投放来源一致不抵消状态矛盾。
2. 针对同一材料，输入“订单 A-2291 来自关键词计划 K-08，归属账户 Z-14”，比较主体、对象与来源字段，三处均与原文一致且状态未被改写，才满足来源核对条件。
3. 针对空结果承接，输入纸面引用数组 []，比较下游设计是否按长度 0 走通链路，不声称虚构规则检索一定返回空数组。
