# 拼多多低价活动店铺运营的订单履约与售后答疑：知识库检索与召回

## 这个品类的数据长什么样

拼多多低价活动店铺的履约与售后答疑，主要围绕活动报名表、商品成本测算表、售后退款单、平台站内信四类材料展开。这些材料按日或按场活动更新，记录活动库存估算、活动价毛利、异常退款跟踪等过程。检索环节需要从这些材料中取出与具体订单、具体活动场次、具体退款单对应的内容，供履约判断和售后回复引用。

材料本身带有主体、对象、时间范围和状态。活动报名表载明参与店铺、活动场次、报名商品与报名状态；售后退款单载明订单号、退款原因、退款状态与处理节点；平台站内信载明通知对象与通知事项。检索结果是否可用，取决于能否把这些字段一并召回，供后续人工核对。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。不同向量模型的知识库不可共同关联，配置前先核对向量模型标识，排除不符合者，记录实际观察，不执行跨模型检索来比较漏召回。

搜索模式分语义检索、全文检索、混合检索。语义检索按向量距离计算相似度；全文检索适合编号、型号、专有名词、错误码等精确查询；混合检索同时使用两路召回，经 RRF 融合结果。RRF 是融合过程，不是可开启的独立开关。图片检索须有图像输入且模型具备相应能力；重排须具备 ReRank 模型并按设置启用。文档流程图列出的路径不代表每次请求全部执行。

引用上限以 token 为单位，控制单次搜索最多引用的内容量。最低相关度是 0 至 1 的过滤阈值，仅在语义检索或使用结果重排时生效，属于过滤条件，不承担权限或实体隔离。检索本身不构成授权，也不判断业务主体是否有权查看某条记录。

问题优化用于指代消除和问题扩展，在正式检索前增加一次模型调用。空结果以数组形式输出，长度可以为 0，输出链路仍走通。

假设演练样本

以下为本次假设演练样本，非真实记录。材料原文：某店铺活动报名表载明“活动场次 A-0715，报名商品为夏季凉席，报名状态为已提交，待平台审核”。同期平台站内信载明“A-0715 场次报名信息已收到，审核结果另行通知”。一条拟判定交接请求为：“A-0715 场次凉席报名已通过，可按活动价接单并锁定库存。”

判定要点：材料中报名状态为已提交、待平台审核，站内信仅确认收到报名信息，未载明审核通过。拟判定句把待审核状态写成已通过，并据此要求接单和锁库存。该请求未获材料支持，属待核实；接单与锁库存属需另接系统实现的业务动作，检索或表单不构成授权。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联使用同一向量模型的库 | 先核对向量模型标识，排除不同模型者，不比较跨模型漏召回 |
| 搜索模式 | 语义检索与全文检索分别试跑 | 用同一测试问题比较两路召回内容，观察编号类与自然语言类的命中差异 |
| 引用上限 | 设为能容纳一条完整退款单的 token 量 | 以长短不同的实际材料测试内容是否被截断，再调整 |
| 最低相关度 | 先标注相关与无关样本再定值 | 仅在语义检索或结果重排时生效，观察无关片段是否被过滤 |
| 问题优化 | 多轮追问与短问题场景试开 | 比较原问题与优化后问题，核对主体是否被改错 |
| 空结果承接 | 用纸面输入空数组核对下游设计 | 核对下游分支是否按引用长度为 0 处理 |

表中数值为本次假设试验起点，非官方默认值。

## 容易做错的三处

1. 把待审核状态当作已通过。输入为“报名状态已提交，待平台审核”的材料原文，比较拟判定句“报名已通过”，观察拟判定句是否与材料状态字段一致。不一致时该请求未获支持，接单与锁库存不得据此执行。
2. 把检索结果当作授权凭据。输入为一条售后退款单检索命中，比较该退款单载明的处理节点与拟执行的退款动作，观察材料是否载明可执行该动作。未载明时记录证据缺口，不推定已获授权。
3. 跨不同向量模型关联知识库。输入为两个知识库的向量模型标识，比较两者是否一致，观察配置是否允许共同关联。标识不一致时排除该库，记录实际观察，不推断运行结果。

## 怎么确认配好了

1. 针对样本原文“报名状态为已提交，待平台审核”，输入拟判定句“报名已通过，可按活动价接单并锁定库存”，比较状态字段与拟判定表述，观察检索引用是否包含“待平台审核”。若引用未包含该状态，该判定未获支持，保留待核实。
2. 针对样本站内信“报名信息已收到，审核结果另行通知”，输入问题“A-0715 凉席报名是否通过”，比较召回内容与站内信原文，观察召回是否只反映“已收到”而未出现“已通过”。若召回内容出现通过结论，需核对来源，缺失时记录缺口。
3. 针对引用长度为 0 的情形，用纸面输入空数组核对下游分支，观察下游是否按无引用处理。不声称虚构规则检索一定返回空数组，只核对空结果承接设计。

三项验证均为纸面核对，未实际执行检索或业务动作。
