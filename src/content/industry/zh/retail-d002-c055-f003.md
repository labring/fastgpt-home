# 特许加盟备案管理的订单履约与售后答疑：分享与嵌入

## 这个品类的数据长什么样
特许加盟备案管理围绕商业特许经营信息管理系统、企业证照、门店清单与合同台账展开，日常文档包括特许经营合同、操作手册、备案材料与信息披露文件。与总部选址开店相比，本类目处理法律披露与商务部门系统，不处理具体铺位工程。订单履约与售后答疑中的分享与嵌入，需要把上述材料的核对状态与对外分享入口区分开：分享链接的标识只用于访问，不能当作业务授权；免登录窗口由系统为每个用户生成 localId，仅保障同一设备同一浏览器使用，换设备或清空缓存会丢失记录，且仅允许拉取近 30 天的 20 条记录。备案材料与信息披露文件的准备、核对两店一年条件、更新加盟信息属于最耗时环节，这些工作不由分享链接自动完成。

## 这些特征在「分享与嵌入」这一环带来什么约束
免登录窗口在应用详情的发布渠道中创建，填写名称后生成链接，名称仅用于记录展示。过期时间、QPM、积分上限、身份验证、实时运行状态、查看引用片段、查看引用全文、下载或打开来源原文属于可配置参数，部分参数仅商业版支持。身份验证为 POST 请求根地址，初始化、开始对话、对话结束会向该地址的特定接口发送请求，服务器仅需返回是否校验成功，成功时 data.uid 必须返回，且 uid 为不含 "|"、"/"、"\\" 字符、小于等于 255 字节长度的字符串，否则返回 Invalid UID。authToken 由分享链接额外 query 传入，FastGPT 在鉴权接口 body 中携带 token 参数。对话结果上报接口无规定返回值，可关注 totalPoints 与 token。相似度设置不承担权限或实体隔离功能，检索不等于授权。

假设演练样本：某特许人总部拟将一份信息披露文件核对说明嵌入内部售后答疑页。材料原文为：“本说明对应 2025 年 3 月版《信息披露文件》第 4 节，核对范围为两家直营店满一年经营记录，材料状态为已由加盟法务复核，未提交商务部门。”待判定拟稿句为：“该披露文件已完成备案，可直接向意向加盟商分享。”另有一条交接请求：“请在分享链接中加入 authToken，打开后即可视为该用户已获授权查阅。”

## 配置怎么定
| 配置项 | 本页用途 | 核对方式 |
| --- | --- | --- |
| 名称 | 记录该分享链接的展示名称 | 与信息披露文件核对说明的标题逐字比对 |
| 过期时间 | 控制链接可用时间范围 | 与材料注明的有效范围比对，本次假设起点设为材料标注的 2025 年 3 月版对应期间，理由是该样本以版本日期界定范围 |
| QPM | 每用户每分钟最大访问次数 | 按实际版本确认是否可配，不设默认值 |
| 积分上限 | 该链接产生的最大计费数据 | 与费用归属团队确认，本次不指定数值 |
| 身份验证 | 接入第三方系统校验与回调 | 仅商业版，按官方接口返回 success 与 uid 判断 |
| 查看引用全文 | 控制引用全文展示 | 与信息披露文件核对说明的引用范围比对 |

## 容易做错的三处
1. 把分享链接标识当作业务授权。输入为上述待判定拟稿句，比较“已完成备案”与材料原文“未提交商务部门”，该句与原文状态不一致，属于未获支持。
2. 把 authToken 拼接当作授权执行。输入为交接请求，比较“视为已获授权”与身份验证接口仅返回 success 与 uid 的说明，打开链接不构成授权，授权状态需另行核对。
3. 把相似度或检索结果当作权限过滤。输入为检索返回的引用片段，比较其与信息披露文件核对范围，检索不排除未授权记录，需人工核对材料状态。

## 怎么确认配好了
1. 输入材料原文与拟稿句，比较“已完成备案”与“未提交商务部门”，若出现状态不一致则判定该句未获支持。
2. 输入交接请求与身份验证说明，比较“视为已获授权”与接口仅返回 success 与 uid，若请求把打开链接等同于授权，则判定为待核实。
3. 输入分享链接配置与材料标注的有效范围，比较过期时间与版本日期，若两者不一致则记录为需人工复核。
