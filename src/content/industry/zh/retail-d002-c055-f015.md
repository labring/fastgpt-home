# 特许加盟备案管理的订单履约与售后答疑：知识库检索与召回

## 这个品类的数据长什么样

特许加盟备案管理处理法律披露与商务部门系统，不处理具体铺位工程。订单履约与售后答疑中，知识库需要承载特许经营合同、操作手册、备案材料与信息披露文件。这些材料的主体是特许人总部、加盟法务与商务主管对接人，出错后果包括被责令备案、加盟合同争议与行政处罚。资料更新频率为不定期与年，本页不据此推出批量同步或交易触发机制。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的库。语义检索、全文检索与混合检索按测试问题比较，不预设一种模式适合全部资料。引用上限以 token 为单位。最低相关度仅在语义检索或使用结果重排时生效。问题优化用于指代消除和问题扩展。检索是取回引用内容，不承担授权判断；相似度得分不构成权限或实体隔离。

假设演练样本：材料原文为“特许人甲于二〇二四年三月向商务主管部门提交备案材料，其中披露文件列明加盟店乙的合同期限至二〇二六年十二月。操作手册第 4 节写明售后配件申请须由加盟商在系统提交。”待判定拟稿句为“加盟店乙的售后配件申请已获总部批准。”原文只载明提交方式，未载明批准事实，该拟稿句未获支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| 关联知识库 | 备案材料库与合同台账库 | 两库使用相同向量模型，可共同关联 |
| 搜索模式 | 混合检索 | 与单独语义检索比较编号类问题命中 |
| 引用上限 | 1500 token | 假设起点，与 800 token 比较内容完整性 |
| 最低相关度 | 0.35 | 假设起点，与 0.5 比较无关片段数量 |
| 问题优化 | 开启 | 与关闭比较连续追问的检索结果 |
| 结果重排 | 启用 | 与不启用比较候选排序 |

## 容易做错的三处

1. 将最低相关度当作权限过滤。输入同一查询，比较返回引用与授权范围，观察是否出现越权内容。
2. 将不同向量模型的库共同关联。核对库标识，排除向量模型不一致者，记录实际观察。
3. 将待审核状态写成已批准。输入拟稿句与原文，比较主体、期间与字段，观察批准事实是否载明。

## 怎么确认配好了

1. 输入材料原文与拟稿句，比较“已获总部批准”与原文“须由加盟商在系统提交”，观察拟稿句是否缺少批准证据。
2. 输入同一查询并分别设置 0.35 与 0.5，比较返回引用数量与无关片段，观察阈值变化对结果的影响。
3. 输入空引用数组 []，核对下游链路是否走通，不声称虚构规则检索一定返回 []。
