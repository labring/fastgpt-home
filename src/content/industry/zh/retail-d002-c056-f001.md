# 生产企业免抵退税的订单履约与售后答疑：HTTP 接口与外部系统

## 这个品类的数据长什么样

生产企业免抵退把内销税额抵减与退税合并计算，这一计算特征决定订单履约与售后答疑阶段的数据必须能回溯到免抵退税申报明细表、出口合同、销售明细账和出口报关单四类材料。日常处理以月为更新节奏，单证与账务在同一月份内需要保持出口数量、离岸价和报关单号的一致。HTTP 接口与外部系统在此环节的作用，是把订单状态、报关单信息和售后问答请求在系统之间传递，接口本身不承担税额计算，也不替代申报。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向指定地址发送请求，Params 用于路径参数，Body 用于 POST/PUT 请求体，Headers 用于请求头，URL、Body、Headers 均可通过 {{}} 引用全局变量、系统变量或前方节点输出。系统变量包含 appId、chatId、responseChatItemId、variables、cTime、histories，其中 chatId 与 responseChatItemId 在测试模式下不存在。返回值通过 JSON path 提取，输出类型选字符串时会把对应 key 的值转成 json 字符串。对话接口使用 APIKey 鉴权，appId 优先级为 body.appId、Authorization 中的拼接形式、apikey 关联的 appId；传入的 model、temperature 无效；Token 消耗需设置 detail=true 后手动计算 responseData 中的 tokens。交互节点返回的 interactive 仅含 type 与 params，entryNodeIds、memoryEdges、nodeOutputs、nodeResponseId 不返回。

假设演练样本：某生产企业 2025 年 3 月出口合同 HT-2025-031，合同标的为自产货物一批，出口报关单号 202503120001，销售明细账记载当月出口销售额 1200000 元，免抵退税申报明细表对应行次已填列。拟判定句为“该批出口已完成退税审批，可向客户答复退税到账”。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 请求地址 | 外部订单系统提供的 URL | 按外部接口文档确定，与文档给出的地址逐字符比对 |
| 请求方法 | POST | 与接口契约声明的方法比对，不一致则记录差异 |
| Headers 鉴权 | Authorization 通过安全配置注入 | 与接口文档要求的鉴权方式比对，不写入公开样例 |
| Body 字段 | 引用前方节点输出的订单号与报关单号 | 与外部接口契约字段名逐项比对 |
| 返回值提取 | 按 JSON path 提取订单状态字段 | 与接口响应实际结构比对，输出类型选字符串 |
| 调试身份字段 | chatId、responseChatItemId 留空 | 测试模式下两者不存在，不将空值记为业务故障 |

## 容易做错的三处

1. 把交互节点返回的 interactive 展示配置当作可提交表单。该字段只含 type 与 params，entryNodeIds、memoryEdges、nodeOutputs、nodeResponseId 不返回，提交动作需另行实现。
2. 将 detail=true 返回的 responseData 中 tokens 直接作为实际消耗。文档说明不会返回实际消耗 Token 值，需手动计算。
3. 用检索相似度分数判断记录是否属于本企业或是否已获授权。相似度不承担实体隔离或权限过滤功能，检索结果不构成授权依据。

对应检查：核对 interactive 返回字段清单，确认是否出现被文档排除的内部字段；核对 detail=true 响应，确认 tokens 是否经手动计算；核对检索结果与权限范围，确认是否将相似度当作授权判断。

## 怎么确认配好了

- 验证一：输入假设样本中的合同 HT-2025-031、报关单号 202503120001、销售明细账出口销售额 1200000 元，以及拟判定句。比较拟判定句是否与免抵退税申报明细表当前状态一致。若明细表未记载退税审批完成，该句为未获支持，不能视为已审批。

- 验证二：输入假设样本中同一报关单号，比较 HTTP 请求 Body 引用的订单号与报关单号是否与外部接口契约字段名一致。若字段名不一致，记录差异，不推定接口会接受。

- 验证三：输入假设样本中 chatId 留空的调试请求，比较返回结果是否将 chatId 缺失报为业务故障。文档说明测试模式下 chatId 不存在，该现象不构成故障。

三项验证均以假设样本为输入，不声称已实际执行。未载明的审批状态、授权范围与接口响应保持未知。
