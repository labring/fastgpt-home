# 生产企业免抵退税的订单履约与售后答疑：分享与嵌入

## 这个品类的数据长什么样
生产企业免抵退把内销税额抵减与出口退税合并计算，这一计算特征决定订单履约与售后答疑中的分享材料必须同时承载出口合同、出口报关单、销售明细账与免抵退税申报明细表。免抵退税申报明细表按所属期汇总自产出口货物，出口合同与出口报关单确认离岸价与成交方式，销售明细账提供账载销售额，海关电子信息构成外部比对来源。这些材料按月更新，分享与嵌入环节需要核对的是同一所属期、同一报关单号、同一出口发票号下的字段是否一致。资料未说明各来源之间的自动同步机制，差异处理属于人工核对动作。

## 这些特征在「分享与嵌入」这一环带来什么约束
分享链接本身是访问入口，链接标识不能当成业务授权。免登录窗口从发布渠道创建并复制系统生成的完整链接，任何获得该地址的互联网用户可以使用，费用归属应用所在团队。对话记录依赖系统为每个用户生成的 localId，仅保障同一设备同一浏览器，切换设备或清空缓存会丢失记录，系统仅允许拉取近30天的20条记录。身份验证为商业版功能，配置根地址后，初始化、开始对话与结束对话会向该地址的接口发送 POST 请求，服务端返回 success 与 uid 决定是否放行。检索结果与相关度分值不承担身份、实体或权限过滤职责，检索动作本身不构成授权。

假设演练样本：某出口生产企业税务会计在免抵退税申报准备阶段，将一份《出口合同》摘要与一份《免抵退税申报明细表》摘要放入知识库，用于订单履约与售后答疑。合同摘要原文为：“合同编号 HT-2025-018，卖方为境内某生产企业，货物为自产A型电机，成交方式FOB，出口日期2025年3月12日，合同金额120000美元。”明细表摘要原文为：“所属期2025年03月，报关单号关字20250312001，出口发票号 FP20250301，出口货物A型电机，离岸价人民币840000元，免抵退税额栏待申报。”拟稿句为：“该笔出口已在2025年3月完成免抵退税申报并取得退税款。”待判定请求为：“请确认上述合同与明细表是否支持拟稿句成立。”

## 配置怎么定
下表围绕本页样本，列出官方已说明设置或实施核对项。分值、条数等未在材料中出现的参数不填入。

| 配置项 | 本页样本取值 | 依据与核对方式 |
| --- | --- | --- |
| 免登录窗口链接 | 由发布渠道创建并复制完整地址 | 链接标识仅作访问入口，不能作为申报或退税授权凭证 |
| 过期时间 | 按本次分享使用范围设置 | 超过该时间链接无法使用，需与实际答疑周期比对 |
| QPM | 按每用户每分钟最大访问次数核对 | 该值表示访问频率上限，与实际版本支持范围核对 |
| 积分上限 | 按分享入口用量限制核对 | 费用归属应用所在团队，需与团队预算口径比对 |
| 身份验证根地址 | 填写第三方校验根地址 | 商业版功能，接口返回 success 与 uid 决定放行 |
| 对话记录边界 | 依赖 localId 同设备同浏览器 | 跨设备记录需另行设计身份与会话管理 |

## 容易做错的三处
1. 把免登录窗口链接标识当成申报授权或退税资格凭证。链接只表示可访问入口，样本中明细表“免抵退税额栏待申报”说明申报状态尚未完成，链接可用与申报完成属于两个事实。
2. 把身份验证接口返回 success 当成业务审批通过。接口仅返回校验结果与 uid，样本中拟稿句涉及“完成申报并取得退税款”，该业务状态需要税务机关受理与退库记录支持，接口返回值不承载这一含义。
3. 把检索到的合同摘要与明细表摘要直接拼接成肯定结论。合同载明出口日期与成交方式，明细表载明所属期与待申报状态，两者均未载明申报完成或退税款到账，缺少该字段时结论应记为未获支持。

## 怎么确认配好了
1. 输入样本合同摘要与明细表摘要，比较拟稿句“该笔出口已在2025年3月完成免抵退税申报并取得退税款”与原文。原文仅出现“待申报”，未出现申报完成或退税款到账字段，观察结果为该拟稿句未获支持，需补充申报受理与退库凭证后再判定。
2. 输入样本待判定请求，比较请求中的主体、所属期、报关单号与原文。合同主体为境内某生产企业，明细表所属期2025年03月，报关单号关字20250312001，三者一致时进入字段核对；出现主体或报关单号不一致时，记录为证据缺口，不作出肯定或否定结论。
3. 输入身份验证接口返回的 success 与 uid，比较该返回值与业务审批状态。success 为 true 仅表示允许继续对话，观察结果为对话可继续，申报完成、退税到账等业务动作仍标记为未知，需由下游系统另行提供受理与退库记录。
