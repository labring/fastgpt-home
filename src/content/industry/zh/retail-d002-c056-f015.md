# 生产企业免抵退税的订单履约与售后答疑：知识库检索与召回

## 这个品类的数据长什么样

生产企业免抵退把内销税额抵减与退税合并计算，这一计算特征决定了知识库要同时容纳申报口径与履约口径两类材料。日常文档包括免抵退税申报明细表、出口合同、销售明细账、出口报关单，数据来源涉及电子税务局、ERP销售、海关电子信息与财务账，按月更新。订单履约与售后答疑场景中，销售单证与税务会计会就某笔出口的报关金额、合同约定与账载金额提出核对请求，检索环节需要把这些材料按同一主体、同一期间、同一字段组织起来，供后续人工判断。检索结果本身只提供引用内容，不承担授权、审批或写入。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的库，跨不同向量模型的库不可共同关联；核对时先核向量模型标识，排除不符合者，记录实际观察，不执行跨模型检索来比较漏召回。检索以库为最小搜索单位，集合仅作分类管理。语义检索依赖向量距离，全文检索依赖关键词命中，混合检索经 RRF 融合多路结果；RRF 是融合过程，不作为开关。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值，不构成权限、实体或业务隔离。引用上限以 token 为单位，输出引用长度可以为 0，空结果链路仍走通。问题优化用于指代消除与问题扩展，会增加一次模型调用。图片检索需要图像输入与相应模型能力，重排需要模型并按设置启用；流程图列出的路径不代表每次请求全部执行。

## 配置怎么定

假设演练样本：某出口生产企业税务会计提交一份核对请求，所附材料原文为三句。第一句：「本企业 2026 年 3 月出口自产货物一批，出口合同编号 H-2026-03，合同约定离岸价 120000 美元。」第二句：「同月出口报关单载明该批货物离岸价 118500 美元。」第三句：「同月销售明细账记录该批货物入账金额 118500 美元。」待判定的拟稿句为：「该批出口的合同价、报关价与账载金额一致，可直接计入免抵退税申报明细表。」判定需同主体、同期间、同一字段：合同价与报关价属不同字段，第三句仅支持报关价与账载金额同值。

| 配置项 | 本页相关设置或核对项 | 与样本的对应 |
| --- | --- | --- |
| 关联的知识库 | 关联一个或多个使用相同向量模型的库 | 将申报明细表、出口合同、销售明细账、出口报关单分别入库，核对向量模型标识一致 |
| 搜索模式 | 按测试问题比较语义、全文与混合检索 | 合同编号 H-2026-03 属精确编号，用全文或混合检索核对 |
| 引用上限 | 单位为 token，按长短不同的实际资料测试内容完整性 | 本次假设试验起点设为 2000 token，理由是该批材料含合同与报关两段较长文本；与 1000 token 的取值比较引用是否被截断 |
| 最低相关度 | 仅在语义检索或使用结果重排时生效 | 先标注相关与无关样本，再调阈值，不用于排除无关业务 |
| 问题优化 | 用于指代消除和问题扩展 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 需具备模型并按设置启用 | 候选较多时核对重排得分，不预设排序结果 |

## 容易做错的三处

1. 把合同价与报关价当作同一字段直接判定一致。样本中合同约定 120000 美元、报关单载明 118500 美元，两者字段不同，不能得出矛盾结论，只能记录差异待核实。
2. 用最低相关度过滤无关业务或未授权记录。该值是过滤阈值，检索不承担授权，未获授权的记录是否在库内属另一环节，本页不作断言。
3. 把检索到引用内容当成审批或写入已完成。引用输出长度为 0 时链路仍走通，检索结果不构成授权、审批或数据库写入。

## 怎么确认配好了

1. 输入样本第一句与第二句，比较合同价与报关价两个字段的取值，观察检索引用是否同时呈现两段原文；若只呈现一段，记录缺口，不判定一致或矛盾。
2. 输入拟稿句，比较其「一致」表述与样本三句原文，观察是否出现同主体、同期间、同字段的互斥取值；样本未载明合同价与报关价可比，判定为未获支持。
3. 输入明确纸面输入 []，核对下游设计对空引用的承接方式，观察链路是否走通；不声称虚构规则检索一定返回 []，也不保证首条命中或全部召回。
