# 生鲜水果门店采购的订单履约与售后答疑：HTTP 接口与外部系统

## 这个品类的数据长什么样

生鲜水果门店采购的日常文档包括采购单、验收单、农残检测报告和损耗记录。与便利店鲜食订货相比，水果采购更多依赖批发市场行情和等级验收，数据来源分散在批发市场行情、供应商报价、门店销售和检测报告之间。采购单记录品种、数量与供应商，验收单记录到货等级与差异，农残检测报告关联批次合规状态，损耗记录反映门店实际报废。这些文档的更新频率为日或每批，订单履约与售后答疑需要把采购单与验收单的状态对应起来。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向外部地址发送请求，Params 用于路径请求参数，Body 用于请求体，Headers 用于请求头。变量来自全局变量、系统变量和前方节点输出，可通过 `{{}}` 引用。系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories，其中 chatId 与 responseChatItemId 在测试模式下不存在。返回值通过 JSON path 提取，输出类型选择字符串时会将对应 key 的值转为 json 字符串。

对话接口使用 APIKey 鉴权，调用 `chat/completions` 时推荐在请求体传入 `body.appId`。传入的 model、temperature 等参数字段无效，由编排决定。detail=true 时返回中间值，stream 模式下通过 event 区分。交互节点返回的 interactive 只包含 type 和 params，entryNodeIds、memoryEdges、nodeOutputs、nodeResponseId 等内部运行态字段不会返回。表单输入需要将内容以对象形式序列化成字符串作为 messages 的值，并确保 chatId 一致。

假设演练样本：某门店生鲜主管在 2025 年 3 月 10 日提交一份采购单，供应商为“青禾果蔬”，品种为红富士苹果，数量 200 箱，验收等级为一级。验收单记录实际到货 195 箱，其中 5 箱外观碰伤。农残检测报告编号 JC-20250310-07，结论为合格。损耗记录显示当日门店报废 3 箱。待判定的交接请求为：“请通过 HTTP 接口把本批验收差异同步给供应商系统，并自动生成补货单。”

## 配置怎么定

| 配置项 | 本次假设试验起点 | 核对方式 |
| --- | --- | --- |
| 请求地址与方法 | 按外部接口文档选择，地址引用已提供的变量 | 核对地址与方法是否与外部接口契约一致 |
| Params 与 Headers | 鉴权凭证通过安全配置注入 | 核对请求参数与请求头，不将凭证写入公开样例 |
| Body | 仅在相应请求类型下使用 | 核对 JSON 结构与外部接口契约 |
| 变量引用 | 引用全局变量、系统变量或前方节点输出 | 逐项核对实际传入值 |
| 返回值提取 | 按 JSON path 提取所需字段 | 核对 key 与输出类型 |
| 调试身份字段 | chatId 与 responseChatItemId 在测试模式下不存在 | 不把调试空值当成业务故障 |

本次假设试验起点的选择理由：该样本涉及采购单、验收单、检测报告与损耗记录四类文档，需要核对请求地址、鉴权、请求体与返回值提取。与什么值比较：将实际传入的变量值与样本中记录的数量、等级、批次编号逐项比较。

## 容易做错的三处

1. 把检索或表单当成授权执行。样本中交接请求要求同步验收差异并生成补货单，表单收集的数值不构成供应商确认，也不构成补货授权。核对输入为交接请求原文，比较对象为是否存在供应商确认或授权记录，观察结果为未获支持。
2. 把测试模式下不存在的 chatId 与 responseChatItemId 当成业务故障。样本中若在测试模式调用，这两个字段不存在。核对输入为测试模式调用记录，比较对象为系统变量说明，观察结果为不将空值判定为故障。
3. 把交互节点返回的展示配置当成完整运行态。样本中若工作流命中交互节点，返回的 interactive 只含 type 和 params。核对输入为交互节点响应，比较对象为文档说明的字段范围，观察结果为 entryNodeIds 等字段不出现。

## 怎么确认配好了

1. 输入样本中的采购单与验收单原文，比较采购数量 200 箱与验收数量 195 箱，观察 HTTP 模块返回值中差异字段是否与 5 箱一致。预期为差异字段可提取，不声称已实测。
2. 输入样本中的交接请求原文，比较是否存在供应商确认或授权记录，观察是否将表单输入判定为授权执行。预期为未获支持，保留证据缺口。
3. 输入样本中的农残检测报告编号 JC-20250310-07，比较返回值提取的 key 与报告编号字段，观察输出类型为字符串时是否转为 json 字符串。预期为可核对，不保证首条命中。
