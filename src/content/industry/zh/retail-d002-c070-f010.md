# 跨境商品合规与标签的订单履约与售后答疑：引用来源与溯源

## 这个品类的数据长什么样
跨境商品合规与标签的日常材料集中在产品测试报告、英文标签、MSDS 与平台禁售清单。这些材料在上架和进口前形成，出错会带来平台下架、海关扣货或消费者索赔。引用来源与溯源要处理的对象是这些文档本身：同一商品可能同时存在检测机构报告、供应商资料与目的国法规库摘录，彼此版本与适用范围不一致时，售后答疑需要指出哪一条引用对应哪一份材料。

## 这些特征在「引用来源与溯源」这一环带来什么约束
知识库搜索可选一个或多个相同向量模型的知识库，跨不同向量模型的库不可共同关联，只能先核标识并排除不符合者。搜索节点以数组输出引用内容，长度可以为 0，空数组不代表工作流报错终止。引用上限以 tokens 计，不是条目数；最低相关度仅过滤低相关度结果，不承担权限或实体隔离。资料更新不定期，每次上新，因此同一商品的不同版本材料可能同时入库，回答须逐条比对原文与引用日期范围。

假设演练样本：某批儿童水杯的供应商资料写“材质：Tritan，适用温度 -20°C 至 100°C，报告编号 LAB-2024-0311，出具日期 2024 年 3 月”。平台禁售清单摘录写“含 BPA 材质水杯禁售”。待判定拟稿句：“该水杯因含 BPA 被平台禁售。”比对同一商品、同一字段：供应商资料载明材质为 Tritan，禁售清单针对含 BPA 材质，两者主体与字段不同，拟稿句未获支持，应记为待核实并保留证据缺口。

## 配置怎么定
| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| 关联的知识库 | 仅选同一向量模型的合规资料库 | 与另一候选库的向量模型标识比较，标识不同则排除 |
| 搜索模式 | 混合检索 | 与纯语义检索比较，编号与型号类查询需关键词命中 |
| 引用上限 | 本次假设起点 3000 tokens | 与默认显示值比较，按单次回答可容纳的原文长度设定 |
| 最低相关度 | 本次假设起点 0.4 | 与检索返回的相关度得分比较，过滤明显无关片段 |
| 问题优化 | 多轮追问时开启 | 与关闭时比较连续追问的召回内容是否含主体 |
| 结果重排 | 候选较多时启用 | 与未重排结果比较排序位置，重排须具备模型 |

## 容易做错的三处
1. 将最低相关度当作权限或实体隔离手段。相关度得分是相似度数值，不识别业务归属，无权记录仍可能被召回。
2. 将引用上限按条目数理解。文档以 tokens 计，按条数估算会与实际引用长度不符。
3. 将跨向量模型的知识库强行共同关联。文档要求相同向量模型才可共同关联，应先核标识并排除不符合者。

## 怎么确认配好了
1. 输入假设样本的供应商资料原文与禁售清单摘录，比较拟稿句“该水杯因含 BPA 被平台禁售”与两份原文的主体和字段。拟稿句与原文不一致时，回答应保留待核实状态并展示引用原文，不输出禁售结论。
2. 输入明确的纸面空结果 `[]`，比较下游回答环节是否正常承接。引用数组长度为 0 时链路仍走通，回答不因空数组中断，也不虚构引用内容。
3. 输入两个向量模型标识不同的知识库选项，比较标识是否一致。标识不同则不执行共同关联，记录实际观察，不推断漏召回或冗余等运行结果。
