# 跨境平台结算与汇兑的订单履约与售后答疑：对话日志与审计

## 这个品类的数据长什么样
结算汇兑围绕已成交订单的资金归集，数据来自平台结算中心、银行流水、支付机构后台与 ERP 订单，更新以周或月为单位。日常材料包括平台结算单、汇率表、服务费发票和收款对账表。售后答疑中，卖家财务常就某笔结算差异、汇率折算口径或服务费归属发起追问，回答依据来自这些材料。该品类出错会带来利润核算错误、税务申报偏差或资金短缺，因此对话日志与审计需要把每次问答与对应的结算材料、会话身份和运行详情关联起来，便于事后核对。

## 这些特征在「对话日志与审计」这一环带来什么约束
日志留存与业务合规审计属于两件事。接口返回的会话、对话与运行详情只说明系统记录了什么，对账、留存与合规要求需要完整业务方案另行落实。检索结果不构成授权，表单只收集值，业务核验、审批、数据库写入与外部同步均需对应的下游实现。运行详情需按官方契约设置 detail，并在 responseData 中查看模块状态与完整结果。未返回的业务数据不能推定已完整留存。

假设演练样本：某跨境卖家财务在会话 chatId 为 C-2024-10-001、应用 appId 为 A-66e29b 下，就 2024 年 10 月平台结算单第 3 行服务费金额发起追问。供核对的材料原文两句：“平台结算单 2024-10 第 3 行服务费金额为 120.00 美元；服务费发票 2024-10 第 3 行金额为 120.00 美元。”待判定的拟稿句为：“该笔服务费已完成对账，可据此申报。”判定需同主体、同期间、同一字段：材料仅显示两处金额一致，未载明对账完成与申报授权，该拟稿句属于未获支持，不能视为已完成对账或已获申报授权。

## 配置怎么定
下表围绕该样本列出与本功能、主任务相关的官方已说明设置或实施核对项。数值为本次假设试验起点，说明选取理由与比较对象，不作为官方默认值。

| 配置项 | 本次假设起点 | 选取理由与比较对象 |
| --- | --- | --- |
| appId | A-66e29b | 样本应用标识，与材料所属应用核对 |
| chatId | C-2024-10-001 | 样本会话标识，与业务记录会话核对 |
| dataId | 样本对话 ID | 定位某轮问答，与运行详情返回核对 |
| detail | true | 需查看 responseData，与 false 时返回比较 |
| source | api | 获取 API 创建会话，与页面会话区分 |
| loadCustomFeedbacks | true | 读取自定义反馈，与 false 时返回比较 |

## 容易做错的三处
1. 把检索结果当成授权依据。样本中检索到服务费金额一致，不能推出对账完成或申报获准。检索不负责权限或实体隔离，相关度分数不是类别、实体或权限过滤器。
2. 把不同入口的会话混算。chatId 为 C-2024-10-001 的会话与页面会话来源不同，source 为 api 时不会获取页面会话，混算会导致日志与业务记录错位。
3. 把未返回字段推定已留存。detail 为 false 时 responseData 不返回，不能据此认定模块状态或完整结果已保存；需按官方契约设置 detail 后查看实际返回。

## 怎么确认配好了
1. 输入样本材料原文与拟稿句，比较材料字段与拟稿句断言。材料仅显示两处金额一致，未载明对账完成与申报授权，拟稿句属未获支持，需记录证据缺口。
2. 输入 chatId C-2024-10-001 与 source api，比较返回会话列表与业务记录。若列表未包含该会话，说明来源或标识不符，需核对后重试，不保证首条命中。
3. 输入 detail true 与 false 两次请求，比较 responseData 是否出现。true 时出现模块状态与完整结果，false 时不出现；未出现时不能推定数据已留存，需记录实际观察。
