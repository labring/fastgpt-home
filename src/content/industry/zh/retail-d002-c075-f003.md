# 达人专场带货合作的订单履约与售后答疑：分享与嵌入

## 这个品类的数据长什么样

在达人专场带货合作的订单履约与售后答疑中，本页说明FastGPT的分享与嵌入如何衔接资料。将达人合作服务说明限定在对应专场，分开核样品、直播和售后扣佣材料。所用场景为自拟文字测试。

## 这些特征在「分享与嵌入」这一环带来什么约束

自拟协作入口拟提供某专场样品问题的处理摘要，不拟开放其他达人协议或完整店铺成交明细。通过渠道完整链接核实际原文，分别问本专场样品与他场合作内容。若其他达人的条款被转述，应保留完整返回查资源授权；资料都属于带货合作不构成共享依据。链接只是进入对话的位置，不能表明接收者有查看全部协议、佣金或成交材料的权利。

## 配置怎么定

| 协作入口核对项 | 达人专场材料 | 验收线索 |
| --- | --- | --- |
| 本场摘要 | 样品问题拟开放范围 | 接收环境原文 |
| 其他资料 | 他场协议及成交明细排除 | 完整返回含条款转述 |
| 阶段证据 | 寄样、直播与售后扣佣分开 | 不能一概写成完成 |
| 跨设备 | 所指专场及事项分别补清 | 查历史与结果来源 |
| 业务动作 | 建议不扣佣或结算 | 记录入口限制及真实执行 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `免登录窗口` | 复制生成的完整分享链接。 |
| `过期时间与QPM` | QPM指每用户每分钟访问上限。 |
| `积分上限` | 按入口及版本核用量与费用条件。 |
| `身份验证` | 第三方认证受商业版范围限制。 |
| `对话记录边界` | 匿名标识依赖同设备、同浏览器。 |

## 容易做错的三处

- 本专场入口转述他场协议或完整成交明细：保存实际条款及完整返回查资源，带货合作同类不说明所有协作者获权。

- 寄样问题换设备追问“售后那部分”缺专场与前问：核历史、主体及来源，匿名会话不自动跨设备，不能猜另一场处理结果。

- 样品寄送、战报或申请被合写成履约扣佣已完成：分别查直播、售后及结算事件，单一阶段不证明全流程，答复不发样或扣佣。

## 怎么确认配好了

验收以拟开放摘要、他场协议和受限明细做允许及否定测试，记录原文可见与拒绝范围，再核版本适用的期限、每用户访问和用量责任。外部人员若需身份验证，另验商业版能力与返回，不由完整链接推定真实身份。答复可以整理待核步骤，不执行寄样、扣佣或结算；合作责任和售后实际结果仍需原始记录与责任人确认，不由对话结束判完成。
