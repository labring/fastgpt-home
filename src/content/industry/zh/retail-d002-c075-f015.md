# 达人专场带货合作的订单履约与售后答疑：知识库检索与召回

## 这个品类的数据长什么样

达人专场带货合作的核心是外部达人履约与佣金结算。日常材料包括达人合作协议、佣金设置单、样品寄送单、直播战报。这些材料分别承载不同事实：协议载明签署与生效状态，佣金设置单载明比例与结算口径，样品寄送单载明寄出与签收，直播战报载明场次成交。检索与召回环节需要把这些材料按库组织，使订单履约与售后答疑时能取到对应原文。数据每场、每周更新，检索结果只反映入库时已经建立的索引内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，应先核标识并排除不符合者，记录实际观察，不执行跨模型检索来比较漏召回。搜索模式可选语义检索、全文检索或混合检索，按测试问题比较，不预设一种模式适合全部资料。引用上限以 token 为单位，最低相关度仅在语义检索或使用结果重排时生效。问题优化用于指代消除和问题扩展，会增加一次模型调用。混合检索通过 RRF 融合多路结果，RRF 是融合过程，不是开启开关。图片检索须有相应图像输入及模型能力，重排须具备模型且按设置启用。检索与召回不承担授权判断：检索到协议文本不表示合作已达成，待审核不表示缺少操作权限。

假设演练样本：某次达人专场合作中，供核对的材料原文为“本协议自双方签署之日起生效，签署日期为2025年3月10日”“佣金设置单载明该场次佣金比例为百分之十五，结算口径为确认收货后结算”“样品寄送单载明样品于2025年3月5日寄出”。一条待判定的拟稿句为“该达人合作已于2025年3月10日生效，佣金按百分之十五结算”。判定需同主体、同期间、同一字段：协议生效日期与拟稿句一致，可获支持；佣金比例与设置单一致，可获支持；结算是否已完成，材料未载明，属未获支持。样品寄出与签收是两个事实，寄出日期不表示签收。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 协议库、佣金设置单库、样品寄送单库、直播战报库 | 先核各库向量模型标识，排除不一致者，再决定共同关联范围 |
| 搜索模式 | 混合检索 | 与语义检索、全文检索分别比较同一测试问题的召回内容 |
| 引用上限 | 本次假设试验起点设为 2000 token | 用长短不同的实际材料测试引用内容是否完整，再与更高或更低值比较 |
| 最低相关度 | 本次假设试验起点设为 0.5 | 先标注相关与无关样本，再比较不同阈值下的过滤结果 |
| 问题优化 | 开启 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 按设置启用 | 确认重排模型可用，比较重排前后候选排序 |

以上数值为本次假设试验起点，用于说明比较方法，不代表官方默认值。引用上限单位为 token。最低相关度是过滤阈值，不是最终排序规则，不承担权限或实体隔离。

## 容易做错的三处

1. 把检索命中当作授权执行。输入为拟稿句“该达人合作已于2025年3月10日生效”，检索到协议文本后直接认定合作已达成。比较对象是协议载明的签署日期与拟稿句日期，观察结果是二者一致才可获支持；合作达成、合同生效是不同事实，材料未载明时记录缺口。
2. 把待审核当作缺少操作权限。输入为交接请求“佣金设置单待审核”，据此判定该场次无结算权限。比较对象是材料载明的审核状态与权限字段，观察结果是材料未载明权限字段时属未获支持，不能称为否定。
3. 跨不同向量模型的库共同关联。输入为多个知识库标识，未核向量模型即共同关联。比较对象是各库标识对应的向量模型，观察结果是标识不一致者应排除并记录，不推断运行结果。

## 怎么确认配好了

1. 输入假设样本中的协议原文与拟稿句，比较协议载明的签署日期与拟稿句日期是否为同一主体、同一期间、同一字段，观察结果是日期一致时该句可获支持；日期未载明时记为未获支持。
2. 输入假设样本中的佣金设置单原文与拟稿句，比较佣金比例与结算口径是否为同一字段，观察结果是比例一致时可获支持；结算是否完成材料未载明，记为待核实。
3. 输入明确的纸面空结果 []，核对下游设计对空引用的承接方式，观察结果是输出链路在引用长度为 0 时仍走通；不声称虚构规则检索一定返回 []。
