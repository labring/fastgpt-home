# 达人佣金结算与扣佣的订单履约与售后答疑：分享与嵌入

## 这个品类的数据长什么样

达人佣金结算与扣佣的成交发生在推广之后，有效订单核对、退款扣佣、开票付款构成月度结算的主要工作量。精选联盟后台提供佣金设置记录与结算账单，财务系统承接退款扣佣明细与发票，达人合同界定结算周期与扣佣口径。四类材料分属不同系统，订单号、达人标识、结算期间与金额字段在跨系统比对时容易错位。本页只处理订单履约与售后答疑中分享与嵌入这一环，说明材料、操作与请求各处于什么授权状态，检索与表单本身不构成授权执行。

## 这些特征在「分享与嵌入」这一环带来什么约束

免登录窗口从发布渠道创建并复制系统生成的完整链接，链接标识用于访问入口，不能当成业务授权。过期时间与 QPM 按使用范围设置并核实际版本，QPM 表示每用户每分钟最大访问次数。积分上限核对分享入口的用量限制及费用归属，部分参数受版本限制。身份验证受商业版范围限制，按官方接口返回的 success 状态与 uid 决定是否放行。匿名本地标识依赖同设备同浏览器，跨设备记录另行设计身份与会话管理。资料给出周、月的更新频率，本页不据此推出批量同步、全量同步或交易触发机制。

假设演练样本：某结算专员拟向外部达人商务分享一个免登录链接，用于查询某月账单。供核对的材料原文为「佣金设置记录：达人 A，结算期间 2025 年 3 月，佣金比例 12%。结算账单：达人 A，2025 年 3 月，应付佣金 4800 元，状态待确认。退款扣佣明细：达人 A，2025 年 3 月，退款订单 3 笔，扣佣 260 元。」待判定的交接请求为「请通过分享链接向达人 A 开放 3 月账单查询入口，链接身份验证已配置，可直接使用。」该请求中的身份验证配置状态、链接授权范围与账单确认状态均需另行核实。

## 配置怎么定

配置围绕样本中的材料与请求展开，只列官方已说明的设置或实施核对项。数值为本次假设试验起点，理由与比较对象一并写明。

| 配置项 | 本次假设试验起点 | 核对方式与理由 |
| --- | --- | --- |
| 名称 | 填写「达人A-3月账单查询」 | 名称仅用于记录展示，与授权范围无关，核对是否与样本达人及期间一致 |
| 过期时间 | 设为样本账单查询期结束后一周 | 超过该时间链接无法使用，与结算专员计划的查询窗口比较，不视为官方默认 |
| QPM | 保留链接创建时的既有值 | QPM 为每用户每分钟最大访问次数，与达人商务实际并发访问量比较后再调整 |
| 积分上限 | 按本次查询预计用量设定 | 该链接产生的最大计费数据，与账单查询的单次用量比较，费用归属应用所属团队 |
| 身份验证 | 填写第三方校验根地址 | 仅需根地址，无需完整路径；按 POST 请求返回的 success 与 uid 判断放行 |
| 对话记录边界 | 依赖同设备同浏览器 | 匿名本地标识跨设备会丢失记录，与达人商务的多设备使用需求比较 |

## 容易做错的三处

1. 把链接标识当作授权凭证。输入为样本中的分享链接与待判定请求，比较链接创建记录与达人 A 的授权范围，若请求声称可直接使用而授权范围未载明，该请求处于未获支持状态。
2. 把待确认账单当作已确认账单。输入为样本材料中「状态待确认」，比较结算账单的确认字段与请求中的开放查询动作，两者同字段取值不同，构成矛盾，需先核实确认状态。
3. 把身份验证配置当作已生效。输入为请求中「身份验证已配置」，比较配置记录与实际校验接口返回，若缺少 success 为 true 与 uid 的返回记录，该配置处于待核实状态。

## 怎么确认配好了

1. 核对链接授权范围。输入样本中的待判定请求与链接创建记录，比较达人标识、结算期间与授权对象，若记录未载明达人 A 的查询授权，结果记为未获支持，不记为否定。
2. 核对账单确认状态。输入样本材料中「状态待确认」与请求中的开放查询动作，比较同一账单记录的确认字段，若两处取值互斥，记为矛盾并保留证据缺口。
3. 核对身份验证返回。输入校验接口的 POST 请求与响应，比较 success 字段与 uid 格式，若返回 success 为 true 且 uid 为不含特殊字符、不超过 255 字节的字符串，满足放行条件；若返回 success 为 false，按 message 提示处理，不推断其他系统报错。
