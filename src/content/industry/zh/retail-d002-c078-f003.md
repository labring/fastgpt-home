# 连锁总部选址开店的订单履约与售后答疑：分享与嵌入

## 这个品类的数据长什么样

连锁总部选址开店发生在门店营业前，核心工作是租赁谈判与工程交付，主要材料为选址评估表、租赁意向书、装修预算和开业排期。这些材料按店不定期更新，每店一套。免登录窗口发布后，任何互联网用户可通过该地址使用应用，费用产生在应用归属团队下。对话记录依赖系统为每个用户生成的 localId，仅保障同一设备同一浏览器，切换设备或清空浏览器缓存会丢失记录，系统仅允许拉取近30天的20条记录。身份验证属于商业版范围，配置根地址后，初始化、开始对话及对话结束都会向该地址的特定接口发送请求。

## 这些特征在「分享与嵌入」这一环带来什么约束

选址开店材料涉及房东资料、租金条款与工程节点，分享链接本身不构成任何业务授权。链接标识、authToken 与 uid 用于识别访问者与拉取对话记录，不表示租赁意向已签署、装修预算已批准或开业排期已确认。身份验证接口返回 success 为 true 才允许继续操作，uid 格式须为不含“|”“/”“\”且不超过255字节的字符串，否则返回 Invalid UID。结果上报接口无规定返回值，响应值与 chat 接口格式相同并多一个 token，其中 totalPoints 与 token 为重点关注字段。过期时间、QPM、积分上限等参数部分仅商业版支持配置。

假设演练样本：某连锁总部拓展部留存一份租赁意向书草稿，原文为“出租方：某商业管理公司；承租方：某连锁总部；标的：某商场三层铺位；意向租期五年；本意向书自双方签署之日起生效，签署前不产生租赁权利义务。”同批材料中一份装修预算表标注“待工程经理复核”，开业排期表标注“待区域开发确认”。现拟将分享链接嵌入内部审批页面，拟稿句为“该铺位租赁意向已生效，装修预算已批准，可按排期开业。”待判定该拟稿句是否获得上述材料支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 核对与比较方式 |
| --- | --- | --- |
| 名称 | 选址开店履约答疑 | 仅用于记录展示，与材料名称逐字比对 |
| 过期时间 | 按本次演练窗口设定 | 超过该时间链接无法使用，与演练起止日期比较 |
| QPM | 按演练访问量设定 | 每用户每分钟最大访问次数，与实测请求次数比较 |
| 积分上限 | 按演练预算设定 | 该链接产生的最大计费数据，与累计消耗比较 |
| 身份验证 | 填写根地址 | 仅商业版支持，接口返回 success 与 uid 是否符合格式 |
| 查看引用片段 | 按演练需要选择 | 与文档所述引用展示范围比较 |

上述数值为本次假设试验起点，选择理由为覆盖一次内部审批演练的访问规模，比较对象为演练期间实际记录值，不表示官方默认值。

## 容易做错的三处

1. 将分享链接或 authToken 当作租赁意向已生效的凭证。链接只解决访问入口，材料中“自双方签署之日起生效，签署前不产生租赁权利义务”属于待核实状态。
2. 将装修预算表标注“待工程经理复核”读成已批准。待审核不证明缺少操作权限，也不等于批准，拟稿句中的“已批准”未获支持。
3. 将开业排期表标注“待区域开发确认”读成可按排期开业。排期确认与开业执行是不同事实，材料未载明确认结果。

## 怎么确认配好了

1. 输入假设样本中的租赁意向书原文与拟稿句，比较拟稿句“租赁意向已生效”与原文“自双方签署之日起生效，签署前不产生租赁权利义务”，只有出现双方签署完成的证据才满足条件，当前为未获支持。
2. 输入装修预算表“待工程经理复核”与拟稿句“装修预算已批准”，比较两者状态字段，只有出现工程经理复核通过并批准的证据才满足条件，当前为待核实。
3. 输入开业排期表“待区域开发确认”与拟稿句“可按排期开业”，比较确认状态与执行状态，只有出现区域开发确认完成的证据才满足条件，当前证据缺口保留。
