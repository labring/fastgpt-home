# 连锁门店价格与陈列稽核的订单履约与售后答疑：分享与嵌入

## 这个品类的数据长什么样

价格与陈列稽核发生在日常经营期，围绕标准持续执行展开。督导系统、POS价格表、门店摄像与总部促销档期构成主要来源，周与月的更新节奏决定巡店照片、价签清单、陈列标准、整改通知是这一品类最常见的文档。订单履约与售后答疑环节需要把这些材料交给区域督导、门店店长或第三方客服入口使用，分享与嵌入因此成为交付通道。材料本身带有期间与门店范围，脱离该范围使用会改变结论的适用范围。

## 这些特征在「分享与嵌入」这一环带来什么约束

免登录窗口从发布渠道创建并复制系统生成的完整链接，链接标识仅用于记录展示，不能当成业务授权。身份验证属于商业版范围，按官方接口返回的 success 状态与 uid 决定是否放行，uid 必须为不含 "|"、"/"、"\\" 字符且不超过 255 字节长度的字符串，否则返回 Invalid UID。对话记录依赖同一设备同一浏览器的 localId，仅允许拉取近 30 天的 20 条记录，跨设备需要另行设计身份与会话管理。检索与相似度不承担权限过滤或实体隔离功能，检索结果不等于授权。

假设演练样本：某连锁品牌运营部拟向区域督导分享一份巡店材料，供核对的原文为「2025年3月华东区A类门店价签抽查记录，抽查门店12家，其中3家存在促销价签与POS价格表不一致，整改通知已于3月18日发出，整改回执截至3月31日未收齐。」待判定的交接请求为「请通过分享链接向督导开放该材料，并允许其查看全部引用片段与来源原文。」

## 配置怎么定

| 配置项 | 本页取值或核对动作 | 依据与边界 |
| --- | --- | --- |
| 名称 | 填写为记录展示用名称，不承载业务含义 | 官方说明名称仅用于记录展示 |
| 过期时间 | 按本次分享使用范围设置，并与实际版本核对是否可配 | 部分参数受版本限制 |
| QPM | 按每用户每分钟最大访问次数理解并核对 | 官方定义，不推断默认值 |
| 积分上限 | 核对分享入口的用量限制与费用归属 | 费用产生在应用归属团队下 |
| 身份验证 | 填写 POST 根地址，按 success 与 uid 判断放行 | 商业版范围，接口仅返回校验结果 |
| 查看引用片段与来源原文 | 按材料授权范围决定是否开启 | 引用展示不改变材料授权状态 |

## 容易做错的三处

1. 把链接标识当成业务授权。链接可创建、可复制，授权状态仍需身份验证接口返回 success 且 uid 合规才能确认，未返回或返回 false 时属于未获支持。
2. 把检索结果当成权限过滤。相似度与召回只反映内容匹配，不排除无关业务或未授权记录，检索到某条材料不表示该材料已获准分享。
3. 把待审核或已发出当成已完成。整改通知已发出、回执未收齐属于阶段证据，不能据此判定整改闭环完成，也不能据此判定门店已执行。

## 怎么确认配好了

1. 输入样本原文与交接请求，比较分享链接是否拼接了 authToken，以及身份验证接口返回的 success 与 uid 是否符合格式要求。只有 success 为 true 且 uid 合规，放行条件才满足；返回 false 或 uid 含禁用字符时，记录为未获支持并保留证据缺口。
2. 输入样本中「3家价签不一致、回执未收齐」这一字段，比较拟稿句是否把未收齐写成已完成整改。拟稿句若声称整改闭环完成，与原文状态不一致；若仅陈述已发出通知与回执未收齐，则与原文一致。
3. 输入样本材料与开启的引用展示设置，比较督导实际可查看的引用片段与来源原文是否落在该材料授权范围内。超出材料范围或涉及其他门店记录时，记录为待核实，不执行跨范围检索来比较结果。
