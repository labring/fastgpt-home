# 连锁门店价格与陈列稽核的订单履约与售后答疑：知识库检索与召回

## 这个品类的数据长什么样

价格与陈列稽核发生在日常经营期，资料按周、按月滚动。督导系统产生巡店照片，POS价格表记录门店实际售价，总部促销档期规定应执行的价格与陈列要求，门店摄像提供现场画面。日常文档包括巡店照片、价签清单、陈列标准、整改通知。这些资料共同回答一个具体问题：某店某日某商品的价格标签与陈列位置是否符合当期档期要求。订单履约与售后答疑环节需要从这些资料中检索出可引用的片段，用于回应门店或区域督导提出的核对请求。资料更新频率本身不改变检索功能，检索动作针对的是已入库的当前版本。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，操作时先核向量模型标识，排除不符合者，记录实际观察。搜索模式分为语义检索、全文检索与混合检索，按测试问题比较三者效果，不预设一种模式适合全部资料。引用上限以 token 为单位，用长短不同的实际资料测试内容是否完整，再调整上限。最低相关度仅在语义检索或使用结果重排时生效，先标注相关与无关样本再调阈值。问题优化用于指代消除和问题扩展，比较原问题与优化后问题，核对主体是否被改错。语义召回和相关度不负责权限或实体隔离。检索库同向量模型要求不能扩展为其他外部系统也要同模型。RRF 是混合结果融合过程，不写成开启开关。

假设演练样本：一份巡店照片的文字备注为“2025年3月10日，A区某店，货架第三层陈列自有品牌纸巾，价签显示9.9元”。一份总部促销档期文档写明“2025年3月1日至3月15日，自有品牌纸巾执行8.8元，陈列于货架第二层”。一条待判定拟稿句为“该店3月10日纸巾价签与陈列均符合档期要求”。判定需同主体、同期间、同一字段：上述两份材料在价格字段上取值互斥（9.9元与8.8元），陈列层数字段也互斥（第三层与第二层）。拟稿句与两份材料均不一致，属于未获支持，不能判定为符合。若只有巡店照片而无档期文档，则价格与陈列要求缺失，记录证据缺口。

## 配置怎么定

| 配置项 | 本次假设起点 | 核对方法 |
| --- | --- | --- |
| 关联知识库 | 巡店照片备注库、价签清单库、陈列标准库、促销档期库 | 核各库向量模型标识，排除不一致者 |
| 搜索模式 | 混合检索 | 用样本问题分别跑语义、全文、混合，比较召回片段 |
| 引用上限 | 假设起点 2000 token | 用长档期文档与短价签清单各测一次，看内容是否截断 |
| 最低相关度 | 假设起点 0.4 | 标注样本中相关与无关片段，观察过滤后剩余项 |
| 问题优化 | 开启 | 对比原问题与优化后问题，核对主体、门店、日期是否被改错 |
| 结果重排 | 按设置启用 | 确认重排模型可用，观察 0-1 得分与排序变化 |

## 容易做错的三处

1. 把最低相关度当作权限或实体过滤。输入：样本问题“A区某店3月10日纸巾价签”。比较：检索返回片段是否只包含该店该日资料。可观察结果：若返回其他门店或其他日期的片段，说明相关度阈值未承担隔离功能，需另接权限实现。
2. 把跨向量模型的知识库强行共同关联。输入：两个向量模型标识不同的库。比较：节点是否允许同时选中。可观察结果：若无法共同关联，记录该限制，不继续编造漏召回或冗余等运行结果。
3. 把待审核的整改通知当作已完成整改。输入：一份标注“待审核”的整改通知。比较：通知状态字段与拟稿句中的“已完成”。可观察结果：状态为待审核时，拟稿句未获支持，记录证据缺口。

## 怎么确认配好了

- 验证一：输入上述假设样本中的巡店照片备注与促销档期文档，比较价格字段 9.9 元与 8.8 元、陈列层字段第三层与第二层。可观察结果：检索返回两份材料原文，拟稿句“均符合档期要求”与两份材料均不一致，判定为未获支持。

- 验证二：输入一条仅含巡店照片备注、无档期文档的查询。比较：检索结果中是否出现档期要求字段。可观察结果：档期要求缺失，记录证据缺口，不判定为符合或不符合。

- 验证三：输入空引用数组 []，核对下游答疑链路是否仍走通。可观察结果：输出链路走通，引用长度为 0，不声称虚构规则检索一定返回 []。以上均为纸面核对，未实际执行检索、审批或整改动作。
