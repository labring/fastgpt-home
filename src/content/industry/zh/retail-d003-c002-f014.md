# MCN机构达人管理的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

MCN机构管理多个达人的长期账号合规，服务对象是签约达人的持续经营，与单场品牌专场合作不同。本页涉及的商品与营销文案起草，材料来源包括达人签约合同、培训记录、违规处理单、账号排期，更新频率为日与周。起草文案时需要判断某句宣传语是否被现有材料支持，材料中的主体、对象、状态与有效范围决定可写与不可写。模型接入与配置在这一环的作用，是把材料文本与拟稿句送入语言模型做比对，配置正确与否直接影响比对结果能否被采信。

## 这些特征在「模型接入与配置」这一环带来什么约束

FastGPT 自 V4.17.0 起以 AI Proxy 为必需依赖，App 与 Admin 都必须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺少任一项启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。模型配置在管理员-模型提供商页面完成，渠道需填写 BaseUrl，不填完整请求地址。系统至少需要一个语言模型和一个索引模型才能正常使用。模型状态探测仅针对已启用的系统模型，未启用模型不参与探测。检索结果的相关度分数不承担权限或实体隔离职责，检索本身不等于授权。

## 配置怎么定

假设演练样本：某MCN机构运营人员需要核对一条拟稿句。供核对的材料原文为三句：达人A与机构于2026年3月1日签署《直播合作协议》，有效期至2027年2月28日；协议附件载明达人A可推广品类为美妆与个护；2026年4月10日违规处理单记录达人A因直播中夸大功效被平台警告一次，状态为已处理。待判定拟稿句为：“达人A是本站最值得信赖的美妆达人，所有产品功效均经严格验证。”以下配置项围绕该样本核对。

| 配置项 | 本页相关设置或核对动作 | 与样本的关系 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 填写 AI Proxy 服务根地址，不附加 /v1 | 文案比对请求经此地址发出 |
| AIPROXY_API_TOKEN | 填写与服务端一致的非空管理员 Token | 缺失则启动校验失败，比对无法进行 |
| 语言模型启用 | 在系统模型中确认至少一个语言模型已启用 | 拟稿句与材料原文的比对依赖语言模型 |
| 索引模型启用 | 确认至少一个索引模型已启用 | 材料入库检索依赖索引模型 |
| 模型状态探测 | 仅对已启用模型生效，可查看 48 小时状态图 | 判断比对所用模型当前是否可用 |
| 渠道 BaseUrl | 填 BaseUrl，不填完整模型请求地址 | 渠道配置错误会导致比对请求失败 |

## 容易做错的三处

1. 把检索相关度当作权限过滤。输入：材料库中含达人A与其他达人的合同。比较：检索返回的相关度分数与访问权限。观察结果：分数高低不表示某条记录对该操作者可见，权限需由下游实现判断。
2. 把待审核状态写成已批准。输入：违规处理单状态字段为“已处理”。比较：拟稿句是否声称“所有产品功效均经严格验证”。观察结果：材料未载明功效验证记录，该表述未获支持。
3. 把模型测试通过当作文案合规通过。输入：渠道测试显示模型可用。比较：模型可用性与拟稿句是否被材料支持。观察结果：模型可用仅说明请求能发出，不说明文案内容成立。

## 怎么确认配好了

1. 输入：上述三句材料原文与拟稿句“达人A是本站最值得信赖的美妆达人，所有产品功效均经严格验证。”比较：拟稿句中“最值得信赖”“所有产品功效均经严格验证”与材料原文。观察结果：材料仅载明合作期限、可推广品类与一次违规警告，未载明信赖度评价或功效验证记录，该拟稿句未获支持，需退回修改。
2. 输入：材料原文“达人A可推广品类为美妆与个护”与一条假设拟稿句“达人A可推广美妆、个护与食品。”比较：拟稿句品类范围与协议附件载明范围。观察结果：食品不在载明范围内，该句与材料不一致，需删除食品或补充授权材料。
3. 输入：假设检索请求返回空结果数组 []。比较：空结果与下游节点设计。观察结果：空结果时下游应走无材料分支，不得据此推断材料不存在或拟稿句成立，需记录证据缺口并转人工核对。
