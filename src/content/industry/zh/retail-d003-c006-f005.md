# 一般贸易出口报关的商品与营销文案起草：多轮对话与提示词

## 这个品类的数据长什么样

在一般贸易出口报关的商品与营销文案起草中，本页说明FastGPT的多轮对话与提示词如何衔接资料。检查品牌与型号描述在追问中是否保留原始来源和当前主体。所用场景为自拟文字测试。

## 这些特征在「多轮对话与提示词」这一环带来什么约束

为出口资料文案另拟一份普通文字：商业发票填有商品品牌栏，但没有品牌历史、市场地位或使用授权的说明。提示词应先把写作范围限定为当前材料能支持的描述，不能从一个品牌栏展开企业背景。比较新会话和带历史的同题输入，检查过去讨论过的其他品牌经历是否进入草稿。文案中的每项背景说法都需回到相应原文，发票字段本身不提供这些额外依据。

## 配置怎么定

| 对话或实施核对项 | 本题材料边界 | 应观察的内容 |
| --- | --- | --- |
| 文案范围 | 发票仅给品牌栏及商品记录 | 不补出品牌历史或市场地位 |
| 历史输入 | 新会话与带历史的同题对照 | 其他品牌叙述是否混入 |
| 型号差异 | 报关单X型、发票Y型分别保留 | 追问有无默认采信较早答案 |
| 问题优化 | 同一商品及双方来源不省略 | 改写后是否仍保留待核型号 |
| 补充资料 | 核心卖点需要产品说明 | 解析结果与说法出处分别检查 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `提示词与任务` | 说明资料、任务和缺证据处理。 |
| `历史记录` | 核实际提交的历史输入。 |
| `问题优化` | 指代消除与问题扩展需复核。 |
| `模型与长度` | 上下文与回复长度分别核对。 |
| `回复格式` | json_schema需给格式并验解析。 |

## 容易做错的三处

- 品牌栏被扩写成历史、地位或使用授权：核当前发票与新增句，历史他牌经历不能借给本品，缺凭证时继续待补。

- 报关单X型和发票Y型在优化问中丢一方：保留改写前后全文和两份身份，恢复差异再核草稿，不让先前选项变默认事实。

- 追问更有吸引力便补出功能、效果或优势：逐句回查产品原文，发票没有卖点依据时不能由润色取得，补资料后同题检验采用。

## 怎么确认配好了

发票没有提供核心卖点，追问“再写得有吸引力”也不能新增功能、效果或优势。可先检查已有草稿是否超出了品牌栏和型号记录的支持范围，再明确需要补充的产品说明。获得新资料后，记录其是否真正进入本轮输入，并用原写作任务重新核对。若下游要固定字段，解析是否成功与卖点是否有来源仍是两项独立检查。
