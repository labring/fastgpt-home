# 一般贸易进口报关的商品与营销文案起草：表单与交互

## 这个品类的数据长什么样

在一般贸易进口报关的商品与营销文案起草中，本页说明FastGPT的表单与交互如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「表单与交互」这一环带来什么约束

进口商品文案可先收商品品名、运输标识及拟介绍的用途问题，保留它们各自来自哪里。自拟材料只有发票和提单相关句子，明确厂家型号与成分资料尚缺。表单负责把这些内容交给下一步，不会从进口资料自动补出商品性能。若希望写成使用介绍，需要实际产品说明；货物已经安排运输的文字，也不构成可以销售或适合特定用途的依据。

## 配置怎么定

| 核对项 | 自拟输入或选择 | 可观察结果 |
| --- | --- | --- |
| 资料身份 | 发票与提单原句分别保留 | 没有混合来源用途 |
| 唛头传值 | 运输标识被标成型号 | 纠正标签后重新起草 |
| 用途分支 | 只整理品名却进入用途介绍 | 检查新增句子是否有依据 |
| 产品缺口 | 型号与成分资料未取得 | 文案未自动补技术属性 |
| 后续批准 | 商品核验与公开发布另办 | 填写结束未代表审核通过 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入` | 收集输入并在提交后传值。 |
| `必填信息核对` | 业务必填与缺项处理需另设计。 |
| `用户选择` | 选择结果对应已连接的分支。 |
| `交互状态` | 分别核等待和完成交互状态。 |
| `后续处理分工` | 校验、审批及写入另核结果。 |

## 容易做错的三处

若提单唛头在传值后被写成型号，应排查原文用途与起草输入的标签，纠正对象再测。另一项测试可选择“只整理已给品名”，但连接实际发送到用途介绍步骤，观察是否产生无来源的适用性句子；核选择值、接收路径和新增措辞，将未有依据的用途留作待补，不让分支名替代事实。 若发票只给商品品名，成稿却补出材料成分，应回查厂家成分原文及当前商品对应；贸易名称不提供组成说明，缺来源时保留属性待补。

## 怎么确认配好了

验收逐项对照发票品名、运输标识、资料缺口及文案对应句，补厂家说明后再问同一主题，确认新资料真正传入。列出本题不可缺的材料并测缺项行为，不把表单写成业务数据库或自动校验器。商品核验、采购准入和发布审批需实际后续流程承担；填写完成不证明进口手续、商品审核或文案发布已被执行。
