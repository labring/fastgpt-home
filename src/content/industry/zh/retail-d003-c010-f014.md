# 京东POP第三方店铺运营的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

在京东POP第三方店铺运营的商品与营销文案起草中，本页说明FastGPT的模型接入与配置如何衔接资料。跟踪材质文字进入文案的过程，避免将材料名称扩成未经支持的环保卖点。所用场景为自拟文字测试。

## 这些特征在「模型接入与配置」这一环带来什么约束

自拟商品附页只写材质为塑料，可作为文案输入的一个明确事实，但没有提供可回收性或环境效果。先核实际模型请求是否包含该句，再看草稿采用了哪些原文支持的表述。若原文未送达却输出具体材质，应排查它来自历史还是生成扩展；服务连通不能证明这项事实有依据。当前任务可以复述已提供属性，额外卖点需要相应产品资料，不能从材料名称直接推导。

## 配置怎么定

| 接入或实施核对项 | 材质文案的条件 | 核对目标 |
| --- | --- | --- |
| 实际输入 | 塑料为附页明示文字 | 是否进入模型请求 |
| 额外卖点 | 未提供可回收或环境效果依据 | 新增判断逐句查来源 |
| 双方材料 | 塑料、金属各有版本 | 商品范围与输入是否完整 |
| 生成覆盖 | 双方送达仍仅采用一方 | 原文与实际返回对应 |
| 补充验证 | 适用说明与真实输入形式 | 同题复测及图片路径另核 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `AI Proxy依赖` | 按实际版本核服务、渠道与应用。 |
| `AIPROXY_API_ENDPOINT` | 使用AI Proxy服务根地址。 |
| `AIPROXY_API_TOKEN` | 管理员Token非空且与服务端一致。 |
| `模型能力` | 按实际输入路径验证所需能力。 |
| `应用参数` | 接口同名字段未必覆盖应用设置。 |

## 容易做错的三处

- 材质原句未进入请求，输出却列具体商品材料：保留实际输入和句子，查历史或生成扩展，连接正常不证明事实有据。

- 塑料与金属均已送达却只采较早附页：核同一商品及版本，再并列返回定位覆盖，不通过模型选择决定真实材质。

- 塑料被扩成可回收或环保效果：回查适用说明和所引条件，没有出处仍待核；补资料后保持原题及设置核新增采用。

## 怎么确认配好了

对可回收性的追问应明确缺少什么来源，暂不要求模型给出肯定或否定结论。可以检查草稿是否从“塑料”补出“可回收”，以及所引材料是否真的包含该条件；没有出处时仍保留待核。补充适用说明后，在原问题和相同设置下复测，记录输入与被采用的段落。若实际文件包含图示或标签图片，另核对应能力，不由当前文字结果推定全部资料形式已经验证。
