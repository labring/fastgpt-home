# 便利店加盟门店督导的商品与营销文案起草：引用来源与溯源

## 这个品类的数据长什么样
加盟督导场景里，商品与营销文案的核对对象来自督导APP、加盟系统、门店照片与总部下发的陈列标准。总部对加盟商执行标准的监督是这一品类区别于直营订货的核心关系，因此文案里出现的促销表述、商品状态和陈列要求，往往需要回到巡店表、加盟合同、整改通知或陈列标准中找依据。周与月的更新节奏意味着同一份材料存在版本先后，起草时先确认所引材料的版本与适用范围，再判断拟稿句是否有对应文字支撑。数据出错会牵动加盟纠纷、品牌形象与合同违约，这使溯源在本任务中属于前置核对动作。

## 这些特征在「引用来源与溯源」这一环带来什么约束
知识库搜索节点可选择多个相同向量模型的知识库，用于向量搜索；不同向量模型的库不可共同关联，核对时先看标识并排除不符合者，不执行跨模型检索来比较漏召回。该节点以数组格式输出引用，长度可以为0，意味着没有搜索到内容时输出链路仍会走通；空数组不等于工作流已经报错终止。检索输出需要交给回答环节，逐条核对回答与引用原文。相似度得分与最低相关度属于过滤阈值，不承担权限或实体隔离功能，检索本身不是授权。全文检索与语义检索、混合检索、结果重排属于可选路径，图片检索须有图像输入及模型能力，重排须具备模型并按设置启用，文档流程图列出路径不代表每次请求全部执行。思考预算属于模型思考强度配置，与引用token上限是两回事。

假设演练样本：某加盟合同附件《陈列标准》2026年3月版载明“端架第二层陈列常温乳饮，单店单日促销价签由总部统一模板打印”；同期巡店表记录该店端架第二层为常温乳饮，价签为手写。一条待判定拟稿句为“本店促销价签按总部统一模板执行”。核对对象是同一门店、同一期间、同一字段“价签形式”，材料原文与拟稿句在该字段上取值互斥，属于矛盾；若巡店表未记录价签形式，则属于未获支持，需要保留证据缺口。

## 配置怎么定
下表仅列与本页任务相关的已说明设置或实施核对项，数值为本次假设试验起点，不作为官方默认值。

| 配置或核对项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| 关联的知识库 | 选取陈列标准库与加盟合同库 | 两库向量模型标识一致才可共同关联，与不符合者排除后比较 |
| 引用内容输出 | 按数组承接，允许长度为0 | 与空数组下游承接设计比较，确认链路走通 |
| 引用输入承接 | 检索输出交给回答环节 | 与逐条回答原文比较，确认引用可回溯 |
| 搜索模式 | 编号、模板名走全文或混合检索 | 与语义检索结果比较，精确字段优先关键词命中 |
| 最低相关度 | 本次假设起点0.5 | 与召回内容比较，过低则结果偏泛 |
| 回复格式 | 普通问答保持默认 | 与json_schema需求比较，仅固定结构时修改 |

## 容易做错的三处
1. 将相似度得分当作权限或实体过滤，认为调高最低相关度即可排除无关门店或未授权记录。应核对的是检索范围与资料版本，权限判断需要另接系统实现。
2. 把不同向量模型的知识库共同关联后推断漏召回或返回冗余。文档只说明需相同向量模型，运行结果未载明，应核对标识并记录实际观察。
3. 将思考预算或引用上限混用，用思考强度控制引用token数量。两者字段不同，应分别核对各自配置项。

对应检查：检查一，输入两个向量模型标识不同的库，比较是否可共同关联，可关联才满足条件；检查二，输入明确的纸面空数组[]，比较下游承接设计是否走通，走通才满足条件；检查三，输入一条拟稿句与材料原文，比较同主体、同期间、同字段取值，取值互斥记为矛盾，未载明记为未获支持。

## 怎么确认配好了
- 验证一，输入假设样本中的陈列标准原文与拟稿句，比较“价签形式”字段取值，材料为总部统一模板、拟稿句称按模板执行而巡店表记录手写，出现同字段互斥取值即识别为矛盾。
- 验证二，输入巡店表未记录价签形式的版本，比较该字段是否有载明，未载明即记为未获支持，保留证据缺口。
- 验证三，输入检索输出数组，比较其是否交给回答环节并逐条对应原文，引用可回溯才满足条件；空数组按允许长度为0承接，不据此断言报错。三项均写明预期，未实际执行。
