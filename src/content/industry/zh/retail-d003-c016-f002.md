# 加盟商培训与开业辅导的商品与营销文案起草：上下文与 token

## 这个品类的数据长什么样

在加盟商培训与开业辅导的商品与营销文案起草中，本页说明FastGPT的上下文与 token如何衔接资料。核培训模拟、纸面考核与开业实操的不同阶段，检查本轮材料和旧班次历史。所用场景为自拟文字测试。

## 这些特征在「上下文与 token」这一环带来什么约束

加盟开业辅导的介绍稿，可拟培训备注：“本轮完成收银模拟，实机环节另排。”考核记录只写“完成纸面识别”。历史稿件曾介绍另一批门店的实机练习，当前不能借用那批结果。起草时先核本轮材料和班次是否实际进入请求，再查看历史中的门店与活动对象。收银模拟、纸面考核和实机练习并列出现，不说明它们已经在本轮全部完成，也不能由签到材料认定学员具备独立操作能力。

## 配置怎么定

| 上下文核对项 | 本题材料 | 验收动作 |
| --- | --- | --- |
| 活动阶段 | 收银模拟与实机另排 | 保留本轮限制。 |
| 考核性质 | 仅纸面识别完成 | 不补出操作技能结果。 |
| 历史身份 | 另一批门店练习 | 核班次与活动对象。 |
| 新增记录 | 同一班次实机材料 | 原题查看真实参与。 |
| 长度检查 | 能力、引用与回复分开 | 核本次实际传入。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `模型上下文` | 以实际模型可接收范围为准。 |
| `回复长度` | 回复上限不同于上下文窗口。 |
| `知识库引用上限` | 知识引用上限按token计。 |
| `历史输入核对` | 比较空历史与带历史的输入。 |
| `结构化承接` | 先验解析，再核字段事实依据。 |

## 容易做错的三处

- “实机环节另排”从输入丢失，介绍稿把模拟写成实机完成时，对照完整备注、实际请求和稿件，定位阶段条件遗漏。

- 另一批门店练习被用于“这一轮”的追问时，固定当前材料比较有无历史，核班次、门店和活动身份。

- 纸面识别记录被写成已经掌握操作时，检查对应实操依据；可解析的考核摘要不证明未给出的技能结果。

## 怎么确认配好了

验收分别问本轮做过什么、哪一环另排以及考核记录支持什么，逐句核实际输入和输出。若实机记录后续补入，先核同一班次，再用原题检查新增来源。模型上下文能力及配置与本次输入范围分别核；引用token上限和回复长度也分开记录，不能靠增加回复补出实操依据。介绍稿应保留这些阶段，培训结束与门店正式开业仍需各自记录。所用文字仅作自拟测试，不描述真实学员成绩。
