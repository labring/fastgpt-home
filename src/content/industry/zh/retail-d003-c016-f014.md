# 加盟商培训与开业辅导的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

加盟商培训与开业辅导属于经营能力移交，与特许备案管理的法律披露性质不同。日常材料包括培训签到表、开业检查表、SOP手册和考核成绩，来源为培训系统、督导APP、门店照片和总部SOP库。商品与营销文案起草要引用这些材料，文案中的宣传句必须能在材料原文里找到对应事实。

本页只处理模型接入与配置：把模型渠道接通，使起草环节可以调用语言模型生成文案草稿。材料是否支持某句宣传语，属于文案核对任务，不在本页展开。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入依赖 AI Proxy。App 与 Admin 服务必须设置 `AIPROXY_API_ENDPOINT` 和非空 `AIPROXY_API_TOKEN`，缺少任一项启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。`AIPROXY_API_ENDPOINT` 填服务根地址，不附加 `/v1`。系统至少需要一个语言模型和一个索引模型才能正常使用；语音识别模型仅生效一个。

模型渠道在管理员-模型提供商页面创建，填写渠道名、协议类型、模型、模型映射、代理地址和 API 密钥。代理地址填 `BaseUrl`，注意是否需要增加 `/v1`。渠道创建后可执行模型测试，输出每个模型的测试结果与请求时长。

假设演练样本：某连锁品牌培训部准备起草一份开业辅导商品介绍。供核对的材料原文为三句：一，培训签到表载明“2026年3月10日，某加盟店店主完成收银与库存课程签到”；二，开业检查表载明“2026年3月12日，该店开业物料检查通过”；三，SOP手册载明“收银动作按第三章执行”。一条待判定的拟稿句为“该店已完成全部开业辅导并通过考核”。材料未载明考核成绩，拟稿句中的“通过考核”无对应证据。

## 配置怎么定

下表围绕上述样本，列出与本功能、本任务相关的官方已说明设置或实施核对项。需要数值处为本次假设试验起点，并说明选取理由与比较对象。

| 配置项 | 本次假设起点 | 说明与核对方式 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 假设填 `http://aiproxy:3000` | 官方要求填根地址，不附加 `/v1`。核对是否以 `/v1` 结尾。 |
| `AIPROXY_API_TOKEN` | 假设填与服务端一致的非空值 | 官方要求非空且与服务端一致。核对是否为空、是否误用应用 API Key。 |
| 语言模型 | 假设启用一个语言模型 | 官方要求至少一个语言模型。核对模型状态是否为已启用。 |
| 索引模型 | 假设启用一个索引模型 | 官方要求至少一个索引模型。核对模型状态是否为已启用。 |
| 渠道代理地址 | 假设填厂商 `BaseUrl` | 官方要求填 `BaseUrl`，注意是否需加 `/v1`。核对是否误填完整请求地址。 |
| 模型映射 | 假设将 `gpt-4o-test` 映射到 `gpt-4o` | 官方示例：FastGPT 请求 `gpt-4o-test`，AI Proxy 向上游发送 `gpt-4o`。核对映射键值是否对应。 |

## 容易做错的三处

1. 把 `AIPROXY_API_ENDPOINT` 填成带 `/v1` 的完整请求地址。输入为环境变量值，比较对象为官方“根地址、不附加 `/v1`”的要求，观察结果为该值以 `/v1` 结尾。
2. 用应用 API Key 充当 `AIPROXY_API_TOKEN`。输入为 Token 值，比较对象为官方“管理员 Token、与服务端一致”的要求，观察结果为该值与服务端管理员 Token 不一致。
3. 在渠道代理地址填入完整模型请求地址。输入为渠道代理地址字段，比较对象为官方“填 `BaseUrl`”的要求，观察结果为该字段包含具体接口路径。

## 怎么确认配好了

1. 针对样本拟稿句“该店已完成全部开业辅导并通过考核”，输入为材料原文三句与拟稿句，比较对象为材料是否载明考核成绩，观察结果为材料未出现考核成绩字段，该句未获支持。
2. 针对 `AIPROXY_API_ENDPOINT` 假设起点 `http://aiproxy:3000`，输入为该值，比较对象为官方根地址要求，观察结果为不以 `/v1` 结尾，满足条件。
3. 针对模型映射假设键值 `gpt-4o-test` 到 `gpt-4o`，输入为映射配置，比较对象为官方示例，观察结果为请求模型与上游模型分别对应，满足条件。若映射键值不一致，记录为待核实，不判定为渠道失效。
