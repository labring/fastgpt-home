# 原产地证书申办的商品与营销文案起草：多轮对话与提示词

## 这个品类的数据长什么样

在原产地证书申办的商品与营销文案起草中，本页说明FastGPT的多轮对话与提示词如何衔接资料。区分商品属性、认证声明与仍缺的营销依据。所用场景为自拟文字测试。

## 这些特征在「多轮对话与提示词」这一环带来什么约束

为原产地资料文案另拟一份中性商品附页，只写棉质T恤及自然白颜色，不附带品质等级、认证或受众结论。提示词先限定可复述的属性，再检查历史里关于其他商品的描述是否进入当前草稿。商品资料可用于说明现有文字，但原产资格需要其他依据；不能因任务与证书申办有关，就在文案中补入已获认证的说法。新会话的同题输入可作为历史影响的对照。

## 配置怎么定

| 对话或实施核对项 | 中性文字样例条件 | 验收目标 |
| --- | --- | --- |
| 属性范围 | 棉质T恤与自然白颜色 | 不补入品质、认证或受众结论 |
| 历史影响 | 同题在新会话中作对照 | 其他商品属性有无进入 |
| 认证描述 | 发票有描述，成本资料未提及 | 区分声明存在与证据已取得 |
| 问题优化 | 保留待补认证依据的状态 | 避免被改写成无依据二选一 |
| 营销缺项 | 卖点与客户定位需要资料 | 新增说法逐项回查来源 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `提示词与任务` | 说明资料、任务和缺证据处理。 |
| `历史记录` | 核实际提交的历史输入。 |
| `问题优化` | 指代消除与问题扩展需复核。 |
| `模型与长度` | 上下文与回复长度分别核对。 |
| `回复格式` | json_schema需给格式并验解析。 |

## 容易做错的三处

- 旧稿中的认证句被重复采用为当前依据：并列当前原文、历史与新增句，用仅含本轮资料的新会话查来源，出现过不说明已获证。

- 成本资料未提认证，被问题优化改成否定证明：保留前后问题与双方来源，区分信息缺席和反驳，不能强迫非真即假的采信。

- 名称、棉质与颜色被扩成独特卖点或确定受众：逐句核用途及定位依据，现有属性不提供这些信息；补相应说明后原题复测。

## 怎么确认配好了

现有商品名称、材质和颜色不能自动给出独特卖点或目标客户。连续要求改换受众、强调用途时，应核对实际历史与新一轮提供的资料，标出没有原文支持的新增说法。取得产品定位或使用说明后，再用原写作任务检查每项内容的出处。若没有补充来源，保持描述范围比把未知条件写成明确营销结论更符合这项阅读测试。

| --- | --- |

| 候选来源 | 中国国际贸易单一窗口、贸促会系统、企业生产记录、客户清关要求 |
