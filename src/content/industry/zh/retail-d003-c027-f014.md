# 品牌经销商订货会的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

品牌经销商订货会的数据来自订货会系统、历史销售、经销商库存与财务授信，更新节奏按季、按年。这一品类面向线下经销商预订，不直接管理平台店铺。商品与营销文案起草要处理订货手册、订货合同、样品清单与授信审批。这些材料决定文案能引用哪些商品信息、政策口径与授权范围。文案起草所需的模型接入，须先确认材料本身是否载明主体、对象与有效范围，再判断拟稿句是否被材料支持。

## 这些特征在「模型接入与配置」这一环带来什么约束

从 V4.17.0 起，AI Proxy 为必需依赖。App 与复用 App/Service 配置的 Admin 服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空的 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。系统至少需要一个语言模型和一个索引模型才能正常使用。模型 ID 是请求 Body 中 `model` 字段的值，全局唯一；模型名用于展示，可以自定义。模型渠道是不同模型提供商的协议，一个模型可以配置在不同渠道中实现负载均衡。

假设演练样本：某品牌渠道部准备一份订货会商品文案。供核对的材料原文为：「本次订货会样品清单载明 A 型保温杯，容量 500 毫升，颜色为雾灰与藏青，样品编号 SP-01。」「订货手册写明，A 型保温杯本季订货起订量为 200 件，报价有效期为订货会当日起 15 天。」待判定的拟稿句为：「A 型保温杯支持 500 毫升容量，并提供雾灰、藏青两色，本季起订 200 件。」该样本仅用于纸面核对，不涉及真实客户或真实编号。

## 配置怎么定

下表只列与本页功能、主任务相关的官方已说明设置或实施核对项。数值一栏中标注为假设试验起点的，仅用于本次纸面比较，不作为官方默认值。

| 设置或核对项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 假设填 `http://aiproxy:3000` | 官方说明为 AI Proxy 服务根地址，不附加 `/v1`；与文档示例比较 |
| `AIPROXY_API_TOKEN` | 假设填非空管理员 Token | 官方要求非空且与服务端一致；与空值比较 |
| 语言模型 | 假设启用一个语言模型 | 官方要求系统至少一个语言模型；与未启用状态比较 |
| 索引模型 | 假设启用一个索引模型 | 官方要求系统至少一个索引模型；与未启用状态比较 |
| 模型 ID | 假设核对为全局唯一值 | 官方说明模型 ID 为请求 Body 中 `model` 字段值；与渠道中的模型名比较 |
| 渠道测试 | 假设在模型测试页执行一次 | 官方提供渠道测试以确认配置模型有效；与未测试状态比较 |

## 容易做错的三处

1. 把 `AIPROXY_API_ENDPOINT` 填成完整模型请求地址并附加 `/v1`。官方说明该变量为 AI Proxy 服务根地址，不要附加 `/v1`。输入为带 `/v1` 的地址，比较对象为文档示例 `http://aiproxy:3000`，可观察结果为启动校验或调用路径与预期不一致。

2. 用应用 API Key 代替 `AIPROXY_API_TOKEN`。官方要求该 Token 为管理员 Token，必须与服务端配置一致且不能为空。输入为应用 API Key，比较对象为服务端配置的管理员 Token，可观察结果为认证不通过。

3. 在拟稿句中写入材料未载明的宣传句。样本材料只载明容量、颜色、起订量与报价有效期，未载明其他功效或授权。输入为超出材料的拟稿句，比较对象为样品清单与订货手册原文，可观察结果为该句未获支持。

## 怎么确认配好了

1. 输入假设样本中的材料原文与拟稿句，比较拟稿句中的容量、颜色、起订量是否与原文同主体、同字段一致。原文载明 500 毫升、雾灰与藏青、200 件，拟稿句与之一致时满足条件；若拟稿句出现原文未载明的字段，则记录为未获支持。

2. 输入假设的 `AIPROXY_API_ENDPOINT` 值，比较其是否为服务根地址且不含 `/v1`。与文档示例一致时满足条件；含 `/v1` 或为完整请求地址时记录为配置错误。

3. 输入假设的语言模型与索引模型启用状态，比较系统是否至少各有一个。两者均启用时满足条件；任一缺失时记录为未满足官方使用前提。以上均为纸面核对，未实际部署或测试。检索与相关度不承担权限或实体隔离；空结果可用明确的纸面输入 `[]` 核对下游设计，不能声称虚构规则检索一定返回空。跨不同向量模型的库不可共同关联，只核标识并排除不符合者。
