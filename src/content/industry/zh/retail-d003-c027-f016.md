# 品牌经销商订货会的商品与营销文案起草：表单与交互

## 这个品类的数据长什么样

在品牌经销商订货会的商品与营销文案起草中，本页说明FastGPT的表单与交互如何衔接资料。订货会文案表单保留定制待评估、样衣标识用途与可选辅料，不把展示作量产承诺。所用场景为自拟文字测试。

## 这些特征在「表单与交互」这一环带来什么约束

自拟订货会素材有样衣图片说明，图上标识仅作展示；厂方回复说定制需求需看图再评估，辅料清单标可另选。表单收系列、样衣用途和这些原句，人员选择补定制意见或核辅料组成，再交写作。展示图不证明可使用任何品牌标识，看图评估也不是已承接量产。本题没有真实订单、定制参数或价格，不从填写需求推采购承诺。

## 配置怎么定

| 订货会宣传表单 | 自拟限制 | 起草核法 |
| --- | --- | --- |
| 定制回复 | 看图后再评估 | 不许诺全图案量产 |
| 样衣标识 | 仅展示 | 不当使用授权 |
| 辅料清单 | 可另选 | 不写每套必含 |
| 人员路径 | 定制或组成 | 核实际原句传入 |
| 正式采购 | 业务认可另核 | 不因填需求成交 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入` | 收集输入并在提交后传值。 |
| `必填信息核对` | 业务必填与缺项处理需另设计。 |
| `用户选择` | 选择结果对应已连接的分支。 |
| `交互状态` | 分别核等待和完成交互状态。 |
| `后续处理分工` | 校验、审批及写入另核结果。 |

## 容易做错的三处

- 待看图评估被成稿写成所有图案都能量产时，对厂方原回复及本次需求，保留尚未评估条件。

- 样衣标识被文案当成可供经销商直接使用的授权时，核展示用途与实际使用许可，图片存在不能替权利依据。

- 可另选辅料被写成每套必含时，对清单组成及实际选配确认，不以样衣画面补随附范围。

## 怎么确认配好了

比较表单提交与两条路径实际接收的系列、用途和缺项，让起草人指出每个定制或包含承诺的出处。补厂方意见只覆盖相应需求，不能扩其他图案；辅料确认亦单独核。业务审核、标识使用、正式下单及资料回填需授权流程与回执，表单只承接素材，不认证供应能力或代双方成交。输出解析成功后仍需逐句核条件，不能让完整宣传稿掩盖未确认事项。
