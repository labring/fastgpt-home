# 品牌自播直播间运营的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

品牌自播由品牌自己承担话术、库存和售后，直播脚本、商品讲解卡、排班表与直播复盘是日常文档。商品与营销文案起草环节需要把讲解卡里的卖点、库存状态和活动口径写成可播出的句子，素材来自抖店罗盘、巨量千川、直播间评论与成交明细。文案一旦与材料不符，会带来虚假宣传投诉和转化下滑。本页只处理模型接入与配置如何支撑这一起草任务，不涉及达人佣金结算。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入依赖 AI Proxy。自 V4.17.0 起，App 与复用 App/Service 配置的 Admin 都必须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺少任一项启动校验失败；旧 OpenAI 环境变量或单模型自定义请求地址不能替代。AIPROXY_API_ENDPOINT 填服务根地址，不附加 /v1。模型能力按应用所需输入核对：图文讲解卡涉及图片时需模型支持图片输入，工具调用与函数调用分别验证。应用参数在应用或节点配置中设置，不能假设兼容对话接口的同名字段会覆盖编排。系统至少需要一个语言模型和一个索引模型才能正常使用。

假设演练样本（纸面材料，非真实记录）：

材料原文一：「本场主推款 A 为春季薄款外套，面料成分标注为棉 60%、聚酯纤维 40%，当前可售库存 120 件。」

材料原文二：「活动口径：本场下单赠同款收纳袋，赠品以订单实际支付后系统登记为准。」

待判定拟稿句：「这款外套是纯棉面料，库存充足，下单立即赠送收纳袋。」

## 配置怎么定

下表为本次假设试验起点，用于纸面核对，不是官方默认值。

| 配置项 | 本次假设起点 | 选择理由与比较对象 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设填 `http://aiproxy:3000` | 与服务根地址格式比较，确认未附加 /v1 |
| AIPROXY_API_TOKEN | 假设填一个非空管理员 Token | 与服务端配置比较，确认一致且非空 |
| 语言模型 | 假设启用一个已测试通过的语言模型 | 与渠道测试结果比较，确认可用 |
| 索引模型 | 假设启用一个已测试通过的索引模型 | 与系统最低要求比较，确认已满足 |
| 模型能力 | 假设按图文讲解卡核对图片输入与工具调用 | 与拟稿任务所需输入比较 |
| 应用参数 | 假设在应用或节点配置中设置 | 与对话接口同名字段比较，确认不互相覆盖 |

## 容易做错的三处

1. 把 AIPROXY_API_ENDPOINT 写成带 /v1 的完整请求地址。检查输入字段值与服务根地址格式，观察是否附加了路径后缀。
2. 用应用 API Key 充当 AIPROXY_API_TOKEN。检查 Token 来源与服务端配置，观察是否一致且非空。
3. 假设对话接口的同名字段会覆盖应用编排参数。检查参数设置位置，观察编排节点配置是否被实际采用。

## 怎么确认配好了

以下验证使用前述假设样本，均为纸面推演，未实际执行。

1. 输入材料原文一与拟稿句「纯棉面料」。比较材料标注的棉 60%、聚酯纤维 40% 与「纯棉」表述，观察两者是否同主体、同字段且取值互斥；若互斥则拟稿句未获材料支持。
2. 输入材料原文二与拟稿句「下单立即赠送收纳袋」。比较材料所述「以订单实际支付后系统登记为准」与「立即赠送」，观察拟稿句是否超出材料载明的状态范围；超出部分属未获支持。
3. 输入材料原文一与拟稿句「库存充足」。比较材料给出的可售库存 120 件与「充足」这一未定义表述，观察材料是否载明判定充足的阈值；未载明时该表述待核实，不判定为否定或冲突。

三项验证均只针对文案是否被材料支持，不涉及企业身份认证、报告分析或其他任务。
