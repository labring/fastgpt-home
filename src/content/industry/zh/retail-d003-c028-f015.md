# 品牌自播直播间运营的商品与营销文案起草：知识库检索与召回

## 这个品类的数据长什么样

品牌自播由品牌自身承担话术、库存与售后，直播脚本、商品讲解卡、排班表、直播复盘构成日常文档主体，数据来源包括抖店罗盘、巨量千川、直播间评论与成交明细，更新频率为每场或小时级。商品与营销文案起草依赖这些材料：讲解卡提供商品对象与卖点，脚本提供话术口径，复盘提供历史转化反馈。检索环节需要把拟稿句与材料原文对齐，确认宣传表述是否被材料支持。更新频率本身不改变检索配置，但材料版本随场次变化，检索前需确认所用版本与当前场次一致。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的库，最小搜索单位是库，集合仅作分类管理。搜索模式可选语义检索、全文检索或混合检索；混合检索通过 RRF 融合多路结果，RRF 是融合过程，不是开关。引用上限以 token 为单位，最低相关度仅在语义检索或使用结果重排时生效。问题优化用于指代消除和问题扩展，会增加一次模型调用。重排需具备模型并按设置启用，图片检索需有图像输入及相应模型能力。相似度与相关度不承担权限或实体隔离功能，检索结果不构成授权。

假设演练样本：某品牌自播团队材料原文为三句——“本场讲解商品为A款保温杯，容量500毫升，材质为304不锈钢。”“A款保温杯本场直播售价为99元，活动期间为2025年3月1日至3月7日。”“A款保温杯不参与七天无理由退货。”拟稿句为“A款保温杯容量500毫升，304不锈钢材质，售价99元，支持七天无理由退货。”核对目标为：容量与材质是否与第一句一致，售价与活动期间是否与第二句一致，退货表述是否与第三句同字段互斥。第三句与拟稿句在退货字段上取值相反，构成同字段矛盾；活动期间与售价为第二句载明内容，拟稿句未写活动期间，属于未完整引用，不构成矛盾。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联含上述三句原文的库 | 该库与拟稿句同向量模型；核标识后排除其他模型库 |
| 搜索模式 | 混合检索 | 拟稿句含商品名与数值，需关键词与语义双路；与单独语义检索结果比较 |
| 引用上限 | 假设起点为800 token | 原文三句合计较短，取能覆盖完整句的值；与500、1200比较内容完整性 |
| 最低相关度 | 假设起点为0.3 | 先标注相关与无关样本再调；与0.2、0.5比较漏召回与噪声 |
| 问题优化 | 本样本开启 | 拟稿句主体明确，用于核对指代是否被改错；与关闭结果比较 |
| 结果重排 | 本样本启用 | 候选较多时二次排序；与不启用结果比较排序变化 |

上述数值为本次纸面试验起点，不是官方默认值。配置表仅覆盖本页文档与主任务，不涉及数据库内部实现。

## 容易做错的三处

1. 把最低相关度当作权限或实体过滤。错误表现：认为设置阈值即可排除无关业务或未授权记录。检查：输入拟稿句，比较返回内容是否仅由相似度决定，确认权限需另接系统实现。
2. 把混合检索后的 RRF 融合写成可开启开关。错误表现：在配置中新增“RRF开关”。检查：核对文档中 RRF 为融合过程，确认配置项中不存在该开关。
3. 把未载明字段判为矛盾。错误表现：拟稿句未写活动期间，被判定与原文冲突。检查：比较同字段取值，确认未载明属于未获支持，仅同字段互斥取值才构成矛盾。

## 怎么确认配好了

1. 输入假设原文三句与拟稿句，比较容量、材质、售价字段是否一致，退货字段是否同字段互斥。预期现象：前三项一致，退货字段出现矛盾提示。
2. 输入明确的纸面空结果 `[]`，核对该输出链路是否仍走通。预期现象：引用内容长度为0，下游设计可承接空数组，不声称虚构规则检索必然返回空。
3. 输入拟稿句并开启问题优化，比较优化后问题与拟稿句主体是否一致。预期现象：主体未被改错，指代消除结果可核对；优化耗时增加属可观察现象，不声称已实测。

以上均为纸面核对，未执行实际检索、部署或审批。缺失字段保持未知，待审核不代表已批准，报价有效期不代表供货期限。
