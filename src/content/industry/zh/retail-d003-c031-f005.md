# 商超塑料袋与一次性用品报告的商品与营销文案起草：多轮对话与提示词

## 这个品类的数据长什么样

该品类围绕一次性塑料制品报告与环保监管展开，资料来自商务部报告系统、POS塑料袋销售、采购系统与门店台账，日常文档包括塑料袋采购台账、销售凭证、半年报告与自律承诺。商品与营销文案起草环节需要从这些材料中提取可核对的事实，用于生成或改写面向消费者的说明文字。材料中的主体、对象、状态与有效范围构成文案可引用的边界，超出边界的表述在后续核对中会暴露为无依据内容。半年报告与日更销售数据的更新节奏不同，文案起草时需区分引用的是哪一类材料，避免把阶段性统计当作持续状态描述。

## 这些特征在「多轮对话与提示词」这一环带来什么约束

多轮对话中，历史记录会带入前文内容，提示词需要写明资料范围、回答任务以及缺证据时的处理方式。模型不应补写业务事实，遇到材料未载明的主体、数量或状态，应保留为待核实项。继续会话时，系统按 chatId 从数据库取会话，messages 数组最后一个内容作为用户问题，其余 message 被忽略；新会话不传入 chatId 时完全通过传入的 messages 构建上下文。问题优化环节涉及指代消除与问题扩展，并非所有短问题都适用，需核对实际带入的上下文。模型支持的上下文长度与回复上限影响长文档与追问组合的处理，回复格式按后续承接选择，选择 json_schema 时需填写对应格式要求并验返回结构。

假设演练样本：某商超门店台账记载“2025年3月采购一次性塑料袋12000只，销售凭证显示同期POS售出8500只，半年报告初稿拟写‘本店塑料袋使用量持续下降’”。拟稿句为“本店塑料袋使用量持续下降”。核对时比较台账采购数量、POS销售数量与半年报告初稿的表述范围，判断“持续下降”是否有同期间、同字段的明确互斥取值支持。该样本为纸面演练，不涉及真实客户或实际报送。

## 配置怎么定

| 配置项 | 本次假设起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 记忆轮数 | 保留少量历史轮数 | 客服与知识库问答类应用通常保留少量历史轮数，比较继续会话时实际带入的上下文是否覆盖当前核对所需材料 |
| 回复上限 | 打开并适当调高 | 生成方案或较长说明时适当调高，比较回复是否被提前截断 |
| 温度 | 偏低 | 文案起草需稳定引用材料，比较不同轮次对同一材料的表述是否一致 |
| 回复格式 | 默认 | 普通问答保持默认，后续流程需读取固定格式时再改 |
| 多模态识别 | 按模型能力开启图片识别 | 材料含截图或表格图片时使用，比较请求发送前是否按模型能力过滤 |
| 隐藏 AI 输出 | 关闭 | 调试时观察中间结果，比较最终展示与内部处理是否一致 |

以上为本次假设试验起点，非官方默认值。

## 容易做错的三处

1. 把“持续下降”当作已确认事实写入文案。输入为台账采购数量与POS销售数量，比较同期间同字段是否有明确互斥取值，若材料仅显示单一期间数据，该表述属于未获支持。
2. 将历史记录中的前文内容当作当前材料的证据。输入为继续会话时带入的上下文，比较其是否来自本次核对范围，若来自其他会话或不相关材料，不能作为当前文案依据。
3. 把相似度分数当作权限或实体过滤条件。输入为检索返回的相关度数值，比较其是否被用于排除无关记录，检索本身不承担授权判断。

## 怎么确认配好了

1. 输入假设样本中的台账原文、销售凭证原文与拟稿句，比较拟稿句中的“持续下降”是否被同期间同字段的明确互斥取值支持，若材料仅显示单期数据则标记为待核实。
2. 输入继续会话的 chatId 与 messages 数组，比较系统实际带入的历史轮数是否与配置的记忆轮数一致，观察最后一条 message 是否被作为用户问题、其余是否被忽略。
3. 输入空引用结果 [] 的纸面场景，比较下游节点是否按无引用内容处理，不声称虚构规则检索一定返回空结果；若实际返回非空，记录观察到的内容并核对来源标识。
