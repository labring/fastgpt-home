# 商超塑料袋与一次性用品报告的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

该品类围绕一次性塑料制品报告与环保监管展开，主要材料来自商务部报告系统、POS塑料袋销售记录、采购系统与门店台账，日常文档包括塑料袋采购台账、销售凭证、半年报告与自律承诺。文案起草需要核对的是采购台账中的材质、规格、数量与日期区间，以及销售凭证中的对应记录。数据更新频率为半年与日两类，本页不据此推导批量同步或实时触发机制。起草环节最耗时的是统计使用量与核对销售凭证，模型接入配置因此要把材料原文与拟稿句之间的对应关系固定下来，避免文案超出材料可支撑的范围。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入由 AI Proxy 承担，App 与 Admin 共享配置中 `AIPROXY_API_ENDPOINT` 与 `AIPROXY_API_TOKEN` 为必填，缺少任一项会导致启动校验失败，旧 OpenAI 环境变量或单模型自定义请求地址不能替代。`AIPROXY_API_ENDPOINT` 填写服务根地址，不附加 `/v1`。模型能力按应用所需输入核对，多模态、工具调用与思考配置分别验证。应用参数在应用或节点配置中设置，不能假设兼容对话接口的同名字段会覆盖编排。系统至少需要一个语言模型和一个索引模型才能正常使用。检索与相关度不承担权限或实体隔离职责，检索库同向量模型的要求不扩展到外部系统。

假设演练样本：某门店台账原文为「2025年3月1日至3月31日，采购一次性塑料袋共12000只，材质为高密度聚乙烯，规格为30cm×50cm，供应商为A包装厂；同期POS塑料袋销售记录为11500只」。待判定拟稿句为「本店塑料袋全部采用可降解材质，月销量稳定超过12000只」。核对点为材质表述与台账记载的材质是否一致，销量数字与销售凭证记载的数量是否一致。

## 配置怎么定

| 配置项 | 本次假设起点 | 与什么比较 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 假设填 `http://aiproxy:3000` | 是否为服务根地址且不带 `/v1` |
| `AIPROXY_API_TOKEN` | 假设填与服务端一致的非空 Token | 是否非空且与服务端一致 |
| 语言模型与索引模型 | 假设各启用一个 | 是否满足系统最少一个语言模型与一个索引模型 |
| 模型能力核对 | 假设按文案任务所需输入逐项核对 | 多模态、工具调用与思考配置是否分别验证 |
| 应用参数 | 假设在应用或节点配置中设置 | 是否误以为对话接口同名字段会覆盖编排 |

假设起点的选取理由是把接入地址与凭证先固定，便于逐项核对；比较方法为对照官方文档中该变量的填写规则。

## 容易做错的三处

1. 把 `AIPROXY_API_ENDPOINT` 填成带 `/v1` 的完整请求地址。检查输入为拟填地址，比较对象为文档所述根地址规则，可观察结果为地址末尾是否多出 `/v1`。
2. 用应用 API Key 代替 `AIPROXY_API_TOKEN`。检查输入为拟填 Token，比较对象为文档所述管理员 Token 要求，可观察结果为该值是否与服务端配置一致且非空。
3. 把拟稿句中的材质与销量直接当作台账与销售凭证已载明。检查输入为拟稿句与台账原文，比较对象为材质字段与数量字段，可观察结果为台账记载材质为高密度聚乙烯、销售记录为11500只，与拟稿句的可降解材质和超过12000只不一致。

## 怎么确认配好了

1. 输入为假设台账原文与拟稿句，比较材质字段，若拟稿句材质与台账记载材质不一致，则判定该句未获材料支持。
2. 输入为假设销售凭证数量11500只与拟稿句数量表述，比较数量字段，若拟稿句数字与凭证记载不一致，则判定该句未获材料支持。
3. 输入为假设填写的接入地址与 Token，比较文档所述填写规则，若地址不带 `/v1` 且 Token 非空并与服务端一致，则接入配置项满足文档条件；若缺少任一项，启动校验失败，具体报错内容未在文档中给出，保持未知。
