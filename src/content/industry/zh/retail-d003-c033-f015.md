# 外汇收结汇与贸易名录的商品与营销文案起草：知识库检索与召回

## 这个品类的数据长什么样

外汇收结汇与贸易名录场景的资料围绕外汇资金与贸易背景真实性展开，主要来源包括国家外汇管理局政策、银行网银记录、企业财务账和海关出口数据。日常处理的文档为收汇水单、贸易合同、发票和外汇业务登记资料，更新频率为每单及每月。与信用证审单相比，该品类关注资金与贸易背景，不审全套信用证单据。这些特征直接影响知识库检索与召回：收汇水单包含收汇主体、金额和日期，贸易合同包含签约主体与标的，发票包含货物描述和金额。商品与营销文案起草时，检索需要从这些资料中召回与拟稿句相关的原文片段，用于核对宣传句是否被材料支持。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，需先核标识并排除不符合者。搜索模式分为语义检索、全文检索和混合检索，混合检索通过 RRF 融合多路结果，Rerank 对候选文本二次排序。引用上限以 token 为单位，最低相关度仅在语义检索或使用结果重排时生效。问题优化用于指代消除和问题扩展。图片检索须有相应图像输入及模型能力，重排须具备模型且按设置启用。检索是召回过程，不负责权限或实体隔离。

假设演练样本：材料原文为“甲方某某进出口有限公司与乙方某某贸易有限公司于二〇二五年三月签订服装出口合同，合同号 HX-2025-031，标的为棉制男式衬衫，数量五千件。乙方于二〇二五年四月通过银行收到甲方汇入的美元货款，银行水单显示付款人为某某进出口有限公司。”待判定拟稿句为“本产品已获得某某进出口有限公司的长期采购承诺。”拟稿句提及的采购承诺在材料原文中没有对应字段，材料仅载明合同号、标的、数量及一笔收汇记录。

## 配置怎么定

| 配置项 | 本页对应设置 | 核对方式 |
| --- | --- | --- |
| 关联的知识库 | 选择使用相同向量模型的收结汇资料库 | 核对各库向量模型标识一致，排除不一致者 |
| 搜索模式 | 按测试问题比较语义、全文与混合检索 | 对同一问题分别观察三路召回内容 |
| 引用上限 | 本次假设试验起点设为 2000 tokens，因样本原文较短且需完整召回合同与发票字段 | 与 1000 tokens 和 4000 tokens 比较，观察召回内容是否完整 |
| 最低相关度 | 先标注相关与无关样本再调阈值 | 用样本原文作相关样本，观察阈值变化后召回变化 |
| 问题优化 | 比较原问题与优化后问题 | 核对主体是否被改错 |
| 结果重排 | 具备 ReRank 模型且按设置启用 | 观察重排得分与引用内容排序 |

## 容易做错的三处

1. 将拟稿句中“长期采购承诺”直接视为材料已载明。输入为样本原文与拟稿句，比较“采购承诺”字段是否出现在原文中，观察结果为原文仅含合同号、标的、数量和一笔收汇记录，未载明采购承诺。
2. 将收汇水单中的付款人等同于合同甲方。输入为水单付款人与合同甲方，比较两者名称是否一致，观察结果为水单显示付款人为某某进出口有限公司，与合同甲方名称相同，但水单未载明该笔款项对应的合同号，无法确认该笔收汇与 HX-2025-031 的对应关系。
3. 将检索召回结果当作授权依据。输入为检索返回的引用内容，比较引用内容是否包含授权或审批字段，观察结果为引用内容仅含合同与收汇事实，未载明任何授权或审批信息。

## 怎么确认配好了

1. 输入样本原文与拟稿句“本产品已获得某某进出口有限公司的长期采购承诺”，比较拟稿句中的“采购承诺”是否在原文中有对应字段，观察结果为原文未载明该字段，判定为未获支持。若原文补充载明采购承诺条款，则需重新核对。
2. 输入样本原文与水单信息，比较水单付款人与合同甲方名称，观察结果为两者名称一致，但水单未载明合同号，判定该笔收汇与合同的对应关系待核实。若水单补充载明合同号 HX-2025-031，则可进一步核对。
3. 输入空引用数组与下游设计，比较下游是否能在引用长度为 0 时继续走通，观察结果为输出链路走通且不产生引用内容。若下游设计依赖引用内容，则需记录该缺口。
