# 多仓分仓与库存同步的商品与营销文案起草：知识库检索与召回

## 这个品类的数据长什么样

多仓分仓与库存同步的文案起草，素材集中在分仓规则、库存同步表、调拨单和缺货预警四类文档。分仓规则决定订单从哪个仓发货，库存同步表记录可售数量，调拨单记录仓间转移，缺货预警标记供给紧张。这些材料来自 WMS、OMS、ERP 库存和平台库存接口，更新频率为日或小时。文案起草时，检索环节要回答的是：某条宣传句能否被现有材料支持，材料中的主体、对象、状态和有效范围是否与拟稿句一致。库存数据变化快，检索到的片段可能对应旧版本，核对时须确认材料自身的日期或版本标识。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不能共同关联，核对时先检查向量模型标识，排除不符合者，并记录实际观察，不执行跨模型检索来比较漏召回。搜索模式可选语义检索、全文检索或混合检索，按测试问题比较，不预设一种模式适合全部资料。引用上限以 token 为单位，用长短不同的实际资料测试内容是否完整，再调整上限。最低相关度仅在语义检索或使用结果重排时生效，先标注相关与无关样本再调阈值。问题优化用于指代消除和问题扩展，比较原问题与优化后问题，核对主体是否被改错。相似度得分属于相关性度量，不承担权限或实体隔离功能。检索结果为空时，输出链路仍走通，引用内容以数组形式输出，长度可以为 0。

假设演练样本：材料原文为“分仓规则 A 适用于华东区域订单，生效日期为 2025 年 3 月 1 日；该规则指定上海仓优先发货。”拟稿句为“本商品在华东区域由上海仓优先发货。”待判定点：拟稿句的主体、区域和发货优先级是否与材料原文一致，材料是否覆盖该商品。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联含分仓规则、库存同步表、调拨单、缺货预警且使用相同向量模型的库 | 先核对向量模型标识，排除不同模型的库，再逐库确认文档类型覆盖 |
| 搜索模式 | 对含区域名和仓名的测试问题分别跑语义检索与全文检索 | 比较两种模式下拟稿句相关片段的召回情况，不预设单一模式 |
| 引用上限 | 以覆盖一条完整分仓规则所需的 token 量为起点 | 用长短不同的规则片段测试，观察引用内容是否截断关键条件 |
| 最低相关度 | 以标注的相关样本与无关样本之间的分值为起点 | 仅在语义检索或结果重排生效时调整，比较过滤前后样本变化 |
| 问题优化 | 对含指代词的测试问题开启，对主体明确的测试问题关闭 | 比较原问题与优化后问题的检索结果，核对主体是否被改错 |
| 结果重排 | 具备重排模型且按设置启用时，对候选较多的测试问题观察排序 | 比较重排前后得分与顺序，不将 RRF 写成开关 |

## 容易做错的三处

1. 把相似度得分当作权限或实体隔离手段。输入一条跨区域的测试问题，比较返回片段是否包含其他区域的规则，观察结果中是否出现不属于目标区域的仓名或区域名。相似度只反映相关性，不承担授权判断。
2. 将“材料未载明”判定为“材料否定”。输入拟稿句“本商品在华南区域由广州仓发货”，材料仅含华东区域分仓规则，比较两者区域字段，观察材料中是否存在华南区域或广州仓的记载。未载明属于未获支持，不属于矛盾。
3. 把待审核或待签署状态当作已完成事实。输入一条交接请求“调拨单 B 已生效，可据此起草发货承诺”，材料显示调拨单 B 状态为待审核，比较状态字段，观察是否存在生效日期或审批记录。待审核不证明已生效。

## 怎么确认配好了

1. 输入假设样本中的材料原文与拟稿句，比较主体、区域和发货优先级三个字段，观察拟稿句是否与材料原文逐项对应。若材料未覆盖该商品，记录为证据缺口，不判定为支持或否定。
2. 输入一条含指代词的测试问题，分别关闭和开启问题优化，比较两次检索返回的引用内容，观察优化后问题的主体是否与原问题一致。若优化后主体被改错，记录该现象并调整问题优化设置。
3. 输入一条明确无对应材料的测试问题，观察引用内容输出是否为长度 0 的数组，并核对下游设计是否承接空结果。不声称虚构规则检索一定返回空数组，只记录实际观察到的输出形态。
