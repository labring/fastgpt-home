# 大卖场生鲜联营柜台的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

大卖场生鲜联营柜台通常由供应商驻场经营并按销售分成，商品与营销文案的素材因此分散在联营合同、日销售报表、损耗单和食品进货查验记录四类文档中。联营合同界定可对外表述的合作范围与结算口径，日销售报表提供当日实际销售数据，损耗单记录报损与分摊情况，食品进货查验记录承载批次、供货方与查验状态。文案起草时，宣传句能否成立取决于这些材料是否同主体、同期间、同字段地支持该句。数据按日、按批更新，这一频率只说明资料给出的更新节奏，不推出任何批量同步、实时触发或全量刷新机制。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入需要 AI Proxy 作为必需依赖，App 与 Admin 均须设置 `AIPROXY_API_ENDPOINT` 和非空 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败，旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两项配置。模型配置在管理员-模型提供商页面完成，渠道填写 `BaseUrl`，模型映射将请求模型映射到上游实际模型。模型探测仅针对已启用模型，首次失败后最多重试 3 次，4 次全部失败才判定异常；探测间隔支持 5～60 分钟整数，告警 Webhook 在状态边沿变化时按模型逐条推送。检索库的向量模型标识需与查询一致，跨模型不具备共同关联条件。

假设演练样本：材料原文一为「甲方与乙方就生鲜柜台签订联营合同，乙方驻场经营，按销售额分成，合同期至某年某月」。材料原文二为「某日销售报表显示该柜台当日销售若干元」。材料原文三为「该批次食品进货查验记录载明供货方与查验状态」。待判定拟稿句为「本柜台生鲜由签约供应商直供，当日销售数据可查」。判定需核对主体、期间与字段是否一致。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填写 AI Proxy 服务根地址，不附加 `/v1` | 与文档要求的根地址格式比较，确认无多余路径 |
| `AIPROXY_API_TOKEN` | 填写与服务端一致的非空管理员 Token | 与文档要求的非空一致条件比较，确认未被应用 API Key 替代 |
| 模型映射 | 将请求模型映射到上游实际模型 | 与渠道内可用模型列表比较，确认映射目标存在 |
| 探测间隔 | 本次假设试验起点设为 30 分钟 | 落在文档支持的 5～60 分钟整数区间，与上下限比较 |
| 告警 Webhook | 填写接收地址并点击测试 | 与文档说明的模拟异常与恢复两条测试消息比较 |
| 检索库向量模型标识 | 记录建库时使用的向量模型标识 | 与查询侧标识比较，标识不一致时排除该库 |

## 容易做错的三处

1. 把 `AIPROXY_API_ENDPOINT` 写成带 `/v1` 或 `/chat/completions` 的完整请求地址。检查：读取该变量值，与文档要求的服务根地址格式比较，出现附加路径即不满足。
2. 用应用 API Key 代替 `AIPROXY_API_TOKEN`。检查：读取该变量，与文档要求的非空管理员 Token 条件比较，为空或来源不符即不满足。
3. 将拟稿句中的「签约供应商直供」当作已由材料支持。检查：将拟稿句与假设样本三句材料逐字段比较，材料未载明直供字段时该表述处于未获支持状态，保留证据缺口。

## 怎么确认配好了

1. 输入假设样本三句材料原文与拟稿句，比较主体、期间与字段是否一致。当三句材料主体相同、期间覆盖拟稿句所指当日、且直供字段有明确记载时，该句才满足条件；字段未载明时记录为未获支持。
2. 输入检索库向量模型标识与查询侧标识，比较两者是否一致。标识一致时该库可参与检索；不一致时排除该库并记录实际观察，不执行跨模型检索来比较漏召回。
3. 输入探测配置的间隔值与 Webhook 地址，比较间隔是否落在 5～60 分钟整数区间、Webhook 测试是否收到模拟异常与模拟恢复两条消息。两项均满足时配置条件成立；未收到消息时记录为待核实，不推断失败原因。
