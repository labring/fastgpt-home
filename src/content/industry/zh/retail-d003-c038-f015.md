# 大卖场生鲜联营柜台的商品与营销文案起草：知识库检索与召回

## 这个品类的数据长什么样

大卖场生鲜联营柜台常由供应商驻场经营并按销售分成，这一经营关系决定了文案起草时的资料边界。联营合同、日销售报表、损耗单、食品进货查验记录分别来自商超生鲜部、联营供应商和门店店长，任何一句对外文案若引用销售数据、损耗比例或查验结论，都需要回到对应文件核对主体、期间和字段。资料更新频率为日或每批，检索时面对的是当日或当批的口径，跨日或跨批引用需要重新确认适用范围。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库，检索以库为最小搜索单位，集合只作分类管理，与搜索效果无关。搜索模式包含语义检索、全文检索和混合检索，混合检索通过 RRF 合并多路结果，结果重排使用 ReRank 模型二次排序。引用上限以 token 为单位，最低相关度仅在语义检索或使用结果重排时生效。问题优化用于指代消除和问题扩展，会增加一次模型调用。图片检索须有图像输入及相应模型能力，重排须具备模型并按设置启用，这些路径不构成每次请求的固定流程。

假设演练样本：某门店生鲜部拟为联营柜台草拟一句损耗说明文案，供核对的材料原文为三句。第一句：“本柜台由联营供应商驻场经营，按销售分成结算。”第二句：“2025年3月1日至3月31日，本柜台叶菜类损耗单合计登记损耗数量120公斤。”第三句：“上述损耗单由门店店长于2025年4月2日完成复核签字。”待判定的拟稿句为：“本柜台叶菜类损耗长期控制在极低水平。”判定所需资料为损耗单原件的期间、数量与复核状态，检索范围限于本柜台已入库的损耗单集合。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 联营合同库、损耗单库、进货查验记录库 | 三库使用相同向量模型方可共同关联；先核标识，排除模型不符者 |
| 搜索模式 | 混合检索 | 拟稿句含“叶菜类损耗”等名词，关键词命中与语义召回各有用途，按测试问题比较三种模式 |
| 引用上限 | 假设起点为若干 token | 该值无官方默认，选此起点用于比较长短损耗单片段是否被完整引用，再与调整后取值对照 |
| 最低相关度 | 假设起点为 0-1 区间内一值 | 该值仅在语义检索或结果重排时生效；先标注相关与无关样本，再比较过滤后保留内容 |
| 问题优化 | 暂不开启 | 拟稿句主体明确，比较开启与关闭时主体是否被改错，再定是否启用 |
| 结果重排 | 暂不启用 | 重排须具备模型并按设置启用，先观察未重排时候选排序，再决定是否引入 |

## 容易做错的三处

1. 把“长期控制在极低水平”当作已被材料支持。材料只给出2025年3月单月损耗数量与复核签字，未载明长期趋势或行业比较基准，该表述属于未获支持。检查动作：输入拟稿句与三句材料原文，比较“长期”“极低”是否有对应字段，观察结果为材料中不存在可比区间或阈值。
2. 把损耗单的复核签字当作损耗数据已生效。签字是复核动作，与损耗数量是否被采纳为结算依据属于不同事实。检查动作：输入第三句材料与拟稿句，比较签字日期与结算字段，观察结果为材料未载明结算采纳状态。
3. 把联营供应商的驻场经营身份当作对外宣传授权。合同关系与文案发布授权属于不同事实。检查动作：输入第一句材料与拟稿句，比较合同主体与发布授权字段，观察结果为材料未载明发布授权范围。

## 怎么确认配好了

1. 输入三句材料原文与拟稿句，在混合检索下比较召回内容是否覆盖损耗单的期间、数量与复核状态。若召回内容缺失期间或复核状态，该拟稿句的判定依据不足，记录缺口。
2. 输入拟稿句与“长期”“极低”两词，比较材料中是否存在对应区间或阈值。若材料未载明，判定为未获支持，保留待核实状态。
3. 输入明确的纸面空结果承接用例，核对下游设计对引用内容长度为0的处理。若下游未定义空结果分支，记录为待补充，不推断检索必然返回空数组。
