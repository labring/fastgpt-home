# 平台商品标题与详情合规的商品与营销文案起草：上下文与 token

## 这个品类的数据长什么样

平台商品标题与详情合规处理宣传真实性和资质展示，不处理包裹交付。日常材料包括商品标题表、详情页素材、广告禁词清单和质检报告。这些材料决定文案起草时能引用什么、不能引用什么。商品标题表给出商品名称、型号和规格；详情页素材给出图片和版式；广告禁词清单给出不能出现的表述；质检报告给出检测对象、检测项目和有效范围。文案起草需要从这些材料中提取可支撑的宣传句，再结合上下文与 token 控制引用内容长度。

## 这些特征在「上下文与 token」这一环带来什么约束

上下文窗口按实际模型能力核对，回复上限控制单次回答长度，两者不是同一件事。知识库引用上限按 token 控制，单段材料较长时可能被裁剪。历史输入会影响检索结果，相同问题在空历史和带历史下可能召回不同内容。结构化承接要求字段齐全并可解析。

假设演练样本：材料原文为“商品名称：便携折叠桌；型号：FT-2024A；展开尺寸：60cm×40cm×30cm；承重：15kg。质检报告编号：Q-2024-0871，检测对象为同型号折叠桌，检测项目为承重，结论为符合委托要求。”拟稿句为“本产品承重可达 15kg，适合户外露营使用。”判定要点：承重数值与材料一致，适用场景“户外露营”在材料中未载明，属于未获支持。交接请求为“请确认该商品标题是否可使用‘承重 15kg’表述”，回复需核对型号与检测对象一致。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 回复上限 | 800 tokens | 需容纳宣传句与依据说明，与 400 tokens 比较是否截断 |
| 引用上限 | 2000 tokens | 材料含标题表与质检报告，与 1000 tokens 比较是否漏引 |
| 最低相关度 | 0.5 | 过滤低相关片段，与 0.3 比较无关片段是否增多 |
| 搜索模式 | 混合检索 | 型号与数值需精确命中，与语义检索比较编号召回 |
| 问题优化 | 开启 | 多轮追问需补全指代，与关闭比较检索词完整性 |
| 回复格式 | json_schema | 需固定字段承接，与默认格式比较解析成功率 |

## 容易做错的三处

1. 把回复上限当作完整上下文窗口。回复上限控制输出长度，上下文窗口按模型能力单独核对，两者混用会导致长材料被误判为可完整引用。
2. 把最低相关度当作权限或实体过滤。相关度是相似度阈值，不排除未授权记录，也不区分不同主体。
3. 把待审核状态当作已批准。材料处于待审核时，拟稿句不能据此判定为已获支持，需记录为待核实。

## 怎么确认配好了

1. 输入假设样本的材料原文与拟稿句，比较拟稿句中的承重数值与材料数值是否一致，一致时该字段获支持，适用场景未载明时记录为未获支持。
2. 输入相同问题分别在空历史和带历史下检索，比较两次召回内容是否一致，不一致时记录上下文差异，不判定为漏召回。
3. 输入空结果 `[]` 核对下游承接设计，比较字段是否齐全、解析是否成功，不声称虚构规则检索一定返回空结果。
