# 平台商品标题与详情合规的商品与营销文案起草：知识库检索与召回

## 这个品类的数据长什么样

平台商品标题与详情合规处理宣传真实性与资质展示，不处理包裹交付。主要资料为平台规则中心条目、广告禁词清单、品牌素材库、质检机构报告、商品标题表与详情页素材。这些资料以周和每次上新为更新节奏，起草时面对的是同一批材料里不同来源、不同有效范围的表述。

资料形态决定检索难点。广告禁词清单多为短词条，适合全文检索命中精确词形。质检报告含编号、型号、检测项目与有效期，编号类查询依赖关键词命中。详情页素材与标题表是自然语言长句，语义检索更易召回相近表述。同一批资料混合存放时，一次检索需要同时覆盖精确词与语义相近内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的库。跨不同向量模型的库不可共同关联，应先核向量模型标识，排除不符合者，记录实际观察，不执行跨模型检索来比较漏召回。

搜索模式按测试问题选择。语义检索依赖向量距离，全文检索依赖关键词命中，混合检索同时使用两路并通过 RRF 融合。RRF 是混合结果的融合过程，不是可开启的开关。最低相关度是过滤阈值，仅在语义检索或使用结果重排时生效，它不承担权限或实体隔离功能，检索本身也不构成授权。

引用内容以数组输出，长度可以为 0，未搜索到内容时该输出链路仍走通。引用上限以 token 为单位，不采用 top k。问题优化在检索前增加一次模型调用，用于指代消除与问题扩展，会增加整体耗时。

资料中的可选路径不代表每次请求全部执行。图片检索需要相应图像输入与模型能力，重排需要具备模型并按设置启用。

### 假设演练样本

以下为纸面假设样本，用于说明核对方法，不指向任何真实主体。

材料原文一（广告禁词清单条目）：本清单适用于平台内所有商品标题与详情页文字，条目“极致”列入禁止使用的绝对化表述。

材料原文二（质检报告摘录）：受检对象为某批次不锈钢保温杯，检测项目为保温效能，报告编号与检测日期见报告首页，报告有效期至所载日期。

拟稿句：本品采用极致工艺，保温效能经质检报告确认合格。

交接请求：请检索本批资料，确认拟稿句是否可直接使用。

判定要点：材料原文一覆盖标题与详情文字并列出“极致”为禁用表述，拟稿句含该词，属同字段明确互斥取值。材料原文二只载明受检对象、检测项目与有效期，未载明“极致工艺”或类似工艺表述，拟稿句该部分未获支持。质检报告是否支持“合格”结论，取决于报告原文是否载明结论字段，样本未提供该字段，属待核实。

## 配置怎么定

| 配置或核对项 | 本样本取值或动作 | 依据与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 广告禁词清单库、质检报告库、详情页素材库 | 先核各库向量模型标识，仅关联标识相同者，不符者排除并记录 |
| 搜索模式 | 混合检索 | 拟稿句含精确词“极致”与自然语言表述，两路召回后由 RRF 融合 |
| 引用上限 | 本次假设试验起点设为覆盖禁词清单条目与报告摘录的 token 量 | 该起点用于让两条材料同时进入引用；与仅能容纳一条材料的更小值比较，观察引用是否完整 |
| 最低相关度 | 本次假设试验起点设为中等值 | 先标注拟稿句与两条材料的相关、无关样本，再与更高、更低值比较过滤结果 |
| 问题优化 | 本样本为单轮完整句，暂不开启 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 按设置启用并具备模型时使用 | 重排得分用于过滤，与未重排的排序结果比较 |

## 容易做错的三处

1. 把最低相关度当作权限或实体过滤。最低相关度是过滤阈值，不排除无关业务或未授权记录。检索不构成授权，业务核验与写入需要下游实现。核对动作：查看该值说明，确认其生效条件仅为语义检索或结果重排。

2. 把 RRF 写成可开启的开关。RRF 是混合检索结果的融合过程。核对动作：检查配置项中是否存在名为 RRF 的开关，若无则记录为融合过程。

3. 用跨向量模型的库共同关联后推断漏召回或冗余。文档只说明可关联相同向量模型的库。核对动作：逐个读取库的向量模型标识，排除不符者，记录实际观察，不推断运行结果。

## 怎么确认配好了

1. 输入上述材料原文一与拟稿句，比较拟稿句是否含清单所列禁用表述。当检索引用中出现该清单条目且拟稿句含该词时，满足禁用词命中的预期。未出现时记录为未命中，不推断原因。

2. 输入上述材料原文二与拟稿句，比较报告摘录是否载明工艺表述与结论字段。当引用内容只含受检对象、检测项目与有效期时，满足“工艺表述未获支持、结论字段待核实”的预期。

3. 输入纸面空结果 []，核对下游设计对引用长度为 0 的处理。当输出链路仍走通且下游按空引用处理时，满足预期。不声称某条虚构规则检索一定返回 []。

三项验证均为纸面核对，未实际执行，不构成测试、部署或审批结论。
