# 快递面单与揽收交接的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

快递面单与揽收交接以电子面单、交接清单、揽收扫描和异常件登记为依据，来源包括快递系统、WMS发运及承运商记录。对外说明发运时效、揽收与异常处理时，草稿须对应具体批次、事件及状态；交接与扫描分别核。

## 这些特征在「模型接入与配置」这一环带来什么约束

文案起草依赖模型接入。FastGPT 借助 AI Proxy 连接模型提供商，App与复用App/Service配置的Admin服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空的 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败。`AIPROXY_API_ENDPOINT` 填写服务根地址，不附加 `/v1`。模型渠道配置中的代理地址同样填写 `BaseUrl`，需要判断是否增加 `/v1`。系统至少需要一个语言模型和一个索引模型才能正常使用。模型能力按应用所需输入核对，多模态、工具调用分别验证。应用参数在应用或节点配置中设置。

假设演练样本：某仓库发运组于2026年3月10日整理一批面单文案，供核对的材料原文为三句。第一句：「本批包裹于2026年3月10日14时完成交接，交接清单编号 JL-20260310-07。」第二句：「截至2026年3月10日18时，该批包裹揽收扫描记录显示 42 件已完成扫描。」第三句：「异常件登记表记录 1 件因外包装破损暂存网点，状态为待处理。」待判定的拟稿句为：「本批包裹已全部完成揽收扫描，无异常件。」核对对象是这三句材料与这一句拟稿之间的支持关系。

## 配置怎么定

下表只列与本页任务相关的官方已说明设置或实施核对项。表中「本次假设试验起点」是纸面核对时选定的比较值，不是官方默认值。

| 配置项 | 官方说明要点 | 本次假设试验起点与比较方法 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 必填，填服务根地址，不附加 `/v1` | 纸面填写 `http://aiproxy:3000`，与文档示例格式逐字符比较，确认无 `/v1` 后缀 |
| `AIPROXY_API_TOKEN` | 必填，非空，与服务端一致 | 纸面填写一个非空字符串，分别核非空及与服务端配置一致，实际调用待测 |
| 模型渠道代理地址 | 填 `BaseUrl`，判断是否增加 `/v1` | 纸面填写厂商 `BaseUrl`，与文档「不要填完整模型请求地址」比较，确认未含具体路径 |
| 模型映射 | 将请求模型映射到具体模型 | 纸面填写 `{"gpt-4o-test": "gpt-4o"}`，与文档示例结构比较，确认键值对应关系 |
| 语言模型与索引模型 | 系统至少各需一个 | 纸面列出已启用模型清单，与「至少一个语言模型和一个索引模型」比较，确认两类均存在 |
| 模型状态探测 | 仅针对已启用模型，间隔 5～60 分钟整数 | 纸面填写间隔 15 分钟，与文档范围比较，确认落在 5～60 之间且为整数 |

## 容易做错的三处

1. 把 `AIPROXY_API_ENDPOINT` 填成带 `/v1` 的地址。输入是纸面填写的地址字符串，比较对象是文档「不要附加 `/v1`」这一说明，可观察结果是地址末尾是否出现 `/v1`。出现即不符合。
2. 用应用 API Key 代替 `AIPROXY_API_TOKEN`。输入是纸面填写的 Token 来源说明，比较对象是文档「AI Proxy 管理员 Token，必须与服务端配置一致且不能为空」，可观察结果是该 Token 是否声明为管理员 Token。声明为应用 API Key 即不符合。
3. 把模型渠道代理地址填成完整请求地址。输入是纸面填写的代理地址，比较对象是文档「不要填完整的模型请求地址，要填写 `BaseUrl`」，可观察结果是地址是否包含 `/chat/completions` 一类具体路径。包含即不符合。

## 怎么确认配好了

1. 针对假设样本第一句「本批包裹于2026年3月10日14时完成交接，交接清单编号 JL-20260310-07」，输入是这句原文与拟稿句「本批包裹已全部完成揽收扫描，无异常件」。比较对象是「完成交接」与「完成揽收扫描」是否为同一字段的同一状态。可观察结果是两者指向不同环节，拟稿句的「全部完成揽收扫描」未获第一句支持。

2. 针对假设样本第二句「截至2026年3月10日18时，该批包裹揽收扫描记录显示 42 件已完成扫描」，输入是这句原文与拟稿句。比较对象是「42 件」与「全部」是否一致。可观察结果是原文给出具体件数，未给出该批总件数，无法判定「全部」成立，该表述待核实。

3. 针对假设样本第三句「异常件登记表记录 1 件因外包装破损暂存网点，状态为待处理」，输入是这句原文与拟稿句「无异常件」。比较对象是「1 件异常件」与「无异常件」是否互斥。可观察结果是两者在同一字段上取值互斥，拟稿句与原文矛盾。三项验证均只描述纸面比较的预期结果，未实际执行测试。
