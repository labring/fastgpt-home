# 批发市场档口交易的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

批发市场档口交易的材料以进货单、手写销售单、摊位租赁合同、货款收据为主，行情来自批发市场，收款走微信，托运凭物流托运单。这些材料分散在纸面与聊天记录中，日频与每单更新并存。商品与营销文案起草要引用其中的品名、规格、数量、价格区间与摊位信息，材料本身不构成对宣传语句的授权。模型接入与配置在此环节的作用，是让起草请求能调用已启用的语言模型，并按材料原文核对生成内容。

## 这些特征在「模型接入与配置」这一环带来什么约束

材料字迹与格式不统一，起草前需要人工把关键字段整理成可引用的文本。系统至少需要一个语言模型和一个索引模型才能正常使用；AI Proxy 为必需依赖，App 与复用 App/Service 配置的 Admin 都须设置 `AIPROXY_API_ENDPOINT` 和非空 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。模型能力按应用所需输入核对，多模态、工具调用与思考配置分别验证；应用参数在应用或节点配置中设置。

假设演练样本：档口商户在 2026 年 3 月 12 日整理一批春季女装，材料原文为“进货单载明：品名针织开衫，规格均码，进货 200 件”“手写销售单载明：3 月 12 日售出 30 件，单价 45 元”“摊位租赁合同载明：A 区 12 号摊位，租期至 2027 年 2 月”。一条待判定拟稿句为“本档口针织开衫全部为当季新款，售完即止”。该句涉及“全部为当季新款”与“售完即止”两项，材料原文未载明款式季节属性与库存终止条件，属于未获支持。

## 配置怎么定

配置围绕本页样本核对，不把数据库内部实现抄成每页必配项。

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填写 AI Proxy 服务根地址 | 按文档要求不附加 `/v1`；与文档示例格式比较 |
| `AIPROXY_API_TOKEN` | 填写与服务端一致的非空管理员 Token | 与 AI Proxy 服务端配置比较，确认一致 |
| 语言模型启用 | 启用一个语言模型用于文案起草 | 与系统“至少一个语言模型”要求比较 |
| 索引模型启用 | 启用一个索引模型 | 与系统“至少一个索引模型”要求比较 |
| 模型能力核对 | 按本页样本所需文本输入核对 | 与模型字段 `vision`、`toolChoice` 等取值比较 |
| 应用参数 | 在应用或节点配置中设置 | 与编排实际读取位置比较，不假设同名对话字段覆盖 |

## 容易做错的三处

1. 把材料原文中的“售出 30 件，单价 45 元”当作全部库存事实，进而写出“售完即止”。输入是拟稿句与材料原文，比较对象是材料是否载明库存终止条件，材料未载明时该句未获支持。
2. 把 `AIPROXY_API_ENDPOINT` 填成完整模型请求地址并附加 `/v1`。输入是所填地址，比较对象是文档要求填写根地址且不附加 `/v1`，附加后与文档格式不符。
3. 用应用 API Key 充当 `AIPROXY_API_TOKEN`。输入是所填 Token，比较对象是文档要求管理员 Token 且不能为空，填入应用 Key 与要求不符。

## 怎么确认配好了

1. 输入假设样本的材料原文与拟稿句“本档口针织开衫全部为当季新款，售完即止”，比较拟稿句中的季节属性与库存终止条件是否在原文出现，原文未载明时该句应判为未获支持，不得判为否定或冲突。
2. 输入所填 `AIPROXY_API_ENDPOINT`，比较其是否为 AI Proxy 服务根地址且未附加 `/v1`，符合文档格式要求时通过；附加路径时记录不符。
3. 输入所填 `AIPROXY_API_TOKEN`，比较其是否与服务端配置一致且非空，一致时通过；填入应用 API Key 时记录不符。三项均为纸面核对，未实际部署或测试。
