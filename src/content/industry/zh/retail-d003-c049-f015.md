# 批发市场档口交易的商品与营销文案起草：知识库检索与召回

## 这个品类的数据长什么样

批发市场档口交易依赖现场议价与托运，进货单、手写销售单、摊位租赁合同、货款收据构成主要文档来源。这些材料日更或每单产生，字迹、简称、口头约定普遍存在。商品与营销文案起草需要从这些材料中确认可引用的商品名称、规格、数量、价格条件与摊位权属状态。检索环节面对的是同一档口在不同日期形成的多份材料，字段口径可能不一致。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的库。跨不同向量模型的库不可共同关联，应先核验向量模型标识，排除不符合者，不执行跨模型检索来比较漏召回。搜索模式包含语义检索、全文检索与混合检索，混合检索通过 RRF 融合多路结果，RRF 是融合过程，不是独立开关。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值，不承担权限或实体隔离。引用上限以 token 为单位，控制每次搜索最多引用的内容量。问题优化用于指代消除和问题扩展，会增加一次模型调用。输出引用内容以数组格式返回，长度可以为 0，空结果链路仍走通。

假设演练样本：某档口一份手写销售单载明“3月12日，A档口向采购商甲发出螺纹钢一批，规格HRB400，数量20吨，单价按当日市场价，货款未收”。一份摊位租赁合同载明“A档口摊位租期自3月1日至次年2月28日，租金按季支付”。一条待判定拟稿句为“A档口3月12日已向采购商甲完成20吨HRB400螺纹钢交付并结清货款”。核法所需资料须在有访问权的目标检索范围或明确的人工输入中，缺失时记录缺口。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联存放该档口进货单、销售单、租赁合同、收据的库 | 先核验各库向量模型标识，排除不同模型者 |
| 搜索模式 | 先以全文检索测试规格与编号类问题 | 与语义检索结果比较，观察规格词命中差异 |
| 引用上限 | 设为能覆盖一份完整销售单的 token 量 | 用长短不同的实际材料测试内容完整性再调整 |
| 最低相关度 | 暂不启用，待标注相关与无关样本后再调 | 该值仅在语义检索或结果重排时生效 |
| 问题优化 | 对含指代的追问开启，对明确问题关闭 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 候选较多且具备重排模型时启用 | 比较重排前后排序，观察相关文本位置变化 |

## 容易做错的三处

1. 将最低相关度当作权限或实体过滤器。该值是相似度过滤阈值，不排除无关业务或未授权记录。检索不承担授权判断。
2. 把 RRF 写成可开启的开关。RRF 是混合检索中多路结果的融合过程，文档未将其描述为独立配置项。
3. 将跨向量模型的库强行共同关联。文档要求关联相同向量模型的知识库，不同模型者应先核标识并排除，不编造共同关联后的运行结果。

## 怎么确认配好了

1. 输入假设销售单原文与拟稿句“A档口3月12日已向采购商甲完成20吨HRB400螺纹钢交付并结清货款”。比较拟稿句中的“结清货款”与销售单载明的“货款未收”。销售单未载明收款事实，该部分属未获支持，应记录证据缺口。
2. 输入假设租赁合同原文与一条询问“A档口摊位租期是否覆盖3月12日”。比较合同载明的租期起止与询问日期。租期覆盖该日期时，可引用合同说明摊位权属期间；合同未载明经营授权范围时，该部分保持未知。
3. 输入一个纸面空结果数组[]，核对下游节点对引用长度为0的处理设计。观察下游是否按空引用继续执行。该核对不声称虚构规则检索一定返回[]，仅验证空结果承接路径。
