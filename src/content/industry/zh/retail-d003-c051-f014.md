# 抖音小店货架运营的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

抖音小店货架运营围绕商品卡与店铺体验分展开，日常文档集中在商品资质页、体验分明细、发货违规申诉与店铺公告。这些材料来自抖店工作台、抖音电商学习中心、精选联盟数据与物流接口，更新频率为日与每单。商品与营销文案起草所需的核对依据，大多落在商品资质页与店铺公告两类文档里，模型接入与配置要解决的是把模型能力接到这些文档的核对流程上，让拟稿句能逐句对照材料原文判断是否被支持。

## 这些特征在「模型接入与配置」这一环带来什么约束

按 FastGPT v4.17.2 文档，从 V4.17.0 起 AI Proxy 为必需依赖，App 与复用 App/Service 配置的 Admin 服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空的 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败；旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。`AIPROXY_API_ENDPOINT` 填 AI Proxy 服务根地址，不要附加 `/v1`。系统至少需要一个语言模型和一个索引模型才能正常使用。模型能力按应用所需输入核对，多模态、工具调用分别验证；应用参数在应用或节点配置中设置。

假设演练样本：材料原文两句，取自一份虚构的商品资质页与店铺公告——“本店在售商品‘四季棉麻围巾’，材质标注为棉麻混纺，执行标准为 FZ/T 73001，资质页有效期至 2026 年 12 月 31 日。”“店铺公告：本店发货时效为付款后 48 小时内发出。”一条待判定拟稿句：“本店围巾为纯棉材质，当天发货。”核对范围限定为上述两份材料。该拟稿句的“纯棉”与资质页“棉麻混纺”属同一字段的不同取值，构成矛盾；“当天发货”与公告“48 小时内发出”同样构成矛盾，两处均判定为未获支持。

## 配置怎么定

下表只列与本页主任务相关的官方已说明设置或实施核对项。数值列中标注“假设起点”的，是本次纸面演练选定的比较起点，不是官方默认值。

| 配置项 | 本次假设起点 | 核对方式与理由 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | `http://aiproxy:3000` | 填根地址，不附加 `/v1`；与官方示例形式比较，确认无多余路径 |
| `AIPROXY_API_TOKEN` | 非空字符串 | 与服务端配置一致且不能为空；与空值比较，空即启动校验失败 |
| 语言模型 | 至少启用一个 | 与“系统至少需要一个语言模型”要求比较，未启用则不可用 |
| 索引模型 | 至少启用一个 | 与“系统至少需要一个索引模型”要求比较，未启用则不可用 |
| 模型映射 | `gpt-4o-test` 映射到 `gpt-4o` | 按官方映射示例核对请求模型名与上游模型名 |
| 渠道优先级 | 假设起点 50 | 范围 1～100，数值越大越易被优先选中；与相邻渠道值比较排序 |

## 容易做错的三处

1. 把 `AIPROXY_API_ENDPOINT` 填成带 `/v1` 或 `/chat/completions` 的完整请求地址。官方说明该变量为服务根地址，不要附加 `/v1`。检查输入该变量的实际字符串，与“根地址”形式比较，出现 `/v1` 即不符合。
2. 用应用 API Key 充当 `AIPROXY_API_TOKEN`。官方要求该 Token 为 AI Proxy 管理员 Token，必须与服务端一致且不能为空。检查填入值与服务端配置值，二者不一致或为空即不符合。
3. 认为配置了语言模型即可起草文案。官方说明系统至少需要一个语言模型和一个索引模型。检查已启用模型列表中两类是否都存在，缺任一即不符合。

## 怎么确认配好了

1. 输入假设样本中资质页原文“材质标注为棉麻混纺”与拟稿句“本店围巾为纯棉材质”。比较两者在同一材质字段上的取值，取值互斥即判定拟稿句未获支持；若拟稿句改为与原文一致的表述，则满足条件。
2. 输入假设样本中公告原文“发货时效为付款后 48 小时内发出”与拟稿句“当天发货”。比较同一发货时效字段，取值互斥即判定未获支持；若拟稿句改为“付款后 48 小时内发出”，则满足条件。
3. 输入 `AIPROXY_API_ENDPOINT` 的实际配置值。与“根地址、不附加 `/v1`”的要求比较，出现 `/v1` 即不满足；无附加路径则满足。三项均以纸面核对完成，未在真实系统执行，结果以实际观察为准。
