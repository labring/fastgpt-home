# 渠道应收账款催收的商品与营销文案起草：引用来源与溯源

## 这个品类的数据长什么样

渠道应收账款催收发生在赊销之后，核心工作是授信管理与现金回收，财务系统、银行回单、经销商订单与销售合同构成主要材料来源。商品与营销文案起草在本品类中处理的文档集中在应收账龄表、催款函、授信协议与发货冻结通知四类。文案内容常涉及账期状态、授信额度使用情况、回款安排等表述，这些表述能否成立，取决于对应材料是否载明同一主体、同一期间、同一字段。材料按周或按月更新，引用时须核对所依据的版本是否仍在有效范围。

## 这些特征在「引用来源与溯源」这一环带来什么约束

文案中的每一句业务表述都需要可追溯至具体材料原文。知识库搜索节点输出引用内容数组，长度可以为 0，空数组意味着该链路仍然走通，不代表工作流报错终止。引用内容是供回答环节承接的输入，最终文案与引用原文须逐条核对。检索关联要求所选知识库使用相同向量模型，这一条件只约束知识库之间的关联，不延伸到外部系统。最低相关度是过滤阈值，语义召回与相关度不承担权限或实体隔离功能，检索本身也不构成授权。混合检索通过 RRF 融合多路结果，属于检索过程，不是可开启的独立开关。资料时效核对须用当前版与历史版文档分别测试来源，是否采用某条引用仍须结合有效版本审核。

假设演练样本

材料原文一（授信协议摘录）：“甲方给予乙方授信额度人民币八十万元，授信有效期自二〇二五年一月一日至二〇二五年十二月三十一日。”

材料原文二（账龄表摘录）：“截至二〇二五年六月三十日，经销商A应收账款余额人民币五十二万元，其中逾期三十一日至六十日区间金额人民币一十二万元。”

材料原文三（发货冻结通知摘录）：“因经销商A超授信发货，自二〇二五年七月一日起暂停对其发货，待回款后另行评估。”

待判定拟稿句：“经销商A授信额度已用尽，公司已停止供货。”

## 配置怎么定

| 配置项 | 本页相关设置或核对项 | 与样本的对应关系 |
| --- | --- | --- |
| 关联的知识库 | 选择一个或多个相同向量模型的知识库 | 授信协议、账龄表、冻结通知须在同一向量模型下关联，跨模型不可共同关联 |
| 搜索模式 | 语义检索、全文检索或混合检索 | 编号、金额、日期类字段适合全文检索或混合检索 |
| 引用上限 | 每次搜索最多引用 n 个 tokens 的内容 | 本次假设试验起点设为 2000 tokens，理由为三份材料合计篇幅较短，与 1000 tokens 比较可观察是否截断 |
| 最低相关度 | 0-1 数值，仅在语义检索或结果重排时生效 | 本次假设试验起点设为 0.5，与 0.3 比较可观察低相关片段是否被过滤 |
| 结果重排 | 须具备重排模型并按设置启用 | 候选较多时用于二次排序，未启用时不产生重排得分 |
| 问题优化 | 检索前进行指代消除与问题扩展 | 拟稿句含“已用尽”“已停止”等指代，开启后可观察检索词是否被补全 |

## 容易做错的三处

1. 把材料未载明的状态当作已确认。样本中授信协议载明额度八十万元，账龄表载明余额五十二万元，两者相加不构成“已用尽”的充分证据；冻结通知载明“暂停发货”，与“停止供货”不是同一事实。错误做法是直接采信拟稿句的完成态表述。
2. 把待审核状态当作缺少操作权限。材料若仅显示某事项待审核，只能记录该状态，不能据此推断操作权限缺失或已获授权。
3. 把检索命中当作授权成立。检索返回引用内容只说明存在相关材料，不说明该材料所涉主体已获批准或该业务动作已执行。

## 怎么确认配好了

1. 输入样本材料原文一与拟稿句“经销商A授信额度已用尽”。比较材料载明的额度金额与账龄表余额，观察两者是否指向同一字段且数值互斥。满足条件为：材料明确载明额度已全部占用，或载明余额等于或超过额度。当前样本两条原文均未载明额度已用尽，结果为未获支持。
2. 输入样本材料原文三与拟稿句“公司已停止供货”。比较冻结通知载明的“暂停发货”与拟稿句的“停止供货”，观察两者是否为同一状态描述。满足条件为：材料明确载明供货已终止。当前样本载明“暂停”并附“待回款后另行评估”，结果为待核实。
3. 输入一个纸面构造的空引用数组 []，观察下游回答环节的设计。满足条件为：空数组输入时下游不报错、不生成无来源的业务结论，并记录该链路已走通。此项用于核对下游承接设计，不声称实际检索一定返回空数组。
