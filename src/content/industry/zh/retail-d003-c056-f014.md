# 生产企业免抵退税的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

生产企业免抵退税的文案依据免抵退税申报明细表、出口合同、销售明细账与出口报关单，资料按月更新。引用商品、数量、成交方式和离岸价口径时，分别核主体、期间及对应批次；同月不自动证明同一笔业务。资料更新频率不代表同步或触发机制。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型辅助文案生成与核对，不执行退税审批或申报写入。App与复用App/Service配置的Admin服务须配置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺失会启动校验失败；旧配置不能替代。地址填AI Proxy根地址，不附加 `/v1`，系统至少需一个语言模型和一个索引模型。多模态、工具与思考能力按实际输入核，应用参数在应用或节点配置中设置。同向量模型要求针对共同关联的知识库，不扩展到外部网站；相关度不替代权限或主体核验。

假设演练样本

以下材料与拟稿句均为纸面假设，用于说明核对方法，不代表任何真实客户、真实公司或合法身份编号。

供核对的材料原文（假设）：

材料一（假设出口合同摘录）：「卖方为境内某生产型企业，合同标的为自产家用纺织品，成交方式为 FOB，合同金额以离岸价计，合同期间为 2025 年 3 月。」

材料二（假设出口报关单摘录）：「境内发货人为该生产型企业，商品名称为家用纺织品，成交方式为 FOB，申报日期为 2025 年 3 月，申报数量为 1200 件。」

材料三（假设免抵退税申报明细表摘录）：「所属期为 2025 年 3 月，出口货物名称为家用纺织品，出口数量为 1200 件，出口销售额按离岸价填列。」

待判定的拟稿句（假设）：「本产品于 2025 年 3 月出口 1200 件，采用 FOB 成交方式，出口销售额以离岸价计。」

## 配置怎么定

下表为本页纸面接入检查，试验值须与实际部署比较。

| 配置项 | 本次假设起点 | 理由与比较方法 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设填写为 `http://aiproxy:3000` | 官方说明填写 AI Proxy 服务根地址且不附加 `/v1`；与文档示例格式比较，确认无多余路径段 |
| AIPROXY_API_TOKEN | 假设填写为与服务端一致的非空管理员 Token | 官方说明不能为空且不能用应用 API Key 代替；与 AI Proxy 服务端配置值比较一致性 |
| 语言模型与索引模型 | 假设各启用一个 | 官方说明系统至少需要一个语言模型和一个索引模型；与「已启用」列表比较，确认两类均非空 |
| 模型能力核对 | 假设按纯文本输入核对 | 官方说明多模态、工具调用分别验证；与拟稿任务实际输入类型比较，确认所需能力已启用 |
| 模型探测间隔 | 假设设为 30 分钟 | 官方说明支持 5～60 分钟整数；与允许范围比较，确认取值落在区间内 |
| 告警 Webhook 地址 | 假设暂不配置 | 官方说明为可选；与是否需要接收状态变化通知比较，未配置时记录为未启用 |

模型探测仅针对系统中当前已启用的系统模型，未启用模型不参与探测。探测失败后最多自动重试 3 次，4 次全部失败才判定为异常。告警 Webhook 在状态边沿变化时触发，持续异常不重复推送。

## 容易做错的三处

1. 把报关数量1200件当成合同数量。合同摘录没有数量；报关单和明细表各载1200件，但同月不证明同批。分别保留有据字段，跨表归属与合同数量待核。

2. 把相关度分数当作权限或实体过滤条件，认为相似度设置可以排除无关业务或未授权记录。官方文档未说明相关度承担该功能，检索结果不构成授权，配置中不应据此设定业务隔离预期。

3. 把模型探测的「已启用」范围理解为全部模型，对未启用模型的状态变化设置告警预期。官方说明未启用模型不参与探测，也不产生历史记录，配置告警时应先核对启用状态。

## 怎么确认配好了

1. 输入三份摘录与拟稿句，逐项核主体、月份及数量。报关单载该企业、2025年3月、1200件；明细表虽同月同量，但没有主体或业务关联标识，跨表归属待核，不能只凭数值相等建立对应。

2. 输入“出口销售额以离岸价计”与明细表，原文支持该表自身的计价口径；将其用于本产品还需主体及业务对应证据，缺失保持待核。

3. 输入“采用FOB成交方式”与合同、报关单，两份均载FOB，可保留各自记载并核是否同一业务。若另写“已获得出口退税资格”，三份均无资格状态，该主张未获支持。
