# 直播选品与样品质检的商品与营销文案起草：知识库检索与召回

## 这个品类的数据长什么样

直播选品与样品质检发生在开播前，要回答的是商品能不能卖、是否适合直播展示。本页处理的任务是商品与营销文案起草，检索与召回服务于拟稿句能否被材料支持。日常文档包括样品评估表、质检报告、供应商资质与禁售清单，来源为供应商资料、检测机构报告、平台负面目录与历史退货率。这些材料决定文案能写什么、不能写什么。质检报告给出检测项目与结论，供应商资质给出主体与有效期，禁售清单给出平台限制范围，样品评估表给出试用观察。文案起草时，检索要能把这些字段按主体、对象、状态与有效范围取回，供逐句核对。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，先核标识并排除不符合者，不执行跨模型检索来比较漏召回。搜索模式有语义检索、全文检索与混合检索，混合检索通过 RRF 融合多路结果；RRF 是融合过程，不写成开启开关。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值，不是最终排序规则。引用上限以 token 为单位。问题优化用于指代消除和问题扩展，会在正式检索前增加一次模型调用。输出引用内容以数组格式返回，长度可以为 0，未搜索到内容时该输出链路仍走通。图片检索须有相应图像输入及模型能力，重排须具备模型且按设置启用，文档总流程图列出的可选路径不代表每次请求全部执行。检索与召回不负责权限或实体隔离。

假设演练样本：材料原文为“供应商甲于2025年3月提交的质检报告显示，批次A-031样品在耐摩擦色牢度项目上结论为合格，报告编号QC-2025-0317，有效期至2026年3月。”“供应商甲提交的营业执照载明经营范围为日用百货销售，有效期至2027年12月。”“平台禁售清单2025年4月版将一次性医用口罩列入限制类目，需提供医疗器械经营备案。”待判定拟稿句：“本款口罩已通过质检，色牢度合格，可放心购买。”此句涉及主体、对象与状态，需逐项比对。

## 配置怎么定

下表只列与本页主任务相关的设置或实施核对项。数值为本次假设试验起点，需与另一组值比较后再定。

| 配置项 | 本次假设起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 选入含质检报告、资质、禁售清单的库 | 先核各库向量模型标识，排除不同模型者 |
| 搜索模式 | 混合检索 | 与语义检索、全文检索分别跑同一批拟稿句比对 |
| 引用上限 | 设为能覆盖一份质检报告结论段的 token 量 | 用长短不同的报告段落测试内容是否完整 |
| 最低相关度 | 先取中间值 | 标注相关与无关样本，观察过滤后是否保留结论句 |
| 问题优化 | 多轮追问时开启 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 候选较多时启用 | 比较重排前后同一拟稿句的候选排序 |

## 容易做错的三处

1. 把最低相关度当成权限或实体过滤。错误输入：拟稿句“本款口罩已通过质检”，检索只设最低相关度。比较：该阈值是否在语义检索或重排时生效，是否排除无关主体。可观察结果：若把阈值调高后仍召回其他供应商的质检结论，说明该设置不承担主体隔离。
2. 把跨向量模型的库直接共同关联。错误输入：将向量模型标识不同的两个库同时选入。比较：各库向量模型标识是否一致。可观察结果：标识不一致时不应执行联合检索，记录实际观察，不推断漏召回或冗余。
3. 把未载明状态当作已否定。错误输入：拟稿句称“可放心购买”，材料只写色牢度合格。比较：材料是否载明“可放心购买”或等同表述。可观察结果：该字段未载明，属未获支持，待核实，不称矛盾或否定。

## 怎么确认配好了

1. 输入假设样本中的质检报告原文与拟稿句“本款口罩已通过质检，色牢度合格，可放心购买”。比较：拟稿句的主体、对象、状态是否与报告原文同主体、同期间、同一字段。可观察结果：色牢度合格可获支持；“可放心购买”未载明，属未获支持，待核实。
2. 输入假设样本中的禁售清单原文与同一拟稿句。比较：清单将一次性医用口罩列入限制类目并要求备案，拟稿句是否载明备案状态。可观察结果：拟稿句未提备案，该部分属证据缺口；待审核不证明缺少操作权限。
3. 输入一个明确的纸面空结果，核对下游承接。比较：引用内容数组长度为 0 时输出链路是否仍走通。可观察结果：下游按空引用处理，不声称某规则检索一定返回空数组。
