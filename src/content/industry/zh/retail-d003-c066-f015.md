# 短视频挂车分销运营的商品与营销文案起草：知识库检索与召回

## 这个品类的数据长什么样

短视频挂车分销依靠内容长期曝光与商品链接转化，不依赖实时讲解。日常资料包括短视频脚本、挂车商品清单、佣金计划与违规反馈，更新频率以日、周为主。商品与营销文案起草的核对重点在于：拟稿句中的宣传内容能否在脚本、清单、佣金计划或违规反馈的原文里找到对应表述。检索环节需要把待判定文案与这些资料建立可追溯的对应关系，检索结果只提供引用内容，不构成对商品资质、佣金结算或推广权限的确认。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库，向量模型标识不同的库不可共同关联，应先核对标识并排除不符合者，不执行跨模型检索来比较漏召回。检索可按语义、全文或混合方式进行，混合检索通过 RRF 融合多路结果，重排须具备模型并按设置启用，图片检索须有相应图像输入及模型能力，这些路径并非每次请求全部执行。最低相关度仅在语义检索或使用结果重排时生效，属于过滤阈值，不承担权限或实体隔离功能。引用上限以 token 为单位，输出引用内容为数组，长度可以为 0。

假设演练样本：供核对的材料原文为三句。第一句：“本视频挂车商品为便携折叠水杯，商品清单编号 A-217，佣金计划比例按精选联盟后台当日显示执行。”第二句：“脚本第三段宣传语为‘轻便易携，适合通勤’。”第三句：“违规反馈记录：标题不得出现绝对化用语。”待判定的拟稿句为：“该商品轻便易携，适合通勤，佣金比例已锁定。”核对时，前两句支持“轻便易携，适合通勤”的表述，佣金部分仅有“按后台当日显示执行”，未载明锁定状态，该分句属于未获支持。样本不涉及真实客户、公司或身份编号。

## 配置怎么定

下表围绕上述样本，列出与本功能、主任务相关的已说明设置或实施核对项。数值仅为本次假设试验起点，用于与另一取值比较，不属官方默认。

| 配置项 | 本次假设试验起点 | 选择理由与比较方式 |
| --- | --- | --- |
| 关联的知识库 | 仅关联使用同一向量模型的脚本库与清单库 | 先核对向量模型标识，与另一模型标识的库比较，确认可共同关联 |
| 搜索模式 | 先按语义检索，再按混合检索各执行一次 | 同一拟稿句分别输入，比较两种模式下引用内容是否覆盖材料原文 |
| 引用上限 | 设为 800 token | 以材料原文长短不同的实际资料测试内容完整性，与 400 token 结果比较 |
| 最低相关度 | 设为 0.4 | 先标注相关与无关样本，与 0.2、0.6 的结果比较，观察无关片段增减 |
| 问题优化 | 对“佣金比例已锁定”单独执行一次 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 在混合检索后启用一次 | 具备重排模型时比较启用前后候选排序，观察得分变化 |

## 容易做错的三处

1. 把“佣金计划比例按精选联盟后台当日显示执行”读成“佣金比例已锁定”。两处主体相同、字段相同，取值互斥，材料原文只载明按当日显示执行，锁定状态未获支持。
2. 将最低相关度当作权限或实体过滤条件，认为调高阈值即可排除无关业务或未授权记录。该值仅在语义检索或结果重排时生效，属于过滤阈值，检索本身不承担授权判断。
3. 把“违规反馈记录：标题不得出现绝对化用语”当作对拟稿句的否定结论。该记录只说明标题要求，未对“轻便易携”作出评价，拟稿句是否违规仍待核实。

## 怎么确认配好了

1. 输入假设材料原文与拟稿句“该商品轻便易携，适合通勤，佣金比例已锁定”，在语义检索下比较引用内容。若引用内容包含前两句原文且不含锁定表述，则满足条件；若引用内容缺失，记录缺口，不判定为否定。
2. 对“佣金比例已锁定”单独执行问题优化，比较优化前后问题。若优化后主体仍为佣金比例且未新增锁定依据，则满足条件；若主体被改为其他字段，属优化偏差，需重新核对。
3. 以空数组作为纸面输入核对下游设计，观察输出链路是否走通。引用内容长度为 0 时链路仍应走通，此为文档说明的节点行为，不表示虚构规则检索一定返回空结果。
