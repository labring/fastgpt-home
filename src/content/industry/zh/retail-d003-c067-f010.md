# 社区团购团长运营的商品与营销文案起草：引用来源与溯源

## 这个品类的数据长什么样

社区团购团长运营管理社区节点与佣金，不直接执行冷链质检。日常文档包括团长协议、佣金表、提货清单和社群公告，更新频率为日或每团。商品与营销文案起草需要从这些材料中提取可核对的表述。团长协议可能载明合作范围与结算条件，佣金表可能载明计佣对象与比例，提货清单可能载明品项与数量，社群公告可能载明活动状态。文案中的宣传句若涉及价格、赠品、时效或授权，须回到对应材料原文逐句核对。资料未载明的字段保持未知，不因其他品类有线上认证或电子合同就推断本类目缺少或具备同类字段。

## 这些特征在「引用来源与溯源」这一环带来什么约束

检索输出的引用内容以数组形式返回，长度允许为零。空数组意味着该输出链路走通，不表示工作流已经报错终止。知识库搜索节点可选择多个相同向量模型的知识库；跨不同向量模型的库不可共同关联，应先核对向量模型标识并排除不符合者。最低相关度是过滤阈值，仅在语义检索或结果重排时生效，不承担权限或实体隔离功能。RRF是混合检索的结果融合过程，不写作可开启的独立开关。图片检索需要相应图像输入及模型能力，重排需要具备重排模型并按设置启用，文档总流程图列出的可选路径不代表每次请求全部执行。

假设演练样本：某团长协议原文写有“本协议自双方签署之日起生效，有效期为2025年1月1日至2025年12月31日”。同期佣金表原文写有“生鲜类目按订单实收金额的5%计佣”。一条待判定拟稿句为“本团生鲜商品长期按实收金额5%返佣，协议签署后立即生效”。核对对象为上述协议与佣金表，期间为2025年度，字段为协议生效条件、有效期与佣金比例。协议原文未载明“长期”与“立即”，佣金表未载明适用期间。该拟稿句的“长期”和“立即”未获支持，“5%”与协议生效条件需分别核对对应字段。待审核不证明缺少操作权限，签署、合作达成与合同生效是三个不同事实。

## 配置怎么定

| 配置项 | 本页相关设置或核对项 | 与样本的对应关系 |
| --- | --- | --- |
| 关联的知识库 | 选择一个或多个相同向量模型的知识库 | 核对协议与佣金表所在库的向量模型标识是否一致 |
| 引用上限 | 每次搜索最多引用 n 个 tokens 的内容 | 本次假设试验起点设为 2000 tokens，理由为样本原文较短，便于逐句比对；与默认展示值比较后调整 |
| 最低相关度 | 0-1 数值，仅在语义检索或结果重排时生效 | 本次假设试验起点设为 0.5，理由为样本问题明确；与检索返回的引用内容逐条比对 |
| 搜索模式 | 语义检索、全文检索或混合检索 | 样本含“5%”与日期，可选用全文检索或混合检索 |
| 结果重排 | 需具备重排模型并按设置启用 | 启用后以重排得分辅助排序，不以得分替代原文核对 |
| 引用内容输出 | 数组格式，长度可为 0 | 用纸面输入 [] 核对下游承接设计，不声称虚构规则检索必返回空数组 |

## 容易做错的三处

1. 把最低相关度当作权限或实体过滤器。输入为样本拟稿句与两个知识库，比较对象为检索返回的引用内容与团长协议、佣金表原文。可观察结果为：引用内容中是否出现与样本主体、期间、字段一致的原句。若未出现，记录为未命中，不推断为无权访问或记录不存在。
2. 把跨向量模型的知识库强行共同关联。输入为协议库与佣金表库的向量模型标识，比较两者是否相同。可观察结果为：标识一致才可共同关联；标识不同则排除不符合者并记录，不执行跨模型检索来比较漏召回。
3. 把待审核或报价有效期当作已生效授权。输入为样本协议原文与拟稿句，比较“签署之日起生效”与“签署后立即生效”是否同字段同取值。可观察结果为：协议原文未写“立即”，该表述未获支持；报价有效期不表示供货期限，待审核不证明缺少操作权限。

## 怎么确认配好了

1. 引用来源核对。输入为样本拟稿句“本团生鲜商品长期按实收金额5%返佣，协议签署后立即生效”，比较对象为团长协议原文与佣金表原文。预期现象为：逐句列出“长期”“立即”“5%”各自对应的原文位置；无对应原文的字段标注为未获支持或待核实，不标注为否定或冲突。
2. 空引用承接核对。输入为纸面输入 []，比较对象为下游回答环节的设计。预期现象为：下游能承接空数组而不报错终止；不声称虚构规则检索一定返回 []。
3. 资料时效核对。输入为当前版与历史版团长协议，比较对象为同一字段的取值。预期现象为：仅当同一字段出现明确互斥取值时才记录为矛盾；只有相关阶段证据时记录为待核实。核法所需资料须在有访问权的目标检索范围或明确的人工输入里，缺失时记录缺口。
