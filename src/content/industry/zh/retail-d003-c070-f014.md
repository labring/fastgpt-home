# 跨境商品合规与标签的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

商品合规发生在商品上架和进口之前，核心证据是产品安全与标签材料。日常文档包括产品测试报告、英文标签、MSDS 和平台禁售清单；来源为平台政策中心、检测机构报告、目的国法规库和供应商资料。资料更新不定期，每次上新都可能产生新版本。文案起草需要把材料原文与拟稿句放在同一份可核对范围内，模型接入与配置要保证这种核对可以按材料逐句进行。

## 这些特征在「模型接入与配置」这一环带来什么约束

从 V4.17.0 起，AI Proxy 为必需依赖。App 和复用 App/Service 配置的 Admin 服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空的 `AIPROXY_API_TOKEN`；缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。`AIPROXY_API_ENDPOINT` 填 AI Proxy 服务根地址，例如 `http://aiproxy:3000`，不要附加 `/v1`。`AIPROXY_API_TOKEN` 必须与服务端配置一致且不能为空，不能用应用 API Key 代替。

模型渠道在 `管理员-模型提供商` 页面配置，模型 ID 是接口请求 Body 中 `model` 字段的值，全局唯一。模型能力按应用所需输入核对；多模态、工具调用及思考配置分别验证。应用参数在应用或节点配置中设置，不能假设兼容对话接口的同名字段会覆盖编排。

假设演练样本：某批护肤品的供应商资料原文为「本产品已完成皮肤刺激性测试，报告编号 LAB-2024-0312，测试对象为成品配方，签发日期 2024 年 3 月 12 日，结论为未观察到刺激性反应。」拟稿句为「本产品通过皮肤刺激性测试，适合敏感肌使用。」待判定的是「适合敏感肌使用」是否被上述材料支持。材料只覆盖刺激性测试结论，未涉及敏感肌适用性。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | `http://aiproxy:3000` | 文档示例根地址，不附加 `/v1`；与文档说明逐字比较 |
| `AIPROXY_API_TOKEN` | 非空管理员 Token | 文档要求非空且与服务端一致；与服务端配置比对 |
| 模型 ID | 按渠道模型填写 | 文档说明模型 ID 全局唯一；与渠道模型列表比对 |
| 模型能力 | 按文案任务所需输入核对 | 文档要求多模态、工具调用分别验证；与任务输入比对 |
| 应用参数 | 在应用或节点配置中设置 | 文档说明不能假设同名字段覆盖编排；与节点配置比对 |
| 模型探测 | 按需开启，间隔取 5～60 之间整数 | 文档给出该范围；与探测配置页比对 |

## 容易做错的三处

1. 把 `AIPROXY_API_ENDPOINT` 写成带 `/v1` 的完整请求地址。文档要求填写服务根地址，附加路径会导致启动校验或调用失败。检查方式是读取环境变量值，与文档示例格式比较，观察是否以根地址结尾。
2. 用应用 API Key 代替 `AIPROXY_API_TOKEN`。文档要求管理员 Token 且与服务端一致。检查方式是比对 App 侧与 AI Proxy 服务端的 Token 值，观察是否一致且非空。
3. 把材料未涉及的内容写成已支持。假设样本中材料只覆盖刺激性测试，拟稿句加入「适合敏感肌使用」。检查方式是把拟稿句拆成断言，逐条与材料原文比较，观察每条断言是否有对应原文。

## 怎么确认配好了

对假设样本逐项执行以下核对，不声称已实测。

1. 输入材料原文「本产品已完成皮肤刺激性测试，报告编号 LAB-2024-0312，测试对象为成品配方，签发日期 2024 年 3 月 12 日，结论为未观察到刺激性反应。」与拟稿句「本产品通过皮肤刺激性测试，适合敏感肌使用。」比较两者主体、对象、状态和有效范围。预期结果是「通过皮肤刺激性测试」被材料支持，「适合敏感肌使用」未获支持，记录为待核实。
2. 输入 `AIPROXY_API_ENDPOINT` 与 `AIPROXY_API_TOKEN` 的配置值，与文档说明比较。预期结果是根地址不带 `/v1`，Token 非空且与服务端一致。若任一项不符，记录为配置未满足。
3. 输入模型渠道中的模型 ID 与模型能力设置，与文案任务所需输入比较。预期结果是模型 ID 与渠道模型一致，任务所需图片输入或工具调用能力已分别核对。若模型未启用或能力缺失，记录为待处理，不推断调用结果。

检索检查只观察返回与失败分支，不保证首条命中或全部召回。空结果可用明确的纸面输入 `[]` 核对下游设计。跨不同向量模型的库不可共同关联，先核标识并排除不符合者，不执行跨模型检索来比较漏召回。
