# 跨境退货翻新与二次销售的商品与营销文案起草：知识库检索与召回

## 这个品类的数据长什么样

退货翻新商品的状态由海外仓质检环节判定，质检结论、翻新记录、报废单和二次上架清单分别记录不同处置阶段。商品文案起草需要从这些材料中确认某件商品的当前状态与可写内容。质检表记录外观与功能结论，翻新记录记录更换配件与包装动作，报废单记录不可再售判定，二次上架清单记录可重新销售的条目。四类材料共同构成文案的事实来源。材料按日或按批更新，检索时以具体批次为范围。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。搜索模式包含语义检索、全文检索与混合检索，混合检索通过 RRF 融合多路结果。引用上限以 token 为单位，最低相关度仅在语义检索或使用结果重排时生效。问题优化用于指代消除与问题扩展，会增加一次模型调用。图片检索需要相应图像输入与模型能力，重排需要具备模型并按设置启用。检索结果不承担权限或实体隔离职能。

假设演练样本

供核对的材料原文（虚构）：

“批次 HX-2405，商品为折叠储物箱，质检结论为外壳轻微划痕、功能正常，翻新记录为更换外包装，处置结论为可二次上架。”

待判定拟稿句：“该批次折叠储物箱经翻新后功能完好，可正常销售。”

核对目标：拟稿句中“功能完好”与材料“功能正常”是否同一字段同一取值；“经翻新后”是否与翻新记录所载动作一致；处置结论是否支持“可正常销售”的表述范围。

## 配置怎么定

| 配置项 | 本页取值或核对方式 | 依据与说明 |
| --- | --- | --- |
| 关联知识库 | 关联存放退货质检表、翻新记录、报废单、二次上架清单的库 | 节点要求同一向量模型，先核标识再关联 |
| 搜索模式 | 以样本问题分别试语义检索与混合检索 | 编号类内容适合全文或混合检索 |
| 引用上限 | 假设试验起点设为覆盖一条完整质检记录的 token 量 | 与长短不同的实际记录比较后调整 |
| 最低相关度 | 先标注相关与无关样本，再比较阈值效果 | 仅在语义检索或结果重排时生效 |
| 问题优化 | 比较多轮追问下原问题与优化后问题的主体是否被改错 | 用于指代消除与问题扩展 |
| 结果重排 | 候选较多且问题明确时按设置启用 | 重排得分可用于过滤 |

## 容易做错的三处

1. 将材料中的“功能正常”改写为“功能完好”，把未载明的程度判断写入文案。核对时比较拟稿句用词与材料原文用词，出现材料未出现的程度词即为超出支持范围。
2. 将“处置结论为可二次上架”直接写成“可正常销售”，把处置阶段结论当作销售事实。核对时比较拟稿句所述事实与材料所载字段，二者不属于同一字段即为未获支持。
3. 将待审核的翻新记录当作已完成的翻新动作写入文案。核对时比较记录状态字段，处于待审核状态即不构成已完成动作。

## 怎么确认配好了

1. 输入假设样本的拟稿句与材料原文，比较“功能完好”与“功能正常”的用词差异。仅当拟稿句用词不超出材料原文表述范围时，该句才通过核对；出现材料未载明的程度词时，记录为超出支持。
2. 输入交接请求“该批次可正常销售”，比较其与处置结论字段。仅当材料明确载有销售许可类字段时该请求才获支持；仅有处置结论时记录为待核实，保留证据缺口。
3. 输入一条仅含图片的查询，比较返回结果与知识库是否建立图片索引。仅当入库时生成有效图片索引且模型支持图片输入时，图片检索路径才可用；未建立索引时记录该路径不可用，不推断文本检索结果。
