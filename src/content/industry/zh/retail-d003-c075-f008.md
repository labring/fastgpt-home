# 达人专场带货合作的商品与营销文案起草：工作流编排

## 这个品类的数据长什么样

在达人专场带货合作的商品与营销文案起草中，本页说明FastGPT的工作流编排如何衔接资料。达人合作预告要区分拟邀请、寄样和档期确认；邀请计划不证明邀请已发出，流程应把待核状态传入起草。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟合作材料写“拟邀请达人举办专场”，寄样单说明样品已交寄，另有待确认档期。邀请计划没有提供邀请已经发出的依据。起草可收这些原句和适用商品，让人员选择补合作确认或整理样品介绍。寄出只支持寄件动作，不证明达人已收到、愿意合作或一定开播；协议草稿里的拟议安排也不能直接写成对外承诺。节点传到起草步骤时，应保留拟邀请与待确认状态。

## 配置怎么定

| 达人预告起草 | 自拟材料性质 | 承接要求 |
| --- | --- | --- |
| 邀请计划 | 拟邀请，合作未确认 | 不写成已发邀请或已敲定 |
| 寄样动作 | 仅交寄 | 不代收样回复 |
| 档期安排 | 仍待确认 | 不作为正式预告 |
| 样品范围 | 具体商品 | 不扩全部商品线 |
| 起草路径 | 补确认或整理介绍 | 收到对应原句 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

寄样冒合作：若交寄被写成已敲定专场，应查本次真实合作回复；草稿冒定档：若拟议档期变正式预告，应取明确确认；样品扩商品线：若单样说明用于全部商品，应核样品对象与稿件覆盖。三项分别核关系、阶段和范围，不由节点完成补出商业决定。

## 怎么确认配好了

验收分别查看补确认和整理介绍分支收到什么，确认商品身份和待定措辞未被删掉。加入达人回复后，只改它实际确认的合作内容；收样、档期或其他商品仍缺时不顺带补齐。对外发布、合作签署与寄件执行需要另接业务步骤核权限和回执，流程有成稿不证明预告可发，也不提供带货效果承诺。
