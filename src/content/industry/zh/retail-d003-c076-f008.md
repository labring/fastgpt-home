# 达人佣金结算与扣佣的商品与营销文案起草：工作流编排

## 这个品类的数据长什么样

在达人佣金结算与扣佣的商品与营销文案起草中，本页说明FastGPT的工作流编排如何衔接资料。佣金结算说明的文案要保留账单、退款扣回与实际处理之间的差别，整理流程不生成财务承诺。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟结算说明有佣金设置原句和待核账单，退款扣回资料只对应一笔交易，发票也未附处理确认。起草流程可收这些来源性质，人员选择补交易对应或补实际处理；本题不写金额、比例或时间承诺。设置记录说明拟采用什么安排，不能证明每笔交易都适用，账单编制也不证明钱已处理，缺项须随原句进入下游。

## 配置怎么定

| 结算说明起草 | 自拟来源 | 需核性质 |
| --- | --- | --- |
| 佣金设置 | 安排原句 | 非确定应付 |
| 账单状态 | 待核 | 非已经结清 |
| 退款扣回 | 只属某笔交易 | 不扩整份账单 |
| 发票材料 | 无处理确认 | 不代执行凭据 |
| 输入传递 | 范围与缺项同行 | 成稿保留待核 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

设置冒应付：若方案文字被写成确定应付，应核实际适用与确认依据；单笔扩整账：若退款扣回覆盖全部账单，应查交易归属；单据冒已结：若发票或账单被写成处理完成，应取对应执行记录。三项分别核适用、范围和阶段，不由材料标题彼此替代。

## 怎么确认配好了

验收看两条分支实际收到的交易范围和待核状态，补本笔对应后只更新该项说明。若仍无执行结果，成稿不能改为已经结清；新增发票标题也不足以改变。正式结算、扣回和账务回写由另接业务流程核权限及回执，流程有输出只说明起草动作，不确认应付结果，也不代替财务复核。
