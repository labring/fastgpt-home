# 达人佣金结算与扣佣的商品与营销文案起草：知识库检索与召回

## 这个品类的数据长什么样
达人佣金结算与扣佣发生在成交之后，核对重点是有效推广与售后扣佣。商品与营销文案起草要引用佣金设置记录、结算账单、退款扣佣明细与发票，这些材料按周或按月更新。文案中出现的佣金比例、结算周期、扣佣条件，必须能对应到上述文档的明确字段。若材料只写到“结算账单已生成”，该句不构成对具体扣佣比例的确认。

## 这些特征在「知识库检索与召回」这一环带来什么约束
知识库搜索节点可关联一个或多个使用相同向量模型的库。检索模式分为语义检索、全文检索与混合检索；混合检索经 RRF 融合多路结果，Rerank 对候选文本二次排序。引用上限以 token 为单位，最低相关度仅在语义检索或使用结果重排时生效。问题优化用于指代消除和问题扩展，会增加一次模型调用。检索不承担权限判断，也不隔离不同主体或不同期间的记录。

假设演练样本：材料原文为“2025年3月结算账单载明，达人A有效推广订单佣金比例为8%，退款订单对应佣金于退款完成当月扣回。发票开具以实际结算金额为准。”待判定拟稿句为“达人A的佣金比例为8%，退款佣金当月扣回。”该句主体与比例字段可对上，扣回时点需核对“退款完成当月”与“当月”是否同一口径。

## 配置怎么定
| 配置或核对项 | 本页取值或动作 | 依据与说明 |
| --- | --- | --- |
| 关联知识库 | 仅关联同一向量模型的佣金结算类库 | 节点要求相同向量模型，跨模型库先核标识并排除 |
| 搜索模式 | 先用混合检索，编号类字段再比全文检索 | 语义与全文各有适用场景，不预设单一模式 |
| 引用上限 | 假设试验起点设为覆盖一条账单字段的 token 量 | 起点由本样本字段长度决定，与更长账单样本比较完整性 |
| 最低相关度 | 先标注相关与无关样本，再调阈值 | 该值仅在语义检索或结果重排时生效 |
| 问题优化 | 多轮追问时开启，并核对主体是否被改错 | 用于指代消除与问题扩展，增加一次模型调用 |
| 空结果承接 | 用纸面输入空数组核对下游分支 | 引用内容长度可为0，输出链路仍走通 |

## 容易做错的三处
1. 把“结算账单已生成”读成佣金比例已确认。账单生成与比例字段载明是两件事，输入为账单原文时，比较对象应是比例字段本身，观察结果是该字段是否出现。
2. 把最低相关度当作权限或主体过滤器。该值是过滤阈值，输入为达人A的拟稿句时，比较对象是相关度得分与阈值，观察结果是低分片段是否被裁掉，主体隔离仍需另行核对。
3. 把待审核的文案当作已批准发布。输入为拟稿句与材料原文，比较对象是两者字段是否同主体、同期间、同字段，观察结果是未载明部分应记为待核实。

## 怎么确认配好了
1. 输入上述假设样本的材料原文与拟稿句，比较比例字段“8%”与拟稿句“8%”是否同主体同期间，出现字段一致且扣回时点口径可对应，才算该句获材料支持。
2. 输入同一材料原文，比较“退款订单对应佣金于退款完成当月扣回”与拟稿句“退款佣金当月扣回”，出现“退款完成当月”与“当月”表述不一致时，该句记为待核实，不记为否定。
3. 输入一条不含任何佣金字段的纸面查询，比较返回引用内容长度是否为0，出现空数组时下游分支按空结果承接；该结果不表示无关查询必然为空，也不表示检索具备权限过滤。
