# 进出口许可证件办理的商品与营销文案起草：工作流编排

## 这个品类的数据长什么样

在进出口许可证件办理的商品与营销文案起草中，本页说明FastGPT的工作流编排如何衔接资料。许可证件服务文案要说明材料准备与办理结果各有出处，不从合同和商品描述直接承诺许可已经取得。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟合同描述拟进口商品，产品说明摘录只写用途，证件材料清单仍缺对应许可结果。流程可收这些原句与对象，人员选择补商品说明或核本次办理依据。这里只起草材料服务说明，不判定商品属于哪种许可类别，也不给办理规则。合同已签不能推出许可已获，清单列有证件名也不说明实际文件存在或覆盖本次商品。

## 配置怎么定

| 证件服务文案 | 自拟资料 | 起草核法 |
| --- | --- | --- |
| 合同对象 | 拟进口商品 | 不推许可已获 |
| 产品用途 | 单句说明 | 不自行定许可类别 |
| 准备清单 | 只列证件名称 | 取实际文件 |
| 对象关系 | 排除另一商品 | 核本次覆盖 |
| 正式结果 | 尚无办理依据 | 不写完成承诺 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

清单冒证件：若待备名称被写成已持有，应取实际文件及对象；用途冒分类：若单句用途被写成确定许可类别，应核真实专业判定依据；他货结果套用：若另一商品文件支持本次，应查对象对应。三项分别核存在性、判断依据和范围，不由流程补出法定要求。

## 怎么确认配好了

验收查看补说明与核办理两个路径的实际输入，确认拟议商品和缺项仍可识别。补入本次文件后，仅修改它覆盖的材料状态，不延伸成其他商品也已获许可。正式申请、主管处理与对外发布需另接步骤核实际权限和回执，成稿不证明许可办理已完成，也不构成进出口合规或准入承诺。
