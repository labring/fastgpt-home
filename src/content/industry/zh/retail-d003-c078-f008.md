# 连锁总部选址开店的商品与营销文案起草：工作流编排

## 这个品类的数据长什么样

在连锁总部选址开店的商品与营销文案起草中，本页说明FastGPT的工作流编排如何衔接资料。开店公告要把选址、租赁意向与正式开业分开，拟议排期不能自动成为对外承诺。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟选址意见写“继续评估”，租赁意向书未有正式确认，开业排期标草案。流程可收地点与这些状态原句，让人员选择补场地依据或核排期确认。装修预算只作为相关资料名称，不写金额；评估继续不代表地点已定，意向书存在也不证明租赁生效。起草门店介绍时应保留哪些内容尚属计划，不因选择进入下一步就改成已开业。

## 配置怎么定

| 开店公告起草 | 自拟状态原句 | 对应证据 |
| --- | --- | --- |
| 选址意见 | 继续评估 | 非地点落定 |
| 租赁意向 | 未正式确认 | 不称已生效 |
| 排期草案 | 拟议安排 | 不作开业通知 |
| 地点传递 | 源地点与接收一致 | 排除他址介绍 |
| 业务执行 | 公告施工另办 | 成稿不证营业 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

意向冒落定：若意向书被写成门店已确定，应取实际确认依据；草案冒开业：若拟议排期变正式营业通知，应核本次批准及执行状态；地点串用：若另一地址介绍进入成稿，应对照源地点与下游输入。三项分别核决策、阶段和对象，不能由文案润色补齐。

## 怎么确认配好了

验收沿补场地和核排期路径查看实际接收，加入地点确认后只更新它证明的内容。排期仍未确认时，不顺带发布确定开业说法；施工资料也不能代替营业状态。正式租赁、施工执行和对外公告需另接业务流程核权限与回执，节点输出只说明草稿形成，不证明门店可营业或计划必定实现。
