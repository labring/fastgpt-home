# 连锁门店闭店清算的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

闭店清算处理退出与资产回收，资料来自POS库存、资产系统、租赁合同和财务账，包括闭店审批、库存清退单、租约解除协议及资产盘点表，按店、不定期更新。文案中的商品、数量、状态和期限须对应原文；授权与租约解除结论分别核，不补未知字段。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入由 AI Proxy 承担。自 V4.17.0 起 AI Proxy 为必需依赖，App 与复用 App/Service 配置的 Admin 服务都必须设置 AIPROXY_API_ENDPOINT 与非空的 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。AIPROXY_API_ENDPOINT 填写服务根地址，不附加 /v1。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两项。

模型配置在管理员-模型提供商页面完成，渠道配置包含渠道名、协议类型、模型、模型映射、代理地址与 API 密钥。代理地址填写 BaseUrl，需确认是否增加 /v1。模型 ID 是请求 Body 中 model 字段的值，全局唯一；模型名用于展示，可自定义。系统至少需要一个语言模型和一个索引模型才能正常使用。模型能力按应用所需输入核对，多模态、工具调用分别验证；应用参数在应用或节点配置中设置，不能假设兼容对话接口的同名字段会覆盖编排。

### 假设演练样本

以下为纸面演练材料，不涉及真实门店或主体。

材料一（库存清退单摘录）：「门店编号 H-07，清退商品：折叠收纳箱 200 件，状态为可售，清退截止日期 2026-11-30。」

材料二（租约解除协议摘录）：「出租方与承租方拟就H-07门店办理租约解除，协议列交还日期2026-11-15，签署状态为待双方签署。」

待判定拟稿句：「H-07 门店折叠收纳箱 200 件，可售，11 月 30 日前完成清退，租约已解除。」

## 配置怎么定

下表围绕本页材料与文案起草任务列出配置项或核对项。数值一栏标注为本次假设试验起点时，需说明选取理由与比较对象。

| 配置项或核对项 | 本次取值或状态 | 说明与比较方法 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设起点 http://aiproxy:3000 | 文档要求填根地址且不附加 /v1；与含 /v1 的写法比较，确认路径层级 |
| AIPROXY_API_TOKEN | 非空管理员 Token | 文档要求与服务端一致且不能为空；与应用 API Key 区分，核对来源 |
| 语言模型与索引模型 | 各至少启用一个 | 文档说明系统最低要求；核对已启用列表是否覆盖两类 |
| 模型映射 | 假设起点 gpt-4o-test 映射至 gpt-4o | 文档示例形式；核请求标识是否按映射指向上游目标 |
| 渠道代理地址 | 填 BaseUrl，按厂商确认 /v1 | 文档要求不填完整请求地址；与完整路径写法比较 |
| 文案字段来源核对 | 逐句对照清退单与租约解除协议 | 核对主体、对象、状态、日期范围是否在材料中载明 |

## 容易做错的三处

1. 把 AIPROXY_API_ENDPOINT 写成含 /v1 的完整请求地址。文档要求填写服务根地址，不附加 /v1。输入为含 /v1 的地址，比较对象为文档所述根地址形式，观察结果是启动校验是否通过、请求路径是否重复拼接。
2. 用应用 API Key 充当 AIPROXY_API_TOKEN。文档要求管理员 Token 且非空。输入为应用侧 Key，比较对象为服务端配置的管理员 Token，先核凭证用途及服务端一致性，实际鉴权结果待测。
3. 在拟稿句中把待签署写成已解除。样本材料二载明签署状态为待双方签署。输入为该拟稿句，比较对象为材料二的签署状态字段，观察结果是该句是否超出材料支持范围；原文未给解除生效条件或完成记录，解除状态待核。

## 怎么确认配好了

以下三项验证均使用上文假设演练样本，不表示已实际执行。

1. 地址配置验证。输入为假设起点 http://aiproxy:3000 与另一条含 /v1 的写法。比较对象为文档对 AIPROXY_API_ENDPOINT 的路径要求。满足条件的现象是：根地址形式与文档描述一致，含 /v1 的写法被识别为不符合；启动校验结果需实际观察后记录。
2. 模型映射验证。输入为假设起点映射关系 gpt-4o-test 至 gpt-4o。比较对象为文档中模型 ID 与上游实际 model 的区分说明。满足条件的现象是：请求侧模型 ID 与上游发送的 model 分别可辨，二者不混为同一字段；渠道测试的实际输出需观察后记录。
3. 文案字段验证。输入为材料一、材料二与待判定拟稿句。比较对象为材料载明的商品名称、数量、状态、清退截止日期与签署状态。满足条件的现象是：数量 200 件、状态可售、截止日期 2026-11-30 与材料一致；签署阶段与解除生效是不同字段，原文只给待签署及交还日期，没有解除完成记录，“租约已解除”待核，不反推已解除或未解除。
