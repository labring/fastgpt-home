# 逆向退货入仓质检的商品与营销文案起草：工作流编排

## 这个品类的数据长什么样

在逆向退货入仓质检的商品与营销文案起草中，本页说明FastGPT的工作流编排如何衔接资料。逆向退货商品介绍要留住质检覆盖与定级依据，入仓记录不能直接支撑成色或可售承诺。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟退货入仓单只写已收件，质检照片仅显示外壳，定级说明待复核，上架单也是安排。流程可收这些原句与物件对应，人员选择补功能检查或核定级。入仓只说明接收动作，外壳图不支持功能完好，安排上架也不证明已公开可售。这里不提供定级标准，更不从素材齐全生成“全部恢复”的商品描述。

## 配置怎么定

| 退货介绍起草 | 自拟所指 | 所需证据 |
| --- | --- | --- |
| 入仓记录 | 仅已收件 | 非品质结论 |
| 照片覆盖 | 只见外壳 | 功能另核 |
| 定级状态 | 待复核 | 不写确定成色 |
| 上架安排 | 任务非许可 | 取实际决定 |
| 物件对应 | 同款也需同件 | 排除他件素材 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

外观冒功能：若外壳照片被写成功能正常，应取实际功能检查；待核冒定级：若复核未完却写确定成色，应查本件明确结论；安排冒可售：若上架任务变成允许销售，应取实际决定依据。三项分别检查证据类型、结论阶段和业务许可，不由流程自动补全。

## 怎么确认配好了

验收查看补检查与核定级两条路径是否收到同一退货件，加入功能记录后只修改其覆盖内容，定级未决仍留待核。若照片来自另一物件，应先排除，不能靠同款名连接。实际库存归类、上架发布和售后承诺需另接业务流程核权限及回执，文案完成不证明该件已复原或已经销售。
