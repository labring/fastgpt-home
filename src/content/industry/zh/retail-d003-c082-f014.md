# 逆向退货入仓质检的商品与营销文案起草：模型接入与配置

## 这个品类的数据长什么样

逆向退货入仓质检处理的是退回包裹与商品等级，不处理新订单出库。主要资料来自 WMS 退货模块、平台售后、承运商退件与质检台，日常文档为退货入库单、质检照片、等级判定表与重售上架单。每件商品、每日更新，意味着文案起草必须逐单对照质检结论，不能沿用原销售页描述。

起草商品与营销文案时，模型接入与配置决定模型能否读取这些材料。系统至少需要一个语言模型和一个索引模型才能正常使用；AI Proxy 为必需依赖，App 与复用其配置的 Admin 服务都必须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN。模型 ID 是请求 Body 中 model 字段的值，全局唯一；模型名仅用于展示。

## 这些特征在「模型接入与配置」这一环带来什么约束

退货入库单与等级判定表属于结构化文本，质检照片属于图像输入。若拟稿需要读取照片判断成色，所用语言模型必须支持图片输入，vision 字段说明该能力。工具调用与函数调用影响分类、内容提取与工具调用，toolChoice 为 true 时优先使用工具选择，functionCall 为 false 时回退到提示词模式。引用内容上限由 quoteMaxToken 描述，思考预算属于另一类配置，两者不互换。

检索环节只负责相关文本召回。语义召回与相关度不承担权限或实体隔离，检索不是授权。同一向量模型是库之间可共同关联的条件；跨不同向量模型的库不可共同关联，只能先核标识、排除不符合者并记录实际观察。空结果可以用明确的纸面输入 [] 核对下游设计。

假设演练样本（纯纸面，未实际调用）：退货入库单载明“退件编号 RT-0001，商品为折叠椅，数量 1 件，签收日期 2026-03-02，质检结论为外观轻微划痕，功能正常，判定等级 B，可重售”。等级判定表载明“B 级：外观存在可见瑕疵，功能完好，可按二手良品上架”。待判定拟稿句为“该折叠椅为全新未使用商品，外观无任何瑕疵”。此句与材料同主体、同对象、同字段：材料说轻微划痕、B 级，拟稿说无任何瑕疵，属同字段互斥取值。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 填写 AI Proxy 服务根地址，不附加 /v1 | 官方要求根地址；与附加 /v1 的写法比较 |
| AIPROXY_API_TOKEN | 填写与服务端一致的非空管理员 Token | 官方要求非空且一致；与空值或应用 API Key 比较 |
| 语言模型 vision | 按需设为 true | 拟稿涉及质检照片；与 false 时无法读图比较 |
| 语言模型 toolChoice / functionCall | 按分类与提取需要核对取值 | 官方说明两者优先级；与提示词模式回退比较 |
| 索引模型 defaultToken / maxToken | 按文本块长度核对 | 官方字段说明；与超出 maxToken 的分割比较 |
| 模型探测间隔 | 假设设为 15 分钟 | 官方支持 5～60 整数；与范围外取值比较 |

## 容易做错的三处

1. 把 AIPROXY_API_ENDPOINT 写成完整模型请求地址并附加 /v1。检查：输入该地址，比较官方“不要附加 /v1”的要求，若地址含 /v1 则不满足。
2. 用应用 API Key 代替 AIPROXY_API_TOKEN。检查：输入所填 Token，比较服务端配置的管理员 Token，若为空或与之一致性不成立则不满足。
3. 把语义相关度当作权限或实体过滤。检查：输入跨实体检索请求，比较返回记录与授权范围，若以相似度分数排除无关业务则属误用。

## 怎么确认配好了

1. 输入假设样本的退货入库单与等级判定表原文，以及拟稿句“该折叠椅为全新未使用商品，外观无任何瑕疵”。比较拟稿句与材料同字段取值：材料为轻微划痕、B 级，拟稿为无任何瑕疵。出现两者互斥的观察结果，即表明该句未获材料支持，需改写或补充证据。材料未载明“全新”状态，该点保持未获支持。
2. 输入质检照片与启用 vision 的语言模型配置。比较模型是否接收图像输入并输出与照片一致的成色描述。若模型返回与照片不符的等级描述，记录为待核实，不推断错误码或自动动作。
3. 输入纸面空结果 [] 与下游拟稿流程。比较下游在无召回文本时的输出行为，观察是否出现无依据宣传句。若下游仍生成具体瑕疵结论，记录该现象，不声称系统自动阻断或自动改写。
