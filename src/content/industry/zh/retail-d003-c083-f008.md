# 门店盘点与防损的商品与营销文案起草：工作流编排

## 这个品类的数据长什么样

在门店盘点与防损的商品与营销文案起草中，本页说明FastGPT的工作流编排如何衔接资料。盘点防损说明要区分差异发现、原因调查和实际处理，不能把盘差或监控摘录直接写成责任结论。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟盘点说明只记账实待核，差异分析列可能原因，监控复核摘录仅描述某段动作。起草流程可收资料范围，由人员选择补盘点依据或核原因记录，不写数量和损失金额，也不提供人员身份或指控。盘差只说明需要查，可能原因仍是推测；报损批准若缺，也不能从清点结束推出库存已调整。

## 配置怎么定

| 盘点防损说明 | 自拟资料性质 | 需保留界线 |
| --- | --- | --- |
| 账实差异 | 仍待核 | 不称原因查明 |
| 分析原句 | 可能原因 | 不冒调查结论 |
| 监控摘录 | 局部动作描述 | 不直接归责 |
| 库存处理 | 缺实际记录 | 不写已调整 |
| 输入传递 | 待核措辞同行 | 补证仅改对应项 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

假设冒原因：若可能原因被写成已查明，应取本次真实调查依据；片段冒责任：若局部录像描述被写成归责，应核完整上下文与实际结论；清点冒处理：若盘点完成变成已调库存，应查对应处理记录。三项分别核推断、证据覆盖和执行，不由稿件完成改变。

## 怎么确认配好了

验收沿补盘点与核原因路径比较实际接收，保留所有待核措辞。补入差异来源后，只改已被证实的解释，未有处理结果仍不写结束。库存变更、报损和正式调查需要另接业务流程核权限及记录，文案仅说明已知与未知，不从视频可见推出责任，也不把流程输出称作防损效果证明。
