# MCN机构达人管理的合同与交易材料比对：引用来源与溯源

## 这个品类的数据长什么样

在MCN机构达人管理的合同与交易材料比对中，本页说明FastGPT的引用来源与溯源如何衔接资料。脚本意见、素材使用范围和达人档期回复分别回指原文。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

MCN合同比对可自拟合作说明“成片用途另见素材授权页”、脚本批注“删去夜景段”和达人回复“周三可沟通”。问是否已允许剪辑后的短片用于门店屏幕时，脚本批注只针对内容，档期回复只说明沟通意向，尚未提供用途页。应把待核授权对象写清为当前成片及门店屏幕，不能因为脚本已经交换过，就把没有看到的使用范围补进答案，或声称已经排好拍摄。

## 配置怎么定

| 交易来源核对项 | 材料与行动范围 | 验收动作 |
| --- | --- | --- |
| 成片对象 | 当前剪辑片 | 核素材身份。 |
| 内容批注 | 删除夜景段 | 不扩成用途许可。 |
| 沟通档期 | 周三讨论 | 另核拍摄确认。 |
| 用途页 | 当前尚未给 | 追查范围及输入。 |
| 旧页归属 | 可能是别达人 | 对照署名和版本。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是脚本删段被引用成门店屏幕使用许可，应查真实用途页及其对应素材，内容意见不等于使用范围。第二处是周三可沟通被写成拍摄档期已定，应读回复所指活动，另找本次拍摄确认。第三处是另一达人的旧用途页挂到当前成片，应核署名、素材身份及适用版本。不同问题需要范围材料、日程确认和来源对象核对，不能由同一机构名称串成授权链。

## 怎么确认配好了

验收分别询问脚本发生了什么变更、达人同意了哪项活动、屏幕用途有什么依据，保存引用中实际采用的文字。若引用只有脚本，先追查用途页是否进入知识范围及回答输入；材料未返回不说明已被禁止使用。取得用途页后仍要核当前素材与使用场景，不从可读该页推定签署、审批或发布已经完成。这里核的是证据支持到哪一步，实际安排仍需相应记录。
