# MCN机构达人管理的合同与交易材料比对：文档解析与分块

## 这个品类的数据长什么样

在MCN机构达人管理的合同与交易材料比对中，本页说明FastGPT的文档解析与分块如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

达人合作条款可用新拟合同作分块测试：“品牌素材可用于本次直播；用于后续推广前需另行约定。”两句在用途和时间上各有限制，解析后不能只留下品牌素材可用的概括。用“本次直播能否使用”和“后续推广依据是什么”分别检索，回查返回内容是否保留原词及条件，避免用一处命中代替两个使用场景的材料核对。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或条件 | 回查线索 |
| --- | --- | --- |
| 原文条件 | 本次直播与后续推广分开 | 不得概括为素材不受限制可用。 |
| 分段完整性 | 后续推广前需另行约定 | 检查时间及用途条件仍关联。 |
| 原数据与索引 | 合同与处理单分别保留 | 不把索引摘要当作责任结论。 |
| 样本检索 | 本次使用与后续使用两个问题 | 分别核原文支持的适用范围。 |
| 更新后复核 | 缺品牌素材清单 | 新增附件需有解析与索引证据。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

另拟违规处理单记载“后续推广中使用了该品牌素材”，这是一项记录说法，不等于已经确认违反合同。先核解析是否保留“后续推广”这一时间语境，再分别查看合同和处理单原数据。索引的作用是提供检索入口，不能把两份材料合并成已经作出的责任结论；材料身份、版本及实际适用关系仍需单独确认。处理单的记录文字还需与合同的用途和时间前提分开核，不能把一条事件陈述当成完整授权链。实际比对所用版本应在原数据中能够回查。

## 怎么确认配好了

合同若另提到品牌素材清单，而当前输入没有清单，就无法从正文解析出全部素材名称。应先登记缺少的附件及它与条款的关系，补充后再检查解析和索引是否更新。重复同一个素材范围问题，核引用是否来自新增附件；若只是上传记录存在而没有对应原数据，仍不能验收已经具备清单内容。本例只验证文字承接，不执行授权或责任认定。
