# MCN机构达人管理的合同与交易材料比对：权限与数据隔离

## 这个品类的数据长什么样

在MCN机构达人管理的合同与交易材料比对中，本页说明FastGPT的权限与数据隔离如何衔接资料。按达人、经纪和审核任务核签约及处理材料权限，保留长期账号管理与单次记录的边界。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

比对练习可自拟某达人签约附页、账号排期与一份违规处理说明，经纪拟核合作事项，审核拟看内容要求，达人只拟看自身相关资料。先按真实账号核读取及操作，不把同属机构作为全员共享依据。若某达人身份能取得另一人的处理说明，应保留完整返回查资源范围；长期管理涉及多账号，单条排期的业务关联不构成跨达人资料访问授权。

## 配置怎么定

| 权限核对项 | MCN长期管理资料 | 验收证据 |
| --- | --- | --- |
| 任务分工 | 经纪、审核及达人各自需求 | 真实账号资源及操作 |
| 达人边界 | 他人处理说明不拟开放 | 完整返回及拒绝范围 |
| 业务称谓 | 签约方与账号主体分开 | 不自动配置团队成员 |
| 外部通知 | 平台账号及接口鉴权另核 | 不能据取回推全员可读 |
| 结果含义 | 已处理不自动等于恢复账号 | 原始结果与内容归属另验 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 签约方或通知主体被直接建成成员角色：核真实账号与资料操作映射，称谓不配置权限，缺对应须责任人确认。

- 本达人读出另一人的合同或处理说明：保留完整返回及资源设置查边界，机构长期管理多个账号不授予跨达人访问。

- 可读处理说明被解释成违规已撤销或账号恢复：并列通知、结果与回答，权限只核读取，已处理的业务含义还需实际来源。

## 怎么确认配好了

验收让经纪、审核、对应达人及无关达人询问同一处理材料，记录实际原句、拒绝和操作。受限条款可能被回答转述，不能只看附件是否列出，应查完整返回。若访问正常但答案混用另一账号排期，转查输入主体与版本，不将内容混用全归为隔离故障。最终按资源列清未确认范围，账号处置、合作权利及内容批准仍由适用资料与责任人核实。

| --- | --- |
| 文档类型 | 达人签约合同、培训记录、违规处理单、账号排期 |
| 候选来源 | MCN后台、平台违规通知、达人账号数据、合同台账 |
