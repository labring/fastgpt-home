# Shopify独立站订单履约的合同与交易材料比对：文档解析与分块

## 这个品类的数据长什么样

在Shopify独立站订单履约的合同与交易材料比对中，本页说明FastGPT的文档解析与分块如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

独立站交易材料可另拟一条运费说明：“标准规则仅适用于区域甲；区域乙另行核对。”解析时需要保留区域及“仅适用”的关系，不能只留下标准规则四字。与一份区域乙订单放在一起阅读时，应先检查取回的条款是否包含排除条件，再决定当前资料能回答什么；本文没有设置运费数值，也没有执行运费核算。区域甲和乙只是自拟说明中的范围标记，不表示真实配送覆盖。检查应聚焦条款所写的限制；订单涉及区域乙，也不等于已有针对该区域的完整规则。

## 配置怎么定

| 核对项（含实施核对） | 本题输入或条件 | 回查线索 |
| --- | --- | --- |
| 原文范围 | 标准规则仅适用于区域甲 | 区域乙不能被自动并入适用范围。 |
| 分段完整性 | 定制商品不适用一般条款 | 保留定制标识、排除及附件指向。 |
| 原数据与索引 | 订单与退款附页分别保留 | 索引概括不是退款处理决定。 |
| 样本检索 | 区域问题与定制退换问题 | 各自核是否取回限制原文。 |
| 更新后复核 | 缺少定制退换附件 | 分别记录补资料与解析遗漏。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

退款记录的自拟附页再写“定制商品退换条件见附件，不适用一般条款”，订单详情则标有定制商品字样。两份原数据应独立保留，解析不能把一般条款当成该订单已经满足的条件。用定制标识和退换问题分别检索，检查分块是否保留指向附件及“不适用”；索引概括也需能回到这些原句，不能构成无出处的退款处理决定。

## 怎么确认配好了

定制退换附件尚未提供时，当前只能定位条款指向，无法从正文补出完整条件。应保留具体缺口并等待适用资料，补齐后核解析、训练或索引状态，再用原交易问题检查新增引用。如果附件原本就在文件中而未被解析出来，则需保留对应位置和失败输出，避免把解析遗漏误记成根本没有规则，也不以重新上传的记录代替内容验收。
