# 一般贸易出口报关的合同与交易材料比对：引用来源与溯源

## 这个品类的数据长什么样

在一般贸易出口报关的合同与交易材料比对中，本页说明FastGPT的引用来源与溯源如何衔接资料。出口合同品名、发票简写和装箱实物描述按对象建立回指。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

出口交易比对可拟合同“桌面金属支架，不含夹灯”、发票“桌架”和装箱说明“支架底座另包”。资料另带一份旧宣传页，照片描述为带灯组合。问本次是否应把夹灯写进商品描述时，应以文字对象核对，不能让宣传组合替代合同排除条件。发票简写需要确认对应关系，底座另包说明包装安排，也不意味着新增配件。这里核的是三份本次材料可支持的商品范围，不从名称推报关资格或处理结果。

## 配置怎么定

| 交易来源核对项 | 材料与行动范围 | 验收动作 |
| --- | --- | --- |
| 合同组成 | 不含夹灯 | 保留排除句。 |
| 发票简称 | 桌架未证实对应 | 找本笔映射。 |
| 底座位置 | 另包不是排除 | 核清单及动作。 |
| 旧宣传页 | 带灯组合 | 核版本及对象。 |
| 实际引用 | 本次合同及发票 | 核限定均传入。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是带灯宣传页被用来扩充本次合同，应核宣传页版本、组合对象和合同排除句，不能只因支架相似就纳入夹灯。第二处是桌架简写被直接等同完整合同品名，应查本笔商品对应说明并保存两处原文。第三处是底座另包被写成底座不在交易内，应读取另包动作及商品清单，不把包装位置改成组成排除。三个问题分别对版本、名称映射和包装语义取证。

## 怎么确认配好了

验收可问合同排除了什么、发票简称能否对应、底座为何分开描述，查看回答实际引用是否包含关键限定。若只引宣传页，不能宣称已完成合同与发票的比对，应追查本次交易材料的范围和传入。补入对应说明后核它是否针对当前商品，不靠相近型号猜同一对象。材料阅读不执行申报，也不替代适用要求的独立核验；引用为空只表示当前未有可用引用，需继续定位。
