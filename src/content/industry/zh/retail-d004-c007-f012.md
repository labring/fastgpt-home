# 一般贸易进口报关的合同与交易材料比对：文档解析与分块

## 这个品类的数据长什么样

在一般贸易进口报关的合同与交易材料比对中，本页说明FastGPT的文档解析与分块如何衔接资料。外箱尺寸与货物规格分栏，不能在解析后共用数值身份。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

进口合同比对自拟附件不填数值，只列“货物规格见技术页”和“外箱尺寸用于装载安排”，页脚注明包装资料不作商品规格。用户问合同是否给出商品尺寸时，原文仅将货物规格指向另一页，外箱栏也限定了用途。解析和分块都应保留这两个范围，不能因为尺寸一词进入同一文件，就用外箱信息补出商品数据，更不能补造技术页内容。

## 配置怎么定

| 原文或分块核对项 | 具体材料关系 | 取证动作 |
| --- | --- | --- |
| 规格转引 | 货物规格见技术页 | 保留未读来源身份。 |
| 包装用途 | 外箱用于装载 | 核用途未转成商品属性。 |
| 页脚条件 | 包装资料不作规格 | 核条件随相关块。 |
| 解析顺序 | 技术页指向与外箱栏相邻 | 查是否串接内容。 |
| 补页复测 | 技术页身份和适用货物 | 核处理、索引及新引用。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

一种失败是页脚被单独切出，外箱栏失去不作规格的限制；另一种是技术页引用与外箱标题相邻，解析把后者接成前者的内容。排查应逐项对照原页布局、解析文字顺序和实际块，找出条件分离或归属串接位置。索引含商品尺寸词也需检查所指原数据，不能让提问用语把包装用途改成商品属性。文档题名完整不能替代栏级关系核验。

## 怎么确认配好了

验收分别用货物规格、外箱尺寸和“现有合同是否列明商品尺寸”的问题检索，核回答仍区分实际给出与转引未读。取得技术页后先核文档身份与适用货物，再检查处理和索引状态，用同题看新增片段是否进入引用。旧包装块可保留装载用途，但不承担商品规格证明。上传技术页成功也不能直接宣布尺寸问题已经回答完整，需要看实际原文与返回内容。
