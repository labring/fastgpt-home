# 亚马逊FBA备货运营的合同与交易材料比对：文档解析与分块

## 这个品类的数据长什么样

在亚马逊FBA备货运营的合同与交易材料比对中，本页说明FastGPT的文档解析与分块如何衔接资料。重贴外箱标记与商品标签除外，需要保留行间否定关系。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

FBA服务附件自拟一行“重贴外箱标记—本次处理”，下一行“商品标签—不在本次范围”，表后补充“新增处理另行确认”。比对是否包含商品重贴时，应先核行级对象与范围。外箱标记与商品标签都含标签含义，不能因名称接近就合并服务；解析若按列输出，否定范围可能被贴错行，分段前必须与原表逐行对照。

## 配置怎么定

| 原文或分块核对项 | 具体材料关系 | 取证动作 |
| --- | --- | --- |
| 服务行 | 外箱与商品标签分开 | 核行值正确配对。 |
| 否定范围 | 商品标签不含 | 核除外随对象。 |
| 新增条件 | 另行确认 | 核注记没有离块。 |
| 原块映射 | 商品入口仍应含除外 | 查索引目标原文。 |
| 附件修订 | 新旧范围可能并存 | 核处理及实际引用版本。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

常见错误是把商品标签行与本次处理拼接，回答宣布包含；另一种失败是新增确认注记分块后丢失，使任何补做都看似可以直接执行。应核原表、解析文本和块中范围，分别记录错行和条件分离。原数据可能有多个检索入口，但商品入口应回指含除外条件的实际原块，不能用索引文字形成新增服务。没有处理结果时也不能把约定范围写成已经完成的贴标动作。

## 怎么确认配好了

验收用外箱标记、商品标签原词及“是否可直接追加商品重贴”测试，检查返回块完整保留所属行与另行确认。输出如列待办，应分清本次范围和待确认新增，不能统一标成可执行。附件修订后核实际处理、索引和返回版本，再复测同题。上传新版不能证明除外行已更新进检索，需逐条对照原文及引用；保留旧块有助定位为何仍出现旧范围。
