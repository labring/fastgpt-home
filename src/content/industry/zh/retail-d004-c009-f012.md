# 亚马逊FBM自发货运营的合同与交易材料比对：文档解析与分块

## 这个品类的数据长什么样

在亚马逊FBM自发货运营的合同与交易材料比对中，本页说明FastGPT的文档解析与分块如何衔接资料。安排发出前的库存确认与特殊区域另核，不能拆成无条件承诺。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

FBM服务条款自拟跨段文字：“库存确认后安排发出”，下一段续写“上述安排不含需另核的特殊区域”。问题问是否所有地区都可直接发出时，续段的上述安排要回到前段动作，不能作为无主语的通用备注。解析需保留段落顺序，分块时应检查库存前置与区域范围能否共同回指；原文没有具体地区清单，不宜自行定义哪些地方属于特殊区域。

## 配置怎么定

| 原文或分块核对项 | 具体材料关系 | 取证动作 |
| --- | --- | --- |
| 前置关系 | 库存确认后安排 | 核条件与动作共同回指。 |
| 续段指代 | 上述安排指前段 | 核段落顺序。 |
| 区域例外 | 特殊区域另核 | 核例外未独立失主语。 |
| 地区缺页 | 未提供具体范围说明 | 不推定例外不存在。 |
| 更新复测 | 续段处理与索引版本 | 比较原问题返回。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

一种失败是库存条件独立在前块，后块只剩安排发出，被回答变成现货承诺；另一处风险是区域除外段离开主句，系统只取到肯定动作。排查需对照原文相邻关系与实际块，分别检查前置条件、范围例外在哪一步丢失。检索入口含全部地区也不能补齐原文范围。索引与原数据应分别核，不能因入口可搜到就认定例外文字已经传给回答。

## 怎么确认配好了

验收分别以库存确认、特殊区域和“所有地区能否直接发出”检索，检查引用是否组合回完整条件。回答应保留库存确认后安排、区域另核两层范围，不补当前库存或实际发货结果。条款更新后核实际处理与索引版本，仍用同题比较返回块；上传成功不代表续段关系已经恢复。若地区说明另页未提供，将缺项记明，不把空缺解释成不存在例外。
