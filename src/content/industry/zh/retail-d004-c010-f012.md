# 京东POP第三方店铺运营的合同与交易材料比对：文档解析与分块

## 这个品类的数据长什么样

在京东POP第三方店铺运营的合同与交易材料比对中，本页说明FastGPT的文档解析与分块如何衔接资料。主机更换条款的附件除外应保留在同一范围解释中。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

京东POP交易附件自拟主条“符合本页条件时更换主机”，紧接括注“附件不随更换，另有确认的除外”，条件页本组未提供。问是否整套更换时，主机、附件与例外确认属于三项阅读对象。解析若忽略括注，或分块只留更换主机，就容易把局部条款扩大为整套安排。现有文字还能说明存在前置条件，但不能自行补出条件内容或认定本次已满足。

## 配置怎么定

| 原文或分块核对项 | 具体材料关系 | 取证动作 |
| --- | --- | --- |
| 主条对象 | 更换主机 | 核没有扩大为整套。 |
| 完整括注 | 附件除外及另有确认 | 核例外与否定同在。 |
| 前置缺页 | 符合条件但页未提供 | 不补资格判断。 |
| 入口原块 | 整套问法指向何处 | 核原文限定。 |
| 条件补入 | 适用条款与新页状态 | 核同题返回和采用情况。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

常见错误是附件不随更换与另有确认除外被拆到两个块，使绝对不含或全部包含都看似有出处；另一种失败是把符合条件概括成已经符合。排查应核括注完整性、原块主语和条件页指向，区分例外拆离与事实补写。索引含整套更换仍应回到原文限定，不由入口用语扩大服务。条款存在不代表已执行换机，缺实际处理记录时要保留边界。

## 怎么确认配好了

验收用主机、附件、另有确认三个原词加整套问题检索，对照返回块是否带完整括注和前置条件。回答应列明当前范围与缺少的确认材料，不代判资格。取得条件页后核它的适用条款及处理、索引状态，再用同题复测。上传成功不证明答案已经采用新页；若仍只回旧主句，应保留原块与引用，定位条件是否未进范围或回答漏用。
