# 仓内拣货复核打包的合同与交易材料比对：知识库检索与召回

## 这个品类的数据长什么样

仓内拣货复核打包处理订单出库，与供应商到货上架属于不同作业段。本页面对的材料是波次拣货单、复核记录、面单、包装耗材单，以及围绕这些材料做合同与交易比对时所需的检索对象。数据按每单、小时更新，因此检索库中的材料版本会随作业推进而变化，比对时必须锁定同一订单、同一作业阶段。

这些材料的主体是订单与包裹，对象是商品、数量、面单号、耗材规格，状态包括已拣、已复核、已打包。知识库检索与召回在此的作用，是把待核对的材料片段找出来交给比对环节，检索本身不判断授权，也不完成审批或写入。

## 这些特征在「知识库检索与召回」这一环带来什么约束

检索以库为最小搜索单位，集合仅作分类管理，与搜索效果无关。知识库搜索节点可关联一个或多个使用相同向量模型的库；跨不同向量模型的库不可共同关联，应先核对向量模型标识，排除不符合者，并记录实际观察，不执行跨模型检索来比较漏召回。引用内容以数组输出，长度可以为 0，即使没有搜索到内容，输出链路也会走通。

搜索模式按测试问题比较语义、全文与混合检索，不预设一种模式适合全部资料。混合检索通过 RRF 融合多路结果，RRF 是融合过程，不是可开启的开关。最低相关度是过滤阈值，仅在语义检索或使用结果重排时生效，它不承担权限或实体隔离，也不按业务类别排除无关记录。引用上限以 token 为单位，用长短不同的实际资料测试内容是否完整。问题优化用于指代消除和问题扩展，需比较原问题与优化后问题，核对主体是否被改错。图片检索须有相应图像输入及模型能力，重排须具备模型且按设置启用，文档列出的可选路径不代表每次请求全部执行。

假设演练样本

供核对的材料原文（纸面样本，非真实记录）：

“波次单 W-0715-A，订单 O-2281，商品 SKU-9，应拣 12 件；复核记录 R-0715-03 记载实复核 12 件，状态：已复核；面单 SF-0001 对应订单 O-2281，状态：已打印。”

待判定的拟稿句：“订单 O-2281 已完成打包并交接承运商。”

该拟稿句中的打包完成与交接承运商，在样本原文中没有对应字段，属于未获支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 关联一个向量模型标识相同的库 | 先核对向量模型标识，排除不同模型的库，再观察召回内容是否来自目标范围 |
| 搜索模式 | 先用全文检索 | 样本含波次单号、订单号、面单号等精确标识，比较语义检索与全文检索对编号的命中差异 |
| 引用上限 | 假设起点 800 token | 样本原文约 3 句，取该值以容纳完整段落；与 400 token 比较，观察复核状态字段是否被截断 |
| 最低相关度 | 假设起点 0.3 | 先标注样本中相关片段与无关片段，再与 0.5 比较，观察无关片段是否减少 |
| 问题优化 | 本次关闭 | 样本问题主体明确，比较开启与关闭时主体是否被改错及耗时变化 |
| 结果重排 | 本次不启用 | 样本候选较少，先观察不重排时的排序，具备模型且启用后再比较得分变化 |

## 容易做错的三处

1. 把检索命中当作授权或审批完成。样本中复核记录状态为已复核，检索到该记录只说明材料存在，不能推出打包完成或交接承运商已执行。检查时输入样本原文与拟稿句，比较拟稿句每个断言是否有同主体、同期间、同字段的原文支持，只有原文明确记载对应状态才满足条件。
2. 用最低相关度排除无关业务或越权记录。最低相关度是过滤阈值，不承担实体或权限隔离。检查时输入样本原文与一条无关片段，比较阈值调整后无关片段是否因相关度低被过滤，若期望的是权限隔离，则条件不满足，应记录为需另接系统实现。
3. 把不同向量模型的库共同关联。检查时输入两个库的向量模型标识，比较标识是否一致，标识不一致时排除该库并记录观察，不推断共同关联后的运行结果。

## 怎么确认配好了

1. 编号类检索验证。输入拟稿句中的“订单 O-2281”与样本原文，使用全文检索，比较返回内容是否包含该订单号及对应面单号 SF-0001；返回内容含这两个标识且未混入其他订单号，视为满足。若返回为空，记录空结果并核对数据是否已完成训练。
2. 状态字段完整性验证。输入样本原文与引用上限 800 token，比较返回内容是否完整包含“状态：已复核”与“状态：已打印”；两个状态字段均出现，视为满足。若字段被截断，记录截断位置并与 400 token 的结果比较。
3. 未获支持断言验证。输入拟稿句与样本原文，比较“已完成打包”“交接承运商”是否有同主体、同期间、同字段的原文记载；原文未载明时，判定为未获支持，保留证据缺口，不判定为否定或冲突。可用纸面输入空数组核对下游对空引用的承接设计，不声称虚构规则检索一定返回空数组。
