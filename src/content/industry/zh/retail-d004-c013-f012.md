# 便利店加盟门店督导的合同与交易材料比对：文档解析与分块

## 这个品类的数据长什么样

在便利店加盟门店督导的合同与交易材料比对中，本页说明FastGPT的文档解析与分块如何衔接资料。陈列清单的范围与门店观察记录不能在标题下混并。所用场景为自拟文字测试。

## 这些特征在「文档解析与分块」这一环带来什么约束

便利店督导约定自拟清单标题“本期须陈列品项”，条目下附“后仓备货不计入陈列”，巡店记录另写“后仓见饮料箱”。问是否完成陈列要求时，解析应保留清单身份和不计入条件，不能把后仓观察接入已陈列清单。巡店所见能说明观察地点，尚不能证明端架或货架陈列；实际清单条目本组未列，不宜自行补出本期应摆哪些商品。

## 配置怎么定

| 原文或分块核对项 | 具体材料关系 | 取证动作 |
| --- | --- | --- |
| 要求身份 | 本期须陈列清单 | 核清单与观察分开。 |
| 地点限制 | 后仓不计入陈列 | 核限制随范围保留。 |
| 巡店对象 | 仅观察到后仓箱件 | 不转成已陈列。 |
| 成员缺项 | 本组无实际条目 | 不从饮料词推成员。 |
| 两源更新 | 清单与巡店各自版本 | 核处理和返回来源身份。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `原始资料核对` | 对照原文件与解析输出。 |
| `分段完整性` | 条件需与其主体保持可关联。 |
| `数据与索引` | 原数据与索引分别保留依据。 |
| `样本检索` | 用原文词句及自然问题复测。 |
| `更新后复核` | 更新后核训练或索引状态。 |

## 容易做错的三处

一种失败是分块将后仓备货不计入从清单标题拆开，使后仓箱件被算作陈列；另一处风险是巡店记录与约定清单被解析成同一来源，观察内容变成要求。应核文档身份、标题归属与实际块中的地点限制，区分条件丢失和来源混并。索引命中饮料也不能确认清单成员或现场达标，需回到原文能支持的对象，不能据共同词语直接计算完成度。

## 怎么确认配好了

验收分别查询本期清单、后仓备货和“后仓看到箱件是否算完成陈列”，核引用保留不计入与观察身份。回答应说明后仓观察不填补陈列证据缺口，且本组仍缺实际条目与陈列记录。补清单或巡店新版后，核实际处理与索引状态并复测同题。上传成功不能代替现场事实核查，也不能证明旧来源混并已修复；保留原文与返回块对照再确认。
