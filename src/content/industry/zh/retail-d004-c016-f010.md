# 加盟商培训与开业辅导的合同与交易材料比对：引用来源与溯源

## 这个品类的数据长什么样

在加盟商培训与开业辅导的合同与交易材料比对中，本页说明FastGPT的引用来源与溯源如何衔接资料。培训签到、考核意见和开业协助确认按事件与责任范围核引用。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

加盟开业材料可拟辅导约定“陈列培训另行安排”、签到表“参加商品介绍”和辅导留言“开业陈列可再沟通”。另带一份旧店考核表，内容是设备操作。问本店是否已完成陈列培训及开业确认时，应区别介绍活动、待安排课程和后续沟通。签到证明某场活动的参与文字，不自动证明另一课程通过；旧店考核的门店和内容都不同，不能补本店缺少的培训与开业记录。

## 配置怎么定

| 交易来源核对项 | 材料与行动范围 | 验收动作 |
| --- | --- | --- |
| 活动身份 | 商品介绍签到 | 不移作陈列考核。 |
| 课程结果 | 参加不等通过 | 核真实评估内容。 |
| 协助行动 | 可再沟通 | 另找本店安排。 |
| 旧店记录 | 设备考核 | 核店别及对象。 |
| 开业确认 | 未给完整依据 | 保留待核项目。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是商品介绍签到被写成陈列考核通过，应核活动名称、课程内容及真实考核结果，参与和通过需要各自证据。第二处是可再沟通被称为已承诺现场协助，应读留言具体动作与适用事项，另查本店协助安排。第三处是旧店设备考核被移用成本店开业确认，应对门店、考核对象及版本。三项分别核活动结果、服务行动和来源归属，不靠同一加盟品牌连接成完成链。

## 怎么确认配好了

验收分别问当前参加了哪场介绍、陈列培训如何安排、开业相关事项确认到哪一步，展开答案实际引用。只有签到表时，保留课程与考核记录待补，不推学员未通过或培训被取消。后续补入安排需核本店及课程，结果页也只支持其实际评估内容。空引用应查知识范围与传递；文字对照不执行培训或开业审批，也不从一份记录宣称门店已具备全部开业条件。
