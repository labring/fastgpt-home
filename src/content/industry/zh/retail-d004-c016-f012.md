# 加盟商培训与开业辅导的合同与交易材料比对：文档解析与分块

## 这个品类的数据长什么样

加盟商培训与开业辅导的文档来自培训系统、督导APP、门店照片与总部SOP库，日常材料包括培训签到表、开业检查表、SOP手册与考核成绩。这一品类与特许备案管理的差别在于，开业辅导是经营能力移交，涉及培训完成、物料到位、动作纠正等事实状态，材料比对需要能回指原文的文档身份与版本。合同与交易材料比对任务要求把签到表、检查表、SOP手册与考核成绩中的主体、对象、状态与有效范围逐项对齐，培训签到表记录人员与日期，开业检查表记录门店与检查项，SOP手册给出动作规范，考核成绩记录人员与分数。这些材料按每店、每月更新，更新后需核对实际训练与索引状态，上传成功不能直接当作检索已更新。

## 这些特征在「文档解析与分块」这一环带来什么约束

分块需按具体资料结构检查段落完整性，避免条件、说明与所约束的内容被拆离。同一组原数据可对应多个索引，检索时先召回向量，再根据向量 ID 去 MongoDB 中寻找原数据内容，对应同一组原数据则合并，向量得分取最高得分。语义检索依赖向量距离，全文检索依赖关键词命中，编号、型号、专有名词适合全文或混合检索。最低相关度是过滤阈值，仅在语义检索或使用结果重排时生效，不负责权限或实体隔离。检索库同向量模型要求不能扩展为外部系统也要同模型。RRF 是混合结果融合过程，不是开启开关。

假设演练样本：材料原文为「2025年3月1日至3月5日，加盟商甲门店店长乙参加收银与库存培训，签到表记录乙于3月1日、3月2日、3月3日签到，考核成绩记录乙得82分。开业检查表记录甲门店3月5日检查收银台物料到位，检查人丙签字。」待判定拟稿句为「乙已完成全部培训并具备开业条件。」判定需同主体、同期间、同一字段：签到表记录3天签到，考核成绩记录82分，检查表记录物料到位，均未载明「全部培训完成」或「具备开业条件」的授权结论，该拟稿句属于未获支持，需保留证据缺口。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 搜索模式 | 混合检索 | 材料含编号与自然语言，需同时用语义召回与全文召回，比较两种模式下同一问题的候选内容差异 |
| 最低相关度 | 假设起点 0.3 | 该值为本次试验起点，因材料含签到日期等精确字段，与 0.5 比较观察过滤后候选数量变化 |
| 引用上限 | 假设起点 2000 tokens | 该值为本次试验起点，因单份检查表与签到表内容较短，与 4000 tokens 比较观察引用内容覆盖范围 |
| 问题优化 | 开启 | 连续追问场景下补全指代，比较开启与关闭时同一追问的召回内容差异 |
| 结果重排 | 启用 | 候选结果较多时二次排序，比较启用与关闭时同一问题的排序位置变化 |
| 分段完整性核对 | 按材料结构逐段核对 | 检查条件、说明与所约束内容是否被拆离，比较分段前后同一材料的召回内容 |

## 容易做错的三处

1. 把上传成功当作检索已更新。输入为某份SOP手册上传操作记录，比较对象为实际训练与索引状态，观察结果为检索该手册新条款时是否返回更新后内容，未核对训练状态时不能判定检索已更新。
2. 把最低相关度当作权限过滤。输入为某加盟商账号的检索请求，比较对象为最低相关度设置与返回内容，观察结果为无关业务记录是否被相似度阈值排除，该设置不负责实体隔离，不能据此判定权限已生效。
3. 把待审核请求当作已批准执行。输入为某门店提交的开业物料补充请求，比较对象为请求状态与批准记录，观察结果为是否存在签署或批准字段，待审核不证明缺少操作权限，也不等于已执行。

## 怎么确认配好了

1. 用假设样本原文检索「乙 培训 签到 3月1日」，输入为签到表原文，比较对象为返回内容是否包含乙、3月1日与签到字段，观察结果为返回内容能回指原文且未出现「全部培训完成」结论，若返回内容缺失主体或日期则记录缺口。
2. 用假设样本拟稿句核对「乙已完成全部培训并具备开业条件」，输入为拟稿句与签到表、考核成绩、检查表原文，比较对象为原文是否载明全部培训完成与开业条件授权，观察结果为原文仅有3天签到、82分与物料到位记录，判定该拟稿句未获支持。
3. 用假设样本检查表检索「甲门店 收银台 物料 3月5日」，输入为检查表原文，比较对象为返回内容是否包含甲门店、收银台、物料与3月5日字段，观察结果为返回内容能回指检查表且未出现签署生效结论，若返回内容为空则以纸面输入[]核对下游设计，记录实际观察结果。
