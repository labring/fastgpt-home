# 加盟商培训与开业辅导的合同与交易材料比对：权限与数据隔离

## 这个品类的数据长什么样

在加盟商培训与开业辅导的合同与交易材料比对中，本页说明FastGPT的权限与数据隔离如何衔接资料。按培训、现场检查与整改依据分配读取，核总部、督导和门店的实际资源范围。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

合同比对练习可拟培训安排附页、门店检查清单和整改说明，分别记录总部、督导和店长要回答的问题。先查真实账号及允许操作，再决定各材料是否可放入同一次阅读。总部SOP、门店照片和签到表可能分别维护，具有督导职责不说明全部原文已开放。资料看起来属于同一家店，也须核日期和版本；签名、照片存在或条款文字相符，不能直接提供现场执行或履约结论。

## 配置怎么定

| 督导比对权限 | 训练及现场来源 | 核对证据 |
| --- | --- | --- |
| 职责映射 | 总部督导店长的问题 | 账号资源及操作 |
| 版本关系 | 培训附页与适用SOP | 实际日期和原句 |
| 门店限制 | 他店照片和内部规则 | 完整返回与拒绝 |
| 外部系统 | 培训登录另核内部读取 | 身份与权限分开 |
| 执行范围 | 签到不代检查整改 | 真实记录及责任判断 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 督导称谓被当全店资料维护角色：核账号、具体资源和操作，缺成员对应交责任人确认，岗位安排不自动创建权限。

- 某店身份读出另一店检查照片或总部内部规则：保存照片来源说明与完整返回查授权，同品牌不说明资源可跨店共享。

- 培训系统可登录被当SOP和检查资料均可读且整改完成：外部身份、内部权限及真实整改证据分别核，签到不替代执行。

## 怎么确认配好了

验收对培训附页、检查原文和整改依据列允许与禁止身份，测试同一来源的读取和拒绝，并记录实际版本。若权限正确但答复引用旧SOP，查本轮输入及材料日期，不扩大账号范围。现场材料尚未取得与已取得未传入分开列缺口，补后重复同题。读取和比对不安排培训、不提交整改，也不确认门店已达标；相应执行要有真实业务记录及责任人判断。
