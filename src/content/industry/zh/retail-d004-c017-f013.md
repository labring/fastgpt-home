# 加盟费与保证金结算的合同与交易材料比对：权限与数据隔离

## 这个品类的数据长什么样

在加盟费与保证金结算的合同与交易材料比对中，本页说明FastGPT的权限与数据隔离如何衔接资料。核加盟付款计划、开票说明和到账资料的读取权限，不把财务文字变成资金或违约判断。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

比对练习可拟加盟合同付款安排、开票说明和本店到账备注，不写金额或真实凭证。运营拟看约定阶段，财务拟查本次收付依据，门店拟核自身资料；先把任务对应到实际账号和允许操作。付款计划、发票和银行来源可能分开管理，任职财务不自动开放全部加盟店。文字显示“已开票”与“待收款”可同时成立，能读取这些说明也不证明履约、欠款责任或双方已认可结算。

## 配置怎么定

| 加盟财务比对权限 | 来源性质 | 核对对象 |
| --- | --- | --- |
| 任务对应 | 运营财务门店各看事项 | 真实账号及操作 |
| 阶段差异 | 计划开票到账分别核 | 原文及本次记录 |
| 他店限制 | 回款和违规记录不混用 | 完整回答及拒绝 |
| 期间范围 | 旧安排不替本期依据 | 输入版本和日期 |
| 处理责任 | 读取不收款或判违约 | 执行资料及确认 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 加盟联系人被当团队成员及全部财务维护权：核真实账号、门店和资源操作，责任人确认必要范围，不由合同签名生成权限。

- 本店比对返回他店回款或内部违规记录：保留具体来源和完整回答查授权，同加盟体系不说明跨店共享，转述也须核。

- 财务接口正常被当内部凭据均可读或款项已到：外部鉴权、资源访问和本次资金记录分别核，发票或计划不替代到账依据。

## 怎么确认配好了

验收让运营、财务、本店及无关门店身份查询同一合同和限制凭据，记录实际原句、可用操作与拒绝。若授权正确而拿旧付款计划答本期问题，查输入、期间和版本，不扩大权限。已取得未传入的凭据与尚无到账记录分别列缺口，补后按原范围复问。访问不收付款、不开票或认定违约；账务处理和责任判断需相应执行资料及责任人确认。
