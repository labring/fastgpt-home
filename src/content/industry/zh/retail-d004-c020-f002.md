# 原产地证书申办的合同与交易材料比对：上下文与 token

## 这个品类的数据长什么样

在原产地证书申办的合同与交易材料比对中，本页说明FastGPT的上下文与 token如何衔接资料。原产资料中的工序陈述、未核来源和版本提示需完整承接。所用场景为自拟文字测试。

## 这些特征在「上下文与 token」这一环带来什么约束

原产地文字比对可拟生产页“在山湾厂装配，原料信息另核”、申请草稿“来源说明待补”和版本便签“旧页仅供参考”。本轮问当前能支持哪些生产事实。输入需保留装配的工序范围及原料待核，不能缩成全部由该厂生产。历史如曾讨论另一商品的原料，也不能带进本次支架。这里不设原产判定规则，材料只能支持其陈述及缺项，不因资料进入模型上下文就变成已核证明。

## 配置怎么定

| 上下文材料核对 | 输入与表达条件 | 验收动作 |
| --- | --- | --- |
| 工序范围 | 装配自述 | 不扩全生产链。 |
| 后半条件 | 原料另核 | 核实际保留。 |
| 版本地位 | 旧页仅参考 | 不替当前。 |
| 商品指代 | 历史别品 | 同题空历史核输入。 |
| 输出层级 | 陈述与证明分开 | 保留归属及待核。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `模型上下文` | 以实际模型可接收范围为准。 |
| `回复长度` | 回复上限不同于上下文窗口。 |
| `知识库引用上限` | 知识引用上限按token计。 |
| `历史输入核对` | 比较空历史与带历史的输入。 |
| `结构化承接` | 先验解析，再核字段事实依据。 |

## 容易做错的三处

第一处是原料另核被裁掉后称生产链完整，应对生产原句与实际请求，核工序和缺项是否均在。第二处是旧参考页或历史别品原料覆盖当前，应核版本、商品及对话指代，用空历史同题对照输入。第三处是答复只写已确认产地而省略陈述来源，应核输出证据层级与回复长度，保留装配自述及待补状态。三项分别查范围送达、资料迁移和结论强度，增加预算也不能替代原资料取证。

## 怎么确认配好了

验收分别问生产页声称哪道工序、什么仍待补、哪页仅作参考，逐句核实际输入与回答。知识引用按token截取时，需要查看是否保留后半句的原料条件，不只检查文件名。模型窗口按实际能力核，回复上限只控制可表达空间。补入新资料后仍对商品、主体和版本，不借同厂别品条件填缺。本练习不判断原产资格、不签发或申办证书，也不证明实际生产来源已被确认。
