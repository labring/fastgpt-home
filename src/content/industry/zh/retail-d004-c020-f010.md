# 原产地证书申办的合同与交易材料比对：引用来源与溯源

## 这个品类的数据长什么样

在原产地证书申办的合同与交易材料比对中，本页说明FastGPT的引用来源与溯源如何衔接资料。申办资料里的生产声明、发运地点和证书草稿按证据性质回指。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

原产地资料可拟供稿说明“在青河厂完成组装”、运输页“由南港发出”和证书草稿“生产信息待核”。商品表只写金属支架，未列生产环节材料。问是否可据发运地确认生产来源并称证书已签发时，要将厂方陈述、物流地点和草稿阶段分开。运输页说明从哪里发出，不直接说明全部生产过程；供稿陈述也不等于已取得证明。引用能呈现这些说法及缺项，不能自行补原产规则或认证结论。

## 配置怎么定

| 交易来源核对项 | 材料与行动范围 | 验收动作 |
| --- | --- | --- |
| 生产陈述 | 青河厂组装 | 核陈述者及依据。 |
| 发运地点 | 南港 | 不当生产地证明。 |
| 商品对应 | 本批金属支架 | 核新增证明对象。 |
| 草稿阶段 | 生产待核 | 保留未确认状态。 |
| 签发结果 | 实际记录未给 | 不由草稿推出。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是南港发运被写成在那里生产，应对运输事件与生产声明对象，另核生产资料，不将地名相同或接近当证据。第二处是组装自述被写成生产来源已经证实，应定位陈述者及实际支撑材料，保留未核环节，不由复述流畅补成证明。第三处是证书草稿被称已签发，应核文件阶段及真实签发记录，待核字样不说明已获确认。三项分别查地点语义、证据类型和文书状态。

## 怎么确认配好了

验收分别问运输页说明哪个行动、供稿者声称哪项生产活动、草稿记录何种进度，逐句核实际引用与身份。如果只收到运输页，保留生产依据与证书状态未核，不能反推声明虚假或申办已被拒。后来补入生产或签发材料，核商品、主体和对应版本，不借他批证明。本次是自拟文字核对，不判断原产资格、不提交申办，也不把文件可读或草稿齐全写成证书已取得。
