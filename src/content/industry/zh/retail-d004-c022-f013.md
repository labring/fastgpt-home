# 品牌全渠道库存调拨的合同与交易材料比对：权限与数据隔离

## 这个品类的数据长什么样

在品牌全渠道库存调拨的合同与交易材料比对中，本页说明FastGPT的权限与数据隔离如何衔接资料。按调出、调入及仓配任务核库存资料权限，资源可读不意味着货物可移动或已接收。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

比对可拟调拨申请、库存快照和收货说明，调出门店看自身来源，调入门店看本次需求，仓配人员核实际移动依据。先确认账号对资源的具体读取和操作，门店地点文字不自动成为团队成员关系。库存快照描述某时点，调拨申请描述拟议动作，收货说明描述另一阶段；三者编号相同也须核原文关系。能够同时读两店库存，不说明有跨店修改资格或真实货物已能调出。

## 配置怎么定

| 全渠道调拨权限 | 不同资料职责 | 实际核法 |
| --- | --- | --- |
| 角色映射 | 调出调入和仓配 | 账号及资源操作 |
| 原文关系 | 申请快照收货阶段分开 | 地点与编号原句 |
| 限制仓库 | 无关库存及内部备注 | 完整回答和拒绝 |
| 接口区别 | WMS鉴权不代内部许可 | 实际访问及移动记录 |
| 账货执行 | 读取不创建调拨或改库存 | 业务记录及确认 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 调拨联系人或地点名被当可维护全渠道库存的角色：核真实账号与操作，调出调入职责不自动授予资源权限。

- 本次申请读出无关仓库库存或其他调拨内部备注：保留地点身份和完整回答查授权，同商品不说明跨仓开放，转述范围也核。

- WMS接口通了被当内部原文获权或调拨已落账：外部鉴权、资源访问和实际移动记录分别核，快照余额不作本次发生量。

## 怎么确认配好了

验收分别用调出、调入、仓配和无关仓库身份查询相同来源，记录原句、地点角色及拒绝。若授权正确却将调出当调入，查输入映射和实际原文，不扩大访问范围。来源尚无本次收货与已有收货未进入请求分别列缺口，补后按原账号复测。资料读取不创建调拨、扣减或增加库存；货物流转与账务处理仍需实际业务记录和责任确认，不由汇总可读推出全部仓库已同步。
