# 品牌商场专柜运营的合同与交易材料比对：权限与数据隔离

## 这个品类的数据长什么样

在品牌商场专柜运营的合同与交易材料比对中，本页说明FastGPT的权限与数据隔离如何衔接资料。把商场合同、活动函与月结资料分开授权，核专柜、品牌和商场各自可读来源。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

比对可拟联营合同片段、商场活动函、销售小票说明和月结编制稿，不写费用数值。品牌核约定范围，专柜核本柜记录，商场协作核其被允许材料；先确认真实账号及操作，商场人员姓名不自动成为品牌团队成员。统一收银资料与品牌内部记录可能更新不同步，活动函也不说明本柜已经执行。原文差异只形成待查点，不能从访问成功认定扣费依据成立、账实已平或任何一方违约。

## 配置怎么定

| 专柜比对权限 | 商场品牌来源 | 实际证据 |
| --- | --- | --- |
| 成员范围 | 品牌专柜及商场协作 | 真实账号和操作 |
| 期间对象 | 合同活动小票月结分开 | 本柜原句和日期 |
| 限制柜台 | 其他销售与内部费用意见 | 完整返回及拒绝 |
| 收银区别 | 商场POS不代品牌权限 | 鉴权及资源读取 |
| 结算确认 | 月结稿不说明双方认可 | 本期记录及确认 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 专柜店长或商场联系人被当品牌全部合同维护成员：核实际账号、本柜对应与允许操作，职责不授予团队角色，缺映射由责任人确认。

- 本柜比对返回其他专柜销售或品牌内部费用意见：保留柜台身份和完整返回查授权，同一商场不说明跨柜开放，概括内容也核。

- 商场POS鉴权成功被当品牌月结原文可读或双方已认可：外部权限、内部资源及本期真实确认分别核，编制稿不代正式结算依据。

## 怎么确认配好了

验收用品牌、专柜、商场协作及无关柜台身份查询同一组来源，留原句、允许操作与拒绝。若授权正确却读另一期间小票，查输入及来源归属，不扩大财务资源。实际月结确认尚未取得与已取得未进入本轮分开，补后按原范围复问。比对不参加活动、调整费用或结账；实际处理需适用约定、业务记录和责任确认，不能把商场收银可见当作品牌账务已经同步完成。
