# 品牌直营门店运营的合同与交易材料比对：权限与数据隔离

## 这个品类的数据长什么样

在品牌直营门店运营的合同与交易材料比对中，本页说明FastGPT的权限与数据隔离如何衔接资料。按直营店销售、排班与陈列资料核权限，品牌雇佣关系不自动开放全部门店来源。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

比对练习可拟排班附页、陈列照片说明和销售汇总文字，让店长核本店安排，区域经理核获准门店，总部人员核内部适用规则。先列真实账号及允许操作，品牌直接雇佣不说明全部门店资料可互看，也不由岗位名自动配置角色。排班、照片和销售材料更新节奏不同；照片标题属于某店不表示已经核到现场，计划上岗不说明实际出勤，来源可读不能合成门店绩效或履约判断。

## 配置怎么定

| 直营店比对权限 | 资料与职责 | 核对对象 |
| --- | --- | --- |
| 成员范围 | 店长区域与总部任务 | 账号门店及操作 |
| 更新差异 | 排班照片销售分开 | 实际来源及日期 |
| 他店限制 | 人员安排和绩效意见 | 完整回答与拒绝 |
| 系统区别 | POS CRM与内部资料 | 身份和读取分别验 |
| 执行依据 | 计划照片不代现场出勤 | 本班记录及确认 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 区域经理姓名被当所有店铺资料维护成员：核实际账号、门店范围和操作，职责与团队授权分开，缺映射由责任人确认。

- 本店比对读出他店员工安排或内部绩效意见：保留来源身份与完整回答查权限，同品牌直属不提供跨店公开依据。

- POS或CRM登录正常被当内部照片资料已获权且人员到岗：外部身份、资源读取和本班实际出勤分别核，排班不作执行记录。

## 怎么确认配好了

验收让店长、区域、总部与无关门店身份查同一限制来源，记录原句、账号操作及拒绝。若权限正确却取另一店陈列，查实际来源和输入映射，不扩大照片库范围。现场说明未取得与已有未传入分别列缺，补后按原权限复问。比对不改排班、记考勤或调整绩效；真实销售、出勤和现场情况须对应业务记录及责任人确认，不能从原文可见推出店务已经执行。
