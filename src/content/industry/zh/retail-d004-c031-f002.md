# 商超塑料袋与一次性用品报告的合同与交易材料比对：上下文与 token

## 这个品类的数据长什么样

在商超塑料袋与一次性用品报告的合同与交易材料比对中，本页说明FastGPT的上下文与 token如何衔接资料。用品报告中的材料类别、采购与使用及报告期间需要保持分列。所用场景为自拟文字测试。

## 这些特征在「上下文与 token」这一环带来什么约束

用品报告比对可拟采购页“塑料袋与纸袋分别登记”、门店记录“纸袋用于展示”和报告草稿“本期使用资料待补”。历史另有上一期塑料袋采购汇总。当前问是否已核清本期塑料袋实际使用。输入需保留材料类别、采购与使用两个动作及本期身份，不能从总表中有袋字就统一为塑料使用，也不能拿展示纸袋推当前消耗。这里不设真实报告规则、申报要求或处罚数字，仅核普通文字材料之间的范围。

## 配置怎么定

| 上下文材料核对 | 输入与表达条件 | 验收动作 |
| --- | --- | --- |
| 材料类别 | 纸与塑料分开 | 核压缩输入。 |
| 行动区别 | 采购与使用 | 不接同一状态。 |
| 报告期间 | 上期非本期 | 核历史指代。 |
| 草稿缺项 | 使用资料待补 | 输出不可省。 |
| 实际完成 | 没有统计或提交 | 不宣称已完成报告。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `模型上下文` | 以实际模型可接收范围为准。 |
| `回复长度` | 回复上限不同于上下文窗口。 |
| `知识库引用上限` | 知识引用上限按token计。 |
| `历史输入核对` | 比较空历史与带历史的输入。 |
| `结构化承接` | 先验解析，再核字段事实依据。 |

## 容易做错的三处

第一处是纸袋与塑料袋在压缩输入中被合成袋，应对采购分类与实际请求，恢复材料类别。第二处是上一期采购沿历史指代变成本期使用，应核期间、动作及原对话，比较空历史同题输入。第三处是答复只给已核清却漏报告待补，应查结论覆盖与回复长度，说明本期使用来源仍缺。三项分别查分类、期间行动和缺项表达，不以更大窗口完成未发生的统计或取证。

## 怎么确认配好了

验收分别问哪类材料、发生何种动作、属于哪个期间，逐句核实际输入与输出。引用token预算要保留分类和待补状态，不用文件条数当完整统计。模型窗口及回复长度各按实际能力核验；当前使用记录没有给，调整预算也不能补真实消耗。新增自拟记录需核本期及类别并保留练习身份。本页不计算实际使用量、不提交报告或作合规判断，也不把采购汇总写成真实报告已完成。
