# 商超收银与会员促销的合同与交易材料比对：上下文与 token

## 这个品类的数据长什么样

商超收银与会员促销场景中，合同与交易材料比对依赖四类文档：促销价签、会员积分规则、收银日报、异常退款单。这些材料来自 POS 系统、会员 CRM、支付平台和价签系统，更新频率为日或每班。收银主管、CRM 运营和财务稽核需要在同一比对任务中核对这些材料，确认促销价格、积分权益与退款记录之间是否一致。材料中的主体、对象、状态和有效范围是判断基础。促销价签载明适用门店与生效时段，会员积分规则载明积分计算方式与适用会员等级，收银日报载明当班交易汇总，异常退款单载明退款原因与授权状态。这些字段分散在不同文档中，比对时需要逐项确认同一主体、同一期间、同一字段的取值关系。

## 这些特征在「上下文与 token」这一环带来什么约束

上下文与 token 在本任务中涉及模型可参考的内容长度、知识库引用上限、历史输入范围和结构化输出承接。模型最大上下文按实际模型能力核对，回复上限控制单次回答长度，两者不是同一概念。知识库引用上限以 token 为单位，每次搜索最多引用 n 个 tokens 的内容，单段材料较长时可能被裁剪，需要结合问题样本核对实际引用内容。历史输入影响连续对话中的检索行为，相同问题在空历史和带历史下可能产生不同输入。结构化输出需要验证字段齐全和解析成功。

假设演练样本：某门店促销价签原文载明“2025年6月1日至6月30日，A类会员购买指定食用油享8折，每卡限购2桶”。会员积分规则原文载明“A类会员消费积分按实付金额1元积1分，促销商品不参与积分”。收银日报原文载明“6月15日当班，A类会员张某购买指定食用油2桶，实付金额96元，积分增加0元”。异常退款单原文载明“6月15日，张某申请退款1桶食用油，退款金额24元，退款原因：重复购买，授权状态：待审核”。待判定拟稿句：“张某6月15日购买食用油获得积分96分，退款后积分已扣减。”该拟稿句与积分规则原文“促销商品不参与积分”及收银日报“积分增加0元”不一致，退款单授权状态为待审核，不能视为已完成退款或积分扣减。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| AI 模型 | 选择支持所需上下文长度的模型 | 按实际模型显示的最大上下文与材料总长度比较，确认能否容纳价签、积分规则、日报和退款单全文 |
| 回复上限 | 设为足以输出比对结论的长度 | 与拟稿句所需依据字段数量比较，确认回复不被截断 |
| 知识库引用上限 | 按 token 设为覆盖四份材料关键段落的数值 | 与单段材料长度和问题样本比较，观察引用内容是否被裁剪 |
| 最低相关度 | 按语义检索或重排生效条件设置 | 该值为过滤阈值，不承担权限或实体隔离功能 |
| 回复格式 | 需要固定字段时选择 json_schema | 验证比对结论字段齐全和解析成功 |
| 思考强度 | 按问题复杂度选择档位 | 思考预算用于模型思考过程，不用于引用 token 上限 |

## 容易做错的三处

1. 将回复上限当作完整上下文窗口。回复上限控制单次回答长度，最大上下文控制单次请求可参考的内容长度，两者不同。检查方法：输入四份材料全文，比较模型实际可参考内容与回复上限数值，观察回复是否因上限被截断。
2. 将最低相关度当作权限或实体过滤。最低相关度是过滤阈值，仅在语义检索或结果重排时生效，不排除无关业务或未授权记录。检查方法：输入含无关门店的查询，观察返回结果是否仅因相关度低被过滤，确认无权限过滤逻辑。
3. 将待审核退款单视为已完成退款。退款单授权状态为待审核，不能推断退款已执行或积分已扣减。检查方法：输入退款单原文与拟稿句，比较授权状态字段与拟稿句表述，观察拟稿句是否将待审核写为已完成。

## 怎么确认配好了

1. 输入假设样本中的四份材料原文和待判定拟稿句，比较拟稿句“获得积分96分”与积分规则“促销商品不参与积分”及收银日报“积分增加0元”，观察比对结论是否指出该句与原文不一致。预期结果为拟稿句不获支持。
2. 输入假设样本中的退款单原文，比较授权状态“待审核”与拟稿句“退款后积分已扣减”，观察比对结论是否将待审核保留为待核实状态。预期结果为退款执行与积分扣减均未获支持。
3. 输入空历史与带历史两种条件下的相同问题，比较检索输入是否因历史轮数不同而变化，观察引用内容是否出现差异。预期结果为历史输入影响检索范围，需按实际引用内容核对，不保证首条命中或全部召回。
