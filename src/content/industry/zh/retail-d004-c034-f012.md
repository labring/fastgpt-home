# 外贸出口退税申报的合同与交易材料比对：文档解析与分块

## 这个品类的数据长什么样

外贸出口退税申报在货物出口后做税务凭证匹配，主要数据来源为电子税务局、出口退税申报系统、海关电子信息与财务账，日常文档包括出口退免税申报表、出口报关单、进货发票与收汇凭证。本页任务为合同与交易材料比对，落到文档解析与分块这一环，需要把上述资料拆成可回指原文的段落，再按主体、对象、期间、字段逐项对照。退税延迟、不得退税与税务风险是出错的后果，因此分段必须保留条件与所约束内容之间的完整关系。数据更新频率为月、每批，本页仅在资料变更后核对实际训练与索引状态，不据此推出批量同步或交易触发机制。

## 这些特征在「文档解析与分块」这一环带来什么约束

分段完整性要求按具体资料结构检查段落，条件、说明与所约束的内容不可拆离。原数据与检索索引需要区分：同一组原数据可对应多个索引，`dataset.datas` 的 `indexes` 字段记录对应向量 ID。检索以库为最小搜索单位，集合仅作分类管理。语义检索依赖向量相似度，适合自然语言问法；全文检索依赖关键词命中，适合编号、型号、专有名词。混合检索经 `RRF` 融合多路结果，`ReRank` 对候选文本二次排序并给出 `0-1` 得分。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值。相似度与相关度不承担权限或实体隔离功能，检索本身不构成授权。

假设演练样本：资料原文为「甲方为境内某外贸企业，乙方为境外采购方，双方于假设日期2024年3月签订编号HT-2024-03的货物买卖合同，约定分两批交付，第一批数量为假设值1000件，结算币种为美元。甲方于假设日期2024年4月取得对应进货发票，发票载明数量1000件。出口报关单载明同一批货物数量1000件。」待判定拟稿句为「本合同项下第一批货物数量与进货发票、出口报关单数量一致，可用于本次退税申报比对。」该样本为纸面假设，未实际提交或测试。

## 配置怎么定

| 配置或核对项 | 本页相关取值或动作 | 与样本的对应关系 |
| --- | --- | --- |
| 搜索模式 | 语义检索、全文检索或混合检索 | 合同编号与数量字段宜用全文或混合检索定位 |
| 引用上限 | 每次搜索最多引用 n 个 tokens | 控制返回给模型的引用内容量，避免无关片段进入比对 |
| 最低相关度 | 0-1 数值，仅在语义检索或结果重排时生效 | 过滤低相关度结果，不承担主体或权限过滤 |
| 结果重排 | 具备 ReRank 模型并按设置启用时执行 | 对候选文本二次排序，得分 0-1 可用于过滤 |
| 问题优化 | 检索前做指代消除与问题扩展，增加一次模型调用 | 连续追问场景可开启，短问题与精确编号场景按实际效果决定 |
| 索引核对 | 区分原数据与索引，确认入库时已建立对应索引 | 资料变更后核对实际训练与索引状态，上传成功不等于检索已更新 |

## 容易做错的三处

1. 将相似度得分当作主体或权限过滤。输入为样本中合同、发票、报关单三份分段，比较对象为各自的主体与数量字段，若仅凭向量得分靠前就认定三份资料属于同一笔交易，缺少主体字段核对，判定不成立。
2. 把最低相关度当作实体隔离手段。输入为样本合同段落与一条无关资料段落，比较两者主体字段，若因相关度低于阈值就推断该无关资料不属于本企业业务，属于把过滤阈值误用为权限判断。
3. 把上传成功当作索引已更新。输入为样本资料变更后的上传动作，比较对象为实际训练状态与索引记录，若未见训练完成或索引生成的实际观察，检索是否覆盖新内容仍为未知。

## 怎么确认配好了

1. 分段完整性核对。输入为样本资料原文三句，比较对象为解析后各段落是否保留主体、对象、数量与期间；当每段均可回指原文对应句子且条件与约束内容未被拆离，满足条件。
2. 字段一致性核对。输入为样本拟稿句与三份资料分段，比较对象为同一字段的数量取值；当三份资料数量均为1000件且主体指向同一笔交易，拟稿句获支持；若某份资料未载明数量，该项为待核实，不判为矛盾。
3. 检索观察与失败分支。输入为合同编号HT-2024-03与自然语言问法各一次，比较对象为返回引用内容是否包含对应段落；预期为编号查询命中合同分段，若返回为空或仅含无关片段，记录该观察并检查分段与索引状态，不保证首条命中或全部召回。

空结果承接可用纸面输入 [] 核对下游设计，不声称虚构规则检索一定返回空数组。跨不同向量模型的库不可共同关联，先核标识并排除不符合者，不执行跨模型检索比较漏召回。待审核不证明缺少操作权限，签署、合作达成与合同生效是三个不同事实，样本未载明授权或生效条款，相关证据缺口保留。
