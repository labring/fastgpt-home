# 天猫旗舰店日常运营的合同与交易材料比对：上下文与 token

## 这个品类的数据长什么样

天猫旗舰店日常运营中，合同与交易材料比对的输入来自天猫商家后台、天猫规则中心、ERP订单表与客服聊天记录。日常文档包括商品发布页、品牌授权书、发货承诺记录与售后工单。品牌授权、旗舰店身份与天猫积分赔付规则使材料比对需要核对授权主体、承诺期间与赔付条件是否一致。资料给出日更与每单两种更新频率，本页不延伸出批量同步、实时触发或全量同步机制。

比对任务围绕同一主体、同一期间、同一字段展开。商品发布页中的发货承诺、品牌授权书的有效范围、售后工单中的处理请求，三者若字段口径不同，不能直接判定矛盾。上下文与 token 环节决定一次比对请求能带入多少材料原文、多少历史对话以及多少知识库引用内容，超出部分在请求前被裁剪。

## 这些特征在「上下文与 token」这一环带来什么约束

模型单次请求可参考的内容长度由最大上下文决定，回复上限只限制输出长度，两者不能混用。记忆轮数控制最多参考前面多少轮聊天，数值越大越容易带入更早对话，也增加消耗。知识库引用上限按 token 控制每次搜索最多引用的内容量，单段材料较长时可能被裁剪。开启问题优化会在正式检索前增加一次模型调用，连续追问的检索效果可能提升，整体耗时也会增加。

假设演练样本：某旗舰店运营人员拟核对一份品牌授权书与商品发布页的授权期间是否一致。授权书原文为：“授权方甲，授权对象乙旗舰店，授权期间2024年1月1日至2024年12月31日，授权范围限于本店商品发布与销售。”商品发布页原文为：“本店品牌授权有效期至2024年12月31日。”待判定拟稿句为：“该店2024年全年品牌授权持续有效，可继续发布商品。”比对请求为：“请判断发布页承诺与授权书是否一致，并说明依据。”该样本仅用于说明上下文与 token 的核对方法，不表示任何真实授权关系。

## 配置怎么定

下表围绕上述样本，列出与本功能、主任务相关的已说明设置或实施核对项。数值起点为本次假设试验起点，说明选择理由与比较对象，不表示官方默认值。

| 配置项 | 本次假设试验起点 | 核对方式与理由 |
| --- | --- | --- |
| AI 模型 | 选择支持所需上下文长度的模型 | 读取模型信息中的最大上下文，与样本材料与拟稿句合计长度比较，确认未被裁剪 |
| 记忆轮数 | 本次试验设为 2 轮 | 样本为单次比对，保留少量历史即可；与设为 0 轮时的输入内容比较，观察是否带入无关对话 |
| 回复上限 | 本次试验设为足以容纳依据与结论 | 打开回复上限并设置长度，与拟稿句所需说明长度比较，确认回复未被提前截断 |
| 知识库引用上限 | 本次试验设为覆盖授权书与发布页两段 | 按 token 控制引用，与两段材料合计长度比较，确认关键字段未被裁掉 |
| 最低相关度 | 本次试验保持默认并记录取值 | 该值仅在语义检索或结果重排时生效，与样本检索结果比较，观察是否过滤掉授权期间字段 |
| 回复格式 | 本次试验保持默认 | 样本只需文字结论，无需固定结构；若改为 json_schema，需另填格式要求并验证字段齐全 |

## 容易做错的三处

1. 把回复上限当作完整上下文窗口。回复上限只限制输出长度，最大上下文才决定单次请求可参考的内容长度。样本中两段材料加拟稿句若超过最大上下文，授权期间字段可能在请求前被裁剪，比对结论失去依据。
2. 把检索结果当作授权状态证明。知识库检索只返回引用内容，不核验授权书是否真实有效，也不判断发布页承诺是否获得授权。样本中检索到授权书原文，不能据此认定授权已生效或发布行为已获批准。
3. 把待审核请求当作已获授权。样本中的比对请求处于待判定状态，审核中不表示缺少操作权限，也不表示授权已获批准。签署、合作达成与合同生效是三个不同事实，样本未载明生效条款时，授权是否生效属于未获支持。

## 怎么确认配好了

1. 输入上述假设样本的授权书原文、发布页原文与拟稿句，比较模型实际接收的内容与两段原文是否一致。若授权期间字段完整出现在请求内容中，说明引用上限与最大上下文足以容纳该样本；若字段缺失，记录为裁剪，不判定为材料矛盾。
2. 输入同一样本，将记忆轮数分别设为 0 轮与 2 轮，比较两次请求带入的历史内容。若 2 轮时带入了与授权期间无关的对话且影响结论，记录为上下文干扰；若两次结论一致，说明该样本对历史轮数不敏感。
3. 输入空引用结果，即纸面输入 []，核对下游节点在无引用内容时的承接设计。观察下游是否给出无依据提示或转人工，不声称虚构规则检索一定返回 []。该核对用于确认空结果分支存在，不表示检索必然为空。
4. 输入样本拟稿句，比较回复中授权期间、授权范围与生效状态三个字段的表述。若回复将“授权期间至2024年12月31日”写成“授权已生效”，记录为字段混淆；若回复明确区分期间与生效状态并标注证据缺口，满足核对条件。
