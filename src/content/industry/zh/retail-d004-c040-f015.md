# 客服咨询知识库维护的合同与交易材料比对：知识库检索与召回

## 这个品类的数据长什么样

客服咨询知识库维护面向FAQ条目、话术模板、商品参数表与升级工单，属于前置问答资料整理，不直接审批退款。资料以周、月为更新频率，来源包括客服系统、商品详情页、售后问题统计与质检抽查。合同与交易材料比对任务要求把待判定的拟稿句或交接请求，与知识库中已入库的原文逐字段核对，识别主体、对象、状态与有效范围是否一致。检索环节决定能否找到可比对的原文；找不到原文时，判定只能停留在证据缺口，不能补造授权或生效条款。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库由库、集合和数据三层组成，最小搜索单位是库。知识库搜索节点可关联一个或多个使用相同向量模型的知识库；跨不同向量模型的库不可共同关联，应先核标识并排除不符合者。语义检索依赖向量距离，全文检索适合编号、型号、专有名词，混合检索通过 RRF 融合多路结果，结果重排使用 ReRank 二次排序。最低相关度仅在语义检索或使用结果重排时生效，属于过滤阈值，不是最终排序规则，也不承担权限或实体隔离功能。引用上限以 token 为单位。引用内容以数组输出，长度可以为 0。

假设演练样本：某知识库内存有一条FAQ原文，内容为“A品牌X1型净水器滤芯更换周期为6个月，自签收次日起算。该说明适用于2025年1月1日后售出的整机订单。”另有一条交接请求拟稿句：“请按上述周期为2024年12月售出的A品牌X1型净水器安排滤芯更换提醒。”核对时需比较售出日期是否落在原文载明的有效范围内。该样本为纸面假设，不指向任何真实客户或订单。

## 配置怎么定

| 配置项 | 本页假设试验起点及理由 | 与什么值比较 |
| --- | --- | --- |
| 关联的知识库 | 仅关联含上述FAQ原文的同一向量模型库 | 核对各库向量模型标识是否一致 |
| 搜索模式 | 先按语义检索与全文检索分别测试样本问题 | 比较两种模式下是否召回该条原文 |
| 引用上限 | 本次假设起点为覆盖原文完整句所需的token量 | 与原文实际长度比较，确认内容不被截断 |
| 最低相关度 | 本次假设起点取中间值，用于观察过滤效果 | 与标注为相关和无关的样本分别比较 |
| 问题优化 | 对含指代的问题开启，对主体完整的样本问题关闭 | 比较优化前后问题主体是否被改错 |
| 结果重排 | 按是否具备ReRank模型决定是否启用 | 比较重排得分与最低相关度阈值 |

## 容易做错的三处

1. 把检索命中当作授权通过。假设样本中拟稿句请求安排2024年12月售出订单的提醒，而原文有效范围限于2025年1月1日后售出订单，检索到原文只能说明找到了可比对材料，不能说明该请求已获授权执行。
2. 把最低相关度当作权限或实体过滤器。该参数只在语义检索或结果重排时生效，用于过滤低相关度结果，不能用来排除无关业务或未授权记录。
3. 把未载明字段判为矛盾。假设样本原文只载明更换周期与有效范围，未载明提醒方式与执行人；拟稿句未涉及这些字段时，应记录为未获支持或待核实，不能判为否定或冲突。

## 怎么确认配好了

1. 输入假设样本原文与拟稿句，在仅关联同一向量模型库的条件下执行检索。比较召回内容是否包含该条FAQ原文。若引用内容为空数组，记录为未召回，不推断系统报错或自动业务动作。
2. 输入拟稿句，比较售出日期字段与原文有效范围字段。同主体、同期间、同一字段出现明确互斥取值时判为矛盾；本样本中2024年12月与2025年1月1日后互斥，判定为超出原文有效范围，同时记录提醒方式与执行人字段缺失。
3. 分别以开启与关闭问题优化的方式输入含指代的追问，比较优化后问题主体是否仍指向A品牌X1型净水器。若主体被改为其他型号，记录为问题优化改错主体，该次检索结果不用于判定。
4. 对图片检索与结果重排路径，仅在存在相应图像输入、模型能力且按设置启用时观察；文档总流程图列出的可选路径不代表每次请求全部执行。空结果承接可用明确的纸面输入[]核对下游设计，不能声称检索一定返回空数组。
