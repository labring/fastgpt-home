# 平台类目资质准入的合同与交易材料比对：工具调用与插件

## 这个品类的数据长什么样

在平台类目资质准入的合同与交易材料比对中，本页说明FastGPT的工具调用与插件如何衔接资料。企业证照、商标和授权链对应不同主体与范围，工具读取不直接决定类目准入。所用场景为自拟文字测试。

## 这些特征在「工具调用与插件」这一环带来什么约束

类目资料比对可先核证照、商标材料和授权原句的主体关系，不提供平台规则或法律结论。自拟输入没有本次平台接受依据，拟议工具仅读取已给段落；参数保留主体、商品范围和材料版本，不从文件齐名推定链条完整，也不由企业经营范围自动补出特定商品许可。必须输入与实际传入值需要对照，工具介绍不保证执行或准入结果。

## 配置怎么定

| 交易比对核对 | 本题自拟材料 | 实际取证 |
| --- | --- | --- |
| 主体角色 | 授权方与材料持有人 | 核原句未混同 |
| 适用范围 | 单项商品与类目分开 | 未自动扩大全部许可 |
| 提交阶段 | 有提交无本次接受 | 另取处理回复 |
| 工具输入 | 主体版本与真实段落 | 实际请求保留来源 |
| 正式准入 | 提交更新和权限另验 | 读取未代替机构判断 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `工具介绍` | 介绍用途、输入和不适用情形。 |
| `工具参数` | 模块及插件参数分别核对。 |
| `必须参数` | 缺合适必参时模型可能不调用。 |
| `工具连接` | 可用工具须连接到调用模块。 |
| `工具调用终止` | 结束调用，不再进行后续AI总结。 |

## 容易做错的三处

主体错接：若授权方与材料持有人被混同，应核原句角色；范围扩大：若单项商品授权被写成全部类目，应查适用说明；提交冒准入：若材料已提交被说成已接受，应取本次处理回复。三项分别核主体、范围和阶段，不由标题或选择值补出。

## 怎么确认配好了

验收保留每份原文身份、真实请求和返回引用，补对应来源后复问，核差异仍能回指。缺适合必须参数可能不调用，应交互取得后看真实请求，先接少量所需工具。终止当前调用后不再调用AI总结；平台提交、资质更新或权限操作另验业务授权及回执，本次比对不证明法律充分、平台已准入或商品已获认可。
