# 平台类目资质准入的合同与交易材料比对：知识库检索与召回

## 这个品类的数据长什么样
平台类目资质准入发生在商品上架或店铺入驻之前，核心材料是主体资质与授权链。营业执照、商标注册证、品牌授权链、行业许可证共同构成一套需要逐项核对的证据集合。这些材料的更新频率为不定期，每次入驻时重新提交，检索侧因此面对的是版本不一、期间不同、字段命名各异的文本。

合同与交易材料比对的任务，是把待核对的拟稿句或交接请求，与知识库中已有材料原文放在同一主体、同一期间、同一字段上比较。检索环节负责把可能相关的材料召回，比对环节负责判断字段是否一致。检索结果本身不构成授权，也不构成资质有效性的确认。

## 这些特征在「知识库检索与召回」这一环带来什么约束
知识库搜索节点可以关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，遇到候选库时应先核对向量模型标识，排除不符合者，记录实际观察，不执行跨模型检索来比较漏召回。

一次检索会按输入内容和搜索参数组合语义检索、全文检索、混合检索、问题优化和重排等能力，最终融合成引用内容。文档列出的可选路径不代表每次请求全部执行：图片检索需要相应图像输入及模型能力，重排需要具备模型并按设置启用。引用内容以数组输出，长度可以为 0，没有搜索到内容时输出链路仍走通。

最低相关度是过滤阈值，仅在语义检索或使用结果重排时生效，不承担权限或实体隔离。相似度得分不能用来排除无关业务或未授权记录。检索环节不执行授权判断，授权状态需要由下游环节另行核对。

假设演练样本：一份待核对的品牌授权链材料原文写为“授权方甲于二〇二四年一月一日授权被授权方乙在华东区域销售第某类商品，授权期限至二〇二五年十二月三十一日”。一条拟稿句写为“乙在华南区域销售第某类商品的授权有效期至二〇二五年十二月三十一日”。待判定的是该拟稿句是否获得材料原文支持。原文的授权区域为华东，拟稿句写为华南，两者在授权区域字段上取值互斥；授权期限字段两者一致。该样本为纸面假设，用于说明比对方法，不代表任何真实主体或已发生的核对。

## 配置怎么定
下表只列与本页任务直接相关的官方已说明设置或实施核对项。需要数值时标明为本次假设试验起点，并说明选择理由与比较对象。

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 仅关联使用同一向量模型的一个库 | 先核对各候选库的向量模型标识，标识不一致者排除，不做跨模型关联 |
| 搜索模式 | 混合检索 | 授权链含主体名称与区域等专有词，混合检索同时使用语义召回与全文召回，再经 RRF 融合 |
| 引用上限 | 起点设为覆盖一份授权链材料的 token 量 | 该值以 token 为单位；用长短不同的实际材料比较引用内容是否完整，再调整 |
| 最低相关度 | 起点设为中等值 | 该值仅在语义检索或结果重排时生效；先标注相关与无关样本，再比较过滤后结果 |
| 问题优化 | 对含指代的多轮追问开启 | 用于指代消除和问题扩展；比较原问题与优化后问题，核对主体与区域是否被改错 |
| 结果重排 | 在候选较多时启用 | 重排对候选文本二次排序，得到 0 至 1 的得分；比较重排前后排序与得分 |

RRF 是混合检索结果的融合过程，不作为独立开关配置。引用上限使用 token 为单位，与思考预算无关。

## 容易做错的三处
1. 把拟稿句中的“华南区域”当作原文已载明。原文的授权区域字段为华东，拟稿句为华南，同一字段取值互斥，这属于与材料原文矛盾，应记录为未获支持。
2. 把检索命中当作授权已确认。检索返回引用内容只说明召回了相关材料，授权是否有效、是否覆盖目标区域，需要按材料原文逐字段核对，检索环节不执行授权判断。
3. 把待审核的入驻请求当作已获批准。请求处于待审核状态，不证明缺少操作权限，也不构成批准；签署、合作达成、合同生效是三个不同事实，材料未载明时保留证据缺口。

## 怎么确认配好了
1. 输入假设样本中的材料原文与拟稿句，比较授权区域字段。原文为华东，拟稿句为华南，同一字段取值互斥，观察到的现象是比对结果标记为与原文矛盾，且该结论仅覆盖区域字段，期限字段另行核对。
2. 输入一条仅写“授权期限至二〇二五年十二月三十一日”而未写授权区域的拟稿句，比较材料原文是否载明区域。原文载明华东，拟稿句未载明区域，观察到的现象是区域字段未获支持、待核实，不能判定为否定或冲突。
3. 输入一条不含任何资质关键词的查询，比较返回的引用内容数组。若数组长度为 0，可按纸面输入 `[]` 核对下游设计是否承接空结果；空结果只说明本次未召回内容，不说明知识库中不存在相关材料。
