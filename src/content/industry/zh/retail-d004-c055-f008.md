# 特许加盟备案管理的合同与交易材料比对：工作流编排

## 这个品类的数据长什么样

在特许加盟备案管理的合同与交易材料比对中，本页说明FastGPT的工作流编排如何衔接资料。加盟合同写明的门店与备案材料列出的主体要分别核对，材料准备和备案结果也属于不同阶段。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟合同写“东区门店使用手册”，备案清单却只列总部名称，披露资料也未标该门店。工作流可先收这几句及各自资料标题，让人员选择补门店适用说明或整理备案依据。分支传递的是所选处理方向，不能自动确认同一主体或满足备案要求；店名相近不足以补出合同与清单之间的对应关系，也不能把手册适用范围扩大到所有加盟点。

## 配置怎么定

| 加盟比对 | 本题自拟片段 | 下游核对 |
| --- | --- | --- |
| 合同门店 | 东区门店 | 清单主体是否有对应依据 |
| 备案清单 | 只列总部 | 不代替本店结果 |
| 手册范围 | 限定门店使用 | 不扩到全部门店 |
| 人员选择 | 补适用或整理备案 | 连接分支收到对应原文 |
| 办理状态 | 结果材料缺失 | 解释仍为待核 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

主体借名：若总部材料被当作该店备案，应核材料列名与合同门店的对应依据；手册范围外推：若“东区门店”被写成全部门店，应回查适用原句及下游接收文本；清单冒结果：若待准备清单被写成备案已完成，应另查本次实际结果材料。三项分别检查主体、适用范围与办理阶段，不能由一条选择结果包办。

## 怎么确认配好了

验收时保留合同摘录和清单原文，比对两条分支各自收到哪份材料；补门店说明的分支不能收到另一加盟点的文件。加入本店对应说明后，只调整主体关系解释，备案结果仍未提供时仍保留待核状态。交互节点记录选择并继续执行，正式提交、外部受理及结果核验需要另接业务步骤，不从节点连通推出备案已生效。
