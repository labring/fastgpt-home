# 生产企业免抵退税的合同与交易材料比对：工作流编排

## 这个品类的数据长什么样

在生产企业免抵退税的合同与交易材料比对中，本页说明FastGPT的工作流编排如何衔接资料。出口合同约定的货物与申报明细的归集期间需要分别比对，整理材料不产生税务处理结论。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟出口合同列“成套部件”，销售明细分列配件，报关资料摘录未写它们如何归集。这里可把合同原句、明细名称及期间作为拟议输入，交由人员选择补对应说明或核所属期间。工作流只传递这些文字和选择，不自行认定不同名称属于同批货物，也不从报关资料存在推定申报明细已确认。税务适用条件和计算不由这一比对样例给出。

## 配置怎么定

| 出口材料比对 | 自拟输入差别 | 本次观察 |
| --- | --- | --- |
| 合同货物 | 成套部件 | 不按名称直接拆并 |
| 销售明细 | 分别列配件 | 需合同对应说明 |
| 归集期间 | 明细期间待核 | 接收保留所属范围 |
| 申报稿 | 只有整理文字 | 不称结果已确认 |
| 分支后续 | 补映射或核期间 | 逐项比对收到原句 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

名称强配：若配件被直接合并为合同成套货物，应取合同与明细的真实对应说明；期间错接：若另一期间明细进入本次比对，应核提交期间与接收原句；编制冒确认：若申报整理稿被当作已确认结果，应查本次实际处理依据。三项分别核货物关系、材料范围和结果性质，报表标题相同也不能省去。

## 怎么确认配好了

将补对应说明与核期间接到不同后续处理，验收逐项比较源文字、选择去向和实际输入。补入映射说明后，可复查名称关系是否有出处，但不能顺带改写处理结果；若期间仍不明确，应保留待核。对外申报、资料变更及结果回读需另核实际权限和业务记录，表单提交或分支完成不证明已申报，更不证明已获某种税务结果。
