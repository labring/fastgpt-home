# 生鲜冷链到店验收的合同与交易材料比对：工作流编排

## 这个品类的数据长什么样

在生鲜冷链到店验收的合同与交易材料比对中，本页说明FastGPT的工作流编排如何衔接资料。冷链温度记录、到店签收与拒收说明各有对象，合同要求不能改写成本批已验收。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟送货单覆盖冷藏整车，温度摘录只注明车厢，拒收说明则针对其中一箱。流程应收录覆盖范围和原句，不填示例温度，也不从车厢记录推定每件货品满足合同条件。人员可选择补箱级检查或核拒收对象；选择走哪条路只安排后续核查，不把到店签字自动认定为全部验收通过，也不代替实际检测和采购判断。

## 配置怎么定

| 冷链比对对象 | 自拟资料范围 | 对应核法 |
| --- | --- | --- |
| 温度来源 | 仅指车厢 | 不称箱级检测 |
| 到店签字 | 只表明签收 | 另取验收结论 |
| 拒收说明 | 针对一箱 | 不扩成整车退回 |
| 人员选择 | 补检测或核拒收 | 查看实际接收原句 |
| 业务执行 | 退运库存另核 | 输出不证明已接受 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

温度对象偷换：若车厢记录被写成该箱检测，应核记录对象与箱级依据；签收冒验收：若到店签字被当作合同条件已满足，应查本批实际验收结论；局部拒收扩全车：若一箱拒收传成整车退回，应对照拒收范围与下游收到文字。三项分别查测量对象、业务阶段和处置范围。

## 怎么确认配好了

验收保留车次、箱级来源说明及选择记录，分别查看补检测与核拒收分支收到的输入。加入该箱检查结论后，可核相应条件是否有证，但不能顺带抹去其他箱的待核状态。实际拒收登记、退运安排与库存处理需要另接业务记录，流程有输出和温度资料可读不证明货品已被接受，更不提供真实冷链效果结论。
