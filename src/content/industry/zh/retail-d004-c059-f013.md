# 生鲜冷链到店验收的合同与交易材料比对：权限与数据隔离

## 这个品类的数据长什么样

在生鲜冷链到店验收的合同与交易材料比对中，本页说明FastGPT的权限与数据隔离如何衔接资料。按供应商、到货批次与质检附件分别核协作权限，避免同一车次被当成全部资料共享范围。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

比对练习可自拟同车配送的两家供应商材料，门店收货人员需核本批单据，供应商只拟取得与自身拒收相关的说明。先按真实身份测试送货单、验收单和质检附件，不能从同一车次推定共享。若某供应商能读另一家的拒收照片说明，应保存其实际返回与资源范围排查；资料按车辆分类有助组织，但不说明外部协作者拥有跨供应商访问权。

## 配置怎么定

| 权限核对项 | 冷链协作范围 | 实际取证 |
| --- | --- | --- |
| 供应商隔离 | 同车两家资料分别确认 | 无关供应商的读取结果 |
| 附件范围 | 送货、验收与质检说明 | 逐资源核原文和操作 |
| 业务姓名 | 质检员记载不配置成员 | 补真实账号与操作映射 |
| 外部照片 | 收货系统鉴权另验 | 回答转述也查完整返回 |
| 问题分工 | 权限与错批温度分开 | 不以访问测试裁定责任 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 质检员姓名被当成员或修改授权：核真实账号、批次资源与操作，验收署名不能自行建立权限，缺映射须责任人确认。

- 同车一供应商读到另一家拒收照片说明：保留具体返回及资源范围查隔离，车辆分类不授予跨供应商访问。

- 温控接口能读被当成所有照片已获权或质量已定责：分开核门店图片鉴权、内部资源和现场证据，照片不显示仍检查回答转述。

## 怎么确认配好了

验收分别用门店收货、对应供应商和无关供应商身份询问同一批次，记录原文读取、操作允许与拒绝结果。若权限正常而答案混用另一批温度，应另查来源身份，不把事件串用都判为隔离故障。可读验收资料仍不直接证明谁应承担质量责任；现场观察、适用条件和责任确认单独核对，不能让访问测试承担业务裁决或完成退赔处理的含义。
