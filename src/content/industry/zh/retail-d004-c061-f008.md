# 生鲜称重分拣的合同与交易材料比对：工作流编排

## 这个品类的数据长什么样

在生鲜称重分拣的合同与交易材料比对中，本页说明FastGPT的工作流编排如何衔接资料。称重分拣材料的商品、包装口径和补差状态需要分别核，分拣任务本身不证明已经称重或完成补偿。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟分拣任务写散装商品，称重标签摘录包含包装，补差单则只记客户提出异议。合同比对不能直接把标签文字当作可比净含量，也不替业务制定换算。流程可收标签口径和异议原句，由人员选择补称重依据或核补差处理。下游要知道任务安排、现场记录与客户申请来自不同阶段，不能因为都出现同一商品名就合成完成记录。

## 配置怎么定

| 分拣交易核对 | 自拟输入 | 本次所需 |
| --- | --- | --- |
| 标签口径 | 记录包含包装 | 不直接作为净量 |
| 任务归属 | 标签可能来自他任务 | 核商品与来源关系 |
| 客户异议 | 只有补差申请 | 不写成已处理 |
| 输入交接 | 包装说明与异议原句 | 检查下游未遗漏 |
| 实务结果 | 称重和补差另取证 | 节点完成不等于解决 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

口径混算：若含包装记录被当净量，应取包装口径和实际称重说明；商品错挂：若另一分拣任务的标签进入本次，应核任务对象与标签来源；申请冒补偿：若补差申请被写成已经处理，应查本次实际处理凭据。三项分别核数量含义、记录归属和执行状态，不由节点连线决定。

## 怎么确认配好了

验收沿补称重依据的选项检查接收文本，确认包装说明没有在交接时消失，再沿补差路径查看它仍是待核申请。补入实际处理结果后复问，核结论仅对应同一商品和异议，不扩大到其他批次。现场称重、退款补差及库存调整需要另接业务证据；这里不提供法定计量判断，也不把流程完成当作客户异议已解决。
