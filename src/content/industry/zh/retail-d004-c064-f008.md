# 直播选品与样品质检的合同与交易材料比对：工作流编排

## 这个品类的数据长什么样

在直播选品与样品质检的合同与交易材料比对中，本页说明FastGPT的工作流编排如何衔接资料。样品评估、检测报告与供应商资质各有覆盖范围，比对流程不能把选品意见写成全批可售结论。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟选品表写“样品手感待复核”，检测资料只覆盖送检样，供应商资质摘录未说明本次商品范围。流程可以收这几句与所指对象，让人员选择补样品观察或查资质适用说明。这里不解释禁售规则，也不由报告标题断言商品允许销售。合同若约定批量供货，仍需另核样品和批次关系，不能把一份样品材料自动扩展到以后所有到货。

## 配置怎么定

| 选品交易核对 | 自拟材料范围 | 对应检查 |
| --- | --- | --- |
| 送检对象 | 仅覆盖样品 | 不扩大全部供货 |
| 主体资质 | 商品范围未说明 | 补实际适用原句 |
| 手感记录 | 待复核 | 不改写选品通过 |
| 人员路径 | 补观察或查适用 | 接收正确商品对象 |
| 批量业务 | 采购上架另核 | 样品不证明未来批次 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

样品扩全批：若送检样结论被写成全部供货合格，应核报告对象与批次对应；资质错用：若主体资料被当本商品证明，应取适用范围原句；待复核冒通过：若手感意见变成选品已批准，应查本次实际评估结论。三项分别检查样本覆盖、资质关系及决策阶段，不能互相补证。

## 怎么确认配好了

验收从样品待复核原句进入，检查补观察与查资质选项传入的对象是否准确。补入商品范围说明后，只更新资质适用解释；手感确认仍缺时，不改变待复核。上架、采购放行与正式选品决定需要另接实际业务记录，流程输出不证明已允许销售，也不证明样品表现会在所有批次重现。

| 候选来源 | 供应商资料、检测机构报告、平台负面目录、历史退货率 |
