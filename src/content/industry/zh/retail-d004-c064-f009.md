# 直播选品与样品质检的合同与交易材料比对：工具调用与插件

## 这个品类的数据长什么样

在直播选品与样品质检的合同与交易材料比对中，本页说明FastGPT的工具调用与插件如何衔接资料。直播样品工具比对约定、样品与批次资料，不能由样品描述推整批质量或可宣传结论。所用场景为自拟文字测试。

## 这些特征在「工具调用与插件」这一环带来什么约束

假设选品条款只约定外观展示，样品说明未做功能测试，供应方大货资料仍待补。工具介绍限定为逐项比对这些文字，列商品、样品及条款版本等必需输入。接调用模块后检查系统参数与插件配置，必要对应不足可能不调用。这里不提供实际测评或质量结果。

## 配置怎么定

| 直播样品比对工具 | 假设资料 | 核验动作 |
| --- | --- | --- |
| 外观展示 | 条款范围有限 | 不推功能保证 |
| 样品说明 | 无功能测试 | 非大货合格 |
| 批次资料 | 仍待补齐 | 不推可宣传 |
| 必要输入 | 商品样品版本 | 核实际调用 |
| 正式选品 | 授权流程另走 | 证据及回执 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `工具介绍` | 介绍用途、输入和不适用情形。 |
| `工具参数` | 模块及插件参数分别核对。 |
| `必须参数` | 缺合适必参时模型可能不调用。 |
| `工具连接` | 可用工具须连接到调用模块。 |
| `工具调用终止` | 结束调用，不再进行后续AI总结。 |

## 容易做错的三处

外观约定被答功能保证时，查条款范围；样品说明被答大货检验合格时，核批次和检测依据；待补资料被答可直接宣传时，查批准及证据。三处分别查承诺范围、样品外推和使用权限，工具返回不能代真实质检。

## 怎么确认配好了

验收输入、调用参数及响应逐条追来源，样品标记紧邻功能缺项，批次待补继续明确列出。若终止调用，核实际输出而不期待后续总结。补检测资料只增加对应项目证据，正式选品认可、宣传批准及订单操作需授权流程与业务回执，工具只列支持和缺证，不裁定安全或整批合格。 外观展示条款与样品功能缺项分别留原文位置，大货资料按批次对应；审阅者可逐项指出拟宣传句子由哪份证据支持，不用样品名称替代检测。
