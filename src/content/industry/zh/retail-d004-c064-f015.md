# 直播选品与样品质检的合同与交易材料比对：知识库检索与召回

## 这个品类的数据长什么样

选品质检在开播前完成，判断的是商品能否上播、能否展示。要核对的材料来自供应商资料、检测机构报告、平台负面目录和历史退货率，落到文档上是样品评估表、质检报告、供应商资质和禁售清单。这些材料按周、按品更新。

合同与交易材料比对的任务，是把待判定的拟稿句或交接请求，与知识库中的材料原文逐项对齐。检索环节只负责把可能相关的原文召回出来，供人工比对字段。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，先核标识并排除不符合者。检索是对整个库进行搜索，集合只用于分类管理，与搜索效果无关。

混合检索同时使用向量检索和全文检索，通过 RRF 公式合并两路搜索结果。RRF 是融合过程，不是可开启的开关。重排需要具备模型并按设置启用，图片检索需要相应图像输入及模型能力，这些是可选路径，并不代表每次请求全部执行。

最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值，不是最终排序规则。引用上限以 token 为单位，控制每次搜索最多引用的内容量。语义召回和相关度不负责权限或实体隔离，检索结果不构成授权。

假设演练样本：某供应商提交的样品评估表原文写有“送检样品名称：便携榨汁杯；送检日期：2025年3月10日；检测项目：食品接触材料迁移量；报告编号：JC-2025-0310；结论：所检项目符合要求”。同一批材料中，供应商资质文件载明“食品接触产品生产许可有效期至2025年6月30日”。一条待判定的交接请求写为“该榨汁杯检测合格，资质有效，可安排上播”。比对时需核对：报告编号与样品名称是否指向同一送检对象，检测结论覆盖的项目是否包含该商品，资质有效期是否覆盖拟上播日期。上述原文未载明拟上播日期，也未载明授权范围，该字段属于未获支持，待核实。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 核对方式 |
| --- | --- | --- |
| 关联知识库 | 仅关联使用同一向量模型的选品质检库 | 核对各库向量模型标识，排除标识不一致者 |
| 搜索模式 | 先用混合检索，同时走语义与全文 | 用编号类问题与自然语言问题分别观察召回内容 |
| 引用上限 | 起点设为覆盖一份完整报告正文的长度 | 用长短不同的实际材料测试内容是否被截断，再调整 |
| 最低相关度 | 先标注相关与无关样本，再定阈值 | 该值仅在语义检索或结果重排时生效 |
| 问题优化 | 仅在多轮追问、短问题场景开启 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 具备模型且候选较多时启用 | 重排后得到 0-1 得分，按得分过滤 |

引用上限的起点选择理由：材料原文长度差异大，用 token 控制比 top k 稳定；比较对象是完整报告正文的实测长度，非官方默认值。

## 容易做错的三处

1. 把检索命中当成授权。假设样本中检索到“结论：所检项目符合要求”，这只是报告原文的字段值，不代表该商品已获准上播，也不代表交接请求已被批准。待审核不证明缺少操作权限，签署、合作达成、合同生效是三个不同事实。
2. 把可选路径当成每次执行。文档流程图列出图片检索、重排等路径，这些需有相应输入与模型能力并按设置启用。未上传图片时不应期待图片检索结果，未启用重排时不应期待重排得分。
3. 把相关度当成权限过滤。最低相关度是过滤阈值，不排除无关业务或未授权记录。检索库同向量模型的要求，不能扩展为外部系统也要同模型。

## 怎么确认配好了

1. 输入假设样本中的样品评估表原文与待判定交接请求，比较报告编号、样品名称、检测项目三个字段是否同主体、同期间、同一字段。观察结果：三字段指向同一送检对象时，比对成立；字段缺失或指向不同对象时，记录为未获支持或待核实。
2. 输入假设样本中的资质文件原文与拟上播日期，比较资质有效期是否覆盖该日期。观察结果：原文未载明拟上播日期时，该比较无法完成，保留证据缺口，不补造授权或生效条款。
3. 输入一条明确写为空的引用内容数组，核对下游设计是否能承接空结果。观察结果：输出链路走通且下游未把空数组当作命中内容时，空结果承接成立；文档未说明虚构规则检索一定返回空数组，该现象属于未获支持。

以上各项均为纸面核对，未实际执行检索、部署或审批，不声称任何业务动作已经发生。
