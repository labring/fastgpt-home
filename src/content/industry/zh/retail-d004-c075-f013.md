# 达人专场带货合作的合同与交易材料比对：权限与数据隔离

## 这个品类的数据长什么样

在达人专场带货合作的合同与交易材料比对中，本页说明FastGPT的权限与数据隔离如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

达人合作协议写有合作期限，可先核这段文字的适用范围，再确认当前账号有权读取协议。品牌商务、MCN机构和达人经纪涉及外部合作，业务参与关系不自动成为FastGPT团队成员或资源授权。若条款比对还需要佣金设置单，应把两个资源分别纳入读取测试；能够看到协议不说明金融或店铺明细也已开放。当前文字检查不推定合作已经履行。

## 配置怎么定

| 权限或实施核对项 | 合作材料范围 | 应检查的事实 |
| --- | --- | --- |
| 协议读取 | 合作期限文字与协议资源 | 当前账号是否实际有权访问 |
| 外部参与者 | 商务、机构、经纪为业务主体 | 不自动映射团队或资源授权 |
| 佣金设置 | 协议与设置单独立可读 | 不由一份材料补写另一份 |
| 缺失条款 | 违约责任仍需相应资料 | 先核存在性与取得权限 |
| 补充后访问 | 两类测试账号读取新增条款 | 记录资源可见及业务缺项 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 品牌商务、MCN或经纪参与合作被当团队获权：核实际成员与协议资源，业务关系不配置读取或操作，也不说明履约完成。

- 协议可读便用一段内容补佣金设置：保留双方原文及真实可见范围，资料分类和分数不决定谁能读，也不能裁定采用哪项比例。

- 内部角色被当成可取店铺或合作平台依据：独立核外部鉴权，缺违约或补充条款仍待取；新来源需测获权与无权身份，不以模型概括认齐备。

## 怎么确认配好了

协议未提供违约责任条款时，完整风险判断仍缺依据；应先确认相关补充文件是否存在，以及当前身份可否取得。外部店铺或合作平台资料的鉴权需要另核，不能依靠内部团队角色推定。补入条款后再次测试获权与未获权账号，观察新增文字是否只对正确身份可见。保留仍缺的业务资料及访问结果，不由模型能概括协议推定全部条款已经齐备。
