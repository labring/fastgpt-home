# 达人专场带货合作的合同与交易材料比对：知识库检索与召回

## 这个品类的数据长什么样

达人专场带货合作围绕外部达人履约与佣金结算展开，品牌商务、MCN机构与达人经纪共同处理达人合作协议、佣金设置单、样品寄送单、直播战报。合同与交易材料比对要求把协议约定与交易记录放到同一字段上核对，例如佣金比例、结算周期、坑位安排。资料更新频率为每场、每周，检索侧只需按现有资料范围组织，不推导批量同步或交易触发机制。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，操作时先核对标识、排除不符合者，并记录实际观察，不执行跨模型检索来比较漏召回。搜索模式按测试问题在语义检索、全文检索与混合检索之间比较，不预设一种模式适合全部资料。引用上限以 token 为单位，用长短不同的实际资料测试内容是否完整。最低相关度仅在语义检索或使用结果重排时生效，先标注相关与无关样本再调阈值。问题优化用于指代消除和问题扩展，须比较原问题与优化后问题，核对主体是否被改错。引用内容以数组输出，长度可以为 0，没有搜索到内容时输出链路仍走通。检索与相似度不承担权限或实体隔离。

假设演练样本：材料原文一为“甲方委托乙方于2025年6月18日进行专场直播，佣金比例为成交额的百分之二十，样品于6月10日前寄达”。材料原文二为“佣金设置单载明本场佣金比例为百分之十五，结算周期为直播结束后三十日”。待判定的拟稿句为“本场佣金按百分之二十结算，结算周期为直播结束后十五日”。该样本仅用于纸面核对，不指向任何真实主体。

## 配置怎么定

| 配置项 | 本页适用设置 | 与样本的对应 |
| --- | --- | --- |
| 关联的知识库 | 关联一个或多个相同向量模型的知识库 | 协议与佣金设置单须在同一向量模型范围内 |
| 搜索模式 | 按测试问题比较语义、全文与混合检索 | 佣金比例、结算周期等字段用全文或混合检索核对 |
| 引用上限 | 以 token 为单位，用长短不同的实际资料测试 | 覆盖两份材料原文后检查内容是否完整 |
| 最低相关度 | 仅在语义检索或使用结果重排时生效 | 先标注相关与无关样本再调阈值 |
| 问题优化 | 用于指代消除和问题扩展 | 比较原问题与优化后问题，核对主体未被改错 |
| 结果重排 | 具备模型且按设置启用时对候选二次排序 | 候选较多时用于比较相关度得分 |

## 容易做错的三处

1. 把拟稿句中的“百分之二十”直接当作已确认结算依据。协议原文与佣金设置单对同一字段给出不同取值，属于同字段明确互斥取值，应判为矛盾，等待核实，不推断哪份有效。
2. 把“结算周期为直播结束后三十日”与拟稿句“十五日”混为同一事实。两者同属结算周期字段且取值互斥，属于矛盾；未载明的部分记录为未获支持。
3. 把检索命中当作授权或审批完成。检索结果只提供引用内容，业务核验、审批、数据库写入与外部同步需要各自的下游实现，待审核不证明缺少操作权限。

## 怎么确认配好了

1. 输入假设样本两份材料原文与拟稿句，比较佣金比例字段：协议为百分之二十、佣金设置单为百分之十五、拟稿句为百分之二十。出现同字段互斥取值时判为矛盾，并保留证据缺口。
2. 输入同一组材料，比较结算周期字段：佣金设置单为三十日、拟稿句为十五日。两者互斥时判为矛盾；材料未载明的其他条款记录为未获支持，不补造授权或生效条款。
3. 输入一条指代不明确的追问，比较原问题与问题优化后的检索词，核对主体是否被改错；再以明确的纸面输入 `[]` 核对空结果时下游链路是否仍走通，不声称虚构规则检索一定返回空数组。
