# 达人佣金结算与扣佣的合同与交易材料比对：权限与数据隔离

## 这个品类的数据长什么样

在达人佣金结算与扣佣的合同与交易材料比对中，本页说明FastGPT的权限与数据隔离如何衔接资料。比较佣金约定与待核扣佣说明时，分别验证合作资料、订单明细和结算意见的可见范围。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

佣金合同练习可拟约定“售后影响另按本单证据复核”，运营备注仅提出待核订单，结算意见尚未获得双方确认。比对人员可以读取合作条款，订单明细和结算附件仍可能属于不同资源。实施时先确认实际成员与资源授权，再检查回答使用了哪份原文，不能由条款可读推明细已看全。运营备注是提出核查的材料，不等于达人已接受扣佣。此处不列真实金额、比例或付款状态，权限测试也不能替代双方事实确认。

## 配置怎么定

| 结算比对权限 | 自拟资料 | 核对线索 |
| --- | --- | --- |
| 合作条款 | 本单证据复核 | 不补订单明细 |
| 订单资源 | 独立明细范围 | 双账号核实际返回 |
| 达人分组 | 仅分类标记 | 跨组访问实际验证 |
| 内部意见 | 未获双方确认 | 编辑不作认可 |
| 外部结算 | 鉴权与写入 | 独立核接收和业务确认 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 缺少订单明细读取权限却答出本单扣佣结论时，对相同明细分别用有权与无权账号检查，核返回内容及引用身份，不能从合作条款填出明细。

- 结算资料按达人分组后被当成已隔离时，核实际资源授权和跨组访问结果，分类名称不证明访问控制成立。

- 能编辑内部意见被写成可以执行扣佣时，核资源操作范围与外部结算接口权限，内部修改不产生对方认可或账务处理。

## 怎么确认配好了

验收保留同一约定、备注与附件，逐账号记录可读、可改和不可见的部分，再复用本单问题检查缺证据处理。权限变更后核实际成员身份，不假定旧会话或相同角色自动继承全部授权。若需连接结算系统，接口鉴权、写入响应和双方确认分别取证。本文只设计资料访问与条款比对方法，不执行扣佣或认定应付结果；正文结论须留在实际可见原文支持的范围。
