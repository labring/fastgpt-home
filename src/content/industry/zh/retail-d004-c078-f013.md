# 连锁总部选址开店的合同与交易材料比对：权限与数据隔离

## 这个品类的数据长什么样

在连锁总部选址开店的合同与交易材料比对中，本页说明FastGPT的权限与数据隔离如何衔接资料。选址比对区分租赁意向、装修预算与开业排期授权，不以文件可读推签约。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

假设选址评估是内部意见，租赁意向书未签，装修预算待批，开业排期仅供讨论。比对要按同一地点和文件用途核成员权限；读到意向书不代表可以承诺租赁或代表总部签约。地点标签不是权限边界，本题不含真实地址、租金、预算数或开业日，也不确认任何地点适合开店。

## 配置怎么定

| 选址比对访问 | 假设状态 | 核查对象 |
| --- | --- | --- |
| 评估 | 内部意见 | 非开店批准 |
| 意向 | 未签文件 | 非已租赁 |
| 预算 | 待批 | 不填金额 |
| 排期 | 讨论稿 | 不补开业日 |
| 地点 | 地址空间范围 | 同资源正反测试 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 门店分组下能读另一候选地点预算时，对资源归属和成员角色，用同资源正反身份核访问。

- 可编辑排期被答成有权宣布开业时，对预算批准、租约签署及公告授权，不以编辑权补业务条件。

- 另一地址已签租约被用来支持本地点时，对地址、空间范围与签署主体，文件名相近不替身份。

## 怎么确认配好了

逐文件列选址评估、租赁、预算及排期的用途和读改管范围。获权与无权成员测试同一资料，引用附件也核，保留实际结果。把合同访问与对外承诺、签署、费用审批分别安排；此纸面比对不发布开业信息、不订立租约。
