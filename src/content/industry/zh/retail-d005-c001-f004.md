# B2B平台撮合交易的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在B2B平台撮合交易的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。以样品记录和交期补充表为两条证据链，查看采购问题实际取回哪一条。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

B2B采购索引可以围绕新拟询报价附页：“可提供材料样品；量产交期需另行确认。”样品获取和量产交期是不同阅读目标，可为同一原数据核对相应搜索文字，但不能把可提供样品概括成量产现货。检索到这段后，回答需分别说明哪一项原文已写明、哪一项仍待确认，索引命中不代表已经取得具体交期。样品可取与量产供货能力也不应混为一项字段。索引检查需能指出相应原句，以及仍未取得的交期说明，不能用同一个命中替代这两类资料。

## 配置怎么定

| 核对项（含实施核对） | 具体原数据或索引 | 验收线索 |
| --- | --- | --- |
| 两份资料共同检索 | 询报价附页与待补交期表 | 只有在同一搜索节点关联这些知识库时，才在该节点核向量模型一致。 |
| 样品状态的文字边界 | 附页“可提供材料样品”；旧记录“样品可取” | 保留样品这一对象；两句均未写量产库存或量产完成时间。 |
| 交期问题的索引目标 | 采购问题问量产交期，不是到哪里取样品 | 核命中索引回指样品附页还是新增交期表，再检查被指原文实际写了什么。 |
| 新表加入后的来源身份 | 补表已入库；旧样品记录仍可检索 | 比较两份资料各自的身份与返回位置，旧记录并不因新增资料而变成交期说明。 |
| 从返回资料到回答 | 候选中有交期文字，答复却仅称样品可取 | 对照实际引用与答复，定位交期文字是否在回答阶段遗漏；保留补表给出的条件。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 索引将样品可取写成量产可立即交付时，并列索引与询报价原句，核新增供货说法。

- 补充量产资料后仍只取回旧样品记录时，核新表是否进入本题范围及索引目标，不能让样品来源回答交期问题。

- 交期说明已返回却在回答中遗漏时，比较候选、实际引用和答复，区分未取回新来源与取回后未使用条件。

## 怎么确认配好了

供应条件补充表未提供时，应把量产交期依据与已有的样品文字分开，说明本题仍无法核实具体交期。补充表取得并入库后，需要检查它的原数据和索引目标，再复用同一采购问题。若复测仍只返回旧样品记录，应保留候选和引用，分别排查新表未进入关联范围、索引指向旧数据，以及回答遗漏已返回的交期文字这几种情况。同一检索节点关联多个知识库时，核实际向量模型一致；来源授权和供货条件单独验证，不能由相关度推定供应资格。
