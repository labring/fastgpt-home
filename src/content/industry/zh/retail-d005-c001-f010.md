# B2B平台撮合交易的库存采购与供应商资料：引用来源与溯源

## 这个品类的数据长什么样

在B2B平台撮合交易的库存采购与供应商资料中，本页说明FastGPT的引用来源与溯源如何衔接资料。样品表面选项、长期供货介绍与本次补货承诺分属不同证据。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

B2B采购溯源可自拟样品单“表面可选粉末涂层”、供应商介绍“提供长期供货服务”和补货询问“本次批次待确认”。问是否能立即按涂层样品补货时，介绍只能说明自述服务，样品单只列选项，询问尚未给出本次确认。引用需保留每份材料的对象和范围，不能因三处文字同属供应商资料，就把选项、能力介绍和订单承诺拼成已经明确的供货安排。

## 配置怎么定

| 采购溯源核对项 | 自拟材料与范围 | 取证动作 |
| --- | --- | --- |
| 样品选项 | 涂层可选 | 不扩成正式供货标准。 |
| 服务自述 | 长期供货介绍 | 核自述范围。 |
| 本次批次 | 询问尚待确认 | 补核适用供货条件。 |
| 被引对象 | 旧询问可能为别材料 | 核对象及版本。 |
| 引用覆盖 | 介绍、样品与询问 | 查实际传入哪份文字。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是把长期供货介绍写成当前批次可立即交付，应找本次供货确认及适用条件。第二处是样品可选涂层被当成正式供货标准，应核最终规格确认，样品不能代替。第三处是引用拿到另一材料的旧询问，却对本次涂层对象下结论，应核被引对象和版本。三项分别需要交易确认、规格依据与来源身份核对，不能用更多介绍页代替缺少的证据。

## 怎么确认配好了

验收分开问样品有哪些选项、供应商如何自述服务、本次批次确认到了哪一步，逐项对照实际引用内容。回答可以列明涂层选项与服务介绍，但本次供货条件仍待确认，不添加交付时间。若引用数组仅有供应商介绍，需检查是否真正传入询问与样品原句；空引用则追查本次范围和传递。无论引用多少，都不由品牌文字或相关度推定供应商资格、现实库存或履约结果。
