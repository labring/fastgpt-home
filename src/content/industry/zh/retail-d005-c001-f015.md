# B2B平台撮合交易的库存采购与供应商资料：知识库检索与召回

## 这个品类的数据长什么样

B2B平台撮合交易的从业主体包括平台运营、供应商与企业采购，日常文档为企业认证资料、询报价单、电子合同与平台结算单。与批发市场档口交易相比，在线认证和电子合同更多，不依赖现场档口。资料更新频率为日、每单。检索面对的是一组主体名称、报价条款、合同状态与结算记录，其中企业认证资料与电子合同属于审核与签署环节的产物，询报价单属于撮合环节的产物。这些文档在同一知识库内并存时，检索词可能同时命中不同性质的内容，因此召回结果需要按材料来源与字段含义分别核对。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。语义检索依赖向量距离，全文检索依赖关键词命中，混合检索通过 RRF 融合两路结果，结果重排使用 ReRank 模型二次排序。最低相关度仅在语义检索或使用结果重排时生效，它是一个过滤阈值，不是排序规则。引用上限以 token 为单位。问题优化用于指代消除和问题扩展，会增加一次模型调用。检索环节本身不承担权限判断，向量相似度不区分企业主体是否已获授权，也不区分记录是否属于当前采购范围。引用内容以数组输出，长度可以为 0，未命中时输出链路仍然走通。

假设演练样本（以下材料为本次纸面核对而编写，不来自真实客户或真实登记信息）：

材料原文一，供应商资料卡：「供应商名称为华岭机电配件有限公司；认证状态为纸质材料已提交，平台审核中；可供货品类为轴承与联轴器。」

材料原文二，询报价单：「询价方为华岭机电配件有限公司；报价对象为深沟球轴承6205；报价有效期为二〇二五年三月一日至二〇二五年三月三十一日；供货周期为签约后另行确认。」

待判定拟稿句：「华岭机电配件有限公司已通过平台认证，可按报价单在有效期内直接供货。」

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| 关联的知识库 | 仅关联存放供应商资料与询报价单的一个库 | 该库使用同一向量模型；与其他不同向量模型的库不共同关联 |
| 搜索模式 | 先以混合检索起步 | 与单独语义检索、单独全文检索的结果逐条比较，观察编号类词是否命中 |
| 引用上限 | 起点设为能容纳两份材料原文的 token 量 | 用长短不同的材料测试内容是否被截断，再与更大上限的结果比较 |
| 最低相关度 | 起点设为中等值 | 先标注相关样本与无关样本，再与更高、更低阈值的结果比较 |
| 问题优化 | 先在多轮追问场景开启 | 比较原问题与优化后问题的检索结果，核对主体是否被改错 |
| 结果重排 | 具备 ReRank 模型时启用 | 比较启用前后的排序，用重排得分与向量得分分别观察 |

以上数值为本次假设试验起点，不是官方默认值。

## 容易做错的三处

1. 把「认证状态为审核中」读成已通过认证。材料原文只记载纸质材料已提交、平台审核中，拟稿句称已通过平台认证，属于超出原文的判定。检查动作：输入拟稿句与材料原文一，比较认证状态字段的取值，观察拟稿句是否与原文一致。
2. 把报价有效期当作供货期限。材料原文二只记载报价有效期至二〇二五年三月三十一日，供货周期为签约后另行确认，拟稿句称可按报价单直接供货，混淆了两个字段。检查动作：输入拟稿句与材料原文二，比较报价有效期与供货周期两处表述，观察是否存在替代。
3. 把检索命中当作授权确认。检索返回引用内容只说明向量或关键词匹配，不说明该供应商已获采购授权。检查动作：输入一条仅含供应商名称的检索请求，比较返回引用与材料原文中的状态字段，观察引用中是否出现授权结论。

## 怎么确认配好了

1. 针对拟稿句「华岭机电配件有限公司已通过平台认证，可按报价单在有效期内直接供货」，输入材料原文一与材料原文二，比较认证状态字段与供货周期字段，只有当拟稿句与两处原文均一致时才满足条件；本次样本中拟稿句与原文不一致。
2. 针对报价有效期字段，输入材料原文二，比较报价有效期与供货周期是否为同一字段，只有当两者未被互相替代时才满足条件；本次样本中两处表述不同。
3. 针对空结果承接，输入一条明确标注为纸面输入的检索请求，其引用内容为[]，比较下游设计是否按长度可以为 0 处理，只有当输出链路在空引用下仍走通时才满足条件。该核对用于验证下游承接，不表示任何虚构规则会返回空结果。

检索仅完成召回，业务验证、审批、数据库写入与外部同步需要另行实现的环节，本页不将其视为已完成。
