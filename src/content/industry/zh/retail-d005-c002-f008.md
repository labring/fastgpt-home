# MCN机构达人管理的库存采购与供应商资料：工作流编排

## 这个品类的数据长什么样

在MCN机构达人管理的库存采购与供应商资料中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

MCN采购流程可以从本次需要核什么合作资料开始，自拟输入把拟合作达人、合同范围及待补培训说明分开。表单收集的是这些已有文字及提供方，提交后应逐项核后续读取步骤收到什么，不能从账号排期推断对方已符合采购条件。合同中允许合作的内容与本次是否可以进入采购，各需要自己的依据；流程先保留这种范围区别，再安排资料提供者继续核实。

## 配置怎么定

| 核对环节 | 本题自拟资料 | 应观察内容 |
| --- | --- | --- |
| 需求拆开 | 合作范围与培训缺口 | 未由排期推定采购资格 |
| 身份传递 | 达人姓名和账号昵称另列 | 无对应依据时仍列缺口 |
| 人工路径 | 补培训或整理现合同 | 各自“是”分支去向正确 |
| 补证变化 | 新增培训原文及同一需求 | 输出实际采用新资料 |
| 外部批准 | 另接采购登记与审批 | 流程结束未代替业务回执 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

可让资料负责人选择补培训记录或只整理合同原文，分别验证对应的“是”分支。若补培训的选择仍送到合同整理，应排查选择值、接收步骤和传入资料，不能用原合同代替新说明。另一项失败是达人姓名在下游被换成账号昵称，没有可核对应关系时，应回看填写文本并保留身份缺口，防止将另一人的资历混入本次采购。 若培训签到被流程当成本次合作资格已核，应回查签到所支持的参加事实与所需培训内容，分别保留合同范围；出勤不能补出能力或本次合作的资料依据。

## 怎么确认配好了

验收沿本次需求、提交内容、分支去向与输出依据回查，观察缺培训资料时和补齐后分别怎样继续。交互状态随节点触发记录，不另设一个全局开关来假定资料已核完。需要外部查档、采购登记或合作审批时，另接真实业务接口并核权限及回执；本次资料流程走到结尾，不能证明供应商已批准、合同已生效或排期已更新。
