# TikTok Shop美国店运营的库存采购与供应商资料：工作流编排

## 这个品类的数据长什么样

在TikTok Shop美国店运营的库存采购与供应商资料中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

TikTok Shop采购流程可先区分页面商品描述、退货检查资料和本次待查库存来源。自拟输入同时给前两项，并明确库存依据未取得，流程不能据退货分级直接判定可采购或可售。表单传值时应保留每项材料所指商品及来源性质，接收步骤先解释已给记录，不把一次商品检查扩成当前所有库存的状态，更不能由商品名称自行建立系统间关联。

## 配置怎么定

| 核对环节 | 本题自拟资料 | 应观察内容 |
| --- | --- | --- |
| 三类范围 | Listing、检查与库存来源 | 未把分级扩为当前库存 |
| 商品对应 | 检查原文故意换成其他商品 | 错配移出后重测 |
| 人工去向 | 补库存或仅看页面 | 选择与接收材料分别核 |
| 缺口保留 | 库存路径仍只接Listing | 没有猜补可用结论 |
| 实际动作 | 采购与上架另验业务记录 | 流程完成未代替平台接受 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |

| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

若另一商品的检查文字传入本题，接收内容再完整也无法解释当前采购，应排查提交来源与商品对应，移出错配文本。可另设人员选择补库存来源或只回看页面说明，验证各自连接；若补库存路径仍只接到Listing，应检查实际输入，不能把人员已选择当成库存资料已经返回，也不能让下游用页面描述猜补可用状态。 若退货检查文字被流程扩成当前可采购库存，应核检查所指单件与本期库存范围，分别回到原文；分级说明不提供仓内可用性，缺对应来源时保留未知。

## 怎么确认配好了

验收保留三个来源范围与分支结果，补库存资料后用相同采购问题复测，确认新增依据进入答复且未知项仍列清。用户选择按所接的“是”分支继续，交互状态的记录不等于业务审查通过。采购登记、库存修改或重新上架若需执行，另接外部流程并核权限、响应及操作记录；流程走通不证明平台已经接受这些动作。
