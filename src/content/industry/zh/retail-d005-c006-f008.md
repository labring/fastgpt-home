# 一般贸易出口报关的库存采购与供应商资料：工作流编排

## 这个品类的数据长什么样

在一般贸易出口报关的库存采购与供应商资料中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

出口采购资料流程可先收合同的供货描述、发票商品原句与供应商尚需确认的事项。自拟输入没有本次供应商回复，不将合同约定直接当成当前备货结果。表单提交后，读取步骤应收到每段文字的身份和范围；装箱说明即使也已提供，仍需核是否对应本次采购对象，不能以单证名称齐全替代交易对应关系或供货承诺的实际依据。

## 配置怎么定

| 核对环节 | 本题自拟资料 | 应观察内容 |
| --- | --- | --- |
| 当前回复 | 合同已给但供应商未回复 | 未从约定推出备货结果 |
| 材料对应 | 发票装箱与本次采购对象 | 单证名称未替代身份依据 |
| 补回复路径 | 选择补证仍写已确认 | 回查传入原文及判断出处 |
| 数量口径 | 包装件数与合同需求分开 | 修正对象后再作比较 |
| 外部办理 | 询单、下单或变更另接 | 分别核授权及真实状态 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

可让经办人选择补本次供货回复或整理现合同，逐项看对应“是”分支。若补回复的路径仍输出“供应商已确认”，应排查传入文本与判断出处，保留未回复状态。另一项失败是装箱件数被传成合同要求数量，需回查各处单位与对象，修正比较口径后重试，不能因数字看起来不同就认定供应商少发或违约。 若发票中所列主体被流程直接当成合同供应商，应回查两份材料各方身份与交易对应；同处一套单据不表示角色相同，缺对应说明时先保留主体未核。

## 怎么确认配好了

验收从采购问题、提交文本、接收步骤到最终说明逐段回看，补供货回复后再问原题，检查回复实际参与解释。节点等待交互并继续，只安排资料处理，不自动形成采购记录。外部询单、合同更新或采购下单需要另接业务接口及授权，核真实返回和办理状态；本次流程结束不能证明合同已变更、货物已备齐或报关已受理。
