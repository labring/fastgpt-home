# 一般贸易进口报关的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在一般贸易进口报关的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。进口备件采购的滤网、支撑环和整套选项按部件关系索引。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

进口采购可拟备件页“滤网单片，不含支撑环”、选项页“带环套件可另询”和联系记录“已发询问”。索引草稿称“带环滤网现货”。当前问单片能否直接带环使用时，需要看到单片排除和另询状态，不能从选项存在推本次已选择，联系记录也没有供货答复。索引应分别回指单片原数据和选项页，不因滤网词重复就将两个来源的范围混成一个已经确认的采购对象。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 部件排除 | 当前单片原文不含支撑环 | 将带环索引逐项对回此句，标出多出的环。 |
| 选项状态 | 带环套件在另一页，只允许另询 | 问能否买套件时保留另询，不当已选组合。 |
| 联系进度 | 联系记录仅说明问题已发出 | 核是否存在同一询问的实际供方回复。 |
| 旧套件 | 历史页可能描述另一片滤网 | 核单片身份、套件组成及实际关联块。 |
| 安装适配 | 单片与支撑环没有安装资料 | 把采购组合确认和实物适配证据分别登记。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是单片索引新增支撑环，应核原数据中的不含与拟索引部件关系，标出不支持的组成。第二处是可另询被写成现货，应查实际回复及供货确认，不由选项页证明库存。第三处是旧带环套件索引被采用为当前单片，应对料件身份、组成和版本。三项分别查部件增写、供货状态和关联对象，不把向量命中或相近商品描述当实际适配证明。

## 怎么确认配好了

验收可分别问单片含什么、带环选项处于何种状态、询问做到了哪一步，保留索引及引用原文。修改关联或索引后用同一单片与套件问题复测，确认真实返回未丢排除条件。没有答复时保留待核，不推供货被拒或不可能带环。全部为自拟文字，没有物理安装测试；模型与索引设置不产生部件适配事实，也不执行进口采购或确认现实库存。
