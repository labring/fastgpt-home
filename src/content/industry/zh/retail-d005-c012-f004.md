# 仓内拣货复核打包的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在仓内拣货复核打包的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。分别核纸箱补货状态、泡棉盘点与箱型规格，保留各项证据的范围。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

仓内包装耗材的采购查询，可以从自拟耗材单开始：“小号纸箱待补；泡棉现有可用，数量待盘点。”另一张申请只写“按上次箱型补充”。为纸箱和泡棉分别拟索引时，须保留待补与待盘点的对象，不能把两个状态合成全套包装材料都有库存。检索验收可分别问纸箱是否在库、泡棉数量是否已确认，观察每个索引实际指向哪段原数据。耗材单写的是采购和盘点线索，没有包裹已完成包装的记录。

## 配置怎么定

| 实施核对项 | 本题材料 | 取证动作 |
| --- | --- | --- |
| 状态对象 | 纸箱待补，泡棉数量待盘点 | 分开核原句及对应索引。 |
| 指代来源 | 上次箱型未提供规格 | 取得被指向的规格再问适配。 |
| 索引错误 | 把现有状态扩给纸箱 | 比较入口文字和实际回答。 |
| 资料变更 | 补入规格与盘点记录 | 用相同三个问题追查新来源。 |
| 图文路径 | 按实际入库方法处理规格图 | 文字提取与图片检索分别核。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 索引将“泡棉现有可用”扩给待补纸箱时，并列原句、索引文本和回答，核在库说法从哪一步增加。待补不代表零库存；本题仍缺实际盘点数量。

- “按上次箱型”没有给出规格。若索引据此写成可用于重件，查被指向的规格原文，不能由旧名称补出承载条件。

- 补入箱型规格后，若返回仍属于另一种箱型，应核索引目标和规格身份；名称相近不能替代本次所问纸箱。

## 怎么确认配好了

取得箱型规格和盘点记录后，先核新原数据及其索引的对应对象，再复用纸箱在库、泡棉数量与重件适配三个问题，比较返回来源的变化。若规格图按文字解析，需对照纸箱名称和限制条件是否提取完整；实际使用图片检索时才核图片描述或向量。关联耗材库与规格库前，核向量模型是否符合共同关联条件。记录新增来源、索引改动和实际引用各自发生的变化；索引数量增加本身不能证明库存已更新，检索验收也不执行采购、收货或包装。
