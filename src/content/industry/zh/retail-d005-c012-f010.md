# 仓内拣货复核打包的库存采购与供应商资料：引用来源与溯源

## 这个品类的数据长什么样

在仓内拣货复核打包的库存采购与供应商资料中，本页说明FastGPT的引用来源与溯源如何衔接资料。整捆纸箱库存、单箱适配与物料分配需要不同凭据。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

仓内采购资料自拟盘点“整捆纸箱在库”、供应商样张“展示外观”和备货要求“单箱内腔需核”。问现有纸箱是否足够并适合本件时，整捆记录没有给可用单箱明细，样张没有内腔规格，备货要求也未有测量结果。引用需保留库存单位与规格对象，不从外观推出容纳能力，也不能把整捆在库写成每个单箱都已分配给本次。

## 配置怎么定

| 采购溯源核对项 | 自拟材料与范围 | 取证动作 |
| --- | --- | --- |
| 库存单位 | 整捆 | 不自行换算可用单箱。 |
| 规格对象 | 单箱内腔 | 查实际规格或核对。 |
| 样张内容 | 只示外观 | 不推容纳能力。 |
| 分配状态 | 旧在库未必本次预留 | 核时点位置及活动。 |
| 新增明细 | 材料批次与备货对应 | 核适用后再答。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是整捆单位被当成可用单箱数量，应核拆分及可分配明细，不自行换算。第二处是样张外观被当内腔适配，应读实际规格或核对记录。第三处是旧盘点物料被写成本次已预留，应查位置、时点与实际分配。三项分别核单位关系、规格依据及库存活动，不让同名纸箱替代这些证据；本组不设尺寸或数量，不能由模型补出。

## 怎么确认配好了

验收分别问盘点用何种单位、样张说明什么、本件适配仍缺什么，核引用各自覆盖。答案应保留单箱明细、内腔核对与分配缺项，不直接宣称够用或装得下。若引用只有样张名称，要查实际传入是否有规格正文；空引用不证明没有纸箱。补入明细后核它对应哪批物料与备货事件，再比较本件问题，不能将一份规格确认扩为所有在库纸箱均可使用。
