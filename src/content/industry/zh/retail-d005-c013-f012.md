# 便利店加盟门店督导的库存采购与供应商资料：文档解析与分块

## 这个品类的数据长什么样

便利店加盟督导场景里，库存采购与供应商资料通常散落在巡店表、加盟合同、整改通知和陈列标准四类材料中。与直营鲜食订货相比，督导环节的核心是总部对加盟商执行标准的监督，材料里同时出现总部要求、加盟店主承诺和实际执行记录。这类材料的更新频率为周或月，单份巡店表可能同时记录陈列检查、总部订货核对和整改追踪三项内容。

对文档解析与分块而言，这意味着同一份材料内部存在多个语义单元：陈列标准条款、订货数量记录、供应商资质说明、整改期限约定。分块时需要保留条款与其约束对象之间的对应关系，避免把“某供应商资质有效期”与“某门店订货数量”拆到不同块后失去上下文。供应商资料中的编号、合同号、许可证号属于精确查询对象，语义向量对这类字符串的区分能力有限，全文检索路径更适合承接。

## 这些特征在「文档解析与分块」这一环带来什么约束

FastGPT 知识库由库、集合和数据三层组成，最小搜索单位是库，集合仅用于分类管理。一组数据可对应多个向量索引，存储于 MongoDB 的 dataset.datas 表，indexes 字段记录向量 ID 数组；向量本身存于 PostgresSQL 的 vector 字段，索引为 HNSW。检索时先召回向量，再按 ID 回 MongoDB 取原数据，同一组原数据被多路命中时合并并取最高得分。

混合检索通过 RRF 融合语义召回与全文召回结果，Rerank 对候选文本二次排序并给出 0-1 得分。最低相关度仅在语义检索或启用结果重排时生效，属于过滤阈值。引用上限以 tokens 为单位控制每次搜索引用的内容量。图片检索需要入库时已建立对应索引，且依赖视觉模型或支持图片的向量模型；重排需要具备 ReRank 模型并按设置启用。这些路径均为可选，单次请求不必然全部执行。

### 假设演练样本

以下为本次纸面核对使用的虚构材料，不指向任何真实门店或企业。

材料原文一：“加盟合同附件三载明，鲜食类供应商资质文件有效期至2026年3月31日，加盟店主应在到期前三十日提交续期材料。”

材料原文二：“2026年1月巡店表记录，A类门店冷柜陈列符合标准，总部订货单号DD-20260112已核对，供应商资质文件归档于门店资料册第二卷。”

待判定拟稿句：“该门店供应商资质持续有效，续期材料已提交。”

核对对象：同一门店、同一期间（2026年1月）、同一字段（供应商资质有效期与续期材料提交状态）。原文仅载明有效期截止日与应提交时限，未载明续期材料已提交，拟稿句后半句属于未获支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 搜索模式 | 混合检索 | 供应商编号与自然语言问法并存，需同时覆盖两类查询；与纯语义检索比较编号命中情况 |
| 最低相关度 | 0.3 | 作为本次试验起点，避免过滤掉资质有效期类长句；与0.5比较召回数量变化 |
| 引用上限 | 2000 tokens | 承接巡店表与合同附件多段内容；与1000比较是否遗漏条款约束对象 |
| 问题优化 | 开启 | 连续追问“第二点是什么”类问题需要指代消除；与关闭比较短问题召回效果 |
| 结果重排 | 启用 | 候选结果较多时二次排序；与不启用比较排序稳定性 |
| 分块依据 | 按条款与记录单元 | 保留供应商资质条款与其约束对象；与按固定长度切分比较上下文完整性 |

## 容易做错的三处

1. 把“续期材料应在到期前三十日提交”直接读成“续期材料已提交”。材料原文只载明应提交时限，未载明提交动作已完成。核对时应比较同一门店、同一期间内是否存在提交记录，缺失时记录为未获支持。

2. 把上传成功当作检索已更新。资料变更后需核对实际训练与索引状态，MongoDB 中 indexes 字段是否已生成对应向量 ID 属于可观察项，上传动作本身不证明检索生效。

3. 把最低相关度当作权限或实体过滤器。该值仅在语义检索或结果重排时生效，用于过滤低相关度结果，不承担排除无关企业或未授权记录的功能。检索结果与授权状态属于不同事实。

## 怎么确认配好了

1. 输入材料原文一与材料原文二，比较拟稿句中“续期材料已提交”是否有对应记录。若两份原文均未出现提交状态字段，则该句为未获支持，不得判定为已提交或已拒绝。

2. 输入供应商资质编号或合同号，比较全文检索与语义检索的命中差异。若编号类查询在全文检索下命中而语义检索未命中，说明分块对精确字符串的保留情况需要检查，记录实际观察结果。

3. 资料更新后，比较上传时间与 dataset.datas 中 indexes 字段的实际状态。若 indexes 未生成对应向量 ID，则检索不会返回新内容，此时记录为索引未更新，不推断为训练失败或数据丢失。
