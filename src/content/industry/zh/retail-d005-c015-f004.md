# 信用证审单交单的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在信用证审单交单的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。分别回查供货方、出库仓和生产附件，防止角色或批次错引。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

信用证审单材料用于采购资料问答时，可先拟商业发票附注：“供货方为甲；生产地点见批次附件。”配套装箱说明只写“货物由乙仓出库”。索引应分别帮助查供货方身份、生产地点线索与发货地点，不将甲、乙或某处地址合成同一角色。现有文字没有给出批次附件，也不能从出库地点推断制造地点。分别问谁供货、何处出库、何处生产，检查返回的依据是否越过各自材料范围。

## 配置怎么定

| 实施核对项 | 本题材料 | 取证动作 |
| --- | --- | --- |
| 主体角色 | 供货方、出库仓与生产地点不同 | 逐题核各自原句。 |
| 附件指向 | 本批生产附件尚未提供 | 不由地址补出制造信息。 |
| 批次误引 | 旧附件可能同名供货方 | 核被引批次与当前指向。 |
| 模型与索引 | 共同检索材料先核条件 | 变更后仍问相同角色问题。 |
| 审单边界 | 检索提供材料定位 | 不将命中认定为银行接受。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 乙仓被索引写成制造方时，查其目标究竟是装箱说明还是生产附件，保留原文与角色替换的差异。

- 同名供货方旧批附件被用于本批时，对照发票指向、附件批次和实际引用，不能由厂名一致认定批次对应。

- 本批附件已补入但仍只返回旧记录时，核新原数据和索引目标；先区分未取回新来源与取回后混用角色，再判断回答。

## 怎么确认配好了

本批生产附件取得后，单独登记为新原数据，检查相关索引有没有仍指向旧批次。模型或索引调整前后固定角色和批次问题，逐句比较实际引用，另看表达是否清楚。共同检索发票库、物流材料库与生产附件库时，核向量模型条件及实际可用来源；无附件的问题仍应记为证据待补。若材料来自扫描件，先对照提取文字中的主体和批次，再按实际图片检索路径核相应内容。索引可帮助查材料，正式审单、供货认可和后续交易处理仍有各自依据与责任。
