# 加盟商培训与开业辅导的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在加盟商培训与开业辅导的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。核课堂样品、选型练习与正式采购的资料身份和版本。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

加盟开业辅导中的采购查询，可以新拟一张培训清单：“演练用咖啡杯样品，不用于门店下单。”考核记录另写“学员完成选型练习”。索引需要分清教学样品、练习结果和正式采购依据。分别用样品用途及是否已下单两个问题检查引用，避免把选型完成和订单完成连成同一流程。材料只描述课堂活动，没有供货确认、交期或可售库存，检索回答应保留这些尚未给出的信息范围。

## 配置怎么定

| 实施核对项 | 本题材料 | 取证动作 |
| --- | --- | --- |
| 清单用途 | 演练样品不用于下单 | 引用保留课堂身份。 |
| 考核对象 | 学员完成选型练习 | 不能扩成采购决定。 |
| 课程版本 | 纸杯与可复用杯分属两版 | 核当前适用材料。 |
| 新采购依据 | 正式物料清单单独保存 | 原问题追查新增引用。 |
| 图文与范围 | 按实际处理链核规格 | 缺项不由样品名补齐。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 学员选型练习完成被写成门店采购已选定时，核考核对象与索引目标，保留课堂结果和业务决定的区别。

- 清单中的“不用于门店下单”被遗漏时，查索引与实际引用是否仍包含用途限制，不能把教学样品作为可直接订货的目录。

- 旧版纸杯说明进入本轮可复用杯介绍时，对照两版原文及适用课程，查实际引用属于哪一版。

## 怎么确认配好了

取得正式开业物料清单后，将它与课堂样例区别保存，再问原来的用途和采购状态问题，确认引用确实移到新来源。新增索引不应把培训案例的历史身份抹掉；同一原数据的多个索引文本也应回到相同适用课程。若培训库和采购资料库需要共同关联，核向量模型及来源范围，不用提高相关度分数替代主体和版本核验。样品图按实际解析或图片检索方式检查，未读到的规格仍需补充。技术复测记录引用变化，不能代替开业验收或供应商确认。
