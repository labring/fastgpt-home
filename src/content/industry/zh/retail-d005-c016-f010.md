# 加盟商培训与开业辅导的库存采购与供应商资料：引用来源与溯源

## 这个品类的数据长什么样

在加盟商培训与开业辅导的库存采购与供应商资料中，本页说明FastGPT的引用来源与溯源如何衔接资料。课程演示设备、讲师服务与开业采购需要分清提供方。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

加盟培训采购自拟课程手册“演示器材由课堂安排”、开业需求“门店拟购操作设备”和服务说明“讲师负责讲解”。问能否向讲师采购课堂同款时，手册没有列销售来源，需求没有确认型号，服务说明只给讲解职责。引用要保留课程、需求与角色，不因讲师使用过器材就把其认定为供货方，也不能把课堂安排写成门店已获得设备。

## 配置怎么定

| 采购溯源核对项 | 自拟材料与范围 | 取证动作 |
| --- | --- | --- |
| 课堂安排 | 器材用于演示 | 不改成门店已采购。 |
| 需求选型 | 拟购操作设备 | 核具体型号关系。 |
| 讲师角色 | 负责讲解 | 不推销售主体。 |
| 供货缺项 | 来源及范围未确认 | 列待核材料。 |
| 适用门店 | 后补清单可能有范围 | 核门店设备对应。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是演示器材被当作门店已采购，应查实际采购及交接依据。第二处是拟购操作设备被写成课堂同款，应核需求选型与规格对应。第三处是讲师职责被扩成设备销售，应查供应主体及可供范围。三项分别核交易事件、型号关系与角色身份，不能用培训手册完成全部判断；即使来源都与开业有关，也没有自然形成设备供货合同。

## 怎么确认配好了

验收分别问课程安排什么、门店需求到哪一步、讲师服务包含什么，对照实际引用保留各自边界。具体采购问题应列明型号和供应来源待核，不补订单或交付。若数组只有课程手册，检查开业需求与服务说明是否进入；如果只有来源名而无职责原句，继续核内容。补入采购清单后核它适用门店与设备，不把一次课堂器材记录推广成所有加盟店的标准采购配置。
