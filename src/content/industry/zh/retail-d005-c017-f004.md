# 加盟费与保证金结算的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在加盟费与保证金结算的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。把保证金台账与本次采购确认分开，检查供货方依据是否属于当前事项。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

加盟费用资料关联采购问答时，可先拟保证金台账备注：“物料领用另走采购单；本记录仅登记保证金事项。”一份待填采购单则写“开业展示架，供货方待定”。两个来源能支持台账用途和采购对象，不能说明保证金已经转作货款，或总部已经为展示架指定供应商。为这两条原数据拟索引文本时，应保留各自的业务对象；用物料是否已采购、供货方是否确定两问核引用，避免让费用台账承接它未记载的采购状态。

## 配置怎么定

| 实施核对项 | 本题材料 | 取证动作 |
| --- | --- | --- |
| 台账对象 | 仅登记保证金事项 | 不补出物料货款用途。 |
| 采购事项 | 展示架供货方待定 | 不从台账推定已采购。 |
| 历史误引 | 同名门店旧采购单 | 核本次事项与实际索引目标。 |
| 新确认材料 | 供货确认单独入库 | 原问题核新增引用。 |
| 图片路径 | 先核真实入库处理 | 对象说明须可回查。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 索引把保证金事项写成已购买展示架时，并列台账原句、待填采购单和答复，核款项用途与完成状态是否由拼接新增。

- 历史同名门店采购单被用于本次事项时，核门店、采购对象及索引目标，不能直接借其供货方名称。

- 本次供货确认已加入却只返回台账说明时，查新原数据、本次采购的索引目标和实际候选；台账没有供货方，不能让回答自行填写。

## 怎么确认配好了

先把本次供货确认与台账、历史采购单分开保存，核门店和采购事项。再查看新原数据及实际候选，确认供货方问题是否引用本次确认。

若仍只返回保证金说明，记录索引目标和本轮引用，定位新增确认没有参与的环节。多个库由同一检索节点关联时，核向量模型条件；资料命中不代替采购审批或下单记录。
