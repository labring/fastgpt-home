# 区域经销商库存补货的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样
区域经销商库存补货属于日常滚动订单，经销商ERP、品牌订货系统、仓库库存和销售回款共同构成补货申请、库存周转表、出库单、回款计划的核对基础。这些材料通常按周或按月更新，HTTP 接口需要把外部系统中的字段映射到本页主任务，即库存采购与供应商资料的核对与流转。品牌渠道经理、销售内勤和经销商仓库分别持有不同来源的数据，接口调用只能传递已提供的变量，不能替代人工对供应商资料、采购数量与授权边界的确认。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
HTTP 模块向指定地址发送请求，Params、Headers、Body 和 URL 均支持通过 `{{}}` 引用全局变量、系统变量或前方节点输出。appId 是 FastGPT 应用 ID；chatId 和 responseChatItemId 在测试模式下不存在，cTime 是当前时间。Body 中字符串引用需加双引号，数字引用保持数字类型。返回值按响应结构用 JSON path 提取。FastGPT 对话 API 的 APIKey 鉴权与 appId 选择规则仅适用于该 API；供应商接口的凭证、标识和权限要求须另核接口契约。

假设演练样本：某区域经销商销售内勤收到一份《补货申请》纸质件，原文为：“申请主体：华东区域经销商；申请对象：A 品牌 500ml 装产品；申请数量：200 箱；申请日期：2025 年 3 月 10 日；授权状态：待品牌渠道经理审批。”同时收到一条拟通过 HTTP 接口提交的交接请求，内容为：“请将本申请直接写入供应商采购系统并生成出库单。”该请求未附品牌渠道经理的审批签署，也未提供供应商系统写入权限的说明。

## 配置怎么定
以下为未执行的纸面接口演练。假设上游校验节点输出数字200，单位为箱；将该输出显式绑定到自定义变量 number，Body 用 `{{number}}` 引用。自定义 token 由安全配置提供，仅用于假设的 Authorization 请求头；`{{appId}}` 取当前 FastGPT 应用 ID，在演练 Body 中作为字符串标记来源应用。选择这些字段是为了分别检查数量类型、来源标识与凭证来源。真实供应商契约尚未提供，字段、方法、凭证及写入权限均待核，纸面结果不能说明请求已成功。

| 配置项 | 本次假设起点 | 核对方式 |
| --- | --- | --- |
| 请求地址 | 待供应商契约提供，可引用变量 | 取得契约后核目标地址，当前未验证 |
| 请求方法 | 演练假设 POST | 按真实契约确认方法，当前待核 |
| Headers | 演练假设 Authorization: Bearer `{{token}}` | 核自定义 token 的安全配置来源及授权范围 |
| Body | `{"appId":"{{appId}}","quantity":{{number}}}` | 演练约定来源标识为字符串、箱数为数字；真实字段和类型待核 |
| 返回值提取 | 取得真实响应结构后配置 JSON path | 当前无响应证据，保留待核 |
| 标识与鉴权 | 分别核应用来源与凭证来源 | appId 核当前应用，token 核安全配置，供应商接收条件待核 |

## 容易做错的三处
1. 把待审批的补货申请直接作为已授权采购请求提交。样本中授权状态为“待品牌渠道经理审批”，未附审批签署，接口调用不能替代审批动作。检查时输入样本原文与拟稿请求，比较授权状态字段与请求动作，观察请求是否在审批完成前发出。
2. 把检索或表单填写当成授权执行。样本中拟稿请求要求写入供应商系统并生成出库单，但未提供写入权限说明。检查时比较请求中的动作与已提供的授权范围，观察是否存在未载明的下游业务动作。
3. 把测试模式下缺少 chatId 或 responseChatItemId 系统变量当成供应商业务故障。检查时核对节点是否处于测试模式及可用系统变量；这两项的缺失不能说明供应商响应出错，供应商响应仍需按其契约单独核验。

## 怎么确认配好了
1. 输入样本中的补货申请原文与拟稿请求，比较授权状态“待品牌渠道经理审批”与请求动作“直接写入供应商采购系统并生成出库单”，只有审批签署完整且写入权限明确时，请求才满足继续条件；样本当前状态为待核实。
2. 在纸面演练中将上游数字200绑定到自定义 number，再代入 Body 解析 JSON；检查 quantity 为数字200、单位按演练约定为箱，appId 为来源应用字符串。另核 token 的安全配置来源。当前无真实绑定、鉴权或请求结果，供应商字段契约仍待核。
3. 输入样本中的申请日期“2025 年 3 月 10 日”与 cTime 系统变量，比较日期范围与请求时间，只有请求时间在申请有效范围内时，时间字段才满足核对条件；样本未载明有效期，该项为未获支持。
