# 区域经销商库存补货的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在区域经销商库存补货的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。核区域、包装版本及样品与批量供货的区别，不用品牌同名代替对应关系。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

区域经销商补货查询，可用自拟南区申请“急需补入新版标签商品”，配北区周转表“旧版包装待调拨”。两个地区和包装版本同时影响问题范围。索引可分别围绕急需商品、待调拨物料建立索引，但原数据没有把北区旧货认定为南区替代品，也没有确认实际可调数量。问南区需求是否有对应供货资料时，应把地区、版本与所问对象一起核对，不由同一品牌名称合并成已有货可发的结论。

## 配置怎么定

| 实施核对项 | 本题材料 | 取证动作 |
| --- | --- | --- |
| 区域对应 | 南区申请与北区周转表 | 共同品牌不等于同一库存。 |
| 包装版本 | 新版标签与旧版包装 | 不自动视作可替代商品。 |
| 样品范围 | 样品可提供，批量待确认 | 引用保留阶段条件。 |
| 新增确认 | 南区新版供货单独留存 | 原需求比较实际来源。 |
| 索引复核 | 同名商品有地区和版本 | 查目标，不仅查入口名称。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 南区新版现货索引实际指向北区旧包装时，保存区域标识、包装版本和返回原文，定位错误映射。

- 样品可提供被写成批量交期已定时，对照供应方回复和实际引用，核“批量待确认”有没有丢失。

- 正确取回旧包装记录后，回答仍可能把它写成新版替代品。应另查支持替代的规格依据；有旧货和可替代南区需求是不同结论。

## 怎么确认配好了

取得南区新版供货确认后，核区域、包装版本和供货阶段，再用原需求问题比对新引用。申请、北区旧包装记录与供应方确认分别保存。

若仍返回旧记录，查新来源及索引目标；若回答提出替代，再核相应规格依据。同一检索节点关联多个区域库时核向量模型条件。资料更新不等于区域调拨已经执行。
