# 原产地证书申办的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在原产地证书申办的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。区分面料提供方、装运地点和来源说明，追查索引实际指向。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

原产资料关联供应商问答时，可以拟生产附件“由甲提供面料，产地说明另附”，配装箱单“在乙仓集中装运”。索引应保留提供方、材料本身和装运地点的不同角色，不能将甲的地址或乙仓所在地写成面料原产地。此处只设普通文字样例，不给出任何原产判定规则。分别问谁提供面料、是否取得产地说明、何处装运，核每个索引所指原文，明确现有资料实际能回答哪一问。

## 配置怎么定

| 实施核对项 | 本题材料 | 取证动作 |
| --- | --- | --- |
| 主体角色 | 面料提供方与装运仓 | 地址不自行变成原产地。 |
| 说明指向 | 面料产地说明另附 | 缺附件保留待补状态。 |
| 材料对象 | 面料与成品外套不同 | 不以产品介绍替来源说明。 |
| 索引映射 | 供应、材料、运输各有原文 | 逐项核目标身份。 |
| 新增依据 | 补入对应面料说明 | 同题核引用，不改旧记录身份。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 乙仓装运地点被写成面料生产地点时，并列装运原句、索引和答复，核地点角色在哪一环改变。

- 甲方成品外套介绍被用于面料来源问题时，核说明对象，不因名称相关就把成品介绍当成已取得的面料来源说明。

- 新增面料说明后仍只取回装箱单时，查新增原数据是否进入本题范围及其索引目标；未取回附件与取回后误读地点要分别定位。

## 怎么确认配好了

补入面料说明后，先核供应主体与具体材料，再以原问题查看新候选和引用。旧装箱单仍是装运材料，不因新附件存在就变成生产记录。

若未取回附件，核本题检索范围及索引目标；若取回后仍混用地点，核原句与答复。同一检索节点跨库关联需核向量模型条件。本页只检验资料定位，不据此给出原产结论。
