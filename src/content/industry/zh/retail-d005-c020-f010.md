# 原产地证书申办的库存采购与供应商资料：引用来源与溯源

## 这个品类的数据长什么样

在原产地证书申办的库存采购与供应商资料中，本页说明FastGPT的引用来源与溯源如何衔接资料。代理整理材料、生产地址和本批制造方并非同一来源结论。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

原产地资料关联采购自拟代理服务表“提供材料整理”、工厂介绍“列生产地址”和供货申请“本批制造方待确认”。问是否可向代理直接采购该厂货物时，服务表没有列商品销售，地址也未建立本批制造关系，申请尚待确认。引用应保留服务、地址与交易对象的区别，不能因代理处理过工厂资料就推定其供货，也不能从地址文字确定本批商品来源。

## 配置怎么定

| 采购溯源核对项 | 自拟材料与范围 | 取证动作 |
| --- | --- | --- |
| 代理角色 | 材料整理服务 | 核是否另有商品销售范围。 |
| 地址内容 | 仅列生产地址 | 不证明本批制造。 |
| 申请状态 | 制造方待确认 | 查本次确认结果。 |
| 货物关联 | 本批与工厂资料 | 核对应原文。 |
| 证据边界 | 角色定位不代证书结论 | 保留资料范围。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是材料整理服务被写成商品供应，应核代理实际服务或销售范围。第二处是工厂地址被当本批制造证明，应查对应货物的来源说明。第三处是申请待确认被写成制造方已定，应核本次确认结果及适用对象。三项分别核角色、货物关系和流程状态，不能用来源链接或公司名连成未提供的供货链，也不据这些片段作出证或合规结论。

## 怎么确认配好了

验收分别问代理服务提供什么、地址资料说明什么、本批制造方是否已确认，检查每项实际引用。答案应保留材料整理与待确认，采购关系仍需依据，不补实际供应。若数组只有工厂介绍，检查代理表和申请是否进入；空引用不证明各方没有关系。补入确认后核本批货物及主体，不把一笔确认推广到该地址全部产品，文件能定位也不能替代正文中应有的货物对应。
