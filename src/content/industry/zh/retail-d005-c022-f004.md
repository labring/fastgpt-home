# 品牌全渠道库存调拨的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在品牌全渠道库存调拨的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。跨渠道采购的借用货架、耗材补购和存放记录按物品用途建立索引。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

全渠道采购可拟申请“补购货架脚垫”、调拨页“架体借用”和存放便签“旧脚垫作样品保留”。草稿索引称“整架可售且脚垫有库存”。当前问是否可直接买整架和现有脚垫。原文分别是耗材需求、借用安排及样品保留，没有整架销售或脚垫可售库存。应核索引所指块的物品及用途，不把同一架有关材料拼成一份供货清单，也不从存放位置存在推样品可用于现实订单。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 架体用途 | 借用 | 不索引成销售。 |
| 脚垫需求 | 补购申请 | 不当库存记录。 |
| 样品地位 | 保留参考 | 不当可售。 |
| 部件关联 | 整架与脚垫 | 核实际指向。 |
| 供货依据 | 本次未给 | 保留待确认。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是架体借用被改写成可售，应核用途原文与关联块，不让索引改变交易类型。第二处是保留样品被写成可售库存，应读存放记录对象及实际供货资料，不从有物品推可采购。第三处是脚垫申请被整架旧索引覆盖，应对部件、申请和版本，核实际返回是否仍针对脚垫。三项分别查用途、库存状态和部件指向，不以向量分数或相似架名替业务确认。

## 怎么确认配好了

验收分别问想补什么、借用什么、样品为何保留，保存拟议索引、原块身份和引用。调整后用整架、脚垫及样品问法复测，核返回范围，不预设每种说法都能准确召回。没有供货资料时列待核，不推供应方不能销售。当前为文字测试，不核实物库存；模型或索引改变不执行采购、调拨或转所有权，真实商品可用与供货仍需独立适用证据。
