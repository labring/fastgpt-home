# 品牌售后维修服务的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在品牌售后维修服务的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。维修采购的借用工具、耗材和校验说明不能在索引中合并。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

品牌维修采购可拟工具页“检测笔为借用”、耗材页“探针帽可单购”和维护便签“校验记录另存”。草稿索引称“已校验检测笔成套销售”。当前问能否直接采购整套工具，原数据只写借用笔与单购帽，没有成套销售或校验结果。索引需按工具和耗材身份各回原块，不能把便签提到记录另存变成记录已存在且有效，更不从某工具用于检测就推其现实性能或资格。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 工具用途 | 借用 | 不索引成销售。 |
| 耗材组成 | 只有探针帽 | 不扩完整工具。 |
| 记录提示 | 另存未读 | 追查真实凭证。 |
| 对象版本 | 当前工具 | 核校验对应。 |
| 实际效果 | 没有设备测试 | 不承诺检测表现。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是借用被改写成销售，应比工具原句与拟索引，核交易用途没有变化。第二处是单购探针帽被拼成完整工具，应对部件组成和实际供货范围。第三处是校验另存被写成已校验，应追查记录身份、对象及版本，不能仅有便签便补结果。三项分别查用途、组成和凭证，检索相似或索引聚焦都不能确认实际工具状态，更不能让耗材页替工具供货证明。

## 怎么确认配好了

验收分别问借什么、卖什么、记录在哪里，保存索引、关联原文和真实引用。调整后同题核检测笔与探针帽返回来源，若只有耗材页，应说明整套供货和校验仍待核；没有返回记录不判从未校验。这里全为自拟文字，没有真实工具测试或设备连接。模型与索引变动只比较引用身份，不承诺适配或检测效果，也不执行借用转销售，实际采购需对应确认。
