# 品牌商场专柜运营的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在品牌商场专柜运营的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。专柜物料采购的画框、海报和陈列方向按不同原块索引。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

商场专柜采购可拟目录“空画框，海报另配”、陈列便签“本柜暂按横放”和供应回复“已收到竖放需求”。草稿索引写“竖款连海报已确认”。当前问能否按竖放成套订货。空框原文没有海报，横放是暂定陈列，收到需求也不证明竖款供应。需要区分物料组成、使用方向与供货动作，不能让索引把三份相关文字组装成目录没有的成套商品，也不从需求收件推最终规格。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 目录组成 | 空框 | 不加海报。 |
| 使用方向 | 暂横放 | 不当固定款式。 |
| 需求接收 | 竖放需求已收 | 不当供货确认。 |
| 原块关联 | 物料与陈列分开 | 核真实目标。 |
| 成套证据 | 当前未给 | 保留待核。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是空框被索引加上海报，应核目录组成及关联原块，不让另配消失。第二处是暂横放被写成固定横款商品，应对陈列便签与实物规格来源，摆放方向不自动定义商品。第三处是竖放需求收件被称竖款供货确认，应回读回复动作及实际确认，保留需求状态。三项分别查组成、用途和供货阶段，不用相近方向词或向量高分替对应规格。

## 怎么确认配好了

验收分别问框包含什么、便签规定哪项动作、供应方回复到了哪里，展开真实引用并保存索引目标。修改后横放与竖款同题复测，查看返回目录是否仍是空框，不预设精确匹配。若只返回陈列便签，列规格和供货依据待核，不反推不能竖放。当前无图片或实物测试；模型与索引变化不执行物料采购、不安装海报，也不证明现实陈列已获商场批准。
