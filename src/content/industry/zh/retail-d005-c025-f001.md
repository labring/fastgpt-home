# 品牌奥莱折扣运营的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样
品牌奥莱折扣运营以清理过季库存为目标，不维护新品正价形象。库存采购与供应商资料环节的主要数据来源是 ERP 库龄、POS 销售、奥莱商场活动与历史折扣，更新频率为周或月。日常文档包括折扣审批、滞销清单、价签和毛利测算表。这些材料在 HTTP 接口与外部系统环节需要被传递、核对与留痕，而接口本身只负责请求发送与返回值解析，不承担折扣审批、毛利核算或供应商资质认定。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
HTTP 模块向对应地址发送请求，Params 用于路径请求参数，Body 用于请求体，Headers 用于请求头。三种数据均可通过 `{{}}` 引用变量，变量来自全局变量、系统变量和前方节点输出。返回值需要配置 key 与 JSON path 提取，输出类型选字符串时会将对应值转为 json 字符串。系统变量中 chatId 与 responseChatItemId 在测试模式下不存在。对话接口调用时，model 与 temperature 等参数字段无效，由编排决定。传入 chatId 非空字符串时，使用该会话并从数据库取历史，messages 数组最后一个内容作为用户问题。detail=true 可返回 responseData 中间值。交互节点返回的 interactive 仅含 type 与 params，entryNodeIds 等内部运行态字段不返回。表单输入需将对象序列化为字符串作为 messages 内容，并保持 chatId 一致。插件调用无需 chatId 与 messages，通过 variables 传输入，非流式详细响应中，从 responseData 的 moduleType=pluginOutput 元素读取 pluginOutput。

假设演练样本：某品牌奥莱渠道清货组于 2025 年 3 月 10 日整理一批过季库存，供应商资料页记录“供应商编码 S-041，联系人已变更，最新对账周期为 2025 年 2 月”。同页附有一句拟稿：“该供应商已通过本季度折扣审批，可直接按新价签执行。”核对材料为上述两段原文，判定对象是“已通过本季度折扣审批”这一状态描述。

## 配置怎么定
下表围绕上述样本，列出与本功能、主任务相关的官方已说明设置或实施核对项。

| 配置项 | 本次假设试验起点 | 核对方式 |
| --- | --- | --- |
| 请求地址 | 外部供应商资料接口地址 | 地址可引用已提供的变量，按外部接口文档选择方法 |
| Headers 鉴权 | Authorization 头 | 凭证通过安全配置注入，不写入公开样例 |
| Body 结构 | 供应商编码与对账周期字段 | 仅在相应请求类型下使用，核对 JSON 结构与外部契约 |
| 变量引用 | 供应商编码来自前方节点输出 | 逐项核对实际传入值，与样本原文比对 |
| 返回值提取 | 按 JSON path 提取对账周期 | 输出类型选字符串时转为 json 字符串 |
| 调试身份 | chatId 在测试模式下不存在 | 不把调试空值当成业务故障 |

本次假设试验起点选择理由：样本涉及供应商编码与对账周期两个字段，需通过 Body 传入并提取返回值核对。比较对象为样本原文中的“S-041”与“2025 年 2 月”，若返回值与原文一致方可进入人工核对，不一致则记录差异。

## 容易做错的三处
1. 把接口返回值当作折扣审批已通过的证据。输入为供应商资料接口返回的对账周期，比较对象是样本原文“已通过本季度折扣审批”这一状态，接口返回值不包含审批状态字段时，该状态未获支持。
2. 在测试模式下将 chatId 空值判定为会话故障。输入为测试模式下的请求，比较对象是文档说明“测试模式下不存在”，观察结果为请求正常发送但无会话上下文，该现象属于文档已说明条件。
3. 将表单输入对象直接作为 messages 内容传递。输入为未序列化的对象，比较对象是文档要求“以对象形式并序列化成字符串”，观察结果为接口无法按预期解析，需按文档格式重新提交。

## 怎么确认配好了
1. 用样本原文“供应商编码 S-041，最新对账周期为 2025 年 2 月”作为输入，比较接口返回值中对应字段，若返回值与原文一致则通过；若返回值缺失或不同，记录差异并保留原文。
2. 用拟稿句“该供应商已通过本季度折扣审批”作为待判定内容，比较样本原文是否包含审批状态字段，若原文未载明则判定为未获支持，不因接口调用成功而视为审批通过。
3. 用 detail=true 发起请求，比较 responseData 中是否包含所需中间值，若返回结果中无对应模块状态，则记录为待核实，不推断为失败原因。空结果可用明确的纸面输入 `[]` 核对下游设计，不声称虚构规则检索一定返回空。
