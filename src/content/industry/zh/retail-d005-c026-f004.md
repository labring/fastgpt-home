# 品牌直营门店运营的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在品牌直营门店运营的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。直营门店的工牌底板、姓名贴和岗位名单按用途保持索引范围。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

直营门店采购可拟工牌页“空白底板”、贴纸页“姓名文字需另确认”和岗位便签“临时陈列协助”。草稿索引写“店长工牌成品”。当前问是否已可采购刻好姓名的店长牌。空板没有姓名，待确认贴纸不构成成品，临时协助也不说明店长职务。应按物料、文字和人员角色各核原数据，不因都属于门店物料就将索引组合成正式身份或已完成制作，更不能从岗位便签推系统授权。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 物料状态 | 空白底板 | 不写已印姓名。 |
| 文字确认 | 姓名待核 | 保留未制作。 |
| 岗位含义 | 临时协助 | 不提升店长。 |
| 门店归属 | 别店印牌 | 核姓名及版本。 |
| 现实行动 | 无授权与采购 | 不称已执行。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是空白底板被索引加姓名成品，应核文字确认及组成来源，保留未制作条件。第二处是临时协助被写成店长，应查角色便签与人员身份，不由工牌名称决定职务。第三处是另一店已印牌索引回指被当前材料采用，应对门店、姓名和版本，不能以同款底板移用。三项分别查成品状态、角色含义和来源归属，检索命中不证明岗位或真实制作已经完成。

## 怎么确认配好了

验收分别问底板提供什么、姓名处于何种状态、便签说明何种任务，展开真实引用及索引关系。修改后同题看空板与成品牌的返回，不保证命名别称都精确命中。若只有空板页，列姓名和当前角色依据缺项，不推无法制作或用户已经被拒。当前无真实人员资料或制作测试，模型与索引变动不改岗位、不授权限或下采购单，实际成品仍需适用确认。
