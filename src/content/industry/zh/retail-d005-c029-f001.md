# 售后维修与补寄的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样

售后维修与补寄围绕恢复商品使用展开，结案方式落在维修完成或配件补寄到位，直接退款属于另一类处理路径。资料来自售后系统、订单系统、维修网点与配件仓WMS，日常文档包括维修申请、补寄单、检测报告与配件出库单。库存采购与供应商资料这一任务，处理的是配件需求如何转为采购记录、供应商资料如何随单流转。

数据更新频率为每单与日。这一频率只说明资料给出的事实，不推出批量同步、全量同步或交易触发机制。HTTP 接口在本任务中承担与外部采购或供应商系统交换请求与响应的角色，接口调用本身不改变任何采购或供应商状态。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向对应地址发送请求，Params 用于路径请求参数，Body 用于请求体，Headers 用于请求头。三者均可通过 `{{}}` 引用变量，URL 同样可以引用变量。变量来源为全局变量、系统变量与前方节点输出。系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories，其中 chatId 与 responseChatItemId 在测试模式下不存在。返回值通过 JSON path 语法提取，出参可选择字符串类型，将对应 key 的值转为 json 字符串输出。

对话接口使用 APIKey 鉴权，调用 chat/completions 时推荐在请求体传入 body.appId，也支持 `Authorization: Bearer <apiKey>-<appId>`。传入的 model、temperature 等字段无效，由编排决定。detail=true 时返回中间值，responseData 保存完整结果。交互节点返回的 interactive 只含 type 与 params，entryNodeIds、memoryEdges、nodeOutputs、nodeResponseId 等内部运行态字段不会返回。表单收集的是值，业务核验、审批、数据库写入与外部同步需要各自的下游实现。检索与相似度不承担授权或实体过滤职能。

假设演练样本：一份配件采购交接材料原文为「维修申请 WX-0417，机型 A2，故障件为电源模块，检测报告结论为需更换，配件出库单尚未生成，采购申请处于待审核」。一条待判定的拟稿句为「该采购申请已批准，可向供应商下单」。材料中主体为维修申请与采购申请，对象为电源模块，状态为待审核，未载明批准记录与下单授权。

## 配置怎么定

| 配置项 | 本页取值或核对项 | 说明 |
| --- | --- | --- |
| 请求地址与方法 | 按外部采购或供应商接口文档选择，地址可引用已提供的变量 | 地址与方法来自外部接口契约 |
| Params 与 Headers | 分别核对请求参数与请求头，鉴权凭证通过安全配置注入 | 公开样例不写入凭证 |
| Body | 仅在相应请求类型下使用，核对 JSON 结构与外部接口契约 | 引用字符串需加引号，数值与布尔不加 |
| 变量引用 | 逐项核对全局变量、系统变量与前方节点输出的实际传入值 | 引用来源限于文档所列三类 |
| 调试身份字段 | chatId 与 responseChatItemId 在测试模式下不存在 | 不把调试空值当成业务故障 |
| 出参提取 | 按 JSON path 语法配置 key，输出类型选字符串时转为 json 字符串 | 提取规则遵守 JS 对象取值规则 |

本页假设试验起点：将待审核采购申请作为一次请求的输入对象，选择该起点是因为样本材料明确处于待审核状态，便于与批准后的记录做同字段比较。该起点为本次假设设定，不是官方默认值。

## 容易做错的三处

1. 把待审核状态读成已批准。样本材料写「采购申请处于待审核」，拟稿句写「已批准，可向供应商下单」。待审核不等于批准，批准记录缺失时该句未获支持。
2. 把接口调用当成采购执行。HTTP 模块发送请求并解析返回值，返回的字段只是响应内容，不构成下单、审批或入库动作。
3. 把相似度或检索结果当成授权依据。相似度分值不承担实体或权限过滤，检索命中不表示该采购申请已获授权。

## 怎么确认配好了

1. 输入样本材料原文与拟稿句，比较材料中的状态字段与拟稿句的表述。材料写待审核，拟稿句写已批准，两者在同一字段上取值不同，拟稿句不成立。预期观察为状态字段不一致。
2. 输入一次请求配置，比较引用变量的来源是否属于全局变量、系统变量或前方节点输出。若引用了文档未列出的来源，该引用无法解析。预期观察为变量来源不在文档所列范围。
3. 输入一次 detail=true 的响应，比较 responseData 中模块返回字段与外部接口契约。若响应中缺少契约要求的字段，该次交互的提取结果不完整。预期观察为字段缺失，具体缺失项以实际响应为准。
