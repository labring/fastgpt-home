# 售后维修与补寄的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在售后维修与补寄的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。维修补寄采购的盖片、装饰环和功能说明按部件位置索引。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

补寄采购可拟清单“背面防尘盖片”、图例文字“装饰环另列”和维修便签“盖片不含锁扣”。索引草稿称“带锁装饰环总成”。当前问是否能采购带锁总成。原数据分开列盖片与装饰环，且没有锁扣，位置与功能都需保留。拟索引不能从盖片会覆盖开口推自带锁紧结构，也不能因图例同页出现装饰环就合成一个完整部件。这里图例仅为自拟文字说明，不预定图片已入库或视觉可检索。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 部件位置 | 背面盖片 | 不接正面旧款。 |
| 功能排除 | 无锁扣 | 索引不可新增。 |
| 装饰部件 | 环另列 | 不自动成总成。 |
| 图例身份 | 普通文字描述 | 不推图片链。 |
| 实际采用 | 组合依据未给 | 保留待核。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是盖片索引新增锁扣，应对原数据排除及拟索引组成，标出不支持功能。第二处是装饰环与盖片被合成总成，应核部件清单和组合确认，不因位置相邻就认同套。第三处是旧正面盖索引被当前背盖问题采用，应核位置、部件身份和版本。三项分别查功能、组成和对象指向，不用向量分数证明物理结构相同，也不以更换模型补缺失部件事实。

## 怎么确认配好了

验收分别问盖片位于哪里、含不含锁扣、装饰环如何列，保存真实引用及其索引关系。修改后同题核背盖与带锁总成，查看原文限定是否仍在，不承诺精确匹配。缺总成资料时保留待核，不判供方不能制作。当前没有实物或图片路径测试；实际若要图片检索须另核入库条件。本页不创建补寄单或采购，也不证明现实维修已恢复功能，采用仍需对应资料。
