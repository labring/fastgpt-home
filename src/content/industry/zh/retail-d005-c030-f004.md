# 商超供应商进场结算的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在商超供应商进场结算的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。供应商采购的外箱描述、内袋清单和确认附件按包装层级索引。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

商超采购可拟目录“外箱贴白标”、内袋页“透明袋无印字”和确认邮件“仅确认外箱描述”。索引草稿写“内外包装均已确认印白标”。当前问所有包装是否都按白标供货。原数据明确不同包装层级，邮件只确认外箱，不能由同一商品或同一邮件主题推全部层级已确认。应把索引回指到具体块，保留内袋无印字与邮件仅确认，不让索引把颜色、印字和确认范围混成一条新规格。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 包装层级 | 外箱与内袋 | 属性分别对应。 |
| 印字条件 | 内袋无字 | 不写白标。 |
| 确认范围 | 仅外箱 | 索引保留限定。 |
| 旧袋来源 | 印字历史页 | 核版本与版式。 |
| 实际采用 | 整体未确认 | 列待核不判拒供。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是外箱白标被索引移到内袋，应对层级及原文属性，找出跨对象添加。第二处是仅确认外箱被写成内外全确认，应核邮件确认对象与实际附件，不由标题概括范围。第三处是旧印字袋来源被当前透明无字袋采用，应核材料、版式及版本。三项分别查包装层级、确认范围和原块身份，不以向量分数或供应商名称相同证明同一规格。

## 怎么确认配好了

验收分别问外箱、内袋和邮件确认覆盖什么，查看实际引用与索引目标。修改后同题核白标与无印字袋问法，记录返回是否保留层级限定，不承诺每问都精确。若只取外箱页，列内袋及整体确认待核，不推不符合或供货已拒。当前为自拟文字，没有真实包装、到货或图片验证；模型与索引调整不下采购单，也不决定验收或结算结果，实际采用需对应确认。
