# 商超塑料袋与一次性用品报告的库存采购与供应商资料：文档解析与分块

## 这个品类的数据长什么样
商超塑料袋与一次性用品报告围绕一次性塑料制品报告与环保监管展开，主要数据来源包括商务部报告系统、POS塑料袋销售、采购系统和门店台账。该品类最耗时的环节是统计使用量、核对销售凭证和报送回收情况，日常文档包含塑料袋采购台账、销售凭证、半年报告和自律承诺。库存采购与供应商资料这一任务中，材料通常以采购台账、供应商资质文件和销售凭证的形式存在，解析与分块需要同时保留台账中的数量、日期、供应商名称，以及凭证中的销售明细。半年报告与日更销售数据并存，材料结构差异较大，分块时须按各自结构处理。

## 这些特征在「文档解析与分块」这一环带来什么约束
采购台账与供应商资料常以表格或条目形式出现，段落拆分须保留表头与对应行、供应商名称与所供品类、日期与数量范围的绑定关系。销售凭证多为逐笔记录，分块后应能回指原始凭证的编号与日期。半年报告和自律承诺属于汇总或声明类材料，分块时应保持其完整语义单元，避免将承诺条件与所约束内容拆离。

原数据与检索索引须区分：一组原数据可对应多个索引，检索时先召回向量再按向量 ID 回查原数据并合并。混合检索通过 RRF 融合语义与全文结果，重排须具备模型并按设置启用，图片检索须有图像输入及相应模型能力，这些路径并非每次请求全部执行。语义召回与相关度不负责权限或实体隔离，检索库同向量模型要求不能扩展为外部系统也须同模型。跨不同向量模型的库不可共同关联，只核标识并排除不符合者。

## 配置怎么定
以下设置与实施核对项围绕本页文档解析与分块任务。假设演练样本：某门店采购台账原文三句——“2025年3月1日，本店向甲供应商采购一次性塑料袋2000个，用于生鲜区包装。同月5日，向乙供应商采购一次性手套500副。上述采购均记入门店台账编号CG-202503。”一条待判定拟稿句：“甲供应商的塑料袋采购已通过环保合规审核。”该拟稿句未在原文中出现审核主体、审核日期或审核结论，属待核实，不能判定为已通过。

| 配置项 | 假设试验起点 | 理由与比较方法 |
| --- | --- | --- |
| 分块粒度 | 按台账单条记录分块 | 与整表分块比较，检查表头与行是否保持绑定 |
| 引用上限 | 本次假设试验起点设为覆盖三条记录的量 | 与仅覆盖一条记录的值比较，观察汇总问题是否召回完整 |
| 最低相关度 | 本次假设试验起点设为中等值 | 与更低值比较，核对低相关片段是否被过滤 |
| 搜索模式 | 混合检索 | 与单独语义检索比较，核对编号类查询命中情况 |
| 问题优化 | 开启 | 与关闭比较，观察短问题或追问的召回差异 |
| 更新后复核 | 上传后执行样本检索 | 与仅确认上传成功比较，核对训练与索引状态 |

## 容易做错的三处
1. 将采购台账中甲供应商的记录与拟稿句“已通过环保合规审核”直接关联。输入为台账原文与拟稿句，比较两者是否含同一审核主体、日期与结论，观察结果是原文未载明审核事实，判定应为待核实。
2. 把表格分块后表头与数据行拆离。输入为含表头的台账表格，比较分块结果是否保留表头与行的对应，观察结果是行内容失去字段含义，检索时无法回指数量与日期。
3. 将上传成功当作检索已更新。输入为上传操作记录，比较是否执行样本检索并核对训练与索引状态，观察结果是未执行检索时无法确认新内容可被召回。

## 怎么确认配好了
1. 输入台账原文三句与拟稿句，比较拟稿句是否含审核主体、日期与结论，观察结果为原文未载明，判定待核实，不判为通过。
2. 输入台账表格分块结果，比较表头与数据行是否绑定，观察结果为绑定保留，检索可回指数量与日期，满足条件。
3. 输入更新后的样本检索请求，比较检索结果是否包含新上传内容，观察结果为样本检索命中新内容且索引状态已更新，满足条件；未命中或状态未知时记录缺口。

空结果可用明确的纸面输入[]核对下游设计，不声称虚构规则检索一定返回[]。待审核不证明缺少操作权限，签署、合作达成与合同生效是三个不同事实。授权状态须按材料、操作与请求分别记录，检索或表单不构成授权执行。
