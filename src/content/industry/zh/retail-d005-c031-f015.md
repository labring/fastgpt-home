# 商超塑料袋与一次性用品报告的库存采购与供应商资料：知识库检索与召回

## 这个品类的数据长什么样

该品类围绕一次性塑料制品报告与环保监管展开，主要数据来源包括商务部报告系统、POS 塑料袋销售、采购系统与门店台账。日常要处理的文档为塑料袋采购台账、销售凭证、半年报告与自律承诺。这些资料分属不同主体与不同期间：采购台账记录供应商、进货数量与日期，销售凭证记录门店零售，半年报告汇总使用量与回收情况。检索环节面对的是多份来源不同、字段口径不同的材料，需要按主体、对象、期间与状态逐项核对，不能把销售数量直接当作采购数量，也不能把某一门店的台账当作总部汇总。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，需先核对向量模型标识，排除不符合者，记录实际观察。搜索模式可选语义检索、全文检索或混合检索，混合检索通过 RRF 融合多路结果，RRF 是融合过程，不是可开启的独立开关。引用上限以 token 为单位控制每次搜索引用的内容量。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值，不是排序规则，也不承担权限或实体隔离功能。问题优化用于指代消除与问题扩展，会额外调用模型。引用内容以数组输出，长度可以为 0，空结果链路仍走通。图片检索需要相应图像输入与模型能力，重排需要具备模型并按设置启用，可选路径不代表每次请求全部执行。检索本身不构成授权，表单收集值，业务核验、审批、数据库写入与外部同步需要各自的下游实现。

假设演练样本：材料原文为“甲方某某连锁超市有限公司与乙方某某塑料制品厂于假设日期签订年度供货意向，约定乙方按甲方月度订单供货，订单经甲方采购负责人书面确认后生效；本意向不构成最低采购量承诺。”待判定拟稿句为“乙方已取得本年度全部供货授权，甲方须按月收货。”核对点在于：意向书是否已转为生效订单、是否有采购负责人书面确认、授权范围是否覆盖全部供货。样本中未载明确认记录与订单编号，该拟稿句未获支持，属待核实。

## 配置怎么定

| 配置项 | 本页取值或核对项 | 依据与说明 |
| --- | --- | --- |
| 关联知识库 | 仅关联向量模型标识一致的采购台账库与供应商资料库 | 节点要求相同向量模型，跨模型不共同关联 |
| 搜索模式 | 本次假设试验起点为混合检索，与全文检索结果比较 | 编号、供应商名称类查询观察全文命中差异 |
| 引用上限 | 本次假设试验起点为 2000 token，与 1000 token 结果比较 | 单位为 token，按台账段落长短观察引用完整性 |
| 最低相关度 | 本次假设试验起点为 0.3，与 0.5 比较 | 仅在语义检索或重排时生效，先标注相关与无关样本 |
| 问题优化 | 多轮追问场景开启，单轮明确问题关闭对照 | 用于指代消除与问题扩展，增加一次模型调用 |
| 结果重排 | 按设置启用，核对是否具备重排模型 | 重排得分 0-1，可按得分过滤 |

## 容易做错的三处

1. 把意向书当作已生效供货授权。样本原文只写明订单经采购负责人书面确认后生效，未载明确认记录，拟稿句称已取得全部供货授权，属未获支持。检查动作：输入拟稿句与原文，比较授权状态字段，观察是否出现书面确认记录；无记录时判定待核实。
2. 把最低相关度当作权限过滤。最低相关度只过滤低相关度结果，不排除未授权记录。检查动作：输入一条涉及其他供应商的查询，比较返回内容与访问权限清单，观察是否仍返回该记录；返回即说明过滤未承担隔离。
3. 把 RRF 当作可开启开关。RRF 是混合检索的结果融合过程，文档未提供独立开关。检查动作：核对配置界面是否存在该开关字段，比较实际可配置项与文档描述，观察字段缺失即记录为不可配置项。

## 怎么确认配好了

1. 授权状态核对。输入假设样本原文与拟稿句，比较授权状态与书面确认字段，观察拟稿句所称授权是否在原文中有对应记录；无记录时输出待核实，不判定为已授权。
2. 空结果承接核对。输入纸面空数组 [] 作为引用内容，比较下游节点是否正常走通，观察链路是否因空结果中断；文档说明长度可以为 0 且链路走通。
3. 跨模型关联核对。输入两个向量模型标识不同的知识库，比较标识是否一致，观察是否被排除在共同关联之外；仅记录标识核对结果，不执行跨模型检索比较漏召回。
4. 问题优化主体核对。输入含指代的多轮问题，比较优化后问题与原文主体，观察主体是否被改错；主体改变时记录偏差，不据此推断检索失败原因。
5. 引用上限完整性核对。输入长短不同的台账段落，比较不同上限下的引用内容，观察长段落是否被截断；截断时记录实际观察，不声称某数值为官方默认。
