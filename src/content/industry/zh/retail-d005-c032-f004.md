# 商超收银与会员促销的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

在商超收银与会员促销的库存采购与供应商资料中，本页说明FastGPT的向量模型与索引如何衔接资料。收银物料采购的样券、空白卡和核销说明按用途建立索引。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

商超收银采购可拟样券页“仅供版式确认，不用于核销”、空白卡目录“不含会员信息”和便签“实际券规则另核”。草稿索引称“可核销会员优惠卡成品”。当前问能否直接采购并投入活动。样券没有核销用途，空卡没有会员内容，规则也没给，不能因都属于收银物料就合成成品权益。索引应保留原数据中的用途限制及缺项，不能把版式确认扩大为规则确认，也不自行加优惠值或价格。

## 配置怎么定

| 原数据与索引核对 | 具体对象关系 | 验收动作 |
| --- | --- | --- |
| 样券用途 | 只确认版式 | 不当可核销。 |
| 卡片内容 | 空白无会员 | 不加已绑定。 |
| 规则状态 | 另行核实 | 不推活动启用。 |
| 关联原块 | 样券与空卡分开 | 查看真实目标。 |
| 业务执行 | 无发券核销操作 | 不称已完成。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是版式样券被索引写成可核销，应核不用于核销原句与关联块。第二处是空白卡被加会员信息，应对目录组成和当前制作资料，不从卡片名称推已绑定身份。第三处是另核券规则被写成活动已可执行，应查真实规则与适用版本，不能以索引完整替规则。三项分别查用途、内容和业务依据，不用向量命中证明实际权益或系统可以核销。

## 怎么确认配好了

验收分别问样券可做什么、空卡含什么、活动仍缺什么，展开实际引用并保存索引目标。修改后同题核版式与核销问法，检查是否回到有排除条件的原文，不保证精确匹配。若只返回空卡页，列会员信息和规则缺项，不推供应方拒绝制作。当前全为自拟文字，无真实会员数据或收银测试；模型与索引改变不采购、不发券或绑定会员，也不宣称真实促销已启用。
