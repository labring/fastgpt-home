# 外汇收结汇与贸易名录的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样
收结汇与贸易名录场景关注外汇资金与贸易背景真实性，不审全套信用证单据。库存采购与供应商资料环节的材料来源包括收汇水单、贸易合同、发票、外汇业务登记资料，更新频率为每单与每月。这些材料进入 HTTP 接口时，主体名称、合同编号、发票号、登记凭证状态共同构成核对基础。外部系统返回的字段需与上述材料逐项对应，接口本身不完成贸易背景真实性判断。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
HTTP 模块向目标地址发送请求，Params 用于路径参数，Body 用于 POST/PUT 请求体，Headers 传递特殊信息。三种数据均可通过 {{}} 引用变量，变量来自全局变量、系统变量、前方节点输出。系统变量包含 appId、chatId、responseChatItemId、variables、cTime、histories；histories 默认最多取 10 条，长度不可修改。chatId 与 responseChatItemId 在测试模式下不存在。返回值通过 JSON path 提取，输出类型选字符串时按 json 字符串格式化。对话接口以 APIKey 鉴权，调用 chat/completions 时推荐在请求体传入 body.appId，也支持 Authorization: Bearer <apiKey>-<appId>。传入的 model、temperature 等字段无效，由编排决定。detail=true 时返回中间值，非 stream 模式结果保存在 responseData；不会返回实际消耗 Token 值，需手动计算 responseData 里的 tokens。authProxy 代理团队成员身份需团队所有者开启，代理身份仍需具备目标应用和会话权限。检索与相似度不承担权限或实体隔离职责，检索不构成授权。

假设演练样本：某外贸企业财务人员提交一份库存采购与供应商资料交接请求。供核对材料原文为：“供应商甲于 2025 年 3 月 10 日签订采购合同 HT-2025-031，合同金额 12 万美元；对应收汇水单 SW-2025-041 显示 2025 年 4 月 2 日到账 12 万美元，付款方名称为 Supplier-A Trading；发票 INV-2025-018 开票日期 2025 年 4 月 5 日。”待判定拟稿句为：“该笔收汇已核对供应商主体与合同金额，可办理结汇。”该请求涉及主体、对象、日期与金额范围，授权边界为提交核对，未包含结汇执行授权。

## 配置怎么定
| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 请求地址 | 按外部接口文档填写，可引用 {{BaseUrl}} | 与接口文档给出的路径逐字符比较 |
| 请求方法 | POST | 与外部接口契约声明的方法比较 |
| Headers 鉴权 | Authorization 引用已配置变量 | 与密钥使用规范要求比较，凭证不写入公开样例 |
| Body 结构 | 按外部接口契约构造 JSON | 与对方字段名、类型逐项比较 |
| 返回值提取 | 按 JSON path 配置 key | 与接口响应示例结构比较 |
| 输出类型 | 字符串 | 与下游文本加工所需格式比较 |

以上数值为本次假设试验起点，不属官方默认值。配置前需确认外部接口文档、鉴权方式与返回结构，未提供文档的字段保持未知。

## 容易做错的三处
1. 将检索或相似度结果当作授权依据。输入为检索返回的供应商记录，比较对象为交接请求中的授权边界，观察结果是检索命中不改变授权状态。检索不构成授权，业务验证与数据库写入需下游实现。
2. 将测试模式下 chatId 与 responseChatItemId 不存在当作业务故障。输入为测试模式请求，比较对象为文档说明的测试模式字段缺失条件，观察结果是该缺失属文档载明情形。
3. 将待审核状态当作已获授权。输入为交接请求中的提交状态，比较对象为签署、合同生效、结汇执行三类事实，观察结果是待审核不证明缺少操作权限，也不等于执行完成。

## 怎么确认配好了
1. 输入假设样本中的材料原文与拟稿句，比较拟稿句是否超出材料载明的授权边界，观察结果是拟稿句声称可办理结汇而材料仅支持提交核对，判定为待核实。
2. 输入假设样本中的供应商名称、合同编号与收汇水单付款方名称，比较三者是否指向同一主体，观察结果是 Supplier-A Trading 与供应商甲的名称对应关系未在材料中载明，判定为未获支持。
3. 输入假设样本中的合同金额 12 万美元与收汇水单到账 12 万美元，比较同期间同字段取值，观察结果是两者一致；发票 INV-2025-018 与合同编号的关联关系未在材料中载明，该部分保持缺失。
