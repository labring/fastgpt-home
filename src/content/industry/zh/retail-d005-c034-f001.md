# 外贸出口退税申报的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样

外贸出口退税申报在货物出口后做税务凭证匹配，库存采购与供应商资料围绕进货发票、出口报关单、收汇凭证展开，数据按月或每批更新。HTTP 接口与外部系统这一环，需要把采购入库单、供应商开票信息、报关单编号等字段，通过请求发送到外部系统，再把返回值解析回本流程。典型从业主体是外贸企业财务、税务会计和单证员，出错的后果是退税延迟、不得退税或税务风险。因此，接口请求里的主体、对象、状态和有效范围必须逐项核对，不能把表单填写或检索命中当成业务授权。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向对应地址发送请求，Params 为路径请求参数，Body 为请求体，Headers 为请求头，三者均可用 `{{}}` 引用变量，变量来自全局变量、系统变量和前方节点输出。URL 也可引用变量。返回值通过 JSON path 提取，输出类型选择字符串时会把对应 key 的值转成 json 字符串。系统变量中 chatId 与 responseChatItemId 在测试模式下不存在，调试时出现的空值属于调试态，不能判定为业务故障。对话接口的 `model`、`temperature` 等参数字段无效，由编排决定；`detail=true` 时可从 responseData 手动读取 tokens。交互节点返回的 interactive 只含 type 和 params，entryNodeIds、memoryEdges、nodeOutputs、nodeResponseId 等内部运行态字段不会返回。表单输入需要把对象序列化成字符串作为 messages 内容，并确保 chatId 一致。检索与相似度只影响返回内容，不承担权限或实体隔离，检索不是授权。

假设演练样本：某外贸企业财务在 2025 年 3 月处理一批出口货物，拟通过 HTTP 模块把采购入库信息发送到外部供应商系统。供核对的材料原文为：“采购入库单号 RK-2025-0312，供应商名称为宁波某贸易有限公司，进货发票号码 04412345，开票日期 2025 年 3 月 10 日，货物已入库，金额 86000 元。”待判定的拟稿句为：“该批采购已完成退税申报，供应商资料已通过审核。”该拟稿句中的“已完成退税申报”与“已通过审核”没有出现在材料原文中，属于未获支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 请求地址 | 外部供应商系统提供的采购入库接口地址 | 与外部接口文档逐字核对，地址中可引用已提供的变量 |
| 请求方法 | POST | 与外部接口契约比较，Body 仅在相应请求类型下生效 |
| Headers 鉴权 | Authorization 引用安全配置中的凭证 | 凭证不写入公开样例，与接口文档要求的头字段比较 |
| Body 字段 | 入库单号、供应商名称、发票号码、开票日期、金额 | 与材料原文逐字段对照，确认字段名和值类型一致 |
| 返回值提取 | 按 JSON path 提取业务状态字段 | 与接口响应示例比较，确认提取路径存在 |
| chatId 处理 | 本次试验使用固定会话标识 | 与接口要求比较，确认非空且长度小于 250 |

## 容易做错的三处

1. 把检索命中或表单填写当成授权执行。输入是供应商名称“宁波某贸易有限公司”，比较对象是材料原文中是否载明授权或审核结论，观察结果是原文没有出现“已通过审核”，因此该拟稿句未获支持。
2. 把调试态空值当成业务故障。输入是测试模式下 chatId 与 responseChatItemId 不存在，比较对象是文档说明的测试模式条件，观察结果是空值属于调试态，不能判定为业务数据缺失。
3. 把交互节点返回的展示配置当成内部运行态。输入是 interactive 只含 type 和 params，比较对象是文档列出的 entryNodeIds、memoryEdges、nodeOutputs、nodeResponseId 不返回，观察结果是这些字段缺失属于接口设计，不能据此推断工作流异常。

## 怎么确认配好了

1. 输入材料原文中的入库单号 RK-2025-0312 与发票号码 04412345，比较 Body 中对应字段值是否与原文逐字一致，观察结果是字段值一致且无多余推断。
2. 输入拟稿句“该批采购已完成退税申报，供应商资料已通过审核”，比较材料原文是否载明退税申报完成与审核通过，观察结果是原文未载明，该句未获支持，需记录证据缺口。
3. 输入外部接口返回的 JSON 响应，比较配置的 JSON path 提取结果与响应实际结构，观察结果是提取值存在且类型符合预期；若响应中该路径不存在，则记录为待核实，不推断为接口故障。
