# 外贸退运与索赔的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

退运与索赔处理出口后的逆向物流与责任认定，资料来自客户邮件、质检报告、海关记录和保险理赔材料。退运协议、索赔函、质量报告和退运报关单每案更新，格式不统一，同一批货物可能同时存在采购合同、质检结论和退运申报文本。向量模型与索引需切分并建立索引，使检索能定位到具体材料段落，供人工核对。

## 这些特征在「向量模型与索引」这一环带来什么约束

知识库搜索以库为最小搜索单位，集合仅用于分类管理，与搜索效果无关。向量检索由 PostgresSQL 的 PG Vector 插件承担，索引为 HNSW；MongoDB 的 dataset.datas 表存储向量原数据，其中 indexes 字段记录对应的向量 ID，为数组，一组数据可对应多个向量。检索时先召回向量，再按向量 ID 回 MongoDB 找原数据，同一组原数据被多路命中则合并，向量得分取最高分。

关联检索的知识库须使用相同向量模型，选择多个知识库时先核实际模型与输入类型，跨不同向量模型的库不可共同关联。语义检索依赖向量距离，适合自然语言问法；全文检索依赖关键词命中，适合编号、型号、专有名词。混合检索同时使用两者并通过 RRF 融合。重排须具备 ReRank 模型并按设置启用，重排后得到 0-1 得分。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值。引用上限以 tokens 计量。检索或表单不构成授权执行，语义召回和相关度不负责权限或实体隔离。节点输出为数组，长度可以为 0。

假设演练样本：以下内容为本次纸面核对构造，不来自任何真实客户或系统记录。

材料原文一（退运协议片段）：“甲方于二〇二四年三月十二日就批次 W2403 的退运事宜与乙方签署本协议，退运原因为到货检验发现外观尺寸超差，退运数量为三百件。本协议自双方签署之日起生效。”

材料原文二（索赔函片段）：“我司就批次 W2403 提出索赔，索赔金额依据第三方质量报告确定，随附报告编号 QC-2403-17。本函提交日期为二〇二四年四月二日，尚待贵方书面确认。”

待判定拟稿句：“批次 W2403 的退运已完成，索赔已获对方确认。”

材料原文一显示协议已签署生效，未载明退运完成；材料原文二显示索赔函已提交并待确认。签署、提交、完成、确认是不同事实，拟稿句的“已完成”与“已获确认”均未获支持。

## 配置怎么定

| 核对项 | 输入 | 比较与观察 |
| --- | --- | --- |
| 向量模型一致性 | 待关联的多个知识库标识 | 模型标识一致才可共同关联，不一致者排除，记录实际观察 |
| 索引与原数据对应 | dataset.datas 中 indexes 字段 | 一组原数据可对应多个向量，索引与原文内容分别核对 |
| 索引内容长度 | 针对 W2403 材料建立的索引文本 | 索引更短更聚焦时检索精度提高，检索范围相应收窄 |
| 图片索引 | 入库时是否生成图片描述或图片向量 | 查询端上传图片不足以命中，须核入库索引是否建立 |
| 引用上限 | 每次搜索最多引用的 tokens 数 | 本次假设试验起点设为 2000 tokens，与 1000 tokens 起点比对引用完整度 |
| 最低相关度 | 0-1 数值 | 仅在语义检索或结果重排时生效，本次假设试验起点设为 0.3，与 0.5 比对召回条数 |

## 容易做错的三处

1. 把待确认当作已确认。索赔函原文写“尚待贵方书面确认”，拟稿句写“索赔已获确认”；输入为索赔函原文，比较“待确认”与“已确认”，观察为状态不一致，属未获支持。
2. 把签署生效当作退运完成。退运协议原文写“自双方签署之日起生效”，未载明退运完成，拟稿句写“退运已完成”；输入为协议原文，比较协议生效与退运完成，观察为原文未载明完成状态，属证据缺口。
3. 把跨模型知识库强行共同关联。输入为两个知识库的模型标识，比较两标识是否一致，观察为标识不一致时排除后者，不执行跨模型检索来比较漏召回。

## 怎么确认配好了

1. 用材料原文一作为输入，检查检索是否返回该退运协议片段。比较返回内容与原文“二〇二四年三月十二日”“批次 W2403”“三百件”是否一致。观察结果满足条件为返回片段包含上述要素；若返回为空数组或要素缺失，记录为未命中并检查索引是否已建立。
2. 用材料原文二作为输入，检查检索是否返回索赔函片段。比较返回内容是否含“QC-2403-17”与“尚待贵方书面确认”。观察结果满足条件为两项均出现；若仅出现报告编号而未出现待确认表述，记录为部分命中，不得据此判定索赔已确认。
3. 用待判定拟稿句作为输入，检查拟稿句两项事实。比较拟稿句“已完成”“已获确认”与两份原文的载明状态。观察结果满足条件为拟稿句仅保留原文支持的事实；若拟稿句含未载明事实，记录为未获支持，保留证据缺口。

空结果承接可用明确的纸面输入 [] 核对下游设计。模型或索引调整后，用同组问题比对引用原文，不根据向量分数单独承诺效果。
