# 外贸退运与索赔的库存采购与供应商资料：知识库检索与召回

## 这个品类的数据长什么样

外贸退运与索赔围绕出口后的逆向物流与责任认定展开，资料以客户邮件、质检报告、海关系统记录和保险公司理赔系统数据为主，日常文档包括退运协议、索赔函、质量报告和退运报关单。这些材料按案生成，更新不定期，每次处理都需要把同一案件的供应商资料、库存批次与退运单据对应起来。

对知识库检索与召回而言，影响集中在三点。材料主体多且角色不同，供应商、承运方、保险方与关务分别出现在不同文件中，检索时需要保留主体标识。同一案件的材料在时间上分阶段形成，退运原因确认、申报办理与索赔提交各自留下不同状态的记录。文档字段未提供时属于未知，检索结果不能替代对状态与授权边界的核对。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库，跨不同向量模型的库不可共同关联。检索先按语义、全文或混合方式召回候选，混合检索通过 RRF 融合多路结果，结果重排使用 ReRank 二次排序。引用上限以 token 为单位，最低相关度仅在语义检索或使用结果重排时生效。按设置开启问题优化后，可做指代消除和问题扩展，并在检索前增加一次模型调用。

检索结果只承担内容召回，不承担权限判断、实体隔离或业务授权。相似度得分不是权限过滤器，召回命中不代表某条退运协议已签署、某笔索赔已获批准或某项操作已获授权。表单收集字段值，业务核验、审批、数据库写入与外部系统同步都需要另行实现的环节。

假设演练样本：某供应商资料页含三句供核对材料原文。第一句为“编号 S-204 的退运协议处于待审核状态，审核人尚未签署。”第二句为“编号 Q-311 的质量报告载明外观检验已完成，功能检验结果栏为空。”第三句为“编号 C-407 的索赔函由客户于2026年3月发出，理赔系统尚未记录受理结果。”待判定拟稿句为“S-204 退运协议已生效，Q-311 质量报告结论为合格，C-407 索赔已获受理。”样本主体、对象、状态与期间均已写明，编号与日期为假设值。

## 配置怎么定

下表围绕上述样本，列出与本功能相关的已说明设置或实施核对项。涉及数值时标注为本次假设试验起点，并说明选择理由与比较对象。

| 配置项 | 本次假设起点 | 核对方式与依据 |
| --- | --- | --- |
| 关联知识库 | 仅关联同一向量模型的一个库 | 核对该库向量模型标识一致，排除标识不符的库 |
| 搜索模式 | 先用全文检索试编号类问题 | 以 S-204、Q-311、C-407 为输入，观察编号是否被命中 |
| 引用上限 | 起点设为能容纳三句原文的 token 量 | 该起点由样本原文长度决定，与仅容纳一句的较小值比较完整性 |
| 最低相关度 | 在语义检索或重排时启用 | 先标注样本中相关与无关片段，再比较不同阈值的过滤结果 |
| 问题优化 | 对含指代的追问开启 | 比较原问题与优化后问题，核对 S-204 等主体是否被改错 |
| 结果重排 | 候选较多时启用 | 比较重排前后候选顺序，观察得分是否用于过滤 |

## 容易做错的三处

1. 把检索命中当作状态确认。输入“S-204 退运协议”，检索返回该协议文本，若据此判定协议已生效，即把召回结果当成签署或生效事实。核对时应区分文本被检索到与协议状态字段取值，待审核不等于已签署。
2. 把相似度得分当作权限或实体过滤。输入某供应商名称，语义检索返回较高得分片段，若据此认定该供应商名下的记录均已授权查看，即混淆了相关度与授权边界。核对时应另行确认访问权与授权状态。
3. 把待判定拟稿句中的空缺字段补成确定结论。样本中 Q-311 功能检验结果栏为空，若拟稿句写为合格，即对未载明字段作出肯定判断。核对时应将未载明字段记为待核实，保留证据缺口。

## 怎么确认配好了

1. 输入样本原文三句，比较检索返回内容与原文表述。若返回片段包含“待审核”“结果栏为空”“尚未记录受理结果”等原文状态用词，且未出现“已生效”“合格”“已受理”等改写，则满足条件。若返回内容替换或补全了状态，则记录该失败分支。
2. 输入待判定拟稿句，比较其三个分句与对应原文。若 S-204 状态仍为待审核、Q-311 功能检验仍为空、C-407 仍无受理记录，则拟稿句与原文不符。预期是识别出三处不获支持，不声称已实测。
3. 输入纸面空结果，即引用内容为长度 0 的数组，核对下游设计是否按空引用继续走通。若下游能在空数组下继续执行且不据此推断无记录，则满足条件。纸面空数组与真实查询分开记录，实际查询结果待测试。

跨不同向量模型的库不可共同关联，核对时先检查向量模型标识并排除不符者，记录实际观察，不对共同关联后的运行结果作断言。图片检索与重排属于可选路径，需具备相应输入与模型能力，并非每次请求都会执行。
