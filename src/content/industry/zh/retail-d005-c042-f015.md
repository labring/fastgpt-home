# 平台商品标题与详情合规的库存采购与供应商资料：知识库检索与召回

## 这个品类的数据长什么样

商品标题表、详情页素材、广告禁词清单与质检报告共同构成合规判断的输入。标题表记录商品名称与卖点措辞，详情页素材承载宣传图片与文案，禁词清单列出不可使用的表述，质检报告提供实物参数依据。这些材料在上新时集中出现，周度复核时再次调取。库存采购与供应商资料环节需要把供应商提供的资质文件、报价单与实物参数纳入同一检索范围，核对宣传措辞是否有对应材料支撑。资料缺失时，检索结果为空并不表示违规成立，只表示当前范围没有可引用的依据。检索动作本身不改变任何材料的授权状态，也不构成对供应商资质的确认。

## 这些特征在「知识库检索与召回」这一环带来什么约束

关联知识库要求使用相同向量模型，跨模型的知识库不能共同关联。检索前先核对各库的向量模型标识，排除不符合者，不执行跨模型检索来比较漏召回。语义检索依赖向量距离，全文检索依赖关键词命中，混合检索通过 RRF 融合两路结果，重排对候选文本二次排序。最低相关度是过滤阈值，仅在语义检索或使用结果重排时生效，它不承担权限或实体隔离功能。引用上限以 token 为单位，控制每次搜索引用的内容量。按设置开启问题优化后，会增加一次模型调用，用于指代消除与问题扩展。图片检索需要图像输入及相应模型能力，重排需要模型且按设置启用，这些路径不构成每次请求的固定环节。节点输出为数组，长度可以为 0，空结果链路仍然走通。

## 配置怎么定

以下配置围绕本页假设演练样本展开。样本材料原文：供应商甲于二〇二五年三月提供某型号电水壶质检报告，报告载明额定功率一千八百瓦，报告编号 QC-2025-0312，有效范围为该批次。待判定拟稿句为“该电水壶额定功率两千瓦，附质检报告”。该拟稿句与报告原文在额定功率字段上取值不同，属于同字段互斥取值。

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联含质检报告的同一向量模型库 | 先核向量模型标识，排除不同模型库 |
| 搜索模式 | 混合检索 | 样本提供报告编号，拟稿句没有具体型号；用编号比较实际召回 |
| 引用上限 | 设定为覆盖一份报告全文的 token 量 | 与报告实际长度比较后调整 |
| 最低相关度 | 设定为中等阈值起点 | 用已标注相关与无关样本比较 |
| 问题优化 | 本次关闭 | 拟稿句主体完整，无指代需消除 |
| 结果重排 | 本次不启用 | 候选数量少，先观察未重排结果 |

以上数值均为本次假设试验起点，不构成官方默认值。当前只有报告摘录，全文长度未提供；取得全文后按所选模型计量，再比较引用上限下的完整性。

## 容易做错的三处

1. 把检索命中当作资质已确认。检索返回质检报告片段，仅表示该片段在检索范围内被召回，供应商资质是否有效、报告是否覆盖当前批次，需要人工核对报告编号与有效范围。检查方式：输入拟稿句，观察返回片段是否包含报告编号与有效范围字段，若片段缺失这些字段，记录为待核实。
2. 把最低相关度当作权限过滤。最低相关度只过滤低相关度结果，不区分供应商或业务实体。检查方式：用同一问题检索，观察返回内容是否跨供应商混入，若混入，记录为检索范围问题，不判定为权限失效。
3. 把 RRF 当作可开启的开关。RRF 是混合检索中多路结果的融合过程，不是独立配置项。检查方式：核对配置界面是否存在名为 RRF 的开关，若不存在，记录为文档描述与界面差异，不推断融合未执行。

## 怎么确认配好了

1. 输入拟稿句“该电水壶额定功率两千瓦，附质检报告”，比较返回片段中的额定功率取值与报告原文一千八百瓦。若返回片段包含报告原文且取值为一千八百瓦，则该拟稿句与原文在额定功率字段上取值不同，判定为待修正；若返回片段为空数组，记录为当前检索范围未召回，不判定拟稿句正确。

2. 输入供应商甲的名称与报告编号 QC-2025-0312，比较返回片段是否包含该编号及有效范围。若返回片段包含编号但未包含有效范围，记录为部分证据，保留有效范围缺口；若返回片段为空，记录为未召回，不推断报告不存在。

3. 构造纸面输入空数组，核对下游设计在引用内容长度为 0 时是否仍走通输出链路。观察下游节点是否收到空数组并继续执行，若下游中断，记录为链路设计问题；若下游继续，记录为空结果承接正常。该核对不声称虚构规则检索一定返回空数组。

以上验证均以假设样本为输入，未实际执行。检索结果不构成授权、批准或资质确认，供应商资料的有效性需另行人工核对。
