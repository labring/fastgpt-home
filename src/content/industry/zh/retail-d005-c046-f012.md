# 平台类目资质准入的库存采购与供应商资料：文档解析与分块

## 这个品类的数据长什么样

类目准入发生在商品上架或店铺入驻之前，审核对象是经营主体与授权链，材料以营业执照、商标注册证、品牌授权链、行业许可证为主。库存采购与供应商资料这一任务，需要把供应商提供的上述材料解析成可检索的文本块，供入驻专员核对主体、对象、有效期与授权范围。数据来源包括平台招商页面、国家企业信用信息公示系统、商标局数据与许可证系统，资料更新不定期，每次入驻重新收集。

这一环节的难点在于授权链往往由多份文件构成，一份授权书同时约束品牌、被授权方、授权商品范围与有效期间。解析与分块若把条件句与所约束的主体拆开，检索时可能召回授权范围却丢失被授权方，核对人员据此判断会产生偏差。因此本页只处理文档进入知识库后的解析、分块与检索观察，不把检索命中当作授权成立。

## 这些特征在「文档解析与分块」这一环带来什么约束

FastGPT 的知识库由库、集合和数据组成，最小搜索单位是库，集合仅用于分类管理。向量存于 PostgresSQL 的 vector 字段，索引为 HNSW，MongoDB 的 dataset.datas 表保存原数据，indexes 字段记录对应的向量 ID，一组数据可对应多个向量。检索时先召回向量，再按向量 ID 回 MongoDB 取原数据，命中同一组原数据则合并，向量得分取最高得分。

这意味着分块策略直接影响核对结果。一组较长的授权链文本可以添加多组向量，任一组被检索到即可召回该数据。语义检索依赖向量距离，全文检索依赖关键词命中，混合检索经 RRF 融合，重排给出 0-1 得分。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值，不承担主体隔离或权限判断。

假设演练样本。供核对的材料原文为：“甲方某某品牌管理有限公司授权乙方某某贸易有限公司，在二零二五年一月一日至二零二五年十二月三十一日期间，于某电商平台销售第某某类注册商标商品。本授权不包含转授权。”待判定的拟稿句为：“乙方已获得该品牌在平台的销售授权，授权范围含转授权。”此样本中主体、对象、期间与排除项均在原文内，拟稿句与原文在同一字段上取值互斥，属于未获支持。

## 配置怎么定

| 配置或核对项 | 本页相关设置 | 说明与边界 |
| --- | --- | --- |
| 搜索模式 | 语义检索、全文检索或混合检索 | 授权链含主体名称与编号，可同时用语义与全文观察 |
| 引用上限 | 每次搜索最多引用的 tokens 数 | 假设试验起点设为 2000 tokens，理由是该样本单份授权书较短，与 1000 和 4000 比较观察召回完整度 |
| 最低相关度 | 0-1 数值，仅在语义检索或结果重排时生效 | 假设试验起点设为 0.3，与 0.2 和 0.5 比较观察无关片段比例 |
| 问题优化 | 检索前做指代消除与问题扩展 | 连续追问授权期间时可开启，单轮明确问题可关闭 |
| 结果重排 | ReRank 模型对候选二次排序 | 需具备重排模型并按设置启用，未启用时不产生重排得分 |
| 分块核对 | 按资料结构检查段落完整性 | 人工核对条件、期间与所约束主体是否同块 |

## 容易做错的三处

1. 把检索命中当作授权成立。输入是样本原文与拟稿句，比较的是同一字段取值，原文写“不包含转授权”而拟稿句写“含转授权”，观察到的结果是二者互斥，拟稿句未获支持。检索只返回引用内容，授权是否成立需另行核对。
2. 把上传成功当作索引已更新。输入是供应商新提交的许可证文件，比较的是训练与索引状态，观察到的是上传完成但检索仍返回旧版本内容，此时应记录待核实，不能判定新证已生效。
3. 用相似度设置排除无关主体。输入是另一家公司的授权书，比较的是检索结果与目标主体名称，观察到的是低相关度过滤只减少低分片段，不按主体或权限排除记录，需人工按主体名称排除。

## 怎么确认配好了

1. 针对假设演练样本，输入拟稿句“乙方已获得该品牌在平台的销售授权，授权范围含转授权”，比较原文“本授权不包含转授权”与拟稿句在同一字段的取值，观察到的现象是两者互斥，判定为未获支持，保留证据缺口。
2. 针对样本原文，输入“二零二五年十二月三十一日”与“授权期间”，比较召回片段是否同时包含期间与所约束主体，观察到的现象是同一数据块内出现主体、对象与期间，视为分块完整；若期间与主体分属不同块，记录为待调整。
3. 针对空引用场景，输入明确的纸面检索结果 []，比较下游引用裁剪与回答生成的设计，观察到的现象是下游按空引用处理并提示无可用内容，不声称虚构规则检索一定返回空数组。

跨不同向量模型的库不可共同关联，应先核对库标识并排除不符合者，记录实际观察，不执行跨模型检索比较漏召回。图片检索需有相应图像输入及模型能力，重排需具备模型并按设置启用，二者均为可选路径，不代表每次请求全部执行。
