# 快递面单与揽收交接的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样
快递交接发生在包裹离仓节点，核心是承运商扫描责任。本页处理的材料是电子面单、交接清单、揽收扫描记录与异常件登记，主任务是库存采购与供应商资料。这些材料里既有面单号、承运商名称、交接批次、扫描时间这类精确字段，也有异常件描述这类自然语言段落。全文检索适合面单号、批次号、承运商名称等精确查询，语义检索适合异常件描述与责任归属的相近表达。两种召回路径的候选内容由 RRF 融合，再由 ReRank 二次排序。数据更新频率为每批、日，本页不据此推出批量同步或实时机制。

## 这些特征在「向量模型与索引」这一环带来什么约束
关联检索的知识库须使用相同向量模型，先核实际模型与输入类型。一个原数据块可以关联多个索引，索引与原文内容分别核对；MongoDB 的 dataset.datas 表用 indexes 字段记录向量 ID 数组，PostgresSQL 的 vector 字段存储向量，检索时先召回向量再按 ID 回查原数据，同一组原数据合并后向量得分取最高得分。索引内容用完整且聚焦的信息建立，检索覆盖与索引长度需结合样本权衡。图片检索还取决于入库时是否生成图片描述或图片向量，不能只看查询端。最低相关度是过滤阈值，仅在语义检索或结果重排时生效，不承担权限或实体隔离。引用上限控制每次搜索最多引用的 tokens 数量，与 top k 不是同一控制方式。

### 假设演练样本
以下为纸面虚构样本，不涉及真实客户、真实公司或合法身份编号。材料原文一：电子面单记录载明“面单号 SF-TEST-0001，承运商甲，交接批次 B-2024-05-10，揽收扫描时间 2024-05-10 18:20，状态已扫描”。材料原文二：异常件登记载明“面单号 SF-TEST-0001，登记日期 2024-05-11，异常类型为外包装破损，处理状态待承运商确认”。待判定拟稿句：“该面单已完成揽收交接，异常件已处理完毕。”判定任务为：比较拟稿句与两份材料原文，主体同为面单号 SF-TEST-0001，期间为 2024-05-10 至 2024-05-11，字段为揽收状态与异常处理状态。揽收状态字段取值为“已扫描”，拟稿句写“已完成揽收交接”；异常处理状态字段取值为“待承运商确认”，拟稿句写“已处理完毕”。同一字段出现互斥取值，拟稿句未获材料支持。

## 配置怎么定
下表为本次假设试验的配置核对项，数值仅为本次纸面演练的起点，不作为官方默认值。

| 配置项 | 本次假设起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 向量模型 | 同一模型标识，仅关联相同向量模型的库 | 先核模型标识与输入类型，排除标识不符的库，不执行跨模型检索比较 |
| 索引内容 | 面单号、承运商、批次、扫描时间、异常类型分字段建索引 | 与异常件描述段落索引分别核对，比较召回候选是否覆盖所需字段 |
| 搜索模式 | 混合检索，面单号类查询同时走全文召回 | 与单独语义检索的候选范围比较，观察面单号是否被全文路径命中 |
| 最低相关度 | 本次起点 0.3，仅语义检索或重排时生效 | 与不设阈值时的候选数量比较，观察低相关片段是否被过滤 |
| 引用上限 | 本次起点 800 tokens | 与候选 chunk 平均长度比较，观察引用内容是否被裁剪 |
| 结果重排 | 配置 ReRank 模型后启用 | 与未重排时的排序比较，观察重排得分 0-1 的分布 |

## 容易做错的三处
1. 把最低相关度当作权限或实体隔离手段。输入为一次语义检索查询，比较对象是过滤前后返回的候选集合，观察结果是低相关片段被过滤，而无关业务或未授权记录不因此被排除。检索本身不完成授权。
2. 把不同向量模型的库共同关联。输入为两个模型标识不同的知识库，比较对象是模型标识字段，观察结果是标识不一致时不应共同关联；跨模型关联后的运行表现无文档依据，保持未知。
3. 把待确认状态写成已完成。输入为异常件登记原文“处理状态待承运商确认”，比较对象是拟稿句“已处理完毕”，观察结果是同字段互斥取值，拟稿句未获支持，待核实状态保留。

## 怎么确认配好了
1. 针对假设样本材料原文一，输入查询“面单号 SF-TEST-0001 揽收扫描时间”，比较返回引用是否包含“2024-05-10 18:20”与“已扫描”，观察结果是引用内容与原文一致。若返回内容缺失该字段，记录为未命中并保留缺口。
2. 针对假设样本拟稿句，输入拟稿句与两份材料原文，比较揽收状态与异常处理状态两个字段，观察结果是揽收状态可对应“已扫描”，异常处理状态出现互斥取值，判定拟稿句未获支持。
3. 针对空结果承接，输入明确的纸面输入 []，比较下游设计是否按数组长度可以为 0 处理，观察结果是输出链路走通且不生成引用内容；不声称虚构规则检索一定返回 []。模型或索引调整后用同组问题比对引用原文，不根据向量分数单独承诺效果。
