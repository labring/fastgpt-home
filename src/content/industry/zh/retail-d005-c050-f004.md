# 投诉举报与监管回复的库存采购与供应商资料：向量模型与索引

## 这个品类的数据长什么样

投诉举报与监管回复场景中，库存采购与供应商资料包括采购订单、供应商资质文件、入库记录、退货凭证及往来沟通记录。这些材料面向平台或监管机关时，需要能还原交易过程、证明采购来源与库存状态。材料通常来自订单系统、客服聊天、12315平台及平台投诉中心，每案整理，更新不定期。

在向量模型与索引环节，这些材料以文本块形式入库，一个原数据块可关联多个索引。检索时先召回向量，再根据向量 ID 去 MongoDB 的 dataset.datas 表寻找原数据内容，同一组原数据合并后取最高得分。关联检索的知识库须使用相同向量模型，先核实际模型与输入类型。

## 这些特征在「向量模型与索引」这一环带来什么约束

材料涉及供应商名称、采购批次、入库数量、退货原因等字段，语义检索适合自然语言描述，全文检索适合编号与专有名词。混合检索通过 RRF 融合多路结果，重排模型对候选文本二次排序并给出 0-1 得分。最低相关度仅在语义检索或使用结果重排时生效，是过滤阈值，不负责权限或实体隔离。

图片检索取决于入库时是否生成图片描述或图片向量，也取决于查询端模型能力。模型或索引调整后，用同组问题比对引用原文，不根据向量分数单独承诺效果。

假设演练样本

供核对的材料原文：
“2025年3月10日，供应商甲向店铺乙发出报价单，报价单编号BJ-20250310，报价有效期至2025年4月10日。店铺乙于2025年3月12日回复确认采购意向，但双方未签署采购合同。2025年3月20日，店铺乙入库一批标注为供应商甲品牌的商品，入库单号RK-20250320，数量200件。”

一条待判定的拟稿句：“供应商甲与店铺乙已达成采购合作，合同已生效。”

判定：材料仅载明报价单发出、采购意向回复与入库记录，未载明合同签署与生效条款。同主体、同期间、同一字段下，报价有效期不表示供货期限，采购意向不表示合同生效。该拟稿句未获支持，需保留证据缺口。

## 配置怎么定

| 配置项 | 假设试验起点 | 说明与比较方法 |
| --- | --- | --- |
| 向量模型 | 与关联知识库实际模型一致 | 核实际模型标识与输入类型，不一致者排除，不执行跨模型检索比较 |
| 索引内容 | 每块聚焦单一供应商或单一批次 | 用完整且聚焦的信息建立索引，检索覆盖与索引长度结合样本权衡 |
| 搜索模式 | 混合检索 | 语义召回与全文召回经 RRF 融合，编号类问题可侧重全文 |
| 最低相关度 | 本次假设起点0.3 | 选此值因样本问题主体明确，与0.5比较观察召回范围变化 |
| 引用上限 | 本次假设起点2000 tokens | 按 tokens 控制，与1000比较观察引用内容长度 |
| 图片索引 | 入库时生成图片描述或图片向量 | 确认向量模型是否支持图片输入，检查图片清晰度与主体 |

## 容易做错的三处

1. 把检索当作授权。输入“供应商甲合同已生效”检索到报价单原文，报价单只证明报价发出，不证明合同签署或生效。检索结果不承担权限或实体隔离功能。

2. 跨向量模型关联。将使用不同向量模型的知识库共同关联，核标识时发现模型不一致，应排除不符者并记录，不执行跨模型检索来比较漏召回。

3. 把报价有效期当作供货期限。材料载明报价有效期至2025年4月10日，拟稿句写“供货期限至2025年4月10日”，同字段下有效期与供货期限为不同事实，该句未获支持。

## 怎么确认配好了

1. 输入假设样本原文与拟稿句“供应商甲与店铺乙已达成采购合作，合同已生效”，比较材料载明的报价、意向、入库三项事实与拟稿句主张的合同生效。观察结果：拟稿句未获支持，记录证据缺口为合同签署与生效条款缺失。

2. 输入“BJ-20250310”进行全文检索，比较召回内容是否包含报价单编号原文。观察结果：引用内容包含该编号及报价有效期，若未召回则检查全文检索配置与索引内容。

3. 输入明确纸面结果`[]`，核对下游链路是否走通。观察结果：引用内容长度为0时输出链路仍走通，与节点文档所述一致。不声称虚构规则检索一定返回`[]`。
