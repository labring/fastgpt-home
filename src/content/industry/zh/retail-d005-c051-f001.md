# 抖音小店货架运营的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样

抖音小店货架运营依靠商品卡与店铺体验分获得流量，日常要处理商品资质页、体验分明细、发货违规申诉和店铺公告。库存采购与供应商资料这一任务里，采购单、供应商资质、到货数量与缺货记录分散在表格和外部系统中，更新频率为日、每单。HTTP 模块向外部地址发送请求，可对接公开 API 或业务服务，用来在采购与供应商资料环节读取或写入数据。请求可引用全局变量、系统变量和前方节点输出，URL、Params、Headers、Body 均支持 `{{}}` 引用。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块的返回值配置代表如何解析接口响应，通过 JSON path 提取需要的值，输出类型选字符串时会把对应 key 的值转成 json 字符串。对话接口中，传入 `chatId` 为 `非空字符串` 时会从数据库取会话，仅用 messages 最后一个内容作为用户问题；`chatId` 与 `responseChatItemId` 在测试模式下不存在，调试空值不等于业务故障。检索结果与相似度不承担授权判断，接口调用与业务审批是两件事。

假设演练样本：供核对的供应商资料原文为「供应商甲，主体为某某商贸有限公司，供货品类为一次性餐具，资质页状态为已提交待审核，报价有效期至2025年3月31日」。一条待判定的交接请求为「将供应商甲加入合格供应商名单，并按其报价直接生成采购单」。原文只显示资质页为已提交待审核，报价有效期属于报价字段，未载明供货期限，也未载明合格名单的批准结果。该请求中「加入合格名单」缺少批准证据，「按其报价直接生成采购单」把报价有效期当成了可执行采购的授权，属于未获支持的判定。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 核对方式 |
| --- | --- | --- |
| 请求地址 | 外部供应商资料接口地址，可含 `{{}}` 变量 | 与外部接口文档地址逐字符比对 |
| 请求方法 | 按外部接口文档选择 | 与文档方法字段比对 |
| Headers 鉴权 | Authorization 通过安全配置注入 | 核对请求头键名，不写入公开样例 |
| Body 结构 | 仅在该请求类型下使用，引用变量加引号 | 与外部接口契约逐字段比对 |
| 出参 key | 按 JSON path 配置，输出类型选字符串 | 与解析后的响应结构比对 |
| 变量来源 | 全局变量、系统变量、前方节点输出 | 逐项核对实际传入值 |

起点选择理由：请求地址与方法以外部接口文档为准，Body 仅在相应请求类型下生效，出参 key 按文档示例的 JSON path 语法配置。这些起点需与外部接口文档对应字段比较，不构成官方默认值。

## 容易做错的三处

1. 把资质页「已提交待审核」当成已批准。输入为供应商资料原文，比较对象是「待审核」与「已批准」两种状态字段，观察结果是两者取值不同，不能互相替代。
2. 把报价有效期当成供货期限或采购授权。输入为报价有效期至2025年3月31日，比较对象是报价字段与供货字段，观察结果是原文未载明供货期限，该字段保持未知。
3. 用相似度分数代替权限判断。输入为检索返回的 score 值，比较对象是相似度与授权状态，观察结果是 score 不表示供应商是否被批准，检索不产生授权。

## 怎么确认配好了

1. 输入假设样本原文与待判定请求，比较「已提交待审核」与请求中的「加入合格名单」，观察结果是请求缺少批准证据，判定为未获支持。
2. 输入报价有效期字段与采购单生成动作，比较报价字段与授权字段，观察结果是原文未载明供货期限与采购授权，判定为待核实。
3. 输入出参 key 配置与解析后响应结构，比较 key 路径与响应字段，观察结果是路径与字段一致时提取成功，不一致时该项保持未知，不推断为接口故障。
