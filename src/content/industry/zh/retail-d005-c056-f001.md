# 生产企业免抵退税的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样

在生产企业免抵退税的库存采购与供应商资料中，本页说明FastGPT的HTTP 接口与外部系统如何衔接资料。出口料件资料读取保留本批出口对应与申报期间整理标记，资料归集不能推出税务处理获准。所用场景为自拟文字测试。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

自拟免抵退税资料整理包有一份“本申报期间出口料件关联表”，列本批出口单据与供应商料件清单待对应；加工记录已归集，处理回执尚未给。这里的期间只是自拟资料标签，不声明法定期限或税务条件。HTTP读取应把出口批次、该期间及供料主体传入，并查实际返回，不能按同名供应商取他批料件。本例不计算税额、不判断资格或提出申报建议。

## 配置怎么定

| 出口料件HTTP | 自拟资料关系 | 核验动作 |
| --- | --- | --- |
| 出口关联表 | 本期间本批待对 | 核出口单据原文 |
| 供应清单 | 料件来源 | 核供料主体 |
| 加工记录 | 已归集 | 非税务获准 |
| 期间身份 | 资料标签 | 不推法定条件 |
| 处理回执 | 尚未提供 | 缺证不推未申报 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `请求地址与方法` | 请求地址与方法遵循外部契约。 |
| `Params与Headers` | 参数、请求头及鉴权分别核对。 |
| Body | 采用JSON请求体时按外部契约核结构。 |
| `变量引用` | 可引用全局、系统或前序输出变量。 |
| `调试身份字段` | 测试时无chatId及responseChatItemId。 |

## 容易做错的三处

资料归集被答处理获准时，核本事项真实回执；同供应商另一出口批次或期间资料进入本批时，对请求、出口单据及原文期间；待对清单被答完整匹配时，核本批出口单据与料件原件的对应。三处分别查处理阶段、出口事项归属和材料关系，不由请求成功生成决定。

## 怎么确认配好了

验收先问这份供应清单关联哪批出口材料、覆盖哪段标示期间，再对实际请求、响应和答复。保持认证脱敏，按真实接口契约核输入及返回覆盖；缺原件时不补料件关系，回执缺席也不反推未申报或不予处理。补本批原件只更新对应，正式税务审核及申报由其授权业务流程与凭据决定。
