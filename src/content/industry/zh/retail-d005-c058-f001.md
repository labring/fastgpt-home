# 生鲜供应商索赔的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样
生鲜供应商索赔围绕到货质量责任展开，主要材料是质量异常单、照片证据、扣款通知与索赔对账单，来源涉及质检系统、WMS 验收、供应商合同与财务对账。与临期折价处理相比，索赔追究的是供应商到货质量责任，不处理门店自然损耗，因此每批验收记录与月度对账是两个并行的数据节奏。在本页任务中，HTTP 接口承担的是把库存采购与供应商资料侧的请求发往外部系统，并把返回值解析为可用字段，接口本身不完成质检判定、扣款确认或供应商赔付。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
HTTP 模块可重复添加、手动配置、触发执行。Params 为路径请求参数，Body 为请求体，Headers 为请求头，三者均可用 `{{}}` 引用变量，URL 同样可以引用变量；变量来自全局变量、系统变量与前方节点输出。系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories，其中 chatId 与 responseChatItemId 在测试模式下不存在，调试时取不到值属于该条件下的正常现象。返回值通过 JSON path 提取，输出类型选字符串时会把对应 key 的值转成 json 字符串。检索与相似度只影响内容匹配，不构成授权、审批或实体隔离；外部系统是否写入、是否同步，取决于对方接口的契约，HTTP 模块只负责发出请求与解析响应。

假设演练样本：某批生鲜到货验收记录原文为「2025 年 3 月 12 日，批次 A-0312，验收数量 200 箱，其中 18 箱叶菜外观异常，质检已拍照留存」。另有一条待判定的交接请求：「请把该批次质量异常单推送至供应商索赔对账接口，并完成扣款确认」。该请求中，材料只支持到货批次与异常数量，扣款确认属于财务对账环节，请求本身未附供应商确认与扣款依据，因此只能作为待核实事项，不能视为已授权执行。

## 配置怎么定
下表围绕上述样本，列出与本功能、本主任务相关的官方已说明设置或实施核对项。数值为本次假设试验起点，仅用于比较方法说明，不作为官方默认值。

| 配置项 | 本次假设试验起点 | 核对方式 |
| --- | --- | --- |
| 请求地址与方法 | 按外部接口文档选择，地址可引用变量 | 与外部接口契约逐字段比对，地址变量取值来自前方节点输出 |
| Params 与 Headers | Authorization 以 Bearer 加凭证注入 | 凭证不写入公开样例，仅核对注入位置与取值来源 |
| Body | 仅在相应请求类型下生效，JSON 结构按契约 | 引用字符串时加引号，数值与布尔不加引号，逐项核对解析结果 |
| 变量引用 | 引用全局变量、系统变量、前方节点输出 | 逐项核对实际传入值，确认变量名与来源节点一致 |
| 返回值提取 | 按 JSON path 语法配置 key | 用响应示例验证提取路径，输出类型选字符串时核对 json 字符串形态 |
| 调试身份字段 | chatId 与 responseChatItemId 测试模式下不存在 | 不以调试空值判定业务故障，改在具备会话条件下复核 |

## 容易做错的三处
1. 把检索或相似度当成授权。检索只做内容匹配，不判断供应商身份、不判断扣款权限。检查：输入样本中的批次与异常数量，比较返回值是否仅含内容字段，观察结果中是否出现身份或权限字段；若没有，则不能据此执行扣款确认。
2. 把待判定请求当成已执行。样本中的扣款确认请求缺少供应商确认与扣款依据，属于待核实。检查：输入该请求原文，比较材料中是否载明供应商确认与扣款金额依据，观察是否只存在到货批次与异常数量；仅有后者时记录为未获支持。
3. 把测试模式下的空值当成业务故障。chatId 与 responseChatItemId 在测试模式下不存在。检查：在测试模式发起请求，比较这两个字段的取值，观察其是否为空；为空时按文档条件记录，不推导外部系统异常。

## 怎么确认配好了
1. 用样本原文核对返回值提取。输入「批次 A-0312，验收数量 200 箱，18 箱叶菜外观异常」，按 JSON path 配置 key，比较提取结果与原文数值，观察 200 与 18 是否分别落到对应字段；若字段为空或错位，说明提取路径与响应结构不一致。
2. 用待判定请求核对授权边界。输入「请把该批次质量异常单推送至供应商索赔对账接口，并完成扣款确认」，比较材料中是否含供应商确认与扣款依据，观察是否只出现到货批次与异常数量；仅出现后者时，记录为待核实，不标记为已授权执行。
3. 用测试模式核对调试字段。在测试模式发起请求，比较 chatId 与 responseChatItemId 的取值，观察其是否为空；为空时按文档条件记录，并在具备会话条件下复核，不据此判定外部系统写入或同步已完成。
