# 生鲜水果门店采购的库存采购与供应商资料：文档解析与分块

## 这个品类的数据长什么样

生鲜水果门店采购的日常资料以采购单、验收单、农残检测报告和损耗记录为主，来源包括批发市场行情、供应商报价、门店销售与检测报告。这些资料的更新频率为每日或每批，采购单与验收单随每次到货产生，检测报告按批次出具。资料结构差异明显：采购单含供应商名称、品名、数量、单价与日期；验收单含等级判定、实收数量与验收人；检测报告含样品名称、检测项目、结果与报告编号；损耗记录含报损品名、数量与原因。这些字段在解析与分块时构成判断主体、对象与有效范围的基础。

## 这些特征在「文档解析与分块」这一环带来什么约束

分块需要保留能回指原文的文档身份与版本。验收单中的等级判定与实收数量属于同一业务事实，条件说明与所约束内容不应被拆离。同一组原数据可对应多个索引，原数据与检索索引分属不同存储。检索时先召回向量，再依据向量 ID 去取原数据，对应同一组原数据则合并，向量得分取最高得分。检索库需要与向量模型匹配，这一要求属于本功能范围，不能扩展为其他外部系统也须同模型。相似度与相关度仅用于排序与过滤，不承担权限或实体隔离。

以下为假设演练样本，用于说明核对方式，不涉及真实客户或真实编号。

材料原文一：供应商甲于二〇二五年三月十日出具报价单，品名为红富士苹果，等级为一级，单价为每公斤六元，报价有效期至二〇二五年三月十七日。

材料原文二：门店于二〇二五年三月十二日出具验收单，对应采购单编号为CG-20250310-01，实收红富士苹果一级八十公斤，验收人签字为李四。

待判定拟稿句：供应商甲在二〇二五年三月十二日已完成对门店的红富士苹果供货。

判定所需证据为：报价单载明单价与有效期，未载明供货期限；验收单载明实收数量与验收人签字，未载明合同生效或供货完成。拟稿句所称“已完成供货”在现有材料中未获支持，属于待核实状态。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 搜索模式 | 混合检索 | 采购单编号与品名需精确命中，自然语言问法需语义召回，两者同时使用 |
| 最低相关度 | 假设起点为0.5 | 该值仅在语义检索或结果重排时生效，需与检索返回的得分分布比较后调整 |
| 引用上限 | 假设起点为2000 tokens | 按 tokens 控制引用量，与单次返回内容的实际长度比较 |
| 问题优化 | 假设开启 | 连续追问中问题常缺少主体，与关闭时的检索结果比较 |
| 结果重排 | 假设开启 | 候选较多时用重排得分过滤，与仅用向量得分的排序比较 |
| 图片检索 | 假设不启用 | 当前资料以文本为主，需先确认向量模型是否支持图片输入 |

## 容易做错的三处

1. 将报价单的有效期当作供货期限。报价单仅载明单价与有效期，供货期限未载明。核对时应比较同一供应商、同一期间、同一字段，报价有效期与供货期限属于不同字段，不能互相替代。
2. 将验收单签字当作合同生效或供货完成。验收单载明实收数量与验收人签字，签署、合作达成与合同生效是三个不同事实。核对时应确认材料中是否载明生效条款，未载明时保留证据缺口。
3. 将相似度得分当作权限或实体隔离手段。相似度与相关度仅用于排序与过滤，检索不承担授权判断。核对时应确认访问范围是否已由目标检索范围限定，不能以得分高低推断记录是否可访问。

## 怎么确认配好了

1. 输入假设演练样本中的报价单原文与拟稿句，比较拟稿句所称“已完成供货”与原文载明的单价、有效期字段。若原文未载明供货期限或生效条款，则拟稿句未获支持，应记录为待核实。
2. 输入假设演练样本中的验收单原文与采购单编号CG-20250310-01，比较实收数量、验收人与采购单对应关系。若编号一致且数量字段可对应，则验收事实成立；若编号不一致或数量字段缺失，则对应关系未获支持。
3. 输入假设演练样本中的供应商名称与品名，分别以编号和自然语言检索。若编号检索命中采购单与验收单，自然语言检索命中报价单与损耗记录，则分段对实际问题的影响可观察；若任一路无结果，则记录该路为空并核对索引状态，不推断其他原因。
