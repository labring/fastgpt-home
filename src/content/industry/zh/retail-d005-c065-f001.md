# 直播间违规申诉的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样

直播间违规申诉针对已经发生的处罚，需要复盘证据链。库存采购与供应商资料这一类文档通常包含采购订单、供应商资质、进货凭证与库存记录，用于说明被处罚商品来源合法、库存状态可追溯。平台违规中心、直播回放、客服记录与商品资质库是主要数据来源，更新不定期，每次违规才触发一次整理。HTTP 接口与外部系统这一环的任务，是把库存采购与供应商资料中的字段通过接口传给外部系统，或从外部系统取回核对结果。资料本身不构成授权，接口调用也不等于业务审批。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向对应地址发送请求，实际操作与 Postman、ApiFox 类似。Params 为路径请求参数，GET 请求中用的居多；Body 为请求体，POST/PUT 请求中用的居多；Headers 为请求头，用于传递特殊信息。三种数据均可通过 `{{}}` 引用变量，URL 也可引用变量。变量来自全局变量、系统变量、前方节点输出。系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories，其中 chatId 与 responseChatItemId 在测试模式下不存在。返回值通过 JSON path 语法提取，出参格式化在 v4.6.8 后加入，输出类型选字符串时会将对应 key 的值转成 json 字符串。

假设演练样本：某店铺收到违规通知，称其售卖的某批次商品缺少供应商资质。供核对的材料原文为三句：一，违规通知载明处罚对象为店铺 A 的直播间，违规日期为 2025 年 3 月 10 日，涉及商品为某型号库存商品；二，采购订单显示该批次商品由供应商 B 于 2025 年 2 月 20 日发货，数量 200 件；三，供应商资质文件载明资质有效期至 2025 年 1 月 31 日。待判定的交接请求为：请通过 HTTP 接口将该批次采购订单与供应商资质提交外部系统，并请求自动确认资质有效。该请求中，资质有效期在违规日期之前已届满，材料原文只显示有效期截止日，未载明续期或展期条款，因此资质是否覆盖违规日期属于未获支持，需人工核实。

## 配置怎么定

配置围绕上述样本，只列与本功能、主任务相关的官方已说明设置或实施核对项。

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 请求地址与方法 | 按外部接口文档填写，地址可引用变量 | 与外部接口契约逐项核对，不预设固定地址 |
| Headers 鉴权 | Authorization 通过安全配置注入 | 与外部接口文档的鉴权要求比较，不写入公开样例 |
| Body 结构 | 引用采购订单号、供应商名称、资质有效期字段 | 与外部接口契约的 JSON 结构逐字段核对 |
| 变量引用 | 引用前方节点输出的订单号与资质文件字段 | 逐项核对实际传入值，确认与材料原文一致 |
| 返回值提取 | 按 JSON path 提取外部系统返回的核对状态 | 与外部接口响应的实际字段比较，不预设成功或失败 |
| 调试身份字段 | chatId 与 responseChatItemId 在测试模式下不存在 | 不把调试空值当成业务故障，测试与正式环境分别核对 |

## 容易做错的三处

1. 把资质有效期届满的材料直接提交外部系统并请求自动确认有效。输入是上述供应商资质文件，比较对象是资质有效期截止日与违规日期，观察结果是有效期截止日在违规日期之前，且材料未载明续期条款，因此自动确认请求缺少依据。
2. 把 HTTP 接口调用当成业务授权或审批完成。输入是待判定的交接请求，比较对象是请求中“请求自动确认资质有效”这一动作与材料原文，观察结果是材料只显示有效期截止日，未载明任何授权或审批结论，接口调用不产生审批效力。
3. 把测试模式下 chatId 与 responseChatItemId 不存在当成接口故障。输入是测试模式下的请求，比较对象是文档说明的测试模式字段缺失条件，观察结果是这两个字段在测试模式下本就不存在，需与正式环境分别核对，不据此判定业务异常。

## 怎么确认配好了

1. 针对假设演练样本，输入供应商资质文件原文与待判定交接请求，比较资质有效期截止日与违规日期，观察结果应为：截止日早于违规日期且无续期条款，因此“资质有效”这一判定属于未获支持，需人工核实，不执行自动确认。
2. 针对假设演练样本，输入采购订单原文与 HTTP 请求 Body 字段，比较订单号、供应商名称、发货日期、数量是否与材料原文一致，观察结果应为：字段逐项对应，若出现材料未载明的字段则记录为缺口，不补造。
3. 针对假设演练样本，输入外部系统返回的核对状态与请求中“自动确认资质有效”这一动作，比较返回值提取结果与实际响应字段，观察结果应为：若返回状态未表明审批完成，则记录为待核实，不将接口返回等同于业务审批或授权生效。
