# 短视频挂车分销运营的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样

短视频挂车分销的转化依靠内容持续曝光与商品链接，日常材料集中在短视频脚本、挂车商品清单、佣金计划与违规反馈。库存采购与供应商资料属于同一工作流里的独立材料，记录采购批次、供应商主体与供货状态。这些材料要经 HTTP 接口与外部系统流转时，数据来源包括精选联盟、播放数据、成交数据与平台规则，更新频率为日或周。资料更新节奏只说明材料本身的变化周期，不构成接口的批量同步、全量同步或实时触发机制。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向对应地址发送请求，实际操作与 Postman、ApiFox 类似。Params 为路径请求参数，GET 请求中居多；Body 为请求体，POST/PUT 请求中居多；Headers 为请求头。三种数据均可通过 `{{}}` 引用变量，URL 也可引用变量，变量来自全局变量、系统变量与前方节点输出。系统变量包含 appId、chatId、responseChatItemId、variables、cTime、histories，其中 chatId 与 responseChatItemId 在测试模式下不存在，调试空值不构成业务故障。返回值配置代表如何解析接口响应，用 JSON path 提取，key 遵循 JS 对象取值规则，输出类型选择字符串时会把对应值转成 json 字符串。对话接口使用 APIKey 鉴权，调用 chat/completions 时推荐在请求体传入 body.appId，也支持 Authorization: Bearer <apiKey>-<appId>；appId 优先级为 body.appId、<apiKey>-<appId>、apikey 关联的 appId。传入的 model、temperature 等字段无效，由编排决定。authProxy 代理团队成员身份需要团队所有者开启，代理身份仍需具备目标应用和会话权限。检索与相似度不承担权限或实体隔离功能。

假设演练样本：材料原文为“供应商甲于2025年3月1日提交挂车商品清单，批次号P-0301，含商品A与商品B，供货状态为待确认；佣金计划编号C-0301，适用期间2025年3月1日至3月31日。”待判定拟稿句为“供应商甲已完成本批次供货确认，可安排采购入库。”该句涉及主体供应商甲、对象批次P-0301、状态供货确认。原文只写“待确认”，拟稿句写“已完成”，两者在同一字段上取值互斥，判定为未获支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 请求地址 | 外部接口文档给出的地址 | 地址可引用变量，与文档给出的路径逐字符比较 |
| 请求方法 | 按外部接口契约选择 | 与接口文档声明的方法比较，GET 用 Params，POST/PUT 用 Body |
| Headers 鉴权 | Authorization 头注入凭证 | 与密钥使用规范比较，凭证不写入公开样例 |
| Body 结构 | 按接口契约构造 JSON | 与接口文档字段逐项比较，字符串引用加引号 |
| 返回值提取 | 配置 key 与输出类型 | 与接口响应示例的 JSON path 比较，输出类型选字符串时转 json 字符串 |
| 变量引用 | 逐项核对实际传入值 | 与全局变量、系统变量、前方节点输出比较 |

以上数值为本次假设试验起点，不是官方默认值。

## 容易做错的三处

1. 把材料中的“待确认”当成已完成。输入为供应商甲批次P-0301材料，比较字段为供货状态，原文取值“待确认”，拟稿句取值“已完成”，同一字段两个互斥取值即矛盾。
2. 把检索或相似度当成权限过滤。输入为一次带 score、similarity 的检索结果，比较是否携带授权字段，结果中无授权字段即不能据此判断记录可用。
3. 把调试模式下的空 chatId、responseChatItemId 当成业务故障。输入为测试模式请求，比较系统变量是否存在，文档说明二者在测试模式下不存在，缺失属于预期。

## 怎么确认配好了

1. 输入假设样本原文与拟稿句，比较主体、对象、字段与取值，供货状态字段出现“待确认”与“已完成”两个互斥取值时，判定拟稿句未获支持。
2. 输入一条引用变量的请求，比较变量来源与实际传入值，全局变量、系统变量、前方节点输出逐项对应时，变量引用满足条件。
3. 输入 detail=true 且 stream=false 的请求，比较返回结构，responseData 中出现模块状态与完整结果时，解析配置满足条件；若返回为空，记录空结果并核对下游设计，不推断具体失败原因。
