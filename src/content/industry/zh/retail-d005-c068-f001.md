# 社区团购预售集单的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样

社区团购预售集单先收订单再组织采购履约，与团长关系维护属于不同工作。库存采购与供应商资料这一环，日常围绕预售商品表、集单结果、采购计划、截单通知四类文档展开。数据来源包括小程序订单、供应商库存、团长反馈与仓配排线，更新频率为日或每场。截单之后下采、安排分拣波次是最耗时的环节，接口一旦把未截单数据当作已确认采购量传给外部系统，后果是缺货退款、履约延误与团长投诉。HTTP 模块发送请求，Params 用于路径请求参数，Body 用于请求体，Headers 用于请求头，三处均可通过 {{}} 引用变量，URL 同样可以引用变量。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

变量来自全局变量、系统变量与前方节点输出。系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories，其中 chatId 与 responseChatItemId 在测试模式下不存在。对话接口调用 chat/completions 时推荐在请求体传入 body.appId，也支持 Authorization: Bearer <apiKey>-<appId>，appId 优先级为 body.appId、<apiKey>-<appId>、apikey 关联的 appId。BaseUrl 是否需要补 v1 按 SDK 而定，出现 404 可补充 v1 重试。传入的 model、temperature 等字段无效，由编排决定。authProxy 代理团队成员身份需团队所有者开启，代理身份仍需具备目标应用和会话权限。

假设演练样本：某平台运营在 2025 年 3 月 10 日截单后，依据预售商品表与集单结果生成采购计划草稿，准备通过 HTTP 模块把供应商编码、商品编码、采购数量、到货日期传给外部采购系统。材料原文两句：「截单时间为 2025 年 3 月 10 日 20:00，集单结果为预售商品 A 共 320 件、商品 B 共 180 件。」「采购计划草稿状态为待采购主管审核，尚未提交外部系统。」待判定拟稿句：「采购计划已确认，可向供应商下单。」该请求由平台运营提出，涉及供应商与商品。草稿待审核，未提供下单授权凭据；不据此推断人员无操作权限。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 核对依据与比较方式 |
| --- | --- | --- |
| 请求方法 | POST | 与外部采购系统接口文档声明的方法比较 |
| 请求地址 | 含 {{BaseUrl}} 的采购写入路径 | 与接口文档地址逐段比对，确认变量可解析 |
| Headers 鉴权 | Authorization 引用已注入变量 | 与密钥使用规范比较，凭证不写入公开样例 |
| Body 字段 | 供应商编码、商品编码、采购数量、到货日期 | 与外部接口契约逐字段比对，确认类型一致 |
| 返回值提取 | 按 JSON path 提取采购单号与状态 | 与接口响应示例的层级比较 |
| 变量来源 | 前方节点输出的集单结果 | 与全局变量、系统变量清单比较，确认来源合法 |

起点选 POST 与写入路径，是因为该请求要传递采购数据，需与外部接口文档声明一致；不把它当作官方默认值。返回值提取遵守 JS 对象取值规则，输出类型选择字符串时会把对应 key 的值转成 json 字符串。

## 容易做错的三处

1. 把待审核的采购计划草稿当作已确认采购量传入外部系统。输入是状态为待采购主管审核的草稿，比较对象是材料原文的审核状态字段，观察结果是请求是否在审核完成前发出。
2. 用 retrieval 的 similarity 或 score 判断供应商是否已授权。输入是检索返回的相关度数值，比较对象是授权状态字段，观察结果是是否把相似度当作权限或实体过滤条件。
3. 在测试模式下引用 chatId 或 responseChatItemId 并当作业务故障。输入是测试模式请求，比较对象是系统变量说明，观察结果是是否把测试模式不存在的字段当成线上异常。

## 怎么确认配好了

1. 针对假设样本的拟稿句「采购计划已确认，可向供应商下单」，输入为材料原文两句与拟稿句，比较对象是原文中「待采购主管审核」这一状态字段，观察结果：拟稿句与同字段取值互斥，判定为未获支持，需保留证据缺口。
2. 针对采购计划写入请求，输入为 Body 中供应商编码、商品编码、采购数量、到货日期四项，比较对象是外部接口契约声明的字段与类型，观察结果：四项均可解析且类型一致时通过，缺项或类型不符时记录为待核实。
3. 针对返回值提取，输入为接口响应示例，比较对象是配置的 JSON path 与提取示例，观察结果：提取值与示例层级一致时通过；响应为空或路径不存在时记录实际观察，不推断确定性失败原因。

表单收集的是值，业务验证、审批、数据库写入与外部同步需要各自的下游实现。检索不承担授权职责，相关度分数不排除无关业务或未授权记录。以上是纸面核对，未实际执行。
