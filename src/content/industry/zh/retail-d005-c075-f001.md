# 达人专场带货合作的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样

达人专场带货合作依赖外部达人履约，库存采购与供应商资料因此横跨品牌商务、MCN机构与达人经纪三方。精选联盟、巨量星图、达人历史数据与店铺成交明细构成主要数据来源，达人合作协议、佣金设置单、样品寄送单、直播战报是需要日常处理的文档。这些资料决定HTTP接口向外部系统传递什么、以何主体名义传递。资料按每场和周更新，接口设计需接受这一节奏，不据此推断批量或实时同步机制。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP模块向对应地址发送请求，Params、Headers、Body分别承载路径参数、请求头与请求体，三者均可通过{{}}引用全局变量、系统变量或前方节点输出，URL同样支持变量引用。系统变量含appId、chatId、responseChatItemId、variables、cTime、histories，其中chatId与responseChatItemId在测试模式下不存在，调试时出现空值属正常，不能当作业务故障。返回值通过JSON path提取，输出类型选字符串时会将对应key的值转为json字符串。对话接口以APIKey鉴权，调用chat/completions时推荐在请求体传入body.appId；appId优先级为body.appId、apiKey-appId、apikey关联的appId。authProxy代理团队成员身份需团队所有者开启，代理身份仍需具备目标应用和会话权限。传入的model、temperature等字段无效，由编排决定。detail=true可返回中间值，tokens需手动计算。检索与相似度不承担权限或实体隔离职责，HTTP调用本身不构成授权。

假设演练样本：某品牌商务与MCN机构就达人专场带货签署合作协议，协议载明供货方为甲供应商，样品寄送单编号YP-0312，佣金设置单约定佣金比例15%，直播战报待生成。商务拟通过HTTP接口向供应商系统提交一份库存采购交接请求，请求体含supplierId、sampleId、commissionRate与deliveryDate，Headers携带Authorization。该请求处于待审核状态，尚未获得供货方确认。拟稿句为：“供应商已确认本次专场库存采购数量与交付日期。”此句所依据的材料仅为协议与样品寄送单，未见供应商确认记录。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 请求地址 | 供应商系统接口地址 | 按外部接口文档选择，地址可引用已提供变量 |
| 请求方法 | POST | 与外部接口契约一致，核对Body是否生效 |
| Headers鉴权 | Authorization: Bearer {{token}} | 凭证经安全配置注入，不写入公开样例 |
| Body字段 | supplierId、sampleId、commissionRate、deliveryDate | 逐项核对与协议、样品寄送单、佣金设置单是否一致 |
| 变量来源 | 全局变量与前方节点输出 | 核对实际传入值，不假定默认值 |
| 返回值提取 | JSON path提取指定key | 输出类型选字符串时转为json字符串 |

## 容易做错的三处

1. 将待审核的交接请求当作供应商已确认。输入为拟稿句与协议、样品寄送单；比较对象是供应商确认记录是否存在；可观察结果为材料中无确认字段时，该句未获支持。
2. 把测试模式下chatId与responseChatItemId不存在当作业务故障。输入为测试模式返回；比较对象是文档说明的测试模式行为；可观察结果为字段缺失但流程正常时，属预期现象。
3. 将检索或相似度结果当作权限判定。输入为接口返回的相似度分值；比较对象是授权范围；可观察结果为分值高低不改变访问权限，检索不构成授权。

## 怎么确认配好了

1. 拟稿句核验：输入为上述拟稿句与协议、样品寄送单原文；比较拟稿句是否与材料同主体、同期间、同字段；可观察结果为材料未载明供应商确认时，该句判定为未获支持。
2. 请求体字段核验：输入为Body中supplierId、sampleId、commissionRate、deliveryDate；比较各字段与协议、样品寄送单、佣金设置单的对应值；可观察结果为字段一致时通过，不一致时记录差异。
3. 返回值提取核验：输入为接口响应与配置的JSON path；比较提取结果与响应实际结构；可观察结果为提取值与响应中对应key一致时通过，路径不匹配时记录未提取到值。
