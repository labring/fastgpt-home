# 连锁总部选址开店的库存采购与供应商资料：引用来源与溯源

## 这个品类的数据长什么样
选址开店发生在门店营业前，核心是租赁和工程交付。库存采购与供应商资料在这个阶段常表现为供应商报价单、样品确认记录、采购意向与交付排期。这些材料的有效期、签署状态与授权范围各不相同，直接决定引用时能否作为依据。资料更新频率为不定期、每店，引用来源必须标注对应门店与版本。

## 这些特征在「引用来源与溯源」这一环带来什么约束
知识库搜索节点选择一个或多个相同向量模型的知识库，输出引用内容数组，长度可以为零。引用上限以 tokens 计，最低相关度仅在语义检索或结果重排时生效。检索结果不构成授权，引用内容需逐条与原文核对。

假设演练样本：某连锁总部拓展部留存一份《供应商报价单》（编号 GYS-2026-014），其中写明“报价对象：华东区新店后厨设备；报价有效期至2026年6月30日；供货排期以双方签署的采购合同为准”。同卷附一份《样品确认记录》（编号 YP-2026-003），写明“样品已确认，采购合同尚未签署”。待判定拟稿句：“该供应商已承诺供货，开业排期可按报价单执行。”

## 配置怎么定
| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅选供应商资料库 | 与库存采购任务对应；核对各库向量模型标识是否一致 |
| 搜索模式 | 混合检索 | 报价单编号属精确查询；与仅语义检索结果比较 |
| 引用上限 | 本次起点 3000 tokens | 报价单与确认记录合计约此量；与 1500 tokens 结果比较覆盖度 |
| 最低相关度 | 本次起点 0.5 | 与 0.3 比较，观察无关片段是否减少 |
| 问题优化 | 开启 | 多轮追问场景；与关闭时检索词比较 |
| 引用内容输出 | 承接至回答节点 | 核对回答是否逐条对应引用原文 |

## 容易做错的三处
1. 把报价单有效期当作供货期限。错误输入：拟稿句称“可按报价单执行”。比较：报价单“有效期至2026年6月30日”与“供货排期以合同为准”。可观察结果：拟稿句超出原文范围。
2. 把样品确认当作合同生效。错误输入：引用 YP-2026-003 支持“已承诺供货”。比较：该记录写明“采购合同尚未签署”。可观察结果：待核实状态被写成确定事实。
3. 把检索命中当作授权。错误输入：以检索到报价单证明可下单。比较：检索输出与授权字段。可观察结果：授权状态仍为未获支持。

## 怎么确认配好了
1. 输入 GYS-2026-014 原文与拟稿句。比较报价对象、有效期、供货排期字段。满足条件：拟稿句与原文一致，或明确标注超出范围。
2. 输入 YP-2026-003 原文与“已承诺供货”表述。比较签署状态字段。满足条件：识别“尚未签署”，判定为待核实。
3. 输入明确纸面空数组 [] 承接至下游。比较下游设计是否按空引用处理。满足条件：下游不报错，且不声称检索一定返回空。
