# 连锁门店闭店清算的库存采购与供应商资料：HTTP 接口与外部系统

## 这个品类的数据长什么样

连锁门店闭店清算处理退出与资产回收，方向与选址开店相反。库存采购与供应商资料来自POS库存、固定资产系统、租赁合同与财务账，更新不定期、每店一次。闭店审批、库存清退单、租约解除协议、资产盘点表构成主要文档，其中库存清退单与资产盘点表决定采购退货、供应商对账与尾款结算的请求内容。这些资料在闭店当期才集中产生，HTTP 请求需要引用前方节点输出或全局变量，把门店、供应商、清退数量与授权状态逐项传入外部系统。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向对应地址发送请求，Params、Body、Headers 均可通过 {{}} 引用全局变量、系统变量与前方节点输出，URL 同样可以引用变量。Body 只在特定请求类型下生效，字符串引用需要加引号。返回值通过 JSON path 提取，输出类型选择字符串时会把对应 key 的值转成 json 字符串。chatId 与 responseChatItemId 在测试模式下不存在，调试时取到空值属于环境差异，不能当成业务故障。对话接口使用 APIKey 鉴权，调用 chat/completions 推荐在请求体传入 body.appId；appId 优先级为 body.appId、<apiKey>-<appId>、apikey 关联的 appId。authProxy 代理团队成员身份需要团队所有者开启，代理身份仍需要具备目标应用和会话权限。传入的 model、temperature 等字段无效，由编排决定。detail=true 时返回中间值，responseData 保存模块状态与完整结果，可据此核对请求是否真正发出以及返回了什么。

假设演练样本：某连锁品牌华东区一家门店于闭店当期提交库存清退申请。库存清退单原文写道：「门店编号 H-021，供应商编号 S-118，清退商品为货架与冷柜共 42 件，清退日期为闭店审批通过后第三个工作日，经办人为门店运营李某，审批状态为已通过闭店审批。」资产盘点表原文写道：「同店同供应商，盘点数量 42 件，盘点日期为清退日期前一日，盘点人签字齐全，未标注差异。」拟判定的交接请求句为：「依据上述两份材料，向供应商系统发起 42 件退货请求，并同步更新采购台账。」判定要点：主体为同店同供应商，对象为 42 件，期间为清退日期前后，字段为数量。两份材料数量一致，但清退单未载明退货授权条款，资产盘点表未载明供应商确认，因此该请求的授权边界属于未获支持，需要补充供应商确认或合同条款后才能执行。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 请求方法 | POST | 按外部接口文档选择，与 GET 样例比较路径参数使用方式 |
| 请求地址 | 含 {{baseUrl}} 变量 | 地址可引用变量，与固定地址写法比较可维护性 |
| Headers 鉴权 | Authorization 引用安全配置 | 凭证不写入公开样例，与明文写法比较风险 |
| Body 结构 | 引用清退单与盘点表字段 | 仅在相应请求类型下生效，与缺失字段的请求比较 |
| 返回值提取 | 按 JSON path 配置 key | 输出类型选择字符串时转 json 字符串，与对象输出比较 |
| detail 取值 | true | 需要中间值核对请求是否发出，与 false 比较可见范围 |

以上数值为本次假设试验起点，不是官方默认值，比较方法为同一请求在两种取值下的返回差异。

## 容易做错的三处

1. 把测试模式下 chatId 为空当成业务故障。输入为测试模式请求，比较项为 chatId 与 responseChatItemId 是否存在，可观察结果为文档说明测试模式下不存在，属于环境差异。
2. 把清退单数量直接当成退货授权。输入为假设样本两份材料，比较项为数量字段与授权条款，可观察结果为数量一致但授权未载明，属于未获支持。
3. 把 detail=false 的返回当成请求未发出。输入为同一请求两种 detail 取值，比较项为 responseData 是否包含模块状态，可观察结果为 false 时缺少中间值，需要改用 true 核对。

## 怎么确认配好了

1. 输入假设样本的清退单与盘点表原文，比较请求体中门店、供应商、数量字段与实际传入值，可观察结果为字段逐项对应且数量为 42，满足条件；若出现空值则记录缺口。
2. 输入拟判定交接请求句，比较其授权依据与材料原文，可观察结果为原文未载明退货授权，判定为未获支持，需要补充供应商确认。
3. 输入一条含 {{baseUrl}} 变量的地址与一条固定地址，比较两种写法的请求结果，可观察结果为变量写法可替换且请求可达，若返回 404 可按文档补充 v1 重试；空结果可用明确的纸面输入 [] 核对下游设计，不声称虚构规则一定返回 []。
