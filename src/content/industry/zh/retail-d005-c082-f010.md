# 逆向退货入仓质检的库存采购与供应商资料：引用来源与溯源

## 这个品类的数据长什么样

退货质检处理逆向包裹与商品等级，数据来源包括 WMS 退货模块、平台售后、承运商退件和质检台。日常文档为退货入库单、质检照片、等级判定表和重售上架单，更新频率为每件、日。库存采购与供应商资料环节需要把退货入库单、质检照片、等级判定表和重售上架单中的来源信息与供应商资料关联，供核对引用。

## 这些特征在「引用来源与溯源」这一环带来什么约束

知识库搜索节点可选择一个或多个相同向量模型的知识库，输出为数组格式的引用内容，长度可以为 0，即使没有搜索到内容，输出链路也会走通。引用上限按 tokens 控制，最低相关度仅在语义检索或结果重排时生效。混合检索通过 RRF 合并多路结果，Rerank 需要模型且按设置启用。检索不负责权限或实体隔离，跨不同向量模型的库不可共同关联。

假设演练样本：供核对的材料原文为“退货入库单 RMA-2024-0417，商品 A，数量 2 件，质检判定为 B 级可重售，质检照片编号 QC-0417-01 至 QC-0417-04，重售上架单 RS-0417 已生成，供应商为某供应商甲。”一条待判定的拟稿句为：“该退货入库单对应的质检照片与重售上架单均已归档，供应商甲资料完整。”该拟稿句需要核对材料原文中是否载明质检照片与重售上架单的归档状态以及供应商甲资料的完整性。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 核对方法 |
| --- | --- | --- |
| 关联的知识库 | 选择退货质检相关的一个知识库 | 核对已选知识库的向量模型标识是否一致，排除不同向量模型的库 |
| 搜索模式 | 混合检索 | 同时使用语义检索与全文检索，通过 RRF 合并结果 |
| 引用上限 | 假设起点为 3000 tokens | 与退货入库单和质检照片的文本长度比较，观察引用内容是否覆盖所需字段 |
| 最低相关度 | 假设起点为 0.3 | 仅在语义检索或结果重排时生效，与重排得分比较，观察低相关结果是否被过滤 |
| 结果重排 | 按设置启用 | 确认重排模型是否可用，比较重排前后候选顺序 |
| 引用内容输出 | 数组格式，长度允许为 0 | 用纸面输入 [] 核对下游设计是否承接空数组 |

## 容易做错的三处

1. 把检索输出当作授权执行。知识库搜索仅返回引用内容，不构成供应商资料审核或重售上架授权。核对时应比较引用内容与退货入库单原文，确认是否载明授权状态。
2. 把最低相关度当作实体或权限过滤。最低相关度是 0-1 的数值过滤阈值，不排除无关业务或未授权记录。核对时应比较过滤前后引用内容，确认是否仅按得分过滤。
3. 把跨向量模型的知识库共同关联。相同向量模型才可共同关联，跨模型不可共同关联。核对时应检查知识库的向量模型标识，排除不符合者，记录实际观察。

## 怎么确认配好了

1. 输入假设样本中的材料原文和拟稿句，比较拟稿句与材料原文是否同主体、同期间、同一字段。若材料原文未载明质检照片与重售上架单的归档状态，则拟稿句未获支持，需记录证据缺口。
2. 输入纸面引用内容 []，比较下游节点是否承接空数组并继续执行。若下游节点要求非空引用，则需调整下游设计，不能声称虚构规则检索一定返回 []。
3. 输入退货入库单 RMA-2024-0417 的供应商字段，比较引用内容是否包含供应商甲。若引用内容未包含供应商甲，则记录为未命中，不推断供应商资料完整或不完整。
