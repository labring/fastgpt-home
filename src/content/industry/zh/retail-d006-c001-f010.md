# B2B平台撮合交易的门店服务与内部培训：引用来源与溯源

## 这个品类的数据长什么样

在B2B平台撮合交易的门店服务与内部培训中，本页说明FastGPT的引用来源与溯源如何衔接资料。销售培训中的示例询问、供应商自述和学员答卷按语境回指。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

B2B培训可拟讲义“先询问客户所需表面”、示例对话“客户想看哑光”和供应商介绍“可提供多种表面”。学员答卷写“哑光已确认可供”。问这一结论是否有来源时，讲义指导收集需求，示例只给偏好，介绍说明自述范围，没有本次供货确认。引用要保留示例身份，不能把教材里的客户当作真实在谈订单，也不能用答卷重复了同一词来证明答案已经符合原文。

## 配置怎么定

| 培训来源核对项 | 教材身份与证据范围 | 验收动作 |
| --- | --- | --- |
| 讲义行动 | 先收集需求 | 不当供货承诺。 |
| 示例偏好 | 想看哑光 | 核是否最终选择。 |
| 供应方自述 | 多种表面 | 核商品范围。 |
| 答卷身份 | 学习输出 | 不循环证明自身。 |
| 引用传入 | 教材与介绍 | 核实际到达内容。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是想看哑光被改成最终选择，应回读示例问题与回复，核是否另有确认文字。第二处是供应商多种表面介绍被写成本次可供，应查当前商品和供货依据，不以通用能力填交易条件。第三处是学员答卷被反向引用为标准答案，应核讲义、示例与答卷的身份，找出结论真正来自哪里。三项分别看需求状态、适用范围和证据层级，不让一份学习输出循环证明自身。

## 怎么确认配好了

验收可分别问讲义要求先做什么、示例客户表达什么、供应商自述覆盖什么，再要求逐句说明答卷的依据。实际引用若只收到答卷，应追查教材和供应商文字是否传入，保留供货条件待核。后来补充的确认要对应示例设定的商品，不能借另项表面补证。空引用也不能直接说明学员答错；此练习只核资料支持范围，不声称已经培训合格、成交或完成供货。
