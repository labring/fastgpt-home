# MCN机构达人管理的门店服务与内部培训：引用来源与溯源

## 这个品类的数据长什么样

在MCN机构达人管理的门店服务与内部培训中，本页说明FastGPT的引用来源与溯源如何衔接资料。达人培训的口播示范、批注和发布范围按素材版本核对。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

达人培训可拟讲义“仅示范介绍次序”、口播样本“先展示杯盖，再展示杯体”和批注“避免遮住标识”。样本页上另有旧活动的发布范围说明。学员询问是否应照读全部台词并可用于本轮活动时，应先区分次序示范、画面意见和旧用途来源。演示文本未要求逐字照读，标识批注也不说明发布范围。引用要保留本轮活动及样本身份，不能因示范片被选进课件就推定已经获得当前发布许可。

## 配置怎么定

| 培训来源核对项 | 教材身份与证据范围 | 验收动作 |
| --- | --- | --- |
| 示范限制 | 只讲次序 | 不扩成逐字脚本。 |
| 画面意见 | 标识可见 | 核局部批注。 |
| 活动范围 | 旧活动说明 | 核本轮适用。 |
| 审核结果 | 未给整片结果 | 另查实际记录。 |
| 当前素材 | 版本与达人对应 | 核新增来源。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是次序示范被写成必须逐字使用的台词，应核讲义限制及实际要求，不把展示结构变成词句规定。第二处是旧活动范围被移作本轮许可，应核活动、素材版本与对应说明。第三处是标识批注被称为整片已审核，应读取批注所指画面及真实审核结果，单项意见不证明全部内容通过。三项分别查示范意图、用途适用和审核范围，不以培训老师提到过就确认。

## 怎么确认配好了

验收分别问示范关注什么、批注改哪处、当前用途依据在哪里，逐项看回答真实引用。若引用只含口播样本，应保留讲义限制与用途页缺口，不把缺页判成禁止发布。补入本轮说明后核其所述素材，不将其他达人或旧剪辑的范围延用。空引用追查来源与传递；这项文字练习不实测口播表现，也不执行审核或发布，回答只能说明当前文本实际支持的做法。
