# Shopify独立站订单履约的门店服务与内部培训：知识库检索与召回

## 这个品类的数据长什么样

Shopify独立站订单履约由商家自行配置支付、运费和履约服务，平台不统一自动退货。这一差别决定门店服务与内部培训的知识库需要覆盖商家自设的运费模板、发货标签与退款记录。主要数据来源为 Shopify Admin、支付网关、承运商系统与库存地点数据，日常文档为订单详情、运费模板、发货标签与退款记录，更新频率为每单与日。门店服务与内部培训场景下，运营人员依据这些文档回答履约问题，检索结果只提供引用内容，不构成退款、改址或补发的授权。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的库。检索以库为最小搜索单位，集合仅作分类管理。一次检索会按输入与参数组合问题优化、语义检索、全文检索、混合检索、图片检索与重排，最终经相似度过滤与引用上限裁剪输出引用内容，输出可为长度 0 的数组。最低相关度仅在语义检索或使用结果重排时生效，是过滤阈值，不承担权限或实体隔离。引用上限以 token 为单位。问题优化用于指代消除与问题扩展，会额外调用模型。图片检索须有图像输入与相应模型能力，重排须具备模型并按设置启用。

假设演练样本：某独立站门店服务培训资料原文为三句——“本店退货申请须在签收后七日内提出，超期申请由门店主管人工复核。退款仅退至原支付渠道，运费不退。运费模板‘华东标准’适用于江苏、浙江、上海，首重一公斤。”一条待判定拟稿句为：“签收后第十日提出的退货申请，门店可直接办理退款至原支付渠道。”该拟稿句与原文“七日内”及“超期由主管人工复核”不一致，属未获支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| 关联知识库 | 门店服务库与履约库，二者向量模型标识一致 | 核标识，排除不同向量模型的库 |
| 搜索模式 | 先语义检索，编号类问题另测全文检索 | 比较同一问题在两种模式下的引用内容 |
| 引用上限 | 起点设为能容纳一段运费模板全文的 token 量 | 与长短不同的实际资料比较完整性 |
| 最低相关度 | 起点取 0 至 1 区间中部值 | 先标注相关与无关样本，再与阈值比较 |
| 问题优化 | 多轮追问场景开启，单轮明确问题关闭 | 比较原问题与优化后问题的主体是否被改错 |
| 结果重排 | 候选较多且问题完整时启用 | 与未重排时同一问题的排序比较 |

上述数值均为本次假设试验起点，非官方默认值。RRF 是混合检索结果的融合过程，不作为独立开关配置。

## 容易做错的三处

1. 把检索命中当作退款或改址授权。输入为引用内容数组，比较其中是否含授权字段，观察结果是引用内容不改变业务状态，退款仍需下游实现。
2. 将不同向量模型的库共同关联。输入为两库的向量模型标识，比较标识是否一致，观察结果是标识不符者须先排除，不能执行跨模型检索来比较漏召回。
3. 把最低相关度当作权限或实体过滤。输入为相似度得分与目标记录，比较得分与访问权限两个字段，观察结果是得分高低不改变记录是否属于当前门店。

## 怎么确认配好了

1. 输入为假设样本原文与拟稿句“签收后第十日提出的退货申请，门店可直接办理退款至原支付渠道”。比较拟稿句与原文的期间字段“七日内”及处理主体“门店主管人工复核”。观察结果为期间与主体均不一致，判定该拟稿句未获支持。
2. 输入为上述样本原文与一条检索问题“华东标准运费模板适用哪些地区”。比较引用内容是否包含“江苏、浙江、上海”与“首重一公斤”。观察结果为引用覆盖该范围即满足，未覆盖则记录缺口，不保证首条命中。
3. 输入为纸面空结果数组 [] 与下游交接设计。比较下游是否按空引用继续走通并记录未获支持，观察结果为下游不因空结果自动触发退款或补发。若未配置该承接，记录为待实现，不声称一定返回空。
