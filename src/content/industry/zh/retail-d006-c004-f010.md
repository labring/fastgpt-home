# Temu半托管卖家运营的门店服务与内部培训：引用来源与溯源

## 这个品类的数据长什么样

在Temu半托管卖家运营的门店服务与内部培训中，本页说明FastGPT的引用来源与溯源如何衔接资料。卖家培训中的政策摘录、讨论答案和版本更新按各自来源核对。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

Temu培训可拟内部课件“包装要求以当前商品页为准”、课堂摘录“外袋保持完整”和讨论答案“所有商品都用同一种袋”。另有一条更新提醒“某类商品补充内衬说明”，但未给补充页。询问是否能按讨论答案指导全部商品时，摘录仅描述外袋状态，讨论答案只是学员概括，更新提醒还提示资料缺项。引用要核商品类别及版本，不能从一条普通要求推出统一包装，也不把提醒标题当完整新增规范。

## 配置怎么定

| 培训来源核对项 | 教材身份与证据范围 | 验收动作 |
| --- | --- | --- |
| 摘录范围 | 外袋状态 | 不扩成袋型统一。 |
| 讨论身份 | 学员概括 | 回溯真实来源。 |
| 更新缺页 | 只给提醒 | 取得原文再读。 |
| 商品类别 | 要求按对象核 | 不套全部商品。 |
| 条件到达 | 商品页与补充页 | 核实际引用。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是外袋完整被扩大成所有商品同袋，应核当前商品页的具体包装对象及条件。第二处是讨论答案被称为平台正式规则，应追溯原始来源与文书身份，课堂输出不提升来源等级。第三处是补充内衬提醒被写成已经读过完整要求，应取得对应补充页并核版本，不能从标题补材料或尺寸。三项分别查适用范围、来源地位和更新内容，不用更多课堂话语替代实际要求。

## 怎么确认配好了

验收可问摘录实际说什么、讨论新增了什么、更新仍缺哪份原文，保存回答采用的引用。只有旧摘录时应保留当前要求未核，不凭资料缺失宣布商品不合规。补入商品页与补充页后，核类别、版本和条件是否同时进入回答；没有返回不等于原页不存在。此练习不宣称真实平台现行规则，也不执行包装审核或修改商品页，操作建议需依实际适用资料决定。
