# Temu半托管卖家运营的门店服务与内部培训：知识库检索与召回

## 这个品类的数据长什么样

Temu半托管卖家运营与全托管供货的差别在于，卖家要维护海外库存并自行发货，日常资料围绕商品申报表、海外库存表、价格申报和平台履约单展开。门店服务与内部培训场景中，运营人员需要把这几类资料的检索结果用于交接和培训答疑，资料更新频率为日或每单。检索结果只提供引用内容，不承担授权、审批或写入职责。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。搜索模式分为语义检索、全文检索和混合检索，混合检索通过 RRF 融合多路结果，结果重排使用 ReRank 模型二次排序。最低相关度仅在语义检索或使用结果重排时生效，引用上限以 token 为单位。检索输出为数组，长度可以为 0，即使没有搜索到内容，输出链路仍然走通。

假设演练样本：某门店培训资料中，商品申报表片段写明“主体：华东某跨境供货商；对象：半托管店铺A的户外折叠桌；状态：申报表已于2025年3月10日提交平台，平台回执显示待审核；有效范围：仅覆盖该店铺该商品。”另一份内部交接请求拟稿句为“店铺A户外折叠桌申报已获批准，可安排海外仓发货并同步库存表。”待判定该拟稿句是否与申报表原文一致。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联含商品申报表、海外库存表、价格申报、平台履约单的同一向量模型库 | 先核对各库向量模型标识是否一致，不一致者排除，不执行跨模型检索 |
| 搜索模式 | 先按全文检索测试申报表编号与状态字段 | 用假设样本中的“待审核”字段比较语义检索与全文检索的命中差异 |
| 引用上限 | 设为覆盖一份申报表片段所需的 token 量 | 用长短不同的申报表与履约单片段测试内容是否被截断，再调整 |
| 最低相关度 | 先不启用，待标注相关与无关样本后再设阈值 | 该值仅在语义检索或结果重排时生效，启用前需有标注样本 |
| 问题优化 | 先关闭，用完整问题测试 | 比较原问题与优化后问题，核对主体“店铺A”与对象“户外折叠桌”是否被改错 |
| 结果重排 | 仅在具备 ReRank 模型且按设置启用时使用 | 重排得分可作为过滤依据，需与未重排结果比较排序变化 |

## 容易做错的三处

1. 把检索输出当作授权执行。假设样本中申报表状态为“待审核”，检索到该片段不代表批准已生效，拟稿句“已获批准”属于未获支持。
2. 把最低相关度当作权限或实体过滤。该值是相似度过滤阈值，不排除无关业务或未授权记录，检索不等于授权。
3. 把跨向量模型的知识库强行关联。节点要求关联相同向量模型的知识库，模型标识不一致时应排除并记录，不编造共同关联后的运行结果。

## 怎么确认配好了

1. 输入假设样本中的申报表原文与拟稿句“店铺A户外折叠桌申报已获批准，可安排海外仓发货并同步库存表”，比较两者主体、对象、状态是否同字段。原文状态为“待审核”，拟稿句写“已获批准”，同字段取值互斥，判定为未获支持。若原文状态字段缺失，则记录为证据缺口。
2. 输入假设样本中的申报表片段，分别用全文检索和语义检索查询“待审核”，比较两种模式返回的引用内容是否包含状态字段。若语义检索返回内容不含状态字段，而全文检索包含，则记录该差异，不声称某一模式必然更优。
3. 输入一个明确的纸面空结果场景，核对下游节点是否按引用长度为 0 的链路继续执行。若下游设计为收到空数组后进入人工核对分支，则记录该设计；不声称虚构规则检索一定返回空数组。
