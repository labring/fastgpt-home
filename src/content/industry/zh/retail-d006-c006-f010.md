# 一般贸易出口报关的门店服务与内部培训：引用来源与溯源

## 这个品类的数据长什么样

在一般贸易出口报关的门店服务与内部培训中，本页说明FastGPT的引用来源与溯源如何衔接资料。出口填表培训的占位文本、品名解释与实际材料按文书身份核验。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

出口材料培训可拟空表“此处填写商品名称”、示例页“桌面支架，示例文字”及讲义“实际名称回原单据核”。学员练习表却填了“桌架配件套装”。问能否据示例确认填写正确时，示例只展示文字位置，讲义要求真实单据，学员又增加了配件和套装含义。当前未提供本次商品原单据。引用应保留占位与示例标识，不把练习填写当作真实出口货物，也不把示例名当所有支架的规范称呼。

## 配置怎么定

| 培训来源核对项 | 教材身份与证据范围 | 验收动作 |
| --- | --- | --- |
| 占位身份 | 填写提示 | 不当已填记录。 |
| 示例名称 | 桌面支架 | 核示例标识。 |
| 新增组成 | 配件与套装 | 找商品依据。 |
| 来源缺项 | 本次原单据 | 明确待补。 |
| 格式与事实 | 字段位置正确不补真实性 | 逐句查来源。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是示例品名被当本次单据原文，应核示例标识和实际来源，不能由教材补商品事实。第二处是配件套装被视为桌面支架的同义表述，应逐项核商品组成依据，名称近似不说明对象相同。第三处是空表提示被引用为已经填齐的记录，应查看练习内容及对应原单据，提示句没有记录本次填写。三项分别查来源身份、语义增加和表格内容，不用格式正确推事实正确。

## 怎么确认配好了

验收先问示例意在展示什么，再问学员新增哪些信息，以及还缺什么来源，逐句读实际引用。只有教材时，应列原商品单据待核，不代出申报结论或说明已通过审查。补入新的自拟商品页可继续练习，但须明示其假设身份，不能包装成真实客户证据。空引用追查范围与传入；本页不提交表格，也不决定海关归类、报关资格或放行状态，实际材料仍需独立核验。
