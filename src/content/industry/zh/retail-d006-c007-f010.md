# 一般贸易进口报关的门店服务与内部培训：引用来源与溯源

## 这个品类的数据长什么样

在一般贸易进口报关的门店服务与内部培训中，本页说明FastGPT的引用来源与溯源如何衔接资料。进口单据课件的字段标题、摘录翻页和角色解释分别回指。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

进口单据培训可拟两页摘录：前页标题“通知联系人”，续页只留“远航仓配”，讲义另写“结合字段标题阅读”。还有一段学员解释“远航仓配就是买方”。问这项解释是否被单据支持时，续页名称缺了角色标题，不能独立变成买方身份。练习也未提供买卖主体页。引用应保留前后页关系，不因同一名称出现在多张纸上就统一成所有角色，更不能由学员解释倒填缺失字段。

## 配置怎么定

| 培训来源核对项 | 教材身份与证据范围 | 验收动作 |
| --- | --- | --- |
| 页间关系 | 标题在前页 | 核对应续页。 |
| 公司角色 | 通知联系人 | 不改作买方。 |
| 学员解释 | 独立学习输出 | 不当正式单据。 |
| 文件归属 | 其他练习同名 | 核编号及页序。 |
| 主体缺项 | 未给本题主体页 | 保留待核。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是无标题续页被写成买方，应核对应前页、页间关系和字段标题，不单取公司名。第二处是学员解释被当正式单据，应对解释与原摘录的身份，另找真实主体字段。第三处是其他练习的同名仓配页被拼成本次续页，应查练习编号、页序及文件身份。三项分别查上下文恢复、来源等级和文件归属，不让引用展示完整的外观掩盖实际角色缺口。

## 怎么确认配好了

验收可分别问该名称归在哪个标题下、学员解释新增了什么、两页如何对应，检查回答实际收到的引用。若只有续页，保留角色待核，不能宣布资料矛盾或买方未知事实已确定。补入主体页后仍要核是否本题，不借同名企业资料补成全套角色。空引用追查范围与传递；本练习只核阅读关系，不变更任何单据主体，也不把可读字段当完成进口业务或取得操作授权。
