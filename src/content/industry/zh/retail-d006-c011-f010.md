# 仅退款争议处理的门店服务与内部培训：引用来源与溯源

## 这个品类的数据长什么样

在仅退款争议处理的门店服务与内部培训中，本页说明FastGPT的引用来源与溯源如何衔接资料。争议培训的案例摘录、评价意见和缺少的后续答复分开。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

仅退款客服训练可拟案例摘录“买家称少一件”、答题指导“先核订单与包装记录”和评语“追问对象较清楚”。练习答卷却写“仓库已证实少发，同意退款”。案例没有仓库答复，评语也只评价提问。引用应保留这是资料收集练习，不能把老师对问题清楚的评价扩大为争议结论正确，更不能将买家主张替换成仓库承认。少件涉及哪个商品和包裹，在当前文字里也仍需核对。

## 配置怎么定

| 培训来源核对项 | 教材身份与证据范围 | 验收动作 |
| --- | --- | --- |
| 主张归属 | 买家陈述 | 不改作仓库承认。 |
| 评语对象 | 提问清楚 | 不当结论认可。 |
| 指导阶段 | 尚需核资料 | 不当已执行。 |
| 少件对象 | 商品与包裹未核 | 核新增对应。 |
| 处理结果 | 当前未给 | 不代作决定。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |

| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是买家称少被写成仓库证实，应核叙述者与后续原始记录，保留主张身份。第二处是评语清楚被写成结论获认可，应读评语针对的是问题还是判断，不用评价词补审核结果。第三处是先核包装指导被写成已经检查完，应查订单及包装实际资料，步骤提示不记录执行。三项分别查说话方、评价范围和作业证据，不从一份高完成度答卷反推这些资料都已具备。

## 怎么确认配好了

验收分别问案例由谁提出何种主张、评语认可什么、指导要求补什么，逐句展开实际引用。若只取评语，不能宣称已读客诉原文；若只读案例，也不推少件属实或退款应获准。新增记录要核本题商品及包裹，并注明仍是演练。空引用追查范围和传入，本页不决定争议责任或退款处理，也不把提出退款与订单未履约等同，实际结论需要各自原始依据。
