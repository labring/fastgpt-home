# 便利店加盟门店督导的门店服务与内部培训：工作流编排

## 这个品类的数据长什么样

在便利店加盟门店督导的门店服务与内部培训中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

加盟督导培训可先收学员本次问题、陈列标准原句与巡店记录说明。自拟文字给标准和发现事项，没有整改复核，用来练习区分应该怎样做与门店是否已经做到。表单提交后，后续阅读步骤应收到来源身份与适用门店，不能把培训中的解释当成现场检查。标准文本可作为学习材料，不证明人员已掌握操作，也不代表整改或加盟审查已经通过。 陈列照片只支持观察所拍布局，不说明学员能够复现这项操作，后者仍需实际考核依据。

## 配置怎么定

| 培训核对 | 本题自拟输入 | 观察依据 |
| --- | --- | --- |
| 标准与现场 | 陈列要求与巡店发现分开 | 未把讲解当现场核验 |
| 门店来源 | 照片属于其他门店 | 核说明后移出错配 |
| 补复核去向 | 只收到旧巡店标题 | 查选择及接收值 |
| 新增材料 | 本店本次复核原文 | 答复实际引用新来源 |
| 正式认定 | 测验或整改关闭另办 | 流程未代替合格结果 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

可让学员选择查看标准说明或补本店复核，分别检查所接的“是”分支。若补复核路径仍只收到旧巡店标题，应排查选择和实际接收值，保留复核缺口。若其他门店照片被传为本店完成依据，要核图片说明与来源对象，先移出错配再读，不能由节点继续执行推定现场情况已核实。 若看过陈列照片就判学员能独立复现，应核照片只观察哪种布局，再查本学员实际操作考核；图片不提供人员能力依据，不能把阅读完成改成操作合格。

## 怎么确认配好了

验收沿问题、提交原文、分支接收与培训答复回查，补本店复核后复问，核新来源是否实际参与解释。交互状态由节点触发记录并等待人员处理，不另设全局状态开关认定培训完成。测验认定、整改关闭或督导回写需要后续节点或外部业务另行落实，流程结束不证明学员已合格或门店已整改。
