# 便利店加盟门店督导的门店服务与内部培训：引用来源与溯源

## 这个品类的数据长什么样

在便利店加盟门店督导的门店服务与内部培训中，本页说明FastGPT的引用来源与溯源如何衔接资料。督导培训的示范照片说明、门店回复和评分例题各核身份。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

门店督导培训可拟示范说明“此图只看价签位置”、门店练习回复“标识已挪到左侧”和评分例题“请评价是否便于阅读”。讲义另提醒“实际验收需当前标准”。学员结论为“左侧就是所有门店标准位置，本店已验收”。这些文字没有给实际标准或验收结果，回复也只记录移动动作。引用需要保留示范只看位置的范围，不能由一道阅读评价题推出通用陈列要求，更不从挪动动作证明已经符合要求。

## 配置怎么定

| 培训来源核对项 | 教材身份与证据范围 | 验收动作 |
| --- | --- | --- |
| 观察维度 | 价签位置 | 不推文字正确。 |
| 移动行动 | 标识挪左 | 不当验收通过。 |
| 通用要求 | 单例不定全店 | 核标准及店型。 |
| 练习身份 | 模拟门店回复 | 不当真实作业。 |
| 易读结果 | 未作实际测量 | 保留评价条件。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是左侧动作被写成全店通用标准，应查当前标准及适用店型，不将单例位置当规范。第二处是门店练习回复被当实际验收记录，应核材料身份和所述行动，移动不代表检查通过。第三处是价签位置示范被扩成文字内容完全正确，应回读示范范围并核实际价签文字，位置观察不覆盖内容。三项分别查标准适用、事件身份和观察维度，不用一次练习补齐多项判断。

## 怎么确认配好了

验收分别问示范观察哪一维、回复发生什么、例题要求评价什么，再将答案回指真实引用。若只有门店回复，应保留适用标准和验收结果待核，不直接判不合格或已合格。补入自拟标准时明确用途与店型，不能称实际公司现行制度。空引用继续追查范围和传递；本页不执行巡店或评分，也不证明阅读便利性已经实测，实际接受仍需对应材料及责任人确认。
