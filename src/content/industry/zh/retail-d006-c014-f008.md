# 便利店鲜食订货的门店服务与内部培训：工作流编排

## 这个品类的数据长什么样

在便利店鲜食订货的门店服务与内部培训中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

鲜食订货培训可先收学员想了解的订货步骤、报损原句及临期处理说明，温控资料另列来源。自拟材料只说明某次有报损，没有对应温控依据，不推定原因或给保存阈值。表单提交后要核阅读步骤收到的材料性质，订货安排、商品处理与测量记录各回答不同问题，不能从有一张报损单推断整批食品质量或门店操作合格。

## 配置怎么定

| 培训核对 | 本题自拟输入 | 观察依据 |
| --- | --- | --- |
| 问题范围 | 订货与处理说明分别读 | 没有提供质量鉴定 |
| 原因缺口 | 报损有，温控资料缺 | 未从发生推原因 |
| 班次错配 | 其他班次记录传入 | 核时间批次后移出 |
| 下游判断 | 报损文字被改成原因结论 | 对照原句修正再测 |
| 业务责任 | 培训认定和实际处理另核 | 提交未代表业务批准 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

可分别选择看订货说明、补温控记录或交负责人核批次，验证实际分支。若补记录路径把另一班次资料送入，应排查时间说明和批次对应，保留本次缺口。若报损描述在下游被改成原因结论，需回查原句与新增判断，纠正后复测，不能由学员选择推定这些业务依据已经审核。 若订货单被训练答复写成商品已经到店，应回查需求安排原句与本批实际接收凭据；计划下单与接收货物不同，缺对应记录时不能补出到货结果。

## 怎么确认配好了

验收分别看原问题、提交文本、接收范围和解释出处，补同批材料后再问，确认答复仍区分记录与原因。交互节点等待后继续，不自动取得设备或仓库数据。人员培训认定、实际订货、食品处理或记录回写需业务负责人另核权限与依据；流程完成只支持检查资料承接，不构成质量鉴定、处理建议已获批准或人员能力合格的结论。
