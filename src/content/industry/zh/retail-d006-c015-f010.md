# 信用证审单交单的门店服务与内部培训：引用来源与溯源

## 这个品类的数据长什么样

在信用证审单交单的门店服务与内部培训中，本页说明FastGPT的引用来源与溯源如何衔接资料。审单培训的正确格式示例、待核事项和老师评语分别追溯。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

审单培训可拟示例页“此处展示文件排列”、练习清单“品名附页待核”和老师评语“排列清楚”。学员答卷进一步写“全部单据已符合本次要求”。示例只讲顺序，评语只谈排列，待核附页仍未给出。引用应保留这三种用途，不把清楚的呈现当内容相符，更不能从老师未指出错误推定已经完成全部核对。本练习没有真实信用证或银行处理记录，也不据此作正式审单意见。

## 配置怎么定

| 培训来源核对项 | 教材身份与证据范围 | 验收动作 |
| --- | --- | --- |
| 示例用途 | 只讲排列 | 不当内容答案。 |
| 评语对象 | 排列清楚 | 不扩全部通过。 |
| 明确缺项 | 品名附页 | 在摘要中保留。 |
| 逐项核验 | 实际依据未给 | 不补审单意见。 |
| 旧例题 | 不替本题附件 | 核题目归属。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |
| `引用输入承接` | 核回答环节实际接收的引用。 |
| `引用展示核对` | 逐项回查展示来源与原文。 |
| `资料时效核对` | 资料身份和有效版本分别核对。 |

## 容易做错的三处

第一处是格式示例被当内容正确答案，应读示例用途及本题实际要求，形式不补事实。第二处是排列评语被写成全部要求通过，应核评语对象，另找逐项内容核对依据。第三处是待核附页被摘要省略后称资料齐全，应对清单缺项与实际引用内容，取得本题附页后再看。三项分别查示例层级、评价范围和材料覆盖，不让肯定词掩盖明确保留的待核状态。

## 怎么确认配好了

验收可分别问示例教什么、评语认可什么、清单尚缺什么，再逐句核引用。若只有老师评语，应保留本题要求与附页待核，不补不符点或宣布可交单。新增附页要核它对应本题及修改背景，旧例题不得直接替换。空引用追查范围和传递；本页不替银行接受单据，不执行交单，也不把学员文章完整或版式整齐当真实能力考核已经通过，评估结果需要明确的实际依据。
