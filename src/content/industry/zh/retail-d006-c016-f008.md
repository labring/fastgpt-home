# 加盟商培训与开业辅导的门店服务与内部培训：工作流编排

## 这个品类的数据长什么样

在加盟商培训与开业辅导的门店服务与内部培训中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

加盟开业培训流程可先收学员问题、适用SOP与本店检查事项。自拟输入只有签到和开业清单说明，没有考核内容或现场复核。表单提交后应核后续步骤保留这些缺口，不能把参加培训写成已经掌握SOP，也不能由清单存在推定门店已准备完成。培训解释使用哪版手册应随原文传下去，不从门店名称自行选择全部适用要求。

## 配置怎么定

| 培训核对 | 本题自拟输入 | 观察依据 |
| --- | --- | --- |
| 出勤边界 | 签到和检查清单已给 | 未写成能力或开业通过 |
| 手册版本 | 旧SOP被当成当前适用 | 回查来源和适用说明 |
| 考核去向 | 补考核仍只传签到标题 | 核实际连接及接收值 |
| 补齐复问 | 本店考核或现场原文 | 解释实际承接新依据 |
| 正式批准 | 培训认定与开业分别核 | 流程未充作合格凭据 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

可分别选择补考核材料或阅读SOP，逐项看实际“是”分支。若补考核仍只送签到标题，要排查接收值和连接，避免把出勤代替能力依据。若旧版手册在传递中被当成当前版本，应回查来源身份和原句，补适用说明后复测；人员选择继续学习，不等于总部已批准该门店开业。 若开业清单仅列待查项目，却被答复写成检查全部完成，应核各项原句性质及本店实际复核记录；清单存在不提供完成结果，不能由交互结束推出开业通过。

## 怎么确认配好了

验收沿问题、填写值、资料版本、分支结果与答复逐项核，补本店考核或现场资料后重复主题，看新增依据确实进入解释。交互状态的记录属于节点行为，不是另一个全局开关宣布培训完成。考核认定、开业批准和档案回写需后续节点或外部流程独立验权限及真实回执，流程结束不能证明学员通过或开业条件已满足。
