# 加盟费与保证金结算的门店服务与内部培训：工作流编排

## 这个品类的数据长什么样

在加盟费与保证金结算的门店服务与内部培训中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

加盟结算培训可先练习区分合同计划、开票、台账记录与银行依据，不在样例中写金额。自拟输入只有计划和通知，缺实际办理凭证；表单收集这些原句及主体，传给后续解释，不自动完成财务对账。学员询问某条如何理解时，答复应限于资料记载，不能从“已开票”推成“已收款”，也不能从通知已发推定扣款已完成。

## 配置怎么定

| 培训核对 | 本题自拟输入 | 观察依据 |
| --- | --- | --- |
| 术语区分 | 计划开票与实际银行依据 | 未由开票推到账 |
| 通知边界 | 有通知无执行记录 | 未推定已经扣款 |
| 凭证去向 | 补记录却只收到通知标题 | 查接收值并保留缺口 |
| 主体错配 | 其他门店台账进入 | 核合同身份后移出 |
| 财务权限 | 实际处理与结算另办 | 培训选择未代替授权 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

可选择补对应凭证或只看合同原句，分别检查接收路径。若补凭证只收到通知标题，应排查实际传值，保留执行依据缺口。若其他门店台账进入本主体说明，需核合同对象和资料身份，先移开错配再读；节点继续向下不表示账务关系已被核准，更不能让学员选择代替财务授权。 若发票原句只记已经开具，学习答复却写成款项到账，应分别核开票说明和本主体银行依据；一份发票不提供资金接收事实，缺凭据时撤去到账结论。

## 怎么确认配好了

验收保留主体、各材料性质与解释出处，补同主体业务记录后再问，核计划与执行仍清楚分开。交互状态由节点触发记录，不用全局状态开关假定财务审查已完。实际扣款、账务修改或结算确认需另接业务流程并核权限与真实回执；本次培训流程结束不证明结算已完成，也不构成对合同效力或处理正当性的判断。
