# 加盟费与保证金结算的门店服务与内部培训：引用来源与溯源

## 这个品类的数据长什么样

在加盟费与保证金结算的门店服务与内部培训中，本页说明FastGPT的引用来源与溯源如何衔接资料。结算培训的分类卡、空白收据和审批示范按材料用途追溯。所用场景为自拟文字测试。

## 这些特征在「引用来源与溯源」这一环带来什么约束

加盟结算培训可拟分类卡“保证金与服务费分别登记”、空白收据“用途待填”和审批示范“资料齐后送复核”。学员把空白收据归成保证金退款已通过。当前材料没有实际收款、申请或审批记录。分类卡可以说明练习要求区分用途，空表不能确定本笔类别，示范也只给未来动作。引用需要保留教材与事件的界线，不由常见流程补一笔不存在的交易，更不能让学员分类同时证明审批结果。

## 配置怎么定

| 培训来源核对项 | 教材身份与证据范围 | 验收动作 |
| --- | --- | --- |
| 类别教学 | 两个用途分列 | 不填本笔用途。 |
| 空表状态 | 用途未填 | 不当实际收据。 |
| 示范条件 | 资料齐后 | 保留前置条件。 |
| 审核动作 | 送复核 | 不当已经通过。 |
| 交易存在 | 没有实际事件 | 保留练习身份。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `关联的知识库` | 同一检索节点关联的库需使用相同向量模型。 |
| `引用内容输出` | 输出为数组，可为空且继续传递。 |

| `引用展示核对` | 逐项回查展示来源与原文。 |

## 容易做错的三处

第一处是用途待填被认作保证金，应核实际用途来源，不以分类卡中的一个类别代空缺。第二处是送复核示范被写成已经通过，应读动作阶段与条件，找实际审核记录才谈结果。第三处是空收据被用来证明已收款，应核文件身份及填写内容，收据模板不是收款凭证。三项分别查类别依据、流程状态和交易存在，不从同一训练主题推出这些事实已经齐全。

## 怎么确认配好了

验收分别问分类卡要求区分什么、空表还缺什么、示范动作何时才发生，逐句查看实际引用。只有分类卡时，保留交易用途与状态未核，不判断能否退还；只有示范也不补申请人和审核人。新增自拟收据或结果页应明确为练习并核对应事项，不能成为客户真实款项记录。空引用追查范围和传递，本页不提供收费或退款规则、不执行结算，也不把课堂材料识别正确当实际业务审核已完成。
