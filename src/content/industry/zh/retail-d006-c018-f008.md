# 区域经销商库存补货的门店服务与内部培训：工作流编排

## 这个品类的数据长什么样

在区域经销商库存补货的门店服务与内部培训中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

经销商培训可先练习怎样阅读补货申请、库存说明与出库记录。自拟输入有需求和回款计划，没有本次出库或到账凭证，不能从计划推出实际执行。表单收集学员问题、经销商身份及相关原句，传到后续阅读时应保留来源范围；库存表标题不提供全部计算定义，也不能由商品同名就合并不同经销商的可用量。

## 配置怎么定

| 培训核对 | 本题自拟输入 | 观察依据 |
| --- | --- | --- |
| 计划执行 | 需求和回款安排分开 | 未写成实际出库到账 |
| 库存口径 | 同商品不同经销商资料 | 未按名称合并可用量 |
| 补出库路径 | 仍收到原补货申请 | 查接收值后补执行依据 |
| 性质改写 | 回款计划变成到账结论 | 回查原句修正再问 |
| 业务认定 | 下单对账与考核另办 | 状态未代替实际批准 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

可选择补出库依据或整理需求说明，分别核分支连接。若补出库路径仍只收到申请文字，应排查接收值，明确需要的是执行记录。若回款计划被下游写成到账事实，需对照原文性质与解释结论，纠正后复问；不能从路径已运行推定财务事项已经核实，也不由一次学习选择建立采购或库存业务记录。 若学习解释被当成周转指标已经核定，应另查真实计算定义、所据资料范围及核定记录；培训中看过库存说明不证明已完成业务计算，缺依据时撤去已核定说法。

## 怎么确认配好了

验收分别保留需求、库存口径、出库缺口与回款说明，对照提交、接收和最终解释，补对应资料后检查新增依据是否进入。交互节点等待人员选择后继续，状态记录不等于培训已通过。补货下单、库存调整、对账确认和人员考核需后续节点或外部流程另办，核真实授权与回执，流程结束不证明经营指标已核定或操作能力已认定。
