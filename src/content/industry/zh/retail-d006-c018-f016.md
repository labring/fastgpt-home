# 区域经销商库存补货的门店服务与内部培训：表单与交互

## 这个品类的数据长什么样

在区域经销商库存补货的门店服务与内部培训中，本页说明FastGPT的表单与交互如何衔接资料。经销商补货培训先辨需求意向、区域与在途货，课堂填写不能执行订单或库存调整。所用场景为自拟文字测试。

## 这些特征在「表单与交互」这一环带来什么约束

假设练习单是门店补货意向，区域规则属于另一经销商，在途说明没有目的店签收。表单收当前门店、商品与资料来源，人员选择核区域或补收货材料。测试缺门店与补齐后的输入，再核下游实际收到的身份。选择节点用于分支，不能替代库存台账或经销权限数据库。

## 配置怎么定

| 补货培训表单 | 假设内容 | 学习核验 |
| --- | --- | --- |
| 补货意向 | 非正式订单 | 查订单凭据 |
| 区域规则 | 另一经销商 | 核地域主体 |
| 在途说明 | 无目的店签收 | 非可售库存 |
| 缺门店输入 | 与补齐对比 | 查实际承接 |
| 实际补货 | 授权流程另走 | 业务回执 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入` | 收集输入并在提交后传值。 |
| `必填信息核对` | 业务必填与缺项处理需另设计。 |
| `用户选择` | 选择结果对应已连接的分支。 |
| `交互状态` | 分别核等待和完成交互状态。 |
| `后续处理分工` | 校验、审批及写入另核结果。 |

## 容易做错的三处

意向填写被答已下单时，查订单回执；他区域规则被套本店时，核经销商及地域；在途被答可售库存时，查接收及可用状态。三处分别查交易阶段、范围与库存事件，培训表单完整不证明真实货物已补到。

## 怎么确认配好了

验收让受训者在原文指出未决事项，两种选择均查连接与信息承接。补签收只修收货阶段，区域许可仍另核，真实订单也需独立凭据。订货、调拨和库存写回由授权业务流程实现，课堂只记录填写及核对经过，不从人员点击推执行成功。 课堂卡片将经销地域与目标店铺对应并列，学员应指出仍缺的本店订单或收货凭据。
