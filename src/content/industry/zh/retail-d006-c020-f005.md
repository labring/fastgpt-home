# 原产地证书申办的门店服务与内部培训：多轮对话与提示词

## 这个品类的数据长什么样

在原产地证书申办的门店服务与内部培训中，本页说明FastGPT的多轮对话与提示词如何衔接资料。用原产材料培训追问区分规则原文、企业说明与课堂假设，核清答案能支持哪项判断。所用场景为自拟文字测试。

## 这些特征在「多轮对话与提示词」这一环带来什么约束

培训练习可给一段企业生产说明，只写某工序在本厂完成，随后问“这样就符合吗”。提示词应保留所问的规则范围，并指出当前没有对应规则原文。工序记载不自行证明满足原产要求。若回答直接给合格结论，应核历史是否真的提供适用条件；没有条件来源时，培训只能讲如何找依据，不能将自拟说明冒充资质审核结果或正式证书。

## 配置怎么定

| 培训对话核对项 | 原产阅读练习 | 实际检查 |
| --- | --- | --- |
| 初始证据 | 企业只描述本厂某工序 | 未给规则不能确认合格 |
| 课堂假设 | 条件段明示为自拟练习 | 上下文保留来源身份 |
| 主体更换 | 产品或目的地发生变化 | 优化问更新对应对象 |
| 真实规范 | 另取适用规则及版本 | 不由回复长度补缺源 |
| 学习承接 | 解释与记录写入分开 | 核结构、解析及后续动作 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `提示词与任务` | 说明资料、任务和缺证据处理。 |
| `历史记录` | 核实际提交的历史输入。 |
| `问题优化` | 指代消除与问题扩展需复核。 |
| `模型与长度` | 上下文与回复长度分别核对。 |

## 容易做错的三处

- 企业只说本厂某工序，回答便认定原产合格：核实际适用规则及支持条件，没有规则原文只能列核对路径，不能给资质结论。

- 自拟课堂条件被引成官方规范：并列假设标识、实际输入与返回，查来源身份在哪步丢失，不能将阅读练习冒充正式证书依据。

- 更换产品或目的地仍沿用上题条件：核原问、优化问与两题身份，条件能留在历史不说明适用新对象，另取本题来源再测。

## 怎么确认配好了

复核使用明确缺规则、补练习条件与更换主体三种问答，记录各轮依据、假设身份及保留的问题。若真实培训需要正式规则，应另取适用版本和责任人确认；增加回复长度不能补出从未提供的规范。答案可列核对路径与需补材料，但不能把练习结论写成实际原产审核已通过。结构化交给学习系统时另验字段与解析，不由文本流畅判定学习记录已写入。
