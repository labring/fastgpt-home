# 品牌全渠道库存调拨的门店服务与内部培训：工作流编排

## 这个品类的数据长什么样

在品牌全渠道库存调拨的门店服务与内部培训中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

库存调拨培训可先收门店缺货说明、调拨申请和库存快照原文，明确没有本次接收凭据。表单提交后应核后续步骤区分需求、申请与执行，不从申请存在推定货物已到店。自拟材料将调出调入地点另列，帮助学习两种角色；同商品跨渠道出现不证明口径相同，流程也不会仅凭这些文字自动完成库存同步或账实核对。

## 配置怎么定

| 培训核对 | 本题自拟输入 | 观察依据 |
| --- | --- | --- |
| 需求执行 | 缺货申请与到店结果分开 | 未从申请推出已收货 |
| 地点角色 | 调出在下游变成调入 | 核原句和接收值纠正 |
| 接收缺口 | 补资料只传物流标题 | 未把标题当确认依据 |
| 新增原文 | 同次调拨接收说明 | 实际进入对应阅读步骤 |
| 正式操作 | 回写对账与考核另办 | 流程未充作权限或同步 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

可选择补运输依据、核库存范围或只解释申请，分别查看连接。若调出地点在传值中变成调入地点，应排查角色原句与接收值，纠正后复测。若补接收路径仍只传物流单标题，需保留接收缺口，不能把运输记录存在写成门店已确认收货，也不能由学员选择代替调拨批准。 若库存快照余额被答复当成本次调拨发生量，应核快照时点、所述对象与本次移动依据；持有多少和移动多少是不同问题，缺过程记录时不能由余额补出发生量。

## 怎么确认配好了

验收逐项比对商品、地点角色、资料时间和解释出处，补同次接收资料后复问，确认新依据进入相应步骤。交互记录状态并等待人员处理，继续执行不等于仓库业务已办。调拨创建、库存回写、对账确认和培训考核需另接业务流程，核真实权限及回执；本次学习流程结束不证明库存已同步或人员已获准操作。
