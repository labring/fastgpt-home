# 品牌商场专柜运营的门店服务与内部培训：工作流编排

## 这个品类的数据长什么样

在品牌商场专柜运营的门店服务与内部培训中，本页说明FastGPT的工作流编排如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

商场专柜培训可先收合同适用说明、商场活动函和学员本次问题，不在样例里填金额。自拟材料只有活动安排与销售小票相关文字，没有本次结算确认；表单将这些来源交给后续阅读，不能从活动函存在推定专柜已经参加，也不能由一张小票推出整期销售或结算已核对。合同主体和活动适用范围需要随原句保留。

## 配置怎么定

| 培训核对 | 本题自拟输入 | 观察依据 |
| --- | --- | --- |
| 安排边界 | 活动函与实际参加分开 | 未由函存在推已执行 |
| 销售范围 | 单张小票及整期缺口 | 未扩大成全期已核对 |
| 补结算路径 | 只收到小票标题 | 核接收内容继续补证 |
| 专柜身份 | 另一专柜合同混入 | 核主体版本后移出 |
| 正式办理 | 报名结算及认定另办 | 交互未代替批准或对账 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

可让人员选择看活动说明、补结算依据或交经办人核主体，分别检查路径。若补结算的选择仍只收到小票标题，应排查实际接收资料，保留本期结算缺口。若另一专柜合同被混入，应核主体和版本，移出错配后复问，不能从同一商场名称推定合同或活动条件相同，也不由学员选择构成业务批准。 若活动函只给参加安排，答复却说本柜已执行活动，应分别回查安排原句与本柜实际参加记录；同一商场的函件不提供每个专柜的执行结果，缺依据时保留待核。

## 怎么确认配好了

验收沿问题、提交值、适用范围与解释出处回查，补本柜本期记录后重复主题，核新增依据真正进入阅读。交互状态记录和等待属于节点行为，继续不等于销售或财务已确认。活动报名、结算回写、合同变更及培训认定需后续节点或外部系统另办，分别核权限与真实回执；流程结束不证明专柜活动已执行或账务已对平。
