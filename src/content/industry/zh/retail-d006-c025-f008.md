# 品牌奥莱折扣运营的门店服务与内部培训：工作流编排

## 这个品类的数据长什么样

在品牌奥莱折扣运营的门店服务与内部培训中，本页说明FastGPT的工作流编排如何衔接资料。奥莱门店培训保留样品、瑕疵说明与可售规则的差别，人员选择不决定商品可售。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

假设培训卡介绍陈列样品，附瑕疵位置说明，可售规则仍待门店确认。先收商品与门店身份，选择看样品用途或补可售依据，再查对应下游实际收到的文字。节点记录交互并继续，不提供人员权限目录，也不代替门店质量或销售判断。本例不填折扣、价格或真实成交。

## 配置怎么定

| 奥莱培训编排 | 假设资料 | 学习核验 |
| --- | --- | --- |
| 陈列样品 | 用途有限 | 不改全新可售 |
| 瑕疵说明 | 须保留位置 | 不写无瑕疵 |
| 可售规则 | 等待本店确认 | 列待补 |
| 培训选择 | 用途或依据 | 核输出承接 |
| 上架事件 | 独立系统操作 | 查真实回执 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

陈列样品被答全新可售时，核用途与商品状态；瑕疵已说明被答无瑕疵时，查原句；培训完成被答商品已上架时，查真实上架回执。三处分别看性质、内容保留与业务事件，不能以完成课程证明商品可销售。

## 怎么确认配好了

验收让受训者在原卡片指出瑕疵位置及规则缺项，两条分支均检查输出承接。规则补齐只改变本店本件依据，其他商品不能跟随泛化。实际定价、质检与上架由门店授权流程和系统操作负责，培训编排只形成可核的学习与补证记录。 培训材料给样品及瑕疵说明各留原文位置，受训者应明确指出尚未提供哪份可售规则。
