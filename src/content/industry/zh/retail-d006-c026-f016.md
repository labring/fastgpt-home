# 品牌直营门店运营的门店服务与内部培训：表单与交互

## 这个品类的数据长什么样

在品牌直营门店运营的门店服务与内部培训中，本页说明FastGPT的表单与交互如何衔接资料。直营门店的排班、陈列和调拨说明支持不同阶段，需要带着本店身份传递。所用场景为自拟文字测试。

## 这些特征在「表单与交互」这一环带来什么约束

直营门店培训可收本店问题、排班说明、陈列材料及库存调拨原句。自拟输入没有实际出勤或调拨接收结果，提交后要核下游保留这些缺口。表单收集文字，不会从排班表自动查考勤，也不能由照片推定门店当下陈列符合要求。人员选择安排的是补资料或继续阅读，具体数据读取和业务接收需实际后续连接实现。

## 配置怎么定

| 培训材料核对 | 本题自拟输入 | 可观察依据 |
| --- | --- | --- |
| 人员阶段 | 排班与实际出勤分开 | 未由安排判已到岗 |
| 照片来源 | 本店和他店身份说明 | 错配图片移出 |
| 调拨状态 | 申请有，接收依据缺 | 未写成已收货 |
| 补证承接 | 本班本次新增原文 | 后续实际收到来源 |
| 正式业务 | 变更回写与认定另办 | 交互未代替数据同步 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入` | 收集输入并在提交后传值。 |
| `必填信息核对` | 业务必填与缺项处理需另设计。 |
| `用户选择` | 选择结果对应已连接的分支。 |
| `交互状态` | 分别核等待和完成交互状态。 |
| `后续处理分工` | 校验、审批及写入另核结果。 |

## 容易做错的三处

排班冒出勤：若拟上岗安排被写成实际到岗，应查本班真实出勤依据；照片对象错配：若其他门店图片进入本题，应核门店和拍摄说明；调拨阶段误写：若申请被说成已接收，应查本次实际接收记录。三项分别核人员执行、来源对象与货物阶段，不以字段已填替代。

## 怎么确认配好了

验收保留门店、班次、资料性质和实际接收内容，补对应出勤或接收原文后复问，看解释实际采用哪些来源。节点记录状态并等待交互，完成后继续，不意味着正式培训认定。字段核验、排班变更、库存回写及人员授权应由后续业务另核权限和真实回执；本次提交不证明门店操作已完成或数据已同步。
