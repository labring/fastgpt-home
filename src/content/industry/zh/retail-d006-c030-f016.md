# 商超供应商进场结算的门店服务与内部培训：表单与交互

## 这个品类的数据长什么样

在商超供应商进场结算的门店服务与内部培训中，本页说明FastGPT的表单与交互如何衔接资料。采购约定、到货验收与对账确认需要各自依据，培训不将合同存在改成已结算。所用场景为自拟文字测试。

## 这些特征在「表单与交互」这一环带来什么约束

商超供应商培训可收合同原句、到货验收说明与待补对账资料，不在样例填写金额。自拟输入只有采购安排和返利协议范围，没有本批次验收结论及本期对账确认。表单提交后应核接收步骤保留哪些是约定、哪些是执行；货物到达与验收通过要分开，合同存在不证明其中任一项已发生。人员选择安排补材料或看原文，不自动查询供应商门户，也不是财务审批。

## 配置怎么定

| 培训材料核对 | 本题自拟输入 | 可观察依据 |
| --- | --- | --- |
| 验收结论 | 供货约定与本批验收分开 | 到货签收也不代替验收通过 |
| 协议适用 | 商品期间原句 | 接收没有丢范围 |
| 确认阶段 | 编制稿无双方确认 | 未写成已经对平 |
| 补齐复问 | 本期对应验收或确认 | 解释实际采用新原文 |
| 正式业务 | 验收结算及认定另办 | 表单未替代财务批准 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入` | 收集输入并在提交后传值。 |
| `必填信息核对` | 业务必填与缺项处理需另设计。 |
| `用户选择` | 选择结果对应已连接的分支。 |
| `交互状态` | 分别核等待和完成交互状态。 |
| `后续处理分工` | 校验、审批及写入另核结果。 |

## 容易做错的三处

合同冒验收：若供货约定被写成本批次已验收通过，应查本批次验收结论原文，只有到货签收也不足以说明验收通过；协议范围丢失：若适用商品或期间未传入，应对照提交与接收恢复；对账稿冒确认：若编制文字被当成双方认可，应查本期真实确认依据。三项分别核验收结论、协议范围和对账确认，不能用材料齐名替代。

## 怎么确认配好了

验收保留供应商、期间、资料性质和实际接收内容，补对应验收或确认后复问，核解释采用哪份新来源。节点等待交互后继续，不自带业务数据库或账务处理。字段核验、采购验收、结算确认和人员认定需后续流程另核授权及回执；本次培训结束不证明财务已对平或供应商操作已获准。
