# 商超塑料袋与一次性用品报告的门店服务与内部培训：表单与交互

## 这个品类的数据长什么样

在商超塑料袋与一次性用品报告的门店服务与内部培训中，本页说明FastGPT的表单与交互如何衔接资料。采购台账、销售凭据、报告稿和承诺材料分别支持什么，需要按原文训练阅读。所用场景为自拟文字测试。

## 这些特征在「表单与交互」这一环带来什么约束

包装用品报告培训可收学员问题、采购台账说明和报告稿原句，不给法规口径或申报要求。自拟材料只有台账与承诺文字，没有完整销售或提交回执；表单应将缺口传给后续读取，不从承诺书存在推定实际履行。人员选择安排补资料或解释现稿，具体业务读取与正式提交由实际流程承担，不能称为系统自动完成合规报告。

## 配置怎么定

| 培训材料核对 | 本题自拟输入 | 可观察依据 |
| --- | --- | --- |
| 台账性质 | 采购与销售来源分开 | 未由入库推售出 |
| 报告阶段 | 编制稿与提交受理分开 | 查真实业务回执 |
| 承诺边界 | 承诺文字与行为依据分开 | 未直接判已履行 |
| 新增资料 | 对应销售或处理原文 | 实际进入后续解释 |
| 正式责任 | 提交留存及认定另办 | 学习未代替合规判断 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入` | 收集输入并在提交后传值。 |
| `必填信息核对` | 业务必填与缺项处理需另设计。 |
| `用户选择` | 选择结果对应已连接的分支。 |
| `交互状态` | 分别核等待和完成交互状态。 |
| `后续处理分工` | 校验、审批及写入另核结果。 |

## 容易做错的三处

采购冒销售：若入库台账被写成实际售出，应查对应销售来源及口径；报告稿冒受理：若编制完成被写成已提交通过，应查真实提交与处理回执；承诺冒执行：若承诺文字被当实际使用记录，应回查业务依据。三项分别核数据性质、提交阶段和行为证据，不由表单非空给出结论。

## 怎么确认配好了

验收保留资料范围、原句性质、选择路径和实际接收内容，补对应销售或回执后复问，核解释仍限于所得依据。交互节点记录状态并等待，完成后继续，不自动建立台账。字段校验、报告提交、留存和培训认定需后续业务另核责任及真实记录；本次学习结束不证明报告已受理、全部材料已核全或业务已合规。
