# 商超收银与会员促销的门店服务与内部培训：表单与交互

## 这个品类的数据长什么样

在商超收银与会员促销的门店服务与内部培训中，本页说明FastGPT的表单与交互如何衔接资料。价签、积分规则和异常退款属于不同资料，培训要保留适用范围与实际支付状态。所用场景为自拟文字测试。

## 这些特征在「表单与交互」这一环带来什么约束

收银会员培训表单可收通用积分规则、价签说明与异常退款问题，不包含金额或真实会员记录。自拟材料没有本次支付处理凭据，不能从规则已配置推定积分已变动。提交后要核下游保留资料范围和来源，人员选择可安排补凭据或看规则，但不是会员数据库选择器，也不由交互结束授予收银或退款权限。

## 配置怎么定

| 培训材料核对 | 本题自拟输入 | 可观察依据 |
| --- | --- | --- |
| 规则适用 | 活动说明随原文传递 | 接收未遗漏范围 |
| 交易结果 | 价签与本单实际凭据分开 | 未直接判实付 |
| 退款阶段 | 申请与处理记录分开 | 未写成资金已退 |
| 公开示例 | 通用规则与自拟交易 | 不含真实会员资料 |
| 业务权限 | 退款写入及认定另办 | 状态未充作正式授权 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入` | 收集输入并在提交后传值。 |
| `必填信息核对` | 业务必填与缺项处理需另设计。 |
| `用户选择` | 选择结果对应已连接的分支。 |
| `交互状态` | 分别核等待和完成交互状态。 |
| `后续处理分工` | 校验、审批及写入另核结果。 |

## 容易做错的三处

规则范围丢失：若适用活动说明未传入，应对照填写与接收恢复；价签冒实付：若标签文字被当本单交易结果，应查实际收银凭据；申请冒退款完成：若异常单只记提出请求，应补对应支付处理记录。三项分别核规则、交易和执行，不用一次继续补出业务事实。

## 怎么确认配好了

验收保留通用材料、交易自拟身份、分支去向与真实接收内容，补相应凭据后复问，核新依据实际进入。节点触发后记录并等待，完成后继续，不自动修改积分或资金。字段核验、真实退款、会员写入和人员认定需后续业务另核授权与回执；本次培训结束不证明款项已退、活动已生效或个人资料权限已通过。
