# 外汇收结汇与贸易名录的门店服务与内部培训：分享与嵌入

## 这个品类的数据长什么样

外汇收结汇与贸易名录的资料围绕外汇资金与贸易背景真实性展开，日常材料包括收汇水单、贸易合同、发票和外汇业务登记资料。与信用证审单不同，这一品类关注收汇主体是否一致、贸易背景能否解释，不审全套信用证单据。门店服务与内部培训中，材料以每单和每月两种节奏进入核对流程。分享与嵌入环节要处理的是：把对话入口交给门店人员或学员时，哪些材料、操作和请求处于什么授权状态。资料更新频率不改变本页功能，此处不展开。

## 这些特征在「分享与嵌入」这一环带来什么约束

免登录窗口从发布渠道创建并复制系统生成的完整链接。链接标识只用于打开对话入口，不能当成业务授权凭证。匿名方式依赖同一设备同一浏览器，跨设备记录需要另行设计身份与会话管理。身份验证受商业版范围限制，按官方接口返回成功状态与 uid。过期时间、QPM、积分上限属于分享入口的用量限制，费用归属应用所属团队。对话结果上报接口无规定返回值，响应值与 chat 接口格式相同，仅多一个 token。

假设演练样本。某外贸公司内部培训页面拟嵌入对话入口，供学员查询收结汇材料清单。供核对的材料原文为：「贸易合同编号 HT-2024-031，收汇水单显示付款方为 ALPHA TRADING，合同签约方为 BETA IMPORT，两者名称不一致；发票金额 12000 美元，水单金额 12000 美元。」一条待判定的拟稿句为：「该笔收汇主体与合同签约方一致，贸易背景已核实，可办理结汇。」按材料原文，收汇主体与合同签约方名称不一致，拟稿句的「一致」判定未获支持；「贸易背景已核实」在材料中没有对应字段，属于未获支持。该拟稿句不应作为培训页面的示例结论。

## 配置怎么定

| 配置项 | 本页用途 | 核对方式 |
| --- | --- | --- |
| 免登录窗口链接 | 门店培训页面嵌入的对话入口 | 从发布渠道创建并复制完整链接，核对 shareId 与业务授权无关 |
| 身份验证根地址 | 接入门店已有系统的校验入口 | 填写根地址，接口返回 success 与 uid；受商业版范围限制 |
| authToken 参数 | 拼接在分享链接后的用户凭证 | 核对链接中 authToken 与校验接口 body 中 token 一致 |
| 过期时间 | 培训页面的使用范围 | 按本次培训周期设置，与链接实际停用时间比较 |
| QPM | 每用户每分钟最大访问次数 | 按培训并发规模设定本次假设试验起点，与实测访问频率比较 |
| 积分上限 | 分享入口的最大计费数据 | 核对费用归属团队，与本次培训预算比较 |

## 容易做错的三处

1. 把链接标识当成业务授权。免登录窗口的 shareId 只用于打开对话入口，材料原文中的合同编号与收汇水单核对属于另一环节，链接可用不代表收汇主体已核对。
2. 把身份验证的 success 当成贸易背景核实。校验接口只返回是否允许继续操作，材料原文中收汇主体与合同签约方是否一致，需要人工比对合同与水单字段。
3. 把匿名对话记录当成跨设备可查。匿名方式依赖同一设备同一浏览器，切换设备会丢失记录，培训场景需要另行设计身份与会话管理。

## 怎么确认配好了

1. 输入假设样本的材料原文与拟稿句，比较拟稿句中的「一致」与原文中两个主体名称，观察结果：名称不一致时该判定不成立。以纸面输入 [] 核对空结果承接设计，不声称虚构规则检索一定返回空。
2. 输入分享链接与 authToken，比较校验接口返回的 success 与 uid，观察结果：success 为 true 且 uid 为不含特定字符、长度不超过 255 字节的字符串，才允许继续操作；uid 格式不符时返回 Invalid UID。
3. 输入本次培训的访问频率与积分消耗，比较 QPM 设定值与实测值、积分上限与累计消耗，观察结果：超过设定值时链接不可继续使用。检索相关度不负责权限或实体隔离，跨向量模型的库不可共同关联，只核标识并排除不符合者，记录实际观察。
