# 外贸出口退税申报的门店服务与内部培训：分享与嵌入

## 这个品类的数据长什么样
外贸出口退税申报在货物出口后做税务凭证匹配，主要数据来自电子税务局、出口退税申报系统、海关电子信息与财务账，日常文档包括出口免退税申报表、出口报关单、进货发票与收汇凭证。门店服务与内部培训场景下，这些材料常用于向同事演示申报表与报关单、发票的对应关系，或把演示入口嵌入内部学习页面。退税延迟、不得退税与税务风险是出错后果，因此分享与嵌入环节必须区分“资料展示”与“申报授权”，分享链接本身不构成任何退税申报权限。

## 这些特征在「分享与嵌入」这一环带来什么约束
免登录窗口从发布渠道创建并复制系统生成的完整链接，链接标识仅用于访问，不能当成业务授权。过期时间与 QPM 按使用范围设置并核对实际版本，QPM 表示每用户每分钟最大访问次数。积分上限核对分享入口的用量限制及费用归属，部分参数受版本限制。身份验证受商业版范围限制，按官方接口返回 success 与 uid 判断是否放行。匿名本地标识依赖同设备同浏览器，跨设备记录需另行设计身份与会话管理。检索与相似度不承担权限或实体隔离。

假设演练样本：某外贸企业培训负责人拟把一份内部演示链接发给同事。供核对的材料原文为：“出口免退税申报表（2024年3月批次，编号 X）已由税务会计填写，状态为待复核；对应出口报关单号 Y、进货发票号 Z 已附。本链接仅用于培训演示，不用于实际申报。”待判定的拟稿句为：“点击该链接即可完成本批次退税申报。”该拟稿句把演示入口写成申报执行，材料原文只说明待复核状态与演示用途，未载明申报授权。

## 配置怎么定
下表围绕上述样本，列出与本功能、主任务相关的官方已说明设置或实施核对项。数值为本次假设试验起点，用于与样本材料状态比较，不代表官方默认值。

| 配置项 | 本次假设起点 | 选用理由与比较对象 |
| --- | --- | --- |
| 名称 | 培训演示链接 | 仅用于记录展示，与样本“培训演示”用途一致 |
| 过期时间 | 设为培训结束后一日 | 与样本待复核状态比较，避免演示链接长期可用 |
| QPM | 假设起点 10 | 与培训人数比较，仅为本次纸面核对起点 |
| 积分上限 | 假设起点 500 | 与演示用量比较，费用归属应用团队 |
| 身份验证 | 填写根地址 | 与商业版范围核对，按 success 与 uid 判断 |
| 实时运行状态 | 关闭 | 与培训演示场景比较，减少无关节点展示 |

身份验证接口的 uid 必须为不含 “|”“/”“\” 且不超过 255 字节的字符串，否则返回 Invalid UID。对话结果上报接口无规定返回值，响应值与 chat 接口格式相同，仅多一个 token，重点关注 totalPoints 与 token。检索检查只记录观察与失败分支，不保证首条命中、全部召回或无关查询必为空；空结果可用纸面输入 [] 核对下游设计。跨不同向量模型的库不可共同关联，先核标识并排除不符者。RRF 是混合结果融合过程，不写成开启开关。

## 容易做错的三处
1. 把分享链接标识当成退税申报授权。样本材料原文只写“待复核”与“培训演示”，拟稿句“点击该链接即可完成本批次退税申报”与原文状态不一致，属于把演示入口写成申报执行。
2. 把身份验证接口返回的 success 当成业务审批。success 只表示校验通过，uid 用于拉取与保存对话记录，不代表申报表已复核或已授权。
3. 把检索相关度当成实体或权限过滤。相似度分数不排除无关企业或未授权记录，跨模型库不可共同关联，需先核标识再排除不符者。

## 怎么确认配好了
1. 输入样本材料原文与拟稿句，比较“待复核、培训演示”与“完成申报”是否同主体、同期间、同一字段。拟稿句与原文状态互斥，判定为未获支持，需改写为“本链接仅用于培训演示，申报状态以复核结果为准”。
2. 输入 authToken 与身份验证根地址，比较接口返回的 success 与 uid 格式。success 为 true 且 uid 不含 “|”“/”“\” 且不超过 255 字节，才满足放行条件；否则按 Invalid UID 或身份错误处理，记录实际观察。
3. 输入纸面检索查询与空结果 []，比较下游设计是否把空结果当作无记录。空结果只能承接为待核实，不能声称虚构规则检索一定返回 []；跨模型库先核标识并排除不符者，记录实际观察而不编造运行结果。
