# 外贸出口退税申报的门店服务与内部培训：知识库检索与召回

## 这个品类的数据长什么样

外贸出口退税申报在货物出口后做税务凭证匹配，主要数据来源为电子税务局、出口退税申报系统、海关电子信息与财务账。门店服务与内部培训场景要围绕出口退免税申报表、出口报关单、进货发票、收汇凭证四类材料做检索与召回。这四类材料的主体、对象、状态字段各不相同：报关单载明出口方与商品信息，进货发票载明供货方与货物，收汇凭证载明收款事实，申报表载明申报期间与退税额。检索时若只命中其中一类，并不能说明凭证链完整。资料更新频率为月、每批，本页功能不依赖更新节奏，不再展开。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库，跨不同向量模型的库不可共同关联。检索前须核对各库的向量模型标识，排除不符合者并记录实际观察，不执行跨模型检索来比较漏召回。语义检索依赖向量距离，全文检索依赖关键词命中，混合检索通过 RRF 融合两路结果，Rerank 对候选文本二次排序。RRF 是融合过程，不是可开启的开关。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值，不是排序规则，也不承担权限或实体隔离。引用上限以 token 为单位，输出引用长度可以为 0。问题优化用于指代消除和问题扩展，会增加一次模型调用。图片检索须有相应图像输入及模型能力，重排须具备模型且按设置启用，文档流程图中的可选路径不代表每次请求全部执行。

假设演练样本：某门店交接一份纸质材料，原文为“2025年3月出口报关单，经营单位为甲外贸公司，商品为棉制女式衬衫，数量1200件；对应进货发票开票方为乙服饰厂，货物名称棉制女式衬衫，数量1200件；收汇凭证收款方甲外贸公司，金额与发票一致；出口退免税申报表所属期2025年3月，状态栏空白。”待判定拟稿句为“该批出口业务凭证齐全，可提交退税申报。”此样本中申报表状态栏空白，签署、合作达成、合同生效是不同事实，报价有效期不表示供货期限，凭证齐全与可提交申报均未获支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联向量模型标识一致的退税材料库 | 先核各库向量模型标识，排除不一致者，记录实际观察 |
| 搜索模式 | 语义检索与全文检索各跑一次 | 用同一测试问题比较两路召回内容，不预设一种模式适合全部资料 |
| 引用上限 | 本次试验起点设为覆盖一份报关单加一份发票的 token 量 | 用长短不同的实际资料测试内容是否完整，再调整该起点 |
| 最低相关度 | 本次试验起点设为0.5 | 先标注相关与无关样本，再调阈值，比较过滤前后结果 |
| 问题优化 | 本次试验对短问题开启 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 本次试验具备重排模型时启用 | 比较重排前后候选顺序，确认重排得分可用于过滤 |

## 容易做错的三处

1. 把检索命中当成授权。输入为上述样本的拟稿句，若系统召回申报表片段，错误做法是据此判定可提交申报。检索不负责权限或实体隔离，申报表状态栏空白属未获支持。
2. 把跨模型库共同关联。输入为两个向量模型标识不同的库，错误做法是直接共同关联后比较召回差异。正确动作是核标识、排除不符者并记录实际观察。
3. 把待审核当成缺少操作权限。输入为样本中申报表状态栏空白，错误做法是判定该门店无操作权限。待审核不证明缺少操作权限，须记录证据缺口。

## 怎么确认配好了

1. 输入上述样本原文与拟稿句，比较召回内容是否包含申报表状态字段。若召回内容仅覆盖报关单、发票、收汇凭证，拟稿句中的“凭证齐全”未获支持，应记录缺口。
2. 输入同一测试问题分别走语义检索与全文检索，比较两路返回内容。若编号类问题在全文检索命中而语义检索未命中，属预期现象，不据此判定某一模式失效。
3. 输入明确纸面空结果[]，比较下游设计是否承接长度为0的引用输出。若下游未定义空结果分支，记录该缺口，不声称虚构规则检索一定返回[]。
