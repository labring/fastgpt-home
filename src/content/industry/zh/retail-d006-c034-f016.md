# 外贸出口退税申报的门店服务与内部培训：表单与交互

## 这个品类的数据长什么样

在外贸出口退税申报的门店服务与内部培训中，本页说明FastGPT的表单与交互如何衔接资料。申报、出口和购进凭据需要对上同笔对象，培训不把资料编制直接写成已办理。所用场景为自拟文字测试。

## 这些特征在「表单与交互」这一环带来什么约束

出口退税材料培训可收申报稿、报关和购进凭据相关原句，只解释资料性质，不提供税务口径或金额。自拟输入没有本次处理回执，表单传给后续步骤时应保留仍待取的依据；报表已编制不证明已受理。人员选择可安排补记录或查看原文，不是税务系统入口，也不能由表单完成推定申报条件已经审核通过。

## 配置怎么定

| 培训材料核对 | 本题自拟输入 | 可观察依据 |
| --- | --- | --- |
| 商品对应 | 购进和出口原文对象 | 无关资料先移出 |
| 申报阶段 | 编制与实际受理分开 | 查本次提交处理记录 |
| 合同身份 | 他合同凭据混入 | 核主体及交易关系 |
| 补证承接 | 本次真实处理回执 | 后续实际收到来源 |
| 正式责任 | 操作留存及认定另办 | 培训未充作税务判断 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入` | 收集输入并在提交后传值。 |
| `必填信息核对` | 业务必填与缺项处理需另设计。 |
| `用户选择` | 选择结果对应已连接的分支。 |
| `交互状态` | 分别核等待和完成交互状态。 |
| `后续处理分工` | 校验、审批及写入另核结果。 |

## 容易做错的三处

购进出口对象错配：若两份凭据指向不同商品，应核交易对应后移出不相关材料；申报阶段误写：若编制稿被当已受理，应查本次提交和处理回执；收汇凭据错套：若其他合同资料填入，应核主体及所指交易。三项分别核商品、办理和合同关系，不由标题齐备补出业务结果。

## 怎么确认配好了

验收保留本题对象、资料性质、选择路径与实际接收内容，补本次回执后复问，核新依据是否进入解释。节点触发后记录并等待交互，完成后继续，不自动提交申报。字段核验、税务操作、留存和人员认定需后续业务另核责任与真实记录；本次学习结束不证明申报已通过、款项已处理或政策判断已成立。
