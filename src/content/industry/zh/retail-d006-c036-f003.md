# 多仓分仓与库存同步的门店服务与内部培训：分享与嵌入

## 这个品类的数据长什么样

多仓分仓发生在订单路由阶段，决定从哪个仓发货，与快递交接属于不同环节。主要数据来源为 WMS、OMS、ERP 库存与平台库存接口，典型从业主体包括供应链计划、WMS 管理员与电商运营。日常文档为分仓规则、库存同步表、调拨单与缺货预警。出错的后果是超卖退款、跨区运费增加与发货延迟。本页只处理门店服务与内部培训中的分享与嵌入：把分仓规则、库存同步表、调拨单、缺货预警交给门店或内部学员时，哪些材料、操作与请求处于什么授权状态，检索或表单不构成授权执行。

## 这些特征在「分享与嵌入」这一环带来什么约束

免登录窗口可创建临时可访问地址，任何互联网用户可经该地址使用应用，费用产生在应用归属团队下。系统为每个用户生成 localId，从云端拉取对话记录，仅保障同一设备同一浏览器，切换设备或清空浏览器缓存则记录丢失，仅允许拉取近 30 天的 20 条记录。身份验证为 POST 根地址，初始化、开始对话与对话结束向该地址特定接口发请求；接口返回 success 为 true 才允许继续，uid 必须返回且为不含 "|"、"/"、"\\" 字符、小于等于 255 字节长度的字符串，否则返回 Invalid UID。authToken 作为额外 query 拼入分享链接，FastGPT 在鉴权接口 body 中携带 token=[authToken]。结果上报接口无规定返回值，重点关注 totalPoints 与 token。过期时间、QPM、积分上限、身份验证等部分参数仅商业版支持配置。

假设演练样本：某供应链计划岗把一份《华东区分仓规则》交给门店学员自学，材料原文为「华东区订单优先由上海仓发货；上海仓可售库存低于安全值时改由杭州仓发货。本规则自 2025 年 3 月 1 日起适用于华东区门店订单。」待判定拟稿句为「门店学员可直接用该分享链接修改上海仓发货优先级。」原文只写发货顺序与生效范围，未授予任何修改权限。

## 配置怎么定

| 配置项 | 本页用途 | 核对方式 |
| --- | --- | --- |
| 名称 | 记录该链接名称，仅用于展示 | 对照培训批次命名，不当作授权标识 |
| 过期时间 | 超过该时间链接无法使用 | 按培训周期设定，核实际版本是否支持 |
| QPM | 每用户每分钟最大访问次数 | 按门店学员规模设本次假设起点，与访问日志比较 |
| 积分上限 | 该链接产生的最大计费数据 | 核费用归属团队，与用量记录比较 |
| 身份验证 | 第三方身份认证与对话回调 | 确认商业版范围，按 success 与 uid 判断 |
| 实时运行状态 | 是否展示当前运行节点 | 按培训是否需要展示节点决定 |

本页不涉及检索库向量模型、相似度阈值、引用上限 token 或 thinking budget。

## 容易做错的三处

1. 把分享链接当作授权凭证。链接标识只用于访问，不表示门店学员获得修改分仓规则的权限。核对输入为拟稿句与材料原文，比较两者是否都载明修改权，材料未载明即未获支持。
2. 把检索或表单当作业务执行。检索返回内容不代表授权，表单收集值不代表审批、数据库写入或外部同步已完成。核对输入为该请求与材料原文，比较是否出现授权或执行记载。
3. 把待审核当作缺少权限。待审核只说明流程未完成，不证明操作权限缺失。核对输入为状态字段，比较同主体同期间同字段取值，未载明则记录为待核实。

## 怎么确认配好了

1. 输入假设样本材料原文与拟稿句，比较原文是否载明门店学员的修改权限。原文只写发货顺序与生效范围，未出现修改授权，拟稿句超出原文范围，判定为未获支持。
2. 输入分享链接配置中的身份验证根地址与 authToken 拼接方式，比较接口返回的 success 与 uid 是否符合文档格式。success 为 true 且 uid 为合规字符串才满足条件；返回 Invalid UID 或 success 不为 true 时记录实际观察，不推断具体原因。
3. 输入对话记录拉取范围，比较是否落在近 30 天的 20 条记录内，以及是否依赖同一设备同一浏览器。跨设备记录需另行设计身份与会话管理，本页不声称已实现。
