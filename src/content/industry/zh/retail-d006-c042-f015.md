# 平台商品标题与详情合规的门店服务与内部培训：知识库检索与召回

## 这个品类的数据长什么样

平台商品标题与详情合规围绕宣传真实性和资质展示展开，不涉及包裹交付。主要材料包括商品标题表、详情页素材、广告禁词清单和质检报告，来源为平台规则中心、广告法合规清单、品牌素材库和质检机构报告。从业主体有电商商品运营、法务合规和美工审核。出错会导致商品下架、投诉举报和行政处罚风险。这些材料在门店服务与内部培训中需要被检索和召回，用于支持运营交接和培训问答。检索环节处理的是文本和图片的相似度匹配，与业务授权状态无关。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可以关联一个或多个使用相同向量模型的知识库。搜索模式包括语义检索、全文检索和混合检索。语义检索依赖向量距离计算相似度，适合自然语言问题；全文检索依赖关键词命中，适合编号、型号和专有名词；混合检索同时使用两种召回并通过 RRF 融合结果。最低相关度是过滤阈值，仅在语义检索或使用结果重排时生效，不负责权限或实体隔离。引用上限以 token 为单位，控制每次搜索最多引用的内容量。问题优化用于指代消除和问题扩展，会在检索前增加一次模型调用。图片检索需要图像输入和相应模型能力，重排需要具备模型且按设置启用。跨不同向量模型的库不可共同关联。

假设演练样本：供核对的材料原文为“某品牌保湿霜，规格50ml，质检报告编号Q2024-0315，报告日期2024年3月，检测结论为符合《化妆品安全技术规范》要求。广告禁词清单列明‘美白’属于需提供特证方可使用的宣称。”一条待判定的拟稿句为“本产品美白保湿，适合所有肤质。”交接请求为“请门店培训时使用上述材料确认拟稿句是否合规。”该样本仅用于纸面核对，不涉及真实客户或实际测试。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 选择使用相同向量模型的商品合规库 | 核验库标识和向量模型标识，排除不同模型者 |
| 搜索模式 | 混合检索 | 标题合规问题含自然语言和编号类查询，比较语义与全文召回结果 |
| 引用上限 | 假设起点为2000 token | 用长短不同的实际资料测试内容完整性，与更小值比较 |
| 最低相关度 | 假设起点为0.5 | 先标注相关与无关样本，比较过滤后结果 |
| 问题优化 | 开启 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 启用 | 具备重排模型时，比较重排前后排序变化 |

以上数值为本次假设试验起点，非官方默认值。

## 容易做错的三处

1. 将检索结果等同于业务授权。输入为知识库搜索返回的引用内容，比较检索结果与运营交接所需的授权状态，观察是否把召回内容直接当作已批准的操作依据。检索不执行授权，授权需要下游系统实现。
2. 跨不同向量模型的库共同关联。输入为多个知识库的向量模型标识，比较各库标识是否一致，观察是否存在不同模型库被同时选入。不同向量模型的库不可共同关联，应核标识并排除不符合者。
3. 将最低相关度当作权限或实体过滤。输入为最低相关度设置值和检索请求，比较过滤前后返回内容，观察是否误认为该阈值能排除无关业务或未授权记录。最低相关度仅过滤低相关度结果，不承担权限隔离。

## 怎么确认配好了

1. 使用假设样本材料原文和拟稿句进行检索。输入为“美白保湿”和“质检报告编号Q2024-0315”，比较返回引用是否包含广告禁词清单中关于“美白”需特证的条目，以及质检报告编号对应内容。若返回引用包含该条目和报告内容，则满足条件；若返回为空，记录缺口，不声称规则一定返回空数组。
2. 使用假设样本的交接请求进行核对。输入为“请门店培训时使用上述材料确认拟稿句是否合规”，比较检索结果是否包含材料原文和拟稿句，观察是否将检索结果标记为待人工核对状态。检索结果不构成合规判定或授权执行。
3. 使用跨模型场景进行纸面核对。输入为两个不同向量模型标识的知识库，比较标识是否一致，观察是否排除不符合者。不执行跨模型检索来比较漏召回，仅核标识并记录实际观察。若无法获取模型标识，保留为未获支持状态。
