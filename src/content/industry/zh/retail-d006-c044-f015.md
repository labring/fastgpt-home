# 平台广告投放与站内流量的门店服务与内部培训：知识库检索与召回

## 这个品类的数据长什么样

平台广告投放与站内流量的资料以投放计划、关键词报表、人群包说明、转化归因表为主，更新频率为日或小时。门店服务与内部培训场景下，检索请求常来自一线人员对投放规则、出价口径、归因口径的即时询问。这类资料的主体、对象和有效范围经常分散在不同文档中，检索环节需要把同一主体、同一期间、同一字段的内容聚合起来，供后续人工核对。检索结果本身只是候选引用内容，不构成授权、审批或执行。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的库。语义检索、全文检索与混合检索各自适合不同资料形态，编号、型号、专有名词类查询更适合全文或混合检索。引用上限以 token 为单位，最低相关度仅在语义检索或使用结果重排时生效。问题优化用于指代消除和问题扩展，会额外调用模型。混合检索通过 RRF 融合多路结果，Rerank 对候选文本二次排序。图片检索需要图像输入及相应模型能力，重排需要模型且按设置启用。检索不承担权限或实体隔离功能。

假设演练样本：某门店培训材料原文为“本店三月投放计划中，关键词‘春季外套’出价调整为 1.20 元，生效期间为三月一日至三月三十一日，适用范围限本店账户。”另一份交接请求写为“请把该关键词出价改为 1.50 元，四月继续沿用。”判定问题：该请求是否与原文的出价、期间、适用范围一致。原文未载明四月安排，也未载明审批人。

## 配置怎么定

| 配置项 | 本页相关设置或核对项 | 与样本的关系 |
| --- | --- | --- |
| 关联的知识库 | 选择一个或多个相同向量模型的库 | 样本资料须在同一向量模型库内可被检索 |
| 搜索模式 | 按测试问题比较语义、全文与混合检索 | 用“春季外套 出价”测试编号与自然语言问法 |
| 引用上限 | 单位为 token，用长短不同资料测试完整性 | 核对三月计划与交接请求是否同段返回 |
| 最低相关度 | 仅在语义检索或结果重排时生效 | 先标注相关与无关样本再调阈值 |
| 问题优化 | 用于指代消除和问题扩展 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 需具备模型并按设置启用 | 候选较多时观察排序变化 |

## 容易做错的三处

1. 把检索命中当作授权。样本中交接请求提到“四月继续沿用”，原文只写三月一日至三月三十一日，检索到该请求不表示四月变更已获批准。核对时应比较同一字段的期间取值，未载明部分记录为待核实。
2. 把不同向量模型的库共同关联。文档要求关联相同向量模型的知识库，跨模型库不可共同关联。核对时先检查库标识，排除不符合者，记录实际观察，不推断跨模型检索的运行结果。
3. 把最低相关度当作权限或实体过滤。该值是过滤阈值，仅在语义检索或结果重排时生效，不排除无关业务或未授权记录。核对时比较阈值调整前后的引用内容，权限问题另行处理。

## 怎么确认配好了

1. 输入样本原文“本店三月投放计划中，关键词‘春季外套’出价调整为 1.20 元，生效期间为三月一日至三月三十一日，适用范围限本店账户”与拟稿句“请把该关键词出价改为 1.50 元，四月继续沿用”。比较同一字段的出价、期间、适用范围。原文出价为 1.20 元、期间为三月一日至三月三十一日、适用范围限本店账户；拟稿句出价 1.50 元、期间指向四月。出价与期间两项与原文不一致，四月安排未获支持，应记录为待核实，不判定为已批准。
2. 输入查询“春季外套 出价 1.20”，分别在语义检索、全文检索、混合检索下观察返回的引用内容。比较返回内容是否包含样本原文所在段落。若返回内容为数组且长度为 0，说明该查询未召回内容，记录为空结果，不声称规则一定返回空数组。若返回内容包含原文段落，核对主体、期间、适用范围是否完整。
3. 输入交接请求“请把该关键词出价改为 1.50 元，四月继续沿用”，在检索结果中比较请求文本与原文文本。观察检索是否同时返回两份材料。若同时返回，检查是否出现同一字段的互斥取值：原文期间为三月，请求指向四月，属于不同期间，不构成同一字段矛盾。请求处于待审核状态，不表示已获操作权限，也不表示变更已执行。
