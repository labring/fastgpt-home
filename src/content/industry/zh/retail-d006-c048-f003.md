# 快递面单与揽收交接的门店服务与内部培训：分享与嵌入

## 这个品类的数据长什么样

快递交接发生在包裹离仓节点，核心是承运商扫描责任。门店服务与内部培训场景中，需要向网点人员或物流专员分享操作入口与培训材料，分享链接本身不构成业务授权。电子面单、交接清单、揽收扫描记录、异常件登记构成日常文档集合，更新频率为每批与日。免登录窗口可创建临时地址供互联网用户使用，费用产生在应用归属团队下，分享范围需要控制。系统为每个用户生成 localId，仅保障同一设备同一浏览器使用，跨设备或清空缓存会丢失记录，仅允许拉取近30天的20条记录。身份验证受商业版范围限制，配置根地址后初始化、开始对话、对话结束会向该地址发送请求。

## 这些特征在「分享与嵌入」这一环带来什么约束

分享链接的 shareId 与 authToken 是访问参数，不能视为授权凭证。身份验证接口返回 success 为 true 且提供 uid 时，FastGPT 允许继续操作；uid 用于拉取和保存对话记录。对话结果上报接口为可选，无规定返回值。门店培训中若将分享链接当作操作许可，会把检索或表单填写误认为授权执行。

假设演练样本：某门店培训负责人拟向网点人员分享操作入口。供核对材料原文为：“该免登录链接配置了身份验证根地址，初始化与对话前校验均返回 success 为 true 且 uid 为 user1。链接过期时间已设置，积分上限已填写。本次分享用于内部培训演示，不用于实际揽收交接授权。”一条待判定拟稿句为：“网点人员打开该链接即可代表门店完成揽收扫描确认。”该拟稿句将访问链接等同于揽收扫描确认授权，材料未载明任何扫描确认权限或交接授权。判定为未获支持，需核实实际授权边界。

## 配置怎么定

| 配置项 | 本页相关设置或核对项 | 核对方法 |
| --- | --- | --- |
| 身份验证根地址 | 填写后初始化、开始对话、对话结束向该地址发请求 | 核对根地址配置与接口返回 success 及 uid |
| authToken 拼接 | 分享链接增加 authToken 参数，FastGPT 在 body 中携带 token | 核对链接参数与鉴权接口 body 中 token 值一致 |
| 过期时间 | 超过该时间链接无法使用 | 核对链接有效期与培训使用期间 |
| 积分上限 | 该链接产生的最大计费数据 | 核对费用归属团队与用量限制 |
| 对话记录边界 | localId 依赖同设备同浏览器，仅拉取近30天20条 | 核对跨设备场景是否需另行设计身份管理 |
| 结果上报接口 | 可选，无规定返回值，含 totalPoints 与 token | 核对是否接入及数据用途 |

## 容易做错的三处

1. 将分享链接的 shareId 或 authToken 当作揽收扫描确认授权。输入为含 authToken 的完整链接，比较材料是否载明扫描确认权限，可观察结果为材料未载明该权限，拟稿句判定为未获支持。
2. 将身份验证接口返回 success 为 true 当作业务操作已完成。输入为初始化接口返回 uid 为 user1，比较该返回是否包含揽收交接执行记录，可观察结果为接口仅返回校验状态，不含业务执行证据。
3. 将对话结果上报接口的 totalPoints 或 token 当作积分扣除已执行。输入为上报请求中的 totalPoints 与 token 字段，比较是否有数据库写入或余额扣减记录，可观察结果为上报接口无规定返回值，扣减需另行实现。

## 怎么确认配好了

1. 输入假设样本中拟稿句“网点人员打开该链接即可代表门店完成揽收扫描确认”，比较材料原文是否载明扫描确认授权，若材料仅载明身份校验与链接参数，则判定为未获支持，需保留授权证据缺口。
2. 输入初始化接口返回 success 为 true 且 uid 为 user1，比较该返回是否包含业务操作执行状态，若仅返回校验成功，则不得判定揽收交接已完成，需核实下游实现。
3. 输入分享链接含 authToken 参数与鉴权接口 body 中 token 值，比较两者是否一致，若一致且 success 为 true，则确认身份校验通过；若不一致或 success 不为 true，则记录身份错误，不得继续推断授权状态。
