# 特许加盟备案管理的门店服务与内部培训：分享与嵌入

## 这个品类的数据长什么样

特许加盟备案管理的数据围绕法律披露与商务部门系统展开，与总部选址开店分属不同事务。主要来源包括商业特许经营信息管理系统、企业证照、门店清单与合同台账。日常文档为特许经营合同、操作手册、备案材料与信息披露文件。这些材料在门店服务与内部培训中常被分享给加盟商或内部人员，分享动作本身不产生授权效力。备案材料与信息披露文件的更新频率为不定期或按年，本页功能不依赖该频率。

## 这些特征在「分享与嵌入」这一环带来什么约束

分享链接、表单填写与检索结果均不构成备案提交、合同签署或培训授权。免登录窗口从发布渠道创建，链接标识不能当成业务授权凭证。身份验证受商业版范围限制，按官方接口返回 success 状态与 uid 判断是否放行。对话记录依赖同一设备同一浏览器中的本地标识，跨设备记录需另行设计身份与会话管理。过期时间与 QPM 按使用范围设置并核实际版本，积分上限核对分享入口的用量限制及费用归属。

假设演练样本：一份供核对的《门店服务与内部培训》材料原文写为：“本手册用于加盟门店员工内部培训，培训记录由门店留存。分享链接仅用于查看操作手册，不替代备案材料提交。”一条待判定的交接请求写为：“请将本分享链接视为已完成内部培训授权。”材料原文含主体（加盟门店员工）、对象（操作手册）、状态（仅用于查看，不替代备案提交）。待判定请求试图把分享行为当作授权完成，与原文状态不一致。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 核对与比较方法 |
| --- | --- | --- |
| 链接名称 | 门店培训手册查看 | 仅用于记录展示，与授权状态无关 |
| 过期时间 | 设为30天 | 本次假设起点，因培训周期约一个月；与材料中培训记录留存范围比较 |
| QPM | 未指定 | 按实际版本支持范围核对，文档未给出默认值 |
| 积分上限 | 未指定 | 核对分享入口用量限制及费用归属 |
| 身份验证 | 填写根地址 | 仅商业版；按接口返回 success 与 uid 判断 |
| 查看引用片段 | 未指定 | 见系统介绍，按实际版本核对 |

## 容易做错的三处

1. 把分享链接标识当作备案提交或培训授权凭证。分享链接仅用于访问，不产生授权效力。
2. 把身份验证返回的 uid 当作业务权限。uid 用于拉取和保存对话记录，不承担备案或合同授权判断。
3. 把待审核的交接请求当作已完成的授权。待审核不证明缺少操作权限，也不等于授权完成。

## 怎么确认配好了

1. 输入假设材料原文与待判定请求，比较“仅用于查看，不替代备案材料提交”与“视为已完成内部培训授权”。若两者状态不一致，则请求未获支持，记录证据缺口。
2. 输入分享链接与 authToken，比较接口返回的 success 与 uid 是否符合文档格式。若 success 不为 true 或 uid 含禁用字符，则提示错误，不进入下一步。
3. 输入跨设备访问场景，比较本地标识能否拉取同一对话记录。若切换设备后记录不可见，则记录该现象，不声称自动同步或授权生效。
