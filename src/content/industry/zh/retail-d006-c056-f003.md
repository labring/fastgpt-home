# 生产企业免抵退税的门店服务与内部培训：分享与嵌入

## 这个品类的数据长什么样

生产企业免抵退税把内销税额抵减和退税合并计算，这一计算方式与外贸企业出口退税存在差别。日常材料包括免抵退税申报明细表、出口合同、销售明细账和出口报关单，数据来自电子税务局、ERP销售、海关电子信息和财务账。门店服务与内部培训场景中，这些材料会以纸质或电子形式在门店与内部人员之间流转，分享与嵌入动作因此需要明确材料处于何种授权状态。

## 这些特征在「分享与嵌入」这一环带来什么约束

免登录窗口从发布渠道创建并复制系统生成的完整链接，链接标识仅用于访问，不能当作业务授权。身份验证受商业版范围限制，按官方接口返回成功状态与uid。匿名本地标识依赖同设备同浏览器，跨设备记录需另行设计身份与会话管理。过期时间与QPM按使用范围设置并核实际版本，QPM表示每用户每分钟最大访问次数。积分上限核对分享入口的用量限制及费用归属。

假设演练样本：某门店拟向内部培训人员分享一份生产企业免抵退税材料，供其核对申报明细表与出口报关单的一致性。待核对的材料原文为：「免抵退税申报明细表第3行所列出口货物离岸价为120000元，对应出口报关单编号为XXXX2024001，申报期间为2024年5月。」拟稿句为：「请通过分享链接查看上述申报明细表，并确认报关单编号与离岸价是否一致。」该请求处于待分享状态，尚未获得任何授权执行。

## 配置怎么定

| 配置项 | 本样本取值或核对项 | 说明 |
| --- | --- | --- |
| 名称 | 免抵退税培训材料分享 | 仅用于记录展示 |
| 过期时间 | 本次假设试验起点设为7天 | 选择7天因培训周期较短，与30天记录拉取上限比较后确定 |
| QPM | 按实际版本核对可设范围 | QPM为每用户每分钟最大访问次数 |
| 积分上限 | 按分享入口用量限制核对 | 费用归属应用所属团队 |
| 身份验证 | 核对是否在商业版范围内 | 按官方接口返回success与uid |
| 对话记录边界 | 核同设备同浏览器条件 | 跨设备记录需另行设计身份与会话管理 |

## 容易做错的三处

1. 把分享链接标识当作业务授权凭证。链接仅提供访问入口，不证明材料已获准对外分享或用于培训。
2. 把待审核的分享请求当作已批准执行。本样本中拟稿句处于待分享状态，未获授权前不能视为已执行。
3. 把匿名本地标识的对话记录当作跨设备可用的培训记录。该标识依赖同设备同浏览器，切换设备或清空缓存会丢失记录。

## 怎么确认配好了

1. 输入本样本材料原文与拟稿句，比较拟稿句是否超出原文所列主体、对象和期间范围。拟稿句仅请求确认报关单编号与离岸价一致性，未超出原文范围，满足条件。
2. 输入身份验证接口返回的success与uid，比较uid格式是否不含「|」「/」「\」且不超过255字节。满足条件时允许继续操作。
3. 输入分享链接的过期时间与QPM设置，比较实际版本可设范围与本次假设试验起点。过期时间7天与QPM取值需与版本支持范围一致，不一致时记录为待核实。
