# 生鲜称重分拣的门店服务与内部培训：表单与交互

## 这个品类的数据长什么样

在生鲜称重分拣的门店服务与内部培训中，本页说明FastGPT的表单与交互如何衔接资料。称重培训表单分别保留单位、标签补打与设备确认事项，完整标签不证明重新称量。所用场景为自拟文字测试。

## 这些特征在「表单与交互」这一环带来什么约束

自拟教学包中，秤面文字说明使用一种重量单位，标签模板使用另一单位但没有读数，操作便笺仅记补打标签，交班单写接手人继续跟进设备确认。表单收批次、原单位和各动作，学员选择核单位或核操作记录。这里没有实测重量、换算数值或设备校准结论。补打不是复称，接班职责也不是获准检定设备；本题只核文字如何传给下游。

## 配置怎么定

| 称重教学表单 | 自拟输入 | 独立核法 |
| --- | --- | --- |
| 单位 | 秤面与模板不同 | 原词不能丢 |
| 标签补打 | 只打印动作 | 不当重新称量 |
| 设备跟进 | 岗位待办 | 不当校准完成 |
| 输入测试 | 缺单位与补齐 | 看真实承接 |
| 正式计量 | 无实测值或程序 | 另核设备凭据 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入` | 收集输入并在提交后传值。 |
| `必填信息核对` | 业务必填与缺项处理需另设计。 |
| `用户选择` | 选择结果对应已连接的分支。 |
| `交互状态` | 分别核等待和完成交互状态。 |
| `后续处理分工` | 校验、审批及写入另核结果。 |

## 容易做错的三处

- 下游保留重量字段却省略原单位时，对秤面说明、标签模板和实际接收，不自行计算或假定两者同口径。

- 补打标签被学员答成已经重新称量时，核便笺动作及实际称量记录，打印凭据不提供新测量结果。

- 交班跟进设备确认被答成校准已经完成时，核责任描述与相应设备凭据，人员姓名不代计量确认。

## 怎么确认配好了

分别用缺单位与补单位的输入测试两条路径，保留批次和动作原句，让学员明确仍缺哪类证据。补模板只修单位来源，真实数值仍未给；补岗位交接也不补设备状态。正式称量、校准、标签写回与库存记录需要实际设备、授权流程及凭据，不由培训表单完成。本页不制定计量程序或法定允许误差，交互结束也不认定人员已通过实操。
