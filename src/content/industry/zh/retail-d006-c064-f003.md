# 直播选品与样品质检的门店服务与内部培训：分享与嵌入

## 这个品类的数据长什么样
选品质检发生在开播前，判断商品能否上播以及是否适合直播展示。资料来自供应商资料、检测机构报告、平台负面目录与历史退货率，日常文档为样品评估表、质检报告、供应商资质、禁售清单，更新频率为周与每品。门店服务与内部培训把上述材料整理后分享给门店人员，嵌入其日常流程。材料是否齐全、处于何种状态，直接决定分享内容能否作为操作依据。

## 这些特征在「分享与嵌入」这一环带来什么约束
分享链接只解决访问入口，不构成业务授权。免登录窗口从发布渠道创建并复制系统生成的完整链接，链接标识不能当成业务授权。过期时间、QPM、积分上限按使用范围设置并核对实际版本，部分参数仅商业版支持。身份验证受商业版范围限制，按接口返回的 success 与 uid 判断。匿名 localId 依赖同一设备同一浏览器，跨设备记录需另行设计身份与会话管理。

假设演练样本：某门店培训用样品评估表原文为「样品编号 S-001，供应商 A，检测报告编号 R-001，结论为合格，报告有效范围仅限该批次，日期 2025-03-01，状态为待门店复核」。一条待判定的交接请求拟稿句为「S-001 已通过复核，可通知门店上播」。判定要点：原文状态为待门店复核，拟稿句称已通过复核，两者同主体同字段取值互斥，拟稿句未获支持。上播通知属于业务执行，需要另行确认授权边界。

## 配置怎么定
| 配置项 | 本页相关设置 | 核对方式 |
| --- | --- | --- |
| 免登录窗口链接 | 从发布渠道创建并复制完整链接 | 核对链接标识与业务授权相互独立 |
| 过期时间 | 按使用范围设置并核对实际版本 | 比较链接有效期与培训周期 |
| QPM | 每用户每分钟最大访问次数 | 核对实际版本是否支持配置 |
| 积分上限 | 分享入口产生的最大计费数据 | 核对费用归属团队 |
| 身份验证 | 商业版范围，按接口返回 success 与 uid | 核对返回值格式与 uid 规则 |
| 对话记录边界 | 匿名 localId 依赖同设备同浏览器 | 跨设备记录另行设计身份管理 |

## 容易做错的三处
1. 把链接标识当成业务授权，用分享链接替代门店复核结论。检查输入为样品评估表原文与拟稿句，比较状态字段取值，观察是否出现「已通过复核」而原文为「待门店复核」。
2. 把身份验证的 success 返回当成选品结论通过。检查输入为鉴权接口响应与样品评估表结论，比较两者字段含义，观察是否把身份校验成功写成质检合格。
3. 把匿名 localId 当成跨设备用户身份。检查输入为记录拉取范围与设备条件，比较同设备同浏览器与跨设备场景，观察跨设备时记录是否可用。

## 怎么确认配好了
1. 输入假设样本原文与拟稿句，比较状态字段「待门店复核」与「已通过复核」，当两者同主体同字段取值互斥时，判定拟稿句未获支持。
2. 输入鉴权接口返回 success 为 true 与样品评估表结论字段，比较两者业务含义，当身份校验成功而质检结论未载明时，记录证据缺口。
3. 输入空结果 [] 与下游展示设计，比较空结果承接方式，当检索返回空时核对下游是否按空处理，不声称虚构规则检索一定返回空。
