# 经销商返利核算的门店服务与内部培训：分享与嵌入

## 这个品类的数据长什么样
返利核算发生在销售之后，核心是政策口径与财务处理。数据来自ERP销售、经销商回款、合同台账与财务系统，日常文档包括返利政策、销量达成表、对账单与红字发票。门店服务与内部培训环节要把返利政策口径、达成数据与开票冲抵要求传递给门店和内部人员，分享与嵌入解决的是这些材料以什么形式、在什么授权状态下被外部或内部人员打开。免登录窗口从应用详情的发布渠道创建，复制系统生成的完整链接；链接标识只用于记录展示，不能当成业务授权。身份验证受商业版范围限制，按官方接口返回的 success 与 uid 判断是否允许继续操作。匿名对话记录依赖同一设备同一浏览器，跨设备需另行设计身份与会话管理。

## 这些特征在「分享与嵌入」这一环带来什么约束
返利材料含销量、回款与政策口径，分享入口的过期时间、QPM、积分上限按使用范围设置并核实际版本，部分参数仅商业版支持。身份验证根地址只填到根，FastGPT 在初始化、开始对话与对话结束向该地址的特定接口发请求，body 携带 token=[authToken]。uid 必须返回且不含 |、/、\ 字符、长度不超过 255 字节，否则返回 Invalid UID。检索与相关度不承担权限或实体隔离，相似度设置不排除无关业务或未授权记录。对话记录边界依赖同设备同浏览器，跨设备记录须另行设计身份与会话管理。

假设演练样本：某品牌返利政策文档写有“2025 年第三季度回款达成率按经销商对账单确认金额计算，退货冲减后口径以财务系统为准”。一条拟稿交接请求为“请把该政策链接发给经销商财务，让其自行核对达成率”。该请求未写明授权范围与身份校验方式，链接标识本身不构成授权。

## 配置怎么定
下表围绕上述样本，列出与本页功能、主任务相关的官方已说明设置或实施核对项。

| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| 名称 | 返利政策季度分享 | 仅用于记录展示，与链接标识区分 |
| 过期时间 | 设为季度结束后 30 天 | 假设起点，与政策适用季度末比较 |
| QPM | 未指定，保持未设置 | 文档未给默认值，须核实际版本 |
| 积分上限 | 未指定，保持未设置 | 文档未给默认值，须核实际版本 |
| 身份验证 | 填根地址，不填完整路径 | 官方要求仅配根地址 |
| 对话记录边界 | 依赖同设备同浏览器 | 与跨设备需求比较，确认是否另接 |

## 容易做错的三处
1. 把链接标识当成业务授权。输入是复制的分享链接，比较对象是样本中“让其自行核对”的授权范围，观察结果是链接能否被未授权主体打开并核对达成率。链接标识只用于记录展示，授权状态须由身份验证接口返回的 success 与 uid 决定。
2. 把相似度当成权限过滤。输入是检索请求与 similarity 设置，比较对象是样本中未授权记录是否应出现，观察结果是返回内容是否含未授权记录。相似度是相关度参数，不承担实体或权限隔离。
3. 把匿名本地标识当成跨设备会话。输入是同一 authToken 在不同设备的打开请求，比较对象是对话记录边界说明，观察结果是切换设备后能否拉取同一 uid 记录。匿名标识仅保障同设备同浏览器。

## 怎么确认配好了
1. 身份校验核对。输入样本中 authToken 与根地址，比较接口返回的 success 与 uid 格式，观察 success 为 true 且 uid 不含 |、/、\ 且不超过 255 字节。success 不为 true 时提示 message 或 msg，此时不视为通过。
2. 授权边界核对。输入拟稿交接请求，比较请求是否写明授权范围与身份校验方式，观察请求是否明确哪些主体可打开、核对哪些字段。未写明授权范围时记录为待核实，不判定为已授权。
3. 记录边界核对。输入同一 authToken 在不同设备打开的操作，比较对话记录边界说明，观察切换设备或清空缓存后记录是否丢失。丢失时记录缺口，不声称已实现跨设备会话。
