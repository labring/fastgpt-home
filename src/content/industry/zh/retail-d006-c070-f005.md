# 跨境商品合规与标签的门店服务与内部培训：多轮对话与提示词

## 这个品类的数据长什么样

在跨境商品合规与标签的门店服务与内部培训中，本页说明FastGPT的多轮对话与提示词如何衔接资料。标签培训跨轮保持市场、产品与测试范围，译文不是合规许可。所用场景为自拟文字测试。

## 这些特征在「多轮对话与提示词」这一环带来什么约束

假设英文标签是待审稿，测试报告只涉及指定样品，MSDS资料缺页，平台禁售清单适用某市场。培训先问标签词义、再问是否可售，应重新核当前问题和实际材料，不能继承译文作为准售结论。所有文字自拟，无真实检测或法律判断。缺页及市场范围要保留，不能因对话已有标签解释就称资料齐全。

## 配置怎么定

| 跨境标签培训 | 假设输入 | 逐轮核查 |
| --- | --- | --- |
| 标签 | 待审译稿 | 不作准售依据 |
| 报告 | 指定样品 | 不扩型号 |
| MSDS | 资料缺页 | 保留缺项 |
| 清单 | 特定市场 | 不跨市场推定 |
| 审查 | 真实规则另核 | 不由问答批准 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `提示词与任务` | 说明资料、任务和缺证据处理。 |
| `历史记录` | 核实际提交的历史输入。 |
| `问题优化` | 指代消除与问题扩展需复核。 |
| `模型与长度` | 上下文与回复长度分别核对。 |
| `回复格式` | json_schema需给格式并验解析。 |

## 容易做错的三处

- 后轮将样品测试扩大到所有型号时，对产品标识及报告范围，历史连续不扩大样本。

- MSDS缺页在摘要中消失时，对原目录和实际发送段落，缺失页不能由上轮释义补出。

- 某市场清单被用来判另一市场可售时，对目的市场和规则版本，译名一致不等于适用一致。

## 怎么确认配好了

分别按标签、报告和清单补料，固定问每份材料能支持什么。对比新会话与多轮结果，记录实际历史；提示词要求标未给字段和适用范围。真实标签合规需另核目标市场有效规则与专业审查，本题只处理资料阅读，不审批或上架。
