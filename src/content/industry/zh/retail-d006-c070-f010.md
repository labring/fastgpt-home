# 跨境商品合规与标签的门店服务与内部培训：引用来源与溯源

## 这个品类的数据长什么样
跨境商品合规与标签的核心证据产生在上架和进口之前，门店服务与内部培训需要围绕产品测试报告、英文标签、MSDS、平台禁售清单四类材料展开。这些材料来自平台政策中心、检测机构报告、目的国法规库和供应商资料，更新不定期，每次上新都要重新核对。门店人员向顾客解释商品合规状态时，引用来源必须能追溯到具体文档版本，培训中演示的检索结果同样如此。资料更新频率不影响本页功能，但同一商品在不同时间点的测试报告版本可能不同，核对时需确认所引用的版本与当前上架状态一致。

## 这些特征在「引用来源与溯源」这一环带来什么约束
知识库搜索节点可以关联一个或多个相同向量模型的知识库，输出以数组格式返回引用内容，长度可以为0，空数组不代表工作流报错终止。检索输出需要交给回答环节，逐条核对回答与引用原文。最低相关度是过滤阈值，仅在语义检索或结果重排时生效，不负责权限或实体隔离。混合检索通过RRF融合多路结果，重排需要模型且按设置启用，图片检索需要相应图像输入及模型能力。跨不同向量模型的库不可共同关联，只能先核标识并排除不符合者。

假设演练样本：某门店收到一份供应商提供的英文标签草稿，原文为“Product: Children's Toy, Model KT-2024, Batch 2024-08, Age Grade: 3+, Manufacturer: ABC Toys Co., Ltd.”。另有一份检测报告草稿，原文为“Test Report No. TR-2024-0815, Sample: KT-2024, Test Date: 2024-08-10, Result: Pass for EN71-3”。一条待判定的拟稿句为“该商品已通过EN71-3检测，适合3岁以上儿童使用”。核对时需确认检测报告中的样品型号与标签草稿中的型号一致，检测日期在有效范围内，且拟稿句中的“已通过”与报告中的“Result: Pass”对应，但报告未载明“适合3岁以上”的结论，该部分属于未获支持。

## 配置怎么定
| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 选择已上架商品的合规文档库 | 核对库标识与向量模型标识，排除不同向量模型的库 |
| 搜索模式 | 混合检索 | 同时使用语义与全文召回，适合型号和编号查询 |
| 最低相关度 | 0.5 | 作为本次试验起点，与0.3和0.7的返回结果比较 |
| 引用上限 | 2000 tokens | 与1000和4000 tokens的返回内容比较 |
| 结果重排 | 启用 | 需具备ReRank模型，比较启用前后的排序变化 |
| 引用内容输出 | 数组格式 | 核对输出长度，空数组时检查下游承接设计 |

## 容易做错的三处
1. 将检索输出直接当作授权结论。检索返回引用内容只表示匹配到文档片段，不表示商品已获批准或标签已通过审核。检查时需核对引用原文与拟稿句的对应关系，确认是否存在未载明的结论。
2. 跨不同向量模型的库执行共同关联。文档明确要求相同向量模型才可共同关联，核对时应先检查库标识和向量模型标识，排除不符合者，记录实际观察结果，不推断运行行为。
3. 将最低相关度用于权限或实体隔离。最低相关度是过滤阈值，不排除无关业务或未授权记录。检查时需确认检索范围是否包含所需资料，缺失时记录证据缺口。

## 怎么确认配好了
1. 使用假设样本中的标签草稿和检测报告，输入检索问题“KT-2024 EN71-3检测结果”，比较返回引用中是否包含检测报告原文，观察引用内容是否与报告中的“Result: Pass”一致。预期返回引用包含该报告片段，但不保证首条命中。
2. 使用拟稿句“该商品已通过EN71-3检测，适合3岁以上儿童使用”，比较拟稿句与引用原文，观察“适合3岁以上”是否有对应原文支持。预期该部分标记为未获支持，需补充证据或修改拟稿。
3. 使用空数组输入[]，核对下游承接设计，观察下游节点是否按空引用处理。预期下游设计能处理空数组，不声称虚构规则检索一定返回[]。
