# 跨境商品合规与标签的门店服务与内部培训：知识库检索与召回

## 这个品类的数据长什么样

跨境商品合规与标签的资料集中在四类文档：产品测试报告、英文标签、MSDS、平台禁售清单。这些资料来自平台政策中心、检测机构报告、目的国法规库和供应商资料，更新不定期，每次上新都要重新核对。门店服务与内部培训场景中，员工需要从知识库检索这些文档，判断某个商品的标签或测试证据是否覆盖当前目的国要求。资料更新不定期意味着知识库中的内容可能与最新政策存在时间差，检索结果仅代表入库时的资料状态。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可以关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，需先核对向量模型标识并排除不符合者。搜索模式可选语义检索、全文检索或混合检索。语义检索依赖向量距离计算相似度，适合自然语言问题；全文检索适合编号、型号、专有名词等精确查询；混合检索同时使用两路召回并通过 RRF 融合结果。最低相关度仅在语义检索或使用结果重排时生效，是过滤阈值，不对权限或实体做隔离。引用上限以 token 为单位，控制每次搜索最多引用的内容量。问题优化用于指代消除和问题扩展，在检索前增加一次模型调用。检索本身不构成授权，门店交接中的材料是否可用，需另行核对授权状态。

假设演练样本：某门店员工收到一份待上架商品的资料，拟检索知识库确认标签合规状态。供核对的材料原文为：“产品名称：便携式充电风扇。测试报告编号：STR-2024-0871，签发日期：2024年3月12日，测试标准：IEC 60335-1。英文标签版本：V2.1，标注输入电压 5V DC。”待判定的拟稿句为：“该商品的测试报告与英文标签已覆盖目的国上架要求，可提交上架。”该拟稿句的判定需要比对：测试报告的标准是否为目的国认可标准、标签版本是否为当前有效版本、目的国要求是否在知识库中有对应记录。材料中未载明目的国名称和该目的国的具体合规要求，该拟稿句的“已覆盖”判断缺少依据。

## 配置怎么定

| 配置项 | 本页相关设置或核对项 | 与样本的关联 |
| --- | --- | --- |
| 关联的知识库 | 选择一个或多个使用相同向量模型的知识库 | 确认合规资料库与标签资料库使用同一向量模型标识 |
| 搜索模式 | 语义检索、全文检索或混合检索 | 样本含编号 STR-2024-0871，可用全文检索或混合检索核对编号命中 |
| 引用上限 | 以 token 为单位设置上限 | 样本资料较短，需确认上限值能完整覆盖测试报告与标签内容 |
| 最低相关度 | 0-1 数值，仅在语义检索或结果重排时生效 | 样本问题明确，可先标注相关与无关样本再调阈值 |
| 问题优化 | 用于指代消除和问题扩展 | 样本问题若为“这个报告合规吗”，需确认优化后主体仍为 STR-2024-0871 |
| 结果重排 | 需具备 ReRank 模型并按设置启用 | 样本候选结果较少时可先不启用，观察语义与全文两路召回情况 |

## 容易做错的三处

1. 将检索命中当作授权通过。样本中检索到测试报告 STR-2024-0871，仅表示该报告在知识库中存在，不表示该报告已通过目的国合规审核，也不表示门店已获得上架授权。授权状态需另行核对，检索结果不承担授权功能。

2. 将最低相关度当作权限或实体过滤器。最低相关度是 0-1 的过滤阈值，用于过滤低相关度结果，不对不同目的国、不同门店或不同供应商的资料做隔离。样本中即使调高最低相关度，也不能保证只返回该目的国的合规要求。

3. 将问题优化后的扩展问题直接当作原始问题使用。问题优化会进行指代消除和问题扩展，样本中若原始问题为“这个报告合规吗”，优化后可能补全为“STR-2024-0871 测试报告是否符合目的国上架要求”，需核对补全后的主体和对象是否与原始材料一致，避免优化过程引入错误主体。

## 怎么确认配好了

1. 输入样本材料原文和拟稿句，比较检索结果中是否包含 STR-2024-0871 的测试报告记录和 V2.1 英文标签记录。观察检索结果是否返回了该编号对应的内容，以及返回内容中是否包含测试标准和标签版本字段。若检索结果为空数组，需核对资料是否已完成训练入库，不能据此判断该商品不合规。

2. 输入“STR-2024-0871 测试报告是否符合目的国上架要求”，比较全文检索与语义检索的返回结果差异。观察全文检索是否命中编号，语义检索是否返回语义相近但编号不同的报告。若语义检索返回了其他编号的报告，需核对返回内容中的编号字段，确认是否为目标报告。

3. 输入样本拟稿句“该商品的测试报告与英文标签已覆盖目的国上架要求，可提交上架”，比较拟稿句中的判断与知识库中实际载明的信息。观察知识库中是否有目的国名称、目的国合规要求、标签有效期等字段。若知识库中未载明目的国要求，该拟稿句的“已覆盖”判断未获支持，需记录证据缺口，不能据此提交上架。
