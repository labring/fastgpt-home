# 进出口许可证件办理的门店服务与内部培训：知识库检索与召回

## 这个品类的数据长什么样

许可证办理发生在申报之前，决定货物能否合法进出口，门店服务与内部培训需要围绕自动进口许可证、两用物项许可证、合同、产品说明四类材料建立可检索的知识库。这些材料由商务主管部门系统、海关商品编码、供应商资料和客户用途说明汇集而来，每票业务都可能产生新的许可证类型与用途说明，资料更新不定期。门店人员遇到客户询问某类货物需要何种证件时，检索结果直接决定后续准备方向，检索偏差会传导到通关与合同履行环节。知识库搜索节点可关联一个或多个使用相同向量模型的知识库，这一条件在门店多业务线并行时构成硬约束。

## 这些特征在「知识库检索与召回」这一环带来什么约束

许可证名称、商品编码、监管证件编号属于精确查询对象，语义检索可能返回相近但不同的证件条目，全文检索对编号和专有名词更直接。混合检索通过 RRF 融合多路结果，重排模型对候选文本二次排序并给出 0-1 得分，最低相关度仅在语义检索或使用结果重排时生效。引用上限以 token 为单位，许可证材料长短差异大，上限过低会截断用途说明的关键段落。问题优化用于指代消除和问题扩展，门店连续追问场景中可补全主体，但会额外调用模型并增加耗时。检索环节只负责返回引用内容，不承担权限校验或实体隔离，也不判断某位员工是否有权查看某类许可证记录。空结果以数组形式输出，长度可以为 0，下游链路仍会走通。

## 配置怎么定

以下配置围绕本页假设演练样本展开，数值为本次假设试验起点，用于与调整后的检索表现比较，不作为官方默认值。

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联使用同一向量模型的门店许可证知识库 | 先核对各库向量模型标识，排除标识不同的库，再比较单库与多库检索结果 |
| 搜索模式 | 语义检索与全文检索各测一轮，再测混合检索 | 用同一组许可证编号问题与自然语言问题分别比较三路返回内容 |
| 引用上限 | 假设设为 3000 tokens | 用长用途说明与短证件条目各测一轮，比较关键段落是否被截断 |
| 最低相关度 | 假设设为 0.4 | 先标注相关与无关样本，比较不同阈值下无关片段进入引用的比例 |
| 问题优化 | 先关闭，再对多轮追问开启 | 比较原问题与优化后问题的主体是否被改错，记录耗时变化 |
| 结果重排 | 先关闭，再在候选较多的问题上开启 | 比较重排前后同一问题的排序位置与 0-1 得分分布 |

## 容易做错的三处

1. 将不同向量模型的知识库共同关联。知识库搜索节点要求关联相同向量模型的知识库，跨模型关联缺乏文档支持。执行检查：核对每个待关联知识库的向量模型标识，排除标识不一致者，记录实际关联范围，不推断跨模型检索的运行结果。
2. 把最低相关度当作权限或实体过滤。该参数是 0-1 的过滤阈值，仅在语义检索或使用结果重排时生效。执行检查：对同一查询分别设置不同阈值，观察返回引用内容的变化，确认阈值调整只影响相关度过滤，不改变可访问的知识库范围。
3. 将检索返回的引用内容直接视为业务授权。检索只输出引用内容，不执行审批、不写入数据库、不同步外部系统。执行检查：查看下游节点是否另有表单收集、人工核对或系统对接设计，对仅有检索结果的链路记录为待补充授权环节。

## 怎么确认配好了

假设演练样本：某门店知识库中存有一份产品说明，原文为“本产品为工业用离心泵，功率 7.5 千瓦，拟出口至东南亚地区，客户用途为工厂冷却循环。”另有自动进口许可证条目，证件状态栏记载“申请已提交，待审核”。一份内部培训拟稿句写道“该产品已取得自动进口许可证，可安排出运。”待判定请求为“请确认该产品许可证是否已生效，并安排出运。”

1. 输入拟稿句与产品说明原文，比较证件状态栏“申请已提交，待审核”与拟稿句“已取得自动进口许可证”。满足条件为：检索返回该证件条目原文，且拟稿句被标注为与原文状态不一致，待审核不等于已生效。
2. 输入待判定请求与许可证条目，比较请求中的“安排出运”与检索返回内容。满足条件为：检索结果中不包含出运授权条款，请求被记录为超出检索环节可确认范围，需另行核对审批状态。
3. 输入一条不含主体信息的短问题，比较关闭与开启问题优化后的检索词。满足条件为：开启后检索词补全了产品与证件类型，返回引用内容与产品说明对应，且主体未被替换为其他货物。

空结果核对：以明确的纸面输入空数组核对下游设计，观察输出链路是否仍走通，记录下游节点在引用长度为 0 时的实际行为，不预设检索一定返回空数组。
