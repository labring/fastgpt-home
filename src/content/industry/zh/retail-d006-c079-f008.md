# 连锁统采统配的门店服务与内部培训：工作流编排

## 这个品类的数据长什么样

在连锁统采统配的门店服务与内部培训中，本页说明FastGPT的工作流编排如何衔接资料。统配培训围绕替代品讨论、周转箱返还和包装单位传递，演练不批准替换或配货。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

本页自拟统配课堂卡：总部替代品对照只供讨论，门店缺货单仍列原规格，配货便笺提出替换并待门店确认；另一条周转箱返还记录只记容器回收。学员提交这些原句后选择核替代范围或核容器与货品，后续应收到同一待确认状态。总部讨论不代门店同意，容器返还不说明货物已被接收。本题无真实配货数量或订单，也不计算箱件换算。

## 配置怎么定

| 统配课堂材料路由 | 自拟限定 | 学习核法 |
| --- | --- | --- |
| 替代对照 | 总部讨论用途 | 不代门店接受 |
| 缺货规格 | 原规格未改 | 核确认方案 |
| 周转箱 | 仅容器返还 | 不当货品签收 |
| 包装单位 | 箱件依据未给 | 不自动换算 |
| 培训路径 | 规格或对象核查 | 不执行实际配货 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

- 讨论中的替代规格被学员答案写成门店已认可时，对对照用途、缺货原规格及明确确认，不让选路径产生商品替换决定。

- 周转箱返还被解释成门店收货完成时，核记录对象、容器交接与货品回执，两种物流对象不合并。

- 总部按箱描述被下游转成门店按件可用时，对包装单位和实际转换依据，缺说明不能用同品名补比例。

## 怎么确认配好了

固定课堂材料分别走两路径，比较提交与接收的规格、对象和单位；让学员指出哪些依据仍缺。补门店确认只更新同一替代方案，容器或货品状态继续各核。材料均标演练，不向真实系统请求配货。正式替换、订单变更与库存回填需业务批准和接口回执，节点等待后继续只记录互动，不认证门店、不认定培训通过或实际调拨。
