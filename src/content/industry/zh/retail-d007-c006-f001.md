# 一般贸易出口报关的经营报表与异常复盘：HTTP 接口与外部系统

## 这个品类的数据长什么样
一般贸易出口报关每单产生报关单、商业发票、装箱单和合同，数据来源包括中国国际贸易单一窗口、海关编码库、货代提单和企业 ERP。与进口报关相比，出口报关还会影响出口退税凭证匹配，因此经营报表与异常复盘必须同时覆盖申报差错和退税凭证两条核对线。数据更新频率为每单，报表口径需要与单票单据逐笔对应，异常复盘要能追溯到具体单号、具体字段和具体单据版本。归类商品编码、填制报关单、核对运费保费是三个最耗时环节，报表字段设计应优先保证这三处可核对。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
HTTP 模块向指定地址发送请求，Params 用于路径请求参数，Body 用于 POST/PUT 请求体，Headers 用于传递请求头，三处均可通过 `{{}}` 引用全局变量、系统变量和前方节点输出。URL 也可引用变量。系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories，其中 chatId 与 responseChatItemId 在测试模式下不存在。返回值通过 JSON path 提取，输出类型选择字符串时会把对应 key 的值转成 json 字符串。对话接口使用 APIKey 鉴权，推荐在请求体传入 body.appId，也支持 Authorization: Bearer <apiKey>-<appId>；传入的 model、temperature 等字段无效，由编排决定。detail=true 时返回中间值，stream 模式下通过 event 区分，非 stream 模式结果保存在 responseData 中。交互节点返回的 interactive 只含 type 和 params，内部运行态字段不返回。检索或表单收集不构成授权，业务核验、审批、数据库写入和外部同步需要各自的下游实现。

假设演练样本：某外贸公司单证员在 2026 年 3 月 10 日处理一票出口报关单，单号 HYP-2026-0310-001，商业发票金额 USD 48,000，装箱单件数 320 件，合同编号 CT-2026-008。拟稿句为“本票出口报关单已完成申报并取得退税凭证”。待判定请求为“将该票状态通过 HTTP 模块写入外部系统”。材料原文仅显示该票已录入企业 ERP 并生成报关单草稿，未显示申报提交、海关回执或退税凭证取得记录。

## 配置怎么定
围绕上述样本，配置表仅列与本功能、主任务相关的官方已说明设置或实施核对项。

| 配置项 | 本次假设试验起点 | 核对方法与理由 |
| --- | --- | --- |
| 请求地址与方法 | 按外部接口文档填写，地址可引用变量 | 核对地址与方法是否与外部接口契约一致 |
| Params 与 Headers | 鉴权凭证通过安全配置注入 | 核对请求参数与请求头，不把凭证写入公开样例 |
| Body | 仅在相应请求类型下使用 | 核对 JSON 结构与外部接口契约 |
| 变量引用 | 引用全局变量、系统变量和前方节点输出 | 逐项核对实际传入值 |
| 调试身份字段 | chatId 与 responseChatItemId 在测试模式下不存在 | 不把调试空值当成业务故障 |
| 返回值提取 | 按 JSON path 配置 key | 核对输出类型与提取结果 |

## 容易做错的三处
1. 把草稿录入当成申报完成。输入为样本材料原文，比较对象为“已录入 ERP 并生成报关单草稿”与“已完成申报并取得退税凭证”，观察结果为材料未显示申报提交、海关回执或退税凭证记录，拟稿句未获支持。
2. 把检索或表单当成授权执行。输入为待判定请求“将该票状态通过 HTTP 模块写入外部系统”，比较对象为表单收集与业务核验、审批、数据库写入、外部同步的下游实现，观察结果为未提供授权凭证或审批记录时，写入请求处于待核实状态。
3. 把调试模式空值当成业务故障。输入为测试模式下 chatId 与 responseChatItemId 不存在，比较对象为文档说明的测试模式条件，观察结果为该空值属于文档已说明情形，不构成业务异常。

## 怎么确认配好了
1. 针对拟稿句“本票出口报关单已完成申报并取得退税凭证”，输入样本材料原文，比较申报提交、海关回执、退税凭证三类记录是否存在，观察结果为三类记录均未出现时，该句未获支持。
2. 针对待判定请求“将该票状态通过 HTTP 模块写入外部系统”，输入请求内容与授权边界说明，比较是否存在审批记录或授权凭证，观察结果为未提供时，该请求停留在待核实状态。
3. 针对空结果承接，输入明确的纸面输入 []，比较下游设计对空数组的处理，观察结果为下游按空结果分支处理时满足条件，不声称虚构规则检索一定返回 []。
