# 加盟商培训与开业辅导的经营报表与异常复盘：对话日志与审计

## 这个品类的数据长什么样

在加盟商培训与开业辅导的经营报表与异常复盘中，本页说明FastGPT的对话日志与审计如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「对话日志与审计」这一环带来什么约束

加盟培训复盘可先核目标对话是否只讲过SOP，还是实际取得了本店考核与开业资料。自拟记录只有签到和手册解释，没有测验过程或现场核查。chatId帮助定位交流，但不能从问答完成推出学员已掌握操作，也不表示开业清单已在业务系统全部勾核。日志实际有哪些输入和返回需要逐项查看，不推定考核字段或全部培训历史自然留存。

## 配置怎么定

| 核对对象 | 本题自拟记录 | 应查证据 |
| --- | --- | --- |
| 学习范围 | 签到和手册解释 | 未直接判掌握操作 |
| 版本混用 | 旧手册会话进入当前 | 核身份版本及来源 |
| 考核缺证 | 返回没有实际测验记录 | 不由detail推通过 |
| 测试区分 | 测试答复与正式考核分开 | 身份历史分别核 |
| 业务批准 | 开业认定与留存另办 | 日志未代替总部批准 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `对话身份` | 将目标会话与资料身份对应。 |
| `运行详情` | 按接口契约查看运行详情。 |
| `字段含义` | 以实际返回字段为准。 |
| `调试与正式调用` | 核调试与正式调用的输入差别。 |
| `业务审计分工` | 对账及留存需方案另行落实。 |

## 容易做错的三处

若旧版手册对话混入本次培训，应排查会话身份、输入版本与解释来源，不能用最近答复代替适用核对。若responseData没有考核记录，就无法证明人员通过；可依官方契约设置detail后看实际返回，缺业务证据仍另取。测试时的身份差异也要单独看，不能把测试答复归为员工正式考核。

## 怎么确认配好了

验收保留门店、学员自拟身份、手册版本和考核缺口，对照正式及调试的历史、输入与返回。补实际业务材料后检查解释，不以记录存在宣布培训完成。开业批准、人员认定、档案回写和留存要求需完整流程另行落实；本次日志核对只说明已取得的交流证据，不证明总部已批准开业或培训质量已完成审计。
