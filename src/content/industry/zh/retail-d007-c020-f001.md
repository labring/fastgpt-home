# 原产地证书申办的经营报表与异常复盘：HTTP 接口与外部系统

## 这个品类的数据长什么样

原产地证服务进口国关税与清关，其申办链条围绕原产地证申请、商业发票、装箱单、生产成本资料展开。经营报表与异常复盘需要把这些单据的字段与外部系统的请求记录放在同一时间线上对照。数据来源包括中国国际贸易单一窗口、贸促会系统、企业生产记录与客户清关要求，更新频率为每单或批量。这一环的报表价值在于：把每单的申报字段、接口请求与外部回执串起来，定位差异发生在哪个字段或哪次请求。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向对应地址发送请求，Params 用于路径参数，Headers 传递特殊信息，Body 在特定请求类型下生效。三类数据均可通过 `{{}}` 引用全局变量、系统变量与前方节点输出。返回值通过 JSON path 提取，输出类型选择字符串时会把对应 key 的值转成 json 字符串。系统变量中 chatId 与 responseChatItemId 在测试模式下不存在，调试时的空值属于环境差异，不能当作业务故障。对话接口的 appId 优先级为 body.appId、`<apiKey>-<appId>`、apikey 关联的 appId；传入的 model、temperature 由编排决定。detail=true 时 responseData 保存模块状态与完整结果，可用于复盘节点运行时间与 token 消耗。

假设演练样本：某出口企业单证员在 2025 年 3 月 10 日提交一份原产地证申请，随附商业发票号 INV-2025-0310、装箱单号 PL-2025-0310 与生产成本资料一份，申请状态为“已提交待审核”。交接请求拟稿句为：“该申请已通过审核并已完成证书签发，可直接用于客户清关。”按现有材料，审核与签发均未载明，该拟稿句属于未获支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 核对方式 |
| --- | --- | --- |
| 请求地址 | 外部接口文档给出的地址 | 与接口文档逐字比对，地址可引用变量 |
| 请求方法 | 按外部接口契约选择 | 与接口文档声明的动作比对 |
| Headers 鉴权 | 通过安全配置注入凭证 | 核对凭证未写入公开样例 |
| Body 结构 | 按接口契约的 JSON 字段 | 核对字段名与类型一致 |
| 返回值提取 | JSON path 表达式 | 用样本响应核对提取结果 |
| 输出类型 | 字符串或对象 | 按下游节点需要选择 |

## 容易做错的三处

1. 把调试环境的空值当成业务故障。测试模式下 chatId 与 responseChatItemId 不存在，若报表按这两个字段统计会话，会把调试记录误判为缺失会话。检查方式：输入测试模式请求，比较返回中这两个字段的有无，观察是否与测试模式说明一致。
2. 把待审核状态写成已签发。样本中申请状态为“已提交待审核”，拟稿句写成“已通过审核并已完成证书签发”。检查方式：输入样本原文与拟稿句，比较状态字段取值，观察拟稿句是否超出原文范围。
3. 用相似度分数替代权限判断。返回中的 similarity 是检索相关度，不承担实体或权限过滤。检查方式：输入含相似度分数的返回，比较其字段含义与权限字段，观察是否把分数当作访问控制依据。

## 怎么确认配好了

1. 输入样本原文与拟稿句，比较“已提交待审核”与“已通过审核并已完成证书签发”，当拟稿句出现原文未载明的审核与签发结论时，判定为未获支持。
2. 输入测试模式下的请求返回，比较 chatId 与 responseChatItemId 是否出现，当两者均不存在时，记录为测试模式差异，不记为业务故障。
3. 输入含 similarity 的返回，比较该字段与权限相关字段，当 similarity 仅表示相关度时，确认未将其用作授权或实体隔离依据。
