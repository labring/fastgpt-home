# 品牌会员私域运营的经营报表与异常复盘：对话日志与审计

## 这个品类的数据长什么样

在品牌会员私域运营的经营报表与异常复盘中，本页说明FastGPT的对话日志与审计如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「对话日志与审计」这一环带来什么约束

会员运营日志复盘可以只用通用规则和自拟活动文字，不在公开样例放个人数据。自拟对话讨论活动安排、券规则与授权缺口，没有实际发送或使用结果。chatId帮助回看这次交流及输入，不表示会员行为、权限和所有触达记录都已自动留存，也不能从聊天中出现“可发送”的建议推定业务已获准或活动已执行。

## 配置怎么定

| 核对对象 | 本题自拟记录 | 应查证据 |
| --- | --- | --- |
| 公开材料 | 通用规则与活动文字 | 没有真实个人数据 |
| 活动混用 | 其他活动相似话术 | 核原题和来源范围 |
| 许可缺证 | 返回无授权操作依据 | 未从建议判可执行 |
| 留存区别 | 日志存在与业务留存要求 | 分别核，不自动宣称满足 |
| 正式处理 | 发送写入和审计另落实 | 对话未代替权限通过 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `对话身份` | 将目标会话与资料身份对应。 |
| `运行详情` | 按接口契约查看运行详情。 |
| `字段含义` | 以实际返回字段为准。 |
| `调试与正式调用` | 核调试与正式调用的输入差别。 |
| `业务审计分工` | 对账及留存需方案另行落实。 |

## 容易做错的三处

若其他活动的对话被纳入本期，应排查活动身份、原问题与来源范围，不能用相似话术借用结果。若responseData没有授权或实际操作依据，就无法证明权限已核验；按官方契约检查detail和真实返回，缺业务记录仍另取。日志记录存在与留存满足业务要求也须分开，不把测试身份记录当正式个人授权。

## 怎么确认配好了

验收保留活动、会话身份、公开材料范围和未给结果，调试与正式的输入、历史及返回分别核，不用真实个人资料填例子。发送、标签写入、优惠处理、留存与合规审计需完整业务方案另落实；本次对话回看不证明活动效果、权限通过或数据处理已完成审查，也不代表账号操作实际发生。
