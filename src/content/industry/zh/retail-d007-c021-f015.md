# 品牌会员私域运营的经营报表与异常复盘：知识库检索与召回

## 这个品类的数据长什么样

会员私域的资料围绕顾客数据与复购触达展开。会员标签表记录分层口径，触达计划记录人群与节奏，优惠券规则记录门槛与有效期，隐私授权记录记录同意状态。这些资料按日或按周更新，用于经营报表与异常复盘时，检索结果需要能回到具体字段与期间。

资料类型混合带来一个直接约束：编号、券码、标签名适合关键词命中，自然语言描述适合语义召回。一次检索可能同时涉及两类，单一模式未必覆盖全部问法。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可以关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，核对时先看标识并排除不符合者，记录实际观察，不执行跨模型检索来比较漏召回。检索是对整个库进行，集合仅用于分类管理，与搜索效果无关。向量召回后按向量 ID 回 MongoDB 取原数据，同一组原数据合并时取最高得分。混合检索经 RRF 融合多路结果，RRF 是融合过程，不是开关。最低相关度仅在语义检索或使用结果重排时生效，它过滤低相关度结果，不承担权限或实体隔离。引用上限以 tokens 为单位，输出引用是数组，长度可以为 0，没有搜索到内容时链路仍走通。

假设演练样本：某品牌 CRM 团队留存一份《会员标签表》片段，原文为「标签『高复购-30天』定义：近30天完成2次及以上支付订单；生效期间2025-06-01至2025-06-30；适用渠道为小程序。」另有一条待判定拟稿句：「该标签在2025年7月仍持续有效。」核对时比较标签定义中的生效期间与拟稿句所述月份，7月不在载明期间内，拟稿句未获支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联使用同一向量模型的库 | 先核向量模型标识，排除不一致者再关联 |
| 搜索模式 | 语义检索与全文检索各跑一遍 | 用同一测试问题比较两路命中，再决定是否混合 |
| 引用上限 | 设为一个覆盖完整券规则的 token 值 | 用长短不同的实际资料片段比较内容是否被截断 |
| 最低相关度 | 先标注相关与无关样本再定阈值 | 仅在语义检索或结果重排时生效，比较过滤前后样本 |
| 问题优化 | 在多轮追问与短问题场景开启 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 候选较多且问题明确时启用 | 需具备重排模型并按设置启用，比较重排前后排序 |

表中数值均为本次假设试验起点，不表示官方默认值。图片检索须有相应图像输入及模型能力，文档流程图列出的可选路径不代表每次请求全部执行。

## 容易做错的三处

1. 把最低相关度当作权限或实体过滤。输入是同一问题下的候选结果，比较对象是相关度得分与授权范围，可观察结果是低分结果被过滤而越权记录是否仍出现。相关度不负责隔离，检索不构成授权。
2. 把跨向量模型的库强行共同关联。输入是待关联库的向量模型标识，比较对象是标识是否一致，可观察结果是标识不一致者被排除并记录。不据此推断漏召回或行为异常。
3. 把待审核或已报价当作已生效。输入是交接材料中的状态字段，比较对象是同一字段在同一期间的取值，可观察结果是状态为待审核时判定为待核实。签署、合作达成、合同生效是三个不同事实。

## 怎么确认配好了

1. 输入上述《会员标签表》原文与拟稿句「该标签在2025年7月仍持续有效」。比较标签定义中的生效期间与拟稿句月份。仅当拟稿句所述月份落在载明期间内才满足支持条件；本次比较结果为未获支持，证据缺口保留。
2. 输入一条含券码的精确查询与一条自然语言查询，分别走全文检索与语义检索。比较两路返回的引用内容数组。观察是否出现某一路为空数组的情况；空结果承接可用纸面输入 [] 核对下游设计，不声称虚构规则检索一定返回 []。
3. 输入一条交接请求：「请将6月触达计划中的券包配置同步至7月。」比较请求所述动作与材料中载明的授权状态。仅当存在明确授权记录且动作与授权范围一致才满足执行条件；本次未提供该授权记录，判定为待核实，不执行同步。

以上均为纸面核对，未实际部署、测试或产生业务动作。
