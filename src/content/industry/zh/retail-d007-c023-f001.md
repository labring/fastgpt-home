# 品牌售后维修服务的经营报表与异常复盘：HTTP 接口与外部系统

## 这个品类的数据长什么样

品牌售后维修服务围绕保修责任与线下维修网点展开，与电商平台售后只处理退款不同，它要同时面对保修卡、维修工单、检测报告与换货审批四类材料。经营报表与异常复盘需要把这些材料的状态串起来看：某张工单处于待检测、待审批还是已完结，某次换货审批是否已经走完授权。数据来源包括售后系统、门店订单、维修网点反馈与国家三包目录，更新频率为每单与每日。

HTTP 接口与外部系统这一环，承担的是把上述状态送出去或取回来的动作。接口本身不判断保修范围，也不替代审批，它只按外部接口文档发送请求并解析响应。报表与复盘因此必须区分：哪些字段来自接口返回值，哪些字段仍需人工核对材料原文。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

接口调用会向对应地址发送 HTTP 请求，Params 用于路径请求参数，Body 用于请求体，Headers 用于请求头。三种数据均可通过 `{{}}` 引用变量，URL 也可引用变量。变量来自全局变量、系统变量与前方节点输出。返回值通过 JSON path 语法提取，输出类型选择字符串时会把对应 key 的值转成 json 字符串。

系统变量中，chatId 与 responseChatItemId 在测试模式下不存在。调试时出现空值，属于文档已说明的测试环境差异，不能据此判定业务故障。鉴权凭证通过安全配置注入，不写入公开样例。接口返回的 `score` 是相似度，不承担权限或实体隔离功能；检索结果不等于授权结果。

假设演练样本：某品牌售后中心在 2025 年 3 月 10 日收到一张维修工单，材料原文为「工单号 WX-0310-07，产品型号 A2，故障描述为屏幕闪烁，保修卡有效期至 2025 年 6 月 30 日，检测报告结论为人为损坏」。待判定的拟稿句为「该工单属于保修范围，可直接安排免费换货」。判断所需主体是工单 WX-0310-07，对象是产品型号 A2，状态是检测报告结论「人为损坏」，有效范围是保修卡有效期至 2025 年 6 月 30 日。该拟稿句与检测报告结论处于同一字段但取值互斥，属于未获支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 请求地址 | 外部接口文档给出的地址 | 与文档地址逐字符比较，地址可引用变量 |
| 请求方法 | 按外部接口契约选择 | 与契约声明的方法比较，不凭经验指定 |
| Headers 鉴权 | 通过安全配置注入凭证 | 与文档要求的鉴权方式比较，不写入公开样例 |
| Body 结构 | 按外部接口契约核对 JSON | 与契约字段逐一比较，仅在相应请求类型下生效 |
| 变量引用 | 引用全局变量或前方节点输出 | 与节点实际输出比较，逐项核对传入值 |
| 返回值提取 | 按 JSON path 语法配置 key | 与接口响应示例比较，输出类型选字符串时转 json 字符串 |

上述起点均为本次假设试验所用，不是官方默认值。数值与字段以外部接口文档为准，文档未载明时保持未知。

## 容易做错的三处

1. 把检索相似度当作权限过滤。输入是接口返回的 `score` 字段，比较对象是授权范围声明，观察结果是 score 高不等于该记录对当前调用方可见。相似度只表示文本相关程度。
2. 把测试模式下的空 chatId 当作业务故障。输入是测试模式返回的 chatId 空值，比较对象是文档对测试模式的说明，观察结果是该空值属于已说明差异，不构成业务异常证据。
3. 把待审批的换货工单写成已批准。输入是工单状态字段，比较对象是审批完成记录，观察结果是状态为待审批时不能得出已批准结论。

## 怎么确认配好了

1. 针对假设样本 WX-0310-07，输入拟稿句「该工单属于保修范围，可直接安排免费换货」，比较对象是检测报告结论「人为损坏」与保修卡有效期，观察结果是拟稿句与检测报告结论在同一字段上取值互斥，判定为未获支持。
2. 针对接口返回值提取，输入一份含 `data.user.name` 的响应，比较对象是配置的 key，观察结果是提取值与响应中对应字段一致；若响应为空数组，则提取结果为空，下游设计需按空值处理，不能声称虚构规则检索一定返回空。
3. 针对鉴权配置，输入一次带 Authorization 头的请求，比较对象是文档要求的鉴权方式，观察结果是请求被接受或返回鉴权错误；未观察到实际响应时，该结果保持未知。检索库同向量模型要求仅适用于该库自身，不扩展为其他外部系统也需同模型。
