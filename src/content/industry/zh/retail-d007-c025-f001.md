# 品牌奥莱折扣运营的经营报表与异常复盘：HTTP 接口与外部系统

## 这个品类的数据长什么样

品牌奥莱折扣运营围绕过季库存清理展开，主要数据来源包括 ERP 库龄、POS 销售、奥莱商场活动与历史折扣。日常文档涉及折扣审批、滞销清单、价签和毛利测算表。数据按周或按月更新，但本页不依赖该频率构造任何自动同步机制。经营报表与异常复盘需要把滞销清单、折扣审批状态和毛利测算结果汇总核对，HTTP 接口在此承担从外部系统取数与回写状态的通道，接口返回内容与内部文档记录之间的一致性成为核对重点。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向目标地址发送请求，Params 为路径请求参数，Body 为请求体，Headers 为请求头，三者均可通过 `{{}}` 引用变量。变量来自全局变量、系统变量和前方节点输出。系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories。chatId 与 responseChatItemId 在测试模式下不存在，调试时不应把空值当作业务故障。返回值通过 JSON path 提取，输出类型选择字符串时会将对应 key 的值转为 json 字符串。对话接口使用 APIKey 鉴权，调用 chat/completions 时推荐在请求体传入 body.appId；传入的 model、temperature 等参数字段无效，由编排决定。detail=true 时可通过 responseData 查看模块状态与完整结果，但不会返回实际消耗 Token 值。交互节点返回的 interactive 仅含 type 和 params，entryNodeIds、memoryEdges、nodeOutputs、nodeResponseId 等内部运行态字段不会返回。

假设演练样本：某品牌奥莱渠道清货组在纸面核对一份滞销清单与折扣审批记录。清单原文为「SKU A 款，库龄 210 天，当前折扣 5 折，归属 2024 年秋季批次」。折扣审批记录原文为「SKU A 款，申请折扣 4 折，审批状态：待审核」。拟稿句为「SKU A 款折扣已批准，可按 4 折执行」。核对时需比较同一 SKU、同一批次、同一折扣字段的取值，审批状态为待审核不构成批准。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 核对方式与理由 |
| --- | --- | --- |
| 请求地址 | 外部接口文档给出的地址，可引用变量 | 按接口文档选择，地址含变量时核对实际传入值 |
| 请求方法 | 按接口文档选择 GET 或 POST | 与接口契约比较，不凭经验指定 |
| Headers 鉴权 | Authorization 通过安全配置注入 | 不写入公开样例，核对凭证是否到位 |
| Body 结构 | 仅在相应请求类型下使用 | 与外部接口契约逐字段比较 |
| 变量引用 | 引用全局变量或前方节点输出 | 逐项核对实际传入值 |
| 返回值提取 | 按 JSON path 配置 key | 与接口响应结构比较，确认提取路径 |

## 容易做错的三处

1. 把待审核状态当作已批准。输入为审批记录原文「审批状态：待审核」，比较对象为拟稿句「折扣已批准」，可观察结果为审批状态字段取值与拟稿句声明不一致，拟稿句未获支持。
2. 把测试模式下 chatId 不存在当作业务故障。输入为测试模式请求，比较对象为系统变量说明中 chatId 在测试模式下不存在的记载，可观察结果为测试环境返回空值，该现象符合文档描述，不构成故障。
3. 把交互节点返回的展示配置当作完整运行态。输入为 interactive 返回内容，比较对象为文档中仅返回 type 和 params 的说明，可观察结果为 entryNodeIds 等字段缺失，该缺失符合文档，不表示运行异常。

## 怎么确认配好了

1. 输入假设演练样本中的清单原文与审批记录原文，比较同一 SKU、同一批次、同一折扣字段的取值，可观察结果为审批状态字段为待审核，拟稿句声明已批准，两者不一致，拟稿句判定为未获支持。
2. 输入一条 detail=true、stream=false 的请求，比较返回结构中 responseData 是否包含模块状态与完整结果，可观察结果为 responseData 存在且含模块信息，usage 中 tokens 值需手动计算，不视为接口直接返回实际消耗。
3. 输入一条测试模式请求，比较 chatId 与 responseChatItemId 是否出现，可观察结果为两者均不存在，该现象与文档记载一致，不判定为业务故障。
