# 外贸出口退税申报的经营报表与异常复盘：工作流编排

## 这个品类的数据长什么样

在外贸出口退税申报的经营报表与异常复盘中，本页说明FastGPT的工作流编排如何衔接资料。退税复盘按资料准备、申报与处理凭据拆分，流程整理不产生税务处理结果。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟出口资料清单列装运文件已汇集，报关摘要仍待核对，另附历史期间处理通知。复盘流程先收期间与材料身份，让人员选择补当前文件或查看差异，再把所选原文传给下游判断。清单齐全只描述已汇集的范围，不能写作本期申报完成；本例不提供真实税额或审批结论。

## 配置怎么定

| 出口退税复盘 | 纸面材料 | 验收依据 |
| --- | --- | --- |
| 资料清单 | 文件已汇集 | 非已申报 |
| 报关摘要 | 仍待核对 | 保留限定 |
| 历史通知 | 另一期间 | 隔离身份 |
| 选择路径 | 补件或看差异 | 查实际传入 |
| 外部办理 | 申报回填另接 | 核权限回执 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

已汇集被答已申报时，核正式提交凭证；历史通知被套本期时，核期间与主体；报关待核被写无差异时，核原文限定。三处分别看办理阶段、时间归属和不确定性，不能用节点运行次数代替业务证据。

## 怎么确认配好了

验收检查每个选择的分支及下游收到的材料版本，补文件后只更新那项缺口。当前处理通知缺席时保留待核，正式税务判断由实际主管流程与凭据确定。外部申报及表格回填须另接接口、核权限和执行回执，流程中的状态记录只说明交互过程。 装运文件的清单位置与本期提交凭证分别列出，避免文件汇集状态遮住申报缺证。
