# 天猫旗舰店日常运营的经营报表与异常复盘：对话日志与审计

## 这个品类的数据长什么样

天猫旗舰店日常运营强调品牌授权、旗舰店身份与天猫积分赔付规则，数据来源包括天猫商家后台、天猫规则中心、ERP订单表与客服聊天记录。经营报表与异常复盘要面对商品发布页、品牌授权书、发货承诺记录、售后工单等文档，更新频率为日与每单。对话日志与审计环节的核心影响在于：客服聊天记录与接口调用记录是复盘延迟发货、售后争议的旁证材料，但日志留存本身不构成业务授权，也不等于合规审计已完成。核对时须把对话身份与业务记录对齐，避免把不同入口的会话混算。

## 这些特征在「对话日志与审计」这一环带来什么约束

对话接口文档说明，调用 chat/completions 时推荐在请求体传入 body.appId，也支持 Authorization: Bearer <apiKey>-<appId>，appId 优先级为 body.appId、<apiKey>-<appId>、apikey 关联的 appId。chatId 为非空字符串时，系统自动从数据库取会话，并以 messages 数组最后一个内容作为用户问题，其余 message 被忽略；chatId 需自行确保唯一且长度小于 250。responseChatItemId 传入后作为本次响应消息 ID 存入数据库，须在当前 chatId 下唯一。detail=true 时，非 stream 模式的中间值保存在 responseData，stream 模式通过 event 区分，event 取值包括 answer、flowNodeStatus、flowResponses、error 等。对话 CRUD 提供会话列表、会话基本信息、对话列表、单个对话运行详情与反馈更新等接口，source=api 只取通过 API 创建的会话。检索相似度与 quoteList 属于召回结果，不承担权限或实体隔离职责；日志存在不等于完成合规审计，对账、留存与合规要求由完整业务方案另行落实。

假设演练样本：材料原文为“本店 2025 年 3 月 1 日至 3 月 31 日订单的发货承诺记录显示，订单 A 于 3 月 5 日下单，承诺 48 小时内发出，实际 3 月 9 日发出。”另有一条待判定拟稿句：“该会话记录可证明订单 A 延迟发货责任已确认。”判断所需主体为店铺运营方，对象为订单 A，状态为已发出且超出承诺窗口，有效范围为 3 月 1 日至 3 月 31 日。拟稿句把日志留存当作责任确认，超出材料支持范围。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| appId 传递位置 | 请求体 body.appId | 与 Authorization 中 <apiKey>-<appId> 写法比较，核对实际生效来源 |
| chatId | 本次演练会话标识 | 检查唯一性与长度小于 250，与目标业务记录对齐 |
| detail | true | 需要中间值时与 detail=false 返回比较，观察 responseData 是否出现 |
| stream | false | 与 stream=true 比较，确认 event 区分方式差异 |
| source | api | 与页面会话比较，确认会话列表只取 API 创建来源 |
| loadCustomFeedbacks | true | 与不传该参数比较，观察自定义反馈字段是否返回 |

以上数值为本次假设演练起点，不是官方默认值。

## 容易做错的三处

1. 把 chatId 当作业务订单号使用。输入为会话标识，比较对象为 ERP 订单表字段，若两者命名相近但来源不同，会话记录不能直接对应订单。
2. 把 detail=true 返回的 quoteList 相似度当作权限过滤结果。输入为召回条目，比较对象为目标检索范围，相似度高不表示该会话有权访问该业务记录。
3. 把日志留存当作责任确认。输入为拟稿句，比较对象为发货承诺记录原文，材料只显示实际发出日期，未载明责任归属，属于未获支持。

## 怎么确认配好了

1. 输入假设样本中的发货承诺记录原文与拟稿句，比较拟稿句是否超出原文所述主体、对象、状态与有效范围，若拟稿句加入责任确认结论而原文未载明，则判定为未获支持。
2. 输入 detail=true 与 detail=false 两次请求，比较 responseData 是否出现中间值，若 detail=true 时 responseData 含模块响应而 detail=false 时不返回，则符合文档所述条件。
3. 输入 source=api 的会话列表请求，比较返回 list 是否只含 API 创建会话，若页面来源会话未出现，则符合文档所述条件；空结果可用纸面输入 [] 核对下游设计，不声称虚构规则检索一定返回空。
