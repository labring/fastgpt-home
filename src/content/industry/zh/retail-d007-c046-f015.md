# 平台类目资质准入的经营报表与异常复盘：知识库检索与召回

## 这个品类的数据长什么样
类目准入发生在上架或入驻之前，核心资料是主体资质与授权链。本任务要处理的文档为营业执照、商标注册证、品牌授权链、行业许可证。这些材料来自平台招商页面、国家企业信用信息公示系统、商标局数据与许可证系统，更新不定期，每次入驻重新收集。经营报表与异常复盘要回答的问题，是某次检索或某份表单请求当前处于什么状态，材料是否齐备，授权链是否连续。检索环节只负责把已入库的资料找出来，它不核验营业执照真伪，也不判断授权是否生效。

## 这些特征在「知识库检索与召回」这一环带来什么约束
资料更新不定期，意味着库内可能同时存在旧版与新版扫描件，检索结果需要人工比对版本与日期。知识库搜索节点可关联一个或多个使用相同向量模型的知识库，跨不同向量模型的库不可共同关联，只能先核标识、排除不符合者。搜索模式分为语义检索、全文检索与混合检索，混合检索通过 RRF 融合多路结果，RRF 是融合过程，不是可开启的开关。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值，不是权限或实体隔离手段。引用上限以 token 为单位，输出引用内容以数组形式给出，长度可以为 0。

假设演练样本：某入驻专员在知识库中检索一份品牌授权链。库内材料原文为三句：“授权方：华辰日化有限公司。被授权方：瑞通商贸有限公司。授权品牌：洁云。授权期限：2025年1月1日至2025年12月31日。”另有一份营业执照原文：“名称：瑞通商贸有限公司。统一社会信用代码：假设编号91330100MA2XXXXX0A。经营范围：日化用品销售。”待判定的拟稿句为：“瑞通商贸有限公司已获得华辰日化有限公司对洁云品牌的长期授权。”该拟稿句的授权期限与原文“2025年1月1日至2025年12月31日”不一致，“长期授权”未获原文支持。

## 配置怎么定
下表围绕本样本，列出与本功能、本任务相关的官方已说明设置或实施核对项。数值仅为本次假设试验起点，用于与另一取值比较。

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 仅关联存放资质扫描件的同一向量模型库 | 跨不同向量模型的库不可共同关联，先核向量模型标识 |
| 搜索模式 | 先用混合检索 | 与单独语义检索、单独全文检索比较召回内容差异 |
| 最低相关度 | 起点设为 0.5 | 仅在语义检索或结果重排时生效，与 0.3、0.7 比较过滤后条数 |
| 引用上限 | 起点设为 3000 tokens | 与 1500、6000 比较授权链三句是否被完整引用 |
| 问题优化 | 本次不开启 | 与开启后比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 本次不启用 | 启用后比较重排得分与向量得分排序差异 |

## 容易做错的三处
1. 把检索召回当成授权确认。样本中检索到授权链三句，只说明资料在库内被找到，授权是否连续、是否覆盖当前入驻期间，仍需人工比对期限与主体。
2. 把最低相关度当作权限过滤。该值只过滤低相关度结果，不排除无关企业或未授权记录，相似度分数不承担实体隔离职责。
3. 把待审核请求当作已批准。拟稿句处于待判定状态，检索到相关材料不表示入驻申请已通过，也不表示保证金已处理。

## 怎么确认配好了
1. 输入样本三句授权链原文与拟稿句，比较拟稿句“长期授权”与原文“2025年1月1日至2025年12月31日”，观察是否识别出期限表述不一致，判定为未获支持。
2. 输入营业执照原文与拟稿句，比较主体名称“瑞通商贸有限公司”与“华辰日化有限公司”，观察拟稿句是否把授权方与被授权方混同，若混同则判定为同主体比对失败。
3. 输入一条与资质无关的问句，观察返回引用数组是否为 0 或仅含低相关片段，不预设无关查询必为空；若返回内容与资质无关，记录为检索范围待收敛，不据此断言权限已隔离。
