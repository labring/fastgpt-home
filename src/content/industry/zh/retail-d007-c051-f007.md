# 抖音小店货架运营的经营报表与异常复盘：对话日志与审计

## 这个品类的数据长什么样
抖音小店货架运营围绕商品卡与店铺体验分展开，数据来自抖店工作台、抖音电商学习中心、精选联盟数据与物流接口，更新频率为日更与每单。经营报表与异常复盘要处理商品资质页、体验分明细、发货违规申诉、店铺公告。对话日志与审计在此环节的作用，是把对话接口产生的会话与对话记录，同上述业务材料按同一主体、同一期间、同一字段对齐。日志记录的是接口侧事实，业务侧的资质状态、申诉结论与赔付结果需要另行核对，两者不能互相替代。

## 这些特征在「对话日志与审计」这一环带来什么约束
会话与对话的标识层级为 appId、chatId、dataId。获取会话列表需传 appId、offset、pageSize、source，source=api 只取通过 API 创建的会话，不取页面上的会话。获取对话列表需传 appId、chatId、offset、pageSize，可选 loadCustomFeedbacks。获取单个对话运行详情需传 appId、chatId、dataId。需要中间值时设置 detail=true，非 stream 模式结果保存在 responseData，stream 模式通过 event 区分。传入的 model、temperature 等参数字段无效，由编排决定。不会返回实际消耗 Token 值，设置 detail=true 后可手动计算 responseData 里的 tokens 值。清空应用会话只清空通过 API Key 创建的会话。

假设演练样本：某抖店商家在 2025 年 3 月 10 日至 3 月 16 日期间，用同一 appId 下的两个 chatId 分别承接商品资质咨询与发货违规申诉咨询。材料原文为：「3 月 12 日体验分明细显示物流体验项扣分，原因栏为空。」「3 月 14 日发货违规申诉状态为待审核，未显示审核结论。」待判定拟稿句为：「该商家 3 月 12 日物流体验扣分已由 3 月 14 日申诉处理完毕。」该拟稿句把待审核当作已处理，且把两个不同 chatId 的会话混为同一业务记录，需要退回核实。

## 配置怎么定
下表为本次假设试验的核对项，数值为假设起点，用于与接口实际返回值比较，不代表官方默认值。

| 核对项 | 假设起点 | 比较方法 |
| --- | --- | --- |
| 会话来源筛选 | source 取 api | 与页面会话列表对照，确认未混入非 API 会话 |
| 会话分页 | offset 为 0，pageSize 为 20 | 与返回 data.total 比较，核对是否需翻页 |
| 对话分页 | offset 为 0，pageSize 为 10 | 与返回 data.total 比较，核对记录是否完整 |
| 中间值返回 | detail 取 true | 检查 responseData 是否含 moduleName、tokens 等字段 |
| 反馈读取 | loadCustomFeedbacks 取 true | 检查返回项是否含 customFeedbacks |
| 身份代理 | authProxy 由团队所有者开启 | 核对代理身份是否具备目标应用与会话权限 |

## 容易做错的三处
1. 把 source=api 的会话列表当作全部会话。输入为一次不带 source 的请求，比较对象为带 source=api 的返回，观察结果是两次返回的 chatId 集合是否一致。不一致说明页面会话与 API 会话属于不同来源。
2. 把 detail=true 的 responseData 当作业务结论。输入为一次 detail=true 的调用，比较对象为体验分明细与申诉状态材料，观察结果是 responseData 中是否出现扣分原因或审核结论字段。未出现即属于证据缺口。
3. 把待审核申诉写成已处理。输入为材料原文「状态为待审核」，比较对象为拟稿句中的「已处理完毕」，观察结果是两者在同一字段上取值互斥，拟稿句不成立。

## 怎么确认配好了
1. 会话身份核对。输入为假设样本中两个 chatId 与 appId，比较对象为获取会话列表返回的 chatId、appId、title，观察结果是返回项是否与目标会话一一对应，未对应者记录为待核实。
2. 运行详情核对。输入为假设样本中 3 月 12 日所在 chatId 与对应 dataId，比较对象为 getResData 返回的 moduleName、moduleType、tokens、runningTime，观察结果是字段是否与接口契约一致，缺失字段保留为未知。
3. 拟稿句判定核对。输入为材料原文两句与拟稿句，比较对象为同一主体、同一期间、同一字段的取值，观察结果是拟稿句是否与原文一致。原文只显示待审核，拟稿句的已处理结论未获支持，应记录为待核实并保留审核结论缺口。
