# 渠道应收账款催收的经营报表与异常复盘：HTTP 接口与外部系统

## 这个品类的数据长什么样
渠道应收账款催收发生在赊销之后，核心是授信与现金回收。主要数据来源包括财务系统、银行回单、经销商订单与销售合同，日常文档为应收账龄表、催款函、授信协议与发货冻结通知。经营报表与异常复盘需要把账龄、回款、授信占用与冻结状态按周或按月对齐，更新频率为周、月。本页核对 HTTP 请求构造、变量引用与返回值提取。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
HTTP 模块向对应地址发送请求，Params 为路径请求参数，Body 为请求体，Headers 为请求头，三者均可通过 `{{}}` 引用变量。变量来自全局变量、系统变量与前方节点输出。系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories；histories 默认最多取 10 条，无法修改长度。返回值配置代表如何解析接口响应，通过 JSON path 或 JS 对象取值规则提取，输出类型选择字符串时会把对应 key 的值转成 json 字符串。对话接口使用 APIKey 鉴权，推荐在请求体传入 body.appId，也支持 Authorization: Bearer <apiKey>-<appId>；appId 优先级为 body.appId、<apiKey>-<appId>、apikey 关联的 appId。model、temperature 等字段由编排决定，不随 API 参数改变；不返回实际消耗 Token 值，需要时设置 detail=true 并手动计算 responseData 里的 tokens。chatId 与 responseChatItemId 在测试模式下不存在。

假设演练样本：材料原文为“某经销商授信协议载明授信额度 50 万元，有效期至 2026 年 3 月 31 日；截至 2026 年 1 月 31 日应收账龄表显示该经销商逾期 30 天以上金额 12 万元；发货冻结通知草稿状态为待审核，未签署。”待判定拟稿句为“该经销商已超授信，应停止发货并启动催收。”核对范围为 2026 年 1 月账期、该经销商主体、授信额度与冻结状态字段。

## 配置怎么定
| 配置项 | 取值或做法 | 依据与核对点 |
| --- | --- | --- |
| 请求地址 | 按外部接口文档填写，可引用变量 | 地址可含 `{{}}`，本次假设起点为文档给出的服务地址，与接口文档逐字比较 |
| 请求方法 | 按外部接口契约选择 GET 或 POST 等 | 方法由外部接口文档决定，不凭经验指定 |
| Headers 鉴权 | Authorization: Bearer `{{token}}` | 凭证通过安全配置注入，不写入公开样例 |
| Body | 仅在相应请求类型下生效，按 JSON 结构填写 | 引用字符串需加 `""`，数字与布尔不加引号 |
| 返回值提取 | 配置 key，按 JSON path 或 JS 对象取值 | key 对应 FastGPT 转化后的格式，输出类型决定是否转字符串 |
| 测试身份字段 | chatId 与 responseChatItemId 在测试模式下不存在 | 测试空值不作为业务故障判断依据 |

## 容易做错的三处
1. 把返回值配置当成接口返回值本身。返回值配置表示如何解析接口响应，输入是接口响应 JSON，比较对象是配置的 key 与响应结构，可观察结果是提取值是否符合预期；未配置 key 时该值未知。
2. 在测试模式下把 chatId 或 responseChatItemId 的空值当作业务异常。输入是测试模式请求，比较对象是文档说明的“测试模式下不存在”，可观察结果是空值出现；该现象不指向业务故障。
3. 用 body.appId 与 Authorization 同时传入且不一致。输入是两处 appId，比较对象是优先级顺序，可观察结果是实际生效的 appId；不一致时以 body.appId 为准，需人工核对。

## 怎么确认配好了
1. 针对假设样本，输入为授信协议原文、账龄表原文与冻结通知草稿状态，比较拟稿句“已超授信，应停止发货并启动催收”与原文，观察结果为：原文仅载明授信额度与有效期、逾期金额、冻结通知待审核，未载明超授信判定与停止发货授权，该拟稿句未获支持，待核实。
2. 针对 HTTP 请求，输入为按外部接口文档填写的地址、方法与 Headers，比较实际发送的 Params、Body 与接口契约，观察结果为字段与类型一致；不一致处记录差异，不推断外部系统行为。
3. 针对返回值提取，输入为接口响应 JSON 与配置的 key，比较提取值与响应中对应路径的值，观察结果为一致或缺失；缺失时记录为未获取，不判定接口失败。

纸面空结果核对：若接口返回空数组 `[]`，下游设计可按空结果承接，不声称检索规则必然返回空。跨不同向量模型的库不可共同关联，只核标识并排除不符合者。检索不负责授权，相似度分数不作为权限或实体过滤。未载明的授权与生效条款保留为证据缺口。
