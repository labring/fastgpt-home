# 生产企业免抵退税的经营报表与异常复盘：HTTP 接口与外部系统

## 这个品类的数据长什么样
生产企业免抵退把内销抵减与出口退税合并计算，经营报表需要同时呈现免抵退申报明细表、出口合同、销售明细账与出口报关单的口径。月度更新意味着接口取数与人工核对在同一期间内完成，离岸价差异是复盘时最常需要定位的对象。HTTP 模块按外部接口文档选择地址与方法，地址和请求体均可引用已提供的变量；返回值通过 JSON path 提取，出参可格式化为字符串供后续节点使用。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
接口取得的是外部系统按契约返回的字段，不自动等于申报口径。Params、Headers、Body 分别对应路径参数、请求头与请求体，鉴权凭证通过安全配置注入。变量来自全局变量、系统变量与前方节点输出，逐项核对实际传入值。chatId 与 responseChatItemId 在测试模式下不存在，调试时的空值属于已知条件，不当作业务故障。检索或表单收集值不构成授权；业务核验、审批、数据库写入与外部同步需要各自的下游实现。

假设演练样本：某生产企业税务会计在 2026 年 3 月复核 2 月经营报表。出口合同原文载明“合同号 HT-2026-021，出口方为境内某生产企业，货物为自产 A 型配件，成交方式 FOB，金额 120000 美元，签署日期 2026 年 2 月 10 日”。出口报关单原文载明“报关单号 202602280001，出口日期 2026 年 2 月 28 日，成交方式 FOB，总价 118000 美元，境内发货人为该生产企业”。销售明细账原文载明“2026 年 2 月，A 型配件出口收入 120000 美元，折人民币 864000 元”。待判定拟稿句为：“2 月该批货物出口收入为 120000 美元，与报关单一致，免抵退申报明细表可按此金额填列。”合同与明细账为 120000 美元，报关单为 118000 美元，属同一字段的不同取值；该拟稿句的“一致”未获支持，申报明细表填列金额待核实。

## 配置怎么定
| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| 请求地址 | 外部接口文档给出的地址 | 与文档地址逐字符比较 |
| 请求方法 | 文档标注的方法 | 与文档方法比较 |
| Headers | 含 Authorization 的键值 | 与鉴权要求比较 |
| Body | 按文档 JSON 结构 | 与接口契约字段比较 |
| 变量引用 | 引用前方节点输出 | 与实际传入值比较 |
| 返回值提取 | 按 JSON path 提取目标字段 | 与响应结构比较 |

以上均为本次假设试验起点，非官方默认值。

## 容易做错的三处
1. 把合同金额与报关单金额视为同一取值。核对时输入两份原文，比较成交方式与总价字段，出现 120000 与 118000 并存即说明拟稿句的“一致”未获支持。
2. 把测试模式下 chatId 为空当作接口故障。输入测试模式请求，比较响应中 chatId 字段，出现缺失即属已知条件，不构成业务异常。
3. 把表单收集的金额当作已核验的申报数据。输入表单返回值，比较其与报关单原文，两者来源不同，表单值不构成申报依据。

## 怎么确认配好了
1. 输入上述合同原文与报关单原文，比较成交方式与总价字段，两者取值不同时，拟稿句的“一致”判定为未获支持，记录证据缺口。
2. 输入测试模式请求，比较响应中 chatId 与 responseChatItemId 是否存在，缺失时按文档已知条件处理，不记为故障。
3. 输入含 JSON 结构的接口响应，按 JSON path 提取目标字段，比较提取值与响应原文，一致时提取配置成立；响应为空数组时，下游按空输入核对，不推断检索结果。
