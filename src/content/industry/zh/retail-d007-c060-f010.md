# 生鲜水果门店采购的经营报表与异常复盘：引用来源与溯源

## 这个品类的数据长什么样
水果采购依赖批发市场行情和等级验收，与总部标准餐食的订货逻辑不同。采购单、验收单、农残检测报告、损耗记录构成经营报表与异常复盘的主要材料，更新频率为日或每批。这些材料在引用来源与溯源环节的作用，是让报表中的数字和复盘结论能够回到具体单据与检测文件。检测报告与验收单的等级结论若未随附原文，报表中的损耗归因就缺少可核对对象。

## 这些特征在「引用来源与溯源」这一环带来什么约束
知识库搜索节点可以关联一个或多个相同向量模型的知识库，输出为引用内容数组，长度可以为 0。空数组意味着搜索链路走通，输出链路不会因无结果而中断。引用上限以 tokens 为单位控制每次搜索最多引用的内容量，最低相关度是 0-1 的过滤阈值，仅在语义检索或结果重排时生效。混合检索通过 RRF 融合多路召回结果，重排需要模型且按设置启用。这些机制只解决检索与排序，不承担权限判断或业务授权。

假设演练样本：供核对的材料原文为三句。第一句：“2025年6月10日，采购单CG-0610-03向A档口采购红富士苹果80箱，单价按当日市场行情执行。”第二句：“2025年6月10日，验收单YS-0610-03记录该批苹果到货78箱，其中2箱压伤，等级判定为二级。”第三句：“2025年6月10日，农残检测报告JC-0610-03显示该批次检测结果合格，报告有效范围为该批次。”一条待判定的拟稿句：“6月10日红富士苹果采购80箱全部合格入库，无损耗。”该拟稿句与验收单的78箱到货、2箱压伤记录不一致，与检测报告的合格结论范围也不一致。

## 配置怎么定
配置围绕本页样本的核对需求，列出与引用来源与溯源直接相关的设置项或实施核对项。

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 选择存放采购单、验收单、检测报告、损耗记录的知识库 | 核对各库向量模型标识是否相同，不同则排除 |
| 搜索模式 | 混合检索 | 编号类查询与自然语言描述并存，与纯语义检索比较召回覆盖 |
| 引用上限 | 假设起点为 3000 tokens | 容纳多份单据原文，与样本材料总长度比较后调整 |
| 最低相关度 | 假设起点为 0.3 | 与 0.1 和 0.5 比较过滤后剩余候选数量 |
| 结果重排 | 按设置启用 | 比较启用前后候选排序与样本拟稿句所需证据的对应关系 |
| 问题优化 | 按设置启用 | 比较多轮追问场景下检索词是否补全主体与期间 |

上述数值为本次假设试验起点，用于与相邻取值比较观察过滤效果，未记载为官方默认值。

## 容易做错的三处
1. 将引用内容数组长度为 0 判定为工作流报错。搜索节点输出数组长度允许为零，空数组表示未检索到内容，链路仍然走通。错误在于把空结果等同于执行失败。
2. 将最低相关度当作权限或实体过滤。最低相关度是 0-1 的过滤阈值，仅在语义检索或结果重排时生效，不排除无关业务或未授权记录。错误在于用相似度设置替代权限判断。
3. 将拟稿句“80箱全部合格入库，无损耗”当作已核实结论。验收单记录78箱到货、2箱压伤，检测报告合格范围仅限该批次。错误在于把不同字段的取值混为同一事实。

## 怎么确认配好了
1. 输入样本三句材料原文与拟稿句，比较拟稿句中的箱数、损耗描述与验收单原文。若检索输出包含验收单原文且拟稿句箱数与原文不一致，则判定拟稿句未获支持。预期为检索结果能定位到验收单，拟稿句需要修改。
2. 输入“6月10日红富士苹果检测结果”，比较检索输出是否包含检测报告原文及其有效范围描述。若输出包含报告原文且范围表述为“该批次”，则引用来源可追溯。预期为报告原文出现在引用内容中。
3. 输入一个纸面空数组 `[]` 作为检索输出，比较下游回答环节的设计是否承接空数组。若下游设计明确处理空数组且不中断，则空结果承接条件满足。预期为下游设计文档记录空数组处理方式，不声称检索一定返回空数组。
