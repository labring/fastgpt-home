# 生鲜水果门店采购的经营报表与异常复盘：知识库检索与召回

## 这个品类的数据长什么样
水果采购的原始材料围绕批发市场行情、供应商报价、门店销售、检测报告展开，日常文档包括采购单、验收单、农残检测报告、损耗记录。更新频率为日或每批，验收等级与损耗控制占用大量人工时间。经营报表与异常复盘需要把不同批次、不同门店、不同日期的材料放在同一检索范围内核对。材料之间常出现同一字段的不同取值，例如验收单记载的到货数量与采购单记载的订购数量，属于同主体、同期间、同一字段的互斥取值，才构成矛盾；若一份是采购单、另一份是损耗记录，字段不同，只能记录为待核实。

## 这些特征在「知识库检索与召回」这一环带来什么约束
知识库搜索节点可关联一个或多个使用相同向量模型的知识库，跨不同向量模型的库不可共同关联。检索时先核向量模型标识，排除不符合者，记录实际观察，不执行跨模型检索来比较漏召回。搜索模式分为语义检索、全文检索、混合检索，混合检索通过 RRF 融合多路结果，RRF 是融合过程，不是可开启的开关。最低相关度仅在语义检索或使用结果重排时生效，是过滤阈值，不承担权限或实体隔离功能。引用上限以 token 为单位，控制每次搜索最多引用的内容量。问题优化用于指代消除和问题扩展，会额外调用模型。图片检索需要图像输入及模型能力，重排需要具备模型并按设置启用。节点输出引用内容为数组，长度可以为 0，空结果链路仍走通。

假设演练样本：某生鲜门店主管提交一份待判定拟稿句，用于异常复盘报告的结论段。供核对材料原文为三句。第一句来自采购单：「2025年6月3日，门店A向档口B订购水蜜桃200箱，单价按当日行情，验收后结算。」第二句来自验收单：「2025年6月3日，门店A实际验收水蜜桃186箱，其中14箱因压伤降级。」第三句来自损耗记录：「2025年6月4日，门店A水蜜桃损耗6箱，原因记为存储温控异常。」拟稿句为：「门店A于2025年6月3日完成水蜜桃采购200箱，验收无异常，损耗为零。」该拟稿句与验收单、损耗记录在同一字段上取值互斥，判定为未获支持。

## 配置怎么定
下表围绕上述样本，列出与本功能、主任务相关的官方已说明设置或实施核对项。数值为本次假设试验起点，理由是样本材料包含长短差异较大的采购单与检测报告，需要观察引用内容是否完整，比较对象为同一问题在不同起点下的返回内容。

| 配置项 | 本次假设试验起点 | 核对方式 |
| --- | --- | --- |
| 关联的知识库 | 仅关联使用相同向量模型的采购、验收、损耗三个库 | 核向量模型标识，排除不同模型库 |
| 搜索模式 | 先以语义检索与全文检索分别试跑，再比较混合检索 | 用同一问题观察三路返回差异 |
| 引用上限 | 起点设为能覆盖一份验收单全文的 token 量 | 与采购单全文所需 token 量比较 |
| 最低相关度 | 先标注样本中相关与无关片段，再设起点 | 观察过滤后是否保留验收单关键句 |
| 问题优化 | 对含指代的追问开启，对明确编号问题关闭 | 比较原问题与优化后问题的主体是否被改错 |
| 结果重排 | 在候选较多时启用，按重排得分过滤 | 观察重排得分与语义得分排序差异 |

## 容易做错的三处
1. 把检索结果当作授权凭据。输入为一条检索命中的采购单，比较对象为审批状态字段，若该字段未载明，观察结果只能是未获支持，不能推断采购已获批准。
2. 把最低相关度当作权限或实体隔离手段。输入为一个跨门店问题，比较对象为返回内容中的门店标识，若返回了其他门店材料，观察结果是该设置不承担隔离功能，需要另行实现访问控制。
3. 把待审核请求当作已执行。输入为一份标注待审核的交接请求，比较对象为签署、合作达成、合同生效三个不同事实，若仅有待审核标记，观察结果是授权状态未完成，不能得出已执行结论。

## 怎么确认配好了
- 验证一：输入上述三句材料原文与拟稿句，比较拟稿句中的数量、验收状态、损耗数量与原文同字段取值，观察结果应为拟稿句与验收单、损耗记录在同一字段上取值互斥，判定为未获支持。
- 验证二：输入一条含指代的追问，比较问题优化前后的主体是否一致，观察结果应为优化后主体未被改错，若主体被替换则记录为问题优化引入偏差。
- 验证三：输入一个纸面空结果数组，比较下游节点是否仍走通，观察结果应为引用内容长度为 0 时链路继续执行；该核对不声称某条虚构规则检索一定返回空数组。以上均为纸面核对，未实际部署或测试。
