# 直播售后集中处理的经营报表与异常复盘：HTTP 接口与外部系统

## 这个品类的数据长什么样
直播售后集中在单场流量后爆发，退款申请与补发单在短时间内堆叠，和主播承诺强相关。经营报表与异常复盘依赖直播订单清单、退款申请、补发单、话术模板四类文档，数据来源涉及抖店售后、客服IM、仓库WMS、物流轨迹。每场后与每日的更新节奏意味着报表核对必须按场次或按日锁定范围，HTTP 接口在这一环承担把外部系统数据取回编排、再交给报表与复盘流程的作用。数据来源分散在多个系统，接口调用只能取回被授权访问的那部分记录，取回结果本身不构成业务授权。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
HTTP 模块向对应地址发送请求，Params、Body、Headers 三处均可用 `{{}}` 引用变量，URL 也可引用变量。变量来自全局变量、系统变量、前方节点输出。系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories；histories 默认最多取 10 条且无法修改长度。chatId 与 responseChatItemId 在测试模式下不存在，调试时取到空值属于测试模式特征，不能当作业务故障。返回值通过 JSON path 提取，输出类型选字符串时会把对应 key 的值转成 json 字符串。HTTP 模块可重复添加、手动配置、触发执行。

假设演练样本：某直播间在 3 月 8 日场次后集中收到退款申请，售后主管在 3 月 9 日整理材料，原文为「3 月 8 日 20:00 至 24:00 场次退款申请共 46 笔，其中 12 笔已由客服登记补发单，补发单状态为待仓库确认；仓库 WMS 尚未回传出库结果。」拟判定句为「该场次 12 笔补发已由仓库完成出库。」待判定的交接请求为「请把该场次退款与补发数据同步给报表流程。」该请求处于待确认状态，不构成已授权执行。

## 配置怎么定
下表围绕上述样本，列出与本功能、经营报表与异常复盘主任务相关的官方已说明设置或实施核对项。需要数值处为本次假设试验起点，并说明选取理由与比较对象。

| 配置项 | 本次假设试验起点 | 选取理由与比较对象 |
| --- | --- | --- |
| 请求地址 BaseUrl | 外部接口文档给出的地址，可含 `{{}}` 变量 | 与外部接口契约中的地址逐字符比较 |
| 请求方法 | 按外部接口文档选择 GET 或 POST 等 | 与文档声明的方法比较，方法不符即记录差异 |
| Params | 按外部接口文档逐项填写，值可引用变量 | 与实际传入值比较，缺项即记录缺口 |
| Headers | Authorization 等按安全配置注入 | 与安全配置中的凭证来源比较，不写入公开样例 |
| Body | 仅在相应请求类型下使用，核对 JSON 结构 | 与外部接口契约的字段结构比较 |
| 返回值提取 | 按 JSON path 配置 key，输出类型选字符串或对应类型 | 与接口响应示例逐路径比较，路径不存在即记录未知 |

## 容易做错的三处
1. 把测试模式下 chatId 或 responseChatItemId 为空当作业务故障。输入为测试模式请求，比较对象为文档说明的「测试模式下不存在」，可观察结果是测试模式请求中这两个字段为空而正式请求中由调用方传入。
2. 把接口返回的退款或补发记录直接当作已授权执行。输入为上述样本中的 12 笔补发单，比较对象为补发单状态「待仓库确认」与仓库 WMS 未回传出库结果，可观察结果是拟判定句所述「已完成出库」未获支持。
3. 把 JSON path 提取到的值当作业务字段含义已确认。输入为提取出的某个 key 值，比较对象为外部接口契约对该字段的定义，可观察结果是字段名相同但含义未经契约确认时只能记录待核实。

## 怎么确认配好了
1. 针对假设演练样本原文，输入为「3 月 8 日 20:00 至 24:00 场次退款申请共 46 笔，其中 12 笔已由客服登记补发单，补发单状态为待仓库确认；仓库 WMS 尚未回传出库结果。」比较对象为拟判定句「该场次 12 笔补发已由仓库完成出库。」可观察结果是补发单状态与仓库回传状态均未显示完成出库，判定句未获支持，证据缺口保留为仓库出库结果未知。
2. 针对待判定的交接请求，输入为「请把该场次退款与补发数据同步给报表流程。」比较对象为该请求的授权状态，可观察结果是该请求处于待确认状态，不构成已授权执行，同步动作是否发生属于未知。
3. 针对 HTTP 模块配置，输入为按外部接口文档填写的地址、方法、Params、Headers、Body 与返回值提取，比较对象为外部接口契约与文档说明的变量来源，可观察结果是路径存在时提取到对应值，路径不存在或字段含义未经契约确认时记录为未知，不推断接口返回值的业务含义。
