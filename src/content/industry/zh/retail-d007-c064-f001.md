# 直播选品与样品质检的经营报表与异常复盘：HTTP 接口与外部系统

## 这个品类的数据长什么样

选品质检发生在开播前，判断对象是商品能否上播、是否适合直播展示。主要材料包括样品评估表、质检报告、供应商资质和禁售清单，来源覆盖供应商资料、检测机构报告、平台负面目录与历史退货率。典型角色为选品经理、供应链BD与质检专员，数据按周、按品更新。

这些材料进入经营报表与异常复盘时，需要与外部系统通过 HTTP 接口交换。接口返回的字段、状态和标识构成复盘证据的一部分，报表口径与接口取值必须能一一对应。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向指定地址发送请求，实际操作与 Postman、ApiFox 类似。Params 为路径请求参数，GET 请求中居多；Body 为请求体，POST/PUT 请求中居多；Headers 为请求头。三类数据均可用 `{{}}` 引用变量，URL 同样可以引用变量。变量来自全局变量、系统变量与前方节点输出。

系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories。文档说明 chatId 与 responseChatItemId 在测试模式下不存在，调试时取不到值属于环境差异，不构成业务故障。返回值通过 JSON path 语法提取，输出类型选择字符串时会把对应 key 的值转成 json 字符串。

对话接口使用 APIKey 鉴权，调用 chat/completions 时推荐在请求体传入 body.appId，也支持 `Authorization: Bearer <apiKey>-<appId>`。appId 优先级为 body.appId、`<apiKey>-<appId>`、apikey 关联的 appId。传入的 model、temperature 等字段无效，由编排决定。detail=true 时中间值保存在 responseData 中，需要 Token 值可手动计算 tokens 字段。

假设演练样本：一份样品评估表原文写明「供应商甲，样品编号 S-001，送检日期 2025 年 3 月 3 日，检测机构报告编号 R-2025-0303，结论为符合上播要求」。一条待判定的交接请求拟稿句为「R-2025-0303 已确认，S-001 可上播」。该拟稿句把报告编号与上播结论直接绑定，但原文未载明报告有效期与授权签署状态，属于未获支持，需保留证据缺口。

## 配置怎么定

| 配置项 | 取值或核对内容 | 依据与说明 |
| --- | --- | --- |
| 请求地址与方法 | 按外部接口文档选择，地址可引用变量 | HTTP 模块文档说明 URL 可通过 `{{}}` 引用变量 |
| Params 与 Headers | 分别核对路径参数与请求头，鉴权凭证安全注入 | 文档说明两者用法与 Postman 基本一致 |
| Body | 仅在相应请求类型下使用，核对 JSON 结构与契约 | 文档说明只有特定请求类型下生效 |
| 变量引用 | 逐项核对全局变量、系统变量、前方节点输出 | 文档列出三类变量来源 |
| 返回值提取 | 按 JSON path 语法配置 key，选择输出类型 | 文档说明输出类型为字符串时转 json 字符串 |
| 调试身份字段 | chatId、responseChatItemId 测试模式下不存在 | 文档明确该差异，不当作业务故障 |

本次假设试验起点：将返回值 key 设为 data.reportStatus，输出类型选字符串，用于与样品评估表中的报告结论字段比对。选择该起点是因为接口响应结构需要先确认字段路径，再与纸质材料字段对齐。

## 容易做错的三处

1. 把测试模式下不存在的 chatId、responseChatItemId 当成接口异常上报。输入为测试模式请求，比较对象是文档对这两个字段的说明，观察结果是测试模式下取不到值，属于环境差异。
2. 把拟稿句中的报告编号与上播结论当成已生效授权。输入为上述拟稿句，比较对象是样品评估表原文，观察结果是原文未载明有效期与签署状态，属于未获支持。
3. 把接口返回的相似度分值当作权限或实体过滤依据。输入为带 score 字段的响应，比较对象是权限配置，观察结果是相似度不承担权限判断，需另接系统实现。

## 怎么确认配好了

1. 用上述样品评估表原文与拟稿句核对：输入为原文两句与拟稿句，比较对象是「报告编号」与「上播结论」是否同主体、同期间、同字段，满足条件时拟稿句可保留，否则标记为待核实。
2. 用测试模式请求核对调试身份字段：输入为不含 chatId 的测试请求，比较对象是文档说明，观察结果是该字段在测试模式下不存在，接口其余返回正常即通过。
3. 用返回值提取配置核对字段路径：输入为接口响应与配置的 key，比较对象是 JSON path 语法，观察结果是提取值与响应中对应字段一致即通过；若路径不符，记录实际观察，不推断具体报错原因。
