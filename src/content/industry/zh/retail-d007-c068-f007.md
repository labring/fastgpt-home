# 社区团购预售集单的经营报表与异常复盘：对话日志与审计

## 这个品类的数据长什么样

预售集单先收订单再组织采购履约，不是团长关系维护。主要数据来源包括小程序订单、供应商库存、团长反馈与仓配排线，日常文档为预售商品表、集单结果、采购计划与截单通知。对话日志与审计在这个品类中承担经营报表与异常复盘的核对入口：截单后的下采数量、分拣波次安排与缺货退款争议，需要回到具体会话与运行记录中定位。数据更新频率为日或每场，这一频率只说明资料给出的更新节奏，不推出批量同步、全量同步、实时或交易触发机制。

## 这些特征在「对话日志与审计」这一环带来什么约束

对话接口以 `chatId` 标识一个应用下的会话，`dataId` 标识会话下的对话。`chatId` 为非空字符串时，系统自动从数据库取会话，并使用 `messages` 数组最后一个内容作为用户问题，其余 message 被忽略；请自行确保 `chatId` 唯一，长度小于 250。不传入 `chatId` 时不使用上下文功能，完全通过传入的 `messages` 构建上下文。`responseChatItemId` 传入后作为本次响应消息的 ID 存入数据库，在当前 `chatId` 下需唯一。需要运行详情时按官方契约设置 `detail=true`，中间值保存在 `responseData`，流模式下通过 `event` 区分。传入的 `model`、`temperature` 等参数字段无效，由编排决定。不会返回实际消耗 Token 值，可设置 `detail=true` 并手动计算 `responseData` 里的 `tokens` 值。日志存在不等于完成合规审计，对账、留存与合规要求由完整业务方案另行落实。

假设演练样本：材料原文为“截单通知：2026年3月10日22时截单，预售商品表A类叶菜计划集单800份；集单结果记录实际成团760份；采购计划按760份下采。”待判定拟稿句为“本场已按800份完成下采，缺货退款由供应商承担。”核对主体为同一场次、同一商品A类叶菜、同一字段下采数量，日期范围为2026年3月10日截单场次。授权边界为运营交接材料核对，不涉及审批执行。

## 配置怎么定

下表围绕上述样本，列出与本功能、主任务相关的官方已说明设置或实施核对项。假设试验起点仅用于本次纸面核对，不作为官方默认值。

| 项目 | 设置或核对内容 | 与样本的关系 |
| --- | --- | --- |
| `appId` | 请求体传入或由密钥关联 | 确定本次会话所属应用 |
| `chatId` | 非空字符串，长度小于 250，确保唯一 | 锁定2026年3月10日截单场次会话 |
| `responseChatItemId` | 当前 `chatId` 下唯一 | 标记该场次响应消息 |
| `detail` | 设为 `true` 以获取中间值 | 取得 `responseData` 供核对 |
| `dataId` | 会话下某一对话的 ID | 定位待判定的下采记录 |
| `source` | 会话列表查询中 `source=api` | 区分 API 创建的会话 |

## 容易做错的三处

1. 把不同入口的会话混算。错误表现为用页面会话的 `chatId` 去核对 API 创建的集单结果。检查：输入两个不同来源的 `chatId`，比较其 `appId` 与 `source`，观察是否指向同一应用与同一来源；不同来源的会话不合并计算。
2. 把日志存在当作合规审计完成。错误表现为仅凭 `dataId` 存在就认定对账与留存已落实。检查：输入样本中的截单通知与集单结果，比较下采数量字段是否一致，观察是否存在未返回的业务数据；未返回字段不能推定已完整留存。
3. 把检索或表单当作授权执行。错误表现为收到交互节点配置即认为用户选择已生效。检查：输入 `event=interactive` 的 `data.interactive`，比较其 `type` 与 `params`，观察是否仅返回展示配置；`entryNodeIds`、`memoryEdges`、`nodeOutputs`、`nodeResponseId` 等内部运行态字段不会返回，待审核不证明缺少操作权限。

## 怎么确认配好了

1. 针对样本拟稿句“本场已按800份完成下采”，输入材料原文中的集单结果760份与采购计划760份，比较同一场次、同一商品、同一字段的下采数量，观察两处均为760份时该拟稿句未获支持；800份与760份在同一字段上互斥，构成矛盾。
2. 针对样本截单通知的日期范围，输入 `chatId` 与 `dataId`，比较会话列表返回的 `updateTime` 与截单日期，观察是否落在2026年3月10日场次；日期不符时记录为待核实，不判定为否定。
3. 针对授权边界，输入运营交接材料与待判定请求，比较请求所指操作是否处于已批准状态，观察是否存在签署、审批或生效记录；报价有效期不表示供货期限，签署、合作达成、合同生效是三个不同事实，缺失时保留证据缺口。
