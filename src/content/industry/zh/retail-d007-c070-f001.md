# 跨境商品合规与标签的经营报表与异常复盘：HTTP 接口与外部系统

## 这个品类的数据长什么样

跨境商品合规与标签的核心证据产生在上架与进口之前，围绕产品安全与标签材料展开。日常材料包括产品测试报告、英文标签、MSDS 与平台禁售清单，来源涉及平台政策中心、检测机构报告、目的国法规库和供应商资料。资料更新不定期，每次上新都可能带来新的判断需求。

经营报表与异常复盘要回答的问题，是某次合规材料交接与接口调用处于什么状态。材料本身是证据，接口请求是动作，两者不能互相替代。检测报告存在，不代表标签已改；接口返回成功，不代表业务侧已完成核验。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向对应地址发送请求，实际操作与 Postman、ApiFox 这类工具接近。Params 为路径请求参数，GET 请求中居多；Body 为请求体，POST/PUT 请求中居多；Headers 为请求头，用于传递特殊信息。三类数据均可通过 `{{}}` 引用变量，URL 也可引用变量。变量来自全局变量、系统变量与前方节点输出。

系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories。其中 chatId 与 responseChatItemId 在测试模式下不存在。节点返回值配置用于指定响应解析方式，通过 JSON path 提取，输出类型选择字符串时会将对应 key 的值转成 json 字符串。自动格式化输出自 v4.6.8 后加入。

对话接口使用 APIKey 鉴权，调用 chat/completions 时推荐在请求体传入 body.appId；也支持 `Authorization: Bearer <apiKey>-<appId>`。传入的 model、temperature 等参数无效，由编排决定。detail=true 时返回中间值，stream 模式下通过 event 区分。检索结果中的 score 是相似度，不承担权限或实体隔离功能。

假设演练样本：某跨境卖家合规专员在 2025 年 3 月 10 日整理一批上新材料的交接记录，材料原文为三句：“产品测试报告编号 TR-2025-0310，出具日期 2025 年 3 月 8 日，结论为符合目的国安全要求。英文标签版本 V2，修改日期 2025 年 3 月 9 日，尚未提交平台审核。MSDS 文件已由供应商提供，未标注版本号。”拟交接请求为：“请通过 HTTP 接口将上述材料状态同步至外部合规台账，并标记为已完成审核。”标签未提交、MSDS版本缺失；拟同步的“已完成审核”与标签状态不符，不能据此记为审核完成。

## 配置怎么定

| 核对项 | 假设起点或实施核对 | 比较对象与理由 |
| --- | --- | --- |
| 请求地址与方法 | 按外部接口文档选择，地址可引用变量 | 与外部接口契约比较，确认方法匹配 |
| Params 与 Headers | 分别核对路径参数与请求头 | 与接口文档逐项比较，鉴权凭证经安全配置注入 |
| Body 结构 | 仅在相应请求类型下使用请求体 | 与外部接口契约比较 JSON 结构 |
| 变量引用 | 引用全局变量、系统变量、前方节点输出 | 与样本实际值比较，逐项核对传入内容 |
| 调试身份字段 | chatId 与 responseChatItemId 测试模式下不存在 | 与运行模式比较，不把调试空值当业务故障 |
| 返回值提取 | 配置 key 按 JS 对象取值规则解析 | 与接口响应结构比较，确认提取路径 |

假设起点仅用于本次纸面核对，不构成官方默认值。

## 容易做错的三处

1. 把材料存在当成状态完成。样本中英文标签版本 V2 尚未提交平台审核，若接口请求把该标签标记为已完成审核，输入是标签状态字段，比较对象是材料原文的“尚未提交”，可观察结果是两者不一致。
2. 把传输成功当成核验完成。即使接口响应成功，也需另核MSDS版本号缺口；本样本未给接口响应，不能写成已观测到同步成功。
3. 把解析配置当成已取到值。输入为返回值key，比较对象须是外部接口的实际响应结构；本样本未给响应，提取结果待核，不能把配置存在写成字段已同步。

## 怎么确认配好了

1. 针对样本拟稿句“请通过 HTTP 接口将上述材料状态同步至外部合规台账，并标记为已完成审核”，输入为标签状态字段与材料原文“尚未提交平台审核”，比较两者是否一致，满足条件为识别出该请求把未提交写成已完成审核，属于待核实。
2. 针对样本中 MSDS 未标注版本号，输入为材料原文与拟同步字段清单，比较版本号字段是否有值，满足条件为记录版本号缺失，不推断供应商已提供完整版本。
3. 先取得拟接接口的契约和脱敏响应样本，再逐项列出报告编号、标签状态、MSDS版本的响应路径，比较key提取值与原文。本页缺响应证据，暂记未验证；另用纸面[]核空结果分支设计，不声称实际接口已返回空。

以上均为纸面核对，未实际调用接口，未产生业务动作。
