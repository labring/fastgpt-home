# 跨境商品合规与标签的经营报表与异常复盘：工作流编排

## 这个品类的数据长什么样

在跨境商品合规与标签的经营报表与异常复盘中，本页说明FastGPT的工作流编排如何衔接资料。跨境标签资料报告要说明每份文件究竟覆盖哪个版本，不把资料汇集写成合规已经确认。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟报告把新英文标签、旧包装检测和无变体说明的安全资料列为齐备，却没有版本对应。流程可收各文件所指对象，人员选择补标签关系或补适用说明，再把未覆盖项传给报告起草。文件名称齐全只支持收集状态，不能证明商品符合要求；本题不解释法规或禁售判据，也不把另一商品资料用于弥补本件缺项。

## 配置怎么定

| 跨境资料报告 | 自拟收集状态 | 范围核对 |
| --- | --- | --- |
| 新英文标签 | 版本关系缺 | 补与报告对应 |
| 旧包装检测 | 非自动支持新版 | 查实际所指 |
| 安全资料 | 变体范围未写 | 不能合并全部 |
| 文件齐名 | 仅支持收集 | 非合规通过 |
| 报告更新 | 按新增证据范围 | 其他版本仍待核 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

齐备冒符合：若材料已收被写成合规通过，应取真实适用审查依据；旧样扩新版：若旧包装结论用于新标签，应核版本关系原句；变体被合并：若无说明的安全资料被写成全部覆盖，应核实际对象与接收文本。三项分别核状态、版本和覆盖，不能由报告表格整齐消除。

## 怎么确认配好了

验收看两个选项分别传来什么对象及缺项，补某变体说明后只更新该范围，未覆盖版本仍列待核。若只新增文件标题，不能写成已审阅内容。实际标签改版、采购放行和上架发布需另接业务流程核权限及回执，报告输出不构成监管认定，也不从节点完成证明商品已经允许销售。

| 候选来源 | 平台政策中心、检测机构报告、目的国法规库、供应商资料 |
