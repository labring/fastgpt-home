# 跨境平台结算与汇兑的经营报表与异常复盘：HTTP 接口与外部系统

## 这个品类的数据长什么样
跨境平台结算与汇兑围绕已成交订单的资金归集展开，处理平台结算单、银行流水、支付机构后台与 ERP 订单之间的对应关系。数据按周或按月更新，日常文档包括平台结算单、汇率表、服务费发票和收款对账表。经营报表与异常复盘需要把这几类材料的同一主体、同一期间、同一字段放在一起比对，HTTP 接口与外部系统承担取数与回写通道，不承担欺诈拒付判断。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束
HTTP 模块向对应地址发送请求，Params 用于路径参数，Body 用于请求体，Headers 用于请求头，三者均可通过 `{{}}` 引用全局变量、系统变量和前方节点输出，URL 同样可以引用变量。返回值通过 JSON path 提取，输出类型选择字符串时会将对应 key 的值转成 json 字符串。系统变量中 chatId 与 responseChatItemId 在测试模式下不存在，调试空值属于环境差异。对话接口的 chatId 为非空字符串时会从数据库取会话，messages 数组最后一个内容作为用户问题；detail=true 时非 stream 模式结果保存在 responseData 中。鉴权使用 APIKey，appId 优先级为 body.appId、`<apiKey>-<appId>`、apikey 关联的 appId。检索与相似度不构成授权，表单只收集值，业务核验、审批、数据库写入与外部同步需要各自的下游实现。

假设演练样本：某跨境卖家财务在 2025 年 3 月月度复盘时，持有一份平台结算单，载明结算期间 2025 年 3 月 1 日至 3 月 31 日、结算主体为店铺 A、币种为美元、平台服务费合计 1200.00 美元；另持有一份收款对账表，载明同一店铺 A、同一期间、到账金额 8800.00 美元。待判定拟稿句为“本期平台服务费已核对无误，可结转利润核算”。该句未写明汇率表版本与服务费发票号码，材料中也没有授权签署或审批记录，因此该拟稿句处于待核实状态。

## 配置怎么定
| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 请求地址 | 外部结算系统提供的结算单查询地址 | 地址来自外部接口文档，本次起点按文档填写，与文档声明的路径逐字符比较 |
| 请求方法 | POST | 按外部接口文档声明的方法填写，与文档声明的方法比较 |
| Headers 鉴权 | Authorization 引用已配置的 token 变量 | 凭证通过安全配置注入，与变量实际传入值比较，不写入公开样例 |
| Body 结构 | 含结算期间与店铺标识字段的 JSON | 按外部接口契约核对字段名与类型，与对方文档逐项比较 |
| 返回值提取 | 对服务费合计配置 key，输出类型为字符串 | 按 JSON path 提取，与结算单原文数值比较 |
| 变量引用范围 | 全局变量、系统变量、前方节点输出 | 逐项核对实际传入值，与节点输出记录比较 |

以上数值与结构为本次假设试验起点，不是官方默认值，也未实际执行。

## 容易做错的三处
1. 把 chatId 或 responseChatItemId 在测试模式下的空值当成业务故障。检查方式：输入测试模式请求，比较返回中这两个字段是否存在，观察空值与文档说明是否一致。
2. 把相似度或检索结果当成授权或实体隔离依据。检查方式：输入含店铺 A 的查询，比较返回记录的主体标识，观察是否出现店铺 A 以外的记录。
3. 把表单收集到的值当成业务已核验或已审批。检查方式：输入假设样本中的拟稿句，比较材料中是否存在审批或签署记录，观察该句是否仍处于待核实状态。

## 怎么确认配好了
1. 输入假设样本中的结算单原文与拟稿句，比较拟稿句是否写明了汇率表版本与服务费发票号码，观察材料中缺失的字段是否仍标记为未知。
2. 输入假设样本中的收款对账表，比较到账金额与结算单服务费是否属于同一主体、同一期间、同一字段，观察两者是否可直接相减，若字段口径不同则记录为待核实。
3. 输入一条含空结果 `[]` 的纸面响应，比较下游节点是否按空数组处理，观察是否出现对空结果的确定性业务结论；检索是否命中、无关查询是否为空均以实际观察为准，不作保证。
