# 逆向退货入仓质检的经营报表与异常复盘：HTTP 接口与外部系统

## 这个品类的数据长什么样

逆向退货入仓质检处理的是退回包裹与商品等级，数据来源包括 WMS 退货模块、平台售后、承运商退件和质检台。与仓内拣货打包相比，这一环节不处理新订单出库，而是围绕退货入库单、质检照片、等级判定表和重售上架单逐件记录。数据更新频率为每件、日。经营报表与异常复盘要回答的问题，是某一批退件在质检判定、重售或报废决策上的分布与偏差，以及这些记录能否通过 HTTP 接口与外部系统稳定对接。

## 这些特征在「HTTP 接口与外部系统」这一环带来什么约束

HTTP 模块向对应地址发送请求，Params 用于路径参数，Body 用于 POST/PUT 请求体，Headers 用于传递特殊信息。URL、Params、Body、Headers 均可用 `{{}}` 引用全局变量、系统变量或前方节点输出。系统变量包括 appId、chatId、responseChatItemId、variables、cTime、histories，其中 chatId 与 responseChatItemId 在测试模式下不存在。返回值通过 JSON path 或 JS 对象取值规则解析，输出类型选字符串时会把对应 key 的值转成 json 字符串。HTTP 模块可操作数据库、调用外部数据源、执行联网搜索、发送邮箱，这些属于需另接系统实现的业务动作，模块本身不完成授权、审批或数据库写入。

假设演练样本：某售后仓 2025 年 3 月 12 日的退货入库单 RB-20250312-017，对象为一件退回商品，质检照片显示外包装破损、商品本体无明显损伤，等级判定表记录为“待复核”，重售上架单尚未生成。待判定的拟稿句为：“该退件已完成质检并可直接重售。”核对材料原文为：“等级判定表状态：待复核；重售上架单：未生成。”此样本中主体为售后仓质检员，对象为该退件，状态为待复核，有效范围限于该单当日记录。

## 配置怎么定

| 配置项 | 本页假设起点 | 核对方式 |
| --- | --- | --- |
| URL | 引用外部接口文档给出的地址 | 确认地址与外部接口契约一致 |
| Params | 按外部接口文档填写路径参数 | 逐项对照接口文档核对 |
| Headers | Authorization 使用 Bearer 加凭证 | 凭证通过安全配置注入，不写入样例 |
| Body | 仅在 POST/PUT 下使用，核对 JSON 结构 | 对照外部接口契约逐字段核对 |
| 变量引用 | 引用全局变量或前方节点输出 | 核对实际传入值是否与材料一致 |
| 调试身份字段 | chatId 与 responseChatItemId 在测试模式下不存在 | 不把调试空值当成业务故障 |

本次假设试验起点选“待复核”作为等级判定表状态，原因是材料原文明确记录该状态，比较对象为重售上架单是否生成。该起点为本次假设值，不是官方默认值。

## 容易做错的三处

1. 把“待复核”当成已完成质检。等级判定表状态为待复核，重售上架单未生成，拟稿句“已完成质检并可直接重售”与材料原文不一致。检查：输入材料原文与拟稿句，比较状态字段与上架单字段，观察拟稿句是否与原文冲突。
2. 把测试模式下 chatId 不存在当成接口故障。文档说明 chatId 与 responseChatItemId 在测试模式下不存在。检查：输入测试模式请求，比较请求中是否传入 chatId，观察是否把空值误判为业务异常。
3. 把 HTTP 模块调用外部数据源当成已完成数据库写入或授权。文档说明模块可操作数据库、调用外部数据源，但授权、审批与写入属于需另接系统实现的业务动作。检查：输入一条调用外部接口的请求，比较返回值与业务状态字段，观察是否把接口返回当成授权或写入完成。

## 怎么确认配好了

1. 针对假设样本 RB-20250312-017，输入材料原文“等级判定表状态：待复核；重售上架单：未生成”与拟稿句“该退件已完成质检并可直接重售”，比较状态字段与上架单字段，若拟稿句与原文冲突则判定为未获支持。预期为冲突，不声称已实测。
2. 针对同一假设样本，输入一条测试模式请求，比较请求中 chatId 与 responseChatItemId 是否存在，若不存在则记录为测试模式正常现象，不判定为业务故障。预期为不存在，不声称已实测。
3. 针对同一假设样本，输入一条调用外部接口的请求，比较接口返回值与业务状态字段，若返回值仅表示接口响应而未携带授权或写入完成标识，则记录为待核实，不判定为授权或写入完成。预期为待核实，不声称已实测。
