# B2B平台撮合交易的跨境资料与多语检索：向量模型与索引

## 这个品类的数据长什么样

在B2B平台撮合交易的跨境资料与多语检索中，本页说明FastGPT的向量模型与索引如何衔接资料。核对资料实际支持的范围及其引用。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

B2B多语索引可用另拟的双语询报价文字：中文写“仅提供未安装组件，安装需另行约定”，英文作同样范围的测试表述。可核对“是否包含安装”和英文安装问题两个搜索入口，看它们是否都能回到原文的排除条件。同一原数据增加不同语言索引，不表示译文已经获得业务认可；这里只比较已提供测试文字的对应关系。

## 配置怎么定

| 核对项（含实施核对） | 具体原数据或索引 | 验收线索 |
| --- | --- | --- |
| 向量模型 | 多语言资料共同关联检索 | 核实际模型一致，不从名称推断。 |
| 原文映射 | 仅提供未安装组件 | 两个语言入口均需回指限制。 |
| 索引内容 | 是否包含安装及对应英文问法 | 不得新增装配和安装服务。 |
| 同题复测 | 中英文问同一安装范围 | 比较两边引用的原句。 |
| 扫描资料 | 缺失版本若以后提供扫描件 | 先核实际文字或图片入库路径；图片检索再核描述或图片向量。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 英文索引新增assembled或with installation时，与未安装组件和安装另议的原句逐项对照，不能用索引新增文字改写报价范围。

- 两个语言索引都命中但引用丢了排除条件时，对照两语实际引用与目标原数据，不以命中两次代替范围核验。

- 仅有测试译文与拟议索引，回答却称正式英文条款已获确认时，核原文身份及确认依据；新增语言索引不是业务认可。

## 怎么确认配好了

任务所需的经业务确认对照尚未提供时，索引不能冒充该正式版本。补充后先核原文、语种、索引与引用的对应，同一检索节点关联的多个知识库需使用相同向量模型。若补充文件是扫描件，先核实际采用的文字或图片入库路径，并与原件对照；采用图片检索路径时才进一步检查描述或图片向量。验收再用两种语言追问同一安装范围，查看引用是否保留仅提供未安装组件和安装另议的限制，不能仅凭两种问法都命中就认为范围一致。
