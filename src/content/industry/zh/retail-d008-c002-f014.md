# MCN机构达人管理的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样
MCN机构管理多个达人的长期账号合规，日常文档包括达人签约合同、培训记录、违规处理单和账号排期。跨境资料与多语检索场景下，同一批材料可能来自不同平台与语言环境，检索结果需要回到具体文档核对。资料更新频率为日、周，本页功能不依赖批量同步或实时触发。模型接入与配置决定检索请求能否发出、返回哪些文本块，不决定记录是否可被某位运营人员查看。

## 这些特征在「模型接入与配置」这一环带来什么约束
从 V4.17.0 起，AI Proxy 为必需依赖，缺少 `AIPROXY_API_ENDPOINT` 或非空 `AIPROXY_API_TOKEN` 会导致启动校验失败。系统至少需要一个语言模型和一个索引模型才能正常使用。模型 ID 为请求 Body 中 `model` 字段的值，全局唯一；模型映射可将 FastGPT 请求的模型映射到上游实际模型。系统内置模型可直接启用，自定义模型通过表单或配置文件添加。模型能力按应用所需输入分别核对，多模态、工具调用与思考配置不能相互替代。检索库的同向量模型要求只用于向量关联，不能扩展为工商网站或其他外部系统也需同模型。

假设演练样本：材料原文为“达人A的签约合同第3页写明2026年1月1日至2026年12月31日有效，培训记录第2页记录2026年3月完成合规培训，违规处理单第1页记载2026年5月一次警告。”待判定拟稿句为“达人A的合同在2026年全年有效，可安排跨境直播排期。”核对对象为合同页、培训记录页与违规处理单页。

## 配置怎么定
以下为本次假设试验起点及核对项，非官方默认值。

| 配置项 | 本次假设起点 | 核对方式 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 假设填写 `http://aiproxy:3000` | 确认未附加 `/v1` 或 `/chat/completions` |
| `AIPROXY_API_TOKEN` | 假设使用非空管理员 Token | 与服务端配置比对，确认非空且一致 |
| 语言模型 | 假设启用一个已测试渠道 | 在模型测试页发起请求，观察返回 |
| 索引模型 | 假设启用一个已测试渠道 | 确认与语言模型分别可用 |
| 模型映射 | 假设将请求模型映射到上游模型 | 比对请求 Body 的 `model` 与上游实际 `model` |
| 检索库标识 | 假设记录向量模型标识 | 比对库标识，排除不一致者 |

## 容易做错的三处
1. 将 `AIPROXY_API_ENDPOINT` 填为完整模型请求地址并附加 `/v1`，启动校验或调用会失败。检查输入是否只含服务根地址，比较文档说明，观察是否通过校验。
2. 将应用 API Key 当作 `AIPROXY_API_TOKEN` 填入。检查输入是否为管理员 Token，与服务端配置比对，观察是否非空且一致。
3. 用相似度分数推断某条记录已获授权。检查输入是否为检索请求，比较返回文本块与材料原文，观察是否仍需回到合同页核对授权边界。

## 怎么确认配好了
1. 输入假设样本材料原文与拟稿句，比较拟稿句“2026年全年有效”与合同页“2026年1月1日至2026年12月31日”，观察拟稿句是否与原文范围一致；若不一致，记录该差异，不据此执行排期。
2. 输入一条仅涉及达人A的检索请求，比较返回文本块是否来自达人A的合同页、培训记录页或违规处理单页，观察是否出现其他达人材料；若出现，记录并排除。
3. 输入空结果承接的纸面输入 `[]`，比较下游设计是否按空结果处理，观察是否触发未定义动作；该核对不声称虚构规则检索一定返回 `[]`。
