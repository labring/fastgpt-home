# TikTok Shop美国店运营的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样
TikTok Shop美国店运营的资料以商品Listing、退货退款记录、Return Grading证据和结算账单为主，来源为Seller Center、订单中心、承运商轨迹和广告报表，更新频率为日与每单。美国本地退货窗口、return grading与海外物流约束使同一退货事件在订单记录、图片证据和结算扣费中呈现不同字段。多语检索要在这些材料中定位同一主体的同一字段，模型接入配置决定检索能否覆盖英文与中文混排文本。

## 这些特征在「模型接入与配置」这一环带来什么约束
FastGPT v4.17.2 中，App 与复用 App/Service 配置的 Admin 必须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺少任一项启动校验失败；旧 OpenAI 环境变量或单模型自定义请求地址不能替代。模型渠道配置中的代理地址填写 BaseUrl，不填完整请求地址。系统至少需要一个语言模型和一个索引模型。全文检索在 Milvus 时走 BM25 单表，其他向量库走 MongoDB $text。检索结果的相关度不承担权限或实体隔离，跨不同向量模型的库不可共同关联。模型探测仅针对已启用系统模型，未启用模型不参与探测。

## 配置怎么定
假设演练样本：某运营交接材料含三句原文——“订单 A-771 于 2026-03-02 提交退货申请，状态为待审核。”“Return Grading 证据包 RG-12 于 2026-03-05 上传，含 4 张商品图片。”“结算账单 B-33 显示 2026-03-10 扣减退货处理费 6.50 美元。”拟判定句为“订单 A-771 的退货已获批准并完成退款。”该句主体为订单 A-771，对象为退货批准与退款，状态为已获批准并完成，材料原文仅显示待审核，未载明批准或退款完成。

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 填写 AI Proxy 服务根地址，不附加 `/v1` | 与文档示例 `http://aiproxy:3000` 比较，确认无路径后缀 |
| AIPROXY_API_TOKEN | 填写与服务端一致的非空管理员 Token | 与文档要求比较，确认非空且非应用 API Key |
| 语言模型 | 启用一个支持英文与中文的语言模型 | 与“系统至少需要一个语言模型”比较 |
| 索引模型 | 启用一个索引模型用于文本块索引 | 与“至少一个索引模型”比较 |
| 全文检索 | 按实际向量库核对走 BM25 或 MongoDB $text | 与文档中 Milvus 与其他向量库的分支比较 |
| 模型探测 | 仅对已启用系统模型开启自动探测 | 与“未启用模型不参与探测”比较 |

## 容易做错的三处
1. 将 AIPROXY_API_ENDPOINT 写成带 `/v1` 或 `/chat/completions` 的完整请求地址，导致启动校验或调用路径不符。
2. 把检索相关度当作权限或实体过滤，认为相似度设置会排除其他店铺或未授权记录；检索本身不执行授权。
3. 将待审核状态直接判定为已批准或已退款，把未载明字段当作已完成事实。

## 怎么确认配好了
1. 输入假设原文中“订单 A-771 状态为待审核”与拟判定句“已获批准并完成退款”，比较同一订单同一状态字段；原文未载明批准或退款完成，判定为未获支持，需保留证据缺口。
2. 输入 AIPROXY_API_ENDPOINT 的拟填值，比较是否以根地址结尾且不含 `/v1`；若含 `/v1`，与文档要求不符，需修正后重新核对。
3. 输入假设原文中“Return Grading 证据包 RG-12 含 4 张商品图片”，比较证据包标识与图片数量字段；若检索结果返回其他证据包标识，记录为不符合，不执行跨模型关联来比较漏召回。
