# 一般贸易进口报关的跨境资料与多语检索：知识库检索与召回

## 这个品类的数据长什么样

一般贸易进口报关围绕进口报关单、商业发票、装箱单、提单、合同展开，核心关注完税价格、运保费和税费缴纳。资料来自国际贸易单一窗口、海关税则、货代到港通知、外汇付款单，更新频率为每单。报关行与关务经理日常处理的材料中，成交方式、运保费、查验配合最耗时间。

跨境场景下，同一批货物可能同时出现中文报关单与英文发票、提单，检索时需要跨语言匹配。向量方案具备跨多语言理解能力，输入中文问题可匹配英文知识点，这对多语资料混存的知识库有直接价值。资料每单更新，意味着知识库内容随每票业务变动，检索结果反映的是入库时已建立索引的内容。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，需要先核对向量模型标识，排除不符合者，记录实际观察。检索是对整个库进行搜索，集合仅用于分类管理，与搜索效果无关。

搜索模式包含语义检索、全文检索、混合检索。语义检索依赖向量距离，适合自然语言问题与跨语言匹配；全文检索依赖关键词命中，适合编号、型号、专有名词；混合检索同时使用两者，通过 RRF 融合结果。RRF 是混合结果的融合过程，不作为独立开关。

引用上限以 token 为单位，控制每次搜索最多引用的内容量。最低相关度是 0-1 的过滤阈值，仅在语义检索或使用结果重排时生效。该阈值过滤低相关度结果，不承担权限、实体或业务范围的隔离功能。检索行为本身不等于授权，检索结果能否用于某项业务动作，需要下游环节另行确认。

图片检索需要相应图像输入及模型能力支持。重排需要具备模型并按设置启用。文档总流程图列出的可选路径不代表每次请求全部执行。

假设演练样本（全部内容为虚构，仅用于核对格式与判断逻辑）：

某进口商提交一份待归档的交接记录，材料原文为：“本票货物成交方式为 CIF，运费与保险费已计入发票金额。商业发票所列收货人与提单通知方为同一主体。合同约定交货期为收到信用证后 60 天。”待判定的拟稿句为：“本票运保费已包含在完税价格中，可直接按发票金额申报，无需另行核对。”

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联向量模型标识一致的一个库 | 先核对各库向量模型标识，排除不一致者，记录实际观察结果 |
| 搜索模式 | 语义检索与全文检索分别测试 | 用同一测试问题比较两种模式的返回内容，不预设单一模式适用全部资料 |
| 引用上限 | 暂设一个 token 值作为起点 | 用长短不同的实际资料测试引用内容是否完整，再调整该值 |
| 最低相关度 | 暂设一个 0-1 数值作为起点 | 先标注相关与无关样本，再比较阈值调整后的过滤现象 |
| 问题优化 | 先关闭，用完整问题测试 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 先不启用 | 确认是否具备重排模型并按设置启用，再比较排序现象 |

## 容易做错的三处

1. 把检索结果当作授权依据。检索返回引用内容，仅表示知识库中存在相关内容，不表示某项业务动作已获批准。待审核状态不证明缺少操作权限，签署、合作达成、合同生效是三个不同事实。
2. 跨向量模型关联知识库。不同向量模型的知识库不可共同关联，需要先核对标识并排除不符合者，不执行跨模型检索来比较漏召回。
3. 用最低相关度承担权限隔离。相关度是过滤阈值，不排除无关业务或未授权记录。检索范围为有访问权的目标范围，缺失时应记录证据缺口。

## 怎么确认配好了

1. 输入上述假设样本的材料原文与拟稿句，比较拟稿句“运保费已包含在完税价格中”与原文“运费与保险费已计入发票金额”的表述范围。原文说明运保费计入发票金额，未载明完税价格的构成方式，拟稿句的“已包含在完税价格中”属于未获支持，需要保留证据缺口。
2. 输入上述假设样本的合同交货期条款，比较“收到信用证后 60 天”与拟稿句的申报安排。两者主体与字段不同，不构成矛盾，也不构成支持，判定为待核实。
3. 用明确的纸面输入空数组核对下游承接设计，观察引用内容长度为 0 时输出链路是否走通。不声称虚构规则检索一定返回空数组。

以上判定均为纸面推演，未在真实系统执行，未产生实际业务动作。
