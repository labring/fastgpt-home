# 京东POP第三方店铺运营的跨境资料与多语检索：文档解析与分块

## 这个品类的数据长什么样

京东POP第三方店铺运营日常处理商品信息表、发货时效约定、纠纷处理单、质保期服务记录。这些材料来自京东商家后台、京东帮助中心、京东开放平台规则与物流轨迹，更新频率为日、每单。跨境资料与多语检索场景中，同一份材料可能包含中文与目标市场语言，术语、编号、型号与自然语言问法混用。数据质量取决于分段是否保留完整语义、索引是否覆盖多语言表达，以及原数据与向量索引的对应关系是否清晰。检索精度受向量模型质量、数据长度与完整性、检索词质量共同影响，分段把条件与所约束内容拆离时，语义召回容易偏离原意。

## 这些特征在「文档解析与分块」这一环带来什么约束

分段须按具体资料结构进行，保留能回指原文的文档身份与版本。一组原数据可对应多个向量索引，检索时命中任一索引即可召回该组数据，得分取最高分。语义检索支持跨多语言理解，输入中文问题可匹配英文知识点，该能力取决于向量模型训练效果。全文检索适合编号、型号、专有名词、错误码等精确查询，走 MongoDB `$text` 加 jieba 分词。混合检索通过 RRF 融合语义与全文结果，Rerank 对候选文本二次排序并给出 0-1 得分。最低相关度仅在语义检索或使用结果重排时生效，属于过滤阈值。引用上限以 tokens 计量，控制每次搜索最多引用的内容量。检索是授权之外的动作，命中内容不代表操作权限已获批准。

假设演练样本：某京东POP店铺运营人员整理一份跨境质保期服务记录，原文为“本店铺质保期服务记录（编号 POP-GW-2024-031）适用于2024年3月1日至2024年3月31日期间售出的跨境商品，质保期为自签收之日起12个月，服务范围限于商品主体功能故障。”另有一条待判定拟稿句：“该记录覆盖2024年4月售出商品的质保申请。”需比较拟稿句所述时间范围与原文有效范围是否一致。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 分段方式 | 按资料结构分段，保留条件与约束 | 与原文段落边界比较，检查条件句是否与所约束内容同段 |
| 索引数量 | 同一组数据建立一组索引 | 与多向量映射说明比较，观察命中任一索引能否召回原数据 |
| 搜索模式 | 混合检索 | 与语义检索、全文检索分别比较，观察编号与自然语言问法的召回差异 |
| 最低相关度 | 本次假设起点 0.3 | 与 0.5 比较，观察过滤后候选数量与相关性的变化 |
| 引用上限 | 本次假设起点 2000 tokens | 与 1000 tokens 比较，观察引用内容完整性与候选裁剪程度 |
| 问题优化 | 本次假设不开启 | 与开启状态比较，观察连续追问场景的检索效果与耗时 |

## 容易做错的三处

1. 把上传成功当作检索已更新。资料变更后需核对实际训练与索引状态，上传动作完成不代表向量索引已重建，检索仍可能返回旧分段。
2. 把最低相关度当作权限或实体过滤。该值是 0-1 的相似度过滤阈值，不区分业务归属，也不排除未授权记录，检索命中不构成操作授权。
3. 把 RRF 当作独立开关。RRF 是混合检索中融合多路结果的过程，不是可开启或关闭的配置项，将其写成开关会误导配置核对。

## 怎么确认配好了

1. 输入假设样本原文与拟稿句，比较拟稿句所述时间范围“2024年4月”与原文有效范围“2024年3月1日至2024年3月31日”，两者不一致时判定拟稿句未获原文支持，记录为待核实。
2. 输入编号“POP-GW-2024-031”执行全文检索，比较返回分段是否包含该编号及完整有效范围，若返回分段缺失有效范围则记录分段不完整。
3. 输入自然语言问句“跨境商品质保期多久”，比较语义检索返回内容是否包含“自签收之日起12个月”，若返回内容仅含商品名称而无质保期则记录语义召回未覆盖该字段。
