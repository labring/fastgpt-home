# 京东POP第三方店铺运营的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

在京东POP第三方店铺运营的跨境资料与多语检索中，本页说明FastGPT的模型接入与配置如何衔接资料。核中英商品信息与服务条件的限定范围，避免译文将充电说明或维修登记扩为额外承诺。所用场景为自拟文字测试。

## 这些特征在「模型接入与配置」这一环带来什么约束

自拟商品对照附页可把“支持充电”与“随附充电器”分别列为待核句，实际中文原文只给前者。模型接入先检查英文输入是否也保留这一范围；若返回把功能译成包装内含配件，应并列请求与原句查证。两种表述涉及能力和随附物，不能因都出现充电词就视为一致。缺少包装说明时，当前对照无法确认是否包含配件，也不能从商品名称补出。

## 配置怎么定

| 接入核对项 | 商品与服务双语范围 | 验收线索 |
| --- | --- | --- |
| 功能原句 | 支持充电不说明随附充电器 | 核请求与输出范围 |
| 包装缺项 | 配件清单未提供 | 不从商品名补随附物 |
| 服务阶段 | 登记维修与完成分开 | 回查completed的来源 |
| 来源送达 | 两端正式材料逐份确认 | 遗漏输入与模型判断分开 |
| 后续补源 | 包装及维修结果另加核对 | 防旧稿覆盖并另验照片 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `AI Proxy依赖` | 按实际版本核服务、渠道与应用。 |
| `AIPROXY_API_ENDPOINT` | 使用AI Proxy服务根地址。 |
| `AIPROXY_API_TOKEN` | 管理员Token非空且与服务端一致。 |
| `模型能力` | 按实际输入路径验证所需能力。 |
| `应用参数` | 接口同名字段未必覆盖应用设置。 |

## 容易做错的三处

- 支持充电被译成随附充电器：保留功能句与包装缺项，对照实际请求查范围扩大，不能从名称或相同充电词补出配件。

- 登记维修被改成completed：回查完成词来自原文还是生成，原文只有登记时应修正，不把译稿当成已有平台结果。

- 两端资料已取得却只有一份进入请求：核资料选择和实际输入，保留遗漏，不能据单方返回声称已验证整份对照或直接判能力不足。

## 怎么确认配好了

验收围绕功能、随附物和服务阶段分别提问，记录每个英文判断对应的中文条件和待核项目。新取得的包装或维修结果说明要以相同题目重新核输入及采用范围，避免旧译稿覆盖新增来源。实际材料若还包括标签照片，应单独检查图像读取，当前文字结果不覆盖图中说明。翻译草稿与已确认资料保持可辨，再由责任人核实际商品与服务信息。
