# 便利店加盟门店督导的跨境资料与多语检索：向量模型与索引

## 这个品类的数据长什么样

在便利店加盟门店督导的跨境资料与多语检索中，本页说明FastGPT的向量模型与索引如何衔接资料。加盟资料的参考门店图不构成当前门店布局批准，双语索引保留示例身份。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

加盟资料可拟中文图注“参考店陈列示例，本店布局待确认”，英文说明“reference-store example; current layout under review”。当前问门店能否按图布置，示例图不能替当前审批意见。索引可以围绕参考布局、当前待核等问题回指说明，但不能把图注写成标准店批准图。先核实际入库材料是文字说明还是图片；仅看到页面有图，不足以推系统已按图片描述或图片向量处理。

## 配置怎么定

| 材料核对项 | 本题具体条件 | 实施取证 |
| --- | --- | --- |
| 图注性质 | 参考示例 | 不换批准图。 |
| 门店身份 | 参考店与本店 | 分别核对象。 |
| 当前状态 | under review | 保留待核。 |
| 实际路径 | 文字或图片 | 先核入库材料。 |
| 后补意见 | 本店本版 | 不借旧店批准。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是example索引成approved layout，应对示例身份与待核状态，查新增结论。第二处是参考店与本店混为一体，应核店别和图注出处，不用相同品牌补当前布局依据。第三处是图像描述漏掉文字待确认，应核实际入库路径与返回原文；若确为图片检索，再查描述是否准确承接限制。三项分别查文类、店别和载体处理，不由视觉近似推当前可照做。

## 怎么确认配好了

验收问图属于哪店、示例说明什么、本店是否有决定材料，对实际索引和原数据逐项回指。同一图注多个索引不等于多份批准；同节点关联多库时核同一向量模型条件。此练习不审查真实加盟资格、装修方案或执行陈列，未命中当前意见只能说明资料未核，不能说本店必未获批。补意见需核当前店及布局版本，再决定回答可支持的范围。
