# 加盟商培训与开业辅导的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样
培训签到表、开业检查表、SOP手册与考核成绩构成开业辅导的核心资料。这些材料在跨境场景下常以多语版本并存，同一门店的签到记录、物料核对结果与动作纠正记录需要跨语言比对。检索任务据此要求模型接入后能按语种返回对应文件片段，供督导与培训人员核对。资料更新频率为每店、月，本页不据此推导批量同步或实时触发机制。

## 这些特征在「模型接入与配置」这一环带来什么约束
AI Proxy 为必需依赖，App 与 Admin 须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。模型 ID 为请求 Body 中 model 字段的值，全局唯一；模型映射可将 FastGPT 请求的模型映射到上游实际模型。系统至少需要一个语言模型和一个索引模型。检索结果受向量库配置影响：Milvus 走 BM25 全文检索，其他向量库走 MongoDB $text。跨不同向量模型的库不可共同关联，须先核标识并排除不符合者。相关度分数不承担权限或实体隔离职责，检索不构成授权。

假设演练样本：某连锁培训部提交一份多语开业检查表，原文为“门店编号 A-07；检查日期 2026 年 3 月；检查项：收银台物料齐备；结论：待复核；复核人未签署”。另有一份拟稿句待判定：“该门店 2026 年 3 月收银台物料齐备，已通过复核。”样本中复核人未签署，拟稿句将待复核写成已通过，属未获支持。

## 配置怎么定
下表围绕上述样本列出官方已说明的设置或实施核对项。数值项明确为本次假设试验起点，并说明比较对象。

| 配置项 | 本次假设起点 | 核对说明 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设填 `http://aiproxy:3000` | 根地址，不附加 `/v1`；与启动校验要求比较 |
| AIPROXY_API_TOKEN | 假设填非空管理员 Token | 与服务端配置一致；空值触发启动失败 |
| 模型映射 | 假设 `gpt-4o-test` 映射到 `gpt-4o` | 核对 FastGPT 请求模型与上游实际模型是否对应 |
| 索引模型 | 假设启用一个索引模型 | 与“至少一个语言模型和一个索引模型”要求比较 |
| 向量库类型 | 假设 Milvus | 核对全文检索走 BM25 还是 MongoDB $text |
| 模型探测 | 假设探测间隔 10 分钟 | 与文档 5～60 分钟整数范围比较 |

## 容易做错的三处
1. 将 AIPROXY_API_ENDPOINT 写成含 `/v1` 的完整请求地址。检查：输入该地址，与文档“不要附加 /v1”比较，出现启动校验失败或请求路径异常即不满足。
2. 把待复核的检查表拟稿句写成已通过复核。检查：输入样本原文与拟稿句，比较复核人签署状态，拟稿句声称已通过而原文未签署即不满足。
3. 将相关度分数当作权限过滤条件。检查：输入同一查询，比较返回记录与授权范围，出现未授权记录即不满足。

## 怎么确认配好了
1. 输入样本原文与拟稿句，比较“待复核”与“已通过复核”的字段取值，拟稿句与原文状态一致才满足；当前样本不满足。
2. 输入 AIPROXY_API_ENDPOINT 假设值，与文档“根地址、不附加 /v1”比较，地址格式符合且启动校验通过才满足。
3. 输入一条跨向量模型库的检索请求，先核标识并排除不符合者；若标识不一致则记录为不可共同关联，不执行跨模型检索比较漏召回。
