# 区域经销商库存补货的跨境资料与多语检索：知识库检索与召回

## 这个品类的数据长什么样

区域经销商库存补货属于日常滚动订单，与季节性集中订货存在节奏差异。补货申请、库存周转表、出库单、回款计划构成主要文档集合，来源覆盖经销商ERP、品牌订货系统、仓库库存与销售回款。周度与月度更新意味着资料版本会随时间推移产生多份并存文本。

跨境多语场景下，同一补货申请可能同时存在中文与译文版本，库存周转表的字段名称在不同语言间需要对齐。检索环节面对的是这些多语、多版本、字段结构不统一的资料，向量模型对跨语言语义有理解能力，编号与型号类精确查询则更依赖全文命中。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，需要先核对向量模型标识，排除不符合者，记录实际观察结果，不执行跨模型检索来比较召回差异。

引用内容以数组格式输出，长度可以为 0，即使没有搜索到内容，输出链路也会走通。这一行为可用于核对下游设计对空结果的处理。

搜索模式分为语义检索、全文检索与混合检索。语义检索依赖向量距离，适合自然语言问法；全文检索依赖关键词命中，适合编号、型号、专有名词；混合检索同时使用两路召回并通过 RRF 融合。RRF 是混合结果融合过程，不作为独立开关描述。重排需要具备模型并按设置启用，图片检索需要相应图像输入及模型能力，文档总流程图列出的可选路径不代表每次请求全部执行。

最低相关度是过滤阈值，仅在语义检索或使用结果重排时生效，不作为最终排序规则。引用上限以 token 为单位，用于控制每次搜索最多引用的内容量。问题优化在正式检索前增加一次模型调用，用于指代消除与问题扩展。

假设演练样本

供核对的材料原文（虚构）：

> 经销商甲于2025年3月提交补货申请单 BH-2025-0312，申请品项为型号 X200 共计 400 件，申请状态栏填写“待品牌渠道经理审核”。该申请单译文版本中，品项型号写作 X200，数量写作 400，状态栏译文为“pending review”。

待判定的拟稿句：

> 补货申请 BH-2025-0312 已获品牌渠道经理批准，型号 X200 的 400 件将于本周发货。

该拟稿句涉及主体（经销商甲）、对象（型号 X200、400 件）、状态（待审核）与授权边界（品牌渠道经理审核）。材料原文显示状态为待审核，拟稿句称已获批准并给出发货时间，两者在状态字段上取值不同。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 仅关联使用同一向量模型的补货资料库 | 核对各库向量模型标识，排除标识不一致者，不执行跨模型检索 |
| 搜索模式 | 先以混合检索运行样本问题 | 样本含型号 X200 与自然语言状态问法，比较语义与全文两路召回内容 |
| 引用上限 | 设为 800 token 作为本次起点 | 以长短不同的实际资料测试内容完整性，与 400 token 结果比较截断情况 |
| 最低相关度 | 设为 0.3 作为本次起点 | 先标注相关与无关样本，比较 0.2 与 0.4 的过滤差异后调整 |
| 问题优化 | 本次样本问题主体明确，暂不开启 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 本次未配置重排模型，不启用 | 重排需具备模型并按设置启用，缺模型时保持关闭 |

## 容易做错的三处

1. 把待审核状态当作已批准。样本原文状态栏为“待品牌渠道经理审核”，拟稿句写“已获品牌渠道经理批准”。输入为样本原文与拟稿句，比较同一状态字段的取值，两者取值不同，拟稿句在该字段上未获支持。
2. 把检索命中当作授权执行。检索返回补货申请原文，仅表示资料被召回，不表示审核通过或发货已安排。输入为检索结果与拟稿句，比较是否存在批准记录，样本中仅有待审核状态，批准事实缺失。
3. 跨向量模型库共同关联。输入为待关联的多个知识库，比较各自向量模型标识，标识不一致者应排除。该错误不产生可断言的运行结果，仅记录标识核对与排除动作。

## 怎么确认配好了

1. 输入样本原文与拟稿句，比较状态字段取值。原文为“待品牌渠道经理审核”，拟稿句为“已获品牌渠道经理批准”。若检索返回的引用内容与原文状态字段一致，且拟稿句未将待审核改写为已批准，则该项核对满足条件。预期为状态字段保持待审核表述，不声称已实测。
2. 输入样本问题“BH-2025-0312 当前审核状态”，比较语义检索与全文检索的召回内容。若全文检索命中型号与单号，语义检索命中状态描述，混合检索经 RRF 融合后引用内容同时覆盖两者，则该项核对满足条件。失败分支为任一路未命中对应内容，记录实际观察。
3. 输入空结果纸面用例，引用内容为 `[]`，比较下游设计对空数组的处理。若下游链路在引用长度为 0 时仍走通，则该项核对满足条件。不声称虚构规则检索一定返回 `[]`，仅以明确纸面输入核对下游设计。
