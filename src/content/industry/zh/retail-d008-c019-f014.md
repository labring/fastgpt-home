# 即时零售门店履约的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

即时零售门店履约按分钟处理线上订单，与周期性盘库存在节奏差异。日常材料包括即时订单、拣货清单、缺货报备与配送异常单，来源涉及抖音即时零售、美团或京东到家后台、门店库存与骑手轨迹。跨境资料与多语检索场景下，这些材料可能以多种语言出现，检索目标通常是订单号、商品名、门店标识与配送状态字段。

材料更新按每单发生，本页不据此推出批量同步或交易触发机制。拣货清单与缺货报备常含替换商品的多语描述，配送异常单可能记录骑手轨迹片段。模型接入与配置需要先确认这些材料的语言分布与字段结构，再决定索引模型与语言模型的能力范围。

## 这些特征在「模型接入与配置」这一环带来什么约束

材料的多语混合意味着索引模型需覆盖实际出现的语言，检索请求的模型标识必须与库内向量模型一致。按官方文档，系统至少需要一个语言模型和一个索引模型才能正常使用；语音识别模型仅生效一个。AI Proxy 为必需依赖，App 与 Admin 服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败。

模型 ID 是接口请求 Body 中 `model` 字段的值，全局唯一。模型映射可将 FastGPT 请求的模型映射到上游具体模型，例如 `gpt-4o-test` 映射为 `gpt-4o`。检索相关度分数不承担权限过滤或实体隔离职责，检索行为本身不构成授权。跨不同向量模型的库不可共同关联，需先核对模型标识并排除不符合者。

假设演练样本：某门店履约团队收到一份跨境拣货资料，原文为三条记录。记录一：“订单号 ORD-2026-0417，门店 SH-03，商品 500ml 矿泉水，拣货状态：已拣货。”记录二：“订单号 ORD-2026-0417，门店 SH-03，商品 500ml 矿泉水，配送状态：待取货。”记录三：“订单号 ORD-2026-0418，门店 SH-03，商品 1L 牛奶，缺货报备：待审核。”拟交接请求为：“请确认 ORD-2026-0417 的配送已完成，并授权按缺货处理 ORD-2026-0418。”

该请求涉及两个不同订单，记录二仅显示待取货，记录三的缺货报备处于待审核。待审核不构成审批通过，待取货不构成配送完成。交接请求中的授权部分在样本中未获支持。

## 配置怎么定

配置围绕本页多语检索样本，列出官方已说明的设置或实施核对项。数值为本次假设试验起点，不作为官方默认值。

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 索引模型 | 选用一个支持多语文本的索引模型 | 对照样本中出现的语言，与库内已有向量模型标识比较，确认一致 |
| 语言模型 | 选用一个支持文本对话的语言模型 | 核对应用所需输入类型，与模型能力字段比较 |
| `AIPROXY_API_ENDPOINT` | 填写 AI Proxy 服务根地址 | 按文档不附加 `/v1`，与部署实际地址比较 |
| `AIPROXY_API_TOKEN` | 填写与服务端一致的非空 Token | 与 AI Proxy 管理员 Token 比较，确认一致 |
| 模型映射 | 将请求模型标识映射到上游实际模型 | 对照渠道配置中的模型名，确认映射关系 |
| 检索范围 | 限定在含样本材料的库内 | 核对库的向量模型标识，排除不同模型的库 |

## 容易做错的三处

1. 将检索命中当作授权依据。样本中 ORD-2026-0418 的缺货报备为待审核，检索到该记录不表示缺货处理已获批准。输入为检索结果，比较对象为报备状态字段，观察结果为状态仍为待审核。

2. 将不同订单的状态混为同一订单。样本中 ORD-2026-0417 与 ORD-2026-0418 为不同订单，记录二的待取货属于前者，记录三的待审核属于后者。输入为两条记录，比较订单号字段，观察结果为订单号不一致。

3. 将待取货视为配送完成。记录二仅显示待取货，未载明送达时间或签收字段。输入为记录二，比较配送状态字段，观察结果为未出现完成标识。

## 怎么确认配好了

1. 核对索引模型与库内向量模型标识。输入为样本材料所在库的模型标识，比较对象为配置中索引模型的标识，观察结果为两者一致。若不一致，记录为待核实，不执行跨模型检索比较。

2. 核对 `AIPROXY_API_ENDPOINT` 与 `AIPROXY_API_TOKEN` 是否均已设置。输入为环境变量配置，比较对象为文档要求的必填条件，观察结果为两项均非空。若任一项缺失，记录为未满足启动条件。

3. 核对拟交接请求中的授权部分是否有对应证据。输入为拟稿请求与三条样本记录，比较对象为请求中的“配送已完成”与“授权按缺货处理”两项，观察结果为记录二未显示完成、记录三处于待审核。两项均未获支持，保留证据缺口，不补造授权条款。
