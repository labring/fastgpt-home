# 原产地证书申办的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

在原产地证书申办的跨境资料与多语检索中，本页说明FastGPT的模型接入与配置如何衔接资料。核中英证书材料的国别角色、地址和商品描述，不将语言对照当成原产结论。所用场景为自拟文字测试。

## 这些特征在「模型接入与配置」这一环带来什么约束

自拟双语附页可将出口国、目的国与企业地址分开写，英文保留对应栏名。模型读取应先核这些关系是否进入请求；地址中出现某国文字不说明商品原产于该国。若回答把出口国或企业所在地换成原产国，应并列原栏名与返回句定位范围扩大。原产判定所需资料另行取得，不能由中英地名相同、渠道可用或回复流畅推定已经具备依据。

## 配置怎么定

| 接入核对项 | 证书双语范围 | 验收线索 |
| --- | --- | --- |
| 国别角色 | 出口国、目的国和地址分开 | 栏名与对应文字送达 |
| 原产边界 | 企业所在地不直接证明原产 | 输出新增判断回查 |
| 用途缺项 | 英文暂缺中文用途段 | 原文缺失与传入遗漏分开 |
| 译稿身份 | 新增译文保留待核状态 | 不冒充证书既有原文 |
| 资料形式 | 盖章扫描件另核读取 | 翻译不执行签发或更正 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `AI Proxy依赖` | 按实际版本核服务、渠道与应用。 |
| `AIPROXY_API_ENDPOINT` | 使用AI Proxy服务根地址。 |
| `AIPROXY_API_TOKEN` | 管理员Token非空且与服务端一致。 |
| `模型能力` | 按实际输入路径验证所需能力。 |
| `应用参数` | 接口同名字段未必覆盖应用设置。 |

## 容易做错的三处

- 出口国或企业地址被改成商品原产国：并列原栏名、请求及返回，查地点角色在哪步改变，地名相同不提供原产依据。

- 资料选择有用途段、请求却缺失：保留两处文字并查传递，当前无法核实模型对用途的理解，不能直接认定译文错误。

- 模型补出的英文用途被称为证书既有原文：回查实际对应来源并保留待核译稿身份，补齐后同题核主体与版本，不以生成代替取得资料。

## 怎么确认配好了

验收按国别角色、地址和用途逐句比对实际输入与输出，记录哪些只是译文建议，哪些有已提供的对应原文。若来源为盖章扫描件，应另验图像或解析后的文字是否完整，不从文字调用推定印章或全部栏位已读取。证书更正与正式签发也不由这轮翻译执行；技术配置核对用于定位调用与输入问题，语言准确仍须结合实际来源和适用要求确认。
