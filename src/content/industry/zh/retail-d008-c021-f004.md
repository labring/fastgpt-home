# 品牌会员私域运营的跨境资料与多语检索：向量模型与索引

## 这个品类的数据长什么样

在品牌会员私域运营的跨境资料与多语检索中，本页说明FastGPT的向量模型与索引如何衔接资料。会员跨语活动资料需区分资料接收登记、活动报名与实际参与。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

品牌会员活动可拟中文登记“愿收活动资料，不作活动报名”，英文页“information opt-in only; attendance unrecorded”。当前问谁参加过活动，愿意收资料不能证明报名或到场；英文opt-in的对象是信息接收。索引应保留资料用途与不报名限定，不能命名成活动参与名单。这里不含真实人员信息，纸面样例只是核行为对象：同样一个登记词，可以指沟通偏好，也可以指报名，必须回看原句。

## 配置怎么定

| 材料核对项 | 本题具体条件 | 实施取证 |
| --- | --- | --- |
| 同意对象 | 资料接收 | 不换活动报名。 |
| 排除动作 | 不作报名 | 核双语保留。 |
| 记录缺口 | attendance unrecorded | 不推未到场。 |
| 活动身份 | 当前轮次 | 核旧名单。 |
| 实际授权 | 本练习不判断 | 不由命中推充分。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

第一处是information opt-in索引成event enrolment，应核同意的对象与中文排除句，查行为转换。第二处是attendance unrecorded被回答成未到场，应核英文范围是未记，不可改成负面观察。第三处是另一场活动名单混入当前登记，应核活动轮次和来源身份，不用同一会员类别拼参加记录。三项分别查动作对象、记录缺口和活动归属，不因多语命中就补会员实际行为。

## 怎么确认配好了

验收分别问允许收什么、是否报名、是否有到场记录，对实际索引和原数据回指，多索引同一表仍是一份偏好材料。同节点关联库核同一向量模型条件，不能由换语言推召回完整或授权充分。此练习不收集名单、发送资料或判断真实同意效力；没命中报名不说明未报名，未记到场也不说明没来。需要本活动独立依据后，才可回答对应阶段。

| --- | --- |
| 文档类型 | 会员标签表、触达计划、优惠券规则、隐私授权记录 |
