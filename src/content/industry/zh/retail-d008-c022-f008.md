# 品牌全渠道库存调拨的跨境资料与多语检索：工作流编排

## 这个品类的数据长什么样

在品牌全渠道库存调拨的跨境资料与多语检索中，本页说明FastGPT的工作流编排如何衔接资料。跨渠道调拨双语资料先保留在途、保留库存与渠道归属，交互传递不能使库存状态自动改变。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

假设英文调拨通知说货仍在途，中文库存备注称该批已为门店保留，另张截图属于线上渠道。收集原句、批次和渠道对应，让人员选择核库存词义或补到货依据。表单提交后逐项检查后续收到的状态；保留库存不代表可售，在途也不能翻作目的店可用。纸面练习没有真实调拨执行。

## 配置怎么定

| 调拨双语传递 | 假设状态 | 核验动作 |
| --- | --- | --- |
| 在途通知 | 尚未到店 | 查收货凭据 |
| 保留库存 | 可用性受限 | 保留原限定 |
| 线上截图 | 另渠道 | 核所属库存池 |
| 人员选择 | 词义或到货 | 看后续输入 |
| 库存操作 | 系统另接 | 权限及回执 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

在途被译成已到店时，查运输与收货凭据；保留被改成可售时，核限制原句；线上截图用于门店余额时，核渠道身份。三处分别看阶段、可用性与对象，不能由节点继续证明库存移动。

## 怎么确认配好了

验收两条选择路径的实际输入，双语对照保留同一批次限定。补到货仅改接收阶段，销售可用性仍需授权及业务状态。截图旁列所属渠道，避免同名商品串库。正式调拨、解锁与库存回写另接系统核权限回执，流程只承接材料及待核条件。 保留库存旁单列解锁依据的缺项，目的店收货与线上余额分别指向其原始材料位置。
