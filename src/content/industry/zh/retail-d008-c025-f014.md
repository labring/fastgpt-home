# 品牌奥莱折扣运营的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

在品牌奥莱折扣运营的跨境资料与多语检索中，本页说明FastGPT的模型接入与配置如何衔接资料。保留款式、尺码体系与活动范围的双语对应，不从译名或价签推定商品属性。所用场景为自拟文字测试。

## 这些特征在「模型接入与配置」这一环带来什么约束

自拟双语附页可列同系列的不同款号，中文尺码说明使用本地标识，英文暂仅保留原标识未给换算依据。接入先核款号与尺码关系是否完整传入，不能把同一字母视为全球等同尺寸。若输出生成具体换算，应回查请求是否真的包含相应说明；没有来源时当前对照无法确认穿着适合度。模型能翻译文字，不说明已经取得品牌尺码表或验证实物尺寸。

## 配置怎么定

| 接入核对项 | 奥莱双语对应条件 | 实际验证 |
| --- | --- | --- |
| 尺码标识 | 本地标识没有换算依据 | 不生成无据尺寸对应 |
| 款式关系 | 同系列各款号分开 | 实际输入保留配对 |
| 门店限制 | 指定店与款式的适用条件 | 定位传入或生成省略 |
| 新增来源 | 品牌对应说明另行补入 | 同题核新条件采用 |
| 其他属性 | 材质及图片标签另核 | 译名不证明实物适合度 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `AI Proxy依赖` | 按实际版本核服务、渠道与应用。 |
| `AIPROXY_API_ENDPOINT` | 使用AI Proxy服务根地址。 |
| `AIPROXY_API_TOKEN` | 管理员Token非空且与服务端一致。 |
| `模型能力` | 按实际输入路径验证所需能力。 |
| `应用参数` | 接口同名字段未必覆盖应用设置。 |

## 容易做错的三处

- 本地尺码字母被输出为确定换算：回查品牌对应依据与请求，未给尺寸表就无法确认，不能从同一字母推全球等同。

- 指定门店条件在英文中变成全店：并列原价签、实际输入与输出，定位传入丢失或生成省略，不由配置裁定活动范围。

- 系列译名相同便把不同款号合并：核款号与尺码的配对及适用来源；补品牌说明后复测，新旧资料身份仍需可辨。

## 怎么确认配好了

验收按款式、尺码标识与门店限制分别设问，记录英文表述采用哪些原文及哪些仍为待核译稿。补入品牌对应说明后，同题同设置查新增条件，不将旧译名覆盖新来源。商品材质与使用说明另有资料才能核，不从清货标签推定缺陷或性能。实际资料如需读图片，另验相应能力；当前文字对照不证明服装标签图像或实物已经被检查。
