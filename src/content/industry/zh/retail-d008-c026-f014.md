# 品牌直营门店运营的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

品牌直营门店由品牌直接雇佣和核算，不通过加盟合同管理，日销售报表、排班表、陈列照片和库存调拨单是日常要处理的文档。跨境资料与多语检索场景下，这些材料可能以中文、英文或其他语言出现，检索环节需要语言模型与索引模型配合。模型接入与配置的边界在于：把可用的模型渠道接入系统，使检索请求能够被正确路由，不涉及门店排班、销售目标或调拨审批等业务动作。

## 这些特征在「模型接入与配置」这一环带来什么约束

系统至少需要一个语言模型和一个索引模型才能正常使用。AI Proxy 为必需依赖，App 和复用 App/Service 配置的 Admin 服务都必须设置 AIPROXY_API_ENDPOINT 和非空的 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。模型 ID 是接口请求 Body 中 model 字段的值，全局唯一；模型名用于展示，可以自定义。模型渠道对应不同提供商协议，一个模型可以配置在不同渠道中实现负载均衡。渠道优先级范围 1～100，数值越大越容易被优先选中。检索相关性由向量模型和索引模型决定，检索本身不承担授权判断，相似度设置不排除无关业务或未授权记录。

假设演练样本（纸面构造，仅用于说明核对方法，不代表任何真实系统运行结果）：

材料原文一，来自某直营门店 2026 年 3 月 15 日日销售报表摘录：“本店当日跨境线上订单 42 笔，其中英文界面下单 17 笔，中文界面下单 25 笔；退货 3 笔，均来自英文界面订单。”

材料原文二，来自同一门店 2026 年 3 月 15 日排班表摘录：“早班 3 人，晚班 2 人；晚班负责闭店后整理陈列照片并上传。”

待判定拟稿句：“该门店 2026 年 3 月 15 日英文界面订单的退货率为 3/42。”

## 配置怎么定

以下为本次假设演练起点的配置核对项，数值为说明对比方法而设定，不表示官方默认值。

| 配置项 | 本次假设演练起点 | 核对方法与理由 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 填写 AI Proxy 服务根地址，不附加 /v1 | 与文档要求比对，确认无多余路径 |
| AIPROXY_API_TOKEN | 填写非空管理员 Token | 与服务端配置比对，确认一致且非空 |
| 语言模型 | 至少启用一个 | 检查系统模型列表，确认存在已启用项 |
| 索引模型 | 至少启用一个 | 检查系统模型列表，确认存在已启用项 |
| 渠道优先级 | 设定为 50 | 与范围 1～100 比对，确认在区间内 |
| 模型映射 | gpt-4o-test 映射到 gpt-4o | 与渠道配置比对，确认映射关系正确 |

## 容易做错的三处

1. 把 AIPROXY_API_TOKEN 与应用 API Key 混用。输入为某部署的环境变量清单，比较对象为文档中 AIPROXY_API_TOKEN 的说明，可观察结果为：若清单中该变量为空或填入了应用 API Key，则不符合配置要求。
2. 在 AIPROXY_API_ENDPOINT 后附加 /v1 或 /chat/completions。输入为填写后的地址值，比较对象为文档中“不要附加 /v1”的说明，可观察结果为：若地址末尾出现 /v1，则与文档要求不一致。
3. 将检索相关性当作权限过滤。输入为某次检索请求及其返回记录，比较对象为记录所属业务范围与请求方授权范围，可观察结果为：若返回了未授权记录，则说明检索环节未执行授权判断，需要下游实现补充。

## 怎么确认配好了

以下三项验证均使用上文假设演练样本，不声称已实际执行。

1. 针对材料原文一与待判定拟稿句：输入为原文中“英文界面下单 17 笔”与拟稿句“英文界面订单的退货率为 3/42”，比较对象为同一字段同一期间的数值，可观察结果为：拟稿句分母 42 与原文英文界面订单数 17 不一致，该句未获原文支持，需核实分母来源。
2. 针对材料原文二：输入为“晚班负责闭店后整理陈列照片并上传”，比较对象为拟稿句是否出现“已上传”或“已完成”等状态描述，可观察结果为：原文仅说明职责分工，未载明上传完成状态，若拟稿句断言已完成，则超出原文范围。
3. 针对模型配置：输入为系统模型列表与渠道配置，比较对象为文档中“至少需要一个语言模型和一个索引模型”的要求，可观察结果为：若列表中存在已启用的语言模型和索引模型各至少一个，则满足最低配置条件；若缺失任一类，则未满足。

检索检查应观察实际返回记录与请求语言、模型标识的对应关系，记录失败分支，不保证首条命中或全部召回。空结果可用明确的纸面输入 [] 核对下游设计，不声称虚构规则检索一定返回 []。跨不同向量模型的库不可共同关联，应先核标识并排除不符合者，记录实际观察。待审核状态不证明缺少操作权限，签署、合作达成、合同生效是三个不同事实，证据缺口需明确保留。
