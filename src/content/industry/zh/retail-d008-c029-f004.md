# 售后维修与补寄的跨境资料与多语检索：向量模型与索引

## 这个品类的数据长什么样

售后维修与补寄围绕恢复商品使用展开，结案方式以维修完成或配件补寄到位为主，与仅退款争议的结案逻辑不同。维修申请、补寄单、检测报告、配件出库单构成日常要处理的文档集合，来源涉及售后系统、订单系统、维修网点与配件仓WMS。数据更新频率为每单与日，这一节奏说明检索内容需要随单据状态持续变化，索引更新与原文核对不能只做一次。跨境资料与多语检索意味着同一批材料可能以不同语言出现，语义检索的跨多语言理解能力在此环节有直接作用，但向量模型本身不承担单据状态判断或授权判定。

## 这些特征在「向量模型与索引」这一环带来什么约束

关联检索的知识库须使用相同向量模型，选择多个知识库时先核对模型标识与输入类型，不符合者排除，不执行跨模型检索来比较漏召回。一个原数据块可以关联多个索引，索引内容与原文内容分别核对。索引应使用完整且聚焦的信息建立，检索覆盖范围与索引长度需结合样本权衡。图片检索能否生效，取决于入库时是否生成图片描述索引或图片向量索引，也取决于查询时模型能力，查询端上传图片并不自动补足入库端缺失的索引。模型或索引调整后，用同组问题比对引用原文，不根据向量分数单独承诺效果。语义召回与相关度分数不承担权限或实体隔离功能，检索结果不等同于业务授权。

假设演练样本：材料原文为“补寄单 BS-2026-0417，商品为某型号电源适配器，申请日期2026年4月17日，状态为待配件仓确认，申请人标注收件地址位于境外。”另有一条拟稿句：“该补寄单已由配件仓确认并完成出库。”待判定事实为配件仓确认与出库完成是否成立。

## 配置怎么定

| 配置项 | 本页相关设置或核对项 | 与样本的关系 |
| --- | --- | --- |
| 关联知识库 | 选择一个或多个相同向量模型的知识库 | 样本材料若分散在多个库，先核模型标识一致 |
| 搜索模式 | 语义检索、全文检索或混合检索 | 补寄单编号属精确查询，可核全文检索路径 |
| 索引内容 | 用完整且聚焦的信息建立索引，索引与原文分别核对 | 核对补寄单原文与索引是否一致 |
| 图片索引 | 确认入库时是否生成图片描述或图片向量索引 | 样本无图片输入，此项记录为未涉及 |
| 引用上限与最低相关度 | 按 tokens 控制引用上限，最低相关度仅在语义检索或结果重排时生效 | 本次假设试验起点设为引用上限2000 tokens、最低相关度0.4，选择理由为样本问题明确且候选较少，比较对象为同组问题在调整前后的引用原文 |
| 结果重排 | 具备重排模型并按设置启用后，对候选文本二次排序 | 样本未启用，记录为未配置 |

## 容易做错的三处

1. 把检索命中当作授权状态。样本中补寄单状态为待配件仓确认，检索到该单据只说明内容被召回，配件仓确认与出库完成仍需下游系统记录或人工核对，检索环节不产生该事实。
2. 把不同向量模型的知识库共同关联。样本材料若分别入库且模型标识不同，应先核对标识并排除不符合者，不继续执行跨模型检索，也不据此推断漏召回或冗余结果。
3. 把相似度分数当作实体或权限过滤。最低相关度是过滤阈值，不区分申请主体、收件地区或授权范围，样本中境外收件地址不会因分数高低被自动排除或纳入。

## 怎么确认配好了

1. 输入样本材料原文与拟稿句，比较拟稿句中的“已由配件仓确认并完成出库”与原文“状态为待配件仓确认”。满足条件为：检索能召回该补寄单原文，且核对结论记录为待核实，不将拟稿句判定为成立。
2. 输入同组问题，比较调整引用上限与最低相关度前后的引用原文。满足条件为：引用内容仍包含补寄单编号与状态字段，未因参数变化丢失判断所需字段；若引用为空数组，则按空结果承接核对下游设计，不声称虚构规则必然返回空。
3. 输入包含图片的查询，比较入库索引记录与查询端模型能力。满足条件为：入库已生成图片描述或图片向量索引且模型支持对应输入时，图片路径参与召回；任一条件缺失时，记录该路径未生效，不推断图搜图结果。
