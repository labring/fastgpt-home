# 商超塑料袋与一次性用品报告的跨境资料与多语检索：知识库检索与召回

## 这个品类的数据长什么样

商超塑料袋与一次性用品报告围绕一次性塑料制品使用与环保监管，资料来自商务部报告系统、POS塑料袋销售、采购系统与门店台账，日常文档包括塑料袋采购台账、销售凭证、半年报告与自律承诺。更新频率为半年与日两类，跨境资料与多语检索需要同时容纳中文台账、外文销售凭证与多语承诺文本。该品类与收银会员促销的差别在于监管报送属性，检索结果直接影响限期整改、罚款与约谈风险，因此召回内容必须能定位到具体材料与字段。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库；跨不同向量模型的库不可共同关联，只能核对标识并排除不符合者。搜索模式分语义检索、全文检索与混合检索，语义检索具备跨多语言理解能力，适合外文凭证与中文问题之间的匹配；全文检索适合编号、型号与专有名词。混合检索经 RRF 融合多路结果，Rerank 对候选文本二次排序，最低相关度仅在语义检索或使用结果重排时生效。引用上限以 token 为单位，输出引用长度可以为 0，空结果链路仍走通。检索与表单收集不构成授权执行，报送、审批与数据库写入需要另有下游实现。

假设演练样本：一份待核对的材料原文为“2024年上半年门店A塑料袋采购台账共12笔，销售凭证编号POS-2024-06-018，自律承诺书签署日期2024年3月5日，半年报告报送状态为待审核。”待判定的拟稿句为“门店A上半年报告已报送完成。”对照原文，报送状态为待审核，拟稿句所称“已报送完成”未获支持，应记录为待核实，不得判定为已完成。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联使用同一向量模型的两个库：台账库与凭证库 | 先核对向量模型标识，排除不同模型库，再比较召回内容是否覆盖两类材料 |
| 搜索模式 | 混合检索 | 台账含编号，凭证含外文描述，比较语义与全文两路结果是否都出现 |
| 引用上限 | 假设起点 2000 tokens | 用长短不同的台账与凭证段落测试内容是否被截断，与完整段落长度比较 |
| 最低相关度 | 假设起点 0.4 | 先标注相关与无关样本，再比较阈值调整后无关片段是否减少 |
| 问题优化 | 开启 | 比较原问题与优化后问题，核对主体“门店A”与期间“上半年”是否被改错 |
| Rerank | 启用 | 候选较多时比较重排得分排序，确认相关凭证是否排在无关片段之前 |

## 容易做错的三处

1. 把检索或表单当作授权执行。错误表现：看到“半年报告报送状态为待审核”即判定已报送。检查输入为该状态字段，比较对象为“已报送完成”的表述，观察结果为两者不一致，应记录为待核实。
2. 跨不同向量模型的库共同关联。错误表现：将台账库与另一不同向量模型的凭证库一起关联。检查输入为各库的向量模型标识，比较对象为相同模型要求，观察结果为标识不符者被排除，不执行跨模型检索。
3. 把最低相关度当作权限或实体过滤。错误表现：认为调高相关度即可排除未授权门店记录。检查输入为相关度阈值与门店范围，比较对象为授权边界，观察结果为阈值变化不改变授权范围，授权需另有下游实现。

## 怎么确认配好了

1. 针对假设样本原文，输入问题“门店A上半年报告报送状态是什么”，比较召回内容是否包含“待审核”字段，观察结果为引用内容中出现该字段且未出现“已报送完成”的改写，即满足条件。
2. 针对拟稿句“门店A上半年报告已报送完成”，输入该句作为待判定文本，比较原文状态字段与拟稿表述，观察结果为两者不一致并记录为待核实，即满足条件。
3. 针对空结果分支，输入一个纸面构造的 [] 引用数组，比较下游设计是否能承接长度为 0 的输出，观察结果为下游链路走通且不报错，即满足条件；该核对不声称虚构规则检索必然返回空结果。
