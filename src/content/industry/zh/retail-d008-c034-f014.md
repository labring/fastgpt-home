# 外贸出口退税申报的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样
出口退税申报在货物出口之后进行税务凭证匹配，主要资料包括出口退免税申报表、出口报关单、进货发票和收汇凭证。财务人员需要把报关单与进货发票逐笔对应，再据以生成申报数据。跨境资料常含英文品名、境外主体名称和多语单证，检索时需按同一申报批次归集。资料按月或按批更新，单证状态可能处于待核对、待补录或待提交。

## 这些特征在「模型接入与配置」这一环带来什么约束
模型接入以 AI Proxy 为必需依赖。App 与 Admin 均须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。端点填写服务根地址，不附加 /v1。系统至少需要一个语言模型和一个索引模型。检索库与索引模型须同一模型标识，跨不同向量模型的库不可共同关联，只能先核标识并排除不符合者。相似度或相关度不承担权限过滤，检索结果不构成授权。

假设演练样本：某外贸企业单证员提交一份纸面材料，原文为“出口报关单号 A-2026-0311，出口日期 2026 年 3 月 11 日，境外买方 Northwind Trading LLC，商品英文名 Stainless Steel Flask，数量 2000 件；对应进货发票号 INV-2026-0311，开票日期 2026 年 3 月 5 日，供货方为境内某制造企业。”待判定拟稿句为“该批货物已完成收汇，可提交退税申报”。样本中未提供收汇凭证，收汇状态未载明。

## 配置怎么定
下表为本次假设试验起点的实施核对项，数值仅用于本页演练，与官方默认值无关。

| 配置或核对项 | 本次假设起点 | 选择理由与比较方法 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设填写 `http://aiproxy:3000` | 与服务根地址一致，比较是否误加 `/v1` |
| AIPROXY_API_TOKEN | 假设配置非空管理员 Token | 与服务端一致，比较是否误用应用 API Key |
| 索引模型标识 | 假设启用一个索引模型 | 与检索库所用模型标识比较，须一致 |
| 语言模型标识 | 假设启用一个语言模型 | 与拟用节点所需能力比较 |
| 多语检索输入范围 | 假设限定本申报批次资料 | 与样本单证号比较，排除其他批次 |
| 空结果承接 | 假设以纸面输入 `[]` 核对下游 | 观察下游是否按空结果处理，不预设返回 |

## 容易做错的三处
1. 把 AIPROXY_API_TOKEN 与应用 API Key 混用。输入为环境变量配置项，比较对象为 AI Proxy 管理员 Token，可观察结果为启动校验是否通过。
2. 把相似度分数当作权限或实体过滤。输入为检索请求与返回列表，比较对象为样本申报批次与授权范围，可观察结果为返回记录是否超出该批次。
3. 用拟稿句直接认定收汇完成。输入为样本原文与拟稿句，比较对象为是否载明收汇凭证，可观察结果为该句是否获得原文支持。

## 怎么确认配好了
1. 针对样本原文与拟稿句，输入为上述报关单、进货发票两句原文及待判定句，比较对象为原文是否载明收汇凭证，若原文未载明收汇，则该拟稿句未获支持，应记录证据缺口。
2. 针对索引模型一致性，输入为检索库标识与已启用索引模型标识，比较对象为两者是否同一，若标识不符则排除该库，不执行跨模型检索。
3. 针对空结果承接，输入为纸面输入 `[]`，比较对象为下游节点对空列表的处理设计，若下游未定义空结果分支，则记录为待核实，不声称检索必返回空。
