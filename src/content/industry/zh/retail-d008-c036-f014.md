# 多仓分仓与库存同步的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

多仓分仓的决定发生在订单路由阶段，回答的是从哪个仓发货。主要材料来自 WMS、OMS、ERP 库存与平台库存接口，日常文档包括分仓规则、库存同步表、调拨单和缺货预警。这类内容以日或小时为节奏更新，同一 SKU 在不同仓的可售数量、优先级和调拨状态会同时出现。

跨境资料与多语检索要处理的是这些材料的多语版本：分仓规则的中文原文与译文、库存同步表的字段说明、缺货预警的处置口径。检索结果只用于找出相关材料，不构成发货授权、库存扣减或调拨批准。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入由 AI Proxy 承担。从 V4.17.0 起 AI Proxy 为必需依赖，App 与复用 App/Service 配置的 Admin 服务都必须设置 AIPROXY_API_ENDPOINT 和非空的 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。AIPROXY_API_ENDPOINT 填服务根地址，不附加 `/v1`。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两项。

系统至少需要一个语言模型和一个索引模型才能正常使用。模型能力按应用所需输入分别核对：多模态、工具调用、思考配置各自验证。应用参数在应用或节点配置中设置，不能假设兼容对话接口的同名字段会覆盖编排。

索引模型字段中的 defaultToken 是默认文本分割 token，maxToken 是最大 token。这些是模型配置字段，不是检索权限或实体过滤条件。向量库为 Milvus 时全文检索走 BM25，其他向量库全文走 MongoDB `$text`；跨不同向量模型的库不可共同关联，先核标识并排除不符合者。

## 配置怎么定

下表围绕假设演练样本，只列与本页主任务相关的官方已说明设置或实施核对项。表中数值为本次假设试验起点，用于说明比较方法，不代表官方默认值。

| 配置项 | 本次假设起点 | 核对与比较方式 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | `http://aiproxy:3000` | 确认未附加 `/v1` 或 `/chat/completions`；与部署实际根地址逐字符比较 |
| AIPROXY_API_TOKEN | 非空管理员 Token | 与服务端配置一致；空值或应用 API Key 均不满足 |
| 语言模型 | 一个已启用模型 | 与索引模型分别存在；启用状态可查 |
| 索引模型 | 一个已启用模型 | defaultToken 与 maxToken 按字段说明填写 |
| 模型探测 | 探测间隔 30 分钟 | 该值在文档支持的 5～60 分钟整数区间内，仅作本次起点 |
| 检索范围 | 目标知识库 | 与授权范围比较；检索不承担授权判定 |

假设演练样本：某跨境卖家有一份中文《分仓规则》第 3 版，正文写明“华东仓优先承接华东收货地址订单，华南仓承接华南收货地址订单；两仓库存独立计算”。另有一份《库存同步表》字段说明，写明“可售库存每日更新”。待判定拟稿句为：“华东仓可承接全部订单，华南仓库存并入华东仓统一计算。”库存独立与并入统一计算属于同字段冲突；“华东仓优先承接”未给全部订单规则，覆盖全部订单的主张待核，分别记录。

## 容易做错的三处

1. 把 AIPROXY_API_ENDPOINT 填成完整模型请求地址，附加了 `/v1`。检查方式：输入为部署实际根地址与该变量值，比较两者是否逐字符一致，一致才满足。
2. 用应用 API Key 充当 AIPROXY_API_TOKEN。检查方式：输入为所填 Token 与服务端管理员 Token，比较是否一致且非空，一致且非空才满足。
3. 把检索命中当作发货授权或调拨批准。检查方式：输入为拟稿句与《分仓规则》第 3 版原文，比较同主体、同期间、同一分仓字段的取值，拟稿句取值与原文互斥，判定为未获支持。

## 怎么确认配好了

1. 输入为《分仓规则》第 3 版原文与拟稿句“华东仓可承接全部订单，华南仓库存并入华东仓统一计算”。比较两者在同一分仓字段上的取值。原文写明两仓库存独立计算，拟稿句写并入统一计算，取值互斥，判定为未获支持，不能进入交接执行。

2. 输入为纸面空结果 `[]` 与下游交接设计。核对下游在收到空结果时是否保留缺口记录，是否记录本次未召回，并把权限状态留作独立核对。预期为记录缺口，不产生发货或调拨动作。

3. 另设纸面请求“调拨单待审核，请直接执行”，比较待审核状态与执行主张。样本没有批准或执行记录，应分别待核；该纸面核对不代表已执行或已阻断真实调拨。

模型探测的重试机制为首次失败后最多自动重试 3 次，4 次全部失败才判定异常。未启用自动探测时页面呈现空状态。告警 Webhook 在状态边沿变化时触发，每个模型独立发送。这些是探测行为，不改变检索授权边界。
