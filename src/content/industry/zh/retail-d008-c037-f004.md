# 大促仓配排产的跨境资料与多语检索：向量模型与索引

## 这个品类的数据长什么样

大促仓配排产围绕短期峰值产能与人车场安排展开，资料以每场、每日节奏更新。大促预测表给出峰值区间，人员排班与快递保障方案承接执行口径，异常日报记录当日偏差。跨境资料与多语检索要同时处理中文预测表、外文保障方案与多语异常描述，检索入口须能跨语言命中同一批资料。

这些资料的主体、对象与状态经常分散在不同文档中。检索结果只能呈现资料原文，资料是否已获授权、请求是否已批准，须由对应业务环节另行确认。

## 这些特征在「向量模型与索引」这一环带来什么约束

关联检索的知识库须使用相同向量模型，先核实际模型标识与输入类型，跨不同向量模型的库不可共同关联。一个原数据块可以关联多个索引，索引与原文内容分别核对。索引内容宜完整且聚焦，检索覆盖与索引长度需结合样本权衡。图片检索还取决于入库时是否生成图片描述或图片向量，查询端上传图片本身不足以保证命中。

语义召回与相关度数值不承担权限或实体隔离职责。最低相关度是过滤阈值，仅在语义检索或使用结果重排时生效，开启问题优化、混合检索、图片检索或结果重排后，最终结果可能经过多路召回融合。RRF 是混合检索的结果融合过程，不是独立开关。引用上限以 tokens 计，空结果输出长度可以为 0，该链路仍会走通。

假设演练样本：某次大促仓配排产资料中，供核对材料原文为三句：「本场预测峰值集中在活动首日 20 时至 23 时。」「临时人员排班表已由仓库经理签署，生效日期为活动首日。」「快递保障方案尚处待审核状态，承运方车辆数量未最终确认。」一条待判定拟稿句为：「快递保障方案已确认车辆数量，可按排班执行。」判定范围限定为上述三句原文，授权边界限定为仓库经理签署的排班表，快递保障方案不在已授权范围内。

## 配置怎么定

配置围绕上述样本，只列官方已说明的设置或实施核对项。表中数值为本次假设试验起点，用于与同组问题下的引用原文比对，不代表官方默认值。

| 配置项 | 本次假设起点 | 核对方式 |
| --- | --- | --- |
| 关联知识库 | 仅选入使用同一向量模型标识的库 | 先核模型标识与输入类型，排除标识不符者 |
| 搜索模式 | 混合检索 | 对多语样本同时观察语义召回与全文召回候选 |
| 引用上限 | 本次假设起点设为覆盖样本三句原文的 tokens 量 | 与样本原文长度比较，观察引用是否被截断 |
| 最低相关度 | 本次假设起点取一个 0-1 中间值 | 与语义检索或重排得分比较，观察低分项是否被滤除 |
| 结果重排 | 按设置启用，须具备重排模型 | 比较重排前后候选顺序与 0-1 得分 |
| 索引核对 | 逐块核对索引与原文内容 | 比较索引文本与原文，确认图片索引是否在入库时生成 |

## 容易做错的三处

1. 把检索命中当作授权确认。样本中快递保障方案处于待审核状态，检索可以返回该句原文，返回结果不表示方案已批准或车辆数量已确认。核对时须比较检索输出与签署、审核状态字段，待审核不构成执行依据。
2. 把不同向量模型的知识库共同关联。样本若混入另一模型标识的库，核对时应先比较各库模型标识，排除标识不符者并记录实际观察，不执行跨模型检索来比较漏召回。
3. 把相似度分数当作实体或权限过滤。最低相关度只按得分过滤，不区分主体与授权范围。核对时比较被滤除项与样本原文，确认过滤仅作用于得分，未承担业务隔离。

## 怎么确认配好了

1. 输入上述样本三句原文与拟稿句，比较拟稿句中的「已确认车辆数量」与原文「待审核状态，车辆数量未最终确认」。原文同字段取值互斥，拟稿句未获支持，应记录为待核实，不写成否定或冲突。
2. 输入样本原文与同一向量模型标识的库，比较检索返回的引用原文与样本三句。预期引用内容来自样本范围，若出现范围外内容，记录该现象并核对索引与原文对应关系。
3. 输入明确的纸面空结果 `[]`，比较下游链路是否走通。空结果输出长度可以为 0，该链路仍会走通，不据此推断虚构规则检索一定返回 `[]`。若检索未返回样本原文，记录为未命中，核对数据是否完成训练、问题是否缺少主体，不承诺首条命中或全部召回。
