# 客服咨询知识库维护的跨境资料与多语检索：向量模型与索引

## 这个品类的数据长什么样

在客服咨询知识库维护的跨境资料与多语检索中，本页说明FastGPT的向量模型与索引如何衔接资料。沿售后问答中的例外条件比较中英索引，区分答复建议与实际退款结果。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

客服知识练习可拟两段对应文字：中文问答写“拆封后须先核商品状态，是否接收另行回复”，英文测试对照同样保留先核与待回复。另有旧答复示例只解释未拆封情形。为“已拆封能否退”拟英文搜索入口时，opened只是对象特征，不应把另行回复消成已同意退货。先看搜索文字回指哪份原数据，再核返回的句子是否包含商品状态这一前提。不同语言入口可以指向同一段资料，但入口数量不能证明例外条件已经译对，也不能把旧例题中的结论借给当前情形。

## 配置怎么定

| 客服多语核对 | 本题原文身份 | 应保存的证据 |
| --- | --- | --- |
| 例外条件 | 已拆封须先核商品状态 | 两语均保留先核，不补成直接接收。 |
| 待定动作 | 是否接收另行回复 | 核回复主体及是否真的已有本件结论。 |
| 旧答复用途 | 只说明未拆封情形 | 标出旧例适用条件及当前问题差异。 |
| 索引回指 | 英文入口与实际原数据 | 查看opened是否指向有该条件的原句。 |
| 处理结果 | 政策文字与实际退款凭证 | 分别列出可解释规则和可证明执行的资料。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 英文入口将待回复写成accepted时，并列两语原句及索引，核同意退货这一状态在哪一步增加。

- 已拆封问题只返回未拆封旧例时，核命中的原数据及适用商品状态，不能因都有退货字样就沿用结论。

- 返回资料保留先核条件，答复却直接宣布退款时，对照候选、实际引用及答复，查条件在哪一环被删。

## 怎么确认配好了

验收分别用中英问法询问拆封状态、谁还需回复及目前能确定什么，查看实际回指原句。补入本件回复后，核它对应同一商品和请求，再检查哪一条结论得到新增依据。若两份资料位于同一搜索节点关联的库，向量模型的一致性在该节点核验；模型一致不等于两语含义一致。这里仅比较自拟问答，不接收商品、不审批退货，也不执行退款。没有本件处理凭证时，检索到政策仍不能报告本件已处理。
