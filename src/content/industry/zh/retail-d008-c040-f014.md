# 客服咨询知识库维护的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

知识库维护处理的是前置问答资料，FAQ条目、话术模板、商品参数表、升级工单构成主要文档集合。跨境场景下这些资料常以多语版本并存，同一商品参数在不同语种条目中需要保持字段口径一致。资料更新按周或按月推进，新品参数同步与高频问题汇总占用的时间最多。这一环节不直接审批退款，答非所问会带来投诉升级与客服培训失败。

## 这些特征在「模型接入与配置」这一环带来什么约束

多语资料进入检索前，需要先确认语言识别与索引模型的关系。Milvus 作为向量库时，全文检索走 BM25，语言识别引擎由 `MILVUS_LANGUAGE_IDENTIFIER` 决定，可选 `lingua` 或 `whatlang`。其他向量库的全文检索走 MongoDB `$text`。跨不同向量模型的库不可共同关联，只能先核对模型标识，排除不符合条件的库，再记录实际观察到的检索结果。相似度分数不承担权限或实体隔离职责，检索本身不构成授权。

模型接入依赖 AI Proxy。从 V4.17.0 起，App 与复用 App/Service 配置的 Admin 服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空的 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败。`AIPROXY_API_ENDPOINT` 填服务根地址，不附加 `/v1`。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。系统至少需要一个语言模型和一个索引模型才能正常使用。

假设演练样本：某知识库运营整理一份多语 FAQ，原文为「本批次商品参数表适用于 2026 年 3 月 1 日至 3 月 31 日上架的 A 类商品，参数项含材质与尺寸，语种为中文与英文」。拟稿句为「该参数表覆盖全部在售商品」。待判定的交接请求为「请将上述参数表接入索引模型并启用多语检索」。原文限定了时间范围、商品类别与字段项，拟稿句扩大了主体范围，交接请求未说明授权状态。

## 配置怎么定

以下设置围绕本页主任务，数值为本次假设试验起点，用于与同字段其他取值比较，不作为官方默认值。

| 配置项 | 本次假设起点 | 选择理由与比较对象 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填入 AI Proxy 根地址 | 与附加 `/v1` 的写法比较，确认不附加路径 |
| `AIPROXY_API_TOKEN` | 填入非空管理员 Token | 与应用 API Key 比较，确认不使用应用 Key 代替 |
| `MILVUS_LANGUAGE_IDENTIFIER` | 设为 `lingua` | 与 `whatlang` 比较，按多语资料的语言识别需求选择 |
| 索引模型 | 启用一个索引模型 | 与未启用状态比较，确认系统具备索引能力 |
| 语言模型 | 启用一个语言模型 | 与未启用状态比较，确认系统具备对话能力 |
| 模型状态探测 | 设为 5 分钟间隔 | 与 60 分钟比较，按核对频率需求选择 |

模型映射按配置核上游目标；可用性探测与材料授权是独立检查，探测成功不说明资料已获授权。

## 容易做错的三处

1. 把相似度分数当作权限过滤器。输入为一次检索请求，比较对象是返回记录的权限归属，观察结果是分数高低与记录授权状态无对应关系。分数不承担实体隔离职责，检索不构成授权。

2. 跨不同向量模型的库执行共同关联。输入为两个模型标识不同的知识库，比较对象是两者的向量模型字段，观察结果是标识不一致。此时应排除不符合者并记录观察，不推断共同关联后的运行结果。

3. 把未载明授权的交接请求当作已获授权执行。输入为「请将参数表接入索引模型并启用多语检索」这一请求，比较对象是授权状态字段，观察结果是该请求未载明批准。待审核不证明缺少操作权限，也不构成执行依据。

## 怎么确认配好了

1. 针对假设样本原文，输入为「本批次商品参数表适用于 2026 年 3 月 1 日至 3 月 31 日上架的 A 类商品，参数项含材质与尺寸，语种为中文与英文」。比较对象是拟稿句「该参数表覆盖全部在售商品」中的主体范围。观察结果是原文限定了时间、类别与字段，拟稿句扩大了覆盖范围，两者在同一字段上取值不一致，拟稿句未获原文支持。

2. 针对交接请求，输入为「请将上述参数表接入索引模型并启用多语检索」。比较对象是授权状态记录。现有请求未给授权记录，授权状态待核；不从缺记录直接判成待审核或已拒绝。若需执行，须补充明确的授权记录；缺失时记录证据缺口。

3. 针对多语检索配置，输入为已启用索引模型与语言模型、`MILVUS_LANGUAGE_IDENTIFIER` 设为 `lingua` 的环境。比较对象是索引模型标识与向量库模型标识。观察结果是标识一致时方可共同关联；标识不一致时排除该库并记录观察。空结果场景可用明确的纸面输入 `[]` 核对下游设计，不声称虚构规则检索一定返回 `[]`。
