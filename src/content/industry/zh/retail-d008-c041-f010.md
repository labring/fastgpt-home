# 平台促销报名与价格管理的跨境资料与多语检索：引用来源与溯源

## 这个品类的数据长什么样
促销报名围绕价格、库存与活动节奏展开，主要材料为活动报名表、促销价审批单、库存锁定表、活动复盘表。资料更新按周或每场活动发生，同一场活动常同时存在中文报名表与英文审批单。跨境场景下，检索需要跨语言找到同一活动的原始材料，并让回答逐条指回原文。材料本身不构成授权：报名表收集字段，审批单记录审批意见，库存锁定表记录锁定范围，三者状态各自独立。

## 这些特征在「引用来源与溯源」这一环带来什么约束
知识库搜索节点可关联一个或多个相同向量模型的知识库，输出为数组格式的引用内容，长度可以为 0，没有搜索到内容时该输出链路仍然走通。引用上限按 tokens 控制单次搜索最多引用的内容量，最低相关度是过滤阈值，仅在语义检索或使用结果重排时生效，二者都不承担权限或实体隔离。混合检索经 RRF 融合多路结果，重排得到 0-1 得分，这些分数只反映相关程度。检索到某份材料不等于该材料已获批准，也不等于价格已生效。

假设演练样本：某品牌销售计划人员为一场平台促销准备材料。中文活动报名表载明“活动期间 2026-03-01 至 2026-03-07，报名状态：已提交，促销价审批单编号 A-207 待审核”。英文促销价审批单载明“Approval ID A-207, status: pending review, valid quote period 2026-02-20 to 2026-02-28”。待判定拟稿句为“该活动促销价已获审批，可按 A-207 执行”。原文只显示审批处于待审核，未载明批准结论，也未载明报价有效期与供货期限的关系，因此该拟稿句未获支持。

## 配置怎么定
| 配置或核对项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| 关联的知识库 | 中文报名表库、英文审批单库 | 两库须为相同向量模型才可共同关联，先核标识，不符者排除 |
| 搜索模式 | 混合检索 | 报名表含活动编号与日期，审批单含编号 A-207，语义与全文各有适用处 |
| 引用上限 | 本次假设试验起点 2000 tokens | 该值为假设起点，用于比较不同取值下引用条数与截断现象 |
| 最低相关度 | 本次假设试验起点 0.5 | 该值为假设起点，仅在语义检索或结果重排时生效，比较过滤前后候选 |
| 结果重排 | 启用 | 混合检索后范围较大，用重排 0-1 得分观察排序变化 |
| 引用输出承接 | 逐条核对回答与引用原文 | 检查引用数组是否交给回答环节，空数组按未命中处理 |

## 容易做错的三处
1. 把检索命中当作审批完成。输入是含 A-207 待审核的审批单，比较对象是拟稿句“已获审批”，观察结果是原文只出现 pending review，判定为未获支持。
2. 把报价有效期当作供货期限。输入是 valid quote period 2026-02-20 至 2026-02-28，比较对象是活动期间 2026-03-01 至 2026-03-07，观察结果是两个日期范围不同字段，供货期限未载明。
3. 把最低相关度当作权限过滤。输入是同一库内不同活动的材料，比较对象是相关度得分与访问授权，观察结果是得分高低不排除未授权记录，权限须由下游实现。

## 怎么确认配好了
1. 用上述样本检索 A-207，输入为中文报名表与英文审批单原文，比较回答是否逐条指向原文，观察结果是每条引用可回溯到对应材料，且未把待审核写成已批准。
2. 用纸面输入空引用数组 [] 核对下游设计，比较下游是否按未命中分支处理，观察结果是链路走通且未伪造来源。
3. 用不同向量模型的两个库核对关联条件，输入为两库标识，比较向量模型是否一致，观察结果是不一致时排除该库并记录实际观察，不执行跨模型检索。
