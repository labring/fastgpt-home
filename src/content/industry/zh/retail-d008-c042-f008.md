# 平台商品标题与详情合规的跨境资料与多语检索：工作流编排

## 这个品类的数据长什么样

在平台商品标题与详情合规的跨境资料与多语检索中，本页说明FastGPT的工作流编排如何衔接资料。标题、素材和检测说明在跨语处理时保持原来范围，不由某个词替代事实或法规判断。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

商品标题跨语流程可收标题原句、已有译写与本商品检测说明，只核材料对应，不提供法律结论或禁词规则。自拟输入没有完整适用要求，表单应把待补范围传下去，不从词语换写推定宣传已通过。人员可选择回原文、补商品依据或交实际负责人核范围；流程不自动完成广告审核，也不由素材库文件名猜出商品认证。

## 配置怎么定

| 跨语流程核对 | 本题自拟材料 | 实际承接依据 |
| --- | --- | --- |
| 表述程度 | 条件原句与已有译写 | 未扩大确定性能 |
| 检测范围 | 本商品与报告样本 | 他物报告没有代填 |
| 要求缺口 | 词表不含全部适用依据 | 未充作审核批准 |
| 补证路径 | 核原文或补对应来源 | 接收保留同一对象 |
| 正式发布 | 修改素材和回写另验 | 整理未代替合规结论 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

程度扩大：若原文条件性描述被译成确定性能，应查对应依据及限定原句；检测对象错配：若其他商品报告套当前标题，应核商品和样本范围；词表冒批准：若只查某份清单就宣布已合规，应核本题真实适用要求与审批记录。三项分别核表述、证据对象和业务判断，不由分支选择补出。

## 怎么确认配好了

验收保留原文、译写、资料版本与实际接收值，补对应商品或要求说明后复问，核每句仍能回指来源。各“是”分支连接逐一查，交互状态不代表已审核。标题修改、素材发布和外部回写需另验授权及真实回执；本次整理只说明资料承接，不证明产品性能、平台接受或法律要求已经满足。
