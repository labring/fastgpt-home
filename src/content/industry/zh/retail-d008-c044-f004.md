# 平台广告投放与站内流量的跨境资料与多语检索：向量模型与索引

## 这个品类的数据长什么样

在平台广告投放与站内流量的跨境资料与多语检索中，本页说明FastGPT的向量模型与索引如何衔接资料。在投放说明的两语索引中保留计划和已执行阶段，不由素材建议推广告效果。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

投放资料练习可拟创意便笺“拟用清洁步骤画面，落地页文案待核”，英文测试文字保持计划与待核。另一份历史素材表只记旧画面已上传，没有说明本轮广告已上线或获得效果。若英文入口把planned creative写成running ad，搜索层就已补出执行状态。画面上传、广告上线和业务结果需要各自记录；索引可帮助找到便笺，不能把三件事合成一项已完成。所用清洁步骤只是自拟素材名称，没有提供清洁效果测试，也不支持由画面主题添加产品功效。

## 配置怎么定

| 投放多语核对 | 拟议素材 | 核验动作 |
| --- | --- | --- |
| 计划状态 | 拟用清洁步骤画面 | 两语不得添广告已运行。 |
| 事件区别 | 上传、上线、结果各自记录 | 逐条找本轮事件所需原文。 |
| 版本身份 | 旧上传与本轮素材 | 核活动及素材对应关系。 |
| 待审文字 | 落地页文案尚待核 | 实际审核结论另找记录。 |
| 素材用途 | 画面主题不是功效实测 | 检索命中不补效果或认证。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 计划画面被英文入口写成广告运行时，核两语阶段词及索引原数据，定位上线状态的新增。

- 旧画面上传记录被用于本轮效果时，核素材版本、活动身份和事件类型，不把上传当成表现数据。

- 落地页待核在回答中变成已通过时，对照原句、引用和答复，查审核结论缺少哪份记录。

## 怎么确认配好了

验收中英分别问拟用什么、目前哪一步有记录、落地页是否核毕，查看每项实际引用。补入本轮上线或审核材料时，各自核对象与事件时间；晚收到材料不等于晚执行。对同一原数据增设两语索引后，仍需比较实际回指，不能用两种问法都命中证明功效或投放效果。共同关联库按同一搜索节点核向量模型，不由此推语言改写可靠。本练习不发布广告、不审核营销宣称，也不给出任何效果数值。
