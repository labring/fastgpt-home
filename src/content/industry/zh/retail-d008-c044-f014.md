# 平台广告投放与站内流量的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

广告投放与站内流量的资料围绕投放计划、关键词报表、人群包说明和转化归因表展开。投放按流量和转化实时调价，数据来源包括巨量千川、京东快车、阿里妈妈和店铺成交数据，更新频率为日或小时。跨境场景下，同一份投放计划可能同时存在中文版和英文版，关键词报表涉及多语词条，人群包说明需要跨语言核对受众定义，转化归因表则要对照不同币种和时区的成交记录。这些材料在检索时以文本块形式进入知识库，模型接入与配置决定了跨语资料能否被正确索引和召回。

## 这些特征在「模型接入与配置」这一环带来什么约束

FastGPT 自 V4.17.0 起，AI Proxy 为必需依赖。App 和复用 App/Service 配置的 Admin 服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空的 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。模型配置在管理员-模型提供商页面进行，渠道配置中的代理地址填写 BaseUrl，不填完整的模型请求地址。系统至少需要一个语言模型和一个索引模型才能正常使用。语音识别模型仅生效一个。

跨境多语检索涉及索引模型对多语文本块的处理。索引模型配置中的 `defaultToken` 和 `maxToken` 决定文本分割和向量化范围。语言模型的多模态能力、工具调用能力需按应用所需输入分别核对。检索库使用同一索引模型是关联前提，不同向量模型的库不可共同关联，需先核标识并排除不符合者。

假设演练样本：某投放专员提交一份交接材料，原文为：“2026年9月1日至9月30日，计划A在巨量千川的日预算为人民币800元，目标ROI为2.5。关键词报表中‘夏季防晒’词条的中文版已确认，英文版‘summer sunscreen’待翻译核对。人群包说明中‘高消费女性’的定义为近30天客单价大于500元。”拟判定句：“计划A在2026年9月的日预算为800元，目标ROI为2.5，可直接用于英文版投放。”待核请求：“请将上述材料接入多语检索库，用于英文版投放计划核对。”

## 配置怎么定

以下配置项围绕上述样本的模型接入与检索核对。数值为本次假设试验起点，用于与文档中对应变量的行为比较。

| 配置项 | 本次假设起点 | 核对方式 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填写 AI Proxy 服务根地址，不附加 `/v1` | 与文档说明的根地址格式比较，确认不含 `/v1` 或 `/chat/completions` |
| `AIPROXY_API_TOKEN` | 填写与服务端一致的非空管理员 Token | 与文档说明比较，确认非空且不使用应用 API Key 代替 |
| 索引模型 `maxToken` | 假设设为 3000，与样本中英文词条长度比较 | 与文档字段说明比较，确认覆盖样本文本块长度 |
| 语言模型 `vision` | 假设设为 true，与样本是否含图片输入比较 | 与文档字段说明比较，确认样本无图片输入时该能力非必需 |
| 模型渠道代理地址 | 填写 BaseUrl，不填完整请求地址 | 与文档说明比较，确认格式为 BaseUrl |
| `MILVUS_LANGUAGE_IDENTIFIER` | 假设使用 `lingua`，与多语词条语言识别需求比较 | 与文档说明比较，确认 Milvus 全文检索走 BM25 |

## 容易做错的三处

1. 将 `AIPROXY_API_ENDPOINT` 填写为完整请求地址并附加 `/v1`。输入为带 `/v1` 的地址，比较文档说明的根地址格式，可观察到格式不符。
2. 用应用 API Key 代替 `AIPROXY_API_TOKEN`。输入为应用 API Key，比较文档说明的管理员 Token 要求，可观察到凭证类型不符。
3. 将拟判定句中的“可直接用于英文版投放”视为已确认。输入为拟判定句，比较样本原文，原文仅表明英文版待翻译核对，未载明英文版投放已获授权，可观察到该判定未获支持。

## 怎么确认配好了

1. 输入样本原文中“2026年9月1日至9月30日，计划A在巨量千川的日预算为人民币800元，目标ROI为2.5”，比较拟判定句“计划A在2026年9月的日预算为800元，目标ROI为2.5”。同一主体、同一期间、同一字段取值一致，满足条件。
2. 输入样本原文中“英文版‘summer sunscreen’待翻译核对”，比较拟判定句“可直接用于英文版投放”。原文仅载明待核对状态，未载明翻译已完成或投放已授权，该判定未获支持，需记录证据缺口。
3. 输入待核请求“请将上述材料接入多语检索库，用于英文版投放计划核对”，比较样本原文的授权状态。原文未载明该请求已获批准，检索接入为待审核状态，不构成授权执行。若检索返回空结果，以明确的纸面输入 `[]` 核对下游设计，不声称虚构规则检索一定返回空。
