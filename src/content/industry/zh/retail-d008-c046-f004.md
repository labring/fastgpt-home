# 平台类目资质准入的跨境资料与多语检索：向量模型与索引

## 这个品类的数据长什么样

在平台类目资质准入的跨境资料与多语检索中，本页说明FastGPT的向量模型与索引如何衔接资料。核材料收集、主体证件与类目准入的不同用途，保留双语目录的缺件标记。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

类目资料练习可拟目录“经营主体证件已收，品牌授权页待补；本表只供材料收集”。英文测试对照保留received和awaiting submission的区别。另有另一类目的历史核对表，不能用它说明本次类目已经通过。若英文入口将documents collected概括成category approved，索引就从收集阶段跨到审核结论。主体身份、品牌授权与类目范围各需对应资料，不能因为证件同属于一家企业就互相替代。此处不列实际准入条件或法律要求，只演示怎样追踪所给目录的文字边界。

## 配置怎么定

| 类目多语核对 | 目录信息 | 具体动作 |
| --- | --- | --- |
| 收件范围 | 主体证件已收 | 仅确认所列材料收到。 |
| 缺件身份 | 品牌授权页待补 | 保留待补与授权对象。 |
| 类目范围 | 旧表属于另一类目 | 原句及实际处理事项分别核。 |
| 文件用途 | 材料收集用表 | 不升级成准入处理结果。 |
| 补充资料 | 授权页与本次回执 | 分别核品牌主体范围和类目决定。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 已收主体证件被入口写成已获品牌授权时，核材料名称、授权对象和待补标记，指出缺少的对应页。

- 历史另一类目表被用于本次通过结论时，核类目身份和实际处理记录，不能由企业相同推定范围相同。

- 材料收集表被答复写成正式准入决定时，对照表用途、实际引用与审核回执，核结论来自哪份资料。

## 怎么确认配好了

验收用中英分别问哪些已收、哪些待补以及有没有本类目决定，查看实际索引目标和引用原句。取得授权页后先核品牌、主体与适用范围；收到处理回执后另核类目和事项，两者不是一份资料的两个名称。多个语言入口可以围绕同一目录设置，但新增入口不补缺件，也不执行审核。同一检索节点关联多个库时核实际向量模型一致，语义与资料身份仍需逐项检查。本例不作法律判断或平台资格保证。
