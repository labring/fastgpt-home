# 平台类目资质准入的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

类目准入在上架或入驻前核主体资质与授权链，材料包括营业执照、商标注册证、品牌授权链和行业许可证。跨境检索需核原件与译件是否为同一材料，保留语种、主体与授权范围。资料不定期更新，每次入驻重收；更新频率不能替代版本核验。

## 这些特征在「模型接入与配置」这一环带来什么约束

FastGPT依赖AI Proxy。App与复用App/Service配置的Admin服务须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺失会启动校验失败；旧OpenAI环境变量或单模型地址不能替代。系统至少需要一个语言模型和一个索引模型，多语能力按选用模型和实际语种测试。模型映射核请求标识与上游目标。自动探测仅覆盖已启用模型，首次失败后最多重试3次，4次全失败才判异常；成功且延迟不超过30秒为正常，成功但超过30秒为高延迟。模型可用性与检索内容质量分别核。

## 配置怎么定

以下配置项围绕跨境资料与多语检索的模型接入环节，列出与本任务直接相关的官方已说明设置或实施核对项。

| 配置项 | 本页用途 | 核对方式 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | AI Proxy 服务根地址，不附加 `/v1` | 与环境变量文档示例格式比对，确认无多余路径 |
| `AIPROXY_API_TOKEN` | AI Proxy 管理员 Token，非空 | 与服务端配置比对，确认一致且非空 |
| 模型渠道协议类型 | 对应模型提供商的协议 | 在管理后台渠道配置页核对协议类型与厂商匹配 |
| 模型映射 | FastGPT 请求模型到上游模型的映射 | 核对映射键值对，例如 `gpt-4o-test` 映射到 `gpt-4o` |
| 索引模型 | 对文本块进行索引，供相关文本检索 | 确认至少启用一个索引模型，并核对多语种处理能力 |
| 模型状态探测 | 周期性测试已启用模型的可用性 | 核对探测范围是否仅覆盖已启用模型，单轮尝试是否为1至4次 |

假设演练样本：某跨境商家拟向平台提交一份品牌授权链材料，原文包含三句。第一句为「授权方：某某品牌管理有限公司；被授权方：某某贸易有限公司；授权品牌：ABC；授权期限：2025年1月1日至2026年12月31日」。第二句为「本授权仅限中国大陆地区线上销售渠道使用」。第三句为「本授权书自双方盖章之日起生效」。待判定的拟稿句为「该授权覆盖目标市场线上销售，有效期限至2026年12月31日」。核对时需比较拟稿句中的「目标市场」与原文第二句的「中国大陆地区」是否一致，以及拟稿句的「有效期限」与原文第一句的「授权期限」是否同字段。样本未定义目标市场，地域覆盖待核；所载期限可引用，双方盖章事实未提供，授权是否已生效仍待核。配置表中索引模型的多语种处理能力需按实际选用的模型核对，不假设所有索引模型对中文与目标市场语言效果相同。

## 容易做错的三处

1. 将 `AIPROXY_API_ENDPOINT` 填写为包含 `/v1` 或 `/chat/completions` 的完整请求地址。环境变量文档说明该值为服务根地址，例如 `http://aiproxy:3000`，不附加 `/v1`。检查时输入该变量值，与文档示例格式比对，确认路径部分仅为根地址，出现 `/v1` 或 `/chat/completions` 即不满足条件。

2. 在模型映射中把 FastGPT 请求的模型 ID 与上游实际模型 ID 混用。模型映射的作用是将 FastGPT 请求的模型映射到具体提供的模型上，例如 `gpt-4o-test` 映射到 `gpt-4o`。检查时输入映射配置的键值对，比较键是否为 FastGPT 中使用的模型 ID、值是否为上游实际模型 ID，应按所配置规则核目标；是否异名本身不能判定映射对错。

3. 将模型状态探测的「异常」判定等同于检索结果为空或资质材料不合格。探测的异常判定条件是连续 4 次请求均发生错误，与检索结果内容无关。检查时输入探测配置中的重试次数与判定条件，比较实际探测记录中的尝试次数与错误信息，确认异常判定仅针对模型请求失败，不涉及检索结果或材料内容。

## 怎么确认配好了

1. 输入三句授权原文与拟稿句，分别核地域、期限和生效条件。目标市场未定义，只能保留原文“中国大陆地区线上销售”；截止2026年12月31日为所载期限，盖章事实缺失，不能据此称当前已生效。

2. 输入映射配置与实际请求日志，核FastGPT模型标识是否按配置指向上游目标。键值同名或异名均不能单独判错；无日志则执行结果待核。

3. 输入所选索引模型与同一授权材料的原件、译件样本，核语种支持及实际召回片段是否对应同一主体与范围。缺译件、能力说明或返回记录时分别待核，不预设为空或必然命中。

以上为纸面核对。状态告警、材料审核与授权生效独立记录，检索分数不能替代权限或主体核验。
