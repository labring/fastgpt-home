# 平台退款退货处理的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

普通平台退款按订单持续发生，不一定关联单场直播承诺，因此跨境资料与多语检索面对的是逐单生成的退款申请、退货物流单、质检照片与退款审批。这些材料可能以不同语言书写，来自平台售后后台、客服聊天、WMS 收货与支付退款记录。资料更新频率为每单与每日，检索需求随订单产生。模型接入与配置这一环要解决的是：让语言模型与索引模型能够读取这些材料并完成跨语言检索，同时不把检索结果当成授权结论。

## 这些特征在「模型接入与配置」这一环带来什么约束

从 V4.17.0 起，AI Proxy 为必需依赖。App 和复用 App/Service 配置的 Admin 服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空的 `AIPROXY_API_TOKEN`；缺少任一项会导致启动校验失败。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。`AIPROXY_API_ENDPOINT` 填写 AI Proxy 服务根地址，不要附加 `/v1`。`AIPROXY_API_TOKEN` 必须与服务端配置一致且不能为空，不能用应用 API Key 代替。

系统至少需要一个语言模型和一个索引模型才能正常使用。模型渠道配置中，模型映射把 FastGPT 请求的模型映射到上游实际模型；代理地址填 `BaseUrl`，注意是否需要增加 `/v1`。检索结果的相关度分数不承担权限或实体隔离功能，检索行为本身不构成授权。

假设演练样本：某平台售后专员收到一笔跨境退货，材料原文为三句。第一句，退款申请载明“订单号 A-1001，申请日期 2026 年 3 月 5 日，退款原因：商品与描述不符，申请状态：待审核”。第二句，退货物流单载明“运单号 SF-7788，收件仓库：深圳保税仓，签收日期 2026 年 3 月 8 日”。第三句，质检照片说明载明“照片编号 QC-03，拍摄日期 2026 年 3 月 9 日，质检结论：外观完好，功能待复测”。待判定的拟稿句为：“该订单已完成退货并批准退款。”此样本中，退款申请状态为待审核，物流单显示已签收，质检结论为功能待复测。拟稿句声称已完成退货并批准退款，与材料载明的待审核状态和待复测结论不一致。

## 配置怎么定

下表为本页纸面接入检查，试验起点不代表官方默认值。

| 配置项 | 本次假设试验起点与理由 | 比较方法与观察对象 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 填写 AI Proxy 服务根地址，不附加 `/v1` | 与文档说明的根地址格式比较，确认未附加路径后缀 |
| `AIPROXY_API_TOKEN` | 填写与服务端一致的非空管理员 Token | 与服务端配置比较，确认非空且一致 |
| 语言模型 | 启用一个语言模型用于文本对话 | 在模型提供商页面确认已启用，且模型测试通过 |
| 索引模型 | 启用一个索引模型用于文本块索引 | 在模型提供商页面确认已启用，且模型测试通过 |
| 模型映射 | 按样本所需模型配置映射关系 | 比较 FastGPT 请求的模型与上游实际模型是否对应 |
| 模型能力 | 按样本所需输入核对模型能力 | 多模态、工具调用分别验证，不假设同名参数可覆盖编排 |

## 容易做错的三处

1. 把待审核状态当成已批准。样本中退款申请状态为“待审核”，拟稿句写“批准退款”。输入为退款申请原文与拟稿句，比较对象为申请状态字段与拟稿句中的批准表述，观察结果为两者是否一致。待审核不证明已批准，也不证明缺少操作权限。
2. 把已签收当成已完成退货。样本中物流单显示签收日期，质检结论为功能待复测。输入为物流单原文与质检照片说明，比较对象为签收事实与退货完成事实，观察结果为材料是否载明退货完成。签收与退货完成是不同事实。
3. 把检索命中当成授权执行。输入为检索请求与返回结果，比较对象为检索结果与授权状态，观察结果为检索是否产生授权效力。检索是信息获取行为，业务验证、审批、数据库写入与外部同步需要各自的下游实现。

## 怎么确认配好了

1. 使用样本原文核对拟稿句。输入为退款申请原文、退货物流单原文、质检照片说明与拟稿句。比较对象为申请状态字段与拟稿句的批准表述。满足条件为拟稿句与材料载明状态一致；若材料状态为待审核，拟稿句不应出现批准退款表述。预期结果为发现不一致，记录证据缺口。
2. 使用样本原文核对退货完成状态。输入为退货物流单原文与质检照片说明。比较对象为签收事实与退货完成事实。满足条件为材料载明退货完成；若仅有签收与待复测结论，退货完成未获支持。预期结果为记录待核实，不声称已完成。
3. 使用空结果输入核对下游设计。输入为纸面输入 `[]`，比较对象为下游流程对空结果的处理设计。检查设计是否区分无引用与授权状态；未说明该分支才记设计缺口。实际查询是否返回[]待测，不因纸面输入直接断言设计有缺陷。
