# 批发市场档口交易的跨境资料与多语检索：向量模型与索引

## 这个品类的数据长什么样

在批发市场档口交易的跨境资料与多语检索中，本页说明FastGPT的向量模型与索引如何衔接资料。在档口询价的两语入口中保留计量对象、意向与实际交货边界。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

档口交易练习可拟询价条“按整箱询货，箱内混款另核”，英文对照写carton enquiry并保留assortment pending。旁边一张样品便条仅列某单款已看样，不能说明整箱全部是同一款，也不证明采购已成交。若英文入口从carton enquiry改成case order，就把询问写成订单；若将case误作某个单品型号，还会混淆计量对象。原数据应保留询价范围及待核项，索引只帮助找到相关文字，不决定箱内组成或实际出货。

## 配置怎么定

| 档口多语核对 | 本题原文 | 具体动作 |
| --- | --- | --- |
| 计量对象 | 按整箱询货 | 区分箱与单品型号。 |
| 箱内组成 | 混款尚待核 | 不从整箱补出全部同款。 |
| 交易阶段 | 只有询价 | 成交另找本次确认依据。 |
| 样品记录 | 某单款已看样 | 不扩大成整箱或订单结果。 |
| 新增资料 | 箱单与订单各有用途 | 核批次对象后分别回答组成与状态。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 整箱被索引成单款整箱时，对照询价条和混款待核句，查新增同款范围来自何处。

- 样品已看被答复写成采购成交时，核样品便条与订单确认依据，两个动作分别留证。

- 英文case被当型号并带入另一商品时，核原句中的计量角色及索引目标，不能由同一个词替换实物对象。

## 怎么确认配好了

验收中英分别问交易处于询问还是确认、箱内组成是否给出、样品便条能证明什么，再查看实际回指。取得箱单或订单材料后，核它对应同一批和同一对象，分别检查组成与交易状态，不能用其中一份补齐所有事实。同一原数据多索引仍应保留carton的计量含义；同一搜索节点关联库核向量模型一致后，继续查具体引用。此例不写入订单，也不确认档口库存、成交或交货结果。
