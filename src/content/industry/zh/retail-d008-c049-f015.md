# 批发市场档口交易的跨境资料与多语检索：知识库检索与召回

## 这个品类的数据长什么样

批发市场档口交易的资料零散程度高于区域经销商补货。进货单、手写销售单、摊位租赁合同、货款收据往往由不同主体在不同时间开出，同一批货的金额、数量、托运信息可能分散在多张纸面上。跨境场景下，同一份资料还可能存在中文与另一种语言的对照版本，检索时需要同时覆盖两种表述。资料更新频率为日、每单，检索侧只需按已有文档建立索引，不因更新频率改变搜索节点行为。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，需先核对向量模型标识并排除不符合者，不执行跨模型检索来比较漏召回。搜索模式可选语义检索、全文检索或混合检索，不预设一种模式适合全部资料。语义检索适合自然语言问题与跨语言语义匹配，全文检索适合编号、型号、专有名词等精确查询，混合检索通过 RRF 融合两路结果。引用上限以 token 为单位，最低相关度仅在语义检索或使用结果重排时生效。问题优化用于指代消除和问题扩展，会增加一次模型调用。图片检索须有相应图像输入及模型能力，重排须具备模型且按设置启用，文档总流程图列出的可选路径不代表每次请求全部执行。输出引用内容以数组格式返回，长度可以为 0，空结果链路仍走通。

假设演练样本：档口老板陈某与采购商签订摊位租赁合同，合同原文写“租赁期自二〇二五年三月一日起至二〇二六年二月二十八日止，月租金人民币八千元，押金两个月”。另有一张手写销售单写“三月五日发牛仔裤三百条，单价四十五元，托运至某地”。一条待判定拟稿句写“该摊位租赁合同已于二〇二六年二月二十八日终止”。判定所需主体为陈某与采购商，对象为摊位租赁合同，期间为上述起止日，状态为合同载明的租赁期。拟稿句称合同已终止，但合同原文只载明租赁期届满日，未载明终止动作或终止确认。租赁期届满与合同终止是两个不同事实，该拟稿句未获支持，属待核实。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 仅关联使用相同向量模型的一个资料库 | 先核对向量模型标识，排除不同模型的库，不执行跨模型检索比较 |
| 搜索模式 | 先按语义检索测试，再按全文检索测试同一问题 | 用同一问题比较两种模式的引用内容，观察编号类与自然语言类问题的差异 |
| 引用上限 | 假设起点为 2000 token | 用于测试长短不同的进货单与租赁合同片段是否被完整引用，与较短上限比较内容完整性 |
| 最低相关度 | 假设起点为 0.4 | 先标注相关与无关样本，再调阈值，仅在语义检索或结果重排时生效 |
| 问题优化 | 先关闭，用完整问题测试 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 具备重排模型时按设置启用 | 重排后得到 0 至 1 得分，按得分过滤，与未重排结果比较排序 |

## 容易做错的三处

1. 把租赁期届满日当作合同终止事实。假设样本中合同原文只写租赁期起止日，拟稿句称合同已终止，二者主体、对象、期间相同，字段取值不同一，属未获支持，需记录证据缺口。
2. 把检索结果当作授权或权限判定。检索命中一份货款收据，只说明该收据在检索范围内被召回，不说明货款已结清或收款已确认。检索不是授权，待审核不证明缺少操作权限。
3. 把跨向量模型的库强行共同关联。文档要求关联相同向量模型的知识库，遇到不同模型标识的库应先排除，不接着编造共同关联后的漏召回或冗余结果。

## 怎么确认配好了

1. 输入假设样本中的摊位租赁合同原文与拟稿句“该摊位租赁合同已于二〇二六年二月二十八日终止”，比较主体、对象、期间、状态四项是否同一。合同原文未载明终止动作时，拟稿句判定为待核实，不判为否定或冲突。
2. 输入手写销售单原文“三月五日发牛仔裤三百条，单价四十五元”，以全文检索模式查询“牛仔裤 三百条”，比较召回内容是否包含该销售单片段。观察引用内容数组是否非空，失败分支为数组长度为 0，此时记录未召回并检查数据是否已完成训练。
3. 输入一条仅涉及另一向量模型库的查询，核对关联知识库的向量模型标识，排除不符合者后不执行跨模型检索。观察是否仅在同一模型库内返回引用内容，未返回结果时记录为未获支持，不推断为漏召回。
