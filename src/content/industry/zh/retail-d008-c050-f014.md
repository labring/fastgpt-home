# 投诉举报与监管回复的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

投诉举报与监管回复面向平台或监管机关，材料需要正式证据与整改文字。主要数据来源为12315平台、平台投诉中心、客服聊天与订单系统，日常文档包括投诉工单、监管询问函、订单证据与整改报告。跨境场景下，同一案件常同时存在多语种工单、境外订单凭证与中文整改稿，检索时需要把不同语言、不同来源的材料归入同一案件脉络。资料不定期、按案更新。本页聚焦模型接入和案件资料对应，不据此判断同步或触发机制。

## 这些特征在「模型接入与配置」这一环带来什么约束

从 V4.17.0 起，AI Proxy 为必需依赖。App 与复用 App/Service 配置的 Admin 服务都必须设置 `AIPROXY_API_ENDPOINT` 和非空的 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败；旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两个配置。`AIPROXY_API_ENDPOINT` 填 AI Proxy 服务根地址，不要附加 `/v1`。系统至少需要一个语言模型和一个索引模型才能正常使用。多语检索依赖索引模型对文本块建立向量，语言模型负责对话与提取；模型能力需按应用实际输入逐项核对，多模态、工具调用与思考配置分别验证，不能假设兼容对话接口的同名字段会覆盖编排设置。检索库若使用同一向量模型方可共同关联；跨不同向量模型的库不能共同关联，应先核对标识并排除不符合者。语义召回与相关度不承担权限或实体隔离职责，检索本身不构成授权。

假设演练样本：某跨境店铺收到一份监管询问函，原文为「本机关于2026年3月10日收到消费者投诉，涉及订单号A-2026-0310，要求被投诉方于收到本函之日起十个工作日内提交书面说明及交易凭证。」拟稿句为「本店已完成整改并提交全部凭证。」待核对的交接请求为「请检索该订单的退款记录并回复监管」。

## 配置怎么定

下表围绕上述样本，列出与本功能、主任务相关的官方已说明设置或实施核对项。表中数值凡标为假设试验起点的，仅为本次纸面演练的取值，需说明选取理由并与对照值比较，不代表官方默认值。

| 配置项 | 本次假设试验起点 | 核对方式与理由 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | `http://aiproxy:3000` | 填根地址，不附加 `/v1`；与启动校验要求比对 |
| `AIPROXY_API_TOKEN` | 假设填入非空管理员 Token | 与服务端配置比对，确认非空且一致 |
| 索引模型 | 假设启用一个索引模型 | 与系统至少一个索引模型的要求比对 |
| 语言模型 | 假设启用一个语言模型 | 与系统至少一个语言模型的要求比对 |
| `MILVUS_LANGUAGE_IDENTIFIER` | 假设为 `lingua` | 仅当向量库为 Milvus 时全文检索走 BM25，与向量库类型比对 |
| 模型探测间隔 | 假设为 15 分钟 | 文档说明支持 5～60 分钟整数，与允许区间比对 |

## 容易做错的三处

1. 把 `AIPROXY_API_ENDPOINT` 写成带 `/v1` 的完整请求地址。输入为配置值，比较对象为文档所述根地址要求，先核根地址格式是否符合文档，整体启动和请求结果待测试。
2. 用应用 API Key 充当 `AIPROXY_API_TOKEN`。输入为 Token 值，比较对象为服务端管理员 Token，可观察结果为鉴权是否被接受。
3. 把检索命中当作已获授权或已提交。输入为检索结果，比较对象为监管函要求的书面说明与凭证是否实际存在，可观察结果为材料是否仍在待核实状态。

## 怎么确认配好了

以下三项验证使用前述假设样本，逐项说明输入、比较与满足条件，均为纸面预期，未实际执行。

1. 输入假设样本原文与拟稿句「本店已完成整改并提交全部凭证。」，比较对象为原文要求的「十个工作日内提交书面说明及交易凭证」。原文只提出提交要求，未载明已提交事实；拟稿句所述完成状态在材料中未获支持，应记为待核实，不得判定为已提交。
2. 输入交接请求「请检索该订单的退款记录并回复监管」，比较对象为检索库中是否存在该订单的退款记录。若检索返回空结果，按明确纸面输入核对下游设计，记录缺口；实际查询是否为空待测试，纸面空数组只用于下游设计核对。检索命中不构成回复监管的授权。
3. 输入假设样本中的订单号 A-2026-0310，比较对象为各检索库所用向量模型标识。先核对标识，排除不符合者，不执行跨模型检索来比较漏召回；记录实际观察到的结果与仍未知的部分。

材料中的签署、合作达成、合同生效属不同事实；待审核不证明缺少操作权限。本页只解决模型接入与配置，运营交接时材料、操作与请求处于何种授权状态，不能以检索或表单代替授权执行。
