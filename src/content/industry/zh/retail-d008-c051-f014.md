# 抖音小店货架运营的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样
抖音小店货架运营围绕商品卡与店铺体验分展开，资料来自抖店工作台、抖音电商学习中心、精选联盟数据与物流接口。跨境资料与多语检索要处理的文档集中在商品资质页、体验分明细、发货违规申诉与店铺公告。资料更新为日频与每单频，检索侧只需按已有资料核对，不据此推出批量同步或交易触发机制。商品资质页常含多语字段与来源说明，模型接入时要先确认索引模型与语言模型均已启用，系统至少需要一个语言模型和一个索引模型才能正常使用。

## 这些特征在「模型接入与配置」这一环带来什么约束
从 V4.17.0 起 AI Proxy 为必需依赖，App 与 Admin 都必须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败；AIPROXY_API_ENDPOINT 填服务根地址，不附加 `/v1`。旧 OpenAI 环境变量或单模型自定义请求地址不能替代这两项。模型 ID 是请求 Body 中 `model` 字段的值，全局唯一；模型名可自定义，仅用于展示。渠道测试与模型测试会实际发送请求，用于初步检查模型是否正常工作。模型探测仅针对已启用的系统模型，未启用模型不参与探测；单轮最多尝试 4 次，4 次全部失败才判定异常。模型调用日志仅保留 1 小时，环境变量可配置。

## 配置怎么定
下表围绕跨境资料与多语检索这一任务，列出与本页文档直接相关的设置或实施核对项。数值列中标注“本次假设试验起点”的，仅为纸面比较用，不是官方默认值。

| 设置或核对项 | 本次假设试验起点 | 核对方式与理由 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设填 `http://aiproxy:3000` | 与服务根地址比较，确认不带 `/v1`；文档要求必填 |
| AIPROXY_API_TOKEN | 假设填非空管理员 Token | 与服务端配置比较，确认一致且非空；不可用应用 API Key 代替 |
| 语言模型与索引模型启用 | 各启用一个 | 在系统模型页核对启用状态；文档要求至少各一个 |
| 模型 ID 与渠道模型对应 | 假设模型 ID 为 `gpt-4o-test` | 与渠道模型映射比较，确认映射到上游 `gpt-4o` |
| 检索范围与访问权 | 假设资料位于有访问权的目标检索范围 | 人工核对资料是否在可访问范围内；检索不承担授权 |
| 模型探测启用与间隔 | 假设间隔 30 分钟 | 与 5～60 分钟整数范围比较；仅针对已启用模型 |

## 容易做错的三处
1. 把 AIPROXY_API_ENDPOINT 填成完整模型请求地址并附加 `/v1`。文档要求填服务根地址且不附加 `/v1`，附加后请求路径与预期不符。
2. 用旧 OpenAI 环境变量或单模型自定义请求地址替代 AI Proxy 两项必填配置。文档明确这两项不能替代，缺少任一项启动校验失败。
3. 将模型探测范围理解为全部模型。文档说明仅针对已启用的系统模型，未启用模型不参与探测，也不产生历史记录。

## 怎么确认配好了
以下验证使用同一假设演练样本。假设演练样本：商品资质页原文写“主体：某某贸易商行；对象：某款保温杯；状态：资质页已提交，审核中；有效范围：2026 年 1 月 1 日至 2026 年 12 月 31 日”。待判定拟稿句为“该商品资质已通过审核，可用于跨境资料检索”。主体、对象、期间、字段均与原文对齐。

1. 输入拟稿句与原文，比较“审核中”与“已通过审核”这两个同字段取值。原文状态为审核中，拟稿句写已通过审核，两者互斥，判定为未获支持。
2. 输入 AIPROXY_API_ENDPOINT 假设值，比较其是否以 `/v1` 结尾。若以 `/v1` 结尾，与文档要求不符，需改为服务根地址。
3. 输入模型探测结果，比较单轮尝试次数与 4 次上限，以及状态是否由非红色变为红色。只有 4 次全部失败才判定异常；持续异常不重复推送。
