# 渠道窜货稽查的跨境资料与多语检索：引用来源与溯源

## 这个品类的数据长什么样

窜货稽查围绕区域与价格秩序展开，不处理返利金额。主要材料包括防伪码系统记录、电商平台价格、经销商发货记录与市场巡检结果，日常文档为窜货投诉单、防伪码记录、处罚通知与调查照片。跨境场景下这些材料常以不同语言呈现，同一批货的防伪码记录与投诉单可能分属不同语种。资料更新以周和不定期为主。引用来源与溯源环节需要把多语材料中的原文片段与检索输出对应起来，供人工核对。

## 这些特征在「引用来源与溯源」这一环带来什么约束

知识库搜索节点以数组输出引用内容，长度允许为零，空数组不代表工作流报错终止。关联知识库须选择相同向量模型，跨模型不可共同关联。语义检索支持跨多语言理解，输入中文问题可匹配英文知识点，但向量搜索精度受模型训练与数据质量影响。混合检索经 RRF 融合多路结果，重排后得到 0-1 得分用于过滤。最低相关度是过滤阈值，仅在语义检索或结果重排时生效。检索本身不承担授权判断，相似度得分不构成实体或权限过滤。

假设演练样本：某品牌渠道管控人员收到一份英文窜货投诉单，原文为“Complaint No. CN-2024-0871. Subject: 300 units of model AX-200 found in Region B on 2024-11-05, outside authorized Region A territory. Batch code BC-7712.”另有一份中文经销商发货记录，原文为“发货单号 FH-2024-1103，型号 AX-200，数量 300 件，批次 BC-7712，收货区域 A，发货日期 2024-11-01。”待判定拟稿句为“该批 AX-200 已确认窜货至 B 区，依据为投诉单 CN-2024-0871。”需核对该拟稿句是否获得原文支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 选择存放投诉单与发货记录且向量模型标识一致的知识库 | 须核对向量模型标识，排除不一致者，不执行跨模型检索 |
| 搜索模式 | 混合检索 | 投诉单含编号 CN-2024-0871，精确编号适合全文召回，语义部分处理多语表述 |
| 最低相关度 | 假设起点 0.3 | 本次试验起点，非官方默认；与不设阈值时的召回条数比较，观察过滤效果 |
| 引用上限 | 假设起点 2000 tokens | 本次试验起点，非官方默认；与 4000 tokens 时的引用完整度比较 |
| 问题优化 | 开启 | 跨语种问题可能缺失主体，开启后观察检索词补全结果 |
| 结果重排 | 按设置启用 | 重排须具备模型且按设置启用，重排得分用于过滤 |

## 容易做错的三处

1. 把检索输出当作授权结论。搜索节点输出引用数组，检索不判断权限。错误做法是看到投诉单被召回即认定窜货成立。检查：核对引用内容是否仅作为待核材料，授权状态另行确认。
2. 跨向量模型关联知识库。不同向量模型的库不可共同关联。错误做法是同时选入标识不一致的库并比较召回。检查：核对每个库的向量模型标识，排除不符合者，记录实际观察。
3. 把待审核状态当作已完成处罚。处罚通知处于待审核不证明已执行。错误做法是依据未签署通知认定处罚生效。检查：核对通知的签署与生效字段，缺失时记录证据缺口。

## 怎么确认配好了

1. 输入假设样本中的英文投诉单原文与中文发货记录原文，比较拟稿句“已确认窜货至 B 区”是否获得原文支持。投诉单载明“found in Region B”与“outside authorized Region A”，发货记录载明收货区域 A。满足条件：拟稿句引用的编号、型号、数量、批次与原文一致，且窜货认定状态与原文表述相符；若原文仅载明发现地点而未载明认定结论，则判定为未获支持。
2. 输入一个仅含中文问题的检索请求，比较语义检索能否匹配英文知识点。满足条件：引用数组返回与中文问题语义相关的英文材料片段，且引用内容可逐条对应原文；若返回空数组，记录为未召回，不推断为无关查询必为空。
3. 输入纸面空数组 [] 作为检索输出，核对下游回答环节的设计。满足条件：下游设计明确承接空数组且不报错终止；若下游设计未载明空数组处理方式，记录为未获支持，不声称虚构规则检索一定返回空数组。
