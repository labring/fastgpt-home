# 渠道窜货稽查的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

渠道窜货稽查围绕区域与价格秩序展开，日常材料包括窜货投诉单、防伪码记录、处罚通知与调查照片。跨境资料与多语检索场景下，同一批材料可能同时存在不同语言的投诉描述、不同地区的价格截图和不同格式的货码清单，检索前需要先确认材料语言与字段结构。该品类数据更新频率为周或不定期，材料到达时间不固定，检索配置不依赖定时触发。最耗时的环节是追踪货源码、比对低价店铺与执行处罚，其中前两项属于本页检索任务的输入范围，处罚执行属于下游业务动作。

## 这些特征在「模型接入与配置」这一环带来什么约束

模型接入依赖 AI Proxy。自 V4.17.0 起，App 与复用 App/Service 配置的 Admin 服务必须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。AIPROXY_API_ENDPOINT 填写 AI Proxy 服务根地址，不附加 /v1。系统至少需要一个语言模型和一个索引模型才能正常使用。索引模型用于对文本块建立索引，语言模型用于对话与多模态图片识别。模型 ID 是请求 Body 中 model 字段的值，全局唯一；模型映射可将 FastGPT 请求的模型映射到上游实际模型。渠道优先级范围 1～100，数值越大越容易被优先选中。检索关联同向量模型要求仅适用于知识库与向量库配置，不扩展到工商网站或其他外部系统。语义召回与相关度不承担权限或实体隔离职责，检索结果不构成授权。

假设演练样本：一份跨境窜货投诉单原文为“投诉方：某区域经销商；被投诉对象：某电商店铺；涉及货码：A-2024-001 至 A-2024-050；发现时间：2024 年 3 月；投诉内容：该店铺在授权区域外低价销售上述货码对应产品。”一条待判定拟稿句为“该店铺已构成跨区窜货，建议立即执行处罚。”核对该拟稿句时，投诉单仅载明投诉内容与货码范围，未载明调查结论与处罚决定，拟稿句中的“已构成”与“立即执行处罚”在材料中未获支持。

## 配置怎么定

配置围绕本页样本的检索与核对需求展开，不将数据库内部实现列为必配项。

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设填写 AI Proxy 服务根地址，不含 /v1 | 官方要求根地址；与含 /v1 的地址比较，确认启动校验通过 |
| AIPROXY_API_TOKEN | 假设填写与服务端一致的非空管理员 Token | 官方要求非空且一致；与应用 API Key 比较，确认不可替代 |
| 索引模型 | 假设启用一个索引模型 | 官方要求至少一个索引模型；与未启用状态比较，确认知识库可用 |
| 语言模型 | 假设启用一个语言模型 | 官方要求至少一个语言模型；与未启用状态比较，确认对话可用 |
| 模型映射 | 假设将 FastGPT 模型 ID 映射到上游实际模型 | 官方说明映射关系；与未映射请求比较，确认上游 model 值 |
| 渠道优先级 | 假设设为 50 | 官方范围 1～100；与设为 1 比较，确认优先选中差异 |

## 容易做错的三处

1. 将 AIPROXY_API_ENDPOINT 填写为含 /v1 的完整请求地址。输入为含 /v1 的地址，比较官方要求的根地址格式，观察启动校验是否失败。
2. 将语义召回相关度当作权限或实体隔离手段。输入为跨区域检索请求，比较返回结果与授权范围，观察是否出现未授权记录，确认相关度不承担隔离职责。
3. 将待判定拟稿句中的“已构成”与“立即执行处罚”当作已确认事实。输入为样本投诉单原文与拟稿句，比较材料是否载明调查结论与处罚决定，观察拟稿句是否超出材料支持范围。

## 怎么确认配好了

1. 输入样本投诉单原文与拟稿句，比较拟稿句中“已构成跨区窜货”与原文“投诉内容”字段，原文未载明调查结论时，拟稿句该部分属于未获支持，需记录证据缺口。
2. 输入样本投诉单原文与拟稿句，比较拟稿句中“立即执行处罚”与原文是否载明处罚决定，原文未载明处罚决定时，该部分属于未获支持，需保留待核实状态。
3. 输入样本投诉单中的货码范围 A-2024-001 至 A-2024-050，比较检索返回结果是否覆盖该范围，若返回空结果，以纸面输入 [] 核对下游设计，不声称虚构规则检索一定返回 []。
