# 生产企业免抵退税的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

生产企业免抵退把内销抵减与出口退税合并计算，归集自产出口、计算免抵退、处理离岸价差异最耗时。跨境资料与多语检索面对四类文档：免抵退税申报明细表、出口合同、销售明细账、出口报关单。它们来自电子税务局、ERP销售、海关电子信息和财务账，按月更新。多语检索要处理合同与报关单的外文品名、贸易术语与金额表述，模型接入与配置决定这些字段能否被正确读取与召回。

## 这些特征在「模型接入与配置」这一环带来什么约束

FastGPT 借助 AI Proxy 连接模型提供商。自 V4.17.0 起 AI Proxy 为必需依赖，App 与复用 App/Service 配置的 Admin 都必须设置 `AIPROXY_API_ENDPOINT` 和非空 `AIPROXY_API_TOKEN`，缺少任一项启动校验失败。`AIPROXY_API_ENDPOINT` 填服务根地址，不附加 `/v1`。系统至少需要一个语言模型和一个索引模型。模型 ID 是请求 Body 中 `model` 字段的值，全局唯一；模型渠道可把 FastGPT 请求的模型映射到上游实际模型。检索是召回，不承担授权、实体隔离或业务核验。

假设演练样本：某出口生产企业资料员整理一批纸质材料，含 2026 年 3 月出口合同一份，合同买方栏为境外某贸易公司，货物描述为外文品名，金额栏为离岸价；同月出口报关单一份，境内发货人为该生产企业，商品名称栏为对应外文品名。拟稿句为“该合同项下货物已由生产企业自产出口，申报明细表可直接归集”。待判定请求为“请检索并确认该合同与报关单可归集为自产出口”。

## 配置怎么定

下表只列与本页文档和主任务相关的官方已说明设置或实施核对项。假设试验起点仅为本次演练取值，不属官方默认值。

| 配置项 | 本次假设试验起点 | 选择理由与比较对象 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | 按部署实际填写服务根地址 | 与文档要求比较：不得附加 `/v1` 或 `/chat/completions` |
| `AIPROXY_API_TOKEN` | 填写与服务端一致的非空管理员 Token | 与应用 API Key 比较，二者不可互相替代 |
| 语言模型 | 启用一个已通过渠道测试的模型 | 与“至少一个语言模型”要求比较 |
| 索引模型 | 启用一个已通过渠道测试的模型 | 与“至少一个索引模型”要求比较 |
| `MILVUS_LANGUAGE_IDENTIFIER` | 保持 `lingua` | 与文档列出的 `lingua`、`whatlang` 比较 |
| `LLM_REQUEST_TRACKING_RETENTION_HOURS` | 保持 `6` | 与调用日志保留时长说明比较 |

## 容易做错的三处

1. 把 `AIPROXY_API_ENDPOINT` 填成带 `/v1` 的完整请求地址。检查：读取该变量值，与文档“填服务根地址，不附加 `/v1`”比较；若值末尾含 `/v1`，判定不符合。
2. 用应用 API Key 充当 `AIPROXY_API_TOKEN`。检查：核对 Token 来源与服务端配置；若来源为应用侧 Key 或值为空，判定不符合。
3. 把检索召回当作自产出口的授权或核验结论。检查：对拟稿句，核对合同与报关单原文是否载明自产属性与归集授权；样本原文未载明，判定为未获支持。

## 怎么确认配好了

以下三项均针对前述假设样本，只写预期，不声称已实测。

1. 输入：假设样本中合同与报关单的外文品名文本。比较：检索结果是否命中这两份材料。满足条件：命中即记录；未命中则记录失败分支，不保证首条命中或全部召回。
2. 输入：拟稿句“该合同项下货物已由生产企业自产出口，申报明细表可直接归集”。比较：同主体、同期间、同一字段下原文是否载明自产属性。满足条件：原文未载明时判定未获支持，保留证据缺口，不补造授权条款。
3. 输入：纸面输入 `[]` 与下游归集设计。比较：下游是否对空结果做显式处理。满足条件：能说明空结果分支即可；不声称虚构规则检索一定返回 `[]`。
