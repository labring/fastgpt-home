# 生鲜供应商索赔的跨境资料与多语检索：向量模型与索引

## 这个品类的数据长什么样

在生鲜供应商索赔的跨境资料与多语检索中，本页说明FastGPT的向量模型与索引如何衔接资料。核供应商收件、复核与认可索赔的两语区别，保留本批商品和证据缺口。所用场景为自拟文字测试。

## 这些特征在「向量模型与索引」这一环带来什么约束

供应商索赔练习可拟收货备注“本批疑有缺量，计量记录待复核”，供应商邮件只回“已收到资料”，英文对照也仅说明receipt of documents。没有供应商认可责任或赔付安排的记录。若入口把documents received概括成claim accepted，就将收件动作改成了索赔认可；本批疑似缺量也不能由一封回信变成已核差异。另有另一批已结事项摘要，应用到本批前必须核对象，不能把同一供应商名称当成同一次问题。此例不含真实索赔金额或责任判断。

## 配置怎么定

| 索赔多语核对 | 拟议原文 | 应核证据 |
| --- | --- | --- |
| 收件动作 | 供应商仅回资料已收 | 不改成认可索赔。 |
| 差异事实 | 本批疑缺、计量待复核 | 原始计量与复核记录另查。 |
| 供应商态度 | 尚缺认可或安排 | 回信逐句核承诺范围。 |
| 批次事项 | 另一批已结摘要 | 不能移给本批作为结果。 |
| 补充记录 | 复核、意见、执行分开 | 同一商品事项逐步更新。 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `向量模型` | 同一检索节点关联的库需使用相同向量模型。 |
| `原数据与索引` | 一条原数据可关联多条索引。 |
| `索引内容` | 索引内容应完整且聚焦。 |
| `图片索引` | 采用图片检索时核描述或图片向量。 |
| `版本与结果复核` | 变更后复用同题比对原文。 |

## 容易做错的三处

- 收到资料被英文索引写成供应商认可索赔时，核回信原句与认可范围，找新增承诺的依据。

- 疑似缺量被回答写成已核实差异时，核计量原始记录、复核状态及对应商品，不用问题描述替代核验。

- 另一批结项摘要被用于本批处理完成时，核批次、事项与实际凭证，不能按供应商同名合并结果。

## 怎么确认配好了

验收两语分别问收到了什么、哪些仍在复核、是否存在认可或处理安排，逐句追到实际原文。补入计量复核、供应商意见或处理记录后，先核本批商品和事项，再分别更新事实与态度、执行状态。多索引对同一原数据应保留收件动作及待核限定，共同关联库在同一搜索节点核实际向量模型一致。本练习不发索赔函、不认定责任，也不由回复文字生成赔付结果。
