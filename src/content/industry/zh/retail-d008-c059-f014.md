# 生鲜冷链到店验收的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

在生鲜冷链到店验收的跨境资料与多语检索中，本页说明FastGPT的模型接入与配置如何衔接资料。保留温控、验收和拒收的时间与状态语义，避免英文对照改变原始观察范围。所用场景为自拟文字测试。

## 这些特征在「模型接入与配置」这一环带来什么约束

自拟双语记录可把途中记录、到货测量和验收意见分为三段，英文各自保留事件身份。模型输入核对先确认这些段落与标题同在，不能将单个温度词或状态词脱离时间理解。若输出把途中观察译成到货结果，应把实际请求与原句并列定位；一次服务响应正常不说明事件关系已经被正确读取，也不证明该批食材品质或责任结论。

## 配置怎么定

| 接入核对项 | 冷链双语事件 | 实际取证 |
| --- | --- | --- |
| 标题关系 | 途中、到货和意见分段保留 | 标题与原文共同送达 |
| 时间语义 | 途中观察不能改成到货结果 | 核请求与返回原句 |
| 待复核状态 | 英文缺项不能用其他段补齐 | 定位未提供或传入丢失 |
| 译稿范围 | 新增文字仅是待核对照 | 不冒充双方正式结论 |
| 图像材料 | 曲线及照片另验读取 | 不推定全部时点或现场结论 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `AI Proxy依赖` | 按实际版本核服务、渠道与应用。 |
| `AIPROXY_API_ENDPOINT` | 使用AI Proxy服务根地址。 |
| `AIPROXY_API_TOKEN` | 管理员Token非空且与服务端一致。 |
| `模型能力` | 按实际输入路径验证所需能力。 |
| `应用参数` | 接口同名字段未必覆盖应用设置。 |

## 容易做错的三处

- 途中观察被译成到货结果：保留记录标题、批次和时点，对照实际请求与输出，定位事件身份改变，不从调用正常推验收正确。

- 待复核缺英文，被其他段Received补成已验收：核各段状态及对应来源，接收事件不等于验收结论，不能借别段填正式意见。

- 新增译稿被称为双方正式结论：保留原附页、实际输入及返回查来源身份，缺正式对照仍待核，拒收理由也不自动证明供应商认可。

## 怎么确认配好了

验收按批次、时点和待复核状态分别设问，检查两种语言是否指向同一段及同一适用对象，再核新增译稿是否扩大原意。拒收原因可以翻译为所记录的理由，但不能附加供应商认可或争议解决的结论。原始资料如果以照片或曲线图提供，要另验相应输入及读取范围，文字测试不能证明图中全部时点已覆盖，也不能代替门店现场确认。
