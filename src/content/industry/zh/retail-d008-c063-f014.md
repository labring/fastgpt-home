# 直播售后集中处理的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

在直播售后集中处理的跨境资料与多语检索中，本页说明FastGPT的模型接入与配置如何衔接资料。直播售后双语材料保持申请人、处理选项与执行状态，不把模板译成已退款。所用场景为自拟文字测试。

## 这些特征在「模型接入与配置」这一环带来什么约束

假设海外买家邮件提出退款，内部补发便笺仍待买家选择，话术模板只介绍可申请的处理路径。模型接入的多语练习应核原邮件、译文和订单说明是否共同送达，分别辨明谁提出退款、谁提出补发、哪项已执行。当前不含支付回执或物流交接证据，模板说明不能证明本订单退款或补发完成；没有真实买家、订单金额或实际外发。

## 配置怎么定

| 直播售后多语输入 | 假设内容 | 核法 |
| --- | --- | --- |
| 买家 | 要求退款 | 保留请求主体 |
| 内部 | 补发待选择 | 不推已同意 |
| 模板 | 可申请路径 | 不称已到账 |
| 订单 | 本场与另场 | 逐单核回执 |
| 通道 | 文字连接测试 | 不执行售后动作 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `AI Proxy依赖` | 按实际版本核服务、渠道与应用。 |
| `AIPROXY_API_ENDPOINT` | 使用AI Proxy服务根地址。 |
| `AIPROXY_API_TOKEN` | 管理员Token非空且与服务端一致。 |
| `模型能力` | 按实际输入路径验证所需能力。 |
| `应用参数` | 接口同名字段未必覆盖应用设置。 |

## 容易做错的三处

- 补发待选择的条件未送入而译文称买家已同意时，核请求包含的原邮件与内部便笺，补齐后重问立场。

- 模板中的可申请退款被翻成已到账时，对可能性、申请状态与支付证据，语义流畅不能补执行动词。

- 另一场直播的补发单支持当前投诉时，对场次、订单和收件对象，不能按同款商品合并售后结果。

## 怎么确认配好了

分别只给买家邮件、再加内部处理意见、最后加对应回执，固定问题核各方立场和完成状态。保存实际送入文本和采用句，对否定、时态与条件逐项看。切换模型维持同输入，扫描订单或录音另测实际支持，不用文字结果覆盖其他模态。服务凭证只用于连接；退款、补发与向买家发送消息需要独立实现和业务授权。
