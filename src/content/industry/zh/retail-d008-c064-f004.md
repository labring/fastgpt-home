# 直播选品与样品质检的跨境资料与多语检索：向量模型与索引

## 这个品类的数据长什么样

直播选品与样品质检发生在开播前，围绕商品能否上播、是否适合展示展开。主要材料包括样品评估表、质检报告、供应商资质与禁售清单，来源为供应商资料、检测机构报告、平台负面目录与历史退货率。资料按周、按品更新。这些材料常含中英文品名、型号、报告编号与检测项目，跨境场景下同一份档案可能由多种语言构成，检索时需要跨语言匹配。

## 这些特征在「向量模型与索引」这一环带来什么约束

向量搜索依赖向量距离计算相似度，语义检索具备跨多语言理解能力，输入中文问题可匹配英文知识点。知识库由库、集合和数据组成，最小搜索单位是库，集合仅用于分类管理，与搜索效果无关。关联检索的知识库须使用相同向量模型，需先核实际模型与输入类型。一个原数据块可关联多个索引，索引内容与原文内容分别核对。索引内容应完整且聚焦，检索覆盖范围与索引长度需结合样本权衡。图片检索还取决于入库时是否生成图片描述或图片向量，不能只看查询端。混合检索通过 RRF 融合多路结果，重排须具备模型且按设置启用，这些可选路径不代表每次请求全部执行。语义召回与相关度不负责权限或实体隔离，检索结果不构成授权。

假设演练样本：某批次供应商资质档案原文为“供应商：A公司（示例）；资质文件：营业执照复印件；有效期至：2026年3月31日；状态：已提交待审核”。一条拟稿交接句为“A公司资质已审核通过，可安排上播”。判定需同主体、同期间、同一字段：原文状态字段为“已提交待审核”，拟稿句称“已审核通过”，二者在同一字段上取值互斥，该拟稿句未获支持。待审核不证明缺少操作权限，也不等于审核通过。

## 配置怎么定

| 核对项 | 本次假设试验起点 | 比较方法 |
| --- | --- | --- |
| 向量模型一致性 | 关联库均标注同一向量模型标识 | 逐库核对标识，排除不一致者，不执行跨模型检索 |
| 索引内容范围 | 每条索引含供应商名称、资质类型、有效期、状态 | 与原文逐字段比对，缺失字段记为缺口 |
| 图片索引生成 | 入库时对样品图生成描述或向量 | 查入库记录是否含图片索引，未生成则查询端无法命中 |
| 检索模式 | 对含型号、报告编号的问题使用全文或混合检索 | 同组问题比对引用原文，观察命中字段 |
| 引用上限 | 设为覆盖一份质检报告主要字段的 tokens 量 | 与报告实际长度比较，过小则字段被截断 |
| 最低相关度 | 设为能保留资质状态字段的水平 | 调低后观察无关片段是否进入引用，记录实际结果 |

表中数值为本次假设试验起点，非官方默认值。引用上限采用 tokens 方式控制，最低相关度仅在语义检索或结果重排时生效。

## 容易做错的三处

1. 把“已提交待审核”当作审核通过。输入为上述资质原文与拟稿句，比较状态字段取值，观察拟稿句是否与原文同字段一致，不一致则记为未获支持。
2. 跨不同向量模型的库共同关联。输入为两个标注不同向量模型标识的库，比较标识，观察是否一致，不一致则排除，不执行检索比较漏召回。
3. 把检索命中当作授权执行。输入为一条检索到的资质记录，比较记录状态与交接请求中的动作，观察状态是否支持该动作，待审核状态不支持上播安排。

## 怎么确认配好了

1. 输入上述假设资质原文与拟稿句，比较状态字段“已提交待审核”与“已审核通过”，观察拟稿句是否被判定为未获支持，满足条件即该判定正确。
2. 输入两个向量模型标识不同的库，比较标识是否一致，观察系统是否排除不一致者，满足条件即模型一致性核对生效。
3. 输入一条空引用结果，比较下游设计是否承接长度为 0 的数组，观察链路是否走通，满足条件即空结果承接正常。检索检查记录实际观察与失败分支，不保证首条命中或全部召回。
