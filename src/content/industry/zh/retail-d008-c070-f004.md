# 跨境商品合规与标签的跨境资料与多语检索：向量模型与索引

## 这个品类的数据长什么样
跨境商品合规与标签的资料以产品测试报告、英文标签、MSDS、平台禁售清单为主，来源包括平台政策中心、检测机构报告、目的国法规库与供应商资料。资料更新不定期，每次上新都可能带来新文件。合规判断发生在上架和进口之前，核心是产品安全与标签证据，出错会带来平台下架、海关扣货或消费者索赔。这些资料往往一份文件同时含中英文、编号与法规条款，检索时既要跨语言理解语义，也要精确定位型号、物质名称和禁售条目。向量模型与索引这一环，正是决定这些资料能否被稳定召回的基础。

## 这些特征在「向量模型与索引」这一环带来什么约束
关联检索的知识库须使用相同向量模型，先核实际模型与输入类型。一个原数据块可以关联多个索引，索引与原文内容分别核对。用完整且聚焦的信息建立索引，检索覆盖和索引长度需结合样本权衡。图片检索还取决于入库是否生成图片描述或图片向量，不能只看查询端。模型或索引调整后用同组问题比对引用原文，不根据向量分数单独承诺效果。向量搜索通过距离判断相似度，精度受向量模型质量、数据质量与检索器精度影响。语义检索适合自然语言与跨语言问题，全文检索适合编号、型号、专有名词。混合检索通过 RRF 融合多路结果，重排对候选文本二次排序并给出 0-1 得分。最低相关度是过滤阈值，仅在语义检索或使用结果重排时生效。引用上限按 tokens 控制，不采用 top k。检索结果为空时，引用内容以长度可以为 0 的数组输出，下游链路仍走通。

假设演练样本：某批出口小家电的供应商资料中，测试报告原文写着“本报告覆盖型号 AB-1200，测试项目为温升，结论为符合委托方提供的限值要求”，英文标签草稿写“Model AB-1200, rated voltage 220V”。拟交接句为“该型号已取得目的国全部合规认证，可直接上架”。判定该句时，材料只支持型号 AB-1200 的温升测试结论，未载明目的国认证机构、证书编号或生效范围，该句属于未获支持。

## 配置怎么定
以下只列与本功能、本任务相关的官方已说明设置或实施核对项。

| 配置项 | 本页取值或核对动作 | 依据与边界 |
| --- | --- | --- |
| 向量模型 | 关联的知识库须使用相同向量模型，先核实际模型与输入类型 | 不同向量模型的库不可共同关联，只核标识并排除不符者 |
| 索引数量 | 一个原数据块可关联多个索引 | 索引与原文内容分别核对，不合并判断 |
| 索引内容 | 用完整且聚焦的信息建立索引 | 检索覆盖与索引长度结合样本权衡 |
| 图片索引 | 核对入库是否生成图片描述或图片向量 | 图片检索须有图像输入及模型能力，不能只看查询端 |
| 搜索模式 | 按样本选择语义检索、全文检索或混合检索 | 混合检索经 RRF 融合，重排须具备模型且按设置启用 |
| 最低相关度 | 本次假设试验起点设为 0.4 | 该值仅在语义检索或使用结果重排时生效，与同组问题的引用原文比对 |

## 容易做错的三处
1. 把不同向量模型的库共同关联。输入为两个知识库标识，比较其向量模型标识，观察是否一致；不一致时排除，不执行跨模型检索来比较漏召回。
2. 把向量分数当作权限或实体过滤。输入为一次检索请求，比较返回引用与可访问范围，观察是否出现无权记录；相似度不承担授权判断。
3. 把待审核的交接请求当作已批准。输入为拟交接句“该型号已取得目的国全部合规认证”，比较材料是否载明认证机构与证书编号，观察是否存在对应字段；缺失时记录为未获支持。

## 怎么确认配好了
1. 输入假设样本中的测试报告原文与拟稿句，比较拟稿句是否超出原文载明的主体、对象与状态，观察是否被标为未获支持；预期为未获支持，不声称已实测。
2. 输入两个知识库标识，比较其向量模型标识，观察是否一致；不一致时排除，不编造共同关联后的运行结果。
3. 输入一条明确无对应资料的查询，比较引用内容输出，观察是否为长度可以为 0 的数组；空结果承接可用纸面输入 [] 核对下游设计，不声称虚构规则检索一定返回 []。
