# 跨境商品合规与标签的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样
跨境商品合规资料以产品测试报告、英文标签、MSDS 与平台禁售清单为主，来源包括平台政策中心、检测机构、目的国法规库与供应商资料。资料在每次上新时补充，同一商品在不同目的国可能对应不同标签版本与检测结论。检索任务需要把多语言资料与具体商品、目的国、批次关联，输出可核对的引用内容。资料更新不定期，本页不据此推导批量同步或实时触发机制。

## 这些特征在「模型接入与配置」这一环带来什么约束
模型接入依赖 AI Proxy。App 与 Admin 必须设置 AIPROXY_API_ENDPOINT 和非空 AIPROXY_API_TOKEN，缺少任一项会导致启动校验失败。模型渠道在管理员-模型提供商页面按协议类型、模型、模型映射、代理地址与 API 密钥配置，代理地址填写 BaseUrl，不附加完整请求路径。语言模型与索引模型字段中，maxContext、maxToken、defaultToken 等取值来自模型配置，不能从其他接口同名字段推断覆盖关系。检索结果与权限、实体隔离无关，相似度设置不承担排除未授权记录的功能。跨向量模型的库不可共同关联，需先核对模型标识并排除不符合者。

假设演练样本：某批儿童水杯拟出口德国，供应商提供的英文标签原文为“Suitable for children over 3 years. BPA free. Not suitable for microwave use.”；检测报告编号为假设的 TEST-2024-0001，结论为“符合 EN 14350”。一条待判定拟稿句为“该产品标签与检测报告均已满足德国上架要求”。该句涉及标签文本、报告结论与目的国要求三类材料，当前仅提供标签与报告，目的国法规库原文未提供。

## 配置怎么定
下表为本次假设试验起点，用于核对配置项与样本的对应关系，不代表官方默认值。

| 配置项 | 本次假设起点 | 选择理由与比较对象 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设填 `http://aiproxy:3000` | 与服务根地址格式比较，不附加 `/v1` |
| AIPROXY_API_TOKEN | 假设填非空管理员 Token | 与 AI Proxy 服务端配置比较，确认一致 |
| 语言模型 maxContext | 假设填 125000 | 与该模型配置中 maxContext 值比较，确认覆盖样本引用长度 |
| 索引模型 defaultToken | 假设填 512 | 与样本文件分块需求比较，确认分块 token 不超过该值 |
| 渠道模型映射 | 假设 `gpt-4o-test` 映射到 `gpt-4o` | 与渠道配置中模型映射字段比较，确认请求模型名与上游模型名对应 |
| 重排模型启用 | 假设未配置 | 与检索结果重排需求比较，确认当前是否具备重排能力 |

## 容易做错的三处
1. 把 AIPROXY_API_ENDPOINT 填成带 `/v1` 的完整请求地址。核对输入为环境变量值，比较对象为服务根地址格式，观察结果为是否附加了 `/v1` 或 `/chat/completions`。
2. 用应用 API Key 代替 AIPROXY_API_TOKEN。核对输入为 Token 来源，比较对象为 AI Proxy 管理员 Token，观察结果为是否与服务端配置一致且非空。
3. 把相似度得分当作权限或实体过滤条件。核对输入为检索返回记录，比较对象为记录所属主体与授权范围，观察结果为是否出现未授权记录被相似度排序带入。

## 怎么确认配好了
- 验证一：针对假设样本标签原文“Suitable for children over 3 years. BPA free. Not suitable for microwave use.”，输入该段文本发起检索，比较返回引用是否包含该原文，观察结果为引用文本与输入一致。若返回空结果，记录为未命中，不推断为规则不存在。

- 验证二：针对待判定拟稿句“该产品标签与检测报告均已满足德国上架要求”，输入该句与样本材料，比较拟稿句是否同时获得标签原文与报告结论支持，观察结果为拟稿句超出已提供材料范围，目的国要求部分未获支持。

- 验证三：针对假设报告编号 TEST-2024-0001 与结论“符合 EN 14350”，输入报告编号检索，比较返回记录的报告编号与结论字段是否与输入一致，观察结果为编号与结论匹配。若检索返回其他编号记录，记录为标识不符并排除。
