# 跨境商品合规与标签的跨境资料与多语检索：知识库检索与召回

## 这个品类的数据长什么样

跨境商品合规发生在商品上架与进口之前，核心证据是产品安全与标签材料。日常文档包括产品测试报告、英文标签、MSDS 与平台禁售清单，来源涵盖平台政策中心、检测机构报告、目的国法规库和供应商资料。资料更新不定期，每次上新都可能带来新版本。这些材料往往主体不同、期间不同，同一份测试报告只覆盖特定型号与特定项目。检索环节要面对多语言问题：中文提问需要命中英文标签或英文报告内容，语义检索具备跨语言理解能力，这决定了检索词与数据分块需要一并考虑。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库。跨不同向量模型的知识库不可共同关联，遇到此类情况先核对标识并排除不符合者，记录实际观察，不执行跨模型检索来比较结果。检索是对整个库进行搜索，集合仅用于分类管理。一次检索会按输入与参数组合语义检索、全文检索、图片检索、问题优化与重排，最终经相似度过滤和引用上限裁剪得到引用内容。引用内容以数组输出，长度可以为 0，未搜索到内容时输出链路仍然走通。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值，不承担权限或实体隔离功能。检索结果不构成授权，也不代表某份材料已被批准或某次交接已获准执行。

假设演练样本：某批儿童水杯拟上架，材料为一份英文测试报告，原文写“Sample: Model CB-100; Test item: phthalate content; Result: pass; Report date: 2025-03-12”。另有一份供应商英文标签草稿，原文写“Suitable for children over 3 years”。待判定的拟稿句为“该型号已完成邻苯二甲酸酯检测，标签年龄标识与报告一致”。报告只覆盖 CB-100 的邻苯项目与出具日期，未载明标签年龄标识的核对结论，该拟稿句的标签一致性部分未获支持，需另行核对。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选取理由与比较方法 |
| --- | --- | --- |
| 关联知识库 | 仅关联使用同一向量模型的合规资料库 | 核对各库向量模型标识，排除标识不符者，不做跨模型比较 |
| 搜索模式 | 先用混合检索 | 型号 CB-100 属精确编号，混合检索同时使用语义召回与全文召回，再与单独语义、全文结果比较 |
| 引用上限 | 设为一个本次试验起点值 | 用长短不同的测试报告与标签片段比较，观察引用内容是否被截断，再调整 |
| 最低相关度 | 先标注相关与无关样本 | 该值仅在语义检索或使用结果重排时生效，按标注样本观察过滤效果 |
| 问题优化 | 多轮追问场景开启 | 比较原问题与优化后问题，核对主体是否被改错，短问题场景再评估耗时 |
| 结果重排 | 具备重排模型时启用 | 重排后得到 0-1 得分，按该得分观察排序变化 |

## 容易做错的三处

1. 把检索命中当作授权或批准。假设演练样本中报告显示 pass，检索命中该报告只说明内容被召回，不表示标签标识已核对通过，也不表示上架已获批准。检查方式：输入该报告原文与拟稿句，比较报告载明的型号、项目、结果、日期与拟稿句主张的范围，只有拟稿句主张落在载明范围内才相符。
2. 把最低相关度当作权限或实体过滤。该值是过滤阈值，不排除无关业务或未授权记录。检查方式：输入一条与合规资料语义相近但属于其他业务的查询，观察返回内容是否仍包含该记录，确认过滤只按相关度生效。
3. 把可选检索路径当作每次必走。图片检索需要图像输入与相应模型能力，重排需要具备模型并按设置启用。检查方式：输入纯文本查询，观察是否出现图片描述或图片向量召回路径，确认路径与输入、能力一致。

## 怎么确认配好了

1. 用假设演练样本的报告原文作为输入，比较返回内容是否包含 CB-100、phthalate content、pass、2025-03-12 四项字段。返回内容同时包含这四项且未被截断，视为该条命中；缺少任一项时记录缺口，不推断为未通过。
2. 用拟稿句作为输入，比较返回内容是否载明标签年龄标识的核对结论。返回内容未载明该结论时，判定为未获支持，保留证据缺口，不判定为冲突。
3. 用明确的纸面输入空数组核对下游设计，观察引用长度为 0 时下游链路是否仍走通。该核对针对链路承接，不表示虚构规则检索一定返回空数组。
