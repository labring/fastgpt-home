# 跨境平台结算与汇兑的跨境资料与多语检索：工作流编排

## 这个品类的数据长什么样

在跨境平台结算与汇兑的跨境资料与多语检索中，本页说明FastGPT的工作流编排如何衔接资料。跨语结算核对保留报表出具视角、日期角色与更正关联，不从译文推可支配资金。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

本题自拟英文平台结算说明、中文商家核对稿和一份更正便笺。英文只列平台向商家的应付事项，中文把平台扣收的服务项目另列，未给银行入账记录；报表期间与银行处理日期尚未对应，更正便笺也未注明替代哪份旧稿。先按出具视角和文件关系收原句，再选择核日期对应或核更正来源。应付方向不是已到账，两个日期角色不可互换，更正提出不说明旧稿已撤销。无真实金额、汇率或资金建议。

## 配置怎么定

| 结算双语关系 | 自拟限定 | 原文核查 |
| --- | --- | --- |
| 平台应付 | 向商家支付方向 | 不当已到账 |
| 扣收项目 | 另一款项方向 | 不擅自净额计算 |
| 日期角色 | 期间与银行事件 | 不互换字段含义 |
| 更正便笺 | 原稿关联未给 | 不按上传时间替代 |
| 实际账务 | 未给执行记录 | 另核授权凭据 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

- 平台应付商家与向商家扣收项目被合成同一款项方向时，对各文的付款方、接收方及原行，不由同属结算材料净额化或计算余额。

- 报表期间被译作银行实际入账日时，核原字段事件含义与银行凭据，日期格式可解析不证明资金时点。

- 更正便笺被下游当作已替换旧稿时，核原稿身份、更正所指行与明确采用依据，不用最新上传时间决定替代。

## 怎么确认配好了

两条路径分别保留原文出具方、日期角色及待补关联，比较提交与实际接收，不预设外部字段名。补银行记录只更新所证事件，不能顺带确认更正已被接受；补更正对应也不产生资金执行。译词须能回到同一来源行，差异无依据时继续列未决。正式对账、费用处理和账务回填另需业务授权与凭据，流程不自动抵扣、换汇或决定可提现金额。
