# 达人专场带货合作的跨境资料与多语检索：知识库检索与召回

## 这个品类的数据长什么样

达人专场带货合作围绕外部达人履约与佣金结算展开，文档以达人合作协议、佣金设置单、样品寄送单、直播战报为主，来源涉及精选联盟、巨量星图、达人历史数据与店铺成交明细。资料按每场、每周更新。跨境场景下同一份合作材料可能同时存在中文与外语版本，检索时既要处理自然语言问法，也要处理编号、型号、专有名词一类精确查询，这决定了检索模式无法只依赖单一向量相似度。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可关联一个或多个使用相同向量模型的知识库，跨不同向量模型的库不可共同关联，需先核对向量模型标识并排除不符合者。语义检索依赖向量距离，适合跨多语言语义相近内容；全文检索依赖关键词命中，适合编号与专有名词；混合检索同时使用两者并通过 RRF 融合。最低相关度仅在语义检索或使用结果重排时生效，是过滤阈值，不承担权限或实体隔离。引用上限以 token 为单位，输出引用内容为数组，长度可以为 0，未命中时该输出链路仍走通。

假设演练样本：某品牌商务留存的达人合作协议摘要原文为“甲方委托乙方于2025年3月15日进行一场专场直播，坑位费人民币三万元，佣金按实际成交额百分之十五结算，样品由甲方寄送。”同批次的佣金设置单摘要为“本场佣金比例百分之十五，结算周期为直播结束后十五个工作日。”一份待判定的交接请求写道“请确认该达人本场佣金比例为百分之十五并已进入结算。”

## 配置怎么定

| 配置或核对项 | 本页样本中的取值或动作 | 依据与比较方式 |
| --- | --- | --- |
| 关联的知识库 | 关联同一向量模型的合作协议、佣金设置单库 | 核对向量模型标识一致，排除不符者 |
| 搜索模式 | 对“佣金比例”类问题比较语义、全文与混合检索 | 按测试问题观察召回差异，不预设单一模式 |
| 引用上限 | 本次假设试验起点设为覆盖单份协议摘要 | 用长短不同资料测试内容是否完整再调整 |
| 最低相关度 | 先标注相关与无关样本再调阈值 | 该值仅在语义检索或结果重排时生效 |
| 问题优化 | 对“本场佣金”类短问题比较原问题与优化后问题 | 核对主体是否被改错，不默认开启 |
| 结果重排 | 候选较多时按设置启用重排 | 需具备重排模型，重排得分可用于过滤 |

## 容易做错的三处

1. 把检索命中当作授权结果。样本中佣金设置单只写明比例与结算周期，未载明审批或结算已执行；检索返回该条内容不表示结算已发生，也不表示操作权限存在。核对时应比较检索到的字段与交接请求所主张的事实是否同一。
2. 把跨向量模型的知识库强行共同关联。样本要求先核对向量模型标识并排除不符合者，不执行跨模型检索来比较漏召回，也不推断共同关联后的运行结果。
3. 把待审核或报价有效期当作确定结论。若某份材料仅处于待审核状态，该状态不证明缺少操作权限；报价有效期与供货期限属于不同字段，不能相互替代。

## 怎么确认配好了

1. 输入样本中的协议摘要与佣金设置单摘要，比较两份材料中“佣金比例”字段是否同主体、同期间、同字段一致，两处均为百分之十五时视为该字段一致，出现互斥取值才视为矛盾。
2. 输入待判定交接请求，比较其主张的“已进入结算”与材料载明内容，材料只载明结算周期而未载明结算已执行时，该主张属于未获支持，记录为证据缺口。
3. 输入一条明确无对应材料的查询，观察输出引用内容是否为长度 0 的数组，并核对下游设计是否按空结果分支处理，不声称虚构规则检索一定返回空数组。
