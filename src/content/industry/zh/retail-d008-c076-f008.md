# 达人佣金结算与扣佣的跨境资料与多语检索：工作流编排

## 这个品类的数据长什么样

在达人佣金结算与扣佣的跨境资料与多语检索中，本页说明FastGPT的工作流编排如何衔接资料。达人双语账单核费用方向、修订状态及出具主体，语言整理不计算应付。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟双语材料包有平台出具的费用说明、达人提出的账单修订请求及机构转寄便笺。英文费用行仅写平台向合作方收取，中文待核稿却未注明收取方向；修订请求尚未获接收方确认。流程先收每份文件的出具方、接收方和原句，再选择核款项方向或核修订对应。转寄机构不是费用出具方，要求改账也不是新账已生效。本题没有真实币种、费率或金额，不据翻译计算应付或扣款。

## 配置怎么定

| 佣金双语材料角色 | 自拟关系 | 核查动作 |
| --- | --- | --- |
| 费用方向 | 平台收取合作方费用 | 不译成平台付佣 |
| 修订请求 | 达人提出未获采纳 | 不改账单版本 |
| 原账单 | 替代关系待核 | 逐行核新证据 |
| 转寄便笺 | 机构转发 | 不当出具确认 |
| 实际账务 | 无金额或执行 | 另核授权回执 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

- 平台收取费用在中文里变成平台支付佣金时，对原句的付款方与接收方，再查下游解释，不能只因账单都有费用栏就合并方向。

- 达人请求修订被传成已经替换旧账单时，核请求用途、原账单身份和明确采纳记录；收到修改意见不等同账单版本已更新。

- 机构转寄便笺被答成机构出具的确认时，对文件作者与转寄动作，回到平台或达人原文定位真实立场。

## 怎么确认配好了

用同一材料先核收取方向，再走修订路径，逐项比提交与后续接收的作者、动词及版本关系。补新账单须核它替代哪份、哪些行获确认，不能把补文件动作当双方结清。缺方向时继续列待核，不凭正负号或译词猜金额含义。真实账务更正、资金处理与对外发送均需另核业务授权和回执；本流程只交接可追溯的双语文字。
