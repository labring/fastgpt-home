# 进出口许可证件办理的跨境资料与多语检索：知识库检索与召回

## 这个品类的数据长什么样

进出口许可证件办理发生在申报之前，决定货物能否合法进出口。本任务处理自动进口许可证、两用物项许可证、合同、产品说明等资料，资料以中文、英文及供应商所在国语言混合出现。向量搜索具备跨多语言理解能力，例如输入中文问题匹配英文知识点，这一特点对多语资料检索有直接作用。资料按每票更新，不同票的许可证类别、商品编码和用途说明各自独立，检索时需要按票区分范围。

## 这些特征在「知识库检索与召回」这一环带来什么约束

知识库搜索节点可以关联一个或多个使用相同向量模型的知识库。跨不同向量模型的库不可共同关联，操作时先核对各库的向量模型标识，排除不符合者，记录实际观察。检索是对整个库进行搜索，集合仅用于分类管理。引用内容以数组格式输出，长度可以为 0，没有搜索到内容时输出链路仍然走通。

语义检索、全文检索、混合检索各有适用条件。编号、型号、专有名词类查询适合全文检索或混合检索；自然语言问法适合语义检索或混合检索。混合检索通过 RRF 合并两路结果，无法直接进行相似度过滤，通常需要重排模型重新排序，并利用重排得分过滤。最低相关度是过滤阈值，仅在语义检索或使用结果重排时生效，不承担权限或实体隔离功能。检索结果不构成授权，许可证是否有效、审批是否完成需要另行核对。

假设演练样本：某票货物资料中，产品说明原文为“本产品用于工业涂层设备，型号 AC-220，出口目的地为马来西亚。”合同节选原文为“买方应于发货前取得两用物项许可证。”待判定的拟稿句为“该票货物已取得两用物项许可证，可安排发运。”样本中没有任何已签发许可证的记载，拟稿句的许可状态未获支持。

## 配置怎么定

| 配置项 | 本次假设试验起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 关联的知识库 | 两个使用相同向量模型的许可证资料库 | 先核对向量模型标识一致，再关联；标识不同者排除 |
| 搜索模式 | 混合检索 | 样本含型号 AC-220 与自然语言用途描述，比较语义与全文两路召回内容 |
| 引用上限 | 按 token 计量，起点设为能容纳完整产品说明段落 | 用长短不同的实际资料测试内容是否完整，再调整 |
| 最低相关度 | 先标注相关与无关样本再调阈值 | 该值仅在语义检索或结果重排时生效 |
| 问题优化 | 多轮追问场景开启 | 比较原问题与优化后问题，核对主体是否被改错 |
| 结果重排 | 具备重排模型时启用 | 比较重排得分与向量得分，按得分过滤 |

## 容易做错的三处

1. 把拟稿句中的许可状态当作已核实事实。样本原文只记载合同要求发货前取得许可证，没有签发记录。检查方式：输入拟稿句与合同原文，比较两者对许可状态的表述，拟稿句出现“已取得”而原文无对应记载时，判定为未获支持。
2. 把不同向量模型的知识库共同关联。检查方式：输入各库的向量模型标识，比较标识是否一致，出现不一致时排除该库并记录，不执行跨模型检索。
3. 把最低相关度当作权限过滤。检查方式：输入一条涉及未授权记录的查询，比较返回内容与授权范围，相关度得分不改变记录的授权状态，授权判断需要另行核对。

## 怎么确认配好了

1. 输入假设样本的产品说明原文与问题“AC-220 的出口目的地”，比较返回内容是否包含“马来西亚”。返回内容含该目的地且引用数组长度大于 0 时满足条件；返回空数组时记录为未召回，检查数据是否完成训练。
2. 输入拟稿句与合同原文，比较两者对许可证状态的表述。拟稿句的“已取得”在原文中无对应记载时，判定为未获支持，保留证据缺口，不补造授权条款。
3. 输入一条纸面空结果 `[]`，比较下游节点对该数组的处理设计。下游能承接长度 0 的引用并继续执行时满足条件；无法承接时记录为待调整，不声称虚构规则检索一定返回空数组。
