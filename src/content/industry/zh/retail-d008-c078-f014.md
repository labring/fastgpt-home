# 连锁总部选址开店的跨境资料与多语检索：模型接入与配置

## 这个品类的数据长什么样

在连锁总部选址开店的跨境资料与多语检索中，本页说明FastGPT的模型接入与配置如何衔接资料。比较选址中英便笺的租赁意向、测量范围与营业准备状态，核模型所见资料及双语主语。所用场景为自拟文字测试。

## 这些特征在「模型接入与配置」这一环带来什么约束

总部选址练习可自拟中文踏勘便笺“门面已看，后场面积待量”，英文测试对照保留viewed frontage与back-area measurement pending。另有房东邮件表示愿继续谈租赁，未附已签合同或开业批准。接入模型处理多语材料时，应核两语是否都进入本次请求，回答能否区分看过位置、实际测量和双方意向。门面照片的文字描述不能补出后场尺寸，愿继续商谈也不是租约已成立。本题材料只为练习语言对应，不提供真实租赁或选址建议。

## 配置怎么定

| 选址多语核对 | 练习材料 | 核验方向 |
| --- | --- | --- |
| 空间 | 门面已看后场待量 | 不扩已看范围 |
| 意向 | 房东愿继续谈 | 核作者与签署依据 |
| 地点 | 本址与旧候选点 | 地址及区域对应 |
| 期间 | 测量时段与收到资料 | 分别留证 |
| 资料形式 | 文字便笺与平面图 | 实际路径分别测试 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `AI Proxy依赖` | 按实际版本核服务、渠道与应用。 |
| `AIPROXY_API_ENDPOINT` | 使用AI Proxy服务根地址。 |
| `AIPROXY_API_TOKEN` | 管理员Token非空且与服务端一致。 |
| `模型能力` | 按实际输入路径验证所需能力。 |
| `应用参数` | 接口同名字段未必覆盖应用设置。 |

## 容易做错的三处

- 中文后场待量句未传入而英文回答给出面积已确认时，保存两语原文及实际输入，查限制是否在语言选择时丢失。

- 房东愿谈被译成总部已承租时，核邮件作者、意向动词及签署依据，分开房东表态与总部动作。

- 旧候选点测量表被用作本址后场资料时，核地址、空间范围和测量期间，名称相近不能支持当前尺寸。

## 怎么确认配好了

验收分别问哪些空间看过、哪个区域仍待量、谁表示愿继续谈，逐句比对中英输出采用的来源。取得本址测量表后，核其覆盖区域和测量时段，再检查回答新增的内容；资料收到较晚不改变测量发生时间。若改为提供平面图，应另测图像或解析输入是否真的送达，不能从文字路径推整图读取成功。服务根地址与管理员Token属于接入条件，不证明选址人员可读取租赁附件；账号授权和材料使用范围另核。
