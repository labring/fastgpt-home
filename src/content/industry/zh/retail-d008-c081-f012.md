# 连锁门店闭店清算的跨境资料与多语检索：文档解析与分块

## 这个品类的数据长什么样
闭店清算围绕退出与资产回收展开，方向与选址开店相反。主要数据来自POS库存、固定资产系统、租赁合同与财务账，典型文档包括闭店审批、库存清退单、租约解除协议与资产盘点表。这些材料常以跨境、多语形式出现，同一门店的租约解除协议可能为外文，库存清退单为中文，资产盘点表含编号与型号。资料不定期按每店更新。文档解析与分块需要保留能回指原文的文档身份与版本，使不同语种、不同格式的材料在检索时仍可定位到具体条款与数量。

## 这些特征在「文档解析与分块」这一环带来什么约束
分段完整性直接影响检索质量。租约解除协议中的条件、说明与其约束的条款若被拆离，检索可能只召回半句。FastGPT将一组数据映射到多组向量，同一组原数据可对应多个索引，检索命中任一索引即可召回该组数据。语义检索具备跨多语言理解能力，例如中文问题匹配英文知识点，这适合多语资料；全文检索适合编号、型号、专有名词等精确查询。混合检索通过RRF融合多路结果，重排模型对候选文本二次排序并给出0-1得分。引用上限以tokens计，最低相关度仅在语义检索或使用结果重排时生效。检索是召回行为，不承担授权判定，也不隔离实体或权限。

假设演练样本：某门店闭店清算材料原文为“租约解除协议（编号L-2024-017）约定押金于交接完成后30日内退还；库存清退单载明货架12组、收银机3台；资产盘点表列出上述资产状态为待复核。”待判定拟稿句为“押金退还义务已随交接完成而生效。”该句涉及主体、对象、状态与有效范围，需与原文比对。

## 配置怎么定
下表围绕上述样本列出与文档解析与分块相关的官方已说明设置或实施核对项。数值为本次假设试验起点，非官方默认。

| 配置项 | 本次假设起点 | 选择理由与比较方法 |
| --- | --- | --- |
| 搜索模式 | 混合检索 | 样本含编号L-2024-017与自然语言问法，比较语义与全文两路召回 |
| 引用上限 | 假设设为2000 tokens | 样本段落较短，比较不同取值下条款是否完整进入引用 |
| 最低相关度 | 假设设为0.3 | 仅语义检索或重排时生效，比较过滤前后候选数量 |
| 问题优化 | 开启 | 样本问题含指代，比较补全前后检索词差异 |
| 结果重排 | 启用 | 候选较多时比较重排得分排序变化 |
| 分段核对 | 按条款边界人工核对 | 检查条件与所约束内容是否同组 |

## 容易做错的三处
1. 将上传成功当作检索已更新。输入为变更后的租约解除协议，比较上传记录与实际训练、索引状态，观察检索是否仍返回旧条款。现象为返回旧内容时说明索引未更新。
2. 将检索命中当作授权依据。输入为押金退还问题，比较检索结果与授权记录，观察是否把召回内容直接用于执行退款。现象为无授权记录时不得执行。
3. 将最低相关度当作权限或实体过滤。输入为跨门店查询，比较过滤前后结果，观察是否误认为该阈值排除了无关门店。现象为阈值仅影响相关度排序。

## 怎么确认配好了
- 验证一：输入样本原文与拟稿句“押金退还义务已随交接完成而生效”，比较原文“押金于交接完成后30日内退还”与拟稿句，观察拟稿句是否将退还期限与生效条件混同。满足条件为能指出原文仅约定退还期限，未载明义务生效时点。

- 验证二：输入编号L-2024-017，分别用全文检索与语义检索，比较两路召回结果，观察编号是否被准确命中。满足条件为全文检索命中该编号，语义检索结果需人工核对。

- 验证三：输入空结果承接场景，以明确纸面输入[]核对下游设计，比较空数组与下游处理逻辑，观察是否将空结果误判为无权限。满足条件为记录空结果并保留证据缺口，不推断授权状态。

跨不同向量模型的库不可共同关联，需先核标识并排除不符合者，记录实际观察。图片检索须有相应图像输入及模型能力，重排须具备模型且按设置启用。待审核不证明缺少操作权限，签署、合作达成与合同生效是三个不同事实。
