# 逆向退货入仓质检的跨境资料与多语检索：文档解析与分块

## 这个品类的数据长什么样

逆向退货入仓质检处理的是退回包裹与商品等级，不处理新订单出库。核心资料包括退货入库单、质检照片、等级判定表、重售上架单，来源为 WMS 退货模块、平台售后、承运商退件与质检台。每件退货都要扫描、判断状态、决定重售或报废，资料随每件、每日更新。

这些资料进入知识库后，检索要同时覆盖中文问题与英文知识点。语义检索具备跨多语言理解能力，输入中文问题可以匹配英文知识点，这一能力取决于向量模型训练效果。质检照片属于图片资料，能否被检索不只取决于搜索时是否上传图片，也取决于入库时是否建立了对应索引。

## 这些特征在「文档解析与分块」这一环带来什么约束

退货入库单含退货单号、商品编号、退件数量、承运商字段；等级判定表含等级代码与判定条件；重售上架单含上架状态。分块时，条件说明与所约束的内容需要保持在同一数据段内，避免等级判定条件与结论被拆到不同块。同一组原数据可以对应多个向量，一组较长文本添加多组向量后，其中一组被检索到即可召回该数据。

全文检索适合编号、型号、专有名词等精确查询；语义检索适合自然语言问法。混合检索同时使用两路召回并通过 RRF 融合结果。重排模型对候选文本二次排序，得分落在 0-1 区间。最低相关度仅在语义检索或使用结果重排时生效，它是过滤阈值，不承担权限或实体隔离功能。

假设演练样本：某售后仓一批退件，退货入库单载明“退货单号 RT-2024-0317，商品编号 SKU-8842，退件数量 6 件，承运商为 A 线”。等级判定表载明“外观破损且配件缺失，判定为 C 级，不得上架重售”。质检照片两张，重售上架单尚未填写。待判定拟稿句为“该批 6 件已完成质检，等级为 C 级，可安排重售上架”。核对范围限定为该退货单号与商品编号对应的资料，授权边界为质检员与库存管理员，退款与报废决定不在本页范围。

## 配置怎么定

| 配置项 | 本页设定或核对项 | 依据与说明 |
| --- | --- | --- |
| 搜索模式 | 混合检索 | 单号、编号走全文召回，自然语言问法走语义召回，两路经 RRF 融合 |
| 引用上限 | 本次假设试验起点 3000 tokens | 该值为本次演练起点，用于与观察到的单块长度比较，非官方默认值 |
| 最低相关度 | 本次假设试验起点 0.4 | 仅在语义检索或结果重排时生效，与观察到的重排得分比较 |
| 分块核对 | 等级条件与结论保持同块 | 按等级判定表结构逐段检查，避免条件与约束内容拆离 |
| 图片索引 | 核对入库时是否生成图片索引 | 图搜图效果取决于向量模型是否支持图片输入及入库索引 |
| 更新后复核 | 核对实际训练与索引状态 | 上传成功不表示检索已更新 |

## 容易做错的三处

1. 分块把等级判定条件与结论拆开。等级判定表原文“外观破损且配件缺失，判定为 C 级，不得上架重售”被切成两块后，检索只召回“判定为 C 级”，拟稿句据此写出“可安排重售上架”，遗漏“不得上架重售”这一约束。
2. 把检索命中当作授权。拟稿句“可安排重售上架”被检索到，仅说明该内容与问题相关，不表示质检员已获得上架批准，也不表示重售上架单已填写。
3. 把图片未召回直接归因于搜索参数。图片能否被检索取决于入库时是否建立图片索引以及模型能力，未核对索引状态就调整参数，无法定位原因。

## 怎么确认配好了

1. 输入退货入库单原文“退货单号 RT-2024-0317，商品编号 SKU-8842，退件数量 6 件，承运商为 A 线”，用编号 SKU-8842 与自然语言“这批退件有多少件”分别检索。比较召回内容是否包含同一组原数据；若编号查询未命中而自然语言查询命中，记录该观察，不判定为系统故障。
2. 输入等级判定表原文“外观破损且配件缺失，判定为 C 级，不得上架重售”，比较召回块是否同时包含判定条件与“不得上架重售”。若只召回“判定为 C 级”，记录分块拆离这一现象。
3. 输入拟稿句“该批 6 件已完成质检，等级为 C 级，可安排重售上架”，比较其与等级判定表原文。原文载明不得上架重售，拟稿句写可安排重售上架，同一字段出现互斥取值，判定为矛盾；重售上架单尚未填写，上架状态未获支持，保留为待核实。若以空结果输入核对下游设计，记录返回情况，不预设虚构规则一定返回空。
