# MCN机构达人管理的运营权限与交接管理：工作流编排

## 这个品类的数据长什么样

在MCN机构达人管理的运营权限与交接管理中，本页说明FastGPT的工作流编排如何衔接资料。达人管理交接要把培训出席、账号排期与处理事项分开，记录已提交不能说明合作权限已经确定。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟交班文字写达人参加过培训，账号排期仍待本人确认，违规处理表只记已转交。流程可收这些原句及适用账号，人员选择补排期回复或查转交进展。培训出席不自动赋予账号操作权，排期安排也不能证明本人已接受；交接传值应留下待确认和转交性质，不从同一达人名称合并不同账号的事项。

## 配置怎么定

| 达人交班流程 | 自拟原句 | 对应核法 |
| --- | --- | --- |
| 培训出席 | 仅参加培训 | 非账号授权 |
| 账号排期 | 待本人确认 | 取真实回复 |
| 处理表 | 已转交 | 非实际办结 |
| 账号身份 | 同达人不同账号分开 | 核接收对象 |
| 后续业务 | 操作签署另核 | 节点不补权限 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

培训冒权限：若出席记录被当账号授权，应核实际授权关系；排期冒接受：若拟定安排写成本人确认，应取本次真实回复；转交冒办结：若转交处理表被写成已解决，应查对应处理结果。三项分别核权限、对方立场和执行阶段，不由流程走完补出。

## 怎么确认配好了

验收分别查看补排期与查进展路径收到的账号和原句，加入本人回复后只更新已确认的排期范围，另一账号的回复不能补本次安排。若处理结果仍缺，应保留待办，不能被培训记录带过。账号操作、合作签署和正式处理需另接业务步骤核权限及回执，节点记录选择并继续不代表已获得授权或所有合作事项已完成。
