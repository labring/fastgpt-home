# 亚马逊FBM自发货运营的运营权限与交接管理：对话日志与审计

## 这个品类的数据长什么样

FBM由卖家自行履约并设置退货地址，平台仓检验环节不参与，订单拣货单、发货确认单、退货地址设置与物流追踪表构成日常交接的主要材料。承运商选择与跟踪号确认耗时较多，未送达投诉进一步拉长处理链。这些材料随每单与每日更新，交接时若把会话记录、检索结果或表单填写当作授权凭据，后续操作容易脱离原定范围。

对话日志与审计在本品类的作用，是让交接双方能按 chatId、dataId 定位同一会话下的具体轮次，核对谁在什么状态下提出了什么请求。日志留存本身不构成合规审计，对账、留存与合规要求由完整业务方案另行落实。

## 这些特征在「对话日志与审计」这一环带来什么约束

对话接口的 chatId 为空时，系统不使用 FastGPT 提供的上下文功能，完全由传入的 messages 构建上下文；chatId 为非空字符串时，系统自动从数据库取会话，并以 messages 数组最后一个内容作为用户问题，其余 message 被忽略。responseChatItemId 传入后会作为本次响应消息的 ID 存入数据库，需保证在当前 chatId 下唯一。detail 决定是否返回中间值，stream 模式通过 event 区分，非 stream 模式结果保存在 responseData 中。会话列表接口的 source=api 只获取通过 API 创建的会话，不获取页面上的会话；清空应用会话同样只清空通过 API Key 创建的会话。会话管理以 appId、chatId 为键，对话管理以 dataId 定位单条对话，运行详情需按 appId、chatId、dataId 三者查询。

假设演练样本：某FBM卖家客服岗在 2025 年 3 月 10 日就订单 A 的退货地址变更发起交接，会话 chatId 为 "fbm-return-0310"，dataId 为 "rec-0310-01"。交接材料原文为：“订单 A 拣货单已打印，发货确认单未生成；退货地址设置为默认仓地址；物流追踪表无该单跟踪号。”拟判定句为：“退货地址变更已获授权，可直接在会话中确认执行。”该句未载明授权主体、授权时间与授权范围，属于未获支持。

## 配置怎么定

| 核对项 | 官方已说明的设置或字段 | 本样本的核对方式 |
| --- | --- | --- |
| 会话身份 | appId、chatId | 核对该交接请求的 chatId 为 "fbm-return-0310"，与订单 A 记录一致 |
| 对话定位 | dataId | 核对 dataId 为 "rec-0310-01"，确认落在同一 chatId 下 |
| 运行详情 | detail、responseData | 需要中间值时按契约设置 detail，检查 responseData 内容 |
| 会话来源 | source=api | 确认该会话由 API 创建，页面会话不在该列表内 |
| 响应消息标识 | responseChatItemId | 本次假设起点为 "resp-0310-01"，选择理由是与 dataId 同批次便于对照；与同 chatId 下其他 responseChatItemId 比较唯一性 |
| 变量替换 | variables | 核对传入变量是否替换输入框中的 [key]，不推定业务授权 |

## 容易做错的三处

1. 把 chatId 为空与 chatId 非空两种上下文行为混为一谈，输入时未确认 messages 最后一个内容是否被当作本轮问题，比较对象是实际传入的 messages 数组与返回的 historyPreview，观察结果是两者是否指向同一问题。
2. 把 source=api 的会话列表当作全部会话，输入为 appId 与 offset、pageSize，比较对象是列表返回的 chatId 集合与页面会话，观察结果是页面会话是否出现在该列表中。
3. 把检索结果或表单填写当作授权凭据，输入为拟判定句与交接材料原文，比较对象是原文是否载明授权主体、时间与范围，观察结果是该句是否获得支持。

## 怎么确认配好了

1. 输入假设样本中的 chatId "fbm-return-0310" 与 dataId "rec-0310-01"，比较运行详情返回的 query 与 historyPreview 是否对应同一轮次，满足条件是二者指向同一问题且 dataId 落在该 chatId 下。
2. 输入拟判定句“退货地址变更已获授权，可直接在会话中确认执行”，比较材料原文是否含授权主体、授权时间与授权范围，满足条件是原文明确载明这三项；本样本未载明，判定为未获支持，授权缺口保留待核实。
3. 输入 source=api 与会话列表请求参数，比较返回的 chatId 集合与页面会话集合，满足条件是页面会话未出现在该列表中；若出现，记录为不符并复核来源字段。
