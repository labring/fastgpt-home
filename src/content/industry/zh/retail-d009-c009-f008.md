# 亚马逊FBM自发货运营的运营权限与交接管理：工作流编排

## 这个品类的数据长什么样

在亚马逊FBM自发货运营的运营权限与交接管理中，本页说明FastGPT的工作流编排如何衔接资料。自发货交接要保留卖家确认、承运交接和退货地址适用范围，确认文字不能自动证明包裹已经移动。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟交班有拣货清单、卖家发货确认和物流待揽收，退货地址设置未说明本单适用。流程可收订单关系和原句，人员选择补承运记录或核退货说明。卖家确认只是该材料记载动作，不代替真实物流交接；拣货也不说明已发出，地址文件存在不能证明客户应退到那里。这里不虚构平台时效要求或默认地址。

## 配置怎么定

| 自发货交接 | 本题自拟阶段 | 应核来源 |
| --- | --- | --- |
| 拣货清单 | 准备动作 | 非发运完成 |
| 卖家确认 | 与承运记录分开 | 取真实交接 |
| 物流状态 | 待揽收 | 不推已经移动 |
| 退货地址 | 本单适用未明 | 补对应原句 |
| 输入路径 | 承运或地址核对 | 订单对象不变 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

确认冒揽收：若卖家文字变成承运已收，应取本单真实交接；拣货串单：若另一订单清单进入本次，应核商品与来源；地址泛用：若未明适用的设置用于所有退货，应核本单原文依据。三项分别核物流阶段、记录归属和范围，不由交接选项认证。

## 怎么确认配好了

验收检查承运与地址路径收到同一订单，补揽收证据后只更新物流步骤，退货适用仍缺时保留待核。若实际记录只是生成追踪标识，不能写成包裹已移动。正式发货、地址变更和客户通知需另接流程核权限及回执，节点运行不证明订单已送达或退货已经受理。
