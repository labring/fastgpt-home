# 加盟商培训与开业辅导的运营权限与交接管理：对话日志与审计

## 这个品类的数据长什么样

加盟商培训与开业辅导属于经营能力移交，与特许备案披露分属不同工作。主要材料来自培训系统、督导APP、门店照片与总部SOP库，日常文档包括培训签到表、开业检查表、SOP手册与考核成绩。这些材料按每店每月更新，构成区域督导向加盟店主移交运营能力的证据链。

对话日志与审计环节面对的是：培训与辅导过程中的对话记录、运行详情与反馈数据。这些数据能否作为交接依据，取决于身份字段、会话归属与运行详情是否可核对，不取决于日志是否存在。

## 这些特征在「对话日志与审计」这一环带来什么约束

会话归属靠 chatId 区分，同一应用下不同 chatId 代表不同会话。对话记录通过 dataId 定位，运行详情需在对话接口中设置 detail=true 后从 responseData 读取。detail=false 时只返回最终回答，中间模块状态不出现。detail=true 且 stream=false 时，responseData 保存各模块的 moduleName、moduleType、runningTime、tokens 等字段；stream=true 时相同内容通过 event=flowResponses 传递。

authProxy 用于代理团队成员身份，需团队所有者创建或编辑 key 时开启，代理身份仍要具备目标应用和会话权限。检索相关度分数只反映文本相似程度，不承担业务实体隔离或权限过滤。日志留存不等于完成合规审计，对账与合规要求由完整业务方案另行落实。

假设演练样本：某连锁品牌培训部为华东区新加盟店“示例店A”建立开业辅导对话应用。2025年3月10日，区域督导提交一条交接请求，拟稿句为“示例店A收银岗位培训已完成，可交接开业”。供核对的材料原文为：培训签到表记录2025年3月8日收银岗位参训4人，签到栏有3人签名；考核成绩表显示该岗位3人通过、1人缺考；开业检查表收银模块状态栏为“待复核”。该请求的授权边界为：区域督导可提交交接申请，交接确认需培训部与运营部共同签署，本请求尚未获得签署。

## 配置怎么定

| 核对项 | 本页相关取值或动作 | 判断依据 |
| --- | --- | --- |
| 会话标识 | 记录 appId 与 chatId，核对目标对话归属 | 同一 chatId 下 dataId 唯一 |
| 运行详情 | 对话接口设 detail=true，从 responseData 读取模块字段 | detail=false 不返回中间状态 |
| 身份代理 | 核对 authProxy 是否由团队所有者开启 | 代理身份仍需目标应用与会话权限 |
| 反馈数据 | 按 dataId 读取 userGoodFeedback 或 userBadFeedback | 取消时不填对应参数 |
| 检索分数 | 记录 similarity 数值，仅作文本相似度参考 | 分数不承担权限或实体过滤 |
| 假设起点 | 相似度参考值设为0.80，用于本次纸面比对 | 选择理由为便于区分高相似与低相似条目，与样本中0.61等实际返回分数比较 |

## 容易做错的三处

1. 把 detail=false 的返回当作完整运行记录。该模式只返回最终回答，模块状态与 tokens 不出现。核对时应确认请求参数中 detail 的实际取值，再对照返回结构中是否存在 responseData。
2. 将 similarity 分数用于判断会话是否有权访问。分数只反映文本相似程度，权限由 authProxy 与目标应用会话权限决定。核对时应分别检查身份配置与分数数值，不将两者合并判断。
3. 把待复核状态的开业检查表读作已完成。样本中收银模块状态为“待复核”，拟稿句称培训已完成可交接。核对时应逐字段比较检查表状态栏与拟稿句表述，状态未变为通过前，交接请求缺少支持。

## 怎么确认配好了

1. 输入样本中的拟稿句“示例店A收银岗位培训已完成，可交接开业”，比较培训签到表签名人数3人与参训4人、考核成绩表缺考1人、开业检查表状态“待复核”。当签到、考核、检查三项均显示完成时，拟稿句才获得支持；当前三项中两项未闭合，拟稿句未获支持。
2. 输入对话接口请求，detail 设为 true、stream 设为 false，比较返回结构中是否出现 responseData 数组及各元素的 moduleName、moduleType、runningTime。当 responseData 存在且包含预期模块时，运行详情可读取；若 detail 为 false，responseData 不出现，运行详情未知。
3. 输入样本中区域督导的交接请求，比较授权边界说明中的签署要求与当前签署记录。当培训部与运营部双方签署均存在时，交接确认成立；当前仅有提交动作，签署记录缺失，交接确认未成立，属待核实状态。
