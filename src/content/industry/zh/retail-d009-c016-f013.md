# 加盟商培训与开业辅导的运营权限与交接管理：权限与数据隔离

## 这个品类的数据长什么样

在加盟商培训与开业辅导的运营权限与交接管理中，本页说明FastGPT的权限与数据隔离如何衔接资料。围绕未核门店事项交接访问，区分整改历史保留与原督导继续读取。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

交接练习可拟待复核门店清单、本轮整改说明和旧培训签到，接手督导拟查哪些事项仍缺现场依据。把待办与实际资源逐项对应，新账号需要什么原文由责任人确认；继任职责不能自动覆盖总部全部规则。旧签到保留可用于追溯，但不说明新人员取得现行SOP，或原督导继续拥有本店资料。照片与检查的门店、日期和来源说明要一并保留，防止历史记录代本轮情况。

## 配置怎么定

| 督导交接权限 | 未结门店事项 | 验收动作 |
| --- | --- | --- |
| 待复核清单 | 整改说明和缺少现场依据 | 新账号实际原文 |
| 旧培训 | 签到不替代现行SOP | 版本及日期 |
| 原督导 | 门店整改与内部规则撤权 | 同源返回和拒绝 |
| 外部身份 | 培训及督导应用分别核 | 账号接口实际结果 |
| 关闭条件 | 留存交接与整改执行分开 | 记录及责任确认 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 接手人只读旧签到便确认当前检查齐备：比对未核清单、实际原文及资料日期，签到缺现场依据，不能补成本轮核验。

- 原督导仍读应撤销的门店整改或内部SOP：保留同源完整回答和授权范围，名单改动与交接签字不证明实际拒绝。

- 总部转岗被当培训系统和督导应用身份同步终止：分别核外部账号及接口，保留历史不等于继续获权，撤权也不证明整改已完成。

## 怎么确认配好了

验收用新账号读取待复核事项，用原督导及无关门店身份请求同一限制材料，记录原句、操作及拒绝。新账号已可读却答旧版要求时，查本轮输入，不以继续扩权处理。外部身份的撤销、现场依据的补取与历史留存分别留证；材料变化后复测原范围。交接不自动安排培训、复核现场或关闭整改，未结事项仍需真实执行资料和责任人确认。
