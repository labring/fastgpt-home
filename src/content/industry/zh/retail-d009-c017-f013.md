# 加盟费与保证金结算的运营权限与交接管理：权限与数据隔离

## 这个品类的数据长什么样

在加盟费与保证金结算的运营权限与交接管理中，本页说明FastGPT的权限与数据隔离如何衔接资料。按未结对账事项交接资源，分别核历史凭据保留、旧人员撤权和外部财务身份。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

交接练习可拟本期未核对账清单、旧付款安排和收到的开票说明，接手财务拟取得本店尚缺来源。先列期间、门店与凭据身份，再确认新账号应读哪些资料及操作。历史凭据仍需留存不等于原经办人继续获权，也不保证接手者拿到本期实际资金记录。付款安排和收付阶段不同，不能把交接表“已整理”改写成对账已平或双方已确认。

## 配置怎么定

| 财务交接权限 | 本期待办 | 实际验收 |
| --- | --- | --- |
| 资料清单 | 未核对账和开票文字 | 新账号来源身份 |
| 旧安排 | 历史计划不供本期资金证据 | 期间及实际返回 |
| 原经办 | 凭据和他店资料撤权 | 同源回答和拒绝 |
| 外部服务 | 银行财务身份另验 | 账号接口实际结果 |
| 结账动作 | 交接不生成凭证或平账 | 本期记录及责任确认 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 新人员只读旧计划便称本期收付依据齐全：并列未核清单、期间与实际返回，确认本期凭据是否取得，不借历史金额或日期补证。

- 原经办身份仍读应撤销凭据或他店违规资料：保留同源完整回答与授权范围，归档和签字不证明访问已被拒绝。

- 内部财务转岗被当银行或财务服务身份同步终止：核外部账号及接口，撤权不处理实际款项，也不替代未结事项责任确认。

## 怎么确认配好了

验收用接手账号查本期待办，再以原人员及无关加盟店身份请求相同受限资料，记录原句和实际操作。账号正确却答旧期间时，先查输入和原文归属，不以扩权修历史承接。外部身份撤销与凭据历史保留分别验，补新回执后在原范围复测。交接不自动生成凭证、确认收款或关闭对账；缺少本期资料的事项继续待核，不由名单变更写成业务完成。
