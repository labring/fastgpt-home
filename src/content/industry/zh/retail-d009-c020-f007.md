# 原产地证书申办的运营权限与交接管理：对话日志与审计

## 这个品类的数据长什么样

原产地证书申办围绕原产地证申请、商业发票、装箱单、生产成本资料展开，服务进口国关税与清关，与信用证审单的约束来源不同。日常数据来自中国国际贸易单一窗口、贸促会系统、企业生产记录与客户清关要求。资料给出每单与批量的更新频率，本页功能不依赖该频率，故不展开同步机制。对话日志与审计这一环要处理的，是同一份证书材料在咨询、填报、交接之间留下的会话记录与运行详情，材料本身与对话记录必须按 chatId、dataId 分别对应。

## 这些特征在「对话日志与审计」这一环带来什么约束

对话接口文档说明，chatId 为不传入时不使用上下文，为非空字符串时从数据库取会话并以 messages 最后一个内容作为用户问题，其余 message 被忽略；responseChatItemId 在当前 chatId 下须唯一。运行详情须设置 detail，非 stream 模式结果保存在 responseData，stream 模式通过 event 区分。文档同时说明，接口不返回实际消耗 Token 值，需要时可设置 detail=true 并手动计算 responseData 里的 tokens。日志存在不等于完成合规审计，对账、留存与合规要求由完整业务方案另行落实。

假设演练样本：某外贸单证员就一份原产地证申请发起会话，材料原文为「原产地证申请：出口商甲，目的国乙，商品丙，申请日期 2025 年 3 月 10 日；商业发票金额 12000 美元；装箱单 40 箱；生产成本资料显示本地增值比例 42%」。会话 chatId 记为 H-20250310-01，dataId 记为 D-01。拟交接请求为「将该会话的运行详情与反馈记录移交下一班次，用于核对填报依据」。该请求中的移交对象、授权范围与生效条件均未载明，属待核实状态，不构成已完成交接。

## 配置怎么定

下表围绕上例，列出与本功能、本任务相关的官方已说明设置或实施核对项。数值一栏为本次假设试验起点，仅用于试跑比对，不作为官方默认值。

| 配置项 | 官方依据或核对动作 | 本次假设起点与比较方式 |
| --- | --- | --- |
| appId 传参 | 推荐在请求体传入 body.appId，优先级为 body.appId、apiKey-appId、apikey 关联的 appId | 起点用样本 appId，与响应中 appId 比对是否同一应用 |
| chatId | 非空字符串时从数据库取会话，须自行确保唯一且长度小于 250 | 起点 H-20250310-01，与获取会话列表返回的 chatId 逐字比对 |
| responseChatItemId | 传入则作为本次响应消息 ID 存入数据库，当前 chatId 下须唯一 | 起点 D-01，与 getResData 返回的 dataId 比对 |
| detail | 需要中间值时设置 detail=true，非 stream 结果在 responseData | 起点 detail=true，检查 responseData 是否含该轮节点记录 |
| source | 获取会话列表时 source=api 只取 API 创建的会话 | 起点 source=api，与页面会话区分后再统计 |
| authProxy | 代理团队成员身份须团队所有者开启，且代理身份仍须具备目标应用与会话权限 | 起点为未开启，核对实际返回是否与开启状态一致 |

## 容易做错的三处

1. 把检索或表单当成授权执行。表单只收集值，业务验证、审批、数据库写入与外部同步需要各自的下游实现。上例中「移交下一班次」的请求未载明授权边界，不能因会话记录存在就认定交接已获批准。
2. 把相似度当作权限或实体过滤。相关度分数不是分类、实体或权限过滤器，检索不承担授权，不能据此排除无关业务或未授权记录。上例中若出现其他出口商的相似材料，须另行按标识核对。
3. 把未返回字段推定为已完整留存。接口文档说明不会返回实际消耗 Token，需要时设置 detail 并手动计算 tokens；未返回的业务数据不能推定已完整留存。上例中生产成本资料的中间值若不在 responseData 中，应记录为缺口。

## 怎么确认配好了

1. 输入样本 chatId H-20250310-01 与 dataId D-01，调用获取单个对话运行详情，比较返回的 dataId 与拟交接记录中的 dataId 是否一致；一致时该条记录可对应到本次会话，不一致时记录为标识不符并停止对应。
2. 输入样本拟交接请求原文，比较请求中是否载明移交对象、授权范围与生效条件；三项均载明且与材料主体一致时满足核对条件，任一项缺失时记录为待核实，不判定为已完成交接。
3. 输入 detail=true 的样本请求，比较 responseData 中出现的模块记录与材料原文所列申请、发票、装箱单、成本资料是否逐项对应；能逐项对应时满足核对条件，出现材料未列字段时记录为需人工确认。空结果承接可用纸面输入 [] 核对下游设计，不声称虚构规则检索一定返回空。
