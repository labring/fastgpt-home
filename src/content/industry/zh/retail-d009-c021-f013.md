# 品牌会员私域运营的运营权限与交接管理：权限与数据隔离

## 这个品类的数据长什么样

在品牌会员私域运营的运营权限与交接管理中，本页说明FastGPT的权限与数据隔离如何衔接资料。交接会员活动时按未结内容移交资源，另核旧人员和CRM身份，不随标签转交触达权。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

交接练习可列待确认活动说明、旧版标签定义和未发送沟通稿，接手人员拟查当前规则，不使用真实人群。先确认本次活动、门店和原文版本，列新账号必要读取及维护范围。历史活动保留可解释旧决定，不说明旧人员继续可读全部会员来源。沟通稿转交也不表示接手人有发送资格；标签的业务含义、团队资源权限和CRM外部身份须分别确认，不能由一张交接表代替。

## 配置怎么定

| 会员活动交接权限 | 待办及历史 | 验证动作 |
| --- | --- | --- |
| 当前事项 | 待确认规则及未发稿 | 新账号必要资源 |
| 旧定义 | 标签不代本次活动依据 | 版本和实际返回 |
| 原人员 | 活动与他店来源撤权 | 同源回答及拒绝 |
| 外部责任 | CRM身份与触达资格 | 分别核实际依据 |
| 运营执行 | 交接不改标签积分消息 | 记录及业务许可 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 新人员只得旧版标签便称当前活动资料齐备：并列待办和实际返回核适用规则，名单存在不能补本次活动依据。

- 原经办仍读应撤销的活动资料或他店会员来源：保留同源完整回答查授权，归档与人员清单变更不说明实际拒绝。

- 内部活动负责人更换被当CRM身份终止或触达资格转交：分别核外部账号及本次业务许可，移交资源不执行发送。

## 怎么确认配好了

验收让新账号读取当前活动待办，再用原人员及无关门店身份请求相同限制材料，记录原句、操作和拒绝。若新账号有权却答旧版说明，查输入与历史版本，不扩大会员资料范围。旧身份撤权、历史留存和触达责任分别留证，规则补齐后按原范围复测。交接不修改标签、积分或消息状态；尚未确认活动依据或处理许可的事项继续待核，不用交接完成推定已运营执行。
