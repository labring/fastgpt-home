# 品牌直营门店运营的运营权限与交接管理：权限与数据隔离

## 这个品类的数据长什么样

在品牌直营门店运营的运营权限与交接管理中，本页说明FastGPT的权限与数据隔离如何衔接资料。交接直营店未结事项时核班次与资源，旧岗位和外部系统身份分别撤销。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

交班练习可列待核陈列、当前排班和上一班调拨说明，新店长拟跟进本店未结事项。先确认门店、班次与原文日期，再列接手账号必要的读取和操作。品牌内部调任不说明全部门店资料自动转交；旧班记录可留作追溯，原人员是否继续可读需另核。排班和调拨申请都是安排性质，交接表写“已转”不说明人员到岗、货物接收或现场已经复查。

## 配置怎么定

| 直营店交接权限 | 本班未结来源 | 验收动作 |
| --- | --- | --- |
| 当前清单 | 陈列排班和调拨分开 | 门店班次及原文 |
| 旧班照片 | 不供本班现场结论 | 拍摄说明和返回 |
| 原店长 | 人员及绩效资料撤权 | 同源回答与拒绝 |
| 外部身份 | POS CRM库存分别核 | 账号接口及留存 |
| 结项条件 | 转交不等出勤调拨巡检 | 执行记录及确认 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 新账号只看旧班照片便称本店当前检查齐备：并列待核清单、拍摄说明与实际返回，缺本班资料继续列，不用同店名称补时点。

- 原店长仍读应撤销的本店人员或内部绩效资料：保留同源完整回答和授权范围，岗位名单变化与归档不证明真实拒绝。

- 内部调任被当POS CRM和库存系统身份同步终止：分别核外部账号接口，旧记录留存不等继续获权，撤权不完成店务处理。

## 怎么确认配好了

验收以新账号读取本班待办，再用原店长和无关门店身份请求相同受限来源，留原句、操作和拒绝。若可读却答上一班安排，核实际历史及输入日期，不增加门店范围。外部身份撤销、旧资料保留和本班缺证分别留档，补新现场说明后按原权限复测。交班不登记考勤、确认调拨或关闭巡检；事项结项需真实执行记录与责任人确认，不由团队权限转交直接认定。
