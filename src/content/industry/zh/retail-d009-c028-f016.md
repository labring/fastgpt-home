# 品牌自播直播间运营的运营权限与交接管理：表单与交互

## 这个品类的数据长什么样

在品牌自播直播间运营的运营权限与交接管理中，本页说明FastGPT的表单与交互如何衔接资料。品牌自播交接把脚本审核、素材权限与账号操作分别确认，表单姓名不等于可开播。所用场景为自拟文字测试。

## 这些特征在「表单与交互」这一环带来什么约束

假设直播交接资料说脚本已初审，图片使用期限待核，继任人员姓名已填但账号权限未给。表单收场次、素材版本与交接事项，缺必填和补齐两种输入都检查。人员选择补素材或核账号，节点只按选择继续相应分支，不充当员工目录，也不自动办理权限。

## 配置怎么定

| 自播交接表单 | 假设状态 | 核查材料 |
| --- | --- | --- |
| 脚本初审 | 层级未完 | 查最终批准 |
| 图片期限 | 本场待核 | 核授权范围 |
| 继任姓名 | 未给账号权限 | 查真实授权 |
| 选择路径 | 素材或账号 | 核提交承接 |
| 开播办理 | 真实系统另接 | 独立审批回执 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入` | 收集输入并在提交后传值。 |
| `必填信息核对` | 业务必填与缺项处理需另设计。 |
| `用户选择` | 选择结果对应已连接的分支。 |
| `交互状态` | 分别核等待和完成交互状态。 |
| `后续处理分工` | 校验、审批及写入另核结果。 |

## 容易做错的三处

初审被答准许开播时，查正式批准；填姓名被答账号可用时，查权限记录；旧场素材许可套本场时，对期限和场次。三处分别看审核层级、身份与授权范围，纸面齐全不证明操作可执行。

## 怎么确认配好了

验收逐支比对提交内容与后续实际输入，素材补证只解决本场使用范围，账号仍独立核。保存缺项与补齐前后的结果，让复核人能定位未决事项。开播、发布、账户授权和业务写回须另接真实系统与审批回执，交互结束不代表整场交接完成。 脚本版本与素材期限各列原文位置，便于接手人继续查证。 开播准备表按场次关联脚本，继任人员的工作交接与账户可用证据分别列示。
