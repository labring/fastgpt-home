# 品牌自播直播间运营的运营权限与交接管理：部署与升级

## 这个品类的数据长什么样

品牌自播由品牌自身承担话术、库存与售后，与达人专场直播以达人佣金为主的模式存在差别。主要数据来源包括抖店罗盘、巨量千川、直播间评论与成交明细，典型从业主体为品牌直播团队、场控、主播与投流专员。日常文档集中在直播脚本、商品讲解卡、排班表与直播复盘。数据按每场、小时更新，这一频率影响的是复盘材料的时效标注，不改变本页涉及的权限与交接判定。

## 这些特征在「部署与升级」这一环带来什么约束

升级到 v4.17.2 需更新 fastgpt-app 与 fastgpt-pro 镜像 tag，并执行两个手动触发脚本：`20261008_migrate_chunk_training` 与 `20261009_migrate_dataset_rebuild_status`。前者要求在确认集群中所有旧版本 App 与 Pro 实例已完全停止、旧任务租约过期后再点击执行；后者依赖前者完成。两项均属手动触发，不阻塞服务启动。从 4.15.0 起开源版不再读取 `config.json`，旧字段需改为环境变量，未使用过这些可选配置时无需额外添加。App 与 Admin 必须设置 `AIPROXY_API_ENDPOINT` 与非空 `AIPROXY_API_TOKEN`，缺少任一项会导致启动校验失败。

假设演练样本：某品牌自播团队排班表原文载明「场控甲负责 3 月 10 日 20:00 场次，授权范围限于讲解节奏与库存播报，不涉及售后工单处理」。同份排班表另有一句拟稿交接请求：「主播乙申请在 3 月 10 日场次结束后接管售后工单处理权限」。该请求未附任何授权签署记录，排班表亦未载明售后权限归属字段。

## 配置怎么定

| 配置项 | 本次假设起点 | 选择理由与比较对象 |
| --- | --- | --- |
| `AIPROXY_API_ENDPOINT` | `http://aiproxy:3000` | 文档要求根地址且不追加 `/v1`，与单模型自定义请求地址比较 |
| `AIPROXY_API_TOKEN` | 假设填写非空值 | 文档要求非空且与服务端一致，与空值比较 |
| `AGENT_SANDBOX_OPENSANDBOX_VOLUME_NAME_PREFIX` | 沿用旧 `VM_VOLUME_NAME_PREFIX` 值 | 文档要求升级时沿用，与新建默认前缀比较 |
| `FILE_TOKEN_KEY` | 假设使用随机强密钥 | 文档要求至少 6 位且不使用示例值 |
| `INVOKE_TOKEN_SECRET` | 假设使用随机强密钥 | 文档要求至少 32 位 |
| `SYNC_INDEX` | `true` | 文档说明关闭后需自行维护索引 |

## 容易做错的三处

1. 把排班表中的拟稿交接请求当作已完成授权。该请求未附签署记录，排班表也未载明售后权限字段，属于未获支持状态。
2. 把 `20261008_migrate_chunk_training` 的点击执行当作已完成迁移。文档说明该脚本为手动触发，需先确认旧实例停止与租约过期。
3. 从旧 `config.json` 字段名推断现行环境变量行为。4.15.0 起开源版不再读取该文件，字段对应关系需按官方表格核对。

## 怎么确认配好了

1. 输入排班表原文两句及拟稿请求，比较「授权范围限于讲解节奏与库存播报」与「接管售后工单处理权限」是否指向同一字段。若排班表未载明售后权限字段，则该请求处于待核实状态，不判定为已授权。
2. 输入 `20261008_migrate_chunk_training` 与 `20261009_migrate_dataset_rebuild_status` 两项脚本名称及文档所述触发条件，比较当前集群是否存在运行中的旧版本实例。若存在，则两项脚本的执行前置条件未满足。
3. 输入 `AIPROXY_API_ENDPOINT` 与 `AIPROXY_API_TOKEN` 两个配置项，比较其是否同时非空且 endpoint 未追加 `/v1`。若任一项为空或 endpoint 含 `/v1`，则启动校验将失败，需按文档修正后重启。
