# 商超收银与会员促销的运营权限与交接管理：工作流编排

## 这个品类的数据长什么样

在商超收银与会员促销的运营权限与交接管理中，本页说明FastGPT的工作流编排如何衔接资料。收银促销交接分清培训演示、规则适用和真实账号授权，交互状态不等于交班完成。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

自拟交班材料含演示账号截图、某店会员活动说明与待移交设备清单。先收门店、岗位和实际待办，由人员选择核促销规则或补设备信息，再传给对应下游。演示账号不提供生产权限，活动说明也未证明已配置。节点等待交互与继续执行应按实际记录核，不增加所谓全局交班开关。

## 配置怎么定

| 收银交班编排 | 假设材料 | 验证重点 |
| --- | --- | --- |
| 演示账号 | 培训截图 | 查真实授权 |
| 活动门店 | 仅指定范围 | 不泛化适用 |
| 设备清单 | 待交接 | 对签收凭据 |
| 选择分支 | 规则或设备 | 查输入输出 |
| 交班完成 | 独立业务手续 | 不由状态推定 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

演示截图被作正式授权时，查真实账号审批；某店活动被套其他门店时，对适用范围；设备清单被答全部交付时，核实际签收。三处分别看权限、范围和物品事件，本例没有真实收银或会员处理结果。

## 怎么确认配好了

验收记录每个分支的原始输入与接收字段，缺设备签收时继续列缺，规则说明补齐也不能使账号自动开通。促销配置、账号移交和设备签收需要业务系统或实际交接手续；流程用于组织核对，不能由材料齐备推整场交班完成。 设备签收与账号授权各列凭据位置，交班复核逐项核对。 交班表将演示环境标记贴在截图旁，设备签收栏保留物品对应，便于接班核验。
