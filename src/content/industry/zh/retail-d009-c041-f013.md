# 平台促销报名与价格管理的运营权限与交接管理：权限与数据隔离

## 这个品类的数据长什么样

在平台促销报名与价格管理的运营权限与交接管理中，本页说明FastGPT的权限与数据隔离如何衔接资料。交接按进行中的活动与平台核资源，验证旧经办撤权及接手人员的必要访问。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

交接练习可列当前活动报名、上一场复盘和另一平台的库存附页，接手人员仅拟跟进当前报名。先核新账号能否读取适用说明及必要库存来源，记录活动、平台和版本。若只取得上一场复盘，无法证明当前任务材料可用，应并列交接所指与实际返回排查。职务相同或商品相同不说明全部历史审批与跨平台资料都应移交，范围需要业务责任人确认。

## 配置怎么定

| 交接权限核对项 | 活动平台与资源 | 验收记录 |
| --- | --- | --- |
| 当前跟进 | 本场报名与上场复盘分开 | 新账号的活动及版本 |
| 平台限制 | 另一平台库存附页另定 | 责任人确认移交边界 |
| 旧账号 | 审批与内部测算撤权独立验 | 原身份完整返回 |
| 不同事项 | 过期、归档和撤权分开 | 逐项核实际结果 |
| 业务批准 | 可操作不代表已获活动变更批准 | 执行记录及未解决项 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 新身份只取上场复盘便称本场报名可用：核活动平台和适用版本，保存交接指向与返回，商品同名不提供当前来源。

- 旧经办仍读审批及内部测算：保留完整返回和资源配置查撤权，新账号获权不证明原账号已被拒绝，跨平台范围另定。

- 入口到期、归档或团队变更被当外部访问终止：分别核这些结果及ERP后台身份，不能互相代替，技术操作不等于活动变更获批。

## 怎么确认配好了

验收记录新身份对当前活动的必要访问、旧身份应被拒绝的资料以及不应移交平台的否定测试。若访问正常却回答上场条件，应查输入和版本，不因内容串用就盲目扩大权限。操作允许不代表已有调整活动或库存的业务批准，具体变更仍需另核实际执行。最终按资源保留未解决项，人员交接结束不说明报名已通过、库存已锁或活动经营条件已全部满足。
