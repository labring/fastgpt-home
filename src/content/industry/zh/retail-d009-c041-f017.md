# 平台促销报名与价格管理的运营权限与交接管理：部署与升级

## 这个品类的数据长什么样

平台促销报名与价格管理围绕价格、库存与活动节奏展开，主要资料来自天猫营销后台、京东活动后台、ERP库存与历史成交价，日常文档包括活动报名表、促销价审批单、库存锁定表与活动复盘表。本页只处理运营权限与交接管理中的部署与升级环节，判定材料、操作与请求各自处于何种授权状态。

资料更新频率为周与每场活动。本页不据此推断任何批量同步、全量同步或交易触发机制。

## 这些特征在「部署与升级」这一环带来什么约束

交接判定需要同主体、同期间、同一字段。待审核状态不证明缺少操作权限；报价有效期不表示供货期限；检索与表单收集本身不构成授权执行。

假设演练样本。 材料原文一：门店运营甲于2026年3月2日提交《春季大促报名表》，报名对象为A款商品，活动档期3月8日至3月12日，报名状态为「待审核」。材料原文二：同日提交的《促销价审批单》写明A款活动到手价199元，审批状态为「待审核」，审批人栏为空。材料原文三：《库存锁定表》显示A款锁定数量500件，锁定状态为「已锁定」，锁定截止3月7日。

待判定的交接请求句：「甲已取得A款春季大促的报名与价格授权，可将报名表、审批单与锁定表交接给乙执行上架。」

配置表围绕该样本，只列官方已说明的设置或实施核对项。表中数值为本次假设试验起点，选取理由与比较对象随行说明，均非官方默认值。

## 配置怎么定

| 项目 | 本次假设试验起点 | 选取理由与比较对象 |
| --- | --- | --- |
| 部署版本核对 | 记录当前 fastgpt-app 与 fastgpt-pro 镜像 tag | 与官方 V4.17.2 升级说明列出的目标 tag 逐项比对，不从旧配置名称推断现行行为 |
| AI Proxy 根地址 | 设为服务根地址，不追加对话接口路径 | 与 AIPROXY_API_ENDPOINT 文档说明比对，确认未填单模型地址 |
| AI Proxy 管理员 Token | 设为与服务端一致的非空值 | 与 AIPROXY_API_TOKEN 文档说明比对，确认非空且不作为应用调用凭证 |
| 升级脚本执行前置 | 确认旧版本实例已完全停止、旧任务租约已过期 | 与 20261008_migrate_chunk_training 与 20261009_migrate_dataset_rebuild_status 的手动触发说明比对 |
| 升级后验证样本 | 用与升级前相同的导入、检索与应用调用样本复核 | 与升级前记录的同一样本结果比对，步骤执行完成不构成零中断结论 |
| 交接材料授权状态 | 逐份记录报名表、审批单、锁定表各自状态字段 | 与样本原文比对，待审核状态不记为已授权 |

## 容易做错的三处

1. 将《促销价审批单》的「待审核」读作已获价格授权。输入为审批状态字段，比较对象为样本原文的「待审核」与空审批人栏，可观察结果为状态字段未变为已批准。
2. 将《库存锁定表》的「已锁定」当作报名与价格授权。输入为锁定状态字段，比较对象为锁定对象与截止日期，可观察结果为该字段只描述库存占用，未载明报名或价格权限。
3. 将检索命中或表单提交当作授权执行。输入为检索结果或表单记录，比较对象为样本原文是否载明授权主体与生效范围，可观察结果为两者均未载明授权结论。

## 怎么确认配好了

1. 输入样本原文三句与待判定交接请求句，比较报名状态字段与「已取得授权」表述，观察结果：报名状态为「待审核」时，该请求句未获材料支持，需记录为待核实。
2. 输入审批状态字段与审批人栏，比较「待审核」与空审批人栏同「已获价格授权」的表述，观察结果：两处字段均未载明批准结论，该部分判定为未获支持。
3. 输入《库存锁定表》的锁定状态与截止日期，比较其字段含义同报名、价格授权范围，观察结果：该表载明锁定截至3月7日，不能支持3月8日至12日活动期间仍有锁定；也不能补出报名或价格授权。期间覆盖与两项授权分别待核，不推断系统已自动释放。
