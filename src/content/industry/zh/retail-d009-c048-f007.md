# 快递面单与揽收交接的运营权限与交接管理：对话日志与审计

## 这个品类的数据长什么样

快递交接发生在包裹离仓节点，核心是承运商扫描责任。这一特征决定对话日志与审计要同时面对两类材料：电子面单、交接清单、揽收扫描记录、异常件登记等业务文档，以及通过对话接口产生的会话、对话与运行详情。业务文档由快递系统、WMS发运、承运商账单承载，对话侧记录由 chatId、dataId、responseChatItemId 等标识串联。两者身份口径不一致时，日志核对容易把不同入口的会话混算。

对话接口文档说明，chatId 为非空字符串时自动从数据库取会话，并以 messages 数组最后一个内容作为用户问题；responseChatItemId 在当前 chatId 下需唯一。detail=true 时返回中间值，非 stream 模式结果保存在 responseData；detail=false 时不返回中间值。这些字段决定审计能看到什么，看不到什么。

## 这些特征在「对话日志与审计」这一环带来什么约束

对话日志的留存不等于完成合规审计。对账、留存与合规要求由完整业务方案另行落实。检索相似度只反映召回排序，不承担权限或实体隔离，不能据 similarity 或 score 判定某个会话属于某网点或某承运商。

以下为假设演练样本，仅用于本页核对方法说明，不代表真实记录或已发生业务。

材料原文一（假设交接清单摘录）：「2026年3月10日，发运组将批次 A-0310 的 120 件包裹交承运商网点 N1，交接人签字栏为空，备注栏写『待网点补签』。」

材料原文二（假设揽收扫描记录摘录）：「2026年3月10日，N1 对批次 A-0310 扫描 96 件，其余 24 件状态栏为空。」

材料原文三（假设异常件登记摘录）：「2026年3月11日，登记 A-0310 差异 24 件，原因栏写『待承运商确认』，处理结果栏为空。」

待判定拟稿句：「该批次已完成揽收交接，差异已闭环。」

## 配置怎么定

下表围绕上述样本，列出与本功能、主任务相关的官方已说明设置或实施核对项。数值为本次假设试验起点，需与对照值比较，不属官方默认。

| 配置项 | 本次假设起点 | 比较与说明 |
| --- | --- | --- |
| chatId | 假设取「audit-A-0310」 | 与业务记录中该批次对应会话标识比较，确认指向同一对话 |
| responseChatItemId | 假设取「resp-A-0310-01」 | 在该 chatId 下核对唯一性，避免同一响应 ID 重复入库 |
| detail | 假设取 true | 与 false 返回比较，确认 responseData 是否含所需节点运行详情 |
| stream | 假设取 false | 与 true 比较，确认结果落在 responseData 或 event 分支 |
| source | 假设取 api | 与页面来源会话比较，确认取回范围限于 API 创建会话 |
| loadCustomFeedbacks | 假设取 true | 与 false 比较，确认自定义反馈是否随对话列表返回 |

## 容易做错的三处

1. 把待补签的交接清单当作已完成交接。上表样本中签字栏为空、备注写「待网点补签」，这是待办状态。拟稿句「已完成揽收交接」缺少签字或等效确认证据，属未获支持。
2. 把部分扫描当作全部揽收。样本扫描 96 件、24 件状态为空，差异登记处理结果为空。拟稿句「差异已闭环」与材料不符，属未获支持。
3. 把检索相似度当作权限或实体过滤。相似度只影响召回顺序，不能据 score 判定会话归属或授权范围。检索不是授权，表单收集值也不等于业务核验或数据库写入。

## 怎么确认配好了

1. 输入假设样本材料一至三与拟稿句。比较拟稿句「已完成揽收交接」与签字栏为空、备注「待网点补签」。观察结果：该句缺少完成交接的证据，应记为未获支持，保留证据缺口。
2. 输入假设样本扫描记录与异常件登记。比较「差异已闭环」与处理结果栏为空、原因栏「待承运商确认」。观察结果：该句属未获支持，不能判定闭环。
3. 输入假设 chatId「audit-A-0310」与业务批次 A-0310 的对应关系。比较会话标识与业务记录标识是否同主体、同期间、同字段。观察结果：标识一致才可继续核对；若不一致或缺失，记录为待核实，不执行跨模型检索比较漏召回。
