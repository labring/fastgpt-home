# 批发市场档口交易的运营权限与交接管理：引用来源与溯源

## 这个品类的数据长什么样

批发市场档口交易零散、依赖现场议价和托运，进货单、手写销售单、摊位租赁合同、货款收据往往分散在纸面与聊天记录中。这类材料常只记数量、金额和经手人，签署、合作达成与合同生效在纸面上未必同步，报价有效期也不等于供货期限。引用来源与溯源要处理的是：把某条回答或某次交接请求追回到具体材料原文，并说明该材料处于什么状态。数据按日、按单更新，这一频率影响的是核对时点，不改变本页功能。

## 这些特征在「引用来源与溯源」这一环带来什么约束

知识库搜索节点可关联一个或多个相同向量模型的知识库，输出为引用数组，长度可以为 0，空数组时该输出链路仍走通。引用数组是检索结果，不构成授权；相似度得分是排序依据，不承担权限或实体隔离。检索范围先核对已选知识库与资料版本。混合检索经 RRF 融合多路结果，重排须具备模型并按设置启用，图片检索须有相应图像输入及模型能力；这些可选路径不表示每次请求全部执行。思考预算是模型思考强度配置，与引用上限的 tokens 无关。以下用一份假设样本说明核对方式。

假设演练样本：某批发市场档口，材料一为手写销售单，载明“2024年3月12日，A档口向采购商甲售出土豆200斤，单价2元，经手人乙，货款未收”。材料二为摊位租赁合同，载明“A档口，租期2024年1月1日至2024年12月31日，承租人丙”。待判定拟稿句为“采购商甲已于2024年3月12日取得该批土豆所有权，货款已结清”。同日另有一条交接请求：“将A档口3月12日全部销售单的引用来源移交给下一班次。”材料中未载明所有权转移条款与货款结清记录。

## 配置怎么定

| 配置或核对项 | 本页取值或动作 | 依据与比较方式 |
| --- | --- | --- |
| 关联的知识库 | 仅选同一向量模型的知识库 | 官方说明相同向量模型才可共同关联；先核标识，排除不符者 |
| 引用上限 | 假设试验起点 2000 tokens，非官方默认 | 因样本材料短句为主，与 4000 tokens 结果比较引用条数差异 |
| 最低相关度 | 假设试验起点 0.3，非官方默认 | 与 0.5 比较，观察同一问题返回引用条数变化 |
| 搜索模式 | 语义检索或混合检索 | 编号、金额类精确字段可另用全文检索比较 |
| 引用内容输出 | 核对数组长度，允许为 0 | 空数组不等于工作流报错终止 |
| 引用输入承接 | 核对检索输出是否交给回答环节 | 逐条比对回答与引用原文 |

## 容易做错的三处

1. 把检索命中当作授权。输入是“将A档口3月12日全部销售单的引用来源移交下一班次”，比较对象是材料一原文，材料只记货款未收，检索返回引用数组不表示移交已获批准，观察结果是引用存在而授权状态仍为未获支持。
2. 把未载明字段判为矛盾。输入是拟稿句“货款已结清”，比较对象是材料一“货款未收”，同一字段出现互斥取值才构成矛盾；材料二未涉及货款，属未获支持，不叫否定或冲突。
3. 把思考预算移作引用上限。输入是模型思考强度设置，比较对象是引用上限的 tokens 字段，二者单位与作用不同，观察结果是调整思考强度不改变引用条数上限。

## 怎么确认配好了

1. 输入假设样本材料一与拟稿句，比较拟稿句“货款已结清”与原文“货款未收”，同一主体、同一日期、同一字段取值互斥，才满足矛盾判定；材料二未载货款，记录为证据缺口。
2. 输入明确的纸面空结果数组 []，比较下游回答环节是否仍继续执行，输出链路走通即满足承接设计核对；不声称某虚构规则检索一定返回空数组。
3. 输入材料一与交接请求，比较引用来源是否可追回原文，以及移交是否具备授权依据；引用可追溯且授权状态标为待核实，才满足本页核对条件，不声称移交已执行。
