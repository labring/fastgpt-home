# 渠道窜货稽查的运营权限与交接管理：对话日志与审计

## 这个品类的数据长什么样

渠道窜货稽查围绕区域和价格秩序展开，不涉及返利金额核算。日常材料包括窜货投诉单、防伪码记录、处罚通知与调查照片，主要来自防伪码系统、电商平台价格、经销商发货记录和市场巡检。数据按周或不定期更新，追踪货源码、比对低价店铺、执行处罚是耗时最多的环节。这些特征落到对话日志与审计上，意味着一次会话往往对应某个具体投诉或某批货的核查过程，日志需要能按 chatId 区分不同入口与不同案件，不能把来自在线使用、分享链接和 API 的会话混算。材料是否齐全、请求处于何种授权状态，直接影响后续能否据日志还原处理经过。

## 这些特征在「对话日志与审计」这一环带来什么约束

对话接口以 APIKey 鉴权，调用 chat/completions 时推荐在请求体传入 body.appId；appId 的优先级为 body.appId、`<apiKey>-<appId>`、apikey 关联的 appId。chatId 为空时不使用平台上下文，完全由传入的 messages 构建；chatId 为非空字符串时，自动从数据库取会话，并以 messages 数组最后一个内容作为用户问题，其余 message 被忽略，需自行保证 chatId 唯一且长度小于 250。传入的 model、temperature 等参数无效，由编排决定。需要中间值时设置 detail，非流式结果保存在 responseData，流式通过 event 区分。会话列表接口的 source=api 只获取通过 API 创建的会话，清空应用会话也仅清空 API Key 创建的会话。这些约束说明：日志能否按案件还原，取决于调用方是否规范传入并区分 chatId，以及是否保留 detail 返回的运行详情。

假设演练样本：某品牌渠道管控人员就一张窜货投诉单发起核查，材料原文为「投诉单编号 A-001，投诉对象为某区域经销商，涉及防伪码段 3001 至 3050，投诉日期 2025 年 3 月 3 日，状态为待核查」。拟交接句为「该投诉单已核查完毕，可执行处罚」。判定要点：材料仅载明状态为待核查，未载明核查结论、处罚依据或审批记录，拟交接句中的「已核查完毕」与「可执行处罚」均未获材料支持，属于待核实，不能当作已完成事实交接。

## 配置怎么定

| 配置或核对项 | 本次假设起点 | 说明与比较方法 |
| --- | --- | --- |
| chatId 唯一性与长度 | 假设起点为 32 字符 | 依据文档要求 chatId 唯一且小于 250，与目标会话标识逐条比对 |
| appId 传入位置 | 假设使用 body.appId | 与 `<apiKey>-<appId>`、apikey 关联值按文档优先级核对 |
| detail 取值 | 假设设为 true | 需运行详情时按文档设置，非流式查 responseData，流式看 event |
| source 过滤 | 假设取 api | 与在线使用、分享链接来源区分，核对是否只取 API 会话 |
| 运行详情字段 | 假设核对 nodeId、moduleType、runningTime | 按接口实际返回字段比对，未返回的业务数据不推定已留存 |

以上数值均为本次假设试验起点，用于说明选择理由与比较对象，并非官方默认值。

## 容易做错的三处

1. 把不同入口的会话混算。输入为在线使用、分享链接与 API 三类会话，比较对象是 chatId 与 source，若未按 source=api 过滤即汇总，会把非 API 会话计入交接范围。
2. 把检索或表单当作授权执行。输入为一次带交互节点的请求，比较对象是交互返回的展示配置与授权记录，若仅凭 userSelectOptions 或 inputForm 收集的值就认为处罚已获批准，属于越权推定。
3. 把日志存在等同于合规审计完成。输入为一份存在但字段不全的运行详情，比较对象是业务对账与留存要求，若未核对缺失字段即认定审计完整，会遗漏证据缺口。

## 怎么确认配好了

1. 输入样本原文「投诉单编号 A-001……状态为待核查」与拟交接句「该投诉单已核查完毕，可执行处罚」，比较材料状态字段与拟稿句结论，只有材料载明核查结论与处罚依据时，拟稿句才获支持，否则记为待核实。
2. 输入一次假设的 API 会话请求，比较 chatId 是否唯一且小于 250、appId 是否按优先级传入，观察会话列表 source=api 能否按该 chatId 取到对应记录。
3. 输入 detail=true 的请求，比较 responseData 中实际返回的 nodeId、moduleType、runningTime 与业务需要的字段清单，缺失字段记录为缺口，不推定已完整留存。

检索与相似度不承担权限或实体隔离，跨不同向量模型的库不可共同关联，只核标识并排除不符者。表单收集值不等于业务验证、审批或数据库写入，这些动作需另接系统实现。
