# 生产企业免抵退税的运营权限与交接管理：权限与数据隔离

## 这个品类的数据长什么样
生产企业免抵退把内销税额抵减与退税合并计算，与外贸企业出口退税的核算路径不同。这一差异使同一份免抵退税申报明细表同时承载内销抵减与出口退税两类信息，出口合同、销售明细账、出口报关单需要与之逐期对应。数据按月更新，交接时若只移交当期表格而不同时移交对应合同与报关单，接手方无法判断某笔出口是否已归集。权限与数据隔离要处理的是：谁可以读、写、管理这些材料，以及交接过程中哪些操作处于待授权状态。

## 这些特征在「权限与数据隔离」这一环带来什么约束
知识库权限是门槛，文件级权限无法绕过它。文件级权限关闭时，文件可读性与知识库一致；开启后每个文件生成权限快照，列表、详情与检索召回按快照逐条鉴权。检索召回按当前成员可读文件过滤，仅在按成员身份鉴权时生效；预选知识库且未按成员身份鉴权的场景不做文件级过滤。团队管理员不绕过文件级权限，团队所有者与系统 root 视为拥有全部文件权限。创建者不能通过协作者配置授予或修改，提交的协作者列表必须包含当前创建者。协作者配置为全量覆盖语义。删除文件仅限创建者。继承态下修改或删除来自父级的协作者会提示冲突，确认后节点转为独立态。关闭文件级权限会删除该知识库下全部文件与文件夹的协作者配置，不可回退。

## 配置怎么定
下表围绕本页样本，只列官方已说明的设置或实施核对项。

| 配置或核对项 | 取值或动作 | 依据与说明 |
| --- | --- | --- |
| 知识库文件级权限 | 开启 | 开启后才可配置单个文件协作者；关闭态下配置写操作被拒绝 |
| 样本文件协作者 | 提交列表须含当前创建者 | 全量覆盖语义，缺创建者会被拒绝 |
| 样本文件角色 | 读权限、写权限、管理员三选 | 创建者由创建或所有权转移产生，不通过协作者配置授予 |
| 交接请求的授权状态 | 记录为待授权 | 待审核不证明缺少操作权限，也不等于已执行 |
| 检索召回鉴权条件 | 按当前成员身份鉴权 | 预选知识库且未按成员身份鉴权时不按文件过滤 |
| 外部系统鉴权 | 与 FastGPT 资源权限分别验证 | 外部接口鉴权不替代资源权限 |

样本中若需一个数值，仅作本次假设试验起点：假设样本文件协作者列表拟提交 3 个主体，其中包含创建者。选 3 是因为样本只涉及一名创建者、一名接手会计、一名复核人；比较对象为提交后系统返回的协作者列表是否仍含创建者。

## 容易做错的三处
1. 把检索相关性当作权限隔离。相关性得分不构成类别、实体或权限过滤，相似度设置不排除无关业务或未授权记录。检索不是授权。
2. 把待审核的交接请求当作已获授权并执行。假设演练样本中，交接请求写“申请将样本文件管理员权限转予接手会计”，状态为待审核；此时不能据此认定权限已转移。
3. 在继承态下直接改写来自父级的协作者。系统提示冲突，确认后节点自动转为独立态，父级权限不被静默改写；若误认为父级已被修改，后续核对会错位。

## 怎么确认配好了
以下验证使用假设演练样本。样本材料原文：“样本文件为某生产企业免抵退税申报明细表，创建者为税务会计甲。样本文件当前协作者为甲（管理员）、乙（写权限）。”一条待判定拟稿句：“申请将样本文件管理员权限转予接手会计丙，交接请求状态为待审核。”

- 验证一：输入上述材料原文与拟稿句，比较拟稿句所称“管理员权限转予丙”与原文所载协作者列表及请求状态。原文未载明权限已转移，请求为待审核。可观察结果为：拟稿句所述转移未获支持，应记录为待核实。

- 验证二：输入样本文件协作者拟提交列表（含创建者甲、乙、丙），比较提交列表是否包含当前创建者。可观察结果为：列表含甲时提交不被拒绝；若提交列表遗漏甲，系统拒绝，此时记录拒绝现象。

- 验证三：输入一条按当前成员身份鉴权的检索请求，比较返回文件范围与当前成员可读文件范围。可观察结果为：不可读文件不被召回；若检索未按成员身份鉴权，则不按文件级权限过滤，此时记录该条件未满足。空结果可用明确的纸面输入 `[]` 核对下游设计，不声称某规则检索必然返回空。
