# 生鲜水果门店采购的运营权限与交接管理：表单与交互

## 这个品类的数据长什么样

在生鲜水果门店采购的运营权限与交接管理中，本页说明FastGPT的表单与交互如何衔接资料。水果采购交接表单收集档次、供货答复与授权，不从岗位交接推可采购或可验收。所用场景为自拟文字测试。

## 这些特征在「表单与交互」这一环带来什么约束

假设样品说明只展示外观等级，供应方尚未回复到货安排，接手人仅接了联系任务。表单收门店、品种与交接事项，人员选择补供货或核采购权限。缺品种和补齐均测试，后续输入逐项对原文；选择节点不充当供应商目录，表单提交不批准采购。

## 配置怎么定

| 水果采购交接 | 假设限定 | 检查依据 |
| --- | --- | --- |
| 外观样品 | 非整批质量 | 查本批检测 |
| 联系任务 | 仅工作分配 | 非采购权限 |
| 到货安排 | 供应尚未答 | 不写确定 |
| 品种必填 | 缺项与补齐 | 核后续原文 |
| 真实操作 | 下单验收另接 | 权限及回执 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入` | 收集输入并在提交后传值。 |
| `必填信息核对` | 业务必填与缺项处理需另设计。 |
| `用户选择` | 选择结果对应已连接的分支。 |
| `交互状态` | 分别核等待和完成交互状态。 |
| `后续处理分工` | 校验、审批及写入另核结果。 |

## 容易做错的三处

样品等级被答整批质量时，查批次检测；联系分派被答采购授权时，核真实权限；未答到货被写确定供应时，对供应回复。三处分别看样品与批次、工作与权限、承诺确定性，本例没有真实采购量或质量结论。

## 怎么确认配好了

验收把样品标记紧邻品种，将联系任务与授权证据分列，缺到货安排继续待核。新增批次材料只增加本批依据，不扩大到全部供应。下单、验收与库存写回需实际业务接口及权限回执，交接表单只传信息，不能替门店决定收货或让新人自动获账号。 外观样品的展示用途与本批货物资料分开列，采购联系人的任务只写联系；供货方到货安排未给时继续待补，不能从同一品种推相同批次质量。
