# 短视频挂车分销运营的运营权限与交接管理：表单与交互

## 这个品类的数据长什么样

在短视频挂车分销运营的运营权限与交接管理中，本页说明FastGPT的表单与交互如何衔接资料。短视频交接表单区分初审脚本、挂车链接待核和账号实际授权。所用场景为自拟文字测试。

## 这些特征在「表单与交互」这一环带来什么约束

自拟交接说本轮脚本只经初审，商品链接待核，品牌资料仍由原维护人管理。表单可收视频事项、当前版本和待办，接手者选择查链接或请求品牌资料。填写接手人不建立账号授权，初审也不证明视频已发布。应把版本及缺项传到后续环节，不能从选了查链接就写成链接已确认，更不能借另一视频的发布记录填本轮结果。

## 配置怎么定

| 短视频交接表单 | 纸面状态 | 具体检查 |
| --- | --- | --- |
| 脚本 | 仅初审 | 非已发布 |
| 商品链接 | 尚待核 | 核本轮对象 |
| 品牌资料 | 原人维护 | 请求不授权 |
| 接手人 | 填写身份 | 另验账号权限 |
| 正式操作 | 发布处理另接 | 真实回执 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入` | 收集输入并在提交后传值。 |
| `必填信息核对` | 业务必填与缺项处理需另设计。 |
| `用户选择` | 选择结果对应已连接的分支。 |
| `交互状态` | 分别核等待和完成交互状态。 |
| `后续处理分工` | 校验、审批及写入另核结果。 |

## 容易做错的三处

初审冒发布时，核当前公开记录；接手姓名冒账号授权时，核实际权限；他视频链接进入本轮时，对视频、商品和版本。三处分别核阶段、访问依据和对象。

## 怎么确认配好了

验收用同一事项比较提交与接收内容，补链接材料后仍核其归属。表单节点的交互完成不执行账号切换、内容发布或佣金处理。实际操作需独立授权与回执，资料缺项继续保留。 将脚本复核人与账号授权责任人分别登记，交接清单应能指出链接核查的对象，不能只写交接完成。
