# 达人专场带货合作的运营权限与交接管理：部署与升级

## 这个品类的数据长什么样
达人专场带货合作依赖外部达人履约与佣金结算，运营权限与交接管理需要围绕达人合作协议、佣金设置单、样品寄送单、直播战报四类材料展开。材料更新频率为每场与周，交接时须区分材料处于拟稿、待审核、已签署还是已执行状态。版本升级后，先核对当前版本与目标版本及对应升级说明，不能从旧配置名称推断现行行为。

## 这些特征在「部署与升级」这一环带来什么约束
假设演练样本：某品牌商务在升级后交接一场达人专场。材料原文为：“达人合作协议编号 HZ-2026-0417，签署状态：待审核，授权范围：单场直播，有效期 2026-05-01 至 2026-05-31。”佣金设置单载明“佣金比例 20%，状态：已提交，待财务确认”。拟交接句为：“该达人专场合作已生效，可执行佣金结算。”

判定要点：协议处于待审核，未签署，合作未达成，合同未生效；佣金设置单已提交但待确认，不能视为已批准；拟交接句将待审核写成已生效，属于状态误判。升级后需在同一字段、同一期间、同一主体下比较状态值，待审核与已生效互斥才构成矛盾。检索或表单收集值不构成授权，业务验证、审批、数据库写入及外部同步需另接系统实现。

## 配置怎么定
以下配置项围绕本页文档与主任务，数值为本次假设试验起点，非官方默认。

| 配置项 | 本次假设起点 | 选择理由与比较方法 |
| --- | --- | --- |
| AIPROXY_API_ENDPOINT | 假设设为 http://aiproxy:3000 | 升级后核对是否与 AI Proxy 根地址一致，不附加 /v1 |
| AIPROXY_API_TOKEN | 假设设为与 AI Proxy 服务端一致的非空值 | 比较 App 与 Admin 配置是否一致，缺少任一项会导致启动校验失败 |
| AGENT_SANDBOX_PROVIDER | 假设为空 | 核对是否启用沙箱；为空时不启用，配置后须同时配置对应必填变量 |
| DEFAULT_TEAM_BASIC_PERMISSIONS_ENABLED | 假设设为 false | 比较 FastGPT 与 Pro Admin 是否保持一致，不影响已有团队 |
| SYNC_INDEX | 假设设为 true | 核对是否在启动时创建缺失索引；关闭后需自行维护索引 |
| AGENT_SANDBOX_SUSPEND_MINUTES | 假设设为 60 | 比较沙箱持续未活跃分钟后自动暂停的设定值 |

## 容易做错的三处
1. 将待审核协议当作已生效。输入为协议状态“待审核”，比较字段为签署状态，观察结果为拟交接句声称“已生效”，两者在同一字段上互斥，构成矛盾。
2. 将佣金设置单“已提交，待财务确认”当作已批准。输入为佣金设置单状态，比较字段为审批状态，观察结果为拟执行结算，缺少财务确认证据，属于未获支持。
3. 将检索结果或表单填写值当作授权执行。输入为检索返回或表单提交，比较对象为授权边界，观察结果为直接执行结算，缺少审批与下游实现，属于越权判断。

## 怎么确认配好了
1. 输入假设样本中协议原文“签署状态：待审核”与拟交接句“已生效”，比较同一字段签署状态，观察结果为待审核与已生效互斥，判定拟交接句不成立。
2. 输入佣金设置单原文“状态：已提交，待财务确认”与拟执行结算请求，比较审批状态字段，观察结果为缺少财务确认，判定结算请求未获支持。
3. 输入纸面空结果 [] 核对下游设计，比较检索输出与授权判断，观察结果为检索不返回授权结论，判定不得以检索或表单值执行结算；缺失证据记录为待核实。
