# 达人佣金结算与扣佣的运营权限与交接管理：权限与数据隔离

## 这个品类的数据长什么样

在达人佣金结算与扣佣的运营权限与交接管理中，本页说明FastGPT的权限与数据隔离如何衔接资料。佣金交接分别限定达人账单与扣佣资料，编辑账单不等于扣款授权。所用场景为自拟文字测试。

## 这些特征在「权限与数据隔离」这一环带来什么约束

假设佣金设置只给规则，结算账单待双方确认，退款扣佣明细未核，发票属于另一结算期。交接应逐份核成员读改管权限，不从“达人”分类推定可以访问所有达人账单。规则可读不证明扣佣已认可；本题不含真实费率、金额或发票号，权限测试不执行结算。

## 配置怎么定

| 佣金交接资源 | 假设状态 | 授权核查 |
| --- | --- | --- |
| 规则 | 设置记录 | 不证扣佣认可 |
| 账单 | 双方待确认 | 限定达人身份 |
| 扣佣 | 明细待核 | 编辑不代执行 |
| 发票 | 另一账期 | 不替本期结清 |
| 成员 | 新旧角色 | 同资源正反测 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `团队角色` | 按实际成员身份核角色。 |
| `资源权限` | 读写与管理范围需按资源核对。 |
| `资料分类` | 分类和标签不能代替授权。 |
| `外部系统权限` | 外部接口鉴权单独验证。 |
| `逐账号验证` | 有权与无权账号访问同一资料。 |

## 容易做错的三处

- 接手人读到其他达人的账单时，对各资源及实际成员角色，用同一账单测获权和无权身份。

- 可编辑扣佣明细被答成有权执行扣款时，对业务审批、对方确认与实际财务动作，编辑权限不能替代。

- 另一期间发票支持本期结清时，对发票期间、账单主体与结算凭证，文件可读不合并账期。

## 怎么确认配好了

列明规则、账单、退款明细与发票各自用途及授权者，保留同资源正反测试和引用访问结果。旧成员退出后的访问也需验证，不能仅检查新成员登录。真实扣款、开票和对外发账单须另核公司流程；自拟练习仅整理证据与访问缺口。
