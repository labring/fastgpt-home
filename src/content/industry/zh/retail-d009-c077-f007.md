# 进出口许可证件办理的运营权限与交接管理：对话日志与审计

## 这个品类的数据长什么样

许可证办理发生在申报之前，决定货物能否合法进出口。与进口报关相比，这一环节的判断依据来自商务主管部门系统、海关商品编码、供应商资料和客户用途说明，涉及自动进口许可证、两用物项许可证、合同和产品说明等文档。资料更新频率为不定期、每票，日常处理中判断监管证件、准备用途说明、跟进审批状态最耗时。这些特征对对话日志与审计的影响在于：会话记录里出现的主体、对象和状态，需要与许可证材料逐项对应，日志存在本身不构成对业务记录的确认。

## 这些特征在「对话日志与审计」这一环带来什么约束

对话接口的 chatId 用于标识一个应用下的会话，dataId 标识会话下的某一条对话。获取会话列表时 source=api 只返回通过 API 创建的会话，清空应用会话同样只清空 API Key 创建的会话，在线使用与分享链接来源的会话不在该范围内。需要运行详情时按官方契约设置 detail=true，节点完整响应保存在 responseData 或通过 event=flowResponses 获取。日志字段与接口实际返回一致，接口未返回的业务数据不能推定已完整留存。

假设演练样本：某外贸企业合规岗人员甲，在 2025 年 3 月 10 日就一票货物询问自动进口许可证的办理状态。供核对的材料原文为：“本票货物对应的自动进口许可证申请已提交商务主管部门系统，当前状态为待审核；合同编号 HT-2025-0310 已由双方签署，生效日期为 2025 年 3 月 12 日。”待判定的交接请求为：“该票许可证已获批准，可安排申报。”核对时需比对材料原文中的状态词“待审核”与请求中的“已获批准”，两者在同一字段上取值不同。材料原文未载明审批通过的时间或文号，该部分证据缺失，请求中的批准结论未获支持。合同已签署与合同已生效属于两个事实，材料原文分别载明，不能合并推断。

## 配置怎么定

下表围绕上述样本，列出与本功能相关的官方已说明设置或实施核对项。

| 配置项 | 本页取值或核对方式 | 依据与说明 |
| --- | --- | --- |
| appId | 按应用详情路径取得，调用时传入 body.appId | 官方文档说明 appId 优先级为 body.appId、apiKey-appId、apikey 关联的 appId |
| chatId | 长度小于 250，同一应用下唯一 | 官方文档说明 chatId 非空时从数据库取会话，需自行确保唯一 |
| responseChatItemId | 在当前 chatId 下唯一 | 官方文档说明传入后作为响应消息 ID 存入数据库 |
| detail | 需要运行详情时设为 true | 官方文档说明非 stream 模式结果保存在 responseData |
| source | 获取 API 会话时传 api | 官方文档说明 source=api 不获取页面上的会话 |
| authProxy | 代理团队成员身份时由团队所有者开启 | 官方文档说明该能力仅适用于 FastGPT >= v4.15.0，代理身份仍需具备目标应用和会话权限 |

本页假设试验起点：将 pageSize 设为 20，原因是样本只有一条会话，20 足以覆盖；比较对象为返回的 total 字段与实际会话条数。该数值为本次假设试验起点，不是官方默认值。

## 容易做错的三处

1. 把待审核当作已批准。样本材料原文写明状态为“待审核”，拟稿句写成“已获批准”。输入为材料原文与拟稿句，比较同一状态字段的取值，观察结果为两者取值不同，拟稿句未获支持。
2. 把合同已签署当作合同已生效。材料原文分别载明签署与生效日期，若拟稿句只写“合同已生效”而省略生效日期，输入为材料原文与拟稿句，比较签署与生效两个字段，观察结果为生效事实缺少对应表述。
3. 把日志存在当作合规审计已完成。输入为会话记录与业务留存要求，比较日志字段与审计所需字段，观察结果为接口未返回的业务数据无法从日志中取得，需另行落实。

## 怎么确认配好了

1. 核对会话归属。输入为假设样本的 chatId 与 appId，比较获取会话列表返回的 chatId 是否与样本一致，观察结果为列表中存在该 chatId 且 source 为 api 时，归属核对通过。
2. 核对运行详情字段。输入为假设样本的 chatId 与 dataId，比较 getResData 返回的 moduleName、runningTime 等字段与接口实际返回是否一致，观察结果为返回字段与文档所列字段相符时，字段核对通过；未返回的业务数据记录为缺口。
3. 核对状态判定。输入为材料原文中的“待审核”与拟稿句中的“已获批准”，比较同一状态字段的取值，观察结果为两者取值不同，拟稿句判定为未获支持；材料原文未载明的审批文号与通过时间记录为缺失证据，保留待核实。
