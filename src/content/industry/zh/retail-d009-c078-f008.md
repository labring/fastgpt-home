# 连锁总部选址开店的运营权限与交接管理：工作流编排

## 这个品类的数据长什么样

在连锁总部选址开店的运营权限与交接管理中，本页说明FastGPT的工作流编排如何衔接资料。选址交接围绕平面图版本、测量许可与资料保管人传递，不把图纸交接当场地移交。所用场景为自拟文字测试。

## 这些特征在「工作流编排」这一环带来什么约束

本页自拟选址资料交接：候选地点有旧平面图，测量人员的便笺指出后场布置待重画，房东仅允许进场测量，资料管理员仍保管新版原图。交接表收地点、图纸版本和每份说明的作者，接手者选择索取新图或核测量许可范围。这里交的是待办与文件线索，不是租赁场地；允许测量不构成出租确认，新图可索取也不代表接手人已经能访问原件。无真实地址、面积或租金。

## 配置怎么定

| 选址资料交接 | 自拟状态 | 验收线索 |
| --- | --- | --- |
| 旧平面图 | 后场待重画 | 对版本与区域 |
| 房东许可 | 仅进场测量 | 不扩租赁装修 |
| 新版原图 | 管理员保管 | 索取接收访问分核 |
| 取图路径 | 传图纸身份 | 不只传地点名称 |
| 场地业务 | 未给租约批准 | 交接不代移交 |

### 固定版本条件

| 文档项或实施核对项 | 条件 |
| --- | --- |
| `表单输入节点` | 提交收集值后传给后续步骤。 |
| `用户选择节点` | 沿所选项连接的分支继续。 |
| `交互状态核对` | 检查等待与提交后的状态。 |
| `输出承接核对` | 逐项比较前后步骤传值。 |
| `外部操作分工` | 外部业务操作需另接实现。 |

## 容易做错的三处

- 便笺说后场需重画，下游却采用旧图说明可用空间时，对旧图版本、便笺覆盖区域和实际引用，找出未更新区域被误用的位置。

- 房东允许测量被答成同意租赁或装修时，核许可原句的动作与对象，不能从进入场地扩大后续使用授权。

- 交接表填了资料保管人便称新图已经交到接手人时，核索取记录、实际文件接收及原件访问；姓名只指联系线索。

## 怎么确认配好了

分别走取图与核许可路径，保存每个下游实际收到的图纸标识、区域限定和未决动作。新图到齐后只替换确有对应的图面，测量许可仍按原范围保留；缺访问可另列待办，不假装读取过图纸。实际租约、施工批准及资源授权由负责人员另核，此流程不发放系统权限或移交场地。验收可用自拟图面文字说明，不能因此声称已完成图像识别或现场测量。
