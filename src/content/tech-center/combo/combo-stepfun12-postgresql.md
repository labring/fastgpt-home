# StepFun 8K 上下文 这一档模型配 PostgreSQL（pgvector） 的配置口径

## 这一档模型的参数意味着什么
`step-1v-8k` 模型参数提供了清晰的工程边界。上下文长度 8000 token 决定了模型单次处理的最大输入量，包括系统指令、用户查询和检索到的内容。引用上限 8000 token 专门用于限制检索内容的 token 总量。这意味着，即使向量库返回了多条召回结果，其合计 token 量也不能超过此上限。图片输入能力允许模型处理图像数据。工具调用功能在此档位未启用，表示模型不具备自主调用外部工具集的能力。

## 配 PostgreSQL（pgvector） 要定哪些

| 配置项 | 建议取法 | 这样取的依据 |
| :---------------- | :---------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PG_URL` | `postgresql://user:password@host:port/database` | 数据库连接字符串，确保可读写权限，并指向已启用 `pgvector` 扩展的数据库。 |
| `ef_construction` | `64` | HNSW 索引构建参数，影响索引质量和构建时间。此值在 `16` 到 `512` 之间，增加可提高召回质量，但会延长索引构建时间。 |
| `ef_search` | `40` | HNSW 索引查询参数，影响查询召回质量和速度。此值应大于或等于 `k`（查询返回的邻居数量），增加可提高召回质量，但会增加查询延迟。 |
| `m` | `32` | HNSW 索引的图层最大连接数。此值在 `4` 到 `64` 之间，增加可提高召回质量，但会增加内存消耗和索引构建时间。 |
| `vector_ip_ops` | `true` | 设置为 `true` 以启用内积相似度计算，适用于文本嵌入场景。 |
| 检索返回条数 | `3` 到 `5` 条 | 结合模型引用上限和单段平均长度，控制召回内容的 token 总量，避免超出模型上下文。 |

## 这两者互相约束的地方
`step-1v-8k` 模型的 8000 token 上下文长度和 8000 token 引用上限，与 PostgreSQL（pgvector）的召回结果紧密关联。向量库返回的是固定数量的段落，而模型引用上限限制的是这些段落的合计 token 数量。当每段召回内容较短时，可以返回较多的段落条数，但如果每段内容较长，则需要减少召回条数以避免超出引用上限。HNSW 索引参数 `ef_construction` 和 `ef_search` 的调整，会影响召回的准确性，进而影响模型获取到有效信息的概率。提高这些参数可以增加召回的准确度，使得模型在有限的引用预算内获得更相关的上下文，从而提升生成回复的质量。

## 容易做错的三处
*   日志显示 `ERROR: vector dimension mismatch`：`pgvector` 存储的向量维度与模型生成的向量维度不一致。
*   界面返回 `Context window exceeded`：检索到的内容加上用户查询，总 token 量超出了模型的上下文长度限制。
*   检索结果为空，但数据库中存在相关数据：`ef_search` 值过低，导致 HNSW 索引在查询时未能找到足够邻居。

## 怎么确认配好了
*   执行一次包含复杂查询的对话，检查模型返回的引用内容是否准确且完整，评估召回内容的质量。
*   在 FastGPT 知识库页面，上传一份文档并等待索引完成，通过查看日志确认 `pgvector` 索引构建无异常。
*   通过 `pg_stat_activity` 视图监控 `pgvector` 查询的平均响应时间，确保查询延迟在可接受范围内。
*   在 FastGPT 后台查看模型输入输出的 token 统计，确认引用内容的 token 总量未超过 8000 token。
