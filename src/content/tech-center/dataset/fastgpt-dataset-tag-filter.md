# FastGPT知识库集合标签的管理与搜索过滤配置

知识库集合标签是FastGPT商业版特有的功能，可用于对知识库中的数据集合进行分类管理，同时支持在问答搜索知识库时通过标签实现精准过滤，帮助用户更高效地管理知识库数据，并提升搜索结果的精确性。

## 标签基础操作
在知识库详情页面可完成标签的全流程管理，支持的操作包括：创建新标签、修改已有标签的名称、删除不再使用的标签；可将单个标签关联多个数据集合，也可为单个数据集合添加多个不同的标签；同时支持通过选择指定标签，快速筛选出关联该标签的所有数据集合，简化知识库的分类管理流程。

## 搜索过滤配置与参数说明
在知识库搜索界面的「集合过滤」栏中，可配置过滤规则以实现精准检索，支持的参数格式示例如下：
```json
{
  "tags": {
    "$and": ["内部文档", "技术手册"],
    "$or": []
  },
  "createTime": {
    "$gte": "2024-05-01 00:00",
    "$lte": "2024-05-31 23:59"
  }
}
```
具体参数规则如下：
1.  标签字段支持传入字符串类型的标签名，也可传入`null`，用于筛选未设置任何标签的数据集合；
2.  当同时配置`$and`和`$or`两种过滤条件时，仅`$and`规则生效；
3.  `createTime`字段的`$gte`和`$lte`需使用`YYYY-MM-DD HH:mm`格式，分别用于筛选创建时间大于、小于指定时间的集合，二者可组合使用以限定时间范围。
