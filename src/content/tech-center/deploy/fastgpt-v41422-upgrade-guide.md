# FastGPT V4.14.22版本升级操作及更新内容说明

## 版本修复详情
本页面为FastGPT自部署场景下V4.14.22版本的升级相关文档，针对该版本的更新内容，主要修复了四类影响功能正常使用的问题：
1.  工作流默认选中模型未回传表单值的问题：该问题会导致前端界面展示的模型与后端实际运行时调用的模型不一致，用户在配置工作流时选择的模型无法正确生效，影响工作流的执行效果；
2.  工作流自动保存时存在边丢失风险：在编辑工作流并自动保存的过程中，可能出现工作流连线（边）丢失的情况，增加用户的重复编辑成本；
3.  管理员修改系统通知弹窗报错问题：管理员（admin）在修改系统通知弹窗的配置时会触发报错，无法正常完成系统通知的配置操作；
4.  工作流混用思考/非思考模型的调用报错问题：当工作流中同时使用思考模型与非思考模型时，可能出现独立reason字段上下文的异常情况，进而导致模型调用报错，影响工作流的正常运行。

## 升级操作步骤
本次V4.14.22版本的升级操作适用于Docker Compose部署的FastGPT实例，仅需更新对应服务的镜像tag即可完成升级，具体步骤如下：
1.  修改fastgpt-app服务（FastGPT主服务）的镜像tag为`v4.14.22`；
2.  修改fastgpt-pro服务（FastGPT商业版）的镜像tag为`v4.14.22`。
完成上述镜像tag的更新后，重启对应的Docker Compose服务即可完成本次版本升级，无需执行额外的数据迁移或环境变量配置操作。

## 版本升级说明
本版本属于FastGPT 4.14.x系列的正式更新版本，用户可根据自身当前使用的版本，按照上述步骤完成升级。
