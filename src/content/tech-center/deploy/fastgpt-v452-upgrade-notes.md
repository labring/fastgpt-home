# FastGPT V4.5.2版本升级说明与更新内容

## V4.5.2 版本更新详情
FastGPT V4.5.2 本次更新包含两项核心改动：一是新增模块插件功能，支持用户自行组装插件以实现模块复用，无需重复配置相同功能模块；二是优化知识库引用提示，调整了知识库内容被调用时的提示逻辑，提升了提示的清晰度与可读性，帮助用户更快速地识别引用来源。本次更新未单独标注环境变量变更，但仍需留意版本迭代过程中的配置差异。

## 升级前置准备
升级至 V4.5.2 前，需先确认当前运行的 FastGPT 版本：若当前版本低于 V4.5，需参照对应版本的升级说明逐步完成升级，例如从 V4.4.x 系列升级需先执行对应升级脚本，再逐步过渡；若当前版本属于 V4.5.x 系列，则可直接执行对应版本的升级脚本完成更新。无论当前版本为何，升级前均需完成系统数据备份，避免升级过程中出现数据丢失或异常。

## 标准升级操作步骤
1.  停止当前运行的 FastGPT 部署服务；
2.  执行对应版本的升级脚本（若当前版本为 V4.5.1 及以下的 V4.5.x 系列，使用 V4.5.1 升级脚本）；
3.  拉取 V4.5.2 版本的部署镜像，若使用 Docker Compose 部署，需同步更新配置文件中的镜像标签；
4.  启动更新后的部署服务；
5.  访问系统后台，验证模块插件功能与知识库引用提示功能是否正常生效。
