# FastGPT V4.6.1版本升级说明与功能详情

# V4.6.1版本功能更新
FastGPT V4.6.1版本作为历史迭代版本，包含多项面向交互与模型支持的优化与新增能力，具体包括：新增GPT4-v模型支持，可实现基于视觉输入的对话交互；新增whisper语音输入功能，支持用户通过语音完成提问与指令输入；优化了TTS流传输逻辑，降低语音合成过程中的延迟，提升实时交互体验；优化TTS缓存机制，对重复使用的语音合成结果进行缓存，减少重复计算的资源开销。

# 版本升级前置要求
升级至V4.6.1版本前，需根据当前运行的FastGPT版本选择对应的升级路径。官方文档中针对每个版本的升级均有明确标注，例如部分版本标注有「升级脚本」「环境变量变更」等提示：标注「升级脚本」的版本可直接通过官方提供的升级脚本完成一键升级；标注「环境变量变更」的版本，需在升级前核对并更新系统的环境变量配置，避免因配置不兼容导致服务启动失败。若当前版本为V4.6及更早的部分版本，需先完成系统数据备份，再执行升级操作，防止升级过程中出现数据丢失。

# 最小升级操作步骤
针对已完成备份且符合升级前置要求的场景，可按照以下步骤完成升级：1. 进入FastGPT部署目录，停止当前运行的FastGPT服务；2. 根据当前版本获取对应版本的官方升级脚本，例如当前版本为V4.6时，使用V4.6对应的升级脚本；3. 执行获取到的升级脚本，等待服务更新与重启完成；4. 检查服务运行状态，确认服务正常启动，验证核心功能是否可用。若升级过程中出现配置相关异常，需核对官方文档中的环境变量说明，调整对应配置项后再次尝试。
