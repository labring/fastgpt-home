# FastGPT V4.8.9版本升级操作及更新内容说明

## 这个版本改了什么
新增功能包括：文件上传配置由系统配置决定是否可上传图片；AI对话节点和工具调用支持选择是否开启图片识别，开启后自动获取对话框上传图片和用户问题中的图片链接；新增文档解析节点；删除所有对话引导内容；QA拆分支持自定义chunk大小，优化gpt4o-mini拆分时chunk太大导致生成内容少的问题。商业版新增功能包括：团队通知账号绑定，用于接收重要信息；知识库集合标签功能，可对知识库进行标签管理；知识库搜索节点支持标签过滤和创建时间过滤；转移App owner权限。优化内容包括：对话框信息懒加载，减少网络传输；清除选文件缓存，支持重复选择同一个文件。修复问题包括：知识库上传文件在网络不稳定或文件较多情况下进度无法到100%；删除应用后回到聊天选择最后一次对话的应用为删除的应用时提示无该应用问题；插件动态变量配置默认值时无法正常显示默认值；工具调用温度和最大回复值未生效；函数调用模式中assistant role的GPT模型必须传入content参数（不影响大部分模型，目前基本都改用ToolChoice模式，FC模式已弃用）；知识库文件上传进度更新可能异常；知识库rebuilding时页面总是刷新到第一页；知识库list openapi鉴权问题；分享链接新对话无法反馈。

## 升级前要确认的事
升级前需完成数据库备份。若部署为商业版且非仅内部使用，需提前准备环境变量中的rootkey以及FastGPT域名。仅内部使用的部署，无需执行商业版初始化操作。

## 升级步骤（照做）
1. 修改镜像：更新FastGPT镜像tag为v4.8.9，更新FastGPT商业版镜像tag为v4.8.9，Sandbox镜像可以不更新。
2. 商业版执行初始化：从任意终端发起以下HTTP请求，将{{rootkey}}替换为环境变量里的rootkey，将{{host}}替换为FastGPT域名：
```bash
curl --location --request POST 'https://{{host}}/api/admin/init/489' \
--header 'rootkey: {{rootkey}}' \
--header 'Content-Type: application/json'
```

## 升级后怎么验证
可通过以下方式验证升级效果：进入系统配置页面确认文件上传配置项生效；在AI对话节点或工具调用中开启图片识别，上传图片并发起对话确认图片可被识别；上传知识库文件确认上传进度可正常显示至100%；测试删除应用后聊天选择页面不会跳转至已删除的应用；检查插件动态变量的默认值可正常显示；测试知识库搜索节点的标签过滤和创建时间过滤功能；访问分享链接发起新对话确认反馈功能正常。
