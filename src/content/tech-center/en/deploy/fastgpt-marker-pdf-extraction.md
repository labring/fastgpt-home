# Marker-Powered PDF Parsing for FastGPT
FastGPT’s self-hosted custom model integration includes the Marker tool for end-to-end PDF content extraction, a critical component for processing academic, technical, and business documents within AI workflows. This parsing solution is designed to capture more than just plain text, preserving visual and structured elements that are essential for accurate context retention in downstream model interactions. The following demonstration uses Tsinghua University’s *ChatDev Communicative Agents for Software Develop.pdf* as a reference sample to showcase Marker’s extraction capabilities.
