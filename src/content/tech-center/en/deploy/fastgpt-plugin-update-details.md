# FastGPT Plugin Update Fixes and Additions

## Plugin Update Overview
This document outlines all plugin-specific modifications released in FastGPT 4.14.4, including new model support, bug fixes, feature enhancements, and utility tool additions. These changes target improved plugin reliability, expanded model compatibility, and enhanced integration functionality for enterprise and developer workflows.

## New Plugin Features
Two distinct new features are included in this update:
1.  Official presets for GLM 4.6 and DeepSeek 3.2 series large language models, enabling direct integration of these models into supported plugin workflows without manual configuration.
2.  A new utility tool that retrieves draft box lists from WeChat Official Accounts, adding content management capabilities for WeChat platform integrations.

## Bug Fixes and Enhanced Configurations
This update resolves three critical plugin issues and adds one configurable parameter for existing functionality:
### Markdown-to-File Custom Filename Support
The Markdown-to-file plugin now supports a user-defined custom filename parameter, replacing the previous auto-generated default file names. The following configuration parameter is available for this plugin:
| Plugin Component | Parameter Name | Function |
|------------------|----------------|----------|
| Markdown-to-File | `custom_filename` | Specifies an exact user-defined name for the output file generated by the plugin |

Additional resolved bugs include:
- Fixed an issue where the MinerU SaaS plugin could not display or select available VLM model versions during setup
- Fixed a parameter passing error in the WeChat Official Account plugin’s batch Markdown upload feature, which disrupted successful batch imports of Markdown content
- Fixed an import cache-related bug that prevented successful plugin updates after initial deployment
