# Check FastGPT Version and Upgrade to Resolve Issues

Many known issues with self-hosted FastGPT are resolved in newer software releases. Before submitting a problem report, validating your current FastGPT version is a critical preliminary step to avoid redundant troubleshooting work.

### Validate Current FastGPT Version
Follow this step-by-step process to confirm your installed version:
1.  Access your deployed FastGPT instance via a supported web browser.
2.  Locate the version information either on the public FastGPT homepage, or within the administrative panel of your instance.
No additional authentication or configuration is required to view this standard version data via these two confirmed access points.

### Upgrade to Latest Stable Release
If your installed FastGPT version is not the latest stable release, you must complete an official upgrade to resolve known issues present in your current build. The official FastGPT upgrade guide is available at the relative path ../upgrading/upgrade-instruction. This resource provides all required steps to safely update your instance to the latest stable version, ensuring you benefit from all resolved bugs and performance improvements included in newer releases.

### Best Practices for Version Maintenance
Regularly checking your FastGPT version and upgrading to the latest stable release minimizes the risk of encountering common, already-fixed problems. Only use the official upgrade guide linked above to perform updates; unauthorized modifications to core instance files may introduce unexpected issues or break existing functionality.
