# Retrieve and set Feishu app credentials for FastGPT

## Locate Core Feishu App Credentials
Access the Lark Open Platform developer console, and navigate to your previously created custom enterprise application. Retrieve the App ID and App Secret values from the application’s overview page. These two critical parameters must be entered into the FastGPT publishing channel configuration dialog. Two reference images support this workflow: feishu-bot-3.png highlights the location of the credentials within the Lark Open Platform console, while feishu-bot-4.png shows the corresponding input fields in the FastGPT configuration interface.

## Optional Encryption Key Configuration
For secure server-to-server communication between Lark and FastGPT, you may configure an optional Encrypt Key. First, navigate to the Events & Callbacks section of your Lark application, then select Encryption Strategy to retrieve the Encrypt Key value. Enter this value into the Lark bot integration dialog within FastGPT. The Encrypt Key encrypts all traffic exchanged between Lark’s servers and your FastGPT deployment. This parameter is not required if you are using HTTPS for your FastGPT instance, but is recommended for HTTP deployments. The Verification Token is auto-generated by default for source verification, but per Lark’s official recommended secure verification method, this configuration field can be safely ignored and does not need to be populated. The reference image for this optional step is feishu-bot-5.png.

## Credential Parameter Reference
The following table outlines all relevant credentials for Feishu integration with FastGPT, including their requirement status and source locations:
| Parameter Name       | Required | Source Location                                  | FastGPT Configuration Target       |
|----------------------|----------|--------------------------------------------------|------------------------------------|
| App ID               | Yes      | Lark Open Platform custom enterprise app console | FastGPT publishing channel dialog  |
| App Secret           | Yes      | Lark Open Platform custom enterprise app console | FastGPT publishing channel dialog  |
| Encrypt Key          | Optional | Lark Open Platform > Events & Callbacks > Encryption Strategy | Lark bot integration dialog |
| Verification Token   | No       | Auto-generated by Lark Open Platform             | Ignored per official setup guidelines |
