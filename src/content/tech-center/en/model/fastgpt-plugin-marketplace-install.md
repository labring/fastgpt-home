# Install FastGPT Plugins via the Marketplace

## Marketplace Plugin Installation Overview
This process allows you to add pre-built plugins to your FastGPT workspace’s team tool library, for integration into AI workflows and Agents. All available plugins are hosted in the official FastGPT Marketplace, with full visibility into their capabilities and access requirements before installation begins.

## Step-by-Step Installation Workflow
Follow these ordered steps to install a plugin from the Marketplace:
1. Open the **Tools** menu within your FastGPT workspace.
2. Select **Add Plugin** in the upper-right corner of the Tools page, then choose the Marketplace installation option.
3. Search for target plugins using keywords for name, source, or category. You may enable the uninstalled-only filter to display only plugins not already installed in your workspace.
4. Open the plugin’s detail page to review its official description, available version options, and requested permissions.
5. Select your preferred plugin version, then click the **Install** button to complete the installation process.

## Post-Installation Configuration and Usage
Once installation is complete, the plugin will appear in your team’s tool list. You can select the plugin when building workflows or configuring AI Agents. Before using the plugin, you must configure any required secrets or runtime parameters as specified by the plugin’s requirements.
