# Build Complex AI Apps With FastGPT Workflows

## FastGPT Workflow Fundamentals
Starting from version 4.0, FastGPT adopted a node-based workflow orchestration system for building AI applications. This system replaces earlier simplified app building approaches with modular, configurable processing steps to implement complex AI workflows. The core benefits of this system include improved flexibility and extensibility, allowing developers to adjust or extend their AI applications without rebuilding core functionality from scratch, tailoring every step of an application’s logic to specific use cases. However, this modular approach introduces a steeper learning curve for new users; individuals with software development experience will find the system more intuitive to adopt.

## Basic Workflow Creation Steps
The following steps outline the core process to build and deploy a workflow using FastGPT’s system, as covered in the official tutorial:
1. Navigate to the workflow editor page within your FastGPT 4.0+ deployment.
2. Drag and drop pre-built workflow nodes onto the editor canvas to represent individual processing steps.
3. Connect nodes in a logical sequence to define the order of execution and flow of data between each step.
4. Review and adjust node configurations to match your application’s requirements.
5. Save the configured workflow and deploy it to launch your custom AI application.
