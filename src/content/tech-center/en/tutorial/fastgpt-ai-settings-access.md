# Access and Configure FastGPT AI Settings

## Core Access Points for FastGPT AI Settings
AI configuration settings are accessible across two primary FastGPT development environments, with both paths launching a shared centralized settings modal for consistent setup.

## Step-by-Step Access Procedures
### App Editor Workflow
1.  Open the target FastGPT app editor project.
2.  Locate the clearly labeled **AI Settings** section within the interface.
3.  Select a preferred AI model from the built-in model selector dropdown.
4.  Click the settings button positioned on the right side of the model selector to open the full AI settings modal.

### Workflow AI Chat Node Workflow
1.  Launch your existing FastGPT workflow project in the workflow editor.
2.  Select the **AI Chat** node from the workflow canvas element library.
3.  Access the model configuration panel linked to the selected AI Chat node.
4.  Click the right-side settings button on the model selector to open the identical shared AI settings modal.

## Default Configuration Recommendation
A success-focused alert with a 🤖 robot icon provides clear guidance for standard use cases: *If you do not have specific requirements, selecting a suitable AI model and keeping the other settings at their defaults is usually enough.* This recommendation applies to both app editor and workflow node configurations.
