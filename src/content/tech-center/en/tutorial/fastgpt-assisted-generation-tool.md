# Generate and Optimize FastGPT Agent Configurations

## Assisted Generation Helper Overview
The FastGPT Assisted Generation Helper Bot automates repetitive agent configuration tasks by leveraging pre-configured workspace settings. The bot automatically retrieves the currently active model, uploaded datasets, and configured candidate tools from the left panel of the agent build interface. Users do not need to manually draft formal system prompts, select compatible tools, or curate background knowledge datasets; instead, they only need to provide a clear natural language description of their intended assistant’s core function.

## Core Automated Capabilities
The helper bot delivers three targeted configuration automation features:
- **Generate and Refine Structured System Prompts**: Creates and iteratively adjusts formal system prompts that define clear operational boundaries and standardized execution rules for the agent, ensuring consistent, predictable behavior during runtime.
- **Recommend Suitable Tools or Virtual Machine Commands**: Identifies the most appropriate pre-configured tools and corresponding command-line instructions aligned with the user’s described task requirements.
- **Suggest Relevant Datasets**: Proposes domain-specific datasets from the active workspace configuration to supplement the agent with necessary background knowledge, improving task accuracy and contextual relevance.

## Step-by-Step Usage Workflow
For technical users, follow this structured workflow to deploy the helper bot:
1. Navigate to the FastGPT agent build interface and confirm the left panel displays your active model, uploaded datasets, and candidate tooling.
2. Launch the Assisted Generation Helper Bot within the build workspace.
3. Input a natural language task description that clearly defines the assistant’s purpose, such as: "I want an assistant that analyzes sales data uploaded in Excel and generates visual charts".
4. Review the automated outputs generated by the helper bot, including refined system prompts, tool recommendations, and dataset suggestions.
5. Validate and adjust the generated configurations as needed before integrating them into your final agent setup.
