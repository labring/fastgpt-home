# Reduce Barriers to Business Data Analysis Workflows

## Core Capabilities of FastGPT Intelligent Data Analysis Agent
FastGPT Agent V2 — Intelligent Data Analysis Agent is engineered to streamline enterprise data analysis workflows. Its core functional attributes include:
- Reduced technical barrier: Authorized users can directly upload Excel or CSV formatted data files and submit analysis requests via natural language, with no requirement to write SQL, Python, or complex spreadsheet formulas.
- Flexible exploratory analysis: The same uploaded dataset supports repeated querying across multiple dimensions including sales performance, sales channels, geographic regions, customer segments, trend analysis, and outlier detection, making it suitable for use cases without a pre-defined analysis path.
- Transparent analysis process: The Agent displays full analysis plans and key execution steps, allowing users to verify how the system interprets input data, calculates required metrics, and draws final conclusions.
- Isolated code execution security: All analysis-related scripts execute within a dedicated virtual machine, mitigating risks of local environment contamination, dependency version conflicts, and unauthorized permission misuse.
- Reusable business analysis framework: Common enterprise analysis scenarios such as monthly sales reviews, weekly operational reports, marketing campaign attribution, and product performance metric diagnostics can all utilize this Agent, converting data analysis from an expert-only task into a repeatable daily workflow.

## Standard Usage Workflow
1. Upload a supported Excel or CSV data file to the FastGPT Intelligent Data Analysis Agent instance
2. Formulate a clear analysis request using natural language, without needing to prepare specialized code or formulas
3. Review the displayed analysis plan and execution steps to confirm alignment with intended analysis goals
4. Submit follow-up natural language queries to explore additional analysis dimensions or refine existing results
5. Retrieve finalized analysis outputs generated by the Agent

## Operational Risk Controls
This Agent mitigates common data analysis risks by executing all analysis scripts in an isolated virtual machine environment. This eliminates exposure to local system contamination, conflicting software dependencies, and improper permission usage that can occur with traditional local script execution.
