# View and Analyze FastGPT Evaluation List Results

## Access the FastGPT Evaluation List
The FastGPT evaluation list centralizes all submitted application evaluation tasks, viewable through the official viewing interface paired with the provided `View app evaluation` screenshot. This list organizes every completed or in-progress evaluation task using consistent, standardized metadata to simplify tracking and analysis. Each row in the list corresponds to a single evaluation task, with core details presented at a glance to reduce manual data gathering.

## Core Evaluation List Fields
Every evaluation task entry includes the following standardized fields, displayed as core list columns:
| Field Name         | Detailed Description                                                                 |
|---------------------|--------------------------------------------------------------------------------------|
| Progress            | Displays the current execution status of the evaluation task, such as pending, running, or completed |
| Created By          | Identifies the user account that created and launched the evaluation task             |
| Target App          | Specifies the FastGPT application that was the subject of the evaluation task        |
| Start/End Time      | Shows the full start and end timestamp range covering the task’s execution period     |
| Overall Score       | Presents the aggregated composite score calculated for the completed evaluation task  |

## Leverage Evaluation Lists for App Refinement
A primary use case for the evaluation list is comparing task results across multiple iterations of your FastGPT application. As you make adjustments to improve app performance, you can use the list to track how each change impacts overall scores and other key metrics over time. This structured comparison eliminates guesswork from the app improvement process, allowing you to validate that modifications deliver intended positive outcomes. Each entry’s complete metadata set also supports targeted deep dives into individual task runs, helping identify consistent trends or unexpected variations in evaluation performance.
