# Enable Real-Time Citation Annotation For FastGPT

## Core Feature Functionality
Authorized users can perform real-time annotation and correction of citation content while browsing active FastGPT chat sessions. The system processes all submitted updates without interrupting the ongoing conversation. All modified citation content is clearly marked with an explicit "Updated" label, ensuring that citation accuracy is maintained while preserving the full integrity of the conversation history. No existing conversation context is altered or lost during the refinement process.

## Collaborative Knowledge Refinement Workflow
This feature enables a seamless knowledge refinement cycle ideal for team collaboration. During active chat usage, the connected Dataset can evolve in real time as authorized users correct and annotate citation content. Each update ensures that subsequent AI-generated responses draw exclusively from the latest, most accurate available source material, aligning outputs with verified, up-to-date information. Teams can collaborate on refining citation data without disrupting ongoing conversations, supporting iterative improvement of the underlying knowledge base.

## Step-by-Step Usage Instructions
1. Gain access to an active chat session with valid authorized user permissions.
2. Locate the citation blocks displayed alongside AI responses within the chat interface.
3. Edit the target citation content to correct errors or add required annotations.
4. Submit the modified citation content; the system will process the update without interrupting the current conversation.
5. Confirm the successful application of the change by verifying the modified content displays the "Updated" label.
