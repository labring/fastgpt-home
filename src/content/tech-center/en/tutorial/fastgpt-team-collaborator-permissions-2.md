# Set Up and Manage FastGPT Team Collaborator Permissions

## Prerequisite for Team Collaborator Permission Management
Before you can manage permissions for any FastGPT team collaborators, you must first add the target collaborators to the team. This mandatory first step ensures that all permission configurations are tied to valid team entities. The following visual demonstrates the initial collaborator addition workflow:
![](/imgs/guide/team_permissions/team_roles_permissions/image2.png)

## Standard Team Permission Configuration Workflow
FastGPT includes a dedicated centralized permissions page for team-wide permission management. To use this workflow:
1.  Navigate to the team’s dedicated permissions management page.
2.  Select the target entity to configure: individual team members, external organizations, or pre-defined groups within the team.
3.  Apply the desired permission settings for the selected entity.
The accompanying image shows the entity selection and permission configuration interface:
![](/imgs/guide/team_permissions/team_roles_permissions/image3.png)

## Direct Resource-Level Permission Modification
For specific FastGPT resources such as apps and datasets, you can skip the centralized permissions page and directly adjust member permissions for the individual resource. This streamlined approach allows for targeted permission changes tied directly to the resource you are working on. The following image illustrates this direct resource permission workflow:
![](/imgs/guide/team_permissions/team_roles_permissions/image4.png)

## Centralized Permissions Page Details
The dedicated team permissions page is the primary hub for all cross-resource team permission administration. This page consolidates all configured access settings, enabling you to review, edit, or revoke permissions across all team resources in a single interface. The visual reference for this centralized page is shown below:
![](/imgs/guide/team_permissions/team_roles_permissions/image5.png)
