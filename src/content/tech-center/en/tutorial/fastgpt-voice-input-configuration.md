# Configure FastGPT Application Voice Input Settings

## Accessing the Voice Input Configuration Dialog
To set up voice input functionality for a FastGPT application, first open the application editor interface. Within the editor’s canvas or component library, locate the labeled Voice Input component. A dedicated settings button is positioned on the right side of this component. Selecting this button will launch the official voice input configuration dialog, which provides access to all available settings for the voice input feature.

## Step-by-Step Access Procedure
Follow these concrete steps to access the voice input configuration dialog using in-editor controls:
1. Open the FastGPT application editor for your target application.
2. Locate the Voice Input component within the editor’s layout.
3. Click the settings button located on the right side of the Voice Input component.
4. Verify that the voice input configuration dialog has loaded successfully.
