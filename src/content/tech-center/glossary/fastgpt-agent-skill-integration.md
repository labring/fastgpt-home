# 说明FastGPT智能体技能集成功能的使用方法

## 一句话定义
FastGPT智能体技能集成功能，用于为智能体绑定技能并提供多技能管理、自动调用与文件查看能力。

## 在 FastGPT 里怎么用
首先为智能体绑定技能，一个智能体支持同时绑定多个不同的技能。沙盒启动时，所有已绑定技能的代码和配置会自动注入并部署到沙盒工作区，各技能间彼此独立、互不冲突。在模型足够智能的前提下，AI会根据输入自动判断是否需要调用技能并在后台虚拟机中安全执行代码。在智能体聊天界面，点击聊天气泡底部的“虚拟机”按钮或右上角的电脑图标，弹出侧边栏即可查看沙盒内的最新文件与代码状态。

## 容易搞错的地方
需确保使用的模型足够智能，才可触发智能自动调用功能；未绑定技能或沙盒未启动时，无法使用虚拟机文件查看功能；绑定多个技能时，各技能的代码与配置彼此独立，不会互相干扰。
