# 说明FastGPT中ASR功能的申请规则与相关要求

## 一句话定义
ASR功能是FastGPT暂未支持的语音转文字功能，用户可提交申请请求新增该功能。

## 在 FastGPT 里怎么用（参数 / 位置 / 步骤）
提交ASR功能申请时，需依次完成五项例行检查的勾选确认：确认当前无类似功能、确认已升级到最新版本、确认已完整查看项目README且现有版本无法满足需求、确认理解并愿意协助跟进测试与反馈、确认理解并认可维护者精力有限且不遵循规则的请求可能被无视或关闭。完成检查后，在功能描述部分清晰说明希望添加ASR能力。

## 容易搞错的地方
未完成全部例行检查项就提交请求，可能导致请求被无视或关闭。未清晰说明具体功能内容，或提交已有类似功能的请求，也不符合提交规范。
