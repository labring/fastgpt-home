# FastGPT中功能请求（Feature）的提交与标记说明

## 一句话定义
FastGPT中的Feature指用于提交新功能需求的GitHub Issue类型，用于向项目团队提出功能新增或改进请求，并通过特定评论标记区分需求状态。
## 在 FastGPT 里怎么用（参数 / 位置 / 步骤）
提交Feature请求需遵循指定规则。新需求问题可直接提交Feature Issue，无需在非对应讨论Issue中留言。提交前需搜索现有Issue（包括已关闭的）确认无类似功能，确认使用项目的最新版本，完整阅读项目README确认现有版本无法满足需求，理解并承诺跟进功能、协助测试并提供反馈。提交时需在评论区附上完整详细的说明和原因，避免仅用简短语句描述。已提交的Feature可通过评论标记判断状态：带有👀评论的Feature已记录到未来规划，带有🎉的Feature已完成或解决。4.7版本正式版后，项目计划进行1个月的细节优化，包括使用体验、代码结构和部署优化。
## 容易搞错的地方
提交Feature请求时，需避免在非对应讨论Issue中留言讨论新需求。不遵循规则的Feature请求可能被忽略或直接关闭。需准确理解标记含义，避免混淆规划中与已完成的需求状态。
