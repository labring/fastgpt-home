# FastGPT 4.6.3版本知识库简介保存后不显示问题说明

## 一句话定义
该异常场景指在使用docker-compose部署的FastGPT 4.6.3版本中，知识库简介字段（intro字段）在配置页面点击保存并提示更新成功后，返回知识库列表页时，简介仍显示为空的问题。

## 在FastGPT里怎么用（参数 / 位置 / 步骤）
该问题涉及的配置参数为intro字段，即知识库简介字段，其编辑位置位于目标知识库的配置页面。具体操作流程为：首先进入需要配置简介的知识库的配置页面，找到intro字段对应的简介编辑区域，填写需要展示的简介内容，随后点击页面的保存按钮，等待系统弹出保存成功的提示信息。完成保存操作后，返回知识库列表页面，查看对应知识库的简介展示状态。当前该异常仅在使用docker-compose部署的4.6.3版本中被记录。

## 容易搞错的地方
容易出现的认知偏差包括：一是认为系统提示保存成功后，知识库列表页的简介会立即同步更新并正确展示；二是误以为该问题与部署方式或版本无关，但根据记录，该异常仅出现在docker-compose部署的4.6.3版本中。此外，部分用户可能忽略部署版本与部署方式的组合条件，导致后续排查方向出现偏差。
