# FastGPT开源版知识库网页同步自定义爬虫配置说明

## 一句话定义
FastGPT开源版中支持将网页内容同步至知识库的自定义爬虫接入功能，可实现自定义网页源的知识库内容同步。

## 在 FastGPT 里怎么用（参数 / 位置 / 步骤）
在FastGPT开源版的知识库网页同步场景中，可自行开发爬虫接口并接入，以完成网页内容向知识库的同步操作。原文明确该功能支持通过自定义爬虫实现网页到知识库的同步，未提及具体的参数名称与配置页面位置，仅说明可通过开发接入的方式完成需求。

## 容易搞错的地方
部分使用者易忽略该功能仅在FastGPT开源版中可用，非开源版本无法通过自行开发爬虫的方式实现网页同步。此外，原文中出现的“爬虫pai”为表述笔误，实际指向自定义爬虫接口，易被误解为非标准技术术语。还有部分使用者可能扩大该功能的应用范围，误以为可用于所有类型的数据源同步，实际仅适用于网页内容同步至知识库的场景。
