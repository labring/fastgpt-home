# FastGPT中变量引用的使用方法与常见问题

## 一句话定义
FastGPT中的变量引用是指在平台各配置模块中调用预定义变量，实现参数动态替换的功能，可覆盖工作流节点配置、数据集管理、聊天渲染等多个功能场景，帮助用户完成参数的动态调整与复用。

## 在 FastGPT 里怎么用（参数 / 位置 / 步骤）
FastGPT的变量引用相关配置文档分布在多个功能模块，官方文档目录中包含工作流节点、数据集管理、聊天功能等多个子页面。其中工作流节点中的`variable_update`节点是专门用于更新变量的配置节点，用户可通过该节点完成变量的创建、更新与调用。官方issue中曾有用户提出，尝试通过变量引用调整温度参数与模型选择参数，相关issue的报错文本为"cant adjust the temperature using variable reference"，该问题为用户在实际配置中遇到的典型异常场景。

## 容易搞错的地方
部分用户在配置过程中，误以为变量引用可直接用于调整温度参数与模型选择参数，但实际使用中该场景下变量引用无法生效。此外，不同功能模块的变量使用规则存在差异，需严格参考对应节点的官方文档完成配置，避免因未遵循模块规则导致配置失效。同时，需注意变量引用的调用需依托已预定义的变量，未定义的变量无法被正常调用。
