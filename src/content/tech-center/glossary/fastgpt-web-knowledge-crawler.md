# FastGPT网页知识库同步爬虫工具的配置与使用说明

## 一句话定义
该术语指FastGPT中用于将网页内容同步至知识库的自定义爬虫工具配置功能。
## 在 FastGPT 里怎么用（参数 / 位置 / 步骤）
该功能属于FastGPT知识库网页同步模块的配套配置项。开源版本支持接入自定义爬虫工具，可在对应配置界面中添加自定义爬虫相关设置，以实现网页内容的爬取与知识库同步。官方建议开发知识库爬虫部分的专属需求，以适配不同的网页爬取场景。
## 容易搞错的地方
容易将该功能与通用网页爬取工具混淆，需注意该功能仅服务于FastGPT的知识库网页内容同步，不可直接用于非知识库相关的网页爬取；开源版仅支持自定义爬虫的接入配置，不可直接使用未完成配置的爬虫工具进行同步操作。部分用户可能误将该功能等同于通用爬虫工具，导致无法正确完成知识库同步流程。
