# FastGPT企业级多渠道机器人接入：版本、配置与运维边界

## 这件事在什么时候变成问题
当企业需要将FastGPT构建的AI应用能力嵌入员工日常使用的办公协作平台，或面向外部用户通过主流社交渠道提供服务时，该需求会从技术探索转化为需落地的业务问题。具体触发场景包括：内部团队无需额外登录FastGPT平台，即可通过企业微信、飞书、钉钉等工具直接调用AI服务；对外运营的公众号需要承接用户的咨询请求，自动生成标准化回复；跨部门协作场景中，统一的AI助手入口需要覆盖主流办公渠道。
该问题仅在满足两个前提时具备决策价值：一是FastGPT部署版本符合对应渠道的最低支持要求，二是企业具备对应平台的管理权限，可完成机器人创建、回调配置等操作。若企业仅使用社区版FastGPT，或未获得对应平台的开发者/管理员权限，则该需求暂无法通过官方原生能力落地。

## 需要先定下来的判据
| 判据 | 取什么值 | 依据 |
| ---- | ---- | ---- |
| 部署类型 | 选择商业版或云服务版 | 官方文档《FastGPT商业版》 |
| 版本门槛 | 匹配对应渠道的最低版本要求 | 各渠道官方教程文档 |
| 自定义域名需求 | 云服务版接入企业微信需配置，商业版可使用自有域名 | 企业微信机器人官方教程 |
| IP白名单配置 | 微信公众号接入需添加FastGPT官方IP | 微信公众号官方教程 |
| 凭证与加密 | 企业微信填 Token 与 Encoding-AESKey；公众号填 AppID、Secret、Token，AES Key 随机生成并选安全模式；飞书填 App ID 与 App Secret，Encrypt Key 可选（HTTP 通信时建议配置）；钉钉填 Client ID 与 Client Secret | 各渠道官方教程 |
| 会话重置方式 | 发送`Reset`大小写敏感 | 飞书、公众号、钉钉官方教程 |
| 权限配置 | 需开通对应平台的消息接收与发送权限 | 飞书、钉钉官方教程 |

判据的取舍需结合企业实际运维能力与业务需求展开。部署类型的选择优先匹配运维资源：商业版适合具备自有服务器运维能力的团队，云服务版适合无需关注底层部署的团队。版本门槛为基础前提，所有渠道的接入操作需在对应版本以上完成。自定义域名与IP白名单为平台强制校验项，需提前完成备案、解析与配置。加密配置保障通信链路安全，不同渠道的密钥规则存在差异，需严格按文档要求填写。会话重置与权限配置为用户体验与功能可用的核心保障，需在配置阶段同步确认。

## 具体怎么做
### 一、前置准备
首先确认FastGPT版本符合对应渠道的最低支持要求，商业版需升级至对应版本，云服务版按需完成自定义域名配置。确认平台侧的后台权限：企业微信的智能机器人入口只有企业创建者或超级管理员能看到；公众号需能登录微信公众平台修改服务器配置；飞书与钉钉需能在开发者后台创建企业自建应用或企业内部应用。完成自有域名备案（云服务版接入企业微信时需使用备案域名），并提前配置好FastGPT的访问域名。
### 二、分渠道配置流程
#### 企业微信机器人
从4.12.4版本起，FastGPT商业版支持直接接入企业微信机器人，无需额外API；云服务版从4.14.4版本起，需先配置自定义域名方可使用。操作步骤包括：登录企业微信管理后台，进入「安全与管理-管理工具-智能机器人」，选择API模式创建机器人，随机或手动生成`Token`与`Encoding-AESKey`并记录。在FastGPT的应用发布渠道页面，选择「企业微信机器人」创建发布渠道，填入获取到的`Token`与`Encoding-AESKey`，复制生成的回调地址，回填至企业微信机器人的配置页面中，完成配置。
#### 微信公众号
从4.8.10版本起，FastGPT商业版支持接入微信公众号，仅支持通过验证的服务号或订阅号。在FastGPT应用发布渠道页面新建微信公众号渠道，填写基础信息后，获取`AppID`、`Secret`与`Token`。登录微信公众平台，将获取的参数填入配置弹窗，添加FastGPT官方IP至IP白名单，随机生成`AES Key`并选择安全加密模式。复制FastGPT生成的回调地址，回填至微信公众平台的服务器配置页面，启用服务器配置即可完成接入。
#### 飞书机器人
从4.8.10版本起，FastGPT商业版支持接入飞书机器人。在飞书开放平台开发者后台创建企业自建应用并添加机器人能力，获取`App ID`与`App Secret`。在FastGPT应用发布渠道页面新建飞书机器人渠道，填入`App ID`与`App Secret`，可选配置`Encrypt Key`用于加密通信。复制FastGPT生成的回调地址，在飞书控制台的「事件与回调」页面配置订阅方式，粘贴回调地址。添加`im.message.receive_v1`接收消息事件，开通「以应用的身份发消息」与「获取单聊、群组消息」权限，发布机器人应用即可完成配置。
#### 钉钉机器人
从4.8.16版本起，FastGPT商业版支持接入钉钉机器人。在钉钉开发者后台创建企业内部应用，获取`Client ID`与`Client Secret`。在FastGPT应用发布渠道页面新建钉钉机器人渠道，填入获取的凭证，复制生成的回调地址。在钉钉开发者后台为应用添加「机器人」应用能力，将消息接收模式设置为HTTP模式，粘贴回调地址至消息接收地址，完成应用版本发布即可在钉钉中使用机器人。
#### 微信个人号
在发布渠道选择`微信个人号`新建渠道，首次需要扫码登录，连接后好友列表会出现`微信 ClawBot`机器人。文档 FAQ 写明目前仅支持 iOS 系统，并需要升级微信版本。
### 三、会话边界确认
会话怎么划分以文档写明的为准：飞书机器人的聊天记录 chatId 有三种来源——私聊聊天框、话题群中的单个话题、普通群聊里由群 ID 与个人 ID 组成；钉钉机器人可以私聊，也可以在群组添加机器人后`@机器人`触发对话。飞书、钉钉与公众号机器人发送`Reset`（注意大小写）会新开一个聊天记录；微信个人号渠道输入`Reset`或`/reset`重置。企业微信机器人的会话划分与重置方式文档没有写明，需按实际环境确认。
### 四、消息没有响应时的核对顺序
企业微信与飞书两份教程给出的顺序一致：先核对平台侧配置（企业微信查可信域名、Token 与 Encoding-AESKey；飞书查回调地址与权限），再看 FastGPT 对话日志里有没有这条提问。有记录而平台没有回应，飞书文档指向的是没给机器人开权限；没有记录，则可能是应用运行出错，可以先换一个最简单的机器人验证链路。飞书机器人无法输入全局变量、文件与图片内容，依赖这些输入的应用接到飞书后需要单独验证。更新说明里与这条链路相关的两处：v4.17.0 起，商业版对飞书、企业微信、钉钉和微信公众号等发布渠道收到的非法消息返回明确的客户端错误；v4.17.1 修复了飞书发布渠道配置`Encrypt Key`时事件订阅 URL 校验无法正确返回 challenge 的问题。

## 怎么验收
1. 向对应渠道的机器人发送测试消息，检查FastGPT对话日志是否存在对应接收记录，通过标准为对话日志里出现这条提问。
2. 等待机器人返回回复内容，对比FastGPT调试界面的输出结果，通过标准为回复内容与预期一致。
3. 向机器人发送`Reset`消息，发起新的对话请求，检查新对话是否不包含历史聊天上下文，通过标准为上下文重置成功。
4. 检查对应平台的机器人配置页面，确认回调地址配置无报错，通过标准为平台验证回调成功。
5. 验证权限配置有效性，飞书与钉钉场景下，向机器人发送消息后确认可正常返回回复，通过标准为无权限报错。
6. 群聊场景测试（若支持），@机器人发送消息，检查是否能正常接收并回复，通过标准为群聊场景功能正常。

## 边界：什么情况下这套做法不成立
按商业版功能差异表，第三方应用发布（飞书、公众号）在社区版中不提供；企业微信与钉钉机器人的教程写的是商业版支持。使用社区版时，这几个渠道无法在发布渠道里直接接入，只能基于 API 自行开发对接。未通过验证的微信公众号无法完成完整配置，测试号可以正常使用，但不能配置`AES Key`。企业内部网络存在严格的防火墙限制，导致FastGPT服务无法被外部平台访问，或外部平台的回调请求无法抵达FastGPT服务时，消息将无法正常传递。
企业未获得对应平台的管理权限，无法完成机器人创建、回调配置与权限开通时，接入操作无法推进。云服务版接入企业微信机器人时，未配置自定义域名将无法满足平台对回调地址的企业主体域名要求。若企业内部网络存在严格的出站/入站限制，导致FastGPT服务无法与对应平台的开放API通信，机器人功能将无法正常运行。此外，飞书话题群的会话划分逻辑与普通群聊存在差异，部分自定义场景的会话边界可能与预期不符。
