# FastGPT 配置与开发参考：版本升级与变更说明

本页汇总站内已发布的各版本的升级操作、升级脚本、环境变量变更与更新内容相关文档，共 170 篇，按标题排序列出。

## 这一类文档通常在讲什么

1. 某个版本升级要执行哪些脚本、按什么顺序操作
2. 某个版本改了哪些环境变量、旧配置怎样适配
3. 某个版本新增、优化与修复了哪些功能

若问题与上述三个方向都不匹配，可返回[配置与开发参考全景](/zh/guide/reference-overview)查找版本升级与回退之外的关联主题。

## 阅读顺序建议

1. 先从表中选择与版本升级与回退当前问题直接对应的条目，核对文档适用版本
2. 对照版本升级与回退的关联条目，列出需要共同配置的依赖项
3. 将版本升级与回退涉及的设置项逐一与参考资料中的官方说明对照
