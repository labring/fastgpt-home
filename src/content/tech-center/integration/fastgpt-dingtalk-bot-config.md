# FastGPT商业版接入钉钉机器人的配置与使用教程

### 功能说明与适用边界
该功能仅FastGPT商业版4.8.16及以上版本支持，无需额外API即可完成钉钉机器人接入。支持两种使用场景：钉钉内与机器人私聊，或在群组中@机器人触发对话。若使用低于该版本的FastGPT商业版，无法直接使用该接入方式。

### 详细配置步骤
1.  **创建钉钉企业内部应用**：在钉钉开发者后台创建企业内部应用，获取Client ID和Client Secret。
2.  **为FastGPT添加发布渠道**：在FastGPT中选择目标应用，进入发布渠道页面，新建钉钉机器人接入渠道，将获取到的Client ID和Client Secret填入配置弹窗。创建完成后点击"请求地址"按钮，复制生成的回调地址。
3.  **添加机器人应用能力**：回到钉钉开发者后台，点击左侧"添加应用能力"，为已创建的企业内部应用添加机器人应用能力。
4.  **配置机器人回调地址**：进入左侧"机器人"应用能力页面，将底部"消息接受模式"设置为HTTP模式，填入之前复制的FastGPT回调地址，调试完成后点击"发布"。
5.  **发布应用版本**：在钉钉开发者后台的"版本管理与发布"页面，点击"创建新版本"，设置版本号和版本描述后保存发布。

### 常见注意事项与FAQ
配置过程中需注意两点：一是需准确复制FastGPT生成的回调地址，避免因地址错误导致机器人无法接收消息；二是需完成钉钉应用的版本发布，否则机器人功能无法正常生效。若需要重置聊天记录，可向机器人发送大小写敏感的`Reset`消息，即可新开一个聊天记录。
