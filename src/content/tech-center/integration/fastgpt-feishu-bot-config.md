# FastGPT接入飞书机器人的配置步骤与注意事项

FastGPT商业版4.8.10及以上版本支持直接接入飞书机器人，无需额外API对接。该功能仅支持在飞书内通过单聊或群聊@机器人的方式调用FastGPT应用，且飞书机器人暂不支持输入全局变量、文件、图片内容作为交互参数，使用前需确认应用版本符合要求。

## 详细配置步骤
1. 申请飞书应用：在飞书开放平台开发者后台创建企业自建应用，添加机器人类型应用，建议使用免费测试企业进行调试。
2. 新建FastGPT发布渠道：进入目标FastGPT应用的发布渠道页面，新建飞书机器人接入渠道并填写基础信息。
3. 填写应用凭证：在飞书开放平台的自建应用中获取App ID、App Secret，填入FastGPT新建渠道的配置弹窗；可选配置Encrypt Key，使用HTTPS协议时无需配置，使用HTTP协议时建议配置，默认生成的Verification Token可忽略，因采用飞书官方推荐的更安全校验方式。
4. 配置回调地址：复制FastGPT发布渠道的请求地址，进入飞书控制台的「事件与回调」页面，点击「配置订阅方式」旁的编辑按钮，粘贴复制的请求地址。
5. 配置回调事件与权限：添加`im.message.receive_v1`（接收消息v2.0）事件，开启对应权限：读取用户发给机器人的单聊消息、接收群聊中@机器人消息事件，不推荐启用「获取群组中所有消息」权限，避免接收无关群消息。
6. 配置回复权限：在飞书控制台「权限管理」中搜索「发消息」，开通"以应用的身份发消息"权限。
7. 发布机器人：进入飞书控制台「版本管理与发布」页面发布机器人，即可在飞书工作台找到该机器人。

## 常见问题与注意事项
- 发送消息无响应：先检查飞书机器人回调地址、权限配置是否正确，查看FastGPT对话日志。若日志有对应提问记录，说明飞书未正确响应，需再次确认机器人权限已开通；若日志无记录，则可能是应用运行报错，可尝试使用基础文本内容测试。
- 重置聊天记录：向机器人发送大小写敏感的`Reset`指令，即可新开聊天记录。
此外需注意，配置事件时应选择新版本权限，避免启用历史版本权限导致功能异常。
