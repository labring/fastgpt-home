# FastGPT商业版接入飞书机器人的完整配置步骤

### 前置说明
从4.8.10版本起，FastGPT商业版支持直接接入飞书机器人，无需额外API。整体配置分为飞书应用申请、FastGPT渠道配置、飞书权限与回调配置三个核心环节。

### 完整配置步骤
1.  **申请飞书应用**：在飞书开放平台开发者后台创建企业自建应用，并添加机器人应用，建议使用免费测试企业便于调试。
2.  **新建FastGPT发布渠道**：在FastGPT中选择目标应用，进入「发布渠道」页面，新建飞书机器人接入渠道并填写基础信息。
3.  **配置凭证信息**：在飞书开放平台的自建应用中获取App ID、App Secret，填入FastGPT的发布渠道配置弹窗。可选配置：若使用HTTP协议通信，可在飞书「事件与回调-加密策略」中获取Encrypt Key填入FastGPT配置；HTTPS协议无需配置该参数，默认生成的Verification Token可忽略。
4.  **配置回调地址**：完成FastGPT渠道创建后，点击「请求地址」复制对应链接，进入飞书控制台「事件与回调」页面，点击「配置订阅方式」旁的编辑按钮，粘贴复制的请求地址。
5.  **配置回调事件与权限**：在「事件与回调」页面添加`im.message.receive_v1`（接收消息v2.0）事件。随后添加两项权限：「读取用户发给机器人的单聊消息」（开启后单聊消息会被转发至FastGPT）、「接收群聊中@机器人消息事件」（开启后群聊@机器人的消息会被转发），不推荐开启「获取群组中所有消息」权限。
6.  **配置回复权限**：进入飞书控制台「权限管理」，搜索「发消息」，找到「以应用的身份发消息」权限并开通。
7.  **发布机器人**：点击飞书控制台「版本管理与发布」完成发布，即可在工作台找到机器人，可将其拉入群组或单独对话。

### 常见问题排查
1.  **发送消息无响应**：先检查飞书机器人回调地址、权限配置是否正确；查看FastGPT对话日志，若存在提问记录但无回应，说明未正确开通机器人回复权限；若无提问记录，可能是应用运行报错，可先测试最简机器人交互（暂不支持全局变量、文件、图片内容）。
2.  **重置聊天记录**：向机器人发送`Reset`（注意大小写），即可新开聊天记录。飞书机器人的聊天记录chatId来源包括私聊聊天框、飞书话题群单个话题、群组聊天的群id+个人id组合。
