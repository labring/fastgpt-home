# FastGPT商业版接入微信公众号的配置与使用方法

FastGPT 4.8.10及以上商业版支持直接接入微信公众号，无需额外调用第三方API。该功能仅支持已通过微信验证的服务号和订阅号，未验证的公众号暂无法接入；开发者可申请微信公众号测试号进行功能验证，但测试号不支持配置AES Key。

## 配置步骤
1. 在FastGPT平台选择需要接入公众号的应用，进入「发布渠道」页面，新建微信公众号接入渠道并填写基础信息。
2. 登录微信公众平台官网（https://mp.weixin.qq.com），获取AppID、Secret和Token三个参数，将其填入FastGPT的配置弹窗中。
3. 配置IP白名单：私有部署用户可自行查询本机IP并添加；国际版用户（访问cloud.fastgpt.io）需添加以下IP列表：35.240.227.100、34.124.237.188、34.143.240.160、34.87.51.146、34.87.79.202、35.247.163.68、34.87.102.86、35.198.192.104、34.126.163.205、34.124.189.116、34.143.149.171、34.87.173.252、34.142.157.52、34.87.180.104、34.87.20.189、34.87.110.152、34.87.44.74、34.87.152.33、35.197.149.75、35.247.161.35；中国大陆地区用户（访问fastgpt.cn）需添加以下IP列表：47.97.1.240、121.43.105.217、121.41.178.7、121.40.65.187、47.97.59.172、101.37.205.32、120.55.195.90、120.26.229.115、120.55.193.112、47.98.190.173、112.124.41.79、121.196.235.183、121.41.75.88、121.43.108.48、112.124.12.6、121.43.52.222、121.199.162.43、121.199.162.102、120.55.94.163、47.99.59.223、112.124.46.5、121.40.46.247、120.26.145.73、120.26.147.199、121.43.125.163、121.196.228.45、121.43.126.202、120.26.144.37。
4. 随机生成AES Key并填入FastGPT配置弹窗，选择加密方式为安全模式。
5. 在FastGPT完成渠道创建后获取回调URL，将该URL填入微信公众平台的对应配置项并提交保存。
6. 若服务器配置未自动启用，需手动启用该配置。
7. 配置完成后，用户向公众号发送的消息将被转发至FastGPT，对话结果会通过公众号返回给用户。

使用过程中，若需要重置当前聊天记录，可向公众号机器人发送大小写敏感的「Reset」消息，即可开启全新的对话会话。需要注意，IP白名单配置错误会导致无法正常接收和转发公众号消息，需确保配置的IP与当前访问的FastGPT服务版本匹配。
