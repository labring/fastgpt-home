# FastGPT接入企业微信智能机器人的配置与使用教程

FastGPT的企业微信智能机器人接入功能有明确的版本适配要求：4.12.4及以上的商业版可直接接入，无需额外API；4.14.4及以上的云服务版支持通过自定义域名方式接入。需要注意的是，企业微信要求智能机器人的消息推送地址必须使用企业主体域名，因此云服务版用户必须先完成自定义域名配置，商业版用户可直接使用企业自有域名。

## 完整配置步骤
1.  **配置自定义域名（云服务版必选）**：商业版用户直接使用企业自有域名即可，云服务版需提前完成自定义域名配置流程。
2.  **创建并配置企业微信智能机器人**
    2.1  使用超级管理员账号登录企业微信管理后台；
    2.2  进入「安全与管理 - 管理工具」页面，找到「智能机器人」入口（仅企业创建者或超级管理员可见该入口）；
    2.3  在创建机器人页面下拉，选择「API模式创建」智能机器人；
    2.4  随机生成或手动输入`Token`和`Encoding-AESKey`，并妥善记录这两个密钥；
    2.5  登录FastGPT平台，选择目标Agent，进入发布渠道页面，选择「企业微信机器人」并点击「创建」；
    2.6  在发布渠道配置页中，填入步骤2.4中记录的`Token`和`Encoding-AESKey`；
    2.7  点击「确认」后，选择已配置的自定义域名，复制回调地址，将其填回企业微信智能机器人的配置页面中。

## 使用与问题排查
完成配置后，可在企业微信通讯录中找到创建的智能机器人，直接发送消息即可调用FastGPT应用。如果出现发送消息后无响应的情况，可按以下步骤排查：首先检查可信域名配置是否正确；其次核对`Token`和`Encoding-AESKey`是否填写无误；最后查看FastGPT的对话日志，若没有对应的提问记录，大概率是应用运行报错，可先尝试使用最简机器人进行测试。
