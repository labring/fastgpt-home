# FastGPT接入企业微信智能机器人的配置步骤与排查方法

本页内容针对FastGPT接入企业微信智能机器人的场景，明确版本支持范围：从4.12.4版本起，FastGPT商业版支持直接接入企微机器人，无需额外API；从4.14.4版本起，FastGPT云服务版支持通过配置自定义域名的方式接入。其中云服务版用户必须先配置自定义域名，因为企微要求智能机器人消息推送地址必须使用企业主体域名；商业版用户可直接使用企业自有域名完成配置。

## 标准配置步骤
1.  超级管理员登录企业微信管理后台
2.  找到智能机器人入口：在「安全与管理 - 管理工具」页面点击「智能机器人」，该入口仅企业创建者或超级管理员可见
3.  选择API模式创建机器人：在创建机器人页面下拉，点击「API模式创建」
4.  获取关键密钥：随机生成或手动输入Token和Encoding-AESKey，并妥善记录
5.  创建企微机器人发布渠道：在FastGPT中选择目标Agent，进入发布渠道页面，选择「企业微信机器人」并点击「创建」
6.  配置发布渠道信息：填入步骤4中记录的Token和Encoding-AESKey
7.  复制回调地址：点击「确认」后，选择已配置的自定义域名，复制回调地址并填回企微智能机器人配置页面

## 常见问题与使用说明
完成配置后，可在企业微信通讯录中找到创建的机器人并发送消息测试。若发送消息无响应，可按以下顺序排查：1. 检查可信域名配置是否正确；2. 检查Token和Encoding-AESKey是否填写正确；3. 查看FastGPT对话日志是否存在对应提问记录，若无记录则可能是应用运行报错，可先尝试最简单的机器人进行测试。
