# FastGPT系统插件开发的官方可用资源与使用指南

FastGPT系统插件开发可依托官方提供的公开资源完成各类相关工作，包括代码仓库获取、开发流程学习、工具使用指导等。本页整理了全部官方公开的插件开发资源，涵盖核心代码仓库与各类工具、开发指南文档，可满足不同开发场景的需求，帮助开发者快速获取所需的开发资料与工具支持。

### 官方资源清单
- FastGPT Plugin 仓库：https://github.com/labring/fastgpt-plugin，存放插件开发相关代码与官方文档的核心仓库
- 系统插件开发指南：https://github.com/labring/fastgpt-plugin/blob/main/docs/dev/how-to-devlop-plugin.md，详细说明系统插件的开发流程与规范
- SDK Factory 使用指南：https://github.com/labring/fastgpt-plugin/blob/main/sdk/factory/README.md，介绍SDK Factory工具的具体使用方法
- CLI 使用指南：https://github.com/labring/fastgpt-plugin/blob/main/apps/cli/README.md，说明CLI工具的操作步骤

### 基础使用指引
如需开展系统插件开发工作，可先获取FastGPT Plugin仓库的完整代码与文档资源。根据具体开发或使用需求，查阅对应指南完成后续操作：开发系统插件可参考系统插件开发指南，了解开发流程与规范；使用SDK Factory工具可查阅SDK Factory使用指南，掌握工具的具体使用方法；使用CLI工具可参考CLI使用指南，完成命令行相关操作。
