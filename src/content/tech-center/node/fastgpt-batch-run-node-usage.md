# FastGPT批量运行节点的配置与批量任务处理方法

批量运行节点是FastGPT V4.8.11版本新增的功能模块，用于迭代处理数组类型的输入数据，以可视化方式实现类似编程语言的循环结构。该节点本质是可自动化重复执行的功能单元，支持数组批量处理、自动遍历元素、保持处理顺序、并行处理优化、条件终止、循环计数以及执行上下文维护，可与AI对话、HTTP请求、内容提取等节点协同工作，适用于批量数据处理、递归任务等场景。

## 配置与使用步骤
配置该节点需设置两个核心必填参数：
1.  **数组输入**：接收字符串、数字、布尔或对象类型的数组数据，可通过代码运行节点生成测试数组，示例代码为`const texts = [ "这是第一段文本", "这是第二段文本", "这是第三段文本" ]; return { textArray: texts };`。
2.  **循环体配置**：包含循环体开始和结束标记，内部可添加任意类型的工作流节点。循环体结束节点需通过下拉菜单选择要输出的变量，该变量会作为单次循环的结果被收集，所有循环结果将组成新的数组作为最终输出。
以批量翻译文本为例，具体操作流程为：先通过代码运行节点生成待处理的文本数组，将批量运行节点的数组输入指向代码运行节点的`textArray`输出变量；在循环体内添加AI对话节点，设置prompt为“请将这段文本翻译成英文”，再添加指定回复节点用于输出处理结果；最后配置循环体结束节点，选择输出变量为AI回复内容，完成整体流程配置。

## 注意事项与使用边界
使用该节点需注意以下要点：首先，仅支持数组类型的输入数据，非数组类型的输入数据无法触发循环逻辑；其次，循环体内部的节点需与业务需求匹配，若未正确配置循环体结束节点的输出变量，将无法收集到有效的结果数组；另外，并行处理为可选的性能优化项，仅在需要提升批量处理效率时开启，避免不必要的资源占用。该节点不适用于单任务处理场景，若仅需处理单个数据，无需使用批量运行节点。
