# FastGPT批量运行节点的配置与批量数据处理方法

## 节点概述与核心特性
批量运行节点是FastGPT V4.8.11版本新增功能，用于对数组类型输入数据进行迭代处理，每次处理数组中一个元素并自动执行后续节点，直至完成全量处理。其设计参考编程语言循环结构，以可视化方式实现自动化重复执行特定工作流，可与AI对话、HTTP请求、内容提取、判断器等节点协同使用，支持数组批量处理、自动遍历、保持处理顺序、并行优化、条件终止、循环计数及执行上下文维护。

## 配置参数说明
该节点需配置两个核心必填输入参数：
1.  **数组**：接收数组类型输入，支持字符串数组、数字数组、布尔数组、对象数组四种类型。
2.  **循环体**：定义单次循环执行的节点流程，包含循环体开始标记与循环体结束标记。循环体结束节点可通过下拉菜单选择输出变量，该变量会作为单次循环结果被收集，所有循环结果将组成新数组作为节点最终输出。

## 最小配置示例（批量文本翻译）
1.  生成测试数组：使用代码运行节点创建文本数组，代码为`const texts = ["这是第一段文本", "这是第二段文本", "这是第三段文本"]; return { textArray: texts };`。
2.  配置批量运行节点：将数组输入绑定至代码运行节点输出的`textArray`变量。
3.  搭建循环体流程：在循环体内添加AI对话节点，设置prompt为“请将这段文本翻译成英文”；再添加指定回复节点用于输出处理结果。
4.  配置循环体结束节点：选择输出变量为AI回复内容，完成整体配置。
运行流程将依次执行代码生成数组、批量遍历处理每个文本元素、收集翻译结果并输出最终数组。
