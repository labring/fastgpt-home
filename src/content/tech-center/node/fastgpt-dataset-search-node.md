# FastGPT工作流知识库搜索节点的参数配置和使用说明

## 节点基本介绍
FastGPT工作流中的知识库搜索节点，是用于实现向量知识库内容检索的核心模块。该节点支持重复添加，在复杂工作流编排中可避免连线过于杂乱，提升界面美观度；同时支持接收外部输入与静态配置两种配置方式，适配不同的业务场景需求。节点触发后将执行向量搜索逻辑，其输出为数组格式的引用内容，即使未搜索到匹配的知识库内容，输出链路仍可正常通行，不会阻断后续工作流节点的执行。

## 核心参数说明
该节点的参数分为输入与输出两类，所有参数均需按照官方文档的规范配置：
输入参数包含两项核心配置：一是「关联的知识库」，可选择一个或多个使用相同向量模型的知识库用于向量搜索，需确保所选知识库的向量模型一致，否则搜索结果将不符合预期；二是「搜索参数」，点击配置项即可查看详细的参数介绍，可根据业务需求调整相关检索规则。
输出参数为「引用内容」，以标准数组格式输出，数组长度可为0，代表本次搜索未匹配到任何知识库内容，该输出链路始终可正常通行，不会因搜索结果为空而终止工作流。

## 最小配置操作步骤
这是一个可直接照做的最小配置示例，无需额外复杂设置：
1. 进入FastGPT应用的工作流编辑页面，从节点库中添加知识库搜索节点；
2. 在节点配置面板的「关联的知识库」选项中，选择一个已创建且完成向量模型配置的知识库，仅可选择同向量模型的知识库；
3. 点击「搜索参数」配置项，参考官方文档的参数说明完成基础配置，无需特殊调整可保留默认设置；
4. 保存节点配置，即可将该节点接入工作流的链路中，通过「引用内容」输出链路获取检索到的知识库内容，供后续节点使用。
