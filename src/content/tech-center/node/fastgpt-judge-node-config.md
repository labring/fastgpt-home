# FastGPT判断器工作流节点的功能与配置说明

## 节点基本介绍
FastGPT判断器是工作流中的专用节点，具备可重复添加、支持外部输入、可触发执行的核心特点。其核心功能为对任意变量进行IF逻辑判断，当变量满足预设条件时执行IF分支流程，不满足预设条件则执行ELSE分支流程，同时支持添加多个判断条件与分支，逻辑与通用编程语言中的IF语句完全一致。该节点的典型使用场景包括：让大模型完成判断后输出固定内容，或是根据大模型的回复内容判断是否触发后续的工作流模块。

## 标准配置步骤
以下为可直接复用的最小配置示例：
1. 进入FastGPT工作流编辑页面，从节点列表中添加判断器节点；
2. 配置节点的外部输入变量，选择需要进行判断的目标变量，例如「知识库引用」变量；
3. 设置判断条件，例如设置“变量长度等于0”的判断规则；
4. 分别配置IF分支与ELSE分支的后续节点：当「知识库引用」变量长度为0时，执行IF分支，可添加文本拼接节点输出"未匹配到相关知识库内容"；当变量长度不为0时，执行ELSE分支，可直接将知识库引用内容拼接至回复流程中。

## 场景扩展说明
判断器节点支持灵活扩展判断条件与分支，可适配更多复杂的业务判断需求。例如可通过叠加多个判断规则，实现多层级的变量校验、多维度的内容筛选等场景。同时该节点可重复添加至工作流中，满足不同环节的判断需求，无需重复创建新的节点实例。
