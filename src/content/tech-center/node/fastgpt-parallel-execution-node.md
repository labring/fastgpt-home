# FastGPT并行执行节点的参数说明与使用示例

## 节点功能与核心特性
该节点适用于FastGPT 4.14.11及以上版本，可接收一个数组，对每个元素同时执行同一段子工作流，最终汇总所有结果输出，适合处理各项独立无依赖的批量任务，例如批量翻译文本、抓取多网页信息、批量调用外部接口。其核心特性包括：多任务并行执行提升效率、支持配置最大并发数平衡速度与资源、单个任务失败不影响整体进度、失败任务可自定义重试次数、成功与失败结果分别归总、运行后可按任务单独查看执行细节。

## 参数说明
### 输入参数
- 数组：必填项，为需批量处理的数据，通常来自上游节点的数组输出，元素支持字符串、数字、对象等，最大长度由部署方设置为100。
- 最大并发数：必填项，默认值为5，取值范围1~部署上限（默认上限为10），用于控制同时运行的任务数量。
- 单轮报错重试次数：必填项，默认值为3，取值范围0~5，设为0则关闭自动重试。
- 执行逻辑：必填项，为节点内部的子流程，由「开始」和「结束」两个固定锚点包围，可自由编排其他节点。

### 输出参数
- 成功结果：仅包含执行成功的任务输出，按输入数组顺序排列，下游通常可直接使用该字段。
- 完整结果：与输入数组一一对应的对象数组，每项格式为`{ success, message, data }`，成功时`success=true`、`data`为输出值；失败时`success=false`、`message`为错误提示、`data`为null。
- 完成状态：整体执行状态，可选值为`success`（全部成功）、`partial_success`（部分失败）、`failed`（全部失败），可用于分支判断逻辑。

## 快速配置示例
以并行翻译文本数组为例，最简配置步骤如下：
1. 使用【代码运行】节点构造测试数组，代码为：
```javascript
function main (){
  const texts = [\"这是第一段文本\", \"这是第二段文本\", \"这是第三段文本\"];
  return { textArray: texts };
}
```
2. 配置【并行执行】节点：选择上游节点的`textArray`作为数组输入，保持最大并发数默认5，单轮报错重试次数默认3。
3. 在执行逻辑内添加【AI对话】节点，设置prompt为`请将下面这段文本翻译成英文：{当前数组项}`，并关闭「返回AI内容」以避免输出交错。
4. 配置【结束】节点，选择输出变量为【AI对话】的回复内容。
5. 下游可直接引用「成功结果」获取翻译后的字符串数组，或引用「完整结果」核对每项执行状态。

## 注意事项与部署配置
使用时需注意：并行执行节点内不可嵌套其他并行或批量运行节点，不支持表单输入、用户选择等交互节点；成功任务内对全局变量的修改可能存在竞争，需通过节点汇总结果获取稳定输出；执行逻辑内的AI节点建议关闭流式输出。私有化部署时可调整两个环境变量：`WORKFLOW_MAX_LOOP_TIMES`默认值100（输入数组最大长度），`WORKFLOW_PARALLEL_MAX_CONCURRENCY`默认值10（最大并发数上限）。
