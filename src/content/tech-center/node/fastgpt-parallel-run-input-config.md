# 配置FastGPT并行运行节点的输入参数与执行逻辑

并行运行节点的输入配置用于定义批量数据处理的核心规则，该节点可接收上游节点输出的数组数据，将数组内的每个元素作为独立任务执行内部子流程，实现批量并行处理的能力，适用于需要同时处理多组数据的业务场景。配置该节点时，需依次完成输入源关联、参数设置与子流程编排。首先绑定上游输出的数组数据为输入参数；其次根据任务需求设置最大并发数与单轮报错重试次数；最后编排包含开始与结束锚点的子流程，定义单个批量任务的执行逻辑。

### 输入参数说明
| 参数             | 必填 | 默认 | 说明                                                                                    |
| ---------------- | ---- | ---- | --------------------------------------------------------------------------------------- |
| 数组             | 是   | -    | 要批量处理的数据，通常来自上游节点的数组输出，元素可以是字符串、数字、对象等            |
| 最大并发数       | 是   | 5    | 最多允许几个任务同时进行，范围 1~上限值（上限由部署方设置，默认 10）                    |
| 单轮报错重试次数 | 是   | 3    | 单个任务失败后自动重试的次数，范围 0~5；设为 0 表示失败不再重试                         |
| 执行逻辑         | 是   | -    | 节点内部要执行的子流程，由「开始」和「结束」两个固定锚点包围，中间可以自由编排其他节点  |

所有参数均为必填项，需根据实际业务需求完成配置。最大并发数的取值范围为1至部署方设置的上限，默认上限为10，过高的并发数可能会对系统资源造成压力。单轮报错重试次数的取值范围为0至5，设为0时，单个任务失败后不会触发自动重试，需通过其他逻辑处理失败结果。执行逻辑的配置需严格遵循边界规则，必须使用节点内置的开始与结束锚点作为子流程的起止标记，中间可根据需求编排任意数量的其他节点，完成单个任务的完整处理流程。
