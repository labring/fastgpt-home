# FastGPT并行执行节点的功能、参数与使用注意事项

## 节点概述与核心特性
并行执行节点适用于FastGPT 4.14.11及以上版本，用于接收数组数据，对每个元素同时执行同一段子工作流，最终汇总输出结果。该节点适合处理各项独立无依赖的批量任务，例如批量翻译文本、多网页信息抓取、批量调用外部接口等。其核心特性包括：多任务并行执行无需排队，可配置最大并发数平衡速度与资源消耗；单个任务失败不会中断整体流程，支持自定义失败重试次数；成功与失败结果分别归总，支持在调试面板按任务单独查看执行细节。

## 参数规则与使用注意事项
该节点的输入参数包含：必填的待处理数组（通常来自上游节点的数组输出，元素支持字符串、数字、对象等）、必填的最大并发数（默认值为5，范围1~部署上限，部署上限由环境变量`WORKFLOW_PARALLEL_MAX_CONCURRENCY`控制，默认值为10）、必填的单轮报错重试次数（默认值为3，范围0~5，设为0则不重试），以及必填的执行逻辑子流程（由「开始」和「结束」锚点包围，可自由编排其他节点）。
输出参数包含三类：按输入顺序排列的成功结果数组，仅包含执行成功的任务输出；与输入数组一一对应的完整结果数组，每项包含`success`、`message`、`data`字段（成功时`success=true`、`data`为输出值；失败时`success=false`、`message`为错误提示、`data`为null）；以及整体完成状态（`success`表示全部成功、`partial_success`表示部分失败、`failed`表示全部失败）。
使用时需注意多项限制：不可嵌套并行执行或批量运行节点；不可在执行逻辑内放置表单输入、用户选择等交互节点；并行流程内修改全局变量或并行容器外节点输出时，可能因多任务竞争导致结果不可控；输入数组最大长度为100（由环境变量`WORKFLOW_MAX_LOOP_TIMES`控制）；执行逻辑内的AI对话节点需关闭流式输出，避免多个任务的输出内容交错显示。

## 快速配置示例（并行翻译文本）
以批量翻译文本数组为例，完整配置步骤如下：
1.  使用代码运行节点生成测试数组，代码内容为：
    ```javascript
    function main (){
      const texts = ["这是第一段文本", "这是第二段文本", "这是第三段文本"];
      return { textArray: texts };
    }
    ```
2.  配置并行执行节点：选择代码运行节点的输出变量`textArray`作为数组输入，保留默认的最大并发数5与单轮报错重试次数3。
3.  在执行逻辑内添加AI对话节点，将开始节点的输入作为待翻译文本，设置prompt为`请将下面这段文本翻译成英文：{当前数组项}`，并关闭「返回AI内容」选项以避免输出交错。
4.  配置执行逻辑的结束节点，将输出变量设置为AI对话的回复内容。
下游可直接引用「成功结果」获取翻译后的字符串数组，引用「完整结果」可查看每项任务的执行状态，通过「完成状态」可快速判断是否需要触发兜底逻辑。
