# 配置FastGPT指定回复模块实现固定或变量化内容输出

## 模块概述
指定回复是FastGPT工作流中的基础节点模块，主要用于特殊状态下的内容回复场景。该模块具备三个核心特点：一是支持重复添加，可在复杂工作流编排中通过多节点拆分避免线路过于杂乱，提升编排美观度；二是回复内容来源灵活，既可以手动输入固定文本内容，也可以通过引用工作流变量获取外部输入的动态内容；三是会将最终配置的回复内容直接输出给客户端，完成回复环节的流程衔接。

## 配置操作步骤
1. 进入FastGPT应用的工作流编辑页面，在左侧节点列表中找到「指定回复」节点，将其添加到工作流画布中；
2. 配置回复内容，提供两种可选方式：第一种是直接在节点配置面板中手动输入固定的文本内容；第二种是通过引用工作流中已定义的变量来获取动态内容；
3. 可根据编排需求重复添加多个指定回复节点，调整节点位置优化链路布局，将该节点接入工作流的上下游链路后，保存当前工作流配置即可完成部署。

## 功能边界说明
该模块仅负责输出预设或变量化的回复内容，不具备其他内容处理能力，仅适用于需要固定或动态返回指定内容的特殊场景，比如用户触发特定流程节点后的固定提示、流程中断时的友好提示等。
