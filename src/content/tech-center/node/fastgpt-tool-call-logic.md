# 详细介绍FastGPT工具节点的运行条件与调用逻辑

## 工具运行的基础条件
工具运行的基础条件包含工具介绍与工具参数两类核心内容。工具介绍用于告知大语言模型工具的功能，辅助模型基于上下文语义判断是否调用该工具。工具参数包含参数介绍与是否必须两个关键配置项。根据参数有无与是否必须的情况，可分为两类工具的调用判断逻辑：无参数工具直接根据工具介绍决定是否执行，例如获取当前时间；有参数工具则分为两种场景，无必须参数的工具，即使上下文无适配参数，大语言模型仍可调用，或自行伪造参数；有必须参数的工具，若上下文无适配参数，大语言模型可能不会调用该工具，可通过提示词引导用户提供所需参数。

## 工具节点配置参数
工具节点的核心配置参数包含以下三项：
| 配置项 | 具体说明 |
| ---- | ---- |
| 工具介绍 | 描述工具的功能与适用场景，供大语言模型判断调用必要性 |
| 参数介绍 | 逐一说明每个调用参数的用途 |
| 是否必须 | 标记每个参数是否为调用该工具的必填项 |
配置时需根据工具实际情况填写对应内容，无参数工具无需配置参数项，有参数工具需完整填写参数介绍与是否必须的标记内容。
