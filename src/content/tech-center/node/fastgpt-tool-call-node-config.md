# FastGPT工作流工具调用节点的配置与使用说明

## 工具调用节点基础说明
工具调用节点是FastGPT工作流的核心模块，可让大语言模型动态决策执行流程，支持调用系统模块或插件。工具的核心组成分为两部分，一是工具介绍，用于告知大语言模型该工具的功能与适用场景；二是工具参数，系统模块的参数已固定，无需额外配置，插件的参数则支持自定义配置。
工具运行需满足两个前提条件，即工具介绍和工具参数。参数需包含两个关键信息：参数介绍与是否必须。大语言模型会结合这两项信息决定是否调用工具，存在三种常见场景：无参数的工具，直接根据工具介绍判断是否执行，例如获取当前时间；有参数但无必须参数的工具，即使上下文中无适配参数，大语言模型也可能调用并伪造参数；有必须参数的工具，若未提供适配参数，大语言模型大概率不会调用，可通过提示词引导用户补充参数。

## 工具调用节点配置步骤
在FastGPT高级编排界面中，拖动工具调用的连接点，可用工具的头部会出现菱形标记。将该菱形与工具调用模块底部的菱形连接，即可关联对应工具。被关联的工具会自动分离工具输入与普通输入，此时可编辑工具介绍，通过调整介绍内容精准控制工具的调用时机。
调试工具调用时，请勿一次性添加过多工具，建议先调优少量工具，确认逻辑无误后再逐步扩展。支持函数调用的模型可一次性调用多个工具，大语言模型会根据上下文自动选择并执行对应工具。

## 附加节点与使用场景
工具调用节点默认会将工具运行结果返回给大语言模型，由模型对结果进行总结输出。若无需此步骤，可将工具调用节点接入工具流程的末尾，直接终止AI总结环节。
使用工具调用节点时，会自动生成两个附加节点：工具调用终止节点和自定义工具变量节点。工具调用终止节点可接在任意工具之后，当工作流执行到该节点时，会强制结束本次工具调用，不再调用其他工具，也不会触发大语言模型针对工具结果的回答。自定义工具变量节点可扩展工具的变量输入，为未被视作工具参数的节点添加参数描述，让工具调用关联对应节点及后续工作流。
