# 使用FastGPT变量更新节点修改全局变量与节点输出

FastGPT的变量更新节点是工作流内置的基础配置节点，具备可重复添加、支持外部输入、可触发执行、需手动配置的特点。该节点的核心功能包括更新指定工作流节点的输出值，以及更新全局变量。其典型使用场景为：为"自定义变量"类型的全局变量赋值，无需用户手动输入；或更新变量更新节点之前的工作流节点输出，让后续使用该输出的节点加载新的数值。

### 配置操作步骤
1.  在工作流画布中添加变量更新节点，支持重复添加多个同类型节点。
2.  手动配置节点目标：选择需要更新的对象，可选择"自定义变量"类型的全局变量，或指定当前工作流内的前置节点。
3.  配置更新的目标值，可通过外部输入接入所需数据完成赋值。
4.  触发该节点执行后，即可完成对应变量或节点输出的更新。

使用该节点时需注意其使用边界与易错点：仅能修改当前工作流内的全局变量与前置节点输出，无法跨工作流操作数据；更新节点输出时，仅能修改该节点之前的工作流节点输出值，后续使用该值的节点才会加载新内容。若未正确配置目标对象或更新值，节点执行时可能出现参数缺失或无更新效果的报错。该节点适合需要动态调整全局变量或前置节点输出的场景，若仅需静态赋值，可直接通过全局变量配置完成，无需添加该节点。
