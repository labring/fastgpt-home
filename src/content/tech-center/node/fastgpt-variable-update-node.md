# 配置FastGPT变量更新节点实现全局变量与节点输出更新

## 节点基本介绍
FastGPT工作流中的变量更新节点是一款基础配置节点，具备四项核心特点：支持重复添加至同一工作流、带有外部输入端口可接收其他节点的输出值、随工作流流程触发执行、需手动配置更新规则与目标。其核心功能包含两类：一是更新指定工作流节点的输出值，二是更新全局变量的存储值。该节点的核心作用在于实现工作流内变量的动态调整：最基础的使用场景是为「自定义变量」类型的全局变量赋值，无需用户手动输入即可完成变量初始化；另一个常用场景是更新该节点之前的工作流节点的输出值，后续链路中的节点将使用更新后的新输出值，打破前序节点的固定输出限制，实现更灵活的工作流逻辑。

## 配置操作步骤
1. 进入FastGPT应用构建的工作流编辑页面，打开目标工作流。
2. 在左侧节点菜单的「工作流节点」分类中，找到「变量更新」节点，将其拖拽至画布的合适位置。
3. 双击「变量更新」节点打开配置面板，选择更新目标：可选择更新全局变量，或更新该节点之前的某一个工作流节点的输出。
4. 配置更新值：通过节点的外部输入端口绑定其他工作流节点的输出，或设置符合业务需求的更新内容。
5. 将该节点与前后的工作流节点进行连接，确认工作流链路完整，完成节点配置。

## 核心使用场景
变量更新节点的使用场景覆盖两类常见需求：其一，当需要为「自定义变量」类型的全局变量设置初始值，且无需用户手动输入时，可通过该节点直接完成赋值，简化用户交互流程；其二，当工作流需要根据中间环节的计算结果调整后续逻辑时，可通过该节点更新前序节点的输出值，让后续节点使用最新的计算结果，实现动态的工作流分支与逻辑调整。
