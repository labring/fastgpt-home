# 介绍FastGPT工作流AI对话节点的参数配置与使用方法

## 节点基本介绍
FastGPT工作流中的AI对话节点是核心执行模块，支持重复添加至工作流画布中，可通过触发机制启动执行。该节点的核心作用是调用配置的AI模型完成对话类任务，是工作流中实现智能交互功能的基础组件，可灵活适配多种业务场景的智能处理需求。

## 核心参数说明
该节点的核心配置项为AI模型模块，支持通过项目根目录下的`config.json`文件配置可选的对话模型列表，未在该文件中配置的模型无法在节点配置面板中选择。当用户双击节点打开配置面板后，点击AI模型配置入口，即可进入详细参数配置页面，完整的参数配置规则可参考官方提供的AI参数配置说明文档。该节点支持重复添加至工作流中，不同的AI对话节点可配置不同的AI模型，以适配不同的业务场景需求。

## 快速配置与使用步骤
1. 登录FastGPT工作区，进入需要编辑的目标工作流页面；
2. 在左侧的节点工具栏中找到AI对话节点，将其拖拽至工作流画布的指定位置；
3. 双击该AI对话节点，打开配置面板，点击面板内的AI模型配置项；
4. 在弹出的模型选择列表中，选择已通过`config.json`配置的目标对话模型；
5. 根据业务需求调整模型的相关参数，完成后保存节点配置；
6. 将工作流的触发节点与该AI对话节点进行连线，即可通过触发机制启动该节点的执行流程，完成AI对话任务。
