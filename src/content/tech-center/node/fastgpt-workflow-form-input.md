# 说明FastGPT工作流中表单输入节点的功能与配置方法

## 节点基础说明
表单输入节点是FastGPT工作流中的用户交互类节点，具备用户交互、可重复添加、触发执行三大特点。当该节点被工作流执行流程触发时，对话会进入交互状态，系统会同步记录当前工作流的运行状态，此时对话界面的对话框会隐藏。待用户完成表单填写并提交必填的信息后，该节点会收集用户填写的所有表单数据，并将其传递到后续的工作流节点中，供后续业务逻辑使用。

## 配置与使用步骤
以下是该节点的最小配置操作流程：
1. 进入FastGPT应用的工作流编辑页面，在左侧节点列表中找到表单输入节点并添加至画布；
2. 根据当前业务场景的需求，配置该节点需要收集的必填表单字段；
3. 将表单输入节点与后续需要使用该表单数据的业务节点进行连线，确保数据可以正常传递；
4. 保存当前工作流并发布，测试触发该节点的执行流程。当工作流执行至该节点时，对话将进入交互状态，用户填写完必填信息并点击提交后，工作流将自动继续执行后续节点。

## 节点核心作用
该节点的核心价值在于能够精准收集业务所需的用户信息，为后续工作流节点提供完整的输入数据。相较于通用的对话交互，表单输入节点可以明确指定需要收集的信息类型，避免用户提供无关内容，确保后续处理环节能够获取到必要的参数，支撑各类自定义业务逻辑的稳定执行。
