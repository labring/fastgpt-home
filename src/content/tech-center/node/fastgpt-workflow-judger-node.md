# FastGPT工作流判断器节点的功能、配置与适用场景

## 节点基本介绍与功能
判断器是FastGPT工作流中的专用逻辑节点，具备可重复添加、支持外部输入、可触发执行的特点。该节点的核心功能是对任意已定义变量进行IF逻辑判断：当变量满足预设条件时，执行预先绑定的IF分支流程；当变量不满足条件时，则执行ELSE分支流程。用户可根据需求增加更多判断条件与分支，整体逻辑与通用编程语言中的IF语句完全一致，例如可配置「知识库引用」变量的长度等于0时触发IF分支，否则执行ELSE分支。

## 配置与使用步骤
1. 在工作流编辑页面添加判断器节点，该节点支持重复添加至任意工作流环节；
2. 配置判断条件：在节点设置中选择需要校验的目标变量，设置匹配规则（如变量长度、数值对比、相等性判断等，具体规则需匹配变量类型）；
3. 绑定分支流程：为满足条件的场景绑定IF分支的后续工作流模块，为不满足条件的场景绑定ELSE分支的后续模块；
4. 保存节点配置并触发工作流执行，节点将根据变量实时结果执行对应分支。

## 适用场景与边界说明
该节点的典型适用场景包括两类：一是让大模型完成判断后输出固定内容，二是根据大模型的回复内容判断是否触发后续工作流模块。需要注意的节点边界包括：仅支持基于已预先定义的变量进行判断，无法直接调用大模型生成判断依据，如需基于大模型输出做判断，需先将大模型回复结果存入变量后再接入判断器；同时，节点的分支流程需正确绑定后续模块，否则会出现流程中断无法执行的问题。此外，多分支配置需遵循逻辑优先级，避免出现条件覆盖或冲突的情况。
