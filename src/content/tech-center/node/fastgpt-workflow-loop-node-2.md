# FastGPT工作流循环节点的使用方法与注意事项

## 核心功能与运行模式
循环节点用于在FastGPT工作流中重复执行子工作流，支持数组循环与条件循环两种模式。数组循环会依次遍历传入的数组，每轮输出当前元素与从0开始的当前下标；条件循环无需依赖数组，持续执行循环体直到触发【循环终止】节点，每轮输出从1开始的当前循环次数。循环执行出错时会保留前序轮次的日志，支持运行中交互节点，系统默认最大循环次数为100次，达到上限会自动停止。

## 参数与注意事项
输入参数需配置循环类型（可选数组循环array、条件循环conditional，默认数组循环），数组循环需指定要处理的数组数据，循环体为子流程且需以【循环开始】为起点。输出参数包含错误信息与自定义输出，自定义输出仅返回最后一轮迭代的值。需注意：循环节点内部不能嵌套其他循环或并行执行节点；条件循环必须包含至少一个【循环终止】节点，否则保存或执行时会报错；若需聚合所有轮次结果，需在循环体外声明全局变量数组，在循环体内用【变量更新】节点追加每轮结果。私有化部署可通过环境变量WORKFLOW_MAX_LOOP_TIMES调整最大循环次数，默认值为100。

## 快速配置示例
以条件循环实现AI文案润色达标为例，步骤如下：1. 将循环类型设置为条件循环；2. 配置循环体内流程：先通过【AI对话】节点优化文案，再通过【AI对话】节点评估文案分数，最后通过【判断器】判断分数是否达标；3. 达标时连线【指定回复】节点后接【循环终止】节点，未达标则直接进入下一轮；4. 在循环节点输出栏添加自定义输出final_text，绑定循环体内【AI对话（文案优化）】节点的回复内容。循环退出后，下游节点可通过final_text获取最终达标文案。
