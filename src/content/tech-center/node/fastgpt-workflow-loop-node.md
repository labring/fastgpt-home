# FastGPT循环节点的配置方法、运行规则与使用场景说明

## 节点概述与运行模式
循环节点用于在工作流中重复执行子工作流，支持数组循环与条件循环两种模式。数组循环依次遍历传入的数组，每轮循环开始时自动输出当前元素与当前下标（从0开始）；条件循环不依赖数组，持续执行循环体直到触发【循环终止】节点，每轮输出当前循环次数（从1开始）。循环出错时会保留此前轮次的日志与结果，支持运行中交互，流程暂停后可恢复。

## 参数说明
输入参数中，"循环类型"为必填项，默认值为数组循环，可选值为数组循环(array)或条件循环(conditional)。数组参数仅在数组循环模式下显示，用于传入批量处理的数据列表，通常来自上游节点的数组输出。循环体为必填项，是包含【循环开始】节点的子流程，内部必须至少包含一个【循环终止】节点，否则工作流保存或执行时会报错。输出参数包括错误信息（string类型，异常中断时返回）与自定义输出，用户可新增自定义输出并绑定内部节点变量，最终输出最后一轮迭代或中断退出时的值。

## 可执行配置示例
以条件循环实现AI文案润色达标为例，步骤如下：
1. 新建工作流并添加循环节点，将循环类型设置为条件循环；
2. 配置循环体：添加【AI对话】节点优化输入文案，添加第二个【AI对话】节点评估优化后的文案得分，添加【判断器】节点判断分数是否达标；
3. 达标分支连接【指定回复】节点与【循环终止】节点，不达标分支直接回到循环开始节点；
4. 在循环节点的输出栏添加自定义输出final_text，绑定循环体内第一个【AI对话】节点的回复内容；
5. 私有化部署时可通过环境变量WORKFLOW_MAX_LOOP_TIMES调整最大循环次数，默认值为100，防止死循环。
