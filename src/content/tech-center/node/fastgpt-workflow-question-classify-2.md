# 配置FastGPT工作流问题分类节点实现用户问题归类

# 功能与适用边界
问题分类节点是FastGPT工作流中的专用节点，用于将用户输入的问题进行分类，并基于分类结果执行后续不同操作。该节点支持重复添加，需接收外部输入且需手动完成配置，最终通过触发function_call模块实现分类判断。需要注意的是，在问题场景较为模糊的情况下，该节点的分类效果可能不明显，无法保证准确归类。

# 配置步骤
在工作流中添加问题分类节点后，依次配置以下参数：
- 系统提示词：用于补充说明各分类的定义，例如可填写"计费常见问题包括套餐价格、余额、积分消耗、续费、发票、退款等问题；当用户询问为什么扣费、如何充值、如何查看账单时，应归类为计费常见问题；当用户询问产品功能或打招呼时，不应归类为计费常见问题"，明确各分类的边界。
- 聊天记录：可选配置，用于引入上下文信息辅助完成分类。
- 用户问题：绑定工作流中传入的用户输入内容变量。
- 分类内容：填写需要使用的分类项，例如"打招呼、计费常见问题、其他问题"，系统会自动生成对应的function_call结构，要求返回值为指定枚举字段，如`abc`对应打招呼、`vvv`对应计费常见问题、`aaa`对应其他问题，且返回值必须为枚举列表中的一项，`type`字段为必填项。

# 使用注意事项
配置时需确保分类内容与系统提示词匹配，避免出现分类定义模糊的情况。若未明确系统提示词的分类规则，可能导致分类结果不符合预期。此外，该节点仅能基于预设的分类项完成归类，无法自动生成通用分类逻辑，且不支持无明确边界的模糊分类场景。同时，该节点依赖function_call模块，需确保当前工作流环境支持该模块的调用。
