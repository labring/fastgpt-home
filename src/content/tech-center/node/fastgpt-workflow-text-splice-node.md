# 配置FastGPT工作流的文本拼接节点实现自定义文本处理

## 功能与特点
文本拼接节点是FastGPT工作流中的文本加工模块，具备可重复添加、支持外部输入、可触发执行、需手动配置的特点。该节点的核心功能是对输入的文本进行固定加工处理，入参仅支持字符串和数字格式，且输入参数可以变量形式嵌入到文本编辑区域中。例如按照官方示例配置，可在所有输入内容前拼接"用户的问题是:"，完成格式统一的文本加工。

## 快速配置步骤
1. 进入FastGPT工作流编辑页面，在节点列表中找到并添加文本拼接节点；
2. 打开节点的配置面板，在文本编辑区域通过变量形式引用输入参数，例如输入`{{input}}`即可将输入内容作为变量替换项，若配置为"用户的问题是:{{input}}"，则会在输入内容前添加指定前缀；
3. 连接节点的输入与输出端口，确保上游模块传入的参数为字符串或数字格式，完成配置后即可触发节点执行。

## 使用边界与注意事项
该节点的使用存在明确边界：仅支持处理字符串和数字类型的输入，若传入数组、对象等非字符串数字类型的参数，会导致节点执行异常，无法生成预期的加工文本。其适用场景包括为任意模块输入自定义格式的文本，或是处理AI模块的系统提示词，完成格式统一的配置。如果需要处理结构化的复杂数据，或是进行多输入的复杂文本组合，该节点无法满足需求，需结合其他工作流节点完成对应操作。
