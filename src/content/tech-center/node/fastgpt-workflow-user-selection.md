# 介绍FastGPT用户选择节点的功能、配置与使用边界

### 核心功能与特点
「用户选择」节点是FastGPT工作流中的用户交互类节点，具备可重复添加、触发执行的特点。当该节点被触发时，当前对话会进入“交互状态”，系统会自动记录当前工作流的运行状态，直至用户完成交互操作后，才会继续向下执行后续工作流流程。例如在典型场景中，触发该节点后对话框会暂时隐藏，待用户做出明确选择后，节点会根据用户的选择执行对应分支（如执行“是”的分支）。该节点的核心作用是为工作流引入用户抉择环节，让流程可以根据用户的反馈调整执行路径。

### 快速配置步骤
1. 在FastGPT工作流编辑器的节点列表中，找到并添加「用户选择」节点；
2. 配置节点的交互提示文本，即向用户提出的需要做出抉择的具体问题；
3. 为节点配置分支逻辑，根据用户的不同选择设置对应的工作流执行路径（如用户选择“是”时触发指定的后续节点）；
4. 将节点与前后工作流节点正确连接，完成整体流程的编排。

### 使用边界与注意事项
该节点仅适用于需要用户做出明确选择的交互场景，无法支持开放式的用户输入需求，此类场景可使用表单输入节点。当工作流流程可自动完成、无需用户介入时，不应使用该节点，避免不必要的交互打断流程运行。此外，触发该节点后，工作流会进入暂停状态，需确保对话上下文的状态保存正常，否则可能出现流程恢复异常的问题。同时，该节点仅在对话模式下生效，非对话类工作流场景无法触发该节点的交互逻辑。
