# 讲解FastGPT工作流表单输入节点的功能与使用方法

### 功能与定位
表单输入节点是FastGPT工作流中的用户交互类节点，支持重复添加，当触发该节点时，对话会进入“交互”状态，系统会记录当前工作流的执行状态，暂停流程直至用户完成交互后，再继续向下执行工作流。当触发表单输入节点时，对话框会隐藏，对话进入交互等待状态；用户需要填写节点配置的必填信息，点击提交后，节点收集到的表单信息会传递至后续工作流节点，供其调用。该节点的核心作用是精准收集业务所需的用户信息，再基于收集到的信息开展后续流程操作，满足需要用户主动提供信息的场景。

### 配置与使用步骤
1. 在FastGPT工作流编辑器中添加表单输入节点；
2. 配置该节点需要收集的字段及必填项，明确需要用户填写的内容；
3. 当工作流执行至该节点时，对话自动进入交互状态，对话框隐藏，等待用户操作；
4. 用户完成必填信息填写并点击提交后，节点将收集到的表单信息传递至后续工作流节点，流程继续执行。

### 使用边界与注意事项
该节点仅适用于需要用户主动提供信息的场景，无法自动完成信息收集，也不能替代其他无需用户交互的节点的功能。使用时需注意，若未配置必填项，可能导致流程无法正常推进或后续节点无法获取有效信息。在工作流需要完全自动执行、无需用户介入的场景下，不应使用该节点，否则流程会因等待用户交互而停滞。此外，该节点会记录工作流状态，仅在用户提交表单后才会恢复流程执行，因此在对流程执行效率有严格要求的场景下需谨慎使用。
