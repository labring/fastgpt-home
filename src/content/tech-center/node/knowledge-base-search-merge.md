# 合并多个知识库搜索结果并按RRF规则重排序与令牌过滤

### 节点核心功能
知识库搜索引用合并节点是FastGPT工作流中的专用整合节点，用于解决多知识库检索结果无法直接输入AI对话节点的问题。当工作流中调用多个知识库搜索节点时，AI对话节点仅支持接收单份知识库引用内容，此时可通过该节点将多个检索结果合并为单一输出，并通过RRF算法根据各检索结果的排名情况进行重新排序，同时支持配置最大令牌数过滤规则，筛选符合长度要求的检索内容。

### 快速配置步骤
1. 进入FastGPT工作流编辑页面，从节点库中拖拽「知识库搜索引用合并」节点至画布；
2. 完成多个独立知识库搜索节点的配置，确保每个搜索节点已绑定目标知识库集合并设置检索参数；
3. 将每个知识库搜索节点的输出端口，依次连接至合并节点的输入端口；
4. 在合并节点的配置面板中，配置最大令牌数过滤参数，限定合并后输出内容的总令牌上限；
5. 将合并节点的输出端口连接至后续的AI对话节点或其他业务处理节点，完成链路配置。

### 典型使用场景
该节点适用于需要同时检索多个知识库集合，并将所有检索结果整合后统一交由AI处理的工作流。例如，在搭配问题分类节点使用时，可先通过分类节点识别用户问题的所属类型，再针对不同类型的问题调用对应知识库进行检索，此时无需为每个知识库检索分支单独配置AI对话节点，仅需通过该合并节点整合所有检索结果，再输入至单一AI对话节点即可完成统一回答，有效简化工作流结构。
