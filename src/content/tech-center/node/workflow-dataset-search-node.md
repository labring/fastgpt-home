# FastGPT工作流知识库搜索节点的配置与使用说明

FastGPT工作流中的知识库搜索节点是实现向量搜索知识库的核心模块。该节点支持重复添加，在复杂工作流编排时可避免线路混乱，优化界面美观性，同时支持外部输入与静态配置，可被触发执行，帮助用户在工作流中快速调用知识库内容。

## 核心参数与输入输出规则
节点的输入包含两个配置项：一是关联的知识库，可选择一个或多个使用相同向量模型的知识库用于向量搜索；二是搜索参数，可点击查看详细参数介绍进行自定义。输出项为引用内容，以数组格式返回，数组长度可为0，即使未搜索到匹配的知识库内容，该节点的输出链路也会正常走通，不会中断后续流程。需注意，必须确保所有关联的知识库使用相同的向量模型，否则可能引发搜索异常。

## 快速配置步骤
1. 进入FastGPT工作流编辑页面，添加知识库搜索节点；
2. 在节点的输入配置中，选择一个或多个符合相同向量模型要求的知识库；
3. 点击搜索参数的查看入口，根据需求配置相关参数；
4. 将该节点的引用内容输出链路对接至后续需要使用知识库内容的节点。

该节点的使用存在明确边界，仅用于向量搜索知识库内容，需搭配其他工作流节点完成后续内容处理。若后续节点需要处理引用内容，需提前兼容空数组的情况，避免因无搜索结果导致流程异常。
