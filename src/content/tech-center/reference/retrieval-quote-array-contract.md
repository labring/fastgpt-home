# FastGPT检索参数与空引用输出基准

搜索模式、引用上限和空引用输出分别影响检索路径、内容量与后续承接。FastGPT v4.17.2官方文档对这些条目给出了取值形式和生效条件。本表将明确记载的行为作为配置复核基准，不把范围中任意一个值写成项目推荐值，也不将文档说明当作准确率或性能实测。

## 参数与输出基准

| 基准项 | 文档明确的取值或形式 | 生效条件与核对点 | 来源小节 |
| --- | --- | --- | --- |
| 搜索模式 | 语义、全文、混合 | 按查询类型比较；三种模式不是同一召回路径 | dataset_engine / 搜索模式 |
| 最低相关度 | 范围0–1；不是统一默认值 | 只在语义检索或使用结果重排时生效 | dataset_engine / 最低相关度 |
| 引用上限 | 单位token | 上限限制引用内容量，不能用片段条数替代 | dataset_engine / 引用上限 |
| 问题优化 | 指代消除、问题扩展 | 利用已提供的上下文；核对优化后的主体 | dataset_engine / 问题优化 |
| 关联知识库 | 一个或多个 | 多个知识库须使用相同向量模型 | dataset_search / 关联的知识库 |
| 引用内容输出 | 数组；长度允许为0 | 空引用输出链路仍会走通，后续行为另行设计 | dataset_search / 引用内容输出 |
| 混合召回融合 | RRF | 融合向量与全文搜索结果，不按单一路径得分理解最终排序 | dataset_engine / 混合检索 |

## 最低相关度与引用上限分别判断

最低相关度的范围为0–1，其生效条件限定在语义检索或使用结果重排。范围本身不提供适合当前知识库的阈值，调整前需用实际问题区分相关与无关材料。引用上限按token限制内容量；返回片段的数量与长条件是否完整是不同问题，复核时要回查具体引用内容及回答输入。

## 空数组的后续路径需要设计

搜索节点可以输出空引用数组，相关链路仍会继续。检索没有证据时，任务可能缺少查询主体、缺少来源文件，也可能已有内容未被召回。补问、补充资料及责任人处理各自需要明确的输入与接收路径，不能因链路继续就生成缺乏依据的业务结论。

## 保持同题对照

复核配置时保留完整问题、所选知识库和对应原文，分别检查检索输出与回答实际输入。资料变化和配置变化分开比较，才能解释是哪项条件导致返回不同。相关度不能认定文件现行有效，取值范围也不能替代资料访问授权。
