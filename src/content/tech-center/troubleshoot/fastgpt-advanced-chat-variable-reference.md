# FastGPT高级编排节点引用历史对话与用户问题的方法

## 现象
在FastGPT v4.8.3公有云版本中创建高级编排，包含4个AI对话节点时，第四个节点需要引用流程初始的用户问题与前3个AI节点的输出结果。使用下拉菜单配置变量时，仅能选择单个变量；手工输入变量时，无法直接调用上述目标变量，仅能通过创建全局变量实现需求。

## 可能原因
未明确高级编排节点内内置变量的调用规则，且下拉菜单仅支持单个变量选择，导致无法直接引用流程内的历史对话与初始用户输入。

## 排查步骤
1. 进入FastGPT v4.8.3公有云版本的高级编排编辑页面。
2. 打开目标AI对话节点的变量引用配置区域。
3. 查看下拉菜单的可选变量范围，确认仅能选择单个变量。
4. 尝试手工输入变量调用格式，确认无法直接获取流程内的初始用户问题与历史AI输出。

## 解决与验证
目前可行的实现方式为创建全局变量，分别存储初始用户问题与各AI节点的输出内容，再在后续节点中调用该全局变量。直接调用内置变量的具体方法未在该issue中明确说明，需按实际环境确认。
