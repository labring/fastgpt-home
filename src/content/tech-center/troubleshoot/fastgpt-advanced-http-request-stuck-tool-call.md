# 解决FastGPT高级编排HTTP请求仅停留在工具调用的问题

## 现象
在FastGPT高级编排场景中配置自定义HTTP请求接口时，按照官方示例完成配置后，流程调试仅停留在工具调用环节，未触发后续的HTTP请求执行步骤，附带工具调用环节界面与配置界面的截图。

## 可能原因
暂未明确具体触发原因，需结合实际配置与运行环境确认。可能的关联方向包括HTTP请求配置参数不符合要求、目标接口的访问权限限制、编排流程节点的连接逻辑异常。

## 排查步骤
1. 核对自定义HTTP接口的配置内容，与官方提供的示例格式进行比对，确认参数填写正确。
2. 检查目标HTTP接口的访问权限，确认当前环境可正常访问该接口。
3. 确认编排流程中工具调用节点与后续HTTP请求节点的连接关系正确。
4. 检查目标HTTP接口的响应格式，确认符合编排流程的解析要求。
5. 查看运行过程中的相关提示信息，排查异常情况。

## 解决与验证
根据排查出的具体问题进行针对性修复，例如修正配置参数、调整接口访问权限、优化流程节点连接逻辑。修复完成后重新运行编排流程，确认流程不再仅停留在工具调用环节，可正常触发并完成HTTP请求的调用与结果处理。
