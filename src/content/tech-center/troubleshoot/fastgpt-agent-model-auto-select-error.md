# 解决FastGPT Agent编辑页AI模型自动选中异常问题

## 现象
在FastGPT v4.14.10.1公有云版本中，打开Agent编辑页时，AI模型会自动选中非已发布版本的模型，多次刷新页面后选中模型会发生异常变化。用户需要手动点击页面中的"历史已发布版本"选项，才能恢复显示正确的已发布模型与对应提示词。预期打开编辑页时应自动加载已发布版本，正确展示选中的AI模型和提示词。

## 可能原因
目前未明确该问题的根因，推测与Agent编辑页加载时的模型缓存逻辑、已发布版本的状态同步机制异常有关，具体根因需按实际环境确认。

## 排查步骤
1.  确认当前使用的FastGPT版本为v4.14.10.1公有云版本。
2.  打开目标Agent的编辑页面，记录首次加载时默认选中的AI模型与对应提示词。
3.  多次刷新Agent编辑页，观察右侧AI模型选中项的变化情况。
4.  点击页面中的"历史已发布版本"选项，查看是否能切换回正确的已发布模型。
5.  确认已绑定的AI模型密钥可正常使用（该问题中用户已验证自身key正常）。

## 解决与验证
临时恢复方案：可手动点击"历史已发布版本"选项，切换到正确的已发布AI模型。长期修复需等待官方后续版本修复该同步逻辑。验证方式：重新打开Agent编辑页，确认首次加载时自动显示已发布版本的正确选中模型与提示词，多次刷新页面后选中状态不再出现异常变化。
