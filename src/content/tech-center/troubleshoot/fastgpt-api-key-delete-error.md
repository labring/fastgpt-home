# 解决FastGPT API秘钥管理删除指定秘钥时误删其他秘钥的问题

## 现象
在FastGPT私有部署4.7版本，以及线上4.8版本的API秘钥管理页面中，执行删除任意指定API秘钥的操作时，实际被删除的秘钥均为列表展示的最后一条秘钥。该问题可通过页面操作直接复现，无额外触发条件限制。

## 可能原因
该问题未获得官方明确根因说明，需结合实际部署环境与代码逻辑排查。大概率存在两类潜在问题：一是前端页面中列表项与删除操作的索引绑定逻辑错误，导致提交的删除目标始终为最后一条；二是后端接口接收的删除请求参数传递错误，未正确获取操作指定的删除目标。

## 排查步骤
1. 确认当前FastGPT的部署版本为4.7或4.8。
2. 登录FastGPT系统，进入API秘钥管理页面，记录各秘钥的展示顺序与对应标识信息。
3. 选择任意非列表末尾的秘钥，执行删除操作，记录实际被删除的秘钥是否为列表最后一条。
4. 打开浏览器开发者工具，查看删除操作发起的网络请求，核对请求中携带的删除目标参数与所选秘钥是否一致。
5. 核对后端接口的代码逻辑，确认接口接收的删除目标参数是否与前端提交的参数匹配。

## 解决与验证
若排查发现为前端索引绑定错误，需修正列表项与删除请求的索引绑定逻辑，确保每次删除操作提交的目标索引与所选秘钥对应一致。若排查发现为后端接口参数传递错误，需修正接口接收参数的获取逻辑，确保正确读取前端提交的删除目标标识。验证方式为重新创建测试API秘钥，按顺序添加至秘钥列表，执行删除指定秘钥的操作，确认实际删除的秘钥与操作目标完全一致。
