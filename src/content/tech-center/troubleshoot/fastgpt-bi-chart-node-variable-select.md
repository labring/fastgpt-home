# 解决FastGPT BI图表插件无法选择代码运行节点返回变量的问题

## 现象
使用FastGPT私有部署版本4.8.11的BI图表功能，连接代码运行节点后，无法选择该代码运行节点返回的变量，操作界面未展示对应变量选项。

## 可能原因
暂无公开明确的已知原因，需结合实际部署环境与配置细节进行排查。

## 排查步骤
1. 确认当前使用的FastGPT私有部署版本为4.8.11，确保版本配置一致。
2. 确认已配置并可正常使用的密钥，且密钥权限覆盖BI图表功能与代码运行节点的调用需求。
3. 重新梳理BI图表插件与代码运行节点的连接流程，检查节点间变量传递的配置是否正确。
4. 查看系统运行日志，提取与BI图表插件、代码运行节点相关的异常信息。

## 解决与验证
暂无公开的通用解决方案，需根据排查步骤中获取的实际异常点进行针对性处理。验证方式为重新配置节点关联关系后，尝试选择代码运行节点返回的变量，确认可正常选中并使用。
