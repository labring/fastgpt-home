# FastGPT常见问题排查及MongoDB版本升级注意事项

## 现象
用户在使用FastGPT过程中遇到以下问题：1. 不清楚演示模式的功能意义；2. 无法找到定义导出过滤敏感信息的位置；3. 询问原版FastGPT是否支持门户页单个应用运行可见度配置及设置位置；4. 创建MCP工具时，除“自定义”外的鉴权类型总会恢复为“无”；5. 将MongoDB从5.0.18升级到5.0.32时，镜像更新说明未提及需要更改Mongo镜像版本。

## 可能原因
结合问题场景分析可能的原因：1. 演示模式的功能说明未在显眼位置展示；2. 敏感信息过滤的配置入口未被用户熟悉；3. 门户应用可见度的配置位置未在官方文档中明确说明；4. MCP工具鉴权类型的保存逻辑存在异常；5. MongoDB镜像升级时未同步更新部署配置中的镜像版本参数。

## 排查步骤
1.  针对演示模式：查阅FastGPT内置说明或官方文档确认其功能（需按实际环境确认）；
2.  针对敏感信息过滤：进入导出配置页面，查找带有“敏感信息”“过滤”关键词的配置项（需按实际环境确认入口位置）；
3.  针对门户应用可见度：登录原版FastGPT的门户管理后台，查找应用配置中的可见性相关设置（需按实际环境确认）；
4.  针对MCP工具鉴权：创建MCP工具时，先选择非“自定义”的鉴权类型，保存后再次查看配置是否恢复为“无”；
5.  针对MongoDB升级：检查部署配置文件中MongoDB镜像的版本参数，对比官方镜像更新说明确认是否需要同步修改。

## 解决与验证
1.  演示模式：可通过官方文档或内置说明确认其用于演示场景的功能（需按实际环境确认）；
2.  敏感信息过滤：在找到的配置入口中完成敏感信息规则定义后，导出内容时即可自动完成过滤；
3.  门户应用可见度：若原版FastGPT支持该配置，可在门户管理的应用配置中找到对应可见度设置项（需按实际环境确认）；
4.  MCP工具鉴权：若出现鉴权类型恢复异常，可将问题反馈至官方仓库排查保存逻辑问题；
5.  MongoDB升级：需在部署配置中同步将Mongo镜像版本修改为5.0.32，重启服务后验证数据库连接正常。
