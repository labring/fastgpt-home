# 调整FastGPT联网查询功能图标至文本输入框内的相关配置

## 现象
当前FastGPT的联网查询功能需通过独立位置的图标开启，未将联网查询图标集成至文本输入框区域。用户希望调整布局，将联网查询图标内置在文本输入框内，实现直接在输入框区域启用联网查询功能。

## 可能原因
现有FastGPT版本的UI布局未将联网查询开启图标集成至文本输入框区域，需通过自定义配置调整组件布局位置。具体配置逻辑需按实际环境确认，未找到公开的明确配置说明。

## 排查步骤
1. 查看当前FastGPT界面中联网查询功能的图标所在位置，确认其与文本输入框的相对布局关系。
2. 查找FastGPT中用于调整UI组件布局的配置入口或参数文件。
3. 核对文本输入框区域可集成的功能组件范围，确认联网查询图标是否可被添加至该区域。
4. 确认是否存在已有的布局配置模板或示例，用于参考调整组件位置。

## 解决与验证
解决方式需通过调整FastGPT的UI布局配置，将联网查询功能的图标集成至文本输入框区域。具体操作需参考官方提供的UI自定义文档，将联网查询图标组件的挂载位置修改为文本输入框内。验证时，打开FastGPT的对话界面，可在文本输入框区域直接看到联网查询图标，点击图标即可正常启用联网查询功能，无需再点击独立位置的图标。
