# 解决FastGPT知识库CSV导入多组自定义索引的问题

## 现象
FastGPT知识库的CSV导入功能仅默认读取前两列数据，无法将第三列及以后的列内容作为多组自定义索引，无法为单段文本配置多个关联问题以提升搜索权重。

## 可能原因
知识库CSV导入的解析逻辑仅预设读取前两列，未开放第三列及后续列作为索引问题的配置入口，未支持多组索引的批量导入操作。

## 排查步骤
1. 准备CSV文件，确认第三列及后续列存储需要关联到对应文本的索引问题。
2. 进入FastGPT知识库导入页面，上传该CSV文件并执行导入操作。
3. 查看导入后的知识库内容，确认仅前两列被识别为文本内容与基础索引问题。
4. 确认当前使用的FastGPT版本是否为最新正式版。

## 解决与验证
目前现有版本未开放CSV导入多组自定义索引的功能，需等待后续版本更新支持该特性。验证方式：待版本更新后，导入包含多列索引问题的CSV文件，确认第三列及以后的内容被识别为额外索引问题，且与对应文本正确关联。
