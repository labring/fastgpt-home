# 解决FastGPT自定义插件引用后代码运行输入报错的问题

## 现象
用户使用FastGPT官网版本https://cloud.tryfastgpt.ai，系统为macOS 15.0 Beta，浏览器为Chrome 131.0.6778.140。创建自定义插件后，在其他工作流中引用该插件并衔接代码运行节点时，点击输入项出现报错。同时自定义插件自身输出正常，接指定回复流程可成功执行。

## 可能原因
当前无明确通用已知原因，需结合具体运行环境、插件配置细节、工作流衔接逻辑进行排查确认。

## 排查步骤
1. 核对当前使用的FastGPT版本、浏览器版本与系统版本，确认与问题发生时的环境一致。
2. 检查自定义插件的配置参数，确认无缺失或格式错误。
3. 单独运行自定义插件，验证插件自身输出是否正常，确认插件功能无误。
4. 检查工作流中插件节点与代码运行节点的衔接配置，确认参数传递逻辑符合要求。

## 解决与验证
1. 完成上述排查步骤后，重新配置工作流中插件与代码运行节点的衔接关系。
2. 点击代码运行节点的输入项，验证报错是否消除。
3. 运行完整工作流，确认插件输出可正常传递至代码运行节点并执行。
若仍存在报错，需结合具体报错文本与环境细节进一步定位问题。
