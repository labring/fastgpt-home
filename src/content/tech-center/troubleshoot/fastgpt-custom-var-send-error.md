# 解决FastGPT私有部署4.8.13版自定义全局变量导致的消息发送异常

## 现象
使用FastGPT私有部署4.8.13版本时，配置自定义全局变量后无法正常发送消息。该异常在保留自定义全局变量配置时持续出现，取消所有自定义全局变量的配置后，消息发送功能可恢复正常运行。

## 可能原因
当前仅明确该异常与自定义全局变量的配置存在关联，具体底层异常原因未在当前反馈中披露，需结合部署日志、配置详情等实际环境信息进一步确认。

## 排查步骤
1.  登录FastGPT私有部署的管理后台，进入全局变量配置页面，查看当前已配置的自定义全局变量列表及具体内容。
2.  临时移除所有自定义全局变量的配置，保存修改后重新进入对话页面测试消息发送功能。
3.  若移除配置后消息发送功能恢复正常，则确认该异常由自定义全局变量配置引发。
4.  如需定位具体异常的配置项，可逐步恢复单个自定义全局变量的配置，每恢复一项后测试一次消息发送功能，直至定位到引发异常的配置项。

## 解决与验证
解决该异常的核心方式为调整自定义全局变量的配置。可先移除所有自定义全局变量，确认功能恢复后，再逐步添加并验证单个配置项，保留可正常运行的配置，移除或修正引发异常的配置项。验证方式为重新配置自定义全局变量（仅保留正常的配置项），测试消息发送功能是否可正常运行。若测试过程中再次出现异常，则需重新排查对应配置项的内容与格式。
