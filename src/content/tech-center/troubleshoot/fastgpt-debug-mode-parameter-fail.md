# 解决FastGPT调试模式下参数无法传递的问题

## 现象
在FastGPT调试模式中，配置的参数无法正常传递，该问题已通过截图记录，用户未提及具体报错文本内容。

## 可能原因
当前无明确预设排查方向，需结合实际运行环境、配置细节确认具体触发原因。

## 排查步骤
1. 确认当前使用的FastGPT版本类型，区分公有云或私有部署版本，对应查找调试模式的配置位置。
2. 核对调试模式下配置的参数内容，确认参数名称与系统要求的格式匹配。
3. 查看系统运行日志，提取与参数传递相关的异常或报错信息。
4. 确认当前使用的密钥可正常调用相关服务，排除密钥异常导致的参数传递问题。

## 解决与验证
针对排查步骤中定位的具体问题进行修复，例如修正参数格式、调整调试模式的配置项，或补充正确的密钥配置。修复完成后，重新进入调试模式，传入预设参数，确认参数可正常传递并生效。
