# 解决FastGPT调试中无法查看输出与JSON格式的问题

## 现象
调试过程无法随时查看输出结果；调试模式下无法查看输出的原始数据（raw-data），无法匹配变量名与接口；无法获取HTTP请求的输入数据，难以对接HTTP接口；知识库搜索结果的变量引用不明确，无法抽取指定内容；原4.7版本生效的Python处理函数无法正常获取输入数据；无法直接查看问题的JSON格式内容用于加工处理。

## 可能原因
1. 未选择对应节点的输出变量，导致无法获取有效数据；
2. 未按当前版本的规范引用知识库搜索结果的变量，导致数据无法正常传递；
3. 未正确查看调试输出的原始数据与JSON格式内容；
4. 沿用旧版操作逻辑，未适配当前版本的节点变量引用规则。

## 排查步骤
1. 确认已选择对应节点的输出变量，按需获取所需的内容。
2. 检查Python处理函数的关联节点，确认是否正确引用节点输出的数据。
3. 查看调试模式下的输出内容，确认是否展示原始数据（raw-data）。
4. 核对HTTP对接逻辑，确认是否正确引用输出的JSON格式数据。
5. 调整操作逻辑，适配当前版本的节点变量引用规则，参考4.7版本的操作方式。

## 解决与验证
1. 直接选择对应节点的输出变量，按需获取所需的内容。
2. 按照4.7版本的操作逻辑调整当前版本的Python处理函数，正确引用知识库搜索结果的变量。
3. 调试模式下可直接查看输出内容，如需查看JSON格式数据，可直接获取输出的原始JSON内容用于HTTP对接或Python加工。
4. 验证：完成上述操作后，可正常查看输出结果、原始数据及JSON格式内容，Python处理函数可正常获取输入数据，HTTP对接逻辑可正常使用。
