# 解决FastGPT流程编排中获取当前用户信息的需求

## 现象
在FastGPT流程编排场景中，无法直接获取当前操作用户的信息（如用户名），无法满足发送通知邮件、抄送当前用户的业务需求。

## 可能原因
FastGPT原生流程编排未内置直接获取当前用户信息的功能或系统变量，无法直接调用相关用户数据，需通过自定义方式实现需求。

## 排查步骤
1. 确认业务场景需要的用户信息类型，如用户名、邮箱等。
2. 检查FastGPT流程编排的内置变量列表，确认无当前用户相关的内置参数。
3. 评估不同解决方案的适配性，选择符合业务需求的实现方式。

## 解决与验证
提供三种可行实现方式：
方案一：静态配置用户信息
1. 进入FastGPT流程编排的全局变量配置页面。
2. 添加用户名、邮箱等用户信息变量，由用户在使用前手动输入。
3. 在流程节点中调用该全局变量，完成后续通知逻辑。
方案二：前端对接实现动态获取
1. 将FastGPT作为中台业务，由前端页面传递当前用户信息至FastGPT流程。
2. 在流程编排中接收前端传递的用户信息，完成业务逻辑。
方案三：流程节点组合实现
1. 在流程中添加问题分类节点，配置AI对话功能，指定输出格式为"用户信息：\n邮件内容："。
2. 配置手动输入用户问题的节点，获取用户输入内容。
3. 添加文本提取节点，从AI对话输出中提取用户信息。
4. 连接HTTP请求节点，使用提取的用户信息完成通知发送。
完成配置后，触发流程即可验证用户信息可正常被调用并完成对应业务场景。
