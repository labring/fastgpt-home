# 针对FastGPT GitHub提交的issue信息不完整的排查与处理方法

## 现象
用户提交的FastGPT相关GitHub issue仅完成例行检查项的部分勾选，未填写问题描述、复现步骤、预期结果等核心内容，上传的截图未正常加载显示，版本信息也未按要求填写。此类issue无法为项目维护者提供足够的问题定位依据，影响问题的跟进与解决效率，不符合项目issue提交的规范要求。

## 可能原因
提交issue时未按照模板要求填写完整的必填内容；图片上传过程中出现异常，导致截图未正常加载；未按模板填写版本、密钥等相关配置信息，导致关键信息缺失。这些原因都会导致issue的有效信息不足，无法支撑问题的排查与解决。

## 排查步骤
1. 核对GitHub issue模板的必填项，确认是否遗漏问题描述、复现步骤、日志截图、版本信息等内容；
2. 检查issue中上传的图片资源，确认是否完成加载，排查图片上传异常的原因；
3. 确认是否按要求填写密钥、版本等相关信息，确保信息完整；
4. 梳理问题的具体表现，补充可复现的操作步骤，便于维护者定位问题。

## 解决与验证
1. 补充填写issue的问题描述、复现步骤、预期结果等核心内容，明确问题的具体表现；
2. 重新上传缺失的截图并确认加载正常，确保图片资源可正常查看；
3. 按模板完善版本、密钥等相关信息，确保所有必填项都已填写；
4. 提交完整的issue信息，确认所有内容均已正确填写且加载正常，此时维护者可基于完整信息快速定位并解决问题。
