# 解决FastGPT私有部署版HTTP模块外部参数不识别问题

## 现象
使用FastGPT私有部署版本的HTTP模块时，请求路径填写外部参数输入的参数无法被识别，仅全局变量可正常使用。该问题的复现场景配有相关截图，但未提供具体参数配置细节。

## 可能原因
当前未明确该问题的具体根因，仅能确认异常表现为外部参数无法被识别，仅全局变量可正常使用，相关信息需结合实际部署环境与配置细节进一步确认。

## 排查步骤
1. 确认当前使用的FastGPT为私有部署版本。
2. 进入HTTP模块的配置页面，查看请求路径中配置的参数类型。
3. 测试仅使用全局变量配置请求路径，确认是否可正常发起请求并完成调用。
4. 对比测试使用外部参数输入的参数配置请求路径的场景，记录请求失败的具体表现。

## 解决与验证
目前暂无公开的通用解决方法，若需解决该问题，需结合实际部署环境与配置细节进一步排查。验证方式为：在HTTP模块请求路径中配置外部参数输入的参数，发起请求确认参数可被正常识别，且请求可正常完成。
