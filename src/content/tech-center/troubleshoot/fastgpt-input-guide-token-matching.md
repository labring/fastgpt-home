# 解决FastGPT输入引导内容无法分词匹配用户输入的问题

## 现象
设置输入引导内容后，用户输入问题时筛选指导内容无法实现分词匹配。例如输入指导内容为【查询北京今天天气！】，用户输入【北京天气】无法匹配到该指引。

## 可能原因
需按实际环境确认匹配逻辑的实现细节，当前已知该问题表现为输入引导匹配未采用分词识别机制。

## 排查步骤
1. 确认输入引导内容已正确添加并保存至应用中。
2. 复现问题场景，记录用户输入内容与对应的输入引导内容。
3. 核对用户输入片段与输入引导内容的重叠关键词，确认匹配场景类型。
4. 需按实际环境查看FastGPT的输入引导相关配置或源码逻辑。

## 解决与验证
将输入引导的匹配规则调整为分词匹配模式。验证时，输入包含引导内容关键词的片段，确认可匹配到对应引导内容。例如输入【北京天气】，可匹配到【查询北京今天天气！】的输入引导。
