# 解决FastGPT GitHub issue提交信息缺失的问题

## 现象
提交FastGPT的GitHub issue时，仅完成例行检查相关勾选与部署版本选择，未填写具体的问题描述、复现步骤、预期结果、相关说明及截图等核心信息，仅保留模板的占位内容，未提供任何可用于定位和处理问题的有效细节，属于不符合issue提交规范的情况。

## 可能原因
用户未按照issue模板的要求填写必要的问题相关内容，仅完成前置的合规性检查步骤，未意识到需要提供具体的问题信息以协助维护者开展排查工作，导致issue无法被有效跟进。此类情况通常源于用户未仔细阅读issue模板的填写说明，仅完成了例行的检查确认。

## 排查步骤
1. 打开已提交的FastGPT GitHub issue页面，查看主体内容区域，确认各字段的填写状态；
2. 对照模板的标准字段，逐一检查问题描述、复现步骤、预期结果、相关说明及截图等字段是否已填写有效内容，避免仅保留占位文本；
3. 确认是否存在因语言设置导致的内容未正确显示或识别的情况，例如自动翻译未正确加载的问题；
4. 核对自身是否已完成项目README与文档的查阅，以及密钥的可用性检查，避免提交重复或无需排查的问题。

## 解决与验证
按照模板要求补充所有缺失的有效信息，确保每个字段都包含与问题相关的具体内容，例如问题发生时的具体表现、可复现的操作步骤、期望的正常结果以及相关的截图等。完成补充后，可确认issue内容完整，能够为维护者提供足够的排查依据，进而推动问题的快速处理。同时，可提前确认自身使用的密钥是否正常，以及是否已查阅过项目README与文档，避免重复提交已解决的问题。
