# 解决FastGPT判断器与流程控制异常及自动保存问题

## 现象
判断器输入文本重复且自动打断；无法基于判断器结果进行分支选定，其他分支部件莫名运行；变量需手动选取且无法重复使用；自动保存功能异常，测试过程中出现报错导致数据丢失；4.8版本歧义多于4.7版本，复杂逻辑流程控制难度提升。

## 可能原因
版本升级后存在自动适配转换问题；现有逻辑控制仅支持if else类判断，不足以支撑复杂流程；节点连接配置未符合当前版本的设计要求。

## 排查步骤
1. 确认当前使用的FastGPT版本，对比4.7与4.8版本的功能差异；
2. 检查判断器节点的连接关系，梳理分支逻辑是否符合设计预期；
3. 检查变量配置项，确认是否存在手动选取且限制重复使用的情况；
4. 测试自动保存功能，记录出现的报错文本。

## 解决与验证
1. 若使用4.8版本出现异常，可选择回退至4.7版本使用；
2. 针对复杂流程控制，保留触发器节点以补充逻辑控制能力；
3. 对于超出基础判断逻辑的复杂业务，可通过自定义API辅助实现；
4. 若遇到执行不符合预期的情况，需明确描述具体异常场景并反馈。
