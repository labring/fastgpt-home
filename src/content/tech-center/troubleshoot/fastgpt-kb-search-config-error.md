# 解决FastGPT知识库搜索配置结果重排无效与最低相关度隐藏问题

## 现象
使用FastGPT 4.6.9私有部署版本时，知识库搜索配置模块出现两处异常：
1.  结果重排的勾选状态无法正常保存，每次进入配置界面时该选项均未勾选。
2.  当检索模式为混合检索时，搜索过滤中的最低相关度配置项会被隐藏；当检索模式切换为语义检索时，该配置项可正常显示。
用户复现场景包括：已配置混合检索、最低相关度0.4、结果重排勾选的workflow，进入配置界面后重排勾选消失且最低相关度隐藏；手动勾选重排保存后再次进入，异常仍会复现；切换为语义检索并勾选重排保存后，再次进入配置界面时重排勾选仍未显示，但最低相关度配置项正常展示。

## 可能原因
该问题未在官方公开文档中明确标注根因，结合复现场景推测，可能与混合检索模式下的配置参数过滤逻辑、结果重排状态的保存与加载逻辑存在异常有关，具体需结合部署环境的代码逻辑进一步排查。

## 排查步骤
1.  确认当前使用的FastGPT版本为4.6.9私有部署版本，记录当前workflow的知识库搜索配置参数，包括检索模式、最低相关度数值、结果重排勾选状态。
2.  进入知识库搜索配置界面，分别切换语义检索和混合检索模式，测试结果重排勾选状态的保存情况与最低相关度配置项的显示状态，记录不同模式下的异常表现。
3.  检查workflow的配置存储数据，确认结果重排勾选参数与最低相关度参数是否被正确存储与读取。
4.  查看部署服务的运行日志，排查配置保存、加载过程中是否存在参数丢失或逻辑过滤异常的情况。

## 解决与验证
目前暂无官方明确的临时解决方法，可尝试以下操作缓解异常影响：
1.  若需使用混合检索模式，可先将检索模式切换为语义检索，完成结果重排与最低相关度配置后保存，再切换回混合检索模式。
2.  若最低相关度配置项隐藏，可尝试切换检索模式后再切回，查看配置项是否恢复显示。
该问题的最终解决需等待官方后续版本修复，或结合部署代码对混合检索模式下的配置过滤逻辑进行调整。
