# FastGPT知识库单个文件生成摘要与标签的实现方法

## 现象
用户需求为对FastGPT知识库中的每个文件生成摘要、为单个文档打上标签，同时希望在预览源文本时自动生成文档的概览、关键字等分析结果。直接通过全文提问提取摘要会消耗较多token，且效果不一定理想。

## 可能原因
未通过提示词配置实现针对单个文件的摘要与标签生成；默认的问答拆分模式未适配摘要生成的需求；预览源文本环节未配置自动分析提示词。

## 排查步骤
1. 确认当前知识库使用的处理模式，是否启用问答拆分模式。
2. 检查预览源文本环节是否存在预设的分析提示词配置。
3. 对比直接全文提问生成摘要的token消耗与实际效果，评估是否符合使用需求。

## 解决与验证
如需实现单个文件的摘要生成，可直接在问答拆分模式下调整提示词，将输出的Q设置为对文档内容的摘要，A设置为输出文档原文。如需在预览源文本时生成概览与关键字分析，可配置对应环节的提示词，输出文本概览、关键字等分析结果。验证时，上传测试文件并触发问答拆分或预览操作，检查是否生成符合要求的摘要与分析内容。
