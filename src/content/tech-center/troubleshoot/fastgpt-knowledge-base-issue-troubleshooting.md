# FastGPT知识库操作及导出功能常见问题排查指南

## 现象
用户反馈FastGPT存在以下使用场景的问题：
1. 知识库单条词条删除功能的使用疑问；
2. 希望实现知识库词条批量删除，但当前操作效率不足；
3. 缺少标准化的知识库分类管理功能；
4. 导出的CSV文件未包含来源列，无法溯源引用内容；
5. 导出操作被限制30分钟才能执行一次；
6. 批量导入文档时，无法选择嵌套文件夹内的文件，仅支持同目录下的文件选择。

## 可能原因
结合官方反馈，出现上述问题的原因包括：
1. 浏览器原生限制，无法跨目录选择文件，导致批量导入仅支持同目录文件；
2. 未配置对象存储服务（OSS），受带宽不足影响，设置了30分钟的导出限制；
3. 批量删除功能暂未开发，官方认为当前直接点击删除的操作效率更高；
4. 知识库标准化分类功能正在评估交互方案，当前仅支持通过tag实现分类；
5. 导出CSV的来源列暂未开发完成。

## 排查步骤
1. 尝试批量导入文档时，检查选择的文件是否均位于同一目录，确认是否因跨目录选择导致导入失败；
2. 执行导出操作时，查看页面提示信息，确认是否触发30分钟的导出限制；
3. 进入目标知识库的编辑页面，检查是否存在单条词条的删除按钮；
4. 查看导出生成的CSV文件内容，确认是否包含来源列；
5. 进入知识库管理页面，检查是否支持通过tag进行分类管理。

## 解决与验证
1. 单条词条删除：进入知识库编辑框，点击对应词条的删除按钮即可完成删除操作；
2. 批量导入嵌套文件：可通过脚本将嵌套文件夹内的所有文件统一转移至同一目录后，再进行批量选择导入；
3. 导出CSV来源列：将在后续版本中补充该列；
4. 导出30分钟限制：因未配置OSS导致，需按实际环境确认调整方式；
5. 知识库分类：当前可通过tag实现分类管理，批量删除功能暂未支持，官方正在考虑交互方案。
