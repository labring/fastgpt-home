# 解决FastGPT知识库最低相关度过滤不生效的问题

## 现象
用户在私有部署V4.6.6版本的FastGPT中，于应用配置的知识库搜索参数里设置最低相关度为0.4，并开启了空搜索回复功能。在调试预览界面提问与知识库无关的问题时，系统未触发空搜索回复，反而返回了知识库引用内容。根据用户附带的截图，这些引用的相关性数值分别为0.12和0.11，均明显低于设定的0.4阈值。

## 可能原因
根据用户反馈的问题表现，当前检索流程未正确校验知识库片段的相关性数值与设定的最低相关度阈值，导致低于阈值的片段被纳入返回结果，进而未触发空搜索回复逻辑。该问题可能与检索逻辑的参数校验环节配置或执行异常有关，具体原因需结合实际部署环境进一步确认。

## 排查步骤
1. 登录FastGPT私有部署后台，进入对应应用的配置页面，找到知识库-搜索参数模块，确认最低相关度的设置值为0.4，检查是否存在配置保存后被重置的情况；
2. 在调试预览界面，输入一段与现有知识库内容无关联的问题，提交后查看返回的知识库引用模块，找到每条引用下方标注的相关性数值；
3. 将每条引用的相关性数值与设定的0.4阈值进行对比，确认是否存在数值低于0.4的片段被返回的情况；
4. 检查空搜索回复的配置项，确认已填写对应的回复内容，且配置已成功保存。

## 解决与验证
1. 重新进入应用配置页面，找到知识库-搜索参数模块，确认最低相关度的设置值为0.4，点击保存按钮后再次检查配置是否生效；
2. 保存配置后，返回调试预览界面，输入一段与知识库无关的问题再次发起提问，观察返回结果：若仅返回相关性不低于0.4的知识库片段，或直接触发空搜索回复，则问题解决；
3. 若仍存在低于阈值的片段被返回或未触发空搜索回复的情况，可将问题细节及截图反馈至官方仓库，协助排查修复。
