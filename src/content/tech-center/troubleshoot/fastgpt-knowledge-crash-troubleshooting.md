# 解决FastGPT点击知识库时页面崩溃的排错方法

## 现象
FastGPT流程可正常运行并回答问题，查看详情页的其他控件点击均正常，但点击知识库控件时页面立即崩溃。该问题跨版本存在，docker logs无错误日志，页面出现未捕获的异常，通过F12控制台可查看到Minified React error #300报错。

## 可能原因
1.  私有部署场景下，模型配置不正确或模型未启用；
2.  浏览器翻译功能干扰页面运行，导致崩溃；
3.  浏览器环境不兼容相关API；
4.  页面中使用的if条件控件逻辑或参数异常，触发页面崩溃。

## 排查步骤
1.  关闭浏览器的翻译功能，重启浏览器后重试点击知识库控件。
2.  打开浏览器控制台的Console面板，查看并记录具体的报错信息。
3.  检查模型配置：确保每个系列模型至少有一个可用，可在【账号-模型提供商】页面中检查；确保至少有一个开启的知识库文件处理模型；检查模型中的对象参数（数组、对象类型）是否为空，若为空可尝试设置为空数组或空对象。
4.  临时禁用页面中的if条件控件，再次点击知识库控件，观察页面是否仍崩溃。
5.  更换浏览器环境后重试，排除浏览器兼容问题。

## 解决与验证
若为浏览器翻译功能导致的问题，关闭翻译功能后即可恢复正常。若为模型配置异常，修正对应配置后重启服务，再次点击知识库验证是否正常。若为if条件控件触发的问题，调整该控件的逻辑或参数后，验证点击知识库控件是否不再崩溃。若为浏览器兼容问题，更换浏览器后即可恢复。每次修改操作后，均需点击知识库控件确认页面状态。
