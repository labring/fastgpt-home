# 排查并解决FastGPT知识库引用上限设置异常问题

## 现象
用户在FastGPT私有部署版本4.14.18及升级后的4.14.26中，创建工作流并添加知识库搜索模块后，设置知识库过滤的引用上限时出现异常：前端界面将数值输入框的最大、最小值配置颠倒，仅允许选择8或100两个数值，输入其他数值后点击确定会被自动还原，且界面的滚动条无法正常拖动调整数值范围。

## 可能原因
该问题的核心原因为前端代码中知识库引用上限的参数配置逻辑存在错误，将数值输入框的最大、最小值设置颠倒，同时错误限制了可选的数值范围，导致滚动条交互无法正常触发，进而无法调整到期望的引用上限数值。

## 排查步骤
1. 确认当前使用的FastGPT私有部署版本为4.14.18或4.14.26，这两个版本为issue中明确提及的受影响版本。
2. 登录FastGPT系统，进入工作流管理页面，创建新工作流或编辑已有工作流。
3. 在工作流编辑界面中，拖动添加知识库搜索模块，打开该模块的配置面板，找到知识库过滤的引用上限设置项。
4. 尝试输入8、100以外的任意数值，点击确定按钮后观察输入框内的数值是否被自动还原。
5. 尝试拖动引用上限输入框旁的滚动条，检查是否可正常调整数值范围，确认异常表现与issue描述一致。
6. 需按实际环境对照官方文档，确认该参数的标准配置范围是否与当前界面表现相符。

## 解决与验证
该问题属于前端代码的逻辑缺陷，需修正知识库引用上限输入框的最大、最小值颠倒配置，并修复滚动条的交互逻辑。验证步骤如下：
1. 按照官方发布的更新说明，升级FastGPT至包含该问题修复的版本，或直接修复前端对应代码逻辑。
2. 重新进入知识库搜索模块的参数设置界面，尝试设置8、100以外的任意数值作为引用上限。
3. 点击确定按钮后，检查输入的数值是否正常保留，未被自动还原。
4. 拖动滚动条确认可正常调整数值范围，验证异常问题是否已完全解决。
