# 解决FastGPT知识库上传表格后换行失效与合并表格无法识别问题

## 现象
用户在FastGPT知识库中上传含表格的docx文件后，出现两个异常问题：一是表格内的换行失效，展示为`<br><br>`标签；二是合并格式的表格无法被正常识别。搜索该知识库时，返回的结果与原文件的表格格式不符，无法正确还原原表格的排版与内容。

## 可能原因
目前未明确具体根因，推测可能与文档解析过程中表格格式的转义处理逻辑、换行符的渲染配置有关，需结合实际部署环境确认。

## 排查步骤
1.  复现问题：上传包含带换行、合并单元格的docx文件到FastGPT知识库，通过工作流搜索该知识库，查看搜索结果中的表格展示效果。
2.  确认文件本身：检查原docx文件的表格格式是否正常，确保换行、合并单元格的设置无异常。
3.  查看解析日志：需按实际环境确认是否可获取FastGPT的文档解析日志，排查解析过程中是否存在格式转义错误。
4.  对比其他文件：上传其他仅含简单表格（无换行、无合并单元格）的docx文件，验证是否仅复杂表格出现该问题。

## 解决与验证
目前可临时通过以下方式缓解与验证：
1.  若需临时修复展示效果，可在前端渲染环节对返回的文本内容执行处理，将`<br><br>`替换为实际换行符，或完成HTML转义。
2.  针对合并表格无法识别的问题，需等待官方修复或按实际环境调整文档解析相关配置。
验证步骤：完成上述处理后，重新上传原docx文件，通过工作流搜索该知识库，确认表格内换行正常显示、合并格式的表格可被正确识别。
