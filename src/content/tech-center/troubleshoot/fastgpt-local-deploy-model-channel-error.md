# 解决本地部署FastGPT后模型渠道页面报错及类型为空的问题

## 现象
使用最新镜像部署本地开发环境且未修改配置，部署完成后打开模型渠道页面会出现报错，且渠道类型为空。直接下载Docker镜像部署无该问题。

## 可能原因
暂无明确的已知匹配原因，需结合本地部署的构建、依赖加载环节实际情况确认。仅可明确本地开发环境部署与官方Docker镜像部署存在差异。

## 排查步骤
1. 对比官方Docker镜像部署与本地部署的配置、构建流程差异
2. 检查本地部署时的依赖安装、镜像构建日志，确认是否存在加载失败或配置遗漏
3. 查看浏览器控制台报错信息，获取页面报错的具体文本
4. 核对本地开发环境的依赖包版本，确认与官方构建环境的一致性

## 解决与验证
若排查发现本地构建环节存在依赖缺失或配置未同步，可补全对应配置或重新执行本地构建流程。验证方式为重新启动本地部署服务，打开模型渠道页面，确认页面不再报错且渠道类型正常显示。
