# 解决FastGPT添加本地模型与自定义搜索后的调用异常问题

## 现象
使用FastGPT公有云v4.8.9版本，执行以下操作后全流程调试出现异常：添加本地模型glm3，将谷歌搜索模板修改为自定义搜索地址且可正常获取网络数据，在config.conf中配置了本地模型相关参数。

## 可能原因
结合操作步骤与异常场景，可能的原因包括：config.conf中本地模型glm3的配置参数存在错误，自定义搜索模板与本地模型的调用链路存在冲突，公有云环境中本地模型服务运行异常，或未正确配置模型调用的相关参数。

## 排查步骤
1. 打开config.conf文件，核对本地模型glm3的配置参数，确保格式与参数值符合要求。
2. 临时关闭自定义搜索模板，仅保留本地模型调用流程，执行调试测试，排查是否为搜索模板与模型调用的链路冲突。
3. 检查公有云环境中本地模型服务的运行状态，确认服务可正常启动与访问。
4. 查看系统日志，提取具体报错信息，定位异常发生的具体节点。

## 解决与验证
根据排查结果进行对应修复：若为配置参数错误，修正config.conf中的本地模型配置；若为链路冲突，调整搜索模板与模型的调用逻辑；若为服务异常，重启本地模型服务或联系对应环境支持。修复完成后，重新执行全流程调试，确认异常消失，可正常获取搜索数据并完成模型调用。
