# 解决FastGPT循环体输出包含无效null元素的问题

## 现象
在FastGPT循环体的遍历流程中，若部分元素被排除，未被输出到循环体结束节点的元素会在最终结果中变为null。此时需手动处理循环结果，才能获取期望的有效元素，无法直接得到仅包含指定输出元素的循环结果。

## 可能原因
当前FastGPT循环体的默认处理逻辑，会将所有遍历项纳入最终结果，未被输出到循环体结束节点的元素会被自动置为null，导致结果中存在无效的null元素，无法直接满足仅保留指定输出元素的需求。

## 排查步骤
1. 确认循环体的遍历范围与需要保留的元素规则，明确哪些元素应被纳入最终结果。
2. 检查循环体结束节点的输出配置，确认已配置的输出项内容。
3. 执行完整的循环体流程，查看输出结果中是否存在未期望的null元素。

## 解决与验证
解决方式为在循环体遍历过程中，仅将需要的元素输出到循环体结束节点。验证时执行循环体流程，确认最终结果仅包含输出到结束节点的有效元素，无多余的null元素，无需额外手动处理循环结果。
