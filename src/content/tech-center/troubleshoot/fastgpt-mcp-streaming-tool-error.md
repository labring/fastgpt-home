# 解决FastGPT MCP服务含流式AI组件时调用无响应问题

## 现象
在FastGPT 4.9.6私有部署版本中，通过工作台-MCP服务创建的两个MCP应用，一个用于SQL查询且不含AI流式输出组件，调用可正常执行；另一个用于数据渲染的工具包含AI流式输出组件，调用时无法获取响应。将该数据渲染工具的AI模型更换为不支持流式输出的模型，并关闭流式输出配置后，可正常调用。

## 可能原因
该问题的直接关联因素为工具是否包含AI流式输出组件及流式配置状态。仅当工具包含流式AI组件时出现调用异常，具体根原因需结合部署日志进一步确认。

## 排查步骤
1. 进入FastGPT工作台的MCP服务管理页面，查看目标工具的配置信息。
2. 确认工具中是否包含AI流式输出组件，记录当前使用的AI模型是否支持流式输出。
3. 检查工具的流式输出配置状态，确认是否开启了流式输出。
4. 若工具包含流式AI组件且开启了流式输出，可临时更换为不支持流式的模型并关闭流式配置，测试调用是否正常。
5. 查看FastGPT服务端及MCP服务的运行日志，定位具体报错信息。

## 解决与验证
若临时测试更换非流式模型并关闭流式配置后可正常调用，说明问题与流式输出组件的响应处理有关。可根据实际部署环境，检查MCP服务的流式响应转发逻辑，或调整AI模型的流式配置适配MCP服务的要求。验证方式为：恢复原工具的AI模型及流式配置，重新调用工具，确认可正常获取响应。
