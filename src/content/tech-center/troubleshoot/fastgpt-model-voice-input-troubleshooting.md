# FastGPT模型调用与语音输入404报错排查指南

## 现象
- 接入多模态模型后，其他工具可正常读取图片，但FastGPT无法读取图片。
- 语音输入操作后出现bad response status code 404报错，对应请求ID为2024052815285657566720090754222。
- 网页可打开语音输入选项，但点击后无反应，或提示浏览器不支持，更换浏览器后仍无效。

## 可能原因
- 模型请求地址配置错误，导致返回404报错。
- 不支持对应模型的视觉接口，兼容性存在问题。
- 语音输入相关配置未正确完成，相关组件的连接配置有误。
- 模型调用链路存在问题，如模型本身或中间服务的请求未通过测试。

## 排查步骤
1. 通过curl工具测试模型本身的请求是否正常，具体参数参考官方文档。
2. 通过curl工具测试中间服务的请求是否正常。
3. 检查配置中的模型地址是否正确，避免出现404报错。
4. 确认当前系统是否支持对应模型的视觉接口，排查兼容性问题。
5. 检查语音输入相关的配置项，确认相关组件的连接是否正常。

## 解决与验证
1. 若为模型地址配置错误，修正配置中的模型地址。
2. 若为接口兼容性问题，可通过二次开发中间服务以支持对应视觉接口。
3. 完成配置调整后，重新发起模型调用或语音输入测试，验证报错是否消失。
4. 语音输入相关问题需按实际环境确认配置项，确保相关组件的连接正常。
