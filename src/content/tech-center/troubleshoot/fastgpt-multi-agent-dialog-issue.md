# 解决FastGPT多智能体协作与多轮对话分类异常问题

## 现象
用户在FastGPT中尝试实现多智能体协作模式，参考类似问题分类的交互逻辑，采用问题分类与工具调用的组合方式，但无法实现有效的多轮持续对话。后续发起的对话会重新执行分类流程，无法延续之前的交互上下文，导致多轮交互逻辑断裂。同时用户反馈当前系统缺少原生的多智能体协作模式支持，无法满足AI Agent主流设计模式中的多智能体协作需求。

## 可能原因
使用问题分类与工具调用的组合模式实现多智能体协作时，系统未保留多轮对话的上下文信息，每次新的对话都会重新触发分类逻辑，导致无法延续之前的交互状态，无法满足多智能体协作的多轮持续对话需求，无法实现连贯的多智能体交互。

## 排查步骤
1. 确认当前应用的交互逻辑是否采用问题分类与工具调用的组合模式。
2. 构建多轮对话测试场景，依次发起多个相关联的对话请求，观察系统是否在后续对话中重新执行分类操作，导致上下文丢失。
3. 检查是否存在与对话上下文保留相关的配置项，相关配置需按实际环境确认。

## 解决与验证
目前暂无公开的标准化配置或代码修改方案。若需实现多智能体协作与多轮持续对话功能，需结合实际业务场景调整交互逻辑，相关的配置参数与实现方式需按实际环境确认。
