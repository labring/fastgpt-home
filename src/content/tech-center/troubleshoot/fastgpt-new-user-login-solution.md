# FastGPT平台创建新用户并成功登录的解决方法

## 现象
当前仅能使用root用户登录FastGPT平台，无法通过新建的用户账号完成登录，需掌握正确的新用户创建与登录配置方法。

## 可能原因
创建新用户时未按照平台要求的密码加密规则生成密文，或未将密文正确存储至平台指定的用户信息存储位置，导致登录验证阶段无法匹配用户输入的明文密码，进而无法完成登录。

## 排查步骤
1. 确认平台当前采用的用户密码加密规则，具体配置需按实际环境确认。
2. 提取待创建新用户的明文密码，按照平台要求的加密方式生成对应的密文内容。
3. 检查平台用户信息存储的数据库或配置项，确认存储字段与加密格式是否匹配，具体检查项需按实际环境确认。
4. 核对新用户的账号信息与生成的密码密文是否对应一致，需按实际环境确认字段映射关系。

## 解决与验证
参考给出的示例，明文密码1234对应的密文为756bc47cb5215dc3329ca7e1f7be33a2dad68990bb94b76d90aa07f4e44a233a，可按照该加密格式生成新用户的密码密文。将生成的密文与新用户的账号信息一同写入平台用户存储的对应字段，完成新用户的创建操作。使用新用户的明文密码尝试登录FastGPT平台，若可正常进入平台，则验证创建与登录流程成功。
