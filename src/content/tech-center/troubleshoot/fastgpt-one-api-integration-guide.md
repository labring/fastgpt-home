# 解决FastGPT无法正常使用需接入one api的问题

## 现象
使用FastGPT时无法实现预期功能，未明确具体报错文本，相关细节需按实际环境确认。

## 可能原因
未完成one api的接入配置，导致功能无法正常实现。

## 排查步骤
1. 确认当前使用的FastGPT部署类型。
2. 核对已配置的密钥是否可正常使用。
3. 检查是否已完成相关接入配置。

## 解决与验证
需按照官方文档指引完成one api的接入配置。具体步骤参考官方文档：https://doc.fastgpt.in/docs/installation/one-api/。配置完成后，验证FastGPT功能是否可正常使用。
