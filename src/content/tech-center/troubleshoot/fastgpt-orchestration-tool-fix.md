# 解决FastGPT自定义编排工具流程调用失败问题

## 现象
自定义编排工具流程后未成功调用，流程逻辑为AI提取关键词后调用工具，因未找到JSON配置项改为再次调用AI。单独调试各分支可正常运行，流程消耗Token，但整体流程未按预期将最终AI回复的结果作为工具引入。

## 可能原因
未明确如何将流程中最终AI回复的结果作为工具引入，且未找到所需的JSON格式配置项，导致编排流程的节点衔接出现问题。

## 排查步骤
1. 检查流程中各节点的输入输出参数关联关系，确认是否存在未正确衔接的链路。
2. 查找流程配置中的JSON格式相关项，确认是否存在遗漏或未启用的配置。
3. 单独调试各分支流程，确认各分支可正常运行后，再整合整体流程进行验证。
4. 确认工具调用的前置条件与参数传递是否符合预期。

## 解决与验证
明确流程中最终AI回复结果作为工具引入的配置方式，确认各节点的输入输出参数正确关联。整合流程后运行，验证工具调用成功，且最终结果符合预期，同时确认Token消耗符合流程设计。
