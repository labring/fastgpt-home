# FastGPT外链用户点击反馈功能显示无权限报错的排错方法

## 现象
使用私有部署版本的FastGPT外链时，用户点击反馈功能会触发无权限相关报错提示，而点赞功能可以正常使用。

## 可能原因
由于点赞功能可正常使用，说明基础外链访问权限配置正常，问题集中在反馈功能的专属权限或配置上。具体原因需结合实际部署环境确认，常见关联方向包括外链功能权限配置、后端接口访问权限限制两类。

## 排查步骤
1. 登录FastGPT后台管理页面，查看对应外链的详细配置，确认反馈功能是否被允许访问。
2. 检查私有部署的后端服务权限规则，确认反馈功能对应的接口未被拦截。
3. 对比点赞功能与反馈功能的调用配置，排查是否存在配置差异。
4. 查看后端服务运行日志，获取无权限报错的具体信息。

## 解决与验证
1. 根据排查结果调整外链配置，开放反馈功能的访问权限。
2. 修正后端接口的权限规则，允许外链访问反馈功能对应的接口。
3. 重新打开FastGPT外链，点击反馈功能，验证是否不再提示无权限报错。
4. 再次测试点赞功能，确认其仍可正常使用，确保调整未影响原有功能。
