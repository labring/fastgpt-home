# FastGPT插件功能入参类型及外部数据参数说明

## 现象
使用FastGPT私有部署版本开发搜索插件时，在添加入参环节无法明确各入参类型的具体含义，未在官方wiki中找到相关说明，其中"外部数据"参数的指向尤为模糊，无法确定其适用场景，影响插件功能的正常开发。

## 可能原因
官方文档中未对插件入参类型及"外部数据"参数的具体含义作出详细解释，导致无法准确匹配业务需求选择对应的入参类型。

## 排查步骤
1.  查看FastGPT官方文档中与插件功能入参配置相关的内容，获取各入参类型的基础说明
2.  对照插件开发界面的入参选项列表，逐一核对各类型的文字描述，明确其大致指向
3.  结合插件的业务需求，梳理需要传递的参数内容，匹配对应类型的选项

## 解决与验证
若需传递用户输入的问题内容，可优先尝试匹配对应类型的入参选项。"外部数据"参数的具体含义需按实际业务场景确认，完成入参配置后，可通过插件测试调用验证参数传递是否符合预期。
