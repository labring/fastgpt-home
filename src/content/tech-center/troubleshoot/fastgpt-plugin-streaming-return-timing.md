# 明确FastGPT插件HTTP流式输出的返回时机

## 现象
用户在使用FastGPT插件的HTTP输出格式流式功能时，对插件结果的返回时机存在疑问，具体为插件输出结果是否需要等待流式输出完全结束后才会返回。

## 可能原因
当前未获取到该问题对应的具体运行日志与配置细节，暂无公开的明确官方说明，该疑问涉及插件流式输出的响应逻辑，具体原因需按实际运行环境与插件配置确认。

## 排查步骤
1.  核对当前使用的插件HTTP输出格式的具体配置。
2.  收集插件运行过程中的输出日志，记录相关的运行数据。
3.  对照FastGPT官方文档的插件相关说明，验证输出逻辑是否符合预期。
4.  若存在多个插件配置，可逐一测试不同配置下的返回结果，对比差异。

## 解决与验证
若需明确插件流式输出的返回时机，需结合实际运行环境与插件配置，参考FastGPT官方文档的插件流式输出说明进行验证。可通过搭建测试场景，模拟插件的流式输出请求，观察插件结果的返回节点，确认是否等待流式输出完全结束后返回。同时，可结合运行日志中的数据传输记录，进一步确认返回时机与流式过程的关联。
