# 解决FastGPT 4.7版本高级编排模块模型下拉框为空问题

## 现象
用户在FastGPT私有部署4.7版本中，升级自4.6.9版本后，高级编排功能内的问题分类模块与文本内容提取模块的AI模型选择下拉框为空，无法选择模型。AI对话模块可正常选择模型。

## 可能原因
该问题仅在从4.6.9版本升级至4.7版本的私有部署环境中出现，暂未明确具体触发原因，需结合实际部署环境确认细节。

## 排查步骤
1. 确认当前FastGPT私有部署版本为4.7，且升级路径为从4.6.9版本升级而来。
2. 打开AI对话模块，确认可正常加载并选择可用的AI模型，验证整体模型配置可用性。
3. 进入高级编排页面，分别查看问题分类模块、文本内容提取模块的模型选择下拉框状态。
4. 核对部署相关配置文件，确认高级编排模块的相关配置是否正确加载（需按实际环境确认）。

## 解决与验证
目前暂未公开标准化解决流程，可尝试以下操作：重新加载前端页面或重启FastGPT服务，核对4.7版本升级文档中关于高级编排模块的配置变更说明（需按实际环境确认）。验证方式为：进入高级编排页面，确认问题分类模块与文本内容提取模块的模型下拉框可正常加载并选择模型。
