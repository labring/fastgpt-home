# FastGPT私有部署4.9版本第三方文件输出异常排查

## 现象
添加第三方文件后出现输出异常，配置的参数格式与流程中文件链接的格式保持一致。

## 可能原因
暂无明确指向的异常原因，需结合实际部署环境、运行日志进一步确认。

## 排查步骤
1. 确认当前使用的FastGPT私有部署版本为4.9。
2. 核对第三方文件链接的格式，确保与流程中配置的文件链接格式一致。
3. 查看系统运行日志，排查文件读取或输出环节的异常信息。
4. 确认所使用的密钥可正常使用，符合项目要求。

## 解决与验证
若参数格式与流程要求不符，调整参数格式至匹配要求后，重新添加第三方文件验证输出是否正常。若为部署版本适配相关问题，需按项目文档要求完成适配调整后验证。
