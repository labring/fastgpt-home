# 解决FastGPT私有部署手动导入插件安装包报错问题

## 现象
FastGPT 4.14.0商业版私有部署版本中，root账号下直接从插件市场点击安装插件可正常完成。手动导入从插件市场下载的pkg格式插件安装包时，无法完成安装且报错。该部署环境无法连接互联网，需通过手动导入方式安装插件。

## 可能原因
未明确具体触发异常的原因，仅已知直接从插件市场安装流程正常，手动导入下载的pkg安装包时出现报错。具体原因需结合实际部署环境与导入操作细节确认。

## 排查步骤
1. 确认当前部署版本为4.14.0商业版私有部署版本，操作账号为root账号。
2. 核对手动导入的pkg安装包是否为从FastGPT插件市场下载的官方文件，确认文件未损坏。
3. 检查部署环境的网络与文件权限设置，因环境无法联网，需确认本地文件访问权限正常，且无额外的安全拦截策略。
4. 查看issue附带的报错截图，定位具体报错信息。

## 解决与验证
暂无公开通用解决方法，需按排查步骤定位具体异常后针对性处理。验证方式为：手动导入插件pkg安装包，确认安装流程可正常完成，插件可正常加载启用。
