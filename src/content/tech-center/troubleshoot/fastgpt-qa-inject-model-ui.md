# 为FastGPT QA数据注入页面添加可视化模型选择UI功能

## 现象
当前FastGPT的QA数据注入功能，仅支持通过修改config.json文件配置模型，未提供可视化的页面选择界面。用户需要手动编辑配置文件，完成停止容器、修改配置、重启容器等一系列操作后才能切换模型，流程繁琐。例如针对简单知识场景可选择轻量化模型，针对需要复杂理解推理的知识场景需选择能力更强的模型，但当前流程需要多次启停容器，操作成本较高。

## 可能原因
原系统的QA数据注入模块，模型配置仅内置了基于config.json的静态读取逻辑，未在页面层开发可视化的模型选择交互组件，导致用户无法直接在页面完成模型选择，只能通过修改静态配置文件实现模型切换。

## 排查步骤
1. 登录FastGPT平台，进入QA数据注入页面，查看是否存在可视化的模型选择控件。
2. 若未找到模型选择控件，尝试通过编辑config.json文件配置目标模型参数。
3. 重启FastGPT容器，验证配置文件修改是否生效。
4. 对比平台其他支持可视化模型选择的页面，确认是否存在功能遗漏。

## 解决与验证
解决该问题的核心是在QA数据注入页面添加可视化的模型选择UI，用户可直接在页面选择所需模型，无需手动修改配置文件。验证流程如下：
1. 进入QA数据注入页面，找到新增的模型选择UI组件。
2. 选择目标模型，完成Q&A数据注入的全部流程。
3. 检查生成的Q&A数据处理结果，确认使用的是所选模型。
4. 切换选择其他模型，重复注入流程，验证无需修改配置文件即可完成切换，无需重启容器即可生效，大幅简化了模型切换的操作流程。
