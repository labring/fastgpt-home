# 解决FastGPT知识库引用上限数值被自动重置的问题

## 现象
私有部署V4.9.2版本的FastGPT中，完成知识库构建后设置简单应用，选择"知识库+对话索引"类型并关联该知识库，点击参数的搜索过滤模块时，引用上限字段无法填入正确数值，输入的内容会自动被改为10或100，最终导致知识库仅引用1条数据。

## 可能原因
目前无明确官方说明，仅能确定问题发生在应用配置的搜索过滤参数设置流程中，未明确具体触发逻辑，需结合实际部署环境进一步排查。

## 排查步骤
1. 确认当前使用FastGPT私有部署V4.9.2版本。
2. 完成知识库构建后，进入应用创建页面，选择"知识库+对话索引"类型的简单应用并关联已构建的知识库。
3. 进入该应用的参数配置页面，打开搜索过滤模块。
4. 尝试在引用上限字段填入自定义数值。
5. 观察输入的数值是否自动被重置为10或100。

## 解决与验证
目前无公开的官方修复方案，可按以下方式验证问题：
1. 完整记录异常配置流程，包括应用类型、知识库关联情况及参数设置步骤，提交至官方反馈渠道。
2. 尝试更换应用配置路径或参数设置方式，避免触发异常逻辑。
验证时，确认引用上限的自定义数值可正常保留，知识库引用数量符合预期设置。
