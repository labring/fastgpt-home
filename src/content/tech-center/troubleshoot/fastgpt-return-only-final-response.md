# 解决FastGPT对话仅返回最终结果不输出中间内容的问题

## 现象
用户反馈FastGPT调用后输出了中间过程内容，希望调整为仅返回最终的结果内容，与标准对话模式的输出效果一致。

## 可能原因
由于当前issue未提供具体配置与报错信息，无法确定明确触发原因，需按实际部署环境、调用方式与配置项进行排查。

## 排查步骤
1. 确认当前使用的FastGPT功能类型，区分标准对话模式与其他自定义输出模式。
2. 查阅FastGPT对应功能的配置说明，检查是否存在与中间内容返回相关的设置。
3. 核对调用代码或接口配置，确认是否存在额外的中间内容输出逻辑。
4. 确认调用密钥与链路的正确性，排除因配置错误导致的额外内容输出。

## 解决与验证
将功能配置调整为仅返回最终结果，匹配标准对话模式的输出逻辑。发起测试调用后，确认输出内容仅包含最终的结果，无中间环节的过程内容。
