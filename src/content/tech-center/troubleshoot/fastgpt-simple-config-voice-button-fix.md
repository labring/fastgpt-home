# 解决FastGPT私有部署版简易配置页语音按钮失效问题

## 现象
在FastGPT私有部署环境中，按照新建应用、进入应用简易配置页面的语音输入配置模块的流程操作后，语音输入相关配置按钮无法正常点击，无法触发配置流程。该类配置按钮在高级编排页面可正常使用，不符合简易配置页语音配置按钮可正常使用的预期。

## 可能原因
当前未明确具体触发因素，需结合实际部署环境进行排查确认。

## 排查步骤
1. 确认当前使用的是FastGPT私有部署版本。
2. 新建应用并进入该应用的简易配置页面。
3. 尝试点击语音输入相关配置按钮，观察是否无法触发配置流程。
4. 切换至高级编排页面，验证同类配置按钮是否可正常操作。

## 解决与验证
目前无公开通用解决方法，需结合实际排查结果进行针对性修复。验证方式为：进入应用简易配置页面，点击语音输入相关配置按钮，确认按钮可正常触发配置流程。
