# 解决FastGPT单个模型自定义API地址与密钥的配置问题

## 现象
用户在FastGPT 4.20版本的模型配置页面中，发现存在自定义API地址输入框，但未提供专属的模型密钥填写位置。尝试将密钥填入自定义请求tokens字段后，无法正常完成模型调用，希望无需通过OneAPI即可为每个模型单独配置API地址与密钥。

## 可能原因
当前配置页面中，自定义API地址模块未配套专属的密钥输入项，通用的自定义请求tokens字段无法适配模型调用的密钥验证规则，导致无法通过该方式完成有效配置。

## 排查步骤
1. 确认当前使用的FastGPT版本为4.20版本。
2. 进入模型配置界面，找到自定义API地址的输入区域。
3. 查看该区域是否存在专属的密钥填写位置，若未找到，尝试将模型密钥填入自定义请求tokens字段。
4. 执行模型调用测试，观察返回结果是否正常，确认配置是否生效。

## 解决与验证
在当前4.20版本中，可通过以下步骤验证配置逻辑：首先进入模型配置页面，填写目标模型的自定义API地址。随后尝试将模型密钥填入自定义请求tokens字段，执行模型调用测试。若调用失败，需确认当前配置是否符合官方模型调用的基本规则。如需实现无需OneAPI的单个模型自定义API地址配置，需等待后续版本优化或确认现有配置项的正确使用方式。
