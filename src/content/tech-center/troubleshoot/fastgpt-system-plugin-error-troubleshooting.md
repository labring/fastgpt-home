# FastGPT添加系统插件后对话报错的排查方法

## 现象
配置大模型且不添加系统插件时，可正常发起对话；添加系统插件后，发起对话时出现报错。

## 可能原因
目前仅明确关联添加系统插件的操作，具体原因需按实际部署环境与日志信息确认。

## 排查步骤
1.  确认系统插件的配置参数完整，无缺失或格式错误。
2.  提取报错截图中的具体报错文本，记录相关信息。
3.  复现不添加系统插件的对话流程，确认大模型本身功能正常，排除大模型自身异常。
4.  核对系统插件与大模型的关联配置是否符合要求。

## 解决与验证
根据排查出的具体问题修正对应配置，修正后重新发起对话。若无法定位具体原因，需结合完整后台日志进一步确认。修正后验证对话流程可正常运行，无报错出现。
