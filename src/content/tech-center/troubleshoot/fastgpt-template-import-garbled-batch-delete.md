# 解决FastGPT模板导入中文乱码且无法批量删除的问题

## 现象
通过模板导入中文内容时出现乱码，已通过更改编码格式解决乱码问题，但无法批量删除相关导入内容。

## 可能原因
具体原因未明确，已知操作中通过调整编码格式解决了乱码问题，无法批量删除的相关诱因需结合实际部署环境确认。

## 排查步骤
1.  检查待导入模板文件的编码格式，确认其编码类型。
2.  按照文档指引调整模板文件编码格式，验证乱码问题是否解决。
3.  尝试执行批量删除操作，确认操作流程是否符合产品使用规范。
4.  确认当前使用的FastGPT版本是否存在相关功能限制。

## 解决与验证
针对乱码问题，可通过调整模板文件的编码格式解决。针对无法批量删除的问题，需按实际部署环境排查操作路径或功能限制。完成乱码修复后，按照标准操作流程尝试批量删除，确认功能是否正常。
