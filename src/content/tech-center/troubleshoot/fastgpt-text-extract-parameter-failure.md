# 解决FastGPT 4.7版本文本内容提取无法获取参数问题

## 现象
在FastGPT 4.7私有部署版本中，使用文本内容提取功能时，无法提取到具体参数，导致无法执行后续流程。

## 可能原因
暂无明确关联的已知原因，需结合实际部署环境、配置参数及运行日志等信息综合确认。

## 排查步骤
1. 确认当前使用的FastGPT私有部署版本为4.7。
2. 检查文本内容提取功能的配置项是否按照预期完成设置。
3. 核对待处理的文本内容与预设的提取参数规则是否匹配。
4. 确认已使用的密钥可正常调用相关服务。
5. 查看功能运行过程中的日志信息，排查是否存在未明确的执行异常。

## 解决与验证
根据排查结果调整对应内容。若为配置项设置错误，修正相关参数；若为提取规则与文本不匹配，调整规则以适配待处理文本；若为其他异常，需结合实际运行日志进一步定位问题。重新执行文本内容提取流程，确认可成功获取具体参数并完成后续流程。
