# 解决FastGPT工具调用回答控制及多工具选择混乱问题

## 现象
FastGPT 4.8.9私有部署版本存在两类问题。第一类为工具调用回答无法通过提示词细化，当AI选中两个工具时，无法指定由AI对话组件完成回答。第二类为当为两个子流程添加AI对话配置后，同时选择两个工具时，AI回答出现混乱。

## 可能原因
当前未明确公开的底层逻辑或配置原因，需按实际部署环境与配置细节确认。

## 排查步骤
1. 确认当前使用的FastGPT版本为4.8.9私有部署版本。
2. 检查工具调用配置与子流程的AI对话配置的关联关系。
3. 复现问题时，记录AI选中的工具数量与已配置的回答模块设置。
4. 核对当前使用的提示词内容，确认是否包含指定回答模块的相关表述。

## 解决与验证
目前无公开的官方标准化解决方法，可按以下方式临时调整。调整提示词内容，明确指定仅由AI对话组件完成回答。拆分子流程配置，减少同时选择的工具数量。验证时重新发起提问，观察AI回答模块是否符合预期，且回答不再出现混乱。
