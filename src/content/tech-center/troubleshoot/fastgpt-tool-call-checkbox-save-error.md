# 解决FastGPT工具调用返回AI内容勾选无法取消的问题

## 现象
在FastGPT私有部署4.8.9版本中，配置工具调用的HTTP请求功能时，取消勾选"工具调用中的返回AI内容"选项并点击确认保存后，再次打开该工具配置页面，该选项的勾选状态仍为已勾选。此时工具调用与AI回复两个配置项均勾选了返回AI内容，在调试流程中会返回两次重复的回复内容，无法仅保留单次有效回复。

## 可能原因
该问题的具体技术根源未明确，仅能确认工具调用配置项的勾选状态保存逻辑存在异常，无法正确将取消勾选的配置持久化保存。

## 排查步骤
1. 登录FastGPT私有部署4.8.9版本的后台，进入工具调用配置页面，找到HTTP请求类型的工具配置项。
2. 取消"工具调用中的返回AI内容"选项的勾选，点击确认按钮完成配置保存。
3. 退出当前配置页面后重新进入，查看"工具调用中的返回AI内容"的勾选状态。
4. 同时查看AI回复配置项的勾选状态，确认是否存在两个配置项均勾选的情况。

## 解决与验证
目前暂无官方内置的快速修复方案，可通过临时调整AI回复的返回AI内容勾选状态，规避调试时的重复回复问题。验证时，重新进入工具配置页面，确认工具调用的返回AI内容勾选状态符合预期，且执行调试流程时仅返回单次回复内容。若需彻底解决该问题，需等待官方修复配置项的状态保存逻辑。
