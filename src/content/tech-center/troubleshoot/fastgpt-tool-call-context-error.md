# 解决FastGPT工具调用后上下文拼接异常问题

## 现象
在FastGPT私有部署版本v4.8.11-fix中，正式聊天界面挂载工具并配置工具调用终止后，触发工具调用时会出现上下文拼接异常。用户先后发起独立提问A与B时，AI会错误将两个提问拼接为A+B的内容，后续的会话请求也会被异常拼接，无法正常区分独立的用户提问，该问题无法在调试界面复现。
## 可能原因
目前未明确该问题的具体代码根因，仅能确认该问题仅在正式聊天界面触发，与工具调用后的上下文会话拼接流程相关，需结合实际部署环境进一步排查。
## 排查步骤
1.  确认当前使用的FastGPT版本为v4.8.11-fix私有部署版本。
2.  避免在调试界面测试，切换至正式聊天界面进行操作。
3.  挂载任意工具并配置工具调用终止，先后发起两个独立的用户提问，观察AI返回的会话内容是否出现拼接异常。
4.  对比调试界面与正式聊天界面的会话表现，确认异常仅出现在正式聊天场景。
## 解决与验证
目前暂无官方发布的快速修复方案。临时验证方式为：在正式聊天界面重新发起独立提问，确认AI不会将前后两个用户提问拼接为合并内容，工具调用流程恢复正常。如需彻底解决该问题，需按实际部署环境的代码逻辑排查会话拼接相关模块。
