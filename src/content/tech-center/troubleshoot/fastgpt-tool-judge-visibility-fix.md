# 解决FastGPT工具选择前判断器不可见的配置问题

## 现象
用户在配置工具选择判断器时，判断器界面不可见，无法查看可选择的工具集合。在尝试添加判断逻辑为"用户问题中包含 @知识库检索，则直接进行知识库检索"的配置时，无法正常完成对应操作。

## 可能原因
需按实际环境确认，暂无明确已知的触发原因。常见排查方向可围绕配置环节完整性、前端缓存状态、相关组件加载情况展开。

## 排查步骤
1.  重新进入工具配置页面，完整走完判断器配置的前置流程，确认未跳过必要步骤。
2.  确认当前使用的密钥可正常调用相关服务，避免因密钥异常导致界面组件无法加载。
3.  清除当前浏览器的缓存数据，刷新页面后重新尝试配置判断器。
4.  核对判断逻辑的表述，确认"用户问题中包含 @知识库检索"的语句格式符合平台配置规则。

## 解决与验证
若排查后定位到具体问题，可针对性处理。例如清除缓存后刷新页面可解决前端渲染异常导致的界面不可见问题，补全前置配置步骤可恢复判断器的正常显示。配置完成后，可通过发送包含"@知识库检索"的测试问题，验证判断器是否正确触发知识库检索操作，确认符合预期效果。
