# 解决FastGPT工具选择模式下文本字段提取失败问题

## 现象
用户使用FastGPT公有云或私有部署版本时，通过工具选择模式搭配文本内容提取功能，尝试提取多个字段时多数情况无法得到正确结果。本地部署4.8.12版本的测试中完全无法成功，公有云版本仅首次调用成功，关闭页面后重新访问则无法再次成功。测试的工具包含充值金额、缴费系统、房间号等多个自定义参数。

## 可能原因
结合用户反馈的信息，可能的原因包括三点。第一，工具的自定义参数生成了非预期的默认值，比如unknown、unsigned这类内容，干扰了字段提取的逻辑判断。第二，字段提取的配置未正确建立用户输入内容与预设参数项的关联关系。第三，工作流节点的参数配置与实际需要提取的目标字段对应存在偏差。

## 排查步骤
1. 查看工具的自定义参数配置，确认是否存在未知、unsigned这类非预期默认值。
2. 核对当前工作流的参数项配置，确认与需要提取的目标字段（如充值金额、缴费系统、房间号）是否一一匹配。
3. 发起单轮对话测试，验证字段提取逻辑是否能正确识别用户输入中的目标内容并关联到对应参数。
4. 若使用私有部署版本，记录当前使用的FastGPT版本号，用于后续排查。

## 解决与验证
针对自定义参数默认值的问题，可修改工具的自定义参数配置，移除非预期默认值，或设置符合业务场景的默认值。若需要引导用户补充未明确的字段，可通过工作流的用户引导配置，在对话中主动提示用户提供相关信息，比如询问具体的缴费系统与房间号。
验证流程如下：重新调整工作流的参数项配置，使用用户输入示例（如“电费充值100元”）进行测试，确认能正确提取充值金额、缴费系统、房间号等目标字段；再次访问页面后重复测试，确认提取功能稳定生效，无异常失败情况。
