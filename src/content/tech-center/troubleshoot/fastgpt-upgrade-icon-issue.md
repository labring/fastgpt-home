# 解决FastGPT升级4.14.1后大模型图标显示异常问题

## 现象
升级FastGPT 4.14.1版本后，所有大模型的图标均显示为FastGPT默认图标，对应截图可佐证该异常表现。

## 可能原因
暂未明确具体触发原因，需结合实际部署环境、配置文件及升级流程细节进行排查确认。

## 排查步骤
1. 确认升级过程正常完成，无异常中断或报错日志。
2. 核对当前运行的FastGPT版本是否为4.14.1，确认未出现版本回退或配置覆盖情况。
3. 检查前端静态资源加载情况，确认大模型图标相关文件未缺失或加载失败。
4. 清除浏览器缓存及前端构建缓存，重新访问FastGPT系统。

## 解决与验证
若异常由浏览器缓存或前端构建缓存导致，清除缓存后即可验证图标是否恢复正常。若异常由静态资源路径配置错误导致，需修正图标文件的配置路径。若异常由升级过程中静态资源未正确替换导致，需重新执行完整的升级流程。完成上述操作后，重启FastGPT服务并清除缓存，验证大模型图标恢复为各自对应的专属图标。
