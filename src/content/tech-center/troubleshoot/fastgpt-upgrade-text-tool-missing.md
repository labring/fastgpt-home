# FastGPT 4.9.1升级后文本加工工具异常排查指南

## 现象
从4.8.11版本升级至4.9.1私有部署版本后，工作流无法找到原使用的文本加工工具，触发报错。用户反馈疑似文本加工功能不可用，相关报错截图已上传至issue，但未展示具体报错文本。

## 可能原因
该问题仅在从4.8.11升级至4.9.1的私有部署场景中被反馈，未明确的版本变更可能导致文本加工工具的注册、加载或配置出现异常，具体原因需结合实际部署环境排查。

## 排查步骤
1. 确认当前运行的FastGPT版本为4.9.1私有部署版本，核对升级过程是否完整执行。
2. 进入工作流配置页面，检查原使用的文本加工工具是否仍存在于可用工具列表内。
3. 核对已配置的API密钥状态，确认密钥可正常调用对应服务且权限未发生变更。
4. 查看FastGPT的部署日志，检索与工具加载、注册相关的错误提示信息。

## 解决与验证
目前暂无公开的官方针对性解决方案。验证时可尝试重新配置工作流中的文本加工工具，确认工具可被正常调用且工作流不再触发报错。若问题仍存在，需等待后续版本更新或结合排查出的具体异常点进行修复。
