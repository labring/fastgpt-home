# 为FastGPT配置用户输入内容的二次干预功能的方法

## 现象
当前FastGPT未提供用户输入内容二次干预的配置入口，无法实现对用户提交的问题进行自定义修改。该场景为用户在使用FastGPT时提出的自定义需求，例如无法将用户输入的"你好"调整为"你好 (使用中文回复)"这类经过二次处理的内容。

## 可能原因
需按实际环境确认，未内置用户输入内容二次干预的配置功能与对应的配置入口。当前FastGPT的应用配置模块未集成该类自定义调整的配置项。

## 排查步骤
1. 进入目标FastGPT应用的配置页面，定位至用户问题相关的配置模块。
2. 检查该模块中是否存在用于编辑用户输入内容的文本输入框或变量配置项。
3. 确认当前使用的FastGPT版本是否支持该功能的相关配置，可参考项目官方README文档确认。

## 解决与验证
根据用户提出的需求，需在用户问题配置栏添加文本输入框与变量配置项，实现对用户输入内容的自定义调整。完成配置后，输入测试内容，确认最终传入模型的内容已完成二次干预。例如输入"你好"后，实际传入模型的内容为"你好 (使用中文回复)"。
