# 解决FastGPT工作流中用户输入内容无法传递至后续节点的问题

## 现象
在FastGPT工作流中，无法将用户输入节点的内容直接作为后续节点的输入内容。例如在写作场景中，创意人员提出想法后，无法让用户选择的选题直接传递至下一个节点进行处理。

## 可能原因
现有用户输入节点未支持将自身输入内容作为可输出变量，导致工作流无法直接获取该节点的输入内容并传递至后续节点。该功能需要配合前端界面改造，当前版本未内置相关配置能力。

## 排查步骤
1. 确认已将FastGPT升级至最新版本。
2. 进入工作流编辑页面，选中用户输入节点，查看节点配置面板中的输出相关选项。
3. 尝试将用户输入节点的内容绑定至后续节点的输入参数，验证是否可正常传递内容。
4. 需按实际环境确认是否存在其他配置限制。

## 解决与验证
可通过扩展现有输入节点的功能，将变量加入作为输出实现需求。开发难度较低，但需要修改前端界面代码。具体实现需等待官方更新或自行完成前端改造。验证方式为：配置用户输入节点，将其输入内容设置为可输出变量，在后续节点中引用该变量，运行工作流后确认用户输入内容可正常传递至后续节点。
