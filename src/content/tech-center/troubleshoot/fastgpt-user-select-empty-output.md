# 解决FastGPT用户选择组件导致对话输出为空的问题

## 现象
开启用户选择组件后，若用户未选择继续提问，对话将出现输出为空的情况。

## 可能原因
当前用户选择组件的交互逻辑未适配用户未选择的场景，未针对该情况做合理处理，进而引发输出为空。

## 排查步骤
1. 确认是否开启了用户选择组件功能。
2. 检查对话过程中用户是否未执行选择继续提问的操作。
3. 查看配套的日志截图，确认输出为空的具体报错信息，需按实际环境确认。

## 解决与验证
可通过调整用户选择组件的配置逻辑实现问题解决。
- 若无需强制用户选择，保留聊天框发送按钮，允许正常发起对话。
- 若需强制用户选择，移除聊天框发送按钮，限制对话发起直至用户完成选择。
验证时，开启用户选择组件后，分别测试未选择和已选择的场景，确认输出为空的问题已修复，对话可正常进行。
