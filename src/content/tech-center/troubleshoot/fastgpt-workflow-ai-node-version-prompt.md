# 解决FastGPT知识库工作流AI对话节点持续显示新版本的问题

## 现象
通过“问题分类 + 知识库”新建知识库工作流并进入画布后，AI对话节点始终显示有新版本提示。点击更新按钮后，该提示不会消失，公有云和私有部署4.8.21版本均出现该问题。

## 可能原因
该问题的具体触发原因未在当前反馈中明确，仅能结合复现场景推测可能与工作流节点的版本缓存机制或前端渲染异常相关，具体细节需按实际环境确认。

## 排查步骤
1.  确认当前使用的FastGPT版本，私有部署版本需核对为4.8.21，公有云版本同步确认版本状态。
2.  检查当前工作流中是否仅AI对话节点存在新版本提示，其他节点的状态是否正常。
3.  刷新页面后，再次点击AI对话节点的更新按钮，观察提示是否消失。
4.  重新创建一个新的“问题分类 + 知识库”类型的知识库工作流，验证是否会复现该问题。

## 解决与验证
目前该问题的官方修复方案未在当前反馈中提及。若通过刷新页面、重新创建工作流无法解决该问题，可提交详细日志与复现步骤至官方反馈渠道。验证方式为：完成操作后，AI对话节点不再持续显示新版本提示，点击更新按钮后提示消失且功能正常运行。
