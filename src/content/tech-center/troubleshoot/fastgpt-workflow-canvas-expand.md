# FastGPT 生成内容展开显示的历史需求与 HTML 预览

## 适用场景与历史记录

原议题希望代码、文章或表格像 Canvas 一样展开显示。 原始讨论提交于 2024-11-06，本页按该记录说明症状或需求的适用范围。

## 已有证据与适用范围

官方 HTML 渲染文档提供预览、源码和全屏模式。全屏展示与可编辑 Canvas 是两项能力。

## 排查与复测

1. 明确需要的是全屏阅读、HTML 预览还是可编辑文档画布。
2. 使用一个最小 HTML 代码块测试预览、源码和全屏模式。
3. 按真实交互需求核对沙箱限制、复制和保存行为，再记录尚需补充的编辑功能。

这些检查用于复现和验证同类场景。继续反馈时，提供准确版本、最小输入、预期结果和脱敏日志，并引用原始讨论。
