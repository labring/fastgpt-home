# 解决FastGPT私有部署版工作流问题分类模块无法选择AI模型的问题

## 现象
FastGPT社区版v4.8.22私有部署环境中，工作流内的问题分类模块无法选择AI模型。页面截图显示该模块的模型选择区域无可选模型选项，同一工作流内添加的AI对话模块可正常展示并选择可用AI模型。

## 可能原因
无明确已知触发原因，需结合实际部署环境、配置项及节点关联逻辑排查。

## 排查步骤
1. 确认当前使用的FastGPT版本为社区版v4.8.22私有部署。
2. 进入目标工作流的编辑页面，分别定位问题分类模块与AI对话模块的模型选择配置区域。
3. 对比两个模块的模型选择区域，确认问题分类模块无可选AI模型列表，AI对话模块可正常加载可选模型。
4. 核对当前绑定的API Key状态，确认Key可正常调用对应AI模型。
5. 检查工作流的节点配置权限，确认问题分类模块未被限制模型选择权限。

## 解决与验证
需根据实际排查结果执行对应修复操作。验证操作如下：进入工作流编辑页面，添加问题分类模块，确认可正常选择目标AI模型，保存工作流后测试模块运行状态，确认功能恢复正常。
