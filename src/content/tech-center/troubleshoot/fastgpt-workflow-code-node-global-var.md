# 解决FastGPT工作流代码运行节点无法接收全局变量问题

## 现象
私有部署版本4.8.14的FastGPT中，工作流的代码运行节点运行时，函数无法接收全局变量的输入。

## 可能原因
需按实际部署环境与配置逐一确认，暂无明确通用原因。

## 排查步骤
1. 确认当前使用的FastGPT版本为4.8.14私有部署版本，核对部署包与配置文件的版本匹配情况。
2. 检查全局变量的配置流程，确认变量已正确绑定至代码运行节点的输入参数中。
3. 核对代码运行节点内的函数逻辑，确认变量接收的代码编写无误，无语法或逻辑错误。
4. 查看工作流运行的相关日志，定位变量接收失败的具体环节与报错信息。

## 解决与验证
根据排查得到的具体问题，修复对应配置或代码逻辑后，重新运行工作流，确认函数可正常接收全局变量输入。
