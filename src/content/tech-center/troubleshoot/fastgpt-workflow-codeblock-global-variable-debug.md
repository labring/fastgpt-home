# FastGPT工作流代码块单步调试无法传入全局变量的排错方法

## 现象
FastGPT私有部署v4.8.9版本中，工作流内代码运行块单步调试时，手动输入参数可正常执行，但无法将已配置的全局变量作为入参传入代码块。

## 可能原因
暂未明确具体触发原因，需结合实际部署环境与配置细节排查。

## 排查步骤
1. 确认当前使用的FastGPT版本为v4.8.9私有部署版本。
2. 检查工作流内全局变量的配置与更新流程是否符合官方文档要求。
3. 对比单步调试时手动输入参数与传入全局变量的参数格式差异。
4. 查看工作流执行日志，确认全局变量传递环节的相关报错信息。

## 解决与验证
1. 通过手动输入参数验证代码块本身可正常运行。
2. 重新配置工作流内代码块与全局变量的入参绑定流程，确保变量引用路径正确。
3. 单步调试前确认全局变量已完成更新并可被工作流正常读取。
4. 传入已配置的全局变量作为入参，验证代码块是否可正常执行。
