# 解决FastGPT工作流调试时不显示讯飞星火模型回答的问题

## 现象
使用FastGPT私有部署v4.8.20版本，配置线上讯飞星火generalv3.5模型后，在工作流内进行调试时，界面未显示模型生成的回答内容。点击查看详情按钮，可看到完整的模型响应内容。退出当前工作流页面并重新进入后，调试界面会自动显示出相关回答。

## 可能原因
目前无明确可溯源的官方说明，相关问题需结合实际部署环境与前端渲染流程确认。结合现象推测，问题可能与工作流调试界面的响应展示逻辑存在关联。

## 排查步骤
1.  确认已配置的讯飞星火generalv3.5模型密钥可用，且模型调用权限正常。
2.  在工作流内完成调试后，点击查看详情按钮，确认接口已返回完整的模型响应内容。
3.  退出当前工作流页面后重新进入，再次查看调试结果是否正常显示。
4.  检查FastGPT私有部署版本是否为v4.8.20，确认是否存在版本相关的兼容性问题（需按实际环境确认）。

## 解决与验证
1.  完成工作流调试后，先点击查看详情按钮，确认模型已生成有效响应内容。
2.  退出当前工作流页面并重新进入，再次进入调试界面，查看回答是否正常显示。
3.  若问题反复出现，需结合实际部署环境检查前端渲染逻辑或接口缓存配置（需按实际环境确认）。
验证标准：重新进入工作流后，调试界面可正常显示模型生成的回答内容，无需额外点击查看详情按钮。
