# 为FastGPT工作台HTTP请求工具添加响应头解析功能

## 现象
在FastGPT工作台设计工作流时，使用“通过HTTP请求”工具调用外部HTTP接口后，当前仅支持解析响应体内容并保存为变量，无法提取响应头中的键值信息，导致无法使用响应头携带的必要数据供后续工作流模块调用。

## 可能原因
当前FastGPT工作台的“通过HTTP请求”工具，仅内置了响应体的解析逻辑，未实现响应头的解析与提取功能，无法将响应头的键值保存为可调用变量。

## 排查步骤
1.  进入FastGPT工作台，打开需要调试的工作流项目。
2.  在工作流中添加“通过HTTP请求”工具，配置目标接口的请求参数并执行测试。
3.  查看工具执行后的变量输出面板，确认可调用的变量仅来自响应体解析结果。
4.  检查工具的配置项，确认无响应头解析相关的设置选项。

## 解决与验证
解决方法为在“通过HTTP请求”工具中新增响应头解析配置功能，支持用户指定需要提取的响应头键名，将对应键值保存为可在后续模块调用的变量。验证流程如下：
1.  重新配置“通过HTTP请求”工具，开启响应头解析开关。
2.  输入需要提取的响应头键名，例如Set-Cookie。
3.  重新执行工作流，查看变量输出面板，确认已生成对应响应头键值的变量。
4.  在后续工作流模块中调用该变量，验证数据可用性。例如针对相关接口调用场景，可提取Set-Cookie中的common-nsid值，用于后续接口请求的必要验证。
