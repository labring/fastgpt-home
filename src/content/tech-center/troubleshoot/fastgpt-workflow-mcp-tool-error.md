# 解决FastGPT工作流中高德MCP工具调用无正确结果的问题

## 现象
用户在FastGPT私有部署v4.9.6版本中，创建简单工作流并配置高德MCP工具调用节点后，运行工作流提问如“杭州天气怎么样”，未返回工具调用的预期结果。单独调试该高德MCP服务时，功能可正常运行。本次使用的大模型为Qwen2.5-32B。

## 可能原因
暂未明确具体根因，结合场景推测可能涉及以下环节异常：工作流中工具调用节点的配置与单独调试时不一致；大模型在工作流场景下未正确生成工具调用指令；工作流节点连接顺序不符合要求；MCP服务的配置在工作流环境中未正常加载。

## 排查步骤
1. 确认当前FastGPT版本为v4.9.6私有部署版本，使用的大模型为Qwen2.5-32B。
2. 比对工作流中工具调用节点的配置与单独调试高德MCP服务的配置，确保参数完全一致。
3. 检查工作流节点的连接顺序，确认工具调用节点正确连接在流程开始节点之后。
4. 重新运行工作流，记录提问内容与实际返回结果，与单独调试MCP服务的返回内容进行对比。
5. 查看工作流运行日志，排查是否存在工具调用相关的异常信息。

## 解决与验证
若发现工作流中工具调用节点的配置与单独调试时不一致，修正配置参数使其匹配。若节点连接顺序存在错误，调整工作流节点的连接逻辑。完成调整后重新运行工作流，输入测试提问，验证是否返回符合预期的工具调用结果。若运行日志存在异常，根据日志提示调整对应配置。若问题仍未解决，需按实际环境进一步排查环境加载或大模型触发逻辑。
