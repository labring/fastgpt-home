# 设置FastGPT多工具调用工作流仅保留最后一次工具输出结果

## 现象
用户配置包含3次工具调用的FastGPT搜索匹配工作流后，系统会将3次工具调用的全部输出展示在控制台。从用户提供的截图可见，控制台同时展示了三次工具调用的详细执行日志与输出内容，用户仅希望保留最后一次工具调用的输出作为最终返回结果。

## 可能原因
FastGPT工作流默认会输出所有工具节点的执行输出内容，未配置仅保留最终结果的相关参数，导致所有工具节点的输出均被纳入最终展示内容。

## 排查步骤
1. 登录FastGPT平台，打开需要调整的工作流编辑页面。
2. 在工作流画布中找到用于返回最终结果的节点。
3. 点击该节点查看其配置参数，寻找用于控制工具调用输出展示范围的相关设置。
4. 若未找到明确的对应设置，需按实际环境确认调整方式。

## 解决与验证
若在结果输出节点的配置中找到可限制工具输出的选项，将其调整为仅保留最后一次工具调用的输出内容。保存工作流的配置后，重新触发工作流执行，查看最终输出结果是否仅包含最后一次工具调用的相关内容。若未找到对应配置项，需结合当前工作流的实际配置情况，确认是否需要通过调整工具节点的输出逻辑或结果节点的拼接规则来实现需求。
