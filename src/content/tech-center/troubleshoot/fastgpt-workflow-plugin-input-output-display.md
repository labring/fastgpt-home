# FastGPT私有部署工作流插件输入输出不显示排查

## 现象
FastGPT私有部署版本v4.8.15、v4.8.16中，新建配置了输入与输出项的空白插件后，将该插件添加至新建空白工作流时，插件的输入与输出项无法正常显示。此前版本创建的插件可正常显示输入输出项。

## 可能原因
该异常可能与v4.8.15至v4.8.16版本的插件或工作流模块更新相关，具体根因需结合项目代码变更日志进一步确认。

## 排查步骤
1. 确认当前FastGPT部署版本为v4.8.15或v4.8.16。
2. 检查目标插件是否已完成输入与输出项的配置。
3. 新建空白工作流，添加该插件，观察输入输出项是否正常显示。
4. 对比历史正常版本的代码逻辑，确认版本更新前后的差异。

## 解决与验证
需根据实际版本情况选择对应修复方案。验证方式为：新建插件并配置输入与输出项，将其添加至工作流后，确认输入输出项正常显示。
