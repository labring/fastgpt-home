# 解决FastGPT工作流回退后多输入节点流程中断问题

## 现象
FastGPT工作流在执行过一次回退线路后，后续遇到带有多个输入箭头的节点时，流程会直接中断。无回退的场景下工作流运行正常。用户复现后发现，选过返回上一步后，后续选择下一步会直接中断，预期无论选择何种路线，流程都能走到最终步骤。

## 可能原因
暂未明确具体技术成因，需结合FastGPT的运行日志与工作流节点的流转逻辑进行排查确认。

## 排查步骤
1.  按照用户提供的复现流程构建测试工作流，执行一次回退操作后，进入带有多个输入箭头的节点，记录流程中断现象。
2.  对比无回退操作的工作流运行情况，确认中断仅在回退后触发。
3.  查看FastGPT的运行日志，提取与节点流转、回退逻辑相关的信息，定位异常点。
4.  核对工作流中各节点的连接配置，确认多输入箭头节点的输入源设置是否正确。

## 解决与验证
目前暂无公开的官方修复方案，可尝试以下操作缓解或解决问题：1. 重置工作流的流转状态，重新导出并导入工作流配置；2. 调整工作流结构，避免在回退操作后立即使用带有多个输入箭头的节点。验证方式：重新运行包含回退与多输入节点的工作流，确认流程可正常执行至最终步骤。
