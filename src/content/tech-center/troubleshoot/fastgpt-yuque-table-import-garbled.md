# 解决FastGPT私有部署中语雀表格文档导入乱码的问题

## 现象
在FastGPT私有部署版本V4.14.7中，新建第三方语雀知识库并导入语雀表格格式文档后，文档内容显示为乱码。具体表现为：知识库分块预览界面内容乱码，关联该知识库的聊天Agent无法获取到正确的文档答案，附带的截图也可佐证该乱码问题。

## 可能原因
当前未明确具体触发该问题的根源，需结合实际部署环境、语雀表格文档的编码格式、FastGPT文档解析配置等信息进一步确认排查。

## 排查步骤
1. 确认当前使用的FastGPT版本为私有部署V4.14.7，匹配问题触发的环境条件。
2. 重新创建语雀第三方知识库，导入同一份原语雀表格文档，验证乱码问题是否复现。
3. 查看原语雀表格文档的原始编码格式，确认是否符合通用编码标准。
4. 检查知识库导入时的参数设置，确认使用了默认配置未进行自定义修改。
5. 查看FastGPT的运行日志，检索与文档解析、字符编码相关的报错信息。

## 解决与验证
若排查发现问题由文档编码不兼容导致，可将语雀表格文档转换为UTF-8编码后重新导入知识库。验证方式为：重新导入转换后的文档，确认分块预览可正常显示文档内容；创建关联该知识库的聊天Agent，咨询文档内的相关信息，确认可获取正确答案。若问题由部署环境的编码配置异常导致，需按实际环境调整相关配置。
