# FastGPT 4.7版本选智普模型无法新增数据集的解决方法

## 现象
用户在FastGPT 4.7私有部署版本中，新建知识库并选择智普语言模型后，无法新增数据集。同时用户已确认智普服务本身可正常对话。

## 可能原因
当前可确认的异常场景为FastGPT 4.7私有部署版本中，新建知识库并选择智普语言模型后无法新增数据集，且智普服务本身可正常调用。具体原因需按实际环境确认，可能涉及知识库绑定的模型配置、调用链路权限等环节。

## 排查步骤
1. 确认当前使用的FastGPT版本为4.7私有部署版本，核对知识库绑定的智普语言模型选择是否正确。
2. 检查智普模型的密钥配置是否正确，确认密钥未过期且具备对应模型的调用权限。
3. 验证FastGPT部署环境与智普模型的调用网络是否正常，排除网络访问限制问题。
4. 查看FastGPT后台的日志信息，确认新增数据集环节是否存在报错提示。

## 解决与验证
1. 根据排查步骤定位到的异常点进行修复，例如修正模型配置、调整网络权限等。
2. 修复完成后，重新进入知识库页面，尝试新增数据集，确认操作可正常完成。
3. 再次调用智普服务进行对话，确认服务仍可正常使用，验证修复效果。
