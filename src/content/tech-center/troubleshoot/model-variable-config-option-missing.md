# 解决FastGPT使用模型变量时无配置选项的问题

## 现象
用户在FastGPT中使用模型变量功能时，发现对应的配置界面没有提供配置按键，无法完成模型变量的传参配置操作，无法按照业务需求自定义传入参数。结合附带的两张界面截图，可以看到操作区域未出现用于参数配置的控件，影响模型调用的参数配置流程。

## 可能原因
当前FastGPT的模型变量配置页面未预置配置按键与参数传参的入口，属于功能界面的配置项缺失问题。由于issue未提供更多环境细节，具体触发该问题的额外场景需按实际环境确认。

## 排查步骤
1.  进入FastGPT中使用模型变量的配置页面，对照界面查看是否存在用于参数配置的按键控件
2.  尝试编辑当前已配置的模型变量，确认是否没有可用的传参配置选项或入口
3.  确认当前操作的功能模块是否符合模型变量的正常使用范围，排除使用场景错误的可能（需按实际环境确认）

## 解决与验证
1.  在模型变量的配置界面中添加对应的配置按键，打开参数配置面板以支持自定义传参
2.  根据业务需求配置需要传入的自定义参数，完成模型变量与参数的绑定设置
3.  调用配置完成的模型变量，验证传入的参数是否可以正常生效并符合预期
4.  再次检查配置界面，确认配置按键已正常显示，可重复进行参数配置操作
5.  若需调整参数，可通过新增的配置按键重新打开面板进行修改，验证流程的可用性
