# 解决FastGPT工作流导出导入后AI模型变量引用丢失问题

## 现象
用户使用FastGPT公有云版本时，在工作流内的AI对话节点配置AI模型的全局变量引用后，执行导出配置再导入的操作，该AI模型的变量引用配置会丢失，导入后该字段显示为空。

## 可能原因
暂未明确具体技术根因，需结合实际部署环境的代码逻辑进一步排查确认。

## 排查步骤
1. 登录FastGPT平台，进入出现配置丢失问题的工作流编辑页面
2. 确认该工作流中已创建全局变量，且AI对话节点的AI模型字段已正确选择全局变量引用
3. 执行导出配置操作，将配置内容复制到剪贴板或保存为文件
4. 执行导入配置操作，粘贴或上传之前导出的配置内容并保存
5. 再次进入该AI对话节点的配置页面，检查AI模型的变量引用配置是否仍为空，验证问题是否存在

## 解决与验证
目前官方暂未发布针对该问题的正式修复版本。临时规避方案为：在导入配置后，重新进入AI对话节点的配置页面，手动重新配置AI模型的全局变量引用。验证方式为：重新配置完成后，再次执行导出导入流程，确认AI模型的变量引用配置未再次丢失。
