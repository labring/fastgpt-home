# FastGPT智能体绑定与调用已发布技能的操作说明

FastGPT的智能体应用支持集成已发布的自定义技能，通过该能力可让智能体获得技能的执行权限，实现更丰富的业务逻辑扩展。需要注意的是，目前仅智能体应用支持直接绑定技能，简易应用及工作流暂不支持该配置。

## 技能绑定操作步骤
1. 进入需要集成技能的智能体应用编辑页面；
2. 在左侧配置面板中找到"关联 Skill"配置项；
3. 点击右侧的"选择"按钮，在弹出的选择窗口中勾选已发布的正式版本技能。
同时需遵循以下注意事项：技能代码需要在安全隔离的环境中运行，因此当关联技能时，系统会自动开启"虚拟机"；且在已关联技能的状态下，无法关闭虚拟机。

## 智能体调用与调试机制
绑定完成后，智能体即可获得该技能的执行能力，支持多技能安全注入：一个智能体可同时绑定多个不同的技能，在沙盒（虚拟机）启动时，所有已绑定技能的代码和配置都会被自动注入并部署到沙盒工作区中，各技能间彼此独立、互不冲突。
智能自动调用的前提是使用的模型足够智能，此时无需手动命令智能体运行代码，AI会根据用户的输入自动判断是否需要调用该技能，并在后台虚拟机中安全执行代码。
用户还可点击聊天气泡底部的"虚拟机"按钮或右上角的电脑图标，在弹出的侧边栏中直接查看虚拟机内当前最新的所有文件内容和代码状态。
