# FastGPT Agent V2辅助生成与调试功能使用说明

FastGPT Agent V2的辅助生成与调试功能，包含辅助生成和调试预览两大模块，其中辅助生成功能仅商业版开放，当前感知范围有限，仍处于优化阶段。

## 辅助生成操作步骤
进入Agent V2配置页面的“辅助生成”选项卡，在对话框输入自然语言诉求，例如“我想要一个能够分析用户上传的Excel销售数据并直接生成可视化图表的助理。AI协作助手会自动润色并生成结构化System Prompt，设定合理约束与引导规则，智能筛选推荐适合当前任务的外部工具或虚拟机命令，同时推荐适配的知识库以补充背景知识。助手生成最佳方案后，系统会自动将推荐的提示词、工具列表、关联知识库及虚拟机开关状态同步并填充到左侧配置面板，全程无需手动二次配置。

## 调试预览功能使用
调试预览提供实时对话测试环境，支持通用调试与虚拟机调试。通用调试功能包括：点击调试窗口右上角的“重开对话”按钮，一键清空当前聊天历史；每条AI回复气泡下方的辅助操作栏，包含复制、朗读、标注（可将问答数据标注并保存至指定知识库、重试回复、展开运行详情树状决策链路，该链路完整记录本次交互的AI思考历程、内部参数动作、工具调用日志，同时展示请求Id、模型型号及精准积分消耗；界面还会直观展示响应耗时；若AI启动复杂任务规划，会流式渲染计划步骤卡片，通过颜色区分进行中、已完成、待处理、已阻塞的执行节点状态，遇到阻塞时可根据卡片提示优化System Prompt或排查工具配置。虚拟机调试的专属能力请参考虚拟机文档。

辅助生成与调试功能仅支持商业版，且当前感知范围有限，使用时需基于左侧面板已配置的模型、知识库与工具。
