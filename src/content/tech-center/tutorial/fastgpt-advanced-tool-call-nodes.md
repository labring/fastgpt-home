# 详细介绍FastGPT高级编排中工具调用节点的配置与使用方法

高级编排场景下，工具调用节点的基础连接与配置逻辑如下。拖动工具调用的连接点时，可用工具的头部会出现菱形标识，可将该菱形与工具调用模块底部的菱形完成连接。完成连接后，被关联的工具会自动分离工具输入与普通输入，支持编辑工具的介绍字段，通过调整介绍内容可精确工具的调用时机。工具调用调试存在不确定性，建议先选择少量工具完成调优后，再逐步扩展工具配置，避免因配置复杂导致调试困难。

#### 标准配置步骤
1. 进入FastGPT高级编排编辑界面，定位工具调用模块与待关联的工具节点。
2. 按住工具调用节点的连接点进行拖动，待目标工具头部出现菱形标识后，将该菱形与工具调用模块底部的菱形完成连接。
3. 选中已完成连接的工具节点，编辑其介绍字段的内容，调整描述以匹配预期的调用时机。
4. 完成单工具或少量工具的配置后，进行调试验证，确认逻辑无误后再添加更多工具节点。

工具调用节点的核心用途分为两种默认场景。默认配置下，工具调用节点在确定调用工具后，会将工具运行的完整结果返回给AI，由AI对结果进行总结后输出。若业务场景中无需AI进行进一步的总结输出，可将工具调用节点接入工具流程的末尾。例如，在执行知识库搜索后接入HTTP请求节点，此时搜索得到的结果不会被返回至工具调用节点供AI进行总结处理。
