# 配置FastGPT Agent的提示词功能与关联设置

## 提示词的核心作用
提示词用于定义FastGPT Agent的核心人设、工作目标和具体规则，是Agent运行逻辑的核心配置项。当前的提示词编辑器支持富文本编辑模式，同时提供`@`快捷唤起功能，可快速绑定工具等上下文能力，简化配置流程。编辑器界面包含两类典型可视化展示场景，分别对应`@`快速绑定工具的操作界面，以及完整的富文本编辑界面。

## 提示词编辑器功能细节
编辑器支持富文本编辑，可直接输入各类格式化文本内容，无需依赖纯文本格式。通过输入`@`符号，可快速唤起工具绑定选项列表，无需手动编写复杂的上下文绑定代码，降低配置的技术门槛。配套的两张截图分别展示了`@`唤起绑定的操作场景，以及富文本编辑的完整编辑区域，帮助用户直观掌握编辑器的使用方法。富文本编辑功能支持常规的文本排版操作，可直观调整内容结构，提升提示词的可读性与规范性，让Agent的指令集更加清晰易懂。

## 通用模型参数配置指引
当需要配置对话大模型、回复长度、推理内容展示等通用模型参数时，需参考对应文档中的AI配置说明进行操作。该参考文档覆盖了Agent运行所需的各类通用模型相关配置项，确保Agent的输出符合预期的格式与效果。这些通用参数的调整会直接影响Agent的回答质量与交互体验，因此需根据实际使用场景进行合理配置。
