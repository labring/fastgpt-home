# FastGPT平台AI智能体技能的设计原理与使用说明

## 什么是AI智能体技能

AI智能体的“技能”是可持久保存、可复用的模块化专业流程与能力包。在日常AI应用中，若需要反复执行同类复杂任务，可将固定的执行逻辑与格式要求封装为技能。例如当你需要AI核对两份复杂财务表格并生成分析报告时，只需一次性将计算代码与报告模板放入技能中，后续对话中直接传入表格，AI即可自动在后台调用该技能完成精准计算与格式整理。

## 核心设计逻辑

从AI智能体的通用设计框架来看，可分为三个核心层面：大脑负责规划与推理，即大模型本身；工具提供单纯的动作接口，类似AI的手脚；技能则封装完整的做事章法与专业逻辑，是包含说明文档与执行代码的模块化包。若将工具比作工具箱中的螺丝刀，技能就相当于家具组装手册，AI可自动从技能库调取对应手册，在隔离沙箱中运行代码完成复杂任务。

## 快速使用与调试步骤

1. 进入应用构建的技能管理页面，点击新建或导入技能；
2. 在隔离沙箱中编写技能的说明文档与逻辑代码，明确技能的使用场景与执行逻辑；
3. 使用平台提供的在线调试环境，该环境集成了文件管理、代码编辑器与交互式终端，左侧配有智能体调试面板，支持热重载实现即改即生效，可在发布前充分调试排错；
4. 确认调试无误后，点击发布按钮保存正式版本，此时改动才会正式应用到生产环境的智能体与工作流中。

需注意两个核心要点：一是编辑区域修改的代码仅在调试区即时生效，不会直接影响生产环境；二是长期闲置的技能会被系统自动归档休眠，休眠期间不会产生运行计费，再次调用或编辑时会自动拉起沙箱复原。
