# 在FastGPT智能体应用中集成与调用已发布的技能

本功能用于将已发布的自定义技能集成到FastGPT智能体应用中，实现AI的工具调用能力。需要注意的是，该功能仅支持智能体应用，简易应用及工作流暂不支持集成技能。技能代码需在安全隔离环境运行，当你关联技能时，系统会自动开启虚拟机，且在已关联技能的状态下，无法手动关闭虚拟机。

## 技能绑定配置步骤
1. 进入目标智能体应用的编辑页面。
2. 在左侧配置面板中，找到"关联Skill"配置项。
3. 点击右侧的"选择"按钮，在弹出的选择窗口中，勾选你已经发布好的正式版本技能。

## 技能调用与状态查看
绑定完成后，智能体即可获得该技能的执行能力。支持多技能安全注入：一个智能体可同时绑定多个不同的技能，在沙盒（虚拟机）启动时，所有已绑定技能的代码和配置会自动注入并部署到沙盒工作区，各技能间彼此独立、互不冲突。在使用的模型足够智能的前提下，AI会根据用户输入自动判断是否需要调用技能，并在后台虚拟机中安全执行代码。你还可以点击聊天气泡底部的"虚拟机"按钮，或右上角的电脑图标，在弹出的侧边栏中查看虚拟机内当前最新的所有文件内容和代码状态。
