# FastGPT智能体调用技能的配置与操作说明

## 技能绑定后的核心能力
绑定完成后，智能体即可获得该技能的执行能力。一个智能体支持同时绑定多个不同的技能。在沙盒（虚拟机）启动时，所有已绑定技能的代码和配置都会被自动注入并部署到沙盒工作区中，各技能间彼此独立、互不冲突，不会出现运行冲突或资源抢占的问题。

## 智能自动调用规则
在使用的模型足够智能的前提下，无需手动命令智能体运行代码。AI会根据输入内容，自动判断是否需要调用该技能，并在后台虚拟机中自动安全地执行代码。

## 虚拟机文件查看操作步骤
1. 打开智能体对应的聊天会话界面。
2. 点击聊天气泡底部的「虚拟机」按钮，或点击界面右上角的电脑图标。
3. 在弹出的侧边栏中，即可直接查看虚拟机内当前最新的所有文件内容和代码状态。
配套的操作示例截图路径为`/imgs/agent_chat_vm_files.png`，可用于对照界面入口位置。
