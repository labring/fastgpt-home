# FastGPT Agent虚拟机功能的启用与使用说明

## 功能概述
当启用虚拟机选项开启后，系统为每个对话会话动态预置并绑定专用沙箱容器。该容器支持三类核心能力：
- 执行动态代码：通过代码执行器运行Python、Node.js甚至Shell脚本，自主完成复杂计算或数据处理。
- 读写本地文件：在独立的`/workspace`目录下创建、修改和读取文件，可用于生成图表、处理上传的CSV/Excel电子表格等。
- 环境自定义配置：可通过关联SKILL包，或配置启动脚本，动态准备专属应用的运行环境。其中启动脚本为虚拟机拉起后且AI正式开始前自动在后台执行的Shell命令，可用于安装特定软件源、Python依赖包或系统级工具。

## 配置流程
启用虚拟机需完成基础配置与可选的环境自定义配置。首先，进入目标Agent的配置页面，找到启用虚拟机的配置项，勾选该选项即可完成基础启用。如需自定义运行环境，可关联SKILL包，或填写启动脚本内容，指定需要在虚拟机初始化阶段执行的Shell命令。配置生效后，每个对话会话将自动绑定专属沙箱容器，支持前述全部功能。

## 功能使用说明
启用虚拟机后，Agent可直接调用代码执行器运行指定脚本，在`/workspace`目录下进行文件读写操作，或通过配置的启动脚本完成环境初始化。所有运行操作均依托专属沙箱容器执行。
