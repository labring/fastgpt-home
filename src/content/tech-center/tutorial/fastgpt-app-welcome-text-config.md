# 详细完整说明在FastGPT应用中配置对话开场白及相关快捷问题的具体操作步骤

# 功能概述
对话开场白是FastGPT应用每次开启新对话时，由系统自动发送的欢迎内容，主要用于向用户介绍应用可处理的问题范围、展示核心能力，或提供常用交互入口。该功能支持标准Markdown语法，可通过标题、列表、链接、加粗等格式优化展示效果；同时支持使用`[快捷问题]`特殊格式配置可点击的交互按钮，用户点击后，系统会将按钮对应的预设内容作为用户输入直接发送至对话流程中，无需手动录入。

# 配置步骤
配置对话开场白需按照以下流程操作：
1.  登录FastGPT平台，进入目标应用的编辑页面；
2.  在页面中找到「对话开场白」配置项，点击其右侧的设置按钮，进入内容编辑界面；
3.  在编辑框中输入开场白内容，可结合Markdown语法和快捷问题格式进行配置；
4.  完成编辑后保存配置，后续新发起的对话将自动展示配置的开场白与快捷问题按钮。

以下是一个最小配置示例：
```markdown
你好，我可以帮你查询产品信息和售后政策。
[如何申请售后？]
[产品支持哪些使用场景？]
```
该示例中，开场白先明确说明应用的服务范围，随后配置了两个高频使用场景的快捷问题按钮，用户点击即可直接发送对应提问。

# 使用建议
配置时需遵循以下原则：
1.  开场白内容需简短明确，优先向用户说明应用可解决的核心问题，避免冗长描述；
2.  快捷问题建议覆盖高频使用场景，单次配置数量不宜过多，防止用户因选项过多难以选择；
3.  若应用要求用户按照固定格式输入内容，可在开场白中给出明确的输入示例，帮助用户快速掌握交互规则。
