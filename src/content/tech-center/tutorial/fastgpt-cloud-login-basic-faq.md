# FastGPT云服务账号登录与基础使用常见问题解答

本页整理了FastGPT云服务的账号登录与基础使用类常见问题，帮助用户快速解决使用中的基础障碍。

## 账号与登录常见问题
FastGPT云服务分为中国大陆版与国际版，两个版本的账号体系互不互通。中国大陆版的官方访问地址为`https://fastgpt.cn`，支持微信、手机号两种登录方式；国际版的官方访问地址为`https://fastgpt.io`，支持邮箱、Google、GitHub三种登录方式，且在2024年9月前可通过手机号完成账号注册。若用户曾使用过对应版本的服务，但后续出现登录失败的情况，可优先尝试切换至另一版本的访问地址进行登录测试。若通过版本切换仍无法解决登录问题，可前往飞书社群联系管理员获取针对性协助。

## 基础功能常见问题
目前FastGPT云服务暂不支持接入用户自行部署的模型，所有应用仅可使用官方提供的统一模型完成运行。该功能暂未开放，用户需使用官方提供的模型资源开展应用构建与对话服务。

## 登录异常标准化处理步骤
若遇到登录异常问题，可按照以下步骤排查处理：
1. 确认访问地址与登录方式匹配：中国大陆版用户需访问`https://fastgpt.cn`，使用微信或手机号完成登录；国际版用户需访问`https://fastgpt.io`，使用邮箱、Google或GitHub完成登录，2024年9月前可通过手机号完成注册。
2. 若首次登录失败，先切换至另一版本的访问地址重试登录操作。
3. 若经过上述两步仍无法正常登录，可直接前往飞书社群联系管理员反馈问题，获取进一步协助。
