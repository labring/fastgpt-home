# FastGPT四类核心应用的快速搭建与配置方法

本文面向FastGPT技术使用者与选型人员，梳理了对话Agent、知识库+对话Agent、工作流、Agent V2四类核心应用的配置逻辑与关键要点。不同应用适配不同业务场景：对话Agent适用于轻量问答、内容生成等轻量场景，核心配置需聚焦模型的中文表达能力与格式遵循性；知识库类应用需绑定专属业务资料，确保回答基于指定内容；工作流可实现多步骤任务编排；Agent V2支持智能数据分析类复杂任务。配置时可复用示例参数与Prompt，正式落地时替换为自身业务资料。

### 对话Agent快速配置步骤
1. 进入工作台点击新建，选择对话Agent，应用名称填写为**企业邮件撰写助手**。
2. 进入配置页后，在AI配置中选择`GLM-5.1`模型（可替换为当前环境已配置的其他可用模型）。
3. 将以下Prompt写入提示词模块：
```
你是一个企业邮件撰写专家，帮助员工撰写专业、清晰、得体的工作邮件。
输出格式：
- **主题行** ：简洁明确
- **称呼** ：根据收件人关系选择“尊敬的 XX 总”或“Hi XX”
- **正文** ：三段式（背景 → 核心内容 → 行动项）
- **落款** ：署名、职位、部门
规则：
- 正文控制在 200-500 字
- 行动项和待办用项目符号列出
- 涉及薪资、人事、法律等敏感内容时，提醒用户谨慎发送
- 不确定收件人关系时使用中性礼貌语气
```
4. 添加Email邮件发送工具，进入工具配置页填写QQ邮箱SMTP参数：
   - SMTP服务器地址：`smtp.qq.com`
   - SMTP端口：`465`，启用SSL
   - SMTP用户名：个人邮箱地址
   - SMTP密码：邮箱授权码（需参考官方授权码获取教程）
5. 设置对话开场白：`你好！我是邮件撰写助手 📧 请告诉我：收件人是谁？邮件目的是什么？需要包含哪些关键信息？我会帮你生成一封专业、得体的邮件。`
6. 验证时可测试三类输入：信息完整的邮件需求、缺少收件人或目的的模糊需求、包含敏感信息的需求，确认助手可生成合规邮件并主动追问缺失信息、提示敏感内容风险。

知识库+对话Agent类应用需先导入民法典、公司制度等指定文档作为知识库，配置对话模型与向量模型，确保AI回答优先引用检索到的资料内容。工作流应用可编排内容审核与自动改写流程，Agent V2则需绑定Excel/CSV示例文件实现智能数据分析。所有配置项均可根据业务场景替换调整，适配实际落地需求。
