# FastGPT四类核心应用的快速搭建与效果验证指南

本页面向FastGPT使用工程师与技术选型人员，基于官方快速上手小节，提供四类核心应用的搭建与验证流程。搭建前需提前准备可用的AI模型（例如GLM-5.1等已配置模型）、知识库测试文件（如民法典、公司制度、产品手册等）、邮箱SMTP授权码（用于邮件工具测试）、Excel或CSV示例文件（用于数据分析测试）。

### 核心应用类型与适配场景
本页覆盖四类核心应用，分别适配不同业务场景：
1.  对话Agent：企业邮件撰写助手，适配企业内部标准化邮件生成需求。
2.  知识库+对话Agent：民法典问答助手，适配基于结构化文档的精准问答需求。
3.  工作流：内容审核与自动改写，适配文本合规校验与内容优化需求。
4.  Agent V2：智能数据分析Agent，适配表格数据自动化分析需求。
阅读时需重点关注三类内容：应用适配的问题类型、关键配置的设计逻辑、验证时需观察的效果表现。官方提供的参数与Prompt可作为初始复用起点，正式落地时可替换为自有业务资料、审核规则、通知渠道与数据文件。

### 快速配置与验证步骤
1.  模型配置：调用GLM-5.1等已配置的AI模型，确保模型可正常调用，无配置异常提示。
2.  知识库搭建：上传民法典等测试文件至平台，配置文档匹配规则，验证检索功能可返回对应文档片段。
3.  对话Agent搭建：关联已配置模型，输入初始Prompt，测试生成符合要求的企业邮件内容。
4.  工作流搭建：添加内容审核节点与自动改写节点，设置审核规则，提交测试文本验证审核结果与改写效果。
5.  Agent V2搭建：上传Excel或CSV示例文件，配置数据分析指令，运行后查看生成的分析结果。
若测试邮箱工具，需提前准备邮箱SMTP授权码完成通知渠道配置。
