# 讲解FastGPT的核心能力、优势与基础使用方法

### 核心能力与优势
FastGPT是基于大语言模型的AI Agent应用开发平台，集知识库问答、可视化工作流、Agent编排、工具调用和技能扩展于一体，可帮助开发者和业务人员快速构建专属AI应用。其核心优势包括：一是简单灵活，提供丰富功能模块，通过拖拽即可搭建个性化AI应用，零代码也能实现复杂业务流程；二是全流程数据智能化，从数据导入、预处理到知识匹配再到智能问答均实现自动化，配合可视化工作流设计可打造专业级AI应用；三是开源开放，支持二次开发，通过标准API即可快速接入外部系统，无需修改源码，同时支持多款主流大模型。

### 基础配置步骤
1. 登录FastGPT平台：根据所在区域选择对应入口，国际版访问https://fastgpt.io，中国大陆版访问https://fastgpt.cn；
2. 导入业务数据：支持导入各类文档及数据，系统将自动完成知识结构化处理；
3. 编排应用流程：通过拖拽式可视化界面添加功能节点，按需定制业务流程，无需编写代码；
4. 完成系统集成：通过标准API接口对接外部平台，严格遵循官方接口规范即可完成接入，无需修改源码。

### 使用边界与注意事项
FastGPT的数据智能解析能力可智能处理PDF文档的复杂结构，保留图片、表格和LaTeX公式，自动识别扫描文件并将内容转换为清晰的Markdown格式，同时支持图片自动标注和索引，确保知识在问答中完整准确呈现。使用过程中需注意：工作流编排需匹配实际业务需求，避免添加冗余功能节点；API集成需严格对齐官方接口要求，否则可能出现调用错误。当需要实现超出现有功能节点覆盖的自定义逻辑时，可通过二次开发完成适配。
