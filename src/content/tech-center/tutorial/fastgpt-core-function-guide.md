# 为工程师提供FastGPT核心功能使用与配置参考

## 核心功能与能力概述
FastGPT是基于大语言模型的AI Agent应用开发平台，集成知识库问答、可视化工作流、Agent编排、工具调用和技能扩展能力，面向开发者与业务人员快速搭建专属AI应用。其核心优势包括三点：一是简单灵活，通过拖拽丰富功能模块即可搭建个性化AI应用，零代码即可实现复杂业务流程；二是数据智能全流程，覆盖数据导入、预处理、知识匹配到智能问答的自动化处理，搭配可视化工作流设计可打造专业级应用；三是开源开放，支持通过标准API快速接入，无需修改源码，兼容主流大模型并持续迭代。
可实现的功能涵盖五大方向：全能知识库可导入各类文档并自动结构化处理，支持多轮上下文智能问答；可视化工作流通过拖拽式界面搭建复杂业务流程，拥有丰富功能节点组件；数据智能解析可处理PDF复杂结构，保留图片、表格和LaTeX公式，自动识别扫描文件并转换为Markdown格式，同时支持图片自动标注与索引；工作流编排可基于Flow模块设计查询数据库、库存等复杂业务流程；API集成完全对齐OpenAI官方接口，可一键接入多平台。

## 快速配置与接入步骤
1. 访问对应版本的FastGPT平台：国际版访问`https://fastgpt.io`，中国大陆版访问`https://fastgpt.cn`；
2. 创建知识库集合，导入所需文档数据，系统将自动完成结构化处理；
3. 进入工作流编辑页面，通过拖拽功能节点搭建业务流程，按需定制编排逻辑；
4. 开启应用的API权限后，可通过对齐OpenAI官方接口的标准API接入自有业务系统，或一键接入企业微信、公众号、飞书、钉钉等平台。

## 功能边界与注意事项
需注意，FastGPT的工作流编排仅支持基于Flow模块的可视化操作，暂不支持非可视化的代码编写；API集成需严格遵循OpenAI官方接口格式，否则会出现调用异常；数据解析仅支持处理常规文档及数据，暂不支持加密文档的自动处理。此外，平台支持的二次开发需通过标准API完成，不建议直接修改源码。
