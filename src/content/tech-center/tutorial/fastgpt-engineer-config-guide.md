# 面向工程师与选型人员的FastGPT功能与配置说明

FastGPT是基于大语言模型的AI Agent应用开发平台，面向开发者与业务人员，集成知识库问答、可视化工作流、Agent编排、工具调用和技能扩展于一体，可帮助技术人员快速搭建专属AI应用。

## 核心功能与特性
FastGPT具备五大核心能力与多项优势。核心能力包括：一是全能知识库，可导入各类文档及数据，自动完成知识结构化处理，支持多轮上下文理解的智能问答，提供完善的知识库管理体验，同时支持知识库搜索方案与参数配置；二是可视化工作流，通过直观的拖拽式界面设计，零代码即可搭建复杂业务流程，搭配丰富的功能节点组件满足多样业务需求；三是数据智能解析，可灵活处理导入数据，支持PDF复杂结构、保留图片、表格与LaTeX公式，自动识别扫描文件并转换为Markdown格式，同时支持图片自动标注与索引，确保知识可被完整准确检索与应用；四是工作流编排，基于Flow模块可设计复杂问答与业务流程，如查询数据库、库存查询等场景；五是API集成能力，完全对齐官方接口，可快速接入多类业务平台。其优势体现在简单灵活、数据智能、开源开放易于集成三个方面，支持通过标准API快速接入，无需修改源码，适配主流大模型。

## 快速配置示例步骤
1. 登录FastGPT平台，进入工作区创建知识库集合；
2. 上传待处理的文档或数据，平台将自动完成预处理、结构化与知识匹配；
3. 在工作流编辑器中拖拽功能节点，按需编排业务流程；
4. 配置API接入，对齐官方接口即可完成对接，支持快速接入多类业务平台。
