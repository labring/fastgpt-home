# FastGPT循环运行节点的参数配置与输出说明

循环运行节点是FastGPT工作流中的迭代执行组件，用于实现批量重复的逻辑流程运行，也用于在工作流中实现重复执行内部流程的功能，其参数配置与输出规则是保障执行稳定性与结果可用性的核心部分，可规范迭代过程的异常处理逻辑，并支持自定义结果的输出格式。该节点的配置包含错误信息与自定义输出两类关键项，可分别处理异常反馈与自定义结果输出的需求。

## 参数配置
| 参数           | 类型     | 说明                                                                                                                                         |
| :------------- | :------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| **错误信息**   | `string` | 循环执行异常中断时的错误信息。                                                                                                               |
| **自定义输出** | 任意类型 | 可在节点的**输出区域**输入变量名来新增自定义输出，并为其绑定内部节点的变量引用。该节点运行结束时，输出最后一轮迭代（或中断退出时）的值。 |

## 输出规则
循环运行节点的输出结果遵循明确的逻辑。当节点正常完成所有迭代流程后，将输出最后一轮迭代中绑定的变量值。若循环执行过程中出现异常并触发中断时，将输出预先配置的错误信息。自定义输出需通过节点输出区域完成配置，输入变量名并绑定内部节点的变量引用，可实现灵活的结果提取与输出配置，适配多种业务场景，满足不同的结果输出需求。
