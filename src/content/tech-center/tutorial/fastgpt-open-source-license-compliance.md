# FastGPT开源协议的使用边界与合规注意事项

### 开源协议基础与允许范围
FastGPT 项目基于 Apache License 2.0 许可开源，整体的权利与限制除附加条款外，均遵循该协议的完整内容，可参考其官方完整版本获取详细说明。本产品的交互设计受到外观专利保护。FastGPT 允许商业化使用，包括作为其他应用的“后端即服务”，或作为应用开发平台提供给企业。

### 需申请商业许可的场景
存在两种场景必须联系作者获取商业许可：其一为多租户 SaaS 服务，除非获得 FastGPT 的明确书面授权，不得使用 fastgpt.io 的源码来运营与 fastgpt.io 服务类似的多租户 SaaS 服务；其二为使用过程中，不得移除或修改 FastGPT 控制台内的 LOGO 或版权信息。

### 合规咨询与申请流程
如果您的商用场景属于需获取许可的范畴，可按照以下步骤操作：1. 确认自身场景类型，明确属于多租户 SaaS 服务或涉及修改移除版权标识；2. 发送电子邮件至 dennis@sealos.io 咨询许可相关事宜。作为项目贡献者，需同意将贡献的代码用于生产者调整开源协议（更严格或更宽松形式），以及用于商业目的如 FastGPT 的云服务。
