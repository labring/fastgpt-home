# FastGPT社区版开源协议条款与授权说明

## 开源协议基础说明
FastGPT 社区版项目基于 Apache License 2.0 许可开源，同时存在两项附加使用条件。首先，项目允许商业化使用，包括将其作为其他应用的“后端即服务”部署，或作为应用开发平台提供给企业使用。但存在例外情况：若使用 fastgpt.io 的源码运营与 fastgpt.io 服务类似的多租户 SaaS 服务，必须获得 FastGPT 的明确书面授权，否则不得开展此类业务。其次，在使用 FastGPT 的过程中，不得移除或修改 FastGPT 控制台内的 LOGO 或版权信息，需保留原有标识内容。

## 贡献者使用约定
作为 FastGPT 项目的代码贡献者，需同意两项使用规则：一是项目生产者有权将开源协议调整为更严格或更宽松的形式；二是贡献者提交的代码可被用于商业目的，包括 FastGPT 的云服务。除上述约定外，所有其他权利和限制均遵循 Apache License 2.0 的完整条款，如需获取详细信息可参考 Apache License 2.0 的官方完整版本。此外，本产品的交互设计受外观专利保护，版权归属为 © 2023 Sealos。

若你的使用场景符合需要额外授权的情况（如运营多租户 SaaS 服务），请通过电子邮件 dennis@sealos.io 联系咨询许可事宜。对于其他合法的商业化使用场景，无需额外联系即可正常开展业务。
