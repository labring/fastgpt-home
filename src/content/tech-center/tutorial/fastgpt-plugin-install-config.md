# FastGPT插件系统的安装、管理与开发配置说明

## 插件系统核心概念与设计目标
FastGPT插件系统适用于v1.0.0及以上版本，原系统插件存在迭代受限、社区贡献门槛高、自定义插件维护复杂等问题，重构后实现了解耦模块化、统一协议、运行隔离、降低开发复杂度、插件市场分发五大设计目标。核心概念包括：插件为独立可复用功能模块，可分为工具、模型预设等类型；插件包为.pkg格式的打包文件，用于插件的安装、更新和分发；工具为一类可被工作流和Agent调用的插件，可封装第三方服务或本地逻辑；工具集为共享元信息和密钥配置的多子工具集合；默认运行时为local-pool，按单插件service维度管理Pod和请求队列。

## 插件安装与管理步骤
系统插件安装支持两种方式：一是系统级安装，root用户可在插件管理页面上传.pkg文件或从插件市场安装，安装后全系统可见；二是团队级安装，仅团队管理员或拥有插件管理权限的成员可操作，安装后仅团队内可见。安装完成后，可在管理页面查看插件状态，状态分为正常（可正常使用）、即将下线（不影响已有工作流运行，无法新增到工作流）、已下线（无法正常使用）三类。系统级插件还可配置系统密钥，由插件服务托管，调用方通过插件配置引用，无需直接接触明文密钥。

## 插件包协议说明
新版插件采用统一.pkg文件交付，构建产物通常包含dist/index.js、dist/manifest.json、图标文件，可选包含README.md和assets/**目录。插件包内包含插件元信息、输入输出schema、密钥schema和图标资源，可供FastGPT页面、工作流和Agent调用使用。
