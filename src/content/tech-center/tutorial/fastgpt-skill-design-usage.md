# FastGPT中AI智能体技能的设计原理与使用说明

## AI智能体技能的核心概念
AI智能体的“技能”是可持久保存、可复用的模块化专业流程与能力包。在主流AI生态的认知框架中，智能体可划分为三个核心层面：大脑负责规划与推理，即大模型本身；工具提供单纯的动作接口，类似AI的“手和脚”；技能则封装了完整的“做事章法与专业逻辑”，由说明文档和逻辑代码组成，如同家具组装手册，可让AI自动调用完成复杂任务。例如，若需反复核对财务表格并生成分析，可将计算代码与报告模板封装为技能，后续直接上传表格即可自动完成任务。

## 技能调试与发布流程
1. 进入技能编辑页面，创建或导入目标技能，所有操作运行在独立的安全运行沙箱中。
2. 使用集成了文件管理、代码编辑器和交互式终端的在线调试环境，在Web IDE中管理文件、使用交互终端进行对话调试，左侧配有智能体调试面板，支持“即改即生效”的热重载，可在发布前充分调试与排错。
3. 编辑区域的代码修改仅在调试区即时生效，点击「发布」按钮生成并保存正式版本后，改动才会正式应用到生产环境的智能体与工作流中。
4. 长期闲置的技能会被系统自动冷归档，当需要再次编辑或被调用时，将自动在后台重新拉起沙箱并复原，休眠期间不产生运行计费。

## FastGPT技能的核心设计特性
FastGPT的技能设计承袭业界主流标准，支持为智能体创建专属的独立代码空间，核心特性覆盖安全、效率、隔离与成本控制四个维度：独立的安全运行沙箱保障技能执行的安全性；即改即生效的调试环境简化开发流程；生产与调试环境的隔离避免了调试改动对线上业务的影响；自动休眠与无感唤醒机制则降低了闲置资源的使用成本。
