# FastGPT技能的创建、管理与调试操作说明

本页用于介绍FastGPT技能的开发与调试全流程，支持在沙盒环境中完成技能创建、文件管理、代码编辑、终端交互与对话调试，所有本地调试修改不会直接影响线上已发布的应用，需通过发布流程同步正式版本。

## 新建与导入技能
在编写代码前，需先在技能列表中创建开发项目，支持两种方式创建或载入技能：
1.  点击页面中的“新建”卡片（带加号标识），在弹窗中设置技能名称、图标、介绍与需求描述。若保留默认的“目标/流程/要求”模板，系统将生成内置基础结构与样例代码，无积分消耗；若输入具体功能需求，系统将调用默认大语言模型自动生成技能方案与初始化代码，会产生相应积分消耗。
2.  若已有备份或分享的技能，可点击页面右上角的“导入技能”按钮，上传ZIP格式的技能压缩包，系统将自动解压并还原所有代码与配置文件。

## 工作区管理与调试
在技能详情页打开后，系统将在安全的沙盒容器中为你初始化并拉起独立运行空间，右侧通过文件树加载项目文件。你可通过右键文件树或点击对应按钮，轻松完成文件的新建、删除、重命名与移动，灵活组织项目目录结构。点击文件树中的任意文件，即可在中央编辑器中打开并编辑代码：编辑器自带自动保存机制，代码修改完成后将自动同步至后台沙盒；文件树会实时感知编辑、终端操作或后台生成的新文件，自动刷新展示最新状态。需注意，此处的所有代码修改仅在调试区即时生效，不会直接影响线上已发布的应用，如需应用最新代码，需点击“发布”生成正式版本，具体发布逻辑可参考版本与发布文档。

右侧底部的命令行终端直接连接后台沙盒，支持输入各类命令行操作，例如在线安装代码依赖包、运行自定义测试与调试脚本等，同时会实时输出命令执行过程与日志，若代码或脚本运行出错，可通过终端报错信息辅助定位问题。

左侧的智能体调试面板提供测试环境，支持通过与智能体对话实时测试编写的技能逻辑：修改代码并保存后，无需手动编译、打包或重新部署，只需在左侧调试框发送下一条消息，系统便会自动运行最新代码，实现即改即生效；你还可直接通过与智能体对话，让其帮你编辑右侧的文件内容（包括创建、删除、修改等），右侧的文件树和编辑器会实时同步展示这些变化。点击页面右上角菜单中的“导出配置”，可将当前工作区的所有代码与配置文件打包为ZIP压缩包下载，方便本地备份或分享。
