# FastGPT系统工具在线上传、更新及权限管理操作指南

### 功能概述与权限说明
FastGPT 从 4.14.0 版本开始支持通过 Web 界面直接上传、更新系统工具，且支持热更新。该功能存在严格的权限限制：仅 root 用户可执行上传、更新或删除系统工具的操作，普通登录用户仅可查看已安装的系统工具。
支持上传的文件需为 `.pkg` 格式，单文件最大容量不超过 100 MB，单次上传最多可选择 15 个文件。需特别注意，待上传的工具文件必须来自 `fastgpt-plugin` 项目通过 `bun run build:pkg` 命令打包后的 `dist/pkgs` 文件夹，否则工具将无法正常加载或运行。

### 在线上传操作步骤
1. 进入配置页面：通过平台导航进入「应用构建 > 工具 > 系统工具」对应的配置页面。
2. 准备工具文件：提前从 `fastgpt-plugin` 项目打包生成的 `dist/pkgs` 文件夹中，获取符合要求的 `.pkg` 格式工具文件。
3. 执行上传操作：点击页面中的「导入/更新」按钮，在弹出的文件选择对话框中选中准备好的 `.pkg` 文件，确认文件信息无误后，点击「确认导入」按钮完成提交。
4. 上传结果验证：上传成功后页面会显示成功提示信息，随后自动刷新页面，新上传的系统工具将出现在工具列表中。
若遇到无法看到「导入/更新」按钮的问题，原因是当前登录用户并非 root 账户，需切换至 root 账户重新登录平台后再操作。

### 工具管理与注意事项
系统工具的管理权限严格区分角色：所有登录用户均可查看已安装的系统工具；仅 root 用户可执行上传新工具、更新已有工具、删除已上传工具的操作。
在上传工具前，需确认工具文件的来源合法性与安全性，避免引入风险内容。同时需严格遵守文件格式、大小与数量限制，否则上传操作将无法成功。上传后的系统工具将作为全平台可用的公共工具，需确保其适配当前平台版本。
