# 配置FastGPT团队模式与团队成员同步规则

## 团队模式类型说明
FastGPT 支持三种团队模式，分别为多团队模式（默认模式）、单团队模式、同步模式。多团队模式为默认启用的模式，每个用户创建账号时，会默认创建以自己为所有者的默认团队。单团队模式是 v4.9 推出的新功能，开启后所有新增用户不再创建自己的默认团队，而是直接加入 root 用户所在的团队，可简化企业的人员和资源管理流程。同步模式下，外部成员系统的成员会自动同步到 FastGPT 中，具体的同步方式和规则需参考 SSO 外部成员同步文档。

## 团队模式配置规则
不同团队模式对应不同的注册权限和团队创建规则，具体参数配置如下：单团队模式不支持短信/邮箱、SSO 注册，仅允许管理员直接添加成员，用户会自动加入 Root 团队且无需自行创建默认团队；多团队模式支持短信/邮箱、管理员直接添加、SSO 三种注册方式，用户创建账号时会自行创建默认团队，不会加入 Root 团队；同步模式不支持自行注册，团队成员由外部系统同步接入，用户会自动加入 Root 团队且无需自行创建默认团队。

## 团队模式配置步骤
配置 FastGPT 团队模式需在 fastgpt-pro 的系统配置-成员配置 模块中完成，具体操作流程为：1. 登录 FastGPT 管理员后台；2. 进入系统配置页面；3. 找到成员配置板块；4. 选择需要启用的团队模式并保存配置即可。
