# 说明FastGPT工具节点的运行条件、参数要求与调用逻辑

## 工具运行的前提条件
要了解工具如何运行，首先需明确其运行条件。第一，需具备工具的介绍（或描述），该介绍用于向LLM说明工具的作用，LLM会结合上下文语义判断是否调用该工具。第二，需具备工具的参数，参数包含两个关键值：参数介绍和是否必须。

## 工具调用的场景规则
结合工具介绍、参数介绍与参数是否必须，LLM会按以下场景判断是否调用工具。
1. 无参数工具：直接根据工具介绍决定是否执行，例如获取当前时间。
2. 有参数工具：
   - 无必须参数：即使上下文中无适合的参数，也可调用该工具，部分情况下LLM会自行伪造参数。
   - 有必须参数：若上下文中无适合的参数，LLM可能不会调用该工具，可通过提示词引导用户提供参数。
以下为工具参数的关键说明项：
| 参数项 | 核心说明 |
| --- | --- |
| 工具介绍 | 向LLM说明工具功能，作为调用判断依据 |
| 参数介绍 | 说明工具参数的用途与填写要求 |
| 是否必须 | 标识参数是否为调用工具的必要条件 |
