# 提升FastGPT向量搜索精度的配置与优化方法

向量搜索是FastGPT知识库检索的核心环节，其精度直接影响检索结果的相关性与可用性。针对不同业务场景的需求，可通过多维度优化手段，提升向量搜索的整体精度，保障检索结果匹配业务目标。

## 通用优化方向
优化分词与分段逻辑：当文本的结构与语义完整且单一时，可提升检索精度。FastGPT可通过优化分词器，保障每组数据的完整性。精简索引内容：减少索引的内容长度，当索引内容更少且更准确时，检索精度会自然提升，但会牺牲一定的检索范围，适合答案要求严格的场景。增加索引数量：可为同一个chunk内容增加多组索引，拓展检索覆盖的维度。优化检索词处理：用户的问题通常模糊或存在缺失，无法形成完整清晰的表述，优化检索词可有效提升精度。微调向量模型：市面上直接使用的向量模型多为通用型，在特定领域的检索精度有限，微调向量模型可提升专业领域的检索效果。

## 可落地的优化操作
1. 分词分段调整：按照语义完整性拆分文本，确保每组数据为单一完整语义单元，优化分词器配置以保障分组合理性。
2. 索引配置调整：根据业务场景选择优化方向，若需严格匹配答案，可精简索引内容；若需拓展检索范围，可为同一chunk添加多组索引。
3. 检索词预处理：对用户输入的检索词进行处理，修正模糊或缺失的表述，提升检索匹配精度。
4. 向量模型适配：基于业务领域的专属数据，对通用向量模型进行微调，适配专业场景的检索需求。
