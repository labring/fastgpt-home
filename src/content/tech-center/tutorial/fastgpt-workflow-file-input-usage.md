# FastGPT工作流中文件输入功能的配置与实际使用操作方法

## 功能入口配置
在FastGPT工作流的系统配置界面中，可找到`文件输入`配置项。点击该配置项右侧的`开启`或`关闭`按键，即可弹出对应的配置弹窗。该操作的配套示意图可在官方文档对应位置查看。

## 标准使用流程
开启文件输入功能后，可按照两类场景完成文件相关操作。第一类为简易文件处理：直接通过工具调用接入文档解析，实现与简易模式一致的使用效果，相关操作的示意图可参考官方文档中的并排配图。第二类为标准化文件处理流程：对上传的文档执行内容提取、内容分析操作，将分析得到的结果传递至HTTP或其他功能模块，搭建完整的文件处理SOP流程。文档解析的完整操作可参考官方配套的示意图。

## 操作辅助说明
所有与文件输入功能相关的操作步骤，均配有官方示意图辅助理解，可通过对应文档位置获取相关配图，帮助快速完成配置与流程搭建。
