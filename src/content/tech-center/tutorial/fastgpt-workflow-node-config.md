# FastGPT工作流节点的配置方法与运行逻辑说明

## 节点基础概念与分类
在FastGPT工作流中，节点可理解为单个功能步骤或接口，多个节点拼接即可实现复杂AI应用流程。节点分为两类：系统节点包括用户引导（配置对话框信息）、流程入口（用户问题节点，作为任务触发起点）；功能节点涵盖知识库搜索、AI对话等，均支持输入输出自由组合。每个节点包含输入、输出和触发器三个核心部分：输入支持手动填写或变量引用（变量范围为全局变量或此前任意节点的输出），AI模型、提示词、聊天记录等均为常见输入项；输出可被后续节点引用，新上下文与AI回复为典型输出；节点四周的四个连接点为触发器，左、上为前置线连接点，右、下为后置线连接点，用于搭建执行链路。

## 工作流运行逻辑与执行规则
FastGPT工作流从【流程开始】节点启动，无固定出口，当所有节点不再执行时流程结束。节点的连接分为前置线（被其他节点连接的线）和后置线（连接其他节点的线），线的状态分为waiting（等待执行）、active（可执行）、skip（跳过执行）。节点执行遵循以下原则：优先检查前置线是否有waiting状态，若有则等待；若存在active状态则执行当前节点；若前置线无waiting或active状态则跳过执行。节点执行完成后，需将后置线状态设为active或skip，同时将前置线设为waiting等待下一轮调用。

## 节点连接与基础配置步骤
1. 进入工作流编辑页面，添加【流程开始】节点作为任务入口，该节点会保存用户输入的问题；
2. 拖拽目标节点（如【AI对话】）到画布，将【流程开始】的后置连接点与【AI对话】的前置连接点相连；
3. 配置【AI对话】节点的必填参数：聊天记录默认使用6条上下文，用户问题需选择【流程开始】节点保存的用户问题变量；
4. 如需删除连接线，可点击连接线中间的`x`图标，左键点击可选中连接线进行调整。

若需合并多个输出结果，可使用文本加工节点合并字符串，或通过知识库搜索节点合并搜索结果；其他类型结果可传入HTTP节点，由业务服务完成合并。工作流适合需要多步骤串联的复杂AI应用，若仅需基础的AI对话或知识库搜索，无需使用工作流编排，避免增加不必要的配置成本。
