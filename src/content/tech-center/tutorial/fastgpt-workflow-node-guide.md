# 讲解FastGPT工作流节点的分类、运行逻辑与配置方法

## 节点基础定义与分类
节点即程序中的功能步骤或接口，可通过拼接实现复杂AI应用流程。节点分为两类：系统节点（如流程开始、用户引导）和功能节点（如知识库搜索、AI对话等）。每个节点包含输入、输出、触发器三个核心部分：输入支持手动输入或引用全局变量、前序节点输出；输出为新上下文、AI回复等，可被后续节点引用；节点四周的连接点为触发器，左、上为前置线连接点，右、下为后置线连接点。

## 工作流运行逻辑
工作流从流程开始节点启动，以节点运行结束作为出口，无固定出口。工作流中的连接线有waiting（等待执行）、active（可执行）、skip（跳过）三种状态。节点执行原则：先检查前置线是否有waiting状态，再检查是否有active状态，若两者都无则跳过该节点。节点执行完成后，需将后置线设为active或skip，并将自身前置线设为waiting等待下一轮调用。以流程开始→知识库搜索→AI对话的流程为例：流程开始执行后后置线设为active，知识库搜索检测到active前置线开始执行，执行后后置线设为active、前置线设为waiting，AI对话检测到active前置线执行，流程结束。

## 最小配置示例步骤
1. 进入工作流编辑页面，添加【流程开始】节点，该节点会保存用户输入的问题。
2. 添加【AI对话】节点，该节点有两个必填参数：`聊天记录`（默认值为6条上下文）和`用户问题`，此处选择【流程开始】节点保存的用户问题作为输入。
3. 点击【流程开始】节点的右侧后置连接点，再点击【AI对话】节点的左侧前置连接点，完成节点连线。
4. 保存工作流并测试，输入问题即可触发完整流程，获取AI回复。
