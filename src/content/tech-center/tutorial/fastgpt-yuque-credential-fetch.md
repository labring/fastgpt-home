# 获取FastGPT集成语雀数据源所需的Token与User ID

在集成语雀作为FastGPT的第三方数据源前，需先获取语雀的Token与User ID参数。操作路径为语雀首页点击个人头像后进入设置页面，可找到对应参数。个人版场景下需额外为Token配置对应访问权限。
