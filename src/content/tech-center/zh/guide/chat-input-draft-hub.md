# FastGPT 对话草稿与消息渲染的核对入口

对话页的体验细节常被当成小事跳过，但它们直接影响测试记录的可信度：草稿有没有留下、渲染范围到哪、页面请求是否被拦。下面三组入口覆盖这些点。

## 输入草稿

入口在对话输入框。核对动作是草稿按标签页分别保存，每个标签页最多十份，最后编辑后一小时有效；测试跨页面对话时先确认草稿没有被另一个标签页覆盖。失败表现是切页面回来草稿消失，原因是超过有效期或该标签页已存满十份。边界：草稿留在本地缓存，不跟随账号在多台设备间同步。

多标签页并行测试时，每个标签页的草稿各自独立，不把草稿当成跨页共享的暂存区；要复用内容，复制一次比切标签页可靠。

## 消息渲染

入口在消息气泡与 Markdown 组件。核对动作是确认 Markdown 里允许的有限 HTML 会按预期渲染，超出范围的标签按纯文本显示；涉及表格与代码块时检查换行与转义。失败表现是粘贴一段带样式的 HTML 后整条消息排版错乱。边界：渲染范围有限，不能当成完整网页容器使用。

渲染范围的变化最容易在粘贴外部内容时暴露：从网页复制一张带样式的表格，从此前文档复制一段代码块，各粘一次看结果。整段样式丢失时，先确认是不是超出了允许的标签范围，再去怀疑浏览器。

## 开场白与提示词

入口在应用配置的对话开场设置与提示词编辑器。核对动作是开场白支持多个预设问题并可拖拽排序，保存后按顺序展示；提示词编辑器里有输入指引与系统变量选择器，变量通过选择器插入，不手写变量名。失败表现是开场问题的顺序与配置不一致，或提示词里的变量名对不上导致运行时为空。边界：开场问题只影响首轮展示，不改变对话历史。

## 页面请求的防护

入口在浏览器控制台与请求记录。核对动作是确认页面请求带 CSRF 校验，跨站提交会被拒绝；把应用嵌进第三方页面时，先验证嵌入方式是否受影响。失败表现是嵌入后提交无响应，控制台出现校验失败。边界：这是请求层防护，与登录态失效是两类问题，排查时分开看。
