# FastGPT插件核心概念与操作使用说明

## 插件核心概念总览
FastGPT的插件体系包含多个标准化核心概念，用于实现功能模块化与复用。插件是独立可复用的功能模块，可分为工具、模型预设、知识库来源等类型。插件包为插件打包后的`.pkg`文件，是不同类型插件完成安装、更新与管理的统一载体。工具是一类插件，通常封装第三方服务、内部接口或本地计算逻辑，可被工作流和Agent调用。工具集为一个插件暴露多个相关子工具的形式，共享插件元信息和密钥配置。插件市场为集中管理插件的平台，支持用户搜索、下载和安装插件。运行时为负责执行插件代码的后端实现，当前默认运行时是 `local-pool`。Pod为本地进程池中的单个插件子进程，单个插件服务可拥有多个Pod。

## 插件核心概念对照表
| 名称     | 说明                                                                            |
| -------- | ------------------------------------------------------------------------------- |
| 插件     | 独立、可复用的功能模块，可以有不同类型，例如工具、模型预设、知识库来源等。      |
| 插件包   | 插件打包后的 `.pkg` 文件。不同类型插件都通过插件包完成安装、更新和管理。        |
| 工具     | 一类插件，通常封装第三方服务、内部接口或本地计算逻辑，可被工作流和 Agent 调用。 |
| 工具集   | 一个插件暴露多个相关子工具，共享插件元信息和密钥配置。                          |
| 插件市场 | 集中管理插件的平台，用户可以在其中搜索、下载和安装插件。                        |
| 运行时   | 负责执行插件代码的后端实现，当前默认运行时是 `local-pool`。                     |
| Pod      | 本地进程池中的单个插件子进程。一个插件 service 可以拥有多个 Pod。               |

## 插件基础操作流程
1. 将开发完成的插件打包为`.pkg`格式的插件包。
2. 访问插件市场，搜索所需插件并完成下载安装。
3. 若使用工具集插件，配置共享的元信息与密钥。
4. 插件将通过默认运行时`local-pool`启动，生成对应Pod子进程。
5. 工具类插件可被工作流和Agent调用。
